2. Σ is a finite set of symbols, called the input alphabet

5. F is a set of final states, which are the states that indicate a successful pattern match

DFAs are used to recognize regular languages, which are languages that can be described by regular expressions. Regular expressions are a compact way of describing patterns in strings, and are used in many applications, including text processing, lexical analysis, and pattern matching.
