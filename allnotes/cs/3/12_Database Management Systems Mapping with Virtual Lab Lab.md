Data Definition Language (DDL) Statements:
- Overview: DDL statements are used to define the structure of a database, including tables, columns, and relationships between tables.
- Key DDL statements:
  1. CREATE TABLE: Used to create a new table in the database.
  2. ALTER TABLE: Used to modify the structure of an existing table.
  3. DROP TABLE: Used to delete a table from the database.
  4. CREATE INDEX: Used to create an index on one or more columns of a table to improve query performance.
  5. DROP INDEX: Used to delete an index from a table.
- Usage:
  1. Creating a database: Use DDL statements to create tables, columns, and relationships between tables in a new database.
  2. Modifying a database: Use DDL statements to modify the structure of an existing database, including adding, modifying, or deleting tables and columns.
  3. Optimizing performance: Use DDL statements to create indexes on columns to improve query performance.

Note: DDL statements play a critical role in defining and managing the structure of a database. This unit covers the key DDL statements, including CREATE TABLE, ALTER TABLE, DROP TABLE, CREATE INDEX, and DROP INDEX, and the usage of these statements in creating and modifying a database, and optimizing performance.

- Overview: A set of SQL commands used to manipulate data stored in a database.
- Key DML commands:
  1. SELECT: Retrieve data from a database.
  2. INSERT: Insert data into a database.
  3. UPDATE: Modify data in a database.
  4. DELETE: Delete data from a database.
- How DML statements work:
  1. Connect to a database using a database management system (DBMS).
  2. Write a DML statement in SQL to perform the desired operation on the data.
  3. Execute the DML statement to perform the operation on the data.
  4. The DBMS returns the result of the operation, if any.
- Use cases:
  1. Retrieving data: SELECT statements are used to retrieve data from a database.
  2. Adding data: INSERT statements are used to add new data to a database.
  3. Updating data: UPDATE statements are used to modify existing data in a database.
  4. Deleting data: DELETE statements are used to delete data from a database.

Note: Data Manipulation Language (DML) statements are a crucial part of database management. This unit covers the key DML commands, including SELECT, INSERT, UPDATE, and DELETE, and how they work. The unit also covers the use cases for DML statements, including retrieving data, adding data, updating data, and deleting data.

## Transaction Control Language(TCL) statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

Transaction Control Language (TCL) statements:
- Overview: TCL statements are used to manage transactions in a database management system.
- Key TCL statements:
  1. COMMIT: Saves changes made during a transaction to the database.
  2. ROLLBACK: Reverses all changes made during a transaction.
  3. SAVEPOINT: Creates a savepoint within a transaction to allow partial rollback of changes.
  4. SET TRANSACTION: Specifies the transaction characteristics, such as isolation level and transaction name.
- Usage: TCL statements are used in conjunction with the Data Manipulation Language (DML) statements, such as SELECT, INSERT, UPDATE, and DELETE, to manage transactions in a database.
- Benefits: TCL statements help ensure data consistency and integrity by allowing for the management of transactions in a database. They also help ensure that changes made to the database during a transaction are either saved or discarded as needed.

Note: TCL statements are an important component of database management systems and are used to manage transactions in a database. This unit covers the key TCL statements, including COMMIT, ROLLBACK, SAVEPOINT, and SET TRANSACTION, and explains how they are used to ensure data consistency and integrity in a database.
