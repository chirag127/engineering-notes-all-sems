### Definition of Cloud for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing is a model for delivering information technology services over the internet. It enables on-demand access to a shared pool of configurable computing resources, such as servers, storage, databases, networks, and software, without the need for direct management by the user.

The definition of cloud computing can be broken down into several key components:

1. On-demand access: Cloud computing provides users with the ability to access computing resources as needed, without the need for long-term commitments or upfront investments.

2. Shared pool of resources: Cloud computing provides users with access to a shared pool of computing resources, such as servers, storage, databases, and software, that can be dynamically provisioned and released as needed.

3. Internet delivery: Cloud computing services are delivered over the internet, allowing users to access them from anywhere with an internet connection.

4. Pay-per-use model: Cloud computing provides a pay-per-use pricing model, where users only pay for the resources they actually use.

There are three main types of cloud computing:

1. Infrastructure as a Service (IaaS): This type of cloud computing provides users with access to raw computing infrastructure, such as servers, storage, and networking, that can be used to build and run applications.

2. Platform as a Service (PaaS): This type of cloud computing provides users with access to a platform for building and running applications, without the need to manage the underlying infrastructure.

3. Software as a Service (SaaS): This type of cloud computing provides users with access to software applications that are hosted and managed by a third-party provider.

In conclusion, cloud computing is a model for delivering information technology services over the internet, providing on-demand access to a shared pool of configurable computing resources, such as servers, storage, databases, networks, and software, without the need for direct management by the user. Cloud computing is delivered over the internet and is typically priced on a pay-per-use basis, and there are three main types of cloud computing: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
### Evolution of Cloud Computing for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing is a technology that has evolved significantly over the past few decades. The evolution of cloud computing can be broadly divided into several stages:

1. Mainframe computing (1960s-1970s): During this stage, large mainframe computers were used to perform complex calculations for businesses and government agencies. 

2. Client-server computing (1980s-1990s): During this stage, personal computers were introduced, and the client-server model became popular, where client computers communicated with server computers to access shared resources. 

3. Grid computing (1990s-2000s): During this stage, the concept of grid computing emerged, where multiple computers were connected to work together to perform complex tasks, such as scientific simulations and data analysis.

4. Utility computing (2000s-2010s): During this stage, the concept of utility computing emerged, where computing resources were treated as a utility, similar to electricity or water, and were provided on-demand over the internet. 

5. Cloud computing (2010s-present): During this stage, cloud computing became mainstream, with the development of large-scale, highly-available, and scalable cloud infrastructure, such as Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). 

Advantages of cloud computing include:

1. Cost savings: Cloud computing allows businesses to reduce their IT costs by paying only for the computing resources they use, rather than having to invest in and maintain their own infrastructure.

2. Scalability: Cloud computing allows businesses to quickly and easily scale their computing resources up or down as needed, without having to invest in new hardware.

3. Flexibility: Cloud computing allows businesses to access a wide range of computing resources, such as storage, computing power, and databases, on-demand, and from anywhere with an internet connection.

Disadvantages of cloud computing include:

1. Security: Cloud computing can be vulnerable to security threats, such as hacking and data theft, and businesses must take steps to secure their data in the cloud.

2. Dependence on internet connectivity: Cloud computing requires a reliable internet connection, and if the connection is lost, access to cloud resources may be disrupted.

In conclusion, the evolution of cloud computing can be divided into several stages, from mainframe computing to cloud computing, and cloud computing provides many advantages, including cost savings, scalability, and flexibility, but also has disadvantages, including security and dependence on internet connectivity.

1. Client-server architecture: REST divides the application into two parts, the client and the server, which communicate with each other using HTTP.

2. Statelessness: REST does not maintain any state between requests, meaning that each request is independent and contains all the information necessary to complete the request.

3. Cacheability: REST allows for caching of responses, which can improve performance and reduce server load.

4. Layered system: REST allows for the use of intermediaries, such as proxy servers and load balancers, between the client and the server, which can improve scalability and security.

3. Scalability: SoS is designed to be scalable, allowing for the addition of new systems and technologies as needed.

4. Flexibility: SoS is designed to be flexible, allowing for changes to be made to individual systems without affecting the entire system.

In conclusion, REST is a software architectural style used for designing web services, based on the HTTP protocol and defined by constraints and best practices for creating scalable and reliable web services. ### Publish, Subscribe Model for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

The Publish/Subscribe (Pub/Sub) Model is a messaging pattern used in cloud computing and IoT. It is a communication paradigm where senders (publishers) of messages do not send messages directly to specific receivers (subscribers), but instead categorize published messages into classes without knowledge of which subscribers, if any, there may be. Subscribers express interest in one or more classes and only receive messages that are of interest, without knowledge of which publishers, if any, there are.

Advantages of Pub/Sub Model:
1. Loose coupling: Publishers and subscribers are loosely coupled and do not need to know about each other.
2. Scalability: The system can scale easily as the number of publishers and subscribers increases.
3. Decoupling: The communication between publishers and subscribers is decoupled, allowing for greater flexibility and reliability.

Examples of Pub/Sub Model in cloud computing:
1. Event-driven architecture: Applications can publish and subscribe to events, allowing for real-time communication and data processing.
2. Message brokers: Services can use message brokers to publish and subscribe to messages, allowing for asynchronous communication and decoupled processing.
3. IoT: IoT devices can use the Pub/Sub Model to publish and subscribe to sensor data, allowing for real-time monitoring and control.
