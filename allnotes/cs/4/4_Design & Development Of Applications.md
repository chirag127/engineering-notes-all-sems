### Design patterns for mobile applications for the notes of the Unit 3 - ADVANCED DESIGN in the subject of Design & Development Of Applications

1. Model-View-Controller (MVC): Separates application logic, data, and user interface into three distinct components.

2. Model-View-Presenter (MVP): Similar to MVC, but with a focus on a clear separation of responsibilities between the presenter and the view.

3. Model-View-ViewModel (MVVM): Similar to MVP, but with a focus on data binding between the model and the view.

4. Singleton: Ensures that a class has only one instance, while providing a global point of access to it.

5. Factory: Defines an interface for creating objects, but lets subclasses decide which class to instantiate.

6. Observer: Defines a one-to-many dependency between objects, so that when one object changes state, all its dependents are notified and updated automatically.

7. Command: Encapsulates a request as an object, allowing for deferred execution and the ability to queue or log requests.

8. Decorator: Adds behavior to an individual object, either statically or dynamically, without affecting the behavior of other objects from the same class.

9. Facade: Provides a simplified interface to a complex system, hiding its underlying complexity.

10. Adapter: Allows classes with incompatible interfaces to work together by wrapping its own interface around that of an already existing class.
