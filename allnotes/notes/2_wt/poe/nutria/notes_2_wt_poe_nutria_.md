### Protocols Governing Web

* Hypertext Transfer Protocol (HTTP) is the set of rules that governs how web pages are transmitted over the internet. It is the foundation of the World Wide Web and is used by web browsers and web servers to communicate with each other.
* Hypertext Transfer Protocol Secure (HTTPS) is a secure version of HTTP that uses encryption to protect data transmitted between a web browser and a web server.
* Secure Sockets Layer (SSL) is a protocol used to secure data transmitted over the internet. It is used to authenticate web servers and encrypt data transmitted between them and web browsers.
* Transport Layer Security (TLS) is the successor to SSL and is used to secure data transmitted over the internet. It is used to authenticate web servers and encrypt data transmitted between them and web browsers.
* Domain Name System (DNS) is a distributed database used to translate domain names into IP addresses. It is used by web browsers and web servers to locate web pages on the internet.
