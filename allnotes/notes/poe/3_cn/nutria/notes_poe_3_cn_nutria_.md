### Introductory Concepts of Computer Networks

- **Network**: A network is a collection of two or more computers that are connected together to share data and resources.
- **Protocols**: Protocols are the set of rules that govern how data is transmitted between two computers. Common protocols include TCP/IP, UDP, and HTTP.
- **Topology**: Topology is the physical or logical arrangement of a network. Common topologies include bus, star, and mesh.
- **IP Addressing**: IP addressing is the process of assigning an IP address to a computer in a network. IP addresses are used to identify a computer on a network and enable data to be routed to the correct destination.
- **Subnetting**: Subnetting is the process of dividing a network into smaller networks called subnets. This allows for more efficient routing of data and improved network security.
- **Routing**: Routing is the process of forwarding data from one network to another. Routers are used to forward data between networks.
- **Switching**: Switching is the process of forwarding data between two or more computers in the same network. Switches are used to forward data between computers in a network.
- **Firewalls**: Firewalls are used to protect a network from unauthorized access. Firewalls can be used to filter data and block malicious traffic.
- **Virtual Private Networks (VPNs)**: VPNs are used to create a secure connection between two or more computers over the internet. VPNs are commonly used to securely access a corporate network from a remote location.

### Organization of the Internet

The Internet is a complex network of interconnected computers and devices that share information with each other. It has evolved from a small, experimental network to a global network that is used by billions of people every day.

The Internet is organized into four main layers: the physical layer, the data link layer, the network layer, and the application layer. Each layer has its own set of protocols and standards that govern how data is transferred and how devices interact with each other.

At the physical layer, the physical components of the network, such as cables, routers, and switches, are used to connect computers and devices to each other.

At the data link layer, the data is broken down into small packets and transmitted over the physical layer. This layer is responsible for providing reliable communication between two computers or devices.

At the network layer, routers and switches are used to forward data packets from one computer or device to another. This layer is responsible for routing data packets across the network.

At the application layer, applications such as web browsers, email clients, and file transfer programs are used to access the network and exchange data with other computers and devices.

In order to remember the four layers of the Internet, a good mnemonic is "P-D-N-A", which stands for Physical, Data Link, Network, and Application.

#### Protocols and Standards in Networks Architecture in Computer Networks

#### The OSI reference model in in Computer Networks 

The OSI (Open Systems Interconnection) reference model is a layered, abstract description of network communication used to guide the design of network protocols. It was developed in the late 1970s by the International Organization for Standardization (ISO) and is now widely accepted as the standard for network communication.

The OSI reference model is composed of seven layers, each of which is responsible for a different aspect of network communication. The layers are organized from the physical layer (layer 1) to the application layer (layer 7).

Layer 1: Physical Layer
The physical layer is responsible for the transmission of raw bits over a physical medium. It defines the electrical, mechanical, and procedural characteristics for network communication.

Layer 2: Data Link Layer
The data link layer is responsible for providing reliable data transfer between two directly connected nodes. It is responsible for error detection and correction, flow control, and media access control.

Layer 3: Network Layer
The network layer is responsible for routing and forwarding packets between nodes in a network. It is responsible for logical addressing, routing decisions, and congestion control.

Layer 4: Transport Layer
The transport layer is responsible for providing reliable end-to-end communication between two nodes. It is responsible for segmentation and reassembly of data, sequencing, flow control, and error control.

Layer 5: Session Layer
The session layer is responsible for managing communication sessions between two nodes. It is responsible for establishing, maintaining, and terminating communication sessions.

Layer 6: Presentation Layer
The presentation layer is responsible for formatting and presenting data to the application layer. It is responsible for encoding, compression, and encryption.

Layer 7: Application Layer
The application layer is responsible for providing services to the user. It is responsible for providing user interfaces, file transfer, and other services.

#### Network Performance and Transmission Impairments in Computer Networks

* Network performance is a measure of how well a network is performing, and is typically measured in terms of throughput, latency, and packet loss.
* Transmission impairments are any factors that can degrade the performance of a network, such as noise, interference, and signal attenuation.
* Noise is any unwanted signal that can interfere with the transmission of data. Examples of noise include static, crosstalk, and thermal noise.
* Interference occurs when two or more signals overlap, resulting in a distorted signal. Common sources of interference include other wireless networks, electrical devices, and even the sun.
* Signal attenuation is the weakening of a signal as it travels through a medium, such as a cable or a wireless channel. This is caused by factors such as distance, obstacles, and the environment.
* Error detection and correction techniques can be used to reduce the impact of transmission impairments. Examples include forward error correction, automatic repeat request, and cyclic redundancy check.
* Quality of Service (QoS) is a set of techniques used to prioritize certain types of network traffic. This can help to reduce the impact of transmission impairments and improve the overall performance of a network.
