  1. Define the problem: This involves specifying the initial state, the goal state, and the actions or operators that can change the state of the problem.
  2. Formulate a search space: This involves representing the problem as a graph or a tree, where the nodes are the possible states and the edges are the actions or operators that can lead from one state to another.
  3. Choose a search strategy: This involves selecting a method of exploring the search space, such as breadth-first search, depth-first search, heuristic search, etc.
  4. Execute the search: This involves applying the chosen search strategy to find a path from the initial state to the goal state, or to find an optimal solution that minimizes some cost function.
  5. Evaluate the solution: This involves assessing the quality and validity of the solution, and comparing it with other possible solutions or alternatives.

### Uninformed Search Methods in Artificial Intelligence

- No heuristics: Uninformed search methods do not use any additional information, such as heuristics or cost functions, to guide the search process. They rely only on the problem definition and the search strategy.
- Completeness: Uninformed search methods are guaranteed to find a solution if one exists, as long as the search space is finite and the branching factor is bounded. However, this may take a long time or a lot of memory, depending on the size and complexity of the problem.
- Optimality: Uninformed search methods are not guaranteed to find the optimal solution, unless the search strategy is uniform-cost search, which expands the nodes with the lowest path cost first. Other uninformed search methods may find a suboptimal solution or a solution with a higher cost.

### Heuristics for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

- A heuristic is a technique that guides the search process towards a goal state in a problem-solving domain.
- A heuristic function, denoted by h(n), estimates the cost of reaching the goal from a given node n in the search space.
- A heuristic function is also called an evaluation function or a cost function.
- A heuristic function is domain-specific and depends on the knowledge of the problem.
- A heuristic function should be consistent, admissible, and efficient.
- A heuristic function is consistent if for every node n and every successor n' of n generated by any action a, the estimated cost of reaching the goal from n is no greater than the step cost of getting to n' plus the estimated cost of reaching the goal from n'.
- A heuristic function is admissible if it never overestimates the cost of reaching the goal, i.e., the cost it estimates is not higher than the lowest possible cost from the current node in the search space.
- A heuristic function is efficient if it can be computed in polynomial time and does not use too much memory.
- Some examples of heuristic functions are:
  - Manhattan distance: the sum of the absolute values of the differences of the coordinates of the current state and the goal state.
  - Euclidean distance: the square root of the sum of the squares of the differences of the coordinates of the current state and the goal state.
  - Straight-line distance: the distance between the current state and the goal state as if there were no obstacles in the way.
  - Number of misplaced tiles: the number of tiles that are not in their goal position in a sliding tile puzzle.
  - Number of conflicts: the number of pairs of queens that are attacking each other in a n-queens problem.
  - Number of unsatisfied clauses: the number of clauses that are false in a Boolean formula in a satisfiability problem.

### Searching with Partial Observations

- Searching with partial observations is a problem-solving method in artificial intelligence that deals with environments that are **partially observable**, meaning that the agent cannot access the complete state of the environment at any given time .
- In such environments, an agent can be in one of several possible states, and an action can lead to one of several possible outcomes. Therefore, the agent needs to maintain a **belief state**, which is a set of possible states that are consistent with the agent's observations and actions.
- A belief state can be represented as a **contingency plan**, which is a tree of actions and observations that specifies what the agent should do in each possible situation. A contingency plan can be constructed by **searching** in the space of belief states, using algorithms such as **AND-OR search** or **expectimax search**.
- Searching with partial observations can be challenging because the size of the belief state can grow exponentially with the number of actions and observations, and because the agent may not have enough information to distinguish between different states.   - **Observation compression**: reducing the number of possible observations by grouping them into equivalence classes that have the same effect on the belief state.

- A constant is a symbol that denotes a specific object in the domain. Constants are usually denoted by uppercase letters such as `A`, `B`, `C`, etc. For example, `P(A)` means that the object `A` has property `P`.
- A term is either a variable or a constant. Terms are used to refer to objects in the domain.
- An atomic formula is a predicate applied to one or more terms. For example, `P(x)`, `R(x,y)`, and `Q(A,B)` are atomic formulas.
- A formula is either an atomic formula or a complex formula. A complex formula is formed by applying logical connectives (such as `¬`, `∧`, `∨`, `→`, `↔`) and quantifiers to other formulas. For example, `¬P(x)`, `P(x) ∧ Q(x)`, `∀x (P(x) → Q(x))`, and `∃x ∃y (R(x,y) ∧ ¬R(y,x))` are formulas.
- A sentence is a formula that has no free variables. A free variable is a variable that is not bound by a quantifier. For example, `P(x)` is not a sentence because `x` is a free variable, but `∀x P(x)` is a sentence because `x` is bound by the universal quantifier.
- A model is a structure that assigns a domain of objects, a value to each constant, and an interpretation to each predicate. A model satisfies a sentence if the sentence is true under the model. - A sentence is a logical consequence of a set of sentences if every model that satisfies the set also satisfies the sentence. For example, `Q(A)` is a logical consequence of the set `{P(A), ∀x (P(x) → Q(x))}` because every model that makes `P(A)` and `∀x (P(x) → Q(x))` true also makes `Q(A)` true.

### Reasoning Systems for Categories

- Reasoning is the process of drawing logical conclusions from a set of facts, rules, and beliefs.
- In artificial intelligence, reasoning systems are used to represent and manipulate knowledge, and to infer new information from existing knowledge.
- Reasoning systems can be classified into different categories based on the type of logic, the type of knowledge, and the type of inference they use.
- Some of the common categories of reasoning systems are:

  - **Deductive reasoning systems**: These systems use rules of logic to derive conclusions from a set of premises. For example, if A implies B, and A is true, then B is true. Deductive reasoning systems are sound, meaning that they always produce valid conclusions, but they are not complete, meaning that they may not be able to derive all possible conclusions from a given set of premises. Deductive reasoning systems are also called rule-based systems or production systems .
  - **Inductive reasoning systems**: These systems use examples or observations to generalize patterns or rules. For example, if all the observed birds can fly, then one can induce that all birds can fly. Inductive reasoning systems are not sound, meaning that they may produce invalid conclusions, but they are complete, meaning that they can derive any possible conclusion from a given set of premises. Inductive reasoning systems are also called learning systems or data-driven systems .
  - **Abductive reasoning systems**: These systems use a set of facts and a goal to infer the most likely explanation or hypothesis. For example, if one observes that the grass is wet, and the goal is to explain why, then one can abduce that it rained. Abductive reasoning systems are neither sound nor complete, meaning that they may produce invalid or incomplete conclusions, but they are useful for generating plausible hypotheses or solutions. Abductive reasoning systems are also called diagnostic systems or hypothesis-driven systems .
  - **Common sense reasoning systems**: These systems use general knowledge about the world and human behavior to reason about everyday situations. For example, if one sees a person holding an umbrella, one can infer that it is raining or that the person expects rain. Common sense reasoning systems are based on heuristics, analogies, and default assumptions, and they can handle uncertainty, ambiguity, and inconsistency. Common sense reasoning systems are also called natural language understanding systems or cognitive systems.
  - **Monotonic reasoning systems**: These systems assume that the knowledge base is consistent and complete, and that new information does not contradict or invalidate existing information. For example, if one knows that all birds can fly, and one learns that a penguin is a bird, then one can still conclude that all birds can fly. Monotonic reasoning systems are simpler and faster, but they are not realistic or flexible. Monotonic reasoning systems are also called classical logic systems or closed-world systems .
  - **Non-monotonic reasoning systems**: These systems allow the knowledge base to be inconsistent and incomplete, and that new information can contradict or invalidate existing information. For example, if one knows that all birds can fly, and one learns that a penguin is a bird, then one has to retract the previous conclusion that all birds can fly. Non-monotonic reasoning systems are more complex and slower, but they are more realistic and flexible. Non-monotonic reasoning systems are also called non-classical logic systems or open-world systems .

- These categories are not mutually exclusive, and some reasoning systems can combine or switch between different types of reasoning depending on the context and the task. For example, a procedural reasoning system (PRS) is a framework for constructing real-time reasoning systems that can perform complex tasks in dynamic environments. It is based on the notion of a rational agent or intelligent agent using the belief–desire–intention software model. A user application is predominately defined by a set of procedural knowledge, called plans, that specify how to achieve goals or react to events. A PRS can use deductive, inductive, abductive, or common sense reasoning depending on the situation and the available knowledge.



### Reasoning with Default Information

- Reasoning with default information is a form of non-monotonic reasoning that allows for drawing plausible conclusions from incomplete or uncertain information, based on general rules that may have exceptions .
- Non-monotonic reasoning is a type of reasoning that does not follow the principle of monotonicity, which states that adding new information to a set of premises cannot reduce the set of conclusions that can be derived from them. In other words, non-monotonic reasoning allows for revising or retracting conclusions when new information contradicts or invalidates them .
- Reasoning with default information is useful in artificial intelligence, as it can model common sense reasoning, handle uncertainty and inconsistency, and cope with incomplete knowledge  .
- One of the most influential formalisms for reasoning with default information is default logic, proposed by Raymond Reiter in 1980  . Default logic consists of a set of facts (the background theory) and a set of default rules, each of the form: p:q/r, where p is the prerequisite, q is the justification, and r is the consequent. A default rule can be read as: if p is true and q is consistent with the facts, then assume r. However, r can be withdrawn if new facts contradict it  .
- For example, consider the following default rule: Bird:Flies/Flies. This means that if something is a bird and it is consistent with the facts that it flies, then assume that it flies. However, this assumption can be retracted if new facts show that the bird is exceptional, such as a penguin or an ostrich  .
- A default theory is a pair of a background theory and a set of default rules. A default theory can have multiple extensions, which are sets of conclusions that can be derived from applying the default rules in a consistent way. An extension is said to be normal if it contains the consequent of every default rule whose prerequisite and justification are in the extension. A default theory is said to be normal if it has at least one normal extension  .
- For example, consider the following default theory: {Tweety is a bird, Bird:Flies/Flies}. This theory has two extensions: {Tweety is a bird, Tweety flies} and {Tweety is a bird}. The first extension is normal, as it contains the consequent of the default rule whose prerequisite and justification are in the extension. The second extension is not normal, as it does not contain the consequent of the default rule. However, both extensions are consistent with the facts  .
- Reasoning with default information can be applied to various domains and tasks in artificial intelligence, such as natural language understanding, planning, diagnosis, learning, and knowledge representation  . However, it also faces some challenges and limitations, such as computational complexity, non-uniqueness of extensions, and lack of expressiveness for some types of defaults  .

### Language Models

- A language model is an AI model that has been trained to predict the next word or words in a text based on the preceding words.
- Language models are useful for various natural language processing tasks, such as speech recognition, machine translation, text summarization, text generation, and question answering.
- Language models can be classified into two broad categories: statistical language models and neural language models.
- Statistical language models use probabilistic methods to estimate the likelihood of a word or a sequence of words given the previous words. They are based on the assumption that words are independent of each other, and that the probability of a word depends only on a fixed number of previous words.
- Some examples of statistical language models are:
  - Unigram language model: a simple model that assumes that each word is independent of the others, and that the probability of a word is based on its frequency in the training corpus.
  - N-gram language model: a generalization of the unigram model that considers the probability of a word based on the previous n-1 words, where n is a parameter that determines the size of the context.
  - Exponential language model: a model that uses a weighted combination of features, such as word identity, part-of-speech, and syntactic structure, to estimate the probability of a word given the previous words.
- Neural language models use deep learning techniques to learn a distributed representation of words and their contexts, and to generate words based on the learned representation. They are based on the assumption that words are not independent of each other, and that the probability of a word depends on the entire history of previous words.
- Some examples of neural language models are:
  - Feedforward neural network language model: a model that uses a multilayer perceptron to learn a nonlinear mapping from the previous words to the next word.
  - Recurrent neural network language model: a model that uses a recurrent neural network to capture the sequential dependencies among words, and to update its hidden state based on the previous words and the current word.
  - Transformer language model: a model that uses a self-attention mechanism to learn the relationships among words in a given context, and to generate words based on the learned attention weights.
  - Large language model: a model that has been trained on a massive amount of text data, using machine learning algorithms, to generate human-like responses to text-based inputs. An example of a large language model is GPT-3, which has 175 billion parameters and was trained on 570 gigabytes of text .
- Language models have many applications in AI, such as:
  - Improving the performance of other natural language processing systems, such as speech recognition, machine translation, text summarization, text generation, and question answering, by providing them with a probabilistic estimate of the next word or words in a given context.
  - Generating natural and coherent texts for various purposes, such as writing articles, stories, poems, lyrics, captions, reviews, summaries, headlines, etc .

  - Analyzing and understanding natural language texts, such as sentiment, emotion, tone, style, topic, etc .
  - Generating novel and creative texts, such as jokes, puns, metaphors, analogies, etc .

### Machine Translation

Machine translation is the process of using artificial intelligence to automatically translate text from one language to another without human involvement. Machine translation can be used for various purposes, such as:

- Communicating with people who speak different languages
- Accessing information in foreign languages
- Publishing multilingual content
- Learning new languages

Machine translation can be classified into different types, depending on the methods and techniques used. Some of the common types are:

- **Rule-based machine translation**: This type of machine translation uses a set of linguistic rules and dictionaries to translate words and phrases from one language to another. Rule-based machine translation is often limited by the complexity and variability of natural languages, and requires a lot of human effort to maintain and update the rules and dictionaries.
- **Statistical machine translation**: This type of machine translation uses statistical models and algorithms to learn from large corpora of parallel texts (texts that are aligned in two or more languages). Statistical machine translation can handle more variations and ambiguities in natural languages, but it may also produce errors and inconsistencies due to the lack of linguistic knowledge and context.
- **Neural machine translation**: This type of machine translation uses artificial neural networks, a form of deep learning, to learn from large corpora of parallel texts. Neural machine translation can translate entire sentences instead of single words, making it faster and more accurate. Neural machine translation can also capture the meaning and style of the original text, and generate more natural and fluent translations.

Machine translation is a challenging and evolving field of artificial intelligence, as it involves many aspects of natural language processing, such as:

- Morphology: The study of the structure and formation of words
- Syntax: The study of the rules and patterns of sentence structure
- Semantics: The study of the meaning and interpretation of words and sentences
- Pragmatics: The study of the use and effect of language in different situations and contexts
- Discourse: The study of the structure and coherence of texts and conversations

Machine translation is also influenced by many factors, such as:

- The quality and quantity of the parallel texts used for training the models
- The similarity and difference between the source and target languages
- The domain and genre of the text to be translated
- The purpose and audience of the translation

Machine translation is not a perfect solution for all translation needs, as it may still have limitations and errors, such as:

- Loss of information or meaning due to word order, grammar, or cultural differences
- Addition of information or meaning that is not present or intended in the original text
- Inconsistency or ambiguity in the use of terminology, style, or tone
- Lack of context or background knowledge to understand the text or the translation

Machine translation can be improved by using various techniques, such as:

- Pre-processing: The process of preparing the text for translation, such as tokenization, normalization, segmentation, or alignment
- Post-processing: The process of refining the translation, such as spell-checking, punctuation, or formatting
- Evaluation: The process of measuring the quality and accuracy of the translation, such as using metrics, human feedback, or automatic tools
- Adaptation: The process of customizing the machine translation system to a specific domain, genre, or user, such as using domain-specific corpora, terminology, or preferences

Machine translation is a useful and powerful tool for overcoming language barriers and facilitating communication and information exchange. However, machine translation is not a substitute for human translation, as it may not be able to capture the nuances, subtleties, and emotions of human language. Machine translation should be used with caution and awareness, and complemented by human intervention and verification when necessary.

### Hardware for Artificial Intelligence

Hardware for artificial intelligence (AI) refers to the specialized computer hardware that is used to execute AI programs faster and with less energy. Hardware for AI can be classified into four main types:

- **CPU** – Central Processing Units are the general-purpose processors that can run various types of instructions. CPUs are good for sequential and logical tasks, but they have limited parallelism and memory bandwidth. CPUs are often used as the main processor in AI systems, and they can also handle the preprocessing and postprocessing of data.
- **GPU** – Graphics Processing Units are chips designed to speed up multidimensional data processing, such as images, videos, and matrices. GPUs have thousands of smaller cores that can work independently on a subspace of input data that requires heavy computing. GPUs are good for parallel and numerical tasks, but they have high power consumption and programming complexity. GPUs are often used as the dedicated hardware for AI modeling and training, especially for deep learning algorithms.
- **FPGA** – Field Programmable Gate Arrays are chips that can be configured to implement any logic function. FPGAs have high flexibility and reconfigurability, but they have low performance and high cost compared to GPUs and ASICs. FPGAs are often used as the dedicated hardware for AI inference and deployment, especially for edge computing and low-power applications.
- **ASIC** – Application Specific Integrated Circuits are chips that are designed for a specific purpose or function. ASICs have high performance and low power consumption, but they have low flexibility and high development cost. ASICs are often used as the dedicated hardware for AI inference and deployment, especially for cloud computing and high-performance applications.

Modern AI systems often combine powerful multicore CPUs with one or more of the dedicated hardware types to achieve the best balance of speed, accuracy, and efficiency. Some examples of AI hardware are:

- **Lisp machines** – These are specialized computers that were designed to run Lisp, a programming language that was widely used for AI research in the 1970s and 1980s. Lisp machines had features such as garbage collection, dynamic typing, and symbolic manipulation that made them suitable for AI applications. However, Lisp machines became obsolete as general-purpose computers became faster and cheaper.
- **Neuromorphic engineering** – This is a field that aims to design hardware that mimics the structure and function of biological neural networks. Neuromorphic hardware can have advantages such as low power consumption, high parallelism, and adaptive learning. However, neuromorphic hardware is still in its infancy and faces challenges such as scalability, reliability, and compatibility.
- **Event cameras** – These are sensors that capture changes in brightness instead of intensity values. Event cameras can have advantages such as high temporal resolution, low latency, and high dynamic range. However, event cameras also have drawbacks such as noise, sparsity, and non-uniformity. Event cameras can be used for AI applications such as object detection, tracking, and recognition.
- **Physical neural networks** – These are hardware systems that use physical phenomena such as light, sound, or fluid to implement neural network operations. Physical neural networks can have advantages such as high speed, low power consumption, and analog computation. However, physical neural networks also have limitations such as noise, precision, and stability. Physical neural networks can be used for AI applications such as image processing, speech recognition, and natural language processing.
