### Classification of Data

1. Qualitative Data: Data that represents qualities or characteristics. For example, color, size, shape, texture, smell, etc. Qualitative data is descriptive in nature.
2. Quantitative Data: Data that represents quantities or numbers. For example, age, weight, temperature, speed, etc. Quantitative data can be measured precisely using tools or instruments.
3. Discrete Data: Data that has distinct values. For example, number of children in a family which can only be 0, 1, 2, 3, and so on. Discrete data can only take certain values.
4. Continuous Data: Data that can take any value within a range. For example, height, weight, temperature, etc. Continuous data can have any value and is not restricted to discrete values.
5. Structured Data: Data that has a defined format or pattern and can be easily stored in relational databases. For example, data in Excel sheets, databases, etc.
6. Unstructured Data: Data that does not have a defined format or pattern. For example, images, videos, text documents, audio, etc. Unstructured data is difficult to analyze.

### Evolution of Analytic Scalability

The following points summarize the evolution of analytic scalability:

1.  Manual Analysis: In the initial days, data analysis was performed manually by data analysts. They used to extract data, clean it and then analyze it manually to draw insights. This was a tedious and time-consuming process with limited scalability.
2.  Spreadsheets: The advent of spreadsheets like Excel made data analysis slightly easier. Analysts could now import data into spreadsheets, apply formulas and conduct some basic analytics. However, spreadsheets still had scalability limitations in terms of data volume and complexity of analysis.
3.  Statistical Packages: Dedicated statistical packages like SPSS and SAS were next in the evolution. They provided a broader set of analytic capabilities and could handle larger data volumes. However, they required specialized expertise and had certain limitations in scalability.
4.  Data Mining Tools: Data mining tools were then introduced to automate certain analytics processes. Tools like IBM SPSS Modeler and KNIME provided automated data mining and machine learning capabilities and improved scalability. However, they still had certain limitations, especially with extremely large data volumes.
5.  Big Data Analytics: The evolution of big data technologies like Hadoop and Spark has now enabled massive scalability in data analytics. These technologies can handle huge volumes and varieties of data and enable advanced analytics, machine learning and deep learning on big data. They power modern data science and AI applications with unprecedented scalability.

The evolution of analytic scalability has enabled analysis of increasingly larger data volumes and more complex analytics. Modern big data technologies have provided a major breakthrough in scalability and enabled data-driven transformations in various businesses and applications.

### Analysis vs Reporting

- **Analysis:** The process of examining and interpreting data in order to draw conclusions or make inferences. Analysis involves breaking down data into smaller pieces to uncover patterns and insights. It seeks to answer 'why' and 'how'.
- **Reporting:** The presentation of analysis and findings. A report outlines key takeaways and insights from data analysis but does not include the deep examination and interpretation of the data that occurs during analysis. Reporting aims to inform and tell a story using data.

To summarize:

- Analysis digs deep into data to find insights and answers
- Reporting shares and presents insights and conclusions from analysis
- Analysis asks 'why' and 'how', reporting shares 'what'
- Both are important parts of working with and communicating about data

### Regression modeling

1. Regression is a statistical technique to analyze the relationship between a dependent variable and one or more independent variables.
2. It helps in modeling the relationship between variables and finding out how the dependent variable changes with the change in the independent variable(s).
3. The goal of regression is to minimize the difference between the observed values and the predicted values of the dependent variable.
4. Types of regression:
- Linear regression: Relationship between variables is linear. It estimates a straight-line relationship between dependent and independent variables.
- Multiple regression: Relationship between dependent and independent variables is linear. It includes multiple independent variables to predict the dependent variable.

### Stochastic Search Methods

- Stochastic search methods involve some element of randomness to explore the search space and find the optimal solution.
- These methods are useful when the search space is very large and complex with many local optima. Purely deterministic methods may get stuck in local optima.
- Some of the popular stochastic search methods are:

1. Simulated Annealing: It is inspired by the metallurgical process of annealing where a material is heated and then cooled slowly to reduce defects. In this method, a random perturbation is introduced to the current solution and the new solution is accepted if it is better than the current one. Sometimes, worse solutions are also accepted with a certain probability that decreases over time. This allows the method to escape local optima.

2. Genetic Algorithms: These are inspired by biological evolution and natural selection. A population of candidate solutions is maintained and evolved over multiple generations using operations like selection, crossover, and mutation. Selection chooses the fittest candidates to produce offspring. Crossover combines parts of two candidate solutions to produce children. Mutation introduces random changes to individuals. Over time, the population evolves towards optimal solutions.

3. Particle Swarm Optimization: It is inspired by the social behavior of bird flocking or fish schooling. A population of particles traverse the search space, each particle adjusting its position in the search space based on its own experience as well as the experience of neighboring particles. Particles converge towards the optimal solution over time through this collective information sharing.

The key advantages of stochastic search methods are that they are not easily trapped in local optima and can explore complex search spaces effectively. However, they may be slow to converge and do not guarantee finding the global optimum. The performance depends on tuning various parameters like the cooling schedule in simulated annealing or crossover and mutation rates in genetic algorithms.

### Sampling Data in a Stream

- Stream data arrives continuously and rapidly. It is not feasible to store and process all the data. Sampling is required to analyze stream data.
- Reservoir sampling: Randomly sample k data points from the stream as they arrive. Replace each sampled point with a new incoming point with a decreasing probability as more points are sampled. This produces a random sample of k points from the entire stream.
- Sketching: Construct a compact summary (sketch) of the data using random projections. The sketch can be used to estimate certain properties (e.g. frequent items) of the data. The accuracy of the estimations depends on the size of the sketch.
- Sliding windows: Use a window of recent data points sliding over the stream to analyze local patterns. The window size needs to be carefully chosen based on how fast the stream changes.
- Stratified sampling: Partition the stream into strata (e.g. bursts/non-bursts) and sample each stratum separately to capture the characteristics of different regimes in the stream.

The techniques need to be evaluated based on:

- Bias: How close the estimates are to the actual values.
- Variance: The variability of the estimates. Lower variance leads to more stable results.
- Space and time efficiency: The sample/sketch size and processing time should be small relative to the stream size and speed.

The appropriate technique depends on the analysis task and stream characteristics. Multiple techniques can also be combined to get better results.

### Counting Frequent Itemsets in a Stream

- A stream is an unbounded sequence of data items. Data arrives continuously and needs to be processed on the fly.
- Frequent itemset mining on streams requires algorithms that can process data progressively and provide frequent itemsets using limited memory.
- The Apriori algorithm and its variants are not suitable for streams as they require multiple passes over the data.
- Algorithms for frequent itemset mining on streams include:
- Lossy Counting: Counts of candidate itemsets are approximated using counters with limited precision. When a counter overflows, counts are reset to zero. This may result in losing some infrequent itemsets.
- Sliding Window: Only recent data items in a window of limited size are considered. As new items arrive and old ones expire, the window slides forward and frequent itemsets are computed over the current window. This may miss itemsets that are frequent over a longer span of time.
- Cache-based: Candidate itemsets and their counts are cached in a limited memory. When the cache is full, the least frequent itemsets are removed. This may result in missing some infrequent but non-zero support itemsets.
- Sketch-based: Data streams are compressed into highly condensed sketches that still retain information to approximate support counts of itemsets. This enables scaling to high speed data streams but may result in errors in support count estimates.

 - Find the two closest clusters
 - Merge them into a single cluster
 3. The merges can be represented in a dendrogram, a tree-like diagram showing the merges.
- Pros: Does not require the number of clusters as input, can capture hierarchical relationships.

 - MinPts: The minimum number of points required to form a dense region.
- Pros: Can find arbitrary shaped clusters and handle noise effectively.
- Cons: Sensitive to input parameters (eps, MinPts), and cannot handle varying density clusters well.

### Design

1. Color: Color is one of the most important tools for visualization. Different colors can be used to distinguish different categories or values. However, color should be used judiciously as too many colors can make a visualization confusing and difficult to understand. Some best practices for using color are:
- Use a maximum of 5-6 colors.
- Use colors that have sufficient contrast and are distinguishable even by color blind people.
- Do not use red and green together as around 8% males have red-green color blindness.
- Ensure that the colors have the appropriate semantic mapping (e.g. red for losses or negative values).

2. Size: Varying the size of visual elements is another technique to display information. Our visual system is highly attuned to differences in size, so this technique works well. However, the size should be varied logically (e.g. higher values represented by larger sizes). Using size alone to represent information can be limiting so it is often used in combination with other techniques like color.

3. Position: Arranging visual elements in different positions is a simple yet effective technique. Our visual system readily detects patterns and variations in positioning. This technique works well for depicting categories or ranks (e.g. stacked bar charts, dot plots). The positions should be used consistently and logically for the visualization to be understandable.

4. Shape: Different shapes can be used to represent different types of information. For example, circles can denote one category of data while squares can denote another. Using a variety of shapes makes it possible to display more categories in the same space. However, too many shapes can make a visualization cluttered and confusing. Shape should be used selectively and shapes that have similar silhouettes should be avoided.

5. Text: Labels and annotations are crucial to make a visualization self-contained and truly informative. However, text should be used judiciously. Too much text can clutter the visualization and make it difficult to understand at a glance. The text should be legible, using an appropriate font size and color. The information conveyed via text should not be duplicated in the graphical elements.
