### Classification of Data

- Data can be classified into different types based on various criteria, such as the source, the format, the structure, the scale, the quality, the granularity, the dimensionality, the variability, and the complexity of the data.
- Some of the common types of data are:

  - **Structured data**: Data that has a predefined schema, format, and organization, such as relational databases, spreadsheets, XML files, etc. Structured data is easy to store, query, and analyze using standard tools and techniques.
  - **Unstructured data**: Data that has no fixed schema, format, or organization, such as text, images, audio, video, social media posts, web pages, etc. Unstructured data is difficult to store, query, and analyze using standard tools and techniques, and requires specialized methods and algorithms.
  - **Semi-structured data**: Data that has some elements of structure, such as tags, labels, metadata, etc., but does not conform to a rigid schema or format, such as JSON files, HTML documents, email messages, etc. Semi-structured data is easier to process than unstructured data, but still requires some parsing and extraction techniques.
  - **Quantitative data**: Data that can be measured or counted using numerical values, such as height, weight, temperature, sales, etc. Quantitative data can be further classified into discrete data (data that can only take certain values, such as number of students, gender, etc.) and continuous data (data that can take any value within a range, such as height, weight, etc.).
  - **Qualitative data**: Data that can be described or categorized using non-numerical values, such as color, taste, opinion, sentiment, etc. Qualitative data can be further classified into nominal data (data that can only be named or labeled, such as gender, nationality, etc.) and ordinal data (data that can be ordered or ranked, such as education level, satisfaction level, etc.).
  - **Big data**: Data that is characterized by high volume, high velocity, and high variety, and that exceeds the capacity and capability of traditional data processing systems and methods. Big data can be structured, unstructured, or semi-structured, and can come from various sources, such as sensors, social media, web logs, etc. Big data requires new technologies and techniques, such as distributed computing, cloud computing, parallel processing, machine learning, etc., to store, manage, and analyze the data.
  - **Small data**: Data that is characterized by low volume, low velocity, and low variety, and that can be processed and analyzed using traditional data processing systems and methods. Small data can be structured, unstructured, or semi-structured, and can come from various sources, such as surveys, experiments, reports, etc. Small data can provide insights and patterns that can be generalized and applied to larger data sets or problems.
  - **Metadata**: Data that describes or provides information about other data, such as the name, type, size, format, source, date, etc. of the data. Metadata can help to organize, manage, and understand the data, and can also facilitate data integration, quality, and security.
  - **Multidimensional data**: Data that can be represented or analyzed using more than one dimension or attribute, such as time, location, product, customer, etc. Multidimensional data can be stored and queried using multidimensional databases or data warehouses, and can be visualized and explored using techniques such as OLAP (Online Analytical Processing), data cubes, pivot tables, etc.
  - **Time-series data**: Data that is collected or recorded over time, such as stock prices, weather data, sensor data, etc. Time-series data can be used to analyze trends, patterns, cycles, seasonality, etc. in the data, and can also be used to forecast or predict future values or events using techniques such as regression, smoothing, ARIMA (Auto-Regressive Integrated Moving Average), etc.
  - **Spatial data**: Data that is related to the location or geometry of objects or phenomena, such as maps, coordinates, shapes, distances, etc. Spatial data can be used to analyze the spatial distribution, relationship, or interaction of the data, and can also be used to perform spatial operations, such as overlay, buffer, intersection, etc. using techniques such as GIS (Geographic Information System), spatial databases, spatial analysis, etc.

### Evolution of Analytic Scalability

- Analytic scalability refers to the ability to handle large and complex data sets for analysis purposes.
- In the past, analytic scalability was limited by the following factors:
  - The separation of the analytic and data environments, which required data to be moved and merged from different sources before analysis.
  - The reliance on single-node or symmetric multiprocessing (SMP) architectures, which had limited processing power and memory capacity.
  - The high cost and complexity of setting up and maintaining dedicated analytic servers or clusters.
- In recent years, analytic scalability has evolved with the emergence of new paradigms and technologies, such as   :
  - The convergence of the analytic and data environments, which enables analysis to be performed where the data resides, reducing data movement and latency.
  - The adoption of massively parallel processing (MPP) architectures, which distribute data and computation across multiple nodes, increasing processing power and memory capacity.
  - The utilization of the cloud, which offers on-demand, scalable, and elastic analytic resources, reducing cost and complexity.
  - The application of grid computing, which leverages existing networked computers to share analytic tasks, increasing efficiency and availability.
  - The implementation of MapReduce, which simplifies parallel processing of large and unstructured data sets, increasing flexibility and scalability.
- The evolution of analytic scalability has enabled new levels of analytic capabilities and insights, as well as new challenges and opportunities for data analytics and visualization.

### Analysis vs Reporting

- Reporting is the process of presenting data in a structured and summarized way, such as tables, charts, dashboards, etc. Reporting helps to answer questions like what, when, where, and how much.
- Analysis is the process of exploring, interpreting, and explaining data, such as finding patterns, trends, outliers, correlations, etc. Analysis helps to answer questions like why, how, and what if.
- Reporting and analysis are both important aspects of data analytics, but they have different purposes and audiences.
- Reporting is usually done for a wider and less technical audience, such as managers, stakeholders, customers, etc. Reporting aims to provide information that is clear, concise, and consistent.
- Analysis is usually done for a more specific and technical audience, such as analysts, researchers, data scientists, etc. Analysis aims to provide insights that are relevant, actionable, and novel.
- Reporting and analysis are not mutually exclusive, but rather complementary. Reporting can provide the context and background for analysis, and analysis can provide the depth and meaning for reporting.

## Unit 2 - Data Analytics Lifecycle

The data analytics lifecycle is a framework for planning and executing data analysis projects. It consists of six phases:

1. Discovery: In this phase, the analyst identifies the business problem, the data sources, the stakeholders, and the project objectives. The analyst also performs a preliminary data exploration to understand the data quality, availability, and relevance.
2. Data preparation: In this phase, the analyst cleans, transforms, and integrates the data from various sources. The analyst also performs data profiling, data reduction, and feature engineering to prepare the data for analysis.
3. Model planning: In this phase, the analyst selects the appropriate analytical techniques, such as regression, classification, clustering, or association, to address the business problem. The analyst also defines the evaluation metrics, such as accuracy, precision, recall, or lift, to measure the performance of the models.
4. Model building: In this phase, the analyst applies the selected analytical techniques to the prepared data and builds the models. The analyst also validates and optimizes the models using techniques such as cross-validation, grid search, or hyperparameter tuning.
5. Communicating results: In this phase, the analyst interprets and communicates the results of the analysis to the stakeholders. The analyst also visualizes the results using charts, graphs, dashboards, or reports, and provides actionable insights and recommendations.
6. Operationalize: In this phase, the analyst deploys the models into production and monitors their performance and impact. The analyst also updates and maintains the models as needed, and documents the project outcomes and lessons learned.

# Regression modeling

Regression modeling is a process of estimating the relationships between independent variables and a dependent variable in data. It can be used to understand how different factors are related to one another, and to predict future values for a target variable  .

## Types of regression models

There are different types of regression models depending on the nature of the variables and the shape of the relationship. Some common types are:

- Linear regression: This model assumes a linear relationship between the independent and dependent variables. It can be used to model continuous or categorical outcomes. The equation of a linear regression model is:

`y = b0 + b1x1 + b2x2 + ... + bnxn + e`

where `y` is the dependent variable, `x1, x2, ..., xn` are the independent variables, `b0, b1, b2, ..., bn` are the coefficients, and `e` is the error term.

- Logistic regression: This model is used to model binary outcomes, such as yes/no, success/failure, or 0/1. It assumes a logistic function for the relationship between the independent and dependent variables. The equation of a logistic regression model is:

`p = 1 / (1 + e^-(b0 + b1x1 + b2x2 + ... + bnxn))`

where `p` is the probability of the outcome being 1, `x1, x2, ..., xn` are the independent variables, `b0, b1, b2, ..., bn` are the coefficients, and `e` is the base of the natural logarithm.

- Polynomial regression: This model is used to model nonlinear relationships between the independent and dependent variables. It assumes a polynomial function for the relationship, such as:

`y = b0 + b1x + b2x^2 + b3x^3 + ... + bnx^n + e`

where `y` is the dependent variable, `x` is the independent variable, `b0, b1, b2, ..., bn` are the coefficients, and `e` is the error term.

- Multiple regression: This model is used to model the relationship between one dependent variable and two or more independent variables. It can be linear, logistic, polynomial, or any other type of regression model. The equation of a multiple regression model is similar to the equation of a single regression model, but with more independent variables.

### Multivariate Analysis

Multivariate analysis (MVA) is a method of analyzing data that involves more than two variables. It is used to study the relationships among the variables and their structures. MVA can help to identify patterns, trends, correlations, and causal effects in complex data sets. MVA can also be used to reduce the dimensionality of data by extracting the most important features or factors.

- **Factor analysis (FA)**: This is used to identify the underlying factors or latent variables that explain the common variance among a set of observed variables. ### Inference and Bayesian Networks

### Competitive Learning

- Competitive learning is a form of **unsupervised learning** in artificial neural networks, in which nodes compete for the right to respond to a subset of the input data.
- Competitive learning works by increasing the **specialization** of each node in the network. It is well suited to finding **clusters** within data.
- Competitive learning is usually implemented with neural networks that contain a hidden layer which is commonly known as the **competitive layer**. Every competitive neuron is described by a vector of weights and calculates the **similarity measure** between the input data and the weight vector.
- Competitive learning can be seen as a variant of **Hebbian learning**, which is based on the principle that neurons that fire together wire together. Hebbian learning strengthens the connections between neurons that have correlated activity, while competitive learning weakens the connections between neurons that have uncorrelated activity.
- Competitive learning can be applied to various problems, such as **data clustering**, **dimensionality reduction**, **feature extraction**, **pattern recognition**, and **self-organization**.
- Competitive learning can be classified into different types, such as **winner-take-all**, **softmax**, **learning vector quantization**, **self-organizing maps**, and **adaptive resonance theory**.
- Competitive learning has some advantages, such as **simplicity**, **robustness**, **scalability**, and **adaptability**. It can also discover the inherent structure of the data without prior knowledge or supervision.
- Competitive learning also has some disadvantages, such as **sensitivity** to the initial conditions, **dependency** on the choice of parameters, **lack** of convergence guarantees, and **difficulty** of interpretation.

### Stochastic Search Methods

- **Simulated annealing**: This method mimics the physical process of annealing, where a metal is heated and then slowly cooled to reach a low-energy state. The algorithm terminates when a convergence criterion is met.

### Counting Distinct Elements in a Stream

- A stream is a sequence of data items that arrive in an online fashion, i.e., one by one and not all at once.
- Counting the number of distinct elements in a stream is a fundamental problem in data stream mining, with applications in network monitoring, web analytics, database systems, etc.
- The challenge is to design algorithms that use limited memory and processing time, and can handle streams of arbitrary length and distribution.
- There are two main approaches to solve this problem: exact and approximate.
- Exact algorithms aim to compute the exact number of distinct elements in the stream, but they require memory proportional to the number of distinct elements, which can be impractical for large or unbounded streams.
- Approximate algorithms trade off accuracy for efficiency, and provide probabilistic guarantees on the error of the estimation. They use memory sublinear in the number of distinct elements, and can handle streams of any size and nature.
- Some examples of approximate algorithms are:

  - Flajolet-Martin algorithm : uses a hash function to map each element to a binary string, and counts the number of leading zeros in the hashed values. The maximum number of leading zeros observed is used to estimate the number of distinct elements.
  - HyperLogLog algorithm: improves on the Flajolet-Martin algorithm by using multiple hash functions and averaging the estimates from each hash function. It reduces the memory and variance of the estimation.
  - KMV algorithm: maintains a sorted list of the k smallest hashed values seen so far, where k is a parameter. The number of distinct elements is estimated by the inverse of the average of the k smallest hashed values.
  - Count-Min sketch: uses a two-dimensional array of counters and multiple hash functions to store the frequencies of the elements. The number of distinct elements is estimated by the minimum of the counters for each element.

- These algorithms have different trade-offs in terms of memory, accuracy, update time, and query time. They can also be extended to handle streams with expiration, i.e., where elements can be removed from the stream after a certain time.

### Counting oneness in a window

- Counting oneness in a window is a problem of estimating the number of 1's in the last k bits of a data stream, where k is a large number that cannot be stored in memory.
- One possible solution is to use the DGIM algorithm, which uses O(log2 N) bits to represent a window of N bits, and allows us to estimate the number of 1's in the window with an error of no more than 50% .
- The DGIM algorithm works as follows:
  - Each bit of the stream has a timestamp, the position in which it arrives. The first bit has timestamp 1, the second has timestamp 2, and so on.
  - The algorithm divides the window into buckets, each consisting of:
    - The timestamp of its right (most recent) end.
    - The number of 1's in the bucket.
  - The algorithm maintains the following invariants for the buckets:
    - There are at most two buckets with the same number of 1's.
    - The buckets are ordered by their timestamps, from left (oldest) to right (most recent).
    - The number of 1's in a bucket is a power of 2.
  - When a new bit arrives, the algorithm updates the buckets as follows:
    - If the bit is 0, nothing changes.
    - If the bit is 1, a new bucket with timestamp equal to the current position and number of 1's equal to 1 is created at the right end of the window.
    - If there are now three buckets with the same number of 1's, the two oldest buckets are merged into one bucket with timestamp equal to the newer of the two and number of 1's equal to the sum of the two.
    - If the oldest bucket falls outside the window, it is discarded.
  - To estimate the number of 1's in the last k bits, the algorithm does the following:
    - Find the rightmost bucket that is completely within the last k bits. Let its timestamp be t and its number of 1's be r.
    - Add r/2 to the estimate, since the bucket may be only partially within the last k bits.
    - For each bucket to the left of t, add its number of 1's to the estimate.
    - Return the estimate as the answer.

### Frequent Itemsets

- Frequent itemsets are useful for discovering association rules, which are implications of the form X -> Y, where X and Y are itemsets and X is a subset of Y. Association rules capture the co-occurrence patterns of items in the data.
- The problem of finding all frequent itemsets in a dataset is challenging because the number of possible itemsets is exponential in the number of items. A naive approach that tests all itemsets for their support is impractical.
- There are several efficient algorithms for finding frequent itemsets, such as Apriori, Eclat, and FP-Growth. These algorithms exploit the downward closure property of frequent itemsets, which states that any subset of a frequent itemset is also frequent. This property allows pruning the search space of itemsets by eliminating candidates that have infrequent subsets.
- The output of frequent itemset mining can be very large, especially for low support thresholds. To reduce the output size, one can use techniques such as closed itemsets, maximal itemsets, or high-confidence rules.

### Mining frequent itemsets

- Frequent itemset mining (pattern mining) is a technique used to derive relationships such as regularities in customers’ shopping behavior in physical and online stores to discover association rules out of the relationships.

For example, {bread, butter} -> {jam} is an association rule that means that customers who buy bread and butter are likely to buy jam as well.
- Frequent itemsets are sets of items that appear together in a dataset with a frequency above a given threshold (called minimum support). For example, {bread, butter, jam} is a frequent itemset if it occurs in more than 10% of the transactions in a dataset.
- Mining frequent itemsets is the process of finding all the frequent itemsets in a dataset. This is usually the first step to generate association rules, which can then be evaluated by measures such as confidence, lift, or conviction.
- There are several algorithms for mining frequent itemsets, such as Apriori, Eclat, and FP-growth. These algorithms differ in how they search the space of possible itemsets and how they prune the candidates that are unlikely to be frequent.
- Apriori is the most commonly used algorithm for mining frequent itemsets. It works by generating candidate itemsets of increasing size (from 1 to n, where n is the number of items in the dataset) and scanning the dataset to count their frequencies. It uses the property that any subset of a frequent itemset must be frequent as well (called the Apriori property) to prune the candidates that have infrequent subsets.
- Eclat is a variant of Apriori that uses a depth-first search strategy and a vertical representation of the dataset (where each item is associated with a set of transaction identifiers that contain it) to avoid repeated scans of the dataset and generate fewer candidates.
- FP-growth is another algorithm for mining frequent itemsets that uses a compressed representation of the dataset called an FP-tree (frequent pattern tree) to avoid generating candidates and scanning the dataset. It works by dividing the dataset into smaller projected datasets based on the frequent items and recursively mining each projected dataset.

### Limited Pass Algorithm for Frequent Itemsets

- The limited pass algorithm is an approximate algorithm that aims to find most of the frequent itemsets in a data set, using fewer passes than the exact algorithms like A-Priori or PCY .
- The basic idea of the limited pass algorithm is to use a random sample of the data set and apply an exact algorithm on the sample with a lower support threshold.
- The sample size and the lower threshold are chosen such that the probability of missing a frequent itemset in the original data set is low.
- The algorithm works as follows:
  - Choose a sample size n and a lower support threshold t, where t < s, the desired support threshold for the original data set.
  - Take a random sample of n baskets from the data set and apply an exact algorithm (such as A-Priori or PCY) on the sample with the threshold t. This will produce a set of candidate frequent itemsets from the sample.
  - Make a second pass over the original data set and count the occurrences of the candidate itemsets. Output those itemsets that have at least s occurrences in the original data set as frequent itemsets.
- The advantage of the limited pass algorithm is that it reduces the number of passes and the memory requirement for finding frequent itemsets, especially when the itemsets are large.
- The disadvantage of the limited pass algorithm is that it may miss some frequent itemsets in the original data set, or include some infrequent itemsets in the output, depending on the quality of the sample and the choice of the lower threshold.
- The limited pass algorithm can be used for big data analytics, where the data set is too large to fit in the main memory and the exact algorithms are too slow or impractical.

## CLIQUE Algorithm

- CLIQUE is a **subspace clustering** algorithm that finds clusters in high-dimensional data by dividing each dimension into equal-width intervals and saving those intervals where the density is greater than a threshold as clusters .
- CLIQUE uses a **density-based** and **grid-based** technique, which means it does not require a predefined number of clusters or a distance function, and it can find clusters of any shape.
- CLIQUE has four main steps :
  - **Partitioning**: The data space is partitioned into a grid of cells, and the cells with density above the threshold are marked as dense cells.
  - **Identifying**: The dense cells are grouped into connected components, which form the clusters in one-dimensional subspaces.
  - **Merging**: The clusters in lower-dimensional subspaces are merged to form clusters in higher-dimensional subspaces, if they share common dense cells.
  - **Pruning**: The clusters that are contained in other clusters are pruned, and the remaining clusters are the final output.
- CLIQUE has some advantages and disadvantages :
  - Advantages:
    - It can handle high-dimensional data and find clusters of any shape.
    - It is scalable and efficient, as it only scans the data once and uses a grid structure to store the density information.
    - It does not require a distance function or a number of clusters as input parameters, only the density threshold and the number of intervals.
  - Disadvantages:
    - It is sensitive to the input parameters, which can affect the quality and quantity of the clusters.
    - It can only find clusters that are aligned with the grid axes, and it may miss clusters that are skewed or curved.
    - It may produce overlapping clusters, which can be confusing or redundant.

## ProCLUS Algorithm

- ProCLUS is a **projected clustering** algorithm that finds clusters in high-dimensional data by selecting a subset of dimensions (called a projection) for each cluster, and assigning objects to the cluster with the closest projection.
- ProCLUS uses a **k-medoids** approach, which means it chooses representative objects (called medoids) for each cluster, and minimizes the distance between the objects and their medoids.
- ProCLUS has five main steps :
  - **Initialization**: The algorithm randomly selects k potential medoids from the data, and assigns each object to the closest medoid.
  - **Iterative refinement**: The algorithm iteratively updates the medoids and the assignments until convergence or a maximum number of iterations is reached.
  - **Dimension selection**: The algorithm selects a subset of dimensions for each cluster, based on the variance and correlation of the objects in the cluster.
  - **Final refinement**: The algorithm refines the medoids and the assignments using only the selected dimensions for each cluster, and removes outliers and empty clusters.
  - **Output**: The algorithm outputs the final clusters, their medoids, and their projections.
- ProCLUS has some advantages and disadvantages :
  - Advantages:
    - It can handle high-dimensional data and find clusters with different projections.
    - It is robust to noise and outliers, as it uses a k-medoids approach and removes them in the final refinement step.
    - It does not require a distance function, only a number of clusters and a maximum number of dimensions as input parameters.
  - Disadvantages:
    - It is sensitive to the input parameters, which can affect the quality and quantity of the clusters.
    - It can only find clusters that are convex and well-separated, and it may miss clusters that are overlapping or non-convex.
    - It may produce clusters with too many or too few dimensions, which can be misleading or incomplete.

### Issues in Data Visualization

Data visualization is the process of transforming data into graphical or visual representations that can communicate insights, patterns, trends, and relationships. Data visualization can help users to understand complex data, make informed decisions, and tell compelling stories. However, data visualization also faces some challenges and issues that can affect its quality, effectiveness, and credibility. Some of the common issues in data visualization are:

- **Bad data**: The quality of the data is the foundation of any data visualization. If the data is inaccurate, incomplete, inconsistent, or outdated, it will lead to misleading or erroneous visualizations. Therefore, data should be carefully collected, sourced, cleaned, and validated before it is visualized. Common errors include data duplication, missing values, incorrect formats, and outliers.
- **Wrong choice of data visualization**: The type of data visualization should match the purpose, audience, and nature of the data. Different types of data visualization have different strengths and limitations, and choosing the wrong one can confuse or misinform the users. For example, pie charts are suitable for showing proportions of a whole, but not for comparing multiple categories or values. Similarly, line charts are good for showing trends over time, but not for showing discrete or categorical data.
- **Too much color or information**: Data visualization should be simple, clear, and focused. Using too many colors, shapes, symbols, or labels can make the visualization cluttered, noisy, or distracting. Moreover, adding too much information or detail can overwhelm or bore the users, or obscure the main message or insight. Therefore, data visualization should follow the principle of less is more, and use color and information sparingly and strategically.
- **Misrepresentation of data**: Data visualization should be honest, accurate, and ethical. It should not manipulate, distort, or exaggerate the data to create false impressions or support biased agendas. Some examples of misrepresentation of data include using misleading scales, axes, or baselines, omitting or hiding data, cherry-picking data, or using inappropriate comparisons or correlations.
- **Inconsistent scales**: Data visualization should use consistent and appropriate scales to represent the data. Scales can be linear, logarithmic, or ordinal, depending on the data and the message. Using inconsistent scales can make the visualization confusing, incomparable, or misleading. For example, using a linear scale for data that has exponential growth or decay can understate or overstate the changes, while using a logarithmic scale for data that has linear changes can flatten or exaggerate the trends.

## Unit 7 - Human Vision

Human vision is the ability to perceive and interpret visual information from the environment. It involves the interaction of the eyes, the brain, and the nervous system. Human vision has the following features and limits:

- **Binocular vision**: Humans have two eyes that are located on the left and right sides of the face. Each eye forms a different image on its retina, which is the light-sensitive layer at the back of the eye. The brain combines these two images to create a single perception of vision that allows humans to see objects in three dimensions and estimate their distance and depth.
- **Eye structure**: The human eye is a complex organ that consists of several parts, such as the cornea, the pupil, the iris, the lens, the vitreous, the retina, the optic nerve, and the extraocular muscles. Each part has a specific function in the process of vision. For example, the cornea is the clear front layer of the eye that bends light to help the eye focus. The pupil is the opening in the center of the iris that controls the amount of light that enters the eye. The lens is the transparent structure behind the pupil that changes shape to focus light onto the retina. The retina is the layer of nerve cells that converts light into electrical signals that are sent to the brain via the optic nerve. The extraocular muscles are the six muscles that control the movements of the eye.
- **Color perception**: Humans can perceive a range of colors that are derived from the combination of three primary colors: red, green, and blue. The retina contains two types of photoreceptors: rods and cones. Rods are more sensitive to light and are responsible for night vision and peripheral vision. Cones are less sensitive to light but can detect different wavelengths of light and are responsible for color vision and central vision. There are three types of cones: L-cones, M-cones, and S-cones, which respond to long, medium, and short wavelengths of light, respectively. The brain interprets the signals from the cones to create the sensation of color.
- **Visual acuity**: Visual acuity is the measure of the sharpness and clarity of vision. It depends on several factors, such as the size and contrast of the object, the distance from the object, the lighting conditions, and the health of the eye. Visual acuity is usually measured by using a Snellen chart, which consists of rows of letters of different sizes. The smallest row of letters that a person can read at a certain distance is used to determine their visual acuity. Normal visual acuity is 20/20, which means that a person can read the 20th row of letters at a distance of 20 feet. A person with 20/40 vision can only read the 20th row of letters at a distance of 40 feet, which means that their vision is less sharp than normal.
- **Visual field**: Visual field is the area of the environment that a person can see at any given moment. It includes the central and peripheral vision. The central vision is the area that a person can see when they focus on a specific point. The peripheral vision is the area that a person can see around the central vision. The normal visual field for each eye is about 170 degrees horizontally and 100 degrees vertically. The visual field of both eyes overlaps by about 120 degrees, which creates the binocular vision. The visual field can be affected by various factors, such as eye diseases, brain injuries, or medications.

### Time Limitations

- Human vision is not only limited by the spatial resolution and color perception, but also by the temporal resolution and motion perception.
- Temporal resolution refers to the ability to distinguish between two events that occur in a short time interval. Motion perception refers to the ability to detect and track the movement of objects in the visual field.

- Some factors that affect the temporal resolution and motion perception are:

  - Flicker fusion: The minimum frequency at which a flickering light appears as a steady light. It varies depending on the brightness, color, and size of the light source, as well as the location on the retina. The average flicker fusion threshold for humans is about 60 Hz, but it can be higher or lower depending on the conditions.
  - Critical flicker frequency: The frequency at which the flicker fusion threshold is reached. It is inversely proportional to the stimulus intensity. The higher the intensity, the lower the critical flicker frequency.
  - Persistence of vision: The phenomenon that a visual stimulus remains in the retina for a brief period after it is removed. It is caused by the slow decay of the photoreceptor response and the neural processing in the visual system. The duration of persistence of vision varies depending on the stimulus characteristics, but it is usually between 50 and 200 ms.
  - Phi phenomenon: The illusion of apparent motion that occurs when two or more stationary stimuli are presented in rapid succession at different locations. It is caused by the temporal integration of the visual system, which fills in the gaps between the stimuli. The phi phenomenon can be used to create animations and movies from still images.
  - Beta movement: A type of apparent motion that occurs when two or more stimuli are presented in rapid succession at the same location, but with different shapes or orientations. It is caused by the temporal integration and the shape constancy of the visual system, which interprets the stimuli as a single object that changes its form. The beta movement can be used to create morphing and transformation effects.
  - Stroboscopic effect: The illusion of apparent motion that occurs when a series of still images are presented in rapid succession, each showing a slightly different phase of a moving object. It is caused by the temporal integration and the motion constancy of the visual system, which interprets the images as a continuous motion.   - Motion aftereffect: The phenomenon that a stationary stimulus appears to move in the opposite direction after viewing a moving stimulus for a prolonged period. It is caused by the adaptation and the contrast of the motion-sensitive neurons in the visual cortex, which become less responsive to the original motion and more responsive to the opposite motion. The motion aftereffect can be used to create motion illusions and art.
