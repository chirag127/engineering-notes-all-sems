## Unit 1 - INTRODUCTION

1. Introduction to Programming
- Programming is the process of creating a set of instructions called code to instruct a computer to perform a task.
- Programming languages are used to communicate instructions to a computer. They enable us to control the behavior of a machine and create various applications.
- The two main types of programming languages are low-level languages and high-level languages. Low-level languages directly control a computer's CPU, while high-level languages use a simpler syntax to accomplish more complex tasks.

2. Software and Applications
- Software refers to the programs that run on a computer and perform tasks. There are two main types of software: system software and application software.
- System software controls the computer's hardware and allows other programs to run, such as the operating system. Application software lets users perform tasks and includes programs like word processors, web browsers, and mobile apps.
- Software can be proprietary, open-source, or free and open-source. Proprietary software is developed by a company and sold to users, while open-source software makes its source code freely available for use and modification.

3. Algorithms and Programming
- Algorithms are sets of steps that programs follow to perform a task or solve a problem. They are essential to programming and tell the computer exactly what steps to execute and what order to follow.
- Programming involves implementing algorithms using a programming language. Programmers translate algorithms into code by defining inputs, outputs, variables, control flows, functions, and logic. They then test and debug the code to ensure the program runs correctly.
- Programming languages provide various levels of abstraction, allowing programmers to implement algorithms at a level they are comfortable with. Lower-level languages offer less abstraction and more direct control, while higher-level languages provide more abstraction and simpler syntax.

### Open Source Platforms

- Arduino: Open-source electronic prototyping platform allowing to create interactive electronic objects. It consists of hardware (board) and software (IDE) and a programming language based on Wiring. It allows to connect various sensors and actuators and to create interactive objects and environments.
- Raspberry Pi: Credit-card sized computer created to promote teaching of basic computer science in schools and developing countries. It allows to create many connected objects and solutions thanks to its GPIO connectors. It runs on Linux and can be programmed in many languages (Python, C/C++, Java, Scratch...).
- BeagleBone: Open source hardware single board computer, capable of running Linux and Android, providing access to its PRUs microcontrollers as well as to various communication interfaces (GPIO, I2C, SPI...). It allows rapid prototyping and creation of connected objects and appliances.
- micro:bit: Small programmable microcontroller board designed for education. It integrates many sensors (accelerometer, compass...) and has LEDs and buttons that can be programmed in various languages (Block editor, JavaScript, Python...). It allows to create simple interactive objects and robots.

### Raspberry Pi for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. Raspberry Pi is a credit card-sized single-board computer developed in the UK by the Raspberry Pi Foundation to promote teaching of basic computer science in schools and developing countries.
2. It provides an affordable and easy-to-use technology that anyone can use to learn to code and create digital devices.
3. Raspberry Pi is capable of doing everything a desktop computer can do like browsing the internet, playing games, etc. But it is a very small computer that runs on very little power.
4. Raspberry Pi has a Broadcom BCM2835 system on a chip, which includes an ARM1176JZF-S 700 MHz processor, VideoCore IV GPU, and was initially shipped with 256 megabytes of RAM, later models have 512 MB or 1 GB RAM.
5. The Raspberry Pi is tailored for interfacing with the real world, so it includes features like a GPIO (general purpose input/output) connector that allows you to control external electronic devices.
6. The affordable price, small size, low power consumption and the ability to interface with the real world components make Raspberry Pi a popular choice for creating DIY smart devices and wearable computing projects.
