## Unit 1 - INTRODUCTION

1. Introduction to Programming
- Programming is the process of creating a set of instructions called code to instruct a computer to perform a task.
- Programming languages are used to communicate instructions to a computer. They enable us to control the behavior of a machine and create various applications.
- The two main types of programming languages are low-level languages and high-level languages. Low-level languages directly control a computer's CPU, while high-level languages use a simpler syntax to accomplish more complex tasks.

2. Software and Applications
- Software refers to the programs that run on a computer and perform tasks. There are two main types of software: system software and application software.
- System software controls the computer's hardware and allows other programs to run, such as the operating system. Application software lets users perform tasks and includes programs like word processors, web browsers, and mobile apps.
- Software can be proprietary, open-source, or free and open-source. Proprietary software is developed by a company and sold to users, while open-source software makes its source code freely available for use and modification.

3. Algorithms and Programming
- Algorithms are sets of steps that programs follow to perform a task or solve a problem. They are essential to programming and tell the computer exactly what steps to execute and what order to follow.
- Programming involves implementing algorithms using a programming language. Programmers translate algorithms into code by defining inputs, outputs, variables, control flows, functions, and logic. They then test and debug the code to ensure the program runs correctly.
- Programming languages provide various levels of abstraction, allowing programmers to implement algorithms at a level they are comfortable with. Lower-level languages offer less abstraction and more direct control, while higher-level languages provide more abstraction and simpler syntax.

4. Resistance: The extent to which a material opposes the flow of current is called resistance. It is measured in ohms (?). Materials with high resistance have few charge carriers available to conduct current, while low resistance means current can flow more freely. Resistance causes the electrical energy to dissipate as heat.

5. Circuit: A complete path that allows current to flow is called an electric circuit. If the circuit is complete, it is called a closed circuit, while an incomplete path is an open circuit. Electric devices use circuits to control the flow of current and perform various functions.

### Circuit Theory

- A circuit is a path that allows electric current to flow.
- Circuits consist of a voltage source, wires that act as pathways, and electronic components that control the flow of electricity.
- The three main components of a circuit are:
    - Voltage source: Provides electrical pressure to drive current through the circuit
    - Load: Electronic components that use electrical energy to perform a task
    - Wires: Conductors that provide a path for current to flow
- There are two types of circuits: open circuits and closed circuits.
    - Open circuits: Broken path, current cannot flow. Voltage source is disconnected from the load.
    - Closed circuits: Complete path, current can flow. Voltage source is connected to the load.
- Ohm's law describes the relationship between voltage, current, and resistance in a circuit. It states that current is directly proportional to voltage and inversely proportional to resistance.
- Resistors reduce the flow of current in a circuit and convert electrical energy into heat. Resistors can be used to control current levels and divide voltages.

## Unit 2 - SOFTWARE HARDWARE FRAMEWORKS

1. Software Frameworks
- A software framework is a reusable design for a software system (or subsystem). It provides a generic structure for solutions of a particular problem. A framework embodies key abstractions and priorities of a software paradigm.
- It is a skeleton or an architectural blueprint of an application which provides basic functionalities and structures to develop software applications.
- Frameworks incorporate key programming patterns and architectures into its structure. It enables modular programming and reduces complexity as the framework handles common tasks.
- Ex: Spring Framework, Struts, Ruby on Rails, etc.

2. Hardware Frameworks
- A hardware framework is the underlying hardware infrastructure or system that supports software frameworks and applications.

- Examples of digital circuits include processors, memory, and logic gates. Examples of analog circuits include amplifiers, oscillators, and filters.
- The choice between digital vs. analog circuits depends on the requirements and goals of the specific system or application. Analog may be better for capturing detailed continuous data while digital may be better for robust processing and storage.

### I2C/IIC

- I2C stands for Inter-Integrated Circuit.
- It is a serial communication protocol for connecting low-speed peripherals to a microcontroller.
- It uses only 2 wires: SDA (Serial Data Line) and SCL (Serial Clock Line).
- I2C devices have addresses that are used to identify them on the bus. A master device (usually a microcontroller) communicates with slave devices (sensors, memory chips, etc.) by sending out the slave address and reading/writing data.
- I2C is a multi-master bus, so more than one master device can be connected to the same bus. However, bus arbitration is required to prevent data corruption if two masters initiate a data transfer at the same time.
- I2C is a low-speed protocol with standard modes of 100 kbit/s (fast mode) and 10 kbit/s (standard mode). Some devices support high-speed mode of up to 3.4 Mbit/s.
- The advantages of I2C are:
  - Few wires (only 2)
  - Can have multiple slaves
  - Standardized protocol
  - Low cost
- The disadvantages are:
  - Limited speed compared to SPI
  - There is a limited number of unique addresses, so the number of connectable devices is limited

### Inter-Integrated Circuit

- I2C (Inter-Integrated Circuit) is a serial bus interface standard that allows low-speed peripherals to communicate with a microprocessor.
- It uses only two bidirectional open-drain lines, Serial Data Line (SDA) and Serial Clock Line (SCL), pulled up with resistors.
- I2C supports multiple masters and slaves with each slave having a unique address.
- Data is transmitted in messages. A message is initiated by the master, which sends the address of the slave it wants to communicate with.
- This is followed by transmission of one or more bytes to the addressed slave. The slave may send zero or more bytes in reply. A message is ended by a STOP condition initiated by the master.
- I2C is useful for connecting slow peripheral devices that are physically close, such as sensors, real-time clocks, memory, and DACs.
- Advantages: Only two wires (clock and data lines), low speeds (up to 400kHz standard, up to 1MHz in some implementations), multiple slave support (up to 112 devices), has been widely adopted so lots of peripherals support I2C interface.
- Disadvantages: Limited maximum speed and distance (meter-scale on a PCB).

### Serial Peripheral Interface

- SPI is a synchronous serial data link standard that allows communication between microcontrollers and peripheral devices or between two microcontrollers.
- It uses a master-slave architecture with one master device and one or more slave devices. The master device initiates and controls all communication.
- SPI uses a clock signal to synchronize data transmission between the devices. The clock signal is always provided by the master.
- SPI uses 4 wires - SCLK (Clock), SDIO (Master Out/Slave In), SDO (Slave Out/Master In), and CS (Chip Select). CS is used to select the device we want to communicate with.
- Data is transmitted in full duplex mode. The master and slave can transmit and receive data at the same time.
- Data is shifted out of the master's MOSI pin and into the slave's MISO pin on each rising or falling edge of the clock signal.
- The maximum data rate depends on the frequency of the clock signal and can reach up to several megabits per second.
- SPI is a simple and efficient interface and is widely used for communication between microcontrollers and sensors or other peripheral ICs.

### Serial UART Communication

- UART stands for Universal Asynchronous Receiver/Transmitter. It is a microchip that converts data between serial and parallel forms.
- In UART communication, data is transmitted in a bit-by-bit fashion, sequentially over a single wire. This is known as serial communication.
- UART converts parallel data from the system bus into a serial bit stream to be transmitted. At the receiving end, it converts the serial bit stream back into parallel data for the system bus.
- UART communication is done using two wires - Transmit (TX) and Receive (RX). The TX line sends data away from the UART, and the RX line receives data towards the UART.
- For UART communication, the following parameters need to be same at both the transmitter and receiver:
-- Baud rate: The rate at which bits are transmitted and received, measured in bits per second (bps). Common baud rates are 9600, 38400, 57600, etc.
-- Data bits: The number of data bits in each character, usually 7 or 8.
-- Parity: Whether to use parity bit for error checking and if so, odd, even or mark/space parity.
-- Stop bits: The number of stop bits added at the end of each character, either 1 or 2.
- UART communication is commonly used to connect peripheral devices such as Bluetooth modules, fingerprint sensors, RFID readers, etc. to microcontrollers or single-board computers. It is a simple and low-cost interface for short-range communication.

### Push and Pull

- Push refers to sending information to users without the user initiating the request. For example, notifications, alerts, updates, etc. sent to users.
- Pull refers to users requesting information when needed. For example, searching for information, loading a web page, etc. The user initiates the request for information.
- In wearable devices and IoT, a balance of push and pull is required:
    - Push is needed to send important notifications or alerts to users. But excessive push can lead to alert fatigue.
    - Pull is needed to retrieve information on-demand. But if all information is pull-based, users may miss out on important updates or notifications.
- An optimal strategy is to use push for high-priority information and alerts but allow users to adjust the push frequency. Also, provide pull mechanisms to retrieve further details or related information.
- For mixed reality, push can be used to send notifications about events or activities nearby. But prolonged AR overlays on the user's view can be distracting. So, pull mechanisms can be provided to bring up AR displays on-demand when needed.
- In general, push should be used judiciously and pull should be the primary mechanism wherever possible. The specific balance of push vs pull depends on the use case and application. User preferences and controls should also be provided to customize the push-pull balance.
