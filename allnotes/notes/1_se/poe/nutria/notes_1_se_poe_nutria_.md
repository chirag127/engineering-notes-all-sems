Software engineering also includes the management of the software development process, including project planning and management, software architecture and design, quality assurance, and software testing.

### Software Components
- **Application Software**: Application software is a type of computer software designed to help the user to perform specific tasks. Examples include web browsers, word processors, media players and games.
- **System Software**: System software is a type of computer program that is designed to run a computer's hardware and application programs. Examples include operating systems, device drivers, diagnostic tools, servers and utilities.
- **Programming Languages**: Programming languages are used to create computer programs. Examples include C, C++, Java, Python and Ruby.
- **Middleware**: Middleware is software that is used to connect different components of a system. Examples include message-oriented middleware, database middleware and application server middleware.
- **Database Management Systems**: Database management systems are used to store and manage data. Examples include Oracle, MySQL and Microsoft SQL Server.
- **Networking Software**: Networking software is used to connect computers and other devices on a network. Examples include protocols such as TCP/IP, and network management software such as Cisco IOS.
