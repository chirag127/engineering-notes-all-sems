## Unit 1 - Develop static web pages using HTML.

1. HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages.
2. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page semantically.
3. The <html> tag defines the root of an HTML document. It contains two sub-sections - the <head> and the <body>.
4. The <head> section contains metadata about the HTML document including the title of the page inside <title> tags.
5. The <body> section contains the visible page content including text, images, links, etc. wrapped between opening and closing <body> tags.
6. Heading tags like <h1> to <h6> are used to denote section headings. <h1> denotes the highest level heading and <h6> the lowest level.
7. The <p> tag is used to denote paragraphs. Paragraphs are blocks of text separated by whitespace.
8. The <a> or anchor tag is used to create links to other pages or sections within the same page.
9. HTML supports adding images using the <img> tag and specifying the image source using the "src" attribute.
10. HTML allows specifying list items using <ul> (unordered list), <ol> (ordered list) and <li> (list item) tags.
