## Data Definition Language (DDL) Statements

Data Definition Language (DDL) is a subset of SQL (Structured Query Language) used to define and manage the structure of a database. DDL statements are used to create, alter, and drop database objects such as tables, views, indexes, and procedures.

Here are some common DDL statements used in Database Management Systems:

1. **CREATE**: This statement is used to create a new database object, such as a table, view, index, or procedure. For example, the `CREATE TABLE` statement is used to create a new table in the database.

2. **ALTER**: This statement is used to modify the structure of an existing database object. For example, the `ALTER TABLE` statement can be used to add, modify, or drop columns in a table.

3. **DROP**: This statement is used to delete a database object. For example, the `DROP TABLE` statement is used to delete a table from the database.

4. **TRUNCATE**: This statement is used to delete all data from a table, but it does not delete the table itself.

5. **RENAME**: This statement is used to rename a database object.

These DDL statements are essential for managing the structure of a database and are commonly used in Database Management Systems Mapping with Virtual Lab Lab. It is important to have a good understanding of these statements when working with databases.



## Data Manipulation Language (DML) Statements

Data Manipulation Language (DML) is a subset of SQL used to manipulate data in a database. It includes statements such as `SELECT`, `INSERT`, `UPDATE`, and `DELETE`. These statements are used to retrieve, add, modify, and delete data in a database.

1. `SELECT` statement: The `SELECT` statement is used to retrieve data from one or more tables in a database. It can be used to retrieve specific columns or rows of data, or to retrieve data that meets certain criteria.

2. `INSERT` statement: The `INSERT` statement is used to add new rows of data to a table in a database. It can be used to insert a single row of data or multiple rows of data at once.

3. `UPDATE` statement: The `UPDATE` statement is used to modify existing data in a table in a database. It can be used to update one or more columns of data in one or more rows of a table.

4. `DELETE` statement: The `DELETE` statement is used to delete existing data from a table in a database. It can be used to delete one or more rows of data from a table.

These DML statements are essential for manipulating data in a database and are commonly used in Database Management Systems Mapping with Virtual Lab Lab. It is important to understand and be able to use these statements when working with databases.



## Data Query Language (DQL) Statements

Data Query Language (DQL) is a subset of the Structured Query Language (SQL) used to retrieve data from a database. DQL statements are used to perform queries on the data stored in the database and retrieve the desired information.

Here are some key points to remember about DQL statements:

1. The primary DQL statement is the `SELECT` statement, which is used to retrieve data from one or more tables in the database.
2. The `SELECT` statement can be used with various clauses such as `WHERE`, `GROUP BY`, `HAVING`, and `ORDER BY` to filter, group, and sort the retrieved data.
3. DQL statements can also include functions and expressions to perform calculations and manipulate the retrieved data.
4. DQL statements can be used in conjunction with Data Manipulation Language (DML) statements such as `INSERT`, `UPDATE`, and `DELETE` to retrieve data for use in data manipulation operations.
5. DQL statements can be used in stored procedures, functions, and triggers to retrieve data for use in database programming.

In the context of the Database Management Systems Mapping with Virtual Lab Lab, DQL statements can be used to retrieve data from the virtual database for use in lab exercises and experiments. Students can practice writing and executing DQL statements to retrieve and manipulate data in the virtual lab environment. 




## Transaction Control Language (TCL) Statements

Transaction Control Language (TCL) statements are used to manage transactions in a database. A transaction is a logical unit of work that contains one or more SQL statements. TCL statements are used to control and manage transactions to ensure the consistency and integrity of data in a database.

Here are some key points to remember about TCL statements:

1. **COMMIT**: The `COMMIT` statement is used to permanently save any changes made by a transaction to the database. Once a transaction is committed, the changes are permanent and cannot be undone.

2. **ROLLBACK**: The `ROLLBACK` statement is used to undo any changes made by a transaction. If a transaction is rolled back, all changes made by the transaction are undone and the database is restored to its previous state.

3. **SAVEPOINT**: The `SAVEPOINT` statement is used to create a savepoint within a transaction. A savepoint is a point within a transaction to which you can roll back. This allows you to undo part of a transaction, rather than the entire transaction.

4. **SET TRANSACTION**: The `SET TRANSACTION` statement is used to specify the characteristics of a transaction. For example, you can use the `SET TRANSACTION` statement to specify that a transaction is read-only or read-write.

TCL statements are an important part of managing transactions in a database and ensuring the consistency and integrity of data. By using TCL statements, you can control and manage transactions to ensure that data is always accurate and up-to-date.
