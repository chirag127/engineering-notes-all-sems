## Data Definition Language (DDL) Statements

Data Definition Language (DDL) is a subset of SQL (Structured Query Language) used to define and manage the structure of a database. DDL statements are used to create, alter, and drop database objects such as tables, views, indexes, and procedures.

Here are some common DDL statements used in Database Management Systems:

1. **CREATE**: This statement is used to create a new database object, such as a table, view, index, or procedure. For example, the `CREATE TABLE` statement is used to create a new table in the database.

2. **ALTER**: This statement is used to modify the structure of an existing database object. For example, the `ALTER TABLE` statement can be used to add, modify, or drop columns in a table.

3. **DROP**: This statement is used to delete a database object. For example, the `DROP TABLE` statement is used to delete a table from the database.

4. **TRUNCATE**: This statement is used to delete all data from a table, but the table structure remains intact. This is useful when you want to quickly delete all data from a table without deleting the table itself.

5. **RENAME**: This statement is used to rename a database object. For example, the `RENAME TABLE` statement can be used to change the name of a table.

These are some of the basic DDL statements used in Database Management Systems. They are essential for creating and managing the structure of a database. In a virtual lab setting, these statements can be used to create and manipulate database objects for practice and experimentation.



## Data Manipulation Language (DML) Statements

Data Manipulation Language (DML) is a subset of SQL (Structured Query Language) used to manipulate data in a database. DML statements are used to insert, update, and delete data in a database. The following are the most commonly used DML statements:

1. **INSERT**: The INSERT statement is used to add new rows of data to a table. The syntax for the INSERT statement is as follows:

```
INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);
```

2. **UPDATE**: The UPDATE statement is used to modify existing data in a table. The syntax for the UPDATE statement is as follows:

```
UPDATE table_name
SET column1 = value1, column2 = value2, ...
WHERE condition;
```

3. **DELETE**: The DELETE statement is used to delete existing data from a table. The syntax for the DELETE statement is as follows:

```
DELETE FROM table_name WHERE condition;
```

4. **SELECT**: The SELECT statement is used to retrieve data from a database. The syntax for the SELECT statement is as follows:

```
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

These DML statements are essential for manipulating data in a database and are commonly used in Database Management Systems Mapping with Virtual Lab Lab. It is important to understand the syntax and usage of these statements in order to effectively manipulate data in a database.



## Data Query Language (DQL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- Data Query Language (DQL) is a subset of the Structured Query Language (SQL) used to retrieve data from a database.
- The primary DQL statement is the SELECT statement, which is used to retrieve data from one or more tables in a database.
- The SELECT statement can be used to retrieve specific columns or rows of data, or to retrieve data that meets certain criteria.
- The SELECT statement can also be used in conjunction with other SQL statements, such as JOIN, to retrieve data from multiple tables.
- The SELECT statement can also be used with aggregate functions, such as COUNT, SUM, AVG, MIN, and MAX, to perform calculations on the data being retrieved.
- The SELECT statement can also be used with the GROUP BY and HAVING clauses to group data and filter the results based on certain conditions.
- The SELECT statement can also be used with the ORDER BY clause to sort the results of the query.
- In addition to the SELECT statement, DQL also includes the SHOW statement, which is used to display information about the database, such as the names of tables and columns.
- The DESCRIBE statement is another DQL statement that can be used to display information about the structure of a table, including the names and data types of its columns.
- The EXPLAIN statement can be used to display information about how a query will be executed, including the query plan and the estimated cost of the query.



## Transaction Control Language(TCL) statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

Transaction Control Language (TCL) is a subset of SQL (Structured Query Language) that is used to manage transactions in a database. A transaction is a logical unit of work that contains one or more SQL statements. TCL statements are used to control transactions, ensuring data integrity and consistency.

Here are some key points to remember about TCL statements:

1. **COMMIT**: This statement is used to permanently save any changes made to the database during a transaction. Once a transaction is committed, the changes cannot be undone.

2. **ROLLBACK**: This statement is used to undo any changes made to the database during a transaction. If a transaction is rolled back, the database is restored to its state before the transaction began.

3. **SAVEPOINT**: This statement is used to create a savepoint within a transaction. A savepoint is a point within a transaction to which you can roll back. This allows you to undo part of a transaction, rather than the entire transaction.

4. **SET TRANSACTION**: This statement is used to specify the characteristics of a transaction, such as its isolation level or whether it is read-only.

TCL statements are an important part of managing transactions in a database, ensuring data integrity and consistency. Understanding how to use these statements is essential for anyone working with databases.
