- **EXPLAIN**: Used to explain the execution plan for a query.
- **LOCK**: Used to lock a table or a row in a table.

## Transaction Control Language (TCL) Statements

* TCL (Transaction Control Language) is a set of commands used to control transactions in a database. It includes commands such as `COMMIT`, `ROLLBACK`, and `SAVEPOINT`.
* `COMMIT` is used to save all the changes made in the current transaction.
* `ROLLBACK` is used to undo all the changes made in the current transaction.
* `SAVEPOINT` is used to set a point in the transaction where you can rollback to.
* TCL is used to maintain data integrity and consistency in databases. It helps to ensure that data is correct and consistent across different transactions.
* TCL statements can be used to control the transactions in a database. They can be used to start, commit, and rollback transactions.
* TCL statements can also be used to create and manage savepoints in a transaction.
* TCL statements can be used to control the locking of data in a database. They can be used to lock and unlock data in a database.
* TCL statements can also be used to manage transactions in a distributed database environment. They can be used to control the synchronization of data between different databases.
