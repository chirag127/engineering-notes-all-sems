- ALTER DATABASE - modifies a database
- ALTER TABLE - modifies a table
- ALTER INDEX - modifies an index

3. DROP - is used to delete an existing database object
- DROP DATABASE - deletes a database
- DROP TABLE - deletes a table
- DROP INDEX - deletes an index

The above DDL statements are used to define the database structure. These statements are parsed by the database system and executed to create/modify/delete the database objects without returning any data.

## Data Manipulation Language(DML) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

1. INSERT: Used to insert new rows into a table. Specifies the table name and value for each column.
2. UPDATE: Used to update existing rows in a table. Specifies the table name, conditions to identify the rows to be updated, and new values for the columns to be updated.
3. DELETE: Used to remove existing rows from a table that satisfy a given condition. Specifies the table name and condition to identify the rows to be deleted.
4. MERGE: Used to insert or update rows depending on some conditions. It allows conditional insert or update of rows.

The above DML statements are used to manipulate (insert, update, delete) data in the database tables. They are executed using SQL and their effects are reflected in the data stored in the database.

## Transaction Control Language(TCL) statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab.

1. COMMIT: This statement is used to permanently save any changes made by the transaction to the database. It releases any locks held by the transaction.
2. ROLLBACK: This statement is used to undo any changes made by the transaction. It brings the database to the state it was in before the transaction began. It releases any locks held by the transaction.
3. SAVEPOINT: This statement is used to create a savepoint inside a transaction. It can be used to rollback a transaction to a specific savepoint. Savepoints allow partial rollbacks.

The TCL statements are used to manage transactions in a database. A transaction begins with a START or BEGIN WORK statement and ends with either a COMMIT to save the changes or a ROLLBACK to undo the changes. The SAVEPOINT statement is used to set savepoints within an ongoing transaction.
