### Semi-structured data

Semi-structured data refers to data that does not conform to a fixed schema or data model, but still contains some organizational properties that make it easier to process and analyze than unstructured data. Some common examples of semi-structured data include:

1. **XML**: Extensible Markup Language (XML) is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. XML data is stored in a hierarchical tree structure, with elements and attributes used to organize and describe the data.

2. **JSON**: JavaScript Object Notation (JSON) is a lightweight data interchange format that is easy for humans to read and write and easy for machines to parse and generate. JSON data is stored as key-value pairs, with the keys being strings and the values being any valid JSON data type, including strings, numbers, objects, arrays, and booleans.

3. **CSV**: Comma-Separated Values (CSV) is a simple file format used to store tabular data, such as a spreadsheet or database. CSV data is stored as plain text, with each line representing a row of data and values separated by commas.

Semi-structured data is often used in situations where the data being stored is not well-defined or is subject to change, as it allows for more flexibility in how the data is organized and represented. It is commonly used in web development, data analysis, and data exchange.

### Analysis vs Reporting

- **Reporting** is the process of organizing data into informational summaries in order to monitor how different areas of a business are performing.
- **Analysis**, on the other hand, is the process of exploring data and reports in order to extract meaningful insights, which can be used to better understand and improve business performance.
- Reporting is focused on the past and present, while analysis is focused on the future.
- Reporting answers the question "What happened?", while analysis answers the question "Why did it happen?" and "What can we do about it?"
- Reporting provides data, while analysis provides insights and recommendations.
- Reporting is often automated and requires little human input, while analysis requires human input and critical thinking.
- Reporting is a necessary first step in the analysis process, as it provides the data that will be analyzed.
- In summary, reporting provides the data, while analysis provides the insights and recommendations for action.

## Unit 2 - Data Analytics Lifecycle

The Data Analytics Lifecycle is a framework for conducting data analytics projects. It consists of several phases that guide the project from start to finish. The phases of the Data Analytics Lifecycle are:

1. **Discovery**: In this phase, the project team identifies the business problem or opportunity and determines the scope of the project. This includes identifying the data sources, the stakeholders, and the project goals.

2. **Data Preparation**: In this phase, the project team collects, cleans, and transforms the data. This includes dealing with missing or incomplete data, removing outliers, and converting the data into a format that can be analyzed.

3. **Model Planning**: In this phase, the project team selects the appropriate analytical techniques and tools to use. This includes identifying the variables and the relationships between them, and selecting the appropriate statistical methods.

4. **Model Building**: In this phase, the project team builds and tests the analytical models. This includes training the models on the data, validating the models, and refining them as needed.

5. **Communicating Results**: In this phase, the project team presents the results of the analysis to the stakeholders. This includes visualizing the data, explaining the findings, and making recommendations.

6. **Operationalizing**: In this phase, the project team implements the recommendations and integrates the analytical models into the business processes. This includes automating the data collection and analysis, and monitoring the results.

The Data Analytics Lifecycle provides a structured approach to conducting data analytics projects. By following the phases of the lifecycle, project teams can ensure that they are addressing the business problem or opportunity in a systematic and rigorous manner.

### Regression modeling for the notes of the Unit 3 - Data Analysis in the subject of Data Analytics

Regression modeling is a statistical technique used to analyze the relationship between two or more variables. It is used to predict the value of one variable based on the values of other variables. The variable being predicted is called the dependent variable, while the variables used to make the prediction are called independent variables.

There are several types of regression models, including:

1. **Linear Regression**: This model assumes a linear relationship between the dependent and independent variables. It is used to predict a continuous dependent variable.

2. **Logistic Regression**: This model is used to predict a binary dependent variable, such as whether an event will occur or not.

3. **Polynomial Regression**: This model is used when the relationship between the dependent and independent variables is non-linear. It can be used to model more complex relationships.

4. **Multiple Regression**: This model is used when there are multiple independent variables. It can be used to predict a continuous dependent variable.

Regression models can be used for a variety of purposes, including:

- Predicting future values
- Identifying trends
- Understanding the relationship between variables
- Evaluating the effectiveness of interventions

In order to build a regression model, the following steps are typically followed:

1. Collect and prepare the data
2. Select the type of regression model
3. Fit the model to the data
4. Evaluate the model
5. Use the model to make predictions

It is important to note that regression models are not perfect and can be influenced by a variety of factors, including the quality of the data and the assumptions made by the model. As such, it is important to carefully evaluate the model and its results before using it to make decisions.



### Unit 3 - Data Analysis: Multivariate Analysis

Multivariate analysis (MVA) is a method of gathering multiple sets of data and drawing cause-and-effect conclusions about their constituent parts. It involves evaluating multiple variables (more than two) to identify any possible association among them. This type of analysis offers a more complete examination of data by looking at all possible independent variables and their relationships to one another .

There are many different models, each with its own type of analysis. Some of these methods include:
- **Multivariate analysis of variance (MANOVA)**: extends the analysis of variance to cover cases where there is more than one dependent variable .
- **Multivariate regression**: attempts to determine a formula that can describe how elements in a vector of variables respond simultaneously to changes in others .
- **Regression analysis**: used to determine the relationship between a dependent variable and one or more independent variables .
- **Analysis of Variance (ANOVA)**: used to determine the relationship between collections of data by analyzing the difference between group means .

Multivariate analysis is especially useful for analyzing complex datasets, allowing you to gain a deeper understanding of the patterns and correlations between several variables simultaneously . Companies must gather all the relevant data they can to make data-driven decisions. Sometimes that involves taking three or more sets of data into account — and that’s where MVA comes in .



### Bayesian Modeling

Bayesian modeling is a statistical approach that is based on the Bayes' theorem. It is used to update the probability of a hypothesis as more evidence or information becomes available. Bayesian modeling is used in various fields, including data analysis, to make predictions and decisions based on uncertain or incomplete data.

Some key points to note about Bayesian modeling are:

1. Bayesian modeling is based on the concept of probability, where the probability of an event is updated as new evidence is obtained.
2. The prior probability represents the initial belief about the probability of an event before any evidence is obtained.
3. The likelihood represents the probability of observing the evidence given the hypothesis.

### Fuzzy Logic

Fuzzy logic is a form of many-valued logic in which the truth values of variables may be any real number between 0 and 1 both inclusive. In classical set theory, the membership of elements in a set is assessed in binary terms according to a bivalent condition — an element either belongs or does not belong to the set. By contrast, fuzzy set theory permits the gradual assessment of the membership of elements in a set.

2. **Fuzzy operators:** Fuzzy operators are used to combine fuzzy sets to produce a new fuzzy set. The most common fuzzy operators are the fuzzy AND, OR, and NOT operators.

3. **Fuzzy rules:** Fuzzy rules are used to describe the relationship between the input and output variables in a fuzzy system. 4. **Fuzzy inference:** Fuzzy inference is the process of drawing conclusions from a set of fuzzy rules and observed data. There are several methods for fuzzy inference, including the Mamdani method, the Sugeno method, and the Tsukamoto method.

Fuzzy logic has been applied to many fields, from control theory to artificial intelligence. It is a powerful tool for modeling complex systems and making decisions in uncertain environments. In the context of data analysis, fuzzy logic can be used to analyze data that is imprecise or uncertain, and to draw conclusions from incomplete or ambiguous information.

### Apriori Algorithm

The Apriori algorithm is an algorithm for frequent itemset mining and association rule learning over transactional databases. It was proposed by Agrawal and Srikant in 1994. The algorithm aims to identify the frequent itemsets in a database by using a bottom-up approach, where frequent subsets are extended one item at a time, and groups of candidates are tested against the data.

The key concepts of the Apriori algorithm are:

1. **Support**: The support of an itemset is the proportion of transactions in the database that contain the itemset.
2. **Confidence**: The confidence of a rule is the proportion of transactions that contain the antecedent (left-hand side) of the rule that also contain the consequent (right-hand side) of the rule.
3. **Frequent Itemset**: An itemset is considered frequent if its support is greater than or equal to a user-specified minimum support threshold.
4. **Association Rule**: An association rule is an implication of the form X → Y, where X and Y are disjoint itemsets. The rule suggests that if a transaction contains the items in X, it is likely to also contain the items in Y.

The Apriori algorithm operates in two steps:

1. **Frequent Itemset Generation**: The algorithm generates all frequent itemsets by iteratively generating candidate itemsets and testing them against the database. The candidate itemsets are generated by extending the frequent itemsets from the previous iteration with one additional item. The candidate itemsets that have a support greater than or equal to the minimum support threshold are considered frequent.
2. **Rule Generation**: The algorithm generates association rules from the frequent itemsets by considering all possible rules that can be formed from each frequent itemset. The rules are generated by dividing the frequent itemset into two disjoint subsets, X and Y, and forming the rule X → Y. The rules that have a confidence greater than or equal to a user-specified minimum confidence threshold are considered strong.

The Apriori algorithm has several advantages, including its simplicity and ease of implementation. However, it also has some limitations, such as its reliance on a user-specified minimum support threshold and its potentially high computational cost for large databases or low minimum support thresholds.

In summary, the Apriori algorithm is a widely used algorithm for frequent itemset mining and association rule learning. It operates by iteratively generating candidate itemsets and testing them against the database to identify the frequent itemsets, from which strong association rules can be generated. The algorithm has several advantages and limitations, and its performance can be affected by the choice of minimum support and confidence thresholds.

### K-means

K-means is a clustering algorithm that is used to partition a dataset into K clusters. It is an iterative algorithm that works by assigning each data point to the cluster whose centroid is closest to it. The centroid of a cluster is the mean of all the data points in the cluster. The algorithm then updates the centroids of the clusters and repeats the process until the centroids no longer change or a maximum number of iterations is reached.

The steps of the K-means algorithm are as follows:
1. Choose the number of clusters, K.
2. Randomly select K initial centroids from the data points.
3. Assign each data point to the cluster whose centroid is closest to it.
4. Recalculate the centroids of the clusters as the mean of all the data points in the cluster.
5. Repeat steps 3 and 4 until the centroids no longer change or a maximum number of iterations is reached.

K-means is a simple and widely used clustering algorithm. However, it has some limitations. For example, it is sensitive to the initial selection of centroids and can get stuck in local optima. It also assumes that clusters are spherical and equally sized, which may not always be the case in real-world data.

In summary, K-means is a clustering algorithm that partitions a dataset into K clusters by iteratively assigning data points to the closest cluster centroid and updating the centroids until convergence. It is simple and widely used, but has some limitations that should be considered when using it for clustering.

- Increased read/write throughput: By distributing the dataset across multiple shards, both read and write operations can be performed faster .
- Increased storage capacity: By increasing the number of shards, you can also increase overall total storage capacity .
- High availability: Shards can provide high availability .

#### Applications of Sharding
- Big Data Analytics: When you have terabytes of data, sharding means you don't have to warehouse data to do analytics on it. With up to 1000 shards in capacity, Oracle Sharding can turn a relational database into a warehouse-sized data store .

### Attribute and Data Types

In the context of data analytics, an attribute refers to a characteristic or feature of a data set. Attributes can be thought of as columns in a table, where each row represents an observation and each column represents an attribute.

Data types refer to the type of data that can be stored in an attribute. Common data types include:

1. **Numeric**: Numeric data types are used to store numbers. They can be further divided into integer (whole numbers) and floating-point (numbers with decimal places) data types.

2. **Categorical**: Categorical data types are used to store data that can be divided into categories or groups. Examples include gender, race, and marital status.

3. **Ordinal**: Ordinal data types are similar to categorical data types, but the categories have a specific order. An example of ordinal data is star ratings (1 star, 2 stars, 3 stars, etc.).

4. **Boolean**: Boolean data types are used to store true/false values.

5. **Text**: Text data types are used to store strings of characters, such as names or addresses.

6. **Date/Time**: Date and time data types are used to store dates and times.

It is important to choose the appropriate data type for each attribute, as this can affect the analysis and visualization of the data. For example, using a numeric data type for an attribute that should be categorical can result in incorrect calculations or misleading visualizations.



### Descriptive Statistics

Descriptive statistics is a branch of statistics that deals with the collection, analysis, interpretation, presentation, and organization of data. It is used to summarize and describe the main features of a dataset. Descriptive statistics can be divided into two main categories: measures of central tendency and measures of variability.

#### Measures of Central Tendency

Measures of central tendency are used to describe the center or typical value of a dataset. The three most common measures of central tendency are the mean, median, and mode.

- **Mean:** The mean is the sum of all the values in a dataset divided by the number of values in the dataset. It is commonly referred to as the average.

- **Median:** The median is the middle value in a dataset when the values are arranged in ascending or descending order. If the dataset has an odd number of values, the median is the middle value. If the dataset has an even number of values, the median is the average of the two middle values.

- **Mode:** The mode is the value that appears most frequently in a dataset. A dataset can have more than one mode if there is more than one value that appears with the same frequency.

#### Measures of Variability

Measures of variability are used to describe the spread or dispersion of a dataset. The three most common measures of variability are the range, variance, and standard deviation.

- **Range:** The range is the difference between the largest and smallest values in a dataset.

- **Variance:** The variance is the average of the squared differences between each value in a dataset and the mean of the dataset.

- **Standard Deviation:** The standard deviation is the square root of the variance. It is a measure of how much the values in a dataset deviate from the mean.

Descriptive statistics provide a summary of the main features of a dataset and can be useful in understanding and visualizing data. They are commonly used in data analytics and can be calculated using various statistical software packages.



### Exploratory Data Analysis

Exploratory Data Analysis (EDA) is an approach to analyzing data sets to summarize their main characteristics, often with visual methods. It is used to understand the data, discover patterns, relationships, or anomalies, and to formulate hypotheses that could lead to new data collection and experiments. EDA is an important step in the data analysis process, as it allows the analyst to make critical decisions about what is interesting to pursue further.

Here are some key points to remember when performing EDA:

1. EDA is an iterative process. The analyst should be willing to revise their hypotheses and assumptions as new information is discovered.

2. Visualization is a powerful tool in EDA. Graphs and charts can help the analyst to quickly identify patterns and relationships in the data.

3. EDA should be performed with an open mind. The analyst should be willing to consider multiple explanations for the patterns observed in the data.

4. EDA can help to identify outliers or anomalies in the data. These observations may be errors, or they may represent interesting phenomena that warrant further investigation.

5. EDA can help to guide the selection of appropriate statistical models and techniques for further analysis.

In summary, EDA is a crucial step in the data analysis process that can help the analyst to better understand the data and make informed decisions about how to proceed. It is an iterative process that involves visualization and critical thinking, and it can help to identify interesting patterns and relationships in the data.
