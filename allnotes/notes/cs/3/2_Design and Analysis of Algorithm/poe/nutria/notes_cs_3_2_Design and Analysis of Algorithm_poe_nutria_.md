A problem is NP-complete if it is both in NP (the set of problems that can be solved in polynomial time) and NP-hard (the set of problems that are at least as hard as the hardest problem in NP).

**Approximation Algorithms**

Approximation algorithms are algorithms that provide a solution to a problem that is close to the optimal solution. These algorithms are used when the optimal solution is too difficult to find or too time consuming to calculate. Approximation algorithms are used in many areas such as graph theory, network optimization, and machine learning.

**Examples**

1. Travelling Salesman Problem: This is a classic problem in which a salesman must visit a set of cities in the shortest possible route. This problem can be solved using an approximation algorithm by finding a route that is close to the optimal solution.

2. Graph Coloring: This is a problem in which a graph must be colored using a minimum number of colors. This problem can be solved using an approximation algorithm by finding a coloring that is close to the optimal solution.

3. n-Queen Problem: This is a problem in which n queens must be placed on a chessboard such that no two queens attack each other. This problem can be solved using an approximation algorithm by finding a placement that is close to the optimal solution.

4. Hamiltonian Cycles: This is a problem in which a cycle must be found that visits every vertex in a graph exactly once. This problem can be solved using an approximation algorithm by finding a cycle that is close to the optimal solution.

5. Sum of Subsets: This is a problem in which a set of numbers must be partitioned into two subsets whose sums are as close as possible. This problem can be solved using an approximation algorithm by finding a partition that is close to the optimal solution.

**NP-Completeness**

NP-Completeness is a concept in computer science that classifies certain decision problems as belonging to a class of problems known as NP-Complete. These problems are thought to be the most difficult to solve, and are often used as a benchmark for the efficiency of algorithms. 

**Approximation Algorithms**

Approximation algorithms are algorithms that are used to solve NP-Complete problems. They attempt to find a solution to the problem that is close to the optimal solution, but not necessarily the exact optimal solution. Approximation algorithms are often used when the exact optimal solution is too difficult to compute in a reasonable amount of time. 

**Examples**

1. Travelling Salesman Problem: This problem involves finding the shortest path between a set of cities, given the distances between them.

3. n-Queen Problem: This problem involves placing n queens on an nxn chessboard such that no two queens attack each other.
4. Hamiltonian Cycles: This problem involves finding a cycle in a graph that visits every vertex exactly once.
