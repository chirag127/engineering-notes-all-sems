### Responsive Web Designing for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. Responsive web design is the approach of designing a website in a way that it responds to the user's viewport, regardless of the device and provides an optimum viewing and interaction experience.

2. Key aspects of responsive web design:

- Flexible grid-based layout: The layout of responsive design is based on a flexible grid that expands and contracts as per the size of the screen.
- Flexible images: Images in responsive design shrink and grow dynamically to fit the size of the screen.
- Media queries: Media queries are used to apply different styling options for different screen sizes. They detect the width of the viewport and load the stylesheet accordingly.
- Relative units: Relative units like %, vw, vh, etc are used instead of fixed pixels so that they can vary dynamically with screen size.
- Responsive frameworks: Framework libraries like Bootstrap and Materialize have in-built responsive features that can be easily utilized.

3. Key benefits of responsive web design:

- Optimized user experience: Users get the best experience of viewing and interaction with the website content on any device.
- SEO friendliness: Responsive websites rank higher in search engines as they are mobile-friendly.
- Cost effectiveness: Only one version of the website needs to be designed and developed which suits all devices, reducing cost.
- Easy maintenance: Only one version needs to be maintained, updated, and managed.

4. Challenges with responsive web design:

- Complex to implement: Responsive design can be complex to implement with flexbox, grids, media queries, and multiple style sheets.
- Performance issues: If not implemented properly, responsive websites can face performance issues due to multiple style sheets and images.
- Compatibility issues: Responsive design may face compatibility issues with older browsers and devices. Regular testing needs to be done to resolve such issues.

### Static and Dynamic Websites

**Static Websites:**
- Content remains the same and is not updated frequently.
- Pages are created manually using HTML, CSS, and JavaScript.
- Each page is created separately and contains static content.
- Web servers simply serve the static files.
- Examples: Personal websites, business brochure sites, etc.

**Dynamic Websites:**
- Content is dynamic and is updated frequently from a database.
- Uses server-side languages like PHP, ASP.NET, etc. to generate web pages.
- Web servers run the code to fetch data from the database and generate web pages.
- Allow user interaction and customized content.
- Examples: E-commerce sites, social networking sites, etc.

The key differences between static and dynamic websites are:

1. Static sites have static content while dynamic sites have dynamic content.
2. Static sites do not need a database while dynamic sites require a database to store data.
3. Static sites do not need server-side languages while dynamic sites require server-side languages.
4. Static sites are simpler to create while dynamic sites are more complex to develop.

The choice between a static or dynamic website depends on the requirements and purpose of the website. Both have their pros and cons and selecting one will depend on factors like frequency of content update, complexity of the website, cost of development and hosting, etc.

### Images and Multimedia for the notes of the Unit 2 - Elements of HTML

1. Images
- Images are inserted in HTML using `<img>` tag
- `<img>` tag has attributes like `src` to specify image source URL, `alt` to specify alternate text and `height`, `width` to specify dimensions
- Images should be in JPEG, PNG or GIF format
- Use `alt` attribute to specify alternate text for images as it provides accessibility and is displayed if image is not loaded

2. Multimedia

### Defining Name Servers for the notes of the Unit 5 - Web Hosting in the subject of Web Designing.

1. Name servers are servers that translate a domain name into an IP address. They are an integral part of the domain name system (DNS).
2. When a user enters a domain name into their web browser, the request is sent to a name server to find the corresponding IP address. The name server then returns the IP address to the user's computer, which connects to the website.
3. There are two types of name servers:
- Primary name servers: Maintain the master list of domain names and IP addresses.
- Secondary name servers: Retrieve information from the primary name servers and store copies of the domain name database. They provide faster responses and redundancy.
4. A domain name can have multiple name servers for redundancy and performance. The name servers for a domain are specified in the domain's DNS configuration.
