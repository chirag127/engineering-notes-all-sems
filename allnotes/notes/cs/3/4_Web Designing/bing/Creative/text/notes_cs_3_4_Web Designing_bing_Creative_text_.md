### Basic principles involved in developing a web site

### Domains and Hosting

### Responsive Web Designing

- Responsive web design (RWD) is an approach or practice in web development that enables a web page to be responsive to the elements of various devices, such as layout, screen resolution, and screen width  .
- Through RWD, a website can work on any device, whether it is viewed on a desktop, tablet, phone, television, or watch .
- Responsive web design is not a separate technology, but a combination of HTML, CSS, and sometimes JavaScript that allows the web content to adapt to the different screen and window sizes of a variety of devices .
- Responsive web design is important for improving the user experience, accessibility, and performance of a website, as well as for optimizing it for search engines and reducing the maintenance costs .
- Some of the techniques that can be used to achieve responsive web design are:
  - Media queries: These are conditional statements that apply different styles based on the device characteristics, such as width, height, orientation, resolution, etc   .
  - Fluid grids: These are layout systems that use relative units, such as percentages, to define the width and height of the elements, instead of fixed units, such as pixels. This allows the elements to resize and reposition according to the available space  .
  - Flexible images: These are images that scale and crop according to the screen size and resolution, using CSS properties, such as max-width, object-fit, and srcset  .
  - Responsive typography: This is the practice of using relative units, such as ems and rems, to define the font size and line height of the text, as well as using media queries to adjust the font size and style based on the device characteristics .
  - Responsive frameworks: These are libraries or tools that provide ready-made components and templates for creating responsive web pages, such as Bootstrap, Foundation, and Materialize .

### Static and Dynamic Websites

- In web design, static and dynamic websites refer to the way they display content .
- A static website is one with stable content, where every user sees the exact same thing on each individual page   .
- A static website is usually written exclusively in HTML and does not require any server-side processing or database.
- A static website is faster, cheaper, and easier to create and maintain than a dynamic website   .
- A static website is suitable for simple and small websites that do not need frequent updates or user interaction   .
- A dynamic website, on the other hand, is one that can display different content and provide user interaction, by making use of advanced programming and databases in addition to HTML    .
- A dynamic website can tailor content per individual visitor, based on their preferences, location, behavior, or other factors  .
- A dynamic website requires server-side processing and database management to generate web pages on-the-fly.
- A dynamic website is slower, more expensive, and more complex to create and maintain than a static website   .
- A dynamic website is suitable for large and interactive websites that need frequent updates or user input   .



### Web Standards and W3C Recommendations

- Web standards are a set of rules and guidelines that define how web technologies should work and how they should be implemented by browsers, servers, and developers.
- Web standards ensure that web pages and applications are interoperable, accessible, secure, and user-friendly across different devices and platforms.
- Web standards are developed by various organizations and communities, such as the World Wide Web Consortium (W3C), the Internet Engineering Task Force (IETF), the Web Hypertext Application Technology Working Group (WHATWG), and the Ecma International.
- W3C is the main international standards organization for the web. It was founded in 1994 by Tim Berners-Lee, the inventor of the web, and is composed of member organizations, staff, and the public.
- W3C publishes documents that define web technologies, such as HTML, CSS, XML, SVG, RDF, and WCAG. These documents follow a process designed to promote consensus, fairness, public accountability, and quality. At the end of this process, W3C publishes Recommendations, which are considered web standards .
- W3C also publishes other types of documents, such as Working Drafts, Candidate Recommendations, Proposed Recommendations, and Working Group Notes, which represent different stages of development and maturity of web technologies .
- W3C web standards are optimized for interoperability, security, privacy, web accessibility, and internationalization. W3C's proven web standards process is based on fairness, openness, royalty-free, and making the web work for everyone .
- W3C is focusing on technologies to enable web access anywhere, anytime, using any device. This includes web access from mobile phones and other mobile devices as well as use of web technology in consumer electronics, printers, interactive television, and even automobiles.
- W3C's web standards are reviewed for accessibility support by the Accessible Platform Architectures (APA) Working Group. The W3C standards and Working Group Notes introduced below are particularly relevant to accessibility:
  - Web Content Accessibility Guidelines (WCAG): provide principles, guidelines, and success criteria for making web content accessible to people with disabilities.
  - Authoring Tool Accessibility Guidelines (ATAG): provide guidelines for designing web authoring tools that are both accessible to authors with disabilities and capable of producing accessible web content.
  - User Agent Accessibility Guidelines (UAAG): provide guidelines for designing web browsers and media players that are accessible to people with disabilities and can render web content according to the user's preferences and needs.
  - Accessible Rich Internet Applications (WAI-ARIA): provide a framework for adding accessibility information to web content and applications using dynamic and interactive features, such as menus, tabs, dialogs, and widgets.
  - Web Accessibility Initiative - Accessible Document Format (WAI-ADF): provide guidance and techniques for creating accessible documents in various formats, such as PDF, EPUB, and Office Open XML.
  - Cognitive Accessibility Roadmap and Gap Analysis (COGA): provide a roadmap and gap analysis for improving web accessibility for people with cognitive and learning disabilities.
  - Personalization Semantics Content Module (Personalization): provide a vocabulary and syntax for expressing personalization preferences and rules for web content and applications.

### Mark up Tags
- Mark up tags are the elements that define the structure and content of a web page.
- Mark up tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p>.
- The first tag in a pair is called the start tag or opening tag, and the second tag is called the end tag or closing tag.
- The content between the start and end tags is called the element content, and the tags and content together form an element.
- Some mark up tags are self-closing, meaning they do not need an end tag. For example, <img> is a self-closing tag that inserts an image on the web page.
- Mark up tags can have attributes, which are additional information that modify the behavior or appearance of the element. Attributes are written inside the start tag, after the tag name, and consist of a name and a value, separated by an equal sign (=). For example, <img src="logo.png" alt="Logo"> has two attributes: src and alt.
- The src attribute specifies the source or location of the image file, and the alt attribute provides an alternative text for the image, in case it cannot be displayed or accessed by the user.
- Mark up tags can be nested, meaning one element can contain another element inside its content. For example, <p><strong>This is a paragraph with bold text.</strong></p> is a nested element, where the <strong> element is inside the <p> element.
- The order of nesting is important, and the elements must be closed in the reverse order of opening. For example, <p><strong>This is wrong.</p></strong> is an invalid mark up, because the <p> element is closed before the <strong> element.
- Mark up tags can be categorized into two types: structural and semantic.
- Structural mark up tags define the layout and presentation of the web page, such as headings, paragraphs, lists, tables, etc. For example, <h1> is a structural tag that creates a level one heading on the web page.
- Semantic mark up tags define the meaning and purpose of the content, such as emphasis, quotations, citations, definitions, etc. For example, <em> is a semantic tag that creates emphasized or italic text on the web page.
- Semantic mark up tags are preferred over structural mark up tags, because they provide more information and accessibility for the users and the web browsers. For example, <em> is better than <i>, because <em> indicates the importance of the text, while <i> only indicates the style of the text.

### Positioning

- Positioning is a CSS property that allows you to control how elements are laid out on a web page.
- Positioning can be used to create complex layouts, overlap elements, or fix elements to a specific location on the screen.
- There are five values for the `position` property: `static`, `relative`, `absolute`, `fixed`, and `sticky`.
- The default value for the `position` property is `static`, which means the element is placed in the normal flow of the document, without any offset or alignment.
- The `relative` value means the element is placed in the normal flow of the document, but can be offset from its original position using the `top`, `right`, `bottom`, and `left` properties. The offset is relative to the element's original position.
- The `absolute` value means the element is removed from the normal flow of the document, and positioned relative to its closest positioned ancestor (an element with a `position` value other than `static`). If there is no positioned ancestor, the element is positioned relative to the document body. The element can be placed anywhere on the page using the `top`, `right`, `bottom`, and `left` properties.
- The `fixed` value means the element is removed from the normal flow of the document, and positioned relative to the viewport (the visible area of the browser window). The element stays in the same place even when the page is scrolled. The element can be placed anywhere on the page using the `top`, `right`, `bottom`, and `left` properties.
- The `sticky` value means the element is placed in the normal flow of the document, but behaves like a `fixed` element when it reaches a certain threshold. The element can be "stuck" to the top, bottom, left, or right edge of the viewport using the `top`, `right`, `bottom`, and `left` properties. The element returns to its normal position when it is no longer within the threshold. The `sticky` value is not supported by all browsers.

### CSS Color

- Color keywords are predefined words that represent a specific color. They are not case-sensitive and can be used as an alternative to color names or values. ### Javascript Types

- Javascript has **seven** basic types: **number**, **string**, **boolean**, **null**, **undefined**, **symbol**, and **object**.

- The **string** type represents a sequence of characters enclosed by single or double quotes. For example, `var name = "Sydney";` and `var greeting = 'Hello';` are both valid string declarations.

- The **object** type represents a collection of properties, each of which has a name and a value. ### Defining Name Servers

- A name server is a specialized server that hosts DNS zone files and plays a vital role in the Domain Name System (DNS) .
- DNS is a system that translates domain names into IP addresses and helps browsers make connections between URLs and websites .
- A domain name needs to be resolved into a valid IP address of a physical server to open a website. A name server is the address of that web server .
- For example, if you want to visit www.example.com, your browser will ask a name server for the IP address of the web server that hosts that website. The name server will look up the DNS records for www.example.com and return the IP address to your browser. Your browser will then send a request to that IP address and load the website .
- Name servers are usually provided by your web hosting provider or your domain registrar. You can edit your domain's name servers at the domain registrar where you purchased your domain name .
- Name servers usually have a format like ns1.example.com and ns2.example.com, where example.com is the name of your web hosting provider or domain registrar .
- Name servers are important because they help direct traffic on the Internet and ensure that your website is accessible to your visitors .

### Using FTP Client

- FTP stands for File Transfer Protocol, which is a standard network protocol for transferring files between a client and a server over the Internet.
- FTP client is a software application that allows the user to upload, download, delete, rename, or move files and directories on a remote server using FTP commands.
- FTP client can be used for web hosting purposes, such as uploading web pages, images, scripts, or other files to a web server, or downloading them for backup or editing.
- Some examples of FTP clients are FileZilla, WinSCP, Cyberduck, and CuteFTP.
- To use FTP client, the user needs to have the following information:
  - The hostname or IP address of the FTP server
  - The username and password for accessing the FTP server
  - The port number for the FTP connection (usually 21)
  - The mode of transfer (binary or ASCII)
  - The directory or path where the files are located on the server or the client
- The steps for using FTP client are as follows:
  - Launch the FTP client and enter the connection details (hostname, username, password, port, etc.)
  - Establish the connection with the FTP server and navigate to the desired directory or path on the server or the client
  - Select the files or directories that need to be transferred and drag and drop them to the other side or use the upload or download buttons
  - Monitor the progress of the transfer and check for any errors or warnings
  - Disconnect from the FTP server when the transfer is complete
- Some advantages of using FTP client are:
  - It is fast and reliable for transferring large or multiple files over the Internet
  - It supports resume and pause functions for interrupted transfers
  - It allows the user to manage the files and directories on the server easily and securely
  - It supports various encryption and authentication methods for enhanced security
  - It can be integrated with other web development tools or applications
- Some disadvantages of using FTP client are:
  - It requires the user to have the FTP server credentials and permissions
  - It can be vulnerable to cyberattacks or data breaches if the connection is not encrypted or protected
  - It can consume a lot of bandwidth and resources for transferring files
  - It can be affected by network latency or congestion
  - It can be incompatible with some file formats or systems

### Basics of SEO

SEO stands for Search Engine Optimization, which is the process of improving the ranking and visibility of a website in search engines. The higher or more frequently a website is displayed in a search engine list (like Google), the more visitors it is expected to receive.

1. Keyword research. Find what people search for and what keywords are relevant to your website's content and goals.
2. Content creation. Craft content that matches the search intent and provides value to the visitors. Use keywords naturally and strategically in your content.

### Onpage Optimization Basics

Onpage optimization is the process of improving the content, structure, and code of a web page to make it more relevant, user-friendly, and accessible for search engines and users. Onpage optimization aims to increase the organic traffic and ranking of a web page in search engine results pages (SERPs).

Some of the basic steps for onpage optimization are:

- **Optimize title tag and meta description.** These are the elements that appear in the SERPs and tell the users and search engines what the page is about. They should include the main keyword, be concise, and compelling.
- **Create high-quality content.** High-quality content is original, unique, informative, and engaging. It should provide value to the users and answer their queries. It should also include relevant keywords, headings, subheadings, and images.
- **Optimize images.** Images should have descriptive file names, alt texts, and captions that include the keywords. They should also be compressed and resized to improve the loading speed and user experience of the web page.
- **Take care of internal linking.** Internal linking is the practice of linking to other relevant pages within the same website. It helps the users navigate the site, find more information, and stay longer on the site. It also helps the search engines crawl and index the site, and understand the site structure and hierarchy.
- **Use SEO-friendly URLs.** URLs are the addresses of the web pages. They should be short, descriptive, and include the keywords. They should also use hyphens to separate words, and avoid using parameters, underscores, or capital letters.
