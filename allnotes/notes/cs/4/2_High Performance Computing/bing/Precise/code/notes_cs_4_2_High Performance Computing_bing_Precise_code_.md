### History of Grid Computing

- The idea of grid computing originated in the 1990s as a metaphor for making computer power as easy to access as an electric power grid.
- Where parallel computing and supercomputers were primarily used in the '80s and '90s, grid computing began to take shape as an option by the mid-1990s.
- Early in the 1990s, Steve Tuecke, Ian Foster, and Carl Kesselman developed the concept of grid computing.
- They created the Globus Toolkit standard, which had grids for controlling data processing, data storage, and heavy computation.
- The power grid metaphor for accessible computing quickly became canonical when Ian Foster and Carl Kesselman published their seminal work, "The Grid: Blueprint for a new computing infrastructure" (1999).
- With the widespread availability of high-speed networks, it became feasible to outsource computing to remote providers and to federate resources from many locations.
- Such observations motivated the development, from the mid-1990s onwards, of a range of innovative Grid technologies, applications, and infrastructures.

### Grid Computing Model and Protocols

Grid computing is a distributed computing model that allows for the sharing of resources across multiple administrative domains. This model is designed to solve large-scale computational problems by utilizing the combined processing power of multiple computers.

The key components of a grid computing system include:

1. **Resource Providers**: These are the organizations or individuals that provide the computational resources, such as processing power, storage, and network bandwidth, to the grid.

2. **Resource Brokers**: These are the entities responsible for matching the computational needs of the users with the available resources on the grid.

3. **Users**: These are the individuals or organizations that utilize the grid to solve their computational problems.

4. **Grid Middleware**: This is the software layer that provides the necessary protocols and services for resource discovery, allocation, and management.

Some of the key protocols used in grid computing include:

- **Grid Resource Allocation and Management (GRAM)**: This protocol is used for the allocation and management of computational resources on the grid.

- **Grid Security Infrastructure (GSI)**: This protocol provides the necessary security mechanisms for authentication and authorization of users and resources on the grid.

- **Grid File Transfer Protocol (GridFTP)**: This protocol is used for the efficient transfer of large data sets between resources on the grid.

- **Grid Resource Information Service (GRIS)**: This protocol is used for the discovery and monitoring of resources on the grid.

These are some of the key components and protocols used in grid computing. This technology allows for the efficient utilization of computational resources to solve large-scale problems.

## Unit 2 - Open Grid Services Architecture

The Open Grid Services Architecture (OGSA) is a set of standards that define the way in which grid computing systems should be built and interact with each other. It is based on the principles of service-oriented architecture (SOA) and aims to provide a common framework for the development of grid applications.

Some key points to note about OGSA include:

1. OGSA is designed to be platform and language independent, allowing for interoperability between different grid systems.
2. It defines a set of standard interfaces and behaviors for grid services, which are the building blocks of grid applications.
3. OGSA services are designed to be loosely coupled and dynamically bound, allowing for flexibility and scalability in grid systems.
4. The architecture supports the creation, management, and discovery of grid services, as well as the management of their interactions and data.
5. OGSA is an evolving standard, with ongoing development and refinement by the grid computing community.

Overall, the Open Grid Services Architecture provides a foundation for the development of grid systems that are interoperable, flexible, and scalable. It is an important component of the broader grid computing ecosystem.

## Unit 4 - Beowulf Cluster

A Beowulf cluster is a computer cluster of what are normally identical, commodity-grade computers networked into a small local area network with libraries and programs installed which allow processing to be shared among them. The result is a high-performance parallel computing cluster from inexpensive personal computer hardware.

- Beowulf clusters are named after the Beowulf poem, as they are both powerful and composed of many parts working together.
- The primary advantage of Beowulf clusters is their ability to provide high-performance computing at a relatively low cost.
- Beowulf clusters are typically used for scientific computing, including tasks such as fluid dynamics simulations, weather modeling, and molecular dynamics simulations.
- Beowulf clusters can be built using off-the-shelf hardware, and can be easily scaled by adding more nodes to the cluster.
- The software used in Beowulf clusters is typically open-source, including the Linux operating system and the MPI library for message passing between nodes.
- Beowulf clusters can be built using a variety of network topologies, including Ethernet, InfiniBand, and Myrinet.

## Unit 5 - Overview of Cloud Computing

Cloud computing is the delivery of computing services, including software, storage, and processing power, over the internet. This allows users to access and use these services without having to invest in and maintain their own computing infrastructure.

1. **On-demand self-service:** Cloud computing allows users to access and use computing resources as needed, without the need for human intervention.

2. **Broad network access:** Cloud services are available over the internet and can be accessed from anywhere with an internet connection.

3. **Resource pooling:** Cloud service providers pool their resources to serve multiple customers, allowing for efficient use of resources.

4. **Rapid elasticity:** Cloud services can be scaled up or down quickly and easily to meet changing demand.

5. **Measured service:** Cloud service usage is monitored and measured, allowing for transparent billing and resource allocation.

Cloud computing has become increasingly popular due to its flexibility, scalability, and cost-effectiveness. It is used by businesses of all sizes, as well as individuals, for a wide range of applications. Some common uses of cloud computing include data storage and backup, web hosting, and software as a service (SaaS).



### Types of Cloud

Clouds are classified into different types based on their shape, size, and altitude. The classification of clouds into types was first proposed by Luke Howard in 1802 and we largely use the same system today . This system splits clouds into three main types - stratus, cumulus, and cirrus .

1. **Stratus clouds** are low-level clouds that are usually uniform and flat, producing a gray layer of cloud cover which may be precipitation-free or may cause periods of light precipitation .

2. **Cumulus clouds** are often described as "puffy" or "cotton-like" in appearance and may have flat bases . Cumulus clouds develop on clear, sunny days when the sun heats the ground directly below .

3. **Cirrus clouds** are high clouds, thin wispy and feathery, composed of ice crystals .

In addition to these three main types, there is a fourth special type, **nimbus**, which is used to describe clouds that produce precipitation .

Clouds can also be grouped by the altitude level or levels in the troposphere at which they are normally found. These groupings include high (cirro-, cirrus), middle (alto-), multi-level (nimbo-, cumulo-, cumulus), and low (strato-, stratus) .
