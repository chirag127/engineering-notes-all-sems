

## Unit 1 - Introduction To Cloud Computing

Cloud computing is a technology that enables users to access and use computing resources, such as servers, storage, and applications, over the internet. It is a cost-effective and efficient way of delivering computing services to businesses and individuals.

Here are some key concepts you should know about cloud computing:

- **Cloud computing models**: There are three main models of cloud computing:
     - **Infrastructure-as-a-Service (IaaS)**: This model provides users with access to virtualized computing resources, such as servers, storage, and networking, over the internet. Users can deploy and manage their own software applications and operating systems on these resources.
     - **Platform-as-a-Service (PaaS)**: This model provides users with a platform for developing, deploying, and managing their own software applications, without having to worry about the underlying infrastructure. The platform includes tools and services for building, testing, and deploying applications.
     - **Software-as-a-Service (SaaS)**: This model provides users with access to software applications over the internet, without having to install or maintain the software on their own devices.

- **Cloud deployment models**: There are four main deployment models of cloud computing:
     - **Public cloud**: This model provides computing resources that are shared among multiple users over the internet. Users can access these resources on a pay-per-use basis.
     - **Private cloud**: This model provides computing resources that are dedicated to a single organization, and are hosted either on-premises or by a third-party provider.
     - **Hybrid cloud**: This model combines public and private cloud resources, allowing users to manage and scale their computing workloads across both environments.
     - **Community cloud**: This model provides computing resources that are shared among a group of organizations with similar requirements, such as security, compliance, or performance.

- **Cloud service providers**: There are many cloud service providers that offer cloud computing services, including:
     - Amazon Web Services (AWS)
     - Microsoft Azure
     - Google Cloud Platform (GCP)
     - IBM Cloud
     - Oracle Cloud

- **Benefits of cloud computing**: There are many benefits of using cloud computing, including:
     - Cost savings: Cloud computing can reduce the cost of hardware, software, and maintenance, as well as the need for in-house IT staff.
     - Scalability: Cloud computing allows users to scale their computing resources up or down as needed, without having to invest in additional hardware.
     - Flexibility: Cloud computing allows users to access their computing resources from anywhere, using any device with an internet connection.
     - Security: Cloud service providers typically offer robust security measures to protect users' data and applications.

- **Challenges of cloud computing**: There are also some challenges associated with cloud computing, including:
     - Security risks: Cloud computing may pose security risks, such as data breaches or unauthorized access to data.
     - Dependence on the internet: Cloud computing relies on the internet to deliver services, which can be a vulnerability if the internet connection is slow or unreliable.
     - Data privacy: Cloud service providers may have access to users' data, which raises concerns about data privacy and ownership.

In conclusion, cloud computing is a powerful technology that has revolutionized the way we use computing resources. By understanding the key concepts and benefits and challenges of cloud computing, you can make informed decisions about whether and how to use cloud computing in your business or personal life.



### Definition of Cloud

Cloud computing refers to the delivery of computing services, including servers, storage, databases, networking, software, analytics, and intelligence, over the internet. These services are provided by third-party providers, who own and maintain the necessary infrastructure, hardware, and software.

The following are some key points that define cloud computing:

- Cloud computing provides on-demand access to a shared pool of computing resources, which can be quickly and easily provisioned without the need for human intervention.
- Cloud services are typically offered on a pay-per-use or subscription basis, allowing organizations to scale their usage up or down as needed, without having to make large upfront investments in infrastructure and software.
- Cloud computing can be accessed from anywhere with an internet connection, using a variety of devices, including desktop computers, laptops, tablets, and smartphones.
- Cloud computing services are typically divided into three categories: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- IaaS provides access to virtualized computing resources, such as servers, storage, and networking, allowing organizations to build and run their own applications and services on top of this infrastructure.
- PaaS provides a complete development and deployment environment for building and running custom applications, without the need to manage the underlying infrastructure.
- SaaS provides access to pre-built software applications, such as email, CRM, and productivity tools, that are hosted and managed by third-party providers.

In summary, cloud computing is a model for delivering computing services over the internet, providing on-demand access to a shared pool of computing resources, and enabling organizations to scale their usage up or down as needed, without having to make large upfront investments in infrastructure and software.



### Evolution of Cloud Computing

Cloud computing has rapidly evolved over the past decade and has become an integral part of modern technology. Here are some of the key milestones in the evolution of cloud computing:

1. Mainframe Computing: In the 1950s and 1960s, mainframe computers were used to perform large-scale computing tasks. However, these computers were extremely expensive and required specialized skills to operate.

2. Client-Server Computing: In the 1980s and 1990s, client-server computing became popular. This architecture allowed for more affordable and flexible computing by distributing processing between a client device and a server.

3. Virtualization: In the early 2000s, virtualization technology emerged as a way to maximize the use of hardware resources by allowing multiple virtual machines to run on a single physical machine.

4. Utility Computing: In the mid-2000s, utility computing was introduced as a way to offer computing resources on-demand, similar to a utility such as electricity. This allowed for more efficient use of resources and cost savings.

5. Cloud Computing: In the late 2000s, cloud computing emerged as a new paradigm for delivering computing services over the internet. This allowed for even greater flexibility and scalability, as well as the ability to pay for only the resources used.

6. Serverless Computing: In recent years, serverless computing has become popular, allowing developers to focus on writing code without worrying about the underlying infrastructure. This further simplifies the development and deployment of applications.

Overall, the evolution of cloud computing has led to more efficient and cost-effective ways of delivering computing services. As technology continues to evolve, we can expect to see even more advancements in the cloud computing space.



### Underlying Principles of Parallel and Distributed Computing

Parallel and distributed computing are two important concepts in computer science, especially in the context of cloud computing. In distributed computing, multiple computers work together to execute different parts of a program simultaneously. - **Fault-tolerance:** Fault-tolerance refers to the ability of a system to continue operating even if one or more components fail. In parallel computing, fault-tolerance can be achieved by replicating data across multiple processors or by using error-correcting codes. In distributed computing, fault-tolerance can be achieved by replicating data across multiple computers or by using redundancy in the network. Fault-tolerance is important because it ensures that the system can continue to operate even in the presence of failures.

- **Communication:** Communication refers to the ability of processors or computers to exchange data with each other. In parallel computing, communication is typically achieved through shared memory or message passing. In distributed computing, communication is typically achieved through message passing over a network. Communication is important because it enables processors or computers to work together to solve complex problems.

- **Load balancing:** Load balancing refers to the ability to distribute tasks evenly across multiple processors or computers. In parallel computing, load balancing is important to ensure that each processor is working on a similar amount of work. In distributed computing, load balancing is important to ensure that each computer is working on a similar amount of work. Load balancing is important because it maximizes the efficiency of the system by utilizing all available resources.

These principles are the foundation of parallel and distributed computing and are essential for understanding how cloud computing works. By breaking down complex tasks into smaller parts and distributing them across multiple processors or computers, parallel and distributed computing enable the processing of large amounts of data quickly and efficiently.

### Elasticity in Cloud

Elasticity is one of the key features of cloud computing. It refers to the ability of the cloud to dynamically allocate and deallocate computing resources based on the workload demand. Elasticity is essential in ensuring that the cloud infrastructure can meet the needs of the users efficiently and effectively. In this section, we will explore the concept of elasticity in cloud computing in more detail.

#### What is Elasticity in Cloud Computing?

Elasticity is the ability of a cloud infrastructure to automatically allocate and deallocate computing resources based on the workload demand. This means that the cloud can scale up or down the resources required by an application or service as needed, without any manual intervention. Elasticity ensures that the cloud infrastructure can meet the changing demands of users and applications, while minimizing the cost of resources.

#### How does Elasticity work in Cloud Computing?

Elasticity in cloud computing works by dynamically allocating and deallocating computing resources based on the workload demand. When the workload increases, the cloud infrastructure automatically adds more computing resources to meet the demand. When the workload decreases, the cloud infrastructure releases the unused resources to save costs.

#### Benefits of Elasticity in Cloud Computing

Elasticity provides several benefits in cloud computing, including:

- Scalability: Elasticity ensures that the cloud infrastructure can meet the changing demands of users and applications, without any manual intervention.
- Cost-effectiveness: Elasticity ensures that the cloud infrastructure uses only the required resources, which helps to minimize the cost of resources.
- Improved performance: Elasticity ensures that the cloud infrastructure can allocate resources quickly and efficiently, which helps to improve the performance of applications and services.
- Increased availability: Elasticity ensures that the cloud infrastructure can handle sudden spikes in demand without any downtime, which helps to increase the availability of applications and services.

#### Elasticity in Public Clouds

Public cloud providers, such as Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP), offer elasticity as a key feature of their cloud offerings. These providers use advanced algorithms and machine learning techniques to automatically allocate and deallocate computing resources based on the workload demand. Public clouds also offer pay-as-you-go pricing, which means that users only pay for the resources they use, making elasticity an affordable option.

#### Elasticity in Private Clouds

Private clouds can also offer elasticity, but it requires more manual intervention compared to public clouds. Private cloud administrators need to monitor the workload demand and manually allocate or deallocate computing resources accordingly. Private clouds also require more upfront investment in infrastructure and hardware, which can make elasticity more expensive compared to public clouds.

#### Conclusion

Elasticity is a key feature of cloud computing that allows the cloud infrastructure to dynamically allocate and deallocate computing resources based on the workload demand. Elasticity provides several benefits, including scalability, cost-effectiveness, improved performance, and increased availability. Public cloud providers offer elasticity as a key feature of their cloud offerings, while private clouds require more manual intervention. Understanding elasticity is essential in designing and managing cloud infrastructure effectively.

## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

Service-Oriented Architecture (SOA) is a software design approach that focuses on building a collection of loosely coupled, autonomous services that communicate with each other to deliver a particular functionality. In the context of cloud computing, SOA is a critical enabling technology that allows enterprises to build scalable, reliable, and flexible cloud-based applications.

Here are some key points to understand about Service-Oriented Architecture:

- SOA is based on the concept of services, which are self-contained, modular, and reusable units of software functionality that can be accessed and combined to create more complex applications.

- Each service in an SOA typically provides a specific business function or capability, such as order management, inventory tracking, or customer support.

- SOA services communicate with each other by exchanging messages over a communication protocol, such as SOAP or REST, using well-defined interfaces and standards.

- SOA services are designed to be loosely coupled, which means that they can be updated or replaced without affecting other services or the overall system.

- SOA promotes the use of standard interfaces and protocols, which makes it easier to integrate different services and components.

- SOA is often used in conjunction with other cloud-enabling technologies, such as virtualization, containerization, and microservices, to create more flexible and scalable cloud-based applications.

- SOA can help organizations to reduce costs, improve agility, and enhance the user experience by enabling them to quickly develop and deploy new applications and services.

Overall, Service-Oriented Architecture is a critical technology for building cloud-based applications that are scalable, flexible, and resilient. By adopting SOA principles and best practices, organizations can create a more agile and responsive IT infrastructure that can adapt to changing business needs and deliver better outcomes for their customers.

### Web Services

Web Services are a type of software system designed to support interoperable machine-to-machine interaction over a network. They are based on the Service-Oriented Architecture (SOA) and use standards-based communication protocols to enable data exchange between disparate applications.

Here are some key points to keep in mind about Web Services:

- Web Services can be divided into two categories: SOAP-based Web Services and RESTful Web Services.
- SOAP-based Web Services use a standardized XML messaging format called SOAP (Simple Object Access Protocol) and support a variety of transport protocols, including HTTP, SMTP, and TCP.
- RESTful Web Services, on the other hand, use lightweight, stateless protocols such as HTTP and support a range of data formats, including JSON and XML.
- Web Services are typically described in a machine-readable format using the Web Services Description Language (WSDL).
- WSDL provides a standard way of defining the interface to a Web Service, including the operations it supports, the input and output parameters, and the communication protocols it uses.
- Web Services can be implemented using a variety of programming languages and frameworks, including Java, .NET, and PHP.
- They offer a range of benefits, including improved interoperability, scalability, and reusability of code.
- Web Services are widely used in modern software development, including in cloud-based applications and microservices architectures.

Overall, Web Services are an essential technology for enabling interoperability and communication between disparate applications, and are an important component of modern software development practices.



### Publish, Subscribe Model for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

The Publish-Subscribe Model is a messaging pattern used in distributed systems, where senders (publishers) do not need to know the identities of receivers (subscribers) in order to communicate with them. The model is also known as the pub/sub model.

Here are some key points to understand the Publish-Subscribe Model:

- In this model, publishers send messages on a particular topic or channel, without knowing the identity of the subscribers who may be interested in receiving the message.
- Subscribers who have registered their interest in a particular topic or channel receive the message when it is published by the publisher.
- Publishers and subscribers are decoupled from each other, meaning they can operate independently without knowing about each other.
- The Publish-Subscribe Model can be used in various scenarios, such as real-time data feeds, event-driven architectures, and message-oriented middleware.
- The model is useful in cloud computing, where applications need to be scalable and distributed across multiple nodes.

Advantages of the Publish-Subscribe Model:

- Loose coupling: Publishers and subscribers are decoupled from each other, which makes it easier to add or remove subscribers without affecting the publishers, or vice versa.
- Scalability: The model can handle a large number of subscribers, as each subscriber only receives the messages they are interested in, rather than receiving all messages sent by the publisher.
- Flexibility: The model allows for dynamic registration and deregistration of subscribers, which can adapt to changing requirements.

Disadvantages of the Publish-Subscribe Model:

- Complexity: The model can be more complex to implement compared to traditional point-to-point messaging systems.
- Overhead: The model requires additional overhead to manage the registration and deregistration of subscribers, as well as maintaining the topics or channels.

In conclusion, the Publish-Subscribe Model is a useful messaging pattern for distributed systems, particularly in cloud computing environments where applications need to be scalable and distributed. It provides loose coupling, scalability and flexibility, but also requires additional complexity and overhead to manage.

In summary, virtualization is a powerful technology that is essential for cloud computing. 4. **Network Virtualization:** This type of virtualization involves creating multiple virtual networks that run on a single physical network infrastructure. Each virtual network operates as if it were a separate physical network, allowing multiple applications to run on a single physical network infrastructure.

5. **Application Virtualization:** This type of virtualization involves separating the application from the underlying operating system and hardware. This allows the application to be run on any device or operating system, making it more flexible and portable.

In conclusion, virtualization is a critical technology that enables cloud computing by providing a layer of abstraction that allows applications to run on a wide variety of hardware and operating systems. ### Virtualization Structures

Virtualization is a key technology in the field of cloud computing that enables the creation of multiple virtual machines (VMs) on a single physical machine. Virtualization structures are used to manage and control these virtual machines, and they play a critical role in the design and implementation of cloud-based systems. In this section, we will discuss some of the key virtualization structures used in cloud computing.

1. Hypervisor
A hypervisor, also known as a virtual machine monitor (VMM), is a software layer that enables the creation and management of virtual machines on a physical machine. It provides a layer of abstraction between the physical machine and the virtual machines, allowing multiple operating systems to run on a single physical machine. There are two types of hypervisors: Type 1 and Type 2. Type 1 hypervisors run directly on the physical hardware, while Type 2 hypervisors run on top of a host operating system.

2. Virtual Machine
A virtual machine (VM) is a software emulation of a physical machine. It provides an isolated environment in which an operating system and applications can run. Each virtual machine has its own resources, such as CPU, memory, storage, and network connectivity. Virtual machines are created and managed by the hypervisor.

3. Virtualization Layer
The virtualization layer is a software layer that sits between the virtual machines and the physical hardware. It provides a set of services that enable the creation, management, and monitoring of virtual machines. The virtualization layer is responsible for allocating physical resources to virtual machines and ensuring that they have access to the resources they need.

4. Virtual Network
A virtual network is a software-defined network that enables communication between virtual machines. It provides a layer of abstraction between the virtual machines and the physical network infrastructure. Virtual networks can be used to create isolated environments for different applications or customers, or to provide connectivity between virtual machines in different locations.

5. Virtual Storage
Virtual storage is a technology that enables the creation of virtualized storage resources. It allows multiple virtual machines to share a common pool of storage resources, while ensuring that each virtual machine has its own isolated storage environment. Virtual storage can be used to create highly available and scalable storage solutions for cloud-based systems.

In conclusion, virtualization structures are essential components of cloud-based systems. They enable the creation and management of virtual machines, and provide a layer of abstraction between the physical hardware and the virtual machines. Understanding the key virtualization structures is critical for designing and implementing cloud-based systems that are scalable, reliable, and cost-effective.

### S3

Amazon S3 (Simple Storage Service) is a highly scalable and durable object storage service offered by Amazon Web Services (AWS). It is designed to store and retrieve any amount of data from anywhere on the web, making it an ideal solution for a wide range of use cases, from backup and archival to big data analytics and content distribution.

#### Key Features of S3

- **Scalability**: S3 can scale to store and retrieve any amount of data, from a few kilobytes to petabytes and beyond, without any upfront costs or capacity planning.

- **Durability**: S3 provides 99.999999999% durability (11 nines) of objects over a given year, which means that data is highly protected against failures, errors, and disasters.

- **Availability**: S3 offers a highly available and resilient storage infrastructure, with a service-level agreement (SLA) of 99.9% uptime per year.

- **Security**: S3 provides multiple layers of security and compliance controls to protect data at rest and in transit, including encryption, access controls, and auditing.

- **Lifecycle Management**: S3 allows users to automate the transition of objects to different storage classes or delete them when they are no longer needed, based on predefined rules.

- **Versioning**: S3 supports versioning of objects, which allows users to preserve, retrieve, and restore every version of an object, even if it has been deleted or overwritten.

- **Cross-Region Replication**: S3 provides a feature called cross-region replication, which allows users to replicate objects across different regions for data redundancy, compliance, or latency reasons.

- **Integrations**: S3 integrates with a wide range of AWS services, such as Amazon EC2, Amazon RDS, Amazon EMR, and Amazon CloudFront, as well as third-party tools and applications.

#### S3 Storage Classes

S3 provides several storage classes that offer different levels of durability, availability, and cost, depending on the access patterns and retention requirements of the data. The main S3 storage classes are:

- **Standard**: This is the default storage class, which provides high durability, availability, and performance for frequently accessed data.

- **Infrequent Access (IA)**: This storage class is designed for data that is accessed less frequently, but still requires rapid access when needed. It offers lower storage cost than the standard class, but with additional retrieval fees.

- **One Zone-Infrequent Access (One Zone-IA)**: This storage class is similar to IA, but stores data in a single availability zone, which reduces the cost but also increases the risk of data loss in case of an availability zone failure.

- **Intelligent-Tiering**: This storage class automatically moves objects between the standard and IA classes based on changing access patterns and costs, without any performance impact or operational overhead.

- **Glacier**: This storage class is designed for data archiving and long-term retention, with very low storage cost but higher retrieval fees and longer retrieval times.

- **Glacier Deep Archive**: This storage class is similar to Glacier, but with even lower storage cost and longer retrieval times, suitable for data that is rarely accessed and can tolerate hours or days of retrieval latency.

#### S3 Access Control

S3 provides several mechanisms to control access to objects and buckets, including:

- **IAM Policies**: These policies define who can perform specific actions on S3 resources, such as creating a bucket, uploading an object, or deleting a bucket.

- **Bucket Policies**: These policies define who can access a specific bucket and what actions they can perform on it, such as listing objects, reading or writing objects, or deleting objects.

- **Object ACLs**: These access control lists define who can access a specific object and what permissions they have, such as read, write, or delete.

- **Bucket ACLs**: These access control lists define who can access a specific bucket and what permissions they have, such as read or write.

#### S3 Pricing

S3 pricing is based on several factors, including:

- **Storage**: The amount of data stored in S3, measured in gigabytes (GB) or terabytes (TB) per month.

- **Requests**: The number of requests made to S3, such as PUT, GET, or DELETE requests, measured in thousands or millions per month.

- **Data Transfer**: The amount of data transferred out of S3 to the internet or other AWS services, measured in gigabytes or terabytes per month.

- **Storage Management**: The cost of managing S3 storage, such as data retrieval, tagging, or inventory, measured in requests or data scanned per month.

S3 offers a simple and transparent pricing model, with no upfront costs, minimum fees, or long-term commitments. Users only pay for what they use, with different pricing tiers for each storage class and region.

### MapReduce

MapReduce is a programming model for processing large datasets in parallel across a cluster of computers. It has become a popular method for processing big data because it can handle large amounts of data in a scalable and efficient way.

#### How MapReduce Works

MapReduce works by dividing a large dataset into smaller subsets and processing them in parallel across a cluster of computers. The processing of the data is done in two steps: map and reduce.

1. **Map**: The map step takes input data and transforms it into a set of key-value pairs. The mapper function takes the input data and applies a function to it that transforms it into a set of key-value pairs. The key-value pairs are then passed to the next step.

2. **Reduce**: The reduce step takes the key-value pairs generated by the map step and combines them into a smaller set of key-value pairs. The reducer function takes the key-value pairs and applies a function to them that aggregates the data into a smaller set of key-value pairs.

#### Advantages of MapReduce

Some of the advantages of MapReduce are:

1. Scalability: MapReduce is designed to work across a cluster of computers, which makes it scalable for processing large datasets.

2. Fault tolerance: MapReduce is fault-tolerant, which means it can handle failures of nodes in the cluster without losing data.

3. Flexibility: MapReduce can be used with a variety of programming languages and frameworks, which makes it flexible for different types of applications.

4. Efficiency: MapReduce is designed to be efficient for processing large datasets in parallel across a cluster of computers.

#### Hadoop MapReduce

Hadoop MapReduce has two main components:

1. **JobTracker**: The JobTracker is responsible for scheduling and monitoring jobs in the Hadoop cluster. It receives requests for jobs from clients and assigns them to available TaskTrackers.

2. **TaskTracker**: The TaskTracker is responsible for running the map and reduce tasks for a particular job. It receives tasks from the JobTracker and executes them on the node where it is running.

Each namespace is managed by a separate NameNode. This improves the scalability of the cluster by distributing the metadata across multiple NameNodes.

2. **Data Block Federation:** The second level of Hadoop federation is data block federation. In data block federation, the data blocks of the Hadoop cluster are divided into smaller blocks. Each block is managed by a separate DataNode. This improves the scalability of the cluster by distributing the data across multiple DataNodes.

3. **Rack-level Federation:** The third level of Hadoop federation is rack-level federation. In rack-level federation, the DataNodes are grouped into racks. Each rack has a separate network switch. 4. **Cluster-level Federation:** The fourth level of Hadoop federation is cluster-level federation. In cluster-level federation, multiple Hadoop clusters are combined into a single logical cluster.
