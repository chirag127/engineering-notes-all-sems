

## Unit 1 - Introduction To Cloud Computing

1. **Definition:** Cloud computing is the delivery of computing services, including software, storage, and processing power, over the internet. These services are provided by third-party companies and can be accessed from anywhere with an internet connection.

2. **History:** The concept of cloud computing has been around since the 1960s, but it wasn't until the late 2000s that it became widely adopted. The rise of the internet and the availability of high-speed connections made it possible for companies to offer cloud services to consumers and businesses.

3. **Types of Cloud Services:** There are three main types of cloud services: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). IaaS provides virtualized computing resources, such as servers and storage, over the internet. PaaS provides a platform for developers to build and deploy applications. SaaS provides software applications over the internet.

4. **Benefits:** Cloud computing offers several benefits, including cost savings, scalability, and flexibility. By using cloud services, companies can avoid the upfront costs of purchasing and maintaining hardware. Cloud services can also be scaled up or down as needed, providing flexibility for changing business needs.

5. **Challenges:** Despite its benefits, cloud computing also presents several challenges, including security, privacy, and vendor lock-in. Companies must ensure that their data is secure when using cloud services, and they must also be aware of privacy concerns. Additionally, companies must be careful to avoid becoming locked into a particular vendor's cloud services.

6. **Future:** The future of cloud computing is likely to see continued growth and adoption, as well as the development of new technologies and services. The use of artificial intelligence and machine learning in cloud computing is also likely to increase.



### Definition of Cloud

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction .

In simpler terms, cloud computing is the delivery of computing services—including servers, storage, databases, networking, software, analytics, and intelligence—over the Internet (“the cloud”) to offer faster innovation, flexible resources, and economies of scale .

Cloud computing is the on-demand availability of computing resources as services over the internet. It eliminates the need for enterprises to procure, configure, or manage resources themselves, and they only pay for what they use .

Cloud computing is on-demand access, via the internet, to computing resources—applications, servers (physical servers and virtual servers), data storage, development tools, networking capabilities, and more—hosted at a remote data center managed by a cloud services provider (or CSP) .



# Evolution of Cloud Computing

The evolution of cloud computing can be divided into three basic phases:

1. **The Idea Phase**: This phase began in the early 1960s with the emergence of utility and grid computing and lasted until the pre-internet bubble era. Joseph Carl Robnett Licklider was the founder of cloud computing .

2. **Virtualization**: In the 1970s, IBM released an operating system called VM that allowed multiple virtual systems to be run on a single physical system . Virtualization for PC-based systems also started in earnest .

3. **The Cloud is Born**: The most recent development of cloud computing has evolved from Web 2.0 technology, which caters to web applications that facilitate participatory information sharing, interoperability, and user-centered design. Examples of Web 2.0 include wikis, blogs, social networking, and video sharing .

Cloud computing has continued to evolve with new technologies such as containers, serverless computing, and improved cloud security .



### Underlying Principles of Parallel and Distributed Computing

1. The terms parallel computing and distributed computing are used interchangeably .
2. Parallel computing implies a tightly coupled system .
3. Distributed systems refer to a wider class of systems, including those that are tightly coupled .
4. Parallel computing is characterized by homogeneity of components (Uniform Structure) .
5. In systems implementing parallel computing, all the processors share the same memory, communication medium, and network .
6. The processors communicate with each other with the help of shared memory .
7. Distributed systems, on the other hand, have their own memory and processors .
8. Parallel computing is often used in tandem with distributed computing .
9. Parallel computing on a single computer uses multiple processors to process tasks in parallel, whereas distributed parallel computing uses multiple computing devices to process those tasks .
10. Parallel and distributed computing occurs across many different topic areas in computer science, including algorithms, computer architecture, networks, operating systems, and software engineering .

- Elasticity can also refer to the ability to grow or shrink the resources used by a cloud-based application.
- Scalability will prevent you from having to worry about capacity planning and peak engineering.

# Basics of Virtualization

Virtualization is a technology that makes cloud computing possible. It enables the hardware resources of a single computer—processors, memory, storage and more—to be divided into multiple virtual computers, called virtual machines (VMs). This allows for more efficient utilization of physical computer hardware and is the foundation of cloud computing.

Cloud providers set up and maintain their own data centers. They create different virtual environments that use the underlying hardware resources. You can then program your system to access these cloud resources by using APIs.

There are different types of virtualization, including server virtualization, storage virtualization, network virtualization, data virtualization, and application virtualization.

- **Server virtualization** is a process that partitions a physical server into multiple virtual servers.
- **Storage virtualization** involves the pooling of physical storage from multiple network storage devices into what appears to be a single storage device that is managed from a central console.
- **Network virtualization** is the process of combining hardware and software network resources and network functionality into a single, software-based administrative entity, a virtual network.
- **Data virtualization** is the process of abstracting, transforming, federating, and delivering data from disparate sources, in real-time or near-real-time, without the need to copy or move the data.
- **Application virtualization** is the separation of an installation of an application from the client computer that accesses it.

Virtualization changes the hardware-software relations and is one of the foundational elements of cloud computing technology that helps utilize the capabilities of cloud computing to the full. One of the most fundamental uses of OS virtualization is for testing applications on different OS and platforms.



# Types of Virtualization

Virtualization is the creation of a virtual version of something, such as an operating system, a server, a storage device, or network resources. There are several types of virtualization, including:

1. **Hardware Virtualization**: This type of virtualization involves creating a virtual machine that acts like a real computer with an operating system. The software executed on these virtual machines is separated from the underlying hardware resources.

2. **Operating System Virtualization**: This type of virtualization allows multiple operating systems to run on a single physical server. Each operating system runs in its own virtual environment and is isolated from the others.

3. **Server Virtualization**: This type of virtualization involves partitioning a physical server into multiple virtual servers. Each virtual server can run its own operating system and applications.

4. **Storage Virtualization**: This type of virtualization involves pooling physical storage from multiple network storage devices into a single storage device that is managed from a central console.

5. **Network Virtualization**: This type of virtualization involves splitting available bandwidth into independent channels that can be assigned to specific servers or devices in real-time.

These are some of the common types of virtualization used in cloud computing. Each type has its own benefits and can be used to improve the efficiency and flexibility of computing resources.



### Implementation Levels of Virtualization

Virtualization is the creation of a virtual version of something, such as an operating system, a server, a storage device, or network resources. There are several levels of virtualization, including:

1. **Hardware-level virtualization:** This is the virtualization of physical hardware resources, such as CPU, memory, and storage. It allows multiple virtual machines to share the same physical hardware resources, while maintaining isolation between them.

2. **Operating system-level virtualization:** This is the virtualization of an operating system, allowing multiple isolated user-space instances to run on a single operating system kernel. Each instance, known as a container, appears to have its own operating system, but in reality, they all share the same underlying kernel.

3. **Application-level virtualization:** This is the virtualization of an application, allowing it to run in a virtual environment that is isolated from the underlying operating system and hardware. This can be useful for running applications that are not compatible with the host operating system, or for running multiple instances of the same application.

4. **Network virtualization:** This is the virtualization of network resources, such as switches, routers, and firewalls. It allows multiple virtual networks to be created and managed on the same physical network infrastructure.

These are the main levels of virtualization, each providing a different degree of abstraction and isolation. They can be used individually or in combination to achieve the desired level of virtualization for a specific use case.

# Layered Cloud Architecture Design

Layered cloud architecture design is a common approach to designing cloud computing systems. It involves organizing the components of a cloud system into layers, with each layer providing a specific set of services to the layer above it. This approach can help to improve the scalability, maintainability, and flexibility of the system.

The following are some key points to consider when designing a layered cloud architecture:

1. **Identification of layers**: The first step in designing a layered cloud architecture is to identify the different layers that will make up the system. Common layers in a cloud architecture include the infrastructure layer, the platform layer, and the application layer.

2. **Separation of concerns**: Each layer in the architecture should have a well-defined set of responsibilities. This separation of concerns can help to reduce the complexity of the system and make it easier to manage and maintain.

3. **Scalability**: A layered architecture can help to improve the scalability of a cloud system. By separating the system into layers, it is possible to scale each layer independently, allowing the system to handle increasing levels of demand.

4. **Flexibility**: A layered architecture can also provide greater flexibility. By separating the system into layers, it is possible to swap out or update individual layers without affecting the rest of the system.

5. **Maintainability**: A layered architecture can make it easier to maintain and update a cloud system. By organizing the system into layers, it is possible to isolate changes to a specific layer, reducing the risk of unintended consequences.

In summary, a layered cloud architecture design can provide many benefits for a cloud computing system, including improved scalability, flexibility, and maintainability. It is important to carefully consider the design of each layer and the interactions between layers to ensure that the system is able to meet the needs of its users.



# NIST Cloud Computing Reference Architecture

The National Institute for Standard and Technology (NIST) created Special Publication (SP) 500-292, “NIST Cloud Computing Reference Architecture,” in September 2011 to establish a baseline cloud computing architecture . The purpose of this reference architecture is to define services and relationships between cloud service providers, consumers, and other stakeholders .

The NIST Cloud Computing Reference Architecture comprises five “Architectural Components” that can be understood as a way of defining the relationships between the most critical stakeholders, which are consumers and providers .

1. **Cloud Consumer**: A person or organization that maintains a business relationship with, and uses the service from, Cloud Providers .
2. **Cloud Provider**: A person, organization, or entity responsible for making a service available to interested parties .
3. **Cloud Auditor**: A party that can conduct independent assessments of cloud services, information system operations, performance, and security of the cloud implementation .
4. **Cloud Broker**: An entity that manages the use, performance, and delivery of cloud services, and negotiates relationships between Cloud Providers and Cloud Consumers .
5. **Cloud Carrier**: An intermediary that provides connectivity and transport of cloud services from Cloud Providers to Cloud Consumers .

NIST aims to foster cloud computing systems and practices that support interoperability, portability, and security requirements that are appropriate and achievable for important usage scenarios . NIST has also published other cloud computing-related publications, such as the US Government Cloud Computing Technology Roadmap and the NIST Cloud Computing Security Reference Architecture .



# Public, Private and Hybrid Clouds

## Public Cloud
- A public cloud is a type of cloud computing in which a service provider makes resources, such as virtual machines (VMs), applications or storage, available to the general public over the internet.
- Public cloud services may be free or offered on a pay-per-usage model.
- Examples of public clouds include Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform.

## Private Cloud
- A private cloud is a type of cloud computing that delivers similar advantages to public cloud, including scalability and self-service, but through a proprietary architecture.
- Unlike public clouds, which deliver services to multiple organizations, a private cloud is dedicated to the needs and goals of a single organization.
- Private clouds can be managed by the organization itself or by a third-party, and can be hosted either on-premises or in a data center.

## Hybrid Cloud
- A hybrid cloud is a cloud computing environment that uses a mix of on-premises, private cloud and third-party, public cloud services with orchestration between the two platforms.
- By allowing workloads to move between private and public clouds as computing needs and costs change, hybrid cloud gives businesses greater flexibility and more data deployment options.
- Hybrid cloud is particularly valuable for dynamic or highly changeable workloads.

# Cloud Security Challenges

Cloud security is a major concern for organizations that are moving their data and applications to the cloud. Here are some of the challenges that organizations face when it comes to cloud security:

1. **Data breaches**: Data breaches can occur due to various reasons such as weak passwords, lack of encryption, and human error. In the cloud, data breaches can have a significant impact as the data is often stored in a shared environment.

2. **Data loss**: Data loss can occur due to various reasons such as accidental deletion, hardware failure, and natural disasters. In the cloud, data loss can have a significant impact as the data is often stored in a shared environment.

## Unit 5 - Cloud Technologies And Advancements: Hadoop

Hadoop is an open-source software framework for storing and processing large datasets using distributed computing. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

Some key features of Hadoop include:
- **Scalability:** Hadoop can handle petabytes of data and can scale up by adding more machines to the cluster.
- **Fault tolerance:** Hadoop replicates data across multiple machines, so if one machine fails, the data is still available on other machines.
- **Flexibility:** Hadoop can handle structured, semi-structured, and unstructured data, making it suitable for a wide range of applications.
- **Cost-effectiveness:** Hadoop runs on commodity hardware, making it a cost-effective solution for storing and processing large datasets.

Hadoop consists of two main components: the Hadoop Distributed File System (HDFS) and the MapReduce programming model. HDFS is a distributed file system that provides high-throughput access to application data, while MapReduce is a programming model for processing large datasets in parallel.

Hadoop has become a popular platform for big data processing and has been widely adopted by companies in various industries, including finance, healthcare, retail, and telecommunications. Its open-source nature and active community have also contributed to its success, with many organizations contributing to its development and improvement.



### MapReduce

MapReduce is a programming model and an associated implementation for processing and generating large data sets. It is a key component of the Apache Hadoop software framework, which is widely used for distributed data processing.

Here are some key points to note about MapReduce:

1. MapReduce is designed to process large volumes of data in parallel by dividing the work into a set of independent tasks.
2. The MapReduce model consists of two main functions: the Map function and the Reduce function.
3. The Map function takes an input key-value pair and produces a set of intermediate key-value pairs.
4. The Reduce function takes an intermediate key and a set of values associated with that key, and merges the values to produce a smaller set of values.
5. The MapReduce framework takes care of scheduling tasks, monitoring their progress, and re-executing failed tasks.
6. MapReduce is widely used for data processing tasks such as data filtering, data aggregation, and data analysis.
7. MapReduce can be used with a variety of data sources, including structured data in databases, unstructured data in files, and data streams.

- OpenStack is an open-source and free software that is deployed as an Infrastructure as a Service (IaaS) .
- The tools that comprise the OpenStack platform, called "projects," handle the core cloud-computing services of compute, networking, storage, identity, and image services .
- OpenStack is one of the three most active open-source projects in the world and is mostly deployed as infrastructure-as-a-service (IaaS) in both public and private clouds where virtual servers and other resources are made available to users .

# Four Levels of Federation

Federation in the context of cloud computing refers to the integration of multiple cloud services to provide a unified view of data and resources. There are four levels of federation:

1. **Data Federation**: This level involves the integration of data from multiple sources, allowing users to access and analyze data from different cloud services as if it were stored in a single location.

2. **Identity Federation**: This level involves the integration of identity management systems, allowing users to use a single set of login credentials to access multiple cloud services.

3. **Application Federation**: This level involves the integration of applications, allowing users to access and use multiple cloud services through a single interface.

4. **Infrastructure Federation**: This level involves the integration of infrastructure, allowing cloud service providers to share resources and provide a more seamless experience for users.

These four levels of federation provide a framework for understanding the different ways in which cloud services can be integrated to provide a more seamless and unified experience for users. Federation can help to improve the efficiency and effectiveness of cloud computing, and is an important concept in the field of cloud technologies and advancements.



# Federated Services and Applications

Federated services and applications refer to the integration of multiple, disparate systems, services, and applications to provide a unified and seamless user experience. This is achieved through the use of common protocols, standards, and interfaces that allow for the sharing of data and functionality between different systems.

In the context of cloud computing, federated services and applications can provide several benefits, including:

1. Improved scalability: By leveraging the resources of multiple cloud providers, federated services can scale more easily to meet changing demand.

2. Increased reliability: Federated services can provide improved reliability by distributing workloads across multiple cloud providers, reducing the risk of downtime due to a single point of failure.

3. Enhanced flexibility: Federated services can provide greater flexibility by allowing organizations to choose the best cloud provider for each workload, based on factors such as cost, performance, and security.

4. Reduced vendor lock-in: By using federated services, organizations can avoid being locked into a single cloud provider, making it easier to switch providers if needed.

Federated services and applications can be implemented using a variety of technologies and approaches, including service-oriented architecture (SOA), application programming interfaces (APIs), and web services.

In the context of Hadoop and big data, federated services can provide a unified view of data stored across multiple Hadoop clusters, allowing for more efficient data processing and analysis. This can be achieved through the use of technologies such as Apache Hadoop YARN, which provides a resource management and scheduling framework for distributed data processing.

Overall, federated services and applications can provide significant benefits in the context of cloud computing and big data, by enabling the integration of multiple systems and services to provide a more seamless and efficient user experience.
