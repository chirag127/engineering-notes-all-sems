### Batch Normalization

It is used to reduce the internal covariate shift, which is the phenomenon of the distribution of the inputs to a layer of a neural network changing during training. This can lead to slower learning and poorer generalization. 

Batch normalization works by normalizing each batch of inputs before passing it through the layer. This means that each input is normalized with respect to the mean and standard deviation of the batch. This helps to reduce the internal covariate shift and leads to faster learning and better generalization. 

Batch normalization also has the benefit of making the network more robust to changes in the input distribution. This is because the normalization is done with respect to the batch, rather than the entire dataset. This makes the network more resilient to changes in the input distribution, as the normalization is done with respect to the batch, rather than the entire dataset.

They are used to transform input data into a different coordinate space, which can be used to improve the performance of deep learning models. STNs are composed of three components: a localization network, a grid generator, and a sampler.

* **Localization Network**: This component is responsible for learning the parameters of the transformation. It takes the input data and produces a set of parameters that define the transformation.

* **Grid Generator**: This component takes the parameters from the localization network and generates a grid, which is used to sample the input data.

* **Sampler**: This component takes the grid generated by the grid generator and samples the input data, producing the transformed output.

STNs can be used in a variety of applications, including image classification, object detection, and segmentation.
