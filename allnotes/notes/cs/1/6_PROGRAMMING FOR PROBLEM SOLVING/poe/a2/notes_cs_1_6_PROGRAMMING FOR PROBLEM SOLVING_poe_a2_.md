## Unit 1 - Introduction to Components of a Computer System: Memory, Processor, I/O Devices, Storage, Operating System, Concept of Assembler, Compiler, Interpreter, Loader and Linker.

**Memory:** Stores data and instructions temporarily for processing by CPU. Types: RAM, ROM, Cache Memory.

**Processor (CPU):** Executes program instructions. Performs basic arithmetic, logical, and control operations. Consists of Control Unit and ALU.

**Input/Output (I/O) Devices:** Used to input data and instructions into computer and output the results. Examples: Keyboard, Mouse, Printer, Monitor, etc.

**Storage:** Used to store data and instructions permanently. Examples: Hard Drive, SSD, Pen Drive, etc.

**Operating System:** System software that acts as an interface between user and the hardware. Performs tasks like file management, memory management, process management, handling I/O operations, etc. Examples: Windows, Linux, macOS, etc.

**Assembler:** Converts assembly language programs into machine language instructions.

**Compiler:** Converts high-level language programs into machine language instructions.

**Interpreter:** Executes instructions of a high-level language program line by line at a time.

**Loader:** Loads the machine language instructions into memory and prepares the program for execution.

**Linker:** Combines two or more object modules and resolves references between them to generate an executable file.

### Idea of Algorithm: Representation of Algorithm, Flowchart, Pseudo Code with Examples, From Algorithms to Programs, Source Code.

1. Algorithm: A step-by-step procedure to solve a problem or achieve some goal is called an algorithm. It is a finite set of instructions that, when executed, accomplishes a task. Algorithms are the basis for all computer programs.

2. Representation of Algorithm: An algorithm can be represented in many ways, such as:
- Words: Written in plain English sentences.
- Pseudocode: Combination of English and programming language syntax.
- Flowcharts: Diagrams that use standard symbols to represent steps in an algorithm.
- Structured English: Uses standard keywords and indentation to show steps.

3. Flowchart: A flowchart is a diagram that illustrates the sequence of steps in an algorithm. It uses standard symbols to represent different types of steps. The most common symbols are:
- Oval: Start/End
- Rectangle: Process/Task
- Diamond: Decision
- Arrow: Flow of steps

4. Pseudo Code: Pseudo code is a simple way to describe the steps of an algorithm in a programming language-independent way. It uses structure and keywords from a programming language but in plain English terms to outline the logic of an algorithm. It include sequence, decision making, and repetition steps.

5. From Algorithms to Programs: Once an algorithm is designed/developed, it forms the basis for writing computer programs in a programming language. The steps in the algorithm are translated into programming language statements to generate the source code which is compiled and executed to solve the problem. The programming language used depends on the type of application and hardware platform.

6. Source Code: The programming instructions written in a programming language are called source code. The source code is converted into machine language by a compiler to create an executable program. The source code allows programmers to write instructions for a computer in a simpler, more human-readable programming language.

- Associativity - The direction in which operators of the same precedence are evaluated

### Conditional Branching: Applying if and Switch Statements, Nesting if and Else and Switch

1. If Statement: The if statement executes a block of code only if a specified condition is true.

Syntax:
if (condition) {
  // block of code to be executed if the condition is true
}

2. Else Statement: The else statement executes a block of code if the same condition is false.

Syntax:
if (condition) {
  // block of code to be executed if the condition is true
} else {
  // block of code to be executed if the condition is false
}

3. Nesting If and Else: You can nest if statements within if statements to create complex logical tests. The inner if statement is only executed if its condition is true and the outer if statement's condition is also true.

Syntax:
if (outer condition) {
  if (inner condition) {
    // run this code only if both conditions are true
  }
}

4. Switch Statement: A switch statement allows a program to evaluate an expression and execute code based on the value of the expression. It's typically used to replace multiple if statements.

Syntax:
switch (expression) {
  case x:
    // code block to be executed if the expression matches x
    break;
  case y:
    // code block to be executed if the expression matches y
    break;
  default:
    // code block to be executed if the expression matches none of the cases
}

The break statements are important to stop the switch from continuing to check cases.

## Unit 3 - Iteration and Loops: Use of While, do While and for Loops, Multiple Loop Variables, Use of Break , Goto and Continue Statements.

1. While Loop: While loop executes a block of statements repeatedly until a given condition is satisfied. The loop condition is tested before executing the loop body.
Syntax: while (condition) { loop body }

2. do-while Loop: do-while loop is similar to while loop but with one key difference i.e. the loop condition is tested after executing the loop body. Therefore, the loop body is executed at least once.
Syntax: do { loop body } while (condition);

3. for Loop: for loop is used to repeat a block of statements for a specified number of times. It consists of 3 parts: initialization, condition and increment/decrement.
Syntax: for (initialization; condition; increment/decrement) { loop body }

4. Multiple Loop Variables: We can use multiple loop variables in a for loop to achieve a multi-dimensional iteration.
Syntax: for (var1 = x1, var2 = x2; condition; var1++, var2++) { loop body }

5. break Statement: break statement is used to exit from a loop immediately. It breaks out of the nearest enclosing loop.
Syntax: break;

6. continue Statement: continue statement is used to skip the current block, and return control back to the "top" of the loop.
Syntax: continue;

7. goto Statement: goto statement is used to alter the normal sequence of execution by transferring control to a specified label.
Syntax: goto label;

### Arrays:

Array Notation and Representation:

- An array is a collection of elements of the same type placed in contiguous memory locations that can be individually accessed by indexing into the array.
- Array notation: Data type name[size]
- The size can be a constant or variable.
- The index of the first element is 0.

Manipulating Array Elements:

- Elements are accessed using the indexing operator [index].
- The index is an integer that specifies the position of the element in the array.
- Array elements can be assigned and accessed in the same way as simple variables.

Using Multi Dimensional Arrays:

- Arrays can have more than one dimension.
- Declaration: data_type name[size1][size2]...[sizeN]
- Elements are accessed using multiple indices.
- The index of the first element is (0,0,...0).
- The rightmost index varies the fastest.

Character Arrays and Strings:

- A character array is an array of characters.
- A string is a character array with a null terminating character '\0' at the end.
- The null terminator is not included when displaying the string.
- Strings can be input/output and manipulated like arrays.

### Basic of searching and Sorting Algorithms:

Searching Algorithms:

- Linear Search: Scans each element of the list sequentially until the desired element is found. Time complexity: O(n).
- Binary Search: Works on sorted arrays/lists. Divides the list in half and checks which half contains the element. Time complexity: O(log n).

Sorting Algorithms:

- Bubble Sort: Comparisons and swaps adjacent elements if out of order. Time complexity: O(n2).
- Insertion Sort: Inserts each element into the correct position in the sorted list. Time complexity: O(n2).
- Selection Sort: Finds the minimum element and places it at the beginning. Repeats until the list is sorted. Time complexity: O(n2).

## Unit 5 - Pointers: Introduction, Declaration, Applications

1. Introduction to Pointers
- Pointer is a variable that stores the address of another variable.
- Declared using * symbol. For example, int *ptr;
- Stores the address of a variable of the same data type. For example, ptr can store address of an int variable.
- Dereferencing operator * is used to access the value at the address stored in the pointer. For example, *ptr accesses the value at the address stored in ptr.

2. Declaration and Applications of Pointers
- Pointers allow passing addresses to functions which improves efficiency and enables call by reference.
- Used to create complex data structures like linked lists, trees, graphs, etc.
- Used in heap (dynamic) memory allocation using malloc(), calloc(), realloc(), free().
- Used to point to memory locations in arrays which enables efficient array traversal and manipulation.

3. Introduction to Dynamic Memory Allocation
- The amount of memory allocated to variables in stack is fixed.
- Dynamic memory allocation refers to allocating memory at run time on the heap which can grow and shrink as required.
- Commonly used functions are:
› malloc() - Allocates memory
› calloc() - Allocates and initializes memory to 0
› realloc() - Resizes previously allocated memory
› free() - Deallocates memory

### File Handling: File I/O Functions, Standard C Preprocessors, Defining and Calling Macros and Command-Line Arguments.

File I/O Functions:

- fopen(): Opens a file and returns a file pointer.
- fclose(): Closes an open file.
- fgetc(): Reads a character from a file.
- fputc(): Writes a character to a file.
- fgets(): Reads a string from a file.
- fputs(): Writes a string to a file.
- fread(): Reads blocks of data from a file.
- fwrite(): Writes blocks of data to a file.

Standard C Preprocessors:

- #include: Includes header files.
- #define: Defines macros.
- #ifdef: Checks if a macro is defined.
- #ifndef: Checks if a macro is not defined.
- #if: Allows sections of code to be included/excluded depending on conditions.
- #else: The alternative for #if.
- #endif: Ends preprocessor conditional.

Defining and Calling Macros:

- Macros are defined using #define.
- A macro is called/used by just using its name.
- Macros are replaced with their definitions wherever they are called/used.
- Macros can take arguments.
- Macros are mainly used for conditional compilation and inlining code.

Command-Line Arguments:

- Command-line arguments are parameters passed to a program on the command line when it is executed.
- The program can access the command-line arguments through main() method parameters.
- The first argument is always the name of the program.
- The argc parameter holds the number of command-line arguments.
- The argv parameter is an array of character pointers holding the actual arguments.
- Command-line arguments are useful to pass input to programs or control their behavior.
