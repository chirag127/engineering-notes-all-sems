- Some types of relations:
-- Function - Every element in the first set is connected to exactly one element in the second set.
-- One-to-one - No two distinct elements in the first set are connected to the same element in the second set.
-- Onto - Every element in the second set is connected to at least one element in the first set.
-- Bijective - A relation that is both one-to-one and onto.

-- Reflexive - Every element is connected to itself (a, a)

-- Antisymmetric - Two distinct elements cannot be connected to each other

### Mathematical Induction for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Mathematical Induction is a method of proof that is used to establish that a given statement is true for all natural numbers.
2. It involves two steps:
- Basis Step: Proving that the statement is true for the first natural number (i.e. n = 1)
- Induction Step: Assuming that the statement is true for some arbitrary natural number n, and then proving that it must also be true for n + 1.
3. If both the Basis Step and Induction Step can be proven, then the statement is true for all natural numbers.
4. Example: Prove that 1 + 2 + 3 + ... + n = n(n+1)/2 for all natural numbers n.
- Basis Step: The statement is true for n = 1. 1 = 1(1+1)/2
- Induction Step: Assume the statement is true for some n. Then, 1 + 2 + ... + n + (n + 1) = (n + 1)(n + 2)/2. Hence, if true for some n, then also true for n + 1.
- Therefore, by Mathematical Induction, the statement is true for all natural numbers n.

### Lagrange's theorem

* Lagrange's theorem states that if G is a finite group and H is a subgroup of G, then the order of H divides the order of G.
* In other words, if n is the order of G and h is the order of H, then h must divide n.
* Proof: Let g1, g2, ..., gn be a list of representatives of the left cosets of H in G. Then n = |G| and each gi is a member of G. Therefore, gih is also a member of G for each i. But gih = gjhk for some j, k and h. Since G is finite, there must be repeats in the list g1h, g2h, ..., gnh. Thus h divides n.
* Consequences: No subgroup of a finite cyclic group can have order greater than the group order. A nontrivial proper subgroup of a finite group cannot have the same order as the group. If G is a nontrivial finite group and p is a prime divisor of |G|, then G has an element of order p.
* The theorem does not hold for infinite groups - the integers under addition, for example, have a subgroup (the even integers) whose order does not divide the order of the group.

### Isomorphism and Homeomorphism of graphs

1. Isomorphism: Two graphs G1(V1, E1) and G2(V2, E2) are said to be isomorphic if there is a one-to-one correspondence between their vertices such that if two vertices are adjacent in G1 then their corresponding vertices are also adjacent in G2, and vice-versa.
2. Homeomorphism: Two graphs G1(V1, E1) and G2(V2, E2) are said to be homeomorphic if their vertex sets can be put into one-to-one correspondence in such a way that incidence is preserved, i.e. {u,v} is an edge of G1 if and only if {f(u),f(v)} is an edge of G2, where f is the mapping between V1 and V2.
3. Conditions for isomorphism:
    1. The number of vertices must be same in both graphs.
    2. The number of edges must be same in both graphs.
    3. The degree of each vertex must be same in both graphs.
    4. The adjacency of vertices must be preserved.
4. Conditions for homeomorphism:
    1. The incidence relations must be preserved.
5. Differences between isomorphism and homeomorphism:
    - Isomorphism requires vertex correspondences as well as edge correspondences whereas homeomorphism requires only incidence (edge) correspondences.
    - Isomorphic graphs are homeomorphic but the converse is not true. Two non-isomorphic graphs can be homeomorphic.
    - Isomorphism is an equivalence relation but homeomorphism is not.

### Pigeonhole Principle

* The Pigeonhole Principle states that if n objects are put into m pigeonholes, with n > m, then at least one pigeonhole must contain more than one object.
* This is a counting argument that can be used to prove that a certain situation is impossible. It is a useful way to show that a system with limited resources cannot accommodate all possible demands.
* Example: If 10 letters are mailed to 8 recipients, then at least one recipient will receive at least 2 letters. There are more letters (10) than recipients (8), so the pigeonholes (recipients) cannot accommodate all letters.
* The Pigeonhole Principle can be generalized to any types of objects and pigeonholes. The key is simply that there must be more objects than pigeonholes. The Principle indicates that some pigeonhole ends up with multiple objects but does not specify which one(s). It only proves that such a situation must exist.
* The Pigeonhole Principle is a useful technique for proving statements of the form "such-and-such cannot be." It is often easy to apply but limited in its power. Stronger theorems are needed to prove statements of the form "such-and-such must be."
