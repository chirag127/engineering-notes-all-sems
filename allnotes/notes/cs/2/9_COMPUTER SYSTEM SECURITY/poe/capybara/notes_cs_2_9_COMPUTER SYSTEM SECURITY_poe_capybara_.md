### Overview
Computer system security is the practice of protecting computer systems and networks from unauthorized access, theft or damage to hardware, software or electronic data. It involves using a combination of hardware, software, and network security measures to safeguard computer systems from various cyber threats.

### Importance of Computer System Security
Computer system security is critical in protecting confidential data and intellectual property, ensuring business continuity, and maintaining customer trust. Failure to protect computer systems can result in data breaches, financial losses, and reputational damage. 

### Types of Cyber Threats
There are many types of cyber threats that can harm computer systems. Some of the most common ones include:

- Malware: Malware is software that is intended to harm computer systems, steal data or gain unauthorized access.
- Phishing: Phishing attacks are designed to trick users into providing sensitive information such as login credentials or credit card numbers.
- Denial of Service (DoS) attacks: DoS attacks are designed to overwhelm computer systems with traffic, making them unavailable to users.
- Man-in-the-middle (MitM) attacks: MitM attacks intercept and alter communications between two parties, allowing attackers to steal sensitive information.

### Security Measures
There are several security measures that can be used to protect computer systems:

- Firewalls: Firewalls are network security devices that control the flow of traffic between computer networks.
- Antivirus software: Antivirus software is designed to detect and remove malware from computer systems.
- Encryption: Encryption is the process of converting data into a code to prevent unauthorized access.
- Access controls: Access controls limit the access of users to computer systems and networks based on their identity and role.

### Conclusion
Computer system security is essential in protecting against cyber threats and ensuring the confidentiality, integrity, and availability of data. By implementing appropriate security measures, organizations can reduce the risk of cyber attacks and protect their computer systems and networks.

### Hijacking & Defense

Hijacking is a type of attack where an attacker gains control over an ongoing session between two parties. The attacker can intercept, manipulate, or steal data transmitted between the two parties. In the context of computer system security, hijacking refers to the unauthorized access to a user's computer or network.

Here are some common types of hijacking attacks:

- **Session hijacking**: This attack involves stealing the session ID of an authenticated user to gain access to their account. Once the attacker has the session ID, they can impersonate the user and perform actions on their behalf.
- **Man-in-the-middle (MitM) attack**: In this attack, the attacker intercepts the communication between two parties and can read, modify, or inject new data into the communication stream.
- **DNS hijacking**: In this attack, the attacker modifies the DNS server settings of a victim's computer or network, redirecting them to a malicious website or server.

To defend against hijacking attacks, here are some best practices:

- **Use strong authentication mechanisms**: Implement two-factor authentication or multi-factor authentication to prevent unauthorized access to user accounts.
- **Encrypt communication channels**: Use protocols like HTTPS or SSL/TLS to encrypt traffic between the client and server, preventing attackers from intercepting and reading the data.
- **Implement secure coding practices**: Developers should follow secure coding practices to prevent vulnerabilities that attackers can exploit to hijack user sessions.
- **Monitor network traffic**: Network administrators should monitor network traffic to detect any suspicious activity, such as unusual network connections or data transfers.
- **Regularly update software**: Keep software up-to-date to patch any vulnerabilities that attackers can use to hijack user sessions.
- **Use a virtual private network (VPN)**: A VPN can encrypt all traffic between the client and server, preventing attackers from intercepting and reading the data.

In conclusion, hijacking attacks can have serious consequences for users and organizations. Implementing strong authentication mechanisms, encrypting communication channels, and following secure coding practices can help defend against hijacking attacks. Regularly monitoring network traffic and keeping software up-to-date are also important to prevent hijacking attacks.



### Control Hijacking

Control hijacking, also known as code injection, is a type of computer security attack that involves taking control of a computer system by exploiting a vulnerability in its code. This type of attack is commonly used to gain access to sensitive information, such as passwords or financial data, or to take control of the system for malicious purposes.

Here are some important points to keep in mind when learning about control hijacking:

- Control hijacking attacks typically involve exploiting a buffer overflow vulnerability in a program's code. This vulnerability occurs when a program tries to write more data to a buffer than it can hold, causing the excess data to overwrite adjacent memory locations.
- By carefully crafting the data that overwrites the adjacent memory locations, an attacker can modify the program's execution flow to take control of the system.
- There are several techniques that attackers can use to achieve control hijacking, including stack-based attacks, heap-based attacks, and return-oriented programming attacks.
- Stack-based attacks involve overwriting the return address of a function in the program's call stack with the address of the attacker's code. When the function returns, the program jumps to the attacker's code instead of the expected location.
- Heap-based attacks involve exploiting vulnerabilities in the program's heap memory, which is used for dynamic memory allocation. By manipulating the heap, an attacker can modify the program's execution flow.
- Return-oriented programming attacks involve chaining together small pieces of code, known as gadgets, that already exist in the program's memory. By jumping to these gadgets in a specific order, an attacker can execute arbitrary code without injecting any new code into the program.
- There are several defensive measures that can be taken to protect against control hijacking attacks, including using stack canaries, data execution prevention, address space layout randomization, and control flow integrity. These techniques make it more difficult for attackers to exploit vulnerabilities in the program's code.

By understanding the techniques used in control hijacking attacks and the defensive measures that can be taken to prevent them, computer security professionals can better protect computer systems from these types of attacks.

### Confinement Principle

The Confinement Principle is a fundamental principle of computer system security. The principle states that a process should be able to access only the resources that are necessary for its execution and nothing else. The principle is also known as the Principle of Least Privilege.

Following are the key points related to the Confinement Principle:

- The Confinement Principle is used to prevent unauthorized access to resources and to limit the damage caused by a security breach.
- The principle states that a process should be confined to its own resources and should not be able to access resources that belong to other processes.
- The principle also states that a process should only be given the minimum set of privileges necessary to perform its task.
- Confinement can be achieved through various mechanisms such as access control lists, capabilities, and virtualization.
- Access control lists are used to restrict access to resources based on the identity of the user or the group to which the user belongs.
- Capabilities are used to restrict access to resources based on the capabilities of the process.
- Virtualization is used to create a virtual environment for the process, which is isolated from other processes and the underlying system.
- The Confinement Principle is closely related to the principle of Separation of Duties, which states that no single user or process should have complete control over a system or its resources.
- The Confinement Principle is also related to the principle of Least Common Mechanism, which states that the mechanisms used to provide security should be as simple and general as possible to minimize the risk of a security breach.

In conclusion, the Confinement Principle is a critical principle of computer system security that helps prevent unauthorized access and limits the damage caused by a security breach. It is achieved by restricting access to resources and by confining processes to their own resources. The principle is closely related to other principles such as Separation of Duties and Least Common Mechanism.

## Unit 4 - Basic cryptography

3. **Key**: A key is a piece of information used in the encryption and decryption process. The key is what allows the sender and recipient of a message to communicate securely.

### IP Security

IP Security (IPSec) is a protocol suite used for securing Internet Protocol (IP) communications. It is commonly used to create Virtual Private Networks (VPNs) to protect data in transit over untrusted networks.

#### Benefits of IPSec

- Confidentiality: IPSec provides encryption to protect data from unauthorized access.
- Authentication: IPSec ensures that data is sent from a trusted source and has not been modified in transit.
- Integrity: IPSec guarantees that data has not been tampered with during transmission.
- Anti-replay Protection: IPSec prevents an attacker from intercepting and resending packets to gain unauthorized access to the network.

#### IPSec Components

IPSec is comprised of the following components:

- Security Associations (SA): SAs define the security parameters for IPSec communication, such as encryption algorithms, keys, and authentication methods.
- Authentication Header (AH): AH provides data integrity, authentication, and anti-replay protection for IP packets.
- Encapsulating Security Payload (ESP): ESP provides confidentiality, data integrity, and authentication for IP packets.
- Internet Key Exchange (IKE): IKE is used to establish and manage SAs between IPSec peers.

#### IPSec Modes

IPSec can operate in two modes:

- Transport Mode: In transport mode, only the IP payload is encrypted and authenticated. The IP header is left intact, which allows for faster processing but provides less security.
- Tunnel Mode: In tunnel mode, both the IP header and payload are encrypted and authenticated. The entire IP packet is encapsulated within another IP packet, which provides more security but can result in slower processing.

#### IPSec Implementation

IPSec can be implemented in hardware or software. Hardware-based IPSec is faster and more secure than software-based IPSec, but it can be more expensive. Software-based IPSec is more flexible and easier to deploy, but it can be slower and less secure.

#### IPSec Limitations

- IPSec can add overhead to IP packets, which can result in slower network performance.
- IPSec does not protect against attacks that occur within the trusted network.
- IPSec requires additional configuration and management, which can be complex and time-consuming.

Overall, IPSec is an effective protocol suite for securing IP communications over untrusted networks. It provides a range of security benefits, but also has some limitations that should be considered when implementing it.

### Routing Security

Routing security is a crucial aspect of computer system security, especially in the context of internet infrastructure. This is because routing is the process of directing network traffic, and any errors or malicious activities could have severe consequences. Here are some important points to keep in mind regarding routing security:

- **BGP Hijacking:** Border Gateway Protocol (BGP) hijacking is a type of attack where an attacker takes control of the BGP routing table and directs traffic to a different destination. This can result in traffic interception, redirection, and even complete network outages. To prevent this, it is important to ensure that BGP routers are secure and that routing updates are authenticated.

- **Route Filtering:** Route filtering is a technique used to prevent unauthorized access to the network. It involves blocking specific IP addresses, subnets or autonomous systems from being advertised or received. This can help prevent attacks such as Distributed Denial of Service (DDoS) and BGP hijacking.

- **Route Validation:** Route validation is a process of verifying the authenticity of routing information. This involves checking if the advertised routes are authorized and if the originating AS is legitimate. Route validation can help prevent BGP hijacking and other types of attacks.

- **Route Origin Validation (ROV):** ROV is a technique used to validate the origin of a route. It involves verifying that the AS that originated the route actually has the authority to do so. This can help prevent route leaks and false announcements.

- **BGPsec:** BGPsec is a security protocol for BGP that provides cryptographic protection for routing information. It is designed to prevent BGP hijacking and other types of attacks by ensuring that routing updates are authenticated and verified. BGPsec is still being developed and deployed, but it is expected to become a standard in the near future.

In conclusion, routing security is an important aspect of computer system security, especially in the context of internet infrastructure. BGP hijacking, route filtering, route validation, ROV, and BGPsec are all important techniques for ensuring routing security. By implementing these techniques, network administrators can help prevent attacks and ensure the integrity of their networks.



### DNS Revisited

DNS (Domain Name System) is a fundamental component of the internet infrastructure. In this unit, we will revisit DNS and its importance in computer system security. Here are some important points to keep in mind:

- DNS is a hierarchical naming system that maps domain names to IP addresses. It allows users to access websites and other internet resources using easy-to-remember domain names instead of numeric IP addresses.
- DNS operates on a client-server model. When a user types in a domain name, the client sends a DNS query to a DNS server, which in turn responds with the corresponding IP address.
- DNS servers can be either authoritative or recursive. Authoritative DNS servers maintain information about a specific domain, while recursive DNS servers perform DNS queries on behalf of clients.
- DNS security is essential to prevent attacks such as DNS spoofing, cache poisoning, and DNS hijacking. These attacks can redirect users to malicious websites or intercept their internet traffic, compromising their privacy and security.
- DNSSEC (DNS Security Extensions) is a set of protocols that add security to DNS transactions. It uses digital signatures to authenticate DNS data and prevent DNS spoofing and other types of attacks.
- DNS over HTTPS (DoH) and DNS over TLS (DoT) are newer protocols that encrypt DNS traffic and protect against eavesdropping and tampering. These protocols are becoming more popular as internet users become more concerned about privacy and security.
- DNS can also be used as a tool for cyberattacks, such as DNS amplification attacks and DNS tunneling. Therefore, it is crucial to implement measures such as firewalls and intrusion detection systems to protect against these threats.

In summary, DNS is a critical component of the internet infrastructure, and its security is essential to ensure the privacy and security of internet users. Understanding the basics of DNS and its vulnerabilities is crucial for computer system security professionals.

### Link layer connectivity and TCP IP connectivity

In the context of computer system security, it is important to understand the concepts of link layer connectivity and TCP IP connectivity. Here are some key points to help you understand these concepts:

#### Link layer connectivity

- The link layer is the lowest layer of the OSI (Open Systems Interconnection) model.
- At the link layer, data is transmitted between nodes on the same physical network segment.
- Link layer connectivity is established through the use of MAC (Media Access Control) addresses.
- MAC addresses are unique identifiers assigned to network interfaces. They are used to identify the source and destination of data packets at the link layer.
- Link layer protocols include Ethernet, Wi-Fi, and Bluetooth.

#### TCP IP connectivity

- TCP (Transmission Control Protocol) and IP (Internet Protocol) are two of the most important protocols in the TCP/IP protocol suite.
- TCP provides reliable, ordered, and error-checked delivery of data between applications running on hosts communicating over an IP network.
- IP provides routing and addressing functions that enable data to be sent from one network to another.
- TCP/IP connectivity is established through the use of IP addresses.
- IP addresses are unique identifiers assigned to hosts on a network. They are used to identify the source and destination of data packets at the network layer.
- TCP/IP protocols include TCP, IP, UDP (User Datagram Protocol), and ICMP (Internet Control Message Protocol).

Understanding link layer and TCP/IP connectivity is important in computer system security because it enables network administrators to identify and troubleshoot network issues that could potentially compromise the security of the system. By analyzing network traffic at the link layer and TCP/IP layer, administrators can detect and prevent unauthorized access, data theft, and other security threats.



### Packet Filtering Firewall

A packet filtering firewall is a type of firewall that examines each incoming and outgoing packet and allows or denies it based on a set of predefined rules.

#### How Packet Filtering Firewall Works

Packet filtering firewall works by examining each packet and comparing it to a set of rules to determine whether to allow or deny it. The rules are typically based on the packet's source and destination addresses, ports, and protocols.

#### Advantages of Packet Filtering Firewall

- Easy to implement and manage
- Low cost
- Can provide basic protection against network attacks

#### Disadvantages of Packet Filtering Firewall

- Limited protection against sophisticated attacks
- Cannot inspect the contents of packets
- Susceptible to IP spoofing attacks

#### Types of Packet Filtering Firewall

- Stateful Packet Filtering Firewall: This type of firewall keeps track of the state of network connections and allows only packets that belong to established connections.
- Stateless Packet Filtering Firewall: This type of firewall examines each packet in isolation and does not maintain any state information.

#### Conclusion

Packet filtering firewall is a basic type of firewall that provides some level of protection against network attacks. However, it has its limitations and is not suitable for protecting against sophisticated attacks. It is important to use additional security measures, such as intrusion detection and prevention systems, in conjunction with packet filtering firewalls to provide comprehensive network security.



### Intrusion Detection

Intrusion detection is the process of identifying and responding to malicious activity that attempts to compromise the confidentiality, integrity, or availability of a computer system or network. It is a critical component of computer system security and is essential for protecting against cyber attacks.

Here are some key points to understand about intrusion detection:

- Intrusion detection can be classified into two types: Host-Based Intrusion Detection Systems (HIDS) and Network-Based Intrusion Detection Systems (NIDS). HIDS monitors activities on a single host, while NIDS monitors network traffic for signs of intrusion.
- Intrusion detection systems use a variety of techniques to identify potential intrusions, including signature-based detection, anomaly-based detection, and rule-based detection.
- Signature-based detection involves comparing known attack patterns or signatures to the incoming data to identify a match. Anomaly-based detection looks for unusual behavior or patterns that may indicate an attack. Rule-based detection uses predefined rules to determine if a particular event is an attack or not.
- Intrusion detection systems can be configured to operate in different modes, including detection-only mode, detection and response mode, and prevention mode. In detection-only mode, the system only detects and reports intrusions. In detection and response mode, the system detects and responds to intrusions by taking action, such as blocking network traffic or terminating processes. In prevention mode, the system actively blocks potential intrusions before they can cause harm.
- Intrusion detection systems generate alerts when potential intrusions are detected. These alerts can be sent to system administrators, security personnel, or other stakeholders for further investigation and response.
- Intrusion detection systems must be continually updated and maintained to remain effective. This includes updating the system with the latest signatures and rules, monitoring system logs for anomalies, and conducting regular audits and assessments.

In conclusion, intrusion detection is a critical component of computer system security that helps to protect against cyber attacks. By understanding the different types, techniques, and modes of intrusion detection, you can better prepare your computer systems and networks to defend against potential threats.
