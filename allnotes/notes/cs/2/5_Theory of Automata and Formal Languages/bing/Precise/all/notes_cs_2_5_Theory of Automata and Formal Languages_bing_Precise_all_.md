# Halting Problem

The halting problem is a decision problem in computer science and mathematics. It asks whether, given a program and an input, the program will eventually halt (finish) or run forever.

- The halting problem is undecidable, meaning that there is no algorithm that can determine, for all possible program-input pairs, whether the program halts on that input or runs forever.
- This result was first proved by Alan Turing in 1936, and is a fundamental result in the theory of computation.
- The proof of the undecidability of the halting problem is done by contradiction, using a technique called diagonalization.
