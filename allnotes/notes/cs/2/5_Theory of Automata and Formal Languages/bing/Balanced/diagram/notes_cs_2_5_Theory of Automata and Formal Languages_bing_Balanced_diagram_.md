

## Unit 1 - Basic Concepts and Automata Theory

- This unit introduces the basic concepts and terminology of formal languages, grammars, and automata theory, which are the foundations of theoretical computer science and compiler design.
- Formal languages are sets of strings that are generated by some rules or patterns. They can be used to model natural languages, programming languages, mathematical expressions, and other symbolic systems.
- Grammars are formal systems that specify how to generate strings in a language. They consist of a set of symbols (terminals and non-terminals), a start symbol, and a set of production rules that describe how to replace non-terminals with other symbols.
- Automata are abstract machines that can recognize or accept strings in a language. They have a finite number of states, a set of input symbols, a transition function that defines how to move from one state to another, and a set of final or accepting states.
- There are different types of languages, grammars, and automata, depending on their expressive power and complexity. The most common ones are:
  - Regular languages, which can be generated by regular expressions or regular grammars, and recognized by finite automata (deterministic or non-deterministic) or regular expressions.
  - Context-free languages, which can be generated by context-free grammars, and recognized by pushdown automata or context-free grammars.
  - Context-sensitive languages, which can be generated by context-sensitive grammars or linear bounded automata, and recognized by linear bounded automata or context-sensitive grammars.
  - Recursively enumerable languages, which can be generated by unrestricted grammars or Turing machines, and recognized by Turing machines or unrestricted grammars.
- There are also some important properties and relations among languages, grammars, and automata, such as:
  - Closure properties, which state whether the union, intersection, complement, concatenation, or Kleene star of two languages of the same type is also a language of that type.
  - Decision problems, which ask whether a given string belongs to a language, whether a language is empty, finite, or infinite, whether two languages are equal, or whether a language is regular, context-free, context-sensitive, or recursively enumerable.
  - Equivalence and conversion, which show how to transform one type of grammar or automaton into another type that generates or recognizes the same language.
  - Hierarchy and inclusion, which compare the expressive power and complexity of different types of languages, grammars, and automata, and show that some types are proper subsets of others. For example, regular languages are a proper subset of context-free languages, which are a proper subset of context-sensitive languages, which are a proper subset of recursively enumerable languages.



### Introduction to Theory of Computation

- Theory of computation (TOC) is a branch of computer science that is concerned with how problems can be solved using algorithms and how efficiently they can be solved.
- TOC includes the fundamental mathematical properties of computer hardware, software and their applications.
- TOC deals with what problems can be solved on a model of computation, using an algorithm, how efficiently they can be solved or to what degree (e.g., approximate solutions versus precise ones).
- A model of computation is an abstract representation of a computing device that defines its capabilities and limitations.
- Some examples of models of computation are Turing machines, finite automata, pushdown automata, and lambda calculus.
- TOC also studies the decidability and undecidability of problems, which means whether there exists an algorithm that can always give a correct answer for any input or not.
- TOC also studies the complexity of problems, which means how much time and space are required to solve them using an algorithm.
- TOC also studies the hierarchy of problems, which means how problems can be classified into different classes based on their complexity and decidability.
- Some examples of complexity classes are P, NP, NP-complete, NP-hard, and co-NP.
- TOC also studies the reducibility of problems, which means how problems can be transformed into other problems that are easier or harder to solve.
- TOC also studies the recursive function theory, which means how functions can be defined and computed using recursion.
- TOC also studies the oracles, which means hypothetical devices that can answer some undecidable or intractable problems in a single step.

- Computability theory also investigates the properties of different models of computation, such as Turing machines, recursive functions, lambda calculus, and cellular automata .
- Some of the main questions that computability theory tries to answer are:
  - What are the fundamental capabilities and limitations of computers and algorithms?
  - What kinds of problems can be solved by computation and what kinds cannot?

  - How can we measure the complexity and efficiency of computation?
  - What are the logical and philosophical implications of computability and incomputability?
- Some of the main results and concepts of computability theory are:
  - The Church-Turing thesis, which states that any effective procedure can be simulated by a Turing machine .
  - The halting problem, which is the problem of deciding whether a given Turing machine will ever stop on a given input. The halting problem is undecidable, meaning that there is no algorithm that can solve it for all cases .
  - The notion of Turing degree, which is a measure of the relative computability of sets of natural numbers. Two sets have the same Turing degree if they are computably equivalent, meaning that each one can be computed from the other by a Turing machine.
  - The notion of reducibility, which is a way of comparing the difficulty of different problems. A problem A is reducible to a problem B if there is an algorithm that can solve A using B as a subroutine. If A is reducible to B, then B is at least as hard as A .
  - The notion of completeness, which is a way of identifying the hardest problems in a given class. A problem A is complete for a class C if A belongs to C and every problem in C is reducible to A. A complete problem is a representative of the computational power of the class .
  - The notion of hierarchy, which is a way of organizing the classes of problems according to their complexity. A hierarchy theorem is a result that shows that there are infinitely many distinct classes of problems with different levels of difficulty .

- Complexity theory also studies other types of resources, such as communication, randomness, parallelism, quantum computation, etc.
- Complexity theory also investigates the relationships between different models of computation, and the trade-offs between different resources.

### Deterministic Finite Automaton (DFA)

- A DFA is a mathematical model of computation that consists of a finite set of states, a finite set of input symbols, a transition function that maps each state and input symbol to a next state, an initial state, and a set of final or accepting states.
- A DFA accepts or rejects a given string of symbols by starting from the initial state and following the transition function for each symbol in the string. If the DFA reaches a final state after reading the entire string, it accepts the string. Otherwise, it rejects the string.
- A DFA is called deterministic because for each state and input symbol, there is exactly one next state. This means that the DFA can only be in one state at any given time, and the next state is uniquely determined by the current state and input symbol .
- A DFA can be represented by a state diagram, which is a directed graph where each node is a state and each edge is labeled by an input symbol. The initial state is marked by an arrow pointing to it, and the final states are marked by double circles .
- A DFA can also be represented by a transition table, which is a matrix where each row corresponds to a state, each column corresponds to an input symbol, and each entry is the next state for that state and symbol.
- A DFA can be used to recognize regular languages, which are languages that can be described by regular expressions. A regular expression is a string that specifies a pattern of symbols using operators such as concatenation, union, and Kleene star .
- A DFA can be constructed from a regular expression using algorithms such as Thompson's construction or McNaughton-Yamada-Thompson algorithm .
- A DFA can be minimized by removing unreachable states, merging equivalent states, and partitioning states into equivalence classes. A minimized DFA has the smallest number of states among all DFAs that recognize the same language .

### Equivalence of DFA and NFA

- A DFA (deterministic finite automaton) is a finite state machine that accepts or rejects a given string of symbols, where each move from a state to another is uniquely determined by the current state and the input symbol.
- An NFA (nondeterministic finite automaton) is a finite state machine that accepts or rejects a given string of symbols, where each move from a state to another is not uniquely determined by the current state and the input symbol. An NFA can have zero, one or more than one move from a given state on a given input symbol, and can also have null moves (moves without input symbol).
- The language recognized by a finite automaton is the set of all strings that it accepts. We denote the language recognized by a finite automaton M by L(M).
- A DFA and an NFA are called equivalent if they recognize the same language, that is, L(D) = L(N) for some DFA D and some NFA N.
- The equivalence of DFA and NFA can be proved by showing that for any DFA D, there is an NFA N such that L(N) = L(D), and vice versa. This means that any language that can be recognized by a DFA can also be recognized by an NFA, and any language that can be recognized by an NFA can also be recognized by a DFA.
- The proof of the equivalence of DFA and NFA consists of two parts: the construction of an NFA from a DFA, and the construction of a DFA from an NFA.
- The construction of an NFA from a DFA is straightforward: we simply copy the states, the input alphabet, the initial state, and the final states of the DFA to the NFA, and we make the transition function of the NFA the same as the transition function of the DFA. This ensures that the NFA simulates the behavior of the DFA on any input string, and accepts the same language as the DFA.
- The construction of a DFA from an NFA is more involved: we use the subset construction, which is a method of creating a new automaton from an existing one by considering the subsets of states of the original automaton as the states of the new automaton. The idea is to make the DFA simulate all the possible moves of the NFA on any input string, and accept the string if and only if the NFA has at least one accepting computation on the string.
- The subset construction works as follows: given an NFA N = (Q, Σ, δ, q0, F), we construct a DFA D = (Q', Σ, δ', q0', F') as follows:
  - Q' is the set of all subsets of Q, that is, the power set of Q. Each state in Q' represents a set of states that the NFA can be in after reading some input string.
  - Σ is the same input alphabet as N.
  - δ' is the transition function of D, defined as follows: for any state R in Q' and any symbol a in Σ, δ'(R, a) is the set of all states that the NFA can reach from any state in R by reading a, or by making null moves before or after reading a. Formally, δ'(R, a) = E(δ(E(R), a)), where E(R) is the set of all states that the NFA can reach from any state in R by making null moves, and δ(E(R), a) is the set of all states that the NFA can reach from any state in E(R) by reading a.
  - q0' is the initial state of D, which is the set of all states that the NFA can reach from the initial state q0 by making null moves. Formally, q0' = E({q0}).
  - F' is the set of all final states of D, which are the subsets of Q that contain at least one final state of N. Formally, F' = {R in Q' | R ∩ F ≠ ∅}.
- The subset construction ensures that the DFA D simulates all the possible moves of the NFA N on any input string, and accepts the string if and only if the NFA has at least one accepting computation on the string. Therefore, the DFA D recognizes the same language as the NFA N, and the equivalence of DFA and NFA is proved.

### Halting Problem

- The halting problem is a decision problem about properties of computer programs on a fixed Turing-complete model of computation.

- The halting problem is an example of an undecidable problem, meaning that there is no effective method to decide whether a given statement is true or false in a given formal system.
- The halting problem also implies that there are some problems that are computationally harder than any decidable problem, such as the universal halting problem, which is the problem of determining whether a given program will halt for every input.

### Introduction to Recursive Function Theory

- A function is called primitive recursive if it can be defined using only composition and primitive recursion, without minimization. Primitive recursion is a special case of recursion where the function is defined by its value at zero and its value at the successor of any input.
