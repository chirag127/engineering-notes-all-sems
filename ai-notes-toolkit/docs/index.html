AI Notes Toolkit

Python scripts for generating AI-powered study notes using Bing and POE APIs.
Includes thousands of CS engineering notes in markdown format.

Note Generators

  • 01_bing_generator.py — Bing AI notes
  • 02_poe_generator.py — POE AI notes
  • poe_client.py — POE API client
  • download_question_papers.py — fetch QPs

Processing Scripts

  • 03_remove_links.py — strip links
  • 05_add_odd_lines.py — process files
  • 06_merge_markdowns.py — merge MD
  • merge_markdowns_v2.py — alternate merger

PDF Utilities

  • 07_markdown_to_pdf.py — MD to PDF
  • 16_pdf_ocr.py — OCR PDFs
  • merge_pdfs.py — merge PDFs
  • merge_pdf_single.py — single merge
