### What is computer science?

- Computer science is the study of computation and its applications.
- Computation is the process of transforming data according to a set of rules or instructions.
- Applications of computation include solving problems, creating systems, and expressing creativity.
- Computer science is an interdisciplinary field that draws from mathematics, logic, engineering, and other disciplines.

### What is a computer system?

- A computer system is a collection of hardware and software that work together to perform computation.
- Hardware is the physical devices that make up a computer system, such as the CPU, memory, disk, keyboard, mouse, monitor, etc.
- Software is the set of instructions or programs that control the hardware and tell it what to do.
- A computer system can be classified into four categories: personal computers, servers, embedded systems, and supercomputers.

### What are the components of a computer system?

- A computer system consists of four main components: input, output, processing, and storage.
- Input is the data or information that is entered into the computer system by the user or another source, such as a keyboard, mouse, microphone, camera, etc.
- Output is the data or information that is displayed or sent by the computer system to the user or another destination, such as a monitor, speaker, printer, network, etc.
- Processing is the manipulation or transformation of data or information by the computer system according to the software instructions, such as arithmetic, logic, control, etc.
- Storage is the retention or preservation of data or information by the computer system for later use, such as RAM, disk, flash, cloud, etc.

### What are the types of software?

- Software can be classified into two main types: system software and application software.
- System software is the software that manages the basic operations and functions of the computer system, such as the operating system, device drivers, utilities, etc.
- Application software is the software that performs specific tasks or functions for the user or another software, such as word processors, web browsers, games, etc.

### What are the types of programming languages?

- Programming languages are the languages that are used to create software by writing instructions or programs for the computer system.
- Programming languages can be classified into three main types: low-level, high-level, and intermediate-level.
- Low-level languages are the languages that are close to the hardware and use binary or hexadecimal codes, such as machine language and assembly language.
- High-level languages are the languages that are close to the human language and use keywords and symbols, such as Python, Java, C++, etc.
- Intermediate-level languages are the languages that are between the low-level and high-level languages and use a combination of codes and keywords, such as C, Pascal, etc.

### What are the steps of software development?

- Software development is the process of creating software by following a series of steps or phases, such as analysis, design, implementation, testing, and maintenance.
- Analysis is the step of defining the problem or the requirements of the software, such as the purpose, scope, functionality, performance, etc.
- Design is the step of planning the solution or the structure of the software, such as the algorithms, data structures, modules, interfaces, etc.
- Implementation is the step of coding or writing the software using a programming language, such as Python, Java, C++, etc.
- Testing is the step of verifying or checking the software for errors or bugs, such as syntax, logic, runtime, etc.
- Maintenance is the step of updating or improving the software to fix errors, add features, or adapt to changes, such as debugging, refactoring, documenting, etc.



### Goals and applications of networks

A network is a system of two or more devices (such as computers, printers, scanners, etc.) that are connected by some medium (such as cables, wireless, satellites, etc.) and can communicate and share resources with each other  .

Some of the main goals of networks are  :

- **Resource sharing**: This means to make all programs, data and equipment available to anyone on the network regardless of the physical location of the resource and the user. For example, a group of office workers can share a common printer, fax, modem, scanner, etc. Resource sharing also enables cost reduction, as fewer devices are needed to serve multiple users.
- **High reliability**: This means to provide alternative sources of supply in case of failure or damage of any component. For example, if one server goes down, another server can take over its tasks. High reliability also improves performance, as the load can be distributed among multiple devices.
- **Scalability**: This means to allow the network to grow and accommodate new devices and users without affecting the existing ones. For example, a network can be expanded by adding more switches, routers, cables, etc. Scalability also enhances flexibility, as the network can be reconfigured or upgraded as needed.
- **Security**: This means to protect the network and its resources from unauthorized access, modification, or destruction. For example, a network can use encryption, authentication, firewalls, etc. to secure the data and devices. Security also ensures privacy, as the network can prevent eavesdropping or snooping of the communication.

Some of the main applications of networks are :

- **Communication**: This means to enable the exchange of information and messages among users and devices on the network. For example, the internet, email, chat, voice over IP, video conferencing, etc. are all forms of communication that rely on networks. Communication also fosters collaboration, as the network can support teamwork and coordination among users.
- **Entertainment**: This means to provide access to various forms of media and content that can be enjoyed by the users on the network. For example, online gaming, streaming, social media, etc. are all forms of entertainment that depend on networks. Entertainment also stimulates creativity, as the network can enable the creation and sharing of user-generated content.
- **Research**: This means to facilitate the collection, analysis, and dissemination of data and knowledge that can be used for scientific or academic purposes. For example, online search, databases, cloud computing, etc. are all forms of research that utilize networks. Research also advances innovation, as the network can enable the discovery and development of new ideas and solutions.



### Categories of networks

A computer network is a system of interconnected devices that can communicate and share data, resources, and applications. Computer networks can be classified based on several criteria, such as the transmission medium, the network size, the topology, and organizational intent. Based on a geographical scale, the different types of networks are:

- **Personal area network (PAN)**: A PAN is the smallest and simplest type of network. PANs connect devices within the range of an individual and are no larger than about 10 meters (m). Examples of PANs are wireless headphones, Bluetooth speakers, smartwatches, and smartphones.
- **Local area network (LAN)**: A LAN is a network that connects devices within a limited area, such as a home, an office, or a building. LANs are typically owned and managed by a single organization or individual. LANs can use wired or wireless technologies, such as Ethernet, Wi-Fi, or Bluetooth. LANs enable fast and secure data transfer, resource sharing, and communication among the connected devices .
- **Wireless local area network (WLAN)**: A WLAN is a type of LAN that uses wireless technologies, such as Wi-Fi, to connect devices. WLANs provide mobility, flexibility, and scalability to the network users. WLANs can be standalone or connected to a wired LAN. WLANs are commonly used in public places, such as airports, hotels, cafes, and libraries, to provide internet access to the visitors.
- **Campus area network (CAN)**: A CAN is a network that connects devices within a campus, such as a university, a school, or a corporate complex. A CAN is larger than a LAN but smaller than a metropolitan area network (MAN). A CAN can use wired or wireless technologies, such as fiber optic cables, Ethernet, or Wi-Fi. A CAN can provide high-speed data transfer, resource sharing, and communication among the campus buildings and departments.
- **Metropolitan area network (MAN)**: A MAN is a network that connects devices within a city or a metropolitan area. A MAN is larger than a LAN or a CAN but smaller than a wide area network (WAN). A MAN can use wired or wireless technologies, such as coaxial cables, fiber optic cables, microwave links, or WiMAX. A MAN can provide internet access, cable TV, telephone, and other services to the residents and businesses in the area .
- **Wide area network (WAN)**: A WAN is a network that connects devices across a large geographical area, such as a country, a continent, or the world. A WAN can span multiple LANs, CANs, or MANs. A WAN can use wired or wireless technologies, such as copper wires, fiber optic cables, satellite links, or cellular networks. A WAN can provide long-distance data transfer, resource sharing, and communication among the connected devices. The internet is the largest and most well-known example of a WAN .
- **Virtual private network (VPN)**: A VPN is a network that creates a secure and encrypted connection between a device and a remote network over a public network, such as the internet. A VPN can use various protocols, such as IPsec, SSL, or OpenVPN, to establish the connection. A VPN can provide privacy, security, and anonymity to the network users. A VPN can also enable access to restricted or censored content, such as geo-blocked websites or streaming services .



### Organization of the Internet

The Internet is the world's largest computer network. It is a global system of interconnected computing devices that can communicate and exchange data using common protocols and standards.

The organization of the Internet can be understood at different levels, such as:

- **Computer and network hardware**: This level deals with the physical devices and components that make up the network, such as computers, routers, switches, cables, wireless access points, etc. These devices are responsible for transmitting and receiving data over the network.
- **Network architecture**: This level defines how the network is structured and designed. It outlines how computers are organized in the network and what tasks are assigned to them. Network architecture components include hardware, software, transmission media (wired or wireless), network topology, and communications protocols.
- **Network topology**: This level describes the shape and layout of the network. It shows how the devices are connected and arranged in the network. There are different types of network topologies, such as bus, ring, star, and mesh.
- **Communications protocols**: This level specifies the rules and conventions for data exchange over the network. Protocols define how data is formatted, encoded, transmitted, received, and acknowledged. There are different layers of protocols that perform different functions, such as physical, data link, network, transport, and application.
- **Internet access and Internet service providers (ISPs)**: This level deals with the way that users connect to the Internet and the services that they receive. ISPs are companies that provide access to the Internet and other related services, such as email, web hosting, domain name registration, etc. ISPs can control and regulate how users use the Internet, such as by setting bandwidth limits, filtering content, blocking websites, etc.
- **Navigation within the Internet**: This level deals with the way that users find and access information and resources on the Internet. It involves the use of tools and techniques, such as domain names, IP addresses, URLs, web browsers, search engines, hyperlinks, etc. These tools help users to locate and identify the servers and websites that host the desired content.

The organization of the Internet is not static or fixed. It is constantly evolving and changing due to technological innovations, social and economic factors, and political and legal influences. The Internet is also not controlled or owned by any single entity or organization. It is a decentralized and distributed network that relies on the cooperation and collaboration of various stakeholders, such as governments, businesses, academic institutions, non-governmental organizations, and individual users.



### ISP

- ISP stands for **Internet Service Provider**    .
- An ISP is a company that provides **access to the internet** to both personal and business customers   .
- An ISP gives you an **internet account**, an **e-mail address**, and **web space** for a web page for a fee.
- An ISP also provides **software packages** (such as browsers), **hosting services** for websites, and **technical support** for its customers .
- An ISP uses special **networking, telecommunications, and routing equipment** to connect its customers to the internet.
- An ISP may also offer other services such as **voice over IP (VoIP)**, **online gaming**, **streaming media**, **cloud computing**, and **security** .
- An ISP can be classified into different types based on the **technology** they use to provide internet access, such as **dial-up**, **DSL**, **cable**, **fiber-optic**, **wireless**, or **satellite**  .
- An ISP can also be classified into different levels based on the **scope** of their network and the **customers** they serve, such as **tier 1**, **tier 2**, or **tier 3** .
- A **tier 1 ISP** is a large ISP that has **global coverage** and can exchange traffic with other tier 1 ISPs without paying fees. Examples of tier 1 ISPs are **AT&T**, **Verizon**, and **Level 3** .
- A **tier 2 ISP** is a medium-sized ISP that has **regional coverage** and can exchange traffic with some tier 1 ISPs and other tier 2 ISPs, but may have to pay fees to access some networks. Examples of tier 2 ISPs are **Comcast**, **Sprint**, and **Cogent** .
- A **tier 3 ISP** is a small ISP that has **local coverage** and can only exchange traffic with other ISPs by paying fees. Examples of tier 3 ISPs are **local cable companies**, **wireless providers**, and **resellers** .
- An ISP can also be classified into different categories based on the **services** they offer, such as **access provider**, **hosting provider**, **transit provider**, or **content provider**.
- An **access provider** is an ISP that provides internet access to end users or subscribers, such as **home users**, **small businesses**, or **mobile users** .
- A **hosting provider** is an ISP that provides web hosting services to customers who want to create and maintain their own websites, such as **domain name registration**, **web design**, **web space**, and **e-mail accounts** .
- A **transit provider** is an ISP that provides internet access to other ISPs, such as **tier 1 ISPs** or **tier 2 ISPs**, by leasing or selling bandwidth and routing services.
- A **content provider** is an ISP that provides online content to end users or subscribers, such as **news**, **entertainment**, **education**, or **social media**.



### Network structure and architecture

- Network devices typically include switches, routers, hubs, bridges, gateways, firewalls, etc.
- Network services typically include DHCP, DNS, FTP, HTTP, SMTP, etc.
- Network structure and architecture also describes how the network devices are connected and the rules that govern data transfer between them .

- A network can also be classified based on its geographic scope, such as local area network (LAN), metropolitan area network (MAN), wide area network (WAN), or personal area network (PAN).

- A network can also be classified based on its communication protocol, which is the set of rules and standards that define how the network devices communicate and exchange data, such as TCP/IP, Ethernet, Wi-Fi, Bluetooth, etc..



### Layering Principles

Layering is a process that is used to simplify network communication and help the host and server interact with each other quickly. It is an important part of the OSI model made to simplify the transmission process by separating communication into pieces that can be sent easily and securely.

The layering principles for the notes of the Unit 1 - Introductory Concepts in the subject of Computer Networks are:

- A layer should be created where a different abstraction is needed.
- Each layer should perform a well-defined function.
- The function of each layer should be chosen with an eye toward defining internationally standardized protocols.
- The layer boundaries should be chosen to minimize the information flow across the interfaces.
- The number of layers should be large enough that distinct functions need not be thrown together in the same layer out of necessity and small enough that the architecture does not become unwieldy.
- The independence of the network layer from the underlying datalink layer is a key principle of the network layer. It ensures that the network layer can be used to allow hosts attached to different types of datalink layers to exchange packets through intermediate routers.
- The network layer itself relies on the following principles:
  - Each network layer entity is identified by a network layer address. This address is independent of the datalink layer addresses that it may use.
  - The service provided by the network layer does not depend on the service or the internal organisation of the underlying datalink layers.
  - The network layer is conceptually divided into two planes: the data plane and the control plane.

### Services in Computer Networks

- Services are applications that run at the network application layer and provide various capabilities to users and devices connected to a network.
- Services can be classified into two types: connection-oriented and connectionless.
  - Connection-oriented services establish a logical connection between the sender and the receiver before exchanging data. They guarantee reliable and in-order delivery of data, but they consume more resources and introduce more delay. An example of a connection-oriented service is TCP (Transmission Control Protocol).
  - Connectionless services do not require a logical connection between the sender and the receiver. They send data as independent packets without any guarantee of reliability or order. They consume less resources and introduce less delay, but they may lose or reorder data. An example of a connectionless service is UDP (User Datagram Protocol).
- Some examples of services in computer networks are :
  - Internet and cloud connectivity: These services enable users and devices to access the internet and cloud-based applications and data. They use protocols such as HTTP (Hypertext Transfer Protocol), HTTPS (Hypertext Transfer Protocol Secure), FTP (File Transfer Protocol), and SMTP (Simple Mail Transfer Protocol).
  - Branch office and campus connectivity: These services enable users and devices in different locations to communicate and collaborate with each other. They use protocols such as VPN (Virtual Private Network), MPLS (Multiprotocol Label Switching), and SD-WAN (Software-Defined Wide Area Network).
  - Private data center services: These services enable users and devices to access and manage data and applications stored in private servers. They use protocols such as NFS (Network File System), SMB (Server Message Block), and iSCSI (Internet Small Computer System Interface).
  - Secure cloud-connectivity services: These services enable users and devices to access and manage data and applications stored in public or hybrid cloud servers. They use protocols such as SSL (Secure Sockets Layer), TLS (Transport Layer Security), and IPSec (Internet Protocol Security).
  - Virtual network services: These services enable users and devices to create and manage virtual networks that are independent of the physical network infrastructure. They use protocols such as VLAN (Virtual Local Area Network), VxLAN (Virtual Extensible Local Area Network), and NFV (Network Function Virtualization).




### Protocols and Standards in Computer Networks

- A **protocol** is a set of rules that defines how devices communicate and exchange data in a network. Protocols specify the format, syntax, semantics, and synchronization of the messages exchanged between the devices. Protocols also handle error detection, correction, and recovery in case of transmission failures. Protocols enable interoperability and compatibility among different types of devices and networks.
- A **standard** is a document that describes the specifications, characteristics, and requirements of a protocol. Standards ensure that protocols are consistent, reliable, and widely accepted by the industry and the users. Standards also facilitate the development, testing, and implementation of protocols. Standards are developed and maintained by various organizations, such as the International Organization for Standardization (ISO), the Institute of Electrical and Electronics Engineers (IEEE), and the Internet Engineering Task Force (IETF).
- Protocols and standards are essential for computer networks because they enable different devices and networks to communicate and share information with each other, regardless of their internal structure, design, or vendor. Protocols and standards also improve the performance, security, and scalability of networks. Protocols and standards are organized into different layers, such as the Open Systems Interconnection (OSI) model and the Transmission Control Protocol/Internet Protocol (TCP/IP) model, to simplify the network architecture and functionality. Some examples of common protocols and standards in computer networks are:

  - **Hypertext Transfer Protocol (HTTP)**: A protocol that defines how web browsers and web servers communicate and exchange web pages and other resources over the internet.
  - **Domain Name System (DNS)**: A protocol that translates human-readable domain names, such as www.example.com, into numerical IP addresses, such as 192.168.1.1, that identify the location of the web servers on the internet.
  - **Simple Mail Transfer Protocol (SMTP)**: A protocol that defines how email messages are sent and received between mail servers and mail clients over the internet.
  - **Ethernet**: A standard that defines the physical and data link layer specifications for wired local area networks (LANs). Ethernet specifies the format, structure, and encoding of the data frames, as well as the medium access control (MAC) addresses, that identify the devices on the network.
  - **Wi-Fi**: A standard that defines the physical and data link layer specifications for wireless local area networks (WLANs). Wi-Fi specifies the frequency bands, modulation schemes, and encryption methods for wireless communication, as well as the service set identifier (SSID), that identifies the wireless network name.



### The OSI reference model

- The OSI reference model stands for Open System Interconnection model and is a conceptual framework that describes how information from a software application in one computer moves through a physical medium to the software application in another computer .
- The OSI reference model was a major advance in the standardisation of network concepts and promoted the idea of a consistent model of protocol layers, defining interoperability between network devices and software.
- The OSI reference model consists of seven layers, and each layer performs a particular network function. The layers are :

  - Layer 1: Physical layer. This layer defines the electrical and physical specifications of the data connection. It defines the relationship between a device and a physical medium. This includes the layout of pins, voltages, cable specifications, hubs, repeaters, network adapters, host bus adapters (HBAs used in storage area networks) and more.
  - Layer 2: Data link layer. This layer provides the functional and procedural means to transfer data between network entities and to detect and possibly correct errors that may occur in the physical layer. It defines the protocol to establish and terminate a connection between two physically connected devices. It also defines the protocol for flow control between them. Examples of data link protocols are Ethernet for local area networks (multi-node), the Point-to-Point Protocol (PPP), HDLC and ADCCP for point-to-point (dual-node) connections.
  - Layer 3: Network layer. This layer provides the functional and procedural means of transferring variable length data sequences from a source to a destination via one or more networks while maintaining the quality of service requested by the transport layer. It performs network routing, flow control, segmentation, congestion control, link layer discovery, and error handling functions. Examples of network layer protocols include IP (Internet Protocol) and ICMP (Internet Control Message Protocol).
  - Layer 4: Transport layer. This layer provides the functional and procedural means of transferring data between end systems, or hosts, and is responsible for end-to-end error recovery and flow control. It ensures complete data transfer. Examples of transport layer protocols include TCP (Transmission Control Protocol), which is connection-oriented, and UDP (User Datagram Protocol), which is connectionless.
  - Layer 5: Session layer. This layer controls the dialogues (connections) between computers. It establishes, manages and terminates the connections between the local and remote application. It provides for full-duplex, half-duplex, or simplex operation, and establishes checkpointing, adjournment, termination, and restart procedures. Examples of session layer protocols include NFS (Network File System), SQL (Structured Query Language), and RPC (Remote Procedure Call).
  - Layer 6: Presentation layer. This layer establishes context between application-layer entities, in which the application-layer entities may use different syntax and semantics if the presentation service provides a mapping between them. If a mapping is available, presentation service data units are encapsulated into session protocol data units and passed down the protocol stack. Examples of presentation layer protocols include XDR (External Data Representation), ASN.1 (Abstract Syntax Notation One), SMB (Server Message Block), AFP (Apple Filing Protocol), and NCP (NetWare Core Protocol).
  - Layer 7: Application layer. This layer supports application and end-user processes. Communication partners are identified, quality of service is identified, user authentication and privacy are considered, and any constraints on data syntax are identified. Everything at this layer is application-specific. This layer provides application services for file transfers, e-mail, and other network software services. Examples of application layer protocols include HTTP (Hypertext Transfer Protocol), FTP (File Transfer Protocol), SMTP (Simple Mail Transfer Protocol), SNMP (Simple Network Management Protocol), and Telnet.

- The OSI reference model is not a protocol, but a model that guides the design and implementation of network protocols. It is also not a rigid standard, but a flexible and adaptable framework that can accommodate various network architectures and technologies .
- The OSI reference model can be used to understand the functions and interactions of different network layers, to compare and contrast different network protocols and architectures, and to troubleshoot network problems by identifying the layer where the problem occurs .



### TCP/IP protocol suite

- TCP/IP stands for Transmission Control Protocol/Internet Protocol and is a suite of communication protocols used to interconnect network devices on the internet .
- TCP/IP is also used as a communications protocol in a private computer network (an intranet or extranet) .
- TCP/IP is commonly known as the Internet protocol suite, which is a framework for organizing the set of communication protocols used in the Internet and similar computer networks according to functional criteria.
- TCP/IP consists of four layers: the application layer, the transport layer, the internet layer, and the network access layer .
- The application layer provides the interface for the user applications to communicate with the network, such as web browsers, email clients, FTP clients, etc .
- The transport layer provides end-to-end data delivery services, such as reliability, flow control, congestion control, and multiplexing. The main protocols in this layer are TCP and UDP .
- The internet layer provides the routing and addressing functions for the data packets across different networks. The main protocol in this layer is IP, which is responsible for the logical addressing and fragmentation of the packets .
- The network access layer provides the physical and link layer functions for the data transmission over the network media, such as Ethernet, Wi-Fi, etc. This layer is also known as the data link layer or the network interface layer .
- TCP/IP is the most widely used protocol suite in the world and is the basis for the Internet and many other networks .



### Network devices and components

Network devices and components are the hardware and software elements that enable communication and data exchange between different devices on a network. They can be classified into two main categories: inter-network and intra-network devices.

- Inter-network devices are those that are mounted within the device, such as a network interface card (NIC) or an RJ45 connector. They allow the device to connect to the network media, such as a cable or a wireless signal.
- Intra-network devices are those that are internal components of the network, such as switches, routers, hubs, and servers. They perform various functions to manage the traffic and data flow within the network and between different networks.

Some of the common network devices and components are:

- Sender: The device that initiates the communication or data transmission on the network, such as a computer or a smartphone.
- Receiver: The device that receives the communication or data transmission on the network, such as a printer or a monitor.
- End Point: The device that is either the source or the destination of the communication or data transmission on the network, such as a sender or a receiver.
- Network Interface Card (NIC): The hardware component that provides the physical interface between the device and the network media. It converts the data from the device into a format that can be transmitted on the network, and vice versa.
- Network Media: The physical or wireless medium that carries the data signals on the network, such as a twisted pair cable, a coaxial cable, a fiber optic cable, or a radio wave.
- Connectors: The hardware components that connect the network media to the network devices, such as a RJ45 connector, a BNC connector, or a ST connector.
- Switch: The network device that connects multiple devices on the same network and forwards data packets to the appropriate destination based on the MAC address of the device. It operates at the data link layer of the OSI model.
- Router: The network device that connects multiple networks and forwards data packets to the appropriate destination based on the IP address of the device. It operates at the network layer of the OSI model.
- Hub: The network device that connects multiple devices on the same network and broadcasts data packets to all the connected devices. It operates at the physical layer of the OSI model.
- Server: The network device that provides services or resources to other devices on the network, such as a file server, a web server, or a mail server. It operates at the application layer of the OSI model.
- Gateway: The network device that connects two different types of networks and translates the data packets between them, such as a modem, a firewall, or a proxy server. It operates at the application layer of the OSI model.
- Bridge: The network device that connects two segments of the same network and filters the data packets based on the MAC address of the device. It operates at the data link layer of the OSI model.
- Repeater: The network device that amplifies the data signals on the network and extends the range of the network media. It operates at the physical layer of the OSI model.
- Brouter: The network device that combines the functions of a bridge and a router and forwards data packets based on the MAC address or the IP address of the device. It operates at the data link layer or the network layer of the OSI model.

## Unit 2 - Physical Layer

The physical layer is the lowest layer of the OSI model, which deals with the transmission and reception of raw bits over a physical medium. The physical layer is responsible for:

- Defining the characteristics of the physical medium, such as the type of cable, connector, wireless frequency, etc.
- Encoding and decoding the bits into electrical, optical, or radio signals, using different modulation and demodulation techniques.
- Transmitting and receiving the signals over the physical medium, using different multiplexing and demultiplexing techniques to share the medium among multiple users.
- Detecting and correcting the errors that may occur during the transmission, using different error detection and correction methods.
- Synchronizing the sender and receiver clocks, using different synchronization methods.
- Regulating the flow of data, using different flow control methods.

Some of the topics covered in this unit are:

- Data and signals: This topic explains the difference between analog and digital data and signals, and how they can be converted from one form to another using different encoding and decoding schemes.
- Transmission impairment: This topic explains the causes and effects of various types of impairments that may degrade the quality of the signals, such as attenuation, distortion, noise, and interference.
- Transmission media: This topic explains the characteristics and types of different transmission media, such as guided media (e.g., twisted pair, coaxial cable, fiber optic cable) and unguided media (e.g., radio waves, microwaves, infrared waves).
- Switching: This topic explains the concept and types of switching, which is a technique to connect multiple devices in a network using switches. The types of switching are circuit switching, packet switching, and message switching.
- Multiplexing: This topic explains the concept and types of multiplexing, which is a technique to combine multiple signals into one signal over a shared medium. The types of multiplexing are frequency division multiplexing (FDM), time division multiplexing (TDM), wavelength division multiplexing (WDM), and code division multiplexing (CDM).

### Network topology design

- Network topology design is the process of creating a physical, virtual, and logical arrangement of infrastructure in an IT network.
- Network topology design helps to optimize the performance, security, scalability, and reliability of the network.
- Network topology design involves the following steps:
  - Analyzing the business requirements and objectives of the network
  - Identifying the network devices, nodes, and connections that are needed to meet the requirements
  - Choosing the best network topology type for the network, such as ring, chain, tree, or mesh
  - Creating a network diagram that shows the placement and interconnection of the network elements
  - Implementing, testing, and monitoring the network design
- Network topology design can be classified into two major categories: physical and logical.
  - Physical topology refers to the actual layout of the network devices, nodes, and connections in a given space.

### Switching techniques and multiplexing

Switching techniques and multiplexing are two important concepts in computer networks that enable efficient and reliable data transmission over shared communication links.

#### Switching techniques

Switching techniques are methods of connecting multiple devices in a network and allowing them to communicate with each other by establishing and releasing connections as needed. There are three main types of switching techniques: circuit switching, message switching, and packet switching.

Packet switching is suitable for both real-time and non-real-time data, such as voice over IP and web browsing. An example of packet switching is the internet.

A node can send data only on its assigned sub-channel, without interfering with other nodes. This eliminates collisions, but may waste some bandwidth or require complex synchronization. Examples of channelization protocols are Frequency Division Multiple Access (FDMA), Time Division Multiple Access (TDMA), and Code Division Multiple Access (CDMA).

  - Filtering: Link layer switches and bridges can discard frames that are not destined for any device on the connected LANs, thus reducing unnecessary traffic .
  - Learning: Link layer switches and bridges can learn the MAC addresses of the devices on the connected LANs by observing the source addresses of the incoming frames and storing them in a table .
  - Spanning tree: Link layer switches and bridges can avoid loops in the network by using a spanning tree protocol that dynamically disables some of the links and creates a tree-like topology .

### Learning bridge and spanning tree algorithms for the notes of the Unit 4 - Medium Access Control and Local Area Networks in the subject of Computer Networks

- A bridge is a device that connects two or more LAN segments and forwards frames between them based on the MAC addresses of the destination and source hosts.
- A bridge operates at the data link layer of the OSI model and can filter, forward, or flood frames depending on the destination MAC address and the bridge's forwarding table.
- A bridge can also learn the MAC addresses of the hosts connected to its ports by observing the source MAC address of the incoming frames and updating its forwarding table accordingly.
- A bridge can create a loop-free logical topology for a network of LAN segments by running the spanning tree protocol (STP).
- The spanning tree protocol is a network protocol that builds a loop-free logical topology for Ethernet networks by disabling some of the redundant links between the bridges.
- The basic function of STP is to prevent bridge loops and the broadcast radiation that results from them.
- Spanning tree also allows a network design to include backup links providing fault tolerance if an active link fails.
- The bridges that participate in spanning tree protocol are often called spanning tree bridges.
- To construct a spanning tree, the bridges run a distributed algorithm that uses bridge protocol data units (BPDUs) as the messages.
- BPDUs are data messages that provide the bridges with network information that's used to carry out STP operations.
- The spanning tree algorithm, which was developed by Radia Perlman at the Digital Equipment Corporation, is based on the following steps:

  - Each bridge assigns itself a unique bridge ID, which is a combination of a priority value and a MAC address.
  - Each bridge broadcasts a configuration message (a type of BPDU) out all of its ports to its neighbors, containing its bridge ID and the cost of the path to the root bridge (initially itself).
  - Each bridge compares the received configuration messages with its own and updates its information if it finds a better path to the root bridge (a bridge with a lower bridge ID or a lower path cost).
  - Each bridge also elects a designated bridge for each LAN segment, which is the bridge that has the lowest path cost to the root bridge on that segment.
  - Each bridge also elects a root port, which is the port that connects to the designated bridge on the LAN segment that has the lowest path cost to the root bridge.
  - Each bridge disables all its ports that are not root ports or designated ports, creating a loop-free spanning tree.
  - The root bridge periodically sends out configuration messages to maintain the spanning tree, and the other bridges forward them along the tree.
  - If a link fails or a new bridge is added, the spanning tree algorithm is run again to reconfigure the spanning tree.

- The spanning tree algorithm is dynamic, so if an outage occurs then the spanning tree is recomputed.
- If the outage should partition the network into two pieces, both pieces will build spanning trees.
- The IEEE 802.1 specification for LAN bridges is based on the spanning tree algorithm.

### CIDR

- CIDR stands for **Classless Inter-Domain Routing** .
- It is a method for **allocating IP addresses** and for **IP routing**.
- It replaces the previous classful network addressing architecture on the Internet .
- It allows for a more efficient and flexible allocation of IP addresses than the older method of assigning a class of IPs to each organization .
- It is based on **variable-length subnet masking (VLSM)**, which enables network engineers to divide an IP address space into a hierarchy of subnets of different sizes .
- It makes it possible to create subnetworks with different host counts without wasting large numbers of addresses.
- CIDR addresses are made up of two sets of numbers: **Prefix** and **Prefix Length** .
- The prefix is the network address, which is the same for all hosts in the same subnetwork.
- The prefix length is the number of significant bits that make up the routing or networking portion of the address.
- The prefix length is written as a slash (/) followed by a decimal number, such as /24.
- The prefix length indicates how many bits of the 32-bit IP address are used for the network address and how many are used for the host address.
- The prefix length can range from 0 to 32, where 0 means the entire address is the host address and 32 means the entire address is the network address.
- The prefix length determines the size of the subnetwork and the number of hosts that can be assigned to it.
- The formula for calculating the number of hosts in a subnetwork is 2^(32 - prefix length) - 2, where the -2 accounts for the network address and the broadcast address.
- For example, a CIDR address of 192.168.1.0/24 means that the network address is 192.168.1.0, the prefix length is 24, and the number of hosts is 2^(32 - 24) - 2 = 254.
- CIDR notation can also be used to aggregate multiple contiguous subnetworks into a larger block, which reduces the size of routing tables and improves routing efficiency .
- This is also known as **supernetting** or **route aggregation** .
- For example, four subnetworks with CIDR addresses of 192.168.1.0/24, 192.168.2.0/24, 192.168.3.0/24, and 192.168.4.0/24 can be aggregated into a single block of 192.168.0.0/22, which has a prefix length of 22 and a number of hosts of 2^(32 - 22) - 2 = 1022 .
- CIDR is widely used on the Internet and other IP networks to allocate and route IP addresses efficiently and flexibly.

### ARP
- ARP stands for Address Resolution Protocol   .
- It is a communication protocol used for discovering the link layer address, such as a MAC address, associated with a given internet layer address, typically an IPv4 address   .
- This mapping is a critical function in the Internet protocol suite, as it allows devices to communicate within a local network   .
- ARP was defined in 1982 by RFC 826, which is Internet Standard STD 37 .

#### How ARP works
- ARP operates in two phases: request and reply   .
- In the request phase, a device that wants to know the MAC address of another device sends a broadcast ARP request packet to the network, containing the IP address of the target device   .
- In the reply phase, the device that has the matching IP address responds with a unicast ARP reply packet, containing its MAC address   .
- The device that sent the request then updates its ARP cache, which is a table that stores the IP-MAC address mappings for a period of time   .
- The device can then use the MAC address to send data packets to the target device   .

#### Types of ARP
- There are different types of ARP, depending on the network topology and the protocol used .
- Some of the common types are:
  - Proxy ARP: A device that acts as a gateway for another device, responding to ARP requests on its behalf .
  - Gratuitous ARP: A device that sends an ARP request or reply with its own IP and MAC address, to announce or update its presence on the network .
  - Reverse ARP (RARP): A device that requests its IP address from a server, by sending its MAC address .
  - Inverse ARP (InARP): A device that requests the IP address of another device, by sending its MAC address .

#### Advantages and disadvantages of ARP
- Some of the advantages of ARP are:
  - It is simple and efficient, as it does not require any configuration or routing information .
  - It is dynamic, as it can adapt to changes in the network topology and IP addresses .
  - It is widely supported, as it is a standard protocol for IPv4 networks .
- Some of the disadvantages of ARP are:
  - It is vulnerable to attacks, such as ARP spoofing, where a malicious device can send fake ARP packets to trick other devices into sending data to the wrong destination .

### Congestion control algorithms

Congestion control algorithms are methods to regulate the flow of data packets in a network and prevent congestion, which can degrade the performance and reliability of the network. Congestion occurs when the demand for network resources exceeds the available capacity. Congestion control algorithms can be implemented at different layers of the network stack, such as the transport layer or the network layer.

Some of the common congestion control algorithms are:

- **Leaky bucket**: This algorithm simulates a leaky bucket that can hold a fixed number of tokens. Tokens are generated at a constant rate and added to the bucket. A packet can be sent only if there is a token available in the bucket. If the bucket is full, any incoming token is discarded. This algorithm limits the burstiness of the traffic and enforces a constant output rate .
- **Token bucket**: This algorithm is similar to the leaky bucket, but it allows some burstiness in the traffic. The bucket can hold a maximum number of tokens, and tokens are generated at a constant rate. A packet can be sent if there is a token available in the bucket, and the token is removed. The bucket can accumulate tokens up to its capacity, allowing a burst of packets to be sent. If the bucket is empty, no packet can be sent .
- **Additive increase multiplicative decrease (AIMD)**: This algorithm is used by TCP to adjust the size of the congestion window, which is the number of packets that can be sent without waiting for an acknowledgment. The algorithm increases the window size by one packet for every round trip time (RTT) if there is no packet loss, and decreases the window size by half if there is a packet loss. This algorithm tries to probe the available bandwidth and back off when congestion occurs .
- **Slow start**: This algorithm is also used by TCP to initialize the congestion window. The algorithm starts with a small window size and doubles it for every RTT until it reaches a threshold value or a packet loss occurs. This algorithm allows TCP to quickly ramp up the transmission rate at the beginning of a connection or after a packet loss .
- **Congestion avoidance**: This algorithm is used by TCP to avoid entering the slow start phase too often. The algorithm increases the window size by one packet for every RTT if the window size is below the threshold value, and increases the window size by one packet for every window size packets if the window size is above the threshold value. This algorithm tries to maintain a linear growth of the window size and avoid congestion .
- **Fast retransmit and fast recovery**: These algorithms are used by TCP to recover from a packet loss without reducing the window size too much. The fast retransmit algorithm detects a packet loss by receiving three duplicate acknowledgments for the same packet, and retransmits the lost packet without waiting for a timeout. The fast recovery algorithm maintains the window size at half of the value before the packet loss, and increases it by one packet for every duplicate acknowledgment received. These algorithms try to avoid the slow start phase and resume the normal transmission rate quickly .

### Multiplexing

Multiplexing is a technique that allows the simultaneous transmission of multiple signals over a single data link. The main purpose of multiplexing is to share a scarce resource, such as a physical transmission medium, among multiple users or applications. Multiplexing can also improve the efficiency and reliability of data transmission by reducing interference and noise.

There are different types of multiplexing techniques, such as:

- Frequency Division Multiplexing (FDM): This technique divides the available bandwidth of the data link into several frequency bands, and assigns each band to a different signal. Each signal is modulated by a carrier wave of a different frequency, and then combined into a single composite signal. At the receiver end, the composite signal is demodulated and filtered to recover the original signals. FDM is suitable for analog signals, such as voice or radio, and can be used in wired or wireless communication systems.
- Time Division Multiplexing (TDM): This technique divides the available time of the data link into several time slots, and assigns each slot to a different signal. Each signal is transmitted in its assigned time slot, and then multiplexed into a single composite signal. At the receiver end, the composite signal is demultiplexed and synchronized to recover the original signals. TDM is suitable for digital signals, such as data or video, and can be used in synchronous or asynchronous modes.
- Wavelength Division Multiplexing (WDM): This technique is a special case of FDM, where the data link is an optical fiber, and the signals are light waves of different wavelengths. Each signal is modulated by a laser of a different wavelength, and then combined into a single composite signal. At the receiver end, the composite signal is demodulated and separated by a prism or a filter to recover the original signals. WDM can increase the capacity and speed of optical communication systems, and can be used in long-distance or metropolitan networks.
- Code Division Multiplexing (CDM): This technique assigns a unique code to each signal, and then spreads the spectrum of each signal using the code. The coded signals are then multiplexed into a single composite signal. At the receiver end, the composite signal is demultiplexed and decoded using the same code to recover the original signals. CDM can improve the security and robustness of data transmission by reducing interference and jamming, and can be used in wireless communication systems, such as cellular networks or satellite networks.

### TCP Congestion Control

- TCP congestion control is a mechanism that aims to avoid network congestion and ensure fair and efficient use of network resources by TCP senders.
- TCP congestion control consists of three main components:
  - Congestion window (cwnd): a variable maintained by the sender that limits the amount of data that can be in transit at any time.
  - Congestion avoidance algorithm: a set of rules that determines how the sender adjusts the cwnd in response to network events, such as acknowledgments, timeouts, or duplicate acknowledgments.
  - Slow start algorithm: a special case of congestion avoidance that is used when the sender starts a new connection or restarts after a long idle period or a packet loss.
- TCP congestion control operates in three phases:
  - Slow start phase: the sender starts with a small cwnd (usually one or two segments) and increases it exponentially for every acknowledgment received, until it reaches a threshold value (ssthresh) or a packet loss occurs.
  - Congestion avoidance phase: the sender increases the cwnd linearly for every round-trip time (RTT), as long as there is no packet loss. The cwnd is incremented by one segment per RTT, which is equivalent to adding one segment for every cwnd segments acknowledged.
  - Congestion detection phase: the sender detects a packet loss by either a timeout or receiving three duplicate acknowledgments. Depending on the detection method, the sender reacts differently:
    - Timeout: the sender assumes that the network is severely congested and sets the ssthresh to half of the current cwnd, and the cwnd to one segment. The sender then enters the slow start phase again.
    - Three duplicate acknowledgments: the sender assumes that the network is mildly congested and sets the ssthresh to half of the current cwnd, and the cwnd to the ssthresh value. The sender then enters the congestion avoidance phase.
- TCP congestion control is based on the additive increase/multiplicative decrease (AIMD) principle, which ensures that the cwnd grows slowly when it is large and shrinks quickly when it is small.
- TCP congestion control is also adaptive and self-clocking, meaning that it adjusts the sending rate according to the feedback from the network and the receiver, and that it synchronizes the sender with the receiver by using acknowledgments as implicit signals.
- TCP congestion control has been improved over the years by introducing various enhancements and variations, such as fast retransmit, fast recovery, selective acknowledgment, NewReno, Vegas, Cubic, BBR, and others  . Some of these algorithms require custom fields to be added to the TCP packet structure, such as XCP, MaxNet, and ECN.

### File Transfer Protocol

- File Transfer Protocol (FTP) is a standard communication protocol used for the transfer of computer files from a server to a client on a computer network.
- FTP is built on a client–server model architecture using separate control and data connections between the client and the server.
- The control connection is used to authenticate the user and send commands, while the data connection is used to transfer the files.
- FTP can operate in two modes: active and passive.
  - In active mode, the client starts listening for incoming data connections from the server on a port specified by the client.
  - In passive mode, the client initiates both the control and data connections to the server, and the server responds with the port number for the data connection.
- FTP can transfer files in two modes: binary and ASCII.
  - In binary mode, the files are transferred as raw data, preserving the exact content and format of the files.
  - In ASCII mode, the files are converted to a standard text format, which may cause some data loss or corruption.
- FTP can support various types of file operations, such as uploading, downloading, renaming, deleting, and listing files and directories.
- FTP can also support resume and append operations, which allow the user to resume an interrupted transfer or append data to an existing file.
- FTP is widely used for transferring files over the Internet and between computer systems, but it has some limitations and security risks .
  - FTP does not encrypt the data or the credentials, making them vulnerable to interception and tampering .
  - FTP does not support compression, encryption, authentication, or integrity verification of the transferred files .
  - FTP does not handle network errors or failures gracefully, and may require manual intervention to resume or restart a transfer .
- To overcome these limitations and risks, various extensions and alternatives to FTP have been developed, such as FTPS, SFTP, SCP, and WebDAV .
  - FTPS is FTP with SSL/TLS encryption, which adds security and privacy to the FTP protocol.
  - SFTP is SSH File Transfer Protocol, which provides file access, file transfer, and file management over any reliable data stream, usually SSH.
  - SCP is Secure Copy Protocol, which is a simplified version of SFTP that only supports file transfer over SSH.
  - WebDAV is Web Distributed Authoring and Versioning, which is an extension of HTTP that allows remote collaboration and file management on web servers.

### Cryptography – basic concepts

Cryptography is the science and art of designing and using techniques to secure communication and data in the presence of adversaries. Cryptography has many applications, such as protecting the confidentiality, integrity, and authenticity of information, enabling secure transactions, authentication, digital signatures, and encryption.

Some basic concepts of cryptography are:

- **Plaintext**: The original message or data that needs to be encrypted or protected.
- **Ciphertext**: The encrypted or transformed version of the plaintext that is unreadable by unauthorized parties.
- **Encryption**: The process of converting plaintext into ciphertext using a secret key and an algorithm.
- **Decryption**: The process of converting ciphertext back into plaintext using the same or a different key and algorithm.
- **Key**: A secret value or parameter that is used by the encryption and decryption algorithms to produce the ciphertext and plaintext.
- **Algorithm**: A set of rules or steps that define how the encryption and decryption are performed.
- **Symmetric-key cryptography**: A type of cryptography where the same key is used for both encryption and decryption. Examples of symmetric-key algorithms are AES, DES, and RC4.
- **Asymmetric-key cryptography**: A type of cryptography where different keys are used for encryption and decryption. One key is called the public key and can be shared with anyone, while the other key is called the private key and must be kept secret. Examples of asymmetric-key algorithms are RSA, ECC, and DSA.
- **Hash function**: A mathematical function that maps any input to a fixed-length output, called a hash or a digest. A hash function has the property that it is easy to compute the hash from the input, but hard to find the input from the hash. Hash functions are used for verifying the integrity and authenticity of data, such as in digital signatures and message authentication codes. Examples of hash functions are SHA-256, MD5, and BLAKE2.
- **Digital signature**: A cryptographic technique that allows a sender to sign a message with their private key, and a receiver to verify the signature with the sender's public key. A digital signature provides non-repudiation, meaning that the sender cannot deny having sent the message. Examples of digital signature schemes are RSA, DSA, and ECDSA.
- **Public-key infrastructure (PKI)**: A system that manages the creation, distribution, and verification of public keys and digital certificates. A digital certificate is a document that binds a public key to an identity, such as a name or an email address. A certificate authority (CA) is a trusted entity that issues and revokes digital certificates. Examples of PKI standards are X.509, PGP, and SSL/TLS.
