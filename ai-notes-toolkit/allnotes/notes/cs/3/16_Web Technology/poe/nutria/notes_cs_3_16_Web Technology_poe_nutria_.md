### Protocols Governing Web

1. HTTP (Hypertext Transfer Protocol) is the foundation of data communication for the World Wide Web. It is used to transfer files (text, images, videos, etc.) between a web server and a web browser.

2. HTTPS (Hypertext Transfer Protocol Secure) is an extension of the HTTP protocol that adds an extra layer of security to the data transfer process. It uses encryption to protect the data from being intercepted and read by unauthorized parties.

3. FTP (File Transfer Protocol) is a protocol used to transfer files from one computer to another over the Internet. It is commonly used to download files from a web server to a web browser.

4. DNS (Domain Name System) is a distributed database system that translates domain names (such as www.example.com) into IP addresses.

5. SMTP (Simple Mail Transfer Protocol) is a protocol used to send emails from one computer to another over the Internet.

6. SSL (Secure Sockets Layer) is a protocol used to encrypt data transferred over the Internet. It is commonly used for secure web transactions.

5. Event delegation is a process in which an event handler is attached to a parent element and responds to events triggered on any of its child elements.
