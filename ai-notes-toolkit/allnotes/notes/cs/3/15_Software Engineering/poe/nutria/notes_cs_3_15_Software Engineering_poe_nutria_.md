### Software Development Life Cycle (SDLC) Models

1. Waterfall Model: This model is the most basic and traditional model of software development. It is a linear sequential life cycle model where each phase must be completed before the next phase can begin and there is no overlapping in the phases.

2. Iterative Model: This model is based on incremental development, where the software is developed in incremental, rapid cycles. Each iteration is a complete version of the software and the iterations are developed one after the other.

3. Spiral Model: This model is based on the iterative approach and is also known as the spiral lifecycle model. It combines elements of both design and prototyping-in-stages, in an effort to combine advantages of top-down and bottom-up concepts.

4. Agile Model: This model is based on adaptive software development. It is a type of incremental software development model where requirements and solutions evolve through collaboration between self-organizing, cross-functional teams.

5. V-Model: This model is based on the verification and validation concept of software development. It is a type of waterfall model where each phase of the development cycle is linked to its respective phase of testing.

6. Big Bang Model: This model is a type of software development model where the entire software development process is completed in one go. It is a single cycle process which does not have any distinct phases and is completed in one go.
