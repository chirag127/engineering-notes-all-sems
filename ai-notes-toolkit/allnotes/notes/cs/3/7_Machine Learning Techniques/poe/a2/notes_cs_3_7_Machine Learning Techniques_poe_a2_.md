### Artificial Neural Network

- Artificial Neural Networks (ANNs) are inspired by biological neural networks that constitute animal brains.
- They are made up of interconnected nodes that must be trained on large amounts of data to learn how to perform a task.
- ANNs are well suited to tasks like pattern recognition, classification, and prediction.

-- Input Layer: The input data is fed into the network through the input layer.
-- Hidden Layers: The hidden layers process the input and determine the strength of the output. The number of hidden layers varies by network architecture.
-- Output Layer: The output layer produces the final output of the network based on the processing done in the hidden layers.
- Training an ANN involves iteratively adjusting the strengths of the connections between nodes (weights and biases) to produce the desired outputs for a given input.
- Backpropagation is a common training algorithm that calculates the gradient of the loss function with respect to the weights and biases, then adjusts them to minimize the loss.
- Once trained, an ANN can then be used to make predictions on new data.

### Decision Tree Learning

- Decision trees are a supervised learning method used for classification and regression problems.
- They work by splitting the data into subsets based on an attribute value. This process is repeated on each subset in a recursive manner called recursive partitioning.
- The recursion is terminated when the subset reaches a pre-defined purity. The decision at each node is made to maximize information gain (classification) or variance reduction (regression).
- The resulting structure can be represented as a tree with leaf nodes denoting the classification/regression outcome.
- The advantages of decision trees are:
- Easy to understand and interpret
- Requires little data preprocessing
- Can handle both numerical and categorical data
- The disadvantages are:
- Tendency to overfit the training data
- Require techniques like pruning to avoid overfitting
- The final tree can be quite complex and difficult to interpret for large data sets.

### Support Vector Machine

- Support Vector Machine (SVM) is a supervised learning algorithm which can be used for both classification or regression challenges.
- However, it is mainly used for classification problems.
- In SVM, we plot each data item as a point in n-dimensional space (where n is the number of features) and we try to find a hyperplane to separate the data points of two classes.
- The hyperplane is the line that maximizes the margin between the two classes. The points that are closest to the hyperplane are called support vectors.
- The goal is to make the margin as wide as possible. A wider margin means lower generalization error.
- SVM uses kernel tricks to transform the non-linearly separable problem to a linearly separable problem. Some commonly used kernels are:
  - Linear kernel
  - Polynomial kernel
  - Radial basis function (RBF) kernel
- The main advantages of SVM are:
  - It has a low training and prediction time compared to many other classification algorithms.
  - It performs very well even with a limited number of training data.
  - It provides good generalization ability.
- The main disadvantage is that SVM does not directly provide probability estimates, and these can be difficult to obtain.

### Issues in Machine Learning

- Overfitting: When a model is trained with a limited set of training data, it may get very good at predicting the training examples, but may not generalize well to new data. This is known as overfitting. Methods like cross-validation and regularization are used to address overfitting.
- Underfitting: When a model is not complex enough to capture the underlying patterns in the data, it is known as underfitting. Underfitted models have high bias and low variance. Increasing the complexity of the model can fix underfitting.
- High variance: When a model gives highly variable predictions for the same input data points, it is said to have high variance. Complex models with many parameters may suffer from high variance. Regularization techniques are used to address high variance.
- High bias: When a model consistently has a large error, it is known as high bias. Such models tend to miss the underlying patterns in the data. Increasing the complexity of the model or collecting more data can help reduce high bias.
- Irrelevant features: The presence of irrelevant features in the data may affect model performance. Feature selection methods are used to select only relevant features and improve model performance.
- Curse of dimensionality: The performance of many machine learning algorithms degrades as the number of features increases. This is known as the curse of dimensionality. Techniques like feature selection and dimensionality reduction are used to address this issue.

## Unit 2 - REGRESSION

1. Regression is a statistical technique to analyze the relationship between a dependent variable and one or more independent variables.

2. The goal of regression is to determine the "best fit" line or curve that minimizes the error between the observed and predicted values of the dependent variable.

3. Types of Regression:
    - Simple Linear Regression: One independent variable and one dependent variable. Used to model the relationship between two variables.
    - Multiple Linear Regression: Two or more independent variables and one dependent variable. Used to model the relationship between two or more independent variables and one dependent variable.
    - Logistic Regression: The dependent variable is a binary variable that contains only two possible categories. Used for predicting the outcome of a categorical dependent variable based on one or more independent variables.

4. Assumptions of Regression:
    - Linear relationship between the independent and dependent variables.
    - Multicollinearity: The independent variables are not highly correlated with each other.
    - Independence of errors: The errors are uncorrelated and have a mean of zero.
    - Homoscedasticity: The error term has the same variance across all values of the independent variables.
    - Normal distribution of errors: The errors are normally distributed.

5. Uses of Regression:
    - Causal analysis: Estimate the effect of changing one or more independent variables on the dependent variable.
    - Forecasting and prediction: Predict the value of the dependent variable based on the values of the independent variables.
    - Modeling relationships: Quantify relationships between variables and understand the interactions between them.

### Linear Regression for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Linear Regression is a supervised learning algorithm where the predicted output is continuous and has a constant slope. It is used to predict a quantitative value based on the value of another variable.
2. The equation for Linear Regression is Y=mX+c where m is the slope and c is the intercept. The goal is to minimize the error between the predicted line and the actual points.

- Linear relationship between dependent and independent variables
- Multivariate normality - Error terms are normally distributed
- Homoscedasticity - Equal variance of error terms
- Independence of error terms - Error terms are uncorrelated
- No multicollinearity - Independent variables are not correlated

6. Applications of Linear Regression:
- Predicting housing prices
- Predicting sales revenue
- Predicting BMI based on height and weight

### Logistic Regression

1. Logistic Regression is a supervised classification algorithm. It is used to predict a binary outcome (1 / 0, yes / no, true / false) given a set of independent variables.
2. In Logistic Regression, the dependent variable (target) is a binary variable that contains only two possible categories. The goal is to use an algorithm to predict the binary target variable based on the values of the independent variables.
3. The algorithm involves developing a better-fit logistic regression model based on the training dataset and using it to predict the outcome for new data.
4. The logistic regression model is:
$$h(x) = \frac{1}{1 + e^{-(w^Tx+b)}}$$
Where
- $h(x)$ is the hypothesis function
- $w$ is the weight vector
- $x$ is the input vector
- $b$ is the bias

5. The probability that the outcome is 1 is given by $h(x)$. Hence, to get the final class, we threshold $h(x)$ at 0.5, i.e. if $h(x) \geq 0.5$, then predict 1 (True), else predict 0 (False).
6. The weights ($w$) and bias ($b$) are estimated using Maximum Likelihood Estimation. The model performance can be evaluated using confusion matrix, accuracy, precision, recall, F1 score, etc.

### BAYESIAN LEARNING for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Bayesian learning is a method of statistical inference in which Bayes' theorem is used to update the probability estimate for a hypothesis as more evidence or information becomes available.
2. In Bayesian learning, we start with an initial probability distribution over the hypotheses and then update this distribution based on the data. The strength of Bayesian learning is that it allows you to incorporate your prior beliefs and update them in the light of observed data.
3. The steps involved in Bayesian learning are:

- Specify a prior distribution over the hypotheses (represent initial beliefs)
- Obtain data (evidence)
- Calculate the likelihood of the data under each hypothesis
- Apply Bayes' theorem to obtain the posterior distribution over hypotheses
- Make predictions or decisions based on the posterior distribution

4. Some advantages of Bayesian learning are:

- It allows you to incorporate prior knowledge into the model.
- It gives you a natural way to handle both parametric and structural uncertainty.
- It provides a principled way to incorporate new data and update beliefs.
- It allows you to compare models and weigh evidence.

5. Some disadvantages of Bayesian learning are:

- It can be computationally intensive.
- The choice of prior distribution can influence results.
- It is not always straightforward to specify priors.

6. Examples of Bayesian learning applications include spam filtering, speech recognition, computer vision, expert systems, etc.

### Bayes theorem for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Bayes theorem is a statistical theorem that provides a way to update the probability of an event given some evidence or new information.
2. It uses prior probabilities andconditional probabilities to calculate the posterior probability.
3. The formula for Bayes theorem is:
 Posterior probability = Likelihood x Prior probability / Evidence
4. It is commonly used in regression models in Machine Learning to compute the probabilities of the predictions and determine the confidence in those predictions.
5. Some key terms used in Bayes theorem are:
 - Prior probability: The initial probability of an event. Denoted as P(A)
 - Likelihood: The probability of evidence given an event. Denoted as P(E|A)
 - Posterior probability: The updated probability of an event after seeing evidence. Denoted as P(A|E)
 - Evidence: The new information observed. Denoted as E
6. Bayes theorem allows updating the probabilities as more evidence or information becomes available. This makes the predictions more accurate as the model gets trained on more data.
7. Some applications of Bayes theorem in regression are:
 - Gaussian Naive Bayes
 - Bayesian linear regression
 - Bayesian logistic regression

### Bayes Optimal Classifier for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Bayes Optimal Classifier is a classifier that minimizes the probability of error by providing the optimal decision boundary.
2. It uses the Bayesian probability theory which calculates the probability of an event occurring based on prior knowledge of conditions that might be related to the event.
3. The optimal decision boundary is the one that maximizes the posterior probability of the correct class given the input features.
4. The key steps to construct a Bayes Optimal classifier are:

- Calculate the probability density functions for each class.
- Calculate the prior probabilities of each class.
- Apply Bayes' theorem to calculate the posterior probabilities of each class given the features.
- Choose the class with the highest posterior probability as the prediction.

5. Some pros of Bayes Optimal classifier are:

- It is optimal in the sense of minimizing probability of error.
- It takes into account the costs of misclassification in its output.

6. Some cons are:

- It requires the knowledge of probability density functions of the features conditioned on each class which is difficult to determine in practice.
- It can be computationally intensive if the dimensions of the feature space are high.

7. Bayes Optimal classifier serves as a benchmark to evaluate the performance of other practical classifiers.

### EM algorithm for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Introduction
- EM stands for Expectation Maximization. It is a iterative method to find maximum likelihood estimates of parameters in statistical models.
- It is used when there are latent variables or hidden variables whose values are not directly observable.
- It alternates between performing an expectation (E) step, which computes the expectation of the log-likelihood evaluated using the current parameter estimates, and a maximization (M) step, which computes parameters by maximizing the expected log-likelihood found on the E step. These parameter-estimates are then used to determine the distribution of the latent variables in the next E step.

2. Steps in EM algorithm
- E-step: Compute the expected value of the complete-data log-likelihood using the current parameter estimates.
- M-step: Maximize the expected log-likelihood from the E-step to compute new parameter estimates.
- Repeat E-step and M-step until convergence.

3. Applications of EM algorithm
- Used in data clustering algorithms like Gaussian Mixture Models (GMM).
- Used for estimating parameters of Hidden Markov Models (HMM).
- Used for dimensionality reduction techniques like Factor Analysis.
- Used to estimate parameters of linear regression models with missing data.

4. Advantages and Disadvantages
- Advantage: Guaranteed to find at least local maxima of likelihood function.
- Disadvantage: Can be slow to converge and get stuck in local maxima. Depends on good initial estimates.
- Disadvantage: Does not directly provide measures of uncertainty for parameter estimates. Bootstrap methods may be needed for that.

### Entropy

- Entropy is a measure of uncertainty associated with a random variable. It represents the amount of randomness or disorder in the variable.
- For a discrete random variable X with possible values {x1, x2, ..., xn} and probabilities {p(x1), p(x2), ..., p(xn)} respectively, the entropy is defined as:
H(X) = -∑p(xi)logp(xi)
- The base of the logarithm used in entropy calculation does not matter and can be 2, e or 10. Entropy will be measured in units of bits, nats or hartleys respectively for the three logarithmic bases.
- Entropy has a maximum value when all outcomes are equally likely (max uncertainty) and is 0 when one outcome has probability 1 (no uncertainty).

### Information gain

- Information gain is the decrease in entropy after observing a feature/attribute. It is used to decide which attribute to split on at each node of a decision tree.
- For a dataset S and an attribute A with v possible values {a1, a2, ..., av}, the information gain is:
Gain(S, A) = H(S) - ∑v(|Sv|/|S|)H(Sv)
- where Sv is the subset of S with attribute value av of A, |Sv| is the number of elements in Sv and H(Sv) is the entropy of Sv.
- The attribute with the highest information gain is chosen to split on to produce the most homogeneous subsets possible. This process is repeated on each subset recursively until the stopping criterion is met.

### Derivation of Backpropagation Algorithm

1. Forward propagation: In forward propagation, we calculate the output of each layer based on the inputs and weights. We get the final output of the network.
2. Cost function: We then calculate the cost function which is the error between the predicted output and the actual output. The objective is to minimize the cost function.
3. Backpropagation: In backpropagation, we calculate the gradient of the cost function w.r.t the weights. This is done in the reverse order of forward propagation.
4. Weight update: We then update the weights in the direction of decreasing cost. The weights are updated by subtracting a small value (learning rate) multiplied by the gradients from the weights.
5. Repeat: We repeat steps 1-4 multiple times which is called training the neural network. As we keep updating the weights, the cost function decreases and the model improves.

The key steps in backpropagation are:
1. Calculate the gradient of the cost function w.r.t the output of the last layer
2. Calculate the gradient of the cost function w.r.t the weights of the last layer
3. Repeat the above two steps for the second last layer and so on until we reach the first layer

The derivation involves application of chain rule to calculate the gradients. The goal of backpropagation is to efficiently calculate the gradients which are then used to update the weights and reduce the cost function.

### SOM Algorithm and its variant for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. Self-Organizing Map (SOM) is a type of artificial neural network that is trained using unsupervised learning to produce a low-dimensional, discretized representation of the input space of the training samples, called a map.

2. SOM converts complex, nonlinear statistical relationships in high-dimensional data into simple geometric relationships on a low-dimensional display.

3. The key steps in SOM are:

(a) Initialize the weights of the neurons randomly
(b) Select a random input vector from the input data
(c) Determine the winning neuron i.e. the neuron whose weight vector is closest to the input vector
(d) Update the weights of the winning neuron and its neighboring neurons
(e) Repeat steps #2 through #4 until convergence is reached

4. After training, input vectors that are nearby in the high-dimensional input space produce activation in nearby neurons on the map. This results in a topology-preserving mapping that can be useful for visualization.

5. Some variants of SOM are:

(a) Growing SOM: Starts with a small map size and grows dynamically.
(b) Gradient SOM: Uses a gradient-descent based approach to updating neuron weights.
(c) Batch SOM: Processes input vectors in batches rather than individually.
(d) Encoder SOM: The map dimensions are specified and a decoding mechanism is used to estimate input vectors from map responses.

### Activation function for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. An activation function is a function that is applied at each node of a neural network to determine the output of that node given an input or set of inputs.

2. The purpose of the activation function is to introduce non-linearity into the network. Without an activation function, the outputs of a neural network would be linear combinations of the inputs, and complex relationships would not be learnable.

3. Some commonly used activation functions are:

- Sigmoid: f(x) = 1 / (1 + e^-x)
- Tanh: f(x) = (e^x - e^-x) / (e^x + e^-x)
- ReLU: f(x) = max(0, x)

4. The choice of activation function depends on the problem and the network architecture. For example:

- Sigmoid and Tanh saturate and die off for very large inputs, and tend to work well for networks with floating-point weights and values in a reasonable range.
- ReLU does not saturate and trains much faster than sigmoid/tanh but may be prone to the "dying ReLU" problem where a large gradient can cause a ReLU unit to never activate on any future input. ReLU is a common choice for hidden layers in deep neural networks.

5. An important consideration when choosing an activation function is that it must be differentiable or else it would not be possible to calculate gradients to update the weights in the network. Sigmoid, tanh, and ReLU are all differentiable.

### Q Learning for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Q Learning is a model-free reinforcement learning algorithm. It does not require a model of the environment and can handle problems with stochastic transitions and rewards.
2. The goal of Q Learning is to learn a policy which tells an agent what action to take under what circumstances. It does so by learning an action-value function (Q function) which evaluates the long-term reward for each action in each state.
3. The Q function is estimated based on the agent's interaction with the environment. The agent selects actions and observes rewards and next states. Based on this, it updates its Q estimates, thereby gradually learning to predict the long-term reward of state-action pairs and learning an optimal policy.
4. The Q update rule is:
Q(s, a) = Q(s, a) + alpha * (reward + gamma * max(Q(s', a')) - Q(s, a))
where alpha is the learning rate, gamma is the discount factor, s is the current state, a is the current action, s' is the next state and reward is the immediate reward received after taking action a in state s.
5. As the agent interacts with the environment, its Q estimates get more and more accurate, allowing it to determine better actions to take. An epsilon-greedy policy is commonly used to balance between exploration and exploitation. With probability epsilon, a random action is selected for exploration, otherwise the action with the highest Q value is selected for exploitation.

### Q Learning Algorithm

1. Q Learning is a model-free reinforcement learning algorithm.
2. It learns an action-value function (Q function) that gives the expected reward for taking an action in a given state & following the optimal policy thereafter.
3. The goal is to learn the optimal action-selection policy that maximizes the expected reward over the long run.
4. The Q function is updated using the Bellman equation - Q(s,a) = r + gamma*max[Q(s',a')]. Here, r is the immediate reward, gamma is the discount factor and s' is the next state.
5. The Q-table (table of Q values) is initialized with random values and the agent interacts with the environment, observing rewards and updating Q values based on the rewards.
6. With each interaction, the algorithm converges to the optimal Q-function and optimal policy.
7. The key steps in Q Learning are:
    1. Initialize Q(s,a) arbitrarily
    2. Repeat:
        1. Take action a in state s and observe reward r and next state s'
        2. Compute Q(s,a) = r + gamma * max[Q(s',a')]
        3. Update Q(s,a) = Q(s,a) + alpha * [Q(s,a) - Q(s,a)]
        4. s <- s'
8. Q Learning is a simple yet powerful algorithm that has been applied to a variety of problems. However, it does not scale well to problems with large state-action spaces due to the creation and storage of the Q-table.
