KCS aims to improve service delivery, productivity, cost reduction, and customer satisfaction by creating and maintaining documentation as part of the support process .

Some of the main features of KCS are:

- KCS is based on the principle of "capture, structure, reuse, and improve" knowledge as a by-product of solving problems.
- KCS involves the whole organization, not just the service desk, in creating and using knowledge. KCS encourages collaboration, feedback, and continuous improvement of knowledge.
- KCS uses a demand-driven approach, meaning that knowledge is created and updated based on the needs and requests of the customers and users, not on the assumptions or predictions of the service providers.
- KCS uses a structured format for knowledge articles, with a clear distinction between the problem, the cause, and the resolution. KCS also uses metadata, such as keywords, categories, and status, to make knowledge articles easy to find and use.
- KCS measures the value and quality of knowledge based on its usage and outcomes, not on its quantity or completeness. KCS uses metrics such as reuse rate, resolution time, customer satisfaction, and cost per incident to evaluate the impact of knowledge on service delivery.

### Problem Solving Approach to Typical AI Problems

- Problem solving is one of the main tasks of artificial intelligence. It involves finding a sequence of actions that can transform a given initial state into a desired goal state.
- A typical AI problem can be formulated as a search problem, where the search space consists of all possible states and the search operators are the actions that can change one state into another.
- A search problem can be defined by four components: 
  - A set of states, also called the state space, that represent the possible configurations of the world.
  - A set of operators, also called the actions, that can change one state into another.
  - An initial state, which is the starting point of the search.
  - A goal state, or a set of goal states, which are the desired outcomes of the search.
- A solution to a search problem is a sequence of operators that can transform the initial state into a goal state. A solution can be optimal or suboptimal, depending on the criteria used to evaluate the quality of the solution, such as the length, cost, or utility of the sequence.
- A search algorithm is a method that systematically explores the search space and finds a solution to a search problem. A search algorithm can be characterized by several properties, such as:
  - Completeness: whether it can find a solution if one exists.
  - Optimality: whether it can find the best solution according to some criteria.
  - Time complexity: how long it takes to find a solution in terms of the number of states visited.
  - Space complexity: how much memory it requires to store the states visited.
- Some examples of typical AI problems that can be solved by search algorithms are:
  - Pathfinding: finding the shortest or cheapest path from one location to another on a map or a graph.
  - Puzzle solving: finding the steps to rearrange a set of tiles or pieces into a desired configuration, such as the 8-puzzle or the Rubik's cube.
  - Planning: finding the actions to achieve a set of goals in a dynamic and uncertain environment, such as a robot navigating a warehouse or a game character performing a task.
  - Game playing: finding the best move to make in a competitive or cooperative game, such as chess, tic-tac-toe, or Go.
  - Constraint satisfaction: finding the values for a set of variables that satisfy a set of constraints, such as a sudoku puzzle or a timetable.

### Search Strategies

Search strategies are methods or algorithms that help in solving search problems in artificial intelligence. A search problem consists of a search space, start state, and goal state. Search strategies help the AI agents to attain the goal state through the assessment of scenarios and alternatives.

Search strategies can be classified into two types: uninformed search and informed search.

- Uninformed search: Also known as blind search, it is a search strategy that does not use any domain-specific knowledge or heuristic information to guide the search. It only uses the problem definition and the available operators to explore the search space. Uninformed search strategies are of six types:

  - Breadth-first search: It is a search strategy that expands the shallowest node in the search tree first. It uses a queue data structure to store the nodes and explores all the nodes at a given depth before moving to the next level. It is complete and optimal for problems with uniform path costs, but it has a high space complexity.
  - Depth-first search: It is a search strategy that expands the deepest node in the search tree first. It uses a stack data structure to store the nodes and explores one branch of the tree as far as possible before backtracking. It is incomplete and suboptimal, but it has a low space complexity.
  - Depth-limited search: It is a search strategy that limits the depth of the search tree to a predefined value. It avoids the problem of infinite paths in depth-first search, but it may miss the solution if the depth limit is too small.
  - Iterative deepening depth-first search: It is a search strategy that combines the benefits of breadth-first search and depth-first search. It performs depth-limited search with increasing depth limits until the solution is found or the search space is exhausted. It is complete and optimal for problems with uniform path costs, and it has a low space complexity.
  - Bidirectional search: It is a search strategy that simultaneously searches forward from the start state and backward from the goal state. It stops when the two searches meet in the middle. It is complete and optimal for problems with uniform path costs, and it has a lower time complexity than breadth-first search, but it has a higher space complexity and requires the goal state to be known in advance.
  - Uniform cost search: It is a search strategy that expands the node with the lowest path cost from the start state. It uses a priority queue data structure to store the nodes and explores the nodes in increasing order of their path costs. It is complete and optimal for problems with non-uniform path costs, but it has a high space complexity.

- Informed search: Also known as heuristic search, it is a search strategy that uses domain-specific knowledge or heuristic information to guide the search. It estimates the cost or distance of reaching the goal state from each node and selects the node with the lowest value. Informed search strategies are of four types:

  - Greedy search: Also known as best-first search, it is a search strategy that expands the node that appears to be closest to the goal state. It uses a heuristic function that estimates the cost of reaching the goal state from each node and selects the node with the lowest value. It is incomplete and suboptimal, but it has a low time complexity.
  - A* search: It is a search strategy that minimizes the total estimated solution cost, that includes the cost of reaching a node from the start state and the cost of reaching the goal state from that node. It uses a heuristic function that combines both costs and selects the node with the lowest value. It is complete and optimal for problems with admissible and consistent heuristics, but it has a high space complexity.
  - Hill climbing search: It is a search strategy that moves in the direction of increasing heuristic values until it reaches a local maximum or a plateau. It is a variant of greedy search that does not maintain a search tree and only keeps track of the current node. It is incomplete and suboptimal, but it has a low space and time complexity.
  - Simulated annealing search: It is a search strategy that avoids getting stuck in local maxima or plateaus by allowing some downhill moves with a decreasing probability. It is inspired by the physical process of annealing, where a solid is heated and then slowly cooled to reach a low-energy state. It is complete and optimal for problems with infinite search spaces, but it has a high time complexity and requires a suitable cooling schedule.



### Uninformed Search Methods

Uninformed search methods are a type of search algorithms that do not use any additional information to guide the search process. They only use the information provided in the problem definition, such as the start state, the goal state, and the actions that can be performed in each state. Uninformed search methods explore the search space in a systematic, but blind, manner without considering the cost of reaching the goal or the likelihood of finding a solution. Some of the key features of uninformed search methods are:

- Systematic exploration: Uninformed search methods explore the search space systematically, either by expanding all children of a node (e.g. breadth-first search) or by exploring as deep as possible in a single path before backtracking (e.g. depth-first search).
- No heuristics: Uninformed search methods do not use any additional information, such as heuristics or cost functions, to estimate the quality of a node or a path. They only check if a node is a goal state or not.
- Completeness: Uninformed search methods are guaranteed to find a solution if one exists, as long as the search space is finite and the branching factor is finite.
- Optimality: Uninformed search methods are not guaranteed to find the optimal solution, unless they explore all possible paths to the goal state. Some uninformed search methods, such as uniform-cost search, can find the optimal solution if the path cost is a non-decreasing function of the depth of the node.
- Time and space complexity: Uninformed search methods have high time and space complexity, as they may generate and store a large number of nodes in the search space. The time and space complexity depend on the branching factor, the depth of the solution, and the depth of the search tree.

Some of the common uninformed search methods are:

- Depth-first search (DFS): It is a search algorithm that explores the search tree from the root node and goes as deep as possible in a single path before backtracking. It uses a stack data structure to store the nodes to be expanded. It is not complete in infinite or cyclic graphs, and it is not optimal in general. It has a time complexity of O(b^m) and a space complexity of O(bm), where b is the branching factor and m is the maximum depth of the search tree.
- Breadth-first search (BFS): It is a search algorithm that explores the search tree from the root node and expands all the nodes at a given depth before moving to the next depth level. It uses a queue data structure to store the nodes to be expanded. It is complete and optimal for uniform-cost problems, where all actions have the same cost. It has a time complexity of O(b^d) and a space complexity of O(b^d), where b is the branching factor and d is the depth of the solution.
- Uniform-cost search (UCS): It is a search algorithm that expands the node with the lowest path cost from the root node. It uses a priority queue data structure to store the nodes to be expanded, where the priority is the path cost. It is complete and optimal for any problem with a non-decreasing path cost function. It has a time complexity of O(b^1 + C*/ε) and a space complexity of O(b^1 + C*/ε), where b is the branching factor, C* is the optimal path cost, and ε is the minimum action cost.
- Depth-limited search (DLS): It is a search algorithm that explores the search tree from the root node and goes as deep as a given limit before backtracking. It uses a stack data structure to store the nodes to be expanded. It is not complete and not optimal in general. It has a time complexity of O(b^l) and a space complexity of O(bl), where b is the branching factor and l is the depth limit.
- Iterative deepening search (IDS): It is a search algorithm that combines the benefits of DFS and BFS. It performs a series of DLS with increasing depth limits until a solution is found or the search space is exhausted. It is complete and optimal for uniform-cost problems. It has a time complexity of O(b^d) and a space complexity of O(bd), where b is the branching factor and d is the depth of the solution.



### Informed Search

Informed search is a type of search algorithm that uses additional information or heuristics to guide the search process towards the goal state. Informed search algorithms are also called heuristic search algorithms. Heuristics are functions that estimate the cost or distance from a given state to the goal state. Heuristics can help to reduce the search space and speed up the search process.

Some examples of informed search algorithms are:

- **Best-first search**: This is a general search strategy that expands the most promising node according to a given heuristic function. Best-first search can be seen as a combination of depth-first search and breadth-first search, where the depth or breadth is determined by the heuristic value of each node. Best-first search can be further classified into different variants, such as greedy best-first search, A* search, and beam search.
- **Greedy best-first search**: This is a type of best-first search that always expands the node that is closest to the goal, according to the heuristic function. Greedy best-first search is not guaranteed to find the optimal solution, as it may get stuck in local minima or dead ends. However, it can be fast and efficient for some problems.
- **A* search**: This is a type of best-first search that balances the cost of the path so far and the estimated cost to the goal, according to the heuristic function. A* search is guaranteed to find the optimal solution, if the heuristic function is admissible and consistent. An admissible heuristic is one that never overestimates the cost to the goal, and a consistent heuristic is one that satisfies the triangle inequality. A* search can be optimal and efficient, but it may also require a lot of memory to store the nodes in the search tree.
- **Beam search**: This is a type of best-first search that limits the number of nodes that are expanded at each level, according to a given beam width. Beam search can reduce the memory requirements of best-first search, but it may also miss the optimal solution or fail to find any solution at all. Beam search can be seen as a trade-off between breadth-first search and depth-first search, where the beam width determines the degree of exploration or exploitation.

### Backtracking Search

- Backtracking search is a technique for solving constraint satisfaction problems (CSPs), which are problems where the goal is to find an assignment of values to a set of variables that satisfies a set of constraints.
- A CSP can be represented by a set of variables X = {X1, X2, ..., Xn}, a set of domains D = {D1, D2, ..., Dn}, where Di is the set of possible values for Xi, and a set of constraints C = {C1, C2, ..., Cm}, where each constraint Ci involves some subset of variables and specifies the allowed combinations of values for that subset.
- A solution to a CSP is a complete assignment of values to all variables that satisfies all constraints.
- Backtracking search is a recursive algorithm that tries to find a solution by exploring the space of partial assignments, starting from an empty assignment and extending it one variable at a time.
- At each step, the algorithm chooses an unassigned variable and tries each value in its domain, checking if the value is consistent with the current partial assignment and the constraints. If the value is consistent, the algorithm recurses on the next variable. If the value is inconsistent, the algorithm backtracks and tries another value for the previous variable. If all values for a variable are exhausted, the algorithm returns failure.
- Backtracking search can be improved by using various heuristics and techniques, such as:

  - Variable ordering: choosing the next variable to assign based on some criteria, such as the minimum remaining values (MRV) heuristic, which selects the variable with the fewest legal values left, or the degree heuristic, which selects the variable with the most constraints on the remaining variables.
  - Value ordering: choosing the order of values to try for a variable based on some criteria, such as the least constraining value (LCV) heuristic, which selects the value that rules out the fewest values for the remaining variables.
  - Forward checking: keeping track of the remaining legal values for the unassigned variables and pruning the domains of the variables that are affected by the current assignment, thus reducing the branching factor and detecting failures earlier.
  - Arc consistency: enforcing a stronger form of consistency between pairs of variables, such that for every value in the domain of one variable, there is at least one consistent value in the domain of the other variable.   - Backjumping: a form of backtracking that jumps back more than one level when a dead end is reached, thus avoiding revisiting the same partial assignments. ### Reasoning with Default Information

- Reasoning with default information is a form of non-monotonic reasoning that allows for drawing plausible conclusions from incomplete or uncertain premises by using general rules that may have exceptions .
- Non-monotonic reasoning is a type of reasoning that does not follow the principle of monotonicity, which states that adding new information to a set of premises cannot reduce the set of conclusions that can be derived from them.
- Reasoning with default information is useful in artificial intelligence because it can model common sense reasoning, where humans often make assumptions based on typical or normal situations, but are willing to revise them when they encounter exceptions or contradictory evidence  .
- There are different formalisms for reasoning with default information, such as default logic, circumscription, autoepistemic logic, and defeasible logic . They differ in how they represent and apply default rules, how they handle conflicts and inconsistencies, and how they cope with incomplete or unknown information .
- A default rule is a rule that has the form: if P, then normally Q, where P is the prerequisite, Q is the consequent, and normally is a modal operator that indicates that Q is true in most cases, but not necessarily in all cases  . For example, a default rule could be: if X is a bird, then normally X can fly.
- A default rule can be applied to a set of premises if the prerequisite is consistent with the premises, and the consequent is not contradicted by the premises  . For example, given the premise that Tweety is a bird, we can apply the default rule above and conclude that Tweety can fly, unless we have additional information that Tweety is an exception, such as Tweety is a penguin.
- A default rule can be retracted or overridden if new information shows that the case at hand is exceptional or that the rule is invalid  . For example, if we learn that Tweety is a penguin, we have to retract our previous conclusion that Tweety can fly, and apply a different default rule: if X is a penguin, then normally X cannot fly.
- A default rule can be protected or preserved if new information is irrelevant or does not affect the validity of the rule  . For example, if we learn that Tweety is blue, we do not have to retract our previous conclusion that Tweety can fly, because the color of Tweety does not affect its ability to fly.
- Reasoning with default information involves two types of default rules: expectation-evoking and explanation-evoking. Expectation-evoking rules are used to generate hypotheses or predictions based on typical or normal situations, while explanation-evoking rules are used to provide justifications or causes based on plausible or reasonable situations. For example, an expectation-evoking rule could be: if X is a student, then normally X studies hard, while an explanation-evoking rule could be: if X studies hard, then normally X is a student.

### Language Models

- A language model is an AI model that has been trained to predict the next word or words in a text based on the preceding words.
- Language models can be classified into two categories: statistical and neural.
- Statistical language models use probability distributions to estimate the likelihood of a word given its context. They can be further divided into subtypes such as unigram, n-gram, and exponential language models.
- Unigram language models assume that each word is independent of the others and use the frequency of each word in the corpus to calculate its probability.
- N-gram language models use the previous n-1 words as the context and use the frequency of each n-gram in the corpus to calculate its probability.
- Exponential language models use a weighted combination of features such as word identity, part-of-speech, and syntactic structure to calculate the probability of a word given its context.

### Machine Translation

- Machine translation (MT) is the task of automatically translating text or speech from one natural language to another.
- MT is one of the oldest and most challenging applications of artificial intelligence, as it requires understanding the meaning and context of the source language and generating fluent and accurate text or speech in the target language.
- MT can be classified into different types based on the level of analysis and the method of translation:

  - **Direct translation**: This is the simplest type of MT, where each word or phrase in the source language is replaced by a corresponding word or phrase in the target language, without any analysis of the structure or meaning of the sentences. This type of translation is fast and easy to implement, but often produces inaccurate and ungrammatical results, as it does not account for the differences in syntax, morphology, semantics, pragmatics, and culture between languages.
  - **Rule-based translation**: This type of MT uses a set of linguistic rules and dictionaries to analyze the source language and generate the target language. The rules can be based on the grammar, syntax, semantics, and pragmatics of the languages, and can be manually crafted or learned from parallel corpora (texts that are aligned in both languages). Rule-based translation can produce more accurate and consistent results than direct translation, but it requires a lot of human expertise and effort to develop and maintain the rules and dictionaries, and it may not be able to handle novel or ambiguous expressions or idioms.
  - **Statistical translation**: This type of MT uses statistical models and machine learning algorithms to learn the probabilities of translating words, phrases, or sentences from the source language to the target language, based on large amounts of parallel corpora. Statistical translation does not rely on linguistic rules or dictionaries, but instead learns from data. Statistical translation can handle novel and ambiguous expressions or idioms, and can adapt to different domains and genres, but it may produce ungrammatical or nonsensical results, and it requires a lot of computational resources and data to train and run the models.
  - **Neural translation**: This type of MT uses neural networks, such as recurrent neural networks (RNNs), convolutional neural networks (CNNs), or transformers, to encode the source language into a vector representation and decode it into the target language. Neural translation can capture the semantic and contextual information of the source language and generate fluent and natural text or speech in the target language, and it can also learn from monolingual corpora (texts that are only in one language) or multilingual corpora (texts that are in more than two languages). Neural translation can produce high-quality and state-of-the-art results, but it may also generate errors or hallucinations, and it requires a lot of computational resources and data to train and run the networks.

- MT can also be classified into different types based on the mode of translation:

    - **Text-to-text translation**: This is the mode of MT where the input and output are both written text. This is the most common and widely used mode of MT, as it can be applied to various domains and purposes, such as web pages, documents, books, subtitles, etc.
    - **Speech-to-text translation**: This is the mode of MT where the input is speech and the output is written text. This mode of MT can be useful for transcribing audio or video recordings, or for providing captions or subtitles for speech content.
    - **Text-to-speech translation**: This is the mode of MT where the input is written text and the output is speech. This mode of MT can be useful for providing audio or voice output for text content, or for generating synthetic speech in different languages.

### Hardware for Artificial Intelligence

Hardware for artificial intelligence (AI) refers to the specialized computer hardware that is used to execute AI programs faster and with less energy. Hardware for AI can be classified into four main types:

- **CPU** – Central Processing Units are the general-purpose processors that can handle a variety of tasks. CPUs are composed of a few cores that can perform complex operations on large amounts of data. CPUs are suitable for sequential and branching logic, but not for parallel processing or matrix operations that are common in AI applications.
- **GPU** – Graphics Processing Units are chips designed to speed up multidimensional data processing, such as images, videos, or neural networks. GPUs are made up of thousands of smaller cores that can work independently on a subspace of input data that requires heavy computing. GPUs are suitable for parallel processing and matrix operations, but not for sequential and branching logic.
- **FPGA** – Field Programmable Gate Arrays are chips that can be configured to implement any logic function. FPGAs are composed of a large array of logic blocks that can be interconnected to form custom circuits. FPGAs are suitable for low-latency and high-throughput applications, but not for complex and dynamic logic.
- **ASIC** – Application Specific Integrated Circuits are chips that are designed for a specific purpose. ASICs are composed of hardwired logic that can perform a predefined function. ASICs are suitable for high-performance and low-power applications, but not for flexibility and scalability.

Modern AI systems often combine powerful multicore CPUs to solve parallel processing with dedicated hardware such as GPUs or FPGAs to accelerate specific tasks. Some examples of dedicated hardware for AI are:

- **Tensor Processing Units (TPUs)** – ASICs developed by Google to accelerate tensor operations for deep learning. TPUs are designed to perform matrix multiplication and activation functions with high efficiency and low precision.
- **Neural Processing Units (NPUs)** – ASICs developed by various companies to accelerate neural network inference for edge devices. NPUs are designed to perform convolution, pooling, and normalization operations with low power consumption and high accuracy.
- **Vision Processing Units (VPUs)** – ASICs developed by various companies to accelerate computer vision tasks for edge devices. VPUs are designed to perform feature extraction, object detection, and face recognition operations with low latency and high reliability.

Hardware for AI is an active and evolving research area that aims to develop new devices and architectures to support the tremendous processing power AI requires to realize its full potential. Some of the emerging trends and challenges in hardware for AI are:

- **Neuromorphic computing** – The design of hardware that mimics the structure and function of biological neural networks. Neuromorphic computing aims to achieve high performance, low power, and adaptive learning capabilities by using analog, digital, or hybrid circuits that emulate neurons and synapses.
- **Quantum computing** – The use of quantum mechanical phenomena to perform computation. Quantum computing aims to achieve exponential speedup, superposition, and entanglement by using quantum bits (qubits) that can exist in two states simultaneously and interact with each other.
- **Memory-centric computing** – The integration of memory and computation in the same device or chip. Memory-centric computing aims to overcome the bottleneck of data movement between memory and processing units by using novel materials, devices, and architectures that enable in-memory computing.
