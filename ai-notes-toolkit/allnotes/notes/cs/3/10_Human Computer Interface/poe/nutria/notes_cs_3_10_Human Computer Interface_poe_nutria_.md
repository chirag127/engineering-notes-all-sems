### A Brief History of Screen Design

2. In the 1980s, Apple released the first Macintosh computer which featured a GUI and a mouse. This was the first commercially successful GUI and it revolutionized computing.

3. In the 1990s, Microsoft released Windows 95 which featured a more modern GUI and was the first operating system to use a taskbar.

4. In the 2000s, touchscreen technology was developed which allowed users to interact with a computer directly through their fingers. This technology has been used in smartphones, tablets, and other devices.

5. In the 2010s, high-resolution displays and high-dpi screens have become more common. This has allowed for more precise and detailed user interfaces.

### The Graphical User Interface

1. A graphical user interface (GUI) is a type of user interface that allows users to interact with electronic devices through graphical icons and visual indicators such as secondary notation, rather than text-based user interfaces, typed command labels or text navigation. 
2. GUIs were introduced in reaction to the perceived steep learning curve of command-line interfaces (CLIs), which require commands to be typed on a computer keyboard.
3. The actions in a GUI are usually performed through direct manipulation of the graphical elements.
4. Commonly used in the form of a desktop environment, a GUI permits the user to effectively control the computer or other device using visual indicators and graphical icons.
5. A GUI typically comes bundled with the operating system of a computer and provides an easy-to-use interface for performing basic tasks such as navigating folders and launching applications.
6. Some popular GUI operating systems include Microsoft Windows, Apple macOS, and Linux.
