### Search Strategies for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Breadth First Search (BFS):
- Explores adjacent nodes first before going to deeper levels.
- Uses a queue data structure.
- Guarantees the shortest path.
- Complexity: O(b^d) where b is the branching factor and d is the depth of the tree.

2. Depth First Search (DFS):
- Goes deeper into the tree along each branch before backtracking.
- Uses a stack data structure.
- Does not guarantee the shortest path.
- Complexity: O(b^d) where b is the branching factor and d is the depth of the tree.

3. Greedy Best First Search:
- Estimates the cost to reach the goal and always expands the node that appears to be the best choice.
- Does not guarantee optimal solutions.
- Complexity: Difficult to analyze.

4. A* Search:
- Combines greedy and breadth first approach.
- Calculates a score (f(n)) = g(n) + h(n) to determine which node to expand next where g(n) is the real cost to reach the node and h(n) is the estimated cost to reach goal from that node.
- Guarantees optimal solutions if the heuristic (h(n)) underestimates the real cost to reach the goal.
- Complexity: O(b^d) where b is the branching factor and d is the depth of the tree.

### Local Search Algorithms and Optimization Problems

1. Local search algorithms start with an initial solution and iteratively try to find a better solution in the neighborhood of the current solution.
2. The neighborhood of a solution is the set of solutions that can be reached from the current solution by applying one modification. For example, in the traveling salesman problem, the neighborhood of a tour is the set of tours that can be obtained by interchanging two cities in the current tour.
3. Local search algorithms get trapped in local optima, that is, solutions that are optimal within their neighborhood but not necessarily global optima. To avoid local optima, techniques like simulated annealing, tabu search, and genetic algorithms are used.
4. An optimization problem involves finding the best solution from among a set of possible solutions. The quality of a solution is measured using a cost function. The goal is to minimize the cost function.
5. Examples of optimization problems are the traveling salesman problem, graph coloring, job scheduling, and network routing. These problems are NP-hard, so approximate solutions are found using heuristic search techniques.

### Searching with Partial Observations

- Searching with partial observations refers to searching a problem space when only partial information about the current state is known.
- This is common in real-world problems where full observability of the current state is not possible.
- Methods like Hill-climbing search and simulated annealing cannot be directly applied as the evaluation function cannot be fully defined with partial observations.
- Some approaches for searching with partial observations:
    - Myopic search: Expands the node that appears best based on available information. This can lead to getting trapped in local optima.
    - Non-myopic search: Some lookahead is performed to prevent myopic behavior. But this can increase computational requirements.
    - Memory-based search: Past experiences are stored and used to determine the next move. But this may not always be optimal if situations differ.
    - Randomized search: Some randomness is incorporated to explore unseen areas of the search space. But may be inefficient if randomness dominates.
- An appropriate strategy needs to be designed based on the specifics of the problem and availability of observations. There is no general optimal solution for all problems with partial observability.

### Constraint Propagation for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Constraint propagation is a technique used to reduce the search space in problem solving by detecting and removing inconsistent values.
2. It works by propagating the constraints forward to remove values that violate the constraints.
3. For example, if X > Y is a constraint and X = 5 is given, we can infer that Y cannot be 6 or more. So we can remove the values 6, 7, 8, etc. for Y. This is constraint propagation.
4. It is commonly used in tasks like sudoku solving, crossword solving, etc. to effectively prune the search space and arrive at the solution faster.
5. The types of constraints that can be propagated are:

- Equality constraints: X = Y
- Inequality constraints: X > Y, X >= Y, X < Y, X <= Y
- Set constraints: X belongs to set S

6. The constraint propagation process continues until no more inconsistent values can be eliminated or a contradiction is reached. In the latter case, backtracking is required.
7. Constraint propagation is a preprocessing step that is used to simplify problems and reduce the search space before using other search techniques like backtracking, hill climbing, etc. It speeds up the search process and increases the efficiency of problem solving.

### Backtracking Search

- Backtracking search is a general algorithmic technique that considers all possible solutions and recursively builds them up step by step.
- It is used to find all (or some) possible solutions of a computational problem by incrementally building candidate solutions until a solution is found or the candidate is determined to be invalid. In the latter case, the candidate is discarded and another one is built.
- The basic idea is to recursively enumerate all candidate solutions and check if each candidate satisfies the problem's constraints. If so, it is a valid solution. Otherwise, the search terminates.
- The key point is to intelligently "prune" the search space using constraints/heuristics to avoid unnecessary exploration of infeasible paths.
- For example, backtracking search can be used to solve constraint satisfaction problems, including graph coloring, map coloring, Hamiltonian path/cycle problems, etc.
- The steps in backtracking search are:

1. Start with the initial state/partial solution
2. Check if the current partial solution satisfies the goal. If yes, display the solution and return.
3. Otherwise, consider the next possible move/extension of the current partial solution.
4. For each possible move, recursively call the backtrack routine to continue the search.
5. If all moves have been tried and no solution has been found, undo the last move and return to the previous state to try the next move.
6. Repeat steps 3-5 until a solution is found or all possibilities have been explored without success.

- The key advantage is that it guarantees to find all (or some) solutions if present. However, the exponential time complexity is a disadvantage due to exploring many infeasible paths. Heuristics and pruning can help address this to some extent.

### Optimal Decisions in Games

- Games involve making decisions to achieve a goal. The decisions are made to maximize the reward or minimize the cost.
- The optimal decision is the one that leads to the best possible outcome. To find the optimal decision, we evaluate all possible decisions and their outcomes and choose the one with the maximum reward or minimum cost.
- Games can be classified into two types:
    - Zero-sum games: The reward for one player is the cost for the other player. The sum of all rewards is zero. For example, chess is a zero-sum game.
    - Non-zero-sum games: The reward or cost for one player does not necessarily lead to the equal and opposite reward or cost for the other player. The sum of all rewards can be non-zero. For example, collaborative games are non-zero-sum games.
- To find the optimal decision in games, we can use:
    - Minimax algorithm: For zero-sum games, to find the decision that minimizes the maximum possible loss.
    - Alpha-beta pruning: An optimization technique for the minimax algorithm to reduce the search space.
    - Expectiminimax algorithm: For non-zero-sum games, to find the decision that maximizes the minimum expected utility.
    - Recursive algorithms: As the number of decisions and outcomes increase, the algorithms become computationally expensive. Pruning techniques and approximations are used to overcome this.

### Alpha – Beta Pruning

- Alpha-beta pruning is a search algorithm technique to reduce the number of nodes that are evaluated in minimax algorithm.
- It ensures that the nodes which do not influence the final decision are not evaluated, thereby speeding up the minimax algorithm.
- It works by maintaining two values, alpha and beta, which keep track of the minimum value that the maximizing player can achieve and the maximum value that the minimizing player can achieve respectively.
- These values are updated at each level of the tree and the subtrees which cannot influence the final decision are pruned.
- The basic idea is that if we have found a value v for the maximizing player that is greater than the current minimum value for the minimizing player(alpha), then there is no point in exploring the other child nodes of the maximizing player as they won't produce a greater value. Similarly, if we have a value v for the minimizing player that is less than the current maximum value for the maximizing player(beta), then there is no need to explore the other child nodes of the minimizing player.
- This results in the reduction of the search space and allows faster decision making.

### Stochastic Games

- Stochastic games are a generalization of Markov decision processes (MDPs) to multiple agents.
- In stochastic games, there are multiple players, each with their own set of actions and rewards.
- The dynamics of the game evolve according to a Markov process, but the transition probabilities and rewards now depend on the joint actions of all players.
- Solving a stochastic game means finding a Nash equilibrium, i.e. a joint strategy profile from which no player has an incentive to deviate unilaterally.
- The Markov property of stochastic games allows the use of dynamic programming methods to solve for Nash equilibria, analogous to solving MDPs.

### Backward Chaining for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Backward chaining is a reasoning technique which starts with the goal and works backwards to find ways of achieving it.
2. It is used in expert systems and logic-based systems.
3. The steps involved in backward chaining are:
- Identify the goal clause.
- Check if the goal clause is a known fact. If yes, then stop. If no, then proceed to the next step.
- Identify an antecedent of the goal clause. This is a subgoal that can lead to achieving the goal.
- Check if the subgoal is a known fact. If yes, then substitute and proceed to the next subgoal. If no, then make it the current goal and go to step 2.
4. Repeat step 3 until a known fact is reached or no more antecedents are left. If a known fact is reached, the goal is achieved. If no antecedents are left, the goal cannot be achieved.
5. Backward chaining has the advantage that the lines of reasoning are goal-directed. The disadvantage is that it may search through a large number of alternatives before finding a solution or determining that no solution exists.

### Reasoning with Default Information for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Default reasoning is used when there is incomplete information. It involves inferring conclusions based on default assumptions.
2. A default rule is of the form:
IF conditions THEN conclusion UNLESS exception
3. The default conclusion is inferred if the exception does not hold, even if the conditions are not known to hold.
4. For example, a default rule could be:
IF x is a bird THEN x can fly UNLESS x is a penguin
5. This allows us to conclude that Tweety can fly even without knowing that Tweety is a bird, as long as we know Tweety is not a penguin.
6. Default rules are useful as they allow reasoning with incomplete information. However, incorrect conclusions may be reached if an exception holds that we are not aware of.
7. To handle this, a default theory may specify multiple default rules and the strengths of exceptions. The conclusion is then based on the strongest applicable rule.
8. Default logic provides a formal framework for specifying and reasoning with default rules and theories. It associates a level of justification with each conclusion based on the defaults and facts used to derive it.

1. Information Retrieval (IR) is the process of obtaining relevant information from a collection of documents.
2. The key tasks of IR are:
- Indexing: converting documents into a standardized format that enables efficient search and retrieval.
- Querying: enabling users to search the document collection.
- Retrieval: identifying and returning relevant documents.
3. Indexing approaches:
- Keywords: associating index terms (keywords) with documents.
- Full-text indexes: indexing the words/tokens in the document.
- Concept-based indexing: associating semantic concepts/topics with documents.
4. Query languages:
- Keywords: entering phrases/individual keywords.
- Booleans: combining keywords using AND/OR/NOT.
- Probabilistic: ranking results based on keyword probabilities.
- Vector Space Model: representing queries/documents as vectors, calculating similarity.
5. Evaluation measures:
- Precision: proportion of retrieved documents that are relevant.
- Recall: proportion of relevant documents that are retrieved.
- F-measure: harmonic mean of precision and recall.

### Machine Translation for the notes of the Unit 5 - APPLICATIONS in the subject of ARTIFICIAL INTELLIGENCE KCS.

- Machine Translation is the task of automatically converting text from one human language to another.
- It is one of the most challenging areas of AI research as computers have to account for ambiguity, context, and cultural differences to translate accurately.
- The key steps in Machine Translation are:

1. Text Analysis - Breaking down the input text into words, phrases, and concepts.
2. Transfer - Converting the input into an intermediate representation that can be mapped to the target language.
3. Generation - Producing the target language text from the intermediate representation.

- The two broad approaches to Machine Translation are:

1. Rule-based - Uses handcrafted rules to analyze and generate the translation. These systems are difficult to build and not very robust.
2. Statistical - Uses statistical techniques and large volumes of bilingual text corpora to train Machine Translation models. These models are more robust but often make grammatical mistakes.

- Neural Machine Translation is a type of Statistical Machine Translation that uses Neural Networks to predict the likelihood of a target language sentence. It has achieved significant improvements in the quality of Machine Translation and is the current state-of-the-art approach.

- Evaluation of Machine Translation systems is done using automatic metrics like BLEU score and human evaluation to compare the output translations with reference translations done by humans.

- Machine Translation has applications in facilitating communication across languages, aiding in reading comprehension, and accelerating the distribution of information across the world. However, the output still requires human review for quality and context.

### Speech Recognition for the notes of the Unit 5 - APPLICATIONS in the subject of ARTIFICIAL INTELLIGENCE KCS:

1. Speech recognition is the process of converting spoken words into text. It is used to interact with computers and other devices using voice instead of typing.
2. The speech recognition system receives the speech waveform as audio signal and converts it into a sequence of words.
3. The major steps involved in speech recognition are:
- Speech sampling: The audio signal is first sampled and digitized.
- Feature extraction: Important features are extracted from the raw audio signal like Mel Frequency Cepstral Coefficients (MFCCs).
- Acoustic modeling: The features are matched with the possible words or phrases to find the correct transcription. Statistical models like Hidden Markov Models (HMMs) are used.
- Language modeling: The likelihood of a sequence of words is determined using language models to evaluate the results from acoustic modeling and select the best transcription.
4. Speech recognition has various applications like speech-to-text transcription, voice dialing system, interactive voice response, etc. It makes human-computer interaction more efficient and natural but still faces challenges in recognizing speech in noisy environments or with a broad range of accents.

### Moving for the notes of the Unit 5 - APPLICATIONS in the subject of ARTIFICIAL INTELLIGENCE KCS.

1. Expert Systems
- Systems that contain stored knowledge and inference procedures that can be used to solve problems in a specific domain.
- They are designed to mimic human experts in particular domains.
- Components:
    - Knowledge base: Contains domain-specific information.
    - Inference engine: Applies logical rules to the knowledge base to deduce new conclusions.
    - User interface: Allows users to query the system and receive explanations or answers.
- Examples: Medical diagnosis, technical troubleshooting, financial analysis.

2. Robotics
- Design and construction of robots that can perform physical tasks.
- Robots are designed to perform human tasks with a high degree of repetition and accuracy.
- Components:
    - Mechanical system: Provides motion and the ability to manipulate objects.
    - Sensors: Detect the robot's state and the state of the environment.
    - Controller: Coordinates the robot's actions based on sensory input and tasks.
    - Programming: Sets of instructions that coordinate the robot's functions.
- Examples: Assembly line robots, surgical assist robots, autonomous vehicles.

3. Machine Learning
- Methods that allow AI systems to learn directly from data without being explicitly programmed.
- The systems use data to identify patterns and make predictions or decisions without being explicitly programmed to perform the task.
- Types:
    - Supervised learning: Uses labeled data to learn a function that maps inputs to outputs.
    - Unsupervised learning: Finds hidden patterns in unlabeled data.
    - Reinforcement learning: Learns by interacting with a dynamic environment.
- Examples: Image classification, speech recognition, machine translation, robot control.
