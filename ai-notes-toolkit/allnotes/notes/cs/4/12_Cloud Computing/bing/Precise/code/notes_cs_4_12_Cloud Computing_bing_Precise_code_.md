

## Unit 1 - Introduction To Cloud Computing

Cloud computing is the delivery of computing services, including software, storage, and processing power, over the internet. These services are provided by third-party companies, allowing users to access and use them without the need for local hardware or software.

Some key points to consider when discussing cloud computing include:

1. **Scalability:** Cloud computing allows users to easily scale their computing resources up or down as needed, without the need for significant upfront investment in hardware.

2. **Cost-effectiveness:** By using cloud computing services, users can avoid the costs associated with purchasing, maintaining, and upgrading local hardware and software.

3. **Accessibility:** Cloud computing services can be accessed from anywhere with an internet connection, making it easy for users to work remotely or collaborate with others.

4. **Reliability:** Cloud computing providers typically have multiple data centers and backup systems, ensuring that users' data and applications are always available.

5. **Security:** Cloud computing providers invest heavily in security measures to protect their users' data, and many offer advanced security features such as encryption and access controls.

Overall, cloud computing offers many benefits to users, including scalability, cost-effectiveness, accessibility, reliability, and security. It is an increasingly popular choice for businesses and individuals looking to access computing resources without the need for local hardware or software.



### Definition of Cloud

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.

In simpler terms, cloud computing is the on-demand availability of computing resources as services over the internet. It eliminates the need for enterprises to procure, configure, or manage resources themselves, and they only pay for what they use.

Some key points to remember about cloud computing are:
- It provides on-demand access to computing resources via the internet.
- Resources can include applications, servers, data storage, development tools, networking capabilities, and more.
- These resources are hosted at a remote data center managed by a cloud services provider (or CSP).
- Cloud computing eliminates the need for enterprises to procure, configure, or manage resources themselves.
- Users only pay for what they use.



### Evolution of Cloud Computing

- The evolution of cloud computing can be divided into three basic phases: The Idea Phase, The Pre-Internet Bubble Era, and The Recent Development of Cloud Computing .
- The Idea Phase incepted in the early 1960s with the emergence of utility and grid computing. Joseph Carl Robnett Licklider was the founder of cloud computing .
- The most recent development of cloud computing has evolved from the Web2.0 technology which caters to web applications that facilitate participatory information sharing, interoperability & user-centered design, etc. Examples of Web 2.0 include wikis, blogs, social networking & video sharing .
- New technologies have emerged recently as a result of the growth of cloud computing. The delivery of many, dynamically scalable, virtualized resources as a service through the Internet is known as cloud computing .
- Virtualization changes everything. Twenty years later in the 1970s, IBM released an operating system called VM that allowed multiple virtual systems to run on a single physical system .
- Virtualization for PC-based systems started in earnest. As the Internet grew, so did the demand for virtualization .
- The cloud is born. By the late 1990s, the concept of delivering computing resources through a global network was starting to be called "cloud computing" .
- Distributed Systems, Mainframe computing, and Cluster computing are some of the other important milestones in the evolution of cloud computing .
- Foundational Cloud Computing Trends include Containers, Serverless Computing, and Cloud Security .



### Underlying Principles of Parallel and Distributed Computing

- The terms parallel computing and distributed computing are used interchangeably.
- Parallel computing implies a tightly coupled system.
- Distributed systems refers to a wider class of system, including those that are tightly coupled.
- Parallel computing is characterised by homogeneity of components (Uniform Structure).
- Multiple Processors share the same physical memory in parallel computing.
- In systems implementing parallel computing, all the processors share the same memory. They also share the same communication medium and network. The processors communicate with each other with the help of shared memory.
- Distributed systems, on the other hand, have their own memory and processors.
- Distributed computing is often used in tandem with parallel computing. Parallel computing on a single computer uses multiple processors to process tasks in parallel, whereas distributed parallel computing uses multiple computing devices to process those tasks.




### Cloud Characteristics

Cloud computing is a technology that uses computing resources, including hardware and software, offering services over a network. Here are some of the major characteristics of cloud computing:

### Elasticity in Cloud Computing

Elasticity is a defining characteristic that differentiates cloud computing from previously proposed computing paradigms, such as grid computing. In cloud computing, elasticity is defined as "the degree to which a system is able to adapt to workload changes by provisioning and de-provisioning resources in an autonomic manner, such that at each point in time the available resources match the current demand as closely as possible".

Elasticity in cloud computing is the ability for the organization to adjust its storage requirements in terms of capacity and processing with respect to operational requirements. This has the following benefits:

- Elasticity can refer to ‘cloudbursting’ from on-premises infrastructure into the public cloud for example to meet a sudden or seasonal demand.
- Elasticity can also refer to the ability to grow or shrink the resources used by a cloud-based application.
- Elasticity in cloud computing allows you to scale computer processing, memory, and storage capacity to meet changing demands.
- Scalability will prevent you from having to worry about capacity planning and peak engineering.

## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

Service Oriented Architecture (SOA) is an architectural style that supports service orientation. It is a way of designing, developing, deploying, and managing enterprise systems where services are the primary means of communication and integration.

1. **Service orientation** is a design paradigm that defines the use of services to support the requirements of software users. In a service-oriented architecture, services are the building blocks used to construct applications.

2. **Services** are self-contained, modular components that can be described, published, located, and invoked over a network. They are designed to perform a specific task and can be reused by different applications.

3. **SOA** provides a way to manage the complexity of large-scale distributed systems by breaking them down into smaller, more manageable components. It also promotes loose coupling between components, which makes it easier to change and evolve the system over time.

4. **SOA** can be implemented using a variety of technologies, including web services, messaging, and RESTful APIs. It is not tied to any specific technology or platform.

5. **Benefits of SOA** include increased flexibility, scalability, and reusability, as well as improved alignment between business and IT. It can also help reduce costs by enabling the reuse of existing services and components.

6. **Challenges of SOA** include the need for effective governance, the complexity of managing distributed systems, and the need for a cultural shift towards service orientation.

### Publish, Subscribe Model

The publish/subscribe model is a messaging pattern used in asynchronous communication systems. It is a part of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing. Here are some key points to note:

1. In this model, messages are sent from publishers to subscribers through a message broker or event bus.
2. Publishers send messages without knowing who the subscribers are, and subscribers receive messages without knowing who the publishers are.
3. Subscribers express their interest in receiving certain types of messages by subscribing to a specific topic or pattern.
4. The message broker or event bus is responsible for routing messages from publishers to subscribers based on the topic or pattern.
5. This model allows for loose coupling between publishers and subscribers, as they do not need to know about each other's existence.
6. It also allows for scalability, as new publishers and subscribers can be added without affecting the existing system.
7. Common use cases for the publish/subscribe model include event-driven architectures, message-oriented middleware, and distributed systems.




### Basics of Virtualization

Virtualization is the creation of a virtual version of something, such as an operating system, a server, a storage device, or network resources. It allows multiple operating systems to run on a single physical machine, sharing the underlying hardware resources.

Here are some key points to remember about virtualization:

1. Virtualization enables the creation of virtual machines (VMs), which are isolated environments that can run their own operating systems and applications.
2. Virtualization can improve resource utilization, as multiple VMs can share the same physical resources.
3. Virtualization can also improve security, as each VM is isolated from the others, reducing the risk of a security breach affecting multiple systems.
4. Virtualization can be implemented at different levels, including hardware, operating system, and application virtualization.
5. Virtualization can be used for a variety of purposes, including server consolidation, testing and development, and cloud computing.

Virtualization is a key enabling technology for cloud computing, as it allows multiple customers to share the same physical infrastructure while maintaining isolation and security. It also enables the dynamic allocation of resources, allowing cloud providers to quickly provision and deprovision resources as needed. 




### Types of Virtualization

Virtualization is the process of creating a virtual version of something, such as an operating system, a server, a storage device, or network resources. There are several types of virtualization, including:

1. **Hardware Virtualization**: This type of virtualization involves creating virtual machines that act like real computers with their own operating systems. The virtual machines are created and managed by a hypervisor, which is a software layer that sits between the hardware and the virtual machines.

2. **Operating System Virtualization**: This type of virtualization involves running multiple operating systems on a single physical server. Each operating system runs in its own virtual environment and is isolated from the others.

3. **Storage Virtualization**: This type of virtualization involves creating virtual storage devices that can be used by multiple servers. The virtual storage devices are created and managed by a storage virtualization software layer.

4. **Network Virtualization**: This type of virtualization involves creating virtual networks that can be used by multiple servers. The virtual networks are created and managed by a network virtualization software layer.

5. **Application Virtualization**: This type of virtualization involves running applications in a virtual environment that is isolated from the underlying operating system and hardware. This allows multiple applications to run on a single server without interfering with each other.

These are some of the main types of virtualization used in cloud computing. Each type of virtualization has its own benefits and use cases, and can be used to improve the efficiency and flexibility of IT infrastructure.

### Virtualization Structures

5. **Network virtualization:** This type of virtualization abstracts the physical network infrastructure and presents it as a single logical network. This can improve the efficiency of network utilization and make it easier to manage and allocate network resources.

Virtualization structures are an important part of cloud enabling technologies and service-oriented architecture, as they allow for the efficient sharing of resources and the creation of virtual machines. This can improve the scalability and flexibility of cloud computing systems.

## Unit 3 - Cloud Architecture, Services And Storage

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources. These resources can include networks, servers, storage, applications, and services. Cloud computing allows users to access and use these resources without the need for expertise in, or control over, the underlying technology infrastructure.

### Cloud Architecture

Cloud architecture refers to the design of systems and components needed for cloud computing. Typically, these components include:

- **Front-end platform:** This includes the user interface and the client's computer or device.

- **Back-end platform:** This includes the servers, storage, and other infrastructure components.

- **Cloud-based delivery:** This includes the delivery of software, infrastructure, and platform services over the internet.

- **Network:** This includes the internet and other network connections that enable communication between the front-end and back-end platforms.

### Cloud Services

Cloud services refer to the various services that are delivered over the internet through cloud computing. These services can include:

- **Software as a Service (SaaS):** This refers to the delivery of software applications over the internet. Users can access and use these applications without the need for installation or maintenance.

- **Platform as a Service (PaaS):** This refers to the delivery of a platform for the development, deployment, and management of applications. This allows users to develop and deploy applications without the need for managing the underlying infrastructure.

- **Infrastructure as a Service (IaaS):** This refers to the delivery of computing infrastructure, such as servers, storage, and networking, as a service. This allows users to access and use these resources without the need for managing the underlying physical hardware.

### Cloud Storage

Cloud storage refers to the storage of data on remote servers that can be accessed over the internet. This allows users to store and access their data from anywhere, at any time, without the need for local storage devices. Cloud storage can be used for various purposes, such as backup and disaster recovery, data archiving, and data sharing.

Cloud storage can be delivered through various models, such as public cloud storage, private cloud storage, and hybrid cloud storage. Public cloud storage refers to the storage of data on servers owned and managed by a third-party service provider. Private cloud storage refers to the storage of data on servers owned and managed by the user's organization. Hybrid cloud storage refers to the use of both public and private cloud storage, where some data is stored on public cloud servers and some data is stored on private cloud servers.



### Layered Cloud Architecture Design

1. Layered cloud architecture design is a common approach to organizing cloud computing resources and services.
2. This design involves separating the cloud infrastructure into distinct layers, each with its own specific function and responsibility.
3. The layers in a typical cloud architecture include the infrastructure layer, the platform layer, and the application layer.
4. The infrastructure layer is responsible for providing the physical and virtual resources necessary to support the cloud environment, such as servers, storage, and networking.
5. The platform layer provides the tools and services necessary to develop, deploy, and manage cloud applications, such as operating systems, middleware, and runtime environments.
6. The application layer is where the actual cloud applications reside and is responsible for delivering the functionality and services to the end-users.
7. By separating the cloud infrastructure into distinct layers, it is possible to achieve greater flexibility, scalability, and manageability in the cloud environment.
8. Each layer can be independently scaled and managed, allowing for more efficient use of resources and improved performance.
9. Layered cloud architecture design is widely used in both public and private cloud environments and is a key concept in the field of cloud computing.



### NIST Cloud Computing Reference Architecture

The National Institute for Standard and Technology (NIST) created Special Publication (SP) 500-292, “NIST Cloud Computing Reference Architecture,” in September 2011 to establish a baseline cloud computing architecture. NIST SP 500-292 defines services and relationships between cloud service providers, consumers, and other stakeholders.

The most critical stakeholders in the NIST Cloud Computing Reference Architecture are consumers and providers. The entire architecture, comprising five “Architectural Components,” can be understood as a way of defining the relationships between them.

NIST will lead interested USG agencies and industry to define a neutral cloud computing reference architecture and taxonomy to extend the NIST cloud computing model, to use as a frame of reference to facilitate communication, and to illustrate and understand various cloud services in the context of an overall Cloud Computing Model.

### IaaS (Infrastructure as a Service)

IaaS is one of the three main categories of cloud computing services, alongside Software as a Service (SaaS) and Platform as a Service (PaaS). IaaS provides virtualized computing resources over the internet. It is an instant computing infrastructure, provisioned and managed over the internet.

- IaaS allows users to rent virtualized hardware, such as servers, storage, and networking, from a cloud provider.
- The cloud provider manages the infrastructure, while the user has control over the operating systems, storage, and deployed applications.
- IaaS is a flexible and scalable solution, allowing users to quickly scale up or down their infrastructure as needed.
- IaaS is commonly used for web hosting, virtual data centers, and testing and development environments.
- Some examples of IaaS providers include Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).



### PaaS

PaaS, or Platform-as-a-Service, is a cloud computing model that provides customers a complete cloud platform—hardware, software, and infrastructure—for developing, running, and managing applications without the cost, complexity, and inflexibility that often comes with building and maintaining that platform on-premises.

In general, PaaS solutions have three main parts:
1. Cloud infrastructure including virtual machines (VMs), operating system software, storage, networking, firewalls.
2. Software for building, deploying and managing applications.
3. A graphic user interface, or GUI, where development or DevOps teams can do all their work.

PaaS is a complete cloud environment that includes everything developers need to build, run, and manage applications—from servers and operating systems to all the networking, storage, middleware, tools, and more. It offers a flexible, scalable cloud platform to develop, deploy, run, and manage apps.

PaaS is a complete development and deployment environment in the cloud, with resources that enable you to deliver everything from simple cloud-based apps to sophisticated, cloud-enabled enterprise applications.

### MapReduce

MapReduce is a programming model and an associated implementation for processing and generating large data sets. It is a key component of the Apache Hadoop software framework, which is used for distributed processing of large data sets across clusters of computers.

The MapReduce model consists of two main phases: the Map phase and the Reduce phase. In the Map phase, the input data is divided into chunks and processed in parallel by multiple map tasks. Each map task applies a user-defined function to the input data and generates a set of intermediate key-value pairs.

In the Reduce phase, the intermediate key-value pairs are shuffled and sorted, and then fed into reduce tasks. Each reduce task applies a user-defined function to the key-value pairs with the same key, and generates a set of output values.

The main advantages of the MapReduce model are its simplicity, scalability, and fault-tolerance. It allows developers to easily write programs that can process large amounts of data in parallel, and it automatically handles the distribution of data and computation across the cluster, as well as the recovery from failures.

Some common use cases for MapReduce include:

- Data filtering and transformation
- Aggregation and summarization
- Joining and grouping of data
- Machine learning and data mining

MapReduce is widely used in many industries, including finance, healthcare, retail, and telecommunications, for processing large amounts of data in a scalable and efficient manner. It is an important tool for data scientists and engineers working with big data.
