### Iterative Coding Methodology

Iterative coding methodology is a software development approach that involves building and refining a system through repeated cycles of design, development, and testing. This approach is commonly used in the development of wearable computing, mixed reality, and Internet of Everything (IoE) systems.

1. **Planning:** The first step in the iterative coding methodology is to define the goals and requirements of the system. This involves identifying the target audience, the desired functionality, and the constraints of the system.

2. **Design:** Once the goals and requirements have been defined, the next step is to design the system. This involves creating a detailed plan for how the system will be built, including the architecture, user interface, and data structures.

3. **Development:** After the design has been completed, the next step is to begin developing the system. This involves writing code, integrating components, and testing the system to ensure that it meets the requirements.

4. **Testing:** Once the system has been developed, it must be tested to ensure that it is functioning correctly. This involves running a series of tests to identify any bugs or issues that need to be addressed.

5. **Evaluation:** After the system has been tested, it must be evaluated to determine whether it meets the goals and requirements that were defined during the planning phase. If the system does not meet these requirements, it must be refined and improved through additional iterations of design, development, and testing.

6. **Deployment:** Once the system has been fully developed and tested, it can be deployed for use by the target audience.

The iterative coding methodology is an effective approach for developing complex systems, as it allows for continuous improvement and refinement throughout the development process. This approach is particularly well-suited for the development of wearable computing, mixed reality, and IoE systems, as these technologies are rapidly evolving and require frequent updates and improvements.

### Unit 1 - INTRODUCTION: Circuit Theory

Circuit theory is a fundamental topic in the field of electrical engineering and is essential for understanding the behavior of electronic devices and systems. It is the study of the properties and behavior of electrical circuits, which are networks of interconnected components such as resistors, capacitors, and inductors.

Some key concepts in circuit theory include:
- **Ohm's Law**: This law states that the current flowing through a conductor between two points is directly proportional to the voltage across the two points.
- **Kirchhoff's Laws**: These laws describe the conservation of charge and energy in electrical circuits. Kirchhoff's Current Law (KCL) states that the sum of currents entering a node is equal to the sum of currents leaving the node. Kirchhoff's Voltage Law (KVL) states that the sum of the voltage drops around any closed loop in a circuit is equal to zero.
- **Series and Parallel Circuits**: In a series circuit, components are connected end-to-end such that the same current flows through all of them. In a parallel circuit, components are connected such that the voltage across each component is the same.
- **Thevenin's and Norton's Theorems**: These theorems provide methods for simplifying complex circuits by replacing a network of components with an equivalent circuit consisting of a single voltage or current source and a single resistor.

Circuit theory is a fundamental building block for understanding more advanced topics in electrical engineering, including wearable computing, mixed reality, and the Internet of Everything. It provides the foundation for analyzing and designing electronic systems that can interact with the physical world. Understanding circuit theory is essential for anyone working in these fields.

### Understanding Processing Code Structure

2. **Draw() function:** This function is called repeatedly to update the display. It is used to draw graphics, update animations, and perform other tasks that need to be done repeatedly.

3. **Variables:** Variables are used to store data that can be used and changed throughout the program. Processing has several built-in variable types, including int, float, boolean, and color.

4. **Functions:** Functions are used to organize code into reusable blocks. They can be called from within the setup() and draw() functions, as well as from other functions.

5. **Control structures:** Control structures, such as if statements and for loops, are used to control the flow of the program. They allow the program to make decisions and repeat actions.

6. **Libraries:** Libraries are collections of pre-written code that can be used to add functionality to a Processing program. There are many libraries available for Processing, including libraries for working with sound, video, and 3D graphics.

By understanding the structure of a Processing program, you can begin to write your own programs and create your own interactive graphics and animations. This is an important foundation for further study in the field of wearable computing, mixed reality, and the Internet of Everything.

### Analog to Digital Conversion

This is an important process in the field of Wearable Computing, Mixed Reality, and the Internet of Everything, as it allows for the processing and transmission of data from analog sensors and devices.

1. **Sampling**: The first step in ADC is sampling, where the analog signal is measured at regular intervals. The rate at which the signal is sampled is known as the sampling rate and is measured in Hertz (Hz). The sampling rate must be at least twice the highest frequency component of the analog signal, according to the Nyquist-Shannon sampling theorem, to avoid aliasing.

2. **Quantization**: The next step is quantization, where the sampled signal is rounded to the nearest value in a finite set of discrete levels. The number of levels is determined by the number of bits used to represent the digital signal, with more bits resulting in a higher resolution and more accurate representation of the analog signal.

3. **Encoding**: The final step is encoding, where the quantized signal is converted into a digital code, typically in binary form. This code can then be transmitted, stored, or processed by digital systems.

ADC is a crucial component in many applications, including audio and video recording, data acquisition, and sensor networks. It is important to carefully select the appropriate ADC parameters, such as the sampling rate and resolution, to ensure accurate and reliable conversion of the analog signal.

### Inter-Integrated Circuit

Inter-Integrated Circuit (I2C) is a multi-master, multi-slave, packet switched, single-ended, serial computer bus invented in 1982 by Philips Semiconductor (now NXP Semiconductors). It is widely used for attaching lower-speed peripheral ICs to processors and microcontrollers in short-distance, intra-board communication.

Some key features of I2C include:

- The maximum number of nodes is limited by the address space, and also by the total bus capacitance of 400 pF, which restricts practical communication distances to a few meters.

- Reading configuration data from SPD EEPROMs on DIMMs.
- Reading temperature, voltage, and fan speed from sensors.
- Controlling OLED or LCD displays, including setting contrast and brightness.

Serial Peripheral Interface (SPI) is a synchronous serial communication interface specification used for short-distance communication, primarily in embedded systems. It is a full-duplex, master-slave communication protocol.

- SPI uses four signal lines: Master Out Slave In (MOSI), Master In Slave Out (MISO), Serial Clock (SCK), and Slave Select (SS).
- The master device initiates the communication and controls the clock signal.

### Serial UART Communication

- UART stands for Universal Asynchronous Receiver/Transmitter.
- It is a hardware device for asynchronous serial communication between devices.
- UARTs transmit data asynchronously, meaning there is no clock signal to synchronize the output of bits from the transmitting UART to the sampling of bits by the receiving UART.
- Instead of a clock signal, the transmitting UART adds start and stop bits to the data packet being transferred. These bits define the beginning and end of the data packet so the receiving UART knows when to start reading the bits.
- The receiving UART samples the data line at a specific rate, known as the baud rate, to determine the value of each bit.
- The baud rate is the rate at which information is transferred in a communication channel. It is usually expressed in bits per second (bps).
- The start bit is always a logic low (0) level and the stop bit is always a logic high (1) level.
- The data packet is framed by the start and stop bits, and the data within the frame is transmitted least significant bit (LSB) first.
- UARTs can be configured to transmit and receive different data packet sizes, typically between 5 and 8 bits.
- Parity bits can also be added to the data packet for error detection.
- UARTs are commonly used in microcontroller-based systems to communicate with other devices, such as computers, sensors, and other microcontrollers.
- UART communication can be implemented using hardware or software, with hardware implementations typically being faster and more reliable.
- Common applications of UART communication include GPS receivers, Bluetooth modules, and wireless radio frequency (RF) modules.

### Advanced I/O

1. Advanced I/O refers to the input/output operations that are more complex than the basic read and write operations.
2. These operations can include asynchronous I/O, scatter/gather I/O, and memory-mapped I/O.
3. Asynchronous I/O allows a program to initiate an I/O operation and continue processing without waiting for the operation to complete.
4. Scatter/gather I/O allows a program to read or write data from or to multiple buffers in a single operation.
5. Memory-mapped I/O maps a file or device into the virtual memory space of a program, allowing the program to access the file or device as if it were in memory.
6. These advanced I/O techniques can improve the performance and efficiency of programs that need to perform a large number of I/O operations.
7. They are commonly used in high-performance computing, database systems, and multimedia applications.
8. Advanced I/O is an important topic in the study of Wearable Computing, Mixed Reality, and the Internet of Everything, as these technologies often require efficient and high-speed data transfer and processing.

### sqLite

SQLite is a database engine written in the C programming language. It is not a standalone app; rather, it is a library that software developers embed in their apps. As such, it belongs to the family of embedded databases.

SQLite was designed to allow the program to be operated without installing a database management system or requiring a database administrator. Unlike client–server database management systems, the SQLite engine has no standalone processes with which the application program communicates.

SQLite is an in-process library that implements a self-contained, serverless, zero-configuration, transactional SQL database engine. It is a popular choice as an embedded database for local/client storage in application software such as web browsers. It is also used in many other applications that need a lightweight, embedded database.

SQLite is a C-language library that implements a small, fast, self-contained, high-reliability, full-featured, SQL database engine. SQLite is the most used database engine in the world. SQLite is built into all mobile phones and most computers and comes bundled inside countless other applications that people use every day.

Unlike most other SQL databases, SQLite does not have a separate server process. SQLite reads and writes directly to ordinary disk files. A complete SQL database with multiple tables, indices, triggers, and views, is contained in a single disk file.
