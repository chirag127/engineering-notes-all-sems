## Unit 1 - Understanding the implementation of IOT

- IOT stands for Internet of Things, which refers to the network of physical devices, sensors, actuators, and software that can collect, process, and exchange data over the internet.
- IOT enables various applications and services that can improve the efficiency, convenience, and quality of life for humans and other living beings.
- IOT can be implemented in different domains, such as smart homes, smart cities, smart agriculture, smart healthcare, smart manufacturing, smart transportation, and smart energy.
- IOT devices can communicate with each other and with cloud servers using various protocols, such as MQTT, CoAP, HTTP, and WebSocket.
- IOT devices can use different technologies for connectivity, such as Wi-Fi, Bluetooth, Zigbee, LoRaWAN, cellular, and satellite.
- IOT devices can be classified into three types based on their roles and capabilities: edge devices, gateways, and cloud servers.
- Edge devices are the ones that directly interact with the physical environment and collect data from sensors or control actuators. They can have limited processing and storage capabilities and low power consumption.
- Gateways are the ones that act as intermediaries between edge devices and cloud servers. They can perform data aggregation, filtering, compression, encryption, and protocol translation. They can have moderate processing and storage capabilities and medium power consumption.
- Cloud servers are the ones that provide centralized data storage, analysis, and management. They can perform data processing, visualization, machine learning, and decision making. They can have high processing and storage capabilities and high power consumption.

- IOT Smart Parking Using RFID is a system that aims at replacing the traditional parking system with a high technological, IoT based smart parking system by using RFID (radio-frequency identification) technology .

- The system consists of the following components  :
  - RFID tags: These are attached to the vehicles that want to access the parking slot. They can be passive or active, depending on whether they have a battery or not. Passive tags are cheaper and have a shorter range, while active tags are more expensive and have a longer range.
  - RFID readers: These are installed at the entry and exit gates of the parking slot. They can read the RFID tags and send the data to the server via Wi-Fi or Ethernet.
  - Server: This is the central unit that manages the parking slot. It can store the data of the RFID tags, the availability of the parking space, the payment details, and the user information. It can also communicate with the mobile app and the display board.
  - Mobile app: This is an optional feature that allows the users to book the parking slot in advance, pay the parking fee, and get the directions to the parking slot. It can also show the real-time status of the parking slot and the history of the parking transactions.
  - Display board: This is installed at the parking slot to show the availability of the parking space, the parking fee, and the instructions for the users.
- The system works as follows  :
  - The user approaches the entry gate of the parking slot with the RFID tag attached to the vehicle.
  - The RFID reader scans the tag and sends the data to the server.
  - The server checks the validity of the tag and the availability of the parking space. If the tag is valid and the space is available, the server sends a signal to open the gate and assigns a parking space to the user. If the tag is invalid or the space is full, the server sends a signal to reject the user and displays a message on the board.
  - The user parks the vehicle in the assigned space and leaves the parking slot.
  - The user returns to the parking slot and approaches the exit gate with the RFID tag attached to the vehicle.
  - The RFID reader scans the tag and sends the data to the server.
  - The server calculates the parking fee based on the duration of the parking and the user's payment method. If the user has paid in advance or has a subscription, the server sends a signal to open the gate and displays a message on the board. If the user has not paid or has insufficient balance, the server sends a signal to close the gate and displays a message on the board.
  - The user pays the parking fee using the mobile app or a card reader and leaves the parking slot.
- The advantages of the system are  :
  - It reduces the parking search time and traffic congestion by providing real-time information on the availability of the parking space.
  - It improves the security and safety of the vehicles and the users by using RFID tags and readers that can prevent unauthorized access and theft.

  - A microcontroller unit (MCU) that controls the logic and communication of the system.
  - A GSM module that enables the SMS functionality and connects the system to the cellular network.
  - A LCD display that shows the voltage values of the three phases and the status of the system.
  - Three voltage sensors that measure the voltage of each phase and send the data to the MCU.
  - Three relays that switch on or off the power supply to the loads based on the phase status.
  - A buzzer that sounds an alarm when a phase failure is detected.
- The system works as follows:
  - The MCU continuously reads the voltage values of the three phases from the sensors and displays them on the LCD.
  - The MCU also compares the voltage values with a predefined threshold and determines if any phase is missing or below the normal range.
  - If a phase failure is detected, the MCU activates the corresponding relay to cut off the power supply to the load connected to that phase, to prevent damage or overload.
  - The MCU also sends an SMS to the authorized person, informing them of the phase failure and the location of the system.
  - The buzzer also sounds an alarm to alert the nearby personnel of the problem.
  - The system can be configured by sending SMS commands to the GSM module, such as setting the threshold voltage, the phone number of the authorized person, and the location of the system.

### IOT based Three Phase Power Failure Monitoring with SMS Alerts

- This is an advanced system that monitors power failure in a three-phase system.
- A three-phase system is a common method of alternating current electric power generation, transmission, and distribution. It consists of three wires or phases (R, Y, and B) that carry equal currents and are offset in time by one-third of the period.
- When one phase of a three-phase system gets lost, a phase loss occurs. This is referred to as a ‘single phasing’, this failure generally caused by a blown fuse, thermal overload, broken wire, worn contact or mechanical failure .
- A phase loss can cause serious damage to the equipment and appliances connected to the system, such as motors, compressors, pumps, etc. It can also result in overheating, reduced efficiency, increased power consumption, and fire hazards.
- To prevent such consequences, it is important to detect and alert the phase loss as soon as possible. This is where the IOT based system comes in handy.
- The IOT based system consists of the following components:
  - A voltage sensor module that measures the voltage of each phase and sends the data to the microcontroller.
  - A microcontroller that processes the data and compares it with a threshold value. If the voltage of any phase falls below the threshold, it indicates a phase loss and triggers the GSM module.
  - A GSM module that sends an SMS alert to the authorized person with the details of the phase loss and the location of the system.
  - An LCD display that shows the voltage of each phase and the status of the system.
  - An IOT module that connects the system to the internet and uploads the data to a cloud server for remote monitoring and analysis.
- The system works as follows:
  - The voltage sensor module continuously measures the voltage of each phase and sends the data to the microcontroller via analog pins.
  - The microcontroller converts the analog data to digital data and compares it with a predefined threshold value. If the voltage of any phase is lower than the threshold, it indicates a phase loss and sets a flag for that phase.
  - The microcontroller then sends a command to the GSM module to send an SMS alert to the authorized person with the details of the phase loss and the location of the system. The GSM module uses a SIM card and a network service provider to send the SMS.
  - The microcontroller also sends the data to the LCD display via digital pins. The LCD display shows the voltage of each phase and the status of the system (OK or FAIL).
  - The microcontroller also sends the data to the IOT module via serial communication. The IOT module connects the system to the internet using Wi-Fi or Ethernet and uploads the data to a cloud server for remote monitoring and analysis. The cloud server can be accessed by a web browser or a mobile app.
- The system has the following advantages:
  - It can detect and alert the phase loss in real time and prevent further damage to the equipment and appliances.
  - It can send the SMS alert to the authorized person regardless of the distance and location of the system.
  - It can upload the data to the cloud server for remote monitoring and analysis and provide historical and statistical information on the system performance and power quality.
  - It can be easily installed and configured and does not require any additional wiring or hardware.
  - It can be integrated with other IOT devices and applications for smart grid and smart home solutions.

  - The ESP8266 module is connected to the serial pins of the Arduino board and the power supply .
  - The Arduino board is programmed to read the analog value from the MQ5 sensor and compare it with a threshold value that indicates the gas level   .
  - If the gas level is above the threshold, the Arduino board will send a signal to the buzzer to make a sound and to the ESP8266 module to send data to the IOT platform   .
