## Introduction

The Internet of Things (IoT) is defined as the network of physical objects, things that are embedded, with sensors, software and other technologies for the purpose of connecting and exchanging data with, other devices and systems over the internet. #### CO 3 Demonstrate the ability to transmit data wirelessly between different devices. K4

Wireless data transmission is the process of sending and receiving data without using physical wires or cables. Wireless data transmission can be classified into two main types: radio frequency (RF) and optical.

- Radio frequency (RF) transmission uses electromagnetic waves to carry data through the air, such as Wi-Fi, Bluetooth, and cellular networks. RF signals are easily generated, ranging from 3 kHz to 300 GHz. RF transmission has the advantages of being able to penetrate walls and other obstacles, and being able to cover long distances. However, RF transmission also has some drawbacks, such as being susceptible to interference, noise, and security breaches, and requiring licenses for some frequency bands.
- Optical transmission uses light to send data, such as infrared, visible light, and laser. Optical transmission has the advantages of being immune to electromagnetic interference, having high bandwidth and low power consumption, and being secure and license-free. However, optical transmission also has some drawbacks, such as being limited by line-of-sight, being affected by atmospheric conditions, and requiring precise alignment and pointing of the transmitters and receivers.

- Understand the basic principles and characteristics of wireless data transmission methods, such as frequency, wavelength, modulation, encoding, multiplexing, and channel access.

- Select and use appropriate wireless data transmission methods and devices for different scenarios and requirements, such as distance, bandwidth, power, security, and cost.

#### CO 5 Examine various SQL queries from MySQL database K4, K5

- SQL stands for Structured Query Language, which is a standard language for accessing and manipulating data in relational databases.
- MySQL is one of the most popular open-source relational database management systems (RDBMS) that supports SQL.
- SQL queries are statements that specify what data to retrieve, insert, update, or delete from a database.
- SQL queries can be classified into four categories: Data Definition Language (DDL), Data Manipulation Language (DML), Data Query Language (DQL), and Data Control Language (DCL).
- DDL is used to define the structure and schema of the database, such as creating, altering, or dropping tables, views, indexes, etc.
- DML is used to manipulate the data in the database, such as inserting, updating, or deleting records, etc.
- DQL is used to query the data in the database, such as selecting, joining, filtering, sorting, grouping, etc.
- DCL is used to control the access and privileges of the database, such as granting, revoking, or denying permissions, etc.
- Some examples of SQL queries from MySQL database are:

  - To create a table named `students` with four columns: `id`, `name`, `age`, and `grade`:

    ```sql
    CREATE TABLE students (
      id INT PRIMARY KEY,
      name VARCHAR(50) NOT NULL,
      age INT,
      grade CHAR(1)
    );
    ```

  - To insert a record into the `students` table:

    ```sql
    INSERT INTO students (id, name, age, grade) VALUES (1, 'Alice', 18, 'A');
    ```

  - To select all the records from the `students` table:

    ```sql
    SELECT * FROM students;
    ```

  - To select only the `name` and `grade` columns from the `students` table where the `age` is greater than 20:

    ```sql
    SELECT name, grade FROM students WHERE age > 20;
    ```

  - To update the `grade` of the student with `id` 1 to 'B':

    ```sql
    UPDATE students SET grade = 'B' WHERE id = 1;
    ```

  - To delete the record of the student with `id` 2 from the `students` table:

    ```sql
    DELETE FROM students WHERE id = 2;
    ```

  - To create a view named `top_students` that contains the `name` and `grade` of the students who have a grade of 'A' or 'B':

    ```sql
    CREATE VIEW top_students AS
    SELECT name, grade FROM students WHERE grade IN ('A', 'B');
    ```

  - To grant the `SELECT` and `UPDATE` privileges on the `students` table to the user `bob`:

    ```sql
    GRANT SELECT, UPDATE ON students TO bob;
    ```

  - To revoke the `UPDATE` privilege on the `students` table from the user `bob`:

    ```sql
    REVOKE UPDATE ON students FROM bob;
    ```

  - To deny the `DELETE` privilege on the `students` table to the user `bob`:

    ```sql
    DENY DELETE ON students TO bob;
    ```

- A string is a sequence of characters, such as "Hello, world!" or "This is a sentence.".

- A character is a single symbol, such as "H" or "!" or ".".
- To count the number of words and characters in a given string, we can use the following steps:

  - Initialize two variables, word_count and char_count, to zero.
  - Loop through each character in the string, using a variable i to keep track of the index.
  - If the character at index i is a space or a punctuation mark, and the character at index i-1 is not a space or a punctuation mark, then increment word_count by one. This means we have reached the end of a word.
  - Increment char_count by one for every character in the string, regardless of whether it is a space or a punctuation mark or not. This means we have counted one more character.
  - After the loop ends, check if the last character in the string is not a space or a punctuation mark. If so, increment word_count by one. This means we have one more word that was not counted by the loop.
  - Return word_count and char_count as the final results.

```python
def word_and_char_count(string):
  # Initialize word_count and char_count to zero
  word_count = 0
  char_count = 0

  # Loop through each character in the string
  for i in range(len(string)):
    # If the character is a space or a punctuation mark, and the previous character is not
    if (string[i] == " " or string[i] in [".", ",", "!", "?"]) and (i == 0 or string[i-1] != " " and string[i-1] not in [".", ",", "!", "?"]):

    word_count += 1

  return word_count, char_count
```

- There are different ways to interface sensors with Arduino/Raspberry Pi, depending on the type of sensor, the communication protocol, and the available pins on the board. Some of the common ways are:

  - **Direct connection**: This is the simplest way to connect a sensor to the board, using the GPIO (General Purpose Input/Output) pins. The sensor can be either digital or analog, and the board can read the sensor value using digitalRead() or analogRead() functions. For example, a push button, a LED, a potentiometer, etc. can be directly connected to the board.

The devices can be either masters or slaves, and each device has a unique address. The master initiates the communication and sends or requests data from the slaves. The slaves respond to the master's commands. For example, a temperature and humidity sensor (DHT11), a LCD display, a gyroscope, etc. can be connected to the board using I2C.
  - **SPI (Serial Peripheral Interface)**: This is another serial communication protocol that allows multiple devices to share the same four-wire bus (MOSI, MISO, SCK, and SS). The devices can be either masters or slaves, and each device has a separate chip select (SS) pin. The master controls the clock (SCK) and sends or receives data from the slaves using the MOSI and MISO pins. The master selects the slave by pulling its SS pin low. For example, a pressure sensor (BMP180), a SD card, a RFID reader, etc. can be connected to the board using SPI.
  - **UART (Universal Asynchronous Receiver/Transmitter)**: This is a serial communication protocol that uses two wires (TX and RX) to transmit and receive data between devices. The devices must have the same baud rate, parity, and stop bits to communicate properly. The board can use the built-in serial port or software serial to communicate with the sensor. For example, a GPS module, a Bluetooth module, a GSM module, etc. can be connected to the board using UART.
  - **USB (Universal Serial Bus)**: This is a standard communication protocol that uses a cable to connect devices to a host computer. The devices can be either peripherals or hubs, and each device has a unique address. The host computer controls the communication and sends or requests data from the devices. The devices can use different classes of drivers to perform specific functions. For example, a webcam, a keyboard, a mouse, etc. can be connected to the board using USB.

- Some of the basic Linux commands that you can try in the terminal are:

  - `ls`: This command lists the files and directories in the current working directory. You can use various options with `ls` to change the format and details of the output. For example, `ls -l` shows the long listing format with permissions, size, date, and owner of each file and directory. `ls -a` shows the hidden files and directories that start with a dot (.). `ls -R` shows the files and directories recursively, including the subdirectories. You can also use `ls` with a specific path or name to list only the files and directories that match. For example, `ls /home/pi` lists the files and directories in the `/home/pi` directory. `ls *.txt` lists the files that end with `.txt` in the current working directory.

An absolute path starts with a slash (/) and specifies the exact location of a directory from the root of the file system. - `mkdir` is a command that creates a new directory in the current working directory or a specified path.
- `rmdir` is a command that removes an empty directory from the current working directory or a specified path.
- `tar` is a command that creates or extracts compressed archive files that contain multiple files or directories.
- `g` is not a valid command in Linux. Perhaps you meant `grep`, which is a command that searches for a pattern in a file or input and prints the matching lines.

- To create a directory named `project` in the current working directory, use `mkdir project`.
- To remove a directory named `project` from the current working directory, use `rmdir project`.

- To extract the files and directories from the compressed archive file named `project.tar.gz` in the current working directory, use `tar xzvf project.tar.gz`.
