#### CO 5 Examine various SQL queries from MySQL database K4, K5

SQL (Structured Query Language) is a standard programming language used to manage and manipulate relational databases. MySQL is an open-source relational database management system that uses SQL to interact with the data stored in its databases.

Here are some common SQL queries that can be used in a MySQL database:

1. **SELECT**: The SELECT statement is used to retrieve data from one or more tables in a database. The basic syntax is `SELECT column1, column2, ... FROM table_name;`. You can also use the `*` wildcard character to select all columns from a table.

2. **INSERT**: The INSERT statement is used to add new records to a table. The basic syntax is `INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);`.

3. **UPDATE**: The UPDATE statement is used to modify existing records in a table. The basic syntax is `UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;`.

4. **DELETE**: The DELETE statement is used to delete existing records from a table. The basic syntax is `DELETE FROM table_name WHERE condition;`.

5. **CREATE**: The CREATE statement is used to create a new table in a database. The basic syntax is `CREATE TABLE table_name (column1 datatype, column2 datatype, ...);`.

6. **ALTER**: The ALTER statement is used to add, modify, or delete columns in an existing table. The basic syntax is `ALTER TABLE table_name ADD column_name datatype;` to add a new column, `ALTER TABLE table_name MODIFY column_name datatype;` to modify an existing column, and `ALTER TABLE table_name DROP COLUMN column_name;` to delete a column.

7. **DROP**: The DROP statement is used to delete a table from a database. The basic syntax is `DROP TABLE table_name;`.

These are just a few examples of the many SQL queries that can be used in a MySQL database. It is important to have a good understanding of SQL and its syntax in order to effectively interact with and manipulate data in a MySQL database.

#### 4. a) Light an LED through Python program

1. To light an LED through a Python program, you will need a Raspberry Pi, an LED, a breadboard, and some jumper wires.
2. Connect the LED to the breadboard and connect the Raspberry Pi to the breadboard using the jumper wires.
3. Install the necessary libraries on the Raspberry Pi, such as the RPi.GPIO library.
4. Write a Python program that imports the RPi.GPIO library and sets the pin connected to the LED as an output pin.
5. Use the GPIO.output() function to turn the LED on and off.
6. Run the Python program on the Raspberry Pi to light the LED.

Here is an example Python program that can be used to light an LED:

```python
import RPi.GPIO as GPIO
import time

LED_PIN = 17

GPIO.setmode(GPIO.BCM)
GPIO.setup(LED_PIN, GPIO.OUT)

while True:
    GPIO.output(LED_PIN, GPIO.HIGH)
    time.sleep(1)
    GPIO.output(LED_PIN, GPIO.LOW)
    time.sleep(1)
```

This program sets the pin connected to the LED as an output pin and then enters an infinite loop that turns the LED on and off with a delay of one second between each state change. You can modify the delay to change the speed at which the LED blinks.

#### CO 5 Examine various SQL queries from MySQL database K4, K5

Structured Query Language (SQL) is a standard programming language used to manage and manipulate relational databases. MySQL is one of the most popular open-source relational database management systems that use SQL.

Here are some common SQL queries that can be used in a MySQL database:

1. **SELECT**: This query is used to retrieve data from one or more tables in a database. The basic syntax is `SELECT column1, column2, ... FROM table_name;`. You can also use the `WHERE` clause to filter the results based on certain conditions.

2. **INSERT**: This query is used to insert new records into a table. The basic syntax is `INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);`.

3. **UPDATE**: This query is used to update existing records in a table. The basic syntax is `UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;`.

4. **DELETE**: This query is used to delete existing records from a table. The basic syntax is `DELETE FROM table_name WHERE condition;`.

5. **CREATE**: This query is used to create a new table in a database. The basic syntax is `CREATE TABLE table_name (column1 datatype, column2 datatype, ...);`.

6. **ALTER**: This query is used to add, modify, or delete columns in an existing table. The basic syntax is `ALTER TABLE table_name ADD column_name datatype;` to add a new column, `ALTER TABLE table_name MODIFY COLUMN column_name datatype;` to modify an existing column, and `ALTER TABLE table_name DROP COLUMN column_name;` to delete a column.

7. **DROP**: This query is used to delete an entire table from a database. The basic syntax is `DROP TABLE table_name;`.

These are just a few examples of the various SQL queries that can be used in a MySQL database. It is important to have a good understanding of these queries in order to effectively manage and manipulate data in a MySQL database.

4. **DELETE**: Used to delete data from a database table. For example, to delete a student record with the name 'John' from the 'students' table, the query would be: `DELETE FROM students WHERE name = 'John';`

5. **CREATE**: Used to create a new database table. For example, to create a new table named 'courses' with columns 'id', 'name', and 'credits', the query would be: `CREATE TABLE courses (id INT, name VARCHAR(255), credits INT);`

6. **ALTER**: Used to modify the structure of an existing database table. For example, to add a new column named 'description' to the 'courses' table, the query would be: `ALTER TABLE courses ADD COLUMN description TEXT;`

7. **DROP**: Used to delete a database table. For example, to delete the 'courses' table, the query would be: `DROP TABLE courses;`

These are just a few examples of the various SQL queries that can be used in a MySQL database. It is important to have a good understanding of these queries to effectively manage and manipulate data in a MySQL database.

# CO 1 Understand the concept of Internet of Things K3

- The Internet of Things (IoT) refers to the interconnection of physical devices, vehicles, buildings, and other objects embedded with electronics, software, sensors, and network connectivity, which enables these objects to collect and exchange data.
- IoT allows objects to be sensed and controlled remotely across existing network infrastructure, creating opportunities for more direct integration of the physical world into computer-based systems, and resulting in improved efficiency, accuracy, and economic benefit.
- IoT involves extending internet connectivity beyond standard devices, such as desktops, laptops, smartphones, and tablets, to any range of traditionally non-internet-enabled physical devices and everyday objects.
- IoT devices are equipped with sensors, software, and other technologies that allow them to connect and exchange data with other devices and systems over the internet.
- IoT has the potential to transform many industries, including healthcare, transportation, agriculture, and manufacturing, by enabling new levels of automation, data analysis, and decision-making.
- IoT is a rapidly growing field, with the number of connected devices expected to reach tens of billions in the coming years.
- Key challenges in the development and deployment of IoT include security, privacy, interoperability, and the management of the large amounts of data generated by connected devices.

2. There are several **wireless technologies** that can be used for data transmission, including Bluetooth, Wi-Fi, cellular networks, and infrared.
3. **Bluetooth** is a short-range wireless technology that is commonly used for transmitting data between devices such as smartphones, tablets, and laptops. It operates in the 2.4 GHz frequency band and has a range of up to 10 meters.
4. **Wi-Fi** is a wireless networking technology that uses radio waves to provide high-speed internet and network connections. It operates in the 2.4 GHz and 5 GHz frequency bands and has a range of up to 100 meters.
5. **Cellular networks** use radio waves to transmit data between mobile devices and cell towers. They operate in various frequency bands and have a range of several kilometers.
6. **Infrared** is a wireless technology that uses infrared light to transmit data. It has a short range of up to 1 meter and is commonly used in remote controls.
7. To transmit data wirelessly between different devices, the devices must be equipped with the appropriate wireless technology and be within range of each other.
8. The **data transmission process** involves encoding the data into a format that can be transmitted, transmitting the data using the chosen wireless technology, and decoding the data at the receiving device.
9. **Security measures** such as encryption and authentication can be used to protect the transmitted data from interception and unauthorized access.
10. Wireless data transmission has many **advantages**, including increased mobility, flexibility, and convenience. However, it can also be subject to interference and security risks.

# CO 5 Examine various SQL queries from MySQL database K4, K5

SQL (Structured Query Language) is a standard language used to manage and manipulate data stored in relational databases. MySQL is one of the most popular open-source relational database management systems that uses SQL.

Here are some common SQL queries that can be used in a MySQL database:

1. **SELECT**: This query is used to retrieve data from one or more tables in a database. The basic syntax is `SELECT column1, column2, ... FROM table_name;`. You can also use the `WHERE` clause to filter the results based on a condition.

2. **INSERT**: This query is used to insert new records into a table. The basic syntax is `INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);`.

3. **UPDATE**: This query is used to update existing records in a table. The basic syntax is `UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;`.

4. **DELETE**: This query is used to delete records from a table. The basic syntax is `DELETE FROM table_name WHERE condition;`.

5. **CREATE**: This query is used to create a new table in a database. The basic syntax is `CREATE TABLE table_name (column1 datatype, column2 datatype, ...);`.

6. **ALTER**: This query is used to add, modify, or delete columns in an existing table. The basic syntax is `ALTER TABLE table_name ADD column_name datatype;` to add a new column, `ALTER TABLE table_name MODIFY COLUMN column_name datatype;` to modify an existing column, and `ALTER TABLE table_name DROP COLUMN column_name;` to delete a column.

7. **DROP**: This query is used to delete a table, view, index, or other object from a database. The basic syntax is `DROP object_type object_name;`.

These are just some of the basic SQL queries that can be used in a MySQL database. There are many more advanced queries and functions that can be used to manipulate and manage data in a MySQL database. It is important to have a good understanding of these queries and their syntax to effectively work with a MySQL database.

# mkdir, rmdir, tar, gzip

- `mkdir` is a command used to create a new directory in a file system. The syntax for the command is `mkdir [options] directory_name`. Some common options include `-p` to create parent directories as needed and `-m` to set the file mode for the new directory.

- `rmdir` is a command used to remove an empty directory in a file system. The syntax for the command is `rmdir [options] directory_name`. Some common options include `-p` to remove the directory and its parent directories if they are empty.

- `tar` is a command used to create or extract tar archives. Tar archives are used to store multiple files in a single file, often for the purpose of backup or transfer. The syntax for the command is `tar [options] [archive_name] [file1] [file2] ...`. Some common options include `-c` to create a new archive, `-x` to extract an archive, and `-f` to specify the name of the archive file.

- `gzip` is a command used to compress or decompress files using the gzip compression algorithm. The syntax for the command is `gzip [options] [file1] [file2] ...`. Some common options include `-d` to decompress a file, `-k` to keep the original file, and `-l` to list the compressed size of the file.

These commands are commonly used in Linux and Unix-like operating systems for file and directory management, as well as for data compression and archiving. They are powerful tools that can be used in a variety of ways to manage and manipulate files and directories. It is important to understand the syntax and options for each command in order to use them effectively.
