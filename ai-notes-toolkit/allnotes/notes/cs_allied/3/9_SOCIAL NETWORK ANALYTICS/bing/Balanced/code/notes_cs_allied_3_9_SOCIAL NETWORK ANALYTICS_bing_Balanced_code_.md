### Key concepts and measures in network analysis

- Network analysis is a method of studying the structure and behavior of complex systems composed of many interacting units, such as social networks, computer networks, biological networks, etc. 
- Network analysis involves the following key concepts and measures:
  - **Network**: A network is a representation of a system as a set of nodes (or vertices) and a set of links (or edges) that connect pairs of nodes. Nodes can represent any entity, such as people, organizations, genes, web pages, etc. Links can represent any relation, such as friendship, collaboration, interaction, citation, etc.
  - **Node degree**: Node degree is the number of links that a node has with other nodes in the network. It is a measure of the node's connectivity and activity. Node degree can be divided into in-degree (the number of incoming links) and out-degree (the number of outgoing links) for directed networks, where links have a direction.
  - **Path**: A path is a sequence of nodes and links that connects two nodes in the network. It is a measure of the distance and accessibility between nodes. The length of a path is the number of links in the sequence. The shortest path (or geodesic) between two nodes is the path with the minimum length.
  - **Centrality**: Centrality is a measure of the importance or influence of a node or a link in the network. There are different types of centrality, such as degree centrality (based on node degree), closeness centrality (based on the average shortest path length to other nodes), betweenness centrality (based on the number of shortest paths that pass through the node or link), eigenvector centrality (based on the centrality of the node's neighbors), etc. 
  - **Clustering**: Clustering is a measure of the tendency of nodes to form groups or communities in the network. There are different ways to define and measure clustering, such as the clustering coefficient (the ratio of the number of links among a node's neighbors to the maximum possible number of links), the modularity (the difference between the number of links within groups and the expected number of links under a random network), the density (the ratio of the number of links in the network to the maximum possible number of links), etc. 
  - **Network level**: Network level is a measure of the overall structure and properties of the network. It can include measures such as the size (the number of nodes and links in the network), the diameter (the maximum shortest path length among any pair of nodes in the network), the average path length (the average of the shortest path lengths among all pairs of nodes in the network), the degree distribution (the frequency distribution of node degrees in the network), the assortativity (the tendency of nodes to link with similar or dissimilar nodes in terms of some attribute), the transitivity (the ratio of the number of triangles in the network to the number of connected triples of nodes), etc.

### Personal networks

Personal networks are subsets of social networks that consist of the individuals or groups that a person interacts with or has some kind of relationship with. Personal networks can vary in size, density, diversity, and composition, depending on the person's characteristics, preferences, and context. Personal networks can provide various types of social support, such as emotional, instrumental, informational, or appraisal support, that can affect the person's well-being, behavior, and outcomes.

Some key concepts and methods in personal network analysis are:

- **Ego**: The focal person whose personal network is being analyzed.
- **Alter**: A member of the ego's personal network, who has some kind of tie or relationship with the ego.
- **Egocentric network**: The set of alters that the ego names or identifies as part of their personal network, and the ties among them.
- **Sociocentric network**: The set of all actors and ties in a defined social system, such as a community, organization, or population.
- **Name generator**: A question or a set of questions that elicits the names of alters from the ego, based on some criteria or topic of interest.
- **Name interpreter**: A question or a set of questions that collects additional information about the alters or the ties between the ego and the alters, such as their attributes, roles, frequency of contact, strength of relationship, etc.
- **Network boundary**: The criterion or rule that determines who is included or excluded in the personal network.
- **Network size**: The number of alters in the personal network.
- **Network density**: The proportion of ties that exist among the alters in the personal network, relative to the total number of possible ties.
- **Network diversity**: The extent to which the alters in the personal network differ from each other in terms of their attributes, such as age, gender, ethnicity, occupation, etc.
- **Network composition**: The distribution of alters in the personal network according to their attributes or categories, such as family, friends, coworkers, etc.
- **Network visualization**: The graphical representation of the personal network, using nodes to represent the ego and the alters, and edges to represent the ties among them.
- **Network metrics**: The quantitative measures that describe the structure, function, or properties of the personal network, such as degree centrality, closeness centrality, betweenness centrality, clustering coefficient, etc.

Personal network analysis can be used to study and understand various aspects of social support, such as:

- How personal networks are formed, maintained, or changed over time, and how they are influenced by individual, interpersonal, or environmental factors.

### Electronic sources for network analysis

- Network analysis is the process of determining the electrical parameters of a circuit or network, such as voltage, current, resistance, impedance, power, etc. 
- Network analysis can be performed using various methods, such as Kirchhoff's laws, mesh analysis, nodal analysis, superposition, Thevenin's theorem, Norton's theorem, etc. 
- Electronic sources are devices that provide electrical energy to a circuit or network, such as batteries, generators, solar cells, etc. 
- Electronic sources can be classified into two types: voltage sources and current sources. 
- A voltage source is a device that maintains a constant voltage across its terminals, regardless of the current flowing through it. A voltage source can be ideal or practical. An ideal voltage source has zero internal resistance, while a practical voltage source has some internal resistance. 
- A current source is a device that maintains a constant current through its terminals, regardless of the voltage across it. A current source can be ideal or practical. An ideal current source has infinite internal resistance, while a practical current source has some internal resistance. 
- Electronic sources can be transformed from one type to another using source transformation techniques. Source transformation is a method of simplifying complex electrical networks by converting voltage sources to current sources and vice versa. 
- Electronic sources can be connected in series or parallel to form equivalent sources. Series connection means that the sources have the same current but different voltages. Parallel connection means that the sources have the same voltage but different currents. 
- Electronic sources can be used for network analysis by applying various circuit laws and theorems, such as Ohm's law, Kirchhoff's laws, superposition, Thevenin's theorem, Norton's theorem, etc. These laws and theorems help to find the equivalent resistance, voltage, current, and power of a network.  
- Electronic sources can also be measured and calibrated using network analyzers. Network analyzers are instruments that measure the frequency response, impedance, and other characteristics of electronic networks. Network analyzers can apply corrections for cables and connectors by comparing what they measure to the values of the standards.

### The Resource Description Framework (RDF) and RDF Schema

- OWL is based on the Resource Description Framework (RDF), a standard for representing information about web resources.
- OWL uses the XML syntax for serializing RDF data, and also has alternative syntaxes such as RDF/XML, Turtle, and Manchester.
- OWL is endorsed by the World Wide Web Consortium (W3C) as a standard for the Semantic Web.

  - **Proof layer**: This layer provides the means to verify and explain the results of the logic layer, using proof languages, such as PML, etc. These languages allow representing and exchanging proofs and justifications for the inferences made on the Semantic Web.
  - **Trust layer**: This layer deals with the issues of trust, security, and privacy on the Semantic Web, using various mechanisms, such as digital signatures, encryption, authentication, authorization, etc. These mechanisms allow ensuring the integrity, confidentiality, and provenance of the data and metadata on the Semantic Web.
