# Sources and nature of data

- Data is any type of information that can be measured, accessed or used in any way in a given study.
- Data sources are the physical or digital locations where data is stored in a data table, data object, or some other storage format.
- Data sources can be classified into two types: statistical and non-statistical .
  - Statistical sources refer to data that is gathered for some official purposes, such as censuses, surveys, administrative records, etc .
  - Non-statistical sources refer to data that is collected for other administrative purposes or for the private sector, such as business transactions, social media, web analytics, etc .
- Data sources can also be classified into two types: primary and secondary .
  - Primary sources refer to data that is collected directly from the original source or the phenomenon of interest, such as experiments, observations, interviews, etc .
  - Secondary sources refer to data that is derived from primary sources or other secondary sources, such as books, articles, reports, etc .
- The nature of data refers to the characteristics or attributes of data, such as its type, format, quality, validity, reliability, etc.
  - Data type refers to the kind of data, such as numerical, categorical, ordinal, etc.
  - Data format refers to the way data is represented, such as text, image, audio, video, etc.
  - Data quality refers to the accuracy, completeness, consistency, timeliness, and relevance of data.
  - Data validity refers to the extent to which data measures what it is intended to measure.
  - Data reliability refers to the extent to which data can be reproduced or replicated under similar conditions.
- The sources and nature of data are important to consider in data analytics and visualization, as they affect the choice of methods, tools, and techniques for data processing, analysis, and presentation.



# Classification of Data

Classification of data is the process of organizing data by relevant categories so that it may be used and protected more efficiently. Data classification can be done according to different criteria, such as:

- **Data type**: Data can be classified into numerical, categorical, ordinal, or binary data based on the type of values they contain. Numerical data are quantitative and can be measured, such as height, weight, or temperature. Categorical data are qualitative and can be grouped into categories, such as gender, color, or nationality. Ordinal data are categorical data that have a natural order, such as grades, ranks, or ratings. Binary data are categorical data that have only two possible values, such as yes/no, true/false, or 0/1.
- **Data source**: Data can be classified into primary, secondary, or tertiary data based on the source of their collection. Primary data are collected directly from the original source, such as surveys, interviews, or experiments. Secondary data are collected from other sources that have already processed or analyzed primary data, such as books, journals, or reports. Tertiary data are collected from sources that have summarized or compiled secondary data, such as encyclopedias, directories, or databases.
- **Data quality**: Data can be classified into accurate, precise, reliable, valid, or complete data based on the quality of their measurement or representation. Accurate data are close to the true value or reality. Precise data are consistent and have a small margin of error. Reliable data are trustworthy and can be reproduced. Valid data are relevant and appropriate for the purpose or context. Complete data are not missing any essential information or values.
- **Data sensitivity**: Data can be classified into public, private, internal, confidential, or restricted data based on the level of security or privacy they require. Public data are important information, though often available material that's freely accessible for anyone, such as census data, weather data, or government data. Private data differ from public data, though it doesn't have a high level of security like some other types of data, such as personal data, financial data, or health data. Internal data are data that are only accessible within an organization or a group, such as employee data, customer data, or project data. Confidential data are data that are sensitive and need to be protected from unauthorized access, such as trade secrets, intellectual property, or classified information. Restricted data are data that are highly sensitive and need to be protected from any access, such as nuclear codes, military data, or national security data.

The objectives of data classification are to:

- Make data easier to locate and retrieve
- Enhance data security and compliance
- Optimize data storage and management
- Improve data analysis and decision making
- Reduce data risks and costs

# Evolution of Analytic Scalability

- Analytic scalability refers to the ability to handle large and complex data sets for analysis purposes.
- In the past, analytic scalability was limited by the constraints of the data environment, such as the storage capacity, processing speed, and data integration challenges.
- To overcome these limitations, analysts had to pull the data together in a separate analytics environment and then perform analysis, often using sampling or aggregation techniques to reduce the data size.
- However, this approach had several drawbacks, such as the loss of information, the increased complexity of data management, and the lack of real-time analysis.
- With the advent of big data, the need for analytic scalability increased exponentially, as the volume, variety, velocity, and veracity of data grew beyond the capabilities of traditional data environments.
- To address this need, several new paradigms emerged that enabled greater scalability and efficiency for analytics, such as:
  - The convergence of the analytic and data environments, which means that the analysis can be performed within the same environment where the data is stored, without the need for data movement or duplication  .
  - Massively parallel processing (MPP) architectures, which use multiple nodes or servers to distribute the data and the computation, allowing for faster and more scalable analysis of large data sets  .
  - The cloud, which provides on-demand access to scalable and elastic computing resources, such as storage, processing, and analytics services, without the need for upfront investment or maintenance  .
  - Grid computing, which leverages the idle or underutilized resources of a network of computers to perform distributed and parallel analysis of large data sets  .
  - MapReduce, which is a programming model and a framework for processing large data sets in parallel using a cluster of commodity hardware, based on the principles of functional programming  .
- These paradigms have enabled new levels of analytic scalability, allowing analysts to handle big data more effectively and efficiently, and to generate more valuable and timely insights   .

# Analysis vs Reporting

- Analysis and reporting are two different processes that are often confused or used interchangeably in the context of data analytics and visualization.
- Reporting is the process of presenting data in a structured and summarized way, usually using tables, charts, graphs, or dashboards. Reporting aims to answer questions such as what, when, where, and how much.
- Analysis is the process of exploring, interpreting, and explaining data, usually using statistical methods, models, or algorithms. Analysis aims to answer questions such as why, how, and what if.
- Reporting is useful for providing an overview of the current state of affairs, monitoring key performance indicators, and communicating facts and figures to stakeholders.
- Analysis is useful for discovering patterns, trends, outliers, and relationships in the data, testing hypotheses, and generating insights and recommendations for decision making.
- Reporting and analysis are complementary and interdependent processes. Reporting can provide the input and context for analysis, and analysis can provide the output and feedback for reporting.

# Unit 2 - Data Analytics Lifecycle

The data analytics lifecycle is a framework for planning and executing data analysis projects. It consists of six phases:

- **Discovery**: This phase involves identifying the business problem, defining the objectives and scope of the analysis, and gathering the relevant data sources and stakeholders.
- **Data preparation**: This phase involves cleaning, transforming, and integrating the data into a suitable format for analysis. It also involves exploring the data to understand its characteristics, quality, and distribution.
- **Model planning**: This phase involves selecting the appropriate analytical techniques and tools for the data and the problem. It also involves creating and validating hypotheses, and designing experiments or tests to evaluate them.
- **Model building**: This phase involves applying the selected techniques and tools to the data, and generating insights, patterns, or predictions. It also involves assessing the accuracy, validity, and reliability of the results, and refining the models as needed.
- **Communicate results**: This phase involves presenting and visualizing the results to the stakeholders, and explaining the methods, assumptions, and limitations of the analysis. It also involves providing recommendations, actions, or solutions based on the results.
- **Operationalize**: This phase involves deploying the models or solutions into production, and monitoring and evaluating their performance and impact. It also involves updating, maintaining, and improving the models or solutions as the data and the problem evolve.

# Various phases of data analytics lifecycle

Data analytics lifecycle is a series of steps that guide the process of transforming data into insights and actions that can help achieve business goals. Different models of data analytics lifecycle may have different names and numbers of phases, but they generally share some common elements. One of the most widely used models is the CRISP-DM (Cross-Industry Standard Process for Data Mining) methodology, which consists of six phases :

- **Business understanding**: This phase involves defining the problem or opportunity, identifying the objectives and success criteria, and understanding the business context and requirements.
- **Data understanding**: This phase involves collecting, exploring, and describing the data, as well as assessing its quality, relevance, and availability.
- **Data preparation**: This phase involves cleaning, transforming, integrating, and formatting the data to make it ready for analysis.
- **Modeling**: This phase involves applying various analytical techniques and algorithms to the data, such as statistics, machine learning, or visualization, to discover patterns, relationships, or insights.
- **Evaluation**: This phase involves assessing the validity, reliability, and usefulness of the results, as well as comparing them with the objectives and success criteria, and identifying any limitations or assumptions.
- **Deployment**: This phase involves communicating, presenting, or implementing the results, as well as monitoring, maintaining, and updating the analytical solution.

Another model of data analytics lifecycle is the data life cycle, which focuses more on the technical aspects of data management and governance. It consists of eight stages:

- **Generation**: This stage involves creating or capturing data from various sources, such as sensors, transactions, or user interactions.
- **Collection**: This stage involves acquiring, storing, and organizing the data in a centralized or distributed location, such as a database, a data warehouse, or a cloud platform.
- **Processing**: This stage involves transforming, enriching, and validating the data to ensure its quality, consistency, and completeness.
- **Analysis**: This stage involves applying various analytical techniques and tools to the data, such as statistics, machine learning, or visualization, to extract insights, knowledge, or value.
- **Publication**: This stage involves making the data and the results available and accessible to the intended audience, such as internal or external stakeholders, customers, or partners.
- **Archiving**: This stage involves preserving and protecting the data and the results for future use, reference, or compliance, such as by using backup, encryption, or retention policies.
- **Purging**: This stage involves deleting or destroying the data and the results that are no longer needed, relevant, or valid, such as by using deletion, anonymization, or shredding methods.
- **Usage**: This stage involves using the data and the results to support decision making, problem solving, or innovation, as well as measuring and evaluating the impact and value of the data and the results.

Both models of data analytics lifecycle aim to provide a structured and systematic way to manage data for converting it into information that can be used to fulfill organizational and project goals. However, they are not rigid or linear, and they may require iteration, adaptation, or customization depending on the specific context, scope, and complexity of the data analytics project.

# Bayesian modeling

Bayesian modeling is a statistical approach that uses probability to represent all uncertainty within a model, both the uncertainty regarding the output and the uncertainty regarding the input (aka parameters) to the model. Bayesian modeling is based on Bayes' theorem, which describes how to update the probability of an event or a hypothesis after obtaining new data or evidence.

Some of the advantages of Bayesian modeling are:

- It can incorporate prior knowledge or beliefs into the analysis, which can improve the accuracy and efficiency of the inference.
- It can handle complex and hierarchical models that are difficult to fit using frequentist methods.
- It can provide a full posterior distribution of the parameters and the predictions, which can be used to quantify the uncertainty and perform hypothesis testing.
- It can be used to inform decision-making by providing a quantitative assessment of various risks and scenarios.

Some of the challenges of Bayesian modeling are:

- It requires specifying a prior distribution for the parameters, which can be subjective and controversial.
- It often involves computationally intensive methods, such as Markov chain Monte Carlo (MCMC), to sample from the posterior distribution, which can be slow and difficult to diagnose.
- It can suffer from overfitting or underfitting if the model or the prior is not appropriate for the data.

Some of the applications of Bayesian modeling are:

- Bayesian hierarchical modeling, which is a multilevel model that allows for the variation and dependence of the parameters across different groups or levels.
- Bayesian network, which is a graphical model that represents the conditional dependencies and independencies among a set of variables.
- Bayesian optimization, which is a method for finding the optimal value of an objective function that is expensive or noisy to evaluate.
- Bayesian inference, which is a method for estimating the parameters and the predictions of a model given the data and the prior.



# Inference and Bayesian Networks

## Introduction

- Bayesian networks are a type of probabilistic graphical model that uses Bayesian inference for probability computations .
- Bayesian networks aim to model conditional dependence, and therefore causation, by representing conditional dependence by edges in a directed graph .
- Through these relationships, one can efficiently conduct inference on the random variables in the graph through the use of factors .
- Factors are functions that map a set of variables to a real number, representing the strength of their association.
- Bayesian networks can be used for various tasks, such as classification, diagnosis, prediction, decision making, and learning .

## Inference

- Inference is one key objective in a Bayesian network (BN), and it aims to estimate the posterior distributions of state variables based on evidence (observations).
- Inference can be divided into two types: exact and approximate.
- Exact inference methods compute the exact posterior distributions by exploiting the structure of the BN and applying the rules of probability .
- Exact inference methods include enumeration, variable elimination, and junction tree algorithms .
- Approximate inference methods use sampling or optimization techniques to generate approximate posterior distributions when exact methods are intractable or inefficient .
- Approximate inference methods include stochastic simulation, Markov chain Monte Carlo (MCMC), belief propagation, and variational methods  .

## Bayesian Networks

- A Bayesian network is a directed acyclic graph (DAG) where each node represents a random variable and each edge represents a conditional dependence .
- A Bayesian network encodes a joint probability distribution over the variables in the graph, which can be factorized as follows :

$$
P(X_1, X_2, ..., X_n) = \prod_{i=1}^n P(X_i | Pa(X_i))
$$

- where $Pa(X_i)$ denotes the set of parents of $X_i$ in the graph.
- A Bayesian network also requires a set of conditional probability tables (CPTs) that specify the conditional probabilities of each variable given its parents .
- A Bayesian network can be constructed from data using various methods, such as score-based, constraint-based, or hybrid approaches .
- A Bayesian network can also be updated with new data using Bayesian learning, which applies Bayes' rule to update the parameters of the CPTs .

  - Compact description of data. Example: Classical decomposition: Xt = Tt +St +Yt, where Xt is the observed value, Tt is the trend component, St is the seasonal component, and Yt is the random component.

# Linear Systems Analysis & Nonlinear Dynamics

## Linear Systems Analysis

- A linear system is a system whose behavior can be described by a linear equation or a set of linear equations.
- A linear equation is an equation that satisfies the properties of superposition and homogeneity, which means that the sum of two solutions is also a solution, and that multiplying a solution by a constant factor does not change its nature.
- A linear system can be represented by a matrix equation of the form **Ax = b**, where **A** is a matrix of coefficients, **x** is a vector of unknowns, and **b** is a vector of constants.
- A linear system can be solved exactly by using methods such as Gaussian elimination, matrix inversion, or eigenvalue decomposition.
- A linear system can also be interpreted as a linear transformation that maps a vector space to another vector space, preserving the properties of vector addition and scalar multiplication.
- A linear system can be classified as consistent or inconsistent, depending on whether it has a solution or not, and as unique or non-unique, depending on whether it has one or more solutions.
- A linear system can be analyzed by using tools such as the rank, the determinant, the trace, the inverse, the transpose, the adjoint, and the eigenvalues and eigenvectors of the matrix **A**.
- A linear system can be used to model various phenomena in science, engineering, and mathematics, such as electrical circuits, mechanical vibrations, heat transfer, population dynamics, and linear regression.

## Nonlinear Dynamics

- A nonlinear system is a system whose behavior cannot be described by a linear equation or a set of linear equations.
- A nonlinear equation is an equation that does not satisfy the properties of superposition and homogeneity, which means that the sum of two solutions may not be a solution, and that multiplying a solution by a constant factor may change its nature.
- A nonlinear system can be represented by a nonlinear function or a set of nonlinear functions, such as polynomials, trigonometric functions, exponential functions, logarithmic functions, or rational functions.
- A nonlinear system can be solved approximately by using methods such as iteration, fixed-point, Newton-Raphson, or numerical integration.
- A nonlinear system can also be interpreted as a nonlinear transformation that maps a vector space to another vector space, altering the properties of vector addition and scalar multiplication.
- A nonlinear system can be classified as stable or unstable, depending on whether it converges to a fixed point or diverges from it, and as periodic or chaotic, depending on whether it exhibits regular or irregular behavior over time.
- A nonlinear system can be analyzed by using tools such as the phase portrait, the bifurcation diagram, the Lyapunov exponent, the Poincaré map, and the attractor of the system.
- A nonlinear system can be used to model various phenomena in science, engineering, and mathematics, such as pendulums, oscillators, chemical reactions, biological systems, and nonlinear regression.

# Counting Distinct Elements in a Stream

- A stream is a sequence of data items that arrive in an online fashion, i.e., one by one and not all at once.
- Counting the number of distinct elements in a stream is a fundamental problem in data stream mining, with applications in network monitoring, web analytics, database systems, etc.
- The challenge is to design algorithms that use limited memory and processing time, and can handle streams of arbitrary length and distribution.
- A naive solution is to store all the elements seen so far in a hash table, and update the count whenever a new element arrives. However, this requires O(n) memory, where n is the number of distinct elements, which can be impractical for large or unbounded streams.
- A better solution is to use probabilistic data structures, such as sketches or sampling, that can estimate the number of distinct elements with a small error and a high probability, using only sublinear memory.
- Some examples of probabilistic data structures for counting distinct elements are:

  - Flajolet-Martin sketch: This sketch uses a hash function to map each element to a binary string, and keeps track of the minimum number of leading zeros among all the hashed elements. The number of distinct elements is estimated by 2^r, where r is the minimum number of leading zeros. This sketch uses O(log log n) memory and has a relative error of O(1/sqrt(m)), where m is the number of bits in the sketch.
  - HyperLogLog sketch: This sketch is an improvement of the Flajolet-Martin sketch, that uses multiple hash functions and partitions the stream into buckets. The number of distinct elements is estimated by a harmonic mean of the 2^r values for each bucket, where r is the minimum number of leading zeros in each bucket. This sketch uses O(log log n) memory and has a relative error of O(1.04/sqrt(m)), where m is the number of buckets.
  - MinHash sketch: This sketch uses a hash function to map each element to a numerical value, and keeps track of the minimum value among all the hashed elements. The number of distinct elements is estimated by 1/p, where p is the probability that the minimum value is less than a threshold. This sketch uses O(1) memory and has a relative error of O(1/sqrt(n)), where n is the number of elements in the stream.
  - Count-Min sketch: This sketch uses multiple hash functions and a two-dimensional array of counters. For each element, the sketch increments the counters in the corresponding rows and columns of the array. The number of distinct elements is estimated by the minimum of the counters for each hash function. This sketch uses O(epsilon^-1 log delta^-1) memory and has a relative error of O(epsilon) with a probability of 1-delta, where epsilon and delta are user-defined parameters.

# Counting oneness in a window

- Counting oneness in a window is a problem of estimating the number of 1's in the last k bits of a data stream, where k is a large number that cannot be stored in memory.
- One possible solution is to use the DGIM algorithm, which uses a compact representation of the stream using buckets of 1's with timestamps and sizes.
- The DGIM algorithm works as follows :
  - Each bit of the stream has a timestamp, the position in which it arrives. The first bit has timestamp 1, the second has timestamp 2, and so on.
  - The algorithm maintains a set of buckets, each consisting of the timestamp of its rightmost bit and the number of 1's in the bucket.
  - The buckets are stored in a circular array of size N, where N is the length of the window. The algorithm also stores the total number of bits ever seen in the stream modulo N, which allows to determine the position of any bit in the current window.
  - The buckets are subject to two invariants:
    - There are at most two buckets of any size.
    - The buckets are ordered by their timestamps, from oldest to newest.
  - Whenever a new bit arrives, the algorithm performs the following steps:
    - If the bit is 0, it is ignored.
    - If the bit is 1, it is added as a new bucket of size 1 and timestamp equal to the current position in the stream.
    - If there are now three buckets of size 1, the oldest two are merged into a bucket of size 2 and timestamp equal to the newer of the two.
    - If there are now three buckets of size 2, the oldest two are merged into a bucket of size 4 and timestamp equal to the newer of the two.
    - And so on, until there are at most two buckets of any size.
    - If the oldest bucket falls out of the window, it is deleted from the array.
  - To estimate the number of 1's in the last k bits, the algorithm performs the following steps:
    - Find the oldest bucket that is entirely within the last k bits, call it B.
    - Sum the sizes of all the buckets newer than B, call it S.
    - Add half of the size of B to S, call it E.
    - Return E as the estimate, which is guaranteed to be within 50% of the true count.



# Decaying Window

- A decaying window is a technique for processing data streams that assigns different weights to different parts of the stream based on their recency.
- The idea is to give more importance to the recent data and less importance to the older data, as they may be less relevant or outdated.
- A decaying window can be implemented in different ways, such as using exponential decay, time-fading, or landmark windows.
- A decaying window can be useful for finding frequent itemsets, outliers, trends, or patterns in streaming data, as it can adapt to the changing characteristics of the data over time.

## Exponential Decay

- One way to implement a decaying window is to use an exponential decay function, which reduces the weight of each element in the stream by a constant factor as it gets older.
- For example, if the stream consists of elements a1, a2, ..., at, where a1 is the first element to arrive and at is the current element, and c is a small constant, such as 10^-6 or 10^-9, then the weight of each element ai is given by e^(-c(t-i)).
- The advantage of this method is that it does not require a fixed window size or a sliding mechanism, as the weight of each element decays continuously over time.
- The disadvantage is that it may be difficult to choose an appropriate value for c, as it affects the rate of decay and the sensitivity to recent changes.

## Time-Fading

- Another way to implement a decaying window is to use a time-fading function, which reduces the weight of each element in the stream by a certain threshold after a certain time interval.
- For example, if the stream consists of elements a1, a2, ..., at, where a1 is the first element to arrive and at is the current element, and T is a time interval, such as one hour or one day, then the weight of each element ai is given by 1 if it arrived within the last T time units, and 0 otherwise.
- The advantage of this method is that it is easy to implement and understand, as it only requires a simple comparison of timestamps.
- The disadvantage is that it may be too abrupt or coarse, as it ignores the gradual changes in the data and discards the older data completely.

## Landmark

- A third way to implement a decaying window is to use a landmark window, which divides the stream into segments based on certain events or markers, and assigns different weights to different segments based on their distance from the current segment.
- For example, if the stream consists of elements a1, a2, ..., at, where a1 is the first element to arrive and at is the current element, and L is a landmark, such as the start of a day or a week, then the weight of each element ai is given by 1 if it belongs to the current segment, and 0.5^k if it belongs to the k-th previous segment.
- The advantage of this method is that it can capture the periodicity or seasonality of the data, as it aligns the segments with the natural cycles of the data.
- The disadvantage is that it may be sensitive to the choice of the landmark, as it affects the length and number of the segments.

# Mining frequent itemsets

- Frequent itemsets are sets of items that appear together frequently in a dataset, such as a transactional database or a relational database.
- Mining frequent itemsets is a technique used to discover patterns and relationships among items in a dataset, such as association rules, which describe how often items are purchased together or imply each other.
- Mining frequent itemsets can help to understand customer behavior, market basket analysis, recommender systems, anomaly detection, and other data mining tasks.
- There are different algorithms for mining frequent itemsets, such as Apriori, Eclat, and FP-growth. These algorithms differ in how they generate and prune candidate itemsets, how they count the support of itemsets, and how they store and traverse the data structure.
- Apriori is the most commonly used algorithm for mining frequent itemsets. It works by applying the Apriori principle, which states that any subset of a frequent itemset must also be frequent. Apriori generates candidate itemsets of increasing size and scans the dataset to count their support. It prunes any candidate itemset that has a support lower than a minimum threshold. Apriori is simple and easy to implement, but it can be inefficient and slow for large datasets, as it generates many candidates and scans the dataset multiple times.
- Eclat is an algorithm that improves the efficiency of Apriori by using a vertical data format, where each item is associated with a set of transactions that contain it. Eclat generates candidate itemsets by intersecting the transaction sets of frequent items, and counts their support by the size of the intersection. Eclat avoids scanning the dataset multiple times and reduces the number of candidates, but it can consume more memory and be slower for sparse datasets, as it stores large transaction sets.
- FP-growth is an algorithm that further improves the efficiency of Apriori and Eclat by using a compressed data structure called a frequent pattern tree (FP-tree), which stores the frequent items and their occurrence counts in a prefix tree. FP-growth generates frequent itemsets by recursively mining the FP-tree, without generating any candidate itemsets. FP-growth is faster and more scalable than Apriori and Eclat, but it can still consume a lot of memory for dense datasets, as it builds a large FP-tree.



# Market Based Modelling for Frequent Itemsets and Clustering

- Market based modelling is a data mining technique that assumes that there are two kinds of entities: items and baskets.
- Items are the products or services that are sold or bought in a market, such as books, groceries, movies, etc.
- Baskets are the collections of items that are purchased or consumed together by a customer, such as a shopping cart, a movie ticket, a library loan, etc.
- There is a many-to-many relationship between items and baskets, meaning that a basket can contain multiple items, and an item can belong to multiple baskets.
- The goal of market based modelling is to discover patterns and associations among the items and baskets, such as which items are frequently bought together, which items are complementary or substitutable, which items are popular or unpopular, etc.
- These patterns and associations can help in various tasks, such as recommendation systems, cross-selling, customer segmentation, market segmentation, etc.

## Frequent Itemsets

- A frequent itemset is a subset of items that occurs frequently in the baskets  .
- The frequency of an itemset is the number or proportion of baskets that contain all the items in the itemset.
- For example, if there are 100 baskets in total, and 20 of them contain both bread and butter, then the itemset {bread, butter} has a frequency of 20 or 0.2.
- A frequent itemset is an itemset that has a frequency above a given threshold, called the minimum support.
- The minimum support is a parameter that can be set by the user or the analyst, depending on the problem and the data.
- For example, if the minimum support is 0.1, then only the itemsets that have a frequency of at least 10 or 0.1 are considered frequent.
- Finding frequent itemsets is an important step in market based modelling, as it can reveal the common preferences and behaviors of the customers.
- Frequent itemsets can also be used to generate association rules, which are rules that express the conditional probability of one itemset given another itemset.
- For example, if the itemset {bread, butter} has a frequency of 0.2, and the itemset {bread} has a frequency of 0.5, then the association rule bread -> butter has a confidence of 0.4, meaning that 40% of the baskets that contain bread also contain butter.
- Association rules can help in identifying the relationships and dependencies among the items, such as which items are likely to be bought together, which items are likely to influence the purchase of other items, which items are likely to be bought after or before other items, etc.

- Clustering can be performed using various algorithms and methods, such as k-means, hierarchical, density-based, etc.

# Apriori Algorithm

- Apriori algorithm is a data mining technique for finding frequent itemsets and association rules in a transactional database  .
- Frequent itemsets are sets of items that appear together in a minimum number of transactions, called the support threshold  .
- Association rules are implications of the form X -> Y, where X and Y are itemsets, meaning that transactions containing X are likely to contain Y as well  .
- Apriori algorithm uses a bottom-up approach, where it starts with finding the frequent 1-itemsets (single items) and then iteratively generates larger and larger itemsets by joining and pruning the previous ones  .
- The join step combines two itemsets of size k to form a candidate itemset of size k+1, if they share k-1 items in common  .
- The prune step eliminates the candidate itemsets that have a subset that is not frequent, based on the Apriori property that all subsets of a frequent itemset must be frequent  .
- The algorithm stops when no more frequent itemsets can be generated or when the maximum size of the itemsets is reached  .
- Apriori algorithm can be used to find the association rules by computing the confidence of each rule, which is the ratio of the support of the itemset to the support of the antecedent  .
- The rules that have a confidence above a minimum threshold are considered strong and are outputted by the algorithm  .
- Apriori algorithm has some advantages and disadvantages  :
  - Advantages:
    - It is simple and easy to implement.
    - It can handle large datasets efficiently.
    - It can be parallelized and distributed for scalability.
  - Disadvantages:
    - It may generate a huge number of candidate itemsets, especially when the items are numerous and the support threshold is low.
    - It may scan the database multiple times, which can be costly for disk-based databases.
    - It may not find the optimal itemsets or rules, as it depends on the user-defined parameters.

# Limited Pass Algorithm for Frequent Itemsets

- The limited pass algorithm is an approximate algorithm that aims to find most of the frequent itemsets in a data set, without making multiple passes over the data.
- The algorithm works as follows:
  - First, it takes a random sample of the data set and applies a lower support threshold to find the candidate frequent itemsets in the sample.
  - Then, it makes one pass over the entire data set and counts the occurrences of the candidate itemsets, filtering out those that do not meet the original support threshold.
  - The remaining itemsets are the approximate frequent itemsets of the data set.
- The advantages of the limited pass algorithm are:
  - It reduces the number of passes over the data set to two, which can save a lot of time and memory for large data sets.
  - It can find most of the frequent itemsets, especially those with high support, with high probability.
- The disadvantages of the limited pass algorithm are:
  - It may miss some of the frequent itemsets, especially those with low support, due to sampling error or lower threshold.
  - It may include some of the infrequent itemsets, due to sampling error or higher threshold.
  - It does not guarantee to find the exact collection of frequent itemsets, which may affect the quality of the association rules or other mining tasks.

# Clustering Techniques for the Notes of the Unit 5 - Frequent Itemsets and Clustering in the Subject of Introduction to Data Analytics and Visualization

Clustering is a type of unsupervised learning method of machine learning that aims to group data points into clusters based on some similarity or distance measure. - **Gaussian Mixture Model**: This is a probabilistic method that assumes that the data points are generated by a mixture of Gaussian distributions and estimates the parameters of the distributions using the expectation-maximization algorithm. # Hierarchical Clustering

- Hierarchical clustering is a method of cluster analysis that seeks to build a hierarchy of clusters.
- Clustering is a technique to create homogeneous groups of entities or objects based on their similarity or dissimilarity.
- Hierarchical clustering can be performed in two ways: agglomerative or divisive.
  - Agglomerative clustering is a bottom-up approach that starts with each observation in its own cluster and then merges the closest pairs of clusters until all observations are in one cluster .
  - Divisive clustering is a top-down approach that starts with all observations in one cluster and then splits the cluster into smaller clusters based on some criterion until each observation is in its own cluster .

  - Linkage methods can be single, complete, average, centroid, median, ward, or other types depending on the desired properties of the resulting clusters.

# K-means Clustering Algorithm

- K-means clustering is a method of **vector quantization**, originally from signal processing, that aims to partition n observations into k clusters in which each observation belongs to the cluster with the nearest mean (cluster centers or cluster centroid), serving as a prototype of the cluster.
- K-means clustering is an **unsupervised learning algorithm**. There is no labeled data for this clustering, unlike in supervised learning.
- K-means clustering is a simple and elegant approach for partitioning a data set into K distinct, nonoverlapping clusters. To perform K-means clustering, we must first specify the desired number of clusters K; then, the K-means algorithm will assign each observation to exactly one of the K clusters.
- K-means clustering is deployed to discover groups that haven’t been explicitly labeled within the data. It’s being actively used today in a wide variety of business applications such as customer segmentation, market analysis, image compression, etc.

## Steps of K-means Clustering Algorithm

The algorithm works as follows:

1. First, we initialize k points, called means or cluster centroids, randomly.
2. We categorize each item to its closest mean and we update the mean’s coordinates, which are the averages of the items categorized in that mean so far.
3. We repeat the process for a given number of iterations and at the end, we have our clusters.

## Advantages and Disadvantages of K-means Clustering Algorithm

Some of the advantages of K-means clustering are:

- It is easy to implement and understand.
- It is computationally efficient and scalable for large data sets.
- It can produce tight clusters with spherical shapes.

Some of the disadvantages of K-means clustering are:

- It requires the number of clusters K to be specified in advance, which may not be easy to determine.
- It is sensitive to the initial choice of cluster centroids, which may lead to different results for different runs of the algorithm.
- It is not suitable for data sets with clusters of different sizes, densities, or shapes, as it assumes equal variance and spherical clusters.
- It may not converge to the global optimum, but to a local optimum, depending on the initial cluster centroids.



# Clustering High-Dimensional Data

Clustering high-dimensional data is the process of finding groups of similar objects in data sets that have many attributes or dimensions. Clustering is a useful technique for data analysis, data mining, and data visualization, but it becomes challenging when the data is high-dimensional. Some of the problems and solutions for clustering high-dimensional data are:

- **Curse of dimensionality**: As the number of dimensions increases, the data becomes sparse and the distance between any two points becomes similar. This makes it hard to define meaningful clusters and measure their quality. One solution is to reduce the dimensionality of the data by selecting a subset of relevant features, using feature extraction techniques, or applying dimensionality reduction methods.
- **Complexity and scalability**: Clustering high-dimensional data requires more computational resources and time than clustering low-dimensional data. ## CLIQUE Algorithm

- CLIQUE is a **subspace clustering algorithm** that uses a **density and grid-based technique** to find clusters in high-dimensional data. 
- CLIQUE finds clusters by dividing each dimension into equal-width intervals and saving those intervals where the density is greater than a threshold as clusters. 
- CLIQUE can find clusters of any shape and is able to find any number of clusters in any number of dimensions, where the number is not predetermined by a parameter. 
- CLIQUE has four steps: 
  - **Identify dense units**: For each dimension, divide it into a number of intervals and count the number of points in each interval. A unit is an interval that has more points than the density threshold. A dense unit is a unit that is part of a cluster.
  - **Generate candidate subspace clusters**: For each pair of dense units that share all but one dimension, merge them into a candidate subspace cluster of higher dimensionality.
  - **Determine maximal subspace clusters**: A subspace cluster is maximal if it is not contained in any other subspace cluster. Prune the candidate subspace clusters that are not maximal.
  - **Generate minimal descriptions for clusters**: A minimal description for a cluster is the smallest set of dimensions that defines the cluster. Prune the dimensions that are not relevant for the cluster.

## ProCLUS Algorithm

- ProCLUS is a **projected clustering algorithm** that uses a **k-means-like technique** to find clusters in high-dimensional data. 
- ProCLUS finds clusters by randomly selecting k medoids and assigning each point to the nearest medoid. Then, for each medoid, it finds the most relevant dimensions for the cluster and projects the points onto those dimensions. Finally, it refines the medoids and the dimensions until convergence. 
- ProCLUS can find clusters of different shapes and sizes and is able to find the relevant dimensions for each cluster. 
- ProCLUS has four steps: 
  - **Initialization**: Randomly select k medoids and assign each point to the nearest medoid.
  - **Iterative phase**: For each medoid, find the most relevant dimensions for the cluster and project the points onto those dimensions. Then, recompute the medoids and reassign the points to the nearest medoid.
  - **Refinement phase**: Remove the outliers and the bad medoids and repeat the iterative phase.
  - **Final output**: Return the final medoids and the relevant dimensions for each cluster.

# Clustering for Streams and Parallelism

Clustering is a technique for finding groups of similar data points in a dataset. Clustering can be applied to different types of data, such as text, images, graphs, or time series. Clustering data streams can help discover patterns, trends, and outliers in the data, as well as reduce the storage and processing costs of the data.

However, clustering data streams poses several challenges, such as:

- The data may be infinite, noisy, or evolving, which requires the clustering algorithm to be adaptive, robust, and scalable.

- Online-offline scheme: A common approach for clustering data streams is to use a two-phase scheme, which consists of an online component and an offline component. The online component processes the data stream points as they arrive and produces summary statistics, such as micro-clusters, sketches, or histograms. The offline component uses the summary data to generate the final clusters, using a traditional clustering algorithm or a merging strategy. This scheme can reduce the memory and computation requirements of the clustering algorithm, as well as handle concept drift and outliers in the data stream.
- Parallel and distributed clustering: Another approach for clustering data streams is to use parallel or distributed computing frameworks, such as MapReduce, Spark, or Storm. These frameworks can enable the clustering algorithm to handle large-scale, distributed, or heterogeneous data streams, by partitioning the data into multiple subsets and processing them in parallel or distributed manner. The clustering algorithm can then combine the results from different subsets using a global aggregation or consensus mechanism. This approach can improve the scalability, performance, and fault-tolerance of the clustering algorithm, as well as handle data privacy and security issues.
- Correlation-based clustering: A specific problem for clustering parallel data streams is to group multiple streams with similar behavior and trend together, instead of clustering the data points within one data stream. This problem can be solved by using correlation-based clustering, which measures the similarity between data streams based on their correlation coefficients, such as Pearson's correlation or Spearman's rank correlation. The correlation coefficients can be computed efficiently and incrementally using summary statistics, such as mean, variance, or covariance. The correlation-based clustering can then use a threshold or a clustering algorithm to group the data streams into clusters based on their correlation values  .

These are some of the main concepts and techniques for clustering data streams and parallelism. Clustering data streams and parallelism is an active and important research area, as it can provide valuable insights and applications for various domains, such as sensor networks, social media, web mining, or anomaly detection.

# Issues for the notes of the Unit 6 - Introduction to Visualization in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

Data visualization can help users to explore, analyze, and understand data, as well as to communicate insights and findings to others. However, data visualization also faces some challenges and issues that need to be addressed and avoided. Some of the common issues are:

- **Correlation is not causation**: Correlations make us see false relationships. For example, a graph may show that ice cream sales and shark attacks are positively correlated, but that does not mean that ice cream causes shark attacks or vice versa. Correlations do not imply causation, and data visualization should not mislead users to draw wrong conclusions based on spurious correlations.

- **Similarities now do not mean similarities forever**: On top of false correlations, a relationship happening within our observational set does not imply a relationship always. For example, a graph may show that the GDP of a country and its life expectancy are positively correlated, but that does not mean that the same relationship will hold in the future or in other countries. Data visualization should not extrapolate beyond the data or assume that patterns are stable and universal.

- **Axes make all the difference**: The size and number of axes can change the way we interpret data. For example, a graph may show that the unemployment rate of a country has decreased over time, but if the y-axis is truncated or zoomed in, the decrease may look more dramatic than it actually is. Data visualization should not manipulate the axes to exaggerate or downplay the trends or differences in the data.

- **Abusing the Law of Large Numbers (LLN)**: The LLN states that as the sample size increases, the sample mean approaches the population mean. However, some data visualizations may abuse this law to make claims based on insufficient or biased data. For example, a graph may show that the average height of a group of people is 170 cm, but if the sample size is too small or not representative of the population, the average may not be accurate or meaningful. Data visualization should not use the LLN to justify or generalize from inadequate or unrepresentative data.

- **Misleading color contrast**: Color is among the most persuasive design elements. Even subtle shade variations elicit strong emotional responses. In data visualization, high degrees of color contrast may cause viewers to believe that value disparities are greater than they really are. For example, a map may use a red-green color scheme to show the political preferences of different regions, but if the colors are too bright or saturated, the map may exaggerate the differences or polarize the opinions. Data visualization should not use misleading color contrast to distort or bias the data.

- **Using an unsuitable format**: The nature of the data usually dictates the format of the data visualization. The most important characteristic is whether the data is qualitative (it describes or categorizes) or quantitative (meaning, it’s measurable). For example, a pie chart may be suitable for showing the proportions of different categories, but not for showing the changes over time or the comparisons across groups. Data visualization should not use an unsuitable format to display the data or confuse the users.

- **Lack of better data visualization literacy**: A lack of proper knowledge of data visualization can do more harm than good. First, it confuses the audience, or worse, it misleads them. Additionally, a poorly structured data visualization denotes a loss of time and effort, which delays the decision-making process in deadline-driven projects. Data visualization should not be created or consumed without adequate data visualization literacy, which includes the skills and knowledge to design, interpret, and evaluate data visualizations.

These are some of the issues that data visualization faces today, and they should be avoided or resolved to ensure that data visualization is effective, efficient, and ethical. Data visualization is a powerful tool for data analysis and communication, but it also comes with great responsibility and challenges.

# Unit 7 - Human Vision

Human vision is the ability to perceive and interpret visual information from the environment. It involves the interaction of the eyes, the brain, and the nervous system. Human vision has the following features and limits:

- **Binocular vision**: Humans have two eyes that are located on the left and right sides of the face. Each eye forms a different image on the retina, which is the light-sensitive layer at the back of the eye. The brain combines these two images to create a single perception of vision that allows humans to see objects in three dimensions and estimate their distance and depth .

The pupil is the opening in the center of the iris that controls the amount of light that enters the eye. The lens is the transparent structure behind the pupil that changes shape to focus light onto the retina. The retina is the layer of nerve cells that converts light into electrical signals that are sent to the brain via the optic nerve. The extraocular muscles are the six muscles that control the movements of the eye .
- **Color perception**: Humans can perceive a range of colors that are derived from the combination of three primary colors: red, green, and blue. The retina contains two types of photoreceptor cells that are sensitive to different wavelengths of light: rods and cones. Rods are more abundant and work better in dim light, but they cannot distinguish colors. Cones are less numerous and work better in bright light, and they are responsible for color vision. There are three types of cones that respond to different ranges of wavelengths: S-cones (short-wavelength, blue), M-cones (medium-wavelength, green), and L-cones (long-wavelength, red). - **Visual field**: Visual field is the area of the environment that a person can see at any given moment without moving the eyes or the head. It is determined by the position and angle of the eyes, the size and shape of the eyelids, and the presence of any obstructions or defects in the eye or the brain. # Figure Caption in Visual Interface

- A figure caption is a text that accompanies a figure in a visual interface, such as a chart, a graph, a map, or an image.
- A figure caption serves several purposes, such as:
  - Providing a title or a summary of the figure
  - Explaining the data source, the variables, the units, the scale, or the legend of the figure
  - Highlighting the main findings, trends, patterns, or insights from the figure
  - Providing additional information or context that is not visible in the figure
  - Citing the original source or author of the figure, if applicable
- A figure caption should be concise, clear, accurate, and informative. It should not repeat the information that is already shown in the figure, but rather complement it or add value to it.
- A figure caption should be placed close to the figure, preferably below it, and aligned with the left edge of the figure. It should be formatted differently from the main text, such as using a smaller font size, a different font style, or a different color.
- A figure caption should follow a consistent style and format throughout the document or the interface. It should use proper punctuation, capitalization, and grammar. It should also use the same terminology and notation as the figure and the main text.
- A figure caption should be numbered sequentially if there are multiple figures in the document or the interface. The number should be preceded by the word "Figure" and followed by a period. The number should also be referenced in the main text when the figure is mentioned or discussed.
- A figure caption should be tested for readability, comprehension, and accessibility. It should be easy to read and understand by the intended audience, and it should not create confusion or ambiguity. It should also be accessible to people with visual impairments, such as using alternative text or audio descriptions.



# Visual Objects and Data Objects

- Visual objects are any identifiable, separate, and distinct parts of the visual world that have certain visual attributes, such as shape, color, size, position, orientation, texture, etc. 
- Data objects are any abstract entities that have certain data values, such as numbers, strings, categories, dates, etc.
- Visual objects and data objects can be mapped to each other using visual encoding, which is the process of assigning data values to visual features of visual objects. 
- Visual encoding can be used to create effective visualizations that convey information and insights from data objects to human viewers.
- Visual encoding can be based on different principles, such as:
  - Expressiveness: the visual encoding should express all and only the data values of the data objects.
  - Effectiveness: the visual encoding should match the perceptual and cognitive abilities of human viewers, such as preattentive processing, gestalt principles, visual hierarchy, etc.
  - Efficiency: the visual encoding should minimize the cognitive load and the visual clutter of the visualization.
- Visual encoding can be applied to different types of data objects, such as:
  - Nominal data: data values that represent categories or names, such as countries, colors, genres, etc. Nominal data can be encoded using visual features that are distinct and recognizable, such as shape, color hue, texture, etc.
  - Ordinal data: data values that represent an ordered sequence or rank, such as grades, ratings, sizes, etc. Ordinal data can be encoded using visual features that have an inherent order, such as color saturation, color brightness, size, position, etc.
  - Quantitative data: data values that represent numerical measurements or quantities, such as temperature, speed, income, etc. Quantitative data can be encoded using visual features that have a proportional or linear relationship, such as length, area, angle, position, etc.
- Visual encoding can also be applied to different types of data structures, such as:
  - Univariate data: data objects that have only one data value, such as a single number, category, or date. Univariate data can be encoded using simple visual objects, such as points, bars, pie slices, etc.
  - Bivariate data: data objects that have two data values, such as a pair of numbers, categories, or dates. Bivariate data can be encoded using visual objects that have two visual features, such as x-y coordinates, width-height, color-shape, etc.
  - Multivariate data: data objects that have more than two data values, such as a vector of numbers, categories, or dates. Multivariate data can be encoded using visual objects that have multiple visual features, such as glyphs, parallel coordinates, treemaps, etc.
  - Hierarchical data: data objects that have a nested or tree-like structure, such as a file system, an organization chart, a taxonomy, etc. Hierarchical data can be encoded using visual objects that have a parent-child relationship, such as nodes and links, nested circles, icicle plots, etc.
  - Network data: data objects that have a relational or graph-like structure, such as a social network, a web graph, a citation network, etc. Network data can be encoded using visual objects that have a source-target relationship, such as nodes and links, matrices, arc diagrams, etc.
  - Temporal data: data objects that have a time-related or sequential structure, such as a time series, a timeline, a video, etc. Temporal data can be encoded using visual objects that have a temporal feature, such as position, color, animation, etc.
  - Spatial data: data objects that have a geographic or physical structure, such as a map, a floor plan, a satellite image, etc. Spatial data can be encoded using visual objects that have a spatial feature, such as position, shape, color, texture, etc.
