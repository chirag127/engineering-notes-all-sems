- Bar charts: This type of chart is used to compare data across different categories.
- Line charts: This type of chart is used to show trends over time.
- Scatter plots: This type of chart is used to show the relationship between two variables.
- Heat maps: This type of chart is used to show the density of data points in a particular area.

### Evolution of Analytic Scalability

In the field of data analytics, the scalability of analytics has undergone a significant evolution over the past few years. Here are some key points to consider:

- **Traditional Analytics:** Traditional analytics involves analyzing data using a single machine or server. This approach has limitations when it comes to processing large volumes of data or complex queries.

- **Parallel Processing:** One of the first solutions to the scalability problem was parallel processing, which involves using multiple machines to process large datasets. This approach allows for faster processing times and can handle larger volumes of data.

- **Distributed Computing:** Distributed computing takes parallel processing to the next level by breaking down a task into smaller sub-tasks that can be processed simultaneously across multiple machines. This approach allows for even faster processing times and can handle even larger volumes of data.

- **Cloud Computing:** Cloud computing has revolutionized the scalability of data analytics by providing on-demand access to computing resources, enabling organizations to scale up or down as needed. This approach allows for cost-effective processing of large volumes of data and enables organizations to take advantage of advanced analytics tools and techniques.

- **Edge Computing:** Edge computing is a newer approach to scalability that involves processing data at the edge of the network, closer to where the data is generated. This approach can help reduce latency and enable real-time processing of data.

Overall, the evolution of analytic scalability has enabled organizations to process larger volumes of data, handle more complex queries, and take advantage of advanced analytics tools and techniques. As data continues to grow at an exponential rate, it is likely that the scalability of analytics will continue to evolve to meet these growing demands.

## Unit 2 - Data Analytics Lifecycle

In this unit, we will learn about the Data Analytics Lifecycle. It is a process of examining data sets in order to draw conclusions about the information they contain. The Data Analytics Lifecycle consists of the following steps:

1. **Business Understanding:** In this step, we define the problem and identify the objectives of the analysis. We also define the success metrics and determine the scope of the analysis.

2. **Data Collection:** In this step, we gather the data from different sources. We collect structured and unstructured data and store it in a suitable format.

3. **Data Preparation:** In this step, we clean the data, remove the missing values, and transform the data into a suitable format for analysis. We also perform feature engineering to create new features that may be helpful during analysis.

4. **Data Analysis:** In this step, we analyze the data using statistical and machine learning algorithms. We identify patterns, trends, and relationships in the data.

5. **Data Visualization:** In this step, we create visualizations that help us to understand the data and communicate the insights to stakeholders. We use charts, graphs, and other visual aids to present the data.

6. **Model Building:** In this step, we build predictive models using the data. We use machine learning algorithms to create models that can make predictions about future events.

7. **Model Deployment:** In this step, we deploy the model in the production environment. We also monitor the performance of the model and make necessary changes to improve its accuracy.

8. **Model Maintenance:** In this step, we maintain the model by updating it with new data and improving its accuracy over time. We also retire the model when it is no longer useful.

By following the Data Analytics Lifecycle, we can ensure that the data analysis process is systematic, efficient, and effective. It helps us to make data-driven decisions and achieve the desired outcomes.

### Model Building

Model building is a crucial step in the data analytics lifecycle. It involves creating a mathematical representation of real-world phenomena to help understand and predict future outcomes. Here are some key points to keep in mind when building models:

- **Data Preparation:** Before building a model, it is important to ensure that the data is clean, complete, and relevant. This involves removing any outliers, filling in missing values, and scaling the data to ensure that all variables are on the same scale.

- **Variable Selection:** Choosing the right variables is critical to building an accurate model. It is important to select variables that are relevant to the problem being solved and that have a strong correlation with the outcome variable.

### K-means for the notes of the Unit 5 - Frequent Itemsets and Clustering in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

K-means is a popular clustering algorithm used in data analytics to group similar data points together. Here are some important points to keep in mind when working with K-means:

- K-means is an iterative algorithm that partitions data points into K clusters based on their similarity.
- The algorithm works by randomly selecting K points as initial centroids and then assigning each data point to the closest centroid.
- After the initial assignments, the algorithm recalculates the centroids of each cluster by taking the mean of all the data points assigned to that cluster.
- It then repeats the assignment and recalculation steps until the centroids no longer change or a maximum number of iterations is reached.
- The value of K must be chosen beforehand and can significantly affect the clustering results. It is often chosen through trial and error or by using domain knowledge.
- K-means is sensitive to the initial centroid selection, so it is common to run the algorithm multiple times with different initializations and choose the result with the lowest sum of squared errors.
- K-means assumes that the clusters are spherical and equally sized, so it may not work well with non-spherical or unevenly sized clusters.
- It is important to preprocess the data before applying K-means to ensure that the results are meaningful. This can include scaling or normalizing the data and handling missing values.
