1. Breadth First Search (BFS)
- Expands neighbor nodes in increasing order of distance from the root node.
- Guarantees shortest path.
- Uses queue data structure - FIFO.

2. Depth First Search (DFS)
- Expands neighbor nodes in decreasing order of distance from the root node.
- Does not guarantee shortest path.
- Uses stack data structure - LIFO.
- Useful for problems like graph connectivity, cycle detection, topological sorting.

3. Greedy Best First Search
- Sorts neighbor nodes according to a heuristic function and expands best node first.
- Does not guarantee optimal solution. Useful for problems with imprecise evaluation functions.

4. A* Search
- Combines greedy and breadth first approach.
- Uses a heuristic function to estimate distance of node from goal.
- Guarantees optimal solution if the heuristic function satisfies certain properties.
- Most optimal search algorithm for many problems.

### Constraint Propagation for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Constraint propagation is a technique used to prune the search space and reduce the complexity of problems.
2. It works by identifying and enforcing constraints between variables to deduce how they can or cannot be assigned.
3. As constraints are identified and enforced, values are eliminated from the possible assignments of variables, thus reducing the search space.
4. This process continues until no more deductions can be made or all variables have a single possible value.
5. If a contradiction is reached at any point (no possible assignments for a variable remain), then the initial constraints were inconsistent and no solution exists.
6. Otherwise, the remaining possible values represent solutions to the constrained problem.
7. Constraint propagation is commonly used in conjunction with search to both reduce the search space and detect failures early.
8. By identifying and enforcing constraints, we can potentially avoid extensive searching of portions of the space that cannot lead to solutions.

### Backtracking Search
- Backtracking search is a general algorithmic technique for solving problems by attempting to build up a solution incrementally until it is complete, with dead ends abandoned.
- It proceeds stepwise, abandoning partial solutions when it is determined that they cannot lead to a complete, valid solution.
- The basic steps of backtracking search are:
1. Start at the initial state.
2. Generate applicable successors to the current state.
3. For each successor, recurse on that state.
4. If a goal state is reached, return the path to it.
5. If no goal state can be reached from the current state (a dead end), return to the previous state.
- Backtracking search is guaranteed to find a solution if one exists, but it may explore some paths more than once and thus may be inefficient. It is often used for problems that require finding all solutions or for problems where an efficient method for determining unproductive paths is difficult to find.
- Examples of problems that can be solved using backtracking search are: sudoku, crossword puzzles, parsing context-free grammars, finding minimal subset sum, graph coloring, etc.
- The key features of backtracking search are: incrementally constructing candidates to the solutions, abandoning each partial candidate (backtracking) as soon as it is found to not lead to a valid solution and recursion that enumerates incomplete candidates.

### Stochastic Games

- Stochastic games are a generalization of Markov decision processes (MDPs) to multiple agents.
- In stochastic games, there are multiple players (agents), each with their own set of actions and rewards.

2. The key steps in IR are:

- Searching: The index is searched to find documents that contain terms similar to the query terms.
- Ranking: The retrieved documents are ranked in the order of their relevance to the user query.
3. IR Evaluation measures:
- Precision: Percentage of retrieved documents that are relevant.
- Recall: Percentage of relevant documents that are retrieved.
- F-measure: Harmonic mean of precision and recall.
4. Types of IR systems:
- Boolean Retrieval: Uses Boolean logic (AND, OR, NOT) to match query terms and index terms.
- Vector Space Model: Documents and queries are represented as vectors and similarity is computed using cosine similarity.
- Probabilistic Retrieval: Models the probability of relevance of a document given the query.
- Language Models: Models the probability of generating a query given a document.

### Speech Recognition for the notes of the Unit 5 - APPLICATIONS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Speech recognition is the inter-disciplinary subfield of computational linguistics that develops methodologies and technologies that enables the recognition and translation of spoken language into text by computers.
2. It incorporates knowledge and research in acoustics, computer science, signal processing, linguistics, and patterns recognition.
3. The core of automatic speech recognition is to determine the most probable corresponding text given the acoustic signal. It requires extracting a set of acoustic features from the raw audio signal and finding the closest match with the models.
4. The steps involved in Speech Recognition are:
- Speech waveform segmentation - Dividing the continuous speech signal into distinct utterances.
- Feature extraction - Converting the raw speech signal into a set of features which contains linguistic information.
- Acoustic modeling - Finding the phonetic transcription of the speech signal based on the extracted features.
- Language modeling - Using the phonetic transcription and other contextual information to find the most probable word sequence.
- Decoding - Combining the output of acoustic model and language model to find the best matching text for the speech signal.
5. Speech recognition has a wide range of applications such as voice assistants, dictation systems, virtual assistants, speech to text converters, etc. The high demand for speech-enabled applications and devices is driving innovation and advancement in this field.
