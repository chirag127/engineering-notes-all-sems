## Unit 3 - Network Layer in Computer Networks

The network layer is the third layer in the OSI model and is responsible for delivering packets from the source to the destination across multiple network segments. In this unit, we will cover the following topics related to the network layer in computer networks:

### 1. Network Layer Functions
- The network layer provides logical addressing and routing services to the transport layer.
- It is responsible for creating and forwarding packets from the source to the destination.
- It also performs fragmentation and reassembly of packets if they are too large to be transmitted over a network.

### 2. Network Layer Protocols
- The most commonly used network layer protocol is the Internet Protocol (IP).
- Other network layer protocols include AppleTalk, IPX, and DECnet.
- Each protocol has its own addressing scheme and routing algorithm.

### 3. Internet Protocol (IP)
- The Internet Protocol (IP) is the most widely used network layer protocol.
- It provides a connectionless, best-effort delivery service to the transport layer.
- IP packets contain source and destination IP addresses, as well as other information used for routing.

### 4. IP Addressing
- IP addresses are 32-bit binary numbers that uniquely identify devices on a network.
- There are two versions of IP addressing: IPv4 and IPv6.
- IPv4 addresses are 32 bits long, while IPv6 addresses are 128 bits long.

### 5. Routing
- Routing is the process of selecting the best path for packets to travel from the source to the destination.
- There are two types of routing: static and dynamic.
- In static routing, the routes are manually configured by a network administrator.
- In dynamic routing, the routes are learned automatically through routing protocols.

### 6. Routing Protocols
- Routing protocols are used to exchange routing information between routers.
- Examples of routing protocols include RIP, OSPF, and BGP.
- Each routing protocol has its own advantages and disadvantages, and is suited for different network topologies and sizes.

By understanding the network layer and its functions, protocols, addressing, and routing, you will have a solid foundation for designing and implementing networks that are efficient, scalable, and reliable.
