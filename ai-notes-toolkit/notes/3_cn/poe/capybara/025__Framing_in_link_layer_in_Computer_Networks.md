#### Framing in link layer in Computer Networks

In computer networks, framing is the process of adding a header and a trailer to the data bits before transmission. The link layer is responsible for framing and is also known as the data link layer.

The following are the key points related to framing in link layer:

- The data link layer divides the stream of bits received from the network layer into manageable frames.
- Each frame has a header and a trailer that contain information about the frame, such as the source and destination addresses.
- The header and trailer are added to the data bits in the transmitting device and removed in the receiving device.
- Framing helps to synchronize the transmission between the sender and receiver.
- There are two main types of framing: character-oriented framing and bit-oriented framing.
- Character-oriented framing uses a special character to indicate the start and end of each frame.
- Bit-oriented framing uses a sequence of bits to indicate the start and end of each frame.
- Framing errors can occur if the start and end of the frame are not detected correctly.
- The cyclic redundancy check (CRC) is used to detect errors in the frame.

In conclusion, framing in the link layer is an essential process in computer networks that helps to ensure the reliable transmission of data between devices. Understanding the different types of framing and how errors can occur is crucial for network engineers and administrators.
