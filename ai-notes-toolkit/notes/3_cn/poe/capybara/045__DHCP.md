#### DHCP

Dynamic Host Configuration Protocol (DHCP) is a network protocol that is used to automatically assign IP addresses and other configuration settings to devices on a network. Here are some points to know about DHCP:

- DHCP is used to assign IP addresses to devices on a network, which enables them to communicate with other devices on the same network.
- DHCP servers are responsible for assigning IP addresses to devices on the network.
- DHCP clients are devices that request an IP address from a DHCP server.
- DHCP servers can also assign other configuration settings to devices, such as subnet masks, default gateways, and DNS servers.
- DHCP relies on a lease system, where the DHCP server leases an IP address to a client for a set amount of time.
- When a device's lease expires, it must request a new IP address from the DHCP server.
- DHCP can be used in both wired and wireless networks.
- DHCP is a widely used protocol in modern networks, as it greatly simplifies the process of assigning IP addresses to devices.
