
#### Link layer switches & bridges in local area network

* A link layer switch is a device that operates at the data link layer (Layer 2) of the OSI model. It is used to interconnect devices on a local area network (LAN).
* A bridge is a device that connects two or more LANs. Bridges can be used to divide a large LAN into smaller LANs, or to join two or more LANs together.
* Link layer switches and bridges are both used to forward data between two or more nodes on a network.
* Link layer switches are more efficient than bridges, as they use hardware-based switching to forward data, while bridges use software-based forwarding.
* Link layer switches and bridges can both be used to provide additional security to a network, by allowing only authorized users to access certain parts of the network.
* Link layer switches and bridges can both be used to provide Quality of Service (QoS) to certain types of traffic, such as voice or video.
