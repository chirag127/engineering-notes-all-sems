
#### Multiple Access Protocols in Medium Access Control

1. **ALOHA**: ALOHA is a simple, uncoordinated multiple access protocol that was developed at the University of Hawaii. It is a slotted version of the original ALOHA protocol, where each station transmits in a pre-defined time slot.

2. **CSMA**: Carrier Sense Multiple Access (CSMA) is a protocol in which each node on the network listens to the channel before transmitting. If the channel is found to be busy, the node will wait until the channel is free before transmitting.

3. **CSMA/CD**: Carrier Sense Multiple Access with Collision Detection (CSMA/CD) is an extension of the CSMA protocol. In addition to carrier sensing, it also detects collisions and retransmits the data after a certain time delay.

4. **TDMA**: Time Division Multiple Access (TDMA) is a multiple access protocol that divides the transmission channel into different time slots. Each node is allocated a specific time slot for transmitting data.

5. **FDMA**: Frequency Division Multiple Access (FDMA) is a multiple access protocol that divides the transmission channel into different frequency bands. Each node is allocated a specific frequency band for transmitting data.

6. **CDMA**: Code Division Multiple Access (CDMA) is a multiple access protocol that uses codes to distinguish between different nodes on the network. Each node is assigned a unique code that is used to identify the node when transmitting data.
