
### File Transfer Protocol in Application Layer

* File Transfer Protocol (FTP) is a network protocol used to transfer files between computers on a network. 
* FTP is part of the Application Layer of the Internet Protocol Suite, and is used to transfer files between computers on the same network or between computers on different networks.
* FTP is a client-server protocol, with the client initiating the connection and the server responding. 
* FTP uses two separate connections, one for data and one for control. The control connection is used to send commands and receive responses, while the data connection is used to send and receive the actual file data.
* FTP supports both active and passive connections. In an active connection, the client initiates the connection to the server, while in a passive connection, the server initiates the connection to the client.
* FTP supports a variety of authentication methods, including clear-text passwords, public key authentication, and Kerberos.
* FTP also supports encryption of data connections through the use of Secure Sockets Layer (SSL) or Transport Layer Security (TLS).
* FTP is widely used to transfer files over the Internet, and is supported by most operating systems.
