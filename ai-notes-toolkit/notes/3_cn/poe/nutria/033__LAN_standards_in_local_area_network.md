
#### LAN standards in local area network

* Ethernet: The most commonly used LAN standard, Ethernet is a set of rules for how computers communicate on a local area network. It is used for both wired and wireless networking.
* Token Ring: Developed by IBM, Token Ring is an older LAN standard that uses a token passing system to control access to the network.
* FDDI: Fiber Distributed Data Interface (FDDI) is a LAN standard that uses fiber optic cables to transmit data.
* Wi-Fi: Wi-Fi is a wireless LAN standard that uses radio waves to transmit data. It is the most popular form of wireless networking.
* Bluetooth: Bluetooth is a wireless LAN standard that uses short-range radio waves to transmit data. It is commonly used for connecting devices such as headphones and mice to computers.
