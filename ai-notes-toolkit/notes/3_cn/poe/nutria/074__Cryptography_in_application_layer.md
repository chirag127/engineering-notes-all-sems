
### Cryptography in Application Layer

1. Cryptography is a method of protecting information and communications through the use of codes, so that only those with the appropriate key can access the information.

2. Cryptography is used in application layer protocols such as SSL/TLS, SSH, and IPsec to ensure secure communication.

3. SSL/TLS is used to secure web traffic and is the primary protocol used for secure web browsing. It uses public key cryptography to encrypt data and authenticate the server and the client.

4. SSH is an application layer protocol used to securely connect to remote computers. It uses public key cryptography to authenticate the user and encrypts all data sent over the connection.

5. IPsec is a suite of protocols used to secure communications at the network layer. It uses a combination of symmetric and asymmetric cryptography to authenticate the sender and encrypt data.
