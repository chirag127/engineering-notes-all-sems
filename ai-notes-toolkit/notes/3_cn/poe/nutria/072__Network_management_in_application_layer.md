
### Network Management in Application Layer

1. Network management is a set of activities that are used to maintain and administer computer networks.
2. Network management can be divided into two categories: physical layer management and application layer management.
3. Physical layer management deals with the physical components of a network, such as cables, routers, and switches.
4. Application layer management deals with the protocols and applications that enable communication between devices.
5. Common application layer protocols include HTTP, FTP, SMTP, and DNS.
6. Application layer network management activities include monitoring network performance, configuring network settings, and troubleshooting problems.
7. Network management tools help to automate many of these activities, making network management easier and more efficient.
