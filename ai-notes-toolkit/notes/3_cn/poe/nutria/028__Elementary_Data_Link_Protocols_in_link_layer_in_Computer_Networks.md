

#### Elementary Data Link Protocols in link layer in Computer Networks

1. The data link layer is responsible for the reliable transfer of data frames from one node to another.
2. It provides the physical transmission of the data and also handles the error control and flow control.
3. The data link layer is divided into two sublayers: the logical link control (LLC) and the media access control (MAC).
4. The LLC layer is responsible for the framing of data and error control.
5. The MAC layer is responsible for the addressing of frames, controlling the access to the medium, and flow control.
6. There are two main types of data link protocols: connection-oriented and connectionless.
7. Connection-oriented protocols are based on the transmission control protocol (TCP) and are used in applications that require reliable data transfer.
8. Connectionless protocols are based on the user datagram protocol (UDP) and are used in applications that don't require reliable data transfer.
9. Examples of connection-oriented protocols are HDLC, PPP, and X.25.
10. Examples of connectionless protocols are Ethernet, Token Ring, and FDDI.
