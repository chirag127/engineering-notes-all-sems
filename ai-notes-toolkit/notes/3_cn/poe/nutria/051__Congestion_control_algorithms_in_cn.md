
### Congestion control algorithms in cn

1. Congestion control algorithms are used to regulate the amount of data that can be sent over a network.

2. The main objective of these algorithms is to ensure that the network is not overloaded and that the data is delivered in a timely manner.

3. The most common congestion control algorithms used in computer networks are:
    * AIMD (Additive Increase Multiplicative Decrease)
    * TCP (Transmission Control Protocol)
    * RED (Random Early Detection)
    * ECN (Explicit Congestion Notification)

4. AIMD is a congestion control algorithm that uses a feedback system to adjust the rate at which data is sent. It works by gradually increasing the amount of data sent until the network becomes congested, at which point the rate is decreased.

5. TCP is the most widely used congestion control algorithm. It works by monitoring the amount of data that is sent and adjusting the rate accordingly.

6. RED is a congestion control algorithm that works by randomly dropping packets when the network is congested. This helps to reduce the amount of data sent and prevent the network from becoming overloaded.

7. ECN is a congestion control algorithm that works by explicitly sending a notification to the sender when the network is congested. This helps to reduce the amount of data sent and prevent the network from becoming overloaded.
