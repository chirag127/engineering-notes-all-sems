
### Window Management in Transport Layer

* Window Management is the process of managing the flow of data between two endpoints in a network. 
* It is used to ensure that data is transmitted in an efficient and reliable manner, while also providing flow control.
* The Transport Layer of the OSI model is responsible for the delivery of data from one application to another.
* Window Management is an important part of the Transport Layer, as it is used to regulate the amount of data that can be sent or received at any given time.
* The window size is determined by the sender and receiver, and is based on the amount of data that can be transmitted without causing congestion. 
* The sender will send a window size to the receiver, and the receiver will then adjust the window size according to the amount of data that can be sent without causing congestion.
* The window size is dynamic and can be adjusted as needed. If the receiver is unable to receive the data, the sender will reduce the window size. 
* If the receiver is receiving data too slowly, the sender will increase the window size.
* The window size is also used to ensure that data is delivered in the correct order. 
* The sender will keep track of the data that has been sent and the data that has been received. 
* If the data is received out of order, the sender will request that the receiver re-send the data. 
* Window Management is an important part of the Transport Layer, as it ensures that data is transmitted efficiently and reliably.
