
## Unit 2 - Link Layer in Computer Networks and Medium Access Control and Local Area Networks

1. The link layer is the lowest layer of the OSI model. It is responsible for providing reliable data transfer between two nodes located on the same physical medium. 
2. The link layer provides services such as error detection and correction, flow control, and media access control. 
3. Error detection and correction is a process that detects and corrects errors that may occur during data transmission. This is done by adding a checksum to the data packet, which is used to verify the integrity of the data. 
4. Flow control is used to ensure that the data transmission rate is the same at both ends of the link. This is done by regulating the rate at which data is sent from one end of the link to the other. 
5. Media access control is used to ensure that only one node at a time has access to the medium. This is done by using a protocol such as CSMA/CD (Carrier Sense Multiple Access/Collision Detection). 
6. Local area networks (LANs) are networks that are used to connect computers in a small geographic area. These networks are typically used to share resources such as printers and files. 
7. The link layer is responsible for providing reliable data transfer between two nodes located on the same LAN. This is done by using protocols such as Ethernet, Token Ring, and FDDI.
