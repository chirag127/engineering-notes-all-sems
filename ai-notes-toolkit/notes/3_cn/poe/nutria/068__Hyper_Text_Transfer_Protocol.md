
### Hyper Text Transfer Protocol

- Hyper Text Transfer Protocol (HTTP) is a protocol used for communication between clients and servers on the World Wide Web. 
- It is a request-response protocol, meaning that a client requests a resource from a server and the server responds with the requested resource. 
- HTTP is based on the Transmission Control Protocol (TCP) and is used to transfer data in the form of HTML documents, images, videos, and other types of files.
- HTTP is stateless, meaning that each request is independent of all other requests. 
- Requests are sent using methods such as GET, POST, PUT, and DELETE. 
- HTTP is a text-based protocol and is composed of a set of rules and guidelines for communication between clients and servers. 
- HTTP is an application-layer protocol and is used to transfer data between web browsers and web servers. 
- HTTP is secure and can be used to transfer sensitive information such as credit card numbers. 
- HTTP is used for transmitting and receiving data over the internet and is the most widely used protocol on the web.
