
#### ICMP

* Internet Control Message Protocol (ICMP) is a protocol used by network devices, such as routers, to communicate with each other. It is used to provide feedback on the status of the network, report errors, and provide other useful information.
* ICMP messages are sent in the form of packets, which contain information about the source and destination of the message, as well as the message itself.
* ICMP messages are used for a variety of purposes, such as informing a host that a destination is unreachable, notifying a router of a problem with a link, or providing information about network performance.
* ICMP is an integral part of the IP protocol, and is used by network devices to keep the network running smoothly. It is also used for troubleshooting and diagnosing network problems.
