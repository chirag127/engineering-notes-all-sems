
### Forwarding and Delivery in Network Layer

1. **Forwarding** is the process of sending data packets from a source node to a destination node across a network. It is the responsibility of the network layer to ensure that packets are delivered correctly and efficiently. 

2. The network layer is responsible for routing packets through intermediate nodes, which requires the use of routing algorithms. These algorithms determine the best path for a packet to take from the source node to the destination node. 

3. **Delivery** is the process of ensuring that packets are delivered to the correct destination. This is done by using the addressing information included in the packet header. 

4. To ensure delivery, the network layer must be able to detect and correct errors that occur during transmission. This is done using error-detection and error-correction protocols. 

5. The network layer also provides a number of other services, such as flow control, congestion control, and quality of service (QoS). These services are used to ensure that data is delivered in an efficient and reliable manner.
