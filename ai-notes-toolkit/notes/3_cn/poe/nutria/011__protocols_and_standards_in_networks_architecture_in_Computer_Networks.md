

#### Protocols and Standards in Networks Architecture in Computer Networks

1. **TCP/IP**: The Transmission Control Protocol/Internet Protocol (TCP/IP) is the most widely used network protocol suite. It is a set of rules and guidelines that define how data is transmitted across a network. It is used for communication between two or more computers on a network.

2. **Ethernet**: Ethernet is a networking technology that allows computers to communicate with each other over a local area network (LAN). It is the most widely used LAN technology and is based on the IEEE 802.3 standard.

3. **IPv4 and IPv6**: IPv4 and IPv6 are two versions of Internet Protocol (IP) addresses. IPv4 is the most widely used version of IP and is used to identify a computer on a network. IPv6 is the newer version and is used to provide more addresses than IPv4.

4. **Routing Protocols**: Routing protocols are used to determine the best path for data to travel from one computer to another. Examples of routing protocols include Open Shortest Path First (OSPF), Border Gateway Protocol (BGP), and Routing Information Protocol (RIP).

5. **Network Security Protocols**: Network security protocols are used to secure data as it is transmitted over a network. Examples of network security protocols include Secure Socket Layer (SSL), Transport Layer Security (TLS), and Secure Shell (SSH).
