
### Multiplexing in transport layer

* Multiplexing is a process that enables multiple digital signals to be sent over a single physical connection. 
* In the transport layer, multiplexing is used to send multiple streams of data over a single connection. 
* Multiplexing is accomplished by dividing the data stream into smaller chunks, and then assigning each chunk a unique identifier. 
* The receiver then reads the identifier and reconstructs the data stream. 
* Multiplexing allows for efficient use of the physical connection, since multiple data streams can be sent over the same connection. 
* It also allows for better bandwidth utilization, since the physical connection can be used by multiple users at the same time. 
* Multiplexing is used in many different applications, such as streaming media, teleconferencing, and online gaming.
