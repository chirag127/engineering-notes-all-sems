#### Multiple access protocols in medium access control

1. Time Division Multiple Access (TDMA):
- Each device is allocated a different time slot within the channel.
- Device can only transmit in its allocated time slot.
- Allows multiple devices to share the channel.
- Requires synchronization between the devices and base station.

2. Frequency Division Multiple Access (FDMA):
- The available bandwidth is divided into different frequency ranges.
- Each device is allocated a different frequency range.
- Device can only transmit in its allocated frequency range.
- Allows multiple devices to share the channel.
- Frequency allocation needs to avoid interference between adjacent channels.

3. Code Division Multiple Access (CDMA):
- Each device is allocated a unique code.
- Device spreads its signal across the bandwidth using its unique code.
- Receiver uses the code to recover the signal.
- Allows multiple devices to share the channel.
- Code allocation needs to minimize interference between devices.

4. Space Division Multiple Access (SDMA):
- Uses antenna arrays to create spatial beams.
- Each device is allocated a different spatial beam.
- Device can only transmit in its allocated spatial beam.
- Allows multiple devices to share the channel.
- Requires complex antenna arrays and signal processing.
