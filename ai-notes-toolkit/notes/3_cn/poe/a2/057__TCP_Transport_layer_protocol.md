#### TCP Transport layer protocol

1. TCP is a transport layer protocol that provides reliable, ordered, and error-checked delivery of transmitted data over IP networks.
2. TCP establishes a dedicated end-to-end connection between two hosts.
3. TCP uses a three-way handshake to establish a connection between two hosts.
4. TCP provides reliable data transmission with the help of sequence and acknowledgement numbers. The sender assigns a sequence number to each byte transmitted and the receiver acknowledges the data by sending an acknowledgement number.
5. TCP provides in-order delivery of data. The receiving host reassembles the received data in the correct order using the sequence numbers.
6. TCP provides flow control and congestion control. The sender cannot overwhelm the receiver with data. TCP uses sliding window protocol for flow control.
7. TCP provides full duplex data transmission. Data can be transmitted in both directions simultaneously.
8. The TCP header includes source and destination port numbers, sequence and acknowledgement numbers, header length, reserved flags, and window size.
9. Common TCP protocols include HTTP, FTP, SMTP, and Telnet. HTTP uses TCP port 80, FTP uses TCP port 21, SMTP uses TCP port 25, and Telnet uses TCP port 23.
