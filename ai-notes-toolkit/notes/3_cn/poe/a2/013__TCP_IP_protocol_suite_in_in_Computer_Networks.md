#### TCP/IP protocol suite in Computer Networks

1. TCP/IP model: The TCP/IP protocol suite is a set of protocols developed by DARPA for communication over packet-switched networks. It consists of four layers:

- Link layer: Handles data transmission over physical network medium. Examples: Ethernet, Wi-Fi.
- Internet layer: Handles IP addressing and routing. Example: IP.
- Transport layer: Provides end-to-end communication services. Examples: TCP, UDP.
- Application layer: Provides services to applications. Examples: HTTP, FTP, SMTP, DNS.

2. IP (Internet Protocol): The primary protocol at the internet layer. It is responsible for addressing and routing packets across networks. It is a connectionless protocol and provides best-effort delivery. Two versions are IPv4 and IPv6.
3. TCP (Transmission Control Protocol): A transport layer protocol that provides reliable, ordered, and error-checked delivery of sent packets over IP networks. It is a connection-oriented protocol.
4. UDP (User Datagram Protocol): A transport layer protocol that provides fast but unreliable delivery of packets over IP networks. It is a connectionless protocol.
