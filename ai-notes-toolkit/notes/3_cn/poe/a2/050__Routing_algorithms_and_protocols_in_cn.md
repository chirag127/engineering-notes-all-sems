### Routing algorithms and protocols in cn

1. Distance vector routing protocol:
- Routing table contains distances to destinations
- Regular updates to neighbors with distance vector
- Count to infinity problem can occur
- Examples: RIP, BGP

2. Link state routing protocol:
- Routing table contains complete map of network topology
- Regular flooding of link state updates
- Examples: OSPF, IS-IS

3. Hierarchical routing:
- Divide network into areas to reduce routing overhead
- Route between areas using default routes and summary routes
- Example: OSPF hierarchical design

4. Policy-based routing:
- Routing decisions based on criteria other than destination address
- Examples: Load balancing, QoS routing

5. Multicast routing:
- Delivery of data from one to many destinations efficiently
- Uses reverse path forwarding algorithm to build multicast tree
- Examples: PIM, DVMRP, MOSPF
