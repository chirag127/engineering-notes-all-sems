#### Flow control in link layer in Computer Networks.

1. Flow control is a technique to regulate the rate of data transmission between two nodes to prevent overflow.
2. In link layer, flow control is implemented using acknowledgements and window size.
3. Sender can transmit only a fixed number of frames (specified by window size) without receiving an acknowledgement.
4. Receiver sends acknowledgement for the frames received. On receiving acknowledgement, sender sends the next set of frames.
5. If acknowledgement is not received within a time period, sender retransmits the frames.
6. This mechanism ensures that receiver buffer does not get overflown and no frames are lost.
7. Sliding window protocol is an example of flow control mechanism used in link layer.
