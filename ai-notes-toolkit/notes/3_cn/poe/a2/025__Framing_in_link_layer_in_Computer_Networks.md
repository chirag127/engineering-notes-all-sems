#### Framing in link layer in Computer Networks.

1. Framing is a technique employed by the link layer to distinguish between multiple messages in a single transmission on the physical medium.
2. Each message is divided into separate frames comprising of control information and the actual message data.
3. The control information is added by the link layer and is removed by the receiver before passing the message to the upper layer.
4. The key purposes of framing are:
- Synchronization: Allow the receiver to identify the starting and ending of each frame.
- Error detection: Include error detection codes to check for errors.
- Flow control: Include sequence numbers to identify the order of frames.
- Addressing: Include source and destination addresses in the frame header.
