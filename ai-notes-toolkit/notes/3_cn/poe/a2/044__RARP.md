#### RARP

Reverse Address Resolution Protocol (RARP) is a protocol by which a physical machine in a local area network can request to learn its Internet Protocol (IP) address, given its physical, or hardware, address.

- RARP is primarily used to obtain an IP address when a machine is booted and its IP address is unknown. The physical address is used to identify the machine.
- The RARP request is broadcast on the local network and handled by a RARP server, which looks up the physical address in a table to find the corresponding IP address.
- The RARP server then sends a RARP reply unicast back to the requesting machine with the IP address.
- RARP has largely been superseded by the Bootstrap Protocol (BOOTP) and the Dynamic Host Configuration Protocol (DHCP), which serve a similar purpose but are more flexible and feature-rich.
- However, RARP may still be used in some scenarios involving devices with limited capabilities or lacking DHCP support.
