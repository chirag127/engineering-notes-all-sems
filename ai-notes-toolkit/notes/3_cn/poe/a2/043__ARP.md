#### ARP

ARP stands for Address Resolution Protocol. It is a protocol used to map IP addresses to MAC addresses.

- ARP is used when a device needs to send data to another device on the same network. It sends out an ARP broadcast to get the MAC address of the destination IP address.
- The device with the destination IP address responds with its MAC address. The sending device then uses this MAC address to send the data.
- ARP caches the IP-MAC mapping to speed up future communications to the same device.
- ARP is used on local networks and is not routed between networks.
- ARP spoofing is a threat where a malicious actor sends spoofed ARP replies to redirect traffic to itself. This can be used to conduct man-in-the-middle attacks.
- Secure ARP protocols like ARPsec and SAE (Secure Address Encapsulation) can be used to help prevent ARP spoofing.
