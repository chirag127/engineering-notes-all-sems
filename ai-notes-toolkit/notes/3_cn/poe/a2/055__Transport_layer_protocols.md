### Transport layer protocols

1. TCP (Transmission Control Protocol):
- Connection-oriented protocol (establishes dedicated end-to-end connection between two hosts before data transmission)
- Provides reliable data transmission with in-order delivery
- Uses 3-way handshake to establish connection
- Uses sequence and acknowledgement numbers to achieve reliability
- Provides congestion control to avoid congestion collapse
- Used by applications requiring high reliability such as HTTP, SMTP, FTP, etc.

2. UDP (User Datagram Protocol):
- Connectionless protocol (does not establish dedicated end-to-end connection)
- Provides fast but unreliable data transmission (does not guarantee delivery or ordering)
- Used by applications requiring fast data transmission such as video streaming, DNS, etc. where some loss is tolerable.

3. SCTP (Stream Control Transmission Protocol):
- Connection-oriented protocol
- Provides reliable and unreliable data transmission
- Multi-homing and multi-streaming capabilities to provide more robust data transmission
- Used for signaling and control information in telecommunication networks
