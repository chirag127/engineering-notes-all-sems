### Routing in network layer

1. Routing is the process of selecting paths in a network along which to send network traffic. Routing is performed for both incoming and outgoing data.
2. The network layer of the OSI model is responsible for packet forwarding including routing of incoming and outgoing messages.
3. The main components involved in routing are:
- Routers: Routers connect multiple networks and forward traffic based on routing tables and routing protocols.
- Routing tables: Routing tables contain information about available routes and help routers determine the best path for forwarding packets.
- Routing protocols: Routing protocols are used to update routing tables and communicate between routers. Examples include RIP, OSPF, BGP, etc.
4. Routing can be static or dynamic. In static routing, routes are manually configured in routing tables. In dynamic routing, routes are automatically learned and updated using routing protocols.
5. The goals of routing are to minimize delays, maximize throughput, maximize reliability and maximize security.
