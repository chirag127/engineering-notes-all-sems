#### Network Components in Computer Networks

1. Hosts: Hosts refer to end devices that are connected to a network and are used to generate or consume data or resources. Examples include personal computers, servers, routers, etc.

2. Transmission media: Transmission media refer to the physical pathways that are used to transmit signals between hosts. For example, cables, wireless channels, etc. The medium chosen depends on factors like cost, bandwidth, error rate, security, etc.

3. Network devices: Network devices refer to the intermediary devices that are used to enable communication between hosts and facilitate functions like routing, switching, etc. Examples include switches, routers, firewalls, etc.

4. Network interfaces: The network interfaces refer to the ports on the hosts and network devices that are used to physically connect to a transmission medium. For example, Ethernet ports, USB ports, etc. The interfaces convert data from the device into signals suitable for transmission over the chosen medium.

5. Protocols: Protocols are the rules and conventions that are used to facilitate communication between devices in a network. They govern parameters like format of the data, error handling, flow control, etc. Examples include IP, TCP, UDP, Ethernet, etc. Protocols work in layers to process and deliver data between network devices.
