#### LAN standards in local area network

1. Ethernet: Ethernet is a family of computer networking technologies commonly used in local area networks (LAN), metropolitan area networks (MAN) and wide area networks (WAN). It defines wiring and signaling for the physical layer and data link layer of the OSI model network architecture.

2. Token Ring: Token Ring is a computer networking technology used to build local area networks. It uses a special three-byte frame called a token that travels around a logical ring of workstations or servers. This token passing is a channel access method providing fair access for all stations, and elimination of collisions.

3. FDDI: Fiber Distributed Data Interface (FDDI) is a standard for data transmission in a local area network. It uses optical fiber as the physical medium and supports transmission speeds of 100 megabits per second. FDDI provides a high-speed fault tolerant shared communications medium.

4. Wireless LAN: Wireless LAN (WLAN) is a wireless local area network, which is the linking of two or more computers or other devices wirelessly to share network resources. WLAN devices operate in the 2.4, 3.6, 5 or 60 GHz frequency bands and provide coverage areas from tens to thousands of feet. Standards include IEEE 802.11, the HiperLAN standards and other protocols.
