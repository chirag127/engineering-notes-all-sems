#### Services in Network Architecture

1. Client-Server Model: In this model, services are provided by servers to clients. The clients send requests to the servers and servers process the requests and send responses back to the clients. For example, a web browser is a client that sends requests to web servers and receives web pages in response.

2. Peer-to-Peer Model: In this model, nodes in the network act as both clients and servers. The nodes share resources and services directly with each other instead of using dedicated servers. For example, in peer-to-peer file sharing networks, the nodes directly share files with each other.

3. Client-Cache Model: In this model, clients can cache the data obtained from the servers to service future client requests. This reduces the load on servers and provides faster access to data for clients. For example, web browsers cache website content to serve web page requests faster. However, the cached data may become stale if it is not updated from the server periodically.

4. Multicast Delivery Model: In this model, servers send one data stream that is received by multiple clients. This is more efficient than sending separate unicast streams to each client. For example, media streaming services use multicast to deliver video and audio to multiple users simultaneously. However, multicast routing and delivery is more complex to implement.
