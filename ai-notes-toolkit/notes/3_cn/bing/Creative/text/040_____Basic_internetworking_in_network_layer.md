### Basic internetworking in network layer

- Internetworking is the process of connecting different networks using routers and other devices that operate at the network layer of the OSI model .
- An internetwork is a collection of networks that can communicate with each other using a common protocol, such as the Internet Protocol (IP).
- Internetworking enables data exchange and resource sharing across heterogeneous networks, such as Ethernet, wireless, and point-to-point links.
- Internetworking requires addressing and routing mechanisms to identify and deliver packets to the correct destination network and host.
- There are three types of internetwork addresses that are commonly used: data-link layer addresses, media access control (MAC) addresses, and network-layer addresses.
- Data-link layer addresses are used to identify each physical network connection of a network device, such as a network interface card (NIC).
- MAC addresses are a type of data-link layer addresses that are assigned by the manufacturer of the NIC and are usually fixed and unique.
- Network-layer addresses are logical addresses that are assigned by the network administrator or the network service provider and can be changed or reassigned.
- IP addresses are a type of network-layer addresses that are used to identify each host and network in an internetwork.
- Routers are the devices that interconnect different networks and perform the internetworking functions of addressing and routing.
- Routers use routing tables and routing protocols to determine the best path for each packet to reach its destination.
- The Internet is the most notable example of an internetwork that connects millions of networks and hosts using the TCP/IP protocol suite .
- The Internet is composed of four layers: the network access layer, the internetwork layer, the host-to-host transport layer, and the application layer.
- The network access layer defines the physical and data-link layer specifications for different types of networks, such as Ethernet, wireless, and point-to-point links.
- The internetwork layer defines the IP protocol and its related functions, such as addressing, fragmentation, and error handling.
- The host-to-host transport layer defines the TCP and UDP protocols and their related functions, such as reliability, flow control, and port numbers.
- The application layer defines the protocols and services that are used by applications to communicate with each other, such as HTTP, FTP, and SMTP.
