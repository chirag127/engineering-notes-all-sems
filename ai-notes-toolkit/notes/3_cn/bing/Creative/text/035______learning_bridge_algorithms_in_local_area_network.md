#### Learning bridge algorithms in local area network

- A bridge is a device that connects two or more local area networks (LANs) and forwards frames based on their destination MAC addresses.
- A bridge algorithm is a set of rules or procedures that a bridge uses to decide which frames to forward, which frames to filter, and which ports to use.
- There are different types of bridge algorithms, such as transparent bridging, source routing bridging, and spanning tree protocol.
- Transparent bridging is the most common type of bridge algorithm. It uses a self-learning technique to build and maintain a forwarding table that maps MAC addresses to ports.
- Source routing bridging is used in token ring networks. It requires the source station to specify the path of the frame in the header, using a route discovery process.
- Spanning tree protocol is a bridge algorithm that prevents loops in a network with redundant links. It creates a logical tree topology by blocking some ports and allowing only one path between any two LANs.
