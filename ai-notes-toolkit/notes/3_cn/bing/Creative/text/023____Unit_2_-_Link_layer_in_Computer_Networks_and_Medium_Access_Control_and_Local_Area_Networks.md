## Unit 2 - Link layer in Computer Networks and Medium Access Control and Local Area Networks

- The link layer is the lowest layer in the TCP/IP model. It is responsible for sending and receiving frames between nodes on the same physical link.
- A frame is a unit of data that contains a header, a payload, and a trailer. The header contains information such as the source and destination addresses, the type of data, and the error detection code. The payload is the actual data to be transmitted. The trailer contains a special sequence of bits that marks the end of the frame.
- The link layer has two main functions: framing and error control. Framing is the process of dividing the data stream into frames and adding headers and trailers. Error control is the process of detecting and correcting errors that may occur during transmission.
- The link layer can use different techniques for error control, such as parity bits, checksums, cyclic redundancy checks (CRCs), and automatic repeat request (ARQ). Parity bits are extra bits that are added to the data to make the number of 1s even or odd. Checksums are values that are computed from the data and appended to the frame. CRCs are more complex checksums that use polynomial division. ARQ is a protocol that requires the sender to wait for an acknowledgment from the receiver before sending the next frame. If the acknowledgment is not received within a certain time, the sender retransmits the frame.
- The link layer can also use different techniques for medium access control (MAC), which is the process of coordinating the access of multiple nodes to a shared medium, such as a cable or a wireless channel. MAC techniques can be classified into two categories: deterministic and probabilistic. Deterministic techniques use a predefined order or schedule to determine which node can transmit at a given time. Probabilistic techniques use randomization or contention to decide which node can transmit at a given time.
- Some examples of deterministic MAC techniques are time division multiple access (TDMA), frequency division multiple access (FDMA), and code division multiple access (CDMA). TDMA divides the time into slots and assigns each slot to a node. FDMA divides the frequency into channels and assigns each channel to a node. CDMA assigns a unique code to each node and allows them to transmit simultaneously using different codes.
- Some examples of probabilistic MAC techniques are carrier sense multiple access (CSMA), carrier sense multiple access with collision detection (CSMA/CD), and carrier sense multiple access with collision avoidance (CSMA/CA). CSMA requires the node to sense the medium before transmitting and wait if the medium is busy. CSMA/CD requires the node to sense the medium during transmission and abort if a collision is detected. CSMA/CA requires the node to exchange control frames with the intended receiver before transmitting and avoid collisions by using a backoff algorithm.
- A local area network (LAN) is a network that connects devices within a small geographic area, such as a building or a campus. LANs typically use a single link layer technology and a single MAC technique. LANs can be classified into two types: wired and wireless. Wired LANs use cables, such as twisted pair, coaxial, or fiber optic, to connect the devices. Wireless LANs use radio waves, such as infrared, microwave, or radio frequency, to connect the devices.
- Some examples of wired LAN technologies are Ethernet, token ring, and fiber distributed data interface (FDDI). Ethernet is the most widely used LAN technology. It uses CSMA/CD as the MAC technique and supports various data rates, such as 10 Mbps, 100 Mbps, 1 Gbps, and 10 Gbps. Token ring is a LAN technology that uses a ring topology and a token-passing protocol as the MAC technique. It supports a data rate of 4 Mbps or 16 Mbps. FDDI is a LAN technology that uses a dual ring topology and a token-passing protocol as the MAC technique. It supports a data rate of 100 Mbps and uses fiber optic cables.
- Some examples of wireless LAN technologies are Wi-Fi, Bluetooth, and ZigBee. Wi-Fi is the most widely used wireless LAN technology. It uses CSMA/CA as the MAC technique and supports various standards, such as 802.11a, 802.11b, 802.11g, 802.11n, and 802.11ac. These standards differ in the frequency band, the modulation scheme, the channel width, and the data rate. Bluetooth is a wireless LAN technology that uses a frequency hopping spread spectrum (FHSS) technique and supports various versions, such as Bluetooth 1.0, Bluetooth 2.0, Bluetooth 3.0, and Bluetooth 4.0.
