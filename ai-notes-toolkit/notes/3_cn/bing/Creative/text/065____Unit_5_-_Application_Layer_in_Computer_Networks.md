## Unit 5 - Application Layer in Computer Networks

- The application layer is the topmost layer of the TCP/IP model that provides the interface between the applications and the network.
- The application layer defines the protocols that enable different processes and applications to communicate and exchange data over the network.
- The application layer protocols are specific to the type and purpose of the applications, such as web browsing, email, file transfer, remote login, etc.
- Some of the common application layer protocols are:

  - **Hypertext Transfer Protocol (HTTP)**: It is the protocol that governs the communication between web browsers and web servers. It defines how the browsers request and receive web pages, images, videos, and other resources from the servers. It also defines how the servers respond to the requests and send the requested resources. HTTP uses the TCP protocol at the transport layer to ensure reliable and ordered delivery of data.
  - **Domain Name System (DNS)**: It is the protocol that maps the human-readable domain names (such as www.google.com) to the numerical IP addresses (such as 172.217.160.78) that identify the network devices. It enables the users to access the websites and services by using the domain names instead of the IP addresses. DNS uses both TCP and UDP protocols at the transport layer, depending on the size and type of the queries and responses.
  - **Simple Mail Transfer Protocol (SMTP)**: It is the protocol that enables the sending and receiving of email messages over the network. It defines how the email clients and servers interact and exchange the email messages. It also defines the format and structure of the email messages, such as the header, body, attachments, etc. SMTP uses the TCP protocol at the transport layer to ensure reliable and ordered delivery of email messages.
  - **Post Office Protocol (POP)** and **Internet Message Access Protocol (IMAP)**: They are the protocols that enable the email clients to retrieve the email messages from the email servers. They differ in the way they handle the email messages on the server. POP downloads the email messages from the server to the client and deletes them from the server, while IMAP synchronizes the email messages between the server and the client and keeps them on the server. POP and IMAP use the TCP protocol at the transport layer to ensure reliable and ordered delivery of email messages.
  - **File Transfer Protocol (FTP)**: It is the protocol that enables the transfer of files between the network devices. It defines how the file clients and servers interact and exchange the files. It also defines the commands and responses for establishing the connection, authentication, file listing, file uploading, file downloading, etc. FTP uses two TCP connections at the transport layer, one for control and one for data, to ensure reliable and ordered delivery of files.
  - **Telnet** and **Secure Shell (SSH)**: They are the protocols that enable the remote login and access to the network devices. They differ in the way they handle the security and encryption of the data. Telnet sends the data in plain text, while SSH encrypts the data using public-key cryptography. Telnet and SSH use the TCP protocol at the transport layer to ensure reliable and ordered delivery of data.
