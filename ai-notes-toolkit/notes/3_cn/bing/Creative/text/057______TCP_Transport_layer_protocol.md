#### TCP Transport layer protocol

- TCP stands for Transmission Control Protocol  .
- It is a transport layer protocol that facilitates the transmission of packets from source to destination   .
- It is a connection-oriented protocol that means it establishes the connection prior to the communication that occurs between the computing devices in a network  .
- TCP is a reliable protocol as it follows the flow and error control mechanism. It also supports the acknowledgment mechanism, which checks the state and sound arrival of the data .
- TCP uses a three-way handshake to establish the connection between the sender and the receiver. The three steps are: SYN, SYN-ACK, and ACK .
- TCP uses a four-way handshake to close the connection between the sender and the receiver. The four steps are: FIN, ACK, FIN, ACK .
- TCP provides various features such as congestion control, flow control, sequencing, retransmission, and multiplexing .
- TCP is suitable for applications that require reliable and ordered delivery of data, such as web browsing, email, file transfer, etc .
