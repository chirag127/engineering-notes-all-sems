#### IP

- IP stands for Internet Protocol, which is a set of rules that govern how data is transmitted and received over the internet.
- An IP address is a unique numerical label that identifies a device on a network that uses the IP protocol. For example, 192.0.2.1 is an IP address.
- There are two versions of IP: IPv4 and IPv6. IPv4 uses 32-bit addresses, which can support up to 4.3 billion devices. IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 devices.
- IP addresses can be classified into two types: public and private. Public IP addresses are visible to the internet and can be used to communicate with other devices across the world. Private IP addresses are not visible to the internet and can only be used to communicate with devices within a local network.
- IP addresses can also be classified into two categories: static and dynamic. Static IP addresses are fixed and do not change over time. Dynamic IP addresses are assigned by a server and can change over time.
- IP addresses are assigned by internet service providers (ISPs) or network administrators. To find your IP address on a Windows device, you can follow these steps:

  - On the taskbar, select Wi-Fi network > the Wi-Fi network you're connected to > Properties.
  - Under Properties, look for your IP address listed next to IPv4 address.

- IP addresses are used for various purposes, such as:

  - Network interface identification: IP addresses help devices to identify each other on a network and establish connections.
  - Location addressing: IP addresses help devices to locate each other on the internet and route data packets to the correct destination.
  - IP tracing: IP addresses can be used to trace the origin and location of an email, a website, or a device.
  - IP hiding: IP addresses can be hidden or changed by using proxy servers, VPNs, or Tor, which can enhance privacy and security.

- Some advantages of IP are:

  - It is a universal and standard protocol that can be used by any device on the internet.
  - It is scalable and flexible, as it can support different types of networks and devices.
  - It is reliable and robust, as it can handle errors and failures in the network.

- Some disadvantages of IP are:

  - It is vulnerable to security threats, such as hacking, spoofing, or interception.
  - It is inefficient and wasteful, as it can cause network congestion and packet loss.
  - It is limited and insufficient, as it can run out of address space and cannot support all the features and functions of the internet.

- Some examples of IP applications are:

  - Web browsing: IP addresses are used to access websites and web pages on the internet.
  - Email: IP addresses are used to send and receive emails over the internet.
  - Online gaming: IP addresses are used to connect and play with other players online.
  - Streaming: IP addresses are used to stream and watch videos, music, or podcasts online.

- Some mnemonics and learning tricks for IP are:

  - IP = I Play: IP is used for playing online games and streaming online media.
  - IP = Internet Protocol: IP is the protocol that enables internet communication and data transmission.
  - IP = In Pieces: IP divides data into packets and sends them over the network in pieces.
