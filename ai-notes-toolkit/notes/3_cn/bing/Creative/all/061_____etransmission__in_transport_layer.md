# Transmission in Transport Layer

The transport layer is the fourth layer of the OSI model, which provides end-to-end communication between application processes running on different hosts within a network. The transport layer performs the following functions:

- It takes the data from the upper layer (application layer), and it divides the data into smaller packets, called segments, and then transmits them to the network layer (layer 3).
- It assigns a port number to each segment, which identifies the source and destination application processes. The port number is a 16-bit number that ranges from 0 to 65535. The port number is added to the segment header, along with other information such as sequence number, acknowledgment number, checksum, etc.
- It ensures reliable transmission of segments by using mechanisms such as flow control, error control, and congestion control. Flow control regulates the rate of data transmission between the sender and the receiver, to avoid buffer overflow. Error control detects and corrects errors in the segments, by using techniques such as checksum, acknowledgment, and retransmission. Congestion control prevents network congestion by adjusting the window size or the sending rate of the sender, based on the feedback from the network or the receiver.
- It provides two modes of transmission: connection-oriented and connectionless. Connection-oriented transmission establishes a logical connection between the sender and the receiver before sending the data, and maintains the connection until the data transfer is complete. Connectionless transmission does not require a connection establishment or termination, and sends the data as independent datagrams. Connection-oriented transmission is more reliable and ordered, but also more complex and overhead. Connectionless transmission is simpler and faster, but also less reliable and unordered.

The most common transport protocols of TCP/IP are the Transmission Control Protocol (TCP) and the User Datagram Protocol (UDP). TCP is a connection-oriented protocol that provides reliable, ordered, and error-free transmission of segments. UDP is a connectionless protocol that provides fast, simple, and unreliable transmission of datagrams. TCP is used for applications that require high reliability and accuracy, such as web browsing, email, file transfer, etc. UDP is used for applications that can tolerate some loss and delay, such as video streaming, voice over IP, online gaming, etc.
