#### LAN standards in local area network

- A local area network (LAN) is a data communication network connecting various terminals or computers within a building or a limited geographical area.
- The connection among the devices in a LAN could be wired or wireless.
- LAN standards are the specifications and protocols that define the operation and performance of a LAN.
- The most widely used and recognized family of LAN standards is the IEEE 802 series , which covers various aspects of LAN technologies, such as Ethernet, Wireless LAN, Bridging, and Media Access Control .
- The IEEE 802 series consists of twelve members, numbered 802.1 through 802.12, with a focus group of the IEEE 802 LAN/MAN Standards Committee (LMSC) devoted to each.
- The following table summarizes the main IEEE 802 standards and their functions :

| Standard | Function |
| -------- | -------- |
| 802.1    | Higher layer LAN protocols, such as bridging, security, and network management |
| 802.2    | Logical link control, which provides a common interface for different MAC protocols |
| 802.3    | Ethernet, which is the most widely used LAN technology based on CSMA/CD |
| 802.4    | Token bus, which is a LAN technology based on token passing in a bus topology |
| 802.5    | Token ring, which is a LAN technology based on token passing in a ring topology |
| 802.6    | Metropolitan area network (MAN), which is a network that covers a larger area than a LAN |
| 802.7    | Broadband LAN using coaxial cable, which is a LAN technology that uses frequency division multiplexing |
| 802.8    | Fiber optic LAN, which is a LAN technology that uses optical fibers as the transmission medium |
| 802.9    | Integrated services LAN, which is a LAN technology that supports both voice and data traffic |
| 802.10   | LAN security, which is a standard that defines encryption and authentication mechanisms for LANs |
| 802.11   | Wireless LAN, which is a LAN technology that uses radio waves as the transmission medium |
| 802.12   | Demand priority LAN, which is a LAN technology that uses a priority-based access method |
