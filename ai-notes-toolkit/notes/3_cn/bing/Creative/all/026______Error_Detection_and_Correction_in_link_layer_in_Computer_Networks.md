#### Error Detection and Correction in link layer in Computer Networks

- Error detection and correction in link layer is the process of detecting and correcting data frames that have been corrupted or lost during transmission .
- The link layer uses various error detection and correction techniques for this purpose. The basic approach is the use of redundancy, where additional bits are added to facilitate the detection and correction of errors .
- There are three main techniques for detecting errors in frames: Parity Check, Checksum and Cyclic Redundancy Check (CRC) .
  - Parity Check: The parity check is done by adding an extra bit, called parity bit to the data to make a number of 1s either even in case of even parity or odd in case of odd parity. For example, if the data is 1011 and even parity is used, the parity bit is 0 and the transmitted data is 10110. If the data is 1100 and odd parity is used, the parity bit is 1 and the transmitted data is 11001. The receiver checks the parity bit and detects an error if the number of 1s is not consistent with the parity scheme.
  - Checksum: The checksum is done by dividing the data into equal segments of n bits and adding them together using one's complement arithmetic. The result is called the checksum and is appended to the data as an extra segment. For example, if the data is 10110011 00101100 and n is 8, the checksum is calculated as 10110011 + 00101100 = 11011111. The transmitted data is 10110011 00101100 11011111. The receiver adds all the segments and checks if the result is all 1s. If not, there is an error in the data.
  - Cyclic Redundancy Check (CRC): The CRC is done by treating the data as a polynomial and dividing it by a fixed divisor polynomial. The remainder is called the CRC and is appended to the data as an extra segment. For example, if the data is 1011 and the divisor polynomial is x^3 + x + 1, the CRC is calculated as 1011 / 1011 = 1 with a remainder of 000. The transmitted data is 1011000. The receiver divides the data by the same divisor polynomial and checks if the remainder is zero. If not, there is an error in the data.
- Error correction in link layer is the process of recovering the original data from the corrupted or lost frames. There are two main techniques for correcting errors in frames: Automatic Repeat Request (ARQ) and Forward Error Correction (FEC) .
  - Automatic Repeat Request (ARQ): The ARQ is done by adding an acknowledgment mechanism to the transmission. The sender expects an acknowledgment from the receiver for each frame sent. If the acknowledgment is not received within a certain time or if the acknowledgment indicates an error, the sender retransmits the frame. There are three main types of ARQ: Stop-and-Wait ARQ, Go-Back-N ARQ and Selective Repeat ARQ.
    - Stop-and-Wait ARQ: The sender sends one frame at a time and waits for an acknowledgment before sending the next frame. The receiver sends an acknowledgment for each frame received. If the sender does not receive an acknowledgment within a certain time, it retransmits the frame. This method is simple but inefficient as the sender has to wait for each acknowledgment.
    - Go-Back-N ARQ: The sender sends multiple frames without waiting for acknowledgments, but keeps a copy of each frame in a window of size N. The receiver sends an acknowledgment for each frame received, but only accepts frames in sequence. The sender retransmits all the frames from that sequence number onwards. This method is more efficient than Stop-and-Wait ARQ, but it may cause unnecessary retransmissions if some frames are lost or corrupted.
