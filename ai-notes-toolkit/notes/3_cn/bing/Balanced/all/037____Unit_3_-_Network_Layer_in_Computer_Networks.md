## Unit 3 - Network Layer in Computer Networks

- The network layer is the third layer in the OSI model of computer networks. It is also called the Internet layer in the TCP/IP model.
- The main function of the network layer is to transfer network packets from the source to the destination across different networks or subnets.
- The network layer provides the following services to the transport layer and the upper layers:
  - Host and network addressing: The network layer assigns logical addresses (such as IP addresses) to the hosts and networks, and uses them to identify and locate the source and destination of the packets.
  - Routing: The network layer determines the best path or route for the packets to reach the destination, based on various factors such as distance, cost, congestion, etc. The network layer uses routers to forward the packets across different networks or subnets.
  - Fragmentation and reassembly: The network layer may divide a large packet into smaller fragments to fit the maximum transmission unit (MTU) of the underlying network. The network layer also reassembles the fragments at the destination and delivers the original packet to the transport layer.
  - Error control and congestion control: The network layer may detect and correct errors in the packets, such as checksum errors, and retransmit the corrupted packets. The network layer may also control the flow of packets to avoid congestion or overload in the network.
  - Quality of service (QoS): The network layer may provide different levels of service to different types of packets, such as delay, bandwidth, reliability, etc. The network layer may use different techniques such as priority, reservation, or differentiation to achieve QoS.
- The network layer can be divided into two sublayers: the network layer protocol and the network layer interface.
  - The network layer protocol is the set of rules and formats that define how the packets are structured, addressed, routed, and delivered. Examples of network layer protocols are IP, ICMP, ARP, RARP, etc.
  - The network layer interface is the set of functions and procedures that allow the network layer to communicate with the data link layer and the transport layer. The network layer interface may use different types of sockets, such as TCP sockets, UDP sockets, or raw sockets, to send and receive packets.
- The network layer can be implemented in different ways, such as connectionless or connection-oriented, datagram or virtual circuit, stateless or stateful, etc. These design choices affect the performance, reliability, and complexity of the network layer.
  - Connectionless network layer: The network layer does not establish or maintain any connection or session between the source and destination. Each packet is treated independently and may take different routes or arrive out of order. The network layer does not guarantee the delivery, order, or integrity of the packets. The transport layer or the application layer is responsible for error control and reordering. Examples of connectionless network layer protocols are IP and ICMP.
  - Connection-oriented network layer: The network layer establishes and maintains a connection or session between the source and destination before sending any packets. The network layer reserves resources and assigns a unique identifier to the connection. The network layer guarantees the delivery, order, and integrity of the packets. The network layer is responsible for error control and reordering. Examples of connection-oriented network layer protocols are X.25 and ATM.
  - Datagram network layer: The network layer treats each packet as a self-contained unit of information, with its own source and destination addresses. The network layer does not keep any information about the packets or the connections. The network layer is simple, flexible, and scalable, but may suffer from congestion, delay, or loss. Examples of datagram network layer protocols are IP and ICMP.
  - Virtual circuit network layer: The network layer establishes a logical connection or circuit between the source and destination, and assigns a label or number to each packet. The network layer keeps information about the packets and the connections in a table or database. The network layer is more reliable, efficient, and secure, but may be complex, rigid, and costly. Examples of virtual circuit network layer protocols are X.25 and ATM.
  - Stateless network layer: The network layer does not store any information about the packets or the connections. The network layer does not keep track of the state or status of the packets or the connections. The network layer is simple, fast, and scalable, but may not be able to handle errors, congestion, or QoS. Examples of stateless network layer protocols are IP and ICMP.
