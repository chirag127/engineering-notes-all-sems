#### ARP
- ARP stands for **Address Resolution Protocol**   .
- It is a communication protocol used for discovering the **link layer address**, such as a **MAC address**, associated with a given **internet layer address**, typically an **IPv4 address**   .
- It is a critical function in the **Internet protocol suite**   .
- It was defined in 1982 by **RFC 826**, which is **Internet Standard STD 37**.
- It works by sending **broadcast packets** to all hosts on the same network and asking for the MAC address of the host with a specific IP address.
- The host with the matching IP address replies with its MAC address, and the sender stores this information in a **cache table** for future use.
- ARP can be divided into two types: **static ARP** and **dynamic ARP**.
  - Static ARP: The sender manually enters the IP-MAC mapping in the cache table and does not need to send ARP requests.
  - Dynamic ARP: The sender dynamically learns the IP-MAC mapping by sending ARP requests and receiving ARP replies.
- ARP can also be classified into four types based on the network topology: **ARP**, **Proxy ARP**, **Reverse ARP (RARP)**, and **Inverse ARP (InARP)**.
  - ARP: The sender and the receiver are on the same network and use ARP to find each other's MAC address.
  - Proxy ARP: The sender and the receiver are on different networks and use a router as a proxy to find each other's MAC address.
  - RARP: The sender has a MAC address but no IP address and uses RARP to find its IP address from a RARP server.
  - InARP: The sender has an IP address but no MAC address and uses InARP to find its MAC address from a router.
- ARP has some advantages and disadvantages:
  - Advantages:
    - It is simple and easy to implement.
    - It is flexible and adaptable to different network architectures.
    - It reduces the network overhead by caching the IP-MAC mappings.
  - Disadvantages:
    - It is vulnerable to **ARP spoofing** attacks, where an attacker sends fake ARP packets to trick the sender into sending data to the wrong destination.
    - It is inefficient and wasteful when the network size is large, as it floods the network with broadcast packets.
    - It does not support IPv6, which uses a different protocol called **Neighbor Discovery Protocol (NDP)**.
- A possible mnemonic to remember the four types of ARP is **PAIR**:
  - P: Proxy ARP
  - A: ARP
  - I: InARP
  - R: RARP
- A possible learning trick to understand the difference between static and dynamic ARP is to compare them to a phone book:
  - Static ARP: The sender has a phone book with the names and phone numbers of all the hosts on the network and does not need to call anyone to ask for their number.
  - Dynamic ARP: The sender does not have a phone book and has to call a directory service to ask for the phone number of a specific host.
- A possible ASCII diagram to illustrate the ARP process is:

```
Sender (IP1, MAC1)                    Receiver (IP2, MAC2)
    |                                      |
    | ARP request: Who has IP2?           |
    | MAC1 -> FF:FF:FF:FF:FF:FF (broadcast)|
    |------------------------------------->|
    |                                      | ARP reply: I have IP2.
    |                                      | MAC2 -> MAC1 (unicast)
    |<-------------------------------------|
    |                                      |
```
