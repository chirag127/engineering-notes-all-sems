#### IP

- IP stands for Internet Protocol, which is a set of rules that govern how data is transmitted and received over the internet.
- An IP address is a numerical label that identifies a device on a network that uses the IP protocol. For example, 192.0.2.1 is an IP address.
- There are two versions of IP: IPv4 and IPv6. IPv4 uses 32-bit addresses, which can support up to 4.3 billion devices. IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 devices.
- IP addresses can be classified into two types: public and private. Public IP addresses are assigned by internet service providers (ISPs) and are visible to the internet. Private IP addresses are assigned by network administrators and are only visible within a local network.
- IP addresses can also be classified into two modes: static and dynamic. Static IP addresses are fixed and do not change. Dynamic IP addresses are assigned by a server and can change over time.
- IP addresses are used for network interface identification and location addressing. Network interface identification means that each device on a network can be uniquely identified by its IP address. Location addressing means that each IP address can be mapped to a physical location, such as a city, region, or country.
- IP addresses are also used for routing, which is the process of finding the best path for data packets to travel from a source to a destination. Routers are devices that use IP addresses to forward packets to the next hop on the path.
- IP addresses are written in dotted decimal notation for IPv4 and hexadecimal notation for IPv6. For example, 192.0.2.1 is an IPv4 address and 2001:db8::1 is an IPv6 address.
- A mnemonic to remember the difference between IPv4 and IPv6 is: IPv4 has four numbers, IPv6 has six letters.
- A learning trick to find your IP address on a Windows device is: On the taskbar, select Wi-Fi network > the Wi-Fi network you're connected to > Properties. Under Properties, look for your IP address listed next to IPv4 address or IPv6 address.
