#### Network devices in Computer Networks

Network devices are physical devices that enable communication and interaction between hardware on a computer network. Each networking device operates in a distinct computer network segment and performs distinct functions. A network may require hundreds or thousands of different network devices to maintain and build out various LAN and WAN.

Some of the common types of network devices are:

- **Repeater**: A repeater is a device that operates at the physical layer and regenerates the signal over the same network. It can extend the transmission distance of a network by amplifying the weak signals. However, it cannot filter the traffic or prevent collisions.
- **Hub**: A hub is a device that operates at the physical layer and connects multiple wires coming from different branches. It acts as a multiport repeater and broadcasts the incoming data to all the ports. It is simple and cheap, but it creates a lot of noise and congestion in the network.
- **Bridge**: A bridge is a device that operates at the data link layer and connects two or more network segments. It can filter the traffic based on the MAC addresses and forward the data to the appropriate segment. It can also reduce collisions and increase the network performance.
- **Switch**: A switch is a device that operates at the data link layer and connects multiple devices in a network. It can store the MAC addresses of the connected devices in a table and forward the data to the specific port. It can also create separate collision domains and improve the network efficiency .
- **Router**: A router is a device that operates at the network layer and routes the data packets based on their IP addresses. It can connect different networks with different protocols and architectures. It can also perform network address translation (NAT), firewall, and encryption functions .
- **Gateway**: A gateway is a device that operates at the application layer and converts the data from one format to another. It can connect different networks with different protocols and applications. It can also perform protocol conversion, data encryption, and authentication functions.
- **Brouter**: A brouter is a device that combines the functions of a bridge and a router. It can filter the traffic at the data link layer and route the traffic at the network layer. It can also create separate broadcast domains and reduce the network congestion.
- **NIC**: A network interface card (NIC) is a device that operates at the physical and data link layers and connects a computer to a network. It can convert the digital signals from the computer to the electrical signals for the network and vice versa. It can also provide the MAC address for the computer and perform error detection and correction functions.

Some of the mnemonics and learning tricks for the network devices are:

- To remember the order of the network devices from the lowest to the highest layer, use the phrase **RHBS RGBN** (Repeater, Hub, Bridge, Switch, Router, Gateway, Brouter, NIC).
- To remember the functions of the network devices, use the acronym **RAFFLE** (Regenerate, Amplify, Filter, Forward, Link, Encrypt).
- To remember the difference between a hub and a switch, use the word **BUSH** (Broadcast, Unicast, Switch, Hub). A hub broadcasts the data to all the ports, while a switch unicasts the data to the specific port.
