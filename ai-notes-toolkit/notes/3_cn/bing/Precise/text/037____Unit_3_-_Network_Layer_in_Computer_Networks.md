## Unit 3 - Network Layer in Computer Networks

The network layer is responsible for routing data packets from the source to the destination. This layer is responsible for logical addressing and routing. Some of the key functions of the network layer include:

1. **Routing:** The network layer is responsible for finding the best path for data transmission from the source to the destination. This is done using routing algorithms.

2. **Logical Addressing:** The network layer assigns logical addresses to devices on the network. These addresses are used to identify devices on the network and to route data packets.

3. **Fragmentation and Reassembly:** The network layer is responsible for breaking down large data packets into smaller packets that can be transmitted over the network. These packets are then reassembled at the destination.

4. **Error Handling and Diagnostics:** The network layer is responsible for detecting and correcting errors that may occur during data transmission. It also provides diagnostic tools to help troubleshoot network issues.

5. **Congestion Control:** The network layer is responsible for managing network congestion. It does this by controlling the flow of data packets on the network to prevent congestion.

The network layer plays a crucial role in ensuring reliable and efficient data transmission on a computer network. It provides the necessary tools and functions to route data packets, manage network congestion, and handle errors.
