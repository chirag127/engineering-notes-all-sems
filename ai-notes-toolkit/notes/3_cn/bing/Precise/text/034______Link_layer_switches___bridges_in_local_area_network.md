#### Link layer switches & bridges in local area network

- Link layer switches and bridges are networking devices that operate at the link layer (layer 2) of the OSI model.
- They are used to connect multiple devices on a local area network (LAN) and to filter and forward data packets between them.
- Switches and bridges work by learning the MAC addresses of the devices connected to them and forwarding data packets to the appropriate destination based on the destination MAC address.
- Switches are more advanced than bridges and can support more ports and higher data transfer rates.
- Both switches and bridges can improve network performance by reducing the number of collisions and increasing the available bandwidth for each device.
- Switches and bridges can also be used to create multiple collision domains, which can further improve network performance by reducing the number of devices competing for access to the network medium.
- In summary, link layer switches and bridges are essential components of a local area network, providing connectivity, filtering, and forwarding of data packets to improve network performance.
