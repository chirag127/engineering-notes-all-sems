### Multiplexing in transport layer

- Multiplexing is the process of combining multiple data streams into a single stream for transmission over a shared medium.
- In the transport layer, multiplexing is used to allow multiple applications to share a single network connection.
- This is achieved by assigning a unique identifier, called a port number, to each application.
- When data is sent from an application, the transport layer adds the port number to the data packet.
- When the data packet reaches its destination, the transport layer uses the port number to determine which application the data is intended for and delivers the data to that application.
- This allows multiple applications to send and receive data simultaneously over a single network connection.
- Multiplexing in the transport layer is essential for efficient use of network resources and for enabling communication between multiple applications on different devices.
