## Unit 4 - Transport Layer in Computer Networks

The transport layer is the fourth layer in the OSI model and is responsible for end-to-end communication between devices in a computer network. Some of the key functions of the transport layer include:

1. **Segmentation and reassembly**: The transport layer divides the data into smaller segments that can be transmitted over the network. At the receiving end, these segments are reassembled into the original data.

2. **Connection-oriented and connectionless communication**: The transport layer supports both connection-oriented and connectionless communication. In connection-oriented communication, a connection is established between the sender and receiver before data is transmitted. In connectionless communication, data is transmitted without establishing a connection.

3. **Flow control**: The transport layer is responsible for controlling the flow of data between the sender and receiver. This is done to prevent the receiver from being overwhelmed by the incoming data.

4. **Error control**: The transport layer is responsible for detecting and correcting errors that may occur during data transmission.

5. **Multiplexing**: The transport layer is responsible for multiplexing multiple communication streams between the sender and receiver.

Some of the common protocols used at the transport layer include TCP (Transmission Control Protocol) and UDP (User Datagram Protocol). TCP is a connection-oriented protocol that provides reliable data transmission, while UDP is a connectionless protocol that provides faster but less reliable data transmission.
