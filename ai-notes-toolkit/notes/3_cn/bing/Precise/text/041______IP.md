#### IP
- IP stands for Internet Protocol.
- It is a set of rules that govern how data is transmitted over the internet.
- IP is responsible for routing data packets from the source to the destination.
- Each device connected to the internet has a unique IP address.
- There are two versions of IP in use today: IPv4 and IPv6.
- IPv4 addresses are 32-bit numbers, while IPv6 addresses are 128-bit numbers.
- The IP protocol is used in conjunction with the Transmission Control Protocol (TCP) to form the TCP/IP protocol suite.
- The IP protocol is responsible for the logical addressing and routing of data packets, while the TCP protocol is responsible for ensuring reliable data transmission.
- IP is a connectionless protocol, meaning that it does not establish a dedicated end-to-end connection before transmitting data.
- IP is an integral part of the internet and is used by virtually all internet-connected devices.
