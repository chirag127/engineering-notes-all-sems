#### Network structure with reference to Computer Networks

- A computer network is a group of interconnected devices that can communicate with each other and share resources.
- The structure of a computer network refers to the way in which the devices are connected and the protocols used for communication.
- There are several common network structures, including:
  - **Bus**: In a bus network, all devices are connected to a central cable, called the bus. Data is transmitted along the bus and all devices can receive it, but only the intended recipient processes it.
  - **Star**: In a star network, all devices are connected to a central hub or switch. Data is transmitted from the sender to the hub, which then forwards it to the intended recipient.
  - **Ring**: In a ring network, all devices are connected in a closed loop. Data is transmitted from one device to the next until it reaches its destination.
  - **Mesh**: In a mesh network, each device is connected to multiple other devices. Data can be transmitted along multiple paths to reach its destination.
- Each network structure has its own advantages and disadvantages. For example, a bus network is simple and inexpensive to set up, but can become slow and congested as the number of devices increases. A star network is more scalable, but requires more cabling and a central hub or switch.
- The choice of network structure depends on factors such as the size of the network, the amount of data being transmitted, and the need for reliability and security.
- A mnemonic to remember the different network structures is **BSRM** (Bus, Star, Ring, Mesh).
