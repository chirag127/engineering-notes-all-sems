#### TCP Transport layer protocol

- TCP stands for Transmission Control Protocol.
- It is one of the main protocols in the Internet Protocol Suite.
- It is a connection-oriented protocol, which means that a connection is established and maintained until the application programs at each end have finished exchanging messages.
- TCP provides reliable, ordered, and error-checked delivery of data between applications running on different devices.
- TCP achieves this reliability by assigning a sequence number to each byte transmitted and requiring a positive acknowledgment (ACK) from the receiving device. If the ACK is not received within a certain time, the data is retransmitted.
- TCP also includes a flow control mechanism, which ensures that the sender does not overwhelm the receiver with data.
- TCP is used by many common applications such as the World Wide Web, email, and file transfer.

Mnemonic: **T**ransmission **C**ontrol **P**rotocol - **T**ransfers **C**ontent **P**roperly
