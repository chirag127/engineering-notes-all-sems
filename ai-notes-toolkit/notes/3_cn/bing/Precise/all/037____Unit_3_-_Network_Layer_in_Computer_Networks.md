## Unit 3 - Network Layer in Computer Networks

The network layer is responsible for routing data packets from the source to the destination. It is the third layer of the OSI model and is also known as the Internet layer in the TCP/IP model.

1. **Routing:** The network layer is responsible for finding the best path for data packets to travel from the source to the destination. This is done through the use of routing algorithms and protocols such as OSPF, RIP, and BGP.

2. **Logical Addressing:** The network layer uses logical addresses, such as IP addresses, to identify devices on the network. These addresses are used by the routing algorithms to determine the best path for data packets.

3. **Fragmentation and Reassembly:** The network layer is responsible for breaking down large data packets into smaller packets, known as fragments, for transmission. It is also responsible for reassembling the fragments at the destination.

4. **Error Control and Flow Control:** The network layer is responsible for detecting and correcting errors that may occur during transmission. It also manages the flow of data to prevent congestion and ensure reliable delivery.

A mnemonic to remember the functions of the network layer is **"Real Friends Fight Everytime"**, where each letter stands for Routing, Logical Addressing (Friends), Fragmentation and Reassembly (Fight), and Error Control and Flow Control (Everytime).

An example of the network layer in action is when you send an email from your computer to a friend's computer. The network layer on your computer determines the best path for the data packets to travel, assigns a logical address to the destination, breaks down the data into smaller packets, and manages the flow of data to ensure reliable delivery. At the destination, the network layer reassembles the packets and delivers the email to your friend's inbox.

In summary, the network layer is responsible for routing, logical addressing, fragmentation and reassembly, and error and flow control. It plays a crucial role in ensuring reliable and efficient communication on a computer network.
