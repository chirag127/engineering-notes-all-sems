### Terminology used with Graph

- A graph is a collection of vertices (or nodes) and edges (or arcs) that connect them.
- A vertex is a point or an entity in the graph that can have a name or a value.
- An edge is a line or a link that connects two vertices in the graph. It can have a direction or a weight associated with it.
- A directed graph (or digraph) is a graph where all the edges have a direction, indicating the source and the destination of the edge.
- An undirected graph is a graph where the edges do not have a direction, meaning that they can be traversed in either direction.
- A weighted graph is a graph where the edges have a weight or a cost associated with them, indicating the distance or the difficulty of traversing the edge.
- A subgraph is a graph that is a part of another graph, containing some of the vertices and edges of the original graph.
- A path is a sequence of edges that connects two vertices in the graph. A path can be simple or cyclic, depending on whether it repeats any vertex or edge or not.
- A cycle is a path that starts and ends at the same vertex. A cycle can be simple or complex, depending on whether it repeats any other vertex or edge or not.
- A connected graph is a graph where there is a path between any two vertices in the graph. A disconnected graph is a graph where there are some vertices that are not reachable from other vertices.
- A component is a subgraph of a graph that is connected. A graph can have one or more components, depending on how many disconnected parts it has.
- A tree is a graph that is connected and has no cycles. A tree has exactly one path between any two vertices in the graph.
- A forest is a graph that is disconnected and has no cycles. A forest is a collection of trees.
- A spanning tree is a subgraph of a graph that is a tree and contains all the vertices of the original graph. A graph can have one or more spanning trees, depending on how many edges are removed from the original graph.
- A minimum spanning tree is a spanning tree of a weighted graph that has the minimum total weight among all the possible spanning trees of the graph. A graph can have one or more minimum spanning trees, depending on how many edges have the same minimum weight.
