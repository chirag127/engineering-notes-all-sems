### Built in Data Types in C

- Data types are the classifications of data items that tell the compiler how the programmer intends to use the data.
- Built in data types are the data types that are predefined and supported by the C language.
- The built in data types in C are:

  - int: used to store integer values, such as 1, 0, -5, etc. The size of int is usually 4 bytes, but it may vary depending on the compiler and the platform.
  - float: used to store floating-point values, such as 3.14, 0.5, -2.3, etc. The size of float is usually 4 bytes, but it may vary depending on the compiler and the platform.
  - double: used to store double-precision floating-point values, such as 3.14159, 0.123456, -2.34567, etc. The size of double is usually 8 bytes, but it may vary depending on the compiler and the platform.
  - char: used to store single characters, such as 'a', 'b', 'c', etc. The size of char is always 1 byte, and it can store any ASCII value from 0 to 255.
  - void: used to indicate the absence of any data type, such as in the return type of a function that does not return any value, or in the argument list of a function that does not take any parameters.

- Each data type has a range of values that it can store, and a format specifier that is used to print or scan the data type in input/output operations.
- The range and the format specifier of each data type are shown in the table below:

| Data type | Range | Format specifier |
| --------- | ----- | ---------------- |
| int       | -2,147,483,648 to 2,147,483,647 | %d or %i |
| float     | 1.2E-38 to 3.4E+38 | %f or %e |
| double    | 2.3E-308 to 1.7E+308 | %lf or %le |
| char      | 0 to 255 | %c |
| void      | N/A | N/A |

- The C language also allows the programmer to create derived data types from the built in data types, such as arrays, pointers, structures, unions, and enumerations.
- The derived data types are used to store more complex data structures, such as lists, trees, graphs, etc.
- The derived data types will be discussed in more detail in the following topics.
