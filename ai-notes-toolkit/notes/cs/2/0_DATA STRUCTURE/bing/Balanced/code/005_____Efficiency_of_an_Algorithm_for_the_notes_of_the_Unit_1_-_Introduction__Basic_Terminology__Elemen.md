### Efficiency of an Algorithm

- An algorithm is a finite sequence of well-defined steps that solves a problem or performs a task.
- The efficiency of an algorithm measures how well it uses the available resources (such as time and space) to achieve its goal.
- The time complexity of an algorithm is the amount of time it takes to execute as a function of the input size.
- The space complexity of an algorithm is the amount of memory it uses as a function of the input size.
- The asymptotic notations are mathematical tools that help us compare the performance of different algorithms by ignoring the constant factors and lower-order terms.
- The Big Oh notation (O) represents the upper bound of the time or space complexity of an algorithm. It means that the algorithm will not take more than O(f(n)) time or space for any input of size n, where f(n) is some function of n.
- The Big Theta notation (Θ) represents the tight bound of the time or space complexity of an algorithm. It means that the algorithm will take exactly Θ(f(n)) time or space for any input of size n, where f(n) is some function of n.
- The Big Omega notation (Ω) represents the lower bound of the time or space complexity of an algorithm. It means that the algorithm will take at least Ω(f(n)) time or space for any input of size n, where f(n) is some function of n.
- The time-space trade-off is a concept that states that sometimes we can improve the time complexity of an algorithm by using more space, or vice versa.
- An abstract data type (ADT) is a logical description of a set of data and the operations that can be performed on it, without specifying how the data is stored or how the operations are implemented.
