### Algorithm for the notes of the Unit 1 - Introduction: Basic Terminology, Elementary Data Organization, Built in Data Types in C. Algorithm, Efficiency of an Algorithm, Time and Space Complexity, Asymptotic notations: Big Oh, Big Theta and Big Omega, Time-Space trade-off. Abstract Data Types (ADT) in the subject of DATA STRUCTURE

1. **Basic Terminology**: Data, Information, Data Structure, Data Type, Abstract Data Type (ADT).
2. **Elementary Data Organization**: Bits, Bytes, Words, Records, Files.
3. **Built-in Data Types in C**: int, char, float, double, void.
4. **Algorithm**: A step-by-step procedure for solving a problem or achieving a specific task.
5. **Efficiency of an Algorithm**: The efficiency of an algorithm is measured by its time and space complexity.
6. **Time and Space Complexity**: Time complexity is the amount of time an algorithm takes to complete its task, while space complexity is the amount of memory an algorithm uses to complete its task.
7. **Asymptotic Notations**: Big Oh, Big Theta, and Big Omega are used to describe the growth rate of an algorithm's time and space complexity.
8. **Time-Space Trade-off**: The trade-off between the time and space complexity of an algorithm.
9. **Abstract Data Types (ADT)**: An ADT is a data type that is defined by its behavior, rather than its implementation. Examples include stacks, queues, and lists.
