### Time-Space trade-off

Time-Space trade-off refers to the balance between the time it takes to execute an algorithm and the amount of memory it requires. In many cases, an algorithm that is faster in terms of execution time may require more memory, while an algorithm that uses less memory may take longer to execute. This trade-off is often considered when designing algorithms, as it is important to find a balance between the two.

1. Time complexity refers to the amount of time it takes for an algorithm to complete its task. It is usually measured in terms of the number of basic operations performed by the algorithm.
2. Space complexity refers to the amount of memory required by an algorithm to complete its task. It is usually measured in terms of the number of memory cells used by the algorithm.
