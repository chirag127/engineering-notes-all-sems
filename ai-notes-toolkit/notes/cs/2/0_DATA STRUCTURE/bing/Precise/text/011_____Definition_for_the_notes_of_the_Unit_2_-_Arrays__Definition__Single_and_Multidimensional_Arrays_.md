### Unit 2 - Arrays and Linked Lists

#### Arrays
- An array is a collection of elements of the same data type, stored in contiguous memory locations.
- Arrays can be single or multidimensional.
- Single dimensional arrays are also known as one-dimensional arrays or linear arrays.
- Multidimensional arrays have more than one dimension, such as two-dimensional arrays or three-dimensional arrays.
- The representation of arrays can be in row-major order or column-major order.
- In row-major order, the elements of an array are stored row by row.
- In column-major order, the elements of an array are stored column by column.
- The index formulae for 1-D, 2-D, 3-D, and n-D arrays can be derived based on the representation of the array.
- Arrays have various applications, such as in the representation of sparse matrices.
- Sparse matrices are matrices that have a large number of zero elements.
- There are various representations of sparse matrices, such as the triplet representation or the compressed sparse row representation.

#### Linked Lists
- A linked list is a linear data structure where elements are stored in nodes.
- The nodes are linked together using pointers.
- Linked lists can be implemented using arrays or pointers.
- There are various types of linked lists, such as singly linked lists, doubly linked lists, and circularly linked lists.
- In a singly linked list, each node has a pointer to the next node.
- In a doubly linked list, each node has a pointer to the next node and a pointer to the previous node.
- In a circularly linked list, the last node points to the first node.
- Operations on a linked list include insertion, deletion, and traversal.
- Linked lists can be used to represent polynomials.
- Polynomial addition, subtraction, and multiplication can be performed using linked lists.
- Polynomials can be represented using single variable or two variables.
