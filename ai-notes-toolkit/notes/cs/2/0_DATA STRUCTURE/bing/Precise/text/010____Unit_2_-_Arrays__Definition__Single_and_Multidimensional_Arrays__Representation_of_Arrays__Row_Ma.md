## Unit 2 - Arrays and Linked Lists

### Arrays

- An array is a collection of elements of the same data type, stored in contiguous memory locations.
- Arrays can be single or multidimensional.
- Single dimensional arrays are represented as a list of elements, while multidimensional arrays are represented as a table of elements.
- The representation of arrays can be done in two ways: row-major order and column-major order.
- In row-major order, the elements are stored row by row, while in column-major order, the elements are stored column by column.
- The index formulae for 1-D, 2-D, 3-D and n-D arrays can be derived based on the representation of the array.
- Arrays have various applications, such as in the representation of matrices, including sparse matrices.
- Sparse matrices are matrices that have a large number of zero elements. They can be represented using various methods, such as using an array of non-zero elements.

### Linked Lists

- A linked list is a linear data structure where elements are stored in nodes, and each node points to the next node in the list.
- Linked lists can be implemented using arrays or pointers.
- There are different types of linked lists, such as singly linked lists, doubly linked lists, and circularly linked lists.
- Operations on a linked list include insertion, deletion, and traversal.
- Linked lists can also be used to represent polynomials, where each node represents a term in the polynomial.
- Polynomial addition, subtraction, and multiplication can be performed using linked lists, for both single variable and two variable polynomials.
