### Time-Space trade-off

Time-Space trade-off is a concept in computer science that refers to the balance between the time it takes to execute an algorithm and the amount of memory it requires. In general, an algorithm that is faster in terms of time complexity may require more memory, while an algorithm that is more efficient in terms of space complexity may take longer to execute.

- Time complexity refers to the amount of time an algorithm takes to complete as a function of the size of the input.
- Space complexity refers to the amount of memory an algorithm requires as a function of the size of the input.
- The time-space trade-off is an important consideration when choosing an algorithm for a particular task, as it may be necessary to balance the need for speed with the need for memory efficiency.
- Asymptotic notations such as Big Oh, Big Theta, and Big Omega are used to describe the time and space complexity of algorithms.
- Abstract Data Types (ADT) are a way to define the behavior of a data structure, independent of its implementation.
