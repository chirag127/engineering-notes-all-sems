### Built-in Data Types in C

C language supports four basic types of built-in data types:

1. **Integers**: Integers are used to store whole numbers. The keyword used to declare an integer variable is `int`. The size of an integer variable is usually 2 or 4 bytes, depending on the compiler and the computer architecture.

2. **Floating-point numbers**: Floating-point numbers are used to store real numbers, i.e., numbers with a fractional part. The keyword used to declare a floating-point variable is `float` or `double`. The size of a `float` variable is usually 4 bytes, while the size of a `double` variable is usually 8 bytes.

3. **Characters**: Characters are used to store individual characters, such as letters, digits, and punctuation marks. The keyword used to declare a character variable is `char`. The size of a `char` variable is always 1 byte.

4. **Void**: The `void` type is used to indicate that a function does not return any value or to declare generic pointers.

C language also supports derived data types, such as arrays, structures, unions, and pointers, which are constructed from the built-in data types.
