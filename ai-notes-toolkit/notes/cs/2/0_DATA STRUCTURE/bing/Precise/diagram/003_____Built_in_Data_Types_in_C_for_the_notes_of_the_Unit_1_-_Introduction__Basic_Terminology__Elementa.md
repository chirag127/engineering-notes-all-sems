### Built in Data Types in C

C language supports several built-in data types, including:

1. **Integer types**: used to store whole numbers. The size of integer types varies depending on the system, but it is usually 2 or 4 bytes. Integer types can be signed or unsigned, and can be of different sizes, such as short, int, and long.

2. **Floating-point types**: used to store real numbers, such as 3.14 or -2.71. Floating-point types can represent a wider range of values than integer types, and can store fractional values. There are two floating-point types in C: float and double.

3. **Character types**: used to store characters, such as letters, digits, and punctuation marks. Character types are usually 1 byte in size, and can be signed or unsigned. The most common character type is char.

4. **Void type**: used to indicate that a function does not return a value, or that a pointer does not point to any specific data type.

5. **Derived data types**: C also supports derived data types, such as arrays, pointers, structures, and unions, which are built from the built-in data types.

These built-in data types provide the foundation for building more complex data structures and algorithms in C. It is important to understand the characteristics and limitations of each data type in order to use them effectively in your programs.
