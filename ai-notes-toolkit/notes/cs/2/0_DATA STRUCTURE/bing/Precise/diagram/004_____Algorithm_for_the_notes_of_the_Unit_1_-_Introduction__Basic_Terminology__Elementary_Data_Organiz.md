### Algorithm for the notes of the Unit 1 - Introduction: Basic Terminology, Elementary Data Organization, Built in Data Types in C. Algorithm, Efficiency of an Algorithm, Time and Space Complexity, Asymptotic notations: Big Oh, Big Theta and Big Omega, Time-Space trade-off. Abstract Data Types (ADT) in the subject of DATA STRUCTURE

1. **Basic Terminology**: Data structure is a way of organizing data in a computer so that it can be used efficiently. Different types of data structures are suited to different kinds of applications, and some are highly specialized to specific tasks.
2. **Elementary Data Organization**: Data can be organized in different ways, such as arrays, linked lists, stacks, queues, trees, and graphs.
3. **Built-in Data Types in C**: C has several built-in data types, including int, char, float, double, and void.
4. **Algorithm**: An algorithm is a step-by-step procedure for solving a problem or achieving a specific task.
5. **Efficiency of an Algorithm**: The efficiency of an algorithm is measured by its time and space complexity.
6. **Time and Space Complexity**: Time complexity is the amount of time an algorithm takes to complete its task, while space complexity is the amount of memory it requires.
7. **Asymptotic Notations**: Asymptotic notations, such as Big Oh, Big Theta, and Big Omega, are used to describe the growth rate of an algorithm's time and space complexity.
8. **Time-Space Trade-off**: Time-space trade-off refers to the balance between the time and space complexity of an algorithm. Sometimes, an algorithm can be made faster by using more memory, or vice versa.
9. **Abstract Data Types (ADT)**: An ADT is a high-level description of a collection of data and the operations that can be performed on that data. It defines the behavior of the data type, but not its implementation.
