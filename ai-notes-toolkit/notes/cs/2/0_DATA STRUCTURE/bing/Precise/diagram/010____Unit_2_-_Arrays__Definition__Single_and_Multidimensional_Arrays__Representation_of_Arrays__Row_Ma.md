## Unit 2 - Arrays and Linked Lists

### Arrays

- An array is a collection of elements of the same data type, stored in contiguous memory locations.
- Arrays can be single or multidimensional.
- Single dimensional arrays are represented as a list of elements, while multidimensional arrays are represented as a table of elements.
- The representation of arrays can be done in two ways: row-major order and column-major order.
- In row-major order, the elements of an array are stored row by row, while in column-major order, the elements are stored column by column.
- The index formulae for 1-D, 2-D, 3-D, and n-D arrays can be derived based on the representation of the array.
- Arrays have various applications, such as storing and manipulating data in a structured manner.
- Sparse matrices, which are matrices with a large number of zero elements, can be represented using arrays in an efficient manner.

### Linked Lists

- A linked list is a linear data structure, where the elements are not stored in contiguous memory locations.
- Linked lists can be implemented using arrays or pointers.
- Singly linked lists have nodes that contain data and a pointer to the next node in the list.
- Doubly linked lists have nodes that contain data, a pointer to the next node, and a pointer to the previous node in the list.
- Circularly linked lists have the last node pointing to the first node in the list.
- Operations on a linked list include insertion, deletion, and traversal.
- Linked lists can be used to represent polynomials, where each node represents a term in the polynomial.
- Addition, subtraction, and multiplication of single variable and two variable polynomials can be performed using linked lists.
