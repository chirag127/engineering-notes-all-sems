### Efficiency of an Algorithm

- The efficiency of an algorithm is a measure of the amount of resources (time and space) required by the algorithm to solve a problem.
- The time complexity of an algorithm is the amount of time it takes for the algorithm to complete its execution, while the space complexity is the amount of memory it requires.
- Asymptotic notations such as Big Oh, Big Theta, and Big Omega are used to describe the time and space complexity of an algorithm.
- Big Oh notation provides an upper bound on the growth rate of the algorithm's time or space complexity.
- Big Theta notation provides a tight bound on the growth rate of the algorithm's time or space complexity.
- Big Omega notation provides a lower bound on the growth rate of the algorithm's time or space complexity.
- Time-space trade-off refers to the balance between the time and space complexity of an algorithm. In some cases, an algorithm can be made faster by using more memory, or it can be made to use less memory by taking more time to execute.
- An Abstract Data Type (ADT) is a high-level description of a collection of data and the operations that can be performed on that data. It defines the behavior of the data type, but not its implementation.
