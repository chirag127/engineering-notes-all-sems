# Terminology used with Graph

Graphs are mathematical structures used to model pairwise relations between objects. A graph is made up of vertices (also called nodes or points) connected by edges (also called links or lines).

- **Vertex**: A vertex, also called a node or a point, is a fundamental unit of which graphs are formed. It represents an entity such as an object or a person.

- **Edge**: An edge, also called a link or a line, is a connection between two vertices. It represents a relationship or interaction between the two vertices it connects.

- **Degree**: The degree of a vertex is the number of edges connected to it.

- **Path**: A path is a sequence of edges that connect a sequence of vertices.

- **Cycle**: A cycle is a path that starts and ends at the same vertex.

- **Connected Graph**: A graph is connected if there is a path between every pair of vertices.

- **Disconnected Graph**: A graph is disconnected if it is not connected.

- **Subgraph**: A subgraph is a graph whose vertices and edges are subsets of another graph.

- **Tree**: A tree is a connected graph with no cycles.

- **Forest**: A forest is a disjoint union of trees.

- **Spanning Tree**: A spanning tree of a graph is a subgraph that is a tree and contains all the vertices of the graph.

- **Minimum Spanning Tree**: A minimum spanning tree of a graph is a spanning tree with the smallest possible total edge weight.

- **Adjacency Matrix**: An adjacency matrix is a square matrix used to represent a graph. The elements of the matrix indicate whether pairs of vertices are adjacent or not in the graph.

- **Adjacency List**: An adjacency list is a collection of unordered lists used to represent a graph. Each list describes the set of neighbors of a vertex in the graph.

- **Depth First Search (DFS)**: Depth First Search is an algorithm for traversing or searching tree or graph data structures. It starts at the root node and explores as far as possible along each branch before backtracking.

- **Breadth First Search (BFS)**: Breadth First Search is an algorithm for traversing or searching tree or graph data structures. It starts at the root node and explores all the neighboring nodes at the present depth level before moving on to the nodes at the next depth level.

- **Transitive Closure**: The transitive closure of a graph is a graph that contains an edge between two vertices if and only if there is a path between those two vertices in the original graph.

- **Shortest Path Algorithm**: A shortest path algorithm is an algorithm that finds the shortest path between two vertices in a graph.

- **Warshal Algorithm**: The Warshall algorithm, also known as Floyd–Warshall algorithm, is an algorithm for finding the shortest paths in a weighted graph with positive or negative edge weights.

- **Dijkstra Algorithm**: The Dijkstra algorithm is an algorithm for finding the shortest paths between nodes in a graph, which may represent, for example, road networks.
