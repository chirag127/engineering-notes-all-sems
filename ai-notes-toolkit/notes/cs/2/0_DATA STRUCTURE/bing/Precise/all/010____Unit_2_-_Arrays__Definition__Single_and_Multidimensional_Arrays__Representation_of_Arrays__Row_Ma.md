## Unit 2 - Arrays and Linked Lists

### Arrays

- An array is a collection of elements of the same data type, stored in contiguous memory locations.
- Arrays can be single or multidimensional. A single dimensional array is a list of elements, while a multidimensional array is an array of arrays.
- Arrays can be represented in row-major order or column-major order. In row-major order, the elements are stored row by row, while in column-major order, the elements are stored column by column.
- The index formulae for 1-D, 2-D, 3-D and n-D arrays can be derived based on the representation of the array.
- Arrays have many applications, including the representation of sparse matrices. Sparse matrices are matrices that have a large number of zero elements. They can be represented using arrays to save space.

### Linked Lists

- A linked list is a data structure that consists of a sequence of nodes, each containing data and a reference to the next node in the list.
- Linked lists can be implemented using arrays or pointers. In an array implementation, the nodes are stored in an array, while in a pointer implementation, the nodes are dynamically allocated in memory.
- Linked lists can be singly linked, doubly linked or circularly linked. In a singly linked list, each node has a reference to the next node. In a doubly linked list, each node has a reference to the next and previous nodes. In a circularly linked list, the last node has a reference to the first node.
- Operations on a linked list include insertion, deletion and traversal. These operations can be performed at different positions in the list, such as at the beginning, at the end or at a specific position.
- Linked lists can be used to represent polynomials. The polynomial can be represented as a linked list, where each node contains the coefficient and exponent of a term. Polynomial addition, subtraction and multiplication can be performed using linked lists.
