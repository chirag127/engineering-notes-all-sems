### Built-in Data Types in C

C language supports four basic types of built-in data types:

1. **Integer types**: Used to store integer values. It includes `char`, `int`, `short`, `long`, and `long long`.
2. **Floating-point types**: Used to store real numbers. It includes `float` and `double`.
3. **Void type**: Used for functions that do not return a value.
4. **Derived types**: These include arrays, pointers, structures, and unions.

Each data type has its own range of values that it can represent. For example, the `int` data type can represent integer values within a certain range, depending on the system and compiler used.

It is important to choose the appropriate data type for the data being stored to ensure efficient use of memory and to prevent errors or unexpected behavior.
