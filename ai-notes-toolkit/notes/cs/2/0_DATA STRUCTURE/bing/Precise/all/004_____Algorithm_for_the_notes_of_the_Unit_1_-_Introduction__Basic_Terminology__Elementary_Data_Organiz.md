## Algorithm
- An algorithm is a step-by-step procedure to solve a problem.
- It is a finite set of instructions that, if followed, accomplishes a particular task.
- An algorithm must be clear and unambiguous, with well-defined inputs and outputs.

## Efficiency of an Algorithm
- The efficiency of an algorithm is measured by its time and space complexity.
- Time complexity refers to the amount of time an algorithm takes to complete its task.
- Space complexity refers to the amount of memory an algorithm uses to complete its task.

## Time and Space Complexity
- Time complexity is usually expressed using big O notation, which describes the upper bound of the algorithm's growth rate.
- Space complexity is usually expressed using big O notation, which describes the upper bound of the algorithm's memory usage.

## Asymptotic Notations: Big Oh, Big Theta and Big Omega
- Big Oh notation provides an upper bound on the growth rate of an algorithm's time or space complexity.
- Big Theta notation provides a tight bound on the growth rate of an algorithm's time or space complexity.
- Big Omega notation provides a lower bound on the growth rate of an algorithm's time or space complexity.

## Time-Space Trade-Off
- Time-space trade-off refers to the balance between the time and space complexity of an algorithm.
- An algorithm may be optimized for time at the expense of space, or vice versa.

## Abstract Data Types (ADT)
- An abstract data type (ADT) is a high-level description of a collection of data and the operations that can be performed on that data.
- It defines the behavior of the data, but not its implementation.
- Common examples of ADTs include stacks, queues, and lists.

## Built-in Data Types in C
- C has several built-in data types, including int, char, float, and double.
- These data types have a fixed size and range, and are used to represent numbers, characters, and real numbers, respectively.
- C also has derived data types, such as arrays, structures, and pointers, which are built from the built-in data types.
