## Unit 2 - Arrays and Linked Lists

In this unit, we will learn about arrays and linked lists, which are two fundamental data structures used in computer science. We will cover the following topics:

### Arrays

- Arrays are a collection of elements of the same data type, stored in contiguous memory locations.
- Single dimensional arrays are also known as vectors, while multidimensional arrays are known as matrices.
- Arrays can be represented in row major order or column major order, depending on the programming language or application.
- Index formulae can be derived for 1-D, 2-D, 3-D, and n-D arrays.
- Applications of arrays include searching, sorting, and matrix operations.
- Sparse matrices can be represented using arrays.

### Linked Lists

- Linked lists are a data structure that consists of a sequence of nodes, where each node contains data and a pointer to the next node.
- Linked lists can be implemented using arrays or pointers.
- Singly linked lists have a pointer to the next node, while doubly linked lists have pointers to the next and previous nodes.
- Circularly linked lists have the last node pointing to the first node.
- Operations on a linked list include insertion, deletion, and traversal.
- Linked lists can be used to represent polynomials, where each node represents a term in the polynomial.
- Addition, subtraction, and multiplication of single variable and two variables polynomials can be performed using linked lists.

By mastering the concepts of arrays and linked lists, you will have a solid foundation for understanding more complex data structures and algorithms.
