### Built in Data Types in C

C programming language provides various built-in data types which are used to store different types of values. These data types differ in their size and the range of values they can hold. The built-in data types in C are:

1. **int:** The `int` data type is used to store integer values. It is a signed data type which means it can hold both positive and negative values. The size of `int` depends on the compiler and the platform. Typically, it is 4 bytes on most modern platforms.

2. **float:** The `float` data type is used to store floating-point values. It is used to store numbers with decimal points. The size of `float` is 4 bytes and it can store values up to 7 decimal places.

3. **double:** The `double` data type is used to store double-precision floating-point values. It is used to store numbers with very high precision. The size of `double` is 8 bytes and it can store values up to 15 decimal places.

4. **char:** The `char` data type is used to store single characters. It can hold any character from the ASCII table. The size of `char` is 1 byte.

5. **short:** The `short` data type is used to store small integers. It is a signed data type and its size is 2 bytes.

6. **long:** The `long` data type is used to store large integers. It is a signed data type and its size is 8 bytes.

7. **unsigned int:** The `unsigned int` data type is used to store only positive integers. It is an unsigned data type and its size is the same as that of `int`.

8. **unsigned char:** The `unsigned char` data type is used to store positive characters. It can hold any character from the ASCII table. The size of `unsigned char` is 1 byte.

9. **unsigned short:** The `unsigned short` data type is used to store small positive integers. It is an unsigned data type and its size is 2 bytes.

10. **unsigned long:** The `unsigned long` data type is used to store large positive integers. It is an unsigned data type and its size is 8 bytes.

These data types are used extensively in C programming language for storing different types of values. It is important to choose the appropriate data type for storing values as it can affect the performance and efficiency of the program.
