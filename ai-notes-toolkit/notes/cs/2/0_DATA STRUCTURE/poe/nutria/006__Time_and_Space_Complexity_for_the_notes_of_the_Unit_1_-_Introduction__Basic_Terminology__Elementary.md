

### Time and Space Complexity

* Algorithm efficiency is determined by its **time complexity**, which is the amount of time it takes for an algorithm to run, and its **space complexity**, which is the amount of memory it requires. 
* **Time complexity** is the measure of the amount of time it takes for an algorithm to run as a function of the input size. 
* **Space complexity** is the measure of the amount of memory it requires to run as a function of the input size.
* **Asymptotic notations** are used to measure the time and space complexity of an algorithm. The three main ones are **Big O**, **Big Theta**, and **Big Omega**. 
* **Big O** notation is used to measure the worst-case time complexity of an algorithm. 
* **Big Theta** notation is used to measure the average-case time complexity of an algorithm. 
* **Big Omega** notation is used to measure the best-case time complexity of an algorithm. 
* The **time-space trade-off** is an important concept in algorithm design. It is the idea that by increasing the amount of space used by an algorithm, the time complexity can be reduced. 
* **Abstract Data Types (ADT)** are used in the subject of Data Structures. An ADT is a data type that is defined in terms of the operations that can be performed on it.
