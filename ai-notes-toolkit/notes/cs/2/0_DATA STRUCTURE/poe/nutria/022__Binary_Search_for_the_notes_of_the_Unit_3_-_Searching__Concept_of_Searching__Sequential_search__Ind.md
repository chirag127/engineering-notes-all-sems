

### Binary Search

Binary Search is an efficient searching algorithm used to search for an element in a sorted array. It works by dividing the array into two halves and then comparing the element to be searched with the middle element of the array. If the element is equal to the middle element, the search is successful. Otherwise, the search continues in either the left or the right half of the array depending on the comparison.

#### Concept of Searching

Searching is a process of finding an element from a collection of elements. It is an important operation in data structures. The efficiency of searching depends on the data structure used to store the elements. Examples of data structures used for searching are arrays, linked lists, binary search trees, and hash tables.

#### Sequential search

Sequential search is a basic searching algorithm used to search for an element in an array. It works by comparing the element to be searched with each element in the array sequentially until the element is found.

#### Index Sequential Search

Index sequential search is an improvement of the sequential search algorithm. It uses an index table to store the elements in the array. The index table stores the elements in sorted order and contains the indices of the elements in the array. This helps in reducing the number of comparisons required for searching.

#### Concept of Hashing & Collision Resolution Techniques used in Hashing

Hashing is a technique used to store and retrieve elements from a collection. It works by mapping the elements to a unique key using a hash function. The hash function maps the elements to a unique key and the key is used to store and retrieve the elements. Collision resolution techniques are used to handle collisions, which occur when two elements map to the same key. Examples of collision resolution techniques are open addressing, chaining, and linear probing.

#### Sorting

Sorting is an important operation in data structures. It is used to arrange elements in a particular order. Examples of sorting algorithms are insertion sort, selection sort, bubble sort, quick sort, merge sort, heap sort, and radix sort. Each sorting algorithm has its own advantages and disadvantages.
