#### Searching

* **Concept of Searching**: Searching is a process of finding an element from a given set of elements. It is an important operation in data structure.

* **Sequential search**: It is a technique of searching an element in a list or an array. It involves searching an element by traversing the list sequentially.

* **Index Sequential Search**: It is an improvement over the sequential search. It involves indexing the elements of the list and then searching the element using the index.

* **Binary Search**: It is an efficient search technique that uses the divide and conquer approach. It involves dividing the list into two halves and then searching the element in the appropriate half.

#### Hashing

* **Concept of Hashing**: Hashing is a technique of mapping a data element to a unique identifier. It is used for storing and retrieving data from a data structure.

* **Collision resolution Techniques used in Hashing**: Collision resolution techniques are used to handle collisions in hashing. The techniques used in hashing are chaining, open addressing and linear probing.

#### Sorting

* **Insertion Sort**: It is a sorting technique that uses the divide and conquer approach. It involves dividing the list into two halves and then sorting the elements in each half.

* **Selection Sort**: It is a sorting technique that uses the divide and conquer approach. It involves selecting the smallest element from the list and then sorting the remaining elements.

* **Bubble Sort**: It is a sorting technique that uses the divide and conquer approach. It involves comparing adjacent elements and then swapping them if they are not in the correct order.

* **Quick Sort**: It is a sorting technique that uses the divide and conquer approach. It involves selecting a pivot element and then sorting the elements according to the pivot element.

* **Merge Sort**: It is a sorting technique that uses the divide and conquer approach. It involves dividing the list into two halves and then merging the sorted halves.

* **Heap Sort**: It is a sorting technique that uses the divide and conquer approach. It involves building a heap data structure and then sorting the elements according to the heap.

* **Radix Sort**: It is a sorting technique that uses the divide and conquer approach. It involves sorting the elements according to their digits.
