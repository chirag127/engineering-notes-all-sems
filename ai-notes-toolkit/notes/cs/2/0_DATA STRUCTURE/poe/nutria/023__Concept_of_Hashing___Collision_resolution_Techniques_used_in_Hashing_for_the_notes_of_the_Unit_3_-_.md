
### Concept of Hashing & Collision Resolution Techniques Used in Hashing

Hashing is a technique used to store and retrieve data from a data structure called a hash table. It is a type of data structure that uses a hash function to map keys to values. The hash function takes a key and computes an index in the hash table where the corresponding value is stored.

Collision resolution techniques are used to determine how to handle collisions, which occur when two different keys are mapped to the same index in the hash table. There are several collision resolution techniques, including linear probing, separate chaining, and open addressing.

#### Searching

Searching is a process of finding an element in a data structure. There are several searching techniques, including sequential search, index sequential search, and binary search.

Sequential search is a technique that searches for an element in a data structure by comparing each element in the data structure to the value being searched for.

Index sequential search is a technique that searches for an element in a data structure by first searching for the index of the element before searching for the element itself.

Binary search is a technique that searches for an element in a sorted data structure by repeatedly dividing the search space in half.

#### Sorting

Sorting is a process of arranging elements in a data structure in a particular order. There are several sorting algorithms, including insertion sort, selection sort, bubble sort, quick sort, merge sort, heap sort, and radix sort.

Insertion sort is a sorting algorithm that sorts elements in a data structure by repeatedly inserting elements into their correct position.

Selection sort is a sorting algorithm that sorts elements in a data structure by repeatedly selecting the smallest element in the unsorted portion of the data structure and swapping it with the first element in the unsorted portion.

Bubble sort is a sorting algorithm that sorts elements in a data structure by repeatedly swapping adjacent elements if they are in the wrong order.

Quick sort is a sorting algorithm that sorts elements in a data structure by repeatedly partitioning the data structure around a pivot element and recursively sorting the two partitions.

Merge sort is a sorting algorithm that sorts elements in a data structure by first dividing the data structure into smaller sub-arrays, sorting the sub-arrays, and then merging the sorted sub-arrays together.

Heap sort is a sorting algorithm that sorts elements in a data structure by repeatedly building a heap from the elements and extracting the largest element from the heap.

Radix sort is a sorting algorithm that sorts elements in a data structure by repeatedly sorting the elements based on their individual digits.
