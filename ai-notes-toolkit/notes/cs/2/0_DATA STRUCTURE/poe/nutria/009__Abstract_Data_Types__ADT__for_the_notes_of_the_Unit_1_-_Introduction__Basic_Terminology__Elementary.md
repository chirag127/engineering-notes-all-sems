
### Abstract Data Types (ADT)

* Basic Terminology: A set of fundamental concepts and principles used to describe and analyze a particular problem or domain.
* Elementary Data Organization: The way in which data is organized and stored in a computer system.
* Built-in Data Types in C: Primitive data types such as int, char, float, and double, as well as user-defined data types such as structs and unions.
* Algorithm: A step-by-step procedure for solving a problem.
* Efficiency of an Algorithm: The amount of time and/or space required to execute an algorithm.
* Time and Space Complexity: The amount of time and/or space required to execute an algorithm.
* Asymptotic Notations: Big Oh, Big Theta and Big Omega, which are used to describe the time and space complexity of an algorithm.
* Time-Space Trade-off: The idea that the time required to execute an algorithm can be reduced by increasing the amount of space required.
* Abstract Data Types (ADT): A type of data structure that is defined by the operations that can be performed on it, rather than by its physical implementation. Examples of ADTs include stacks, queues, and trees.
