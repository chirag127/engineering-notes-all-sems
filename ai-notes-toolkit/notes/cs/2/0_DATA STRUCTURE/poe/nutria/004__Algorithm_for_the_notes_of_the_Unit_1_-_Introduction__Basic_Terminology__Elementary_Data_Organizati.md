

### Algorithm for the notes of the Unit 1 - Introduction 

1. Basic Terminology: 
    - Algorithms are a set of instructions used to solve a problem.
    - Elementary Data Organization: Data is arranged in a logical order to facilitate efficient storage and retrieval.
    - Built in Data Types in C: C language provides a set of built-in data types like int, float, char, etc.
2. Algorithm: 
    - Efficiency of an Algorithm: The efficiency of an algorithm is determined by the number of operations it performs to solve a problem.
    - Time and Space Complexity: Time complexity measures the amount of time an algorithm takes to execute, while space complexity measures the amount of memory it requires.
    - Asymptotic Notations: Big Oh, Big Theta and Big Omega are asymptotic notations used to measure the complexity of an algorithm.
    - Time-Space Trade-off: This refers to the process of trading off time for space or vice versa, depending on the problem at hand.
3. Abstract Data Types (ADT): ADT is a type of data structure used in data science to represent the data in a logical and organized manner. It is used to store and manipulate data efficiently. ADT is used in the subject of DATA STRUCTURE.
