
### Application of Arrays

* Arrays are a type of data structure which store a collection of elements. They are used to store and manipulate data in an efficient manner.

* Arrays can be single-dimensional (1D), two-dimensional (2D), three-dimensional (3D) and n-dimensional (nD).

* Representation of Arrays: Row Major Order and Column Major Order. 
* Derivation of Index Formulae for 1-D,2-D,3-D and n-D Array Application of arrays. 

### Sparse Matrices
* Sparse matrices are matrices which contain a large number of zero elements. 
* They are used to represent data in a more efficient manner.

### Linked Lists
* Linked lists are a type of data structure which stores data in a linked list structure. 
* Array implementation and pointer implementation of singly linked lists, doubly linked list, and circularly linked list are possible. 
* Operations on a Linked List include insertion, deletion, and traversal.

### Polynomial Representation
* Polynomials can be represented in terms of their coefficients and powers. 
* Addition, subtraction and multiplication of single variable and two variables polynomials are possible.
