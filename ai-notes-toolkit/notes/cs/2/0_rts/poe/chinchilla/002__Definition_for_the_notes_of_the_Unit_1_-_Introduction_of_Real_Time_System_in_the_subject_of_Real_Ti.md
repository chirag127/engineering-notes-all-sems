### Definition for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System

Real-time systems are computer systems that are designed to respond to events in a timely and predictable manner. These systems are used in a variety of applications where timing is critical, such as industrial control systems, medical devices, and aerospace systems.

Here are some key definitions and concepts to understand in the introduction of real-time systems:

1. **Real-time system:** A computer system that is designed to respond to events in a timely and predictable manner.

2. **Hard real-time system:** A real-time system that has strict timing requirements. If a task is not completed within its deadline, it can result in catastrophic consequences.

3. **Soft real-time system:** A real-time system that has less strict timing requirements. If a task is not completed within its deadline, it may result in degraded performance but not catastrophic consequences.

4. **Deadline:** The time by which a task must be completed in a real-time system.

5. **Response time:** The time it takes for a system to respond to an event.

6. **Interrupt:** An event that causes a computer system to stop its current task and switch to a higher-priority task.

7. **Priority inversion:** A situation where a low-priority task holds a resource that a high-priority task needs, causing the high-priority task to be blocked.

8. **Preemption:** The ability of a higher-priority task to interrupt a lower-priority task and take control of the system.

9. **Scheduling:** The process of determining which task should run next in a real-time system.

10. **Concurrency:** The ability of a real-time system to execute multiple tasks simultaneously.

In summary, the introduction of real-time systems involves understanding the concept of timely and predictable response to events, the difference between hard and soft real-time systems, key terms such as deadline, response time, interrupt, priority inversion, preemption, scheduling, and concurrency.
