
### Soft Real Time Systems

* Soft real-time systems are computer systems that must respond to external events within a certain amount of time, but are not subject to hard deadlines.
* They are typically used in applications where the consequence of missing a deadline is not catastrophic.
* Examples of soft real-time systems include video streaming, voice recognition, and robotics.
* Soft real-time systems must have the ability to respond to external events in a timely manner, but the exact timing of the response is not critical.
* The system must be able to prioritize tasks and allocate resources accordingly to ensure that the most important tasks are completed first.
* Soft real-time systems are often implemented using priority scheduling algorithms, which allow tasks to be assigned different levels of priority.
* Soft real-time systems may also use scheduling algorithms that take into account the system's current load and the expected duration of tasks.
* In addition, soft real-time systems must be able to detect and respond to external events in a timely manner. This requires the system to have a mechanism for detecting external events and a mechanism for responding to them.
