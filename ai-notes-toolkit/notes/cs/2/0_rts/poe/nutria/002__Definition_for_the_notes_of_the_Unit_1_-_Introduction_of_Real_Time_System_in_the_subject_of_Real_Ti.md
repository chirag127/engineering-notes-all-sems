
### Definition for the Notes of the Unit 1 - Introduction of Real Time System in the Subject of Real Time System

1. Real-time systems are computer systems that are designed to respond to external events within a specified time frame.
2. In real-time systems, the correctness of the system depends on the timeliness of the system's response.
3. Real-time systems must meet deadlines and must be able to process data as it arrives.
4. Real-time systems are used in applications where there is a need for quick response to external events, such as in embedded systems, robotics, avionics, and manufacturing control systems.
5. Real-time systems must be able to process multiple tasks simultaneously and must be able to handle unpredictable delays.
6. Real-time systems must also be reliable and fault-tolerant.
7. Real-time systems are typically designed using a combination of hardware and software components.
