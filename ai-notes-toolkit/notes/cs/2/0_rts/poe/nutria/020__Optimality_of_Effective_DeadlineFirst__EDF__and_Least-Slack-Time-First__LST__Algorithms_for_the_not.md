
### Optimality of Effective DeadlineFirst (EDF) and Least-Slack-Time-First (LST) Algorithms for the notes of the Unit 2 - Real Time Scheduling in the subject of Real Time System

1. Effective DeadlineFirst (EDF) is an algorithm used to schedule tasks in real-time systems. It is based on the idea that tasks that have a shorter deadline should be given priority over tasks with longer deadlines.

2. EDF is an optimal scheduling algorithm as it guarantees that all tasks will be completed on time if the processor is capable of handling the load.

3. Least-Slack-Time-First (LST) is another algorithm used to schedule tasks in real-time systems. It is based on the idea that tasks with the least amount of slack time should be given priority over tasks with more slack time.

4. LST is an optimal scheduling algorithm as it guarantees that all tasks will be completed on time if the processor is capable of handling the load.

5. Both EDF and LST are optimal scheduling algorithms for real-time systems. However, EDF is slightly more efficient than LST since it does not require the calculation of slack time for each task.
