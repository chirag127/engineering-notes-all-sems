
### Introduction to Unit 1 - Set Theory 

1. Set Theory is a branch of mathematics that deals with the study of sets, which are collections of objects that can be related in some way.

2. A set is a collection of distinct objects, called elements, that can be related in some way. Sets can be finite or infinite, and can contain any type of element, such as numbers, strings, or even other sets.

3. A subset is a collection of elements from a given set. A subset is said to be proper if it is not equal to the set itself.

4. Set operations are operations that can be performed on sets. Examples of set operations include union, intersection, and complement.

5. Relations are a way of expressing the relationship between two sets. Examples of relations include equality, inclusion, and disjointness.

6. Functions are a way of mapping elements from one set to another. Examples of functions include one-to-one, onto, and bijective functions.

7. Discrete Structures & Theory of Logic is a branch of mathematics that deals with the study of discrete mathematical structures and the principles of logical reasoning. It is used to model and analyze complex systems, including computer algorithms and networks.
