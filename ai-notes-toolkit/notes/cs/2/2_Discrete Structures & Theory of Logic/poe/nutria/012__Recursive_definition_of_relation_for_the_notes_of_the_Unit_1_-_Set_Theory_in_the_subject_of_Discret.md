
### Recursive definition of relation for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

- A relation is a set of ordered pairs. 
- A relation is said to be __recursive__ when the set of ordered pairs contains one or more ordered pairs that contain the relation itself. 
- For example, a relation R is said to be recursive when it contains an ordered pair (x, R) where x is an element of the set and R is the relation itself. 
- In other words, a recursive relation is one that contains itself as a subset. 
- A recursive relation can also be written as a function, where the function takes an input and produces an output that is a subset of the relation itself. 
- Recursive relations can be used to describe many types of structures, such as trees and graphs. 
- They can also be used to define certain types of algorithms, such as the Fibonacci sequence.
