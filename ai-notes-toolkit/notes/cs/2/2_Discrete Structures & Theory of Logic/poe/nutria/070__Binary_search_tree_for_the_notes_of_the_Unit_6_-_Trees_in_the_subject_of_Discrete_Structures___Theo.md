
### Binary Search Tree
A binary search tree is a data structure that is used to store data in a tree-like structure. It is a type of self-balancing binary tree, in which each node stores an item of data and has two child nodes, left and right. The left child node stores data that is less than the parent node, while the right child node stores data that is greater than or equal to the parent node.

The following are the key features of a binary search tree:

* The left subtree of a node contains only nodes with values less than the node's value.
* The right subtree of a node contains only nodes with values greater than or equal to the node's value.
* The left and right subtree each must also be a binary search tree.
* There must be no duplicate values.

The following are some of the operations that can be performed on a binary search tree:

* Search: Given a value, the search operation can be used to find the node containing the value.
* Insert: Given a value, the insert operation can be used to insert a new node containing the value into the tree.
* Delete: Given a value, the delete operation can be used to delete the node containing the value from the tree.
* Traversal: The traversal operation is used to traverse the tree in order to print out the values in the tree. There are three types of traversal: pre-order, in-order, and post-order.

Binary search trees are used in many applications, such as databases, sorting algorithms, and search engines. They are also used in data structures such as heaps, priority queues, and sets.
