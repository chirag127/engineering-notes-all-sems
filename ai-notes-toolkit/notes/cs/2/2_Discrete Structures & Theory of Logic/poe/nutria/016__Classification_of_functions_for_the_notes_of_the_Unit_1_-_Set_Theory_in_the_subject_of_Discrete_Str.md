
### Classification of functions for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. **Injective (One-to-one) functions:** A function is said to be injective if every element in the domain is mapped to a unique element in the range.

2. **Surjective (Onto) functions:** A function is said to be surjective if every element in the range is mapped to at least one element in the domain.

3. **Bijective (One-to-one and Onto) functions:** A function is said to be bijective if it is both injective and surjective.

4. **Identity functions:** An identity function is a function that maps each element of a given set to itself.

5. **Constant functions:** A constant function is a function in which the output of the function is the same for all inputs.

6. **Composition of functions:** The composition of two functions is the combination of two functions in which the output of one function is the input of the other function.
