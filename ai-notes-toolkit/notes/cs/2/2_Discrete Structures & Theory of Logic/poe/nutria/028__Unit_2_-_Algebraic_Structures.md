
## Unit 2 - Algebraic Structures

1. Algebraic Structures are mathematical systems that are defined by a set of elements and operations that act on them. 
2. The most common algebraic structures are groups, rings, and fields. 
3. A group is a set of elements with a single binary operation that is associative, has an identity element, and is closed under inverses. 
4. A ring is a set of elements with two binary operations, addition and multiplication, that are associative, have an identity element, and are closed under inverses. 
5. A field is a set of elements with two binary operations, addition and multiplication, that are associative, have an identity element, are commutative and distributive, and are closed under inverses. 
6. Other algebraic structures include lattices, vector spaces, algebras, and modules. 
7. Algebraic Structures are used to study abstract algebra, linear algebra, and number theory.
