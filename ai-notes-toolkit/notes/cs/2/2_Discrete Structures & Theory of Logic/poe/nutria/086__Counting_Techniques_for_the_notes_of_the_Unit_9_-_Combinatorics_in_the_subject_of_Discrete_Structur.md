3. Factorials: Factorials are used to calculate the number of ways to arrange a group of objects when the order matters. This is done by taking the number of objects and multiplying it by the number of objects minus one, then subtracting one. 

4. Binomial Coefficients: Binomial coefficients are used to calculate the number of ways to select a group of objects from a larger group when the order matters. This is done by taking the number of objects in the larger group and dividing it by the number of objects in the smaller group, then subtracting one.
