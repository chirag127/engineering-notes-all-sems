
### Well Formed Formula of Predicate

A well-formed formula of predicate (or WFF) is a formula that is constructed according to certain syntactic rules. In the context of discrete structures and the theory of logic, a WFF is the most basic form of a logical statement.

A WFF consists of two components:
1. A predicate, which is a statement about an object or set of objects.
2. One or more arguments, which are the objects or sets of objects in the statement.

The syntax of a WFF is important because it determines the meaning of the statement. In order to be valid, a WFF must follow certain rules:
1. All predicates must be expressed in terms of the same set of objects.
2. All predicates must be of the same type.
3. All arguments must be valid, i.e. they must refer to a set of objects that actually exist.
4. All arguments must be of the same type.
5. All arguments must be related to the predicate in a logical way.
6. The WFF must be logically consistent.

A WFF is said to be valid if it follows all of the above rules. If a WFF is valid, then it is true in all possible contexts. If a WFF is not valid, then it is false in some contexts.
