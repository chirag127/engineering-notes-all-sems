
### First Order Predicate Logic 

* Predicate logic is a type of formal logic that extends propositional logic with predicates. 
* Predicates are expressions that can be evaluated to either true or false and can be used to describe properties of objects. 
* Predicate logic allows for the use of quantifiers, which are words that specify the number of objects that satisfy a given condition. 
* The two most common quantifiers are the universal quantifier (∀) and the existential quantifier (∃). 
* The universal quantifier is used to indicate that all objects in a given set satisfy a given condition, while the existential quantifier is used to indicate that at least one object in a given set satisfies a given condition. 
* Predicate logic also allows for the use of variables, which can be used to refer to specific objects in a set. 
* Predicate logic can be used to express more complex statements than propositional logic, and is often used in computer science and mathematics.
