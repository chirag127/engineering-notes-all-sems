
### Ordered pairs for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. An **ordered pair** is a set of two elements that are related in some way. 
2. The elements of an ordered pair are usually written as (x, y) where x is the first element and y is the second element. 
3. An ordered pair can be used to represent a point on a graph, a vector, or a relationship between two elements. 
4. An ordered pair is also known as a **Cartesian product**, which is a set of all possible ordered pairs from two sets. 
5. An ordered pair can also be used to represent a function. A function is a relationship between two sets of elements, where each element in one set has a corresponding element in the other set. 
6. In set theory, an ordered pair is used to represent the relationship between two sets. For example, the ordered pair (A, B) could represent the relationship between sets A and B. 
7. The ordered pair (x, y) is also used to represent the coordinates of a point on a graph. 
8. In mathematics, an ordered pair is used to represent the slope of a line. The slope of a line is the ratio of the change in the y-coordinate to the change in the x-coordinate.
