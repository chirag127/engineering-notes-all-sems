
### Euler and Hamiltonian Paths

1. An **Euler path** is a path in a graph that visits every edge exactly once.
2. An **Euler circuit** is an Euler path that starts and ends at the same vertex.
3. A **Hamiltonian path** is a path in a graph that visits every vertex exactly once.
4. A **Hamiltonian circuit** is a Hamiltonian path that starts and ends at the same vertex.
5. An Euler path or circuit exists in a graph if and only if each vertex has an even degree.
6. A Hamiltonian path or circuit exists in a graph if and only if the graph is connected and each vertex has degree at least two.
