
## Unit 1 - Set Theory

1. A **set** is a collection of distinct objects, called **elements** or **members**. 
2. The **order** of the elements in a set is not important.
3. The **number** of elements in a set is called its **cardinality**.
4. Two sets are **equal** if they have the same elements, regardless of order.
5. The **empty set**, denoted by $\emptyset$, is the set with no elements.
6. A **subset** of a set is a set whose elements are all contained in the original set.
7. The **universal set**, denoted by $\mathbb{U}$, is the set containing all elements under consideration.
8. The **complement** of a set is the set of elements not in the original set.
9. The **intersection** of two sets is the set of elements that are in both sets.
10. The **union** of two sets is the set of elements that are in either set.
