
### Functions for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

* A function is a special type of relation that assigns a unique output to each input. 
* A function is a set of ordered pairs such that for each element of the domain, there is exactly one element of the range. 
* The domain of a function is the set of all inputs, and the range is the set of all outputs. 
* The graph of a function is the set of all points (x, y) such that y = f(x). 
* A function is said to be injective (one-to-one) if for each element of the domain, there is exactly one element of the range. 
* A function is said to be surjective (onto) if for each element of the range, there is at least one element of the domain. 
* A function is said to be bijective (one-to-one and onto) if it is both injective and surjective. 
* The inverse of a function is the set of all points (x, y) such that x = f(y). 
* A function is said to be invertible if it has an inverse. 
* The composition of two functions is the set of all points (x, y) such that y = f(g(x)). 
* The composition of two functions is also a function.
