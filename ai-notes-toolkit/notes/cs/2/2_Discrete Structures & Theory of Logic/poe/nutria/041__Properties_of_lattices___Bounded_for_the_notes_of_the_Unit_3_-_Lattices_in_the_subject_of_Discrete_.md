
### Properties of Lattices – Bounded

1. A lattice is a partially ordered set in which any two elements have a greatest lower bound (GLB) and a least upper bound (LUB). 
2. A bounded lattice is a lattice that has a greatest element, denoted as 1, and a least element, denoted as 0. 
3. A bounded lattice is said to be complete if every subset of it has a LUB and a GLB. 
4. A lattice can be represented by its Hasse Diagram, which is a graphical representation of the lattice’s partial order relation. 
5. If a lattice is bounded, then its Hasse Diagram is a finite graph. 
6. In a bounded lattice, every element has a unique representation in the Hasse Diagram. 
7. Every subset of a bounded lattice has a LUB and a GLB, which can be found by looking at the Hasse Diagram. 
8. The dual of a bounded lattice is another bounded lattice, in which the order relation is reversed. 
9. A bounded lattice can be represented as a set of sets, where each set is a subset of the lattice. 
10. A bounded lattice can also be represented as a directed acyclic graph, in which the edges represent the order relation.
