
### Definition for the notes of the Unit 6 - Trees in the subject of Discrete Structures & Theory of Logic

* A tree is a data structure consisting of nodes in a parent-child relationship. 
* The topmost node is called the root node, and the nodes below it are called the children of the root node. 
* Each node has a value associated with it, and each node can have an arbitrary number of children. 
* A tree is a hierarchical structure, with each node having a parent and zero or more children. 
* The root node is the only node that does not have a parent. 
* The nodes at the bottom of the tree are called leaves. 
* The height of a tree is the maximum number of edges from the root node to any leaf. 
* The depth of a node is the number of edges from the root node to that node. 
* A binary tree is a tree in which each node has at most two children. 
* A binary search tree is a binary tree in which each node's value is greater than all of its left descendants and less than all of its right descendants. 
* A balanced binary tree is a binary tree in which the height of the two subtrees of any node differ by at most one. 
* A complete binary tree is a binary tree in which each level, except possibly the last, is completely filled, and all nodes are as far left as possible. 
* A full binary tree is a binary tree in which each node has either two children or no children. 
* A perfect binary tree is a binary tree in which all leaves are at the same depth, and all internal nodes have two children.
