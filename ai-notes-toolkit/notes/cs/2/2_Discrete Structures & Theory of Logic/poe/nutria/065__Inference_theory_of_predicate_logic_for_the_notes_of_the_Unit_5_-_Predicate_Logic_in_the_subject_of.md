
### Inference Theory of Predicate Logic

1. Predicate logic is a formal language used to describe the relationships between objects, properties, and relations. 
2. It is an extension of propositional logic and allows for more complex statements to be expressed.
3. Inference rules are used to infer new statements from existing ones.
4. Inference rules are divided into two types: logical rules and semantic rules.
5. Logical rules are used to infer new statements from existing ones using the logical connectives such as “and”, “or”, “if-then”, etc.
6. Semantic rules are used to infer new statements from existing ones using the semantic relations between objects, properties, and relations.
7. Inference rules can be used to prove theorems in predicate logic.
8. Inference rules can also be used to generate new knowledge from existing knowledge.
9. Inference rules can be used to solve problems in predicate logic.
