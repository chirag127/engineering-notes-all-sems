### Equality of relations

- Two relations R and S on a set A are said to be equal if for every (a, b) in R, (a, b) is also in S and vice-versa.
- In other words, R = S if and only if R ⊆ S and S ⊆ R.
- Equal relations have exactly the same ordered pairs.
- Example: Let R = {(1, 2), (3, 4)} and S = {(3, 4), (1, 2)} on set A = {1, 2, 3, 4}. Then, R = S as they contain exactly the same ordered pairs.
- Properties:
    - Reflexive: R = R
    - Symmetric: If R = S then S = R
    - Transitive: If R = S and S = T then R = T
- Equal relations on a set A have similar properties as relations on A. So, properties like reflexivity, symmetry and transitivity are preserved under equality of relations.
