### Binary tree traversal

1. Inorder traversal: Left -> Root -> Right
- Visit left subtree
- Visit root
- Visit right subtree

2. Preorder traversal: Root -> Left -> Right
- Visit root
- Visit left subtree
- Visit right subtree

3. Postorder traversal: Left -> Right -> Root
- Visit left subtree
- Visit right subtree
- Visit root

The traversals can be used to:
- Get nodes in sorted order (inorder)
- Duplicate a binary tree (preorder)
- Delete a binary tree (postorder)

The traversals can be implemented using recursion or iteration.
The time complexity of all traversals is O(n) where n is the number of nodes in the binary tree.
