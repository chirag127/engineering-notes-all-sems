### Functions for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Set: A well-defined collection of objects is called a set. The objects in a set are called its elements or members.

2. Empty set: A set with no elements is called an empty set. It is denoted by { }.

3. Universal set: A set which contains all possible elements under consideration is called universal set. It is denoted by U.

4. Subset: A set A is called a subset of set B if every element of A is also an element of B. It is denoted by A ⊆ B.

5. Power set: The set of all subsets of a given set S is called the power set of S. It is denoted by P(S).

6. Venn diagrams: Venn diagrams are pictorial representation of sets and their relationships using closed figures. They are extensively used to teach set theory concepts.
