### Operations on functions for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Composition of functions: If f and g are two functions defined on sets A and B respectively, then we can form a composite function g°f by applying f first and then g. That is, (g°f)(x) = g[f(x)] for all x in A.
2. Inverse of a function: A function f from a set A to a set B has an inverse function f^-1 from B to A if f(f^-1(y)) = y for every y in B and f^-1(f(x)) = x for every x in A. Inverse functions are useful in solving equations.
3. Identity function: The identity function I on any set A is defined by I(x) = x for all x in A. It leaves each element unchanged.
4. Constant function: A constant function on any set A is a function with the same fixed value for every element in its domain, for example f(x) = 7 for all x in A.
