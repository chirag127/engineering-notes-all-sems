### Introduction for the notes of the Unit 1 - Set Theory

1. A set is a collection of objects. The objects in a set are called its elements or members.
2. Sets are usually denoted by capital letters: A, B, C, etc. The elements of a set are denoted by lowercase letters: a, b, c, etc.
3. The order of elements in a set is irrelevant. {a, b, c} is the same set as {c, b, a}.
4. A set with no elements is called the empty set and is denoted by Ø.
5. Two sets are equal if and only if they have exactly the same elements.
6. Subsets: If all the elements of set A are also elements of set B, then A is a subset of B. This is written as A ⊆ B.
7. Proper subset: If A is a subset of B, but A is not equal to B, then A is called a proper subset of B. This is written as A ⊂ B.
8. Power set: The power set of a set A is the set of all subsets of A. It is denoted by P(A) or 2A.
9. Union: The union of two sets A and B, denoted by A ∪ B, is the set of elements that are in A, in B, or in both A and B.
10. Intersection: The intersection of two sets A and B, denoted by A ∩ B, is the set of elements that are common to both A and B.
