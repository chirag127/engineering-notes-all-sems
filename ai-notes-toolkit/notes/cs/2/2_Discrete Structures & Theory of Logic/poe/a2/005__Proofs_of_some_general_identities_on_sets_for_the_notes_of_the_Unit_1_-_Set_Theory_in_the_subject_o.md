### Proofs of some general identities on sets for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Proof that A union (B intersection C) = (A union B) intersection (A union C):

Given: A, B and C are sets
To Prove: A union (B intersection C) = (A union B) intersection (A union C)
Proof:
A union (B intersection C)
= A union {x: x is an element of B and x is an element of C}
= A union (A intersection B) intersection (A intersection C)
= (A union A intersection B) intersection (A intersection C)
= A union B intersection (A intersection C)
= (A union B) intersection (A union C)

2. Proof that A intersection (B union C) = (A intersection B) union (A intersection C):

Given: A, B and C are sets
To Prove: A intersection (B union C) = (A intersection B) union (A intersection C)
Proof:
A intersection (B union C)
= A intersection {x: x is an element of B or x is an element of C}
= {x: x is an element of A and (x is an element of B or x is an element of C)}
= {x: x is an element of A and x is an element of B}
union {x: x is an element of A and x is an element of C}
= (A intersection B) union (A intersection C)
