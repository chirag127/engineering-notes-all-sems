### Modular and Complete lattice for the notes of the Unit 3 - Lattices

1. A lattice (L, ≤) is said to be modular if for all a, b, c in L, if a ≤ b then a ∨ (b ∧ c) = (a ∨ b) ∧ c.
2. A lattice (L, ≤) is said to be complete if every subset S of L has both a greatest lower bound (glb) and a least upper bound (lub).
3. Every complete lattice is modular but the converse is not true.
4. Finite lattices are always complete.
5. The set of all subsets of a set X ordered by inclusion is a complete lattice.
6. The set of all intervals on the real line ordered by reversed inclusion is a complete lattice.
7. A lattice (L, ≤) is said to be algebraic if every element can be written as a join of meet-irreducibles.
8. A lattice (L, ≤) is said to be distributive if for all a, b, c in L, a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c).
9. Distributive lattices are necessarily modular as well as algebraic.
10. The lattices of subspaces of a vector space and subgroups of a group are distributive lattices.
