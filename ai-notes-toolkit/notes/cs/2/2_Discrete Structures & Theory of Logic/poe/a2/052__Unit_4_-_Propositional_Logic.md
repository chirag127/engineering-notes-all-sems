## Unit 4 - Propositional Logic

1. Propositional logic deals with propositions (statements) that can either be true or false.
2. Propositions are combined using logical operators like and (∧), or (∨), not (¬), implies (→), if and only if (↔).
3. Truth tables can be used to determine the truth values of composite propositions based on the truth values of their components.
4. Some common logical equivalences like De Morgan's laws and distributive law can be used to simplify logical expressions.
5. Logical validity of an argument can be checked by converting the statements into a logical expression and then simplifying it. If it reduces to a tautology, the argument is valid.
6. The concepts of necessary and sufficient conditions can be expressed in propositional logic using logical equivalence.
