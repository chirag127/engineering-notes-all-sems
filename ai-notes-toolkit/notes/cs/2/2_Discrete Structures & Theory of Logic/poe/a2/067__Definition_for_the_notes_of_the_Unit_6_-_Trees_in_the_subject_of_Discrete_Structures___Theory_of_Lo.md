### Definition for the notes of the Unit 6 - Trees in the subject of Discrete Structures & Theory of Logic

1. Tree: A tree is an undirected graph which contains no cycles and has a unique path between every pair of nodes.
2. Root: The root is the node at the top of the tree which has no incoming edges.
3. Parent/Child: A parent is a node which has an edge coming into it from another node. A child is a node which has an edge going out of it to another node. A parent can have multiple children but a child can have only one parent.
4. Leaf: A leaf is a node which has no children.
5. Subtree: A subtree is a tree which is a subset of a larger tree. It includes a node, its children and their children and so on. The node at the top of the subtree is the root of that subtree.
6. Height: The height of a tree is the length of the longest path from the root node to a leaf node.
7. Degree: The degree of a node is the number of children it has.
