### Mathematical Induction for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Mathematical Induction is a method of proof that is used to establish that a given statement is true for all natural numbers.
2. It involves two steps:
- Basis Step: Proving that the statement is true for the first natural number (i.e. n = 1)
- Induction Step: Assuming that the statement is true for some arbitrary natural number n, and then proving that it must also be true for n + 1.
3. If both the Basis Step and Induction Step can be proven, then the statement is true for all natural numbers.
4. Example: Prove that 1 + 2 + 3 + ... + n = n(n+1)/2 for all natural numbers n.
- Basis Step: The statement is true for n = 1. 1 = 1(1+1)/2
- Induction Step: Assume the statement is true for some n. Then, 1 + 2 + ... + n + (n + 1) = (n + 1)(n + 2)/2. Hence, if true for some n, then also true for n + 1.
- Therefore, by Mathematical Induction, the statement is true for all natural numbers n.
