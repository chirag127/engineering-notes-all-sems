### Order of relations

1. Reflexive relation: A relation R on a set A is reflexive if for every element a in A, aRa holds. For example, the relation "is equal to" on the set of real numbers is reflexive.
2. Symmetric relation: A relation R on a set A is symmetric if for every pair of elements a and b in A, aRb implies bRa. For example, the relation "is parallel to" on the set of lines is symmetric.
3. Transitive relation: A relation R on a set A is transitive if for every triple of elements a, b and c in A, aRb and bRc implies aRc. For example, the relation "is greater than" on the set of integers is transitive.
4. Equivalence relation: An equivalence relation is a relation that is reflexive, symmetric and transitive. For example, the relation "has the same remainder when divided by 3" on the set of integers is an equivalence relation.
