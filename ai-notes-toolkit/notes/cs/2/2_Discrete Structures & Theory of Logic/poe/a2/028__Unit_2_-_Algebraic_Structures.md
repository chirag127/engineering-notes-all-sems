## Unit 2 - Algebraic Structures

1. Groups: A group is a set of elements with an operation that combines any two elements to form another element in the set. The operation must satisfy four conditions - closure, associativity, identity, and invertibility. Examples of groups include the set of integers under addition, the set of nonzero real numbers under multiplication, etc.

2. Rings: A ring is a set of elements with two operations - addition and multiplication - such that the set is an abelian group under addition and the multiplication operation is distributive over addition. The elements are not required to have multiplicative inverses. Examples include the set of integers, real numbers, polynomials, etc. under the usual addition and multiplication.

3. Fields: A field is a ring where every nonzero element has a multiplicative inverse. The standard examples are the rational, real, and complex numbers. Fields are used to study division and ratios.

4. Vector Spaces: A vector space is a set of vectors with operations of addition, subtraction, and scalar multiplication that satisfy certain properties. Vector spaces are used to study linear combinations and linear independence. Examples include Rn and Cn.

The content summarizes the key definitions and examples of the major algebraic structures of groups, rings, fields, and vector spaces.
