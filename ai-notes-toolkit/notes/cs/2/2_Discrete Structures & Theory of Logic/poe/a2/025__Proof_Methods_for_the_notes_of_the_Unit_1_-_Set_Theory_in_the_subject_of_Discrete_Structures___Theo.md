### Proof Methods for the notes of the Unit 1 - Set Theory

1. Direct Proof: Proving a statement is true by showing directly that it must be true. For example:
To prove: If x is an integer, then x^2 is an integer.
Proof: Let x be an integer. Then x = n for some integer n.
Therefore, x^2 = n^2 for some integer n.
Therefore, x^2 is an integer.

2. Proof by Contradiction: Proving a statement is true by showing that assuming its negation leads to a contradiction. For example:
To prove: The square root of 2 is irrational.
Proof: Suppose sqrt(2) = p/q where p and q are integers.
Then 2q^2 = 2p^2 or q^2 = 2. This is impossible since 2 does not divide any odd integer.
Therefore, there are no integers p and q such that sqrt(2) = p/q.
Therefore, sqrt(2) is irrational.

3. Mathematical Induction: A proof technique used to prove that a statement is true for all natural numbers. It involves two steps:
1. Prove the statement is true for the smallest natural number (base case).
2. Prove that if the statement is true for some natural number n, then it must also be true for n+1 (inductive step).
If both steps can be proven, then the statement is true for all natural numbers.
