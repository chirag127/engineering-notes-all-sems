### Functions

A function is a relation that assigns to each element of a set A, called the domain, exactly one element of a set B, called the codomain. The set of all elements that are assigned by the function is called the range.

A function can be represented by a set of ordered pairs, a table, a graph, or a formula. For example, the function that assigns to each natural number its square can be represented by:

- The set of ordered pairs {(0,0), (1,1), (2,4), (3,9), ...}
- The table:

| x | f(x) |
|---|------|
| 0 | 0    |
| 1 | 1    |
| 2 | 4    |
| 3 | 9    |
|...|...   |

- The graph:

![graph of y=x^2](https://www.mathsisfun.com/algebra/images/quadratic-graph.svg)

- The formula: f(x) = x^2

Some important concepts related to functions are:

- The inverse of a function f is a function that reverses the effect of f. For example, the inverse of f(x) = x^2 is f^(-1)(x) = sqrt(x), where sqrt(x) is the positive square root of x. The inverse of a function exists only if the function is one-to-one, meaning that each element of the codomain is assigned to at most one element of the domain.
- The composition of two functions f and g is a function that applies g first and then f. For example, the composition of f(x) = x^2 and g(x) = x + 1 is f(g(x)) = (x + 1)^2. The composition of two functions is associative, meaning that f(g(h(x))) = (f(g))(h(x)) = f((g(h))(x)).
- The identity function is a function that assigns each element of a set to itself. For example, the identity function on the set of natural numbers is i(x) = x. The identity function is the neutral element for the composition of functions, meaning that f(i(x)) = i(f(x)) = f(x) for any function f.
