### Representation of graphs

- A graph is a mathematical structure that represents a pairwise relationship between objects.
- A graph consists of a set of vertices (or nodes) and a set of edges (or arcs) that connect the vertices.
- A graph can be symbolized as G(V, E), where V is the set of vertices and E is the set of edges.
- A graph can be represented in different ways, such as:

  - **Adjacency matrix**: A two-dimensional array of size |V| x |V|, where the entry at row i and column j is 1 if there is an edge from vertex i to vertex j, and 0 otherwise.
  - **Adjacency list**: A list of lists, where the ith list contains the vertices that are adjacent to vertex i.
  - **Incidence matrix**: A two-dimensional array of size |V| x |E|, where the entry at row i and column j is 1 if vertex i is incident to edge j, and 0 otherwise.
  - **Edge list**: A list of pairs, where each pair represents an edge between two vertices.
  - **Graphical representation**: A visual representation of the graph, where the vertices are drawn as points or circles, and the edges are drawn as lines or curves connecting the vertices.
