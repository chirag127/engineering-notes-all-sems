## Unit 1 - Set Theory

- A **set** is a collection of distinct objects, such as numbers, letters, symbols, etc.
- The objects in a set are called **elements** or **members** of the set.
- A set can be represented by listing its elements inside curly braces, such as {1, 2, 3} or {a, b, c}.
- A set can also be defined by a rule or a property that its elements satisfy, such as {x | x is an even integer} or {y | y is a vowel}.
- Two sets are **equal** if they have exactly the same elements, regardless of the order or repetition of the elements.
- A set that has no elements is called the **empty set** or the **null set**, and is denoted by ∅ or {}.
- The **cardinality** or the **size** of a set is the number of elements in the set, and is denoted by |A| for a set A.
- A set that has only one element is called a **singleton** or a **unit set**, such as {5} or {x}.
- A set that has a finite number of elements is called a **finite set**, such as {1, 2, 3, 4, 5}.
- A set that has an infinite number of elements is called an **infinite set**, such as {1, 2, 3, ...} or {x | x is a natural number}.
- A set that contains all the elements of another set is called a **superset** of that set, and is denoted by A ⊇ B for sets A and B.
- A set that is contained in another set is called a **subset** of that set, and is denoted by A ⊆ B for sets A and B.
- A set that is a subset of another set but not equal to it is called a **proper subset** of that set, and is denoted by A ⊂ B for sets A and B.
- A set that has no elements in common with another set is called a **disjoint set** from that set, and is denoted by A ∩ B = ∅ for sets A and B.
- The **union** of two sets is the set that contains all the elements that are in either set or both sets, and is denoted by A ∪ B for sets A and B.
- The **intersection** of two sets is the set that contains all the elements that are in both sets, and is denoted by A ∩ B for sets A and B.
- The **difference** of two sets is the set that contains all the elements that are in the first set but not in the second set, and is denoted by A - B or A \ B for sets A and B.
- The **complement** of a set is the set that contains all the elements that are not in the given set, and is denoted by A' or A^c for a set A.
- The **universal set** is the set that contains all the elements under consideration, and is denoted by U or Ω.
- The **power set** of a set is the set that contains all the subsets of the given set, and is denoted by P(A) or 2^A for a set A.
- The **Cartesian product** of two sets is the set that contains all the ordered pairs of elements from the two sets, and is denoted by A × B for sets A and B.
