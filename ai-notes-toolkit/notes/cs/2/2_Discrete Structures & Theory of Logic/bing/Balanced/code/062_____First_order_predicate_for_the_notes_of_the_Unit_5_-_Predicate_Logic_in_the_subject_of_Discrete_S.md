### First order predicate logic

- First order predicate logic is a formal language in which propositions are expressed in terms of predicates, variables and quantifiers .
- A predicate is a symbol that represents a property or relation of one or more objects . For example, `P(x)` means that `x` has the property `P`, and `R(x,y)` means that `x` and `y` are related by `R`.
- A variable is a symbol that can stand for any object in a given domain . For example, `x` and `y` are variables that can represent any person, animal, number, etc.
- A quantifier is a symbol that specifies how many objects in the domain satisfy a given predicate . For example, `∀x P(x)` means that `P` is true for all objects in the domain, and `∃x P(x)` means that there is at least one object in the domain that satisfies `P`.
- A formula is a well-formed expression that can be true or false depending on the values of the variables and the interpretation of the predicates . For example, `∀x (P(x) → Q(x))` is a formula that says that for every object in the domain, if it has the property `P`, then it also has the property `Q`.
- The syntax of first order predicate logic defines the rules for constructing valid formulas from symbols . For example, a formula can be an atomic formula (a predicate with variables or constants as arguments), a negation of a formula (`¬φ`), a conjunction of two formulas (`φ ∧ ψ`), a disjunction of two formulas (`φ ∨ ψ`), an implication of two formulas (`φ → ψ`), an equivalence of two formulas (`φ ↔ ψ`), a universal quantification of a formula (`∀x φ`), or an existential quantification of a formula (`∃x φ`).
- The semantics of first order predicate logic defines the rules for evaluating the truth value of a formula in a given model . A model consists of a domain (a set of objects) and an interpretation (a function that assigns meanings to the predicates, constants and functions in the language). A formula is true in a model if it is satisfied by every assignment of values to the variables in the model, and false otherwise.
- The inference rules of first order predicate logic define the rules for deriving new formulas from existing ones using logical reasoning . For example, modus ponens is an inference rule that says that if `φ` and `φ → ψ` are true, then `ψ` is also true. There are also rules for introducing and eliminating quantifiers, such as universal instantiation, universal generalization, existential instantiation and existential generalization.
- The advantages of first order predicate logic over propositional logic are that it can express more complex and nuanced propositions, and that it can capture the structure and meaning of natural language sentences . For example, the sentence "Every human is mortal" can be translated into first order predicate logic as `∀x (Human(x) → Mortal(x))`, but it cannot be expressed in propositional logic without introducing a separate symbol for each human.
- The limitations of first order predicate logic are that it cannot express propositions that involve predicates or functions of higher order (such as predicates of predicates, or functions that return functions), and that it is undecidable, meaning that there is no algorithm that can determine whether a given formula is valid or not . For example, the sentence "There is a property that only one object has" can be translated into second order logic as `∃P (∃x P(x) ∧ ∀y (P(y) → y = x))`, but it cannot be expressed in first order logic. Also, the problem of determining whether a formula is valid or not is equivalent to the halting problem, which is known to be unsolvable.
