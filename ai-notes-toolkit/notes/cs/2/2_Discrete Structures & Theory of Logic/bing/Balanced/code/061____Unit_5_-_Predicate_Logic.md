## Unit 5 - Predicate Logic

Predicate logic is a branch of logic that deals with predicates, quantifiers, and variables. Predicate logic allows us to express more complex statements than propositional logic, such as "Every human is mortal" or "Some cats are black".

- A predicate is a symbol that represents a property or relation of some objects. For example, P(x) could mean "x is prime" or "x is a person".
- A quantifier is a symbol that specifies how many objects satisfy a predicate. For example, ∀x P(x) means "for all x, P(x) is true" or "P(x) is true for every x". ∃x P(x) means "there exists some x such that P(x) is true" or "P(x) is true for some x".
- A variable is a symbol that can stand for any object in a given domain. For example, x, y, z are variables that can represent any number, person, animal, etc.
- A domain is a set of objects that the variables can range over. For example, the domain of natural numbers, the domain of humans, the domain of cats, etc.
- A constant is a symbol that represents a specific object in a domain. For example, 2, Alice, Garfield are constants that represent a number, a person, and a cat, respectively.

Predicate logic has a syntax and a semantics, just like propositional logic. The syntax defines the rules for forming well-formed formulas (wffs) using predicates, quantifiers, variables, constants, and logical connectives. The semantics defines the rules for assigning truth values to wffs based on the interpretation of the symbols and the domain.

Some examples of wffs in predicate logic are:

- ∀x (P(x) → Q(x)) : For all x, if x is prime, then x is odd.
- ∃y (R(a, y) ∧ S(y, b)) : There exists some y such that a is related to y and y is related to b.
- ¬∃z (T(z) ↔ ¬T(z)) : There does not exist any z such that z is both true and false.

Predicate logic can be used to formalize natural language sentences, mathematical statements, and logical arguments. Predicate logic can also be used to perform logical reasoning, such as applying rules of inference, proving theorems, and checking validity and consistency. Predicate logic is more expressive and powerful than propositional logic, but also more complex and difficult to work with.
