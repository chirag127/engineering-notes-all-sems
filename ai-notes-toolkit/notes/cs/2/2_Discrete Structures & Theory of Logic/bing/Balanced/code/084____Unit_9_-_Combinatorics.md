## Unit 9 - Combinatorics

Combinatorics is the branch of mathematics that studies the ways of counting, arranging, and selecting objects from a given set or collection. Some of the main topics in combinatorics are:

- **Factorial**: The factorial of a positive integer n, denoted by n!, is the product of all positive integers less than or equal to n. For example, 5! = 5 x 4 x 3 x 2 x 1 = 120. The factorial of 0 is defined to be 1, that is, 0! = 1.
- **Permutation**: A permutation of a set of n objects is an ordered arrangement of those objects. For example, the permutations of the set {a, b, c} are abc, acb, bac, bca, cab, and cba. The number of permutations of n objects is given by n!, that is, n factorial.
- **Combination**: A combination of a set of n objects is an unordered selection of k objects from that set, where k is less than or equal to n. For example, the combinations of the set {a, b, c} taken 2 at a time are ab, ac, and bc. The number of combinations of n objects taken k at a time is given by the binomial coefficient, denoted by (n k) or C(n, k), and defined as:

(n k) = C(n, k) = n! / (k! x (n - k)!)

- **Binomial theorem**: The binomial theorem is a formula that gives the expansion of a binomial expression raised to a positive integer power. For example, the binomial theorem states that:

(a + b)^n = (n 0) a^n + (n 1) a^(n-1) b + (n 2) a^(n-2) b^2 + ... + (n n) b^n

where (n k) are the binomial coefficients.

- **Probability**: Probability is the measure of how likely an event is to occur, given a sample space of all possible outcomes. Probability can be calculated using the formula:

P(event) = number of favorable outcomes / number of possible outcomes

For example, the probability of rolling a 6 on a fair die is 1/6, since there is one favorable outcome (6) out of six possible outcomes (1, 2, 3, 4, 5, 6).

- **Counting principles**: Counting principles are rules that help us count the number of possible outcomes in a situation involving multiple choices or stages. Some of the common counting principles are:

  - **Multiplication principle**: If there are m ways to do one thing and n ways to do another thing, then there are m x n ways to do both things.
  - **Addition principle**: If there are m ways to do one thing and n ways to do another thing, and these two things cannot be done at the same time, then there are m + n ways to do either one thing or the other thing.
  - **Inclusion-exclusion principle**: If there are m ways to do one thing and n ways to do another thing, and some of these ways overlap, then there are m + n - k ways to do either one thing or the other thing, where k is the number of ways that both things can be done at the same time.
