## Unit 4 - Propositional Logic

Propositional logic is a branch of logic that studies the ways of combining and modifying statements, called propositions, using logical connectives and operators. Propositional logic can be used to analyze and evaluate arguments based on their logical structure and validity.

Some of the main topics covered in this unit are:

- **Propositions and truth values**: A proposition is a declarative sentence that can be either true or false, but not both. The truth value of a proposition is the truth or falsity of the proposition. For example, "Sydney is an AI assistant" is a proposition with the truth value true.

- **Logical connectives and truth tables**: Logical connectives are symbols or words that are used to form compound propositions from simpler ones. The main logical connectives are: negation (¬), conjunction (∧), disjunction (∨), conditional (→), and biconditional (↔). Each logical connective has a corresponding truth table that shows how the truth value of the compound proposition depends on the truth values of its components. For example, the truth table for negation is:

| p | ¬p |
|---|----|
| T | F  |
| F | T  |

- **Logical equivalence and tautology**: Two propositions are logically equivalent if they have the same truth value in every possible situation. Logical equivalence can be tested using truth tables or logical laws. A tautology is a proposition that is always true, regardless of the truth values of its components. For example, p ∨ ¬p is a tautology.

- **Logical implication and contradiction**: A proposition p logically implies another proposition q if whenever p is true, q is also true. Logical implication can be tested using truth tables or logical laws. A contradiction is a proposition that is always false, regardless of the truth values of its components. For example, p ∧ ¬p is a contradiction.

- **Arguments and validity**: An argument is a sequence of propositions, where some of them are called premises and one of them is called the conclusion. The premises are intended to provide evidence or support for the conclusion. An argument is valid if it is impossible for the premises to be true and the conclusion to be false. Validity can be tested using truth tables or logical laws. For example, the following argument is valid:

p → q
p
∴ q

- **Normal forms and rules of inference**: A normal form is a standard way of writing a proposition using a specific set of logical connectives. There are different types of normal forms, such as conjunctive normal form (CNF), disjunctive normal form (DNF), and negation normal form (NNF). Normal forms can be useful for simplifying or transforming propositions. A rule of inference is a logical principle that allows us to derive a new proposition from one or more existing propositions. There are different types of rules of inference, such as modus ponens, modus tollens, and hypothetical syllogism. Rules of inference can be useful for constructing or evaluating arguments.
