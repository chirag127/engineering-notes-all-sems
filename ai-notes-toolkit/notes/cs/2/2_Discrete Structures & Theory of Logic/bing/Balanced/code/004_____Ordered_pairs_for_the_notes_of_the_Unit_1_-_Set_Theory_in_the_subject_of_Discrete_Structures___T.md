### Ordered pairs

- An ordered pair is a pair of elements that are arranged in a specific order.
- An ordered pair is written as (a, b), where a is the first element and b is the second element.
- The order of the elements matters, so (a, b) is not the same as (b, a) unless a = b.
- An ordered pair can be used to represent a relation between two sets, such as A and B.
- A relation is a set of ordered pairs, where the first element of each pair belongs to A and the second element belongs to B.
- A relation can be written as R = {(a, b) | a ∈ A and b ∈ B and some condition is satisfied}.
- For example, if A = {1, 2, 3} and B = {4, 5, 6}, then R = {(1, 4), (2, 5), (3, 6)} is a relation from A to B.
- A relation can also be represented by a table, a graph, or a mapping diagram.
- A table lists the ordered pairs in rows and columns, such as:

| a | b |
|---|---|
| 1 | 4 |
| 2 | 5 |
| 3 | 6 |
