### Proof by counter-example

- A proof by counter-example is a method of disproving a statement by showing that there exists a specific case where the statement is false.
- A counter-example is a specific instance of the general case that contradicts the statement.
- To prove by counter-example, we need to find one counter-example that makes the statement false. We do not need to check all possible cases.
- A proof by counter-example can only be used to disprove a universal statement, such as "for all x, P(x)" or "for every x, P(x)".
- A proof by counter-example cannot be used to prove an existential statement, such as "there exists x such that P(x)" or "some x satisfy P(x)".
- A proof by counter-example has the following form:

  - Statement: For all x, P(x)
  - Counter-example: Let x = c, where c is a specific value
  - Explanation: Show that P(c) is false
  - Conclusion: Therefore, the statement is false

- Here is an example of a proof by counter-example:

  - Statement: For all natural numbers n, n^2 + n + 41 is prime
  - Counter-example: Let n = 40
  - Explanation: n^2 + n + 41 = 40^2 + 40 + 41 = 1681, which is not prime (it is divisible by 41)
  - Conclusion: Therefore, the statement is false

- Here is another example of a proof by counter-example:

  - Statement: For every real number x, x^2 >= x
  - Counter-example: Let x = 0.5
  - Explanation: x^2 = 0.5^2 = 0.25, which is less than x = 0.5
  - Conclusion: Therefore, the statement is false

- A proof by counter-example can also be used to disprove a conditional statement, such as "if P, then Q". In this case, we need to find a counter-example where P is true and Q is false.
- A proof by counter-example for a conditional statement has the following form:

  - Statement: If P, then Q
  - Counter-example: Let x = c, where c is a specific value that makes P true and Q false
  - Explanation: Show that P(c) is true and Q(c) is false
  - Conclusion: Therefore, the statement is false

- Here is an example of a proof by counter-example for a conditional statement:

  - Statement: If x is an even integer, then x + 1 is odd
  - Counter-example: Let x = -2
  - Explanation: x is an even integer, but x + 1 = -1, which is not odd (it is negative)
  - Conclusion: Therefore, the statement is false

- Here is another example of a proof by counter-example for a conditional statement:

  - Statement: If x is a rational number, then x^2 is rational
  - Counter-example: Let x = sqrt(2)
  - Explanation: x is a rational number, but x^2 = 2, which is not rational (it is irrational)
  - Conclusion: Therefore, the statement is false

- A proof by counter-example can also be used to disprove a biconditional statement, such as "P if and only if Q". In this case, we need to find a counter-example where P and Q have different truth values, either P is true and Q is false, or P is false and Q is true.
- A proof by counter-example for a biconditional statement has the following form:

  - Statement: P if and only if Q
  - Counter-example: Let x = c, where c is a specific value that makes P and Q have different truth values
  - Explanation: Show that P(c) and Q(c) have different truth values
  - Conclusion: Therefore, the statement is false

- Here is an example of a proof by counter-example for a biconditional statement:

  - Statement: x is a multiple of 4 if and only if x is a multiple of 2
  - Counter-example: Let x = 6
  - Explanation: x is a multiple of 2, but not a multiple of 4
  - Conclusion: Therefore, the statement is false
