### Equality of relations

- A relation is a set of ordered pairs that represents a connection or association between two sets, called the domain and the codomain of the relation.
- Equality is a special kind of relation that compares two objects or sets and determines if they are the same or not.
- Two relations are equal if and only if they have the same domain, the same codomain, and the same set of ordered pairs.
- Equality of relations is an equivalence relation, meaning that it satisfies the following properties for any relations R, S, and T:
  - Reflexivity: R = R
  - Symmetry: If R = S, then S = R
  - Transitivity: If R = S and S = T, then R = T
- Equality of relations is also compatible with other operations on relations, such as union, intersection, composition, and inverse. That is, if R = S, then for any relation T, we have:
  - R ∪ T = S ∪ T
  - R ∩ T = S ∩ T
  - R ∘ T = S ∘ T
  - T ∘ R = T ∘ S
  - R⁻¹ = S⁻¹
