### Combination of sets

- A set is a collection of distinct objects, such as numbers, letters, symbols, etc.
- A set can be represented by listing its elements inside curly braces, such as {1, 2, 3} or {a, b, c}.
- A set can also be represented by using a rule that defines its elements, such as {x | x is an even integer} or {y | y is a vowel}.
- The order and repetition of elements do not matter in a set, such as {1, 2, 3} = {3, 1, 2} = {1, 1, 2, 3}.
- The cardinality of a set is the number of elements in the set, such as |{1, 2, 3}| = 3 or |{a, b, c}| = 3.
- The empty set is the set that has no elements, and is denoted by ∅ or {}.
- A subset of a set is a set that contains some or all of the elements of the original set, such as {1, 2} ⊆ {1, 2, 3} or {a, b} ⊆ {a, b, c}.
- A proper subset of a set is a subset that is not equal to the original set, such as {1, 2} ⊂ {1, 2, 3} or {a, b} ⊂ {a, b, c}.
- A universal set is a set that contains all the elements of interest in a given context, such as U = {1, 2, 3, 4, 5, 6} or U = {a, e, i, o, u}.
- A complement of a set is the set of all the elements in the universal set that are not in the original set, such as {1, 2, 3}' = {4, 5, 6} or {a, e, i}' = {o, u}.
- A union of two sets is the set of all the elements that are in either of the sets, such as {1, 2, 3} ∪ {4, 5, 6} = {1, 2, 3, 4, 5, 6} or {a, e, i} ∪ {o, u} = {a, e, i, o, u}.
- An intersection of two sets is the set of all the elements that are in both of the sets, such as {1, 2, 3} ∩ {2, 3, 4} = {2, 3} or {a, e, i} ∩ {e, i, o} = {e, i}.
- A difference of two sets is the set of all the elements that are in the first set but not in the second set, such as {1, 2, 3} - {2, 3, 4} = {1} or {a, e, i} - {e, i, o} = {a}.
