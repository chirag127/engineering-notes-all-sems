### Equality of relations

- A relation is a set of ordered pairs that represents a connection or association between two sets, called the domain and the codomain of the relation.
- Two relations R and S are said to be equal, denoted by R = S, if and only if they have the same domain, the same codomain, and the same set of ordered pairs.
- Formally, R = S if and only if dom(R) = dom(S), codom(R) = codom(S), and R = S as sets.
- For example, let A = {1, 2, 3} and B = {a, b, c}. Define R and S as follows:

R = {(1, a), (2, b), (3, c)}
S = {(x, y) | x ∈ A, y ∈ B, and x is the numerical equivalent of y}

- Then R and S are equal relations, because dom(R) = dom(S) = A, codom(R) = codom(S) = B, and R = S as sets.
- Note that the definition of equality of relations does not depend on how the relations are defined or represented, but only on their domain, codomain, and set of ordered pairs.
