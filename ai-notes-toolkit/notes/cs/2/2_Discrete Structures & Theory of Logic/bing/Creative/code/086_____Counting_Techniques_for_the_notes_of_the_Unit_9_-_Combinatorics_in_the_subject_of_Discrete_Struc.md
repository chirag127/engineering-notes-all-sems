### Counting Techniques for the notes of the Unit 9 - Combinatorics in the subject of Discrete Structures & Theory of Logic

Combinatorics is the branch of mathematics that deals with the study of finite or countable discrete structures. It includes the enumeration or counting of objects having certain properties. Combinatorics methods can be used to develop estimates about how many operations a computer algorithm will require, and to count possible outcomes in a uniform probability experiment.

Some basic counting techniques are:

- **The rule of products**: If there are $n_1$ ways to do task 1, and $n_2$ ways to do task 2, and so on, then there are $n_1 \times n_2 \times \cdots \times n_k$ ways to do the tasks in sequence. For example, if there are 10 shirts and 8 pants to choose from, then there are $10 \times 8 = 80$ ways to choose an outfit.
- **The rule of sums**: If there are $n_1$ ways to do task 1, and $n_2$ ways to do task 2, and so on, and the tasks are mutually exclusive, then there are $n_1 + n_2 + \cdots + n_k$ ways to do one of the tasks. For example, if there are 5 red balls and 7 blue balls in a box, then there are $5 + 7 = 12$ ways to pick one ball from the box.
- **Factorials**: The number of ways to arrange $n$ distinct objects in a row is $n! = n \times (n-1) \times \cdots \times 2 \times 1$. For example, the number of ways to arrange 5 books on a shelf is $5! = 120$.
- **Permutations**: The number of ways to choose and arrange $r$ objects from a set of $n$ distinct objects is $P(n,r) = n!/(n-r)!$. For example, the number of ways to choose and arrange 3 letters from the word "COMBINATORICS" is $P(13,3) = 13!/(13-3)! = 1716$.
- **Combinations**: The number of ways to choose $r$ objects from a set of $n$ distinct objects, without regard to order, is $C(n,r) = n!/(r!(n-r)!)$. This is also denoted by ${n \choose r}$. For example, the number of ways to choose 3 letters from the word "COMBINATORICS", without regard to order, is $C(13,3) = 13!/(3!(13-3)!) = 286$.
- **Binomial coefficients**: The coefficients of the binomial expansion $(x+y)^n$ are given by ${n \choose r}$, where $r$ ranges from $0$ to $n$. For example, $(x+y)^3 = {3 \choose 0}x^3 + {3 \choose 1}x^2y + {3 \choose 2}xy^2 + {3 \choose 3}y^3$. Binomial coefficients satisfy many identities, such as ${n \choose r} = {n \choose n-r}$ and ${n \choose r} = {n-1 \choose r-1} + {n-1 \choose r}$.
- **Generalized permutations and combinations**: When the objects are not distinct, or when there are repetitions or restrictions, the counting techniques can be generalized by using the principle of inclusion-exclusion, the stars and bars method, or the multinomial theorem. For example, the number of ways to arrange the letters of the word "MISSISSIPPI" is ${11 \choose 4,4,2,1} = \frac{11!}{4!4!2!1!} = 34650$, where ${n \choose k_1,k_2,\ldots,k_m}$ denotes the multinomial coefficient.
