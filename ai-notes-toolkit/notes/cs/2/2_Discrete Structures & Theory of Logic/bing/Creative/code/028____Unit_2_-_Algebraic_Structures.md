## Unit 2 - Algebraic Structures

An algebraic structure is a set of elements with one or more operations defined on it that satisfy certain properties or axioms. Some examples of algebraic structures are groups, rings, fields, vector spaces, matrices, etc.

In this unit, we will learn about the following topics:

- **Binary operations**: A binary operation is a function that takes two elements from a set and returns another element from the same set. For example, addition and multiplication are binary operations on the set of real numbers. We will learn how to define and classify binary operations based on their properties, such as commutativity, associativity, identity, inverse, etc.

- **Groups**: A group is an algebraic structure that consists of a set and a binary operation that satisfies four properties: closure, associativity, identity, and inverse. For example, the set of integers with addition is a group. We will learn how to identify and construct groups, and how to prove that a given structure is a group or not. We will also learn about some special types of groups, such as abelian groups, cyclic groups, permutation groups, etc.

- **Subgroups**: A subgroup is a subset of a group that is also a group under the same operation. For example, the set of even integers is a subgroup of the group of integers with addition. We will learn how to find and test subgroups, and how to use some criteria, such as Lagrange's theorem, to determine the order and structure of subgroups.

- **Homomorphisms and isomorphisms**: A homomorphism is a function that preserves the structure of a group, i.e., it maps elements from one group to another group such that the operation is preserved. For example, the function that maps an integer to its remainder modulo n is a homomorphism from the group of integers with addition to the group of integers modulo n with addition. An isomorphism is a bijective homomorphism, i.e., it is a one-to-one and onto function that preserves the structure of a group. For example, the function that maps an integer to its negative is an isomorphism from the group of integers with addition to itself. We will learn how to define and identify homomorphisms and isomorphisms, and how to use them to compare and classify groups.

- **Rings and fields**: A ring is an algebraic structure that consists of a set and two binary operations, usually called addition and multiplication, that satisfy certain properties, such as closure, associativity, commutativity, distributivity, identity, etc. For example, the set of integers with addition and multiplication is a ring. A field is a ring that also satisfies the properties of inverse and commutativity for both operations. For example, the set of rational numbers with addition and multiplication is a field. We will learn how to define and construct rings and fields, and how to prove that a given structure is a ring or a field or not. We will also learn about some special types of rings and fields, such as integral domains, zero-divisor-free rings, Euclidean domains, etc.

- **Polynomials**: A polynomial is an expression that consists of variables and coefficients, and involves only the operations of addition, subtraction, multiplication, and non-negative integer exponents. For example, x^2 + 3x - 5 is a polynomial. We will learn how to define and manipulate polynomials, and how to use them to construct rings and fields. We will also learn how to perform arithmetic operations on polynomials, such as addition, subtraction, multiplication, division, and remainder. We will also learn how to find the degree, leading coefficient, roots, and factors of a polynomial.

- **Vector spaces and matrices**: A vector space is an algebraic structure that consists of a set of vectors and two operations, usually called vector addition and scalar multiplication, that satisfy certain properties, such as closure, associativity, commutativity, distributivity, identity, inverse, etc. For example, the set of n-tuples of real numbers with component-wise addition and multiplication by a real number is a vector space. A matrix is a rectangular array of numbers, symbols, or expressions, arranged in rows and columns. For example, [[1, 2], [3, 4]] is a 2x2 matrix.
