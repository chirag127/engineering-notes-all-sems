# Boolean Algebra

- Boolean algebra is a branch of mathematics that deals with operations on logical values with binary variables  .
- The Boolean variables are represented as binary numbers to represent truths: 1 = true and 0 = false .
- The basic operations of Boolean algebra are the logical operations AND, OR and NOT .
- Boolean algebra traces its origins to an 1854 book by mathematician George Boole .
- Boolean algebra is used to simplify and analyze the logic of digital circuits, such as logic gates, flip-flops, multiplexers, etc .
- Boolean algebra can also be defined abstractly as any set with binary operations ∧ and ∨ and a unary operation ¬ thereon satisfying the Boolean laws .
- The Boolean laws are the axioms and rules of inference that govern the manipulation of Boolean expressions .
- Some of the common Boolean laws are:

  - Commutative laws: A ∧ B = B ∧ A and A ∨ B = B ∨ A
  - Associative laws: (A ∧ B) ∧ C = A ∧ (B ∧ C) and (A ∨ B) ∨ C = A ∨ (B ∨ C)
  - Distributive laws: A ∧ (B ∨ C) = (A ∧ B) ∨ (A ∧ C) and A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C)
  - Identity laws: A ∧ 1 = A and A ∨ 0 = A
  - Complement laws: A ∧ ¬A = 0 and A ∨ ¬A = 1
  - Idempotent laws: A ∧ A = A and A ∨ A = A
  - De Morgan's laws: ¬(A ∧ B) = ¬A ∨ ¬B and ¬(A ∨ B) = ¬A ∧ ¬B
  - Absorption laws: A ∧ (A ∨ B) = A and A ∨ (A ∧ B) = A
  - Involution law: ¬(¬A) = A

- A Boolean function is a function that takes one or more Boolean variables as inputs and produces a single Boolean output .
- A Boolean function can be represented in various ways, such as a truth table, a Boolean expression, a logic diagram, etc .
- A Boolean expression is a combination of Boolean variables and operators that evaluates to a Boolean value .
- A Boolean expression can be simplified using the Boolean laws and algebraic manipulation .
- A Boolean expression can also be converted into different forms, such as the canonical form, the standard form, the sum-of-products form, the product-of-sums form, etc .
- A logic diagram is a graphical representation of a Boolean function using symbols for the variables and operators .
- A logic diagram can be simplified using the rules of logic gates, such as the elimination of redundant gates, the combination of parallel or series gates, the application of De Morgan's laws, etc .
- A logic diagram can also be converted into different forms, such as the NAND form, the NOR form, the XOR form, etc .
