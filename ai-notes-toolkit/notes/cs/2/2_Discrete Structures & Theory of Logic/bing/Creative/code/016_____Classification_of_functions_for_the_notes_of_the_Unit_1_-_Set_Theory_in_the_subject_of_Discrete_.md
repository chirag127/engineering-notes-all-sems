### Classification of functions

A function is a relation between two sets that assigns exactly one element of the second set to each element of the first set. The first set is called the domain and the second set is called the codomain. The set of all elements that are assigned by the function is called the range.

There are different ways to classify functions based on their properties. Some of the common classifications are:

- **One-to-one function**: A function is one-to-one if it assigns different elements of the codomain to different elements of the domain. In other words, no two distinct elements of the domain have the same image in the codomain. A one-to-one function is also called an injective function.

- **Onto function**: A function is onto if it assigns every element of the codomain to some element of the domain. In other words, the range of the function is equal to the codomain. An onto function is also called a surjective function.

- **One-to-one and onto function**: A function is one-to-one and onto if it is both one-to-one and onto. Such a function is also called a bijective function or a bijection. A bijective function has a unique inverse function that maps the codomain back to the domain.

- **Constant function**: A function is constant if it assigns the same element of the codomain to every element of the domain. The range of a constant function consists of a single element.

- **Identity function**: A function is identity if it assigns every element of the domain to itself. The domain and the codomain of an identity function are the same set. The identity function is a bijective function.

- **Linear function**: A function is linear if it can be expressed as f(x) = ax + b, where a and b are constants and a is not zero. A linear function has a constant rate of change and forms a straight line when graphed.

- **Quadratic function**: A function is quadratic if it can be expressed as f(x) = ax^2 + bx + c, where a, b and c are constants and a is not zero. A quadratic function has a variable rate of change and forms a parabola when graphed.

- **Polynomial function**: A function is polynomial if it can be expressed as f(x) = a_n x^n + a_(n-1) x^(n-1) + ... + a_1 x + a_0, where a_n, a_(n-1), ..., a_1, a_0 are constants and a_n is not zero. A polynomial function is a sum of terms, each of which is a constant multiplied by a power of x. The highest power of x in the function is called the degree of the polynomial.

- **Rational function**: A function is rational if it can be expressed as f(x) = p(x) / q(x), where p(x) and q(x) are polynomial functions and q(x) is not zero. A rational function is a ratio of two polynomial functions.

- **Exponential function**: A function is exponential if it can be expressed as f(x) = a^x, where a is a constant and a is not zero or one. An exponential function has a constant base and a variable exponent. It models phenomena that grow or decay exponentially, such as population, bacteria, radioactive decay, etc.

- **Logarithmic function**: A function is logarithmic if it can be expressed as f(x) = log_a x, where a is a constant and a is greater than zero and not equal to one. A logarithmic function is the inverse of an exponential function. It models phenomena that grow or decay logarithmically, such as sound intensity, pH, Richter scale, etc.

- **Trigonometric function**: A function is trigonometric if it can be expressed as f(x) = sin x, cos x, tan x, csc x, sec x, cot x, or any combination of these. A trigonometric function relates the angles and sides of a right triangle. It also models periodic phenomena, such as waves, cycles, oscillations, etc.
