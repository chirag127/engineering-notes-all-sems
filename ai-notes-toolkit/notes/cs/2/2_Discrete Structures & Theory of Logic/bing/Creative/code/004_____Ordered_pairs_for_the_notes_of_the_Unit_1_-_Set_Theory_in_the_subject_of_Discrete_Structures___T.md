### Ordered pairs for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

- An ordered pair is a pair of two objects that are written inside parentheses and separated by a comma, such as (a, b).
- The order of the objects in an ordered pair is significant, meaning that (a, b) is different from (b, a) unless a = b.
- An ordered pair can represent a point on a coordinate plane, where the first object is the x-coordinate and the second object is the y-coordinate, such as (3, 4).
- An ordered pair can also represent an element of a relation or a cartesian product, where the first object is from one set and the second object is from another set, such as (red, circle).
- The set of all possible ordered pairs of two sets A and B is called the cartesian product of A and B, and is denoted by A × B.
- A relation is a subset of a cartesian product, meaning that it is a set of ordered pairs that satisfy some property or rule, such as R = {(a, b) | a < b}.
- A function is a special type of relation, where each element of the first set is paired with exactly one element of the second set, such as f = {(x, y) | y = 2x + 1}.
- An ordered pair can be represented graphically by a dot or an arrow on a coordinate plane, or by a table or a mapping diagram that shows the correspondence between the objects.
