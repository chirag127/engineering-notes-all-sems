# Recursive algorithms for the notes of the Unit 8 - Recurrence Relation & Generating function in the subject of Discrete Structures & Theory of Logic

- A recursive algorithm is an algorithm that solves a problem by calling itself on smaller instances of the same problem until a base case is reached .
- A base case is a simple case that can be solved directly without recursion .
- A recursive step is a rule that reduces the problem to one or more smaller subproblems of the same kind .
- A recursive algorithm must have at least one base case and at least one recursive step .
- A recursive algorithm can be implemented using a function or a procedure that calls itself.
- A recursive algorithm can be more elegant and concise than an iterative algorithm, but it may also be less efficient or more difficult to understand.
- A recursive algorithm can be analyzed using recurrence relations, which are equations that express the running time or the number of operations of the algorithm as a function of the input size.
- A recurrence relation can be solved using various methods, such as substitution, iteration, master theorem, or generating functions.
- A generating function is a function that encodes a sequence of numbers as the coefficients of a power series.
- A generating function can be used to find closed-form solutions, asymptotic behavior, or combinatorial properties of a recurrence relation.
