### Complemented for the notes of the Unit 3 - Lattices in the subject of Discrete Structures & Theory of Logic

- A **lattice** is a partially ordered set (poset) in which every pair of elements has a unique least upper bound (lub) and a unique greatest lower bound (glb).
- A **bounded lattice** is a lattice that has a minimum element (denoted by 0) and a maximum element (denoted by 1).
- A **complemented lattice** is a bounded lattice in which every element has a **complement**, that is, an element such that their lub is 1 and their glb is 0.
- A **distributive lattice** is a lattice that satisfies the **distributive laws**, that is, for any elements x, y, and z in the lattice, x ∧ (y ∨ z) = (x ∧ y) ∨ (x ∧ z) and x ∨ (y ∧ z) = (x ∨ y) ∧ (x ∨ z), where ∧ denotes the glb and ∨ denotes the lub.
- A **Boolean algebra** is a distributive complemented lattice. It is also called a **Boolean lattice**.
- A **sublattice** of a lattice L is a subset of L that is also a lattice under the same partial order.
- A **homomorphism** between two lattices L and M is a function f: L → M that preserves the lub and glb operations, that is, for any elements x and y in L, f(x ∨ y) = f(x) ∨ f(y) and f(x ∧ y) = f(x) ∧ f(y).
- An **isomorphism** between two lattices L and M is a bijective homomorphism f: L → M that has an inverse homomorphism f^-1: M → L.
- Two lattices L and M are **isomorphic** if there exists an isomorphism between them. Isomorphism is an equivalence relation on the class of all lattices.
- A **lattice diagram** is a graphical representation of a lattice, in which the elements are represented by points and the partial order is represented by lines connecting the points, such that if x ≤ y, then x is below y and there is no element z between x and y such that x ≤ z ≤ y.
- A **Hasse diagram** is a simplified lattice diagram, in which the lines are drawn only for the **cover relations**, that is, the pairs of elements x and y such that x < y and there is no element z between x and y such that x < z < y. A Hasse diagram can be obtained from a lattice diagram by removing the transitive and reflexive edges.
- A **chain** in a poset is a subset of elements that are totally ordered, that is, for any two elements x and y in the chain, either x ≤ y or y ≤ x.
- An **antichain** in a poset is a subset of elements that are incomparable, that is, for any two elements x and y in the antichain, neither x ≤ y nor y ≤ x.
- The **height** of a poset is the length of the longest chain in the poset, where the length of a chain is the number of elements in the chain minus one.
- The **width** of a poset is the size of the largest antichain in the poset, where the size of an antichain is the number of elements in the antichain.
- A **graded poset** is a poset in which every element has a **rank**, that is, a nonnegative integer that measures its distance from the minimum element, such that if x < y, then the rank of x is strictly less than the rank of y, and if x covers y, then the rank of x is one more than the rank of y.
- A **modular lattice** is a lattice that satisfies the **modular law**, that is, for any elements x, y, and z in the lattice, if x ≤ z, then x ∨ (y ∧ z) = (x ∨ y) ∧ z.
- A **semimodular lattice** is a lattice that satisfies the **weaker modular law**, that is, for any elements x, y, and z in the lattice, if x covers z, then x ∨ (y ∧ z) = (x ∨ y) ∧ z.
