### Linear Bounded Automata

Linear Bounded Automata (LBA) is a type of non-deterministic Turing machine that operates on an input string of a finite length. It is a restricted form of Turing machine where the tape head is not allowed to move off the portion of the tape containing the input. The tape head can only move within the bounds of the input string, hence the name "Linear Bounded".

Some key points to remember about Linear Bounded Automata are:

1. LBA is a type of non-deterministic Turing machine.
2. It operates on an input string of a finite length.
3. The tape head is not allowed to move off the portion of the tape containing the input.
4. The tape head can only move within the bounds of the input string.
5. LBA is a restricted form of Turing machine.

Linear Bounded Automata is an important concept in the study of Turing Machines and Recursive Function Theory, as it provides a way to model computation with limited resources. It is also used in the study of formal languages, as it can be used to recognize context-sensitive languages.
