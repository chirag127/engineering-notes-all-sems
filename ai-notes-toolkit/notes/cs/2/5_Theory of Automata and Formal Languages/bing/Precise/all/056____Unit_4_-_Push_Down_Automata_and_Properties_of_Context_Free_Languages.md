## Unit 4 - Push Down Automata and Properties of Context Free Languages

1. **Push Down Automata (PDA)** is a type of automaton that is used to recognize context-free languages. It is an extension of the finite automaton with an additional stack data structure.
2. A PDA is defined by a 7-tuple (Q, Σ, Γ, δ, q0, Z, F) where:
    - Q is a finite set of states
    - Σ is the input alphabet
    - Γ is the stack alphabet
    - δ is the transition function
    - q0 is the initial state
    - Z is the initial stack symbol
    - F is the set of final states
3. There are two types of PDA: deterministic and non-deterministic. A deterministic PDA has at most one transition for each combination of state, input symbol, and stack symbol, while a non-deterministic PDA can have multiple transitions for the same combination.
4. Context-free languages are a subset of formal languages that can be generated by a context-free grammar. They have the property of being closed under union, concatenation, and Kleene star operations.
5. The pumping lemma for context-free languages states that for any context-free language L, there exists a constant n such that for any string w in L with length greater than or equal to n, w can be divided into 5 substrings w = uvxyz such that:
    - |vy| > 0
    - |vxy| ≤ n
    - uv^ixy^iz is in L for all i ≥ 0
6. The Chomsky normal form is a normal form for context-free grammars in which every production rule is of the form A → BC or A → a, where A, B, and C are non-terminal symbols and a is a terminal symbol.
7. The Greibach normal form is another normal form for context-free grammars in which every production rule is of the form A → aB1B2...Bk, where A and Bi are non-terminal symbols and a is a terminal symbol.
8. The CYK algorithm is an algorithm for parsing context-free languages in Chomsky normal form. It uses dynamic programming to determine whether a given string can be generated by a given context-free grammar.
