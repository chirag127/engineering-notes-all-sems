## Unit 2 - Regular Expressions and Languages

1. **Regular Expressions:** A regular expression is a pattern that describes a set of strings. It is a way to describe and parse text. Regular expressions are used in many programming languages, text editors, and other tools to search and manipulate text.

2. **Regular Language:** A regular language is a formal language that can be expressed using a regular expression. It is a subset of the set of all possible strings over a given alphabet.

3. **Finite Automata:** A finite automaton is a mathematical model used to recognize regular languages. It consists of a finite set of states, a set of input symbols, a transition function, an initial state, and a set of accepting states.

4. **Deterministic Finite Automata (DFA):** A deterministic finite automaton is a type of finite automaton where for each state and input symbol, there is exactly one transition to a next state.

5. **Nondeterministic Finite Automata (NFA):** A nondeterministic finite automaton is a type of finite automaton where for each state and input symbol, there can be multiple transitions to next states.

6. **Conversion of NFA to DFA:** An NFA can be converted to an equivalent DFA using the subset construction algorithm.

7. **Regular Grammar:** A regular grammar is a type of formal grammar that generates a regular language. It consists of a finite set of production rules, where each rule has the form A -> aB or A -> a, where A and B are non-terminal symbols and a is a terminal symbol.

8. **Closure Properties of Regular Languages:** Regular languages are closed under union, intersection, complement, concatenation, and Kleene star operations.

9. **Pumping Lemma for Regular Languages:** The pumping lemma for regular languages is a property that can be used to prove that a language is not regular.

10. **Applications of Regular Expressions and Languages:** Regular expressions and languages have many applications in computer science, including text processing, lexical analysis, and pattern matching. They are also used in the design of compilers and other language processing tools.
