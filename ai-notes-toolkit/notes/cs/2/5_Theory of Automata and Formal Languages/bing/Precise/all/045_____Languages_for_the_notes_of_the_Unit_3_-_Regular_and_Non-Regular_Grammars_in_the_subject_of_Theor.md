# Unit 3 - Regular and Non-Regular Grammars

### Languages

- A language is a set of strings of symbols that may be constructed according to certain rules.
- In the context of formal languages, a string is a finite sequence of symbols taken from a finite alphabet.
- An alphabet is a non-empty, finite set of symbols.
- A language can be defined by a grammar, which is a set of rules for constructing strings in the language.
- A regular grammar is a type of formal grammar that can generate regular languages.
- Regular languages are a subset of the set of all possible languages.
- Non-regular grammars can generate languages that are not regular.
- The study of formal languages and grammars is important in the field of computer science, particularly in the areas of automata theory, compiler design, and natural language processing.
