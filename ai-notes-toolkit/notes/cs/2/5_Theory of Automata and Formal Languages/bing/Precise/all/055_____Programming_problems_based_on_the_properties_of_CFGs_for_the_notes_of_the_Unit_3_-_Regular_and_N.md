# Programming problems based on the properties of CFGs

Context-free grammars (CFGs) are a type of formal grammar used to generate strings in a language. They are commonly used in computer science, particularly in the field of compiler design and natural language processing. Here are some programming problems based on the properties of CFGs:

1. **Parsing:** Given a string and a CFG, write a program to determine if the string can be generated by the CFG. This problem can be solved using various parsing algorithms such as the Earley parser, the CYK parser, or the LL parser.

2. **Ambiguity:** Given a CFG, write a program to determine if the grammar is ambiguous. A grammar is ambiguous if there exists a string that can be generated by the grammar in more than one way. This problem is undecidable in general, but there are heuristics that can be used to detect ambiguity in some cases.

3. **Chomsky Normal Form:** Given a CFG, write a program to convert the grammar into Chomsky Normal Form (CNF). CNF is a restricted form of CFG where all production rules are of the form A -> BC or A -> a, where A, B, and C are non-terminal symbols and a is a terminal symbol. This form is useful for certain parsing algorithms and for proving properties of CFGs.

4. **CYK Algorithm:** Given a string and a CFG in CNF, write a program to determine if the string can be generated by the CFG using the CYK algorithm. The CYK algorithm is a dynamic programming algorithm that can be used to parse strings in O(n^3) time, where n is the length of the string.

5. **Greibach Normal Form:** Given a CFG, write a program to convert the grammar into Greibach Normal Form (GNF). GNF is a restricted form of CFG where all production rules are of the form A -> aB1B2...Bk, where A and Bi are non-terminal symbols and a is a terminal symbol. This form is useful for certain parsing algorithms and for proving properties of CFGs.

These are some of the programming problems that can be solved based on the properties of CFGs. These problems can be useful for understanding the properties of CFGs and for developing skills in parsing and compiler design.
