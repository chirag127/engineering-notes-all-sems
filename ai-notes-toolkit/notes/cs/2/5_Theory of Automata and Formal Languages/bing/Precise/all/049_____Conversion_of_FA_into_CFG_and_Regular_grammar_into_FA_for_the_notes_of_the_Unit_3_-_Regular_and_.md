# Conversion of FA into CFG and Regular grammar into FA

## Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

1. **Finite Automata (FA)** is a mathematical model of computation that is used to recognize patterns within input taken from some character set (or alphabet).
2. **Context-Free Grammar (CFG)** is a formal grammar that describes a set of strings that can be generated by a set of production rules.
3. **Regular Grammar** is a type of formal grammar that is used to generate regular languages, which are a subset of context-free languages.
4. **Conversion of FA into CFG**: To convert a FA into a CFG, we can create a production rule for each transition in the FA. The non-terminal symbol on the left side of the production rule represents the current state of the FA, and the terminal symbol on the right side represents the input symbol that causes the transition. The non-terminal symbol following the terminal symbol represents the next state of the FA after the transition.
5. **Conversion of Regular Grammar into FA**: To convert a regular grammar into a FA, we can create a state for each non-terminal symbol in the grammar. The start state of the FA corresponds to the start symbol of the grammar. The transitions in the FA are created based on the production rules of the grammar. If a production rule has the form `A -> aB`, where `A` and `B` are non-terminal symbols and `a` is a terminal symbol, then we create a transition from the state corresponding to `A` to the state corresponding to `B` with the input symbol `a`. The accepting states of the FA correspond to the non-terminal symbols that have production rules of the form `A -> ε`, where `ε` represents the empty string.
