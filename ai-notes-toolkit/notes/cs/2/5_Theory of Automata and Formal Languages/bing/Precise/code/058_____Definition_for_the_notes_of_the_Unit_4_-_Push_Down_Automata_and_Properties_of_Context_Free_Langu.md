### Definition for the notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

- **Pushdown Automata (PDA)** is a type of automaton that is used to recognize context-free languages. It is an extension of the finite automaton with an additional stack memory.
- A PDA is defined by a 7-tuple (Q, Σ, Γ, δ, q0, Z, F) where:
    - Q is a finite set of states
    - Σ is a finite input alphabet
    - Γ is a finite stack alphabet
    - δ is a transition function: Q × (Σ ∪ {ε}) × Γ → P(Q × Γ*)
    - q0 ∈ Q is the initial state
    - Z ∈ Γ is the initial stack symbol
    - F ⊆ Q is the set of accepting states
- **Context-free languages (CFLs)** are a type of formal language that can be generated by a context-free grammar. They are a strict superset of regular languages and a strict subset of context-sensitive languages.
- Some properties of context-free languages include:
    - Closure under union, concatenation, and Kleene star
    - Closure under reversal
    - Closure under homomorphism and inverse homomorphism
    - Not closed under intersection or complement
    - Decidable emptiness, finiteness, and membership problems
    - Undecidable equivalence and inclusion problems
- The **pumping lemma for context-free languages** is a property that can be used to prove that a language is not context-free. It states that for any context-free language L, there exists a constant n such that for any string w ∈ L with |w| ≥ n, w can be written as w = xyz such that |xy| ≤ n, |y| ≥ 1, and for all i ≥ 0, xyiz ∈ L.
