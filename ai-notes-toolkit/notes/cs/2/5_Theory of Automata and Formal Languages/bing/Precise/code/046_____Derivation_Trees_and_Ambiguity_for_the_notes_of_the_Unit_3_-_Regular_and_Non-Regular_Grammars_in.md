### Derivation Trees and Ambiguity

- A derivation tree is a graphical representation of a derivation of a string from a grammar.
- It is a tree structure where the root node is the start symbol of the grammar and the leaf nodes are the terminals of the grammar.
- Each internal node of the tree represents a non-terminal symbol and the children of the node represent the right-hand side of a production rule applied to the non-terminal symbol.
- A string is derived from a grammar by starting with the start symbol and repeatedly applying production rules until only terminal symbols remain.
- A derivation tree shows the sequence of production rules applied to derive a string from the grammar.
- Ambiguity in a grammar means that there is more than one derivation tree for the same string.
- An ambiguous grammar can generate the same string in multiple ways, leading to multiple parse trees for the same string.
- Ambiguity can make it difficult to determine the intended meaning of a string generated by the grammar.
- To resolve ambiguity, the grammar can be modified to eliminate the ambiguity or a disambiguation method can be used to select the intended parse tree.
