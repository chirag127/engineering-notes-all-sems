### Unit 3 - Regular and Non-Regular Grammars

#### Languages

- A language is a set of strings over an alphabet.
- An alphabet is a finite set of symbols.
- A string is a finite sequence of symbols from an alphabet.
- The empty string is denoted by ε and is a string of length 0.
- The set of all strings over an alphabet Σ is denoted by Σ*.
- A language can be finite or infinite.
- A language can be described by a grammar, which is a set of rules for generating strings in the language.
- A regular grammar is a type of grammar that can generate regular languages.
- A non-regular grammar is a type of grammar that can generate non-regular languages.
- Regular languages are a subset of context-free languages, which are a subset of context-sensitive languages, which are a subset of recursively enumerable languages.
- The Chomsky hierarchy classifies languages and grammars into four types: Type-0 (recursively enumerable), Type-1 (context-sensitive), Type-2 (context-free), and Type-3 (regular).
- Regular languages can be recognized by finite automata, while non-regular languages cannot be recognized by finite automata.
