### Definition for the notes of the Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

- **Regular Grammar**: A regular grammar is a formal grammar that is right-linear or left-linear. In a right-linear grammar, the right-hand side of each production rule consists of a string of terminals followed by at most one non-terminal. In a left-linear grammar, the right-hand side of each production rule consists of at most one non-terminal followed by a string of terminals.

- **Non-Regular Grammar**: A non-regular grammar is a formal grammar that is not regular. It can generate a language that cannot be generated by a regular grammar. Non-regular grammars can have production rules with more than one non-terminal on the right-hand side, or with non-terminals in arbitrary positions on the right-hand side.

- **Formal Grammar**: A formal grammar is a set of production rules that define a formal language. It consists of a set of non-terminal symbols, a set of terminal symbols, a start symbol, and a set of production rules. The production rules specify how the non-terminal symbols can be transformed into strings of terminal and non-terminal symbols.

- **Formal Language**: A formal language is a set of strings of symbols that are generated by a formal grammar. The symbols in the strings are taken from a finite alphabet of terminal symbols. The strings in a formal language can be of any length, including zero.
