### Derivations for the notes of the Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

1. A **regular grammar** is a formal grammar that is right-linear or left-linear. In other words, all production rules in a regular grammar have either the form `A -> aB` or `A -> Ba`, where `A` and `B` are non-terminal symbols and `a` is a terminal symbol.
2. A **non-regular grammar** is a formal grammar that is not regular. This means that it contains production rules that do not have the form `A -> aB` or `A -> Ba`.
3. A **regular language** is a formal language that can be generated by a regular grammar. This means that all strings in the language can be derived using the production rules of the regular grammar.
4. A **non-regular language** is a formal language that cannot be generated by a regular grammar. This means that there are strings in the language that cannot be derived using the production rules of any regular grammar.
5. The **Chomsky hierarchy** is a classification of formal languages based on their generative power. Regular languages are the least powerful, followed by context-free languages, context-sensitive languages, and recursively enumerable languages.
6. The **Pumping Lemma for regular languages** is a tool used to prove that a language is not regular. It states that for any regular language, there exists a constant `p` such that any string in the language of length at least `p` can be divided into three parts `xyz` such that `|xy| <= p`, `|y| >= 1`, and `xy^iz` is in the language for all `i >= 0`.
7. A **finite automaton** is a computational model used to recognize regular languages. It consists of a finite set of states, an input alphabet, a transition function, an initial state, and a set of accepting states.
8. A **deterministic finite automaton (DFA)** is a finite automaton where, for each state and input symbol, there is exactly one transition to a next state.
9. A **nondeterministic finite automaton (NFA)** is a finite automaton where, for each state and input symbol, there can be multiple transitions to next states.
10. The **powerset construction** is an algorithm used to convert an NFA into an equivalent DFA. It constructs a new DFA where each state represents a set of states in the NFA, and the transitions are defined based on the transitions in the NFA.
