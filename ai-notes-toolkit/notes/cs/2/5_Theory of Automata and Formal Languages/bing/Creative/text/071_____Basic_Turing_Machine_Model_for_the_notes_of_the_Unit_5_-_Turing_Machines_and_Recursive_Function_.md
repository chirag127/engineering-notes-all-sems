### Basic Turing Machine Model

- A Turing machine is a mathematical model of computation describing an abstract machine that manipulates symbols on a strip of tape according to a table of rules.
- It was invented in 1936 by Alan Turing, a British mathematician and logician, to investigate the extent and limitations of what can be computed.
- A Turing machine can accept the languages (recursively enumerable set) generated by type 0 grammars, which are the most general and powerful type of grammars in the Chomsky hierarchy.
- A basic Turing machine consists of the following components :
  - An infinite tape divided into cells, each cell containing one symbol from a finite alphabet. The tape serves as the input, output and working memory of the machine.
  - A tape head that can read and write symbols on the tape and move one cell to the left or right at a time.
  - A finite set of states, one of which is designated as the initial state and some of which are designated as the final or accepting states.
  - A transition function that specifies, for each state and tape symbol, what the machine should do next: write a new symbol, move the head, and change the state.
- A Turing machine operates as follows :
  - The machine starts in the initial state with the input string placed on the tape and the head positioned on the leftmost symbol of the input.
  - The machine reads the current symbol on the tape and consults the transition function to determine what to do next.
  - The machine performs the actions specified by the transition function: writing a new symbol on the tape, moving the head one cell to the left or right, and changing the state.
  - The machine repeats steps 2 and 3 until it reaches a final state or a configuration that has no defined transition.
  - The machine accepts the input if it halts in a final state, and rejects the input otherwise.
- A Turing machine can be represented by a diagram, a table, or a formal notation .
- A Turing machine can simulate any other Turing machine, and thus any other model of computation, such as a finite automaton, a pushdown automaton, or a lambda calculus .
- A Turing machine can perform any computation that is possible by a human with a pencil and paper, given enough time and space .
- A Turing machine can also perform computations that are not possible by a human, such as deciding the halting problem, which is the problem of determining whether a given Turing machine will halt on a given input .
- A Turing machine is a powerful and elegant model of computation, but it is also an idealized and unrealistic one, as it assumes an infinite tape, unlimited time, and perfect reliability .
