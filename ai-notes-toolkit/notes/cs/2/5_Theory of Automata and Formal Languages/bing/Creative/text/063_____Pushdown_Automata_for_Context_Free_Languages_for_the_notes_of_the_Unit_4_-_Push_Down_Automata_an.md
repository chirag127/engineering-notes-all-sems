### Pushdown Automata for Context Free Languages

- A **pushdown automaton** (PDA) is a finite automaton with an additional component called a **stack**, which is a data structure that allows operations of pushing (adding) and popping (removing) symbols at one end .
- A PDA can use the stack to store and retrieve information that is needed to process the input symbols. The stack can also be used to keep track of the current state of the computation.
- A PDA can be either **deterministic** or **nondeterministic**, depending on whether there is at most one possible transition for each input symbol and stack symbol, or there may be more than one.
- A PDA can be formally defined as a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F), where:
  - Q is a finite set of states
  - Σ is a finite set of input symbols
  - Γ is a finite set of stack symbols
  - δ is a transition function that maps Q × (Σ ∪ {ε}) × Γ to a subset of Q × Γ*
  - q0 is the initial state
  - Z0 is the initial stack symbol
  - F is a set of final states
- A PDA can accept an input string in two ways: by **final state** or by **empty stack**. In the former, the PDA accepts if it reaches a final state after reading the entire input. In the latter, the PDA accepts if it empties the stack after reading the entire input.
- A **context-free language** (CFL) is a language that can be generated by a **context-free grammar** (CFG), which is a set of production rules that describe how to form strings from a set of terminal and nonterminal symbols .
- A CFG can be formally defined as a 4-tuple (V, Σ, R, S), where:
  - V is a finite set of nonterminal symbols
  - Σ is a finite set of terminal symbols
  - R is a finite set of production rules of the form A → α, where A ∈ V and α ∈ (V ∪ Σ)*
  - S is the start symbol
- A CFL can be derived from a CFG by applying the production rules starting from the start symbol until no nonterminal symbols remain.
- The set of all CFLs is identical to the set of languages accepted by PDAs, which makes these languages amenable to parsing. Further, for a given CFG, there is a direct way to produce a PDA for the grammar (and thereby the corresponding language), though going the other way (producing a grammar given a PDA) is not always possible .
- The set of regular languages is a subset of CFLs, which means that every language that can be accepted by a finite automaton can also be accepted by a PDA. However, there are some CFLs that are not regular, such as {a^n b^n | n ≥ 0}, which can be accepted by a PDA but not by a finite automaton.
