### Definition for the notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

- A **push down automaton (PDA)** is a finite state machine with an additional stack memory.
- A PDA can perform three actions in a single step: read an input symbol, pop a symbol from the stack, and push a symbol onto the stack.
- A PDA is formally defined as a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F), where
  - Q is a finite set of states
  - Σ is a finite input alphabet
  - Γ is a finite stack alphabet
  - δ is a transition function that maps Q × (Σ ∪ {ε}) × Γ to a finite subset of Q × Γ*
  - q0 is the initial state
  - Z0 is the initial stack symbol
  - F is a set of final states
- A PDA can accept an input string in two ways: by **final state** or by **empty stack**.
  - By final state: a PDA accepts an input string if it reaches a final state after reading the entire input and performing zero or more stack operations.
  - By empty stack: a PDA accepts an input string if it empties the stack after reading the entire input and performing zero or more stack operations.
- The **language accepted by a PDA** is the set of all input strings that the PDA accepts in either way.
- A language is called **context-free** if it is accepted by some PDA.
- A **context-free grammar (CFG)** is a formal way of describing a context-free language using rules of the form A → α, where A is a variable and α is a string of variables and terminals.
- A CFG is formally defined as a 4-tuple (V, Σ, R, S), where
  - V is a finite set of variables
  - Σ is a finite set of terminals
  - R is a finite set of rules of the form A → α
  - S is the start variable
- A CFG can **derive** a string by applying the rules in R in a sequence, starting from S and ending with a string of terminals.
- The **language generated by a CFG** is the set of all strings that the CFG can derive.
- A CFG is said to be in **Chomsky normal form (CNF)** if every rule in R is of the form A → BC or A → a, where A, B, and C are variables and a is a terminal.
- A CFG is said to be in **Greibach normal form (GNF)** if every rule in R is of the form A → aα, where A is a variable, a is a terminal, and α is a string of variables.
- Every context-free language can be generated by a CFG in CNF or GNF, except for the empty language and the language containing only the empty string.
- The **pumping lemma for context-free languages** is a property that states that if L is a context-free language, then there exists a constant n such that for any string w in L with |w| ≥ n, there exist strings u, v, x, y, and z such that
  - w = uvxyz
  - |vxy| ≤ n
  - |vy| > 0
  - for all i ≥ 0, uvi x yi z is in L
- The pumping lemma can be used to prove that a language is not context-free by showing a contradiction.
