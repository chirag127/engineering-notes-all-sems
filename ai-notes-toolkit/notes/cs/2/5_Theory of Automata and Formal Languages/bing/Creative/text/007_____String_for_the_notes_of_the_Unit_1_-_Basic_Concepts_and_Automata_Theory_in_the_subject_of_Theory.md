### String

- A string is a finite sequence of symbols chosen from some set of alphabet or ∑ .
- A string is denoted by w in automata.
- The length of a string is the number of symbols present in the string.
- Examples of strings in automata are:
  - If ∑ = {a, b}, then some valid strings are a, ab, baa, babab, etc.
  - If ∑ = {0, 1}, then some valid strings are 0, 01, 1010, 111000, etc.
- The empty string or null string is the string with no symbols or characters. It is denoted by ε or λ.
- The set of all possible strings over an alphabet ∑ is denoted by ∑*. For example, if ∑ = {a, b}, then ∑* = {ε, a, b, aa, ab, ba, bb, aaa, aab, aba, abb, baa, bab, bba, bbb, ...}
