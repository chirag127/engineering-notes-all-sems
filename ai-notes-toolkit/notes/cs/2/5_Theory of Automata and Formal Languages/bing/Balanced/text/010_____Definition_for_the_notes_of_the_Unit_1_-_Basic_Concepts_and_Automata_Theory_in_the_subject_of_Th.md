### Definition for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

- Automata theory is the study of abstract machines and automata, as well as the computational problems that can be solved using them.
- An automaton is a self-operating device that follows a predetermined sequence of operations or responds to predetermined instructions.
- Automata theory is a branch of theoretical computer science that explores the properties and limitations of different types of automata and the languages they can recognize or generate.
- Automata theory has applications in various fields, such as compiler design, formal verification, cryptography, artificial intelligence, natural language processing, etc.
- Some of the basic concepts and terms in automata theory are:
  - Alphabet: A finite, non-empty set of symbols, usually denoted by Σ.
  - String: A finite sequence of symbols from an alphabet, also called a word.
  - Language: A set of strings over an alphabet, usually denoted by L.
  - Finite automaton: A mathematical model of a machine that has a finite number of states and transitions between them, and can accept or reject a string based on its final state.
  - Deterministic finite automaton (DFA): A finite automaton that has exactly one transition for each symbol and state.
  - Nondeterministic finite automaton (NFA): A finite automaton that can have zero, one, or more transitions for each symbol and state.
  - Regular expression: A notation for describing a language using symbols, concatenation, union, and closure operators.
  - Regular language: A language that can be recognized by a finite automaton or described by a regular expression.
  - Context-free grammar: A set of rules for generating strings in a language, consisting of a set of variables, terminals, start symbol, and production rules.
  - Context-free language: A language that can be generated by a context-free grammar.
  - Pushdown automaton: A finite automaton that has an additional stack memory that can store and retrieve symbols.
  - Turing machine: A finite automaton that has an infinite tape memory that can read and write symbols.
  - Decidable language: A language that can be recognized by a Turing machine that always halts.
  - Undecidable language: A language that cannot be recognized by any Turing machine, or can only be recognized by a Turing machine that may not halt.
