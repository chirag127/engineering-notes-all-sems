### String

- A string is a finite sequence of symbols from a given alphabet.
- An alphabet is a finite set of symbols, such as {0, 1} or {a, b, c, ..., z} .
- A string can be denoted by enclosing the symbols in quotation marks, such as "0101" or "hello".
- The length of a string is the number of symbols in it, denoted by |s|, where s is the string.
- The empty string is the string with no symbols, denoted by ε or λ.
- A string can be concatenated with another string by appending the symbols of the second string to the end of the first string, such as "ab" + "cd" = "abcd".
- A string can be repeated n times by concatenating it with itself n times, such as "ab" ^ 3 = "ababab".
- A string can be reversed by reversing the order of its symbols, such as rev("abc") = "cba".
- A string can be a substring of another string if it appears as a contiguous sequence of symbols in the other string, such as "ab" is a substring of "abc" and "cab" but not of "ba" or "ac".
- A string can be a prefix of another string if it appears as a substring at the beginning of the other string, such as "ab" is a prefix of "abc" and "abba" but not of "ba" or "cab".
- A string can be a suffix of another string if it appears as a substring at the end of the other string, such as "ab" is a suffix of "cab" and "abba" but not of "ba" or "abc".
- A string can be a subsequence of another string if it can be obtained by deleting some symbols from the other string, such as "ab" is a subsequence of "abc" and "cab" but not of "ba" or "ac".
