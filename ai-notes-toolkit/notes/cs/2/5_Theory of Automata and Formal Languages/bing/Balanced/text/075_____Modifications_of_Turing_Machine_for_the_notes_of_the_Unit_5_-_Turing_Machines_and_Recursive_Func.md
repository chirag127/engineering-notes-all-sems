### Modifications of Turing Machine

A Turing machine is a mathematical model of computation that can perform any algorithmic task by reading and writing symbols on an infinite tape. A Turing machine consists of a finite set of states, a finite alphabet of symbols, a transition function that maps a state and a symbol to a new state, a new symbol and a direction of movement, and a start state and a set of final states.

There are several variations or modifications of Turing machines that are equivalent in terms of computational power, meaning that they can recognize the same class of languages or compute the same functions. Some of these modifications are:

- **Multiple track Turing machine**: A k-track Turing machine (for some k>0) has k-tracks and one R/W head that reads and writes all of them one by one. Each track can store one symbol from the alphabet. A multiple track Turing machine can simulate a single track Turing machine by using different symbols to encode the information on each track. Conversely, a single track Turing machine can simulate a multiple track Turing machine by using a larger alphabet and a more complex transition function.

- **Two-way infinite tape Turing machine**: A two-way infinite tape Turing machine has an infinite tape that extends in both directions, instead of only to the right. A two-way infinite tape Turing machine can simulate a standard Turing machine by using a special symbol to mark the left end of the tape and ignoring any symbols to the left of it. Conversely, a standard Turing machine can simulate a two-way infinite tape Turing machine by using two tapes, one for the left part and one for the right part of the original tape, and switching between them as needed.

- **Multi-tape Turing machine**: A multi-tape Turing machine has k tapes (for some k>0) and k R/W heads, one for each tape. The tapes are initially filled with the input string on the first tape and blanks on the other tapes. The transition function depends on the state and the symbols read by all the heads, and determines the new state, the new symbols to be written on each tape, and the direction of movement for each head. A multi-tape Turing machine can simulate a single tape Turing machine by using one tape to store the state and the symbol under the head, and the other tapes to store the rest of the tape. Conversely, a single tape Turing machine can simulate a multi-tape Turing machine by using a larger alphabet and a more complex transition function to encode the information on each tape and the position of each head.

- **Multi-head Turing machine**: A multi-head Turing machine has one tape and k R/W heads (for some k>0) that can move independently on the tape. The transition function depends on the state and the symbols read by all the heads, and determines the new state, the new symbols to be written on the tape, and the direction of movement for each head. A multi-head Turing machine can simulate a single head Turing machine by using one head to perform the computation and the other heads to store the state and the symbol under the head. Conversely, a single head Turing machine can simulate a multi-head Turing machine by using a larger alphabet and a more complex transition function to encode the information on the tape and the position of each head.

- **Non-erasing Turing machine**: A non-erasing Turing machine is a Turing machine that cannot change the input symbols to blanks, but can replace them with any other symbol except blank. A non-erasing Turing machine can simulate a standard Turing machine by using a special symbol to mark the erased symbols and ignoring them in the computation. Conversely, a standard Turing machine can simulate a non-erasing Turing machine by using the same transition function and writing blanks instead of the input symbols.

- **Non-deterministic Turing machine**: A non-deterministic Turing machine is a Turing machine that can have more than one possible transition for a given state and symbol. A non-deterministic Turing machine accepts an input string if there exists at least one sequence of transitions that leads to a final state. A non-deterministic Turing machine can simulate a deterministic Turing machine by choosing one of the possible transitions arbitrarily. Conversely, a deterministic Turing machine can simulate a non-deterministic Turing machine by using a multi-tape Turing machine, where one tape stores the input string, one tape stores the current configuration, and one tape stores the next possible configurations.
