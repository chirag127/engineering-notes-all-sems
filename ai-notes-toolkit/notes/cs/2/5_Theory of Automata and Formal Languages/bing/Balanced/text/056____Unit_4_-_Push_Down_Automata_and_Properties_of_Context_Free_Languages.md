## Unit 4 - Push Down Automata and Properties of Context Free Languages

- A **push down automaton (PDA)** is a finite automaton with an additional memory component called a **stack**. The stack can store an unbounded amount of symbols and can be accessed only from the top. A PDA can perform three types of actions on the stack: **push**, **pop**, and **read**.
- A PDA can be either **deterministic** or **nondeterministic**. A deterministic PDA (DPDA) has at most one possible transition for any given input symbol and stack symbol. A nondeterministic PDA (NPDA) can have multiple possible transitions for any given input symbol and stack symbol.
- A PDA can be defined as a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F), where:
  - Q is the set of states
  - Σ is the input alphabet
  - Γ is the stack alphabet
  - δ is the transition function, which maps Q × (Σ ∪ {ε}) × Γ to a subset of Q × Γ*
  - q0 is the initial state
  - Z0 is the initial stack symbol
  - F is the set of final states
- A PDA can accept an input string in two ways: by **final state** or by **empty stack**. By final state, the PDA accepts an input string if it reaches a final state after reading the entire input string. By empty stack, the PDA accepts an input string if it empties the stack after reading the entire input string.
- A **context free language (CFL)** is a language that can be generated by a **context free grammar (CFG)**. A CFG is a 4-tuple (V, Σ, R, S), where:
  - V is the set of variables or nonterminals
  - Σ is the set of terminals
  - R is the set of production rules, which have the form A → ρ, where A ∈ V and ρ ∈ (V ∪ Σ)*
  - S is the start symbol
- A CFL can also be accepted by a PDA. There is an equivalence between CFLs and PDAs, which means that for every CFL, there exists a PDA that accepts it, and for every PDA, there exists a CFL that it accepts.
- CFLs have some important properties, such as:
  - Closure: CFLs are closed under union, concatenation, Kleene star, reversal, and homomorphism. This means that if L1 and L2 are CFLs, then L1 ∪ L2, L1L2, L1*, L1R, h(L1), and h(L2) are also CFLs, where h is a homomorphism function that maps each symbol in Σ to a string in Σ*.
  - Decidability: There are some decision problems that can be solved for CFLs, such as emptiness, finiteness, membership, equivalence, and inclusion. This means that there are algorithms that can determine whether a given CFL is empty, finite, contains a given string, is equal to another CFL, or is a subset of another CFL.
  - Pumping lemma: There is a lemma that can be used to prove that a language is not a CFL. The lemma states that if L is a CFL, then there exists a constant n such that for any string w ∈ L with |w| ≥ n, there exist strings u, v, x, y, z such that w = uvxyz, |vxy| ≤ n, |vy| > 0, and for any i ≥ 0, uvi xyi z ∈ L. The intuition is that a long enough string in a CFL can be pumped by repeating a substring in the middle.
