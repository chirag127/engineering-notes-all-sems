## Unit 1 - Basic Concepts and Automata Theory

- This unit introduces the fundamental concepts and models of computation, such as alphabets, strings, languages, grammars, automata, and Turing machines.
- An alphabet is a finite set of symbols, such as {0, 1} or {a, b, c, ..., z}.
- A string is a finite sequence of symbols from an alphabet, such as 0101 or hello.
- A language is a set of strings over an alphabet, such as the set of all binary strings or the set of all English words.
- A grammar is a set of rules that describe how to generate strings in a language, such as the rules of English syntax or the rules of arithmetic expressions.
- An automaton is an abstract machine that can recognize strings in a language, such as a finite state machine or a pushdown automaton.
- A Turing machine is a special type of automaton that can simulate any other automaton and perform any computation that is algorithmically solvable, such as adding two numbers or sorting a list.
- The unit covers the following topics:

  - Formal languages and grammars: Chomsky hierarchy, regular languages, context-free languages, context-sensitive languages, recursively enumerable languages, and their corresponding grammars.
  - Finite automata: deterministic and nondeterministic finite automata, regular expressions, equivalence and conversion, closure properties, pumping lemma, and applications.
  - Pushdown automata: deterministic and nondeterministic pushdown automata, context-free grammars, equivalence and conversion, closure properties, pumping lemma, and applications.
  - Turing machines: deterministic and nondeterministic Turing machines, variants and extensions, Church-Turing thesis, decidability and undecidability, halting problem, and reducibility.
