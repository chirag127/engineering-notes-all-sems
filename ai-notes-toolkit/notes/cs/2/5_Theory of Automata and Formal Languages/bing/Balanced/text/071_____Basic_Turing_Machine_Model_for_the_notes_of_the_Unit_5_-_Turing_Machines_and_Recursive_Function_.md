### Basic Turing Machine Model

- A Turing machine is a mathematical model of computation describing an abstract machine that manipulates symbols on a strip of tape according to a table of rules.
- It was invented in 1936 by Alan Turing, a British mathematician and logician, to investigate the extent and limitations of what can be computed.
- A Turing machine can accept the languages (recursively enumerable set) generated by type 0 grammars, which are the most general and powerful type of grammars in the Chomsky hierarchy.
- A basic Turing machine model consists of the following components :
  - An infinite tape divided into cells, each cell containing one symbol from a finite alphabet. The tape serves as the input, output and working memory of the machine.
  - A tape head that can read and write symbols on the tape, and move one cell to the left or right at a time.
  - A finite set of states, one of which is designated as the initial state, and some of which are designated as the final or accepting states.
  - A transition function that specifies, for each state and tape symbol, what the machine should do next: write a new symbol on the tape, move the head left or right, and change to a new state or halt.
- A Turing machine operates as follows :
  - The machine starts in the initial state with the tape head positioned on the leftmost cell of the input string.
  - The machine reads the symbol on the current cell and consults the transition function to determine the next action.
  - The machine performs the action and moves to the next state, unless the action is to halt, in which case the machine stops.
  - The machine repeats steps 2 and 3 until it halts or loops forever.
  - The machine accepts the input if it halts in an accepting state, rejects the input if it halts in a non-accepting state, and does not decide the input if it loops forever.

| qf | (0, R, qf) | (1, R, qf) | (B, R, qf) |

- A Turing machine can simulate any other Turing machine, and any algorithm that can be executed by a computer can be implemented by a Turing machine . Therefore, Turing machines are considered as a universal model of computation.
