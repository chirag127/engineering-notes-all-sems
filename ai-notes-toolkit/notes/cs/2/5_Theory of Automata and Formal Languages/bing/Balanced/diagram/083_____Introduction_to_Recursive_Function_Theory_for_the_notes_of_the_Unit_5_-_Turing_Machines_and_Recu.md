### Introduction to Recursive Function Theory

- Recursive function theory is a branch of mathematical logic that studies the properties and limitations of computable functions on natural numbers .
- A function is computable if there is an effective method or algorithm to compute its value for any given input. For example, the factorial function `n! = n * (n-1) * ... * 1` is computable because there is a simple algorithm to calculate it using repeated multiplication.
- There are different models of computation that can capture the notion of computability, such as Turing machines, lambda calculus, register machines, etc. Recursive function theory shows that these models are equivalent in power, meaning that they can compute exactly the same class of functions .
- A function is called recursive if it can be defined in terms of simpler functions using a finite number of basic operations, such as composition, primitive recursion, and minimization. For example, the factorial function can be defined recursively as `f(0) = 1` and `f(n+1) = (n+1) * f(n)` .
- A function is called partially recursive if it is recursive but may not be defined for some inputs. For example, the inverse factorial function `f(n) = the smallest k such that k! = n` is partially recursive because it is not defined for inputs that are not factorials of natural numbers .
- A function is called total recursive if it is recursive and defined for all inputs. For example, the addition function `f(x,y) = x + y` is total recursive because it is defined for any pair of natural numbers .
- A function is called primitive recursive if it can be defined using only composition and primitive recursion, without minimization. Primitive recursion is a special case of recursion where the function is defined by its value at zero and its value at the successor of any input. For example, the factorial function can be defined using primitive recursion as `f(0) = 1` and `f(n+1) = (n+1) * f(n)` .
- A function is called recursively enumerable if there is a recursive function that enumerates its values. For example, the function `f(n) = the nth prime number` is recursively enumerable because there is a recursive function that generates the sequence of prime numbers .
- Recursive function theory explores the relationships and differences between these classes of functions, as well as the decidability and undecidability of various problems involving them. For example, it is undecidable whether a given recursive function is total, primitive, or constant .
