### Context Free Grammar (CFG)

- A context free grammar (CFG) is a set of rules that defines a language by specifying how any valid string can be derived from a special symbol called the start symbol.
- A CFG consists of four components: a set of terminals, a set of non-terminals, a start symbol, and a set of production rules.
- Terminals are the basic symbols that appear in the strings of the language. Non-terminals are placeholders that can be replaced by sequences of terminals and/or non-terminals according to the production rules.
- The start symbol is a special non-terminal that represents the whole language. The production rules are the rules that specify how a non-terminal can be replaced by a sequence of terminals and/or non-terminals.
- A CFG can be written in the form of G = (V, T, S, P), where V is the set of non-terminals, T is the set of terminals, S is the start symbol, and P is the set of production rules.
- A production rule has the form A -> α, where A is a non-terminal and α is a sequence of terminals and/or non-terminals. The symbol -> means "can be replaced by".
- A derivation is a sequence of steps that shows how a string can be obtained from the start symbol by applying the production rules. A derivation can be written as S => α1 => α2 => ... => αn, where S is the start symbol, α1, α2, ..., αn are sequences of terminals and/or non-terminals, and => means "yields in one step".
- A language is said to be context free if it can be generated by a CFG. A language that is not context free is called context sensitive. Context free languages have many applications in computer science, such as parsing, programming languages, and compilers.
- A CFG can be represented by a diagram called a parse tree, which shows the hierarchical structure of a string derived from the CFG. A parse tree has the following properties:
  - The root node is labeled with the start symbol.
  - Each leaf node is labeled with a terminal symbol.
  - Each internal node is labeled with a non-terminal symbol.
  - The children of an internal node are labeled with the symbols that appear on the right-hand side of the production rule that was used to replace the non-terminal symbol of the parent node.
  - The string represented by the parse tree can be obtained by reading the labels of the leaf nodes from left to right.

Here is an example of a CFG and a parse tree for the string "aabb":

- CFG: G = ({S, A, B}, {a, b}, S, {S -> AB, A -> aA | a, B -> bB | b})
- Parse tree:


- String: "aabb"
