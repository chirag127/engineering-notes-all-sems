### Definition for the notes of the Unit 4 - Pushdown Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

- A **pushdown automaton** (PDA) is a type of automaton that employs a **stack** as an extra memory to store symbols .
- A PDA can be formally defined as a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F), where :
  - Q is a finite set of **states**.
  - Σ is a finite set of **input symbols**.
  - Γ is a finite set of **stack symbols**.
  - δ is a **transition function** that maps Q × Σε × Γε to a finite subset of Q × Γε, where ε denotes the empty string.
  - q0 is the **initial state**.
  - Z0 is the **initial stack symbol**.
  - F is a set of **final states**.
- A PDA can perform three types of operations on the stack :
  - **Push**: add a symbol to the top of the stack.
  - **Pop**: remove a symbol from the top of the stack.
  - **No operation**: leave the stack unchanged.
- A PDA can read a given input string from left to right and choose a transition based on the input symbol, the current state, and the symbol at the top of the stack .
- A PDA can be either **deterministic** or **nondeterministic**, depending on whether the transition function is a function or a relation .
- A PDA can recognize **context-free languages**, which are languages that can be generated by context-free grammars .
