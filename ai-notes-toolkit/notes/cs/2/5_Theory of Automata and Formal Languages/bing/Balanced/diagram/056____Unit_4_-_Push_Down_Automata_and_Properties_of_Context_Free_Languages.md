## Unit 4 - Push Down Automata and Properties of Context Free Languages

- A push down automaton (PDA) is a finite automaton with an additional component called a stack, which can store an unbounded amount of symbols.
- A PDA can perform three types of actions: read an input symbol and move to the next one, push a symbol onto the stack, or pop a symbol from the stack.
- A PDA can be either deterministic (DPDA) or nondeterministic (NPDA), depending on whether it has a unique transition for each input symbol and stack symbol or not.
- A context free language (CFL) is a language that can be generated by a context free grammar (CFG), which is a set of rules that describe how to form strings from a finite alphabet and a set of variables.
- A CFG consists of four components: a set of variables, a set of terminals, a start variable, and a set of production rules.
- A CFL can be accepted by a PDA in two ways: by empty stack or by final state.
- By empty stack, a PDA accepts a string if it can read the entire input and empty the stack.
- By final state, a PDA accepts a string if it can read the entire input and reach a state that is marked as final.
- The relation between PDAs and CFLs is that a language is context free if and only if it is accepted by a PDA.
- This means that for every CFL, there exists a PDA that accepts it, and for every PDA, there exists a CFG that generates the language accepted by it.
- The properties of CFLs include the following:
  - CFLs are closed under union, concatenation, and Kleene star operations, but not under intersection, complement, or difference operations.
  - CFLs are not closed under reversal, but the reversal of a CFL is also a CFL.
  - CFLs are not closed under homomorphism, but the inverse homomorphism of a CFL is also a CFL.
  - CFLs are not closed under substitution, but the substitution of a regular language into a CFL is also a CFL.
  - CFLs are not closed under inverse substitution, but the inverse substitution of a regular language into a CFL is also a CFL.
