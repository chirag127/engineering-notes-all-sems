### Moves for the notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

Push Down Automata (PDA) is an extension of Finite State Machine that accepts Context Free Languages. PDAs use a stack to keep track of the input strings and to make the decision whether to accept or reject the input string.

The following are the moves of a PDA:

1. Start State: PDA starts in the start state with an empty stack.

2. Push Operation: When the PDA reads a non-terminal symbol, it pushes it onto the stack.

3. Pop Operation: When the PDA reads a terminal symbol, it pops the top symbol from the stack.

4. Epsilon Transition: The PDA can move from one state to another state without reading any input symbol, but it can perform operations on the stack.

5. Accepting State: The PDA accepts the input string if it reaches an accepting state when the input string is completely read and the stack is empty.

6. Rejecting State: The PDA rejects the input string if it reaches a rejecting state when the input string is completely read and the stack is not empty.

7. Non-Deterministic Transition: The PDA can move from one state to multiple states for the same input symbol and stack symbol.

Properties of Context-Free Languages:

1. Closure Properties:
- Union: If L1 and L2 are two context-free languages, then their union L1 ∪ L2 is also context-free.
- Concatenation: If L1 and L2 are two context-free languages, then their concatenation L1L2 is also context-free.
- Kleene Star: If L is a context-free language, then its Kleene star L* is also context-free.

2. Pumping Lemma:
- Every context-free language has a pumping length p such that any string w in the language with |w| ≥ p can be pumped.

3. Ambiguity:
- A context-free language is ambiguous if there exist two or more leftmost or rightmost derivations for any string in the language.

4. Normal Forms:
- Chomsky Normal Form: Every context-free language can be generated by a context-free grammar in Chomsky normal form.
- Greibach Normal Form: Every non-empty, right-linear context-free language can be generated by a context-free grammar in Greibach normal form.

By understanding the moves of a PDA and the properties of context-free languages, we can analyze and design algorithms for various problems in computer science, such as parsing, compiling, and natural language processing.
