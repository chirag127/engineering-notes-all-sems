### Definition for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

In this unit, we will introduce the basic concepts and definitions related to Automata Theory, which is a branch of Computer Science that studies the behavior of abstract machines.

1. Automaton: An automaton is an abstract machine that can perform a sequence of actions based on a set of rules. It can be thought of as a simple computer that follows a predefined set of instructions.

2. Finite Automaton (FA): A finite automaton is a type of automaton that has a finite number of states. It is used to recognize regular languages, which are a subset of formal languages.

3. Deterministic Finite Automaton (DFA): A DFA is a type of finite automaton where each transition from one state to another is uniquely determined by the input symbol. It accepts a string if there exists a path from the initial state to a final state that corresponds to the string.

4. Non-deterministic Finite Automaton (NFA): An NFA is a type of finite automaton where there may be multiple transitions from one state to another for a given input symbol. It accepts a string if there exists at least one path from the initial state to a final state that corresponds to the string.

5. Regular expression: A regular expression is a sequence of characters that defines a pattern, which can be used to match strings. It is a concise way of representing regular languages.

6. Formal Language: A formal language is a set of strings that are formed by a given set of rules. It can be thought of as a language that is spoken by an abstract machine.

7. Chomsky Hierarchy: The Chomsky Hierarchy is a classification of formal languages based on their generative power. It consists of four classes: regular languages, context-free languages, context-sensitive languages, and recursively enumerable languages.

8. Context-free Grammar: A context-free grammar is a set of production rules used to generate strings in a context-free language. It consists of a set of variables, a set of terminals, a start symbol, and a set of production rules that define how variables can be replaced by strings of variables and terminals.

9. Pushdown Automaton (PDA): A pushdown automaton is an extension of a finite automaton that uses a stack to keep track of its current state. It is used to recognize context-free languages.

10. Turing Machine (TM): A Turing machine is an abstract machine that can simulate any algorithmic process. It consists of a tape that can be read and written to, a finite set of states, and a set of transition rules that define how the machine can change its state based on the input symbol and the current state. It is used to recognize recursively enumerable languages.

These are the basic concepts and definitions that you need to know to understand the theory of automata and formal languages. Understanding these concepts will help you in building more complex automata and designing algorithms for formal languages.
