
## Unit 3 - Regular and Non-Regular Grammars

1. Regular grammars are a type of formal grammar used in computer science and linguistics to describe a set of strings. They are based on a finite set of rules and can be used to generate an infinite set of strings.

2. Non-regular grammars are a type of formal grammar used in computer science and linguistics to describe a set of strings that cannot be generated by a regular grammar. They are based on a finite set of rules and can be used to generate an infinite set of strings.

3. A regular grammar is composed of four components: a set of terminal symbols, a set of non-terminal symbols, a set of productions and a start symbol. The terminal symbols are the symbols that represent the strings that the grammar can generate. The non-terminal symbols are symbols that represent variables or placeholders in the grammar. The productions are the rules that define how the grammar generates strings. The start symbol is the symbol that represents the beginning of the string.

4. A non-regular grammar is composed of four components: a set of terminal symbols, a set of non-terminal symbols, a set of productions and a start symbol. The terminal symbols are the symbols that represent the strings that the grammar can generate. The non-terminal symbols are symbols that represent variables or placeholders in the grammar. The productions are the rules that define how the grammar generates strings. The start symbol is the symbol that represents the beginning of the string. Unlike regular grammars, non-regular grammars can also include productions with multiple symbols on the right-hand side.

5. Regular grammars can be used to generate strings that are accepted by a Turing machine. Non-regular grammars can generate strings that are not accepted by a Turing machine.

6. Regular grammars can be used to generate languages that are accepted by a finite automaton. Non-regular grammars can generate languages that are not accepted by a finite automaton.
