
## Unit 4 - Push Down Automata and Properties of Context Free Languages

1. Push Down Automata (PDA) is a type of machine used in the theory of computation to recognize and process context-free languages.

2. A PDA is essentially a finite-state machine augmented with an additional memory component called a "stack".

3. The stack is used to store symbols that have been read from the input string and can be used to determine the next action in the computation.

4. A PDA can be thought of as a finite-state machine with a stack-like memory which can be used to store and retrieve symbols.

5. The set of all strings accepted by a PDA is known as the language accepted by the PDA.

6. The language accepted by a PDA is a context-free language.

7. The Chomsky Hierarchy is a classification of formal languages based on their generative power.

8. Context-free languages are a subset of the Chomsky Hierarchy and are generated by context-free grammars.

9. A context-free grammar is a set of production rules that describe how strings of symbols can be generated from a single non-terminal symbol.

10. The pumping lemma for context-free languages states that for any context-free language, there is a constant “pumping length” such that any string of that length or longer can be broken down into three parts, one of which can be repeated an arbitrary number of times without changing the language accepted by the PDA.
