
### Conversion of FA into CFG and Regular grammar into FA 

1. Finite Automata (FA) are used to recognize strings in a given language. They consist of a finite set of states and a transition function which maps each state to another state.

2. Conversion of FA into Context Free Grammars (CFG) is done by constructing a CFG that generates the same language as the given FA.

3. Regular Grammars (RG) are used to generate strings in a given language. They consist of a finite set of production rules and a start symbol.

4. Conversion of Regular Grammars into Finite Automata (FA) is done by constructing a FA that recognizes the same language as the given RG. 

5. To convert a FA into a CFG, each state of the FA is converted into a non-terminal symbol and the transition function is used to construct the production rules. 

6. To convert a RG into a FA, each production rule is converted into a transition and the start symbol is used to construct the initial state.
