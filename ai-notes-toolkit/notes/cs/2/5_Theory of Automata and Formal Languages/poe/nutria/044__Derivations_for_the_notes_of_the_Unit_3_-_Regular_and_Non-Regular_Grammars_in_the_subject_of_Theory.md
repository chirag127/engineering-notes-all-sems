
### Derivations for the Notes of the Unit 3 - Regular and Non-Regular Grammars in the Subject of Theory of Automata and Formal Languages

1. Regular grammars are defined as a set of production rules used to generate a language. A regular grammar consists of four components: terminals, non-terminals, production rules, and start symbol.

2. Non-regular grammars are a set of production rules used to generate a language that is not regular. Non-regular grammars can be divided into two categories: context-free grammars and unrestricted grammars.

3. Context-free grammars are a type of non-regular grammar that can generate a language by using a set of production rules and a single non-terminal symbol.

4. Unrestricted grammars are a type of non-regular grammar that can generate a language by using a set of production rules and multiple non-terminal symbols.

5. Derivations are a process used to generate a sequence of strings from a grammar. A derivation of a string is generated by applying production rules to the start symbol.

6. A derivation tree is a tree structure used to represent the derivations of a string. Each node in the tree represents a production rule and the edges represent the application of the rule.

7. A parse tree is a tree structure used to represent the structure of a string. Each node in the tree represents a terminal or non-terminal symbol and the edges represent the application of the production rules.
