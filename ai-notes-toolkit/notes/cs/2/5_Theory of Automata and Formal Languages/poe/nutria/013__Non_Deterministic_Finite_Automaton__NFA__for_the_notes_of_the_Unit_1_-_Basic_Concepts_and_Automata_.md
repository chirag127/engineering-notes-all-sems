
### Non Deterministic Finite Automaton (NFA)

A Non Deterministic Finite Automaton (NFA) is a type of finite automaton which can have multiple transitions from a single state for a single input symbol. This means that an NFA can have multiple paths of execution for a given input string.

An NFA is defined as a 5-tuple (Q, Σ, δ, q0, F) where:

* Q is a finite set of states
* Σ is a finite set of input symbols
* δ is a transition function
* q0 is the initial state
* F is a set of accepting states

An NFA can be represented as a directed graph, where the nodes represent the states and the edges represent the transitions.

An NFA can be used to recognize regular languages, which are languages that are generated by regular expressions. Regular expressions are strings that are composed of symbols, operators and parentheses. Examples of regular expressions include ab*, a(bc)* and (a|b)*a.
