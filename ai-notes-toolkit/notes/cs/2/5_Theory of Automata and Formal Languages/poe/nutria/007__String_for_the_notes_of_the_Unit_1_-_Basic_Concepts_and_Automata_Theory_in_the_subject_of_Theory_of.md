
### Unit 1 - Basic Concepts and Automata Theory

* Automata Theory is a branch of computer science which deals with the study of abstract machines and their properties.
* Formal languages are languages that can be described by a set of rules or a grammar.
* A string is a finite sequence of symbols taken from a given alphabet.
* A language is a set of strings.
* Finite Automata (FA) are used to recognize strings of a given language.
* Regular languages are languages that can be recognized by a finite automaton.
* Non-deterministic Finite Automata (NFA) is a type of finite automata which can have multiple transitions for a given input.
* Deterministic Finite Automata (DFA) is a type of finite automata which has only one transition for a given input.
* Pushdown Automata (PDA) is a type of finite automata which can use a stack to store and retrieve symbols.
* Turing Machines (TM) are used to recognize strings of a given language and can be used to solve any computable problem.
