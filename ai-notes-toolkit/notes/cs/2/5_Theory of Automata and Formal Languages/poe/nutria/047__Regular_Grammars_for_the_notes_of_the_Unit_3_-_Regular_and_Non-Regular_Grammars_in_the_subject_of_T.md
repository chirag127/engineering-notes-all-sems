
### Regular Grammars for the Notes of the Unit 3 - Regular and Non-Regular Grammars in the Subject of Theory of Automata and Formal Languages

* A regular grammar is a set of rules for generating strings from a given language.
* A regular grammar consists of a set of symbols, called terminals, and a set of production rules.
* The production rules of a regular grammar are of the form A → a, where A is a non-terminal symbol and a is a string of terminals.
* A regular grammar can be represented as a finite automaton.
* A regular grammar is said to be non-regular if it contains production rules of the form A → aB, where B is a non-terminal symbol.
* A regular grammar is said to be context-free if it contains production rules of the form A → a, where A is a non-terminal symbol and a is a string of terminals.
* A regular grammar can be represented as a context-free grammar.
* A regular language is a set of strings that can be generated by a regular grammar.
* A non-regular language is a set of strings that cannot be generated by a regular grammar.
