
### Acceptability of a String and Language

* A string is said to be acceptable if it is an element of a language. 
* A language is a set of strings.
* A string is a sequence of symbols drawn from an alphabet.
* An alphabet is a finite set of symbols.
* A language is accepted by a finite automata if the set of strings accepted by the automata is the same as the language.
* A finite automata is a machine that is used to accept or reject strings of symbols.
* A finite automata consists of a set of states, an input alphabet, a transition function, a start state and a set of final states.
* A transition function is a mapping from a set of states and an input symbol to a set of states.
* A string is said to be accepted by a finite automata if it starts in the start state and ends in a final state.
* The language accepted by a finite automata is the set of strings that are accepted by the automata.
