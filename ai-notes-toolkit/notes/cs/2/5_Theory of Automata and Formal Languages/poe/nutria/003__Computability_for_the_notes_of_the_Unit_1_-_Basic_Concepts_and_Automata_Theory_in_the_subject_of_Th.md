
### Computability for Unit 1 - Basic Concepts and Automata Theory

* A formal language is a set of strings over some alphabet. 
* A Turing machine is a mathematical model of computation which can be used to determine if a given string is part of a formal language. 
* A Turing machine consists of a finite set of states, a finite set of symbols, and a finite set of transition rules. 
* A language is said to be computable if it can be accepted by a Turing machine. 
* A language is said to be decidable if it can be decided by a Turing machine. 
* A language is said to be recognizable if it can be recognized by a Turing machine. 
* The halting problem is the problem of determining, given a Turing machine and an input, whether the Turing machine will ever halt on that input. 
* The Church-Turing thesis states that any computable problem can be solved by a Turing machine. 
* A universal Turing machine is a Turing machine which can simulate any other Turing machine. 
* A deterministic finite automaton (DFA) is a finite state machine which accepts a language. 
* A nondeterministic finite automaton (NFA) is a finite state machine which recognizes a language. 
* A pushdown automaton is a finite state machine which accepts a context-free language.
