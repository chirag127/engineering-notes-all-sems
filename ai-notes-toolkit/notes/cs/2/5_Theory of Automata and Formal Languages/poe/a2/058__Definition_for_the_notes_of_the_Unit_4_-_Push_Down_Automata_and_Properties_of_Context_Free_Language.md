### Definition for the notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

1. Pushdown Automata: Pushdown automata is a way of implementing Context Free Grammars. It is similar to Finite Automata with a stack which helps in remembering the sequence of inputs. The stack can be pushed and popped based on the input and current state. The acceptance of input string depends on the final state and stack contents.
2. Properties of Context Free Languages:
- The Empty String ε is always in a CFL.
- If L1 and L2 are CFLs, then the union (L1 U L2), concatenation (L1.L2) and Kleene Closure (L1*) of CFLs are also CFLs.
- The set of all strings formed using the alphabet set is a CFL.
- The set of all palindromes over an alphabet is a CFL.
- The set of all strings with equal number of a’s and b’s is a CFL.
3. Applications of Context Free Languages:
- Programming Languages: The syntax of programming languages can be specified using Context Free Grammars.
- Databases: The schema of databases can be defined using Context Free Grammars.
- Artificial Intelligence: The input language of chatbots and voice assistants can be defined using Context Free Grammars.

The above points cover the key definitions and properties of Pushdown Automata and Context Free Languages which would be important to study for exams related to the Theory of Automata and Formal Languages.
