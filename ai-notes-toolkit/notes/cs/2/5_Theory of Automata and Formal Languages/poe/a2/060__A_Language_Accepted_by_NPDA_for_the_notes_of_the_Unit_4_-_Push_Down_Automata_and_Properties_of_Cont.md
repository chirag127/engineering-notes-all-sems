### A Language Accepted by NPDA for the notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

1. A Nondeterministic Pushdown Automaton (NPDA) is a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F) where
- Q is a finite set of states
- Σ is a finite input alphabet
- Γ is a finite stack alphabet
- δ is a transition function from Q x (Σ ∪ {ε}) x Γ to finite subsets of Q x Γ*
- q0 is the initial state
- Z0 is the start stack symbol
- F is a set of final states

2. A configuration of an NPDA is a string over (Q x Γ)* such that the symbol at any position is either (q,X) or (q,ε) where q is a state and X is a stack symbol or ε represents the empty stack. The initial configuration will be (q0, Z0).

3. A move from one configuration to another is defined based on the transition function δ. The automaton can read an input symbol and replace the top stack symbol based on δ. The automaton accepts an input string if there exists a sequence of moves starting from the initial configuration resulting in a final configuration where the top stack symbol is ε.

4. The language accepted by an NPDA is the set of all strings accepted by it. The language accepted is said to be context-free. The power of NPDA is equivalent to Context-Free Grammars. Any language accepted by an NPDA can be generated by a CFG and vice-versa.

5. Some key properties of languages accepted by NPDA (Context-Free Languages):
- They are closed under union, concatenation, and Kleene star.
- They properly contain regular languages and are properly contained in recursively enumerable languages.
- The pumping lemma holds for them.
- They have strictly less computational power than Turing-recognizable languages.
