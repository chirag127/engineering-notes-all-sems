### Introduction to Recursive Function Theory

1. Recursive functions are functions that can be computed by a deterministic Turing machine. They are also known as Turing-computable functions.
2. A function f(x) is said to be recursive if and only if there exists an algorithm to compute the function. In other words, if the function can be computed by some Turing machine then it is called recursive.
3. The class of recursive functions is very broad and contains most of the functions that arise in mathematics and computer science. Most of the functions that we compute in practice are recursive functions.
4. Some examples of recursive functions are:
 - Factorial function: f(n) = n!
 - Fibonacci function: f(n) = Fib(n)
 - Exponentiation function: f(x, n) = x^n
 - Greatest common divisor function: f(a, b) = gcd(a, b)
5. An important theorem regarding recursive functions states that a function is recursive if and only if it can be expressed in lambda calculus. In other words, lambda calculus and Turing-computable functions have the same power of expression.
6. The study of recursive functions and their properties is known as recursive function theory. It is a branch of computability theory and is important in understanding the limitations and capabilities of computing machines.
