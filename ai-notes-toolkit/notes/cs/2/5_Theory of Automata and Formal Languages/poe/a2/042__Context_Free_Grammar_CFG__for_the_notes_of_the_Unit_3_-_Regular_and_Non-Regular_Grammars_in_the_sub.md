### Context Free Grammar(CFG)

1. A Context Free Grammar(CFG) is a quadruple (V, T, P, S) where
- V is a finite set of variables(non-terminals)
- T is a finite set of terminals
- P is a finite set of production rules
- S in V is the start variable

2. Production rules are of the form X -> a where X is a variable and a is a string of terminals and/or variables.
3. A string is generated by starting with the start variable and repeatedly replacing a variable with a string of terminals and variables on the right hand side of a production rule.
4. A language is the set of strings generated by a grammar.
5. A context free grammar is more powerful than a regular grammar. It can generate all and only the recursive languages.
6. Some examples of context free grammars:
- (V, T, P, S) where V = {S, A}, T = {a, b}, P contains rules S -> A and A -> aSb
