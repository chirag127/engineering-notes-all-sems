### Computability for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1.  A problem is said to be computable if there exists an algorithm that can solve the problem. Algorithms are a finite set of precise instructions for performing a computation or solving a problem.
2.  A function is computable if there exists an algorithm that can compute its values for any input. The class of computable functions is referred to as the recursive functions.
3.  The Church-Turing thesis states that everything that is computable is computable by a Turing machine. In other words, the Turing machines can compute exactly the functions that are computable. This thesis forms the basis for the accepted definition of an algorithm as a set of instructions for a Turing machine.
4.  According to the Church-Turing thesis, problems that can be solved by algorithms running on a digital computer are called algorithmically solvable or computable problems. Problems that cannot be solved by any algorithm are called unsolvable or uncomputable problems.
5.  The halting problem is a well-known example of an uncomputable problem. The halting problem asks if there exists an algorithm that can determine whether any given program finishes running or runs forever. This problem has been shown to be undecidable, i.e., no such algorithm exists.
