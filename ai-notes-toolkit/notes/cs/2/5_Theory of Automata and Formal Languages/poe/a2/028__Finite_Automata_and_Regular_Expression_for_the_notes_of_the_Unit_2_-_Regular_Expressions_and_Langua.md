### Finite Automata and Regular Expression

- Finite Automata: A finite automaton is a mathematical model of a machine with a finite number of states. It is used to recognize patterns in the input string. It reads the input symbols one by one and transitions from one state to another. It halts in either an accepting or rejecting state.
- Components of Finite Automata:
 - States: Finite set of states
 - Alphabet: Finite set of input symbols
 - Transition function: Function that maps current state and input symbol to next state
 - Start state: Initial state of the automaton
 - Accepting states: Set of states where the automaton accepts the input
- Regular Expression: A regular expression is a pattern that describes a set of strings. It is denoted by letters, digits, and special characters. It is useful in specifying the syntax of a formal language. Regular expressions can be converted into finite automata and vice versa.
- Properties of Regular Languages:
 - Closure: The regular operations like union, concatenation, and Kleene star of regular languages results in a regular language.
 - Finite Automata Acceptance: A language is regular if there exists a finite automaton that accepts it.
 - No Ambiguity: A regular expression cannot have more than one leftmost derivation of a string.
 - Membership: It is decidable whether a given string is in a regular language or not.
