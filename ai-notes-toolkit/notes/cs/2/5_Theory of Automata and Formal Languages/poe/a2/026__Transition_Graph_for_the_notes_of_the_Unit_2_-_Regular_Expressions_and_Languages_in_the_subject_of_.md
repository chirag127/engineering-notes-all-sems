### Transition Graph for the notes of the Unit 2 - Regular Expressions and Languages

1. Transition Graph: The transition graph of a finite state machine is a directed graph consisting of states as nodes and transitions as edges. Each transition is labeled with an input symbol.
2. Start State: The start state is the state from which the automata starts processing input strings. It is denoted by an arrow pointing to it.
3. Accept State: An accept state is a state in which the automata halts if the input string is in the language. It is denoted by a double circle.
4. Transitions: Transitions are edges in the transition graph labeled with input symbols. A transition from state 's1' to state 's2' labeled with input symbol 'a' is denoted by 's1-a-s2' .
5. epsilon transition: An epsilon transition is a transition without any input symbol. It is denoted by 'ε ' .

The transition graph contains all the information about a finite state machine. Given a transition graph, the equivalent finite state machine can be constructed. Regular expressions can be easily converted to transition graphs and vice-versa. Transition graphs provide an intuitive way of visualizing the working of a finite state machine.
