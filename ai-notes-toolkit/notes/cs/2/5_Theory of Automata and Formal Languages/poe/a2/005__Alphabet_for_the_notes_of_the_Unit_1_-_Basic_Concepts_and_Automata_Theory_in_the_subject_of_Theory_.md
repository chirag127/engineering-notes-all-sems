### Alphabet for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1. An alphabet is a finite set of symbols. It is the basic building block of languages.
2. The symbols can be letters, digits, punctuation marks, etc. For example, the English alphabet contains 26 letters from A to Z.
3. The number of symbols in an alphabet is called its cardinality. A finite alphabet has a fixed cardinality.
4. Null or empty alphabet: An alphabet with zero symbols is called the null or empty alphabet. No string can be formed using the empty alphabet.
5. An alphabet can be specified explicitly by listing all its symbols between curly braces, e.g. {0, 1} is a binary alphabet.
6. Letters are typically denoted by lowercase Greek letters like Sigma (σ), Gamma (γ), Delta (δ), etc. The cardinality of an alphabet Sigma is denoted by |Sigma|.
7. Examples of alphabets:
    - {0, 1} - Binary alphabet
    - {a, b} - Alphabet with 2 symbols
    - {a, b, c} - Alphabet with 3 symbols
    - {a, b, ..., z} - The English alphabet
    - {+, -, *, /} - Arithmetic symbols
