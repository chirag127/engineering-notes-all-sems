### Decision Problems of CFL

- Membership Problem: Given a string w and a CFL L, determine if w is in L. This can be solved in polynomial time using PDA simulation.
- Emptiness Problem: Given a PDA M, determine if L(M) = {}. This can be solved in polynomial time by attempting to accept an empty string. If successful, L(M) is non-empty.
- Finiteness Problem: Given a PDA M, determine if L(M) is finite. This is undecidable as the halting problem for PDAs is undecidable. We cannot always determine if a PDA accepts a finite or infinite number of strings.
- Universality Problem: Given a PDA M and CFL L, determine if L(M) = L. This is undecidable as we cannot determine if a PDA accepts all strings in a CFL. The emptiness and finiteness problems are prerequisite to solving universality and they are undecidable.
