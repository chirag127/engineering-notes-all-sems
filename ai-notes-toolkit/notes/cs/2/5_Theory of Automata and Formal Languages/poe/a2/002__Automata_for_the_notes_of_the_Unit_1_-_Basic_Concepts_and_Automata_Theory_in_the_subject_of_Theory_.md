### Automata for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1. Finite Automata:
- Finite number of states
- Reads input symbols one by one
- Changes state based on input symbol and current state
- Halts in an accept or reject state
- Used to recognize regular languages

2. Deterministic Finite Automata (DFA):
- Has only one transition from current state on an input symbol
- Always halts
- Recognizes the same set of languages as Non-deterministic Finite Automata (NFA)

3. Non-deterministic Finite Automata (NFA):
- May have multiple transitions or ε-transitions (Null transitions) from a state on an input symbol
- May not halt for some inputs
- Converted to equivalent DFA using subset construction

4. Pushdown Automata:
- Has a stack to push/pop symbols
- More powerful than Finite Automata
- Recognizes Context-Free Languages (CFL)
- Used to check for balanced parenthesis, recognize programming languages, etc.

5. Turing Machine:
- Has a read/write tape which is its memory
- Most powerful automaton model
- Can recognize all recursively enumerable languages
- Universal Turing Machine can simulate any Turing Machine
