### Nondeterministic Pushdown Automata (NPDA)

- Nondeterministic pushdown automata (NPDA) is a variant of pushdown automata where for each input symbol, the automaton may have multiple possible transitions.
- The NPDA may have multiple choices for the next state and/or the symbol to be pushed/popped from the stack.
- The acceptance condition for NPDA is same as PDA, i.e. the stack should be empty when the input string is fully read.
- The language accepted by a NPDA is the union of languages accepted by each possible transition sequence.
- The power of NPDA is same as PDA, i.e. an NPDA can accept any context-free language. However, NPDA may have multiple accepting paths for the same input string.
- Although the descriptive power is same, NPDA are not preferred as accepting power of a regular/context-free language as it is non-deterministic. The PDA is preferred due to single accepting sequence for an input string.
