### Control Charts

- Control charts are a graphical tool for statistical process control (SPC), which is the use of various methods and tools to monitor and improve the quality and performance of a process over time .
- Control charts help to determine if a process is in a state of control, which means that the process is stable and predictable, and that the variation in the process output is due to common causes (random or inherent) and not special causes (assignable or preventable) .
- Control charts can also help to identify the sources of special causes, and to evaluate the effects of process changes or improvements .
- Control charts consist of three main elements :
  - A central line, which represents the average or target value of the process output.
  - An upper control limit (UCL) and a lower control limit (LCL), which are calculated from the historical data and represent the boundaries of the natural variation of the process output.
  - Data points, which are plotted in time order and show the values of the process output measured at different intervals.
- Control charts can be classified into two main types, depending on the type of data being plotted :
  - Variable control charts, which are used for continuous data, such as length, weight, temperature, etc. Examples of variable control charts are X-bar and R charts, X-bar and S charts, and individual and moving range (I-MR) charts.
  - Attribute control charts, which are used for discrete data, such as counts, proportions, defects, etc. Examples of attribute control charts are p charts, np charts, c charts, and u charts.
- Control charts can be used to monitor various aspects of a process, such as the mean, the variation, the proportion of defectives, the number of defects, etc. Depending on the aspect being monitored, different control charts may be appropriate .
- Control charts can be interpreted by applying some basic rules, such as :
  - A process is considered to be in control if all the data points are within the control limits and show a random pattern.
  - A process is considered to be out of control if one or more data points are outside the control limits, or if the data points show a non-random pattern, such as a trend, a cycle, a shift, or a cluster.
  - When a process is out of control, the special causes of variation should be investigated and eliminated, and the process should be brought back to a state of control.
