### Control Charts for Variables (p, np and c charts)

- Control charts are graphical tools that help monitor the quality of a process or product over time.
- Control charts can be classified into two types: variable control charts and attribute control charts.
- Variable control charts are used for continuous data, such as length, weight, temperature, etc. Attribute control charts are used for discrete data, such as defects, errors, failures, etc.
- There are four types of attribute control charts: p chart, np chart, c chart and u chart.
- p chart is used to plot the proportion of defective items in a sample. np chart is used to plot the number of defective items in a sample. c chart is used to plot the number of defects in a sample. u chart is used to plot the average number of defects per unit in a sample.
- The assumptions for attribute control charts are:
  - The samples are independent and randomly selected from the population.
  - The items are either defective or non-defective, or the defects are either present or absent. There is no degree of defectiveness or defect severity.
  - The probability of defect is constant for each item or unit.
- The control limits for attribute control charts are calculated using the following formulas:

  - p chart: UCL = p̅ + zα/2√(p̅(1-p̅)/n), LCL = p̅ - zα/2√(p̅(1-p̅)/n), where p̅ is the average proportion of defectives, n is the sample size, and zα/2 is the z-score for the desired confidence level.
  - np chart: UCL = np̅ + zα/2√(np̅(1-p̅)), LCL = np̅ - zα/2√(np̅(1-p̅)), where np̅ is the average number of defectives, and the other terms are the same as above.
  - c chart: UCL = c̅ + zα/2√(c̅), LCL = c̅ - zα/2√(c̅), where c̅ is the average number of defects, and the other terms are the same as above.
  - u chart: UCL = u̅ + zα/2√(u̅/n), LCL = u̅ - zα/2√(u̅/n), where u̅ is the average number of defects per unit, n is the average sample size, and the other terms are the same as above.

- To construct an attribute control chart, the following steps are followed:
  - Collect data in subgroups or samples over time.
  - Calculate the proportion, number or average of defectives or defects for each sample.
  - Plot the data points on the chart and connect them with a line.
  - Calculate the center line and the control limits using the formulas above.
  - Draw the center line and the control limits on the chart.
  - Analyze the chart for any patterns or signals of variation that indicate the process is out of control.

- Some examples of attribute control charts are:

  - p chart for the proportion of defective products in a manufacturing process.
  - np chart for the number of defective light bulbs in a batch.
  - c chart for the number of scratches on a car body.
  - u chart for the number of errors per page in a document.
