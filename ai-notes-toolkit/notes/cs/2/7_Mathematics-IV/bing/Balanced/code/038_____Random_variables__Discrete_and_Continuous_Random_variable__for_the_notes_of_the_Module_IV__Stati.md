### Random variables (Discrete and Continuous Random variable)

- A random variable is a variable that is used to denote the numerical outcome of a random experiment. For example, the number of heads in 10 coin tosses is a random variable.
- Random variables can be classified into two types: discrete and continuous.
- A discrete random variable can take only a finite or countable number of values. For example, the number of students in a class is a discrete random variable, as it can only take integer values from 0 to the maximum class size.
- A continuous random variable can take any value in a given interval. For example, the height of a person is a continuous random variable, as it can take any value between 0 and the maximum possible height.
- The probability distribution of a random variable describes how likely each possible value is. For discrete random variables, the probability distribution is given by a probability mass function (PMF), which assigns a probability to each possible value. For continuous random variables, the probability distribution is given by a probability density function (PDF), which assigns a probability to each interval of values.
- Some examples of discrete random variables are:
  - A binomial random variable, which counts the number of successes in a fixed number of independent trials with the same probability of success. For example, the number of heads in 10 coin tosses is a binomial random variable with 10 trials and a probability of success of 0.5 for each trial.
  - A Poisson random variable, which counts the number of events that occur in a fixed interval of time or space with a constant average rate. For example, the number of cars that pass through a toll booth in an hour is a Poisson random variable with an average rate of 20 cars per hour.
- Some examples of continuous random variables are:
  - A uniform random variable, which has a constant probability over a given interval. For example, the time it takes to finish a multiple-choice question is a uniform random variable between 0 and 2 minutes.
  - A normal random variable, which has a bell-shaped probability distribution that is symmetric around the mean and decreases as the value moves away from the mean. For example, the IQ score of a person is a normal random variable with a mean of 100 and a standard deviation of 15.
