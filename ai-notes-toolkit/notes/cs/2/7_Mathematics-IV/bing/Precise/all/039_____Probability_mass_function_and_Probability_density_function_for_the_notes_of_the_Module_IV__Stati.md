### Probability mass function and Probability density function

- A **probability mass function (pmf)** is a function that gives the probability of a discrete random variable being equal to a particular value.
- The pmf is defined for discrete random variables, where the set of possible outcomes is countable.
- The pmf must satisfy two conditions:
  1. The probability of each possible outcome must be between 0 and 1, inclusive.
  2. The sum of the probabilities of all possible outcomes must equal 1.
- An example of a discrete random variable is the number of heads that come up when flipping a coin three times. The possible outcomes are 0, 1, 2, and 3 heads, and the pmf would give the probability of each of these outcomes occurring.

- A **probability density function (pdf)** is a function that describes the probability of a continuous random variable falling within a particular range of values.
- The pdf is defined for continuous random variables, where the set of possible outcomes is uncountable.
- The pdf must satisfy two conditions:
  1. The probability of any single outcome must be 0, since there are an infinite number of possible outcomes.
  2. The integral of the pdf over the entire range of possible outcomes must equal 1.
- An example of a continuous random variable is the time it takes for a particular machine to complete a task. The pdf would describe the probability of the machine taking between a certain range of times to complete the task.
