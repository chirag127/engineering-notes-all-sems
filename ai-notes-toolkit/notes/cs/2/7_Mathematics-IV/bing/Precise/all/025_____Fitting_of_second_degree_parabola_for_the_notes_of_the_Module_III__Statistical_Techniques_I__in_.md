# Fitting of Second Degree Parabola

Fitting of second degree parabola is a statistical technique used to find the best fit parabola for a given set of data points. This technique is used in Module III: Statistical Techniques I of the subject Mathematics-IV KCS.

Here are the steps to fit a second degree parabola to a given set of data points:

1. Collect the data points and plot them on a graph.
2. Calculate the values of the sums: Σx, Σy, Σx^2, Σx^3, Σx^4, and Σxy.
3. Use these sums to form the normal equations for the parabola of the form y = ax^2 + bx + c.
4. Solve the normal equations to find the values of a, b, and c.
5. Use the values of a, b, and c to plot the parabola on the graph.
