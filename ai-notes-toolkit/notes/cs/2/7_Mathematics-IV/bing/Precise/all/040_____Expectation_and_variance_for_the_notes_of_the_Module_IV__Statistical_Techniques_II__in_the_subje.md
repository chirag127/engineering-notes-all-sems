# Expectation and Variance

## Expectation

The expectation or expected value of a random variable is the weighted average of all possible values that the variable can take on. The weights are the probabilities of the variable taking on the respective values.

The expected value of a discrete random variable X is defined as:

E(X) = ∑[x * P(X=x)]

where the sum is taken over all possible values of X.

The expected value of a continuous random variable X is defined as:

E(X) = ∫[x * f(x) dx]

where f(x) is the probability density function of X.

## Variance

The variance of a random variable is a measure of how spread out the values of the variable are. It is defined as the expected value of the squared deviation of the variable from its mean.

The variance of a random variable X is defined as:

Var(X) = E[(X - E(X))^2]

The standard deviation of a random variable is the square root of its variance.

The variance can also be calculated using the formula:

Var(X) = E(X^2) - (E(X))^2

where E(X^2) is the expected value of the square of X.
