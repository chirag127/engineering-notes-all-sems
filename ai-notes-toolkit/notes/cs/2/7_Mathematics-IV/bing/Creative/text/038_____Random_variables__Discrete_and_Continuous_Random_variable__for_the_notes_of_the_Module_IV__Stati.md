### Random variables (Discrete and Continuous Random variable)

- A random variable is a variable that is used to denote the numerical outcome of a random experiment.
- A random experiment is an experiment whose outcome cannot be predicted with certainty.
- For example, tossing a coin, rolling a die, picking a card from a deck, etc. are random experiments.
- A random variable can be either discrete or continuous, depending on the type of values it can take.
- A discrete random variable can take only a finite or countable number of values .
- For example, the outcome of rolling a die is a discrete random variable, as it can only take one of six possible values: 1, 2, 3, 4, 5, or 6.
- A continuous random variable can take any value in a given interval or range .
- For example, the height of a person is a continuous random variable, as it can take any value between 0 and some maximum value.
- A continuous random variable cannot be measured exactly, but only approximated.
- For example, it would make no sense to find the probability that a person's height is exactly 170 cm, as it might be 170.01234... cm or 169.98765... cm.
