### Classification of linear partial differential equation of second order for the notes of the Module II: Applications of Partial Differential Equations: in the subject of Mathematics-IV KCS.

1. Homogeneous equation: If R(x, y, u, ux, uy) = 0, then the equation is homogeneous.

2. Non-homogeneous equation: If R(x, y, u, ux, uy) ≠ 0, then the equation is non-homogeneous.

3. Elliptic equation: If a11a22 - a12a21 > 0, then the equation is elliptic.

4. Parabolic equation: If a11a22 - a12a21 = 0 and a11 ≠ 0 or a22 ≠ 0, then the equation is parabolic.

5. Hyperbolic equation: If a11a22 - a12a21 < 0, then the equation is hyperbolic.

Where aij are partial derivatives.
