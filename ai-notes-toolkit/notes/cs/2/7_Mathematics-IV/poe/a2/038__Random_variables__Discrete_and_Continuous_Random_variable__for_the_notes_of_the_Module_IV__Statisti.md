### Random variables (Discrete and Continuous Random variable)

- A random variable is a variable whose possible values are numerical outcomes of a random phenomenon.
- Random variables can be classified into two categories:
  - Discrete random variable: A random variable that can take on only specific isolated values. For example, number of heads in a roll of two dice.
  - Continuous random variable: A random variable that can take on any value in an interval. For example, height of students in a class.
- Probability distribution of a random variable describes the probabilities of different outcomes.
  - For discrete random variable, probability distribution is probability mass function.
  - For continuous random variable, probability distribution is probability density function.
- Expected value (mean) and variance are two key parameters to describe the behavior of a random variable. They are defined differently for discrete and continuous random variables.
- Most processes or phenomena in real life can be represented by random variables. Knowledge of random variables is essential to study Statistics and Probability.
