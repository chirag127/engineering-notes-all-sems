### Conditional probability for the notes of the Module IV: Statistical Techniques II: in the subject of Mathematics-IV KCS.

1. Conditional probability: Probability of an event given that another event has already occurred. It is denoted by P(A|B) which is read as "Probability of A given B".
2. Formula: P(A|B) = [P(A and B)] / P(B)
Provided P(B) ≠ 0
3. Independence of events: Two events A and B are said to be independent if P(A|B) = P(A) or P(B|A) = P(B)
i.e. the occurrence of one event does not affect the probability of the other event.
4. Multiplication theorem: For any two events A and B, P(A and B) = P(A) x P(B|A)
Provided P(A) ≠ 0
5. Bayes' theorem: It is used to find the probability of an event A given that another event B has occurred i.e. to find P(A|B).
        P(A|B) = [P(B|A) x P(A)] / P(B)
        Provided P(B) ≠ 0
