### Scheduling Concepts for the notes of the Unit 3 - CPU Scheduling in the subject of Operating system

CPU scheduling is a crucial aspect of operating system design, which aims to improve system performance and ensure that all processes are executed in a fair manner. In this unit, we will discuss some of the key scheduling concepts that are essential for understanding CPU scheduling.

Here are the important scheduling concepts that you need to know:

- **Process:** A process is an executing instance of a program in the operating system. It consists of a code segment (text), data segment, and a stack segment.

- **CPU Burst:** CPU burst is the amount of time that a process spends executing on the CPU before it is blocked by an I/O request or suspended.

- **I/O Burst:** I/O burst is the amount of time that a process spends waiting for an I/O operation to complete before it can resume execution.

- **Scheduling Algorithm:** A scheduling algorithm is a method used by the operating system to determine which process should be executed next on the CPU.

- **Preemptive Scheduling:** Preemptive scheduling is a scheduling algorithm in which the operating system can preempt a running process and allocate the CPU to another process.

- **Non-Preemptive Scheduling:** Non-preemptive scheduling is a scheduling algorithm in which the operating system cannot preempt a running process, and the process must voluntarily release the CPU.

- **CPU Utilization:** CPU utilization is the percentage of time that the CPU is busy executing processes.

- **Throughput:** Throughput is the number of processes that are completed per unit of time.

- **Turnaround Time:** Turnaround time is the amount of time that a process spends in the system from the time it is submitted to the time it is completed.

- **Waiting Time:** Waiting time is the amount of time that a process spends waiting in the ready queue before it is executed.

- **Response Time:** Response time is the amount of time that a process spends waiting for its first CPU burst to start executing.

These are some of the essential concepts that you need to understand to master CPU scheduling. By understanding these concepts, you will be able to analyze and compare different scheduling algorithms and select the most appropriate one for a particular operating system.
