
### Prevention for the Notes of Unit 3 - CPU Scheduling in Operating Systems

1. The operating system must be able to effectively manage the CPU and its resources.
2. CPU scheduling should be done in an efficient manner, so that all processes are completed in a timely manner.
3. CPU scheduling should be done in an orderly manner, so that processes are not interrupted by other processes.
4. The operating system should be able to distinguish between foreground and background processes and prioritize them accordingly.
5. The operating system should be able to detect and prevent deadlocks, which can occur when two or more processes are waiting for a resource that is held by another process.
6. The operating system should be able to detect and prevent starvation, which can occur when a process is not given enough CPU time to complete its task.
7. The operating system should be able to detect and prevent thrashing, which can occur when the CPU is overloaded with processes and is unable to complete any of them.
8. The operating system should be able to detect and prevent resource contention, which can occur when two or more processes are competing for the same resource.
