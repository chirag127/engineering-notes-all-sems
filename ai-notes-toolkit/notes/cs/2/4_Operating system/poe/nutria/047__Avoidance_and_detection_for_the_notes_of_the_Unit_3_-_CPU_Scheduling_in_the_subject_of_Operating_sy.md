
### Avoidance and Detection for the Notes of the Unit 3 - CPU Scheduling in the Subject of Operating System

1. CPU scheduling is the process of determining which process should be executed by the CPU and when. 
2. CPU scheduling is used to improve CPU utilization and to ensure that all processes get a fair share of the CPU's time.
3. There are two main techniques used for CPU scheduling: avoidance and detection. 
4. Avoidance techniques involve preventing a process from using the CPU when it is not needed. Examples of avoidance techniques include priority scheduling, preemptive scheduling, and round-robin scheduling. 
5. Detection techniques involve detecting when a process needs to be removed from the CPU and replaced with a new process. Examples of detection techniques include time-slicing and multiprocessing. 
6. CPU scheduling algorithms can be evaluated based on their ability to optimize CPU utilization, minimize wait time, and provide fairness.
