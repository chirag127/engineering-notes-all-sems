

### Process Identification Information for the Notes of the Unit 3 - CPU Scheduling in the Subject of Operating System

1. Process Identification: A process is an instance of a program that is being executed. A process is identified by a unique process identifier (PID).

2. CPU Scheduling: CPU scheduling is the process of determining which process should be executed by the CPU at any given time. It is also referred to as process scheduling.

3. Scheduling Algorithms: There are various algorithms available for CPU scheduling. Some of the most common algorithms include First Come First Serve (FCFS), Shortest Job First (SJF), Round Robin (RR), and Priority Scheduling.

4. Context Switching: A context switch is the process of switching from one process to another. During a context switch, the state of the current process is saved and the state of the new process is loaded.

5. Preemptive Scheduling: Preemptive scheduling is a scheduling algorithm that allows the CPU to switch from one process to another based on certain criteria such as priority or time quantum.

6. Time Quantum: Time quantum is the amount of time a process is allowed to execute before it is preempted by another process.
