
### Process Transition Diagram for the Notes of Unit 3 - CPU Scheduling in Operating System

1. Process transition diagrams are used to illustrate the various states that a process can go through during its lifetime.

2. A process can transition from one state to another based on various system events, such as a timer interrupt, an I/O request, or a system call.

3. The states of a process are usually divided into three categories: running, ready, and blocked.

4. The running state is when the process is actively using the CPU.

5. The ready state is when a process is waiting for the CPU to become available.

6. The blocked state is when a process is waiting for an I/O operation to complete.

7. CPU scheduling algorithms are used to decide which process should be running at any given time.

8. Scheduling algorithms can be divided into two categories: preemptive and non-preemptive.

9. Preemptive scheduling algorithms allow a process to be interrupted while it is running and replaced by another process.

10. Non-preemptive scheduling algorithms allow a process to run until it has completed its work or has voluntarily yielded the CPU.
