
### Segmentation for the notes of the Unit 4 - Memory Management in the subject of Operating system

1. **Segmentation** is a memory management technique that divides a computer's primary memory into segments or blocks.

2. Each segment is a logical division of the physical memory and is used to store different types of data such as program code, data, or stack.

3. When a program is loaded into memory, the operating system allocates a segment for it and the program is divided into multiple parts, which are then stored in different segments.

4. This technique helps in the efficient utilization of memory and improves the performance of the system.

5. The segments are usually of fixed size and can be of varying sizes.

6. The main advantage of segmentation is that it allows the sharing of memory between different programs.

7. It also helps in reducing the wastage of memory as unused memory can be allocated to other programs.

8. Segmentation also helps in protecting the memory from being corrupted by other programs.

9. The main disadvantage of segmentation is that it increases the complexity of the system and requires more memory for the segmentation table.

10. Segmentation is used in modern operating systems such as Windows and Linux.
