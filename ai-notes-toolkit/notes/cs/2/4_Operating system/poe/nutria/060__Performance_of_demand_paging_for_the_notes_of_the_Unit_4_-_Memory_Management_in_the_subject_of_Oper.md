
### Performance of Demand Paging for Unit 4 - Memory Management in Operating System

- Demand paging is a memory management technique in which pages of memory are loaded into RAM only when they are requested by the operating system.
- This technique is used to reduce the amount of RAM needed for a program, as only the pages that are requested will be loaded into memory.
- Demand paging can improve performance by reducing the amount of time spent waiting for pages to be loaded into memory.
- The operating system keeps track of the pages that are requested and will load them into RAM when they are requested.
- When a page is requested, it is loaded into RAM and any other pages that are needed for the program are also loaded into RAM.
- If a program requests a page that is not in RAM, the operating system will swap out a page that is currently in RAM and replace it with the requested page.
- The operating system will also keep track of the pages that are not being used and will swap them out if they are not requested for a certain period of time.
- Demand paging can improve the performance of a program by reducing the amount of time spent waiting for pages to be loaded into memory.
