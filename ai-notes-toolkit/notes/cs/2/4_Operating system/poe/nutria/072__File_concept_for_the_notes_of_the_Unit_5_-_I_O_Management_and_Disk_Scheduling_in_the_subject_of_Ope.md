
### File Concept for Unit 5 - I/O Management and Disk Scheduling 

1. I/O Management: I/O management is a process in which the operating system manages the input and output operations of a computer system. It is responsible for controlling the flow of data between the CPU and external devices.

2. Disk Scheduling: Disk scheduling is the process of scheduling the order in which disk requests are serviced. It is responsible for deciding which requests should be serviced first, and which can wait. Common disk scheduling algorithms include First Come First Serve (FCFS), Shortest Seek Time First (SSTF), and SCAN.

3. File Concept: A file is a collection of related data stored on a disk. Files are used to store data in a structured way, and can be organized into folders. Files have attributes such as size, type, and permissions.

4. File Access: File access is the process of reading and writing data from and to a file. Access can be sequential, meaning the data is read or written in the same order as it is stored, or random, meaning the data can be read or written in any order.

5. File System: A file system is a set of rules and conventions used to store and organize files on a disk. It is responsible for keeping track of the files on the disk, and providing access to them. Common file systems include FAT, NTFS, and EXT4.
