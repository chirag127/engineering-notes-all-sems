
### File Directories for Unit 5 - I/O Management and Disk Scheduling in Operating System

* I/O Management involves the efficient and effective management of input/output operations. This includes managing the transfer of data between the CPU and external devices, such as disks, printers, and other peripherals.
* Disk scheduling is the process of deciding which requests for I/O operations should be serviced first. Common disk scheduling algorithms include First Come First Serve (FCFS), Shortest Seek Time First (SSTF), and SCAN.
* File systems are used to store and organize data on disks. Common file systems include FAT, NTFS, and EXT.
* Directories are used to organize and structure files within a file system. Directories can contain both files and other directories, and are organized in a hierarchical structure.
* File permissions are used to control access to files and directories. Common permissions include Read, Write, and Execute.
