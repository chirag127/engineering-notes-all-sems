
### Thrashing for the Notes of Unit 4 - Memory Management in the Subject of Operating System

1. **Thrashing** is a phenomenon in which the system spends a large amount of time in swapping pages between main memory and secondary memory, without doing any useful work.

2. Thrashing occurs when the system does not have enough physical memory to accommodate all the processes it needs to run.

3. When the system is thrashing, the CPU utilization is low and the response time is high.

4. Thrashing can be prevented by using memory management techniques such as paging, segmentation, and virtual memory.

5. Paging allows the system to store a process's data in small pieces, or pages, in main memory.

6. Segmentation divides memory into logical segments, each of which contains a group of related instructions and data. 

7. Virtual memory is a technique that uses secondary memory to store parts of a process that are not currently in use.

8. Memory management techniques can also be used to reduce the amount of time spent swapping pages between main memory and secondary memory.
