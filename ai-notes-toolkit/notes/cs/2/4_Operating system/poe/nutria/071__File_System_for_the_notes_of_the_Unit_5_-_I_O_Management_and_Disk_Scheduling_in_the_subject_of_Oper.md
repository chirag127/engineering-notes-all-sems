
### File System for the notes of the Unit 5 - I/O Management and Disk Scheduling in the subject of Operating System

- File systems are responsible for organizing and controlling the storage of data on a computer system.
- I/O management is the process of controlling the input and output of data to and from the system.
- Disk scheduling is the process of determining which requests for data should be serviced first.
- File systems are divided into two main components: the file allocation table (FAT) and the directory structure.
- The FAT is responsible for keeping track of the physical location of files on the disk.
- The directory structure is responsible for organizing and managing the files and directories on the disk.
- Disk scheduling algorithms determine the order in which requests for data should be serviced.
- Common disk scheduling algorithms include first-come-first-served (FCFS), shortest-seek-time-first (SSTF), and elevator (SCAN).
- RAID (Redundant Array of Independent Disks) is a technology that combines multiple disks into a single logical unit.
- RAID provides fault tolerance and improved performance by distributing data across multiple disks.
