### Scheduling Concepts for the notes of the Unit 3 - CPU Scheduling in the subject of Operating system

CPU scheduling is an essential concept in operating systems that determines which process should be executed when the CPU is available. Here are some of the critical scheduling concepts:

- **Process Scheduling:** It is the process of selecting a process from the ready queue and allocating CPU resources to it. The scheduler performs this task in the operating system.

- **Preemptive Scheduling:** In preemptive scheduling, the operating system interrupts the currently executing process and allocates the CPU to another process with a higher priority. The scheduler uses a timer interrupt to perform this task.

- **Non-Preemptive Scheduling:** In non-preemptive scheduling, the currently running process will continue to execute until it voluntarily releases the CPU or completes its execution. The scheduler will only allocate the CPU to another process when the current process completes.

- **CPU-bound Process:** A process that requires a significant amount of CPU time for its execution is called a CPU-bound process. The scheduler must allocate sufficient CPU time to this process to ensure that it completes its execution efficiently.

- **I/O-bound Process:** A process that spends most of its time waiting for I/O operations to complete is called an I/O-bound process. The scheduler must allocate sufficient CPU time to this process to ensure that it can complete its I/O operations efficiently.

- **Burst Time:** It is the amount of time that a process requires to complete its execution before releasing the CPU voluntarily or being preempted by the operating system.

- **Turnaround Time:** It is the time taken by a process to complete its execution from the time it is submitted to the time it finishes its execution.

- **Waiting Time:** It is the time that a process spends waiting in the ready queue before getting allocated to the CPU.

- **Response Time:** It is the time taken by the operating system to respond to an event generated by a process, such as an I/O request or a system call.

- **Scheduling Algorithms:** These are the algorithms used by the scheduler to determine which process should be allocated the CPU next. Some commonly used scheduling algorithms are First-Come-First-Serve (FCFS), Shortest-Job-First (SJF), Round Robin, Priority Scheduling, and Multilevel Queue Scheduling.

Understanding these concepts is crucial for a thorough understanding of CPU scheduling in operating systems. It is essential to note that different scheduling algorithms have different performance metrics and are suitable for different types of processes.
