### File Directories for the Notes of the Unit 5 - I/O Management and Disk Scheduling in the Subject of Operating System

In this unit, we will be discussing the I/O Management and Disk Scheduling in the Operating System. To better understand this topic, we need to know about File Directories. Here are some points to help you understand:

- A File Directory is a database that contains information about all files in a file system.

- It is also known as a File Control Block (FCB), which is a data structure used by the file system to store information about the file.

- The File Directory contains information such as the file name, size, location on the disk, date and time of creation, and date and time of modification.

- The File Directory is organized in a hierarchical structure, which means that it has a parent-child relationship.

- The topmost directory is called the Root Directory, which contains all the other directories and files.

- Each directory can contain subdirectories and files.

- The File Directory is used by the Operating System to locate files when they are requested by a user or an application.

- When a file is created, the Operating System assigns it a unique identifier called an Inode.

- The Inode is used by the File Directory to locate the file on the disk.

- Each Inode contains information about the file, such as its size, location on the disk, and date and time of creation.

- The File Directory is also used by the Operating System to manage disk space.

- When a file is deleted, the Operating System frees up the space occupied by the file and updates the File Directory to reflect the change.

- The File Directory is an essential component of the file system and plays a vital role in the efficient management of files and disk space.

By understanding the File Directory, you will have a better understanding of how the Operating System manages files and disk space.
