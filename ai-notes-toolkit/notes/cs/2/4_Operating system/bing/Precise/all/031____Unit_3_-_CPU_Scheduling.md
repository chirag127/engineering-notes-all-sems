## Unit 3 - CPU Scheduling

CPU scheduling is the process of determining which process in the ready queue is to be allocated the CPU. The main objective of CPU scheduling is to maximize CPU utilization and increase the throughput of the system.

Some of the key points to remember about CPU scheduling are:

1. CPU scheduling is the basis of multiprogramming operating systems.
2. The CPU scheduler selects a process from the ready queue and allocates the CPU to it.
3. The selection process is carried out by the short-term scheduler or the CPU scheduler.
4. The objective of CPU scheduling is to maximize CPU utilization and increase the throughput of the system.
5. There are several CPU scheduling algorithms, each with its own advantages and disadvantages.
6. The choice of a CPU scheduling algorithm depends on the specific requirements of the system.
7. Some of the common CPU scheduling algorithms are First-Come, First-Served (FCFS), Shortest Job First (SJF), Priority Scheduling, and Round Robin (RR) scheduling.
8. CPU scheduling decisions are taken at four different instances: when a process switches from running to waiting state, when a process switches from running to ready state, when a process switches from waiting to ready state, and when a process terminates.
9. The performance of the CPU scheduling algorithm is measured in terms of CPU utilization, throughput, turnaround time, waiting time, and response time.
