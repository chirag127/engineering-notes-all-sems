# Unit 1 - Introduction : Operating system and functions

- An operating system (OS) is a software program that manages the hardware and software resources of a computer.
- The OS performs basic tasks, such as controlling and allocating memory, prioritizing the processing of instructions, controlling input and output devices, facilitating networking and managing files.
- The OS also provides a user interface, such as a graphical user interface (GUI), that allows users to interact with the computer and its applications.
- The OS acts as an intermediary between the user and the hardware, making the computer system convenient and efficient to use.
- The OS can be classified into different types based on various criteria, such as the number of users, the number of tasks, the type of hardware, the type of interface, the degree of control, the distribution of processing and the purpose of use.
- Some examples of common OS are Windows, Linux, MacOS, Android, iOS, etc.
- The main functions of an OS are:

  - Process management: The OS creates and terminates processes, assigns them to the CPU and other resources, schedules their execution, handles synchronization and communication among processes, and handles deadlocks and errors.
  - Memory management: The OS allocates and deallocates memory to processes, manages the virtual and physical memory, implements memory protection and sharing, and handles memory fragmentation and swapping.
  - File management: The OS organizes files and directories on the disk, provides file access and security, implements file operations, such as create, delete, read, write, etc., and manages disk space and performance.
  - Device management: The OS controls the input and output devices, such as keyboard, mouse, monitor, printer, disk, etc., by using device drivers, allocates and deallocates devices to processes, and handles device errors and interrupts.
  - Security and protection: The OS protects the system and the data from unauthorized access, malicious attacks, and accidental damage, by using authentication, encryption, backup, firewall, antivirus, etc.
  - User interface: The OS provides a user-friendly and consistent way of interacting with the system and the applications, by using command-line interface (CLI), graphical user interface (GUI), or touch-based interface.
  - Networking and communication: The OS enables the system to communicate with other systems and devices over a network, by using protocols, such as TCP/IP, HTTP, FTP, etc., and provides services, such as web browsing, email, file transfer, remote access, etc.
