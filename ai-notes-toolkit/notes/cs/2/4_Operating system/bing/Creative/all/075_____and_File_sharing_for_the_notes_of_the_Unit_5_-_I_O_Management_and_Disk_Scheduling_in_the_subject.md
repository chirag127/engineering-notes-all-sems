# Unit 5 - I/O Management and Disk Scheduling

## I/O Management

- I/O management is the process of controlling the input and output devices of a computer system.
- I/O devices can be classified into two categories: block devices and character devices.
- Block devices transfer data in fixed-size blocks, such as disks, tapes, and CD-ROMs.
- Character devices transfer data one byte at a time, such as keyboards, mice, and printers.
- I/O management involves the following components and functions:
  - I/O devices: the physical hardware that performs input and output operations.
  - Device drivers: the software modules that communicate with the I/O devices and provide a uniform interface to the operating system.
  - Device controllers: the hardware components that control the operation of one or more I/O devices.
  - Interrupt handlers: the routines that handle the interrupts generated by the I/O devices when they complete an operation or encounter an error.
  - I/O buffers: the memory areas that store the data to be transferred between the I/O devices and the main memory.
  - I/O scheduling: the algorithm that determines the order and priority of the I/O requests from the processes.
  - I/O performance: the measure of the efficiency and effectiveness of the I/O system.

## Disk Scheduling

- Disk scheduling is the process of deciding which disk request to service next, based on the current position of the disk head and the pending requests in the disk queue.
- Disk scheduling aims to minimize the seek time, which is the time required to move the disk head to the desired track.
- Disk scheduling also aims to maximize the disk throughput, which is the amount of data transferred per unit time.
- Disk scheduling algorithms can be classified into two categories: non-preemptive and preemptive.
- Non-preemptive algorithms service the requests in the order they arrive, without interrupting the current request. Examples of non-preemptive algorithms are:
  - First Come First Served (FCFS): the simplest algorithm that services the requests in the order they arrive, regardless of the disk head position.
  - Shortest Seek Time First (SSTF): the algorithm that services the request that is closest to the current disk head position, minimizing the seek time.
  - SCAN: the algorithm that services the requests in one direction until there are no more requests in that direction, then reverses the direction and repeats the process.
  - C-SCAN: the algorithm that services the requests in one direction until there are no more requests in that direction, then jumps to the other end of the disk and repeats the process in the same direction.
  - LOOK: the algorithm that is similar to SCAN, but changes the direction only when there are no more requests in the current direction, rather than reaching the end of the disk.
  - C-LOOK: the algorithm that is similar to C-SCAN, but jumps to the next request in the opposite direction, rather than the other end of the disk.
- Preemptive algorithms can interrupt the current request if a higher priority request arrives. Examples of preemptive algorithms are:
  - Shortest Remaining Time First (SRTF): the algorithm that services the request that has the shortest remaining seek time, based on the current disk head position and the pending requests.
  - Earliest Deadline First (EDF): the algorithm that services the request that has the earliest deadline, assuming that each request has a deadline associated with it.
  - Priority Scheduling: the algorithm that services the request that has the highest priority, assuming that each request has a priority associated with it.
