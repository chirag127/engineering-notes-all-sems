### System Components for the notes of the Unit 1 - Introduction : Operating system and functions in the subject of Operating system

- A system component is a process, program, utility, or another part of a computer's operating system that helps to manage different areas of the computer.
- An operating system is a large and complex system that can only be created by partitioning into small pieces.
- The main components of an operating system are  :
  - **Process Management**: A process is a program in execution. A process can be suspended temporarily and the execution can be resumed later. Process management involves creating and deleting processes, scheduling CPU time, managing concurrency and synchronization, and handling communication and deadlock issues.
  - **File Management**: A file is a collection of related information which is defined by its creator. Files are used for long-term storage and for both input and output. File management involves creating and deleting files, organizing files into directories, controlling access and security, and managing disk space and fragmentation.
  - **Network Management**: A network is a collection of computers and devices that are connected by communication channels. Network management involves establishing and maintaining network connections, routing and forwarding data packets, handling network errors and congestion, and providing network security and authentication.
  - **Main Memory Management**: Main memory is the primary and fastest storage area in a computer. Main memory management involves allocating and deallocating memory space to processes, managing virtual memory and swapping, and implementing memory protection and sharing.
  - **Secondary Storage Management**: Secondary storage is the non-volatile and permanent storage area in a computer, such as hard disks, flash drives, optical disks, etc. Secondary storage management involves formatting and partitioning disks, managing free space and allocation, and implementing file systems and backup strategies.
  - **I/O Device Management**: I/O devices are the peripherals that allow a computer to interact with the external world, such as keyboards, mice, monitors, printers, scanners, etc. I/O device management involves detecting and configuring devices, managing device drivers, buffering and caching data, and performing error handling and recovery.
  - **Security Management**: Security management involves protecting the computer system and its resources from unauthorized access, modification, or damage. Security management involves implementing encryption and decryption, authentication and authorization, auditing and logging, and firewall and antivirus mechanisms.
  - **Command Interpreter System**: Command interpreter system is the interface between the user and the operating system. It allows the user to enter commands and execute programs, either through a graphical user interface (GUI) or a command-line interface (CLI). Command interpreter system involves parsing and interpreting user input, displaying output and error messages, and providing help and documentation.
