### Protection schemes for the notes of the Unit 4 - Memory Management in the subject of Operating system

- Memory management is the process of allocating and deallocating memory to processes and ensuring efficient and effective use of the available memory resources.
- Memory protection is a mechanism that prevents a process from accessing memory that is not allocated to it or that belongs to another process or the operating system.
- Memory protection is essential for the security, reliability, and performance of the operating system and the processes running on it.
- There are different schemes for implementing memory protection, such as:
  - Base and limit registers: These are hardware registers that store the starting address (base) and the size (limit) of the memory allocated to a process. The CPU checks every memory reference made by the process against these registers and generates an exception if the reference is invalid or out of bounds.
  - Segmentation: This is a scheme that divides the logical address space of a process into variable-sized segments, each with its own base and limit registers. Segmentation allows better access protection than other schemes because memory references are relative to a specific segment and the hardware will not permit the process to access memory not defined for that segment. Segmentation can also support logical organization of the process, such as code, data, stack, etc.
  - Paging: This is a scheme that divides the physical memory into fixed-sized frames and the logical address space of a process into equal-sized pages. The pages are mapped to the frames by a data structure called the page table, which is maintained by the operating system. Paging allows the operating system to allocate memory to a process in non-contiguous frames, which improves memory utilization and reduces external fragmentation. Paging also enables the operating system to implement protection by using flags in the page table entries, such as valid/invalid, read/write, user/kernel, etc.
  - Virtual memory: This is a scheme that extends the concept of paging by allowing the operating system to use secondary storage (such as disk) as an extension of the main memory. Virtual memory allows the operating system to execute processes that are larger than the available physical memory, by swapping pages between the main memory and the disk as needed. Virtual memory also provides protection by using the page table entries to control the access rights and the presence of the pages in the main memory.
