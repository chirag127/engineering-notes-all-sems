### Paging
- Paging is a memory management technique that allows the physical address space of a process to be non-contiguous.
- Paging avoids the problem of external fragmentation by dividing the physical memory into fixed-sized blocks called frames and the logical memory into blocks of the same size called pages.
- When a process is to be executed, its pages are loaded into any available memory frames from their source (disk, for example).
- The hardware maintains a page table for each process, which maps the logical page numbers to the physical frame numbers in memory.
- The logical address generated by the CPU is divided into two parts: a page number and an offset. The page number is used as an index into the page table to find the corresponding frame number. The offset is combined with the frame number to produce the physical address that is sent to the memory unit.
- Paging allows the physical memory to be shared by multiple processes, as each process has its own page table. Paging also allows the use of virtual memory, which is a technique that allows the execution of processes that are not completely in memory.
- Paging has some advantages and disadvantages. Some of the advantages are:
  - It eliminates external fragmentation, as any free frame can be allocated to a process that needs it.
  - It simplifies memory allocation and deallocation, as only the page table needs to be updated.
  - It supports the relocation and protection of processes, as the page table can be modified to change the mapping of logical to physical addresses.
- Some of the disadvantages are:
  - It introduces internal fragmentation, as the pages are of fixed size and a process may not occupy the entire page.
  - It increases the overhead of the system, as the hardware needs to maintain and access the page table for every memory reference.
  - It may cause more page faults, which are situations where the requested page is not in memory and needs to be brought from the disk. Page faults increase the execution time of the process and the disk I/O operations.
