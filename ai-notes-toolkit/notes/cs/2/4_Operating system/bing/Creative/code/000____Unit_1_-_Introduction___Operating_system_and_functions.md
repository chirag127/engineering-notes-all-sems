## Unit 1 - Introduction : Operating system and functions

- An operating system (OS) is a software program that manages the hardware and software resources of a computer.
- The OS performs basic tasks, such as controlling and allocating memory, prioritizing the processing of instructions, controlling input and output devices, facilitating networking and managing files.
- The OS also provides a user interface, such as a graphical user interface (GUI), that allows users to interact with the computer and its applications.
- The OS acts as an intermediary between the user and the hardware, making the computer system convenient and efficient to use.
- The OS can be classified into different types, such as single-user, multi-user, single-tasking, multi-tasking, distributed, embedded, real-time, batch, interactive, etc., depending on the features and functions they provide.
- The main functions of an OS are:

  - Process management: The OS creates and terminates processes, allocates and deallocates resources, schedules and synchronizes processes, handles process communication and coordination, and handles process errors and exceptions.
  - Memory management: The OS manages the main memory and secondary memory, allocates and frees memory space, implements memory protection and sharing, and handles memory swapping and paging.
  - Device management: The OS manages the input and output devices, such as keyboard, mouse, monitor, printer, disk, etc., allocates and frees device controllers, implements device drivers and interrupt handlers, and handles device errors and failures.
  - File management: The OS manages the files and directories, such as creating, deleting, renaming, copying, moving, etc., allocates and frees disk space, implements file access methods and permissions, and handles file errors and security.
  - Network management: The OS manages the network resources, such as routers, switches, hubs, etc., implements network protocols and services, such as TCP/IP, FTP, HTTP, etc., and handles network errors and security.
  - Security management: The OS protects the system from unauthorized access, malicious attacks, viruses, etc., implements authentication, encryption, firewall, etc., and handles security breaches and incidents.
  - User interface: The OS provides a user interface, such as a command-line interface (CLI) or a graphical user interface (GUI), that allows users to interact with the system and its applications, and provides feedback and help.
