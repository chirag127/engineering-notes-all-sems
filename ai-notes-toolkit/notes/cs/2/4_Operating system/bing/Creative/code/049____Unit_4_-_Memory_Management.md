## Unit 4 - Memory Management

Memory management is the process of allocating and deallocating memory to programs and processes in a computer system. Memory management is essential for efficient and secure operation of a computer system, as well as for supporting multitasking, virtualization, and memory protection.

Some of the topics covered in this unit are:

- **Memory hierarchy**: The different levels of memory in a computer system, such as registers, cache, main memory, and secondary memory, and their characteristics, such as speed, size, cost, and volatility.
- **Memory allocation**: The methods of assigning memory to programs and processes, such as static, dynamic, contiguous, and non-contiguous allocation, and their advantages and disadvantages.
- **Memory fragmentation**: The problem of having unused or wasted memory spaces between allocated memory blocks, and the techniques to reduce or eliminate it, such as compaction, coalescing, and defragmentation.
- **Memory paging**: The technique of dividing the physical memory into fixed-sized units called pages, and the logical memory into units called page frames, and mapping them using a page table. Paging allows for non-contiguous allocation, virtual memory, and memory protection.
- **Memory segmentation**: The technique of dividing the logical memory into variable-sized units called segments, and mapping them to the physical memory using a segment table. Segmentation allows for logical organization of memory, protection, and sharing.
- **Virtual memory**: The technique of using secondary memory as an extension of the main memory, and creating the illusion of having more memory than physically available. Virtual memory allows for running larger programs, multiprogramming, and memory protection.
- **Memory protection**: The mechanism of preventing unauthorized or illegal access to memory by programs or processes, and ensuring the integrity and security of data and code. Memory protection can be achieved by using hardware or software techniques, such as base and limit registers, access rights, memory mapping, and encryption.
