### Schedulers for the notes of the Unit 3 - CPU Scheduling in the subject of Operating system

- Schedulers are the components of the operating system that decide which processes should be executed by the CPU and when.
- Schedulers are essential for achieving efficient utilization of the CPU and other system resources, as well as providing fairness and responsiveness to the processes.
- There are three types of schedulers in operating systems: long-term, mid-term, and short-term schedulers  .
- Long-term scheduler (or admission scheduler) is responsible for controlling the degree of multiprogramming, i.e., the number of processes that are present in the ready queue. It selects which processes should be admitted into the system from the pool of new processes. It runs infrequently and may involve complex criteria such as process priority, memory requirements, I/O devices needed, etc. It can also reject some processes to prevent system overload or to enforce security policies.
- Mid-term scheduler (or medium-term scheduler) is responsible for managing the degree of multiprogramming, i.e., the number of processes that are in the main memory. It performs swapping or paging of processes between the main memory and the secondary memory (such as disk) to improve the memory utilization and the mix of CPU-bound and I/O-bound processes. It runs occasionally and may involve criteria such as memory usage, process aging, etc. It can also suspend or resume some processes to balance the system load or to improve the system performance.
- Short-term scheduler (or CPU scheduler) is responsible for selecting the next process to run on the CPU from the ready queue. It allocates the CPU to the process for a small amount of time (called a time slice or a quantum) and then preempts the process if it is not completed or if it is not cooperative. It runs frequently and must be fast and simple. It can involve various criteria such as process priority, CPU burst time, arrival time, etc. It can also implement different scheduling algorithms such as first-come first-served (FCFS), shortest job first (SJF), priority scheduling, round robin (RR), etc.
