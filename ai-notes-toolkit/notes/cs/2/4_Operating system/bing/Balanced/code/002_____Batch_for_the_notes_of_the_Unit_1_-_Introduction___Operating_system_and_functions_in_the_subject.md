### Batch for the notes of the Unit 1 - Introduction : Operating system and functions

- An operating system (OS) is a software that manages the hardware and software resources of a computer system and provides common services for the execution of various applications.
- The main functions of an operating system are:
  - Process management: The OS creates and terminates processes, allocates and deallocates resources, schedules and synchronizes processes, handles inter-process communication and deadlock prevention.
  - Memory management: The OS manages the main memory and secondary memory, allocates and frees memory space, implements paging and segmentation, handles virtual memory and memory protection.
  - File system management: The OS organizes files and directories, provides file access and security, implements file operations and backup, supports different file systems and disk formatting.
  - Device management: The OS controls the input/output devices, allocates and frees device drivers, implements device buffering and spooling, handles device errors and interrupts.
  - User interface: The OS provides a graphical user interface (GUI) or a command-line interface (CLI) for the user to interact with the system, executes user commands and programs, displays system messages and errors.
  - Security: The OS protects the system from unauthorized access, malware, and other threats, implements authentication and encryption, monitors system activities and logs, enforces access control and policies.
  - Networking: The OS enables the system to communicate with other systems over a network, supports various network protocols and services, handles network errors and congestion, implements distributed computing and cloud computing.
