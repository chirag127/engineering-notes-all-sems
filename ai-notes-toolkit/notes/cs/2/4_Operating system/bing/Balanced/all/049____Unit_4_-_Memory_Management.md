## Unit 4 - Memory Management

Memory management is the process of allocating and deallocating memory to programs and processes in a computer system. Memory management ensures that each program and process has enough memory to execute, and that the memory is not wasted or corrupted.

Some of the topics covered in this unit are:

- Memory hierarchy: The different levels of memory in a computer system, such as registers, cache, main memory, and secondary memory. Each level has different characteristics, such as size, speed, cost, and volatility.
- Memory allocation: The methods of assigning memory to programs and processes, such as static, dynamic, and automatic allocation. Static allocation is done at compile time, dynamic allocation is done at run time, and automatic allocation is done by the compiler or the operating system.
- Memory fragmentation: The problem of having unused or wasted memory spaces between allocated memory blocks, which reduces the efficiency and performance of memory management. Memory fragmentation can be internal or external, depending on whether the unused space is within or outside the allocated blocks.
- Memory compaction: The technique of moving allocated memory blocks to reduce or eliminate external fragmentation, and create larger contiguous free memory spaces. Memory compaction can be done by the operating system or by the programs themselves, depending on the memory allocation method used.
- Paging: The technique of dividing the physical memory into fixed-sized units called pages, and the logical memory (or address space) of a program or process into units of the same size called page frames. Paging allows the operating system to map any page frame to any page, and to swap pages in and out of the physical memory as needed.
- Segmentation: The technique of dividing the logical memory of a program or process into variable-sized units called segments, which correspond to logical units of the program, such as functions, data structures, or modules. Segmentation allows the operating system to map any segment to any part of the physical memory, and to provide protection and sharing of segments among different programs or processes.
- Virtual memory: The technique of using secondary memory, such as disk, as an extension of the physical memory, and creating the illusion that the program or process has more memory than the actual available memory. Virtual memory allows the operating system to run programs or processes that are larger than the physical memory, and to multiprogram more efficiently.
- Memory protection: The mechanism of ensuring that each program or process can access only its own allocated memory, and that the memory is not corrupted by other programs or processes. Memory protection can be implemented by hardware or software, and can use techniques such as base and limit registers, access rights, and memory mapping.
- Memory management unit (MMU): The hardware device that translates the logical addresses generated by the CPU into physical addresses that access the memory. The MMU can also perform memory protection, paging, and segmentation functions, depending on the design of the computer system.
