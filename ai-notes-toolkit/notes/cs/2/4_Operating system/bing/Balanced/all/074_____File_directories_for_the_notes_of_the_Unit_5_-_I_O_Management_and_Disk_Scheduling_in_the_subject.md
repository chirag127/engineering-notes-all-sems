# File directories for the notes of the Unit 5 - I/O Management and Disk Scheduling in the subject of Operating system

- A file directory is a data structure that stores information about the files in a file system, such as their names, sizes, permissions, and locations on the disk.
- A file system is a collection of files and directories that are organized in a hierarchical structure, where each directory can contain subdirectories and files.
- A file system provides an interface for users and applications to access, create, modify, and delete files and directories, as well as to manage the disk space and performance.
- A file system can be implemented in different ways, such as using a contiguous allocation, a linked allocation, or an indexed allocation scheme, depending on the trade-offs between speed, space, and reliability.
- A file system can also support different types of files, such as regular files, directories, special files, and symbolic links, depending on the functionality and compatibility required by the operating system and the applications.
- A file system can also implement different types of directories, such as single-level directories, two-level directories, tree-structured directories, acyclic graph directories, and general graph directories, depending on the flexibility and complexity required by the users and the applications.
- A file system can also provide different types of access methods, such as sequential access, direct access, indexed sequential access, and random access, depending on the efficiency and convenience required by the users and the applications.
- A file system can also provide different types of protection mechanisms, such as access control lists, capabilities, passwords, and encryption, depending on the security and privacy required by the users and the applications.
- A file system can also provide different types of consistency and recovery techniques, such as journaling, checkpointing, shadowing, and logging, depending on the robustness and reliability required by the users and the applications.

- I/O management is the process of coordinating and controlling the input and output devices and operations of a computer system, such as keyboards, mice, monitors, printers, disks, and network interfaces.
- I/O management is responsible for providing an abstract and uniform interface for the users and the applications to access and manipulate the I/O devices and data, as well as for managing the performance and efficiency of the I/O subsystem.
- I/O management can be implemented in different ways, such as using a polling, an interrupt-driven, a direct memory access, or an I/O channel approach, depending on the trade-offs between CPU utilization, I/O device utilization, and system throughput.
- I/O management can also support different types of I/O devices, such as block devices, character devices, and network devices, depending on the functionality and compatibility required by the operating system and the applications.
- I/O management can also support different types of I/O operations, such as synchronous I/O, asynchronous I/O, blocking I/O, nonblocking I/O, and buffered I/O, depending on the efficiency and convenience required by the users and the applications.
- I/O management can also support different types of I/O scheduling algorithms, such as first-come first-served, shortest seek time first, scan, circular scan, look, and circular look, depending on the fairness and performance required by the users and the applications.

- Disk scheduling is the process of deciding the order and timing of the disk requests that are issued by the I/O subsystem to the disk controller and the disk drive.
- Disk scheduling is important for improving the performance and efficiency of the disk operations, as well as for reducing the wear and tear of the disk components.
- Disk scheduling can be influenced by various factors, such as the number and size of the disk requests, the seek time, the rotational latency, the transfer time, the disk geometry, the disk head movement, and the disk cache.
- Disk scheduling can also be implemented using different algorithms, such as first-come first-served, shortest seek time first, scan, circular scan, look, and circular look, depending on the trade-offs between fairness, performance, and complexity.
