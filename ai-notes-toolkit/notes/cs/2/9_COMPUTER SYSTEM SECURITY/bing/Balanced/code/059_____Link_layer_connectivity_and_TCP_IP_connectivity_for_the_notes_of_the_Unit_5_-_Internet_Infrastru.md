### Link layer connectivity and TCP IP connectivity

- The link layer is the lowest layer of the TCP/IP model, which is a simplified version of the OSI model.
- The link layer is responsible for sending and receiving data frames over a physical medium, such as a cable or a wireless channel.
- The link layer also provides error detection, flow control, and media access control for the data frames.
- The link layer is sometimes called the network access layer or the network interface layer, as it connects the network layer (IP) to the physical layer.
- The link layer protocols vary depending on the type and topology of the network, such as Ethernet, Wi-Fi, PPP, etc.
- The link layer can be divided into two sublayers: the logical link control (LLC) and the media access control (MAC).
- The LLC sublayer provides a common interface for the network layer protocols, such as IP, and handles multiplexing, error control, and flow control.
- The MAC sublayer deals with the physical addressing of the devices, the access to the shared medium, and the transmission of the data frames.
- The link layer addresses are usually 48-bit or 64-bit numbers, also known as MAC addresses, that are unique for each device on the network.
- The link layer connectivity is established when two devices on the same network segment can exchange data frames using their MAC addresses.
- The network layer (IP) is the second layer of the TCP/IP model, which is responsible for routing packets across different networks.
- The network layer provides logical addressing, fragmentation, and encapsulation for the packets.
- The network layer protocols include IP, ICMP, ARP, RARP, etc.
- The network layer addresses are usually 32-bit or 128-bit numbers, also known as IP addresses, that identify the source and destination of the packets.
- The network layer connectivity is established when two devices on different network segments can exchange packets using their IP addresses.
