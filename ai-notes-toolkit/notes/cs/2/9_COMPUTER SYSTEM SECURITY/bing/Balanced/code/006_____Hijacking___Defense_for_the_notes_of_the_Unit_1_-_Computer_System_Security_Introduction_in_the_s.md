### Hijacking & Defense

- Hijacking is a type of network security attack in which the attacker takes control of computer systems, software programs and/or network communications  .
- Hijacking can be used to steal data, compromise the system, disrupt the service, impersonate the user, or perform malicious actions on behalf of the hijacker.
- Hijacking can occur in various ways, such as:
  - Session hijacking: the attacker intercepts and takes over an existing network session between two parties, such as a web browser and a web server.
  - DNS hijacking: the attacker redirects the domain name resolution requests to a malicious server, which can lead to phishing, malware infection, or censorship.
  - IP hijacking: the attacker announces false routing information to the network, which can cause traffic diversion, blackholing, or denial-of-service.
  - Browser hijacking: the attacker modifies the settings or installs malicious extensions on the user's web browser, which can change the homepage, redirect the search engine, display unwanted ads, or spy on the user's activity.
  - Ransomware: the attacker encrypts the user's data or locks the user's system, and demands a ransom for the decryption key or the unlock code.
- Defense against hijacking can involve various techniques, such as:
  - Encryption: the use of cryptographic algorithms to protect the data from unauthorized access or modification.
  - Authentication: the use of passwords, tokens, biometrics, or certificates to verify the identity of the parties involved in a communication.
  - Authorization: the use of access control policies to grant or deny permissions to the resources or actions on a system.
  - Integrity: the use of checksums, hashes, or digital signatures to ensure the data has not been tampered with.
  - Firewall: the use of hardware or software devices to filter the incoming and outgoing network traffic based on predefined rules.
  - Antivirus: the use of software programs to detect and remove malicious code from the system.
  - Update: the use of patches or upgrades to fix the vulnerabilities or bugs in the system or software.
