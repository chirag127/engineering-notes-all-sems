### Security interface for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

- The Security Interface Framework is a set of Objective-C classes that provide user interface elements for programs that implement security features such as authorization, access to digital certificates, and access to items in keychains.
- Secure architecture principles are the guidelines and best practices for designing and implementing secure systems. Some of the common principles are:
  - Isolation: The principle of isolation states that different components or layers of a system should be separated and isolated from each other, so that a compromise or failure of one component does not affect the others. Isolation can be achieved by using different processes, machines, networks, or domains .
  - Least privilege: The principle of least privilege states that each user or process should be given the minimum amount of privileges or permissions necessary to perform their tasks, and no more. This reduces the attack surface and the potential damage of a breach or misuse .
- Web security landscape is the overview of the threats and challenges faced by web applications and services, and the solutions and countermeasures to mitigate them. Some of the web security definitions and goals are:
  - Confidentiality: The property that ensures that the data or communication is not disclosed to unauthorized parties or intercepted by malicious actors.
  - Integrity: The property that ensures that the data or communication is not modified, corrupted, or tampered with by unauthorized parties or malicious actors.
  - Availability: The property that ensures that the data or service is accessible and usable by authorized parties or legitimate users when needed.
  - Authentication: The process of verifying the identity of a user or a system that requests access to a resource or a service.
  - Authorization: The process of granting or denying access to a resource or a service based on the identity and privileges of a user or a system.
  - Non-repudiation: The property that ensures that the origin and the content of a data or communication can be proven and verified, and that the sender or the receiver cannot deny their involvement .
