## Unit 1 - Computer System Security Introduction

Computer system security is the protection of computer systems and information from harm, theft, and unauthorized use. It is the process of preventing and detecting unauthorized use of your computer system . It also involves the design and implementation of secure computer systems, based on recent research papers.

Some of the components of a computer system that need to be protected are:

- Hardware: the physical part of the computer, like the system memory and disk drive.
- Firmware: permanent software that is etched into a hardware device’s nonvolatile memory and is mostly invisible to the user.
- Software: the programming code that runs on the computer, like the operating system, applications, and utilities.
- Data: the information that is stored and processed by the computer, like the files, databases, and network traffic.

Some of the threats to computer system security are :

- Malware: malicious software that can infect, damage, or control a computer system, like viruses, worms, trojans, ransomware, spyware, etc.
- Phishing: fraudulent emails or websites that trick users into revealing their personal or financial information, or downloading malware.
- Denial-of-service: attacks that overwhelm a computer system or network with requests, making it unavailable or slow for legitimate users.
- Man-in-the-middle: attacks that intercept and alter the communication between two parties, like eavesdropping, tampering, or impersonating.
- Password cracking: attacks that try to guess or steal the passwords of users or administrators, using brute force, dictionary, or social engineering methods.
- Data breaches: unauthorized access or disclosure of sensitive or confidential data, like personal, financial, or health information.

Some of the techniques for achieving computer system security are:

- Cryptography: the science of encrypting and decrypting data, using mathematical algorithms and keys, to ensure confidentiality, integrity, and authenticity.
- Authentication: the process of verifying the identity of a user or a device, using passwords, tokens, biometrics, or certificates.
- Authorization: the process of granting or denying access to resources or actions, based on the identity and privileges of a user or a device.
- Access control: the mechanism of enforcing authorization policies, using rules, roles, permissions, or attributes.
- Firewalls: devices or software that filter the network traffic, allowing or blocking packets based on predefined criteria, like source, destination, port, or protocol.
- Intrusion detection and prevention: systems or software that monitor and analyze the network or system activity, looking for signs of malicious or anomalous behavior, and taking actions to stop or mitigate them.
