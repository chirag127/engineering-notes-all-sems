## Unit 5 - Internet Infrastructure

- Internet infrastructure is the physical hardware, transmission media, and software used to interconnect computers and users on the Internet.
- Internet infrastructure is responsible for hosting, storing, processing, and serving the information that makes up websites, applications, and content.
- Internet infrastructure is a network of networks, composed of different types and levels of networks that connect in various ways.
- The main components of Internet infrastructure are:
  - End devices, such as computers, smartphones, tablets, etc. that send and receive data over the Internet.
  - Network access devices, such as modems, routers, switches, etc. that connect end devices to the Internet service providers (ISPs).
  - ISPs, such as cable, DSL, fiber, satellite, etc. that provide access to the Internet backbone.
  - Internet backbone, which is a network of high-speed fiber-optic cables and routers that carry data across the world.
  - Internet exchange points (IXPs), which are physical locations where different ISPs exchange traffic with each other.
  - Domain name system (DNS), which is a distributed database that maps domain names to IP addresses.
  - Web servers, which are computers that host and deliver web pages and other content to end devices.
  - Web browsers, which are software applications that request and display web pages and other content from web servers.
- The Internet is different from the Web, which is a service built on top of the Internet infrastructure.
- The Web uses a protocol called hypertext transfer protocol (HTTP) to communicate between web servers and web browsers.
- The Web uses a format called hypertext markup language (HTML) to structure and present web pages and other content.
- The Web uses a system called uniform resource locator (URL) to identify and locate web pages and other content on the Internet.
- The Internet also supports other services, such as email, instant messaging, voice over IP, file sharing, etc. that use different protocols and formats.
- The Internet is constantly evolving and expanding, with new technologies and initiatives to improve its performance, security, accessibility, and affordability.
