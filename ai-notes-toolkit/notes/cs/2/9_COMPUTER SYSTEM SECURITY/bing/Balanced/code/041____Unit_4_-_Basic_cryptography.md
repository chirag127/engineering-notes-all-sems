## Unit 4 - Basic cryptography

Cryptography is the science of securing information by transforming it into a form that only the intended recipients can understand. Cryptography has many applications, such as:

- Protecting the confidentiality, integrity, and authenticity of data in transit and at rest
- Enabling secure communication and transactions over the internet
- Providing digital signatures, encryption, and decryption services
- Implementing access control and authentication mechanisms
- Supporting cryptographic protocols and algorithms

Some basic concepts and terms in cryptography are:

- Plaintext: The original message or data that is to be encrypted or decrypted
- Ciphertext: The transformed message or data that results from encryption or decryption
- Encryption: The process of converting plaintext into ciphertext using a secret key and an algorithm
- Decryption: The process of converting ciphertext back into plaintext using the same or a different secret key and an algorithm
- Key: A piece of information that is used to encrypt or decrypt data
- Algorithm: A set of rules or steps that define how to encrypt or decrypt data
- Symmetric cryptography: A type of cryptography where the same key is used for both encryption and decryption
- Asymmetric cryptography: A type of cryptography where different keys are used for encryption and decryption
- Public key cryptography: A type of asymmetric cryptography where one key is public and can be shared with anyone, and the other key is private and kept secret by the owner
- Hash function: A mathematical function that maps any input to a fixed-length output, such that it is easy to compute the output given the input, but hard to find the input given the output, or to find two inputs that produce the same output
- Digital signature: A way of verifying the identity and integrity of a message or document, by using a private key to generate a unique value that can be verified by anyone using the corresponding public key
- Certificate authority: A trusted entity that issues and manages digital certificates, which are documents that bind a public key to an identity or a domain name
- Cryptanalysis: The art and science of breaking cryptographic systems, by finding weaknesses in the algorithms, keys, or protocols
- Cryptographic attack: A method or technique of cryptanalysis that exploits a vulnerability or flaw in a cryptographic system, such as brute force, ciphertext-only, known-plaintext, chosen-plaintext, chosen-ciphertext, or side-channel attacks
