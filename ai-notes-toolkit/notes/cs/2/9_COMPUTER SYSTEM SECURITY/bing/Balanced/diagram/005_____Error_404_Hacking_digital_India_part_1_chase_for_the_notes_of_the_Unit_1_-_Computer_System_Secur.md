## Computer System Security

- Computer system security is the protection of computer systems and networks from unauthorized access, modification, disruption, or destruction.
- Computer system security aims to ensure the confidentiality, integrity, and availability of data and resources in a computer system.
- Computer system security involves various aspects, such as cryptography, authentication, access control, firewalls, intrusion detection and prevention, malware analysis and defense, and security policies and standards.

## Threats and Attacks

- A threat is a potential source of harm to a computer system or network, such as a malicious actor, a natural disaster, or a hardware failure.
- An attack is an attempt to exploit a vulnerability in a computer system or network to cause harm or gain unauthorized access.
- Attacks can be classified into two types: passive and active.
  - Passive attacks are those that do not alter the data or resources in a computer system or network, but only observe or analyze them, such as eavesdropping, traffic analysis, or reconnaissance.
  - Active attacks are those that modify or destroy the data or resources in a computer system or network, such as denial-of-service, spoofing, tampering, or malware infection.

## Security Goals and Services

- The main goals of computer system security are to provide the following properties for data and resources in a computer system or network:
  - Confidentiality: the property that data or resources are not disclosed to unauthorized parties.
  - Integrity: the property that data or resources are not modified or corrupted by unauthorized parties.
  - Availability: the property that data or resources are accessible and usable by authorized parties when needed.
- The main services of computer system security are to provide the following functions to achieve the security goals:
  - Encryption: the process of transforming data into an unintelligible form using a secret key, so that only authorized parties can decrypt it using the same or a different key.
  - Authentication: the process of verifying the identity or legitimacy of a party or a message, using a secret or a public key, a password, a biometric feature, or a token.
  - Authorization: the process of granting or denying access rights to data or resources based on the identity, role, or policy of a party.
  - Non-repudiation: the process of providing proof that a party or a message is authentic and cannot be denied by the party or the sender.
  - Auditing: the process of recording and analyzing the activities and events in a computer system or network for security purposes.
