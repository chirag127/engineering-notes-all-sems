# Web security definitions, goals and threat models

## Web security definition

Web security is the practice of protecting web applications and web servers from unauthorized access, modification, or damage by malicious actors. Web security aims to ensure the confidentiality, integrity, and availability of web resources and data.

## Web security goals

The main goals of web security are:

- To prevent unauthorized access to web resources and data, such as user accounts, databases, files, etc.
- To prevent unauthorized modification or manipulation of web resources and data, such as injecting malicious code, altering content, etc.
- To prevent unauthorized damage or destruction of web resources and data, such as deleting files, crashing servers, etc.
- To ensure the availability and performance of web resources and data, such as minimizing downtime, optimizing speed, etc.

## Web security threat models

A web security threat model is a structured process for identifying and assessing the potential threats and vulnerabilities that may affect a web application or a web server, and prioritizing the appropriate countermeasures to mitigate or eliminate them. A web security threat model typically involves the following steps:

- Define the scope and boundaries of the web application or server, such as the components, interfaces, data flows, etc.
- Identify the assets and data that need to be protected, such as user credentials, personal information, financial transactions, etc.
- Identify the potential adversaries and their capabilities, motivations, and goals, such as hackers, cybercriminals, competitors, etc.
- Identify the potential threats and attack vectors that may exploit the vulnerabilities of the web application or server, such as SQL injection, cross-site scripting, denial-of-service, etc.
- Assess the likelihood and impact of each threat, and assign a risk rating based on the severity and probability of occurrence, such as high, medium, low, etc.
- Identify the existing or potential countermeasures that can prevent or reduce the risk of each threat, such as encryption, authentication, authorization, validation, etc.
- Prioritize the countermeasures based on the cost, benefit, and feasibility of implementation, and document the recommendations and action plans.

There are different methods and frameworks for conducting web security threat modeling, such as STRIDE, DREAD, OCTAVE, etc. Each method has its own advantages and disadvantages, and may suit different scenarios and contexts. The choice of the method depends on the goals, resources, and preferences of the web security team.
