### Packet filtering firewall

- A packet filtering firewall is the most basic type of firewall that controls data flow to and from a network .
- It is a network security solution that allows network packets to move across between networks and controls their flow using a set of user-defined rules, IP addresses, ports, and protocols .
- A packet filtering firewall can be implemented as a standalone device or as a part of a router.
- A packet filtering firewall examines each packet, which comprises user data and control information, and tests them according to a set of pre-established rules.
- The rules can be based on the source and destination IP addresses, the source and destination ports, and the protocol used by the packet .
- The packet filtering firewall can either accept, reject, or drop the packet based on the rules .
- The packet filtering firewall can also log the packets that are accepted or rejected for auditing purposes.
- A packet filtering firewall is a low-level network security feature that operates in the network layer of the OSI model .
- A packet filtering firewall is easy to implement and has low overhead and high performance .
- However, a packet filtering firewall also has some limitations and drawbacks, such as  :
  - It cannot inspect the content or the application layer data of the packets.
  - It cannot prevent attacks that use valid IP addresses, ports, and protocols.
  - It cannot prevent spoofing, fragmentation, or encryption attacks.
  - It cannot handle stateful or dynamic connections that use random ports or protocols.
  - It can be difficult to configure and maintain the rules and policies.
