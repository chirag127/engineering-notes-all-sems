### DNS revisited for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

- DNS stands for Domain Name System.
- DNS is a technical cornerstone of the Internet, but it faces significant challenges in growth and security.
- The Internet depends on DNS; when it doesn't work, neither does the Internet.
- DNS allows you to interact with devices on the Internet without having to remember long strings of numbers.
- Each computer on the Internet has its own unique address, known as an IP address.
- DNS translates domain names to IP addresses so browsers can load Internet resources.
