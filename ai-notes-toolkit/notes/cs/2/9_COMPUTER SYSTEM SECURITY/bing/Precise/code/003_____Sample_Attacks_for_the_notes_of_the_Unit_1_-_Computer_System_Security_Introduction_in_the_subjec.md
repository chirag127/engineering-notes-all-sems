### Sample Attacks for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY

1. **Phishing:** This is a type of attack where attackers send fraudulent emails or create fake websites to trick users into revealing their personal information, such as login credentials or credit card numbers.

2. **Malware:** Malware is a type of software designed to harm or exploit any device, network, or service. Examples of malware include viruses, worms, Trojan horses, and spyware.

3. **Man-in-the-middle (MitM) attack:** This is a type of attack where an attacker intercepts communication between two parties to eavesdrop or alter the communication.

4. **Denial-of-service (DoS) attack:** This is a type of attack where an attacker floods a network or server with traffic to overwhelm it and make it unavailable to users.

5. **SQL injection:** This is a type of attack where an attacker inserts malicious code into a SQL statement to manipulate a database and gain unauthorized access to data.

6. **Cross-site scripting (XSS):** This is a type of attack where an attacker injects malicious code into a website, which is then executed by the user's browser, allowing the attacker to steal sensitive information or manipulate the user's interaction with the website.

7. **Brute-force attack:** This is a type of attack where an attacker tries to guess a user's password by trying many different combinations until the correct one is found.

8. **Zero-day exploit:** This is a type of attack where an attacker exploits a previously unknown vulnerability in a software or system to gain unauthorized access or perform malicious actions.

These are some common types of attacks that can compromise the security of computer systems. It is important to be aware of these threats and take appropriate measures to protect against them.
