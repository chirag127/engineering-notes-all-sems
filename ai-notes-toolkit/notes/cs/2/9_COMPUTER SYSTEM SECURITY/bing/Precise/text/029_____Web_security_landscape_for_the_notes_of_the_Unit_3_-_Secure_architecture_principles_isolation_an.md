### Web security landscape for the notes of the Unit 3 - Secure architecture principles isolation and least privilege in the subject of COMPUTER SYSTEM SECURITY

- Secure architecture principles include isolation and least privilege access.
- Isolation and least privilege are part of the principles of secure design, which also include compartmentalization, defense in depth, and keeping it simple.
- The principle of least privilege is about controlling access to resources in a computing environment.
- Defense in depth involves using more than one security mechanism, securing the weakest link, and failing securely.
- Applying these principles can increase the likelihood that your security architecture assures confidentiality, integrity, and availability.
- Reducible permissions pose a vertical privilege escalation security risk, which can be exploited for unauthorized access to data or to perform operations not normally allowed.
