### Cookies, Frames, and Frame Busting

#### Cookies
- Cookies are small text files that are stored on a user's computer by a website.
- They are used to store information about the user's activity on the website, such as login information, preferences, and browsing history.
- Cookies can be used to track user behavior and deliver personalized content.
- However, cookies can also pose a security risk if they are not handled properly. For example, if a cookie contains sensitive information, it could be intercepted by an attacker.

#### Frames
- Frames are a way to divide a web page into multiple sections, each of which can display content from a different source.
- Frames can be used to display content from different websites on the same page, which can be useful for creating mashups or aggregating content.
- However, frames can also pose a security risk. For example, if a frame displays content from an untrusted source, it could be used to execute malicious code or steal user information.

#### Frame Busting
- Frame busting is a technique used to prevent a web page from being displayed within a frame.
- This is done by using JavaScript to check if the current page is being displayed within a frame, and if so, redirecting the user to the top-level page.
- Frame busting is used to prevent clickjacking attacks, where an attacker overlays a transparent frame over a legitimate web page to trick the user into clicking on something they did not intend to.
- Frame busting is an important security measure for websites that handle sensitive information, such as login pages or online banking sites.
