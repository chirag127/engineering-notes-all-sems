### Control Hijacking
Control hijacking is a type of computer attack where an attacker gains control over the flow of execution of a program. This is typically done by exploiting a vulnerability in the program, such as a buffer overflow, to overwrite the return address on the stack. Once the attacker has control over the flow of execution, they can execute arbitrary code, potentially causing harm to the system or stealing sensitive information.

Some key points to remember about control hijacking are:
- It is a type of computer attack where an attacker gains control over the flow of execution of a program.
- It is typically done by exploiting a vulnerability in the program, such as a buffer overflow.
- Once the attacker has control over the flow of execution, they can execute arbitrary code.
- This can potentially cause harm to the system or steal sensitive information.
