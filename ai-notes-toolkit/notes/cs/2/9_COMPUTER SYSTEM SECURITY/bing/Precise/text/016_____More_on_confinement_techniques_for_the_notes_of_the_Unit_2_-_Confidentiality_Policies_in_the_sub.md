### More on confinement techniques for the notes of the Unit 2 - Confidentiality Policies in the subject of COMPUTER SYSTEM SECURITY

Confinement techniques are used to ensure that information is only accessed by authorized users and processes. These techniques are essential in maintaining the confidentiality of sensitive information in computer systems. Some of the confinement techniques used in computer system security include:

1. **Access Control Lists (ACLs):** An ACL is a list of permissions attached to an object, such as a file or a directory, that specifies which users or processes are allowed to access the object and what operations they can perform on it.

2. **Role-Based Access Control (RBAC):** RBAC is a method of regulating access to computer resources based on the roles of individual users within an organization. In RBAC, permissions are assigned to roles rather than individual users, and users are assigned to roles based on their job functions.

3. **Mandatory Access Control (MAC):** MAC is a type of access control in which the operating system enforces a security policy that determines who can access which resources. In MAC, the system assigns security labels to all objects and users, and access decisions are based on these labels.

4. **Discretionary Access Control (DAC):** DAC is a type of access control in which the owner of an object, such as a file or a directory, has the discretion to decide who can access the object and what operations they can perform on it.

5. **Encryption:** Encryption is the process of encoding information in such a way that only authorized parties can access it. Encryption can be used to protect the confidentiality of information stored on a computer or transmitted over a network.

These are some of the confinement techniques used in computer system security to ensure the confidentiality of sensitive information. It is important to understand and implement these techniques to maintain the security of computer systems.
