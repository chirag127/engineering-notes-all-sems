## Unit 4 - Basic Cryptography

Cryptography is the practice of secure communication in the presence of third parties. It involves techniques for secure communication, data integrity, and authentication.

1. **Encryption** is the process of converting plaintext into ciphertext, which is unreadable without the key to decrypt it.
2. **Decryption** is the reverse process of encryption, where ciphertext is converted back into plaintext using the key.
3. **Symmetric-key cryptography** uses the same key for both encryption and decryption.
4. **Asymmetric-key cryptography** uses a public key for encryption and a private key for decryption.
5. **Hash functions** are used to ensure data integrity by generating a fixed-size output from an input of arbitrary size.
6. **Digital signatures** are used to authenticate the sender of a message and to ensure the message has not been tampered with.
