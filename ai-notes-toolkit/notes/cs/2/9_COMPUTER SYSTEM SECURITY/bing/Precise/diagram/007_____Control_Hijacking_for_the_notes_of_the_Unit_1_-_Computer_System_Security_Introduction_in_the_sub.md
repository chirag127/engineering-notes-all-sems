### Control Hijacking

Control hijacking is a type of attack that exploits a program error, particularly a memory corruption vulnerability, at application runtime to subvert the intended control flow of a program. Control-hijacking attacks are also known as Control-flow hijacking attacks.

- In a control hijacking attack, the attacker's goal is to take control over the target machine (such as a web server) and execute arbitrary code on the target machine by hijacking the control flow of the program.

- A variety of defensive mechanisms have been proposed to mitigate control-flow hijacking attacks.

- Hijacking can also refer to a type of network security attack in which the attacker takes control of a communication between two entities and masquerades as one of them.
