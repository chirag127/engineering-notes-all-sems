### Unix and Windows Access Control Summary

#### Unit 3 - Secure Architecture Principles: Isolation and Least Privilege

- **Access control** is the process of granting or denying specific requests to obtain and use information and related information processing services.

- **Unix** and **Windows** are two popular operating systems that implement access control mechanisms to protect the confidentiality, integrity, and availability of data.

- **Unix** access control is based on the concept of users and groups. Each file and directory has an owner and a group, and the system uses a set of permissions to determine who can read, write, or execute the file.

- **Windows** access control is based on the concept of access control lists (ACLs). An ACL is a list of access control entries (ACEs) that define the permissions for a specific user or group.

- **Isolation** is a key principle in secure architecture. It involves separating system components or processes to limit the potential damage that can be caused by a security breach.

- **Least privilege** is another important principle in secure architecture. It involves granting users and processes only the minimum level of access necessary to perform their tasks.

- Both Unix and Windows implement mechanisms to support isolation and least privilege, such as user accounts, file permissions, and process isolation.

- It is important to properly configure access control settings in both Unix and Windows systems to ensure the security of data and system resources.
