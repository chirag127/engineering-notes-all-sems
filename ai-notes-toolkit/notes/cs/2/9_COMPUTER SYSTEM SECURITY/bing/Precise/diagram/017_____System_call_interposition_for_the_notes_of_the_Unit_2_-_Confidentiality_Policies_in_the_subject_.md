### System Call Interposition

System call interposition is a powerful method for regulating and monitoring program behavior. It is a key component to implement confinement and is implemented using the reference monitor. System call interposition mediates requests from the application to the operating system.

In computing, a system call is the programmatic way in which a computer program requests a service from the kernel of the operating system it is executed on. A system call is a way for programs to interact with the operating system.

By monitoring and restricting system calls, an application may be prevented from causing harm. Solutions based on system call interposition have been developed in the past. System call interposition allows these systems to detect intrusions as policy violations and prevent them while they are happening.

A wide variety of security tools have been developed which use system call interposition. It is a powerful method for regulating and monitoring program behavior.
