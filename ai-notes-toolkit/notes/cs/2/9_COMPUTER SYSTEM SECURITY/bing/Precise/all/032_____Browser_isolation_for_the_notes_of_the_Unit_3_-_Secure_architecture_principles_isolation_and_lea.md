### Browser Isolation

Browser isolation is a cybersecurity model that aims to physically isolate an internet user's browsing activity (and the associated cyber risks) away from their local networks and infrastructure . This is typically achieved by leveraging virtualization or containerization technology to isolate the user's web browsing activity away from the endpoint device, significantly reducing the attack surface for rogue links and files .

Browser isolation can also be referred to as Web Isolation. It is a technology that contains web browsing activity inside an isolated environment, like a sandbox or virtual machine, in order to protect computers from any malware the user may encounter. This isolation may occur locally on the computer or remotely on a server .

There are different types of browser isolation, including remote browser isolation and on-premise browser isolation. Remote browser isolation technology loads webpages and executes any associated JavaScript code on a cloud server, while on-premise browser isolation does the same thing, but on a server that an organization manages internally .

Browser isolation can be an effective way to reduce an enterprise's exposure to web-based attacks. For example, Microsoft Edge supports browser isolation using Application Guard . This feature can be enabled through the Control Panel by selecting the check box next to Microsoft Defender Application Guard .

In summary, browser isolation is a cybersecurity model that aims to physically isolate an internet user's browsing activity from their local networks and infrastructure, in order to protect against cyber risks. It can be achieved through virtualization or containerization technology and can occur locally or remotely. Different types of browser isolation include remote and on-premise browser isolation. It can be an effective way to reduce exposure to web-based attacks.
