# Cookies, Frames, and Frame Busting

## Cookies
- Cookies are small text files that are stored on a user's computer by a website.
- They are used to store information about the user's activity on the website, such as login information, preferences, and browsing history.
- Cookies can be used to track user behavior and deliver personalized content.
- There are two types of cookies: session cookies and persistent cookies.
- Session cookies are temporary and are deleted when the user closes their browser.
- Persistent cookies remain on the user's computer until they are deleted or expire.

## Frames
- Frames are a way to divide a web page into multiple sections, each of which can display content from a different source.
- Frames can be used to display content from different websites on the same page.
- Frames can also be used to create a consistent layout for a website, with a header, footer, and navigation menu that remain the same across all pages.

## Frame Busting
- Frame busting is a technique used to prevent a web page from being displayed within a frame.
- This is often used to prevent clickjacking attacks, where a malicious website displays a legitimate website within a frame and overlays it with invisible buttons to trick the user into clicking on something they didn't intend to.
- Frame busting can be achieved using JavaScript or by sending the `X-Frame-Options` HTTP header.
