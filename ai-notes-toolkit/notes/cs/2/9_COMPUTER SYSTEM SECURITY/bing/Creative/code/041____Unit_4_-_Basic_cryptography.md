## Unit 4 - Basic cryptography

- Cryptography is the art of securing information by turning plaintext into ciphertext.
- Plaintext is the original message that can be read by anyone, while ciphertext is the encrypted message that can only be read by someone who has the key to decrypt it.
- Encryption is the process of transforming plaintext into ciphertext using a cipher, which is a mathematical algorithm that defines how to encrypt and decrypt data .
- Decryption is the process of transforming ciphertext back into plaintext using the same cipher and the key.
- There are two main types of cryptography: symmetric and asymmetric .
- Symmetric cryptography uses the same key for both encryption and decryption. The key must be shared securely between the sender and the receiver of the message. Examples of symmetric ciphers are AES, DES, and RC4 .
- Asymmetric cryptography, or public key cryptography, uses a pair of keys for encryption and decryption: a private key and a public key. The private key is kept secret by the owner, while the public key can be shared with anyone. The public key can be used to encrypt a message, but only the private key can decrypt it. Similarly, the private key can be used to sign a message, but only the public key can verify it. Examples of asymmetric ciphers are RSA, ECC, and DSA .
- Cryptography techniques include confidentiality, integrity, non-repudiation, and authentication.
- Confidentiality means that only the intended recipient can read the message. Encryption provides confidentiality by making the message unreadable to anyone who does not have the key.
- Integrity means that the message has not been altered or tampered with during transmission. Hash functions and digital signatures provide integrity by generating a unique value or signature for the message that can be checked by the receiver.
- Non-repudiation means that the sender cannot deny sending the message. Digital signatures provide non-repudiation by proving that the message was signed by the sender using their private key.
- Authentication means that the sender and the receiver can verify each other's identity. Public key cryptography provides authentication by allowing the sender and the receiver to exchange their public keys and use them to encrypt and decrypt messages.
- Cryptography is used in many applications, such as digital signatures, time stamping, electronic money transactions, cryptocurrency, and more.
