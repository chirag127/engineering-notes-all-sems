### Link layer connectivity and TCP IP connectivity

- The link layer is the lowest layer of the TCP/IP model, which is a simplified version of the OSI model.
- The link layer is responsible for the physical and logical connection of devices on a local network segment, such as Ethernet, Wi-Fi, or Bluetooth.
- The link layer handles the transmission and reception of data frames, error detection and correction, media access control, and addressing.
- The link layer is also called the network access layer or the network interface layer, as it provides the interface between the network layer and the physical layer.
- The link layer protocols are specific to the type of physical medium and network topology used, such as ARP, PPP, SLIP, or MAC.
- The network layer is the second layer of the TCP/IP model, which is similar to the third layer of the OSI model.
- The network layer is responsible for the routing and forwarding of packets across different networks, such as the Internet.
- The network layer handles the addressing, fragmentation, and reassembly of packets, as well as the congestion control and quality of service.
- The network layer protocols are independent of the physical medium and network topology used, such as IP, ICMP, IGMP, or IPsec.
- The network layer is also called the internet layer, as it provides the common protocol for interconnecting different networks.
