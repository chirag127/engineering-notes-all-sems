## Unit 1 - Computer System Security Introduction

- Computer system security is the protection of information and resources from unauthorized access, use, modification, or destruction.
- Computer system security aims to achieve the following objectives:
  - Confidentiality: ensuring that only authorized parties can access the information.
  - Integrity: ensuring that the information is not altered or corrupted by unauthorized parties.
  - Availability: ensuring that the information and resources are accessible and usable by authorized parties when needed.
  - Accountability: ensuring that the actions and activities of the parties involved in the system are traceable and auditable.
  - Non-repudiation: ensuring that the parties cannot deny their involvement or responsibility in the system.
- Computer system security faces various threats and challenges, such as:
  - Malicious attacks: intentional attempts to compromise the security of the system by unauthorized parties, such as hackers, cybercriminals, terrorists, etc.
  - Accidental errors: unintentional mistakes or failures that affect the security of the system, such as human errors, software bugs, hardware faults, natural disasters, etc.
  - Insider threats: authorized parties who abuse their privileges or access to compromise the security of the system, such as disgruntled employees, spies, whistleblowers, etc.
- Computer system security requires a comprehensive and systematic approach that involves the following components:
  - Policy: the set of rules and guidelines that define the security objectives, requirements, and responsibilities of the system and its stakeholders.
  - Mechanism: the technical means and methods that implement the security policy and enforce the security controls, such as encryption, authentication, authorization, auditing, etc.
  - Assurance: the degree of confidence and trust that the security policy and mechanism are effective and reliable, such as testing, verification, evaluation, certification, etc.
- Computer system security is a dynamic and evolving field that requires constant monitoring, updating, and improvement to cope with the changing threats and technologies.
