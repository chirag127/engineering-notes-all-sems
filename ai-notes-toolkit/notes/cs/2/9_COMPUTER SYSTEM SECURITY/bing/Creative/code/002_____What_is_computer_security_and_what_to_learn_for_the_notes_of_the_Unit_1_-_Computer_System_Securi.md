# What is computer security and what to learn for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY

- Computer security, also called cybersecurity or information technology security, is the protection of computer systems and networks from attack by malicious actors that may result in unauthorized information disclosure, theft of, or damage to hardware, software, or data, as well as from the disruption or misdirection of the services they provide.
- Computer security can be implemented using passwords, encryption, and firewalls, and denying physical access to a computer's location.
- Computer security is a broad and multidisciplinary field that covers topics such as cryptography, network security, operating system security, software security, web security, database security, cloud security, mobile security, human factors, ethics, and legal issues.
- Some of the learning objectives for the Unit 1 - Computer System Security Introduction are:
  - To understand the basic concepts and terminology of computer security.
  - To identify the main threats and vulnerabilities of computer systems and networks.
  - To recognize the principles and techniques of security design and evaluation.
  - To appreciate the ethical and legal implications of computer security.
  - To develop critical thinking and problem-solving skills for computer security.
