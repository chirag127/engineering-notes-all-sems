### Security interface for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

- The security interface is a set of user interface elements that provide access and control over security features such as authorization, access to digital certificates, and access to items in keychains.
- Secure architecture principles are the guidelines and best practices for designing and implementing secure systems. Some of the common principles are:
  - Isolation: The principle of isolation states that different components or processes of a system should be separated from each other to limit the impact of a compromise or failure. Isolation can be achieved by using different layers, domains, or mechanisms such as virtualization, containers, firewalls, etc.
  - Least privilege: The principle of least privilege states that each user or process should have the minimum amount of privileges or permissions required to perform its function. This reduces the attack surface and the potential damage of a breach. Least privilege can be enforced by using access control policies, roles, or tokens .
- Web security landscape is the overview of the threats, vulnerabilities, and countermeasures that affect the security of web applications and services. Some of the common aspects of web security are:
  - Web security definitions: Web security is the protection of web resources and data from unauthorized access, modification, or destruction. Web resources include web pages, web servers, web browsers, web APIs, etc. Web data includes user input, cookies, sessions, databases, etc.
  - Web security goals: Web security aims to achieve the following objectives:
    - Confidentiality: The property that web data is only accessible to authorized parties and not disclosed to unauthorized parties.
    - Integrity: The property that web data is not modified or corrupted by unauthorized parties or processes.
    - Availability: The property that web resources and services are accessible and functional to authorized parties and not disrupted by unauthorized parties or processes.
    - Authentication: The process of verifying the identity of a user or a web resource.
    - Authorization: The process of granting or denying access to web resources or data based on the identity or role of a user or a web resource.
    - Non-repudiation: The property that the actions or transactions of a user or a web resource can be verified and traced and cannot be denied or disputed.
