### DNS revisited

- DNS stands for Domain Name System, which is a distributed database that maps domain names to IP addresses and other information.
- DNS enables users to access websites and services using human-readable names instead of numerical addresses.
- DNS works in a hierarchical manner, with a root zone at the top, followed by top-level domains (TLDs), second-level domains (SLDs), and subdomains.
- DNS relies on a network of servers, called name servers, that store and update the records for each domain.
- DNS uses a client-server model, where a client (such as a web browser) sends a query to a name server, and the name server responds with the requested information or a referral to another name server.
- DNS uses a recursive or iterative mode of resolution, where a name server can either answer the query directly, or forward it to another name server closer to the authoritative source of the information.
- DNS uses various types of records, such as A, AAAA, CNAME, MX, NS, PTR, SOA, SRV, and TXT, to store different kinds of information for each domain.
- DNS also supports dynamic updates, where a domain owner can change the records for their domain without having to contact the name server administrator.
- DNS is a critical component of the internet infrastructure, as it enables users to access websites and services easily and efficiently.
- DNS is also a potential target for various types of attacks, such as DNS spoofing, DNS hijacking, DNS cache poisoning, DNS amplification, and DNS tunneling, that can compromise the security and availability of the internet.
- DNS security is the practice of protecting the DNS system from these attacks, by using various techniques, such as DNSSEC, DNS filtering, DNS firewall, and DNS monitoring.
