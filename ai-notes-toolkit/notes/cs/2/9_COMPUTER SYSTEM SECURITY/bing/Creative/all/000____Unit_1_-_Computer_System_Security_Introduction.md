# Unit 1 - Computer System Security Introduction

Computer system security is the protection of computer systems and information from harm, theft, and unauthorized use. It is the process of preventing and detecting unauthorized use of your computer system  . Computer system security involves the following aspects:

- **Hardware security**: the physical protection of computer hardware, such as the system memory and disk drive, from theft, damage, or tampering. Hardware security can be achieved by using serial numbers, doors and locks, and alarms.
- **Firmware security**: the protection of permanent software that is etched into a hardware device’s nonvolatile memory and is mostly invisible to the user, such as the BIOS or the firmware of a router. Firmware security can be achieved by using encryption, authentication, and secure boot mechanisms.
- **Software security**: the protection of software, such as the operating system, applications, and data, from unauthorized access, modification, or deletion. Software security can be achieved by using passwords, encryption, access control, firewalls, antivirus, and secure coding practices .
- **Network security**: the protection of computer networks and the data transmitted over them from attack by malicious actors, such as hackers, viruses, or worms. Network security can be achieved by using encryption, authentication, firewalls, intrusion detection and prevention systems, and secure protocols .

Computer system security is important for ensuring the confidentiality, integrity, and availability of information and services. Confidentiality means that only authorized parties can access the information. Integrity means that the information is not altered or corrupted. Availability means that the information and services are accessible when needed.

Computer system security is also a challenging and dynamic field, as new threats and attacks emerge constantly, and new techniques and technologies are developed to counter them. Computer system security requires a combination of technical, organizational, and human factors to achieve effective protection .
