# Intrusion Detection Systems

- An intrusion detection system (IDS) is a device or software application that monitors a network or systems for malicious activity or policy violations  .
- An IDS can send alerts to IT and security teams when it detects any security risks and threats, and can also log the events for further analysis .
- An IDS can be classified into different types based on the scope, method, and location of detection   .
  - Scope: An IDS can be either network-based (NIDS) or host-based (HIDS). A NIDS monitors the traffic on a network segment or a device, while a HIDS monitors the activity on a specific host or system   .
  - Method: An IDS can use either signature-based or anomaly-based detection. A signature-based IDS compares the network traffic or system activity with a database of known attack patterns or signatures, while an anomaly-based IDS establishes a baseline of normal behavior and flags any deviations from it   .
  - Location: An IDS can be either inline or passive. An inline IDS is placed directly on the network path and can block or modify the traffic, while a passive IDS is placed off the network path and can only monitor and alert the traffic   .
- An IDS can be combined with an intrusion prevention system (IPS) to form an intrusion detection and prevention system (IDPS), which can not only detect but also prevent or mitigate the attacks   .
- An IDS can provide several benefits for network and system security, such as:
  - Detecting and alerting on known and unknown attacks   .
  - Providing visibility and insight into network and system activities   .
  - Supporting forensic analysis and incident response   .
  - Complementing other security controls and tools   .
- An IDS can also face some challenges and limitations, such as:
  - Generating false positives or false negatives   .
  - Requiring regular updates and maintenance   .
  - Consuming network and system resources   .
  - Being vulnerable to evasion or bypass techniques   .
