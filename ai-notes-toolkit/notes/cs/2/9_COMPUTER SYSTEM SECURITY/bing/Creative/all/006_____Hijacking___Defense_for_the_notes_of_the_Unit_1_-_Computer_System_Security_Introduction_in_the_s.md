# Hijacking & Defense

## Definition

- Hijacking is a type of network security attack in which the attacker takes control of computer systems, software programs and/or network communications  .
- Hijacking can be used to steal data, compromise the system, disrupt the service, impersonate the user, or perform malicious actions on behalf of the attacker.
- Hijacking can occur in various forms, such as session hijacking, DNS hijacking, browser hijacking, IP hijacking, etc.

## Examples

- Session hijacking: The attacker intercepts and modifies the packets of an ongoing communication session between two parties, such as a web browser and a web server, and takes over the session as if he/she were one of the legitimate parties.
- DNS hijacking: The attacker redirects the DNS queries of a victim to a malicious DNS server that provides false IP addresses for the requested domain names, leading the victim to visit fake or malicious websites.
- Browser hijacking: The attacker modifies the settings or installs malicious software on the victim's web browser, such as changing the home page, redirecting the search engine, displaying unwanted ads, or installing spyware or malware.
- IP hijacking: The attacker announces a false route for a range of IP addresses that belong to another network, causing the traffic destined for those addresses to be diverted to the attacker's network.

## Defense

- Hijacking can be prevented or detected by using various security mechanisms, such as encryption, authentication, integrity checking, digital signatures, firewalls, intrusion detection systems, etc.
- Encryption: Encryption is the process of transforming data into an unreadable form that can only be decrypted by the intended recipient. Encryption can protect the data from being intercepted or modified by the attacker during transmission or storage.
- Authentication: Authentication is the process of verifying the identity of a user or a system before granting access to a resource or a service. Authentication can prevent the attacker from impersonating a legitimate user or system or accessing unauthorized resources or services.
- Integrity checking: Integrity checking is the process of ensuring that the data has not been altered or corrupted during transmission or storage. Integrity checking can detect any modification or tampering of the data by the attacker and alert the sender or the receiver.
- Digital signatures: Digital signatures are a type of encryption that use a pair of keys, one public and one private, to sign and verify the data. Digital signatures can provide both integrity and authentication for the data, as well as non-repudiation, which means that the sender cannot deny sending the data.
- Firewalls: Firewalls are devices or software that monitor and filter the incoming and outgoing network traffic based on predefined rules. Firewalls can block or allow the traffic based on the source, destination, port, protocol, or content of the packets, and prevent or limit the access of the attacker to the network or the system.
- Intrusion detection systems: Intrusion detection systems are devices or software that analyze the network or the system activity and detect any signs of unauthorized or malicious behavior. Intrusion detection systems can alert the administrator or the user of any potential or actual hijacking attempts and provide information about the source, nature, and impact of the attack.
