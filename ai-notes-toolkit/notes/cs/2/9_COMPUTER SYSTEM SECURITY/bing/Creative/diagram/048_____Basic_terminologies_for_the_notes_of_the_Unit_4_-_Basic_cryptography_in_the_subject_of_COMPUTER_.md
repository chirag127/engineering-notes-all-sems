### Basic terminologies for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

- Cryptography: The science or art of designing and using methods to protect information from unauthorized access or modification. Cryptography involves the use of terms like plain text, cipher text, algorithm, key, encryption, and decryption.
- Plain text: The original message or data that needs to be encrypted or hidden. Plain text is also called clear text or cleartext .
- Cipher text: The transformed message or data that results from applying an encryption algorithm to the plain text. Cipher text is also called encrypted text or cryptogram .
- Algorithm: A set of rules or steps that defines how to perform a certain task, such as encryption or decryption. An algorithm can be expressed in various ways, such as in natural language, pseudocode, flowchart, or mathematical notation.
- Key: A piece of information that is used as an input to an encryption or decryption algorithm, along with the plain text or cipher text. A key determines the output of the algorithm and acts as a secret parameter that controls the security of the cryptosystem .
- Encryption: The process of transforming plain text into cipher text using an encryption algorithm and a key. Encryption aims to ensure the confidentiality, integrity, and authenticity of the plain text .
- Decryption: The reverse process of encryption, which transforms cipher text back into plain text using a decryption algorithm and a key. Decryption aims to recover the original message or data from the encrypted form .
- Cryptosystem: A system that consists of the elements involved in cryptography, such as the plain text, cipher text, algorithm, key, encryption, and decryption. A cryptosystem can be classified into two types: symmetric and asymmetric .
- Symmetric cryptosystem: A type of cryptosystem that uses the same key for both encryption and decryption. Symmetric cryptosystems are also called secret-key or private-key cryptosystems. Examples of symmetric algorithms are AES, DES, and RC4  .
- Asymmetric cryptosystem: A type of cryptosystem that uses different keys for encryption and decryption. Asymmetric cryptosystems are also called public-key or two-key cryptosystems. Examples of asymmetric algorithms are RSA, Diffie-Hellman, and ECC  .
- Hash: A function that maps an arbitrary-length input (such as a message or a file) to a fixed-length output (such as a string of bits or a number). A hash function is also called a message digest, a checksum, or a fingerprint. A hash function aims to ensure the integrity and authenticity of the input by detecting any changes or tampering  .
- Salt: A random value that is added to the input of a hash function or a password-based encryption algorithm to increase the security and complexity of the output. A salt is also called a nonce or a randomizer. A salt aims to prevent attacks such as dictionary attacks or rainbow table attacks that exploit the predictability or repetition of the input  .
