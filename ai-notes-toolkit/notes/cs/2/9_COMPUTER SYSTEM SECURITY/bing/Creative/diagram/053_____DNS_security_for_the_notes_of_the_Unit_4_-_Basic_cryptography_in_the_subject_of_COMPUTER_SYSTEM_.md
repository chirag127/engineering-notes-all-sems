### DNS security
- DNS security is the practice of protecting DNS infrastructure from cyber attacks in order to keep it performing quickly and reliably .
- DNS infrastructure consists of DNS servers, DNS resolvers, DNS clients, and DNS records that map domain names to IP addresses and other information.
- DNS security incorporates a number of overlapping defenses, such as:
  - Establishing redundant DNS servers to ensure availability and resilience in case of failure or attack.
  - Applying security protocols like DNSSEC to authenticate and verify DNS records and prevent DNS spoofing or hijacking.
  - Requiring rigorous DNS logging to monitor and audit DNS queries and responses and detect anomalies or malicious activities.
  - Implementing DNS filtering to block or redirect end user web traffic from accessing malicious or unwanted websites and media.
  - Using DNS encryption to protect DNS traffic from eavesdropping or tampering by third parties.
- DNS security is important because DNS is a critical component of the internet infrastructure and a common target for cyberattacks. DNS attacks can cause serious consequences, such as :
  - Disrupting or denying access to legitimate websites and online services.
  - Redirecting users to fake or malicious websites that can steal personal or financial information or deliver malware.
  - Exposing or altering sensitive data or records stored in DNS servers or resolvers.
  - Compromising the security or performance of other network devices or systems that rely on DNS.
