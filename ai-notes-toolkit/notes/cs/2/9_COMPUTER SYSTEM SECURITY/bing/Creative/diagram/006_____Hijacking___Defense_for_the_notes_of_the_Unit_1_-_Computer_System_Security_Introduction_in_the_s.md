### Hijacking & Defense

- Hijacking is a type of network security attack in which the attacker takes control of computer systems, software programs and/or network communications  .
- Hijacking can be used to steal data, compromise the system, disrupt the service, impersonate the user, or perform malicious actions on behalf of the hijacked entity.
- Hijacking can occur in various ways, such as exploiting vulnerabilities, intercepting network traffic, spoofing identities, injecting malicious code, or gaining physical access to the system .
- Some common types of hijacking attacks are:
  - Session hijacking: The attacker takes over an active communication session between two parties, such as a web browser and a web server, and impersonates one or both of them.
  - URL hijacking: The attacker redirects the user to a malicious website that looks similar to the intended one, by manipulating the domain name system (DNS) or the web browser settings.
  - Browser hijacking: The attacker modifies the web browser settings, such as the home page, the search engine, or the toolbars, to display unwanted ads, pop-ups, or malware.
  - Email hijacking: The attacker gains access to the user's email account and sends spam or phishing messages to the contacts, or reads or deletes the user's emails.
  - Ransomware hijacking: The attacker encrypts the user's files or locks the user's system and demands a ransom to restore the access or the data.
- Some common defense techniques against hijacking are:
  - Encryption: The use of cryptographic methods to protect the data and the communication from unauthorized access or modification.
  - Authentication: The use of passwords, biometrics, tokens, or certificates to verify the identity of the parties involved in the communication.
  - Authorization: The use of access control policies to restrict the actions that the parties can perform on the system or the network.
  - Firewall: The use of a software or hardware device that filters the incoming and outgoing network traffic based on predefined rules.
  - Antivirus: The use of a software program that scans the system or the network for malicious code and removes or quarantines it.
  - Updates: The use of regular patches or upgrades to fix the vulnerabilities or bugs in the system or the software.
  - Awareness: The use of education and training to inform the users about the risks and the best practices of network security.
