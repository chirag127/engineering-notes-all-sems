### Intrusion Detection

Intrusion detection is a mechanism used to detect unauthorized access to computer systems or networks. It is an important part of computer system security and plays a crucial role in protecting against cyber attacks. In this section, we will learn about the basics of intrusion detection and its various types.

#### Types of Intrusion Detection

1. **Host-based Intrusion Detection System (HIDS):** HIDS is a type of intrusion detection system that is installed on individual hosts or machines. It monitors the activity and behavior of the host and detects any suspicious activity or unauthorized access.

2. **Network-based Intrusion Detection System (NIDS):** NIDS is a type of intrusion detection system that is installed on a network. It monitors network traffic and detects any suspicious activity or unauthorized access.

3. **Hybrid Intrusion Detection System (HIDS/NIDS):** Hybrid intrusion detection systems combine the features of both HIDS and NIDS. These systems can provide better security by monitoring both host activity and network traffic.

#### Intrusion Detection Techniques

1. **Signature-based Detection:** Signature-based detection is a technique that uses a database of known attack signatures to detect intrusions. When a pattern matching the signature is detected, an alert is sent to the security administrator.

2. **Anomaly-based Detection:** Anomaly-based detection is a technique that detects abnormal behavior by monitoring the activity of the system or network. It creates a baseline of normal behavior and triggers an alert when any activity deviates from this baseline.

3. **Heuristic-based Detection:** Heuristic-based detection is a technique that uses a set of rules and statistical analysis to detect intrusions. These rules are based on the behavior of known attacks and can detect new or unknown attacks.

#### Intrusion Detection Systems Deployment

1. **Distributed Deployment:** In a distributed deployment, intrusion detection systems are installed on multiple hosts or machines. This provides redundancy and ensures that if one system fails, the other systems can still detect intrusions.

2. **Centralized Deployment:** In a centralized deployment, intrusion detection systems are installed on a single server or machine. This provides a single point of control and makes it easier to manage and maintain the system.

3. **Hybrid Deployment:** Hybrid deployment is a combination of distributed and centralized deployment. In this deployment, intrusion detection systems are installed on multiple hosts or machines, but the alerts are sent to a centralized server for analysis and response.

#### Conclusion

Intrusion detection is an essential part of computer system security. It provides protection against cyber attacks and helps to maintain the integrity and confidentiality of computer systems and networks. By understanding the types of intrusion detection systems and the techniques used, security administrators can deploy effective intrusion detection systems and protect their organizations from cyber threats.
