### Real World Protocols for the Notes of Unit 4 - Basic Cryptography in the Subject of Computer System Security

Cryptography is an essential aspect of computer system security. It helps in protecting sensitive information from unauthorized access, alteration, or theft. In this unit, we will cover the basics of cryptography and some of the real-world protocols used to secure data.

Here are some of the real-world protocols for the notes of Unit 4 - Basic Cryptography in the subject of Computer System Security:

1. SSL/TLS Protocol:
   - SSL (Secure Sockets Layer) and TLS (Transport Layer Security) protocols are used for secure communication over the internet.
   - These protocols provide encryption, authentication, and integrity of data transmitted between the client and the server.
   - SSL/TLS ensures that the data exchanged between the client and the server is kept confidential and cannot be intercepted by a third party.

2. AES Protocol:
   - Advanced Encryption Standard (AES) is a symmetric encryption algorithm used to encrypt data.
   - AES uses a block cipher to encrypt data, and it is considered to be one of the most secure encryption algorithms.
   - AES is widely used in various applications such as file encryption, disk encryption, and network security.

3. RSA Protocol:
   - RSA (Rivest-Shamir-Adleman) is a public-key cryptography algorithm used for secure communication.
   - RSA uses two keys, a public key, and a private key, to encrypt and decrypt data.
   - RSA is widely used in various applications such as secure communication, digital signatures, and secure authentication.

4. Diffie-Hellman Protocol:
   - Diffie-Hellman is a key exchange protocol used to establish a shared secret key between two parties.
   - The protocol allows two parties to agree on a shared secret key without communicating the key directly.
   - Diffie-Hellman is widely used in various applications such as VPNs, secure email, and secure messaging.

5. Kerberos Protocol:
   - Kerberos is a network authentication protocol used to provide secure authentication between clients and servers.
   - Kerberos uses a trusted third party, known as a Key Distribution Center (KDC), to provide authentication services.
   - Kerberos is widely used in various applications such as Active Directory, network authentication, and single sign-on.

In conclusion, understanding the basics of cryptography is crucial in ensuring the security of computer systems. The real-world protocols discussed above are just a few examples of the many protocols used to secure data in various applications. It is essential to have a thorough understanding of these protocols to ensure the confidentiality, integrity, and availability of sensitive information.
