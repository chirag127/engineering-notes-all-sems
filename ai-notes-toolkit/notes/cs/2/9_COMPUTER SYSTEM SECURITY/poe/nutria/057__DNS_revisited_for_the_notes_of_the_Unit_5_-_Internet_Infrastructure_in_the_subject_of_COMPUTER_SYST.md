
### DNS Revisited for the Notes of Unit 5 - Internet Infrastructure in COMPUTER SYSTEM SECURITY

1. Domain Name System (DNS) is a hierarchical distributed naming system for computers, services, or any resource connected to the Internet or a private network. 
2. DNS translates human-readable domain names into numerical IP addresses.
3. DNS is an essential part of the Internet infrastructure and is used to locate web servers and other services.
4. DNS is organized into a hierarchy of domains, with each domain representing a particular administrative or organizational unit.
5. DNS can be used to provide load balancing, security, and other features to improve the performance and reliability of web services.
6. DNS can be used to map IP addresses to hostnames, which makes it easier to remember web addresses.
7. DNS can also be used to map domain names to IP addresses of other services, such as mail servers or FTP servers.
8. DNS is typically managed by a DNS server, which stores the DNS records and responds to requests from clients.
9. DNS is a critical component of Internet security, as it helps to protect against malicious attacks and other security threats.
10. DNS is also used for authentication and authorization, as it can be used to verify the identity of a user or service.
