
### Other issues in access control for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

1. Authorization: Authorization is the process of determining which users and/or processes have access to specific resources within a system. Authorization is typically based on a user's identity or role within the system.

2. Access Control Lists (ACLs): An ACL is a list of permissions associated with a particular resource, such as a file or directory. It specifies which users and/or processes have access to the resource and what type of access they have (read, write, execute, etc.).

3. Role-Based Access Control (RBAC): RBAC is an access control model that is based on the roles that users and/or processes have within a system. It allows for fine-grained control over who has access to which resources.

4. Mandatory Access Control (MAC): MAC is an access control model that is based on the security labels associated with each resource. It allows for fine-grained control over who has access to which resources, based on the security labels.

5. Discretionary Access Control (DAC): DAC is an access control model that is based on the user's identity. It allows for fine-grained control over who has access to which resources, based on the user's identity.

6. Least Privilege Principle: The least privilege principle is a security principle that states that users and/or processes should only be granted the minimum privileges necessary to perform their job. This helps to reduce the risk of unauthorized access to sensitive resources.
