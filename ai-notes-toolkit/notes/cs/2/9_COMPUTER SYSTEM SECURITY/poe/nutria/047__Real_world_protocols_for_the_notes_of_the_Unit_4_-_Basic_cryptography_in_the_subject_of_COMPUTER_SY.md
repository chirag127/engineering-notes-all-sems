
### Real world protocols for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

1. Cryptography is the practice of using encryption algorithms to protect data from unauthorized access. 
2. Cryptographic algorithms are designed to be secure, meaning they are difficult to break even with powerful computers and sophisticated attacks. 
3. Cryptographic algorithms can be used to protect data in transit and at rest. 
4. Cryptographic algorithms can also be used to authenticate the identity of users and devices.
5. Cryptographic algorithms are used in various protocols such as SSL/TLS, IPSec, SSH, and Kerberos. 
6. SSL/TLS is a protocol used to secure communication over the internet. 
7. IPSec is a protocol used to secure communication over networks. 
8. SSH is a protocol used to securely access remote systems. 
9. Kerberos is an authentication protocol used to securely authenticate users and devices. 
10. Cryptography is an important part of computer system security and can be used to protect data from unauthorized access.
