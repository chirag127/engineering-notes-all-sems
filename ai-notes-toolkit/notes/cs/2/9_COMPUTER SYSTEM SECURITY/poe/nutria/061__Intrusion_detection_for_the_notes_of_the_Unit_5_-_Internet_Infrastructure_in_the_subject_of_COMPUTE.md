
### Intrusion Detection for Unit 5 - Internet Infrastructure in COMPUTER SYSTEM SECURITY

Intrusion detection is an important component of computer system security. It is used to detect malicious activity on a network or system, and alert administrators to take appropriate measures.

1. Intrusion detection systems (IDS) are designed to monitor network traffic and detect suspicious activity.
2. IDS can be either signature-based or anomaly-based. Signature-based IDS detect known malicious activity, while anomaly-based IDS detect suspicious activity that does not match a known pattern.
3. IDS can be deployed on a network or host level. Network-based IDS monitor traffic on a network, while host-based IDS monitor activity on a single system.
4. IDS can be used to detect malicious activity such as port scans, network scans, denial of service attacks, and buffer overflows.
5. IDS can be used to detect insider threats, such as employees with malicious intent.
6. IDS can be used to detect malicious activity from outside sources, such as hackers.
7. IDS can be used to detect unauthorized access to a system or network.
8. IDS can be used to detect malicious activity on a system or network, such as viruses, worms, and Trojans.
9. IDS can be used to detect changes to system or network configurations.
10. IDS can be used to detect unauthorized use of system or network resources.
