
### VM Based Isolation for the Notes of the Unit 2 - Confidentiality Policies in the Subject of Computer System Security

1. Virtual Machine (VM) based isolation is a method of protecting a system from malicious software by running it in an isolated environment. 
2. This environment is created by using a virtual machine, which is a software implementation of a physical computer. 
3. The VM runs on the same physical hardware as the host system, but it is isolated from the host system and other VMs. 
4. This isolation increases the security of the system, as the malicious software is unable to access the host system or other VMs. 
5. Additionally, the VM can be configured with its own security policies, such as firewall rules, user access control, and data encryption. 
6. This allows the system to be protected even if the host system is compromised. 
7. VM based isolation is an important tool for implementing confidentiality policies in computer system security. 
8. By running sensitive applications in an isolated environment, it is possible to ensure that the data remains confidential and secure. 
9. Additionally, the isolation of the VM allows the system administrator to control who can access the data and what operations can be performed on the data. 
10. This ensures that only authorized personnel can access the data, and that any unauthorized access is prevented.
