
### Packet Filtering Firewall

1. A packet filtering firewall is a security system that inspects incoming and outgoing packets of data and either allows or blocks them based on a set of rules.

2. It is used to protect networks from malicious traffic, such as malicious code, viruses, and other malicious activities.

3. Packet filtering firewalls can be used to control access to the network, restrict access to certain websites, and control which services are available.

4. Packet filtering firewalls use access control lists (ACLs) to define the rules for filtering traffic. These rules can be based on the source or destination IP address, the type of protocol being used, or the type of application.

5. Packet filtering firewalls can be implemented either in hardware or software. Hardware-based packet filtering firewalls are more secure, but are more expensive and require more maintenance.

6. Packet filtering firewalls can also be used to protect against Denial of Service (DoS) attacks, by limiting the number of requests that can be made from a single source.
