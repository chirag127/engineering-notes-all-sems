
### Cookies frames and frame busting

- Cookies frames and frame busting are techniques used to protect web applications from malicious attacks. 
- Cookies frames are used to isolate a web application from the outside world, preventing malicious code from being executed. 
- Frame busting is a technique that prevents a web page from being embedded in a frame or iframe. This prevents malicious code from being injected into the page. 
- Secure architecture principles such as isolation and least privilege can be used to further protect web applications from malicious attacks. 
- Isolation is a technique used to limit the impact of malicious code by isolating it from other parts of the system. 
- Least privilege is a security principle that requires users to have the least amount of privilege necessary to perform their job. This reduces the risk of malicious code being executed.
