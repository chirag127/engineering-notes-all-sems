### Web security landscape

1. XSS (Cross-site scripting): Injection of client-side scripts into web pages viewed by other users. Allows attackers to bypass access controls such as same-origin policy.
2. CSRF (Cross-site request forgery): Forces authenticated users to send requests from their account without their knowledge or intent.
3. Broken authentication: Vulnerabilities in the authentication system, allowing attackers to guess passwords or reuse/steal credentials.
4. insecure direct object references: Insufficient or absent checks when accessing data, enabling readers to access data they are not authorized to read.
5. SQL injection: Insertion of SQL commands into an application's queries to read or modify or delete sensitive data from a database.
6. compromised data over the network: Any data sent over the network like credentials, personal information etc. can be stolen by man-in-the-middle or sniffing attacks. Use of HTTPS and encryption is necessary.
7. Publicly accessible metadata: Sensitive data like file names, folders, schemas etc. can reveal confidential information if not properly secured.
8. brute force attacks: Automated attempts to log in by trying a large number of possible passwords or PINs

This covers the major vulnerabilities in web applications from a security perspective. Proper input validation, access control, use of HTTPS and encryption are some of the measures to mitigate these risks.
