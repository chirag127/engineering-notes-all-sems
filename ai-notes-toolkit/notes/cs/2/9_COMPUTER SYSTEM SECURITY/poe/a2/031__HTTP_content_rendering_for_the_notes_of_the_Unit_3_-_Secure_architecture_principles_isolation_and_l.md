### HTTP content rendering for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

1. HTTP or Hypertext Transfer Protocol is the set of rules for transferring web pages on the World Wide Web.
2. An HTTP message consists of a header and a body. The header contains information about the request or response while the body contains the resource representations.
3. The HTTP content is rendered on the browser based on the content type specified in the header. Some common content types are:
- HTML: Renders as a web page
- CSS: Used to style the HTML content
- JS: Used to add dynamic functionality to web pages
- Images: Renders as images like JPG, PNG, GIF, etc.
- JSON: Renders as a JSON structure which can be parsed by JavaScript
- XML: Renders as XML data which can be processed by applicable parsers
4. Security aspects to consider for HTTP content rendering:
- Trusted content only: Ensure only authorized content is rendered from trusted sources
- Content sniffing protection: Prevent browsers from guessing and rendering untrusted content types
- Cross-site scripting protection: Encode outputs to prevent injection of malicious scripts
- Clickjacking protection: Use X-Frame-Options header to prevent rendering in iframes
- CORS: Enable CORS for APIs to allow rendering of resources in permitted domains
