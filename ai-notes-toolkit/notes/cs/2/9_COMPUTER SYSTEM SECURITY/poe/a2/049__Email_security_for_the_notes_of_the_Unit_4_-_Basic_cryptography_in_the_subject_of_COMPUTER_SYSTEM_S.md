### Email security for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

1. Email encryption
- Symmetric encryption algorithms like AES can be used to encrypt the email contents. The sender and recipient should share a secret key to encrypt and decrypt the emails.
- However, sharing the secret key is a challenge as it needs to be exchanged securely. Public key cryptography can be used here where the recipient's public key is used to encrypt and private key is used to decrypt.

2. Digital signatures
- Digital signatures using private key can be used to authenticate the sender of an email. The recipient can verify the signature using the sender's public key to ensure that the email was indeed sent by the legitimate sender.
- This helps prevent impersonation attacks where hackers send spoofed emails appearing from a legitimate sender.

3. Limiting metadata
- Email metadata like subject, sender, recipient, date, etc. can reveal sensitive information. This can be prevented using encryption and anonymous communication networks like Tor.
- However, if metadata is encrypted, it can arouse suspicion and still reveal that someone is sending encrypted emails. Anonymous networks completely hide the metadata but often have slower speeds.

4. Email security best practices
- Use strong and unique passwords for email accounts
- Enable two-factor authentication if available
- Beware of phishing emails and malicious attachments or links
- Keep software and antivirus up to date
- Be cautious of unencrypted Wi-Fi networks
- Follow general cybersecurity best practices
