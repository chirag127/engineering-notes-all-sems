### More on confinement techniques for the notes of the Unit 2 - Confidentiality Policies in the subject of COMPUTER SYSTEM SECURITY.

1. Jail: Programs run in a restricted environment called jail. The jail limits the set of system calls a process can invoke. This prevents the process from accessing resources or performing operations outside its intended scope.
2. Sandbox: The sandbox technique confines a process to a restricted environment which is isolated from the rest of the system. The process inside the sandbox has limited resources and restricted system calls. This prevents the process from causing any harm to the system even if it is compromised.
3. Virtualization: Virtualization creates virtual environments that are isolated from each other and the host system. Processes running inside a virtual environment are restricted to the resources provided by the virtual environment. This limits the impact of a compromised process to its virtual environment.
4. Controlled Execution: In controlled execution, the behavior of a process is closely monitored and controlled. The process is allowed to perform only specific actions. This limits the ability of a compromised process to take undesired actions or access restricted data. Various methods used for controlled execution include software fault isolation and proof-carrying code.

The above points cover the key confinement techniques used to restrict processes to a limited scope and prevent them from causing undesired actions. These techniques are useful in enforcing confidentiality policies and maintaining system security.
