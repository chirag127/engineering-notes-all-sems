### Intrusion Detection Systems

1. An Intrusion Detection System (IDS) is a system that monitors network traffic for suspicious activity and alerts administrators when potential malicious activity is detected.
2. The main types of IDS are:
- Network-based IDS (NIDS): Monitors the entire network for suspicious traffic patterns. Analyzes network packets for signs of attacks.
- Host-based IDS (HIDS): Analyzes system activity on a particular host for suspicious behavior. Logs user and system activity and alerts for deviations from normal behavior.
3. IDS use one or more detection methods:
- Signature-based: Matches traffic patterns to known attack signatures. Effective for known attacks but cannot detect new attacks.
- Anomaly-based: Flags deviations from established baseline metrics of normal traffic and activity. Can detect new attacks but prone to false positives.
- Heuristic/Behavior-based: Flags suspicious behavior and patterns as possible attacks. Combines characteristics of signature and anomaly-based detection with machine learning algorithms.
4. Challenges with IDS include:
- Generating too many false positives which can lead to alert fatigue.
- Inability to detect new or "zero-day" attacks for which there are no known signatures.
- Evasion techniques used by attackers to avoid detection.
- Resource requirements to monitor traffic and activity at high volumes.
