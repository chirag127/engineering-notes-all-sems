## Unit 1 - Computer System Security Introduction

1. Security threats - There are various security threats to computer systems like malware, ransomware, phishing attacks, DDoS attacks etc. These threats can steal data, encrypt files for ransom and disrupt systems.

2. Security goals - The main goals of computer system security are:

- Confidentiality - Preventing unauthorized disclosure of data
- Integrity - Preventing unauthorized modification of data
- Availability - Ensuring authorized users have access to resources

3. Security mechanisms - Some common security mechanisms to achieve the security goals are:

- Passwords - For authentication
- Encryption - For confidentiality of data
- Digital signatures - For integrity and authentication of data
- Firewalls - For controlling network traffic
- Antivirus software - For detecting and preventing malware

4. Responsibilities - Following are the key responsibilities to ensure computer system security:

- Individual users - Use strong passwords, keep systems and software updated, be wary of phishing emails etc.
- System administrators - Apply patches, configure firewalls and security systems, monitor for intrusions etc.
- Software developers - Remove vulnerabilities and bugs, incorporate security in the software development lifecycle
- Security professionals - Conduct audits, create security policies and monitor for advanced persistent threats
