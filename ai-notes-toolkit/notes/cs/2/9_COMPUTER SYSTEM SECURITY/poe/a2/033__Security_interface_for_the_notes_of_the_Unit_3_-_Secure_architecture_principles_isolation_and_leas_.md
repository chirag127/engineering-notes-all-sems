### Security interface for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

1. Isolation: Isolation is a security principle which states that entities should be separated from one another. This can be achieved using various techniques like:
- Segregation: Physically separating hardware, software and network.
- Sandboxing: Running software in a restricted environment.
- Jails: Restricting software to specific resources.
- Virtualization: Running software on virtual systems.

2. Least privilege: The principle of least privilege states that entities should be given only the privileges needed to perform their tasks. This limits the damage caused due to misuse or exploitation of privileges. Some ways to achieve least privilege are:
- Only providing required access rights and permissions to users and software.
- Using the principle of default deny where everything is denied by default unless explicitly permitted.
- Applying privilege bracketing where privileges are given for a limited scope and time.

3. Layered system: A layered system has multiple layers with each layer only allowed to access the layer immediately below it. This enforces isolation and least privilege. The layers can be arranged in a hierarchy with the most trusted layers at the bottom and least trusted at the top. Some examples are TCP/IP stack, OSI model, etc.
