### Advanced Control Hijacking attacks

1. Session Hijacking: An attacker takes over a session between two computers. The attacker steals the session ID and impersonates one of the parties.
2. Cross-Site Request Forgery (CSRF): An attacker forces an authenticated user to send a request from their browser without their knowledge or intent.
3. Man-in-the-Browser (MitB): An attacker injects malicious code into the victim's browser to modify web application transactions and steal data.
4. DNS Hijacking: An attacker redirects DNS queries to a malicious DNS server to direct users to fake websites or steal data.
5. URL Hijacking: An attacker creates a fake website with a URL that is similar to the legitimate one to steal login credentials or other sensitive data.

The above points cover some advanced attacks to hijack control from authorized users or computers. These highlight the need for secure software, encrypted communications, and constant patching to avoid vulnerabilities that can lead to hijacking attacks. Strict access controls and authentication measures also help prevent unauthorized access.
