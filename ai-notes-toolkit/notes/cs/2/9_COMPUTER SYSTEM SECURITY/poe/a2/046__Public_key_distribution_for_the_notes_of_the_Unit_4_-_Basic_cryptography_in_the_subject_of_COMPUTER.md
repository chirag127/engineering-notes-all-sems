### Public key distribution for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY.

1. Public key cryptography requires exchange of public keys between parties to enable encryption and digital signatures.
2. This exchange must be done securely, or an adversary can substitute its own public key and decrypt/sign messages improperly.
3. Common approaches:
 - Trusted third party: Parties get each other's public keys from a trusted key server.
 - Web of trust: Parties sign each other's public keys and verify chains of signatures.
 -DNS and certificates: Public keys are bound to domain names in a trusted hierarchy.
4. Ultimately, anything beyond direct in-person exchange of public keys relies on trust in some external system or organisation.
5. Key revocation becomes important if private keys are compromised, to prevent misuse of existing distributed public keys.
