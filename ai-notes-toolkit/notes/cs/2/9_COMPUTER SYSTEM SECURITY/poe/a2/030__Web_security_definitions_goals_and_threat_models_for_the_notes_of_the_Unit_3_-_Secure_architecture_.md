### Web security definitions, goals, and threat models

- **Web security:** Protection of web applications and APIs from threats and vulnerabilities. The goal is to maintain confidentiality, integrity, and availability of web-based resources.
- **Goals of web security:**
    - Confidentiality: Preventing unauthorized disclosure of data.
    - Integrity: Preventing unauthorized modification of data.
    - Availability: Ensuring authorized parties can access resources when needed.
- **Web threats:** Malicious actors and actions targeting web applications, such as:
    - Cross-site scripting (XSS): Injecting client-side scripts into web pages viewed by other users.
    - SQL injection: Inserting SQL commands through input data to manipulate the database.
    - Cross-site request forgery (CSRF): Forcing authenticated users to send requests from their accounts without their knowledge.
    - Broken authentication and session management: Exploiting flaws in authentication and session management to compromise accounts.
    - Sensitive data exposure: Exposing sensitive data through insecure data storage, transmission, or access control.
    - Security misconfiguration: Misconfiguration of web servers, application servers, databases, etc. leading to vulnerabilities.
    - Using components with known vulnerabilities: Using third-party libraries and components with unpatched vulnerabilities.
- **Threat modeling:** Systematic approach to identifying and mitigating threats targeting a system. Involves identifying assets, trust levels, and threats, and evaluating the likelihood and impact of threats to determine risk and mitigation priorities. Helps in designing security controls and ensuring a secure system.
