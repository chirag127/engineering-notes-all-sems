### Public key cryptography for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

1. Public key cryptography is a cryptographic system that uses pairs of keys for encryption and decryption.

2. It uses two different keys - a public key and a private key. The public key can be shared with everyone while the private key is kept secret.

3. The public key is used to encrypt the message and the private key is used to decrypt the message. Since only the recipient has the private key, only they will be able to read the message. This ensures confidentiality.

4. The private key can also be used to digitally sign messages to provide authentication and integrity. The sender's private key is used to sign the message and the public key is used to verify the signature. Since only the sender has the private key, the signature must have been created by the sender.

5. The strength of the public key cryptographic system depends on the difficulty of solving the mathematical challenge of reversing the key computation. The keys are based on mathematical algorithms and the most common algorithms are RSA, ECC, and ElGamal.

6. Public key cryptography is beneficial but computationally more intensive than symmetric key cryptography. It is used in protocols like TLS, SSL, SSH and PGP.
