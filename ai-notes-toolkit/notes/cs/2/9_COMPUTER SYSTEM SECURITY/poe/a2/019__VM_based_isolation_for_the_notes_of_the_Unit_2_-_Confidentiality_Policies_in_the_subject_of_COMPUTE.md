### VM based isolation for the notes of the Unit 2 - Confidentiality Policies

1. Virtual Machines (VMs) provide hardware-level isolation between different virtual environments. Each VM has its own virtual CPU, memory, storage, and network resources.
2. A VM runs its own operating system and applications and behaves like a physical computer. However, the resources of the VM are simulated/emulated and the underlying hardware is shared with other VMs.
3. VMs can be used to isolate different applications/tasks with different security/privacy requirements from each other. This limits unintended information flows between the tasks.
4. The VM environment can be configured with strict confidentiality policies to prohibit information leakage. The virtual networking can restrict information flows to only explicitly allowed destinations.
5. However, VMs do not provide perfect isolation. Vulnerabilities in the VM system software or the guest OS/applications can be exploited to leak information. The shared hardware resources may also enable side-channel attacks to extract information. Additional protections like memory encryption and access control are needed to strengthen isolation.
