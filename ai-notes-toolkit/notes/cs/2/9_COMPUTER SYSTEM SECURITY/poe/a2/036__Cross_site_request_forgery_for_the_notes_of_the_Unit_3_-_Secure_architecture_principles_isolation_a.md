### Cross site request forgery

- CSRF or XSRF is a type of malicious exploit of a website where unauthorized commands are performed on behalf of an authenticated user.
- The attacker uses social engineering to trick the user into clicking a malicious link or visiting a malicious website.
- Once the user is authenticated to the target website, the attacker forces the user's browser to send a request to the website, which then unwittingly performs actions with the user's credentials.
- For example, an attacker could force the user to perform financial transactions, change passwords, or other sensitive actions on the target website.
- Defence: Use CSRF tokens, CAPTCHAs, limiting allowed actions, checking referrer header.
