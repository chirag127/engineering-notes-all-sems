## Unit 4 - Basic cryptography

Cryptography is the practice of secure communication in the presence of third parties. It is the art of encoding messages so that only the intended recipient can read them. It is an important tool in protecting sensitive information, such as passwords, credit card numbers, and other confidential data. In this unit, we will learn the basics of cryptography.

### Cryptography Concepts

1. **Encryption**: Encryption is the process of converting plain text into a cipher text. The cipher text is unintelligible and cannot be read by anyone who does not have the key to decrypt it.

2. **Decryption**: Decryption is the process of converting cipher text back into plain text. The recipient of an encrypted message must have the key to decrypt it.

3. **Key**: A key is a piece of information used in the encryption and decryption process. The key is what allows the sender and recipient of a message to communicate securely.

4. **Symmetric Key Cryptography**: In symmetric key cryptography, the same key is used for both encryption and decryption. This means that both the sender and recipient of a message must have the same key.

5. **Asymmetric Key Cryptography**: In asymmetric key cryptography, there are two different keys: a public key and a private key. The public key is used for encryption, while the private key is used for decryption. This allows for secure communication without the need for both parties to have the same key.

6. **Hashing**: Hashing is the process of taking a piece of data and producing a fixed-length output. This output is called a hash. Hashing is often used to verify the integrity of data.

### Cryptography Techniques

1. **Substitution Cipher**: In a substitution cipher, each letter in the plain text is replaced by a different letter or symbol. This is a simple form of encryption that is easy to crack.

2. **Transposition Cipher**: In a transposition cipher, the letters in the plain text are rearranged. This is also a simple form of encryption that is easy to crack.

3. **Caesar Cipher**: The Caesar Cipher is a simple substitution cipher in which each letter in the plain text is shifted a certain number of places down the alphabet. This is also easy to crack, but it is a good introduction to cryptography.

4. **RSA**: RSA is a widely used asymmetric key encryption algorithm. It is named after its inventors, Ron Rivest, Adi Shamir, and Leonard Adleman. RSA is used to secure online transactions and is one of the most secure encryption techniques available.

### Conclusion

Cryptography is an important tool in protecting sensitive information. Understanding the basic concepts and techniques of cryptography is essential for anyone working with confidential information. In this unit, we have covered the basics of cryptography, including encryption, decryption, keys, symmetric and asymmetric key cryptography, hashing, and various cryptography techniques.
