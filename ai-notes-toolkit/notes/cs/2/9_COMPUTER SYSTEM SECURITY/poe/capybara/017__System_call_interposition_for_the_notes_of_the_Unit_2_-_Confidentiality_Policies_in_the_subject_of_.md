### System call interposition for the notes of the Unit 2 - Confidentiality Policies in the subject of COMPUTER SYSTEM SECURITY:

- System call interposition is a method of monitoring and controlling system calls made by a process in an operating system.
- It involves intercepting the system calls made by the process and redirecting them to a monitoring process.
- This monitoring process can then decide whether to allow or deny the system call based on the confidentiality policies in place.
- System call interposition can be used to enforce confidentiality policies such as access control, data encryption, and information hiding.
- It can also be used to monitor and audit system calls made by a process for security purposes.
- System call interposition can be implemented in the kernel or user space of an operating system.
- In the kernel-based approach, a kernel module intercepts the system calls and forwards them to a monitoring process in user space.
- In the user-space approach, a library intercepts the system calls and forwards them to a monitoring process in user space.
- System call interposition can be used in conjunction with other security mechanisms such as firewalls, intrusion detection systems, and antivirus software.
- However, system call interposition can introduce performance overhead and may not be suitable for real-time applications.
