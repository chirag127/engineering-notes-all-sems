### Microprogram Sequencing

- Microprogram sequencing is the process of generating the addresses of the microinstructions stored in the control memory of a microprogrammed control unit .
- The microprogram sequencer is the component that performs this task by using digital functions or logic circuits to suit a particular application .
- The microprogram sequencer can be designed with different methods, such as:
  - Fixed sequencing: The next microinstruction address is obtained by incrementing the current address by one. This method is simple and fast, but does not allow for branching or looping in the microprogram.
  - Conditional sequencing: The next microinstruction address is obtained by testing some condition bits in the microinstruction or the status register, and selecting one of the possible addresses based on the outcome. This method allows for branching and looping, but requires more hardware and time.
  - Unconditional sequencing: The next microinstruction address is explicitly specified in the microinstruction. This method allows for maximum flexibility and control, but requires more bits and memory space for the microinstruction.
- The microprogram sequencer can also be classified into two types, depending on the source of the next microinstruction address:
  - Horizontal microprogram sequencer: The next address is generated by the microprogram sequencer itself, using logic circuits or a counter. This type is faster and simpler, but less flexible and adaptable.
  - Vertical microprogram sequencer: The next address is generated by the microinstruction itself, using a field or a bit. This type is more flexible and adaptable, but slower and more complex.
