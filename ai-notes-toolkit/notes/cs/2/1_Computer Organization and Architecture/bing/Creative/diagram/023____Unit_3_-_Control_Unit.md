## Unit 3 - Control Unit

The control unit is the part of the central processing unit (CPU) that directs the operation of the processor. It generates control signals that activate other parts of the CPU, such as the arithmetic logic unit (ALU), the registers, the memory, and the input/output devices.

The control unit performs the following functions:

- It fetches the instruction from the memory and decodes it to determine the operation and the operands.
- It generates the necessary control signals to execute the instruction by coordinating the data movement among the registers, the ALU, the memory, and the input/output devices.
- It monitors the status of the CPU and the external devices to handle interrupts, exceptions, and errors.
- It updates the program counter (PC) to point to the next instruction to be executed.

The control unit can be classified into two types:

- Hardwired control unit: It uses a fixed logic circuit to generate the control signals for each instruction. It is fast, but inflexible and difficult to modify.
- Microprogrammed control unit: It uses a special memory called the control store to store the control signals for each instruction as a sequence of microinstructions. It is flexible and easy to modify, but slower than the hardwired control unit.
