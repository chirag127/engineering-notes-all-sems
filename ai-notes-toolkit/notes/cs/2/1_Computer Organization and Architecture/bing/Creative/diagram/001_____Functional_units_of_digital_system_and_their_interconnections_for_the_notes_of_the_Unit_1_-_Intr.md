### Functional units of digital system and their interconnections

A digital system is a system that processes and stores data in binary form, using electronic devices such as transistors, logic gates, and memory cells. A digital system can perform various functions, such as arithmetic, logic, control, input, output, and communication. To perform these functions, a digital system consists of several functional units that are interconnected by buses. A bus is a set of wires or lines that carry data, address, or control signals between different components of the system.

The main functional units of a digital system are:

- **Input unit**: This unit takes the input from the user or an external device and converts it into binary code that can be processed by the system. The input unit may include devices such as keyboards, mouse, scanners, microphones, cameras, etc. The input unit sends the binary data to the central processing unit (CPU) through the input bus.

- **Central processing unit (CPU)**: This unit is the brain of the system, as it performs all the processing and computation tasks. The CPU consists of two main subunits: the arithmetic and logic unit (ALU) and the control unit (CU).

  - **Arithmetic and logic unit (ALU)**: This subunit performs the arithmetic and logic operations on the data, such as addition, subtraction, multiplication, division, comparison, and bitwise operations. The ALU receives the data and the operation code from the CPU through the data bus and the control bus, respectively. The ALU performs the operation and sends the result back to the CPU through the data bus.

  - **Control unit (CU)**: This subunit controls the execution of instructions and the coordination of other functional units. The CU fetches the instructions from the memory unit through the data bus and the address bus, decodes them, and generates the appropriate control signals to the ALU and other units. The CU also handles the interrupts, exceptions, and branching operations.

- **Memory unit**: This unit stores the data and the instructions that are needed by the CPU and other units. The memory unit may include different types of memory devices, such as random access memory (RAM), read-only memory (ROM), cache memory, hard disk, etc. The memory unit communicates with the CPU and other units through the data bus and the address bus. The data bus carries the data to be read or written, and the address bus carries the address of the memory location.

- **Output unit**: This unit displays the output of the system to the user or an external device. The output unit may include devices such as monitors, printers, speakers, etc. The output unit receives the binary data from the CPU through the output bus and converts it into a suitable form for the output device.
