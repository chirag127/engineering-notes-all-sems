
### ROM Memories 

* Read-Only Memory (ROM) is a type of non-volatile memory used in computers and other electronic devices. 
* ROM stores the program instructions for basic operations such as booting up the computer and performing basic input/output tasks. 
* ROM is non-volatile, meaning it does not require power to retain its contents even when the computer is switched off. 
* ROM is often used to store firmware, which is a type of software that is programmed into a device and can only be modified or updated with special tools. 
* ROM is used in many embedded systems, such as car engines, where its non-volatility is desirable. 
* ROM is also used in video game consoles, where it stores the game data. 
* ROM is usually programmed at the factory, and can only be read, not written to.
