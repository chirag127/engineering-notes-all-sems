
## Unit 5 - Input / Output

1. Input/Output (I/O) is the process of taking data from one source and providing it to another.
2. I/O devices are the physical components used to transfer data between a computer and its environment.
3. Common I/O devices include keyboards, mice, printers, scanners, storage devices, and displays.
4. I/O operations involve the transfer of data from an input device to the computer's memory and from the computer's memory to an output device.
5. The most common type of I/O operation is data transfer, which involves the transfer of data from an input device to a computer's memory.
6. The data is then processed by the computer, and the results are sent to an output device.
7. I/O operations can also involve the transfer of data between two computers, or between a computer and a network.
8. I/O operations are typically managed by an operating system, which provides a set of instructions for managing data transfers.
9. The operating system also provides the necessary software and hardware drivers to enable I/O operations.
10. I/O operations are necessary for the functioning of any computer system.
