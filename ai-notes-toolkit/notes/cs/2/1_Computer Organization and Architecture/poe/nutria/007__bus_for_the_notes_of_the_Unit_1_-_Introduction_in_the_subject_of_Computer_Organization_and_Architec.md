
### Bus

* A bus is a communication system that transfers data between components inside a computer, or between computers. 
* It is a collection of wires through which data is transmitted from one part of a computer to another. 
* Bus width is the number of bits that can be sent simultaneously along a bus. 
* The components of a bus include the control bus, address bus, and data bus. 
* The control bus is used to synchronize the activities of the components. 
* The address bus is used to specify the location of the data that is to be read or written. 
* The data bus is used to transfer the actual data between the components. 
* The speed of the bus is determined by the clock speed of the computer. 
* A bus can be parallel or serial. 
* In a parallel bus, multiple bits are transmitted simultaneously, while in a serial bus, bits are transmitted one at a time. 
* The bus also determines the maximum amount of memory that can be used by the computer.
