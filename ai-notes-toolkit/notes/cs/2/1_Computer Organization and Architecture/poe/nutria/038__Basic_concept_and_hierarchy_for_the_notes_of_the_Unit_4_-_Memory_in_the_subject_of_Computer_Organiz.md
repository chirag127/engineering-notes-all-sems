
### Basic concept and hierarchy for the notes of the Unit 4 - Memory in the subject of Computer Organization and Architecture

1. Memory is the component of a computer system that stores data and instructions. It is divided into two types: primary memory and secondary memory. 

2. Primary memory is the main working memory of the computer system and is used to store data and instructions that are actively being used by the processor. It is usually composed of RAM (random access memory) and ROM (read-only memory).

3. Secondary memory is used to store data and instructions that are not currently being used by the processor. It is usually composed of hard drives, optical disks, and magnetic disks.

4. Memory hierarchy is the arrangement of memory from fastest to slowest, with RAM being the fastest. This hierarchy is used to optimize the performance of the computer system.

5. Caching is a technique used to improve the performance of the computer system by storing frequently used data and instructions in the fastest memory.

6. Virtual memory is a technique used to extend the amount of available memory by using the hard drive as an extension of the RAM. This allows programs to run even if there is not enough RAM available.
