
### Program Control for the Notes of the Unit 3 - Control Unit in the Subject of Computer Organization and Architecture

1. Program control refers to the instructions that a computer must follow in order to execute a given program. 
2. These instructions are written in a programming language and are then translated into machine language by a compiler or interpreter.
3. The control unit is responsible for controlling the flow of instructions within a computer system. 
4. It is responsible for decoding instructions, fetching data, and executing instructions.
5. The control unit is also responsible for managing the flow of data between the processor and memory. 
6. Branch instructions are used to control the flow of instructions within a program. 
7. These instructions allow the program to jump to a different address in memory, depending on the result of a comparison. 
8. Subroutines are also used to control the flow of instructions. 
9. A subroutine is a sequence of instructions that can be called from any other part of the program. 
10. Subroutines are used to reduce the amount of code that has to be written, and to make the code more readable.
