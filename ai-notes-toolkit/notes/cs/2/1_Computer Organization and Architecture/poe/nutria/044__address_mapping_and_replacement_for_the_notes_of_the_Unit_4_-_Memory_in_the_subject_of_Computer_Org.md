
### Address Mapping and Replacement for the Notes of the Unit 4 - Memory in the Subject of Computer Organization and Architecture

1. Address mapping is the process of mapping an address from one system to another. It is used to access memory in a computer system. 
2. Address mapping can be done using direct mapping, set associative mapping, or fully associative mapping. 
3. Direct mapping is the simplest form of address mapping, where the address is mapped directly to a memory location. 
4. Set associative mapping is a more complex form of address mapping, where the address is mapped to a set of memory locations. 
5. Fully associative mapping is the most complex form of address mapping, where the address is mapped to any memory location. 
6. Address replacement is an important part of memory management. It is the process of replacing an address in the main memory with another address. 
7. The most common methods of address replacement are FIFO (First-In-First-Out) and LRU (Least Recently Used). 
8. FIFO replaces the oldest address in the main memory with the new address. 
9. LRU replaces the least recently used address in the main memory with the new address. 
10. Address mapping and replacement are important concepts in computer organization and architecture. They allow the computer to access memory efficiently and effectively.
