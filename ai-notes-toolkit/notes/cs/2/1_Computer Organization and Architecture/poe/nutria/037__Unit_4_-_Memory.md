
## Unit 4 - Memory

1. Memory is the ability to store, retain, and recall information and experiences. It is the fundamental process that allows us to learn, remember, and use information. 
2. Memory is divided into three main categories: short-term memory, long-term memory, and working memory. 
3. Short-term memory is the ability to store small amounts of information for a short period of time. It is sometimes referred to as "active memory" because it is constantly being used and updated. 
4. Long-term memory is the ability to store large amounts of information for a long period of time. It is sometimes referred to as "passive memory" because it is not actively being used. 
5. Working memory is the ability to remember and use information in the present moment. It is the bridge between short-term and long-term memory, and is used to help us process and store new information. 
6. There are several different types of memory, including visual memory, auditory memory, and semantic memory. Visual memory is the ability to remember images, while auditory memory is the ability to remember sounds. Semantic memory is the ability to remember facts and concepts. 
7. Memory is affected by a variety of factors, including age, stress, and physical health. Memory can also be improved through practice and repetition.
