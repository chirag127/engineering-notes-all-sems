## Unit 3 - Architecture of 8086 Microprocessor

The 8086 microprocessor is an important component in computer technology. It is widely used in many systems including personal computers and embedded systems. In this unit, we will discuss the architecture of the 8086 microprocessor, including its register organization, bus interface unit, execution unit, memory addressing, and memory segmentation. We will also cover the operating modes, instruction sets, instruction format, types of instructions, and interrupts.

### Register Organization

The 8086 microprocessor has 14 general-purpose registers, each of which is 16 bits in size. These registers are divided into three categories: data registers, pointer registers, and index registers. The data registers are used for general-purpose data storage, the pointer registers are used for storing addresses, and the index registers are used for arithmetic and indexing.

### Bus Interface Unit

The bus interface unit (BIU) is responsible for interfacing the microprocessor with the system bus. It provides the necessary signals and controls for data transfer between the microprocessor and memory or I/O devices. The BIU also contains the instruction queue, which stores up to six instructions to be executed by the execution unit.

### Execution Unit

The execution unit (EU) is responsible for executing the instructions fetched from the instruction queue by the BIU. It contains the arithmetic and logic unit (ALU), which performs arithmetic and logical operations, and the flag register, which contains flags that indicate the status of operations performed by the ALU.

### Memory Addressing and Segmentation

The 8086 microprocessor can address up to 1 MB of memory using memory segmentation. Memory segmentation divides the memory into segments, each of which is 64 KB in size. The microprocessor uses segment registers to specify the segment in which the memory operand is located.

### Operating Modes

The 8086 microprocessor has two operating modes: real mode and protected mode. In real mode, the microprocessor operates in a similar manner to the 8088 microprocessor, which has a 20-bit address bus and can address up to 1 MB of memory. In protected mode, the microprocessor can access up to 4 GB of memory and provides support for virtual memory and multitasking.

### Instruction Sets and Formats

The 8086 microprocessor has two instruction sets: the original 8086 instruction set and the 8088 instruction set. The original 8086 instruction set contains 117 instructions, while the 8088 instruction set contains 240 instructions. The instructions are divided into different formats, including one-byte, two-byte, and three-byte formats.

### Types of Instructions

The instructions of the 8086 microprocessor can be classified into several types, including data transfer instructions, arithmetic and logic instructions, program control instructions, and string instructions. Data transfer instructions are used to move data between registers and memory, arithmetic and logic instructions perform arithmetic and logical operations, program control instructions control the execution flow of the program, and string instructions perform operations on strings of data.

### Interrupts

The 8086 microprocessor supports both hardware and software interrupts. Hardware interrupts are generated by external devices, while software interrupts are generated by software programs. When an interrupt occurs, the microprocessor saves the current state of the program and executes the interrupt service routine (ISR), which is a special subroutine that handles the interrupt.

In conclusion, the architecture of the 8086 microprocessor is an important concept for computer technology. Understanding the register organization, bus interface unit, execution unit, memory addressing, and memory segmentation is crucial to designing and implementing computer systems. Additionally, knowledge of the operating modes, instruction sets, types of instructions, and interrupts is essential for programming and debugging applications on the 8086 microprocessor.
