

### Execution Unit

The execution unit is one of the three main components of the 8086 microprocessor. It is responsible for executing the instructions given by the user, which are stored in the memory. In this section, we will discuss the execution unit in detail.

#### Register Organization

The execution unit has several registers, which are used to store data temporarily. These registers are classified into three types: general-purpose registers, segment registers, and index registers.

- General-purpose registers: There are eight general-purpose registers in the execution unit. They are named as AX, BX, CX, DX, BP, SI, DI, and SP. These registers are used to store data temporarily during the execution of instructions.

- Segment registers: The execution unit has four segment registers, which are named as CS, DS, SS, and ES. These registers are used to store the base address of the segments in the memory.

- Index registers: The execution unit has two index registers, which are named as SI and DI. These registers are used to store the offsets or indices of the memory locations.

#### Bus Interface Unit

The bus interface unit is responsible for controlling the data transfer between the execution unit and the memory or input/output devices. It also generates the memory addresses and controls the timing of the data transfer.

#### Memory Addressing and Segmentation

The execution unit uses memory addressing to access the data stored in the memory. The memory is divided into segments, and each segment is addressed by a segment register. The execution unit also uses memory segmentation, which allows the memory to be divided into logical partitions.

#### Operating Modes

The execution unit operates in two modes: real mode and protected mode.

- Real mode: In real mode, the execution unit can access only 1 MB of memory. This mode is used for running the older programs that were designed for the earlier versions of the 8086 microprocessor.

- Protected mode: In protected mode, the execution unit can access up to 4 GB of memory. This mode is used for running the newer programs that require more memory.

#### Instruction Sets and Formats

The execution unit supports two instruction sets: the 8086 instruction set and the 80186 instruction set. The 8086 instruction set has a total of 117 instructions, while the 80186 instruction set has 126 instructions.

The instruction format of the execution unit consists of an opcode, which specifies the operation to be performed, and one or more operands, which are the data on which the operation is to be performed.

The execution unit supports several types of instructions, which are classified into the following categories:

- Data transfer instructions

#### Interrupts

The execution unit supports two types of interrupts: hardware interrupts and software interrupts.

- Hardware interrupts: Hardware interrupts are generated by the input/output devices or other hardware components of the computer. When a hardware interrupt occurs, the execution of the current program is suspended, and the control is transferred to the interrupt service routine.

- Software interrupts: Software interrupts are generated by the software programs. These interrupts are used for performing certain operations, such as calling a system function or handling an error.
