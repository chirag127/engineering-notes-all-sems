## Unit 3 - Architecture of 8086 Microprocessor

The 8086 microprocessor is a 16-bit microprocessor that was first introduced by Intel in 1978. This unit covers the architecture of the 8086 microprocessor, including the following topics:

### Register Organization

The 8086 microprocessor has 14 registers, which are used for various purposes. These registers can be classified into three categories:
- General Purpose Registers: AX, BX, CX, DX
- Segment Registers: CS, DS, SS, ES
- Pointer and Index Registers: SP, BP, SI, DI
- Flag Register: FLAGS

### Bus Interface Unit

The Bus Interface Unit (BIU) is responsible for fetching instructions and data from memory and sending them to the Execution Unit (EU). It also performs address calculation and generates memory addresses.

### Execution Unit

The Execution Unit (EU) is responsible for executing instructions. It contains the Arithmetic and Logic Unit (ALU), which performs arithmetic and logical operations, and the Control Unit (CU), which controls the flow of instructions.

### Memory Addressing and Segmentation

The 8086 microprocessor uses a segmentation model for memory addressing. Memory is divided into segments, which are addressed using segment registers. This allows for a larger address space than a purely 16-bit model.

### Operating Modes

The 8086 microprocessor has two operating modes:
- Real Mode: In this mode, the microprocessor behaves like a 16-bit processor with a maximum addressable memory of 1MB.
- Protected Mode: In this mode, the microprocessor can access up to 16MB of memory and provides memory protection.

### Instruction Sets

The 8086 microprocessor has two instruction sets:
- Real Mode Instruction Set: This set includes all the instructions that can be used in Real Mode.
- Protected Mode Instruction Set: This set includes additional instructions that can be used in Protected Mode.

### Instruction Format

Instructions in the 8086 microprocessor are of variable length, ranging from 1 to 6 bytes. Instructions can be divided into two categories:
- Register-Reference Instructions: These instructions operate on the registers.
- Memory-Reference Instructions: These instructions operate on the memory.

### Types of Instructions

The 8086 microprocessor supports various types of instructions, including:
- Data Transfer Instructions
- Arithmetic Instructions
- Logical Instructions
- Branch Instructions
- String Instructions
- Input/Output Instructions

### Interrupts

The 8086 microprocessor supports hardware and software interrupts. Hardware interrupts are generated by external devices, while software interrupts are generated by the program itself. Interrupts can be classified into two categories:
- Maskable Interrupts: These interrupts can be disabled by clearing the Interrupt Flag (IF) in the Flags Register.
- Non-Maskable Interrupts: These interrupts cannot be disabled and have higher priority than maskable interrupts.

This concludes the overview of the architecture of the 8086 microprocessor. Understanding these concepts is crucial for writing efficient programs for the 8086 microprocessor.
