### Instruction Sets for the Notes of the Unit 2 - Pin Diagram and Internal Architecture of 8085 Microprocessor

The 8085 microprocessor is an 8-bit microprocessor that is widely used in various applications such as embedded systems, automation, control systems, and many more. In this unit, we will be discussing the pin diagram and the internal architecture of the 8085 microprocessor. We will also be discussing the instruction sets that are used in the 8085 microprocessor.

#### Pin Diagram and Internal Architecture of 8085 Microprocessor

1. The 8085 microprocessor has a 40-pin dual in-line package (DIP).
2. The pins of the 8085 microprocessor are classified into six groups: power supply and clock, address bus, data bus, control and status signals, interrupt signals, and serial input/output signals.
3. The internal architecture of the 8085 microprocessor consists of registers, arithmetic logic unit (ALU), control and status signals, interrupt signals, and machine cycle.

#### Instruction Sets

1. The instruction sets in the 8085 microprocessor are classified into six categories: data transfer, arithmetic operations, logical operations, branching operations, machine control, and assembler directives.
2. Data transfer instructions are used to transfer data between registers or memory locations.
3. Arithmetic operations instructions are used to perform arithmetic operations such as addition, subtraction, multiplication, and division.
4. Logical operations instructions are used to perform logical operations such as AND, OR, XOR, and complement.
5. Branching operations instructions are used to transfer control to a different part of the program based on certain conditions.
6. Machine control instructions are used to control the flow of the program, such as halt, nop, and interrupt enable/disable.
7. Assembler directives instructions are used to provide instructions to the assembler, such as defining variables and constants.

#### Addressing Modes

1. The addressing modes in the 8085 microprocessor are classified into five categories: immediate addressing, direct addressing, indirect addressing, indexed addressing, and relative addressing.
2. Immediate addressing mode involves specifying the data directly in the instruction itself.
3. Direct addressing mode involves specifying the address of the memory location where the data is stored.
4. Indirect addressing mode involves specifying the address of the memory location where the address of the data is stored.
5. Indexed addressing mode involves specifying the address of the memory location where the index is stored and using it as an offset to access the data.
6. Relative addressing mode involves specifying the address of the memory location relative to the current program counter.

#### Instruction Formats

1. The instruction formats in the 8085 microprocessor are classified into three categories: one-byte instruction format, two-byte instruction format, and three-byte instruction format.
2. One-byte instruction format involves specifying the operation code (opcode) in the first byte of the instruction.
3. Two-byte instruction format involves specifying the opcode in the first byte and the operand in the second byte of the instruction.
4. Three-byte instruction format involves specifying the opcode in the first byte, the operand in the second byte, and the address in the third byte of the instruction.

In conclusion, the instruction sets are an important aspect of the 8085 microprocessor. By understanding the various instruction sets, addressing modes, and instruction formats, we can develop efficient programs that can be executed by the 8085 microprocessor.
