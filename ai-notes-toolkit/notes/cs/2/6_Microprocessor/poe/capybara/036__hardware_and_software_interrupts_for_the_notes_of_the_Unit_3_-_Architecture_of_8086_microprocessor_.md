### Hardware and Software Interrupts

Interrupts are signals that the microprocessor receives from different sources that stop the current execution of instructions, and divert the control to a different program or routine. Interrupts are categorized into two types, hardware interrupts, and software interrupts.

#### Hardware Interrupts

Hardware interrupts are the signals generated by the hardware devices attached to the microprocessor, such as keyboard, mouse, disk drive, etc. In 8086 microprocessor, hardware interrupts are identified by a unique interrupt number ranging from 0 to 255. Some of the important hardware interrupts are:

- Interrupt 0: Divide-by-zero interrupt
- Interrupt 1: Single-step interrupt
- Interrupt 2: Non-maskable interrupt
- Interrupt 3: Breakpoint interrupt
- Interrupt 4: Overflow interrupt
- Interrupt 5: Bound range exceeded interrupt
- Interrupt 6: Invalid opcode interrupt
- Interrupt 7: Coprocessor not available interrupt
- Interrupt 8: Double fault interrupt
- Interrupt 9: Coprocessor segment overrun interrupt
- Interrupt 10: Invalid Task State Segment (TSS) interrupt
- Interrupt 11: Segment not present interrupt
- Interrupt 12: Stack exception interrupt
- Interrupt 13: General protection fault interrupt
- Interrupt 14: Page fault interrupt
- Interrupt 15: Reserved interrupt
- Interrupt 16: Floating-point exception interrupt
- Interrupt 17: Alignment check interrupt
- Interrupt 18: Machine check interrupt
- Interrupt 19: SIMD floating-point exception interrupt
- Interrupt 20 to 31: Reserved for external hardware interrupts

#### Software Interrupts

Software interrupts are the interrupts that are generated by the software programs running on the microprocessor. In 8086 microprocessor, software interrupts are identified by the INT instruction, followed by a software interrupt number ranging from 0 to 255. Some of the important software interrupts are:

- Interrupt 0: Divide-by-zero exception
- Interrupt 1: Single-step exception
- Interrupt 2: NMI
- Interrupt 3: Breakpoint exception
- Interrupt 4: Overflow exception
- Interrupt 5: Bounds check exception
- Interrupt 6: Invalid opcode exception
- Interrupt 7: Coprocessor not available exception
- Interrupt 8: Double fault exception
- Interrupt 9: Coprocessor segment overrun exception
- Interrupt 10: Invalid TSS exception
- Interrupt 11: Segment not present exception
- Interrupt 12: Stack exception
- Interrupt 13: General protection fault exception
- Interrupt 14: Page fault exception
- Interrupt 15: Reserved
- Interrupt 16: Coprocessor error exception
- Interrupt 17: Alignment check exception
- Interrupt 18: Machine check exception

Interrupts are essential in the microprocessor, as they make the system more efficient by allowing the microprocessor to perform different tasks simultaneously. Understanding interrupts is crucial for any programmer working with the microprocessor.
