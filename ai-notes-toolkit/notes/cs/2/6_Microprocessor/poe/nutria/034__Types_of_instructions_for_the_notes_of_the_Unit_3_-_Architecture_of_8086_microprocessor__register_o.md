
### Types of instructions for the notes of the Unit 3 - Architecture of 8086 microprocessor: 

* Register Organization: The 8086 microprocessor uses 16-bit registers to store data and instructions. The registers are divided into 4 categories: General-Purpose Registers, Segment Registers, Pointer Registers and Index Registers. 

* Bus Interface Unit: The Bus Interface Unit (BIU) is responsible for managing the communication between the processor and the rest of the system. It is responsible for fetching instructions and data from memory, decoding them and sending them to the Execution Unit. 

* Execution Unit: The Execution Unit (EU) is responsible for executing the instructions fetched from memory. It is responsible for decoding the instructions and executing them accordingly. It also handles interrupts and exceptions.

* Memory Addressing: The 8086 microprocessor uses a segmented memory addressing scheme. Each memory location is identified by a segment and an offset. The segment is the starting address of a segment of memory and the offset is the distance between the starting address and the memory location.

* Memory Segmentation: The 8086 microprocessor uses memory segmentation to divide the memory into segments. Each segment is used for a specific purpose, such as code, data, stack, etc. The segments can be moved around in memory to optimize the use of memory.

* Operating Modes: The 8086 microprocessor can operate in two modes: Real Address Mode (RAM) and Protected Mode (PM). In RAM, the processor can access the entire physical memory, while in PM, the processor can access only a portion of the physical memory.

* Instruction Sets: The 8086 microprocessor supports three instruction sets: 8086, 80286 and 80386. Each instruction set has its own set of instructions, which are used to perform various operations.

* Instruction Format: The 8086 microprocessor uses a two-byte instruction format. The first byte is the opcode, which specifies the type of instruction to be executed, and the second byte is the operand, which specifies the data to be used in the instruction.

* Types of Instructions: The 8086 microprocessor supports a variety of instructions, including arithmetic, logical, data transfer, control transfer, interrupt and exception handling instructions.

* Interrupts: The 8086 microprocessor supports two types of interrupts: hardware interrupts and software interrupts. Hardware interrupts are triggered by external hardware devices, while software interrupts are triggered by software instructions.

* Software Interrupts: Software interrupts are triggered by software instructions. They are used to perform various operations, such as system calls, system initialization, and exception handling.
