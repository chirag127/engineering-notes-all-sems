
### Pin diagram and internal architecture of 8085 microprocessor

The 8085 microprocessor is an 8-bit processor with a 40-pin package. It has 8-bit ALU (Arithmetic Logic Unit) and 8-bit registers. The 8085 microprocessor has the following components:

* Registers: The 8085 microprocessor has 6 8-bit registers (A, B, C, D, E, and H) and one 16-bit register (L).

* ALU: The ALU performs arithmetic and logical operations on data.

* Control & Status: The control & status unit is responsible for controlling the flow of instructions and data, as well as generating status signals.

* Interrupt: The 8085 microprocessor supports two interrupt signals: INTR and RST 7.5.

* Machine Cycle: The 8085 microprocessor has five machine cycles: Opcode Fetch, Memory Read, Memory Write, I/O Read and I/O Write.

* Instruction Sets: The 8085 microprocessor supports two instruction sets: the 8-bit set and the 16-bit set.

* Addressing Modes: The 8085 microprocessor supports four addressing modes: immediate, direct, register and indirect.

* Instruction Formats: The 8085 microprocessor supports three instruction formats: one-byte, two-byte and three-byte.

* Instruction Classification: The 8085 microprocessor supports the following instruction types: data transfer, arithmetic operations, logical operations, branching operations, machine control and assembler directives.
