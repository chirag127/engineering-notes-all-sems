
## Unit 3 - Architecture of 8086 microprocessor

* Register Organization: The 8086 microprocessor contains 16-bit registers and 8-bit registers. The 16-bit registers are used to store data and addresses while the 8-bit registers are used to store data.

* Bus Interface Unit: The 8086 microprocessor contains a Bus Interface Unit (BIU) which is responsible for fetching instructions from memory and transferring data between the processor and memory.

* Execution Unit: The Execution Unit (EU) is responsible for executing instructions.

* Memory Addressing: The 8086 microprocessor supports two types of memory addressing: direct and indirect. Direct addressing is used when the memory address is known and indirect is used when the address is not known.

* Memory Segmentation: The 8086 microprocessor uses segmentation to divide memory into segments. Each segment is a 16-bit address space and is used to store data and instructions.

* Operating Modes: The 8086 microprocessor supports two operating modes: real mode and protected mode. Real mode is used for running programs written for the 8086 processor while protected mode is used for running programs written for the 80286 processor and higher.

* Instruction Sets: The 8086 microprocessor supports two instruction sets: the 8086 instruction set and the 80286 instruction set.

* Instruction Format: The 8086 microprocessor supports two instruction formats: the one-byte and two-byte instruction formats.

* Types of Instructions: The 8086 microprocessor supports two types of instructions: the data transfer instructions and the arithmetic instructions.

* Interrupts: The 8086 microprocessor supports two types of interrupts: hardware interrupts and software interrupts. Hardware interrupts are triggered by external devices while software interrupts are triggered by programs.
