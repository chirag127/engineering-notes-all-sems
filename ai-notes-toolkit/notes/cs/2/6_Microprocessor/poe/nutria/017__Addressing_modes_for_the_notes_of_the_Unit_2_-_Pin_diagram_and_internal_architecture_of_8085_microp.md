
### Addressing Modes for the Notes of Unit 2 - Pin Diagram and Internal Architecture of 8085 Microprocessor

* The 8085 microprocessor consists of the following components:
  * Registers: These are the storage locations inside the microprocessor.
  * ALU (Arithmetic Logic Unit): This is responsible for performing arithmetic and logical operations.
  * Control & Status: This is responsible for controlling the flow of the program and keeping track of the status of the microprocessor.
  * Interrupts: This is responsible for handling external interrupts.
  * Machine Cycle: This is responsible for controlling the timing of the microprocessor.

* Instruction Sets: The 8085 microprocessor has a set of instructions that it can understand and execute.

* Addressing Modes: There are various addressing modes that are used to specify the location of data and instructions in memory. These include:
  * Immediate Addressing: This is used to specify a constant value as an operand.
  * Direct Addressing: This is used to specify the memory location of an operand.
  * Register Addressing: This is used to specify the contents of a register as an operand.
  * Indirect Addressing: This is used to specify the memory location of the address of an operand.

* Instruction Formats: The 8085 microprocessor uses a variety of instruction formats to specify the operation to be performed. These include:
  * Single-Byte Instructions: These instructions consist of one byte and are used to perform simple operations.
  * Two-Byte Instructions: These instructions consist of two bytes and are used to perform more complex operations.
  * Three-Byte Instructions: These instructions consist of three bytes and are used to perform more complex operations.

* Instruction Classification: Instructions can be classified into the following categories:
  * Data Transfer Instructions: These are used to move data between memory and registers.
  * Arithmetic Instructions: These are used to perform arithmetic operations on data.
  * Logical Instructions: These are used to perform logical operations on data.
  * Branching Instructions: These are used to transfer control to a different part of the program.
  * Machine Control Instructions: These are used to control the operation of the microprocessor.
  * Assembler Directives: These are used to specify instructions to the assembler.
