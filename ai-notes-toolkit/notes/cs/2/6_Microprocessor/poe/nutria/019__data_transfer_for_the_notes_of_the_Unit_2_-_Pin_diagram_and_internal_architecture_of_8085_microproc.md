
### Data Transfer for the Notes of the Unit 2 - Pin diagram and internal architecture of 8085 microprocessor

* The 8085 microprocessor consists of the following components:
  * Registers: Used to store data and instructions.
  * ALU: Arithmetic and Logic Unit, which performs arithmetic operations such as addition and subtraction, and logical operations such as AND, OR and NOT.
  * Control & Status: Used to control the operation of the microprocessor and to provide status information.
  * Interrupt: A type of signal that can be used to pause the current operation and start a new one.
  * Machine Cycle: A sequence of steps that the microprocessor follows to execute an instruction.

### Instruction Sets

* An instruction set is a list of instructions that can be executed by the microprocessor.
* Each instruction has an opcode (operation code) that is used to identify it.
* The 8085 has a total of 77 instructions.

### Addressing Modes

* Addressing modes are used to specify the location of data and instructions in memory.
* The 8085 has six addressing modes:
  * Immediate: Data is specified directly in the instruction.
  * Direct: Data is specified by a memory address.
  * Register: Data is specified by a register.
  * Register Indirect: Data is specified by a register that contains a memory address.
  * Indexed: Data is specified by a memory address that is calculated using a register.
  * Relative: Data is specified by a memory address that is calculated using the program counter.

### Instruction Formats

* An instruction format is a set of fields that are used to specify an instruction.
* The 8085 has three instruction formats:
  * One-byte: Contains an 8-bit opcode.
  * Two-byte: Contains an 8-bit opcode and an 8-bit operand.
  * Three-byte: Contains an 8-bit opcode, an 8-bit address and an 8-bit operand.

### Instruction Classification

* Instructions can be classified according to the type of operation they perform:
  * Data Transfer: Used to move data between memory and registers.
  * Arithmetic Operations: Used to perform arithmetic operations such as addition and subtraction.
  * Logical Operations: Used to perform logical operations such as AND, OR and NOT.
  * Branching Operations: Used to jump to a different part of the program.
  * Machine Control: Used to control the operation of the microprocessor.
  * Assembler Directives: Used to specify information about the program.
