
### ALU for the Notes of the Unit 2 - Pin Diagram and Internal Architecture of 8085 Microprocessor, Registers, ALU, Control & Status, Interrupt and Machine Cycle

* The 8085 Microprocessor is an 8-bit processor that uses an ALU (Arithmetic Logic Unit) for performing arithmetic and logic operations. 
* It has a 16-bit address bus and an 8-bit data bus. 
* It has 8 registers, namely A, B, C, D, E, H, L, and SP (Stack Pointer). 
* The Control & Status register contains the status of the processor and the interrupt enable/disable flags. 
* The 8085 Microprocessor has five interrupt sources: TRAP, RST 7.5, RST 6.5, RST 5.5, and INTR.
* The Machine Cycle is the basic unit of operation of the 8085 Microprocessor. It consists of four steps: Opcode Fetch, Memory Read, Memory Write, and I/O Read/Write.
* The Instruction Set of the 8085 Microprocessor consists of instructions for data transfer, arithmetic operations, logical operations, branching operations, machine control, and assembler directives. 
* The Addressing Modes of the 8085 Microprocessor are Immediate, Direct, Register, Register Indirect, and Indexed addressing modes. 
* The Instruction Formats of the 8085 Microprocessor are one-byte, two-byte, and three-byte instructions. 
* The Instruction Classification of the 8085 Microprocessor includes data transfer, arithmetic operations, logical operations, branching operations, machine control, and assembler directives.
