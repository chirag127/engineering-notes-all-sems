
### Data Transfer for the Notes of the Unit 4 - Assembly Language Programming Based on Intel 8085/8086

* Instructions: 
  * Data Transfer: Transferring data between registers, memory and I/O devices.
  * Arithmetic: Addition, subtraction, multiplication and division.
  * Logic: Bit manipulation, logical operations, and comparison operations.
  * Branch Operations: Unconditional and conditional jumps, subroutines, and interrupts.
  * Looping, Counting and Indexing: Repetition of instructions, looping, counting and indexing.
* Programming Techniques:
  * Counters and Time Delays: Utilizing counters and time delays to create delays.
  * Stacks and Subroutines: Utilizing stacks and subroutines to store and recall data.
  * Conditional Call and Return Instructions: Utilizing conditional calls and returns to create conditional branching.
* Microprocessor KCS:
  * Understanding the architecture of the Intel 8085/8086 microprocessor and its instruction set.
  * Learning the fundamentals of assembly language programming for the 8085/8086 microprocessor.
  * Developing assembly language programs for the 8085/8086 microprocessor.
