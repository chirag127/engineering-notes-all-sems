
### Instruction sets for the notes of the Unit 3 - Architecture of 8086 microprocessor: 

1. Register Organization: The 8086 microprocessor consists of four 8-bit registers (AX, BX, CX, DX) and six 16-bit registers (SP, BP, SI, DI, CS, DS). The registers are used to store data and instructions, and can be used to perform arithmetic and logical operations. 

2. Bus Interface Unit: The bus interface unit (BIU) is responsible for fetching instructions from memory and transferring data and instructions to and from the processor. It also performs address calculations and transfers data between the processor and memory.

3. Execution Unit: The execution unit (EU) is responsible for executing instructions and performing arithmetic and logical operations on data.

4. Memory Addressing: The 8086 microprocessor supports two types of memory addressing: linear and segmented. Linear addressing allows the processor to access memory directly, while segmented addressing requires the processor to calculate the memory address from a segment and offset.

5. Memory Segmentation: The 8086 microprocessor uses memory segmentation to divide memory into segments of 64KB. Each segment is assigned a 16-bit segment address, which is used to calculate the memory address of a particular location in memory.

6. Operating Modes: The 8086 microprocessor supports two operating modes: real mode and protected mode. Real mode is used to access memory up to 1MB, while protected mode allows the processor to access memory up to 16MB.

7. Instruction Sets: The 8086 microprocessor supports two instruction sets: the 8086 instruction set and the 80286 instruction set. The 8086 instruction set consists of instructions for performing arithmetic and logical operations, branching, looping, and interrupt handling. The 80286 instruction set adds instructions for memory segmentation and paging.

8. Instruction Format: The 8086 microprocessor supports two instruction formats: one-byte and two-byte. One-byte instructions are used to perform simple operations, while two-byte instructions are used to perform more complex operations.

9. Types of Instructions: The 8086 microprocessor supports two types of instructions: data transfer instructions and arithmetic/logical instructions. Data transfer instructions are used to move data between memory and registers, while arithmetic/logical instructions are used to perform arithmetic and logical operations on data.

10. Interrupts: The 8086 microprocessor supports two types of interrupts: hardware interrupts and software interrupts. Hardware interrupts are triggered by external devices, while software interrupts are triggered by instructions.
