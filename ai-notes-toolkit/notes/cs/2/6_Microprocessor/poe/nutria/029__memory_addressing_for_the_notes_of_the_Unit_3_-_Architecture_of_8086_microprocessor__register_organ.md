

### Memory Addressing for the Notes of the Unit 3 - Architecture of 8086 Microprocessor 

* Register Organization: The 8086 microprocessor consists of four main parts - the Bus Interface Unit (BIU), the Execution Unit (EU), the Memory Address Register (MAR) and the Memory Data Register (MDR). The BIU is responsible for fetching instructions from memory and sending them to the EU for execution. The MAR stores the address of the memory location to be accessed and the MDR stores the data that is to be written to or read from memory. 
* Bus Interface Unit: The Bus Interface Unit (BIU) is responsible for controlling the data and address buses. It fetches instructions from memory, decodes them and sends them to the EU for execution. It also sends the addresses of memory locations to the MAR. 
* Execution Unit: The Execution Unit (EU) is responsible for executing instructions. It contains the Arithmetic Logic Unit (ALU) which performs arithmetic and logical operations, the Program Counter (PC) which stores the address of the next instruction to be executed, the Stack Pointer (SP) which stores the address of the top of the stack and the Instruction Register (IR) which stores the instruction that is currently being executed. 
* Memory Addressing: The 8086 microprocessor uses two types of memory addressing - direct and indirect. In direct addressing, the address of the memory location to be accessed is given directly in the instruction. In indirect addressing, the address of the memory location is stored in a register or memory location and the address of the register or memory location is given in the instruction. 
* Memory Segmentation: The 8086 microprocessor uses memory segmentation to divide memory into segments of up to 64Kb. Each segment can be addressed by a 16-bit segment address. The segment address is combined with a 16-bit offset address to form a 20-bit physical address. 
* Operating Modes: The 8086 microprocessor has two operating modes - real mode and protected mode. In real mode, the microprocessor operates in 16-bit mode and can only access up to 1MB of memory. In protected mode, the microprocessor operates in 32-bit mode and can access up to 4GB of memory. 
* Instruction Sets: The 8086 microprocessor supports two instruction sets - the 8086 instruction set and the 8087 instruction set. The 8086 instruction set consists of instructions for arithmetic, logical and control operations. The 8087 instruction set consists of instructions for floating-point operations. 
* Instruction Format: The 8086 microprocessor supports three instruction formats - one-byte, two-byte and three-byte. The one-byte instruction format consists of an opcode and an optional immediate data byte. The two-byte instruction format consists of an opcode and two optional immediate data bytes. The three-byte instruction format consists of an opcode and three optional immediate data bytes. 
* Types of Instructions: The 8086 microprocessor supports five types of instructions - data transfer, arithmetic, logical, control and string instructions. Data transfer instructions are used to move data between memory and registers. Arithmetic instructions are used to perform arithmetic operations. Logical instructions are used to perform logical operations. Control instructions are used to control the flow of the program. String instructions are used to move data between memory and registers in blocks. 
* Interrupts: The 8086 microprocessor supports two types of interrupts - hardware interrupts and software interrupts. Hardware interrupts are generated by external devices such as the keyboard and the mouse. Software interrupts are generated by instructions in the program.
