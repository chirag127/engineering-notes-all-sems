## Unit 4 - Assembly language programming based on intel 8085/8086. Instructions, data transfer, arithmetic, logic, branch operations, looping, counting, indexing, programming techniques, counters and time delays, stacks and subroutines, conditional call and return instructions

- Assembly language is a low-level programming language that uses mnemonics to represent machine instructions. Each mnemonic corresponds to a binary opcode that the processor can execute.
- Intel 8085 and 8086 are two microprocessors that belong to the x86 family. They have different architectures, instruction sets, and addressing modes.
- Intel 8085 is an 8-bit microprocessor that has a 16-bit address bus and a 8-bit data bus. It can address up to 64 KB of memory. It has 74 instructions, divided into five groups: data transfer, arithmetic, logic, branch, and control.
- Intel 8086 is a 16-bit microprocessor that has a 20-bit address bus and a 16-bit data bus. It can address up to 1 MB of memory. It has 133 instructions, divided into nine groups: data transfer, arithmetic, logic, shift and rotate, string, branch, loop, flag manipulation, and processor control.
- Data transfer instructions are used to move data between registers, memory, and I/O devices. Some examples are MOV, MVI, LDA, STA, IN, and OUT.
- Arithmetic instructions are used to perform addition, subtraction, increment, decrement, and decimal adjustment operations on data. Some examples are ADD, SUB, INR, DCR, and DAA.
- Logic instructions are used to perform bitwise logical operations on data, such as AND, OR, XOR, NOT, and compare. Some examples are ANA, ORA, XRA, CMA, and CMP.
- Branch instructions are used to alter the sequence of execution based on certain conditions, such as flags, registers, or memory contents. Some examples are JMP, JZ, JNZ, JC, JNC, CALL, and RET.
- Looping instructions are used to repeat a block of code for a specified number of times or until a condition is met. Some examples are LOOP, LOOPE, LOOPNE, and CX.
- Counting instructions are used to increment or decrement a register or a memory location by one. Some examples are INC, DEC, INX, and DCX.
- Indexing instructions are used to access data in memory using an index register that holds the base address of the data. Some examples are LXI, LDAX, STAX, and XCHG.
- Programming techniques are methods or strategies to write efficient and structured assembly programs. Some examples are modular programming, top-down design, bottom-up design, and debugging tools.
- Counters and time delays are used to measure the duration of events or to generate precise timing signals. They can be implemented using loops, timers, or interrupts.
- Stacks and subroutines are used to store and retrieve data or return addresses during program execution. They can be implemented using stack pointer, stack segment, push, pop, call, and return instructions.
- Conditional call and return instructions are used to invoke or exit a subroutine based on certain conditions, such as flags, registers, or memory contents. Some examples are CC, CNC, CZ, CNZ, RC, and RNC.
