### Register Organization for the Notes of the Unit 3 - Architecture of 8086 Microprocessor

- The 8086 microprocessor is a 16-bit processor that has a complex internal architecture consisting of two main units: the Bus Interface Unit (BIU) and the Execution Unit (EU).
- The BIU is responsible for fetching instructions from memory, decoding them, and transferring data to and from memory and I/O devices via the system bus.
- The EU is responsible for executing the instructions and performing arithmetic and logical operations on data.
- The 8086 microprocessor has 14 user-accessible 16-bit registers that are grouped into four categories: data registers, pointer and index registers, segment registers, and instruction pointer and flags register.
- The data registers are AX, BX, CX, and DX, which can be used to store operands and results of arithmetic and logical operations. Each data register can be split into two 8-bit registers, such as AH and AL for AX, for performing 8-bit operations.
- The pointer and index registers are SP, BP, SI, and DI, which can be used to store addresses of data in memory. SP and BP are used as stack pointer and base pointer for stack operations, while SI and DI are used as source and destination index for string operations.
- The segment registers are CS, DS, SS, and ES, which are used to store the 16-bit segment addresses of the code, data, stack, and extra segments in memory. The 8086 microprocessor uses a segmented memory model, where the physical address of any location is calculated by adding the segment address and the offset address.
- The instruction pointer and flags register are IP and FLAGS, which are used to store the 16-bit offset address of the next instruction to be executed and the status and control flags of the processor. The flags register has 9 bits that indicate the result of the previous operation or the state of the processor, such as the carry flag, the zero flag, the sign flag, the overflow flag, the direction flag, the interrupt flag, the trap flag, and the parity flag.
- The 8086 microprocessor has three operating modes: the minimum mode, the maximum mode, and the protected mode. The minimum mode is used when the 8086 is the only processor in the system, while the maximum mode is used when the 8086 is interfaced with a coprocessor such as the 8087. The protected mode is used to access more than 1 MB of memory and to provide memory protection and multitasking features.
- The 8086 microprocessor has a rich instruction set that can be classified into five types: data transfer instructions, arithmetic instructions, logical instructions, control transfer instructions, and string instructions. The instruction format consists of one or more bytes, where the first byte is the opcode and the following bytes are the operands or the displacement or the immediate data.
- The 8086 microprocessor supports two types of interrupts: hardware interrupts and software interrupts. Hardware interrupts are generated by external devices such as the keyboard, the timer, or the disk controller, and are handled by the interrupt controller chip 8259. Software interrupts are generated by the program using the INT instruction, and are handled by the interrupt service routines stored in the interrupt vector table located at the beginning of the memory.
