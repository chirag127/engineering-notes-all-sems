### Architecture of 8086 microprocessor

- Execution unit (EU): The EU is responsible for decoding and executing instructions, performing arithmetic and logical operations, and accessing data from memory or registers. The EU contains the general-purpose registers, the pointer and index registers, and the flag register.
- Memory addressing: The 8086 uses a 20-bit address bus to access up to 1 MB of memory. The physical address is calculated by adding the segment address (multiplied by 16) and the offset address. The segment address is stored in one of the four segment registers: code segment (CS), data segment (DS), stack segment (SS), or extra segment (ES). The offset address is specified by the instruction or by one of the pointer or index registers: instruction pointer (IP), base pointer (BP), stack pointer (SP), source index (SI), or destination index (DI).
- Memory segmentation: The 8086 divides the memory into segments of up to 64 KB each. Each segment has a base address and a limit. The base address is the starting address of the segment, and the limit is the number of bytes in the segment minus one. Segments can overlap or be disjoint. Segments can be used for different purposes, such as code, data, stack, or extra data.
