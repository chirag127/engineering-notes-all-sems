# Microprocessor Architecture and Operation of Its Components

- A microprocessor is a single integrated circuit (IC) that contains the data processing logic and control of a computer's central processing unit (CPU) .
- A microprocessor consists of three main components: arithmetic logic unit (ALU), control unit (CU), and register array .
- The ALU performs arithmetic and logical operations on the data received from an input device or memory . It can also perform operations on floating-point numbers .
- The CU controls the instructions and flow of data within the computer . It generates control signals to coordinate the execution of instructions by the ALU and the register array .
- The register array consists of a set of registers that store data temporarily during the execution of instructions . Some of the registers are:
  - Accumulator: It holds one of the operands as well as the result in operations performed by the ALU .
  - Program counter: It holds the address of the next instruction to be executed .
  - Instruction register: It holds the current instruction being executed .
  - Status register: It holds the flags that indicate the status of the ALU operations .
- A microprocessor also has a system bus that connects it to the memory modules and the input/output unit . The system bus consists of three types of lines: data bus, address bus, and control bus .
- The data bus transfers data between the microprocessor and the memory or the input/output unit . It is bidirectional and has a fixed width (e.g., 8 bits, 16 bits, etc.) .
- The address bus transfers the addresses of the memory locations or the input/output devices to be accessed by the microprocessor . It is unidirectional and has a fixed width (e.g., 16 bits, 32 bits, etc.) .
- The control bus transfers the control signals between the microprocessor and the memory or the input/output unit . It is bidirectional and has a variable number of lines depending on the microprocessor .
