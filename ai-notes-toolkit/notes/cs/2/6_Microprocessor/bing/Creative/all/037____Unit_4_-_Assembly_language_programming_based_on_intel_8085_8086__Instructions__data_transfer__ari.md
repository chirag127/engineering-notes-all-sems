# Unit 4 - Assembly language programming based on intel 8085/8086

- Assembly language is a low-level language that uses mnemonics to represent the binary instructions that the microprocessor can execute  .
- Assembly language is specific to a given processor, so the syntax and instruction set of 8085 and 8086 are different .
- 8085 is an 8-bit microprocessor that can address 64 KB of memory, while 8086 is a 16-bit microprocessor that can address 1 MB of memory.
- 8085 has a single accumulator (A) and six general purpose registers (B, C, D, E, H, L), while 8086 has four data registers (AX, BX, CX, DX) and four pointer/index registers (SP, BP, SI, DI).
- 8085 has 74 instructions, while 8086 has 133 instructions.
- 8085 has five addressing modes: immediate, register, direct, register indirect, and implied, while 8086 has nine addressing modes: immediate, register, direct, register indirect, based, indexed, based indexed, relative, and based indexed with displacement.
- The instructions in assembly language can be classified into four categories: data transfer, arithmetic, logic, and branch operations  .
- Data transfer instructions are used to move data between registers, memory, and I/O devices. Examples are MOV, MVI, LDA, STA, IN, OUT, etc.  .
- Arithmetic instructions are used to perform arithmetic operations on data, such as addition, subtraction, multiplication, division, increment, and decrement. Examples are ADD, SUB, MUL, DIV, INR, DCR, etc.  .
- Logic instructions are used to perform logical operations on data, such as AND, OR, XOR, NOT, complement, shift, and rotate. Examples are ANA, ORA, XRA, CMA, RLC, RRC, etc.  .
- Branch operations are used to alter the sequence of execution of instructions, such as jump, call, return, and loop. Examples are JMP, JC, JNC, CALL, RET, LOOP, etc.  .
- Looping, counting, and indexing are programming techniques that use branch operations and registers to repeat a set of instructions for a certain number of times or until a condition is met  .
- Counters and time delays are programming techniques that use loop instructions and register values to generate a specific duration of time for the microprocessor to perform a task or wait for an event  .
- Stacks and subroutines are programming techniques that use the stack pointer (SP) register and the memory to store and retrieve data or return addresses during the execution of a program  .
- Conditional call and return instructions are branch operations that allow the microprocessor to execute a subroutine or return from it based on a condition flag, such as carry, zero, sign, parity, etc.  .
