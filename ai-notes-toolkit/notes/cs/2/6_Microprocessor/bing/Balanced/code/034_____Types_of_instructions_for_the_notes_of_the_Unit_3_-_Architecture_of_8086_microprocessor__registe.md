### Types of instructions for the notes of the Unit 3 - Architecture of 8086 microprocessor: register organization, bus interface unit, execution unit, memory addressing, and memory segmentation. Operating modes. Instruction sets, instruction format, Types of instructions. Interrupts: hardware and software interrupts.

- The 8086 microprocessor is a 16-bit microprocessor that has 16 data lines and 20 address lines. It can address up to 1 MB of memory. It consists of two independent sections or units: the bus interface unit (BIU) and the execution unit (EU)   .
- The BIU provides the interface of 8086 to external memory and I/O devices via the system bus. It performs various machine cycle operations such as fetch, read, write, and interrupt acknowledge. It also contains a 6-byte instruction queue that prefetches instructions from memory and stores them for the EU to execute  .
- The EU executes the instructions fetched by the BIU. It contains the arithmetic and logic unit (ALU), the control unit, the decode unit, and the registers. The registers are divided into two groups: general-purpose registers and special-purpose registers  .
- The general-purpose registers are AX, BX, CX, and DX. They can be used for data manipulation and arithmetic operations. They can also be accessed as 8-bit registers by using their high and low parts, such as AH and AL for AX. The special-purpose registers are SP, BP, SI, DI, IP, CS, DS, SS, ES, and FLAGS. They are used for various functions such as stack pointer, base pointer, source index, destination index, instruction pointer, code segment, data segment, stack segment, extra segment, and status flags  .
- The memory addressing of 8086 is based on the concept of segmentation. The memory is divided into segments of 64 KB each, and each segment has a 16-bit address. The segments are identified by the segment registers CS, DS, SS, and ES. To access a memory location, the 8086 uses a 20-bit physical address, which is formed by adding a 16-bit offset address to a 16-bit segment address. The offset address can be specified by using the general-purpose registers, the special-purpose registers, or immediate values  .
- The 8086 has two operating modes: minimum mode and maximum mode. In minimum mode, the 8086 operates as a single processor in a system. It uses the control signals generated by itself to control the memory and I/O devices. In maximum mode, the 8086 operates as a master processor in a multiprocessor system. It uses an external coprocessor, such as 8087, 8089, or 8088, to perform some tasks. It also uses an external bus controller, such as 8288, to generate the control signals for the memory and I/O devices  .
- The 8086 supports 8 types of instructions: data transfer instructions, arithmetic instructions, bit manipulation instructions, string instructions, program execution transfer instructions, processor control instructions, iteration control instructions, and interrupt instructions . The instruction format of 8086 consists of one or more bytes, which include the opcode, the addressing mode, the operands, and the prefixes. The opcode specifies the operation to be performed, the addressing mode specifies how the operands are accessed, the operands specify the data or the addresses involved in the operation, and the prefixes modify the default segment, size, or direction of the operation  .
- The interrupts of 8086 are signals that cause the processor to suspend the current program and execute a subroutine. There are two types of interrupts: hardware interrupts and software interrupts. Hardware interrupts are generated by external devices, such as keyboard, timer, or printer, to request the processor's attention. Software interrupts are generated by the program, using the INT instruction, to invoke a predefined service routine. The 8086 has 256 interrupt vectors, each corresponding to a 4-byte address in the memory. The interrupt vector table is located at the beginning of the memory, from 0000H to 03FFH  .
