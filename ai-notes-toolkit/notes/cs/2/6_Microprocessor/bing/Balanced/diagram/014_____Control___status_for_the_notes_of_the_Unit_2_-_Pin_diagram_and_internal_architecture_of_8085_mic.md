### Control and Status

- The 8085 microprocessor provides two control signals, RD and WR, to initiate read or write cycle. These signals are used both for reading/writing memory and for reading/writing an input/output device.
- The 8085 microprocessor also provides a signal, IO/M, to indicate whether the initiated cycle is for an input/output device or for a memory device. IO/M is high for input/output operations and low for memory operations .
- The 8085 microprocessor has three status signals, S0, S1 and S2, which indicate the type of operation being performed. The status signals are encoded as follows :

| S2 | S1 | S0 | Operation |
|----|----|----|-----------|
| 0  | 0  | 0  | HALT      |
| 0  | 0  | 1  | WRITE     |
| 0  | 1  | 0  | READ      |
| 0  | 1  | 1  | FETCH     |
| 1  | 0  | 0  | INTERRUPT |
| 1  | 0  | 1  | DMA       |
| 1  | 1  | 0  | HOLD      |
| 1  | 1  | 1  | RESET     |

- The 8085 microprocessor also has a signal, READY, which is used to synchronize the microprocessor with slower devices. READY is an active low signal, which means that the device is ready when it is low. When READY is high, the microprocessor waits until it becomes low before completing the current cycle .
- The 8085 microprocessor also has a signal, RESET IN, which is used to reset the microprocessor and initialize the registers. RESET IN is an active high signal, which means that the microprocessor is reset when it is high. The microprocessor remains in the reset state as long as RESET IN is high .
- The 8085 microprocessor also has a signal, RESET OUT, which is used to reset the peripheral devices connected to the microprocessor. RESET OUT is an active low signal, which means that the peripheral devices are reset when it is low. RESET OUT is generated by the microprocessor after it is reset by RESET IN .
- The 8085 microprocessor also has a signal, HOLD, which is used by an external device to request the microprocessor to relinquish the control of the buses. HOLD is an active high signal, which means that the request is made when it is high. The microprocessor acknowledges the request by sending a signal, HLDA, which is an active high signal. The microprocessor then enters the hold state and tri-states the buses. The external device can then use the buses for its own purpose. The microprocessor resumes the normal operation when HOLD becomes low .
- The 8085 microprocessor also has a signal, INTR, which is used by an external device to request the microprocessor to execute an interrupt service routine. INTR is an active high signal, which means that the request is made when it is high. The microprocessor acknowledges the request by sending a signal, INTA, which is an active low signal. The microprocessor then executes a call instruction to jump to the interrupt service routine. The external device provides the lower 8 bits of the address of the interrupt service routine on the data bus during the INTA cycle .
- The 8085 microprocessor also has a signal, TRAP, which is used by an external device to request the microprocessor to execute a non-maskable interrupt service routine. TRAP is an active high edge-triggered signal, which means that the request is made when it goes from low to high. The microprocessor acknowledges the request by sending a signal, INTA, which is an active low signal. The microprocessor then executes a call instruction to jump to the interrupt service routine. The address of the interrupt service routine is fixed at 0024H .
