### Interrupt and Machine Cycle

- An interrupt is a signal that causes the microprocessor to temporarily stop its current program execution and switch to a predefined subroutine called an interrupt service routine (ISR).
- The ISR performs the task requested by the interrupting device and then returns control to the main program.
- The 8085 microprocessor has five hardware interrupt pins: INTR, RST 7.5, RST 6.5, RST 5.5, and TRAP  .
- The hardware interrupts are initiated by external devices by applying an appropriate signal at the interrupt pin of the microprocessor.
- The microprocessor checks the interrupt pins after each instruction execution and if any interrupt is enabled, it acknowledges the interrupt by sending an INTA' signal to the device.
- The device then sends an 8-bit instruction to the microprocessor, which can be either a CALL or a RST instruction.
- The microprocessor executes the instruction and jumps to the ISR address.
- The ISR address can be either predefined (for RST instructions) or specified by the device (for CALL instructions).
- The microprocessor saves the address of the next instruction on the stack before jumping to the ISR.
- After completing the ISR, the microprocessor returns to the main program by popping the address from the stack and using a RET instruction.
- The interrupts can be classified into two types: maskable and non-maskable.
- Maskable interrupts are those that can be enabled or disabled by software instructions, such as EI (enable interrupt) and DI (disable interrupt).
- Non-maskable interrupts are those that cannot be disabled by software and have the highest priority, such as TRAP .
- The priority order of the interrupts is as follows: TRAP > RST 7.5 > RST 6.5 > RST 5.5 > INTR .
- A machine cycle is the time required by the microprocessor to complete one operation of accessing memory, I/O, or acknowledging an external request.
- A machine cycle consists of three smaller units called T-states, which are the subdivisions of the clock periods of the microprocessor.
- The number and duration of T-states vary depending on the type of machine cycle.
- The 8085 microprocessor has five types of machine cycles: opcode fetch, memory read, memory write, I/O read, and I/O write.
- The opcode fetch cycle is used to fetch the opcode of an instruction from the memory. It consists of four T-states: T1, T2, T3, and T4.
- The memory read cycle is used to read data from the memory. It consists of three T-states: T1, T2, and T3.
- The memory write cycle is used to write data to the memory. It also consists of three T-states: T1, T2, and T3.
- The I/O read cycle is used to read data from an I/O device. It is similar to the memory read cycle, except that the I/O device is selected by the IO/M' signal instead of the MEMR' signal.
- The I/O write cycle is used to write data to an I/O device. It is similar to the memory write cycle, except that the I/O device is selected by the IO/M' signal instead of the MEMW' signal.
- The interrupt acknowledge cycle is used to acknowledge an interrupt request from an external device. It consists of three or more T-states, depending on the type of interrupt.

- The second T-state (T2) is used to receive the 8-bit instruction from the device.
- The third T-state (T3) is used to decode and execute the instruction.
