### Unit 3 - Architecture of 8086 Microprocessor

1. **Register Organization:** The 8086 microprocessor has a total of 14 registers which are divided into four categories: General purpose registers, Segment registers, Pointer and Index registers, and Instruction pointer and Flags registers.

2. **Bus Interface Unit:** The Bus Interface Unit (BIU) is responsible for generating the physical addresses for memory and I/O operations, and for fetching instructions from memory.

3. **Execution Unit:** The Execution Unit (EU) is responsible for decoding and executing instructions. It communicates with the BIU to access memory and I/O devices.

4. **Memory Addressing:** The 8086 microprocessor uses a 20-bit address to access memory, allowing it to address up to 1 MB of memory.

5. **Memory Segmentation:** The 8086 microprocessor uses a segmented memory model, where the memory is divided into segments of up to 64 KB each. Each segment is identified by a 16-bit segment selector.

6. **Operating Modes:** The 8086 microprocessor has two operating modes: Minimum mode and Maximum mode. In Minimum mode, the 8086 operates as a standalone processor, while in Maximum mode, it operates in a multiprocessor system.

7. **Instruction Sets:** The 8086 microprocessor has a rich instruction set, including instructions for data transfer, arithmetic, logical, control transfer, and string manipulation.

8. **Instruction Format:** The 8086 instructions have a variable-length format, ranging from 1 to 6 bytes.

9. **Types of Instructions:** The 8086 instructions can be broadly classified into four categories: Data transfer instructions, Arithmetic and logic instructions, Control transfer instructions, and String instructions.

10. **Interrupts:** The 8086 microprocessor supports both hardware and software interrupts. Hardware interrupts are generated by external devices, while software interrupts are generated by executing an interrupt instruction.
