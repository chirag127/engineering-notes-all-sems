
## Unit 5 - APPLICATIONS

* Applications are software programs designed to perform specific tasks for users. 
* Common applications include word processors, spreadsheets, email clients, web browsers, and media players. 
* Applications are designed to be used by humans, as opposed to system software which is designed to control the hardware and run the computer. 
* Applications are written in programming languages such as C, C++, Java, and Python. 
* Applications are generally designed to be user-friendly, with graphical user interfaces and intuitive controls. 
* Applications can be installed on a local computer, or accessed online through the cloud. 
* Applications are often designed to interact with other applications, such as databases and web services.
