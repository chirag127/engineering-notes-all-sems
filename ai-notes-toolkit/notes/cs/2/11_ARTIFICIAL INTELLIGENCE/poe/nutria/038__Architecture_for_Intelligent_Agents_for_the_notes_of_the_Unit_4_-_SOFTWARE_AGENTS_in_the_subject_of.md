
### Architecture for Intelligent Agents

1. An intelligent agent is a computer program that is able to autonomously act in an environment in order to achieve a certain goal. 
2. Intelligent agents can be divided into two categories: reactive agents and deliberative agents. 
3. Reactive agents are agents that do not take the environment into consideration and are programmed to react to certain stimuli. 
4. Deliberative agents are agents that are able to take the environment into account when making decisions. 
5. An example of a deliberative agent is a chess-playing program, which is able to take the current state of the game into account when deciding on a move. 
6. In order to make intelligent decisions, agents must have access to a variety of information sources. 
7. This includes knowledge about the environment, the task, and the agent's own capabilities. 
8. The agent must also be able to use this information to determine the best course of action to achieve its goal. 
9. In order to do this, the agent must be able to learn from its experiences and adapt its behavior accordingly. 
10. This is known as learning by experience. 
11. In addition, agents must be able to communicate with other agents in order to coordinate their actions. 
12. This is known as multi-agent systems. 
13. Finally, agents must be able to reason and make decisions based on their knowledge. 
14. This is known as decision-theoretic reasoning.
