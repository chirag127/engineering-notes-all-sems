
### Uninformed Search

Uninformed search is a type of problem solving method used in Artificial Intelligence (AI) that does not use any additional knowledge or information other than that given in the problem itself. Uninformed search algorithms are also known as blind search algorithms because they do not use any additional information to guide the search.

The most common uninformed search algorithms are:

1. Breadth-First Search (BFS): BFS is an algorithm that searches a graph or tree level by level, expanding the nodes at each level before moving to the next.

2. Depth-First Search (DFS): DFS is an algorithm that searches a graph or tree by going as deep as possible into each branch before backtracking.

3. Uniform-Cost Search (UCS): UCS is an algorithm that searches a graph or tree by expanding the node that has the lowest cost associated with it.

4. Iterative Deepening Search (IDS): IDS is an algorithm that combines the features of BFS and DFS by doing a series of depth-first searches, gradually increasing the depth limit with each iteration.

Uninformed search algorithms are simple to implement, but they can be computationally expensive and may not find the optimal solution.
