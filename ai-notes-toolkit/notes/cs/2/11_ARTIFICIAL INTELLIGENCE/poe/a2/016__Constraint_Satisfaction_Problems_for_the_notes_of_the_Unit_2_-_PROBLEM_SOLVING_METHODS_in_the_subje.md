### Constraint Satisfaction Problems

- Constraint satisfaction problems involve finding a solution that satisfies a set of constraints.
- The constraints define the conditions that the variables must satisfy.
- The goal is to find a valid assignment of values to variables that satisfies all the constraints.
- Examples:
    - Scheduling: Assign tasks to time slots subject to constraints on resource availability and task dependencies.
    - Floor planning: Assign components of a circuit board to locations on the board subject to constraints on connections between components.
    - Probabilistic reasoning: Assign probabilities to uncertain events subject to constraints of probabilities summing to one and being between zero and one.
- Representation:
    - Variables: Things whose values need to be determined.
    - Domains: Possible values each variable can take.
    - Constraints: Relationships between variables that must be satisfied.
- Search Approaches:
    - Systematic search: Try possible values for variables in a systematic way.
    - Random search: Try random values for variables.
    - Heuristic search: Guiding systematic search using heuristics to focus search.
    - Local search: Starts with an initial solution and does local neighborhood searches to find better solutions.
