## Unit 3 - KNOWLEDGE REPRESENTATION

1. Knowledge Representation - Representing knowledge in a computer-usable form is known as Knowledge Representation (KR). It is a key step towards building intelligent systems.
2. Significance - It makes the knowledge usable by a computer. It facilitates machine reasoning, inference, and problem solving. It is required for tasks like planning, decision making, perception, etc.
3. Knowledge Representation Languages - Languages like Prolog, Conceptual Graphs, Rules, Frames, Ontologies, etc. are used to represent knowledge. They use logic and symbols to encode knowledge about the world.
4. Models of KR - Some of the models/approaches for KR are:

- Logical - Uses formal logic to represent knowledge
- Probabilistic - Represents uncertainty using probabilities
- Conceptual - Represents knowledge using objects, concepts and relationships
- Frame-based - Uses frames/schemas to represent knowledge and situations
- Neural networks - Uses machine learning and neural networks

5. Applications - KR has applications in various domains like expert systems, robotics, natural language processing, information retrieval, etc. It enables computers to use encoded knowledge to solve complex tasks, make inferences, take decisions, etc.
