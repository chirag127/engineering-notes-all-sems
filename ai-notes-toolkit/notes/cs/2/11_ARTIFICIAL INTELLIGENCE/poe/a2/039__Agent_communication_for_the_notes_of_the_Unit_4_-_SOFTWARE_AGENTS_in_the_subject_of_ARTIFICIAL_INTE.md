### Agent communication for the notes of the Unit 4 - SOFTWARE AGENTS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Agents need to communicate with each other to cooperate and coordinate. This communication can be:
- Direct: Agents communicate directly with each other.
- Indirect: Agents communicate via a central server.

2. The communication language needs to be a standard format that both the agents understand. Some ways this can be achieved are:
- Defining ontology: Agents agree on the terminology and syntax of the language.
- Using a formal language: Agents use a formally defined language with strict syntax and semantics. e.g. KQML, FIPA-ACL.

3. The content of the communication will depend on the task that the agents are cooperating on. It will contain:
- Messages: Contains data and commands that one agent sends to others.
- Performatives: The purpose of the message e.g. request, inform, query, etc.
- Ontology: Shared vocabulary and concepts to facilitate unambiguous communication.
- Protocol: Series of messages exchanged between agents following certain rules.

4. Some applications of agent communication are:
- Cooperation: Agents work together to solve a task by communicating and coordinating.
- Negotiation: Agents communicate to arrive at an agreement in a conflict scenario.
- Coordination: Multiple agents communicate to organise their activities and use resources efficiently.
