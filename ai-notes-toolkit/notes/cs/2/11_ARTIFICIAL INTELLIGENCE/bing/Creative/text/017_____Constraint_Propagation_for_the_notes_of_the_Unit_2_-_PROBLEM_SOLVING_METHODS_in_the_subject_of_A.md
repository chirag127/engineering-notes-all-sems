### Constraint Propagation

- Constraint propagation is a technique for reducing the search space of a problem by applying constraints that eliminate inconsistent or infeasible values from the domains of the variables.
- A constraint is a relation that restricts the possible values of one or more variables. For example, in a map-coloring problem, a constraint could be that two adjacent regions cannot have the same color.
- A domain is the set of possible values that a variable can take. For example, in a map-coloring problem, a domain could be the set of colors {red, green, blue}.
- Constraint propagation works by applying inference rules that exploit the structure of the constraints to remove values from the domains of the variables. For example, if a variable X has a domain {red, green, blue} and a constraint that X != Y, where Y has a domain {red, blue}, then we can infer that X cannot be red or blue, and thus reduce its domain to {green}.
- Constraint propagation can be applied repeatedly until either a solution is found, a contradiction is detected, or no more progress can be made. A solution is found when all the variables have singleton domains (i.e., only one possible value). A contradiction is detected when any variable has an empty domain (i.e., no possible value). No more progress can be made when the domains of the variables do not change after applying the inference rules.
- Constraint propagation can be combined with other search techniques, such as backtracking or local search, to solve constraint satisfaction problems (CSPs). A CSP is a problem that consists of a set of variables, a set of domains for each variable, and a set of constraints that must be satisfied by any solution. Examples of CSPs include map-coloring, sudoku, crossword puzzles, scheduling, and timetabling.
