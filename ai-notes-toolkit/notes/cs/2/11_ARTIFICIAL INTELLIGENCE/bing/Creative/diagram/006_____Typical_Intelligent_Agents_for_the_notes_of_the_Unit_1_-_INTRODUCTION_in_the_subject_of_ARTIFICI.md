### Typical Intelligent Agents

- An **intelligent agent** (IA) is an entity that makes a decision, that enables artificial intelligence to be put into action.
- It can also be described as a software entity that conducts operations in the place of users or programs after sensing the environment.
- It uses **sensors** to perceive the environment and **actuators** to initiate action in that environment.
- In addition, intelligent agents may **learn** from the environment to achieve their **goals**.
- Driverless cars and the Siri virtual assistant are examples of intelligent agents in AI.
- Intelligent agents in AI are closely related to agents in economics, and versions of the intelligent agent paradigm are studied in cognitive science, ethics, the philosophy of practical reason, as well as in many interdisciplinary socio-cognitive modeling and computer social simulations.

#### Types of Intelligent Agents

- There are different types of intelligent agents based on their degree of intelligence, autonomy, and functionality.
- Some of the common types are:

  - **Simple reflex agents**: These agents act based on the current percept, without considering the history of percepts. They have a fixed set of rules that map the percepts to the actions. For example, a vacuum cleaner agent that cleans the dirty spots and avoids the obstacles.
  - **Model-based reflex agents**: These agents act based on the current percept and a model of the world that they maintain. They have a set of rules that map the percepts and the state of the world to the actions. For example, a self-driving car agent that navigates the road based on the traffic, speed limit, and road conditions.
  - **Goal-based agents**: These agents act based on the current percept, a model of the world, and a goal that they want to achieve. They have a set of rules that map the percepts, the state of the world, and the goal to the actions. For example, a chess-playing agent that moves the pieces to win the game.
  - **Utility-based agents**: These agents act based on the current percept, a model of the world, a goal, and a utility function that measures how desirable a state is. They have a set of rules that map the percepts, the state of the world, the goal, and the utility to the actions. For example, a stock-trading agent that buys and sells stocks to maximize the profit.
  - **Learning agents**: These agents act based on the current percept, a model of the world, a goal, a utility function, and a learning component that updates the agent's knowledge and behavior based on the feedback from the environment. They have a set of rules that map the percepts, the state of the world, the goal, the utility, and the learning to the actions. For example, a speech recognition agent that improves its accuracy based on the user's corrections.

#### Functions of Intelligent Agents

- Some of the common functions of intelligent agents are:

  - **Information access and navigation**: Intelligent agents improve information access and navigation by employing search engines to look for information. For example, a web crawler agent that indexes the web pages and a query agent that answers the user's questions.
  - **Information filtering and analysis**: Intelligent agents filter and analyze information based on the user's preferences and needs. For example, a spam filter agent that blocks unwanted emails and a recommender agent that suggests products or services to the user.
  - **Personal assistance and automation**: Intelligent agents provide personal assistance and automation by performing tasks on behalf of the user. For example, a calendar agent that schedules appointments and a chatbot agent that converses with the user.
  - **Monitoring and notification**: Intelligent agents monitor and notify the user about the changes in the environment or the system. For example, a weather agent that alerts the user about the weather conditions and a security agent that detects intrusions or threats.
  - **Coordination and cooperation**: Intelligent agents coordinate and cooperate with other agents or humans to achieve a common goal. For example, a team of agents that play soccer and a negotiation agent that bargains with other agents or humans.
