## Unit 3 - KNOWLEDGE REPRESENTATION

- Knowledge representation is the process of encoding information about a domain in a form that can be used by an intelligent agent to reason and act.
- Knowledge representation involves choosing a suitable representation language, defining the syntax and semantics of the language, and using the language to express facts, rules, constraints, preferences, and goals about the domain.
- Knowledge representation languages can be classified into three main categories: logic-based, network-based, and frame-based.
- Logic-based languages use formal logic to represent knowledge as a set of sentences or formulas that can be manipulated by logical inference rules. Examples of logic-based languages are propositional logic, first-order logic, and description logic.
- Network-based languages use graphs or networks to represent knowledge as a set of nodes and links that capture the relationships among concepts. Examples of network-based languages are semantic networks, conceptual graphs, and Bayesian networks.
- Frame-based languages use frames or schemas to represent knowledge as a set of slots and fillers that capture the attributes and values of concepts. Examples of frame-based languages are frames, scripts, and object-oriented languages.
- Knowledge representation languages have different advantages and disadvantages depending on the characteristics of the domain and the tasks to be performed by the agent. Some criteria for evaluating knowledge representation languages are expressiveness, efficiency, consistency, completeness, and naturalness.
