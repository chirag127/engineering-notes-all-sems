### Reasoning with Default Information

- Default information is the information that is assumed to be true unless there is evidence to the contrary.
- For example, if we know that John is a bird, we can assume that John can fly, unless we have evidence that John is a penguin or an ostrich.
- Reasoning with default information is useful for dealing with incomplete or uncertain knowledge, as well as common sense reasoning.
- There are different formalisms for representing and reasoning with default information, such as default logic, nonmonotonic logic, circumscription, and closed-world assumption.
- Default logic is a logic that allows us to express conditional rules of the form: if A is true, then normally B is true, unless there is an exception C. For example, if X is a bird, then normally X can fly, unless X is abnormal.
- Nonmonotonic logic is a logic that allows us to revise our conclusions when new information is added. For example, if we initially conclude that John can fly based on the default rule that birds can fly, we can retract this conclusion when we learn that John is a penguin.
- Circumscription is a technique that allows us to minimize the extension of a predicate, that is, to assume that a predicate holds for the smallest possible set of objects, unless there is evidence to the contrary. For example, if we want to circumscribe the predicate Abnormal, we can assume that no object is abnormal, unless there is evidence that it is.
- Closed-world assumption is an assumption that states that whatever is not known to be true is false. For example, if we do not know that John is a penguin, we can assume that John is not a penguin. This assumption is often used in databases and logic programming.
