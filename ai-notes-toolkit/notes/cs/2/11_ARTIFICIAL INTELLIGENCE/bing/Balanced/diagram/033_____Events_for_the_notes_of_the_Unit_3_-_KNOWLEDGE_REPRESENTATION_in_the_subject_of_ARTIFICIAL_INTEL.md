### Events

- Events are the occurrence of things in the real world .
- Events are the actions which occur in our world.
- Events are an essential kind of knowledge in the world, which trigger the spring up of event-centric knowledge representation form like Event KG (EKG).
- Events need to describe what is true, when something is happening.
- Events can involve symbolic representations of objects and events which are not immediately present but exist only in imagination.

Some examples of events are:

- A concert is an event that involves music, performers, audience, venue, time, etc.
- A flight is an event that involves flying, flyer, origin, destination, time, etc.
- A birthday is an event that involves a person, a date, a celebration, etc.
