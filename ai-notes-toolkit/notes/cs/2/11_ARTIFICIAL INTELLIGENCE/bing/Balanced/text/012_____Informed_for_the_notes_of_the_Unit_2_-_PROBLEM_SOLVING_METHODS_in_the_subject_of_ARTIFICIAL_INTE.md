- Informed search is a type of search strategy that uses additional information or heuristics to guide the search process towards the goal state more efficiently.
- Heuristics are functions that estimate the cost or distance from a given state to the goal state, based on some domain knowledge or intuition.
- Informed search algorithms use heuristics to rank or prioritize the nodes in the search space, and select the most promising node to expand at each step.
- Some examples of informed search algorithms are:
  - Greedy best-first search: This algorithm selects the node with the lowest heuristic value, i.e., the node that seems closest to the goal, at each step. It is not optimal, as it may get stuck in local minima or dead ends, but it is fast and memory-efficient.
  - A* search: This algorithm selects the node with the lowest value of f(n) = g(n) + h(n), where g(n) is the cost of the path from the start node to n, and h(n) is the heuristic value of n. It is optimal and complete, if the heuristic is admissible, i.e., it never overestimates the true cost to the goal, and consistent, i.e., it satisfies the triangle inequality. It is also efficient, but it may require a lot of memory to store the nodes.
  - Iterative deepening A* search: This algorithm is a variation of A* search that uses a threshold value to limit the search depth at each iteration. It gradually increases the threshold until the goal is found or the search space is exhausted. It is optimal, complete, and memory-efficient, but it may repeat some work at each iteration.
  - Recursive best-first search: This algorithm is a variation of A* search that uses a recursive function to explore the search space. It keeps track of the f-value of the best alternative path from each ancestor of the current node, and prunes the branches that exceed that value. It is optimal, complete, and memory-efficient, but it may also repeat some work at each recursive call.
