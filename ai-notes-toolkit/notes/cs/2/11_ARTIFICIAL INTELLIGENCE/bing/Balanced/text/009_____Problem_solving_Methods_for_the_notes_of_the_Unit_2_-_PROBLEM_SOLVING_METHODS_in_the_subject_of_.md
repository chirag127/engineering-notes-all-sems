### Problem solving Methods

- Problem solving is the process of finding a solution to a given situation or goal, given some initial conditions and constraints.
- Problem solving methods are systematic and general approaches that can be applied to different types of problems, such as search, planning, optimization, reasoning, learning, etc.
- Problem solving methods can be classified into two main categories: **knowledge-based** and **search-based**.

#### Knowledge-based methods

- Knowledge-based methods rely on the use of domain-specific knowledge and rules to guide the problem solving process.
- Knowledge-based methods can be further divided into **deductive** and **inductive** methods.

##### Deductive methods

- Deductive methods use logical inference to derive conclusions from a set of premises or facts.
- Deductive methods can be based on **propositional logic**, **predicate logic**, **modal logic**, **temporal logic**, etc.
- Deductive methods can be used for tasks such as **theorem proving**, **consistency checking**, **query answering**, **diagnosis**, etc.

##### Inductive methods

- Inductive methods use generalization and abstraction to infer patterns or rules from a set of examples or observations.
- Inductive methods can be based on **decision trees**, **neural networks**, **genetic algorithms**, **clustering**, etc.
- Inductive methods can be used for tasks such as **classification**, **regression**, **clustering**, **association rule mining**, etc.

#### Search-based methods

- Search-based methods rely on the exploration of a large space of possible solutions or states, using some criteria to evaluate and select the best ones.
- Search-based methods can be further divided into **uninformed** and **informed** methods.

##### Uninformed methods

- Uninformed methods use no domain-specific knowledge or heuristics to guide the search process.
- Uninformed methods can be based on **breadth-first search**, **depth-first search**, **uniform-cost search**, **iterative deepening search**, etc.
- Uninformed methods can be used for tasks such as **path finding**, **puzzle solving**, **game playing**, etc.

##### Informed methods

- Informed methods use some domain-specific knowledge or heuristics to guide the search process, by estimating the cost or quality of each solution or state.
- Informed methods can be based on **best-first search**, **greedy search**, **A* search**, **hill climbing**, **simulated annealing**, etc.
- Informed methods can be used for tasks such as **optimization**, **planning**, **scheduling**, **constraint satisfaction**, etc.
