# Architecture for Intelligent Agents

- An intelligent agent is a system that perceives its environment via sensors and acts rationally upon that environment with its effectors.
- The architecture of an agent describes its modules and capabilities, and how these operate together.
- The agent architecture determines how the agent function is implemented, i.e., how the agent maps percepts to actions.
- The agent function is the mathematical description of the agent's behavior, i.e., what the agent should do.
- The agent program is the actual code that runs on the agent's architecture and implements the agent function.
- Agent = Architecture + Agent Program

## Types of Agent Architectures

- There are three primary types of agent architectures in AI:
  - Reactive agents: Reactive agents are the simplest type of AI agent. They do not have any internal state or memory, and they only act based on the current percept. They are fast and robust, but they cannot handle complex or dynamic environments. An example of a reactive agent is a thermostat that adjusts the temperature based on the current room temperature.
  - Deliberative agents: Deliberative agents are more sophisticated than reactive agents. They have an internal state and memory, and they can reason about their goals and plans. They can handle complex and dynamic environments, but they are slower and more prone to errors. An example of a deliberative agent is a chess-playing program that searches for the best move based on the current board state and its strategy.
  - Hybrid agents: Hybrid agents combine the advantages of reactive and deliberative agents. They have both a reactive layer and a deliberative layer, and they can switch between them depending on the situation. They can balance speed and accuracy, and they can cope with uncertainty and change. An example of a hybrid agent is a self-driving car that can react to traffic and road conditions, but also plan its route and destination.

## Applications of Intelligent Agents

- Intelligent agents have many applications in various domains, such as:
  - Robotics: Intelligent agents can control robots that perform tasks such as navigation, manipulation, exploration, and coordination. For example, a robotic vacuum cleaner is an intelligent agent that cleans the floor autonomously.
  - E-commerce: Intelligent agents can facilitate online transactions and services, such as shopping, bidding, negotiation, and recommendation. For example, a price-comparison agent is an intelligent agent that searches for the best deals on the web for a given product.
  - Education: Intelligent agents can enhance learning and teaching, such as providing feedback, guidance, tutoring, and assessment. For example, a pedagogical agent is an intelligent agent that interacts with students and adapts to their needs and preferences.
  - Entertainment: Intelligent agents can create engaging and immersive experiences, such as games, stories, and simulations. For example, a non-player character is an intelligent agent that acts as a friend or foe in a video game.
  - Health: Intelligent agents can assist in diagnosis, treatment, monitoring, and prevention of diseases and disorders. For example, a personal health assistant is an intelligent agent that tracks the user's health status and provides advice and reminders.
