## Unit 2 - Conditionals: Conditional statement in Python (if-else statement, its working and execution), Nested-if statement and Elif statement in Python, Expression Evaluation & Float Representation.

In this unit, we will cover the following topics related to conditional statements in Python:

1. **If-else statement**: The if-else statement is used to execute a block of code if a certain condition is true, and another block of code if the condition is false. The syntax for if-else statement is as follows:

```
if condition:
    # code to be executed if the condition is true
else:
    # code to be executed if the condition is false
```

2. **Nested-if statement**: The nested-if statement is used when we want to check multiple conditions in a single code block. The syntax for nested-if statement is as follows:

```
if condition1:
    # code to be executed if condition1 is true
    if condition2:
        # code to be executed if condition2 is true
    else:
        # code to be executed if condition2 is false
else:
    # code to be executed if condition1 is false
```

3. **Elif statement**: The elif statement is used when we want to check multiple conditions in a single code block, but we want to execute a different block of code for each condition. The syntax for elif statement is as follows:

```
if condition1:
    # code to be executed if condition1 is true
elif condition2:
    # code to be executed if condition2 is true
else:
    # code to be executed if both condition1 and condition2 are false
```

4. **Expression Evaluation**: In Python, expressions are evaluated using a set of rules known as operator precedence. The rules specify which operators are evaluated first when an expression is evaluated. The order of evaluation can be changed by using parentheses to group expressions. 

5. **Float Representation**: In Python, floating-point numbers are represented using a standard called IEEE 754. IEEE 754 specifies how floating-point numbers are stored in memory and how arithmetic operations are performed on them. It is important to be aware of IEEE 754 when working with floating-point numbers in Python.

In conclusion, understanding conditional statements in Python is essential for writing efficient and effective code. By mastering if-else statements, nested-if statements, and elif statements, as well as understanding expression evaluation and float representation, you will be well-equipped to write complex programs in Python.
