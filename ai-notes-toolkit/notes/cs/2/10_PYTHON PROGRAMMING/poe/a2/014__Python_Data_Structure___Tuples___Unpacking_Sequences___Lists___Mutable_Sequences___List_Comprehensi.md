### Python Data Structure : Tuples , Unpacking Sequences , Lists , Mutable Sequences , List Comprehension , Sets , Dictionaries

Tuples:
- Tuples are immutable sequences of Python objects.
- Tuples are written using round brackets ().
- Elements of a tuple can be of different data types.
- A tuple with a single element must have a trailing comma. Example: (4, ).
- Tuples can be used to hold related pieces of information together.

Unpacking Sequences:
- You can unpack sequences (tuples, lists) into distinct variables.
- The number of variables must match the number of values in the sequence.
- Example: a, b, c = (1, 2, 3). This unpacks the tuple (1, 2, 3) and assigns the values to the three variables.

Lists:
- Lists are mutable sequences of Python objects.
- Lists are written using square brackets [].
- Elements of a list can be accessed using indexing and slicing.
- Lists can contain objects of different data types.
- Lists are mutable, meaning their elements can be changed.

Mutable Sequences:
- In addition to lists, strings and tuples are sequences in Python.
- However, only lists are mutable sequences.
- Mutable sequences can be changed after they are created.
- Tuple elements cannot be changed. You cannot reassign elements of a tuple.
