### Boolean Expression

- Boolean expressions evaluate to either True or False.
- They are used to make logical decisions in a program.
- The basic boolean expressions are:

**Equality Expressions:**

- x == y: True if x is equal to y
- x != y: True if x is not equal to y

**Relational Expressions:**

- x > y: True if x is greater than y
- x < y: True if x is less than y
- x >= y: True if x is greater than or equal to y
- x <= y: True if x is less than or equal to y

**Logical Expressions:**

- x and y: True if both x and y are true
- x or y: True if either x or y is true
- not x: True if x is false (complements the boolean value)

**Precedence of Operators:**

- Not has the highest precedence.
- And has higher precedence than Or.
- Expressions inside parentheses are evaluated first.

Eg:
>>> 2 > 3 and 4 < 6
False
>>> 2 > 3 or 4 < 6
True
>>> not (2 > 3)
True

- Boolean expressions are used to control the flow of a program through conditional statements like if-else.
