### Arithmetic Operators

- Addition: +
- Subtraction: -
- Multiplication: *
- Division: /
- Floor Division: // (Divides and rounds down to the nearest whole number)
- Exponent: ** (Raises a number to a power)
- Modulus: % (Returns the remainder of a division operation)

These operators can be used to perform mathematical calculations in Python. They follow the standard order of operations (PEMDAS or Please Excuse My Dear Aunt Sally). Parentheses () can be used to change the order of evaluation.

The arithmetic operators take numerical values (int, float, complex) and perform the relevant operation on them producing a resulting numerical value. For example:

```
print(5 + 3) # Output: 8
print(10 - 2) # Output: 8
print(3 * 4) # Output: 12
print(10 / 2) # Output: 5.0
```

The arithmetic operators can also be used with variables that contain numerical values. For example:

```
x = 10
y = 5
print(x + y) # Output: 15
print(x - y) # Output: 5
print(x * y) # Output: 50
print(x / y) # Output: 2.0
```
