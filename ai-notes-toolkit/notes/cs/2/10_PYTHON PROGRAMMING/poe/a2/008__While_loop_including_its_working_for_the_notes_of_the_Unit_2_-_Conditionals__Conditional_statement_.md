### While loop including its working for the notes of the Unit 2 - Conditionals: Conditional statement in Python (if-else statement, its working and execution), Nested-if statement and Elif statement in Python, Expression Evaluation & Float Representation. in the subject of PYTHON PROGRAMMING.

1. While loop: While loop is used to repeat a block of code continuously until the given condition is True. The condition is checked before executing the loop body.
Syntax:
while condition:
    body of loop

Example:
i = 1
while i <= 5:
    print(i)
    i += 1   # increases the value of i by 1

Output:
1
2
3
4
5

2. Working: The while loop works by checking the condition first. If the condition evaluates to True, then the body of the loop is executed. Again the condition is checked, and this process repeats until the condition becomes False. Then the control comes out of the loop.

3. Use cases: While loops are useful when you want to repeat a block of code an unknown number of times until a condition is met. Some examples are:
- Traversing a list/string until the end is reached
- Taking input from a user until a valid input is entered
- Repeating a task until a process is complete (like downloading a file)

4. Infinite loop: If the condition never becomes False, the loop will never stop repeating and becomes an infinite loop. This must be avoided as it freezes the program.
