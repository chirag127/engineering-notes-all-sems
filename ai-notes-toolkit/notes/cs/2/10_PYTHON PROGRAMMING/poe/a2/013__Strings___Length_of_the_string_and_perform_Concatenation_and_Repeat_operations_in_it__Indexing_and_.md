### Strings :

1. Length of the string: Use len() function to get the length of the string. For example: len("Python") will return 6.
2. Concatenation: Joining two strings. Use + operator. For example: "Py" + "thon" will give "Python".
3. Repeat: Repeating the string multiple times. Use * operator. For example: "Py" * 2 will give "PyPy".
4. Indexing: Accessing individual characters using their index. For example: "Python"[0] will give 'P'. Index starts from 0.
5. Slicing: Extracting a part of the string. Use [start:end] syntax. For example: "Python"[1:3] will give 'yt'. Start index is inclusive and end index is exclusive.

### Function:

1. Parts of a function: def keyword, name of the function, parameters, colon, indented block of code(function body).
2. Execution of a function: Call the function by its name and pass arguments to get the output.
3. Keyword arguments: Arguments that have default values. Use name=value syntax. For example: def myfunc(x, y=10)
4. Default arguments: Arguments that will be used if no argument is passed. Example: def myfunc(x, y=10)
5. Scope rules: The region of code where a variable names is valid. Global variables can be accessed across the program. Local variables exist only inside the function.
