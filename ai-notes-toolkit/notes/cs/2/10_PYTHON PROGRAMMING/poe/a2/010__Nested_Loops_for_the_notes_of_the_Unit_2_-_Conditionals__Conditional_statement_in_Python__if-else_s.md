### Nested Loops for the notes of the Unit 2 - Conditionals:

1. Conditional statement in Python (if-else statement, its working and execution)
- If condition is true, then execute the code block under if
- Else part is executed if the condition is false
- Syntax: if condition:
       code block 1
   else:
       code block 2

2. Nested-if statement and Elif statement in Python
- Nested if: An if statement inside an if statement
- Elif: Used to test multiple conditions. Elif stands for "else if"
- Syntax:
   if condition1:
       code block 1
   elif condition2:
       code block 2
   else:
       code block 3

3. Expression Evaluation & Float Representation
- Expressions are evaluated and then converted to Boolean values (True or False) in conditionals
- Floating point numbers are represented in decimal form and have rounding errors
- To get precise results, use decimal module for float operations
