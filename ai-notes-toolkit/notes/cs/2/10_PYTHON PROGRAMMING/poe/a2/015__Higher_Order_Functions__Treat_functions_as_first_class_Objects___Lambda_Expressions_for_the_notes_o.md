### Higher Order Functions: Treat functions as first class Objects , Lambda Expressions

- Functions in Python can be treated as objects. This means that functions can be passed as arguments to other functions, can be returned by other functions and can be assigned to variables.
- Functions that take one or more functions as arguments are called higher-order functions.
- Examples of higher-order functions are map(), filter() and reduce().
- Lambda expressions (or lambda forms) are anonymous functions that can take any number of arguments but can only have one expression. They are useful when you need a short function for a short period of time.
- The syntax of a lambda function is `lambda parameters: expression`
- Examples of lambda expressions:
    - `square = lambda x: x * x`
    - `is_even = lambda x: x % 2 == 0`

Parts of A Function , Execution of A Function , Keyword and Default Arguments ,Scope Rules:

- Parts of a function: def, function name, parameters, colon, indent block
- A function is executed when it is called by its name followed by parentheses
- Keyword arguments are inputs whose values are specified by keywords and default arguments are input values that are specified in function definition to be used if no input is passed in function call.
- The scope of a variable refers to the part of the program where the variable can be accessed. Python follows LEGB rule for scoping: Local, Enclosing, Global, Built-in.
