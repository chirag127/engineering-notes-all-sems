## Unit 3 - Resource Sharing

- Resource sharing is the process of making the resources of one computer system available to other computer systems on a network.
- Resource sharing can improve the efficiency, performance, reliability, and scalability of distributed systems.
- Resource sharing can also enable collaboration, communication, and coordination among users and applications.
- Resource sharing can be classified into two types: data sharing and device sharing.

### Data Sharing
- Data sharing is the process of making the data stored on one computer system accessible to other computer systems on a network.
- Data sharing can be achieved by using file systems, databases, or data streams.
- File systems allow users to store, organize, and access files and directories on a shared storage device.
- Databases allow users to store, query, and manipulate structured data on a shared server.
- Data streams allow users to send and receive continuous data on a shared channel.

### Device Sharing
- Device sharing is the process of making the devices attached to one computer system available to other computer systems on a network.
- Device sharing can be achieved by using device drivers, middleware, or virtualization.
- Device drivers allow users to access the functionality and features of a shared device through a standard interface.
- Middleware allows users to access the services and resources of a shared device through a network protocol.
- Virtualization allows users to create and use virtual instances of a shared device on a network.
