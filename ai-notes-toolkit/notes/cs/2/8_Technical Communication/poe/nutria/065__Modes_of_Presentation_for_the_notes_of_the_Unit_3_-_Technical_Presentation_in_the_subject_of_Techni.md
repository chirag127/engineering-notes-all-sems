
### Modes of Presentation for the Notes of Unit 3 - Technical Presentation in the Subject of Technical Communication

1. Oral Presentation: This is the most common type of presentation and involves delivering a speech or a talk in front of an audience. It can include the use of visual aids, such as slides or videos, to help illustrate the point.

2. Written Presentation: This type of presentation involves writing a document or report that is intended to be read by an audience. It can include the use of graphics or diagrams to help illustrate the point.

3. Digital Presentation: This type of presentation involves using digital tools, such as a computer or tablet, to create a presentation. This can include the use of multimedia elements, such as audio, video, and animation, to help illustrate the point.

4. Poster Presentation: This type of presentation involves creating a physical poster that is intended to be displayed in a public space. It can include the use of graphics, diagrams, and text to help illustrate the point.
