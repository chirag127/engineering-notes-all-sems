- Security attacks: Any action that compromises the security of information or resources. They can be classified into two categories: passive attacks (e.g., eavesdropping, traffic analysis) and active attacks (e.g., modification, replay, denial of service).
- Security services: The services that are provided by a system to counter security attacks and enhance the security of data and resources. They can be classified into five categories: confidentiality (e.g., encryption, access control), integrity (e.g., hashing, digital signatures), authentication (e.g., passwords, certificates), non-repudiation (e.g., timestamps, receipts), and availability (e.g., redundancy, backup).
- Security mechanisms: The methods or tools that are used to implement security services. They can be classified into two categories: preventive mechanisms (e.g., encryption, authentication) and detective mechanisms (e.g., auditing, intrusion detection).
- Classical encryption techniques: The techniques that are based on simple mathematical operations and do not require complex algorithms or keys. They can be classified into two categories: substitution ciphers (e.g., Caesar cipher, monoalphabetic cipher, polyalphabetic cipher) and transposition ciphers (e.g., rail fence cipher, columnar cipher, permutation cipher).
- Cryptanalysis: The art or science of breaking encryption schemes and recovering the plaintext from the ciphertext. It can be classified into two categories: ciphertext-only attack (e.g., frequency analysis, brute force) and known-plaintext attack (e.g., linear cryptanalysis, differential cryptanalysis).
- Steganography: The technique of hiding information within other information, such as images, audio, or text. It can be used to enhance the security of encryption by concealing the existence of the message.
- Stream and block ciphers: The techniques that are based on complex mathematical operations and require algorithms and keys. They can be classified into two categories: stream ciphers (e.g., RC4, A5/1, Salsa20) and block ciphers (e.g., DES, AES, Blowfish).
- Block ciphers principles: The principles that are used to design and analyze block ciphers. They include: block size (the number of bits that are encrypted or decrypted at a time), key size (the number of bits that are used to control the encryption or decryption process), round (a basic operation that is repeated several times to transform the plaintext into the ciphertext or vice versa), subkey (a part of the key that is used in each round), S-box (a substitution table that maps a set of input bits to a set of output bits), P-box (a permutation table that rearranges the order of bits), and SP-network (a structure that combines S-boxes and P-boxes in each round).
- Shannon’s theory of confusion and diffusion: The theory that was proposed by Claude Shannon to measure the security of encryption schemes. It states that: confusion (the complexity of the relationship between the plaintext and the ciphertext) and diffusion (the spread of the influence of a single plaintext or ciphertext bit over many ciphertext or plaintext bits) are the two properties that are essential for a secure cipher.
- Fiestal structure: A common structure that is used to implement block ciphers. It consists of two halves of the block that are processed alternately in each round, using a function that depends on the subkey and a swap operation that exchanges the two halves at the end of each round.
- Data encryption standard (DES): A widely used block cipher that was developed by IBM and adopted by the US government in 1977. It has a block size of 64 bits, a key size of 56 bits, and 16 rounds of fiestal structure. It is considered insecure today due to its small key size and the advances in cryptanalysis and computing power.
