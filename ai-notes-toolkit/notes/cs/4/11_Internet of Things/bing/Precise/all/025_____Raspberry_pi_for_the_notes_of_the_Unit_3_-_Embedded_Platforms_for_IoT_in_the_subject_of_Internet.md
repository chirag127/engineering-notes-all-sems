# Unit 3 - Embedded Platforms for IoT: Raspberry Pi

- Raspberry Pi is a series of small single-board computers developed in the United Kingdom by the Raspberry Pi Foundation.
- The original model became popular for its low cost and small size, making it suitable for use in education, home automation, and other projects.
- Raspberry Pi boards run a variety of operating systems, including Linux-based distributions such as Raspbian, and Microsoft Windows 10 IoT Core.
- The Raspberry Pi has a Broadcom system on a chip (SoC), which includes an ARM-compatible central processing unit (CPU) and an on-chip graphics processing unit (GPU).
- The Raspberry Pi also has several interfaces for connecting peripherals, including USB, HDMI, Ethernet, and General-purpose input/output (GPIO) pins.
- The GPIO pins allow the Raspberry Pi to interact with the physical world, making it a popular choice for Internet of Things (IoT) projects.
- The Raspberry Pi Foundation provides extensive documentation and support for using the Raspberry Pi in IoT projects, including tutorials and example code.
- The Raspberry Pi is a versatile and affordable platform for developing IoT projects, and its popularity and community support make it an excellent choice for beginners and experienced developers alike.
