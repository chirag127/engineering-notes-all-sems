### Unit 5 - Programming the Arduino

#### Arduino IDE

1. The Arduino Integrated Development Environment (IDE) is a software application that provides a text editor for writing code, a message area, a text console, and a toolbar with buttons for common functions.
2. The Arduino IDE is used to write, compile, and upload code to the Arduino board.
3. The IDE supports the C and C++ programming languages and includes a library manager for adding and managing libraries.
4. The IDE also includes a serial monitor for displaying data sent from the Arduino board to the computer.
5. The Arduino IDE is available for Windows, macOS, and Linux operating systems.
6. The code written in the Arduino IDE is called a sketch. Sketches are saved with the file extension .ino.
7. The Arduino IDE includes a number of example sketches that demonstrate the use of various functions and libraries.
8. The Arduino IDE uses a simplified version of C++, making it easier to learn to program.
9. The Arduino IDE includes a built-in function called setup() that is called once when the sketch starts. This function is used to initialize variables, pin modes, and libraries.
10. The Arduino IDE also includes a built-in function called loop() that is called repeatedly as long as the Arduino board has power. This function is used to control the behavior of the program.
