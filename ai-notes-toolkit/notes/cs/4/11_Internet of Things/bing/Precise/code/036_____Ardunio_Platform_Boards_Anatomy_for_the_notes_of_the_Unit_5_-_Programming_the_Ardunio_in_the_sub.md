### Unit 5 - Programming the Arduino: Arduino Platform Boards Anatomy

1. **Microcontroller:** The microcontroller is the brain of the Arduino board. It is responsible for executing the code uploaded to the board and controlling the input/output pins.
2. **Input/output pins:** The input/output pins are used to connect sensors, actuators, and other components to the Arduino board. They can be configured as digital or analog inputs/outputs.
3. **Power jack:** The power jack is used to connect an external power source to the Arduino board. The board can be powered by a battery or an AC-to-DC adapter.
4. **USB port:** The USB port is used to connect the Arduino board to a computer. It is used to upload code to the board and to power the board when it is connected to a computer.
5. **Voltage regulator:** The voltage regulator is responsible for regulating the voltage supplied to the board. It ensures that the board receives a stable voltage, even if the input voltage fluctuates.
6. **Reset button:** The reset button is used to reset the microcontroller. Pressing the reset button restarts the code uploaded to the board.
7. **LEDs:** The LEDs on the Arduino board are used to indicate the status of the board. For example, the power LED indicates that the board is receiving power, while the TX and RX LEDs indicate data transmission and reception, respectively.
8. **Crystal oscillator:** The crystal oscillator is used to generate a clock signal for the microcontroller. The clock signal is used to synchronize the operations of the microcontroller.
