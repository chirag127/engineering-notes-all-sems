### Unit 5 - Programming the Arduino in the subject of Internet of Things
#### Additions in Arduino

1. To add numbers on the Arduino, we use the addition operator (+). The example below shows how to add two numbers together. `int a = 2; int b = 7; int sum; sum = a + b;`  .
2. Addition is one of the four primary arithmetic operations. The operator + (plus) operates on two operands to produce the sum. The syntax is `sum = operand1 + operand2;` .
3. The `sum` variable is allowed to have data types such as `int`, `float`, `double`, `byte`, `short`, `long`. The `operand1` and `operand2` can be either a variable or a constant and are allowed to have data types such as `int`, `float`, `double`, `byte`, `short`, `long` .
4. There is also a convenient shorthand to perform addition on a variable with another constant or variable using the `+=` compound addition operator .
