### Unit 5 - Programming the Arduino

#### Additions in Arduino

- To add numbers on the Arduino, the addition operator (+) is used.
- The addition operator operates on two operands to produce the sum.
- The syntax for addition is `sum = operand1 + operand2;`.
- The `sum` variable can be of data types: int, float, double, byte, short, long.
- The `operand1` and `operand2` can be variables or constants of data types: int, float, double, byte, short, long.
- An example of addition on the Arduino is shown below:

```c
int a = 2;
int b = 7;
int sum;
sum = a + b;
```

- There is also a shorthand to perform addition on a variable with another constant or variable using the compound addition operator (+=).
