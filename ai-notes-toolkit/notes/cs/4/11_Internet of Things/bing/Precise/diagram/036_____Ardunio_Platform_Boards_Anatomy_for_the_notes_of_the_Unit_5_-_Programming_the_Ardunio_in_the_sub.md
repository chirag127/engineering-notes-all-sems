### Unit 5 - Programming the Ardunio
#### Ardunio Platform Boards Anatomy

1. **Microcontroller:** The microcontroller is the brain of the Arduino board. It is responsible for executing the code uploaded to the board and controlling the input and output pins.
2. **Input/Output Pins:** The input/output pins are used to connect sensors, actuators, and other components to the Arduino board. They can be configured as digital or analog inputs or outputs.
3. **Power Jack:** The power jack is used to connect an external power source to the Arduino board. This can be used to power the board and any connected components.
4. **USB Port:** The USB port is used to connect the Arduino board to a computer. This allows for uploading code to the board and for serial communication between the board and the computer.
5. **Reset Button:** The reset button is used to restart the microcontroller on the Arduino board. This can be useful for debugging code or resetting the board to its initial state.
6. **Voltage Regulator:** The voltage regulator is used to regulate the voltage supplied to the Arduino board. This ensures that the board and any connected components receive a stable and consistent voltage.
7. **Crystal Oscillator:** The crystal oscillator is used to provide a clock signal to the microcontroller on the Arduino board. This clock signal is used to control the timing of the microcontroller's operations.
8. **LEDs:** The LEDs on the Arduino board are used to indicate the status of the board. For example, the power LED indicates that the board is receiving power, while the TX and RX LEDs indicate serial communication activity.
