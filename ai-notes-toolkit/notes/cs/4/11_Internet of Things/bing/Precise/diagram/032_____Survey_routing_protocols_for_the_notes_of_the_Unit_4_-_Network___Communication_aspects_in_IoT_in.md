### Survey routing protocols for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

1. **Routing Protocols:** Routing protocols are used to find the best path for data transmission in a network. In the context of IoT, routing protocols are used to transmit data between resource-constrained devices in a network.

2. **RPL:** RPL (Routing Protocol for Low-Power and Lossy Networks) is the most commonly used routing protocol in IoT. It is designed to find the best routing path in Low-Power and Lossy Networks (LLNs) and is classified as a distance vector and resource routing protocol. The RPL algorithm supports multipoint-to-point (MP2P), point-to-multipoint (P2MP), and point-to-point (P2P) data flows.

3. **CORPL:** Cognitive RPL (CORPL) is a non-standard extension of RPL that is designed for cognitive networks. It is used to improve the performance of RPL in cognitive networks.

4. **M2M Communication:** Machine-to-machine (M2M) communication is an enabler technology for IoT that provides communication between machines and devices without human intervention.
