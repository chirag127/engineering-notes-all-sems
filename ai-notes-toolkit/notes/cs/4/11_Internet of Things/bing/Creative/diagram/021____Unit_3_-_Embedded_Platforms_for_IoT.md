# Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are hardware and software systems that enable IoT devices to perform their functions and communicate with other devices and networks.
- Embedded platforms for IoT typically consist of:
  - A microcontroller or microprocessor that executes the application logic and controls the device's peripherals.
  - A memory unit that stores the program code and data.
  - A communication interface that supports wired or wireless connectivity protocols such as Ethernet, Wi-Fi, Bluetooth, Zigbee, LoRa, etc.
  - A power supply that provides the required voltage and current for the device's operation.
  - A sensor or actuator that interacts with the physical environment and provides input or output data.
  - An embedded operating system or firmware that manages the device's resources and provides basic services such as scheduling, memory management, device drivers, network stack, security, etc.
- Embedded platforms for IoT can be classified into different categories based on their performance, power consumption, size, cost, and application domain. Some examples of embedded platforms for IoT are:
  - Mbed OS: An open source platform that provides a secure and scalable environment for developing IoT applications. It supports various microcontrollers, communication modules, sensors, and cloud services. It also offers a web-based IDE, a command-line tool, and a library of reusable components.
  - Amazon FreeRTOS: A real-time operating system that extends the FreeRTOS kernel with libraries for connectivity, security, and over-the-air updates. It is designed for low-power and cost-sensitive IoT devices that connect to AWS cloud services or other devices.
  - Raspberry Pi: A single-board computer that runs Linux or Windows 10 IoT Core. It has a 64-bit quad-core processor, 1 GB or 2 GB of RAM, and various interfaces such as HDMI, USB, GPIO, etc. It can be used for prototyping, education, and hobby projects.
  - AMD Ryzen Embedded: A family of processors that deliver high-performance graphics and computing for IoT gateways, edge servers, and smart devices. They support up to four cores, 8 GB of DDR4 memory, and multiple displays. They also offer security features such as secure boot, encrypted memory, and secure firmware updates.
  - Cisco Embedded Services Switch: A compact and rugged switch that provides high-bandwidth and critical security features for industrial IoT applications. It has 10 10G SFP+ ports, a feature-rich IOS-XE based platform, and a small-form-factor that solves size, weight, and power challenges. It is designed for remote and harsh environments.
