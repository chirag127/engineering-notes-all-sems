# ARM Cortex

- ARM Cortex is a group of 32-bit and 64-bit RISC ARM processor cores licensed by Arm Holdings  .
- ARM Cortex cores are intended for application use in embedded systems, such as microcontrollers, ASICs, ASSPs, FPGAs, and SoCs .
- ARM Cortex cores are divided into four profiles: A, R, M, and S.
  - Cortex-A profile: for high-performance and general-purpose applications, such as smartphones, tablets, laptops, servers, etc. Supports 32-bit and 64-bit instruction sets, virtual memory, and optional security extensions .
  - Cortex-R profile: for real-time and safety-critical applications, such as automotive, industrial, medical, etc. Supports 32-bit instruction set, memory protection, and optional security extensions.
  - Cortex-M profile: for low-cost and energy-efficient applications, such as sensors, IoT devices, wearables, etc. Supports 32-bit instruction set, reduced instruction set, and optional security extensions .
  - Cortex-S profile: for secure applications, such as smart cards, SIM cards, etc. Supports 32-bit instruction set, reduced instruction set, and security extensions.
- ARM Cortex cores have various features and capabilities, such as:
  - Thumb-2 technology: a mixed 16/32-bit instruction set that improves code density and performance.
  - NEON technology: a SIMD (single instruction multiple data) engine that accelerates multimedia and signal processing applications.
  - Helium technology: a SIMD engine for Cortex-M profile that enhances DSP (digital signal processing) and ML (machine learning) applications.
  - TrustZone technology: a security extension that creates a secure and non-secure world for isolating sensitive data and code.
  - Split-Lock capability: a feature that allows Cortex-A profile cores to operate in either split mode (independent execution) or lock mode (redundant execution) for safety-critical applications.
  - LPAE (Large Physical Address Extension): a feature that enables Cortex-A profile cores to access up to 1 TB of physical memory.
