# Overview of IoT supported Hardware platforms such as Arduino

- IoT (Internet of Things) is the network of physical objects embedded with sensors, actuators, and communication capabilities that can interact with each other and the Internet.
- IoT devices require hardware platforms that can support the functionalities of sensing, processing, and communicating data.
- There are many IoT hardware platforms available in the market, each with different features, capabilities, and costs.
- Some of the common IoT hardware platforms are:

  - **Arduino**: Arduino is an open-source platform that consists of microcontroller boards and a software development environment. Arduino boards can be programmed using a variety of languages, such as C, C++, Python, and JavaScript. Arduino boards can interface with various sensors, actuators, and modules using analog and digital pins, serial ports, I2C, SPI, and other protocols. Arduino boards can also communicate with the Internet using Ethernet, WiFi, Bluetooth, LoRa, GSM, or other wireless technologies. Arduino boards are suitable for prototyping and developing IoT applications that require low power consumption, simple logic, and basic connectivity. Some examples of Arduino boards are Arduino Uno, Arduino Nano, Arduino Mega, Arduino MKR1000, Arduino MKR WiFi 1010, etc.    

  - **Raspberry Pi**: Raspberry Pi is a single-board computer that runs on Linux operating system. Raspberry Pi can perform complex computations, run multiple programs, and support various programming languages, such as Python, Java, C, C++, etc. Raspberry Pi can interface with various sensors, actuators, and modules using GPIO pins, USB ports, HDMI port, camera port, etc. Raspberry Pi can also communicate with the Internet using Ethernet, WiFi, Bluetooth, or other wireless technologies. Raspberry Pi is suitable for prototyping and developing IoT applications that require high performance, rich functionality, and advanced connectivity. Some examples of Raspberry Pi models are Raspberry Pi Zero, Raspberry Pi 3, Raspberry Pi 4, Raspberry Pi Pico, etc.   

  - **ESP8266**: ESP8266 is a low-cost WiFi module that can be used as a standalone microcontroller or as a WiFi shield for other microcontrollers. ESP8266 can be programmed using Arduino IDE, Lua, MicroPython, or other languages. ESP8266 can interface with various sensors, actuators, and modules using GPIO pins, serial ports, I2C, SPI, etc. ESP8266 can also communicate with the Internet using WiFi or other wireless technologies. ESP8266 is suitable for prototyping and developing IoT applications that require low cost, low power consumption, and WiFi connectivity. Some examples of ESP8266 boards are ESP-01, ESP-12, NodeMCU, Wemos D1, etc.  

  - **Intel Edison**: Intel Edison is a tiny computer module that can run on Linux or Windows operating system. Intel Edison can perform complex computations, run multiple programs, and support various programming languages, such as C, C++, Python, Node.js, etc. Intel Edison can interface with various sensors, actuators, and modules using GPIO pins, I2C, SPI, UART, etc. Intel Edison can also communicate with the Internet using WiFi, Bluetooth, or other wireless technologies. Intel Edison is suitable for prototyping and developing IoT applications that require high performance, small size, and advanced connectivity. Some examples of Intel Edison boards are Intel Edison Arduino Breakout, Intel Edison Mini Breakout, etc.  

  - **BeagleBone**: BeagleBone is a single-board computer that runs on Linux operating system. BeagleBone can perform complex computations, run multiple programs, and support various programming languages, such as Python, Java, C, C++, etc. BeagleBone can interface with various sensors, actuators, and modules using GPIO pins, USB ports, HDMI port, Ethernet port, etc. BeagleBone can also communicate with the Internet using Ethernet, WiFi, Bluetooth, or other wireless technologies. BeagleBone is suitable for prototyping and developing IoT applications that require high performance, rich functionality, and advanced connectivity. Some examples of BeagleBone models are BeagleBone Black, BeagleBone Green, BeagleBone Blue, etc.
