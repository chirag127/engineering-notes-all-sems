# Ardunio Platform Boards Anatomy

Arduino boards are the microcontroller development platform that will be at the heart of your projects. They can sense the environment by receiving inputs from many sensors, and affect their surroundings by controlling lights, motors, and other actuators. Arduino boards can be programmed using the Arduino IDE, a cross-platform application that allows you to write code and upload it to the board. 

There are many types of Arduino boards, each with different features and capabilities. One of the most popular and widely used Arduino boards is the Arduino Uno, which is based on the ATmega328P microcontroller. The Arduino Uno board has the following main components :

- **Microcontroller**: This is the brain of the board, a tiny computer that can execute instructions written in code. The microcontroller has 32 KB of flash memory for storing the program, 2 KB of SRAM for storing variables, and 1 KB of EEPROM for storing non-volatile data. The microcontroller also has a 16 MHz crystal oscillator that provides the clock signal for the board.
- **USB port**: This is used to connect the board to the computer and to power the board. The USB port also allows the board to communicate with the computer using serial communication. The USB port can provide up to 500 mA of current to the board, but it is recommended to use an external power supply if the board requires more current.
- **USB to serial chip**: This is what makes it possible to program the Arduino board from the computer. The USB to serial chip converts the USB signals to serial signals that the microcontroller can understand. The chip also handles the auto-reset feature that resets the board when a new program is uploaded.
- **Power jack**: This is used to connect an external power supply to the board. The board can accept a voltage range of 7 to 12 V, but the recommended voltage is 9 V. The power jack has a polarity protection diode that prevents the board from being damaged if the power supply is connected with the wrong polarity.

- **Reset button**: This is used to manually reset the board. Pressing the reset button will restart the program from the beginning. The reset button can also be used to enter the bootloader mode, which is necessary for uploading a new program to the board.
