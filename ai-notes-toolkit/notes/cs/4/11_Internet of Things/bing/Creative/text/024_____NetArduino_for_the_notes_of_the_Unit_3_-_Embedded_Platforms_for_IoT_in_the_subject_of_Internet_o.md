### Netduino

- Netduino is an open-source electronics prototyping platform based on the.NET Micro Framework.
- It uses the ARM Cortex-M 32-bit RISC ARM processor core as a 32-bit ARM-microcontroller.
- The Netduino boards (except the discontinued Mini and Go models) are designed to be pin-compatible with most Arduino shields.
- Netduino features a 32-bit microcontroller and a rich development environment, suitable for engineers and hobbyists alike .
- Netduino can be used to build nearly any Connected Thing you can dream up, such as IoT devices, robots, sensors, etc .
- Netduino applications can be built on Windows (with Visual Studio), or on Mac OS (with either Visual Studio for Mac or Xamarin Studio).
- Netduino is 100% open source: Hardware, Firmware, and Netduino.Foundation.
- Netduino.Foundation is a library that simplifies the use of common hardware components and peripherals, such as LEDs, buttons, displays, sensors, etc.
- Netduino supports various communication protocols, such as Ethernet, WiFi, Bluetooth, SPI, I2C, UART, etc.
- Netduino has different models, such as Netduino 3, Netduino 3 Ethernet, Netduino 3 WiFi, Netduino Plus 2, Netduino 2, etc. Each model has different specifications, such as memory, speed, power, etc.
