# Communicating Data with H/W Units

- In IoT, data communication refers to the process of transferring data between IoT devices, gateways, network servers, and cloud applications.
- Data communication can be unidirectional (send data) or bidirectional (send and receive data) .
- Data communication can be wired or wireless, depending on the type of IoT device and the network protocol used .
- Some common network protocols for IoT data communication are Wi-Fi, Bluetooth, Ethernet, Satellite, Zigbee, LoRaWAN, MQTT, CoAP, etc.   .
- IoT devices may use different protocols at different layers of the network stack, such as physical, data link, network, transport, and application layers .
- IoT devices may communicate directly with the internet or via a gateway, which provides a link between the IoT device and the network server or cloud application  .
- Network servers and cloud applications are responsible for managing how the data is transmitted, processed, stored, and presented to the end users .
- Data communication in IoT can be classified into different types based on the source and destination of the data, such as human-to-machine (H2M), machine-to-human (M2H), machine-to-machine (M2M), and human-to-human (H2H) .
- Data communication in IoT can also be classified into different types based on the scope and scale of the data, such as device-to-device (D2D), device-to-cloud (D2C), device-to-gateway (D2G), and back-end data sharing .
