# Raspberry Pi

- Raspberry Pi is a small, low-cost, single-board computer that allows people to explore computing and learn programming  .
- Raspberry Pi uses a system on a chip (SoC), which integrates the CPU and GPU in a single integrated circuit, with the RAM, USB ports, and other components soldered onto the board.
- Raspberry Pi can plug into a computer monitor or TV, and use a standard keyboard and mouse.
- Raspberry Pi can run various operating systems, such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, etc.
- Raspberry Pi can be used for various applications, such as web browsing, gaming, media streaming, robotics, home automation, etc.
- Raspberry Pi has different models and features, such as Raspberry Pi 400, Raspberry Pi 4, Raspberry Pi Zero, etc .
- Raspberry Pi also has accessories, such as cameras, cases, displays, etc .
- Raspberry Pi is supported by the Raspberry Pi Foundation, a UK charity that aims to make computing accessible and affordable for everybody.
