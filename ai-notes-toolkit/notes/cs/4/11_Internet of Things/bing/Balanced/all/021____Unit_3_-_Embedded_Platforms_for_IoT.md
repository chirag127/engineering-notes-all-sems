# Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are hardware and software systems that enable IoT devices to perform their functions and communicate with other devices and networks.
- Embedded platforms for IoT typically consist of three main components: a microcontroller or microprocessor, a communication module, and a software stack.
- A microcontroller or microprocessor is a small computer chip that executes the instructions and logic of the IoT device. It can also interface with sensors, actuators, and other peripherals.
- A communication module is a device that allows the IoT device to connect to a wireless or wired network, such as Wi-Fi, Bluetooth, cellular, or Ethernet. It can also support various protocols and standards, such as MQTT, CoAP, HTTP, or TCP/IP.
- A software stack is a collection of software components that provide the functionality and services of the IoT device. It can include an operating system, a middleware, a framework, an application, and a cloud service.
- There are many choices of embedded platforms for IoT, depending on the requirements and specifications of the IoT device. Some examples are:
  - Mbed OS: an open source platform that provides a secure and scalable software stack for IoT devices, including an RTOS, a device management service, and a cloud service.
  - Amazon FreeRTOS: a platform that extends the FreeRTOS kernel with libraries for connectivity, security, and OTA updates for IoT devices, and integrates with AWS IoT services.
  - Cisco Embedded Services: a platform that provides embedded switches and routers for industrial IoT applications, with high-bandwidth, security, and robustness features.
  - AMD Embedded Solutions: a platform that provides embedded processors for IoT gateways and edge computing applications, with high-performance, low-power, and integrated graphics capabilities.
