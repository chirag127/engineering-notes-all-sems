# Tablets for the notes of the Unit 7 - IoT Applications

- IoT applications are the use cases of IoT devices and technologies that provide value to end-users, businesses, or society.
- IoT devices are any physical objects that can connect to the internet and communicate data, such as sensors, actuators, cameras, wearables, smart appliances, etc.
- IoT technologies are the hardware, software, protocols, and platforms that enable the connectivity, data processing, and analytics of IoT devices.
- Tablets are portable computing devices that have a touch screen and can run various applications, such as web browsers, games, e-books, etc.
- Tablets can be used for various IoT applications, such as:
  - Remote monitoring and control of IoT devices, such as smart home systems, security cameras, thermostats, etc.
  - Data visualization and analysis of IoT data, such as dashboards, charts, graphs, etc.
  - Virtual and augmented reality applications that use IoT data, such as navigation, gaming, education, etc.
  - Voice and gesture recognition applications that use IoT sensors, such as voice assistants, smart speakers, etc.
  - Healthcare applications that use IoT devices, such as telemedicine, medication adherence, fitness tracking, etc.
- Some examples of tablets that are suitable for IoT applications are:
  - Apple iPad: A popular tablet that runs on iOS and has a high-quality display, camera, microphone, and speakers. It can run various IoT applications from the App Store, such as HomeKit, HealthKit, ARKit, etc.
  - Samsung Galaxy Tab: A tablet that runs on Android and has a large screen, stylus, and cellular connectivity. It can run various IoT applications from the Google Play Store, such as SmartThings, Google Fit, Google Lens, etc.
  - Microsoft Surface: A tablet that runs on Windows and has a detachable keyboard, mouse, and pen. It can run various IoT applications from the Microsoft Store, such as Cortana, Skype, OneNote, etc.
  - Amazon Fire: A tablet that runs on Fire OS and has a low price, long battery life, and Alexa integration. It can run various IoT applications from the Amazon Appstore, such as Ring, Blink, Kindle, etc.
