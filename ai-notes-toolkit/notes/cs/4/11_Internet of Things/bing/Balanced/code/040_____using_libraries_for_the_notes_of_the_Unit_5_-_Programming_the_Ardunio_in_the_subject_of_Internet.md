# Using libraries for Arduino

- Libraries are files written in C or C++ (.c,.cpp) which provide extra functionality for use in sketches, e.g. working with hardware or manipulating data .
- Libraries can be installed from the Library Manager, which is available from the Arduino IDE version 1.6.2.
- To use a library in a sketch, select it from Sketch > Import Library .
- Some libraries are built-in and some are contributed by the Arduino community.
- Libraries can be used for various purposes, such as controlling sensors, displays, motors, communication protocols, etc.
- Libraries usually consist of a header file (.h) and a source file (.cpp), which define the classes and functions of the library.
- Libraries may also include examples, keywords, and other files.
- Libraries can be modified and customized according to the user's needs.
- Libraries can be shared with other users through the Arduino website or other platforms.
