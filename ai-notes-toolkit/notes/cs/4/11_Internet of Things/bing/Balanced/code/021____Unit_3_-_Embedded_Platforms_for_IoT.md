## Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are hardware and software systems that enable IoT devices to perform their functions and communicate with other devices and networks.
- Embedded platforms for IoT typically consist of:
  - A microcontroller or microprocessor that executes the application logic and controls the device's sensors and actuators.
  - An embedded operating system or firmware that provides low-level services such as memory management, task scheduling, device drivers, network protocols, and security features.
  - A development environment that allows programmers to write, compile, debug, and deploy code for the embedded platform.
  - A connectivity module that supports wireless or wired communication standards such as Wi-Fi, Bluetooth, Ethernet, LoRa, Zigbee, etc.
  - A power supply that provides the required voltage and current for the device's operation.
  - A form factor that determines the size, shape, and weight of the device and its components.
- Embedded platforms for IoT can be classified into different categories based on their performance, power consumption, cost, and functionality. Some examples of embedded platforms for IoT are:
  - Mbed OS: An open-source platform that supports ARM-based microcontrollers and provides a cloud-based development environment, a real-time operating system, a device management service, and a library of drivers and protocols for IoT applications.
  - Amazon FreeRTOS: A platform that extends the FreeRTOS kernel with libraries for secure connectivity, over-the-air updates, device provisioning, and cloud integration for IoT devices using AWS services.
  - Raspberry Pi: A single-board computer that runs Linux or Windows and can be used for prototyping and developing IoT applications using various sensors, actuators, and modules.
  - Cisco Embedded Services Switch: A ruggedized switch that provides high-bandwidth, security, and edge computing capabilities for industrial IoT applications in remote and harsh environments.
  - AMD Ryzen Embedded: A processor that offers high-performance, low-power, and integrated graphics for IoT gateways and edge devices that require learning and decision making capabilities within a secure platform.
