### Architectural view for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things

- The architectural view of IoT is the way of describing the structure and behavior of an IoT system, which consists of various components and layers that interact with each other to provide the desired functionality.
- The architecture of IoT is not standardized or universally agreed upon, but rather depends on the specific application domain, requirements, and design choices of the IoT system.
- However, some common elements and layers can be identified in most IoT architectures, such as:

  - **Devices**: These are the physical objects that are equipped with sensors, actuators, processors, and communication interfaces, which enable them to collect, process, and exchange data with other devices or systems. Devices can be simple (e.g., temperature sensors, RFID tags, etc.) or complex (e.g., smartphones, smart watches, etc.).
  - **Network**: This is the layer that provides the connectivity and communication between the devices and other components of the IoT system. The network can use various technologies and protocols, such as Wi-Fi, Bluetooth, ZigBee, cellular, LoRa, MQTT, CoAP, etc.
  - **Cloud**: This is the layer that provides the storage, processing, and analysis of the data collected from the devices, as well as the delivery of services and applications to the end users. The cloud can use various platforms and technologies, such as AWS, Azure, Google Cloud, Hadoop, Spark, etc.
  - **Application**: This is the layer that provides the user interface and the business logic of the IoT system, which enables the users to interact with the devices and the data, and to achieve the desired outcomes. The application can use various technologies and frameworks, such as web, mobile, desktop, etc.

- Depending on the complexity and the scope of the IoT system, some additional layers or sub-layers can be added to the architecture, such as:

  - **Edge**: This is the layer that provides the local processing and analysis of the data collected from the devices, before sending it to the cloud, which can reduce the latency, bandwidth, and cost of the IoT system. The edge can use various devices and technologies, such as gateways, routers, fog nodes, edge servers, etc.
  - **Semantic**: This is the layer that provides the representation and interpretation of the data collected from the devices, using common standards and ontologies, which can enable the interoperability and integration of the IoT system with other systems and domains. The semantic layer can use various technologies and frameworks, such as RDF, OWL, SPARQL, etc.
