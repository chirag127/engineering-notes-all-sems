
## Unit 5 - Programming the Ardunio

1. The Arduino is an open-source microcontroller board that can be programmed using a range of programming languages.
2. The Arduino IDE (Integrated Development Environment) is the software platform used to write and upload code to the Arduino board.
3. C++ is the primary language used to program the Arduino, but other languages such as Python and Processing are also supported.
4. The Arduino board has a range of input and output pins that can be used to connect to external components such as LEDs, sensors, and motors.
5. The Arduino board also has a range of built-in features such as analog-to-digital converters and timers.
6. The Arduino IDE includes a range of libraries that can be used to quickly and easily write code to control external components.
7. The Arduino IDE also includes a range of debugging and simulation tools that can be used to test and debug code.
