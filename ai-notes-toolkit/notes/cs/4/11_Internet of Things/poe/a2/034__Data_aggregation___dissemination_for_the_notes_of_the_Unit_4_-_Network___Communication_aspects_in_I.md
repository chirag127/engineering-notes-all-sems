### Data aggregation & dissemination for the notes of the Unit 4 - Network & Communication aspects in IoT

1. Data aggregation: The data collected from various sensors and devices in an IoT system need to be aggregated at a single point for further processing and analysis. This aggregation of data can be done at the device level, gateway level or at the cloud level.
- Device level: Each device collects and stores its own data locally.
- Gateway level: Data from nearby devices is collected and aggregated at the gateway.
- Cloud level: Data from all the devices and gateways is collected and aggregated at the cloud platform.

2. Data dissemination: The aggregated data needs to be disseminated to the relevant applications and users. This can be done through gateways or cloud platforms.
- Gateways can disseminate data to local applications and devices.
- Cloud platforms can disseminate data to applications and users over the Internet.

3. Considerations: Some of the key considerations for data aggregation and dissemination in IoT are:
- Volume of data generated by devices and systems.
- Speed of aggregation and dissemination required.
- Computational capabilities of devices and gateways.
- Bandwidth requirements for transferring data.
- Security and privacy of data.
- Interoperability between components and systems.

4. Technologies: Some of the technologies used for data aggregation and dissemination in IoT are:
- Message queues
- Stream processing
- Databases
- Application programming interfaces (APIs)
- Networking protocols like HTTP, CoAP, MQTT, AMQP, etc.
