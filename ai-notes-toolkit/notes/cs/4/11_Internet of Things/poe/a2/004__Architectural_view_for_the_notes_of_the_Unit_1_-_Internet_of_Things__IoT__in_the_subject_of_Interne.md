### Architectural view for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things.

1.  Sensors: Sensors are used to sense the physical world parameters like temperature, humidity, light, pressure etc. and convert them into electrical signals which are fed to microcontrollers/microprocessors.
2.  Microcontrollers/Microprocessors: These are small computing devices that receive the signals from sensors and process them. They can control actuators which can interact with the physical world based on the sensor inputs and programming. Example: Arduino, Raspberry Pi etc.
3.  Connectivity: The microcontrollers/microprocessors are connected to the internet using various wired/wireless technologies like Wi-Fi, Bluetooth, cellular data, LoRaWAN etc. This connectivity allows the sensors and devices to send data to cloud and also receive data/commands from cloud.
4.  Cloud: The data from the sensors and devices is sent to the cloud for storage and further processing. The cloud provides scalable computing and storage resources. It runs various software/machine learning algorithms on the data and also provides an interface to visualize and interact with the data.
5.  Actuators: Based on the data from sensors and cloud processing, the microcontrollers/microprocessors control the actuators to interact with the physical world. Example: motors, displays, alarms etc. The actuators take actions based on programming in microcontrollers and cloud commands.
