### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT

1. Raspberry Pi is a small computer that plugs into a computer monitor or TV, and uses a standard keyboard and mouse. It is a capable little device that enables people of all ages to explore computing and learn how to program in languages like Scratch and Python.
2. Raspberry Pi is a printed circuit board that can be used for many applications and works with the Linux operating system. It provides an affordable platform for embedded products, automation or robotics, education and IoT projects.
3. The Raspberry Pi has a variety of input and output options that allow it to interface with electronics, allowing it to control things and send sensor data to services. It has GPIO pins, USB ports, an Ethernet port, HDMI output etc that enables connectivity and control.
4. The Raspberry Pi can be programmed using variety of programming languages like Python, Scratch, C/C++ etc. This allows it to be used to build desktop and server software, machine learning applications or be incorporated into IoT projects to add smart capabilities.
5. The small size and low cost of the Raspberry Pi makes it an ideal platform for students, hobbyists and professionals to learn programming and build innovative projects. It is being increasingly used in IoT solutions to collect data, control devices and add automation. Its versatility and accessibility has helped its popularity as an embedded platform for IoT.
