### Security Challenges for the notes of the Unit 6 - Challenges in IoT

1. Privacy concerns: IoT devices collect a large amount of user data which can be vulnerable to privacy breaches if not secured properly. The data from IoT devices can be tracked and misused by hackers.

2. Identity and access management: There are a large number of IoT devices and managing the identity and access of each device is a challenge. If not managed properly, it can lead to unauthorized access to IoT devices and networks.

3. Insufficient security standards: There is a lack of common security standards and frameworks for IoT devices and ecosystems leading to vulnerabilities. The devices have varying hardware and software complexities making it difficult to implement common security practices.

4. Limitations of IoT devices: The IoT devices have limited power, storage and processing capabilities which make it difficult to incorporate strong security measures. This makes the devices an easy target for cyber attacks like hacking and malware infections.

5. Interconnectivity of devices: The interconnected nature of IoT ecosystem makes it challenging to control the spread of security breaches. A vulnerability in one device can affect the entire network. It is difficult to put security measures in place for the complex and dynamic interactions between IoT devices.

6. Remote access: IoT devices can be accessed from remote locations making them prone to remote attacks. If the remote access is not secured with strong authentication and encryption, it can lead to compromised devices and networks.

7. software updates: Regular software updates are required to patch vulnerabilities and strengthen security. However, updating software on each IoT device in a network is a challenging task and often lags leading to vulnerable devices remaining in the network.
