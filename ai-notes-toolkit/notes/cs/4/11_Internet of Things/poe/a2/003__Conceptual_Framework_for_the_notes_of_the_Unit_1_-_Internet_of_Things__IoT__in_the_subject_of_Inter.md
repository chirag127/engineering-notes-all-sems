### Conceptual Framework for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things

1. Internet of Things (IoT): Internet of Things refers to the interconnection of everyday physical objects and appliances via the internet. These devices are equipped with sensors, network connections, and software which allows them to send and receive data.
2. Components of IoT: The key components of the Internet of Things are:
- Sensors: Sensors are used to detect and measure physical parameters like temperature, humidity, pressure, etc. and convert them into electric signals.
- Connectivity: Connectivity is provided using protocols like WiFi, Bluetooth, Zigbee, etc. The connected devices can then send and receive data over the internet.
- Cloud: The data is sent to the cloud or data centers for storage and analysis. The cloud provides resources for storing and processing the huge amounts of data generated by the IoT devices.
- Application: The data from the cloud is sent to applications which can be used to monitor, analyze and control the connected devices. The applications could be mobile apps, desktop software or web applications.
3. IoT Architecture: The architectural framework of Internet of Things can be classified into 4 layers:
- Perception Layer: Includes the sensors and devices to detect the physical parameters.
- Network Layer: Provides connectivity between the devices and the cloud using protocols.
- Service Layer: Includes cloud services to process and analyze the data.
- Application Layer: Includes the user applications to access the data and control the devices.
