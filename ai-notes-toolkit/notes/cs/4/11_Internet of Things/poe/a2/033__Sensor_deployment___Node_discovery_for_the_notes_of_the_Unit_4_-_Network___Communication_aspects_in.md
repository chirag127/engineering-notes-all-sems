### Sensor deployment & Node discovery

* Sensors are deployed in the field to sense the physical parameters like temperature, humidity, pressure, etc. These sensors are connected to the nodes/gateways.
* Nodes are the devices that receive the data from the sensors and transmit it to the cloud for storage and processing. Nodes can be microcontrollers, Raspberry Pis, embedded systems, etc.
* Node discovery is the process of detecting the nodes that are present in the network. This is required to establish communication between the nodes and the cloud. Some methods for node discovery are:
** Manual configuration: Nodes are configured manually with the credentials to access the network. Not scalable for large networks.
** Beaconing: Nodes periodically transmit beacon signals advertising their presence. Other nodes detect these beacon signals to discover neighboring nodes.
** Node querying: A central server queries the entire network range for the detection of nodes. Nodes respond to the query messages to announce their presence.

* Once the nodes are discovered, they can be accessed and communicated with for retrieving sensor data and sending actuator control messages.
