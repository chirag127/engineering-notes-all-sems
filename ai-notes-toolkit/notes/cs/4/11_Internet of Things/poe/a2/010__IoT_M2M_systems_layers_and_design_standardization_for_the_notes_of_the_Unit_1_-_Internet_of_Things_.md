### IoT/M2M systems layers and design standardization

- Physical layer: Comprises of sensors and actuators that capture and control the physical parameters. These include temperature, humidity, pressure sensors, motors, switches, etc.
- Device/Gateway layer: Consists of embedded systems and gateways that receive input from sensors and control the actuators. These devices collect the data, optionally aggregate and filter the data and send it to the network layer.
- Network layer: Responsible for establishing connectivity between the devices and gateways (device layer) and the servers (application layer) over various wired/wireless networks.
- Application/Middleware layer: Consists of software frameworks and applications that store, process and analyze the data received from the network layer and provide user interfaces to interact with the system.

Standardization in IoT/M2M systems:

- Hardware standardization: Standard protocols and interfaces for sensors and actuators to communicate with embedded devices. Example: OneM2M sensor interface standards
- Communication standardization: Standard communication technologies and protocols for device to device and device to server communication. Example: MQTT, CoAP, etc.
- Semantic standardization: Standard data formats and semantic models for representing information in IoT systems. Example: JSON, XML, O-MI, etc.
- Discovery and directory standardization: Standard mechanisms to discover IoT devices and directories to store device metadata. Example: DNS-SD, mDNS, etc.
- Security and privacy standardization: Standard authentication, authorization, encryption and privacy mechanisms for IoT systems. Example: DTLS, TLS, etc.
