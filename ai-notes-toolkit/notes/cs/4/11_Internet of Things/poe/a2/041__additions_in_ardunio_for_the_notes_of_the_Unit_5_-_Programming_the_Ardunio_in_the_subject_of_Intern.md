### Additions in Arduino for Unit 5 - Programming the Arduino

1. Libraries
- libraries are archive files containing multiple functions/code modules that can be added to sketches to provide extra functionality.
- Ex: Serial library is used for serial communication, SPI library for SPI communication, Ethernet library for Ethernet shield, etc.
- To install a library, download the library as a ZIP file and then use the Sketch -> Include Library -> Add .ZIP Library menu option.

2. Data Types
- int - stores whole numbers, from -32768 to 32767
- long - stores larger whole numbers, from -2,147,483,648 to 2,147,483,647
- float - stores floating point numbers, from 3.4028235E38 to -3.4028235E38
- double - stores larger floating point numbers, from 1.79769e308 to -1.79769e308
- boolean - stores true or false values
- char - stores a single character

3. Control Structures
- if else - for conditional execution of code
- for - for looping a specific number of times
- while - for looping until a condition is met
- switch case - for choosing between multiple options
- etc.

4. Functions
- Functions are blocks of code that are executed only when they are called.
- They are used to organize code, avoid repetition and make code more readable.
- Format: return_type function_name(arguments) { // function body }
- Ex: void loop(), digitalWrite(), analogRead(), etc. are inbuilt functions in Arduino. We can also create our own functions.
