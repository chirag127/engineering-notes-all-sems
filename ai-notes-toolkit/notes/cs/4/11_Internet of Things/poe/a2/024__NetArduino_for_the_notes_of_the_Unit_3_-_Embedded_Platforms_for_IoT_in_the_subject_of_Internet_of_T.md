### NetArduino for the notes of the Unit 3 - Embedded Platforms for IoT

- NetArduino is an open source hardware platform based on Arduino and Wi-Fi. It is designed for experimenting and learning about IoT and embedded systems.
- It has an Atmega328 microcontroller, a Wi-Fi module and plenty of I/O pins to connect sensors and actuators.
- It is compatible with the Arduino IDE and allows creating IoT applications using Wi-Fi connectivity and Arduino programming language easily.
- Some applications of NetArduino are home automation, environment monitoring, robotics control wirelessly etc.
- It has following key features:
    - Atmega328 microcontroller
    - Wi-Fi module (ESP-12E)
    - I/O pins compatible with Arduino shields
    - 3.3V and 5V power supply pins
    - Compatible with Arduino IDE
    - Open source hardware and software
- To start using NetArduino, you need to:
    - Assemble the NetArduino board
    - Connect it to PC and power supply
    - Install Arduino IDE
    - Connect sensors and modules to the I/O pins
    - Write code in Arduino IDE and upload to the board to build IoT projects
