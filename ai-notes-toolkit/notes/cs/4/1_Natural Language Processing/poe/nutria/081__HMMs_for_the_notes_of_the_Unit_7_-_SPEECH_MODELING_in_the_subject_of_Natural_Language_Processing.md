
### HMMs for the Notes of the Unit 7 - SPEECH MODELING in the Subject of Natural Language Processing

* Hidden Markov Models (HMMs) are probabilistic models used to describe the temporal structure of speech. 
* HMMs are composed of two main components: an underlying Markov chain and an observation model. 
* The Markov chain consists of a set of states and the probability of transitioning from one state to another. 
* The observation model is a probability distribution over the possible observations that can be generated from each state. 
* HMMs are used to model speech signals in a variety of ways, including speech recognition, speech synthesis, and speech coding. 
* HMMs are also used for speech recognition, in which the system tries to identify the spoken words or phrases from a given set of audio data. 
* HMMs can be used to model the temporal structure of speech signals by using a sequence of states and transitions between them. 
* HMMs can also be used to model the spectral structure of speech signals by using a set of Gaussian mixture models (GMMs). 
* HMMs can be used to model the prosodic structure of speech signals by using a set of HMM-based prosody models. 
* HMMs are also used in speech synthesis, in which the system tries to generate a speech signal that is similar to the input speech signal. 
* HMMs are also used in speech coding, in which the system tries to compress the speech signal by using a set of HMM-based coding algorithms.
