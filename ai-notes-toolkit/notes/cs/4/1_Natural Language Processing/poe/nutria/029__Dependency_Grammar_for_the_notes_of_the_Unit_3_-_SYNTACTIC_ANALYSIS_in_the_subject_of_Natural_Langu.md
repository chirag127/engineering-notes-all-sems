
### Dependency Grammar for the Notes of Unit 3 - Syntactic Analysis in Natural Language Processing

* Dependency grammar is a type of syntactic analysis in which the structure of a sentence is represented as a graph of dependencies between the words.
* Dependency relations are represented as labeled arcs between words. The labels indicate the type of relation between the words, such as subject, object, or modifier.
* Dependency grammar is used in natural language processing to analyze the structure of a sentence and to identify the syntactic relations between words.
* Dependency grammar is also used to generate parse trees, which are used to represent the syntactic structure of a sentence.
* Dependency grammar is a powerful tool for natural language processing, as it can be used to identify the syntactic relations between words in a sentence and to generate parse trees.
