
### Context Free Grammars
Context Free Grammars (CFG) are a set of rules used to describe the syntax of a language. They are used in Natural Language Processing (NLP) to analyze and understand the structure of a sentence. 

CFG is composed of four components: 
1. **Terminal symbols** – These are the words that appear in the sentence. 
2. **Non-terminal symbols** – These are the symbols that are used to represent the structure of a sentence. 
3. **Production rules** – These are the rules that define how the non-terminal symbols are combined to form a sentence. 
4. **Start symbol** – This is the symbol that starts the sentence. 

CFG can be used to determine the syntactic structure of a sentence. It can be used to identify the subject, verb, and object of a sentence and can be used to determine if a sentence is grammatically correct. CFG can also be used to generate new sentences by combining existing terminals and non-terminals. 

CFG is a powerful tool for understanding and analyzing natural language. It can be used to create language models that can be used to generate new sentences and can be used to create machine translation systems.
