
### Object-oriented Analysis and Design (OOAD) Process

1. OOAD is a process used to develop software applications and services using object-oriented programming languages.
2. It is a systematic approach to designing and developing software applications based on a set of principles and practices that focus on the objects used in the software.
3. OOAD involves the use of Unified Modeling Language (UML) to create diagrams that represent the system being developed.
4. OOAD is used to create an enterprise-wide service-oriented architecture (SOA) that can be used to develop applications that can be used across multiple platforms.
5. OOAD is a process that involves the use of object-oriented techniques such as classes, objects, inheritance, and polymorphism to create a system that is easy to maintain and extend.
6. OOAD also involves the use of design patterns to create reusable components that can be used in different applications.
7. OOAD is a process that is used to create applications that are easy to maintain, extend, and understand.
