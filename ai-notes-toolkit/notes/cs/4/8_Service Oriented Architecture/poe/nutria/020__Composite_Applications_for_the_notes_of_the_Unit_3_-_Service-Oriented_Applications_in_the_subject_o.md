
### Composite Applications for the Notes of Unit 3 - Service-Oriented Applications in Service Oriented Architecture

1. Composite applications are applications that are composed of multiple services.

2. A service-oriented architecture (SOA) is a way of designing applications in which services are shared and reused across multiple applications.

3. Composite applications are composed of multiple services that are connected together to create a single application.

4. The services can be written in different programming languages and can run on different platforms.

5. The services are connected together using various techniques, such as web services, message queues, and remote procedure calls.

6. The services can be hosted on different servers, making it easier to scale the application.

7. The services can be managed independently, making it easier to maintain and update the application.

8. Composite applications provide many benefits, such as increased scalability, increased flexibility, and increased maintainability.
