
## Unit 9 - SOA Best Practices

1. Service-Oriented Architecture (SOA) is a design pattern that enables the development of applications that are composed of services.

2. Services should be designed to be autonomous, meaning they should have their own data stores, business logic, and user interfaces.

3. Services should be designed to be self-contained and loosely coupled, meaning they should be able to function independently of other services.

4. Services should be designed to be reusable, meaning they should be designed to be used in multiple contexts.

5. Services should be designed to be composable, meaning they should be able to be combined to create new services.

6. Services should be designed to be secure, meaning they should be protected from unauthorized access and modification.

7. Services should be designed to be extensible, meaning they should be able to accommodate new features and functionality.

8. Services should be designed to be scalable, meaning they should be able to handle increased workloads.

9. Services should be designed to be fault tolerant, meaning they should be able to continue to function despite errors or failures.
