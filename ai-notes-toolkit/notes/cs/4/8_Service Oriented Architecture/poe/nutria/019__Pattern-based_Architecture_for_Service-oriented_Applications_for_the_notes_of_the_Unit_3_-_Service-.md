
### Pattern-based Architecture for Service-oriented Applications

1. Service-oriented architecture (SOA) is a design pattern for building distributed applications that are composed of services. 
2. SOA is based on the idea of encapsulating business logic into separate components that can be invoked over a network. 
3. Each service is self-contained and can be accessed through a standardized interface. 
4. SOA enables applications to be composed from multiple services that can be located on different machines and accessed over the network. 
5. The SOA pattern is often used to build enterprise applications that are composed of multiple services. 
6. A service-oriented architecture is typically composed of two main components: a service registry and a service bus. 
7. The service registry stores information about the services that are available in the system. 
8. The service bus is a software component that enables services to communicate with each other. 
9. Services can be invoked using the service bus, which provides a standardized interface for communication between services. 
10. The service bus also provides a layer of abstraction between services, allowing them to be invoked without knowledge of the underlying technology.
