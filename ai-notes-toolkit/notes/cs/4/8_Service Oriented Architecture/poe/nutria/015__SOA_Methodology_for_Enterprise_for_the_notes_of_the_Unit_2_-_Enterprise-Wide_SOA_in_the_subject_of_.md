
### SOA Methodology for Enterprise

1. Service Oriented Architecture (SOA) is a set of principles and methodologies for designing and developing software applications as a set of services. 
2. SOA allows for the reuse of services, which can be shared among different applications. 
3. SOA enables applications to be loosely coupled, meaning that changes to one application will not affect the other applications. 
4. SOA encourages the use of standard protocols to communicate between services, allowing for better interoperability. 
5. SOA provides a framework for enterprise-wide integration, allowing for the sharing and reuse of data, services, and applications across the enterprise. 
6. SOA promotes the use of web services, which are self-contained and self-describing services that are accessible over the Internet. 
7. SOA facilitates the development of distributed applications, which can be deployed across multiple platforms and locations. 
8. SOA encourages the use of open standards and protocols to ensure that applications are interoperable and can be easily integrated.
