
### WAP: Architecture for the Unit 2 - Wireless Networking

Wireless LAN Overview: 

- MAC (Media Access Control) issues: MAC is a protocol layer within the data link layer of the OSI reference model that is responsible for the delivery of data frames between nodes of a network. It is responsible for the efficient and reliable delivery of data frames within the network.
- IEEE 802.11: IEEE 802.11 is a standard for wireless local area networks (WLANs) that defines the physical layer and Media Access Control (MAC) layer of the network. It defines the operating frequency, data rate, modulation, and security protocols used in WLANs.
- Bluetooth: Bluetooth is a wireless technology standard for exchanging data over short distances from fixed and mobile devices. It is used for communication between devices such as computers, mobile phones, and peripherals.
- Wireless in Mobile Computing: Mobile computing is the use of wireless devices to access data and services on the Internet. It is a form of ubiquitous computing that allows users to access information and services on the go. Wireless technologies such as Wi-Fi, Bluetooth, and cellular networks are used to enable mobile computing.
