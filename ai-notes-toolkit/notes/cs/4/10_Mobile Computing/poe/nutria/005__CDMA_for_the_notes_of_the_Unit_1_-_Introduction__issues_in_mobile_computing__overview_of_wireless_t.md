
### CDMA for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

1. Mobile Computing is a field of computing that enables users to access data and information from anywhere at any time.
2. Wireless telephony is a form of communication that allows users to communicate without the need for a physical connection.
3. Cellular concept is a concept that divides a geographic area into small cells, each of which has its own base station for communication.
4. GSM (Global System for Mobile Communications) is a standard for digital mobile phone communication that is used by most mobile phone networks around the world.
5. CDMA (Code Division Multiple Access) is a digital cellular technology used for mobile communication. It uses spread spectrum technology for communication and allows multiple users to access the same channel. CDMA is more secure than other cellular technologies as it uses a unique code to identify each user.
