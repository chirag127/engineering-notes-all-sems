
## Unit 4 - Mobile Agents computing, security and fault tolerance, transaction processing in mobile computing

1. Mobile Agents Computing: Mobile Agents Computing is a distributed computing model which allows for the execution of autonomous programs, or agents, on remote computers. This model is particularly suited to mobile environments, as it allows for the execution of tasks on remote computers without the need for a user to be physically present.

2. Security and Fault Tolerance: Security and Fault Tolerance are key considerations when using Mobile Agents Computing. Security measures must be taken to ensure that agents are not able to access sensitive data or carry out malicious activities. Fault tolerance measures must also be implemented to ensure that agents are able to complete their tasks successfully, even in the event of network or system failure.

3. Transaction Processing in Mobile Computing: Transaction Processing in Mobile Computing is the process of securely executing transactions over a mobile network. This process must take into account the security and reliability of the network, as well as the need for transactions to be completed quickly and efficiently. Specialized protocols and algorithms are used to ensure that transactions are processed securely and efficiently.
