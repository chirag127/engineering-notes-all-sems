
## Unit 3 - Data Management Issues, Data Replication for Mobile Computers, Adaptive Clustering for Mobile 

1. Data management issues refer to the challenges associated with the collection, storage, and manipulation of data. These issues are especially relevant for mobile computers, which often have limited storage capacity and limited processing power.

2. Data replication is a technique used to ensure data is available and accessible on mobile computers. It involves making multiple copies of data, which can be stored on multiple devices or in multiple locations. This helps to ensure data is not lost or corrupted in the event of a device or network failure.

3. Adaptive clustering is a technique used to improve the performance of mobile computers. It involves grouping mobile devices into clusters, which can be used to share data and resources. This helps to reduce the amount of data that needs to be stored and transmitted on each device, and can improve the speed and reliability of data transfers.
