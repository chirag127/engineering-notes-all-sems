## Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless

Wireless networking has become an essential part of our lives, and it is crucial to understand its basics. In this unit, we will cover the following topics:

### MAC Issues

* MAC (Media Access Control) is the protocol used to control access to the wireless network.
* MAC issues can occur when two or more devices try to access the network at the same time, leading to collisions and a decrease in network efficiency.
* To avoid MAC issues, the IEEE 802.11 protocol was introduced.

### IEEE 802.11

* IEEE 802.11 is a set of standards that define the wireless LAN (Local Area Network).
* The IEEE 802.11 protocol defines the rules for wireless communication between devices.
* The protocol uses carrier sense multiple access with collision avoidance (CSMA/CA) to avoid collisions and ensure efficient network performance.
* The IEEE 802.11 protocol supports different frequencies and data transfer rates.

### Bluetooth

* Bluetooth is a wireless technology used to connect devices over short distances.
* Bluetooth uses the frequency-hopping spread spectrum (FHSS) to avoid interference and improve network performance.
* Bluetooth devices are designed to work in a personal area network (PAN).

### Wireless LAN

* A wireless LAN is a type of local area network that uses wireless technology to connect devices.
* Wireless LANs are used in homes, offices, and public places to provide internet access.
* Wireless LANs are more flexible and convenient than wired LANs but may have security concerns.

In conclusion, understanding the basics of wireless networking, including MAC issues, IEEE 802.11, Bluetooth, and wireless LANs, is crucial to ensure efficient network performance and security.
