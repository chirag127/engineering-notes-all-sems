### Applications for the Notes of Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the Subject of Mobile Computing

In this unit, you will learn about the basics of wireless networking, including MAC issues, IEEE 802.11, Blue Tooth, and Wireless. Here are some applications that can help you understand the concepts better:

1. **Wireshark:** Wireshark is an open-source network analyzer that allows you to capture and analyze network traffic in real-time. You can use it to analyze wireless traffic, including 802.11 frames and Bluetooth packets. It also provides a graphical representation of the captured data, making it easier to understand.

2. **NetStumbler:** NetStumbler is a popular wireless network discovery tool that can help you find wireless access points (APs) and detect unauthorized APs. It can also display information about the APs, such as SSID, signal strength, and channel number.

3. **AirSnort:** AirSnort is a wireless LAN (WLAN) tool that can help you crack WEP encryption keys. It works by passively monitoring transmissions, computing the encryption key when enough packets have been gathered.

4. **Kismet:** Kismet is another wireless network discovery tool that can detect wireless APs and clients. It provides a lot of information about the detected devices, including SSID, MAC address, signal strength, and encryption type.

5. **Bluetooth Scanner:** Bluetooth Scanner is an Android app that allows you to discover and connect to Bluetooth devices. It can display information about the discovered devices, such as name, address, and service type.

6. **Fing:** Fing is a network scanner that can help you discover all devices connected to your network, including wireless devices. It can display information about the devices, such as IP address, MAC address, and device type.

7. **WiFi Analyzer:** WiFi Analyzer is an Android app that allows you to analyze and optimize your wireless network. It can display information about the wireless channels, signal strength, and interference levels. You can also use it to find the best channel for your wireless network.

These applications can help you understand the basics of wireless networking, including MAC issues, IEEE 802.11, Blue Tooth, and Wireless. They provide a practical way to learn about the concepts and can help you prepare for exams.
