### Disconnected operations for the notes of the Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile in the subject of Mobile Computing.

1. Disconnected operation: Mobile devices get disconnected from the network frequently due to limited bandwidth, poor connectivity, etc. Hence, mobile applications should support disconnected operations by caching data locally and synchronizing with the server database when the connection is available. This ensures continuous availability of data and services.

2. Data replication: Due to limited storage, memory and processing power of mobile devices, it is not feasible to store and process huge amounts of data on the mobile device. Hence, data is replicated from centralized databases to the mobile device selectively based on usage. This reduces the synchronization time and cost. The replica can be updated when the device is connected to the network.

3. Adaptive clustering: In MANETs, mobile nodes can move freely and cluster heads change dynamically. Hence, an adaptive clustering algorithm is required which can dynamically change the cluster formation based on node mobility, energy levels, etc. This enhances scalability and performance of routing, data dissemination, etc. in the mobile ad hoc network.

4. Summary: To handle data management issues and provide consistent performance in mobile computing, techniques like disconnected operation, data replication and adaptive clustering are employed. These techniques efficiently utilize the available resources and adapt to the dynamic nature of mobile environments.
