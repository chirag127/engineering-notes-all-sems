### CDMA

- Code Division Multiple Access
- Spread spectrum technology
- Each signal is spread over a wide frequency band
- Unique code is assigned to each user to separate signals
- Bandwidth is not divided into channels
- All users share the full bandwidth all the time
- More bandwidth efficient than TDMA and can support more users
- Used in 2G and 3G cellular systems like IS-95 and cdma2000
- Requires tight power control to minimize interference
- Signal can be recovered only if correct code is used
- Used for voice and data in cellular systems
