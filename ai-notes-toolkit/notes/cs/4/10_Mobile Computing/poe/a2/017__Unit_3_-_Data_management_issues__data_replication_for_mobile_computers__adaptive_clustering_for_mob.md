## Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile

1. Data management issues for mobile devices:
- Limited storage capacity
- Limited battery life
- Frequent disconnections
- Location-dependent data access

2. Data replication for mobile devices:
- Replicate data on local storage for offline access and faster access
- Periodically sync with central database
- Handle conflicts when multiple replicas are updated

3. Adaptive clustering for mobile networks:
- Groups of mobile devices form clusters based on proximity
- Each cluster has a cluster head which coordinates communication with the central database
- Cluster formation and cluster heads change dynamically as devices move
- Reduces communication overhead compared to each device accessing the central database individually
