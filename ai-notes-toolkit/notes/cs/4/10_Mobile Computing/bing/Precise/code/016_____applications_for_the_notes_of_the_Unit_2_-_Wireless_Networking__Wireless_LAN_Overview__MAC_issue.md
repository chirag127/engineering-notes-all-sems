### Applications for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

1. Wireless networking allows for the connection of multiple devices without the need for cables or wires.
2. Wireless LANs (Local Area Networks) use radio waves to transmit data between devices.
3. MAC (Media Access Control) issues in wireless networking include collision avoidance and the hidden node problem.
4. IEEE 802.11 is a set of standards for implementing wireless LANs.
5. Bluetooth is a short-range wireless technology used for communication between devices.
6. Wireless technology has many applications, including mobile computing, home automation, and the Internet of Things.
