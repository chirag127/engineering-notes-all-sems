### Channel Structure

In the context of wireless telephony and cellular networks, the channel structure refers to the way in which the available frequency spectrum is divided and allocated for communication between the mobile devices and the base stations.

1. **Frequency Division Multiple Access (FDMA):** This method divides the available frequency spectrum into multiple channels, each with a specific frequency range. Each user is assigned a unique channel for communication.

2. **Time Division Multiple Access (TDMA):** This method divides the available time into multiple time slots. Each user is assigned a unique time slot for communication, allowing multiple users to share the same frequency channel.

3. **Code Division Multiple Access (CDMA):** This method assigns a unique code to each user, allowing multiple users to share the same frequency channel simultaneously. The signals from different users are separated using the assigned codes.

These are the three main methods used for channel allocation in cellular networks. Each method has its own advantages and disadvantages, and the choice of method depends on various factors such as the number of users, the available frequency spectrum, and the desired level of security.
