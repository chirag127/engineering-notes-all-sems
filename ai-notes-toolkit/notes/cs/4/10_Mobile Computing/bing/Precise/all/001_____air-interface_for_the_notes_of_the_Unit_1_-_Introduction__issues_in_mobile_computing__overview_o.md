# Unit 1 - Introduction, Issues in Mobile Computing, Overview of Wireless Telephony: Cellular Concept, GSM

### Air-interface

- Air-interface refers to the radio frequency portion of the circuit between the mobile device and the active base station.
- It is the technical space that enables wireless communication between a mobile device and a network.
- The air-interface is a critical component of any wireless system as it determines the quality of the communication link.
- The air-interface is defined by a set of technical standards that specify the radio frequency, modulation scheme, and other parameters.
- In the context of wireless telephony, the air-interface is used to transmit voice and data between the mobile device and the network.
- The cellular concept is based on the use of multiple, low-power transmitters to provide coverage over a large area.
- The Global System for Mobile Communications (GSM) is a digital mobile telephony system that uses a variation of Time Division Multiple Access (TDMA) to enable multiple users to share the same frequency channel.
- GSM is the most widely used standard for mobile telephony in the world, with over 80% of the global mobile market using the standard.
