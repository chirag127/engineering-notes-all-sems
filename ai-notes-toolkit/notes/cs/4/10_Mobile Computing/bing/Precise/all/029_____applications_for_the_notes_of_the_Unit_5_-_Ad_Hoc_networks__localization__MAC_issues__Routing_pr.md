# Unit 5 - Ad Hoc Networks, Localization, MAC Issues, Routing Protocols, Global State Routing (GSR) in Mobile Computing

## Applications of Ad Hoc Networks
- Ad hoc networks can be used in emergency situations where there is no existing communication infrastructure or the infrastructure is damaged.
- Ad hoc networks can be used for military operations in remote areas where there is no existing communication infrastructure.
- Ad hoc networks can be used for temporary events such as conferences, exhibitions, and concerts where a temporary network is needed.
- Ad hoc networks can be used for sensor networks where sensors are deployed in remote areas to collect data.

## Localization
- Localization is the process of determining the physical location of a device in a network.
- Localization can be achieved using various techniques such as GPS, triangulation, and time difference of arrival.
- Localization is important in ad hoc networks for routing and location-based services.

## MAC Issues
- MAC (Medium Access Control) is responsible for controlling access to the shared medium in a network.
- In ad hoc networks, MAC protocols need to be designed to handle the dynamic nature of the network and the limited resources of the devices.
- Common MAC protocols used in ad hoc networks include CSMA/CA and TDMA.

## Routing Protocols
- Routing protocols are responsible for finding and maintaining routes between devices in a network.
- In ad hoc networks, routing protocols need to be designed to handle the dynamic nature of the network and the limited resources of the devices.
- Common routing protocols used in ad hoc networks include AODV, DSR, and OLSR.

## Global State Routing (GSR)
- GSR is a routing protocol for ad hoc networks that uses the global state of the network to make routing decisions.
- GSR maintains a global view of the network by periodically exchanging link state information between devices.
- GSR can provide more efficient routing compared to other routing protocols, but it requires more resources and may not scale well in large networks.
