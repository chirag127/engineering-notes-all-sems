### CDMA for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

- CDMA stands for Code Division Multiple Access.
- CDMA is a communications technology used in cellular systems.
- In CDMA, each user is assigned a unique code sequence.
- The cellular structure of a wireless network consists of clusters of cells .
- GSM is another cellular technology that is widely used.
- GSM supports transmitting data and voice both at once, but CDMA does not have this feature.
- The main distinction between GSM and CDMA is that in GSM, the customer information is put on a SIM card which can be moved to a new mobile phone. Whereas only mobile phones from a set of whitelisted companies can be used with a CDMA network .
- GSM uses a variation of time division multiple access (TDMA) and is the most widely used of the three digital wireless telephony technologies: TDMA, GSM and CDMA .
- GSM digitizes and compresses data, then sends it down a channel with two other streams of user data, each in its own time slot .
