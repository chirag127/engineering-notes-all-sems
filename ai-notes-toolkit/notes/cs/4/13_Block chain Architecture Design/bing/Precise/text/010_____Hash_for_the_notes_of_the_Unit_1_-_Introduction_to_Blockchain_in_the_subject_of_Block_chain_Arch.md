### Hash for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

- A hash is a mathematical function that takes an input of any size and produces a fixed-size output.
- Hash functions are commonly used in cryptography and data storage.
- In the context of blockchain, hash functions are used to secure the data stored in blocks.
- Each block in a blockchain contains a hash of the previous block, creating a chain of blocks that cannot be altered without changing the hash values of all subsequent blocks.
- Common hash functions used in blockchain include SHA-256 and Keccak-256.
- Hash functions are designed to be one-way, meaning that it is computationally infeasible to determine the original input from the hash value.
- This property makes hash functions useful for verifying the integrity of data, as any changes to the data will result in a different hash value.
- In blockchain, hash functions are also used in the mining process to create new blocks and add them to the chain.
- Miners compete to find a hash value that meets certain criteria, and the first miner to find such a value is rewarded with a certain number of cryptocurrency units.
- The use of hash functions in blockchain ensures the security and integrity of the data stored in the chain.
