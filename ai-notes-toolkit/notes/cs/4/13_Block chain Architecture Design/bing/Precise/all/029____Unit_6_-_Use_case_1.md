## Unit 6 - Use Case 1

1. A use case is a description of a system's behavior as it responds to a request from a user.
2. Use cases are used to capture the functional requirements of a system.
3. Each use case describes a specific scenario in which the system interacts with a user or another system to achieve a goal.
4. Use cases are typically written in a structured format, with a clear description of the actors involved, the preconditions, the steps of the interaction, and the postconditions.
5. Use cases can be used to drive the development process, by providing a clear and concise description of the system's behavior.
6. Use cases can also be used to validate the system, by ensuring that all the required functionality has been implemented and that the system behaves as expected.
