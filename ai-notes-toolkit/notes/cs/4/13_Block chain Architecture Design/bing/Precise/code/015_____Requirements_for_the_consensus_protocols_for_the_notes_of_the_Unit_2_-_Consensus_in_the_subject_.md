### Requirements for the consensus protocols for the notes of the Unit 2 - Consensus in the subject of Block chain Architecture Design

1. **Agreement:** All nodes in the network must agree on the same value.
2. **Termination:** The protocol must eventually terminate and all nodes must decide on a value.
3. **Validity:** If all nodes propose the same value, then all nodes must decide on that value.
4. **Fault tolerance:** The protocol must be able to function correctly even if some nodes are faulty or malicious.
5. **Integrity:** No node should be able to propose more than one value.
6. **Robustness:** The protocol should be able to withstand network delays, partitions, and packet loss.
