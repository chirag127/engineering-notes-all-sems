### Hash for the notes of the Unit 1 - Introduction to Blockchain in the subject of Blockchain Architecture Design

- Hashing is a process of converting a message or data into a fixed size string of characters.
- The resulting string is called a hash value, hash code, or simply a hash.
- Hashing is widely used in cryptography and blockchain technology.
- In blockchain, hashing is used to create a unique identifier for each block in the chain.
- Each block in the chain contains a hash value of the previous block, creating a chain of blocks that cannot be altered without changing all subsequent blocks.
- This creates a secure and tamper-proof ledger of transactions.
- Hashing algorithms used in blockchain include SHA-256, Scrypt, and Ethash.
- The SHA-256 algorithm is widely used in popular cryptocurrencies like Bitcoin and Ethereum.
- Hashing also allows for efficient storage and retrieval of data, as the hash value can be used as a compact representation of the original data.
- However, it is important to note that hashing is a one-way function, meaning it is not possible to retrieve the original data from the hash value.
- Hashing is a crucial component of blockchain technology and is essential to ensuring the security and integrity of the blockchain ledger.
