

## Unit 6 - Use Case 1

1. Use cases are a tool used to identify the requirements, or functionalities, of a system.
2. A use case is a set of actions that a system performs to achieve a goal.
3. Use cases are created by analyzing the system's users and their goals.
4. Use cases are used to identify the functional requirements of a system, such as what the system should do, how it should do it, and when it should do it.
5. Use cases are typically written in a structured format, using a combination of natural language and diagrams.
6. Use cases can be used to document the system's user requirements, and can be used to create test plans to ensure that the system meets the user's needs.
