
### Permissions for the Notes of the Unit 1 - Introduction to Blockchain in the Subject of Blockchain Architecture Design

1. Permissioned blockchains require users to be authenticated before being able to access the network.
2. Permissioned blockchains are typically used to manage private data and are not open to the public.
3. Permissioned blockchains can be used to create and manage digital identities, which can be used to control access to resources on the blockchain.
4. Permissioned blockchains can be used to create and manage digital assets, such as cryptocurrencies, and to track their ownership.
5. Permissioned blockchains can be used to create and manage smart contracts, which are programs that execute automatically when certain conditions are met.
6. Permissioned blockchains can be used to create and manage decentralized applications (dApps), which are applications that run on the blockchain.
7. Permissioned blockchains can be used to create and manage decentralized autonomous organizations (DAOs), which are organizations that are managed by a distributed network of computers.
8. Permissioned blockchains can be used to create and manage distributed ledgers, which are databases that are shared across multiple computers.
