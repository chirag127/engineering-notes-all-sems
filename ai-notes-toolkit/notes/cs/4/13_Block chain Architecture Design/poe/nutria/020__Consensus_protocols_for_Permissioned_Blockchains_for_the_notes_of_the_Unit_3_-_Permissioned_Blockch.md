
### Consensus Protocols for Permissioned Blockchains

1. Proof of Authority (PoA): PoA is a consensus algorithm which relies on a set of validators which are pre-selected and approved by the network. It is a highly secure consensus system, as the validators are known and trusted entities.

2. Practical Byzantine Fault Tolerance (PBFT): PBFT is a consensus algorithm which relies on a set of validators to reach consensus. It is a very efficient consensus system, as it requires only a few messages exchanged between the validators for consensus to be reached.

3. Delegated Proof of Stake (DPoS): DPoS is a consensus algorithm which relies on a set of delegates who are elected by the network. It is a secure consensus system, as the delegates are elected based on their reputation and the amount of stake they hold.

4. Proof of Elapsed Time (PoET): PoET is a consensus algorithm which relies on a random selection process to choose the validator who will create the next block. It is a secure consensus system, as it is based on a random selection process.

5. Byzantine Fault Tolerance (BFT): BFT is a consensus algorithm which relies on a set of validators to reach consensus. It is a secure consensus system, as it requires a majority of the validators to agree on a transaction for it to be processed.
