### Control Operations for the notes of the Unit 2 - Quantum Computation

1. Controlled-NOT (CNOT) Gate:
- It is a 2-qubit gate that flips the target qubit if and only if the control qubit is |1>.
- If control = |0>, then target qubit remains unchanged.
- If control = |1>, then target qubit's state gets flipped.
- It is a fundamental gate for quantum computing and quantum error correction.

2. Toffoli Gate:
- It is a 3-qubit gate that flips the target qubit if and only if both the control qubits are |1>.
- If either control qubit is |0>, then target qubit remains unchanged.
- It is a 3-qubit controlled-controlled-not gate.
- It is a universal reversible gate and can be used to implement any boolean function.

3. Fredkin Gate:
- It is a 3-qubit gate that swaps the states of the target qubit and the second control qubit if and only if the first control qubit is |1>.
- If the first control qubit is |0>, then none of the qubits change state.
- It is a fundamental gate for topological quantum computing.
