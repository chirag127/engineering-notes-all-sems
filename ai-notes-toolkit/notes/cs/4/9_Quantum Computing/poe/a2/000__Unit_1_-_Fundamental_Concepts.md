## Unit 1 - Fundamental Concepts

1. Data
- Data refers to raw facts and figures that can be collected, stored, and processed for some purpose.
- Data can be numbers, letters, symbols, sounds, images, etc. that have some meaning.

2. Information
- Information is data that has been organized or presented in a meaningful context.
- For data to become information, it must be interpreted and take on some significance.

3. Processing
- Data and information must be processed or manipulated in some way to derive value from them.
- Processing involves functions such as sorting, classifying, summarizing, averaging, correlating, and transforming data and information.

4. Storage
- Data and information must be stored or recorded in some medium for later use.
- Common storage media include paper, tapes, disks, and integrated circuits.

5. Database
- A database is a repository of data that is organized so that it can be easily accessed, managed, and updated.
- Database software is used to create, read, update, and delete data in a database.

6. Retrieval
- The ultimate goal of storing data and information is to retrieve what is needed.
- Effective storage and retrieval depends on how well the data and information were organized.

7. Analysis
- Retrieved data and information must be analyzed or interpreted to determine their meaning and significance.
- Data and information analysis is key to all fields of research and applications.
