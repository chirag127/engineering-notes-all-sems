### Requirements for the notes of the Unit 2 - Open Grid Services Architecture in the subject of High Performance Computing.

1. Define Open Grid Services Architecture (OGSA)
- OGSA is a standard that defines a service-oriented architecture for accessing and sharing resources such as computing powers, databases, applications, etc. over the internet.
- It enables on-demand access to resources based on service level agreements.
- It uses web services to provide a standard way to invoke and manage grid resources and applications.

2. Discuss the core components of OGSA
- Grid service: A software component that encapsulates some grid functionality and makes it available over a network. It is a stateful web service.
- Grid service container: The environment that hosts grid services. It provides threading, security, resource management, and communication facilities to grid services.
- Grid service handle: A reference to a grid service instance that can be used to invoke operations on the service.
- Grid service document: An XML document that describes a grid service including its interfaces and behaviors.

3. Explain the capabilities of OGSA
- On-demand access: Resources can be accessed as needed.
- Hiding complexity: The technical complexity of the grid is hidden by the standard service interfaces.
- Adaptability: OGSA can work with heterogeneous systems and technologies. New resources and services can be added easily.
- Reliability: Fault detection and recovery mechanisms can be implemented.
- Security: Authentication, authorization, and other security services can be incorporated.
