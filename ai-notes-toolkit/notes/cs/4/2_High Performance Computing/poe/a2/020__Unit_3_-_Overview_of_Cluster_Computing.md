## Unit 3 - Overview of Cluster Computing

1. A cluster is a group of computers that work together closely so that in many respects they can be viewed as a single system. Clusters are commonly used for distributed computing projects that require considerable computing power.
2. The components of a cluster are regular computers or servers that are connected through a network. Each machine in a cluster is called a node. The nodes in a cluster share storage and processing resources to complete common tasks.
3. Cluster computing is often used for tasks that can be divided into parts that can be solved concurrently, such as scientific simulations, data processing, and web services. The cluster harnesses the combined power of multiple nodes to solve a problem more quickly than if a single node was used.
4. The main advantages of cluster computing are cost effectiveness and high performance. Commodity components can be used to build a cluster, and open source software is available to help coordinate the nodes. Performance can be improved by simply adding more nodes to the cluster.
5. However, cluster computing also introduces additional complexity in programming, resource management, and system administration. Special software is required to coordinate the operation of the nodes, allocate tasks, and combine results. Administration challenges include deploying software to many nodes, dealing with node failures, and optimizing resource usage.
