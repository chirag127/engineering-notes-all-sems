### Resource Management and Scheduling

- Resource management is critical for efficient operation of cluster computing systems. The key resources to be managed are:
- CPUs: Need to allocate CPUs to competing jobs/tasks.
- Memory: Need to allocate memory to competing jobs/tasks.
- Storage: Need to allocate storage to competing jobs/tasks and manage I/O bandwidth.
- Network: Need to allocate network bandwidth to competing jobs/tasks.

- Typical resource management objectives:
- Maximize resource utilization.
- Meet performance goals/SLAs.
- Enforce fairness/priority.
- Optimize power/cost.

- Scheduling refers to the process of allocating resources to jobs. Key scheduling decisions include:
- Which job to run next?
- Which resources to allocate to a job?
- Preemption: Whether and when to suspend a running job to free up resources for a higher-priority job.

- Commonly used scheduling policies/algorithms include:
- First-come, first-served (FCFS)
- Shortest job first (SJF)
- Priority-based
- Round-robin
- Multilevel feedback queue
- Backfilling
- Space-sharing vs. Time-sharing
