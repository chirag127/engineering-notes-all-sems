### Cloud Computing Components

1. Infrastructure as a Service (IaaS):
- It provides access to computing resources like servers, storage, and networking.
- The service providers offer virtualized resources wherein customers can launch virtual machines(VMs) with the operating system of their choice.
- Examples: Amazon EC2, Google Compute Engine, etc.

2. Platform as a Service (PaaS):
- It provides a computing platform with an environment to develop, run, and manage applications.
- The service providers offer a framework for development, testing, and hosting web applications.
- Examples: AWS Elastic Beanstalk, Google App Engine, Azure, etc.

3. Software as a Service (SaaS):
- It provides access to applications as a service wherein customers can use the applications as per their requirements, on-demand.
- The service providers own the infrastructure and manage the application.
- Examples: G Suite, Office 365, Salesforce, etc.

The components in cloud computing provide various resources and services to suit different requirements. Customers can choose and utilize the suitable component(s) based on their needs and budget.
