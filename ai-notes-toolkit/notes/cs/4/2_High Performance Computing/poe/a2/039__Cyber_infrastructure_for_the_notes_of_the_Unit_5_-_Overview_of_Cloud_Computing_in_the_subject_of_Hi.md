### Cyber infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing.

1. Cloud Computing: Cloud Computing refers to the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.
2. Types of Cloud Computing: There are three main types of cloud computing:
- Infrastructure as a Service (IaaS): The lowest level of cloud computing where the cloud provider offers the infrastructure components such as servers, storage, and network on rent. The customer can install their choice of OS and software. Examples: Amazon EC2, Microsoft Azure.
- Platform as a Service (PaaS): The cloud provider offers a computing platform along with the infrastructure. The customer can deploy their applications on the platform without the complexity of maintaining the infrastructure. Examples: AWS Elastic Beanstalk, Google App Engine.
- Software as a Service (SaaS): The cloud provider offers applications over the Internet. The customer can access the applications online without the complexity of software maintenance. Examples: Gmail, Dropbox, Salesforce, etc.

3. Benefits of Cloud Computing:
- Increased Agility and Scalability: It is easy to scale up or down the resources based on demand.
- Reduced Cost: No upfront capital expenditure on infrastructure and pay-as-you-go model reduces costs.
- Automatic Software Updates: Software updates happen automatically on the cloud without any user intervention.
- High Availability: The cloud infrastructure offers redundancy and backup resulting in high availability of resources and applications.
- Easy Access: Access to resources and applications over the Internet from anywhere at any time.
