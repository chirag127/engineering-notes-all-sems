### Application for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing.

1. Cloud Computing: Cloud computing refers to the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.

2. Types of Cloud Computing: There are three main types of cloud computing:

- Infrastructure as a Service (IaaS): Provides virtual computing resources like servers, storage, and networking. The customer can install their own software and operating systems. Example: Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP)
- Platform as a Service (PaaS): Provides a computing platform to develop, run, and manage applications. The customer can develop their own applications. Example: AWS Elastic Beanstalk, Azure App Service, GCP App Engine
- Software as a Service (SaaS): Provides access to application software and databases. The customer accesses the software over the internet. Example: G Suite, Office 365, Salesforce, Dropbox

3. Benefits of Cloud Computing:
- Scalability: Scaling computing resources up or down as needed.
- Flexibility: Ability to switch between services and resources.
- Automatic updates: Software and servers are automatically updated by the provider.
- Disaster recovery: Cloud provider has redundancy and backup in place for data protection.
- Accessibility: Access resources from anywhere via the Internet.
- Pay-as-you-go: Pay for only the resources used. No upfront capital investment in data centers.
