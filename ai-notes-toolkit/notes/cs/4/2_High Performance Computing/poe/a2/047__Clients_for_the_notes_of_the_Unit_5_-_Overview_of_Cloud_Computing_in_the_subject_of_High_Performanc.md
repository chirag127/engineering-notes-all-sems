### Clients for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

1. Web Browsers: Web browsers can be used to access the cloud services via web interfaces. Some cloud service providers have web-based consoles to manage the cloud resources.
2. Command Line Tools: Command line tools are available to interface with the cloud services to manage the resources programmatically. For example, Amazon provides the AWS CLI to manage Amazon Web Services from the command line.
3. Software Development Kits: SDKs are available for popular programming languages to access the cloud services and manage the resources through code. For example, Amazon provides SDKs for Java, Python, Node.js, C++, Ruby, etc. to access AWS services.
4. Mobile Apps: Mobile apps are available to manage and monitor the cloud resources via mobile devices. For example, Amazon provides the AWS Mobile Hub with pre-built features to add cloud capabilities to mobile apps.
