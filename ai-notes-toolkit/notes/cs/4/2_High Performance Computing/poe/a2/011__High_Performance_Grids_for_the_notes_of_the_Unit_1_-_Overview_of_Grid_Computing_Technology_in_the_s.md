### High‐Performance Grids

1. A grid is a type of distributed system that coordinates resources that are not subject to centralized control.
2. Grid computing combines computers from multiple administrative domains to reach a common goal.
3. The key characteristics of a grid are:
- Heterogeneity: Components are heterogeneous in terms of hardware, software, networking, and administration.
- Dynamism: The grid configuration changes dynamically. Resources may join or leave the grid at any time.
- Scalability: The grid should exhibit good scalability and performance as the number of resources and users increases.
- Locality: Computation and data are placed close to the resources that can serve them most efficiently.
4. The main components of a grid infrastructure are:
- Resources: The computing, storage, data, and application resources in the grid.
- Resource brokers: Match resources to requests based on policies.
- Monitoring and discovery service: Keeps track of available resources and their status.
- Authentication service: Verifies users’ identities and controls access to resources.
- Data management: Manages storage space, metadata, and movement of data.
- Communications: Allows components to interact and exchange information.
