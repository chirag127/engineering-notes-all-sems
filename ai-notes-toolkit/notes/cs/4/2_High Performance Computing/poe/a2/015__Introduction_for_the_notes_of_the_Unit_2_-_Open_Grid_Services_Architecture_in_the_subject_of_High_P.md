### Introduction for the notes of the Unit 2 - Open Grid Services Architecture

1. Open Grid Services Architecture (OGSA) - OGSA is a service-oriented architecture for distributed computing infrastructure like grids. It aims to standardize the structure and interactions of grid services to enable greater interoperability among grid systems.
2. Key features of OGSA -
    - Standard mechanisms for service creation, naming, discovery, and access.
    - Language and platform independence - Services can be implemented in any language and executed on any platform.
    - Open standards - Based on open protocols and interfaces like WS-*.
    - Service-oriented - Focuses on encapsulating functionality in services with formal interfaces.
    - Grid-enabled - Meets requirements like large-scale resource sharing, coordinating resources belonging to multiple organizations, etc.
3. Service statelessness - OGSA services strive to be stateless, that is, they do not store client state information between requests. Maintaining state introduces issues like scalability and fault-tolerance. However, some services may use conversational state or contextual state to improve performance.
4. Service activation and lifetime - Services in OGSA are activated on-demand and can be deactivated when not required. This on-demand activation of services and managing their lifetime improves resource utilization.
5. Service access - Standard mechanisms are defined in OGSA for service access using service handles, service data, and service state. Services can be accessed via open standard interfaces based on web services.
