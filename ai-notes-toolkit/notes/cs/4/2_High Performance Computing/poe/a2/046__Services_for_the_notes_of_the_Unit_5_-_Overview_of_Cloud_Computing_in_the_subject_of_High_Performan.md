### Services for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

1. Infrastructure as a Service (IaaS): Provides access to computing resources such as servers, storage, and networking. The consumer has the control over the underlying infrastructure but does not manage the infrastructure itself. e.g. AWS EC2, Azure Virtual Machines
2. Platform as a Service (PaaS): Provides a computing platform or environment to develop, run, and manage applications without the complexity of building and maintaining the infrastructure typically associated with developing and launching an app. e.g. AWS Elastic Beanstalk, Azure App Service
3. Software as a Service (SaaS): Provides access to applications/software as a service over the internet. The software is managed by the service provider. The consumer accesses the software but does not have control over the infrastructure or platform that it runs on. e.g. G Suite, Office 365, Salesforce
4. Function as a Service (FaaS): Enables developers to deploy single-purpose, programmatic functions that are executed on-demand. The service provider manages the infrastructure required to run the function. e.g. AWS Lambda, Azure Functions, Google Cloud Functions

The above points cover the key cloud computing services. The appropriate service can be selected based on the level of control and management required by the consumer as well as the use case.
