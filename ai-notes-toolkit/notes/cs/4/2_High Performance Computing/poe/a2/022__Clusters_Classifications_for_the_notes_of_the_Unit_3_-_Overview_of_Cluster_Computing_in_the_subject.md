### Clusters Classifications for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

1. According to Architecture
- Shared Memory Architecture: All nodes have access to shared memory.
- Distributed Memory Architecture: Each node has its own memory and processors can access memory of other nodes over network interconnect.
- Shared Disk Architecture: Nodes have their own memory but share storage (hard disks).

2. According to Purpose
- General Purpose Clusters: Used for a variety of applications.
- Special Purpose Clusters: Optimized for specific applications like molecular dynamics, fluid dynamics simulations, etc.

3. According to Ownership
- Dedicated Clusters: Owned and used by a single organization.
- Public or Open Clusters: Available for use by general public or a large research community.

4. According to Funding
- Institutional Clusters: Funded and maintained by schools, universities or research labs.
- Commercial Clusters: Funded and maintained by companies for commercial use.

The above points cover the major cluster classifications based on architecture, purpose, ownership and funding. Cluster computing is a key topic under high performance computing to understand distributed and parallel processing.
