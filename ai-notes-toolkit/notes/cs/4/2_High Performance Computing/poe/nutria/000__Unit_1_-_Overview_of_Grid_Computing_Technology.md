
## Unit 1 - Overview of Grid Computing Technology

* Grid computing is a type of distributed computing that enables the sharing of computing resources across multiple organizations and geographical locations. 
* It is a form of parallel computing that involves the use of multiple computers to solve a single problem. 
* Grid computing is typically used for high-performance computing (HPC) applications, such as scientific simulations and data analysis. 
* The grid computing model is based on the idea of connecting multiple computers to form a single, virtual computer. 
* Grid computing is a distributed computing model that allows users to access computing resources in a distributed environment. 
* It is a form of distributed computing that allows users to access computing resources from multiple geographically distributed locations. 
* Grid computing allows for the sharing of resources, such as memory, storage, and processing power, among multiple organizations and locations. 
* Grid computing can be used to achieve scalability, reliability, and cost-effectiveness. 
* Grid computing can be used to solve complex problems that require large amounts of computing power. 
* Grid computing can also be used to provide a secure environment for data sharing and collaboration.
