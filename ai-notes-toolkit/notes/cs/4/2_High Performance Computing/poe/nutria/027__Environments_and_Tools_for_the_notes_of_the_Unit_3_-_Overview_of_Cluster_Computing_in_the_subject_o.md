
### Environments and Tools for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

* Cluster computing is a distributed computing system that allows users to access a large number of computers and process data in parallel.
* Cluster computing systems are typically composed of multiple computers, each of which has its own memory and processing power.
* Cluster computing systems can be used to solve complex problems that require large amounts of processing power, such as big data analysis, scientific computing, and artificial intelligence applications.
* Cluster computing systems can also be used to provide high availability and scalability, which is important for mission-critical applications.
* A cluster computing system typically consists of a head node, which acts as the control center, and multiple compute nodes, which are used to perform the computations.
* The head node is responsible for managing the cluster, scheduling jobs, and monitoring the state of the system.
* Compute nodes are responsible for performing the actual computations.
* In order to use a cluster computing system, users need to install and configure a cluster management software package.
* Popular cluster management software packages include Apache Hadoop, Apache Spark, and Kubernetes.
* Users can also use tools such as Apache Ambari and Apache Mesos to manage their cluster computing systems.
