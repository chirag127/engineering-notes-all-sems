
### Storage for the Notes of Unit 5 - Overview of Cloud Computing in High Performance Computing

1. Cloud computing is a type of computing that involves the delivery of computing resources such as storage, applications, and processing power over the internet. It allows users to access these resources on demand, without having to purchase and maintain physical hardware.

2. Cloud storage is a form of remote storage that allows users to store, access, and share data over the internet. It provides users with the ability to store and access data from any location, eliminating the need to store it locally.

3. High performance computing (HPC) is a type of computing that uses special hardware and software to process large amounts of data quickly. It is used in scientific and engineering applications, where large amounts of data need to be processed in a short amount of time.

4. Cloud computing and HPC are often used together to provide users with the ability to access and process large amounts of data quickly. For example, HPC can be used to process large amounts of data in the cloud, allowing users to access and analyze data faster than would be possible with traditional computing resources.

5. Cloud computing and HPC also provide users with the ability to scale their computing resources as needed. This means that they can scale up their computing resources to meet the demands of their applications, without having to purchase and maintain additional physical hardware.
