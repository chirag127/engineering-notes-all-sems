
### Types of Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing 

1. **Desktop Grid**: A desktop grid is a type of distributed computing system that uses the resources of many personal computers connected by a local area network or the Internet. It is often used for scientific and research purposes. 

2. **Cluster Grid**: A cluster grid is a type of distributed computing system that uses the resources of many computers connected by a local area network or the Internet. It is often used for scientific and research purposes. 

3. **Volunteer Grid**: A volunteer grid is a type of distributed computing system that uses the resources of many volunteer computers connected by the Internet. It is often used for scientific and research purposes. 

4. **Grid Middleware**: Grid middleware is a type of software that enables the integration of distributed computing resources, such as desktop grids, cluster grids, and volunteer grids. It provides the necessary tools for the efficient management of these resources. 

5. **Grid Computing**: Grid computing is a type of distributed computing system that uses the resources of many computers connected by the Internet. It is often used for scientific and research purposes. It enables the sharing of resources, such as storage and processing power, across multiple computers. 

6. **Utility Computing**: Utility computing is a type of distributed computing system that uses the resources of many computers connected by the Internet. It is often used for commercial purposes. It enables the sharing of resources, such as storage and processing power, across multiple computers.
