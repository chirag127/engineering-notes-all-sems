
### Types of Cloud for the Notes of Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

1. Public Cloud: A public cloud is a cloud computing service that is made available to the public over the internet. These services are owned and operated by third-party cloud service providers, who deliver their computing resources like servers and storage over the internet.

2. Private Cloud: A private cloud is a cloud computing service that is hosted within a private network or data center. It is owned and operated by a single organization, and can be used to store and manage data.

3. Hybrid Cloud: A hybrid cloud is a combination of public and private cloud services. It allows organizations to store and manage data in both public and private clouds, and to move data between them.

4. Community Cloud: A community cloud is a cloud computing service that is shared by multiple organizations. It is hosted within a private network or data center, and is owned and operated by a group of organizations that have similar requirements.

5. Multi-Cloud: A multi-cloud is a cloud computing service that uses multiple cloud service providers. It allows organizations to store and manage data across multiple cloud providers, and to move data between them.
