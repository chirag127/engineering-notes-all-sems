
## Unit 2 - Open Grid Services Architecture

* Open Grid Services Architecture (OGSA) is a set of standards and specifications developed by the Global Grid Forum (GGF) to enable interoperability between different grid systems.
* OGSA is based on the concept of a service-oriented architecture (SOA) and provides an open, standards-based framework for distributed computing.
* OGSA defines a set of services and protocols that allow applications to access and share resources over a distributed network.
* OGSA includes a set of protocols for communication between services, such as the Grid Service Protocol (GSP) and the Grid Service Discovery Protocol (GSDP).
* OGSA also defines a set of services, such as the Grid Resource Allocation Service (GRAS), the Grid Security Service (GSS), and the Grid Metadata Service (GMS).
* OGSA provides a unified, distributed computing environment that allows applications to access and share resources across multiple platforms and organizations.
