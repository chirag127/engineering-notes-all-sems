
### High Performance Computing for the Notes of Unit 1 - Overview of Grid Computing Technology 

1. High Performance Computing (HPC) is a type of computing that uses advanced computer hardware, software, and algorithms to solve large and complex problems. 

2. Grid computing is a type of distributed computing that uses multiple computers connected to a network to share the workload of a complex task. 

3. Grid computing is often used to solve large-scale problems that require a lot of computing power, such as large-scale scientific simulations, data analysis, and machine learning.

4. Grid computing is composed of nodes, or computers, that are connected to a network and can communicate with each other.

5. The nodes are connected to a central server, which is responsible for managing the workload and distributing tasks to the nodes.

6. Grid computing is a cost-effective way to solve complex problems, as it allows the user to leverage the computing power of multiple computers.

7. Grid computing is also an efficient way to use computing power, as it allows the user to take advantage of the computing resources of multiple computers.

8. Grid computing is used in a variety of fields, from scientific research to business applications. 

9. Grid computing is a powerful tool for solving large and complex problems, and is becoming increasingly popular in the world of HPC.
