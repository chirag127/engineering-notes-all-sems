
### Cyber Infrastructure for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

1. Cyber infrastructure is a term used to describe the combination of hardware, software, networks, and services that support the delivery of cloud computing services.

2. Cloud computing is a model of computing where resources, such as software, applications, and data, are delivered over the internet, rather than stored on a local computer.

3. High Performance Computing (HPC) is a form of computing that uses a large number of processors to solve complex problems.

4. HPC systems are used in fields such as scientific research, engineering, and finance, as they allow for faster and more accurate calculations.

5. Cloud computing provides a cost-effective way to access and utilize HPC resources, as it allows organizations to rent computing resources from cloud providers.

6. Cloud providers offer a variety of services, such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).

7. IaaS is a cloud computing model that provides users with access to computing resources, such as physical servers, storage, and networking.

8. PaaS is a cloud computing model that provides users with access to a platform for developing, testing, and deploying applications.

9. SaaS is a cloud computing model that provides users with access to software applications that can be accessed over the internet.

10. Cloud computing can provide organizations with access to a variety of HPC resources, such as high-performance processors, large amounts of memory, and high-speed networks.
