## Unit 5 - Overview of Cloud Computing

Cloud computing is a model of providing computing services that include storage, processing power, and applications over the internet. In this unit, we will explore the different aspects of cloud computing, including the types of cloud, deployment models, and service models.

### Types of Cloud

1. Public Cloud - A public cloud is a cloud infrastructure that is available to the general public. The cloud vendor provides resources such as servers and storage, and customers can access these resources over the internet.

2. Private Cloud - A private cloud is a cloud infrastructure that is dedicated to a single organization. The organization may choose to manage the cloud infrastructure themselves or outsource it to a cloud vendor.

3. Hybrid Cloud - A hybrid cloud is a combination of public and private cloud infrastructure. Organizations can use a hybrid cloud to take advantage of the scalability and cost-effectiveness of public cloud while still maintaining control over critical data in a private cloud.

### Deployment Models

1. Infrastructure as a Service (IaaS) - In an IaaS model, the cloud vendor provides virtualized hardware such as servers, storage, and networking. Customers can use these resources to build their own applications and services.

2. Platform as a Service (PaaS) - In a PaaS model, the cloud vendor provides a platform for customers to build and deploy applications. The platform includes tools for development, testing, and deployment.

3. Software as a Service (SaaS) - In a SaaS model, the cloud vendor provides software applications to customers over the internet. Customers can access the software through a web browser or mobile application.
