### Cyber infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing.

Cloud computing is a model for enabling convenient, on-demand network access to a shared pool of configurable computing resources that can be rapidly provisioned and released with minimal management effort. It provides access to a large number of computing resources that can be accessed from anywhere in the world.

The cyber infrastructure for cloud computing includes the following components:

- **Hardware Infrastructure:** This includes servers, storage devices, networking equipment, and other physical resources that are used to provide computing services to users. The hardware infrastructure is typically owned and managed by cloud service providers.

- **Software Infrastructure:** This includes the operating systems, databases, middleware, and other software applications that are used to manage and run the hardware infrastructure. The software infrastructure is typically provided by the cloud service provider.

- **Virtualization Technology:** This technology enables the creation of virtual machines that can run on a physical server. Virtualization technology allows multiple virtual machines to run on a single physical server, which increases resource utilization and reduces cost.

- **Cloud Management Platform:** This platform provides the tools and services needed to manage and monitor cloud computing resources. It includes features such as resource provisioning, workload management, and security management.

- **Security Infrastructure:** Cloud computing requires robust security measures to protect sensitive data and prevent unauthorized access. The security infrastructure includes firewalls, intrusion detection systems, and other security tools.

- **Service Delivery Platform:** This platform provides the tools and services needed to deliver cloud computing services to end-users. It includes features such as self-service portals, billing systems, and customer support tools.

In conclusion, cyber infrastructure is a critical component of cloud computing. It provides the hardware, software, and security tools needed to deliver reliable and scalable computing services to users. By understanding the key components of cyber infrastructure, students can gain a better understanding of how cloud computing works and how it can be used to support high performance computing applications.
