## Unit 2 - Open Grid Services Architecture

- Open Grid Services Architecture (OGSA) is a set of standards that extends Web services and service-oriented architecture to the grid computing environment .
- Grid computing is the use of distributed and heterogeneous resources to solve large-scale problems that require high performance, availability, and scalability.
- OGSA defines a common framework for building, deploying, and managing grid services, which are Web services that support the dynamic and transient nature of grid resources .
- OGSA addresses key concerns in grid systems, such as security, discovery, data management, resource management, notification, and fault tolerance .
- OGSA uses most of Web service technologies, such as WSDL and SOAP, but it also defines new concepts and extensions, such as Grid Service, Grid Service Handle, Grid Service Reference, Service Data, and Factory .
- OGSA aims to be largely agnostic in relation to the transport-level handling of data upon the grid, and to support various types of resources, such as computational, storage, network, database, and application .
- OGSA is developed and maintained by the Open Grid Forum, which is an international community of researchers, developers, and users of grid technologies.
