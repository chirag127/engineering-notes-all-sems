# Internet Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Internet computing is the use of the internet as a platform for distributed computing, data processing, and communication across heterogeneous devices and networks.
- Grid computing is a form of internet computing that enables the sharing and coordination of resources across multiple organizations, domains, and locations, for solving large-scale problems that require high-performance computing (HPC).
- HPC is the ability to process data and perform complex calculations at high speeds, using parallel processing, distributed computing, and specialized hardware and software.
- Grid computing originated as a paradigm for HPC, as an alternative to expensive supercomputers, by harnessing the idle or underutilized resources of networked computers.
- Grid computing can be seen as a subset of cloud computing, which is another form of internet computing that provides on-demand access to scalable and elastic resources, such as servers, storage, and applications, over the internet.
- Grid computing differs from cloud computing in several aspects, such as:
  - Grid computing is more decentralized and heterogeneous, while cloud computing is more centralized and homogeneous.
  - Grid computing is more collaborative and cooperative, while cloud computing is more competitive and commercial.
  - Grid computing is more focused on scientific and academic applications, while cloud computing is more focused on business and consumer applications.
  - Grid computing is more concerned with performance and efficiency, while cloud computing is more concerned with availability and reliability.
- Grid computing can be classified into different types, such as:
  - Computational grid: A grid that provides access to distributed computing power for executing large-scale tasks, such as simulations, modeling, and analysis.
  - Data grid: A grid that provides access to distributed data sources and storage systems for managing and processing large volumes of data, such as databases, archives, and repositories.
  - Service grid: A grid that provides access to distributed services and applications for delivering functionality and value, such as web services, workflows, and software components.
  - Knowledge grid: A grid that provides access to distributed knowledge and information for supporting decision making and problem solving, such as ontologies, semantic web, and artificial intelligence.
