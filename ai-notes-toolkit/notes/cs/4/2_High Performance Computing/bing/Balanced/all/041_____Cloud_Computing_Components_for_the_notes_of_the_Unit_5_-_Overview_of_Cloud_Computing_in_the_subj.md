# Cloud Computing Components

Cloud computing is a model of delivering computing services over the internet, such as storage, processing, networking, software, and analytics. Cloud computing architecture refers to the components and subcomponents required for cloud computing. These components typically consist of a front end platform, a back end platform, a cloud based delivery, and a network.

Here are some important components of cloud computing architecture:

- **Client Infrastructure**: Client infrastructure is a front-end component that provides a graphical user interface (GUI) for the user to access the cloud services. The client infrastructure can be a fat client, a thin client, or a mobile device. A fat client is a device that has its own operating system and applications, such as a desktop or a laptop. A thin client is a device that relies on the cloud for most of its functionality, such as a web browser or a terminal. A mobile device is a device that can access the cloud services through a wireless network, such as a smartphone or a tablet.

- **Application**: The application is the software or platform that the user wants to access from the cloud. The application can be a web application, a mobile application, a desktop application, or a cloud-native application. A web application is a software that runs on a web browser and communicates with the cloud through the internet. A mobile application is a software that runs on a mobile device and communicates with the cloud through a wireless network. A desktop application is a software that runs on a fat client and communicates with the cloud through the internet. A cloud-native application is a software that is designed and developed for the cloud environment, using cloud services and features.

- **Service**: The service component manages the type of service that the user can access according to the client's requirements. There are three types of cloud computing service models: infrastructure as a service (IaaS), platform as a service (PaaS), and software as a service (SaaS). IaaS offers compute and storage services, such as virtual machines, containers, and databases. PaaS offers a develop-and-deploy environment to build cloud applications, such as frameworks, tools, and libraries. SaaS delivers applications as services, such as email, CRM, and ERP.

- **Runtime Cloud**: The runtime cloud component is the back-end component that executes the application logic and processes the user requests. The runtime cloud can be a single server, a cluster of servers, or a distributed system of servers. The runtime cloud can use different technologies and architectures, such as virtualization, containerization, microservices, and serverless computing. Virtualization is the partitioning of a single physical server into multiple logical servers. Containerization is the packaging of an application and its dependencies into a portable and isolated unit. Microservices is the design of an application as a collection of small and independent services. Serverless computing is the execution of an application without managing the underlying servers.

- **Storage**: The storage component is the back-end component that stores and retrieves the data for the application. The storage component can be a file system, a database, or an object store. A file system is a hierarchical structure of files and folders. A database is a structured collection of data that supports queries and transactions. An object store is a flat structure of data that supports metadata and scalability.

- **Infrastructure**: The infrastructure component is the physical or virtual hardware that supports the cloud computing services. The infrastructure component can be a server, a network device, a storage device, or a security device. A server is a computer that provides computing resources and services. A network device is a device that enables communication and connectivity between the servers and the clients, such as a router, a switch, or a firewall. A storage device is a device that stores and retrieves data, such as a disk, a tape, or a flash. A security device is a device that protects the cloud computing environment from unauthorized access and attacks, such as a VPN, an IDS, or an encryption device.

- **Management**: The management component is the component that monitors and controls the cloud computing services and resources. The management component can be a software, a tool, or a platform. A software is a program that performs a specific function, such as a hypervisor, a container engine, or a load balancer. A tool is a program that helps the user to perform a task, such as a dashboard, a console, or a CLI. A platform is a program that provides a set of features and capabilities, such as a cloud management platform, a cloud orchestration platform, or a cloud automation platform.
