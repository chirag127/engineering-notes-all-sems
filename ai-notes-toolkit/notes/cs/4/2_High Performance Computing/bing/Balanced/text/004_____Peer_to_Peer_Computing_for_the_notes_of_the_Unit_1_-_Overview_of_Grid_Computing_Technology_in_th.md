### Peer‐to‐Peer Computing

- Peer-to-peer (P2P) computing is a distributed application architecture that partitions tasks or workloads between peers.
- Peers are equally privileged, equipotent participants in the network. They are said to form a peer-to-peer network of nodes.
- In a P2P network, the peers are computer systems which are connected to each other via the Internet. Files can be shared directly between systems on the network without the need of a central server. In other words, each computer on a P2P network becomes a file server as well as a client.
- P2P computing enables each node to function as both a client and a server, and to initiate or respond to communication requests from other nodes.
- P2P computing can be used for various purposes, such as file sharing, distributed computing, collaborative work, content delivery, social networking, and communication.
- P2P computing has some advantages over the client-server model, such as scalability, fault tolerance, load balancing, resource utilization, and anonymity.
- P2P computing also has some challenges, such as security, privacy, quality of service, interoperability, and legal issues.
