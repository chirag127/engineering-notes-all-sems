### Services for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Cloud computing is the delivery of different services through the Internet, such as data storage, servers, databases, networking, software, analytics, and intelligence. Cloud computing services provide users with a series of functions, including:

- Email
- Storage, backup, and data retrieval
- Data analysis and processing
- Application development and testing
- Web hosting and content delivery
- Artificial intelligence and machine learning
- Security and compliance

There are different types of cloud computing services, depending on the level of abstraction and the degree of control that the user has over the resources. The main types are:

- Infrastructure as a Service (IaaS): This is the most basic type of cloud computing service, where the user can rent servers, storage, network, and operating systems from a cloud provider. The user has full control over the infrastructure and can install and run any software they want. The user only pays for the resources they use. Examples of IaaS providers are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform, and IBM Cloud .
- Platform as a Service (PaaS): This type of cloud computing service provides the user with a platform to develop, run, and manage applications without having to worry about the underlying infrastructure. The user can use the tools and frameworks provided by the cloud provider to create and deploy applications. The user only pays for the resources they use. Examples of PaaS providers are Google App Engine, Microsoft Azure App Service, AWS Elastic Beanstalk, and IBM Cloud Foundry .
- Software as a Service (SaaS): This type of cloud computing service delivers software applications over the Internet, usually through a web browser. The user does not have to install or maintain the software, and can access it from any device. The user only pays for the subscription or usage of the software. Examples of SaaS providers are Google Workspace, Microsoft Office 365, Salesforce, and Dropbox .
- Function as a Service (FaaS): This type of cloud computing service allows the user to run code snippets or functions in response to events or triggers, without having to manage servers or infrastructure. The user only pays for the execution time of the functions. Examples of FaaS providers are AWS Lambda, Google Cloud Functions, Microsoft Azure Functions, and IBM Cloud Functions .

Cloud computing services offer many benefits to users, such as:

- Scalability: Cloud computing services can scale up or down according to the demand and workload of the user, without requiring any upfront investment or planning.
- Cost-effectiveness: Cloud computing services can reduce the operational and capital expenses of the user, as they only pay for the resources they use, and do not have to buy or maintain hardware or software.
- Reliability: Cloud computing services can provide high availability and fault tolerance, as they have multiple redundant servers and data centers across the world, and can automatically recover from failures.
- Security: Cloud computing services can provide security and compliance features, such as encryption, authentication, authorization, auditing, and monitoring, to protect the user's data and applications from unauthorized access or attacks.
- Innovation: Cloud computing services can enable the user to access the latest technologies and tools, such as artificial intelligence, machine learning, big data, and IoT, and to create and deploy new and innovative applications faster and easier.
