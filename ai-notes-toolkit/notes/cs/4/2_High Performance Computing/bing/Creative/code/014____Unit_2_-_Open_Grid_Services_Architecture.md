## Unit 2 - Open Grid Services Architecture

- Open Grid Services Architecture (OGSA) is a set of standards that extends Web services and service-oriented architecture to the grid computing environment .
- Grid computing is the use of a large number of computers, often geographically distributed, to solve complex problems that require high performance, scalability, and reliability.
- OGSA was developed by the Open Grid Forum (OGF), formerly known as the Global Grid Forum (GGF), from 2002 to 2006.
- OGSA defines a common framework for building, deploying, and managing grid services, which are Web services that support the creation, discovery, monitoring, and management of distributed resources .
- OGSA specifies a core set of interfaces, behaviors, resource models, and bindings that enable interoperability and integration among heterogeneous grid systems.
- OGSA also defines a set of functional capabilities that address common grid requirements, such as security, data management, execution management, information management, and self-management.
- OGSA aims to provide a consistent and open way to access and share resources across different domains, platforms, and organizations .
- OGSA is not a specific implementation or product, but a reference architecture that guides the development of grid standards and technologies .
