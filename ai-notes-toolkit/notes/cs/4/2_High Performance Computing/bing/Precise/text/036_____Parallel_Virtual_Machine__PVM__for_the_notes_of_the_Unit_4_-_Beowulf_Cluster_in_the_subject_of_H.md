### Parallel Virtual Machine (PVM)

- PVM stands for Parallel Virtual Machine.
- It is a software package that permits a heterogeneous collection of Unix and/or Windows computers hooked together by a network to be used as a single large parallel computer.
- PVM is designed to allow a network of heterogeneous Unix and/or Windows machines to be used as a single distributed parallel processor.
- Large computational problems can be solved more cost-effectively by using the aggregate power and memory of many computers.
- PVM can be used as stand-alone software or as a foundation for other heterogeneous network software.
- In the PVM console, you can use commands to add machines to the parallel virtual machine, show all the machines of the parallel virtual machine, show all the running processes with their tids, and stop a running process.
