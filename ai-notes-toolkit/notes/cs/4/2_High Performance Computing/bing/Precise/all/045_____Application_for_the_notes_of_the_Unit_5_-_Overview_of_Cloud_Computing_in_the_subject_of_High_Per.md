# Unit 5 - Overview of Cloud Computing

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.

Here are some key points to note about cloud computing:

1. Cloud computing provides users with access to a wide range of computing resources, including processing power, storage, and software applications, without the need for them to own or manage these resources themselves.

2. Cloud computing is based on a pay-per-use model, where users only pay for the resources they actually use.

3. Cloud computing can be used to provide a wide range of services, including infrastructure as a service (IaaS), platform as a service (PaaS), and software as a service (SaaS).

4. Cloud computing can provide significant cost savings for users, as they do not need to invest in expensive hardware and software, and can scale their usage up or down as needed.

5. Cloud computing can also provide increased flexibility and agility for users, as they can quickly and easily access new resources and services as their needs change.

6. Cloud computing can be delivered through a variety of deployment models, including public, private, and hybrid clouds.

7. Cloud computing raises a number of security and privacy concerns, as users' data is stored and processed by third-party providers.

8. Cloud computing is a rapidly evolving field, with new technologies and services being developed and introduced on a regular basis.
