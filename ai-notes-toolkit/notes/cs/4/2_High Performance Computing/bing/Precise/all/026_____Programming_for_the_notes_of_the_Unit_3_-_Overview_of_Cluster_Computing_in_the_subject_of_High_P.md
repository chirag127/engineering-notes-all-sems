# Unit 3 - Overview of Cluster Computing

Cluster computing is a form of computing in which a group of computers are linked together so that they can act like a single entity. This is done in order to improve performance and/or availability of resources. Cluster computing is a popular choice for high performance computing (HPC) applications, as it allows for the use of commodity hardware to achieve high levels of performance.

Some key points to consider when discussing cluster computing include:

- Cluster computing involves linking together multiple computers, often using a high-speed network, in order to work together on a common task.
- Clusters can be used for a variety of purposes, including improving performance, increasing availability, and providing redundancy.
- Cluster computing is often used in HPC applications, where large amounts of computing power are required.
- Commodity hardware can be used to build clusters, making them a cost-effective solution for many organizations.
- Cluster management software is used to manage the resources of the cluster and to schedule jobs to run on the cluster.
- There are many different types of clusters, including Beowulf clusters, which are built using commodity hardware and open-source software, and high-availability clusters, which are designed to provide continuous availability of services.
