### Unit 5 - Overview of Cloud Computing

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.

1. **Characteristics of Cloud Computing:** Cloud computing has several essential characteristics, including on-demand self-service, broad network access, resource pooling, rapid elasticity, and measured service.

2. **Service Models:** Cloud computing offers three main service models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).

3. **Deployment Models:** There are four main deployment models for cloud computing: public cloud, private cloud, community cloud, and hybrid cloud.

4. **Benefits of Cloud Computing:** Cloud computing offers several benefits, including cost savings, scalability, flexibility, and improved collaboration.

5. **Challenges of Cloud Computing:** Despite its many benefits, cloud computing also presents several challenges, including security, privacy, and vendor lock-in.
