## Unit 5 - Cloud Technologies And Advancements Hadoop

Hadoop is an open-source software framework used for distributed storage and processing of large datasets on computer clusters. It is a part of the Apache project sponsored by the Apache Software Foundation.

### Advancements in Hadoop

1. Hadoop 3.0: It is the latest major version of Hadoop that was released in December 2017. It comes with many new features such as support for erasure coding, GPU acceleration, and containerization.

2. Hadoop YARN: YARN stands for Yet Another Resource Negotiator. It is a core component of Hadoop that separates the resource management and job scheduling/monitoring functions. This allows Hadoop to support multiple data processing engines such as Apache Spark, Apache Flink, and Apache Storm.

3. Hadoop Security: Hadoop has made significant improvements in the area of security in recent years. It provides various security features such as Kerberos authentication, Secure Socket Layer (SSL), and Access Control Lists (ACLs).

4. Hadoop in the Cloud: Hadoop can be deployed on various cloud platforms such as Amazon Web Services (AWS), Google Cloud Platform (GCP), and Microsoft Azure. This allows organizations to take advantage of the scalability and flexibility of the cloud while still using Hadoop for their data processing needs.

### Cloud Technologies in Hadoop

1. Infrastructure as a Service (IaaS): IaaS is a cloud computing model where the cloud provider offers virtualized computing resources such as servers, storage, and networking. Hadoop can be deployed on IaaS platforms such as AWS Elastic Compute Cloud (EC2) and Microsoft Azure Virtual Machines.

2. Platform as a Service (PaaS): PaaS is a cloud computing model where the cloud provider offers a platform for developers to build and deploy applications. Hadoop can be deployed on PaaS platforms such as Google Cloud Dataproc and Azure HDInsight.

3. Software as a Service (SaaS): SaaS is a cloud computing model where the cloud provider offers software applications that are accessed through the internet. Hadoop can be accessed through SaaS platforms such as Qubole and Cloudera Altus.

4. Hybrid Cloud: A hybrid cloud is a cloud computing environment that combines on-premises infrastructure with one or more cloud providers. Hadoop can be deployed in a hybrid cloud environment, allowing organizations to take advantage of both on-premises and cloud resources.

In conclusion, Hadoop is a powerful tool for processing large datasets, and advancements in Hadoop and cloud technologies have made it easier to deploy and manage Hadoop clusters. Organizations can take advantage of Hadoop's scalability and flexibility by deploying it on various cloud platforms or in a hybrid cloud environment.
