
### Open Stack for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

1. OpenStack is an open-source cloud computing platform that provides Infrastructure as a Service (IaaS). It is designed to be highly scalable and is used by organizations to build private, public, and hybrid clouds.

2. OpenStack consists of several components, each of which provides different services and features. These components include Compute, Object Storage, Block Storage, Networking, Image Service, and Identity Service.

3. OpenStack is designed to be highly extensible, allowing users to customize and extend its functionality. It also supports a wide range of operating systems, including Linux, Windows, and Mac OS X.

4. OpenStack is used by organizations to build private, public, and hybrid clouds. It can also be used to build and manage enterprise applications, including web-scale applications, databases, and analytics.

5. OpenStack is used in many industries, including government, finance, healthcare, education, and retail. It is also used by many organizations to build and manage their cloud infrastructures.
