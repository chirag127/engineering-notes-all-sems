
### Virtual Box for the Notes of the Unit 5 - Cloud Technologies and Advancements Hadoop in the Subject of Cloud Computing

* VirtualBox is a powerful x86 and AMD64/Intel64 virtualization product for enterprise as well as home use. 
* It allows users to run multiple operating systems on the same computer. 
* It supports a wide range of guest operating systems including but not limited to Windows (NT 4.0, 2000, XP, Server 2003, Vista, Windows 7, Windows 8, Windows 10), DOS/Windows 3.x, Linux (2.4, 2.6, 3.x and 4.x), Solaris and OpenSolaris, OS/2, and OpenBSD. 
* It also supports limited virtualization of macOS on Apple hardware. 
* It provides an interface for the user to control the guest operating system. 
* It is capable of running multiple virtual machines simultaneously. 
* It provides a virtual environment in which applications can be installed and run without affecting the host operating system. 
* It also supports the use of virtual hard disks and other virtual storage devices. 
* It can be used to run applications in a test environment without the risk of damaging the host operating system. 
* It is also used for software development and testing, as well as for running legacy applications on modern operating systems.
