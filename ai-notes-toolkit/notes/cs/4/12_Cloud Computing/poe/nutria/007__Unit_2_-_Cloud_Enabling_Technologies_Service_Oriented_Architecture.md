
## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

* Service Oriented Architecture (SOA) is an architectural pattern that enables the development of distributed applications that are based on the exchange of data between loosely coupled services.
* SOA is based on the concept of services, which are autonomous components that provide a specific function that can be accessed by other services. The services are connected through a common communication protocol, such as HTTP, and communicate using a standard message format, such as XML or JSON.
* The key benefits of SOA include improved scalability, flexibility, and maintainability of applications. By using SOA, applications can be built from loosely coupled services, which can be easily modified and replaced without impacting the entire system.
* SOA is also beneficial for cloud computing, as it allows applications to be built using cloud-based services. This allows applications to be deployed to multiple cloud environments and allows for a greater degree of scalability and flexibility.
* SOA also enables the development of applications that are more resilient to failure, as services can be easily replaced or modified without impacting the entire system. This makes applications more reliable and secure.
