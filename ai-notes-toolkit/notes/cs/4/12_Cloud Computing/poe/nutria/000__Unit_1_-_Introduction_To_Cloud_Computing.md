
## Unit 1 - Introduction To Cloud Computing

1. Cloud Computing is a type of computing that involves delivering computing services, such as data storage, software, databases, and networks, over the internet.

2. It is based on the concept of virtualization, which involves creating a virtual version of a physical computer or server.

3. Cloud Computing offers many advantages, such as cost savings, scalability, and increased productivity.

4. There are three main types of cloud services: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).

5. IaaS provides virtualized computing resources, such as servers, storage, and networking.

6. PaaS provides a platform for developing, testing, and deploying applications.

7. SaaS provides applications that are accessed over the internet.

8. Cloud Computing also provides many security benefits, including data encryption, identity and access management, and disaster recovery.
