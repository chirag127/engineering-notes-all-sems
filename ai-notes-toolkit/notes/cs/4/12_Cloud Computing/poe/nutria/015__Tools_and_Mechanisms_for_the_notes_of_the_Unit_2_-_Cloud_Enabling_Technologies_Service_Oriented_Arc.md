
### Tools and Mechanisms for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

* Service Oriented Architecture (SOA) is a software development methodology that enables applications to be built by combining loosely coupled, interoperable services. 
* SOA is based on the concept of service-oriented computing, which is a distributed computing approach that enables services to be exposed to the outside world. 
* SOA enables services to be accessed by other applications via standard protocols, such as HTTP, SOAP, and REST.
* SOA provides a platform for applications to communicate and share data, allowing them to be more easily integrated into existing systems.
* SOA also enables applications to be more easily scaled and managed, as services can be deployed independently.
* SOA enables applications to be more easily tested and maintained, as services can be tested and updated independently.
* SOA also enables applications to be more easily monitored, as services can be monitored independently.
