### Virtual Box for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

1. VirtualBox is a powerful x86 and AMD64/Intel64 virtualization product for enterprise as well as home use. Not only is VirtualBox an extremely feature rich, high performance product for enterprise customers, it is also the only professional solution that is freely available as Open Source Software under the terms of the GNU General Public License (GPL) version 2.

2. Some of the key benefits of VirtualBox are:
- Runs on a wide variety of host operating systems, including Linux, macOS, and Windows.
- Creates virtual machines with many guest operating systems, including but not limited to Windows, Linux, BSD, and OS/2.
- Freely available as Open Source Software.
- Enterprise-ready, being suitable for production deployments.
- High performance with guest machines often running at near-native speed.
- Supports a wide range of guest operating systems, including the latest versions of Windows and Linux, both as 32-bit and 64-bit guests.
- Compatible with many cloud infrastructures and management tools.
- Simple to deploy and get started. Create your first virtual machine within minutes.

3. Setting up Hadoop in VirtualBox:
- Download VirtualBox and install it.
- Download a Linux distribution and install it as a virtual machine in VirtualBox.
- Download Hadoop and unpack it.
- Configure Hadoop by editing the configuration files.
- Start Hadoop.
- Access the Hadoop web interfaces to monitor the cluster.
- You can now run Hadoop jobs on your virtual cluster.
