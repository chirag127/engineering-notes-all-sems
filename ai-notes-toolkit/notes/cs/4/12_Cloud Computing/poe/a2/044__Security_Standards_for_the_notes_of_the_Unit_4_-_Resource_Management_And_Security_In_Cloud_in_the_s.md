### Security Standards for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

1. Infrastructure security: This includes security of the underlying hardware, networks, and software that make up the cloud infrastructure. The cloud provider must ensure that the infrastructure is protected from external and internal threats. This includes protection from DDoS attacks, account hijacking, and man-in-the-middle attacks.

2. Data protection: The cloud provider must ensure that customer data is protected. This includes encryption of data in transit and at rest, access control mechanisms, and ensuring that only authorized individuals can access sensitive data. Compliance with regulations such as HIPAA and GDPR may also be necessary.

3. Identity and access management: Strong authentication and access control mechanisms must be in place to ensure that only legitimate users can access the cloud infrastructure and applications. This includes protection against account hijacking and unauthorized access.

4. Application security: Cloud-based applications must be designed and developed securely. This includes input validation, authentication, access control, and other application security best practices. The cloud provider may provide additional application scanning and security testing tools.

5. Governance and compliance: The cloud provider must implement strong governance mechanisms to ensure compliance with security standards and regulations. This includes having clear policies, controls, and audit mechanisms to validate security and compliance. Proper reporting mechanisms must also be in place.
