### Virtualization of CPU for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1.  CPU virtualization is a technique where a single physical CPU is presented as multiple virtual CPUs. Each virtual CPU executes instructions as if it were physically present.
2.  The hypervisor or virtual machine monitor is software, firmware or hardware that creates and runs virtual machines. It is responsible for allocating available resources to virtual machines and scheduling the execution of virtual CPUs.
3.  The hypervisor presents a virtual operating system with a set of virtual resources and executes it like a physical system. The guest OS hence runs in complete isolation and is unaware of other virtual machines on the system.
4.  There are two types of hypervisors - Type 1 or bare metal hypervisors run directly on the host machine hardware to control the hardware and manage guest VMs. Type 2 or hosted hypervisors run within a conventional OS environment.
5.  Benefits of CPU virtualization include increased utilization, isolation, flexibility and agility. Multiple VMs can share the resources of a single physical CPU resulting in lower costs and environmental footprint. Workloads can be isolated and migrated easily for performance, security or management.
