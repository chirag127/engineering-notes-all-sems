### S3 for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

1. S3 stands for Simple Storage Service. It is a storage service provided by Amazon Web Services (AWS).
2. It is an object storage built to store and retrieve any amount of data from anywhere on the internet.
3. The data in S3 is stored in buckets. A bucket is a container for objects (files). Each bucket has a global namespace.
4. Objects stored in S3 can range from 0 Bytes to 5 TB in size. There is no limit on the number of objects stored in a bucket.
5. S3 provides 99.999999999% durability and 99.99% availability of objects over a given year. It is designed to be highly fault tolerant and scalable.
6. S3 offers high performance, low latency, and high throughput. It can support peak loads of high requests. Data transfer and access can be controlled with Tiers.
7. S3 provides secure authentication and authorization capabilities. It supports access control lists (ACLs) and bucket policies to manage data access and integrates with AWS identity and access management (IAM) to control access to buckets and objects.
8. S3 supports features like versioning, replication, encryption, and lifecycle management which makes it suitable for various use cases like data archiving, security and compliance, content management, static website hosting, big data analytics, machine learning, etc.
9. S3 has a simple web service interface that can be used to store and retrieve any amount of data, at any time, from anywhere on the web. It is Cost-effective and highly scalable.
