### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud

1. Define security governance: Security governance refers to the set of practices, policies, standards, and processes that ensure the effective management of security and compliance risks to meet an organization's information security objectives. It includes the processes for planning, designing, implementing, monitoring, and management of information security programs.

2. Importance of security governance:
- Ensures security compliance with regulations and laws like GDPR, HIPAA, etc.
- Provides oversight and management of security controls and activities.
- Handles security risks and vulnerabilities in a systematic manner.
- Facilitates decision making regarding security investments and resource allocation.
- Communicates security objectives and responsibilities to stakeholders.

3. Components of security governance:
- Policies: Documented statements that define rules, responsibilities and expected behavior.
- Standards: Documented agreements on norms, procedures and requirements.
- Processes: Documented sets of activities and tasks to achieve specific objectives.
- Framework: Structured sets of concepts, principles, practices and processes.
- Reporting: Regular status updates on security metrics, compliance, issues, etc.
- Oversight: Independent review of the effectiveness of security governance.

4. Security governance in cloud:
- Understand shared security model and security responsibilities of cloud providers and enterprises.
- Ensure visibility into the security controls and activities of the cloud provider.
- Apply own security governance practices for the enterprise's cloud resources and data.
- Leverage cloud security certifications and accreditations to evaluate cloud provider's security.
- Continuously monitor cloud security and compliance and take necessary actions.
