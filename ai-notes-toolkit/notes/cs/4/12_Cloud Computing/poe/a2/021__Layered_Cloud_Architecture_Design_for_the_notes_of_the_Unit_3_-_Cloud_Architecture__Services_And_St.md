### Layered Cloud Architecture Design

1. Infrastructure as a Service (IaaS): This is the lowest level service model in cloud computing. It provides the basic building blocks for cloud IT which includes networking, storage, servers, and virtualization. The consumer has the control over the infrastructure but does not manage the underlying hardware. Example: Amazon EC2, Microsoft Azure Virtual Machines, etc.

2. Platform as a Service (PaaS): This is the middle layer which provides the platform to develop, run, and manage applications without the complexity of maintaining the infrastructure. The consumer has control over the deployed applications and application hosting environment settings but does not have access to the underlying infrastructure. Example: AWS Elastic Beanstalk, Azure App Service, etc.

3. Software as a Service (SaaS): This is the topmost layer which provides the cloud-based end-user applications. The applications are accessed from various devices through a thin client interface such as a web browser. The customer does not have any control over the infrastructure or platforms. Example: G Suite, Office 365, Salesforce, etc.

This three-layer architecture enables the separation of concerns and increases the portability, interoperability, and reusability of the resources. The layers can be used independently or in combination based on the requirements of the use cases.
