### Cloud Storage for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

1.  Object Storage - Data is stored as objects with an ID, metadata and content. Scales to exabytes. Used for unstructured data like images, videos, log files, backups, etc. Examples - AWS S3, Azure Blob Storage, Google Cloud Storage.
2.  File Storage - Data is stored in a hierarchical file system. Used for storing files and data that require a file system interface. Examples - AWS EFS, Azure Files, Google Cloud Filestore.
3.  Block Storage - Data is stored in blocks andaccessed via block devices. Used for storing data of databases, VMs, etc. Examples - AWS EBS, Azure Disks, Google Cloud Persistent Disks.
4.  Archival Storage - Used for archiving rarely accessed data at lower costs. Examples - AWS Glacier, Azure Archive Storage.

The advantages of cloud storage are scalability, durability, high availability, low cost, and connectivity across regions and zones. The type of storage to use depends upon the use case in terms of structure, frequency of access, latency and throughput requirements, etc. The cloud providers offer various storage options with different characteristics at different price points to suit diverse needs.
