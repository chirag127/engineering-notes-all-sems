### Cloud Storage Providers for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

1. Amazon S3:
- Object storage built to store and retrieve any amount of data from anywhere
- Scalable, high performance, secure and durable
- Data is stored in Buckets
- Access via SDK, CLI or Web interface
- Useful for storing static content, backups, archives, analytics data etc.

2. Microsoft Azure Blob Storage:
- Object storage for cloud based storage of large amounts of unstructured data
- Scales to meet storage needs and offers high availability and durability
- Data stored in containers
- Access via SDK, CLI or web interface
- Useful for similar use cases as S3

3. Google Cloud Storage:
- Unified object storage built to store and scale data for cloud based applications
- Highly durable, scalable and secure
- Data stored in Buckets
- Access via SDK, CLI or web interface
- Use cases are similar to S3 and Blob Storage
