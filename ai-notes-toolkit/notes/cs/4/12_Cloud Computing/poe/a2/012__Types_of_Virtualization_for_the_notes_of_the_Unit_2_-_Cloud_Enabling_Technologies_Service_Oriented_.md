### Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1. Full Virtualization: Complete simulation of the physical machine. Guest OS is unaware of being virtualized. Examples: VMware, VirtualBox.
2. Para-virtualization: Guest OS is modified to be Virtualization-aware to achieve near-native performance. Example: Xen.
3. OS-level Virtualization: Multiple isolated user-space instances are virtualized on a single kernel. Examples: Docker, LXC.
4. Application Virtualization: Application is virtualized and isolated from the underlying OS. Examples: Microsoft App-V, VMware ThinApp.

The goal of the notes is to provide formal study material to learn and understand Types of Virtualization for the Cloud Computing course.
