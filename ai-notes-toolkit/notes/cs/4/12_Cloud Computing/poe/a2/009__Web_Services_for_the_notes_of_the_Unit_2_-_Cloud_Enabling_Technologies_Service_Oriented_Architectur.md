### Web Services for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1. Web Services are self-contained, self-describing, modular applications that can be published, located, and invoked over a network, typically the Internet.
2. Web Services are built on open standards and can be accessed by any application or system regardless of the platform or programming language.
3. The key components of a Web Service include:
- An interface described in a machine-processable format (WSDL)
- Messages that are exchanged using a protocol (SOAP)
- Description of the data being exchanged (XML Schema)
4. The main benefits of Web Services include:
- Language and platform independence
- Interoperability and integration
- Reusability
- Flexibility
5. The key enabling technologies for Web Services are:
- XML: For describing data and messaging
- SOAP: For messaging
- WSDL: For describing interfaces
- UDDI: For discovery
6. The key standards organizations for Web Services include:
- W3C: For XML, XML Schema, SOAP
- OASIS: For WSDL, BPEL
- IETF: For XML-RPC, SOAP
