### Storage‐as‐a‐Service for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

1. Storage as a Service (STaaS) is a cloud-based storage model in which the cloud provider owns and maintains the hardware and software infrastructure required for the storage and the customer pays for the storage capacity and usage.
2. The key benefits of STaaS are:
- Scalability and elasticity: Storage capacity can be easily scaled up or down as per the customer's requirements.
- Pay-as-you-go model: Customers pay only for the storage capacity and usage.
- Reduced management overhead: The cloud provider manages the underlying hardware, software, security patches, data replication, etc. The customer does not have to manage the infrastructure.
3. The different types of STaaS are:
- Object storage: Stores data as objects with an identifier (name) to retrieve the data. It can store huge amounts of unstructured data.
- Block storage: Provides access to raw block-level storage volumes that can be attached to cloud-based virtual machines. It can be used like a traditional hard disk.
- File storage: Provides a file system interface and can be mounted to cloud-based virtual machines. It is suited for storing structured data.
