### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1.  Hypervisor - A hypervisor is a software that creates and runs virtual machines. It allows one host machine to support multiple guest virtual machines by sharing its resources. The two types of hypervisors are:
    -   Type 1/Bare-metal hypervisor - Runs directly on the host machine hardware and controls the hardware. Ex - VMWare ESXi, Microsoft Hyper-V.
    -   Type 2/Hosted hypervisor - Runs on a host operating system as an application and the host OS interacts with the hardware and the hypervisor interacts with the host OS. Ex - VirtualBox, VMWare Workstation.

2.  Virtual Machine (VM) - A virtual machine is a software-based computer that executes programs like a physical computer. It has its own virtual hardware like CPU, memory, storage, and network interfaces. Multiple VMs can run on the same physical machine and share the resources. The VM is isolated from the host system and other VMs.

3.  Virtualization - Virtualization is a technology that creates virtual versions of devices or resources, such as a server, storage device, network, etc. The virtual resources can be used just like their physical counterparts but are more efficient and flexible. The two main types of virtualization are:
    -   Server virtualization - Multiple virtual servers run on a single physical server.
    -   Network virtualization - Combines hardware and software resources and network services into a single, software-based administrative entity.
