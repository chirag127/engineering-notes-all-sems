### Tools and Mechanisms for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing:

1. Web Services:
- Web services are self-contained, self-describing, modular applications that can be discovered and accessed over a network, such as the Internet, and executed on a remote system hosting the requested services.
- Three major types are SOAP, REST and XML-RPC.

2. Service Oriented Architecture (SOA):
- A collection of services which communicate with each other. The communication comprises of data exchange in the form of messages.
- Services are built as independent components which can be reused across multiple applications.
- Services communicate with each other using APIs and service interfaces.

3. Message Queueing/Message Oriented Middleware:
- Messages are queued and distributed between applications through asynchronous messaging.
- Messages are stored temporarily in a queue and processed as and when the application is ready to consume them.
- It enables decoupling of applications and asynchronous processing. e.g. Apache Kafka, RabbitMQ, etc.

4. API Management:
- APIs or Application Programming Interfaces act as an interface for applications to interact with each other.
- API Management tools allow publishing, documenting and overseeing APIs.
- Key functions include access control, rate limiting, analytics, developer portals, etc. e.g. Apigee, AWS API Gateway, etc.
