### Cloud Security Challenges

1. Data Breaches: Storing data on the cloud makes it vulnerable to breaches and leaks. There is a risk of unauthorized access to sensitive data by hackers.
2. Account Hacking: Cloud accounts can be hacked if passwords are weak or stolen. This can lead to compromisation of data, resources, and accounts.
3. Insider Threats: Cloud admins or other insiders can misuse their access to data and resources. This can be avoided through authorization controls and surveillance.
4. Shared Technology Issues: The underlying infrastructure is shared across users in the cloud. This can make a customer's data and resources vulnerable to threats targeting other users on the shared infrastructure.
5. Compliance: Meeting compliance requirements like data location, security controls, etc. can be challenging in the cloud.The cloud customer needs to ensure compliance to regulations.
6. Vendor Lock-In: It can be difficult to port data and applications from one cloud provider to another. This can create dependence on the cloud provider and affect pricing and terms.
7. Management Complexity: Managing cloud resources and security can be quite complex due to the scale and distributed nature of cloud computing. This requires continuous monitoring and management.
