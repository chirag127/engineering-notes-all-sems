## Unit 1 - Introduction To Cloud Computing

1. Cloud Computing: Cloud computing refers to the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.

2. Benefits of Cloud Computing:
 - Increased Agility: Cloud computing increases the agility of an organization since resources can be easily provisioned and de-provisioned on demand.
 - Lower Costs: Cloud computing reduces the costs for organizations as they only pay for the resources they use. There are no upfront infrastructure costs.
 - Easy Access: Cloud computing provides easy access to resources from any location via the Internet.
 - Scalability: It is easy to scale resources up or down as per demand in cloud computing. This makes it a great fit for organizations with dynamic workload requirements.
 - Reliability: Cloud computing offers high reliability as the infrastructure is robust and monitored 24/7 by experts. Data is also backed up and replicated regularly.

3. Service Models: The three main service models of cloud computing are:
 - Infrastructure as a Service (IaaS): Provides access to computing resources such as servers, storage, and networking. The user has administrative access over the infrastructure.
 - Platform as a Service (PaaS): Provides a computing platform such as an operating system, programming language execution environment, database, etc. The user does not have administrative access over the infrastructure.
 - Software as a Service (SaaS): Provides access to applications that are run on cloud infrastructure. The user does not have administrative access over the platform or infrastructure.

4. Deployment Models: The two main deployment models of cloud computing are:
 - Public Cloud: In a public cloud, the infrastructure is owned and operated by a third-party cloud service provider and made available to the general public over the internet.
 - Private Cloud: In a private cloud, the infrastructure is operated solely for a single organization. It may be managed internally or by a third-party and located on-premises or off-premises.
