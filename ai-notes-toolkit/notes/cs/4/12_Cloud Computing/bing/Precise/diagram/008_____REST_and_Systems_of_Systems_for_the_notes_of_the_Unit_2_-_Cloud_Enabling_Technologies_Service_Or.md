### REST and Systems of Systems for Cloud Enabling Technologies Service Oriented Architecture

- REST (Representational State Transfer) is an architectural style for building web services.
- RESTful web services are based on lightweight HTTP methods and have largely superseded WS*-style services because of their relative simplicity.
- Service-Oriented Architecture (SOA) is a method of software development that uses software components called services to create business applications.
- Each service provides a business capability, and services can communicate with each other across platforms and languages.
- SOA supports scenarios for application integration, data integration, and service orchestration style automation of business processes or workflows.
- This speeds up software design and development by enabling developers to spend less time integrating and more time focusing on other tasks.
- REST APIs can be used to publish or consume application data and logic from anywhere, to anywhere, on any platform.
- Systems of Systems refers to the integration of multiple independent systems to achieve a larger, more complex system.
- In the context of Cloud Enabling Technologies and SOA, Systems of Systems can refer to the integration of multiple services to achieve a larger, more complex application or system.
