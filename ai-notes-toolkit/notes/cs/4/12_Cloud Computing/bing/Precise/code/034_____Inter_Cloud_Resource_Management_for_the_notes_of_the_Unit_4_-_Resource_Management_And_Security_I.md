### Inter Cloud Resource Management

Inter-Cloud Resource Management refers to the management of resources across multiple cloud infrastructures. A cloud’s infrastructure’s processing and storage capacity could be exhausted. In such cases, combining numerous various separate clouds into a single fluid mass for on-demand operations can be helpful.

There are several types of Inter-Cloud Resource Management, including:
- **Federation Clouds**: A federation cloud is a kind of inter-cloud where several cloud service providers willingly link their cloud infrastructures together to exchange resources. Cloud service providers in the federation trade resources in an open manner.
- **Multi-Cloud Libraries**: Clients use a uniform cloud API as a library to create their own brokers. Inter clouds that employ libraries make it easier to use clouds consistently.

The inter-cloud initiatives OPTIMUS, contrail, MOSAIC, STRATOS, and commercial cloud management solutions leverage multi-cloud services.

Resource management is one of the key concerns to be addressed in Intercloud computing. To organize your resources, define a management group hierarchy, consider and follow a naming convention, and apply resource tagging. Management levels and hierarchy Azure provides four levels of management: management groups, subscriptions, resource groups, and resources.
