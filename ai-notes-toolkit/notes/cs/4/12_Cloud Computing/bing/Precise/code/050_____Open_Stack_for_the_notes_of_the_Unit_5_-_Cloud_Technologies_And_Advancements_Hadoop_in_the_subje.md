### Open Stack

OpenStack is an open-source cloud operating system that controls large pools of compute, storage, and networking resources throughout a datacenter. These resources are managed and provisioned through APIs with common authentication mechanisms. A dashboard is also available, giving administrators control while empowering their users to provision resources through a web interface.

- OpenStack is open-source and free software.
- It is used for cloud computing and deployed as an Infrastructure as a Service (IaaS).
- It is one of the three most active open source projects in the world.
- OpenStack is developed by the community, for the community.
