# Unit 4 - Resource Management And Security In Cloud

## Resource Management in Cloud
- Resource management in cloud is the process of allocating, monitoring, and optimizing the use of cloud resources such as compute, storage, network, and applications.
- Resource management in cloud aims to achieve the following objectives:
  - Maximize the performance and availability of cloud services and applications.
  - Minimize the cost and waste of cloud resources.
  - Ensure the compliance and security of cloud resources.
- Resource management in cloud involves the following tasks:
  - Resource provisioning: The process of creating, configuring, and deploying cloud resources according to the user's requirements and specifications.
  - Resource scaling: The process of adjusting the capacity and performance of cloud resources according to the changing workload and demand.
  - Resource monitoring: The process of collecting, analyzing, and reporting the metrics and status of cloud resources such as utilization, performance, availability, and health.
  - Resource optimization: The process of applying policies, rules, and algorithms to improve the efficiency and effectiveness of cloud resources such as load balancing, auto-scaling, and resource pooling.
  - Resource governance: The process of defining, enforcing, and auditing the policies, standards, and best practices for cloud resource management such as access control, security, compliance, and quality of service.

## Security in Cloud
- Security in cloud is the process of protecting the confidentiality, integrity, and availability of cloud resources, data, and applications from unauthorized access, modification, or destruction.
- Security in cloud aims to achieve the following objectives:
  - Prevent and mitigate the risks and threats of cyberattacks, data breaches, and malicious insiders.
  - Ensure the compliance and accountability of cloud providers and users with the relevant laws, regulations, and standards.
  - Enhance the trust and confidence of cloud users and customers in the cloud services and applications.
- Security in cloud involves the following tasks:
  - Security assessment: The process of identifying and evaluating the security risks and vulnerabilities of cloud resources, data, and applications.
  - Security design: The process of applying the security principles and best practices to the architecture and configuration of cloud resources, data, and applications.
  - Security implementation: The process of deploying and integrating the security tools and controls to the cloud resources, data, and applications such as encryption, authentication, authorization, firewall, antivirus, and intrusion detection and prevention systems.
  - Security monitoring: The process of collecting, analyzing, and reporting the security events and incidents of cloud resources, data, and applications such as logs, alerts, and audits.
  - Security response: The process of responding and recovering from the security events and incidents of cloud resources, data, and applications such as incident management, forensics, and remediation.
