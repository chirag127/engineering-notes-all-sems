## Unit 3 - Cloud Architecture, Services and Storage

- Cloud architecture is the way technology components combine to build a cloud, in which resources are pooled through virtualization technology and shared across a network.
- Cloud architecture consists of a front-end platform (the client or device used to access the cloud), a back-end platform (servers and storage), a cloud-based delivery model (software as a service, platform as a service, or infrastructure as a service), and a network (internet or intranet).
- Cloud services are the on-demand delivery of IT resources and applications via the internet with pay-as-you-go pricing. Cloud services can provide various benefits such as scalability, reliability, security, and cost-efficiency.
- Cloud services can be categorized into three main types: software as a service (SaaS), platform as a service (PaaS), and infrastructure as a service (IaaS).
  - SaaS is a software delivery model that provides access to cloud-based applications over the internet, without the need for installation, maintenance, or management of the software by the user. Examples of SaaS are email, online office tools, CRM, and ERP systems.
  - PaaS is a cloud computing environment that provides a platform for developing, testing, deploying, and managing applications without the need for managing the underlying infrastructure, such as servers, storage, network, and operating systems. Examples of PaaS are web hosting, database management, and analytics services.
  - IaaS is a cloud computing service that provides access to computing resources, such as servers, storage, network, and virtualization, over the internet, without the need for purchasing, installing, or maintaining the hardware. Examples of IaaS are virtual machines, containers, and storage services.
- Cloud storage is a service that allows users to store and access data on remote servers over the internet, instead of on local devices or on-premises servers. Cloud storage can offer advantages such as scalability, durability, availability, and cost-effectiveness.
- Cloud storage can be classified into four types: object storage, file storage, block storage, and hybrid storage.
  - Object storage is a service that stores data as objects, which consist of data, metadata, and a unique identifier. Object storage is suitable for storing unstructured or semi-structured data, such as images, videos, documents, and logs. Examples of object storage are Azure Blob Storage and Amazon S3 .
  - File storage is a service that stores data as files in a hierarchical structure, similar to a traditional file system. File storage is suitable for storing structured or semi-structured data, such as spreadsheets, databases, and configuration files. Examples of file storage are Azure Files and Amazon EFS .
  - Block storage is a service that stores data as blocks of fixed size, which are assigned to a unique address. Block storage is suitable for storing low-latency, high-performance data, such as operating systems, applications, and databases. Examples of block storage are Azure Disk Storage and Amazon EBS .
  - Hybrid storage is a service that combines the features of object storage and file storage, and provides a unified interface for accessing both types of data. Hybrid storage is suitable for storing big data analytics, such as data lakes. An example of hybrid storage is Azure Data Lake Storage Gen2.
