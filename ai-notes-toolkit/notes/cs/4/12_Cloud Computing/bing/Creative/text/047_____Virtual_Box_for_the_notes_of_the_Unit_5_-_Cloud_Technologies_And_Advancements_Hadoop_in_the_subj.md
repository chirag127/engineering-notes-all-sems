### Virtual Box for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- VirtualBox is a hosted hypervisor that allows users to create and run virtual machines (VMs) on a single physical machine.
- VirtualBox can be used for cloud computing as it enables users to deploy applications on different operating systems and platforms without modifying the code or configuration .
- VirtualBox supports various operating systems such as Windows, Linux, Mac OS X, Solaris, and FreeBSD as both hosts and guests.
- VirtualBox uses application programming interface (API) and software development kit (SDK) to manage the following aspects of virtualization:
  - Creation, deletion, and cloning of VMs
  - Configuration and control of VMs
  - Networking and storage of VMs
  - Snapshot and restore of VMs
  - Import and export of VMs
- VirtualBox secures remote connections to restricted applications via 256-bit encryption keys, and ensures users cannot download or store data on remote devices.
- VirtualBox can be integrated with other cloud services such as Oracle Cloud Infrastructure, Amazon Web Services, and Microsoft Azure to extend the functionality and scalability of VMs.
- VirtualBox can be used to run Hadoop, a framework for distributed processing of large data sets, on a single machine or a cluster of machines.
  - Hadoop consists of two main components: Hadoop Distributed File System (HDFS) and Hadoop MapReduce.
  - HDFS is a distributed file system that stores data across multiple nodes and provides fault tolerance and high availability.
  - MapReduce is a programming model that divides a large task into smaller subtasks and distributes them to multiple nodes for parallel processing.
  - VirtualBox can be used to create a Hadoop cluster with multiple VMs, each running a different role such as NameNode, DataNode, JobTracker, or TaskTracker.
  - VirtualBox can also be used to create a pseudo-distributed Hadoop cluster with a single VM, where all the roles are run on the same node.
  - VirtualBox can help users to learn and experiment with Hadoop without investing in expensive hardware or cloud resources.
