### On‐demand Provisioning

- On-demand provisioning is a feature of cloud computing that allows users to access and allocate cloud resources as and when they need them, without requiring human intervention or long-term commitment .
- On-demand provisioning enables cloud users to scale up or down their computing resources dynamically, depending on their workload and demand.
- On-demand provisioning also reduces the cost and complexity of managing cloud resources, as users only pay for what they use and do not have to worry about over-provisioning or under-provisioning.
- On-demand provisioning can be implemented in different ways, depending on the cloud service model and the cloud provider. Some examples are:
  - On-demand self-service: Users can provision cloud resources such as servers, storage, network, or applications through a web-based portal or an API, without requiring any approval or assistance from the cloud provider .
  - On-demand resource provisioning: Cloud providers can provision cloud resources for users based on their estimated or actual load, using algorithms or policies to optimize the resource utilization and performance of the cloud.
  - On-demand provisioning in Azure Active Directory: Users can provision user accounts and groups from an external identity source to Azure AD, using a manual or scheduled process, or by triggering a provisioning request on demand .
- On-demand provisioning is one of the essential characteristics of cloud computing, as defined by the National Institute of Standards and Technology (NIST). It enables cloud users to have greater flexibility, agility, and efficiency in using cloud services.
