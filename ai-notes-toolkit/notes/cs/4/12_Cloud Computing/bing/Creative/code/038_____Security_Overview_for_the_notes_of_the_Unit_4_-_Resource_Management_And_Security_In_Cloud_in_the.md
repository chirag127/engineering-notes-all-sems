### Security Overview

Cloud security is the collection of procedures and technology designed to address external and internal threats to business security in the cloud computing environment. Cloud security encompasses three core capabilities: confidentiality, integrity, and availability .

- Confidentiality is the ability to keep information secret from people who shouldn't have access. This can be achieved by encryption, access control, authentication, and auditing.
- Integrity means that systems operate as they are intended to function and produce outputs that are not unexpected or misleading. This can be achieved by data validation, checksums, digital signatures, and backups.
- Availability means that systems and data are accessible and usable by authorized users when needed. This can be achieved by redundancy, load balancing, disaster recovery, and monitoring.

Cloud security also involves the following aspects :

- Compliance: ensuring that the cloud service provider and the cloud customer adhere to the relevant laws, regulations, standards, and policies that govern their operations and data protection.
- Governance: establishing the roles, responsibilities, policies, and procedures that define how the cloud service provider and the cloud customer manage and control their cloud resources and services.
- Risk management: identifying, assessing, and mitigating the potential threats and vulnerabilities that may affect the cloud environment and the data stored or processed in it.
- Identity and access management: managing the identities and credentials of the users and devices that access the cloud services and resources, and enforcing the appropriate level of authorization and authentication.
- Data security: protecting the data stored or processed in the cloud from unauthorized access, modification, deletion, or leakage, using encryption, masking, tokenization, or other techniques.
- Network security: securing the communication channels and network infrastructure that connect the cloud service provider and the cloud customer, and preventing attacks such as denial-of-service, spoofing, or interception.
- Application security: securing the software applications that run on the cloud platform or use the cloud services, and preventing attacks such as injection, cross-site scripting, or broken authentication.
