### Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the process of creating a virtual representation of physical resources, such as servers, storage, network, and applications, in order to optimize the utilization and management of IT resources. Virtualization enables the creation of multiple virtual machines (VMs) that run on the same physical hardware, each with its own operating system and applications. Virtualization also allows the abstraction and pooling of physical resources, such as storage and network devices, and the provision of these resources to VMs on demand.

There are different types of virtualization, especially in the context of cloud computing. They are:

- **Server virtualization**: Server virtualization is the process of partitioning a physical server into multiple virtual servers, each with its own operating system and applications. Server virtualization enables the consolidation of multiple servers on a single physical machine, reducing the cost and complexity of managing and maintaining physical servers. Server virtualization also improves the availability, scalability, and performance of applications, as VMs can be migrated, replicated, and load-balanced across different physical servers. Server virtualization is the most common type of virtualization in cloud computing, as it enables the creation of cloud services, such as infrastructure as a service (IaaS), platform as a service (PaaS), and software as a service (SaaS)    .

- **Storage virtualization**: Storage virtualization is the process of abstracting and pooling the physical storage devices, such as disks, tapes, and arrays, and presenting them as logical storage units to the VMs or applications. Storage virtualization enables the management of storage resources from a central console, regardless of their location and vendor. Storage virtualization also improves the efficiency, reliability, and flexibility of storage, as it enables the allocation, replication, backup, and recovery of storage resources on demand. Storage virtualization is an essential component of cloud computing, as it enables the storage of large amounts of data in the cloud, and the access to these data from anywhere and anytime   .

- **Network virtualization**: Network virtualization is the process of abstracting and pooling the physical network devices, such as switches, routers, and firewalls, and presenting them as logical network entities to the VMs or applications. Network virtualization enables the creation of multiple virtual networks that run on the same physical network, each with its own topology, protocols, and policies. Network virtualization also improves the security, performance, and scalability of network, as it enables the isolation, encryption, and optimization of network traffic. Network virtualization is a key enabler of cloud computing, as it enables the connectivity and communication of VMs and applications across different cloud environments, such as public, private, and hybrid clouds   .

- **Data virtualization**: Data virtualization is the process of abstracting and integrating data from different sources, such as databases, files, and web services, and presenting them as a single logical data source to the VMs or applications. Data virtualization enables the access and analysis of data from heterogeneous and distributed sources, without requiring the physical movement or replication of data. Data virtualization also improves the quality, consistency, and security of data, as it enables the validation, transformation, and masking of data. Data virtualization is a vital component of cloud computing, as it enables the delivery of data as a service (DaaS) to the VMs or applications, and the support of data-intensive applications, such as business intelligence, analytics, and machine learning .

- **Application virtualization**: Application virtualization is the process of abstracting and encapsulating an application from its underlying operating system and hardware, and presenting it as a self-contained and portable executable file to the VMs or users. Application virtualization enables the deployment and execution of applications on any compatible device, without requiring the installation or configuration of the application. Application virtualization also improves the compatibility, performance, and security of applications, as it enables the isolation, optimization, and protection of applications. Application virtualization is a useful technique of cloud computing, as it enables the delivery of applications as a service (AaaS) to the VMs or users, and the support of various types of applications, such as web, desktop, and mobile applications .
