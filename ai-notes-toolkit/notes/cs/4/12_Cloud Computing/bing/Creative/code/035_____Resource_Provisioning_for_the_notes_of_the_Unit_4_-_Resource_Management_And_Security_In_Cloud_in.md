# Resource Provisioning for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Resource provisioning is the allocation of the cloud provider's resources to a client.
- It is the process of integrating and executing cloud computing resources within an IT organization.
- It is an important aspect of the cloud computing model, which tells how a client acquires cloud services and resources from a cloud supplier.
- Resource provisioning can be conducted using one of three delivery models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), or Software as a Service (SaaS).
- Each delivery model differs depending on the kinds of resources or services an organization purchases, how and when the cloud provider delivers those resources or services, and how the customer pays for them.
- Resource provisioning can also be done in a cloud-edge computing environment, which combines the advantages of cloud computing and edge computing.
- Cloud-edge computing enables the distribution of resources and services across the cloud and the edge nodes, which are closer to the end-users and devices.
- Resource provisioning in a cloud-edge computing environment involves challenges such as heterogeneity, scalability, reliability, security, and optimization.
- Resource provisioning has to do with assuring that the cloud service will be sufficiently resourced as customer demand increases.
- To do this, a cloud service provider (CSP) would need to take certain measures to successfully deliver on its service level agreements (SLAs).
- For instance, the CSP might have procedures in place to add servers or storage as demand increases.
- Resource provisioning can be done manually or automatically, depending on the level of automation and orchestration supported by the cloud provider.
- Manual provisioning involves the user requesting and configuring the resources through a web portal or a command-line interface.
- Automatic provisioning involves the cloud provider dynamically allocating and releasing the resources based on predefined rules or policies.
- Resource provisioning can also be done using third-party tools or frameworks that can simplify and automate the process of creating, managing, and deleting cloud resources.
