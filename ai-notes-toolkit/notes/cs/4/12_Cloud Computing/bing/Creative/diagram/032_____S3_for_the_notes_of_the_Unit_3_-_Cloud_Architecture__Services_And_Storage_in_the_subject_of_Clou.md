### S3
- S3 stands for Simple Storage Service, and it is a cloud object storage solution provided by Amazon Web Services (AWS) .
- S3 allows you to store and retrieve any amount of data from anywhere over the internet, using a web services interface .
- S3 is designed for durability, availability, scalability, and performance, and it is ideal for data lakes, mobile applications, backup and restore, archival, IoT devices, ML, AI, and analytics .
- S3 is based on the concept of buckets and objects. A bucket is a container for objects, and an object is a file with data and metadata. Each object has a unique key that identifies it within a bucket .
- S3 offers different storage classes that vary in cost, performance, and availability. The storage classes are:
  - S3 Standard: for general-purpose storage of frequently accessed data .
  - S3 Intelligent-Tiering: for data with unknown or changing access patterns .
  - S3 Standard-Infrequent Access (S3 Standard-IA): for data that is accessed less frequently, but requires rapid access when needed .
  - S3 One Zone-Infrequent Access (S3 One Zone-IA): for data that is accessed less frequently, but does not require the resilience of being stored across multiple Availability Zones .
  - S3 Glacier: for long-term archival of data that can tolerate retrieval times of several hours .
  - S3 Glacier Deep Archive: for long-term archival of data that can tolerate retrieval times of 12 hours .
- S3 also provides various features and services to enhance the functionality and security of your data, such as:
  - S3 Versioning: to keep multiple versions of an object in the same bucket .
  - S3 Lifecycle: to automate the transition of objects between storage classes .
  - S3 Encryption: to protect your data at rest and in transit .
  - S3 Access Control: to manage the permissions and policies for accessing your data .
  - S3 Replication: to copy your data across regions or buckets .
  - S3 Analytics: to monitor and optimize the storage costs and performance of your data .
  - S3 Event Notifications: to trigger actions based on events that occur in your buckets .
  - S3 Select: to retrieve only a subset of data from an object .
  - S3 Batch Operations: to perform bulk actions on multiple objects .
- S3 is compatible with other AWS services and third-party applications that use the S3 API, which is the de-facto standard object storage API for storing unstructured data in the cloud .
