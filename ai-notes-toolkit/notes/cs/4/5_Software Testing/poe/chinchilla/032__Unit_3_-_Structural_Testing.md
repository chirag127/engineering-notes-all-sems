## Unit 3 - Structural Testing

Structural testing is a type of testing that focuses on the internal structure of a software application. It involves testing the code, design, and architecture of the application to ensure that it meets the requirements and specifications.

The following are the key points to keep in mind when studying structural testing:

1. Structural testing is also known as white-box testing because it involves testing the internal structure of the application, which is accessible to developers and testers.

2. The primary objective of structural testing is to ensure that all the paths and logical conditions in the code have been tested and that there are no defects or errors in the application.

3. Structural testing techniques include branch coverage, statement coverage, path coverage, and condition coverage.

4. Branch coverage involves testing all the possible branches or decision points in the code. This ensures that all the possible outcomes of a decision are tested.

5. Statement coverage involves testing every statement in the code. This ensures that every line of code is executed at least once during testing.

6. Path coverage involves testing all the possible paths through the code. This ensures that all the possible combinations of decisions and actions are tested.

7. Condition coverage involves testing all the possible conditions or Boolean expressions in the code. This ensures that all the possible outcomes of a condition are tested.

8. Structural testing is usually performed by developers, but it can also be performed by independent testers or a combination of both.

9. The tools used for structural testing include code coverage tools, debugging tools, and static analysis tools.

10. The advantages of structural testing include improved code quality, better test coverage, and early detection of defects.

11. The disadvantages of structural testing include the need for skilled testers and the high cost of testing.

In conclusion, structural testing is an important aspect of software testing that ensures the quality and reliability of software applications. By understanding the key points of structural testing, you can develop effective testing strategies and techniques to ensure that your applications meet the requirements and specifications.
