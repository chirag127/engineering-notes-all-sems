
### Fault for the Notes of the Unit 1 - Review of Software Engineering in the Subject of Software Testing

1. Fault is defined as an error in a program or system that leads to incorrect or unexpected results.

2. Fault localization is the process of isolating the source of an error or fault in a system.

3. Fault tolerance is the ability of a system to continue to operate even when one or more of its components fail.

4. Fault tree analysis is a method of analyzing the causes of a fault or error in a system by constructing a graphical representation of the system and its components.

5. Fault injection is a technique used to test the robustness of a system by deliberately introducing faults into it.

6. Software fault tolerance is the ability of a software system to continue to operate even when one or more of its components fail.

7. Software testing is the process of evaluating a system or its components to detect errors, bugs, or other defects.

8. Test coverage is the degree to which the source code of a program has been tested.

9. Regression testing is the process of testing a system or its components after changes have been made to ensure that the changes have not caused any unexpected behavior.
