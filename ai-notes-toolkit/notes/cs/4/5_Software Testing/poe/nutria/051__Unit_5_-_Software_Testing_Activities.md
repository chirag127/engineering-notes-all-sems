
## Unit 5 - Software Testing Activities

1. **Software Testing** is a process used to identify the correctness, completeness, security, and quality of developed computer software. It involves the execution of a software component or system component to evaluate one or more properties of interest. 
2. **Types of Software Testing** include: 
    * **Functional Testing** - This type of testing is used to evaluate the functionality of the software. It involves testing the application against the functional requirements and verifying that the application functions as expected. 
    * **Non-Functional Testing** - This type of testing is used to evaluate the non-functional aspects of the software, such as performance, scalability, usability, etc. 
    * **Regression Testing** - This type of testing is used to verify that the changes made to the software have not introduced any new bugs or errors. 
3. **Benefits of Software Testing** include: 
    * Improved Quality - Software testing helps to ensure that the software is of high quality, is reliable, and meets the requirements of the user. 
    * Reduced Cost - By finding and fixing bugs early in the development process, software testing helps to reduce the cost of development. 
    * Improved User Experience - Software testing helps to ensure that the software is usable and meets the expectations of the users. 
4. **Software Testing Process** includes the following steps: 
    * Requirements Analysis - This step involves analyzing the functional and non-functional requirements of the software. 
    * Test Planning - This step involves creating a plan for the testing process. 
    * Test Design - This step involves designing the tests that will be used to evaluate the software. 
    * Test Execution - This step involves executing the tests and recording the results. 
    * Test Reporting - This step involves reporting the results of the tests. 
    * Test Closure - This step involves closing the tests and documenting the results.
