
## Unit 2 - Functional Testing

1. Functional testing is a type of software testing that focuses on the functionality of an application or system. It is used to ensure that all of the required functions of the application or system work as expected.

2. Functional testing involves testing individual functions, as well as the interactions between different functions. It is typically done after unit testing and integration testing, and before system testing.

3. Functional testing is done by both manual and automated methods. Manual testing involves testing the application manually, while automated testing involves using a tool or script to test the application.

4. The purpose of functional testing is to ensure that the application or system meets the requirements set out in the specification. It is also used to identify any bugs or defects in the application or system.

5. Functional testing is an important part of the software development process, as it helps to identify any issues with the application or system before it is released to the public.
