
## Unit 4 - Regression Testing

Regression testing is a type of software testing that verifies that software which was previously developed and tested still performs the same way after it was changed or interfaced with other software. It is used to confirm that a recent code change has not adversely affected existing features.

1. Regression testing is performed when changes are made to the software and it is important to make sure that the changes did not introduce any new bugs.
2. It is also used to determine if changes to one part of the software have caused unintended effects in other parts of the software.
3. Regression testing should be conducted after any changes to the software, such as bug fixes, new features, or changes to existing features.
4. The goal of regression testing is to ensure that any changes made to the software do not introduce any new bugs and that the software continues to function as expected.
5. Regression testing is an iterative process and should be performed multiple times as changes are made to the software.
6. Regression tests should cover all areas of the software, including the user interface, back-end, and database.
7. Automated tests are often used to perform regression testing, as they can be run quickly and repeatedly.
8. Regression testing is an important part of the software development process and should be performed regularly to ensure that the software continues to function as expected.
