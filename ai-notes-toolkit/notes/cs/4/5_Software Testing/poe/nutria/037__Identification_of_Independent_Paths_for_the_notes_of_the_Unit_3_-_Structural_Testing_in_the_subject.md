
### Identification of Independent Paths for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

* Structural testing is a type of software testing that focuses on the internal structure of a program.
* The aim of structural testing is to ensure that all parts of the program are working correctly and that there are no bugs or errors.
* To identify independent paths, the first step is to create a graph of the program’s control flow.
* This graph can then be used to identify all the possible paths through the program.
* Once all the possible paths have been identified, the next step is to determine which paths are independent.
* An independent path is a path through the program that does not depend on any other path.
* To determine which paths are independent, a coverage criterion such as statement coverage or branch coverage can be used.
* Once all the independent paths have been identified, they can be tested to ensure that they are working correctly.
