
### Test Data for the notes of the Unit 5 - Software Testing Activities in the Subject of Software Testing

1. Test data is the input given to a software program to test its functionality and verify that it is working as expected.
2. Test data can be created manually or generated automatically.
3. Test data should be designed to cover all possible combinations of input that could be used to test the software.
4. Test data should be designed to test the boundary conditions of the software.
5. Test data should be designed to test the negative conditions of the software.
6. Test data should be designed to test the performance of the software.
7. Test data should be designed to test the security of the software.
8. Test data should be designed to test the scalability of the software.
9. Test data should be designed to test the usability of the software.
10. Test data should be designed to test the compatibility of the software.
