
### Data Flow Testing for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

1. Data Flow Testing is a white box testing technique that focuses on the flow of data through a system.
2. It is used to identify defects in the logic of the system and to ensure that the data is processed correctly.
3. It is based on the idea of tracing the flow of data through the system, from the inputs to the outputs.
4. It is used to identify errors in the logic of the system, such as incorrect data processing or incorrect data flow.
5. It is also used to identify potential security vulnerabilities, such as data leakage.
