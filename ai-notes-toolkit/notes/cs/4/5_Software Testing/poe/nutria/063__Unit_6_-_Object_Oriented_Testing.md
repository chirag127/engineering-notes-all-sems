
## Unit 6 - Object Oriented Testing

1. Object-oriented testing is a software testing technique that focuses on testing the behavior and functionality of objects within an application.

2. This technique is used to ensure that the objects within an application are behaving as expected and that the application is functioning properly.

3. Object-oriented testing typically involves creating test cases that test individual objects, as well as testing the interactions between objects.

4. The goal of object-oriented testing is to ensure that the objects within the application are working correctly, and that the application is able to meet the requirements of the end user.

5. Object-oriented testing is an important part of the software development process, as it helps to ensure that the application is functioning correctly and meets the user's needs.
