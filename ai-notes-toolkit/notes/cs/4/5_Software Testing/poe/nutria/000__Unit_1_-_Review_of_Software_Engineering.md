
## Unit 1 - Review of Software Engineering

1. Software engineering is the process of designing, developing, and maintaining software applications. It involves the application of engineering principles and techniques to create reliable, efficient, and cost-effective software solutions.
2. Software engineering is a multidisciplinary field that combines elements from computer science, mathematics, and engineering.
3. The goal of software engineering is to create software that is reliable, efficient, and cost-effective.
4. Software engineering involves the use of various tools, techniques, and processes to create, maintain, and improve software applications.
5. The software engineering process includes requirements gathering, design, implementation, testing, and maintenance.
6. Requirements gathering involves gathering and analyzing user requirements to determine the software application’s functional and non-functional requirements.
7. Design involves creating a software architecture that meets the user requirements and is efficient, reliable, and cost-effective.
8. Implementation involves coding the software application and ensuring that it meets the user requirements.
9. Testing involves verifying that the software application meets the user requirements and is free of errors.
10. Maintenance involves making changes to the software application to ensure it meets the user requirements and is up to date.
