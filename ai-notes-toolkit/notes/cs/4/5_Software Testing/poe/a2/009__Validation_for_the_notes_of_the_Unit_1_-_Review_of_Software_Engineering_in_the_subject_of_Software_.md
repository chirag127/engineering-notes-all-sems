### Validation for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. Software Engineering is an engineering discipline which is concerned with all aspects of software production.
2. The major tasks in software engineering are:
- Analysis: Determine what the software should do.
- Design: Develop a plan for software.
- Implementation: Write the software.
- Testing: Check that the software is error-free, easy to use, and efficient.
- Maintenance: Correct, adapt, and improve the software.
3. The software process is a set of activities whose goal is to produce a software product that satisfies specific requirements. It can be decomposed into several phases:
- Specification: State the requirements and constraints.
- Development: Translate the specification into a software product.
- Validation: Check that the software product satisfies the specified requirements.
- Evolution: Adapt the software product to requirements changes.
4. Software Testing is the process of evaluating a software product to detect differences between expected and actual results. It involves operation of a system or application under controlled conditions and evaluating one or more characteristics of interest.
