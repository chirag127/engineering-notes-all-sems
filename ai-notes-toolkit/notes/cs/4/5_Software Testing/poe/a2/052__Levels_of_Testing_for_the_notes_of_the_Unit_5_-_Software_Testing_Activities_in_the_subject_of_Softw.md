### Levels of Testing

1. Unit Testing - Testing of individual software components or modules. Eg: Testing a single function.
2. Integration Testing - Testing of combined software modules. Eg: Testing interface between modules.
3. System Testing - Testing the complete software product as a whole. Eg: Testing end-to-end flows.
4. Acceptance Testing - Testing by end-user to accept the software. Eg: Testing software against requirements.

- Focuses on functional requirements.
- Performed in a controlled environment.
- Documents issues found for resolution.

The above testing levels are executed in a sequential order to ensure quality software. Each level must satisfy its exit criteria before the next level is executed.
