### Class Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

1. Class testing involves testing the individual classes that are a part of the software to check whether they are working as intended.
2. This is done by writing test cases for all the methods/functions in the class and executing them.
3. Test cases should be written to check for both valid and invalid inputs and verify that the output is as expected.
4. Class dependencies should also be tested by mocking the dependent classes and simulating different scenarios.
5. Constructor testing is also important to ensure that object creation is happening properly.
6. Inheritance hierarchies must be tested by creating objects of base and derived classes and verifying that the inheritance is working correctly.
7. Exception testing must be done to check if the exception handling is implemented accurately.
8. Final classes cannot be subclassed so that needs to be tested to verify restriction.

The above points cover the key aspects of class testing to verify functionality, dependencies, inheritance, exceptions and other features as per the requirements. Class testing is done before integrating the classes and testing the entire software solution.
