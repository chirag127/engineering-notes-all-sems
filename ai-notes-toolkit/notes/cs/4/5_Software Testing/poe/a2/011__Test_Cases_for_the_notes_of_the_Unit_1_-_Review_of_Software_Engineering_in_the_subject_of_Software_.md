1. What is Software Engineering?
- Software Engineering is an engineering discipline which is concerned with all aspects of software production.
- It applies systematic, disciplined, quantifiable approach to the development, operation, maintenance, and retirement of computer software.
- It encompasses activities, methods, practices needed to analyze user needs, design, implement, and test software.

2. Software Development Life Cycle
- Requirements Analysis: Gathering requirements from user and analyzing them.
- Design: Developing design and architecture of the software.
- Implementation or Coding: Implementing the software design into programming code.
- Testing: Conducting various testing types to detect and fix any bugs or defects.
- Deployment: Deploying the final software and making it available for user.
- Maintenance: Performing changes or corrections to fix any issues reported or to adapt to changing user needs.

3. Need of Software Testing
- To check whether the software developed meets the requirements and specifications or not.
- To identify and detect bugs, defects, and other issues in the software as early as possible and remove them.
- To ensure that the software developed is of good quality, reliable, and usable.
- To reduce complexities and risks in software development.
