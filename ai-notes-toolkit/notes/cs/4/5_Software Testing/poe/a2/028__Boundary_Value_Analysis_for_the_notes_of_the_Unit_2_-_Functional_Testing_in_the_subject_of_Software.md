### Boundary Value Analysis for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

- Boundary value analysis is a software testing technique in which tests are designed to include representatives of boundary values.
- The boundaries that are tested typically include the edges of input equivalence classes, output equivalence classes or on decision points in an algorithm.
- The objective of boundary value analysis is to detect errors at boundaries of the input domain.
- For example, if a system accepts numbers in the range 1 to 100, test cases might include -1, 0, 1, 100, 101.
- This technique essentially complements equivalence partitioning since it focuses on "corner cases" or values that are significantly different from the expected normal range of inputs.
- Boundary value analysis is useful for testing for software bugs like buffer overflows or memory leaks that may cause a system to crash or behave unexpectedly.
- It is important to test for multiple boundaries that may exist for a single input and to choose test cases that exercise boundaries in combination.
