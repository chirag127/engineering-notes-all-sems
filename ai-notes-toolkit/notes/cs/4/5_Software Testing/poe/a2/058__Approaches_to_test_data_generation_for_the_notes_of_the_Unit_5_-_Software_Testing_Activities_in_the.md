### Approaches to test data generation for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing.

1. Boundary value analysis:
- Choose test data that lie along data extremes.
- E.g.: minimum, maximum, just inside/outside boundaries.
- Checks errors at boundaries.

2. Equivalence partitioning:
- Divide input data into partitions where each partition has equivalent behavior.
- E.g.: valid vs invalid inputs, input data ranges.
- At least one test case from each partition.

3. Cause-effect graphing:
- Represent inputs/outputs and reasons/causes of software behavior.
- Derive test cases from the graph to exercise diverse behaviors.

4. Random testing:
- Test cases are generated randomly.
- May achieve certain coverage but not suited for critical systems.
- May require large number of tests to achieve adequate coverage.

5. Syntax testing:
- Check conformity to expected syntax/formats.
- E.g.: check date formats, check password complexity.

The above approaches can be combined to generate effective test data and achieve good coverage to uncover maximum bugs. The test data should be selected judiciously based on the system and test objectives.
