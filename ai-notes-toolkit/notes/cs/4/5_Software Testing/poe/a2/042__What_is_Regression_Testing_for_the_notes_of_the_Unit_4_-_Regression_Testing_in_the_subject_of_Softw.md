### What is Regression Testing

1. Regression Testing is a type of software testing to confirm that a recent program or code change has not adversely affected existing features.
2. It is performed to ensure that changes made to the software do not result in bugs or issues in the unchanged parts of the software.
3. Regression Testing is done by re-running the test cases that were previously executed. The results are then compared with the expected results to check for any bugs.
4. It is important because even small changes in the code can sometimes affect other parts of the software and introduce unintended side-effects or bugs.
5. Regression Testing can be performed manually or using automated testing tools. Automated Regression Testing is preferred as it is more efficient, fast, and reliable.
6. Challenges with Regression Testing:
- Deciding which test cases to re-run.
- Managing a large number of test cases.
- Handling dependencies between test cases.
- Balancing between thorough testing and available time.
