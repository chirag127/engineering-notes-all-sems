### Difference Between Verification and Validation

- Verification: It is the process of checking whether the software meets the specifications and requirements or not. It is the process of evaluating software to find errors/defects.
- Validation: It is the process of checking whether the software meets the user needs and expectations or not. It is done to check if the software is usable.
- Verification is done by testing team while validation is done by client/end users.
- Verification evaluates the process while validation evaluates the product.
- Verification is done at every stage of SDLC while validation is done at the final stage.
- Verification uses techniques like reviews, inspections, walkthroughs, etc. while validation uses techniques like testing, pilot runs, etc.
- The main goal of verification is to check correctness while the main goal of validation is to check functionality and usability.
