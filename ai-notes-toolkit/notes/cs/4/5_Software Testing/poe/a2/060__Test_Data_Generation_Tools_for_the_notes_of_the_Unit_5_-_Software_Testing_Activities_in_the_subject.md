### Test Data Generation Tools for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

1. Boundary Value Analysis:
- It is a black-box test design technique to generate test inputs
- Generates test data by choosing input values at the boundaries of the input domain
- Tests the boundaries between partitions of input data values
- It can be applied to both input and output domains of the system under test

2. Equivalence Partitioning:
- Divides the input domain into equivalence classes
- Generates test input values from each equivalence partition
- It is a black-box test design technique to generate test inputs
- Each partition represents a group of values. Only one value from each partition needs to be tested

3. Cause-Effect Graphing:
- It is a white-box test data generation technique
- Models inputs, processing logic and outputs of a system as a graph
- Traverses the graph systematically to generate test inputs
- Use it for components with complex processing logic
