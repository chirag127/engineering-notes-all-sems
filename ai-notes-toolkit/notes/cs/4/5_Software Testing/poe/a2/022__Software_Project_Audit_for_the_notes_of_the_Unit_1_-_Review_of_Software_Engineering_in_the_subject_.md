### Software Project Audit for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing.

1. Software project audits are conducted to evaluate the software development process followed in a project. It helps to identify the issues and risks involved in the software development lifecycle.
2. The key areas focused in a software project audit are:
- Requirements analysis: Whether the requirements are clearly defined, documented and verified.
- Design: Whether the software design is properly done and addresses all the requirements. Whether the design documents are maintained properly.
- Coding: Whether the coding standards are followed. Whether the code is modular, readable and well-documented.
- Testing: Whether proper testing strategies are adopted. Whether testing is done at all phases of SDLC. Whether there are any test cases or test plans.
- Change management: Whether any changes made to the software are properly managed under change control.
- Project monitoring and control: Whether the project is monitored and controlled properly. Whether there are any metrics to measure the productivity and health of the project.
3. The key benefits of a software project audit are:
- Identifying the potential risks and issues early in the project lifecycle.
- Evaluating the efficiency and effectiveness of the software development process.
- Taking corrective actions to address the issues identified.
- Improving the software development process for the ongoing and future projects.
