### Debugging for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing.

1. Debugging is the process of finding and resolving bugs or defects in the software.
2. It is done by identifying the exact location of the bug and then fixing it.
3. Some common debugging techniques are:
- Step by Step Execution: Running the program step by step to find the line where the error occurs.
- Breakpoints: Pausing the execution of the program at specified lines to check the values of variables.
- Watch Window: Observing the values of selected variables as the program runs.
- Logging: Printing log statements at specific locations to output variables values or status.
4. Debuggers are tools which help to debug software by pausing execution, stepping through code line by line, observing variable values, etc.
5. Effective debugging requires good analytical and logical reasoning skills to find the root cause of the bug.
6. Debugging is an iterative process where finding one bug could lead to finding more bugs. So, it should be performed with patience and persistence.
