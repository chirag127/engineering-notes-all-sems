### Database testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing.

1. Database testing is done to check the data integrity i.e. accuracy, consistency and security of data in the database.
2. Some common database testing techniques are:
- Data validity testing - Check if the data types, sizes, ranges, values, etc. are as expected. Also, check for orphaned and missing data.
- Referential integrity testing - Check if the relationships between tables are intact like foreign key constraints.
- Authorization and access control testing - Test if only authorized users can access and modify data. Check for SQL injection vulnerabilities.
- Backup and recovery testing - Test the database backup and recovery process.
- Stored procedures testing - Test the stored procedures for expected input/output and check if there are any errors or side effects.
3. Some tools used for database testing are:
- SQLUnit - An open source tool for testing database queries and stored procedures.
- DbFit - A database testing tool that supports various databases like MySQL, Oracle, etc.
- UAT-Database Tester - A commercial tool to automate database testing for queries, procedures, functions, etc. across different databases.
4. Database testing should be performed continuously to catch issues early and ensure a robust database for the application. It is an important part of testing web applications and overall software quality assurance.
