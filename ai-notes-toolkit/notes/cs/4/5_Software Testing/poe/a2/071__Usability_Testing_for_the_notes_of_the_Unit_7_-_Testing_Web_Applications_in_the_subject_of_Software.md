### Usability Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

1. Usability testing is a technique to evaluate a product by testing it on users. The aim is to identify any problems with the user experience, interface, and interaction design.
2. Recruit real users to test the product - Choose target audience for the product and recruit users matching the demographic. Get opinions from a varied set of users with different backgrounds and experiences to identify diverse issues.
3. Set specific tasks to complete - Give the users well-defined tasks that are important and common activities on the application to measure success and identify issues in the workflow. Observe and note down the problems they face.
4. Note observations and user reactions - Closely observe the users interacting with the product. Note down all problems, comments, confusions, and difficulties they face. Also note positive feedback and ease of completing tasks.
5. Identify and prioritize issues - Review all the notes and observations to list down the significant usability issues. Prioritize them by impact and severity. Share findings with the design and development team to fix issues and improve user experience.
6. Repeat testing after fixes - Once the major issues are resolved, conduct another round of usability testing to ensure the changes have worked and there are no new issues introduced. Repeat testing to continually improve the product.
