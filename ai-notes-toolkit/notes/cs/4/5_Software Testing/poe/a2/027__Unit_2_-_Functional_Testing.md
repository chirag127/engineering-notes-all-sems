## Unit 2 - Functional Testing

1. Functional Testing is a type of black-box testing that focuses on the functionality of an application/system/software. It ensures that the functionality of the system works as expected.
2. The key steps involved in Functional Testing are:
- Understanding requirements and specifications.
- Identifying test scenarios based on specifications.
- Preparing test cases and test data.
- Executing the test cases.
- Analyzing and reporting results.
3. The different types of Functional Testing are:
- Unit Testing - Tests individual components/units of the software.
- Integration Testing - Tests the interface between two or more integrated units/components.
- System Testing - Tests the fully integrated software product as a whole.
- Sanity Testing - Performs quick smoke test to ensure that the build is stable enough for further testing.
- Smoke Testing - Checks for the stability of the software build.
- Regression Testing - Tests if the previous bugs have been fixed and no new bugs have been introduced.
4. The key benefits of Functional Testing are:
- Ensures that the software meets the specified requirements.
- Increases the quality of the software and reduces the number of defects/bugs.
- Provides concrete test cases and test scenarios that can be reused for regression testing.
- Gives accurate and timely feedback to the developers or testers.
- Improves the customer satisfaction.
