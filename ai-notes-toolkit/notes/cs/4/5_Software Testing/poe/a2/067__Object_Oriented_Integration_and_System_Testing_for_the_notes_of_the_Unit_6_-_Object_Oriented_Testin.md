### Object Oriented Integration and System Testing

1. Integration Testing
- Testing integrated modules/components to verify interfaces.
- Top down integration - Test high level modules first.
- Bottom up integration - Test lower level modules first.
- Hybrid integration - Mix of top down and bottom up.
- Big bang integration - Integrate and test all modules at once.
- Incremental integration - Integrate and test modules incrementally.

2. System Testing
- Testing the whole system to validate requirements.
- Recovery testing - Induce faults to check recovery.
- Application testing (UI testing) - Test user interfaces.
- Security testing - Check for threats, vulnerabilities and access control.
- Performance testing - Check response times, throughput, resource usage, scalability, etc.
- Volume testing - Test with large data volumes.
- Load testing - Test with many users accessing simultaneously.
- Stress testing - Test beyond normal load to identify breaking points.
