## Unit 4 - Regression Testing

1. Regression Testing is a type of software testing to confirm that a recent program or code change has not adversely affected existing features.
2. Regression Testing is performed to ensure that the software product is defect-free after new features or modifications have been implemented. It helps to identify bugs introduced by changes and ensure that the software product meets specified requirements.
3. The key objectives of Regression Testing are:
- To detect defects early and fix them.
- To determine if changes have any adverse effect on existing functionalities.
- To ensure that the software product meets the required specifications.
4. Types of Regression Testing:
- Full Regression Testing: Testing the whole application to ensure no new bugs are introduced.
- Partial Regression Testing: Testing only affected components by changes.
- Unit Regression Testing: Testing individual units of the source code.
5. Challenges in Regression Testing:
- Requirement of considerable time and resources.
- Difficulty in determining which areas of the software to re-test.
- Management of test cases and test data.
- Regression test selection to minimize cost and time.
