### Test Data for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

1. Test data is the input data used to test the software and check its working and output.
2. It is used to validate the functionality and performance of the software.
3. It should be selected carefully to get maximum code coverage and uncover maximum bugs.
4. Types of test data:
- Valid test data: Data that is accepted by the system as per requirements. For example, valid username and password to log in to a system.
- Invalid test data: Data that is rejected by the system as per requirements. For example, invalid username and password to log in to a system.
- Extreme values: Boundary values or maximum/minimum values allowed as per requirements. For example, maximum and minimum numbers or lengths allowed.
- Random test data: Generated randomly to tests the system's ability to handle unexpected or random inputs.
5. Test data requirements:
- Should have variety to check different scenarios
- Should be easy to automate
- Should be available before starting testing
- Should have proper documentation on how it was identified and justification for the selected test data.
