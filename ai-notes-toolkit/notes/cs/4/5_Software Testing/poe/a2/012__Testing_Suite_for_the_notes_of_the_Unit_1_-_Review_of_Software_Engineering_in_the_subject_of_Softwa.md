### Testing Suite for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing.

1. Software Engineering: Software Engineering is an engineering discipline which is concerned with all aspects of software production.
2. Software Testing: Software Testing is a process of evaluating a software item to detect differences between given input and expected output. It involves execution of a program or application with the intent of finding failures and verifying that the software meets the required results.
3. Testing Objectives: The objectives of testing are:
- To check the functionality of the software against specified requirements.
- To ensure that the software is defect free.
- To ensure software quality and reliability.
- To ensure that software performance and execution time requirements are met.
4. Testing Types: The major types of software testing are:
- Unit Testing: Unit Testing is done on individual modules or components of the software.
- Integration Testing: Integration Testing is performed to check interfaces between software components.
- System Testing: System Testing is conducted on a complete, integrated software product to evaluate the system's compliance with its specified requirements.
- Acceptance Testing: Acceptance Testing is done to determine whether the software meets the acceptance criteria and to enable the users to determine whether to accept the software or not.
