1.  Software Engineering is the application of engineering principles to software development. It involves a systematic approach to the development, operation, maintenance, and retirement of computer software.
2.  The main activities of software engineering are:
    -   Requirements analysis: Understanding the requirements of the users and stakeholders and documenting them.
    -   Design: Coming up with a design plan to build the software.
    -   Implementation: Implementing the software product as per the design.
    -   Testing: Testing the software product to identify and fix any bugs or errors.
    -   Deployment: Deploying the software for user use.
    -   Maintenance: Making modifications to the software to fix bugs or add new features.
3.  The software development lifecycle typically follows sequential steps, but can also be iterative. The main software development lifecycle models are:
    -   Waterfall model: Sequential steps through requirements, design, implementation, testing, and deployment.
    -   Agile model: Iterative and incremental approach focusing on collaboration and adapting to changes. Common agile methodologies are Scrum and XP.
4.  To ensure high quality software, software engineering emphasizes principles such as:
    -   Upfront planning
    -   Structured programming
    -   Formal methods
    -   Management and review processes
    -   Precise documentation
