### Performance Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

1. Performance Testing is done to determine the performance of a system or application under a particular workload. It helps to identify and address bottlenecks or other performance issues.
2. Some key performance metrics to measure are:
- Response time: Time taken to respond to a request.
- Throughput: Number of transactions completed in a given time period.
- Resource utilization: Processor, memory, disk, network bandwidth usage, etc.
3. Types of Performance Testing:
- Load Testing: Testing the application's performance under increasing load. Helps find the maximum load the application can handle without significant performance degradation.
- Stress Testing: Testing the application's performance beyond normal expected load to identify breaking point.
- Soak Testing: Running a system at high load for a prolonged period to identify performance issues like memory leaks.
- Spike Testing: Suddenly increasing the load on the application to test performance under bursty/peak load conditions.
4. Requirements for Performance Testing:
- Identify key scenarios and use cases to be tested
- Determine appropriate workload models and metrics
- Set up proper test environment with necessary resources
- Use relevant tools to simulate load and monitor performance
- Analyze results and tune system to address bottlenecks
