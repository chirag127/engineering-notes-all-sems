### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

When testing software, it is essential to have a way to determine whether the output of the software is correct or not. This is where oracles come in. An oracle is a mechanism for determining the correctness of the output of software under test. Here are some common types of oracles:

1. **Requirement-based oracles**: These oracles determine correctness based on the requirements specified for the software. The output of the software is compared to the requirements to determine whether it is correct or not.

2. **Specification-based oracles**: These oracles determine correctness based on the software's specifications. The output of the software is compared to the specifications to determine whether it is correct or not.

3. **Code-based oracles**: These oracles determine correctness based on the code of the software. The output of the software is compared to the expected output based on the code to determine whether it is correct or not.

4. **Comparison-based oracles**: These oracles determine correctness by comparing the output of the software to a reference output. The reference output can be generated by a different implementation of the software or by a human expert.

5. **Experience-based oracles**: These oracles determine correctness based on the experience of the tester. The tester uses their experience to determine whether the output of the software is correct or not.

It is important to choose the appropriate oracle for a particular testing scenario to ensure that the correctness of the software is determined accurately. In addition, it is important to document the oracle used in the testing process to ensure that the testing process can be repeated in the future.
