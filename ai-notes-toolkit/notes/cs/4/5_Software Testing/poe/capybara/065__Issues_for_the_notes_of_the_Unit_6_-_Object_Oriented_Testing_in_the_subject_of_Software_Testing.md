### Issues for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

Object Oriented Testing is an essential part of software testing, and it is vital to understand the issues related to it. Here are some of the issues that you should keep in mind while preparing notes for Unit 6 of the subject of Software Testing:

- **Understanding the Object-Oriented Paradigm:** Before you start with Object Oriented Testing, it is essential to understand the paradigm itself. You should have a clear understanding of the concepts like classes, objects, inheritance, encapsulation, and polymorphism.

- **Choosing the Right Testing Techniques:** Object Oriented Testing requires different techniques as compared to traditional testing techniques. You should be aware of the various testing techniques like Class Testing, Component Testing, Integration Testing, and System Testing. You should choose the testing techniques that are suitable for the software you are testing.

- **Testing for Inheritance and Polymorphism:** Inheritance and Polymorphism are two essential concepts of Object Oriented Programming. It is essential to test these concepts thoroughly to ensure that they are working correctly. You should be aware of the various testing techniques like Subclass Testing, Superclass Testing, and Polymorphic Testing.

- **Test Data Management:** Object Oriented Testing requires a vast amount of test data. You should be prepared to handle this data and manage it efficiently. You should be able to generate test data that can cover all possible scenarios and ensure that the software is functioning correctly.

- **Test Automation:** Object Oriented Testing can be time-consuming and complex. Test Automation can help to reduce the testing time and make the testing process more efficient. You should be aware of the various test automation tools and techniques like Selenium, JUnit, and TestNG.

- **Managing the Test Environment:** Object Oriented Testing requires a specific test environment. You should be able to create and manage this environment efficiently. You should be aware of the various tools and techniques like Docker, Jenkins, and Travis CI.

- **Reporting and Analysis:** Object Oriented Testing requires proper reporting and analysis of the test results. You should be able to create reports that are easy to read and understand. You should also be able to analyze the test results and identify the issues that need to be addressed.

In conclusion, Object Oriented Testing is an essential part of software testing, and it requires a different approach than traditional testing. You should be aware of the various issues related to Object Oriented Testing and prepare your notes accordingly.
