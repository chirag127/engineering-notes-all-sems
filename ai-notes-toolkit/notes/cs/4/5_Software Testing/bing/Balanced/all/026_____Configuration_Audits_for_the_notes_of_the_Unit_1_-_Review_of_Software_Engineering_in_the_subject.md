# Configuration Audits

- Configuration audits are a process of verifying that the software product conforms to the specified requirements and design documents .
- Configuration audits are performed by an independent team or authority that is not involved in the development or testing of the software product .
- Configuration audits are conducted at the end of each software development phase or release, or whenever a significant change is made to the software configuration .
- Configuration audits help to ensure the quality, reliability, and consistency of the software product, and to identify and resolve any discrepancies or defects .
- Configuration audits consist of two types: Functional Configuration Audit (FCA) and Physical Configuration Audit (PCA) .
  - FCA verifies that the software product meets the functional requirements and specifications, and that it performs as expected .
  - PCA verifies that the software product matches the physical design and documentation, and that it includes all the necessary components and files .
- Configuration audits are supported by configuration management, which is a process of controlling and tracking the changes to the software product and its configuration metadata.
- Configuration management helps to maintain the integrity and traceability of the software product, and to facilitate the configuration audits.
