## Unit 2 - Functional Testing

- Functional testing is a type of software testing that verifies that the software performs as expected according to the requirements or specifications.
- Functional testing involves testing the functionality of the software at various levels, such as unit, integration, system, and acceptance testing.
- Functional testing can be performed manually or using automated tools, depending on the scope, complexity, and resources of the project.
- Functional testing can be classified into different types, such as black-box testing, white-box testing, and gray-box testing, based on the level of knowledge and access to the internal structure and logic of the software.
- Functional testing can also be categorized into different techniques, such as equivalence partitioning, boundary value analysis, decision table testing, state transition testing, use case testing, and exploratory testing, based on the criteria and methods used to design and execute test cases.
- Functional testing aims to ensure that the software meets the functional requirements and expectations of the users and stakeholders, and that it is free of defects and errors that may affect its functionality.
