# Reducing the number of test cases for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

- Regression testing is the process of retesting a software system after making changes to it, such as fixing bugs, adding new features, or modifying existing ones.
- Regression testing aims to ensure that the changes do not introduce new defects or affect the existing functionality of the system.
- Regression testing can be costly and time-consuming, especially when the system is large and complex, and the changes are frequent and extensive.
- Therefore, it is desirable to reduce the number of test cases that need to be executed for regression testing, without compromising the quality and effectiveness of the testing.
- There are several techniques and strategies for reducing the number of test cases for regression testing, such as:

  - Test case prioritization: This technique involves ranking the test cases according to some criteria, such as their importance, coverage, fault-detection ability, or execution time, and selecting the most relevant ones for regression testing. Test case prioritization can help increase the rate of fault detection and reduce the testing effort.
  - Test case selection: This technique involves selecting a subset of test cases from the original test suite that are relevant to the changes made to the system. Test case selection can help eliminate redundant or obsolete test cases and focus on the ones that are affected by the changes.
  - Test case minimization: This technique involves reducing the size or complexity of the test cases, by removing unnecessary or redundant inputs, outputs, or steps, or by combining or simplifying multiple test cases into one. Test case minimization can help reduce the testing time and resources, while maintaining the coverage and fault-detection ability of the test cases.
  - Test suite augmentation: This technique involves adding new test cases to the existing test suite, to cover the new or modified functionality of the system. Test suite augmentation can help improve the completeness and adequacy of the test suite, and detect new or regression faults.
  - Regression test automation: This technique involves using software tools or scripts to automate the execution, verification, and reporting of the test cases, instead of performing them manually. Regression test automation can help increase the speed, accuracy, and consistency of the testing, and reduce the human effort and errors.
