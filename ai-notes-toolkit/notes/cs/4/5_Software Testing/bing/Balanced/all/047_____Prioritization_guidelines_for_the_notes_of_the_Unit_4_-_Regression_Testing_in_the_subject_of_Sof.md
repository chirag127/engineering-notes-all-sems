# Prioritization guidelines for the notes of the Unit 4 - Regression Testing

- Regression testing is the process of retesting the modified parts of a software system and ensuring that no new defects have been introduced due to the changes.
- Regression testing is important because it helps to maintain the quality and reliability of the software, detect and fix bugs, and prevent regression failures in the future.
- Regression testing can be performed at different levels of testing, such as unit testing, integration testing, system testing, and acceptance testing.
- Regression testing can be done manually or automatically, depending on the availability of test cases, test tools, and resources.
- Regression testing can be classified into three types: retest all, selective, and test case prioritization.
  - Retest all is the simplest and most comprehensive approach, where all the existing test cases are executed again after any change in the software. This ensures complete coverage, but it is also time-consuming and costly.
  - Selective is the approach where only a subset of the existing test cases are executed, based on some criteria, such as the impact of the change, the risk of the functionality, the frequency of use, etc. This reduces the testing effort, but it may also miss some defects.
  - Test case prioritization is the approach where the existing test cases are ranked according to some criteria, such as the severity of the defect, the probability of failure, the coverage of the code, etc. and executed in that order. This maximizes the effectiveness of the testing, but it requires a good ranking algorithm and a reliable test oracle.
- Regression testing can be further enhanced by using some techniques, such as regression test suite minimization, regression test suite augmentation, and regression test selection.
  - Regression test suite minimization is the technique of reducing the size of the test suite by eliminating redundant or obsolete test cases, while preserving the coverage and fault detection capability of the original test suite.
  - Regression test suite augmentation is the technique of adding new test cases to the test suite to cover the new or modified functionality, or to expose the new or modified faults.
  - Regression test selection is the technique of selecting a subset of the test suite that is relevant and adequate for the current version of the software, based on some criteria, such as the code coverage, the change impact analysis, the dependency analysis, etc.
