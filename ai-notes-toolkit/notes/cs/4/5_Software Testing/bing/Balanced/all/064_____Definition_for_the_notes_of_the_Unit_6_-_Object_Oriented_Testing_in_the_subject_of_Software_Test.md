# Object Oriented Testing

- Object oriented testing is a software testing process that is conducted to test the software using object oriented paradigms like encapsulation, inheritance, polymorphism, etc. 
- Object oriented testing is different from conventional testing strategies because the concepts of object oriented programming are way different from that of conventional ones. 
- Object oriented testing revolves around the fundamental entity known as “class”, which is a blueprint for creating objects. 
- Object oriented testing encompasses three levels, namely, unit testing, subsystem testing, and system testing. 
- Unit testing is the testing of individual classes or modules with focus on testing the code of that module. 
- Subsystem testing is the testing of a group of classes or modules that work together to provide a specific functionality. 
- System testing is the testing of the whole software system as a single entity with focus on testing the functionality, performance, reliability, and usability of the system. 
- Object oriented testing requires different techniques and tools than conventional testing because of the features of object oriented programming, such as inheritance, polymorphism, dynamic binding, etc. 
- Some of the techniques and tools used for object oriented testing are class testing, state-based testing, scenario-based testing, fault-based testing, mutation testing, etc.
