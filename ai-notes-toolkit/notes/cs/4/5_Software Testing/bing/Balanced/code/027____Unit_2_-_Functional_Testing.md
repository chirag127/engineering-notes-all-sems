## Unit 2 - Functional Testing

- Functional testing is a type of software testing that verifies that the software performs as expected according to the requirements or specifications.
- Functional testing involves testing the functionality of the software at various levels, such as unit, integration, system, and acceptance testing.
- Functional testing can be performed manually or with the help of automated tools.
- Functional testing can be classified into different types, such as black-box testing, white-box testing, and gray-box testing.
- Black-box testing is a type of functional testing that focuses on the input and output of the software, without considering the internal structure or logic of the code.
- White-box testing is a type of functional testing that examines the internal structure and logic of the code, as well as the input and output of the software.
- Gray-box testing is a type of functional testing that combines both black-box and white-box testing techniques, using some knowledge of the internal structure and logic of the code, as well as the input and output of the software.
- Functional testing can also be categorized into different techniques, such as equivalence partitioning, boundary value analysis, decision table testing, state transition testing, use case testing, and exploratory testing.
- Equivalence partitioning is a technique of functional testing that divides the input domain of the software into different classes or partitions, such that each partition is expected to produce the same output or behavior.
- Boundary value analysis is a technique of functional testing that tests the software at the boundary values or limits of the input domain, such as minimum, maximum, or edge values.
- Decision table testing is a technique of functional testing that uses a table or matrix to represent the possible combinations of inputs and outputs of the software, as well as the rules or conditions that govern them.
- State transition testing is a technique of functional testing that tests the software based on the changes or transitions of its states, as well as the events or actions that trigger them.
- Use case testing is a technique of functional testing that tests the software based on the scenarios or workflows that describe how the users interact with the software and what outcomes they expect.
- Exploratory testing is a technique of functional testing that involves testing the software without a predefined plan or script, using the tester's creativity, intuition, and experience to discover defects or issues.
