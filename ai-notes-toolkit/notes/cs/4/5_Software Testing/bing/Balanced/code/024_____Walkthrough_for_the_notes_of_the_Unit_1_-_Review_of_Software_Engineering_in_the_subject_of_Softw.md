### Walkthrough for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Software engineering is the application of engineering principles and practices to the development and maintenance of software systems that meet the needs and expectations of stakeholders.
- Software engineering involves activities such as requirements analysis, design, implementation, testing, deployment, maintenance, and evolution.
- Software engineering is guided by standards, methodologies, models, processes, tools, and best practices that aim to improve the quality, productivity, and reliability of software systems.
- Software testing is a software engineering activity that involves checking whether a software system meets its specifications and satisfies its intended purpose.
- Software testing can be performed at different levels of abstraction, such as unit testing, integration testing, system testing, and acceptance testing.
- Software testing can also be classified according to the type of testing technique, such as black-box testing, white-box testing, or grey-box testing.
- Software testing can be conducted in different phases of the software development life cycle, such as verification testing, validation testing, or regression testing.
- Software testing can be performed manually or automatically, using tools and frameworks that support test design, execution, and evaluation.
- Software testing can be influenced by various factors, such as the software quality attributes, the software development model, the software testing objectives, the software testing strategies, and the software testing metrics.
