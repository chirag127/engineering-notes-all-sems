### Verification for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Verification is the process of checking whether the software meets the specified requirements and design specifications.
- Verification can be done by various methods, such as reviews, inspections, walkthroughs, audits, and testing.
- Verification can be performed at different stages of the software development life cycle, such as planning, analysis, design, coding, testing, and maintenance.
- Verification can be classified into two types: static verification and dynamic verification.
- Static verification is the process of checking the software artifacts without executing them, such as requirements, design documents, code, test cases, etc.
- Static verification can be done by manual or automated techniques, such as peer reviews, static analysis tools, code quality metrics, etc.
- Static verification can help to detect errors, inconsistencies, ambiguities, and deviations from standards and best practices in the software artifacts.
- Static verification can also help to improve the quality, readability, maintainability, and reusability of the software artifacts.
- Dynamic verification is the process of checking the software behavior by executing it, such as unit testing, integration testing, system testing, acceptance testing, etc.
- Dynamic verification can be done by manual or automated techniques, such as test cases, test scripts, test data, test tools, etc.
- Dynamic verification can help to detect faults, failures, defects, and bugs in the software functionality, performance, usability, security, reliability, etc.
- Dynamic verification can also help to validate the software against the user expectations, business needs, and operational environment.
- Verification is an important activity in software engineering, as it can help to ensure the quality, correctness, completeness, and consistency of the software product.
- Verification can also help to reduce the cost, time, and effort of software development, testing, and maintenance, by identifying and correcting the errors and defects early in the software development life cycle.
