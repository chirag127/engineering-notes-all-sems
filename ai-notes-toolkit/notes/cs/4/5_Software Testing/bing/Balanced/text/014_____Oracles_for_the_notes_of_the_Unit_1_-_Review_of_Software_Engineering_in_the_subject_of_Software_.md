### Oracles

- An oracle is a mechanism for determining whether a test has passed or failed.
- An oracle can be a source of information about the expected output of a program for a given input .
- An oracle can be a person, a document, a specification, a tool, or another program.
- An oracle can specify the exact output values or only some constraints or properties of them.
- An oracle can be complete or partial, consistent or inconsistent, correct or incorrect, explicit or implicit.
- An oracle can be derived from various sources, such as requirements, design, code, user expectations, domain knowledge, or intuition .
- An oracle can be used to check the functional correctness, performance, usability, security, or reliability of a program .
- An oracle can be static or dynamic, deterministic or probabilistic, exact or approximate, automated or manual .
- An oracle can be hard to find, design, implement, or maintain .
- An oracle can be heuristic, meaning it is fallible and may not always provide the right answer.
