### Test for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- The test consists of 10 multiple-choice questions based on the notes of the Unit 1 - Review of Software Engineering.
- Each question has four options, only one of which is correct.
- The test is timed and has a duration of 15 minutes.
- The test covers the following topics from the notes:

  - Software engineering definition and objectives
  - Software engineering process models
  - Software engineering activities and tasks
  - Software engineering principles and standards
  - Software engineering challenges and trends

- The test is designed to assess the following learning outcomes:

  - Explain the meaning and importance of software engineering
  - Compare and contrast different software engineering process models
  - Identify and describe the main software engineering activities and tasks
  - Apply software engineering principles and standards to software development
  - Analyze the current and future challenges and trends in software engineering

- The test is scored based on the number of correct answers. Each correct answer is worth one point. There is no negative marking for incorrect or unanswered questions.
- The test results will be displayed at the end of the test along with the correct answers and explanations.
- The test can be taken only once and cannot be repeated or reviewed.
- The test is confidential and should not be shared or discussed with anyone else.
