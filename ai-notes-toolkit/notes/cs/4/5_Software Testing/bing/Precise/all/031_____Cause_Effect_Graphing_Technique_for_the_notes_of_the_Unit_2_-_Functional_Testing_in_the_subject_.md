### Cause Effect Graphing Technique

Cause Effect Graphing Technique is a black box testing technique used in functional testing. It is a graphical representation of inputs and the associated outputs effects which can be used to design test cases.

Here are some key points to note about Cause Effect Graphing Technique:

1. It helps to identify the possible causes and effects of a system.
2. It is used to reduce the number of test cases by eliminating redundant test cases.
3. It is based on the principle that for every input condition, there is an associated output condition.
4. It is also known as Ishikawa diagram or Fishbone diagram.
5. It is useful for complex systems where the number of inputs and outputs is large.
6. It helps to identify the root cause of a problem in the system.

In summary, Cause Effect Graphing Technique is a useful tool for designing test cases in functional testing, especially for complex systems with a large number of inputs and outputs. It helps to identify the root cause of a problem and eliminate redundant test cases.
