# Unit 4 - Regression Testing

Regression testing is a type of software testing that ensures that previously developed and tested software still performs the same way after it has been changed or interfaced with other software.

Here are some key points to remember about regression testing:

1. The main goal of regression testing is to ensure that changes to the software do not introduce new defects or break existing functionality.
2. Regression testing can be performed at any level of testing, including unit, integration, system, and acceptance testing.
3. Regression testing can be done manually or automated, depending on the complexity and size of the software.
4. Regression testing is an ongoing process and should be performed regularly as changes are made to the software.
5. Regression testing can be time-consuming and expensive, so it is important to prioritize and select the most important test cases to run.
6. Regression testing can help to catch defects early, reducing the cost and time required to fix them.
