# Unit 6 - Object Oriented Testing

## Issues in Object Oriented Testing

1. **Inheritance**: Inheritance allows the creation of subclasses that share some or all of the characteristics of the parent class. This can create difficulties in testing, as changes in the parent class can affect the behavior of the subclasses.

2. **Polymorphism**: Polymorphism allows objects of different classes to be treated as objects of a common superclass. This can create difficulties in testing, as the behavior of an object can depend on its dynamic type, which may not be known until runtime.

3. **Encapsulation**: Encapsulation hides the internal details of an object from the outside world. This can create difficulties in testing, as it may not be possible to directly access the internal state of an object to verify its correctness.

4. **Complexity**: Object-oriented systems can be more complex than traditional systems, due to the increased number of relationships between objects. This can create difficulties in testing, as it may be difficult to ensure that all possible interactions between objects are tested.

5. **Object State**: Objects in an object-oriented system can have complex internal states, which can change over time. This can create difficulties in testing, as it may be difficult to ensure that an object is in the correct state before a test is performed.

6. **Object Interactions**: Objects in an object-oriented system can interact with each other in complex ways. This can create difficulties in testing, as it may be difficult to ensure that all possible interactions between objects are tested.

7. **Object Identity**: Objects in an object-oriented system can have unique identities, which can affect their behavior. This can create difficulties in testing, as it may be difficult to ensure that objects with the same identity behave in the same way.

8. **Concurrency**: Object-oriented systems can support concurrency, where multiple objects can be active at the same time. This can create difficulties in testing, as it may be difficult to ensure that all possible interactions between concurrent objects are tested.
