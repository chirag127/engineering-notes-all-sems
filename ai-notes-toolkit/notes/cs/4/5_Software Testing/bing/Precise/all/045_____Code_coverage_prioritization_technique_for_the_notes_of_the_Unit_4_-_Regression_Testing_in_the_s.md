# Code Coverage Prioritization Technique

Code coverage prioritization technique is a method used in regression testing to organize test cases in a test suite in an order that allows for faster code coverage and early detection of faults . This technique is based on code coverage, meaning that test cases are prioritized based on their ability to cover the code .

There are several approaches to code coverage prioritization, including:

- **Total Statement Coverage Prioritization**: This technique prioritizes test cases based on the total number of statements covered by the test case .

- **Code Combinations Coverage Based Prioritization (CCCP)**: This technique applies a new coverage criterion to regression test case prioritization, where test cases are prioritized based on their ability to cover code combinations .

Regression testing is performed alongside software development to ensure that new changes do not affect the behavior of unchanged code. Having a good test-case suite that covers the software as a whole can be challenging and costly, as the suite can be large and running all test cases may take a while. Code coverage prioritization techniques can help to select an appropriate number of test cases from a test suite that might expose a fault in the modified program .
