# Terminologies in Testing

Here are some key terminologies in testing that are important to know for the Unit 1 - Review of Software Engineering in the subject of Software Testing:

1. **Test Case**: A test case is a set of conditions or variables under which a tester will determine whether a system under test satisfies requirements or works correctly.

2. **Test Suite**: A test suite is a collection of test cases that are intended to be used to test a software program to show that it has some specified set of behaviors.

3. **Test Plan**: A test plan is a document detailing the objectives, target market, internal beta team, and processes for a specific beta test for a software or hardware product.

4. **Test Scenario**: A test scenario is a hypothetical story that helps a tester think through a complex problem or system.

5. **Test Script**: A test script is a set of instructions that will be performed on the system under test to test that the system functions as expected.

6. **Test Harness**: A test harness is a collection of software and test data configured to test a program unit by running it under varying conditions and monitoring its behavior and outputs.

7. **Test Oracle**: A test oracle is a mechanism for determining whether a test has passed or failed.

8. **Test Driver**: A test driver is a program that sets up and executes a test of a component or system.

9. **Test Stub**: A test stub is a small program that simulates the behavior of a component or system that is not available or not yet developed.

10. **Test Data**: Test data is data that has been specifically identified for use in tests, typically of a computer program.
