## Unit 3 - Structural Testing

Structural testing, also known as white-box testing, is a method of testing software that involves examining the internal structure of the code being tested. This type of testing is typically performed by developers and focuses on the implementation of the software, rather than its functionality.

Some key points to remember about structural testing are:

1. Structural testing is used to verify the internal structure of the code.
2. It is typically performed by developers.
3. It focuses on the implementation of the software, rather than its functionality.
4. Structural testing can help identify issues with the code that may not be apparent through functional testing alone.
5. Common techniques used in structural testing include statement coverage, branch coverage, and path coverage.

In summary, structural testing is an important part of the software development process that can help ensure the quality and reliability of the code being produced. By examining the internal structure of the code, developers can identify and address issues that may not be apparent through functional testing alone.
