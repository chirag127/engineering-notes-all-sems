### Decision Table Based Testing

Decision Table Based Testing is a type of functional testing that is used to test the system behavior for different input combinations. It is a black-box testing technique that is particularly useful when the system has logical conditions that can be expressed in a tabular form.

Here are some key points to remember about Decision Table Based Testing:

1. Decision Table Based Testing is used to test the system behavior for different input combinations.
2. It is a black-box testing technique.
3. It is particularly useful when the system has logical conditions that can be expressed in a tabular form.
4. A decision table is a table that represents the system's behavior for different combinations of inputs.
5. Each column in the decision table represents a unique combination of inputs.
6. Each row in the decision table represents an output or an action that the system should take for the given combination of inputs.
7. Decision Table Based Testing can help to ensure that all possible combinations of inputs have been tested.
8. It can also help to identify any missing or contradictory requirements.
