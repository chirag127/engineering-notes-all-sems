### Generation of Graph from Program

1. The first step in generating a graph from a program is to identify the control flow of the program. This can be done by analyzing the source code and identifying the different paths that can be taken during execution.
2. Once the control flow has been identified, the next step is to represent it in a graphical form. This is typically done using a control flow graph (CFG), which is a directed graph that represents the flow of control within the program.
3. Each node in the CFG represents a basic block, which is a sequence of instructions that are always executed together. The edges between the nodes represent the flow of control between the basic blocks.
4. The CFG can be used to identify the different paths that can be taken during the execution of the program. This information can be used to design test cases that cover all the possible paths, which is an important aspect of structural testing.
5. In addition to the CFG, other types of graphs can also be generated from the program, such as data flow graphs and call graphs. These graphs provide additional information about the program that can be useful for testing and debugging.
