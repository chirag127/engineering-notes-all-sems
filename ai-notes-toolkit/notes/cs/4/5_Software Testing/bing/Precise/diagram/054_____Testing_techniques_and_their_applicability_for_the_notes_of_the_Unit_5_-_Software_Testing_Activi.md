### Testing Techniques and their Applicability

Unit 5 - Software Testing Activities

Subject: Software Testing

1. **Black Box Testing**: This technique is used to test the functionality of the software without knowing its internal structure or code. It is applicable to all levels of testing, including unit, integration, system, and acceptance testing.

2. **White Box Testing**: This technique is used to test the internal structure and code of the software. It is applicable to unit and integration testing.

3. **Gray Box Testing**: This technique combines both black box and white box testing methods. It is applicable to integration and system testing.

4. **Boundary Value Analysis**: This technique is used to test the behavior of the software at the boundary values of its input domain. It is applicable to all levels of testing.

5. **Equivalence Partitioning**: This technique is used to divide the input domain of the software into equivalent classes and test each class. It is applicable to all levels of testing.

6. **Decision Table Testing**: This technique is used to test the software's behavior for different combinations of inputs. It is applicable to system and acceptance testing.

7. **State Transition Testing**: This technique is used to test the software's behavior when it transitions from one state to another. It is applicable to system and acceptance testing.

8. **Use Case Testing**: This technique is used to test the software's behavior for different use cases. It is applicable to system and acceptance testing.

9. **Exploratory Testing**: This technique is used to explore the software and find defects that were not covered by other testing techniques. It is applicable to all levels of testing.

10. **Ad-hoc Testing**: This technique is used to test the software without any formal planning or documentation. It is applicable to all levels of testing.

These are some of the common testing techniques and their applicability in the software testing process. Each technique has its own strengths and weaknesses, and the selection of the appropriate technique depends on the specific requirements and objectives of the testing process.
