### Unit 6 - Object Oriented Testing

Object-oriented testing is a testing technique that is used to test object-oriented software. It is different from traditional testing techniques because it takes into account the unique features of object-oriented software. Some of the issues that arise when testing object-oriented software include:

1. **Inheritance**: Inheritance allows a class to inherit properties and methods from a parent class. This can make it difficult to test the inherited code because it may not be clear which class is responsible for the behavior being tested.

2. **Polymorphism**: Polymorphism allows objects of different classes to be treated as objects of a common superclass. This can make it difficult to test the behavior of an object because the behavior may depend on the class of the object.

3. **Encapsulation**: Encapsulation is the practice of hiding the internal details of an object and providing a public interface for interacting with the object. This can make it difficult to test the internal state of an object because the internal details are hidden.

4. **Complexity**: Object-oriented software can be more complex than traditional software because it involves the interaction of many objects. This can make it difficult to test the software because there may be many possible interactions between objects.

These are some of the issues that arise when testing object-oriented software. It is important to take these issues into account when designing and implementing tests for object-oriented software.
