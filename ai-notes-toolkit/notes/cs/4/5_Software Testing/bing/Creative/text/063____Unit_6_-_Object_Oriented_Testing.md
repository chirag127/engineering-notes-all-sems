## Unit 6 - Object Oriented Testing

- Object oriented testing is a testing technique that focuses on the behavior and structure of objects and classes in an object oriented system.
- Object oriented testing can be divided into two categories: class testing and system testing.
- Class testing is the testing of individual classes and their methods, attributes, and interactions with other classes.
- System testing is the testing of the whole system as a collection of classes and objects that collaborate to achieve the system's functionality and quality attributes.
- Object oriented testing can be performed at different levels of abstraction, such as unit testing, integration testing, and system testing.
- Object oriented testing can use different types of test cases, such as state-based test cases, scenario-based test cases, and fault-based test cases.
- State-based test cases are test cases that check the state and behavior of an object or a class under different inputs and events.
- Scenario-based test cases are test cases that check the functionality and quality of the system by simulating realistic user scenarios and workflows.
- Fault-based test cases are test cases that are designed to expose potential faults or errors in the system by using negative or invalid inputs and events.
- Object oriented testing can use different techniques and tools to support the testing process, such as test design techniques, test coverage criteria, test automation tools, and test metrics.
