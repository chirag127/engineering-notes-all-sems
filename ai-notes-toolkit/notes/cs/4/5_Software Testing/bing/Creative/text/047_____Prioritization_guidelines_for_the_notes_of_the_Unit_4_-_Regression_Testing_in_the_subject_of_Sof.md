### Prioritization guidelines for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

- Regression testing is the process of retesting the modified parts of a software system and ensuring that no new defects have been introduced due to the changes.
- Regression testing is important because it helps to maintain the quality and reliability of the software system, and to avoid the risk of regression bugs that can affect the functionality, performance, security, or usability of the system.
- Regression testing can be performed at different levels of testing, such as unit testing, integration testing, system testing, or acceptance testing, depending on the scope and impact of the changes made to the system.
- Regression testing can be done manually or automatically, depending on the availability of test cases, test tools, test resources, and test time. Automated regression testing is preferred over manual regression testing because it can save time, effort, and cost, and can increase the test coverage and accuracy.
- Regression testing can be classified into three types: retest all, selective, and test suite minimization. Retest all is the simplest and most comprehensive type of regression testing, where all the existing test cases are executed again after any change to the system. Selective regression testing is the most common and practical type of regression testing, where only a subset of test cases that are relevant to the changes are executed. Test suite minimization is the most advanced and efficient type of regression testing, where the test cases are reduced to the minimum number that can cover all the affected parts of the system.
- Regression testing can be prioritized based on various criteria, such as the severity of the changes, the frequency of the changes, the complexity of the changes, the dependency of the changes, the risk of the changes, the criticality of the system, the customer requirements, the business value, the test resources, and the test time. Prioritization can help to optimize the regression testing process and to focus on the most important and relevant test cases.
- Regression testing can be supported by various techniques, tools, and strategies, such as regression test selection, regression test coverage, regression test oracle, regression test automation, regression test maintenance, regression test reporting, and regression test management. These can help to improve the effectiveness and efficiency of the regression testing process and to ensure the quality and reliability of the software system.
