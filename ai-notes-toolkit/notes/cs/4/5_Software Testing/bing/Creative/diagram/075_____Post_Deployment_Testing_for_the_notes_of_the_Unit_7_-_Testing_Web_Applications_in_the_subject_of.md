### Post Deployment Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

- Post deployment testing is a type of testing in which the software is tested after it is being deployed to production.
- The purpose of post deployment testing is to ensure that the software functions as intended in the real environment and meets the user expectations and requirements.
- Post deployment testing involves the following activities  :
  - Post-deployment verification: The QA or Test lead verifies the software application as per the test plans and test cases and compares them with the previous or existing ones.
  - User acceptance testing: The end users or stakeholders test the software application and provide feedback on its usability, functionality, performance, and quality.
  - Smoke testing: The basic functionality of the software application is tested to ensure that it is stable and ready for further testing.
  - Regression testing: The existing functionality of the software application is tested to ensure that it is not affected by the new changes or updates.
  - Performance testing: The speed, scalability, reliability, and resource consumption of the software application are tested to ensure that it meets the expected standards and SLAs.
  - Security testing: The security aspects of the software application are tested to ensure that it is protected from unauthorized access, data breaches, and malicious attacks.
  - Monitoring: The software application is monitored for its availability, performance, errors, and usage statistics to identify and resolve any issues or anomalies.
- Post deployment testing can be done using various strategies, such as:
  - Rolling update deployment: A subset of running application instances is updated instead of simultaneously updating every application instance.
  - Blue-green deployment: Two identical environments are created, one for production and one for testing. The traffic is switched between them after testing is completed.
  - Canary deployment: A small percentage of users are exposed to the new version of the software application and their feedback is collected before rolling out to the rest of the users.
  - Feature flags: A feature or functionality is enabled or disabled for a specific group of users or conditions using a configuration setting.
- Post deployment testing is an essential part of the software development life cycle and helps to ensure the quality, reliability, and user satisfaction of the software application.
