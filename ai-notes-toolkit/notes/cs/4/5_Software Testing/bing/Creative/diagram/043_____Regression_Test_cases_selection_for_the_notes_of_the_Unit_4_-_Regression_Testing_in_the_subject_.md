# Regression Test Cases Selection

Regression testing is the process of retesting the modified parts of a software system and ensuring that no new defects have been introduced due to the changes. Regression testing can be done at different levels of testing, such as unit, integration, system, or acceptance testing.

Regression test cases selection is the activity of choosing a subset of test cases from the existing test suite to perform regression testing. The main goal of regression test cases selection is to reduce the cost and time of regression testing while maintaining the effectiveness and coverage of the test suite.

There are different techniques and criteria for regression test cases selection, such as:

- **Retest all**: This technique involves retesting all the test cases in the test suite, regardless of the changes made to the software. This technique ensures the highest coverage and effectiveness, but it is also the most expensive and time-consuming technique.
- **Retest modified**: This technique involves retesting only the test cases that are directly affected by the changes made to the software. This technique reduces the cost and time of regression testing, but it may miss some defects that are indirectly affected by the changes.
- **Retest modified and related**: This technique involves retesting the test cases that are directly or indirectly affected by the changes made to the software. This technique considers the dependencies and relationships among the test cases, such as data flow, control flow, or call graph. This technique improves the effectiveness and coverage of regression testing, but it may also increase the cost and time of regression testing.
- **Retest prioritized**: This technique involves retesting the test cases that are prioritized based on some criteria, such as risk, severity, frequency, or history of failure. This technique aims to maximize the fault detection rate and minimize the cost and time of regression testing. However, this technique may require additional effort and information to prioritize the test cases.

Some of the factors that influence the regression test cases selection are:

- **The scope and impact of the changes**: The more extensive and complex the changes are, the more test cases may need to be retested to ensure the quality of the software.
- **The size and complexity of the test suite**: The larger and more complex the test suite is, the more difficult and time-consuming it may be to select the appropriate test cases for regression testing.
- **The availability and reliability of the test oracle**: The test oracle is the mechanism or source that determines the expected outcome of a test case. The availability and reliability of the test oracle may affect the feasibility and accuracy of regression testing.
- **The resources and constraints of the testing environment**: The resources and constraints of the testing environment, such as time, budget, personnel, or tools, may limit the scope and frequency of regression testing.
