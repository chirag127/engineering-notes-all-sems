## Unit 2 - Functional Testing

- Functional testing is a type of software testing that verifies that the software performs its intended functions according to the requirements and specifications.
- Functional testing involves testing the software against a set of predefined inputs, outputs, and expected behaviors.
- Functional testing can be performed at different levels of software development, such as unit testing, integration testing, system testing, and acceptance testing.
- Functional testing can be done manually or with the help of automated tools.
- Functional testing can be classified into different types, such as black-box testing, white-box testing, and gray-box testing.
- Black-box testing is a type of functional testing that focuses on the external behavior of the software, without considering its internal structure or implementation details.
- White-box testing is a type of functional testing that focuses on the internal structure and logic of the software, using the knowledge of the source code and design.
- Gray-box testing is a type of functional testing that combines both black-box and white-box techniques, using partial knowledge of the software's internal structure and behavior.
- Functional testing can also be categorized into different techniques, such as equivalence partitioning, boundary value analysis, decision table testing, state transition testing, use case testing, and exploratory testing.
- Equivalence partitioning is a technique that divides the input domain of the software into a number of equivalent classes, such that each class represents a set of inputs that produce the same output or behavior.
- Boundary value analysis is a technique that tests the software at the boundary values of the input domain, such as the minimum, maximum, and edge cases, to identify any errors or defects.
- Decision table testing is a technique that uses a table to represent the combinations of inputs and outputs for the software, based on the rules and conditions that govern its behavior.
- State transition testing is a technique that tests the software based on its states and transitions, using a state diagram or a state table to model its behavior.
- Use case testing is a technique that tests the software based on the use cases or scenarios that describe the interactions between the software and its users or other systems.
- Exploratory testing is a technique that tests the software without any predefined test cases or scripts, using the tester's creativity and intuition to explore the software's functionality and discover any errors or defects.
