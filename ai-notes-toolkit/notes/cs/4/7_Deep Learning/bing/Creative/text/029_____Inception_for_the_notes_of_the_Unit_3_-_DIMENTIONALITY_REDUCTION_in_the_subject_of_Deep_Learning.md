### Inception for the notes of the Unit 3 - DIMENTIONALITY REDUCTION in the subject of Deep Learning

- Inception is a deep learning model based on convolutional neural networks (CNNs) that was introduced by Google in 2014 .
- Inception aims to reduce the computational cost of CNNs by using different types of convolutional filters in parallel, such as 1x1, 3x3, 5x5, and max pooling, to capture different features at different scales.
- Inception also uses 1x1 convolutions to reduce the number of channels before applying larger convolutions, which reduces the number of parameters and computations.
- Inception has several versions, such as Inception V1 (also known as GoogLeNet), Inception V2, Inception V3, and Inception V4, each with improved performance and efficiency  .
- Inception V3 is the third version of Inception, which was released in 2015. It has 48 layers and uses batch normalization, factorized convolutions, label smoothing, and auxiliary classifiers .
- Inception V3 achieved a top-5 error rate of 3.46% on the ImageNet dataset, which is a benchmark for image classification and detection .
- Inception can be used for dimensionality reduction by extracting features from the last convolutional layer or the last fully connected layer, which can be fed into other classifiers or clustering algorithms .
