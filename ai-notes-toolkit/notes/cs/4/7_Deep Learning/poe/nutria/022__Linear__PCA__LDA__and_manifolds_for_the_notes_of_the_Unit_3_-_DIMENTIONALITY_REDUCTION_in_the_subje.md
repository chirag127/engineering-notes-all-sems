
### Linear (PCA, LDA) and Manifolds

1. Principal Component Analysis (PCA) is a linear transformation technique used to reduce the dimensionality of data. It works by finding the directions of maximum variance in the data and projecting the data onto a lower-dimensional space.

2. Linear Discriminant Analysis (LDA) is a linear transformation technique used for supervised learning. It works by finding the directions of maximum class separability in the data and projecting the data onto a lower-dimensional space.

3. Manifolds are mathematical objects used to represent data in high-dimensional spaces. They can be used to reduce the dimensionality of data by transforming it into a lower-dimensional space.

4. Dimensionality reduction is the process of reducing the number of features (or dimensions) in a dataset. This can be done by either removing features or by projecting the data onto a lower-dimensional space.

5. PCA and LDA are two techniques used for dimensionality reduction. PCA is an unsupervised technique, while LDA is a supervised technique.

6. Manifolds can also be used for dimensionality reduction. They are often used to represent data in high-dimensional spaces and can be used to reduce the dimensionality of data by transforming it into a lower-dimensional space.
