
### ResNet for the Notes of Unit 3 - Dimensionality Reduction in Deep Learning

1. **ResNet** stands for **Residual Network** and is a type of convolutional neural network (CNN) architecture developed by Microsoft Research.

2. ResNet is designed to reduce the number of parameters in a CNN by using a residual learning framework. This allows for deeper networks to be trained without the need for additional layers, as the residuals can be reused.

3. ResNet also utilizes batch normalization, which helps to reduce the internal covariate shift in the network and increase the speed of training.

4. The ResNet architecture consists of multiple layers of convolutional and pooling layers, followed by a fully connected layer. The convolutional layers are used to extract the features from the input image, while the pooling layers are used to reduce the dimensionality of the feature maps.

5. The fully connected layer is used to classify the image based on the extracted features. The output of the network is a probability distribution over the labels.

6. Dimensionality reduction is an important part of the ResNet architecture. It is used to reduce the number of parameters in the network, which helps to reduce the computational cost of training the network.

7. Dimensionality reduction can be achieved by using either principal component analysis (PCA) or singular value decomposition (SVD). PCA is used to reduce the dimensionality of the feature maps, while SVD is used to reduce the number of parameters in the fully connected layer.

8. The ResNet architecture has been used to achieve state-of-the-art performance in image classification tasks. It has also been used for other tasks such as object detection, semantic segmentation, and medical image analysis.
