
### Architectures for the Notes of Unit 3 - Dimensionality Reduction in the Subject of Deep Learning

1. Principal Component Analysis (PCA): PCA is a technique used to reduce the dimensionality of a dataset by projecting it onto a lower-dimensional subspace. It is a linear transformation technique that uses the eigenvectors of the covariance matrix of the data to determine the directions of the new subspace.

2. Linear Discriminant Analysis (LDA): LDA is a supervised technique used to project data onto a lower-dimensional subspace while preserving class separability. It is a linear transformation technique that uses the eigenvectors of the between-class scatter matrix and the within-class scatter matrix to determine the directions of the new subspace.

3. Autoencoders: Autoencoders are a type of neural network used to reduce the dimensionality of a dataset. They are composed of an encoder and a decoder, which are both trained on the same dataset. The encoder maps the input data into a lower-dimensional latent space, while the decoder reconstructs the input data from the latent space.

4. Generative Adversarial Networks (GANs): GANs are a type of neural network used to generate new data points from a given dataset. They are composed of two networks, a generator and a discriminator. The generator creates new data points from a given dataset, while the discriminator evaluates the generated data points and determines whether they are real or fake.
