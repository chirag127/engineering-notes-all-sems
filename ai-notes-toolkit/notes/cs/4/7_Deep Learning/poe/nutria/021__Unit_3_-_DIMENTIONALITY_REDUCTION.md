
## Unit 3 - DIMENTIONALITY REDUCTION

1. Dimensionalty reduction is a process of reducing the number of random variables under consideration, while retaining the essential characteristics of the data set. 
2. It is mainly used for data visualization and for reducing the time and storage space needed for data processing.
3. There are two main types of dimensionalty reduction: feature selection and feature extraction. 
4. Feature selection involves selecting a subset of the original features in the data set, while feature extraction involves transforming the data into a new set of features.
5. Principal Component Analysis (PCA) is a commonly used technique for feature extraction. It involves transforming the data set into a new set of variables, which are a linear combination of the original variables. 
6. PCA is used to reduce the dimensionality of a data set while preserving the essential characteristics of the data.
7. Other popular techniques for dimensionalty reduction include Linear Discriminant Analysis (LDA), Independent Component Analysis (ICA), and Singular Value Decomposition (SVD). 
8. These techniques are used to reduce the dimensionality of a data set while preserving the structure of the data. 
9. Dimensionalty reduction can also be used to reduce the complexity of a data set, making it easier to interpret and analyze.
