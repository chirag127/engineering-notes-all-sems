
### Non-Convex Optimization for Deep Networks 

1. Non-convex optimization is an important tool in the field of deep learning, as it helps to find the optimal parameters of a deep network. 
2. Non-convex optimization algorithms are used to minimize the loss function of a deep network, which is a measure of how well the network is performing. 
3. The most popular non-convex optimization algorithms are gradient descent, stochastic gradient descent, and Adam. 
4. These algorithms use the gradient of the loss function to update the parameters of the deep network. 
5. Gradient descent is a first-order optimization algorithm which updates the parameters of the deep network by taking a step in the direction of steepest descent. 
6. Stochastic gradient descent is an extension of gradient descent which uses a randomly chosen subset of the training data to update the parameters of the deep network. 
7. Adam is an adaptive optimization algorithm which uses an adaptive learning rate and momentum to update the parameters of the deep network. 
8. Other non-convex optimization algorithms such as Newton's method, conjugate gradient, and quasi-Newton methods can also be used to optimize a deep network. 
9. These algorithms use the second-order derivatives of the loss function to update the parameters of the deep network. 
10. Regularization techniques such as weight decay and dropout can also be used to improve the performance of a deep network.
