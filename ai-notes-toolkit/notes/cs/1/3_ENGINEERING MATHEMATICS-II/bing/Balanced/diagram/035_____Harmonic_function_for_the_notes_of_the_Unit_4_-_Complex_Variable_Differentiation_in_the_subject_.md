### Harmonic Function

- A function u(x, y) is called **harmonic** if it is twice continuously differentiable and satisfies the following partial differential equation :

$$\nabla^2 u = u_{xx} + u_{yy} = 0$$

- This equation is called **Laplace's equation** and it is one of the most important equations in mathematics, physics and engineering.

- Harmonic functions occur frequently and play an essential role in these domains. In complex analysis, harmonic functions are called the solutions of the Laplace equation.

- Harmonic functions have many properties that make them useful and interesting. Some of these properties are  :

  - Every harmonic function is **analytic**, that is, it can be locally expressed as power series. This is a general fact about elliptic operators, of which the Laplacian is a major example.

  - If $f(z) = u(x, y) + iv(x, y)$ is analytic on a region $A$, then both $u$ and $v$ are harmonic functions on $A$. Conversely, if $u(x, y)$ is harmonic on a connected region $A$, then $u$ is the real part of an analytic function $f(z) = u(x, y) + iv(x, y)$ .

  - The **maximum principle** states that a harmonic function cannot have a local maximum or minimum in the interior of its domain, unless it is constant. This implies that the boundary values of a harmonic function determine its behavior in the interior.

  - The **mean value property** states that the value of a harmonic function at any point is equal to the average of its values on any circle centered at that point. This property can be generalized to higher dimensions and other shapes.

  - Harmonic functions are **conformal**, that is, they preserve angles and shapes locally. This means that they can be used to map one domain to another in a way that preserves the geometry.

  - Harmonic functions are **unique**, that is, there is only one harmonic function that satisfies a given set of boundary conditions. This follows from the maximum principle and the mean value property.

  - Harmonic functions are **stable**, that is, small changes in the boundary values or the domain do not cause large changes in the harmonic function. This makes them suitable for modeling physical phenomena that are governed by Laplace's equation, such as heat conduction, electrostatics, fluid flow, etc.
