### Simultaneous linear differential equations

- A simultaneous differential equation is one of the mathematical equations for an indefinite function of one or more than one variables that relate the values of the function.
- A simultaneous linear differential equation is a system of two or more linear differential equations that involve the same independent variable and the same dependent variables.
- A general form of a system of n simultaneous linear differential equations is:

$$
\begin{cases}
a_{11}(x)\frac{dy_1}{dx} + a_{12}(x)\frac{dy_2}{dx} + \cdots + a_{1n}(x)\frac{dy_n}{dx} = f_1(x)\\
a_{21}(x)\frac{dy_1}{dx} + a_{22}(x)\frac{dy_2}{dx} + \cdots + a_{2n}(x)\frac{dy_n}{dx} = f_2(x)\\
\vdots\\
a_{n1}(x)\frac{dy_1}{dx} + a_{n2}(x)\frac{dy_2}{dx} + \cdots + a_{nn}(x)\frac{dy_n}{dx} = f_n(x)
\end{cases}
$$

where $a_{ij}(x)$ and $f_i(x)$ are given functions of $x$, and $y_1, y_2, \ldots, y_n$ are the unknown functions to be determined.

- A solution of a system of simultaneous linear differential equations is a set of functions $y_1, y_2, \ldots, y_n$ that satisfy all the equations in the system for all values of $x$ in a given interval.
- A system of simultaneous linear differential equations can be solved by various methods, such as elimination, substitution, matrix method, or Laplace transform method  .
- Simultaneous linear differential equations can be used to model various real-life problems, such as electric circuits, mechanical vibrations, population dynamics, chemical reactions, etc .
