### Op-Amp Basics

- An op-amp (operational amplifier) is a device that amplifies the difference between two input voltages and produces a single output voltage.
- An op-amp has two input terminals, labeled as V+ (non-inverting input) and V- (inverting input), and one output terminal, labeled as Vout .
- An op-amp also has two power supply terminals, labeled as Vs+ (positive supply) and Vs- (negative supply), which provide the maximum and minimum output voltages respectively.
- An op-amp can be considered as a differential-to-single-ended converter, since it converts a differential input signal (V+ - V-) to a single-ended output signal (Vout).
- An op-amp has a very high open-loop gain, which means that the output voltage is proportional to the input voltage difference multiplied by a large constant. The open-loop gain is usually denoted by A or AOL.
- An op-amp has a very high input impedance, which means that it draws very little current from the input sources. The input impedance is usually denoted by Zin.
- An op-amp has a very low output impedance, which means that it can drive a large current to the load without losing much voltage. The output impedance is usually denoted by Zout.
- An op-amp has a very high common-mode rejection ratio (CMRR), which means that it ignores any voltage component that is common to both input signals, such as noise or DC offset. The CMRR is usually denoted by R or CMRR.
- An op-amp can be used in various configurations, such as inverting amplifier, non-inverting amplifier, summing amplifier, difference amplifier, integrator, differentiator, comparator, etc .
