### Introduction of Basic and Universal Gates

- A logic gate is a device that performs a basic logical operation on one or more binary inputs and produces a single binary output.
- There are three basic logic gates: AND, OR, and NOT. These gates can be used to implement any Boolean function or logic expression.
- AND gate: It has two or more inputs and one output. The output is 1 only when all the inputs are 1, otherwise it is 0.
- OR gate: It has two or more inputs and one output. The output is 1 when at least one of the inputs is 1, otherwise it is 0.
- NOT gate: It has one input and one output. The output is the complement of the input, i.e., 0 becomes 1 and 1 becomes 0.
- There are two universal logic gates: NAND and NOR. These gates can be used to implement any other logic gate or Boolean function by using different combinations of them.
- NAND gate: It is the negation of the AND gate, i.e., the output is 0 only when all the inputs are 1, otherwise it is 1.
- NOR gate: It is the negation of the OR gate, i.e., the output is 0 when at least one of the inputs is 1, otherwise it is 1.
