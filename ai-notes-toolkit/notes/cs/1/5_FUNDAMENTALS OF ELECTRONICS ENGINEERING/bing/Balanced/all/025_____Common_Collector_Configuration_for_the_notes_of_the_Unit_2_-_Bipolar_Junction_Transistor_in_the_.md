# Common Collector Configuration

- Common collector configuration is one of the three basic single-stage bipolar junction transistor (BJT) amplifier topologies, typically used as a voltage buffer.
- In this configuration, the base terminal of the transistor serves as the input, the emitter terminal is the output and the collector terminal is common for both input and output. Hence, it is named as common collector configuration .
- The common collector configuration is also known as grounded collector configuration, because the collector terminal is usually grounded.
- The common collector configuration is also referred to as emitter follower or voltage follower, because the output voltage follows the input voltage with a small voltage drop across the base-emitter junction .
- The key characteristics of a common collector amplifier are:
  - A high input impedance, which means that the input current is very small and the input signal is not significantly loaded.
  - A low output impedance, which means that the output voltage is not affected by the load resistance and the output can drive a large current.
  - A non-inverting voltage gain of approximately one, which means that the output voltage is almost equal to the input voltage, except for a small voltage drop of about 0.7 V for silicon transistors.
  - A high current gain, which means that the output current is much larger than the input current, depending on the transistor parameters.
- The common collector configuration is useful for applications that require impedance matching, such as connecting a high impedance source to a low impedance load, or for driving low impedance devices, such as speakers or LEDs.
