### Number system & representation

1. Decimal number system: Base 10, uses 10 digits (0-9). Commonly used number system.
2. Binary number system: Base 2, uses only 0s and 1s. Used in digital electronics to represent ON/OFF electrical states.
3. Octal number system: Base 8, uses 8 digits (0-7).
4. Hexadecimal number system: Base 16, uses 16 digits (0-9, A-F). Useful for representing binary numbers in a more compact way.

Number representation:
- Decimal: 123
- Binary: 01111011
- Octal: 173
- Hexadecimal: 7B

Decimal to other base conversions:
Divide the decimal number successively by the base and note down the remainders in reverse order.
For example:
Decimal 57 to binary:
57 / 2 = 28 R 1   (Write 1)
28 / 2 = 14 R 0   (Write 0)
14 / 2 =  7 R 0   (Write 0)
7 / 2 =  3 R 1   (Write 1)
3 / 2 =  1 R 1   (Write 1)
1 / 2 =  0 R 1   (Write 1)
Binary = 111001

Similar procedure for decimal to octal/hexadecimal conversion.
