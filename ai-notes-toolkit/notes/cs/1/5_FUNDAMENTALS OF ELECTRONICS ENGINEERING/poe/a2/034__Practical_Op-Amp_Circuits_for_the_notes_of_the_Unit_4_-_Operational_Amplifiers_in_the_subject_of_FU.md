### Practical Op-Amp Circuits

- Inverting Amplifier: The inverting amplifier uses negative feedback to reduce the gain error and improve linearity. The gain is set by the feedback resistor (Rf) and input resistor (Rin) ratio.
- Non-Inverting Amplifier: The non-inverting amplifier has a gain set by the external resistors and does not invert the input signal. The input resistor (Rin) provides input bias current compensation.
- Comparator: The comparator uses an open-loop configuration with a very high gain to switch the output between two states based on the input. It converts an analog input to a digital output.
- Integrator: The integrator uses a capacitor feedback loop to produce an output voltage proportional to the integral of the input. It converts the input voltage to a corresponding current or charge.
- Differentiator: The differentiator uses a capacitor feedback loop to produce an output voltage proportional to the derivative of the input. It converts the input voltage to a corresponding voltage or current rate of change.
- Voltage Follower: The voltage follower has a gain of 1 and high input impedance with low output impedance. It isolates the input from the output and prevents loading.
- Summing Amplifier: The summing amplifier adds multiple input voltages after scaling by input resistors. The gains of the inputs are inversely proportional to the input resistor values.
