### Common Emitter

- In common emitter configuration, the emitter terminal is common to both input and output.
- The input is applied between the base and emitter terminals and the output is taken across the collector and emitter terminals.
- The input characteristics show that the base current controls the collector current. A small change in base current results in a large change in collector current. Hence, the common emitter configuration exhibits voltage amplification.
- The voltage gain in CE configuration is called as Beta or Current gain and is given by β = Ic/Ib.
- The output characteristics of a common emitter transistor show that collector-emitter voltage, Vce for a given collector current, Ic can be varied by changing the base current, Ib. This is used to amplify the signal.
- Some key features of common emitter configuration are:
-- Voltage amplification
-- Good input impedance (due to base biasing)
-- Medium output impedance (due to collector resistance)
-- 180° phase shift between input and output
-- Mostly used for transistor amplifier circuits.
