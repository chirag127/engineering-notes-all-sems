
### Inverting Amplifier 

* An inverting amplifier is an operational amplifier circuit configuration that produces an output voltage which is 180° out of phase with the input voltage. 
* An inverting amplifier is used to amplify an input voltage signal while also changing its polarity. 
* The gain of an inverting amplifier is determined by the ratio of the feedback resistor to the input resistor.
* The feedback resistor is a resistor placed between the output of the amplifier and the inverting input of the amplifier. 
* The input resistor is a resistor placed between the input signal and the inverting input of the amplifier.
* The output voltage of an inverting amplifier is equal to the product of the gain and the input voltage. 
* An inverting amplifier can be used to create a bandpass filter, a low-pass filter, or a high-pass filter. 
* An inverting amplifier can also be used to create an active integrator or an active differentiator.
