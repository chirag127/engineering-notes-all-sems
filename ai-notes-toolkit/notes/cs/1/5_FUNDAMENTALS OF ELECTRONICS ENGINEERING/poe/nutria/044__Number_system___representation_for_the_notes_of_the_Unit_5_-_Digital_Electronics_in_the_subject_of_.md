
### Number System & Representation for the Notes of the Unit 5 - Digital Electronics in the Subject of FUNDAMENTALS OF ELECTRONICS ENGINEERING

1. Binary Number System: This system is based on two digits 0 and 1. It is the most widely used system in digital electronics. 
2. Decimal Number System: This system is based on ten digits from 0 to 9. It is used for calculations in everyday life. 
3. Hexadecimal Number System: This system is based on sixteen digits from 0 to 9 and A to F. It is used for representing large binary numbers. 
4. Octal Number System: This system is based on eight digits from 0 to 7. It is used for representing binary numbers in a more compact form. 
5. BCD (Binary Coded Decimal) Number System: This system is based on a combination of binary and decimal digits. It is used for representing decimal numbers in a binary form. 
6. Gray Code Number System: This system is based on a sequence of numbers in which only one bit changes between adjacent numbers. It is used for representing binary numbers in a more efficient manner. 
7. ASCII (American Standard Code for Information Interchange) Code: This system is based on a combination of binary and alphanumeric codes. It is used for representing text and symbols in digital form.
