## Unit-1: 8

### Topic: Introduction to Computer Hardware

1. Computer hardware refers to the physical components of a computer system, including the central processing unit (CPU), memory, storage devices, input/output devices, and other peripherals.
2. The CPU is the brain of the computer, responsible for executing instructions and processing data. It consists of the control unit, arithmetic and logic unit (ALU), and registers.
3. Memory, also known as random access memory (RAM), is a type of volatile memory that temporarily stores data and instructions for the CPU to access quickly.
4. Storage devices, such as hard disk drives (HDDs) and solid-state drives (SSDs), provide non-volatile storage for data and programs.
5. Input/output devices, such as keyboards, mice, monitors, and printers, allow users to interact with and receive output from the computer system.
6. Other peripherals, such as speakers, webcams, and scanners, provide additional functionality to the computer system.
7. The motherboard is the main circuit board in a computer system, connecting all the components and providing power and communication between them.
8. Computer hardware can be classified into two main categories: internal components and external components.
9. Internal components are those that are installed inside the computer case, while external components are those that are connected to the computer system through ports or cables.
10. Understanding computer hardware is essential for troubleshooting and upgrading computer systems, as well as for selecting and purchasing new computer systems.
