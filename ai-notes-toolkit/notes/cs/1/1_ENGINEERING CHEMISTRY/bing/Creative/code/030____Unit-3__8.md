- Unit-3: 8 is a topic that covers the basics of **linear algebra**, which is a branch of mathematics that deals with **vectors**, **matrices**, **systems of linear equations**, and **linear transformations**.
- Some of the main concepts and definitions in this topic are:

  - A **vector** is an ordered list of numbers that can represent a point, a direction, a force, or any other quantity that has both magnitude and direction. For example, `[2, 3, -1]` is a vector with three components.
  - A **matrix** is a rectangular array of numbers that can represent a collection of vectors, a system of linear equations, a linear transformation, or any other operation that involves multiple vectors. For example, `[[1, 2], [3, 4]]` is a matrix with two rows and two columns.
  - A **system of linear equations** is a set of equations that can be written in the form `Ax = b`, where `A` is a matrix, `x` is a vector of unknowns, and `b` is a vector of constants. For example, `[[1, 2], [3, 4]]x = [5, 6]` is a system of two linear equations with two unknowns.
  - A **linear transformation** is a function that maps one vector space to another vector space, and preserves the properties of vector addition and scalar multiplication. For example, `T(x) = Ax` is a linear transformation that maps a vector `x` to a vector `Ax`, where `A` is a matrix.

- Some of the main operations and properties in this topic are:

  - **Vector addition** is the operation of adding two vectors component-wise, resulting in a new vector. For example, `[2, 3, -1] + [1, -2, 4] = [3, 1, 3]`.
  - **Scalar multiplication** is the operation of multiplying a vector by a number, resulting in a new vector. For example, `2 * [2, 3, -1] = [4, 6, -2]`.
  - **Dot product** is the operation of multiplying two vectors component-wise and summing up the results, resulting in a number. For example, `[2, 3, -1] * [1, -2, 4] = 2 * 1 + 3 * (-2) + (-1) * 4 = -9`.
  - **Matrix multiplication** is the operation of multiplying a matrix by another matrix or a vector, resulting in a new matrix or vector. For example, `[[1, 2], [3, 4]] * [5, 6] = [1 * 5 + 2 * 6, 3 * 5 + 4 * 6] = [17, 39]`.
  - **Matrix transpose** is the operation of swapping the rows and columns of a matrix, resulting in a new matrix. For example, `[[1, 2], [3, 4]]^T = [[1, 3], [2, 4]]`.
  - **Matrix inverse** is the operation of finding a matrix that, when multiplied by the original matrix, results in the identity matrix, if such a matrix exists. For example, `[[1, 2], [3, 4]]^-1 = [[-2, 1], [1.5, -0.5]]`, because `[[1, 2], [3, 4]] * [[-2, 1], [1.5, -0.5]] = [[1, 0], [0, 1]]`.
  - **Matrix determinant** is a number that measures the area or volume of the parallelogram or parallelepiped spanned by the columns or rows of a matrix. For example, `det([[1, 2], [3, 4]]) = 1 * 4 - 2 * 3 = -2`.
  - **Matrix rank** is the number of linearly independent columns or rows of a matrix. For example, `rank([[1, 2], [3, 4]]) = 2`, because the columns `[1, 3]` and `[2, 4]` are linearly independent.
