# Proximate and Ultimate Analysis Method

- Proximate analysis is the technique used to analyze the compounds in a mixture, such as coal, biomass, or biogas.
- Ultimate analysis is the technique used to analyze the elements present in a compound, such as carbon, hydrogen, nitrogen, sulfur, and oxygen.
- Both methods are useful for determining the quality and combustion characteristics of fuels.

## Numerical Problems

- Example 1: A coal sample has the following proximate analysis (wt%): moisture 10, volatile matter 35, fixed carbon 45, ash 10. Calculate the mass of air required for complete combustion of 1 kg of coal. Assume that air contains 21% oxygen and 79% nitrogen by volume, and that the products of combustion are carbon dioxide, water vapor, nitrogen, and ash.

- Solution: The first step is to calculate the mass fractions of carbon, hydrogen, and oxygen in the coal sample, using the following formula:

  - Carbon fraction = (fixed carbon + volatile matter) x 0.8
  - Hydrogen fraction = (volatile matter) x 0.05
  - Oxygen fraction = (volatile matter) x 0.1

  - Substituting the values from the proximate analysis, we get:

  - Carbon fraction = (45 + 35) x 0.8 = 64 wt%
  - Hydrogen fraction = (35) x 0.05 = 1.75 wt%
  - Oxygen fraction = (35) x 0.1 = 3.5 wt%

  - The next step is to write the stoichiometric equation for the combustion of coal, using the mass fractions of carbon, hydrogen, and oxygen:

  - C0.64H0.0175O0.035 + a(O2 + 0.79/0.21 N2) -> b CO2 + c H2O + d N2 + e ash

  - The coefficients a, b, c, d, and e can be determined by applying the mass balance for each element. For carbon, we have:

  - 0.64 = b x 12/44
  - Solving for b, we get b = 1.17

  - For hydrogen, we have:

  - 0.0175 x 2 = c x 2
  - Solving for c, we get c = 0.0175

  - For oxygen, we have:

  - 0.035 + a x 0.21 = b x 32/44 + c
  - Substituting the values of b and c, we get a = 1.32

  - For nitrogen, we have:

  - a x 0.79 = d x 28/28
  - Solving for d, we get d = 1.04

  - For ash, we have:

  - e = 0.1

  - The final stoichiometric equation is:

  - C0.64H0.0175O0.035 + 1.32(O2 + 3.76 N2) -> 1.17 CO2 + 0.0175 H2O + 3.92 N2 + 0.1 ash

  - The mass of air required for complete combustion of 1 kg of coal is:

  - 1.32 x (32 + 3.76 x 28) = 5.48 kg
