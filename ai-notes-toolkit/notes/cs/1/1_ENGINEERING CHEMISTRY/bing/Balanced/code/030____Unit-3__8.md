## Unit-3: 8

- This unit covers the topic of **linear programming**, which is a method of finding the optimal solution to a problem that involves multiple constraints and objectives.
- Linear programming can be used to model and solve various real-world problems, such as resource allocation, production planning, transportation, scheduling, etc.
- The basic idea of linear programming is to represent the problem as a system of **linear inequalities** that define the **feasible region**, which is the set of all possible solutions that satisfy the constraints.
- The objective of linear programming is to find the **optimal solution**, which is the point in the feasible region that maximizes or minimizes a **linear objective function**.
- To solve a linear programming problem, one can use various methods, such as **graphical method**, **simplex method**, **dual simplex method**, **revised simplex method**, **interior point method**, etc.
- The graphical method is a visual way of finding the optimal solution by plotting the feasible region and the objective function on a graph and identifying the **extreme points**, which are the vertices of the feasible region. The optimal solution is one of the extreme points that gives the best value of the objective function.
- The simplex method is an algebraic way of finding the optimal solution by transforming the problem into a **standard form**, which has the following characteristics:
  - All variables are non-negative.
  - All constraints are equations.
  - The objective function is to be maximized.
- The simplex method then uses a **tableau**, which is a matrix representation of the problem, and performs a series of **pivot operations**, which are elementary row operations that change the basic and non-basic variables, to move from one extreme point to another until the optimal solution is reached or the problem is found to be **unbounded** or **infeasible**.
- The dual simplex method is a variation of the simplex method that can be used to solve problems that are not in standard form, such as minimization problems or problems with greater-than-or-equal-to constraints. The dual simplex method converts the original problem into its **dual problem**, which has the opposite objective and the opposite constraints, and then applies the simplex method to the dual problem to find the optimal solution of the original problem.
- The revised simplex method is another variation of the simplex method that can improve the computational efficiency and accuracy of the solution by using a different representation of the tableau, which only stores the **basic variables** and the **coefficients** of the objective function, and by updating the tableau using **matrix inversion** instead of pivot operations.
- The interior point method is a different approach to solving linear programming problems that does not rely on finding the extreme points of the feasible region, but instead starts from an **interior point** of the feasible region and moves towards the optimal solution by following the **direction of improvement**, which is determined by the **gradient** of the objective function and the **feasibility conditions** of the constraints. The interior point method can be faster and more robust than the simplex method for large-scale problems.
