#### CO CO Statement Bloom’s
- CO stands for Course Outcome, which is a statement that describes what students are expected to know, understand, or be able to do by the end of a course.
- CO statement should be clear, measurable, and aligned with the course objectives and assessment methods.
- Bloom's taxonomy is a framework for classifying educational goals based on the level of cognitive skills involved, from lower-order to higher-order thinking.
- Bloom's taxonomy consists of six categories: remember, understand, apply, analyze, evaluate, and create. Each category has a set of verbs that can be used to write CO statements.
- For example, a CO statement for a course on programming could be: "By the end of this course, students will be able to **create** a simple web application using HTML, CSS, and JavaScript."
- The verb **create** indicates that the CO statement belongs to the highest level of Bloom's taxonomy, which requires students to synthesize and generate new products or ideas.
