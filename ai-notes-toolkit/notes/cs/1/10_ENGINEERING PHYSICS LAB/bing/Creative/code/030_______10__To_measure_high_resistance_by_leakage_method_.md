##### 10. To measure high resistance by leakage method.

- High resistance by leakage method is a technique for measuring very high value of resistance, such as the leakage between the two conductors of a cable.
- Digital multimeters or LCR meters are unable to measure very high resistance with high accuracy, as they are designed for normal value of resistance (generally 1 Ω - 20M Ω)   .
- The principle of this method is to apply a known voltage source to the resistance under test and measure the resulting current using a sensitive voltmeter.
- The circuit diagram for this method is shown below:

```
+-----+      +-----+
|     |      |     |
|  V  |      |  R  |
|     |      |     |
+-----+      +-----+
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  |            |
  +-----+      |
  |     |      |
  |  V  |      |
  |     |      |
  +-----+      |
    |          |
    +----------+
```

- In this circuit, V is the voltage source, R is the high resistance to be measured, and V is the voltmeter.
- The current through the circuit is given by:

```
I = V / R
```

- The voltmeter reading is equal to the current multiplied by the voltmeter resistance, which is assumed to be very high compared to R:

```
V = I * V
```

- Therefore, the resistance R can be calculated by:

```
R = V * V / V
```

- This method has the advantage of testing the resistance with the normal operating voltage applied, which can reveal any defects or breakdowns that may not be detected by low voltage measurements.
- This method also has some limitations, such as the need for a stable and accurate voltage source, a sensitive and high resistance voltmeter, and a good insulation of the circuit components to avoid any leakage currents.
