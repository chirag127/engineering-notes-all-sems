#### CO CO Statement Bloom’s

- CO stands for Course Outcomes, which are statements that describe what learners should be able to do or demonstrate at the end of a course.
- CO statements should be clear, measurable, and aligned with the course objectives and assessment methods.
- Bloom's taxonomy is a framework for classifying the levels of cognitive skills that learners can demonstrate, from the lowest (remembering) to the highest (creating).
- Bloom's taxonomy can help teachers write effective CO statements by providing a list of action verbs that correspond to each level of cognitive skill .
- For example, a CO statement for a course on programming could be: "By the end of this course, learners will be able to **apply** basic programming concepts and **create** simple programs using Python."
- Bloom's taxonomy can also help teachers map the CO statements with the Program Outcomes (POs), which are statements that describe what learners should be able to do or demonstrate at the end of a program.
- Mapping COs with POs can help teachers ensure that the course is relevant, coherent, and aligned with the program goals.
- For example, a PO for a program on computer science could be: "Graduates will have the ability to **design**, **implement**, and **evaluate** computer-based systems, processes, components, or programs to meet desired needs."
- A CO statement for a course on programming can be mapped with this PO by showing how the CO contributes to the PO. For instance, the CO statement above can be mapped with the PO by indicating that the CO helps learners **design** and **implement** computer-based systems using Python.
