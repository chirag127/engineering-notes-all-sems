## Introduction

CNC stands for Computer Numerical Control. It is a process of using a computer-driven machine tool to produce a part out of solid material in a different shape. CNC machines can perform various operations such as drilling, milling, turning, cutting, etc. on metal components with high accuracy and precision.

## Main features of CNC machine

Some of the main features of CNC machine are:

- It can be programmed to execute a sequence of operations automatically without human intervention.
- It can produce complex shapes and geometries that are difficult or impossible to achieve by manual machines.
- It can produce parts with consistent quality and accuracy, eliminating human errors and variations.
- It can operate for long hours without fatigue or breakdown, increasing productivity and efficiency.
- It can be easily modified and reprogrammed to produce different parts, enhancing flexibility and versatility.

## Main parts of CNC machine

The main parts of a CNC machine are:

- Input device: This is the device that is used to input the part program in the CNC machine. The part program is a set of instructions that tells the machine how to move and control the tool and the workpiece. The input device can be a punch tape reader, a magnetic tape reader, or a computer via RS-232-C communication .
- Machine control unit (MCU): This is the heart of the CNC machine. It consists of a microprocessor, a memory, and an interface circuit. It receives the part program from the input device, interprets it, and generates the signals to control the motion and speed of the machine tools .
- Machine tools: These are the components that perform the actual machining operations on the workpiece. They include a sliding table, a spindle, a tool holder, a cutting tool, etc. The machine tools are driven by motors and controlled by the MCU according to the part program  .
- Driving system: This is the system that provides the power and motion to the machine tools. It consists of motors, gears, belts, pulleys, etc. The driving system can be either servo or stepper, depending on the type and accuracy of the CNC machine .
- Feedback system: This is the system that monitors the actual position and speed of the machine tools and compares them with the desired values. It consists of sensors, encoders, transducers, etc. The feedback system sends the error signals to the MCU, which then adjusts the driving system accordingly to correct the deviations .
- Display unit: This is the device that shows the status and information of the CNC machine to the operator. It can be a monitor, a keyboard, a mouse, etc. The display unit can also be used to edit and modify the part program, as well as to monitor the machining process .
- Bed: This is the base or foundation of the CNC machine. It supports and aligns the other parts of the machine. It is usually made of cast iron or steel, and has a rigid and stable structure .
- Headstock: This is the part of the CNC machine that holds and rotates the spindle and the cutting tool. It is mounted on the bed and can be moved along the X-axis. The headstock can have different types of spindles, such as horizontal, vertical, or angular, depending on the machining operation .
- Tailstock: This is the part of the CNC machine that supports and holds the other end of the workpiece. It is also mounted on the bed and can be moved along the Z-axis. The tailstock can have different types of centers, such as live, dead, or revolving, depending on the workpiece shape and size .
