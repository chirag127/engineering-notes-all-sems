# To determine the least count of Vernier calliper, vernier height gauge, micrometer (Screw gauge) and take different reading over given metallic pieces using these instruments.

## Introduction

- The least count of an instrument is the smallest measurement that can be taken with it. It is the ratio of the smallest division on the main scale to the number of divisions on the vernier scale.
- Vernier calliper, vernier height gauge and micrometer are instruments used to measure the dimensions of small objects with high accuracy and precision.
- Vernier calliper consists of two scales: a main scale and a vernier scale. The main scale is fixed and has a graduated scale in millimeters or inches. The vernier scale is movable and slides along the main scale. It has a smaller number of divisions than the main scale, usually 10 or 20. The vernier scale can measure the fraction of a division on the main scale by aligning with it.
- Vernier height gauge is similar to vernier calliper, but it is used to measure the height of objects. It consists of a base, a vertical column and a sliding head. The base has a main scale graduated in millimeters or inches. The sliding head has a vernier scale and a scriber. The scriber is used to mark the height of the object on the column.
- Micrometer (screw gauge) consists of a U-shaped frame, a spindle, a thimble, a sleeve and a ratchet. The spindle is a screw that moves in and out of the frame when the thimble is rotated. The sleeve has a main scale graduated in millimeters or inches. The thimble has a vernier scale with 50 or 100 divisions. The ratchet is used to apply a constant pressure on the object to be measured.

## Procedure

- To determine the least count of vernier calliper, vernier height gauge and micrometer, the following formula is used:

  - Least count = (value of one division on the main scale) / (number of divisions on the vernier scale)

  - For example, if the main scale of a vernier calliper has 1 mm divisions and the vernier scale has 10 divisions, then the least count is:

    - Least count = (1 mm) / (10) = 0.1 mm

- To take different readings over given metallic pieces using these instruments, the following steps are followed:

  - For vernier calliper:

    - Place the object between the jaws of the vernier calliper and close them gently until they touch the object.
    - Read the main scale value that coincides with the zero mark of the vernier scale. This is the main scale reading (MSR).
    - Find the vernier scale division that coincides with any main scale division. This is the vernier scale reading (VSR).
    - The total reading is obtained by adding the MSR and the VSR multiplied by the least count. The formula is:

      - Total reading = MSR + (VSR x Least count)

      - Total reading = 12 mm + (4 x 0.1 mm) = 12.4 mm
