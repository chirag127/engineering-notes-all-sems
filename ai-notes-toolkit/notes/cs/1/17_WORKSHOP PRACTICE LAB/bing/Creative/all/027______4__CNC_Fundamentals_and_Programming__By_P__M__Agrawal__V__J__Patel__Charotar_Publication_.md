# CNC Fundamentals and Programming

This is a summary of the book CNC Fundamentals and Programming by P. M. Agrawal and V. J. Patel, published by Charotar Publication in 2022   . The book explains the basics of NC/CNC machine tools, operations and part programming, as well as advanced topics such as macro programming, DNC and CAPP.

The book is divided into 10 chapters, as follows:

- Chapter 1: Introduction to NC/CNC Machine Tools
  - This chapter introduces the concept of NC/CNC machine tools, their advantages, disadvantages, applications and classification. It also explains the basic components and functions of NC/CNC systems, such as controller, drive, feedback, memory and display.
- Chapter 2: CNC Machine Tool Hardware
  - This chapter describes the various types of CNC machine tools, such as turning, milling, drilling, grinding, EDM and laser cutting. It also discusses the features and specifications of CNC machine tools, such as axes, spindle, tool magazine, workholding devices, coolant and chip removal systems.
- Chapter 3: CNC Machine Tool Software
  - This chapter covers the software aspects of CNC machine tools, such as operating system, compiler, interpreter, editor and simulator. It also explains the concepts of interpolation, look-ahead, canned cycles, subprograms and macros.
- Chapter 4: CNC Part Programming
  - This chapter introduces the methods and formats of CNC part programming, such as manual, conversational and CAD/CAM. It also explains the basic elements and rules of CNC part programming, such as coordinate systems, axes notation, program structure, word address format, G and M codes, modal and non-modal commands, and program examples.
- Chapter 5: CNC Turning Programming
  - This chapter focuses on the CNC turning programming, such as turning center configuration, tool geometry, tool selection, tool offset, cutting parameters, machining operations, program examples and simulation.
- Chapter 6: CNC Milling Programming
  - This chapter focuses on the CNC milling programming, such as milling center configuration, tool geometry, tool selection, tool offset, cutting parameters, machining operations, program examples and simulation.
- Chapter 7: CNC Drilling Programming
  - This chapter focuses on the CNC drilling programming, such as drilling center configuration, tool geometry, tool selection, tool offset, cutting parameters, machining operations, program examples and simulation.
- Chapter 8: Macro Programming
  - This chapter explains the concept and advantages of macro programming, such as parameterization, conditional branching, looping, arithmetic and logic operations, and user-defined variables. It also provides examples of macro programs for various applications, such as hole patterns, bolt circles, pocket milling, thread milling and contour machining.
- Chapter 9: Direct Numerical Control (DNC)
  - This chapter describes the concept and benefits of DNC, such as data transfer, program storage, program editing, program verification and program management. It also discusses the hardware and software components of DNC systems, such as host computer, communication interface, network topology, protocols and formats.
- Chapter 10: Computer Aided Part Programming (CAPP)
  - This chapter introduces the concept and objectives of CAPP, such as automation, standardization, optimization and integration of part programming. It also explains the types and methods of CAPP, such as variant, generative, interactive and feature-based. It also provides examples of CAPP systems, such as APT, ADAPT and CATIA.
