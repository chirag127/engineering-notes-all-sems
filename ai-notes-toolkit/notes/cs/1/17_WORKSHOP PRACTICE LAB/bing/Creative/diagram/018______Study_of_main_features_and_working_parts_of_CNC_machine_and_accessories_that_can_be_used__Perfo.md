#### Study of main features and working parts of CNC machine and accessories that can be used. Perform different operations on metal components using any CNC machines

- CNC stands for Computer Numerical Control, which is a process of using a computer-driven machine tool to produce a part out of solid material in a different shape.
- CNC machines can perform various operations on metal components, such as drilling, milling, turning, threading, tapping, boring, etc.
- CNC machines have the following main features and parts  :

  - Input device: This is the device that is used to input part programs in a CNC machine. Part programs are a set of instructions that tell the machine how to move and what to do. Input devices can be punch tape readers, magnetic tape readers, or computers via RS-232-C communication.
  - Machine control unit (MCU): This is the heart of the CNC machine. It receives the part program from the input device and converts it into electrical signals that control the motion and speed of the machine tools. It also monitors the feedback system and displays the status of the machine on the display unit.
  - Machine tools: These are the components that actually perform the cutting or shaping of the material. A CNC machine tool always has a sliding table and a spindle to control position and speed. The table can move along one or more axes (X, Y, Z) and the spindle can rotate at different speeds and angles. The machine tools can also have different attachments, such as drills, mills, lathes, etc.
  - Driving system: This is the system that provides power and motion to the machine tools. It consists of motors, gears, belts, pulleys, etc. The driving system is controlled by the MCU according to the part program.
  - Feedback system: This is the system that measures the actual position and speed of the machine tools and sends the information back to the MCU. It consists of sensors, encoders, transducers, etc. The feedback system ensures the accuracy and precision of the CNC machine.
  - Display unit: This is the device that shows the current status and parameters of the CNC machine, such as position, speed, error, etc. It can be a monitor, a keyboard, a panel, etc.
  - Bed: This is the base or foundation of the CNC machine. It supports and aligns the other parts of the machine. It is usually made of cast iron or steel.
  - Headstock: This is the part of the CNC machine that holds the spindle and the driving system. It is usually fixed at one end of the bed.
  - Tailstock: This is the part of the CNC machine that supports the other end of the workpiece. It can be moved along the bed to adjust the length of the workpiece. It can also have a center or a chuck to hold the workpiece.

- CNC machines can also have various accessories that can be used to enhance their performance, such as:

  - Coolant system: This is the system that provides a liquid or gas to cool down the cutting tools and the workpiece. It prevents overheating, friction, and wear. It can also improve the surface finish and the tool life.
  - Lubrication system: This is the system that provides oil or grease to lubricate the moving parts of the CNC machine. It reduces friction, wear, and noise. It can also prevent corrosion and rust.
  - Chip conveyor: This is the device that collects and removes the chips or shavings that are produced during the cutting process. It prevents the accumulation of chips on the machine and the workpiece. It can also improve the safety and cleanliness of the CNC machine.
  - Tool changer: This is the device that allows the CNC machine to automatically change the cutting tools according to the part program. It reduces the setup time and the manual intervention. It can also increase the productivity and the flexibility of the CNC machine.
  - Workpiece clamping: This is the device that holds the workpiece securely on the table or the spindle. It can be a vise, a clamp, a chuck, a collet, etc. It ensures the stability and the alignment of the workpiece during the cutting process.
