#### To determine the least count of Vernier calliper, vernier height gauge, micrometer (Screw gauge) and take different reading over given metallic pieces using these instruments.

- The least count of an instrument is the smallest measurement that can be taken with it. It is equal to the ratio of the smallest division on the main scale to the number of divisions on the vernier scale.
- A vernier calliper is an instrument that can measure the length, diameter, or depth of an object with high precision. It consists of a main scale and a sliding vernier scale that can move along the main scale. The main scale has divisions of 1 mm and the vernier scale has 10 divisions that coincide with 9 divisions on the main scale. Therefore, the least count of a vernier calliper is 1/10 mm or 0.1 mm.
- A vernier height gauge is an instrument that can measure the height of an object from a reference surface. It consists of a vertical main scale and a sliding vernier scale that can move along the main scale. The main scale has divisions of 1 mm and the vernier scale has 10 divisions that coincide with 9 divisions on the main scale. Therefore, the least count of a vernier height gauge is 1/10 mm or 0.1 mm.
- A micrometer (screw gauge) is an instrument that can measure the thickness or diameter of an object with very high precision. It consists of a fixed anvil, a movable spindle, a thimble, a sleeve, and a ratchet. The sleeve has a main scale with divisions of 0.5 mm and the thimble has a circular vernier scale with 50 divisions that coincide with 25 divisions on the sleeve. Therefore, the least count of a micrometer is 0.5/50 mm or 0.01 mm.
- To take different readings over given metallic pieces using these instruments, follow these steps:
  - For vernier calliper and vernier height gauge, place the object between the jaws or on the reference surface and slide the vernier scale until it touches the object. Read the main scale value and the vernier scale value that coincide with each other. Add them to get the total reading. Repeat this for different objects and record the readings in a table.
  - For micrometer, place the object between the anvil and the spindle and rotate the thimble until it touches the object. Use the ratchet to apply a uniform pressure. Read the sleeve value and the thimble value that coincide with each other. Add them to get the total reading. Repeat this for different objects and record the readings in a table.
  - Compare the readings obtained by different instruments and calculate the percentage error. The percentage error is the ratio of the difference between the actual value and the measured value to the actual value, multiplied by 100. The actual value can be obtained by using a standard instrument or by averaging the readings of different instruments. The percentage error indicates the accuracy and precision of the instrument. The lower the percentage error, the better the instrument.
