# Workshop Practice Lab:

Workshop Practice Lab is a course designed to provide students with hands-on experience in various workshop processes and techniques. The course typically covers the following topics:

1. Safety: Students learn about the importance of safety in the workshop and how to use tools and equipment safely.
2. Hand Tools: Students learn about the various hand tools used in the workshop, such as hammers, screwdrivers, pliers, and saws, and how to use them correctly.
3. Measuring Instruments: Students learn about the different measuring instruments used in the workshop, such as rulers, calipers, and micrometers, and how to use them accurately.
4. Machine Tools: Students learn about the various machine tools used in the workshop, such as lathes, milling machines, and drilling machines, and how to operate them correctly.
5. Welding: Students learn about the different types of welding, such as arc welding, gas welding, and TIG welding, and how to perform them safely.
6. Sheet Metal Work: Students learn about the various techniques used in sheet metal work, such as cutting, bending, and forming, and how to perform them correctly.
7. Carpentry: Students learn about the different types of wood and how to work with them, as well as the various techniques used in carpentry, such as sawing, planing, and sanding.
8. Fitting: Students learn about the different techniques used in fitting, such as filing, drilling, and tapping, and how to perform them accurately.

The course provides students with the opportunity to develop practical skills and gain experience in using tools and equipment in a workshop setting. It is an essential course for students pursuing careers in engineering, manufacturing, and related fields.
