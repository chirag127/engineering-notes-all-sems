### Trim

Computer Aided Design (CAD) is a computer-based tool used by engineers and designers to create, modify, analyze, and optimize designs. One of the essential functions of CAD is to create 2D and 3D models of the designs. In this unit, we will learn about Trim, which is a command used to remove unnecessary or unwanted parts of a design.

Here are some important points that you should know about Trim:

- Trim is a command used in CAD software to remove unwanted portions of a design.
- It is used to clean up and simplify the design by removing overlapping lines or other unnecessary elements.
- The Trim command can be accessed from the Modify toolbar in most CAD software.
- To use the Trim command, select the objects that you want to trim and then select the portion of the object that you want to remove.
- You can use the Trim command to remove portions of lines, arcs, circles, and other objects.
- The Trim command is an essential tool for creating clean and precise designs.

In conclusion, Trim is an important command in CAD software that helps engineers and designers to create clean and precise designs. By removing unnecessary or unwanted portions of a design, the Trim command helps to simplify and optimize the design. It is an essential tool for any CAD user and should be mastered by anyone who wants to create precise and efficient designs.
