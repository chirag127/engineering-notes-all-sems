Engineering drawing is a graphical representation of an object or a structure that is used to communicate technical information to people who need to understand it. Orthographic projection is a technique used to create a two-dimensional representation of a three-dimensional object by projecting its views onto a set of planes. In this unit, you will learn about the basics of engineering drawing and orthographic projections.

Here are some important points to keep in mind:

- Engineering drawing is a precise and accurate representation of an object, and it is used to convey technical information to engineers, architects, and other professionals.
- Orthographic projection is a technique used to create a two-dimensional representation of a three-dimensional object by projecting its views onto a set of planes.
- Orthographic projection is based on the principle of projection, which states that a point in space can be projected onto a plane to create a two-dimensional representation of that point.
- To create an orthographic projection, you need to choose a set of planes that will represent the object in three dimensions.
- The most common set of planes used in orthographic projection is the front, top, and side views.
- Each view in an orthographic projection is created by projecting the object onto the corresponding plane.
- In engineering drawing, it is important to use standard symbols and conventions to ensure that the information is communicated clearly and accurately.
- Some of the common symbols used in engineering drawing include lines, circles, arcs, and dimensions.
- There are different types of lines used in engineering drawing, such as solid lines, dashed lines, and centerlines.
- In addition to standard symbols and conventions, it is also important to use clear and concise language when communicating technical information through engineering drawing.

By understanding the basics of engineering drawing and orthographic projection, you will be able to create accurate and precise representations of objects and structures, which will be essential in your future work as an engineer or architect.
