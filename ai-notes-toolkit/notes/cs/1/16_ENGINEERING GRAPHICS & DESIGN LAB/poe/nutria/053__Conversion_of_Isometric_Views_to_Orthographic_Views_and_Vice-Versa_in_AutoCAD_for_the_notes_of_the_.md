
### Conversion of Isometric Views to Orthographic Views and Vice-Versa in AutoCAD

1. Isometric views are three-dimensional views of an object. They are commonly used in engineering drawings to show the three-dimensional form of an object.
2. Orthographic views are two-dimensional views of an object. They are commonly used in engineering drawings to show the exact size, shape and location of an object.
3. AutoCAD is a computer-aided design software that allows users to create 3D models and 2D drawings.
4. AutoCAD can be used to convert isometric views to orthographic views and vice-versa.
5. To convert an isometric view to an orthographic view, the user must first draw the isometric view in AutoCAD.
6. Then, the user must select the isometric view and use the “Isometric to Orthographic” command to convert the view to an orthographic view.
7. To convert an orthographic view to an isometric view, the user must first draw the orthographic view in AutoCAD.
8. Then, the user must select the orthographic view and use the “Orthographic to Isometric” command to convert the view to an isometric view.
9. The conversion of isometric views to orthographic views and vice-versa in AutoCAD can be used to create more accurate and detailed engineering drawings.
