
## Unit 1 - Introduction to Engineering Drawing and Orthographic Projections

1. Engineering drawing is a type of technical drawing used to create an accurate representation of an object or structure. It is used to communicate ideas and instructions to engineers and other professionals involved in the design and manufacture of products.

2. Orthographic projections are a type of drawing used to represent three-dimensional objects in two dimensions. It is used to create accurate representations of objects in a variety of views, such as side, front, and top.

3. Engineering drawings are typically created using CAD (computer-aided design) software. This software allows for the creation of detailed drawings that can be used to manufacture products.

4. Orthographic projections are used to create a set of drawings that represent an object from different perspectives. These drawings are used to communicate the object's design to engineers, manufacturers, and other professionals.

5. Engineering drawing is an important skill for any engineer. It is used to create accurate representations of objects and to communicate ideas and instructions to other professionals.

6. Orthographic projections are an important tool for engineers and designers. They provide a way to create accurate representations of objects in two dimensions, which can be used to communicate ideas and instructions to other professionals.
