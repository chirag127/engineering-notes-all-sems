
### Isometric Scales

1. Isometric scales are used to represent three-dimensional objects on a two-dimensional surface.
2. Isometric scales are usually expressed as a ratio between the length of the object on the drawing and the actual length of the object in real life.
3. Isometric scales are typically represented as 1:1, 1:2, 1:4, 1:8, and so on.
4. When using an isometric scale, the length of the object on the drawing will be the same as the actual length of the object in real life when the ratio is 1:1.
5. When using a ratio of 1:2, the length of the object on the drawing will be twice as long as the actual length of the object in real life.
6. When using a ratio of 1:4, the length of the object on the drawing will be four times as long as the actual length of the object in real life.
7. When using a ratio of 1:8, the length of the object on the drawing will be eight times as long as the actual length of the object in real life.
8. Isometric scales are used to represent objects accurately on a two-dimensional surface.
