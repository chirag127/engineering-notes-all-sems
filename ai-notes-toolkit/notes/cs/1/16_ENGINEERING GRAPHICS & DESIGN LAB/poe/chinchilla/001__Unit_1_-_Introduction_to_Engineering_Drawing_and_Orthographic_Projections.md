## Unit 1 - Introduction to Engineering Drawing and Orthographic Projections

In this unit, we will cover the basics of engineering drawing and orthographic projections. Engineering drawing is a graphical representation of an object that is used to communicate its design and details to others. Orthographic projections are a method of representing a 3D object in 2D, using multiple views from different angles.

### What is Engineering Drawing?

Engineering drawing is a type of technical drawing that is used to communicate the design and details of an object. It is a graphical representation of an object that is created using lines, symbols, and dimensions. It is used by engineers, designers, and manufacturers to communicate the design of a product or part to others.

### Types of Engineering Drawings

There are several types of engineering drawings, including:

- **Sketches:** Freehand drawings used to quickly communicate an idea or design.
- **Assembly drawings:** Drawings that show how parts fit together to create a larger product or system.
- **Detail drawings:** Drawings that provide specific information about individual parts or components.
- **Isometric drawings:** Drawings that show the object in 3D, using angles and proportions to create a realistic view.
- **Perspective drawings:** Drawings that show the object in 3D, using depth and shading to create a realistic view.

### Orthographic Projections

Orthographic projections are a method of representing a 3D object in 2D, using multiple views from different angles. This projection is used to create a detailed engineering drawing of an object. Orthographic projections use multiple views, including:

- **Front view:** A view of the object from the front.
- **Top view:** A view of the object from the top.
- **Side view:** A view of the object from the side.

Orthographic projections are created by projecting each view onto a plane that is perpendicular to the object. This creates a two-dimensional representation of the object that includes all of its details and dimensions.

### Conclusion

Engineering drawing and orthographic projections are essential skills for engineers, designers, and manufacturers. They are used to communicate the design of a product or part to others, and to create detailed drawings that can be used in the manufacturing process. By mastering these skills, you will be able to create accurate and detailed engineering drawings that are essential for success in the field of engineering.
