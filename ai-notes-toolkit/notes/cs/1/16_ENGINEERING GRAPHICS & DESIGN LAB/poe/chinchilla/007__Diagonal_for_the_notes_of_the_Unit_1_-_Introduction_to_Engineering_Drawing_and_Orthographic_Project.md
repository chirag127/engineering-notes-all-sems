In this unit, we will cover the basics of Engineering Drawing and Orthographic Projections. Here are some important points to remember:

1. Engineering Drawing is a graphical representation of an object or a structure that is used to communicate design ideas to others.

2. Orthographic Projections are a set of techniques used to represent a 3D object in 2D views. These views include front, top, and side views.

3. The purpose of orthographic projections is to create accurate and detailed drawings that can be used for manufacturing, construction, and other applications.

4. The two main types of engineering drawings are detail drawings and assembly drawings. Detail drawings show a single part of an object in great detail, while assembly drawings show how multiple parts fit together.

5. Engineering drawings use a standardized set of symbols, lines, and dimensions to convey important information about the design.

6. The most common types of lines used in engineering drawings include object lines, hidden lines, centerlines, and dimension lines.

7. It is important to follow the correct conventions when creating engineering drawings. For example, object lines are always drawn as thick lines, while hidden lines are drawn as thin lines.

8. Orthographic projections can be created using either first-angle or third-angle projection methods. In first-angle projection, the object is placed in front of the views, while in third-angle projection, the object is behind the views.

9. When creating orthographic projections, it is important to think about the relationship between the different views. For example, the front view should always match the height and width of the object, while the side view should match the depth of the object.

10. Overall, engineering drawing and orthographic projections are essential skills for anyone working in engineering or design. By following the correct conventions and using the appropriate techniques, you can create accurate and detailed drawings that can be easily understood by others.
