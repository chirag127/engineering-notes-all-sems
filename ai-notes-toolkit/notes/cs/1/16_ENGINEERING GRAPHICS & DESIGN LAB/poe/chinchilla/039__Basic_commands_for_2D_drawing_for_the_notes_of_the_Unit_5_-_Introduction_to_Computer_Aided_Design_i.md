### Basic commands for 2D drawing for the notes of the Unit 5 - Introduction to Computer Aided Design in the subject of ENGINEERING GRAPHICS & DESIGN LAB

In the world of computer-aided design (CAD), 2D drawing is the most fundamental and essential skill. 2D drawing forms the foundation for 3D modeling and serves as the basis for most engineering designs. Here are some basic commands for 2D drawing that you should be familiar with:

1. Line Command: The Line command is used to draw straight lines. To use this command, select the Line tool from the toolbar or type "Line" in the command line. Then, click on the starting point of the line and drag the cursor to the endpoint. Once you're done, press Enter to complete the line.

2. Circle Command: The Circle command is used to draw circles. To use this command, select the Circle tool from the toolbar or type "Circle" in the command line. Then, click on the center point of the circle and drag the cursor to set the radius. Once you're done, press Enter to complete the circle.

3. Arc Command: The Arc command is used to draw arcs. To use this command, select the Arc tool from the toolbar or type "Arc" in the command line. Then, click on the starting point of the arc, drag the cursor to set the midpoint, and drag it again to set the endpoint. Once you're done, press Enter to complete the arc.

4. Polyline Command: The Polyline command is used to draw a sequence of connected line segments. To use this command, select the Polyline tool from the toolbar or type "Polyline" in the command line. Then, click on the starting point of the polyline and drag the cursor to set the endpoint of the first line segment. Continue clicking to set the endpoints of the subsequent line segments. Once you're done, press Enter to complete the polyline.

5. Rectangle Command: The Rectangle command is used to draw rectangles. To use this command, select the Rectangle tool from the toolbar or type "Rectangle" in the command line. Then, click on the starting point of the rectangle and drag the cursor to set the endpoint of the diagonal. Once you're done, press Enter to complete the rectangle.

6. Hatch Command: The Hatch command is used to fill an enclosed area with a pattern. To use this command, select the Hatch tool from the toolbar or type "Hatch" in the command line. Then, select the closed boundary you want to fill and specify the pattern you want to use. Once you're done, press Enter to complete the hatch.

7. Dimension Command: The Dimension command is used to add dimensions to your drawing. To use this command, select the Dimension tool from the toolbar or type "Dimension" in the command line. Then, click on the object you want to dimension and drag the cursor to set the dimension line. Once you're done, press Enter to complete the dimension.

These are some basic commands for 2D drawing that you should be familiar with. With practice, you can become proficient in using these commands and create precise and detailed drawings.
