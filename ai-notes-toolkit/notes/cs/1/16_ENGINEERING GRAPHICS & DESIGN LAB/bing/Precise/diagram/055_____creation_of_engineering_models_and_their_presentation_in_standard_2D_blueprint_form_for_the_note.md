#### ENGINEERING GRAPHICS & DESIGN LAB KCS

#### Creation of Engineering Models and their Presentation in Standard 2D Blueprint Form

1. Engineering models are created using computer-aided design (CAD) software. This software allows engineers to create, modify, analyze, and optimize designs.
2. CAD software can be used to create 2D drawings or 3D models of objects. These models can be used to visualize and test the design before it is manufactured.
3. Once the design is finalized, it can be presented in the form of a standard 2D blueprint. This blueprint is a technical drawing that shows the dimensions, materials, and construction details of the object.
4. Blueprints are created using standardized symbols and conventions to ensure that they are easily understood by anyone who needs to work with them.
5. The blueprint is then used by manufacturers, builders, and other professionals to create the final product.
