# Polyline

A polyline is a continuous line composed of one or more line segments. It is a basic element in computer-aided design (CAD) and is used to represent a wide range of geometric shapes, including lines, curves, and polygons.

In the context of engineering graphics and design, polylines are used to represent the outlines of objects, as well as to create complex shapes by combining multiple line segments. They can be used to create both two-dimensional and three-dimensional shapes.

Some key points to remember about polylines include:

- A polyline is composed of one or more line segments.
- Polylines can be used to represent a wide range of geometric shapes.
- In CAD, polylines are used to represent the outlines of objects and to create complex shapes.
- Polylines can be used to create both two-dimensional and three-dimensional shapes.
