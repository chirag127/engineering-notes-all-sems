# Conversion of Isometric Views to Orthographic Views and Vice-Versa in AutoCAD

In the subject of Engineering Graphics & Design Lab, Unit 5 - Introduction to Computer Aided Design, one of the important topics is the conversion of isometric views to orthographic views and vice-versa in AutoCAD.

1. **Isometric View**: An isometric view is a 3D representation of an object, where the three coordinate axes appear equally foreshortened and the angles between them are 120 degrees.

2. **Orthographic View**: An orthographic view is a 2D representation of an object, where the views are projected onto planes that are perpendicular to the coordinate axes.

3. **Conversion from Isometric to Orthographic**: To convert an isometric view to an orthographic view in AutoCAD, the following steps can be followed:
    1. Open the isometric drawing in AutoCAD.
    2. Use the `FLATSHOT` command to create a 2D representation of the 3D model.
    3. Select the desired view (top, front, or side) and adjust the settings as needed.
    4. The resulting 2D drawing can be used as an orthographic view.

4. **Conversion from Orthographic to Isometric**: To convert an orthographic view to an isometric view in AutoCAD, the following steps can be followed:
    1. Open the orthographic drawing in AutoCAD.
    2. Use the `EXTRUDE` command to create a 3D model from the 2D drawing.
    3. Use the `VIEW` command to change the view to an isometric view.
    4. The resulting 3D model can be used as an isometric view.

These are the basic steps for converting between isometric and orthographic views in AutoCAD. It is important to note that the specific steps and commands may vary depending on the version of AutoCAD being used. It is recommended to consult the AutoCAD documentation for detailed instructions.
