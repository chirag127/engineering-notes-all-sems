# Unit 5 - Introduction to Computer Aided Design

## Trim

- Trim is a command in Computer Aided Design (CAD) software that is used to remove unwanted portions of an object.
- The Trim command can be used to remove lines, arcs, circles, or other shapes that extend beyond the boundaries of another object.
- To use the Trim command, the user must first select the cutting edges, which are the objects that will be used to trim the unwanted portions of the object.
- After selecting the cutting edges, the user can then select the objects to be trimmed.
- The Trim command can be used in both 2D and 3D design.
- Trim is a useful tool for creating clean and precise designs in CAD software.
