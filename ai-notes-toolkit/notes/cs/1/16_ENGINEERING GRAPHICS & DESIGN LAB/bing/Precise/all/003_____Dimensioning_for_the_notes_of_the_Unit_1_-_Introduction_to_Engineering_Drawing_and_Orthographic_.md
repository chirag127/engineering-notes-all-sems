# Dimensioning

Dimensioning is the process of adding measurements to a drawing. It is an essential part of creating technical drawings, such as engineering drawings and orthographic projections, which are used to communicate the design of a product or structure to others. Here are some key points to remember when dimensioning:

1. Dimensions should be placed in a clear and unambiguous manner, so that they can be easily read and understood by anyone who needs to use the drawing.
2. The units of measurement used should be consistent throughout the drawing, and should be clearly indicated.
3. Dimensions should be placed outside the view, unless there is not enough space, in which case they can be placed inside the view.
4. Extension lines should be used to indicate the points between which the dimension is being measured.
5. Dimension lines should be drawn between the extension lines, with arrowheads at each end to indicate the direction of measurement.
6. The dimension value should be placed above the dimension line, centered between the arrowheads.
7. If the dimension value is too large to fit between the arrowheads, it can be placed outside the dimension line, with a leader line connecting it to the dimension line.
8. If multiple dimensions are being shown in the same direction, they should be aligned and spaced evenly.
9. If a dimension is being repeated, it should be indicated using a reference dimension, which is shown in parentheses.
10. If a dimension is not to scale, it should be indicated using a note, such as "NTS" (not to scale).

These are some of the basic principles of dimensioning that are important to keep in mind when creating technical drawings. By following these guidelines, you can ensure that your drawings are clear, accurate, and easy to understand.
