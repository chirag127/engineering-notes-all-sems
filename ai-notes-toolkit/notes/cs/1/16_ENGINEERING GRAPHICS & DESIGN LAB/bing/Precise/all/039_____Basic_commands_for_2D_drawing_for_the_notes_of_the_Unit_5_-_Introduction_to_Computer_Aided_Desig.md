### Basic commands for 2D drawing

1. **Line**: This command is used to draw a straight line between two points.
2. **Circle**: This command is used to draw a circle with a specified center point and radius.
3. **Arc**: This command is used to draw an arc with a specified center point, radius, and start and end angles.
4. **Rectangle**: This command is used to draw a rectangle with specified corner points.
5. **Polygon**: This command is used to draw a regular polygon with a specified number of sides and center point.
6. **Ellipse**: This command is used to draw an ellipse with a specified center point, major axis, and minor axis.
7. **Hatch**: This command is used to fill an enclosed area with a pattern or solid color.
8. **Text**: This command is used to add text to the drawing.
9. **Dimension**: This command is used to add dimensions to the drawing.
10. **Move**: This command is used to move selected objects to a new location.
11. **Copy**: This command is used to create a copy of selected objects.
12. **Rotate**: This command is used to rotate selected objects around a specified base point.
13. **Scale**: This command is used to scale selected objects by a specified factor.
14. **Trim**: This command is used to trim lines that extend beyond a selected boundary.
15. **Extend**: This command is used to extend lines to meet a selected boundary.
16. **Offset**: This command is used to create parallel lines or curves at a specified distance from the original object.
17. **Mirror**: This command is used to create a mirrored copy of selected objects.
18. **Array**: This command is used to create an array of objects in a rectangular or polar pattern.
19. **Fillet**: This command is used to create a rounded corner between two lines.
20. **Chamfer**: This command is used to create a beveled edge between two lines.

These are some of the basic commands for 2D drawing in Computer Aided Design. It is important to become familiar with these commands in order to effectively use CAD software for engineering graphics and design.
