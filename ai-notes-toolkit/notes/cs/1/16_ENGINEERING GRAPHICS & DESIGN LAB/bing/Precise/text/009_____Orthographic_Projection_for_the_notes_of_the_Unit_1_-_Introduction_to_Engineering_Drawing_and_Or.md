### Orthographic Projection

Orthographic projection is a method of representing three-dimensional objects in two dimensions. It is a form of parallel projection, where all the projection lines are orthogonal to the projection plane. This results in each plane of the object being projected onto the plane as a true shape, with no distortion.

In engineering drawing, orthographic projection is commonly used to represent an object in a multi-view drawing. This involves representing the object in several views, typically a front, top, and right side view. Each view shows the object as if it were being viewed from a different direction, with the projection lines perpendicular to the plane of the view.

Some key points to remember about orthographic projection are:
- It is a method of representing 3D objects in 2D.
- It is a form of parallel projection.
- All projection lines are orthogonal to the projection plane.
- Each plane of the object is projected as a true shape, with no distortion.
- It is commonly used in engineering drawing to represent an object in a multi-view drawing.
- Each view shows the object as if viewed from a different direction, with projection lines perpendicular to the plane of the view.
