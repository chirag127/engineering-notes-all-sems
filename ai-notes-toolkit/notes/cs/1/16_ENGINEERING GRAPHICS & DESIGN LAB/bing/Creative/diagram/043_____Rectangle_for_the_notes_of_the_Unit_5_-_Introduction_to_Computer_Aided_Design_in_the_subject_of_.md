### Rectangle

- A rectangle is a four-sided polygon with four right angles.
- A rectangle can be defined by two opposite vertices or by a vertex and the length and width of the rectangle.
- A rectangle can be drawn in a computer aided design (CAD) software by using the following commands:
  - **RECTANG** or **REC**: This command creates a rectangular polyline by specifying two opposite corners of the rectangle.
  - **@length,width**: This option allows the user to enter the length and width of the rectangle after specifying the first corner.
- A rectangle has the following properties:
  - **Area**: The area of a rectangle is the product of its length and width. The formula is A = lw, where A is the area, l is the length, and w is the width.
  - **Perimeter**: The perimeter of a rectangle is the sum of the lengths of its four sides. The formula is P = 2l + 2w, where P is the perimeter, l is the length, and w is the width.
  - **Diagonal**: The diagonal of a rectangle is the line segment that connects two opposite vertices of the rectangle. The length of the diagonal can be found by using the Pythagorean theorem. The formula is d = √(l^2 + w^2), where d is the diagonal, l is the length, and w is the width.
- A rectangle can be modified in a CAD software by using the following commands:
  - **MOVE** or **M**: This command moves the selected objects from one location to another by specifying a base point and a second point.
  - **ROTATE** or **RO**: This command rotates the selected objects around a base point by specifying an angle or a reference angle.
  - **SCALE** or **SC**: This command scales the selected objects by specifying a base point and a scale factor or a reference length.
  - **TRIM** or **TR**: This command trims the selected objects by cutting them at the intersection with another object or a cutting edge.
  - **EXTEND** or **EX**: This command extends the selected objects by stretching them to meet another object or a boundary edge.
  - **FILLET** or **F**: This command creates a rounded corner between two objects or the adjacent sides of a polyline by specifying a radius.
  - **CHAMFER** or **CHA**: This command creates a beveled corner between two objects or the adjacent sides of a polyline by specifying a distance or an angle.
- A rectangle can be dimensioned in a CAD software by using the following commands:
  - **DIMLINEAR** or **DIMLIN**: This command creates a linear dimension by specifying two extension line origins and a location for the dimension line.
  - **DIMALIGNED** or **DIMALI**: This command creates an aligned dimension by specifying two extension line origins and a location for the dimension line.
  - **DIMANGULAR** or **DIMANG**: This command creates an angular dimension by specifying three points that define an angle and a location for the dimension arc.
  - **DIMRADIUS** or **DIMRAD**: This command creates a radial dimension by specifying the center of a circle or an arc and a location for the dimension line.
  - **DIMDIAMETER** or **DIMDIA**: This command creates a diameter dimension by specifying a circle or an arc and a location for the dimension line.
  - **DIMSTYLE** or **D**: This command creates and modifies dimension styles that control the appearance of dimensions, such as text, arrows, lines, and units.
