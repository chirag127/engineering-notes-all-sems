### Trim

- Trim is a command in computer aided design (CAD) software that allows you to cut or remove unwanted parts of an object or a drawing.
- Trim can be used to create new shapes or modify existing ones by trimming the edges or segments that intersect with other objects or boundaries.
- Trim can also be used to clean up the drawing and remove unnecessary or overlapping lines or curves.

#### How to use the Trim command in AutoCAD?

- AutoCAD is a popular CAD software that has a Trim command that can be accessed from the Modify panel or by typing TRIM in the command line.
- To use the Trim command in AutoCAD, follow these steps  :

  1. Click on the TRIM icon or type TRIM and press Enter.
  2. Select the objects or boundaries that you want to use as cutting edges. You can select individual objects or use a selection window or a crossing fence. To use all objects as boundaries, press Enter at the first Select Objects prompt.
  3. Right-click or press Enter to confirm the selection of cutting edges.
  4. Select the objects or segments that you want to trim. You can select individual objects or use a selection window or a crossing fence. To trim all possible objects, press Enter at the second Select Objects prompt.
  5. Right-click or press Enter to end the command.

#### How to use the Trim command in CATIA V5?

- CATIA V5 is another CAD software that has a Trim command that can be accessed from the Sketcher workbench or by selecting the Trim icon from the Profile toolbar.
- To use the Trim command in CATIA V5, follow these steps:

  1. Select the Trim icon from the Profile toolbar or right-click on the sketch and select Trim from the contextual menu.
  2. Click on the segment or curve that you want to trim. The segment or curve will be trimmed at the nearest intersection point with another element.
  3. Repeat the step 2 for other segments or curves that you want to trim.
  4. Click on the Exit icon or press Esc to end the command.
