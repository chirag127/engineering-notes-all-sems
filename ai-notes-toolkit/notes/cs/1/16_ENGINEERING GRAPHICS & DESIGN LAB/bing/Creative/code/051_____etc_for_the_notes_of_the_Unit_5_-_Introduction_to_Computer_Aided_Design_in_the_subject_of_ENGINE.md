### Unit 5 - Introduction to Computer Aided Design

- Computer-aided design (CAD) is a manufacturing process that allows us to digitally create 2D drawings or 3D models of future products.
- CAD helps designers and engineers visualize a product’s construction, before fabricating it.
- CAD also enables the creation of solid models that can be used for conceptual design, detailed design and engineering analysis.
- CAD software can vary in complexity, functionality and cost, depending on the application and industry.
- Some examples of CAD software are AutoCAD, SolidWorks, Creo Parametric, CATIA, Inventor, SketchUp, etc.
- CAD software can be used for various engineering disciplines, such as mechanical, civil, electrical, architectural, etc.
- CAD software can also be integrated with other tools, such as computer-aided manufacturing (CAM), computer-aided engineering (CAE), finite element analysis (FEA), etc.
- CAD software can improve the quality, efficiency and productivity of the design process, as well as reduce errors, costs and time .
- CAD software can also facilitate collaboration, communication and documentation among the design team and stakeholders .
- CAD software requires the user to have a good understanding of the engineering principles, geometry, mathematics and physics involved in the design problem .
- CAD software also requires the user to have a good command of the specific software features, commands, menus, options, etc .
- CAD software can be learned through various methods, such as online courses, tutorials, books, videos, etc.
- CAD software can be assessed through various methods, such as assignments, projects, quizzes, exams, etc.
