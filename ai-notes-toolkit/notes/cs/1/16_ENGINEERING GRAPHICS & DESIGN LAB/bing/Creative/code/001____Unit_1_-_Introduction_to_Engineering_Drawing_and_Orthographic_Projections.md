# Unit 1 - Introduction to Engineering Drawing and Orthographic Projections

- Engineering drawing is a graphical language used by engineers and other technical personnel to communicate design ideas, specifications, and dimensions of physical objects or systems.
- Engineering drawing can be classified into two types: artistic drawing and technical drawing. Artistic drawing is used to express aesthetic or creative ideas, while technical drawing is used to convey accurate and precise information about the shape, size, and features of an object or system.
- Engineering drawing can be further divided into two categories: pictorial drawing and orthographic drawing. Pictorial drawing is a three-dimensional representation of an object or system, while orthographic drawing is a two-dimensional representation of an object or system.
- Orthographic drawing is based on the principle of orthographic projection, which is a method of projecting the features of a three-dimensional object onto a plane or a set of planes perpendicular to each other.
- Orthographic projection can be classified into two types: first-angle projection and third-angle projection. First-angle projection is used in Europe and Asia, while third-angle projection is used in North America and Australia. The difference between the two types is the position of the object relative to the planes of projection.
- In first-angle projection, the object is placed in the first quadrant, which is behind the vertical plane and above the horizontal plane. The front view is projected onto the vertical plane, the top view is projected onto the horizontal plane, and the side view is projected onto a plane perpendicular to both the vertical and horizontal planes. The planes of projection are unfolded such that the front view is on the right, the top view is on the bottom, and the side view is on the left.
- In third-angle projection, the object is placed in the third quadrant, which is in front of the vertical plane and below the horizontal plane. The front view is projected onto the vertical plane, the top view is projected onto the horizontal plane, and the side view is projected onto a plane perpendicular to both the vertical and horizontal planes. The planes of projection are unfolded such that the front view is on the left, the top view is on the top, and the side view is on the right.
- To distinguish between the two types of projection, a symbol called the projection symbol is drawn on the drawing. The projection symbol consists of a cone with a solid and a dashed line. The solid line represents the vertical plane, and the dashed line represents the horizontal plane. The position of the cone indicates the type of projection. In first-angle projection, the cone is pointing away from the object, while in third-angle projection, the cone is pointing towards the object.

- To draw an orthographic drawing, the following steps are followed:
  - Select the most descriptive view of the object as the front view. The front view should show the most features and details of the object.
  - Draw the front view on the vertical plane, using the appropriate scale and dimensions. The front view should be aligned with the center of the drawing sheet.
  - Project the top view from the front view onto the horizontal plane, using the same scale and dimensions. The top view should be aligned with the front view.
  - Project the side view from the front view onto a plane perpendicular to both the vertical and horizontal planes, using the same scale and dimensions. The side view should be aligned with the front view and the top view.
  - Draw the projection symbol on the drawing, indicating the type of projection used.
  - Add any necessary dimensions, notes, symbols, or labels to the drawing, following the standards and conventions of engineering drawing.
  - Check the drawing for accuracy, completeness, and clarity.
