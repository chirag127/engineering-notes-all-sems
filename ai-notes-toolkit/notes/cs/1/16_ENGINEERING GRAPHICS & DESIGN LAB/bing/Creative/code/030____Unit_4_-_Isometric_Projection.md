## Unit 4 - Isometric Projection

- Isometric projection is a method for visually representing three-dimensional objects in two dimensions in technical and engineering drawings.
- It is an axonometric projection in which the three coordinate axes appear equally foreshortened and the angle between any two of them is 120 degrees .
- Isometric projection is a form of orthographic projection, which means that the object is mapped onto the drawing plane by dropping perpendiculars from each point to the plane.
- Isometric projection preserves the true dimensions and angles of the object along the three principal directions, but distorts the shape and size of the object in other directions.
- Isometric projection is useful for showing the general shape and arrangement of the object, but not for showing the exact measurements or details.
- Isometric projection can be drawn by using a 30-degree set square and a compass, or by using an isometric grid paper, or by using a computer-aided design (CAD) software.
- Isometric projection can be converted to other types of projections, such as oblique projection or perspective projection, by applying appropriate transformations.
- Isometric projection can be used to create isometric drawings, which are pictorial representations of the object that show the three visible faces of the object in a single view.
- Isometric drawings are often used in engineering, architecture, video games, and graphic design to convey the three-dimensional shape and appearance of the object .
- Isometric drawings can be enhanced by adding shades, shadows, colors, textures, and other visual effects to create a realistic impression of the object.
