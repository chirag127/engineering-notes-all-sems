### Unit 1 - Introduction to Engineering Drawing and Orthographic Projections

- Engineering drawing is a graphical language used by engineers and other technical personnel to communicate technical information, such as design specifications, dimensions, tolerances, materials, and manufacturing processes.
- Engineering drawing follows a set of standards and conventions to ensure clarity, accuracy, and uniformity of the drawings.
- Engineering drawing can be classified into two types: pictorial drawing and orthographic drawing.
- Pictorial drawing is a drawing that shows the object as it appears to the eye, with three dimensions: length, width, and height. Pictorial drawing can be further divided into three types: isometric, oblique, and perspective drawing.
- Isometric drawing is a pictorial drawing that shows the object with equal angles of 120 degrees between the three principal axes. Isometric drawing preserves the true dimensions of the object along the axes, but distorts the angles and shapes of the faces.
- Oblique drawing is a pictorial drawing that shows the object with one face parallel to the plane of projection, and the other two faces receding at an angle of 30, 45, or 60 degrees. Oblique drawing preserves the true dimensions of the object along the parallel face, but distorts the dimensions and shapes of the receding faces.
- Perspective drawing is a pictorial drawing that shows the object as it appears to the eye from a particular point of view, with vanishing points and foreshortening. Perspective drawing preserves the realistic appearance of the object, but distorts the dimensions and shapes of the object.
- Orthographic drawing is a drawing that shows the object with two dimensions: length and width. Orthographic drawing can be further divided into two types: multiview drawing and axonometric drawing.
- Multiview drawing is an orthographic drawing that shows the object with two or more views, each view representing a different plane of projection. Multiview drawing preserves the true dimensions and shapes of the object, but requires multiple views to show the complete information of the object.
- Axonometric drawing is an orthographic drawing that shows the object with one view, but with three axes tilted at different angles. Axonometric drawing preserves the true dimensions of the object along the axes, but distorts the angles and shapes of the faces. Axonometric drawing can be further divided into three types: isometric, dimetric, and trimetric drawing.
- Isometric drawing is an axonometric drawing that shows the object with equal angles of 120 degrees between the three axes. Isometric drawing is the same as isometric pictorial drawing, except that it uses orthographic projection instead of perspective projection.
- Dimetric drawing is an axonometric drawing that shows the object with two angles equal and one angle unequal between the three axes. Dimetric drawing preserves the true dimensions of the object along two axes, but distorts the dimensions and shapes of the object along the third axis.
- Trimetric drawing is an axonometric drawing that shows the object with three angles unequal between the three axes. Trimetric drawing preserves the true dimensions of the object along one axis, but distorts the dimensions and shapes of the object along the other two axes.
