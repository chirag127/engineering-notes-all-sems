# Unit 5 - Introduction to Computer Aided Design

## Hatch

- Hatch is a command in AutoCAD that is used to fill an area of selected objects with a hatch pattern or fill.
- Hatch patterns represent materials to be used and incorporated within a design, such as brick, concrete, wood, etc.
- Hatches can also be used to designate areas or room types, such as office, kitchen, bathroom, etc.
- Hatches can be applied to closed boundaries, such as circles, rectangles, polygons, etc., or to open boundaries, such as lines, arcs, splines, etc., by using the gap tolerance option.
- Hatches can be associated or non-associated to their boundaries. Associated hatches update automatically when their boundaries are modified, while non-associated hatches remain unchanged.
- Hatches can be edited by using the properties palette, the hatch edit command, or the grips on the hatch boundary.
- Hatches can be customized by using the hatch creation tab, which allows the user to choose from different types of patterns, scales, angles, colors, layers, etc.
- Hatches can be created from existing objects, such as blocks, images, xrefs, etc., by using the object option in the hatch command.
- Hatches can be converted to boundary objects, such as polylines, regions, etc., by using the hatch to back command.
- Hatches can be exported and imported as .pat files, which contain the definition of the hatch pattern.
