### Rectangle

- A rectangle is a quadrilateral with four right angles and four sides of equal or unequal lengths.
- A rectangle can be drawn in a computer aided design (CAD) software by using various methods, such as:
  - Using the Rectangle command and specifying two opposite corners of the rectangle.
  - Using the Line command and drawing four lines that are perpendicular to each other and form a closed loop.
  - Using the Polygon command and specifying the number of sides as four and the inscribed or circumscribed circle option.
- A rectangle can be modified in a CAD software by using various tools, such as:
  - Using the Move command and selecting the rectangle and a base point and a destination point to move it to a new location.
  - Using the Rotate command and selecting the rectangle and a center point and an angle to rotate it around the center point.
  - Using the Scale command and selecting the rectangle and a base point and a scale factor to change its size proportionally.
  - Using the Trim command and selecting the rectangle and another object to cut off the parts of the rectangle that extend beyond the other object.
  - Using the Extend command and selecting the rectangle and another object to extend the sides of the rectangle to meet the other object.
  - Using the Offset command and selecting the rectangle and a distance to create a parallel copy of the rectangle at the specified distance.
  - Using the Mirror command and selecting the rectangle and a mirror line to create a symmetrical copy of the rectangle across the mirror line.
  - Using the Array command and selecting the rectangle and a number of rows and columns and a distance to create a rectangular array of copies of the rectangle.
  - Using the Fillet command and selecting the rectangle and a radius to round off the corners of the rectangle with arcs of the specified radius.
  - Using the Chamfer command and selecting the rectangle and a distance to cut off the corners of the rectangle with straight lines of the specified distance.
- A rectangle can be dimensioned in a CAD software by using various tools, such as:
  - Using the Linear command and selecting two points on a side of the rectangle to create a linear dimension that shows the length of the side.
  - Using the Aligned command and selecting two points on a side of the rectangle that is not horizontal or vertical to create an aligned dimension that shows the true length of the side.
  - Using the Angular command and selecting two lines that form an angle in the rectangle to create an angular dimension that shows the angle between the lines.
  - Using the Leader command and selecting a point on the rectangle and a text to create a leader that points to the rectangle and displays the text.
  - Using the Text command and selecting a point and a text to create a text that shows the name or description of the rectangle.
