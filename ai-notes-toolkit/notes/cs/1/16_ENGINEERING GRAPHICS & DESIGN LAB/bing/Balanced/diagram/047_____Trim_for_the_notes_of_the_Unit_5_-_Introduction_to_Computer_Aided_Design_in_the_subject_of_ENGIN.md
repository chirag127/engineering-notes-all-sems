### Trim

- Trim is a command in computer aided design (CAD) software that allows you to cut or remove unwanted parts of an object or a drawing.
- Trim can be used to create new shapes or modify existing ones by trimming the edges or segments that intersect with other objects or boundaries.
- Trim can also be used to clean up the drawing and remove unnecessary or overlapping lines.

#### How to use Trim in AutoCAD

- AutoCAD is a popular CAD software that has a Trim command that can be accessed from the Modify panel or by typing TRIM in the command line.
- To use Trim in AutoCAD, you need to follow these steps:

  1. Select the objects or boundaries that you want to use as cutting edges. You can select individual objects or press Enter to use all objects as boundaries.
  2. Select the objects or segments that you want to trim. You can select individual objects or use a selection window or a crossing fence to select multiple objects.
  3. Press Enter to finish the command and see the trimmed objects.

- You can also use the Shift key to switch between trimming and extending while using the Trim command.
