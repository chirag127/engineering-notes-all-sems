### Diagonal

- A diagonal is a straight line that connects two opposite corners of a polygon, such as a rectangle or a square.
- A diagonal scale is a type of graphical scale that is used to measure small fractions of the unit of measurement in engineering and cartographic drawings.
- A diagonal scale consists of a main scale and a number of sub-scales that are drawn parallel to the main scale and divided into equal parts.
- A diagonal scale can represent different units and multiples of units, such as meters, centimeters, and millimeters, or feet, inches, and fractions of inches.
- A diagonal scale can be drawn by following these steps :
  - Find the length of the scale by multiplying the largest unit by the number of units to be represented on the scale.
  - Draw a horizontal line and mark the zero point and the end point of the scale.
  - Divide the scale into equal parts according to the number of units and subdivide the first part into the number of sub-units.
  - Draw vertical lines from the division points and extend the last vertical line beyond the scale.
  - Divide the last vertical line into the same number of parts as the sub-units and label them accordingly.
  - Draw diagonal lines from the subdivision points on the first vertical line to the successive next subdivision points on the last vertical line.
  - Label the main scale and the sub-scales with the appropriate units and multiples.
- A diagonal scale can be used to measure the length of an object by aligning the zero point of the scale with one end of the object and reading the value at the other end of the object from the main scale and the sub-scale.
- A diagonal scale can also be used to draw the length of an object by marking the value from the main scale and the sub-scale on the scale and drawing a line from the zero point to the marked point.
- A diagonal scale can improve the accuracy and precision of the measurements and drawings by reducing the errors and uncertainties that may arise from using a ruler or a compass.
- A diagonal scale can also be used to show the section views of an object by drawing diagonal lines or cross-hatching on the area that has been theoretically cut .
- A diagonal scale can also be used to mark the centers of circles and the axes of symmetrical parts, such as cylinders and bolts, by drawing short diagonal lines.
- A diagonal scale can also be used to show where an object is broken to save drawing space or reveal interior features by drawing break lines, which can be either freehand thick lines or long, ruled thin lines with zigzags.
