### Scales for the notes of the Unit 1 - Introduction to Engineering Drawing and Orthographic Projections

- A scale is a ratio that relates the dimensions of a drawing to the actual dimensions of the object represented by the drawing.
- A scale can be expressed as a fraction, a decimal, or a verbal statement. For example, 1/10, 0.1, or 1 cm = 10 cm are different ways of expressing the same scale.
- A scale can be classified into three types: full scale, reduced scale, and enlarged scale.
  - A full scale drawing has the same dimensions as the actual object. For example, a 1:1 scale means that 1 unit on the drawing equals 1 unit on the object.
  - A reduced scale drawing has smaller dimensions than the actual object. For example, a 1:2 scale means that 1 unit on the drawing equals 2 units on the object.
  - An enlarged scale drawing has larger dimensions than the actual object. For example, a 2:1 scale means that 2 units on the drawing equals 1 unit on the object.
- A scale can be used to measure the dimensions of an object from a drawing, or to draw an object with given dimensions.
  - To measure the dimensions of an object from a drawing, multiply the dimensions on the drawing by the scale factor. For example, if a drawing has a 1:10 scale and a line on the drawing measures 5 cm, then the actual length of the line on the object is 5 x 10 = 50 cm.
  - To draw an object with given dimensions, divide the dimensions of the object by the scale factor. For example, if an object has a length of 60 cm and a drawing has a 1:20 scale, then the length of the line on the drawing is 60 / 20 = 3 cm.
- A scale can be represented by a scale bar, which is a line segment divided into equal parts that correspond to the units of the scale. For example, a scale bar with a 1:100 scale can have 10 cm divided into 10 parts, each representing 1 m on the object. A scale bar can help the viewer to estimate the dimensions of an object from a drawing without using a ruler or a calculator.
