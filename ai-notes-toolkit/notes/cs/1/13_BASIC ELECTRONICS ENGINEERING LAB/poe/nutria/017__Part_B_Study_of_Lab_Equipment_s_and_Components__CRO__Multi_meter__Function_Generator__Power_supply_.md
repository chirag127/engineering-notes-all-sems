
### Part B Study of Lab Equipment’s and Components: 

1. CRO (Cathode Ray Oscilloscope): It is a type of electronic test instrument that is used to observe the waveforms of electronic signals. It provides a visual display of the signal's voltage, frequency and other characteristics.

2. Multi meter: It is an electronic test instrument used to measure voltage, current, resistance and other electrical properties of a circuit.

3. Function Generator: It is an electronic test instrument used to generate various types of electrical waveforms.

4. Power supply: It is an electronic device used to supply power to a circuit. It can be either active or passive.

5. Active components: These are components which require an external power source to operate. Examples include transistors, capacitors, resistors, and diodes.

6. Passive components: These are components which do not require an external power source to operate. Examples include resistors, capacitors, inductors, and transformers.

7. Bread Board: It is a type of electronic test instrument used to construct and test circuits. It consists of a baseboard with interconnected rows of holes, into which components can be plugged.

These test equipment can be demonstrated online from any lab of ECE department or physical mode is only option.
