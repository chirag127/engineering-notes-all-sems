### Characteristics of BJT in CE configuration

- BJT stands for bipolar junction transistor, which is a three-terminal device that can amplify electrical signals.
- CE stands for common emitter, which is one of the three possible configurations of BJT, where the emitter terminal is common to both input and output circuits.
- The input signal is applied between the base and the emitter terminals, and the output signal is taken from the collector and the emitter terminals.
- The CE configuration is an inverting amplifier, which means that the output signal is 180 degrees out of phase with the input signal.
- The CE configuration has the following characteristics:

  - Input characteristics: These are the curves that show the relation between the base current (I_B) and the base-emitter voltage (V_BE) for different values of collector-emitter voltage (V_CE). The input characteristics are similar to the forward characteristics of a diode, as the base-emitter junction is forward biased. The input resistance (r_in) is the ratio of the change in V_BE to the change in I_B at a constant V_CE. The input resistance is typically low, in the range of hundreds of ohms.

  - Output characteristics: These are the curves that show the relation between the collector current (I_C) and the collector-emitter voltage (V_CE) for different values of base current (I_B). The output characteristics have three regions: the active region, the saturation region, and the cutoff region. In the active region, the collector current is proportional to the base current, and the collector-emitter voltage is positive. The current gain (beta) is the ratio of the change in I_C to the change in I_B at a constant V_CE. The current gain is typically high, in the range of tens to hundreds. In the saturation region, the collector current reaches a maximum value, and the collector-emitter voltage is low. The transistor is said to be saturated, as both the base-emitter and the base-collector junctions are forward biased. In the cutoff region, the collector current is zero, and the collector-emitter voltage is high. The transistor is said to be cut off, as both the base-emitter and the base-collector junctions are reverse biased.

  - Transfer characteristics: These are the curves that show the relation between the output current (I_C) and the input voltage (V_BE) for different values of collector-emitter voltage (V_CE). The transfer characteristics are useful to determine the operating point of the transistor, which is the combination of I_C and V_CE that gives the desired output signal. The operating point can be fixed by using a biasing circuit, which provides the necessary DC voltages and currents to the transistor.

  - Amplification characteristics: These are the parameters that measure the ability of the transistor to amplify the input signal. The most important amplification characteristics are:

    - Voltage gain (A_V): This is the ratio of the change in output voltage (V_o) to the change in input voltage (V_i) at a constant frequency. The voltage gain is negative, as the output signal is inverted with respect to the input signal. The voltage gain is typically medium, in the range of tens.

    - Power gain (A_P): This is the ratio of the output power (P_o) to the input power (P_i) at a constant frequency. The power gain is positive, as the output power is greater than the input power. The power gain is typically high, in the range of thousands to millions.

    - Bandwidth (B_W): This is the range of frequencies over which the transistor can amplify the input signal without significant distortion or attenuation. The bandwidth is determined by the frequency response of the transistor, which shows how the voltage gain varies with the frequency. The bandwidth is typically low, in the range of kilohertz to megahertz.
