# 5. Characteristics of BJT: BJT in CE configuration

- BJT stands for Bipolar Junction Transistor, which is a three-terminal device that can amplify electrical signals.
- BJT has three terminals: emitter (E), base (B), and collector (C).
- BJT can be connected in different ways, depending on which terminal is taken as the common terminal for both input and output. These are called configurations.
- The most common configuration is the Common-Emitter (CE) configuration, where the emitter is the common terminal.
- In the CE configuration, the input signal is applied between the base and the emitter, and the output signal is taken from the collector and the emitter.
- The CE configuration is an inverting amplifier, which means that the output signal is 180 degrees out of phase with the input signal.
- The CE configuration has high voltage gain, high current gain, and high power gain, which makes it suitable for amplification applications.
- The CE configuration has two types of characteristics: input characteristics and output characteristics.
- The input characteristics show the relation between the input current (IB) and the input voltage (VBE) for different values of the output voltage (VCE).
- The input characteristics are similar to the forward characteristics of a diode, as the base-emitter junction is forward biased in the CE configuration.
- The input characteristics can be used to find the input resistance (Rin) of the CE configuration, which is the ratio of the change in input voltage to the change in input current.
- The output characteristics show the relation between the output current (IC) and the output voltage (VCE) for different values of the input current (IB).
- The output characteristics are divided into three regions: active region, saturation region, and cut-off region.
- The active region is where the output current is proportional to the input current, and the output voltage is high. This is the region where the CE configuration works as an amplifier.
- The saturation region is where the output current is maximum, and the output voltage is low. This is the region where the CE configuration works as a switch that is ON.
- The cut-off region is where the output current is zero, and the output voltage is high. This is the region where the CE configuration works as a switch that is OFF.
- The output characteristics can be used to find the output resistance (Rout) of the CE configuration, which is the ratio of the change in output voltage to the change in output current.
- The output characteristics can also be used to find the voltage gain (Av), current gain (Ai), and power gain (Ap) of the CE configuration, which are the ratios of the output voltage, current, and power to the input voltage, current, and power, respectively.
