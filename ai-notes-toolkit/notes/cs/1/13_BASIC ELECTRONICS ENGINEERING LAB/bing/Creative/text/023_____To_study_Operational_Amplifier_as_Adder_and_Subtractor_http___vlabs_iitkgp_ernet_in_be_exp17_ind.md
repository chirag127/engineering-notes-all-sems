### To study Operational Amplifier as Adder and Subtractor

- An operational amplifier (op-amp) is a high-gain electronic voltage amplifier with a differential input and a single-ended output.
- An op-amp can be used as part of a positive or negative feedback amplifier or as an adder or subtractor type circuit using just pure resistances in both the input and the feedback loop.
- An adder circuit is a type of op-amp circuit that can perform the sum of two or more input voltages. The output voltage is proportional to the algebraic sum of the input voltages.
- A subtractor circuit is a type of op-amp circuit that can perform the difference of two input voltages. The output voltage is proportional to the algebraic difference of the input voltages.
- A differential amplifier is a type of op-amp circuit that can perform both addition and subtraction of two input voltages. The output voltage is proportional to the weighted difference of the input voltages .

- To study the op-amp as adder and subtractor, the following steps are required:
  - Connect the op-amp circuit as per the desired configuration (adder, subtractor or differential amplifier) using resistors, power supply and input sources.
  - Apply the input voltages to the op-amp terminals and measure the output voltage using a voltmeter or an oscilloscope.
  - Vary the input voltages and observe the changes in the output voltage. Compare the output voltage with the expected value from the formula.
  - Analyze the results and verify the operation of the op-amp circuit as adder or subtractor.
