# Characteristic of BJT: BJT in CE configuration

- BJT stands for Bipolar Junction Transistor, which is a three-terminal device that can amplify electrical signals.
- BJT can be connected in three different configurations by keeping one terminal common and using the other two terminals for the input and output. These configurations are common base (CB), common emitter (CE), and common collector (CC).
- CE configuration is the most widely used configuration of BJT, where the emitter terminal is common to both input and output circuits. The input signal is applied between the base and the emitter, and the output signal is taken from the collector and the emitter.
- CE configuration has the following characteristics :
  - It has a high power gain, which is the product of voltage gain and current gain.
  - It has a medium voltage gain, which is the ratio of output voltage to input voltage.
  - It has a high current gain, which is the ratio of output current to input current.
  - It has a low input resistance, which is the resistance seen by the input signal at the base terminal.
  - It has a high output resistance, which is the resistance seen by the output signal at the collector terminal.
  - It has an inverted phase relationship between the input and output signals, which means that the output signal is 180 degrees out of phase with the input signal.
- The input and output characteristics of CE configuration can be obtained by plotting the input current (I_B) versus the input voltage (V_BE) and the output current (I_C) versus the output voltage (V_CE) for different values of the other variable.
- The input characteristics of CE configuration show that the input current (I_B) increases exponentially with the input voltage (V_BE) for a given output voltage (V_CE). This is because the base-emitter junction behaves like a forward-biased diode.
- The output characteristics of CE configuration show that the output current (I_C) is almost constant for a given input current (I_B) and increases slightly with the output voltage (V_CE). This is because the collector-emitter junction behaves like a reverse-biased diode.
- The output characteristics of CE configuration also show that the output current (I_C) depends on the base current (I_B), which means that the base current controls the output current. This is the principle of current amplification in BJT.
- The output characteristics of CE configuration also show that the output current (I_C) decreases with the increase of the output voltage (V_CE) beyond a certain point. This is because the collector-emitter junction undergoes breakdown due to the high electric field. The breakdown voltage is called the common-emitter breakdown voltage (BV_CE0).
- The output characteristics of CE configuration also show that the output current (I_C) curves are not parallel to each other, but slightly bend towards the output voltage (V_CE) axis. This is because the effective base width decreases with the increase of the output voltage (V_CE) due to the Early effect. The intercept of the output current (I_C) curves on the output voltage (V_CE) axis is called the Early voltage (V_A).
- The CE configuration of BJT can be used as an inverting amplifier, a switch, or an oscillator, depending on the biasing and the load circuit.
