### Verification of Truth Table of Various Logic Gate

A logic gate is a device that performs a Boolean logic operation on one or more binary inputs and then outputs a single binary output. There are different types of logic gates, such as AND, OR, NOT, NAND, NOR, and XOR, each with its own truth table that shows the output for every possible combination of inputs.

To verify the truth table of a logic gate, the suitable integrated circuit (IC) is taken and the connections are given using the circuit diagram. For all the ICs, 5V is applied to the pin 14 while the pin 7 is connected to the ground. The logical inputs of the truth table are applied and the corresponding output is noted.

The following are the steps to verify the truth table of various logic gates using ICs:

- AND gate (IC 7408): Connect the inputs A and B to the pins 1 and 2, and the output Y to the pin 3. Apply the inputs 0 and 1 in all possible combinations and note the output. The output should be 1 only when both inputs are 1, otherwise 0. This verifies the truth table of AND gate.

- OR gate (IC 7432): Connect the inputs A and B to the pins 1 and 2, and the output Y to the pin 3. Apply the inputs 0 and 1 in all possible combinations and note the output. The output should be 1 when either or both inputs are 1, otherwise 0. This verifies the truth table of OR gate.

- NOT gate (IC 7404): Connect the input A to the pin 1, and the output Y to the pin 2. Apply the inputs 0 and 1 and note the output. The output should be the complement of the input, i.e., 0 when input is 1 and 1 when input is 0. This verifies the truth table of NOT gate.

- NAND gate (IC 7400): Connect the inputs A and B to the pins 1 and 2, and the output Y to the pin 3. Apply the inputs 0 and 1 in all possible combinations and note the output. The output should be 0 only when both inputs are 1, otherwise 1. This verifies the truth table of NAND gate.

- NOR gate (IC 7402): Connect the inputs A and B to the pins 1 and 2, and the output Y to the pin 3. Apply the inputs 0 and 1 in all possible combinations and note the output. The output should be 0 when either or both inputs are 1, otherwise 1. This verifies the truth table of NOR gate.

- XOR gate (IC 7486): Connect the inputs A and B to the pins 1 and 2, and the output Y to the pin 3. Apply the inputs 0 and 1 in all possible combinations and note the output. The output should be 1 when the inputs are different, otherwise 0. This verifies the truth table of XOR gate.
