# Characteristic of BJT: BJT in CE configuration

- BJT stands for Bipolar Junction Transistor, which is a three-terminal device that can amplify electrical signals.
- BJT can be connected in three different configurations by keeping one terminal common and using the other two terminals for the input and output. These configurations are Common Base (CB), Common Emitter (CE), and Common Collector (CC).
- In CE configuration, the emitter terminal is the common terminal for both input and output. The input signal is applied between the base and the emitter, and the output signal is taken between the collector and the emitter.
- CE configuration is the most widely used configuration for BJT amplifiers, because it has high power gain, medium voltage gain, and high current gain. It also has a high input impedance and a low output impedance, which makes it suitable for impedance matching.
- The characteristics of BJT in CE configuration can be studied by plotting the input and output characteristics curves, which show the relationship between the input and output currents and voltages.
- The input characteristics curve shows the variation of the base current (I_B) with respect to the base-emitter voltage (V_BE) for different values of the collector-emitter voltage (V_CE). It is similar to the forward characteristics of a diode, because the base-emitter junction is forward biased in CE configuration. The input characteristics curve can be used to determine the input resistance of the BJT, which is the ratio of the change in V_BE to the change in I_B.
- The output characteristics curve shows the variation of the collector current (I_C) with respect to the collector-emitter voltage (V_CE) for different values of the base current (I_B). It has three regions: the cut-off region, where I_C is zero and the BJT is off; the active region, where I_C is proportional to I_B and the BJT is on; and the saturation region, where I_C is constant and the BJT is fully on. The output characteristics curve can be used to determine the output resistance of the BJT, which is the ratio of the change in V_CE to the change in I_C. It can also be used to determine the DC current gain (h_FE), which is the ratio of I_C to I_B, and the Early voltage (V_A), which is the extrapolated intercept of the output characteristics curve on the V_CE axis.
- The CE configuration of BJT has some limitations, such as the common-emitter breakdown voltage (BV_CE0), which is the maximum value of V_CE that the BJT can withstand without undergoing avalanche breakdown. It also has a phase shift of 180 degrees between the input and output signals, which means that the output signal is inverted with respect to the input signal.
