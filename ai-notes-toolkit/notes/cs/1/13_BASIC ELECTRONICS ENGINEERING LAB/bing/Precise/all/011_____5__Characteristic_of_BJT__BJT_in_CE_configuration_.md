### 5. Characteristics of BJT: BJT in CE configuration

1. **Current Gain:** The current gain of a BJT in CE configuration is defined as the ratio of the collector current to the base current. It is denoted by β.
2. **Voltage Gain:** The voltage gain of a BJT in CE configuration is defined as the ratio of the output voltage to the input voltage. It is typically high and can be controlled by the biasing conditions.
3. **Input Impedance:** The input impedance of a BJT in CE configuration is the ratio of the input voltage to the input current. It is typically low, in the range of a few hundred ohms.
4. **Output Impedance:** The output impedance of a BJT in CE configuration is the ratio of the output voltage to the output current. It is typically high, in the range of a few kilo-ohms.
5. **Phase Shift:** The phase shift of a BJT in CE configuration is the difference in phase between the input and output signals. It is typically 180 degrees, meaning that the output signal is inverted with respect to the input signal.

These are some of the key characteristics of a BJT in CE configuration. They determine the performance of the device in various applications.
