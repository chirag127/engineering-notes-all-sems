### Operational Amplifier as Adder and Subtractor

An operational amplifier, or op-amp, is a high-gain electronic voltage amplifier with a differential input and, usually, a single-ended output. It can be used in a variety of applications, including as an adder and subtractor.

#### Adder
An adder circuit is used to add multiple input signals and produce a single output signal that is the sum of the inputs. An op-amp can be used to create an adder circuit by connecting multiple input signals to the inverting input of the op-amp through individual resistors. The non-inverting input is connected to ground. The output of the op-amp is fed back to the inverting input through a feedback resistor. The output voltage is proportional to the sum of the input voltages.

#### Subtractor
A subtractor circuit is used to subtract one input signal from another and produce a single output signal that is the difference between the inputs. An op-amp can be used to create a subtractor circuit by connecting one input signal to the non-inverting input of the op-amp and the other input signal to the inverting input through a resistor. The output of the op-amp is fed back to the inverting input through a feedback resistor. The output voltage is proportional to the difference between the input voltages.

In summary, an operational amplifier can be used as an adder and subtractor by appropriately connecting the input signals and feedback resistor to the op-amp. This allows for the addition and subtraction of multiple input signals to produce a single output signal.
