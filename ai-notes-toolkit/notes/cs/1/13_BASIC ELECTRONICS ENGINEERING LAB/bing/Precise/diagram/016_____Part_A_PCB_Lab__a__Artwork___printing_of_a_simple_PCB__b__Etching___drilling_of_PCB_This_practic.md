### Part A PCB Lab: 
a. Artwork & printing of a simple PCB. 
b. Etching & drilling of PCB 

This practical is not possible by virtual lab. It will be conducted only in physical mode.

1. **Artwork & printing of a simple PCB**: The first step in creating a PCB is to design the circuit and create the artwork. This can be done using a computer-aided design (CAD) program. Once the design is complete, it is printed onto a transparent film using a high-resolution printer. This film is then used to create the PCB.

2. **Etching & drilling of PCB**: After the artwork is printed, the PCB is etched. This involves removing the unwanted copper from the board to create the desired circuit pattern. This is typically done using a chemical etching process. Once the etching is complete, the PCB is drilled to create holes for the components to be mounted.

It is important to note that this practical can only be conducted in physical mode and not in a virtual lab.
