### Components of C Language

* Standard I/O in C
- printf() - prints output to console
- scanf() - takes input from console
- Various format specifiers like %d, %f, %s, etc. to print different types of data

* Fundamental Data types
- int, float, double, char, etc.
- sizeof() operator to get size of data types

* Variables and Memory Locations
- Variables store values at memory locations
- Memory is stack allocated or heap allocated depending on variable scope and lifetime

* Storage Classes
- auto, register, static, extern to declare variable scope and linkage
