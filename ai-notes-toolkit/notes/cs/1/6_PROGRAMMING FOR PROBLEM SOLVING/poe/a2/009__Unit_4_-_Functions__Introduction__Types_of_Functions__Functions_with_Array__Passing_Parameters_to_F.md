## Unit 4 - Functions: Introduction, Types of Functions, Functions with Array, Passing Parameters to Functions, Call by Value, Call by Reference, Recursive Functions.

1. Introduction to Functions:
- A function is a block of organized, reusable code that is used to perform a single, related action.
- Functions allow you to segment your code into logical blocks, making it more structured, easier to read and debug.
- You can call/invoke/execute functions whenever needed. This avoids repetition and makes the code modular.

2. Types of Functions:
- Built-in functions: Functions that are built into the programming language like print(), input(), etc. in Python.
- User-defined functions: Functions defined by the user to perform a specific task. You need to define them before calling them.

3. Functions with Array:
- You can pass entire arrays to functions. The function can then process the array and return it or modify it.
- For example, you can pass an array to a sorting function to sort the elements or to a calculation function to calculate the average, etc.
