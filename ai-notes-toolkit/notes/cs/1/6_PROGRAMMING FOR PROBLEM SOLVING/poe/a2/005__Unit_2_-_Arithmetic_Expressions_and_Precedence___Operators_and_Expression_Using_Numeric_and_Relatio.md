## Unit 2 - Arithmetic Expressions and Precedence : Operators and Expression Using Numeric and Relational Operators, Mixed Operands, Type Conversion, Logical Operators, Bit Operations, Assignment Operator, Operator precedence and Associatively.

1. Numeric Operators
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%) - Remainder of a division

2. Relational Operators
- Greater than (>)
- Less than (<)
- Greater than or equal to (>=)
- Less than or equal to (<=)
- Equal to (==)
- Not equal to (!=)

3. Type Conversion
- Explicit - Using functions like int(), float(), etc.
- Implicit - Automatic conversion done by compiler

4. Logical Operators
- AND (&&) - Returns true if both operands are true
- OR (||) - Returns true if any of the operands is true
- NOT (!) - Inverts the logical state of its operand

5. Bitwise Operators
- AND (&) - Sets each bit to 1 if both bits are 1
- OR (|) - Sets each bit to 1 if one of two bits is 1
- XOR (^) - Sets each bit to 1 if only one of two bits is 1
- NOT (~) - Inverts all the bits
- Zero-fill shift (<<) - Shifts left by pushing zeros in from the right and letting the leftmost bits fall off
- Signed shift (>>) - Shifts right by pushing copies of the leftmost bit in from the left, and letting the rightmost bits fall off

6. Assignment Operator
- (=) - Assigns values from right side expressions to left side variables

7. Operator Precedence and Associativity
- Precedence - The order in which operators are evaluated
- Associativity - The direction in which operators of the same precedence are evaluated
