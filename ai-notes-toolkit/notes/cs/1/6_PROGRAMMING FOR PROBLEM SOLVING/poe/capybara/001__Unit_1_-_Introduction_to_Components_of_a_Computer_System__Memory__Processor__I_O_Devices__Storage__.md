## Unit 1 - Introduction to Components of a Computer System: Memory, Processor, I/O Devices, Storage, Operating System, Concept of Assembler, Compiler, Interpreter, Loader and Linker

In this unit, we will learn about the various components that make up a computer system. These components include:

- **Memory:** This is where the computer stores data and instructions that it needs to perform various tasks. There are two types of memory - primary memory (RAM) and secondary memory (hard disk, SSD, etc.).

- **Processor:** This is the "brain" of the computer. It executes instructions and performs calculations. The speed of the processor is measured in GHz (gigahertz).

- **I/O Devices:** These are the input and output devices that allow the user to interact with the computer. Examples include keyboards, mice, printers, and monitors.

- **Storage:** This is where the computer stores data and applications. There are two types of storage - primary storage (RAM) and secondary storage (hard disk, SSD, etc.).

- **Operating System:** This is the software that manages the computer's resources and provides a user interface. Examples include Windows, macOS, and Linux.

- **Assembler:** This is a program that converts assembly language into machine language.

- **Compiler:** This is a program that converts high-level programming languages into machine language.

- **Interpreter:** This is a program that executes instructions directly, without first translating them into machine language.

- **Loader:** This is a program that loads executable files into memory so that they can be executed.

- **Linker:** This is a program that combines object files into a single executable file.

In summary, understanding the components of a computer system is essential for anyone working with computers. By understanding how each component works, we can better optimize our computer systems for optimal performance.
