## Unit 4 - Functions: Introduction, Types of Functions, Functions with Array, Passing Parameters to Functions, Call by Value, Call by Reference, Recursive Functions.

Functions are a fundamental concept in programming that allow developers to break down complex tasks into manageable, reusable pieces of code. In this unit, we will explore the basics of functions and how they can be used to improve the efficiency and readability of your code.

### Introduction to Functions

- A function is a block of code that performs a specific task.
- Functions are used to modularize code, making it easier to read, debug, and maintain.
- Functions can be called from other parts of your code, making them highly reusable.
- The syntax for defining a function is as follows:
```python
def function_name(parameters):
    # function body
    return value
```
- The `def` keyword is used to define a function, followed by the function name and any parameters it accepts.
- The function body is indented and contains the logic for performing the task.
- The `return` keyword is used to specify the value that the function should return when it is called.

### Types of Functions

- There are two main types of functions: built-in functions and user-defined functions.
- Built-in functions are provided by the programming language and can be called directly without being defined by the user.
- Examples of built-in functions include `print()`, `len()`, and `range()`.
- User-defined functions are created by the user and can be tailored to perform specific tasks.
- User-defined functions can be called just like built-in functions.

### Functions with Array

- In addition to accepting standard parameters, functions can also accept arrays as input.
- Arrays can be passed to a function in the same way as other parameters.
- Functions can also return arrays as output, allowing them to be used in more complex tasks.

### Passing Parameters to Functions

- Parameters are used to pass data to a function.
- Parameters can be defined when the function is created and passed when the function is called.
- There are two ways to pass parameters to a function: call by value and call by reference.

### Call by Value

- Call by value is a method of passing parameters where the value of the parameter is copied and passed to the function.
- Changes made to the value within the function do not affect the original value.

### Call by Reference

- Call by reference is a method of passing parameters where a reference to the original value is passed to the function.
- Changes made to the value within the function affect the original value.

### Recursive Functions

- A recursive function is a function that calls itself.
- Recursive functions can be used to solve complex problems by breaking them down into smaller sub-problems.
- Recursive functions must have a base case to prevent infinite recursion.

In conclusion, functions are a powerful tool for organizing and modularizing your code. By breaking down complex tasks into smaller, reusable pieces, you can make your code more efficient, readable, and maintainable. Understanding the different types of functions and how to pass parameters to them is essential for any developer.
