### Programming Basics: Structure of C Program, Writing and Executing the First C Program, Syntax and Logical Errors in Compilation, Object and Executable Code.

- A C program is a collection of one or more functions that perform a specific task.
- A function is a block of code that has a name, a set of parameters, and a return value.
- The main function is the starting point of a C program. It is where the program execution begins and ends.
- A C program has the following basic structure:

```c
// Preprocessor directives
#include <stdio.h>
// Other header files or macros

// Function prototypes
void func1(int x);
int func2(char c);

// Global variables
int a = 10;
char b = 'A';

// Main function
int main()
{
    // Local variables
    int x = 20;
    char y = 'B';

    // Statements
    printf("Hello, world!\n");
    func1(x);
    y = func2(b);
    printf("y = %c\n", y);

    // Return statement
    return 0;
}

// Function definitions
void func1(int x)
{
    // Statements
    printf("x = %d\n", x);
}

int func2(char c)
{
    // Statements
    return c + 1;
}
```

- To write a C program, you need a text editor and a compiler.
- A text editor is a software that allows you to create and edit text files. You can use any text editor of your choice, such as Notepad, Visual Studio Code, or Sublime Text.
- A compiler is a software that translates the source code written in C into machine code that can be executed by the computer. You can use any compiler of your choice, such as GCC, Clang, or Visual Studio.
- To execute a C program, you need to follow these steps:
  - Save the source code in a text file with a .c extension, such as hello.c
  - Compile the source code using the compiler, such as gcc hello.c -o hello.exe
  - Run the executable file generated by the compiler, such as hello.exe
- During the compilation process, the compiler may encounter errors in the source code that prevent it from generating the executable file. These errors can be classified into two types: syntax errors and logical errors.
- Syntax errors are errors that violate the rules of the C language, such as missing semicolons, mismatched parentheses, or undeclared variables. Syntax errors are detected by the compiler and reported as error messages. For example:

```c
// Syntax error: missing semicolon
int x = 10

// Syntax error: mismatched parentheses
if (x > 0 {
    printf("x is positive\n");
}

// Syntax error: undeclared variable
y = x + 1;
```

- Logical errors are errors that cause the program to behave incorrectly or produce unexpected results, such as wrong calculations, incorrect conditions, or infinite loops. Logical errors are not detected by the compiler and may not produce any error messages. For example:

```c
// Logical error: wrong calculation
int area = 2 * 3.14 * r; // Should be 3.14 * r * r

// Logical error: incorrect condition
if (x = 0) // Should be x == 0
{
    printf("x is zero\n");
}

// Logical error: infinite loop
while (x > 0) // Should be x < 0
{
    x--;
}
```

- To fix syntax errors, you need to read the error messages carefully and locate the source of the error in the code. Then, you need to correct the code according to the rules of the C language.
- To fix logical errors, you need to debug the program using tools such as breakpoints, watches, or print statements. Then, you need to identify the cause of the error and modify the code accordingly.
- The output of the compilation process is an object file that contains the machine code of the program. The object file has a .o or .obj extension, such as hello.o or hello.obj
- The object file is not yet executable by the computer. It needs to be linked with other object files or libraries that provide additional functionality, such as input/output, math, or graphics. The linking process is done by a linker, which is usually part of the compiler.
