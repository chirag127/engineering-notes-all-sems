## Unit 1 - Introduction to Components of a Computer System: Memory, Processor, I/O Devices, Storage, Operating System, Concept of Assembler, Compiler, Interpreter, Loader and Linker.

- A computer system is a combination of hardware and software that performs various tasks such as input, processing, output, and storage.
- The main components of a computer system are:
  - Memory: It is the part of the computer that stores data and instructions temporarily or permanently. Memory can be classified into two types: volatile and non-volatile. Volatile memory, such as RAM, loses its contents when the power is turned off. Non-volatile memory, such as ROM, retains its contents even when the power is off .
  - Processor: It is the part of the computer that executes the instructions and performs the calculations. The processor consists of two main units: the arithmetic logic unit (ALU) and the control unit (CU). The ALU performs arithmetic and logical operations, while the CU controls the flow of data and instructions .
  - I/O Devices: They are the parts of the computer that allow the user to interact with the computer and the external environment. Input devices, such as keyboard and mouse, provide data input to the processor. Output devices, such as monitor and printer, display or print the results of the processing .
  - Storage: It is the part of the computer that stores data and instructions permanently or semi-permanently. Storage devices can be classified into two types: primary and secondary. Primary storage, such as cache and registers, is directly accessible by the processor and has high speed but low capacity. Secondary storage, such as hard disk and optical disk, is indirectly accessible by the processor and has low speed but high capacity .
  - Operating System: It is the software that manages the resources and activities of the computer system. It provides an interface between the user and the hardware, and between the application programs and the hardware. It performs functions such as process management, memory management, file management, device management, security, and networking .
- The concept of assembler, compiler, interpreter, loader, and linker are related to the translation and execution of programs written in high-level languages, such as C and Java, into machine code that can be understood by the processor.
  - Assembler: It is a program that converts assembly language, which is a low-level language that uses mnemonics and symbols, into machine code.
  - Compiler: It is a program that converts high-level language, which is a language that uses English-like words and syntax, into machine code in one go. It generates an executable file that can be run by the processor.
  - Interpreter: It is a program that converts high-level language into machine code line by line. It does not generate an executable file, but executes the program directly in memory.
  - Loader: It is a program that loads the executable file generated by the compiler or the assembler into memory and prepares it for execution.
  - Linker: It is a program that links the executable file with the libraries and other modules that are required by the program. It resolves the references and addresses of the external symbols and functions.
