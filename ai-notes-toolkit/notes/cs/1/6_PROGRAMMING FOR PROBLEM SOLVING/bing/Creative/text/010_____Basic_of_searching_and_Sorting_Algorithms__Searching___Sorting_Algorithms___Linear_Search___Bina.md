### Basic of Searching and Sorting Algorithms

Searching and sorting algorithms are fundamental techniques for manipulating data in a computer program. They are widely used in various applications, such as databases, web search engines, cryptography, and artificial intelligence.

Searching algorithms are methods for finding a specific element or a set of elements that satisfy some criteria in a collection of data, such as an array, a list, a tree, or a graph. Sorting algorithms are methods for arranging the elements of a collection in a specific order, such as ascending, descending, alphabetical, or numerical.

Some of the most common and simple searching and sorting algorithms are:

- **Linear search**: A searching algorithm that scans each element of a collection from left to right until it finds the target element or reaches the end of the collection. It has a time complexity of O(n), where n is the number of elements in the collection.
- **Binary search**: A searching algorithm that works on a sorted collection and repeatedly divides the search range in half until it finds the target element or determines that it does not exist. It has a time complexity of O(log n), where n is the number of elements in the collection.
- **Bubble sort**: A sorting algorithm that repeatedly compares and swaps adjacent elements of a collection until it is sorted. It has a time complexity of O(n^2), where n is the number of elements in the collection.
- **Insertion sort**: A sorting algorithm that iterates over the elements of a collection and inserts each element into its correct position in a sorted subarray. It has a time complexity of O(n^2), where n is the number of elements in the collection.
- **Selection sort**: A sorting algorithm that iterates over the elements of a collection and selects the smallest (or largest) element and swaps it with the first (or last) element of the unsorted subarray. It has a time complexity of O(n^2), where n is the number of elements in the collection.
