## Structure of C Program

- A C program consists of one or more functions, which are blocks of code that perform a specific task.
- The main function is the starting point of the program, where the execution begins.
- The main function can call other functions, which can call other functions, and so on, forming a hierarchy of function calls.
- A function has a name, a list of parameters, and a body that contains the statements to execute.
- A function can return a value to the caller using the return statement.
- A function can also use variables, which are names for data that can be stored, changed, and used in the program.
- A variable has a name, a type, and a value. The type determines the size and format of the data that can be stored in the variable.
- A variable can be declared at the beginning of a function, or inside a block of code delimited by curly braces {}.
- A variable can be initialized with a value when it is declared, or assigned a value later using the assignment operator =.
- A variable can be used in expressions, which are combinations of values, variables, and operators that produce a new value.
- A variable can also be passed as an argument to a function, which means that the function can use the value of the variable in its body.
- A C program can also use comments, which are lines of text that are ignored by the compiler and are used to explain or document the code.
- A comment can start with /* and end with */, or start with // and end with the end of the line.
- A C program can also use preprocessor directives, which are lines of code that start with # and are processed by the preprocessor before the compilation.
- A preprocessor directive can include a header file, which is a file that contains declarations of functions, variables, constants, and types that can be used in the program.
- A preprocessor directive can also define a macro, which is a name that can be replaced by a value or a code fragment by the preprocessor.
- A preprocessor directive can also use conditional compilation, which is a way of selecting which parts of the code to compile or ignore based on some conditions.

## Writing and Executing the First C Program

- To write a C program, you need a text editor, which is a software that allows you to create and edit text files.
- You can use any text editor you like, such as Notepad, Visual Studio Code, or Sublime Text.
- You need to save your C program with a .c extension, which indicates that it is a C source file.
- A simple C program that prints "Hello, world!" to the standard output can be written as follows:

```c
// This is a comment
#include <stdio.h> // This is a preprocessor directive that includes the header file stdio.h
int main() // This is the main function
{
    printf("Hello, world!\n"); // This is a statement that calls the printf function
    return 0; // This is a statement that returns 0 to the caller
}
```

- To execute a C program, you need a compiler, which is a software that translates the C source code into executable code that can run on your computer.
- You can use any compiler you like, such as GCC, Clang, or Visual Studio.
- You need to compile your C program with the compiler, which will produce an object file and an executable file.
- The object file contains the machine code that corresponds to the C source code, and has a .o or .obj extension.
- The executable file contains the machine code that can be run by the operating system, and has a .exe extension on Windows or no extension on Linux or Mac OS.
- You need to run the executable file with the operating system, which will execute the machine code and produce the output of the program.
- The output of the program can be displayed on the screen, written to a file, or sent to another program.
