## Unit 1 - Introduction to Components of a Computer System: Memory, Processor, I/O Devices, Storage, Operating System, Concept of Assembler, Compiler, Interpreter, Loader and Linker.

A computer system is a device that can perform various tasks by processing data and information. A computer system consists of two main components: hardware and software. Hardware refers to the physical parts of the computer, such as the motherboard, CPU, GPU, RAM, storage, and I/O devices. Software refers to the programs and instructions that run on the computer, such as the operating system, applications, and utilities.

The following are the main components of a computer system and their functions:

- **Memory**: Memory is the component that stores data and instructions temporarily or permanently. Memory can be classified into two types: volatile and non-volatile. Volatile memory, such as RAM, loses its contents when the power is turned off. Non-volatile memory, such as ROM, retains its contents even when the power is off. Memory can also be classified into primary and secondary memory. Primary memory, such as RAM and cache, is directly accessible by the CPU and is faster but more expensive than secondary memory. Secondary memory, such as hard disk and flash drive, is indirectly accessible by the CPU and is slower but cheaper than primary memory.
- **Processor**: Processor, also known as CPU, is the component that executes the instructions and performs the calculations and logic operations. Processor consists of two main parts: the control unit and the arithmetic logic unit. The control unit fetches, decodes, and controls the execution of instructions. The arithmetic logic unit performs the arithmetic and logic operations on the data. Processor can have one or more cores, which are independent units that can execute instructions simultaneously. Processor can also have a cache, which is a small and fast memory that stores frequently used data and instructions.
- **I/O Devices**: I/O devices, also known as input/output devices, are the components that allow the user to interact with the computer and the external environment. Input devices, such as keyboard, mouse, scanner, and microphone, provide data and commands to the computer. Output devices, such as monitor, printer, speaker, and headphone, display or produce the results or feedback from the computer. Some devices, such as touchscreen, webcam, and joystick, can function as both input and output devices.
- **Storage**: Storage is the component that stores data and information permanently or semi-permanently. Storage can be classified into two types: internal and external. Internal storage, such as hard disk, SSD, and optical disk, is located inside the computer case and is connected to the motherboard. External storage, such as USB drive, memory card, and cloud storage, is located outside the computer case and is connected to the computer via a cable or a wireless network. Storage can also be classified into two types: magnetic and optical. Magnetic storage, such as hard disk and floppy disk, uses a magnetized surface to store data. Optical storage, such as CD, DVD, and Blu-ray, uses a laser beam to read and write data.
- **Operating System**: Operating system, also known as OS, is the software that manages the resources and activities of the computer system. Operating system performs various functions, such as:

  - Booting: Loading the OS into the memory when the computer is turned on.
  - User Interface: Providing a graphical or textual interface for the user to interact with the computer.
  - Process Management: Creating, scheduling, and terminating the processes that run on the computer.
  - Memory Management: Allocating, deallocating, and swapping the memory for the processes and the data.
  - File Management: Organizing, accessing, and manipulating the files and directories on the storage devices.
  - Device Management: Controlling, communicating, and coordinating the I/O devices and their drivers.
  - Security: Protecting the computer system from unauthorized access, viruses, and malware.
  - Networking: Enabling the communication and data transfer between the computer and other computers or devices on a network.

- **Concept of Assembler, Compiler, Interpreter, Loader and Linker**: Assembler, compiler, interpreter, loader and linker are the software tools that translate, load, and link the source code or the object code into the executable code that can run on the computer.
