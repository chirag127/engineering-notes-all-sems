### Programming Basics: Structure of C Program, Writing and Executing the First C Program, Syntax and Logical Errors in Compilation, Object and Executable Code

- A C program is a collection of one or more functions that perform a specific task.
- A function is a block of code that has a name, a set of parameters, and a return value.
- The main function is the starting point of a C program. It is called by the operating system when the program is executed.
- A C program can also include other files, such as header files, that contain declarations of constants, variables, and functions that are used in the program.
- A C program can be written using any text editor, such as Notepad, and saved with a .c extension.
- To execute a C program, it needs to be compiled and linked by a compiler, such as GCC, that converts the source code into machine code that can be understood by the computer.
- The compilation process involves two steps: preprocessing and translation.
- Preprocessing is the step where the compiler replaces the directives, such as #include and #define, with the corresponding code or value.
- Translation is the step where the compiler checks the syntax and semantics of the code and generates an object file that contains the machine code for each function.
- The object file has a .o extension and can be linked with other object files or libraries to form an executable file that can be run by the computer.
- The executable file has a .exe extension on Windows and no extension on Linux or Mac OS.
- The linking process can be done by the compiler or by a separate linker program, such as ld, that combines the object files and resolves the references between them.
- A syntax error is a mistake in the grammar or spelling of the code, such as a missing semicolon or a mismatched parenthesis, that prevents the compiler from translating the code.
- A logical error is a mistake in the logic or algorithm of the code, such as a wrong condition or a wrong calculation, that causes the program to produce incorrect or unexpected results.
- Syntax errors can be detected and reported by the compiler, but logical errors can only be found by testing and debugging the program.
- To test and debug a C program, one can use a debugger, such as gdb, that allows the user to run the program step by step, examine the values of variables, and set breakpoints and watchpoints to stop the program at certain points or when certain conditions are met.
