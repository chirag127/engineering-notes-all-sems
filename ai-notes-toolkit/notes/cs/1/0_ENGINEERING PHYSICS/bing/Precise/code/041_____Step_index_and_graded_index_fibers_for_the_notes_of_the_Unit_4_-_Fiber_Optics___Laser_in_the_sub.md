### Step Index and Graded Index Fibers

Step index fiber and graded index fiber are two types of optical fibers used in fiber optics communication. Here are some key points to note about these two types of fibers:

1. **Step index fiber** is a fiber in which the core is of a uniform refractive index and there is a sharp decrease in the index of refraction at the cladding.
2. **Graded index fiber** is a type of fiber where the refractive index of the core is maximum at the center core and then it decreases towards core-cladding interface.
3. One of the major differences between a step index fiber and a graded index fiber is that a step index fiber has a core with constant refractive index and makes a step change from the core – cladding interface while a graded index fiber does not have a core with constant refractive index, and it makes a gradual change from the core – cladding interface.
4. Step index fiber is often used for short distance communication. Step index fibers are less expensive to manufacture than graded index fibers. They have a higher numerical aperture, this allows them to collect light from a wider range of angles. Step index fibers have higher dispersion.
5. Step index fiber is of two types viz; mono mode fiber and multi mode fiber. Graded index fiber is of only of one type that is multi mode fiber.
6. In step index fiber, different modes are launched at different acceptance angles causing higher modes to travel longer paths. This causes modal dispersion. In graded index fiber, the refractive index of the core gradually lowers towards the cladding. Light travels faster in lower refractive index.
