# Ideal and Practical Transformer

## Ideal Transformer

- An ideal transformer is a hypothetical device that has no losses and no magnetic leakage.
- It has infinite permeability and zero reluctance of the core, so that all the flux produced by the primary winding links with the secondary winding.
- It has zero winding resistance and zero leakage reactance, so that there is no voltage drop in the windings and no reactive power loss.
- It has no iron losses (hysteresis and eddy current losses) in the core, so that there is no power loss in the core.
- It has no copper losses (I^2^R losses) in the windings, so that there is no power loss in the windings.
- It has no load regulation, meaning that the secondary voltage remains constant regardless of the load current.
- It has 100% efficiency, meaning that the input power equals the output power.

## Practical Transformer

- A practical transformer is a real device that has some losses and some magnetic leakage.
- It has finite permeability and some reluctance of the core, so that some of the flux produced by the primary winding does not link with the secondary winding. This is called the leakage flux.
- It has some winding resistance and some leakage reactance, so that there is some voltage drop in the windings and some reactive power loss. This is called the impedance drop.
- It has some iron losses (hysteresis and eddy current losses) in the core, so that there is some power loss in the core. This is called the core loss.
- It has some copper losses (I^2^R losses) in the windings, so that there is some power loss in the windings. This is called the copper loss.
- It has some load regulation, meaning that the secondary voltage decreases as the load current increases. This is called the voltage regulation.
- It has less than 100% efficiency, meaning that the input power is greater than the output power. This is called the efficiency.
