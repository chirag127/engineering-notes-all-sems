## Unit 1 - Matrices

- A matrix is a rectangular array of numbers, symbols, or expressions, arranged in rows and columns.
- The size or order of a matrix is given by the number of rows and columns it has. For example, a matrix with 3 rows and 2 columns has order 3 x 2.
- The elements of a matrix are denoted by a lowercase letter with two subscripts, indicating the row and column position. For example, a<sub>12</sub> is the element in the first row and second column of matrix A.
- A matrix can be represented by enclosing its elements in square brackets [ ] or parentheses ( ).
- A matrix can be classified into different types based on its properties, such as:
  - Square matrix: a matrix with the same number of rows and columns.
  - Diagonal matrix: a square matrix with all non-diagonal elements equal to zero.
  - Identity matrix: a diagonal matrix with all diagonal elements equal to one.
  - Zero matrix: a matrix with all elements equal to zero.
  - Row matrix: a matrix with only one row.
  - Column matrix: a matrix with only one column.
  - Scalar matrix: a diagonal matrix with all diagonal elements equal to the same scalar value.
  - Symmetric matrix: a square matrix that is equal to its transpose, i.e., A = A<sup>T</sup>.
  - Skew-symmetric matrix: a square matrix that is equal to the negative of its transpose, i.e., A = -A<sup>T</sup>.
  - Upper triangular matrix: a square matrix with all elements below the main diagonal equal to zero.
  - Lower triangular matrix: a square matrix with all elements above the main diagonal equal to zero.
- Matrices can be added, subtracted, multiplied, and divided by scalars, as well as multiplied by other matrices, following certain rules and conditions.
- The transpose of a matrix is obtained by interchanging its rows and columns, i.e., the element in the i<sup>th</sup> row and j<sup>th</sup> column of A becomes the element in the j<sup>th</sup> row and i<sup>th</sup> column of A<sup>T</sup>.
- The determinant of a square matrix is a scalar value that represents the area or volume of the parallelogram or parallelepiped spanned by the column vectors of the matrix. It can be calculated by various methods, such as expansion by minors, cofactors, or Laplace's formula.
- The inverse of a square matrix A is another matrix A<sup>-1</sup> such that AA<sup>-1</sup> = A<sup>-1</sup>A = I, where I is the identity matrix. The inverse of a matrix can be found by using the adjoint method, the row reduction method, or the Gauss-Jordan method.
- The rank of a matrix is the number of linearly independent rows or columns in the matrix. It can be determined by reducing the matrix to its row echelon form or column echelon form and counting the number of non-zero rows or columns.
- The system of linear equations Ax = b, where A is a matrix, x is a column vector of unknowns, and b is a column vector of constants, can be solved by various methods, such as matrix inversion, Cramer's rule, Gaussian elimination, or Gauss-Jordan elimination.
