### Euler’s Theorem for homogeneous functions

- A function f(x, y, z, ...) is called **homogeneous** of degree n if f(tx, ty, tz, ...) = t^n f(x, y, z, ...) for any scalar t .
- For example, f(x, y, z) = x^3 + y^3 + z^3 + xy^2 + xz^2 + yx^2 + zx^2 + zy^2 + xyz is homogeneous of degree 3.
- Euler's theorem states that if f(x, y, z, ...) is a homogeneous function of degree n, then x ∂f/∂x + y ∂f/∂y + z ∂f/∂z + ... = n f(x, y, z, ...)   .
- This theorem can be proved by differentiating both sides of the definition of homogeneous function with respect to t and then setting t = 1 .
- Euler's theorem can be used to find the partial derivatives of homogeneous functions or to simplify the calculations of total derivatives or differentials .
