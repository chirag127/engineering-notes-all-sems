### Solution of system of linear equations

- A system of linear equations is a set of equations that involve the same variables and can be written in the form `a1x1 + a2x2 + ... + anxn = b`, where `a1, a2, ..., an` and `b` are constants and `x1, x2, ..., xn` are variables.
- A solution to a system of linear equations is an assignment of values to the variables that satisfies all the equations simultaneously. For example, the ordered pair `(4, 7)` is a solution to the system of equations `x + y = 11` and `2x - y = 1` because it makes both equations true.
- A system of linear equations can have zero, one, or infinitely many solutions, depending on how the equations are related to each other. If the equations are inconsistent, meaning that they have no common solution, then the system has zero solutions. If the equations are consistent and independent, meaning that they have exactly one common solution, then the system has one solution. If the equations are consistent and dependent, meaning that they have infinitely many common solutions, then the system has infinitely many solutions.
- There are different methods to find the solution of a system of linear equations, such as graphing, substitution, elimination, matrix methods, and Cramer's rule. Each method has its own advantages and disadvantages, depending on the type and number of equations, the number of variables, and the coefficients of the equations.
- Graphing is a method that involves plotting the graphs of the equations on the same coordinate plane and finding the point(s) of intersection, if any. The point(s) of intersection are the solution(s) of the system. Graphing is a visual and intuitive method, but it may not be very accurate or efficient, especially if the equations are not in slope-intercept form or if the solution is not an integer.
- Substitution is a method that involves solving one equation for one variable in terms of the other variables, and then substituting the expression into the other equation(s) to eliminate that variable. The process is repeated until only one variable remains, and then the value of that variable is found. Substitution is a simple and logical method, but it may involve a lot of algebraic manipulation and fractions, especially if the coefficients are not integers.
- Elimination is a method that involves adding, subtracting, or multiplying the equations by appropriate constants to eliminate one or more variables. The process is repeated until only one variable remains, and then the value of that variable is found. Elimination is a fast and systematic method, but it may also involve a lot of algebraic manipulation and fractions, especially if the coefficients are not integers or if the system is not in standard form.
- Matrix methods are methods that involve representing the system of equations as a matrix, which is a rectangular array of numbers, and then performing certain operations on the matrix to reduce it to a simpler form, such as row echelon form or reduced row echelon form. The solution of the system can then be read from the matrix. Matrix methods are efficient and convenient, especially for large systems of equations, but they require knowledge of matrix operations and notation, and they may not be very intuitive or easy to remember.
- Cramer's rule is a method that involves finding the determinant of the coefficient matrix and the augmented matrix of the system, and then using a formula to find the value of each variable. The determinant is a number that represents the area or volume of a parallelogram or a parallelepiped formed by the column vectors of the matrix. Cramer's rule is a direct and elegant method, but it only works for square systems of equations, meaning that the number of equations and variables are equal, and it may involve a lot of computation and fractions, especially if the determinant is large or not a multiple of the denominator.
