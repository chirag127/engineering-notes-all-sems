### Approximation of errors for the notes of the Unit 3 - Differential Calculus-II in the subject of ENGINEERING MATHEMATICS-I

- The approximation of errors is the study of how to estimate the change or error in the value of a function due to a small change or error in the value of its independent variable.
- The approximation of errors can be done using differentials, linear approximation, or error propagation methods.
- Differentials are the product of the derivative of a function and the change in the independent variable, i.e. `dy = f'(x)dx` or `df(x) = f'(x)dx`.
- Differentials can be used to approximate the change in the value of a function, i.e. `Δy ≈ dy` or `f(x + dx) ≈ f(x) + dy`.
- Linear approximation is the process of finding a linear function that is close to a given function at a given point. The linear function is usually the tangent line to the function at that point.
- Linear approximation can be used to estimate the value of a function near a given point, i.e. `f(x) ≈ f(a) + f'(a)(x - a)`, where `a` is the given point and `f'(a)` is the slope of the tangent line.
- Error propagation is the technique of finding the error in the value of a function due to the errors in the values of its inputs. The error in the function is usually proportional to the errors in the inputs and their derivatives.
- Error propagation can be used to estimate the maximum possible error in the value of a function, i.e. `|Δy| ≤ |f'(x)| |Δx|`, where `Δy` is the error in the function, `f'(x)` is the derivative of the function, and `Δx` is the error in the input.
- The relative error and percentage error are the ratios of the absolute error to the exact value of the function or the input, i.e. `relative error = |Δy| / |y|` and `percentage error = (|Δy| / |y|) * 100%`.
