## Unit 2 - Differential Calculus- I

Differential calculus is a branch of mathematics that studies the rate of change of functions. It has many applications in science, engineering, economics, and other fields.

Some of the basic concepts and rules of differential calculus are:

- **Derivative**: The derivative of a function f(x) at a point x=a is the limit of the ratio of the change in f(x) to the change in x as x approaches a, if it exists. It is denoted by f'(a) or df/dx|<sub>x=a</sub>. The derivative measures the slope of the tangent line to the graph of f(x) at x=a. It also gives the instantaneous rate of change of f(x) at x=a.

- **Differentiation**: The process of finding the derivative of a function is called differentiation. There are various rules and formulas for finding the derivatives of different types of functions, such as:

  - **Power rule**: If f(x) = x<sup>n</sup>, where n is any constant, then f'(x) = nx<sup>n-1</sup>.
  - **Sum rule**: If f(x) = g(x) + h(x), then f'(x) = g'(x) + h'(x).
  - **Product rule**: If f(x) = g(x)h(x), then f'(x) = g'(x)h(x) + g(x)h'(x).
  - **Quotient rule**: If f(x) = g(x)/h(x), where h(x) ≠ 0, then f'(x) = (g'(x)h(x) - g(x)h'(x))/h(x)<sup>2</sup>.
  - **Chain rule**: If f(x) = g(h(x)), then f'(x) = g'(h(x))h'(x).

- **Applications of derivatives**: Derivatives can be used to find various properties and characteristics of functions, such as:

  - **Extrema**: The maximum and minimum values of a function are called extrema. A function f(x) has a local maximum at x=a if f(a) ≥ f(x) for all x near a. Similarly, f(x) has a local minimum at x=a if f(a) ≤ f(x) for all x near a. A function f(x) has an absolute maximum at x=a if f(a) ≥ f(x) for all x in the domain of f(x). Similarly, f(x) has an absolute minimum at x=a if f(a) ≤ f(x) for all x in the domain of f(x). To find the extrema of a function, we can use the following steps:

    - Find the critical points of f(x), which are the points where f'(x) = 0 or f'(x) is undefined.
    - Use the first derivative test or the second derivative test to determine whether the critical points are local maxima, local minima, or neither.
    - Compare the values of f(x) at the critical points and the endpoints of the domain (if any) to find the absolute maxima and minima.
