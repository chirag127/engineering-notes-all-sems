# Curve tracing for the notes of the Unit 2 - Differential Calculus- I in the subject of ENGINEERING MATHEMATICS-I

- Curve tracing is the method of studying the properties and shape of a curve whose equation is given in cartesian, polar or parametric form.
- Curve tracing helps to sketch the graph of a function using the information obtained from its derivatives, such as extrema, concavity, inflection points, asymptotes, etc .
- Curve tracing also helps to find the traces of a surface, which are the curves that represent the intersection of the surface and a plane.

## Steps for curve tracing

- Identify the type of equation (cartesian, polar or parametric) and the degree of the curve (linear, quadratic, cubic, etc).
- Find the domain and range of the function, and the intervals where it is defined, continuous and differentiable.
- Find the x- and y-intercepts of the curve, if any, by setting y = 0 and x = 0 respectively.
- Find the symmetry of the curve, if any, by checking if f(x) = f(-x), f(-x) = -f(x), or f(x) = -f(-x).
- Find the asymptotes of the curve, if any, by checking the limits of the function as x or y approaches infinity or a finite value.
- Find the first derivative of the function and use it to find the critical points, where f'(x) = 0 or undefined, and the intervals where the function is increasing or decreasing.
- Find the second derivative of the function and use it to find the points of inflection, where f''(x) = 0 or undefined, and the intervals where the function is concave up or concave down.
- Plot the points and intervals obtained from the previous steps on a number line and use them to sketch the curve.
- Label the important features of the curve, such as intercepts, extrema, inflection points, asymptotes, etc.

## Example of curve tracing

- Consider the function f(x) = x^3 - 3x^2 - 9x + 5.
- The equation is cartesian and the degree is cubic.
- The domain of the function is all real numbers, and the range is also all real numbers. The function is defined, continuous and differentiable for all x.
- The x-intercepts are the solutions of f(x) = 0, which are x = -1, x = 1, and x = 5. The y-intercept is f(0) = 5.
- The function has no symmetry, as f(x) ≠ f(-x), f(-x) ≠ -f(x), and f(x) ≠ -f(-x).
- The function has no asymptotes, as the limits of the function as x or y approaches infinity or a finite value are either finite or do not exist.
- The first derivative of the function is f'(x) = 3x^2 - 6x - 9. The critical points are the solutions of f'(x) = 0, which are x = -1 and x = 3. The function is increasing on (-∞, -1) and (3, ∞), and decreasing on (-1, 3).
- The second derivative of the function is f''(x) = 6x - 6. The point of inflection is the solution of f''(x) = 0, which is x = 1. The function is concave up on (1, ∞), and concave down on (-∞, 1).
