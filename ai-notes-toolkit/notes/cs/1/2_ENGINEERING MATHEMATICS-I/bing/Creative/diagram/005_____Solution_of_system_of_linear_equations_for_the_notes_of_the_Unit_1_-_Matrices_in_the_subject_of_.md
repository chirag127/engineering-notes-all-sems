### Solution of system of linear equations

- A system of linear equations is a set of two or more equations with the same variables, such as:

```
x + y = 5
2x - y = 1
```

- A solution to a system of linear equations is an assignment of values to the variables that makes all the equations true at the same time, such as:

```
x = 2, y = 3
```

- A system of linear equations can have zero, one, or infinitely many solutions, depending on how the equations are related to each other.

- A system of linear equations can be represented by a matrix, which is a rectangular array of numbers arranged in rows and columns, such as:

```
| 1  1 | | x |   | 5 |
| 2 -1 | | y | = | 1 |
```

- A matrix can be used to perform operations on the system of linear equations, such as adding, subtracting, or multiplying rows or columns, or swapping the order of rows or columns.

- The goal of these operations is to transform the matrix into a simpler form, such as an echelon form or a reduced echelon form, which makes it easier to find the solution to the system of linear equations.

- An echelon form of a matrix is one where the first nonzero element in each row (called the leading entry) is to the right of the leading entry of the row above it, and all the elements below a leading entry are zero, such as:

```
| 1  1 | | x |   | 5 |
| 0 -3 | | y | = | 9 |
```

- A reduced echelon form of a matrix is one where the leading entry in each row is 1, and all the elements above and below a leading entry are zero, such as:

```
| 1  0 | | x |   | 2 |
| 0  1 | | y | = | 3 |
```

- A system of linear equations can be solved by using different methods, such as:

  - Graphing: Plotting the equations on a coordinate plane and finding the point of intersection, if any.
  - Substitution: Solving one equation for one variable and substituting it into the other equation(s) to eliminate it.
  - Elimination: Adding or subtracting the equations to eliminate one variable and solve for the other(s).
  - Matrix methods: Using matrices to represent and manipulate the system of linear equations, such as Gaussian elimination, Gauss-Jordan elimination, inverse matrix method, or Cramer's rule.
