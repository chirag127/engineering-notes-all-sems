

#### Course Outcomes:

- Understand and explain the fundamentals of software engineering 
- Develop and evaluate software solutions using appropriate development methodologies 
- Analyze and design software solutions using appropriate software engineering tools and techniques 
- Implement and test software solutions using appropriate software engineering tools and techniques 
- Evaluate the impact of software engineering on society and the environment 
- Develop and demonstrate an understanding of professional, ethical, legal, security and social issues related to software engineering
