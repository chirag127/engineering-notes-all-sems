##### 7. Determination of the efficiency of a dc motor by loss summation method (Swinburne's test)

- Connect the dc motor to a dc supply and load it with a variable resistance.
- Note down the readings of armature current (Ia), armature voltage (Va), field current (If) and speed (N) for different loads.
- Calculate the copper loss (Pcu) in armature for each load using Ia^2 Ra where Ra is armature resistance.
- Calculate the iron loss (Pw) for each load using Steinmetz's formula Pw = k1N^1.5 + k2 where N is speed, k1 and k2 are constants.
- Calculate the mechanical output (Pm) for each load using torque and speed equations.
- Efficiency (eta) is calculated using eta = (Pm) / (Va Ia) for each load.
- Plot a graph of efficiency Vs load. Efficiency decreases with increase in load.
- Maximum efficiency corresponds to optimum load on the motor.
