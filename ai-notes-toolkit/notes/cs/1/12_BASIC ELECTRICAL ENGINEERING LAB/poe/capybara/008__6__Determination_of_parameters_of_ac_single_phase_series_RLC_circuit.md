##### 6. Determination of parameters of ac single phase series RLC circuit.

In order to determine the parameters of an AC single phase series RLC circuit, the following steps need to be followed:

1. Measure the resistance (R) of the circuit using a multimeter. This can be done by connecting the multimeter in series with the circuit and taking the reading.

2. Measure the inductance (L) of the circuit using an inductance meter. This can be done by connecting the inductance meter in series with the circuit and taking the reading.

3. Measure the capacitance (C) of the circuit using a capacitance meter. This can be done by connecting the capacitance meter in parallel with the circuit and taking the reading.

4. Calculate the resonant frequency (fr) of the circuit using the formula:

    fr = 1 / (2 * pi * sqrt(L * C))

   where pi is the mathematical constant and sqrt is the square root function.

5. Apply a sinusoidal voltage to the circuit and measure the current (I) and the voltage (V) across the circuit using an oscilloscope. 

6. Calculate the impedance (Z) of the circuit using the formula:

    Z = V / I

7. Calculate the phase angle (φ) between the voltage and current using the formula:

    φ = arctan((ωL - 1/ωC) / R)

   where arctan is the inverse tangent function and ω is the angular frequency.

8. Calculate the reactance (X) of the circuit using the formula:

    X = Z * sin(φ)

9. Calculate the inductive reactance (XL) using the formula:

    XL = ωL

10. Calculate the capacitive reactance (XC) using the formula:

    XC = 1 / (ωC)

11. Calculate the quality factor (Q) of the circuit using the formula:

    Q = XL / R

12. Calculate the bandwidth (BW) of the circuit using the formula:

    BW = fr / Q

   where fr is the resonant frequency calculated in step 4.

By following these steps, the parameters of an AC single phase series RLC circuit can be determined. These parameters are important for designing and analyzing circuits in various applications.
