### CO-5 Estimate the rate constant of reaction. K3

1. The rate constant (k) of a reaction can be estimated using the following methods:
- Study the effect of temperature on the rate of reaction. According to Arrhenius equation, k ∝ e^(-Ea/RT). A plot of log k vs 1/T gives a straight line with slope = -Ea/R. The value of k can be calculated at a given T.
- Study the effect of concentration on rate of reaction. For a reaction of nth order, the rate is given by, rate = k [A]^n. A plot of log rate vs log [A] gives a straight line with slope = n. The value of k can be calculated.
- Isolation method. If k can be isolated in a rate expression containing k, its value can be calculated if all other parameters are known.
- Half-life method. For a first order reaction, t1/2 = 0.693/k. If t1/2 is known, k can be calculated. Similarly for a nth order reaction, t1/n = 1/k [A]0^n can be used to calculate k.

2. The dimensions of rate constant (k) depend on the order of the reaction.
- For a first order reaction, k has dimensions of time^(-1)
- For a second order reaction, k has dimensions of concentration x time^(-1)
- For a nth order reaction, k has dimensions of (concentration)^(n-1) x time^(-1)
