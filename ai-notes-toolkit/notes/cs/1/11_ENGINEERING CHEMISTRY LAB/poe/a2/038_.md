# Notes on Machine Learning

## Supervised Learning

1. Classification: Predicting a category or class (e.g. spam/not-spam, cat/dog). Uses labeled training data to learn a classification model. Examples: Logistic regression, decision trees, naive Bayes, neural networks.
2. Regression: Predicting a continuous value (e.g. housing price). Uses labeled training data to learn a regression model. Examples: Linear regression, Lasso regression, neural networks.

## Unsupervised Learning

1. Clustering: Finding hidden patterns or clusters in unlabeled data. Groups similar data points together. Examples: K-means, hierarchical clustering.
2. Anomaly Detection: Identifying data points that do not conform to expected behavior. Examples: Isolation Forest, one-class support vector machines.
3. Dimensionality Reduction: Reducing the number of features under consideration. Often used to visualize high-dimensional data or simplify models. Examples: Principal component analysis, linear discriminant analysis.
