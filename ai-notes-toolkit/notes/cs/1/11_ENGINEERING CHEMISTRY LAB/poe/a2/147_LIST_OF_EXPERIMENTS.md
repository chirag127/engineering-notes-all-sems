# LIST OF EXPERIMENTS

1. Determination of the focal length of a convex lens by u-v method

- Set up the apparatus with a convex lens, an object pin and a screen.
- Measure the distances of the object pin and the screen from the optical centre of the lens. Let them be u and v respectively.
- Measure the size of the image formed on the screen. Let it be h'.
- Calculate the focal length (f) using the relation: 1/v - 1/u = 1/f

2. Determination of the focal length of a concave lens

- Set up the apparatus with a concave lens, an object pin and a screen.
- Measure the distances of the object pin and the screen from the optical centre of the lens. Let them be u and v respectively.
- No real image is formed. Measure the distance of the virtual image from the optical centre. Let it be v'.
- Calculate the focal length (f) using the relation: 1/v' - 1/u = 1/f
