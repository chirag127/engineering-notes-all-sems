### K3

1. K3 is a statistical measure that helps track the concentration of a variable in a population. It is calculated as the sum of the cubed deviations from the mean, divided by the number of data points.
2. A high K3 value indicates that the data points tend to be clustered closely around the mean, while a low K3 value indicates that the data are more dispersed and spread out.
3. K3 is a measure of skewness - it increases with the cube of the deviation from the mean. This means that K3 is highly sensitive to outliers and extreme values in the data. For this reason, K3 is not as commonly used as other measures of dispersion like the standard deviation.
4. The formula for calculating K3 is:

K3 = (x1 - mean)3 + (x2 - mean)3 + ... + (xn - mean)3
n

Where x1 to xn are the data points and n is the number of data points.

5. Some key properties of K3:
- Always >= 0
- Units same as original data
- Sensitive to extreme values (outliers)
- Increases as data becomes more skewed
- Not useful as a standalone measure - should be used with mean and standard deviation
