
### 2-Computer assisted software based Language Learning:

1. Computer assisted language learning (CALL) is a form of technology-enhanced language learning which uses computer software to facilitate the learning process.

2. CALL software can be used to facilitate language learning in a variety of ways, such as providing interactive exercises and activities, providing feedback on performance, and tracking progress.

3. CALL software can be used to teach a variety of language skills, such as reading, writing, speaking, listening, and grammar.

4. CALL software can also be used to teach language learners about culture and customs associated with the target language.

5. CALL software can be used in a variety of settings, such as in the classroom, at home, or online.

6. CALL software can also be used to create personalized learning plans for language learners, as well as to provide feedback and support.
