### Displaying data from multiple tables for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab.

When working with databases, it is often necessary to access and display data from multiple tables. This can be achieved through the use of SQL statements that join the tables together based on common fields.

Here are the steps to follow when displaying data from multiple tables:

1. Identify the tables that need to be joined - In order to display data from multiple tables, it is necessary to identify the tables that contain the relevant data. This can be done by examining the database schema or by consulting the database documentation.

2. Determine the common field(s) - Once the relevant tables have been identified, it is necessary to determine the common field(s) that will be used to join the tables together. This is typically a field that exists in both tables and contains the same data.

3. Use the JOIN statement - Once the common field(s) have been identified, the tables can be joined together using the JOIN statement. The JOIN statement is used to combine rows from two or more tables based on a related column between them.

4. Specify the SELECT statement - After the tables have been joined together, the SELECT statement is used to specify the columns that should be displayed in the output. This can include columns from both tables, as well as any calculated fields or aggregate functions.

5. Use aliases to distinguish between columns with the same name - When selecting columns from multiple tables, it is possible for two or more columns to have the same name. In this case, aliases can be used to distinguish between them and ensure that the correct data is displayed.

By following these steps, it is possible to display data from multiple tables in a database using SQL statements. This is a powerful tool that can be used to extract valuable insights and information from large and complex databases.
