## Unit 1 - Installing Oracle/MYSQL

In this unit, we will discuss the installation process of Oracle and MYSQL databases. Follow the below steps to install Oracle or MYSQL:

### Installing Oracle

1. Download the Oracle database installer from the official website.
2. Extract the downloaded zip file.
3. Open the extracted folder and run the "setup.exe" file.
4. Choose the "Install database software only" option and click next.
5. Choose the appropriate database edition and click next.
6. Select the installation path and click next.
7. Enter the Oracle Home User details and click next.
8. Review the summary and click install.
9. Wait for the installation to complete.
10. Once the installation is complete, configure the database using the provided configuration assistant.

### Installing MYSQL

1. Download the MYSQL database installer from the official website.
2. Run the downloaded installer.
3. Choose the appropriate setup type and click next.
4. Choose the installation path and click next.
5. Enter the root user password and click next.
6. Select the database usage and click next.
7. Review the summary and click install.
8. Wait for the installation to complete.
9. Once the installation is complete, configure the database using the provided configuration wizard.

Note: Make sure to check the system requirements before installing the database to avoid any issues. Also, always install the latest version of the database for better performance and security.
