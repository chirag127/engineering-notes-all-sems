### Create MS Access Database

- To create a database in MS Access, you can follow these steps  :
  - Open Access. If Access is already open, select File > New.
  - Select Blank database, or select a template that suits your needs.
  - Enter a name for the database, select a location, and then select Create.
  - If needed, select Enable content in the yellow message bar when the database opens.
  - You can now start creating tables, queries, forms, reports, and other objects in your database.
- To create a table in MS Access, you can follow these steps:
  - In the Navigation Pane, double-click the table that you want to use as the basis for your new table.
  - On the Home tab, in the Views group, click View, and then click Design View.
  - On the Design tab, in the Tools group, click Save As.
  - In the Save As dialog box, type a name for your new table, and then click OK.
  - You can now modify the fields, properties, and indexes of your new table as needed.
  - To switch to Datasheet view and enter data in your new table, on the Home tab, in the Views group, click View, and then click Datasheet View.
