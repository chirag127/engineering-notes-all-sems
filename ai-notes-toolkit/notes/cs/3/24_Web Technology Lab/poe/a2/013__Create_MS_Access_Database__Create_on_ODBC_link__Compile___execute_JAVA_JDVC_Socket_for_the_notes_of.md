### Create MS Access Database

1. Open MS Access and click on Blank Database.
2. Enter the Database name and click Create.
3. Go to Table tab and click on Table Design.
4. Enter the Field Name and Data type and set Primary Key.
5. Save the Table.
6. Similarly, create more tables as per the requirement.

### Create ODBC link

1. Go to Control Panel -> Administrative Tools -> Data Sources (ODBC).
2. Click on Add button and select Microsoft Access Driver (*.mdb).
3. Browse the Database file and click Finish.
4. Give the Data Source Name and click OK.
5. The ODBC link is created.

### Compile & execute JAVA JDVC Socket

1. Import java.sql.*; for database connectivity.
2. Load the Driver Class - Class.forName("sun.jdbc.odbc.JdbcOdbcDriver");
3. Get the Connection - conn = DriverManager.getConnection("jdbc:odbc:DataSourceName");
4. Create Statement - stmt = conn.createStatement();
5. Execute Query - rs = stmt.executeQuery("Select * from TableName");
6. Display the results.
7. Similarly, execute other queries.
8. Close the connection.

### Design dynamic web page using server side programming Ex. ASP/JSP/PHP

1. Learn the syntax of the chosen technology (ASP/JSP/PHP).
2. Create web pages with HTML and incorporate the server side scripts.
3. Connect to the database using the scripts and fetch the data.
4. Display the data dynamically on the web page using loops and conditions.
