## Unit 4 - Design dynamic web page using server side programming Ex. ASP/JSP/PHP

1. ASP - Active Server Pages:
- ASP is Microsoft's server side scripting language
- ASP pages contain HTML and scripts written in VBScript
- The scripts are processed on the server and the output is sent to the client as HTML
- ASP is used to create dynamic web pages that can access databases and perform various server side tasks

2. JSP - JavaServer Pages:
- JSP is Java's server side scripting language
- JSP pages contain HTML and Java code snippets
- The Java code is compiled into servlets which are executed on the server and the output is sent to the client
- JSP is used to create dynamic web pages and access Java libraries and frameworks

3. PHP - Hypertext Preprocessor:
- PHP is an open source server side scripting language
- PHP code is embedded into HTML pages
- The PHP code is executed on the server and the output is sent to the client as HTML
- PHP can access databases and perform various web development tasks
- PHP is a very popular language for developing dynamic web pages due to its simplicity and portability

The above points cover the key aspects of the 3 server side programming languages - ASP, JSP and PHP which can be used to design dynamic web pages.
