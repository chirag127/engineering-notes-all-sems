### Write programs using Java script for Web Page to display browsers information for the notes of the Unit 2 - Develop Java programs for window/web-based applications in the subject of Web Technology Lab.

1. Introduction to JavaScript
- JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages.
- It allows web pages to be interactive and more dynamic.
- It can update and change both HTML and CSS.
- It can calculate, manipulate and validate data.
- It can access and modify content.
- It reacts to events triggered by the user or the browser.

2. Basic structure of a JavaScript program
- JavaScript code is executed by the browser and embedded within the <script> tag usually within the HTML <head> or <body> section.
- A JavaScript program contains variables to store values, operators to manipulate values, control flows to control the logic and functions to organize the code.

3. Display browser information using JavaScript
- The browser information like name, version, OS, vendor, etc. can be accessed using JavaScript and displayed on the web page.
- This can be achieved using the Navigator object which contains information about the browser.
- For example, to display the browser name - document.write(navigator.appName);
- Similarly, other details like version, platform, vendor, etc. can be accessed and displayed on the web page.

4. Conclusion
- In this way, JavaScript programs can be written to display the browser information on the web page.
- This helps in identifying the browser and its version to render the web page accordingly.
- JavaScript provides various objects and methods to access and manipulate the browser details.
