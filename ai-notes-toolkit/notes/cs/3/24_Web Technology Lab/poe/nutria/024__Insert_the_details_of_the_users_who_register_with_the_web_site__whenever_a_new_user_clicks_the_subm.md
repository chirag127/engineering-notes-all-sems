
### Insert the details of the users who register with the web site
When a new user clicks the submit button in the registration page for the notes of the Unit 5 - Design server site applications using JDDC, ODBC and section tracking API in the subject of Web Technology Lab, the following details should be inserted: 

1. User name 
2. Password 
3. Email address 
4. Phone number 
5. Physical address 
6. Date of birth 
7. Gender 
8. Any other personal information requested by the site.
