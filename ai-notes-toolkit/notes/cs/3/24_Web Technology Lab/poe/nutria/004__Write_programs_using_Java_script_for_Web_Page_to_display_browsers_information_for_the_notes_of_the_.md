
### Write programs using JavaScript for Web Page to display browsers information

1. JavaScript is a scripting language used to create and control dynamic web content.
2. JavaScript can be used to create interactive web pages and applications.
3. JavaScript can be used to detect the user's browser and display information about it.
4. The `navigator` object in JavaScript can be used to access information about the user's browser, including its name, version, and platform.
5. The `navigator.userAgent` property contains a string that describes the user's browser, which can be used to determine the browser type.
6. The `navigator.appName` property can be used to determine the name of the browser, such as Chrome, Firefox, or Safari.
7. The `navigator.appVersion` property can be used to determine the browser version.
8. The `navigator.platform` property can be used to determine the platform, such as Windows or Mac OS.
9. JavaScript can be used to display browser information, such as the name, version, and platform, to the user.
