
### Program to illustrate JDBC connectivity

1. JDBC stands for Java Database Connectivity and is a Java API used to connect Java applications to databases. 
2. It provides a set of classes and interfaces that enable a Java application to access a database. 
3. JDBC provides methods to query and update data in a database, and is oriented towards relational databases.
4. To use JDBC, an application must have a JDBC driver, which is a set of classes that implements the JDBC interfaces. 
5. The driver is responsible for translating the calls from the Java application into a format that the database understands.
6. JDBC drivers are available for most popular databases, such as Oracle, MySQL, and PostgreSQL.
7. To use JDBC, the application must first create a JDBC connection. 
8. This is done by specifying the URL of the database, along with the username and password. 
9. Once the connection is established, the application can use the JDBC methods to query and update the database.
10. In the context of web programming, JDBC can be used to create dynamic web pages by connecting to a database and retrieving data to be displayed on the page.
11. For example, an ASP/JSP/PHP application can use JDBC to connect to a database and retrieve data to be displayed in an HTML table. 
12. This allows the application to create dynamic web pages that can be updated with data from the database.
