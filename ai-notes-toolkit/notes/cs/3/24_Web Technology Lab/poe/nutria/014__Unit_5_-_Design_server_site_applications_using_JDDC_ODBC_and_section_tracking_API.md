
## Unit 5 - Design server site applications using JDDC, ODBC and section tracking API

1. JDDC (Java Database Connectivity) is an application programming interface (API) that enables Java programs to access a database. It is used to connect Java applications to a relational database.

2. ODBC (Open Database Connectivity) is an application programming interface (API) that enables programs written in C and other languages to access a database. It is used to connect programs written in C to a relational database.

3. Section Tracking API is an application programming interface (API) that enables programs to access a database. It is used to track sections of a web application, such as web pages, user forms, and other elements.

4. JDDC, ODBC and Section Tracking API can be used together to design server-side applications. JDDC and ODBC can be used to access the database, while the Section Tracking API can be used to track sections of the application.

5. When designing a server-side application using JDDC, ODBC and Section Tracking API, it is important to consider the security of the application. It is important to ensure that only authorized users can access the data in the database, and that the data is kept secure.
