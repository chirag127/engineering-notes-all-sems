
## Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP

1. Dynamic web pages are web pages that are generated in real-time based on user input and/or server-side processes.
2. Server-side programming technologies, such as ASP, JSP and PHP, are commonly used to create dynamic web pages.
3. ASP (Active Server Pages) is a server-side scripting language developed by Microsoft. It is used to create dynamic web pages and is integrated with HTML.
4. JSP (Java Server Pages) is a server-side scripting language developed by Sun Microsystems. It is based on the Java programming language and is used to create dynamic web pages.
5. PHP (Hypertext Preprocessor) is a server-side scripting language developed by Zend Technologies. It is used to create dynamic web pages and is integrated with HTML.
6. In order to create a dynamic web page using server-side programming technologies, the web page must be written in the appropriate language and then uploaded to the web server.
7. Once the web page is uploaded to the web server, it can be accessed by users through their web browsers.
8. The web page can then be used to interact with users, process data and generate dynamic content in real-time.
