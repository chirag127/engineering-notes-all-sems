
### Create a Cookie and add these four user id’s and passwords to this Cookie

1. To create a Cookie, use the `Cookie` class in the JDBC library.
2. Use the `setProperty` method to add the four user id’s and passwords to the Cookie.
3. Use the `getProperty` method to retrieve the user id’s and passwords from the Cookie.
4. Use the `removeProperty` method to remove the user id’s and passwords from the Cookie.
5. Use the `store` method to store the Cookie in the server site application.
6. Use the `load` method to load the Cookie from the server site application.
7. Use the `ODBC` library to access the section tracking API.
8. Use the `executeQuery` method to execute queries on the section tracking API.
9. Use the `executeUpdate` method to update the section tracking API.
