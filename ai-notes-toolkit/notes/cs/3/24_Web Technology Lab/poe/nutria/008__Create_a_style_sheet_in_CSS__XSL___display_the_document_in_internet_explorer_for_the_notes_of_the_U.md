
### Create a Style Sheet in CSS/XSL & Display the Document in Internet Explorer
1. CSS (Cascading Style Sheets) is a style sheet language used to describe the presentation of a document written in HTML or XML (including XHTML). CSS describes how elements should be rendered on screen, on paper, in speech, or on other media.
2. XSL (Extensible Stylesheet Language) is a language used to transform and render XML documents. XSL can be used to transform XML documents into HTML, text, or other XML documents.
3. To create a style sheet in CSS/XSL, you need to write a set of rules that define how the elements of the document should be rendered. These rules are written in the form of CSS/XSL selectors and declarations.
4. Once the style sheet is created, it can be linked to the HTML document in which the elements should be rendered. This can be done by adding a <link> element in the <head> section of the document, or by adding a <style> element in the <head> section.
5. To display the document in Internet Explorer, you need to include a reference to the style sheet in the HTML document. This can be done by adding a <link> element in the <head> section of the document, or by adding a <style> element in the <head> section. 
6. Once the style sheet is linked to the HTML document, the elements of the document will be rendered according to the rules specified in the style sheet.
