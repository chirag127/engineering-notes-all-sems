
## Unit 1 - Develop static web pages using HTML

1. HTML stands for HyperText Markup Language, and is the language used to create webpages. 
2. HTML is a markup language, meaning it describes the content of a webpage using tags. 
3. HTML tags are used to structure and format the content of a webpage, such as headings, paragraphs, lists, and images. 
4. HTML documents must be written in a specific format, using a combination of HTML tags and plain text. 
5. HTML documents must also include a DOCTYPE declaration, which specifies the version of HTML used in the document. 
6. HTML documents must be valid, meaning they must follow the rules of HTML syntax. 
7. HTML documents must be well-structured, meaning they must use the correct HTML tags for the content being displayed. 
8. HTML documents must be viewable in all browsers, meaning they must be compatible with different browsers and different versions of HTML.
