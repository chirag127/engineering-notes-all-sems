
### Writing an HTML Program to Design an Entry Form of Student Details and Send it to Store at Database Server

1. Begin by creating a form in HTML. This can be done by using the `<form>` tag.
2. Add the necessary form elements that will be used to collect student information. This can include text boxes, radio buttons, check boxes, and so on.
3. Add the `action` attribute to the `<form>` tag. This will specify the URL of the page that will process the data.
4. Add the `method` attribute to the `<form>` tag. This will specify the type of request that will be sent to the server (e.g. `GET` or `POST`).
5. Add the `name` attribute to each form element. This will specify the name of the data that will be sent to the server.
6. Add the `value` attribute to each form element. This will specify the value of the data that will be sent to the server.
7. Add a submit button to the form. This can be done by using the `<input>` tag with the `type` attribute set to `submit`.
8. Once the form is complete, save the HTML file.
9. Connect to the database server. This can be done using a programming language such as PHP, Python, or JavaScript.
10. Create a SQL query that will insert the data collected from the form into the database.
11. Execute the query.
12. Close the connection to the database.
