### Software Measurement and Metrics for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- **Size Metrics**: Lines of Code (LOC), Function Points (FP)
- **Complexity Metrics**: Cyclomatic Complexity, Halstead Metrics
- **Quality Metrics**: Defect Density, Reliability, Maintainability
- **Effort Estimation**: COCOMO Model, Use Case Points
- **Cost Benefit Analysis**: Comparing costs and benefits of two or more options to determine the best course of action.
- **Reliability**: The ability of a system or component to perform its required functions under stated conditions for a specified period of time. Measured using Mean Time Between Failures (MTBF).
- **Maintainability**: The ease with which a software system or component can be modified to correct faults, improve performance or other attributes, or adapt to a changed environment. Affects the overall cost of ownership of a software.
