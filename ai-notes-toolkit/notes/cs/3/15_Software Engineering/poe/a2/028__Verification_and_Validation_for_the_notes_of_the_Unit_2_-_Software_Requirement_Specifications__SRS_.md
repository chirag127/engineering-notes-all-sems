### Verification and Validation for the notes of the Unit 2 - Software Requirement Specifications (SRS) in the subject of Software Engineering

1. Verification:
- Checking whether the software meets the specifications and requirements as intended.
- Performed at every stage of software development.
- Techniques: Review, Inspection, Walkthrough, Testing.
- Verifies the product at every stage.

2. Validation:
- Checking whether the software meets the user needs and requirements.
- Performed at the end of the software development.
- Techniques: Testing, Simulation, Prototyping.
- Validates the final product.

3. Difference between Verification and Validation:
- Verification is a process of evaluation where we check whether the system meets the specifications. Validation is checking whether the system meets the user needs.
- Verification is a static technique whereas validation involves actual execution of the software.
- Verification is done at every stage whereas validation is done at the end of the development.

The above points cover the key concepts and differences between Verification and Validation which are important topics under Software Requirement Specifications (SRS) in Software Engineering.
