### Software Components for the notes of the Unit 1 - Introduction to Software Engineering

1. Software: Software is a set of instructions that tells a computer what to do and how to perform a task. It includes programs, libraries, and data.
2. Programming Languages: Programming languages are used to communicate instructions to a computer. They are structured languages with rules (syntax) on how symbols and phrases can be combined to form statements and programs.
3. Software Applications: Software applications are programs designed to perform specific tasks for users. Examples include word processors, spreadsheets, database systems, browsers, and games.
4. Software Components: Software components are distinct parts or modules of software that are designed to work together. They include libraries, frameworks, and software development kits.
5. Software Architecture: The software architecture refers to the high level design of software and the relationships between its components. It includes components of a system, the responsibilities of those components, and the relationships between them.
