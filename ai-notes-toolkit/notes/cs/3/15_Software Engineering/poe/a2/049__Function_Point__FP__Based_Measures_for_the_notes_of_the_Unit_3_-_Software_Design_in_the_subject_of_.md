### Function Point (FP) Based Measures

- Function Point Analysis (FPA) is a method to measure software size based on functional user requirements.
- It considers five major components of a software - Input, Output, Logical Internal Files, External Interface Files, and External Inputs.
- Each component is given a complexity rating based on data element types and file types to compute an Unadjusted Function Point (UFP) count.
- Final Adjusted Function Point (AFP) is calculated by multiplying UFP with various Technical Complexity Factor (TCF) and Environmental Complexity Factor (ECF).
- AFP can be used to estimate effort, cost, and schedule in a project. It is a language-independent measure.
- Limitations: It does not consider non-functional requirements and software architecture. It also relies on subjective ratings which can introduce inaccuracies.
- Other FP based measures: Full Function Points (considers more components), Mark II Function Points (revised complexity ratings), COSMIC Function Points (includes object-oriented concepts).
