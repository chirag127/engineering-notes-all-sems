## Unit 1 - Introduction to Software Engineering

1. Software Engineering: Software Engineering is the systematic application of engineering approaches to the development of software. It involves a series of steps to analyze problems and develop solutions.

2. Software Development Life Cycle: The Software Development Life Cycle or SDLC is a process used by the software industry to design, develop and test high quality softwares. The SDLC aims to produce a high-quality software that meets or exceeds customer expectations, reaches completion within times and cost estimates. The basic stages of SDLC are:

- Requirements Analysis: Identifying the requirements of the software to be developed.
- Design: Developing design plans that meet the specified requirements.
- Implementation: Implementing the design in a programming language.
- Testing: Testing the software for bugs, errors and edge cases.
- Deployment: Deploying the software for user use.
- Maintenance: Fixing bugs and improving performance.

3. Programming Languages: Programming languages are languages designed to communicate instructions to a machine, particularly a computer. They can be used to create programs that control the behavior of a machine or to express algorithms. Some popular programming languages are:

- Java
- Python
- C++
- JavaScript
- PHP
