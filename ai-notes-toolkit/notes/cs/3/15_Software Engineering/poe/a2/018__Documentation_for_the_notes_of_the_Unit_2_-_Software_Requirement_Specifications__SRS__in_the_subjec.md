### Documentation for the notes of the Unit 2 - Software Requirement Specifications (SRS) in the subject of Software Engineering.

1. Introduction
- Software Requirement Specification (SRS) is a detailed description of the intended purpose and environment for a software system.
- It includes a set of use cases that describe interactions between the users and the system.
- SRS is a prerequisite for designing the software architecture and system.

2. Importance of SRS
- It helps in understanding the exact needs of the customer.
- It serves as an input for the next phase of the software development lifecycle i.e. software design.
- It provides a reference document for verification and validation of the final product.
- It facilitates estimation and control of the project development.

3. Contents of SRS
- Introduction
- Overall description
- System features
- External interface requirements
- System features
- Performance requirements
- Logical database requirement
- Design constraints
- Assumption and dependencies
- Appendices
