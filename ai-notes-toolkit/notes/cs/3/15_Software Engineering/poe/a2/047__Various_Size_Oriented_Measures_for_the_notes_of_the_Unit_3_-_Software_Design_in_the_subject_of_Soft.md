### Various Size Oriented Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering.

1. Lines of Code (LOC):
- Counts the number of lines of source code.
- Does not account for line length or complexity.
- Useful for estimating effort required for maintenance or porting.

2. Function Points (FP):
- Counts major software components (external inputs, external outputs, logical files, external interfaces) and assigns a weight to each based on complexity.
- Attempts to quantify software size independent of the programming language.
- Useful for estimating required effort and cost in the early stages of a project.

3. Object Points (OP):
- Similar to FP but counts objects (classes) instead of components.
- Claims to provide an object-oriented software size measure.
- Still not widely used in practice.

4. Use Case Points (UCP):
- Counts use cases and assigns a complexity weight to each.
- Also attempts to provide a size measure independent of implementation details.
- Interesting approach but not yet widely adopted.

The above points summarise the key size-oriented software measures. There are many others but none is perfect and there is no universal agreement on the 'best' measure. The choice of measure depends on the specific purpose and the type of software under consideration.
