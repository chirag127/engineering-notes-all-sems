### Software Development Life Cycle (SDLC) Models

1. Waterfall Model:
- Linear and sequential model
- Phases: Requirements, Design, Implementation, Testing, Deployment
- Output of one phase is input to next phase
- No overlapping of phases
- Difficult to accommodate changes

2. Incremental Model:
- Divides system functionality into increments
- Each increment passes through SDLC
- Early increments deliver core functionality
- Next increments add additional functionality
- Allows sequential development and early releases

3. Spiral Model:
- Combines elements of prototyping and waterfall model
- Each loop in the spiral represents a phase in the SDLC
- Software is developed in iterations called spirals
- Each spiral involves planning, risk analysis, engineering and evaluation
- Provides risk handling and is suitable for large, expensive and complicated software.

4. Agile Model:
- Iterative and incremental
- Emphasizes teamwork, collaboration and process adaptability
- Accepts changing requirements and flexible responses
- Short development cycles called sprints
- Focuses on early releases and customer feedback
- Includes versions like Scrum, XP, Lean, Kanban, etc.
