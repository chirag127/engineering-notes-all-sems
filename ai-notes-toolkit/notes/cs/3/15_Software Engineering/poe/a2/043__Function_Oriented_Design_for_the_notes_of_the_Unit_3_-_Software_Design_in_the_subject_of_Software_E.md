### Function Oriented Design

1. Focus on functions and modules: In function oriented design, the system is decomposed into modules (functions) that perform specific tasks. The interfaces between the modules are defined such that the output of one module acts as the input to the other module.
2. Divide and conquer: The overall system is divided into smaller sub-problems that can be solved independently. This makes the system simple, modular, and easy to test.
3. Loose coupling: The modules are loosely coupled. This means that a change in one module does not affect the other modules. This makes the system robust and flexible to changes.
4. Information hiding: The modules hide the implementation details from each other. Only the interfaces are exposed. This makes the system more maintainable and less prone to errors.
5. Reusability: The modules can be reused without any modifications in other systems. This makes the system cost-effective and efficient.

The key benefits of function oriented design are simplicity, robustness, flexibility, reusability, and reduced maintenance cost. However, this design may not be suitable if the system needs to respond to events very quickly as the modular structure can add overhead. The function oriented approach works well if the system can be divided into independent functions that perform specific tasks.
