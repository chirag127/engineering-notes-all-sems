## Unit 4 - Software Testing

1. Software Testing - Software testing is a process used to identify the correctness, completeness, and quality of developed computer software. It involves execution of a program or application with the intent of finding software bugs (errors or other defects).
2. Types of Software Testing - There are various types of software testing such as:
- Unit Testing - Testing individual software components.
- Integration Testing - Testing combined components as a group.
- Functional Testing - Testing software functionality according to specifications.
- System Testing - Testing the complete system as a whole.
- Performance Testing - Checking the performance and scalability aspects.
- Acceptance Testing - Testing by end users or clients to validate requirements.
- Regression Testing - Testing to ensure changes did not break existing functionality.
3. Test Cases - Test cases are a set of conditions or variables under which a tester will determine if a system under test satisfies requirements or works correctly. They are designed to test individual units of functionality and can be combined to form test suites.
4. Defect/Bug Life Cycle - The bug/defect life cycle typically involves the following stages:
- New - When a defect is initially detected and reported.
- Open - When the defect is assigned to a developer to be fixed.
- Fixed - When a developer fixes the defect and closes the report.
- Pending Retest - The testing team will retest the defect fix.
- Closed - If the defect is verified as fixed, the defect is closed.
- Reopened - If the defect is found to still exist, the defect is reopened.
