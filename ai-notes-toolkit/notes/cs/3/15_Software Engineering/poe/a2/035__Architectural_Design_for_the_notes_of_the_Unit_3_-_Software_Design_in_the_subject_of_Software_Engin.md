### Architectural Design for the notes of the Unit 3 - Software Design in the subject of Software Engineering.

1. Introduction
- Software Architecture refers to the fundamental structures of a software system and the discipline of creating such structures and systems.
- It involves decision making about - Components, Connections between components, Constraints and trade-offs.
- Goals - Functional requirements, Usability, Performance, Scalability, Security, Maintainability, Portability.

2. Architectural Styles
- Client-Server - Separates UI and data storage.
- Peer-to-Peer - Decentralized, no separate server component.
- Layered - Divides components into layers like presentation, business logic, data access.
- Event-driven - Based on the production and consumption of events.
- Microkernel - Provides basic services and the rest are user-defined extensions.
- Microservices - Application is divided into many smaller modular services.
- Space-based - Components communicate via tuple spaces.
- Pipes and filters - Components connected via pipelines that accept inputs and produce outputs.

3. Architectural Patterns
- Model-View-Controller
- Publisher-Subscriber
- Service-Oriented Architecture
- Representational State Transfer
