### Pseudo Codes for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Pseudo code is an informal high-level description of the operating logic of a computer program. It uses the structural conventions of a normal programming language, but is intended for human reading rather than machine reading.

2. Pseudo code typically omits details that are important for machine processing, such as declarations and minor syntax details. The purpose of pseudo code is to define the steps necessary to solve a problem in a readable, structured yet informal manner.

3. Pseudo code helps the programmer organize their thoughts systematically before implementing the actual code. It helps identify potential problems earlier on and also serves as documentation for the logic behind the program.

4. Some common conventions used in pseudo code are:

- Use simple and easy to understand names for variables and procedures
- Indentation to show logic structure
- Sequence, selection and iteration statements similar to actual programming languages but simpler
- Comments to describe the logic and steps

5. Here is an example of pseudo code to find the largest number in a list of numbers:

largest = numbers[0]

for i = 1 to length of numbers:

    if numbers[i] > largest:

        largest = numbers[i]

end for

print largest

The pseudo code follows the general structure and logic flow of an actual program but with simpler and informal language for easy understanding.
