### Software Quality Attributes

1. Functionality: The degree to which the software satisfies specified requirements.
- Completeness: All functions and features are included.
- Correctness: The software performs correctly as intended.
- Accuracy: Output is correct for given inputs.
- Appropriateness: Software functions appropriately for its purpose.

2. Reliability: The ability of the software product to perform its required functions under stated conditions for a specified period of time.
- Maturity: Number of faults remaining in the system.
- Availability: Readiness for correct service.
- Fault Tolerance: Ability to continue normal operation despite the presence of hardware or software faults.

3. Usability: The effort needed for use, and the individual assessment of such use, by a stated or implied set of users.
- Learnability: How easy it is to learn the software.
- Understandability: How easy it is to understand the software.
- Operability: How easy it is to operate and control the software.

4. Efficiency: The amount of computing resources and time required to perform a function.
- Time behavior: Response and processing times.
- Resource utilization: Amount of memory and processor usage.
- Throughput: Volume of transactions or tasks completed per unit time.

5. Maintainability: The ease with which a software system can be modified to change or add capabilities, correct faults, improve performance or other attributes, or adapt to a changed environment.
- Modularity: Software is divided into discrete components.
- Reusability: Existing software is used again in new applications.
- Analyzability: The ability to diagnose problems.
- Changeability: The ease of modifying the software.

6. Portability: The ease of transferring the software from one hardware or software environment to another.
