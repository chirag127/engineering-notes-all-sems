### Control Flow Graphs

- Control flow graphs are a way to represent control flow of a program.
- They are made up of nodes representing basic blocks of code and directed edges representing possible flows of control.
- Basic blocks are sequences of statements where control enters at the first statement and exits at the last statement without any intervening control flow.
- The start node represents the entry point of the program and the end node represents the exit point of the program.
- Edges in the graph represent paths that may be taken.
- Control flow graphs can be used to:
-- Analyze the runtime complexity and behavior of a program.
-- Check for features like recursion or concurrency.
-- Enable optimizations by compilers like code scheduling.
