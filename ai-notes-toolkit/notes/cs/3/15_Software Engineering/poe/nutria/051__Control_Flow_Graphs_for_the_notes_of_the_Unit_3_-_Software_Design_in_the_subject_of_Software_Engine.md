
### Control Flow Graphs for the Notes of the Unit 3 - Software Design in the Subject of Software Engineering

* Control flow graphs are a graphical representation of the sequence of operations in a program. 
* A control flow graph consists of nodes and edges. The nodes represent operations, while the edges represent the flow of control between them. 
* The nodes in a control flow graph can be connected by one or more edges. Each edge has a direction associated with it, indicating the flow of control. 
* Control flow graphs are used to visualize the logical flow of a program and to identify potential errors. 
* Control flow graphs can be used to identify loops, branches, and other control structures in a program. 
* Control flow graphs can also be used to analyze the performance of a program. 
* Control flow graphs are useful for debugging and testing programs.
