
### Modularization for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Modularization is a software design technique that involves breaking down a program into distinct parts, or modules, with each module containing a specific set of related functions.

2. Modularization allows for easier maintenance and debugging of code, as well as easier code reuse and scalability.

3. Modularization helps to reduce complexity by breaking down the code into manageable chunks.

4. Modularization can also help improve the readability of code, making it easier to understand and maintain.

5. Modularization can also help to improve the performance of a program by allowing for better optimization of code.

6. Modularization can help to reduce the amount of code needed to complete a task, as well as reduce the amount of code duplication.
