
### Various Size Oriented Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. **LOC (Lines of Code)**: LOC is a measure of the size of a software program, expressed as the number of lines of code. It is typically used to measure the complexity of the software.

2. **Function Points**: Function points are a measure of the size of a software program, expressed as the number of functional requirements of the program.

3. **Cyclomatic Complexity**: Cyclomatic complexity is a measure of the complexity of a software program, expressed as the number of independent paths through the program's source code.

4. **Halstead Complexity Measures**: Halstead complexity measures are measures of the size and complexity of a software program, expressed as the number of distinct operators and operands used in the program.

5. **Number of Classes**: The number of classes is a measure of the size of a software program, expressed as the number of classes in the program.

6. **Number of Methods**: The number of methods is a measure of the size of a software program, expressed as the number of methods in the program.
