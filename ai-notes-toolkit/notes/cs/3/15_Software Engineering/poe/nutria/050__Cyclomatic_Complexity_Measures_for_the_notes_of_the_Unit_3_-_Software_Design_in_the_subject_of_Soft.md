
### Cyclomatic Complexity Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Cyclomatic complexity is a measure of the number of linearly independent paths through a program’s source code. 
2. It is used to measure the complexity of a software system and to identify sections of code that may need to be refactored. 
3. Cyclomatic complexity is determined by the number of decision points (e.g. if/else statements, for/while loops, etc.) in a program. 
4. Higher cyclomatic complexity indicates a higher level of complexity, and thus a higher risk of bugs and a greater need for maintenance. 
5. It is important to note that cyclomatic complexity is not a measure of the quality of a program, but rather a measure of its structural complexity. 
6. Cyclomatic complexity can be used to identify sections of code that may need to be refactored in order to reduce complexity and improve maintainability.
