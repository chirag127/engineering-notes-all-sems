
## Unit 4 - Software Testing

* Software testing is a process of executing a program or system with the intent of finding errors. 
* It can also be used to ensure that the software meets the requirements of the customer. 
* Software testing is an important part of software development and maintenance.
* There are different types of software testing, such as unit testing, integration testing, system testing, acceptance testing, and regression testing. 
* Unit testing is a technique used to test individual units or components of a software system. 
* Integration testing is used to test the interactions between different components of a software system. 
* System testing is used to test the overall functionality of a software system. 
* Acceptance testing is used to verify that the software meets the customer's requirements. 
* Regression testing is used to verify that changes to the software have not caused any unintended side effects.
