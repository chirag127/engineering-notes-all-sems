
## Unit 5 - Software Maintenance and Software Project Management

1. Software Maintenance: 
Software maintenance is the process of modifying and updating existing software applications to ensure they remain operational and continue to meet the needs of the user. It includes activities such as bug fixes, feature enhancements, performance improvements, security updates, and other software upgrades.

2. Software Project Management:
Software project management is the application of project management techniques to the development of software. It involves the planning, organizing, and controlling of software development activities in order to meet the project's objectives. It includes activities such as project scope definition, resource allocation, risk management, and project scheduling.
