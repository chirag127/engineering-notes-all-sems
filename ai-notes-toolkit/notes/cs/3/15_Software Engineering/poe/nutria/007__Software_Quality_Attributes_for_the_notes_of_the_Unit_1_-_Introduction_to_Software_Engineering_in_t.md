
### Software Quality Attributes

1. Reliability: The ability of a system to perform its intended functions in a consistent and accurate manner.
2. Usability: The ease with which a user can learn and use a system.
3. Efficiency: The amount of resources (time, memory, etc.) consumed by a system in order to produce a given result.
4. Maintainability: The ease with which a system can be modified or updated.
5. Portability: The ability of a system to be used on multiple platforms or architectures.
6. Testability: The ability of a system to be tested for correctness and performance.
7. Security: The ability of a system to protect its data and resources from unauthorized access.
