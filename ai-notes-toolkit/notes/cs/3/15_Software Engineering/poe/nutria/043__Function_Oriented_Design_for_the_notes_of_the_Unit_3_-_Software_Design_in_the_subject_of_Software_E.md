
### Function Oriented Design

* Function Oriented Design is a software development approach that focuses on the functions of a software system and how they interact with each other. 
* It is based on the idea that software should be designed around the functions it performs, rather than the data it manipulates.
* It is a top-down approach to design, where the main functions are identified first, then the sub-functions are identified, and so on.
* The main goal of Function Oriented Design is to create software that is modular, flexible, and easy to maintain.
* Function Oriented Design emphasizes the reuse of code and the ability to extend existing functionality.
* It also encourages the use of abstraction, encapsulation, and modularity to make the code more maintainable.
* Function Oriented Design also focuses on the readability and maintainability of code, which is essential for long-term software development.
