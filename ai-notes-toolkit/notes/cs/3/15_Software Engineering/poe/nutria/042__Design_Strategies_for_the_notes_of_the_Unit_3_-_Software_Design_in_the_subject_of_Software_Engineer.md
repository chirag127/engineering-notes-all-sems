
### Design Strategies for the Notes of Unit 3 - Software Design in Software Engineering 

1. **Object-Oriented Design**: Object-oriented design is a type of software design that focuses on creating objects that represent real-world entities and the relationships between them. This approach helps to create software that is more maintainable, reusable and extensible.

2. **Design Patterns**: Design patterns are reusable solutions to common software design problems. They provide a way to structure code and make it easier to maintain. Common design patterns include Model-View-Controller (MVC), Factory, Observer, and Singleton.

3. **Test-Driven Development (TDD)**: Test-driven development is a software development methodology that emphasizes the importance of writing tests before writing code. This helps to ensure that the code is correct and works as expected.

4. **Refactoring**: Refactoring is the process of improving the design of existing code without changing its external behavior. This is done by restructuring code to make it easier to understand and maintain.

5. **Software Architecture**: Software architecture is the high-level structure of a software system. It defines the overall design of the system and provides a blueprint for its implementation. Common software architectures include client-server, distributed, and layered architectures.
