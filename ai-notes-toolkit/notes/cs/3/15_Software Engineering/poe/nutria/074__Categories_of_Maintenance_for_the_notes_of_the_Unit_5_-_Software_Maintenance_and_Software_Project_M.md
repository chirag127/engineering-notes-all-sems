
### Categories of Maintenance for the notes of the Unit 5 - Software Maintenance and Software Project Management in the subject of Software Engineering

1. Corrective Maintenance: This type of maintenance is used to fix errors or bugs in the software. It is usually done after the software has been released.

2. Adaptive Maintenance: This type of maintenance is used to make the software compatible with changes in the environment. This includes changes in hardware, operating systems, and other software.

3. Perfective Maintenance: This type of maintenance is used to improve the usability, performance, or other features of the software.

4. Preventive Maintenance: This type of maintenance is used to prevent future problems from occurring. This includes regular testing, code reviews, and other activities to ensure the software is working as expected.
