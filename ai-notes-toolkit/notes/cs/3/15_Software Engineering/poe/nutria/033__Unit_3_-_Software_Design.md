

## Unit 3 - Software Design

1. Software design is the process of creating a plan for a software system. It involves defining the architecture, components, interfaces, and other characteristics of a system.

2. Software design is an iterative process that involves multiple stakeholders and requires a thorough understanding of the problem domain. It is important to consider user requirements, performance, security, maintainability, and other factors when designing a system.

3. Good software design is essential for creating a system that is efficient, reliable, and maintainable. It is important to understand the principles of software design and the different design paradigms, such as object-oriented design and functional programming.

4. Software design patterns are reusable solutions to common software design problems. They are used to structure code and to make it easier to maintain.

5. Software design tools are used to create visual representations of a system and to simulate its behavior. These tools can be used to quickly prototype a system and to identify potential problems.
