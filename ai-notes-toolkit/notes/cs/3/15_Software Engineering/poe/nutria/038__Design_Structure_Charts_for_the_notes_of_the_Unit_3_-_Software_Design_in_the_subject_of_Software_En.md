
### Design Structure Charts for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Design Structure Charts (DSC) are a graphical representation of the decomposition of a system into its components.
2. DSCs can be used to represent any system, including software systems.
3. A DSC consists of a set of boxes, each representing a component of the system, and arrows connecting the boxes representing the relationships between components.
4. DSCs can be used to represent the structure of a system, the flow of control within a system, and the data flow between components.
5. DSCs can be used to identify potential problems in a system’s design.
6. DSCs can be used to document a system’s design, and can be used to communicate the design to other stakeholders.
7. DSCs can also be used to represent the design of a system before it is implemented.
