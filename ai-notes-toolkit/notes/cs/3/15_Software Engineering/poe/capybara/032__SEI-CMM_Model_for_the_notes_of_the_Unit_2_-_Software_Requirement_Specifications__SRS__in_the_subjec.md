### SEI-CMM Model for the notes of the Unit 2 - Software Requirement Specifications (SRS) in the subject of Software Engineering.

The SEI-CMM (Software Engineering Institute Capability Maturity Model) is a model that evaluates the maturity of an organization in software development. The model has five levels, and each level represents a different level of maturity in software development.

The five levels of the SEI-CMM model are as follows:

1. Initial Level: At this level, the software development process is ad hoc, and there is no formal process in place. The software development team relies on the experience and skills of individual team members to complete projects.

2. Repeatable Level: At this level, the software development process is repeatable, and there is a basic level of project management in place. The software development team follows a set of defined processes and procedures to complete projects.

3. Defined Level: At this level, the software development process is defined, and there is a formal process in place. The software development team follows a set of defined processes and procedures that are documented and communicated to all team members.

4. Managed Level: At this level, the software development process is measured, and there is a focus on continuous improvement. The software development team collects data on the software development process and uses this data to improve processes and procedures.

5. Optimizing Level: At this level, the software development process is optimized, and there is a focus on continuous improvement and innovation. The software development team uses data, metrics, and feedback to improve processes and procedures continually.

The SEI-CMM model is a valuable tool for organizations to evaluate their maturity level in software development. By using the model, organizations can identify areas of improvement and focus on continuous improvement in their software development process.
