### Pseudo Codes for the notes of the Unit 3 - Software Design in the subject of Software Engineering

Pseudo code is a high-level description of a computer program written in a human-readable form. It is used as a tool for designing and planning software systems. In this unit, we will learn how to write effective pseudo codes for software design. Here are some guidelines to follow:

1. Use simple language: Pseudo code should be easy to understand and should use simple language that is easily understood by the reader.

2. Use structured programming concepts: Pseudo code should be structured in a way that reflects the programming concepts being used. For example, use loops for repetitive tasks and conditional statements for decision making.

3. Use standard notation: Use standard notation for programming constructs such as variables, arrays, and functions. This makes the pseudo code more readable and understandable.

4. Use indentation and whitespace: Use indentation and whitespace to make the pseudo code more readable and easier to follow. Indentation should be consistent and should reflect the structure of the code.

5. Use comments: Use comments to explain the purpose of the code and to provide additional information that is not obvious from the pseudo code itself.

6. Use meaningful variable names: Use meaningful variable names that reflect the purpose of the variable. This makes the pseudo code more readable and easier to understand.

7. Use modular design: Use modular design principles to break down complex problems into smaller, more manageable pieces. This makes the pseudo code easier to write and maintain.

8. Test the pseudo code: Test the pseudo code to ensure that it works as expected. This can be done by walking through the code and verifying that it produces the correct output.

By following these guidelines, you can create effective pseudo codes for software design. Pseudo code is an important tool for designing and planning software systems, and mastering it is a crucial skill for any software engineer.
