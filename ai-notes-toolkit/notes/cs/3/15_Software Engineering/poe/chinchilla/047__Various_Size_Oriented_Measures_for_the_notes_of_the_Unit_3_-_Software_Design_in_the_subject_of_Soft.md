### Various Size Oriented Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering 

In software engineering, size-oriented measures are used to estimate the size of software projects. These measures are based on the size of the software product, either in terms of lines of code or function points. Here are some of the commonly used size-oriented measures:

1. Lines of Code (LOC): This measure is based on the number of lines of code written for a software project. It is a simple and straightforward measure but has some limitations, such as not accounting for the complexity of the code.

2. Function Points (FP): This measure is based on the functionality provided by the software. It takes into account the complexity of the code and the user interactions with the software. It is a more accurate measure than LOC but requires more effort to calculate.

3. Object Points (OP): This measure is similar to FP but is based on the number of objects used in the software. It takes into account the complexity of the code and the interactions between objects.

4. Use Case Points (UCP): This measure is based on the number of use cases in the software. It takes into account the complexity of the software's functionality and the user interactions with the software.

5. Feature Points (FP2): This measure is an extension of FP and takes into account the number of features provided by the software. It is a more accurate measure than FP but requires more effort to calculate.

6. Source Lines of Code (SLOC): This measure is similar to LOC but includes only the lines of code that are written by the software developers. It excludes the lines of code that are generated by tools and libraries.

7. Non-Commenting Lines of Code (NCLOC): This measure is similar to LOC but excludes the lines of code that are comments.

Size-oriented measures are useful for estimating the effort and cost required for developing software projects. However, they should be used in conjunction with other measures, such as quality-oriented measures, to get a complete picture of the software project.
