### Design Strategies for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- Software design is the process of defining the architecture, components, modules, interfaces, and data for a software system to satisfy specified requirements.
- Software design is a critical component of software engineering and involves making decisions about the structure, behavior, and quality of the software system.
- Software design strategies are the approaches that are taken to design software systems. They help to guide the design process and ensure that the system meets the desired goals and constraints.
- There are several software design strategies that can be used, depending on the nature, scope, and complexity of the software system. Some of the common software design strategies are:

  - Structured design: This strategy is based on the principle of divide and conquer. It starts with a high-level view of the system and gradually breaks it down into smaller, more manageable components. Each component has a well-defined function and interface, and communicates with other components through data flow diagrams. Structured design is suitable for developing simple and modular software systems that have low coupling and high cohesion.
  - Function-oriented design: This strategy is based on the principle of abstraction. It focuses on the functionality of the system and identifies the major functions that the system should perform. Each function is decomposed into sub-functions, and the data and control flow among them is defined. Function-oriented design is suitable for developing software systems that have a clear and stable set of requirements and that are mainly driven by data processing logic.
  - Object-oriented design: This strategy is based on the principle of encapsulation. It focuses on the data and behavior of the system and identifies the major objects that the system should manipulate. Each object has a state and a set of operations that can be performed on it. The objects are organized into classes and hierarchies, and the relationships and interactions among them are defined. Object-oriented design is suitable for developing software systems that have complex and dynamic requirements and that are mainly driven by user interface logic.

- In addition to the software design strategies, there are also software design methods that provide specific techniques and tools for applying the strategies. Some of the common software design methods are:

  - Structured analysis and design technique (SADT): This method is based on structured design and uses graphical notation to represent the data flow and control flow of the system. It helps to analyze the system requirements and design the system architecture and components.
  - Structured systems analysis and design method (SSADM): This method is based on function-oriented design and uses a combination of graphical and textual notation to represent the system functions, data, and processes. It helps to model the system requirements and design the system data and logic.
  - Unified modeling language (UML): This method is based on object-oriented design and uses a standard set of diagrams to represent the system objects, classes, relationships, and interactions. It helps to model the system requirements and design the system structure and behavior.

- Software design strategies and methods are not mutually exclusive and can be combined and adapted to suit the needs of different software systems and projects. The choice of software design strategy and method depends on various factors, such as the type, size, and complexity of the software system, the availability of resources and tools, the preferences and skills of the software designers, and the standards and guidelines of the software engineering process.
