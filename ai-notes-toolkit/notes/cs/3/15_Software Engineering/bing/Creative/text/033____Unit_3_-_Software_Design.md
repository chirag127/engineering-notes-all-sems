## Unit 3 - Software Design

- Software design is the process of defining the architecture, components, interfaces, and other characteristics of a software system.
- Software design is based on the requirements and specifications of the software system, which are derived from the analysis of the problem domain and the needs of the stakeholders.
- Software design is an iterative and creative process that involves various activities, such as:

  - Design modeling: creating graphical or textual representations of the software system, such as UML diagrams, data flow diagrams, entity-relationship diagrams, etc.
  - Design patterns: applying reusable solutions to common design problems, such as creational, structural, and behavioral patterns.
  - Design principles: following general guidelines and best practices for designing software systems, such as cohesion, coupling, abstraction, encapsulation, modularity, etc.
  - Design methods: using systematic approaches and techniques for designing software systems, such as structured design, object-oriented design, agile design, etc.
  - Design evaluation: assessing the quality and suitability of the software design, using criteria such as functionality, reliability, usability, efficiency, maintainability, etc.

- Software design is influenced by various factors, such as:

  - Software development process: the model or methodology used for planning, organizing, and managing the software development activities, such as waterfall, spiral, incremental, agile, etc.
  - Software development tools: the software applications and environments used for supporting the software development activities, such as editors, compilers, debuggers, testing tools, etc.
  - Software development standards: the rules and conventions used for ensuring the consistency and quality of the software development activities, such as coding standards, documentation standards, testing standards, etc.
  - Software development team: the group of people involved in the software development activities, such as developers, designers, testers, managers, etc.
