### Static Testing Strategies

Static testing is a software testing technique that involves checking the software artifacts without executing the code. Static testing can help to find defects and improve the quality of software development at an early stage. Static testing can be done in two ways: review and static analysis .

- Review: Review is a process of examining the software documents, such as requirements, design, test cases, etc., to find and eliminate errors or ambiguities. Review can be done by different methods, such as informal review, walkthrough, inspection, etc. Review can help to improve the clarity, consistency, completeness, and correctness of the software documents   .
- Static analysis: Static analysis is a process of analyzing the software code, such as syntax, structure, data flow, etc., to find and eliminate errors or vulnerabilities. Static analysis can be done by different tools, such as compilers, code analyzers, code metrics, etc. Static analysis can help to improve the performance, security, maintainability, and reliability of the software code   .

Some of the benefits of static testing are:

- It can detect defects early in the software development life cycle, which can reduce the cost and time of fixing them later.
- It can improve the communication and collaboration among the software development team members, as they can share feedback and suggestions on the software artifacts.
- It can enhance the quality and efficiency of the software development process, as it can prevent defects from propagating to the later stages.
- It can complement the dynamic testing, as it can cover the aspects that dynamic testing cannot, such as code style, documentation, etc.   .
