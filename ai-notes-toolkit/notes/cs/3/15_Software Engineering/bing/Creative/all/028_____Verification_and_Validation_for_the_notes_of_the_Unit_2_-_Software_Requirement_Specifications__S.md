# Verification and Validation

- Verification and validation are an integral part of software engineering.
- Verification and validation help reduce the chances of product failure and improve the reliability of the end product.
- Verification and validation are the processes of checking that a software system meets specifications and requirements so that it fulfills its intended purpose  .
- Verification and validation may also be referred to as software quality control .
- Verification is a process of determining if the software is designed and developed as per the specified requirements .
- Validation is the process of checking if the software (end product) has met the client’s true needs and expectations .
- Software testing is incomplete until it undergoes verification and validation processes.
- Verification and validation can be performed at different stages of the software development life cycle.
- Verification and validation can be applied to different types of software artifacts, such as requirements, design, code, test cases, documentation, etc.
- Verification and validation can be performed using different methods, such as reviews, inspections, walkthroughs, testing, analysis, etc.
- Verification and validation can be classified into four levels, according to the IEEE standard 1012-2016:
  - Component verification and validation: performed on individual software components, such as modules, functions, classes, etc.
  - Integration verification and validation: performed on groups of software components that interact with each other, such as subsystems, interfaces, etc.
  - System verification and validation: performed on the entire software system as a whole, including hardware, software, and external interfaces.
  - Qualification verification and validation: performed on the software system in its operational environment, including user acceptance testing, certification, etc.
