# Introduction to Software Engineering

Software engineering is the application of engineering principles and practices to the design, development, testing, and maintenance of software systems. Software engineering aims to produce software products that are high-quality, reliable, and maintainable, and that meet the needs and expectations of the users and stakeholders.

Some of the topics covered in this unit are:

- The definition and scope of software engineering
- The software development life cycle (SDLC) and its models
- The software process and its activities
- The software requirements and specifications
- The software design and architecture
- The software testing and quality assurance
- The software maintenance and evolution
- The software project management and planning
- The software engineering ethics and professional issues

Some of the learning outcomes of this unit are:

- To understand the basic concepts and principles of software engineering
- To compare and contrast different SDLC models and software processes
- To apply various techniques and tools for software requirements elicitation, analysis, and validation
- To design and model software systems using appropriate methods and notations
- To implement and test software systems using appropriate programming languages and frameworks
- To evaluate and improve software quality using various metrics and standards
- To manage and control software projects using various methods and tools
- To adhere to the ethical and professional standards of software engineering

Some of the references for this unit are:

- Software Engineering by Ian Sommerville
- Software Engineering: A Practitioner's Approach by Roger S. Pressman
- Design Patterns: Elements of Reusable Object-Oriented Software by Erich Gamma, Richard Helm, Ralph Johnson, and John Vlissides
- Introduction to Software Engineering Design: Processes, Principles, and Patterns with UML2 by Christopher Fox
- Introduction to Software Engineering by Ronald J. Leach
