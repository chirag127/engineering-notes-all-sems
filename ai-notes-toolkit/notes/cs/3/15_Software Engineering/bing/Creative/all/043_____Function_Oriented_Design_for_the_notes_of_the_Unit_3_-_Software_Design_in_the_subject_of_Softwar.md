# Function Oriented Design

- Function Oriented Design is an approach to software design where the design is decomposed into a set of interacting units or modules where each unit or module has a clearly defined function.
- The system is designed from a functional viewpoint, meaning that the focus is on what the system does rather than how it does it .
- The main steps involved in Function Oriented Design are:
  - Identify the functions that the system needs to perform and organize them in a hierarchy of abstraction.
  - Construct a data flow diagram (DFD) that shows the flow of information and data among the functions.
  - Define the data dictionary that contains the information about the data items used in the DFD.
  - Refine the DFD and the data dictionary until the design is complete and consistent.
  - Map the DFD and the data dictionary to a structured programming language or a pseudocode.
- The main advantages of Function Oriented Design are:
  - It is easy to understand and communicate the design using graphical notations such as DFD.
  - It supports top-down development and modularization of the system.
  - It facilitates testing and maintenance of the system by isolating the functions and data.
- The main disadvantages of Function Oriented Design are:
  - It does not capture the dynamic behavior and interactions of the system components.
  - It does not support object-oriented concepts such as inheritance, polymorphism, and encapsulation.
  - It may lead to poor data abstraction and coupling among the modules.
