# Code Inspection for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

- Code inspection is a type of static testing that involves reviewing the code in an application to check for defects .
- Its purpose is to correct the issues in the programming language so the software performs at its highest potential .
- Code inspection is a verification technique that evaluates the precision of the code within the product .
- Code inspection helps in reducing the ratio of defect multiplication and avoids later-stage error detection by simplifying all the initial error detection processes.
- Code inspection is also known as peer review or Fagan inspection, after Michael Fagan, the creator of a very popular software inspection process.

## Steps of code inspection

The following are the general steps of code inspection  :

1. Planning: The inspection team is formed and the roles of the members are assigned. The inspection leader schedules the inspection meeting and distributes the code to be inspected to the team members.
2. Overview: The inspection leader gives an overview of the code and its objectives to the team members. The team members familiarize themselves with the code and its context.
3. Preparation: The team members individually examine the code and identify any potential defects or issues. They use a checklist of common errors and standards to guide their review. They also prepare questions and comments for the inspection meeting.
4. Inspection: The inspection team meets and discusses the code and the issues identified by the team members. The inspection leader moderates the meeting and ensures that the discussion is focused and constructive. The inspection scribe records the defects and the actions to be taken to resolve them.
5. Rework: The code author or the assigned person makes the necessary changes to the code based on the inspection feedback. The code is then re-inspected or verified by the inspection leader or another team member.
6. Follow-up: The inspection leader checks that all the defects have been resolved and that the code meets the quality standards. The inspection leader also prepares a report on the inspection results and the lessons learned. The report is shared with the relevant stakeholders and used for future improvement.
