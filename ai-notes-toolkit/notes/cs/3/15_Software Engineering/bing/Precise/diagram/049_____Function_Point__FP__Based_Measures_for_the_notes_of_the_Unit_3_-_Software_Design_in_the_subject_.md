### Function Point (FP) Based Measures

Function Point (FP) is a unit of measurement that represents the functionality provided by a software system. It is used to measure the size of a software application or project and is commonly used in software development and maintenance projects.

Here are some key points to consider when using Function Point (FP) based measures:

1. Function Point (FP) based measures are used to estimate the size of a software project by measuring the functionality provided by the system.
2. The Function Point (FP) count is calculated by analyzing the user requirements and identifying the various functions that the system must perform.
3. The functions are then classified into five categories: External Inputs, External Outputs, External Inquiries, Internal Logical Files, and External Interface Files.
4. Each function is assigned a complexity level (low, average, or high) based on the number of data elements and the number of record types involved.
5. The complexity level is then used to determine the number of Function Points (FP) for each function.
6. The total Function Point (FP) count is calculated by adding the Function Points (FP) for all functions.
7. Function Point (FP) based measures can be used to estimate the effort, cost, and duration of a software project.
8. Function Point (FP) based measures are widely used in the software industry and are recognized as a standard for measuring the size of software projects.
