### Function Oriented Design

Function Oriented Design is a design methodology used in software engineering. It is used to design software systems by decomposing the system into smaller units called functions or procedures. The main focus of this design methodology is on the functions performed by the system rather than the data used by the system.

Some key points to remember about Function Oriented Design are:

1. It is a top-down approach to software design.
2. The system is decomposed into smaller units called functions or procedures.
3. The main focus is on the functions performed by the system.
4. Data is considered secondary to the functions.
5. It is best suited for small to medium-sized systems with well-defined requirements.

Function Oriented Design is one of the many design methodologies used in software engineering. It is important to choose the right design methodology for the system being developed to ensure that the design is effective and efficient.
