### Various Size Oriented Measures

Size oriented measures are used to measure the size of the software. These measures are used to estimate the effort and cost required to develop the software. Some of the commonly used size oriented measures are:

1. **Lines of Code (LOC)**: This measure counts the number of lines of code in the software. It is a simple and widely used measure, but it has some limitations. For example, it does not take into account the complexity of the code or the programming language used.

2. **Function Points (FP)**: This measure takes into account the functionality provided by the software. It is based on the number of user inputs, user outputs, user inquiries, external interfaces, and internal logical files. Function points are more complex to calculate than lines of code, but they provide a more accurate measure of the size of the software.

3. **Object Points (OP)**: This measure is similar to function points, but it is used for object-oriented software. It takes into account the number of classes, methods, and attributes in the software.

These are some of the commonly used size oriented measures in software engineering. They can be used to estimate the effort and cost required to develop the software, and to track the progress of the software development process.
