### Static Testing Strategies

Static Testing is a software testing technique used to check defects in a software application without executing the code. It is done to avoid errors at an early stage of development, making it easier to identify and solve errors. It also helps find errors that may not be found by Dynamic Testing.

Some useful tips to perform a static testing process in Software Engineering include:
- Focusing only on things that really count
- Explicitly planning and tracking review activities

The two main types of static testing techniques are:
1. **Manual examinations**: Manual examinations include analysis of code done manually, also known as REVIEWS.
2. **Automated analysis using tools**: Automated analysis is basically static analysis done using tools.

Static testing checks the code, requirement documents, and design documents to find errors, while Dynamic testing checks the functional behavior of the software system, memory/CPU usage, and overall performance of the system.

A static test evaluates the quality of a system without actually running the system. The static test looks at portions or system elements to detect problems as early as possible.
