# Structural Testing (White Box Testing)

Structural testing, also known as white box testing, is a method of testing software that tests the internal structure, design, and implementation of the code itself. This type of testing is typically performed by developers and requires knowledge of the code and programming language used.

Some key points to remember about structural testing are:

1. Structural testing is used to verify the internal workings of the software, rather than its functionality.
2. This type of testing is typically performed by developers, as it requires knowledge of the code and programming language used.
3. Structural testing can help identify issues with the code itself, such as logic errors or incorrect implementation of algorithms.
4. Common techniques used in structural testing include statement coverage, branch coverage, and path coverage.
5. Structural testing can be used in conjunction with other testing methods, such as functional testing, to ensure comprehensive testing of the software.

In summary, structural testing is an important method of testing the internal structure and implementation of software code. It can help identify issues and improve the overall quality of the software. It is typically performed by developers and can be used in conjunction with other testing methods to ensure comprehensive testing of the software.
