### Function Oriented Design

Function Oriented Design is a software design methodology that focuses on the decomposition of the system into a set of interacting functions. It is also known as functional decomposition or structured design. This approach is based on the idea that software systems can be designed by identifying the functions that the system needs to perform and then designing the system around those functions.

Some key points to consider when using Function Oriented Design are:

1. The system is decomposed into a hierarchy of functions, with the top-level functions representing the main tasks of the system and the lower-level functions representing sub-tasks.

2. Each function is designed to perform a specific task and should have a well-defined input and output.

3. The functions are designed to be modular and independent, so that changes to one function do not affect the others.

4. The design process involves identifying the data that needs to be processed by the system and designing the data structures to support the functions.

5. The design should be flexible and allow for changes and enhancements to the system.

Function Oriented Design is a popular approach for designing software systems, particularly for systems that are procedural in nature. It is widely used in the development of business applications, scientific software, and other systems that involve complex data processing. However, it may not be suitable for all types of software systems, particularly those that are object-oriented or involve complex user interactions. In such cases, other design methodologies, such as Object-Oriented Design, may be more appropriate.
