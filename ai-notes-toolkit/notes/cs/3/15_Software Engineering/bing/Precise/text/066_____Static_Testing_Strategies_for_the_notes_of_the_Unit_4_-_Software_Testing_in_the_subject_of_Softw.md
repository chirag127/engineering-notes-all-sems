### Static Testing Strategies

Static Testing is a software testing technique used to check defects in software applications without executing the code. It is done to avoid errors at an early stage of development, as it is easier to identify and solve errors. It also helps find errors that may not be found by Dynamic Testing.

There are two different steps or techniques in Static Testing: review and static analysis.

1. **Static Review**: This is typically carried out to find and remove errors and ambiguities found in supporting documents. Documents reviewed include software requirements specifications, design, and test cases.

2. **Static Analysis**: This evaluates the quality of a system without actually running the system. While that may seem impossible, it can be accomplished in a few ways. The static test looks at portions or system elements to detect problems as early as possible.

Some useful tips to perform a static testing process in Software Engineering include focusing only on things that really count and explicitly planning and tracking review activities.
