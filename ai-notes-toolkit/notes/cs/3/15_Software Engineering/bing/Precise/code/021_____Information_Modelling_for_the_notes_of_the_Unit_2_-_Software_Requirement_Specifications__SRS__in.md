### Information Modelling
Information modelling is a technique used to define the data requirements of a system. It is a part of the software requirement specification (SRS) process in software engineering. Here are some key points to remember about information modelling:

1. Information modelling is used to define the data requirements of a system.
2. It helps to identify the data entities, their attributes, and the relationships between them.
3. Information modelling can be done using various techniques such as Entity-Relationship (ER) modelling, Class modelling, and Object modelling.
4. The output of information modelling is an information model, which is a graphical representation of the data requirements of a system.
5. Information modelling is an iterative process and the information model may be refined as the requirements of the system are better understood.
6. The information model is used as a basis for the design of the database and the data access layer of the system.
