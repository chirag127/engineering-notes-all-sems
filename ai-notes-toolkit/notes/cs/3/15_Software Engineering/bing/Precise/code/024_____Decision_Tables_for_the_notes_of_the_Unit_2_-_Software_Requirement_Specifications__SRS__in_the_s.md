### Decision Tables

Decision tables are a precise yet compact way to model complicated logic. Decision tables, like flowcharts and if-then-else and switch-case statements, associate conditions with actions to perform, but in many cases do so in a more elegant way.

Here are some key points to remember about decision tables:

- Decision tables are used to represent complex decision logic in a tabular format.
- They are particularly useful when there are multiple conditions that need to be evaluated before a decision can be made.
- A decision table consists of four quadrants: conditions, actions, rules, and an optional else rule.
- The conditions are listed in the top left quadrant, one condition per row.
- The actions are listed in the top right quadrant, one action per row.
- The rules are listed in the bottom left quadrant, one rule per column.
- Each rule specifies the values for each condition and the actions that should be taken if the conditions are met.
- The optional else rule specifies the actions that should be taken if none of the rules apply.
- Decision tables can be used to document business rules, system requirements, and test cases.
