### Review and Management of User Needs

- User needs are the expectations and requirements of the end-users or stakeholders of a software system.
- User needs can be expressed in various forms, such as user stories, use cases, scenarios, goals, tasks, etc.
- User needs are the basis for defining the software requirements, which are the detailed and precise specifications of what the software system should do and how it should behave.
- Reviewing and managing user needs is an important activity in the software engineering process, as it ensures that the software system meets the needs and expectations of the users and stakeholders, and that the software requirements are consistent, complete, correct, and feasible.
- Reviewing and managing user needs involves the following steps:

  - Eliciting user needs: This is the process of gathering and understanding the user needs from various sources, such as interviews, surveys, observations, documents, etc. Eliciting user needs requires effective communication and collaboration skills, as well as techniques such as brainstorming, prototyping, storyboarding, etc.
  - Analyzing user needs: This is the process of organizing, prioritizing, and refining the user needs, and identifying any conflicts, gaps, or ambiguities. Analyzing user needs requires analytical and critical thinking skills, as well as techniques such as affinity diagrams, MoSCoW analysis, Kano model, etc.
  - Validating user needs: This is the process of verifying and confirming that the user needs are accurate, realistic, and acceptable. Validating user needs requires feedback and evaluation skills, as well as techniques such as reviews, inspections, walkthroughs, etc.
  - Documenting user needs: This is the process of recording and communicating the user needs in a clear and consistent manner. Documenting user needs requires documentation and presentation skills, as well as standards and formats such as IEEE 830, Volere, etc.
  - Managing user needs: This is the process of controlling and tracking the changes and updates to the user needs throughout the software engineering process. Managing user needs requires configuration and change management skills, as well as tools and methods such as traceability matrix, version control, etc.
