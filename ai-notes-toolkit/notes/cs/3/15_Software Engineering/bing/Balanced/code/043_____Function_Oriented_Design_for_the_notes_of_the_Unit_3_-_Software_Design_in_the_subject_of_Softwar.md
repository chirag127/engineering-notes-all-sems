### Function Oriented Design

- Function Oriented Design is an approach to software design where the design is decomposed into a set of interacting units or modules where each unit or module has a clearly defined function .
- The system is designed from a functional viewpoint, meaning that the focus is on what the system does rather than how it does it.
- The main steps involved in Function Oriented Design are:
  - Identify the functions that the system needs to perform and the data that the system needs to process.
  - Construct a data flow diagram (DFD) that shows the flow of data and the functions that operate on the data.
  - Refine the DFD by decomposing the functions into sub-functions and adding more details to the data.
  - Define the data dictionary that contains the information about the data items defined in the DFD.
  - Design the structure chart that shows the hierarchical relationship among the modules and the control flow among them.
  - Design the algorithm and data structure for each module.
- The main advantages of Function Oriented Design are:
  - It is easy to understand and communicate the design using graphical notations such as DFD and structure chart.
  - It supports top-down design and modularization, which facilitate the development and maintenance of the software.
  - It allows the reuse of existing modules or functions in different contexts or applications.
- The main disadvantages of Function Oriented Design are:
  - It does not capture the dynamic behavior of the system or the interactions among the objects in the system.
  - It does not support object-oriented concepts such as encapsulation, inheritance, and polymorphism, which are essential for developing complex and adaptable software systems.
  - It may result in poor data abstraction and cohesion, as the data is scattered across different modules or functions.
