### Code Inspection

- Code inspection is a formal and systematic technique for finding errors and defects in software source code.
- Code inspection involves a team of reviewers who examine the code and check for compliance with coding standards, design specifications, and functional requirements.
- Code inspection can improve software quality, reduce development costs, and facilitate knowledge transfer among developers.
- Code inspection can be performed at any stage of software development, but it is most effective when applied early and frequently.
- Code inspection can be classified into two types: static and dynamic.
  - Static code inspection is performed without executing the code, using tools such as code analyzers, code metrics, code reviews, and code walkthroughs.
  - Dynamic code inspection is performed by executing the code, using tools such as debuggers, profilers, test cases, and code coverage.
- Code inspection can follow a structured process, such as the Fagan inspection method, which consists of six steps:
  - Planning: The inspection leader selects the code to be inspected, assigns roles to the reviewers, and schedules the inspection meeting.
  - Overview: The inspection leader gives an overview of the code and its objectives to the reviewers, and clarifies any questions or doubts.
  - Preparation: The reviewers individually examine the code and identify potential defects, using checklists, guidelines, and tools.
  - Inspection: The inspection team meets and discusses the code and the defects found, using a moderator to facilitate the discussion and a recorder to document the results.
  - Rework: The code author fixes the defects identified during the inspection, and verifies that no new defects are introduced.
  - Follow-up: The inspection leader checks that the rework is done correctly, and reports the inspection outcome and metrics to the management.
