### Need for Maintenance

- Software maintenance is the process of modifying a software system or component after delivery to correct faults, improve performance or other attributes, or adapt to a changed environment.
- Software maintenance is necessary for various reasons, such as:
  - To fix errors or bugs that were not detected during testing or that emerged after deployment.
  - To enhance the functionality or performance of the software system or component to meet new or changing requirements.
  - To ensure compatibility with new hardware, software, or operating systems.
  - To comply with new standards, regulations, or policies.
  - To improve the usability, reliability, security, or maintainability of the software system or component.
- Software maintenance can be classified into four types, namely:
  - Corrective maintenance: This involves fixing errors or defects in the software system or component that affect its functionality or performance.
  - Adaptive maintenance: This involves modifying the software system or component to adapt to changes in the environment, such as new hardware, software, or operating systems.
  - Perfective maintenance: This involves enhancing the software system or component to improve its functionality, performance, or other attributes, such as adding new features, improving user interface, or optimizing algorithms.
  - Preventive maintenance: This involves modifying the software system or component to prevent potential problems or errors, such as improving the documentation, code structure, or testing procedures.
