# Data Flow Diagrams

- A data flow diagram (DFD) is a graphical representation of the flow of data and information in a system or process.
- A DFD shows the sources and destinations of data, the processes that transform data, the data stores that hold data, and the data flows that connect them.
- A DFD can be used for analysis or modeling of various types of systems in different fields, such as software engineering, business, information systems, etc.
- A DFD can help software engineers to understand the operation and limitations of a system, to identify the requirements and specifications, and to design and implement the system.
- A DFD can also help stakeholders to communicate and collaborate on the system development, to verify and validate the system, and to document and maintain the system.

## Types of DFDs

- There are two main types of DFDs: logical and physical.
- A logical DFD focuses on the functionality and logic of the system, without considering the implementation details, such as hardware, software, network, etc. A logical DFD is also called a context diagram or a level 0 DFD.
- A physical DFD shows the actual components and resources that are involved in the system, such as devices, programs, files, etc. A physical DFD is also called a level 1 DFD or a detailed DFD.
- A DFD can be further decomposed into lower levels to show more details and complexity of the system. Each lower level DFD is numbered according to its parent DFD, such as level 2, level 3, etc.

## Symbols and Notations of DFDs

- A DFD uses four basic symbols to represent the elements of the system: processes, data flows, data stores, and external entities.
- A process is a function or an activity that transforms data from one form to another. A process is represented by a circle or a rounded rectangle with a name or a number inside.
- A data flow is a movement or a transfer of data between processes, data stores, or external entities. A data flow is represented by an arrow with a label that describes the data.
- A data store is a place where data is stored or accumulated for later use. A data store is represented by a rectangle with two parallel lines on the side and a name inside.
- An external entity is a source or a destination of data that is outside the scope of the system. An external entity is represented by a rectangle with a name inside.
