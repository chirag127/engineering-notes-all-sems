# Various Size Oriented Measures

- Size oriented measures are software metrics that are derived by normalizing quality and/or productivity measures by considering the size of the software that has been produced .
- The size of the software can be measured in different ways, such as lines of code, number of pages of documentation, number of modules, etc.
- Size oriented measures are useful for estimating the effort, cost, and schedule of software projects, as well as for measuring and comparing the productivity and quality of software developers and teams .
- Some examples of size oriented measures are:

  - **Lines of code (LOC)**: This is the most common and simple measure of software size. It counts the number of lines of source code in a program, excluding comments and blank lines. LOC can be used to estimate the effort and cost of software development, as well as to measure the complexity, efficiency, and maintainability of software. However, LOC has some limitations, such as being dependent on the programming language, coding style, and level of abstraction .
  - **Function points (FP)**: This is a measure of software size that is based on the functionality provided by the software to the user. It counts the number of inputs, outputs, inquiries, files, and interfaces in a software system, and assigns a weight to each based on its complexity. FP can be used to estimate the effort and cost of software development, as well as to measure the productivity and quality of software. FP has some advantages over LOC, such as being independent of the programming language, coding style, and level of abstraction, and being more closely related to the user requirements .
  - **Object points (OP)**: This is a measure of software size that is based on the number and complexity of objects in an object-oriented software system. It counts the number of screens, reports, and components in a software system, and assigns a weight to each based on its complexity. OP can be used to estimate the effort and cost of software development, as well as to measure the productivity and quality of software. OP has some advantages over LOC and FP, such as being more suitable for object-oriented software, and being more closely related to the user interface .
