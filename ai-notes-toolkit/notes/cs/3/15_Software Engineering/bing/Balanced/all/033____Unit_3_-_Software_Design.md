## Unit 3 - Software Design

Software design is the process of defining the architecture, components, interfaces, and other characteristics of a software system. Software design is a creative and iterative activity that involves various methods, tools, and principles.

Some of the topics covered in this unit are:

- Software design principles: These are general guidelines or best practices that help to achieve desirable qualities in a software system, such as modularity, cohesion, coupling, abstraction, encapsulation, inheritance, polymorphism, etc. Some examples of software design principles are:

  - Single responsibility principle: A class or module should have only one reason to change.
  - Open-closed principle: A class or module should be open for extension but closed for modification.
  - Liskov substitution principle: A subclass should be substitutable for its superclass without breaking the program.
  - Interface segregation principle: A class or module should not depend on methods or properties that it does not use.
  - Dependency inversion principle: A class or module should depend on abstractions rather than concretions.

- Software design methods: These are systematic approaches or techniques that help to structure, model, and document the software design. Software design methods can be classified into two categories: structured and object-oriented. Some examples of software design methods are:

  - Structured design methods: These are based on the concepts of functional decomposition, data flow diagrams, structure charts, etc. They focus on the functions or processes of the software system and how data flows between them. Some examples of structured design methods are:

    - Structured analysis and design technique (SADT): This is a graphical notation that uses rectangles to represent functions and arrows to represent data flows.
    - Yourdon/Constantine method: This is an extension of SADT that uses different symbols to represent different types of functions and data flows.
    - Jackson structured programming (JSP): This is a textual notation that uses indentation and brackets to represent the structure of a program.

  - Object-oriented design methods: These are based on the concepts of classes, objects, inheritance, polymorphism, etc. They focus on the data or entities of the software system and how they interact with each other. Some examples of object-oriented design methods are:

    - Unified modeling language (UML): This is a standard graphical notation that uses various diagrams to represent different aspects of a software system, such as use case diagrams, class diagrams, sequence diagrams, etc.
    - Booch method: This is a precursor of UML that uses similar diagrams but with different symbols and notations.
    - Object modeling technique (OMT): This is another precursor of UML that uses similar diagrams but with different symbols and notations.

- Software design tools: These are software applications that support the software design process by providing features such as graphical editors, code generators, documentation generators, etc. Software design tools can be classified into two categories: CASE tools and IDEs. Some examples of software design tools are:

  - Computer-aided software engineering (CASE) tools: These are software applications that automate or assist some aspects of the software engineering process, such as analysis, design, testing, etc. Some examples of CASE tools are:

    - Rational Rose: This is a CASE tool that supports UML and other object-oriented design methods.
    - Microsoft Visio: This is a CASE tool that supports various types of diagrams, such as flowcharts, data flow diagrams, etc.
    - SmartDraw: This is a CASE tool that supports various types of diagrams, such as flowcharts, data flow diagrams, etc.

  - Integrated development environments (IDEs): These are software applications that provide a comprehensive set of features for developing, debugging, testing, and deploying software applications. Some examples of IDEs are:

    - Eclipse: This is an IDE that supports various programming languages, such as Java, C++, Python, etc.
    - Visual Studio: This is an IDE that supports various programming languages, such as C#, VB.NET, C++, etc.
    - NetBeans: This is an IDE that supports various programming languages, such as Java, PHP, C++, etc.
