# Pseudo Codes for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- Pseudo code is a text outline of the program design     .
- Pseudo code uses descriptive statements that are arranged as functional blocks  .
- Pseudo code does not have to obey any set-out rules, but it should be similar to a simplified programming language  .
- Pseudo code acts as the bridge between your brain and computer's code executor .
- Pseudo code can be an ideal way to start any software development project that involves collaboration and joint effort in creating a design or structure  .
- Pseudo code can also be used to describe how an algorithm should work, or to test the logic of a program before writing actual code  .
- Pseudo code can be written using common ANSI shapes for flowcharts, such as ovals for terminals, arrows for flowlines, rhomboids for inputs and outputs, rhombuses for decisions, and rectangles for processes.
- Pseudo code can also be written using keywords and symbols that are similar to programming languages, such as IF, THEN, ELSE, FOR, WHILE, DO, etc   .
- Pseudo code should be clear, concise, consistent, and easy to understand by anyone who reads it   .
- Pseudo code should be indented properly to show the structure and sequence of the program   .

Here is an example of pseudo code for a program that calculates the area of a circle:

```
// This program calculates the area of a circle
// Input: radius of the circle
// Output: area of the circle

START
  DECLARE radius, area, pi
  READ radius
  SET pi = 3.14
  COMPUTE area = pi * radius * radius
  WRITE area
STOP
```
