### Software Quality Frameworks

- Software quality frameworks are models that connect and integrate the different views of software quality, such as the customer view and the developer view .
- Software quality frameworks treat software as a product that has certain characteristics that affect its ability to satisfy stated and implied needs .
- Software quality frameworks can be used to define, measure, evaluate, and improve software quality  .
- Some examples of software quality frameworks are:
  - ISO/IEC 25000 series, also known as SQuaRE (System and Software Quality Requirements and Evaluation), which contains a framework to evaluate software product quality based on eight quality characteristics, such as security, reliability, and maintainability.
  - ISO/IEC 5055, which defines a framework to measure software product quality based on four quality attributes, such as functional suitability, performance efficiency, security, and maintainability.
  - IEEE 1061, which defines a framework to establish and validate software quality requirements and metrics.
  - CMMI (Capability Maturity Model Integration), which defines a framework to assess and improve the processes and practices of software development and maintenance.
