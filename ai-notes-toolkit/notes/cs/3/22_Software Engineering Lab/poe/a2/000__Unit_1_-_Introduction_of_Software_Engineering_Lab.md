## Unit 1 - Introduction of Software Engineering Lab

1. Software Engineering Lab - Introduction
- Software Engineering Lab course aims to provide students with hands-on experience in Software Engineering concepts and tools.
- Students will get exposure to the complete Software Development Life Cycle by working on projects.
- The lab experiments cover the major activities of the Software Development Life Cycle such as Requirements Engineering, Design, Coding, Testing and Implementation.

2. Software Development Life Cycle
- The Software Development Life Cycle or SDLC defines the stages involved in the development of software. It comprises of the following stages:
- Requirements Analysis: Determining the requirements of the software to be developed.
- Design: Defining the architecture of the software.
- Implementation: The software is developed as per the design.
- Testing: The software is tested for any bugs or errors.
- Deployment: The final software is deployed for user use.
- Maintenance: Software is maintained to fix any issues reported.

3. Tools for Software Engineering
- There are many tools available to aid the Software Engineering process:
- Requirements elicitation tools such as RDP or KASE
- Modeling tools such as UML
- Coding tools such as IDEs (Integrated Development Environments)
- Testing tools such as JUnit, Selenium
- Project management tools such as Github, Trello, etc.
- Students will get hands-on experience working with many such tools as part of the lab experiments.
