1. Introduction
- Software Engineering Lab aims to apply software engineering concepts and practices to real-world software projects.
- It helps students to understand software development life cycle (SDLC) and gain hands-on experience on software development tools and techniques.

2. Software Development Life Cycle (SDLC)
- SDLC refers to the process of designing and developing software. It provides a systematic approach to software development.
- The major phases of SDLC are:
-- Requirement Analysis: Understanding the problem and software requirements.
-- Design: Transforming the software requirements into a software design.
-- Implementation: Implementing the software design in a programming language.
-- Testing: Testing the software to identify and fix bugs.
-- Deployment: Deploying the software for customer use.
-- Maintenance: Modifying and improving the software as needed.
