2. Software Development Life Cycle
- Requirements Analysis: Determining what the customer needs and documenting the requirements
- Design: Defining the software architecture, components, interfaces, and data
- Implementation: Coding in a programming language
- Testing: Detecting and fixing bugs or defects
- Deployment: Releasing the software for customer use
- Maintenance: Fixing bugs, adding new features, or adjusting to changes

3. Methodologies and Model
- Waterfall Model: Sequential model with distinct stages
- Agile Methodology: Incremental, iterative approach promoting teamwork and flexibility
- Other methods: Spiral, Rapid Application Development, Scrum, Extreme Programming, etc.

4. Version Control using Git
- Git is a distributed version control system to track changes in source code
- Key concepts: repository, commit, branch, merge, push, pull, clone, fork, etc.
- Benefits: Maintains a history of changes, allows collaboration, encourages experimentation, etc.
