### StarUML for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

1. StarUML is a free, open source UML modelling tool used for software engineering and designing systems.
2. It supports various UML diagrams like Use Case diagram, Class diagram, Sequence diagram, Activity diagram, State Machine diagram, etc. which are required to model software systems.
3. It has a simple and easy to use interface with drag and drop features and formatting options to create neat diagrams.
4. The diagrams can be exported as images in PNG, JPEG, SVG, etc. formats and as XMI files to be imported in other modelling tools.
5. It is a helpful tool for students and professionals to learn and understand UML concepts bypractically creating diagrams for software projects.
6. It runs on multiple platforms like Windows, Linux, macOS, etc. and has feasible system requirements to work smoothly.
7. It provides features like auto-layout to easily organise diagrams, code generation from class diagrams, etc. making it a useful tool for software modelling.
