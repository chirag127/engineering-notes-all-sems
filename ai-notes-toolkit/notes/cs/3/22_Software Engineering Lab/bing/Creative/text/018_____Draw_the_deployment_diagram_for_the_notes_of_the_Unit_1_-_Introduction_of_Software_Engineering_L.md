### Deployment diagram

```markdown
A deployment diagram is a type of UML diagram that shows the physical arrangement of the components of a software system and how they are connected. A deployment diagram can also show the hardware devices, nodes, artifacts, and communication links.

The main elements of a deployment diagram are:

- Node: A node is a physical device that can execute software, such as a computer, a server, a mobile phone, etc. A node is represented by a cube with the name of the node on it.
- Artifact: An artifact is a piece of software that can be deployed on a node, such as a file, a library, a database, a web application, etc. An artifact is represented by a rectangle with the name of the artifact and a small rectangle on the upper right corner.
- Component: A component is a modular part of a software system that provides a specific functionality, such as a class, a module, a package, etc. A component is represented by a rectangle with the name of the component and two small rectangles on the left side.
- Communication link: A communication link is a connection between two nodes that allows data transfer, such as a network, a cable, a wireless connection, etc. A communication link is represented by a solid line with an optional label for the protocol or the bandwidth.
- Deployment specification: A deployment specification is a set of properties or parameters that define how an artifact is deployed on a node, such as the configuration, the location, the version, etc. A deployment specification is represented by a dashed line from the artifact to the node with a label for the specification.
```
