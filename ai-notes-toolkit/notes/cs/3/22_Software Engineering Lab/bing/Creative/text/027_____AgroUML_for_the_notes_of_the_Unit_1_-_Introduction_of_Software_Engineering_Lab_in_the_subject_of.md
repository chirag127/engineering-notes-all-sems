### AgroUML for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

- AgroUML is an open-source application that supports modeling activities using UML (Unified Modeling Language)  .
- UML is a standard graphical notation for describing the structure and behavior of software systems .
- AgroUML supports almost all diagram types of UML 1.4, such as use case, class, sequence, state, activity, collaboration, deployment, and component diagrams   .
- AgroUML also provides features such as code generation, reverse engineering, design critics, cognitive support, and XMI import/export   .
- AgroUML can run on any Java platform and is available in ten languages   .
- AgroUML can help in improving software designs and documentation by providing notes and To-Do list panes .
- AgroUML can be downloaded from its official website or from other sources such as GitHub or Filehippo    .
- AgroUML can be installed and configured by following the instructions given in the user manual or online tutorials .
- AgroUML can be used to create and edit UML diagrams by using the graphical user interface or the keyboard shortcuts .
- AgroUML can be used to export UML diagrams as GIF, PNG, PS, EPS, PGML, and SVG formats .
