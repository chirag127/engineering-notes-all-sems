# Unit 1 - Introduction of Software Engineering Lab

## Objectives

- To understand the basic concepts and principles of software engineering.
- To learn the software development life cycle models and their advantages and disadvantages.
- To apply the software engineering techniques and tools to design, implement, test, and document software projects.
- To gain hands-on experience in using software engineering tools such as UML, CASE, IDE, testing tools, etc.

## Experiments

1. Study the software development life cycle models such as waterfall, spiral, incremental, iterative, agile, etc. and compare their features, benefits, and drawbacks.
2. Study the software engineering process models such as CMMI, ISO, IEEE, etc. and understand their levels, stages, and activities.
3. Study the software engineering standards and guidelines such as IEEE, ISO, ANSI, etc. and learn how to apply them to software projects.
4. Study the software engineering ethics and professional codes of conduct such as ACM, IEEE, SEI, etc. and learn how to deal with ethical issues and dilemmas in software engineering.
5. Study the software engineering documentation and communication techniques such as SRS, SDD, UML, DFD, ERD, etc. and learn how to write and present software documents.
6. Study the software engineering design principles and methods such as abstraction, modularity, coupling, cohesion, etc. and learn how to design software architectures and components using UML diagrams.
7. Study the software engineering implementation techniques and tools such as programming languages, IDEs, compilers, debuggers, etc. and learn how to code, compile, and debug software programs.
8. Study the software engineering testing techniques and tools such as testing types, levels, strategies, methods, etc. and learn how to test, verify, and validate software products using testing tools.
9. Study the software engineering maintenance and evolution techniques and tools such as change management, configuration management, version control, etc. and learn how to maintain and evolve software products using maintenance tools.
10. Study the software engineering project management techniques and tools such as project planning, estimation, scheduling, risk management, quality management, etc. and learn how to manage and control software projects using project management tools.
