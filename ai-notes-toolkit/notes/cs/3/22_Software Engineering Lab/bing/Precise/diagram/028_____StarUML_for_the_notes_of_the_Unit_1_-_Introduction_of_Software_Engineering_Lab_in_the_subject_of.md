### StarUML

StarUML is a software engineering tool for system modeling using the Unified Modeling Language (UML), as well as Systems Modeling Language (SysML), and classical modeling notations. It is published by MKLabs and is available on Windows, Linux, and MacOS .

#### History

StarUML is the successor of an object-oriented modeling software called Plastic. Plastic 1.0 was published in 1997 to support the OMT notation. The version 1.1 published in 1998 dropped the OMT to support in favor of UML .

#### Installation

StarUML is an open-source software that can be installed directly from the homepage of the website and it is licensed under the GNU Public License. A new project by approach link on the home page is available from where an empty project can be selected .

#### Diagrams

StarUML supports various types of diagrams, including Class Diagram, Package Diagram, Composite Structure Diagram, Object Diagram, Component Diagram, Deployment Diagram, Use Case Diagram, Sequence Diagram, Communication Diagram, Statechart Diagram, and Activity Diagram  .
