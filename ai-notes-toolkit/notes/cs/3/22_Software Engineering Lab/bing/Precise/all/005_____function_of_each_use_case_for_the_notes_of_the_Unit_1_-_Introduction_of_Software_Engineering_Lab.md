### Function of Each Use Case for the Notes of the Unit 1 - Introduction of Software Engineering Lab in the Subject of Software Engineering Lab

A use case is a description of how a system interacts with one or more external entities called actors. Actors can be users, other systems, or hardware devices. The main function of a use case is to capture the functional requirements of a system from the perspective of the user.

Here are the main functions of each use case:

1. **Describing the interactions between the system and the actors:** A use case describes the interactions between the system and the actors in a step-by-step manner. This helps to ensure that all the necessary interactions are captured and that the system behaves as expected.

2. **Capturing the functional requirements of the system:** A use case captures the functional requirements of the system from the perspective of the user. This helps to ensure that the system meets the needs of the user and that the system is easy to use.

3. **Providing a basis for testing:** Use cases provide a basis for testing the system. Test cases can be derived from the use cases to ensure that the system behaves as expected.

4. **Providing a basis for user documentation:** Use cases can be used as a basis for user documentation. The use cases can be used to create user manuals and help files that describe how to use the system.

In summary, the main function of each use case is to capture the functional requirements of a system from the perspective of the user, describe the interactions between the system and the actors, provide a basis for testing, and provide a basis for user documentation.
