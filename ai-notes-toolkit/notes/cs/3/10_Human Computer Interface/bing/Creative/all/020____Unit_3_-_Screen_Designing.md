## Unit 3 - Screen Designing

Screen designing is the process of creating the visual layout and interface of a software application or a website. Screen designing involves the following steps:

- **Identify the user requirements and goals:** The screen designer should understand the needs and expectations of the target users, as well as the objectives and functionalities of the application or website. This can be done by conducting user research, interviews, surveys, personas, scenarios, etc.
- **Create wireframes and prototypes:** The screen designer should create low-fidelity sketches or mockups of the screen layout, navigation, and interaction. Wireframes show the basic structure and elements of the screen, such as buttons, menus, text, images, etc. Prototypes are interactive versions of the wireframes that simulate the user experience and feedback. Wireframes and prototypes can be created using tools such as Balsamiq, Figma, Adobe XD, etc.
- **Apply design principles and guidelines:** The screen designer should follow the established principles and guidelines of user interface design, such as consistency, clarity, simplicity, feedback, affordance, etc. These principles and guidelines help to ensure that the screen design is user-friendly, intuitive, attractive, and accessible. The screen designer should also consider the design standards and conventions of the platform or device that the application or website will run on, such as web, mobile, desktop, etc.
- **Test and evaluate the screen design:** The screen designer should test and evaluate the screen design with the target users and stakeholders, and collect their feedback and suggestions. Testing and evaluation can be done by using methods such as usability testing, heuristic evaluation, cognitive walkthrough, etc. The screen designer should use the feedback and suggestions to improve and refine the screen design until it meets the user requirements and goals.
