### Keyboard and function keys

- A keyboard is a device that allows you to input text, numbers, symbols, and commands to a computer or other device. A keyboard usually has several groups of keys based on their function.
- The function keys are a set of keys labeled F1 to F12 that are located at the top of a keyboard. They can perform different functions depending on the operating system or the running program.
- The Fn key, or function key, is a modifier key that can be used to activate the secondary functions of the F keys. For example, you can use the Fn key to adjust the volume, brightness, or backlight of your device by pressing Fn and the corresponding F key .
- The function keys can also be used to perform common tasks such as opening the help menu, saving a file, refreshing a web page, or switching between windows. Here are some examples of what the function keys can do on Windows 10 and 11 :

  - F1: Opens the help menu of the active program or the Windows help menu if no program is active.
  - F2: Renames the selected file or folder in File Explorer or on the desktop.
  - F3: Opens the search box in File Explorer or on the desktop.
  - F4: Closes the active window or program. If pressed with Alt, it shuts down the program immediately. If pressed with Ctrl, it repeats the last action in some programs.
  - F5: Refreshes the current web page or window. If pressed with Ctrl, it refreshes the web page and clears the cache.
  - F6: Switches between the address bar, tabs, and content in a web browser. If pressed with Ctrl and Shift, it reverses the direction of switching.
  - F7: Checks the spelling and grammar in some programs such as Microsoft Word. If pressed with Shift, it turns on or off the caret browsing mode in a web browser.
  - F8: Accesses the boot menu or the advanced startup options in Windows. This key may not work on some devices due to fast startup settings.
  - F9: Refreshes the document in Microsoft Word. If pressed with Fn, it can also adjust the keyboard backlight on some devices.
  - F10: Activates the menu bar of the active program or window. If pressed with Shift, it opens the context menu of the selected item. If pressed with Fn, it can also mute the sound on some devices.
  - F11: Toggles the full-screen mode of the active program or window. If pressed with Fn, it can also adjust the brightness on some devices.
  - F12: Opens the developer tools in a web browser. If pressed with Fn, it can also turn on or off the airplane mode on some devices.

- The function keys can also have different functions in different programs. For example, in Microsoft Excel, F2 can edit the selected cell, F4 can repeat the last action or switch between absolute and relative references, and F9 can calculate all the formulas in the workbook. You can usually find the function key shortcuts in the program's help menu or documentation.
