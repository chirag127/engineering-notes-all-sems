## Unit 3 - Screen Designing

- Screen designing is the process of creating the layout, appearance, and functionality of the user interface (UI) for a software application, website, or mobile app.
- Screen designing involves the following steps:
  - Define the purpose, goals, and target audience of the application or website.
  - Conduct user research and analysis to understand the needs, preferences, and expectations of the users.
  - Create user personas, scenarios, and user stories to represent the different types of users and their tasks.
  - Sketch, wireframe, and prototype the screen layouts, navigation, and interactions using tools such as Adobe XD, Figma, Sketch, or Balsamiq.
  - Apply the principles of visual design, such as color, typography, alignment, contrast, and hierarchy, to enhance the aesthetics and usability of the screens.
  - Test and evaluate the screen designs with users and stakeholders, and iterate based on the feedback and data.
- Screen designing requires the following skills and knowledge:
  - User-centered design (UCD) methods and techniques, such as user research, personas, user stories, user flows, and usability testing.
  - Visual design principles and elements, such as color theory, typography, grid systems, and white space.
  - UI design patterns and best practices, such as consistency, clarity, feedback, and affordance.
  - UI design tools and software, such as Adobe XD, Figma, Sketch, or Balsamiq, to create and edit screen designs.
  - UI design standards and guidelines, such as Material Design, iOS Human Interface Guidelines, or Web Content Accessibility Guidelines (WCAG).
- Screen designing is an important part of the software development process, as it affects the user experience (UX) and satisfaction of the users, as well as the functionality and performance of the application or website.
