## Unit 4 - Windows

- Windows is an operating system developed by Microsoft that runs on personal computers, laptops, tablets, and other devices.
- Windows provides a graphical user interface (GUI) that allows users to interact with the system and applications using windows, icons, menus, and pointers.
- Windows also provides various services and features, such as file management, security, networking, device drivers, and application compatibility.
- Windows is the most widely used operating system in the world, with different versions and editions for different markets and needs.
- Some of the popular versions of Windows are Windows 10, Windows 8.1, Windows 7, Windows Vista, Windows XP, and Windows Server.
- Windows 10 is the latest version of Windows, released in 2015, that offers a unified platform for various devices, such as PCs, tablets, smartphones, and Xbox.
- Windows 10 introduces new features, such as Cortana, a personal assistant that can perform tasks and answer questions using voice or text input, and Microsoft Edge, a web browser that replaces Internet Explorer.
- Windows 10 also supports multiple desktops, a new start menu, a notification center, and a continuum mode that adapts the interface according to the device and input method.
- Windows 8.1 is an update to Windows 8, released in 2013, that improves the performance and usability of the system, especially for touch-screen devices.
- Windows 8.1 restores the start button and allows users to boot directly to the desktop, instead of the start screen that displays tiles of apps and settings.
- Windows 8.1 also introduces new features, such as Bing Smart Search, that integrates web and local search results, and SkyDrive, a cloud storage service that syncs files and settings across devices.
- Windows 7 is a version of Windows, released in 2009, that focuses on simplicity, reliability, and compatibility.
- Windows 7 introduces new features, such as Aero, a visual style that adds transparency and animation effects to the windows and taskbar, and Snap, a feature that allows users to resize and arrange windows by dragging them to the edges of the screen.
- Windows 7 also improves the performance and security of the system, and supports touch-screen and multi-touch input.
