## Unit 4 - Windows

- Windows is an operating system developed by Microsoft that runs on personal computers, laptops, tablets, and other devices.
- Windows provides a graphical user interface (GUI) that allows users to interact with the system and applications using a mouse, keyboard, touch screen, or voice commands.
- Windows also provides various features and services, such as file management, security, networking, multimedia, web browsing, gaming, and more.
- Some of the most popular versions of Windows are Windows XP, Windows 7, Windows 8, Windows 10, and Windows 11.
- Windows XP was released in 2001 and introduced a new visual style, improved stability, and enhanced security.
- Windows 7 was released in 2009 and improved the performance, usability, and compatibility of Windows. It also introduced new features, such as the taskbar, libraries, and Aero Snap.
- Windows 8 was released in 2012 and introduced a new interface, called the Start screen, that was optimized for touch devices. It also integrated online services, such as Microsoft account, OneDrive, and the Windows Store.
- Windows 10 was released in 2015 and combined the best features of Windows 7 and Windows 8. It also introduced new features, such as Cortana, Edge, and the Action Center.
- Windows 11 was released in 2021 and redesigned the interface, icons, and sounds of Windows. It also introduced new features, such as widgets, snap layouts, and the Microsoft Store.
