### New and Navigation schemes selection of window for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

- A window is a rectangular area on the screen that displays information and allows interaction with an application or a document.
- Windows can have different types, sizes, shapes, styles, and behaviors depending on the purpose and context of use.
- Windows can be classified into primary windows, secondary windows, modal windows, modeless windows, and pop-up windows.
- Primary windows are the main windows that display the core content and functionality of an application or a document. They usually have a title bar, a menu bar, a toolbar, a status bar, and a scroll bar.
- Secondary windows are the windows that provide additional information or functionality that support the primary windows. They can be dialog boxes, property sheets, palettes, wizards, or help windows.
- Modal windows are the windows that require the user's attention and action before they can return to the primary window. They usually have a title bar, an icon, a message, and one or more buttons. They can be used for alerts, confirmations, errors, warnings, or prompts.
- Modeless windows are the windows that do not block the user's interaction with the primary window. They usually have a title bar, a close button, and a resize handle. They can be used for displaying information, providing options, or performing tasks.
- Pop-up windows are the windows that appear temporarily when the user performs a certain action, such as clicking a button, selecting a menu item, or hovering over an element. They usually have a border, a title, and a content area. They can be used for showing menus, tooltips, notifications, or previews.

- Navigation schemes are the ways that the user can move between different windows or within a window. They can be classified into sequential, hierarchical, or network navigation schemes.
- Sequential navigation schemes are the navigation schemes that follow a linear order or a predefined sequence of steps. They can be used for tasks that have a clear start and end point, such as filling a form, completing a wizard, or following a tutorial.
- Hierarchical navigation schemes are the navigation schemes that follow a tree-like structure or a nested arrangement of categories and subcategories. They can be used for tasks that involve browsing, exploring, or searching a large amount of information, such as navigating a file system, a website, or a database.
- Network navigation schemes are the navigation schemes that allow the user to move freely between any windows or elements that are related or linked to each other. They can be used for tasks that involve finding, comparing, or analyzing information from multiple sources, such as browsing the web, using a map, or reading a hypertext.

- Selection of window and navigation schemes depends on several factors, such as the user's goals, tasks, preferences, skills, and expectations, the application's purpose, functionality, and content, the device's capabilities, limitations, and constraints, and the environment's conditions, context, and culture.
- Some general guidelines for selecting window and navigation schemes are:

  - Use primary windows for displaying the main content and functionality of the application or document.
  - Use secondary windows for providing additional information or functionality that support the primary windows.
  - Use modal windows for requiring the user's attention and action before they can return to the primary window.
  - Use modeless windows for allowing the user to interact with the primary window while accessing other information or functionality.
  - Use pop-up windows for showing temporary or contextual information or functionality that are triggered by the user's action.
  - Use sequential navigation schemes for tasks that have a clear start and end point and a fixed number of steps.
  - Use hierarchical navigation schemes for tasks that involve browsing, exploring, or searching a large amount of information that are organized into categories and subcategories.
  - Use network navigation schemes for tasks that involve finding, comparing, or analyzing information from multiple sources that are related or linked to each other.
  - Provide clear and consistent cues, feedback, and affordances for the user to understand and use the window and navigation schemes effectively and efficiently.
  - Avoid using too many or too complex windows or navigation schemes that can confuse, overwhelm, or frustrate the user.
