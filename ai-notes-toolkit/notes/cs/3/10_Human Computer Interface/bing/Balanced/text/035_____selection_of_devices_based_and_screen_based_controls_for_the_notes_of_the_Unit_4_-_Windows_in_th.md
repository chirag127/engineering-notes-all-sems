### Selection of device based and screen based controls for windows

- Device based controls are physical input devices that allow the user to interact with the windows system, such as mouse, keyboard, touchpad, joystick, etc.
- Screen based controls are graphical elements that appear on the windows screen, such as buttons, menus, icons, sliders, etc.
- The selection of device based and screen based controls depends on several factors, such as:
  - The type and size of the display: Larger displays may require more screen based controls to fill the space, while smaller displays may require more device based controls to avoid cluttering the screen. Touchscreens may also require different screen based controls than non-touchscreens, such as larger buttons or gestures.
  - The task and context of the user: Different tasks and contexts may require different levels of precision, speed, feedback, and ease of use. For example, a mouse may be more precise and faster than a touchpad for drawing or selecting, while a touchpad may be more convenient and comfortable for scrolling or zooming. Similarly, a menu may be more suitable for selecting from a large number of options, while a button may be more suitable for a simple action or confirmation.
  - The user preferences and abilities: Different users may have different preferences and abilities for using device based and screen based controls. For example, some users may prefer using keyboard shortcuts over mouse clicks, while others may prefer using voice commands over typing. Some users may also have physical or cognitive limitations that affect their ability to use certain controls, such as visual impairments, motor impairments, or learning difficulties.
- Some general guidelines for selecting device based and screen based controls are:
  - Use device based controls that are compatible with the display and the system. For example, use a mouse or a touchpad for a non-touchscreen display, and use a stylus or a finger for a touchscreen display. Avoid using device based controls that are not supported by the system, such as a joystick for a word processor.
  - Use screen based controls that are consistent with the windows design principles and conventions. For example, use the same icons, colors, fonts, and layouts for screen based controls across different windows applications. Avoid using screen based controls that are unfamiliar or confusing to the user, such as custom symbols, inconsistent labels, or hidden menus.
  - Use device based and screen based controls that are appropriate for the task and the context. For example, use device based controls that allow the user to perform the task efficiently and accurately, and use screen based controls that provide the user with clear and relevant feedback and guidance. Avoid using device based and screen based controls that are unnecessary, redundant, or distracting for the task and the context, such as too many buttons, menus, or pop-ups.
