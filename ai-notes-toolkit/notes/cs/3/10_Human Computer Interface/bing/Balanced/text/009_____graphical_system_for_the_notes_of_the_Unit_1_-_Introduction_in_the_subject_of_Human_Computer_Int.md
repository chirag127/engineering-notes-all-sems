### Graphical System for the Notes of the Unit 1 - Introduction in the Subject of Human Computer Interface

- Human-computer interaction (HCI) is a design field that focuses on the interfaces between people and computers.
- HCI incorporates multiple disciplines, such as computer science, psychology, human factors, and ergonomics, into one field.
- HCI aims to create intuitive and usable interfaces that meet the needs and preferences of the users.
- A graphical user interface (GUI) is a form of user interface that allows users to interact with electronic devices through graphical icons and audio indicators, instead of text-based UIs, typed command labels or text navigation.
- A GUI lets users communicate with the computer with the help of a mouse, keyboard, touch screen, or other input devices.
- A GUI can provide feedback, affordance, visibility, consistency, and constraints to guide the user's actions and expectations.
- A GUI can also support multiple modes of interaction, such as direct manipulation, menus, dialogs, windows, icons, and pointers (WIMP).
- A GUI can enhance the user experience by providing aesthetics, functionality, and accessibility.
- A GUI can be designed using various methods and tools, such as sketches, wireframes, prototypes, mockups, and user testing.
- A GUI can be evaluated using various criteria and metrics, such as usability, user satisfaction, efficiency, effectiveness, and learnability.
- A GUI can be influenced by various factors, such as the context of use, the user's goals, the device's capabilities, and the design principles.
- A GUI can be improved by following the user-centered design (UCD) process, which involves understanding the user's needs, designing the interface, implementing the interface, and evaluating the interface.
