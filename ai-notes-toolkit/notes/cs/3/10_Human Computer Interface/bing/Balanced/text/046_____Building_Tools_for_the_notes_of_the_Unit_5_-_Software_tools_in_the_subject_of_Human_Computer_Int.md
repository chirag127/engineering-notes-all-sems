### Building Tools for Human Computer Interface

- Human computer interface (HCI) is a design field that focuses on the interfaces between people and computers.
- HCI incorporates multiple disciplines, such as computer science, psychology, human factors, and ergonomics, into one field.
- HCI aims to create intuitive and usable interfaces that meet the needs and preferences of the users.
- Building tools for HCI are software applications or systems that help in designing, developing, testing, or evaluating HCI systems.
- Some examples of building tools for HCI are:

  - Interface Building Tools: Design methods that help in designing command languages, data-entry structures, and widgets. For example, Adobe XD, Figma, Sketch, etc.
  - Interface Mockup Tools: Tools to develop a quick sketch of GUI. For example, Microsoft Visio, Visual Studio.Net, etc.
  - Software Engineering Tools: Extensive programming tools to provide user interface management system. For example, Java, C#, Python, etc.
  - Evaluation Tools: Tools to evaluate the correctness and completeness of programs. For example, usability testing, heuristic evaluation, cognitive walkthrough, etc.
  - Visualization Tools: Tools to convey information through graphical or visual representations. For example, Tableau, Power BI, D3.js, etc.
  - Interaction Tools: Tools that facilitate human-computer interaction through various modalities, such as speech, gesture, touch, eye-tracking, etc. For example, Siri, Alexa, Google Assistant, etc.
