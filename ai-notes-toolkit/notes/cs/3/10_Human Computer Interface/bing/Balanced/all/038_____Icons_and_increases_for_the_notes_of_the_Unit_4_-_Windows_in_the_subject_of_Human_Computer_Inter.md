# Icons and Interfaces for Windows

- Icons are visual images and symbols that help users understand and move through an app. They represent a concept, action, or status. 
- Windows 11 uses three types of icons: application, system, and file type. 
- Application icons identify an app and convey its personality. They are displayed on the Start menu, taskbar, and tiles. 
- System icons are used throughout the user interface as visual metaphors for common actions and statuses, such as delete, save, error, or warning.  
- File type icons indicate the format of a file, such as PDF, DOCX, or JPG. They are displayed on File Explorer, desktop, and dialogs. 
- Icons should follow the design principles of Windows 11, such as simplicity, clarity, consistency, and inclusivity. 
- Icons should use the Fluent Design System, which is a set of guidelines and tools for creating engaging and adaptive user interfaces. 
- Icons should be scalable, adaptable, and responsive to different screen sizes, resolutions, and themes. 
- Icons should be designed in a vector format, such as SVG, which allows for easy resizing and editing. 
- Icons should use a 32x32 pixel grid as the base size, and provide variants for 16x16, 24x24, 48x48, and 256x256 pixels. 
- Icons should use a limited and harmonious color palette, based on the Windows 11 theme colors. 
- Icons should use a consistent style, shape, and perspective, and avoid unnecessary details, gradients, and shadows. 
- Icons should convey meaning and affordance, and avoid ambiguity, confusion, and offense. 
- Icons should be tested and validated with users, especially those with different accessibility needs, such as low vision, color blindness, or cognitive impairments. 
- Icons can be customized by users to suit their personal preferences and needs. Users can change the icons for desktop, folders, and file types using the Settings app or third-party programs.  
- Icons can be downloaded from various sources, such as IconScout, which offers free and premium icons in different styles and formats.
