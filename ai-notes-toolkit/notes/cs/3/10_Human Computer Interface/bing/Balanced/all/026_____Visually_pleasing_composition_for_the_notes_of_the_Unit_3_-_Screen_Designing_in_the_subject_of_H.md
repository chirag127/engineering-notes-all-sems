# Visually pleasing composition for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

- Visually pleasing composition is the arrangement of elements on a page or screen that creates a harmonious and attractive impression for the viewer.
- A visually pleasing composition can help to draw attention, convey a message, and enhance the readability and retention of the notes .
- Some of the principles and techniques for creating a visually pleasing composition for the notes are:

  - Use a consistent and clear layout that organizes the information in a logical and hierarchical way .
  - Use different fonts and font sizes, colors, and styles to emphasize the important words or sentences on the notes .
  - Use symbols, abbreviations, and images to supplement the text and reduce the amount of words on the notes .
  - Use white space, margins, and borders to create contrast and balance between the elements on the notes .
  - Use alignment, proximity, and repetition to create unity and harmony among the elements on the notes .
  - Use shapes, lines, and curves to create visual interest and guide the eye movement of the viewer .
  - Use the rule of thirds, the golden ratio, or the Fibonacci spiral to create a dynamic and aesthetically pleasing composition .

|                                                                       |
|  # Unit 3 - Screen Designing                                          |
|                                                                       |
|  ## Screen Design Principles                                          |
|                                                                       |
|  - **Clarity**: The screen should be easy to read and understand.     |
|  - **Consistency**: The screen should follow the same design rules    |
|    and conventions throughout the interface.                          |
|  - **Feedback**: The screen should provide appropriate and timely     |
|    responses to the user's actions.                                   |
|  - **Simplicity**: The screen should avoid unnecessary complexity     |
|    and clutter.                                                       |
|  - **Structure**: The screen should organize the information in a     |
|    logical and hierarchical way.                                      |
|  - **Navigation**: The screen should allow the user to move easily    |
|    and intuitively between different screens and tasks.               |
|  - **Affordance**: The screen should indicate the possible actions    |
|    and functions of the interface elements.                           |
|  - **Aesthetics**: The screen should be visually pleasing and         |
|    appealing to the user.                                             |
|                                                                       |
|  ## Screen Design Techniques                                          |
|                                                                       |
|  - **Wireframing**: A low-fidelity sketch of the screen layout and    |
|    elements.                                                          |
|  - **Prototyping**: A high-fidelity mockup of the screen appearance   |
|    and functionality.                                                 |
|  - **Storyboarding**: A sequence of screens that illustrates the      |
|    user's interaction and experience.                                 |
|  - **User Testing**: A process of evaluating the screen design with   |
|    real or potential users.                                           |
|                                                                       |
|  ## Screen Design Tools                                               |
|                                                                       |
|  - **Sketch**: A vector-based design tool for creating wireframes     |
|    and prototypes.                                                    |
|  - **Figma**: A cloud-based design tool for creating wireframes,      |
|    prototypes, and collaborative designs.                             |
|  - **Adobe XD**: A design tool for creating wireframes, prototypes,   |
|    and interactive designs.                                           |
|  - **Balsamiq**: A design tool for creating wireframes and mockups.   |
|                                                                       |
