## Unit 4 - Windows

- Windows is an operating system developed by Microsoft that runs on personal computers, laptops, tablets, and other devices.
- Windows provides a graphical user interface (GUI) that allows users to interact with the system and applications using a mouse, keyboard, touch screen, or voice commands.
- Windows also provides various features and services, such as file management, security, networking, multimedia, web browsing, gaming, and more.
- Some of the most popular versions of Windows are Windows XP, Windows 7, Windows 8, Windows 10, and Windows 11.
- Windows is compatible with a wide range of hardware and software from different vendors and developers.

### Windows Components

- Windows consists of several components that work together to provide the functionality and user experience of the operating system. Some of the main components are:

  - Kernel: The core of the operating system that manages the system resources, such as memory, CPU, disk, and devices. The kernel also handles the communication between the hardware and the software.
  - Shell: The interface of the operating system that allows users to launch and manage applications, access files and folders, and customize the system settings. The shell includes the desktop, the taskbar, the start menu, the file explorer, and the control panel.
  - Services: The background processes that perform various tasks, such as security, networking, printing, updating, and more. Services can be started, stopped, or configured by the user or the system.
  - Drivers: The software components that enable the operating system to communicate with the hardware devices, such as printers, scanners, cameras, sound cards, and more. Drivers are usually provided by the device manufacturers or vendors.
  - Applications: The software programs that run on the operating system and provide various functions and features, such as word processing, spreadsheet, web browsing, gaming, and more. Applications can be installed, uninstalled, or updated by the user or the system.

### Windows Installation and Configuration

- Windows can be installed on a device using a bootable media, such as a CD, DVD, USB, or network. The installation process involves several steps, such as:

  - Choosing the language, region, and keyboard layout.
  - Accepting the license agreement and terms of use.
  - Selecting the installation type, such as upgrade or custom.
  - Choosing the partition and drive where Windows will be installed.
  - Copying the files and settings from the media to the device.
  - Restarting the device and completing the initial setup, such as creating a user account, setting a password, and connecting to a network.

- Windows can be configured after the installation to suit the user's preferences and needs. Some of the configuration options are:

  - Changing the display settings, such as resolution, brightness, and color.
  - Adjusting the sound settings, such as volume, balance, and quality.
  - Setting the date and time, and choosing the time zone and format.
  - Enabling or disabling the features and services, such as firewall, antivirus, updates, and more.
  - Installing or updating the drivers and applications, and removing the unwanted ones.
  - Creating or modifying the user accounts, and setting the permissions and privileges.
