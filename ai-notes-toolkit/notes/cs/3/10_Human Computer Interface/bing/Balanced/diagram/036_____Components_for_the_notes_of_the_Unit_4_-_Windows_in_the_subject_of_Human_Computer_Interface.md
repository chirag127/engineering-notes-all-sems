### Components of Windows in Human Computer Interface

A window is a graphical user interface (GUI) element that displays the content of an application or a file on the screen. A window can have various components that allow the user to interact with the application or the file, such as menus, icons, scroll bars, buttons, etc. A window can also be resized, moved, minimized, maximized, or closed by the user. A window is managed by a window manager, which is part of a windowing system that handles the input and output of multiple windows on the screen.

Some of the common components of windows in human computer interface are:

- **Pointer**: A symbol that appears on the screen and that the user can move to select objects and commands. The pointer can have different shapes depending on the context, such as an arrow, a hand, a crosshair, etc. The pointer is usually controlled by a pointing device, such as a mouse, a trackpad, a touch screen, etc.
- **Icon**: A small graphical representation of a program, a file, a folder, or a command. Icons can be used to launch applications, open files, access folders, or execute commands. Icons can also show the status or the type of the object they represent, such as a document, a picture, a video, etc.
- **Menu**: A set of options presented to the user, to help with the execution of the program. Menus can be organized in different ways, such as drop-down menus, pop-up menus, context menus, etc. Menus can also have submenus, which are menus within menus. Menus can be accessed by clicking on a menu bar, a menu button, or by right-clicking on an object.
- **Scroll bar**: A graphical element that allows the user to scroll the content of a window, such as a document, a web page, a list, etc. A scroll bar consists of a slider, which can be dragged by the user, and two arrows, which can be clicked to move the slider up or down. A scroll bar can be horizontal or vertical, depending on the orientation of the content.
- **Button**: A graphical element that can be clicked by the user to perform a specific action, such as submitting a form, closing a window, playing a video, etc. A button can have a label, an icon, or both, to indicate its function. A button can also have different states, such as normal, pressed, disabled, etc.
- **Text box**: A graphical element that allows the user to enter or edit text, such as a name, a password, a search query, etc. A text box can have a label, a placeholder, or a hint, to indicate what the user should type. A text box can also have different attributes, such as size, length, format, etc.
- **Check box**: A graphical element that allows the user to select or deselect one or more options from a list. A check box consists of a square, which can be checked or unchecked by the user, and a label, which describes the option. A check box can also have different states, such as checked, unchecked, indeterminate, etc.
- **Radio button**: A graphical element that allows the user to select one option from a list. A radio button consists of a circle, which can be selected or deselected by the user, and a label, which describes the option. A radio button can also have different states, such as selected, deselected, etc. Only one radio button can be selected at a time in a group of radio buttons.
- **List box**: A graphical element that allows the user to select one or more options from a list. A list box consists of a rectangular area, which displays the options, and a scroll bar, which allows the user to scroll the options. A list box can also have different attributes, such as single or multiple selection, sorted or unsorted, etc.
- **Combo box**: A graphical element that combines a text box and a list box. A combo box allows the user to enter or select an option from a list. A combo box consists of a text box, which displays the selected option or the user input, and a button, which opens a list box, which displays the options. A combo box can also have different attributes, such as editable or non-editable, sorted or unsorted, etc.
