### Screen planning and purpose for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

1. Screen planning is the process of designing and organizing the layout and content of a screen in a user interface.
2. The purpose of screen planning is to create a user-friendly and intuitive interface that allows users to easily navigate and interact with the system.
3. Effective screen planning takes into account the user's needs, goals, and preferences, as well as the context in which the interface will be used.
4. Screen planning involves the selection and arrangement of interface elements such as text, images, buttons, and input fields.
5. The layout and organization of these elements should be logical and consistent, making it easy for users to understand and use the interface.
6. Screen planning also involves the use of visual design principles such as color, contrast, and typography to enhance the usability and aesthetics of the interface.
7. The ultimate goal of screen planning is to create an interface that is efficient, effective, and satisfying for the user.
