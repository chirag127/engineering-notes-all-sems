### Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. **Window Frame**: The frame is the outermost part of the window that holds the window panes in place and provides a mounting point for the window hardware.
2. **Title Bar**: The title bar is the horizontal bar at the top of a window that displays the window's title and contains buttons for minimizing, maximizing, and closing the window.
3. **Menu Bar**: The menu bar is the horizontal bar below the title bar that contains drop-down menus for accessing the window's functions and commands.
4. **Toolbar**: The toolbar is a row of buttons or icons that provide quick access to commonly used commands or functions.
5. **Status Bar**: The status bar is the horizontal bar at the bottom of a window that displays information about the current state of the window or the program it represents.
6. **Scroll Bar**: The scroll bar is a vertical or horizontal bar that allows the user to scroll the contents of the window.
7. **Window Pane**: The window pane is the area within the window frame that displays the window's contents.
8. **Minimize, Maximize, and Close Buttons**: These buttons are located in the title bar and allow the user to minimize, maximize, or close the window.
9. **Resize Handle**: The resize handle is a small area in the lower-right corner of a window that allows the user to resize the window by clicking and dragging.
