### Characteristics for the notes of the Unit 1 - Introduction in the subject of Human Computer Interface

1. **Usability**: The system should be easy to use and learn, with a user-friendly interface.
2. **Efficiency**: The system should be efficient in terms of time and effort required to complete tasks.
3. **Effectiveness**: The system should be effective in achieving the desired goals and objectives.
4. **Learnability**: The system should be easy to learn and remember, with clear and concise instructions.
5. **Flexibility**: The system should be flexible and adaptable to different user needs and preferences.
6. **Error Tolerance**: The system should be tolerant of user errors and provide clear and helpful error messages.
7. **Satisfaction**: The system should provide a satisfying and enjoyable user experience.
