# Keyboard and Function Keys

## Unit 5 - Software Tools in the Subject of Human Computer Interface

- A keyboard is an input device that allows a user to enter letters, numbers, and other symbols into a computer.
- The most common type of keyboard is the QWERTY keyboard, which is named after the first six letters on the top row of keys.
- Function keys are a set of keys located at the top of the keyboard, typically labeled F1 through F12.
- These keys are used to perform specific tasks, depending on the software program being used.
- For example, in many programs, the F1 key is used to open the help menu, while the F5 key is used to refresh the screen.
- Some keyboards also have additional function keys, such as multimedia keys for controlling audio and video playback.
- The use of function keys can vary between different software programs, and it is important for users to familiarize themselves with the specific functions of these keys in the programs they use.
