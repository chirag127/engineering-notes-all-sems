# Pointing Devices

Pointing devices are input devices that allow a user to interact with a computer by moving a cursor or pointer on the screen. These devices are used to select, move, and manipulate objects on the screen. Some common pointing devices include:

1. **Mouse**: A mouse is a small handheld device that is moved across a flat surface to control the movement of the cursor on the screen. It typically has one or more buttons that can be used to select and manipulate objects.

2. **Trackball**: A trackball is similar to a mouse, but instead of moving the entire device, the user rolls a ball on the top of the device to control the movement of the cursor.

3. **Touchpad**: A touchpad is a flat, touch-sensitive surface that is typically found on laptop computers. The user moves their finger across the surface to control the movement of the cursor.

4. **Stylus**: A stylus is a pen-like device that is used to interact with touchscreens. The user can tap, swipe, and draw on the screen using the stylus.

5. **Joystick**: A joystick is a handheld device that consists of a stick that pivots on a base. The user moves the stick to control the movement of the cursor or an object on the screen.

These are some of the common pointing devices used in Human-Computer Interaction. Each device has its own advantages and disadvantages, and the choice of device may depend on the specific task or application.
