## Unit 4 - Windows

1. Windows is an operating system developed by Microsoft Corporation.
2. It is a graphical operating system, meaning it uses graphical icons and visual indicators to interact with the user.
3. The first version of Windows, Windows 1.0, was released in 1985.
4. Windows is the most widely used operating system in the world, with a market share of over 75%.
5. Some of the key features of Windows include its user-friendly interface, support for a wide range of hardware and software, and its ability to run multiple applications simultaneously.
6. Windows has gone through several versions, with the latest being Windows 10.
7. Windows 10 introduced several new features, including the Cortana virtual assistant, the Edge web browser, and the ability to run Universal Windows Platform apps.
8. Windows is used by both home and business users, and is available in several editions, including Windows Home, Windows Pro, and Windows Enterprise.
9. Windows is also available for other devices, such as tablets and smartphones, through the Windows 10 Mobile operating system.
10. Microsoft regularly releases updates for Windows, which include security patches, bug fixes, and new features.
