# Unit 1 - Introduction to Human Computer Interface

## Graphical System

1. A graphical system is a type of user interface that allows users to interact with electronic devices through graphical icons and visual indicators.
2. It is a way to make computers more user-friendly and easier to use.
3. Graphical systems are commonly used in operating systems, such as Windows, macOS, and Linux.
4. They provide a visual way to navigate and interact with the computer, making it easier for users to find and use the features they need.
5. Graphical systems can also include features such as drag-and-drop, which allows users to move files and folders by clicking and dragging them with the mouse.
6. They can also include features such as context menus, which provide quick access to commonly used commands by right-clicking on an object.
7. Graphical systems have evolved over time, with newer versions offering more advanced features and improved usability.
8. They are an important part of human-computer interaction, as they provide a way for users to interact with computers in a more intuitive and natural way.
