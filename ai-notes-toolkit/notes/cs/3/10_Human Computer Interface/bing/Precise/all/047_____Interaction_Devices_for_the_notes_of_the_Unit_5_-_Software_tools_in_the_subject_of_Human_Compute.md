# Interaction Devices

Interaction devices are hardware components that allow users to interact with a computer system. These devices are used to input data, issue commands, and control the computer. Some common interaction devices include:

1. Keyboard: A keyboard is a device that allows users to enter text and numbers into a computer. It is one of the most common input devices and is used for typing documents, sending emails, and entering commands.

2. Mouse: A mouse is a pointing device that allows users to control the movement of a cursor on the screen. It is used to select, drag, and drop objects, as well as to navigate through menus and windows.

3. Touchscreen: A touchscreen is a display that can detect the presence and location of a touch within the display area. It is used to interact with the computer by touching the screen with a finger or stylus.

4. Microphone: A microphone is a device that converts sound waves into an electrical signal. It is used to input voice commands and record audio.

5. Game controller: A game controller is a device used to control video games. It typically has buttons, joysticks, and triggers that allow the user to interact with the game.

6. Scanner: A scanner is a device that captures images of documents, photos, or objects and converts them into digital format. It is used to input images into the computer for editing or storage.

7. Digital camera: A digital camera is a device that captures still images or videos and stores them in digital format. It is used to input images and videos into the computer for editing or sharing.

These are some of the common interaction devices used in Human-Computer Interface. Each device has its own unique features and capabilities, and the choice of device depends on the specific task and user preferences.
