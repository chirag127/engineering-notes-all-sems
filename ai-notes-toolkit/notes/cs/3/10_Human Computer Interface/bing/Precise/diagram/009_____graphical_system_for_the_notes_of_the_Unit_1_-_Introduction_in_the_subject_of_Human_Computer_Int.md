### Graphical System for the Notes of the Unit 1 - Introduction in the Subject of Human Computer Interface

1. A graphical system is a visual representation of data and information.
2. It can be used to organize and present information in a clear and concise manner.
3. In the context of Human Computer Interface (HCI), a graphical system can be used to present information about the subject in a visually appealing and easy-to-understand manner.
4. This can include the use of diagrams, charts, and other visual aids to help convey information.
5. A well-designed graphical system can help students better understand and retain information about the subject.
6. It can also make studying and reviewing material more engaging and effective.
7. In summary, a graphical system is a valuable tool for presenting information in the subject of HCI, and can greatly enhance the learning experience.
