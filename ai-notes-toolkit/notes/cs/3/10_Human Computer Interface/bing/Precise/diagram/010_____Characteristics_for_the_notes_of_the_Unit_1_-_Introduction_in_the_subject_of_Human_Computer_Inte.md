### Characteristics for the notes of the Unit 1 - Introduction in the subject of Human Computer Interface

1. **Usability**: The interface should be easy to use and learn, allowing the user to accomplish their tasks efficiently and effectively.
2. **Accessibility**: The interface should be accessible to users with a wide range of abilities, including those with disabilities.
3. **Consistency**: The interface should be consistent in its design and behavior, allowing the user to develop a mental model of how it works.
4. **Feedback**: The interface should provide clear and timely feedback to the user about their actions and the system's state.
5. **Error prevention and recovery**: The interface should prevent errors from occurring, and if they do occur, provide the user with the ability to recover from them.
6. **Flexibility**: The interface should be flexible, allowing the user to customize it to their needs and preferences.
7. **Aesthetics**: The interface should be visually appealing and engaging, enhancing the user's experience.
