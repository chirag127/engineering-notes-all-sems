### Unit 4 - Windows in Human Computer Interface

#### Components

1. **Window Frame**: The outermost part of the window that defines its boundaries and provides a visual separation from other windows.
2. **Title Bar**: The horizontal bar at the top of the window that displays the window's title and contains buttons for minimizing, maximizing, and closing the window.
3. **Menu Bar**: The horizontal bar below the title bar that contains drop-down menus for accessing the window's functions and features.
4. **Toolbar**: A row of buttons or icons that provide quick access to commonly used commands or functions.
5. **Status Bar**: The horizontal bar at the bottom of the window that displays information about the current state of the window or its contents.
6. **Scroll Bar**: A vertical or horizontal bar that allows the user to scroll the contents of the window.
7. **Client Area**: The main area of the window where the content is displayed.
8. **Resize Handle**: A small area in the lower-right corner of the window that allows the user to resize the window by clicking and dragging.
