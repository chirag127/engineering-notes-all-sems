
### New and Navigation Schemes Selection of Windows

* Windows are graphical user interfaces (GUIs) that allow users to interact with a computer by manipulating graphical objects on the screen.
* Windows have a hierarchical structure that can be navigated using the mouse or a keyboard shortcut.
* A window can be divided into two distinct areas: the main window and the child window.
* The main window contains the title bar, menu bar, toolbar, and status bar.
* The child window contains the content of the window, such as text, images, or other media.
* Windows can be resized and moved around the screen using the mouse.
* Windows can also be minimized and maximized using the mouse or keyboard shortcut.
* Windows can be opened, closed, and moved between different screens.
* Windows can also be opened in full-screen mode.
* Windows can be customized using themes, colors, and fonts.
* Windows can also be customized with widgets, such as clocks, calendars, and taskbars.
