
### Screen Planning and Purpose for Unit 3 - Screen Designing

1. Screen planning involves designing the layout of the screen, determining the type of user interface to be used, and selecting the appropriate software components.

2. The purpose of screen design is to create an interface that is easy to use, aesthetically pleasing, and meets the user's needs.

3. It is important to consider the user's experience when planning the screen layout. This includes considering the user's physical abilities, preferences, and context.

4. The layout of the screen should be designed to be clear and intuitive, with information and controls organized in a logical manner.

5. The user interface should be designed to be consistent, so that users can easily transfer their knowledge from one screen to another.

6. The user interface should also be designed to be efficient, so that users can quickly and easily access the information and controls they need.

7. It is important to consider the user's goals when designing the user interface. This includes considering the user's desired outcome and the tasks they need to complete to achieve it.

8. The user interface should also be designed to be secure, so that users' data and information is protected.

9. It is important to consider the user's environment when designing the user interface. This includes considering the user's device, operating system, and network connection.
