### Ordering of Screen Data and Content for the Notes of Unit 3 - Screen Designing in the Subject of Human Computer Interface

Screen designing is a crucial aspect of creating a user-friendly interface that enhances the user's experience. In this unit, we will discuss the ordering of screen data and content, which plays a vital role in creating a successful user interface. 

Here are some points to keep in mind:

1. **Hierarchy of Information:** The most important information should be displayed prominently on the screen. It should be easy to find and access. The hierarchy of information is determined by its importance and relevance to the user.

2. **Consistency:** Consistency in design is essential in creating a user-friendly interface. The ordering of screen data and content should be consistent throughout the application. This consistency helps users navigate the application with ease.

3. **Grouping of Information:** Similar information should be grouped together. This grouping makes it easier for the user to understand the content and reduces cognitive load. Grouping also helps to create a logical flow of information.

4. **White Space:** White space is an essential element of screen design. It helps to break up the content and creates a visual hierarchy. White space also helps to reduce cognitive load and improves the readability of the content.

5. **Visual Cues:** Visual cues, such as icons, help the user to understand the content quickly. These cues should be consistent throughout the application and should be placed in a prominent location.

6. **Navigation:** Navigation is an essential aspect of screen design. It should be easy to find and access. Navigation should be consistent throughout the application and should be placed in a prominent location.

7. **Error Messages:** Error messages should be displayed in a prominent location and should be easy to understand. The error message should provide clear instructions on how to resolve the issue.

In conclusion, ordering of screen data and content is an essential aspect of screen designing. It helps to create a user-friendly interface that enhances the user's experience. The points mentioned above should be kept in mind while designing the user interface to ensure its success.
