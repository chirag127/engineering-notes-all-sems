### Focus and Emphasis for the Notes of Unit 3 - Screen Designing in the Subject of Human Computer Interface

Screen designing is a crucial aspect of human-computer interaction. It involves the creation of an interface that allows users to interact with computer systems. The following are the key points to focus on while studying screen designing:

1. Understanding user needs: The first step in screen designing is to understand the needs of the users. It is essential to identify their requirements and preferences to create an interface that meets their needs.

2. Visual hierarchy: The visual hierarchy of the interface is critical in screen designing. The designer should arrange the elements in a way that makes it easy for users to navigate and find what they are looking for. The use of color, size, and contrast can help in creating a visual hierarchy.

3. Consistency: Consistency is essential in screen designing. The interface should have a consistent layout, font, and color scheme to make it easy for users to understand and use.

4. Usability: Usability is a critical factor in screen designing. The designer should create an interface that is easy to use, intuitive, and requires minimal effort to complete tasks.

5. Accessibility: Accessibility is another crucial aspect of screen designing. The interface should be accessible to all users, including those with disabilities. The designer should consider factors such as color contrast, text size, and keyboard navigation, among others.

6. Feedback: Feedback is essential in screen designing. The interface should provide users with feedback on their actions. This feedback can be in the form of visual cues, such as animation or sound, to let users know that their actions have been registered.

7. Testing: Testing is critical in screen designing. The designer should test the interface to ensure that it meets the needs of the users and is easy to use. User testing can provide valuable feedback that can be used to improve the interface.

In summary, screen designing is an essential aspect of human-computer interaction. Understanding user needs, creating a visual hierarchy, maintaining consistency, ensuring usability and accessibility, providing feedback, and testing are the key points to focus on while studying screen designing.
