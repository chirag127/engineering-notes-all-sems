## Unit 4 - Windows

Windows is a popular operating system used by millions of people worldwide. In this unit, we will examine the key features and functions of Windows, including:

- The desktop: The desktop is the main screen that appears when you start up your computer. It is where you will find your icons, files, folders, and other important information.

- The Start menu: The Start menu is a central hub where you can access all of your applications, settings, and files. It is located in the bottom left-hand corner of the desktop.

- File Explorer: File Explorer is the default file management tool in Windows. It allows you to browse, open, and manage files and folders on your computer.

- Control Panel: The Control Panel is a powerful tool that allows you to configure and customize various aspects of your Windows operating system. It can be accessed from the Start menu, and it includes options to change your display settings, add or remove programs, and more.

- Task Manager: Task Manager is a system utility that allows you to view and manage all of the processes and programs running on your computer. It can be accessed by pressing Ctrl+Shift+Esc or by right-clicking the taskbar and selecting Task Manager.

- Windows Updates: Windows Updates are important for keeping your computer secure and up-to-date. They include security patches, bug fixes, and new features. You can check for updates by going to Settings > Update & Security > Windows Update.

- Cortana: Cortana is a virtual assistant that can help you with a variety of tasks, including setting reminders, finding information online, and more. It can be accessed by clicking the search bar in the taskbar or by saying "Hey Cortana" if you have a microphone.

- Microsoft Store: The Microsoft Store is a digital distribution platform where you can download and install apps, games, and other software. It is accessible from the Start menu and includes both free and paid apps.

- Windows Defender: Windows Defender is a built-in antivirus program that helps protect your computer from viruses, malware, and other threats. It is automatically enabled in Windows 10 and can be managed through the Windows Security app.

Overall, Windows is a powerful and versatile operating system that offers a wide range of features and functions for both personal and professional use. By familiarizing yourself with these key components, you can become more efficient and productive in your daily computer use.
