### Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. Graphical User Interface (GUI):
   - A GUI is a type of interface that allows users to interact with electronic devices using images and graphics, rather than text-based commands.
   - Windows is a prime example of a GUI, where users can interact with the system using icons, menus, buttons, and other graphical elements.

2. Window Manager:
   - A Window Manager is a software component responsible for managing the placement and appearance of windows on the screen.
   - It allows users to move, resize, minimize, and close windows using various graphical elements.

3. Title bar:
   - The title bar is a horizontal bar that appears at the top of each window.
   - It displays the name of the window and provides buttons for minimizing, maximizing, and closing the window.

4. Menu bar:
   - The menu bar is a horizontal bar that appears below the title bar.
   - It contains menus that provide access to various functions and settings of the application.

5. Toolbars:
   - Toolbars are a collection of buttons that provide quick access to commonly used functions.
   - They are typically located below the menu bar and can be customized by the user.

6. Status bar:
   - The status bar is a horizontal bar that appears at the bottom of the window.
   - It displays information about the current state of the application, such as the progress of a task or the status of an internet connection.

7. Dialog boxes:
   - Dialog boxes are windows that appear on top of the main application window.
   - They are used to request input from the user or to display important messages.

8. Scrollbar:
   - The scrollbar is a graphical element that appears on the side of a window.
   - It allows users to scroll through the contents of a window that are too large to fit on the screen.

9. Icons:
   - Icons are small graphical elements that represent files, folders, and applications.
   - They can be used to launch applications, open files, or perform other actions.

10. Context menus:
   - Context menus are menus that appear when the user right-clicks on an object, such as a file or folder.
   - They provide quick access to various options and functions related to the selected object. 

Overall, these components form the core of the Windows interface, and understanding their functions and features is essential for effective use of the system.
