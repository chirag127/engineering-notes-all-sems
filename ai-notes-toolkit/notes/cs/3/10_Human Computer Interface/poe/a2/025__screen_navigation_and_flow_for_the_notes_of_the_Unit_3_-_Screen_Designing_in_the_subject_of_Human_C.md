### Screen Navigation and Flow

1. Screen Flow
- The flow of screens in an app or website is the sequence of screens that a user encounters and the paths between them.
- An effective screen flow guides the user to their goal while providing a good user experience.
- Types of screen flows:
    - Linear flow: Moving in one direction from start to end. Eg. Sign-up process.
    - Non-linear flow: Users can navigate in different directions. Eg. Website with many pages.
    - Wizard: Multi-step flow where users provide information sequentially.

2. Screen Navigation
- Refers to the design of how users can move between screens.
- Common navigation options:
    - Back/cancel button: Goes to previous screen.
    - Home button: Goes to the home/first screen.
    - Menu button: Accesses a menu to navigate to other screens.
    - Breadcrumbs: Shows current location within a hierarchy of screens.
    - Links/buttons: Directly links to other relevant screens.
- Navigation should be clear, concise, consistent and easy to use.
- Same navigation options should appear in same position on all screens for predictability.

3. Minimizing Cognitive Load
- The screen flow and navigation should be designed to minimize the cognitive load on the user's mind.
- Ways to minimize cognitive load:
    - Limit number of choices and options.
    - Remove unnecessary screens and information.
    - Use consistent and predictable patterns.
    - Provide feedback and guidance to user.
    - Arrange elements in a simple and uncluttered manner.
