### Human interaction with computers

- Text-based interaction: Early interaction with computers was through text. Users typed commands or input and computers responded with text output.
- Graphical user interfaces (GUIs): The introduction of graphics, windows, icons and a mouse allowed more intuitive interaction. Windows, icons, and menus replaced text commands.
- Direct manipulation: GUIs allowed direct manipulation of on-screen objects using the mouse and other input devices. This was more intuitive than typed commands.
- Modes: Early interfaces were modal, requiring users to specify which application or mode they wanted to interact with. Contemporary interfaces are modeless, where interaction is more fluid.
- Metaphors: Interface designers often use familiar physical world metaphors to help users understand and interact with software - e.g. file folders, desktops, documents. However, these can sometimes be limiting or confusing.
- User research: Understanding user requirements and evaluating interfaces to ensure usability has become a key part of interface design using methods like user testing, surveys, behavioural analysis, etc.
- The future: Emerging technologies like voice, gesture, augmented/virtual reality interfaces are enabling more natural and immersive interaction paradigms. However, they introduce new usability challenges.
