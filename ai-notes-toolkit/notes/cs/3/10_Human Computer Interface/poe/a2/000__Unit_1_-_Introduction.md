## Unit 1 - Introduction

1. Topic 1: Introduction to Programming
- Programming is the process of designing and developing algorithms to solve problems or achieve some goals.
- Algorithms are a sequence of steps to solve a problem or achieve some goal.
- Programming languages are used to write algorithms in a syntax that can be understood by computers.
- The two major types of programming languages are low-level languages and high-level languages.

2. Topic 2: How Computers Work
- Computers work on the principle of input, processing, storage, and output.
- The central processing unit or CPU fetches instructions and performs operations on data.
- Computer memory stores data and program instructions for the CPU.
- Storage devices hold data and programs permanently for later use.
- Input and output devices interface with users and other devices.

3. Topic 3: Choosing a Programming Language
- The choice of a programming language depends on the purpose of programming, programmer preferences, software requirements, hardware requirements, etc.
- Popular and common programming languages include Java, Python, C/C++, JavaScript, PHP, etc.
- The features and applications of different programming languages should be evaluated before choosing a language for a particular purpose.
