### The graphical user interface for the notes of the Unit 1 - Introduction in the subject of Human Computer Interface.

1. GUI stands for Graphical User Interface. It is a type of user interface that allows users to interact with electronic devices through graphical icons and visual indicators such as secondary notation, instead of text-based user interfaces, typed command labels or text navigation.

2. The advantages of GUI are:
- Easy to use: GUIs are easier to use than command-line interfaces, which require commands to be typed on the keyboard.
- Faster to use: With the use of pointing devices and icons, GUIs are faster to use than typing commands.
- Easier to learn: GUIs are easier to learn than command-line interfaces as they provide visual cues to help users.

3. The disadvantages of GUI are:
- Slower system response: GUI systems require more memory and processing power as they involve additional software and graphics rendering which can lead to slower system response.
- Higher system requirements: The additional software and graphics of GUI systems lead to higher system requirements and cost.
- Less efficient for expert users: For expert users who are well versed with the commands, CLI can be more efficient than GUI.

4. Examples of GUIs: The Microsoft Windows operating system, MacOS, and the several versions of UNIX that include a GUI are common examples of operating systems that utilize a GUI. Many modern software applications also employ GUIs.
