## Unit 5 - Software tools

1. Text Editors - Text editors are software applications that are used to create and edit plain text files. They provide a simple interface for writing and formatting text. Some popular text editors are:
- Notepad++ - Free, open source text editor for Windows with syntax highlighting and code folding.
- Sublime Text - Sophisticated text editor for code, markup and prose.
- Vim - Highly configurable text editor built to enable efficient text editing.
- Emacs - Extensible, customizable text editor—and more. At its core is an interpreter for Emacs Lisp.

2. IDEs - Integrated Development Environments or IDEs are software applications that provide a complete suite of tools for software development. They typically include:
- A source code editor
- A compiler and/or interpreter
- A debugger
- A build automation tool
Popular IDEs include:
- Eclipse - Extensible IDE mainly for Java, but supports other languages too like C/C++, PHP, Python, etc.
- IntelliJ IDEA - IDE for Java, but also supports other languages like Kotlin, Scala, Groovy, etc.
- Visual Studio - Microsoft's IDE supporting languages like C#, C++, JavaScript, TypeScript, Python, etc.
- XCode - IDE for macOS primarily used for developing software for macOS and iOS. Supports Swift, Objective-C, C++, etc.

3. Version Control Systems - VCS or Version Control Systems are software tools that track changes to code or other files, enabling developers to recall specific versions later. They enable collaboration and prevent issues like overriding each other's changes. Popular VCSs include:
- Git - Distributed VCS with a focus on speed and efficiency.
- Mercurial - Distributed VCS with a simple and consistent interface.
- Subversion - Centralized VCS with a straightforward design.
