### Icons and increases for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. Icons:
- Small pictorial representations of commands, files, etc.
- Help in quickly identifying options.
- Easy to understand than text.
- Take less space.
- Culturally neutral.

2. Windows:
- A rectangular area on the screen that contains a program or a set of programs.
- Allow interaction with multiple applications simultaneously.
- Can be resized, moved, hidden, etc.
- Provide environment to work in.
- Types:
-- Document window: Single application, eg. MS Word.
-- Dialog window: Gets input from user, eg. Save As dialog.
-- Utility window: Provides access to the environment's tools/utilities.
