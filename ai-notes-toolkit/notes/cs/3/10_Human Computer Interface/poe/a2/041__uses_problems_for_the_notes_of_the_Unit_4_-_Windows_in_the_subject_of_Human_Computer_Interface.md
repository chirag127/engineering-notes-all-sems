### Uses & Problems of Windows (Unit 4 - HCI)

1. Windows allow users to view multiple applications, files, and data simultaneously. This allows for easier multitasking and referencing of information from multiple sources.
2. However, too many open windows can lead to desktop clutter and make it difficult to find the required window. Unmanaged windows can also lead to information overload and decreased productivity.
3. The size and placement of windows can affect user experience. If windows are too small, the applications may be difficult to use. If windows are arranged haphazardly, it can be difficult to view and access them. Allowing users to customize window sizes and locations can enhance their experience.
4. Different types of windows may be needed for various tasks. For example, popup windows are useful for alerts but can be annoying if overused. Modal windows that require a response can be useful but may be disruptive to workflow if used frequently. The application should use appropriate types of windows for the right purposes and situations.
5. The features and controls of windows such as minimize, maximize, close buttons; scrollbars; title bars; etc. allow users to manage windows. However, if these controls are not easily found or are unfamiliar to users, it can create a poor experience. Controls should be intuitive and consistent across applications.
