### Q Learning function for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Q Learning is a model-free reinforcement learning algorithm.
2. It learns an optimal action-selection policy directly from interaction with the environment.
3. Q Learning estimates the expected long term reward for taking an action in a given state as Q(state, action) incrementally.
4. The Q values are updated using the Bellman equation - Q(state, action) = Reward + Gamma * Max(Q(next state, all actions))
5. The algorithm follows an explore-exploit strategy to balance exploration of unvisited states and exploitation of the current policy.
6. The optimal policy can be obtained by selecting the action that maximizes Q(state, action) for each state.
7. Q Learning convergence can be proven under certain conditions and it has been applied in various problems like control problems, game playing etc.

The above points cover the key aspects of Q Learning algorithm which can be studied in detail as a part of Reinforcement Learning techniques.
