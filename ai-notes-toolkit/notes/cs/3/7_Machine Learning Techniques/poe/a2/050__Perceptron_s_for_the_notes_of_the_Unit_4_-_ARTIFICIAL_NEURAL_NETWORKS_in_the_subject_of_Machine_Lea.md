### Perceptron’s for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. Perceptron is a single-layer neural network and is a basic building block of neural networks.
2. It is a linear classifier algorithm that makes its predictions based on a linearly separable dataset.
3. It has an input layer that receives the input data and an output layer that produces the output.
4. It has weights associated with the input features/attributes. The weighted sum of the input is calculated and if the result exceeds a threshold value then it produces an output, else no output is produced.
5. The weights are adjusted in each iteration based on the error made in the previous iteration using a learning rule until the perceptron achieves 100% accuracy on the training set.
6. Perceptron learning algorithm can converge to a correct weight vector only if the given dataset is linearly separable. If not, the algorithm will continue indefinitely.
7. Perceptron forms a foundation for learning in multi-layer neural networks by incorporating non-linearity through activation functions.
