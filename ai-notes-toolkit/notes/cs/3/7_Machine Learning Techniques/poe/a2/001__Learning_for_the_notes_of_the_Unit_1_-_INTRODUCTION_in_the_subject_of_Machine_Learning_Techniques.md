### Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

1. Machine Learning - Machine Learning is a field of computer science that gives computers the ability to learn without being explicitly programmed. Machine Learning focuses on the development of computer programs that can change when exposed to new data.

2. Types of Machine Learning - There are three types of Machine Learning:

a. Supervised Learning - Supervised Learning uses labeled examples to learn a function that maps inputs to outputs. It uses known input and output data to learn the mapping function. Examples: Classification and Regression.

b. Unsupervised Learning - Unsupervised Learning uses unlabeled data to find hidden patterns or clusters in the data. It is used to draw inferences from the data. Example: Clustering.

c. Reinforcement Learning - Reinforcement Learning learns by interacting with a dynamic environment. The system learns from feedback in the form of rewards in an uncertain and possibly delayed reactions. Example: Learning to play games.

3. Why Machine Learning? - Machine Learning is a growing and exciting field of artificial intelligence because of the following reasons:

a. Large amounts of data availability - There is a huge amount of data available in various forms and Machine Learning utilizes that data to learn and make decisions.

b. Increased computing processing power - The increased computing processing power enables machine learning algorithms to process huge amounts of data and train machine learning models.

c. Need for automation - There is a need to automate tasks and make decisions to improve efficiency. Machine Learning addresses this need by learning and making predictions on new data.

d. Research advancement - There have been significant research advancements in Machine Learning that have led to more accurate algorithms and models. This has increased the application of Machine Learning to various real-world problems.
