### Properties of SVM for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques:

1. SVM can solve linear and non-linear problems: SVM can be used for classification and regression problems. It uses a nonlinear mapping to transform the input data into a higher dimension and constructs an optimal separating hyperplane with the maximal margin in this higher dimensional space.

2. SVM is effective in high dimensional spaces: SVM performs well in cases where the number of dimensions is greater than the number of samples. It avoids overfitting in such cases and hence is known as a regularization method.

3. SVM is Memory efficient: SVM does not need to compute the eigenvectors of a kernel matrix and stores only the support vectors. This makes it memory efficient and thus it can be used with large datasets.

4. SVM provides global optimality: The optimization problem of SVM has a global optimal solution and a unique solution. This is because it is a convex optimization problem. This ensures the good generalization performance of SVM.

5. SVM is versatile: Different kernel functions can be specified in SVM to learn complex decision boundaries. This makes SVM a very versatile classification technique to solve nonlinear problems. Some commonly used kernels are linear, polynomial and RBF kernels.
