### Naïve Bayes classifier for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques.

1. Naïve Bayes is a supervised learning classification algorithm based on applying Bayes' Theorem with strong (naive) independence assumptions between the features.
2. It is mainly used in text classification which includes a high-dimensional training dataset.
3. In Naïve Bayes, each feature's value is assumed to be independent of the other features' values. This assumption is called class conditional independence.
4. The steps involved in Naïve Bayes are:

a) Calculate the probability of each class (target value)
b) Calculate the probability of each feature given a class
c) Apply Bayes' theorem to calculate the probability of a class given the features
d) Predict the class with highest posterior probability

5. Some pros of Naïve Bayes are:

a) Simple and easy to implement
b) Works well even with small training data
c) High scalability - can handle thousands of features efficiently

6. Some cons of Naïve Bayes are:

a) The assumption of independence of features is often not true
b) May perform poorly if the features are correlated
c) May overfit if the training data is not representative

7. Applications of Naïve Bayes include:

a) Spam filtering
b) Sentiment analysis
c) Document classification
