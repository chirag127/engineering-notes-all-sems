### Concept learning for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Regression is a supervised learning technique which focuses on predicting a continuous value based on the given input variables.
2. The goal is to determine the relationship between the independent variables(x) and the dependent variable(y) and use it to predict the outcome for new data.
3. Simple Linear Regression: It analyzes the relationship between a single independent variable(x) and the dependent variable(y). The relationship is represented using a straight line called a regression line.
4. Multiple Linear Regression: It analyzes the relationship between two or more independent variables(x) and the dependent variable(y). The relationship is represented using a linear equation which includes coefficients for each independent variable.
5. Assumptions of Linear Regression:
- Linear relationship between the dependent and independent variables.
- Multivariate normality - Error terms are normally distributed.
- Homoscedasticity - Equal variance of error terms.
- Independence of errors - Error terms are uncorrelated.
- Lack of multicollinearity - Independent variables are not highly correlated.

6. Evaluation Metrics: Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), R-Squared (R2).
