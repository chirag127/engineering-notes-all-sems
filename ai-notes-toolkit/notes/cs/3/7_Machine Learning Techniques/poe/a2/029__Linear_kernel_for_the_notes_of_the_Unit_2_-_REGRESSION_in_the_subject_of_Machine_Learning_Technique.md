### Linear kernel for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Linear regression is a linear approach for modeling the relationship between a scalar response (or dependent variable) y and one or more explanatory variables (or independent variables) denoted X.
2. The case of one explanatory variable is called simple linear regression. For more than one explanatory variable, the process is called multiple linear regression.
3. The linear regression model is "linear" in parameters. It assumes a linear relationship between the independent variables (x) and the dependent variable (y).
4. The linear regression equation is:
y = b0 + b1*x
Where b0 is the intercept and b1 is the slope.
5. The objective is to minimize the error between the predicted output and the actual output. The most common error metric is Mean Squared Error.
6. The least-squares estimate is the value of the parameter that minimizes the sum of squared residuals (difference between the predicted and actual value).
7. Applications of linear regression:
- Simple linear regression: Growth modeling, process control, estimating causal relationships
- Multiple linear regression: Economics (GDP prediction, investing), sciences (prediction), social sciences (effect of variables on a outcome)
