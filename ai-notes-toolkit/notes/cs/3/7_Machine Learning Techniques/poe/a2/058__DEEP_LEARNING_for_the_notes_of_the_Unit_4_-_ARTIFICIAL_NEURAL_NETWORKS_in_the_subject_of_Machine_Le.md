### DEEP LEARNING for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS

1. Artificial Neural Networks (ANNs) are inspired by biological neural networks and are made up of interconnected nodes that operate like neurons firing and connections that operate like synapses.
2. ANNs learn complex patterns in large data sets by being trained on lots of examples to detect patterns and learn features of the data that can then be used to make predictions on new data.
3. Deep Learning is a type of machine learning that uses neural networks with many layers of processing units for feature extraction and pattern analysis.
4. The more layers in a deep network, the higher the level of abstraction that can be learned from the data. Deeper layers learn higher-level features from lower-level features.
5. Deep Learning has achieved state-of-the-art results in various domains such as computer vision, speech recognition, natural language processing, and more. Deep networks are able to automatically learn complex patterns in large data sets without the need for handcrafted rules or features.
6. The main types of deep neural networks are convolutional neural networks (CNNs), recurrent neural networks (RNNs), and long short-term memory networks (LSTMs).
7. Training deep networks is challenging as it requires large amounts of data and computing power and can be prone to overfitting. Various techniques are used to optimize training like regularization, dropout, data augmentation, and transfer learning.
