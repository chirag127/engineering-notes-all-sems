### Introduction to Deep Learning for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS

1. Deep Learning is a subset of Machine Learning that uses neural networks with many layers of processing units for feature extraction and pattern analysis.
2. These deep neural networks attempt to mimic how the human brain works and learn in a hierarchical fashion.
3. They are fed with large amounts of data and learn complex patterns in the data to make predictions or decisions without being explicitly programmed.
4. Some of the popular deep learning architectures are:
    - Convolutional Neural Networks (CNNs) - Used for image processing and computer vision.
    - Recurrent Neural Networks (RNNs) - Used for processing sequential data and time series.
    - Long Short-Term Memory (LSTM) Networks - A type of RNN capable of learning long-term dependencies.
    - Generative Adversarial Networks (GANs) - Used to generate synthetic yet realistic images.
5. Deep Learning has achieved state-of-the-art results in various domains such as computer vision, speech recognition, natural language processing, and more.
6. However, deep learning models require large amounts of data to learn effectively and may be prone to biases in the data or adversarial attacks. More research is being done to address these limitations.
