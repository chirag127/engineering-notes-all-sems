### Bayes theorem for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Bayes theorem is a statistical theorem that provides a way to update the probability of an event given some evidence or new information.
2. It uses prior probabilities andconditional probabilities to calculate the posterior probability.
3. The formula for Bayes theorem is:
 Posterior probability = Likelihood x Prior probability / Evidence
4. It is commonly used in regression models in Machine Learning to compute the probabilities of the predictions and determine the confidence in those predictions.
5. Some key terms used in Bayes theorem are:
 - Prior probability: The initial probability of an event. Denoted as P(A)
 - Likelihood: The probability of evidence given an event. Denoted as P(E|A)
 - Posterior probability: The updated probability of an event after seeing evidence. Denoted as P(A|E)
 - Evidence: The new information observed. Denoted as E
6. Bayes theorem allows updating the probabilities as more evidence or information becomes available. This makes the predictions more accurate as the model gets trained on more data.
7. Some applications of Bayes theorem in regression are:
 - Gaussian Naive Bayes
 - Bayesian linear regression
 - Bayesian logistic regression
