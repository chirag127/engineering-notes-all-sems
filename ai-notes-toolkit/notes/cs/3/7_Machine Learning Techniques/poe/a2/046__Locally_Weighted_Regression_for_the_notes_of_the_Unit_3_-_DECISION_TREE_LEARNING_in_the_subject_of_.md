### Locally Weighted Regression for the notes of the Unit 3 - DECISION TREE LEARNING in the subject of Machine Learning Techniques

1. Locally Weighted Regression is a type of regression analysis which fits simple models to localized subsets of the data to build up a more global model.
2. It is a non-parametric regression technique as it does not assume any functional form for the regression curve.
3. The localized subsets of data are determined according to the nearness of the predictions and the weighting of each data point depends on its distance from the point whose response is being estimated.
4. The locally weighted regression is accomplished by a moving window over the data, computing a weighted regression for each subset of data within the window. Nearby points are given higher weights and distant points are given negligible weights.
5. The variable window width or bandwidth controls the degree of smoothing. A large bandwidth leads to underfitting whereas a small bandwidth may lead to overfitting. Cross-validation can be used to determine an optimal bandwidth.
6. Locally weighted regression can capture nonlinearities and local variations in regression curves and robust to outliers. It produces simple, interpretable models unlike nonparametric techniques based on kernel methods.
7. Some of the limitations are difficulty in choosing bandwidth, computational complexity and tendency to overfit or underfit with inappropriate bandwidth selection.
