### Data Science Vs Machine Learning

1. Data Science is an interdisciplinary field that uses scientific methods, processes, algorithms and systems to extract knowledge and insights from data in various forms, both structured and unstructured. Machine Learning is a field of computer science that gives computers the ability to learn without being explicitly programmed. Machine Learning is a subset of Data Science.

2. Data Science focuses on the entire data processing pipeline that includes data collection, data extraction, data cleaning, data transformation, data modeling, data visualization, data storage etc. Machine Learning focuses on the data modeling aspect of the data processing pipeline. It uses methods like regression, clustering, classification etc to learn and make predictions on data.

3. A Data Scientist must have knowledge of statistics, programming, data visualization etc. A Machine Learning Engineer must have strong knowledge of Machine Learning algorithms and programming skills to implement them.

4. Some applications of Data Science are personalized recommendations, fraud detection, sentiment analysis etc. Some applications of Machine Learning are image classification, speech recognition, machine translation etc.

5. The ultimate goal of Data Science is to extract insights from data that can drive business decisions and optimize business outcomes. The goal of Machine Learning is to make accurate predictions or decisions without being explicitly programmed to perform the task.
