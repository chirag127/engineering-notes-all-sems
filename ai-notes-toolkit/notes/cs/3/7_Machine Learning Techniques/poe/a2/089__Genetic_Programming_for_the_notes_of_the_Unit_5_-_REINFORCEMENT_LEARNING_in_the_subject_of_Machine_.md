### Genetic Programming for the notes of the Unit 5 - REINFORCEMENT LEARNING

1. Genetic Programming: Genetic Programming is a machine learning technique inspired by biological evolution. It automates the design of complex structures (computer programs) whose behaviors improve over time through processes of mutation, recombination, and selection.

2. Steps involved:
    - Randomly generate an initial population of computer programs.
    - Evaluate the fitness of each program in the population.
    - Repeat the following until a termination condition is met:
        - Select programs to reproduce based on fitness.
        - Breed new programs through crossover and mutation.
        - Evaluate the fitness of the offspring programs.
    - The program with the highest fitness is the result.

3. Strengths:
    - GP can automatically generate computer programs to solve problems.
    - GP has tackled problems in various fields like finance, robotics, signal processing, etc.

4. Weaknesses:
    - GP needs to specify the program structures and the operations to build programs from. This requires expert knowledge.
    - GP can be computationally expensive. The training time increases with increase in complexity and size of the programs.
    - GP may produce programs that are hard for humans to interpret.

5. Applications:
    - Robot control
    - Image processing
    - Classification problems
    - Financial forecasting
    - Function optimization
    - Fuzzy systems modeling
