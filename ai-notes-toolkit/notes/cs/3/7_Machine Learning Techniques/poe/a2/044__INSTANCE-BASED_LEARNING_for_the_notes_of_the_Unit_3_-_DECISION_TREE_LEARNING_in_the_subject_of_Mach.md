### INSTANCE-BASED LEARNING

- Instance-based learning does not explicitly construct a general internal model, but instead stores instances or examples
- During classification, the new instance is compared to the stored instances, and the closest match is used to label the new instance.
- The closest match is determined using a distance metric, such as Euclidean distance.
- The key advantage is that it is often simple to implement and can learn disjunctive expressions naturally.
- The key disadvantage is that all training data must be stored, so these methods do not scale well to large data sets.
- Examples of instance-based learning methods include nearest neighbor and case-based reasoning.
