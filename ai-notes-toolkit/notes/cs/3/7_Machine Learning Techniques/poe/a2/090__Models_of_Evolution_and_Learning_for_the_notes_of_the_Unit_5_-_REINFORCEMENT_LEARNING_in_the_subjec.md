### Models of Evolution and Learning for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Evolution Strategies:
- Population of individuals, each with a set of parameters (genome)
- Individuals interact with environment
- Fitness function evaluates performance
- Selection, reproduction, mutation of high-performing individuals
- Repeated over generations
- Can optimize complex, black-box functions

2. Genetic Algorithms:
- Population of individuals, each with encoded set of parameters (chromosomes)
- Fitness function evaluates performance
- Selection, crossover, mutation operators
- Repeated over generations
- Often used for optimization and search

3. Learning Automata:
- Finite set of actions
- Update probabilities of selecting actions based on feedback
- Converge to optimal action selections
- Simple technique, limited applicability
