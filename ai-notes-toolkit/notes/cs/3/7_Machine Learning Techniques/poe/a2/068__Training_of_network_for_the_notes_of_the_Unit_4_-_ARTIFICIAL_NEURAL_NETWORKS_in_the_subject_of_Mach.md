### Training of network for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS

1. Gather the data: Collect the input data and the desired output data to train the neural network. The training data should be representative of the problem.

2. Choose the network architecture: Decide the number of input, hidden and output layers and the number of neurons in each layer. Choose an appropriate activation function for each layer.

3. Initialize the weights and biases: Randomly assign initial values to the weights and biases of the network. These values will get updated during training.

4. Forward propagation: Provide the input to the network and calculate the output using forward propagation.

5. Calculate the error: Calculate the error between the actual output and the desired output. Sum the errors for all the training examples.

6. Backpropagation: Use backpropagation to update the weights and biases by propagating the error from the output layer to the input layer.

7. Repeat steps 4 to 6: Repeat the steps of forward propagation, error calculation and backpropagation multiple times using all the training examples. This is called an epoch.

8. Check for convergence: Check if the network has converged by seeing if the error is within the acceptable range or if the validation accuracy is acceptable. If not, repeat step 7.

9. Testing: Test the trained network with unseen data and evaluate the performance using appropriate metrics.
