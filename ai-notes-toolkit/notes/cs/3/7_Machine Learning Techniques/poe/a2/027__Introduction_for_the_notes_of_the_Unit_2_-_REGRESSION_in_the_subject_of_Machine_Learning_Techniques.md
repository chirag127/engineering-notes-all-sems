### Introduction for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Regression is a supervised learning technique which is used to predict a continuous output variable based on the input variables.
2. It fits a line or a curve to the data points to determine the relationship between the variables and uses this to predict new values.
3. The two main types of regression are:
 - Linear regression: Fits a straight line to the data points. It is suitable when the relationship between the variables is linear.
 - Polynomial regression: Fits a curved line to the data points. It is suitable when the relationship between the variables is non-linear. Higher degree polynomials can fit more complex relationships but are at risk of overfitting.
4. The regression line is characterized by its slope and y-intercept. The slope represents the strength and direction of the relationship between the variables.
5. Regression is a simple yet powerful analysis that can provide valuable insights into data. It is a useful starting point for predictive modeling and forms the basis for more advanced techniques like logistic regression and linear discriminant analysis.
