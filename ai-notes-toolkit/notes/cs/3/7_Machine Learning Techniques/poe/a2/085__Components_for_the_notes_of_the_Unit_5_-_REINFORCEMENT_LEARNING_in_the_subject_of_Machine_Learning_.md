### Components

1. Agent: The learner or decision-maker. The entity that takes actions and receives rewards.
2. Environment: Everything the agent interacts with. This includes the state space and the reward function.
3. State: The current situation which the agent perceives its environment to be in. The set of states is called the state space.
4. Action: The agent's possible behaviors or moves. The set of actions is called the action space.
5. Policy: The agent's strategy for selecting actions. The policy is the conditional probability of taking an action given the current state.
6. Reward: The feedback from the environment in response to the agent's actions. The goal is to maximize the expected cumulative reward.
7. Value Function: A prediction of the expected cumulative reward for a state or state-action pair. The value function is what the agent is trying to learn.
8. Model: The agent's internal representation of the environment's dynamics. The agent can use the model to plan and make predictions.
