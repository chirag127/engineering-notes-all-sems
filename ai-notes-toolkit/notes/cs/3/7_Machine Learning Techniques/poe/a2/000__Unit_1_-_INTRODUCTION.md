## Unit 1 - INTRODUCTION

1. Introduction to Programming
- Programming is the process of creating instructions for a computer to follow in a programming language.
- Programming languages act as mediators between humans and machines. They convert human-readable instructions into machine-readable code.
- The two major types of programming are low-level programming and high-level programming. Low-level programming deals with machine code while high-level programming languages are easier to read and are more user-friendly.

2. Programming Paradigms
- The programming paradigm refers to the style or pattern of programming. Some popular paradigms are:
-- Imperative: Focus on describing 'how' to solve a problem using statements and procedures. Examples: C, C++, Java.
-- Declarative: Focus on describing 'what' the problem is and not how to solve it. Examples: SQL, HTML, CSS.
-- Functional: Treat computation as the evaluation of mathematical functions and avoids state and mutable data. Examples: Lisp, Haskell, Clojure.
-- Logical: Focus on logical propositions and inferences. Examples: Prolog.

3. Software Development Life Cycle
- The Software Development Life Cycle (SDLC) is a systematic process for developing software. It consists of the following stages:
-- Requirements Analysis: Determining what the software should do.
-- Design: Coming up with a plan to build the software.
-- Implementation: Coding and testing the software.
-- Deployment: Installing and launching the software.
-- Maintenance: Fixing bugs and adding new features.
