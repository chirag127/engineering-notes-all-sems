
### EM Algorithm for the Notes of Unit 2 - REGRESSION in the Subject of Machine Learning Techniques

1. EM Algorithm is an iterative method used in Machine Learning techniques. It is used to estimate the parameters of a given model.

2. EM algorithm is an expectation-maximization approach to model fitting. It consists of two steps:
    - Expectation (E) step: In this step, the model’s parameters are estimated using the current values of the parameters.
    - Maximization (M) step: In this step, the parameters are updated according to the values obtained in the E step.

3. EM algorithm is used for regression problems. It can be used to find the parameters of a linear or non-linear regression model.

4. EM algorithm is an iterative process. It starts with an initial set of parameters and then iteratively updates them until the parameters converge to a certain value.

5. The EM algorithm can be used to solve problems with missing data. It can also be used to find the parameters of a model when the data is incomplete or corrupted.

6. EM algorithm is an efficient and accurate method for solving regression problems. It is also relatively simple to implement and can be used in various applications.
