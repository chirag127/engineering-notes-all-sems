
### Entropy and Information Theory for the Notes of Unit 3 - Decision Tree Learning in Machine Learning Techniques

* Entropy is a measure of the uncertainty associated with a random variable. It is a measure of the amount of information needed to determine the probability distribution of the random variable. 
* Information theory is a branch of mathematics that deals with the analysis of the storage, transmission, and manipulation of information. It is closely related to the study of entropy and is a fundamental tool in machine learning. 
* Decision tree learning is a method of supervised learning in which a decision tree is used to model the data. It is used to predict the value of a target variable based on the values of one or more independent variables. 
* Entropy is used in decision tree learning to determine the best split point for a given set of data. It is calculated by measuring the amount of information gained when a given set of data is split into two or more subsets. The higher the entropy, the more information is gained. 
* Entropy can also be used to evaluate the quality of a decision tree. The lower the entropy, the better the quality of the decision tree. 
* Information theory can be used to measure the amount of information contained in a given set of data. The higher the amount of information, the more likely it is that the data contains useful patterns and relationships. 
* Information theory can also be used to measure the complexity of a decision tree. The higher the complexity, the more likely it is that the decision tree will overfit the data.
