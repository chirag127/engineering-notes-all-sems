
### Bayesian Learning for the Notes of the Unit 2 - Regression in the Subject of Machine Learning Techniques

1. Bayesian learning is a type of machine learning technique that uses Bayesian inference to make predictions. 
2. Bayesian learning uses Bayes’ theorem to calculate the probability of an event based on prior knowledge of conditions related to the event. 
3. The Bayesian approach to machine learning is based on the idea that we can learn from our data and use this knowledge to make predictions about future data. 
4. In Bayesian learning, each data point is considered to be a sample from a probability distribution, and the learning algorithm uses this distribution to make predictions. 
5. Bayesian learning can be used to solve regression problems, where the goal is to predict a continuous value based on a set of inputs. 
6. In a Bayesian regression problem, the goal is to find the posterior distribution of the model parameters given the data. 
7. The posterior distribution is calculated using Bayes’ theorem and can be used to make predictions about future data points. 
8. Bayesian learning can also be used to solve classification problems, where the goal is to classify data points into one of a set of categories. 
9. In a Bayesian classification problem, the goal is to find the posterior distribution of the model parameters given the data. 
10. The posterior distribution is calculated using Bayes’ theorem and can be used to make predictions about which category a new data point belongs to.
