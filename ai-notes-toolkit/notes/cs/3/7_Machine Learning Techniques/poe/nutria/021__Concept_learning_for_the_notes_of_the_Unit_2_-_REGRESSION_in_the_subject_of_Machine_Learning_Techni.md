
### Concept Learning for the Notes of the Unit 2 - REGRESSION in the Subject of Machine Learning Techniques

1. Regression is a type of supervised machine learning technique used to predict a continuous numerical value.
2. The goal of regression is to fit a model to a set of data points in order to make predictions about unseen data points.
3. Regression models are used to predict a wide range of values, such as stock prices, house prices, and even election results.
4. Linear regression is the most commonly used regression technique and is used to fit a linear equation to a set of data points.
5. Multiple linear regression can be used to fit a more complex equation with multiple independent variables.
6. Polynomial regression can be used to fit a polynomial equation to a set of data points.
7. Logistic regression is used to predict a binary outcome, such as a yes/no answer or a 0/1 result.
8. Support vector machines (SVMs) are a type of supervised machine learning technique used to classify data points into two or more categories.
9. Decision trees are a type of supervised machine learning technique used to classify data points into two or more categories.
10. Random forests are an ensemble of decision trees used to improve the accuracy of a classification model.
