
### Types of Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

1. Supervised Learning: Supervised learning is a type of machine learning algorithm that uses a known dataset (labeled data) to predict the output for new data. It is commonly used for classification and regression tasks.

2. Unsupervised Learning: Unsupervised learning is a type of machine learning algorithm that does not require labeled data for training. It is commonly used for clustering and dimensionality reduction tasks.

3. Reinforcement Learning: Reinforcement learning is a type of machine learning algorithm that uses rewards and punishments to learn how to take actions in an environment. It is commonly used for robotics, game playing, and decision making tasks.

4. Transfer Learning: Transfer learning is a type of machine learning algorithm that uses knowledge from a previously trained model to improve the performance of a new model. It is commonly used for natural language processing and computer vision tasks.
