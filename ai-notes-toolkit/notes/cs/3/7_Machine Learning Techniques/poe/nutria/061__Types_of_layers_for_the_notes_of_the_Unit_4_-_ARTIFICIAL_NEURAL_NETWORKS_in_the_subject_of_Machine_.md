
### Types of layers for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. Input Layer: This layer is responsible for receiving the input data and passing it to the other layers.
2. Hidden Layer: This layer is responsible for performing the actual computation and is usually made up of neurons.
3. Output Layer: This layer is responsible for producing the output of the Artificial Neural Network.
4. Recurrent Layer: This layer is responsible for processing the data in a sequential manner.
5. Convolutional Layer: This layer is responsible for processing the data in a 2-dimensional manner.
6. Pooling Layer: This layer is responsible for reducing the number of parameters and computation in the network.
7. Normalization Layer: This layer is responsible for normalizing the data to make it easier to process.
