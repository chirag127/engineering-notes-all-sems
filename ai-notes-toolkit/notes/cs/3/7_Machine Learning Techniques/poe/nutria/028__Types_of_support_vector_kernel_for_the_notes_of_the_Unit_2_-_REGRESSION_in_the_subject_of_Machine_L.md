
### Types of Support Vector Kernel for Unit 2 - REGRESSION in Machine Learning Techniques
1. Linear Kernel: This kernel is used when the data is linearly separable. It is the simplest kernel and can be written as a dot product of two vectors.
2. Polynomial Kernel: This kernel is used when the data is non-linearly separable. It can be written as a polynomial of degree d of the dot product of two vectors.
3. Radial Basis Function (RBF) Kernel: This kernel is used when the data is non-linearly separable. It is a Gaussian kernel and can be written as the similarity between two vectors.
4. Sigmoid Kernel: This kernel is used when the data is non-linearly separable. It is a sigmoid function and can be written as a sigmoid of the dot product of two vectors.
