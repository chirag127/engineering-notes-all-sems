
### Derivation of Backpropagation Algorithm

1. Backpropagation is a supervised learning algorithm used to train neural networks. It works by calculating the error between the output of the neural network and the expected output for a given input.

2. The algorithm then adjusts the weights of the neurons in the network to minimise the error. This is done by calculating the gradient of the error function with respect to the weights and then updating the weights accordingly.

3. The backpropagation algorithm is based on the chain rule of calculus. This states that the derivative of a composite function can be expressed as the product of the derivatives of the individual functions.

4. The chain rule is used to calculate the gradient of the error function with respect to the weights of the neurons. This is done by repeatedly applying the chain rule to calculate the derivative of the error function with respect to each weight.

5. The backpropagation algorithm is used to train neural networks by adjusting the weights in the network to minimise the error. This is done by calculating the gradient of the error function with respect to the weights and then updating the weights accordingly.
