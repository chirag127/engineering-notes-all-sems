
### Properties of SVM for the Notes of the Unit 2 - REGRESSION in the Subject of Machine Learning Techniques

* Support Vector Machines (SVM) are supervised learning algorithms used for classification and regression tasks. 
* They are based on the concept of decision planes that separate data into different classes. 
* SVMs are one of the most powerful and widely used machine learning algorithms. 
* SVMs are effective in high-dimensional spaces and can handle large feature sets. 
* SVMs use a subset of training points in the decision function (called support vectors), so they are also memory efficient. 
* SVMs are versatile and can be used for different types of regression problems, such as linear, polynomial, and radial basis function (RBF) regressions. 
* SVMs have several hyperparameters that can be tuned to improve the model's performance, such as the regularization parameter, kernel type, and kernel parameters. 
* SVMs can be used in combination with other algorithms, such as neural networks, to further improve the model's performance.
