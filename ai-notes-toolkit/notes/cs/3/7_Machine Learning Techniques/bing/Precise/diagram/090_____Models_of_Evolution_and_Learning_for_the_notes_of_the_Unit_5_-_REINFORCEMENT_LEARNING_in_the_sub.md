### Models of Evolution and Learning

Unit 5 - REINFORCEMENT LEARNING

Machine Learning Techniques

1. **Evolutionary Algorithms**: These are optimization algorithms that are based on the principles of natural selection and genetics. They are used to find solutions to problems by simulating the process of natural evolution.

2. **Genetic Algorithms**: A type of evolutionary algorithm that uses techniques such as selection, crossover, and mutation to evolve a population of solutions towards an optimal solution.

3. **Evolution Strategies**: Another type of evolutionary algorithm that uses mutation and selection to evolve a population of solutions. Unlike genetic algorithms, evolution strategies do not use crossover.

4. **Reinforcement Learning**: A type of machine learning that focuses on training agents to make a sequence of decisions in an environment to maximize a reward. The agent learns by interacting with the environment and receiving feedback in the form of rewards or punishments.

5. **Q-Learning**: A type of reinforcement learning algorithm that uses a Q-table to store the estimated values of state-action pairs. The agent uses this table to select actions that maximize the expected reward.

6. **SARSA**: Another type of reinforcement learning algorithm that is similar to Q-learning. The main difference is that SARSA uses the current action and the next state to update the Q-table, while Q-learning uses the maximum value of the next state.

7. **Temporal Difference Learning**: A class of reinforcement learning algorithms that use the difference between the current and expected future rewards to update the value function.

8. **Monte Carlo Methods**: A class of reinforcement learning algorithms that use sampling to estimate the value function. The agent generates episodes of experience and uses the average return from these episodes to update the value function.
