### SUPPORT VECTOR MACHINE

Support Vector Machine (SVM) is a supervised machine learning algorithm that can be used for classification, regression, and outlier detection. It performs optimal data transformations to determine boundaries between data points based on predefined classes, labels, or outputs .

Some advantages of using SVMs include their effectiveness in high dimensional spaces and their ability to still be effective in cases where the number of dimensions is greater than the number of samples .

SVMs are also known as support vector networks and are associated with learning algorithms that analyze data for classification and regression analysis .

SVMs can be used for two-group classification problems. After giving an SVM model sets of labeled training data for each category, they are able to categorize new text .
