### Issues in SVM

Support Vector Machines (SVM) is a popular machine learning algorithm used for classification and regression problems. However, like any other algorithm, it has its own set of limitations and issues. Some of the issues in SVM are:

1. **Not suitable for large datasets**: SVM algorithm is not suitable for large data sets . This is because the training time for SVM increases exponentially with the size of the dataset.

2. **Poor performance with noisy data**: SVM does not perform very well when the data set has more noise i.e. target classes are overlapping . This is because it becomes difficult to draw a clear hyperplane without misclassifying the data points.

3. **Poor performance with imbalanced datasets**: SVMs perform poorly in imbalanced datasets. This is because the soft margin optimization problem becomes skewed towards the minority class when imbalanced data is used for training.

4. **Limitations with high dimensional data**: In cases where the number of features for each data point exceeds the number of training data samples, the SVM will underperform.

These are some of the issues that one may encounter while using SVM for regression problems in the subject of Machine Learning Techniques. It is important to keep these limitations in mind while choosing the right algorithm for a given problem.
