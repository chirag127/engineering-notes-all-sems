### Unit 1 - INTRODUCTION

Machine Learning Techniques is a subject that focuses on the study and development of algorithms that can learn from and make predictions on data. Here are some key points to note for Unit 1 - INTRODUCTION:

1. Machine learning is a subset of artificial intelligence that involves the use of algorithms to learn from data and make predictions or decisions.
2. The goal of machine learning is to enable computers to learn from data and improve their performance over time without being explicitly programmed.
3. Machine learning algorithms can be supervised, unsupervised, or semi-supervised.
4. Supervised learning involves using labeled data to train a model to make predictions or decisions.
5. Unsupervised learning involves using unlabeled data to find patterns or relationships in the data.
6. Semi-supervised learning involves using a combination of labeled and unlabeled data to train a model.
7. Some common applications of machine learning include image recognition, natural language processing, and predictive modeling.
8. Machine learning techniques can be used in a variety of fields, including healthcare, finance, and marketing.
