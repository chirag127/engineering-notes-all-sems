### Bayesian Networks

Bayesian networks are graphical models that represent the probabilistic relationships between variables in a system. They are used in a variety of applications, including machine learning, to model complex systems and make predictions.

Here are some key points to remember about Bayesian networks:

1. Bayesian networks are directed acyclic graphs (DAGs) where nodes represent variables and edges represent the probabilistic dependencies between them.
2. Each node in a Bayesian network has a conditional probability table (CPT) that specifies the probability of the node taking on a particular value given the values of its parents in the graph.
3. Bayesian networks can be used for both supervised and unsupervised learning.
4. In supervised learning, the network is trained on a labeled dataset to learn the relationships between the variables.
5. In unsupervised learning, the network is used to discover the underlying structure of the data by finding the most probable configuration of the variables.
6. Bayesian networks can handle missing data and can be used for both classification and regression tasks.
7. Bayesian networks can be used for both causal and diagnostic reasoning.
