### Artificial Neural Network

- An Artificial Neural Network (ANN) is a computational model that is inspired by the structure and functional aspects of biological neural networks.
- It is composed of a large number of highly interconnected processing elements (neurons) working in unison to solve specific problems.
- ANNs, like people, learn by example. An ANN is configured for a specific application, such as pattern recognition or data classification, through a learning process.
- Learning in biological systems involves adjustments to the synaptic connections that exist between the neurons. This is true of ANNs as well.
- ANNs have been used to solve a wide variety of tasks that are hard to solve using ordinary rule-based programming, including computer vision and speech recognition.
