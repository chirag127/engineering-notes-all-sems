### Learning Task for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Reinforcement Learning is a type of Machine Learning that focuses on training models through reward-based systems.
2. The goal of Reinforcement Learning is to develop a system that can learn to make decisions based on the feedback it receives from its environment.
3. The system learns by interacting with its environment and receiving rewards or punishments for its actions.
4. The system's goal is to maximize the cumulative reward it receives over time.
5. Reinforcement Learning is used in various applications such as game playing, robotics, and resource management.
6. There are two main approaches to Reinforcement Learning: model-based and model-free.
7. Model-based Reinforcement Learning involves creating a model of the environment and using it to make decisions.
8. Model-free Reinforcement Learning involves learning directly from the environment without creating a model.
9. Some common algorithms used in Reinforcement Learning include Q-Learning, SARSA, and Deep Q-Networks.
10. Reinforcement Learning is an active area of research and new techniques and algorithms are being developed to improve its performance.
