# Unit 5 - Reinforcement Learning
## Genetic Algorithms

- Genetic Algorithms are algorithms that are based on the evolutionary idea of natural selection and genetics.
- GAs are adaptive heuristic search algorithms i.e. the algorithms follow an iterative pattern that changes with time.
- It is a type of reinforcement learning where the feedback is necessary without telling the correct path to follow.
- Genetic algorithms can be applied to reinforcement learning, a fast-developing branch of machine learning that is capable of tackling complex tasks.
- Genetic algorithms are used to solve optimization problems in machine learning.
