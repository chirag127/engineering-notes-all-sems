### Properties of SVM for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. SVM is a supervised learning algorithm used for classification and regression analysis.
2. SVM constructs a hyperplane or set of hyperplanes in a high-dimensional space, which can be used for classification, regression, or other tasks.
3. The goal of SVM is to find the optimal hyperplane that separates the data into different classes.
4. SVM uses a technique called kernel trick to transform the data into a higher dimensional space, where it is easier to find the optimal hyperplane.
5. SVM is effective in high dimensional spaces and is memory efficient.
6. SVM is versatile and can be used with different kernel functions to solve different types of problems.
7. SVM is sensitive to the choice of kernel parameters and the choice of the regularization parameter C.
8. SVM can be used for both linear and non-linear classification.
9. SVM can handle large feature spaces and is relatively robust against overfitting.
10. SVM can be used for multi-class classification by using techniques such as one-vs-all or one-vs-one.
