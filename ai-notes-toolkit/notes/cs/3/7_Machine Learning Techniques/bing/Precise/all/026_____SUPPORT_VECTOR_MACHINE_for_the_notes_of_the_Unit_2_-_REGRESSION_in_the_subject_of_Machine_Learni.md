# SUPPORT VECTOR MACHINE

Support Vector Machine (SVM) is a supervised machine learning algorithm used for classification and regression analysis. It is commonly used in the field of Machine Learning Techniques, specifically in the unit of Regression.

Here are some key points to note about SVM:

1. SVM is a binary classifier, meaning it can only classify data into two classes.
2. SVM works by finding the hyperplane that best separates the data into two classes.
3. The hyperplane is chosen in such a way that it maximizes the margin between the two classes.
4. The margin is defined as the distance between the hyperplane and the closest data points from each class. These closest points are called support vectors.
5. SVM can also be used for multi-class classification by using techniques such as one-vs-all or one-vs-one.
6. SVM can also be used for regression by introducing an error term in the optimization problem.
7. SVM can handle non-linearly separable data by using kernel functions to map the data into a higher dimensional space where it can be linearly separated.

SVM is a powerful algorithm that can be used for a variety of tasks in the field of Machine Learning Techniques. It is important to understand the underlying concepts and principles in order to effectively apply it to real-world problems.
