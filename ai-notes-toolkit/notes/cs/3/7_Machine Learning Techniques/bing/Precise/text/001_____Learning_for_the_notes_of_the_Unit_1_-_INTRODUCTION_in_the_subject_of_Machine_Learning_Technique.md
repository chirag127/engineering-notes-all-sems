### Unit 1 - INTRODUCTION

Machine Learning Techniques is a subject that focuses on the study of algorithms and statistical models that computer systems use to perform a specific task without using explicit instructions, relying on patterns and inference instead.

1. Machine Learning is a subset of Artificial Intelligence that involves the use of algorithms to learn from data and make predictions or decisions without being explicitly programmed to do so.
2. Machine Learning algorithms can be supervised, unsupervised, or semi-supervised.
3. Supervised learning involves using labeled data to train a model to make predictions or decisions.
4. Unsupervised learning involves using unlabeled data to find patterns or relationships in the data.
5. Semi-supervised learning involves using a combination of labeled and unlabeled data to train a model.
6. Common applications of Machine Learning include image and speech recognition, natural language processing, and predictive analytics.
7. Machine Learning techniques can be used to improve the accuracy and efficiency of various tasks, including classification, regression, clustering, and anomaly detection.
