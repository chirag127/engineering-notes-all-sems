### Issues in SVM for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. **Choice of kernel:** The choice of kernel function can have a significant impact on the performance of the SVM. Different kernels are suited to different types of data and problems, and selecting the appropriate kernel can be challenging.

2. **Parameter selection:** The performance of an SVM is also sensitive to the values of its parameters, such as the regularization parameter C and the kernel parameters. Selecting the appropriate values for these parameters can be difficult and time-consuming.

3. **Scaling of data:** SVMs are sensitive to the scaling of the data, and it is important to scale the data appropriately before training the model. This can be challenging, especially when dealing with high-dimensional data.

4. **Outliers:** SVMs can be sensitive to outliers, which can affect the position of the decision boundary. This can be addressed by using robust SVM methods, but these methods can be computationally expensive.

5. **Computationally intensive:** Training an SVM can be computationally intensive, especially for large datasets. This can make it challenging to use SVMs for large-scale problems.

6. **Interpretability:** The decision boundary produced by an SVM can be difficult to interpret, especially when using non-linear kernels. This can make it challenging to understand how the model is making its predictions.
