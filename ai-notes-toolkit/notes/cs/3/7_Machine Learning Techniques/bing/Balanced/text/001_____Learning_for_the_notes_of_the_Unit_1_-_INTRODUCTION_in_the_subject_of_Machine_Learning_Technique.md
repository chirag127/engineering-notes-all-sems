### Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

- Machine learning is the study of algorithms and models that can learn from data and perform tasks such as prediction, classification, clustering, etc. without being explicitly programmed .
- Machine learning can be divided into three main types: supervised learning, unsupervised learning, and reinforcement learning  .
  - Supervised learning is the task of learning a function that maps an input to an output based on example input-output pairs. It requires labeled data, i.e., data with known outputs. Examples of supervised learning are regression, classification, and neural networks  .
  - Unsupervised learning is the task of finding patterns or structure in unlabeled data, i.e., data without known outputs. Examples of unsupervised learning are clustering, dimensionality reduction, and generative models  .
  - Reinforcement learning is the task of learning how to act in an environment to maximize a reward. It does not require labeled data, but rather learns from its own actions and feedback. Examples of reinforcement learning are control, game playing, and robotics  .
- Machine learning involves four main components: data, model, algorithm, and evaluation  .
  - Data is the raw information that is used to train and test the machine learning model. Data can be numerical, categorical, textual, image, audio, video, etc. Data can be preprocessed to remove noise, outliers, missing values, etc. and to extract features, i.e., relevant attributes of the data  .
  - Model is the mathematical representation of the machine learning problem. It can be a function, a set of rules, a probability distribution, a graph, a neural network, etc. A model has parameters, i.e., variables that can be adjusted to fit the data, and hyperparameters, i.e., variables that control the behavior of the model  .
  - Algorithm is the procedure that is used to train the model, i.e., to find the optimal values of the parameters that minimize a loss function, i.e., a measure of the error between the model output and the true output. Algorithms can be iterative, i.e., updating the parameters in small steps, or analytical, i.e., finding the parameters in a closed-form solution. Examples of algorithms are gradient descent, Newton's method, k-means, expectation-maximization, etc  .
  - Evaluation is the process of measuring the performance of the model on unseen data, i.e., data that is not used for training. Evaluation can be done using metrics, i.e., numerical values that quantify the accuracy, precision, recall, f1-score, etc. of the model, or using visualizations, i.e., plots, graphs, charts, etc. that show the results of the model  .
- Machine learning has many applications in various domains, such as computer vision, natural language processing, speech recognition, recommender systems, bioinformatics, etc   . Machine learning can also be used for research, innovation, and discovery in science, engineering, and humanities   .
