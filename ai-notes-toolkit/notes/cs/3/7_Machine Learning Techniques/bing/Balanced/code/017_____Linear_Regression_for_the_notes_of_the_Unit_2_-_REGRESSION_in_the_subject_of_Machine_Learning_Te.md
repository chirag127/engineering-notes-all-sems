### Linear Regression for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

- Linear regression is a supervised machine learning algorithm that predicts a numeric target based on one or more independent variables .
- Linear regression tries to find the best-fitting straight line that minimizes the sum of squared errors between the predicted and actual values .
- Linear regression can be divided into two types: simple linear regression and multiple linear regression.
  - Simple linear regression uses only one independent variable to predict the target.
  - Multiple linear regression uses two or more independent variables to predict the target.
- Linear regression can be learned using different methods, such as ordinary least squares, gradient descent, or regularized methods .
  - Ordinary least squares is a statistical method that finds the optimal values of the coefficients by solving a system of linear equations.
  - Gradient descent is an iterative optimization method that updates the coefficients by moving in the opposite direction of the gradient of the error function .
  - Regularized methods are extensions of ordinary least squares that add a penalty term to the error function to reduce overfitting and improve generalization.
- Linear regression is one of the most fundamental and widely used machine learning algorithms because of its simplicity, interpretability, and applicability to many domains  .
