## Unit 2 - REGRESSION

Regression is a statistical method that allows us to examine the relationship between one or more explanatory variables (also called independent variables or predictors) and a response variable (also called dependent variable or outcome). Regression can be used to describe how the response variable changes as the explanatory variables vary, and to make predictions or estimates of the response variable for new values of the explanatory variables.

There are different types of regression models, depending on the nature and number of the explanatory and response variables, and the assumptions that are made about the relationship between them. Some of the most common types of regression models are:

- **Linear regression**: This is the simplest and most widely used type of regression model. It assumes that the response variable is a linear function of one or more explanatory variables, plus some random error. The linear function can be written as:

  `y = b0 + b1x1 + b2x2 + ... + bnxn + e`

  where `y` is the response variable, `x1, x2, ..., xn` are the explanatory variables, `b0, b1, b2, ..., bn` are the coefficients that measure the effect of each explanatory variable on the response variable, and `e` is the error term that captures the variability in the response variable that is not explained by the explanatory variables.

  Linear regression can be further classified into simple linear regression (when there is only one explanatory variable) and multiple linear regression (when there are two or more explanatory variables).

- **Logistic regression**: This is a type of regression model that is used when the response variable is binary, meaning that it can only take two possible values, such as 0 or 1, yes or no, success or failure, etc. Logistic regression assumes that the probability of the response variable being 1 is a logistic function of one or more explanatory variables, plus some random error. The logistic function can be written as:

  `p = 1 / (1 + exp(-z))`

  where `p` is the probability of the response variable being 1, `z = b0 + b1x1 + b2x2 + ... + bnxn + e` is the linear predictor, and `exp` is the exponential function.

  Logistic regression can be used to model the odds or the odds ratio of the response variable being 1, and to make predictions or estimates of the probability of the response variable for new values of the explanatory variables.

- **Polynomial regression**: This is a type of regression model that is used when the relationship between the response variable and the explanatory variables is not linear, but can be approximated by a polynomial function of one or more explanatory variables, plus some random error. The polynomial function can be written as:

  `y = b0 + b1x1 + b2x1^2 + b3x1^3 + ... + bnx1^n + e`

  where `y` is the response variable, `x1` is the explanatory variable, `b0, b1, b2, ..., bn` are the coefficients that measure the effect of each term of the polynomial function on the response variable, and `e` is the error term.

  Polynomial regression can be used to model nonlinear relationships, such as quadratic, cubic, or higher-order curves, and to make predictions or estimates of the response variable for new values of the explanatory variables.

- **Multiple regression**: This is a general term that refers to any type of regression model that involves two or more explanatory variables and one response variable. Multiple regression can be linear, logistic, polynomial, or any other type of regression model, depending on the nature and number of the explanatory and response variables, and the assumptions that are made about the relationship between them.

  Multiple regression can be used to examine the combined effect of multiple explanatory variables on the response variable, and to control for confounding or mediating factors that may affect the relationship between the variables of interest.
