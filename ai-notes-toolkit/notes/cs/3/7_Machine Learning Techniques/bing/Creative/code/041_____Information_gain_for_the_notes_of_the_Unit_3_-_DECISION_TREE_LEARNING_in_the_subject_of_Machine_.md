### Information gain for the notes of the Unit 3 - DECISION TREE LEARNING in the subject of Machine Learning Techniques

- Information gain is a measure of how much information a feature provides about the class label of a dataset .
- Information gain is based on the concept of entropy, which is the degree of disorder or uncertainty in a system .
- Entropy can be calculated as the negative sum of the probabilities of each class multiplied by the logarithm of those probabilities .
- Information gain can be calculated as the difference between the entropy of the parent node and the weighted average of the entropies of the child nodes after splitting on a feature .
- Information gain can be used as a split criterion in decision tree learning, where the feature that maximizes the information gain is chosen as the best split at each node .
- Information gain can help to reduce the complexity and improve the accuracy of decision trees by selecting the most relevant and informative features .
- Information gain can also be interpreted as the mutual information between a feature and the class label, which is the amount of information that one variable reveals about another .
- Information gain can be generalized to multivariate cases, where the mutual information between a set of features and the class label can be computed .
- Information gain can be affected by the number of possible values of a feature, where features with more values tend to have higher information gain than features with fewer values .
- Information gain can be normalized by dividing it by the entropy of the feature, which gives a measure of the intrinsic information of the feature .
- Information gain can be compared with other split criteria, such as the Gini index or the chi-square test, which have different advantages and disadvantages .
