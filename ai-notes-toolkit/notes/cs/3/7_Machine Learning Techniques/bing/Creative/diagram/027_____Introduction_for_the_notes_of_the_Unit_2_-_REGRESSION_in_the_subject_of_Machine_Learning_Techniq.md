### Introduction for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

- Regression is a type of supervised learning technique that aims to predict a continuous output variable (y) based on one or more input variables (x).
- Regression can be used for various purposes, such as estimating the relationship between variables, testing hypotheses, forecasting future values, and evaluating the effect of interventions.
- There are different types of regression models, depending on the nature and number of input variables, the shape and form of the output variable, and the assumptions and constraints of the model.
- Some of the common types of regression models are:
  - Linear regression: assumes a linear relationship between the input and output variables, and minimizes the sum of squared errors between the predicted and actual values.
  - Polynomial regression: extends linear regression by adding higher-order terms of the input variables, and can capture nonlinear relationships between the input and output variables.
  - Logistic regression: predicts a binary output variable (0 or 1) based on one or more input variables, and uses a logistic function to model the probability of the output variable.
  - Multiple regression: involves more than one input variable, and can be linear or nonlinear depending on the model.
  - Ridge regression: adds a regularization term to the linear regression model, and penalizes large coefficients to reduce overfitting and multicollinearity.
  - Lasso regression: another type of regularization technique that uses the absolute value of the coefficients instead of the squared value, and can perform feature selection by shrinking some coefficients to zero.
  - Support vector regression: uses the concept of support vectors and kernels to fit a nonlinear function that minimizes the error within a specified margin.
  - Decision tree regression: uses a tree-like structure to split the input space into regions, and assigns a constant value to each region based on the average output value of the training data in that region.
  - Random forest regression: an ensemble method that combines multiple decision tree regressors, and averages their predictions to reduce the variance and improve the accuracy of the model.
  - Neural network regression: uses a network of artificial neurons to learn a nonlinear function that maps the input variables to the output variable, and can approximate any continuous function given enough hidden layers and neurons.
