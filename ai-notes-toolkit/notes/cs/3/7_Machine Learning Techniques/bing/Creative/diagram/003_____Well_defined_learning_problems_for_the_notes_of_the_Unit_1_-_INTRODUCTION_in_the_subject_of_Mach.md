### Well defined learning problems

- A well defined learning problem is a problem that can be solved by a machine learning system using data or experience.
- A learning problem is well posed if it satisfies three conditions :
  - A solution to the problem exists and is unique.
  - The solution depends on the data or experience, but is not sensitive to small changes in them.
  - The solution can be measured by some performance metric that improves with more data or experience.
- Examples of well defined learning problems are :
  - Learning to recognize spoken words from audio signals.
  - Learning to classify images into categories based on their features.
  - Learning to predict the price of a house based on its attributes.
- To design a learning system for a well defined learning problem, we need to specify three components :
  - The task T that the system needs to perform, such as recognition, classification, prediction, etc.
  - The experience E that the system can use to learn, such as data, feedback, examples, etc.
  - The performance measure P that the system can use to evaluate its progress, such as accuracy, error, precision, recall, etc.
- A well defined learning problem can be solved by different types of machine learning methods, such as supervised, unsupervised, semi-supervised, reinforcement, etc.
- A well defined learning problem can also be categorized by the complexity, dimensionality, and structure of the data or experience, such as linear, nonlinear, parametric, nonparametric, etc.
