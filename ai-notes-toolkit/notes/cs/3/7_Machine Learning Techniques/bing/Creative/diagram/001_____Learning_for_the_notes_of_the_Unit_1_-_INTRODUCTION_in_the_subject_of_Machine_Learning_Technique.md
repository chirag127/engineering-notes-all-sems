# Unit 1 - INTRODUCTION

## What is Machine Learning?

- Machine learning is an AI technique that teaches computers to learn from experience.
- Machine learning algorithms use computational methods to “learn” information directly from data without relying on a predetermined equation as a model.
- The algorithms adaptively improve their performance as the number of samples available for learning increases.
- Machine learning techniques are used to automatically find the valuable underlying patterns within complex data that we would otherwise struggle to discover.
- The hidden patterns and knowledge about a problem can be used to predict future events and perform all kinds of complex decision making.

## Types of Machine Learning

- Machine learning uses two types of techniques: supervised learning and unsupervised learning.
- Supervised learning trains a model on known input and output data so that it can predict future outputs.
- Unsupervised learning finds hidden patterns or intrinsic structures in input data.
- There are also other types of machine learning techniques, such as semi-supervised learning, reinforcement learning, and deep learning, which will be discussed in later units.

## Applications of Machine Learning

- Machine learning has a wide range of applications in various domains, such as natural language processing, computer vision, speech recognition, robotics, healthcare, finance, education, and more .
- Some examples of machine learning applications are:
  - Spam filtering, sentiment analysis, and machine translation in natural language processing.
  - Face detection, object recognition, and image segmentation in computer vision.
  - Speech recognition, speaker identification, and speech synthesis in speech processing.
  - Self-driving cars, robot navigation, and robot manipulation in robotics.
  - Disease diagnosis, drug discovery, and medical imaging analysis in healthcare.
  - Fraud detection, credit scoring, and stock market prediction in finance.
  - Personalized learning, adaptive testing, and student modeling in education.
  - And many more!
