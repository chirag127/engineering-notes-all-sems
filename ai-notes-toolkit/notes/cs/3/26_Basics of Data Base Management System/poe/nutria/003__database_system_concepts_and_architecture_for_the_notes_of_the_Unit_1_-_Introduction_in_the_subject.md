
### Database System Concepts and Architecture
1. Database: A database is a collection of related data, stored and accessed electronically from a computer system. It is usually organized in a way that allows data to be easily accessed, managed and updated. 
2. Database Management System (DBMS): A DBMS is a software system designed to manage databases. It provides users with a way to store and retrieve data from the database. 
3. Data Model: A data model is a conceptual representation of the data in a database. It describes how the data is structured and how it is related to each other. 
4. Database Architecture: Database architecture is the design and structure of a database system. It includes the physical components of the system, such as the hardware and software, as well as the logical components, such as the data model and the database management system. 
5. Database Administration: Database administration is the process of managing a database system. It includes tasks such as designing the database, creating and modifying tables, and ensuring the security of the data. 
6. Data Manipulation Language (DML): DML is a language used to manipulate data in a database. It includes commands such as SELECT, INSERT, UPDATE and DELETE. 
7. Data Definition Language (DDL): DDL is a language used to define the structure of a database. It includes commands such as CREATE, ALTER and DROP. 
8. Query Language: A query language is a language used to retrieve data from a database. It includes commands such as SELECT and JOIN. 
9. Transaction Processing: Transaction processing is the process of executing a series of database operations as a single unit. It ensures that the data remains consistent and secure. 
10. Database Security: Database security is the process of protecting the data in a database from unauthorized access. It includes measures such as authentication, authorization and encryption.
