

## Unit 4 - Data Base Design & Normalization

1. Database design is the process of designing a database that is able to store and manage data efficiently.
2. A database should be designed to meet the business requirements of the organization.
3. Database normalization is the process of organizing the data in a database to reduce data redundancy and improve data integrity.
4. Normalization involves breaking down large tables into smaller tables and linking them using relationships.
5. Normalization also involves eliminating redundant data from the database and ensuring that data is stored in the most efficient way.
6. Normalization is an important part of database design as it helps to ensure data integrity and reduce data redundancy.
