
### DCL for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System

* Data Control Language (DCL) is a subset of Structured Query Language (SQL) used to control access to data stored in a database. 
* DCL includes commands like GRANT and REVOKE which are used to give users access to the database and its objects, and to manage their privileges. 
* DCL also includes commands like CREATE USER and DROP USER which are used to create and delete user accounts. 
* DCL commands are usually issued by the database administrator or other authorized personnel. 
* It is important to note that DCL commands are not used to manipulate data; instead, they are used to manage the access rights of users.
