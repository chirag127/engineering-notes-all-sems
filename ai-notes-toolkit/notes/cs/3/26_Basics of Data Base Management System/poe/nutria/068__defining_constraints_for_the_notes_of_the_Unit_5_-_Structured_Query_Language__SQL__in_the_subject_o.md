
### Defining Constraints in SQL
1. A constraint is a rule that restricts the data that can be stored in a table. 
2. It is used to ensure the accuracy and integrity of the data in the database.
3. Constraints can be defined at the column level or table level. 
4. There are four types of constraints in SQL:
    * **Primary Key**: A primary key is a column or combination of columns that uniquely identifies each row in a table.
    * **Foreign Key**: A foreign key is a column or combination of columns that references a primary key in another table.
    * **Unique Key**: A unique key is a column or combination of columns that must be unique for each row in a table.
    * **Check Constraint**: A check constraint is a condition that must be met for each row in a table.
