
### Features of Unit 6 - PL/SQL in Basics of Data Base Management System 

- PL/SQL is a procedural language that is used to execute database operations and transactions.
- It is a combination of SQL and procedural programming language, which provides a powerful tool for database manipulation and querying.
- PL/SQL enables developers to write stored procedures, functions, packages, triggers, types, and more.
- PL/SQL code is compiled into bytecode and stored in the database, making it more secure and efficient than other languages.
- PL/SQL provides strong exception handling capabilities and allows for the use of variables, constants, and user-defined types.
- PL/SQL can be used to create user-defined functions, stored procedures, and triggers to automate database operations.
- PL/SQL can be used to create database objects such as tables, views, and indexes.
- PL/SQL can be used to write queries that are more efficient and easier to maintain.
- PL/SQL can be used to create web services and integrate with other applications.
