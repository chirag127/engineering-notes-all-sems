

### Functional Dependencies for the Notes of Unit 4 - Data Base Design & Normalization

1. Functional dependencies are relationships between attributes in a relation.
2. A functional dependency is a constraint between two sets of attributes in a relation.
3. A functional dependency states that the value of one attribute determines the value of another attribute.
4. Functional dependencies can be used to identify the minimal set of attributes needed to uniquely identify a tuple in a relation.
5. Functional dependencies can also be used to identify the normal forms of a relation.
6. The first normal form (1NF) states that all attributes must be atomic, i.e. each attribute must contain only one value.
7. The second normal form (2NF) states that all non-key attributes must depend on the whole of the primary key.
8. The third normal form (3NF) states that all non-key attributes must depend only on the primary key.
9. The Boyce-Codd normal form (BCNF) states that all determinants must be candidate keys.
10. The fourth normal form (4NF) states that all multi-valued dependencies must be eliminated.
