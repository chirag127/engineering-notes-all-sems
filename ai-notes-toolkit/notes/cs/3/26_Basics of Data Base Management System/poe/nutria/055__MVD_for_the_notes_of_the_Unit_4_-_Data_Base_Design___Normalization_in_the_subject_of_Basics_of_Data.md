
### MVD for the Notes of Unit 4 - Data Base Design & Normalization

1. A Multi-valued Dependency (MVD) is a type of functional dependency in which one attribute is functionally dependent on a set of two or more attributes. 
2. MVDs are used to ensure data integrity and consistency in a database.
3. An MVD is defined as A →→ B, where A is the determinant and B is the dependent. 
4. The determinant is the set of attributes that determine the value of the dependent attribute. 
5. The dependent is the attribute whose value is determined by the determinant.
6. An MVD is a type of functional dependency in which the dependent attribute is functionally dependent on a set of two or more attributes. 
7. MVDs are used to ensure data integrity and consistency in a database. 
8. The MVD is an important concept in database design and normalization.
9. It is used to identify and eliminate redundant data from a database.
10. It is also used to ensure that the data is organized in a consistent and logical manner.
