
### Queries and Sub-Queries in Structured Query Language (SQL)

1. Queries are used to extract data from a database. They are written using the Structured Query Language (SQL).

2. Sub-queries are used to combine multiple queries into one. They are written using the same syntax as regular queries.

3. A query can be used to retrieve data from a single table or multiple tables.

4. A sub-query can be used to retrieve data from multiple tables and combine the results into a single result set.

5. A query can be used to filter data based on certain criteria.

6. A sub-query can be used to filter data based on multiple criteria.

7. A query can be used to sort data in ascending or descending order.

8. A sub-query can be used to sort data in multiple ways.

9. A query can be used to aggregate data from multiple tables.

10. A sub-query can be used to aggregate data from multiple tables and combine the results into a single result set.
