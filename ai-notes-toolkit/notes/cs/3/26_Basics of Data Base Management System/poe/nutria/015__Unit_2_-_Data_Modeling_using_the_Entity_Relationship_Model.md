
## Unit 2 - Data Modeling using the Entity Relationship Model

1. The Entity Relationship Model (ERM) is a powerful tool used to design and visualize data models.
2. It is a graphical representation of entities, relationships, and attributes that can be used to represent data in a database.
3. An entity is an object, person, place, or concept about which data can be stored.
4. Relationships are the links between entities and describe how they are related to one another.
5. Attributes are the characteristics of an entity that can be used to describe it.
6. ERMs are used to design databases by mapping out the entities and relationships between them.
7. ERMs can also be used to generate SQL statements to create the database.
8. ERMs are also used to analyze data and identify patterns and trends.
