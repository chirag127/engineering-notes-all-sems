
### Basic Operations – Selection and Projection

* Selection is the process of retrieving rows from a relation based on a condition. The condition is specified in the **WHERE** clause of the SELECT statement.
* Projection is the process of retrieving columns from a relation. The columns to be retrieved are specified in the **SELECT** clause of the SELECT statement.
* The **SELECT** clause is used to specify which columns to retrieve from the relation.
* The **WHERE** clause is used to specify which rows to retrieve from the relation.
* The **ORDER BY** clause is used to specify the order in which the rows are retrieved from the relation.
* The **GROUP BY** clause is used to group rows from the relation based on the values of one or more columns.
* The **HAVING** clause is used to specify conditions on the groups created by the GROUP BY clause.
* The **DISTINCT** keyword is used to retrieve only unique rows from the relation.
