
### Joins for the Notes of the Unit 5 - Structured Query Language (SQL) in the Basics of Data Base Management System

* A join is a query that combines rows from two or more tables, views, or materialized views. 
* The most common type of join is an inner join, which returns all rows in the joined tables that match the specified criteria.
* An outer join returns all rows from one table, plus any rows from the other table that match the specified criteria.
* SQL joins can also be used to combine data from multiple tables into a single result set.
* Joins can be used to perform calculations, such as finding the sum of two columns in different tables.
* Joins can also be used to perform calculations on multiple tables, such as finding the average of two columns in different tables.
* Joins can be used to filter data, such as selecting only rows from one table that match criteria in another table.
* Joins can also be used to perform operations on multiple tables, such as updating values in one table based on values in another table.
