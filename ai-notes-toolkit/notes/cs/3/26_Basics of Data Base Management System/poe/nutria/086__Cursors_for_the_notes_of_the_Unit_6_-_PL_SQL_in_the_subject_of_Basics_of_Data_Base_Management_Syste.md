
### Cursors for the Notes of Unit 6 - PL/SQL in the Subject of Basics of Database Management System

1. A cursor is a pointer to a private SQL area that stores information about a specific query.
2. Cursors are used to process individual rows returned by a query.
3. The cursor is used to traverse through the set of rows one row at a time.
4. PL/SQL cursors are used to process the result set of a query.
5. Cursors allow the user to control the context area, which contains information about the query and the processing of the result set.
6. Cursors can be either implicit or explicit.
7. Implicit cursors are automatically created and managed by the Oracle server.
8. Explicit cursors are created and managed by the user.
9. Cursors can be used to update, delete, and insert records.
10. Cursors can also be used to retrieve data from multiple tables.
