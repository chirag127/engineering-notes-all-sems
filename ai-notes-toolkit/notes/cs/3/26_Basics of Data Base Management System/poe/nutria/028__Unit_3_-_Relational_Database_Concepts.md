
## Unit 3 - Relational Database Concepts

1. Relational databases are a type of database that stores data in tables related to one another. 
2. Tables are made up of columns and rows, where each row contains one record, and each column contains a field. 
3. The columns are used to define the data type and structure of the data, while the rows contain the actual data. 
4. Relationships between tables are established using foreign keys, which are columns that reference the primary key of another table. 
5. Data integrity is maintained by enforcing constraints on the data, such as primary key constraints, foreign key constraints, and check constraints. 
6. SQL (Structured Query Language) is the language used to interact with relational databases. 
7. Common operations in SQL include creating tables, inserting data, updating data, deleting data, and querying data. 
8. The ACID (Atomicity, Consistency, Isolation, Durability) properties are used to ensure that data is stored and retrieved reliably.
