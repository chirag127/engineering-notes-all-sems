

### Tuples for the Notes of the Unit 3 - Relational Database Concepts in the Subject of Basics of Data Base Management System

1. A **tuple** is a collection of related data items that share a common name.
2. Each item in a tuple is called an **attribute**.
3. A **relation** is a set of tuples that have the same attributes.
4. A **primary key** is an attribute or combination of attributes that uniquely identifies each tuple in a relation.
5. A **foreign key** is an attribute or combination of attributes that is used to refer to a primary key in another relation.
6. A **referential integrity constraint** ensures that a foreign key always refers to an existing tuple in the related relation.
7. A **join** is a query that combines the data from two or more relations.
8. A **view** is a virtual relation that is derived from one or more relations. 
9. A **data integrity constraint** is a rule that is used to ensure the accuracy and consistency of data in a relation.
