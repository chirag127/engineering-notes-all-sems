
### Candidate Key

- A candidate key is a set of one or more attributes that can uniquely identify a tuple (row) in a relation (table).
- A candidate key must contain a minimum number of attributes to be able to uniquely identify a tuple.
- The Entity Relationship Model (ERM) is a data modeling technique used to represent the structure of a database.
- It is used to identify the relationships between entities and to define the structure of data within a database.
- A candidate key is used to uniquely identify a tuple in the ERM.
- A candidate key must contain a minimum number of attributes to be able to uniquely identify a tuple.
- A candidate key must be a minimal set of attributes that can uniquely identify a tuple in the relation.
- A candidate key must contain unique values for all of its attributes.
- A candidate key must be a minimal set of attributes that can identify a tuple without any additional information.
- A candidate key must not contain any redundant or duplicate data.
