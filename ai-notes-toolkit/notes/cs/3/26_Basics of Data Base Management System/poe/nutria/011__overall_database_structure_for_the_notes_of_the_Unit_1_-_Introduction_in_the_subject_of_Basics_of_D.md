
### Overall Database Structure for the Notes of the Unit 1 - Introduction in the Subject of Basics of Data Base Management System

1. Database: A database is a collection of logically related data and a set of programs to access those data. 
2. Database Management System (DBMS): A DBMS is a software package that enables users to create, store, modify and access data in a database.
3. Database Structure: A database structure is the arrangement of data in a database. It defines the way data is organized and stored in the database.
4. Tables: A table is a collection of related data stored in a database. It is composed of columns and rows.
5. Fields: A field is a single piece of data in a table.
6. Primary Key: A primary key is a field that uniquely identifies a record in a table. 
7. Foreign Key: A foreign key is a field in a table that is used to reference a primary key in another table.
8. Indexes: An index is a data structure used to improve the speed of data retrieval from a database.
9. Views: A view is a virtual table that is created by a query. It is a subset of the data in a table.
10. Normalization: Normalization is the process of organizing data in a database to reduce data redundancy and improve data integrity.
