

### Integrity Constraints for the Notes of the Unit 3 - Relational Database Concepts in the Subject of Basics of Database Management System 

1. Entity Integrity Constraint: This constraint states that the primary key of a relation must not contain any null values. 

2. Referential Integrity Constraint: This constraint states that any foreign key value must match a primary key value in the related table.

3. Domain Integrity Constraint: This constraint states that all values in a column must be of the same data type and must fall within the specified range. 

4. User-Defined Integrity Constraint: This constraint is defined by the user and is based on business rules. It is used to enforce additional restrictions on the data.
