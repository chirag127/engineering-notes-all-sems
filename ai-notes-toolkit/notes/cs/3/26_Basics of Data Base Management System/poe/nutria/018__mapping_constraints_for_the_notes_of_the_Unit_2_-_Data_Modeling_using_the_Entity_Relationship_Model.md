
### Mapping Constraints for the Notes of the Unit 2 - Data Modeling using the Entity Relationship Model in the Subject of Basics of Data Base Management System

1. Entity-relationship (ER) modeling is a graphical approach to data modeling that is used to define the structure of a database.
2. ER modeling is used to represent the logical structure of a database, including entities, attributes, relationships, and constraints.
3. Entities are the objects or items that are stored in a database. An entity is represented by a rectangle in ER modeling.
4. Attributes are the properties of an entity that describe it. An attribute is represented by an oval in ER modeling.
5. Relationships are the connections between two or more entities. A relationship is represented by a diamond in ER modeling.
6. Constraints are the rules that must be followed when creating or modifying data in a database. Constraints are represented by lines connecting entities and attributes in ER modeling.
7. ER modeling can be used to identify entities, attributes, relationships, and constraints in a database. It can also be used to design a database from scratch or to modify an existing database.
