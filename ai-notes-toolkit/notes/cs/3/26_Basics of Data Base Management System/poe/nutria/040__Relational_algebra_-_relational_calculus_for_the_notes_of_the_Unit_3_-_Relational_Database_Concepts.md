
### Relational Algebra - Relational Calculus

* Relational Algebra is a procedural language used to query databases. It is based on the mathematical principles of set theory and consists of a set of operators that take one or more relations as input and produce a new relation as output.
* Relational calculus is a non-procedural language used to query databases. It is based on the mathematical principles of predicate calculus and consists of a set of predicates that describe the desired output relation.
* Relational algebra and relational calculus are used to manipulate and query relational databases.
* Relational algebra operators include selection, projection, union, intersection, difference, and join.
* Relational calculus predicates include selection, projection, equality, inequality, and membership.
* Relational algebra and relational calculus can be used together to solve complex queries.
* Both relational algebra and relational calculus can be used to optimize query execution by using techniques such as indexing and query optimization.
