
### DML in PL/SQL

1. Data Manipulation Language (DML) is a language used to query and manipulate data in a database. 
2. PL/SQL is a procedural language extension of SQL used to create and manage stored procedures, functions, and triggers in an Oracle database. 
3. DML statements in PL/SQL are used to query, insert, update, and delete data. 
4. The SELECT statement is used to query data from a database table. 
5. The INSERT statement is used to add new records to a database table. 
6. The UPDATE statement is used to modify existing records in a database table. 
7. The DELETE statement is used to delete records from a database table. 
8. PL/SQL also provides other DML statements such as MERGE, LOCK TABLE, and SAVEPOINT. 
9. PL/SQL also provides the ability to create, update, and delete records in bulk using the FORALL statement.
