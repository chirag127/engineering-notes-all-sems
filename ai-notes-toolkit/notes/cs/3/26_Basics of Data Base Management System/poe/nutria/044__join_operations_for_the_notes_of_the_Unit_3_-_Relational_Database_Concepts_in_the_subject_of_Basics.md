
### Join Operations

* A join operation is a way of combining data from two or more tables in a relational database.
* It is used to retrieve data from multiple tables based on a common field.
* There are four types of join operations: inner join, outer join, left join, and right join.
* An inner join combines two tables based on a common field and returns only the matching rows from both tables.
* An outer join combines two tables based on a common field and returns all rows, including those that do not match.
* A left join combines two tables based on a common field and returns all rows from the left table, even if there is no match in the right table.
* A right join combines two tables based on a common field and returns all rows from the right table, even if there is no match in the left table.
