
### Data Models for the Notes of the Unit 1 - Introduction in the Basics of Database Management System

* A **data model** is a collection of concepts and rules used to describe an organization's data and how it is used.
* The most commonly used data models are the **relational model** and the **object-oriented model**.
* The **relational model** is a mathematical model used to represent data in a structured way. It is based on the concept of a relation, which is a set of tuples with a specific set of attributes.
* The **object-oriented model** is a data model that uses objects to represent data. An object is a collection of attributes and methods that can be used to manipulate the data.
* Another data model that is commonly used is the **hierarchical model**. This model is based on the concept of a tree structure, where each node in the tree is a record containing data.
* The **network model** is another data model that is used to represent data in a network structure. It is based on the concept of a graph, where each node in the graph is a record containing data.
* The **entity-relationship model** is a data model that is used to represent the relationship between entities. An entity is a collection of attributes and relationships that can be used to describe a real-world object or concept.
* The **object-relational model** is a data model that combines the concepts of the object-oriented model and the relational model. It is used to represent data in a structured way that is both object-oriented and relational.
