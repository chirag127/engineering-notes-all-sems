

### Unit 5 - Structured Query Language (SQL) 

1. SQL (Structured Query Language) is a domain-specific language used in programming and designed for managing data held in a relational database management system (RDBMS). 
2. SQL statements are used to perform tasks such as updating data on a database, or retrieving data from a database. 
3. SQL commands can be used to create, modify, and delete database objects such as tables, views, and stored procedures. 
4. SQL also includes a data manipulation language (DML) which is used to insert, update, and delete data from a database. 
5. SQL also includes a data definition language (DDL) which is used to create, modify, and delete database objects. 
6. SQL also includes a data control language (DCL) which is used to control access to a database. 
7. SQL also includes a transaction control language (TCL) which is used to manage transactions. 
8. SQL also includes a data query language (DQL) which is used to query data from a database.
