
### Relational Database Structure

1. A relational database is a type of database that stores and provides access to data points that are related to one another.
2. The structure of a relational database consists of tables which contain columns and rows.
3. Each column represents a particular attribute of the data and each row represents a particular record.
4. The tables are related to each other through the use of keys.
5. The primary key is a column that uniquely identifies each row in a table.
6. Foreign keys are columns in one table that refer to the primary key of another table.
7. This allows for the creation of relationships between tables, which can be used to retrieve data from multiple tables.
8. Normalization is the process of organizing data into tables in such a way that reduces data redundancy and increases data integrity.
9. Normalization involves breaking down data into smaller tables and establishing relationships between them.
10. This helps to ensure that data is stored efficiently and that data integrity is maintained.
