
### Stored Functions for the Notes of Unit 6 - PL/SQL in Basics of Database Management System

1. Stored functions are user-defined functions that are stored in the database and can be used in SQL statements.
2. They can accept input parameters and return a single value.
3. Stored functions can be used to perform calculations, manipulate data, or call other functions.
4. They are created using the CREATE FUNCTION statement and can be modified using the ALTER FUNCTION statement.
5. Stored functions can be used in SELECT, INSERT, UPDATE, and DELETE statements.
6. They can be used in WHERE clauses, as well as in GROUP BY and ORDER BY clauses.
7. Stored functions can also be used in PL/SQL blocks.
8. Stored functions can be nested, meaning that one stored function can call another stored function.
9. Stored functions can be used to encapsulate business logic and reduce the amount of code that needs to be written.
10. Stored functions can improve the performance of database applications by reducing the amount of code that needs to be executed.
