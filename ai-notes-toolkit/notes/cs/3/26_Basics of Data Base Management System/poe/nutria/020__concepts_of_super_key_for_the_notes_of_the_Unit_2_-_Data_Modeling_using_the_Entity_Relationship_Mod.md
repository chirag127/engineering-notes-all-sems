
### Concepts of Super Key

1. A superkey is a set of attributes that uniquely identifies a record in a relation.
2. Superkeys are used in the Entity Relationship Model (ERM) to ensure data integrity and accuracy.
3. A superkey can be composed of one or more attributes, and can be a candidate key or a non-candidate key.
4. A candidate key is a set of attributes that uniquely identifies a record in a relation and is minimal, meaning it contains only the attributes necessary to uniquely identify the record.
5. A non-candidate key is a set of attributes that can uniquely identify a record in a relation, but is not minimal.
6. Superkeys are used to identify entities in a database, and to ensure data integrity and accuracy by preventing duplicate records from being entered into the database.
