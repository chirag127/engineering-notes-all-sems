### An overview of database management system for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

In this unit, we will introduce the basic concepts of database management system (DBMS). The following are the main points that will be covered:

1. Definition of DBMS: A DBMS is a software system that manages the storage, organization, and retrieval of data from a database.

2. Components of DBMS: A DBMS consists of several components, including the data definition language (DDL), data manipulation language (DML), query language, and storage manager.

3. Advantages of DBMS: DBMS provides numerous advantages, such as data consistency, data integrity, data security, efficient data access, and reduced data redundancy.

4. Types of DBMS: There are four main types of DBMS, including hierarchical, network, relational, and object-oriented DBMS.

5. Relational database model: The relational database model is the most widely used model for DBMS. It involves creating tables to represent entities and their relationships.

6. SQL: SQL is a standard language used for managing relational databases. It is used to create, modify, and query databases.

7. Database design: Database design is the process of creating a database schema, which is a blueprint of the database structure.

8. Database administration: Database administration involves tasks such as backup and recovery, performance tuning, security management, and user management.

9. Application development: DBMS provides a platform for application development by providing interfaces for connecting to the database and executing queries.

In conclusion, the introduction to DBMS is essential for understanding the basics of data management. The above points provide an overview of the key concepts that will be covered in this unit. It is important to understand these concepts to build a solid foundation for advanced topics in DBMS.
