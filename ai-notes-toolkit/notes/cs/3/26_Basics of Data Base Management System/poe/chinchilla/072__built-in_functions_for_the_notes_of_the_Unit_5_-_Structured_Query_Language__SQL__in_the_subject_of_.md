### Built-in Functions for the Notes of Unit 5 - Structured Query Language (SQL)

In SQL, built-in functions are used to perform various operations on data in a database. These functions can be used to manipulate data, perform calculations, and extract information from the database. Here are some of the most commonly used built-in functions in SQL:

1. COUNT(): This function is used to count the number of rows in a table. It can also be used to count the number of occurrences of a specific value in a column.

2. SUM(): This function is used to calculate the sum of values in a column.

3. AVG(): This function is used to calculate the average of values in a column.

4. MIN(): This function is used to find the minimum value in a column.

5. MAX(): This function is used to find the maximum value in a column.

6. UPPER(): This function is used to convert all characters in a string to uppercase.

7. LOWER(): This function is used to convert all characters in a string to lowercase.

8. SUBSTRING(): This function is used to extract a portion of a string.

9. DATE(): This function is used to convert a string or numeric value to a date.

10. NOW(): This function is used to get the current date and time.

11. TRIM(): This function is used to remove whitespace from the beginning and end of a string.

12. CONCAT(): This function is used to concatenate two or more strings together.

13. LENGTH(): This function is used to find the length of a string.

14. ROUND(): This function is used to round a numeric value to a specified number of decimal places.

15. CAST(): This function is used to convert a value of one data type to another data type.

By using these built-in functions, you can perform a variety of operations on data in a database, making it easier to manipulate and analyze large amounts of data. Understanding these functions is essential for anyone working with SQL and helps in creating efficient queries.
