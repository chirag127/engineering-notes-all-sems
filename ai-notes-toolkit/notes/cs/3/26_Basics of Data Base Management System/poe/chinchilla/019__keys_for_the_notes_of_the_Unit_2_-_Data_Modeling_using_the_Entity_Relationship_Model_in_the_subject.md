### Keys for the Notes of Unit 2 - Data Modeling using the Entity Relationship Model

1. The Entity Relationship Model (ERM) is a conceptual data model used to represent the relationships between different entities in a database system.
2. The ERM uses entities to represent real-world objects or concepts and relationships to represent the associations between those entities.
3. There are three types of relationships in the ERM: one-to-one, one-to-many, and many-to-many.
4. In the ERM, entities are represented by rectangles, and relationships are represented by diamonds.
5. Each entity in the ERM has attributes that describe the entity's properties or characteristics.
6. Keys are used to uniquely identify entities in a database system.
7. A primary key is a unique identifier for an entity and is used to ensure that each record in a table can be uniquely identified.
8. Foreign keys are used to establish relationships between entities and ensure referential integrity in the database.
9. Superkeys are sets of attributes that can be used to uniquely identify an entity, but they may contain more attributes than necessary.
10. Candidate keys are minimal superkeys that can uniquely identify an entity.
11. Alternate keys are candidate keys that are not selected as the primary key.
12. Composite keys are primary keys that are made up of more than one attribute.
13. Surrogate keys are artificially generated keys that are used as the primary key when no natural primary key exists.
14. In the ERM, keys are represented by underlining the attribute or set of attributes that make up the key.
15. It is important to choose appropriate keys for each entity in a database system to ensure data integrity and efficient data retrieval.
