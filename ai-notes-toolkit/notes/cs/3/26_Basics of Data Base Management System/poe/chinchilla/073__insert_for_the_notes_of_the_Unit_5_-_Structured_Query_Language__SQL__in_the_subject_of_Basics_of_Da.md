### Unit 5: Structured Query Language (SQL)

Structured Query Language (SQL) is a standard language used to manage relational databases. It provides a way to interact with databases and perform various operations like creating tables, inserting data, updating data, and deleting data. In this unit, we will cover the basics of SQL and its syntax.

#### SQL Basics

- SQL stands for Structured Query Language.
- It is used to manage relational databases.
- SQL is a standard language, which means it is used across various database management systems like MySQL, Oracle, SQL Server, etc.
- SQL is used to perform various operations on databases, including creating tables, inserting data, updating data, and deleting data.

#### SQL Syntax

- SQL commands are written in a specific syntax that must be followed for the commands to work.
- SQL commands are not case sensitive, but it is recommended to write SQL commands in uppercase to enhance readability.
- SQL commands are terminated by a semicolon (;).

#### SQL Commands

- SQL commands can be divided into four categories: Data Definition Language (DDL), Data Manipulation Language (DML), Data Control Language (DCL), and Transaction Control Language (TCL).
- DDL commands are used to define the structure of a database, including creating tables, altering tables, and dropping tables.
- DML commands are used to manipulate data in a database, including inserting data, updating data, and deleting data.
- DCL commands are used to control access to a database, including granting and revoking permissions to users.
- TCL commands are used to manage transactions in a database, including committing transactions and rolling back transactions.

#### SQL Statements

- SQL commands are made up of SQL statements.
- SQL statements are used to perform specific tasks, such as creating a table or inserting data into a table.
- SQL statements are made up of keywords, identifiers, and values.
- Keywords are reserved words in SQL that have a specific meaning, such as SELECT, INSERT, UPDATE, and DELETE.
- Identifiers are names given to database objects, such as tables, columns, and indexes.
- Values are the data that is stored in a database, such as numbers, strings, and dates.

#### SQL Functions

- SQL functions are used to perform calculations and manipulate data in a database.
- SQL functions can be divided into two categories: scalar functions and aggregate functions.
- Scalar functions operate on a single value and return a single value, such as the UPPER function, which converts a string to uppercase.
- Aggregate functions operate on a group of values and return a single value, such as the SUM function, which calculates the sum of a group of numbers.

#### Conclusion

SQL is a powerful language used to manage relational databases. It provides a way to interact with databases and perform various operations like creating tables, inserting data, updating data, and deleting data. Understanding the basics of SQL and its syntax is essential for working with databases.
