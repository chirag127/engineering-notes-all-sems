# Unit 1 - Introduction

## What is a database?
- A database is a collection of related data that is organized and stored in a structured way.
- A database can store various types of data, such as text, numbers, images, audio, video, etc.
- A database can be accessed and manipulated by using a software application called a database management system (DBMS).

## What is a database management system (DBMS)?
- A DBMS is a software system that provides the functionality to create, maintain, and manipulate databases.
- A DBMS can perform various operations on the data, such as insertion, deletion, modification, retrieval, analysis, etc.
- A DBMS can also ensure the security, integrity, consistency, and reliability of the data.
- A DBMS can support different types of databases, such as relational, hierarchical, network, object-oriented, etc.

## What are the advantages of using a database?
- A database can provide the following benefits:
  - Data independence: The data can be separated from the application programs that use it, allowing the data to be changed without affecting the programs.
  - Data abstraction: The data can be represented at different levels of detail, hiding the complexity and implementation details from the users.
  - Data consistency: The data can be maintained in a consistent state, avoiding errors and anomalies.
  - Data security: The data can be protected from unauthorized access and modification, ensuring the confidentiality and integrity of the data.
  - Data sharing: The data can be accessed and used by multiple users and applications, facilitating the communication and collaboration among them.
  - Data integrity: The data can be enforced to follow certain rules and constraints, ensuring the validity and accuracy of the data.
  - Data backup and recovery: The data can be backed up and restored in case of failures or disasters, ensuring the availability and durability of the data.
