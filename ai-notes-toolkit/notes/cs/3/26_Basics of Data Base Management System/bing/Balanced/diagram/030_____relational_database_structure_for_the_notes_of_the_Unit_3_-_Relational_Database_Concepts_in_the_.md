### Relational Database Structure

- A relational database is a collection of data organized into tables, where each table consists of rows and columns.
- Each row in a table represents a record or a tuple, which is a collection of related values or attributes.
- Each column in a table represents an attribute or a field, which is a property or characteristic of the records.
- Each table in a relational database has a unique name and a primary key, which is an attribute or a combination of attributes that can uniquely identify each record in the table.
- A table can also have foreign keys, which are attributes that refer to the primary keys of other tables, to establish relationships between tables.
- A relationship is an association or a link between two or more tables, based on common attributes or foreign keys.
- There are three types of relationships in a relational database: one-to-one, one-to-many, and many-to-many.
- A one-to-one relationship is when each record in one table is related to exactly one record in another table.
- A one-to-many relationship is when each record in one table is related to zero or more records in another table, and each record in the other table is related to exactly one record in the first table.
- A many-to-many relationship is when each record in one table is related to zero or more records in another table, and each record in the other table is related to zero or more records in the first table.
- A many-to-many relationship cannot be directly represented in a relational database, and requires an intermediate table or a junction table to store the associations between the records of the two tables.
- A relational database can be represented by a schema, which is a diagram that shows the tables, their attributes, their primary keys, their foreign keys, and their relationships.
- A schema can also show the constraints, which are the rules or conditions that must be satisfied by the data in the tables, such as data types, domain restrictions, uniqueness, referential integrity, etc.
- A schema can be created using a data definition language (DDL), which is a set of commands or statements that define the structure and the constraints of the tables in a relational database.
- A schema can be manipulated using a data manipulation language (DML), which is a set of commands or statements that insert, update, delete, or query the data in the tables of a relational database.
- A schema can be queried using a query language, such as SQL (Structured Query Language), which is a standard language for accessing and manipulating data in a relational database.
