### Database Users and Administrator

Database users and administrator are the people who are accessing or working with the database. The primary aim of the database management system (DBMS) is to store the data or information and retrieve it whenever it is needed by the database users. There are different types of database users and administrator, depending on their interaction with the database and their roles and responsibilities. Here are some of the common types of database users and administrator:

- **Native Users**: These are the database users who are communicating with the database through an already written program. For example, when a student logs in to an online learning platform, they are using a program that interacts with the database to fetch the relevant data. Native users do not need to know the details of the database or the query language. They only need to know how to use the program interface.

- **Application Programmers**: These are the software developers and programming professionals who write the programs that interact with the database. They use a programming language and a query language (such as SQL) to create, update, delete, and retrieve data from the database. Application programmers need to know the logical and physical structure of the database, the query language syntax and semantics, and the application logic and requirements.

- **Casual Users**: These are the database users who occasionally access the database for some specific purpose. They do not have a regular or predefined pattern of database usage. They may use a query language (such as SQL) or a graphical user interface (such as a web browser) to submit queries to the database. Casual users need to have some knowledge of the query language and the database schema, but they do not need to be experts.

- **Sophisticated Users**: These are the database users who have a high level of expertise and experience in using the database. They may use a query language (such as SQL) or a specialized application (such as a data analysis tool) to access the database. Sophisticated users need to have a deep understanding of the query language, the database schema, the data semantics, and the optimization techniques.

- **Parametric Users**: These are the database users who perform a specific function or task on the database, such as data entry, data validation, data reporting, etc. They use a predefined program or interface that allows them to enter or view the data based on some parameters. Parametric users do not need to know the details of the database or the query language. They only need to know how to use the program or interface.

- **Database Administrator (DBA)**: Database administrator (DBA) is a person or a team who defines the schema and also controls the three levels of the database: the external level, the conceptual level, and the internal level. The DBA is responsible for creating, maintaining, securing, and managing the database. The DBA has full control of the database and can grant or revoke permissions to other database users. The DBA needs to have a comprehensive knowledge of the database system, the query language, the data modeling techniques, the backup and recovery procedures, the performance tuning methods, and the security policies.
