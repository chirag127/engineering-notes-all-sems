### SQL operators and their procedure

SQL operators are symbols or keywords that are used to perform operations on values or expressions in SQL statements. They are used to specify conditions, filter results, compare values, perform calculations, concatenate strings, and more. SQL operators can be classified into six types:

- Arithmetic operators: These operators are used for mathematical operations on numerical data, such as adding, subtracting, multiplying, dividing, and finding the remainder. For example, `SELECT 10 + 10;` returns 20. The arithmetic operators are `+`, `-`, `*`, `/`, and `%`.
- Comparison operators: These operators are used to compare two values or expressions and return a boolean value (true or false). They are often used in the `WHERE` clause to filter rows based on a condition. For example, `SELECT * FROM customers WHERE age > 18;` returns all the customers whose age is greater than 18. The comparison operators are `=`, `<>`, `!=`, `>`, `<`, `>=`, `<=`, `!<`, `!>`, `IS`, `IS NOT`, `IN`, `NOT IN`, `BETWEEN`, `NOT BETWEEN`, `LIKE`, `NOT LIKE`, `EXISTS`, and `NOT EXISTS`.
- Logical operators: These operators are used to combine two or more conditions and return a boolean value. They are often used in the `WHERE` clause to filter rows based on multiple conditions. For example, `SELECT * FROM customers WHERE age > 18 AND gender = 'M';` returns all the male customers whose age is greater than 18. The logical operators are `AND`, `OR`, `NOT`, and `XOR`.
- Bitwise operators: These operators are used to perform bit-level operations on binary data, such as shifting, rotating, and masking. They are often used to manipulate binary flags or bit fields. For example, `SELECT 10 & 3;` returns 2, which is the result of performing a bitwise AND operation on the binary representations of 10 and 3. The bitwise operators are `&`, `|`, `^`, `~`, `<<`, and `>>`.
- String operators: These operators are used to perform operations on string data, such as concatenating, extracting, replacing, and converting. They are often used to manipulate text values or expressions. For example, `SELECT 'Hello' + ' ' + 'World';` returns 'Hello World', which is the result of concatenating two strings with a space. The string operators are `+`, `||`, `SUBSTRING`, `LEFT`, `RIGHT`, `CHARINDEX`, `REPLACE`, `UPPER`, `LOWER`, and `CAST`.
- Set operators: These operators are used to combine two or more result sets and return a single result set. They are often used to perform set operations, such as union, intersection, and difference. For example, `SELECT name FROM customers UNION SELECT name FROM employees;` returns the names of all the customers and employees, without duplicates. The set operators are `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`, and `MINUS`.
