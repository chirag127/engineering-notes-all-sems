### Types of security for the notes of the Unit 9 - Database Security in the subject of Basics of Data Base Management System

Database security is the process of protecting and safeguarding the database from unauthorized access or cyber-attacks. There are different types of database security that should be implemented in your business, such as:

- **Authentication**: Database authentication is the type of database security that verifies the user's login credentials which are stored in the database. If the user's login credentials match in the database, then the user can access the database. Authentication can be done by using passwords, biometrics, tokens, or certificates .
- **Database Encryption**: Database encryption is the type of database security that transforms the data in the database into an unreadable form using a secret key or algorithm. Database encryption can protect the data from unauthorized access, modification, or theft. Database encryption can be applied to the whole database, a table, a column, or a cell .
- **Backup Database**: Backup database is the type of database security that creates a copy of the database and stores it in a safe location. Backup database can help to recover the data in case of data loss, corruption, or disaster. Backup database can be done manually or automatically, and can be stored on a local disk, a remote server, or a cloud service .
- **Physical Security**: Physical security is the type of database security that protects the database server from physical damage, theft, or sabotage. Physical security can include locking the server room, installing security cameras, alarms, or guards, and using fire suppression systems .
- **Application Security**: Application security is the type of database security that protects the database from malicious attacks that exploit the vulnerabilities in the database applications or interfaces. Application security can include using secure coding practices, testing and debugging the applications, updating and patching the applications, and using web application firewalls  .
- **Access Control**: Access control is the type of database security that regulates who can access what data in the database and how they can access it. Access control can include using roles, privileges, permissions, or policies to grant or deny access to the data, and using audit logs to monitor and record the access activities  .

These are some of the types of database security that can help to protect the database from various threats and risks. Database security is an essential part of database management and should be implemented and maintained properly.
