### SQL data type and literals

- A data type defines the kind of value that a column or a variable can store in a database.
- SQL supports many data types, such as numeric, character, date, time, boolean, etc.
- A literal is a fixed or constant value that can be assigned to a column or a variable of a specific data type.
- SQL uses different syntaxes for different types of literals, such as single quotes for character literals, numeric literals without quotes, and keywords for boolean literals.
- Some examples of SQL data types and literals are:

| Data type | Description | Example of literal |
|-----------|-------------|--------------------|
| INTEGER | A whole number | 42 |
| DECIMAL(p, s) | A decimal number with precision p and scale s | 3.14 |
| CHAR(n) | A fixed-length character string of length n | 'Hello' |
| VARCHAR(n) | A variable-length character string of maximum length n | 'World' |
| DATE | A date value in the format YYYY-MM-DD | '2023-03-15' |
| TIME | A time value in the format HH:MM:SS | '22:11:25' |
| BOOLEAN | A logical value of true or false | TRUE |

- SQL also supports some special literals, such as NULL, which represents a missing or unknown value, and DEFAULT, which represents the default value of a column.
