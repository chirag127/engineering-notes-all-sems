# Name of the Experiment for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- A possible name for the experiment is **Database Management for Relational Databases using Azure Lab Services**.
- The experiment aims to teach the basic concepts and skills of database management using two popular relational database management systems (RDBMS): MySQL and SQL Server.
- The experiment involves setting up a virtual machine template in a lab with both MySQL Database Server and SQL Server 2019 server installed and configured.
- The experiment also requires creating and accessing databases, tables, views, queries, and stored procedures using both MySQL and SQL Server tools and commands.
- The experiment covers the following topics and objectives:
  - Database concepts and terminology
  - Relational database model and schema design
  - Data definition language (DDL) and data manipulation language (DML)
  - SQL queries and subqueries
  - Joins, unions, and set operations
  - Aggregate functions and group by clause
  - Views and indexes
  - Stored procedures and triggers
  - Database security and backup
- The experiment can be assessed by using quizzes, assignments, and projects that test the students' understanding and application of the database concepts and skills.
