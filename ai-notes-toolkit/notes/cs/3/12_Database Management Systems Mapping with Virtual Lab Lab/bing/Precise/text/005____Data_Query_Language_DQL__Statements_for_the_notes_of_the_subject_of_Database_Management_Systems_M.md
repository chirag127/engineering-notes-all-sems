## Data Query Language (DQL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- Data Query Language (DQL) is a subset of the Structured Query Language (SQL) used to retrieve data from a database.
- The primary DQL statement is the SELECT statement, which is used to retrieve data from one or more tables in a database.
- The SELECT statement can be used to retrieve specific columns, rows, or both from a table.
- The SELECT statement can also be used with various clauses such as WHERE, GROUP BY, HAVING, and ORDER BY to filter, group, and sort the retrieved data.
- The SELECT statement can also be used with aggregate functions such as COUNT, SUM, AVG, MIN, and MAX to perform calculations on the retrieved data.
- The SELECT statement can also be used with JOIN clauses to retrieve data from multiple related tables.
- The SELECT statement can also be used with subqueries to retrieve data based on the results of another query.
- The SELECT statement can also be used with UNION, INTERSECT, and EXCEPT operators to combine the results of multiple queries.
- The SELECT statement can also be used with the LIMIT and OFFSET clauses to limit the number of rows returned and to specify the starting point for the returned data.
- The SELECT statement can also be used with the DISTINCT keyword to remove duplicate rows from the result set.
