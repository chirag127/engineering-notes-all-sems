## Data Definition Language (DDL) Statements

Data Definition Language (DDL) is a subset of SQL (Structured Query Language) used to define and manage the structure of a database. DDL statements are used to create, alter, and drop database objects such as tables, views, indexes, and procedures.

Some common DDL statements include:

1. **CREATE**: This statement is used to create a new database object, such as a table or view. For example, the `CREATE TABLE` statement is used to create a new table in the database.

2. **ALTER**: This statement is used to modify the structure of an existing database object. For example, the `ALTER TABLE` statement can be used to add, modify, or delete columns in a table.

3. **DROP**: This statement is used to delete a database object. For example, the `DROP TABLE` statement is used to delete a table from the database.

4. **TRUNCATE**: This statement is used to delete all data from a table, but it does not delete the table itself.

5. **RENAME**: This statement is used to rename a database object.

These DDL statements are used in the Database Management Systems Mapping with Virtual Lab Lab to define and manage the structure of the database used in the lab exercises.
