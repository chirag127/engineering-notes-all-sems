## Data Manipulation Language (DML) Statements

Data Manipulation Language (DML) is a subset of SQL used to retrieve, insert, update, and delete data in a database. DML statements are used to manipulate the data stored in the database objects like tables, views, etc.

Here are the main DML statements used in SQL:

1. **SELECT**: The SELECT statement is used to retrieve data from one or more tables or views. It is the most commonly used DML statement.

2. **INSERT**: The INSERT statement is used to add new rows of data to a table. You can insert data into a table either by specifying the values for each column or by using a SELECT statement to retrieve data from another table.

3. **UPDATE**: The UPDATE statement is used to modify the data in existing rows of a table. You can update one or more columns of a table at a time.

4. **DELETE**: The DELETE statement is used to remove rows from a table. You can delete one or more rows based on a specified condition.

These DML statements are essential for manipulating the data stored in a database and are commonly used in Database Management Systems Mapping with Virtual Lab Lab. It is important to have a good understanding of these statements to effectively work with data in a database.
