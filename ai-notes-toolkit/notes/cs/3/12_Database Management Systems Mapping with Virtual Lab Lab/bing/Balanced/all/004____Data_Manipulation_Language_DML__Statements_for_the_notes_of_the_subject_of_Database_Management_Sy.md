# Data Manipulation Language(DML) Statements

- Data Manipulation Language (DML) is a subset of SQL that is used to access and modify data in existing tables  .
- DML statements can perform operations such as inserting, updating, deleting, and selecting data from tables  .
- DML statements are part of a transaction, which is a logical unit of work that either succeeds or fails as a whole .
- Some common DML statements are:
  - **INSERT**: adds one or more rows to a table   .
  - **UPDATE**: modifies one or more columns of one or more rows in a table   .
  - **DELETE**: removes one or more rows from a table   .
  - **SELECT**: retrieves data from one or more tables or views   .
  - **MERGE**: combines the data from two tables into one table based on a matching condition .
  - **CALL**: executes a stored procedure or a function .
  - **EXPLAIN PLAN**: displays the execution plan of a SQL statement .
  - **LOCK TABLE**: locks one or more tables or views in a specified mode .
- The syntax and usage of DML statements may vary depending on the database system and version.
- DML statements can be used in conjunction with other SQL statements, such as Data Definition Language (DDL) and Data Control Language (DCL), to create and manage database objects and permissions .
