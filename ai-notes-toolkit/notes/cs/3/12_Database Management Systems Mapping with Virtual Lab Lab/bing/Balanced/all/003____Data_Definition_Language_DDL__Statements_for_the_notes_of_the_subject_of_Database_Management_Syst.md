# Data Definition Language (DDL) Statements

- Data Definition Language (DDL) is a subset of SQL and a part of DBMS (Database Management System) .
- DDL statements are used to define and modify the database structure or schema, which is the organization of data   .
- DDL statements include commands like CREATE, ALTER, TRUNCATE and DROP, which are used to create or modify the tables, files, indexes, columns and other database objects  .
- DDL statements are different from Data Manipulation Language (DML) and Data Query Language (DQL), which are used to manipulate and query the data within the database objects  .
- DDL statements are executed by the database system, which checks the syntax and semantics of the statements and updates the metadata or catalog of the database .
