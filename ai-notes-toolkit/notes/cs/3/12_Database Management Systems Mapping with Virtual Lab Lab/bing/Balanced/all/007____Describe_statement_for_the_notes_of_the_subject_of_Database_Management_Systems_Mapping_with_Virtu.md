## Describe statement for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- Database Management Systems (DBMS) are software applications that allow users to create, manipulate, and query data stored in databases.
- A database is a collection of structured data that is organized according to a logical model, such as a relational model, a hierarchical model, or a network model.
- A virtual lab is a simulated environment that provides users with access to various tools and resources for learning and experimentation, such as virtual machines, software applications, and data sets.
- Database Management Systems Mapping with Virtual Lab Lab is a subject that teaches students how to use DBMS software and virtual labs to perform various tasks related to database management, such as:
  - Creating and modifying database schemas, tables, views, indexes, and constraints.
  - Inserting, updating, deleting, and retrieving data from databases using SQL queries and commands.
  - Performing data analysis and manipulation using functions, operators, joins, subqueries, and aggregates.
  - Implementing data security and integrity using transactions, locks, and triggers.
  - Designing and optimizing database systems using normalization, denormalization, and indexing techniques.
  - Comparing and contrasting different types of DBMS, such as MySQL, SQL Server, Oracle, and MongoDB.
  - Exploring various aspects of database administration, such as backup, recovery, performance tuning, and replication.
- The subject uses Azure Lab Services as a platform for setting up and accessing virtual labs that contain DBMS software and data sets. Azure Lab Services is a cloud-based service that allows instructors to create and manage virtual labs for their classes, and students to access and use the labs from any device and location.
- The subject also uses Labguru as a scientific data management system that helps students to organize, document, and share their lab work and results. Labguru is a web-based application that integrates with various tools and platforms, such as ELN, LIMS, and informatics.
- The subject aims to provide students with both theoretical and practical knowledge of database management systems and their applications in various domains and scenarios. The subject also helps students to develop skills such as critical thinking, problem-solving, collaboration, and communication.
