## Data Manipulation Language(DML) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

1. INSERT: Used to insert new rows into a table. Specifies the table name and value for each column.
2. UPDATE: Used to update existing rows in a table. Specifies the table name, conditions to identify the rows to be updated, and new values for the columns to be updated.
3. DELETE: Used to remove existing rows from a table that satisfy a given condition. Specifies the table name and condition to identify the rows to be deleted.
4. MERGE: Used to insert or update rows depending on some conditions. It allows conditional insert or update of rows.

The above DML statements are used to manipulate (insert, update, delete) data in the database tables. They are executed using SQL and their effects are reflected in the data stored in the database.
