## Database Management Lab for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

1. Learn to create a database using MySQL. Understand the basic commands like CREATE, ALTER, DROP, etc.
2. Learn to create tables with different datatypes like int, char, varchar, date, etc. and add constraints like primary key, foreign key, unique key, etc.
3. Understand the relationships between tables like one-to-one, one-to-many, and many-to-many and create tables based on those relationships.
4. Learn to insert, update, and delete data from the tables.
5. Understand aggregate functions and group by clause. Learn to retrieve data from tables using basic to complex SQL queries.
6. Learn to create users and grant privileges for database administration. Understand the concept of normal forms to design the database schema.
7. Get hands-on experience of database design for a project using E-R diagram and normalization.
