## Describe statement for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

1. Database Management Systems (DBMS) is a software application that interacts with end users, applications, and the database itself to capture and analyze data.

2. A DBMS makes it possible for end users to create, read, update and delete data in a database. The DBMS ensures integrity and security of the database.

3. The components of a DBMS are - Data Definition Language (DDL), Data Manipulation Language (DML), Data Control Language (DCL), Query Language (QL), and the Database Administrator (DBA).

4. DDL is used to define the database structure. DML is used for managing data. DCL is used to control access. QL is used for querying the database. DBA is responsible for authorizing access and maintaining the DBMS.

5. The Virtual Lab simulates a real-world scenario where we can create databases, tables, and perform various operations to understand the concepts in a practical manner. It provides a GUI to execute SQL queries and see the output.

6. The Virtual Lab helps in connecting the theoretical knowledge of DBMS with practical applications to gain a deeper understanding of the concepts and enhance problem-solving skills. Mapping the theoretical knowledge with hands-on experiments develops a stronger grasp of the subject.
