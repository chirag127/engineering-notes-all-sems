## Unit 3 - Link Layer

The link layer is one of the layers in the OSI model that is responsible for providing reliable and efficient transfer of data between adjacent network nodes. In this unit, we will discuss the key concepts related to the link layer. Here are some important points to keep in mind:

- The link layer is responsible for framing, error detection and correction, flow control, and access control.
- In framing, the link layer adds start and end delimiters to the data to mark the beginning and end of the frame.
- Error detection and correction is done using techniques such as cyclic redundancy check (CRC) and forward error correction (FEC).
- Flow control is necessary to avoid overwhelming the receiver with too much data. Techniques such as window-based flow control and rate-based flow control are used.
- Access control is used to manage access to the shared medium in a network. Techniques such as carrier sense multiple access with collision detection (CSMA/CD) and carrier sense multiple access with collision avoidance (CSMA/CA) are used.
- Ethernet is the most widely used link layer protocol in wired networks. It uses CSMA/CD for access control and supports speeds ranging from 10 Mbps to 100 Gbps.
- Wi-Fi is the most widely used link layer protocol in wireless networks. It uses CSMA/CA for access control and supports speeds ranging from 1 Mbps to 10 Gbps.
- Other link layer protocols include Token Ring, FDDI, and PPP.
- Ethernet and Wi-Fi both use MAC addresses to identify network nodes. MAC addresses are assigned by the manufacturer and are unique to each device.
- Bridges and switches are used to connect multiple network segments at the link layer. They use MAC addresses to forward data between segments.
- Virtual LANs (VLANs) are used to group network nodes logically, regardless of their physical location. VLANs are implemented at the link layer using switches.
- Link aggregation allows multiple physical links to be combined into a single logical link. This increases bandwidth and provides redundancy in case of link failures.
- Link layer security is important to prevent unauthorized access and attacks on the network. Techniques such as MAC address filtering, port security, and 802.1X authentication are used.
