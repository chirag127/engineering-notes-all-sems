## Unit 2 - Physical Layer

The Physical Layer is the first layer of the OSI model, which provides the transmission of raw bits over a communication channel. The Physical Layer is responsible for transmitting data between devices on the same network. It is the foundation of all communication networks and plays a crucial role in the transmission of data.

### Topics Covered in Physical Layer

1. Introduction to Physical Layer
2. Data transmission and Reception
3. Transmission Media
4. Transmission Modes
5. Modulation Techniques
6. Multiplexing and Demultiplexing
7. Error Detection and Correction
8. Data Link Control

### Introduction to Physical Layer

The Physical Layer is the first layer in the OSI model, which provides the transmission of raw bits over a communication channel. It is responsible for converting digital data into a physical signal that can be transmitted over a communication medium. The Physical Layer is also responsible for receiving the signal from the medium and converting it back into digital data.

### Data Transmission and Reception

The Physical Layer is responsible for transmitting data between devices on the same network. It uses various techniques such as modulation, multiplexing, and demultiplexing to achieve this. The Physical Layer also handles the synchronization of data transmission and reception.

### Transmission Media

The Physical Layer uses various transmission media to transmit data. The transmission media can be wired or wireless. Wired transmission media includes twisted pair, coaxial cable, and fiber optic cable. Wireless transmission media includes radio waves, microwave, and infrared.

### Transmission Modes

The Physical Layer uses different transmission modes to transmit data. The transmission mode determines the direction of data flow between devices. The transmission modes can be simplex, half-duplex, or full-duplex.

### Modulation Techniques

The Physical Layer uses modulation techniques to transmit data over a communication channel. Modulation is the process of converting digital data into an analog signal that can be transmitted over a communication medium. The modulation techniques used in the Physical Layer include Amplitude Modulation (AM), Frequency Modulation (FM), and Phase Modulation (PM).

### Multiplexing and Demultiplexing

The Physical Layer uses multiplexing and demultiplexing techniques to transmit multiple signals over a single communication channel. Multiplexing is the process of combining multiple signals into a single signal, while demultiplexing is the process of separating the combined signal into individual signals.

### Error Detection and Correction

The Physical Layer uses error detection and correction techniques to ensure the accuracy of data transmission. Error detection techniques include Parity Check, Checksum, and Cyclic Redundancy Check (CRC). Error correction techniques include Automatic Repeat Request (ARQ) and Forward Error Correction (FEC).

### Data Link Control

The Physical Layer is also responsible for Data Link Control. Data Link Control includes the establishment, maintenance, and termination of a data link connection. It is responsible for flow control, error control, and access control. Flow control regulates the flow of data between devices. Error control detects and corrects errors that occur during data transmission. Access control determines which device can access the communication channel at a particular time.

In conclusion, the Physical Layer is a critical layer in the OSI model, which provides the transmission of raw bits over a communication channel. It plays a crucial role in the transmission of data and is responsible for converting digital data into a physical signal that can be transmitted over a communication medium. The Physical Layer is also responsible for receiving the signal from the medium and converting it back into digital data.
