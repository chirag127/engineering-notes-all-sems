## Unit 5 - Network Layer

The network layer is the third layer of the OSI model. It is responsible for the transmission of data packets from one network to another. The following are some of the key functions of the network layer:

- **Logical addressing**: The network layer is responsible for assigning logical addresses to devices on the network. These addresses are used to identify devices on the network and to route data packets to their destination.

- **Routing**: The network layer is responsible for routing data packets between networks. It uses routing algorithms to determine the best path for a data packet to take to reach its destination.

- **Fragmentation and reassembly**: The network layer is responsible for breaking up large data packets into smaller packets, known as fragments, for transmission over the network. It is also responsible for reassembling these fragments into the original data packet at the destination.

- **Congestion control**: The network layer is responsible for managing network congestion. It uses techniques such as traffic shaping and admission control to prevent the network from becoming overloaded.

- **Quality of Service (QoS)**: The network layer is responsible for providing QoS guarantees to applications. It uses techniques such as bandwidth allocation and prioritization to ensure that applications receive the necessary network resources to function properly.

In addition to the OSI model, the network layer is also an important component of the TCP/IP protocol stack. In the TCP/IP protocol stack, the network layer is represented by the Internet Protocol (IP). The IP protocol is responsible for logical addressing, routing, fragmentation and reassembly, and congestion control.

In conclusion, the network layer is a critical component of any network. It is responsible for logical addressing, routing, fragmentation and reassembly, congestion control, and QoS. Understanding the network layer is essential for anyone working with computer networks.
