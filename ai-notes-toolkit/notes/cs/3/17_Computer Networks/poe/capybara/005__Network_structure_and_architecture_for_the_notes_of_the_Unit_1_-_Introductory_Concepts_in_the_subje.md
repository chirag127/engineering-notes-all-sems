

### Network Structure and Architecture

- Network architecture refers to the design of a computer network and the way in which components are organized.
- The structure of a network can be described in terms of its topology, which determines how devices are connected to each other.
- Different types of topologies include bus, star, ring, mesh, and tree.
- Each topology has its own advantages and disadvantages, depending on the needs of the network.
- Network architecture also includes the protocols and standards used to transmit data between devices.
- Examples of network protocols include TCP/IP, HTTP, FTP, and SMTP.
- Standards such as Ethernet, Wi-Fi, and Bluetooth define how devices communicate with each other over a network.
- Network architecture can be divided into layers, with each layer responsible for a specific function.
- The most commonly used model for network architecture is the OSI model, which has seven layers: physical, data link, network, transport, session, presentation, and application.
- Each layer has its own protocols and functions, and data is passed between layers using standardized interfaces.
- Understanding network architecture is important for designing, implementing, and troubleshooting computer networks.
