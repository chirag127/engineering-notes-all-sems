### LAN standards for the notes of the Unit 4 - Medium Access Control and Local Area Networks

1. Ethernet: Ethernet is a family of computer networking technologies commonly used in local area networks (LAN), metropolitan area networks (MAN) and wide area networks (WAN). It was commercially introduced in 1980 and defined in 1983 as IEEE 802.3. Ethernet has largely replaced competing wired LAN technologies.

2. Token Ring: Token Ring network technology is a local area network protocol which resides at the data link layer (DLL) of the OSI model. It uses a special three-byte frame called a token that travels around a logical ring of workstations or servers. This token passing is a channel access method providing fair access for all stations, and eliminates collisions.

3. FDDI: Fiber Distributed Data Interface (FDDI) is a standard for data transmission in a local area network. It uses optical fiber cables as the physical medium and provides a maximum bandwidth of 100 Mbit/s. FDDI was sometimes referred to as "CDDI" or "Copper Distributed Data Interface" when used over twisted pair copper wire. FDDI and CDDI are no longer being actively developed or marketed.

Wireless LAN: A wireless local area network (WLAN) is a wireless computer network that links two or more devices using wireless communication within a limited area such as a home, school, computer laboratory, campus, or office building. This gives users the ability to access shared resources and peripherals as well as Internet access and network connectivity, without needing to physically plug into the network using cables.
