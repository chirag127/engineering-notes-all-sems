### Services for the notes of the Unit 1 - Introductory Concepts in Computer Networks

1. Network services: Services provided by the network to facilitate communication between processes. Ex: Remote login, File transfer, Network file system, Mail services.

2. User services: Services that directly serve the end user application software. Ex: Web browsing, Streaming media.

3. Application services: Services provided to application software to simplify certain tasks or abstract details of network operations. Includes directories and databases.

4. Middleware services: Software that enables interoperation of multiple application services. Ex: Transaction processing monitors, Message-oriented middleware.

5. System services: Include services like time synchronization, network management, and security.
