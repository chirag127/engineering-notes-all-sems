### RARP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks.

1. RARP stands for Reverse Address Resolution Protocol. It is used to map IP addresses to MAC addresses.
2. In RARP, the client device broadcasts a request onto the network with its own MAC address and requests for its IP address.
3. The RARP server which has the IP-MAC address mapping tables responds to this request with the IP address corresponding to the client's MAC address.
4. RARP is not commonly used nowadays as most devices now have DHCP which assigns IP addresses dynamically. RARP is rarely implemented in devices nowadays.
5. The packet structure of RARP consists of an opcode specifying if it is a request or reply, sender and target MAC address and sender IP address in the reply.
