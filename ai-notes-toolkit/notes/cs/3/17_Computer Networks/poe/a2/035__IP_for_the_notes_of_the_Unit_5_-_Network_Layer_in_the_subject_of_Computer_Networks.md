### IP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

1. IP or Internet Protocol is a network layer protocol used to route packets across the internet. It is responsible for delivering packets from the source host to the destination host by forwarding them to the next network router or destination host.
2. The key features of IP are:
- Connectionless: IP is a connectionless protocol i.e. it does not establish a dedicated end-to-end connection between two hosts. Each packet is treated independently.
- Unreliable: IP provides an unreliable service i.e. it does not guarantee delivery of packets. Packets may be lost, corrupted or delivered out of order.
- Best effort delivery: IP attempts to deliver all packets but does not guarantee delivery, correctness or in-order delivery of packets.
- Packet switched: IP transmits packets where each packet contains the complete addressing information.
3. The IP packet contains a header with source and destination IP addresses, protocol type and other metadata. The payload contains the user data.
4. The IP protocol uses IP addresses to identify hosts and route packets in an IP network. The IP address is a 32 bit or 128 bit number represented in decimal or binary format.
5. The key functions of IP are:
- Addressing: The source and destination hosts are identified using IP addresses.
- Fragmentation: If the packet size exceeds the MTU, IP fragments the packet into smaller packets.
- TTL: A time to live field prevents packets from looping endlessly.
- Options: IP provides options to support security, recording route etc.
