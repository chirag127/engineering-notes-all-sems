## Unit 5 - Network Layer

1. The network layer is responsible for routing network packets across network devices like routers. It uses IP addresses to uniquely identify devices and route packets.
2. The primary protocol of the network layer is the Internet Protocol or IP. IP specifies the format of packets and a protocol for routing packets between networks.
3. Two versions of IP are used - IPv4 and IPv6. IPv4 uses 32-bit addresses and has limited address space. IPv6 uses 128-bit addresses and has a much larger address space.
4. Routers operate at the network layer and use routing protocols to determine the best path for network packets and forward them accordingly. Some common routing protocols are RIP, OSPF, BGP, etc.
5. Two key concepts at the network layer are forwarding and routing. Forwarding refers to the transfer of packets from input to output interfaces based on destination addresses. Routing refers to the process of determining optimal paths for forwarding packets.
6. Other protocols at the network layer include ICMP for control and error messaging, IGMP for managing multicast groups, and ARP for mapping IP addresses to MAC addresses.
