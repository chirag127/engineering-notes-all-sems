### The OSI reference model for the notes of the Unit 1 - Introductory Concepts in the subject of Computer Networks.

1. The OSI model consists of seven layers:
- Physical layer: deals with the physical connections between devices. Examples: cables, radio frequencies, etc.
- Data link layer: handles data transmission between devices. Examples: MAC addresses, error detection, etc.
- Network layer: handles routing of data packets between networks. Examples: IP addresses, routing protocols, etc.
- Transport layer: ensures reliable data transmission between applications. Examples: TCP, UDP, port numbers, etc.
- Session layer: manages sessions between applications. Examples: TCP sessions, etc.
- Presentation layer: handles data formatting information. Examples: data compression, data encryption, etc.
- Application layer: provides interfaces for applications to access the network. Examples: HTTP, SMTP, FTP, etc.

2. Each layer performs a separate and distinct task and then passes the data on to the next layer.
3. Data is passed from upper layers down to lower layers during transmission and from lower layers up to upper layers during reception.
4. The OSI model is a conceptual framework and is not directly implemented in networking protocols. But the TCP/IP model maps to the OSI model.
