### Routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks.

1. Routing is the process of selecting paths in a network along which to send network traffic. Routing is performed for many kinds of networks, including the telephone network, electronic data networks (such as the Internet), and transportation networks.

2. The routing process usually directs forwarding tables in routers to dictate the next hop to which a packet should be forwarded toward its destination network. The routing process computes the best path based on the destination address, the network topology, and current traffic conditions.

3. The routing algorithm must react to changes in the network, such as link failures or congestion. The algorithm may aim to minimize the number of hops, minimize latency, minimize cost, or maximize throughput. There may be constraints on available routes, such as security issues with certain routes.

4. Routing algorithms determine the specific choice of route. Each router uses its own routing algorithm to compute the best path. The most common intra-domain routing protocols are RIP, OSPF, and BGP. The most common inter-domain routing protocols are EBGP and IBGP.

5. Routers communicate between each other using routing protocols to build and maintain a routing table containing the best available routes between any two systems. As the network topology changes, routers inform other routers of the changes to maintain consistent and up-to-date routing information.
