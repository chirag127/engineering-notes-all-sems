### Network management for the notes of the Unit 7 - Application Layer in the subject of Computer Networks.

1. Network monitoring - Continuously monitoring the network for errors and other key performance indicators. This enables detecting and diagnosing problems early. Metrics like bandwidth usage, CPU usage, memory usage, traffic patterns, etc. are monitored.
2. Fault management - Detecting, isolating and correcting faults or problems in the network. This includes monitoring for errors and diagnosing and troubleshooting any issues. Possible faults could be device failures, link failures, excessive traffic, security issues, etc.
3. Configuration management - Configuring, updating, backing up and restoring devices and software in the network. This ensures consistency and correctness of configurations across the network.
4. Accounting management - Tracking network resource usage for accounting or billing purposes. This could be tracking bandwidth usage, CPU usage or other metrics to generate reports or invoices.
5. Performance management - Monitoring and maintaining the performance of the network and network devices. This could include monitoring response times, throughput, resource usage, etc. and taking corrective actions to optimize performance.
6. Security management - Implementing, monitoring and maintaining security on the network. This includes things like implementing firewalls, VPNs, password policies, monitoring for intrusions or attacks, etc. to protect the network.
