### World Wide Web and Hyper Text Transfer Protocol

1. World Wide Web (WWW): It is a massive distributed client-server information system. The web is a collection of millions of individual pages located on servers all across the Internet. These web pages are accessed via HTTP and identified by a Uniform Resource Locator (URL).

2. Hyper Text Transfer Protocol (HTTP): It is the underlying protocol of the World Wide Web. It defines how messages should be formatted and transmitted and what actions web servers and browsers should take in response to various commands. For example, when a user enters a URL into a browser, an HTTP command is sent to the web server directing it to fetch and transmit the requested webpage.

3. HTTP is a stateless protocol: This means that the server does not maintain any information about the state of the client connection. Each client request is treated independently, without relating it to previous requests. After responding to a request, the server does not expect future requests to relate to the previous one. This simplifies the server design and ensures that servers can handle many requests simultaneously.

4. HTTP methods: The most common HTTP methods are GET, POST, PUT, DELETE. They allow for different types of operations to be performed on a web resource. For example, GET is used to retrieve data, POST is used to send data to be processed, and PUT/DELETE are used to modify/delete data.
