### Network devices and components

1. Repeater - A repeater is a device that receives a signal and re-amplifies or regenerates it before forwarding it on. It is used to extend the length of a network.
2. Hub - A hub is a central connection point for devices in a network. It connects multiple Ethernet devices together and forwards traffic between them. It operates at the physical layer and amplifies the signal.
3. Switch - A switch is a multi-port network bridge that processes and forwards data at the data link layer (layer 2) of the OSI model. It forwards data only to the destination ports that lead to the destination device. It uses MAC addresses to identify the source and destination.
4. Router - A router is a network device that forwards data packets between computer networks based on network layer information and routing tables. It operates at the network layer (layer 3) and uses logical addressing (IP addresses) to identify the source and destination. It connects different IP networks and can filter and control traffic.
5. Gateway - A gateway is a network node that connects two networks using different protocols together. It translates between the protocols to facilitate the transfer of data. It operates at multiple layers of the OSI model (physical, network and transport).
6. Modem - A modem (modulator-demodulator) is a device that converts between digital data and analog signals to enable transfer of data over telephone or cable lines. It enables devices to connect to the Internet using existing telephone lines or TV cable lines.
