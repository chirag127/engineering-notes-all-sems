
### Routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

1. Routing is the process of finding paths in a network from a source to a destination. It is a key component of network layer protocols. 
2. A router is a device that forwards data packets between networks. It uses routing protocols to determine the best path for forwarding data packets.
3. Routing protocols use various metrics such as hop count, delay, bandwidth, and cost to determine the best path.
4. Routing algorithms such as link-state and distance-vector are used to calculate the best path.
5. Routing tables are used to store information about the best paths to different destinations.
6. Routing protocols can be divided into two categories: interior gateway protocols (IGPs) and exterior gateway protocols (EGPs).
7. IGPs are used to route traffic within an autonomous system (AS). Examples of IGPs include RIP, OSPF, and IS-IS.
8. EGPs are used to route traffic between autonomous systems. Examples of EGPs include BGP and EIGRP.
9. Routing protocols can be classified as either static or dynamic. Static routing is configured manually, while dynamic routing is configured automatically.
10. Routing security is important to protect networks from malicious attacks. Techniques such as access control lists, authentication, and encryption can be used to secure routing protocols.
