
## Unit 3 - Link Layer

1. The link layer is the layer in the OSI model that is responsible for sending data frames between two computers connected by a physical medium, such as an Ethernet cable.
2. It is responsible for addressing, routing, and error detection and correction.
3. The link layer is responsible for the physical connection between two devices.
4. It is responsible for the reliable delivery of data frames from one device to the other.
5. It is responsible for flow control, which is the process of controlling the rate at which data is sent from one device to the other.
6. It is responsible for error detection and correction, which is the process of detecting and correcting errors that occur during the transmission of data.
7. It is responsible for addressing, which is the process of assigning a unique address to each device on the network.
8. It is responsible for routing, which is the process of determining the best path for data to travel from one device to the other.
9. It is responsible for media access control, which is the process of controlling access to the physical medium.
