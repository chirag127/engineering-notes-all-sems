
### Basic Internetworking

* Internetworking is the process of connecting two or more computer networks together to form a larger network. 
* The Internet is the largest example of an internetwork. It is an interconnected network of networks that use the Internet Protocol Suite (TCP/IP) to communicate.
* The network layer of the Internet Protocol Suite is responsible for routing packets between networks. It includes protocols such as Internet Protocol (IP), Address Resolution Protocol (ARP), Internet Control Message Protocol (ICMP), and Border Gateway Protocol (BGP).
* Network devices such as routers, switches, and firewalls are used to interconnect networks and provide security and QoS (Quality of Service).
* Network addressing is used to identify hosts on a network. IP addresses are used to identify hosts on the Internet, while MAC addresses are used to identify hosts on a local network.
* Network segmentation is used to divide a network into smaller, more manageable segments. This helps to reduce network congestion and improve security.
* Network topologies are used to describe the physical and logical layout of a network. Common topologies include bus, star, and mesh.
* Network protocols such as Ethernet and Wi-Fi are used to provide communication between devices on a network.
* Network security is used to protect networks from malicious attacks and unauthorized access. Common security measures include firewalls, encryption, and authentication.
