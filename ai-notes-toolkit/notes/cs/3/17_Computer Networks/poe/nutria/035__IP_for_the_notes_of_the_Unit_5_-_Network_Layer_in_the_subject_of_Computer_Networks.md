
### IP for the Notes of the Unit 5 - Network Layer in the Subject of Computer Networks

* The Internet Protocol (IP) is the primary protocol used for communication across the Internet. It is responsible for addressing, routing, and delivering data packets from one device to another.
* IP addresses are unique identifiers assigned to each device on a network, and allow for communication between those devices.
* IP packets are composed of a header and a payload. The header contains information about the source and destination of the packet, as well as other control information. The payload contains the actual data being transmitted.
* IP supports a variety of protocols, including TCP, UDP, ICMP, and ARP. Each of these protocols has its own purpose and is used for different types of communication.
* IP routing is the process of forwarding IP packets from one device to another. Routers use routing tables to determine the best path to a destination.
* IP security is an important part of network security. It involves using encryption, authentication, and other methods to protect data as it is transmitted across the Internet.
