
### Domain Name System

- Domain Name System (DNS) is a distributed database system used to translate domain names (such as www.example.com) into IP addresses and vice versa.
- DNS is essential for the functioning of the modern internet, as it allows users to access websites using easily-memorized domain names rather than having to remember the IP addresses of each website.
- DNS is organized into a hierarchy of name servers, with the root name servers at the top of the hierarchy.
- Each domain name is associated with a set of name servers which are responsible for providing IP address information for that domain.
- DNS is also used for other services, such as email routing and content delivery networks.
