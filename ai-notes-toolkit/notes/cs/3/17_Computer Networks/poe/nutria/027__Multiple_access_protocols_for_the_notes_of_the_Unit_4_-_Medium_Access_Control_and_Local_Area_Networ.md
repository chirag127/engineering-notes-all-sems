
### Multiple Access Protocols 

1. **Aloha Protocol**: The Aloha protocol is a medium access control protocol developed at the University of Hawaii in the 1970s. It is a pure slotted system, in which a station transmits whenever it has data to send. It is a simple protocol and is used in satellite communications and radio networks.

2. **CSMA/CD**: Carrier Sense Multiple Access/Collision Detection (CSMA/CD) is a protocol used to access a shared network medium. It is used in Ethernet networks and is based on the idea that a station should listen before transmitting. If the channel is busy, the station will wait until it is free before attempting to transmit.

3. **CSMA/CA**: Carrier Sense Multiple Access/Collision Avoidance (CSMA/CA) is a protocol used to access a shared network medium. It is used in wireless networks and is based on the idea that a station should listen before transmitting. If the channel is busy, the station will wait until it is free before attempting to transmit.

4. **Token Passing**: Token passing is a network access protocol used in local area networks (LANs). It is based on the idea that a station should wait for a token before attempting to transmit. The station with the token has the right to transmit, and once it is done, it passes the token to the next station.

5. **Polling**: Polling is a network access protocol used in local area networks (LANs). It is based on the idea that a station should wait to be polled by the network before attempting to transmit. The network controller sends a poll message to the station, and the station responds with its data.
