
### RARP for the Notes of Unit 5 - Network Layer in Computer Networks

1. RARP (Reverse Address Resolution Protocol) is a protocol used by a host to request its IP address from a local router.

2. It is a broadcast-based protocol, meaning that the request is sent to all nodes in the local network.

3. The response from the router is sent to the requesting host, which then uses the IP address to configure its network interface.

4. RARP is typically used on diskless workstations and other devices that do not have a permanent IP address assigned.

5. The RARP protocol is part of the TCP/IP suite of protocols and is defined in RFC 903.
