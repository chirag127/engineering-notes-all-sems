
### Elementary Data Link Protocols

* **Data Link Layer** is the second layer of the OSI model. It is responsible for the transmission of data across a physical link.
* **Elementary Data Link Protocols** are protocols that are used to control the flow of data across the physical link.
* **Error Detection and Correction** is a key feature of Elementary Data Link Protocols. Error detection techniques are used to detect errors in the data that is transmitted across the link. Error correction techniques are used to correct the errors that are detected.
* **Flow Control** is another important feature of Elementary Data Link Protocols. Flow control techniques are used to ensure that the data is transmitted at a rate that the receiver can handle.
* **Access Control** is another feature of Elementary Data Link Protocols. Access control techniques are used to ensure that multiple devices can access the link without interfering with each other.
* **Link Layer Addressing** is used to identify the source and destination of the data that is transmitted across the link.
