
## Unit 6 - Transport Layer

1. The transport layer is responsible for the delivery of data between applications on different hosts.
2. It provides end-to-end communication services to applications and is responsible for the reliability of data delivery.
3. It provides services such as connection-oriented communication, flow control, and error control.
4. The transport layer uses two protocols for communication, namely the Transmission Control Protocol (TCP) and the User Datagram Protocol (UDP).
5. TCP is a connection-oriented protocol that provides reliable, in-order delivery of data.
6. UDP is a connectionless protocol that provides an unreliable delivery of data.
7. The transport layer also provides port numbers which are used to identify the applications on each host.
8. The transport layer provides services to the application layer such as multiplexing, demultiplexing, and segmentation.
