
### Forwarding and Delivery for Unit 5 - Network Layer

1. **Forwarding:** Forwarding is the process of moving packets from one network node to another. It is a fundamental process in computer networks and is typically implemented in the network layer of the OSI model. 

2. **Routing:** Routing is the process of determining the best path for a packet to take from one node to another. Routing is typically implemented in the network layer of the OSI model.

3. **Delivery:** Delivery is the process of ensuring that a packet is successfully transmitted from one node to another. Delivery is typically implemented in the network layer of the OSI model.

4. **Reliability:** Reliability is the process of ensuring that a packet is successfully received by its intended destination. Reliability is typically implemented in the network layer of the OSI model.

5. **Flow Control:** Flow control is the process of regulating the rate at which packets are sent from one node to another. Flow control is typically implemented in the network layer of the OSI model.
