
### Learning Bridge and Spanning Tree Algorithms for Unit 4 - Medium Access Control and Local Area Networks in Computer Networks 

* Bridges are layer 2 devices that connect two segments of a Local Area Network (LAN). They are used to extend the reach of the LAN by allowing devices on different segments to communicate with each other. 
* Spanning Tree Protocol (STP) is used to ensure that there are no loops in the network. It does this by electing a root bridge and then configuring the ports on each bridge so that only one path exists between two devices. 
* Bridges can also be used to filter traffic between two networks. This is done by configuring the bridge to only allow certain types of traffic to pass through. 
* Bridges can also be used to provide redundancy in the network. This is done by configuring multiple bridges in a loop so that if one bridge fails, the other bridges can still provide a path for the traffic.

* STP is a layer 2 protocol that works by exchanging messages between bridges to determine the best path for the data to travel. 
* STP works by electing a root bridge, which is the bridge with the lowest bridge ID. The root bridge then sends out BPDUs (Bridge Protocol Data Units) which contain information about the network topology.
