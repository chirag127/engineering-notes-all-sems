
### Layering Principles for Unit 1 - Introductory Concepts in Computer Networks 
1. **Layering** is a technique used in computer networking that divides a complex problem into smaller, more manageable parts. 
2. Each layer is responsible for a specific set of tasks and communicates with the layer above and below it. 
3. The layers are organized in a stack, with each layer adding services to the layer below it. 
4. The layers are designed to work together to provide a complete solution to the problem. 
5. The most common example of layering is the seven-layer Open Systems Interconnection (OSI) model. 
6. The OSI model is used to describe how data is transmitted over a network. 
7. Each layer in the OSI model has a specific purpose and is responsible for certain functions. 
8. The physical layer is responsible for transmitting and receiving data over the physical medium. 
9. The data link layer is responsible for providing reliable data transmission. 
10. The network layer is responsible for providing logical addressing and routing of data packets. 
11. The transport layer is responsible for providing reliable end-to-end communication. 
12. The session layer is responsible for establishing, managing, and terminating communication sessions. 
13. The presentation layer is responsible for translating data between the application layer and the network. 
14. The application layer is responsible for providing services to the user.
