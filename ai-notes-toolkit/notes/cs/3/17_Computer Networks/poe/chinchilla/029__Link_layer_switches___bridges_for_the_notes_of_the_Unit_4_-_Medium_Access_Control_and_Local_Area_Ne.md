### Link Layer Switches & Bridges

Link layer switches and bridges are essential networking devices that operate at the data link layer of the OSI model. They are responsible for connecting network segments and improving network performance by filtering and forwarding network traffic.

Here are some essential points to understand about link layer switches and bridges:

- Link layer switches and bridges operate at the data link layer (Layer 2) of the OSI model.
- They are used to connect network segments and improve network performance by filtering and forwarding network traffic.
- Link layer switches are more advanced than bridges and typically have more ports, higher throughput, and additional features such as VLAN support.
- Bridges are simpler devices that connect network segments and reduce network congestion by filtering out unnecessary traffic.
- Both switches and bridges use MAC addresses to forward network traffic.
- Switches and bridges operate in store-and-forward mode, which means they buffer incoming frames before they are transmitted to the next network segment.
- Link layer switches and bridges can be used to build local area networks (LANs) and wide area networks (WANs) by connecting multiple network segments.
- Some common features of link layer switches and bridges include port mirroring, VLAN support, link aggregation, and QoS (Quality of Service) support.
- Port mirroring is a feature that allows network administrators to monitor network traffic by copying all traffic from one switch port to another.
- VLAN support allows network administrators to create virtual LANs that can isolate network traffic and improve network security.
- Link aggregation allows multiple physical links to be combined into a single logical link, which can improve network performance and redundancy.
- QoS support allows network administrators to prioritize network traffic based on application or user requirements.

In summary, link layer switches and bridges are essential networking devices that operate at the data link layer of the OSI model. They are used to connect network segments and improve network performance by filtering and forwarding network traffic. Understanding the features and capabilities of these devices is essential for building and maintaining modern computer networks.
