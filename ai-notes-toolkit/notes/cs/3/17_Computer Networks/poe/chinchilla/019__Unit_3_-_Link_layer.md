## Unit 3 - Link layer

The link layer is the second layer in the OSI reference model and is responsible for providing reliable data transfer over a physical link between two devices. Here are some important points to understand about the link layer:

1. The link layer is responsible for transmitting data between devices on the same network segment.

2. It defines the format of the data transmitted over the network, including the packet headers and trailers.

3. The link layer provides error detection and correction mechanisms to ensure data integrity during transmission.

4. It also handles flow control, which is the process of regulating the flow of data between devices to prevent data loss or congestion.

5. The link layer is implemented in hardware, typically in network interface cards (NICs).

6. The link layer uses MAC (Media Access Control) addresses to identify devices on the network. MAC addresses are unique identifiers assigned to each NIC by the manufacturer.

7. The link layer supports both connection-oriented and connectionless communication.

8. Ethernet is the most commonly used link layer protocol in wired networks, while Wi-Fi is the most commonly used in wireless networks.

9. Other link layer protocols include Token Ring, FDDI (Fiber Distributed Data Interface), and ATM (Asynchronous Transfer Mode).

10. The link layer interacts with the physical layer, which is responsible for transmitting raw bits over the network medium.

Understanding the link layer is essential for building and maintaining reliable networks. It provides the foundation for higher-level protocols and applications to operate effectively.
