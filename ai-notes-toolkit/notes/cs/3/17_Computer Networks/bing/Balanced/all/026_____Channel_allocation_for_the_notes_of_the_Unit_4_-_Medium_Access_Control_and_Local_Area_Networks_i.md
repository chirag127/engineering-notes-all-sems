# Channel Allocation for the notes of the Unit 4 - Medium Access Control and Local Area Networks in the subject of Computer Networks

Channel allocation is a process in which a single channel is divided and allotted to multiple users in order to carry user specific tasks. Channel allocation techniques are used to efficiently utilize the available bandwidth and avoid interference among users. There are three main types of channel allocation techniques in computer networks:

- Static Channel Allocation (SCA): In this technique, a fixed number of channels or frequency bands are assigned to each user or cell in advance, regardless of the traffic demand or interference. This technique is simple and easy to implement, but it may result in low utilization and poor performance if the traffic is uneven or unpredictable .
- Dynamic Channel Allocation (DCA): In this technique, channels or frequency bands are not permanently assigned to any user or cell, but are allocated on demand according to the traffic and interference conditions. This technique can adapt to the changing traffic patterns and improve the utilization and performance, but it requires more complex and sophisticated algorithms and coordination among users or cells  .
- Hybrid Channel Allocation (HCA): In this technique, a combination of SCA and DCA is used to balance the advantages and disadvantages of both techniques. For example, some channels can be fixed for certain users or cells, while others can be dynamically allocated according to the traffic and interference conditions. This technique can provide more flexibility and efficiency, but it also requires more design and optimization efforts.

Some examples of channel allocation techniques in computer networks are:

- Frequency Division Multiple Access (FDMA): In this technique, the available bandwidth is divided into several frequency bands, and each user or cell is assigned one or more frequency bands for transmission and reception. This technique is simple and robust, but it may suffer from inter-channel interference and frequency-dependent fading.
- Time Division Multiple Access (TDMA): In this technique, the available bandwidth is divided into several time slots, and each user or cell is assigned one or more time slots for transmission and reception. This technique can avoid inter-channel interference and frequency-dependent fading, but it may suffer from synchronization and delay issues.
- Code Division Multiple Access (CDMA): In this technique, the available bandwidth is shared by all users or cells, and each user or cell is assigned a unique code for transmission and reception. This technique can achieve high spectral efficiency and robustness against interference and fading, but it may suffer from inter-code interference and complex receiver design.
- Carrier Sense Multiple Access (CSMA): In this technique, each user or cell senses the channel before transmitting, and defers the transmission if the channel is busy. This technique can reduce collisions and improve the throughput, but it may suffer from hidden and exposed terminal problems and random access delay.
- Token Passing: In this technique, a special message called a token is circulated among the users or cells in a predefined order, and only the user or cell that holds the token can transmit. This technique can avoid collisions and provide fair access, but it may suffer from token loss and single point of failure.
- Polling: In this technique, a central controller or a master user or cell polls each user or cell in a predefined order, and grants the transmission opportunity to the user or cell that has data to send. This technique can avoid collisions and provide priority access, but it may suffer from polling overhead and single point of failure.
