# Link layer switches and bridges

- Link layer switches and bridges are network devices that operate at the data link layer (layer 2) of the OSI model and forward data frames based on MAC addresses.
- They are used to connect multiple LANs together to form a larger LAN or to segment a LAN into smaller subnets for better performance and security.
- The main difference between a switch and a bridge is that a switch has multiple ports, while a bridge has only two ports.
- A switch can forward data frames to the specific port where the destination MAC address is located, while a bridge has to broadcast the frame to all ports except the source port.
- A switch can also perform filtering, learning, and aging functions to maintain a MAC address table that maps each MAC address to a port.
- A bridge can also perform these functions, but with a smaller MAC address table and less efficiency.
- Some switches can also operate at the network layer (layer 3) of the OSI model and forward data packets based on IP addresses. These switches are called layer 3 switches or multilayer switches.
- A layer 3 switch can also perform routing functions and support different network protocols and subnets.
- A wireless access point is a special type of bridge that connects a wired LAN to a wireless LAN. It can also act as a switch for wireless devices.
