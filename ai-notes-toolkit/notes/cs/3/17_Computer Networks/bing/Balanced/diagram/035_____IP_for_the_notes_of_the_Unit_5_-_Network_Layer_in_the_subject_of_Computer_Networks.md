### IP

- IP stands for Internet Protocol and is the network layer communications protocol in the Internet protocol suite for relaying datagrams across network boundaries .
- IP is responsible for addressing host interfaces, encapsulating data into datagrams (including fragmentation and reassembly) and routing datagrams from a source host interface to a destination host interface across one or more IP networks.
- IP information is attached to each packet, and this information helps routers to send packets to the correct destination.
- IP is a connectionless protocol, which means that it does not establish a connection before sending data, and it does not guarantee reliable delivery, order, or error checking of packets .
- IP uses a 32-bit or 128-bit address to identify each host interface, which is divided into network and host portions. The network portion is used to route packets to the destination network, and the host portion is used to identify the specific host within the network .
- IP supports two versions: IPv4 and IPv6. IPv4 is the most widely used version, but it has a limited address space of about 4.3 billion addresses. IPv6 is the newer version, which has a much larger address space of about 3.4×10^38 addresses and provides some additional features such as improved security and mobility .
- IP works with other protocols in the Internet protocol suite, such as TCP, UDP, ICMP, and ARP, to provide end-to-end communication between applications across the Internet .
