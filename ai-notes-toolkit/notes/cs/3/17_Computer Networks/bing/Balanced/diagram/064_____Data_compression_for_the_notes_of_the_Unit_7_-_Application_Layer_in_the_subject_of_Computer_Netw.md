- Data compression is the process of reducing the amount of data needed for the storage or transmission of a given piece of information, typically by the use of encoding techniques  .
- Data compression can save storage capacity, speed up file transfer and decrease costs for storage hardware and network bandwidth .
- Data compression can be either lossy or lossless. Lossy compression reduces the quality of the original data, while lossless compression preserves the exact data.
- Lossy compression is suitable for multimedia data, such as images, audio and video, where some loss of quality is acceptable. Lossless compression is suitable for text, documents and executable files, where any loss of data can cause errors or corruption.
- Some common data compression algorithms are:
  - Huffman coding: a lossless compression technique that assigns variable-length codes to symbols based on their frequencies.
  - Run-length encoding: a lossless compression technique that replaces repeated symbols with a count and a symbol.
  - Lempel-Ziv coding: a lossless compression technique that exploits the redundancy in the data by using a dictionary of previously seen patterns.
  - JPEG: a lossy compression technique for images that uses discrete cosine transform and quantization to reduce the number of bits per pixel.
  - MP3: a lossy compression technique for audio that uses psychoacoustic models and bit allocation to reduce the number of bits per sample.
  - MPEG: a lossy compression technique for video that uses motion estimation and compensation, discrete cosine transform and quantization to reduce the number of bits per frame.
