### Routing
- Routing is the process of finding a path from a source to a destination in a network of nodes.
- Routing can be classified into two types: static and dynamic.
- Static routing is when the routes are fixed and predetermined by the network administrator or the network design. Static routing is simple, fast, and reliable, but it cannot adapt to changes in the network topology or traffic conditions.
- Dynamic routing is when the routes are updated and changed according to the current network state. Dynamic routing is more flexible and scalable, but it requires more computation, communication, and memory resources.
- Routing can also be classified into two categories: unicast and multicast.
- Unicast routing is when a packet is sent from a source to a single destination. Unicast routing can use either shortest path algorithms or distance vector algorithms to find the optimal route.
- Shortest path algorithms are based on the global knowledge of the network topology and the link costs. They compute the shortest path from the source to every other node in the network using algorithms such as Dijkstra's or Bellman-Ford.
- Distance vector algorithms are based on the local knowledge of the neighboring nodes and their distances to the destination. They exchange distance vectors with their neighbors and update their routing tables using algorithms such as RIP or BGP.
- Multicast routing is when a packet is sent from a source to a group of destinations. Multicast routing can use either source-based trees or group-shared trees to deliver the packets.
- Source-based trees are constructed by the source node for each group. They use the shortest path from the source to each destination in the group. They have low delay and high bandwidth efficiency, but they require more storage and maintenance overhead.
- Group-shared trees are constructed by a designated node called the core or the rendezvous point for each group. They use the shortest path from the core to each destination in the group. They have low storage and maintenance overhead, but they may have higher delay and lower bandwidth efficiency.
