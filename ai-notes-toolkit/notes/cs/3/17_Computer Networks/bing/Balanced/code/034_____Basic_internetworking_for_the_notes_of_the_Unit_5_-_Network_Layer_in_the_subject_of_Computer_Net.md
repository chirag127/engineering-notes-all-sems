# Basic Internetworking

- Internetworking is the process of connecting different networks together to form a larger network, such as the Internet.
- Internetworking is implemented in the network layer of the OSI model, which is layer 3 .
- The network layer is responsible for routing packets of data across different networks, using logical addresses such as IP addresses .
- The network layer also provides services such as fragmentation, error control, congestion control, and quality of service.
- The network layer uses protocols such as IP, ICMP, ARP, RARP, and DHCP to perform its functions .
- The network layer can be divided into two sublayers: the internet layer and the transport layer.
- The internet layer handles the communication between hosts and networks, using IP addresses and routing algorithms.
- The transport layer handles the communication between processes on different hosts, using port numbers and transport protocols such as TCP and UDP.
