## Unit 2 - Physical Layer

The physical layer is the first and lowest layer of the Open Systems Interconnection (OSI) model of computer networking. It is responsible for sending bits from one device to another along the network using electrical, mechanical, or procedural interfaces.

Some of the main functions of the physical layer are:

- It defines the physical characteristics of the transmission medium, such as the type of cable, connectors, voltage levels, etc.
- It defines the encoding and modulation schemes that are used to represent bits into signals, such as binary, Manchester, NRZ, etc.
- It defines the data rate (how many bits a sender can send per second) and the bandwidth (the range of frequencies that can be used for transmission) of the channel.
- It performs synchronization of bits, which means that the sender and the receiver agree on a common clock signal to avoid errors due to timing differences.
- It performs error detection and correction, which means that the sender and the receiver use some techniques to detect and correct errors that may occur during transmission, such as parity check, CRC, etc.
- It performs multiplexing and demultiplexing, which means that the sender and the receiver use some methods to combine or separate multiple signals into one channel, such as FDM, TDM, WDM, etc.
- It performs transmission medium decision, which means that the sender and the receiver decide on the direction of data transfer, such as simplex, half-duplex, or full-duplex.
- It performs physical topology decision, which means that the sender and the receiver decide on the shape of the network, such as mesh, star, bus, ring, etc .

The physical layer is a fundamental layer underlying the higher level functions in a network, and can be implemented through a great number of different hardware technologies with widely varying characteristics. Some examples of physical layer devices are hubs, repeaters, cables, connectors, etc.
