### Network devices and components

Network devices and components are the physical or logical entities that enable communication and data transfer among different devices in a network. They can be classified into two main categories: inter-network devices and intra-network devices.

- Inter-network devices are the ones that are mounted within the device, such as a network interface card (NIC) or an RJ45 connector. They allow the device to connect to the network media, such as a cable or a wireless signal.
- Intra-network devices are the ones that are internal components of the network, such as switches, routers, hubs, repeaters, gateways, bridges, and servers. They perform different functions in the network, such as forwarding, routing, filtering, amplifying, translating, or providing services to the connected devices.

Some of the basic network devices and components are:

- Sender: The device that initiates the communication or data transfer in the network, such as a computer, a smartphone, or a printer.
- Receiver: The device that receives the communication or data transfer in the network, such as a computer, a smartphone, or a printer.
- End Point: The device that is either the source or the destination of the communication or data transfer in the network, such as a sender or a receiver.
- Network Interface Card (NIC): The hardware component that allows a device to connect to the network media and communicate with other devices in the network. It has a unique address called a MAC address that identifies the device in the network.
- Network Media: The physical or wireless medium that carries the communication or data transfer signals in the network, such as a twisted pair cable, a coaxial cable, a fiber optic cable, or a radio wave.
- Connectors: The hardware components that connect the network media to the network devices, such as an RJ45 connector, a BNC connector, or an ST connector.
- Switch: The network device that forwards the communication or data transfer signals to the appropriate destination device based on the MAC address. It creates a separate collision domain for each connected device, which reduces network congestion and improves network performance.
- Router: The network device that forwards the communication or data transfer signals to the appropriate destination network based on the IP address. It creates a separate broadcast domain for each connected network, which reduces network traffic and improves network security.
- Hub: The network device that forwards the communication or data transfer signals to all the connected devices in the network. It creates a single collision domain and a single broadcast domain for all the connected devices, which increases network congestion and reduces network performance.
- Repeater: The network device that amplifies the communication or data transfer signals in the network. It extends the range of the network media and prevents signal degradation due to attenuation or interference.
- Gateway: The network device that translates the communication or data transfer signals between different network protocols, such as TCP/IP, IPX/SPX, or AppleTalk. It enables communication and data transfer among different types of networks, such as LAN, WAN, or MAN.
- Bridge: The network device that filters the communication or data transfer signals based on the MAC address. It divides a large network into smaller segments, which reduces network congestion and improves network performance.
- Server: The network device that provides services to the connected devices in the network, such as file sharing, web hosting, email, or printing. It has a high processing power, memory, and storage capacity to handle multiple requests from the network devices.
