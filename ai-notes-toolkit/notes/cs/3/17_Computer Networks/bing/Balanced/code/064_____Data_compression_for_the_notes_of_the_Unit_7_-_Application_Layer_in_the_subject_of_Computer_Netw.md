### Data compression

- Data compression is the process of reducing the amount of data needed for the storage or transmission of a given piece of information, typically by the use of encoding techniques.
- Data compression can be performed by using smaller strings of bits (0s and 1s) in place of the original string and using a ‘dictionary’ to decompress the data if required. Other techniques include the introduction of pointers (references) to a string of bits that the compression program has become familiar with or removing redundant characters.
- Data compression can be broadly classified into two types: lossless and lossy.
  - Lossless compression: It is a compression technique that preserves the original data without any loss of information. It is suitable for text, audio, and some image data that require high fidelity. The various algorithms used to implement lossless data compression are:
    - Run length encoding: It is a technique that replaces consecutive identical characters or symbols with a single character and a count of its repetitions. For example, the string "AAAAABBBBCCCC" can be compressed as "5A4B4C".
    - Differential pulse code modulation: It is a technique that encodes the difference between successive samples of a signal, rather than the absolute values. This reduces the number of bits needed to represent the signal, as the differences are usually smaller than the original values.
    - Dictionary based encoding: It is a technique that uses a predefined dictionary of common strings or symbols and replaces them with shorter codes. For example, the string "the quick brown fox jumps over the lazy dog" can be compressed as "1 2 3 4 5 6 7 8 9", where the dictionary is {"the":1, "quick":2, "brown":3, "fox":4, "jumps":5, "over":6, "lazy":7, "dog":8, " ":9}.
  - Lossy compression: It is a compression technique that discards some information from the original data, resulting in some loss of quality or accuracy. It is suitable for image, video, and some audio data that can tolerate some distortion. The various algorithms used to implement lossy data compression are:
    - JPEG: It is a technique that compresses images by dividing them into blocks of pixels and applying a discrete cosine transform (DCT) to each block. The DCT coefficients are then quantized and encoded using Huffman coding or arithmetic coding. The quantization step introduces some loss of information, as some coefficients are rounded off or set to zero.
    - MPEG: It is a technique that compresses video by exploiting the temporal and spatial redundancy in the frames. It uses motion estimation and compensation to encode the difference between successive frames, rather than the absolute values. It also uses DCT, quantization, and Huffman coding or arithmetic coding to compress the frames. The motion estimation and quantization steps introduce some loss of information, as some details are ignored or approximated.
    - MP3: It is a technique that compresses audio by applying a psychoacoustic model to the signal. The psychoacoustic model determines which frequencies are perceptible by the human ear and discards the ones that are not. It also uses DCT, quantization, and Huffman coding or arithmetic coding to compress the signal. The psychoacoustic model and quantization steps introduce some loss of information, as some sounds are masked or distorted.

- Data compression can be applied at different layers of the network, depending on the type and purpose of the data. For example, data compression can be applied at the application layer for specific applications, such as web browsing, email, or file transfer. Data compression can also be applied at the data link layer or the physical layer for general data transmission, such as in modems or routers.
- Data compression can have various benefits and drawbacks, depending on the type and degree of compression. Some of the benefits are:
  - Reduced storage space: Data compression can save disk space or memory by storing or caching compressed data.
  - Reduced transmission time: Data compression can reduce the bandwidth or the number of bits needed to transmit data over a network, resulting in faster data transfer or lower communication costs.
  - Reduced processing time: Data compression can reduce the computational complexity or the number of operations needed to process data, resulting in faster data processing
