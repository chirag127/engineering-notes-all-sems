### World Wide Web and Hyper Text Transfer Protocol

- The World Wide Web (WWW) is a system of interlinked hypertext documents that can be accessed via the Internet using a web browser.
- A hypertext document is a text file that contains links to other documents or resources, such as images, videos, or audio files.
- The links in a hypertext document are called hyperlinks, and they allow users to navigate from one document to another by clicking on them.
- The WWW was invented by Tim Berners-Lee and his team at CERN in 1989-1991, and it is one of the most popular applications of the Internet.
- The HyperText Transfer Protocol (HTTP) is the foundation of the WWW, and it is used to load webpages using hypertext links.
- HTTP is an application layer protocol that runs on top of other layers of the network protocol stack, such as TCP/IP.
- HTTP defines how a client (such as a web browser) and a server (such as a web server) communicate and exchange information over the Internet.
- HTTP uses a request-response model, where the client sends a request message to the server, and the server sends back a response message to the client.
- A request message consists of a method, a URL, and optional headers and body. A method indicates the action that the client wants the server to perform, such as GET, POST, PUT, or DELETE. A URL specifies the location of the resource that the client wants to access, such as https://www.example.com/index.html. Headers provide additional information about the request, such as the content type, the user agent, or the cookies. The body contains the data that the client wants to send to the server, such as form inputs or file uploads.
- A response message consists of a status code, optional headers, and optional body. A status code indicates the result of the request, such as 200 OK, 404 Not Found, or 500 Internal Server Error. Headers provide additional information about the response, such as the content type, the server name, or the cache control. The body contains the data that the server wants to send to the client, such as the webpage content, an image, or an error message.
- HTTP is a stateless protocol, which means that each request and response are independent and do not keep track of the previous or subsequent ones. However, HTTP can use cookies to store and retrieve state information, such as user preferences, session IDs, or authentication tokens.
- HTTP has evolved over time to improve its performance, security, and functionality. The original version of HTTP was HTTP/0.9, which only supported the GET method and plain text responses. The current version of HTTP is HTTP/2, which supports multiple requests and responses in parallel, binary framing, header compression, server push, and stream prioritization. The next version of HTTP is HTTP/3, which is based on the QUIC protocol and uses UDP instead of TCP as the transport layer.
