### Basic internetworking for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- The network layer is the part of the Internet communications process where packets of data are sent back and forth between different networks.
- The network layer is also called the Internet layer in the TCP/IP model, which is a simpler and more widely used model than the OSI model.
- The network layer is responsible for routing, addressing, fragmentation, and error control of packets.
- An internetwork is an interconnected collection of physical networks that use a common protocol to communicate.
- An internetwork can be classified into three types based on who administers and who participates in them: intranet, extranet, and internet.
- An intranet is a private internetwork that is accessible only to authorized users within an organization.
- An extranet is a semi-private internetwork that is accessible to authorized users from outside an organization, such as business partners or customers.
- An internet is a public internetwork that is accessible to anyone with a network device and an Internet service provider (ISP).
- The most notable example of an internet is the Internet (capitalized), which is a global network of networks that uses the TCP/IP protocol suite.
- Internetworking requires three kinds of addresses: data-link layer addresses, network-layer addresses, and media access control (MAC) addresses.
- Data-link layer addresses are used to identify each physical network connection of a network device, such as a network interface card (NIC).
- Network-layer addresses are used to identify each logical network connection of a network device, such as an IP address.
- MAC addresses are used to identify each network device uniquely, such as a router or a switch.
- Internetworking also requires devices that can interconnect different networks, such as routers, gateways, and bridges.
- Routers are devices that can forward packets between networks based on network-layer addresses.
- Gateways are devices that can translate packets between networks that use different protocols.
- Bridges are devices that can forward packets between networks that use the same protocol but have different data-link layer formats.
