### Goals and applications of networks

- A network is a collection of devices that can communicate with each other through a shared medium or channel.
- The main goals of networks are to enable data exchange, resource sharing, and distributed computing among the devices.
- Some of the applications of networks are:

  - Email: Allows users to send and receive messages across the network.
  - Web: Allows users to access and publish information on the network using a browser and a server.
  - File transfer: Allows users to upload and download files from the network using a client and a server.
  - Streaming: Allows users to watch or listen to media content on the network using a player and a source.
  - Voice over IP: Allows users to make and receive voice calls on the network using a phone and a gateway.
  - Online gaming: Allows users to play games with other users on the network using a console and a server.
  - Social networking: Allows users to create and maintain profiles, contacts, and groups on the network using a platform and a server.
  - Cloud computing: Allows users to access and use computing resources on the network using a device and a provider.
