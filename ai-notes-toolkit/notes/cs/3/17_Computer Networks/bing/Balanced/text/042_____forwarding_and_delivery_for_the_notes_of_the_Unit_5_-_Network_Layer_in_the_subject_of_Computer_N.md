### Forwarding and Delivery for the Notes of the Unit 5 - Network Layer in the Subject of Computer Networks

- The network layer is responsible for the delivery of packets from the source host to the destination host across one or more networks.
- The network layer provides two main functions: forwarding and routing.
- Forwarding is the process of moving a packet from an input interface to an output interface of a router based on the destination address of the packet.
- Routing is the process of finding the best path from the source to the destination in the network.
- The delivery of a packet can be direct or indirect.
  - Direct delivery occurs when the source and destination hosts are on the same network and the packet is delivered directly to the destination host.
  - Indirect delivery occurs when the source and destination hosts are on different networks and the packet is delivered through one or more intermediate routers.
- The network layer can use different protocols to perform forwarding and routing, such as IP, IPsec, ICMP, IGMP, and GRE.
  - IP (Internet Protocol) is the main protocol that provides logical addressing and fragmentation of packets.
  - IPsec (Internet Protocol Security) is a protocol that provides security services such as encryption and authentication for IP packets.
  - ICMP (Internet Control Message Protocol) is a protocol that provides error and control messages for IP packets.
  - IGMP (Internet Group Management Protocol) is a protocol that supports multicast communication in IP networks.
  - GRE (Generic Routing Encapsulation) is a protocol that encapsulates packets of one protocol into another protocol for tunneling purposes.
