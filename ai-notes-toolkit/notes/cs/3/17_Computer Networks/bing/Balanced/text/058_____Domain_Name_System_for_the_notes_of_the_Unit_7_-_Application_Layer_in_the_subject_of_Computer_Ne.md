### Domain Name System

- The Domain Name System (DNS) is a method for mapping alphabetic names to numeric IP addresses on the Internet, similar to how a phone book maps a person's name to a phone number.
- DNS is a hierarchical and decentralized naming system that allows computers, servers, services, resources, network devices and components to be identified and located on large networks such as the public Internet .
- A network domain is an administrative grouping of multiple private computer networks or local hosts within the same infrastructure. Domains can be identified using a domain name; domains which need to be accessible from the public Internet can be assigned a globally unique name within the Domain Name System (DNS).
- A domain name consists of one or more labels, each separated by a dot. The right-most label is called the top-level domain (TLD), such as .com, .org, .net, etc. The second-level domain (SLD) is the label to the left of the TLD, such as google.com, wikipedia.org, etc. The labels to the left of the SLD are called subdomains, such as mail.google.com, en.wikipedia.org, etc.
- Domain names can be internationalized using special characters from different scripts or languages, such as ümlaut.com, 中文网.cn, etc. However, these domain names are encoded using ASCII characters in a format called Punycode, such as xn--mlaut-6qa.com, xn--fiq228c.com, etc.
- Name servers are the servers that store and provide the domain name to IP address mappings. There are different types of name servers, such as authoritative name servers, recursive name servers, caching name servers, etc.
- An authoritative name server is the name server that has the original and definitive data for a domain name. It is responsible for answering queries from other name servers or resolvers about its domain name and its subdomains.
- A recursive name server is the name server that queries other name servers on behalf of a client (such as a web browser) until it finds the IP address for the requested domain name. It may also cache the results of previous queries to speed up the process.
- A caching name server is the name server that stores the results of previous queries in a local cache for a certain period of time. It can answer queries from its cache without contacting other name servers, reducing the network traffic and latency.
- A DNS resolver is the software component that initiates and performs the queries to the name servers on behalf of a client. It may be part of the operating system, the web browser, or a separate application.
- A circular dependency occurs when two or more name servers depend on each other to resolve a domain name. For example, if ns1.example.com and ns2.example.com are the name servers for example.com, and ns1.example.com has the IP address of ns2.example.com, and vice versa, then there is a circular dependency. To avoid this problem, glue records are used, which are additional records that provide the IP addresses of the name servers along with the domain name.
- Record caching is the process of storing the results of previous queries in a local cache for a certain period of time. It can improve the performance and efficiency of the DNS system by reducing the network traffic and latency. However, it can also cause problems when the data changes and the cache becomes outdated. To prevent this, each record has a time-to-live (TTL) value, which specifies how long the record can be cached before it expires and needs to be refreshed.
- Reverse lookup is the process of finding the domain name associated with an IP address. It is done using a special domain name called in-addr.arpa for IPv4 addresses and ip6.arpa for IPv6 addresses. For example, to find the domain name for the IP address 192.168.1.1, a reverse lookup query is made for 1.1.168.192.in-addr.arpa.
- Client lookup is the process of finding the IP address associated with a domain name. It is done by sending a query to a recursive name server, which then contacts other name servers until it finds the answer. The answer may be cached by the recursive name server or the client for future use.
