## Unit 6 - Transport Layer

- The transport layer is the fourth layer of the OSI model, which provides end-to-end communication between processes running on different hosts in a network.
- The transport layer performs the following functions and services:
  - Data transfer: The transport layer ensures that the data is delivered reliably and in the correct order from the source to the destination. It can use error detection, error correction, retransmission, and acknowledgment mechanisms to achieve this.
  - Bandwidth guarantees: The transport layer can provide quality of service (QoS) guarantees for the data transfer, such as minimum bandwidth, maximum delay, and maximum jitter. It can use flow control, congestion control, and reservation protocols to achieve this.
  - Delay guarantees: The transport layer can also provide delay guarantees for the data transfer, such as maximum end-to-end delay and maximum delay variation. It can use buffering, scheduling, and prioritization techniques to achieve this.
  - Multiplexing/de-multiplexing: The transport layer can multiplex multiple data streams from different processes or applications into a single data stream for transmission, and de-multiplex the received data stream into separate data streams for different processes or applications. It can use port numbers, sequence numbers, and headers to achieve this.
  - Connection management: The transport layer can establish, maintain, and terminate connections between processes or applications. It can use connection-oriented or connectionless protocols to achieve this.
- The transport layer uses different protocols to provide different levels of services and functionalities, such as TCP, UDP, SPX, DCCP, and SCTP.
  - TCP (Transmission Control Protocol): TCP is a connection-oriented, reliable, and secure protocol that provides data transfer, bandwidth guarantees, delay guarantees, and multiplexing/de-multiplexing services. TCP uses a three-way handshake to establish a connection, a sliding window mechanism to control the flow and congestion of data, and a four-way handshake to terminate a connection. TCP is used by various applications, such as HTTP, FTP, SMTP, and SSH.
  - UDP (User Datagram Protocol): UDP is a connectionless, unreliable, and insecure protocol that provides data transfer and multiplexing/de-multiplexing services. UDP does not use any mechanism to ensure the reliability, order, or security of data, and does not provide any QoS guarantees. UDP is used by applications that require low latency, high throughput, or real-time communication, such as DNS, DHCP, RTP, and VoIP.
  - SPX (Sequenced Packet Exchange): SPX is a connection-oriented, reliable, and secure protocol that provides data transfer and multiplexing/de-multiplexing services. SPX is based on IPX (Internetwork Packet Exchange), which is a network layer protocol for Novell NetWare networks. SPX uses sequence numbers and acknowledgments to ensure the reliability and order of data, and encryption and authentication to ensure the security of data. SPX is used by applications that run on Novell NetWare networks, such as NCP, SAP, and RIP.
  - DCCP (Datagram Congestion Control Protocol): DCCP is a connection-oriented, unreliable, and secure protocol that provides data transfer and congestion control services. DCCP is designed for applications that require congestion control but can tolerate some loss or reordering of data, such as multimedia streaming, online gaming, and telephony. DCCP uses a half-connection mechanism to establish a connection, a congestion control identifier (CCID) to select a suitable congestion control algorithm, and a reset mechanism to terminate a connection. DCCP is used by applications that use RTP, such as SIP and RTSP.
  - SCTP (Stream Control Transmission Protocol): SCTP is a connection-oriented, reliable, and secure protocol that provides data transfer, bandwidth guarantees, delay guarantees, and multiplexing/de-multiplexing services. SCTP is designed for applications that require multiple streams of data within a single connection, such as web browsing, email, and file transfer. SCTP uses a four-way handshake to establish a connection, a stream identifier (SID) to identify different streams of data, and a shutdown mechanism to terminate a connection. SCTP is used by applications that use HTTP, SMTP, and FTP.
