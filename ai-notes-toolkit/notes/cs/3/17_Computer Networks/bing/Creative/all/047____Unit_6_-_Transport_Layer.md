## Unit 6 - Transport Layer

- The transport layer is the fourth layer of the OSI model and the third layer of the TCP/IP model. It provides end-to-end communication services for applications, such as error control, flow control, segmentation, reassembly, multiplexing, and demultiplexing.
- The transport layer is responsible for ensuring that data is delivered reliably and efficiently from the source to the destination, regardless of the underlying network layer protocols and technologies.
- The transport layer uses two main protocols: Transmission Control Protocol (TCP) and User Datagram Protocol (UDP). TCP is a connection-oriented protocol that provides reliable, ordered, and error-free delivery of data. UDP is a connectionless protocol that provides fast, unordered, and unreliable delivery of data.
- The transport layer uses port numbers to identify different applications and services on the same host. Port numbers are 16-bit numbers that range from 0 to 65535. Well-known port numbers are assigned by the Internet Assigned Numbers Authority (IANA) to standard services, such as HTTP (80), FTP (21), and SSH (22). Dynamic port numbers are allocated by the operating system to applications that request them.
- The transport layer segments the data received from the application layer into smaller units called segments (for TCP) or datagrams (for UDP). Each segment or datagram contains a header and a payload. The header contains information such as the source and destination port numbers, the sequence number, the acknowledgment number, the checksum, and the flags. The payload contains the application data.
- The transport layer reassembles the segments or datagrams received from the network layer into the original data stream and delivers it to the application layer. The transport layer uses sequence numbers and acknowledgment numbers to ensure that all segments or datagrams are received in the correct order and without errors. The transport layer also uses checksums to detect any corruption in the segments or datagrams.
- The transport layer provides flow control to prevent the sender from overwhelming the receiver with too much data. The transport layer uses a sliding window mechanism to regulate the amount of data that can be sent and received at any time. The transport layer also uses congestion control to adjust the sending rate based on the network conditions and avoid congestion collapse.
- The transport layer provides multiplexing and demultiplexing to enable multiple applications and services to share the same network connection. The transport layer uses port numbers to distinguish between different applications and services on the same host and to direct the segments or datagrams to the appropriate application or service.
