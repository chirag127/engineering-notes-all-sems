# Process-to-process delivery

- Process-to-process delivery is the function of the transport layer in computer networks  .
- It is the delivery of the entire message from a source process to a destination process .
- A process is an application program that is running on the host .
- There might be more than one process running on the same host, each identified by a port number.
- The transport layer is responsible for multiplexing and demultiplexing the data from different processes using port numbers  .
- The transport layer also provides error control, flow control, congestion control, and reliability services for the data transmission.
- The transport layer protocols in the Internet model are UDP, TCP, and SCTP.
- UDP is a connectionless and unreliable protocol that provides minimal services .
- TCP is a connection-oriented and reliable protocol that provides full-duplex, byte-stream, and sliding window services .
- SCTP is a connection-oriented and reliable protocol that provides message-oriented, multi-streaming, and multi-homing services.
