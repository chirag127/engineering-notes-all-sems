# Electronic Mail

Electronic mail, or email, is a computer-based application for the exchange of messages between users over the internet. Here are some points to note about email:

- An email address is a unique identifier for each user, typically in the format of name@domain.com.
- An email message consists of a header and a body. The header contains information such as the sender, the recipient, the subject, the date, and the priority. The body contains the actual content of the message, which can be text, images, attachments, or other formats.
- An email system consists of three main components: user agents, mail servers, and protocols.
  - A user agent is a software program that allows a user to compose, send, receive, and read email messages. Examples of user agents are Gmail, Outlook, Thunderbird, etc.
  - A mail server is a computer that stores and forwards email messages. Each domain (such as gmail.com or outlook.com) has one or more mail servers that handle the email traffic for that domain. A mail server can act as both a sender and a receiver of email messages.
  - A protocol is a set of rules that governs the communication between mail servers and user agents. The two main protocols for email are Simple Mail Transfer Protocol (SMTP) and Post Office Protocol (POP) or Internet Message Access Protocol (IMAP).
    - SMTP is used to send email messages from a user agent to a mail server, or from one mail server to another. SMTP uses port 25 by default and operates in a store-and-forward manner.
    - POP and IMAP are used to retrieve email messages from a mail server to a user agent. POP downloads the messages to the user agent and deletes them from the mail server, while IMAP synchronizes the messages between the user agent and the mail server. POP uses port 110 by default and IMAP uses port 143 by default.
- Email is one of the most widely used applications on the internet, but it also has some limitations and challenges, such as spam, phishing, security, privacy, and reliability.
