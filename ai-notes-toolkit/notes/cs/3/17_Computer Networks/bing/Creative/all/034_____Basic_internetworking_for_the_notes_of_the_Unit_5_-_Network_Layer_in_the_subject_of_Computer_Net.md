# Basic Internetworking

- Basic internetworking is the process of connecting different physical networks to form a logical network, such as the Internet .
- Basic internetworking is implemented in the network layer (layer 3) of the OSI model or the Internet layer (layer 2) of the TCP/IP model .
- Basic internetworking involves the following components and concepts  :
  - **Physical networks**: The underlying networks that are interconnected, such as LANs, WANs, MANs, etc. They use different data link layer protocols, such as Ethernet, Wi-Fi, ATM, etc.
  - **Routers**: The devices that forward packets between different physical networks based on their network layer addresses, such as IP addresses. Routers have multiple interfaces, each connected to a different physical network.
  - **Internetwork**: The interconnected collection of physical networks, such as the Internet. An internetwork is a logical network that provides end-to-end communication between hosts across different physical networks.
  - **Network layer protocols**: The protocols that operate in the network layer and provide internetworking functions, such as addressing, routing, fragmentation, error control, etc. Examples of network layer protocols are IP, ICMP, ARP, etc.
  - **Network layer addresses**: The addresses that uniquely identify each host or interface in an internetwork, such as IP addresses. Network layer addresses are independent of data link layer addresses, such as MAC addresses. Network layer addresses are used by routers to forward packets to their destinations.
