### Learning bridge and spanning tree algorithms for the notes of the Unit 4 - Medium Access Control and Local Area Networks in the subject of Computer Networks

- Bridges are devices that connect two or more LAN segments and forward frames based on the destination MAC address. Bridges can create a larger network by joining multiple LANs and reduce collisions by dividing the network into smaller collision domains.
- Bridges can also create loops in the network topology, which can cause problems such as broadcast storms, multiple frame copies, and inconsistent MAC address tables. To avoid these problems, bridges need to run a protocol that can detect and eliminate loops in the network.
- Spanning tree protocol (STP) is a network protocol that builds a loop-free logical topology for Ethernet networks. The basic function of STP is to prevent bridge loops and the broadcast radiation that results from them. Spanning tree also allows a network design to include backup links providing fault tolerance if an active link fails.
- STP works by creating a spanning tree, which is a subset of the network that contains all the nodes but no loops. A spanning tree is a tree because it has no cycles, and it spans the network because it connects all the nodes. A spanning tree can be constructed by using a distributed algorithm that runs on each bridge in the network.
- The spanning tree algorithm, which was developed by Radia Perlman at the Digital Equipment Corporation, is based on the following steps:
  - Each bridge has a unique identifier (ID) and assigns a cost to each of its ports based on the link speed. The bridge with the lowest ID is elected as the root bridge of the network. The root bridge is the reference point for the spanning tree construction.
  - Each bridge determines its root port, which is the port that has the lowest cost path to the root bridge. The root bridge has no root port, as it is the root of the spanning tree.
  - Each bridge determines its designated port, which is the port that has the lowest cost path to the root bridge among all the ports on the same LAN segment. The designated port is responsible for forwarding frames to and from the root bridge on that segment. The root bridge has all its ports as designated ports, as it is the closest to itself on every segment.
  - All the ports that are neither root ports nor designated ports are blocked, which means they do not forward any frames. Blocked ports are used to break loops in the network topology.
  - The resulting set of root ports and designated ports forms the spanning tree, which is a loop-free subset of the network that connects all the bridges and LAN segments.
- The bridges that participate in spanning tree protocol are often called spanning tree bridges. To construct and maintain the spanning tree, the bridges exchange configuration messages called bridge protocol data units (BPDUs) out of all their ports to their neighbors. BPDUs contain information such as the bridge ID, the root bridge ID, the cost to the root bridge, and the port ID. BPDUs are used to carry out STP operations such as electing the root bridge, determining the root port and the designated port, and detecting topology changes.
- The spanning tree algorithm is dynamic, so if an outage occurs then the spanning tree is recomputed. If the outage should partition the network into two pieces, both pieces will build spanning trees. All bridges send out regular BPDUs on all interfaces to keep the spanning tree updated. If a bridge does not receive a BPDU from a neighbor for a certain period of time, it assumes that the link has failed and initiates a topology change notification (TCN) to inform the other bridges of the change. The bridges then adjust their port states and BPDUs accordingly to form a new spanning tree.
