### Routing algorithms and protocols for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- Routing is the process of finding and selecting the best path for data transmission from source to destination in a computer network.
- Routing algorithms are the software programs that implement the logic of routing, i.e., they decide the optimal path for each packet based on some criteria or metric.
- Routing protocols are the set of rules and procedures that routers use to communicate with each other and exchange routing information.
- Routing algorithms and protocols can be classified into two main categories: static and dynamic.
  - Static routing algorithms and protocols are those that do not change the routing table unless the network administrator manually updates it. They are simple, fast, and secure, but they cannot adapt to network changes or failures.
  - Dynamic routing algorithms and protocols are those that update the routing table automatically based on the current network conditions, such as traffic, congestion, link failures, etc. They are more complex, slower, and less secure, but they can adapt to network changes or failures.
- Routing algorithms and protocols can also be classified based on the scope of their operation: intra-domain and inter-domain.
  - Intra-domain routing algorithms and protocols are those that operate within a single autonomous system (AS), which is a group of routers under the same administrative control. They are also called interior gateway protocols (IGPs).
  - Inter-domain routing algorithms and protocols are those that operate between different autonomous systems. They are also called exterior gateway protocols (EGPs).
- Some of the common routing algorithms and protocols are  :
  - Distance vector routing algorithm and protocol: This algorithm and protocol use the hop count (the number of routers along the path) as the metric to find the shortest path. Each router maintains a vector (a table) of the distances to all other routers in the network and periodically exchanges it with its neighbors. An example of a distance vector routing protocol is the Routing Information Protocol (RIP) .
  - Link state routing algorithm and protocol: This algorithm and protocol use the link cost (a measure of the quality or performance of a link) as the metric to find the lowest cost path. Each router maintains a complete map of the network topology and the link costs and periodically floods it to all other routers in the network. An example of a link state routing protocol is the Open Shortest Path First (OSPF) protocol .
  - Path vector routing algorithm and protocol: This algorithm and protocol use the path (a sequence of ASes along the path) as the metric to find the best path. Each router maintains a vector (a table) of the paths to all other routers in the network and periodically exchanges it with its neighbors. An example of a path vector routing protocol is the Border Gateway Protocol (BGP) .
  - Hierarchical routing algorithm and protocol: This algorithm and protocol use a hierarchical structure of the network to reduce the size and complexity of the routing table. Each router maintains a table of the distances to all other routers in its own level and the next higher level. An example of a hierarchical routing protocol is the Intermediate System to Intermediate System (IS-IS) protocol .
