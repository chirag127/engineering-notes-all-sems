### Logical Addressing

Logical addressing is a scheme of addressing that allows computers to communicate over a network using a global addressing scheme. Logical addresses are also called internet protocol (IP) addresses, and they are assigned by the network layer of the TCP/IP protocol stack. Logical addresses are software-based and can be different from the physical addresses of the network devices, which are hardware-based and assigned by the data link layer. Logical addresses are translated into physical addresses by a function called address resolution protocol (ARP) before the data is sent over the network.

Some features and functions of logical addressing are:

- Logical addresses are hierarchical, meaning they are divided into two parts: network id and host id. The network id identifies the network to which the host belongs, and the host id identifies the specific host within the network. The network id and host id can have different lengths depending on the class of the address.
- Logical addresses are unique, meaning no two hosts on the internet can have the same logical address. This ensures that the data can be delivered to the correct destination without ambiguity.
- Logical addresses are portable, meaning they can be changed or moved from one network to another without affecting the physical address of the host. This allows hosts to communicate across different networks using routers, which are devices that forward data based on the logical address.
- Logical addresses are dynamic, meaning they can be assigned or released automatically by a server called dynamic host configuration protocol (DHCP) when a host joins or leaves a network. This simplifies the management and allocation of logical addresses.

In this diagram, there are three networks: A, B, and C. Each network has a different network id, which is the first part of the logical address. For example, network A has a network id of 10.0.0.0, network B has a network id of 20.0.0.0, and network C has a network id of 30.0.0.0. The second part of the logical address is the host id, which identifies the specific host within the network. For example, host 1 in network A has a host id of 1, host 2 in network B has a host id of 2, and host 3 in network C has a host id of 3. The logical address of each host is the combination of the network id and the host id. For example, the logical address of host 1 in network A is 10.0.0.1, the logical address of host 2 in network B is 20.0.0.2, and the logical address of host 3 in network C is 30.0.0.3.

When a host wants to communicate with another host on the same network, it can use the logical address directly. For example, if host 1 in network A wants to send data to host 4 in network A, it can use the logical address 10.0.0.4 as the destination address. However, when a host wants to communicate with another host on a different network, it needs to use a router, which is a device that connects different networks and forwards data based on the logical address. For example, if host 1 in network A wants to send data to host 2 in network B, it needs to use the logical address 20.0.0.2 as the destination address, and the router will forward the data to the appropriate network. The router has two or more interfaces, each with a different logical address and a different physical address. The physical address is the hardware-based address of the network device, which is usually a 48-bit number represented by hexadecimal digits. The physical address is also called the media access control (MAC) address, and it is assigned by the data link layer of the TCP/IP protocol stack. The physical address is used to identify the network device at the link level, and it is not changed by the router. The physical address of each host and each interface of the router is shown in the diagram as well.

Before the data is sent over the network, the logical address of the destination host needs to be translated into the physical address of the next hop, which is either the destination host itself or the router interface. This translation is done by a function called address resolution protocol (ARP), which is a protocol that maps logical addresses to physical addresses.
