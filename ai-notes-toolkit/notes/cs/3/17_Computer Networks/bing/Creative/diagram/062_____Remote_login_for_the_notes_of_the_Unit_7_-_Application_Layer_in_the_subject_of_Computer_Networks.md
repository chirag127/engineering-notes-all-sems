### Remote login

- Remote login is a process in which a user can log on to a remote computer and use the services and applications that are available on that computer.
- Remote login is one of the functions of the application layer in the OSI model, which is the layer that interacts with the user and the presentation layer.
- Remote login requires a protocol that can establish a connection between the local and the remote computer, and transfer the user's keystrokes and the remote computer's output.
- One of the most common protocols for remote login is Telnet, which stands for Terminal Network.
- Telnet uses a client-server model, where the user's computer is the client and the remote computer is the server.
- Telnet operates on port 23 of the transport layer, and uses TCP as the underlying protocol.
- Telnet is a simple and unencrypted protocol, which means that the data exchanged between the client and the server is not secure and can be intercepted by attackers.
- Other protocols that can be used for remote login are Secure Shell (SSH), Remote Desktop Protocol (RDP), and Virtual Network Computing (VNC).
