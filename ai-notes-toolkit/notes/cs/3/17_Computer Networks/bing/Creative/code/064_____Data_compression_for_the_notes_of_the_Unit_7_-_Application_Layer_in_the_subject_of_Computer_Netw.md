### Data compression

Data compression is the process of reducing the amount of data needed for the storage or transmission of a given piece of information, typically by the use of encoding techniques. Data compression can improve the efficiency and performance of computer networks by reducing the time, cost and bandwidth required for data transfer.

There are two main types of data compression techniques: lossless and lossy. Lossless compression techniques preserve the exact information of the original data, while lossy compression techniques discard some information that is considered less important or redundant.

Some of the common data compression techniques are:

- **Run length encoding (RLE)**: This technique replaces consecutive identical symbols or bytes with a single symbol or byte followed by the number of repetitions. For example, the string "AAAAABBBBCCCC" can be compressed as "A5B4C4". This technique is useful for data sets that contain large amounts of redundant information, such as graphics and video data.
- **Differential pulse code modulation (DPCM)**: This technique encodes the difference between successive samples of a signal, rather than the absolute value of each sample. This reduces the number of bits required to represent each sample, as the difference is usually smaller than the original value. For example, the sequence "10, 12, 15, 18, 20" can be compressed as "10, 2, 3, 3, 2". This technique is useful for data sets that have high correlation between adjacent samples, such as audio and image data.
- **Dictionary based encoding**: This technique uses a predefined dictionary of symbols or strings to encode the data. The dictionary can be fixed or adaptive, depending on whether it is predetermined or updated during the compression process. For example, the string "the cat sat on the mat" can be compressed using a fixed dictionary as "1 2 3 4 1 5", where the numbers represent the corresponding words in the dictionary. This technique is useful for data sets that have high frequency of certain symbols or strings, such as text and natural language data.
- **Huffman coding**: This technique assigns variable-length codes to the symbols or bytes based on their frequency of occurrence. The most frequent symbols or bytes are assigned the shortest codes, while the least frequent ones are assigned the longest codes. For example, the string "ABRACADABRA" can be compressed using Huffman coding as "01101110100010101101110", where A is encoded as 0, B as 10, R as 110, C as 1110 and D as 1111. This technique is useful for data sets that have uneven distribution of symbols or bytes, such as text and binary data.
- **Lempel-Ziv (LZ) algorithm**: This technique uses a sliding window to find repeated patterns in the data and encode them as references to previous occurrences. The sliding window contains a fixed number of symbols or bytes that are compared with the incoming data. If a match is found, the algorithm outputs a pointer to the location and length of the match, otherwise it outputs the original symbol or byte. For example, the string "ABABABABABAB" can be compressed using LZ algorithm as "AB(0,2)(0,4)(0,8)", where (0,2) means go back 0 positions and copy 2 symbols, (0,4) means go back 0 positions and copy 4 symbols, and (0,8) means go back 0 positions and copy 8 symbols. This technique is useful for data sets that have long and frequent repetitions, such as text and natural language data.
