### IPv6

- IPv6 is the most recent version of the Internet Protocol (IP), the communications protocol that provides an identification and location system for computers on networks and routes traffic across the Internet .
- IPv6 is designed to solve many of the problems of the current version of the Internet Protocol suite (known as IPv4) about address depletion, security, auto-configuration, extensibility, and so on .
- IPv6 addresses have a size of 128 bits, in contrast to IPv4 addresses which have a size of 32 bits. Therefore, IPv6 has a vastly enlarged address space, allowing for more devices and services to be connected to the Internet.
- IPv6 addresses are written in eight groups of four hexadecimal digits, separated by colons, for example: 2001:0db8:85a3:0000:0000:8a2e:0370:7334. A shorthand notation can be used to compress zeros within an address, for example: 2001:db8:85a3::8a2e:370:7334.
- IPv6 has several types of addresses, such as unicast, multicast, anycast, and broadcast. Unicast addresses identify a single interface, multicast addresses identify a group of interfaces, anycast addresses identify the nearest interface in a group, and broadcast addresses identify all interfaces in a network.
- IPv6 has several features that improve the performance, security, and scalability of the Internet, such as:
  - Stateless address autoconfiguration (SLAAC), which allows devices to automatically configure their IPv6 addresses without the need for a server.
  - Neighbor discovery protocol (NDP), which replaces the ARP protocol in IPv4 and provides functions such as address resolution, router discovery, and duplicate address detection.
  - IPsec, which is a mandatory component of IPv6 and provides encryption and authentication for IP packets.
  - Extension headers, which allow for additional information to be added to the IPv6 packets, such as routing options, fragmentation, and mobility.
  - IPv6 transition mechanisms, which enable the coexistence and interoperability of IPv4 and IPv6 networks, such as dual-stack, tunneling, and translation.
