### World Wide Web and Hyper Text Transfer Protocol

- The World Wide Web (WWW) is a system of interlinked hypertext documents that can be accessed via the Internet using a web browser.
- A hypertext document is a text file that contains links to other documents or resources, such as images, videos, or audio files.
- The links in a hypertext document are called hyperlinks, and they allow users to navigate from one document to another by clicking on them.
- The WWW was invented by Tim Berners-Lee and his team at CERN in 1989-1991, as a way to share information among researchers across the world.
- The Hypertext Transfer Protocol (HTTP) is the application layer protocol that enables the communication between web browsers and web servers on the WWW.
- HTTP is based on the client-server model, where a web browser is a client that requests a web page from a web server that hosts the website.
- HTTP uses the Uniform Resource Locator (URL) to identify and locate the web page that the client wants to access.
- A URL consists of four parts: the protocol (http), the domain name (www.example.com), the path (/index.html), and the optional query string (?q=hello).
- HTTP defines a set of methods or verbs that the client can use to request different types of actions from the server, such as GET, POST, PUT, DELETE, etc.
- HTTP also defines a set of status codes that the server can use to respond to the client's request, such as 200 (OK), 404 (Not Found), 500 (Internal Server Error), etc.
- HTTP is a stateless protocol, which means that each request and response are independent and do not keep any information about previous interactions.
- HTTP can be extended or modified by using headers, which are additional fields that provide more information about the request or the response, such as Content-Type, Content-Length, Cookie, etc.
- HTTP can also be secured by using the Transport Layer Security (TLS) protocol, which encrypts the data exchanged between the client and the server. The secure version of HTTP is called HTTPS, and it uses the https protocol and the default port 443.
- HTTP has evolved over time to improve its performance, security, and functionality. The current version of HTTP is HTTP/2, which was standardized in 2015 and supports features such as multiplexing, compression, server push, etc.
