### LAN standards

A local area network (LAN) is a data communication network connecting various terminals or computers within a building or limited geographical area. The connection among the devices could be wired or wireless . LAN standards are the specifications that define the physical and logical characteristics of a LAN, such as the transmission medium, the data rate, the access method, the frame format, the addressing scheme, and the error control mechanism. Some of the most common LAN standards are:

- **Ethernet**: It is the most widely used LAN standard, based on the IEEE 802.3 specification. It uses a bus or star topology and supports data rates of 10 Mbps, 100 Mbps, 1 Gbps, and 10 Gbps. It uses the carrier sense multiple access with collision detection (CSMA/CD) protocol to access the shared medium  .
- **Token Ring**: It is a LAN standard based on the IEEE 802.5 specification. It uses a ring topology and supports data rates of 4 Mbps and 16 Mbps. It uses a token-passing protocol to access the medium, where a special frame called a token circulates around the ring and grants permission to the node that holds it to transmit data  .
- **Wireless LAN**: It is a LAN standard based on the IEEE 802.11 family of specifications. It uses radio waves or infrared signals to communicate among the devices, without the need for cables. It supports data rates of up to 600 Mbps, depending on the frequency band, the modulation scheme, and the number of spatial streams. It uses the carrier sense multiple access with collision avoidance (CSMA/CA) protocol to access the medium, where a node sends a request to send (RTS) frame before transmitting data and waits for a clear to send (CTS) frame from the receiver  .
- **Fiber Distributed Data Interface (FDDI)**: It is an optical fiber-based LAN standard that uses the IEEE 802.8 specification. It uses a dual ring topology and supports data rates of 100 Mbps. It uses a token-passing protocol similar to Token Ring, but with some enhancements to handle the higher speed and the longer distance of the fiber medium .
