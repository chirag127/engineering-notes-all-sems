# UDP and TCP for the notes of the Unit 6 - Transport Layer in the subject of Computer Networks

- The transport layer is the fourth layer of the OSI model and the third layer of the TCP/IP model. It is responsible for providing end-to-end communication between applications and ensuring reliable and efficient data transfer.
- The transport layer uses two main protocols: UDP (User Datagram Protocol) and TCP (Transmission Control Protocol). They have different features and characteristics that suit different types of applications and network conditions.
- UDP is a connectionless and unreliable protocol that does not guarantee data delivery, order, or integrity. It has a simple header that contains only the source and destination port numbers, the length, and the checksum. UDP is suitable for applications that require speed, low overhead, or real-time communication, such as video streaming, online gaming, or voice over IP (VoIP).
- TCP is a connection-oriented and reliable protocol that ensures data delivery, order, and integrity. It has a complex header that contains many fields, such as the sequence number, the acknowledgment number, the window size, the flags, and the options. TCP is suitable for applications that require reliability, error recovery, or congestion control, such as web browsing, email, or file transfer.
- UDP and TCP use port numbers to identify the source and destination applications of the data. Port numbers are 16-bit numbers that range from 0 to 65535. Some port numbers are reserved for well-known services, such as port 80 for HTTP, port 25 for SMTP, or port 53 for DNS. Other port numbers are dynamically assigned by the operating system for ephemeral connections.
- UDP and TCP have different mechanisms to handle data transmission and reception. UDP sends datagrams without waiting for acknowledgments or checking for errors. UDP does not implement flow control or congestion control and depends on the higher layer protocols or the application for these functions. UDP also does not segment or reassemble data and relies on the network layer to handle the maximum transmission unit (MTU) of the underlying network.
- TCP sends segments that are numbered and acknowledged by the receiver. TCP implements flow control by using a sliding window mechanism that adjusts the amount of data that can be sent without receiving an acknowledgment. TCP also implements congestion control by using algorithms such as slow start, congestion avoidance, fast retransmit, and fast recovery. TCP segments and reassembles data according to the MTU of the network and handles fragmentation and reordering of segments.
