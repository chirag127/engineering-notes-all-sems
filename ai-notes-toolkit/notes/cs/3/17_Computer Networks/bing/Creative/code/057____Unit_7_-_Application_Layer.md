## Unit 7 - Application Layer

The application layer is the topmost layer of the TCP/IP and OSI models that provides the interface and protocols for communication between applications over a network. The application layer contains several protocols that enable different types of services and functionalities, such as file transfer, email, web browsing, remote access, and network management. Some of the common application layer protocols are:

- **TELNET**: Telnet stands for the TELetype NETwork. It helps in terminal emulation. It allows Telnet clients to access and execute commands on remote hosts that run Telnet servers. Telnet uses port 23 and operates on a client-server model. Telnet is not secure as it sends data in plain text.  
- **FTP**: FTP stands for file transfer protocol. It is the protocol that actually lets us transfer files. It can transfer files between two computers, one acting as the client and the other as the server. FTP uses two ports: 20 for data transfer and 21 for control messages. FTP supports authentication, directory listing, and file manipulation. FTP is also not secure as it sends data and credentials in plain text.   
- **TFTP**: The Trivial File Transfer Protocol is a simplified version of FTP. It is used to transfer files without authentication or encryption. It uses port 69 and operates on a connectionless model using UDP. TFTP is mainly used for booting devices or transferring configuration files.  
- **SMTP**: SMTP stands for Simple Mail Transfer Protocol. It is the protocol that enables the sending and receiving of email messages. SMTP uses port 25 and operates on a client-server model using TCP. SMTP can only send text messages and attachments. SMTP servers can relay messages to other SMTP servers until they reach the destination.   
- **DNS**: DNS stands for Domain Name System. It is the protocol that maps domain names to IP addresses and vice versa. DNS uses port 53 and operates on a hierarchical and distributed model using UDP or TCP. DNS servers can cache, forward, or resolve queries from clients. DNS also supports other types of records, such as MX, NS, CNAME, and PTR.    
- **HTTP**: HTTP stands for Hypertext Transfer Protocol. It is the protocol that enables the communication between web browsers and web servers. HTTP uses port 80 and operates on a request-response model using TCP. HTTP can transfer different types of media, such as text, images, audio, and video. HTTP also supports methods, such as GET, POST, PUT, and DELETE, to perform different actions on web resources.   
- **SNMP**: SNMP stands for Simple Network Management Protocol. It is the protocol that enables the monitoring and management of network devices, such as routers, switches, servers, and printers. SNMP uses port 161 and operates on a manager-agent model using UDP. SNMP can collect, store, and modify information about network devices using a common data structure called MIB (Management Information Base). SNMP also supports traps, which are notifications sent by agents to managers when certain events occur.    
- **DHCP**: DHCP stands for Dynamic Host Configuration Protocol. It is the protocol that enables the automatic assignment of IP addresses and other network parameters to hosts on a network. DHCP uses port 67 and 68 and operates on a client-server model using UDP. DHCP can offer, lease, renew, and release IP addresses to hosts using a four-step process. DHCP also supports options, such as default gateway, DNS server, and subnet mask.    

These are some of the examples of application layer protocols. There are many more protocols that provide different types of services and functionalities at the application layer. The application layer protocols are essential for enabling the communication and interaction between applications over a network.
