### Remote login for the notes of the Unit 7 - Application Layer in the subject of Computer Networks

- Remote login is the ability to access data stored on a computer from a remote location .
- Remote login allows the user to open, edit and save files located on the remote device from anywhere in the world.
- Remote login also allows the user to interact with the remote computer as if the user terminal were directly connected to that computer .
- Remote login is useful for outside workers, travelers, and people who work outside the office .
- Remote login requires a network or direct telecommunication link between the user terminal and the host computer .
- Remote login can be achieved by using different protocols and applications, such as Telnet, SSH, RDP, VNC, etc .
- Remote login can pose security risks, such as unauthorized access, data theft, malware infection, etc.
- Remote login can be secured by using encryption, authentication, firewall, VPN, etc.
