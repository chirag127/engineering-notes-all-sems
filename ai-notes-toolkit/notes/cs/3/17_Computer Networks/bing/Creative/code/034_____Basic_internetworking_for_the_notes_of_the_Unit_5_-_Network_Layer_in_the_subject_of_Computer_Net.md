### Basic internetworking for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- The network layer is the part of the Internet communications process where packets of data are sent back and forth between different networks.
- The network layer is also called the Internet layer in the TCP/IP model, which is the most widely used model for Internet protocols.
- The network layer is responsible for routing, addressing, fragmentation, and reassembly of packets.
- Internetworking is the process of connecting different physical networks into a logical network using routers and other devices.
- Internetworking allows data to be transmitted across heterogeneous networks that may have different architectures, protocols, and topologies.
- The most notable example of internetworking is the Internet, which is a global network of networks that uses the IP protocol.
- Internetworking requires three types of addresses: data-link layer addresses, network-layer addresses, and media access control (MAC) addresses.
- Data-link layer addresses are used to identify each physical network connection of a network device, such as a network interface card (NIC).
- Network-layer addresses are used to identify each logical network connection of a network device, such as an IP address.
- MAC addresses are used to identify each device on a local area network (LAN), such as an Ethernet address.
- Internetworking devices include routers, switches, bridges, gateways, and firewalls.
- Routers are devices that forward packets between networks based on network-layer addresses.
- Switches are devices that forward packets between devices on the same network based on MAC addresses.
- Bridges are devices that connect two networks of the same type and forward packets based on MAC addresses.
- Gateways are devices that connect two networks of different types and perform protocol conversion.
- Firewalls are devices that filter packets based on predefined rules and policies.
