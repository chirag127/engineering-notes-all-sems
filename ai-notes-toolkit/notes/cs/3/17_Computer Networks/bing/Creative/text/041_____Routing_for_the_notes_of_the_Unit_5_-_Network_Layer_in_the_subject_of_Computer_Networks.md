### Routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- Routing is the process of delivering packets from one network to another by choosing an optimal path  .
- Routing takes place at the network layer (layer 3) of the Open Systems Interconnection (OSI) reference model .
- Routing is performed by a special device known as a router  .
- A router is a networking device that forwards the packet based on the information available in the packet header and forwarding table .
- A router connects to two or more IP networks or subnetworks and passes data packets between them as needed.
- Routing can be classified into three types: static routing, dynamic routing, and default routing.
- Static routing is a process in which we have to manually add routes to the routing table.
- Dynamic routing is a process in which routers exchange information about the network topology and automatically update the routing table.
- Default routing is a process in which a router forwards all packets that do not match any entry in the routing table to a default gateway.
- Routing algorithms can be categorized into two types: distance vector and link state.
- Distance vector algorithms use the hop count as the metric to find the shortest path to the destination.
- Link state algorithms use the cost of each link as the metric to find the shortest path to the destination.
