### TCP/IP protocol suite

- TCP/IP stands for **Transmission Control Protocol/Internet Protocol** and is a suite of communication protocols used to interconnect network devices on the internet .
- TCP/IP is also used as a communications protocol in a private computer network (an intranet or extranet).
- TCP/IP is commonly known as the **Internet protocol suite**, which is a framework for organizing the set of communication protocols used in the Internet and similar computer networks according to functional criteria.
- TCP/IP consists of four layers: the **application layer**, the **transport layer**, the **internet layer**, and the **network access layer**.
- The application layer provides the interface for the user applications to communicate with the network, such as web browsers, email clients, FTP clients, etc. The application layer protocols include HTTP, SMTP, FTP, DNS, etc.
- The transport layer provides the end-to-end data transmission services between the source and destination hosts, such as reliability, flow control, congestion control, error detection, etc. The transport layer protocols include TCP, UDP, etc.
- The internet layer provides the logical addressing and routing functions for the packets to traverse across different networks, such as IP addresses, subnet masks, routers, etc. The internet layer protocols include IP, ICMP, ARP, etc.
- The network access layer provides the physical and data link functions for the packets to access the underlying network media, such as Ethernet, Wi-Fi, etc. The network access layer protocols include MAC addresses, frames, switches, etc.
