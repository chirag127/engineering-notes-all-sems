### Network management

- Network management is the process of configuring, monitoring, and maintaining a reliable network—ensuring connectivity between devices and the people or software applications that use them .
- Network management also refers to the platform that IT and NetOps teams use to complete these ongoing tasks.
- Network management involves various functions, such as network planning, design, deployment, operation, administration, maintenance, security, performance, and optimization .
- Network management can be performed using different tools, such as network monitoring, network security, network automation, and other tools either hosted on-premise or on the cloud .
- Network management can benefit from following some best practices, such as conducting a network landscape inventory regularly, strategically leveraging both hardware and software tools, updating the network devices and software, implementing network segmentation, enforcing network security policies, automating network tasks, monitoring network performance and availability, troubleshooting network issues, documenting network changes, and reviewing network performance reports.
