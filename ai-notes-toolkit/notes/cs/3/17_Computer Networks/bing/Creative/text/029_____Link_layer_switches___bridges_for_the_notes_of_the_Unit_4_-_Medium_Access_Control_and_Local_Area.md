### Link layer switches & bridges

- Link layer switches and bridges are network devices that operate at the data link layer (layer 2) of the OSI model and forward data frames based on MAC addresses .
- Link layer switches and bridges can connect multiple LANs (local area networks) together to form a larger LAN. This process of aggregating networks is called network bridging .
- Link layer switches and bridges can also filter and isolate traffic within a LAN, reducing collisions and increasing bandwidth efficiency .
- Link layer switches and bridges can learn the MAC addresses of the devices connected to their ports by observing the source addresses of the incoming frames. They can then use a forwarding table to decide which port to send a frame to, based on the destination address .
- Link layer switches and bridges can also perform error detection and correction on the frames, using techniques such as CRC (cyclic redundancy check) or checksum .
- Some link layer switches can also operate at the network layer (layer 3) of the OSI model and forward data packets based on IP addresses. These switches are called layer-3 switches or multilayer switches.
- A wireless access point is a specialized link layer bridge that creates a link between a wired and a wireless network, allowing wireless devices to communicate with the wired network.
