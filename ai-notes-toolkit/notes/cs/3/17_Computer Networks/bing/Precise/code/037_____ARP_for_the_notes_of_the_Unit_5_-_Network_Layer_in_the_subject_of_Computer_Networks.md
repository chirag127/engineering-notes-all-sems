### ARP

ARP (Address Resolution Protocol) is a protocol used to map an IP address to a physical address (MAC address) on a local network. It is a crucial component of the network layer in the OSI model.

Here are some key points to remember about ARP:

1. ARP operates at the network layer of the OSI model.
2. ARP is used to resolve IP addresses to MAC addresses on a local network.
3. ARP maintains a cache of recently resolved IP to MAC address mappings to reduce the number of ARP requests.
4. ARP requests are broadcast to all devices on the local network.
5. ARP replies are sent directly to the requesting device.
6. ARP is a stateless protocol, meaning it does not maintain any information about the state of the network or the devices on it.
