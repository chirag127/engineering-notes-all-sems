### IP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- IP stands for Internet Protocol.
- It is a protocol used for communication over the internet.
- IP is responsible for routing data packets between devices on a network.
- It is a connectionless protocol, meaning that it does not establish a connection before sending data.
- IP is part of the TCP/IP protocol suite, which is the foundation of the internet.
- IP addresses are used to identify devices on a network.
- There are two versions of IP in use: IPv4 and IPv6.
- IPv4 addresses are 32 bits long, while IPv6 addresses are 128 bits long.
- The main function of IP is to provide a best-effort delivery service for data packets.
- IP does not guarantee that packets will be delivered, nor does it guarantee the order in which they will be delivered.
- IP packets can be lost, duplicated, or delivered out of order.
- Higher-level protocols, such as TCP, are used to provide reliability and ensure that data is delivered correctly.
- IP also supports fragmentation and reassembly of packets, which allows large packets to be split into smaller packets for transmission over networks with smaller maximum transmission units (MTUs).
- IP is a fundamental protocol that enables communication over the internet and other networks. It is an essential part of the network layer of the OSI model.
