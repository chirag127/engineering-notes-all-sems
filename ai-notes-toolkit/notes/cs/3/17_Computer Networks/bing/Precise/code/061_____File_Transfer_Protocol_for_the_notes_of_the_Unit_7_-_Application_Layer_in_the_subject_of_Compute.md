### File Transfer Protocol (FTP)

File Transfer Protocol (FTP) is a standard network protocol used to transfer files from one host to another over a TCP-based network, such as the Internet. FTP is built on a client-server architecture and uses separate control and data connections between the client and the server.

Here are some key points to remember about FTP:

1. FTP is a standard network protocol used to transfer files between hosts over a TCP-based network.
2. FTP uses a client-server architecture, where the client initiates a connection to the server to request a file transfer.
3. FTP uses separate control and data connections between the client and the server.
4. The control connection is used to send commands and receive responses, while the data connection is used to transfer the actual files.
5. FTP can be used to transfer files of any size and type, including text, binary, and compressed files.
6. FTP supports both active and passive modes for data transfer.
7. FTP is not a secure protocol, as data is transmitted in clear text. To secure file transfers, other protocols such as SFTP or FTPS can be used.
