### Unit 3 - Link Layer: Framing

1. Framing is the process of encapsulating data into a frame or packet for transmission over a network.
2. Frames are the basic unit of data transmission in the link layer.
3. The link layer is responsible for providing a reliable link between two directly connected nodes.
4. The link layer adds a header and a trailer to the data to create a frame.
5. The header contains information such as the source and destination addresses, while the trailer contains error-detection information.
6. The link layer uses framing to ensure that data is transmitted reliably and without errors.
7. Different link layer protocols use different framing methods, such as character stuffing or bit stuffing.
8. Framing is an essential part of the link layer and is necessary for reliable data transmission over a network.
