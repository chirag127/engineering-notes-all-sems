### Elementary Data Link Protocols

Elementary Data Link Protocols are the protocols used in the Data Link Layer of the OSI model. The Data Link Layer is responsible for providing reliable data transfer between two adjacent nodes in a network. Some of the key functions of the Data Link Layer include:

1. **Framing**: The Data Link Layer takes the packets from the Network Layer and encapsulates them into frames. The frames are then transmitted over the physical link.

2. **Error Control**: The Data Link Layer is responsible for detecting and correcting errors that may occur during transmission. This is achieved through the use of error detection and correction techniques such as checksums and cyclic redundancy checks (CRC).

3. **Flow Control**: The Data Link Layer is responsible for regulating the flow of data between the sender and the receiver. This is achieved through the use of flow control techniques such as stop-and-wait and sliding window.

4. **Media Access Control**: The Data Link Layer is responsible for controlling access to the shared communication medium. This is achieved through the use of media access control techniques such as Carrier Sense Multiple Access with Collision Detection (CSMA/CD) and Token Ring.

Some of the common Elementary Data Link Protocols include:

- **High-Level Data Link Control (HDLC)**: HDLC is a bit-oriented protocol that provides a reliable data link between two nodes. It uses a combination of flow control, error control, and framing techniques to provide reliable data transfer.

- **Point-to-Point Protocol (PPP)**: PPP is a byte-oriented protocol that provides a standard method for transporting multi-protocol datagrams over point-to-point links. It uses a combination of framing, error control, and link control techniques to provide reliable data transfer.

- **Slip (Serial Line Internet Protocol)**: SLIP is a simple protocol used for transmitting IP datagrams over a serial line. It uses a simple framing technique to encapsulate IP datagrams into frames for transmission over the serial line.
