## Unit 5 - Network Layer

The network layer is responsible for routing data packets from the source to the destination. It is the third layer of the OSI model and is responsible for the following functions:

1. **Logical Addressing:** The network layer provides logical addressing to uniquely identify devices on the network. This is done using IP addresses.

2. **Routing:** The network layer is responsible for routing data packets from the source to the destination. This is done using routing algorithms and routing tables.

3. **Fragmentation and Reassembly:** The network layer is responsible for fragmenting large data packets into smaller packets that can be transmitted over the network. It is also responsible for reassembling the fragmented packets at the destination.

4. **Error Handling and Diagnostics:** The network layer is responsible for detecting and handling errors that may occur during transmission. It also provides diagnostic tools to troubleshoot network issues.

5. **Congestion Control:** The network layer is responsible for managing network congestion by controlling the flow of data packets.

The network layer plays a crucial role in ensuring reliable and efficient communication over a network. It provides the necessary mechanisms to route data packets from the source to the destination, handle errors, and manage network congestion.
