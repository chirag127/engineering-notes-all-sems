### Network devices and components

Unit 1 - Introductory Concepts in the subject of Computer Networks

1. **Network Interface Card (NIC)**: A hardware component that connects a computer to a network. It provides a physical connection between the computer and the network cable.

2. **Hub**: A device that connects multiple computers or other network devices together. It receives data from one device and sends it to all other connected devices.

3. **Switch**: Similar to a hub, a switch connects multiple devices together. However, it is more intelligent and can direct data to a specific device, rather than broadcasting it to all connected devices.

4. **Router**: A device that connects multiple networks together and directs data between them. It uses routing tables and protocols to determine the best path for data to travel between networks.

5. **Modem**: A device that modulates and demodulates signals, allowing data to be transmitted over telephone or cable lines.

6. **Firewall**: A security device that monitors and controls incoming and outgoing network traffic based on predetermined security rules.

7. **Wireless Access Point (WAP)**: A device that allows wireless devices to connect to a wired network. It converts data from a wired network into a wireless signal and vice versa.

8. **Bridge**: A device that connects two networks together and filters traffic between them. It can be used to divide a large network into smaller segments to reduce congestion.

9. **Repeater**: A device that amplifies a signal to extend the range of a network. It can be used to connect two network segments that are too far apart to be connected directly.

These are some of the common network devices and components used in computer networks. Each device serves a specific purpose and plays a crucial role in ensuring efficient and secure communication between devices on a network.
