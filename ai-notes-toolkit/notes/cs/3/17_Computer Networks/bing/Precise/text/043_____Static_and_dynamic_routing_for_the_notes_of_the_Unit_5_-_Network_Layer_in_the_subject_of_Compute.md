### Static and dynamic routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

1. **Static routing** is a type of routing in which the network administrator manually configures the routing table on a router. This means that the administrator must specify the routes for each destination network and the next hop router for each route.
2. Static routing is simple to implement and requires less processing power and memory than dynamic routing. However, it is not scalable and can be difficult to manage in large networks.
3. **Dynamic routing** is a type of routing in which the router automatically learns and updates its routing table based on information it receives from other routers in the network. This is done using routing protocols such as OSPF, RIP, and BGP.
4. Dynamic routing is more scalable and easier to manage than static routing, as the router automatically adapts to changes in the network topology. However, it requires more processing power and memory than static routing.
5. In summary, static routing is best suited for small, simple networks, while dynamic routing is better for larger, more complex networks.
