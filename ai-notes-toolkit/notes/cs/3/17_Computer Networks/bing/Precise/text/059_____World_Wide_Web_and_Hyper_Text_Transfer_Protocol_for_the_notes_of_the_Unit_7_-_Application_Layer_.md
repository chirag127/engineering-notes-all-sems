### World Wide Web and Hyper Text Transfer Protocol

The World Wide Web (WWW) is a system of interlinked hypertext documents accessed through the Internet. It was invented by Tim Berners-Lee in 1989 while working at CERN, the European Organization for Nuclear Research.

The HyperText Transfer Protocol (HTTP) is the protocol used for transmitting web pages over the Internet. It is an application layer protocol that runs on top of the Transmission Control Protocol (TCP) and the Internet Protocol (IP).

Here are some key points about the World Wide Web and HTTP:

1. The World Wide Web is a system of interlinked hypertext documents accessed through the Internet.
2. HTTP is the protocol used for transmitting web pages over the Internet.
3. HTTP is an application layer protocol that runs on top of TCP and IP.
4. The first web page was put online on August 6, 1991.
5. The World Wide Web has revolutionized the way we access and share information.
