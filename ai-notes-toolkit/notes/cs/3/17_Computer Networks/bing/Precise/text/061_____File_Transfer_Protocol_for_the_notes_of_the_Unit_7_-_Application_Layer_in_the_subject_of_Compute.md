### File Transfer Protocol

File Transfer Protocol (FTP) is a standard network protocol used to transfer files from one host to another over a TCP-based network, such as the Internet. FTP is built on a client-server architecture and uses separate control and data connections between the client and the server.

Here are some key points to remember about FTP:

1. FTP is a standard network protocol used for transferring files over the Internet.
2. FTP uses a client-server architecture.
3. FTP uses separate control and data connections between the client and the server.
4. FTP is commonly used to transfer files between a local computer and a remote server.
5. FTP can be used to upload files to a server or to download files from a server.
6. FTP can be used with a command-line interface or with a graphical user interface (GUI).
7. FTP uses port 21 for control connections and port 20 for data connections.
8. FTP supports both active and passive modes for data transfer.
9. FTP supports anonymous access, where users can log in with the username "anonymous" and their email address as the password.
10. FTP is not a secure protocol and does not encrypt data in transit. For secure file transfers, other protocols such as SFTP or FTPS can be used.
