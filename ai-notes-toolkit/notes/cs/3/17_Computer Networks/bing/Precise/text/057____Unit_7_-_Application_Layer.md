## Unit 7 - Application Layer

The Application Layer is the topmost layer of the OSI model and is responsible for providing services to the user. It is the layer closest to the user and provides a means for the user to interact with the network. Some of the key functions of the Application Layer include:

1. **Resource Sharing:** The Application Layer enables users to share resources such as files, printers, and databases across the network.

2. **Remote Access:** The Application Layer provides remote access to network resources, allowing users to access resources from remote locations.

3. **Email Services:** The Application Layer provides email services, allowing users to send and receive emails across the network.

4. **Network Management:** The Application Layer provides network management services, allowing network administrators to monitor and manage the network.

5. **Directory Services:** The Application Layer provides directory services, allowing users to search for and access network resources.

Some common protocols used in the Application Layer include HTTP, FTP, SMTP, and DNS. These protocols provide the rules and standards for communication between applications on different devices.
