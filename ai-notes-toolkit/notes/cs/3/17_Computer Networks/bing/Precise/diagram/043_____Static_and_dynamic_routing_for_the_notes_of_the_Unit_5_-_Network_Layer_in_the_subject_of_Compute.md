### Unit 5 - Network Layer: Static and Dynamic Routing

Routing is the process of selecting a path for traffic in a network, or between or across multiple networks. There are two main types of routing: static and dynamic.

1. **Static Routing:** In static routing, the network administrator manually configures the routing table in each router with the network destinations and the next hop for each destination. Static routing is simple to implement and works well in small networks with few routers and stable network topologies. However, it does not scale well and requires manual reconfiguration when the network topology changes.

2. **Dynamic Routing:** In dynamic routing, routers exchange information about the network topology and automatically update their routing tables based on this information. Dynamic routing protocols, such as OSPF and BGP, are used to facilitate this exchange of information. Dynamic routing is more complex to implement than static routing, but it scales well and can adapt to changes in the network topology automatically.

In summary, static routing is suitable for small, stable networks, while dynamic routing is more appropriate for larger, more complex networks with changing topologies. Both types of routing have their advantages and disadvantages, and the choice between them depends on the specific requirements of the network.
