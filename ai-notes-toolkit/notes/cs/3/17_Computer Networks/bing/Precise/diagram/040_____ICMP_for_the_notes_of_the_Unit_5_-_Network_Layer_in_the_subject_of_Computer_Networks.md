### ICMP (Internet Control Message Protocol)
- ICMP is a protocol used in the Internet Protocol Suite.
- It is used by network devices to send error messages and operational information.
- ICMP is a supporting protocol in the Internet protocol suite and is not used by end-user network applications directly.
- ICMP messages are typically generated by network devices, such as routers, to indicate error conditions or provide other information about the state of the network.
- ICMP messages are encapsulated within IP datagrams, and thus rely on IP to deliver the messages to the appropriate destination.
- Some common ICMP message types include:
    - Destination Unreachable: sent by a router to indicate that a destination host or network cannot be reached.
    - Time Exceeded: sent by a router to indicate that a datagram has been discarded because its time to live (TTL) value has reached zero.
    - Echo Request and Echo Reply (Ping): used to test the reachability of a network host.
- ICMP is an important tool for network administrators to diagnose network issues and ensure the proper functioning of the network.
