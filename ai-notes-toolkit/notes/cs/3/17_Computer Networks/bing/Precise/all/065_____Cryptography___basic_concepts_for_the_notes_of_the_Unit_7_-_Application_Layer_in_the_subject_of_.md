# Cryptography – basic concepts

Cryptography is the practice of secure communication in the presence of third parties. It involves the use of mathematical algorithms to convert information into a code that can only be deciphered by someone who has the key to unlock it. Cryptography is used to protect data from unauthorized access, alteration, or theft.

Here are some basic concepts in cryptography:

1. **Encryption**: The process of converting plaintext (readable data) into ciphertext (encoded data) using an encryption algorithm and a key.

2. **Decryption**: The reverse process of encryption, where ciphertext is converted back into plaintext using a decryption algorithm and a key.

3. **Key**: A piece of information used by the encryption and decryption algorithms to convert plaintext into ciphertext and vice versa.

4. **Symmetric-key cryptography**: A type of cryptography where the same key is used for both encryption and decryption.

5. **Asymmetric-key cryptography**: A type of cryptography where different keys are used for encryption and decryption. One key is used to encrypt the data, and another key is used to decrypt it.

6. **Hash function**: A mathematical function that takes an input and produces a fixed-size output, called a hash. Hash functions are used to verify the integrity of data.

7. **Digital signature**: A cryptographic technique used to verify the authenticity of a digital message or document.

These are some of the basic concepts in cryptography. Cryptography is an important part of the application layer in computer networks, as it helps to ensure secure communication between different parties. It is used in various applications, such as secure email, online banking, and e-commerce.
