## Unit 7 - Application Layer

The Application Layer is the topmost layer of the OSI model and is responsible for providing services to the user. It is the layer closest to the user and provides a means for the user to interact with the network. Some of the key functions of the Application Layer include:

1. **Resource sharing and device redirection:** This allows users to share resources such as files and printers over the network.

2. **Remote file access and transfer:** This allows users to access and transfer files over the network.

3. **Network management:** This includes functions such as network monitoring and diagnostics.

4. **Directory services:** This provides a means for users to locate resources on the network.

5. **Electronic messaging:** This includes services such as email and instant messaging.

6. **Virtual terminals:** This allows users to log in to remote systems and interact with them as if they were local.

Some common protocols used at the Application Layer include HTTP, FTP, SMTP, and DNS. These protocols provide the rules and formats for communication between applications over the network.
