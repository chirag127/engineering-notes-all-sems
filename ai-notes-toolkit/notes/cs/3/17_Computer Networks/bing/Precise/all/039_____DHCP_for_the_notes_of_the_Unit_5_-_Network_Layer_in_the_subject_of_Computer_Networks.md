### DHCP (Dynamic Host Configuration Protocol)

DHCP is a network management protocol used on Internet Protocol (IP) networks. It is used to automatically assign IP addresses and other network configuration parameters to devices on a network.

Here are some key points to remember about DHCP:

1. DHCP is used to automatically assign IP addresses to devices on a network.
2. DHCP can also provide other network configuration parameters, such as the subnet mask, default gateway, and DNS server addresses.
3. DHCP operates on a client-server model. The DHCP server maintains a pool of available IP addresses and assigns them to clients as needed.
4. When a device connects to a network, it sends a broadcast message requesting an IP address. The DHCP server responds with an offer of an IP address and other configuration information.
5. The client can accept the offer and configure its network settings accordingly, or it can decline the offer and continue to search for another DHCP server.
6. DHCP can be used on both wired and wireless networks.
7. DHCP is an essential part of modern network management and is widely used in both enterprise and home networks.
