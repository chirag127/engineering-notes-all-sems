### ICMP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- ICMP stands for Internet Control Message Protocol.
- ICMP works in the network layer of the OSI model and the internet layer of the TCP/IP model.
- ICMP is used to send control messages to network devices and hosts.
- Routers and other network devices monitor the operation of the network using ICMP.
- ICMP is a network layer protocol.
- ICMP messages are not passed directly to the data link layer. The message is first encapsulated inside the IP datagram before going to the lower layer.
- IP does not have an inbuilt mechanism for sending error and control messages. It depends on ICMP to provide an error control.
- ICMP is used for reporting errors and management queries.
- ICMP is mainly used to determine whether or not data is reaching its intended destination in a timely manner.
- Commonly, the ICMP protocol is used on network devices, such as routers.
