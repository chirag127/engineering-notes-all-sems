# Elementary Data Link Protocols

Elementary Data Link Protocols are the protocols used in the Data Link Layer of the OSI model for computer networks. The Data Link Layer is responsible for providing reliable data transfer between two adjacent nodes in a network. Some of the key functions of the Data Link Layer include:

1. Framing: The Data Link Layer takes the packets from the Network Layer and encapsulates them into frames for transmission over the physical medium.
2. Error Control: The Data Link Layer is responsible for detecting and correcting errors that may occur during transmission.
3. Flow Control: The Data Link Layer regulates the flow of data between two nodes to prevent the receiver from being overwhelmed by the sender.
4. Access Control: The Data Link Layer controls access to the shared medium in a multi-access network.

Some of the common Elementary Data Link Protocols include:

- HDLC (High-Level Data Link Control): A bit-oriented protocol used for both point-to-point and multi-point connections.
- PPP (Point-to-Point Protocol): A protocol used for point-to-point connections over serial links.
- SLIP (Serial Line Internet Protocol): An early protocol used for point-to-point connections over serial links.
- Ethernet: A protocol used for local area networks (LANs) that provides both physical and data link layer functionality.

These protocols provide the necessary functionality for reliable data transfer between two adjacent nodes in a network. They are essential for the proper functioning of computer networks.
