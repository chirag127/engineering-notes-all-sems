
## Unit 5 - APPLICATIONS

1. Applications are computer programs designed to help users complete tasks.
2. Applications are designed to run on a variety of operating systems, including Windows, macOS, and Linux.
3. Applications can be installed on a user's computer, or accessed online.
4. Applications can be used to create documents, images, and videos, or to access the internet, play games, and more.
5. Popular applications include web browsers, email clients, word processors, spreadsheets, media players, and games.
6. Applications can be purchased or downloaded for free from the internet.
7. Developers create applications to meet specific user needs.
8. Applications are often updated to add new features and fix bugs.
