
## Unit 2 - PROBLEM SOLVING METHODS

1. Analytical Problem Solving: This approach involves breaking down a problem into its component parts and analyzing each part to determine a solution. It is a logical, systematic approach that can be used to solve complex problems.

2. Algorithmic Problem Solving: This approach involves creating a set of steps or instructions that can be followed to solve a problem. It is often used to solve mathematical and computer science problems.

3. Heuristic Problem Solving: This approach involves using trial and error to solve a problem. It is often used when the problem is too complex to solve using analytical or algorithmic methods.

4. Creative Problem Solving: This approach involves using brainstorming and other creative techniques to generate new ideas or solutions to a problem. It is often used when no existing solution exists.
