### Agent communication for the notes of the Unit 4 - SOFTWARE AGENTS

1. Agents need to communicate with each other to collaborate and solve complex problems.
2. Communication between agents can be either indirect or direct:
- Indirect communication: Agents communicate via the environment. They sense the changes in the environment made by other agents.
- Direct communication: Agents exchange messages with each other.
3. Direct communication between agents can be synchronous or asynchronous:
- Synchronous: Agents exchange messages simultaneously.
- Asynchronous: Agents exchange messages at different times. Asynchronous communication is more flexible but can lead to inconsistencies.
4. Some ways for agent communication are:
- Speech acts: Agents communicate by sending messages that perform actions like requesting, informing, querying, etc.
- Perceptual symbols: Agents communicate by constructing shared perceptual symbols.
- FIPA ACL: A standard language for agent communication. It allows agents to send various speech acts to each other.
