### Machine Translation for the notes of the Unit 5 - APPLICATIONS in the subject of ARTIFICIAL INTELLIGENCE KCS.

1. Machine Translation is a method of translating text or speech from one language to another using a machine.
2. It makes use of computer software that has been trained on massive amounts of data to learn how to translate between languages.
3. The key steps involved in Machine Translation are:
- Analysis: The input text is analyzed to break it into smaller units like sentences and phrases.
- Transfer: The source language structures are converted into target language structures.
- Generation: The target language text is generated from the transferred structures.
4. The major approaches to Machine Translation are:
- Rule-based: Uses linguistic rules to analyze and generate the translation.
- Statistical: Uses statistical techniques and large amounts of data to learn how to translate.
- Neural: Uses neural networks which can capture linguistic nuances and produce more fluent translations.
5. Evaluation of Machine Translation:
- Automatic metrics like BLEU, ROUGE, etc. are used to evaluate the quality of the machine translated output.
- Human evaluation by doing tests like post-editing, adequacy and fluency, etc. can provide more reliable assessment but are more expensive and time-consuming.
