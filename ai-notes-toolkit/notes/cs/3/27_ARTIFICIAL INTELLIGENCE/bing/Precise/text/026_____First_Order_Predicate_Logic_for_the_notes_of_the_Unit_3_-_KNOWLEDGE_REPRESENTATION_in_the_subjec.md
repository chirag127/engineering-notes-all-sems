### First Order Predicate Logic

First-order predicate logic is a formal system used in mathematics, computer science, and linguistics to represent and manipulate statements about objects and their properties. It is also known as first-order logic or predicate calculus.

Here are some key points to remember about first-order predicate logic:

1. First-order predicate logic extends propositional logic by introducing quantifiers, which allow us to make statements about collections of objects.
2. The two most common quantifiers are the universal quantifier, denoted by the symbol ∀, and the existential quantifier, denoted by the symbol ∃.
3. The universal quantifier is used to make statements that are true for all objects in a given domain, while the existential quantifier is used to make statements that are true for at least one object in the domain.
4. In first-order predicate logic, statements are made up of predicates, which are functions that take one or more arguments and return a truth value.
5. Predicates can be combined using logical connectives such as AND, OR, and NOT to form more complex statements.
6. First-order predicate logic also allows the use of functions, which take one or more arguments and return an object.
7. Inference rules, such as modus ponens and universal instantiation, can be used to derive new statements from existing ones.
