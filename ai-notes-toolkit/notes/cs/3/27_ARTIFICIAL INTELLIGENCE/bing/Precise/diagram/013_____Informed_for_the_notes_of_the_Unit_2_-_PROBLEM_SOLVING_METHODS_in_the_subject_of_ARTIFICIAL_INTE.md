### Informed Search

Informed search is a type of search strategy used in Artificial Intelligence for problem-solving. It is also known as heuristic search. Informed search algorithms use problem-specific knowledge beyond the definition of the problem itself to find solutions more efficiently than uninformed search methods.

Some of the common informed search methods are:

1. **Best-first search:** This is a search algorithm that explores a graph by expanding the most promising node chosen according to a specified rule. It uses a heuristic function to determine the order in which the search visits nodes in the tree.

2. **Greedy best-first search:** This is a type of best-first search that always expands the node that is closest to the goal, as estimated by a heuristic function.

3. **A* search:** This is a type of best-first search that uses a heuristic function to estimate the cost of the cheapest solution through a given node. It combines the cost to reach the node and the estimated cost to the goal to determine the order in which the search visits nodes in the tree.

4. **Iterative deepening A* (IDA*):** This is a variant of the A* algorithm that uses iterative deepening to reduce the memory requirements of the search.

These are some of the informed search methods used in Artificial Intelligence for problem-solving. They use heuristics to guide the search and find solutions more efficiently than uninformed search methods.
