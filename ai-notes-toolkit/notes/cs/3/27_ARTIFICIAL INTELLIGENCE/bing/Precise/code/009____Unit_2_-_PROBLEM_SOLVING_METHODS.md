## Unit 2 - PROBLEM SOLVING METHODS

Problem-solving is a process of finding a solution to a problem. There are several methods that can be used to solve problems, including:

1. **Trial and Error:** This method involves trying different solutions until the problem is solved. It is often used when there is no clear solution to the problem.

2. **Algorithm:** An algorithm is a step-by-step procedure for solving a problem. It is often used when the problem can be broken down into smaller, more manageable parts.

3. **Heuristics:** Heuristics are rules of thumb or mental shortcuts that can be used to solve problems. They are often used when the problem is complex and there is no clear solution.

4. **Divide and Conquer:** This method involves breaking the problem down into smaller, more manageable parts and solving each part separately. It is often used when the problem is complex and can be divided into smaller parts.

5. **Backtracking:** Backtracking is a method of solving problems by trying different solutions and then backing up to try a different solution if the first one does not work. It is often used when the problem has multiple solutions.

6. **Brute Force:** Brute force is a method of solving problems by trying all possible solutions until the problem is solved. It is often used when the problem has a small number of possible solutions.

These are some of the common methods used for problem-solving. Each method has its own advantages and disadvantages and the best method to use depends on the specific problem at hand. It is important to choose the right method for the problem to ensure that it is solved efficiently and effectively.
