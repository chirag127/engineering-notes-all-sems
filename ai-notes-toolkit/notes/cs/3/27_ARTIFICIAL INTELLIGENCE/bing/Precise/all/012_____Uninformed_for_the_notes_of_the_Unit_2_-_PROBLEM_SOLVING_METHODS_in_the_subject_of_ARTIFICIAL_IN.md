# Uninformed Search

Uninformed search, also known as blind search, is a search strategy that does not use any problem-specific knowledge. It is a basic search method that is used to solve problems when no additional information is available about the search space. Uninformed search methods include:

1. **Breadth-first search (BFS)**: This is a search algorithm that explores all the nodes at the present depth level before moving on to the nodes at the next depth level.

2. **Depth-first search (DFS)**: This is a search algorithm that explores as far as possible along each branch before backtracking.

3. **Uniform-cost search**: This is a search algorithm that expands the node with the lowest path cost.

4. **Depth-limited search**: This is a search algorithm that limits the depth of the search tree to a predetermined level.

5. **Iterative deepening depth-first search**: This is a search algorithm that combines the benefits of depth-first search and breadth-first search by gradually increasing the depth limit.

Uninformed search methods are generally less efficient than informed search methods, which use problem-specific knowledge to guide the search. However, uninformed search methods can still be useful when no additional information is available about the search space.
