# Events

Events are one of the types of knowledge representation in artificial intelligence. Events are occurrences or happenings that involve changes in the state of the world. Events can be represented by predicates, frames, scripts, or other formalisms.

Some of the characteristics of events are:

- Events have temporal and causal relations with other events. For example, an event can precede, follow, or coincide with another event, or an event can cause or be caused by another event.
- Events can have participants, locations, durations, and other attributes. For example, an event of buying a book can have a buyer, a seller, a book, a price, a place, and a time as its attributes.
- Events can be classified into different types or categories based on their properties or roles. For example, an event can be a physical event, a mental event, a speech event, a social event, etc.
- Events can be abstract or concrete, depending on the level of detail or specificity. For example, an event of reading a book can be abstract if it does not specify which book, when, where, or how, or it can be concrete if it does specify those details.

Some of the applications of events in artificial intelligence are:

- Event representation learning: This is the task of learning vector representations of events that can capture their syntactic and semantic information from text corpora. These representations can be used for downstream tasks such as script event prediction, event coreference resolution, event extraction, etc.
- Event calculus: This is a logic-based formalism for representing and reasoning about events and their effects. It can be used for planning, temporal reasoning, causal reasoning, etc.
- Knowledge graphs: These are graph-based structures that represent entities and their relations in a domain of interest. Events can be modeled as nodes or edges in a knowledge graph, and can be enriched with external commonsense knowledge.
