### Search Strategies

- A search strategy is a method for finding a solution to a problem by exploring the state space of the problem.
- A state space is a representation of all the possible configurations of the problem, where each configuration is called a state.
- A solution is a sequence of states that leads from the initial state to the goal state, where the problem is solved.
- A search strategy consists of two components: a search algorithm and a search heuristic.
- A search algorithm is a set of rules that determines how to select the next state to explore from the current state.
- A search heuristic is a function that estimates the cost or distance of reaching the goal state from a given state.
- A search strategy can be classified as either uninformed or informed, depending on whether it uses a search heuristic or not.
- Uninformed search strategies do not use any domain-specific knowledge and rely only on the problem definition. They are also called blind search strategies.
- Informed search strategies use a search heuristic to guide the search towards the goal state. They are also called heuristic search strategies.

Some examples of search strategies are:

- Breadth-first search: an uninformed search strategy that explores the state space level by level, starting from the initial state and expanding all the successors of each state in a queue.
- Depth-first search: an uninformed search strategy that explores the state space by going deeper into the branches of the state space tree, starting from the initial state and expanding the first successor of each state in a stack.
- Uniform-cost search: an uninformed search strategy that explores the state space by selecting the state with the lowest path cost from the initial state, using a priority queue.
- Greedy search: an informed search strategy that explores the state space by selecting the state with the lowest heuristic value, using a priority queue.
- A* search: an informed search strategy that explores the state space by selecting the state with the lowest sum of the path cost and the heuristic value, using a priority queue.
