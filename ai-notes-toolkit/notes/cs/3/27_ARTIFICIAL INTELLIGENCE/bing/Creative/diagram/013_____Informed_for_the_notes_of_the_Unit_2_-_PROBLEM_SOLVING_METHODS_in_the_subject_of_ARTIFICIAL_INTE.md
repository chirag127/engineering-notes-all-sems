### Informed

Informed is a term used to describe a problem-solving method in artificial intelligence that uses additional information or heuristics to guide the search process towards the goal state. Informed methods are also called heuristic methods, as they rely on some measure of how close a state is to the goal, or how promising a state is for further exploration. Informed methods are contrasted with uninformed methods, which do not use any domain-specific knowledge and only rely on the problem definition.

Some of the informed methods that are commonly used in artificial intelligence are:

- **Best-first search**: This is a general search strategy that expands the most promising node according to a given evaluation function. The evaluation function can be a combination of the cost of reaching the node and the estimated cost of reaching the goal from the node. Best-first search can be seen as a generalization of breadth-first search and depth-first search, depending on the evaluation function used. Some examples of best-first search algorithms are greedy best-first search, A* search, and beam search.
- **Hill climbing**: This is a local search strategy that starts from an initial state and iteratively moves to a neighboring state that has a higher value according to a given objective function. The objective function can be the same as the evaluation function used in best-first search, or it can be a different measure of the quality of a state. Hill climbing can be seen as a special case of best-first search, where only one node is expanded at each step. Hill climbing can get stuck in local maxima, plateaus, or ridges, and may not find the global optimum. Some variations of hill climbing are steepest ascent hill climbing, random-restart hill climbing, and simulated annealing.
- **Genetic algorithms**: These are population-based search strategies that mimic the process of natural evolution. Genetic algorithms start from a set of randomly generated states, called individuals, and apply genetic operators, such as selection, crossover, and mutation, to produce new individuals. The individuals are evaluated according to a given fitness function, which can be the same as the objective function used in hill climbing, or it can be a different measure of the quality of a state. Genetic algorithms can explore multiple regions of the search space simultaneously, and can escape from local optima by introducing diversity and randomness. Genetic algorithms are often used for optimization problems, such as function optimization, machine learning, and scheduling.
