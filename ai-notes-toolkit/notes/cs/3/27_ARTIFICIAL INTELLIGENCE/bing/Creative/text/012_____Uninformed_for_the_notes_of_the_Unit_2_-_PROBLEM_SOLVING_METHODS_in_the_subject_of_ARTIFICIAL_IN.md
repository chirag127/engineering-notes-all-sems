### Uninformed Search Methods

Uninformed search methods are a type of search algorithms that do not use any additional information to guide the search process. They only use the information provided in the problem definition, such as the start state, the goal state, and the actions that can be performed in each state. Uninformed search methods explore the search space in a systematic, but blind, manner without considering the cost of reaching the goal or the likelihood of finding a solution. Some of the key features of uninformed search methods are:

- Systematic exploration: Uninformed search methods explore the search space systematically, either by expanding all children of a node (e.g. breadth-first search) or by exploring as deep as possible in a single path before backtracking (e.g. depth-first search).
- No heuristics: Uninformed search methods do not use any additional information, such as heuristics or cost functions, to estimate the quality of a node or a path. They only check if a node is a goal state or not.
- Completeness: Uninformed search methods are guaranteed to find a solution if one exists, as long as the search space is finite and the branching factor is finite.
- Optimality: Uninformed search methods are not guaranteed to find the optimal solution, unless they explore all possible paths to the goal state. Some uninformed search methods, such as uniform-cost search, can find the optimal solution if the path cost is a non-decreasing function of the depth of the node.
- Time and space complexity: Uninformed search methods have high time and space complexity, as they may generate and store a large number of nodes in the search space. The time and space complexity depend on the branching factor, the depth of the solution, and the depth of the search tree.

Some of the common uninformed search methods are:

- Depth-first search (DFS): It is a search algorithm that explores the search tree from the root node and goes as deep as possible in a single path before backtracking. It uses a stack data structure to store the nodes to be expanded. It is not complete in infinite or cyclic graphs, and it is not optimal in general. It has a time complexity of O(b^m) and a space complexity of O(bm), where b is the branching factor and m is the maximum depth of the search tree.
- Breadth-first search (BFS): It is a search algorithm that explores the search tree from the root node and expands all the nodes at a given depth before moving to the next depth level. It uses a queue data structure to store the nodes to be expanded. It is complete and optimal for uniform-cost problems, where all actions have the same cost. It has a time complexity of O(b^d) and a space complexity of O(b^d), where b is the branching factor and d is the depth of the solution.
- Uniform-cost search (UCS): It is a search algorithm that expands the node with the lowest path cost from the root node. It uses a priority queue data structure to store the nodes to be expanded, where the priority is the path cost. It is complete and optimal for any problem with a non-decreasing path cost function. It has a time complexity of O(b^1 + C*/ε) and a space complexity of O(b^1 + C*/ε), where b is the branching factor, C* is the optimal path cost, and ε is the minimum action cost.
- Depth-limited search (DLS): It is a search algorithm that explores the search tree from the root node and goes as deep as a given limit before backtracking. It uses a stack data structure to store the nodes to be expanded. It is not complete and not optimal in general. It has a time complexity of O(b^l) and a space complexity of O(bl), where b is the branching factor and l is the depth limit.
- Iterative deepening search (IDS): It is a search algorithm that combines the benefits of DFS and BFS. It performs a series of DLS with increasing depth limits until a solution is found or the search space is exhausted. It is complete and optimal for uniform-cost problems. It has a time complexity of O(b^d) and a space complexity of O(bd), where b is the branching factor and d is the depth of the solution.
