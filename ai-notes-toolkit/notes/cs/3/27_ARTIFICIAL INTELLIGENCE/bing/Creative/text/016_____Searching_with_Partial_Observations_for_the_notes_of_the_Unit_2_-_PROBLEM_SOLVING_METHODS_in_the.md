### Searching with Partial Observations

- Searching with partial observations is a problem-solving technique in artificial intelligence that deals with environments that are partially observable, meaning that the agent cannot fully perceive the state of the world at any given time.
- In such environments, the agent has to maintain a **belief state**, which is a set of possible states that are consistent with the agent's history of actions and observations.
- A **belief state** can be represented as a probability distribution over the possible states, or as a logical formula that captures the constraints on the possible states.
- A **search problem** with partial observations can be formulated as a **belief-state search problem**, where the initial state is the agent's initial belief state, the goal test is a function that checks if a belief state satisfies the goal condition, the actions are the same as in the original problem, and the successor function maps a belief state and an action to a new belief state that incorporates the effects of the action and the observation.
- A **solution** to a belief-state search problem is a **conditional plan**, which is a sequence of actions and observations that leads the agent from the initial belief state to a goal belief state.
- Searching with partial observations can be very challenging, as the size of the belief state can grow exponentially with the number of actions and observations, and the branching factor of the search tree can be very high.
- Some possible approaches to searching with partial observations are:

  - **Search with no observations**: This is a special case where the agent assumes that the environment is deterministic and fully observable, and ignores any observations. This can be useful if the observations are unreliable or irrelevant, but it can also lead to failure if the agent's assumptions are wrong.
  - **Search with complete observations**: This is another special case where the agent assumes that the environment is deterministic and fully observable, and uses the observations to update its belief state. This can be useful if the observations are reliable and informative, but it can also be unrealistic or infeasible in many domains.
  - **Search with partial observations**: This is the general case where the agent has to deal with uncertainty and incompleteness in both the environment and the observations. The agent has to use probabilistic or logical reasoning to update its belief state, and to evaluate the expected utility of different actions. This can be more realistic and robust, but also more computationally demanding and complex.
  - **Online search**: This is a variant of search where the agent interleaves planning and execution, and adapts its plan based on the observations it receives during execution. This can be useful if the environment is dynamic or unpredictable, or if the agent has limited time or memory. However, online search can also be risky, as the agent may commit to suboptimal or irreversible actions.
