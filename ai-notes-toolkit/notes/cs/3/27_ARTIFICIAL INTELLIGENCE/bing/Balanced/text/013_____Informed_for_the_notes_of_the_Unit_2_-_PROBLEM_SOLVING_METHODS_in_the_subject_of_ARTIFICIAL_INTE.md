### Informed Search
- Informed search is a type of search strategy that uses problem-specific knowledge to guide the search process and find solutions more efficiently.
- Informed search algorithms are also called heuristic search algorithms, because they use a heuristic function to estimate the cost or distance to the goal state from any given state.
- A heuristic function is a function that maps a state to a non-negative real number, which represents the estimated cost or distance to the goal state from that state. The lower the heuristic value, the closer the state is to the goal state.
- A heuristic function should be admissible, which means that it never overestimates the actual cost or distance to the goal state. An admissible heuristic function is also consistent, which means that it satisfies the triangle inequality: for any two states s and s', h(s) <= c(s, s') + h(s'), where c(s, s') is the actual cost of moving from s to s'.
- Some examples of informed search algorithms are:
  - Best-first search: a general search algorithm that expands the node with the lowest heuristic value at each step. It uses a priority queue to store the nodes, ordered by their heuristic values. It is complete and optimal if the heuristic function is admissible and consistent.
  - Greedy best-first search: a special case of best-first search that uses only the heuristic function to guide the search, ignoring the actual cost of the path so far. It is not optimal and may not be complete, but it is fast and memory-efficient.
  - A* search: a special case of best-first search that uses the sum of the actual cost of the path so far and the heuristic value of the node as the evaluation function. It is optimal and complete if the heuristic function is admissible and consistent, but it may require a lot of memory.
  - Iterative deepening A* search: a variant of A* search that uses a threshold to limit the maximum evaluation function value of the nodes to be expanded. It iteratively increases the threshold until a solution is found or the threshold exceeds the lowest evaluation function value in the frontier. It is optimal and complete if the heuristic function is admissible and consistent, and it is more memory-efficient than A* search.
  - Recursive best-first search: a variant of best-first search that uses a recursive algorithm to explore the search space. It keeps track of the best alternative path for each node and prunes the nodes that have a higher evaluation function value than the best alternative path. It is optimal and complete if the heuristic function is admissible and consistent, and it is more memory-efficient than best-first search.
