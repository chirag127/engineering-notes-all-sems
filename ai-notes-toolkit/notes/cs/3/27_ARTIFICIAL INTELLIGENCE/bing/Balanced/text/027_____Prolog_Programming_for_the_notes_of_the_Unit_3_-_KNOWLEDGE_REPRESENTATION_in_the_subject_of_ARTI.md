### Prolog Programming for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

- Knowledge representation (KR) is the process of encoding and manipulating knowledge in a logical and mathematical form for artificial intelligence (AI) applications.
- Propositional logic (PL) is the simplest form of KR, where all the statements are made by propositions, which are declarative sentences that are either true or false.
- Prolog is a logic programming language that has an important role in AI, especially for KR and reasoning. Unlike many other programming languages, Prolog is intended primarily as a declarative programming language, where the programmer specifies what the program should do, not how it should do it.
- In Prolog, logic is expressed as relations, which are called facts and rules. Facts are statements that are always true, such as `father(john, mary).` which means John is the father of Mary. Rules are statements that are conditionally true, such as `grandfather(X, Y) :- father(X, Z), father(Z, Y).` which means X is the grandfather of Y if X is the father of Z and Z is the father of Y.
- Prolog programs consist of a database of facts and rules, and a query engine that can answer questions based on the database. For example, given the facts and rules above, the query `grandfather(john, alice)?` will return `yes` if there is a fact `father(john, bob).` and another fact `father(bob, alice).` in the database.
- Prolog uses a technique called unification to match variables in the query with values in the database. Unification is a process of finding a substitution that makes two terms equal. For example, the query `father(X, mary)?` will unify X with john, since `father(john, mary).` is a fact in the database.
- Prolog also uses a technique called backtracking to explore different possibilities in the database. Backtracking is a process of undoing a choice and trying another one when a dead end is reached. For example, the query `father(X, Y)?` will first unify X with john and Y with mary, then backtrack and unify X with bob and Y with alice, if both facts are in the database.
- Prolog can also handle more complex forms of KR, such as nonmonotonic logic, which allows for reasoning with incomplete or uncertain information. One example of nonmonotonic logic is answer set programming (ASP), which is a KR language with roots in older nonmonotonic logics and Prolog. ASP programs consist of a set of rules that define possible models or answer sets of the program. Each answer set represents a consistent and complete state of the world that satisfies the rules .
