### Prolog Programming

- Prolog stands for **programming in logic** . It is a declarative language, which means that a program consists of data based on the facts and rules (logical relationship) rather than computing how to find a solution.
- Prolog has its roots in **first-order logic**, a formal logic, and unlike many other programming languages, Prolog is intended primarily as a **declarative programming language**: the program logic is expressed in terms of relations, represented as facts and rules. A computation is initiated by running a query over these relations.
- Prolog programming means programming in logic to be used in the **computational semantic**. The prolog programming is based on the fact and rules of the data-based language. A prolog programming is a logical relationship and data-related works for advanced computational technology.
- Prolog programming is based on three main concepts: **unification**, **backtracking**, and **recursion**.
  - Unification: The basic idea is, can the given terms be made to represent the same structure.
  - Backtracking: When a task fails, prolog traces backwards and tries to satisfy previous task.
  - Recursion: Recursion is the basis for any search in program.
- Prolog programming can be used for various applications, such as **artificial intelligence**, **natural language processing**, **expert systems**, **database management**, **game development**, and **web development**  .
- Prolog programming has several **dialects** and **implementations**, such as **Visual Prolog**, **SWI-Prolog**, **SICStus Prolog**, **Gödel**, and **Datalog** . Each dialect may have different syntax, features, and libraries .
