### Searching with Partial Observations

- Searching with partial observations is a type of problem solving method where the agent does not have complete information about the state of the world or the effects of its actions.
- In such problems, the agent has to deal with uncertainty and ambiguity, and use its sensors and memory to gather and update its knowledge.
- Some examples of searching with partial observations are:
  - Navigating a maze with limited vision or hearing.
  - Playing a card game with hidden cards or bluffing.
  - Diagnosing a disease with noisy or incomplete symptoms.
- To solve such problems, the agent can use different types of search algorithms, such as:
  - Blind search: The agent does not use any information about the state of the world or the goal, and tries random actions until it reaches the goal or exhausts its resources. This is the simplest but also the most inefficient method.
  - Heuristic search: The agent uses some information or intuition about the state of the world or the goal, and tries actions that are likely to bring it closer to the goal. This is a more efficient but also more complex method that requires domain knowledge and a good heuristic function.
  - Online search: The agent interleaves planning and execution, and updates its plan based on the feedback from the environment. This is a more flexible but also more risky method that requires the agent to be reactive and adaptive.
  - Belief state search: The agent maintains a set of possible states of the world that are consistent with its observations, and tries actions that are optimal for the worst-case scenario. This is a more robust but also more computationally expensive method that requires the agent to reason about uncertainty and probabilities.
