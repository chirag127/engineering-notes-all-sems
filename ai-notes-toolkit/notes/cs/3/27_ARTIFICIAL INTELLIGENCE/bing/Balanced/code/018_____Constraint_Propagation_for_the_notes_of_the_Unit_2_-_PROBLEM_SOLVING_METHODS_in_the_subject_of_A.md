# Constraint Propagation

- Constraint propagation is a form of reasoning, using a network of related facts, in which a value or range of possible values determined for one variable constrains the possible values of variables to which it is related.
- Constraint propagation can be used to solve constraint satisfaction problems (CSPs), which are problems where a set of variables must be assigned values that satisfy a set of constraints.
- Constraint propagation can be applied to both numeric and symbolic domains, such as computer vision, natural language processing, scheduling, etc.
- Constraint propagation can be performed by applying rules of combination and modification of constraints, such as arc consistency, path consistency, etc.
- Constraint propagation can reduce the search space of a CSP by eliminating inconsistent values from the domains of the variables, or by detecting unsatisfiable constraints.
- Constraint propagation can be used in conjunction with search methods, such as backtracking, to make a given problem simpler to solve.
- Constraint propagation can be implemented using variables ranging over finite domains, and propagators that enforce the constraints on the variables.
