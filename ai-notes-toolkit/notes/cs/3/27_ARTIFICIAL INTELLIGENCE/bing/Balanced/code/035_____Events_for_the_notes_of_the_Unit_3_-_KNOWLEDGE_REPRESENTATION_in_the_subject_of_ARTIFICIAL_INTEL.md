# Events

- Events are the occurrence of things in the real world .
- Events are the actions which occur in our world.
- Events are an essential kind of knowledge in the world.
- Events can trigger changes in the state of objects, relations, and other events.
- Events can be represented by using predicates, arguments, and temporal information.
- Events can be organized as Event Knowledge Graphs (EKGs), which are event-centric knowledge representation forms that link events with entities, relations, and other events.
- Events can be used for various applications, such as event extraction, event summarization, event reasoning, event prediction, and event question answering.
