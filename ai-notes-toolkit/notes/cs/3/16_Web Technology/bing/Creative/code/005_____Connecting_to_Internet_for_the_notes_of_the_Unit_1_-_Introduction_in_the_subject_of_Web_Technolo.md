### Connecting to Internet

- The Internet is a global network of computers and devices that can communicate and share information with each other.
- To connect to the Internet, you need an Internet Service Provider (ISP) that provides you with access to the network.
- There are different ways to connect to the Internet, depending on the type of device, the location, and the speed of the connection.
- Some of the common ways to connect to the Internet are:

  - Wi-Fi: This is a wireless connection that uses radio waves to transmit data between devices and a router. A router is a device that connects multiple devices to a single Internet connection. You can use Wi-Fi to connect to the Internet from your laptop, smartphone, tablet, or other devices that have Wi-Fi capability. To use Wi-Fi, you need to be within the range of a Wi-Fi network, which may be provided by your ISP, a public hotspot, or a private network. You also need to know the network name and password, if any, to join the network. 
  - Ethernet: This is a wired connection that uses a cable to connect your device to a router or a modem. A modem is a device that converts the signals from your ISP into a format that your device can understand. Ethernet is usually faster and more reliable than Wi-Fi, but it limits your mobility and requires a physical port on your device. You can use Ethernet to connect to the Internet from your desktop computer, laptop, or other devices that have an Ethernet port. To use Ethernet, you need to plug one end of the cable into your device and the other end into the router or modem. 
  - Dial-up: This is an outdated connection that uses a phone line and a modem to connect your device to the Internet. Dial-up is very slow and unreliable, and it prevents you from using your phone line for other purposes while you are online. You can use dial-up to connect to the Internet from your desktop computer or laptop that has a modem and a phone jack. To use dial-up, you need to plug your modem into the phone jack, then dial a number provided by your ISP to establish a connection. 

- Once you are connected to the Internet, you can use a web browser to access the web, which is a collection of web pages and other resources hosted on web servers. Web servers are computers that store and deliver web content to web clients. Web clients are devices that request and display web content using web browsers. Web browsers are software applications that allow you to navigate the web using a graphical user interface.
- To access a web page, you need to know its web address, also known as a URL (Uniform Resource Locator). A URL consists of several parts, such as the protocol, the domain name, the path, and the query string. For example, the URL https://www.example.com/index.html?name=Sydney has the following parts:

  - Protocol: This indicates the method of communication between the web client and the web server. The most common protocol is HTTP (Hypertext Transfer Protocol), which defines how web pages are requested and delivered. Other protocols include HTTPS (HTTP Secure), which encrypts the communication for security, and FTP (File Transfer Protocol), which allows file transfer between computers.
  - Domain name: This identifies the web server that hosts the web page. A domain name consists of one or more labels separated by dots, such as www.example.com. The rightmost label is called the top-level domain (TLD), which indicates the type or the location of the web server, such as .com for commercial, .edu for education, or .uk for United Kingdom. The leftmost label is called the subdomain, which specifies a particular section or service of the web server, such as www for the World Wide Web, or mail for email. The middle labels are called the second-level domain and the third-level domain, which are usually chosen by the owner of the web server to represent their name, brand, or organization.
  - Path: This specifies the location of the web page within the web server. A path consists of one or more segments separated by slashes, such as /index.html. The rightmost segment is called the file name, which indicates the name and the format of the web page, such as .html for Hypertext Markup Language, .css for Cascading Style Sheets, or .js for JavaScript.
