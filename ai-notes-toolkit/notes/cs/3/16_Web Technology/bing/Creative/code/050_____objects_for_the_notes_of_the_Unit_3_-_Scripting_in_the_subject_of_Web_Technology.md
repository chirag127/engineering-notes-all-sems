### Objects for the notes of the Unit 3 - Scripting in the subject of Web Technology

- An object is a programming entity that represents a real-world concept or thing, such as a person, a car, a book, etc.
- An object has two main characteristics: data and behavior. Data are the attributes or properties of the object, such as its name, color, size, etc. Behavior are the actions or methods that the object can perform, such as move, speak, read, etc.
- Objects are created from classes, which are blueprints or templates that define the data and behavior of a specific type of object. For example, a class named Person can define the data (name, age, gender, etc.) and behavior (walk, talk, eat, etc.) of a person object.
- Objects can inherit data and behavior from other objects, which are called their parent or superclass objects. This is called inheritance, and it allows for code reuse and specialization. For example, a class named Student can inherit from the Person class, and add more data (grade, major, etc.) and behavior (study, take exams, etc.) specific to a student object.
- Objects can also encapsulate data and behavior, which means that they can hide some of their details from the outside world, and only expose what is necessary or relevant. This is called encapsulation, and it allows for abstraction and modularity. For example, a class named Car can encapsulate the data (engine, wheels, etc.) and behavior (start, stop, accelerate, etc.) of a car object, and only provide a simple interface (key, pedal, steering wheel, etc.) for the user to interact with the car object.
- Scripting languages are programming languages that are designed for writing short and simple scripts, which are programs that automate tasks or manipulate data. Scripting languages are usually interpreted, which means that they are executed line by line by a program called an interpreter, rather than compiled, which means that they are translated into machine code by a program called a compiler.
- Scripting languages are often used for web development, as they can interact with web browsers, web servers, databases, and other web technologies. Some of the most popular scripting languages for web development are JavaScript, Python, Ruby, PHP, and Perl.
- Scripting languages can also support object-oriented programming, which means that they can create and manipulate objects as described above. However, some scripting languages are not strictly class-based, which means that they do not require classes to create objects. Instead, they use prototypes, which are template objects that can be cloned and modified to create new objects. This is called prototype-based programming, and it allows for more flexibility and dynamism. An example of a commonly used prototype-based scripting language is JavaScript.
