### I/O for the notes of the Unit 1 - Introduction

- I/O stands for input/output, which refers to the communication between a computer system and the external world.
- Input is the data or information that is given to a computer system by a user, a device, or another system.
- Output is the data or information that is produced by a computer system for a user, a device, or another system.
- I/O devices are the hardware components that enable input and output operations, such as keyboards, mice, monitors, printers, scanners, speakers, etc.
- I/O interfaces are the software components that manage the interaction between the computer system and the I/O devices, such as drivers, protocols, standards, etc.
- I/O operations are the processes that involve transferring data or information between the computer system and the I/O devices, such as reading, writing, displaying, printing, scanning, etc.
- I/O is an essential aspect of web technology, as it enables the exchange of data or information between web servers and web clients, such as browsers, applications, etc.
- Web servers are computer systems that host web resources, such as web pages, images, videos, etc., and respond to requests from web clients.
- Web clients are computer systems or devices that access web resources from web servers, using web protocols, such as HTTP, HTTPS, FTP, etc.
- Web protocols are the rules and standards that define how web servers and web clients communicate with each other, such as the format, structure, and syntax of the messages, the methods and parameters of the requests and responses, the security and encryption of the data, etc.
- Web resources are the data or information that are available on the web, such as web pages, images, videos, etc., and are identified by unique addresses, called URLs (Uniform Resource Locators).
- Web pages are the most common type of web resources, and are composed of HTML (Hypertext Markup Language) documents, which contain the content and structure of the web page, and optionally CSS (Cascading Style Sheets) and JavaScript, which provide the style and functionality of the web page.
- HTML documents are composed of elements, which are the building blocks of the web page, and are defined by tags, which are the keywords that specify the type and attributes of the elements.
- CSS is a language that defines the presentation of the HTML elements, such as the color, font, layout, etc., and can be embedded in the HTML document or linked as a separate file.
- JavaScript is a scripting language that defines the behavior of the HTML elements, such as the interaction, animation, validation, etc., and can be embedded in the HTML document or linked as a separate file.
