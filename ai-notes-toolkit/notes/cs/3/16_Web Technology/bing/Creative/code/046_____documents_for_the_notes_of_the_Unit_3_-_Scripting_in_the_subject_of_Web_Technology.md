### Unit 3 - Scripting

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server, rather than compiled by a compiler.
- Scripting languages are often embedded in HTML documents, using special tags or attributes, such as `<script>` or `onclick`.
- Scripting languages can manipulate the content, structure, and style of web pages, as well as communicate with web servers and databases.
- Scripting languages can also provide user interactivity, such as validating user input, creating pop-up windows, or responding to user events.
- Some examples of scripting languages are JavaScript, PHP, Python, Ruby, and Perl.

#### JavaScript

- JavaScript is the most widely used scripting language for web development.
- JavaScript is a client-side scripting language, which means it runs on the user's browser, not on the web server.
- JavaScript can access and modify the HTML elements and CSS properties of a web page, using the Document Object Model (DOM).
- JavaScript can also use the Browser Object Model (BOM) to interact with the browser window, such as changing the URL, opening new tabs, or displaying alerts.
- JavaScript can also use the XMLHttpRequest object to send and receive data from a web server, using the Asynchronous JavaScript and XML (AJAX) technique.
- JavaScript can also use the JSON (JavaScript Object Notation) format to exchange data with web servers and databases, using a simple and lightweight syntax.
- JavaScript can also use various libraries and frameworks, such as jQuery, React, Angular, and Vue, to simplify and enhance web development.

#### PHP

- PHP is a server-side scripting language, which means it runs on the web server, not on the user's browser.
- PHP can embed code in HTML documents, using the `<?php ?>` tags, or use separate files with the `.php` extension.
- PHP can connect to various databases, such as MySQL, PostgreSQL, Oracle, and MongoDB, using the PDO (PHP Data Objects) or mysqli (MySQL Improved) extensions.
- PHP can also use the $_GET, $_POST, $_COOKIE, and $_SESSION superglobals to access data from the URL, forms, cookies, and sessions, respectively.
- PHP can also use various built-in functions and libraries, such as date, string, array, and math functions, to perform various operations and calculations.
- PHP can also use various frameworks, such as Laravel, Symfony, CodeIgniter, and CakePHP, to simplify and enhance web development.
