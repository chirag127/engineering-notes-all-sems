# Forms

- A web form, also called an HTML form, is an online page that allows for user input.
- It is an interactive page that mimics a paper document or form, where users fill out particular fields.
- Web forms can be rendered in modern browsers using HTML and related web-oriented languages.
- Web forms can for example include the following form elements: text boxes, text areas, radio buttons, check boxes, dropdown lists, hidden fields, file upload, and buttons.
- Web forms often act as a communication bridge that allows a user to communicate with a company and vice versa.
- Web forms can be used for various purposes, such as signing up for a newsletter, placing an order, registering for an account, submitting feedback, etc .
- Web forms are typically enclosed by a `<form>` element, which defines the form and its attributes, such as the action, method, enctype, name, etc.
- The `<form>` element can contain various input elements, such as `<input>`, `<select>`, `<textarea>`, `<button>`, etc, which define the type, name, value, label, and appearance of the user input.
- The `<form>` element can also contain other elements, such as `<fieldset>`, `<legend>`, `<label>`, `<output>`, etc, which provide structure, accessibility, and feedback for the form.
- Web forms can be validated, processed, and stored using various scripting languages, such as JavaScript, PHP, Python, etc, depending on the server-side and client-side requirements .
- Web forms can be enhanced, customized, and integrated with other web services using various tools, such as Google Forms, HubSpot, Bootstrap, etc, depending on the design and functionality needs .
