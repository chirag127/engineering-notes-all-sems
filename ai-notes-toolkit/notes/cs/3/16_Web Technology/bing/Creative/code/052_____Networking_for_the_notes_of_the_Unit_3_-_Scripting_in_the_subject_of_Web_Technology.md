### Networking for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Networking is the process of connecting multiple devices or systems over a network, such as the Internet, to exchange information and data.
- Networking can be done using various protocols, such as TCP/IP, HTTP, FTP, SMTP, etc.
- Networking can also involve programming, which is the process of creating and executing code to perform specific tasks or functions on a network.
- Networking programming can be done using various languages, such as Python, C#, JavaScript, etc.
- Networking programming can be classified into two types: client-side and server-side.

#### Client-side programming
- Client-side programming is the process of creating and embedding scripts in a web page that are executed by the web browser of the user.
- Client-side scripts can be used to enhance the interactivity, functionality, and appearance of a web page, such as validating user input, creating animations, or displaying dynamic content.
- Client-side scripts can be written in various languages, such as HTML, CSS, JavaScript, etc.
- Client-side scripts can also use AJAX (Asynchronous JavaScript and XML) to communicate with the server without reloading the web page.
- Client-side scripts have limited access to the user's system and the network, and they depend on the browser's compatibility and support.

#### Server-side programming
- Server-side programming is the process of creating and executing scripts on a web server that produce a customized response for each user.
- Server-side scripts can be used to perform complex tasks, such as accessing databases, processing forms, sending emails, or generating dynamic web pages.
- Server-side scripts can be written in various languages, such as PHP, Python, Ruby, C#, JavaScript (NodeJS), etc.
- Server-side scripts can also use frameworks, such as Django, Flask, Rails, ASP.NET, Express, etc., to simplify and speed up the development process.
- Server-side scripts have full access to the server's operating system and the network, and they can choose what programming language and version they wish to use.
