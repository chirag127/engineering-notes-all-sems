### Event handling

- Event handling is the process of creating and executing code that responds to changes in the browser or operating system environment.
- Events are signals that indicate user actions, such as clicking a button, moving the mouse, typing a key, or loading a page .
- Event handlers are functions or methods that are attached to specific elements or objects, and are invoked when the corresponding event occurs .
- Event handlers can be used to create dynamic and interactive web pages, by modifying the content, style, or behavior of the elements or objects in response to user input .
- Event handlers can be added or removed using methods such as `addEventListener()` and `removeEventListener()` .
- Event handlers can be registered for different types of events, such as `click`, `mouseover`, `keydown`, `load`, etc .
- Event handlers can access information about the event, such as the target element, the mouse position, the key code, etc, using the event object that is passed as a parameter to the handler function .
- Event handlers can also control the propagation and default behavior of the event, by using methods such as `stopPropagation()` and `preventDefault()` .
