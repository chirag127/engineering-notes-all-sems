- Scripting is the process of creating and embedding scripts in a web page to add dynamic capabilities and interactivity.
- Scripts are lists of commands that are interpreted and executed by a certain program or scripting engine.
- Scripting languages are high-level languages that are easy to learn and use, and do not require compilation.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages run on the browser and manipulate the web page elements without reloading the page. Examples are JavaScript, VBScript, and HTML5  .
- Server-side scripting languages run on the web server and generate dynamic web pages based on user input or database queries. Examples are PHP, ASP, Perl, Python, and Ruby on Rails  .
- Scripting languages can communicate with each other and with other web technologies such as HTML, CSS, XML, JSON, AJAX, etc .
- Scripting languages can enhance the functionality, usability, and security of web applications .
