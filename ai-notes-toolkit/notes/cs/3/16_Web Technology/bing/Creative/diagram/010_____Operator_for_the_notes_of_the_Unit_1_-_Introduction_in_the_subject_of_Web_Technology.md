### Operator

- An operator is a symbol or a keyword that performs a specific operation on one or more operands.
- An operand is a value or a variable that is involved in the operation.
- Operators can be classified into different types based on the number of operands, the type of operands, and the functionality of the operation.
- Some of the common types of operators are:

  - Arithmetic operators: These operators perform basic mathematical operations such as addition, subtraction, multiplication, division, modulus, exponentiation, and increment/decrement. For example, `+`, `-`, `*`, `/`, `%`, `**`, `++`, `--`.
  - Assignment operators: These operators assign a value to a variable or a property. For example, `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`.
  - Comparison operators: These operators compare two operands and return a boolean value (true or false) based on the result of the comparison. For example, `==`, `!=`, `===`, `!==`, `>`, `<`, `>=`, `<=`.
  - Logical operators: These operators perform logical operations on one or more boolean operands and return a boolean value. For example, `&&` (logical AND), `||` (logical OR), `!` (logical NOT).
  - Bitwise operators: These operators perform bitwise operations on one or more integer operands and return an integer value. For example, `&` (bitwise AND), `|` (bitwise OR), `^` (bitwise XOR), `~` (bitwise NOT), `<<` (left shift), `>>` (right shift), `>>>` (unsigned right shift).
  - String operators: These operators perform operations on string operands and return a string value. For example, `+` (concatenation), `+=` (concatenation assignment), `[]` (indexing), `slice()` (substring extraction), `indexOf()` (searching), `replace()` (replacing), `toUpperCase()` (converting to upper case), `toLowerCase()` (converting to lower case).
  - Conditional operator: This operator evaluates a condition and returns one of two values based on the result of the condition. For example, `condition ? value1 : value2`.
  - Comma operator: This operator evaluates two or more expressions and returns the value of the last expression. For example, `x = (y = 3, y + 1)`.
  - Spread operator: This operator expands an iterable object (such as an array or a string) into individual elements. For example, `...array`.
  - Rest operator: This operator collects the remaining elements of an iterable object (such as an array or a string) into an array. For example, `function(...args)`.
  - Destructuring operator: This operator extracts the values of properties or elements from an object or an array and assigns them to variables. For example, `{x, y} = obj`, `[a, b] = arr`.
  - New operator: This operator creates a new instance of a constructor function or a class. For example, `new Date()`.
  - Delete operator: This operator removes a property from an object. For example, `delete obj.prop`.
  - Typeof operator: This operator returns the data type of an operand. For example, `typeof 42`.
  - Instanceof operator: This operator tests whether an object is an instance of a constructor function or a class. For example, `obj instanceof Date`.
  - In operator: This operator tests whether a property exists in an object. For example, `"prop" in obj`.
  - Of operator: This operator iterates over the values of an iterable object (such as an array or a string). For example, `for (let value of array)`.
  - Await operator: This operator pauses the execution of an async function until a promise is resolved or rejected. For example, `let result = await promise`.
  - Yield operator: This operator pauses the execution of a generator function and returns a value to the caller. For example, `function* generator() { yield 1; yield 2; yield 3; }`.
  - Void operator: This operator evaluates an expression and returns undefined. For example, `void 0`.
  - This operator: This operator refers to the current object or context. For example, `this.name`.
