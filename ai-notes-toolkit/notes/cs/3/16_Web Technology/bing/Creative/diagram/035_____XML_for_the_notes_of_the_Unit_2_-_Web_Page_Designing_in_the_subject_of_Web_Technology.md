### XML

- XML stands for **Extensible Markup Language**   .
- XML is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable   .
- XML is a text-based markup language derived from Standard Generalized Markup Language (SGML).
- XML is designed to store and transport data via various web services connecting different applications and promoting data exchange .
- XML is a simple and powerful tool in this era of data flow between multiple applications.
- XML is a software- and hardware-independent tool for storing and transporting data.
- XML is a self-descriptive markup language   that does not specify how to display the data like HTML .
- XML allows users to define their own tags designed specifically for their needs.
- XML is a W3C (World Wide Web Consortium) recommendation.
