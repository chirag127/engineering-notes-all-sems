### Implicit Objects

- Implicit objects are a set of Java objects that the JSP container makes available to developers in each page   .
- These objects can be accessed as built-in variables via scripting elements and can also be accessed programmatically by JavaBeans and Servlets.
- Implicit objects are created during the translation phase of JSP to the servlet. These objects are created as local variables inside the service() method generated by the container.
- Implicit objects provide access to various aspects of the web application, such as the request, the response, the session, the application context, etc .
- There are 9 implicit objects in JSP . They are:

  - **out**: It is an object of JspWriter class that is used to write any data to the buffer. It has methods such as print(), println(), clear(), clearBuffer(), flush(), etc.
  - **request**: It is an object of HttpServletRequest class that represents the HTTP request from the client. It has methods such as getParameter(), getParameterValues(), getAttribute(), setAttribute(), getHeader(), getCookies(), etc.
  - **response**: It is an object of HttpServletResponse class that represents the HTTP response to the client. It has methods such as setContentType(), addCookie(), sendRedirect(), setStatus(), etc.
  - **session**: It is an object of HttpSession class that represents the session between the client and the server. It has methods such as getId(), getCreationTime(), getLastAccessedTime(), getMaxInactiveInterval(), setMaxInactiveInterval(), getAttribute(), setAttribute(), removeAttribute(), invalidate(), etc.
  - **application**: It is an object of ServletContext class that represents the application context or the web application. It has methods such as getInitParameter(), getInitParameterNames(), getAttribute(), setAttribute(), removeAttribute(), getRealPath(), getServerInfo(), getServletContextName(), etc.
  - **config**: It is an object of ServletConfig class that represents the configuration information of the JSP page. It has methods such as getInitParameter(), getInitParameterNames(), getServletContext(), getServletName(), etc.
  - **page**: It is an object of Object class that represents the current JSP page. It is equivalent to this keyword in Java.
  - **pageContext**: It is an object of PageContext class that represents the context of the current JSP page. It has methods such as getAttribute(), setAttribute(), removeAttribute(), findAttribute(), getOut(), getRequest(), getResponse(), getSession(), getApplication(), getConfig(), getPage(), forward(), include(), handlePageException(), etc.
  - **exception**: It is an object of Throwable class that represents the exception thrown in the current JSP page. It is only available in the error pages that have the directive <%@ page isErrorPage="true" %>. It has methods such as getMessage(), getCause(), getStackTrace(), printStackTrace(), etc.

- Implicit objects are not available in servlets, as servlets are lower-level components that do not have the JSP container's support. To access the implicit objects in servlets, we need to use the request and response objects explicitly. For example, to get the session object in servlet, we need to write:

  ```java
  HttpSession session = request.getSession(true);
  ```
