### Introduction

- Scripting is a technique of writing code that can be executed by an interpreter or a browser to perform a specific task or function on a web page or a web application.
- Scripting languages are high-level languages that are easy to write, read and debug. They do not need to be compiled before running, unlike programming languages such as C, Java or C#.
- Scripting languages are often used to add interactivity, dynamism, validation, animation and other features to web pages and web applications. They can also be used to manipulate data, communicate with servers, access databases and perform other tasks.
- Some of the common scripting languages used in web development are JavaScript, PHP, Python, Ruby, Perl and ASP.NET.
- Scripting languages can be classified into two types: client-side scripting and server-side scripting.

  - Client-side scripting is the code that runs on the user's browser and interacts with the HTML document and the DOM (Document Object Model). It can respond to user events, validate user input, manipulate web page elements, create cookies and perform other tasks. Examples of client-side scripting languages are JavaScript, VBScript and ActionScript.
  - Server-side scripting is the code that runs on the web server and interacts with the HTTP request and response. It can process user data, generate dynamic web pages, access databases, send emails and perform other tasks. Examples of server-side scripting languages are PHP, Python, Ruby, Perl and ASP.NET.
