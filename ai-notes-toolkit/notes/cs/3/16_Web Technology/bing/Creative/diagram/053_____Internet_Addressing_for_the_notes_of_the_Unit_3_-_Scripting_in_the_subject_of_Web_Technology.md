### Internet Addressing

- Internet addressing is the process of assigning a unique identifier to each device or host that communicates over the internet.
- Internet addresses are used by the Internet Protocol (IP) and other higher-level protocols to route packets through the network.
- There are two versions of IP: IPv4 and IPv6, which have different formats and capacities for internet addresses.
- IPv4 addresses are 32-bit binary numbers, usually written in dotted decimal notation, such as 192.168.0.1. Each IPv4 address consists of two parts: a network prefix and a host identifier. The network prefix identifies the network or subnet to which the host belongs, and the host identifier identifies the specific host within that network or subnet. The length of the network prefix varies depending on the class of the address or the subnet mask applied to it.
- IPv6 addresses are 128-bit binary numbers, usually written in hexadecimal notation, such as 2001:db8::1. Each IPv6 address consists of two parts: a 64-bit network prefix and a 64-bit interface identifier. The network prefix identifies the network or subnet to which the host belongs, and the interface identifier identifies the specific interface of the host within that network or subnet. The interface identifier can be derived from the MAC address of the host or randomly generated.
- Each internet host is assigned at least one unique internet address. However, some hosts may have more than one address, such as gateway hosts that connect different networks or hosts that have multiple interfaces. Each interface to an internet is assigned its own unique address.
- Each IP address is associated with virtual ports in a computer that act as a doorway that allows web applications or websites to send and receive data or information on your device. The ports are identified by 16-bit numbers, ranging from 0 to 65535. Some ports are reserved for well-known services, such as port 80 for HTTP or port 443 for HTTPS.
- The internet is made up of interconnected large networks that are each responsible for certain blocks of IP addresses; these large networks are known as autonomous systems (AS). A variety of routing protocols, such as Border Gateway Protocol (BGP), help route packets across ASes based on their destination IP addresses.
