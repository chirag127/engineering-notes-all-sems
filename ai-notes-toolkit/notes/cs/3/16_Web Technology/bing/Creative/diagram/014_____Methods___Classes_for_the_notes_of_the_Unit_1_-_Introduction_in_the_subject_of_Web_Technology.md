### Methods & Classes

- A method is a set of instructions that performs a specific task or operation on an object or a class.
- A class is a blueprint or a template that defines the attributes and behaviors of a group of objects that share common characteristics.
- In web technology, methods and classes are used to create dynamic and interactive web pages that can respond to user actions and events.
- Some examples of methods and classes in web technology are:

  - The `document` object represents the HTML document that is displayed in the browser. It has methods such as `getElementById()`, `createElement()`, `write()` and `close()` that can manipulate the document elements and content.
  - The `window` object represents the browser window or tab that contains the document. It has methods such as `alert()`, `confirm()`, `prompt()` and `open()` that can display dialog boxes and open new windows or tabs.
  - The `Math` object is a built-in object that provides mathematical constants and functions. It has methods such as `random()`, `round()`, `sqrt()` and `sin()` that can perform various calculations.
  - The `String` object is a built-in object that represents a sequence of characters. It has methods such as `length()`, `indexOf()`, `slice()` and `replace()` that can manipulate strings.
  - The `Date` object is a built-in object that represents a date and time. It has methods such as `getFullYear()`, `getMonth()`, `getDate()` and `getTime()` that can get and set the date and time components.
  - The `Array` object is a built-in object that represents a list of values. It has methods such as `push()`, `pop()`, `shift()` and `sort()` that can add, remove, reorder and sort the array elements.
  - The `XMLHttpRequest` object is a built-in object that allows communication with a server without reloading the page. It has methods such as `open()`, `send()`, `abort()` and `setRequestHeader()` that can send and receive data from the server.
  - The `jQuery` object is a library object that simplifies the use of JavaScript and DOM manipulation. It has methods such as `ready()`, `ajax()`, `hide()` and `fadeIn()` that can handle document loading, server requests, animations and effects.
