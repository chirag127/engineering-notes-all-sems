### Data type

- A data type is a classification of data that specifies how the data is stored, manipulated, and displayed by a computer system.
- Data types are important for web development because they determine how the web browser interprets and renders the data on a web page.
- Some common data types used in web development are:

  - **Text**: A sequence of characters that can represent words, sentences, paragraphs, or any other textual information. Text can be formatted using HTML tags, CSS styles, or JavaScript functions. Examples of text data are: `<p>Hello, world!</p>`, `"Sydney"`, `document.title`.
  - **Number**: A numerical value that can be used for calculations, comparisons, or measurements. Numbers can be integers (whole numbers) or decimals (fractional numbers). Examples of number data are: `42`, `3.14`, `Math.PI`.
  - **Boolean**: A logical value that can be either true or false. Booleans are used for conditional statements, loops, or boolean operations. Examples of boolean data are: `true`, `false`, `5 > 3`.
  - **Array**: A collection of data items that are stored in a sequential order and accessed by their index (position). Arrays can store any type of data, including other arrays. Examples of array data are: `[1, 2, 3]`, `["red", "green", "blue"]`, `[[1, 2], [3, 4]]`.
  - **Object**: A collection of data items that are stored in a key-value pair format and accessed by their key (name). Objects can store any type of data, including other objects. Examples of object data are: `{name: "Sydney", age: 21}`, `{x: 10, y: 20, z: 30}`, `{person: {name: "Alice", age: 25}, animal: {name: "Bob", type: "cat"}}`.
  - **Function**: A block of code that can be executed when called by its name or assigned to a variable. Functions can take parameters (inputs) and return values (outputs). Functions can also be nested inside other functions. Examples of function data are: `function add(a, b) {return a + b;}`, `var square = function(x) {return x * x;}`, `function greet(name) {function sayHello() {return "Hello, " + name;}; return sayHello();}`.
