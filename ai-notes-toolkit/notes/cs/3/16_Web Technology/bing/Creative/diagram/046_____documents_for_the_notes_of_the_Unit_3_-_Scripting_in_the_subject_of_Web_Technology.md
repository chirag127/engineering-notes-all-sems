### Documents for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a programming technique that allows the creation of dynamic and interactive web pages.
- Scripting languages are interpreted, not compiled, and run on the client-side or the server-side of the web application.
- Client-side scripting languages run on the web browser and manipulate the HTML document object model (DOM) and the browser events. Examples are JavaScript, VBScript, and TypeScript.
- Server-side scripting languages run on the web server and generate the HTML code that is sent to the browser. Examples are PHP, Python, Ruby, and ASP.NET.
- Scripting languages have some common features, such as variables, data types, operators, expressions, statements, functions, objects, arrays, and control structures.
- Scripting languages also have some specific features, such as built-in objects, libraries, frameworks, and APIs that provide additional functionality and interaction with the web environment.
- Scripting languages can be embedded in HTML using the `<script>` tag or linked to an external file using the `src` attribute.
- Scripting languages can also be used to create web applications that use the AJAX (Asynchronous JavaScript and XML) technique, which allows the exchange of data between the browser and the server without reloading the web page.
- Scripting languages can also be used to create web applications that use the REST (Representational State Transfer) architecture, which defines a set of principles and constraints for designing web services that are based on the HTTP protocol and the resource-oriented approach.
