### JavaScript
- JavaScript is a **scripting language** that can be used to create dynamic and interactive web pages.
- JavaScript can run on both the **client-side** (browser) and the **server-side** (Node.js).
- JavaScript is a **multi-paradigm** language that supports **object-oriented**, **imperative**, and **declarative** (e.g. functional) programming styles.
- JavaScript is a **prototype-based** language that uses **prototypal inheritance** instead of classes.
- JavaScript is a **single-threaded** language that uses **asynchronous** and **event-driven** mechanisms to handle concurrent operations.
- JavaScript is a **dynamic** and **weakly typed** language that does not require variable declarations or type annotations.

### JavaScript Basics
- JavaScript uses **variables** to store values of different **data types**, such as **strings**, **numbers**, **booleans**, **objects**, **arrays**, **functions**, etc.
- JavaScript uses **operators** to perform arithmetic, logical, comparison, assignment, and other operations on values and variables.
- JavaScript uses **statements** to control the flow of execution, such as **if-else**, **switch-case**, **for**, **while**, **break**, **continue**, etc.
- JavaScript uses **functions** to define reusable blocks of code that can take parameters and return values.
- JavaScript uses **objects** to store key-value pairs of properties and methods that can be accessed using dot (.) or bracket ([]) notation.
- JavaScript uses **arrays** to store ordered collections of values that can be accessed using index (0-based) or methods (e.g. push, pop, slice, etc.).
- JavaScript uses **events** to handle user interactions, such as **click**, **mouseover**, **keydown**, etc., by attaching **event listeners** and **event handlers** to HTML elements.
- JavaScript uses the **Document Object Model (DOM)** to manipulate the structure and content of web pages using methods (e.g. getElementById, querySelector, createElement, etc.) and properties (e.g. innerHTML, style, className, etc.).
- JavaScript uses the **Browser Object Model (BOM)** to interact with the browser and its components, such as **window**, **location**, **history**, **navigator**, **screen**, etc.
- JavaScript uses **built-in objects** to provide common functionality, such as **Math**, **Date**, **String**, **Number**, **Boolean**, **Array**, **Object**, **Function**, etc.
