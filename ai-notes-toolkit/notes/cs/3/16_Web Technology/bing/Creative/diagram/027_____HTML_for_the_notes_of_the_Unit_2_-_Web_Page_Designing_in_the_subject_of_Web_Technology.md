### HTML
- HTML stands for Hyper Text Markup Language. It is the code that is used to structure a web page and its content.
- HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear or act a certain way.
- HTML elements are made up of a start tag, an end tag, and the content between them. For example, `<p>This is a paragraph.</p>`
- Some HTML elements are self-closing, which means they do not need an end tag. For example, `<img src="image.jpg" alt="An image">`
- HTML elements can have attributes, which are additional information that modify or describe the element. Attributes are specified in the start tag, and usually consist of a name and a value. For example, `<a href="https://www.example.com">A link</a>`
- HTML elements can be nested, which means they can contain other elements. For example, `<p>This is a <strong>bold</strong> word.</p>`
- HTML elements can be grouped into different categories, such as:
  - Metadata: Elements that provide information about the page, such as `<head>`, `<title>`, `<meta>`, `<link>`, etc.
  - Content: Elements that define the main content of the page, such as `<body>`, `<h1>` to `<h6>`, `<p>`, `<div>`, `<span>`, etc.
  - Text: Elements that define the text formatting and semantics, such as `<strong>`, `<em>`, `<a>`, `<abbr>`, `<code>`, etc.
  - Multimedia: Elements that embed media content, such as `<img>`, `<audio>`, `<video>`, `<canvas>`, `<svg>`, etc.
  - Forms: Elements that create interactive forms, such as `<form>`, `<input>`, `<label>`, `<button>`, `<select>`, etc.
  - Tables: Elements that create tabular data, such as `<table>`, `<tr>`, `<td>`, `<th>`, `<caption>`, etc.
  - Lists: Elements that create ordered or unordered lists, such as `<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`, etc.
  - Scripts: Elements that execute or include scripts, such as `<script>`, `<noscript>`, `<iframe>`, etc.
- HTML documents have a basic structure, which consists of:
  - A document type declaration (`<!DOCTYPE html>`) that specifies the HTML version.
  - A `<html>` element that wraps the whole document.
  - A `<head>` element that contains the metadata of the document, such as the title, the character encoding, the style sheets, etc.
  - A `<body>` element that contains the main content of the document, such as the headings, the paragraphs, the images, etc.
- HTML documents can be validated using online tools, such as the W3C Markup Validation Service, to check for syntax errors and compatibility issues.
