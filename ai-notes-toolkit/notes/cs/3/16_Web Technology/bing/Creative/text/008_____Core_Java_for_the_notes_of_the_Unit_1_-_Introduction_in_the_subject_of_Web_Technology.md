### Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

- Core Java is the basic and fundamental part of the Java programming language that is used for developing general-purpose applications.
- Core Java covers the essential concepts and features of the Java language, such as data types, operators, control statements, classes, objects, inheritance, polymorphism, exception handling, collections, input/output, etc.
- Core Java is also the foundation for developing advanced Java technologies, such as Java Enterprise Edition (JEE), Java Database Connectivity (JDBC), Java Servlets, Java Server Pages (JSP), Java Server Faces (JSF), etc.
- Web Technology is the use of various tools and techniques to create and deliver web-based applications and services over the internet.
- Web Technology involves the use of web servers, web browsers, web protocols, web languages, web frameworks, web databases, web security, web design, web development, etc.
- Web Technology enables the communication and interaction between users and web applications, as well as the integration and interoperability of different web systems and platforms.
- Core Java is one of the most popular and widely used web technologies for creating dynamic, interactive, and scalable web applications.
- Core Java provides the functionality and flexibility to create web applications that can run on any platform and device, using the Java Virtual Machine (JVM).
- Core Java also provides the support for various web standards and protocols, such as HTTP, HTTPS, TCP/IP, FTP, SMTP, etc.
- Core Java also provides the libraries and frameworks for developing web applications, such as Servlet API, Java Server Pages (JSP), Java Server Faces (JSF), Java Server Pages Standard Tag Library (JSTL), etc.
- Core Java also provides the tools and techniques for connecting and manipulating web databases, such as Java Database Connectivity (JDBC), Java Persistence API (JPA), Hibernate, etc.
- Core Java also provides the features and mechanisms for ensuring the security and reliability of web applications, such as encryption, authentication, authorization, session management, exception handling, logging, etc.
