### Statements for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is the process of creating and embedding scripts in a web page to add dynamic capabilities and interactivity.
- Scripts are lists of commands that are interpreted and executed by a certain program or scripting engine.
- Scripting languages are high-level languages that are easy to write and run without compilation.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages are executed by the browser on the user's device and manipulate the web page elements.
- Examples of client-side scripting languages are JavaScript, VBScript, and HTML5.
- Server-side scripting languages are executed by the web server and generate dynamic web pages based on the user's request.
- Examples of server-side scripting languages are PHP, ASP, Perl, Python, and Ruby on Rails.
- Scripting languages can be used for various purposes, such as validating user input, creating animations, fetching data, sending emails, and more.
- JavaScript is the most widely used scripting language for web development and can interact with HTML, CSS, and web APIs.
- Web APIs are application programming interfaces that provide access to web features and services, such as geolocation, storage, media, and more.
