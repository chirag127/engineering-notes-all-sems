### DTD for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- DTD stands for Document Type Definition. It is a set of rules that defines the structure and content of an XML or HTML document.
- DTD specifies what elements, attributes, entities, and notations are allowed in a document, and how they are related to each other.
- DTD can be declared either internally or externally. An internal DTD is embedded within the document itself, while an external DTD is referenced by a URL or a file name.
- DTD can be used to validate a document against a predefined schema, to ensure that it conforms to the rules and standards of the DTD.
- DTD can also be used to provide information to applications that process the document, such as browsers, editors, parsers, or converters.
- DTD consists of the following components:
  - Element declarations: define the names and types of elements that can appear in a document, and their possible attributes and child elements.
  - Attribute declarations: define the names and types of attributes that can be associated with an element, and their default or fixed values.
  - Entity declarations: define the names and values of entities that can be used to represent special characters, symbols, or strings in a document.
  - Notation declarations: define the names and formats of external data that can be embedded or referenced in a document, such as images, audio, or video.
  - Comments: provide additional information or explanation about the DTD or the document, and are ignored by the applications that process the document.
  - Processing instructions: provide instructions to the applications that process the document, such as how to display or handle the document.
