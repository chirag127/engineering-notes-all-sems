### AWT controls

- AWT stands for Abstract Window Toolkit, which is a set of APIs for developing graphical user interfaces or web applications in Java .
- AWT controls are components that allow a user to interact with the application in various ways, such as clicking buttons, entering text, selecting options, etc .
- AWT controls are subclasses of the java.awt.Component class, which is the root class for all graphical components .
- AWT controls can be divided into two categories: lightweight and heavyweight .
  - Lightweight controls are those that do not have a native peer, which means they are drawn and handled by Java code only. Examples of lightweight controls are Label, Button, Checkbox, etc .
  - Heavyweight controls are those that have a native peer, which means they are drawn and handled by the underlying platform's windowing system. Examples of heavyweight controls are Frame, Dialog, FileDialog, etc .
- AWT controls can be added to containers, which are components that can hold other components. Containers are subclasses of the java.awt.Container class, which is a subclass of the java.awt.Component class .
- AWT containers can be divided into two categories: top-level and intermediate .
  - Top-level containers are those that have a title bar, border, and menu bar. They are independent windows that can be displayed on the screen. Examples of top-level containers are Frame, Dialog, and FileDialog .
  - Intermediate containers are those that do not have a title bar, border, or menu bar. They are used to group and organize other components within a top-level container. Examples of intermediate containers are Panel, ScrollPane, and Applet .
- AWT controls can be arranged in different layouts, which are subclasses of the java.awt.LayoutManager interface. Layouts are used to specify how components are positioned and sized within a container .
- AWT supports the following types of layouts: BorderLayout, FlowLayout, GridLayout, CardLayout, and GridBagLayout .
- AWT controls can respond to various events, which are subclasses of the java.awt.AWTEvent class. Events are objects that represent the user's actions, such as mouse clicks, keyboard presses, window closing, etc .
- AWT supports the following types of events: ActionEvent, AdjustmentEvent, ComponentEvent, ContainerEvent, FocusEvent, ItemEvent, KeyEvent, MouseEvent, MouseWheelEvent, PaintEvent, TextEvent, WindowEvent, etc .
- AWT controls can register listeners, which are objects that implement the java.awt.event.EventListener interface or its subinterfaces. Listeners are used to handle the events generated by the controls .
- AWT supports the following types of listeners: ActionListener, AdjustmentListener, ComponentListener, ContainerListener, FocusListener, ItemListener, KeyListener, MouseListener, MouseWheelListener, TextListener, WindowListener, etc .
