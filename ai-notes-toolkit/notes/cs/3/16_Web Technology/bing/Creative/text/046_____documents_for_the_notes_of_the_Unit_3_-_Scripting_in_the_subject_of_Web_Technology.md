### Documents for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server at run-time, rather than compiled beforehand.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages are executed by the browser on the user's device, and can manipulate the HTML document, the browser window, and the user interface. Examples of client-side scripting languages are JavaScript, VBScript, and TypeScript.
- Server-side scripting languages are executed by the web server, and can generate dynamic HTML pages, access databases, and perform other server-side tasks. Examples of server-side scripting languages are PHP, Python, Ruby, and ASP.NET.
- Scripting languages have some advantages and disadvantages over compiled languages, such as:
  - Advantages:
    - Scripting languages are easier to learn and use, as they have simpler syntax and less strict rules.
    - Scripting languages are more flexible and portable, as they can run on different platforms and browsers without recompilation.
    - Scripting languages can provide faster development and testing cycles, as they do not require compilation and linking steps.
  - Disadvantages:
    - Scripting languages are slower and less efficient, as they require more memory and processing power to interpret the code at run-time.
    - Scripting languages are less secure and reliable, as they are more prone to errors and vulnerabilities, and have less control over the hardware and system resources.
    - Scripting languages are less standardized and compatible, as they may have different implementations and features across different browsers and servers.
