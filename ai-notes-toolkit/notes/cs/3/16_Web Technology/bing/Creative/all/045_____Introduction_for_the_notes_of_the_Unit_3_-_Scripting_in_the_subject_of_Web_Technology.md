# Introduction for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server at run-time, rather than compiled by a compiler beforehand.
- Scripting languages are often embedded in HTML documents, using special tags or delimiters, such as `<script>` or `<?php>`.
- Scripting languages can perform various tasks, such as validating user input, manipulating data, generating dynamic content, controlling multimedia, and interacting with databases.
- Some examples of scripting languages are JavaScript, PHP, Python, Ruby, and Perl.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages are executed by the browser on the user's machine, and can access and modify the HTML document, the browser window, and the user's preferences and actions.
- Server-side scripting languages are executed by the web server, and can access and modify the server's resources, such as files, databases, and network connections.
- Client-side and server-side scripting languages can communicate with each other using various methods, such as forms, cookies, sessions, and Ajax.
