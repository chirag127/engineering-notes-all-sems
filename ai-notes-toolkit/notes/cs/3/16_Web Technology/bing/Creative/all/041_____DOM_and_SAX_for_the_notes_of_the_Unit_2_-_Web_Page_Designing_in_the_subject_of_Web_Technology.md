# DOM and SAX for Web Page Designing

- DOM stands for **Document Object Model**. It is a programming interface for web documents that represents the page as a tree of nodes and objects . It allows a language (such as JavaScript) to manipulate, structure, and style the website.
- SAX stands for **Simple API for XML**. It is an event-based parser for XML documents that reads the document from top to bottom and triggers events when it encounters elements, attributes, or text . It is useful for processing large XML files that do not fit in memory.
- The main differences between DOM and SAX are  :
  - DOM reads and writes the entire document, while SAX only reads the document.
  - DOM allows random access and traversal of the document, while SAX only allows sequential access and forward traversal.
  - DOM consumes more memory and CPU time, while SAX consumes less memory and CPU time.
  - DOM provides more information and flexibility, while SAX provides less information and flexibility.
  - DOM is suitable for small to medium size XML files, while SAX is suitable for large XML files.
