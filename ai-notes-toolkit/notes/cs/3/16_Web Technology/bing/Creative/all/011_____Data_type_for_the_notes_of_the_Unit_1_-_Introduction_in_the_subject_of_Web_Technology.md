# Data type

- A data type is a classification of data that specifies how the data is stored, manipulated, and displayed by a computer system.
- Data types are important for web development because they determine how the web browser interprets and renders the data on a web page.
- Some common data types used in web development are:

  - **Text**: A sequence of characters that can represent words, sentences, paragraphs, or any other textual information. Text can be formatted using HTML tags, CSS styles, or JavaScript functions. Examples of text data are: "Hello, world!", "<p>This is a paragraph.</p>", and "document.write('Hello, world!')".
  - **Number**: A numerical value that can be used for calculations, comparisons, or measurements. Numbers can be integers (whole numbers) or decimals (fractional numbers). Examples of number data are: 42, 3.14, and -5.
  - **Boolean**: A logical value that can be either true or false. Booleans are used for conditional statements, logical operations, or toggling states. Examples of boolean data are: true, false, and (3 > 2).
  - **Array**: A collection of data items that are stored in a sequential order and can be accessed by their index (position). Arrays can store any type of data, such as text, numbers, booleans, or other arrays. Examples of array data are: ["red", "green", "blue"], [1, 2, 3, 4, 5], and [[1, 2], [3, 4], [5, 6]].
  - **Object**: A collection of data items that are stored in a key-value pair format and can be accessed by their key (name). Objects can store any type of data, such as text, numbers, booleans, arrays, or other objects. Examples of object data are: {name: "Sydney", age: 21, skills: ["AI", "Web", "Python"]}, {x: 10, y: 20, z: 30}, and {person: {name: "Alice", age: 25}, address: {city: "New York", country: "USA"}}.
