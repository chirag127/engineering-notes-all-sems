# Methods & Classes

- A method is a set of instructions that performs a specific task or operation on some data or objects.
- A class is a blueprint or template that defines the attributes and behaviors of a type of object.
- In object-oriented programming, a class can contain one or more methods that operate on the data or objects of that class.
- A class can also inherit methods and attributes from another class, which is called the superclass or parent class.
- A class can also override or modify the methods and attributes inherited from the superclass, which is called the subclass or child class.
- An object is an instance or example of a class, which has its own state and identity.
- An object can access and manipulate the data or objects of its class using the methods defined in the class.
- An object can also invoke the methods of its superclass or subclass using the dot (.) operator or the super keyword.
- A method can have zero or more parameters, which are the inputs or arguments that the method requires to perform its task.
- A method can also have a return value, which is the output or result that the method produces after performing its task.
- A method can be public, private, protected, or default, which determines the visibility or accessibility of the method to other classes or objects.
- A method can also be static, final, abstract, or synchronized, which determines the behavior or functionality of the method in different contexts or scenarios.
