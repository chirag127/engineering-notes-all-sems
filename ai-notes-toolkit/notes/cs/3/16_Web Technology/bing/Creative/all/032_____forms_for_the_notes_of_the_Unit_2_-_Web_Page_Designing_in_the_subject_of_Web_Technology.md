# Forms

- Forms are used to collect user input on a web page.
- Forms consist of one or more input elements, such as text fields, checkboxes, radio buttons, drop-down lists, etc.
- Forms are enclosed by the `<form>` tag, which has attributes such as `action`, `method`, `name`, `id`, etc.
- The `action` attribute specifies the URL of the server-side script that will process the form data.
- The `method` attribute specifies the HTTP method to use when sending the form data, such as `GET` or `POST`.
- The `name` attribute assigns a name to the form, which can be used to identify it in scripts or stylesheets.
- The `id` attribute assigns a unique identifier to the form, which can be used to access it in scripts or stylesheets.
- The input elements are enclosed by the `<input>` tag, which has attributes such as `type`, `name`, `value`, `placeholder`, `required`, etc.
- The `type` attribute specifies the type of input element, such as `text`, `password`, `email`, `number`, `checkbox`, `radio`, `submit`, etc.
- The `name` attribute assigns a name to the input element, which can be used to access its value in the server-side script.
- The `value` attribute specifies the initial or default value of the input element.
- The `placeholder` attribute specifies a hint or a sample value for the input element, which is displayed when the element is empty.
- The `required` attribute specifies that the input element must be filled in before submitting the form.
- Other input elements include `<textarea>`, `<select>`, `<option>`, `<button>`, `<label>`, etc.
- The `<textarea>` element creates a multi-line text input area, which has attributes such as `rows`, `cols`, `maxlength`, etc.
- The `<select>` element creates a drop-down list, which has attributes such as `name`, `size`, `multiple`, etc.
- The `<option>` element defines an option in the drop-down list, which has attributes such as `value`, `selected`, etc.
- The `<button>` element creates a clickable button, which has attributes such as `type`, `name`, `value`, etc.
- The `<label>` element defines a label for an input element, which has attributes such as `for`, `id`, etc.
- The `<fieldset>` and `<legend>` elements can be used to group related input elements and provide a caption for them.
