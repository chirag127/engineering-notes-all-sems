# Implicit Objects

Implicit objects are Java objects that are created by the servlet container and are available to the JSP pages. They can be used to access various information and functionalities related to the request, response, session, application, etc. Implicit objects are also known as pre-defined variables because they do not need to be declared explicitly in the JSP pages. They are created as local variables inside the service() method of the servlet that is generated from the JSP page.

There are nine implicit objects in JSP:

- **out**: This object is an instance of JspWriter class that is used to write data to the output stream of the response. It has methods like print(), println(), flush(), clear(), etc. The out object is different from the PrintWriter object that is obtained from the response object in a servlet. The out object has a buffer that can be cleared before sending the response to the client. The PrintWriter object does not have a buffer and sends the data directly to the client.
- **request**: This object is an instance of HttpServletRequest interface that represents the HTTP request made by the client. It has methods to get the request parameters, headers, cookies, attributes, etc. The request object also provides access to the session and the servlet context objects.
- **response**: This object is an instance of HttpServletResponse interface that represents the HTTP response sent to the client. It has methods to set the response status, headers, cookies, content type, etc. The response object also provides access to the output stream and the writer objects.
- **session**: This object is an instance of HttpSession interface that represents the session associated with the request. A session is a mechanism to store and share data across multiple requests from the same client. The session object has methods to get and set the session attributes, id, creation time, last accessed time, etc. The session object also provides methods to invalidate the session and check if it is new or not.
- **application**: This object is an instance of ServletContext interface that represents the web application context. It has methods to get and set the application attributes, initialization parameters, resource paths, etc. The application object also provides access to the servlet and filter registrations, request dispatcher, etc.
- **config**: This object is an instance of ServletConfig interface that represents the configuration information of the JSP page. It has methods to get the initialization parameters, servlet name, and servlet context objects.
- **page**: This object is an instance of java.lang.Object class that represents the current JSP page. It is equivalent to the this keyword in Java. The page object can be used to access the instance variables and methods of the JSP page.
- **pageContext**: This object is an instance of PageContext class that encapsulates the information and functionality related to the current JSP page. It has methods to get and set the page, request, response, session, application, config, and out objects. It also has methods to get and set the page attributes, forward and include other resources, handle exceptions, etc.
- **exception**: This object is an instance of java.lang.Throwable class that represents the exception thrown by the JSP page. It is only available in the error pages that are specified by the page directive with isErrorPage="true" attribute. The exception object can be used to get the error message, stack trace, cause, etc. of the exception.
