## Unit 4 - Enterprise Java Bean

Enterprise Java Beans (EJB) is a server-side component architecture for the Java Platform, Enterprise Edition (Java EE). EJB is used to simplify the development of large, distributed applications by providing a container-managed environment for components.

1. EJB components are server-side components that encapsulate business logic and can be accessed remotely by clients.
2. EJB components are managed by an EJB container, which provides services such as transaction management, security, and concurrency control.
3. There are three types of EJB components: session beans, entity beans, and message-driven beans.
4. Session beans are used to represent a single client's interaction with the server and can be either stateful or stateless.
5. Entity beans are used to represent persistent data and can be either container-managed or bean-managed.
6. Message-driven beans are used to process asynchronous messages from a message queue.
7. EJB components can be accessed by clients using either the Java Naming and Directory Interface (JNDI) or the Java Remote Method Invocation (RMI) API.
8. EJB components can be deployed in an EJB container provided by a Java EE application server.
