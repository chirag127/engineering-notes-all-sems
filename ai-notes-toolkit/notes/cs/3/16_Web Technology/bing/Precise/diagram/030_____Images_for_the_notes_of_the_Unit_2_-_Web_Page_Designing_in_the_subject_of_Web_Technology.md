### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Images are an important part of web page design as they can convey information and add visual interest to a page.
2. There are several types of images that can be used on a web page, including raster images (such as JPEG, GIF, and PNG) and vector images (such as SVG).
3. Raster images are made up of pixels and are best for photographs and other images with complex color variations.
4. Vector images are made up of mathematical equations and are best for logos, icons, and other images with simple shapes and colors.
5. Images can be added to a web page using the `<img>` tag, which has several attributes, including `src` (which specifies the source of the image) and `alt` (which provides alternative text for the image).
6. It is important to optimize images for the web by reducing their file size and choosing the appropriate file format to ensure fast loading times and good user experience.
7. Images can also be used as backgrounds, links, and in other ways to enhance the design and functionality of a web page.
