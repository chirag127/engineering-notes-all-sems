### Unit 3 - Scripting in Web Technology: Forms

1. Forms are used to collect user input and submit it to a server for processing.
2. The `<form>` element is used to create an HTML form.
3. The `action` attribute specifies where to send the form data when the form is submitted.
4. The `method` attribute specifies how to send the form data.
5. Common form controls include text fields, checkboxes, radio buttons, and submit buttons.
6. The `<input>` element is used to create form controls.
7. The `type` attribute specifies the type of form control to create.
8. The `name` attribute specifies the name of the form control.
9. The `value` attribute specifies the initial value of the form control.
10. Form data is sent as name/value pairs.
11. Server-side scripting languages such as PHP, ASP, and JSP can be used to process form data.
12. Client-side scripting languages such as JavaScript can be used to validate form data before submission.
