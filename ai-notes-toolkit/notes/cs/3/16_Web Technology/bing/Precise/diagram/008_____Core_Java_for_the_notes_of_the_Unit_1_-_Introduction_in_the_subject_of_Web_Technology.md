### Unit 1 - Introduction to Core Java

Core Java refers to the core components of the Java programming language. It is the foundation of the Java Platform, Standard Edition (Java SE) and is used for building standalone applications.

Here are some key points to note about Core Java:

1. Core Java is the basic foundation of the Java programming language.
2. It includes fundamental concepts such as data types, control structures, classes, objects, inheritance, and exception handling.
3. Core Java is used for building standalone applications, as opposed to Java Enterprise Edition (Java EE) which is used for building web-based applications.
4. The Java Development Kit (JDK) is the primary tool for developing Core Java applications.
5. Core Java is platform-independent, meaning that code written in Core Java can run on any operating system that has a Java Virtual Machine (JVM) installed.
