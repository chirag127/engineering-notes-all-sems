### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. **Introduction to Frames**: Frames allow for multiple `.html` documents to be displayed inside of one browser window at a time. Each `.html` file within a frame is called a frameset.
2. **Creating Frames**: Frames are created using the `<frameset>` tag in place of the `<body>` tag in an HTML document. The `<frameset>` tag defines how many rows or columns of frames will be created and their sizes.
3. **Frame Attributes**: The `<frame>` tag is used to define each frame within a frameset. The `src` attribute is used to specify the URL of the document to be displayed in the frame. Other attributes such as `name`, `scrolling`, `noresize`, and `frameborder` can be used to further customize the appearance and behavior of frames.
4. **Targeting Frames**: Links can be set to open in specific frames using the `target` attribute. The value of the `target` attribute should match the `name` attribute of the frame in which the linked document should be displayed.
5. **Nested Framesets**: Framesets can be nested inside of other framesets to create more complex layouts.
6. **Advantages and Disadvantages of Frames**: Frames can provide a consistent look and feel to a website by allowing for the use of a common header, footer, or navigation menu. However, frames can also cause issues with search engine optimization, bookmarking, and printing.
