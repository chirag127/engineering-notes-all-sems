### Methods & Classes for the notes of the Unit 1 - Introduction in the subject of Web Technology

- **Methods** are functions that are associated with an object and can be called using the dot notation. For example, `object.method()`.
- **Classes** are templates for creating objects. They define the properties and methods that an object will have.
- A **class** is defined using the `class` keyword, followed by the name of the class and a colon. The body of the class is indented and contains the class's methods and properties.
- **Methods** are defined using the `def` keyword, followed by the method's name and a pair of parentheses. The body of the method is indented and contains the code that will be executed when the method is called.
- **Objects** are created by calling the class's constructor, which is a special method named `__init__`. The constructor is called when an object is created and is used to set the initial values of the object's properties.
- **Inheritance** is a mechanism that allows a class to inherit the properties and methods of another class. The class that is being inherited from is called the **base class**, and the class that is inheriting from the base class is called the **derived class**.
- **Polymorphism** is the ability of an object to take on many forms. In the context of object-oriented programming, this means that a single method can behave differently depending on the object that is calling it.
- **Encapsulation** is the practice of hiding the internal details of an object and providing a public interface for interacting with the object. This is achieved by defining methods and properties as either public or private.
