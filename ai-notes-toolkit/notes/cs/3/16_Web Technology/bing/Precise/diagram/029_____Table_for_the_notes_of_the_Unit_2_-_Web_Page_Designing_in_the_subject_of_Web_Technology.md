### Table for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. **Introduction to Web Page Designing:** Web page designing involves the creation and arrangement of web pages that make up a website. It includes aspects such as layout, color scheme, graphics, and content.
2. **HTML:** HTML (Hypertext Markup Language) is the standard markup language used to create web pages. It provides the structure and content of a web page.
3. **CSS:** CSS (Cascading Style Sheets) is a style sheet language used to describe the look and formatting of a web page. It is used to separate the presentation of a web page from its content.
4. **JavaScript:** JavaScript is a programming language used to add interactivity and dynamic content to web pages.
5. **Responsive Web Design:** Responsive web design is an approach to web design that aims to provide an optimal viewing experience across a wide range of devices, from desktop computers to mobile phones.
6. **Web Accessibility:** Web accessibility refers to the practice of making websites usable by people with disabilities. It involves designing web pages in a way that allows everyone, including people with disabilities, to access and use them.
7. **Search Engine Optimization:** Search engine optimization (SEO) is the process of improving the visibility of a website or a web page in a search engine's unpaid results. It involves optimizing the content and structure of a web page to make it more search engine friendly.
8. **Web Analytics:** Web analytics is the measurement, collection, analysis, and reporting of web data for the purpose of understanding and optimizing web usage. It is used to track and analyze the behavior of visitors to a website.
