### Unit 1 - Introduction: Layout Managers in Web Technology

- Layout managers are used to arrange and organize the components of a user interface within a container.
- They determine the size and position of the components based on the rules and constraints of the layout manager being used.
- Some common layout managers include:
  - **Flow Layout:** arranges components in a left-to-right flow, much like words in a paragraph.
  - **Border Layout:** divides the container into five regions: north, south, east, west, and center. Each region can contain only one component.
  - **Grid Layout:** arranges components in a grid of cells, with each cell being the same size.
  - **Card Layout:** manages two or more components that share the same display space, with only one component being visible at a time.
  - **GridBag Layout:** a flexible layout manager that aligns components in a grid of rows and columns, with each component occupying one or more cells.
- The choice of layout manager depends on the specific needs of the user interface being designed.
- Layout managers can be combined and nested within each other to create complex and dynamic user interfaces.
