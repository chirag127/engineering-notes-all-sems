### XML

XML (eXtensible Markup Language) is a markup language used for storing and transporting data. It is a flexible way to create common information formats and share both the format and the data on the World Wide Web, intranets, and elsewhere.

Here are some key points to note about XML:

- XML is a markup language, not a programming language.
- XML is used to store and transport data, not to display data.
- XML is designed to be self-descriptive.
- XML is a W3C Recommendation.
- XML tags are not predefined. You must define your own tags.
- XML is case sensitive.
- XML elements must be properly nested.
- XML documents must have a root element.
- XML attributes must be quoted.
