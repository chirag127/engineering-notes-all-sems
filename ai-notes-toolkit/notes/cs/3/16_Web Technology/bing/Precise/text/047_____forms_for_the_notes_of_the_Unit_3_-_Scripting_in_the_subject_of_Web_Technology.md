### Unit 3 - Scripting in Web Technology: Forms

1. Forms are used to collect user input and submit it to a server for processing.
2. The `<form>` tag is used to create an HTML form.
3. The `action` attribute specifies where to send the form data when the form is submitted.
4. The `method` attribute specifies how to send the form data (GET or POST).
5. Input elements are used to create various form controls, such as text fields, checkboxes, radio buttons, and submit buttons.
6. The `<label>` tag is used to define a label for an input element.
7. The `<input>` tag is used to create an input field where the user can enter data.
8. The `type` attribute specifies the type of input element to display.
9. The `name` attribute specifies the name for the input element, which is used to reference the form data after the form is submitted.
10. The `value` attribute specifies the initial value for the input element.
11. The `<select>` tag is used to create a drop-down list.
12. The `<option>` tag is used to define an option in the drop-down list.
13. The `<textarea>` tag is used to create a multi-line input field.
14. The `<button>` tag is used to create a clickable button.
15. Form validation is the process of ensuring that user input is correct, complete, and secure before it is sent to the server.
