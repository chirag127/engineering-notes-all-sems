### Package and Interface

A **package** is a collection of related classes and interfaces that are grouped together. Packages help to organize code and prevent naming conflicts. In Java, packages are created by using the `package` keyword followed by the package name at the top of the source file.

An **interface** is a collection of abstract methods (methods without a body) that can be implemented by any class. Interfaces are used to define a contract between classes, specifying what methods a class must implement. In Java, interfaces are created using the `interface` keyword.

Here are some key points to remember about packages and interfaces:

- Packages help to organize code and prevent naming conflicts.
- Interfaces define a contract between classes, specifying what methods a class must implement.
- Classes can implement multiple interfaces.
- Interfaces can extend other interfaces.
- A class that implements an interface must provide an implementation for all of its methods.
- Interfaces can contain default methods, which provide a default implementation for a method.
- Interfaces can also contain static methods.
