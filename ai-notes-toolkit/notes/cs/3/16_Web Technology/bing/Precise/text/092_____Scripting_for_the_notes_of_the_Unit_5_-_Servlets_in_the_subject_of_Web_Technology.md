### Unit 5 - Servlets

Servlets are Java programs that run on a web server and handle HTTP requests and responses. They are used to create dynamic web content and can interact with databases, web services, and other resources.

Here are some key points to remember about servlets:

1. Servlets are part of the Java Enterprise Edition (Java EE) platform and are managed by a servlet container, such as Apache Tomcat or GlassFish.
2. Servlets can handle HTTP GET, POST, PUT, DELETE, and other request methods.
3. Servlets can generate HTML, XML, JSON, or other types of content to be sent back to the client.
4. Servlets can use the Java Database Connectivity (JDBC) API to interact with databases.
5. Servlets can use the Java Naming and Directory Interface (JNDI) to look up resources, such as data sources or enterprise beans.
6. Servlets can use the JavaMail API to send email.
7. Servlets can use the Java API for XML Processing (JAXP) to parse and generate XML documents.
8. Servlets can use the Java API for RESTful Web Services (JAX-RS) to create RESTful web services.
9. Servlets can use the Java API for WebSocket (JSR 356) to create WebSocket endpoints.
10. Servlets can use the Java Authentication and Authorization Service (JAAS) to implement authentication and authorization.
