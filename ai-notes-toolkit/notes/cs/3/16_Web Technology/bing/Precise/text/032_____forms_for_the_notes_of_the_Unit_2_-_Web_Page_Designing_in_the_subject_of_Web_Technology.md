### Forms for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- Forms are used to collect user input on a web page.
- Forms can contain various types of input elements such as text fields, checkboxes, radio buttons, dropdown menus, etc.
- Forms are created using the `<form>` element.
- The `action` attribute of the `<form>` element specifies where to send the form data when the form is submitted.
- The `method` attribute of the `<form>` element specifies how to send the form data. The two most common methods are `GET` and `POST`.
- The `<input>` element is used to create various form controls. The `type` attribute of the `<input>` element specifies the type of input element to display.
- The `<label>` element is used to associate a text description with a form control.
- The `<select>` element is used to create a dropdown list. The `<option>` elements define the available options in the list.
- The `<textarea>` element is used to create a multi-line text input field.
- The `<button>` element is used to create a clickable button.
- Form validation can be performed on the client-side using JavaScript or on the server-side using a server-side scripting language such as PHP or ASP.
- CSS can be used to style forms and form controls.
