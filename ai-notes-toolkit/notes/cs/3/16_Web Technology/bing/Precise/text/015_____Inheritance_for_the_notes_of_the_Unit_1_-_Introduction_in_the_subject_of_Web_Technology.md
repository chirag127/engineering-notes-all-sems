### Inheritance for the notes of the Unit 1 - Introduction in the subject of Web Technology

Inheritance is a mechanism in object-oriented programming that allows a new class to be created based on an existing class. The new class is called a subclass or derived class, and the existing class is called the superclass or base class.

- Inheritance allows the subclass to inherit the properties and methods of the superclass.
- This means that the subclass can reuse the code from the superclass, which can save time and effort in development.
- Inheritance also allows the subclass to add new properties and methods, or to override the properties and methods of the superclass.
- This allows the subclass to customize the behavior of the superclass to meet its specific needs.
- Inheritance is a powerful tool for organizing and structuring code, and it is a fundamental concept in object-oriented programming.
