# Unit 3 - Scripting in Web Technology

- Scripting is a programming method that allows developers to add interactivity and dynamic content to websites.
- Scripts are small programs that are embedded in web pages and executed on the client-side (in the user's web browser) or server-side (on the web server).
- The most commonly used scripting language for client-side scripting is JavaScript.
- JavaScript allows developers to manipulate the Document Object Model (DOM) of a web page, respond to user events, and perform asynchronous operations using AJAX (Asynchronous JavaScript and XML).
- Server-side scripting languages include PHP, Python, Ruby, and ASP.NET. These languages are used to generate dynamic web content, interact with databases, and perform other server-side operations.
- Scripting languages are typically easier to learn and use than traditional programming languages, making them a popular choice for web development.
- It is important to note that client-side scripts can be viewed and modified by users, so sensitive information and operations should be handled on the server-side.
