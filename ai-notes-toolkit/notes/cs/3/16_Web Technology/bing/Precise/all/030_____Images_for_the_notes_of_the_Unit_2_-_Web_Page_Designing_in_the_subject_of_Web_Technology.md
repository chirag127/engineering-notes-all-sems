### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Images are an essential part of web page designing. They add visual appeal and can convey information more effectively than text alone.
2. There are several types of images that can be used on web pages, including raster images, vector images, and animated images.
3. Raster images are made up of pixels and are commonly used for photographs and other detailed images. They can be saved in various file formats, including JPEG, GIF, and PNG.
4. Vector images are made up of geometric shapes and are commonly used for logos and other graphics that need to be scaled without losing quality. They can be saved in file formats such as SVG and EPS.
5. Animated images can add movement and interactivity to a web page. They can be created using various techniques, including GIFs, CSS animations, and JavaScript.
6. When using images on a web page, it is important to consider factors such as file size, image quality, and accessibility. Images should be optimized for web use to ensure fast loading times and a good user experience.
7. Alternative text should be provided for images to ensure that they are accessible to users with visual impairments or those using screen readers.
8. Images can be added to a web page using the `<img>` HTML tag. The `src` attribute specifies the source of the image, while the `alt` attribute provides alternative text for the image.
9. CSS can be used to style and position images on a web page. Common properties used for styling images include `width`, `height`, `border`, and `margin`.
10. In summary, images are an important part of web page designing and can enhance the user experience when used effectively. It is important to consider factors such as file size, image quality, and accessibility when using images on a web page.
