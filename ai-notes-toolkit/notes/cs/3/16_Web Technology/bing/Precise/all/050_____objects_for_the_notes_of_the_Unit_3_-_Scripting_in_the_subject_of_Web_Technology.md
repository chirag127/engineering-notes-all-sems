# Unit 3 - Scripting in Web Technology: Objects

- An object is a collection of properties, and a property is an association between a name (or key) and a value.
- A property's value can be a function, in which case the property is known as a method.
- Objects in JavaScript are standalone entities that can be manipulated and interacted with.
- Objects can be created using object literals, constructors, or the Object.create() method.
- Properties of an object can be accessed using dot notation or bracket notation.
- The `this` keyword refers to the object that the function is a method of.
- Objects can be used to organize and structure code, making it easier to read and maintain.
- Inheritance allows objects to inherit properties and methods from other objects, reducing code duplication and increasing code reusability.
- JavaScript has several built-in objects, such as `Array`, `Date`, and `Math`, that provide useful methods and properties for common tasks.
