# XML

XML (eXtensible Markup Language) is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable. It is a widely used format for data interchange and storage.

Here are some key points to note about XML:

1. XML is a markup language, not a programming language.
2. XML is used to store and transport data.
3. XML is a self-describing language, meaning that the tags used to markup the data describe the data itself.
4. XML is platform-independent and can be used on any operating system or programming language.
5. XML is extensible, meaning that users can create their own tags to describe their data.
6. XML is a W3C (World Wide Web Consortium) recommendation, meaning that it is a standard for web development.
