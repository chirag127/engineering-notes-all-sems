## Unit 4 - Enterprise Java Bean

1. Enterprise Java Beans (EJB) is a server-side component architecture for the Java Enterprise Edition (Java EE) platform.
2. EJBs are used to encapsulate business logic and provide a way to develop scalable, distributed, and transactional applications.
3. EJBs can be either session beans or message-driven beans.
4. Session beans can be stateful, stateless, or singleton.
5. Message-driven beans are used to process messages asynchronously.
6. EJBs can be accessed by local or remote clients.
7. EJBs support transactions, security, concurrency, and resource management.
8. EJBs can be deployed in an EJB container, which manages their lifecycle and provides services such as naming, transaction management, and security.
9. EJBs can be developed using annotations or deployment descriptors.
10. EJBs can be used in combination with other Java EE technologies such as JPA, JMS, and JAX-RS.
