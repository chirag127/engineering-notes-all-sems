### HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages and other information that can be displayed in a web browser.

1. HTML is used to structure content on the web and give meaning to the content.
2. HTML consists of a series of elements or tags that are used to enclose different parts of the content to make it appear or behave in a certain way.
3. The enclosing tags can make a piece of text into a hyperlink to another web page, italicize words, or make the font bigger or smaller, among other things.
4. HTML documents are saved with the .html or .htm file extension and can be opened and edited using a text editor or an HTML editor.
5. HTML is not a programming language, but rather a markup language that is used to structure and format content on the web.
