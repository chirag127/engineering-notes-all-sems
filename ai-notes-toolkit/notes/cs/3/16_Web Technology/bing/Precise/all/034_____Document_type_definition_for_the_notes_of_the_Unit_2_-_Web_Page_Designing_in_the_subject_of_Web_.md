### Document Type Definition (DTD) - Unit 2: Web Page Designing

1. A Document Type Definition (DTD) is a set of markup declarations that define a document type for an SGML-family markup language (SGML, XML, HTML).
2. A DTD defines the valid building blocks of an XML document. It sets the rules for the document's structure with a list of legal elements and attributes.
3. A DTD can be declared inline inside an XML document, or as an external reference.
4. XML uses a subset of SGML DTD.
5. The purpose of a DTD is to define the structure and the legal elements and attributes of an XML document.
6. A DTD can be used to verify that the data being exchanged between systems conforms to the expected structure.
7. DTDs are one of several SGML and XML schema languages, and are also used in the validation of other markup languages such as HTML.
8. DTDs are written in a syntax that is similar to that of XML, but with some differences.
9. DTDs can be used to specify the allowed structure and content of an XML document, including the allowed elements, attributes, and their relationships.
10. DTDs can also be used to specify the default values for attributes, and to define entities that can be used to represent special characters or strings of text.
