# Unit 3 - Scripting in Web Technology

- Scripting is a programming technique that allows developers to add interactivity and dynamic content to web pages.
- Scripts are small programs that are embedded in web pages and executed by the web browser.
- The most commonly used scripting language for web development is JavaScript.
- JavaScript is a high-level, interpreted programming language that is used to create interactive effects within web browsers.
- Scripts can be used to create a wide range of interactive features, such as form validation, image rollovers, and drop-down menus.
- Scripts can also be used to manipulate the Document Object Model (DOM) of a web page, allowing developers to dynamically change the content and layout of a page.
- In addition to JavaScript, other scripting languages used in web development include VBScript, Perl, and PHP.
- Scripting languages are typically easier to learn and use than traditional programming languages, making them a popular choice for web development.
- Scripting can also be used on the server-side to generate dynamic web pages and interact with databases.
- Server-side scripting languages include PHP, ASP.NET, and JSP.
