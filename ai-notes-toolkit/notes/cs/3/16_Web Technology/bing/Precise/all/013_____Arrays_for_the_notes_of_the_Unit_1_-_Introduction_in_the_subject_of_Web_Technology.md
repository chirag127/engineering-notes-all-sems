### Unit 1 - Introduction: Arrays

An array is a data structure that stores a collection of elements. These elements are stored in contiguous memory locations and can be accessed using an index.

- Arrays can store elements of the same data type.
- The size of an array is fixed and must be declared at the time of its creation.
- Elements in an array can be accessed using their index, which starts from 0.
- Arrays can be one-dimensional, two-dimensional, or multi-dimensional.
- One-dimensional arrays are used to store a list of elements, while two-dimensional arrays are used to store data in a tabular form.
- Multi-dimensional arrays are used to store data in more complex structures, such as matrices.
- Common operations that can be performed on arrays include accessing, inserting, deleting, and searching for elements.
- Arrays are commonly used in computer programming to store and manipulate data.
