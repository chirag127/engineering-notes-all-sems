# Unit 1 - Introduction: Methods & Classes in Web Technology

- **Methods** are functions that are associated with an object or class. They define the behavior of the object or class and can be used to manipulate the object's data or perform actions on it.

- **Classes** are templates for creating objects. They define the properties and methods that an object will have. When an object is created from a class, it is called an instance of that class.

- In web technology, classes and methods are used to organize and structure code, making it easier to maintain and reuse.

- Classes can be used to define custom data types, such as a user or a product, and methods can be used to define the actions that can be performed on those data types.

- Classes and methods can also be used to create reusable components, such as form validation or data processing, that can be used across multiple web pages or applications.

- In many programming languages used for web development, such as JavaScript, classes and methods are defined using specific syntax and keywords.

- To create a class, the `class` keyword is used, followed by the name of the class and a set of curly braces `{}` containing the class's properties and methods.

- Methods are defined within the class using the `function` keyword, followed by the method's name and a set of parentheses `()` containing any parameters the method takes. The method's code is then written within a set of curly braces `{}`.

- To create an instance of a class, the `new` keyword is used, followed by the name of the class and any arguments that need to be passed to the class's constructor method.

- Once an instance of a class has been created, its methods can be called using dot notation, with the name of the instance followed by a dot `.` and the name of the method.

- Classes and methods are a fundamental part of object-oriented programming, a common paradigm used in web development. They allow for the creation of modular, reusable code that is easier to maintain and extend.
