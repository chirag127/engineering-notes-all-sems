# Unit 1 - Introduction to Core Java

Core Java refers to the core or fundamental concepts of the Java programming language. It is the foundation upon which all other Java technologies are built. Here are some key points to remember about Core Java:

1. Java is an object-oriented programming language, which means that it is based on the concept of objects, which can contain data and methods to manipulate that data.
2. Java is platform-independent, meaning that code written in Java can run on any platform or operating system that has a Java Virtual Machine (JVM) installed.
3. Java is a strongly-typed language, which means that the type of a variable must be explicitly specified and cannot be changed during the execution of the program.
4. Java has a rich set of built-in libraries and APIs that provide a wide range of functionality, including networking, database connectivity, and graphical user interfaces.
5. Java is widely used for developing web, mobile, and enterprise applications.
