### Unit 2 - Web Page Designing: Forms

- Forms are used to collect user input on a web page.
- The `<form>` tag is used to create an HTML form.
- The `<input>` tag is used to create form controls such as text fields, checkboxes, and radio buttons.
- The `type` attribute of the `<input>` tag specifies the type of form control to create.
- The `name` attribute of the `<input>` tag specifies the name of the form control.
- The `value` attribute of the `<input>` tag specifies the initial value of the form control.
- The `<label>` tag is used to define a label for a form control.
- The `<select>` tag is used to create a drop-down list.
- The `<option>` tag is used to define the options in a drop-down list.
- The `<textarea>` tag is used to create a multi-line text input field.
- The `<button>` tag is used to create a clickable button.
- The `action` attribute of the `<form>` tag specifies where to send the form data when the form is submitted.
- The `method` attribute of the `<form>` tag specifies how to send the form data (GET or POST).
- The `<fieldset>` tag is used to group related form controls.
- The `<legend>` tag is used to define a caption for a `<fieldset>` element.
