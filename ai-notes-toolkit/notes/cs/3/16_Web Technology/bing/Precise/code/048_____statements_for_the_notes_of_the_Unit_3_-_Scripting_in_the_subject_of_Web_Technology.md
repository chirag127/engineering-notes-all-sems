### Unit 3 - Scripting in Web Technology

1. Scripting is a programming technique that allows developers to add interactivity and dynamic content to web pages.
2. Scripts are small programs that are embedded in web pages and executed by the web browser.
3. The most commonly used scripting language for web development is JavaScript.
4. JavaScript can be used to manipulate the Document Object Model (DOM) of a web page, allowing developers to dynamically change the content and layout of a page.
5. Scripts can also be used to validate user input, create animations, and perform other tasks that enhance the user experience.
6. In addition to JavaScript, other scripting languages such as PHP and Python can be used for server-side scripting to generate dynamic web content.
7. Scripting can also be used to create web applications that run entirely in the user's browser, without the need for server-side processing.
8. It is important to write secure and efficient scripts to ensure the safety and performance of web applications.
