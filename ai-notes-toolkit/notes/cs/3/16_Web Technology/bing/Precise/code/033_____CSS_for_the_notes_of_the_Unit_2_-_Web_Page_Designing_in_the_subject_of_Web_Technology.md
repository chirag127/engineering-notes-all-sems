### CSS for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.

Here are some key points to remember about CSS:

1. CSS is used to separate the presentation of a web page from its content, making it easier to maintain and update the design of a website.
2. CSS allows for the creation of reusable styles that can be applied to multiple elements or pages, reducing the amount of code needed to style a website.
3. CSS has a wide range of selectors that can be used to target specific elements, classes, or IDs on a page.
4. CSS has a powerful inheritance mechanism that allows styles to be passed down from parent elements to their children.
5. CSS has a wide range of properties that can be used to control the layout, typography, and visual effects of a web page.

In summary, CSS is an essential tool for web designers and developers, allowing them to create visually appealing and well-organized web pages. It is important to have a good understanding of CSS when working in the field of web technology.
