### DTD for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- DTD stands for Document Type Definition.
- It is a set of markup declarations that define a document type for an SGML-family markup language (SGML, XML, HTML).
- A DTD defines the valid building blocks of an XML document.
- It sets the rules for the structure and content of an XML document.
- A DTD can be declared inline inside an XML document, or as an external reference.
- DTDs use a formal grammar to define the legal elements and attributes of an XML document.
- DTDs are one of several XML schema languages, with others including XML Schema and RELAX NG.
- DTDs have limitations, such as the inability to define data types or to create namespaces.
- Despite these limitations, DTDs remain widely used, particularly in the publishing industry.
