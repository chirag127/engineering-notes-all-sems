### Document Type Definition (DTD) - Unit 2: Web Page Designing

1. A Document Type Definition (DTD) is a set of markup declarations that define a document type for SGML-family markup languages (SGML, XML, HTML).
2. A DTD defines the valid building blocks of an XML document. It sets the rules for the structure and content of an XML document.
3. A DTD can be declared inline inside an XML document, or as an external reference.
4. The purpose of a DTD is to define the legal elements and attributes of an XML document.
5. A DTD can be used to verify that the data being exchanged between systems is valid and conforms to the expected structure.
6. DTDs are one of several SGML and XML schema languages, and are also used in the validation of other SGML and XML-based formats, such as XHTML.
7. DTDs use a formal grammar to define the structure and content of an XML document. This grammar is used to validate the document and ensure that it conforms to the expected structure.
8. DTDs are written in a specialized syntax that is different from XML. They use a set of declarations to define elements, attributes, and other constructs.
9. DTDs are an important part of the XML ecosystem, and are widely used in many applications and industries.
