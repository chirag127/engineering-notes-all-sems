### Package and Interface

#### Package
- A package is a collection of related classes and interfaces that are grouped together.
- Packages help to organize code and avoid naming conflicts.
- Packages can be imported into other classes, allowing the use of their classes and interfaces.
- The `java` package, for example, contains many useful classes and interfaces for working with the Java language.

#### Interface
- An interface is a collection of abstract methods (methods without a body) that can be implemented by any class.
- Interfaces are used to define a common set of behaviors that can be implemented by multiple classes.
- A class that implements an interface must provide an implementation for all of its methods.
- Interfaces can be used to achieve polymorphism, allowing objects of different classes to be treated as objects of a common type.
