### Introduction for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Scripting is a programming technique that enables the automation of tasks within a software application or on a website.
2. Scripts are written in a scripting language, which is a type of programming language that is interpreted rather than compiled.
3. Some common scripting languages used in web development include JavaScript, PHP, and Python.
4. Scripts can be used to add interactivity to a website, such as responding to user input or updating content dynamically.
5. Scripting can also be used to automate tasks on the server-side, such as processing form data or generating dynamic content.
6. In the context of web development, client-side scripting refers to scripts that are executed by the user's web browser, while server-side scripting refers to scripts that are executed by the web server.
7. Understanding scripting is an important part of web development, as it enables developers to create dynamic and interactive web applications.
