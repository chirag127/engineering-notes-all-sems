### Table for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. **Introduction to Web Page Designing:** Web page designing involves the creation and arrangement of web pages that make up a website. It includes aspects such as layout, color scheme, graphics, and content.

2. **HTML:** HTML (Hypertext Markup Language) is the standard markup language used to create web pages. It provides a structure for the content of a web page, defining elements such as headings, paragraphs, links, and images.

3. **CSS:** CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. It allows for the separation of presentation and content, enabling the designer to control the layout, colors, and fonts of a web page.

4. **JavaScript:** JavaScript is a programming language commonly used in web development to add interactivity and dynamic behavior to web pages. It can be used to create features such as drop-down menus, pop-up windows, and form validation.

5. **Responsive Web Design:** Responsive web design is an approach to web design that aims to create web pages that provide an optimal viewing experience across a wide range of devices, from desktop computers to mobile phones. This is achieved through the use of flexible layouts, images, and CSS media queries.

6. **Web Accessibility:** Web accessibility refers to the practice of designing and developing websites that are usable by people with disabilities. This includes considerations such as providing alternative text for images, using clear and simple language, and ensuring that the website can be navigated using a keyboard.

7. **Search Engine Optimization:** Search engine optimization (SEO) is the process of improving the visibility of a website or a web page in a search engine's unpaid results. This can be achieved through techniques such as using relevant keywords, creating high-quality content, and building links from other websites.

8. **Web Analytics:** Web analytics is the measurement, collection, analysis, and reporting of web data for the purpose of understanding and optimizing web usage. This can provide valuable insights into user behavior and can help to inform decisions about website design and content.

9. **Web Design Tools:** There are many tools available to assist in the web design process, including text editors, graphics software, and content management systems. These tools can help to streamline the design process and improve the quality of the final product.

10. **Web Design Best Practices:** There are many best practices that can be followed when designing a web page, including using a clear and consistent layout, ensuring that the website is easy to navigate, and providing high-quality content that is relevant to the user. Following these best practices can help to create a positive user experience and improve the effectiveness of the website.
