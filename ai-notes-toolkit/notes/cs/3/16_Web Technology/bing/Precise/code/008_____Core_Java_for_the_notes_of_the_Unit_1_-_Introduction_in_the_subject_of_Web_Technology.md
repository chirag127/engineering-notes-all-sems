### Unit 1 - Introduction to Core Java

Core Java refers to the core components of the Java programming language. It is the foundation of the Java platform and is used to develop a wide range of applications, from mobile apps to web applications and games.

Here are some key points to note about Core Java:

1. Java is an object-oriented programming language, which means that it is based on the concept of objects and classes.
2. Java is platform-independent, meaning that code written in Java can run on any platform that has a Java Virtual Machine (JVM) installed.
3. Java is known for its "write once, run anywhere" capability, which means that code written in Java can run on any platform without the need for recompilation.
4. Java has a rich set of built-in libraries and APIs that make it easy to develop complex applications.
5. Java is a statically-typed language, which means that the type of a variable must be declared before it is used.
6. Java has strong memory management and garbage collection, which helps to prevent memory leaks and improve the performance of applications.

These are some of the key features of Core Java that make it a popular choice for developing a wide range of applications. In the following units, we will explore these features in more detail and learn how to use them to develop robust and scalable applications.
