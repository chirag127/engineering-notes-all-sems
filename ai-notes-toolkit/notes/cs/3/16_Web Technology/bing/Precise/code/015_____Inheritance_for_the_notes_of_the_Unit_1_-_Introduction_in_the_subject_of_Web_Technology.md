### Inheritance for the notes of the Unit 1 - Introduction in the subject of Web Technology

Inheritance is a mechanism in object-oriented programming that allows a new class to be created based on an existing class. The new class, called the subclass, inherits the properties and methods of the existing class, called the superclass.

Some key points to remember about inheritance are:

1. Inheritance allows for code reuse, as common properties and methods can be defined in the superclass and inherited by the subclass.
2. The subclass can add new properties and methods, as well as override inherited methods.
3. Inheritance can be used to model a hierarchy of related classes, with more general classes at the top and more specific classes at the bottom.
4. Inheritance is transitive, meaning that if class B inherits from class A, and class C inherits from class B, then class C also inherits from class A.
5. Inheritance is not the only way to achieve code reuse and should be used judiciously. Other techniques, such as composition, can also be used to achieve similar goals.
