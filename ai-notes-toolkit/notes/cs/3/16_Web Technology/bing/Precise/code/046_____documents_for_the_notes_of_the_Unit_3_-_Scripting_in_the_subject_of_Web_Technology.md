### Unit 3 - Scripting in Web Technology

1. **Introduction to scripting:** Scripting is a programming language that is interpreted by another program at runtime, rather than being compiled by the computer's processor. It is used to automate tasks and add interactivity to web pages.

2. **Client-side scripting:** Client-side scripting refers to scripts that are executed by the user's web browser. These scripts are used to create dynamic and interactive web pages. Examples of client-side scripting languages include JavaScript, VBScript, and JScript.

3. **Server-side scripting:** Server-side scripting refers to scripts that are executed by the web server. These scripts are used to generate dynamic web pages and interact with databases. Examples of server-side scripting languages include PHP, ASP, and JSP.

4. **JavaScript:** JavaScript is a high-level, interpreted programming language that is commonly used for client-side scripting. It is used to add interactivity to web pages, validate user input, and manipulate the Document Object Model (DOM).

5. **Document Object Model (DOM):** The DOM is a programming interface for web documents. It represents the structure of a document as a tree of objects, with each object representing a part of the document. JavaScript can be used to manipulate the DOM to dynamically update the content of a web page.

6. **Event handling:** Event handling refers to the process of responding to user actions, such as mouse clicks or key presses. JavaScript can be used to add event listeners to elements on a web page, which will execute a specified function when the event occurs.

7. **AJAX:** AJAX stands for Asynchronous JavaScript and XML. It is a technique for creating fast and dynamic web pages without reloading the entire page. AJAX allows a web page to send and receive data from a server in the background, without interfering with the display and behavior of the page.

8. **JSON:** JSON stands for JavaScript Object Notation. It is a lightweight data interchange format that is easy for humans to read and write, and easy for machines to parse and generate. JSON is commonly used to transmit data between a server and a web application, as an alternative to XML.

9. **jQuery:** jQuery is a fast, small, and feature-rich JavaScript library. It makes things like HTML document traversal and manipulation, event handling, and animation much simpler with an easy-to-use API that works across a multitude of browsers.

10. **Frameworks and libraries:** There are many frameworks and libraries available for both client-side and server-side scripting. These tools provide pre-written code and functions that can simplify the development process and improve the performance and functionality of web applications. Examples include AngularJS, React, and Node.js.
