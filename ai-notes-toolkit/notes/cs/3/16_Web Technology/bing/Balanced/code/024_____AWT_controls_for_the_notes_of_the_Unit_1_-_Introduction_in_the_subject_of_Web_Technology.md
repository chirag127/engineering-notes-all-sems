### AWT controls

- AWT stands for Abstract Window Toolkit, which is a set of APIs for developing graphical user interfaces or web applications in Java .
- AWT controls are components that allow a user to interact with the application in various ways, such as buttons, text fields, checkboxes, lists, etc .
- AWT controls are subclasses of the java.awt.Component class, which is the root class for all graphical components .
- AWT controls can be grouped into two categories: lightweight and heavyweight .
  - Lightweight controls are those that do not have a native peer, meaning they are drawn by Java code and do not rely on the underlying platform for their appearance and behavior. Examples of lightweight controls are labels, canvases, and images .
  - Heavyweight controls are those that have a native peer, meaning they are mapped to a native window or widget of the underlying platform and inherit their appearance and behavior from it. Examples of heavyweight controls are buttons, text fields, scrollbars, dialogs, etc .
- AWT controls can be added to containers, which are components that can hold other components and arrange them in a layout. Containers are also subclasses of the java.awt.Component class .
- The most common containers in AWT are panels, frames, and dialogs .
  - A panel is a container that does not have a title bar, border, or menu bar. It is a generic container that can be used to group other components .
  - A frame is a container that has a title bar, border, menu bar, and can be resized and minimized. It is a top-level window that can display other components .
  - A dialog is a container that has a title bar, border, and can be modal or non-modal. It is a secondary window that can display a message or request input from the user .
- AWT controls can be created by using their constructors and setting their properties, such as size, location, color, font, etc. They can also be registered with event listeners, which are objects that handle the events generated by the user's interaction with the controls .
- AWT controls can be added to a container by using the add() method of the container. The container can also use a layout manager, which is an object that controls the size and position of the components within the container .
- AWT controls can be displayed by invoking the setVisible() method of the container, which makes the container and its components visible on the screen .
