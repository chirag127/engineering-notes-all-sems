## Unit 2 - Web Page Designing

- Web page designing is the process of creating and arranging the content of a web page, such as text, images, links, videos, etc.
- Web page designing involves two aspects: web design and web development.
- Web design is the visual and aesthetic aspect of a web page, such as layout, color scheme, typography, etc. Web design is usually done using tools like HTML, CSS, and JavaScript.
- Web development is the functional and interactive aspect of a web page, such as navigation, user input, data processing, etc. Web development is usually done using tools like PHP, Python, Ruby, etc.
- Web page designing follows some principles and guidelines to ensure usability, accessibility, and compatibility of the web page across different devices and browsers.
- Some of the principles and guidelines are:

  - Consistency: The web page should have a consistent look and feel throughout, such as using the same fonts, colors, and layout.
  - Simplicity: The web page should avoid unnecessary clutter and complexity, and focus on the essential content and functionality.
  - Contrast: The web page should use contrast to highlight the important elements and create visual hierarchy, such as using dark text on light background, or using different sizes and weights for headings and paragraphs.
  - Alignment: The web page should align the elements to create a sense of order and balance, such as using grids, margins, and padding.
  - Proximity: The web page should group the related elements together and separate the unrelated elements, to create a clear structure and organization.
  - Repetition: The web page should repeat some elements to create a sense of unity and harmony, such as using the same logo, navigation, or footer on every page.
  - White space: The web page should use white space to create a sense of breathing room and clarity, and to avoid overcrowding and confusion.
  - Feedback: The web page should provide feedback to the user to indicate the status and outcome of their actions, such as using colors, icons, or messages.
