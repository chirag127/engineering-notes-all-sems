### Unit 3 - Scripting

- Scripting is a technique of writing code that can be executed by a web browser or a web server to create dynamic web pages or web applications.
- Scripting languages are high-level, interpreted, and often platform-independent languages that can run on different web browsers or web servers without requiring compilation.
- Scripting languages can be classified into two types: client-side scripting and server-side scripting.

#### Client-side scripting

- Client-side scripting is the technique of writing code that runs on the web browser of the user, and can manipulate the HTML document, the browser window, or the user interface.
- Client-side scripting can enhance the interactivity, usability, and functionality of web pages, and can also validate user input, store data locally, or communicate with other web pages or web services.
- Some examples of client-side scripting languages are JavaScript, VBScript, TypeScript, CoffeeScript, etc.

#### Server-side scripting

- Server-side scripting is the technique of writing code that runs on the web server, and can generate dynamic web pages or web applications based on the user request, the server data, or the database.
- Server-side scripting can provide security, authentication, session management, data processing, and business logic for web pages or web applications, and can also access or modify the server files, the database, or the web services.
- Some examples of server-side scripting languages are PHP, ASP.NET, Python, Ruby, Perl, etc.
