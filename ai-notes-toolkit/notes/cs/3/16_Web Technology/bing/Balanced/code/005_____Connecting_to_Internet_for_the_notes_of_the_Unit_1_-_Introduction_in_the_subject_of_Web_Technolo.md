### Connecting to Internet

- The internet is a global network of computers and devices that communicate with each other using standardized protocols.
- To connect to the internet, you need an internet service provider (ISP) that provides you with access to the network, such as America Online or Earthlink.
- There are different ways to connect to the internet, depending on the type of device, the location, and the speed of the connection.
- Some of the common ways to connect to the internet are:

  - Wi-Fi: This is a wireless connection that uses radio waves to transmit data between devices and a router. A router is a device that allows you to connect multiple devices to a single internet connection. You can use Wi-Fi to connect to the internet from your laptop, smartphone, tablet, or other devices that have a Wi-Fi adapter. To use Wi-Fi, you need to be within the range of a Wi-Fi network, which may be provided by your ISP, a public hotspot, or a private network. You also need to know the network name and password, if any, to join the network.
  - Ethernet: This is a wired connection that uses a cable to connect your device to a router or a modem. A modem is a device that converts the signals from your ISP into a format that your device can understand. Ethernet is usually faster and more reliable than Wi-Fi, but it limits your mobility and requires a physical port on your device. You can use Ethernet to connect to the internet from your desktop computer, laptop, or other devices that have an Ethernet port.
  - Dial-up: This is an outdated connection that uses a phone line and a modem to connect your device to the internet. Dial-up is very slow and unreliable, and it prevents you from using your phone line for other purposes while you are online. You can use dial-up to connect to the internet from your desktop computer or laptop that has a modem and a phone jack.

- Once you are connected to the internet, you can use a web browser to access the web, which is a collection of web pages and other resources hosted on servers around the world. A web page is a document that contains text, images, videos, and other elements that can be displayed by a web browser. A server is a computer that stores and delivers web pages and other resources to clients that request them. A client is a device or a software that connects to the internet and requests web pages and other resources from servers.
- To access a web page, you need to know its web address, also known as a URL (Uniform Resource Locator). A URL consists of several parts, such as the protocol, the domain name, the path, and the query string. For example, the URL https://www.example.com/index.html?name=Sydney has the following parts:

  - Protocol: This indicates the method of communication between the client and the server. The most common protocol for the web is HTTP (Hypertext Transfer Protocol), which defines how web pages and other resources are transferred over the internet. Other protocols include HTTPS (HTTP Secure), which encrypts the data for security, and FTP (File Transfer Protocol), which allows you to upload and download files from a server.
  - Domain name: This identifies the server that hosts the web page or the resource. A domain name consists of one or more labels separated by dots, such as www.example.com. The rightmost label is called the top-level domain (TLD), which indicates the type or the location of the server, such as .com for commercial, .edu for education, or .uk for United Kingdom. The leftmost label is called the subdomain, which specifies a particular section or service of the server, such as www for the World Wide Web. The middle labels are called the second-level and third-level domains, which further identify the server or the organization that owns it, such as example for Example Corporation.
  - Path: This specifies the location of the web page or the resource on the server. A path consists of one or more segments separated by slashes, such as /index.html. The rightmost segment is called the file name, which indicates the name and the type of the web page or the resource, such as index.html for a HTML (Hypertext Markup Language) document. The leftmost segment is called the root, which represents the top-level directory of the server. The middle segments are called the subdirectories, which organize the web pages and the resources into folders, such as /images for a folder that contains images.
