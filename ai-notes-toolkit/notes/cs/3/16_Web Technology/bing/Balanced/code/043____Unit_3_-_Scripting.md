## Unit 3 - Scripting

- Scripting is the process of writing and executing a series of commands or instructions that can be run by a computer program or system.
- Scripting languages are high-level languages that are interpreted or compiled at run-time, rather than compiled in advance.
- Scripting languages are often used for automating tasks, manipulating data, creating dynamic web pages, testing software, and developing games.
- Some common scripting languages are Python, JavaScript, Ruby, Perl, Bash, and PowerShell.
- Scripting languages have some advantages and disadvantages compared to compiled languages, such as:
  - Advantages:
    - Easier to learn and use, as they have simpler syntax and less boilerplate code.
    - More flexible and expressive, as they support multiple paradigms and features, such as dynamic typing, regular expressions, and closures.
    - More portable and cross-platform, as they can run on different operating systems and platforms with minimal changes.
    - Faster to develop and debug, as they allow rapid prototyping and interactive testing.
  - Disadvantages:
    - Slower to execute, as they incur overhead from interpretation or compilation at run-time.
    - Less secure and reliable, as they are more prone to errors, bugs, and vulnerabilities, due to lack of type checking, memory management, and compilation errors.
    - Less efficient and scalable, as they consume more memory and CPU resources, and have less control over low-level operations and hardware.
- Scripting languages can be classified into different types, based on their design and implementation, such as:
  - Embedded scripting languages, which are integrated into a host application or system, and can access and manipulate its data and functions. Examples are JavaScript, Lua, and VBScript.
  - Stand-alone scripting languages, which can run independently as a separate program or process, and can interact with other programs or systems through files, pipes, sockets, or APIs. Examples are Python, Ruby, and Perl.
  - Shell scripting languages, which are used to control and automate the operations of a command-line interface or a shell. Examples are Bash, PowerShell, and Zsh.
  - Domain-specific scripting languages, which are designed for a specific application domain or problem, and have specialized syntax and features for that domain. Examples are SQL, R, and MATLAB.
