### Methods & Classes

- A method is a block of code that performs a specific task. It can be invoked by other parts of the program or by the user.
- A class is a blueprint for creating objects. It defines the attributes and behaviors of the objects of that class.
- In web technology, methods and classes are used to create dynamic and interactive web pages. For example, JavaScript methods and classes can manipulate the HTML elements and respond to user events.
- Some of the common methods and classes in web technology are:

  - `document.getElementById(id)`: This method returns the HTML element with the specified id attribute. It can be used to access and modify the element's properties and content.
  - `document.createElement(tagName)`: This method creates a new HTML element with the specified tag name. It can be used to add new elements to the web page.
  - `element.appendChild(child)`: This method adds a new child element to the end of the specified parent element. It can be used to create nested elements and build the web page structure.
  - `element.setAttribute(name, value)`: This method sets the value of the specified attribute for the specified element. It can be used to change the appearance and functionality of the element.
  - `element.addEventListener(type, listener)`: This method adds an event listener to the specified element. It can be used to execute a function when the element is triggered by a certain event, such as a click or a mouseover.
  - `window.location`: This class represents the current URL of the web page. It has properties and methods that can be used to get and set the URL components, such as the hostname, pathname, search, hash, etc.
  - `window.history`: This class represents the browser's history of visited pages. It has properties and methods that can be used to navigate back and forth, push and pop states, and manipulate the history stack.
  - `window.localStorage`: This class represents the local storage of the browser. It allows the web page to store and retrieve data in the form of key-value pairs. It can be used to persist data across browser sessions and improve the user experience.
