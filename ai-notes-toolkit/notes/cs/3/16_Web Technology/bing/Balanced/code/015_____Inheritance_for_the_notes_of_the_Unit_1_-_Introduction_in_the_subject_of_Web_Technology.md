### Inheritance

- Inheritance is a concept in object-oriented programming that allows one class to inherit the properties and methods of another class.
- Inheritance enables code reuse and polymorphism, which means that the same code can behave differently depending on the context.
- Inheritance is implemented using the `extends` keyword in Java, the `:` operator in C++, and the `class` statement in Python.
- Inheritance can be single, multiple, or hierarchical, depending on how many classes are involved in the inheritance relationship.
- Single inheritance is when a class inherits from only one parent class.
- Multiple inheritance is when a class inherits from more than one parent class.
- Hierarchical inheritance is when a class inherits from a parent class, and then has one or more subclasses that inherit from it.
- Inheritance can also be categorized as public, protected, or private, depending on the access level of the inherited members.
- Public inheritance means that the inherited members are accessible to the subclass and the outside world.
- Protected inheritance means that the inherited members are accessible to the subclass and its subclasses, but not to the outside world.
- Private inheritance means that the inherited members are accessible only to the subclass, but not to its subclasses or the outside world.
