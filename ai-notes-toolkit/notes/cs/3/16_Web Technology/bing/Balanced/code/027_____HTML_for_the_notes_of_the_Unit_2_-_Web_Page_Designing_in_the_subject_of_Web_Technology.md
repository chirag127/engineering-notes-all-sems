### HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- HTML stands for Hyper Text Markup Language, which is the code that is used to structure a web page and its content .
- HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear or act a certain way.
- HTML elements are made up of two tags: an opening tag and a closing tag, with the content in between. For example, `<p>This is a paragraph.</p>` .
- Some HTML elements are self-closing, which means they do not need a closing tag. For example, `<img src="image.jpg" alt="An image">` .
- HTML elements can have attributes, which are additional information that modify or describe the element. Attributes are specified in the opening tag, using a name-value pair separated by an equal sign. For example, `<a href="https://www.example.com">This is a link</a>` .
- HTML elements can be nested inside other elements, which creates a hierarchy of elements that defines the structure of the web page. For example, `<html><head><title>My page</title></head><body><h1>My heading</h1><p>My paragraph</p></body></html>` .
- HTML documents must start with a document type declaration, which tells the browser what version of HTML the page is using. The declaration is written as `<!DOCTYPE html>` .
- HTML documents must also have a `<html>` element that wraps the entire page, a `<head>` element that contains information about the page, and a `<body>` element that contains the visible content of the page .
- HTML documents can have different types of content, such as headings, paragraphs, lists, images, links, tables, forms, etc. Each type of content has a specific HTML element or elements that are used to mark it up .
- HTML documents can also use CSS (Cascading Style Sheets) to style the appearance of the elements, and JavaScript to add interactivity and functionality to the page .
