### Manipulating for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

- Enterprise Java Bean (EJB) is a Java technology that provides a server-side component architecture for developing distributed, transactional, secure and portable applications .
- EJB components are called enterprise beans, which are written in the Java programming language and encapsulate the business logic of an application .
- There are three types of enterprise beans: entity beans, session beans and message-driven beans.
  - Entity beans represent persistent data stored in a database. They can be accessed and updated by multiple clients .
  - Session beans represent transient data and business processes that are specific to a client session. They can be stateful or stateless .
  - Message-driven beans are stateless beans that process messages asynchronously from a message queue or topic .
- EJB components run inside a container, which is a runtime environment that provides services such as security, transaction management, dependency injection, concurrency control and lifecycle management .
- EJB components can be accessed by local or remote clients using various protocols, such as Java Remote Method Invocation (RMI), Java Message Service (JMS), Java API for RESTful Web Services (JAX-RS) or Java API for XML Web Services (JAX-WS) .
- EJB components can also interact with other Java EE components, such as servlets, JavaServer Pages (JSP), JavaServer Faces (JSF), Java Persistence API (JPA) or Contexts and Dependency Injection (CDI) .
- EJB technology is part of the Jakarta EE platform, which is the successor of the Java EE platform. The latest version of EJB is 4.0, which was released in 2020.
