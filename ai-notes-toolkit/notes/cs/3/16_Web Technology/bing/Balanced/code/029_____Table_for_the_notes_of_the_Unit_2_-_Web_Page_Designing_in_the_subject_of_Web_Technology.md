| Introduction to Web Page Designing | Definition and purpose of web pages | - A web page is a document that can be accessed through a web browser over the internet or intranet. <br> - The purpose of web pages is to present information, provide interactivity, and enable communication. |
|  | Types of web pages | - Static web pages: These are web pages that do not change in response to user input or server-side events. They are created using HTML and CSS and stored as files on the web server. <br> - Dynamic web pages: These are web pages that change in response to user input or server-side events. They are created using scripting languages such as PHP, ASP, or JavaScript and interact with databases or other web services. |
|  | Web page components | - A web page consists of various components such as text, images, videos, audio, links, forms, tables, lists, etc. <br> - These components are arranged using HTML tags and styled using CSS properties. <br> - Some components may also have interactivity or functionality using JavaScript or other scripting languages. |
| HTML | Basic structure and syntax of HTML | - HTML stands for HyperText Markup Language and is the standard language for creating web pages. <br> - HTML uses tags to mark up the content of a web page. A tag consists of a name enclosed in angle brackets, such as `<p>` for paragraph or `<img>` for image. Some tags have attributes that provide additional information, such as `src` for source or `alt` for alternative text. <br> - HTML tags are usually paired, with a start tag and an end tag, such as `<p>` and `</p>`. Some tags are self-closing, meaning they do not need an end tag, such as `<img />`. <br> - HTML documents have a basic structure that consists of a `<html>` tag, a `<head>` tag, and a `<body>` tag. The `<head>` tag contains information about the document, such as the `<title>` or the `<meta>` tags. The `<body>` tag contains the visible content of the document, such as the `<h1>` or the `<p>` tags. |
|  | Common HTML tags and attributes | - Some of the common HTML tags are: <br> - `<h1>` to `<h6>`: These are heading tags that define the titles and subtitles of a web page. The `<h1>` tag is the most important and the `<h6>` tag is the least important. <br> - `<p>`: This is the paragraph tag that defines a block of text. <br> - `<a>`: This is the anchor tag that defines a hyperlink to another web page or resource. The `href` attribute specifies the URL of the destination. The `target` attribute specifies how the destination should be opened, such as `_blank` for a new tab or `_self` for the same tab. <br> - `<img>`: This is the image tag that defines an image to be displayed on the web page. The `src` attribute specifies the URL of the image. The `alt` attribute specifies the alternative text that is displayed if the image cannot be loaded. The `width` and `height` attributes specify the dimensions of the image in pixels. <br> - `<div>`: This is the division tag that defines a section or a container for other elements. It is used to group and organize the layout of the web page. <br> - `<span>`: This is the span tag that defines a part or a segment of text. It is used to apply styles or scripts to a specific portion of text. <br> - `<ul>` and `<ol>`: These are the unordered list and ordered list tags that define a list of items. The `<ul>` tag creates a list with bullet points, while the `<ol>` tag creates a list with numbers or letters. Each item in the list is defined by the `<li>` tag. <br> - `<table>`: This is the table tag that defines a table of data. The table consists of rows defined by the `<tr>` tag, columns defined by the `<td>` tag, and headers defined by the `<th>` tag. The `<caption>` tag defines the title of the table. The `<thead>`, `<tbody>`, and `<tfoot>` tags define the sections of the table. |
