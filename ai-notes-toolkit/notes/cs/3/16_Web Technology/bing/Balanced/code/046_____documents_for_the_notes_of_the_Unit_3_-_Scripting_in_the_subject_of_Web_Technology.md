### Unit 3 - Scripting

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server at run time, rather than compiled in advance.
- Scripting languages can be embedded in HTML documents or stored in external files that are linked to HTML documents.
- Scripting languages can interact with HTML elements, browser events, user input, web servers, databases, and other web technologies.
- Some examples of scripting languages are JavaScript, PHP, Python, Ruby, and Perl.

#### JavaScript

- JavaScript is a scripting language that runs on the client side, meaning it is executed by the browser.
- JavaScript can manipulate HTML elements, change the appearance and content of web pages, validate user input, create animations, and communicate with web servers.
- JavaScript can be embedded in HTML documents using the `<script>` tag or stored in external files with the `.js` extension that are linked to HTML documents using the `src` attribute of the `<script>` tag.
- JavaScript follows the syntax and rules of the ECMAScript standard, which is a subset of JavaScript.
- JavaScript supports data types, variables, operators, expressions, statements, functions, objects, arrays, and built-in objects such as Math, Date, String, and Number.

#### PHP

- PHP is a scripting language that runs on the server side, meaning it is executed by the web server before sending the HTML output to the browser.
- PHP can generate dynamic and customized web pages, process user input, access databases, send and receive cookies, and communicate with other web technologies.
- PHP can be embedded in HTML documents using the `<?php ?>` tag or stored in external files with the `.php` extension that are linked to HTML documents using the `include` or `require` functions.
- PHP follows the syntax and rules of the C language, but also supports features from other languages such as Perl and Java.
- PHP supports data types, variables, constants, operators, expressions, statements, functions, classes, objects, arrays, and built-in objects such as $_GET, $_POST, $_COOKIE, and $_SESSION.
