### Statements for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is the process of creating and embedding scripts in a web page to add dynamic capabilities and functionality.
- Scripts are lists of commands that are interpreted and executed by a certain program or scripting engine.
- Scripting languages are high-level programming languages that are easy to use and learn, and do not require compilation.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages are executed by the browser on the user's device, and are used to manipulate the web page's content, style, and behavior .
- Examples of client-side scripting languages are JavaScript, VBScript, and HTML .
- Server-side scripting languages are executed by the web server, and are used to generate dynamic web pages, access databases, and handle user requests.
- Examples of server-side scripting languages are PHP, ASP, Perl, Python, and Ruby on Rails.
- JavaScript is the most widely used scripting language for web development, and can be used for both client-side and server-side scripting.
- JavaScript can be applied to HTML pages using the <script> element, which can contain either inline code or a reference to an external file.
- JavaScript can interact with the web page's elements using the Document Object Model (DOM), which is a tree-like representation of the HTML structure.
- JavaScript can also use various web APIs to access features such as geolocation, storage, media, and networking.
