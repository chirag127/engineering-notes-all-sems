### Scripting for the notes of the Unit 5 - Servlets in the subject of Web Technology

- Scripting is a web development method that uses scripts to create dynamic and interactive web pages.
- Scripts are small programs that are embedded in HTML documents and executed by the web browser or the web server.
- There are two types of scripting: client-side and server-side.
- Client-side scripting is executed by the web browser on the user's machine. It can manipulate the HTML document, validate user input, communicate with the server, and create animations and effects.
- Server-side scripting is executed by the web server on the server machine. It can access databases, generate dynamic content, perform authentication and authorization, and process business logic.
- Servlets are a type of server-side scripting technology that use Java as the programming language.
- Servlets are Java classes that implement the javax.servlet.Servlet interface and run inside a Java-enabled web server.
- Servlets can handle HTTP requests and responses, access databases, perform session management, and communicate with other web components.
- Servlets are compiled into bytecode and loaded by the web server. They have a life cycle that consists of initialization, service, and destruction methods.
- Servlets can be configured and mapped to URLs using web.xml deployment descriptor or annotations.
- Servlets can use request and response objects to access and manipulate HTTP headers, parameters, attributes, cookies, and sessions.
- Servlets can use JavaServer Pages (JSP) technology to create dynamic web pages that separate presentation from business logic.
- JSP pages are HTML documents that contain Java code snippets and special tags that are processed by the web server and converted into servlets.
- JSP pages can use scripting elements, directives, actions, expressions, and custom tags to create dynamic content and access web components.
- JSP pages can use the Java Standard Tag Library (JSTL) and Expression Language (EL) to simplify the scripting and reduce the Java code.
