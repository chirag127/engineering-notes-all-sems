### Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

- Core Java is the basic and fundamental part of the Java programming language that is used for developing general-purpose applications.
- Core Java covers the essential features and concepts of the Java language, such as data types, operators, control statements, arrays, strings, classes, objects, inheritance, polymorphism, exception handling, input/output, collections, generics, concurrency, and networking.
- Core Java is also known as Java Standard Edition (Java SE) or Java Platform, Standard Edition (Java Platform, SE).
- Core Java is the foundation for developing other Java technologies and frameworks, such as Java Enterprise Edition (Java EE) or Java Platform, Enterprise Edition (Java Platform, EE) and Java Micro Edition (Java ME) or Java Platform, Micro Edition (Java Platform, ME).
- Core Java enables developers to create portable, secure, robust, high-performance, and scalable applications that can run on various platforms, such as Windows, Linux, Mac OS, and Solaris, using the Java Virtual Machine (JVM).
- Core Java follows the principle of "write once, run anywhere" (WORA), which means that the same Java code can be executed on any machine that supports the JVM, without requiring recompilation or modification.
- Core Java is one of the most popular and widely used programming languages in the world, with millions of developers and billions of devices running Java applications.
