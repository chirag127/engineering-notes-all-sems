### I/O for the notes of the Unit 1 - Introduction in the subject of Web Technology

- I/O stands for input/output, which refers to the communication between a computer system and its users, devices, or other systems.
- Input is the data or commands that are entered into a computer system, such as keyboard strokes, mouse clicks, voice commands, or scanned images.
- Output is the data or information that are produced by a computer system, such as text, images, sound, or video displayed on a screen, printed on a paper, or sent to another system.
- I/O devices are the hardware components that enable input and output, such as keyboards, mice, scanners, monitors, printers, speakers, or network cards.
- I/O operations are the processes that involve transferring data or information between a computer system and its I/O devices, such as reading, writing, displaying, or printing.
- I/O is an essential aspect of web technology, as it enables the interaction between web servers, web browsers, and web users.
- Web servers are computer systems that store and deliver web pages and other web resources to web browsers over the internet.
- Web browsers are software applications that request and display web pages and other web resources from web servers or local files.
- Web users are the people who use web browsers to access and interact with web pages and other web resources on the internet or local files.
- Web pages are documents that contain text, images, links, and other elements that can be displayed by web browsers.
- Web resources are any data or information that can be accessed by web browsers, such as images, videos, audio, scripts, stylesheets, or databases.
- Web pages and web resources are identified by unique addresses called URLs (Uniform Resource Locators), which specify the protocol, domain name, path, and file name of the resource.
- Web pages and web resources are encoded using standard languages and formats, such as HTML (HyperText Markup Language), CSS (Cascading Style Sheets), JavaScript, XML (Extensible Markup Language), JSON (JavaScript Object Notation), or JPEG (Joint Photographic Experts Group).
- Web pages and web resources are transferred between web servers and web browsers using standard protocols, such as HTTP (HyperText Transfer Protocol), HTTPS (HyperText Transfer Protocol Secure), FTP (File Transfer Protocol), or SMTP (Simple Mail Transfer Protocol).
- Web technology is constantly evolving and expanding, as new standards, languages, formats, protocols, devices, and applications are developed and adopted.
