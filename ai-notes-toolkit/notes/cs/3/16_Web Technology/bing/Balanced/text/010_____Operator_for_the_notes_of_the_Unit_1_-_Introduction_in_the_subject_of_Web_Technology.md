### Operator

- An operator is a symbol that performs a specific operation on one or more operands.
- An operand is a value or a variable that is involved in the operation.
- Operators can be classified into different types based on the number of operands, the type of operands, and the functionality of the operation.
- Some of the common types of operators are:

  - Arithmetic operators: These operators perform basic mathematical operations such as addition, subtraction, multiplication, division, modulus, exponentiation, and negation. For example, `+`, `-`, `*`, `/`, `%`, `**`, and `-`.
  - Assignment operators: These operators assign a value to a variable or a property. For example, `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, and `.=`.
  - Comparison operators: These operators compare two operands and return a boolean value (true or false) based on the result of the comparison. For example, `==`, `!=`, `===`, `!==`, `<`, `>`, `<=`, `>=`, `<=>`, and `??`.
  - Logical operators: These operators perform logical operations such as conjunction, disjunction, negation, and conditional. For example, `&&`, `||`, `!`, and `?:`.
  - Bitwise operators: These operators perform operations on the binary representation of the operands, such as bitwise and, bitwise or, bitwise xor, bitwise not, left shift, right shift, and zero-fill right shift. For example, `&`, `|`, `^`, `~`, `<<`, `>>`, and `>>>`.
  - String operators: These operators perform operations on strings, such as concatenation, interpolation, and extraction. For example, `.`, `.=`, `"`, `'`, and `{}`.
  - Array operators: These operators perform operations on arrays, such as union, difference, intersection, and append. For example, `+`, `-`, `*`, and `[]`.
  - Type operators: These operators perform operations on the type or the class of the operands, such as type casting, type checking, type declaration, and type inference. For example, `(type)`, `instanceof`, `declare`, and `as`.
  - Control operators: These operators control the flow of execution of the program, such as branching, looping, and exiting. For example, `if`, `else`, `switch`, `case`, `for`, `while`, `do`, `break`, `continue`, and `return`.
  - Function operators: These operators perform operations on functions, such as definition, invocation, passing, returning, and binding. For example, `function`, `()`, `=>`, `call`, `apply`, and `bind`.
  - Object operators: These operators perform operations on objects, such as creation, access, modification, deletion, and iteration. For example, `new`, `.`, `[]`, `->`, `in`, `of`, and `delete`.
  - Class operators: These operators perform operations on classes, such as definition, inheritance, instantiation, polymorphism, and abstraction. For example, `class`, `extends`, `implements`, `new`, `super`, and `abstract`.
  - Namespace operators: These operators perform operations on namespaces, such as definition, import, export, and alias. For example, `namespace`, `use`, `as`, `import`, `export`, and `from`.
  - Error operators: These operators perform operations on errors, such as throwing, catching, handling, and logging. For example, `throw`, `try`, `catch`, `finally`, and `error_log`.
