### Introduction to AJAX

- AJAX stands for **Asynchronous JavaScript and XML** .
- AJAX is **not** a programming language, but a technique for creating **better, faster, and more interactive web applications** .
- AJAX uses various web technologies on the **client-side** to communicate with the web server **behind the scenes** without reloading the whole page .
- AJAX uses **XMLHttpRequest** object to request data from the web server, and **JavaScript and HTML DOM** to display or use the data.
- AJAX can transport data as **XML, plain text, or JSON** text.
- AJAX allows web pages to be **updated asynchronously** by exchanging data with the web server, which improves the user experience and performance .
