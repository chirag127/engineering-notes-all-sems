### URL for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is the process of creating and embedding scripts in a web page to make it dynamic and interactive.
- Scripts are lists of commands that are interpreted and executed by a certain program or scripting engine.
- There are two types of scripting: client-side and server-side.
- Client-side scripting is executed by the web browser on the user's device. It can manipulate the web page elements, validate user input, communicate with the server, and create animations and effects.
- Server-side scripting is executed by the web server before sending the web page to the browser. It can generate dynamic web pages, access databases, handle user authentication, and perform business logic.
- Some common scripting languages are:
  - JavaScript: a client-side scripting language that can also run on the server using Node.js .
  - PHP: a server-side scripting language that can embed HTML code and interact with databases.
  - XML: a markup language that can store and exchange data between different applications.
  - HTML: a markup language that defines the structure and content of a web page.
  - Perl: a general-purpose scripting language that can handle text processing, web development, and system administration.
- Scripting is an essential part of web development as it can enhance the functionality, usability, and appearance of a web page.
