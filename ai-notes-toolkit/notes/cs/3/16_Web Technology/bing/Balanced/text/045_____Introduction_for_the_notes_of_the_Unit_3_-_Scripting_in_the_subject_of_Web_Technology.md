### Introduction for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a technique of writing code that can be executed by an interpreter or a browser to perform a specific task or function on a web page or a web application.
- Scripting languages are high-level languages that are easy to write, read and debug. They are often interpreted rather than compiled, which means they are translated into machine code at run time rather than before execution.
- Scripting languages are usually embedded in HTML documents or linked to external files. They can interact with the HTML elements, the browser, the server and other web resources to create dynamic and interactive web pages or applications.
- Some examples of scripting languages are JavaScript, PHP, Python, Ruby, Perl and ASP.NET.
- Scripting languages can be classified into two types: client-side scripting and server-side scripting.
- Client-side scripting is the type of scripting that runs on the user's browser. It can manipulate the HTML document, validate user input, create animations, handle events and communicate with the server using AJAX (Asynchronous JavaScript and XML).
- Server-side scripting is the type of scripting that runs on the web server. It can process user requests, access databases, generate dynamic HTML content, send emails and perform other server-side tasks.
- Both types of scripting can work together to create a rich and responsive web experience for the user.
