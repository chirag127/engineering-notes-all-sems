### Java Applet

- A Java applet is a small dynamic Java program that can be transferred via the Internet and run by a Java-compatible Web browser.
- The main difference between Java-based applications and applets is that applets are typically executed in an AppletViewer or Java-compatible Web browser, while applications are executed by the Java interpreter.
- Java applets are written in the Java programming language, or another programming language that compiles to Java bytecode, and delivered to users in the form of Java bytecode .
- Java bytecode is a set of instructions that can be executed by a Java virtual machine (JVM), which is a software layer that interprets the bytecode and runs it on the underlying hardware and operating system.
- Java applets can provide web applications with interactive and dynamic features that HTML cannot offer, such as animations, games, calculators, etc.
- Java applets are launched from HTML using the `<applet>` tag, which specifies the name, size, and parameters of the applet.
- Java applets have limited functionality and access to the user's system, as they are subject to security restrictions imposed by the browser and the JVM.
- Java applets are no longer supported by most modern browsers, as they have been replaced by other technologies such as JavaScript, HTML5, and Java Web Start.
