# Introduction to AJAX

- AJAX stands for **Asynchronous JavaScript and XML**. It is a technique for creating dynamic and interactive web pages that can update parts of the page without reloading the whole page.
- AJAX uses a combination of **XMLHttpRequest** object, **JavaScript**, **HTML**, **CSS** and **XML** or **JSON** to communicate with the web server and manipulate the Document Object Model (DOM) of the web page.
- AJAX allows the web page to **send and receive data** from the web server in the background, without interfering with the display and behavior of the web page.
- AJAX can improve the **user experience** and **performance** of the web page by reducing the network traffic and latency, and providing faster and smoother feedback to the user.
- AJAX can also enable the web page to **interact with other web services** and APIs, such as Google Maps, Flickr, YouTube, etc.
