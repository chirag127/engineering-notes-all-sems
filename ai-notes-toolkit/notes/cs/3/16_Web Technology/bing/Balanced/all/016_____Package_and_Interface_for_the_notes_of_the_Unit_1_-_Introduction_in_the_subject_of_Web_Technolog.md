# Package and Interface

## Package
- A package is an organized set of related classes and interfaces in a programming language like Java .
- A package helps to group similar types of classes and interfaces and avoid name conflicts .
- A package can be accessed using an import statement in the source code  .
- A package can have subpackages and can be nested to any level .
- A package can have different levels of access modifiers (public, protected, default, private) to control the visibility of its classes and interfaces .
- A package can be created using the package keyword followed by the package name .

## Interface
- An interface is a set of fields and abstract methods that mainly allows implementing abstraction in a programming language like Java  .
- An interface defines a contract or a specification for the classes that implement it  .
- An interface can be extended by another interface using the extends keyword or implemented by a class using the implements keyword  .
- An interface can have only public, static, and final fields and public and abstract methods  .
- An interface can have default and static methods that provide default implementations for the classes that implement it  .
- An interface can be created using the interface keyword followed by the interface name  .
