# Protocols Governing Web

- Protocols are a set of rules or standards that enable communication between different devices or applications over a network.
- The web is a collection of interconnected documents and resources that are accessed using the internet, which is a global network of computers and networks.
- The web relies on various protocols to function properly and efficiently. Some of the most common protocols governing the web are:

  - **TCP/IP (Transmission Control Protocol/Internet Protocol)**: This is the fundamental protocol suite that enables data transmission across the internet and other networks. It consists of two main protocols: TCP, which ensures reliable and ordered delivery of data packets, and IP, which routes the packets to their destination based on their addresses .
  - **HTTP (HyperText Transfer Protocol)**: This is the protocol that defines how web browsers and web servers communicate and exchange information. It uses a request-response model, where the browser sends a request for a resource (such as a web page, an image, or a file) to the server, and the server responds with the resource or an error message. HTTP also supports methods such as GET, POST, PUT, and DELETE, which specify the action to be performed on the resource.
  - **DNS (Domain Name System)**: This is the protocol that translates human-readable domain names (such as www.example.com) into numerical IP addresses (such as 192.168.1.1) that are used by the TCP/IP protocol. DNS also provides other information such as the mail server and the name server for a domain. DNS uses a hierarchical and distributed database of domain names and IP addresses, which are maintained by various servers around the world.
  - **SMTP (Simple Mail Transfer Protocol)**: This is the protocol that enables the sending and receiving of email messages over the internet. SMTP uses a client-server model, where the client (such as an email application) connects to the server (such as an email provider) and sends the message to the recipient's address. SMTP also supports commands such as HELO, MAIL, RCPT, DATA, and QUIT, which specify the details of the message and the connection.
  - **FTP (File Transfer Protocol)**: This is the protocol that enables the transfer of files between different computers or networks over the internet. FTP uses a client-server model, where the client (such as a file manager) connects to the server (such as a web host) and requests to upload or download files. FTP also supports commands such as USER, PASS, LIST, RETR, STOR, and QUIT, which specify the authentication, navigation, and transfer of files.
