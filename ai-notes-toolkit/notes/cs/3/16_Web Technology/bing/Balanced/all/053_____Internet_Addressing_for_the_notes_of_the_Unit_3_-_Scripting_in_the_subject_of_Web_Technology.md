# Internet Addressing

- Internet addressing is the process of assigning unique identifiers to devices and networks that communicate over the Internet Protocol (IP)  .
- Internet addresses are also known as IP addresses, and they consist of four numbers separated by dots, such as 192.168.1.1  .
- Each IP address has two parts: a network address and a host address. The network address identifies the network or subnetwork that the device belongs to, and the host address identifies the specific device within that network or subnetwork  .
- For example, in the IP address 192.168.1.1, the network address is 192.168.1 and the host address is 1. The network address can be further divided into a network prefix and a subnet prefix, depending on the size and structure of the network  .
- There are two versions of IP addressing: IPv4 and IPv6. IPv4 uses 32-bit addresses, which can support up to 4.3 billion devices on the Internet. IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 devices on the Internet  .
- IPv4 addresses are written in decimal notation, while IPv6 addresses are written in hexadecimal notation. For example, an IPv4 address might look like 192.168.1.1, while an IPv6 address might look like 2001:db8::1  .
- IP addressing is essential for routing data packets across the Internet. Each packet contains the source and destination IP addresses, as well as other information, such as the protocol, the length, and the checksum. Routers use the IP addresses to determine the best path to deliver the packet to its destination  .
- IP addressing also enables various services and applications on the Internet, such as domain name system (DNS), which maps human-readable names to IP addresses, such as www.google.com to 172.217.14.206  .
