# Unit 3 - Scripting

## Statements

- A statement is a command or instruction that tells a script to do something.
- Statements are written in a specific syntax or format that the script interpreter can understand and execute.
- Statements can be simple or complex, depending on the task they perform and the logic they involve.
- Statements can be grouped together into blocks, which are enclosed by curly braces `{}`. Blocks can be nested inside other blocks to create more complex structures.
- Statements can be terminated by a semicolon `;`, which indicates the end of a command. However, some scripting languages do not require semicolons and can infer the end of a statement from the context or the line break.
- Statements can be commented out by using special symbols or characters that tell the script interpreter to ignore them. Comments are useful for documenting the code and explaining its purpose or functionality. Different scripting languages have different ways of writing comments, such as `//`, `/*...*/`, `#`, `<!--...-->`, etc.
