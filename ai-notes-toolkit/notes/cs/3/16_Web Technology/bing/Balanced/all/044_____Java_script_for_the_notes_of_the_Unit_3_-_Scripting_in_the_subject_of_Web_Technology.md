# JavaScript for the notes of the Unit 3 - Scripting in the subject of Web Technology

## Introduction

- JavaScript is a scripting language that runs in the web browser and can manipulate the HTML and CSS elements of a web page.
- JavaScript can also interact with the user, the browser, and external resources such as web APIs, databases, and files.
- JavaScript is one of the most popular and widely used programming languages in the web development field.

## Basic Syntax and Features

- JavaScript code is written inside `<script>` tags in an HTML document or in a separate `.js` file that is linked to the HTML document.
- JavaScript code consists of statements that end with a semicolon `;` and are executed from top to bottom.
- JavaScript is case-sensitive, meaning that `var` and `VAR` are different identifiers.
- JavaScript has two types of comments: single-line comments that start with `//` and multi-line comments that start and end with `/*` and `*/`.
- JavaScript has different types of values, such as numbers, strings, booleans, arrays, objects, functions, etc.
- JavaScript has different ways of declaring variables, such as `var`, `let`, and `const`.
- JavaScript has different operators, such as arithmetic, assignment, comparison, logical, bitwise, etc.
- JavaScript has different control structures, such as `if...else`, `switch`, `for`, `while`, `do...while`, `break`, `continue`, etc.
- JavaScript has different built-in objects, such as `Math`, `Date`, `String`, `Array`, `RegExp`, etc.
- JavaScript has different built-in methods, such as `alert()`, `console.log()`, `prompt()`, `parseInt()`, `parseFloat()`, etc.

## Functions and Events

- JavaScript functions are blocks of code that can be defined and called to perform a specific task or return a value.
- JavaScript functions can be declared using the `function` keyword or assigned to a variable using the `function` expression or the arrow function syntax.
- JavaScript functions can have parameters that are passed as arguments when the function is called.
- JavaScript functions can have a `return` statement that specifies the value to be returned to the caller.
- JavaScript functions can be nested, meaning that a function can be defined inside another function and have access to the outer function's variables and parameters.
- JavaScript events are actions or occurrences that happen in the browser, such as clicking a button, loading a page, resizing a window, etc.
- JavaScript can respond to events by attaching event handlers or listeners to HTML elements using the `addEventListener()` method or the `on` attribute.
- JavaScript can trigger events using the `dispatchEvent()` method or the `click()` method for click events.
- JavaScript can access the event object that contains information about the event, such as the type, target, coordinates, etc.

## DOM and BOM

- DOM stands for Document Object Model, which is a representation of the HTML document as a tree of nodes or objects that can be accessed and manipulated by JavaScript.
- BOM stands for Browser Object Model, which is a collection of objects that provide information and functionality related to the browser window, such as `window`, `document`, `location`, `history`, `navigator`, etc.
- JavaScript can use the DOM methods and properties to select, create, modify, and delete HTML elements and attributes, such as `getElementById()`, `querySelector()`, `createElement()`, `setAttribute()`, `appendChild()`, `removeChild()`, etc.
- JavaScript can use the DOM methods and properties to change the style and layout of HTML elements, such as `style`, `className`, `classList`, `offsetWidth`, `offsetHeight`, etc.
- JavaScript can use the BOM methods and properties to interact with the browser window, such as `open()`, `close()`, `resizeTo()`, `moveTo()`, `alert()`, `confirm()`, `prompt()`, etc.
- JavaScript can use the BOM methods and properties to navigate and manipulate the browser history, such as `back()`, `forward()`, `go()`, `pushState()`, `replaceState()`, etc.
- JavaScript can use the BOM methods and properties to access and modify the URL of the current page, such as `href`, `hash`, `search`, `pathname`, etc.
