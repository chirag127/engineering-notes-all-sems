# Networking for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is the process of creating and embedding scripts in a web page to add dynamic capabilities and interactivity.
- Scripts are lists of commands that are interpreted and executed by a certain program or scripting engine.
- Scripting languages are high-level languages that are easy to write and run without compilation.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages are executed by the browser on the user's device and can manipulate the Document Object Model (DOM) of the web page.
- Examples of client-side scripting languages are JavaScript, VBScript, and TypeScript.
- Server-side scripting languages are executed by the web server and can generate dynamic web pages, access databases, and handle user input.
- Examples of server-side scripting languages are PHP, Python, Ruby, and Perl.
- Scripting languages can be used for various purposes in web development, such as validating user input, creating animations, fetching data, sending emails, and more.
- JavaScript is the most widely used scripting language for web development and can run both on the client-side and the server-side.
- JavaScript can interact with HTML and CSS to create dynamic and responsive web pages.
- JavaScript can also use various web APIs to access features and functionalities of the web platform, such as geolocation, web storage, web sockets, and more.
