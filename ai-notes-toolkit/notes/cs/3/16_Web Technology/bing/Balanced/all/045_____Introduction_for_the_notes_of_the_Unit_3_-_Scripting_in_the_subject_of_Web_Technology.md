# Introduction for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server, rather than compiled by a compiler.
- Scripting languages can be embedded in HTML documents or stored in external files that are linked to HTML documents.
- Scripting languages can manipulate the content, structure, and style of web pages, as well as interact with users, web servers, databases, and other web resources.
- Scripting languages can be classified into two types: client-side scripting and server-side scripting.
- Client-side scripting languages are executed by the browser on the user's device. They can access and modify the Document Object Model (DOM) of the web page, respond to user events, validate user input, and communicate with web servers using AJAX (Asynchronous JavaScript and XML) or WebSockets.
- Server-side scripting languages are executed by the web server on the host machine. They can generate dynamic web pages, process user requests, perform database operations, and send emails.
- Some of the popular scripting languages are JavaScript, PHP, Python, Ruby, Perl, and ASP.NET.
