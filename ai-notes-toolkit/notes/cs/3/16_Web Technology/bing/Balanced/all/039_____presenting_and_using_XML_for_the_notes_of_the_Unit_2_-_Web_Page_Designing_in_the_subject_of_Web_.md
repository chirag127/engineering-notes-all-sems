# Presenting and using XML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- XML stands for Extensible Markup Language. It is a language for creating and storing structured data that can be used across different platforms and applications.
- XML is similar to HTML in syntax, but unlike HTML, XML does not have predefined tags or elements. XML allows users to define their own tags and elements to suit their needs and preferences.
- XML is not a presentation language, but a data description language. It does not specify how the data should be displayed, but only what the data is and how it is organized. XML documents can be transformed into different formats using style sheets or other tools.
- XML is widely used for web development, as it enables data exchange and interoperability between different systems and applications. Some examples of XML applications are RSS feeds, web services, SOAP messages, SVG graphics, XHTML documents, etc.
- XML documents have a simple and hierarchical structure, consisting of the following components:

  - XML declaration: It is an optional statement that specifies the version, encoding, and standalone status of the XML document. It must be the first line of the document and start with `<?xml ... ?>`.
  - Root element: It is the main element that contains all other elements in the XML document. It must have a start tag and an end tag, and it must be the only element at the top level of the document.
  - Child elements: They are the elements that are nested inside the root element or other elements. They can have attributes, text, or other child elements as their content. They must have a start tag and an end tag, or a self-closing tag if they are empty.
  - Attributes: They are name-value pairs that provide additional information about an element. They are written inside the start tag of the element, separated by spaces, and enclosed in quotation marks. They cannot have child elements or text as their content.
  - Text: It is the actual data that is stored in the XML document. It can be written inside the start tag and the end tag of an element, or between the quotation marks of an attribute. It can contain any character, except the reserved ones (`<`, `>`, `&`, `"`, `'`), which must be escaped using predefined entities or numeric references.
  - Comments: They are notes or annotations that are ignored by the XML parser. They are written between `<!--` and `-->`, and they can appear anywhere in the XML document, except inside the XML declaration, elements, attributes, or text.
  - Processing instructions: They are instructions for the XML processor or other applications that handle the XML document. They are written between `<?` and `?>`, and they can appear anywhere in the XML document, except inside the XML declaration, elements, attributes, or text.
  - CDATA sections: They are sections of text that are treated as raw data by the XML parser. They are written between `<![CDATA[` and `]]>`, and they can appear anywhere in the XML document, except inside the XML declaration, elements, attributes, or text. They are useful for writing text that contains reserved characters, without escaping them.
  - Entity references: They are placeholders for predefined or user-defined characters or strings that are substituted by the XML parser. They are written as `&name;` or `&#number;`, and they can appear anywhere in the XML document, except inside the XML declaration, elements, attributes, or comments. They are useful for writing special characters, symbols, or frequently used text.

- XML documents must follow some rules and conventions to be well-formed and valid. A well-formed XML document is one that conforms to the basic syntax and structure of XML. A valid XML document is one that conforms to a specific schema or grammar that defines the allowed elements, attributes, and content of the XML document. A schema can be written using DTD (Document Type Definition) or XML Schema languages.
- XML documents can be presented and used in different ways, depending on the purpose and the target audience. Some common methods are:

  - Using style sheets: Style sheets are files that define how the XML data should be formatted and displayed. XSL is a more powerful and complex language that can transform XML documents into other formats, such as HTML, PDF, or plain text.
