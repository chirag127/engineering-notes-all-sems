
### Java Database Connectivity (JDBC)

* JDBC is a Java API used for connecting programs written in Java to a wide range of databases. 
* JDBC provides methods for querying and updating data in databases. 
* It is a standard API for database-independent connectivity between the Java programming language and a wide range of databases. 
* JDBC is a key component of Enterprise Java Beans (EJB) and is used in the development of distributed, transactional, and secure enterprise applications. 
* JDBC is used for accessing and manipulating data in databases such as Oracle, MySQL, SQL Server, PostgreSQL, and Sybase. 
* It provides a set of classes and interfaces for establishing and managing connections. 
* JDBC also provides a set of classes and interfaces for creating and executing SQL statements. 
* JDBC provides support for transactions, stored procedures, and metadata. It also provides support for distributed transactions and two-phase commit.
