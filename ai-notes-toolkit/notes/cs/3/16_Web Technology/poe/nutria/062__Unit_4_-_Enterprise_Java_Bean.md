
## Unit 4 - Enterprise Java Bean

* Enterprise Java Beans (EJB) are server-side components that are used to build distributed enterprise applications.
* EJBs are used to encapsulate business logic, provide access to databases, and allow for the development of secure, transactional applications.
* EJBs are written in Java and run on an application server.
* An EJB application consists of one or more EJB components, which are deployed to an application server.
* EJBs can be packaged into Enterprise Archive (EAR) files, which can then be deployed to an application server.
* EJB components can be divided into three types: session beans, entity beans, and message-driven beans.
* Session beans are used to provide access to business logic and are typically stateless.
* Entity beans are used to represent persistent data and are typically stateful.
* Message-driven beans are used to process messages sent to an application server.
* EJBs can be accessed remotely through Remote Method Invocation (RMI) or Web Services.
* EJBs can be secured using authentication and authorization mechanisms.
* EJBs can be used to access databases, send emails, and access other services.
