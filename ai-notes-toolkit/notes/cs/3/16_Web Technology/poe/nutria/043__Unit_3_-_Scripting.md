

## Unit 3 - Scripting

1. Scripting is the process of writing scripts, which are small programs written in a programming language. 
2. Scripts are used to automate tasks, such as creating webpages, executing commands in a shell, or running programs on a computer.
3. Scripting languages are typically interpreted languages, meaning that the code is not compiled before being run.
4. Common scripting languages include JavaScript, Python, Ruby, and Bash.
5. Scripts can be used to create webpages, automate tasks, and create applications.
6. Scripts can also be used to create games, and to control robots and other hardware.
7. Writing scripts requires knowledge of the syntax and semantics of the scripting language being used.
8. Scripts can be created using text editors or integrated development environments (IDEs).
9. Scripts can also be debugged using a debugger, which is a tool that allows the programmer to step through the code and view the values of variables.
10. Scripts can be tested using unit tests, which are small programs that test the functionality of a script.
