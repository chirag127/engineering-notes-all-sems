
### Transaction Processing for the Notes of Unit 4 - Enterprise Java Bean in Web Technology

1. Transactions are units of work that are performed against a database.
2. A transaction is a logical unit of work that must either complete in its entirety or have no effect on the database.
3. Transaction processing systems (TPS) are computerized systems that manage the transactions that occur within an organization.
4. Enterprise Java Beans (EJBs) are server-side components used to build distributed enterprise applications.
5. An EJB transaction is a logical unit of work that can contain multiple method calls to different EJBs.
6. EJB transactions are managed by the application server and the underlying database.
7. A transaction manager is responsible for managing the transactions and ensuring that they are processed correctly.
8. The two main types of transactions are container-managed transactions (CMTs) and bean-managed transactions (BMTs).
9. CMTs are managed by the application server and the developer does not need to write any code to manage the transaction.
10. BMTs are managed by the developer and require the developer to write code to manage the transaction.
11. Transactions can be rolled back if an error occurs during processing.
12. The transaction manager is responsible for ensuring that the changes made by the transaction are either committed or rolled back.
