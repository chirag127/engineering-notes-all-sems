
### Stored Procedures for the Notes of Unit 4 - Enterprise Java Bean in Web Technology

1. Stored Procedures are pre-defined database objects that allow users to execute operations on a database.

2. They are commonly used to perform operations such as retrieving data from a database, inserting or updating data in a database, or deleting data from a database.

3. Enterprise Java Beans (EJBs) are a type of Java component that allows developers to create server-side applications.

4. EJBs are typically used to provide a layer of abstraction between the database and the application.

5. Stored procedures can be used in conjunction with EJBs to provide a more efficient way of performing operations on a database.

6. Stored procedures can be used to retrieve, insert, update, and delete data from a database.

7. Stored procedures also allow developers to write custom SQL queries that can be executed on the database.

8. Stored procedures can be used to create more secure applications by preventing SQL injection attacks.

9. Stored procedures can also be used to improve the performance of an application by reducing the number of database round trips required to perform an operation.
