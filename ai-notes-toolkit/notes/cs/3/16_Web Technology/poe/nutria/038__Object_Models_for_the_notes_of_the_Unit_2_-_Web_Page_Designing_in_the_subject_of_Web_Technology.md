
### Object Models for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

* An object model is a set of objects that are used to represent the data and the logic of a web page.
* The object model consists of objects such as HTML elements, text, images, and other media.
* It also includes objects such as forms, links, and navigation elements.
* Object models can be used to create complex web pages that are interactive and dynamic.
* Object models are used to create a consistent look and feel to a web page.
* Object models can also be used to create a consistent user experience across multiple web pages.
* Object models are also used to create a consistent user interface across multiple web pages.
* Object models can also be used to create a consistent user experience across multiple devices.
