
### Manipulating for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. Enterprise Java Beans (EJBs) are server-side components that enable developers to quickly build and deploy enterprise applications.
2. EJBs provide a number of services, such as transaction management, security, and resource pooling, that simplify the development of enterprise applications.
3. There are three types of EJBs: session beans, entity beans, and message-driven beans.
4. Session beans are used to implement business logic and provide services to clients. They are transient and can exist in either a stateful or stateless form.
5. Entity beans are used to represent persistent data in a database. They are persistent and can exist in either a container-managed or bean-managed form.
6. Message-driven beans are used to process asynchronous messages. They are transient and can exist in either a durable or non-durable form.
7. EJBs can be deployed in a variety of application servers, such as Apache Tomcat, JBoss, and WebLogic.
8. To deploy an EJB, the developer must create a deployment descriptor and package the EJB into an archive file.
9. EJBs can be accessed via a variety of APIs, such as the Java EE Connector Architecture (JCA) and the Java Messaging Service (JMS).
10. EJBs can be secured using a variety of techniques, such as declarative security and programmatic security.
