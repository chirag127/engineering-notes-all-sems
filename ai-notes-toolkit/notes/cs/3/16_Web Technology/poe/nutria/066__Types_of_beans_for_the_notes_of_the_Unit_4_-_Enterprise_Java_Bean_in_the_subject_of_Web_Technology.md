
### Types of Beans for the Notes of the Unit 4 - Enterprise Java Bean in the Subject of Web Technology

1. Session Beans: Session beans are used to represent a client's interaction with a server. They are short-lived and exist only for the duration of a client's interaction with the server.

2. Entity Beans: Entity beans are used to represent persistent data stored in a database. They are used to represent data that needs to be accessed and manipulated over a long period of time.

3. Message-Driven Beans: Message-driven beans are used to process messages sent to the server. They are used to process asynchronous messages sent to the server.

4. JavaBeans: JavaBeans are reusable components that can be used to represent data or logic. They are used to represent data and logic that can be used in multiple applications.
