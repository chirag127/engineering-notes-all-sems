
### Prepared Statements for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. Enterprise Java Beans (EJBs) are components that enable developers to build distributed applications.
2. EJBs are server-side components that are written in Java and can be deployed in a Java EE application server.
3. EJBs can be used to provide services such as database access, transaction processing, security, and messaging.
4. A PreparedStatement is an object that represents a pre-compiled SQL statement.
5. PreparedStatements can be used to execute parameterized SQL queries and provide better performance than standard SQL statements.
6. PreparedStatements are used in EJBs to execute SQL queries against a database.
7. PreparedStatements are created using the Connection object and can be used to execute queries, update data, and delete data.
8. PreparedStatements can also be used to execute stored procedures and functions.
9. PreparedStatements provide better performance than standard SQL statements because the SQL statement only needs to be parsed once and can be reused multiple times.
10. PreparedStatements also provide better security because the SQL statement is pre-compiled and the parameters are bound to the statement, preventing SQL injection attacks.
