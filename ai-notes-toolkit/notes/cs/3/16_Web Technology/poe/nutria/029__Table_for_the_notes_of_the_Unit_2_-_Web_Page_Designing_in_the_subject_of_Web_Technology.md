
### Table for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. Web page designing is the process of creating web pages that are visually appealing and easy to navigate.

2. It involves the use of HTML, CSS, and other web technologies to create web pages that are attractive and functional.

3. HTML is the language used to create the structure and content of a web page.

4. CSS is the language used to define the look and feel of a web page.

5. JavaScript is a scripting language used to add interactivity to a web page.

6. Web designers must have an understanding of the principles of design, such as typography, color theory, and layout.

7. Web designers must also have an understanding of user experience (UX) design in order to create web pages that are easy to use and intuitive for the user.

8. Responsive design is a technique used to create web pages that are optimized for different screen sizes and devices.

9. Accessibility is an important consideration for web designers, as web pages must be accessible to all users, regardless of their physical or mental abilities.
