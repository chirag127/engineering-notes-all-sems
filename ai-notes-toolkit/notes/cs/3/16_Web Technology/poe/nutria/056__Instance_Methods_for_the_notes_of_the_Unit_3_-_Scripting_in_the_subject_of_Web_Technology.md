
### Instance Methods

* `onload`: This is an event handler that is triggered when a web page is loaded. It can be used to execute code when the page is loaded, such as setting up initial values or loading data from the server.
* `onclick`: This is an event handler that is triggered when a user clicks on an element. It can be used to execute code when a user interacts with a page, such as submitting a form or clicking a button.
* `onchange`: This is an event handler that is triggered when a user changes the value of an element, such as a text field or a dropdown menu. It can be used to execute code when a user changes the value of an element, such as validating a form or updating data on the page.
* `onsubmit`: This is an event handler that is triggered when a user submits a form. It can be used to execute code when a user submits a form, such as validating the form data or sending the data to the server.
* `onmouseover`: This is an event handler that is triggered when a user moves their mouse over an element. It can be used to execute code when a user interacts with a page, such as displaying a tooltip or highlighting an element.
* `onmouseout`: This is an event handler that is triggered when a user moves their mouse away from an element. It can be used to execute code when a user interacts with a page, such as hiding a tooltip or un-highlighting an element.
