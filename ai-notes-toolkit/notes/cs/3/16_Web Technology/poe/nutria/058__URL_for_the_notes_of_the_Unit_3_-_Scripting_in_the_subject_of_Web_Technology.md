

### URL for the Notes of the Unit 3 - Scripting in the Subject of Web Technology

1. Scripting is a type of programming that is used to create dynamic web pages and applications.
It is used to add interactivity to webpages and to control the behaviour of web applications.

2. JavaScript is the most popular scripting language used on the web. It is a high-level, interpreted language that is used to create dynamic webpages and applications.

3. HTML is also a scripting language, although it is not as powerful as JavaScript. HTML is used to create the structure of a webpage.

4. CSS is a style sheet language used to control the appearance of a webpage. It is used to style HTML elements and to create the look and feel of a webpage.

5. The W3C (World Wide Web Consortium) is the organization responsible for setting standards for web technologies, including scripting languages.

6. There are many resources available online for learning scripting languages, including tutorials, books, and online courses.
