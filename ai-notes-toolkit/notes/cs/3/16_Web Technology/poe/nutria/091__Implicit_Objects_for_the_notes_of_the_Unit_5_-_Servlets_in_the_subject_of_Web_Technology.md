
### Implicit Objects for the notes of the Unit 5 - Servlets in the subject of Web Technology

* **Request**: The request object represents the request from the client to the server. It is an instance of the javax.servlet.ServletRequest interface. It contains information about the request such as parameters, headers, and the body of the request.

* **Response**: The response object represents the response from the server to the client. It is an instance of the javax.servlet.ServletResponse interface. It contains information about the response such as the status code, headers, and the body of the response.

* **Session**: The session object represents a session between the client and the server. It is an instance of the javax.servlet.http.HttpSession interface. It contains information about the session such as the session ID, the creation time, and the last accessed time.

* **Application**: The application object represents the application context for the servlet. It is an instance of the javax.servlet.ServletContext interface. It contains information about the application such as the context path, the servlet mappings, and the initialization parameters.

* **Out**: The out object represents the output stream to the client. It is an instance of the javax.servlet.ServletOutputStream interface. It is used to write data to the response body.

* **Config**: The config object represents the configuration of the servlet. It is an instance of the javax.servlet.ServletConfig interface. It contains information about the servlet such as the servlet name, the servlet context, and the initialization parameters.
