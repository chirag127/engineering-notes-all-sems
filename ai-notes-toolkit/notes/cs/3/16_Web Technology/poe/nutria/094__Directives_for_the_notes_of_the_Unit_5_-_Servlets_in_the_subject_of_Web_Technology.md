
### Directives for the Notes of the Unit 5 - Servlets in the Subject of Web Technology

1. Servlets are Java programs that run on a web server and generate dynamic web content.
2. Servlets are used to create and manage web applications.
3. Servlets are written in Java and must be compiled before they can be run.
4. Servlets are deployed in a web container, which is a component of a web server.
5. Servlets have access to the Java EE APIs, which provide access to databases, messaging systems, and other services.
6. Servlets can respond to requests from clients and generate dynamic content based on the request.
7. Servlets can use the request and response objects to communicate with the client.
8. Servlets can use session objects to store information about a user's session.
9. Servlets can use filters to pre-process requests and post-process responses.
10. Servlets can use listeners to respond to events such as session creation and destruction.
