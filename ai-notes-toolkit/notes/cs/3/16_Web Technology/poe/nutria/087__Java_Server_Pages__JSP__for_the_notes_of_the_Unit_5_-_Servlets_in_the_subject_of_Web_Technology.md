
### Java Server Pages (JSP) 

* JSP is a Java-based web technology used to create dynamic web pages. 
* JSPs are compiled into Java servlets and run on a web server. 
* JSPs can be used to access databases, create dynamic web pages, and process user input. 
* JSPs are written in HTML and can include Java code, which is executed on the server.
* JSPs can also be used to include content from other web pages, such as images, video, and audio. 
* JSPs are commonly used to create web applications and web services. 
* JSPs are also used to create interactive web pages and web applications.
