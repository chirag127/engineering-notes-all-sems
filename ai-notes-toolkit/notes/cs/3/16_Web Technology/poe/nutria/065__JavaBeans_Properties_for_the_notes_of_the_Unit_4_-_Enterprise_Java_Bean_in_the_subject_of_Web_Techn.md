
### JavaBeans Properties for the Notes of the Unit 4 - Enterprise Java Bean in the Subject of Web Technology

1. JavaBeans are reusable software components that can be used to create sophisticated applications.
2. A JavaBean must implement the JavaBeans API and must have a no-arg constructor.
3. JavaBeans have properties that can be set and retrieved.
4. JavaBeans can be used to create distributed applications by using the Java Remote Method Invocation (RMI) technology.
5. Enterprise JavaBeans (EJBs) are server-side components that are used to build distributed enterprise applications.
6. EJBs are written in Java and are managed by an EJB container.
7. An EJB container provides services such as security, transaction management, and resource pooling.
8. EJBs can be used to create distributed applications by using the Java Message Service (JMS).
9. EJBs are divided into two types: session beans and entity beans.
10. Session beans are used to provide services to clients, while entity beans are used to store data in a database.
