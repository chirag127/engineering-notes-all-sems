
### Methods & Classes for the notes of the Unit 1 - Introduction in the subject of Web Technology

* Methods are a set of instructions that are used to perform a specific task. A method is a function that is associated with a class and can be called to perform a specific task. 
* Classes are templates that are used to create objects. Objects are instances of classes that contain data and methods. 
* In web technology, classes are used to define the structure of a web page. They are also used to store data and methods that can be used to manipulate the data. 
* Classes can also be used to create components that can be reused in different parts of a web page. 
* Object-oriented programming (OOP) is a programming paradigm that is based on the concept of objects. It is used to create complex web applications. OOP is based on the idea of creating objects that contain data and methods that can be used to manipulate the data.
