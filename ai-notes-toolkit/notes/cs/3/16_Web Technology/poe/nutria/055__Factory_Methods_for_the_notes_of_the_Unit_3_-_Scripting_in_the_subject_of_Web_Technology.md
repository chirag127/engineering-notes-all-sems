
### Factory Methods 

* Factory methods are functions or methods that create objects. They are used to create an object of a specific type.
* Factory methods are commonly used in object-oriented programming and are used to create objects of a specific type.
* The factory method pattern is a way of creating objects without having to specify the exact class of the object that will be created. 
* In this pattern, a factory class has a method that returns a new instance of a class, based on the parameters passed in.
* Factory methods can also be used to create objects that have different implementations depending on the parameters passed in. 
* Factory methods are often used in web development, for example to create database connections, or to create DOM elements.
* Factory methods can also be used to create objects from a configuration file, such as a JSON file.
* Factory methods can also be used to create objects from other objects, such as by cloning the existing object.
