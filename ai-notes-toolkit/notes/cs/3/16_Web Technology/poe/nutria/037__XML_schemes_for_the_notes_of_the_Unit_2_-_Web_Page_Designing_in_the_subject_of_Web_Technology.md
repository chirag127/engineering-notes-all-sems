
### XML Schemes for Unit 2 - Web Page Designing

1. XML stands for **eXtensible Markup Language** and is a markup language used to store and transport data.
2. XML documents are plain text documents that contain tags that are used to define the structure and content of the document.
3. XML documents are self-describing and are written in a hierarchical structure.
4. XML documents can be validated against a schema to ensure that the document is well-formed and contains the correct data.
5. XML is used to create web pages and to store data for web applications.
6. XML can be used to create and store data in a variety of different formats, such as HTML, XHTML, SVG, and MathML.
7. XML can be used to create a data model for a website, including the structure of the website, the content, and the relationships between the content.
8. XML can be used to store data in a structured way, making it easier to search and manipulate the data.
9. XML can be used to create a web service that can be used to access and manipulate the data.
10. XML is often used in combination with other technologies, such as XSLT, to create dynamic web pages.
