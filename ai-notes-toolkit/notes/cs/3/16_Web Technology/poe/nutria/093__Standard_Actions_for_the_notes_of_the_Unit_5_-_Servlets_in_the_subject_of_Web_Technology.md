
### Standard Actions for the Notes of Unit 5 - Servlets in Web Technology

1. Servlets are Java classes that are used to extend the capabilities of servers that host applications accessed by means of a request-response programming model.
2. Servlets can be used to handle requests for dynamic content, such as HTML pages and XML documents.
3. Servlets are used to process client requests, generate dynamic content, manage sessions, and provide access to databases and other resources.
4. A servlet is deployed in a servlet container, which is a part of a web server.
5. Servlets are used to process requests and generate responses.
6. The servlet container is responsible for managing the lifecycle of servlets, mapping requests to servlets, and ensuring that servlets are properly initialized and destroyed.
7. The servlet container also provides services such as request dispatching, security, and session management.
8. Servlets can be used to create web applications that are portable across platforms and servers.
