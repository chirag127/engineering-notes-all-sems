

### List for the Notes of Unit 2 - Web Page Designing in Web Technology

1. Web page designing is the process of creating a website that is visually appealing and user-friendly.
2. Web page design involves the use of HTML, CSS, and JavaScript to create a website.
3. HTML is used to structure the content of a website, while CSS is used to style the content.
4. JavaScript is used to add interactivity to a website, such as creating forms, drop-down menus, and animations.
5. Responsive design is a technique used to make a website look good on any device, such as a desktop computer, tablet, or smartphone.
6. Accessibility is an important part of web page design, as it ensures that people with disabilities can access and use the website.
7. Search engine optimization (SEO) is a technique used to make a website more visible in search engine results.
8. Web page design also involves the use of graphics, such as logos and images, to make a website more visually appealing.
9. Usability testing is a technique used to evaluate a website and identify any areas that need improvement.
