
### Forms for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology
1. Forms are a way of collecting user input on a web page. They can be used to capture data, submit queries, and perform other tasks.
2. Forms are composed of HTML elements, such as text fields, radio buttons, checkboxes, and select menus.
3. Forms can be used to collect data from the user, such as name, address, email, phone number, etc.
4. Forms can also be used to submit queries to the server, such as search queries, login information, and other requests.
5. Forms can also be used to perform tasks, such as submitting a form to send an email, or submitting a form to add an item to a shopping cart.
6. Forms are composed of HTML elements, such as labels, text fields, radio buttons, checkboxes, select menus, and submit buttons.
7. Form elements can be styled with CSS to create a visually appealing form.
8. Forms can be validated with JavaScript to ensure that the user has entered valid data.
9. Forms can be processed with server-side language, such as PHP, to store the data in a database or to perform other tasks.
