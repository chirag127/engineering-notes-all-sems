
### XML for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. XML stands for **Extensible Markup Language**, and is used to create documents with a structured format.
2. XML documents are comprised of elements, which have both a start and an end tag.
3. XML documents can also contain attributes, which are used to provide additional information about the elements.
4. XML documents must also include a root element, which encloses all other elements.
5. XML documents must also be well-formed, meaning they must follow a set of rules that dictate how the elements are arranged.
6. XML documents can be used to create web pages, as well as other types of documents.
7. XML documents can be validated against a Document Type Definition (DTD) or an XML Schema to ensure that they are valid.
8. XML documents can also be transformed into other formats, such as HTML, using an XSLT stylesheet.
