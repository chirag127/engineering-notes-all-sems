
### Connecting to Internet for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. The internet is a global network of computers that allows users to access and share information.
2. Connecting to the internet requires a device with an internet connection, such as a laptop, desktop computer, or mobile device.
3. To access the internet, users must have an internet service provider (ISP) that provides a connection.
4. Web technology is the use of the internet and related technologies to access and share information on the web.
5. Web browsers are used to access websites and web applications.
6. Web servers are used to host websites and web applications.
7. Web protocols are used to communicate between web browsers and web servers.
8. HTML (HyperText Markup Language) is used to structure web content.
9. CSS (Cascading Style Sheets) is used to style web content.
10. JavaScript is used to create interactive web content.
