
## Unit 2 - Web Page Designing

1. Web page design refers to the process of creating a website, which involves planning, creating content, and coding. 
2. Web page design is an important part of web development and involves the use of HTML, CSS, and JavaScript to create a visually appealing and functional website.
3. HTML is the language used to create the structure of a web page, while CSS is used to style the page. JavaScript can be used to add interactivity to the page.
4. The design of a web page should be user-friendly and accessible, meaning that it is easy to use and understand for all users.
5. Good web page design should be responsive, meaning that it will adjust to different screen sizes and devices.
6. Web page design should also be optimized for search engines, meaning that it should include keywords and meta tags that will help the page rank higher in search engine results.
7. Additionally, web page design should be optimized for speed, meaning that it should load quickly and efficiently. 
8. Web page design should also be optimized for accessibility, meaning that it should be usable by people with disabilities.
9. Web page design should also be optimized for security, meaning that it should use secure protocols and encryption to protect user data.
