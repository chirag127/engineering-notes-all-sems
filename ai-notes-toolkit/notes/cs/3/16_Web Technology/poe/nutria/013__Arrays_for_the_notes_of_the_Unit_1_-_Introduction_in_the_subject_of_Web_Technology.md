
### Arrays for the Notes of Unit 1 - Introduction in Web Technology

1. An array is a data structure used to store a collection of items in a single variable. 
2. Arrays are commonly used to store a list of items, such as a list of products, a list of user names, or a list of webpages. 
3. Arrays are an efficient way to store data and can be used to store data of any type, including strings, numbers, and objects. 
4. Arrays can be created in JavaScript using the `Array` constructor or the array literal syntax. 
5. Arrays are indexed, meaning that each item in the array is assigned a numerical index. 
6. Arrays can be manipulated using built-in methods such as `push()`, `pop()`, `shift()`, and `unshift()`. 
7. Arrays can be used to store complex data structures, such as a list of objects. 
8. Arrays can be used to create powerful search and filter functions. 
9. Arrays can also be used to create dynamic webpages, such as forms and tables.
