
### Unit 3 - Scripting in Web Technology

1. Scripting is a type of programming language used to create dynamic web applications. 
2. It is used to automate tasks, create interactive webpages and control user input. 
3. Scripting languages are typically lightweight and easier to learn than other programming languages. 
4. Common scripting languages include JavaScript, PHP, Ruby, Python, and Perl. 
5. Scripting languages are used to create dynamic webpages, which can respond to user input and interact with databases. 
6. Scripts can be embedded in HTML documents, allowing them to be executed when the document is loaded. 
7. Scripts can also be used to create client-side applications, such as web forms and games. 
8. Scripting languages are also used to create server-side applications, such as web services and APIs. 
9. Scripts can be used to automate tasks, such as sending emails or generating reports. 
10. Scripts can also be used to create custom interfaces, such as chatbots and voice-activated assistants.
