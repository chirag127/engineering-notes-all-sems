### Joining for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. Enterprise JavaBeans (EJB) is a server-side software component architecture for modular construction of enterprise applications.
2. EJB supports transactions, security, scalability, concurrency, and other services.
3. EJB includes two main types of beans:
 - Session beans: Used to implement business logic.
 - Message-driven beans: Used to process messages asynchronously.
4. The EJB container provides resources and services to the enterprise beans. The beans must be deployed into the EJB container.
5. The deployment descriptor (ejb-jar.xml file) contains the metadata to describe the enterprise beans and its requirements. It is used by the EJB container to manage the beans.
6. Some key services provided by the EJB container are:
 - Lifecycle management: Creating, removing and pooling of beans.
 - Transaction management: Demarcating transactions boundaries.
 - Security: Authenticating and authorizing access to beans.
 - Remote access: Exposing business interfaces to remote clients.
 - Persistence: Integrating with data sources and providing object-relational mapping.
