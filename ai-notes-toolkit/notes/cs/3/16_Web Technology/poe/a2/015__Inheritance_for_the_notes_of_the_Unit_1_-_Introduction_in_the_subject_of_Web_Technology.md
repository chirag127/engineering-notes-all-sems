### Inheritance for the notes of the Unit 1 - Introduction in the subject of Web Technology.

1. Inheritance is a mechanism in which one class acquires the properties and behaviors of another class. The class that inherits the properties and behaviors of another class is called a child class or a subclass and the class whose properties and behaviors are inherited is called a parent class or a superclass.
2. Inheritance is used for code reusability. The properties and behaviors of a superclass can be reused by its subclasses. This removes redundant code and makes the program more efficient.
3. The general syntax for inheritance is:
class subclass_name(superclass_name):
    pass
4. The child class inherits all the methods and attributes of the parent class. It can also have its own methods and attributes in addition to the inherited ones.
5. If the child class defines a method with the same name as in parent class, it will override the method in the parent class. This is known as Method Overriding.
6. Use the super() function to refer to the parent class and call its attributes and methods.
