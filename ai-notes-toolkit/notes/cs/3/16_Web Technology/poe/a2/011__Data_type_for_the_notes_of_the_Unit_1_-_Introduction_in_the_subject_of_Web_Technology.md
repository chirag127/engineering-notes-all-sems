### Data type for the notes of the Unit 1 - Introduction in the subject of Web Technology.

1. Text - Used to represent strings and characters like alphabets, numbers, symbols, etc. Examples: String to store name, etc.
2. Numeric - Used to represent numbers. Examples: Integer to store age, Float to store percentages, etc.
3. Boolean - Used to represent logical entities and can have only two possible values: true or false. Examples: To represent conditions like user is logged in or not.
4. Object - Used to represent more complex data structures. Examples: To store collection of data, combinations of primitives data, etc.
5. Array - A type of object which is ordered and integer-indexed. Examples: To store list of names, list of ages, etc.
6. Date - Used to represent dates and times. Examples: To store creation date, modified date, etc.

The data types are used to define the type of value that can be assigned to a variable to make the data more predictable and easier to handle. The appropriate data type should be selected based on the type of data that needs to be stored.
