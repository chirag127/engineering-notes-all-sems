### XML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML stands for eXtensible Markup Language. It is a markup language much like HTML used to store and transport data.
2. XML was designed to carry data, not to display data like HTML.
3. XML tags are not predefined like HTML tags. You can define your own tags in XML.
4. XML documents have a tree structure with a root element and elements are nested within each other.
5. XML tags use < and > symbols. They always come in pairs - an opening tag and a closing tag.
6. XML tags have attributes just like HTML tags. Attributes are written within the opening tag.
7. XML documents can be validated against a set of rules called DTD or an XML Schema. This ensures the XML document is structured correctly.
8. XML is widely used to share data over the internet as it makes the data easily understandable to both humans and machines.
9. Some applications that use XML are RSS feeds, SOAP, SVG etc.
