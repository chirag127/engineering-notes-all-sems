### Implicit Objects

- request object - It is used to get the data sent by the client through HTTP request. It contains data about the request such as header, parameters, etc.
- response object - It is used to send the response back to the client. It is used to set headers, status code, and send data or html content.
- out object - It is used to send output to the client. It can be used instead of response object for sending output.
- session object - It is used to maintain the state of a user across multiple requests. It stores information specific to a user.
- application object - It is used to share data across multiple users. It stores information specific to the web application and is accessible to all users.
- pageContext object - It provides access to various other implicit objects. It encapsulates request, response, session, and application objects.
- config object - It is used to get the initialization parameters from the web application deployment descriptor (web.xml).
