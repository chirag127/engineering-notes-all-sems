### Arrays for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. An array is a data structure that stores a collection of elements of the same type. It is a linear collection of elements where each element can be accessed using its index.
2. The index is a number associated with each element in the array. It starts from 0 and goes up to n-1, where n is the size of the array.
3. Arrays allow efficient access to any element since the index of each element can be computed in constant time. However, inserting and deleting elements is inefficient as it requires re-indexing of all subsequent elements.
4. Arrays can be Single Dimensional Arrays (1D arrays) where elements are arranged in a linear fashion or Multi Dimensional Arrays (2D, 3D arrays) where elements are arranged in a matrix or a cube respectively.
5. Arrays can be used to implement other data structures like stacks and queues which restrict the type of operations that can be performed on them and allow efficient implementations.
