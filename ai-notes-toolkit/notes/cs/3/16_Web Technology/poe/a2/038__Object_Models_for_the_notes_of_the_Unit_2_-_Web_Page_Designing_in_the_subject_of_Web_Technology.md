### Object Models for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. DOM (Document Object Model):
- It is a programming interface for HTML and XML documents.
- It represents the page so that programs can change the document structure, style and content.
- The DOM is constructed as a tree of nodes:
    - The root node is the topmost element in the page
    - Each element, piece of text, etc is a node with children and siblings
- Languages like JavaScript can access and update each object in this model, enabling dynamic behavior and interactivity.

2. CSSOM (CSS Object Model):
- It is an interface where a CSS style sheet is represented as objects and properties.
- The CSSOM allows JavaScript to access and manipulate properties and rules within CSS to enable dynamic styling.
- It enables manipulation of styles from JS for reactive UI experiences without needing to alter the CSS file directly.

3. Render Tree:
- The render tree is generated from the DOM and CSSOM.
- It is used to calculate the final output representation of the page.
- The render tree includes the visual styles of each node from the CSSOM.
- The render tree is what the browser uses to construct the actual pixels on the screen.
