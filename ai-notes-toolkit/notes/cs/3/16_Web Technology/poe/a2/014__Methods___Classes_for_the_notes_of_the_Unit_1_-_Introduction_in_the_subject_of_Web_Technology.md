### Methods & Classes for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Methods:
- A method is a block of code which only runs when it is called.
- You can pass data, known as parameters, into a method.
- Methods allow you to organize your code into blocks that perform specific tasks.

2. Classes:
- A class is a blueprint for creating objects.
- Objects get their behaviors from classes and have attributes that are defined in the class.
- Defining a class allows you to create multiple objects that are of the same type.
- The class definition includes attributes, which describe the object, and methods, which are functions that operate on the attributes.

By using methods and classes, we can logically group the codes, simplify the codes, prevent repetition and make the codes more efficient and easier to understand and manage. Methods and classes form the basis for Object Oriented Programming.
