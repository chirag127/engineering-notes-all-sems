### Java Applet for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Java Applet is a small application written in Java programming language that can be embedded into HTML pages.
2. Java applets can perform interactive multimedia presentations, demonstrations and simulations right inside the web browser.
3. Java applets have full multimedia capability and run on any platform without the need for browser plug-ins.
4. The <applet> tag is used to embed a Java applet into an HTML page. Attributes used in the <applet> tag specify the applet size, archive file, code file, etc.
5. The archive attribute specifies a JAR file containing the applet class files and any other resource files. The code attribute specifies the name of the primary applet class containing the applet's starting point.
6. The applet tag may include <param> tags to pass parameters to the applet. The applet can access these parameters via the getParameter() method.
7. Since Java applets have access to powerful APIs, execution of untrusted applets can pose security risks. Hence, applets have strict security constraints - they cannot access local resources, communicate with hosts other than the one that served them, etc.
8. The Java Plug-in software allows Java applets to run in popular browsers on supported platforms. The availability of plug-ins, changing browsers and security prompts can affect the user experience of applets. Hence, applets are not as popular today as they used to be.
