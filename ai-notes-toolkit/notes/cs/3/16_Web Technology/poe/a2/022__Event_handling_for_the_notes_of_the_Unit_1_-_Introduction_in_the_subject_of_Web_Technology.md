### Event handling for the notes of the Unit 1 - Introduction in the subject of Web Technology.

1. Events: Actions or occurrences that happen in the system you are programming, which the system tells you about so you can respond to them in some way if desired.
2. Event listeners: The mechanism by which code can detect and respond to events. You register event listeners with the system, and they are triggered when events occur.
3. Handling events: The process of writing code that will be executed in response to an event. This is where you define what should happen when a specific event is detected.
4. Common web events:
 - Load - the browser has finished loading the page
 - Click - the user clicks on something
 - Input - the user enters data or makes a change to form input
 - Scroll - the user scrolls
 - Resize - the browser window is resized
 - Keypress - a keyboard key is pressed

You would attach event listeners for these events to DOM elements using JavaScript and then write handling code that would execute in response to the events as necessary. Event handling allows web pages to be interactive and dynamic.
