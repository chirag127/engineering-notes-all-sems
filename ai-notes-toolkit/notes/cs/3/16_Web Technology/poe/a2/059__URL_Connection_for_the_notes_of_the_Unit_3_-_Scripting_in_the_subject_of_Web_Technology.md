### URL Connection for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. URL stands for Uniform Resource Locator. It is the address of a resource on the Internet.
2. The basic structure of a URL consists of:
   - Scheme - Defines the protocol to use, e.g. http, https, ftp
   - Host - Domain name or IP address of the server
   - Port - Optional, specifies the port number to use (if non-standard)
   - Path - Specifies the path to the resource
   - Query - Optional, contains query parameters
   - Fragment - Optional, specifies a fragment or anchor within the resource
3. To connect to a URL in a script, use the open() function of the URL object.
4. The open() function takes two parameters:
   - The URL to open
   - Optional, a string specifying the mode (read, write, append, etc.)
5. After opening the connection, you can:
   - Read data from the URL using the read() method
   - Access the URL and query parameters using the URL object properties
6. It is important to always close the connection when done using the close() method to free up system resources.
