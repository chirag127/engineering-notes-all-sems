### Stored Procedures for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. Stored procedures are precompiled database queries that are stored in the database.
2. They allow you to encapsulate frequently used queries and reuse them.
3. Stored procedures can accept inputs (IN parameters) and return multiple values (OUT parameters) and return status.
4. Using stored procedures can reduce network traffic by limiting the data transmitted between the application and the database.
5. Stored procedures provide better security as the actual SQL statements do not have to be sent to the database. The calling application only sends the name of the stored procedure and the parameters.
6. Stored procedures can be used for centralizing database access logic and avoiding duplication of code in multiple application modules.
7. Performance can be improved as the database can optimize and cache the stored procedures.
8. Complex logic and intricate SQL queries can be encapsulated into stored procedures that are easy to maintain and reuse.
