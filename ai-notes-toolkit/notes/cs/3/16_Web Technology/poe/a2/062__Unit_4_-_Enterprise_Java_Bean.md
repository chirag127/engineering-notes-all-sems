## Unit 4 - Enterprise Java Bean

1. Enterprise JavaBeans (EJB) is a development architecture for building highly scalable and distributed enterprise applications using Java EE technology.
2. EJB supports features such as container management, transaction management, security authorization, remoting, persistence, concurrency, and more.
3. The EJB architecture has two main components:

- Session Beans: Used for task processing and business logic. There are two types: Stateless and Stateful.
- Message-Driven Beans: Used to process asynchronous messages.

4. An EJB container provides run-time services for Enterprise Beans and manages their lifecycle. The container injects resources and enforces security.
5. Key benefits of EJB include:

- Reduced development time through the use of services provided by the container.
- Improved performance through the use of features such as caching and connection pooling.
- Increased maintainability through separation of application logic and system services.
- Improved scalability and reliability through distribution and failover capabilities.
- Enforced security through EJB declarative authorization.

6. EJB can be considered as an evolution of older technologies such as COM+/DCOM and CORBA. However, EJB is tailored to the Java EE environment and utilizes key Java technologies.
