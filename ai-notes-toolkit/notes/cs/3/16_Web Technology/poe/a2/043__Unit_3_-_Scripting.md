## Unit 3 - Scripting

1. Scripting is a way to automate tasks on a computer. Scripts are programs that are interpreted and executed by another program.
2. Scripting languages are easier to learn and use as compared to conventional programming languages. Some popular scripting languages are:
    - JavaScript - Used to create interactive effects within web pages
    - Python - General purpose language used for both scripting and application development
    - PHP - Server side scripting language mainly used for web development
    - Ruby - Scripting language designed to be simple and easy to read
3. Some common uses of scripting are:
    - To automate repetitive tasks like data processing or backups
    - To add functionality to applications
    - To create web pages and applications
    - To perform system administration tasks
4. To write a script, you first need to choose a scripting language that is suitable for your task. Then you define the steps to be performed in a logical sequence in the form of commands and instructions which can be understood by the interpreter. The script is then executed by the interpreter which carries out the defined steps and displays the output.
