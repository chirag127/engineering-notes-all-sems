### Documents for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Introduction to Scripting
- Scripting languages: Scripting languages are programming languages that are embedded into web pages and are processed by the client web browser. Example: JavaScript, VBScript.
- Purposes of scripting in web pages: Add interactivity, Validate forms, Dynamic HTML ( manipulate styles and content), Respond to user events (mouse clicks, key presses), Send and retrieve cookies, Request data from server.

2. The JavaScript Language
- Embed JavaScript code in HTML pages using <script> tag
- JavaScript runs in the client browser
- Object-based scripting language: Uses objects and methods to perform tasks
- Example of JavaScript code: Changing image on mouse click, Validating web form fields, Displaying pop-up messages

3. The Document Object Model (DOM)
- The DOM is a representation of an HTML document as a tree of nodes
- Scripting languages interact with the DOM to access and modify web page content
- Methods to access and modify DOM nodes: getElementById(), getElementsByTagName(), parentNode, childNodes, nextSibling, appendChild() etc.
- Example: Changing style attributes of DOM elements using JavaScript

4. JavaScript Events
- JavaScript programmes react to events such as web page loading, button clicking, mouse moving etc.
- Use HTML event attributes to invoke JavaScript code for an event
- Example: JavaScript code to display an alert when a button is clicked
