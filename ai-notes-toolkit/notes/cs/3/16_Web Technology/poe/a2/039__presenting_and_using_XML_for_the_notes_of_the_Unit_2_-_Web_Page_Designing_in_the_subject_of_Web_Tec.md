### Presenting and using XML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML stands for Extensible Markup Language. It is a markup language designed to store and transport data.
2. XML tags are not predefined like HTML tags. XML tags are user-defined based on the data. For example, to store details of a book, tags like `<book>`, `<title>`, `<author>` etc. can be defined.
3. XML documents must have a root element which wraps the entire document. For example, `<root>...</root>`
4. XML tags are case-sensitive. `<Book>` and `<book>` denote different elements.
5. XML tags can be nested. For example, `<book><title>...</title></book>`
6. XML documents must be well-formed i.e. they must follow rules such as every opening tag must have a closing tag, tags must be properly nested etc.
7. XML is a platform independent and programming language independent standard. The data in XML can be processed using any programming language.
8. XML is widely used to store and transport data over the internet as it is human readable and machine understandable.
