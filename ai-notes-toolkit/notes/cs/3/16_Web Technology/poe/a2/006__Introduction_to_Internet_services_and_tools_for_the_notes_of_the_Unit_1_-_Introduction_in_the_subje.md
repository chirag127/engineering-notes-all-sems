### Introduction to Internet services and tools for the notes of the Unit 1 - Introduction in the subject of Web Technology

1.  World Wide Web: The World Wide Web (www) refers to the massive repository of interlinked web pages that can be accessed via the Internet. The web pages are accessed using a web browser and are linked to each other using hyperlinks. The World Wide Web is one of the services available on the Internet.
2.  Web Browser: A web browser is a software application that is used to access and display web pages. Some popular web browsers are Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc. The web browser retrieves the web pages from web servers and displays them on the client system.
3.  Web Server: A web server is a software program that delivers web pages to the web browsers. It is a computer that is connected to the Internet and has the server software installed. Whenever a web browser requests for a web page, the web server locates the page and sends it to the browser so that it can be displayed. Example: Apache, Nginx, IIS, etc.
4.  Internet: The Internet refers to the massive network of networks that connects millions of computers and servers from across the globe. It is a global system of interconnected computer networks that use a common set of protocols to communicate with each other and exchange data, messages, and other resources. The Internet is an infrastructure that provides various services such as email, web browsing, streaming media, etc.
