### I/O for the notes of the Unit 1 - Introduction

1. Input: Input refers to the data entered into a system. In web technology, input is the data entered by the user into web forms, search boxes, etc. The input is then processed by the web application to generate the required output.

2. Output: Output refers to the data/results produced by a system after processing the input. In web technology, the output could be a web page, a file download, displaying an image/video, sending an email, etc. The output is presented to the user in a format that is usable to them.

3. HTTP: Hypertext Transfer Protocol is the set of rules for transferring web pages on the World Wide Web. It defines how messages should be formatted and transmitted between web servers and browsers. HTTP determines the verbs to use, states the action to be taken for different responses, etc. It is a core protocol of the web.

4. HTML: Hypertext Markup Language is the main markup language for creating web pages and web applications. It uses a series of elements consisting of tags inside angle brackets to structure and give meaning to the web content. HTML is used to display images, format text, create links, etc. on web pages. It forms the structure of the web.

5. URL: Uniform Resource Locator is a web address that defines the location of a resource on the web and the mechanism to access it. A URL contains the protocol to use, domain name, path, filename, and parameters to access the required resource. URLs are used to access web pages, images, videos, etc. on the web.
