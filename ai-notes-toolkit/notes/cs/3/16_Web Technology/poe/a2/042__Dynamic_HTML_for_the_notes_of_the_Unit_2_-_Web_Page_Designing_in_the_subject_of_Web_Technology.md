### Dynamic HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Dynamic HTML or DHTML is a collection of technologies used together to create interactive and animated web pages by using a combination of HTML, CSS, and JavaScript.
2. It allows web pages to be dynamic and interactive instead of static.
3. Elements can be hidden, shown, moved, or modified on a web page without reloading the page. This is possible due to the DOM (Document Object Model) which treats the HTML document as objects that can be manipulated.
4. JavaScript is used to access and modify the DOM tree which updates the web page. This happens quickly giving an illusion of a dynamic and interactive web page.
5. The onmouseover and onmouseout events are commonly used to create rollover effects and animate objects on the web page.
6. DHTML allows web pages to react to user input without sending requests to the server, makes web pages more responsive and interactive, and enables features like drag and drop.
7. However, it has compatibility issues with different browsers, increased webpage complexity, and security concerns. The dynamic features may not work if JavaScript is disabled.
