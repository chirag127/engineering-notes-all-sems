### Introduction and Web Development Strategies

1. Introduction
- Web technology refers to the languages and tools used to create web pages and web applications.
- The key languages of web technology are HTML, CSS, and JavaScript.
- Web development is the process of creating web applications and websites using web technologies.

2. Web Development Strategies
- Static website: Contains fixed web pages with no dynamic functionality. Created using HTML and CSS.
- Dynamic website: Contains web pages generated on the fly using a server-side language like PHP, Ruby, or Python along with HTML and CSS.
- Single-page application: Behaves like a desktop app and only loads a single HTML page. Uses JavaScript to dynamically update that page as the user interacts with the app.
- Progressive web app: Web app that can be installed and used like a native mobile app. Utilizes service workers to work offline and receive push notifications.
