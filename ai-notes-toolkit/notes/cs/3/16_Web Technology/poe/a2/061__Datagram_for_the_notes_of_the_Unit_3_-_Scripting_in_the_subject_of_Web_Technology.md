### Datagram for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. JavaScript:
- JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages.
- Used to create interactive effects within web pages and applications.
- Can update and change both HTML and CSS.
- Interactive effects include menus, pop-up windows, games, animations, validations, and more.

2. How JavaScript Works:
- Embedded in HTML pages and interpreted by the browser.
- The browser parses the JavaScript code and executes the instructions.
- The result is a dynamic, interactive web page.
- JavaScript code can react to user events like clicks, form input, etc. and perform updates accordingly.

3. JavaScript Output:
- JavaScript can output data to the:
-- Web page - by writing to an HTML element, changing content or attributes.
-- Browser console - for testing and debugging purposes.
-- Pop-up alert box - to display messages to the user.

4. JavaScript Data Types:
- String - for text data
- Number - for numeric data
- Boolean - for true/false logical data
- Object - for more complex data structures
- Array - a type of object for ordered lists
- Null - for unknown values
- Undefined - for unassigned values
