### Package and Interface for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Package: A package is a grouping of related classes, interfaces, and sub-packages. It is a way to organize and reuse code modules.

2. Interface: An interface is a contract between a class and the outside world. It defines the methods, constants, and properties that a class must have to implement that interface. It allows a class to implement multiple interfaces and inherit from only one class.

3. Benefits of Packages and Interfaces:

- Packages avoid naming conflicts between classes with the same name.
- Packages make it easier to locate and use classes.
- Interfaces allow a class to implement multiple interfaces and support polymorphism.
- Interfaces decouple implementation from interfaces allowing flexibility.
