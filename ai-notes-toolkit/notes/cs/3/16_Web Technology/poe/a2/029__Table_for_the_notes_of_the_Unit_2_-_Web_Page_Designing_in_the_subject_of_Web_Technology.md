### Table for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. HTML: Hypertext Markup Language is the main markup language used to create web pages. It uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page and its content.

2. HTML Elements: The components of an HTML document are called HTML elements. They are represented using tags. The opening tag contains the element name surrounded by < and >. The closing tag contains the element name preceded by </. For example: <html> is the opening tag and </html> is the closing tag for the HTML element.

3. HTML Attributes: HTML elements can have attributes which provide additional information about the element. They are always specified in the opening tag. For example: <img src="image.png">. Here, src is the attribute which specifies the source of the image.

4. HTML Versions: There are several versions of HTML: HTML 2, HTML 3, HTML 4, XHTML, HTML5. HTML5 is the latest version with new features like video, audio, canvas, etc.

5. CSS: Cascading Style Sheets is used to style the HTML elements. It specifies properties such as font, color, size, background, spacing, etc. to decorate web pages. There are three ways to add CSS to HTML: Inline Styling, Embedded Style Sheets and External Style Sheets.
