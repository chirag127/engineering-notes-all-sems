### String handling for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Strings: Strings are sequences of characters. They are represented using double quotes ("abc") or single quotes ('abc').
2. String length: The length property returns the length of a string. For example, "abc".length returns 3.
3. String methods:
- .indexOf(): Returns the index of the first occurrence of a substring.
- .lastIndexOf(): Returns the index of the last occurrence of a substring.
- .startsWith(): Checks if a string begins with a specified substring. Returns true or false.
- .endsWith(): Checks if a string ends with a specified substring. Returns true or false.
- .trim(): Removes whitespace from the beginning and end of a string.
- .toUpperCase(): Converts a string to uppercase.
- .toLowerCase(): Converts a string to lowercase.
4. Concatenation: The + operator can be used to concatenate (join) two strings. For example, "Hello " + "World" returns "Hello World".
5. Template literals: Template literals allow embedding expressions within strings using backticks (`) and ${}. For example, `Hello ${name}!` can be used to personalize a greeting.
