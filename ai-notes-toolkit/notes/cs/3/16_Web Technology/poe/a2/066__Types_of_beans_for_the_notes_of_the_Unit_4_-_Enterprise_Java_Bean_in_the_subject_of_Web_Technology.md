### Types of beans for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology:

1. Session Beans:
- Stateful: Maintains conversational state for a client.
- Stateless: Does not maintain any state for a client.

2. Message-driven Beans:
- Listen for JMS messages asynchronously.
- Used to process messages from JMS queues or topics.

3. Entity Beans:
- Represent data (from a database, for example) and encapsulate the data.
- Can be managed (stored and synchronized) by the container.
