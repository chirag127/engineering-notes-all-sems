### Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Java is a programming language and computing platform first released by Sun Microsystems in 1995.
2. Java runs on a virtual machine, which allows it to run on many platforms and operating systems.
3. Java is object-oriented - it supports concepts like inheritance, abstraction, polymorphism and encapsulation.
4. The Java compiler converts Java code into bytecodes which are executable on the Java Virtual Machine (JVM). The JVM is available on many operating systems, and the same bytecodes can run on all of them.
5. Some key benefits of Java are:
- Platform independence: Ability to run on many operating systems and hardware architectures.
- Security: Java has a Security Manager which defines what resources a program can access.
- Stability: Java's memory management avoids common errors like memory leaks or dangling pointers.
- Performance: Java's Just-In-Time compiler executes bytecodes into machine code for high performance.
- Multithreading: Java supports multithreaded programming which allows multiple parts of a program to run concurrently.
- Huge API: Java has an extensive API library to handle tasks like networking, I/O, XML parsing, database connectivity, etc.
