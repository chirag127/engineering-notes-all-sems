### Java Server Pages Overview

- Java Server Pages (JSP) is a Java technology that allows software developers to dynamically generate HTML, XML, or other types of documents in response to a Web client request.
- JSP technology separates the user interface from the static content. The JSP pages contain JSP elements, which are translated into servlets by the JSP engine.
- The JSP engine executes the servlet and generates a response that is sent back to the client.
- The key benefits of JSP technology are:
-- Separates the presentation layer from the business logic
-- Supports reusable components
-- Offers a simple and fast development approach
-- Compatible with Java technology-based applications
-- Supports software engineering best practices
- The JSP engine parses the JSP page and converts the JSP elements into servlet components. The results are pure servlets that contain Java programming language statements and JSP declarations.
- The main JSP scripting elements are:
-- Expressions: Used to insert Java values into the output.
-- Scriptlets: Used to contain Java code fragments.
-- Declarations: Used to declare variables or methods to be used in the JSP page.
- JSP pages are compiled every time they are called. This allows for changes made to JSP pages to be immediately available to the server.
