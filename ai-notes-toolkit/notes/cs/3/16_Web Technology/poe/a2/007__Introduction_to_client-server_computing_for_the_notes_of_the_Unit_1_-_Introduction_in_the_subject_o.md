### Introduction to client-server computing

1. Client-server computing is a distributed application structure that partitions tasks or workloads between the providers of a resource or service, called servers, and service requesters, called clients.
2. Clients and servers communicate over a network on separate devices. The client device sends a request to the server, which then processes the request and returns a response.
3. A key advantage of the client-server model is that it allows for efficient use of resources. Servers can be optimized for providing services, and clients can be optimized for user interaction. It also enables the use of powerful servers, potentially accessing large data sets or computational resources on behalf of many clients.
4. The responsibilities of the server include:
- Providing a service or resource to clients, such as files, devices, data, processing power, etc.
- Managing client requests and responding to them.
- Enforcing security and authentication policies.
- Monitoring performance and integrating with other servers.
5. The responsibilities of the client include:
- Initiating requests to the server.
- Displaying or using the services or resources provided by the server.
- Managing the user interface.
