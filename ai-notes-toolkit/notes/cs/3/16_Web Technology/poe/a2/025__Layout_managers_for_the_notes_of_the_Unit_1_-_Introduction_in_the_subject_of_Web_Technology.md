### Layout managers for the notes of the Unit 1 - Introduction in the subject of Web Technology.

1. Fixed Layout:
- The dimensions of the element are fixed and do not change with the size of the browser window.
- Example: `<div style="width: 200px; height: 100px;">`
- Useful for: Headers, footers, sidebars.

2. Liquid Layout:
- The dimensions of the element change proportionally with the size of the browser window.
- Example: `<div style="width: 50%; height: 100px;">`
- Useful for: The main content area.

3. Elastic Layout:
- The dimensions of the element grow and shrink as the size of the browser window changes.
- Example: `<div style="width: 50%; height: 100px;">` with CSS `min-width` and `max-width` properties.
- Useful for: The main content area. Provides flexibility but enforces limits.

4. Hybrid Layout:
- A mix of multiple layouts to get the benefits of each layout type.
- Example: `<header>` with fixed layout, `<main>` with elastic layout, and `<aside>` with liquid layout.
- Useful for: Most web pages.
