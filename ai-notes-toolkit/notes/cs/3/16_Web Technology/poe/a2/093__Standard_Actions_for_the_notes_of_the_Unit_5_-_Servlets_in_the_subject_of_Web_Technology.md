### Standard Actions for the notes of the Unit 5 - Servlets in the subject of Web Technology

1. Servlet is a Java program that runs on a web server. It processes client requests and returns responses.
2. Servlets handle requests and responses through service methods.
3. The service method of the servlet is invoked by the web server for every client request.
4. The request received from the client contains the request parameters and attributes in a protocol-dependent manner. The servlet extracts the necessary information from the request object and performs the required processing.
5. The servlet generates the response to be sent back to the client. The response contains the response status code, headers, and the response body which is generated as a result of the request processing. The response is sent back to the client through the web server.
6. Servlets execute in a multithreaded manner, so multiple requests can be processed concurrently by a single servlet instance. Proper synchronization is required when multiple threads access shared resources.
7. Servlets can maintain state using various techniques like session management, hidden fields, cookies, etc.
8. Various lifecycle methods are provided to servlets to perform initialization and cleanup tasks.
