### HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

HTML or Hypertext Markup Language is the standard markup language used to create web pages. In this unit, we will learn about the basics of HTML and how it is used in web page designing. Here are some important points to remember:

- HTML stands for Hypertext Markup Language.
- HTML is used to create the structure and content of a web page.
- HTML uses tags to define elements such as headings, paragraphs, links, images, etc.
- The basic structure of an HTML document includes the <!DOCTYPE html> declaration, the <html> element, the <head> element, and the <body> element.
- The <!DOCTYPE html> declaration is used to specify the version of HTML being used.
- The <html> element is the root element of an HTML document and contains all other elements.
- The <head> element contains information about the document such as the title, meta data, and links to external stylesheets and scripts.
- The <body> element contains the content of the web page.
- HTML tags have opening and closing tags, and the content is placed between these tags.
- Some HTML tags have attributes that provide additional information about the element.
- HTML tags can be nested, which means that one element can be placed inside another element.
- HTML tags can be styled using CSS (Cascading Style Sheets).
- HTML5 is the latest version of HTML and includes new elements such as <nav>, <section>, <article>, <header>, <footer>, <video>, <audio>, and more.

In conclusion, HTML is a fundamental language for web designing and is essential knowledge for any web developer. Understanding the basics of HTML is crucial in creating functional and visually appealing web pages.
