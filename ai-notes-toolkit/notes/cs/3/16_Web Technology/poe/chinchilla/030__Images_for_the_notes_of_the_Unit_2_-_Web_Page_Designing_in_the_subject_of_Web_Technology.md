### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

When designing a web page, images are a crucial element that can enhance the visual appeal and convey important information to the users. In this unit, we will discuss the role of images in web page designing and their types. Here are some key points to keep in mind:

- Images can be used for various purposes in web page designing, such as decorative, informative, or functional.
- Decorative images are used to enhance the visual appeal of a web page and create a pleasant user experience. They can be photos, illustrations, or graphic elements.
- Informative images are used to convey specific information to the users, such as charts, graphs, or diagrams. These images can help users understand complex concepts more easily.
- Functional images are used to perform specific actions on the web page, such as buttons, icons, or logos. These images should be designed with usability in mind and should be easily recognizable by the users.
- When selecting images for a web page, it is important to consider their quality, size, and format. High-quality images can enhance the visual appeal of a web page, while low-quality images can have a negative impact. The size of the images should be optimized to ensure fast loading times, and the format should be chosen based on the type of image and its intended use.
- There are several types of image formats that can be used in web page designing, such as JPEG, PNG, GIF, and SVG. Each format has its own advantages and disadvantages, and the choice of format should be based on the specific requirements of the web page.
- Accessibility is an important factor to consider when using images in web page designing. Images should have descriptive alt text that can be read by screen readers, and the text should provide an accurate description of the image.
- Copyright and licensing issues should also be taken into consideration when using images in web page designing. It is important to ensure that the images used are either in the public domain or have been licensed for use on the web page.

By keeping these key points in mind, you can effectively use images in your web page designing to create a visually appealing and user-friendly experience for your users.
