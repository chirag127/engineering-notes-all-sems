### Dynamic HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Dynamic HTML (DHTML) is a combination of HTML, JavaScript, and CSS that allows for dynamic and interactive web page design. DHTML enables developers to create web pages that can respond to user actions, such as mouse clicks, without requiring a page refresh. Here are some key points to remember about Dynamic HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology:

- DHTML allows for dynamic web page design by using JavaScript to manipulate the Document Object Model (DOM) of the web page.
- The DOM is a tree-like structure that represents the elements of an HTML document, and JavaScript can be used to add, remove, or modify these elements on the fly.
- DHTML can be used to create interactive menus, drop-down lists, and other user interface elements that respond to user actions without requiring a page refresh.
- CSS can be used to style the dynamic elements created with DHTML, allowing for a more visually appealing and consistent user interface.
- One common use of DHTML is in form validation, where JavaScript can be used to ensure that user input is valid before submitting the form to the server.
- DHTML can also be used to create animations and other visual effects on the web page, such as changing the color or position of an element in response to a user action.
- However, it is important to keep in mind that DHTML can also have negative effects on website performance, as dynamic elements can increase page load times and put a strain on the user's device.
- Therefore, it is important to use DHTML judiciously and only when necessary to achieve the desired functionality and user experience.

In conclusion, Dynamic HTML is a powerful tool for creating dynamic and interactive web pages, but it should be used with care to avoid negative impacts on website performance. By understanding the principles and best practices of DHTML, web developers can create engaging and functional websites that provide a great user experience.
