### Internet Addressing

In the world of web technology, internet addressing plays a crucial role in identifying and locating resources on the World Wide Web. Internet addressing involves the use of unique identifiers to locate and access web resources. In this unit, we will learn about the various aspects of internet addressing and how it is used in web scripting.

Here are some key points to keep in mind when studying internet addressing:

1. Internet Protocol (IP) Addressing: IP addressing is a fundamental aspect of internet addressing that involves the use of unique numerical identifiers to locate devices on a network. An IP address consists of a series of four numbers separated by dots, such as 192.168.0.1.

2. Domain Name System (DNS): DNS is a hierarchical naming system that maps domain names to IP addresses. DNS allows users to access web resources using human-readable domain names, such as www.example.com, instead of numerical IP addresses.

3. Uniform Resource Locator (URL): A URL is a string of characters that specifies the location of a web resource. A URL consists of several parts, including the protocol, domain name, path, and query string. For example, http://www.example.com/index.html?query=example.

4. Internet Assigned Numbers Authority (IANA): IANA is responsible for managing and coordinating the allocation of IP addresses and domain names on the internet. IANA works with regional internet registries to ensure that IP addresses and domain names are allocated efficiently and fairly.

5. IPv4 and IPv6: IPv4 and IPv6 are two versions of the IP protocol. IPv4 uses 32-bit addresses and can support up to 4.3 billion unique addresses, while IPv6 uses 128-bit addresses and can support up to 340 undecillion unique addresses.

6. Private and Public IP Addresses: Private IP addresses are used within a private network and cannot be accessed from the internet. Public IP addresses, on the other hand, are assigned by an internet service provider (ISP) and can be accessed from the internet.

7. Port Numbers: Port numbers are used to identify specific services or applications on a network. Port numbers range from 0 to 65535, with well-known ports reserved for specific services such as HTTP (port 80) and HTTPS (port 443).

By understanding these key concepts of internet addressing, you will be better equipped to navigate and work with web resources in your web scripting projects.
