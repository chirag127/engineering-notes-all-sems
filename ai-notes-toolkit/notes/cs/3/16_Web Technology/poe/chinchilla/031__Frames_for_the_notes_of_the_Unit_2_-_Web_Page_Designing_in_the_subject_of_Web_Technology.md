### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Frames are a useful tool in web page designing that allow for the display of multiple web pages within a single web page. This feature can be used to create a more dynamic and interactive user experience. Here are some important points to keep in mind when working with frames:

- Frames are created using the `<frame>` tag in HTML.
- Frames can be arranged in a variety of configurations, including rows and columns.
- Each frame can have its own HTML document, which is referenced using the `src` attribute.
- Frames can be given a name using the `name` attribute, which can be used to target the frame from other parts of the web page.
- Frames can be resized using the `rows` and `cols` attributes, or by using JavaScript to dynamically adjust the size.
- Frames can be styled using CSS, just like any other HTML element.
- Frames have some limitations, including difficulties with search engine optimization and accessibility. It is important to consider these factors when deciding whether or not to use frames in a web page design.

When working with frames, it is important to keep the overall user experience in mind. Frames can be a powerful tool for organizing and presenting information, but they can also be confusing or frustrating for users if not used properly. It is important to test your web page design thoroughly to ensure that the frames are working as intended and providing a positive user experience.
