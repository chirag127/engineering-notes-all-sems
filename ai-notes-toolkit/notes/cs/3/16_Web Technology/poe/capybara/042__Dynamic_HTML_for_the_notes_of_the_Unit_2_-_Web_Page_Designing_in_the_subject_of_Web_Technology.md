### Dynamic HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Dynamic HTML (DHTML) is a combination of HTML, CSS, and JavaScript that allows web developers to create interactive and engaging web pages. DHTML technology is used to create dynamic effects that enhance the user experience of a website. Here are some important points to understand about Dynamic HTML:

- DHTML is a technology that allows web developers to create web pages that are more interactive and engaging than traditional HTML pages.
- DHTML uses a combination of HTML, CSS, and JavaScript to create dynamic effects such as animations, menus, and pop-up windows.
- DHTML can be used to create dynamic effects that respond to user actions, such as mouse clicks or keyboard input.
- DHTML can be used to create interactive forms that allow users to submit data and receive real-time feedback.
- DHTML can be used to create web pages that are compatible with a wide range of devices, including desktop computers, laptops, tablets, and smartphones.
- DHTML can be used to create web pages that load quickly and efficiently, which is important for providing a good user experience.
- DHTML can be used to create web pages that are search engine friendly, which is important for improving the visibility of a website on the internet.
- DHTML can be used to create web pages that are accessible to people with disabilities, which is important for ensuring that everyone can use and enjoy the website.

In summary, Dynamic HTML is an important technology for web developers who want to create interactive and engaging web pages. By using a combination of HTML, CSS, and JavaScript, developers can create dynamic effects that enhance the user experience of a website. Understanding Dynamic HTML is an essential part of learning about web page designing in the subject of Web Technology.
