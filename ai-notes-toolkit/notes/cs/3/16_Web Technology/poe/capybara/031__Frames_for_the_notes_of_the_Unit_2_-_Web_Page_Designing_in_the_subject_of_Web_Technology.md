### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Frames are a way to divide a web page into several sections, each containing a separate HTML document. Frames are used to create a layout where one or more frames act as containers for other HTML documents. Frames allow for the presentation of information from multiple sources in a single web page.

Here are some key points to remember about frames:

- Frames are created using the `<frame>` tag.
- The `<frame>` tag is used within the `<frameset>` tag to define the layout of the frames.
- The `<frameset>` tag is used to define the number of rows and columns in the frameset.
- The `src` attribute of the `<frame>` tag specifies the HTML document to be displayed in that frame.
- Frames can be set to have a fixed or variable size.
- A frameset can have a `noresize` attribute set to prevent users from resizing the frames.
- The `<noframes>` tag is used to provide content for browsers that do not support frames.

When designing web pages with frames, it's important to keep the following in mind:

- Frames can complicate bookmarking and printing.
- Search engines may have difficulty indexing framed pages.
- Frames can make navigation more difficult for users with disabilities.
- Frames can be less effective than using CSS for layout.

Overall, while frames can be useful in certain situations, they should be used with caution and with consideration for their potential drawbacks. It's important to weigh the benefits and drawbacks of frames before deciding whether or not to use them in a web page design.
