### Core Java

Java is a popular programming language that is widely used in the development of web applications. It is a high-level language that is platform-independent, meaning that it can run on any operating system. In this section, we will discuss the basics of Core Java.

#### Variables

Variables are used to store data. In Java, there are different types of variables, such as int, double, char, and boolean. Variables are declared using the syntax `type variable_name`.

#### Operators

Java supports different types of operators such as arithmetic, relational, logical, and bitwise. Arithmetic operators are used to perform mathematical operations, while relational operators are used to compare two values. Logical operators are used to combine two or more conditions, and bitwise operators are used to perform bit-level operations.

#### Control Statements

Control statements are used to control the flow of a program. Java supports different types of control statements such as if-else, switch, for, while, and do-while. These statements are used to perform different actions based on certain conditions.

#### Arrays

Arrays are used to store a collection of data of the same type. In Java, arrays are declared using the syntax `type[] array_name`. Arrays can be of different types, such as int, double, char, and boolean.

#### Object-Oriented Programming

Java is an object-oriented programming language. Object-oriented programming is a programming paradigm that is based on objects, which can contain data and code. Java supports different concepts of object-oriented programming such as encapsulation, inheritance, and polymorphism.

#### Exception Handling

Exception handling is used to handle runtime errors in a program. Java uses the try-catch block to handle exceptions. The try block contains the code that might throw an exception, while the catch block contains the code that handles the exception.

#### Input and Output

Java provides different classes to handle input and output operations. The System.out.println() statement is used to print output to the console, while the Scanner class is used to read input from the console.

#### Conclusion

In this unit, we discussed the basics of Core Java. Java is a popular programming language that is widely used in the development of web applications. Understanding the basics of Core Java is essential for anyone who wants to become a Java developer.
