### Object Models for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Object Models play a crucial role in web development. They are used to represent the structure, behavior, and properties of objects on a web page. Here are some important points to understand Object Models in Web Page Designing:

- The Document Object Model (DOM) is the most widely used Object Model in web development. It represents the web page as a hierarchical tree structure, where each element in the tree represents an object on the web page. 

- The DOM provides a set of methods and properties that allow developers to manipulate the objects on a web page dynamically. For example, developers can use the DOM to add or remove elements, change the content of elements, or style elements on a web page.

- Another important Object Model in web development is the Browser Object Model (BOM). The BOM represents the web browser itself as an object, and provides access to its properties and methods. This allows developers to manipulate the browser's behavior, such as opening new windows or navigating to a new URL.

- JavaScript is the primary language used for manipulating Object Models in web development. Developers can use JavaScript to access and manipulate the objects in the DOM and BOM.

- Understanding Object Models is essential for creating dynamic and interactive web pages. By mastering Object Models, developers can create web pages that respond to user input and provide a more engaging user experience.

- The use of Object Models is not limited to web development. Object Models are used in many other areas of software development, such as desktop and mobile applications.

In conclusion, Object Models are a fundamental concept in web development. They provide developers with the tools to create dynamic and interactive web pages, and are an essential part of any web developer's toolkit.
