### Document type definition for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Here are some important points to consider when it comes to Document Type Definition (DTD):

- A Document Type Definition (DTD) is a set of rules that defines the structure, elements, and attributes of an XML document.
- DTDs are used to ensure that an XML document is well-formed and valid.
- A well-formed XML document follows the basic rules of XML syntax, while a valid XML document follows the rules specified in the DTD.
- DTDs can be included within an XML document or referenced externally.
- DTDs define the elements and attributes that are allowed in an XML document, as well as their order and relationships.
- DTDs can also specify default values for attributes and define entities for reusable pieces of text.
- There are two types of DTDs: internal and external. Internal DTDs are included within the XML document, while external DTDs are referenced from an external file.
- DTDs can be written using a variety of syntaxes, including Document Type Definition (DTD), XML Schema, and Relax NG.
- The use of DTDs is important in web page designing, as they help ensure that the HTML code used to create a web page is well-formed and valid.
- DTDs can also be used to validate other types of XML documents, such as RSS feeds and XHTML documents. 

By following these guidelines and understanding the importance of DTDs, web designers can create well-formed and valid web pages that are accessible to all users.
