
### Padding Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* Padding is the space between the content of an element and its border.
* Padding can be set using length values (e.g. `px`, `em`, `rem`) or percentages.
* The `padding` property can be used to set the padding for all four sides of an element at once.
* The `padding-top`, `padding-right`, `padding-bottom`, and `padding-left` properties can be used to set the padding for each side of an element individually.
* The `padding` property can also accept multiple values, which will set the padding for the top, right, bottom, and left sides of an element in that order.
* The `box-sizing` property can be used to control the way the padding is calculated. By default, the padding is added to the width and height of an element.
* Padding can also be used to create space between elements in a page.
