
### CSS Color for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* CSS color is used to define the color of HTML elements and text.
* The color can be specified using a color name (e.g. red, blue, green), a hexadecimal code (e.g. #FF0000 for red), or an RGB value (e.g. rgb(255, 0, 0) for red).
* The opacity of an element can also be specified with the opacity property.
* The HSL (Hue, Saturation, and Lightness) color model can also be used to specify colors.
* The RGBA (Red, Green, Blue, Alpha) color model can also be used to specify colors with an alpha channel for transparency.
* The HSLA (Hue, Saturation, Lightness, Alpha) color model can also be used to specify colors with an alpha channel for transparency.
* CSS also allows for color gradients, which can be linear or radial.
* The `currentColor` keyword can be used to refer to the color of the element itself.
* The `inherit` keyword can be used to inherit the color from a parent element.
