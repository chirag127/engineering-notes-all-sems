
### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a language used to style and format webpages.
2. CSS is used to control the presentation of elements on a webpage. It is used to control colours, fonts, text sizes, margins, and other aspects of the webpage.
3. CSS can be used to create responsive webpages. Responsive webpages are those that can be viewed on different devices with different screen sizes.
4. CSS can be used to create animations and transitions. Animations are used to create a smoother user experience.
5. CSS can be used to create layouts and grids. Layouts are used to determine the placement of elements on a webpage.
6. CSS can be used to create responsive images. Responsive images are those that are automatically resized depending on the device they are being viewed on.
7. CSS can be used to create responsive typography. Responsive typography is used to ensure that text is displayed correctly on different devices.
8. CSS can be used to create responsive navigation menus. Responsive navigation menus are used to ensure that the navigation menu is displayed correctly on different devices.
