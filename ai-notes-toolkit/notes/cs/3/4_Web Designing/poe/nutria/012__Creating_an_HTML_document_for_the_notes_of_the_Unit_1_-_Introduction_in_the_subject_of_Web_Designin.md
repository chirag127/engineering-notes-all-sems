
### Creating an HTML Document for the Notes of the Unit 1 - Introduction in the Subject of Web Designing

1. HTML stands for Hypertext Markup Language and is the most basic building block of the World Wide Web.
2. HTML is used to create web pages that can be viewed in a web browser.
3. HTML documents are composed of a series of elements such as headings, paragraphs, images, links and lists.
4. HTML documents are written in tags that define the structure of the document.
5. HTML documents can be created using a text editor or a web page editor.
6. HTML documents must be validated to ensure that they adhere to the HTML standards.
7. HTML documents can be styled using Cascading Style Sheets (CSS).
8. HTML documents can be interactive with the use of JavaScript.
