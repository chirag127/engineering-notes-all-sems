
### Navigation Bar for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. What is CSS?
    - CSS stands for Cascading Style Sheets. It is a language used to describe the presentation of a web page. It is used to control the layout, font, color, and other aspects of the page's appearance.

2. What are the benefits of using CSS?
    - CSS allows for a separation of content and design, which makes it easier to maintain a website. It also makes it easier to update the design of a website without having to update the content. Additionally, CSS can be used to create responsive designs that scale to different devices and screen sizes.

3. What are the main components of a CSS rule?
    - A CSS rule consists of a selector, a property, and a value. The selector identifies the element or elements to which the rule will be applied. The property defines the aspect of the element to be changed, and the value defines the actual change.
