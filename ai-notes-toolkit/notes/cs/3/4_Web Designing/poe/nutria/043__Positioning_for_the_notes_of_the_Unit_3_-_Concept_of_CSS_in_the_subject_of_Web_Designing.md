
### Positioning for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* CSS positioning is a powerful tool for web designers to control the layout of their webpages.
* Positioning can be used to create complex layouts that would otherwise be difficult or impossible to achieve with HTML.
* CSS positioning can be used to position elements relative to the browser window, another element on the page, or the page itself.
* There are four types of positioning: static, relative, absolute, and fixed.
* Static positioning is the default positioning for elements. It places the element in the normal flow of the page and does not affect other elements on the page.
* Relative positioning is similar to static positioning, but it allows the element to be shifted relative to its normal position.
* Absolute positioning allows an element to be placed anywhere on the page, regardless of the normal flow of the page.
* Fixed positioning is similar to absolute positioning, but the element is fixed relative to the browser window, even when the page is scrolled.
* It is important to note that positioning can affect the size and position of other elements on the page. It is important to use positioning carefully in order to avoid unexpected results.
