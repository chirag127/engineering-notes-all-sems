
### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* CSS (Cascading Style Sheets) is a language used to style webpages. It is used to control the appearance of HTML elements on a webpage.
* CSS is used to define the font, size, color, spacing, and other properties of HTML elements.
* CSS can be written in three different ways: inline, embedded, and external.
* Inline CSS is written directly inside the HTML element, while embedded and external CSS are written in separate files.
* CSS can be used to create responsive layouts that adjust to different screen sizes.
* CSS can also be used to create animations and transitions.
* CSS is a powerful tool for web design and is essential for creating modern websites.
