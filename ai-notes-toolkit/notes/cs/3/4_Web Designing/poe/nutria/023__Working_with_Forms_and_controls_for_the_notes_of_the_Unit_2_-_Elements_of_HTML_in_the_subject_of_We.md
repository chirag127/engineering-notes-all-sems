
### Working with Forms and controls

- Forms are used to collect user input in HTML documents.
- A form consists of one or more input elements, such as text fields, checkboxes, radio buttons, and submit buttons.
- Each form element has a name and a value.
- The value of the form element is the data that is sent to the server when the form is submitted.
- The `<form>` element is used to create a form.
- The `<input>` element is used to create an input field.
- The `<select>` element is used to create a drop-down list.
- The `<textarea>` element is used to create a text area.
- The `<button>` element is used to create a submit button.
- The `<label>` element is used to create a label for a form element.
- The `<fieldset>` element is used to group related form elements.
- The `<legend>` element is used to create a title for a fieldset.
