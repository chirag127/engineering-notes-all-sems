
### Grouping for the Notes of the Unit 3 - Concept of CSS in the Subject of Web Designing

* CSS stands for Cascading Style Sheets and is used to style HTML documents.
* CSS can be used to define colors, fonts, margins, padding, and other styling elements.
* CSS can also be used to define the layout of a page, such as how elements are arranged and the size and position of elements.
* CSS can be written in three different ways: inline, internal, and external. 
* Inline CSS is written directly into the HTML element, while internal and external CSS are written in separate files.
* CSS can be used to create responsive designs that adjust to different screen sizes and device types.
* CSS can also be used to create animations and transitions to create dynamic web pages.
