
### Variables in JS for the Notes of the Unit 4 - Introduction to Client Side Scripting in the Subject of Web Designing

* Variables are used to store values in JavaScript. 
* Variables are declared using the `var` keyword followed by the variable name and an optional value.
* Variables can be assigned new values at any time.
* Variables can be used to store strings, numbers, booleans, and objects.
* Variables can be used to store the result of a function.
* Variables can be used to store the result of an expression.
* Variables can be used to store the result of a comparison.
* Variables can be used to store the result of a mathematical operation.
* Variables can be used to store the result of a loop.
* Variables can be used to store the result of an array.
* Variables can be used to store the result of an object.
