
### Working with Lists and Tables for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Lists are used to present information in an organized manner. They can be used to create bulleted lists, numbered lists, and even definition lists.

2. Tables are used to present data in a tabular format. They can be used to create tables with multiple columns and rows.

3. CSS can be used to style lists and tables. This includes setting the font size, font color, background color, and other properties.

4. CSS can also be used to add padding and margins to lists and tables. This can help to create space between elements and make them look more organized.

5. CSS can also be used to create hover effects on lists and tables. This can help to make elements more interactive and engaging.

6. CSS can also be used to create responsive lists and tables. This means that they will look different on different screen sizes.
