
### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a style sheet language used to define the look and formatting of a document written in a markup language.
2. CSS can be used to control the layout of multiple web pages all at once.
3. CSS can be used to define colors, fonts, layouts, spacing, and other aspects of web pages.
4. CSS is used to define the presentation of HTML elements.
5. CSS can be used to create responsive designs that adapt to different screen sizes.
6. CSS is a powerful tool for creating visually appealing web pages.
7. CSS can be used to create animations and interactive elements.
8. CSS can be used to create custom designs for different devices.
9. CSS can be used to create print-friendly versions of web pages.
10. CSS can be used to improve the performance of web pages.
