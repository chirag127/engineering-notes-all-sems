
### Defining Name Servers for the notes of the Unit 5 - Web Hosting in the subject of Web Designing

1. Name servers are computers that store the DNS records for a domain. 
2. They help to direct users to the correct web server when they type in a domain name.
3. They are essential for hosting a website as they tell the domain where to point to. 
4. When a domain is registered, the registrar will provide the name servers for the domain. 
5. It is important to ensure that the name servers are pointing to the correct web server. 
6. If the name servers are not pointing to the correct web server, the website will not be accessible. 
7. To change the name servers, the domain owner must log in to their domain registrar and update the name servers. 
8. It is important to note that it can take up to 48 hours for the changes to take effect.
