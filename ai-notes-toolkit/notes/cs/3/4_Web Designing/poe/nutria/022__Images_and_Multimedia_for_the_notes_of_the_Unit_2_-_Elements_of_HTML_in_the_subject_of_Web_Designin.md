
### Images and Multimedia 

- Images and multimedia can be added to a web page using HTML. 
- The `<img>` tag is used to add images to a web page. It takes the `src` attribute to specify the source of the image. 
- The `<video>` tag is used to add videos to a web page. It takes the `src` attribute to specify the source of the video. 
- The `<audio>` tag is used to add audio to a web page. It takes the `src` attribute to specify the source of the audio. 
- The `<object>` tag is used to embed an object such as an applet, audio, video, or another web page into a web page. 
- The `<embed>` tag is used to embed an object such as an applet, audio, video, or another web page into a web page. 
- The `<iframe>` tag is used to embed an inline frame into a web page. It takes the `src` attribute to specify the source of the frame. 
- The `<canvas>` tag is used to draw graphics on a web page. It takes the `width` and `height` attributes to specify the size of the canvas.
