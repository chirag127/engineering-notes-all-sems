
### What is HTML?
1. HTML stands for HyperText Markup Language
2. HTML is a markup language used to create web pages
3. HTML is made up of elements, which are represented by tags
4. HTML tags tell the browser how to display content
5. HTML is written in plain text, which means it can be written and edited in any text editor
6. HTML documents are made up of two parts: the head and the body
7. The head of the document contains information about the document, such as the title and meta tags
8. The body of the document contains the content that is displayed on the web page
9. HTML documents can be linked to other HTML documents and other web resources, such as images, videos, and stylesheets
10. HTML is used to create interactive web pages and applications
