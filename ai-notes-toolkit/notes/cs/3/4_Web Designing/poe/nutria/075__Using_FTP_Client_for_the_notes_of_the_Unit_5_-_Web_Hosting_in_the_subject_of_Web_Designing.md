
### Using FTP Client for the Notes of the Unit 5 - Web Hosting in the Subject of Web Designing

1. FTP stands for File Transfer Protocol and is a way to transfer files between computers.
2. FTP clients are programs that allow users to connect to an FTP server and transfer files between the two computers.
3. FTP clients can be used to upload and download files from a web hosting server.
4. To connect to an FTP server, the user must provide a valid username and password.
5. Once connected, the user can browse the files on the server and transfer files between the two computers.
6. FTP clients also allow users to change permissions on files and folders, create and delete files and folders, and rename files and folders.
7. It is important to remember to disconnect from the server after transferring files to ensure that no other users can access the files.
8. FTP clients are an essential tool for web designers and developers who need to upload and manage files on their web hosting servers.
