
### CSS Styling for the Notes of Unit 3 - Concept of CSS in Web Designing

1. CSS stands for Cascading Style Sheets and is used to style webpages.
2. CSS is used to define the layout and presentation of a webpage, including colors, fonts, and other visual elements.
3. CSS can be written in an external file or within the HTML document itself.
4. CSS can be used to create responsive webpages that adjust to different screen sizes and devices.
5. CSS can be used to create animation and interactive effects on a webpage.
6. CSS has a variety of selectors that can be used to apply styling to specific elements on a webpage.
7. CSS can be used to create complex layouts with grids and flexbox.
8. CSS can be used to create transitions and transformations to elements on a webpage.
9. CSS can be used to create media queries that allow for different styling based on the user's device and screen size.
10. CSS can be used to create custom fonts and icons.
