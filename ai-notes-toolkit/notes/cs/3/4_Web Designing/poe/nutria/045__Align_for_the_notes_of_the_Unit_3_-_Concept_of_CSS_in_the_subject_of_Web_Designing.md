
### Align for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* Aligning elements in CSS can be done using the `text-align`, `vertical-align`, and `float` properties. 
* The `text-align` property is used to align text horizontally in a container. It can take the values `left`, `right`, `center`, and `justify`. 
* The `vertical-align` property is used to align text vertically in a container. It can take the values `top`, `bottom`, `middle`, and `baseline`. 
* The `float` property is used to float an element to the left or right of its container. It can take the values `left` and `right`. 
* Aligning elements in CSS can be used to create complex layouts and designs for webpages.
