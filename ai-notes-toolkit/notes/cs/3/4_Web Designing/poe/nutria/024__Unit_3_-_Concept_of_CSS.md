
## Unit 3 - Concept of CSS

1. CSS stands for Cascading Style Sheets. It is a language used to describe the presentation of a web page written in a markup language like HTML.

2. CSS styles can be applied to HTML elements, including font size, font color, background color, and borders.

3. CSS can be used to create responsive web designs, allowing the page to display differently depending on the device or screen size.

4. CSS can be written in two ways: inline or embedded. Inline CSS is written directly into the HTML document, while embedded CSS is written in an external style sheet.

5. CSS can be used to create animations, transitions, and interactive elements on a website.

6. CSS can be used to create a consistent look and feel across a website, ensuring all elements on the page look and behave the same way.
