
### JS Arrays for the Notes of Unit 4 - Introduction to Client Side Scripting in the Subject of Web Designing

* An array is a special type of variable that can store multiple values in a single variable.
* Arrays are used to store data in a structured way, and can be used to store any type of data, including strings, numbers, and objects.
* Arrays are created using the `Array()` constructor, or by using the array literal syntax `[]`.
* Arrays can be accessed using their index, which is the position of the element in the array.
* Arrays can be manipulated using various methods, such as `push()`, `pop()`, `shift()`, `unshift()`, `splice()`, `sort()`, `reverse()`, and `concat()`.
* Arrays can also be iterated over using the `forEach()` method, or using the `for...of` loop.
