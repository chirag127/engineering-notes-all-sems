
### Web Standards and W3C recommendations for the notes of the Unit 1 - Introduction in the subject of Web Designing

* The World Wide Web Consortium (W3C) is an international organization that sets standards for web development. 
* W3C standards include HTML, CSS, and XML, among others. 
* W3C standards are designed to ensure web pages are accessible to all users, regardless of hardware, software, language, or other factors. 
* W3C recommends using web standards to create websites that are accessible, usable, interoperable, and reliable. 
* W3C also recommends using web standards to create websites that are secure and perform well. 
* Web standards are constantly evolving, so web developers must keep up to date with the latest standards.
