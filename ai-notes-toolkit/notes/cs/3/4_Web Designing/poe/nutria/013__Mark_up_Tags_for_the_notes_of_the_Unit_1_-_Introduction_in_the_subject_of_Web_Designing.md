
### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

* HTML stands for Hyper Text Markup Language. It is used to create the structure and content of webpages.
* CSS stands for Cascading Style Sheets. It is used to define the look and feel of webpages.
* JavaScript is a programming language used to create interactive webpages.
* HTML tags are used to structure the content of a webpage.
* CSS selectors are used to style the elements of a webpage.
* JavaScript functions are used to add interactivity to a webpage.
* A web page is composed of HTML, CSS, and JavaScript code.
* HTML, CSS, and JavaScript code must be written in a valid syntax in order for a webpage to be displayed correctly.
