
### Working with block elements and objects for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS is a language used to style and layout webpages. It is used to control the presentation of HTML elements on a web page.
2. Block elements are HTML elements that are used to create a rectangular box around some content. Examples of block elements include `<div>`, `<p>`, `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, `<h6>`, `<ul>`, `<ol>`, `<li>`, `<table>`, and `<blockquote>`.
3. Objects are HTML elements that are used to create an object or image on a web page. Examples of objects include `<img>`, `<embed>`, `<object>`, and `<video>`.
4. CSS can be used to control the layout of block elements and objects on a web page. This includes setting the size, position, color, padding, margin, and other properties.
5. CSS can also be used to create animations and transitions, which can be used to create dynamic effects on web pages.
6. CSS can be used to create responsive designs, which can adapt to different screen sizes and devices. This allows a single web page to look good on both desktop and mobile devices.
