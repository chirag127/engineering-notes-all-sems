### Pseudo Class

Pseudo-class is a CSS selector that selects an element based on its state or position in the document tree. It is used to style specific elements based on user interaction with the web page, such as hovering over a link or clicking on a button.

Here are some of the commonly used pseudo-classes in CSS:

1. :hover - This pseudo-class selects an element when the mouse cursor is over it. It is often used to change the color or style of a link when the user hovers over it.

2. :active - This pseudo-class selects an element when it is being clicked on. It is often used to change the color or style of a button to indicate that it has been clicked.

3. :focus - This pseudo-class selects an element when it has focus, such as when it is selected using the keyboard. It is often used to change the color or style of a form input field when it is selected.

4. :first-child - This pseudo-class selects the first child element of a parent element. It is often used to style the first item in a list differently from the rest.

5. :last-child - This pseudo-class selects the last child element of a parent element. It is often used to style the last item in a list differently from the rest.

6. :nth-child() - This pseudo-class selects an element based on its position in a list. It is often used to style every other item in a list, or to apply different styles to specific items in a list.

7. :nth-of-type() - This pseudo-class selects an element based on its position among elements of the same type. It is often used to style every other paragraph or heading on a page.

8. :not() - This pseudo-class selects all elements except those that match the specified selector. It is often used to apply styles to all elements except a specific one.

Pseudo-classes are a powerful tool in CSS that allow you to create dynamic and interactive web pages. By using them effectively, you can create a more engaging and user-friendly experience for your website visitors.
