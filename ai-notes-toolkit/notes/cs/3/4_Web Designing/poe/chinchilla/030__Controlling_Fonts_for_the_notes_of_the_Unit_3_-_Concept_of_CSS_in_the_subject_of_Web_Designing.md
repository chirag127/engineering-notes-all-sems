### Controlling Fonts for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

In web design, the font is an essential element that can affect the overall appearance and readability of a website. CSS provides several ways to control fonts on a webpage. Here are some important points to keep in mind when controlling fonts using CSS:

- **Font Families:** CSS allows you to specify a list of font families for a webpage. The browser will use the first font in the list that is available on the user's computer. If none of the fonts in the list are available, the browser will use its default font. To specify a font family, use the "font-family" property in CSS. For example, to use the "Arial" font family, you would use the following code: 

```
font-family: Arial, sans-serif;
```

- **Font Sizes:** CSS allows you to specify font sizes in different units such as pixels, ems, and percentages. The default font size is usually 16px. To change the font size, use the "font-size" property in CSS. For example, to set the font size to 18px, you would use the following code: 

```
font-size: 18px;
```

- **Font Styles:** CSS allows you to specify font styles such as bold, italic, and underline. You can also use a combination of these styles. To set the font style, use the "font-style" property in CSS. For example, to make the font bold, you would use the following code: 

```
font-weight: bold;
```

- **Text Transformations:** CSS allows you to transform text using various techniques such as capitalization, uppercase, lowercase, and text decoration. To transform text, use the "text-transform" property in CSS. For example, to make all text uppercase, you would use the following code: 

```
text-transform: uppercase;
```

- **Font Variants:** CSS allows you to specify font variants such as small-caps and normal. To set the font variant, use the "font-variant" property in CSS. For example, to use small-caps, you would use the following code: 

```
font-variant: small-caps;
```

In summary, CSS provides several ways to control fonts on a webpage. By using these techniques, you can improve the readability and appearance of your website.
