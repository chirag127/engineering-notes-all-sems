### Unit 3 - Concept of CSS

CSS or Cascading Style Sheets is a language used for describing the presentation of a document written in HTML or XML. It is a cornerstone technology of the World Wide Web, alongside HTML and JavaScript. CSS allows web developers to separate the presentation of a web page from its content, making it easier to update and maintain the design of a website. In this unit, we will cover the following topics:

1. Introduction to CSS:
   * What is CSS?
   * Why is CSS important in web design?
   * How does CSS work?
   * The different versions of CSS.

2. CSS Selectors:
   * What are selectors?
   * Types of selectors - element, class, ID, attribute, pseudo-class, and pseudo-element.
   * How to use selectors in CSS.
   * Specificity of selectors.

3. CSS Properties:
   * What are CSS properties?
   * How to use CSS properties to style HTML elements.
   * Common CSS properties for text, background, borders, and layout.
   * Using shorthand CSS properties.

4. CSS Box Model:
   * What is the CSS box model?
   * The different parts of the box model - content, padding, border, and margin.
   * How to use the box model to create layout and spacing.

5. CSS Layout:
   * What is CSS layout?
   * Types of layout - fixed, fluid, and responsive.
   * How to use CSS layout to create different types of web pages.

6. CSS Frameworks:
   * What are CSS frameworks?
   * The advantages and disadvantages of using CSS frameworks.
   * Popular CSS frameworks - Bootstrap, Foundation, and Materialize.

In conclusion, CSS is an essential language for web designers to create visually appealing and functional websites. By mastering the concepts covered in this unit, you will have a solid foundation in CSS that will enable you to create beautiful and responsive web pages.
