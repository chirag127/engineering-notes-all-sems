### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

In this unit, we will be discussing the concept of CSS in web designing. CSS stands for Cascading Style Sheets, which is a styling language used to describe the look and formatting of a document written in HTML. CSS allows web designers to separate the presentation of a web page from its content, making it easier to maintain and modify the website's style.

Here are some important points to keep in mind while studying the concept of CSS:

1. CSS syntax: CSS uses a simple syntax to define styles for HTML elements. It consists of a selector, which is used to target the HTML element, and one or more declarations, which define the style rules for that element.

2. Types of selectors: There are several types of selectors in CSS, including element selectors, class selectors, ID selectors, and attribute selectors. Each type of selector allows web designers to target specific HTML elements and apply styles to them.

3. CSS properties: CSS properties are used to define the style rules for HTML elements. Some common CSS properties include font-size, color, background-color, margin, padding, and border.

4. CSS box model: The CSS box model is used to define the layout and spacing of HTML elements on a web page. It consists of four elements: content, padding, border, and margin. Understanding the box model is essential for creating well-designed web pages.

5. CSS layout techniques: CSS offers several layout techniques, including float, position, and display, which allow web designers to position and arrange HTML elements on a web page.

6. CSS frameworks: CSS frameworks are pre-written CSS code libraries that can be used to quickly create responsive and well-designed web pages. Some popular CSS frameworks include Bootstrap, Foundation, and Materialize.

In conclusion, understanding the concept of CSS is essential for creating well-designed and visually appealing web pages. By learning the syntax, selectors, properties, box model, layout techniques, and frameworks of CSS, you will be able to create professional-looking websites that are both functional and aesthetically pleasing.
