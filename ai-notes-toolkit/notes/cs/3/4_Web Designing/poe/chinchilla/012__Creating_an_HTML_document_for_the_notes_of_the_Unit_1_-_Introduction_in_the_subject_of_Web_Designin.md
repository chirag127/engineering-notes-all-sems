### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

HTML is the foundation of web designing. It stands for Hypertext Markup Language and is used to create web pages. In this unit, you will learn the basics of HTML and how to create an HTML document for the notes of Unit 1 - Introduction.

Here are the steps to create an HTML document for your notes:

1. Open a text editor: You can use any text editor to create an HTML document. Examples of text editors are Notepad, Sublime Text, Atom, and Visual Studio Code.

2. Create a new file: After opening a text editor, create a new file by clicking on the “New File” option.

3. Start with the HTML tag: The first thing you need to do is to add the HTML tag at the beginning of your document. This tag tells the browser that this is an HTML document.

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title>Unit 1 - Introduction</title>
    </head>
    <body>
    </body>
    </html>
    ```

4. Add the head section: The head section contains metadata about the document such as the title of the page, stylesheets, and scripts. Add the head section inside the HTML tag.

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title>Unit 1 - Introduction</title>
    </head>
    <body>
    </body>
    </html>
    ```

5. Add the body section: The body section contains the content of the page. Add the body section inside the HTML tag, after the head section.

    ```html
    <!DOCTYPE html>
    <html>
    <head>
        <title>Unit 1 - Introduction</title>
    </head>
    <body>
        <h1>Introduction to Web Designing</h1>
        <p>In this unit, you will learn the basics of HTML, CSS, and JavaScript.</p>
        <h2>HTML</h2>
        <p>HTML stands for Hypertext Markup Language and is used to create web pages.</p>
        <h2>CSS</h2>
        <p>CSS stands for Cascading Style Sheets and is used to style web pages.</p>
        <h2>JavaScript</h2>
        <p>JavaScript is a programming language used to create interactive web pages.</p>
    </body>
    </html>
    ```

6. Save your document: After creating your HTML document, save it with a .html extension. For example, “unit1.html”.

Congratulations! You have created an HTML document for your notes on Unit 1 - Introduction in the subject of Web Designing.
