### CSS Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing:

1. Color: Used to set the color of the text or background. Example: color: blue;
2. Font-family: Used to set the font face. Example: font-family: Arial;
3. Font-size: Used to set the font size. Example: font-size: 16px;
4. Background-color: Used to set the background color of an element. Example: background-color: cyan;
5. Text-align: Used to set the horizontal alignment of the text. Example: text-align: center;
6. Border: Used to set the border around an element. Example: border: 1px solid black;
7. Height and Width: Used to set the height and width of an element. Example: height: 100px; width: 50%;
8. Margin: Used to create margin outside the border. Example: margin: 20px;
9. Padding: Used to create padding inside the border. Example: padding: 10px;
