### Validation of Forms for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

1. Introduction to Form Validation
- Form validation is the process of checking if the input values in a form adhere to the constraints or rules set for them.
- It is done to ensure correct and high quality data is entered.
- It can be done at server side or client side.
- In this unit, we will learn about client side form validation using JavaScript.

2. WhyValidateForms?
- It provides a good user experience by giving instant feedback to the user.
- It saves server time as invalid data is not sent to the server.
- It enhances the security of the application by blocking malicious data.

3. How to Validate?
- Decide on the validation rules for each field (length, format, range etc.)
- Attach an event handler to the form submission that will check each field and if invalid, display an error.
- Use a variety of inbuilt JavaScript functions to validate each type of field.
- Examples:
-- For email: use isValidEmail()
-- For required fields: check if value is empty
-- For number: use isNaN()
-- For date: use Date object methods
