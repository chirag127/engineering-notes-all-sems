### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing.

1. What is CSS?
CSS stands for Cascading Style Sheets. It is a styling language used to style an HTML document. It separates the content from presentation.

2. Why use CSS?
- It makes web pages attractive and presentable.
- It saves a lot of time as you can change the look of the whole website by changing just one file.
- It makes web pages consistent in terms of layout and design.
- It makes web pages compliant with web standards.
- It makes web pages accessible.

3. How to add CSS to HTML?
There are three ways to add CSS to HTML:

Inline - Using style attribute in HTML elements
<h1 style="color:blue;">Hello World</h1>

Internal - Using <style> element in the head section
<head>
<style>
h1 {
  color: blue;
}
</style>
</head>

External - Using a separate .css file
<head>
<link rel="stylesheet" href="styles.css">
</head>
