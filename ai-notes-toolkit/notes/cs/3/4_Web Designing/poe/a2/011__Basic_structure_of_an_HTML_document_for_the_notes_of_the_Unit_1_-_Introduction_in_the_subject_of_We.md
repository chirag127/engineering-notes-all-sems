### Basic structure of an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing.

1. HTML stands for Hypertext Markup Language.
2. An HTML document basically consists of a tree of elements and has a header section, body section, and a footer section.
3. The basic structure of an HTML document is:

<!DOCTYPE html>
<html>
<head>
</head>
<body>
</body>
</html>

4. The <!DOCTYPE> declaration defines the document type and is placed at the top of the HTML document. It tells the browser which version of HTML the page is written in.
5. The <html> element is the root element of an HTML document. It contains two sub-elements: <head> and <body>.
6. The <head> element contains metadata about the HTML document. It includes the title of the document, meta information, CSS styles, script references, etc.
7. The <body> element contains the visible content of the webpage. This is where all the text, images, videos, etc. are placed.
8. The <footer> element contains information about the author of the webpage or any copyright information. It is placed at the end of the <body> element.
