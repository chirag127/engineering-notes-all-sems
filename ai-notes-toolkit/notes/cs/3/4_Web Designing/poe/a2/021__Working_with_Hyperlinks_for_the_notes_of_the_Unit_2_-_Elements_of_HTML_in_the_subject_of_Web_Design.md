### Working with Hyperlinks for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing.

1. Hyperlinks are used to link one page to another page.
2. The HTML tag used for creating hyperlinks is <a> anchor element.
3. The syntax for creating a hyperlink is:
<a href="link_goes_here">Link text goes here</a>
4. The href attribute specifies the URL or web address of the linked page. The link text is the clickable text that links to another page.
5. For example, to link to Wikipedia:
<a href="https://en.wikipedia.org/">Link to Wikipedia</a>
6. Hyperlinks can be of two types - internal links and external links.
7. Internal links point to pages within the same website. External links point to pages on other websites.
8. Internal links use relative path as the link source while external links use the full URL as the link source.
9. For example, an internal link:
<a href="about.html">About Page</a>
10. And an external link:
<a href="https://www.w3schools.com">W3Schools</a>
