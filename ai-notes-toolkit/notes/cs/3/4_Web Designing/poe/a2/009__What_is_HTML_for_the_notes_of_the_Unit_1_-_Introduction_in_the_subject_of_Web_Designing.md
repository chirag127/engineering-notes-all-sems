### What is HTML

1. HTML stands for Hypertext Markup Language.
2. It is the main markup language used to create web pages.
3. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page semantically.
4. Each HTML tag contains an opening tag and a closing tag with content in between. For example, <p>This is a paragraph</p>.
5. HTML tags are not displayed on the web page, but they specify how the content should be structured and presented in the browser.
6. HTML provides the basic structure of a web page and is married with CSS and JavaScript to add styling and interactivity to web pages.
7. The latest version of HTML is HTML5 which provides many new features like video, audio, canvas, semantic markup, offline web apps, geolocation, etc.
8. To learn HTML, you can take online courses or tutorials and practice writing HTML code to build your own web pages.
