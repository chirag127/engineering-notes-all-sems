### Attribute sector for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style the HTML elements and control the look and feel of a web page.
3. There are 3 ways to add CSS to HTML:

- Inline - Using the "style" attribute in HTML elements
- Internal - Using a <style> element in the HTML head
- External - Using a CSS file and linking it from the HTML head

4. The advantages of external CSS are:

- It separates the presentation from the content
- It makes it easier to maintain the website (update styles)
- It enables reuse of the same CSS style rules across multiple web pages

5. The basic syntax of a CSS rule is:

selector {
property: value;
property: value;
}

6. Some common CSS selectors are:

- element (selects all elements of that type)
- .class (selects all elements with that class)
- #id (selects the element with that id)
- element, element (selects all elements of both types)
- element element (selects elements of the first type that are descendants of the second type)

7. Common CSS properties are:

- color - text color
- background-color - background color
- font-family - font face
- font-size - font size
- width / height - element size
- border - border style, width and color
- margin / padding - spacing outside and inside
