### Java Script Loops for the notes of the Unit 4 - Introduction to Client Side Scripting

1. Loops are used to repeat a block of code. This helps in reducing the amount of code and saves time.
2. The three common types of loops in Java Script are:
- For loop: Used to repeat a block of code for a specified number of times. The for loop contains initialization, condition and increment expression.
- While loop: Repeats a block of code while a specified condition is true. The condition is checked before executing the code block.
- Do...While loop: Also repeats a block of code while a specified condition is true. However, the condition is checked after executing the code block. Hence, the code block is executed at least once.
3. For example:
For loop:
for (let i = 0; i < 5; i++) {
    console.log(i); // Prints 0, 1, 2, 3, 4
}

While loop:
let i = 0;
while (i < 5) {
    console.log(i); // Prints 0, 1, 2, 3, 4
    i++;
}

Do...While loop:
let i = 0;
do {
    console.log(i); // Prints 0, 1, 2, 3, 4
    i++;
} while (i < 5);

4. Loops are useful to repeat a block of code for a certain number of times or until a condition is met. They help in reducing the amount of repetitive code and make the code more efficient and easy to read and understand.
