### Web Hosting Basics

1. Web hosting refers to the service of storing and sharing website files with users over the internet.
2. A web host is a company that provides space on a server to store the files for a website and allows users to access those files via the internet.
3. The main types of web hosting are:
- Shared hosting: Multiple websites are hosted on the same server and share its resources. Inexpensive but can face performance issues during high traffic.
- VPS hosting: A virtual private server is allocated to the website providing more resources than shared hosting. More customizable but costlier than shared hosting.
- Dedicated hosting: The entire server is rented out for a website providing maximum speed and resources but is the most expensive option.
4. Key factors to consider when choosing a web host are:
- Bandwidth and disk space: Sufficient bandwidth and disk space is required based on the size and traffic of the website.
- Server uptime: The percentage of time the server is operational. Higher the uptime, the more reliable the host. Aim for 99.5% uptime or higher.
- Customer support: Quick support is necessary in case of issues. Evaluate the language, availability and efficiency of the support team.
- Cost: Prices vary based on the type and resources of the hosting plan. Compare prices of different hosts offering similar features.
- Additional features: Evaluate additional features like one-click installations, backups, security features, etc. and how useful they would be for your website.
