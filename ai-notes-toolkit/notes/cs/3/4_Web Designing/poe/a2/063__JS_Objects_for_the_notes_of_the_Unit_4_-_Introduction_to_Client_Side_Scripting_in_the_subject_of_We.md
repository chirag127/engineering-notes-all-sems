### JS Objects for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

1. Objects in JavaScript are a collection of key-value pairs. A key can be a string or a symbol and each key is associated with a value of any type.
2. You can create an object using an object literal - {}. For example: const user = {name: 'John', age: 30};
3. You can access properties using dot notation or bracket notation. For example: user.name or user['name']
4. You can add or update properties at any time. For example: user.age = 31; will update the age property. user.gender = 'male'; will add a new property.
5. You can use objects to model real world things and create more complex data structures.
6. Object methods allow you to define actions for objects. For example: const user = {name: 'John', age: 30, greet: function() { console.log('Hello!'); } }; user.greet(); will call the greet method.
7. This keyword refers to the object that the method is a part of. For example: const user = {name: 'John', age: 30, greet: function() { console.log('Hello, my name is ' + this.name); } }; user.greet(); will print "Hello, my name is John".
8. You can nest objects inside other objects to create more complex data structures. For example: const company = { employees: [{name: 'John'}] };
