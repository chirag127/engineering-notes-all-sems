### Dimension for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style the web pages written in HTML. It separates the presentation of the web page from the HTML content.
3. Using CSS has the following advantages:
- It makes web pages adaptable to different screen sizes and resolutions.
- It allows multiple HTML pages to share a common design format by linking them to a single CSS file.
- It reduces complexities and redundancy in the HTML code.
- It makes it easy to maintain the look and feel of a website. Updates can be made in the CSS and the changes are reflected throughout the website.
4. The various ways to add CSS to an HTML page are:
- Inline styles: Using the "style" attribute in the HTML elements.
- <h1 style="color:blue;">Heading</h1>
- Internal stylesheet: Using a <style> element in the head section.
- External stylesheet: Using a link to point to an external .css file.
- <link rel="stylesheet" href="style.css">
5. The syntax of a CSS rule consists of a selector and a declaration block. The declaration block contains one or more declarations separated by semicolons. Each declaration includes a CSS property and a value.
- For example: h1 {color: blue; font-size: 36px;}
