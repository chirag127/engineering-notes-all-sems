### JS Arrays for the notes of the Unit 4 - Introduction to Client Side Scripting

1. Arrays are used to store multiple values in a single variable.
2. Arrays are ordered collections of values. Each value has an index which is used to access the values.
3. Arrays are created using square brackets []. For example: const fruits = ['Apple', 'Banana', 'Orange']
4. Values in arrays can be accessed using index. Index starts from 0. For example: fruits[0] will give 'Apple'
5. Arrays have a length property that holds the number of items in the array. For example: fruits.length will give 3
6. Arrays are mutable i.e. the values can be changed. For example: fruits[1] = 'Strawberry' will change the value at index 1 to 'Strawberry'
7. Arrays have methods and properties to perform various operations like slice, splice, push, pop etc.
8. JavaScript has multidimensional arrays which are arrays containing other arrays. For example: const matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
