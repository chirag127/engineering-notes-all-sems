### Working with Arrays for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing.

1. An array is a special variable that can hold more than one value at a time.
2. Arrays are used to store multiple values in a single variable.
3. Arrays are indexed based, which means each value is assigned an index number.
4. Arrays are enclosed in [square brackets] with values separated by commas.
5. For example: let colors = ['Red', 'Green', 'Blue']
6. The index of the arrays starts at 0. So the index of the first item is 0, second item is 1 and so on.
7. To access a value from an array, we use the index number. For example: colors[0] will return 'Red'.
8. Array indexes are very flexible. You can use strings, objects or anything as an index. But using numbers is more efficient.
9. The length property returns the number of items in an array. For example: colors.length will return 3.
10. Arrays are very useful for storing and managing collections of data. They make code more efficient and easier to read and maintain.
