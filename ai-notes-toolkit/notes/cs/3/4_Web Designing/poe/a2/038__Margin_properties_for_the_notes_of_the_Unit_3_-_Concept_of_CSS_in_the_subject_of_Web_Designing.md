### Margin properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Margin is the space outside the border. It pushes other elements away from the sides of the elements.
2. Margin can be set for top, right, bottom, and left sides individually using margin-top, margin-right, margin-bottom, and margin-left properties respectively.
3. Margin can be set for all 4 sides at once using margin property.
4. Margin can be set in % and px and other units.
5. Margin can be negative to overlap elements.
6. Margin is transparent and is not a part of the element's background color.
7. Use margin to create space and structure the layout.
8. Do not use margin with inline elements. It has no effect.
9. Margin collapses vertically between two block elements. The greater of the two margins will be used.

The above points cover the key concepts and properties related to margins in CSS. Margins help create space and structure the layout in an effective way. Proper use of margins is important to design a good website layout.
