### Working with Text for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing.

1. Introduction to HTML elements
- HTML elements are the building blocks of a web page that consists of a start tag, content, and an end tag.
- The start and end tags contain the element name surrounded by angle brackets.
- Examples: <html>, <head>, <title>, <body>, <h1>, <p>, etc.

2. Basic HTML elements
- <html> and </html> - defines the HTML document
- <head> and </head> - contains metadata about the document
- <title> and </title> - specifies the title of the web page
- <body> and </body> - contains the visible web page content
- <h1> to <h6> - defines HTML headings
- <p> - defines a paragraph
- <br> - inserts a single line break
- <hr> - inserts a horizontal rule (thematic break)

3. Emphasizing text
- <b> and </b> - defines bold text
- <strong> and </strong> - defines bold text (for important text)
- <i> and </i> - defines italic text
- <em> and </em> - defines italic text (for emphasizing text)
