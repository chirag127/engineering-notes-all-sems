### CSS Advanced for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS Floats
- Float is a CSS positioning property. It can be used to make elements float to the left or right of their container, allowing text and other elements to wrap around it.
- Common uses of floats include making layouts, columns, clearing and more.

2. CSS Flexbox
- Flexbox is a CSS layout mode that makes it easy to align items, distribute space, and more.
- It works by turning elements into flex containers and flex items. You then use various flex properties to control layout.
- Common uses of flexbox include equal height columns, centering content, and creating responsive layouts.

3. CSS Grid
- CSS Grid is a two-dimensional layout system for CSS. It lets you lay content out in rows and columns.
- You define a grid structure on a parent element, then place children elements into the grid areas you want them to appear in.
- Grid is a powerful layout system and is gaining popularity as a newer, improved way to create complex responsive layouts.

4. CSS Transitions
- CSS transitions allow you to animate the change of a CSS property value. This lets you animate elements when they are hovered over, focused, etc.
- You specify the CSS property you want to animate, the duration of the animation, and optionally other details like timing function and delay.
- Transitions are a great way to add subtle animation and interactivity to your website and make the experience more dynamic and interesting for users.
