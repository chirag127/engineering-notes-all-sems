### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style the web pages and control the design/look and feel of a web page.
3. CSS is separated from the HTML content which makes it easier to maintain the website.
4. CSS rules are applied to HTML elements based on selectors. Selectors can be:
- Element selectors: Selects elements based on the element name e.g. h1, p, div etc.
- Class selectors: Selects elements based on the class attribute.
- ID selectors: Selects elements based on the id attribute.
- Universal selector: Selects all elements on the page.
5. CSS properties are applied to selectors and control the appearance of the elements. Some CSS properties are:
- Color: To set the color of the text.
- Background-color: To set the background color of an element.
- Font-size: To control the size of the text.
- Font-family: To specify the font of the text.
- Padding: To add space around the content.
- Margin: To add space outside the border.
- Border: To specify the border width, style and color.
