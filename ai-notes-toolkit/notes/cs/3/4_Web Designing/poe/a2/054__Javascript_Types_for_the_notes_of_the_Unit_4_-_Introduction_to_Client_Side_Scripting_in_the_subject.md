### Javascript Types

1. String - Used to represent text data. Written in double or single quotes. Example: 'Hello' or "Hello"
2. Number - Used to represent numeric data. Example: 5, 10.45, -20
3. Boolean - Used to represent true or false values. Only has two values - true or false. Example: true, false
4. Object - Used to represent more complex data structures. Examples: Array, Date, Function etc.
5. Null - Used to represent unknown or empty value. It is a value that represents nothing.
6. Undefined - Used to represent unassigned values. A variable that has been declared but not assigned has undefined value.

The above points cover the basic data types in Javascript that are used to represent different kinds of data in the scripts. Strings, Numbers and Booleans are primitive data types while Objects, Null and Undefined are complex data types. A clear understanding of Javascript data types is essential to write flawless scripts.
