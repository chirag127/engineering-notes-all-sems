### Align

1. CSS stands for Cascading Style Sheets. It is used to style the web pages and controls the layout of web pages.
2. Some of the key concepts of CSS are:
- Selectors: Selectors are patterns used to select the HTML elements you want to style. Eg: h1, .class, #id, etc.
- Properties: Properties are the styles you want to apply to the selected elements. Eg: color, font-size, background-color, etc.
- Values: Values are the settings or options for a CSS property. Eg: red, 12px, white, etc.
3. There are three ways to implement CSS:
- Inline: Using the style attribute in HTML elements.
- Internal: Using a <style> element in an HTML page.
- External: Using a .css file and linking it to the HTML page.
4. The cascading order or weightage of CSS is:
Inline > Internal > External
This means if there are two selectors targeting the same element, the one defined inline will be applied.
5. Some uses of CSS are:
- Style web pages and control layout
- Create responsive designs
- Ensure web accessibility
- Change the look and feel of a website easily by editing the CSS file
6. Key concepts to know about CSS layout are block vs inline elements, normal flow, flexbox, grid, positioning, float, clear, etc.
