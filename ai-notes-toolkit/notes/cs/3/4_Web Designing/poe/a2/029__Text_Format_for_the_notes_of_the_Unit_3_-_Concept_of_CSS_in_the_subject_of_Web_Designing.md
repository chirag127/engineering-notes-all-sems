### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. It is used to style an HTML document.
3. It separates the presentation of the document from the structure of the document.
4. It can be added to HTML documents in 3 ways:
   1. Inline - using the style attribute in HTML elements
   2. <head> - using a <style> element in the head section
   3. External File - using a link to an external .css file
5. The CSS ruleset consists of a selector and a declaration block.
6. A selector specifies the element(s) to be styled.
7. A declaration block contains one or more declarations separated by semicolons.
8. A declaration includes a property and a value, separated by a colon.
9. CSS properties affect how elements are displayed.
10. Common CSS properties include:
- color - specifies the text color
- background-color - specifies the background color
- font-family - specifies the font face
- font-size - specifies the text size
- text-align - specifies the text alignment
