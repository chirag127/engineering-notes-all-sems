### Web Standards and W3C recommendations for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. Web standards: Web standards are technical standards that define rules and guidelines for designing and developing web pages and web applications to make web pages accessible to all. Some key web standards are:
- HTML: HTML or Hypertext Markup Language is the main web markup language to structure web pages and web applications.
- CSS: CSS or Cascading Style Sheets is used to style the HTML elements and define the layout of web pages.
- JavaScript: JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It is used to create interactive effects within web browsers.

2. W3C or World Wide Web Consortium: W3C is the main international standards organization for the web. It develops and maintains the web standards to promote web accessibility and compatibility. Some key standards defined by W3C are:
- HTML5, CSS3 and ECMAScript: The latest versions of the core web languages - HTML, CSS and JavaScript
- Web Accessibility Initiative (WAI): WAI guidelines to make web content and applications accessible to people with disabilities.
- Internationalization: Standards for internationalization and localization to support different languages and regions.

The above points cover the key web standards and W3C recommendations that are essential to know for designing accessible and compatible web pages and applications. These form the base for the Unit 1 - Introduction to Web Designing.
