### Introduction to HTML

1. HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages.
2. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page semantically.
3. The <html> tag is the root element that defines an HTML document.
4. The <head> tag contains metadata about the HTML document like its title, character encoding, stylesheets, scripts, etc.
5. The <title> tag specifies the title of the HTML document which is displayed in the browser's title bar or on the page's tab.
6. The <body> tag contains the visible page content that is shown to the user on the web browser.
7. Headers are defined using tags like <h1> to <h6>. <h1> is the highest heading level and <h6> is the lowest.
8. Paragraphs are defined using the <p> tag.
9. HTML documents form the structure of a web page and are rendered by web browsers to display the content to users.
10. HTML focuses on the structure and semantics of the content rather than the presentation. CSS and JavaScript are used to style the web page and add interactivity and dynamic functionality respectively.
