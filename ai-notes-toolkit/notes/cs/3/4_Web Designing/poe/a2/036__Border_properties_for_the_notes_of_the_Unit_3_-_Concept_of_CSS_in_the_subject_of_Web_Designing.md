### Border properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing.

1. border-style: This property specifies the style of the border. Values include:
- solid: A solid line
- dotted: A series of dots
- dashed: A series of short lines
- double: Two solid lines
- groove: Appears to be carved into the page
- ridge: Appears to stick out from the page
- inset: Appears to be embedded into the page
- outset: Appears to stick out from the page

2. border-width: This property specifies the width of the border. Values can be in pixels, percentages, or the keyword values thin, medium, or thick.

3. border-color: This property specifies the color of the border. Values can be keywords (such as red or blue), RGB values, HEX codes, HSL values, RGBA values, or HSLA values.

4. border: This is a shorthand property for border-width, border-style, and border-color. Values are applied in the following order: border-style, border-width, border-color. Omitted values will be set to their default values.

5. border-radius: This property rounds the corners of an element's border. Values include pixels, percentages, or the keyword value inherit. Radius values control how "rounded" the corners are.
