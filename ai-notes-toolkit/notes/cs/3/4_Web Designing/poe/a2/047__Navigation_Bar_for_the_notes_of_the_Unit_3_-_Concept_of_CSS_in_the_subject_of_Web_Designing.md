### Navigation Bar for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Introduction to CSS
- CSS stands for Cascading Style Sheets.
- It is used to style a web page and control the appearance of multiple web pages.
- It separates the presentation of a document from the structure (HTML).
- It can be used inline, internal or external.

2. CSS Syntax
- The CSS syntax consists of a selector and a declaration block.
- A selector points to the HTML element to be styled.
- The declaration block contains one or more declarations surrounded by curly braces.
- Each declaration includes a property and a value separated by a colon.
- Multiple declarations are separated by semicolons.

3. CSS Selectors
- CSS selectors are used to "find" (or select) the HTML elements to be styled.
- Different selectors have different uses and precedence.
- Examples: element selector, id selector, class selector, universal selector, etc.
