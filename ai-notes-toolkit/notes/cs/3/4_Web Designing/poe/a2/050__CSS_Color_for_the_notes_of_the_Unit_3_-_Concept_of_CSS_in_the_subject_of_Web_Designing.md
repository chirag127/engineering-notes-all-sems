### CSS Color for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Color can be specified in CSS in a variety of ways:
- RGB values: rgb(255, 0, 0)
- Hex codes: #ff0000
- Color names: red
- HSL: hsl(0, 100%, 50%)
- RGBA and HSLA allow you to specify opacity/transparency

2. Color pickers can help you find the color you want and will show you the different formats for that color.

3. Contrast and accessibility: Ensure there is adequate color contrast for text, especially for those with visual impairments. Use a color contrast checker or follow WCAG guidelines.

4. Default colors: If no color is specified for an element, it will inherit the color of its parent element. The very top element (html) has default colors set (often black for text, white/gray for backgrounds).

5. Multiple colors can be specified for gradients, text shadows, box shadows etc. to create certain effects.
