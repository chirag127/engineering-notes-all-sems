### Using FTP Client for the notes of the Unit 5 - Web Hosting in the subject of Web Designing.

1. FTP or File Transfer Protocol is a network protocol used to transfer files between a client and a server over a network.
2. An FTP client is a software which is used to transfer files to and from an FTP server. Some popular FTP clients are FileZilla, WinSCP, Cyberduck etc.
3. To connect to an FTP server, you need the FTP server address, username and password. Enter these details in the FTP client to connect to the server.
4. After connecting to the FTP server, you will see two panels - local site and remote site. The local site shows your local computer and the remote site shows the FTP server's file structure.
5. To upload files to the FTP server, drag and drop files from local site to remote site or click on upload button and select files. Similarly, to download files from FTP server, drag and drop from remote site to local site or click on download button.
6. FTP clients are commonly used to upload website files to web servers. Web hosting companies provide FTP access to upload files to the web server.
7. While uploading/downloading files, choose the file transfer mode as binary for images and other files or auto for normal text files. This is to ensure proper transfer of files.
