### Pseudo class for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Pseudo-classes are used to add special effects to certain states of an element.
2. Some of the commonly used pseudo-classes are:
- :hover - Applies a style when the user's mouse pointer hovers over an element.
- :active - Applies a style when an element is activated by the user.
- :focus - Applies a style when an element has focus.
- :first-child - Applies a style to an element that is the first child of some other element.
- :last-child - Applies a style to an element that is the last child of some other element.
3. Pseudo-classes always start with a colon (:) followed by the name of the pseudo-class and are added to a selector as if they were a class.
4. They enable you to add special effects to your web pages without using classes or IDs.
5. Examples:

p:hover {
  background-color: yellow;
}

div:active {
  border-style: dotted;
}

input:focus {
  background-color: lightgray;
}
