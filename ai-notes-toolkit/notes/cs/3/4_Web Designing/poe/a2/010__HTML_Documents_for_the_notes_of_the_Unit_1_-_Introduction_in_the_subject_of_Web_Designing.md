### HTML Documents for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages.
2. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page semantically.
3. The <html> tag defines the root of an HTML document. It consists of a <head> and a <body> section.
4. The <head> section contains metadata about the HTML document such as the title, scripts, stylesheets, etc. The <title> tag specifies the title of the web page.
5. The <body> section contains the visible content of the web page like headings, paragraphs, images, videos, etc.
6. HTML elements are represented by tags. Tags usually come in pairs - an opening tag and a closing tag. The closing tag has a forward slash (/).
7. Attributes provide additional information about elements. They are always specified in the opening tag and have a name and value separated by =.
8. HTML documents can be viewed directly in the browser without any styling by using the .html or .htm file extension.
9. HTML is easy to learn and is platform and browser independent. It forms the structure of a web page and provides semantic meaning to the content.
