### Javascript Types

In Javascript, every value has a type, and these types can be divided into two categories: primitive types and object types. Understanding the different types is crucial for working with Javascript.

#### Primitive Types

1. **Number:** Represents both integer and floating point numbers. Example: `42`, `3.14`.

2. **String:** Represents a sequence of characters. Example: `"Hello, World!"`.

3. **Boolean:** Represents a logical value, either `true` or `false`.

4. **Undefined:** Represents a variable that has been declared but not assigned a value.

5. **Null:** Represents a deliberate non-value.

6. **Symbol:** A new primitive type introduced in ECMAScript 6 that represents a unique identifier.

#### Object Types

1. **Object:** An object is a collection of properties, where each property has a name and a value. Example: `let person = {name: "John", age: 30};`.

2. **Array:** An ordered list of values. Example: `let fruits = ["Apple", "Banana", "Orange"];`.

3. **Function:** A block of code that can be called by name. Example: `function add(a, b) {return a + b;}`.

4. **Date:** Represents a date and time. Example: `let today = new Date();`.

5. **RegExp:** Represents a regular expression. Example: `let regExp = /[A-Z]/;`.

6. **Error:** Represents an error that occurred during the execution of code. Example: `throw new Error("Something went wrong");`.

Knowing the types in Javascript is important for understanding how variables work, how functions are called, and how to manipulate data. It is essential for becoming proficient in client-side scripting for web designing.
