### Display for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS or Cascading Style Sheets is an important concept in Web Designing. It is used to control the appearance and layout of a webpage. Here are some important points to keep in mind while studying CSS:

- CSS stands for Cascading Style Sheets.
- CSS is used to style HTML elements.
- CSS can be applied to an HTML document in three ways: inline, internal, or external.
- The syntax of CSS is simple and consists of a selector followed by a set of properties and values.
- Selectors are used to target HTML elements, and properties and values are used to define the styling of those elements.
- CSS allows for a wide range of styling options, including font size, color, background color, margin, padding, border, and more.
- CSS also allows for the creation of responsive designs, which can adjust to different screen sizes and devices.
- CSS can be used to create animations and transitions, adding movement and interactivity to a webpage.
- CSS frameworks, such as Bootstrap, provide pre-made styling options and layouts for web developers to use.
- CSS preprocessors, such as Sass and Less, allow for more advanced and efficient coding techniques, including variables, mixins, and functions.

By understanding the concept of CSS and its various applications, a web designer can create visually appealing and functional websites.
