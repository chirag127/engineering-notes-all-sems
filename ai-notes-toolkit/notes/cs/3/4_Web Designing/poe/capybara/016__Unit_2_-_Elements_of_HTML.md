## Unit 2 - Elements of HTML

HTML, or HyperText Markup Language, is the foundation of the World Wide Web. It is the standard markup language used to create web pages. In this unit, we will discuss the various elements of HTML that are essential in creating a web page.

### Basic Structure of an HTML Document

1. HTML documents consist of two main parts: the head and the body. 
2. The head section contains information about the document, such as the title of the page, keywords, and author. 
3. The body section contains the actual content of the document, such as text, images, and links. 

### HTML Tags

1. HTML tags are used to define the structure and content of a web page. 
2. Tags are enclosed in angle brackets, such as `<tag>`. 
3. Tags have opening and closing tags, such as `<tag></tag>`. 
4. Some tags are self-closing, such as `<img />`. 

### Common HTML Tags

1. `<h1>` to `<h6>`: Heading tags, used to define headings and subheadings. 
2. `<p>`: Paragraph tag, used to define a paragraph of text. 
3. `<a>`: Anchor tag, used to create links to other web pages or sections within the same page. 
4. `<img>`: Image tag, used to insert images into the web page. 
5. `<ul>` and `<li>`: Unordered list and list item tags, used to create bulleted lists. 
6. `<ol>` and `<li>`: Ordered list and list item tags, used to create numbered lists. 
7. `<div>`: Division tag, used to group elements together. 
8. `<span>`: Span tag, used to apply styles to a small section of text. 

### Attributes

1. Attributes provide additional information to HTML tags. 
2. Attributes are included within the opening tag, such as `<tag attribute="value">`. 
3. Common attributes include `class`, `id`, `src`, `href`, and `style`. 

### HTML Entities

1. HTML entities are special characters that cannot be typed on a keyboard. 
2. Entities are represented by their entity name or entity number, such as `&copy;` or `&#169;`. 
3. Entities are used to display special characters, such as copyright symbols, trademarks, and currency symbols. 

By understanding the elements of HTML, you can create well-structured and organized web pages. Remember to use proper syntax and follow best practices to ensure that your web pages are compatible with all browsers and devices.
