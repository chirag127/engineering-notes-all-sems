### Working with Lists and Tables

In web designing, lists and tables are important components for displaying information. Here are some key points to keep in mind when working with lists and tables using CSS:

#### Lists

- There are two types of lists in HTML: ordered lists (OL) and unordered lists (UL).
- Ordered lists are used for displaying items in a numbered or lettered sequence, while unordered lists are used for displaying items with bullet points.
- To style lists using CSS, you can target the OL or UL element and apply styles to the list items (LI) within it.
- Common list styles include changing the color or shape of the bullet points, adjusting the indentation, and adding background colors or borders to the list.

#### Tables

- Tables are used for displaying tabular data in rows and columns.
- In HTML, tables are created using the table, tr, and td elements. The table element defines the table, the tr element defines the row, and the td element defines the cell within the row.
- To style tables using CSS, you can target the table, tr, and td elements and apply styles to them. Common table styles include changing the font size, adjusting the padding and spacing, and adding borders to the table or cells.
- Additionally, you can use the :hover pseudo-class to apply styles to cells when the user hovers over them.

By understanding the basics of working with lists and tables, you can create visually appealing and organized displays of information on your website.
