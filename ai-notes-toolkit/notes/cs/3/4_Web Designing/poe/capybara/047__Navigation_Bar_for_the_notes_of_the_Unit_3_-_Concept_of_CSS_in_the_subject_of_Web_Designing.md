### Navigation Bar for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

A navigation bar is an essential element in any web page as it helps users navigate through the website. The following points highlight the key concepts of creating a navigation bar using CSS:

- The first step in creating a navigation bar is to create an HTML structure for it. This structure typically includes an unordered list `<ul>` and list items `<li>`. Each list item represents a menu item in the navigation bar.

- Once the HTML structure is in place, the next step is to apply CSS styles to it. CSS styles can be used to change the font, color, size, and spacing of the navigation bar.

- One popular technique for creating a navigation bar is to use CSS floats. This involves floating the list items to the left and setting a width for each item. This technique allows for easy customization of the navigation bar and can be used to create dropdown menus.

- Another technique for creating a navigation bar is to use CSS flexbox. This technique is more modern and allows for more flexible layouts. Flexbox can be used to create both horizontal and vertical navigation bars.

- The hover effect is a popular technique for adding interactivity to a navigation bar. This involves changing the background color or text color of the menu item when the user hovers over it.

- The active or current menu item is another important concept in navigation bars. This is the menu item that represents the current page the user is on. Adding a different style to the active menu item helps users identify where they are on the website.

- Responsive design is another key concept when creating a navigation bar. This involves creating a navigation bar that adapts to different screen sizes, making it easy for users to navigate on mobile devices.

In summary, creating a navigation bar using CSS involves creating an HTML structure, applying CSS styles, using techniques such as floats or flexbox, adding interactivity, highlighting the active menu item, and ensuring responsive design.
