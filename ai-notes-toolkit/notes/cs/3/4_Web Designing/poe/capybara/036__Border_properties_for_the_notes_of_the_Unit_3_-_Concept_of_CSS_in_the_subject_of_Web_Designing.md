### Border Properties for the Notes of Unit 3 - Concept of CSS in the Subject of Web Designing

In CSS, the border property is used to define the border around an HTML element. The border property consists of three main parts: border-width, border-style, and border-color. Here are some important points to keep in mind when working with border properties:

- `border-width`: This property defines the thickness of the border. It can be specified using different units like pixels, ems or percentages. The default value is `medium`.

- `border-style`: This property defines the style of the border. It can be solid, dotted, dashed, double, groove, ridge, inset or outset. The default value is `none`.

- `border-color`: This property defines the color of the border. It can be specified using different formats like color names, RGB values or hexadecimal values. The default value is the color of the element.

- `border`: This property is a shorthand for setting all the three properties - `border-width`, `border-style` and `border-color` - in a single line. 

- `border-radius`: This property is used to create rounded corners for an HTML element. It can be specified using different units like pixels, ems or percentages.

- `border-image`: This property is used to define an image as the border of an HTML element.

- `outline`: This property is used to create an outline around an HTML element. It is similar to the border property, but it is not a part of the box model.

These border properties can be used to create visually appealing designs for web pages. It is important to understand the various aspects of border properties in order to make effective use of them in web designing.
