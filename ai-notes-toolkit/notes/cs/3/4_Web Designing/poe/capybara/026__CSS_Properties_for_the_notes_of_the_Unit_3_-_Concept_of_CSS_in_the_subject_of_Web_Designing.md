### CSS Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS (Cascading Style Sheets) is a powerful styling tool used in web designing to enhance the visual appeal of a website. There are various CSS properties that can be used to create stunning designs. In this article, we will discuss some of the most commonly used CSS properties.

1. Background-color:
This property is used to set the background color of an element. It takes a color value as its parameter. For example, background-color: #FFFFFF; sets the background color of an element to white.

2. Font-size:
This property is used to set the font size of an element. It takes a value in pixels, em, or percentage as its parameter. For example, font-size: 16px; sets the font size of an element to 16 pixels.

3. Color:
This property is used to set the color of the text inside an element. It takes a color value as its parameter. For example, color: #000000; sets the color of the text inside an element to black.

4. Border:
This property is used to create a border around an element. It takes three parameters: border-width, border-style, and border-color. For example, border: 1px solid #000000; creates a 1-pixel-wide solid black border around an element.

5. Margin:
This property is used to create space outside an element. It takes a value in pixels, em, or percentage as its parameter. For example, margin: 10px; creates a 10-pixel-wide space outside an element.

6. Padding:
This property is used to create space inside an element. It takes a value in pixels, em, or percentage as its parameter. For example, padding: 10px; creates a 10-pixel-wide space inside an element.

7. Text-align:
This property is used to set the alignment of the text inside an element. It takes four values: left, right, center, and justify. For example, text-align: center; centers the text inside an element.

These are some of the most commonly used CSS properties. By using these properties creatively, web designers can create beautiful and visually appealing websites.
