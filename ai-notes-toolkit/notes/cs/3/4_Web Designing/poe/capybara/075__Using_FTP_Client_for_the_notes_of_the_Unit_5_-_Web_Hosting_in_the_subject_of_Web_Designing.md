### Using FTP Client for the notes of the Unit 5 - Web Hosting in the subject of Web Designing

FTP (File Transfer Protocol) is a standard network protocol used to transfer files from one host to another over the internet. It is commonly used by web developers to transfer website files to a web hosting server. Here are some important points to keep in mind while using an FTP client for web hosting:

- Choose a reliable FTP client: There are several FTP client software available in the market such as FileZilla, Cyberduck, and WinSCP. Choose the one that suits your requirements and is easy to use.

- Connect to your web hosting server: To connect to your web hosting server, you need to enter the FTP credentials provided by your web hosting provider. These credentials include the FTP hostname, username, and password.

- Navigate to the website files: Once you are connected to the web hosting server, navigate to the directory where your website files are stored. This directory is often named "public_html" or "www".

- Transfer files: To transfer files from your local computer to the web hosting server, simply drag and drop the files from your local computer to the remote directory on the web hosting server.

- Set file permissions: Some files on the web server require specific permissions to function properly. For example, PHP files require 644 permissions and directories require 755 permissions. You can set these permissions using the FTP client.

- Check file transfer status: After uploading the files to the web hosting server, it is important to check the file transfer status. This can be done by checking the transfer queue in the FTP client software.

In conclusion, using an FTP client is an important skill for web developers who want to transfer their website files to a web hosting server. By following the above points, you can ensure a smooth and error-free file transfer process.
