### Basic Structure of an HTML Document

HTML stands for HyperText Markup Language, which is used to create web pages. An HTML document is composed of various elements and tags that define the structure of a web page. Here are the basic components of an HTML document:

1. Document Type Declaration (DTD): It specifies the version of HTML used in the document. The current version is HTML5.

2. HTML element: It is the root element of an HTML document and contains all other elements.

3. Head element: It contains information about the document such as the title, metadata, and links to external files.

4. Title element: It specifies the title of the document that appears in the browser tab.

5. Body element: It contains the main content of the document such as text, images, videos, and links.

6. Heading elements: They are used to define headings of different levels such as h1, h2, h3, h4, h5, and h6.

7. Paragraph element: It represents a block of text.

8. Anchor element: It is used to create hyperlinks to other pages or resources.

9. Image element: It is used to insert images into the document.

10. List elements: They are used to create ordered (ol) or unordered (ul) lists.

11. Table element: It is used to create tables that display data in rows and columns.

12. Form element: It is used to create forms that allow users to input data.

13. Style element: It is used to define CSS styles that apply to the document.

14. Script element: It is used to define JavaScript code that executes in the document.

Understanding the basic structure of an HTML document is essential for creating web pages that are well-structured and easy to read. By following these guidelines, you can create web pages that are accessible to all users and optimized for search engines.
