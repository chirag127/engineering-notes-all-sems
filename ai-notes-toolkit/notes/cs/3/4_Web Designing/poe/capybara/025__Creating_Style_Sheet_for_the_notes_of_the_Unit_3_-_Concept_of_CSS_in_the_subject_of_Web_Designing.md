### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

In this unit, we will be learning about the concept of Cascading Style Sheets (CSS) and how to create style sheets for our web pages. Here are some points to keep in mind when creating a style sheet:

- Use the `link` tag to link your style sheet to your HTML document. The `link` tag should be placed within the `head` section of your HTML document.
- Use the `style` tag to define your CSS rules directly within your HTML document. The `style` tag should be placed within the `head` section of your HTML document.
- Use the `id` and `class` attributes to target specific HTML elements and apply styles to them.
- Use the `color`, `font-family`, `font-size`, `text-align`, and `background-color` properties to style your text and background.
- Use the `border` property to add borders to your HTML elements.
- Use the `padding` and `margin` properties to add spacing around your HTML elements.
- Use the `display` property to control how your HTML elements are displayed on the page.
- Use the `float` property to position your HTML elements horizontally.
- Use the `position` property to position your HTML elements absolutely or relatively.
- Use the `z-index` property to control the stacking order of your HTML elements.

By following these guidelines, you can create a well-organized and visually-appealing style sheet for your web pages. Good luck with your CSS styling!
