### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

In web designing, markup tags are used to structure the content and define its meaning. Here are some of the markup tags that are commonly used in web designing:

- `<html>` tag: This tag is used to define the start of an HTML document. It is the root tag of an HTML document and all other tags are nested within it.
- `<head>` tag: This tag is used to define the head section of an HTML document. It contains the title of the document, metadata, and other important information that is not displayed on the web page.
- `<body>` tag: This tag is used to define the body section of an HTML document. It contains all the visible content of the web page such as text, images, videos, etc.
- `<h1>` to `<h6>` tags: These tags are used to define headings of different levels. `<h1>` being the main heading and `<h6>` being the smallest heading.
- `<p>` tag: This tag is used to define a paragraph of text.
- `<a>` tag: This tag is used to define a hyperlink. It is used to link one web page to another or to a specific section within the same web page.
- `<img>` tag: This tag is used to insert an image into an HTML document.
- `<ul>` and `<li>` tags: These tags are used to define an unordered list. `<ul>` tag defines the unordered list and `<li>` tag defines each list item.
- `<ol>` and `<li>` tags: These tags are used to define an ordered list. `<ol>` tag defines the ordered list and `<li>` tag defines each list item.
- `<div>` tag: This tag is used to define a section of an HTML document. It is used to group together related elements and apply styles to them.

These are some of the commonly used markup tags in web designing. Understanding these tags is crucial for creating well-structured and semantic HTML documents.
