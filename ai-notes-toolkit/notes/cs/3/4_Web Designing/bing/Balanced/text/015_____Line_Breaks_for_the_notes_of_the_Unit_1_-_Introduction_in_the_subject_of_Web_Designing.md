### Line Breaks

- Line breaks are used to create a new line in a text without starting a new paragraph.
- In HTML, line breaks are created by using the `<br>` tag, which is an empty element that does not need a closing tag.
- The `<br>` tag can be used within any block-level or inline element, such as `<p>`, `<div>`, `<span>`, etc.
- The `<br>` tag is useful for formatting text that has a specific layout, such as addresses, poems, or song lyrics.
- The `<br>` tag should not be used to create extra space between elements, as this can be done with CSS properties such as `margin` or `padding`.
- The `<br>` tag should also not be used to separate paragraphs, as this can be done with the `<p>` tag or other semantic elements.
