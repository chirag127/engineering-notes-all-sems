### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

- A markup tag is a piece of code that defines how the content of a document should be formatted, displayed, or processed.
- Markup tags are usually enclosed in angle brackets (< and >) and can have attributes that provide additional information or options for the tag.
- Markup tags can be classified into two types: structural and presentational.
- Structural tags describe the logical structure or meaning of the document, such as headings, paragraphs, lists, tables, etc. They are independent of the appearance or presentation of the document.
- Presentational tags specify how the content of the document should look or sound, such as font size, color, alignment, etc. They are dependent on the medium or device that displays or renders the document.
- Some examples of structural tags are: `<h1>`, `<p>`, `<ul>`, `<table>`, etc.
- Some examples of presentational tags are: `<b>`, `<i>`, `<font>`, `<center>`, etc.
- Markup tags can be nested, which means that one tag can contain another tag inside it. For example, `<p><b>This is a bold paragraph.</b></p>`.
- Markup tags can also be self-closing, which means that they do not need a closing tag. For example, `<br>` is a tag that inserts a line break in the document.
