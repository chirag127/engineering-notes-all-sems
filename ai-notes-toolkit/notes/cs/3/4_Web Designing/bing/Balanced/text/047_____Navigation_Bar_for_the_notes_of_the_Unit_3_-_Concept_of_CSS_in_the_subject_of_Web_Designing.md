### Navigation Bar

- A navigation bar is a user interface element that provides links to different sections or pages of a website.
- A navigation bar can be horizontal or vertical, depending on the layout and design of the website.
- A navigation bar can be created using HTML elements such as `<nav>`, `<ul>`, `<li>`, and `<a>`, or using CSS properties such as `display`, `flex`, `grid`, `position`, `float`, `margin`, `padding`, `border`, `background`, `color`, `font`, etc.
- A navigation bar can be styled using CSS selectors, pseudo-classes, pseudo-elements, and media queries to achieve different effects and responsiveness.
- A navigation bar can be enhanced using JavaScript or jQuery to add interactivity, animation, or dynamic features.
