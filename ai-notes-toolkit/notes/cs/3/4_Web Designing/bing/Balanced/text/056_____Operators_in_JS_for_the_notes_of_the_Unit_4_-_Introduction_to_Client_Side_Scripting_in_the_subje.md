### Operators in JS for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- Operators are symbols that perform some operations on one or more operands (values or variables).
- JavaScript supports the following types of operators:
  - Arithmetic operators: perform mathematical calculations on numeric operands, such as `+`, `-`, `*`, `/`, `%`, `**`, `++`, `--`.
  - Assignment operators: assign a value to a variable, such as `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`.
  - Comparison operators: compare two operands and return a boolean value (true or false), such as `==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`.
  - Logical operators: combine two or more boolean values and return a boolean value, such as `&&`, `||`, `!`.
  - Bitwise operators: perform bitwise operations on integer operands, such as `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`.
  - String operators: concatenate (join) two or more strings, such as `+`, `+=`.
  - Conditional (ternary) operator: evaluate a condition and return one of two values, such as `condition ? value1 : value2`.
  - Comma operator: evaluate two or more expressions and return the value of the last expression, such as `expr1, expr2, expr3`.
  - Unary operators: perform an operation on a single operand, such as `delete`, `typeof`, `void`.
  - Relational operators: test the relationship between an object and its prototype chain, such as `in`, `instanceof`.
- Operators have different precedence (priority) levels, which determine the order of evaluation in an expression. Operators with higher precedence are evaluated before operators with lower precedence. Parentheses can be used to change the order of evaluation and group sub-expressions.
