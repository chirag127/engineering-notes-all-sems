### What is HTML

- HTML stands for **HyperText Markup Language**  .
- HTML is the **standard markup language** for creating web pages and web applications .
- HTML describes the **structure** and **content** of a web page using **HTML elements**  .
- HTML elements are the **building blocks** of a web page. They consist of **tags** and **attributes**  .
- HTML tags are used to **enclose** or **wrap** different parts of the content and make them appear or act a certain way.
- HTML attributes are used to **provide additional information** about the elements or **modify their behavior**  .
- HTML elements can be **nested** inside other elements to create complex layouts and designs  .
- HTML elements can also **link** to other web pages or resources using the **href** attribute  .
- HTML documents have a **standard structure** that includes a **doctype declaration**, a **head** section, and a **body** section  .
- The **doctype declaration** tells the browser which version of HTML the document is using  .
- The **head** section contains **metadata** about the document, such as the **title**, the **character encoding**, and the **style sheets**  .
- The **body** section contains the **visible content** of the document, such as the **headings**, the **paragraphs**, the **images**, and the **tables**  .
- HTML documents can be **styled** using **CSS** (Cascading Style Sheets), which is a separate language that defines how HTML elements should look  .
- HTML documents can also be **enhanced** using **JavaScript**, which is a separate language that adds interactivity and functionality to HTML elements  .
