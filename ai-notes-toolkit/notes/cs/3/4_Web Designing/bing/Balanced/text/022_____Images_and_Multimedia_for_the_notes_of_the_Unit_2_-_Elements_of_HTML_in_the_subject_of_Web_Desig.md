### Images and Multimedia for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

- Images and multimedia are essential elements of web design that can enhance the appearance and functionality of web pages.
- Images can be used to display logos, icons, photos, diagrams, charts, etc. Multimedia can be used to play audio, video, animation, etc.
- HTML provides several tags and attributes to embed images and multimedia in web pages, such as `<img>`, `<audio>`, `<video>`, `<source>`, `<track>`, etc.
- The `<img>` tag is used to insert an image in a web page. It has several attributes, such as `src`, `alt`, `width`, `height`, `align`, etc. The `src` attribute specifies the URL of the image file. The `alt` attribute provides an alternative text for the image in case it cannot be displayed. The `width` and `height` attributes specify the dimensions of the image in pixels. The `align` attribute specifies the alignment of the image relative to the surrounding text, such as `left`, `right`, `top`, `middle`, `bottom`, etc.
- The `<audio>` tag is used to insert an audio file in a web page. It has several attributes, such as `src`, `controls`, `autoplay`, `loop`, `muted`, etc. The `src` attribute specifies the URL of the audio file. The `controls` attribute displays the audio player with play, pause, volume, etc. The `autoplay` attribute automatically plays the audio when the page loads. The `loop` attribute repeats the audio indefinitely. The `muted` attribute silences the audio by default.
- The `<video>` tag is used to insert a video file in a web page. It has several attributes, such as `src`, `controls`, `autoplay`, `loop`, `muted`, `width`, `height`, `poster`, etc. The `src` attribute specifies the URL of the video file. The `controls` attribute displays the video player with play, pause, volume, etc. The `autoplay` attribute automatically plays the video when the page loads. The `loop` attribute repeats the video indefinitely. The `muted` attribute silences the video by default. The `width` and `height` attributes specify the dimensions of the video in pixels. The `poster` attribute specifies the URL of an image to show before the video starts playing.
- The `<source>` tag is used to specify multiple sources for the `<audio>` or `<video>` tag, in case the browser does not support the default format. It has two attributes, `src` and `type`. The `src` attribute specifies the URL of the alternative source file. The `type` attribute specifies the MIME type of the source file, such as `audio/mpeg`, `video/mp4`, etc.
- The `<track>` tag is used to add subtitles, captions, descriptions, or chapters to the `<audio>` or `<video>` tag. It has several attributes, such as `src`, `kind`, `label`, `srclang`, `default`, etc. The `src` attribute specifies the URL of the track file, which must be in WebVTT format. The `kind` attribute specifies the type of the track, such as `subtitles`, `captions`, `descriptions`, or `chapters`. The `label` attribute specifies the name of the track, which is displayed in the track menu. The `srclang` attribute specifies the language of the track, using a valid BCP 47 language tag. The `default` attribute indicates that the track is selected by default.
