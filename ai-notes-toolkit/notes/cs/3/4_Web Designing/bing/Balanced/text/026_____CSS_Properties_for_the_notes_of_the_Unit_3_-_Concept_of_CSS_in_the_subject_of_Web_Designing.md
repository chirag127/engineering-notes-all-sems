### CSS Properties

- CSS properties are the attributes that define how HTML elements are styled and displayed on a web page.
- CSS properties are specified in a style sheet, either internally (within the `<style>` tag) or externally (in a separate file with the `.css` extension).
- CSS properties are written as key-value pairs, separated by a colon and followed by a semicolon. For example, `color: red;` sets the text color to red.
- CSS properties can be grouped into categories based on their function and effect. Some of the common categories are:

  - **Text properties**: These properties control the appearance and layout of text, such as font, size, color, alignment, spacing, decoration, etc. For example, `font-family: Arial;` sets the font of the text to Arial.
  - **Background properties**: These properties control the background of an element, such as color, image, position, size, repeat, etc. For example, `background-color: yellow;` sets the background color of the element to yellow.
  - **Border properties**: These properties control the border of an element, such as width, style, color, radius, etc. For example, `border: 2px solid black;` sets the border of the element to 2 pixels wide, solid and black.
  - **Box model properties**: These properties control the dimensions and spacing of an element, such as width, height, margin, padding, border, etc. For example, `width: 50%;` sets the width of the element to 50% of its parent element's width.
  - **Layout properties**: These properties control the position and arrangement of elements on a web page, such as display, position, float, clear, flex, grid, etc. For example, `display: block;` sets the element to be displayed as a block-level element, which occupies the entire horizontal space.
  - **Transform properties**: These properties control the transformation of an element, such as rotate, scale, skew, translate, etc. For example, `transform: rotate(45deg);` rotates the element by 45 degrees clockwise.
  - **Transition properties**: These properties control the animation of an element when its state changes, such as duration, timing-function, delay, etc. For example, `transition: all 0.5s ease-in-out;` applies a smooth transition to all the properties of the element that change over 0.5 seconds.
  - **Other properties**: There are many other properties that can be used to style and enhance the web page, such as opacity, filter, clip-path, box-shadow, etc. For example, `opacity: 0.5;` sets the opacity of the element to 0.5, which makes it semi-transparent.
