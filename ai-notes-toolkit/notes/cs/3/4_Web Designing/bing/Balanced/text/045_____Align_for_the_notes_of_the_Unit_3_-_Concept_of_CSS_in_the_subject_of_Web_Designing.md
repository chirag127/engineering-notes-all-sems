### Align for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for **Cascading Style Sheets** and is used to **style and layout web pages** .
- CSS is a **rule-based language** that allows you to define the **presentation** of a document written in HTML or XML.
- CSS rules consist of **selectors** and **declarations**. Selectors are used to **target** the elements or groups of elements that you want to style. Declarations are used to **specify** the properties and values that you want to apply to the selected elements.
- CSS rules can be written in three ways: **inline**, **internal**, or **external**. Inline CSS is written directly in the HTML element using the `style` attribute. Internal CSS is written in the `<head>` section of the HTML document using the `<style>` tag. External CSS is written in a separate file with the `.css` extension and linked to the HTML document using the `<link>` tag.
- CSS has many advantages over using HTML alone for styling web pages, such as:
  - **Separation of content and presentation**: CSS allows you to keep the structure and content of your web page separate from its appearance and layout, making it easier to maintain and update.
  - **Consistency and reusability**: CSS allows you to apply the same style rules to multiple elements or pages, ensuring a consistent look and feel across your website and reducing code duplication.
  - **Flexibility and control**: CSS gives you more options and control over how your web page is displayed on different devices, browsers, and screen sizes, allowing you to create responsive and adaptive designs.
  - **Enhanced features and effects**: CSS enables you to add animations, transitions, transformations, filters, and other decorative features to your web page, making it more interactive and engaging.
