### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page.
- CSS allows web developers to separate the presentation of a web page from its content and structure. This makes it easier to maintain, update and reuse the web design.
- CSS can control various aspects of the web page appearance, such as fonts, colors, backgrounds, borders, margins, padding, alignment, layout, etc.
- CSS can also create dynamic effects, such as transitions, animations, transformations, filters, etc. that enhance the user experience and interactivity of the web page.
- CSS can be applied to HTML elements in three ways: inline, internal and external. Inline CSS is written inside the HTML element using the style attribute. Internal CSS is written inside the head section of the HTML document using the style tag. External CSS is written in a separate file with the .css extension and linked to the HTML document using the link tag.
- CSS follows a set of rules or syntax that defines how to select and style HTML elements. A CSS rule consists of a selector and a declaration block. A selector specifies which HTML element or elements to apply the style to. A declaration block contains one or more declarations that define the style properties and values for the selected element or elements. A declaration consists of a property and a value, separated by a colon and ending with a semicolon. A declaration block is enclosed by curly braces.
- CSS has a cascading order that determines which style rule has priority over another when there are conflicting or overlapping styles. The cascading order is based on the following factors: specificity, inheritance and source order. Specificity is a measure of how specific a selector is. Inheritance is the mechanism by which some style properties are passed from parent elements to child elements. Source order is the order in which the style rules are written or loaded in the HTML document.
- CSS can be enhanced by using preprocessors, frameworks and libraries that provide additional features and functionalities. Preprocessors are tools that extend the CSS syntax and allow the use of variables, mixins, functions, nesting, etc. Frameworks are collections of predefined CSS rules and classes that provide a consistent and responsive web design. Libraries are collections of reusable CSS components and effects that can be easily integrated into a web page. Some examples of preprocessors are Sass, Less and Stylus. Some examples of frameworks are Bootstrap, Foundation and Bulma. Some examples of libraries are Animate.css, Hover.css and Font Awesome.
