### Display for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets and is used to style and layout web pages .
- CSS is a rule-based language that allows you to define the rules by specifying groups of styles that should be applied to particular elements or groups of elements on your web page.
- CSS can alter the font, color, size, and spacing of your content, split it into multiple columns, or add animations and other decorative features.
- CSS can also describe how elements should be rendered on different media, such as screen, paper, speech, or other devices.
- CSS works by associating rules with HTML elements. A rule consists of a selector and a declaration block. A selector is a pattern that matches some elements on the web page. A declaration block contains one or more declarations, which are property-value pairs that specify the style of the selected elements.
- For example, the following CSS rule applies a red color to all the paragraphs on the web page:

```css
p {
  color: red;
}
```

- The selector is `p`, which matches all the `<p>` elements in the HTML document. The declaration block contains one declaration, which sets the `color` property to `red`.
- CSS rules can be written in a separate file with a `.css` extension, or embedded in the `<style>` element in the HTML document, or inline in the `style` attribute of an HTML element.
- CSS has a cascading mechanism that determines how conflicting rules are resolved. The cascade takes into account the source, specificity, and order of the rules, and applies the rule with the highest priority to the element.
- CSS also has a inheritance mechanism that allows some properties to be inherited from the parent element to the child element, unless overridden by a more specific rule.
- CSS has various modules that define different aspects of web design, such as colors, fonts, backgrounds, borders, layouts, animations, transitions, transforms, grids, flexbox, etc.
- CSS is constantly evolving and new features are added regularly. The current version of CSS is CSS3, which is divided into several levels and specifications.
