### Operators in JS

Operators are special symbols that perform operations on values and variables. They are used to manipulate data and perform calculations. Operators can be classified into different types based on their function and syntax. Here are some of the common types of operators in JavaScript:

- **Arithmetic operators**: These operators perform basic mathematical operations such as addition, subtraction, multiplication, division, remainder, exponentiation, increment, and decrement. For example, `2 + 3` returns `5`, `4 / 2` returns `2`, `5 % 2` returns `1`, `2 ** 3` returns `8`, `x++` increases the value of `x` by `1`, and `y--` decreases the value of `y` by `1`.
- **Assignment operators**: These operators assign a value to a variable. The basic assignment operator is `=`, which assigns the value of the right operand to the left operand. For example, `x = 5` assigns `5` to `x`. There are also compound assignment operators that combine an arithmetic or bitwise operator with an assignment. For example, `x += 5` is equivalent to `x = x + 5`, `y -= 2` is equivalent to `y = y - 2`, `z *= 3` is equivalent to `z = z * 3`, and so on.
- **Comparison operators**: These operators compare two values and return a boolean value (`true` or `false`) based on the result of the comparison. There are two types of comparison operators: equality and relational. Equality operators check if the values are equal or not, while relational operators check if the values are greater than, less than, or equal to each other. For example, `2 == 2` returns `true`, `2 != 3` returns `true`, `2 > 3` returns `false`, `2 <= 2` returns `true`, and so on. There are also strict equality operators (`===` and `!==`) that check not only the value but also the type of the operands. For example, `2 === "2"` returns `false`, because `2` is a number and `"2"` is a string, while `2 == "2"` returns `true`, because the values are converted to the same type before comparison.
- **Logical operators**: These operators perform logical operations on boolean values or expressions that evaluate to boolean values. They are used to combine or negate conditions. The logical operators are `&&` (logical AND), `||` (logical OR), and `!` (logical NOT). For example, `true && false` returns `false`, `true || false` returns `true`, `!true` returns `false`, and so on. The logical operators can also use short-circuit evaluation, which means that the second operand is evaluated only if the first operand is not enough to determine the result. For example, `true || x` returns `true` without evaluating `x`, because `true` is enough to make the expression `true`.
- **Bitwise operators**: These operators perform operations on the binary representation of the values. They are used to manipulate individual bits or perform low-level operations. The bitwise operators are `&` (bitwise AND), `|` (bitwise OR), `^` (bitwise XOR), `~` (bitwise NOT), `<<` (left shift), `>>` (right shift), and `>>>` (unsigned right shift). For example, `5 & 3` returns `1`, because the binary representation of `5` is `0101` and the binary representation of `3` is `0011`, and the bitwise AND operation returns `0001`, which is `1` in decimal. Similarly, `5 | 3` returns `7`, because the bitwise OR operation returns `0111`, which is `7` in decimal. The bitwise operators can also be combined with assignment operators, such as `x &= 3`, `y |= 5`, `z ^= 2`, and so on.
