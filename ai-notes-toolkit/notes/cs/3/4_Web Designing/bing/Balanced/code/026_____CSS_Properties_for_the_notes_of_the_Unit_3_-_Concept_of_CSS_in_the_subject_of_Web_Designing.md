# CSS Properties

CSS properties are used to assign styles or behaviors to HTML elements. CSS properties can be divided into two categories: inherited and non-inherited. Inherited properties are passed from parent elements to their children, while non-inherited properties are applied only to the specified element.

Some of the most common CSS properties are:

- **color**: sets the color of the text content of an element.
- **background-color**: sets the background color of an element.
- **font-family**: sets the font family of the text content of an element.
- **font-size**: sets the size of the font of the text content of an element.
- **font-style**: sets the style of the font of the text content of an element, such as normal, italic, or oblique.
- **font-weight**: sets the weight of the font of the text content of an element, such as normal, bold, or lighter.
- **text-align**: sets the horizontal alignment of the text content of an element, such as left, right, center, or justify.
- **text-decoration**: sets the decoration of the text content of an element, such as none, underline, overline, or line-through.
- **border**: sets the border of an element, which is composed of four sub-properties: border-width, border-style, border-color, and border-radius.
- **margin**: sets the space outside the border of an element, which is composed of four sub-properties: margin-top, margin-right, margin-bottom, and margin-left.
- **padding**: sets the space inside the border of an element, which is composed of four sub-properties: padding-top, padding-right, padding-bottom, and padding-left.
- **display**: sets the display mode of an element, such as block, inline, inline-block, or none.
- **position**: sets the position of an element, such as static, relative, absolute, or fixed.
- **top**, **right**, **bottom**, **left**: sets the offset of an element from its normal position, depending on the value of the position property.
- **width**: sets the width of an element, which can be specified in various units, such as pixels, percentages, or ems.
- **height**: sets the height of an element, which can be specified in various units, such as pixels, percentages, or ems.
- **overflow**: sets how the content of an element is handled when it exceeds the size of the element, such as visible, hidden, scroll, or auto.
- **transform**: applies a transformation to an element, such as rotate, scale, skew, or translate.
- **transition**: specifies a transition effect for an element when its property changes, which is composed of four sub-properties: transition-property, transition-duration, transition-timing-function, and transition-delay.
- **animation**: specifies an animation effect for an element, which is composed of eight sub-properties: animation-name, animation-duration, animation-timing-function, animation-delay, animation-iteration-count, animation-direction, animation-fill-mode, and animation-play-state.
