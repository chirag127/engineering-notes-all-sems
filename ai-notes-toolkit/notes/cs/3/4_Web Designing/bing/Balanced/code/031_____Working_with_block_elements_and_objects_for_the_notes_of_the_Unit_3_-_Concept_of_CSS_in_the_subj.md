### Working with block elements and objects

- Block elements are HTML elements that occupy the entire width of their parent container and start on a new line. Examples of block elements are `<div>`, `<p>`, `<h1>`, `<ul>`, etc.
- Block elements can be styled with CSS properties such as `width`, `height`, `margin`, `padding`, `border`, `background`, etc.
- Block elements can also be positioned with CSS properties such as `position`, `top`, `left`, `right`, `bottom`, `float`, `clear`, etc.
- Objects are HTML elements that can contain other HTML elements or external resources such as images, videos, audio, etc. Examples of objects are `<img>`, `<video>`, `<audio>`, `<iframe>`, `<embed>`, etc.
- Objects can be styled with CSS properties such as `width`, `height`, `margin`, `padding`, `border`, `background`, etc.
- Objects can also be positioned with CSS properties such as `position`, `top`, `left`, `right`, `bottom`, `float`, `clear`, etc.
- Objects can also have attributes that specify their source, type, size, etc. Examples of attributes are `src`, `type`, `width`, `height`, `alt`, `title`, etc.
- Objects can also have events that trigger actions when they are interacted with. Examples of events are `onclick`, `onload`, `onerror`, `onmouseover`, etc.
