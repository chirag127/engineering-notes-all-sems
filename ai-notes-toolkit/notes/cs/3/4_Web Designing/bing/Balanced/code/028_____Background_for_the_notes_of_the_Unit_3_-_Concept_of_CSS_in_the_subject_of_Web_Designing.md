### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page.
- CSS was created in 1996 by the World Wide Web Consortium (W3C) to separate the presentation from the structure and content of HTML documents.
- CSS allows web developers to apply consistent styles, such as fonts, colors, margins, and layouts, to multiple HTML elements and pages.
- CSS also enables web developers to create responsive web design, which means that the web pages can adapt to different screen sizes and devices.
- CSS has three levels of specification: CSS1, CSS2, and CSS3. Each level adds new features and capabilities to the previous one. CSS3 is the latest and most advanced version of CSS, which includes modules such as animations, transitions, transforms, grids, flexbox, and media queries.
- CSS has three ways of applying styles to HTML elements: inline, internal, and external. Inline styles are written directly in the HTML tag using the style attribute. Internal styles are written in the head section of the HTML document using the style element. External styles are written in a separate file with the .css extension and linked to the HTML document using the link element.
- CSS uses selectors to target specific HTML elements and apply styles to them. Selectors can be based on element names, classes, ids, attributes, pseudo-classes, pseudo-elements, or combinations of them. Selectors have different levels of specificity, which determines which style rule has precedence over another in case of a conflict.
- CSS uses properties and values to define the styles for the selected HTML elements. Properties are the aspects of the elements that can be styled, such as color, font-size, border, etc. Values are the possible settings for the properties, such as red, 16px, solid, etc. Properties and values are written in the form of property: value; and enclosed in curly braces {} after the selector.
- CSS uses the cascade, inheritance, and specificity rules to determine how the styles are applied to the HTML elements. The cascade means that the styles are applied in the order of their sources, from the browser's default styles, to the user's preferences, to the author's styles, and finally to the inline styles. Inheritance means that some properties are passed from the parent element to the child element, unless they are overridden by a more specific rule. Specificity means that the more specific a selector is, the higher priority it has over a less specific one.
