### Margin properties

- The margin properties in CSS are used to create space around elements, outside of any defined borders.
- The margin properties can be applied to any element, except elements with display: none or display: table-column-group.
- The margin properties can have one, two, three, or four values, depending on how many sides of the element are specified.
- The margin properties are:

  - margin-top: sets the top margin of an element.
  - margin-right: sets the right margin of an element.
  - margin-bottom: sets the bottom margin of an element.
  - margin-left: sets the left margin of an element.
  - margin: sets all four margins of an element in a shorthand form.

- The values of the margin properties can be:

  - a length value (such as px, em, rem, etc.)
  - a percentage value (relative to the width of the containing element)
  - auto (the browser calculates the margin)
  - inherit (the margin is inherited from the parent element)

- The margin properties can also be negative, which means the element will be moved closer to its adjacent elements.
- The margin properties can create a collapsing effect, which means that if two adjacent elements have margins, the margin between them will be the larger of the two, not the sum of both.
- The margin properties can be overridden by the box-sizing property, which can change how the width and height of an element are calculated.
