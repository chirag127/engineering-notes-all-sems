### JavaScript Loops

- Loops are used to execute a block of code repeatedly until a certain condition is met.
- JavaScript supports different types of loops, such as `for`, `while`, `do...while`, `for...in`, and `for...of`.
- The syntax of a `for` loop is:

```javascript
for (initialization; condition; update) {
  // code block to be executed
}
```

- The initialization statement is executed only once before the loop starts. It is usually used to define and set up a loop counter variable.
- The condition statement is evaluated at the beginning of every loop iteration and will continue as long as it evaluates to true. When the condition is false, the loop will stop.
- The update statement is executed at the end of every loop iteration. It is usually used to increment or decrement the loop counter variable.
- The syntax of a `while` loop is:

```javascript
while (condition) {
  // code block to be executed
}
```

- The condition statement is evaluated before each loop iteration and will continue as long as it evaluates to true. When the condition is false, the loop will stop.
- The syntax of a `do...while` loop is:

```javascript
do {
  // code block to be executed
} while (condition);
```

- The code block will be executed once before the condition is checked. Then the condition statement is evaluated and will continue as long as it evaluates to true. When the condition is false, the loop will stop.
- The syntax of a `for...in` loop is:

```javascript
for (key in object) {
  // code block to be executed
}
```

- The `for...in` loop iterates over the properties of an object. The key variable will hold the name of each property in the object.
- The syntax of a `for...of` loop is:

```javascript
for (value of iterable) {
  // code block to be executed
}
```

- The `for...of` loop iterates over the values of an iterable object, such as an array, a string, or a map. The value variable will hold the value of each element in the iterable object.
- Loops can be controlled by using the `break` and `continue` statements.
- The `break` statement can be used to exit a loop completely.
- The `continue` statement can be used to skip the current iteration of a loop and continue with the next one.
