### HTML Tags
- HTML tags are keywords that define the structure and content of a web page.
- HTML tags are enclosed in angle brackets `<` and `>` and usually come in pairs, such as `<p>` and `</p>`.
- The opening tag `<p>` marks the beginning of a paragraph, and the closing tag `</p>` marks the end of it.
- Some HTML tags are self-closing, meaning they do not need a closing tag. For example, `<br>` is a line break tag that creates a new line on the web page.
- HTML tags can have attributes that provide additional information or functionality to the tag. Attributes are written inside the opening tag, after the tag name, and consist of a name and a value, separated by an equal sign `=`.
- For example, `<img src="image.jpg" alt="A picture of a cat">` is an image tag that has two attributes: `src` and `alt`. The `src` attribute specifies the source of the image file, and the `alt` attribute provides an alternative text for the image in case it cannot be displayed.
- HTML tags can be nested, meaning one tag can contain another tag inside it. For example, `<p><strong>This is a bold paragraph.</strong></p>` is a paragraph tag that contains a strong tag inside it. The strong tag makes the text inside it bold.
- HTML tags are case-insensitive, meaning they can be written in uppercase or lowercase letters. However, it is a good practice to use lowercase letters for consistency and readability.
- HTML tags must follow the syntax rules of HTML, otherwise the web page may not display correctly or as intended. Some of the syntax rules are:
  - Every opening tag must have a matching closing tag, unless it is a self-closing tag.
  - Nested tags must be properly closed in the reverse order of opening. For example, `<p><em>This is an italic paragraph.</em></p>` is correct, but `<p><em>This is an italic paragraph.</p></em>` is not.
  - Attribute values must be enclosed in quotation marks, either single `'` or double `"`.
  - There must be no spaces between the tag name and the first attribute, or between attributes.
  - There must be no spaces or other characters between the angle brackets and the tag name. For example, `< p>` or `<p >` are not valid tags.
