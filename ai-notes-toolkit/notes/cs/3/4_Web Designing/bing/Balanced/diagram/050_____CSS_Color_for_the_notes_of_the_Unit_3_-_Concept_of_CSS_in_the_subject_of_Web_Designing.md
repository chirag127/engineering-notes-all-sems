# CSS Color

- CSS color property is used to set the color of the text, background, border, and other elements in a web page.
- CSS color values can be specified in different ways, such as by name, hexadecimal, RGB, HSL, or using keywords.
- CSS color names are predefined names that represent 140 standard colors, such as `red`, `blue`, `green`, etc.
- CSS hexadecimal values are six-digit codes that start with a `#` sign and represent the amount of red, green, and blue in the color, such as `#FF0000` for red, `#00FF00` for green, and `#0000FF` for blue.
- CSS RGB values are numerical values that specify the amount of red, green, and blue in the color, ranging from 0 to 255, such as `rgb(255, 0, 0)` for red, `rgb(0, 255, 0)` for green, and `rgb(0, 0, 255)` for blue.
- CSS HSL values are numerical values that specify the hue, saturation, and lightness of the color, ranging from 0 to 360 for hue, and from 0% to 100% for saturation and lightness, such as `hsl(0, 100%, 50%)` for red, `hsl(120, 100%, 50%)` for green, and `hsl(240, 100%, 50%)` for blue.
- CSS keywords are special words that represent some common colors, such as `black`, `white`, `transparent`, `currentcolor`, etc.
- CSS color property can be applied to any HTML element using the following syntax:

```css
selector {
  color: value;
}
```

- For example, to set the color of the `<h1>` element to red, we can use the following CSS code:

```css
h1 {
  color: red;
}
```

- To set the background color of the `<body>` element to yellow, we can use the following CSS code:

```css
body {
  background-color: yellow;
}
```

- To set the border color of the `<div>` element to blue, we can use the following CSS code:

```css
div {
  border: 5px solid blue;
}
```

- CSS color property can also be inherited from the parent element, or overridden by the child element, depending on the specificity and cascade rules of CSS.
