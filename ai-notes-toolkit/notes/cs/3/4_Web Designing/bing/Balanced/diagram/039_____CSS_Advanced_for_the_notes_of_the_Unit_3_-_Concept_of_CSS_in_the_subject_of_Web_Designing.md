### CSS Advanced

CSS stands for Cascading Style Sheets. It is a language that is used to style HTML elements, such as fonts, colors, layouts, animations, etc. CSS can be applied to HTML elements in different ways, such as inline, internal, external, or using the `style` attribute.

Some of the advanced topics of CSS are:

- CSS selectors: These are patterns that match HTML elements based on their attributes, classes, ids, pseudo-classes, pseudo-elements, etc. CSS selectors can be combined using combinators, such as descendant, child, adjacent sibling, general sibling, etc. CSS selectors can also be grouped using commas, or nested using pre-processors, such as Sass or Less.
- CSS specificity: This is a measure of how specific a CSS selector is, and how it affects the priority of applying the styles to the matched elements. CSS specificity is calculated based on the number of id, class, attribute, and element selectors in a selector, as well as the order of the selectors and the source of the styles. The higher the specificity, the higher the priority. CSS specificity can be overridden using the `!important` keyword, or by using more specific selectors.
- CSS inheritance: This is a mechanism that allows some CSS properties to be inherited from the parent element to the child element, such as `color`, `font-family`, `font-size`, etc. CSS inheritance can be controlled using the `inherit`, `initial`, or `unset` keywords, or by using more specific selectors.
- CSS cascade: This is a process that determines the final style of an element based on the order and source of the CSS rules that apply to it. CSS cascade follows a set of rules, such as:

  - The origin of the style: The styles can come from different sources, such as user agent (browser), user (preferences), author (web page), or animation (keyframes). The styles from the author have higher priority than the styles from the user, which have higher priority than the styles from the user agent. The styles from the animation have the highest priority.
  - The importance of the style: The styles can be marked as `!important`, which gives them higher priority than the normal styles. The styles marked as `!important` from the author have higher priority than the styles marked as `!important` from the user, which have higher priority than the normal styles from any source.
  - The specificity of the selector: The styles with higher specificity have higher priority than the styles with lower specificity, as explained above.
  - The order of the style: The styles that appear later in the source have higher priority than the styles that appear earlier, if they have the same origin, importance, and specificity.

- CSS box model: This is a concept that describes how the size and layout of an element are affected by its content, padding, border, and margin. The content is the actual text or image inside the element. The padding is the space between the content and the border. The border is the line that surrounds the element. The margin is the space between the border and the adjacent elements. The width and height of an element can be calculated based on the content, padding, and border, or based on the specified values. The box-sizing property can be used to change how the width and height are calculated, such as `content-box` (default), `border-box`, or `padding-box`.
- CSS layout: This is a topic that covers how to arrange and position the elements on a web page, using different techniques, such as:

  - Normal flow: This is the default layout mode, where the elements are placed one after another, following the order and direction of the source code. The elements can be block-level or inline-level, depending on their display property. Block-level elements take up the whole width of their parent element, and start on a new line. Inline-level elements take up only the space needed for their content, and can be on the same line as other inline-level elements. The position property can be used to change the normal flow of an element, such as `static` (default), `relative`, `absolute`, `fixed`, or `sticky`.
  - Floats: This is a technique that allows an element to be taken out of the normal flow, and placed to the left or right of its parent element, or the nearest ancestor that is not `static`. The float property can be used to set the float direction of an element, such as `left`, `right`, or `none` (default).
