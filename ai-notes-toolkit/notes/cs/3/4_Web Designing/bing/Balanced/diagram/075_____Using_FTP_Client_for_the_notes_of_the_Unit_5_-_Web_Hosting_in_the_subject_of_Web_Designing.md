### Using FTP Client

- FTP stands for File Transfer Protocol, which is a standard protocol for transferring files to and from remote machines running FTP servers .
- An FTP client is a software utility that establishes a connection between a host computer and a remote server, typically an FTP server .
- An FTP client provides the dual-direction transfer of data and files between two computers over a TCP network or an Internet connection .
- An FTP client allows the user to upload, download, or move files on the server, as well as create, delete, or rename directories .
- Some examples of FTP clients are FileZilla, WinSCP, Cyberduck, and CuteFTP.
- To use an FTP client, the user needs to know the hostname, username, and password of the FTP server, as well as the port number if it is not the default one (21).
- The user can then launch the FTP client and enter the server details to connect to the server and access the files and directories.
- The user can then use the FTP client's interface to browse, select, and transfer files between the local host and the remote server.
- The user can also use commands to perform various operations on the server, such as `ls` to list the files, `cd` to change the directory, `get` to download a file, `put` to upload a file, and `quit` to end the session.
