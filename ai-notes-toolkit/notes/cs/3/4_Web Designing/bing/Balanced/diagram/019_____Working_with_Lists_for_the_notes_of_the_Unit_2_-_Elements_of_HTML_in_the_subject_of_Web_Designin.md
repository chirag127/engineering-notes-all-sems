### Working with Lists

- Lists are used to display a series of related items in a structured and organized way.
- HTML supports three types of lists: ordered lists, unordered lists, and definition lists.
- Ordered lists use numbers, letters, or roman numerals to indicate the order or sequence of the list items. They are created with the `<ol>` tag and each item is enclosed in a `<li>` tag.
- Unordered lists use bullets, circles, squares, or other symbols to mark the list items. They are created with the `<ul>` tag and each item is enclosed in a `<li>` tag.
- Definition lists consist of pairs of terms and definitions. They are created with the `<dl>` tag and each term is enclosed in a `<dt>` tag and each definition is enclosed in a `<dd>` tag.
- Lists can be nested inside other lists to create sublists. To nest a list, simply place the list tags inside a `<li>` tag of the parent list.
- Lists can be styled with CSS properties such as `list-style-type`, `list-style-image`, `list-style-position`, and `list-style`.
- Lists can also be used to create navigation menus, tables of contents, and other interactive elements.
