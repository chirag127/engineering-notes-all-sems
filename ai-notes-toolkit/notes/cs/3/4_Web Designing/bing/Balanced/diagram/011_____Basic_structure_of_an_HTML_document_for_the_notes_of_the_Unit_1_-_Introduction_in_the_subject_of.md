### Basic structure of an HTML document

- An HTML document is a text file that contains markup tags and content.
- Markup tags are special keywords that start and end with angle brackets (< and >). They tell the browser how to display the content.
- The content is the text, images, links, and other elements that appear on the web page.
- An HTML document has two main parts: the head and the body.
- The head contains information about the document, such as the title, the character encoding, and the style sheets.
- The body contains the actual content of the document, such as headings, paragraphs, lists, tables, and forms.
- The head and the body are enclosed by the <html> and </html> tags, which indicate the start and end of the HTML document.
- The head is enclosed by the <head> and </head> tags, which indicate the start and end of the head section.
- The body is enclosed by the <body> and </body> tags, which indicate the start and end of the body section.
- The title of the document is specified by the <title> and </title> tags, which are placed inside the head section.
- The character encoding of the document is specified by the <meta> tag, which is also placed inside the head section.
- The style sheets of the document are linked by the <link> tag, which is also placed inside the head section.
- The following diagram shows the basic structure of an HTML document:

```
<html>
  <head>
    <title>Document title</title>
    <meta charset="UTF-8">
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <!-- Document content goes here -->
  </body>
</html>
```
