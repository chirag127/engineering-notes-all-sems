### Working with Arrays

- An array is a data structure that can store multiple values of the same or different types in a single variable.
- An array can be created by using the `Array` constructor or the array literal syntax `[]`.
- An array can be accessed by using the index notation `array[index]`, where `index` is a zero-based integer that represents the position of the element in the array.
- An array can be modified by using the assignment operator `=` or the array methods such as `push`, `pop`, `shift`, `unshift`, `splice`, `slice`, `sort`, `reverse`, etc.
- An array can be iterated by using the `for` loop, the `for...of` loop, the `forEach` method, or the `map`, `filter`, `reduce`, etc. methods.
- An array can be converted to a string by using the `toString` method or the `join` method.
- An array can be checked for its length by using the `length` property or the `isArray` method.
