# Javascript Types

- Javascript is a **dynamically typed** language, which means that the type of a variable is determined at runtime, not at compile time.
- Javascript has **seven** basic types: **number**, **string**, **boolean**, **null**, **undefined**, **symbol**, and **object**.
- The **typeof** operator can be used to check the type of a variable or value. For example, `typeof 42` returns `"number"`, and `typeof "hello"` returns `"string"`.
- The **number** type represents both integers and floating-point numbers. There is no separate type for integers. For example, `42` and `3.14` are both numbers.
- The **string** type represents a sequence of characters enclosed in single or double quotes. For example, `"hello"` and `'world'` are both strings.
- The **boolean** type represents a logical value that can be either **true** or **false**. For example, `true` and `false` are both booleans.
- The **null** type represents a value that intentionally has no value. For example, `null` is the only value of the null type.
- The **undefined** type represents a value that has not been assigned or initialized. For example, `undefined` is the only value of the undefined type.
- The **symbol** type represents a unique and immutable identifier that can be used as a property key or a constant. For example, `Symbol("foo")` creates a new symbol with the description `"foo"`.
- The **object** type represents a collection of properties and methods that can be accessed by dot notation or bracket notation. For example, `{name: "Alice", age: 25}` is an object with two properties, `name` and `age`.
- Objects can be classified into different kinds of objects, such as **arrays**, **functions**, **dates**, **regular expressions**, and **built-in objects**. For example, `[1, 2, 3]` is an array, `function() { return "hello"; }` is a function, `new Date()` is a date, `/[a-z]+/` is a regular expression, and `Math` is a built-in object.
