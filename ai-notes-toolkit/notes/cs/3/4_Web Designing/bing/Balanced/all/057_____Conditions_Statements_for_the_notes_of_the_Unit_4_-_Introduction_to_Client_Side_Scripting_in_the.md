# Condition Statements for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- Condition statements are used to control the flow of execution of a program based on some conditions.
- Condition statements can be written in different languages, such as JavaScript, which is a popular client-side scripting language for web designing.
- Condition statements can be of different types, such as if, if-else, if-else-if, switch, and ternary operator.
- If statement is used to execute a block of code only if a condition is true.
- If-else statement is used to execute a block of code if a condition is true, or another block of code if the condition is false.
- If-else-if statement is used to execute one of several blocks of code based on multiple conditions.
- Switch statement is used to execute one of many blocks of code based on a value or expression.
- Ternary operator is used to assign a value to a variable based on a condition. It is a shorthand for if-else statement.
- The syntax and examples of condition statements in JavaScript are as follows:

```javascript
// if statement
if (condition) {
  // code to execute if condition is true
}

// if-else statement
if (condition) {
  // code to execute if condition is true
} else {
  // code to execute if condition is false
}

// if-else-if statement
if (condition1) {
  // code to execute if condition1 is true
} else if (condition2) {
  // code to execute if condition2 is true
} else {
  // code to execute if none of the conditions are true
}

// switch statement
switch (value or expression) {
  case value1:
    // code to execute if value or expression matches value1
    break;
  case value2:
    // code to execute if value or expression matches value2
    break;
  default:
    // code to execute if none of the cases match
}

// ternary operator
variable = condition ? value1 : value2;
// assigns value1 to variable if condition is true, or value2 if condition is false
```
