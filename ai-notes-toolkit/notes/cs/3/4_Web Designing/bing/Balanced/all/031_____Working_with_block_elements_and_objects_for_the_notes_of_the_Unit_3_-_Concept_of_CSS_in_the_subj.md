# Working with block elements and objects

- Block elements are HTML elements that occupy the entire width of their parent container and start on a new line. Examples of block elements are `<div>`, `<p>`, `<h1>`, `<ul>`, etc.
- Block elements can be styled with CSS properties such as `width`, `height`, `margin`, `padding`, `border`, `background`, `display`, `position`, etc.
- Block elements can contain other block elements or inline elements. Inline elements are HTML elements that do not start on a new line and only occupy the space needed for their content. Examples of inline elements are `<span>`, `<a>`, `<img>`, `<em>`, etc.
- Block elements can be transformed into inline elements or vice versa by using the `display` property in CSS. The possible values for the `display` property are `block`, `inline`, `inline-block`, `none`, etc.
- Block elements can also be aligned horizontally or vertically by using the `text-align` or `vertical-align` properties in CSS. The possible values for the `text-align` property are `left`, `right`, `center`, `justify`, etc. The possible values for the `vertical-align` property are `top`, `middle`, `bottom`, `baseline`, etc.
- Block elements can also be positioned relative to their normal flow, to their parent element, or to the viewport by using the `position` property in CSS. The possible values for the `position` property are `static`, `relative`, `absolute`, `fixed`, etc.
- Block elements can also be layered on top of each other by using the `z-index` property in CSS. The `z-index` property specifies the stack order of an element, where higher values are closer to the viewer. The default value for the `z-index` property is `auto`, which means the element inherits the stack order from its parent element.
- Block elements can also be transformed by using the `transform` property in CSS. The `transform` property allows to rotate, scale, skew, or translate an element. The possible values for the `transform` property are `rotate()`, `scale()`, `skew()`, `translate()`, etc.
- Block elements can also be animated by using the `transition` or `animation` properties in CSS. The `transition` property specifies how an element changes from one state to another, such as changing its color, size, or position. The `animation` property specifies how an element moves or changes over time, such as fading in, bouncing, or sliding. The possible values for the `transition` property are `property`, `duration`, `timing-function`, `delay`, etc. The possible values for the `animation` property are `name`, `duration`, `timing-function`, `delay`, `iteration-count`, `direction`, `fill-mode`, `play-state`, etc.
