# CSS Properties

CSS properties are the attributes that define how HTML elements are styled and displayed on a web page. CSS properties are specified in the form of property: value pairs, separated by semicolons and enclosed in curly braces. For example:

```css
h1 {
  color: blue;
  font-size: 36px;
}
```

In this example, `color` and `font-size` are CSS properties, and `blue` and `36px` are their corresponding values. The `h1` selector indicates that the properties apply to all `<h1>` elements on the page.

There are hundreds of CSS properties that can be used to control various aspects of the appearance and layout of HTML elements, such as colors, fonts, backgrounds, borders, margins, padding, positioning, alignment, visibility, animation, and more. Some of the most commonly used CSS properties are:

- `color`: Specifies the text color of an element.
- `background-color`: Specifies the background color of an element.
- `font-family`: Specifies the font family of an element, such as Arial, Times New Roman, or Verdana.
- `font-size`: Specifies the font size of an element, in pixels, points, ems, or other units.
- `font-weight`: Specifies the font weight of an element, such as normal, bold, or lighter.
- `font-style`: Specifies the font style of an element, such as normal, italic, or oblique.
- `text-align`: Specifies the horizontal alignment of text within an element, such as left, right, center, or justify.
- `text-decoration`: Specifies the decoration of text within an element, such as none, underline, overline, or line-through.
- `border`: Specifies the border of an element, including its width, style, and color. For example, `border: 2px solid red;`.
- `margin`: Specifies the space outside the border of an element, in pixels or other units. For example, `margin: 10px;`.
- `padding`: Specifies the space inside the border of an element, in pixels or other units. For example, `padding: 5px;`.
- `width`: Specifies the width of an element, in pixels, percentages, or other units. For example, `width: 50%;`.
- `height`: Specifies the height of an element, in pixels, percentages, or other units. For example, `height: 100px;`.
- `display`: Specifies how an element is displayed on the page, such as block, inline, inline-block, or none. For example, `display: block;`.
- `position`: Specifies the position of an element relative to its normal position, its parent element, or the viewport, such as static, relative, absolute, or fixed. For example, `position: absolute;`.
- `top`, `right`, `bottom`, `left`: Specifies the offset of an element from its position, in pixels or other units. For example, `top: 20px;`.
- `z-index`: Specifies the stacking order of an element, in case of overlapping elements. For example, `z-index: 10;`.
- `visibility`: Specifies the visibility of an element, such as visible, hidden, or collapse. For example, `visibility: hidden;`.
- `opacity`: Specifies the opacity of an element, from 0 (transparent) to 1 (opaque). For example, `opacity: 0.5;`.
- `transform`: Specifies the transformation of an element, such as rotate, scale, skew, or translate. For example, `transform: rotate(45deg);`.
- `transition`: Specifies the transition effect of an element, such as duration, timing function, delay, and property. For example, `transition: all 1s ease-in-out;`.
- `animation`: Specifies the animation effect of an element, such as name, duration, timing function, delay, iteration count, direction, fill mode, and play state. For example, `animation: bounce 2s infinite alternate;`.

These are some of the basic CSS properties that can be used to style and manipulate HTML elements on a web page. For a complete reference of all CSS properties, visit https://developer.mozilla.org/en-US/docs/Web/CSS/Reference.
