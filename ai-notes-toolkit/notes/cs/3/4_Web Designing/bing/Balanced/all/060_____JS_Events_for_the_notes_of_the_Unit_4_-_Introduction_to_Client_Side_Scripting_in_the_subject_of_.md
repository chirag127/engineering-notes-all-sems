# JS Events

- JS events are actions or occurrences that happen in the browser, such as clicking a button, loading a page, or typing a key.
- JS events can be used to trigger functions or scripts when a certain event happens, such as validating a form, updating a web page, or creating animations.
- JS events are represented by objects that contain information about the event, such as the type of event, the target element, the coordinates of the mouse, or the key pressed.
- JS events can be handled by adding event listeners to HTML elements, using the `addEventListener()` method or the `on` attribute.
- JS events can be categorized into different types, such as mouse events, keyboard events, window events, form events, or media events.
- Some common JS events are:

  - `click`: occurs when the user clicks on an element
  - `load`: occurs when the browser finishes loading a document or an image
  - `change`: occurs when the value of an input element changes
  - `submit`: occurs when the user submits a form
  - `keydown`: occurs when the user presses a key
  - `mouseover`: occurs when the mouse pointer moves over an element
  - `resize`: occurs when the browser window is resized
  - `scroll`: occurs when the user scrolls the document
  - `play`: occurs when a media element starts playing
  - `pause`: occurs when a media element pauses playing

- JS events can be propagated or bubbled up from the target element to its ancestors, or captured or trickled down from the root element to the target element.
- JS events can be stopped from propagating or capturing by using the `stopPropagation()` method or the `cancelBubble` property of the event object.
- JS events can be prevented from performing their default actions, such as following a link or submitting a form, by using the `preventDefault()` method of the event object.
