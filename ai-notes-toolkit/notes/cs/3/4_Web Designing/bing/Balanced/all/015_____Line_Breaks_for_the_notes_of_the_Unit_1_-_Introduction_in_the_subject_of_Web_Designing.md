# Line Breaks

- Line breaks are used to create a new line of text in HTML documents.
- Line breaks are created by using the `<br>` tag, which is an empty element that does not need a closing tag.
- The `<br>` tag can be used anywhere within the body of an HTML document, such as within paragraphs, headings, lists, tables, etc.
- The `<br>` tag can also be used to create extra space between elements by using it multiple times.
- The `<br>` tag is useful for formatting text that needs to follow a specific layout, such as addresses, poems, quotes, etc.
- However, the `<br>` tag should not be used to create paragraphs or sections of text, as this can affect the semantic structure and accessibility of the document. Instead, the `<p>` tag should be used to create paragraphs, and the `<div>` or `<section>` tags should be used to create sections of text.
- The `<br>` tag can be styled with CSS properties, such as `color`, `font-size`, `border`, etc. However, this is not recommended, as it can create inconsistency and confusion in the document. Instead, the `<br>` tag should be used only for its intended purpose, which is to create a line break.
