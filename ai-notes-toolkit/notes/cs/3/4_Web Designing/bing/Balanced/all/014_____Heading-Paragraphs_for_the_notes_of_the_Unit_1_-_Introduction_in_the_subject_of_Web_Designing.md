# Heading-Paragraphs for the notes of the Unit 1 - Introduction in the subject of Web Designing

- A heading is a text that introduces a section of a web page. It is usually displayed in a larger or bolder font than the rest of the text.
- A paragraph is a group of sentences that form a coherent unit of text. It is usually displayed in a smaller or normal font than the heading.
- Headings and paragraphs are important elements of web design because they help to organize the content and make it easier for the readers to scan and understand.
- Headings and paragraphs are marked up using HTML tags. HTML stands for HyperText Markup Language and it is the standard language for creating web pages.
- The most common HTML tags for headings are `<h1>` to `<h6>`, where `<h1>` is the largest and most important heading and `<h6>` is the smallest and least important heading. For example, `<h1>Introduction</h1>` creates a heading with the text "Introduction".
- The HTML tag for paragraphs is `<p>`. For example, `<p>This is a paragraph.</p>` creates a paragraph with the text "This is a paragraph.".
- Headings and paragraphs can be styled using CSS. CSS stands for Cascading Style Sheets and it is the language for describing the presentation of web pages. For example, `h1 {color: blue;}` applies the color blue to all `<h1>` elements.
