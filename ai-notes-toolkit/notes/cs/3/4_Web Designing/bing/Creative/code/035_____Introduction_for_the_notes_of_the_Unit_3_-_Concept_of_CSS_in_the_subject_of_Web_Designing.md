### Introduction

- CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page.
- CSS allows you to separate the presentation of a web page from its content. You can apply different styles, such as colors, fonts, layouts, and animations, to HTML elements using CSS rules.
- CSS can make your web pages more attractive, consistent, and responsive. You can also use CSS to adapt your web pages to different devices, such as desktops, tablets, and mobile phones.
- CSS has three main components: selectors, properties, and values. A selector is a pattern that matches one or more HTML elements. A property is an aspect of the element that can be styled, such as width, height, or color. A value is the specific setting for the property, such as 100px, 50%, or red.
- CSS rules are written in a style sheet, which is a file that ends with the .css extension. You can link a style sheet to an HTML document using the <link> element in the <head> section. You can also write CSS rules inside an HTML document using the <style> element or inline using the style attribute.
- CSS follows a cascading order, which means that the style applied to an element depends on the specificity and importance of the selector, the source of the style sheet, and the order of the rules. The more specific and important the selector, the higher the priority of the rule. The style sheet that is closest to the element, such as inline or embedded, has the highest precedence. The last rule that matches the element wins if there is a tie.
- CSS has many features and modules that allow you to create complex and dynamic web pages. Some of the topics that you will learn in this unit are:

  - How to use different types of selectors, such as element, class, id, attribute, pseudo-class, and pseudo-element selectors.
  - How to use different units and values, such as lengths, percentages, colors, keywords, and functions.
  - How to use the box model, which defines how the size and spacing of an element are calculated.
  - How to use the display and position properties, which control how an element is laid out on the page.
  - How to use the flexbox and grid properties, which enable you to create flexible and responsive layouts.
  - How to use the transform, transition, and animation properties, which enable you to create dynamic effects and movements.
  - How to use the media query and responsive design techniques, which enable you to adapt your web pages to different screen sizes and orientations.
