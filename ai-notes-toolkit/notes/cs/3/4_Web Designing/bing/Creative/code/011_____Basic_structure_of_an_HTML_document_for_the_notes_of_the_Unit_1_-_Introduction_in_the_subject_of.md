# Basic structure of an HTML document

- An HTML document is a text file that contains markup tags that define the content and appearance of a web page.
- An HTML document has two main parts: the head and the body.
- The head contains information about the document, such as the title, the character encoding, the style sheets, and the scripts.
- The body contains the actual content of the document, such as text, images, links, forms, and tables.
- An HTML document starts with a declaration that specifies the version of HTML used, followed by the opening `<html>` tag and the closing `</html>` tag.
- The head and the body are enclosed within the `<html>` tag, using the opening `<head>` and `<body>` tags and the closing `</head>` and `</body>` tags respectively.
- An HTML document can also include comments, which are ignored by the browser and can be used to add notes or explanations to the code.
- An HTML document can also include special characters, such as symbols, accents, and emojis, using the character entity references, which start with an ampersand (&) and end with a semicolon (;).
- An HTML document can also include external resources, such as images, videos, audio, style sheets, and scripts, using the `<img>`, `<video>`, `<audio>`, `<link>`, and `<script>` tags respectively.
- An HTML document can also include hyperlinks, which allow the user to navigate to other web pages or sections of the same page, using the `<a>` tag with the `href` attribute.
- An HTML document can also include lists, which can be ordered, unordered, or definition lists, using the `<ol>`, `<ul>`, and `<dl>` tags respectively.
- An HTML document can also include tables, which can display data in rows and columns, using the `<table>`, `<tr>`, `<td>`, and `<th>` tags respectively.
- An HTML document can also include forms, which can collect user input, such as text, checkboxes, radio buttons, and buttons, using the `<form>`, `<input>`, `<label>`, and `<button>` tags respectively.
- An HTML document can also include semantic elements, which provide meaning and structure to the content, such as headings, paragraphs, sections, articles, and footers, using the `<h1>` to `<h6>`, `<p>`, `<section>`, `<article>`, and `<footer>` tags respectively.

Here is an example of a simple HTML document:

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>My First Web Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>This is my first web page.</p>
  <p>I am learning HTML.</p>
  <a href="https://www.w3schools.com/html/">Learn more about HTML</a>
</body>
</html>
```
