### Markup Tags
- Markup tags are the elements that define the structure and content of a web document.
- Markup tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p>.
- The first tag in a pair is called the start tag or opening tag, and the second tag is called the end tag or closing tag.
- The text or content between the start and end tags is called the element content.
- Some markup tags are self-closing, meaning they do not need an end tag. For example, <br> is a self-closing tag that inserts a line break in the document.
- Markup tags can have attributes, which are additional information that modify the behavior or appearance of the element. Attributes are written inside the start tag, after the tag name, and consist of a name and a value, separated by an equal sign (=). For example, <img src="logo.png" alt="Logo"> is a self-closing tag that displays an image with the source (src) attribute pointing to the file name and the alternative text (alt) attribute providing a description for the image.
- Markup tags can be nested, meaning one element can contain another element as its content. For example, <p><strong>This is a paragraph with bold text.</strong></p> is a paragraph element that contains a strong element as its content. The nested element must be closed before the containing element is closed.
- Markup tags can be categorized into two types: structural and presentational.
  - Structural tags define the logical structure and meaning of the document, such as headings, paragraphs, lists, tables, etc. For example, <h1> is a structural tag that indicates a level one heading.
  - Presentational tags define the appearance and style of the document, such as font, color, alignment, etc. For example, <b> is a presentational tag that makes the text bold.
  - Presentational tags are deprecated in HTML5, meaning they should not be used anymore. Instead, CSS (Cascading Style Sheets) should be used to control the presentation of the document. CSS is a separate language that can be linked to or embedded in HTML documents. For example, <style> is a tag that can contain CSS rules inside the HTML document.
