### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page.
- CSS can be used to control the layout, colors, fonts, borders, backgrounds, and other aspects of the presentation of HTML elements.
- CSS can be applied to HTML elements in three ways: inline, internal, and external.
  - Inline CSS: The style attribute is used to add CSS rules directly to an HTML element. For example: `<p style="color: blue;">This is a blue paragraph.</p>`
  - Internal CSS: The `<style>` element is used to add CSS rules inside the `<head>` section of an HTML document. For example: `<style> p {color: blue;} </style>`
  - External CSS: The `<link>` element is used to link an external CSS file to an HTML document. For example: `<link rel="stylesheet" href="style.css">`
- CSS rules consist of two parts: a selector and a declaration.
  - A selector is the part that specifies which HTML elements to apply the style to. For example: `p`, `h1`, `#id`, `.class`, etc.
  - A declaration is the part that contains one or more property-value pairs, separated by semicolons and enclosed in curly braces. For example: `{color: blue; font-size: 16px;}`
  - A property is the aspect of the HTML element that can be styled, such as color, font-size, margin, etc.
  - A value is the specific setting for the property, such as blue, 16px, 10px, etc.
- CSS rules can be grouped together by using commas to separate multiple selectors, or by using nested selectors to target specific elements within other elements. For example: `p, h1 {color: blue;}` or `div p {color: blue;}`
- CSS rules can also be inherited from parent elements to child elements, or overridden by more specific selectors or by using the `!important` keyword. For example: `body {color: black;} p {color: blue;}` or `p {color: blue !important;}`
- CSS has various units to specify the values of properties, such as pixels (px), percentages (%), ems (em), rems (rem), etc. For example: `p {font-size: 1.2em; margin: 10px;}`
- CSS has various color values to specify the colors of properties, such as color names (blue, red, etc.), hexadecimal values (#0000FF, #FF0000, etc.), RGB values (rgb(0,0,255), rgb(255,0,0), etc.), HSL values (hsl(240,100%,50%), hsl(0,100%,50%), etc.), etc. For example: `p {color: blue; background-color: #FFFF00;}`
- CSS has various selectors to target HTML elements based on their attributes, pseudo-classes, pseudo-elements, or combinations of them. For example: `[href]`, `:hover`, `::before`, `a[href^="https"]`, etc.
- CSS has various properties to style HTML elements, such as font-family, font-style, font-weight, text-align, text-decoration, text-transform, line-height, letter-spacing, word-spacing, etc. For example: `p {font-family: Arial, sans-serif; font-style: italic; font-weight: bold; text-align: center; text-decoration: underline; text-transform: uppercase; line-height: 1.5; letter-spacing: 2px; word-spacing: 4px;}`
