### Working with Arrays

- An array is a data structure that can store multiple values of the same or different types in a single variable.
- An array can be created by using the `Array` constructor or by using the array literal syntax `[]`.
- An array can be accessed or modified by using the index notation `[]` with a numeric index, starting from 0.
- An array has a `length` property that returns the number of elements in the array.
- An array can be iterated over by using a `for` loop, a `for...of` loop, or a `forEach` method.
- An array can be manipulated by using various methods, such as `push`, `pop`, `shift`, `unshift`, `slice`, `splice`, `concat`, `join`, `reverse`, `sort`, `filter`, `map`, `reduce`, etc.
- An array can be converted to a string by using the `toString` method or the `join` method with a separator argument.
- An array can be checked for its type by using the `Array.isArray` method or the `instanceof` operator.
