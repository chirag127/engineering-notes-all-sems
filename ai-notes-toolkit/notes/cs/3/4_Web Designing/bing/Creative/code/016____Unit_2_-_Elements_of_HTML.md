## Unit 2 - Elements of HTML

HTML stands for HyperText Markup Language. It is the standard language for creating web pages and web applications. HTML consists of elements that define the structure and content of a web page.

An HTML element is a piece of code that starts with a start tag and ends with an end tag. The start tag usually has the format `<element>` and the end tag has the format `</element>`. For example, `<p>` and `</p>` are the start and end tags for a paragraph element. Some elements do not have an end tag, such as `<img>` for an image element. These are called self-closing elements.

An HTML element can have attributes that provide additional information about the element. Attributes are written inside the start tag, after the element name, and have the format `name="value"`. For example, `<img src="image.jpg" alt="A picture">` is an image element with two attributes: `src` and `alt`. The `src` attribute specifies the source of the image, and the `alt` attribute provides an alternative text for the image.

An HTML element can also have content, which is the text or other elements that appear between the start and end tags. For example, `<p>This is a paragraph.</p>` is a paragraph element with the content "This is a paragraph." Some elements, such as `<img>`, do not have content.

There are many types of HTML elements, each with a specific purpose and syntax. Some of the most common elements are:

- `<html>`: The root element that contains the whole web page.
- `<head>`: The element that contains the metadata of the web page, such as the title, the character encoding, and the links to external resources.
- `<title>`: The element that defines the title of the web page, which appears in the browser tab or window.
- `<body>`: The element that contains the visible content of the web page, such as text, images, links, and forms.
- `<h1>` to `<h6>`: The elements that define the headings of different levels, from the most important (`<h1>`) to the least important (`<h6>`).
- `<p>`: The element that defines a paragraph of text.
- `<a>`: The element that defines a hyperlink to another web page or resource. It has an attribute called `href` that specifies the destination of the link.
- `<img>`: The element that defines an image. It has an attribute called `src` that specifies the source of the image, and an optional attribute called `alt` that provides an alternative text for the image.
- `<ul>` and `<ol>`: The elements that define unordered and ordered lists, respectively. They contain one or more `<li>` elements that define the list items.
- `<div>` and `<span>`: The elements that define generic containers for other elements. They are often used to group elements for styling or layout purposes.

These are some of the basic elements of HTML. There are many more elements that can be used to create different types of web pages and applications. To learn more about HTML elements, you can refer to the following resources:
