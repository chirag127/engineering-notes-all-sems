### Line Breaks
- A line break is a way of ending a line of text and starting a new one without creating a new paragraph.
- In HTML, line breaks are created by using the `<br>` tag, which is an empty element that does not need a closing tag.
- The `<br>` tag can be used anywhere within the text, such as within a paragraph, a heading, a list item, or a table cell.
- The `<br>` tag is useful for creating line breaks in poems, addresses, quotations, or other situations where the text layout is important.
- The `<br>` tag should not be used to create extra space between paragraphs or sections, as this can be done with CSS properties such as margin or padding.
- The `<br>` tag should also not be used to create multiple line breaks in a row, as this can affect the readability and accessibility of the web page.
- The `<br>` tag is a semantic element, which means it conveys some meaning or information about the text. Therefore, it should be used only when the line break is part of the content, not the presentation.
