### Introduction to JavaScript

- JavaScript is a scripting language that runs in the web browser and can manipulate the HTML and CSS elements of a web page dynamically.
- JavaScript was created by Brendan Eich in 1995 and is standardized by the ECMAScript specification.
- JavaScript can perform various tasks such as validating user input, creating animations, fetching data from a server, and interacting with the Document Object Model (DOM) of a web page.
- JavaScript code can be embedded in the HTML document using the `<script>` tag or linked to an external file using the `src` attribute.
- JavaScript code can be executed either when the web page is loaded, when an event occurs, or when a function is called.
- JavaScript is case-sensitive, meaning that the names of variables, functions, and keywords must be written exactly as they are defined.
- JavaScript uses semicolons to end statements and curly braces to group blocks of code.
- JavaScript supports various data types such as numbers, strings, booleans, arrays, objects, functions, and symbols.
- JavaScript supports various operators such as arithmetic, assignment, comparison, logical, bitwise, and ternary operators.
- JavaScript supports various control structures such as if-else, switch, for, while, do-while, and break-continue statements.
- JavaScript supports various built-in objects such as Math, Date, String, Array, and RegExp, as well as user-defined objects using constructors and prototypes.
- JavaScript supports various built-in functions such as alert, prompt, confirm, console.log, and setTimeout, as well as user-defined functions using the function keyword or the arrow syntax.
- JavaScript supports various features such as hoisting, closures, scope, inheritance, and polymorphism, which make it a powerful and flexible language.
