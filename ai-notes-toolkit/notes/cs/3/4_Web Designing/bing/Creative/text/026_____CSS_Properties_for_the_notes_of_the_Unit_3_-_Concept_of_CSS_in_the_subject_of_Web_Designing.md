### CSS Properties

- CSS properties are used to apply styles to HTML elements, such as fonts, colors, spacing, layout, etc.
- CSS properties are written as key-value pairs, separated by a colon and followed by a semicolon, e.g. `color: red;`
- CSS properties can be grouped into categories, such as background, border, box model, color, font, layout, list, text, transform, transition, etc.
- CSS properties can be inherited from parent elements, or overridden by more specific selectors or inline styles.
- CSS properties can be set using custom variables, also known as custom properties, which are defined using the `--` syntax and accessed using the `var()` function, e.g. `--main-color: black; color: var(--main-color);`
- CSS properties can be referenced using an alphabetical index, or by browsing key concepts and selectors by type.
