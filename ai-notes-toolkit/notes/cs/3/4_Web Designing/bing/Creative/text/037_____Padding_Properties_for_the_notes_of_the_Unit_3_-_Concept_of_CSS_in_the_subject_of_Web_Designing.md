### Padding Properties

- Padding is the space between the content and the border of an element  .
- Padding can be used to create space around an element's content, inside of any defined borders .
- Padding can be specified using one, two, three, or four values .
  - If one value is given, it applies to all four sides of the element .
  - If two values are given, the first value applies to the top and bottom sides, and the second value applies to the left and right sides .
  - If three values are given, the first value applies to the top side, the second value applies to the left and right sides, and the third value applies to the bottom side .
  - If four values are given, they apply to the top, right, bottom, and left sides in that order .
- Padding values can be set using lengths or percentages, and cannot accept negative values.
- The initial, or default, value for all padding properties is 0 .
- The padding property is a shorthand property for setting all the padding properties in one declaration .
- The padding properties are: padding-top, padding-right, padding-bottom, and padding-left .
- The padding properties can be used to control the layout of an element and its children, as well as the background color and image of an element .
- The padding properties are inherited from the parent element, unless explicitly specified otherwise.
- The padding properties can be affected by the box-sizing property, which determines how the width and height of an element are calculated .
