## Unit 2 - Elements of HTML

- HTML stands for HyperText Markup Language, which is the standard language for creating web pages and web applications.
- HTML consists of a series of elements, which are the building blocks of a web page. Elements are written using tags, which are enclosed in angle brackets (< and >).
- An element usually has a start tag and an end tag, with the content in between. For example, `<p>This is a paragraph.</p>` is an element that represents a paragraph of text.
- Some elements are self-closing, which means they do not have an end tag. For example, `<img src="image.jpg" alt="An image">` is an element that displays an image.
- Elements can have attributes, which are additional information that modify or describe the element. Attributes are written inside the start tag, after the element name, and consist of a name and a value, separated by an equal sign (=). For example, `src` and `alt` are attributes of the `img` element, and their values are `"image.jpg"` and `"An image"`, respectively.
- Elements can be nested inside other elements, which means they form a hierarchy or a tree structure. For example, `<html><head><title>My webpage</title></head><body><p>Hello, world!</p></body></html>` is a nested structure of elements that represents a basic web page.
- The root element of an HTML document is the `html` element, which contains two child elements: the `head` element and the `body` element. The `head` element contains information about the document, such as the title, meta data, and links to external resources. The `body` element contains the visible content of the document, such as text, images, links, and forms.
- There are many types of elements in HTML, each with a specific purpose and syntax. Some of the common elements are:

  - `h1` to `h6`: These elements represent headings of different levels, from the most important (`h1`) to the least important (`h6`). For example, `<h1>My webpage</h1>` is a level 1 heading that displays the text "My webpage" in a large font size.
  - `p`: This element represents a paragraph of text. For example, `<p>This is a paragraph.</p>` is a paragraph that displays the text "This is a paragraph." in a normal font size.
  - `a`: This element represents a hyperlink, which is a clickable text that leads to another web page or a location within the same page. For example, `<a href="https://www.example.com">Visit example.com</a>` is a hyperlink that displays the text "Visit example.com" and links to the website "https://www.example.com".
  - `img`: This element represents an image, which is a visual representation of data or information. For example, `<img src="image.jpg" alt="An image">` is an image that displays the file "image.jpg" and has the alternative text "An image" for accessibility purposes.
  - `ul` and `ol`: These elements represent unordered and ordered lists, which are collections of items that are displayed in a vertical sequence. For example, `<ul><li>Item 1</li><li>Item 2</li><li>Item 3</li></ul>` is an unordered list that displays the items "Item 1", "Item 2", and "Item 3" with bullet points. `<ol><li>Item 1</li><li>Item 2</li><li>Item 3</li></ol>` is an ordered list that displays the items "Item 1", "Item 2", and "Item 3" with numbers.
  - `li`: This element represents a list item, which is a single element of a list. For example, `<li>Item 1</li>` is a list item that displays the text "Item 1".
  - `div` and `span`: These elements represent generic containers, which are used to group or style other elements. For example, `<div class="container"><p>This is a paragraph.</p></div>` is a container that wraps a paragraph element and has the class name "container". `<span style="color: red;">This is red text.</span>` is a container that wraps some text and applies the style "color: red" to it.
