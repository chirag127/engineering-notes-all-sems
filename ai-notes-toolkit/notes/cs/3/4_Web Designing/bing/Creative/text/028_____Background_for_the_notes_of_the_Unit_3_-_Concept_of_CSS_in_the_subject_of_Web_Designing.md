### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for **Cascading Style Sheets** and it is a **stylesheet language** used to describe the presentation of a document written in HTML or XML.
- CSS is used to **style and layout web pages** — for example, to alter the font, color, size, and spacing of your content, split it into multiple columns, or add animations and other decorative features .
- CSS is a **rule-based language** — you define the rules by specifying groups of styles that should be applied to particular elements or groups of elements on your web page.
- CSS rules consist of two parts: a **selector** and a **declaration block**. A selector is a pattern that matches some elements on the web page, and a declaration block is a set of properties and values that define how those elements should look.
- CSS rules can be written in three ways: **inline**, **internal**, or **external**. Inline CSS is written directly in the HTML element using the `style` attribute, internal CSS is written in the `<style>` element in the `<head>` section of the HTML document, and external CSS is written in a separate file with the `.css` extension and linked to the HTML document using the `<link>` element.
- CSS has a **cascading** mechanism that determines how multiple rules and styles are applied to the same element. The cascade resolves conflicts by following a set of **precedence rules** based on the source, specificity, and order of the CSS rules.
- CSS also supports **inheritance**, which means that some properties are automatically passed from a parent element to its children elements. This reduces the need to specify the same style for every element.
- CSS has a **box model** that defines how the layout of each element is calculated. The box model consists of four parts: **content**, **padding**, **border**, and **margin**. The content is the actual text or image inside the element, the padding is the space between the content and the border, the border is the line around the element, and the margin is the space outside the border.
- CSS has many **properties** and **values** that can be used to style and layout web pages. Some of the most common properties are `color`, `font-family`, `font-size`, `text-align`, `background-color`, `width`, `height`, `display`, `position`, `margin`, `padding`, `border`, `float`, `clear`, `transform`, `transition`, `animation`, etc.
- CSS also has **selectors** and **combinators** that can be used to target specific elements or groups of elements on the web page. Some of the most common selectors are `*`, `element`, `.class`, `#id`, `[attribute]`, `:pseudo-class`, `::pseudo-element`, etc. Some of the most common combinators are ` `, `>`, `+`, `~`, etc.
- CSS also has **media queries** that can be used to apply different styles depending on the device, screen size, orientation, resolution, etc. Media queries use the `@media` rule and a set of **logical expressions** to specify the conditions for applying the styles.
- CSS also has **variables** that can be used to store and reuse values throughout the stylesheet. Variables use the `--` prefix and the `var()` function to define and use the values.
- CSS also has **functions** that can be used to perform calculations, manipulate colors, generate images, etc. Some of the most common functions are `calc()`, `rgb()`, `hsl()`, `linear-gradient()`, `radial-gradient()`, `url()`, etc.
