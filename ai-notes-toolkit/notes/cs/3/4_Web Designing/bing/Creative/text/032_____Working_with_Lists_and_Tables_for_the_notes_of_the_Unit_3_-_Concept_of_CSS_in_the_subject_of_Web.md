### Working with Lists and Tables

- Lists and tables are common elements in web design that can be styled with CSS.
- Lists are used to display a series of items in a vertical or horizontal order. There are three types of lists in HTML: unordered lists (`<ul>`), ordered lists (`<ol>`), and definition lists (`<dl>`).
- Tables are used to display data in rows and columns. Tables are created with the `<table>` element and its subelements: `<tr>` for table rows, `<td>` for table cells, `<th>` for table headers, `<thead>` for table head, `<tbody>` for table body, and `<tfoot>` for table foot.
- CSS can be used to change the appearance and layout of lists and tables, such as the color, font, size, spacing, alignment, border, background, etc.
- Some common CSS properties for styling lists are:
  - `list-style-type`: specifies the type of bullet or number for list items, such as `disc`, `circle`, `square`, `decimal`, `lower-alpha`, `upper-roman`, etc.
  - `list-style-image`: specifies an image to use as the bullet for list items, such as `url("star.png")`.
  - `list-style-position`: specifies the position of the bullet or number relative to the list item, such as `inside` or `outside`.
  - `list-style`: a shorthand property for setting the above properties in one declaration, such as `list-style: none;` or `list-style: lower-roman inside;`.
- Some common CSS properties for styling tables are:
  - `border`: specifies the width, style, and color of the border around the table or its cells, such as `border: 1px solid black;`.
  - `border-collapse`: specifies whether the borders of adjacent cells are collapsed into a single border or separated, such as `border-collapse: collapse;` or `border-collapse: separate;`.
  - `border-spacing`: specifies the distance between the borders of adjacent cells, such as `border-spacing: 10px;`.
  - `width` and `height`: specify the width and height of the table or its cells, such as `width: 50%;` or `height: 100px;`.
  - `padding` and `margin`: specify the space inside and outside the table or its cells, such as `padding: 5px;` or `margin: 10px;`.
  - `text-align` and `vertical-align`: specify the horizontal and vertical alignment of the text in the table or its cells, such as `text-align: center;` or `vertical-align: middle;`.
  - `background-color` and `background-image`: specify the background color and image for the table or its cells, such as `background-color: yellow;` or `background-image: url("pattern.png");`.
- CSS can also be used to create different types of lists and tables, such as nested lists, horizontal lists, striped tables, responsive tables, etc. by using selectors, pseudo-classes, pseudo-elements, and media queries.
