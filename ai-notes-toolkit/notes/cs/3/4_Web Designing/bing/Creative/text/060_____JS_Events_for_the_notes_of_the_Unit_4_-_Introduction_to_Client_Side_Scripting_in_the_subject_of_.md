### JS Events

- JS events are changes in the state of an object or the browser that can trigger some code to run   .
- JS events can be used to provide a dynamic and interactive interface to a webpage .
- JS events can be hooked to elements in the Document Object Model (DOM) using event handlers or event listeners  .
- JS events can be categorized into different types, such as user interface events, keyboard and mouse events, form events, media events, database events, DOM mutation events, etc .
- JS events can use different propagation modes, such as bubbling (from child to parent) or capturing (from parent to child) to determine the order of event handling .
- JS events can be prevented from propagating further or from performing their default actions using methods such as `stopPropagation()` or `preventDefault()` .
- JS events can be created and dispatched using the `Event` constructor and the `dispatchEvent()` method .
