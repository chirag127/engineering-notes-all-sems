### Condition Statements
- Condition statements are used to control the flow of execution of a program based on some conditions.
- Condition statements can be divided into two types: if statements and switch statements.
- If statements are used to execute a block of code if a condition is true, or another block of code if the condition is false.
- If statements can be nested, meaning that an if statement can be inside another if statement, to create more complex conditions.
- If statements can also be combined with else if and else clauses, to specify multiple conditions and corresponding actions.
- Switch statements are used to execute a block of code based on the value of a variable or an expression.
- Switch statements can have multiple cases, each with a different value and a block of code to execute if the value matches.
- Switch statements can also have a default case, which is executed if none of the other cases match.
- Switch statements are useful when there are many possible values and actions, and when the values are discrete and known in advance.
- Condition statements are essential for creating dynamic and interactive web pages, as they allow the program to respond to user input, events, and data.
