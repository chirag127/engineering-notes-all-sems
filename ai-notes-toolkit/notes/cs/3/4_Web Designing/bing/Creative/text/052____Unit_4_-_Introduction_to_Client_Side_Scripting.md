## Unit 4 - Introduction to Client Side Scripting

- Client side scripting is a technique of writing code that runs on the web browser of the user, rather than on the web server of the website.
- Client side scripting can enhance the interactivity, functionality, and usability of web pages by allowing the code to respond to user actions, events, and inputs without reloading the page or sending requests to the server.
- Client side scripting can also reduce the load on the web server and the network bandwidth by performing some tasks locally on the user's device.
- Some examples of client side scripting languages are JavaScript, HTML, CSS, jQuery, AngularJS, React, etc.
- Client side scripting languages can be embedded in HTML documents using the `<script>` tag, or linked externally using the `src` attribute of the `<script>` tag.
- Client side scripting languages can access and manipulate the elements of the web page using the Document Object Model (DOM), which is a tree-like representation of the HTML document.
- Client side scripting languages can also use various APIs (Application Programming Interfaces) to interact with the web browser, the user's device, and other web services. Some examples of APIs are XMLHttpRequest, Geolocation, Web Storage, Canvas, etc.
- Client side scripting languages can also use various libraries and frameworks to simplify and enhance the development of web applications. Some examples of libraries and frameworks are jQuery, Bootstrap, AngularJS, React, etc.
