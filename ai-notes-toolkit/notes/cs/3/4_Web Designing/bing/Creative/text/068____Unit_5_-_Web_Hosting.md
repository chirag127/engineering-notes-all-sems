## Unit 5 - Web Hosting

- Web hosting is the service of providing storage space and access for websites on the internet.
- Web hosting providers are companies that rent out servers, network equipment, and software to host websites for clients.
- Web hosting can be classified into different types based on the level of control, performance, and resources available to the website owner.
- Some common types of web hosting are:
  - Shared hosting: The website shares a server and its resources with other websites. This is the most affordable and simple option, but it may have limited performance, security, and customization.
  - Dedicated hosting: The website has a server and its resources exclusively for itself. This is the most expensive and complex option, but it offers the highest performance, security, and customization.
  - VPS hosting: The website has a virtual server and its resources allocated from a physical server. This is a middle ground between shared and dedicated hosting, offering more control and flexibility than shared hosting, but less cost and complexity than dedicated hosting.
  - Cloud hosting: The website is hosted on a network of servers that can scale up or down depending on the traffic and demand. This is a modern and flexible option, offering high availability, reliability, and scalability, but it may have variable costs and less control over the server configuration.
- Web hosting also involves other aspects such as domain names, SSL certificates, email accounts, databases, backups, security, and technical support.
