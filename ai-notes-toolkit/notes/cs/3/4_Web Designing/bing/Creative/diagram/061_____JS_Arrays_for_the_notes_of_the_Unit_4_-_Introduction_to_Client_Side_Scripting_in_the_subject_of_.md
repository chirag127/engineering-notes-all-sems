### JS Arrays

- An array is a data structure that can store multiple values of the same or different types in a single variable.
- An array can be created by using square brackets `[]` and separating the values by commas `,` or by using the `new Array()` constructor function.
- An array can be accessed by using its index, which is a zero-based number that represents the position of the value in the array. For example, `array[0]` returns the first value in the array, and `array[array.length - 1]` returns the last value in the array.
- An array can be modified by using its index and the assignment operator `=`. For example, `array[0] = "new value"` changes the first value in the array to "new value".
- An array can be iterated over by using a `for` loop, a `for...of` loop, a `for...in` loop, or a `forEach` method. For example, `for (let i = 0; i < array.length; i++) { console.log(array[i]); }` prints each value in the array to the console.
- An array can be manipulated by using various methods, such as `push`, `pop`, `shift`, `unshift`, `splice`, `slice`, `concat`, `join`, `reverse`, `sort`, `filter`, `map`, `reduce`, etc. For example, `array.push("new value")` adds a new value to the end of the array, and `array.pop()` removes and returns the last value in the array.
- An array can be converted to a string by using the `toString` method or the `join` method. For example, `array.toString()` returns a string with all the values in the array separated by commas, and `array.join("-")` returns a string with all the values in the array separated by hyphens.
- An array can be checked for its type by using the `typeof` operator or the `Array.isArray` method. For example, `typeof array` returns "object", and `Array.isArray(array)` returns true if the array is an array and false otherwise.
