### Line Breaks

- A line break is a way of ending a line of text and starting a new one without creating a new paragraph.
- In HTML, line breaks are created by using the `<br>` tag, which is an empty element that does not need a closing tag.
- The `<br>` tag can be used anywhere within the body of an HTML document, and it will force the text after it to start on a new line.
- For example, the following HTML code will display the text "Hello" and "World" on two separate lines:

```html
<p>Hello<br>World</p>
```

- The output will look like this:

<p>Hello<br>World</p>

- Line breaks can be useful for creating lists, addresses, poems, or any other text that needs to be formatted in a specific way.
- However, line breaks should not be used to create extra space between paragraphs or sections of text. For that purpose, CSS properties such as margin or padding should be used instead.
