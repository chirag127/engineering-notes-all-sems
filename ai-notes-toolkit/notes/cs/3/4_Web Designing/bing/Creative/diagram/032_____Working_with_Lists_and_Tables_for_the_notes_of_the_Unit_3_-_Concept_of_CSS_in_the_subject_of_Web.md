### Working with Lists and Tables

- Lists and tables are common elements in web pages that can be styled with CSS.
- Lists can be ordered (numbered) or unordered (bulleted). Tables can have rows, columns, cells, headers, footers, captions, and borders.
- CSS properties for lists include `list-style-type`, `list-style-image`, `list-style-position`, and `list-style`. These properties can change the appearance and position of the list markers.
- CSS properties for tables include `border`, `border-collapse`, `border-spacing`, `width`, `height`, `padding`, `margin`, `text-align`, `vertical-align`, `background-color`, `background-image`, and `background-repeat`. These properties can change the appearance and layout of the table and its elements.
- CSS selectors for lists and tables include `ul`, `ol`, `li`, `table`, `tr`, `td`, `th`, `thead`, `tbody`, `tfoot`, and `caption`. These selectors can target specific elements or groups of elements in the list or table.
- CSS pseudo-classes for lists and tables include `:first-child`, `:last-child`, `:nth-child`, `:nth-of-type`, `:first-of-type`, `:last-of-type`, `:empty`, and `:not`. These pseudo-classes can target specific elements based on their position, type, or content in the list or table.
- CSS pseudo-elements for lists and tables include `::before` and `::after`. These pseudo-elements can insert content before or after the list or table element.
- CSS can also create custom lists and tables using `display`, `position`, `float`, `clear`, `flex`, `grid`, and other layout properties. These properties can change the way the list or table elements are arranged and aligned on the page.
