### Introduction

CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page. CSS can control the layout, colors, fonts, backgrounds, borders, margins, padding, and other aspects of the presentation of HTML elements. CSS can also create animations, transitions, and transformations for HTML elements.

Some of the benefits of using CSS are:

- It separates the content from the presentation, making the HTML code more readable and maintainable.
- It allows the web designer to apply consistent styles across multiple web pages, reducing the amount of code and improving the performance.
- It enables the web designer to create responsive web pages that can adapt to different screen sizes and devices.
- It provides a variety of selectors, properties, and values that can create complex and dynamic designs.

CSS can be applied to HTML elements in three ways:

- Inline style: The style attribute is added to an HTML element and contains one or more CSS declarations.
- Internal style: The `<style>` element is added to the `<head>` section of an HTML document and contains one or more CSS rules.
- External style: The `<link>` element is added to the `<head>` section of an HTML document and links to an external CSS file that contains one or more CSS rules.
