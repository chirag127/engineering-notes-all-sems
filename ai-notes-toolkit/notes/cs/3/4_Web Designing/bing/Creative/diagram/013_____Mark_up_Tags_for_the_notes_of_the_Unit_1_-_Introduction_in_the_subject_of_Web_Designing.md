# Mark up Tags

- Mark up tags are the elements that define the structure and content of a web page.
- Mark up tags are written in a language called HTML (HyperText Markup Language), which is the standard language for creating web pages and web applications.
- Mark up tags consist of a start tag, an end tag, and optionally some attributes and content between them.
- The start tag begins with a left angle bracket (<) followed by the name of the element and any attributes, and ends with a right angle bracket (>).
- The end tag begins with a left angle bracket followed by a slash (/) and the name of the element, and ends with a right angle bracket.
- The content is the text or other elements that are displayed on the web page between the start and end tags.
- The attributes are additional information that modify the behavior or appearance of the element. They are written as name-value pairs inside the start tag, separated by spaces and enclosed in quotation marks.
- For example, the following mark up tag defines a paragraph element with the attribute align="center" and the content "This is a paragraph":

```html
<p align="center">This is a paragraph</p>
```

- Some mark up tags are self-closing, which means they do not have an end tag and the start tag ends with a slash before the right angle bracket. For example, the following mark up tag defines an image element with the attributes src="logo.png" and alt="Logo":

```html
<img src="logo.png" alt="Logo" />
```

- Some mark up tags are container elements, which means they can contain other elements as their content. For example, the following mark up tag defines a div element, which is a generic container for grouping other elements, with the attribute id="container" and the content of two paragraph elements:

```html
<div id="container">
  <p>This is the first paragraph</p>
  <p>This is the second paragraph</p>
</div>
```

- Some mark up tags are inline elements, which means they can be placed inside other elements without breaking the flow of the content. For example, the following mark up tag defines a span element, which is a generic inline container for styling or grouping other elements, with the attribute style="color:red" and the content "This is red text":

```html
<span style="color:red">This is red text</span>
```

- Some mark up tags are block-level elements, which means they create a new line and occupy the entire width of the parent element. For example, the following mark up tag defines a heading element, which is a block-level element for displaying a title or a subtitle, with the content "This is a heading":

```html
<h1>This is a heading</h1>
```

- Some mark up tags are semantic elements, which means they convey some meaning or information about the content they contain. For example, the following mark up tag defines a section element, which is a semantic element for defining a thematic group of content, with the content of a heading and a paragraph:

```html
<section>
  <h1>This is a section</h1>
  <p>This is a paragraph in the section</p>
</section>
```

- Some mark up tags are non-semantic elements, which means they do not convey any meaning or information about the content they contain. For example, the following mark up tag defines a b element, which is a non-semantic element for making the text bold, with the content "This is bold text":

```html
<b>This is bold text</b>
```

- Mark up tags are case-insensitive, which means they can be written in uppercase, lowercase, or mixed case. However, it is a good practice to write them in lowercase for consistency and readability.
- Mark up tags must follow the syntax rules of HTML, which include:

  - Every start tag must have a corresponding end tag, unless it is a self-closing tag.
  - Every element must be properly nested, which means the start and end tags of an element must be contained within the start and end tags of its parent element.
  - Every attribute must have a value, which must be enclosed in quotation marks.
  - Every element and attribute name must be valid, which means they must be predefined in the HTML specification or registered as custom elements or attributes.
