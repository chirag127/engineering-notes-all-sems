# JS Objects

- An object is a collection of properties that store values and functions that perform actions.
- An object can be created using the object literal syntax, which uses curly braces `{}` to enclose the properties and functions.
- A property is a key-value pair, where the key is a name or identifier and the value can be any data type, such as a string, number, boolean, array, or another object.
- A function inside an object is called a method, and it can access the object's properties using the `this` keyword.
- An object can be accessed and modified using the dot notation `object.property` or the bracket notation `object["property"]`.
- An object can also be created using the `new` keyword and a constructor function, which is a function that defines the properties and methods of the object.
- A constructor function can be named using the Pascal case convention, such as `Person`, `Car`, or `Book`.
- A constructor function can use the `this` keyword to refer to the object being created, and assign values to its properties and methods.
- An object created by a constructor function can inherit the properties and methods of another object using the `prototype` property, which is a special object that links the object to its parent object.
- The `prototype` property can be used to add new properties and methods to all objects created by the same constructor function, or to override existing ones.
- The `Object` constructor function is the root of all objects in JavaScript, and it provides some built-in methods and properties that can be used on any object, such as `Object.keys()`, `Object.values()`, `Object.assign()`, and `Object.prototype.toString()`.
- An object can also be created using the `Object.create()` method, which takes an existing object as a parameter and returns a new object that inherits from it.
- An object can also be created using the `class` keyword, which is a syntactic sugar for the constructor function and prototype pattern.
- A class can have a `constructor` method that defines the properties and methods of the object, and can use the `super` keyword to call the constructor of the parent class.
- A class can also have other methods that define the behavior of the object, and can use the `static` keyword to define methods that belong to the class itself, not the object.
- A class can also use the `extends` keyword to inherit from another class, and can use the `get` and `set` keywords to define getter and setter methods that access or modify the object's properties.
