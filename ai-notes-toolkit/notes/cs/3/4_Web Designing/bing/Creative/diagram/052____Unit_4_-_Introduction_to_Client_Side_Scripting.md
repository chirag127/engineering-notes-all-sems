## Unit 4 - Introduction to Client Side Scripting

- Client side scripting is a technique of writing code that runs on the web browser of the user, rather than on the web server of the website.
- Client side scripting can enhance the interactivity, functionality, and usability of a web page by allowing the user to interact with the page without reloading it or sending requests to the server.
- Client side scripting can also reduce the load on the web server and the network bandwidth by performing some tasks locally on the user's device.
- Client side scripting languages are usually interpreted, meaning that they are translated into machine code by the browser at runtime, rather than compiled beforehand.
- Some examples of client side scripting languages are JavaScript, VBScript, JScript, TypeScript, CoffeeScript, etc.
- Client side scripting languages can access and manipulate the Document Object Model (DOM) of the web page, which is a tree-like representation of the HTML elements and their attributes, styles, and events.
- Client side scripting languages can also use various APIs (Application Programming Interfaces) to access and use the features and functionalities of the web browser, such as geolocation, local storage, web sockets, web workers, etc.
- Client side scripting languages can also communicate with the web server using various methods, such as AJAX (Asynchronous JavaScript and XML), JSON (JavaScript Object Notation), REST (Representational State Transfer), etc.
- Client side scripting languages can also use various frameworks and libraries to simplify and enhance the development process, such as jQuery, React, Angular, Vue, etc.
