# Registering domains for the notes of the Unit 5 - Web Hosting in the subject of Web Designing

- A domain name is the name of a website that users type in the browser to access it, such as google.com or wikipedia.org.
- Registering a domain name is the process of finding an available web address and signing up to use it for a certain period of time, usually one year or more.
- To register a domain name, one needs to choose a domain name registrar, which is a company that provides the service of registering and managing domain names.
- Some examples of domain name registrars are Google Domains, GoDaddy, Namecheap, and Domain.com .
- Some domain name registrars also offer web hosting services, which are the services that store and deliver the files and data of a website to the users. Web hosting is necessary for a website to be online and accessible.
- Some examples of web hosting companies are Hostinger, A2 Hosting, Bluehost, and SiteGround.
- If a domain name registrar does not offer web hosting, one needs to purchase and register the domain name with one company and host the website with another company.
- To register a domain name with a domain name registrar, one needs to follow these steps :
  - Choose a domain name that is unique, memorable, and relevant to the website's purpose and audience.
  - Check the availability of the domain name by using the search tool on the registrar's website. If the domain name is taken, one can try a different name or a different domain extension, such as .com, .net, .org, etc.
  - Add the domain name to the cart and select the registration period, which is the length of time that one wants to use the domain name. The longer the period, the cheaper the annual fee.
  - Complete the checkout process by providing personal and payment information and agreeing to the domain name contract, which is the agreement between the registrar and the registrant that defines the terms and conditions of using the domain name.
  - Verify the domain name registration by following the instructions sent by the registrar to the email address provided during the checkout process. This may include clicking on a link or entering a code.
  - Set up the domain name by connecting it to the web hosting service, either by using the tools provided by the registrar or the hosting company, or by manually changing the domain name servers (DNS) settings.
- To avoid losing the domain name, one needs to renew the registration before it expires by paying the renewal fee. Some registrars offer automatic renewal options or reminders to help the registrants keep their domain names.
