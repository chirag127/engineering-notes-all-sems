# Controlling Fonts

- Fonts are an important aspect of web design, as they affect the appearance and readability of the text on a web page.
- CSS provides various properties to control the fonts used on a web page, such as font-family, font-size, font-weight, font-style, and font-variant.
- The font-family property specifies the name of the font or a list of fonts to use for the text. The browser will try to use the first font in the list that is available on the system. If none of the fonts are available, the browser will use a default font.
- The font-size property specifies the size of the font in pixels, points, ems, percentages, or other units. The default font size is 16 pixels. The font size can be adjusted relative to the parent element's font size using keywords such as larger, smaller, or medium.
- The font-weight property specifies the weight or boldness of the font. The possible values are normal, bold, bolder, lighter, or a numeric value from 100 to 900. The higher the number, the bolder the font.
- The font-style property specifies the style or slant of the font. The possible values are normal, italic, oblique, or inherit. The italic value makes the font slanted to the right, while the oblique value makes the font slanted to the left or right depending on the direction of the text.
- The font-variant property specifies whether the text should be displayed in small-caps or normal. The small-caps value makes the lowercase letters look like small uppercase letters, while the normal value does not change the text.

- Here is an example of how to use the font properties in CSS:

```css
p {
  font-family: Arial, Helvetica, sans-serif;
  font-size: 14px;
  font-weight: bold;
  font-style: italic;
  font-variant: small-caps;
}
```

- This will make the text inside the `<p>` elements look like this:

<p style="font-family: Arial, Helvetica, sans-serif; font-size: 14px; font-weight: bold; font-style: italic; font-variant: small-caps;">This is an example of how the text will look like.</p>
