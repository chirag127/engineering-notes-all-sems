# CSS Id and Class

- CSS Id and Class are two types of selectors that can be used to apply styles to HTML elements.
- A selector is a pattern that matches one or more elements in a document.
- A CSS Id selector matches an element that has a specific id attribute value. The syntax is `#id` where `id` is the value of the id attribute.
- A CSS Class selector matches an element that has a specific class attribute value. The syntax is `.class` where `class` is the value of the class attribute.
- An element can have multiple class values separated by spaces, and a class selector can match any of them.
- An element can only have one id value, and an id selector can only match one element in a document.
- Id selectors have higher specificity than class selectors, which means they override the styles applied by class selectors if there is a conflict.
- Id selectors are useful for styling unique elements that need to be identified by a single name, such as a logo, a header, or a footer.
- Class selectors are useful for styling groups of elements that share some common characteristics, such as a button, a link, or a paragraph.
- Id and class selectors can be combined with other selectors, such as element selectors, pseudo-class selectors, or attribute selectors, to create more complex and specific rules.
- Id and class selectors can also be used to target elements for JavaScript manipulation or DOM manipulation.
