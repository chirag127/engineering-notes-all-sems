# Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for **Cascading Style Sheets** and it is a **stylesheet language** that is used to **style and layout web pages** .
- CSS can be used to **alter the font, color, size, and spacing** of the content, **split it into multiple columns**, or **add animations and other decorative features** to the web pages.
- CSS can also be used to **adapt the presentation** of the web pages to different types of devices, such as **screen, paper, speech, or other media**.
- CSS works by applying **rules** to the elements or groups of elements on the web page. For example, a rule can specify that the main heading should be shown as large red text.
- CSS rules consist of two parts: a **selector** and a **declaration block**. The selector identifies which element or elements the rule applies to, and the declaration block contains one or more declarations that specify the style properties and values for the selected element(s).
- A declaration consists of a **property** and a **value**, separated by a colon and followed by a semicolon. For example, `color: red;` is a declaration that sets the color property to red.
- CSS rules can be written in three ways: **inline**, **internal**, or **external**. Inline CSS is written directly in the HTML element using the `style` attribute, internal CSS is written in the `<style>` tag in the `<head>` section of the HTML document, and external CSS is written in a separate file with the `.css` extension and linked to the HTML document using the `<link>` tag.
- CSS has a **cascading** mechanism that determines how the rules are applied when there are multiple rules that match the same element. The cascading order is based on the **source**, **specificity**, and **importance** of the rules. The source refers to where the rule comes from, such as inline, internal, external, or user agent (browser) stylesheets. The specificity refers to how specific the selector is, such as by element, class, id, or pseudo-class. The importance refers to whether the rule has the `!important` keyword that overrides other rules.
- CSS has a **box model** that defines how the layout of the elements is calculated. The box model consists of four parts: **content**, **padding**, **border**, and **margin**. The content is the actual text or image inside the element, the padding is the space between the content and the border, the border is the line that surrounds the element, and the margin is the space between the border and the adjacent elements. The width and height properties of an element refer to the content area, not the entire box. To include the padding and border in the width and height calculations, the `box-sizing` property can be set to `border-box`.
- CSS has various **selectors**, **properties**, and **values** that can be used to create different styles and effects for the web pages. Some of the common selectors are: element, class, id, attribute, descendant, child, sibling, pseudo-class, and pseudo-element. Some of the common properties are: font-family, font-size, font-weight, color, background-color, background-image, border, margin, padding, display, position, float, clear, width, height, overflow, text-align, vertical-align, line-height, and list-style. Some of the common values are: keywords, lengths, percentages, colors, URLs, and functions.
