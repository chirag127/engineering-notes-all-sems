# Working with Arrays

- An array is a data structure that can store multiple values of the same or different types in a single variable.
- An array can be created by using the `Array` constructor or by using the array literal syntax `[]`.
- An array can be accessed by using the index notation `[]`, where the index is a zero-based integer that represents the position of the element in the array.
- An array can be modified by using the assignment operator `=` or by using various methods such as `push`, `pop`, `shift`, `unshift`, `splice`, `slice`, `sort`, `reverse`, etc.
- An array can be iterated over by using a `for` loop, a `for...of` loop, a `for...in` loop, or by using various methods such as `forEach`, `map`, `filter`, `reduce`, etc.
- An array can be converted to a string by using the `toString` method or the `join` method.
- An array can be checked for its length by using the `length` property or the `isArray` method.
