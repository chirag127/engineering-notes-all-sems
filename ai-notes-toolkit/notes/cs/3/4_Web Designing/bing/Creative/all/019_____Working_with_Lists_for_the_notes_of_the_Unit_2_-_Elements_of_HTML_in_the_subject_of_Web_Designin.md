# Working with Lists

- Lists are used to display a series of related items in a structured and organized way.
- HTML provides three types of lists: ordered lists, unordered lists, and definition lists.
- Ordered lists use numbers, letters, or roman numerals to indicate the order or sequence of the list items. They are created with the `<ol>` element, and each list item is enclosed in a `<li>` element.
- Unordered lists use bullets, circles, squares, or other symbols to mark the list items. They are created with the `<ul>` element, and each list item is enclosed in a `<li>` element.
- Definition lists consist of pairs of terms and definitions. They are created with the `<dl>` element, and each term is enclosed in a `<dt>` element, while each definition is enclosed in a `<dd>` element.
- Lists can be nested inside other lists to create sublists. To nest a list, simply place another list element inside a `<li>` element of the parent list.
- Lists can be styled with CSS properties, such as `list-style-type`, `list-style-image`, `list-style-position`, and `list-style`.
- Lists can also be used to create navigation menus, tables of contents, and other interactive elements.
