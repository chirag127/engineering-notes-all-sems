# Unit 3 - Concept of CSS in Web Designing

CSS stands for **Cascading Style Sheets**. It is a **stylesheet language** that is used to **style and layout web pages**. CSS can alter the **appearance** of HTML elements, such as font, color, size, spacing, alignment, background, borders, etc. CSS can also create **visual effects**, such as animations, transitions, transformations, filters, etc. CSS can also control the **adaptability** of web pages, such as responsiveness, media queries, grids, flexbox, etc.

Some of the main concepts of CSS are:

- **Selectors**: Selectors are patterns that match HTML elements and apply styles to them. There are different types of selectors, such as element, class, id, attribute, pseudo-class, pseudo-element, etc. For example, `p` is an element selector that matches all `<p>` elements, `.red` is a class selector that matches all elements with `class="red"`, and `:hover` is a pseudo-class selector that matches elements when the mouse pointer is over them.
- **Properties and values**: Properties and values are the building blocks of CSS rules. Properties are keywords that specify what aspect of an element to style, and values are the possible settings for each property. For example, `color` is a property that specifies the text color of an element, and `red` is a value that sets the color to red. Properties and values are separated by a colon (`:`) and followed by a semicolon (`;`). For example, `color: red;`.
- **Rules and declarations**: Rules and declarations are the basic units of CSS syntax. A rule consists of a selector and a declaration block. A declaration block consists of one or more declarations enclosed in curly braces (`{}`). For example, `p { color: red; }` is a rule that applies the color red to all `<p>` elements. A declaration consists of a property and a value. For example, `color: red;` is a declaration that sets the color property to red.
- **Cascading and specificity**: Cascading and specificity are the mechanisms that determine how conflicting CSS rules are resolved. Cascading means that the order of the rules matters, and the later rules override the earlier ones. Specificity means that the more specific the selector, the higher the priority of the rule. For example, if there are two rules that apply to the same element, such as `p { color: red; }` and `p.blue { color: blue; }`, the second rule will win because it has a higher specificity (class selector is more specific than element selector).
- **Inheritance and the box model**: Inheritance and the box model are the concepts that describe how CSS affects the structure and layout of web pages. Inheritance means that some CSS properties are passed down from parent elements to child elements, unless they are overridden by more specific rules. For example, if the `<body>` element has a font size of 16px, all the text elements inside it will inherit the same font size, unless they have their own font size specified. The box model means that every element on a web page is represented by a rectangular box, which has four components: content, padding, border, and margin. The content is the actual text or image inside the element, the padding is the space between the content and the border, the border is the line that surrounds the element, and the margin is the space between the element and its neighboring elements. The box model affects how elements are sized and positioned on the web page.
