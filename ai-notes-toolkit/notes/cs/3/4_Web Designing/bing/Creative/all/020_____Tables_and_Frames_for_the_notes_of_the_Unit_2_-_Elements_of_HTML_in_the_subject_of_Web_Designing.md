# Tables and Frames

## Tables
- A table is a way of organizing data in rows and columns.
- Tables are created using the `<table>` tag, which contains one or more `<tr>` tags for each row, and one or more `<td>` tags for each cell in a row.
- Tables can also have a header row, which is created using the `<th>` tag instead of the `<td>` tag, and a caption, which is created using the `<caption>` tag inside the `<table>` tag.
- Tables can have various attributes to control their appearance and layout, such as `border`, `cellpadding`, `cellspacing`, `align`, `width`, `height`, etc.
- Tables can also have nested tables, which are tables inside other tables, created by using the `<table>` tag inside a `<td>` tag.

## Frames
- Frames are a way of dividing a web page into multiple sections, each of which can display a different HTML document.
- Frames are created using the `<frameset>` tag, which contains one or more `<frame>` tags for each section.
- Frames can have various attributes to control their size and position, such as `rows`, `cols`, `frameborder`, `scrolling`, `noresize`, etc.
- Frames can also have a name attribute, which can be used to target links to specific frames using the `target` attribute of the `<a>` tag.
- Frames can also have a `<noframes>` tag, which contains alternative content for browsers that do not support frames.
