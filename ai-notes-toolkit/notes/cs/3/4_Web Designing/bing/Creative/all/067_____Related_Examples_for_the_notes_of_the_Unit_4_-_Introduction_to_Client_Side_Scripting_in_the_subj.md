# Related Examples for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- Client-side scripting is a technique of writing code that runs on the user's browser, rather than on the server.
- Client-side scripting can be used to enhance the interactivity, functionality, and performance of web pages.
- Client-side scripting can also reduce the load on the server and the network by performing some tasks locally on the user's device.
- Some of the common client-side scripting languages are JavaScript, TypeScript, jQuery, Angular, React, Vue, and Blazor WebAssembly.
- Some of the common examples of client-side scripting are:

  - **Form validation**: Client-side scripts can check the user input for errors, such as missing or invalid data, and display appropriate messages or warnings before submitting the form to the server. This can improve the user experience and save the server resources.
  - **Dynamic content**: Client-side scripts can manipulate the HTML elements of a web page, such as adding, removing, or changing the content, style, or attributes of the elements. This can create dynamic and responsive web pages that can change according to the user's actions or preferences.
  - **Animation and effects**: Client-side scripts can create animations and effects on the web page, such as fading, sliding, zooming, or rotating the elements. This can enhance the visual appeal and interactivity of the web page.
  - **User interface components**: Client-side scripts can create user interface components, such as menus, tabs, accordions, modals, tooltips, or popups, that can provide additional information or functionality to the user. These components can also be customized and styled according to the web page design.
  - **Web storage and cookies**: Client-side scripts can store data on the user's device, using web storage or cookies, that can persist across multiple visits or sessions. This can enable features such as remembering the user's preferences, settings, or login information, or tracking the user's behavior or activity on the web page.
