# Markup Tags

- Markup tags are the elements that define the structure and content of a web page.
- Markup tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p>.
- The first tag in a pair is called the start tag or opening tag, and the second tag is called the end tag or closing tag.
- The content between the start and end tags is called the element content, and the tags and content together are called the element.
- Some markup tags are self-closing, meaning they do not need an end tag, such as <img> or <br>.
- Markup tags can have attributes, which are additional information that modify the behavior or appearance of the element.
- Attributes are written inside the start tag, after the tag name, and consist of a name and a value, separated by an equal sign (=).
- The value of an attribute is usually enclosed in quotation marks (" or '), such as <img src="logo.png" alt="Logo">.
- Some attributes are required for certain elements, such as the src attribute for the <img> element, and some are optional, such as the alt attribute for the <img> element.
- Markup tags can be nested, meaning one element can contain another element, such as <p><strong>This is a paragraph with bold text.</strong></p>.
- The order of nesting is important, and the elements must be closed in the reverse order of opening, such as <p><em><strong>This is correct.</strong></em></p> and not <p><em><strong>This is wrong.</em></strong></p>.
- Markup tags are case-insensitive, meaning they can be written in uppercase, lowercase, or mixed case, such as <P>, <p>, or <P>.
- However, it is recommended to use a consistent style for readability and maintainability, such as lowercase for HTML tags and uppercase for XML tags.
- Markup tags can be divided into two categories: structural and semantic.
- Structural tags define the layout and presentation of the web page, such as <head>, <body>, <div>, <span>, etc.
- Semantic tags define the meaning and purpose of the content, such as <h1>, <p>, <a>, <img>, etc.
- Semantic tags are preferred over structural tags, as they provide more information to the browsers, search engines, and assistive technologies, such as screen readers.
- Semantic tags also make the web page more accessible, understandable, and maintainable.
