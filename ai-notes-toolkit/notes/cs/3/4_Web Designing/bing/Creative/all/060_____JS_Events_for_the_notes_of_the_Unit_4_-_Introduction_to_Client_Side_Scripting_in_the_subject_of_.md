# JS Events

## What are JS Events?

- JS Events are the changes in the state of an object or element in the browser that can be detected and reacted to by JavaScript code  .
- JS Events can be triggered by user actions, such as clicking, typing, scrolling, etc., or by browser actions, such as loading, resizing, etc.   .
- JS Events can be used to provide a dynamic and interactive interface to a webpage, by executing some code when an event occurs   .

## How to use JS Events?

- JS Events can be used by attaching event handlers or event listeners to the elements that can fire events   .
- An event handler is a function that is assigned to an element's event attribute, such as `onclick`, `onload`, `onsubmit`, etc..
- An event listener is a function that is registered to an element using the `addEventListener()` method, which takes the event type and the callback function as arguments .
- An event handler or listener can access the event object, which contains information about the event, such as the type, target, timestamp, coordinates, etc. .
- An event handler or listener can also use the `this` keyword to refer to the element that fired the event.

## What are some common JS Events?

- There are many types of JS Events, which can be categorized into different groups, such as mouse events, keyboard events, form events, window events, etc.  .
- Some common JS Events are:

  - `click`: fired when the user clicks on an element.
  - `load`: fired when the browser finishes loading a document or an element.
  - `change`: fired when the value of an input element changes.
  - `submit`: fired when the user submits a form.
  - `resize`: fired when the browser window is resized.
  - `scroll`: fired when the user scrolls the document or an element.
  - `keydown`: fired when the user presses a key on the keyboard.
  - `keyup`: fired when the user releases a key on the keyboard.
  - `mouseover`: fired when the mouse pointer moves over an element.
  - `mouseout`: fired when the mouse pointer moves out of an element.
