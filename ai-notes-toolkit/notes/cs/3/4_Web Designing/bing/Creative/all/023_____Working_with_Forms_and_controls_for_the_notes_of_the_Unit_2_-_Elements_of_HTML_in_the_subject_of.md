# Working with Forms and Controls in HTML

- A form is a collection of elements that allow a user to enter and submit data to a server.
- A form is created using the `<form>` element, which has attributes such as `action`, `method`, and `enctype` to specify how the data is sent and processed.
- A form can contain different types of input elements, such as text fields, checkboxes, radio buttons, buttons, etc. Each input element has a `name` attribute that identifies the data, and a `value` attribute that holds the data.
- Some input elements also have a `type` attribute that defines the kind of input, such as `text`, `password`, `email`, `number`, `date`, `color`, etc.
- Some input elements can be grouped together using the `<fieldset>` and `<legend>` elements, which provide a label and a border for the group.
- Some input elements can be validated using the `required`, `pattern`, `min`, `max`, `minlength`, `maxlength`, etc. attributes, which enforce certain rules on the data.
- A form can also contain other elements, such as `<label>`, `<select>`, `<option>`, `<textarea>`, `<output>`, etc. that provide additional functionality and accessibility for the form.
- A form can be submitted using a button with the `type="submit"` attribute, which triggers the `action` attribute of the form.
- A form can also be reset using a button with the `type="reset"` attribute, which clears all the input values in the form.
- A form can be styled using CSS properties, such as `display`, `margin`, `padding`, `border`, `background`, `font`, etc.
- A form can also be enhanced using JavaScript events, such as `onsubmit`, `onchange`, `oninput`, `onclick`, etc. that allow for dynamic interaction and feedback.
- A form can also be customized using custom form controls, which are elements that mimic the behavior and appearance of native form controls, but with more flexibility and creativity.
- A custom form control can be created using HTML, CSS, and JavaScript, and can use attributes such as `tabindex`, `role`, `aria-label`, etc. to provide keyboard and assistive technology accessibility.
- A custom form control can also use the `<input type="hidden">` element to store and send the data to the server.
