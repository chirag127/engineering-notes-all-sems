## Unit 2 - Elements of HTML

- HTML stands for HyperText Markup Language and is used to create the structure and content of web pages.
- HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear a certain way, or act a certain way.
- The enclosing tags can make a word or image hyperlink to somewhere else, can italicize words, can make the font bigger or smaller, and so on.
- An HTML element is defined by a start tag, some content, and an end tag.
- The start tag is the name of the element, enclosed in angle brackets. The end tag is the same as the start tag, but with a forward slash before the element name.
- For example, to make a word bold, you would use the `<strong>` element: `<strong>This word is bold.</strong>`
- Some common HTML elements include `<p>` for paragraphs, `<a>` for links, `<img>` for images, `<ul>` and `<ol>` for lists, and `<div>` for divisions or sections of the page.
- HTML also has attributes, which provide additional information about an element. Attributes are defined within the start tag, after the element name, and are made up of a name and a value, separated by an equals sign.
- For example, to add a link to a word, you would use the `<a>` element with the `href` attribute: `<a href="https://www.example.com">This is a link.</a>`
- Attributes can also be used to add classes or IDs to elements, which can be used for styling or scripting purposes.
- It is important to properly nest HTML elements, meaning that if one element is contained within another, the start and end tags of the inner element must be completely contained within the start and end tags of the outer element.
- HTML also has a specific document structure, with the `<html>` element enclosing the entire page, the `<head>` element containing metadata and the `<body>` element containing the page's content.
- HTML5 introduced new semantic elements, such as `<header>`, `<nav>`, `<article>`, `<section>`, `<aside>`, and `<footer>`, to provide more meaningful structure to web pages.
- It is important to write valid and well-formed HTML, as it ensures that the page will be displayed correctly in all browsers and can be accessed by all users, including those using assistive technologies.
