### CSS Styling

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.

Here are some key points to remember when using CSS for styling:

1. CSS can be added to HTML documents in three ways: inline, internal, and external.
2. Inline styles are added directly to an HTML element using the `style` attribute.
3. Internal styles are defined within the `style` element, inside the `head` section of an HTML page.
4. External styles are defined in a separate CSS file, which is linked to the HTML document using the `link` element.
5. CSS selectors are used to select the HTML elements to which the styles should be applied.
6. The most common CSS selectors are element, class, and ID selectors.
7. CSS properties are used to define the styles for the selected elements.
8. CSS properties are defined using a property-value pair, separated by a colon.
9. Multiple CSS properties can be defined for a single selector by separating them with a semicolon.
10. CSS styles can be inherited from parent elements to child elements.
