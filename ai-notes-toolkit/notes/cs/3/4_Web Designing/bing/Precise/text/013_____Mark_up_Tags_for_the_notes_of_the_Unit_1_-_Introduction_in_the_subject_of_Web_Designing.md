### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

- Markup tags are used to define the structure and layout of a web page.
- They are used to format text, add images, create links, and more.
- Some common markup tags include `<html>`, `<head>`, `<body>`, `<h1>` to `<h6>`, `<p>`, `<a>`, `<img>`, `<ul>`, `<ol>`, `<li>`, `<table>`, `<tr>`, `<td>`, `<th>`, `<form>`, `<input>`, `<textarea>`, `<select>`, `<option>`, `<button>`, `<label>`, `<br>`, `<hr>`.
- These tags are used in pairs, with an opening tag and a closing tag, such as `<p>` and `</p>`.
- Some tags, such as `<br>` and `<hr>`, are self-closing and do not require a closing tag.
- The `<html>` tag is used to define the root of an HTML document and is the container for all other HTML elements.
- The `<head>` tag is used to define information about the document, such as the title, meta information, and links to stylesheets and scripts.
- The `<body>` tag is used to define the main content of the document.
- The `<h1>` to `<h6>` tags are used to define headings, with `<h1>` being the most important and `<h6>` being the least important.
- The `<p>` tag is used to define a paragraph of text.
- The `<a>` tag is used to define a hyperlink.
- The `<img>` tag is used to embed an image in the document.
- The `<ul>` and `<ol>` tags are used to define unordered and ordered lists, respectively, and the `<li>` tag is used to define list items.
- The `<table>` tag is used to define a table, with the `<tr>` tag defining a table row, the `<td>` tag defining a table cell, and the `<th>` tag defining a table header cell.
- The `<form>` tag is used to define a form for user input, with the `<input>`, `<textarea>`, `<select>`, `<option>`, `<button>`, and `<label>` tags used to define form controls.
- The `<br>` tag is used to insert a line break, and the `<hr>` tag is used to insert a horizontal rule.
