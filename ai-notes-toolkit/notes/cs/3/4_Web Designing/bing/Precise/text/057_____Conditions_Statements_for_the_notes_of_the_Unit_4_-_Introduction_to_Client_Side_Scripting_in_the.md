### Conditions Statements for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- Conditional statements are used to perform different actions based on different conditions.
- In client-side scripting, conditional statements are used to control the flow of the program.
- The most common conditional statements used in client-side scripting are `if`, `else`, `else if`, and `switch`.
- The `if` statement is used to specify a block of code to be executed if a specified condition is true.
- The `else` statement is used to specify a block of code to be executed if the same condition is false.
- The `else if` statement is used to specify a new condition to test if the first condition is false.
- The `switch` statement is used to perform different actions based on different conditions.
- Conditional statements can be nested, meaning that one conditional statement can be placed inside another.
- Conditional statements can be used in combination with logical operators such as `&&`, `||`, and `!` to create more complex conditions.
- Conditional statements are an essential part of client-side scripting and are used to create dynamic and interactive web pages.
