### JS Functions

Functions are one of the fundamental building blocks in JavaScript. A function is a set of statements that performs a specific task and can be reused throughout the code. Functions can be defined using function declarations or function expressions.

1. **Function Declarations:** A function declaration defines a function with the specified parameters. The syntax for a function declaration is as follows:
```
function functionName(parameters) {
  // function body
}
```
2. **Function Expressions:** A function expression defines a function as part of a larger expression, such as a variable assignment. The syntax for a function expression is as follows:
```
let functionName = function(parameters) {
  // function body
}
```
3. **Function Parameters:** Functions can take parameters, which are values passed into the function when it is called. These values can be used within the function to perform calculations or other tasks.
4. **Function Return Values:** Functions can return a value using the `return` statement. The value returned by the function can be used in the code that called the function.
5. **Function Scope:** Variables defined within a function have local scope, meaning they are only accessible within the function. Variables defined outside of a function have global scope and are accessible throughout the code.

Functions are a powerful tool in JavaScript, allowing for code reuse and modularization. By defining functions to perform specific tasks, code can be made more readable and maintainable.
