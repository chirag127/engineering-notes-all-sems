### Defining Name Servers

- Name servers are an essential component of the Domain Name System (DNS).
- DNS is responsible for translating human-readable domain names into IP addresses that computers can understand.
- Name servers store DNS records for a domain and respond to DNS queries from clients.
- When a client wants to access a website, it sends a DNS query to a name server asking for the IP address of the domain.
- The name server checks its records and returns the IP address to the client, which can then connect to the website.
- Each domain must have at least two name servers, which are specified during the domain registration process.
- Name servers can be managed by the domain registrar, a web hosting company, or the domain owner.
- It is important to ensure that the name servers for a domain are correctly configured and functioning properly, as any issues can result in the website being inaccessible.
