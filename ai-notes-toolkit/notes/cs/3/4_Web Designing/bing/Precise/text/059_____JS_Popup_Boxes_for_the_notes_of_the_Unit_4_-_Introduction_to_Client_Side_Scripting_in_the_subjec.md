### JS Popup Boxes

JavaScript provides three types of popup boxes: Alert box, Confirm box, and Prompt box.

1. **Alert Box:** An alert box is used to display a message to the user. The user must click "OK" to proceed. The syntax for an alert box is `window.alert("message");`.

2. **Confirm Box:** A confirm box is used to ask the user to verify or accept something. The user must click either "OK" or "Cancel" to proceed. The syntax for a confirm box is `window.confirm("message");`.

3. **Prompt Box:** A prompt box is used to ask the user to input a value before entering a page. The user must click either "OK" or "Cancel" to proceed. The syntax for a prompt box is `window.prompt("message", "default value");`.

These popup boxes can be useful for providing information to the user, asking for confirmation before performing an action, or prompting the user for input. They are a simple and effective way to interact with the user in client-side scripting.
