### Web Hosting Basics

1. **Web hosting** is a service that allows individuals and organizations to make their website accessible on the internet.
2. A **web host** is a company that provides the technology and services needed for a website to be viewed on the internet.
3. Websites are stored on **servers**, which are powerful computers that are connected to the internet.
4. When someone wants to view a website, they enter the website's address into their web browser. The browser then sends a request to the server where the website is stored, and the server sends the website's files back to the browser to be displayed.
5. There are several types of web hosting, including **shared hosting**, **dedicated hosting**, **VPS hosting**, and **cloud hosting**.
6. **Shared hosting** is the most common type of web hosting, where multiple websites share the same server and resources.
7. **Dedicated hosting** is where a single website has its own server and resources.
8. **VPS hosting** is a type of hosting where multiple websites share the same server, but each website has its own resources.
9. **Cloud hosting** is a type of hosting where a website's files are stored on multiple servers, allowing for greater flexibility and scalability.
10. When choosing a web host, it is important to consider factors such as the amount of storage and bandwidth needed, the level of technical support provided, and the cost of the service.
