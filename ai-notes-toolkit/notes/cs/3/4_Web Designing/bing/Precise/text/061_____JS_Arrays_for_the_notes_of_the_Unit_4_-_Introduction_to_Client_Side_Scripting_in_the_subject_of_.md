### JS Arrays

- An array is a data structure that can store a collection of values.
- Each value in an array is called an element, and each element has a unique index number.
- The index number starts from 0 and increments by 1 for each element.
- Arrays can store values of different data types, including numbers, strings, and objects.
- To create an array, you can use the square bracket notation `[]` or the `Array` constructor.
- To access an element in an array, you can use the square bracket notation with the index number of the element.
- To add an element to an array, you can use the `push` method or assign a value to the next available index.
- To remove an element from an array, you can use the `pop` method or the `splice` method.
- You can use the `length` property to get the number of elements in an array.
- You can use various methods to manipulate arrays, such as `map`, `filter`, `reduce`, `sort`, and `reverse`.
- You can also use the spread operator `...` to copy or merge arrays.
