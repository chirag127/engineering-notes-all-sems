### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. To create an HTML document, open a text editor such as Notepad or TextEdit and save the file with an `.html` extension.
2. The first line of the HTML document should be the document type declaration, which specifies the version of HTML being used. For HTML5, the declaration is `<!DOCTYPE html>`.
3. The next element is the `<html>` tag, which is the root element of the HTML page. It should have a `lang` attribute that specifies the language of the document.
4. Within the `<html>` tag, there should be a `<head>` element that contains metadata about the page, such as the title and character encoding.
5. The `<title>` element within the `<head>` specifies the title of the page, which is displayed in the browser's title bar or tab.
6. The `<meta>` element can be used to specify the character encoding of the page, using the `charset` attribute. For example, `<meta charset="UTF-8">` specifies that the page uses the UTF-8 character encoding.
7. After the `<head>` element, there should be a `<body>` element that contains the main content of the page.
8. Within the `<body>` element, various HTML tags can be used to structure the content, such as headings (`<h1>` to `<h6>`), paragraphs (`<p>`), lists (`<ul>`, `<ol>`, `<li>`), links (`<a>`), images (`<img>`), and more.
9. It is important to properly nest HTML tags and close all tags that require a closing tag.
10. Once the HTML document is complete, it can be opened in a web browser to view the rendered page.
