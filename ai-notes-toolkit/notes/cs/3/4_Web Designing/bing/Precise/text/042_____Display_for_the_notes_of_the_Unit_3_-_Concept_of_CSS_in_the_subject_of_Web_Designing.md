### Display for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets.
- CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
- CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
- CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
- CSS can be applied to a web page in three ways: inline, internal, and external.
- Inline styles are applied directly to an HTML element using the `style` attribute.
- Internal styles are defined within the `head` section of an HTML document using the `style` element.
- External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
- CSS uses a set of rules to determine how to style an HTML element. These rules are made up of selectors and declarations.
- Selectors are used to specify which HTML elements to apply the style to.
- Declarations are used to define the style properties and values for the selected elements.
- CSS has a wide range of properties that can be used to style an HTML element, including color, font, background, border, and many more.
- CSS also provides a powerful mechanism for selecting elements based on their attributes, classes, and IDs.
- CSS has a cascading mechanism that determines the order in which styles are applied to an element. Styles defined later in the stylesheet or closer to the element take precedence over earlier or more general styles.
- CSS has a box model that defines the layout of an element on a web page. The box model includes the content, padding, border, and margin of an element.
- CSS also provides a range of layout techniques, including flexbox and grid, to help developers create complex and responsive web page layouts.
