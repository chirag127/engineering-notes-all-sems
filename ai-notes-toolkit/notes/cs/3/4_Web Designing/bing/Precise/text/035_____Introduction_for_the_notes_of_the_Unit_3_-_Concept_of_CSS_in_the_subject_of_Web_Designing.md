### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be used to create consistent, visually appealing designs across multiple web pages.
6. CSS is a cornerstone technology of the World Wide Web, alongside HTML and JavaScript.
7. CSS has a simple syntax and uses a number of English keywords to specify the names of various style properties.
8. CSS can be applied to a web page in several ways, including inline, internal, and external stylesheets.
9. CSS has a powerful cascading mechanism, allowing developers to create complex designs by combining multiple stylesheets.
10. CSS has evolved over time, with the latest version being CSS3, which introduces new features and capabilities.
