### Pseudo class for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- A pseudo-class is a keyword added to a selector that specifies a special state of the selected element(s).
- Pseudo-classes are used to define the style for an element in a specific state, such as when an element is being hovered over by the mouse pointer.
- Pseudo-classes are written with a colon (:) before the name of the pseudo-class, for example `a:hover`.
- Some common pseudo-classes include `:hover`, `:active`, `:visited`, and `:first-child`.
- Pseudo-classes can be combined with other selectors to create more specific styles, for example `a:hover` will only apply the style to `a` elements when they are being hovered over.
- Pseudo-classes can also be used with pseudo-elements, for example `a::before:hover` will apply the style to the `::before` pseudo-element of `a` elements when they are being hovered over.
- Pseudo-classes are supported in all modern browsers.
