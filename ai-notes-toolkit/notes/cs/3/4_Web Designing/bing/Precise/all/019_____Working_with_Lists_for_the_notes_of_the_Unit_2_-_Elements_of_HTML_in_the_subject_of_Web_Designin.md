### Working with Lists

Lists are an important element of HTML and are used to organize and present information in a structured manner. There are three types of lists in HTML: ordered lists, unordered lists, and definition lists.

1. **Ordered Lists**: An ordered list is a numbered list, where each item is preceded by a number. Ordered lists are created using the `<ol>` tag, and each list item is created using the `<li>` tag. For example:
```
<ol>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ol>
```

2. **Unordered Lists**: An unordered list is a bulleted list, where each item is preceded by a bullet. Unordered lists are created using the `<ul>` tag, and each list item is created using the `<li>` tag. For example:
```
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

3. **Definition Lists**: A definition list is used to define terms and their descriptions. Definition lists are created using the `<dl>` tag, with the `<dt>` tag used to define the term, and the `<dd>` tag used to define the description. For example:
```
<dl>
  <dt>Term 1</dt>
  <dd>Description 1</dd>
  <dt>Term 2</dt>
  <dd>Description 2</dd>
</dl>
```

When working with lists, it is important to properly nest list items and to use the appropriate list type for the information being presented. Lists can also be styled using CSS to change the appearance of the list markers and the layout of the list items.
