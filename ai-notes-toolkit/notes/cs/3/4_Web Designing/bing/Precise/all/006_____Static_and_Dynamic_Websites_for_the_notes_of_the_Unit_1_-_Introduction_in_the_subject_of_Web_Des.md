# Unit 1 - Introduction: Static and Dynamic Websites

## Static Websites
- A static website is a website that is composed of fixed content, where each page displays the same information to every visitor.
- Static websites are built using HTML, CSS, and JavaScript.
- The content of a static website does not change unless it is manually updated by a developer.
- Static websites are generally faster and easier to create than dynamic websites.
- They are best suited for websites with a small amount of content that does not need to be updated frequently.

## Dynamic Websites
- A dynamic website is a website that generates content in real-time, based on user interactions or other factors.
- Dynamic websites are built using server-side scripting languages such as PHP, ASP, or JSP.
- The content of a dynamic website can change based on user interactions, such as filling out a form or clicking a button.
- Dynamic websites are generally more complex to create than static websites.
- They are best suited for websites with a large amount of content that needs to be updated frequently, such as e-commerce websites or social media platforms.
