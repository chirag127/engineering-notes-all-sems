# Unit 4 - Introduction to Client Side Scripting: Operators in JS

Operators in JavaScript are used to perform operations on values and variables. There are several types of operators in JavaScript, including:

1. **Arithmetic Operators**: These operators are used to perform mathematical operations on numbers, such as addition, subtraction, multiplication, and division. Examples include `+`, `-`, `*`, and `/`.

2. **Assignment Operators**: These operators are used to assign values to variables. The most common assignment operator is `=`, which assigns the value of the right operand to the variable on the left.

3. **Comparison Operators**: These operators are used to compare two values and return a boolean value (`true` or `false`) depending on the result of the comparison. Examples include `==`, `!=`, `>`, `<`, `>=`, and `<=`.

4. **Logical Operators**: These operators are used to combine multiple boolean expressions and return a single boolean value. Examples include `&&` (and), `||` (or), and `!` (not).

5. **String Operators**: The `+` operator can also be used to concatenate (join) two strings together.

6. **Ternary Operator**: This operator is used as a shorthand for an `if...else` statement. It takes three operands and returns a value depending on the result of a condition. The syntax is `condition ? valueIfTrue : valueIfFalse`.

7. **Type Operators**: These operators are used to determine the data type of a value or variable. Examples include `typeof` and `instanceof`.

8. **Bitwise Operators**: These operators are used to perform bitwise operations on numbers. Examples include `&`, `|`, `^`, `~`, `<<`, `>>`, and `>>>`.

These are some of the main operators in JavaScript. They can be used in various combinations to perform complex operations and manipulate values and variables in a program. It is important to understand how these operators work and how to use them effectively in order to write efficient and effective JavaScript code.
