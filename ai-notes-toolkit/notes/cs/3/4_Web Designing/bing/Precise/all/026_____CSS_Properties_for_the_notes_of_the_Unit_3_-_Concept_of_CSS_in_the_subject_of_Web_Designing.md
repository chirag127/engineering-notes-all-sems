# CSS Properties

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts. CSS properties are used to apply styles to elements in a web page.

Here are some commonly used CSS properties:

1. **color**: This property sets the color of the text in an element.
2. **background-color**: This property sets the background color of an element.
3. **font-size**: This property sets the size of the font used in an element.
4. **font-family**: This property sets the font used in an element.
5. **text-align**: This property sets the horizontal alignment of text within an element.
6. **margin**: This property sets the margin space outside of an element's border.
7. **padding**: This property sets the padding space inside of an element's border.
8. **border**: This property sets the border around an element.
9. **width**: This property sets the width of an element.
10. **height**: This property sets the height of an element.

These are just a few of the many CSS properties available. CSS properties can be used to create a wide range of visual effects and layouts on a web page. It is important to have a good understanding of CSS properties when designing and developing web pages.
