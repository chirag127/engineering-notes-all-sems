# Unit 3 - Concept of CSS in Web Designing

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the look and formatting of a document written in a markup language such as HTML. CSS is used to separate the presentation of a document from its content, allowing for greater flexibility and control in the design of web pages.

Some key points to remember about CSS are:

1. CSS is used to define the style of a web page, including the layout, colors, and fonts.
2. CSS can be applied to HTML documents in three ways: inline, internal, and external.
3. Inline styles are applied directly to an HTML element using the `style` attribute.
4. Internal styles are defined within the `head` section of an HTML document using the `style` element.
5. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
6. CSS selectors are used to target specific HTML elements and apply styles to them.
7. CSS properties are used to define the style of an element, such as its color, font, or width.
8. CSS can be used to create responsive designs that adapt to different screen sizes and devices.

These are some of the key concepts of CSS in web designing. It is important to have a good understanding of CSS to create effective and visually appealing web pages.
