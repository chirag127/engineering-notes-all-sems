### Unit 1 - Introduction: Line Breaks

- In web designing, line breaks are used to separate content into different lines.
- Line breaks can be created using the `<br>` tag in HTML.
- The `<br>` tag is an empty tag, meaning it does not require a closing tag.
- Line breaks can also be created using CSS by setting the `white-space` property to `pre` or `pre-line`.
- It is important to use line breaks appropriately to improve the readability of the content on a web page.
- Line breaks should not be used excessively, as it can make the content appear cluttered and difficult to read.
- It is recommended to use line breaks in conjunction with other formatting techniques, such as headings and paragraphs, to create a well-structured and easy-to-read web page.
