### Unit 3 - Concept of CSS in Web Designing

#### Align

1. The `align` property is used to specify the horizontal alignment of an element's content.
2. It can be used with block-level elements, such as `<div>`, `<p>`, and `<h1>` to `<h6>`.
3. The `align` property can take one of the following values: `left`, `right`, `center`, or `justify`.
4. For example, to center the content of a `<div>` element, you can use the following CSS code:
```
div {
    text-align: center;
}
```
5. The `align` property can also be used with table cells to align the content within the cell.
6. For example, to align the content of a table cell to the right, you can use the following CSS code:
```
td {
    text-align: right;
}
```
7. It is important to note that the `align` property is not supported in HTML5. Instead, the `text-align` property should be used in CSS to achieve the same effect.
