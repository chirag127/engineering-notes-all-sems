### Tables and Frames for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

- **Tables** are used to organize data in a tabular format, with rows and columns.
- The `<table>` tag is used to create a table in HTML.
- The `<tr>` tag is used to define a table row.
- The `<th>` tag is used to define a table header cell.
- The `<td>` tag is used to define a table data cell.
- The `colspan` and `rowspan` attributes can be used to merge cells horizontally and vertically, respectively.
- **Frames** allow multiple HTML documents to be displayed in the same browser window, divided into resizable regions.
- The `<frameset>` tag is used to define a frameset, which specifies the layout of the frames.
- The `<frame>` tag is used to define a frame within a frameset.
- The `src` attribute of the `<frame>` tag specifies the URL of the document to be displayed in the frame.
- The `noresize` attribute can be used to prevent the user from resizing a frame.
- The `<noframes>` tag can be used to provide alternative content for browsers that do not support frames.
