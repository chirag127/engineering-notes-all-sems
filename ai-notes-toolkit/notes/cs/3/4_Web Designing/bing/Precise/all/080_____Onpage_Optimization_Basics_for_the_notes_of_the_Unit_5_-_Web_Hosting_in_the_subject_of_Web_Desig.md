# Onpage Optimization Basics

Onpage optimization refers to the practice of optimizing individual web pages in order to rank higher and earn more relevant traffic in search engines. It involves optimizing both the content and the HTML source code of a page. Here are some key points to consider when optimizing a web page:

1. **Title tag**: The title tag is one of the most important on-page SEO elements. It should accurately and concisely describe the content of the page and include the primary keyword.

2. **Meta description**: The meta description is a brief summary of the page's content that appears in search engine results. It should be compelling and include the primary keyword.

3. **Header tags**: Header tags (H1, H2, H3, etc.) are used to format the content and improve its readability. The H1 tag should include the primary keyword and accurately describe the page's content.

4. **URL structure**: The URL of a page should be descriptive and include the primary keyword. It should also be easy to read and remember.

5. **Image optimization**: Images should be optimized for the web by compressing them and including descriptive file names and alt tags.

6. **Internal linking**: Internal linking refers to linking to other pages on the same website. It helps to improve the site's navigation and can also help to distribute page authority throughout the site.

7. **Content**: The content of a page should be high-quality, relevant, and include the primary keyword. It should also be easy to read and provide value to the reader.

These are some of the basic elements of onpage optimization. By following these guidelines, you can improve the visibility and relevance of your web pages in search engine results.
