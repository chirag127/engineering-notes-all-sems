### Defining Name Servers

- Name servers are an essential component of the Domain Name System (DNS).
- DNS is responsible for translating human-readable domain names into IP addresses that computers can understand.
- Name servers store DNS records for a domain and respond to DNS queries from other computers.
- When a user enters a domain name into their web browser, the browser sends a DNS query to the name servers associated with that domain.
- The name servers respond with the IP address of the server hosting the website associated with the domain name.
- This allows the user's browser to connect to the server and access the website.
- Name servers are typically provided by the domain registrar or web hosting company.
- It is important to ensure that the name servers for a domain are correctly configured to ensure that the website is accessible to users.
