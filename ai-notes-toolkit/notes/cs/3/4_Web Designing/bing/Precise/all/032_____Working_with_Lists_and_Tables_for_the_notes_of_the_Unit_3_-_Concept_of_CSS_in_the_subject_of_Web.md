### Working with Lists and Tables

Unit 3 - Concept of CSS in the subject of Web Designing

1. Lists and tables are common elements in web design and can be styled using CSS.
2. Lists can be either ordered or unordered. Ordered lists use numbers to indicate the order of the items, while unordered lists use bullets.
3. CSS can be used to change the appearance of the list markers, as well as the spacing and indentation of the list items.
4. Tables are used to display data in a tabular format, with rows and columns.
5. CSS can be used to style the table, including changing the border, background color, and text alignment of the cells.
6. The `table`, `tr`, `th`, and `td` elements are used to create a table in HTML, and can be targeted with CSS to apply styles.
7. The `border-collapse` property can be used to control the appearance of the borders between table cells.
8. The `:nth-child` pseudo-class can be used to apply styles to specific rows or columns in a table.
9. The `colspan` and `rowspan` attributes can be used to merge cells in a table.
10. CSS can also be used to create responsive tables that adjust their layout based on the screen size of the device.
