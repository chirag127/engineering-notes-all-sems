## Unit 2 - Elements of HTML

1. HTML stands for HyperText Markup Language and is used to structure content on the web.
2. HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear or act in a certain way.
3. The enclosing tags can make a word or image hyperlink to somewhere else, can italicize words, can make the font bigger or smaller, and so on.
4. An HTML element is set off from other text in a document by "tags," which consist of the element name surrounded by "<" and ">".
5. The text between the start and end tags is the element's content.
6. Some common HTML elements include headings, paragraphs, links, images, and lists.
7. HTML elements can have attributes, which provide additional information about the element.
8. Attributes are specified in the start tag and usually consist of a name and a value, separated by an equals sign.
9. HTML documents have a structure that includes a head and a body.
10. The head contains information about the document, while the body contains the document's content.
11. HTML documents should start with a document type declaration, which specifies the version of HTML being used.
12. HTML5 is the latest version of HTML and introduces new elements and attributes that make it easier to structure and style web content.
