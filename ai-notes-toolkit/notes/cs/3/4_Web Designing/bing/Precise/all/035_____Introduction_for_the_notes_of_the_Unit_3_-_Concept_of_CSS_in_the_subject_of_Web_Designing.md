### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets.
- CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
- CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
- CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
- CSS is one of the core technologies used in web development, along with HTML and JavaScript.
- CSS has a simple syntax and uses a set of English keywords to specify the names of various style properties.
- A style sheet consists of a list of rules, with each rule consisting of one or more selectors and a declaration block.
- CSS can be applied to a web page in three ways: inline, internal, and external.
- CSS has a powerful cascading mechanism, which allows styles to be inherited from parent elements to child elements.
- CSS has a rich set of selectors, which allows developers to target specific elements, classes, and IDs on a web page.
- CSS has a wide range of properties, which allows developers to control the layout, typography, colors, and other aspects of a web page's appearance.
- CSS has a number of advanced features, such as animations, transitions, and transformations, which allow developers to create rich and interactive web pages.
- CSS is constantly evolving, with new features and improvements being added to the language on a regular basis.
