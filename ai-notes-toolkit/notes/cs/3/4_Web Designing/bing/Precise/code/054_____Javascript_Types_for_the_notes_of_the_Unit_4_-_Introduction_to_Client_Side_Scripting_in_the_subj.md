### Unit 4 - Introduction to Client Side Scripting: Javascript Types

JavaScript is a loosely typed or a dynamic language. This means that you don't have to declare the type of a variable ahead of time. The type will get determined automatically while the program is being processed. However, JavaScript does have data types, and it is important to understand them.

1. **Number**: This data type includes all numbers, including integers and floating-point numbers. For example, `var x = 3.14;` or `var y = 123e5;`.
2. **String**: This data type represents a sequence of characters. For example, `var name = "John Doe";`.
3. **Boolean**: This data type represents a logical entity and can have two values: `true` or `false`. For example, `var isFinished = false;`.
4. **Undefined**: A variable that has been declared but has not been assigned a value is `undefined`. For example, `var x;`.
5. **Null**: This data type represents a non-existent or invalid object or address. For example, `var person = null;`.
6. **Object**: This data type represents a collection of properties, and each property has a name and a value. For example, `var car = {type:"Fiat", model:"500", color:"white"};`.
7. **Symbol**: This data type represents a unique value that is not equal to any other value. It was introduced in ECMAScript 6. For example, `var sym1 = Symbol();`.

These are the basic data types in JavaScript. It is important to understand them in order to write effective and efficient code.
