### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. An HTML document is a text file that contains markup tags to describe the structure and content of a web page.
2. The first step in creating an HTML document is to open a text editor and create a new file with the `.html` extension.
3. The basic structure of an HTML document includes the `<!DOCTYPE html>` declaration, the `<html>` element, the `<head>` element, and the `<body>` element.
4. The `<!DOCTYPE html>` declaration specifies that the document is an HTML5 document and should be interpreted as such by the web browser.
5. The `<html>` element is the root element of the HTML page and contains all other elements within it.
6. The `<head>` element contains metadata about the document, such as the title, character encoding, and links to stylesheets and scripts.
7. The `<body>` element contains the main content of the web page, including text, images, and other media.
8. Within the `<body>` element, various other HTML elements can be used to structure and format the content, such as headings, paragraphs, lists, and tables.
9. It is important to use semantic HTML elements to provide meaning and structure to the content, making it more accessible and easier to style with CSS.
10. Once the HTML document is complete, it can be saved and opened in a web browser to view the resulting web page.
