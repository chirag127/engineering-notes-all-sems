### Working with Text

Unit 2 - Elements of HTML in the subject of Web Designing

1. HTML stands for HyperText Markup Language and is used to structure content on the web.
2. HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear or act in a certain way.
3. The enclosing tags can make a word or image hyperlink to somewhere else, can italicize words, can make the font bigger or smaller, and so on.
4. The most common way to add text to an HTML document is by using the `<p>` element, which stands for "paragraph".
5. The `<p>` element automatically adds some white space before and after the text, to separate it from other content.
6. Other common text elements include `<h1>` to `<h6>` for headings, `<em>` for emphasis, `<strong>` for strong importance, and `<span>` for a generic inline container.
7. Text can also be formatted using CSS (Cascading Style Sheets), which allows for greater control over the appearance of text, including font, size, color, and spacing.
8. It is important to use the appropriate HTML elements for their intended purpose, as this helps with accessibility and search engine optimization.
