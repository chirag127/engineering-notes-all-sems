### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows you to create rules that specify how the content of elements within an HTML file will be displayed.
5. CSS is used to separate the presentation of a web page from its content, making it easier to maintain and update.
6. CSS can be used to create consistent styling across multiple pages of a website.
7. CSS can be added to an HTML document in three ways: inline, internal, and external.
8. Inline styles are added directly to an HTML element using the `style` attribute.
9. Internal styles are defined within the `style` element in the `head` section of an HTML document.
10. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element in the `head` section.
