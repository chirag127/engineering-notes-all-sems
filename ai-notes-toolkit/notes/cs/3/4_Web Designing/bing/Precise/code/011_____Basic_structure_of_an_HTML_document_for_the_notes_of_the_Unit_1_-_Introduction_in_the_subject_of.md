### Basic structure of an HTML document

1. **DOCTYPE declaration**: The first line of an HTML document is the DOCTYPE declaration, which specifies the version of HTML used in the document. For HTML5, the declaration is `<!DOCTYPE html>`.
2. **HTML element**: The root element of an HTML document is the `<html>` element. This element encloses all other elements in the document.
3. **Head element**: The `<head>` element is a container for metadata, such as the document's title, character encoding, and links to stylesheets and scripts. It is placed within the `<html>` element.
4. **Body element**: The `<body>` element contains the main content of the document. It is placed within the `<html>` element, after the `<head>` element.
5. **Headings**: Headings are defined using the `<h1>` to `<h6>` elements, with `<h1>` being the highest level and `<h6>` being the lowest.
6. **Paragraphs**: Paragraphs are defined using the `<p>` element.
7. **Lists**: There are two types of lists in HTML: ordered and unordered. Ordered lists are created using the `<ol>` element, and list items are added using the `<li>` element. Unordered lists are created using the `<ul>` element, with list items added in the same way.
8. **Links**: Links are created using the `<a>` element. The `href` attribute specifies the URL of the linked resource.
9. **Images**: Images are added to an HTML document using the `<img>` element. The `src` attribute specifies the URL of the image, and the `alt` attribute provides a text description of the image.
10. **Tables**: Tables are created using the `<table>` element. Rows are added using the `<tr>` element, and cells are added using the `<td>` element. The `<th>` element is used to add header cells.
