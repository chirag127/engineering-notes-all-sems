### Heading-Paragraphs for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. **Web Designing** is the process of creating and designing websites.
2. It involves various aspects such as **web page layout**, **content production**, and **graphic design**.
3. Web Designing is a subset of the broader category of **Web Development**.
4. The primary tool used for designing websites is a **web browser**.
5. **HTML** (Hypertext Markup Language) is the standard markup language used to create web pages.
6. **CSS** (Cascading Style Sheets) is a style sheet language used for describing the look and formatting of a document written in a markup language.
7. **JavaScript** is a programming language commonly used to create interactive effects within web browsers.
8. Web Designing is an important aspect of creating an online presence for businesses and individuals.
9. A well-designed website can help attract and retain customers, and improve the user experience.
10. There are many different approaches to web design, and designers must consider factors such as **usability**, **accessibility**, and **search engine optimization** when creating a website.
