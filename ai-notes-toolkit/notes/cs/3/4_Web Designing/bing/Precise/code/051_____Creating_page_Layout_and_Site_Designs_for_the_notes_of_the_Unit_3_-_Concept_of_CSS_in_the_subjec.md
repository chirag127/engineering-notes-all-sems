### Creating Page Layout and Site Designs

Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS (Cascading Style Sheets) is a style sheet language used for describing the presentation of a document written in a markup language like HTML.
2. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
3. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
4. CSS can be used to create a variety of page layouts, from simple single-column designs to complex multi-column layouts.
5. CSS provides a range of layout options, including fixed, fluid, and responsive designs.
6. Fixed layouts have a set width and do not change size based on the size of the user's screen.
7. Fluid layouts use percentages to define the width of page elements, allowing the layout to adjust to the size of the user's screen.
8. Responsive layouts use CSS media queries to adjust the layout based on the size of the user's screen, providing an optimal viewing experience on a variety of devices.
9. CSS also provides a range of tools for creating site designs, including the ability to define styles for common page elements like headers, footers, and navigation menus.
10. CSS frameworks like Bootstrap and Foundation provide pre-designed styles and components that can be used to quickly create professional-looking site designs.
11. CSS preprocessors like Sass and Less allow developers to write more modular and maintainable CSS code by providing features like variables, mixins, and nested rules.
12. In summary, CSS is a powerful tool for creating page layouts and site designs, providing developers with a range of options for defining the visual appearance of web pages.
