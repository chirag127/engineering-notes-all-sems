### JS Popup Boxes

JavaScript provides three types of popup boxes: Alert box, Confirm box, and Prompt box.

1. **Alert Box:** An alert box is used to display a message to the user. It is often used to make sure that the user is informed about something before moving on. The syntax for an alert box is `window.alert("message");`.

2. **Confirm Box:** A confirm box is used to ask the user to verify or accept something. It displays a message and two buttons: OK and Cancel. If the user clicks OK, the box returns true. If the user clicks Cancel, the box returns false. The syntax for a confirm box is `window.confirm("message");`.

3. **Prompt Box:** A prompt box is used to ask the user to input a value before entering a page. It displays a message and an input field. The user must enter a value and click OK or Cancel. If the user clicks OK, the box returns the input value. If the user clicks Cancel, the box returns null. The syntax for a prompt box is `window.prompt("message", "default value");`.

These popup boxes can be useful for interacting with the user and providing feedback or information. They are a part of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing.
