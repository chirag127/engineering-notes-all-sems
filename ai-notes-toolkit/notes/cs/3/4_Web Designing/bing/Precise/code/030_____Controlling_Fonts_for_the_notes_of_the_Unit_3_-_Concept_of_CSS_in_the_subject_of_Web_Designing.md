### Controlling Fonts

1. **Font Family**: The font-family property specifies the font for an element. It can hold several font names as a "fallback" system. If the browser does not support the first font, it tries the next font.
2. **Font Size**: The font-size property sets the size of the text. It can be specified in length values, such as pixels, em, or percentage.
3. **Font Style**: The font-style property specifies the font style for a text. It can be normal, italic, or oblique.
4. **Font Weight**: The font-weight property sets how thick or thin characters in text should be displayed. It can be normal, bold, bolder, lighter, or a number from 100 to 900.
5. **Text Transform**: The text-transform property controls the capitalization of text. It can be none, capitalize, uppercase, or lowercase.
6. **Text Decoration**: The text-decoration property specifies the decoration added to text. It can be none, underline, overline, or line-through.
7. **Line Height**: The line-height property specifies the height of a line. It can be a number, length, or percentage.
8. **Text Align**: The text-align property specifies the horizontal alignment of text. It can be left, right, center, or justify.
9. **Text Indent**: The text-indent property specifies the indentation of the first line in a text block. It can be specified in length values, such as pixels, em, or percentage.
10. **Letter Spacing**: The letter-spacing property increases or decreases the space between characters in a text. It can be normal or a length value, such as pixels or em.
11. **Word Spacing**: The word-spacing property increases or decreases the space between words in a text. It can be normal or a length value, such as pixels or em.

These are some of the ways to control fonts using CSS. It is important to understand and use these properties to create visually appealing and readable web pages.
