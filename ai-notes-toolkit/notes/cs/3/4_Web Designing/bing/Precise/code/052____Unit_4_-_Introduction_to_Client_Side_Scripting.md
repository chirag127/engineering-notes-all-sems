## Unit 4 - Introduction to Client Side Scripting

1. **Client-side scripting** refers to the execution of scripts on the user's web browser, rather than on the web server.
2. These scripts are usually written in a scripting language such as JavaScript and interact with the HTML elements on the page to provide dynamic and interactive content.
3. Some common uses of client-side scripting include form validation, user interface enhancements, and dynamic content updates.
4. Client-side scripts are executed by the user's web browser, which means that the processing is done on the user's device, rather than on the server.
5. This can improve the performance and responsiveness of web applications, as it reduces the load on the server and the network.
6. However, it also means that the user's device must have the necessary resources and capabilities to execute the scripts.
7. It is important to note that client-side scripts can be viewed and modified by the user, so they should not be used to store or transmit sensitive information.
8. In addition, not all users may have JavaScript enabled in their browsers, so it is important to provide alternative content or functionality for those users.
