### HTML Documents

- HTML stands for HyperText Markup Language.
- HTML is the standard markup language for creating web pages and other information that can be displayed in a web browser.
- HTML documents are text files that contain a combination of content and markup.
- Markup is the set of instructions that tells the web browser how to display the content.
- HTML documents are saved with the .html or .htm file extension.
- The basic structure of an HTML document includes the `<!DOCTYPE html>` declaration, the `<html>` element, the `<head>` element, and the `<body>` element.
- The `<!DOCTYPE html>` declaration is used to specify the version of HTML used in the document.
- The `<html>` element is the root element of an HTML page and contains all other elements.
- The `<head>` element contains information about the document, such as the title and meta data.
- The `<body>` element contains the main content of the document, such as text, images, and links.
- HTML elements are used to create the structure and layout of a web page.
- HTML elements are represented by tags, which are enclosed in angle brackets.
- Most HTML elements have an opening tag and a closing tag, with the content in between.
- Some HTML elements, such as `<img>` and `<br>`, are self-closing and do not have a closing tag.
- HTML elements can have attributes, which provide additional information about the element.
- Attributes are specified in the opening tag of the element and are written as name-value pairs.
- HTML documents can also include CSS and JavaScript to add style and interactivity to the page.
