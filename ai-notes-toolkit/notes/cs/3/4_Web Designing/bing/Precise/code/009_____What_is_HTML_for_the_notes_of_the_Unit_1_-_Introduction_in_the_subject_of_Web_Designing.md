### Unit 1 - Introduction: What is HTML

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages and other information that can be displayed in a web browser. Here are some key points to know about HTML:

1. HTML is used to structure content on the web: HTML provides a means to create structured documents by denoting structural semantics for text such as headings, paragraphs, lists, links, quotes and other items.

2. HTML is not a programming language: HTML is a markup language, which means it is used to annotate text to define how it should be displayed, but it does not have the ability to perform calculations or logic like a programming language.

3. HTML is the foundation of the web: HTML is the foundation upon which most websites are built. It provides the structure and content of a web page, while other technologies like CSS and JavaScript are used to style and add interactivity to the page.

4. HTML has evolved over time: HTML has gone through several versions since its inception, with the most recent version being HTML5. Each version has added new features and capabilities to the language, while also improving upon existing features.

5. HTML is easy to learn: HTML is a relatively simple language to learn, with a straightforward syntax and a limited set of elements to work with. This makes it a great starting point for anyone interested in web development.
