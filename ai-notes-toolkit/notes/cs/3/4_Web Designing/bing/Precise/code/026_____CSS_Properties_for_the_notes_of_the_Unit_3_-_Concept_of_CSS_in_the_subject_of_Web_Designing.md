### CSS Properties

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.

Here are some commonly used CSS properties:

1. **color**: This property sets the color of an element's text.
2. **background-color**: This property sets the background color of an element.
3. **font-size**: This property sets the size of the font used for the text in an element.
4. **font-family**: This property specifies the font for an element's text.
5. **text-align**: This property sets the horizontal alignment of text within an element.
6. **margin**: This property sets the margin area on all four sides of an element.
7. **padding**: This property sets the padding area on all four sides of an element.
8. **border**: This property sets the border on all four sides of an element.
9. **width**: This property sets the width of an element.
10. **height**: This property sets the height of an element.

These are just a few of the many CSS properties available. CSS provides a powerful and flexible way to control the appearance of web pages. By using CSS, web designers can create attractive and consistent designs for their web pages.
