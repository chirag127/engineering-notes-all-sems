### JS Functions

Functions are one of the fundamental building blocks in JavaScript. A function is a set of statements that performs a specific task and can be reused throughout the code.

Here are some key points to remember about functions in JavaScript:

1. Functions can be defined using a function declaration or a function expression.
2. Functions can accept parameters and return a value.
3. Functions can be called by their name followed by parentheses, with any arguments passed inside the parentheses.
4. Functions can be assigned to variables and passed as arguments to other functions.
5. Functions have access to variables in their own scope, as well as any outer scopes.
6. Functions can be used to create closures, which allow data to be kept private.

These are some of the basic concepts of functions in JavaScript. Understanding how to use functions effectively is an important part of mastering the language.
