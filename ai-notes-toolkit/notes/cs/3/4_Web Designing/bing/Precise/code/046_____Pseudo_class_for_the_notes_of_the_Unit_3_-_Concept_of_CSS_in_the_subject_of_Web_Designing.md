### Pseudo class for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- A pseudo-class is a keyword added to a selector that specifies a special state of the selected element(s).
- Pseudo-classes are used to define the style for an element in a specific state, such as when an element is being hovered over by the mouse pointer.
- Pseudo-classes are added to selectors by using a colon (`:`) followed by the pseudo-class name.
- Some common pseudo-classes include `:hover`, `:active`, `:visited`, and `:first-child`.
- Pseudo-classes can be combined with other selectors to create more specific styles. For example, `a:hover` selects all `a` elements that are being hovered over by the mouse pointer.
- Pseudo-classes can also be used with pseudo-elements to create even more specific styles. For example, `p::first-line:hover` selects the first line of all `p` elements that are being hovered over by the mouse pointer.
- Pseudo-classes are supported in all major browsers.
