### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

- Markup tags are used to define the structure and layout of a web page.
- These tags are enclosed in angle brackets `< >` and are used to mark the beginning and end of an element.
- Some common markup tags include:
  - `<html>`: Defines the root of an HTML document.
  - `<head>`: Contains metadata and information about the document.
  - `<body>`: Contains the main content of the document.
  - `<h1>` to `<h6>`: Defines headings, with `<h1>` being the largest and `<h6>` being the smallest.
  - `<p>`: Defines a paragraph.
  - `<a>`: Defines a hyperlink.
  - `<img>`: Defines an image.
  - `<ul>` and `<ol>`: Defines unordered and ordered lists, respectively.
  - `<li>`: Defines a list item.
- These tags are used in combination to create the structure and layout of a web page.
- It is important to use the correct tags and to nest them properly to ensure that the page is displayed correctly.
