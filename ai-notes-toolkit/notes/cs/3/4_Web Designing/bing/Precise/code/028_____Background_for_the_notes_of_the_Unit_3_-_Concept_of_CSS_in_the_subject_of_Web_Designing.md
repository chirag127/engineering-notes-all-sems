### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets.
- CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
- CSS is one of the core technologies used in web design, along with HTML and JavaScript.
- CSS allows developers to separate the presentation of a web page from its content, making it easier to maintain and update.
- CSS was first proposed by Håkon Wium Lie in 1994 and was later developed by the World Wide Web Consortium (W3C).
- The first version of CSS, CSS1, was released in 1996, followed by CSS2 in 1998 and CSS3 in 1999.
- CSS3 is the latest version of CSS and is split into several separate modules, each dealing with a specific aspect of styling.
- CSS is widely supported by all modern web browsers and is used by almost all websites to control their layout and appearance.
