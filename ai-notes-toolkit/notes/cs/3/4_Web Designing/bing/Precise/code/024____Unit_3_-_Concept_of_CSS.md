## Unit 3 - Concept of CSS

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define how HTML elements are to be displayed.
4. CSS can be used to control the layout of multiple web pages all at once.
5. CSS can be used to create visually engaging webpages, user interfaces for web applications, and user interfaces for many mobile applications.
6. CSS can be used to define the look and feel of a website, including colors, fonts, and layout.
7. CSS can be used to create responsive design, which means that the layout of a webpage will adjust based on the size of the screen it is being viewed on.
8. CSS can be used to create animations and transitions.
9. CSS can be used to create print-friendly versions of webpages.
10. CSS is a powerful tool for web designers and developers, allowing them to create visually engaging and user-friendly websites and applications.
