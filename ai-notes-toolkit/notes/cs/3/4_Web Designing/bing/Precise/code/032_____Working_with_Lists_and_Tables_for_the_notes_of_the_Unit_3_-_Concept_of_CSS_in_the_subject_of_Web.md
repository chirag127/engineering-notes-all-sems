### Working with Lists and Tables

Unit 3 - Concept of CSS in the subject of Web Designing

- CSS can be used to style and format lists and tables in HTML.
- Lists can be styled using properties such as `list-style-type`, `list-style-image`, and `list-style-position`.
- Tables can be styled using properties such as `border`, `border-collapse`, `border-spacing`, and `empty-cells`.
- CSS can also be used to control the layout of tables, including the alignment of text within cells, the width of columns, and the height of rows.
- Pseudo-elements such as `::before` and `::after` can be used to add content before or after list items or table cells.
- CSS can also be used to create custom counters for ordered lists, using the `counter-reset` and `counter-increment` properties.
- The `display` property can be used to change the default display behavior of list items and table cells, allowing for more flexible layouts.
- CSS can also be used to create responsive tables, which adjust their layout based on the size of the screen.
