### Unit 4 - Introduction to Client Side Scripting: JS Objects

- JavaScript objects are containers for named values, called properties and methods.
- An object is a collection of related data and/or functionality.
- Objects can be created using object literals or using the `new` keyword and a constructor function.
- Object properties can be accessed using dot notation or bracket notation.
- The `this` keyword refers to the current object.
- Objects can be used to represent real-world objects and their properties and behaviors.
- Objects can be nested within other objects to create complex data structures.
- The `Object` class provides several useful methods for working with objects, such as `Object.keys()` and `Object.values()`.
- Inheritance allows objects to inherit properties and methods from other objects, allowing for code reuse and organization.
