### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. An HTML document is a text file that contains markup tags that define the structure and content of a web page.
2. To create an HTML document, you can use a text editor such as Notepad or TextEdit, or an HTML editor such as Adobe Dreamweaver or Microsoft Expression Web.
3. The first line of an HTML document should be the DOCTYPE declaration, which specifies the version of HTML used in the document. For example, to specify HTML5, the DOCTYPE declaration would be `<!DOCTYPE html>`.
4. After the DOCTYPE declaration, the HTML document should contain an opening `<html>` tag and a closing `</html>` tag, which enclose all the content of the document.
5. Within the `<html>` tags, the document should contain a `<head>` section and a `<body>` section. The `<head>` section contains information about the document, such as the title and meta data, while the `<body>` section contains the main content of the document.
6. The title of the document is specified within the `<head>` section using the `<title>` tag. For example, to specify the title "Unit 1 - Introduction", the `<title>` tag would be `<title>Unit 1 - Introduction</title>`.
7. The content of the document is specified within the `<body>` section using various HTML tags to define the structure and formatting of the content. For example, to create a heading, you can use the `<h1>` to `<h6>` tags, to create a paragraph, you can use the `<p>` tag, and to create a list, you can use the `<ul>` or `<ol>` tags with `<li>` tags for each list item.
8. To save the HTML document, choose "Save As" from the File menu of your text or HTML editor, and save the file with a `.html` or `.htm` extension.
9. To view the HTML document in a web browser, simply open the file using the browser's "Open File" command, or by dragging the file onto the browser window.
