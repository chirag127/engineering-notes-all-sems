### Static and Dynamic Websites

#### Unit 1 - Introduction

##### Static Websites
- A static website is a website that is delivered to the user exactly as stored.
- It consists of a series of HTML files, each representing a physical page of the website.
- The content of a static website does not change unless it is manually updated by a web developer.
- Static websites are suitable for small websites with a limited number of pages and simple content.

##### Dynamic Websites
- A dynamic website is a website that generates content in real-time.
- It uses server-side scripting languages such as PHP, ASP, or JSP to generate the content.
- The content of a dynamic website can change based on user interaction, time, or other factors.
- Dynamic websites are suitable for large websites with complex content and functionality.
