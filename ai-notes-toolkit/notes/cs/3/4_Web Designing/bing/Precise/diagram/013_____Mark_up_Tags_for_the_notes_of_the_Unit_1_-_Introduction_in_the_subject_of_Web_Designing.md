### Unit 1 - Introduction: Mark up Tags

1. **HTML (HyperText Markup Language)** is the standard markup language for creating web pages and other information that can be displayed in a web browser.
2. HTML uses **markup tags** to describe the structure and content of a web page.
3. Markup tags are enclosed in **angle brackets** (e.g. `<tagname>`) and are used to define elements such as headings, paragraphs, links, images, and more.
4. Some common HTML tags include:
    - `<h1>` to `<h6>`: Used to define headings, with `<h1>` being the largest and `<h6>` being the smallest.
    - `<p>`: Used to define a paragraph.
    - `<a>`: Used to define a hyperlink.
    - `<img>`: Used to embed an image.
    - `<ul>` and `<li>`: Used to create an unordered list.
5. HTML tags can also have **attributes**, which provide additional information about the element. Attributes are defined within the start tag, after the tag name, and are written as `name="value"`.
6. Some common HTML attributes include:
    - `href`: Specifies the URL of the page the link goes to (used with the `<a>` tag).
    - `src`: Specifies the URL of the image to embed (used with the `<img>` tag).
    - `alt`: Specifies alternative text for an image, to be displayed if the image cannot be loaded (used with the `<img>` tag).
7. HTML tags are usually used in **pairs**, with a start tag (e.g. `<tagname>`) and an end tag (e.g. `</tagname>`). The content of the element is placed between the start and end tags.
8. Some HTML tags, such as `<img>` and `<br>`, are **self-closing** and do not require an end tag.
9. HTML documents have a specific **structure**, with the `<html>` tag enclosing the entire document, the `<head>` tag containing information about the page, and the `<body>` tag containing the main content of the page.
10. It is important to write **valid** and **well-formed** HTML, following the rules and standards of the language, to ensure that web pages are displayed correctly across different browsers and devices.
