### Unit 4 - Introduction to Client Side Scripting: Javascript Types

JavaScript is a loosely typed or a dynamic language. This means that you don't have to declare the type of a variable ahead of time. The type will get determined automatically while the program is being processed. However, there are some basic data types that are available in JavaScript:

1. **Number**: This data type is used to represent numeric values. It can be an integer or a floating-point value.
2. **String**: This data type is used to represent a sequence of characters. It is used to store and manipulate text.
3. **Boolean**: This data type can have only two values: `true` or `false`. It is used to represent logical values.
4. **Undefined**: This data type represents a variable that has not been assigned a value.
5. **Null**: This data type represents a variable that has been explicitly set to have no value or object.
6. **Object**: This data type is used to store collections of data. An object can contain properties and methods.
7. **Symbol**: This data type is used to represent a unique identifier.

These are the basic data types available in JavaScript. It is important to understand these data types and how to use them when working with JavaScript in web designing.
