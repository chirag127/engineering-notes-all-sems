### Basic structure of an HTML document

1. **DOCTYPE declaration**: The first line of an HTML document is the DOCTYPE declaration, which specifies the version of HTML used in the document. For HTML5, the declaration is `<!DOCTYPE html>`.
2. **HTML element**: The root element of an HTML document is the `<html>` element. This element encloses all other elements in the document.
3. **Head element**: The `<head>` element is a container for metadata, such as the document's title, character encoding, and links to stylesheets and scripts. This element is placed within the `<html>` element.
4. **Body element**: The `<body>` element contains the main content of the document. This element is placed within the `<html>` element, after the `<head>` element.
5. **Headings**: Headings are defined with the `<h1>` to `<h6>` elements, with `<h1>` being the highest level heading and `<h6>` being the lowest.
6. **Paragraphs**: Paragraphs are defined with the `<p>` element.
7. **Links**: Links are defined with the `<a>` element. The `href` attribute specifies the URL of the page the link goes to.
8. **Images**: Images are defined with the `<img>` element. The `src` attribute specifies the URL of the image file.
9. **Lists**: There are two types of lists in HTML: ordered and unordered. Ordered lists are defined with the `<ol>` element and list items are defined with the `<li>` element. Unordered lists are defined with the `<ul>` element and list items are defined with the `<li>` element.
10. **Tables**: Tables are defined with the `<table>` element. A table is divided into rows with the `<tr>` element and cells with the `<td>` element. The `<th>` element is used to define a header cell in a table.
