### CSS Advanced

CSS (Cascading Style Sheets) is a style sheet language used for describing the presentation of a document written in a markup language like HTML. CSS is a cornerstone technology of the World Wide Web, alongside HTML and JavaScript.

Unit 3 - Concept of CSS in the subject of Web Designing covers the following advanced topics:

1. **Selectors**: CSS selectors are used to select the HTML elements that you want to style. Some advanced selectors include attribute selectors, pseudo-classes, and pseudo-elements.

2. **Box Model**: The CSS box model is the foundation of layout on the Web. It describes the content of the space taken up by an element. Each element is represented as a rectangular box, with the box's content, padding, border, and margin built up around one another like the layers of an onion.

3. **Layout**: CSS provides several properties for controlling the layout of a web page. These include the display, position, and float properties.

4. **Transitions and Animations**: CSS transitions and animations allow you to create smooth, gradual transitions between the values of specific CSS properties. This can be used to create a variety of effects, such as hover effects, loading animations, and page transitions.

5. **Responsive Design**: Responsive design is an approach to web design that makes web pages render well on a variety of devices and window or screen sizes. This is achieved through the use of flexible layouts, images, and CSS media queries.

These are some of the advanced topics covered in Unit 3 - Concept of CSS in the subject of Web Designing. It is important to have a good understanding of these concepts in order to create effective and visually appealing web pages.
