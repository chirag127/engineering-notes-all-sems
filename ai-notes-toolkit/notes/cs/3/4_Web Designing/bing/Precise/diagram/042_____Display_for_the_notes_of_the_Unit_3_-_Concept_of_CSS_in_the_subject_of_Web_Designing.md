### Unit 3 - Concept of CSS in Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be applied to a web page in three ways: inline, internal, and external.
6. Inline CSS is applied directly to an HTML element using the `style` attribute.
7. Internal CSS is defined within the `style` element in the `head` section of an HTML document.
8. External CSS is defined in a separate file with a `.css` extension and linked to an HTML document using the `link` element.
9. CSS uses a set of rules to apply styles to elements on a web page. Each rule consists of a selector and a declaration block.
10. The selector specifies which elements the rule applies to, and the declaration block contains one or more declarations that define the styles to be applied.
11. CSS has a wide range of selectors, including element, class, and ID selectors.
12. CSS also has a powerful inheritance mechanism, allowing styles to be inherited from parent elements to child elements.
13. CSS has a wide range of properties that can be used to define the appearance of elements, including color, font, and layout properties.
14. CSS also has a number of advanced features, including animations, transitions, and transformations.
15. CSS is constantly evolving, with new features and improvements being added regularly.
