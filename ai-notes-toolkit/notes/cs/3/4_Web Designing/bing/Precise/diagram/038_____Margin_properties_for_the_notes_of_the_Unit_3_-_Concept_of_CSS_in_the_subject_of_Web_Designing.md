### Margin Properties

The margin properties in CSS are used to create space around elements, outside of any defined borders. Here are some key points to remember about margin properties:

1. The `margin` property is a shorthand property for the individual margin properties: `margin-top`, `margin-right`, `margin-bottom`, and `margin-left`.
2. The `auto` value can be used for the margin property to horizontally center an element within its container.
3. Negative values are allowed for the margin properties, which can cause the element to overlap with other elements on the page.
4. The margin properties can be set using length values, percentages, or the `inherit` keyword.
5. The `inherit` keyword specifies that the margin property should be inherited from the parent element.
6. The `margin` property can be used to collapse vertical margins between elements. When two elements have margins that touch, the larger margin value is used, and the smaller margin value is discarded.
