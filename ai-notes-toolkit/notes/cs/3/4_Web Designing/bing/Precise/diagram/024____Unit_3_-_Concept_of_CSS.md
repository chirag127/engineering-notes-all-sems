## Unit 3 - Concept of CSS

CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the look and formatting of a document written in a markup language. Here are some key points to remember about CSS:

1. CSS is used to separate the presentation of a document from its content, allowing for greater flexibility and control in the specification of presentation characteristics.
2. CSS allows for the creation of rules that specify how the content of an element should be displayed. These rules can be applied to multiple elements, making it easy to apply consistent styling across a website.
3. CSS provides a wide range of styling options, including the ability to control the layout, color, font, and other visual aspects of a document.
4. CSS can be used to create responsive designs, allowing for the creation of websites that adapt to different screen sizes and devices.
5. CSS can be used in conjunction with HTML and JavaScript to create dynamic and interactive web pages.

Overall, CSS is an essential tool for web developers, allowing for the creation of visually appealing and functional websites. It is important to have a solid understanding of CSS when working in web development.
