### Unit 4 - Introduction to Client Side Scripting: JS Arrays

- An array is a data structure that can store a collection of values.
- In JavaScript, arrays are created using square brackets `[]` and can store values of different data types.
- The values in an array are called elements and are accessed using their index, which starts from 0.
- The `length` property can be used to determine the number of elements in an array.
- Arrays have several built-in methods, such as `push()`, `pop()`, `shift()`, `unshift()`, `splice()`, `slice()`, `concat()`, `join()`, `reverse()`, `sort()`, and `forEach()`, that can be used to manipulate the elements in an array.
- Arrays can also be iterated over using loops, such as a `for` loop or a `for...of` loop.
- Multidimensional arrays, or arrays of arrays, can be used to store more complex data structures.
