### Images and Multimedia

#### Unit 2 - Elements of HTML

##### Web Designing

1. Images and multimedia are important elements of web design, as they can enhance the visual appeal and interactivity of a website.
2. The `<img>` tag is used to embed images in an HTML page. The `src` attribute specifies the URL of the image, while the `alt` attribute provides alternative text for the image.
3. The `<audio>` and `<video>` tags are used to embed audio and video content in an HTML page. The `src` attribute specifies the URL of the media file, while the `controls` attribute adds playback controls to the media player.
4. It is important to optimize images and multimedia for the web, by reducing file size and using appropriate file formats, to ensure fast loading times and a good user experience.
5. Accessibility is also an important consideration when using images and multimedia. Alternative text and captions should be provided to make the content accessible to users with disabilities.
