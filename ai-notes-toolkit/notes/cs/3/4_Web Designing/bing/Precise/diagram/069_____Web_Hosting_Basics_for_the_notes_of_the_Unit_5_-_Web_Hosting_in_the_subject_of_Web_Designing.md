### Unit 5 - Web Hosting: Web Hosting Basics

Web hosting is the service of providing storage space and access for websites on the internet. It allows individuals and organizations to make their website accessible to the public. Here are some key points to understand about web hosting:

1. **Web Hosts:** A web host is a company that provides the technology and services needed for a website to be viewed on the internet. Websites are stored on servers, which are powerful computers that are connected to the internet.

2. **Domain Names:** A domain name is the address of a website that people type into their web browser to access the site. Domain names must be registered with a domain registrar, and they must be unique.

3. **Types of Web Hosting:** There are several types of web hosting available, including shared hosting, dedicated hosting, virtual private server (VPS) hosting, and cloud hosting. Each type has its own advantages and disadvantages, and the choice depends on the needs of the website.

4. **Bandwidth and Storage:** Bandwidth refers to the amount of data that can be transferred to and from a website, while storage refers to the amount of space available for storing files on the server. Both are important factors to consider when choosing a web hosting plan.

5. **Uptime and Reliability:** Uptime refers to the amount of time that a website is available and accessible to visitors. Reliability refers to the consistency of the web hosting service in terms of uptime and performance. It is important to choose a web host with a good track record of uptime and reliability.

6. **Security:** Security is a crucial aspect of web hosting, as websites are vulnerable to hacking and other forms of cyber attack. A good web host will provide security features such as firewalls, malware scanning, and regular backups to protect against data loss.

7. **Customer Support:** Customer support is an important factor to consider when choosing a web host. A good web host will provide responsive and helpful customer support to assist with any issues that may arise.

In summary, web hosting is an essential service for anyone looking to create a website. It is important to understand the basics of web hosting and to carefully consider the needs of the website when choosing a web hosting plan.
