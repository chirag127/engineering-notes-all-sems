### Unit 1 - Introduction: Line Breaks

- In web designing, line breaks are used to separate content into different lines.
- Line breaks can be added using the `<br>` tag in HTML.
- The `<br>` tag is an empty tag, which means it does not require a closing tag.
- Line breaks can also be added using the newline character `\n` in some programming languages, such as JavaScript.
- In CSS, the `white-space` property can be used to control how white space, including line breaks, is handled in an element.
- It is important to use line breaks appropriately to improve the readability and organization of the content on a web page.
