

### Dynamic Programming with Examples Such as Resource Allocation Problem

Dynamic Programming is a method of solving complex problems by breaking them down into smaller, simpler subproblems. It is used for problems that have overlapping subproblems, which means that the same subproblem can be used multiple times to solve the problem. 

Resource Allocation Problem is a type of Dynamic Programming problem. It is used to find the optimal allocation of resources to tasks or activities. 

Examples of Dynamic Programming problems include: 

- Knapsack: Given a set of items, each with a weight and a value, determine the number of each item to include in a collection so that the total weight is less than or equal to a given limit and the total value is as large as possible. 

- All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms: Given a graph with weighted edges, find the shortest path from each vertex to every other vertex in the graph. 

- Resource Allocation Problem: Given a set of tasks and a set of resources, determine how to allocate the resources to the tasks in order to maximize the overall value of the tasks. 

- Backtracking: Given a set of constraints, find a solution that satisfies all the constraints. 

- Branch and Bound with Examples Such as Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets: Given a set of constraints, find the optimal solution that satisfies all the constraints. 

These problems are all examples of Dynamic Programming, and can be used to solve Design and Analysis of Algorithm problems.
