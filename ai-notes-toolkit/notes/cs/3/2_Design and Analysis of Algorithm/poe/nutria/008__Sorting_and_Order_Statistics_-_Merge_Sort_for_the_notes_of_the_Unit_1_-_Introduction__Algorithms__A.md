
### Sorting and Order Statistics - Merge Sort

* Algorithms are a set of step-by-step instructions that can be used to solve a problem.
* Analyzing Algorithms is the process of determining the complexity of an algorithm, i.e. the amount of resources (time, memory, etc.) it takes to solve a problem.
* Complexity of Algorithms can be measured in terms of time, space, or both.
* Growth of Functions is the rate at which a function grows as its input size increases.
* Performance Measurements are used to evaluate the efficiency of an algorithm.
* Sorting and Order Statistics are algorithms used to arrange data in a certain order.
* Shell Sort is an algorithm for sorting data that uses insertion sort and a sequence of increments to sort the data.
* Quick Sort is an algorithm for sorting data that uses the divide-and-conquer approach.
* Merge Sort is an algorithm for sorting data that uses a divide-and-conquer approach to divide the data into subproblems and then merge the sorted subproblems.
* Heap Sort is an algorithm for sorting data that uses a binary heap to sort the data.
* Comparison of Sorting Algorithms is the process of examining the differences between different sorting algorithms.
* Sorting in Linear Time is an algorithm for sorting data that takes linear time to sort the data.
