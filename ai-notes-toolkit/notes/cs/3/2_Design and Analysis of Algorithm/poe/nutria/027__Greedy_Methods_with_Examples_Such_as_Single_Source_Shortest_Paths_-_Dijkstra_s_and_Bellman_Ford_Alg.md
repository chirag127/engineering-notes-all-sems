
### Greedy Methods

Greedy methods are an algorithmic strategy for solving optimization problems by making the best local decision at each step. Greedy algorithms are used in many different areas, including:

* Single Source Shortest Paths - Dijkstra’s and Bellman Ford Algorithms
* Optimal Reliability Allocation
* Knapsack
* Minimum Spanning Trees – Prim’s and Kruskal’s Algorithms

These algorithms are used to solve problems in the field of design and analysis of algorithms.

#### Single Source Shortest Paths - Dijkstra’s and Bellman Ford Algorithms

Single source shortest paths algorithms are used to find the shortest paths from a given source node to all other nodes in a graph. Dijkstra's algorithm is a popular example of single source shortest paths algorithms. It works by exploring the graph, starting from the source node, and assigning the shortest distance to each node. Bellman Ford algorithm is another example of single source shortest paths algorithms. It works by iteratively relaxing the edges of the graph until the shortest paths to all other nodes are found.

#### Optimal Reliability Allocation

Optimal reliability allocation algorithms are used to determine the optimal allocation of resources such as network nodes, links, and components to maximize the reliability of a system. These algorithms work by exploring the graph and finding the optimal allocation of resources that maximizes the reliability of the system.

#### Knapsack

Knapsack algorithms are used to solve the knapsack problem, which is the problem of selecting items from a set of items with given weights and values such that the total weight of the selected items does not exceed a given capacity and the total value is maximized. These algorithms work by exploring the search space and finding the optimal solution that maximizes the value of the selected items.

#### Minimum Spanning Trees – Prim’s and Kruskal’s Algorithms

Minimum spanning trees algorithms are used to find the minimum spanning tree of a given graph. Prim's algorithm is a popular example of minimum spanning trees algorithms. It works by exploring the graph and selecting the minimum cost edge to add to the tree. Kruskal's algorithm is another example of minimum spanning trees algorithms. It works by exploring the graph and selecting the edges with the minimum weights to add to the tree.
