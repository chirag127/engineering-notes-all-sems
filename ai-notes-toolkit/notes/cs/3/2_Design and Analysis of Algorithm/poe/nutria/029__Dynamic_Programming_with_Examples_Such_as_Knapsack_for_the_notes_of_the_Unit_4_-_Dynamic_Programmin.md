

### Dynamic Programming with Examples Such as Knapsack 

Dynamic programming is an approach to solving problems in which a recursive solution is broken down into smaller sub-problems. It is used to solve complex problems by breaking them down into simpler sub-problems and then combining the solutions of the sub-problems to get the overall solution.

- Knapsack Problem: A knapsack problem is a problem in which a given set of items must be packed into a knapsack such that the total value of the items is maximized while the total weight of the items is minimized. 
- All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms: Warshal's and Floyd's algorithms are used to find the shortest path between all pairs of nodes in a graph. 
- Resource Allocation Problem: This problem is used to allocate resources such as processors, memory, and storage to tasks in a manner that maximizes efficiency and minimizes cost. 
- Backtracking: Backtracking is a technique used to solve problems that involve searching for a solution from a set of possible solutions. It is used to find a solution to a problem by systematically exploring all possible solutions. 
- Branch and Bound with Examples Such as Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets: Branch and bound is an algorithm used to solve optimization problems. It involves breaking down a problem into smaller sub-problems and then combining the solutions of the sub-problems to get the overall solution. Examples of problems that can be solved using branch and bound include the Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets.
