
### Backtracking with Examples Such as Sum of Subsets

Backtracking is an algorithmic-technique for solving problems recursively by trying to build a solution incrementally, one piece at a time, removing those solutions that fail to satisfy the constraints of the problem at any point of time. Backtracking is applicable only for discrete problems and is used to find all possible solutions to a problem by exhaustively searching through the solution space.

Sum of Subsets is an example of backtracking. The problem is to find a subset of a given set of numbers that adds up to a given sum. The problem can be solved using backtracking by considering all possible subsets of the given set and checking if the sum of the elements in the subset is equal to the given sum.

#### Dynamic Programming

Dynamic Programming is an algorithmic technique used to solve complex problems by breaking them down into smaller sub-problems. It is used to solve optimization problems by storing the results of intermediate steps in a table and using them to solve the problem.

Examples of dynamic programming problems include Knapsack, All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms, and Resource Allocation Problem.

#### Branch and Bound

Branch and Bound is an algorithmic technique used to solve optimization problems by exhaustively searching through the solution space. It involves dividing the problem into sub-problems, solving each sub-problem, and combining the results of the sub-problems to obtain the solution to the original problem.

Examples of branch and bound problems include Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets.
