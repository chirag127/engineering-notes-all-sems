
## Unit 5 - NP-Completeness and Approximation Algorithms with Examples Such as Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets

This unit covers the concept of NP-Completeness and Approximation Algorithms with examples such as Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets.

* NP-Completeness: 
  * NP-Completeness is a concept in computer science that refers to decision problems that are both in the set of NP (nondeterministic polynomial time) problems and are also NP-hard. 
  * NP-hard problems are those that are at least as hard as any problem in NP. 
  * NP-complete problems are the hardest problems in NP, meaning that they are the most difficult to solve in polynomial time.

* Approximation Algorithms: 
  * Approximation algorithms are algorithms that are used to solve NP-hard problems in polynomial time. 
  * These algorithms are used to find approximate solutions to a problem, rather than the exact solution. 
  * Examples of approximation algorithms include the Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets.

* Travelling Salesman Problem: 
  * The Travelling Salesman Problem (TSP) is an optimization problem in which a salesman must visit a set of cities in the shortest possible route. 
  * The goal is to find the shortest route that visits each city exactly once and returns to the starting point.

* Graph Coloring: 
  * Graph coloring is a problem in which the vertices of a graph must be colored with a certain number of colors such that no two adjacent vertices have the same color. 
  * This problem is NP-hard and can be solved using approximation algorithms.

* n-Queen Problem: 
  * The n-Queen Problem is a problem in which n queens must be placed on an nxn chessboard such that no two queens attack each other. 
  * This problem is NP-hard and can be solved using approximation algorithms.

* Hamiltonian Cycles: 
  * A Hamiltonian cycle is a path in a graph that visits each vertex exactly once and returns to the starting vertex. 
  * This problem is NP-hard and can be solved using approximation algorithms.

* Sum of Subsets: 
  * The Sum of Subsets problem is a problem in which a set of integers must be partitioned into two subsets such that the sum of each subset is the same. 
  * This problem is NP-hard and can be solved using approximation algorithms.
