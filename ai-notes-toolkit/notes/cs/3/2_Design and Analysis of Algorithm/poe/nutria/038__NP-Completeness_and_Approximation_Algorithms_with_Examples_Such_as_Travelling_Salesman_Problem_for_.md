
### NP-Completeness and Approximation Algorithms with Examples Such as Travelling Salesman Problem

NP-completeness and approximation algorithms are essential concepts in the field of design and analysis of algorithms. This unit will explore these algorithms, with examples such as the Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles, and Sum of Subsets. 

**Travelling Salesman Problem**

The Travelling Salesman Problem (TSP) is a classic problem in computer science, which involves finding the shortest route that visits a given set of cities. It is an NP-complete problem, meaning that it is not possible to solve it in polynomial time. However, there are a variety of approximation algorithms which can be used to find a near-optimal solution. 

**Graph Coloring**

Graph coloring is a problem which involves assigning colors to the vertices of a graph, so that no two adjacent vertices have the same color. This problem is also NP-complete, but there are a variety of approximation algorithms which can be used to find a near-optimal solution. 

**n-Queen Problem**

The n-Queen Problem is a classic problem in computer science, which involves finding a way to place n queens on an nxn chessboard, so that no two queens attack each other. This problem is also NP-complete, but there are a variety of approximation algorithms which can be used to find a near-optimal solution. 

**Hamiltonian Cycles**

A Hamiltonian cycle is a cycle which visits each vertex of a graph exactly once. This problem is also NP-complete, but there are a variety of approximation algorithms which can be used to find a near-optimal solution. 

**Sum of Subsets**

The Sum of Subsets problem is a classic problem in computer science, which involves finding a subset of a given set of numbers whose sum is equal to a given target. This problem is also NP-complete, but there are a variety of approximation algorithms which can be used to find a near-optimal solution.
