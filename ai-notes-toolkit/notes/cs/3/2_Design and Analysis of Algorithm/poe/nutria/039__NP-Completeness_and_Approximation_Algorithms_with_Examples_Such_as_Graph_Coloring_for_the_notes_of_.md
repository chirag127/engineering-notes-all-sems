
### NP-Completeness and Approximation Algorithms with Examples 

This unit covers the topics of NP-Completeness and Approximation Algorithms with Examples such as Travelling Salesman Problem, Graph Coloring, n-Queen Problem, Hamiltonian Cycles and Sum of Subsets. 

**NP-Completeness** 

NP-Completeness is a concept in computer science that states that certain computational problems are so difficult to solve that no efficient algorithm can be found to solve them. These problems are known as NP-complete problems. 

**Approximation Algorithms** 

Approximation algorithms are algorithms that are used to solve NP-complete problems. These algorithms are not guaranteed to find the optimal solution, but they are able to find a solution that is close to the optimal solution. 

**Examples** 

1. Travelling Salesman Problem (TSP): This problem involves finding the shortest path between a given set of cities. 

2. Graph Coloring: This problem involves coloring a graph such that no two adjacent vertices have the same color. 

3. n-Queen Problem: This problem involves placing n queens on a chessboard such that no two queens are in the same row, column or diagonal. 

4. Hamiltonian Cycles: This problem involves finding a path that visits each vertex of a graph exactly once. 

5. Sum of Subsets: This problem involves finding a subset of a given set of numbers such that the sum of the numbers in the subset is equal to a given number.
