# Discovery
- The discovery phase is the first and most important phase of the data analytics lifecycle.
- The discovery phase involves identifying the business problem or opportunity, defining the objectives and scope of the analytics project, and gathering the relevant data sources and stakeholders.
- The discovery phase has the following steps:

  - **Problem definition**: This step involves understanding the business context and the problem or opportunity that needs to be addressed by the analytics project. The problem definition should be clear, specific, measurable, achievable, relevant, and time-bound (SMART).
  - **Objective setting**: This step involves defining the goals and expected outcomes of the analytics project, such as improving customer satisfaction, increasing revenue, reducing costs, or optimizing processes. The objectives should be aligned with the business strategy and the problem definition, and should be quantifiable and verifiable.
  - **Scope definition**: This step involves determining the boundaries and limitations of the analytics project, such as the data sources, data types, data quality, data volume, data granularity, data availability, data security, data privacy, data governance, analytical methods, analytical tools, analytical techniques, analytical outputs, analytical deliverables, analytical stakeholders, analytical roles, analytical responsibilities, analytical timeline, analytical budget, analytical risks, and analytical assumptions. The scope definition should be realistic, feasible, and flexible.
  - **Data collection**: This step involves identifying, acquiring, and accessing the relevant data sources that are needed for the analytics project. The data sources can be internal or external, structured or unstructured, static or dynamic, historical or real-time, etc. The data collection should be ethical, legal, and compliant with the data governance and data privacy policies and regulations.
  - **Data exploration**: This step involves examining, summarizing, and visualizing the collected data to gain insights, identify patterns, discover anomalies, and understand the data characteristics, such as the data distribution, data variability, data correlation, data outliers, data missingness, data quality, data relevance, data completeness, data consistency, data accuracy, data validity, data reliability, data timeliness, data usability, etc. The data exploration should be systematic, comprehensive, and iterative.
