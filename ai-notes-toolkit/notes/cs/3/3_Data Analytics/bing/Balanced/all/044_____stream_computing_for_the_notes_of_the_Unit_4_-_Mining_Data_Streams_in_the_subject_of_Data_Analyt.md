# Stream Computing

Stream computing is a programming paradigm that deals with data streams, or sequences of events in time, as the central input and output objects of computation. Stream computing enables organizations to process data streams that are always on and never ceasing, and to produce actionable results in real time. Stream computing uses software algorithms that analyze the data as it streams in, without storing it first, to increase speed and accuracy when dealing with data handling and analysis.

Some of the applications of stream computing are:

- Fraud detection: Stream computing can help detect fraudulent transactions or activities by analyzing data streams from various sources, such as credit cards, bank accounts, or online platforms, and flagging any anomalies or suspicious patterns.
- Sensor networks: Stream computing can help monitor and control sensor networks, such as smart grids, smart cities, or smart homes, by processing data streams from sensors, actuators, or devices, and providing feedback or commands in real time.
- Social media analytics: Stream computing can help analyze social media data streams, such as tweets, posts, or comments, and extract insights or trends from them, such as sentiment, topics, or influencers.

Some of the platforms for stream computing are:

- IBM Stream Computing: IBM Stream Computing is a platform that continuously analyzes data and connects to all data sources, using a high-performance runtime system and a graphical development environment. IBM Stream Computing also includes System S, a distributed stream processing platform that supports complex analytics and queries over data streams.
- Apache Flink: Apache Flink is an open source platform for stream processing that supports stateful computations over data streams, and provides high throughput, low latency, and fault tolerance.
- Apache Spark: Apache Spark is an open source platform for large-scale data processing that supports stream processing as one of its components, using micro-batches of data streams and providing high-level APIs for various languages.
