# Exploratory Data Analysis

- Exploratory data analysis (EDA) is an approach of analyzing data sets to summarize their main characteristics, often using statistical graphics and other data visualization methods.
- EDA helps determine how best to manipulate data sources to get the answers you need, making it easier for data scientists to discover patterns, spot anomalies, test hypotheses, and check assumptions.
- EDA is an important first step in any data analysis, as it identifies general patterns in the data, such as outliers and unexpected features, that might affect the subsequent analysis or modeling.
- EDA can be performed using various tools and techniques, such as descriptive statistics, histograms, box plots, scatter plots, correlation matrices, etc.
- EDA can be classified into two types: univariate and multivariate. Univariate EDA focuses on one variable at a time, while multivariate EDA explores the relationships between two or more variables.
