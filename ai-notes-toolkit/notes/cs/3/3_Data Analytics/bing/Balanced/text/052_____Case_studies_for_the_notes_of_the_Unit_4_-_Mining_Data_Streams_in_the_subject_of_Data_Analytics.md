### Case studies for the notes of the Unit 4 - Mining Data Streams in the subject of Data Analytics

- Mining data streams is the process of extracting knowledge structures, such as models and patterns, from continuous and unbounded streams of information.
- Data stream mining poses many challenges, such as high data volume, high data velocity, concept drift, limited memory and processing resources, and evolving data distributions.
- Data stream mining algorithms need to be scalable, adaptive, incremental, and robust to handle these challenges.
- Some of the applications of data stream mining include network monitoring, sensor networks, web analytics, social media analysis, fraud detection, and recommender systems.
- Here are some case studies of data stream mining from different domains:

  - A Case Study: Stream Data Mining Classification
    - This case study presents a stream data mining classification algorithm based on the Hoeffding tree, which is a decision tree that can be incrementally updated with new data.
    - The algorithm uses a sliding window technique to handle concept drift, which is the change in the underlying data distribution over time.
    - The algorithm is evaluated on two real-world datasets: the electricity market dataset and the weather dataset.
    - The results show that the algorithm can achieve high accuracy and low memory consumption compared to other stream data mining algorithms.
  - Improvised methods for tackling big data stream mining challenges: case study of predicting the number of emergency department visits
    - This case study proposes a holistic data stream mining approach that combines different components of data stream mining, such as feature selection, ensemble learning, and concept drift detection, to improve the prediction performance.
    - The approach is applied to the problem of predicting the number of emergency department visits in a hospital, which is a challenging and important task for health care management.
    - The approach is tested on a real-world dataset that contains 1.5 million records of emergency department visits from 2009 to 2013.
    - The results show that the approach can achieve better accuracy, stability, and adaptability than existing data stream mining methods.
  - An update on global mining land use
    - This case study presents an updated dataset of global mining land use, which covers both active and inactive mining sites from 2000 to 2019.
    - The dataset is derived from two sources: the Global Mining Footprint dataset, which mapped 295 major mine sites worldwide, and the Global Surface Mining dataset, which mapped 6,941 mine sites using satellite imagery and machine learning.
    - The dataset provides a comprehensive and consistent spatial representation of mining land use, which can be used for various environmental and socio-economic analyses.
    - The dataset reveals that mining land use has increased by 17.6% from 2000 to 2019, with the largest expansion occurring in Africa, Asia, and South America.
