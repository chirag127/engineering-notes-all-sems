### Analytics for Unstructured Data

- Unstructured data is information that is not organized in a pre-defined manner, such as text, video, audio, web server logs, social media, and more .
- Unstructured data analysis is the process of using data analytics tools to automatically organize, structure and get value from unstructured data.
- Unstructured data analysis techniques can be classified into three categories: exploratory data analysis, qualitative data analysis, and AI and ML.
- Exploratory data analysis (EDA) is a set of initial investigations done to identify the main characteristics, patterns, and outliers in unstructured data. EDA can use techniques such as descriptive statistics, data visualization, and clustering.
- Qualitative data analysis mainly applies for unstructured text data. This can include techniques such as text mining, sentiment analysis, topic modeling, and natural language processing (NLP). Qualitative data analysis can help extract meaning, insights, and opinions from textual data.
- AI and ML unstructured data analysis techniques include decision trees, principal component analysis (PCA), artificial neural networks, image analysis, temporal modeling techniques, market segmentation analysis, and more. These techniques help with predictive analytics and uncovering the data insights.
- Tips for unstructured data analytics:
  - Keep the business objectives in mind. The analytical techniques you choose should match up to your business objectives.
  - Define metadata for faster data access. Metadata is data about data, such as the source, format, and quality of the data. Metadata can help you find and access the relevant data faster.
  - Choose the right analytics techniques. Depending on the type and complexity of the unstructured data, you may need different techniques to analyze it. For example, text data may require NLP, while image data may require image analysis.
  - Identify the right data sources. Unstructured data can come from various sources, such as social media, web pages, customer reviews, etc. You need to identify the sources that are relevant and reliable for your analysis.
  - Evaluate the technologies you’d want to use. There are various tools and platforms available for unstructured data analysis, such as MongoDB, Hadoop, Spark, etc. You need to evaluate the features, costs, and benefits of each technology and choose the one that suits your needs.
  - Get real-time data access. Unstructured data is often dynamic and changing, so you need to access and analyze it in real-time to get the most accurate and timely insights.
  - Store and integrate data using data lakes. Data lakes are repositories that can store and integrate large volumes and varieties of unstructured data in their raw form. Data lakes can help you preserve the originality and flexibility of the data and enable faster analysis.
  - Wrangle the unstructured data. Data wrangling is the process of cleaning, transforming, and enriching the unstructured data to make it ready for analysis. Data wrangling can help you improve the quality and usability of the data and reduce errors and biases.
