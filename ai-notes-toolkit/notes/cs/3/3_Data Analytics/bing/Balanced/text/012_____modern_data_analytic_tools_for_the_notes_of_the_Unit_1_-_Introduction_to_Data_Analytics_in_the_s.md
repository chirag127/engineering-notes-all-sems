### Modern Data Analytic Tools

- Data analytics is the process of collecting, organizing, analyzing, and presenting data to gain insights and support decision making.
- Modern data analytic tools are software applications or platforms that enable data analysts to perform various tasks related to data analytics, such as data extraction, transformation, loading, modeling, visualization, reporting, and machine learning.
- Some of the modern data analytic tools that are widely used in 2023 are:

  - **Python**: Python is a general-purpose programming language that has a rich set of libraries and frameworks for data analysis, such as pandas, numpy, scipy, scikit-learn, matplotlib, seaborn, and tensorflow. Python allows data analysts to write concise and readable code, manipulate and process large and complex data sets, and apply various statistical and machine learning techniques. Python is also compatible with other data analytic tools, such as Apache Spark, Jupyter Notebook, and Power BI .
  - **R**: R is a programming language and environment that is designed for statistical computing and graphics. R has a comprehensive collection of packages and functions for data analysis, such as dplyr, tidyr, ggplot2, shiny, and caret. R enables data analysts to perform exploratory data analysis, data visualization, statistical inference, and predictive modeling. R is also integrated with other data analytic tools, such as Excel, Power BI, and Tableau .
  - **SAS**: SAS is a software suite that offers solutions for data management, business intelligence, advanced analytics, and machine learning. SAS has a graphical user interface and a programming language that allow data analysts to access, manipulate, analyze, and report on data from various sources. SAS also provides tools for data mining, forecasting, optimization, and text analytics. SAS is widely used in industries such as banking, healthcare, and government .
  - **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel allows data analysts to perform basic data analysis, such as sorting, filtering, summarizing, and charting data. Excel also has features such as pivot tables, formulas, functions, and macros that enable data analysts to perform more advanced data analysis, such as data validation, data cleaning, data modeling, and scenario analysis. Excel is compatible with other data analytic tools, such as Power Query, Data Model, Power BI, and R .
  - **Power BI**: Power BI is a business intelligence and data visualization tool that is part of the Microsoft Power Platform. Power BI allows data analysts to connect to various data sources, transform and model data, create interactive dashboards and reports, and share insights with others. Power BI also supports advanced analytics, such as natural language processing, geospatial analysis, and artificial intelligence. Power BI can be used as a desktop application, a web service, or a mobile app  .
  - **Tableau**: Tableau is a business intelligence and data visualization tool that helps data analysts to explore, analyze, and communicate data. Tableau allows data analysts to connect to various data sources, create and customize visualizations, build interactive dashboards and stories, and collaborate with others. Tableau also supports advanced analytics, such as statistical analysis, predictive modeling, and machine learning. Tableau can be used as a desktop application, a web service, or a mobile app  .
  - **Apache Spark**: Apache Spark is an open-source distributed computing framework that enables data analysts to process large-scale data sets in a fast and efficient way. Apache Spark supports various data analysis tasks, such as batch processing, stream processing, machine learning, graph analysis, and natural language processing. Apache Spark can be integrated with various data analytic tools, such as Python, R, SQL, and Hadoop .
