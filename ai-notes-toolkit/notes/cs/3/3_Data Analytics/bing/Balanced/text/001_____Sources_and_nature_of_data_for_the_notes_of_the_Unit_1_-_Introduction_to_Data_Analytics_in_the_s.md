### Sources and nature of data

- Data is any information that can be measured, recorded, or communicated.
- Data can come from various sources, such as surveys, experiments, observations, transactions, sensors, social media, etc.
- Data can have different natures, such as quantitative or qualitative, structured or unstructured, discrete or continuous, etc.
- Quantitative data is data that can be expressed in numbers, such as height, weight, temperature, etc.
- Qualitative data is data that can be expressed in words, such as color, opinion, mood, etc.
- Structured data is data that has a predefined format and can be easily stored, processed, and analyzed, such as tables, spreadsheets, databases, etc.
- Unstructured data is data that has no predefined format and can be difficult to store, process, and analyze, such as text, images, audio, video, etc.
- Discrete data is data that can only take certain values, such as count, gender, yes/no, etc.
- Continuous data is data that can take any value within a range, such as length, time, speed, etc.
