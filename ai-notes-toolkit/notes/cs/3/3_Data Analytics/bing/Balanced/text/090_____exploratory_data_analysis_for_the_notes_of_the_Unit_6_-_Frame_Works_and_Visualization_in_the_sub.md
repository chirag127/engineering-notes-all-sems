### Exploratory Data Analysis

- Exploratory data analysis (EDA) is the process of examining and summarizing data sets using descriptive statistics, visualizations, and other techniques.
- EDA helps to understand the characteristics, patterns, and relationships in the data, as well as to identify any potential problems or anomalies.
- EDA is often the first step in data analysis, before applying any formal statistical or machine learning methods.
- EDA can be performed using various tools and frameworks, such as Python, R, Excel, Tableau, Power BI, etc.

### Frameworks and Visualization

- Frameworks are software libraries or packages that provide a set of functions, classes, or methods for performing common tasks or operations on data, such as data manipulation, analysis, modeling, or visualization.
- Some examples of frameworks for data analysis are pandas, numpy, scipy, sklearn, etc. in Python, and dplyr, tidyr, ggplot2, etc. in R.
- Visualization is the process of creating graphical representations of data, such as charts, graphs, maps, or dashboards, to communicate information, insights, or findings.
- Visualization helps to explore, understand, and present data in an effective and engaging way, as well as to support decision making and storytelling.
- Some examples of visualization tools are matplotlib, seaborn, plotly, etc. in Python, and ggplot2, plotly, shiny, etc. in R.
