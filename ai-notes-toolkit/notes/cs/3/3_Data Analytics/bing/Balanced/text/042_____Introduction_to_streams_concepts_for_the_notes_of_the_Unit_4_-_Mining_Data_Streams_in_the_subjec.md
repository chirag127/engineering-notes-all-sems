### Introduction to streams concepts for the notes of the Unit 4 - Mining Data Streams in the subject of Data Analytics

- A data stream is an existing, continuous, ordered (implicitly by entrance time or explicitly by timestamp) chain of items.
- Data streams capture the data processing needs of today, where random access is expensive and a single scan algorithm is preferred.
- Data streams are generated by various sources, such as equipment sensors, clickstreams, social media feeds, stock market quotes, app activity, and more.
- Streaming analytics is the continuous processing and analysis of big data in motion.
- Streaming analytics can provide real-time insights and actions from the data streams, such as anomaly detection, fraud prevention, sentiment analysis, recommendation systems, etc.
- Streaming analytics can be classified into hard and soft real-time, depending on the latency period and the criticality of the application.
- Stream processing is a data management technique that involves ingesting a continuous data stream to quickly analyze, filter, transform or enhance the data in real time.
- Stream processing can be done by various tools and frameworks, such as Apache Kafka, Apache Spark, Apache Flink, Apache Storm, etc.
- Stream processing can be combined with batch processing and interactive processing to form a unified data processing architecture, such as the lambda architecture or the kappa architecture.
