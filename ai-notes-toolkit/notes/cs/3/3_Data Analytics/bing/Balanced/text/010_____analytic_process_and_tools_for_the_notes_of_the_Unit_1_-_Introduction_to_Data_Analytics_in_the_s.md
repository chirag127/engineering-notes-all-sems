### Analytic Process and Tools

- Analytic process is the systematic application of data analysis techniques to solve a problem or achieve a goal.
- Analytic tools are the software or methods that enable data collection, manipulation, visualization, and interpretation.
- Some examples of analytic tools are:
  - Microsoft Power BI: A data visualization tool that allows users to create interactive dashboards and reports from various data sources.
  - Tableau: A business intelligence tool that enables users to explore, analyze, and share data insights through interactive charts and graphs.
  - Qlik Sense: A machine learning tool that uses artificial intelligence to generate insights and recommendations from data.
  - Looker: A data platform that connects to various databases and allows users to create custom data models and queries.
- Some steps of the analytic process are:
  - Define the problem or objective: Identify the question or goal that the analysis aims to answer or achieve.
  - Collect and prepare the data: Gather the relevant data from various sources and clean, transform, and integrate it for analysis.
  - Explore and analyze the data: Use descriptive and inferential statistics, data visualization, and machine learning techniques to discover patterns, trends, and relationships in the data.
  - Interpret and communicate the results: Summarize the findings and implications of the analysis and present them in a clear and concise manner to the stakeholders.
- Some techniques and tools for process analysis are:
  - Process modeling: A way of documenting and visualizing the steps, inputs, outputs, and resources of a process using flow charts, process maps, written procedures, and work instructions .
  - Process mapping: A type of process modeling that focuses on the activities, roles, and interactions of a process using symbols, arrows, and text .
  - Process improvement: A method of identifying and eliminating waste, inefficiency, and errors in a process using frameworks such as Lean, Six Sigma, and Kaizen .
  - Cause and effect analysis: A technique of finding the root causes of a problem or an effect using tools such as fishbone diagrams, Pareto charts, and 5 Whys .
