### Pig

- Pig is a framework for processing large data sets that runs on top of Hadoop and MapReduce.
- Pig provides a high-level language called Pig Latin, which allows users to write data analysis programs using various operators and functions.
- Pig converts Pig Latin scripts into MapReduce jobs, which are executed on Hadoop clusters.
- Pig can handle structured, semi-structured, and unstructured data, and supports various file formats such as text, CSV, Excel, RC, etc.
- Pig is used for data analysis because of its features such as:
  - Ease of programming: Pig Latin is a simple and expressive language that can perform complex data transformations with minimal code.
  - Optimization: Pig automatically optimizes the execution plan of Pig Latin scripts, and allows users to customize the optimization strategies.
  - Extensibility: Pig allows users to define their own functions, load and store functions, and user-defined data types using Java, Python, or other languages.
  - Interoperability: Pig can interoperate with other Hadoop components such as Hive, HBase, Spark, etc.
