## Unit 3 - Data Analysis

Data analysis is the process of collecting, organizing, exploring, and interpreting data to answer questions, solve problems, or make decisions. Data analysis can be done using various methods and tools, depending on the type and purpose of the data.

Some of the topics covered in this unit are:

- Data types and sources: Data can be classified into different types, such as numerical, categorical, or textual, and can be obtained from various sources, such as surveys, experiments, or databases.
- Data visualization: Data visualization is the use of graphs, charts, maps, or other visual elements to present data in a clear and effective way. Data visualization can help to identify patterns, trends, outliers, or relationships in the data.
- Descriptive statistics: Descriptive statistics are numerical measures that summarize the main features of a data set, such as the mean, median, mode, range, standard deviation, or frequency distribution. Descriptive statistics can help to describe the central tendency, variability, or shape of the data.
- Inferential statistics: Inferential statistics are methods that use sample data to make generalizations or predictions about a population or a phenomenon. Inferential statistics can help to test hypotheses, estimate parameters, or compare groups using techniques such as confidence intervals, hypothesis testing, or analysis of variance.
- Correlation and regression: Correlation and regression are methods that measure the strength and direction of the linear relationship between two variables. Correlation can help to assess how two variables are related, while regression can help to model the relationship and make predictions based on the data.
