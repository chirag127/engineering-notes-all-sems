### Case studies for the notes of the Unit 4 - Mining Data Streams in the subject of Data Analytics

Mining data streams is the process of extracting knowledge from continuous and unbounded flows of data. Data stream mining has many applications and challenges in various domains, such as network monitoring, sensor networks, web mining, social media analysis, etc. In this unit, we will review some case studies for mining data streams, based on the following sources:

- A Case Study: Stream Data Mining Classification by Ketan Desale (2015)
- Data Streams in Data Mining Simplified 101 by Hevo (2020)
- Mining Data Streams: A Review by Charu C. Aggarwal et al. (2005)
- Improvised methods for tackling big data stream mining challenges: case study of electricity price forecasting by Nada Lavrač et al. (2016)
- An Overview on Mining Data Streams by João Gama and Mohamed Medhat Gaber (2009)
- DATA STREAM MINING by Albert Bifet and Eibe Frank (2010)

The case studies are:

- **Stream Data Mining Classification**: This case study presents a method for classifying data streams using a sliding window technique and a decision tree algorithm. The method is applied to a real-world dataset of network intrusion detection, where the goal is to identify malicious or anomalous network activities. The method is evaluated in terms of accuracy, memory usage, and processing time, and compared with other existing methods. The results show that the proposed method can achieve high accuracy and low memory consumption, while adapting to the changes in the data stream. 
- **Data Streams in Data Mining Simplified 101**: This case study provides a comprehensive overview of the concepts and techniques of data stream mining, such as data stream models, data stream processing, data stream algorithms, and data stream applications. The case study also introduces some tools and platforms for data stream mining, such as Apache Kafka, Apache Spark, Apache Flink, and Hevo. The case study explains how data stream mining can help businesses gain insights and make decisions from real-time data. 
- **Mining Data Streams: A Review**: This case study surveys the state-of-the-art research in data stream mining, covering the main challenges and issues, such as data stream models, data stream algorithms, data stream mining tasks, and data stream mining applications. The case study also discusses some open problems and future directions for data stream mining research. 
- **Improvised methods for tackling big data stream mining challenges: case study of electricity price forecasting**: This case study proposes a novel approach for big data stream mining, which combines different components, such as data stream preprocessing, feature selection, ensemble learning, and change detection. The approach is applied to the problem of electricity price forecasting, which is a complex and dynamic task that requires high accuracy and timeliness. The approach is compared with several baseline methods, and the results show that it can improve the prediction performance and adapt to the changes in the data stream. 
- **An Overview on Mining Data Streams**: This case study gives a general introduction to the field of data stream mining, focusing on the main challenges and issues, such as incremental learning, cost-performance management, change detection, and novelty detection. The case study also presents some examples of data stream mining applications, such as web mining, sensor networks, and text mining. 
- **DATA STREAM MINING**: This case study describes the data stream paradigm and its advantages over the traditional batch processing paradigm. The case study also introduces some data stream mining algorithms and tools, such as MOA, VFML, and ADWIN. The case study demonstrates how data stream mining can handle large and evolving data sets, and how it can be applied to various domains, such as spam filtering, concept drift detection, and recommender systems.
