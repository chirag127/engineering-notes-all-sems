### Mining frequent itemsets

- Frequent itemsets are sets of items that appear together frequently in a dataset, such as a transactional database or a relational database.
- Mining frequent itemsets is a technique used to discover patterns and relationships among items in a dataset, such as association rules, which can be used for various data mining tasks, such as recommendation systems, market basket analysis, fraud detection, etc.
- Mining frequent itemsets involves finding all the itemsets that satisfy a minimum support threshold, which is the minimum number or percentage of transactions that contain the itemset.
- There are several algorithms for mining frequent itemsets, such as Apriori, Eclat, and FP-growth. These algorithms differ in how they generate and prune the candidate itemsets, how they store and traverse the data structure, and how they exploit the properties of the itemsets, such as anti-monotonicity, downward closure, etc.
- Apriori is the most commonly used algorithm for mining frequent itemsets. It works by generating candidate itemsets of increasing size (from 1-itemsets to k-itemsets) and scanning the dataset to count their support. It prunes the candidates that do not meet the minimum support threshold and uses the Apriori property to avoid generating unnecessary candidates. The Apriori property states that if an itemset is frequent, then all its subsets are also frequent.
- Eclat is a depth-first search algorithm that uses a vertical data format, where each item is associated with a tidset, which is the set of transaction ids that contain the item. It generates candidate itemsets by intersecting the tidsets of the frequent items and prunes the candidates that have a smaller tidset than the minimum support threshold. It uses the downward closure property to avoid generating unnecessary candidates. The downward closure property states that if an itemset is infrequent, then all its supersets are also infrequent.
- FP-growth is a divide-and-conquer algorithm that uses a compact data structure called FP-tree, which is a prefix tree that stores the frequent items and their occurrence counts in each transaction. It generates frequent itemsets by recursively constructing conditional FP-trees for each frequent item and extracting the frequent itemsets from the conditional FP-trees. It does not generate any candidate itemsets and uses the FP-tree to avoid scanning the dataset multiple times.
