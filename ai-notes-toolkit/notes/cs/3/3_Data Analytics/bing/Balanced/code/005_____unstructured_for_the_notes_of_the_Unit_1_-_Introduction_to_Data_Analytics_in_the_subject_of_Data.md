# Unit 1 - Introduction to Data Analytics

## Unstructured Data

- Unstructured data is information that does not have a pre-defined data model or is not organized in a pre-defined manner.
- Unstructured data is typically text-heavy, but may contain data such as dates, numbers, and facts as well.
- Unstructured data is difficult to store and manage in a mainstream relational database or RDBMS.
- Unstructured data is best managed in non-relational (NoSQL) databases.
- Unstructured data can be categorized as qualitative data.
- Examples of unstructured data include email messages, videos, photos, webpages, audio files, and business documents.
- Unstructured data accounts for the vast majority of new data being generated today.
- Unstructured data can provide valuable insights for business analytics, but requires specialized tools and methods to process and analyze.
