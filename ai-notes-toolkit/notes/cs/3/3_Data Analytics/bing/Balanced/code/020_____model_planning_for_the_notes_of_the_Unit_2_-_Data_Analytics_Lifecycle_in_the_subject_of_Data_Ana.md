### Model Planning

- Model planning is the third phase of the data analytics lifecycle, after data preparation and data exploration.
- In this phase, the analyst selects the appropriate modeling techniques and tools to address the business problem and the data characteristics.
- The main objectives of model planning are:
  - To identify the variables and features that are relevant for the analysis and the prediction.
  - To determine the optimal number and size of the data subsets for training, validation, and testing the models.
  - To choose the best algorithms and methods for building and evaluating the models, such as regression, classification, clustering, etc.
  - To define the performance metrics and criteria for selecting the best model, such as accuracy, precision, recall, F1-score, etc.
- The main steps of model planning are:
  - Variable selection: This involves selecting the dependent and independent variables, as well as the potential predictors and outcomes, based on the data exploration results and the business objectives. Variable selection can be done manually or using automated techniques, such as correlation analysis, feature importance, or dimensionality reduction.
  - Data partitioning: This involves splitting the data into three subsets: training, validation, and testing. The training set is used to build the models, the validation set is used to tune the model parameters and compare different models, and the testing set is used to evaluate the final model performance on unseen data. Data partitioning can be done randomly or using stratified sampling, depending on the data distribution and the analysis goal.
  - Model selection: This involves choosing the most suitable modeling techniques and tools for the analysis, based on the data type, the problem type, and the available resources. Model selection can be done based on prior knowledge, literature review, or trial and error. Some examples of modeling techniques are linear regression, logistic regression, decision tree, k-means clustering, etc.
  - Model evaluation: This involves assessing the quality and validity of the models, using the performance metrics and criteria defined earlier. Model evaluation can be done using various methods, such as confusion matrix, ROC curve, AUC score, etc. The best model is the one that maximizes the desired metric and minimizes the error on the validation set.
