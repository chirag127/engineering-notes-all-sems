### MapR

- MapR is a big data platform that integrates Hadoop, an open-source software framework, and Spark, an open-source data processing engine.
- The platform includes global event streaming, real-time database capabilities, and enterprise storage.
- MapR supports open source tools such as Hadoop, Spark and Drill as well as open industry standards such as POSIX and NFS.
- MapR enables fast and reliable analytics on complex and large-scale data sets.
- MapR provides the following features and benefits :
  - High availability and disaster recovery with no single point of failure or data loss.
  - Scalability and performance with distributed processing and parallelism.
  - Security and governance with encryption, authentication, authorization and auditing.
  - Ease of use and management with self-healing, automation and monitoring.
  - Interoperability and compatibility with a broad set of Hadoop ecosystem projects and standard APIs.
  - Flexibility and innovation with support for multiple data types, formats and sources.
