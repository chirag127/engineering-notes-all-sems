## Unit 5 - Frequent Itemsets and Clustering

This unit covers two important topics in data mining: finding frequent itemsets and performing clustering.

### Frequent Itemsets

- A frequent itemset is a set of items that occurs together frequently in a given dataset.
- For example, in a dataset of supermarket transactions, a frequent itemset could be {bread, milk, eggs}.
- Finding frequent itemsets is useful for discovering associations, correlations, and patterns among items.
- For example, finding frequent itemsets can help identify cross-selling opportunities, customer preferences, and market segments.
- A common measure of the frequency of an itemset is its support, which is the fraction of transactions that contain the itemset.
- For example, if {bread, milk, eggs} has a support of 0.2, it means that 20% of the transactions contain these three items.
- A frequent itemset is one that has a support above a given threshold, called the minimum support.
- For example, if the minimum support is 0.1, then only itemsets with a support of at least 0.1 are considered frequent.
- Finding frequent itemsets is challenging because the number of possible itemsets grows exponentially with the number of items.
- For example, if there are 100 items, there are 2^100 possible itemsets, which is too large to enumerate and test for frequency.
- Therefore, efficient algorithms are needed to find frequent itemsets without scanning the entire dataset multiple times.
- One such algorithm is the Apriori algorithm, which exploits the property that any subset of a frequent itemset must also be frequent.
- For example, if {bread, milk, eggs} is frequent, then {bread, milk}, {bread, eggs}, {milk, eggs}, {bread}, {milk}, and {eggs} must also be frequent.
- The Apriori algorithm works as follows:
  - It starts with the set of all frequent 1-itemsets, called L1.
  - It then generates the set of all candidate 2-itemsets, called C2, by joining L1 with itself.
  - It then scans the dataset and prunes any candidate that has a support below the minimum support, resulting in the set of all frequent 2-itemsets, called L2.
  - It then repeats the process of generating candidates and pruning them, increasing the size of the itemsets by one at each iteration, until no more candidates can be generated or no more frequent itemsets can be found.
- The output of the Apriori algorithm is the union of all the frequent itemsets of different sizes, called the frequent itemset lattice.
- The Apriori algorithm can be improved by using various techniques, such as hashing, transaction reduction, partitioning, sampling, and dynamic itemset counting.

### Clustering

- Clustering is the process of grouping similar objects into clusters, such that objects within a cluster are more similar to each other than to objects in other clusters.
- For example, in a dataset of customers, clustering can help segment them into different groups based on their demographics, preferences, or behavior.
- Clustering is useful for exploratory data analysis, data compression, data summarization, anomaly detection, and data visualization.
- Clustering is an unsupervised learning task, meaning that there is no predefined label or class for the objects, and the goal is to discover the inherent structure or patterns in the data.
- Clustering can be performed on different types of data, such as numerical, categorical, textual, spatial, temporal, or mixed data.
- Clustering can also be performed at different levels of granularity, such as hierarchical, flat, or overlapping clustering.
- There are many different methods and algorithms for clustering, each with its own assumptions, advantages, and disadvantages.
- Some of the most common clustering methods are:
  - K-means clustering, which partitions the data into k clusters by minimizing the sum of squared distances from each object to its cluster centroid, which is the mean of the objects in the cluster.
  - Hierarchical clustering, which builds a tree-like structure of clusters by either merging smaller clusters into larger ones (agglomerative) or splitting larger clusters into smaller ones (divisive), based on some measure of similarity or distance between clusters.
