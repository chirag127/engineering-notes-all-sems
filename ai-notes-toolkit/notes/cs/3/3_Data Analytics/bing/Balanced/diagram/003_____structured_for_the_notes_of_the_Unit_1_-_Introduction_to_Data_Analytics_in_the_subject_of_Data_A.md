### Unit 1 - Introduction to Data Analytics

- Data analytics is the process of collecting, organizing, analyzing, and interpreting data to gain insights and support decision making.
- Data analytics can be applied to various domains, such as business, science, engineering, health, education, and social sciences.
- Data analytics can be classified into four types, based on the level of complexity and the purpose of the analysis:

  - Descriptive analytics: summarizes what has happened in the past using historical data. Examples: reports, dashboards, charts, tables.
  - Diagnostic analytics: explains why something has happened in the past using statistical techniques. Examples: correlation, regression, hypothesis testing.
  - Predictive analytics: predicts what will happen in the future using machine learning and data mining. Examples: forecasting, classification, clustering, association rules.
  - Prescriptive analytics: recommends what actions to take in the future using optimization and simulation. Examples: decision analysis, scheduling, resource allocation.

- Data analytics involves various steps, such as:

  - Data acquisition: collecting data from various sources, such as databases, files, sensors, web, etc.
  - Data preprocessing: cleaning, transforming, and integrating data to make it suitable for analysis. Examples: handling missing values, outliers, duplicates, inconsistencies, etc.
  - Data exploration: exploring data to understand its characteristics, patterns, and relationships. Examples: summary statistics, visualization, dimensionality reduction, etc.
  - Data modeling: applying analytical techniques to data to generate insights and predictions. Examples: regression, classification, clustering, association rules, etc.
  - Data evaluation: assessing the quality and validity of the analytical results. Examples: accuracy, precision, recall, F1-score, ROC curve, etc.
  - Data communication: presenting and communicating the analytical results to the stakeholders. Examples: reports, dashboards, charts, tables, etc.

- Data analytics requires various skills, such as:

  - Domain knowledge: understanding the context and the problem of the domain where data analytics is applied.
  - Data literacy: understanding the concepts and methods of data analytics, such as data types, data structures, data sources, data quality, data analysis, etc.
  - Data manipulation: manipulating data using tools and languages, such as Excel, SQL, Python, R, etc.
  - Data visualization: visualizing data using tools and languages, such as Excel, Tableau, Power BI, Python, R, etc.
  - Data science: applying advanced analytical techniques using tools and languages, such as Python, R, TensorFlow, PyTorch, etc.
  - Data storytelling: communicating data insights using narratives, visuals, and interactive elements, such as reports, dashboards, charts, tables, etc.
