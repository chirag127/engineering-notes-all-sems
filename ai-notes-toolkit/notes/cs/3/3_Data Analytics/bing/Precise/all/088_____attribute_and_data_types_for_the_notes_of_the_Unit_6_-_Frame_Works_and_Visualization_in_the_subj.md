# Unit 6 - Frame Works and Visualization in Data Analytics

## Attributes and Data Types

- Attributes are characteristics or properties of data that can be measured or observed.
- Data types refer to the type of data that can be stored in an attribute.
- Common data types include:
  - Numeric: used to store numbers, such as integers or floating-point values.
  - Text: used to store strings of characters, such as names or addresses.
  - Date/Time: used to store dates and times.
  - Boolean: used to store true/false values.
- The choice of data type for an attribute depends on the nature of the data and the intended use of the attribute.
- It is important to choose the appropriate data type for an attribute to ensure that the data is stored and processed correctly.
- Some data visualization tools and frameworks may have specific requirements for the data types of attributes used in visualizations.
