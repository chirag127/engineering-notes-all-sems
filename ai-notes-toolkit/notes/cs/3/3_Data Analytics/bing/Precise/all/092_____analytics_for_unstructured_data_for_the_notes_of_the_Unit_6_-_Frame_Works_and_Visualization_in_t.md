### Unit 6 - Frame Works and Visualization: Analytics for Unstructured Data

1. Unstructured data refers to data that does not have a predefined data model or is not organized in a pre-defined manner. Examples include text, images, and videos.
2. Analytics for unstructured data involves extracting meaningful insights from this type of data.
3. Techniques for analyzing unstructured data include natural language processing, image and video analysis, and sentiment analysis.
4. Frameworks for analyzing unstructured data include Apache Hadoop, Apache Spark, and Elasticsearch.
5. Visualization tools for unstructured data include Tableau, QlikView, and D3.js.
6. These tools and frameworks allow for the processing, analysis, and visualization of large amounts of unstructured data, enabling organizations to gain valuable insights and make data-driven decisions.
