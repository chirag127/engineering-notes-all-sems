# Unit 1 - Introduction to Data Analytics

### Semi-Structured Data

- Semi-structured data refers to data that has some level of organization, but not enough to be considered structured data.
- This type of data often has a flexible schema, meaning that the structure of the data can change over time.
- Examples of semi-structured data include JSON, XML, and CSV files.
- Semi-structured data can be more difficult to analyze than structured data, as it requires more processing to extract meaningful information.
- However, semi-structured data can also be more flexible and adaptable than structured data, as it can accommodate changes in the data structure more easily.
