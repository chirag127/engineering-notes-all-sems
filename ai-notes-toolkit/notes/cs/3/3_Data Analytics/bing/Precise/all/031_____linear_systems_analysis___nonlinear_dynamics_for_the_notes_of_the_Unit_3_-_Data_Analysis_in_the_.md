### Linear Systems Analysis & Nonlinear Dynamics

#### Unit 3 - Data Analysis in the subject of Data Analytics

1. Linear dynamical systems can be solved exactly, in contrast to most nonlinear ones. Occasionally, a nonlinear system can be solved exactly by a change of variables to a linear system. Moreover, the solutions of (almost) any nonlinear system can be well-approximated by an equivalent linear system near its fixed points.

2. For linear analysis, all structural components are elastic, and only elastic properties are needed for analysis. For nonlinear analysis, some components can yield, and additional inelastic properties are needed for these components. These properties are more complicated than the elastic properties.

3. The fundamental knowledge of nonlinear analysis and control is essential to engineers for analyzing and controlling nonlinear instability phenomena.

4. Linear stability analysis of continuous-time nonlinear systems involves finding an equilibrium point of the system, calculating the Jacobian matrix of the system at the equilibrium point, calculating the eigenvalues of the Jacobian matrix, and determining the stability of the system based on the real part of the dominant eigenvalue.

5. Introduction to applied linear algebra and linear dynamical systems includes applications to circuits, signal processing, communications, and control systems. Topics include least-squares approximations of over-determined equations and least-norm solutions of underdetermined equations, symmetric matrices, matrix norm, and singular value decomposition.

6. Experimental technique and data analysis have seen such dramatic progress that, by now, most fundamental properties of nonlinear dynamical systems have been observed in the laboratory. Great efforts are being made to exploit ideas from chaos theory wherever the data displays more structure than can be captured by traditional methods.
