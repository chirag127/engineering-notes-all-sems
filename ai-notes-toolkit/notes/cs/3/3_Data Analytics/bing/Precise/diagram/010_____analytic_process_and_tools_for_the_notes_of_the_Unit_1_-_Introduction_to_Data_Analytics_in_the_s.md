### Unit 1 - Introduction to Data Analytics
#### Analytic Process and Tools

1. **Data Collection:** The first step in the analytic process is to collect data from various sources such as databases, spreadsheets, and text files.

2. **Data Preprocessing:** The collected data is then preprocessed to remove any inconsistencies, missing values, and outliers. This step is crucial as it ensures the quality of the data used for analysis.

3. **Data Exploration:** The preprocessed data is then explored using various techniques such as data visualization and descriptive statistics to gain insights and identify patterns.

4. **Data Analysis:** The next step is to analyze the data using various statistical and machine learning techniques to make predictions, identify relationships, and discover trends.

5. **Data Interpretation:** The results of the analysis are then interpreted to draw conclusions and make decisions.

6. **Data Visualization:** The final step is to present the results of the analysis using various visualization techniques such as charts, graphs, and tables.

Some of the popular tools used in the analytic process include:
- **R:** A programming language and software environment for statistical computing and graphics.
- **Python:** A high-level programming language widely used for data analysis and machine learning.
- **Excel:** A spreadsheet program used for data analysis and visualization.
- **Tableau:** A data visualization software used to create interactive dashboards and reports.
- **SAS:** A software suite used for advanced analytics, business intelligence, and data management.
