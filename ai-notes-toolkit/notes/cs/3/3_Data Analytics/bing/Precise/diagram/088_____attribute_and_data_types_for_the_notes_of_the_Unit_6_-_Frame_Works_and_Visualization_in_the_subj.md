### Unit 6 - Frame Works and Visualization in Data Analytics
#### Attributes and Data Types

- **Attributes** refer to the characteristics or features of data that can be measured or observed.
- **Data types** refer to the classification of data based on the type of values it can take.
- Common data types include:
  - **Numeric**: Data that represents numbers, such as integers or floating-point numbers.
  - **Categorical**: Data that represents categories or groups, such as gender or color.
  - **Ordinal**: Data that represents ordered categories, such as size (small, medium, large).
  - **Boolean**: Data that represents true or false values.
  - **Date/Time**: Data that represents dates or times.
- Different data types require different visualization techniques and frameworks to effectively represent the data.
- It is important to correctly identify the data type of each attribute in a dataset to ensure accurate analysis and visualization.
