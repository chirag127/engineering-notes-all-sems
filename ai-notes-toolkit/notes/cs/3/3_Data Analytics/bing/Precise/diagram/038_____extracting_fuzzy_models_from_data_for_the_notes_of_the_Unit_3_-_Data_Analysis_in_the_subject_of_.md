### Extracting Fuzzy Models from Data

1. Extracting fuzzy rules from data allows relationships in the data to be modeled by "if-then" rules that are easy to understand, verify, and extend .
2. Fuzzy rules can be extracted for both function approximation and pattern classification .
3. The rule extraction methods are based on estimating clusters in the data.
4. By extracting knowledge from fuzzy data models with fuzzy ontologies, it may facilitate the fuzzy ontology development and the information sharing in the context of the Semantic Web.
5. Extracting fuzzy rules from data can also act as a gap-bridge of the realization of semantic interoperations between the existing database applications and the Semantic Web.
