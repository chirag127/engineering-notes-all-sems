### Introduction to Streams Concepts

Unit 4 - Mining Data Streams in the subject of Data Analytics

1. A **data stream** is a continuous flow of data that is generated in real-time.
2. Data streams are often generated by sensors, social media, financial transactions, and other sources that produce data at a high rate.
3. The data in a stream is typically **unbounded**, meaning that there is no fixed end to the stream and data can continue to flow indefinitely.
4. **Stream processing** involves analyzing and processing data as it arrives in the stream, rather than storing it and processing it later.
5. Stream processing is useful for applications that require real-time analysis and decision-making, such as fraud detection, stock trading, and social media analysis.
6. **Stream mining** is the process of extracting useful information and knowledge from data streams.
7. Stream mining algorithms must be able to handle the high volume and velocity of data in streams, and must be able to adapt to changes in the data over time.
8. Common techniques used in stream mining include **classification**, **clustering**, **frequent pattern mining**, and **anomaly detection**.
9. Stream mining is a challenging task due to the **dynamic nature** of data streams and the need for **real-time processing**.
