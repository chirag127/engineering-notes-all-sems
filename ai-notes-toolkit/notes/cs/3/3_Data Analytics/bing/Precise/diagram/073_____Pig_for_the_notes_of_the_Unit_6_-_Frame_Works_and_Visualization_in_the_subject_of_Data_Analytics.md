### Unit 6 - Frame Works and Visualization in Data Analytics: Pig

1. Pig is a high-level platform for creating MapReduce programs used with Hadoop.
2. It is designed to handle any kind of data, making it well-suited for data analysis tasks.
3. Pig consists of a language called Pig Latin, which is used to express data analysis programs.
4. Pig Latin is a procedural language, where users specify a sequence of data transformations to be performed.
5. Pig programs can be run in two modes: local mode and MapReduce mode.
6. In local mode, Pig runs on a single machine, while in MapReduce mode, Pig programs are translated into MapReduce jobs and executed on a Hadoop cluster.
7. Pig provides many built-in functions for common data analysis tasks, such as filtering, grouping, and joining data.
8. Users can also create their own custom functions using languages such as Java, Python, and Ruby.
9. Pig can be used interactively through the Grunt shell, or Pig scripts can be saved and run as batch jobs.
10. Pig is widely used in industry for data analysis tasks, and has a large and active community of users and developers.
