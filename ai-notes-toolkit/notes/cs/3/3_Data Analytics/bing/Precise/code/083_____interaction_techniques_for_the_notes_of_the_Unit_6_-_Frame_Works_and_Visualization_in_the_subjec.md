### Interaction Techniques for Unit 6 - Frameworks and Visualization in Data Analytics

1. **Brushing and Linking**: This technique allows the user to highlight or select data points in one visualization, and see the corresponding data points highlighted in other visualizations.
2. **Dynamic Queries**: This technique allows the user to interactively filter data by adjusting sliders or other input controls, and see the results update in real-time.
3. **Focus + Context**: This technique provides a detailed view of a specific area of the data, while still showing the overall context of the data.
4. **Overview + Detail**: This technique provides an overview of the entire data set, along with a detailed view of a specific area of the data.
5. **Zooming and Panning**: This technique allows the user to zoom in and out of the data, and pan around to explore different areas of the data.
6. **Coordinated Multiple Views**: This technique provides multiple coordinated views of the data, allowing the user to explore the data from different perspectives.
