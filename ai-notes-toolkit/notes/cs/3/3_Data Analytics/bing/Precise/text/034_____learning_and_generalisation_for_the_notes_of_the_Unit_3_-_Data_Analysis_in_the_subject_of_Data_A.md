### Learning and Generalisation

- **Learning** refers to the process of acquiring knowledge or skills through experience, study, or instruction.
- In the context of data analysis, learning often involves using data to build a model that can make predictions or decisions.
- **Generalisation** refers to the ability of a model to perform well on new, unseen data.
- A model that generalises well is able to make accurate predictions or decisions even when presented with data that it has not seen before.
- To achieve good generalisation, it is important to use appropriate techniques to prevent overfitting, such as cross-validation and regularisation.
- Overfitting occurs when a model is too complex and fits the training data too closely, resulting in poor performance on new data.
- Cross-validation involves dividing the data into multiple subsets and using some of these subsets for training and others for validation.
- Regularisation involves adding a penalty term to the loss function to encourage the model to have small weights, which can help prevent overfitting.
- In summary, learning and generalisation are important concepts in data analysis, and techniques such as cross-validation and regularisation can help improve the generalisation performance of a model.
