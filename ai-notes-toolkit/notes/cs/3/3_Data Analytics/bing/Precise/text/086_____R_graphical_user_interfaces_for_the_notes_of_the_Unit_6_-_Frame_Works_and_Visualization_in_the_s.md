### R Graphical User Interfaces

- R is a command line driven program. The user enters commands at the prompt (> by default) and each command is executed one at a time .
- There are several major R packages for GUI programming: RGtk2, qtbase, Tcl/Tk, and gWidgets .
- RStudio is the most famous IDE and GUI for R .
- Rattle is a popular free graphical user interface for R, well approached for its extensive data mining use .
- StatET for R is another free GUI for R .
- The R code used in GUIs should be visible and any R code should be able to be used .
