### Systems and Applications

Unit 6 - Frame Works and Visualization in the subject of Data Analytics covers the following topics:

1. **Frameworks**: Frameworks are software libraries that provide a structure for building applications. They can help developers save time and effort by providing pre-built components and functionalities. Some popular frameworks for data analytics include Apache Hadoop, Apache Spark, and TensorFlow.

2. **Visualization**: Visualization is the process of representing data in a graphical or visual format. It can help users understand and analyze data more easily. Some popular visualization tools for data analytics include Tableau, QlikView, and Microsoft Power BI.

3. **Applications**: Data analytics has many applications in various industries, including finance, healthcare, and marketing. Some common applications of data analytics include customer segmentation, fraud detection, and predictive maintenance.
