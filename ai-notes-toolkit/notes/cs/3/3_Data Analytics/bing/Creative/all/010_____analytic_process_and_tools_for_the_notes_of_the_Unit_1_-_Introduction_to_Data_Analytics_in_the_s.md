# Analytic Process and Tools

## Definition

- Analytic process is a systematic approach to identify, collect, analyze, and interpret data to support decision making and problem solving in various domains .
- Analytic tools are software applications or platforms that enable data analysis and visualization, such as Microsoft Power BI, Tableau, Qlik Sense, Looker, etc.

## Steps of Analytic Process

- The analytic process typically involves the following steps :
  - Define the problem or objective: What is the question or goal of the analysis? What are the expected outcomes or deliverables?
  - Identify and collect data: What are the sources and types of data needed for the analysis? How will the data be acquired, stored, and validated?
  - Analyze data: What are the methods and techniques to explore, transform, and model the data? How will the data be cleaned, integrated, and summarized?
  - Interpret and communicate results: What are the key findings and insights from the data analysis? How will the results be presented and communicated to the stakeholders?
  - Implement and monitor actions: What are the recommendations and actions based on the data analysis? How will the actions be implemented and monitored for effectiveness and impact?

## Types of Analytic Tools

- There are various types of analytic tools that can be used for different purposes and stages of the analytic process, such as  :
  - Process analysis tools: These tools help to understand and document the current or desired state of a process, such as flowcharts, process maps, written procedures, work instructions, etc.
  - Data analysis tools: These tools help to manipulate and explore the data, such as spreadsheets, databases, statistical software, programming languages, etc.
  - Data visualization tools: These tools help to create and display graphical representations of the data, such as charts, graphs, dashboards, maps, etc.
  - Business intelligence tools: These tools help to integrate and analyze data from multiple sources, such as data warehouses, data lakes, online analytical processing (OLAP), etc.
  - Machine learning tools: These tools help to apply artificial intelligence and algorithms to learn from the data and make predictions, such as neural networks, decision trees, clustering, etc.
  - Reporting and communication tools: These tools help to generate and share reports and documents based on the data analysis, such as word processors, presentation software, email, etc.
