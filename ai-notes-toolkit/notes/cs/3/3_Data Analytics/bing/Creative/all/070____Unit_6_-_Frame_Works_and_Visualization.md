## Unit 6 - Frameworks and Visualization

- In this unit, you will learn about some of the popular frameworks and tools for data analysis and visualization in Python.
- A framework is a collection of libraries, modules, and packages that provide a common structure and functionality for a specific domain or task.
- A visualization is a graphical representation of data or information that helps to communicate insights, patterns, trends, or relationships.
- Some of the frameworks and tools you will learn in this unit are:

  - Pandas: A framework for data manipulation and analysis that provides high-performance data structures and operations for working with tabular and multidimensional data.
  - Matplotlib: A library for creating static, animated, and interactive visualizations in Python that supports a variety of plots, styles, and backends.
  - Seaborn: A library for statistical data visualization that builds on top of Matplotlib and integrates with Pandas, providing high-level functions and aesthetics for exploring and presenting data.
  - Plotly: A library for interactive data visualization that enables creating and sharing web-based plots and dashboards, supporting multiple languages and platforms.
  - Dash: A framework for building web applications for data analysis and visualization that uses Plotly for the front-end and Flask for the back-end, allowing users to create interactive user interfaces with Python code.
  - Bokeh: A library for interactive data visualization that targets modern web browsers, providing high-level functions and widgets for creating dynamic and interactive plots and dashboards.
  - Altair: A library for declarative data visualization that uses the Vega-Lite grammar, a JSON-based specification for describing visualizations, allowing users to create charts with a simple and concise syntax.
