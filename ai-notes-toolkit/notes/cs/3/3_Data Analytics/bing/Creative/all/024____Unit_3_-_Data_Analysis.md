## Unit 3 - Data Analysis

Data analysis is the process of collecting, organizing, exploring, and interpreting data to answer questions, test hypotheses, and draw conclusions. Data analysis can be done using various methods, tools, and techniques, depending on the type, source, and purpose of the data.

Some of the topics covered in this unit are:

- **Data types and sources**: Data can be classified into different types, such as categorical, numerical, ordinal, or interval, based on the nature and level of measurement of the data. Data can also come from different sources, such as surveys, experiments, observations, or secondary sources.
- **Data visualization**: Data visualization is the use of graphical representations, such as charts, graphs, maps, or diagrams, to display and communicate data. Data visualization can help to explore the patterns, trends, outliers, and relationships in the data, as well as to present the findings and insights to the audience.
- **Descriptive statistics**: Descriptive statistics are numerical or graphical summaries that describe the main features of a data set, such as the center, spread, shape, and variability of the data. Some of the common descriptive statistics are mean, median, mode, range, standard deviation, variance, frequency, and percentiles.
- **Inferential statistics**: Inferential statistics are methods that use sample data to make generalizations or predictions about a population or a phenomenon of interest. Some of the common inferential statistics are confidence intervals, hypothesis testing, correlation, and regression.
- **Data analysis tools**: Data analysis tools are software applications or programs that help to perform data analysis tasks, such as data cleaning, manipulation, transformation, visualization, and modeling. Some of the popular data analysis tools are Excel, R, Python, SPSS, SAS, and Tableau.
