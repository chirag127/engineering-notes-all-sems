# Stream Computing

Stream computing is a programming paradigm that deals with data streams, or sequences of events in time, as the central input and output objects of computation. Stream computing enables organizations to process data streams that are always on and never ceasing, and to analyze the data in real time as it streams in to increase speed and accuracy when dealing with data handling and analysis .

Some of the topics that are covered in stream computing are:

- Stream processing platforms: These are software systems that provide the infrastructure and tools for developing and executing stream processing applications. Stream processing platforms typically support features such as parallel and distributed processing, fault tolerance, scalability, load balancing, state management, windowing, and stream analytics.
- Stream processing applications: These are software applications that use stream processing platforms to perform specific tasks on data streams, such as filtering, transformation, aggregation, correlation, pattern matching, anomaly detection, and complex event processing. Stream processing applications can be used for various domains, such as finance, health care, security, social media, and internet of things.
- Stream analytics: These are techniques and methods for extracting insights and knowledge from data streams, such as descriptive, predictive, and prescriptive analytics. Stream analytics can help organizations spot opportunities and risks across all data sources, and make timely and informed decisions based on the current and historical data.
