# Filtering Streams

- Filtering streams is a process of selecting a subset of data from a continuous stream of events based on some criteria.
- Filtering streams can be useful for reducing the volume of data, removing noise or irrelevant data, or focusing on a specific aspect of the data.
- Filtering streams can be done in different ways, such as using SQL-like queries, geospatial functions, machine learning models, or custom code.
- Filtering streams can be applied to various data sources, such as event hubs, IoT devices, social media, sensors, or web logs.
- Filtering streams can be integrated with various data sinks, such as data lakes, data warehouses, data explorers, or dashboards.
- Filtering streams can be implemented using various tools and platforms, such as Azure Stream Analytics, Google Analytics 4, Apache Spark, or Apache Flink.

Some examples of filtering streams are:

- Filtering and ingesting real time data from Azure Event Hubs to Azure Data Explorer using the Stream Analytics no-code solution .
- Filtering, reporting on, or restricting access to data subsets in Google Analytics 4 using the property-level filters.
- Filtering and ingesting real time data from Azure Event Hubs to Azure Data Lake Storage Gen2 using the Stream Analytics no-code solution.
- Filtering and analyzing geospatial data from IoT devices using the built-in geospatial functions in Azure Stream Analytics.
