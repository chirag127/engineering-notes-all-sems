### Learning and Generalisation for the Notes of the Unit 3 - Data Analysis in the Subject of Data Analytics

- Learning is the process of finding patterns or relationships in data that can be used to make predictions or classifications.
- Generalisation is the ability of a model to perform well on new data that was not used for training or validation .
- Learning and generalisation are closely related, as the goal of learning is to produce a model that can generalise well to unseen data.
- Some factors that affect learning and generalisation are:
  - The size and quality of the data set: more data can help the model learn more complex patterns, but the data should also be relevant, representative, and free of errors or noise.
  - The complexity and flexibility of the model: more complex models can capture more nuances in the data, but they can also overfit to the training data and fail to generalise well. Overfitting is when the model learns the specific details or noise in the data, rather than the underlying patterns or relationships.
  - The choice of the learning algorithm and the hyperparameters: different algorithms have different strengths and weaknesses, and the hyperparameters control how the algorithm learns from the data. Hyperparameters are the parameters that are not learned by the model, but are set by the user, such as the learning rate, the number of iterations, or the regularization term.
  - The evaluation and validation methods: the model should be evaluated and validated on a separate data set that is not used for training, called the holdout or test set. This can help measure the generalisation performance of the model and avoid overfitting to the training data. However, reusing the holdout set multiple times can also lead to overfitting to the holdout set itself, as the model can adapt to the specific characteristics of the holdout set.
- Some techniques that can improve learning and generalisation are:
  - Data preprocessing: this involves transforming, cleaning, or augmenting the data to make it more suitable for learning. For example, data preprocessing can include scaling, normalising, encoding, imputing, or adding noise to the data.
  - Data splitting: this involves dividing the data into three subsets: training, validation, and test. The training set is used to fit the model, the validation set is used to tune the hyperparameters, and the test set is used to evaluate the final model.
  - Cross-validation: this involves splitting the data into k folds, and using one fold as the validation set and the rest as the training set. This is repeated k times, and the average validation performance is used to select the best model. Cross-validation can help reduce the variance of the validation error and make better use of the data.
  - Regularization: this involves adding a penalty term to the loss function that reduces the complexity or flexibility of the model. For example, regularization can include L1 or L2 norms, dropout, or early stopping. Regularization can help prevent overfitting and improve generalisation.
  - Data generalisation: this involves creating a more abstract or coarse representation of the data, such as grouping, binning, or clustering. Data generalisation can help reduce the dimensionality or variability of the data, and make it easier for the model to learn the essential features or patterns.
