# Learning and Generalization for the Notes of the Unit 3 - Data Analysis in the Subject of Data Analytics

- Learning analytics is the collection and analysis of data about learners and their environments for the purpose of understanding and improving learning outcomes.
- Machine learning is a subset of learning analytics that focuses on creating models that can learn from data and make predictions or decisions.
- Generalization is the ability of a machine learning model to perform well on new data that was not used for training or validation.
- Overfitting is the problem of a machine learning model that learns too much from the training data and fails to generalize to new data.
- Regularization is a technique to prevent overfitting by adding a penalty term to the model complexity or reducing the number of features or parameters.
- Bias is the difference between the expected prediction of a model and the true value of the target variable.
- Variance is the variability of the model prediction for a given data point.
- Bias-variance trade-off is the balance between having a simple model that has high bias and low variance, and a complex model that has low bias and high variance.
- Adaptive data analysis is the process of using the same data for multiple analyses, which can lead to overfitting and false discoveries.
- Holdout reuse is the practice of using the same data for both model selection and evaluation, which can also cause overfitting and invalid generalization.
- Data generalization is the process of creating a more broad categorization of data in a database, which can help to protect privacy and reduce noise.
