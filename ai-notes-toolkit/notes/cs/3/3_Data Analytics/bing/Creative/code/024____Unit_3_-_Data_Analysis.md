## Unit 3 - Data Analysis

Data analysis is the process of collecting, organizing, exploring, and interpreting data to answer questions, solve problems, or make decisions. Data analysis can be done using various methods, tools, and techniques, depending on the type, source, and purpose of the data.

Some of the topics covered in this unit are:

- Data types and sources: Data can be classified into different types, such as numerical, categorical, ordinal, or nominal, depending on the nature and level of measurement of the data. Data can also come from different sources, such as surveys, experiments, observations, or secondary sources, depending on the research design and objectives.
- Data visualization: Data visualization is the use of graphical representations, such as charts, graphs, maps, or tables, to display and communicate data. Data visualization can help to summarize, explore, and compare data, as well as to identify patterns, trends, outliers, or relationships in the data.
- Descriptive statistics: Descriptive statistics are numerical measures that describe the main features of a data set, such as the center, spread, shape, or distribution of the data. Some common descriptive statistics are mean, median, mode, range, standard deviation, variance, quartiles, percentiles, frequency, relative frequency, histograms, box plots, and scatter plots.
- Inferential statistics: Inferential statistics are methods that use sample data to make generalizations or predictions about a population or a parameter of interest. Some common inferential statistics are confidence intervals, hypothesis testing, correlation, regression, and ANOVA.
- Data analysis tools: Data analysis tools are software applications or programs that help to perform data analysis tasks, such as data entry, data cleaning, data manipulation, data visualization, data modeling, data interpretation, and data presentation. Some examples of data analysis tools are Excel, SPSS, R, Python, and Tableau.
