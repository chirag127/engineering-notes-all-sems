### Hadoop Distributed File System

- Hadoop Distributed File System (HDFS) is the primary data storage system used by Hadoop applications.
- HDFS is a distributed file system that provides high-throughput access to data across highly scalable Hadoop clusters  .
- HDFS splits files into large blocks and distributes them across nodes in a cluster. It then transfers packaged code into nodes to process the data in parallel.
- HDFS is designed to handle large data sets running on commodity hardware, and to scale to hundreds or thousands of nodes.
- HDFS has a master-slave architecture, where a NameNode manages the file system metadata and DataNodes store the actual data.
- HDFS provides fault tolerance, data replication, data locality, and high availability features.
