## Unit 1 - Introduction to Data Analytics

- Data analytics is the process of collecting, organizing, analyzing, and interpreting data to gain insights and support decision making.
- Data analytics can be applied to various domains, such as business, science, engineering, health, education, and social sciences.
- Data analytics can be classified into four types, depending on the purpose and complexity of the analysis:
  - Descriptive analytics: summarizes what has happened in the past using historical data.
  - Diagnostic analytics: explains why something has happened in the past using statistical techniques.
  - Predictive analytics: forecasts what is likely to happen in the future using mathematical models.
  - Prescriptive analytics: recommends what actions should be taken in the future using optimization and simulation methods.
- Data analytics can be performed using various tools and techniques, such as spreadsheets, databases, programming languages, statistical software, machine learning, data visualization, and data storytelling.
- Data analytics requires a combination of skills, such as data literacy, analytical thinking, problem solving, communication, and domain knowledge.
