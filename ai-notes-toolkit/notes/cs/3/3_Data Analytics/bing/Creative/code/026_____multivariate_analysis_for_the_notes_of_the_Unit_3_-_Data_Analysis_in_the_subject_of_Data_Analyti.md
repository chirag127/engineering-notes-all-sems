# Multivariate Analysis

- Multivariate analysis (MVA) is a method of gathering multiple sets of data and drawing cause-and-effect conclusions about their constituent parts.
- MVA is based on the principles of multivariate statistics, which deals with the analysis of data that have more than one variable or outcome.
- MVA is used to address the situations where multiple measurements are made on each experimental unit and the relations among these measurements and their structures are important.
- MVA can help to identify patterns, trends, correlations, clusters, outliers, and interactions among the variables.
- MVA can also help to test hypotheses, compare groups, predict outcomes, and optimize solutions.
- MVA can be classified into two main types: multivariate dependence techniques and multivariate interdependence techniques.
- Multivariate dependence techniques are used when there is a clear distinction between dependent variables (also called response variables or outcomes) and independent variables (also called explanatory variables or predictors).
- Multivariate interdependence techniques are used when there is no clear distinction between dependent and independent variables, and the goal is to explore the relationships among all the variables.
- Some examples of multivariate dependence techniques are:
  - Multiple regression: used to measure the effect of multiple independent variables on one continuous dependent variable.
  - Multivariate analysis of variance (MANOVA): used to measure the effect of multiple independent variables on two or more continuous dependent variables.
  - Discriminant analysis: used to classify observations into two or more groups based on multiple independent variables.
  - Canonical correlation analysis: used to measure the correlation between two sets of multiple variables.
- Some examples of multivariate interdependence techniques are:
  - Principal component analysis (PCA): used to reduce the dimensionality of a large set of variables by creating new variables that capture most of the variance in the original variables.
  - Factor analysis: used to identify the underlying factors or latent variables that explain the common variance among a set of observed variables.
  - Cluster analysis: used to group observations into homogeneous and distinct clusters based on their similarity on multiple variables.
  - Multidimensional scaling (MDS): used to represent the distances or dissimilarities among a set of objects in a low-dimensional space.
