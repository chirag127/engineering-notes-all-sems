### Classification of Data for the Notes of Unit 1 - Introduction to Data Analytics

1. Quantitative Data: Data that is measurable and represented numerically is quantitative data. For example, height, weight, age, income, sales, etc. This data can be analyzed using statistical techniques.
2. Qualitative Data: Data that is descriptive and conceptual in nature is qualitative data. For example, color, gender, opinion, etc. This data is analyzed using techniques like coding and thematic analysis.
3. Discrete Data: Data that has a finite set of possible values is discrete data. For example, number of children, number of products purchased, etc. This data can only take on certain values (integers).
4. Continuous Data: Data that can take on any fractional value in a range is continuous data. For example, height, weight, temperature, etc. This data can take on any value.

The above points highlight the key ways in which data can be classified. Based on the classification, appropriate analytics techniques can be applied to derive insights from the data.
