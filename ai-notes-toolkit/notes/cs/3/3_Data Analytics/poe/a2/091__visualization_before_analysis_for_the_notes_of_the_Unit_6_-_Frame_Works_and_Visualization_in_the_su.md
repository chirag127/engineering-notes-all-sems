### Visualization before analysis

1. Visualization is an important step before diving into detailed analysis of the data. It helps in getting an overview of the data and identifying patterns, trends and outliers.
2. Some of the benefits of visualization are:
- Getting a sense of scale of data - Visualization helps in understanding the magnitude and scale of data. For example, a bar chart or a line chart can give an idea of the range of values and identify the max and min values.
- Spotting patterns - Visualization makes it easy to spot patterns, trends and clusters in the data. For example, a scatter plot may reveal a linear pattern or clusters of data points.
- Checking assumptions - Visualization is useful to check assumptions about the data and test hypotheses. For example, a histogram can be used to check if the data is normally distributed or not.
- Communicating insights - Visualization is a powerful way to communicate insights and findings to others as it is easy to understand and interpret.
3. Some common visualization techniques are bar charts, line charts, histograms, box plots, scatter plots, heat maps, etc. The choice of visualization technique depends on the type of data (categorical vs quantitative), number of variables and the insights we want to derive.
4. Visualization should be followed up with further analysis to derive meaningful insights and draw solid conclusions from the data. Visualization provides a starting point but detailed analysis is required for an in-depth understanding.
