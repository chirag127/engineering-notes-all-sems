### Semi-structured notes for Unit 1 - Introduction to Data Analytics

1. Data Analytics - The process of examining data and identifying patterns to make better decisions. It involves applying an analytical process to raw data to derive insights and reach conclusions.
2. Types of Data - There are 3 types of data:
	- Structured data - Data that is organized in a fixed format like database tables, spreadsheet files, etc. e.g. Customer records, Sales data.
	- Unstructured data - Data that does not have a fixed format. e.g. Text, Audio, Images, Videos.
	- Semi-structured data - Data that has a loose structure like XML and JSON files. e.g. Log files, CSV files.
3. Steps in the Data Analytics Process - The major steps involved in the data analytics process are:
	1. Understanding the Business Objective
	2. Obtaining and Understanding the Data
	3. Preparing the Data
	4. Exploring and Visualizing the Data
	5. Building Models
	6. Evaluating and Optimizing
	7. Deploying and Monitoring
4. Tools and Technologies - Some of the tools and technologies used in Data Analytics are:
	- Python and R for data analysis and visualization
	- SQL for querying data
	- Hadoop and Spark for big data processing
	- Tableau and Power BI for data visualization
	- SAS and SPSS for statistical analysis
	- MongoDB and Cassandra for document and wide-column data storage
