### MapReduce for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics

1. MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
2. It consists of two major tasks - Map and Reduce.
3. The map task divides the input into smaller sub-problems, which are then solved in parallel by the map tasks.
4. The reduce task aggregates the results of the map tasks into a final output.
5. The map and reduce tasks are both distributed across multiple nodes in a cluster to achieve fast processing of very large data sets.
6. MapReduce allows for parallel processing of the map and reduction operations.
7. It is a scalable and fault-tolerant processing framework and is suited for processing large volume of data in distributed clusters of commodity machines.
8. MapReduce is an integral part of big data processing systems like Hadoop.
9. Some key characteristics of MapReduce are:
    - Scalable: It can scale to large clusters of machines.
    - Fault tolerant: It is tolerant to failures and can re-execute failed tasks.
    - Distributed: It distributes the computation across multiple machines.
10. Some applications of MapReduce are:
    - Counting frequencies of words in a document
    - Building inverted indexes
    - Data mining and machine learning algorithms
