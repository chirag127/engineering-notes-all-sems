### Systems and Applications for Unit 6 - Frameworks and Visualization

1. Data Visualization Libraries
- Matplotlib: Comprehensive library for creating static, animated, and interactive visualizations in Python. Used for basic plotting and can create publication-quality figures.
- Seaborn: Built on top of Matplotlib and provides a high-level interface for drawing attractive statistical graphics.
- Bokeh: Creates interactive plots, dashboards, and data applications that can be viewed in browsers. Supports large, streaming, and time-series data.
- Plotly: Used to create interactive web-based graphs online or on-premise. Can be used in Python, R, MATLAB, Excel, and other languages.

2. Data Visualization Frameworks
- Dash: Open-source framework for building analytical web applications in Python without JavaScript. Can create interactive, web-based dashboards and applications.
- Shiny: Package from R that makes it easy to build interactive web apps straight from R. Can host standalone apps on a webpage or embed them in R Markdown documents or build dashboards.
- Apache Superset: Data exploration and visualization web application. Provides rich visualizations, smart filters and aggregates, and customizable dashboards.

3. Other Tools
- Jupyter Notebooks: Web-based environment for interactive computing using Python, R, Julia, and Scala. Allows data cleaning and transformation, numerical simulation, statistical modeling, machine learning, and more.
- Tableau: Interactive data visualization software with a drag-and-drop interface. Allows you to easily connect to data, then visualize and create interactive, sharable dashboards.
- Power BI: Business analytics service by Microsoft for analyzing data and sharing insights. Has a simple drag-and-drop report authoring experience and includes connectors to many data sources.
