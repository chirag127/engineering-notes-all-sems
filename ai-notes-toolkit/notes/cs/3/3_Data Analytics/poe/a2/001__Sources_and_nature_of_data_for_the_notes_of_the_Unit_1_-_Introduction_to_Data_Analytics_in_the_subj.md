### Sources and nature of data for the notes of the Unit 1 - Introduction to Data Analytics in the subject of Data Analytics.

1.  Primary data: Data collected for a specific purpose. For example, surveys, experiments, observation, etc.
2.  Secondary data: Data collected for some other purpose but used for the current purpose. For example, census data, real estate data, retail data, etc.
3.  Qualitative data: Data involving descriptions, opinions, feelings, etc. For example, reviews, interviews, open-ended surveys, etc.
4.  Quantitative data: Data involving numbers and statistics. For example, sales data, ratings, demographic data, etc.
5.  Structured data: Data with a defined structure. For example, data in databases with defined columns.
6.  Unstructured data: Data with no defined structure. For example, emails, documents, audio, video, images, etc.
7.  Static data: Data that does not change with time. For example, geographic data.
8.  Dynamic data: Data that changes with time. For example, stock prices, sales data, etc.

The above points cover the key sources and nature of data relevant for the notes of the Unit 1 - Introduction to Data Analytics in the subject of Data Analytics. The data could be primary or secondary, qualitative or quantitative, structured or unstructured, static or dynamic. Different types of data are suitable for different types of analysis.
