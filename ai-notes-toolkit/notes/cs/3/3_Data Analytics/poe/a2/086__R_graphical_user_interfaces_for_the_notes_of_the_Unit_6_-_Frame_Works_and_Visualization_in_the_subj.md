### R graphical user interfaces for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics.

1. RStudio: RStudio is an integrated development environment (IDE) for R. It provides a console, syntax-highlighting editor that supports direct code execution, and tools for plotting, history, debugging and workspace management.
2. Shiny: Shiny is a web application framework for R. It makes it easy to build interactive web apps straight from R. You can host standalone apps on a webpage or embed them in R Markdown documents or build dashboards.
3. R Markdown: R Markdown is a file format for making dynamic documents with R. An R Markdown document is basically Markdown (an easy-to-write plain text format) with embedded R code chunks. You can render the document to many output formats including HTML, PDF, and Word files.
4. Tidyverse: The tidyverse is a set of R packages designed for data science. All packages share an underlying design philosophy, grammar, and data structures. The core packages (dplyr, tidyr, readr, purrr, and tibble) are designed to work together naturally, making common data tasks including filtering, sorting, mutating, and plotting fast and easy.
5. Plotly: Plotly's R package lets you make interactive plots, online dashboards, and web apps straight from R. Plotly uses JavaScript and the open-source D3.js library to visualize data interactively in any browser.
