### Real Time Sentiment Analysis for Notes of Unit 4 - Mining Data Streams

1. Sentiment analysis is the process of determining whether a piece of writing is positive, negative or neutral. It's used to analyze people's opinions, evaluations, attitudes, and emotions towards a topic.

2. Real-time sentiment analysis is sentiment analysis performed on data streams in real time. As data streams in, the sentiment is analyzed and results are obtained with minimal latency. This is important for applications like monitoring social media sentiment about a brand or product and taking immediate actions.

3. Some steps involved in real-time sentiment analysis:

a) Data collection: Data from sources like social media streams, customer reviews, etc. is collected in real time.

b) Data preprocessing: The data is preprocessed by steps like tokenization, removal of stopwords, punctuation, etc. to extract relevant words and phrases.

c) Feature extraction: Features are extracted from the preprocessed data to capture sentiment like occurrence of positive or negative words, emoticon usage, capitalization, etc.

d) Model application: A sentiment analysis model is applied on the features to predict sentiment as positive, negative or neutral.

e) Visualization: The results are visualized in real time to monitor sentiment trends.

4. Some techniques used for real-time sentiment analysis:

a) Rule-based approach: Sentiment is determined using handcrafted rules based on occurrences of positive or negative words.

b) Machine learning approach: Machine learning models like Naive Bayes, SVM, LSTM, etc. are trained on labeled data to learn sentiment patterns and predict sentiment of new data.

c) Deep learning approach: Deep neural networks are used to automatically learn complex patterns in language to predict sentiment. They often provide the best results but require large amounts of data and computing power.
