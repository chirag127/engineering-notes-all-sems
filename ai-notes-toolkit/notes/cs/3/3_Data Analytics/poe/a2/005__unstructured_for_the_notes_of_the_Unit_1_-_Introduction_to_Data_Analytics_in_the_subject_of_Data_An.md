### Unstructured Notes for Unit 1 - Introduction to Data Analytics

1. Data Analytics - Data analytics is the process of examining data and patterns to discover useful information and insights to help make better decisions. It involves applying an analytical process to raw data in order to extract insights and make predictions.

2. Types of Data - There are three types of data:

a. Structured data - Data that has a defined length, format and structure such as numbers, dates, strings, etc. Examples: Excel sheets, Databases.

b. Semi-structured data - Data that has some structure but is not strictly defined such as XML, JSON, etc. Examples: Logs, XML files.

c. Unstructured data - Data that has no defined structure such as text, media, etc. Examples: Word documents, PDFs, Images, Videos, Audio files.

3. Data Collection Methods - There are three main methods to collect data:

a. Experiment - Controlled observation to measure the effect of a variable.

b. Survey - Asking people questions to gather information.

c. Observation - Recording patterns of behavior, events or outcomes.

4. Analyzing Data - The steps to analyze data are:

a. Ask questions and define objectives

b. Prepare and organize data

c. Exploratory Data Analysis (EDA) - Plot distributions, find patterns, check missing values, etc.

d. Data Modeling - Apply machine learning algorithms and statistical methods to find relationships and insights.

e. Evaluate and interpret results - Assess accuracy and significance of results and take actions.
