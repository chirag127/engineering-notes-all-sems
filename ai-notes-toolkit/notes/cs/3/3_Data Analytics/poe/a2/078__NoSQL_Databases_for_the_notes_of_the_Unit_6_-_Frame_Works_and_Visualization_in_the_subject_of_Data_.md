### NoSQL Databases

1. NoSQL databases are non-relational databases. They have a simple design, distributed, open-source, and horizontally scalable.
2. The data in NoSQL databases is stored in many ways like:
- Key-value pair: Data is stored in an array of key-value pairs. Example: DynamoDB
- Document: Data is stored in documents (instead of rows & columns in a table). Example: MongoDB and CouchDB
- Graph: Data is stored in nodes, properties, and lines. Example: Neo4J and JanusGraph
- Wide-column: Data is stored in columns instead of rows. Example: Cassandra and HBase
3. Advantages of NoSQL:
- Scales easily with large amounts of data
- Schema-less: No need to define schema initially
- Distributed: Spread data across multiple servers
- Open source and has a simple architecture
4. Use cases:
- Storing geospatial data
- Storing graphs and relationships
- Content management systems
- E-commerce applications
- Mobile and web applications with huge user load
