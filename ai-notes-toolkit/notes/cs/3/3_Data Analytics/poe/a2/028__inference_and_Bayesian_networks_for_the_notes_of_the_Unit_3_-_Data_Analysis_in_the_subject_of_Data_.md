### Inference and Bayesian Networks

1. Inference: Drawing conclusions from given data or evidence. Inference is used to determine the probability of an event, given that another event has occurred.
2. Bayesian Networks: A probabilistic graphical model that represents a set of random variables and their conditional dependencies via a directed acyclic graph (DAG). The nodes represent variables and the edges represent conditional dependencies.
3. Components of a Bayesian Network:
    - Directed Acyclic Graph (DAG): The structure of the Bayesian Network showing the relationships between variables.
    - Conditional Probability Tables (CPTs): The probabilities associated with each variable given its parents in the DAG.
4. Advantages of Bayesian Networks:
    - Handle uncertainty and missing data.
    - Compactly represent complex relationships.
    - Support probabilistic reasoning and inference.
    - Modular and flexible.
5. Inference in Bayesian Networks:
    - Query: What is the probability of a subset of variables given evidence on other variables?
    - Exact Inference: Using junction tree algorithm to get the exact probability values.
    - Approximate Inference: Using sampling methods to get approximate probability values when exact inference is infeasible. Examples: Markov Chain Monte Carlo (MCMC), Variational Bayesian Methods.
