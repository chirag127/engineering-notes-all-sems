### Unit 1 - Introduction to Data Analytics

1. What is Data Analytics?
- Data Analytics is the process of examining data and identifying patterns to discover useful information and insights to help in decision making.
- It involves applying analytical techniques and tools to raw data and converting it into meaningful information.
- The ultimate goal is to discover hidden patterns and new insights to make better decisions.

2. Why Data Analytics?
- Data is being generated at an exponential rate in today's world. This data contains hidden insights and information which when uncovered can provide a competitive advantage.
- Data Analytics helps in uncovering these insights to gain business value and enable data-driven decisions.
- It helps in improving processes, discovering new opportunities, personalized experiences, cost reduction, etc. thus increasing revenue and growth.

3. The Data Analytics Process
- The key steps involved in the Data Analytics process are:
-- Data Collection: Gathering relevant data from various sources
-- Data Preparation: Cleaning and organizing the data
-- Data Exploration: Analyzing the data to find patterns and insights
-- Modeling: Building models to analyze data and evaluate variables
-- Interpretation: Interpreting the results and insights obtained
-- Decision Making: Using the insights to make better decisions

4. Tools and Techniques
- Some of the tools and techniques used in Data Analytics include:
-- Data Visualization: To explore and understand data through graphs, charts, etc.
-- Statistics: To analyze data and evaluate variables using statistical techniques
-- Machine Learning: To build models that can learn and make predictions from data
-- Data Mining: To extract hidden patterns and relationships from large data sets
-- Programming Languages: To implement various analytics techniques and tools
