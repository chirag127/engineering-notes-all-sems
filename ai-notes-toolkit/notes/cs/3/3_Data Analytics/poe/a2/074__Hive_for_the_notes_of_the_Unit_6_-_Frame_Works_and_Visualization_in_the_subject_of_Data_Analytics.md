### Hive for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics.

1. Hive is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis.
2. It converts structured data into Hive tables. These tables are stored in HDFS.
3. It provides SQL-like queries (HiveQL) to query data in Hive tables.
4. HiveQL queries are converted into MapReduce jobs which are executed on Hadoop.
5. Hive supports data formats like CSV, JSON, ORC, Parquet, RCFile, SequenceFile, and TextFile.
6. Hive provides tools like Hive Thrift Server and Hive WebHCat Server for remotely accessing Hive.
7. Key components of Hive are Metastore, Driver, Compiler, and Executor.
8. Some key benefits of Hive are its simplicity, scalability, and cost-effectiveness.
9. However, Hive has some disadvantages too like inefficiency for low-latency queries, lack of robust security features, and extra processing overhead.
