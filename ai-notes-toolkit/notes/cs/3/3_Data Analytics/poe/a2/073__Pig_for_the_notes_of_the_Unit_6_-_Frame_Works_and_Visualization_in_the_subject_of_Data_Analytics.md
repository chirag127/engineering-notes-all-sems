### Pig for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics

1. Pig is a high-level scripting language and a platform-independent framework for analyzing large data sets.

2. Pig Latin is the programming language used to write Pig scripts. Pig Latin gets compiled into map/reduce and Apache Tez jobs which are executed on the cluster.

3. Pig excels at describing data analysis problems as multistep data flows and handles all the complex details of scheduling and executing map/reduce and Tez jobs to get the desired results.

4. Some of the advantages of Pig are:

- It is easy to learn, read and write for beginners. The syntax is similar to SQL so it is easy to understand for those with SQL experience.
- It can handle any kind of data without the need for programming to define complex structures.
- It enables parallel processing of data.
- It provides User Defined Functions(UDFs) to define our own functions for processing data.
- It shields the user from the complexity of map/reduce programming and Apache Tez execution engine.

5. Some of the limitations of Pig are:

- It may not be suitable for low latency queries.
- The performance cannot be tuned as well as handwritten map/reduce programs.
- It may not be suitable for queries that need iterative processing.
- The performance can degrade if UDFs are not properly optimized.
