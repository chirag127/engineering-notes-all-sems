
### Classification of Data 

1. **Nominal Data**: This type of data is used to categorize objects, people, or events. It is usually represented by names, labels, or categories. Examples include gender, nationality, and product type. 

2. **Ordinal Data**: This type of data is used to rank objects, people, or events. It is usually represented by numbers, such as 1st, 2nd, 3rd, etc. Examples include student grades and rankings. 

3. **Interval Data**: This type of data is used to measure the difference between objects, people, or events. It is usually represented by numbers, such as temperatures or dates. Examples include temperature and time.

4. **Ratio Data**: This type of data is used to measure the ratio between objects, people, or events. It is usually represented by numbers, such as weights or lengths. Examples include weight and height.
