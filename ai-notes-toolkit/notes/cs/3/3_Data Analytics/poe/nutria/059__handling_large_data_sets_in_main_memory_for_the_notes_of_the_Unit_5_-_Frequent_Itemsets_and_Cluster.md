
### Handling Large Data Sets in Main Memory for Unit 5 - Frequent Itemsets and Clustering in Data Analytics

1. Data sets that are too large to fit into main memory can be handled using out-of-core algorithms. 
2. Out-of-core algorithms are designed to process data sets that are too large to fit into main memory. 
3. Out-of-core algorithms are divided into two categories: streaming algorithms and external memory algorithms. 
4. Streaming algorithms process data one item at a time, while external memory algorithms process data in blocks. 
5. In order to use streaming algorithms, the data must be sorted by the attribute that is being processed. 
6. External memory algorithms are more efficient than streaming algorithms, but require more memory and time for pre-processing. 
7. Frequent itemset mining is a data mining task that is used to find items that frequently occur together in a given dataset. 
8. The most common algorithm for frequent itemset mining is the Apriori algorithm. 
9. The Apriori algorithm uses a bottom-up approach to find frequent itemsets by generating candidate itemsets and then pruning them. 
10. Clustering is a data mining task that is used to group data points into clusters based on their similarity. 
11. K-means clustering is a popular clustering algorithm that is used to partition data points into k clusters. 
12. K-means clustering works by randomly selecting k initial cluster centers and then iteratively assigning data points to the closest cluster center and updating the cluster centers.
