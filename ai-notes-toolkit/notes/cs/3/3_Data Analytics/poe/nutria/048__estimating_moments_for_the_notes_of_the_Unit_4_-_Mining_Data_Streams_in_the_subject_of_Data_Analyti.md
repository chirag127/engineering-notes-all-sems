
### Estimating Moments for the Notes of the Unit 4 - Mining Data Streams in the Subject of Data Analytics

1. Estimating moments is a key concept in data analytics that helps to determine the characteristics of a data set.
2. The most commonly used moments are the mean, median, and mode.
3. The mean is the arithmetic average of a set of data points.
4. The median is the middle value in a set of data points.
5. The mode is the most common value in a set of data points.
6. Estimating moments can also be used to determine the skewness and kurtosis of a data set.
7. Skewness is a measure of the asymmetry of a data set, while kurtosis is a measure of the peakedness of a data set.
8. In mining data streams, estimating moments can be used to identify patterns and trends in the data.
9. Estimating moments can also be used to detect anomalies in data streams, as well as to detect changes in the distribution of the data.
10. Estimating moments can help to identify correlations between different data points, as well as to identify clusters of data points.
