
### Decay Window

Decay window is a technique used in data mining to identify and analyze data streams from a continuous source. It is used to identify patterns in the data stream and to detect changes over time.

- Decay window is a sliding window technique. It is used to analyze data streams over a period of time. 
- It works by keeping a window of data points and then discarding the oldest data point when a new data point is added.
- The size of the window is determined by the user. The larger the window, the more data points are included in the analysis.
- Decay window is used to identify patterns in the data stream and to detect changes over time.
- It is used to detect outliers in the data stream and to identify trends in the data.
- Decay window can be used to identify changes in the data stream over time. This can be used to detect anomalies in the data.
- Decay window can also be used to detect correlations between data points. This can help to identify relationships between different data points.
