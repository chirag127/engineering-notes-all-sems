
### R graphical user interfaces for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics

- R has a range of graphical user interfaces (GUIs) available for users to interact with.
- R Commander is a popular GUI for R. It is a menu-driven system that provides access to most of the features of R.
- RStudio is another popular GUI for R. It is an integrated development environment (IDE) with a range of features such as code completion, debugging, and visualisation.
- Shiny is a web application framework for R. It enables users to create interactive web applications with R.
- Plotly is a data visualisation library for R. It provides a range of interactive visualisations such as 3D plots, maps, and live graphs.
- ggplot2 is a data visualisation library for R. It provides a range of statistical visualisations such as scatter plots, histograms, and box plots.
