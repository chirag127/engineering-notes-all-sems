
### Visual Data Analysis Techniques for Unit 6 - Frameworks and Visualization in Data Analytics

1. Exploratory Data Analysis (EDA): EDA is a technique used to explore and understand the data, identify patterns, and uncover relationships between different variables. It is an iterative process that involves visualizing data, summarizing its characteristics, and testing hypotheses.

2. Data Visualization: Data visualization is the process of creating visual representations of data using charts, graphs, and other visuals. It is an effective way to communicate complex information in an easy-to-understand format.

3. Machine Learning: Machine learning is a type of artificial intelligence that uses algorithms to learn from data and make predictions. It can be used to uncover patterns in data and make predictions about future events.

4. Statistical Analysis: Statistical analysis is the process of collecting, organizing, and analyzing data to identify trends and draw conclusions. It is used to understand the relationships between different variables and make predictions about future events.

5. Data Mining: Data mining is the process of extracting useful information from large amounts of data. It involves using algorithms to identify patterns and relationships in data and draw conclusions from them.
