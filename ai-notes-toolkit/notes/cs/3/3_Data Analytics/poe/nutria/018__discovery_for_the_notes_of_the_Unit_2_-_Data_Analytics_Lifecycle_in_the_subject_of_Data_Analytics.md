
### Discovery for the Notes of the Unit 2 - Data Analytics Lifecycle in the Subject of Data Analytics

1. Discovery is a process of understanding the problem and exploring the data to identify the best approach to solve the problem.
2. This process includes activities such as data collection, data exploration, data cleaning, and data pre-processing.
3. Data exploration involves analyzing the data to understand the characteristics of the data, identify patterns, and identify potential problems.
4. Data cleaning involves removing or correcting invalid or missing data values.
5. Data pre-processing involves transforming the data into a format that is more suitable for analysis.
6. The data analytics lifecycle includes the steps of data discovery, data analysis, data modeling, and data visualization.
7. The goal of the data analytics lifecycle is to use data to gain insights that can be used to make decisions and improve processes.
