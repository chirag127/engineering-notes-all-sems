
### Limited Pass Algorithm

- Limited Pass Algorithm is a type of clustering algorithm used to identify frequent itemsets in a dataset. 
- The algorithm works by scanning the dataset multiple times and counting the number of occurrences of each itemset. 
- The algorithm has two main parameters: the minimum support threshold and the maximum number of passes. 
- The minimum support threshold specifies the minimum number of times an itemset must appear in the dataset in order to be considered a frequent itemset. 
- The maximum number of passes specifies the maximum number of times the algorithm will scan the dataset. 
- The algorithm is efficient in terms of time and space complexity, and is suitable for large datasets. 
- The algorithm can be used to identify and cluster itemsets in a variety of applications such as market basket analysis, web usage mining, and document clustering.
