
### Clustering Techniques for the Notes of the Unit 5 - Frequent Itemsets and Clustering in the Subject of Data Analytics

1. **K-Means Clustering** is an unsupervised machine learning algorithm that is used to group data points into clusters based on their similarity. It works by randomly assigning each data point to a cluster and then iteratively optimizing the clusters by minimizing the distance between the data points and the centroid of the cluster.

2. **Hierarchical Clustering** is an unsupervised machine learning algorithm that is used to group data points into clusters based on their similarity. It works by creating a hierarchy of clusters, where each cluster is a subset of the previous cluster.

3. **DBSCAN** is an unsupervised machine learning algorithm that is used to group data points into clusters based on their similarity. It works by iteratively finding the density-reachable points and assigning them to clusters.

4. **Fuzzy C-Means Clustering** is an unsupervised machine learning algorithm that is used to group data points into clusters based on their similarity. It works by assigning each data point a membership value to each cluster, which can vary between 0 and 1.

5. **Affinity Propagation** is an unsupervised machine learning algorithm that is used to group data points into clusters based on their similarity. It works by sending messages between data points to find clusters that have a high degree of similarity.
