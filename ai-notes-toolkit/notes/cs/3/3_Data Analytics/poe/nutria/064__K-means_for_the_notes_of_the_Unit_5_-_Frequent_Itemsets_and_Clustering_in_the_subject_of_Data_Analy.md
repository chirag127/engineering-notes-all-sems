
### K-means for the Notes of Unit 5 - Frequent Itemsets and Clustering in Data Analytics

1. K-means is a clustering algorithm used to group similar data points together in order to identify patterns and trends. 
2. It is an unsupervised learning algorithm, meaning it does not require labeled data to work.
3. The algorithm works by randomly initializing ‘k’ cluster centers, and then assigning each data point to the cluster center closest to it. 
4. The algorithm then iteratively moves the cluster centers to the mean of the points assigned to them, and reassigns each data point to the closest cluster center. 
5. This process is repeated until the cluster centers stop moving, or until a specified number of iterations have been completed. 
6. K-means can be used to identify frequent itemsets and clusters in data analytics. 
7. By clustering similar items together, it is possible to identify trends and patterns in the data. 
8. This can be used to make predictions and decisions about future data points. 
9. K-means is a fast and efficient algorithm, and is widely used in data analytics.
