
## Unit 6 - Frame Works and Visualization

1. Frameworks are software libraries that provide a common structure for applications in order to reduce the amount of code that needs to be written. 
2. Popular frameworks for web development include Ruby on Rails, Django, and ASP.NET. 
3. Visualization is the process of creating visual representations of data in order to gain insight into the data. 
4. Common types of visualizations include charts, maps, and infographics. 
5. Visualizations can be used to compare data, identify patterns, and uncover trends. 
6. Visualizations can also be used to explain complex data in an easily understandable format. 
7. In order to create effective visualizations, data must be collected, cleaned, and organized. 
8. Once the data is ready, it must be mapped to the appropriate visualization type. 
9. Visualizations can be created using various software tools, such as Tableau, Power BI, and Excel.
