
## Unit 3 - Data Analysis

1. Data analysis is the process of extracting information from raw data to gain insights and make decisions. It involves the use of methods such as statistical analysis, machine learning, and data mining to analyze data sets. 

2. Data analysis can be used to identify trends, uncover patterns, and identify outliers in the data. It can also be used to predict future trends and outcomes. It can be used to help optimize processes, identify areas of improvement, and make informed decisions.

3. Data analysis requires the use of data management tools such as databases, spreadsheets, and data warehouses. It also requires the use of statistical and mathematical techniques such as linear regression, logistic regression, and decision trees. 

4. Data analysis is an important part of the decision-making process. It helps organizations to identify opportunities and risks, and to make informed decisions. It can also be used to identify areas of improvement and to optimize processes.
