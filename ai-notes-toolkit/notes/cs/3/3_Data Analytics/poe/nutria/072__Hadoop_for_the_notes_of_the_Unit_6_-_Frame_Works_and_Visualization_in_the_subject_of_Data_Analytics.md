
### Hadoop for the Notes of Unit 6 - Frameworks and Visualization in Data Analytics

1. Hadoop is an open-source software framework for distributed storage and distributed processing of large datasets on computer clusters.

2. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

3. It is based on the MapReduce programming model, which allows distributed processing of large data sets across clusters of computers.

4. Hadoop enables organizations to store and process large amounts of data quickly and efficiently.

5. It is widely used in the field of data analytics, as it allows for easy storage and retrieval of large amounts of data.

6. Hadoop also provides a framework for distributed computing, which allows for the parallel processing of large datasets.

7. It is used in many applications, such as web indexing, data mining, log processing, machine learning, and natural language processing.

8. Hadoop is often used in conjunction with other frameworks and tools, such as Spark and Hive, to provide an end-to-end data analytics solution.
