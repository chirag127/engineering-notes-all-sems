
### Analytics for Unstructured Data

* Unstructured data is data that does not have a predefined data model or is not organized in a pre-defined manner. Examples of unstructured data include text, audio, video, and images.
* Data analytics for unstructured data typically involves using machine learning algorithms to identify patterns and extract insights from the data.
* Frameworks for data analytics for unstructured data include Natural Language Processing (NLP), Computer Vision, and Speech Recognition.
* NLP is used to analyze text and extract useful information from it. It can be used to detect sentiment, categorize documents, and extract entities and topics.
* Computer vision is used to analyze images and videos and extract useful information from them. It can be used to detect objects, faces, and other features in images.
* Speech recognition is used to convert spoken words into text. It can be used to transcribe audio recordings and identify keywords.
