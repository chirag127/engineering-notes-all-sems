
### CLIQUE and ProCLUS for the notes of the Unit 5 - Frequent Itemsets and Clustering in the subject of Data Analytics

* CLIQUE is an algorithm used to find frequent itemsets in a dataset. It uses vertical data format and works in a recursive fashion.

* ProCLUS is a clustering algorithm used to identify clusters in a dataset. It uses a density-based approach and can handle datasets with noise, outliers, and multiple clusters.

* CLIQUE and ProCLUS can be used together to find frequent itemsets in clusters.

* CLIQUE and ProCLUS can be used to find clusters in a dataset with high frequency itemsets.

* CLIQUE and ProCLUS can be used to identify patterns in a dataset, such as customer segmentation or market segmentation.

* CLIQUE and ProCLUS can be used to identify associations between itemsets and clusters in a dataset.
