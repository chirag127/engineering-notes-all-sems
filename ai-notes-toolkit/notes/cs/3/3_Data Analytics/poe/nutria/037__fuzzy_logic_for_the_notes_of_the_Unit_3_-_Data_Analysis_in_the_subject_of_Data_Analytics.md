
### Fuzzy Logic for the Notes of Unit 3 - Data Analysis in the Subject of Data Analytics

1. Fuzzy logic is an approach to computing based on "degrees of truth" rather than the usual "true or false" (1 or 0) Boolean logic on which most modern computer systems are based. 
2. Fuzzy logic can be used to improve the accuracy of machine learning algorithms, as well as to create more complex systems that can better model real-world situations.
3. Fuzzy logic is based on the idea that the truth of a statement can be represented as a number between 0 and 1, rather than simply true or false. 
4. Fuzzy logic can be used to model complex systems that involve uncertainty, such as systems that involve human behavior or natural phenomena.
5. Fuzzy logic can also be used to create more efficient algorithms for solving problems, as it allows for more flexible and efficient search strategies.
6. Fuzzy logic is used in many areas, including robotics, control systems, image processing, natural language processing, and data mining.
