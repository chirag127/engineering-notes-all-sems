### Frequent Pattern Based Clustering Methods

In the subject of Data Analytics, Unit 5 covers the topic of Frequent Itemsets and Clustering. In this unit, we will focus on the frequent pattern based clustering methods. Following are the points that will help you understand this topic better:

- **Introduction to Frequent Pattern Based Clustering**: Frequent pattern based clustering is a method that is used to cluster similar data items based on the frequency of their occurrence. It is an important technique used in data mining and machine learning.

- **Frequent Itemsets**: Frequent itemsets are a set of items that occur frequently in a dataset. In frequent pattern based clustering, the algorithm identifies frequent itemsets and uses them to cluster similar data items.

- **Apriori Algorithm**: Apriori algorithm is a popular algorithm used in frequent pattern based clustering. It is used to identify frequent itemsets in a dataset. The algorithm works by first identifying the frequent single items in the dataset and then identifying the frequent itemsets by combining the frequent single items.

- **FP-Tree Algorithm**: FP-Tree algorithm is another popular algorithm used in frequent pattern based clustering. It is used to identify frequent itemsets in a dataset. The algorithm works by first constructing a tree structure called FP-Tree and then identifying the frequent itemsets from the tree.

- **Advantages of Frequent Pattern Based Clustering**: Frequent pattern based clustering has several advantages, including:

  - It is a fast and efficient method for clustering large datasets.
  - It can handle datasets with a large number of attributes.
  - It can handle datasets with missing values.

- **Applications of Frequent Pattern Based Clustering**: Frequent pattern based clustering has several applications, including:

  - Market basket analysis
  - DNA sequence analysis
  - Fraud detection
  - Network traffic analysis
