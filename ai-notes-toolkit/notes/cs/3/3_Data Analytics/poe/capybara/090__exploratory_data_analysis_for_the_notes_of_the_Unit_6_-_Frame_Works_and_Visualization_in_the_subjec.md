### Exploratory Data Analysis for the Notes of Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

Exploratory Data Analysis (EDA) is an approach to analyze data to summarize their main characteristics. EDA is an essential preliminary step in any data analysis process. In this unit, we will learn about the frameworks and visualization techniques used in EDA.

Here are the key points to keep in mind for exploratory data analysis:

1. Understand the data: It is crucial to understand the data before analyzing it. This includes identifying the data types, missing values, and outliers in the data. 
2. Data cleaning: Cleaning the data involves removing duplicates, correcting typos, and fixing missing or incorrect values.
3. Descriptive statistics: Descriptive statistics provide a summary of the data, including measures of central tendency, variability, and distribution.
4. Data visualization: Visualization techniques like scatter plots, bar charts, and histograms help in understanding the distribution of the data and identifying patterns and trends.
5. Dimensionality reduction: When dealing with high-dimensional data, it is essential to reduce the dimensions for better visualization and analysis. Techniques like Principal Component Analysis (PCA) can be used for this purpose.
6. Exploring relationships: Exploring relationships between variables can help in identifying correlations and dependencies.
7. Hypothesis testing: Once you have explored the data, you can formulate hypotheses and test them using statistical tests.

In summary, EDA is an essential step in any data analysis process. It helps in understanding the data and identifying patterns and trends. The frameworks and visualization techniques taught in this unit will enable you to perform EDA effectively.
