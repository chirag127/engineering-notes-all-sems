### Systems and Applications for Unit 6 - Frame Works and Visualization in Data Analytics

In this unit, we will explore various systems and applications that can be used for frame works and visualization in data analytics. Here are some important points to remember:

- **Apache Hadoop:** This is an open-source software framework used for distributed storage and processing of large data sets. It includes various components such as Hadoop Distributed File System (HDFS) and MapReduce, which allow for efficient storage and processing of big data.

- **Tableau:** This is a powerful data visualization tool that allows users to create interactive dashboards and reports. It supports various data sources and offers a range of visualization options, making it a popular choice for data analysts.

- **Python:** Python is a popular programming language used in data analytics. It offers various libraries such as Pandas and NumPy, which can be used for data manipulation and analysis. Python also has various visualization libraries such as Matplotlib and Seaborn.

- **Apache Spark:** This is another open-source big data processing framework that is designed for speed and ease of use. It includes various components such as Spark SQL and Spark Streaming, which allow for efficient processing of data in real-time.

- **R:** R is a programming language and environment that is commonly used in statistical computing and data analysis. It includes various libraries such as ggplot2 and dplyr, which can be used for data visualization and manipulation.

- **D3.js:** This is a JavaScript library used for creating dynamic, interactive data visualizations on the web. It supports a range of visualization types and can be used to create custom visualizations.

- **QlikView:** This is a business intelligence platform used for data visualization and discovery. It allows users to create interactive dashboards and reports, and offers various data integration options.

By understanding these systems and applications, data analysts can efficiently manage and analyze large data sets, and communicate their findings through effective visualizations.
