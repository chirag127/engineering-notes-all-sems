### Visual Data Analysis Techniques for the Notes of Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

When it comes to analyzing data, visual representation plays a crucial role in providing insights and understanding patterns. In this unit, we will explore some of the most effective visual data analysis techniques that can be used to analyze data.

Here are some key techniques that you should be familiar with:

- **Scatter Plots:** This technique is used to represent the relationship between two variables. Scatter plots are particularly useful when investigating correlations and identifying patterns in data.

- **Line Charts:** Line charts are used to represent trends over time. This technique is particularly useful when analyzing time-series data and identifying patterns or trends.

- **Bar Charts:** This technique is used to represent categorical data. Bar charts are particularly useful when comparing different categories or groups.

- **Pie Charts:** Pie charts are used to represent proportions or percentages. This technique is particularly useful when analyzing data that can be divided into different categories.

- **Heat Maps:** This technique is used to represent data in a two-dimensional format. Heat maps are particularly useful when analyzing large datasets and identifying patterns or trends.

- **Tree Maps:** Tree maps are used to represent hierarchical data. This technique is particularly useful when analyzing data that can be divided into different levels or categories.

- **Bubble Charts:** Bubble charts are used to represent three-dimensional data. This technique is particularly useful when analyzing data that has multiple variables.

By using these visual data analysis techniques, you can gain a better understanding of your data and identify patterns and trends that may have been missed using traditional data analysis techniques.

Remember to always choose the appropriate technique that will best represent your data and provide the most effective insights. With these techniques, you will be well-equipped to analyze and understand complex datasets.
