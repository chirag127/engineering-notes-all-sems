### Learning and Generalisation

In the field of data analytics, learning and generalisation are essential concepts that enable us to make sense of data and draw meaningful insights. Here are some key points to keep in mind:

- **Learning** refers to the process of training a model to recognize patterns in data. This involves feeding the model a set of input data, along with the correct outputs, and adjusting the model's parameters until it can accurately predict the correct output for new input data.

- There are several types of learning algorithms, including supervised learning, unsupervised learning, and reinforcement learning. Each of these approaches has its own strengths and weaknesses, and the choice of algorithm will depend on the specific problem being addressed.

- Once a model has been trained, it can be used to make predictions on new data. This process is known as **inference**.

- **Generalisation** refers to the ability of a model to make accurate predictions on new, unseen data. A model that has good generalisation performance will be able to make accurate predictions on data that it has not been trained on.

- Generalisation can be improved by using techniques such as regularization, which helps to prevent overfitting (i.e., when a model becomes too specialized to the training data and performs poorly on new data).

- When evaluating a model's performance, it is important to use metrics that take into account both its training performance and its generalisation performance. Common metrics include accuracy, precision, recall, and F1 score.

By understanding the concepts of learning and generalisation, data analysts can build models that are capable of making accurate predictions on new data and drawing meaningful insights from large datasets.
