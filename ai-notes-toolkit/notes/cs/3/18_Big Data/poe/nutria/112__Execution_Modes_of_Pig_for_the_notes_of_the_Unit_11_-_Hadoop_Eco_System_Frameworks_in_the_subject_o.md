
### Execution Modes of Pig

Pig is an open source data analysis platform which is used to run programs on large clusters of Hadoop. It provides an execution environment that allows users to write complex data analysis programs in a scripting language called Pig Latin. Pig Latin programs are then compiled and executed on the Hadoop cluster.

Pig offers two execution modes:

1. **Local Mode**: In this mode, the Pig program is executed on a single machine. This mode is suitable for testing and debugging Pig programs.

2. **MapReduce Mode**: In this mode, the Pig program is executed on the Hadoop cluster. This mode is suitable for running Pig programs on large datasets.
