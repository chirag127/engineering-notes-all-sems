
### Introduction to Unit 10 - SCALA in Big Data
- SCALA is an acronym for Structured Concurrent Actor Language and is a general-purpose programming language which supports both object-oriented and functional programming.
- It is designed to be a concise, type-safe language which is suitable for distributed and concurrent programming.
- SCALA is a statically typed language which allows for the creation of high-performance applications and provides a rich set of libraries and frameworks.
- SCALA is widely used in the field of Big Data, as it allows for the development of distributed applications which can process large amounts of data in parallel.
- SCALA also provides powerful features such as pattern matching, which allows for the extraction of data from complex data structures.
- SCALA is an open source language and is supported by a large community of developers.
