
## Unit 5 - Hadoop Environment

1. Hadoop is an open-source software framework used for distributed storage and distributed processing of large datasets on computer clusters. 
2. Hadoop is designed to scale up from single servers to thousands of machines, each offering local computation and storage. 
3. Hadoop's distributed file system (HDFS) is designed for storing large files and provides a fault-tolerant way of storing data across multiple nodes. 
4. Hadoop's MapReduce is a programming model for processing large datasets in parallel by dividing the work into a set of independent tasks. 
5. Hadoop also provides a library of data processing tools such as Pig and Hive that allow users to quickly and easily analyze large datasets. 
6. Hadoop is widely used in the industry for data-intensive applications such as web indexing, data mining, log processing, machine learning, and scientific simulations.
