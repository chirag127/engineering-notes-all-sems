
### Data Types for the Notes of Unit 8 - MongoDB in the Subject of Big Data

1. MongoDB supports a wide range of data types, including:
    * Numbers (`int`, `long`, `float`, `double`, `decimal`)
    * Strings (`string`, `symbol`)
    * Binary data (`binData`)
    * Boolean values (`bool`)
    * Arrays (`array`)
    * Objects (`object`)
    * Dates (`date`)
    * Null values (`null`)
2. MongoDB also supports a number of special data types, such as:
    * Geospatial data (`geoJSON`, `2dsphere`)
    * Regular expressions (`regex`)
    * JavaScript (`javascript`)
    * Timestamps (`timestamp`)
3. MongoDB also supports user-defined data types, such as:
    * User-defined functions (`function`)
    * User-defined types (`udt`)
4. MongoDB also supports special types for storing large amounts of data, such as:
    * GridFS (`gridfs`)
    * Binary large objects (`blob`)
