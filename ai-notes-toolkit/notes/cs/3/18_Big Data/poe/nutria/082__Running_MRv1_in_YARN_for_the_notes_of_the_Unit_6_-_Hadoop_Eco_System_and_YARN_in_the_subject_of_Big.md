
### Running MRv1 in YARN 

1. Apache Hadoop is an open-source software framework for distributed storage and distributed processing of large data sets on computer clusters built from commodity hardware. 
2. Apache Hadoop YARN is a key component of the Hadoop ecosystem that enables resource management and job scheduling across multiple machines. 
3. YARN can be used to run MapReduce version 1 (MRv1) jobs on a Hadoop cluster. 
4. MRv1 is the original MapReduce implementation that was part of the Apache Hadoop core. 
5. MRv1 is a batch processing system that processes large amounts of data in parallel by dividing the data into smaller chunks and assigning each chunk to a different node in the cluster. 
6. Each node processes its assigned chunk of data and then sends the results back to the master node for aggregation. 
7. YARN is responsible for managing the resources of the cluster and scheduling the jobs to be executed. 
8. YARN can also be used to run non-MapReduce jobs such as Apache Spark applications. 
9. YARN provides scalability, reliability, and security to the Hadoop cluster.
