
### Spark on YARN

* Spark on YARN is a resource management platform for distributed applications that allows users to efficiently manage and execute applications across a shared pool of resources. 
* YARN stands for Yet Another Resource Negotiator and is the resource-management layer of Hadoop. 
* It is responsible for allocating resources to applications running on the cluster and scheduling tasks to be executed on different nodes. 
* Spark on YARN provides an efficient way to manage and execute applications, as it allows users to specify the amount of resources each application requires. 
* It also allows users to specify the number of executors and the number of cores per executor, which allows for better resource utilization. 
* Furthermore, it provides support for fault-tolerance and high availability by allowing users to specify the number of replicas of an application to be run. 
* Spark on YARN also provides support for running multiple versions of Spark, which allows users to take advantage of the latest features of Spark.
