
### Resilient Distributed Databases for the notes of the Unit 9 - Spark in the subject of Big Data

* Resilient Distributed Databases (RDDs) are a type of distributed database that is designed to be fault-tolerant and highly scalable. 
* RDDs are used in big data applications such as Apache Spark to process large data sets. 
* RDDs are composed of a collection of data elements, or records, that are distributed across a cluster of computers. 
* RDDs can be partitioned into multiple partitions, each of which is stored on a different node in the cluster. 
* RDDs are designed to be fault-tolerant, meaning that if one node fails, the data can still be recovered from the other nodes. 
* RDDs are also highly scalable, which means that they can be easily expanded to accommodate large data sets. 
* Apache Spark is an open-source distributed computing framework that is built on top of RDDs. 
* Spark provides a programming interface for creating and manipulating RDDs and executing distributed computations on them. 
* Spark also provides a library of built-in algorithms for data processing and machine learning. 
* Spark can be used to process large data sets in a distributed and fault-tolerant manner.
