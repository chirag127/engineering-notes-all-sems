
### Benefits and Challenges for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

**Benefits**

1. HDFS is a distributed file system that provides high throughput access to application data. 
2. It is highly fault-tolerant and is designed to be deployed on low-cost hardware. 
3. HDFS is well-suited for applications that have large data sets, such as scientific and financial data. 
4. HDFS is designed to store large files, such as images and videos, and supports streaming access to these files.

**Challenges**

1. HDFS is not designed to support real-time applications that require low latency access to data. 
2. HDFS is not suitable for applications that require low-latency updates. 
3. HDFS is not suitable for applications that require random access to files. 
4. HDFS is not suitable for applications that require high levels of security or data integrity.
