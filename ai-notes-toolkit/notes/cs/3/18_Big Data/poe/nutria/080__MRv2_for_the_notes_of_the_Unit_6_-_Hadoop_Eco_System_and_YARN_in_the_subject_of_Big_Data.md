
### MRv2 for the Notes of the Unit 6 - Hadoop Eco System and YARN in the Subject of Big Data

1. Hadoop is an open source software framework for distributed storage and processing of large datasets on computer clusters built from commodity hardware.
2. The Hadoop Eco System consists of several components, including the Hadoop Distributed File System (HDFS) for distributed storage, the MapReduce programming model for distributed processing, and the YARN resource management system for managing resources across the cluster.
3. YARN is a resource management system that is responsible for allocating resources to applications running on the cluster. It also provides a platform for scheduling, monitoring, and managing applications.
4. YARN is composed of two main components: a ResourceManager and a NodeManager.
5. The ResourceManager is responsible for allocating resources to applications and managing the cluster as a whole.
6. The NodeManager is responsible for managing resources on individual nodes and for monitoring the status of applications running on those nodes.
7. The ResourceManager and NodeManager communicate with each other via a protocol called the ApplicationMaster protocol.
8. YARN also provides a framework for scheduling tasks, such as MapReduce jobs, across the cluster.
9. YARN is designed to be fault tolerant, so if a node fails, the ResourceManager can reallocate resources to other nodes in the cluster.
10. YARN also provides security features, such as authentication and authorization, to ensure that only authorized users can access the cluster.
