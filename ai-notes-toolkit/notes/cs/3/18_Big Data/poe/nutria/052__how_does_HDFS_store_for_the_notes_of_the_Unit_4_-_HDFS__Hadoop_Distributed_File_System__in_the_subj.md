
### How Does HDFS Store Data?

1. HDFS is a distributed file system that allows users to store large amounts of data across multiple nodes in a cluster.
2. HDFS stores data in blocks, which are replicated across multiple nodes in the cluster. This ensures that data is not lost if one of the nodes fails.
3. HDFS also provides fault tolerance by replicating the data blocks across different racks of nodes. This helps to ensure that data is always available, even if a rack of nodes fails.
4. HDFS is designed to be highly scalable and can store petabytes of data.
5. HDFS also provides high throughput access to data, allowing users to access large amounts of data in a short amount of time.
6. HDFS is used for large-scale data processing tasks such as those performed by Hadoop.
