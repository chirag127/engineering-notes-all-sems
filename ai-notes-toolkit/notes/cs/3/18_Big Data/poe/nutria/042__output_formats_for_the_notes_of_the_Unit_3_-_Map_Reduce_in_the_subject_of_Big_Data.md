
### Output Formats for the Notes of Unit 3 - Map Reduce in Big Data

- MapReduce is a programming model used for processing and generating large data sets with a parallel, distributed algorithm on a cluster. 
- Output formats are the result of a MapReduce job, and they can be in various formats such as plain text, sequence files, Avro files, and Parquet files. 
- Plain text output is the simplest format, and it is suitable for debugging and testing. 
- Sequence files are binary files that store data as key-value pairs, and they are suitable for storing data in a distributed file system. 
- Avro files are binary files that store data in a compact and efficient format, and they are suitable for storing data in a distributed file system. 
- Parquet files are column-oriented files that store data in a compressed and efficient format, and they are suitable for storing data in a distributed file system.
