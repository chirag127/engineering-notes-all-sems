
### Unit 4 - HDFS (Hadoop Distributed File System)
1. HDFS is a distributed file system that is designed to run on commodity hardware.
2. It is highly fault-tolerant and is suitable for applications with large data sets.
3. HDFS is a Java-based file system that provides a distributed storage layer for data storage and processing.
4. It is based on a master-slave architecture, where the master node is called the NameNode and the slave nodes are called DataNodes.
5. The NameNode manages the file system namespace and regulates access to files by clients.
6. The DataNodes manage the storage of the actual data blocks.
7. HDFS is designed to be highly scalable and fault tolerant.
8. It is designed to be able to store large files, up to several petabytes in size.
9. HDFS is optimized for batch processing, which means that it is not suitable for low-latency applications.
10. HDFS is designed to be able to handle streaming data, but it is not as efficient as other systems for this purpose.
