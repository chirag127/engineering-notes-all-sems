
### Comparison of Pig with Databases for the Notes of Unit 11 - Hadoop Eco System Frameworks in the Subject of Big Data

1. Pig is an open-source data processing platform that is used to query, transform, and analyze large datasets.
2. Pig is a high-level platform that makes it easier to process large datasets than traditional databases.
3. Pig is designed to be used with Hadoop, a distributed file system that allows for efficient processing of large datasets.
4. Pig is a data flow language, which means that it can take data from multiple sources, transform it, and then store it in a single output.
5. Pig is faster and more efficient than traditional databases because it can process data in parallel.
6. Pig is more flexible than traditional databases, as it allows for complex queries and transformations.
7. Pig is more scalable than traditional databases, as it can handle large datasets with ease.
8. Pig is more cost-effective than traditional databases, as it can process data more quickly and efficiently.
