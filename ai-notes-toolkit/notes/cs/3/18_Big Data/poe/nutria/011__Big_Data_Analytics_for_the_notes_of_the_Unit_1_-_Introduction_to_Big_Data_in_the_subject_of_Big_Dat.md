
### Big Data Analytics for the Notes of Unit 1 - Introduction to Big Data 

1. Big Data analytics is the process of collecting, organizing, and analyzing large amounts of data to uncover patterns and trends. 
2. Big Data analytics can be used to identify customer behavior, market trends, and other insights that can help businesses make better decisions.
3. Big Data analytics involves the use of specialized software and algorithms to analyze large datasets.
4. Big Data analytics can be used to identify patterns and trends in large datasets, such as customer buying habits or market trends.
5. Big Data analytics can be used to identify potential opportunities and risks in a business.
6. Big Data analytics can be used to improve customer service, reduce costs, and increase efficiency.
7. Big Data analytics can be used to identify customer preferences and target marketing campaigns.
8. Big Data analytics can be used to analyze customer feedback and improve customer experience.
