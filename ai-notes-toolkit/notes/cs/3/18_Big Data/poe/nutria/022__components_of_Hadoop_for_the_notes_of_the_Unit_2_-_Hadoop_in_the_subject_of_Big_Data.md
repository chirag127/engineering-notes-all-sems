
### Components of Hadoop

1. **Hadoop Distributed File System (HDFS):** This is the primary storage system of Hadoop. HDFS is a distributed file system that allows for the storage of large amounts of data across multiple machines. 

2. **YARN:** YARN stands for Yet Another Resource Negotiator. It is the resource management layer of Hadoop and is responsible for managing the resources in the cluster. 

3. **MapReduce:** MapReduce is the processing layer of Hadoop. It is responsible for processing the data stored in HDFS. 

4. **Hadoop Common:** Hadoop Common is a set of common utilities and libraries that are used by other Hadoop modules. 

5. **Spark:** Spark is an open-source distributed computing framework for large-scale data processing. It is an alternative to MapReduce and is used for real-time data processing.
