
### Job Scheduling for the Notes of the Unit 3 - Map Reduce in the Subject of Big Data

1. Job scheduling is the process of assigning tasks to computers or other resources to optimize the completion time of a given set of tasks.
2. MapReduce is a programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster.
3. In the context of Big Data, job scheduling involves assigning tasks to nodes in a distributed system, such as a Hadoop cluster.
4. Job scheduling algorithms can be used to optimize the performance of a distributed system by minimizing the amount of time needed to complete a given set of tasks.
5. The scheduling of jobs can be done in different ways, such as static scheduling, dynamic scheduling, and hybrid scheduling.
6. Static scheduling assigns tasks to nodes before the execution of the tasks, while dynamic scheduling assigns tasks to nodes during the execution of the tasks.
7. Hybrid scheduling combines both static and dynamic scheduling to optimize the performance of the system.
