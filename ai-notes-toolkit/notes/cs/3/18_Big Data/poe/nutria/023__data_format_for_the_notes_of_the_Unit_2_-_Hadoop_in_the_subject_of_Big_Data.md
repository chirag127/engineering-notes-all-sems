
### Data Format for the Notes of Unit 2 - Hadoop in the Subject of Big Data

1. Hadoop is an open-source software framework that is used for distributed storage and processing of large datasets across clusters of computers. 
2. Hadoop is designed to scale up from single servers to thousands of machines, each offering local computation and storage. 
3. Hadoop has a distributed file system (HDFS) which stores data on multiple nodes in the cluster. 
4. Hadoop also has a resource management system (YARN) which manages the resources in the cluster and allows for job scheduling and resource allocation. 
5. Hadoop also has a data processing framework (MapReduce) which allows for distributed processing of large datasets across multiple nodes in the cluster. 
6. Hadoop can be used for a variety of tasks such as data analysis, machine learning, and even web search. 
7. Hadoop is written in Java and is highly extensible, allowing for custom implementations of its various components.
