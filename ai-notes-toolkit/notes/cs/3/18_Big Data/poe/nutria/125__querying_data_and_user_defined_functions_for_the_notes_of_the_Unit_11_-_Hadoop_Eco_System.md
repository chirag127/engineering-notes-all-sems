
### Querying Data and User Defined Functions for the Notes of the Unit 11 - Hadoop Eco System

* Hadoop provides a powerful platform for querying and processing data stored in HDFS. 
* Hadoop provides a SQL-like query language called HiveQL, which is used to query data stored in HDFS.
* HiveQL is a declarative language that allows users to write queries in a more natural way than traditional SQL.
* HiveQL also supports user-defined functions (UDFs), which are custom functions written in Java, Python, or other languages that can be used to extend the functionality of HiveQL.
* UDFs can be used to perform complex data processing tasks such as text analysis, machine learning, and data mining.
* HiveQL also supports user-defined aggregate functions (UDAFs), which are custom functions written in Java, Python, or other languages that can be used to perform aggregate operations on data stored in HDFS.
* UDAFs can be used to calculate statistics such as averages, counts, and sums.
* HiveQL also supports user-defined table functions (UDTFs), which are custom functions written in Java, Python, or other languages that can be used to transform data stored in HDFS.
* UDTFs can be used to perform complex data transformations such as joins, pivots, and window functions.
