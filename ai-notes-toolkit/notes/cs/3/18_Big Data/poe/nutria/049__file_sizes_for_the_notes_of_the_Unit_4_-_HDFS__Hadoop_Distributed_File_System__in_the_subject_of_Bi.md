
### File Sizes for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

* HDFS is a distributed file system that is designed to store large files across multiple nodes in a cluster. 
* Files in HDFS are split into blocks, with each block typically 64MB in size. 
* Blocks are stored on different nodes in the cluster, and each node is responsible for storing and replicating the blocks it contains. 
* HDFS is designed to be resilient to failure, and the replication of blocks across nodes ensures that if one node fails, the data stored on it can be recovered from the other nodes. 
* HDFS is also able to scale to process large amounts of data, as more nodes can be added to the cluster to increase the storage capacity.
