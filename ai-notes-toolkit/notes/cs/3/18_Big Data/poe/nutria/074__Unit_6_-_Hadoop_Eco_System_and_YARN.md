
## Unit 6 - Hadoop Eco System and YARN

1. Hadoop is an open-source software framework used for distributed storage and processing of large datasets. It is a scalable and reliable platform that provides fault tolerance and data replication.

2. YARN (Yet Another Resource Negotiator) is the resource management layer of Hadoop. It is responsible for allocating resources to applications running on the cluster and scheduling tasks.

3. Hadoop is composed of two main components: the HDFS (Hadoop Distributed File System) and the MapReduce programming model. HDFS is a distributed file system that stores data on commodity machines and provides high-throughput access to data. MapReduce is a programming model for processing large datasets that is based on dividing a task into smaller sub-tasks.

4. YARN provides a platform for developing distributed applications that can run on a Hadoop cluster. It provides a resource management layer that allows applications to request resources from the cluster and provides a scheduling layer that assigns resources to applications.

5. YARN also provides an ApplicationMaster that is responsible for managing the application’s lifecycle. The ApplicationMaster is responsible for negotiating resources from the ResourceManager, tracking the application’s progress, and managing the application’s tasks.

6. YARN also provides a framework for developing distributed applications. It provides an Application Programming Interface (API) that allows developers to write distributed applications that can run on a Hadoop cluster. The API provides a framework for developing distributed applications that can run on a Hadoop cluster.
