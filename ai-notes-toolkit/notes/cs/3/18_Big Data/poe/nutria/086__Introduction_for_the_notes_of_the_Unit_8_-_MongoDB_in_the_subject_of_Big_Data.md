
### Introduction to Unit 8 - MongoDB in Big Data 

* MongoDB is a popular NoSQL database system used for storing large amounts of data.
* MongoDB is an open-source document database that is used by many organizations for storing and managing data.
* MongoDB is a distributed database system that is designed for scalability and high performance.
* MongoDB is a document-oriented database that stores data in JSON-like documents.
* MongoDB is a schema-less database, meaning that the structure of the data is not predefined.
* MongoDB provides a powerful query language that allows users to query and manipulate data in the database.
* MongoDB supports various data types, including strings, numbers, dates, and binary data.
* MongoDB provides features such as replication and sharding that allow users to scale their databases to handle large amounts of data.
* MongoDB is used in many applications, including web applications, mobile applications, and IoT applications.
