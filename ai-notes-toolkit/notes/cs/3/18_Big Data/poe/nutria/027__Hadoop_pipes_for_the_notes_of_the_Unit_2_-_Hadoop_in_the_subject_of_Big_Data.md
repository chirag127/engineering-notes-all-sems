
### Hadoop Pipes 

* Hadoop Pipes is a C++ application programming interface (API) that allows programmers to write applications that are able to interact with Hadoop MapReduce, an open-source framework for distributed computing. 
* Hadoop Pipes enables developers to write applications that can access data stored in HDFS, the Hadoop Distributed File System, as well as process data stored in HBase.
* Hadoop Pipes consists of two components: a C++ library and a binary executable. The library provides the necessary functions to interact with the Hadoop MapReduce framework, while the binary executable is used to launch the application.
* Hadoop Pipes is designed to facilitate the development of distributed applications by providing a simple, yet powerful API. It also provides a number of features, such as the ability to create custom input and output formats, as well as the ability to access HBase data.
* Hadoop Pipes is a key component of the Hadoop ecosystem and provides developers with a powerful tool to create distributed applications.
