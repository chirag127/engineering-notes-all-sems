
### Unit 8 - MongoDB

- MongoDB is an open source NoSQL database that stores data in a JSON-like format.
- MongoDB is a document-oriented database, meaning that it stores data in documents instead of tables.
- MongoDB uses a query language called MongoDB Query Language (MQL) to query data.
- MongoDB supports indexing, which allows for faster query execution.
- MongoDB supports sharding, which allows for horizontal scaling of data.
- MongoDB supports replication, which allows for redundancy and high availability.
- MongoDB supports aggregation, which allows for data analysis and data mining.
- MongoDB supports transactions, which allow for atomicity and consistency of data.
