
## Unit 1 - Introduction to Big Data

1. Big Data is a term used to describe the large amount of data which is too complex and vast for traditional data processing software to manage.

2. Big Data can come from a variety of sources, including web logs, social media, sensors, and mobile devices.

3. Big Data is characterized by its volume, velocity, variety, and veracity.

4. Big Data can be used to uncover insights and trends, and to make better decisions.

5. Big Data is often stored in a distributed file system, such as HDFS, or in a NoSQL database, such as HBase.

6. Big Data analytics techniques include machine learning, predictive analytics, and natural language processing.

7. Big Data can be used for predictive maintenance, customer segmentation, fraud detection, and many other applications.
