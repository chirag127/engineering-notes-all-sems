
### Types of Digital Data

1. Structured Data: Data that is organized in a specific way, usually in a table or spreadsheet format. Structured data is typically stored in a database and is easily searchable. Examples include financial records, customer information, and inventory data.

2. Unstructured Data: Data that is not organized in a specific way. Examples include text documents, audio and video files, and images. Unstructured data is more difficult to analyze and often requires specialized software and tools to process.

3. Semi-Structured Data: Data that is partially organized. Examples include XML, JSON, and HTML files. Semi-structured data is easier to analyze than unstructured data, but still requires specialized software and tools to process.

4. Streaming Data: Data that is generated in real-time and is continuously updated. Examples include stock prices, sensor data, and social media posts. Streaming data requires specialized software and tools to process and analyze.
