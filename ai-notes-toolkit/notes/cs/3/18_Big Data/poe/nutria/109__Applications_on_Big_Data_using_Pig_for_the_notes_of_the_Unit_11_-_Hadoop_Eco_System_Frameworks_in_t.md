
### Applications on Big Data using Pig

1. Pig is an open-source platform used for analyzing large data sets that are stored in the Hadoop file system.
2. Pig Latin is the language used to write programs on Pig.
3. Pig Latin has the ability to process data stored in any format such as plain text, JSON, CSV, etc.
4. Pig Latin can be used to apply transformations, sorting, filtering, joining, and other operations on data stored in the Hadoop file system.
5. Pig Latin provides an easy-to-use interface for writing complex data processing programs.
6. Pig Latin programs are compiled into MapReduce jobs that run on the Hadoop cluster.
7. Pig Latin programs can be debugged using the Pig debugger.
8. Pig Latin can be used to process data stored in HDFS, HBase, and other Hadoop-supported data stores.
9. Pig Latin programs can be integrated with UDFs (user-defined functions) to extend the functionality of the language.
