
### Hadoop Streaming 

- Hadoop streaming is a utility that allows users to create and run jobs with any executable or script as the mapper and/or the reducer. 
- It enables users to utilize different programming languages such as Python, Ruby, and C++ to create MapReduce jobs.
- Hadoop streaming is part of the Apache Hadoop project, which is an open-source software framework for distributed storage and processing of large datasets.
- Hadoop streaming is used to process large datasets stored in HDFS (Hadoop Distributed File System). 
- The mapper and reducer functions can be written in any language that can read and write to standard input and output.
- Hadoop streaming is used to process data in parallel, which makes it more efficient than processing data sequentially.
- Hadoop streaming is used for data analysis, machine learning, and other big data applications.
- Hadoop streaming is a powerful tool for processing large datasets and can be used to create real-time data pipelines.
