
### Command Line Interface for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

1. HDFS is a distributed file system that stores data across multiple nodes in a Hadoop cluster. 
2. HDFS is designed to be fault-tolerant and to scale horizontally.
3. HDFS uses the concept of blocks to store data. Each block is replicated across multiple nodes in the cluster for reliability.
4. HDFS provides a command line interface for managing files and directories in the Hadoop cluster.
5. The basic HDFS commands are `ls`, `mkdir`, `mv`, `cp`, `rm`, `cat`, and `tail`.
6. The `ls` command is used to list the contents of a directory.
7. The `mkdir` command is used to create a new directory.
8. The `mv` command is used to move or rename a file or directory.
9. The `cp` command is used to copy a file or directory.
10. The `rm` command is used to delete a file or directory.
11. The `cat` command is used to view the contents of a file.
12. The `tail` command is used to view the last few lines of a file.
