
### Administering Hadoop

* Hadoop is an open-source software framework used for distributed storage and processing of large datasets.
* It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
* Hadoop consists of two core components: the Hadoop Distributed File System (HDFS) and the MapReduce programming model.
* HDFS is a distributed file system that stores data across multiple nodes in a cluster. It allows for high throughput access to data and is fault tolerant.
* MapReduce is a programming model for processing large datasets in a distributed manner. It consists of two steps: Map and Reduce.
* In the Map step, data is processed in parallel across multiple nodes in the cluster. The Reduce step combines the results of the Map step into a single output.
* Hadoop also provides additional components such as the Hadoop Common library, which contains utilities and libraries needed by other Hadoop modules, and the YARN resource manager, which is responsible for managing resources and scheduling applications.
* Hadoop is used in a variety of applications, including data warehousing, web indexing, scientific simulation, and machine learning.
