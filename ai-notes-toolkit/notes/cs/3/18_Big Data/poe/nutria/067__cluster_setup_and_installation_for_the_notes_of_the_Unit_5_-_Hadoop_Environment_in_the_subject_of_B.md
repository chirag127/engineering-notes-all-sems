
### Cluster Setup and Installation for the Notes of the Unit 5 - Hadoop Environment in the Subject of Big Data

1. Hadoop is an open-source software framework used for distributed storage and processing of large datasets on clusters of computers.
2. It provides a distributed file system and a programming model for distributed computing.
3. To set up a Hadoop cluster, the following components must be installed:
    * Hadoop Common: This component contains the libraries and utilities used by other Hadoop components.
    * Hadoop Distributed File System (HDFS): This component provides a distributed file system for storing large datasets.
    * Hadoop YARN: This component provides a resource management platform for scheduling and executing applications.
    * Hadoop MapReduce: This component provides a programming model for distributed computing.
4. To install the components, you must first configure the cluster. This involves setting up the nodes, configuring the network, and installing the software.
5. After the cluster is set up, you can then install the components. This involves downloading the software, configuring the environment, and running the installation scripts.
6. Once the components are installed, the cluster is ready to use. You can then start running applications on the cluster.
