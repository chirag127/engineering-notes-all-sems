
## Unit 8 - MongoDB 

MongoDB is an open-source document-oriented database system written in C++. It is designed to provide scalability, high performance, and ease of use. MongoDB stores data in collections of documents, which are similar to tables in relational databases. Each document can contain multiple fields, and the data structure can be changed over time without having to alter the database schema. MongoDB is used for a variety of applications, including web applications, mobile applications, and analytics.
