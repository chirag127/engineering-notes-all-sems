
### Data Ingest with Flume and Scoop

* Flume is a distributed, reliable, and available service for efficiently collecting, aggregating, and moving large amounts of log data. It has a simple and flexible architecture based on streaming data flows. 
* Flume is highly configurable and can be used to transport data from many sources, including log files, web servers, and social media sites.
* Scoop is an open source data ingestion tool for Hadoop. It is used to move data from various sources into HDFS. It is designed to be fault-tolerant and can be used to ingest data from multiple sources simultaneously.
* The Hadoop Distributed File System (HDFS) is a distributed file system designed to run on commodity hardware. It provides high-throughput access to application data and is suitable for applications that have large data sets. HDFS is highly fault-tolerant and is designed to be deployed on low-cost hardware.
* HDFS provides a way to store large files across multiple machines. It is designed to be highly available, fault-tolerant, and scalable. HDFS is designed to support high-throughput access to data by applications.
