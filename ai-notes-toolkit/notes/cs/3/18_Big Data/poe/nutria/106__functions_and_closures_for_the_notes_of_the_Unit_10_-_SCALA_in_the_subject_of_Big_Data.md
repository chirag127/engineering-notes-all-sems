
### Functions and Closures for the Notes of the Unit 10 - SCALA in the Subject of Big Data

* Functions in Scala are declared with the keyword `def` and have a return type.
* Closures are functions that can access variables outside of their scope. They are declared with the keyword `val` and have no return type.
* Functions can be nested, allowing for more complex logic.
* Functions can also be partially applied, meaning some of the arguments can be supplied at the time of declaration and the rest at the time of invocation.
* Closures can be used to pass around state between functions, making them useful for implementing stateful algorithms.
* Scala supports higher-order functions, which are functions that take other functions as parameters.
* Scala also supports currying, which is the process of transforming a function that takes multiple arguments into a sequence of functions that each take one argument.
