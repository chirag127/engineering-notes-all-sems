
## Unit 2 - Hadoop

* Hadoop is an open-source software framework used for distributed storage and distributed processing of large datasets on computer clusters built from commodity hardware. 
* It is based on Google's MapReduce and Google File System (GFS) papers. 
* Hadoop provides a distributed file system (HDFS) and a way to run MapReduce programs. 
* Hadoop is designed to scale up from a single server to thousands of machines, each offering local computation and storage. 
* HDFS is a distributed file system that runs on commodity hardware. It is designed to be easily deployed and maintained. 
* It provides high-throughput access to application data and is suitable for applications that have large data sets. 
* HDFS is designed to be fault-tolerant and is highly scalable. 
* MapReduce is a programming model for processing large datasets with a parallel, distributed algorithm on a cluster. 
* It is designed to scale up from a single server to thousands of machines. 
* MapReduce splits the input data-set into independent chunks which are processed by the map tasks in a completely parallel manner. 
* The output of the map tasks is then sorted and passed on to the reduce tasks. 
* The reduce tasks aggregate the output from the map tasks and produce the final result.
