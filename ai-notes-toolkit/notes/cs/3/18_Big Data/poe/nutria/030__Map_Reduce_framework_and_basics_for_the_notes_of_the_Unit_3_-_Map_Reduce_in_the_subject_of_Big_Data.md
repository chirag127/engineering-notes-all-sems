
### Map Reduce Framework and Basics

1. MapReduce is a programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster.

2. MapReduce is a two-step process: 
  - Map step: The master node takes the input, divides it into smaller sub-problems, and distributes them to worker nodes. 
  - Reduce step: The worker nodes process the sub-problems and send the results back to the master node.

3. MapReduce is designed to process large amounts of data in parallel by dividing the work into a set of independent tasks.

4. MapReduce is used in many applications, such as web indexing, data mining, log processing, machine learning, financial analysis, and scientific simulations.

5. MapReduce is a programming framework that allows developers to write programs that process large amounts of data in parallel across a cluster of computers.

6. MapReduce is based on the divide-and-conquer approach to problem solving.

7. MapReduce is designed to be fault tolerant, allowing it to continue running even if one or more of the nodes in the cluster fail.
