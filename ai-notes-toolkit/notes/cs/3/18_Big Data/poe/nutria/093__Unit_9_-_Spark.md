
## Unit 9 - Spark

1. Apache Spark is an open-source distributed computing framework designed for large-scale data processing. It was developed at the University of California, Berkeley in 2009 and is now used by organizations around the world.

2. Spark is designed to provide high performance, ease of use, and scalability. It allows users to process data in a distributed and fault-tolerant manner. It can be used for data analysis, machine learning, stream processing, and graph processing.

3. Spark is written in Scala and can be used in Java, Python, and R. It can be deployed in a variety of ways, including standalone clusters, Hadoop YARN clusters, Apache Mesos clusters, and Kubernetes clusters.

4. Spark offers several APIs for data processing, including the Spark Core API, the Spark SQL API, the Spark Streaming API, and the MLlib API. It also includes a variety of libraries for machine learning, graph processing, and streaming.

5. Spark can be used to process data from a variety of sources, including HDFS, Cassandra, Kafka, and S3. It also supports a wide range of data formats, such as CSV, JSON, Parquet, and Avro.

6. Spark is highly extensible and can be used in a variety of ways. It can be used for data processing, data analysis, machine learning, stream processing, and graph processing. It can also be used for real-time analytics, interactive queries, and streaming applications.
