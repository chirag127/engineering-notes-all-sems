
### Introduction to Indexing for the Notes of Unit 8 - MongoDB in the Subject of Big Data

1. Indexing is a process in MongoDB that allows for faster retrieval of data from a collection. 
2. Indexes are special data structures that store a small portion of the collection’s data set in a way that makes it easier to search. 
3. Indexes speed up the search process by reducing the amount of data that needs to be scanned in order to find a particular document. 
4. Indexes can be created on any field in a MongoDB collection, including fields within embedded documents and arrays. 
5. MongoDB supports several types of indexes, including single-field indexes, compound indexes, unique indexes, and text indexes. 
6. Indexes can be created in the background, allowing for faster query performance without blocking other operations. 
7. Indexes can be dropped and rebuilt when needed. 
8. Indexes can be used to enforce unique constraints on a collection. 
9. Indexes can be used to improve the performance of certain queries.
