## Unit 5 - Hadoop Environment

In this unit, we will be discussing the Hadoop environment. Hadoop is an open-source software framework used for distributed storage and processing of large datasets. The Hadoop environment consists of the following components:

1. Hadoop Distributed File System (HDFS): HDFS is a distributed file system that enables the storage of large datasets across multiple machines.

2. Yet Another Resource Negotiator (YARN): YARN is a resource manager responsible for managing resources and scheduling tasks in a Hadoop cluster.

3. MapReduce: MapReduce is a programming model used for processing large datasets in a distributed environment.

4. Hadoop Common: Hadoop Common provides the common libraries and utilities used by other Hadoop modules.

5. Hadoop Oozie: Oozie is a workflow scheduler system used to manage Hadoop jobs.

6. Hadoop Pig: Pig is a high-level platform for creating MapReduce programs used to analyze large datasets.

7. Hadoop Hive: Hive is a data warehouse system used to query and analyze large datasets stored in Hadoop.

8. Hadoop Sqoop: Sqoop is a tool used to transfer data between Hadoop and relational databases.

9. Hadoop Flume: Flume is a distributed, reliable, and available system used for efficiently collecting, aggregating, and moving large amounts of log data.

10. Hadoop HBase: HBase is a NoSQL database used for storing large amounts of unstructured and semi-structured data in a Hadoop environment.

In conclusion, the Hadoop environment consists of several components that work together to provide a distributed storage and processing system for large datasets. Understanding these components is essential for anyone working with Hadoop.
