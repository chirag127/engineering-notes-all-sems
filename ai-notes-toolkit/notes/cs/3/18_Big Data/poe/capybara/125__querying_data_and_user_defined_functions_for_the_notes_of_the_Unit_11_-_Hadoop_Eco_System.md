### Querying Data and User Defined Functions for the Notes of Unit 11 - Hadoop Eco System

In Hadoop Eco System, querying data is an important aspect of data analysis. Hadoop provides several tools to query data stored in HDFS. In this section, we will discuss the different ways to query data in Hadoop Eco System.

#### Querying Data in Hadoop Eco System

- Hive: Hive is a data warehousing tool in Hadoop Eco System. It provides an SQL-like interface to query data stored in HDFS. HiveQL is the query language used by Hive. It converts queries into MapReduce jobs and runs them on the Hadoop cluster.

- Pig: Pig is another tool in Hadoop Eco System used for data analysis. It provides a high-level language to query data stored in HDFS. Pig Latin is the query language used by Pig. It converts queries into MapReduce jobs and runs them on the Hadoop cluster.

- HBase: HBase is a NoSQL database in Hadoop Eco System. It provides an interface to query data stored in HDFS. HBase queries are written in Java. It is used for real-time access to data.

#### User Defined Functions

- User Defined Functions (UDFs) are a way to extend the functionality of Hive and Pig. They allow users to write custom functions in Java or any other programming language and use them in Hive and Pig.

- Hive UDFs: Hive UDFs can be used to perform complex operations on data stored in HDFS. They can be used to create new functions or modify existing functions. Hive UDFs are written in Java.

- Pig UDFs: Pig UDFs can be used to perform complex operations on data stored in HDFS. They can be used to create new functions or modify existing functions. Pig UDFs can be written in Java, Python, or any other programming language.

In conclusion, querying data and user defined functions are important aspects of Hadoop Eco System. Hive, Pig, and HBase provide different ways to query data stored in HDFS. User Defined Functions can be used to extend the functionality of Hive and Pig.
