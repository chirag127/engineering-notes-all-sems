### MRv2 for the notes of the Unit 6 - Hadoop Eco System and YARN in the subject of Big Data

MRv2, also known as MapReduce version 2, is the next generation of MapReduce framework in Hadoop. It is also known as YARN (Yet Another Resource Negotiator) which is the resource management layer of Hadoop.

Here are some key points to understand about MRv2 in the context of Hadoop Eco System and YARN:

- MRv2 or YARN is designed to manage resources and schedule jobs in Hadoop cluster. It separates the job scheduling and resource management functions from the MapReduce processing functions.

- MRv2 or YARN is more scalable and flexible than the previous version of MapReduce. It allows multiple data processing engines to run on the same Hadoop cluster.

- MRv2 or YARN supports additional data processing frameworks such as Apache Tez, Apache Spark, and Apache Flink. This makes it easier to develop and run complex data processing applications.

- MRv2 or YARN provides a pluggable interface for scheduling, allowing different scheduling algorithms to be used. This enables better resource utilization and job performance.

- MRv2 or YARN supports containerization, which means that each job runs in a separate container. This provides better isolation and security for data processing applications.

- MRv2 or YARN also provides support for distributed caching, which allows data to be cached across the cluster for faster processing.

- MRv2 or YARN provides a web-based user interface to monitor and manage the Hadoop cluster. This includes information about running jobs, resource utilization, and cluster health.

Overall, MRv2 or YARN is an important component of the Hadoop Eco System, providing a robust and scalable framework for managing resources and scheduling jobs in a Hadoop cluster.
