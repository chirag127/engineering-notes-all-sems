### History of Hadoop

1. Hadoop was created by Doug Cutting in 2005. He named it after his son's toy elephant.
2. Hadoop was inspired by two papers from Google - GFS (Google File System) and MapReduce. These papers described Google's distributed file system and a programming model for processing large data sets with parallel, distributed algorithms on a cluster.
3. In 2006, Hadoop's MapReduce and HDFS components were released as open-source projects by Apache Software Foundation.
4. In 2008, Hadoop 0.20 was released with many improvements to MapReduce and HDFS. Yahoo started using Hadoop for its Web indexing.
5. In 2009, Hadoop 1.0 was released with even more robust features like improved performance, automatic failover, and rack awareness. More companies like Facebook, Twitter, eBay started adopting Hadoop.
6. In 2011, Hadoop 2.0 (YARN) was released which added a new resource management framework allowing the execution of applications other than MapReduce on Hadoop clusters.
7. Today, Hadoop has become the foundation of the big data technologies and is being used by most of the major companies for storing and processing huge volumes of data in a distributed manner.
