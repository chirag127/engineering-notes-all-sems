### Hive shell for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

1. Hive is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis.
2. Hive converts SQL queries into MapReduce jobs which are executed on Hadoop cluster.
3. Hive queries are converted into multiple MapReduce jobs based on the tasks required.
4. HiveQL is a query language used to query the data in Hive. It is similar to SQL and provides a SQL-like interface to query and manage large datasets.
5. The Hive shell is an interactive shell where users can enter HiveQL queries to get the results directly without writing code in any programming language. It is easy to learn and use.
6. The results of queries in Hive shell are displayed in a tabular format.
7. Using the Hive shell, we can create, alter, and drop tables/databases and load, query, update, and delete data from tables.
8. The Hive shell can be invoked from the terminal using the command "hive". This will open the Hive shell.
9. The Hive shell provides a mechanism to analyze and query large datasets stored in Hadoop using HiveQL. This makes data analysis scalable and efficient.
