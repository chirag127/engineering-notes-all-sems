### MRv2 for the notes of the Unit 6 - Hadoop Eco System and YARN in the subject of Big Data

1. MRv2 is the upgraded version of MapReduce with enhanced features and capabilities.
2. It works on YARN, a central resource management framework.
3. MRv2 has a client service which schedules jobs, tracks their status and progress.
4. It has a per-job Application Master which negotiates resources from YARN and works with Node Managers to execute and monitor tasks.
5. MRv2 has support for pluggable shuffle handlers and natively supports protocols other than HTTP for shuffle.
6. It has timeline server for job and application level aggregation of metrics and an application web interface for monitoring jobs.
7. MRv2 has extended counters and diagnostic context for applications.
8. It has a faster shuffle phase with configuration of merge thresholds and Writer/Reader selection.
9. MRv2 has security enhancements like container credential provider and per-job delegation tokens.
10. Overall, MRv2 provides higher throughput, scalability, efficiency and richer functionality than traditional MapReduce.
