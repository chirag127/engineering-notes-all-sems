### Built-in Control Structures

1. Conditionals - if/else statements to execute code based on conditions:
- if: Executes code if condition is true
- if/else: Executes code if condition is true, otherwise executes else block
- unless: Executes code unless condition is true

2. Loops - to repeat a block of code:
- for: Repeats code for a fixed number of times
- while: Repeats code while a condition is true
- do/while: Executes code once, then repeats while a condition is true

3. Try/catch - to handle exceptions/errors:
- try: Executes code
- catch: Handles exception if try block fails
- finally: Executes code whether or not an exception occurred in the try block

4. Scala specific features:
- Pattern matching: Matches values against patterns and executes code
- Yield: Used in loops to return multiple values
