### Querying data and user defined functions for the notes of the Unit 11 - Hadoop Eco System

1. HiveQL - HiveQL is a query language for Hive to query data stored in HDFS/Hive. It is similar to SQL and provides a mechanism to project structure onto this data and query the data using a SQL-like language.
2. Hive UDFs - Hive supports user-defined functions (UDFs) to enable users to define their own functions to be used in Hive queries. This allows programmers to extend the functionality of Hive. UDFs can be written in Java or Python and can perform more complex processing than the built-in Hive functions.
3. Pig Latin - Pig Latin is a scripting language that is used with Apache Pig. It is a procedural language that provides a mechanism to analyze large data sets in parallel. Pig Latin abstracts away the complexity of Hadoop and allows users to focus on the analytics.
4. Custom Pig functions - In addition to the built-in functions in Pig, custom functions can be written to extend Pig's functionality. These custom functions can be written in Java, Python, JavaScript, Ruby or Groovy and compiled into the Pig Latin script at compile time. This allows more complex and customized data processing to be performed.
