### Modern Data Analytics Tools

1. Hadoop Ecosystem
- Hadoop Distributed File System (HDFS): Storage
- MapReduce: Processing
- YARN: Resource Management
- Hive: SQL-like queries
- Pig: Scripting language
- Mahout: Machine Learning library

2. Spark
- In-memory cluster computing framework
- Fast processing through Resilient Distributed Datasets (RDDs)
- Supports SQL, Streaming, MLlib machine learning library
- GraphX for graph processing

3. NoSQL Databases
- Document databases: MongoDB, CouchDB
- Key-value stores: Redis, DynamoDB
- Wide-column stores: Cassandra, HBase
- Graph databases: Neo4J, JanusGraph

4. Streaming Analytics
- Process and analyze data in real-time
- Tools: Apache Kafka, Apache Storm, Apache Spark Streaming
- Use cases: Fraud detection, real-time monitoring, IoT data processing

5. Machine Learning Libraries
- MLlib in Apache Spark
- TensorFlow and Keras for deep learning
- Scikit-learn for Python
- Apache Mahout
- Runtime environments: Apache MXNet, Amazon SageMaker
