## Unit 9 - Spark

1. Spark is a fast and general-purpose cluster computing system.
2. It provides high-level APIs in Scala, Java, Python, and R, and an optimized engine that supports general computation graphs for data analysis.
3. Spark runs on Hadoop, standalone, or in the cloud and is capable of accessing diverse data sources including HDFS, Cassandra, HBase, and S3.
4. The main features of Spark are:
- Speed: Spark can run programs up to 100x faster than Hadoop MapReduce in memory, or 10x faster on disk.
- Ease of use: Spark provides simple and expressive APIs in Python, Java, Scala, and SQL, and an optimized engine that supports general computation graphs.
- Generality: You can use Spark to tackle machine learning, SQL, streaming, and graph processing workloads.
- Integration: Spark integrates with Hadoop and can access Hadoop data sources and file formats.
- Advanced analytics: Spark's MLlib library provides common machine learning algorithms with the option of distributed training and SFrame support.
5. The main components of Spark are:
- Spark Core: The underlying general execution engine for distributing and scheduling work.
- Spark SQL: API for working with structured data using SQL and DataFrames.
- Spark Streaming: API for processing data streams and real-time data.
- MLlib: Scalable machine learning library.
- GraphX: Library for graph processing and graph-parallel computation.
