### Pig Latin

Pig Latin is a programming language developed by Yahoo! to analyze large data sets. It is a procedural language that works on HDFS and is translated into MapReduce jobs.

Key points:

- Pig Latin scripts are written in a textual scripting language.
- Pig Latin provides a higher level of abstraction over MapReduce.
- It allows users to write complex MapReduce transformations using simple SQL-like syntax.
- Pig Latin has a rich set of operators to perform various operations like join, filter, group, order, etc.
- Pig Latin scripts are compiled into MapReduce jobs which are executed on a Hadoop cluster.
- Pig Latin has the capability to handle nested data and complex types.
- It provides User Defined Functions (UDF) to implement custom processing logic.
- Pig Latin follows a data flow model and the language is primarily centered around data transformations.

Benefits:

- It is easy to learn for programmers and non-programmers alike.
- It increases the productivity of data analysts and scientists as they can focus on analyzing the data rather than writing tedious code.
- It can handle nested and complex data types easily.
- It provides a variety of operators to transform and process data without the need for custom coding.
- The performance is at par with hand-written MapReduce programs as Pig Latin programs are ultimately converted to MapReduce jobs.
