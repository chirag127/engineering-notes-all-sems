### Spark Applications

1. Spark Core - It has the API for distributed tasks dispatching, scheduling, and basic I/O functionalities.
2. Spark SQL - It is used for structured data processing using SQL and DataFrames. It allows querying data via SQL as well as the DataFrame API.
3. Spark Streaming - It enables scalable, high-throughput, fault-tolerant stream processing of live data streams.
4. MLlib - It is Spark's machine learning library. It provides common machine learning algorithms and utilities.
5. GraphX - It is Spark's API for graphs and graph-parallel computation. It provides an API for expressing graph computation that can be executed in a scalable and fault-tolerant manner on Spark.

The above are the major applications of Spark which can be used for different use cases. Spark Core is the foundation for other libraries. Spark SQL, Streaming and MLlib extend the usage of Spark Core for structured data processing, stream processing and machine learning respectively. GraphX enables graph processing and graph parallelism on Spark.
