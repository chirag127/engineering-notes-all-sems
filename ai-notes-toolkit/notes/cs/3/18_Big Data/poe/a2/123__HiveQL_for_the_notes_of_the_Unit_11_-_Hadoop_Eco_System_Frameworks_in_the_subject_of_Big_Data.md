### HiveQL for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data.

1. HiveQL is a query language for Apache Hive to query data residing in HDFS.
2. It is similar to SQL and converts the queries into MapReduce jobs which are executed on Hadoop.
3. HiveQL supports partitioning of tables and bucketing of tables which optimizes and speeds up the queries.
4. Some of the commonly used clauses in HiveQL are:
- SELECT - to fetch data
- FROM - to specify the input table
- WHERE - to apply filter conditions
- GROUP BY - to aggregate values
- ORDER BY - to sort the results
- JOINs - to join multiple tables
5. HiveQL performs ETL (Extract, Transform, Load) operations on structured as well as semi-structured data in an efficient manner.
6. Some advantages of Hive are:
- Easy to learn for SQL users
- Hides the complexity of MapReduce
- Optimized for large datasets
- Integrates easily with Pig and Spark
- Supports user defined functions (UDFs)
