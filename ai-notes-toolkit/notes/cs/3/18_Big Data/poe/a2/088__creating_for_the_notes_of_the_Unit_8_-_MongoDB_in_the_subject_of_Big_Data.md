### MongoDB

1. MongoDB is a document-oriented NoSQL database used for scalable and distributed systems.
2. MongoDB stores data in JSON-like documents. Fields in a database can vary from document to document and data structure can be changed over time.
3. MongoDB has a flexible schema. This means that documents in a collection can have different fields. This allows you to evolve your data structure quickly and easily.
4. MongoDB supports ad-hoc queries, indexing, and real time aggregation. This makes it a good fit for scalable data storage and analytics.
5. MongoDB uses horizontal scaling, which means that as you increase load, you add more servers into your pool of resources. This allows MongoDB to scale to large data sets and high throughput.
6. MongoDB avoids joins which are expensive in RDBMS systems. Instead, it embeds related data in a single document which avoids expensive joins.
7. MongoDB supports replication and high availability which enables fast failover and server redundancy.
8. Popular use cases of MongoDB are: content management systems, real-time analytics, IoT applications, etc.
