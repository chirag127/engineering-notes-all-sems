### Functions and Closures

- A function is a block of code that performs a specific task. It can be reused and helps in modularizing the code.
- In Scala, a function is defined using the `def` keyword followed by the function name, parameters and the function body enclosed in curly braces.
- The function parameters are variables that take the arguments we pass to the function. The function body contains a sequence of statements that are executed when the function is called.
- A function can return a value using the `return` keyword or simply the expression that evaluates to the return value.
- A closure is a function that retains the references to the variables of its outer scope even after it has exited that scope. This allows the function to access those variables whenever it is called.
- In Scala, closures are implicit. Any function can access variables from outer scopes.
- Closures are useful to create functions that retain some local state and can be used to implement features like memorization, etc.
