### Data Types

1. String - Used to store textual data. Strings in MongoDB must be UTF-8 encoded.
2. Integer - Used to store whole numbers. Includes 32-bit and 64-bit integers.
3. Boolean - Stores true or false values.
4. Double - Used to store floating point values. Represents numbers with decimal points.
5. Min key - Special data type that compares less than all other values. Used for sorting and indexing.
6. Max key - Special data type that compares greater than all other values. Used for sorting and indexing.
7. Array - Used to store arrays or lists of values. Values in an array can be of different data types.
8. Object - Used to store nested documents. The values of the key-value pairs can be of different data types.
9. Null - Represents unknown or empty values.
10. Timestamp - Stores a timestamp with a value of a 64-bit integer specifying the number of milliseconds since the Unix epoch.
11. Date - Stores a date value. Dates are stored as milliseconds since the Unix epoch.
12. Object ID - Stores a 12-byte hexadecimal ID primarily used for uniquely identifying documents.
13. BinData - Stores binary data.
14. Symbol - Stores a unique symbol value.
