### Big Data features – security, compliance, auditing and protection

1. Data Security - Big Data systems store massive amounts of data which makes them a target for security breaches and cyber attacks. Some of the security mechanisms used are:
- Access control - Restricting access to data and analytics to authorized users only.
- Encryption - Converting data into unreadable code that cannot be accessed without a key.
- Tokenization - Replacing sensitive data with unique identification symbols that retain the data's utility without compromising its security.
- Data masking - Hiding specific data elements to protect data privacy.

2. Compliance - Big Data systems need to comply with regulatory requirements such as GDPR, HIPAA, etc. This requires mechanisms to track data provenance, ensure data is used for specific purposes only, delete data when required, etc.
3. Auditing - Detailed logs are maintained to track how data is accessed, modified or deleted. Auditing helps identify security breaches or compliance violations and verify that systems are working as expected.
4. Data Protection - Data needs to be protected from loss, corruption or accidental deletion. This can be achieved through data backups, redundancy, disaster recovery systems, etc.
