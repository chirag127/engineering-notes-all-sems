### Hadoop benchmarks for the notes of the Unit 5 - Hadoop Environment in the subject of Big Data

1. Terasort benchmark:

- Measures the performance of Hadoop in sorting huge amount of data.
- Data is randomly generated with records of 100 bytes.
- Sort time is measured for progressively larger data sizes like 10, 100, 1000 GB etc.
- Generally measures scalability and robustness for very large loads.

2. DFSIO benchmark:

- Checks the I/O performance like read, write in HDFS.
- Generates raw data and writes/reads it from HDFS with varying block sizes and replication factors.
- Measure of throughput and aggregate I/O bandwidth of Hadoop cluster.

3. BigDataBench:

- Diverse workload benchmark to test database systems at scale.
- Includes tasks like data loading, queries, machine learning algorithms etc. simulating typical big data workloads.
- Used to compare configurations and architectures of big data systems with respect to performance for mixed workloads.

4. MrBench:

- Benchmark for testing the performance of complex MapReduce programs.
- Includes jobs from domains like graphs, machine learning, data mining etc. exercising the Map and Reduce functions performance.
- Gives insight into performance bottlenecks of Hadoop cluster for scientific and graph processing type applications.
