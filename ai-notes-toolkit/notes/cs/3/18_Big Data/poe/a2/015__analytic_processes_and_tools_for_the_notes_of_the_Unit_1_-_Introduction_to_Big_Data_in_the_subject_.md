### Analytic Processes and Tools

1. Data Acquisition - Data is collected from various sources like databases, sensors, social media, etc. The data is stored in a data lake.
2. Data Preparation - The data is cleaned and formatted. Missing values are handled and noise is removed.
3. Modeling - Appropriate machine learning models are selected and trained on the prepared data.
4. Evaluation - The performance of the models is evaluated using evaluation metrics to select the best model.
5. Deployment - The best model is deployed for usage in applications.

Some of the tools used in the analytic processes are:

1. Apache Hadoop ecosystem - Used for distributed storage and processing of large data sets. Includes tools like HDFS, MapReduce, Hive, Pig, etc.
2. Apache Spark - An open-source cluster computing framework for processing large data sets. It is faster than Hadoop MapReduce.
3. TensorFlow - An open-source machine learning library for training and deploying machine learning models.
4. Scikit-Learn - A machine learning library for Python with various machine learning algorithms.
5. SQL and NoSQL databases - Used for storing and querying data.

The above points cover the key analytic processes and tools used in big data analysis. The processes and tools used can vary based on the particular use case and organization.
