### Components of Hadoop

1. HDFS - Hadoop Distributed File System
- Master-slave architecture
- Files are split into blocks and distributed across machines
- High fault tolerance
- Scalable and designed for streaming access of large files

2. MapReduce
- Programming model for large scale data processing
- Divides the workload into independent chunks which are processed in parallel
- Output of the map tasks are sorted and input to the reduce tasks
- Fault tolerant

3. YARN
- Resource management platform
- Allocates resources to the applications running on Hadoop
- Decouples resource management and job scheduling/monitoring
- Has resource manager and node manager daemons
