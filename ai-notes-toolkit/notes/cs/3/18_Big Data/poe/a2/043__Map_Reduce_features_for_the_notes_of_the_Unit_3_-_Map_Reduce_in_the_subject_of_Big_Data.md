### Map Reduce features for the notes of the Unit 3 - Map Reduce in the subject of Big Data

1. MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
2. It consists of two major tasks - Map and Reduce.
3. The Map task partitions the input data into independent chunks which are processed by the map tasks in a parallel manner.
4. The Reduce task collects and combines the output of the map tasks and performs some final processing to generate the final output.
5. MapReduce is fault tolerant. If any task fails, it is automatically re-executed on another machine.
6. It is scalable and can handle petabytes of data and thousands of machines.
7. It hides the complexities of parallelization, fault-tolerance, data distribution and load balancing.
8. It is a popular choice for processing huge amounts of data in a distributed fashion due to its simplicity, scalability and efficiency.
