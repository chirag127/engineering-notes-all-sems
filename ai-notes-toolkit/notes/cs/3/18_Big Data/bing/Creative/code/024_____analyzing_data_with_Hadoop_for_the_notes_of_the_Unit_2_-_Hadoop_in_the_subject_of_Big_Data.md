# Analyzing Data with Hadoop

Hadoop is an open source software framework and platform for storing, analyzing and processing large volumes of data in a variety of shapes and forms. Hadoop can help in the analysis of big data by providing the following features :

- **Distributed storage**: Hadoop uses a distributed file system called Hadoop Distributed File System (HDFS) that stores data across multiple nodes in a cluster. HDFS provides high availability, fault tolerance, scalability and parallelism for data storage.
- **Distributed processing**: Hadoop uses a distributed computing model called MapReduce that divides a large data processing task into smaller subtasks and assigns them to different nodes in a cluster. MapReduce provides parallelism, fault tolerance, load balancing and scalability for data processing.
- **Data abstraction**: Hadoop provides a data abstraction layer called Hadoop Common that defines the interfaces and protocols for data access and communication between different components of the Hadoop ecosystem. Hadoop Common also provides libraries and utilities for common tasks such as configuration, logging, serialization, compression, etc.
- **Data integration**: Hadoop provides a data integration layer called Hadoop YARN that manages the resources and scheduling of different applications running on a Hadoop cluster. YARN enables multiple types of data processing frameworks such as batch, interactive, streaming, graph, machine learning, etc. to coexist and share resources on a Hadoop cluster.
- **Data analysis**: Hadoop provides a data analysis layer that consists of various tools and frameworks that can perform different types of analytics on the data stored and processed by Hadoop. Some of the most popular tools and frameworks are   :

  - **Hive**: Hive is a data warehouse system that provides a SQL-like query language called HiveQL for querying and analyzing structured and semi-structured data stored in HDFS. Hive also supports user-defined functions, joins, aggregations, partitions, views, etc.
  - **Pig**: Pig is a data flow language that provides a high-level abstraction for writing complex data transformations and analysis programs. Pig scripts are compiled into MapReduce jobs and executed on a Hadoop cluster. Pig also supports user-defined functions, joins, filters, groupings, etc.
  - **Spark**: Spark is a fast and general-purpose data processing engine that supports batch, interactive, streaming, graph, and machine learning analytics. Spark can run on Hadoop YARN or standalone mode and can access data from HDFS, Hive, HBase, etc. Spark also provides a rich set of APIs in Scala, Java, Python, and R.
  - **HBase**: HBase is a distributed and scalable NoSQL database that provides random read/write access to large amounts of sparse and structured data. HBase is built on top of HDFS and can support real-time and low-latency analytics. HBase also supports secondary indexes, filters, coprocessors, etc.
  - **Mahout**: Mahout is a machine learning library that provides scalable and distributed implementations of various algorithms for classification, clustering, recommendation, etc. Mahout can run on Hadoop MapReduce or Spark and can access data from HDFS, Hive, HBase, etc.
  - **Tableau**: Tableau is a business intelligence and data visualization tool that can connect to various data sources including Hadoop. Tableau can provide interactive and intuitive dashboards, charts, graphs, maps, etc. to explore and communicate insights from big data. Tableau also supports filters, calculations, parameters, etc.
