### HDFS concepts

HDFS is a distributed file system that is designed to store and process large amounts of data on clusters of commodity hardware. HDFS is one of the core components of Apache Hadoop, an open-source framework for big data analytics. HDFS follows the master-slave architecture, where one node acts as the NameNode (master) and the rest of the nodes act as DataNodes (slaves). Some of the key concepts of HDFS are:

- **Blocks**: HDFS divides each file into fixed-size chunks called blocks, which are stored across multiple DataNodes. The default block size is 128 MB, but it can be configured by the user. Each block is replicated on multiple DataNodes for fault tolerance. The number of replicas is also configurable and is usually set to 3. The NameNode maintains the metadata of the file system, such as the file name, size, permissions, block locations, etc. The NameNode also manages the block allocation, replication, and recovery.
- **NameNode**: The NameNode is the master node that controls the file system namespace and regulates the access to files by clients. The NameNode also performs the block management tasks, such as creating, deleting, and replicating blocks. The NameNode stores the metadata of the file system in its main memory for fast access. The metadata is also persisted on the local disk as a file called fsimage, which is a snapshot of the file system state. The NameNode also logs every change to the file system in a file called edit log, which is used to recover the file system state in case of a failure.
- **DataNode**: The DataNode is the slave node that stores and serves the data blocks to the clients. The DataNode also performs the block operations, such as creating, deleting, and replicating blocks, as instructed by the NameNode. The DataNode periodically sends a report of the blocks it is storing to the NameNode, which is called a block report. The DataNode also sends a heartbeat message to the NameNode every few seconds to indicate that it is alive and functioning.
- **Client**: The client is the application that accesses the file system through the HDFS API. The client interacts with the NameNode to obtain the metadata of the file system, such as the file name, size, permissions, block locations, etc. The client then directly communicates with the DataNodes to read or write the data blocks. The client also performs the checksum verification of the data blocks to ensure the data integrity. The client can also perform some administrative tasks, such as creating, deleting, and renaming files or directories, changing the replication factor, etc.
