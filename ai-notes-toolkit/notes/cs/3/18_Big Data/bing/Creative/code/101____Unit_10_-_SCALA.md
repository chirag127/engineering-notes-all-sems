## Unit 10 - SCALA

- Scala is a **general-purpose**, **high-level**, **multi-paradigm** programming language that supports both **object-oriented** and **functional** programming .
- Scala is **strongly** and **statically** typed, meaning that the types of variables and expressions are checked at compile time and cannot be changed at run time .
- Scala is designed to be **concise** and **expressive**, allowing programmers to write less code and avoid boilerplate .
- Scala runs on the **Java Virtual Machine (JVM)** and can interoperate with Java code and libraries. It can also compile to **JavaScript** and run on web browsers or Node.js .
- Scala has many features that make it a powerful and versatile language, such as:
  - **Case classes** and **pattern matching**, which enable concise and elegant data structures and algorithms .
  - **Traits** and **mixins**, which allow multiple inheritance and modular composition of behavior .
  - **Higher-order functions** and **closures**, which enable functional programming and abstraction .
  - **Implicits** and **type classes**, which enable ad-hoc polymorphism and extension of existing types .
  - **Lazy evaluation** and **streams**, which enable efficient and expressive manipulation of infinite or large collections .
  - **Macros** and **metaprogramming**, which enable compile-time code generation and manipulation .
  - **Future** and **Promise**, which enable concurrent and asynchronous programming .
- Scala is an **evolving** language, with new versions and features being released regularly. The latest stable version is **Scala 3.2.2**, which introduces many changes and improvements over Scala 2.
