# Unit 8 - MongoDB

## Introduction

- MongoDB is a popular open-source document-oriented database that stores data in JSON-like format.
- MongoDB is a NoSQL database that does not use tables, rows, and columns to store data, but instead uses collections, documents, and fields.
- MongoDB supports dynamic schema, meaning that documents in the same collection can have different structures and fields.
- MongoDB is designed for scalability, performance, and high availability, and supports sharding, replication, and aggregation.

## MongoDB Terminology

- Database: A logical container for collections of documents.
- Collection: A group of documents that share a common purpose or structure.
- Document: A record of data that consists of one or more fields, each with a value of a specific data type.
- Field: A key-value pair that represents an attribute of a document.
- _id: A special field that is automatically created for every document and serves as a unique identifier.
- BSON: A binary representation of JSON that supports additional data types, such as ObjectId, Date, and Binary.
- Query: A command or expression that specifies the criteria for selecting documents from a collection.
- Projection: A specification of which fields to include or exclude in the query result.
- Update: A command or expression that modifies one or more documents in a collection.
- Index: A data structure that improves the speed and efficiency of queries by providing a sorted map of field values and document locations.
- Aggregation: A process of transforming and analyzing data from a collection using a pipeline of stages, such as match, group, sort, and project.
- Sharding: A method of distributing data across multiple servers or clusters to increase scalability and performance.
- Replica Set: A group of MongoDB servers that maintain the same data set and provide high availability and fault tolerance.
- Primary: The member of a replica set that receives all write operations and replicates them to the other members.
- Secondary: The member of a replica set that replicates the data from the primary and can serve read operations.
- Read Preference: A setting that determines how a client directs read operations to the members of a replica set.
- Write Concern: A setting that determines how a client acknowledges write operations to the members of a replica set.
