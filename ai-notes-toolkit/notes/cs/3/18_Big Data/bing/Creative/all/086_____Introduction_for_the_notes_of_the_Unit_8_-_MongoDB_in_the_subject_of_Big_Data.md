# Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

- MongoDB is a popular open-source document-oriented database that stores data in JSON-like format.
- MongoDB is a NoSQL database that does not use tables, rows, and columns to store data, but instead uses collections, documents, and fields.
- MongoDB is designed for scalability, performance, and high availability, and supports various features such as replication, sharding, indexing, aggregation, text search, geospatial queries, and more.
- MongoDB is widely used for big data applications, as it can handle large volumes of structured, semi-structured, and unstructured data with ease and flexibility.
- MongoDB is compatible with various programming languages and frameworks, and provides drivers and tools for data manipulation and analysis.
- MongoDB follows a schema-less data model, which means that documents in the same collection can have different structures and fields, and the schema can evolve over time.
- MongoDB uses BSON (Binary JSON) as its internal data format, which is a binary-encoded version of JSON that supports additional data types such as date, binary, and ObjectId.
- MongoDB uses CRUD (Create, Read, Update, Delete) operations to manipulate data in the database, and provides various methods and commands for performing these operations.
- MongoDB uses MongoDB Query Language (MQL) to query data in the database, which is a JSON-like syntax that supports various operators and expressions.
- MongoDB uses MongoDB Shell, a JavaScript-based interactive interface, to interact with the database and perform various tasks such as administration, configuration, testing, and debugging.
