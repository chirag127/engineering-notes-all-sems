# History of Hadoop

- Hadoop is an open-source software framework for storing and processing big data in a distributed manner on large clusters of commodity hardware.
- Hadoop was started by Doug Cutting and Mike Cafarella in 2002 when they began working on the Apache Nutch project, which aimed to build a search engine system that could index 1 billion pages.
- The inspiration for Hadoop came from two papers published by Google in 2003 and 2004, describing the Google File System (GFS) and the MapReduce programming model, respectively .
- Cutting, who was working at Yahoo at the time, realized that the existing technologies were not scalable enough to handle the massive amounts of data generated by the web, and decided to implement the Google's ideas in an open-source project.
- He named the project Hadoop after his son's toy elephant. The initial code was contributed to the Nutch project, but later it was moved to a separate subproject under the Apache Software Foundation.
- In 2008, Hadoop broke the world record for sorting 1 terabyte of data in 209 seconds, beating the previous record held by a supercomputer.
- Since then, Hadoop has evolved into a large and diverse ecosystem of related projects that provide various tools and frameworks for big data analytics, such as Pig, Hive, HBase, Spark, Flink, etc .
- Hadoop also introduced new components to its core architecture, such as YARN, a resource manager and scheduler for distributed applications, and Ozone, an object store for Hadoop.
- Hadoop has become one of the most popular and widely used platforms for big data processing, and has been adopted by many organizations across different domains and industries .
