# Unit 8 - MongoDB

MongoDB is a popular open-source document-oriented database that stores data in JSON-like format. MongoDB is designed for scalability, performance, and high availability. MongoDB is part of the NoSQL family of databases, which means it does not use the relational model and SQL language.

Some of the features of MongoDB are:

- Schemaless: MongoDB does not enforce a fixed schema for the documents in a collection. This allows for flexibility and evolution of the data model.
- Indexing: MongoDB supports indexing on any field or combination of fields in a document. Indexes can improve the query performance and support various types of queries, such as text search, geospatial queries, and aggregation.
- Replication: MongoDB supports replication of data across multiple nodes using the replica set feature. A replica set is a group of MongoDB servers that maintain the same data set and provide high availability and data redundancy.
- Sharding: MongoDB supports sharding of data across multiple shards using the sharding feature. A shard is a logical partition of data that is stored on one or more nodes. Sharding can improve the scalability and performance of large data sets by distributing the load and data across multiple servers.
- Aggregation: MongoDB supports aggregation of data using the aggregation framework or the map-reduce function. Aggregation can perform complex data analysis and transformation on the documents in a collection or across multiple collections.
- GridFS: MongoDB supports storing and retrieving large files, such as images, videos, or audio, using the GridFS feature. GridFS divides a file into chunks and stores them as documents in a collection. GridFS also provides metadata and indexing for the files.
