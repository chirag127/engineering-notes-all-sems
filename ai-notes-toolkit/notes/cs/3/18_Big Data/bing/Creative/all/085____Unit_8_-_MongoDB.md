# Unit 8 - MongoDB

MongoDB is an open-source document database and leading NoSQL database. MongoDB is written in C++. This tutorial will give you a basic understanding of MongoDB concepts and how to use MongoDB effectively. 

Some of the topics covered in this tutorial are:

- What is MongoDB and why use it?
- How to install and run MongoDB on different platforms?
- How to create, read, update and delete documents in MongoDB?
- How to use MongoDB operators, expressions and filters?
- How to create and use indexes in MongoDB?
- How to perform aggregation and map-reduce operations in MongoDB?
- How to use MongoDB with various programming languages and frameworks?
- How to use MongoDB Atlas, the cloud service by MongoDB?
- How to use MongoDB Compass, the GUI tool for MongoDB?
- How to secure and backup MongoDB databases?
- How to scale and optimize MongoDB performance?
- How to use MongoDB sharding and replication features?

This tutorial is designed for beginners who want to learn MongoDB in a simple and easy way. You will need a basic knowledge of database concepts and some programming experience to follow this tutorial. You can also use the online tools and exercises provided in this tutorial to practice and test your skills.
