# Modern Data Analytic Tools

- Data analytic tools are software applications that enable users to collect, process, analyze, and visualize data from various sources.
- Data analytic tools can help users to gain insights, make decisions, and solve problems based on data-driven evidence.
- Data analytic tools can be classified into different categories based on their functions, such as data preparation, data exploration, data modeling, data visualization, data reporting, and data mining.
- Some of the modern data analytic tools that are widely used in 2023 are:

  - **Python**: Python is a general-purpose programming language that supports multiple paradigms, such as object-oriented, functional, and procedural. Python has a rich set of libraries and frameworks for data analysis, such as NumPy, pandas, SciPy, scikit-learn, TensorFlow, PyTorch, and Keras . Python also has a large and active community of developers and users who contribute to its development and documentation.
  - **R**: R is a programming language and environment for statistical computing and graphics. R provides a comprehensive collection of packages and functions for data manipulation, analysis, and visualization, such as dplyr, tidyr, ggplot2, shiny, and rmarkdown . R also has a vibrant and diverse community of users and experts who share their knowledge and experience through blogs, forums, and online courses.
  - **SAS**: SAS is a software suite for advanced analytics, business intelligence, data management, and predictive analytics. SAS offers a variety of tools and solutions for data integration, data quality, data governance, data mining, data visualization, and data reporting, such as SAS Enterprise Guide, SAS Visual Analytics, SAS Enterprise Miner, and SAS Viya . SAS also has a strong reputation and presence in the industry, especially in the fields of finance, healthcare, and government.
  - **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel allows users to organize, calculate, and analyze data using formulas, functions, charts, tables, and pivot tables. Excel also supports data import and export from various sources, such as text files, databases, and web pages. Excel can be integrated with other Microsoft tools and services, such as Power Query, Data Model, Power BI Desktop, and Power BI service, to enhance its data analytic capabilities.
  - **Power BI**: Power BI is a cloud-based business analytics service that enables users to create and share interactive dashboards and reports. Power BI can connect to various data sources, such as files, databases, web services, and online platforms. Power BI also provides tools for data transformation, modeling, visualization, and exploration, such as Power Query, Data Model, Power BI Desktop, and Power BI service . Power BI also has a large and growing community of users and developers who create and share custom visuals, templates, and solutions.
  - **Tableau**: Tableau is a software platform for data visualization and business intelligence. Tableau allows users to create and publish interactive dashboards and stories that can be accessed from any device. Tableau can connect to various data sources, such as files, databases, web services, and online platforms. Tableau also provides tools for data preparation, analysis, and exploration, such as Tableau Prep, Tableau Desktop, Tableau Server, and Tableau Online . Tableau also has a passionate and enthusiastic community of users and advocates who share their insights and best practices through blogs, forums, and events.
  - **Apache Spark**: Apache Spark is an open-source distributed computing framework for large-scale data processing. Spark supports multiple programming languages, such as Scala, Python, Java, and R. Spark also provides a rich set of libraries and APIs for data analysis, such as Spark SQL, Spark MLlib, Spark Streaming, and Spark GraphX . Spark also has a high-performance and scalable architecture that can handle data from various sources, such as files, databases, web services, and online platforms.
