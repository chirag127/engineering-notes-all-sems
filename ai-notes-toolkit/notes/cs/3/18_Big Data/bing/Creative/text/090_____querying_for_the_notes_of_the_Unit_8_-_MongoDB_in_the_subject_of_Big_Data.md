### Notes of Unit 8 - MongoDB in Big Data

- MongoDB is a **document-oriented database** that stores data in **JSON-like** format.
- MongoDB is **schema-less**, meaning that the structure of the documents can vary within a collection.
- MongoDB supports **CRUD** operations (**create, read, update, delete**) on the documents using a **query language** similar to JavaScript.
- MongoDB also supports **aggregation** operations to perform complex transformations and analysis on the data.
- MongoDB can be **scaled horizontally** by using **sharding** and **replication** techniques to distribute the data across multiple servers.
- MongoDB is suitable for **big data** applications because it can handle **large volumes** of **unstructured** or **semi-structured** data with **high performance** and **availability**.
