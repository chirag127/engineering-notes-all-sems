### Task Execution for the Notes of the Unit 3 - Map Reduce in the Subject of Big Data

- MapReduce is a programming model that allows processing and generating big data sets with a parallel, distributed algorithm on a cluster.
- MapReduce consists of two phases: Map and Reduce, which are executed by two types of functions: map() and reduce() respectively .
- Map phase: This is the first phase in the execution of a MapReduce job. In this phase, the input data is split into small subsets of data called input splits. Each input split is assigned to a map task, which applies the map() function to the data and produces intermediate key-value pairs as output . The map() function performs filtering and sorting operations on the data.
- Reduce phase: This is the second phase in the execution of a MapReduce job. In this phase, the intermediate key-value pairs from the map tasks are shuffled and sorted by their keys and sent to the reduce tasks. Each reduce task applies the reduce() function to the key-value pairs and produces the final output of the MapReduce job . The reduce() function performs a summary operation on the data, such as aggregation, counting, or averaging.
- MapReduce is a scalable and fault-tolerant model that can handle large volumes of data on clusters of commodity hardware . MapReduce can also be implemented on various platforms, such as Apache Hadoop, Apache Spark, or cloud systems like Amazon Elastic MapReduce (EMR)  .
- MapReduce has many applications in big data analysis, such as web indexing, data mining, machine learning, natural language processing, and image processing . MapReduce can also be combined with other frameworks, such as Apache Pig, Apache Hive, or Apache Mahout, to provide higher-level abstractions and functionalities for big data processing.
