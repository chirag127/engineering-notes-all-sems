### Unit 8 - MongoDB

MongoDB is a popular and widely used Big Data database that can store, query, and analyze large amounts of data in various formats and with high performance and scalability. Some of the key features and concepts of MongoDB are:

- MongoDB is a **document-oriented database** that stores data in JSON-like documents with flexible schemas. This allows for easy data modeling and manipulation, as well as support for a wide range of data types and structures.
- MongoDB is a **distributed database** that can scale horizontally across multiple nodes or clusters using a technique called **sharding**. Sharding partitions the data into smaller chunks and distributes them across the cluster based on a shard key. This enables MongoDB to handle very large data sets and high throughput operations.
- MongoDB is a **NoSQL database** that does not use the traditional relational model or SQL language. Instead, MongoDB uses a powerful and expressive **query language** that supports various operators, filters, aggregations, projections, and updates. MongoDB also supports **indexes** to optimize query performance and **transactions** to ensure data consistency and integrity.
- MongoDB is a **real-time database** that can process and analyze data as it arrives, using features such as **change streams**, **triggers**, and **MongoDB Atlas Data Lake**. Change streams allow applications to subscribe to changes in the data and react accordingly. Triggers enable the execution of custom logic or actions based on data changes. MongoDB Atlas Data Lake allows querying and analyzing data from multiple sources, including MongoDB collections, Amazon S3 buckets, and Apache Kafka topics, using the MongoDB query language.
- MongoDB is a **flexible and versatile database** that can be used for various Big Data applications and use cases, such as **Internet of Things (IoT)**, **social media analytics**, **recommendation engines**, **fraud detection**, **personalization**, and more. MongoDB can also integrate with various Big Data tools and frameworks, such as **Apache Spark**, **Apache Hadoop**, **Apache Kafka**, and **TensorFlow**.
