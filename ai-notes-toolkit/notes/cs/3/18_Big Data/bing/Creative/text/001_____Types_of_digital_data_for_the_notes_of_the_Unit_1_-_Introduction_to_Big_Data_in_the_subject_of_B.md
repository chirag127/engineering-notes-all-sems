### Types of digital data

Digital data is any information that can be stored, processed, or transmitted in a digital form, such as binary digits (bits) or characters. Digital data can be contrasted with analog data, which is represented by a value from a continuous range of real numbers.

There are different types of digital data, depending on the format, structure, and source of the information. Some of the common types of digital data are:

- **Unstructured data**: This type of data has no predefined format or structure, and is usually in the form of text, images, audio, video, or other multimedia. Unstructured data accounts for the majority of the digital data that makes up big data, and is often generated by humans or machines . Examples of unstructured data include:

  - Email
  - Text messages
  - Invoices
  - Text documents
  - Social media posts
  - Web pages
  - Photos
  - Videos
  - Audio files
  - Sensor data

- **Semi-structured data**: This type of data has some level of organization or metadata, but does not conform to a fixed schema or format. Semi-structured data is often in the form of XML, JSON, or CSV files, which can be easily parsed and processed by software applications. Examples of semi-structured data include:

  - Web logs
  - RSS feeds
  - HTML tags
  - XML documents
  - JSON files
  - CSV files
  - Email headers

- **Structured data**: This type of data has a well-defined format and structure, and is usually stored in relational databases or spreadsheets. Structured data is often generated by business applications or transactions, and can be easily queried and analyzed using SQL or other tools. Examples of structured data include:

  - Customer records
  - Product inventory
  - Sales transactions
  - Financial statements
  - Employee data
  - Student grades
  - Weather data

- **Input and output data**: This type of data refers to the information that is provided by users or generated by systems as a result of processing or computation. Input data is the data that is given to a system or application for processing, while output data is the data that is produced by a system or application as a result of processing. Examples of input and output data include:

  - User commands
  - Keyboard strokes
  - Mouse clicks
  - Voice commands
  - Scanned images
  - Printed documents
  - Displayed graphics
  - Audio output
  - Error messages
  - Feedback

Different types of digital data may require different formats, storage, and processing methods, depending on the purpose and context of the data. Some of the common digital data formats are:

- **Text, documentation, scripts**: XML, PDF/A, HTML, Plain Text
- **Still image**: TIFF, JPEG 2000, PNG, JPEG/JFIF, DNG (digital negative), BMP, GIF
- **Geospatial**: Shapefile (SHP, DBF, SHX), GeoTIFF, NetCDF
- **Graphic image**: raster formats: TIFF, JPEG2000, PNG, JPEG/JFIF, DNG, BMP, GIF; vector formats: SVG, EPS, PDF
- **Audio**: WAV, AIFF, FLAC, MP3, AAC, OGG
- **Video**: AVI, MOV, MP4, MKV, MPEG, WMV
- **Tabular data**: CSV, TSV, XLS, XLSX, ODS
- **Database**: SQL, SQLite, MDB, ACCDB
- **Archive**: ZIP, TAR, GZIP, RAR, 7Z
