# Unit 3 - Map Reduce: Test Data and Local Tests

1. Test data refers to the data used to test the functionality and performance of a MapReduce program.
2. It is important to use realistic test data that accurately represents the data that the program will be processing in production.
3. Local tests can be performed on a single machine to test the functionality of the MapReduce program before deploying it to a cluster.
4. Local tests can be performed using the Hadoop LocalRunner, which simulates a MapReduce cluster on a single machine.
5. It is important to perform local tests to ensure that the program is functioning correctly and to identify and fix any issues before deploying it to a cluster.
6. Local tests can also be used to test the performance of the program and to optimize it for better performance on the cluster.
