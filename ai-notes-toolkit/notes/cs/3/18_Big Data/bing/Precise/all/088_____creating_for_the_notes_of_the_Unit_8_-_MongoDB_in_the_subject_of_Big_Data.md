# Unit 8 - MongoDB

MongoDB is a document-based database that stores data in flexible, JSON-like documents. It is a popular choice for big data applications due to its scalability and performance.

Here are some key points to remember about MongoDB:

1. MongoDB is a NoSQL database, meaning it does not use a traditional relational database structure.
2. MongoDB stores data in BSON (Binary JSON) format, which allows for more data types than JSON.
3. MongoDB supports dynamic schemas, meaning the structure of the documents can change over time.
4. MongoDB provides horizontal scalability through sharding, which distributes data across multiple servers.
5. MongoDB has built-in support for aggregation and MapReduce operations, which can be used for data analysis.
6. MongoDB provides drivers for many programming languages, making it easy to integrate with various applications.

These are some of the key features of MongoDB that make it a popular choice for big data applications. It is important to understand these concepts when working with MongoDB in a big data context.
