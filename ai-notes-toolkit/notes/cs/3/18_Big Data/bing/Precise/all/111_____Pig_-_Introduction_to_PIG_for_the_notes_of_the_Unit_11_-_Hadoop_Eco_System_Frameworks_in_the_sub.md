# Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

1. Pig is a high-level platform for creating MapReduce programs used with Hadoop.
2. It is an abstraction over MapReduce that allows developers to write complex data transformations using a simple scripting language called Pig Latin.
3. Pig Latin is a procedural language that allows developers to specify a sequence of data transformations such as filtering, grouping, and joining.
4. Pig translates the Pig Latin script into a series of MapReduce jobs that are executed on the Hadoop cluster.
5. Pig can handle structured, semi-structured, and unstructured data.
6. Pig is commonly used for ETL (Extract, Transform, Load) tasks, data preparation, and ad-hoc data analysis.
7. Pig was developed by Yahoo! and is now an Apache project.
8. Pig can be used with Hadoop on-premises or in the cloud.
9. Pig can be used with other Hadoop ecosystem tools such as Hive, HBase, and Spark.
10. Pig is a powerful tool for data processing and analysis on large datasets.
