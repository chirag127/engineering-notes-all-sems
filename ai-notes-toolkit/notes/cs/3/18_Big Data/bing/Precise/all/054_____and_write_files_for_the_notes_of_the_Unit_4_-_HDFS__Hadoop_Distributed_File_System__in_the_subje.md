### Unit 4 - HDFS (Hadoop Distributed File System)

HDFS is a distributed file system that is designed to store and manage large data sets across multiple machines. Here are some key points to remember about HDFS:

1. HDFS is designed to be highly fault-tolerant and to provide high throughput access to data.
2. HDFS stores data in blocks, with each block being replicated across multiple machines for fault tolerance.
3. HDFS uses a master/slave architecture, with a single NameNode managing the file system metadata and multiple DataNodes storing the actual data.
4. HDFS provides a command line interface for interacting with the file system, as well as a Java API for programmatic access.
5. HDFS is an integral part of the Apache Hadoop ecosystem and is commonly used in big data processing pipelines.
