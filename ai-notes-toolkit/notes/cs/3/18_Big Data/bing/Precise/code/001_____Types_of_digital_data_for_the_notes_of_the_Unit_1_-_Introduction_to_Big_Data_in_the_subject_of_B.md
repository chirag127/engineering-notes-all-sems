### Types of digital data for the notes of the Unit 1 - Introduction to Big Data in the subject of Big Data

Digital data can be classified into several types, including:

1. **Structured data:** This type of data is organized into a specific format or schema, such as a database or spreadsheet. It is easy to search, analyze, and process.

2. **Unstructured data:** This type of data has no specific format or structure, such as text, images, or videos. It is more difficult to search, analyze, and process.

3. **Semi-structured data:** This type of data has some structure, but not as rigid as structured data. Examples include XML or JSON files.

4. **Quantitative data:** This type of data is numerical and can be measured or counted. Examples include height, weight, or temperature.

5. **Qualitative data:** This type of data is non-numerical and is often descriptive. Examples include color, texture, or taste.

6. **Time-series data:** This type of data is collected over time and is used to track changes or trends. Examples include stock prices or weather data.

7. **Spatial data:** This type of data is used to represent geographical information, such as maps or satellite images.

These are some of the common types of digital data that are relevant to the study of Big Data. Understanding the different types of data is important for effectively managing, processing, and analyzing large datasets.
