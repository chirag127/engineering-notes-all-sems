### Real-world Map Reduce

MapReduce is a programming model used to perform distributed processing in parallel in a Hadoop cluster, which makes Hadoop working so fast. When dealing with Big Data, serial processing is no longer of any use. MapReduce has mainly two tasks which are divided phase-wise: Map Task and Reduce Task .

One significant advantage of the Map-Reduce paradigm and its real-world implementations against traditional database systems is fault tolerance. Consider a traditional database system like Teradata .

A real-world example to comprehend the power of MapReduce is Twitter. Twitter receives around 500 million tweets per day, which is nearly 3000 tweets per second. Twitter manages its tweets with the help of MapReduce .
