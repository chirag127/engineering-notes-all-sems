### Unit 8 - MongoDB

MongoDB is a document-based database that stores data in flexible, JSON-like documents. It is a popular choice for big data applications due to its scalability and flexibility.

Here are some key points to remember about MongoDB:

1. MongoDB is a NoSQL database, meaning it does not use the traditional relational database structure.
2. MongoDB stores data in BSON (Binary JSON) format, which allows for more data types than JSON.
3. MongoDB supports dynamic schemas, allowing you to change the structure of your data without having to modify the entire database.
4. MongoDB is horizontally scalable, meaning you can add more servers to handle increasing amounts of data.
5. MongoDB supports sharding, which allows you to distribute data across multiple servers for improved performance and scalability.
6. MongoDB provides built-in aggregation and map-reduce functions for data analysis.
7. MongoDB has a rich query language that allows you to perform complex queries on your data.

These are some of the key features of MongoDB that make it a popular choice for big data applications. It is important to understand these concepts when working with MongoDB in a big data context.
