### Hive shell for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

- Apache Hive is an open-source data warehouse system for querying and analyzing large datasets stored in Hadoop files .
- Hive performs three main functions: data summarization, query, and analysis .
- Hive uses a language called HiveQL (HQL), which is similar to SQL .
- Hive is an ETL (Extract, Transform, Load) and Data warehousing tool used to query or analyze large datasets stored within the Hadoop ecosystem .
- Hive can be used to query and analyze unstructured and semi-structured data in Hadoop .
- Hive runs on top of Hadoop clusters and can be used to query data residing in Amazon EMR (Elastic Map Reduce) clusters, employing an SQL language .
- Hive provides an SQL-like interface to efficiently query and manipulate large data sets residing in various databases and file systems that integrate with Hadoop .
- Hive is a declarative language that is used to develop applications for the Hadoop environment, however, it does not support real-time queries .
- Hive has several components, including HCatalog, which helps data processing tools read and write data on the grid and supports MapReduce and Pig .
