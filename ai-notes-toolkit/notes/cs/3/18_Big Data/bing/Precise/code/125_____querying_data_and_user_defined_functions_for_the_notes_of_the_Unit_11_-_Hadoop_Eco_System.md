### Querying Data and User Defined Functions for the Notes of the Unit 11 - Hadoop Eco System

1. Querying data in Hadoop can be done using various tools and frameworks such as Hive, Pig, and Impala.
2. Hive is a data warehousing and SQL-like query language for Hadoop that allows users to write queries in a familiar SQL syntax.
3. Pig is a high-level platform for creating MapReduce programs used with Hadoop, and it includes a language called Pig Latin for expressing data analysis programs.
4. Impala is a massively parallel processing SQL query engine for Hadoop that provides low latency and high concurrency for BI/analytic queries on Hadoop.
5. User Defined Functions (UDFs) are custom functions written by users to extend the functionality of query languages such as HiveQL and Pig Latin.
6. UDFs can be written in various programming languages such as Java, Python, and Scala, and can be used to perform complex data transformations and analysis.
7. UDFs can be used in queries just like built-in functions, and can be shared and reused by other users.
8. UDFs provide a powerful way to customize and extend the capabilities of Hadoop query languages, allowing users to perform complex data analysis tasks that would otherwise be difficult or impossible to achieve using built-in functions alone.
