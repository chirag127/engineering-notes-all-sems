### Unit 10 - SCALA: Functions and Closures

1. **Functions** in Scala are objects that can be assigned to variables and passed as arguments to other functions.
2. Functions can be defined using the `def` keyword, followed by the function name, parameters, and the function body.
3. Functions can also be defined as **anonymous functions**, also known as **function literals**, which do not have a name and can be assigned to a variable or passed as an argument to another function.
4. A **closure** is a function that references variables from its surrounding scope. These variables are said to be **"captured"** by the closure.
5. Closures can be used to create functions with behavior that depends on the values of the captured variables.
6. In Scala, closures are created automatically when a function references variables from its surrounding scope.
