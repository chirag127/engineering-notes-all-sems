### Unit 10 - SCALA: Basic Types and Operators

Scala has a rich set of basic data types and operators. Here are some of the most commonly used ones:

1. **Numeric Types**: Scala has several numeric types, including `Byte`, `Short`, `Int`, `Long`, `Float`, and `Double`. These types represent 8-bit, 16-bit, 32-bit, and 64-bit signed integers, as well as 32-bit and 64-bit floating-point numbers, respectively.

2. **Boolean Type**: The `Boolean` type represents a value that can be either `true` or `false`.

3. **Character Type**: The `Char` type represents a 16-bit Unicode character.

4. **String Type**: The `String` type represents a sequence of characters.

5. **Arithmetic Operators**: Scala supports the standard arithmetic operators, including `+`, `-`, `*`, `/`, and `%` (modulus).

6. **Relational Operators**: Scala also supports the standard relational operators, including `==`, `!=`, `>`, `<`, `>=`, and `<=`.

7. **Logical Operators**: The logical operators in Scala include `&&` (logical AND), `||` (logical OR), and `!` (logical NOT).

8. **Bitwise Operators**: Scala supports bitwise operators such as `&` (bitwise AND), `|` (bitwise OR), `^` (bitwise XOR), `~` (bitwise NOT), `<<` (left shift), `>>` (right shift), and `>>>` (unsigned right shift).

These are some of the basic types and operators in Scala that are commonly used in Big Data applications. It is important to have a good understanding of these concepts in order to effectively work with data in Scala.
