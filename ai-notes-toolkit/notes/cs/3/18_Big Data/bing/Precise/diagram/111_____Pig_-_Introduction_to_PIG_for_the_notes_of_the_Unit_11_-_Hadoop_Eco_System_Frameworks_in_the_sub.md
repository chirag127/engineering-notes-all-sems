### Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

- Pig is a high-level platform for creating MapReduce programs used with Hadoop.
- It is a data flow language that abstracts the programming from the Java MapReduce idiom into a notation which makes MapReduce programming high level, similar to that of SQL for RDBMS systems.
- Pig Latin is the language used to express data flows in Pig.
- Pig Latin scripts are automatically optimized by the Pig runtime, so the programmer does not have to worry about the execution plan.
- Pig can execute its Hadoop jobs in MapReduce, Apache Tez, or Apache Spark.
- Pig is useful for performing data manipulation operations which are difficult to achieve in MapReduce.
- Pig is designed to handle any kind of data, including structured and unstructured data and relational and nested data.
- Pig is commonly used for ETL (Extract, Transform, Load) processing, research on raw data, and iterative processing.
- Pig is an open-source project under the Apache Software Foundation.
