### Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

1. MongoDB is a document-based, NoSQL database that is designed to handle large volumes of structured and unstructured data.
2. It is a cross-platform database that is written in C++ and is open-source.
3. MongoDB stores data in BSON format, which is a binary representation of JSON.
4. It is a schema-less database, which means that the structure of the data can change over time.
5. MongoDB is designed to be scalable, with built-in support for sharding and replication.
6. It is widely used in big data applications due to its ability to handle large amounts of data and its flexible data model.
7. MongoDB provides a rich set of features for querying and indexing data, making it a powerful tool for data analysis.
8. It is used by many large companies, including Facebook, Google, and Adobe.
