### Unit 11 - Hadoop Eco System Frameworks: Pig Latin

1. Pig Latin is a high-level platform for creating MapReduce programs used with Hadoop.
2. It is a scripting language that is used to process and analyze large data sets.
3. Pig Latin abstracts the programming from the Java MapReduce idiom into a notation which makes MapReduce programming high level, similar to that of SQL for RDBMS systems.
4. Pig Latin programs are executed as a series of MapReduce jobs.
5. Pig Latin includes many built-in functions for common data operations such as filtering, grouping, and joining.
6. Pig Latin can also be extended using User Defined Functions (UDFs) written in Java, Python, or other languages.
7. Pig Latin is typically used for data analysis, data transformation, and data manipulation tasks.
8. Pig Latin scripts can be run in two modes: local mode and MapReduce mode. In local mode, Pig runs on a single machine, while in MapReduce mode, Pig runs on a Hadoop cluster.
