### Unit 10 - SCALA: Functions and Closures

1. **Functions** in Scala are objects that can be assigned to variables, passed as arguments to other functions, and returned as values from other functions.
2. Functions can be defined using the `def` keyword, followed by the function name, parameter list, return type, and function body.
3. Functions can also be defined as **anonymous functions**, also known as **function literals**, using the `=>` syntax.
4. A **closure** is a function that references variables from its surrounding scope. The function can access and modify these variables even when it is invoked outside of its defining scope.
5. Closures are useful for creating functions with behavior that depends on data that is not passed as arguments.
6. In Scala, closures are automatically created when a function references variables from its surrounding scope.
