### Avro and file-based data structures for the notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the subject of Big Data

1. **Avro** is a data serialization system that is used to encode data into a compact binary format.
2. It is designed to support data-intensive applications and is commonly used in the Hadoop ecosystem.
3. Avro provides rich data structures, a compact binary data format, and a container file for storing persistent data.
4. Avro data is stored in a file-based data structure, which is a way of organizing data on disk that allows for efficient access and manipulation.
5. File-based data structures are commonly used in big data systems, as they provide a way to store and retrieve large amounts of data quickly and efficiently.
6. HDFS, or Hadoop Distributed File System, is a distributed file system that is designed to store and manage large data sets across multiple machines.
7. HDFS is built on top of the local file systems of the machines in the cluster and provides a single, unified view of the data stored across all of the machines.
8. Avro can be used in conjunction with HDFS to store and retrieve data in a distributed environment.
9. Avro data can be stored in HDFS as a sequence of Avro container files, which can be accessed and processed in parallel by multiple machines in the cluster.
10. This allows for efficient processing of large data sets using tools such as MapReduce and Spark.
