### Unit 3 - Map Reduce

MapReduce is a programming model and an associated implementation for processing and generating large data sets. Here are some of its features:

1. **Scalability:** MapReduce can process large amounts of data by dividing the work among multiple nodes in a cluster.
2. **Fault tolerance:** MapReduce can handle node failures by reassigning the work to other nodes in the cluster.
3. **Data locality:** MapReduce tries to move the computation to the data, rather than moving the data to the computation, to minimize data transfer and improve performance.
4. **Simplicity:** MapReduce abstracts the complexity of distributed processing, allowing developers to focus on the logic of their application.
5. **Flexibility:** MapReduce can be used for a wide range of data processing tasks, including data filtering, sorting, and aggregation.
