## Unit 5 - Hadoop Environment

Hadoop is an open-source software framework for storing and processing large datasets using distributed computing. The Hadoop environment consists of several components, including:

1. **Hadoop Distributed File System (HDFS)**: A distributed file system that provides high-throughput access to application data.

2. **MapReduce**: A programming model for processing large datasets in parallel across a cluster of computers.

3. **YARN**: A resource management platform responsible for managing compute resources in clusters and using them for scheduling of users' applications.

4. **Hadoop Common**: A set of common utilities that support the other Hadoop modules.

5. **Other components**: Hadoop ecosystem also includes other components such as Hive, Pig, HBase, and ZooKeeper, which provide additional functionality for data processing and management.

In a Hadoop environment, data is stored in HDFS and processed using MapReduce. YARN is responsible for managing resources and scheduling tasks, while Hadoop Common provides common utilities for the other components. The other components in the Hadoop ecosystem provide additional functionality for data processing and management.
