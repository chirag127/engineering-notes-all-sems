### Unit 8 - MongoDB

MongoDB is a document-based, NoSQL database that is used to store and manage large volumes of data. Here are some key points to note about MongoDB:

1. MongoDB stores data in flexible, JSON-like documents, meaning fields can vary from document to document and data structure can be changed over time.
2. MongoDB is a distributed database at its core, so high availability, horizontal scaling, and geographic distribution are built in and easy to use.
3. MongoDB is free and open-source, published under the Server Side Public License (SSPL).
4. MongoDB supports dynamic queries on documents using a document-based query language that's nearly as powerful as SQL.
5. MongoDB provides drivers for a variety of programming languages, making it easy to integrate with existing applications.
