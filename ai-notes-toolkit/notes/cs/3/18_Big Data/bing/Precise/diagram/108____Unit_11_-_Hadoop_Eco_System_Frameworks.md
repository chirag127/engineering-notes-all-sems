## Unit 11 - Hadoop Eco System Frameworks

The Hadoop ecosystem is a collection of frameworks and tools that work together to process and analyze large amounts of data. Some of the key frameworks in the Hadoop ecosystem include:

1. **Hadoop Distributed File System (HDFS)**: A distributed file system that provides high-throughput access to application data.

2. **MapReduce**: A programming model for processing large data sets with a parallel, distributed algorithm on a cluster.

3. **YARN**: A resource management platform responsible for managing compute resources in clusters and using them for scheduling of users' applications.

4. **HBase**: A non-relational, distributed database that runs on top of HDFS.

5. **Hive**: A data warehousing and SQL-like query language for Hadoop.

6. **Pig**: A platform for analyzing large data sets that consists of a high-level language for expressing data analysis programs, coupled with infrastructure for evaluating these programs.

7. **Spark**: An open-source, distributed computing system that can process data up to 100 times faster than MapReduce.

8. **ZooKeeper**: A centralized service for maintaining configuration information, naming, providing distributed synchronization, and providing group services.

These frameworks and tools are designed to work together to provide a comprehensive solution for processing and analyzing large amounts of data. They can be used individually or in combination to meet the specific needs of different applications and use cases.
