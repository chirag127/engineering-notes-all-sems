## Unit 4 - HDFS (Hadoop Distributed File System)

HDFS is a distributed file system that is designed to run on commodity hardware. It is highly fault-tolerant and is designed to be deployed on low-cost hardware. HDFS provides high throughput access to application data and is suitable for applications that have large data sets.

Some key features of HDFS include:
- **Scalability:** HDFS can easily scale to handle petabytes of data by simply adding more nodes to the cluster.
- **Data Reliability:** HDFS replicates data across multiple nodes to ensure data reliability and availability.
- **High Availability:** HDFS is designed to be highly available, with features such as automatic failover and data replication.
- **Cost Effective:** HDFS is designed to run on commodity hardware, making it a cost-effective solution for storing large amounts of data.
- **Ease of Use:** HDFS is easy to use and provides a command-line interface for interacting with the file system.

HDFS is an important component of the Apache Hadoop ecosystem and is used by many big data applications to store and process large amounts of data. It is a key technology for enabling big data analytics and is widely used in industries such as finance, healthcare, and retail.
