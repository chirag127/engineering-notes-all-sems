### Functions and Closures for the Notes of the Unit 10 - SCALA in the Subject of Big Data

1. **Functions** in Scala are objects that can be assigned to variables, passed as arguments to other functions, and returned as values from other functions.
2. Functions can be defined using the `def` keyword, followed by the function name, parameter list, return type, and function body.
3. Functions can also be defined as **anonymous functions**, also known as **function literals**, which do not have a name and can be assigned to a variable or passed as an argument to another function.
4. **Closures** are functions that can access variables from their enclosing scope, even if the function is invoked outside of that scope.
5. Closures are useful for creating functions that can operate on data that is not passed as an argument to the function.
6. In Scala, closures are created automatically when a function accesses a variable from its enclosing scope.
7. Closures can be used to create functions with state, where the state is stored in the variables accessed by the closure.
