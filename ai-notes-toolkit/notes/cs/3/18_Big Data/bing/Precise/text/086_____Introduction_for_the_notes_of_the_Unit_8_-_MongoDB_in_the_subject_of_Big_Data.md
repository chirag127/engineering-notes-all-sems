### Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

1. MongoDB is a document-based database management system.
2. It is a NoSQL database, meaning it does not use the traditional relational database structure.
3. MongoDB stores data in flexible, JSON-like documents, allowing for dynamic schemas.
4. It is designed to handle large amounts of data and is often used in big data applications.
5. MongoDB offers features such as indexing, aggregation, and text search to facilitate data analysis.
6. It is an open-source software, with a large and active community of developers.
7. MongoDB is used by many large companies, including Adobe, eBay, and MetLife.
8. It is part of the MEAN stack, a popular technology stack for building web applications.
