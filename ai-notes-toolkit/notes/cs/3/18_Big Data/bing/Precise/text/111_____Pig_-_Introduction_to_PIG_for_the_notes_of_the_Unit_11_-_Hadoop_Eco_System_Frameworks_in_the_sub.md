### Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

- Apache Pig is a high-level platform for creating programs that run on Apache Hadoop.
- Pig is designed to handle any kind of data, including structured and unstructured data, and is particularly useful for data analysis tasks.
- Pig programs are written in a language called Pig Latin, which is similar to SQL and is easy to learn for anyone familiar with scripting languages.
- Pig Latin scripts are automatically translated into MapReduce jobs by the Pig interpreter, allowing developers to focus on the logic of their data analysis tasks rather than the underlying implementation details.
- Pig is an important part of the Hadoop ecosystem, and is widely used by data scientists and engineers for big data analysis tasks.
- Pig can be used with other Hadoop ecosystem tools such as Hive, HBase, and Spark to build powerful data processing pipelines.
- Pig is open-source software and is freely available for anyone to use.
