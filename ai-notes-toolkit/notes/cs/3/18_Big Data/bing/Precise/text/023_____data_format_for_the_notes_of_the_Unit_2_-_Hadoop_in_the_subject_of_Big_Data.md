### Data Format for the Notes of the Unit 2 - Hadoop in the Subject of Big Data

1. Hadoop is an open-source software framework for storing and processing large datasets.
2. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
3. Hadoop uses a distributed file system called HDFS (Hadoop Distributed File System) to store data.
4. HDFS splits large files into blocks and distributes them across the nodes in the cluster.
5. Hadoop also includes a processing component called MapReduce, which allows for the parallel processing of data stored in HDFS.
6. MapReduce works by dividing the processing task into smaller sub-tasks, which are then assigned to different nodes in the cluster for processing.
7. The results of these sub-tasks are then combined to produce the final result.
8. Hadoop is commonly used for big data applications such as data mining, data analysis, and machine learning.
9. It is widely used in industries such as finance, healthcare, and retail.
10. Hadoop is written in Java and is supported by a large and active community of developers.
