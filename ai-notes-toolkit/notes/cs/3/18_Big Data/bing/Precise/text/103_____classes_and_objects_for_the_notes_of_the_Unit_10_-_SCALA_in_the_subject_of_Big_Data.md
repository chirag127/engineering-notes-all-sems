### Classes and Objects in Scala

Scala is an object-oriented programming language, which means that it is based on the concept of objects. An object is an instance of a class, and a class is a blueprint for creating objects.

Here are some key points to remember about classes and objects in Scala:

1. A class is defined using the `class` keyword, followed by the name of the class and a pair of curly braces `{}` containing the class body.
2. The class body can contain fields (also known as instance variables) and methods (also known as member functions).
3. Fields are defined using `val` or `var`, followed by the name of the field and its type. `val` fields are immutable, while `var` fields are mutable.
4. Methods are defined using the `def` keyword, followed by the name of the method, a pair of parentheses `()` containing the method's parameters, an optional return type, and a pair of curly braces `{}` containing the method body.
5. An object is created by calling the class constructor, which is a special method that is automatically generated by the Scala compiler. The constructor has the same name as the class and is called using the `new` keyword.
6. Once an object is created, its fields and methods can be accessed using the dot `.` operator.

Here is an example of a simple class and object in Scala:

```scala
class Person(val name: String, var age: Int) {
  def greet(): Unit = {
    println(s"Hello, my name is $name and I am $age years old.")
  }
}

val p = new Person("Alice", 25)
p.greet() // prints "Hello, my name is Alice and I am 25 years old."
p.age = 26
p.greet() // prints "Hello, my name is Alice and I am 26 years old."
```

In this example, we define a `Person` class with two fields (`name` and `age`) and one method (`greet`). We then create an object of the `Person` class using the `new` keyword and call its `greet` method. We also update the value of the `age` field and call the `greet` method again to see the updated value.
