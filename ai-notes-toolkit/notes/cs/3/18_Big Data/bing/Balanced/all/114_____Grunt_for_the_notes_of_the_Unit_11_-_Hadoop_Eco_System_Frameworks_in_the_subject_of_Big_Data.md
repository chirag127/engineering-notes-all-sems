# Grunt

- Grunt is Pig's interactive shell that allows users to enter Pig Latin commands and interact with HDFS .
- Grunt can be invoked by typing `pig` command with no script or command to run.
- Grunt can run in local mode or hadoop mode depending on the `-x` option .
- Grunt supports shell and utility commands that can be used to manipulate files, set properties, define aliases, run scripts, etc.
- Grunt can also execute Pig scripts by using `exec` or `run` commands.
- Grunt can be exited by typing `quit` or `exit` commands.
