# Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

- Pig is a tool for processing and analyzing large data sets, also known as big data, using a high-level scripting language called Pig Latin .
- Pig provides an abstraction over MapReduce, which is a framework for parallel processing of data on a cluster of machines .
- Pig can run on top of Hadoop, which is a popular open-source platform for distributed storage and processing of big data  .
- Pig can also run on other platforms that support MapReduce, such as Apache Spark.
- Pig allows users to write data analysis programs in a declarative way, without worrying about the low-level details of MapReduce .
- Pig can handle structured, semi-structured, and unstructured data, and can perform various operations such as filtering, grouping, joining, sorting, aggregating, and transforming data  .
- Pig can also integrate with other tools and languages, such as Python, Java, and R, for more complex data analysis tasks  .
- Pig is widely used by data scientists, engineers, and analysts for big data applications, such as web analytics, social media analysis, text processing, and machine learning  .
