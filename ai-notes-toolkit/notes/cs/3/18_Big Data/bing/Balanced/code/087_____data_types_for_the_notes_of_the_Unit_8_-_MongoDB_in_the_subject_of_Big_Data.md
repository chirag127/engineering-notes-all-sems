### Data types

- MongoDB supports various data types that can be used to store different kinds of values in the database.
- Some of the common data types are:

  - **String**: This is the most basic data type. It is used to store text values. A string must be enclosed in double quotes. For example, `"Hello world"`.
  - **Number**: This is used to store numeric values. MongoDB supports two types of numbers: **integers** and **doubles**. Integers are whole numbers, such as `42`. Doubles are decimal numbers, such as `3.14`.
  - **Boolean**: This is used to store logical values. It can be either `true` or `false`.
  - **Array**: This is used to store a list of values. An array can contain values of any data type. An array must be enclosed in square brackets. For example, `[1, 2, 3]` or `["red", "green", "blue"]`.
  - **Object**: This is used to store a collection of key-value pairs. An object can contain values of any data type. An object must be enclosed in curly braces. For example, `{"name": "Alice", "age": 25}` or `{"scores": [90, 80, 70]}`.
  - **ObjectId**: This is a special data type that is used to store the unique identifier of a document. An ObjectId is a 12-byte hexadecimal string that is automatically generated by MongoDB when a document is inserted. For example, `ObjectId("507f1f77bcf86cd799439011")`.
  - **Date**: This is used to store date and time values. A date value must be created using the `new Date()` constructor. For example, `new Date("2021-03-15T20:51:47Z")`.
  - **Null**: This is used to represent a missing or unknown value. It is written as `null`.
  - **Binary**: This is used to store binary data, such as images, audio, or video files. A binary value must be created using the `new BinData()` constructor. For example, `new BinData(0, "c29tZSBiaW5hcnkgZGF0YQ==")`.
  - **Other**: There are some other data types that are less commonly used, such as **regex**, **code**, **symbol**, **minKey**, and **maxKey**. You can learn more about them in the official MongoDB documentation.
