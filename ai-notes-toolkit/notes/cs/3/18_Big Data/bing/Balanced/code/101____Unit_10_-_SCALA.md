## Unit 10 - SCALA

- Scala is a **strong statically typed** high-level general-purpose programming language that supports both **object-oriented programming** and **functional programming** .
- Scala is designed to be **concise**, and many of its design decisions are aimed to address criticisms of Java.
- Scala programs can compile to **bytecodes** and run on the **JVM (Java Virtual Machine)** or the **JavaScript runtimes** .
- Scala has a **unified type system**, where everything is an object and every operation is a method call.
- Scala supports **multiple inheritance** through **traits**, which are abstract classes that can contain fields and methods.
- Scala supports **pattern matching**, **higher-order functions**, **lazy evaluation**, **immutability**, **tail recursion**, and **currying** as some of the functional programming features .
- Scala also supports **implicits**, which are a way of defining **implicit conversions** and **implicit parameters** that can enhance the expressiveness and readability of the code.
- Scala has a powerful **macro system** that allows programmers to extend the language and generate code at compile time.
- Scala has a rich and diverse **ecosystem** of libraries and frameworks, such as **Akka**, **Spark**, **Play**, **ScalaTest**, and **Scalaz**.
