# Unit 8 - MongoDB

## Introduction

MongoDB is a popular open-source document-oriented database that stores data in JSON-like format. MongoDB is designed for scalability, performance, and flexibility. MongoDB is part of the NoSQL family of databases, which means it does not use the traditional relational model of tables, rows, and columns. Instead, MongoDB organizes data into collections of documents, where each document can have a different structure and schema. MongoDB supports dynamic queries, indexing, aggregation, replication, sharding, and transactions.

Some of the advantages of MongoDB are:

- It can handle large volumes of data with high availability and scalability.
- It can store complex and heterogeneous data types, such as nested objects, arrays, and geospatial data.
- It can support schema evolution and data modeling without requiring schema migrations or joins.
- It can provide fast and flexible queries and updates, with support for full-text search, geospatial queries, and aggregation pipelines.
- It can integrate with various programming languages and frameworks, such as Java, Python, Node.js, and Spring Boot.

Some of the challenges of MongoDB are:

- It may not be suitable for applications that require complex transactions, joins, or referential integrity.
- It may consume more disk space and memory than relational databases, due to its document-oriented nature and lack of normalization.
- It may require more application logic and validation to ensure data consistency and quality.
- It may have some limitations in terms of security, backup, and recovery options.

- How to use the MongoDB shell and GUI tools to interact with the database.

- How to perform various types of queries and updates in MongoDB, such as simple queries, projection, filtering, sorting, aggregation, and update operators.
- How to create and use indexes in MongoDB to improve query performance and support specific query types, such as text and geospatial indexes.
- How to implement replication and sharding in MongoDB to achieve high availability and scalability.
- How to use transactions in MongoDB to perform atomic and consistent operations across multiple documents and collections.
