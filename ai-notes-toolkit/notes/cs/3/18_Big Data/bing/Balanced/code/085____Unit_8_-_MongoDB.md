## Unit 8 - MongoDB

MongoDB is a popular open-source document-oriented database that stores data in JSON-like format. MongoDB is part of the NoSQL family of databases, which means it does not use the relational model of tables, rows, and columns. Instead, MongoDB organizes data into collections of documents, where each document can have a different structure and schema.

Some of the main features and benefits of MongoDB are:

- Flexible and dynamic schema: MongoDB allows you to store documents with varying fields and types, without having to predefine the schema or modify it as the data changes. This gives you more flexibility and agility to model your data according to your application needs.
- Scalability and performance: MongoDB supports horizontal scaling, which means you can distribute your data across multiple servers or clusters to handle large volumes of data and high throughput. MongoDB also provides various features to optimize performance, such as indexing, sharding, replication, and aggregation.
- Rich query language and tools: MongoDB supports a powerful and expressive query language that allows you to perform complex operations on your data, such as filtering, sorting, grouping, aggregating, updating, and deleting. MongoDB also provides various tools and drivers to interact with your database from different programming languages and platforms.

In this unit, you will learn the basics of MongoDB, such as:

- How to install and run MongoDB on your local machine or on a cloud service.
- How to create, read, update, and delete documents in MongoDB using the mongo shell or a GUI tool.
- How to create and use indexes to improve the performance and efficiency of your queries.
- How to use aggregation pipelines to perform advanced data analysis and manipulation on your collections.
- How to use MongoDB Compass, a graphical user interface tool, to explore and manage your data and schema.
- How to use MongoDB Atlas, a cloud-based service, to deploy and manage your MongoDB clusters.
- How to use MongoDB Stitch, a serverless platform, to create and access your MongoDB data from web and mobile applications.
