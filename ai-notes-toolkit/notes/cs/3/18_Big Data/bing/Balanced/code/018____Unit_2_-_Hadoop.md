## Unit 2 - Hadoop

Hadoop is an open-source framework that allows to store and process big data in a distributed environment across clusters of computers using simple programming models. Hadoop is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

Some of the main features and benefits of Hadoop are:

- It can handle any type of data, whether structured, unstructured, or semi-structured.
- It can process large volumes of data in parallel, using a technique called MapReduce.
- It can store data in a fault-tolerant way, using a technique called Hadoop Distributed File System (HDFS).
- It can run on commodity hardware, reducing the cost and complexity of data management.
- It can support a variety of applications, such as data analysis, machine learning, data mining, and web crawling.

Some of the main components of Hadoop are:

- HDFS: A distributed file system that provides high-throughput access to data and ensures data reliability.
- MapReduce: A programming model that allows to process large data sets in parallel, using key-value pairs.
- YARN: A resource management layer that allocates and schedules resources for different applications running on Hadoop.
- Hadoop Common: A set of libraries and utilities that support the other Hadoop modules.
- Hadoop Ecosystem: A collection of tools and frameworks that extend the functionality of Hadoop, such as Hive, Pig, Spark, HBase, and Flume.
