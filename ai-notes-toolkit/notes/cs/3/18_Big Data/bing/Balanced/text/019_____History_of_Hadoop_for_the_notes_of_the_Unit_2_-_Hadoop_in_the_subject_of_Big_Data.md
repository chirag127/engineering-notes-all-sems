### History of Hadoop

- Hadoop is an open-source software framework for storing and processing big data in a distributed manner on large clusters of commodity hardware.
- Hadoop was started by Doug Cutting and Mike Cafarella in 2002, when they began working on the Apache Nutch project, which aimed to build a search engine system that could index 1 billion pages .
- The inspiration for Hadoop came from two papers published by Google in 2003 and 2004, describing the Google File System (GFS) and the MapReduce programming model, respectively  .
- Cutting, who was working at Yahoo at the time, realized that the existing technologies were not scalable enough to handle the massive amounts of data generated by the web, and decided to implement the Google's ideas in an open-source project .
- He named the project Hadoop after his son's toy elephant .
- In 2006, Yahoo donated the Nutch project to the Apache Software Foundation, where it became a subproject of Lucene, a text search engine library .
- In 2008, Hadoop became a top-level Apache project, and also achieved a major milestone by sorting 1 terabyte of data in 209 seconds, beating the previous record held by a supercomputer .
- Since then, Hadoop has evolved into a large and diverse ecosystem of components and subprojects that support a variety of use cases and workloads for big data analytics .
- Some of the major components and subprojects of Hadoop are:

  - Hadoop Common – a set of utilities and libraries that support other Hadoop modules.
  - Hadoop Distributed File System (HDFS) – a distributed file system that provides high-throughput access to application data and can store data across thousands of nodes .
  - Hadoop YARN – a platform that manages computing resources in clusters and schedules user applications.
  - Hadoop MapReduce – an implementation of the MapReduce programming model for large-scale data processing.
  - Hadoop Ozone – an object store for Hadoop that can handle billions of files and supports multiple protocols.
  - Hadoop ZooKeeper – a service that provides coordination and configuration management for distributed applications.
  - Hadoop HBase – a distributed, column-oriented database that provides random, real-time access to big data.
  - Hadoop Hive – a data warehouse system that provides data summarization, query, and analysis using a SQL-like language called HiveQL.
  - Hadoop Pig – a platform that provides a high-level language called Pig Latin for data analysis and transformation.
  - Hadoop Spark – a fast and general engine for large-scale data processing that supports batch, streaming, SQL, machine learning, and graph analytics.
  - Hadoop Mahout – a library that provides scalable machine learning algorithms for clustering, classification, and recommendation.
  - Hadoop Flume – a service that collects, aggregates, and moves large amounts of log data from various sources to HDFS.
  - Hadoop Sqoop – a tool that transfers data between Hadoop and relational databases.
  - Hadoop Oozie – a workflow scheduler that manages and coordinates Hadoop jobs.
  - Hadoop Ambari – a web-based tool that simplifies the provisioning, management, and monitoring of Hadoop clusters.

- Hadoop has become one of the most popular and widely used frameworks for big data processing, and has been adopted by many organizations across various domains, such as web, social media, e-commerce, finance, healthcare, education, and government.
- Hadoop is also constantly evolving and improving, with new features, enhancements, and bug fixes being added by the active and vibrant community of developers and contributors.
