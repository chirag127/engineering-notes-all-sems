### Map Reduce types for the notes of the Unit 3 - Map Reduce in the subject of Big Data

- MapReduce is a framework for processing parallelizable problems across large datasets using a large number of computers (nodes), collectively referred to as a cluster or a grid.
- MapReduce divides a task into smaller parts and assigns them to many devices. Then the end results will be collected in one place and integrate to form effective data sets.
- MapReduce consists of two phases: map and reduce. The map phase takes input pairs, processes them, and produces another set of intermediate pairs as output. The reduce phase takes the intermediate pairs, groups them by key, and performs some aggregation or computation on the values.
- MapReduce can be used for various types of big data analysis, such as:
  - Entertainment: Hadoop MapReduce assists end users in finding the most popular movies based on their preferences and previous viewing history.
  - E-commerce: Several e-commerce companies, such as Flipkart, Amazon, and eBay, employ MapReduce to evaluate consumer buying patterns based on customers’ interests or historical purchasing patterns.
  - Social media: MapReduce can be used to analyze social media data, such as tweets, posts, likes, shares, etc., to understand user behavior, sentiment, trends, and preferences.
  - Data warehouse: MapReduce can be used to perform extract, transform, and load (ETL) operations on large volumes of structured and unstructured data from various sources, such as databases, files, web logs, etc., and store them in a data warehouse for further analysis.
  - Fraud detection: MapReduce can be used to detect fraudulent transactions, activities, or behaviors by applying various algorithms and models on big data.
