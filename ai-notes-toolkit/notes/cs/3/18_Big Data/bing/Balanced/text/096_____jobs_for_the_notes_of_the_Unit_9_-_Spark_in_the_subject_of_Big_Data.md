### Jobs for the notes of the Unit 9 - Spark in the subject of Big Data

- Spark is an open-source framework for distributed data processing and analytics on large-scale datasets.
- Spark supports multiple programming languages, such as Scala, Python, Java, and R, and provides various libraries for SQL, streaming, machine learning, and graph analysis.
- Spark runs on a cluster of machines, where each machine is called a node. A node can be either a master or a worker. The master node coordinates the execution of tasks across the worker nodes, and the worker nodes run the tasks and store the data partitions.
- Spark uses a data abstraction called resilient distributed dataset (RDD), which is a collection of elements that can be operated on in parallel. RDDs can be created from various sources, such as files, databases, or existing collections, and can be transformed and cached in memory or disk.
- Spark also provides a higher-level data abstraction called DataFrame, which is a distributed collection of rows organized into named columns. DataFrames can be created from various sources, such as RDDs, files, databases, or external APIs, and can be manipulated using SQL or domain-specific language (DSL).
- Spark supports two types of operations on RDDs and DataFrames: transformations and actions. Transformations create new RDDs or DataFrames from existing ones, such as map, filter, join, or groupBy. Actions trigger the computation of RDDs or DataFrames and return the results to the driver program or write them to external storage, such as count, collect, save, or show.
- Spark uses a lazy evaluation strategy, which means that transformations are not executed until an action is performed. This allows Spark to optimize the execution plan and avoid unnecessary computations.
- Spark also supports a feature called lineage, which is the sequence of transformations that are applied to an RDD or a DataFrame. Lineage helps Spark to recover from failures by recomputing the lost partitions from the source data or the cached data.
- Spark can run on various cluster managers, such as Hadoop YARN, Apache Mesos, or Kubernetes, or in a standalone mode. Spark also provides a web-based user interface (UI) to monitor the status and performance of the applications and the cluster.
- Spark is widely used for big data applications, such as data engineering, data analysis, data science, and machine learning. Spark offers several advantages over traditional MapReduce frameworks, such as faster processing, lower memory consumption, higher-level APIs, and rich libraries.
