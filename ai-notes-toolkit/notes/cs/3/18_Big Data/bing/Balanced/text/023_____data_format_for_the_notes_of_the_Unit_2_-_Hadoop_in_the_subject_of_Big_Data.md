### Data format for the notes of the Unit 2 - Hadoop in the subject of Big Data

- Hadoop is a framework for distributed processing of large-scale data sets across clusters of computers.
- Hadoop consists of four main components: Hadoop Distributed File System (HDFS), MapReduce, YARN, and Hadoop Common.
- HDFS is a distributed file system that provides high-throughput access to data stored on multiple nodes in a cluster.
- MapReduce is a programming model and an execution engine for parallel processing of data using a map function and a reduce function.
- YARN is a resource manager that allocates and manages resources for applications running on Hadoop.
- Hadoop Common is a set of libraries and utilities that support the other components of Hadoop.
- Hadoop can run on commodity hardware and scale up to thousands of nodes and petabytes of data.
- Hadoop provides fault tolerance, reliability, availability, and scalability for data-intensive applications.
