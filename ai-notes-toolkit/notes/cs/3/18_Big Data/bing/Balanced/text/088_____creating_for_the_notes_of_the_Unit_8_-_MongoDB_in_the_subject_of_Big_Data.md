### Unit 8 - MongoDB in Big Data

- MongoDB is a **document-oriented database** that stores data in **JSON-like** format. It is one of the most popular and widely adopted **Big Data databases** with over 10 million downloads, a large developer community, and hundreds of thousands of deployments .
- MongoDB is a preferred Big Data option thanks to its ability to easily handle a wide variety of data formats, support for real-time analysis, high-speed data ingestion, low-latency performance, flexible data model, easy horizontal scale-out, and powerful query language.
- MongoDB stores huge amounts of data in a naturally traversable format, making it a good choice to store, query, and analyze big data. MongoDB Atlas provides database as a fully managed service, with features like data encryption, security, advanced analytics, and data lakes.
- Some of the key concepts and features of MongoDB in Big Data are:

  - **Collections and Documents**: MongoDB stores data in collections, which are groups of documents. Documents are the basic unit of data in MongoDB, and they consist of key-value pairs. Documents can have nested sub-documents and arrays, allowing for complex and hierarchical data structures.
  - **Schemaless**: MongoDB does not enforce a fixed schema for the documents in a collection, meaning that documents can have different fields and structures. This allows for flexibility and agility in data modeling and application development, as well as accommodating the variety and evolution of data in Big Data scenarios.
  - **Sharding**: MongoDB supports horizontal scaling by distributing data across multiple servers, or shards. Sharding enables MongoDB to handle very large data sets and high throughput operations, as well as providing fault tolerance and high availability. MongoDB automatically balances the data across the shards, and allows for queries and updates to span multiple shards.
  - **Replication**: MongoDB provides data redundancy and reliability by replicating data across multiple servers, or replica sets. A replica set consists of one primary node and one or more secondary nodes, which maintain copies of the same data. The primary node handles all write operations, while the secondary nodes can handle read operations and provide backup in case of primary node failure. MongoDB supports automatic failover and recovery of replica sets.
  - **Aggregation Framework**: MongoDB provides a powerful and expressive way of performing data analysis and transformation using the aggregation framework. The aggregation framework allows for complex data processing pipelines, composed of multiple stages that can filter, group, sort, project, join, and manipulate data. The aggregation framework can leverage indexes, sharding, and replication to optimize performance and scalability.
  - **MongoDB Atlas Data Lake**: MongoDB Atlas Data Lake is a service that allows users to query and analyze data stored in Amazon S3 buckets using the MongoDB query language and tools. MongoDB Atlas Data Lake supports a variety of data formats, including JSON, BSON, CSV, TSV, Parquet, and Avro, and can federate queries across multiple data sources. MongoDB Atlas Data Lake enables users to perform ad hoc and exploratory analytics on large and diverse data sets without moving or transforming the data.
