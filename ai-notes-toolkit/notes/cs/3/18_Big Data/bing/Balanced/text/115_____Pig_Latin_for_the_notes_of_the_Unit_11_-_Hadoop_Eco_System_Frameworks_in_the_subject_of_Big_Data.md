### Pig Latin

- Pig Latin is a high-level scripting language that allows users to write complex data transformations in a simple and expressive way.
- Pig Latin is executed by Apache Pig, a platform for large-scale data analysis that runs on top of Hadoop.
- Pig Latin abstracts the details of MapReduce programming and provides a rich set of built-in operators for common data operations such as filtering, grouping, joining, sorting, and aggregating.
- Pig Latin scripts can be extended with user-defined functions (UDFs) written in Java, Python, or other languages.
- Pig Latin scripts are compiled into a series of MapReduce jobs that are executed on the Hadoop cluster.
- Pig Latin has the following features:
  - It is a declarative language that describes what data is needed and how to process it, rather than how to implement the logic.
  - It is a dataflow language that allows users to specify the flow of data from one operation to another, using pipes and other operators.
  - It is a schema-aware language that can infer the schema of the data from the input sources or the user can specify the schema explicitly.
  - It is a nested data language that can handle complex and hierarchical data structures such as tuples, bags, and maps.
  - It is a lazy evaluation language that only executes the operations when the output is needed, which enables optimization and parallelization of the execution plan.
