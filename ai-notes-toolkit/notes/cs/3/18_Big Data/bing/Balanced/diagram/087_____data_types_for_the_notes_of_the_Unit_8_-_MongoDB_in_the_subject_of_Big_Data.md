### Data Types

- MongoDB supports various data types that are used to store different kinds of values in the database.
- The data types are divided into two categories: BSON types and Extended JSON types.
- BSON types are the binary representation of JSON documents that MongoDB uses internally to store and manipulate data.
- Extended JSON types are the JSON representation of BSON types that MongoDB uses to communicate with external applications and drivers.
- Some of the common data types are:

  - **String**: A UTF-8 encoded string of characters. It can store text, symbols, or any other information that can be represented as a sequence of bytes. For example, `"Hello world"`, `"42"`, or `"👋"`.
  - **Number**: A numeric value that can be either an integer or a floating-point number. MongoDB supports two number types: `NumberInt` and `NumberDecimal`. `NumberInt` is a 32-bit signed integer that can store values from -2,147,483,648 to 2,147,483,647. `NumberDecimal` is a 128-bit decimal floating-point number that can store values with high precision and scale. For example, `42`, `3.14`, or `1.23456789012345678901234567890123456789`.
  - **Boolean**: A logical value that can be either `true` or `false`. It can be used to store binary choices, flags, or conditions. For example, `true`, `false`, or `NumberInt(1) == NumberInt(1)`.
  - **Object**: A document that can contain one or more key-value pairs. The keys are strings and the values can be any data type. It can be used to store complex or nested data structures. For example, `{"name": "Alice", "age": 25, "hobbies": ["reading", "writing", "coding"]}`.
  - **Array**: A list of values that can be of any data type. It can be used to store ordered or unordered collections of data. For example, `[1, 2, 3]`, `["red", "green", "blue"]`, or `[{"name": "Bob", "age": 30}, {"name": "Charlie", "age": 35}]`.
  - **Date**: A date and time value that is stored as a 64-bit signed integer representing the number of milliseconds since the Unix epoch (January 1, 1970). It can be used to store temporal data such as timestamps, events, or schedules. For example, `ISODate("2023-03-15T20:51:46.000Z")`, `new Date()`, or `new Date(2023, 2, 15, 20, 51, 46)`.
  - **ObjectId**: A 12-byte unique identifier that is generated by MongoDB for each document. It consists of a 4-byte timestamp, a 5-byte random value, and a 3-byte incrementing counter. It can be used to reference documents or as a primary key. For example, `ObjectId("507f1f77bcf86cd799439011")`, `new ObjectId()`, or `ObjectId.fromDate(new Date())`.
  - **Null**: A special value that represents the absence of a value. It can be used to indicate missing or unknown data. For example, `null`, `undefined`, or `{"name": null}`.
