### HiveQL

- HiveQL is a query language in Apache Hive for processing and analyzing structured data in a Metastore .
- HiveQL provides the basic SQL-like operations, such as SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY, HAVING, ORDER BY, etc.
- HiveQL also supports some advanced features, such as window functions, subqueries, common table expressions, user-defined functions, etc.
- HiveQL separates users from the complexity of Map Reduce programming and reuses common concepts from relational databases, such as tables, rows, columns, and schema, to ease learning .
- HiveQL allows users to project structure on largely unstructured data and supports storage on various file systems, such as HDFS, S3, ADLS, GS, etc .
- HiveQL can be executed using various interfaces, such as Hive CLI, Hive Web UI, Hive JDBC, Hive ODBC, etc.
