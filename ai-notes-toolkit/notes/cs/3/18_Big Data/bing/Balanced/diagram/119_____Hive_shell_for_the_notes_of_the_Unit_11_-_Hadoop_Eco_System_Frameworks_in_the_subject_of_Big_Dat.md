### Hive shell

- Hive shell is a command-line interface for interacting with Hive queries and commands.
- Hive shell can be launched by typing `$HIVE_HOME/bin/hive` in the terminal.
- Hive shell supports both interactive and batch modes of execution.
- Hive shell allows users to set variables using the `set` command, which can be used in queries or scripts.
- Hive shell also provides Hiveon OS remote access to workers using the Hiveon OS network infrastructure.
- Hive shell has some unique features, such as access via an SSH client and console sharing.
- Hive shell can be used for various tasks, such as data analysis, data manipulation, data loading, and data administration.
