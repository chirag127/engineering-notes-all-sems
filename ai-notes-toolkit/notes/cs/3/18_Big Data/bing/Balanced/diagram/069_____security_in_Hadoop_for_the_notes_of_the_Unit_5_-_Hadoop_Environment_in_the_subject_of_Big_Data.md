### Security in Hadoop

- Security in Hadoop is the process of protecting the data and services of a Hadoop cluster from unauthorized access, modification, or disclosure.
- Security in Hadoop consists of four main aspects: authentication, authorization, encryption, and auditing.
- Authentication is the process of verifying the identity of a user or a service before allowing access to the Hadoop cluster. Authentication can be done using Kerberos, a network protocol that uses tickets and keys to establish secure communication. Kerberos authentication is the recommended and default option for Hadoop security.
- Authorization is the process of granting or denying access to specific resources or operations based on the authenticated identity of a user or a service. Authorization can be done using HDFS file permissions, which control the read, write, and execute access to files and directories, or using Service Level Authorization, which controls the access to Hadoop services such as MapReduce, YARN, and HBase.
- Encryption is the process of transforming data into an unreadable form to prevent unauthorized access or disclosure. Encryption can be done at the network level, using SSL/TLS protocols to secure the communication between Hadoop nodes and clients, or at the data level, using encryption zones to encrypt the data stored in HDFS.
- Auditing is the process of recording and reviewing the activities and events that occur in the Hadoop cluster, such as user login, file access, service invocation, or configuration changes. Auditing can be done using audit logs, which capture the details of each operation performed in the Hadoop cluster, or using external tools, such as Apache Ranger or Apache Sentry, which provide centralized and comprehensive security management and monitoring for Hadoop.
