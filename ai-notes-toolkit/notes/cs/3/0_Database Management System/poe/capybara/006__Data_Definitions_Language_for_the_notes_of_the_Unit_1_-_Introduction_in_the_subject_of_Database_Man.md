### Data Definitions Language for the notes of the Unit 1 - Introduction in the subject of Database Management System

Data Definitions Language (DDL) is a subset of SQL used to define the database schema, which includes tables, views, indexes, and other database objects. DDL statements are used to create, alter, and drop database objects.

Here are some key points to keep in mind when working with DDL:

- DDL statements are used to create, alter, and drop database objects such as tables, views, indexes, and constraints.
- The CREATE statement is used to create a new database object, while the ALTER statement is used to modify an existing object.
- The DROP statement is used to remove an existing object from the database.
- DDL statements are not transactional, meaning that once executed, they cannot be rolled back.
- DDL statements can only be executed by the database owner or users with the appropriate permissions.
- DDL statements can be used to define constraints on database objects, such as primary keys, foreign keys, and check constraints.
- DDL statements can be used to define views, which are virtual tables based on one or more existing tables.
- DDL statements can be used to define indexes, which improve the performance of queries by allowing the database to find data more quickly.

In summary, DDL is an essential part of SQL used to define the structure of a database. Understanding DDL is crucial for anyone working with databases, as it allows them to create, modify, and manage database objects effectively.
