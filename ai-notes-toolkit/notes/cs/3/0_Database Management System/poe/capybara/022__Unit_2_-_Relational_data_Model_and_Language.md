## Unit 2 - Relational Data Model and Language

In this unit, we will learn about the relational data model and its language. The relational data model is a method of structuring data using tables, columns, and rows. The language used to manipulate this data is called Structured Query Language (SQL). 

### Introduction to Relational Data Model

1. The relational data model is based on the concept of tables that consist of rows and columns. Each row represents a unique record, and each column represents a specific attribute of that record.
2. The relational data model is widely used in modern database systems because it allows for efficient and organized data storage and retrieval.
3. The relationships between tables in the relational data model are established through the use of keys. Primary keys are used to uniquely identify each row in a table, while foreign keys are used to establish relationships between tables.

### Structured Query Language (SQL)

1. SQL is the language used to interact with relational databases. It is used to create, read, update, and delete data from a database.
2. SQL is a declarative language, which means that you tell the database what you want to do, and it figures out how to do it.
3. SQL consists of several different types of statements, including SELECT, INSERT, UPDATE, and DELETE statements.
4. SELECT statements are used to retrieve data from a database, while INSERT, UPDATE, and DELETE statements are used to modify data in a database.
5. SQL also includes several different types of clauses, including WHERE, ORDER BY, GROUP BY, and HAVING clauses, which are used to filter, sort, group, and aggregate data.

### Normalization

1. Normalization is the process of organizing data in a database so that it is free from redundancy and inconsistencies.
2. There are several normal forms, including first normal form (1NF), second normal form (2NF), third normal form (3NF), and so on.
3. Normalization helps to prevent data anomalies, such as data insertion, deletion, and update anomalies, which can occur when data is not properly organized.
4. Normalization is important because it helps to ensure that data is consistent, accurate, and easy to maintain.

Overall, understanding the relational data model and SQL is essential for anyone working with databases. By learning these concepts, you will be able to create and manage efficient and organized databases that can store and retrieve data quickly and accurately.
