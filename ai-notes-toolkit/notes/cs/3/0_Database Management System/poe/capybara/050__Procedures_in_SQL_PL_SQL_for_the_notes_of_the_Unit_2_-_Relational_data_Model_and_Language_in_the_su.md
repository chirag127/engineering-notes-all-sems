### Procedures in SQL/PL SQL

Procedures in SQL/PL SQL are a set of instructions that are executed in a specific order to perform a specific task or set of tasks. In database management systems, procedures are used to manipulate data, perform calculations, and simplify complex queries. Here are the procedures in SQL/PL SQL that you need to know for the Unit 2 - Relational Data Model and Language:

1. Creating Procedures: The first step is to create the procedure by using the CREATE PROCEDURE statement. The procedure can be created in either SQL or PL SQL.

2. Naming Procedures: It is essential to name the procedure uniquely so that it can be identified easily. The name should be descriptive, short, and meaningful.

3. Parameters: Parameters are used to pass data to and from procedures. They can be input, output, or both. Input parameters are used to pass data into the procedure, while output parameters are used to return data from the procedure.

4. Variables: Variables are used to store data temporarily in a procedure. They can be declared using the DECLARE statement.

5. IF Statements: IF statements are used to perform conditional processing in a procedure. They can be used to check if a condition is true or false and execute specific code block accordingly.

6. Loops: Loops are used to execute a block of code multiple times. There are two types of loops: FOR and WHILE loops. FOR loops are used when you know the number of times the code should be executed, while WHILE loops are used when you don't know how many times the code should be executed.

7. Cursors: Cursors are used to process individual rows returned by a query. They can be declared using the DECLARE CURSOR statement.

8. Exception Handling: Exception handling is used to catch and handle errors that may occur in a procedure. You can use the EXCEPTION block to handle errors.

9. Calling Procedures: Procedures can be called from other procedures or from SQL statements using the CALL statement.

10. Modifying Procedures: Procedures can be modified using the ALTER PROCEDURE statement. You can modify the procedure's name, parameters, or code. 

These procedures are essential to master for the Unit 2 - Relational Data Model and Language in the subject of Database Management System. By using these procedures, you can simplify complex queries and manipulate data efficiently.
