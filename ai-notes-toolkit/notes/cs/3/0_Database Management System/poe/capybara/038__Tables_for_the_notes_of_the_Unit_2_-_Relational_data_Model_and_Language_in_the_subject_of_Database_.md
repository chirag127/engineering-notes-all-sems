### Tables for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

The relational data model is one of the most widely used models for database management. It is based on the concept of tables and provides a structured way to store and manage data. Here are some key points to remember about tables in the relational data model:

- Tables are used to store data in a structured format.
- Each table consists of rows and columns.
- The rows represent individual records or instances of data.
- The columns represent the attributes or properties of the data.
- Each column has a unique name and data type.
- The data type of a column defines the kind of data that can be stored in that column.
- Tables can have one or more primary keys, which are used to uniquely identify each record in the table.
- Foreign keys are used to establish relationships between tables.
- A foreign key is a column or set of columns in one table that refers to the primary key of another table.
- Tables can be joined together to retrieve data from multiple tables.
- Joining tables involves matching the values in the related columns of the tables.
- There are different types of joins, including inner join, left join, right join, and full outer join.
- Normalization is a process used to eliminate redundancy and improve data integrity in tables.
- Normalization involves dividing tables into smaller tables and establishing relationships between them.

In summary, tables are a fundamental component of the relational data model. They provide a structured way to store and manage data, and are used to establish relationships between different sets of data. Understanding tables and the relationships between them is essential for effective database management.
