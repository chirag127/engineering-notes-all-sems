### Relational Calculus

Relational Calculus is a query language that is used to retrieve data from a relational database. There are two types of Relational Calculus: Tuple Relational Calculus (TRC) and Domain Relational Calculus (DRC).

#### Tuple Relational Calculus (TRC)

- TRC is based on the concept of selecting tuples from a relation.
- It uses a predicate to select the tuples that satisfy a certain condition.
- The predicate is expressed in terms of attributes of the relation.
- TRC is a non-procedural language, meaning that the user specifies what data they want, but not how to retrieve it.
- TRC queries are typically written in the form of an existentially quantified formula.

#### Domain Relational Calculus (DRC)

- DRC is based on the concept of selecting values from a domain.
- It uses a predicate to select the values that satisfy a certain condition.
- The predicate is expressed in terms of variables that range over domains.
- DRC is a non-procedural language, meaning that the user specifies what data they want, but not how to retrieve it.
- DRC queries are typically written in the form of an existentially quantified formula.

- TRC is based on selecting tuples from a relation, while DRC is based on selecting values from a domain.

#### Advantages of Relational Calculus

- Relational Calculus is a declarative language, meaning that the user specifies what data they want, but not how to retrieve it.
- Relational Calculus is a well-defined language with a formal syntax and semantics.
- Relational Calculus is a powerful language that can express complex queries in a concise and intuitive way.
