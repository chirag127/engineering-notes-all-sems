
## Unit 4 - Transaction Processing Concept

1. Transaction Processing is a method of collecting, storing, modifying and retrieving data from a database.
2. It is used to keep track of the day-to-day activities of an organization.
3. Transaction processing systems are designed to process large amounts of data quickly and accurately.
4. The system is used to process a variety of transactions, such as sales, purchases, payments, and payroll.
5. The system is designed to ensure accuracy and consistency of data.
6. It is also used to prevent unauthorized access to sensitive data.
7. The system also includes security measures to protect data from unauthorized access.
8. Transaction processing systems are used in a variety of industries, such as banking, retail, and healthcare.
9. Transaction processing systems are also used in e-commerce applications.
10. Transaction processing systems are used to process and store data in a secure and efficient manner.
