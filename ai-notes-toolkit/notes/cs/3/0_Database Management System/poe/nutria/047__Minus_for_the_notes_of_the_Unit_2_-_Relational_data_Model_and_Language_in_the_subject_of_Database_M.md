
### Minus for the Notes of the Unit 2 - Relational Data Model and Language in the subject of Database Management System

1. The relational data model is a type of data model that uses a collection of tables with columns and rows to represent data and the relationships between them.

2. The relational data model is based on the theory of first-order predicate logic and uses a language called SQL (Structured Query Language) to manipulate the data.

3. SQL is a powerful language that can be used to create, update, delete, and query data from a relational database.

4. The relational data model uses the concept of normalization to ensure data integrity and consistency.

5. Normalization is the process of organizing data into tables and columns in a way that minimizes data redundancy and increases data integrity.

6. The relational data model also uses the concept of referential integrity to ensure that data is consistent across multiple tables.

7. Referential integrity is the process of ensuring that data in one table is consistent with data in another table.

8. The relational data model is used in many popular database management systems such as Oracle, MySQL, and Microsoft SQL Server.
