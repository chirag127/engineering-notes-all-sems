
### Intersection for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

1. Relational data model is a collection of data organized in the form of tables that consist of columns and rows.
2. Each column in a table represents a different attribute of the data, and each row represents a different record.
3. Relational databases are capable of storing large amounts of data and can be easily queried to retrieve specific information.
4. The language used to interact with relational databases is called Structured Query Language (SQL).
5. SQL is a powerful language that allows users to create, modify, and delete tables, as well as query data from them.
6. SQL commands are used to create, modify, and delete tables, as well as query data from them.
7. Joins are a type of SQL command used to combine data from two or more tables.
8. Intersection is a type of join that returns only the rows that are present in both tables.
9. Intersection can be used to compare two tables and find records that are present in both.
