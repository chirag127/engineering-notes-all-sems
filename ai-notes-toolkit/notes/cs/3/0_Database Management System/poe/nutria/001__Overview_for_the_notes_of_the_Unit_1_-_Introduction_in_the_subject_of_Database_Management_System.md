
### Overview for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. Database Management System (DBMS): A DBMS is a software system that allows users to store, manipulate, and retrieve data from a database. It also provides an interface for users to interact with the database.

2. Database: A database is a collection of organized data, typically stored in a computer system, that can be accessed and manipulated by users.

3. Data Model: A data model is a conceptual representation of the structure of data in a database. It defines the relationships between different entities and how they are connected.

4. Database Design: Database design is the process of designing a database to meet the requirements of an application or system. It involves creating a data model, defining the structure of the database, and creating the physical database.

5. Normalization: Normalization is the process of organizing data in a database to reduce data redundancy and improve data integrity. It involves breaking down data into smaller, more manageable pieces and ensuring that data is stored in a consistent format.

6. Structured Query Language (SQL): SQL is a special-purpose programming language used to interact with a database. It is used to create, modify, and query data in a database.
