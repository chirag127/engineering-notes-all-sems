
### Validation Based Protocol for the notes of the Unit 5 - Concurrency Control Techniques in the subject of Database Management System

1. Validation based protocols are a type of concurrency control technique used in database management systems.
2. These protocols ensure that transactions do not interfere with each other when they are being executed concurrently.
3. The main idea behind these protocols is that each transaction is checked for correctness before it is allowed to proceed.
4. In order to check for correctness, the protocol ensures that the database is in a consistent state before the transaction is allowed to continue.
5. This is done by validating the transaction against a set of predefined conditions.
6. If the transaction is found to violate any of these conditions, it is aborted and rolled back to its original state.
7. Validation based protocols are considered to be the most reliable form of concurrency control, as they ensure that the database remains in a consistent state at all times.
8. These protocols are also very efficient, as they do not require any additional locking or blocking of transactions.
9. The main disadvantage of these protocols is that they can be quite complex and time-consuming to implement.
