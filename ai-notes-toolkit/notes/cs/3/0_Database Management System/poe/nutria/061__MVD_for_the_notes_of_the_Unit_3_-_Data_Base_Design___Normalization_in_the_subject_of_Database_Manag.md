
### MVD for the Notes of Unit 3 - Database Design & Normalization

1. **Multivalued Dependencies (MVD)** are a type of functional dependency that occurs when a relation contains two or more independent multi-valued attributes. 
2. An MVD is a constraint between two sets of attributes in a relation, where one set is dependent on the other.
3. MVDs are important in database design and normalization, as they can help to ensure that data is stored in a consistent and organized manner.
4. In order to ensure that an MVD is satisfied, the relation must be in the Third Normal Form (3NF).
5. To determine if a relation is in 3NF, it must first be in the Second Normal Form (2NF).
6. To determine if a relation is in 2NF, it must first be in the First Normal Form (1NF). 
7. The goal of normalization is to reduce data redundancy and ensure that data is stored in a consistent manner.
8. Normalization involves breaking down a relation into smaller, more manageable relations that are in 3NF.
9. Normalization is an iterative process, and it is important to understand the functional dependencies between attributes in order to properly normalize a relation.
