
### Relational Data Model and Language

1. A **Relational Data Model** is a data model that uses relational algebra and tuple relational calculus to store and manipulate data.

2. A **Relational Database** is a database that stores data in tables, which are related to each other by common fields.

3. A **Relational Database Management System** (RDBMS) is a type of database management system that uses the relational data model.

4. The **Structured Query Language** (SQL) is a programming language used to access and manipulate data stored in a relational database.

5. SQL is a declarative language, meaning that it allows users to specify what data they want, rather than how to get it.

6. SQL can be used to create, modify, and delete data, as well as to query and analyze data.

7. SQL includes commands for creating tables, inserting data, updating data, deleting data, and querying data.

8. SQL also includes commands for creating views, stored procedures, and triggers.
