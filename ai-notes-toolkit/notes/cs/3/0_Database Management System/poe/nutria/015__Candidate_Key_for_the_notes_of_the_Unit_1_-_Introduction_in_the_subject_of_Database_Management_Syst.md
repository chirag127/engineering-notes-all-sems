
### Candidate Key for the notes of the Unit 1 - Introduction in the subject of Database Management System

* A Candidate Key is a minimal set of attributes which can uniquely identify a tuple in a relation. 
* It is also known as a Primary Key or Unique Key.
* It is used to identify the tuples in a relation. 
* A Candidate Key should have the following properties:
    * Uniqueness: No two tuples in a relation can have the same value of the Candidate Key.
    * Minimality: The Candidate Key should contain the minimum number of attributes to ensure uniqueness.
    * Irreducibility: The Candidate Key should not be a subset of any other set of attributes in the relation.
* A relation can have more than one Candidate Key. 
* A Super Key is a set of attributes which can identify a tuple in a relation. It can be a Candidate Key or a combination of attributes which includes a Candidate Key.
