
### SQL Data Types and Literals

1. SQL supports multiple data types, including numeric, character, date, and Boolean types. 
2. Numeric data types include integers, decimals, and floating-point numbers. 
3. Character data types include strings of characters, such as varchar and text. 
4. Date data types include the date, time, and timestamp. 
5. Boolean data types include true/false values. 
6. Literals are specific values that can be used in SQL queries. 
7. Integer literals are used to represent whole numbers. 
8. Floating-point literals are used to represent decimal numbers. 
9. Character literals are used to represent strings of characters. 
10. Date literals are used to represent dates, times, and timestamps. 
11. Boolean literals are used to represent true/false values.
