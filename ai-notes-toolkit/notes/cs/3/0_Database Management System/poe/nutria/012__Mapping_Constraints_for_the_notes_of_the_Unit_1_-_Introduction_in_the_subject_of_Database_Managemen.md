
### Mapping Constraints for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. **Entity Integrity Constraint**: This constraint ensures that each row in a table has a unique identifier. 
2. **Referential Integrity Constraint**: This constraint ensures that each foreign key in a table references a valid primary key in another table. 
3. **Domain Integrity Constraint**: This constraint ensures that all values in a column are of the same type and fit within the specified range. 
4. **Key Constraint**: This constraint ensures that each row in a table has a unique identifier. 
5. **Null Constraint**: This constraint ensures that a column cannot contain null values. 
6. **Check Constraint**: This constraint ensures that all values in a column satisfy a specific condition.
