
### Normalization using FD

1. Normalization is the process of organizing data in a database in order to reduce data redundancy and improve data integrity.
2. Normalization involves decomposing a relation into smaller (and less redundant) relations.
3. Normal forms are used to determine what type of normalization should be used.
4. First Normal Form (1NF) requires that all attributes of a relation be atomic (i.e. indivisible).
5. Second Normal Form (2NF) requires that all non-key attributes of a relation be fully dependent on the primary key.
6. Third Normal Form (3NF) requires that all non-key attributes of a relation be non-transitively dependent on the primary key.
7. Fourth Normal Form (4NF) requires that all non-key attributes of a relation be non-transitively dependent on the primary key and be independent of each other.
8. Fifth Normal Form (5NF) requires that all non-key attributes of a relation be non-transitively dependent on the primary key and be mutually independent.
9. Functional Dependencies (FDs) are used to determine whether a relation is in a given normal form.
10. FDs are used to determine whether a relation is in 1NF, 2NF, 3NF, 4NF, and 5NF.
