
### Primary Key for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. A primary key is a column or a set of columns in a database table that uniquely identifies each row in the table.

2. A primary key can be composed of one or more columns. When multiple columns are used as a primary key, they are known as a composite key.

3. A primary key must contain unique values; duplicate values are not allowed. It must not contain null values.

4. A primary key can be used to identify a particular record in a table and to establish relationships between tables in a database.

5. A primary key is used to ensure data integrity in a database. It ensures that no two records have the same values for the primary key columns.

6. A primary key can be used to create an index, which makes searching for a particular record faster.
