

### Cursors for the Notes of Unit 2 - Relational Data Model and Language in Database Management System

* A cursor is a pointer to a specific row in a table. It can be used to navigate, retrieve, and manipulate data in a relational database. 
* Cursors are used in the SQL language to perform operations on data sets that can be retrieved from the database. 
* A cursor can be used to iterate through the rows of a result set, which is a set of data retrieved from a query. 
* Cursors can be used to update, delete, or insert data into a table. 
* Cursors can also be used to process data sets in batches, which can be useful for large data sets. 
* Cursors can also be used to perform complex operations, such as creating temporary tables and performing joins. 
* Cursors can also be used to improve performance by reducing the amount of data that needs to be retrieved from the database.
