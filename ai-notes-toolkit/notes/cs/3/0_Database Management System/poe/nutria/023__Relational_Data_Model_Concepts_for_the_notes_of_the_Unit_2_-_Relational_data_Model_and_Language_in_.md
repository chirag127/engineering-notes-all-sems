
### Relational Data Model Concepts 

1. The relational data model is a method of structuring data in a database. It is based on the idea of a collection of tables, each of which contains related data. 
2. A relational database is composed of one or more tables, each of which is composed of a set of columns and rows. Each row contains a unique set of data, and each column contains a specific type of data. 
3. The tables in a relational database are related to each other through a set of relationships. A relationship is a link between two tables that defines how the data in one table relates to the data in the other table. 
4. The language used to manipulate a relational database is called Structured Query Language (SQL). SQL is a specialized programming language used to query and manipulate data in a relational database. 
5. SQL can be used to create, update, delete, and query data in a relational database. It can also be used to create, modify, and delete tables, columns, and relationships in a relational database. 
6. The relational model also includes a set of rules that define how data can be manipulated in a relational database. These rules are known as the relational model's integrity constraints. 
7. The integrity constraints in a relational database ensure that the data stored in the database is valid and consistent. They also ensure that the data is organized in a way that is easy to query and manipulate.
