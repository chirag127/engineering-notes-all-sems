
### Unit 3 - Database Design & Normalization

1. Database design is the process of creating a logical structure for a database that meets the requirements of the users and the organization.

2. Normalization is the process of organizing data into tables in such a way that the results of using the database are always predictable and consistent. It also helps to reduce data redundancy and improve data integrity.

3. The process of normalization involves breaking down a table into smaller, related tables and defining relationships between them. This helps to ensure data integrity and improve query performance.

4. The goal of normalization is to create a structure that eliminates data redundancy, eliminates the need for null values, and makes it easier to update and delete data.

5. Normalization involves the use of normal forms, which are rules that define how a database should be organized. The most commonly used normal forms are the first, second, and third normal forms.
