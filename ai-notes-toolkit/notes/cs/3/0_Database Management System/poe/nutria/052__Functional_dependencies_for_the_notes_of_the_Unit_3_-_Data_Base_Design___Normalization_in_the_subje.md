
### Functional Dependencies for the Notes of the Unit 3 - Data Base Design & Normalization in the Subject of Database Management System

1. A functional dependency (FD) is a relationship between two attributes in a relation. 
2. A functional dependency is said to hold if the value of one attribute uniquely determines the value of another.
3. Functional dependencies are used to identify the most efficient way to store data in a relational database.
4. A functional dependency is represented by an arrow (→) from the left hand side (LHS) to the right hand side (RHS).
5. The LHS is a set of one or more attributes that uniquely determine the value of the RHS.
6. A functional dependency can be expressed as a set of equations, such as A → B, which means that the value of A uniquely determines the value of B.
7. A functional dependency can be used to normalize a database. Normalization is the process of organizing data in a relational database to reduce data redundancy and improve data integrity.
