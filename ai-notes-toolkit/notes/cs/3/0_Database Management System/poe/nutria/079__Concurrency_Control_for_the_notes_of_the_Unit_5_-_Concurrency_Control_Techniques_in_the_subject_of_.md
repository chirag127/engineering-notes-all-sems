
### Concurrency Control

* Concurrency control is a database management system (DBMS) technique that ensures multiple users have access to the same data simultaneously. 
* It also ensures that each user's transactions are processed in a consistent and predictable manner. 
* Concurrency control is used to prevent data inconsistency and data corruption, as well as to ensure data integrity and consistency. 
* Concurrency control techniques are used to manage the simultaneous access of multiple users to the same data. 
* These techniques can be divided into two categories: pessimistic concurrency control and optimistic concurrency control. 
* Pessimistic concurrency control involves locking the data being accessed by a user, thereby preventing other users from accessing the data. 
* Optimistic concurrency control, on the other hand, allows multiple users to access the same data simultaneously, but checks for any conflicts at the end of the transaction. 
* Some of the commonly used concurrency control techniques are two-phase locking, timestamp ordering, and multiversion concurrency control.
