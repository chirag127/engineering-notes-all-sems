
### Relational Algebra

Relational algebra is a set of operations used to manipulate data stored in relational databases. It is a procedural query language, meaning that it describes a set of steps to be followed in order to achieve a desired result.

The operations in relational algebra can be divided into two categories:

1. Unary Operations: These operations involve only one relation and are used to select, project, and rename attributes.
    * **Select**: This operation selects tuples from a relation based on a given condition.
    * **Project**: This operation projects a relation by selecting only the specified attributes from the relation.
    * **Rename**: This operation renames an attribute in a relation.
2. Binary Operations: These operations involve two or more relations and are used to join, intersect, and subtract relations.
    * **Join**: This operation combines two relations into a single relation.
    * **Intersect**: This operation computes the intersection of two relations.
    * **Difference**: This operation computes the difference between two relations.
