
### Keys for the notes of the Unit 1 - Introduction in the subject of Database Management System
- Database Management System (DBMS): A software system that enables the storage, organization, retrieval, manipulation, and management of data.
- Data Model: A representation of the logical structure of a database.
- Entity: A person, place, thing, or event that is relevant to a database.
- Entity Relationship Diagram (ERD): A diagram that describes the relationships between entities in a database.
- Primary Key: A field or combination of fields that uniquely identifies a record in a table.
- Foreign Key: A field or combination of fields that is used to link two tables together.
- Normalization: The process of organizing data in a database to minimize data redundancy and improve data integrity.
- Structured Query Language (SQL): A language used to interact with a database.
- Data Manipulation Language (DML): A subset of SQL used to manipulate data in a database.
- Data Definition Language (DDL): A subset of SQL used to define the structure of a database.
