
### Unit 3 - Database Design & Normalization

* Database design is the process of creating a logical and structured model of a database. It involves the design of data structures, such as tables, fields, and relationships between them, to store data in the most efficient way possible.
* Normalization is the process of organizing data in a database to reduce data redundancy and improve data integrity. It involves dividing data into smaller, related tables and establishing relationships between them.
* The goal of normalization is to produce a database structure that is more organized and efficient. Normalization typically involves the following steps:
    1. Identifying the entities and attributes of the data.
    2. Determining the relationships between the entities.
    3. Identifying the data redundancies.
    4. Eliminating the redundancies by breaking the data into smaller, related tables.
    5. Establishing relationships between the tables.
* Normalization typically involves the following normal forms:
    1. First Normal Form (1NF) – A table is in 1NF if all the data in the table is atomic, which means that each row contains a single value.
    2. Second Normal Form (2NF) – A table is in 2NF if it is in 1NF and all the non-key attributes are dependent on the primary key.
    3. Third Normal Form (3NF) – A table is in 3NF if it is in 2NF and all the non-key attributes are mutually independent.
    4. Fourth Normal Form (4NF) – A table is in 4NF if it is in 3NF and all the non-key attributes are mutually independent.
