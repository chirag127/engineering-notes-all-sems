

### Integrity Constraints for the Notes of the Unit 2 - Relational Data Model and Language in the Subject of Database Management System

1. **Entity Integrity**: This constraint ensures that no primary key field can be left blank or contain a null value.
2. **Referential Integrity**: This constraint ensures that any foreign key field in a table must match a primary key field in another table.
3. **Domain Integrity**: This constraint ensures that all values entered into a field are valid and within the domain of the field.
4. **User-Defined Integrity**: This constraint allows users to define specific rules that must be followed when entering data into a field.
5. **Business Rules Integrity**: This constraint ensures that all data entered into a field follows the business rules of the organization.
