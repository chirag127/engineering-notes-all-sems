### Domain Constraints
- Domain constraints are the rules that define the valid values for an attribute in a relation.
- Domain constraints are specified by the data type, format, range, and/or set of permissible values for each attribute.
- Domain constraints ensure the data integrity and consistency of the relation by preventing invalid or inconsistent data from being stored.
- Domain constraints can be enforced by the database system or by the application program that manipulates the data.
- Domain constraints can be simple or complex, depending on the level of detail and validation required for the attribute.
- Some examples of domain constraints are:
  - A social security number must be a 9-digit numeric value.
  - A date must be in the format of YYYY-MM-DD.
  - A grade must be one of the letters A, B, C, D, or F.
  - A salary must be a positive decimal number.
