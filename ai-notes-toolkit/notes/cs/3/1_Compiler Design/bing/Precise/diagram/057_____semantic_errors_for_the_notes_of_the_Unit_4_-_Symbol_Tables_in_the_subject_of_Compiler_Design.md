### Semantic Errors

Semantic errors occur when the code is syntactically correct but does not do what the programmer intended. These errors are often caused by incorrect usage of variables, data types, or operations. In the context of compiler design and symbol tables, semantic errors can arise due to issues such as:

1. **Undeclared variables**: If a variable is used in the code but has not been declared in the symbol table, it will result in a semantic error.
2. **Type mismatch**: If an operation is performed on variables of incompatible data types, it will result in a semantic error. For example, attempting to add a string and an integer.
3. **Scope errors**: If a variable is used outside of its scope, it will result in a semantic error. For example, if a variable is declared within a function and then used outside of that function.
4. **Incorrect function usage**: If a function is called with the wrong number or type of arguments, it will result in a semantic error.

These are some common examples of semantic errors that can occur in the context of compiler design and symbol tables. It is important to carefully check the code for these types of errors to ensure that it behaves as intended.
