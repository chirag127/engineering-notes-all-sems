### Derivation and Parse Trees

#### Derivation
- A derivation is a sequence of grammar rule applications that transforms the start symbol into a string of terminal symbols.
- A derivation can be represented as a tree, called a parse tree, where the root is the start symbol and the leaves are the terminal symbols.
- There are two types of derivations: leftmost and rightmost.
- In a leftmost derivation, the leftmost non-terminal symbol is always expanded first.
- In a rightmost derivation, the rightmost non-terminal symbol is always expanded first.

#### Parse Trees
- A parse tree is a graphical representation of a derivation.
- The root of the tree is the start symbol.
- The internal nodes are non-terminal symbols.
- The leaves are terminal symbols.
- The children of a non-terminal node represent the right-hand side of a production rule.
- A parse tree shows the hierarchical structure of the input string according to the grammar rules.
- A parse tree can be used to check if an input string is valid according to the grammar rules.
