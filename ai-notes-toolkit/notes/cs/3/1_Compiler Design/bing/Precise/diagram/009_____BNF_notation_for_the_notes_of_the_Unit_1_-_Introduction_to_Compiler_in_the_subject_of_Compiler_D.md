### BNF Notation

BNF (Backus-Naur Form) notation is a formal mathematical way to describe a language. It is commonly used to specify the syntax of programming languages, command sets, and document formats.

Here are some key points to remember about BNF notation:

1. BNF uses a set of production rules to define the syntax of a language.
2. Each production rule has a left-hand side (LHS) and a right-hand side (RHS).
3. The LHS is a non-terminal symbol, which represents a syntactic category.
4. The RHS is a sequence of terminal and non-terminal symbols, which defines the structure of the syntactic category.
5. Terminal symbols represent the basic elements of the language, such as keywords, operators, and punctuation.
6. Non-terminal symbols represent higher-level syntactic categories, such as expressions, statements, and declarations.
7. The production rules are applied recursively to generate valid sentences in the language.
