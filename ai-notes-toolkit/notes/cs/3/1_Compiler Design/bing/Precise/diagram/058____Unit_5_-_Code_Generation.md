## Unit 5 - Code Generation

Code generation is the process of converting intermediate code into machine code or assembly language. This is the final phase of the compiler, where the code is optimized and translated into a form that can be executed by the target machine.

The following are the key points to remember about code generation:

1. Code generation is the final phase of the compiler.
2. The intermediate code is converted into machine code or assembly language.
3. The code is optimized during this phase.
4. The generated code can be executed by the target machine.
5. Code generation can be done using various techniques such as peephole optimization, instruction selection, and register allocation.

In summary, code generation is an important phase of the compiler that translates the intermediate code into a form that can be executed by the target machine. Various techniques are used to optimize the code during this phase.
