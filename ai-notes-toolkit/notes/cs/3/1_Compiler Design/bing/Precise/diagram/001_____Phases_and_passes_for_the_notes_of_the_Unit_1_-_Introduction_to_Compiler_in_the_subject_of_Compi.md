### Phases and passes for the notes of the Unit 1 - Introduction to Compiler in the subject of Compiler Design

A compiler is a program that translates a source program written in a high-level language into an equivalent target program in a low-level language. The process of compilation is divided into several phases, each of which performs a specific task. These phases are:

1. **Lexical Analysis:** This phase is responsible for scanning the source program and converting it into a sequence of tokens. Each token represents a meaningful unit of the source program, such as a keyword, an identifier, or a constant.

2. **Syntax Analysis:** This phase is responsible for checking the syntactic structure of the source program. It verifies that the sequence of tokens generated by the lexical analyzer conforms to the grammar of the source language.

3. **Semantic Analysis:** This phase is responsible for checking the semantic correctness of the source program. It verifies that the program is meaningful and can be executed. This includes checking for type compatibility, undeclared variables, and other semantic errors.

4. **Intermediate Code Generation:** This phase is responsible for generating an intermediate representation of the source program. This intermediate representation is usually in the form of a three-address code, which is a sequence of instructions that can be easily translated into the target language.

5. **Code Optimization:** This phase is responsible for improving the intermediate code by applying various optimization techniques. The goal is to generate code that is more efficient in terms of execution time and memory usage.

6. **Code Generation:** This phase is responsible for generating the target program in the low-level language. It translates the optimized intermediate code into the target language, taking into account the specific features of the target machine.

A pass is a traversal of the source program by one of the phases of the compiler. A single phase may require multiple passes to complete its task. For example, the code optimization phase may require several passes to apply different optimization techniques.
