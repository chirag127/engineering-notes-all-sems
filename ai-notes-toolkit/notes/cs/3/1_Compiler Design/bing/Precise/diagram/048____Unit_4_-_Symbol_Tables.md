## Unit 4 - Symbol Tables

A symbol table is a data structure used by a compiler or interpreter to keep track of information about the names used in a program. This information includes the location, type, and scope of each name.

Some key points to remember about symbol tables are:

1. Symbol tables are used to store information about identifiers, such as variables, functions, and classes, used in a program.
2. The information stored in a symbol table can include the location, type, and scope of each identifier.
3. Symbol tables are typically implemented using a hash table or a binary search tree.
4. The use of a symbol table allows for efficient name lookup and error checking during the compilation or interpretation of a program.
5. Symbol tables can be used to implement features such as namespaces and overloading.
