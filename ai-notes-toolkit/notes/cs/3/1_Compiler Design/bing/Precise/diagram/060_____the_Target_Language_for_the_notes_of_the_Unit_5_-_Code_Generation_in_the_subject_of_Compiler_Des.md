### Unit 5 - Code Generation: Target Language

The target language is the final output of the code generation phase in the compiler design process. It is the machine language or assembly language that the target machine can execute directly. Here are some key points to remember about the target language:

1. The target language is dependent on the target machine's architecture and instruction set.
2. The target language is usually a low-level language, such as machine language or assembly language.
3. The target language is generated by the code generator, which takes the intermediate representation of the source code as input and produces the target language code as output.
4. The target language code is optimized for efficient execution on the target machine.
5. The target language code is usually not human-readable, as it is intended to be executed by the machine, not read by humans.
