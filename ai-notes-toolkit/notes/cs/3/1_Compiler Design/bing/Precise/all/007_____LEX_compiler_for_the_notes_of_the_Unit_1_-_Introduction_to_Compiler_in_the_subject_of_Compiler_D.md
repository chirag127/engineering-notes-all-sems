# LEX Compiler

LEX is a computer program that generates lexical analyzers. Lexical analyzers are programs that recognize lexical patterns in text. LEX reads an input stream specifying the lexical analyzer and outputs source code implementing the lexer in the C programming language.

Here are some key points to remember about LEX compiler:

1. LEX is a tool used to generate lexical analyzers or scanners.
2. LEX is commonly used with the YACC parser generator.
3. LEX source is a table of regular expressions and corresponding program fragments.
4. The table is translated to a program that reads an input stream, copying it to an output stream and partitioning the input into strings that match the given expressions.
5. As each such string is recognized, the corresponding program fragment is executed.
6. The recognition of the expressions is performed by a deterministic finite automaton generated by LEX.
7. LEX is commonly used for writing compilers and interpreters.
