# Procedures Call for the Notes of the Unit 3 - Syntax-directed Translation in the Subject of Compiler Design

Syntax-directed translation is a method of translating the source program into the target program using the parse tree or abstract syntax tree. It is a powerful technique for specifying the translation of programming languages and can be used to perform semantic analysis and code generation.

Here are some key points to remember about syntax-directed translation:

1. Syntax-directed translation is based on the context-free grammar of the source language.
2. Each production in the grammar is associated with a set of semantic rules that specify how to translate the constructs represented by the production.
3. The translation is performed by attaching actions to the productions in the grammar and executing these actions during parsing.
4. The actions can be used to build an abstract syntax tree, perform type checking, and generate intermediate code.
5. Syntax-directed translation can be implemented using either a top-down or a bottom-up parsing algorithm.
6. Attribute grammars are a formalism for specifying syntax-directed translations.
