# Unit 5 - Code Generation

### Value Numbers and Algebraic Laws

- Value numbering is a technique used in code generation to identify expressions that compute the same value at runtime.
- This technique is used to eliminate redundant computations and improve the efficiency of the generated code.
- Algebraic laws are used to simplify expressions and reduce the number of operations required to compute a value.
- Some common algebraic laws used in code generation include:
  - Commutative laws: `a + b = b + a` and `a * b = b * a`
  - Associative laws: `(a + b) + c = a + (b + c)` and `(a * b) * c = a * (b * c)`
  - Distributive laws: `a * (b + c) = (a * b) + (a * c)` and `a + (b * c) = (a + b) * (a + c)`
  - Identity laws: `a + 0 = a` and `a * 1 = a`
  - Inverse laws: `a + (-a) = 0` and `a * (1/a) = 1` (for `a ≠ 0`)
- These laws can be applied to expressions to simplify them and reduce the number of operations required to compute their value.
- Value numbering and the application of algebraic laws are important techniques used in code generation to improve the efficiency of the generated code.
