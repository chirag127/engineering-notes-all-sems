### Semantic Errors

Semantic errors occur when the code is syntactically correct, but the meaning of the code is not what the programmer intended. These errors are often more difficult to detect and fix than syntax errors because the code can still run, but the output may not be what was expected.

In the context of Compiler Design and Symbol Tables, semantic errors can occur due to various reasons, such as:

1. Incorrect use of identifiers: If an identifier is used before it is declared or defined, or if it is used in a way that is inconsistent with its declaration, a semantic error can occur.

2. Type mismatches: If an operation is performed on operands of incompatible types, a semantic error can occur. For example, attempting to add a string and an integer.

3. Scope errors: If an identifier is used outside of its scope, a semantic error can occur. For example, using a local variable outside of the function in which it is declared.

4. Parameter mismatches: If the number or types of arguments passed to a function do not match the function's declaration, a semantic error can occur.

5. Undeclared functions: If a function is called before it is declared or defined, a semantic error can occur.

These are some common examples of semantic errors that can occur in the context of Compiler Design and Symbol Tables. It is important to carefully check the code for these types of errors to ensure that it behaves as intended.
