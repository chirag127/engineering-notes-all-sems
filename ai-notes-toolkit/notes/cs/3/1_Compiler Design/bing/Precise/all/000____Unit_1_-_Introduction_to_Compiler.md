## Unit 1 - Introduction to Compiler

A compiler is a computer program that translates source code written in a high-level programming language into machine code, which is a low-level language that can be executed by a computer's processor.

1. **Source code** is the human-readable code written by a programmer in a high-level language such as C, C++, or Java.
2. **Machine code** is the binary code that a computer's processor can execute directly.
3. The process of translation from source code to machine code is called **compilation**.
4. Compilers perform several tasks during the compilation process, including lexical analysis, syntax analysis, semantic analysis, code generation, and optimization.
5. **Lexical analysis** involves breaking the source code into individual tokens, such as keywords, identifiers, and operators.
6. **Syntax analysis** involves checking the source code for syntactical errors and building a parse tree to represent the structure of the code.
7. **Semantic analysis** involves checking the source code for semantic errors, such as type mismatches and undeclared variables.
8. **Code generation** involves generating machine code from the parse tree.
9. **Optimization** involves improving the efficiency of the generated machine code.
10. Compilers can be classified based on the number of passes they make over the source code. A **single-pass compiler** makes one pass over the source code, while a **multi-pass compiler** makes multiple passes.
