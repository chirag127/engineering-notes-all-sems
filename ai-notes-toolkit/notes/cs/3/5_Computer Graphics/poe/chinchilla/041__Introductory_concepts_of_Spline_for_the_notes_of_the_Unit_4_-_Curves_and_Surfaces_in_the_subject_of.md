### Introductory concepts of Spline for the notes of the Unit 4 - Curves and Surfaces in the subject of Computer Graphics

Spline is one of the fundamental concepts in computer graphics used to create smooth curves and surfaces. It is used to approximate a complex curve or surface by breaking it down into smaller, simpler segments. Here are some introductory concepts of spline that you need to know:

1. Definition of Spline: A spline is a mathematical function used to approximate a curve or surface by breaking it down into smaller segments. These segments are usually called control points or knots.

2. Types of spline: There are different types of spline, but the most commonly used are B-spline and NURBS (Non-uniform rational B-spline). Both types of spline are used to create smooth curves and surfaces.

3. B-spline: B-spline is a type of spline that uses a set of control points and a degree to create a smooth curve or surface. The degree of a B-spline determines the number of control points required to define a segment. The higher the degree, the more control points required.

4. NURBS: NURBS is a type of spline that uses a set of control points, weights, and a degree to create a smooth curve or surface. The weights of the control points determine the influence of each point on the curve or surface. The higher the weight, the more influence a point has.

5. Advantages of Spline: Spline has several advantages in computer graphics. It allows for smooth and continuous curves and surfaces, making it ideal for creating complex shapes. It also allows for easy manipulation of the control points to modify the shape.

6. Applications of Spline: Spline is widely used in computer graphics for creating 3D models, animation, and visual effects. It is also used in CAD (Computer-Aided Design) and CAM (Computer-Aided Manufacturing) applications.

7. Limitations of Spline: Spline has some limitations, including difficulty in creating sharp corners and edges. It also requires a large number of control points to create complex shapes, which can be computationally expensive.

In conclusion, spline is a fundamental concept in computer graphics used to create smooth curves and surfaces. Understanding the different types of spline and their applications is essential in creating complex 3D models and visual effects.
