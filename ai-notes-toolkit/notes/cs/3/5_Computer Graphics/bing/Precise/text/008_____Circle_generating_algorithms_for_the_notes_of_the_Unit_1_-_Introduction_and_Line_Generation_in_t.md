### Circle generating algorithms for the notes of the Unit 1 - Introduction and Line Generation in the subject of Computer Graphics

1. **Midpoint Circle Algorithm**: This algorithm uses the midpoint of a pixel to determine the location of the next pixel. It is an efficient way to draw circles as it only requires integer calculations and can be easily implemented in hardware.

2. **Bresenham's Circle Algorithm**: This algorithm is an extension of Bresenham's line algorithm and is used to draw circles on a raster grid. It is an efficient algorithm as it uses only integer arithmetic and is easy to implement.

3. **Trigonometric Method**: This method uses trigonometric functions to calculate the coordinates of points on the circle. It is not as efficient as the other two methods as it requires floating-point calculations.

These are some of the commonly used circle generating algorithms in computer graphics. Each algorithm has its own advantages and disadvantages and the choice of algorithm depends on the specific requirements of the application.
