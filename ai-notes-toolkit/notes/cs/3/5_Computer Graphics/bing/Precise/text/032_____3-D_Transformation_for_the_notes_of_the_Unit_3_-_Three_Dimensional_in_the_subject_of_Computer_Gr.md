### 3-D Transformation

Three-dimensional (3D) transformations are used to manipulate 3D objects in computer graphics. These transformations include translation, scaling, rotation, and reflection. They are used to change the position, size, orientation, and shape of 3D objects.

1. **Translation**: Translation is the process of moving an object from one position to another. In 3D, this is done by adding a translation vector to the coordinates of the object.

2. **Scaling**: Scaling is the process of changing the size of an object. In 3D, this is done by multiplying the coordinates of the object by a scaling factor.

3. **Rotation**: Rotation is the process of rotating an object around an axis. In 3D, this is done by applying a rotation matrix to the coordinates of the object.

4. **Reflection**: Reflection is the process of flipping an object over a plane. In 3D, this is done by applying a reflection matrix to the coordinates of the object.

These transformations can be combined to create complex transformations. They are essential for creating realistic 3D graphics and animations.
