## Modeling UML Use Case Diagrams and Capturing Use Case Scenarios

1. Use Case Diagrams:
- Use case diagrams are used to capture the system's functionality and requirements at a high level.
- They represent the interaction between the system and external entities.
- They are used to model the requirements of a system.
- They are represented using ovals/ellipses representing use cases and stick figures representing actors.
- The relationships between actors and use cases are shown using lines.

2. Use Case Scenarios:
- Use case scenarios describe the sequence of steps that occur when a use case is executed.
- They are represented in a numbered or bulleted list format.
- They describe the interactions between the system and actors to achieve the goals of a use case.
- They help in understanding the functionality of the system in a textual format.
- They are used to validate the use case diagrams and understand the system requirements in depth.

The topics covered here will be useful in understanding how to model UML use case diagrams and capture use case scenarios which can be utilized to document the requirements of a software system. These concepts are essential to understand for Software Engineering lab sessions and exams.
