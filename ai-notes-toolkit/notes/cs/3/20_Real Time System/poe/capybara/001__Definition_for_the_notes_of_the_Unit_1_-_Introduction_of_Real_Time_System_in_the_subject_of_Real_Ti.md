### Definition for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System

Real-time systems are computer systems that are designed to respond to events or input within a specific time frame. These systems are used in many different applications, including industrial control systems, avionics, and medical devices.

Here are some key definitions and concepts related to real-time systems:

- **Real-time:** A system is considered real-time if it is able to respond to an event or input within a specific time frame. This time frame is usually measured in milliseconds or microseconds.
- **Hard real-time:** A system is considered hard real-time if it must respond to an event or input within a guaranteed time frame. Failure to do so could result in serious consequences, such as a system failure or a safety hazard.
- **Soft real-time:** A system is considered soft real-time if it is able to respond to an event or input within a reasonable time frame, but there is no guarantee that the response time will be met. Failure to meet the response time may not have serious consequences.
- **Deadlines:** In real-time systems, deadlines are used to specify the time frame within which a response must be provided. Deadlines can be hard or soft, depending on the consequences of a missed deadline.
- **Concurrency:** Real-time systems often have to deal with multiple events or inputs that must be processed simultaneously. Concurrency is the ability of a system to handle these events or inputs in parallel.
- **Scheduling:** Real-time systems use scheduling algorithms to prioritize the processing of events or inputs. The scheduling algorithm determines which events or inputs are processed first, based on their priority and deadline.
- **Response time analysis:** Real-time systems must be analyzed to ensure that they are able to meet their deadlines. Response time analysis involves calculating the worst-case response time for each event or input, and ensuring that the response time is within the required time frame.

By understanding these key concepts and definitions, you will be better equipped to understand and design real-time systems.
