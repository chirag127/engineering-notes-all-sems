
### Hard Real Time Systems

* Hard real-time systems are designed to guarantee a certain level of performance.
* They are used in applications where a certain task must be completed within a specified amount of time, such as controlling a nuclear power plant, controlling an aircraft, or managing a financial transaction.
* Hard real-time systems must be able to guarantee that a task will be completed within a certain amount of time, which is known as the deadline.
* These systems must be able to manage tasks that require a high degree of accuracy and reliability.
* In order to guarantee the performance of hard real-time systems, they must be designed to be deterministic, meaning that the system must always produce the same output for a given set of inputs.
* Hard real-time systems must also be able to handle a large number of tasks simultaneously, as well as handle unexpected events.
* In order to achieve this, hard real-time systems must be designed with a high degree of fault tolerance.
