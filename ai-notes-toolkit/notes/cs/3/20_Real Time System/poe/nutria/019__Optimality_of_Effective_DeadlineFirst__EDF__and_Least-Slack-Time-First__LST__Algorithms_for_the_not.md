
### Optimality of Effective Deadline First (EDF) and Least-Slack-Time-First (LST) Algorithms for the notes of the Unit 2 - Real Time Scheduling in the subject of Real Time System

1. The Effective Deadline First (EDF) algorithm is an optimal scheduling algorithm for real-time systems. 
2. It ensures that all tasks are completed before their deadlines and that the overall system performance is maximized. 
3. The EDF algorithm is based on the concept of deadlines, which are the latest time at which a task must be completed. 
4. The EDF algorithm assigns the highest priority to the task with the nearest deadline. 
5. The Least-Slack-Time-First (LST) algorithm is another optimal scheduling algorithm for real-time systems. 
6. It is based on the concept of slack time, which is the difference between the current time and the task's deadline. 
7. The LST algorithm assigns the highest priority to the task with the least amount of slack time. 
8. Both the EDF and LST algorithms are optimal scheduling algorithms for real-time systems, as they ensure that all tasks are completed before their deadlines and that the overall system performance is maximized.
