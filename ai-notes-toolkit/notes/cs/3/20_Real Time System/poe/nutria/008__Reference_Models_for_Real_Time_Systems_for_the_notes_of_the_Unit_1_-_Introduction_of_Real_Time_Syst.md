
### Reference Models for Real Time Systems
* A real-time system is a system in which the correctness of the result is not only dependent on its logical correctness, but also on the time in which it is produced.
* Real-time systems are used in a wide range of applications such as process control, robotics, avionics, telecommunications, embedded systems, and medical systems. 
* The reference models for real-time systems are conceptual frameworks used to describe the behavior of real-time systems. 
* The most commonly used reference models are the Rate Monotonic Analysis (RMA) and the Earliest Deadline First (EDF) models. 
* The Rate Monotonic Analysis (RMA) model is based on the assumption that higher priority tasks are assigned higher rates. 
* The Earliest Deadline First (EDF) model is based on the assumption that tasks with the earliest deadlines are given higher priority. 
* Both RMA and EDF models are used to analyze the scheduling of tasks in real-time systems. 
* These models can be used to determine the feasibility of a given task set and to optimize the performance of a real-time system.
