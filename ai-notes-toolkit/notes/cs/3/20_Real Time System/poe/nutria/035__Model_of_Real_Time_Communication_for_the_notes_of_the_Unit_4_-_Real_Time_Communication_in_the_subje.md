
### Model of Real Time Communication

1. Real-Time Systems (RTSs) are systems in which the correctness of the system depends not only on the logical correctness of the results, but also on the time at which the results are produced.
2. Real-Time Systems can be divided into two categories: Hard Real-Time Systems (HRTSs) and Soft Real-Time Systems (SRTSs). 
3. HRTSs are systems in which the correctness of the system depends not only on the logical correctness of the results, but also on the time at which the results are produced and the system must meet the deadlines set by the real-time constraints.
4. SRTSs are systems in which the correctness of the system depends not only on the logical correctness of the results, but also on the time at which the results are produced, but the system may not meet the deadlines set by the real-time constraints.
5. Real-Time Communication (RTC) is a type of communication which is used to exchange data between two or more devices in a timely manner. 
6. RTC is used in many applications such as online gaming, video conferencing, stock trading, etc.
7. RTC can be achieved by using protocols such as TCP/IP, UDP, etc.
8. RTC is also used to synchronize devices in distributed systems.
9. RTC can be used for both wired and wireless communication.
10. RTC can be used for both point-to-point communication and broadcast communication.
