
### Basic Concepts in Real Time Communication
1. Real-time systems: A real-time system is a system that must respond to external events within a specified time period. This time period is known as the deadline. Real-time systems are used in applications such as embedded systems, robotics, process control, and multimedia applications. 
2. Scheduling algorithms: Scheduling algorithms are used to determine how tasks are allocated to resources in a real-time system. Examples of scheduling algorithms include Earliest Deadline First (EDF), Rate Monotonic Scheduling (RMS), and Least Laxity First (LLF). 
3. Preemptive scheduling: Preemptive scheduling is a type of scheduling algorithm where tasks can be interrupted in order to execute higher priority tasks. 
4. Non-preemptive scheduling: Non-preemptive scheduling is a type of scheduling algorithm where tasks cannot be interrupted in order to execute higher priority tasks. 
5. Priority inversion: Priority inversion is a phenomenon where a low-priority task is able to prevent the execution of a high-priority task. Priority inversion can occur in both preemptive and non-preemptive scheduling algorithms. 
6. Priority inheritance: Priority inheritance is a technique used to avoid priority inversion. In this technique, the priority of a task is temporarily increased in order to allow the execution of higher priority tasks. 
7. Synchronization: Synchronization is the process of coordinating the activities of multiple tasks in a real-time system. Synchronization techniques include semaphores, monitors, and message passing. 
8. Real-time communication: Real-time communication is the process of exchanging data between two or more nodes in a real-time system. Examples of real-time communication protocols include Ethernet, CAN, and USB.
