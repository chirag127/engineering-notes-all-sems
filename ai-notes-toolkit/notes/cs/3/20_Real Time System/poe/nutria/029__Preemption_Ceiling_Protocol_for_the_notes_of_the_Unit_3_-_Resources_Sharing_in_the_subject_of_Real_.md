
### Preemption Ceiling Protocol

1. Preemption Ceiling Protocol is a scheduling algorithm used in real-time systems. It is used to ensure that high-priority tasks are not delayed by low-priority tasks. 

2. The Preemption Ceiling Protocol works by assigning a priority ceiling to each task. The priority ceiling is the highest priority a task can have while it is running. 

3. When a task is running, no other task with a higher priority than the priority ceiling can preempt the task. This ensures that the task will finish in a timely manner. 

4. When a task is finished, the priority ceiling is lowered to the priority of the next highest priority task in the system. This ensures that the higher priority task can preempt the lower priority tasks. 

5. The Preemption Ceiling Protocol is an effective way to ensure that higher priority tasks are not delayed by lower priority tasks. It is also an efficient way to manage resources in real-time systems.
