
### Definition for the Notes of Unit 1 - Introduction to Real Time System

1. Real Time System (RTS): A type of system where the correctness of the system depends on the results being produced in a timely manner.

2. Timeliness: The ability of a system to meet deadlines and produce results in a timely manner.

3. Hard Real Time System: A type of system where the correctness of the system depends on the results being produced within a specified time limit.

4. Soft Real Time System: A type of system where the correctness of the system depends on the results being produced within a certain time frame.

5. Preemptive Scheduling: A type of scheduling algorithm which assigns tasks to processors based on priority.

6. Non-preemptive Scheduling: A type of scheduling algorithm which assigns tasks to processors based on the order in which the tasks are received.

7. Critical Section Problem: A type of problem where multiple processes are accessing and modifying a shared resource.
