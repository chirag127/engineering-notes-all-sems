## Unit 4 - Real Time Communication

Real time communication is the exchange of information between two or more parties without significant delay. Real time communication can be synchronous or asynchronous, depending on whether the parties are expected to respond immediately or not. Some examples of real time communication are:

- Voice calls
- Video calls
- Instant messaging
- Live streaming
- Online gaming
- Collaborative editing

Some of the benefits of real time communication are:

- It enables faster and more efficient communication and collaboration.
- It enhances the quality and richness of the communication experience.
- It reduces the need for travel and physical meetings.
- It supports social interaction and engagement.

Some of the challenges of real time communication are:

- It requires high bandwidth and low latency network connections.
- It may pose security and privacy risks if the communication is not encrypted or authenticated.
- It may cause distraction and interruption if not managed properly.
- It may create communication overload and fatigue if used excessively.

Some of the technologies and protocols that enable real time communication are:

- Web Real-Time Communication (WebRTC): A set of standards and APIs that allow web browsers and applications to establish peer-to-peer connections for audio, video, and data communication.
- Session Initiation Protocol (SIP): A signaling protocol that initiates, modifies, and terminates multimedia sessions over the Internet Protocol (IP) network.
- Real-time Transport Protocol (RTP): A protocol that defines the format and delivery of audio and video data over IP networks.
- Real-time Messaging Protocol (RTMP): A protocol that enables the streaming of audio and video data between a server and a client.
- WebSocket: A protocol that enables bidirectional and full-duplex communication between a web server and a web browser.
