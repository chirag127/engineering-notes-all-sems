### Definition for the notes of the Unit 1 - Introduction of Real Time System in the subject of Real Time System

- A **real time system** is a system that must respond to events or stimuli from the environment within a specified time interval.
- A **real time system** can be classified into two types: **hard real time system** and **soft real time system**.
- A **hard real time system** is a system that must meet all the deadlines, otherwise it may cause catastrophic consequences or failure. For example, a nuclear reactor control system, a flight control system, a pacemaker, etc.
- A **soft real time system** is a system that can tolerate some missed deadlines, but the quality of service or performance may degrade. For example, a video streaming system, a voice recognition system, a multimedia system, etc.
- A **real time system** can be characterized by four main attributes: **timeliness**, **reliability**, **predictability**, and **adaptability**.
- **Timeliness** means that the system must respond to events or stimuli within a specified time interval, which can be either absolute or relative.
- **Reliability** means that the system must perform its functions correctly and consistently, even in the presence of faults or errors.
- **Predictability** means that the system must behave in a deterministic and consistent manner, and the worst-case execution time and response time of the system must be known or bounded.
- **Adaptability** means that the system must be able to adjust its behavior or parameters according to the changes in the environment or the system itself.
