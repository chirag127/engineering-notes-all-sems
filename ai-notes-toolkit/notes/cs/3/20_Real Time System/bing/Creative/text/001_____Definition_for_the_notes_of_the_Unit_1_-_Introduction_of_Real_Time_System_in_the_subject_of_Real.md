### Definition for the notes of the Unit 1 - Introduction of Real Time System

- A **real time system** is a system that must respond to events within a specified time interval, otherwise it may cause unacceptable consequences or failure.
- A **real time system** consists of a set of **tasks** that have timing constraints and must be executed according to a predefined schedule or priority.
- A **real time system** can be classified into two types: **hard real time system** and **soft real time system**.
- A **hard real time system** is a system that must meet all the deadlines, otherwise it may result in catastrophic damage or loss of life. For example, a nuclear reactor control system, a pacemaker, or an air traffic control system.
- A **soft real time system** is a system that can tolerate some deadline misses, but the quality of service may degrade. For example, a video streaming system, a voice recognition system, or a multimedia system.
- A **real time system** can also be classified into two types: **event-triggered system** and **time-triggered system**.
- An **event-triggered system** is a system that executes tasks based on the occurrence of external or internal events. For example, a sensor network, a fire alarm system, or a keyboard input.
- A **time-triggered system** is a system that executes tasks based on the passage of time. For example, a periodic task, a clock synchronization system, or a time division multiple access system.
