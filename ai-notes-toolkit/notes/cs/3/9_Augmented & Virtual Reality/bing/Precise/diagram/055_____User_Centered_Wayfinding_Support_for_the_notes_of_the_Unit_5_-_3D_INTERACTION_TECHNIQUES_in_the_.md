### User Centered Wayfinding Support

1. User-centered wayfinding support is an important issue during the architectural planning phase, as well as the understanding of human behavior during interaction with unfamiliar complex buildings.
2. Wayfinding in 3D user interfaces is a difficult problem due to the differences between wayfinding in the real world and the virtual world.
3. The immersion in a virtual world is enhanced if the user can interact with it, preferably in natural ways.
4. A user-centered user experience engineering process can be used to design, prototype, and test cognition-driven, context-dependent, and personalized augmented reality user interface and interaction methods.
5. Wayfinding and spatial knowledge can be improved through the use of landmark knowledge, which includes the visual characteristics of the environment such as shape, size, and texture, as well as procedural knowledge, which is the sequence of actions required to follow a path.
