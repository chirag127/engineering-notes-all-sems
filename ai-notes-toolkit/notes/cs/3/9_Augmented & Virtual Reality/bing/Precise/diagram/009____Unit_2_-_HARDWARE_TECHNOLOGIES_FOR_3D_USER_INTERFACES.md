## Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES

1. **3D Display Technologies:** These technologies enable the user to view 3D images and videos. Some examples include stereoscopic displays, autostereoscopic displays, and volumetric displays.

2. **3D Input Devices:** These devices allow the user to interact with 3D environments. Some examples include 3D mice, 3D trackers, and haptic devices.

3. **3D Audio Technologies:** These technologies provide the user with 3D sound. Some examples include binaural audio, ambisonics, and wave field synthesis.

4. **3D Printing Technologies:** These technologies enable the user to create physical 3D objects. Some examples include fused deposition modeling, stereolithography, and selective laser sintering.

5. **Virtual Reality Headsets:** These devices provide the user with an immersive 3D experience. Some examples include the Oculus Rift, HTC Vive, and PlayStation VR.

6. **Augmented Reality Technologies:** These technologies overlay virtual 3D objects onto the real world. Some examples include the Microsoft HoloLens, Google Glass, and Magic Leap.

7. **Motion Capture Technologies:** These technologies capture the movement of the user and translate it into 3D animations. Some examples include optical motion capture, inertial motion capture, and magnetic motion capture.
