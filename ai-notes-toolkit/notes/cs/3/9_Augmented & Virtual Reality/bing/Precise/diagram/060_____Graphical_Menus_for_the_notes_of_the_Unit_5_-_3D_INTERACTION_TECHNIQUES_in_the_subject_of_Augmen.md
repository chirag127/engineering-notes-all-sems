# Unit 5 - 3D INTERACTION TECHNIQUES
## Graphical Menus

- Graphical menus are a type of user interface element that presents a list of options to the user in a visual manner.
- They are commonly used in 3D interaction techniques, such as in virtual and augmented reality environments.
- Graphical menus can be designed in various ways, such as radial menus, pie menus, or linear menus.
- They can be activated by different input methods, such as hand gestures, gaze, or voice commands.
- The design of graphical menus should take into account the context of use, the user's task, and the available input methods.
- Graphical menus can improve the user experience by providing an intuitive and efficient way to access commands and options.
- However, they can also introduce challenges, such as occlusion and clutter, which need to be carefully managed.
