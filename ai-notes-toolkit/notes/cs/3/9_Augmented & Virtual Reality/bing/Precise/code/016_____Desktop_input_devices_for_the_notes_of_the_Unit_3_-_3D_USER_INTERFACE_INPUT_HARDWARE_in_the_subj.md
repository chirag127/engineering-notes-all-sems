### Desktop input devices for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

1. **Mouse**: A mouse is a handheld pointing device that detects two-dimensional motion relative to a surface. It is used to move a cursor on the screen and to interact with graphical user interfaces.
2. **Keyboard**: A keyboard is a typewriter-style device that uses an arrangement of buttons or keys to act as mechanical levers or electronic switches. It is used to input text and commands into a computer.
3. **Trackball**: A trackball is a pointing device consisting of a ball held by a socket containing sensors to detect a rotation of the ball about two axes. It is similar to a mouse, but the ball is rolled with the fingers instead of moving the whole device.
4. **Touchpad**: A touchpad is a pointing device featuring a tactile sensor, a specialized surface that can translate the motion and position of a user's fingers to a relative position on the operating system that is made output to the screen.
5. **Graphics tablet**: A graphics tablet is a computer input device that enables a user to hand-draw images, animations, and graphics, with a special pen-like stylus, similar to the way a person draws images with a pencil and paper.
6. **Joystick**: A joystick is an input device consisting of a stick that pivots on a base and reports its angle or direction to the device it is controlling. It is often used for gaming and for controlling machines such as cranes and trucks.
7. **Microphone**: A microphone is an acoustic-to-electric transducer or sensor that converts sound in air into an electrical signal. It is used to input voice commands and audio into a computer.
8. **Webcam**: A webcam is a video camera that feeds or streams an image or video in real-time to or through a computer to a computer network, such as the Internet. It is used for video conferencing and for capturing images and videos.
