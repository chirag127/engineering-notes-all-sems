### Database - World Space

Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. A database is a structured collection of data that is stored and organized in a way that allows for easy retrieval and manipulation of the data.
2. In the context of augmented and virtual reality, a database can be used to store information about the virtual world, including the objects, characters, and environment.
3. World space refers to the virtual environment in which the user interacts with the virtual objects and characters.
4. The database can be used to store information about the position, orientation, and properties of the objects and characters in the world space.
5. This information can be used to render the virtual world and to enable interactions between the user and the virtual objects and characters.
6. The use of a database in augmented and virtual reality can improve the performance and realism of the virtual world by allowing for efficient storage and retrieval of information about the world space.
