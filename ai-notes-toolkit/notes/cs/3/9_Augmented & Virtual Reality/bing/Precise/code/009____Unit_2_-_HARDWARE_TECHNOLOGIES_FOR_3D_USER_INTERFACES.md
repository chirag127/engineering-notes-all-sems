## Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES

1. **3D Input Devices**: These devices allow users to interact with 3D environments and objects. Examples include 3D mice, joysticks, and motion controllers.
2. **3D Displays**: These displays provide a 3D visual experience to the user. Examples include stereoscopic displays, head-mounted displays, and volumetric displays.
3. **Haptic Feedback Devices**: These devices provide tactile feedback to the user, allowing them to feel virtual objects. Examples include force feedback devices and haptic gloves.
4. **Tracking Systems**: These systems track the position and orientation of the user and/or input devices. Examples include optical tracking systems, magnetic tracking systems, and inertial tracking systems.
5. **Audio Systems**: These systems provide 3D audio to the user, allowing them to hear sounds from different directions. Examples include surround sound systems and binaural audio systems.
