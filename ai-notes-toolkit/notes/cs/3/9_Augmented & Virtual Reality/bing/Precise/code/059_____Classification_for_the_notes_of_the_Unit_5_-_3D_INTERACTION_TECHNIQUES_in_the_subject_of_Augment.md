### Classification for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. **Selection and Manipulation Techniques**: These techniques allow the user to select and manipulate virtual objects in 3D space. Examples include ray-casting, virtual hand, and image plane techniques.

2. **Navigation Techniques**: These techniques allow the user to navigate through the virtual environment. Examples include real walking, walking-in-place, and flying.

3. **System Control Techniques**: These techniques allow the user to control the system and its settings. Examples include menus, buttons, and voice commands.

4. **Symbolic Input Techniques**: These techniques allow the user to input symbolic information, such as text or numbers. Examples include virtual keyboards and handwriting recognition.

5. **Multi-Modal Techniques**: These techniques combine multiple interaction techniques to provide a richer and more natural user experience. Examples include combining gesture and voice input, or combining haptic and visual feedback.
