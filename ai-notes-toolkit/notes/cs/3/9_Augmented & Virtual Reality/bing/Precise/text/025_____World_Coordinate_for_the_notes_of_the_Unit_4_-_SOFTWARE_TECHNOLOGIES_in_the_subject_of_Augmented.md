### World Coordinate

- World Coordinate is a term used in Augmented and Virtual Reality.
- It refers to the coordinate system used to represent the position and orientation of virtual objects in a 3D space.
- The World Coordinate system is typically defined as a right-handed Cartesian coordinate system, with the X-axis pointing to the right, the Y-axis pointing up, and the Z-axis pointing out of the screen.
- The origin of the World Coordinate system is usually defined as the center of the virtual world.
- In Augmented Reality, the World Coordinate system is often aligned with the real world, so that virtual objects can be accurately placed in the real environment.
- In Virtual Reality, the World Coordinate system is used to define the virtual environment and the position of the user within it.
- Understanding and properly using the World Coordinate system is essential for creating realistic and immersive Augmented and Virtual Reality experiences.
