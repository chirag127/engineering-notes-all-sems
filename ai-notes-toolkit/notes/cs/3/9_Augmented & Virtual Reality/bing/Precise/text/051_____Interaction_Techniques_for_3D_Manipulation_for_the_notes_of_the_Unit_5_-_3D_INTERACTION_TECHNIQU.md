### Interaction Techniques for 3D Manipulation

1. **Virtual Hand**: This technique allows the user to interact with virtual objects as if they were using their real hand. The user can grab, move, and manipulate objects in 3D space using a virtual hand controlled by a tracking device.

2. **Ray Casting**: This technique involves pointing a virtual ray from the user's hand or a handheld device and selecting or manipulating objects that the ray intersects with.

3. **Haptic Feedback**: This technique provides the user with tactile feedback when interacting with virtual objects. This can enhance the realism of the interaction and provide the user with a better sense of the properties of the virtual objects.

4. **Voice Commands**: This technique allows the user to issue voice commands to manipulate objects in 3D space. This can be useful for hands-free interaction or when the user's hands are occupied with other tasks.

5. **Gestures**: This technique involves using hand or body gestures to manipulate objects in 3D space. Gestures can be recognized by tracking devices or cameras and can provide a natural and intuitive way to interact with virtual objects.

6. **Physical Props**: This technique involves using physical objects as props to manipulate virtual objects. The physical props can be tracked and their movements can be mapped to the movements of virtual objects.

7. **Multi-Modal Interaction**: This technique involves combining multiple interaction techniques to provide a richer and more flexible interaction experience. For example, a user might use a combination of voice commands, gestures, and haptic feedback to manipulate objects in 3D space.

These are some of the common interaction techniques used for 3D manipulation in the field of Augmented and Virtual Reality. Each technique has its own strengths and limitations and the choice of technique will depend on the specific application and user needs.
