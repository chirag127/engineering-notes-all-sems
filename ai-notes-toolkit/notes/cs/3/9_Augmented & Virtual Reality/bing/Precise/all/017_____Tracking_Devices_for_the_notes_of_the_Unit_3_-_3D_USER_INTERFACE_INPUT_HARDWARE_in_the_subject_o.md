# Tracking Devices for 3D User Interface Input Hardware in Augmented and Virtual Reality

- Tracking devices are used to track the movements of the user in 3D space and provide input to the augmented or virtual reality system.
- One approach to tracking is to use infrared-reflecting markers on 3D input devices, which are then optically tracked by well-calibrated infrared stereo cameras.
- Another approach is to use computer-vision-based software tracking libraries, such as PTC Vuforia Engine, Unity AR Foundation, Google ARCore, or Apple ARKit.
- There are also pen-like input devices, such as the Holo Stylus 3D, which are designed to be easy to use and cover a wide range of applications.
- Traditional input devices, such as keyboards, 2D mice, trackballs, pen- and touch-based tablets, and joysticks, can also be used in desktop 3D user interfaces.
- 6-DOF (degrees of freedom) devices, such as the SpaceBall, SpaceMouse, and SpaceOrb, can also be used to provide input without tracking.
