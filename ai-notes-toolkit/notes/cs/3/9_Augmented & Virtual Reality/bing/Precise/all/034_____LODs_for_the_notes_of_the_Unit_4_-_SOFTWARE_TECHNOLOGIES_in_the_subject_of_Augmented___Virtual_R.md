# Unit 4 - SOFTWARE TECHNOLOGIES in Augmented & Virtual Reality

### LODs

- LODs, or Levels of Detail, is a technique used in computer graphics to manage the complexity of 3D models in real-time rendering.
- The basic idea behind LODs is to use simplified versions of a 3D model when it is far away from the camera, and more detailed versions when it is closer.
- This can help improve performance by reducing the number of polygons that need to be rendered, while still maintaining visual quality.
- LODs can be generated automatically by software, or they can be created manually by artists.
- In the context of Augmented and Virtual Reality, LODs can be used to improve the performance of real-time rendering, allowing for more complex and detailed virtual environments.
