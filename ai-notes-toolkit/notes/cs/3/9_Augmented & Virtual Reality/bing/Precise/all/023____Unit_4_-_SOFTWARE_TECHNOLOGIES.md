## Unit 4 - SOFTWARE TECHNOLOGIES

1. **Software Technologies** refer to the tools, techniques, and methodologies used in the development, deployment, and maintenance of software systems.

2. **Software Development Methodologies** are the frameworks used to structure, plan, and control the process of developing software systems. Some popular methodologies include Waterfall, Agile, and DevOps.

3. **Programming Languages** are the formal languages used to write software programs. Some popular programming languages include Java, Python, and C++.

4. **Software Libraries** are collections of pre-written code that can be used to perform common tasks, such as data manipulation or network communication.

5. **Integrated Development Environments (IDEs)** are software applications that provide a comprehensive environment for software development, including tools for coding, debugging, and testing.

6. **Version Control Systems** are tools used to manage changes to source code over time, allowing developers to track changes, collaborate, and revert to previous versions if necessary.

7. **Software Testing** is the process of evaluating software to ensure that it meets specified requirements and performs as expected. Testing can be performed manually or automated using specialized tools.

8. **Deployment** refers to the process of releasing software to users, either by installing it on their devices or making it available through a network.

9. **Maintenance** involves updating and improving software over time to fix bugs, add new features, and improve performance.

10. **Documentation** is an important part of software development, providing information about how to use, maintain, and extend the software. Documentation can take many forms, including user manuals, API documentation, and inline comments in the source code.
