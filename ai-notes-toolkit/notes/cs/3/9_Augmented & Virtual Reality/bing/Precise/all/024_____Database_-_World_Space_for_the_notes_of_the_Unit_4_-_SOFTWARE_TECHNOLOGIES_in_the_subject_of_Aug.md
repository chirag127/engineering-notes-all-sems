# Database - World Space

Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. A database is a collection of data that is organized and stored in a structured manner.
2. In the context of Augmented and Virtual Reality, a database can be used to store information about the virtual world, including objects, their properties, and their relationships with each other.
3. World space refers to the virtual environment in which the objects in the database exist.
4. The world space can be thought of as a coordinate system, with the origin at the center of the virtual world and the axes representing the dimensions of the virtual space.
5. Objects in the world space can be positioned, rotated, and scaled relative to the origin and axes of the coordinate system.
6. The use of a database in conjunction with a world space allows for efficient management and manipulation of the virtual environment, enabling the creation of complex and immersive experiences in Augmented and Virtual Reality.
