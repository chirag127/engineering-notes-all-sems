# Multimodal System Control Techniques for 3D INTERACTION TECHNIQUES in Augmented & Virtual Reality

Multimodal interaction refers to the use of multiple modes of input and output to interact with a computer system. In the context of 3D interaction techniques in augmented and virtual reality, this can include the use of gestures, spoken language, and other forms of input to control the system.

1. One approach to 3D multimodal interaction in immersive augmented and virtual reality environments accounts for the uncertain nature of the information sources. The resulting multimodal system fuses symbolic and statistical information from a set of 3D gesture, spoken language, and referential agents.

2. Augmented Reality (AR) has proposed several types of interaction techniques such as 3D interactions, natural interactions, tangible interactions, spatial awareness interactions and multimodal interactions. The combination of more than one modality is called multimodal.

3. A virtual reality environment with multimodal interaction technique is presented that allows user to interact with the virtual reality system with the static and stroke hand gesture along with speech and is able to perform few functions.

4. With the boost of computing power in mobile devices and availability of cloud APIs in recent years, mobile augmented reality (AR) applications have become increasingly embedded in people's everyday life.

5. An example of a multimodal interaction algorithm based on AR (ARGEV algorithm) uses the Kinect depth camera to obtain the (n-1) frame gesture depth map and input it into the AlexNet_gesture model for gesture recognition. The output includes vibration feedback and visual effects.
