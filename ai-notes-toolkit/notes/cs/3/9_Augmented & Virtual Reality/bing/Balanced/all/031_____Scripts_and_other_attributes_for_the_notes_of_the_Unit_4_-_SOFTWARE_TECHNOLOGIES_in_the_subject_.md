# Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- **Scripts** are sequences of commands or instructions that are executed by a software program or a system. Scripts can be used to automate tasks, perform calculations, manipulate data, control the flow of execution, or interact with other software components.
- **Attributes** are properties or characteristics of an object, a class, a method, or a variable. Attributes can be used to store information, define behavior, or modify the appearance or functionality of a software element.
- Some examples of scripts and attributes that are relevant for the subject of augmented and virtual reality are:

  - **Unity scripts** are written in C# and are attached to game objects in the Unity engine. Unity scripts can be used to define the logic, behavior, and interaction of the game objects, as well as access the features and components of the Unity engine, such as physics, rendering, audio, input, networking, etc. 
  - **HTML attributes** are modifiers of HTML elements that provide additional information or functionality to the elements. HTML attributes can be used to specify the appearance, content, style, or behavior of the HTML elements, such as the size, color, alignment, source, link, event, etc. 
  - **ARKit scripts** are written in Swift or Objective-C and are used to create augmented reality applications for iOS devices. ARKit scripts can be used to access the features and components of the ARKit framework, such as tracking, rendering, scene understanding, face detection, image recognition, etc. 
  - **VRML scripts** are written in JavaScript and are embedded in VRML files. VRML scripts can be used to create interactive and dynamic virtual reality scenes, as well as access the features and components of the VRML language, such as nodes, fields, events, sensors, interpolators, etc.
