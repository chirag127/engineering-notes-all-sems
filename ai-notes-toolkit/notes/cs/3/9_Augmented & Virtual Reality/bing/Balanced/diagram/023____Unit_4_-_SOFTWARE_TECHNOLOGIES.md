## Unit 4 - SOFTWARE TECHNOLOGIES

- Software technologies are the tools and methods used to create, maintain, and improve software systems.
- Software technologies can be classified into different categories, such as programming languages, software development methodologies, software engineering principles, software testing techniques, software quality assurance, software security, software maintenance, and software evolution.
- Programming languages are the formal languages used to specify the instructions and data for software systems. Programming languages can be divided into low-level and high-level languages, depending on the level of abstraction and closeness to the hardware. Examples of low-level languages are assembly and machine code, while examples of high-level languages are C, Java, Python, and Ruby.
- Software development methodologies are the frameworks and processes used to organize and manage software projects. Software development methodologies can be classified into traditional and agile approaches, depending on the degree of flexibility and adaptability to changing requirements. Examples of traditional methodologies are waterfall and spiral, while examples of agile methodologies are scrum and extreme programming.
- Software engineering principles are the guidelines and best practices used to ensure the quality and reliability of software systems. Software engineering principles can be grouped into different aspects, such as software design, software architecture, software documentation, software reuse, software modularity, software cohesion, software coupling, and software abstraction.
- Software testing techniques are the methods used to verify and validate the functionality and performance of software systems. Software testing techniques can be categorized into different types, such as static and dynamic testing, white-box and black-box testing, unit testing, integration testing, system testing, and acceptance testing.
- Software quality assurance is the process of ensuring that software systems meet the specified requirements and standards. Software quality assurance can involve different activities, such as software reviews, software audits, software inspections, software metrics, software testing, and software verification and validation.
- Software security is the aspect of software engineering that deals with the protection of software systems from malicious attacks and unauthorized access. Software security can involve different techniques, such as encryption, authentication, authorization, access control, firewalls, intrusion detection and prevention, and software vulnerability analysis and patching.
- Software maintenance is the process of modifying and updating software systems after their deployment. Software maintenance can be performed for different reasons, such as correcting errors, improving performance, adding features, adapting to new environments, and complying with new standards.
- Software evolution is the process of changing and improving software systems over time. Software evolution can be driven by different factors, such as user feedback, market demand, technological innovation, and software aging. Software evolution can involve different activities, such as software reengineering, software refactoring, software reverse engineering, and software migration.
