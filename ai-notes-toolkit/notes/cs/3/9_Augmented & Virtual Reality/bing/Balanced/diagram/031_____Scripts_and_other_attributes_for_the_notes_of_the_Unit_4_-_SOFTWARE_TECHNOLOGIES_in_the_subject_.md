### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Scripts are sequences of commands or instructions that are executed by a software program or an interpreter.
- Scripts can be used to automate tasks, manipulate data, control the behavior of applications, or create interactive content.
- Scripts can be written in various languages, such as Python, JavaScript, Lua, or C#, depending on the platform and the purpose of the script.
- Some examples of scripts in augmented and virtual reality are:
  - Scripts that control the movement, animation, and interaction of 3D objects in a virtual environment.
  - Scripts that access the sensors and cameras of a device to capture the real-world data and overlay it with virtual elements.
  - Scripts that handle the user input, such as gestures, voice commands, or controllers, and respond accordingly.
  - Scripts that communicate with external servers or databases to retrieve or store information.
- Other attributes for the notes of the unit 4 are:
  - Software engineering system models, which are abstract representations of the software development process, such as the waterfall model, the spiral model, or the agile model.
  - Software project management, which is concerned with the activities involved in ensuring that software is delivered on time and on schedule and in accordance with the requirements of the organisations developing and procuring the software.
  - Software productivity applications, which are programs that help users perform tasks more efficiently and effectively, such as word processing, spreadsheet, presentation, database, note taking, calendar and contact management, project management, accounting, personal finance, legal, tax preparation, document management, support services, and enterprise computing.
  - Software automation, which is the use of scripts or other tools to perform tasks that would otherwise require human intervention, such as deploying and managing IT environments, testing and debugging software, generating reports and documentation, or performing backups and updates.
