### Objects - Geometry

- An object is a collection of data and methods that operate on that data.
- An object can represent a real-world entity, such as a person, a car, a shape, etc.
- An object has a type, which defines the properties and behaviors of the object.
- A type is also called a class, and an object is an instance of a class.
- A class can have attributes, which are variables that store data for each object of that class.
- A class can also have methods, which are functions that perform actions on or with the object's data.
- A class can inherit from another class, which means it can use the attributes and methods of the parent class, and also add or override them.
- A class can also implement an interface, which is a set of methods that the class must define.
- An interface can be used to specify the common behaviors of different classes that share some functionality, but not necessarily the same data.

- Geometry is the branch of mathematics that studies the properties and relationships of shapes, such as points, lines, angles, curves, surfaces, solids, etc.
- Geometry can be used to model and manipulate objects in computer graphics, such as augmented and virtual reality.
- Geometry can be divided into two main types: Euclidean and non-Euclidean.
- Euclidean geometry is based on the assumption that parallel lines never intersect, and that the sum of the angles of a triangle is 180 degrees.
- Non-Euclidean geometry is based on different assumptions, such as that parallel lines can intersect, or that the sum of the angles of a triangle can be more or less than 180 degrees.
- Non-Euclidean geometry can be used to model curved spaces, such as the surface of a sphere, or the space-time of general relativity.

  - Point: A point is a location in space, with no size or shape. It can be represented by a pair of coordinates (x, y) in a two-dimensional plane, or by a triple of coordinates (x, y, z) in a three-dimensional space.
  - Line: A line is a collection of points that extend infinitely in both directions. It can be represented by an equation of the form y = mx + b, where m is the slope and b is the y-intercept, or by a pair of points (x1, y1) and (x2, y2) that lie on the line.

  - Surface: A surface is a collection of points that form a two-dimensional shape. It can be represented by a function of the form z = f(x, y), where f is a mathematical expression, or by a set of polygons that approximate the shape of the surface.
