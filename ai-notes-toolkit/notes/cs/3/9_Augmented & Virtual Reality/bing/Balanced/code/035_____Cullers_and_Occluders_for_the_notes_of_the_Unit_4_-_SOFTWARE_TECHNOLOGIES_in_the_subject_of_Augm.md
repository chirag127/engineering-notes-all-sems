### Cullers and Occluders

- Cullers and occluders are techniques for improving the performance and realism of augmented and virtual reality applications by eliminating unnecessary rendering of objects or parts of objects that are not visible to the user.
- Culling is the process of discarding objects or polygons that are outside the view frustum, which is the region of space that is projected onto the screen by the camera. Culling can reduce the number of draw calls and the amount of geometry that needs to be processed by the graphics pipeline.
- Occlusion is the phenomenon of objects blocking the view of other objects behind them. Occlusion culling is the process of discarding objects or polygons that are occluded by other objects in the scene, such as walls, furniture, or the user's own body. Occlusion culling can further reduce the number of draw calls and the amount of geometry that needs to be processed by the graphics pipeline.
- Cullers and occluders can also enhance the realism and immersion of augmented and virtual reality applications by creating a more consistent and natural interaction between the real and virtual worlds. For example, occlusion culling can prevent virtual objects from appearing in front of real objects that should occlude them, such as a virtual character behind a real door. This can improve the sense of presence and spatial awareness of the user.
- Cullers and occluders can be implemented in different ways, depending on the type and complexity of the application, the available hardware and software resources, and the desired trade-off between accuracy and performance. Some of the common methods are:

  - Frustum culling: This is the simplest and most widely used form of culling, which discards objects or polygons that are outside the view frustum. This can be done by testing the bounding volumes of the objects, such as spheres, boxes, or cylinders, against the six planes of the view frustum, and rejecting those that are completely outside. Frustum culling can be done on the CPU or the GPU, and can be combined with other culling techniques for more efficiency.
  - Back-face culling: This is a form of culling that discards polygons that are facing away from the camera, and therefore are not visible to the user. This can be done by testing the dot product of the polygon normal and the camera direction, and rejecting those that are negative. Back-face culling can be done on the GPU, and can reduce the number of polygons that need to be rasterized and shaded.
  - Portal culling: This is a form of culling that discards objects or polygons that are outside the portals, which are openings or windows that connect different regions or cells of the scene. This can be done by testing the bounding volumes of the objects against the portal planes, and rejecting those that are completely outside. Portal culling can be done on the CPU or the GPU, and can be useful for indoor scenes with complex geometry and occlusion.
  - Occlusion query: This is a form of occlusion culling that uses the GPU to test the visibility of objects or polygons by rendering them into an occlusion buffer, which is a low-resolution depth buffer that stores the depth values of the pixels. This can be done by issuing occlusion queries for the bounding volumes of the objects, and retrieving the number of pixels that passed the depth test. If the number is zero, the object is occluded and can be discarded. Occlusion query can be done on the GPU, and can be useful for dynamic scenes with moving objects and occluders.
  - Depth buffer: This is a form of occlusion culling that uses the depth buffer, which is a buffer that stores the depth values of the pixels that are rendered on the screen. This can be done by testing the depth values of the pixels that belong to the objects or polygons against the depth buffer, and rejecting those that are behind. Depth buffer can be done on the GPU, and can be useful for static scenes with pre-computed depth maps or depth images.
  - Depth sensor: This is a form of occlusion culling that uses a depth sensor, which is a device that captures the depth values of the real scene. This can be done by testing the depth values of the pixels that belong to the virtual objects or polygons against the depth sensor data, and rejecting those that are behind. Depth sensor can be done on the CPU or the GPU, and can be useful for augmented reality applications with real occluders.
