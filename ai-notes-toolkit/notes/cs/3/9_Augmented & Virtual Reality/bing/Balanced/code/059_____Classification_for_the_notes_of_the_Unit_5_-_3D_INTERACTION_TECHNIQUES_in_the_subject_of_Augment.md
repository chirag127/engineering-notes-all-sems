### Classification of 3D Interaction Techniques

3D interaction techniques are methods that allow users to perform tasks in virtual environments using 3D input devices and feedback. They can be classified according to the type of task they support, such as:

- **Selection and manipulation**: These techniques enable users to select, move, rotate, scale, or deform objects in 3D space. Examples of these techniques are ray-casting, virtual hand, HOMER, and 3D widgets .
- **Navigation**: These techniques enable users to change their viewpoint or position in 3D space. Examples of these techniques are flying, walking, steering, and teleporting .
- **System control**: These techniques enable users to access menus, dialogs, or commands in 3D space. Examples of these techniques are 3D buttons, voice commands, gestures, and gaze .

Some 3D interaction techniques can support more than one type of task, such as 3D cursors, which can be used for selection, manipulation, and system control.

3D interaction techniques can also be classified according to the human control models they use, such as:

- **Position control**: These techniques map the position of the input device directly to the position of the virtual object or viewpoint. Examples of these techniques are virtual hand, flying, and 3D buttons.
- **Rate control**: These techniques map the velocity or acceleration of the input device to the velocity or acceleration of the virtual object or viewpoint. Examples of these techniques are steering, walking, and voice commands.
- **Symbolic control**: These techniques map the discrete or continuous input of the device to discrete or continuous actions in the virtual environment. Examples of these techniques are gestures, ray-casting, and 3D widgets.

Some 3D interaction techniques can use a combination of these control models, such as HOMER, which uses position control for selection and rate control for manipulation.
