### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Scripts are sequences of commands or instructions that are executed by a software program or a system. Scripts can be used to automate tasks, perform calculations, manipulate data, control the flow of execution, or interact with other programs or systems.
- Scripts can be written in various programming languages, such as Python, JavaScript, C#, Lua, etc. depending on the software or system that supports them. Scripts can also be embedded in other files, such as HTML, XML, JSON, etc. to add functionality or interactivity.
- Scripts can be used for various purposes in the context of augmented and virtual reality, such as:
  - Creating and controlling the behavior of virtual objects, characters, or environments.
  - Implementing the logic and rules of the simulation or the game.
  - Handling the input and output of the user, such as gestures, voice, eye tracking, etc.
  - Communicating with external devices, sensors, or services, such as cameras, GPS, web APIs, etc.
  - Testing and debugging the application or the system.
- Other attributes that are important for the notes of the unit 4 - software technologies in the subject of augmented and virtual reality are:
  - Software engineering principles and practices, such as project management, requirements analysis, design, implementation, testing, deployment, and maintenance.
  - Software tools and frameworks that are used to develop, run, and distribute augmented and virtual reality applications, such as Unity, Unreal Engine, ARCore, ARKit, Vuforia, etc.
  - Software standards and formats that are used to represent, store, and exchange data and information in augmented and virtual reality, such as glTF, USDZ, WebXR, etc.
  - Software security and privacy issues and challenges that are related to augmented and virtual reality, such as data protection, user consent, authentication, encryption, etc.
