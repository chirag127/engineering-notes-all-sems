## Unit 5 - 3D INTERACTION TECHNIQUES

- 3D interaction techniques are methods for interacting with 3D environments and objects using 3D input devices and modalities.
- 3D interaction techniques can be classified into four main categories: navigation, selection and manipulation, system control, and symbolic input.
- Navigation techniques allow the user to move around and explore the 3D space, such as flying, walking, or teleporting.
- Selection and manipulation techniques allow the user to select and manipulate 3D objects, such as pointing, grabbing, scaling, or rotating.
- System control techniques allow the user to control the system settings and functions, such as menus, widgets, or voice commands.
- Symbolic input techniques allow the user to enter text, numbers, or symbols in 3D, such as keyboards, handwriting, or gestures.
- 3D interaction techniques can be designed and evaluated based on various criteria, such as usability, performance, naturalness, immersion, and expressiveness .
- 3D interaction techniques can be applied to various domains and applications, such as education, training, gaming, visualization, and design .
