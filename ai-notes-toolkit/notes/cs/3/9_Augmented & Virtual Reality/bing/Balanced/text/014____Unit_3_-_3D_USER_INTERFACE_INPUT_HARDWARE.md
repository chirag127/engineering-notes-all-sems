## Unit 3 - 3D User Interface Input Hardware

- 3D user interface input hardware are devices that capture and interpret the actions performed by the user in a 3D environment.
- The main characteristics of 3D user interface input hardware are:
  - Degrees of freedom (DOF): the number of independent ways that a body can move in space. For example, a 3D mouse can have six DOF: three for translation (x, y, z) and three for rotation (pitch, yaw, roll).
  - Input type/frequency of data: the kind and amount of data that the device generates. For example, discrete input devices produce single data values (e.g. Boolean values), while continuous input devices generate multiple data values (e.g. pixel coordinates).
  - Physical interaction: the amount and type of physical effort required by the user to operate the device. For example, some devices are passive (e.g. gloves) and some are active (e.g. wands).
- Some examples of 3D user interface input hardware are:
  - Keyboards: a set of keys that can be used to enter text, commands, or shortcuts. They are typically used in desktop 3D UIs and have low DOF and discrete input type.
  - 2D mice and trackballs: devices that can move a cursor on a 2D plane. They are also used in desktop 3D UIs and have low DOF and continuous input type.
  - Pen- and touch-based tablets: devices that can sense the position and pressure of a stylus or a finger on a 2D surface. They can be used for drawing, writing, or gesturing in 3D UIs and have low to medium DOF and continuous input type.
  - Joysticks: devices that can sense the direction and magnitude of a force applied to a stick. They can be used for navigation, manipulation, or selection in 3D UIs and have medium DOF and continuous input type.
  - Wands: devices that can sense the position and orientation of a handheld device in 3D space. They can be used for pointing, selecting, or manipulating in 3D UIs and have high DOF and continuous input type.
  - Gloves: devices that can sense the position and orientation of the hand and fingers in 3D space. They can be used for gesturing, grabbing, or manipulating in 3D UIs and have high DOF and continuous input type.
  - Trackers: devices that can sense the position and orientation of the head, body, or limbs in 3D space. They can be used for navigation, interaction, or immersion in 3D UIs and have high DOF and continuous input type.
