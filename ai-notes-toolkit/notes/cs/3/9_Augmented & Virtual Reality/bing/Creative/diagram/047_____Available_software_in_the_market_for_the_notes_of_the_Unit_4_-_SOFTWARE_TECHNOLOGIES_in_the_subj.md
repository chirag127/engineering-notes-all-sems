### Available software in the market for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Augmented reality (AR) and virtual reality (VR) are two technologies that create immersive and interactive experiences for users by overlaying digital content on the real world or creating a simulated environment.
- There are various software tools available in the market for designing and developing AR and VR applications, games, and experiences. Some of the popular and widely used software are:

  - **Adobe Aero**: This is a software that allows users to create and share AR experiences without coding. Users can import 3D models, images, and animations from other Adobe tools and use them to build interactive scenes. Users can also preview and test their AR experiences on their devices and publish them to the web or social media platforms.
  - **Tvori**: This is a software that enables users to create VR animations and stories using a VR headset and controllers. Users can manipulate 3D objects, characters, and environments in a virtual space and record their movements and actions. Users can also add sounds, music, and effects to their VR creations and export them as videos or interactive experiences.
  - **Masterpiece Studio Pro**: This is a software that combines two tools, Masterpiece Creator and Masterpiece Motion, to help users create and animate 3D models for VR and AR. Users can sculpt, paint, and texture 3D models using VR controllers and then rig and animate them using motion capture or keyframes. Users can also export their 3D models to other software or platforms for further editing or publishing.
  - **Vuforia Engine**: This is a software that provides a platform for developing AR applications for various devices and platforms. Users can use the Vuforia Studio tool to create AR experiences using 3D models, animations, and UI elements. Users can also use the Vuforia SDK to integrate AR features into their existing applications using various programming languages and frameworks. Users can also leverage the Vuforia Cloud Recognition service to recognize and track images and objects in the real world.
  - **Unity 3D**: This is a software that is a cross-platform game engine and development environment for creating 2D and 3D games and applications for various platforms, including VR and AR. Users can use the Unity Editor to design and build their scenes and assets, and use the Unity Scripting API to add logic and interactivity to their games and applications. Users can also use the Unity Asset Store to access and download thousands of ready-made assets and tools for their projects.
  - **Oculus Medium**: This is a software that is a VR sculpting and modeling tool for Oculus headsets. Users can use the Oculus Touch controllers to sculpt, paint, and manipulate 3D models in a virtual space. Users can also import and export their 3D models to other software or platforms for further editing or publishing.

- These are some of the software technologies that are available in the market for AR and VR design and development. There are many other software tools that can be used for specific purposes or platforms, such as Unreal Engine, Spark AR, Lens Studio, Blender, Maya, etc. Users can choose the software that best suits their needs and preferences, depending on their level of expertise, budget, and project requirements.
