### 2D Controls for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- 2D controls are user interface elements that are displayed on a two-dimensional plane, such as buttons, sliders, menus, etc.
- 2D controls can be used in augmented reality (AR) and virtual reality (VR) applications to provide interaction and feedback to the user.
- 2D controls can be rendered on a screen, a head-mounted display (HMD), a handheld device, or a projection surface.
- 2D controls can be either static or dynamic, depending on whether they change their position, orientation, size, or appearance based on the user's input or the environment.
- 2D controls can be either direct or indirect, depending on whether they are manipulated by the user's hand, finger, gaze, voice, or other input methods.
- 2D controls can have different advantages and disadvantages in AR and VR applications, depending on the context and the design goals.

Some examples of 2D controls in AR and VR applications are:

- A 2D menu that appears on the user's HMD when they press a button on the controller, allowing them to select different options or settings.
- A 2D slider that adjusts the volume of the sound in a VR environment, which the user can drag with their finger on a touchscreen.
- A 2D map that shows the user's location and direction in a VR simulation, which the user can zoom in and out by pinching on a handheld device.
- A 2D button that triggers an action or a transition in an AR experience, which the user can tap with their finger on a projection surface.
- A 2D label that displays information or instructions to the user in an AR application, which the user can read by looking at it with their gaze.
