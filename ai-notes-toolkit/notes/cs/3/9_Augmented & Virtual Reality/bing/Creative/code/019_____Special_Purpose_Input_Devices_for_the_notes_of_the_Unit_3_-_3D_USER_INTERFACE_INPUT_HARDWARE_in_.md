### Special Purpose Input Devices for 3D User Interface

- Special purpose input devices are designed to capture specific types of input or gestures in 3D space, such as head orientation, hand position, finger movements, body posture, eye gaze, etc.
- These devices are often used in immersive or semi-immersive 3D environments, such as virtual reality (VR) or augmented reality (AR), where the user needs to interact with 3D objects or scenes.
- Some examples of special purpose input devices are:
  - Head-mounted displays (HMDs) or head trackers: These devices track the user's head orientation and position, and display stereo images to create a sense of depth and immersion. 
  - Hand-held controllers or gloves: These devices track the user's hand position and orientation, and sometimes also the finger movements or gestures. They can be used to manipulate 3D objects, point at targets, or perform commands. 
  - Motion capture systems or body trackers: These devices track the user's body posture and movements, and map them to a virtual avatar or character. They can be used for animation, gaming, or social interaction. 
  - Eye trackers: These devices track the user's eye gaze and pupil dilation, and use them as input for selection, navigation, or attention detection. 
  - Biosensors: These devices measure the user's physiological signals, such as brain activity, heart rate, skin conductance, etc., and use them as input for emotion recognition, feedback, or adaptation.
