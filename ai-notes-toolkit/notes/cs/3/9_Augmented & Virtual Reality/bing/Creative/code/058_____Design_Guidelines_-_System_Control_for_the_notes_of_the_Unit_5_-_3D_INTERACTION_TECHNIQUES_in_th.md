### Design Guidelines - System Control

- System control is the task of issuing commands or changing settings in a 3D user interface (3D UI) system.
- System control is often integrated with another 3D interaction task, such as navigation, selection, or manipulation. For example, a user may need to switch between different tools or modes while performing a task in a 3D environment.
- System control techniques should be designed to avoid disturbing the flow of action of an interaction task. For example, they should be easily accessible, intuitive, consistent, and compatible with the task and the 3D environment.
- System control techniques can be classified into three categories:
  - Adapted 2D menus: These are menus that are derived from 2D UIs, such as pop-up menus, pie menus, or radial menus. They can be displayed on a 2D surface, such as a screen or a head-up display, or on a 3D surface, such as a virtual tablet or a wall. They can be operated by pointing, clicking, or gesturing.
  - 1-DOF menus: These are menus that use one degree of freedom (DOF) for input, such as a button, a dial, or a slider. They can be physical or virtual, and can be attached to the user's body, a handheld device, or the environment. They can be operated by pressing, rotating, or sliding.
  - 3D widgets: These are graphical objects that provide direct manipulation of system parameters or functions in 3D space, such as a color picker, a volume control, or a switch. They can be physical or virtual, and can be attached to the user's body, a handheld device, or the environment. They can be operated by grabbing, moving, or releasing.
- Some general design guidelines for system control techniques are  :
  - Provide feedback: The system should provide visual, auditory, or haptic feedback to indicate the state and outcome of the system control actions.
  - Provide affordances: The system control techniques should indicate their functionality and how to operate them by using appropriate shapes, labels, icons, or sounds.
  - Provide consistency: The system control techniques should follow consistent conventions and mappings across different tasks and environments, and match the user's expectations and mental models.
  - Provide compatibility: The system control techniques should be compatible with the task and the environment, and avoid conflicts or interference with other interaction techniques or objects.
  - Provide accessibility: The system control techniques should be easily accessible and visible to the user, and avoid occlusion or clutter in the 3D space.
  - Provide efficiency: The system control techniques should minimize the number of steps, actions, or movements required to perform a system control function, and maximize the speed and accuracy of the user's input.
