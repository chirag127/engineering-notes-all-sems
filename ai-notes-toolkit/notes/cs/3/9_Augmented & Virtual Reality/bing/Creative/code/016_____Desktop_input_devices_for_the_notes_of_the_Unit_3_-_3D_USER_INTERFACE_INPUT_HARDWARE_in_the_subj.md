### Desktop input devices for 3D user interface

- Desktop input devices are devices that are typically used in desktop 3D user interfaces, which are 3D interfaces that run on a conventional 2D display and use 2D or 3D input devices.
- Desktop input devices can be classified into two categories: traditional input devices and desktop 6-DOF input devices .
- Traditional input devices are devices that are commonly used for 2D user interfaces, such as keyboards, 2D mice and trackballs, pen- and touch-based tablets, and joysticks .
  - These devices can be used for 3D user interfaces by mapping their 2D input to 3D actions, such as rotation, translation, scaling, or selection .
  - These devices have the advantages of being familiar, inexpensive, and widely available, but they also have the limitations of being low-dimensional, indirect, and constrained by the 2D display .
- Desktop 6-DOF input devices are devices that can provide six degrees of freedom (DOF) of input, which are three translational DOFs (x, y, z) and three rotational DOFs (pitch, yaw, roll) .
  - These devices can be used for 3D user interfaces by directly manipulating 3D objects or viewpoints in the virtual environment .
  - These devices have the advantages of being high-dimensional, direct, and intuitive, but they also have the limitations of being expensive, rare, and requiring calibration and registration .
  - Examples of desktop 6-DOF input devices are 3D mice, spaceballs, space navigators, and 3D trackers .
- Desktop input devices can be combined with other input modalities, such as voice, gesture, or eye tracking, to create more natural and expressive 3D user interfaces .
