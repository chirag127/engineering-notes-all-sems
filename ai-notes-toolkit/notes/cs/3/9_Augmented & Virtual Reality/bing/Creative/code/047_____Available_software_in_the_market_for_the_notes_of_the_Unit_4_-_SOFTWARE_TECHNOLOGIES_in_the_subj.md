### Available software in the market for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Augmented reality (AR) and virtual reality (VR) are two technologies that create immersive and interactive experiences for users.
- AR overlays digital information or objects on the real world, while VR creates a simulated environment that replaces the real world.
- There are many software tools and platforms that can be used to design, develop, and deploy AR and VR applications.
- Some of the best software for AR and VR design in 2023 are:

  - **Adobe Aero**: The best AR design software overall. It allows users to create and share interactive AR experiences without coding. It supports various 3D formats and integrates with other Adobe tools like Photoshop and Illustrator.
  - **Tvori**: The best budget AR design software. It is a VR-based platform that lets users create and animate 3D scenes and characters in VR. It has a simple and intuitive interface and supports various VR headsets and controllers.
  - **Masterpiece Studio Pro**: The best value VR design software. It is a suite of tools that enables users to create and edit 3D models, animations, and scenes in VR. It has features like sculpting, rigging, posing, and painting, and supports various VR headsets and controllers.
  - **Vuforia Engine**: The best AR design software for advanced users. It is a powerful and versatile platform that enables users to create and deploy AR applications for various devices and platforms. It has features like image recognition, object tracking, spatial mapping, and cloud services.
  - **Unity 3D**: The best free software for AR and VR design. It is a popular and widely used game engine that supports both AR and VR development. It has a rich and flexible editor, a large asset store, and a strong community. It supports various AR and VR platforms and devices, such as ARKit, ARCore, Oculus, and SteamVR.
  - **Oculus Medium**: The best 3D design platform for Oculus headsets. It is a VR-based application that lets users sculpt, model, and paint 3D objects in VR. It has features like layers, stamps, and brushes, and supports various Oculus headsets and controllers.
  - **SketchFab**: The best overall for augmented reality. It is an online platform that allows users to manage, share, and view 3D assets and models. It supports various 3D formats and has features like annotations, animations, and VR/AR mode. It also has an API and a marketplace for 3D content.
  - **ARKit**: The best for using geolocation in AR. It is a framework that enables users to create and deploy AR applications for iOS devices. It has features like face tracking, plane detection, image recognition, and geolocation anchors. It also integrates with other frameworks like SceneKit and RealityKit.
  - **Kudan**: The best for markerless AR. It is a platform that enables users to create and deploy AR applications for various devices and platforms. It has features like markerless tracking, 3D mapping, and SLAM (simultaneous localization and mapping). It also supports various AR/VR headsets and glasses.
  - **TeamViewer**: The best for mixed reality. It is a software that enables users to remotely access and control other devices. It also has a feature called TeamViewer Pilot, which allows users to provide or receive real-time visual instructions and guidance using AR. It supports various devices and platforms, such as smartphones, tablets, computers, and smart glasses.
  - **Sigma Software**: The best for AR/VR games and entertainment. It is a software development company that specializes in creating AR/VR applications and solutions. It has experience in developing AR/VR games, simulations, training, and entertainment for various industries and domains. It also offers consulting and support services for AR/VR projects.
