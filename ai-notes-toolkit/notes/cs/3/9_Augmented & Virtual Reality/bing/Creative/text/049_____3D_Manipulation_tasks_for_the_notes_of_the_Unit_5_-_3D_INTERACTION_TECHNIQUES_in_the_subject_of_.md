### 3D Manipulation Tasks

3D manipulation tasks are the tasks of physically handling objects in a 3D environment, such as selecting, positioning, rotating, and scaling them. These tasks are essential for creating and modifying 3D scenes, as well as interacting with 3D applications and virtual environments. Some of the main aspects of 3D manipulation tasks are:

- **Selection**: Selection is the task of acquiring or identifying a particular object or subset of objects from the entire set of objects available. Selection can be done by pointing, clicking, touching, or gesturing at the desired object, or by using menus, voice commands, or other modalities. Selection can also be done by using filters, such as color, shape, or name, to narrow down the set of candidates. Selection can be either discrete, meaning that only one object can be selected at a time, or continuous, meaning that multiple objects can be selected simultaneously or sequentially  .

- **Positioning**: Positioning is the task of changing the 3D position of an object. Positioning can be done by dragging, throwing, snapping, or aligning the object to a desired location, or by using direct or indirect input devices, such as mice, joysticks, trackers, or gloves. Positioning can also be done by using constraints, such as gravity, collision, or attachment, to limit the range of motion of the object. Positioning can be either absolute, meaning that the object is moved to a fixed coordinate system, or relative, meaning that the object is moved with respect to another object or the user's viewpoint  .

- **Rotation**: Rotation is the task of changing the orientation of an object. Rotation can be done by twisting, turning, or rolling the object, or by using direct or indirect input devices, such as mice, joysticks, trackers, or gloves. Rotation can also be done by using constraints, such as axes, planes, or snap angles, to limit the degrees of freedom of the object. Rotation can be either absolute, meaning that the object is rotated to a fixed coordinate system, or relative, meaning that the object is rotated with respect to another object or the user's viewpoint  .

- **Scaling**: Scaling is the task of changing the size of an object. Scaling can be done by stretching, shrinking, or scaling the object uniformly or non-uniformly, or by using direct or indirect input devices, such as mice, joysticks, trackers, or gloves. Scaling can also be done by using constraints, such as aspect ratio, minimum or maximum size, or preservation of volume, to limit the range of scaling of the object. Scaling can be either absolute, meaning that the object is scaled to a fixed coordinate system, or relative, meaning that the object is scaled with respect to another object or the user's viewpoint .
