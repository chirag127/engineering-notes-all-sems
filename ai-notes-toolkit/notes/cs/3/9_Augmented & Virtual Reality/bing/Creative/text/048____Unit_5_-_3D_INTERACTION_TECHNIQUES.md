## Unit 5 - 3D INTERACTION TECHNIQUES

- 3D interaction techniques are methods for manipulating, navigating, and selecting objects in 3D virtual environments.
- 3D interaction techniques can be classified into four categories: direct manipulation, indirect manipulation, gesture-based, and multimodal.
- Direct manipulation techniques allow the user to directly manipulate objects in 3D space using a 3D input device, such as a 3D mouse, a 3D stylus, or a 3D glove. Examples of direct manipulation techniques are ray-casting, virtual hand, and go-go arm.
- Indirect manipulation techniques use a 2D input device, such as a mouse or a keyboard, to control a 3D cursor or a 3D camera in the virtual environment. Examples of indirect manipulation techniques are mouse-based 3D rotation, 3D widgets, and 3D navigation metaphors.
- Gesture-based techniques use hand or body gestures to perform actions in the virtual environment. Examples of gesture-based techniques are pinch-to-zoom, swipe-to-rotate, and air-tap.
- Multimodal techniques use multiple input modalities, such as speech, vision, and haptics, to enhance the 3D interaction. Examples of multimodal techniques are speech commands, gaze tracking, and force feedback.
