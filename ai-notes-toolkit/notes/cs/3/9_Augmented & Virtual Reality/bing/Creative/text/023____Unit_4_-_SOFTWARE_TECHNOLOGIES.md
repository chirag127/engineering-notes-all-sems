## Unit 4 - SOFTWARE TECHNOLOGIES

- This unit covers the basic concepts and principles of software engineering, software development methodologies, software testing techniques, and software quality assurance.
- The objectives of this unit are to:
  - Understand the software development life cycle and its phases.
  - Compare and contrast different software development models, such as waterfall, agile, and spiral.
  - Apply software testing methods, such as unit testing, integration testing, system testing, and acceptance testing.
  - Evaluate software quality attributes, such as reliability, usability, efficiency, maintainability, and portability.
  - Identify software quality standards and metrics, such as ISO 9126, ISO 25010, and CMMI.
- The topics covered in this unit are:
  - Software engineering: definition, scope, goals, and challenges.
  - Software development life cycle: requirements analysis, design, implementation, testing, deployment, and maintenance.
  - Software development models: waterfall, agile, spiral, and others.
  - Software testing: definition, types, levels, techniques, and tools.
  - Software quality: definition, factors, attributes, standards, and metrics.
