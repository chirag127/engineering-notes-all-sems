### VR toolkits

- VR toolkits are software libraries or frameworks that provide various features and functionalities for developing VR applications or enhancing VR experiences.
- VR toolkits can help with tasks such as rendering, input, interaction, audio, physics, UI, locomotion, and more.
- VR toolkits can be platform-specific or platform-agnostic, depending on whether they support only one VR device or multiple VR devices.
- VR toolkits can be integrated with game engines such as Unity or Unreal Engine, or used as standalone tools or plugins.
- Some examples of VR toolkits are:

  - VRTK (VR Toolkit): A free and open-source collection of reusable solutions for common VR problems, such as grabbing, teleporting, UI, and locomotion. It supports multiple VR platforms and devices, and can be used with Unity or Unreal Engine.  
  - VRToolkit: A modular shader created for ReShade to enhance the clarity and sharpness of VR images, while keeping the performance impact minimal. It supports various sharpening modes and other features, such as depth of field, color correction, and anti-aliasing. It can be used with any VR game or application that supports ReShade.  
  - VR Performance Toolkit: A tool for measuring and optimizing the performance of VR applications, using the Oculus SDK and NVAPI. It provides various metrics, such as frame rate, latency, GPU utilization, and power consumption, and allows for adjusting various settings, such as resolution, refresh rate, and supersampling. It can be used with any VR application that runs on Windows and uses the Oculus runtime. 
  - OVR Toolkit: A utility application that allows for viewing the desktop in VR, placing desktop windows around the VR world, and interacting with them using mouse input, virtual keyboard, or voice commands. It supports multiple VR platforms and devices, and can be used with any VR game or application that runs on SteamVR.
