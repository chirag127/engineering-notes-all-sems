### Multimodal System Control Techniques

- Multimodal system control techniques are methods of using multiple input channels (such as speech, gesture, eye gaze, etc.) to control the system functions (such as menu selection, mode switching, etc.) in a 3D user interface (3DUI).
- Researchers have identified several advantages of using multimodal system control techniques (mostly in the domain of 2D GUIs) that can also apply to 3D UIs:
  - Decoupling: Using an input channel that differs from the main input channel used for interaction with the environment can decrease user cognitive load. For example, using speech to select a menu item while using a 3D tracker to manipulate an object can reduce the need to switch between input devices or modes.
  - Error reduction and correction: The use of multiple input channels can be very effective when the input is ambiguous or noisy, especially with recognition-based input like speech or gestures. For example, using speech and gesture together can increase the accuracy and robustness of the system, and also provide a natural way to correct errors by repeating or modifying the input.
  - Expressiveness and efficiency: The use of multiple input channels can allow users to express their intentions more clearly and concisely, and also perform tasks faster and easier. For example, using speech and gesture together can enable users to specify complex commands or queries with fewer steps or words, and also provide feedback and confirmation to the system.
- Some examples of multimodal system control techniques for 3DUIs are:
  - Speech and gesture: This is one of the most common and natural combinations of input channels for 3DUIs, as it mimics the way humans communicate with each other. Speech can be used to convey commands, queries, or labels, while gesture can be used to point, select, or manipulate objects in 3D space. For example, the Naval Research Laboratory's Dragon 3D VR system used a multimodal system to create digital content in a 3D topographical scene, allowing users to create and position objects by speaking while gesturing in 3D space.
  - Speech and eye gaze: This is another natural and intuitive combination of input channels for 3DUIs, as it leverages the human ability to direct attention and focus with eye movements. Speech can be used to convey commands, queries, or labels, while eye gaze can be used to point, select, or manipulate objects in 3D space. For example, the Natural multimodal interaction in immersive flow visualization system used a multimodal system to explore and analyze 3D flow data, allowing users to select and manipulate data points by speaking while looking at them.
  - Gesture and haptic: This is a combination of input channels that can enhance the realism and immersion of 3DUIs, as it provides tactile and force feedback to the user. Gesture can be used to point, select, or manipulate objects in 3D space, while haptic can be used to feel the shape, texture, or resistance of the objects. For example, the MTI special issue on 3D human–computer interaction featured several papers that used gesture and haptic input for 3DUIs, such as a system that used a haptic glove and a 3D tracker to interact with virtual clay, or a system that used a haptic stylus and a 3D tracker to interact with virtual medical images.
