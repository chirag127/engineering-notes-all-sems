## Unit 3 - 3D USER INTERFACE INPUT HARDWARE

- 3D user interface input hardware are devices that allow users to interact with 3D environments or applications by providing input signals such as position, orientation, motion, gesture, voice, etc.
- 3D user interface input hardware can be classified into four categories based on the type of input they provide: trackers, controllers, gloves, and haptic devices.
- Trackers are devices that measure the position and/or orientation of an object or a user in 3D space. Trackers can be based on different technologies such as optical, magnetic, inertial, acoustic, or hybrid. Trackers can be used to track the head, hand, or body of the user, or any other object that the user wants to manipulate in the 3D environment.
- Controllers are devices that provide discrete or continuous input signals such as buttons, joysticks, dials, sliders, etc. Controllers can be used to perform actions such as selection, manipulation, navigation, or command input in the 3D environment. Controllers can be integrated with trackers to provide combined position and orientation input, or they can be standalone devices that provide input signals independent of the user's position and orientation.
- Gloves are devices that measure the position and/or orientation of the user's fingers and hand, and sometimes provide tactile feedback. Gloves can be used to perform natural gestures such as pointing, grabbing, or pinching in the 3D environment, or to control virtual objects or menus. Gloves can also provide haptic feedback such as vibration, force, or temperature to enhance the realism and immersion of the 3D environment.
- Haptic devices are devices that provide force or tactile feedback to the user, simulating the physical properties of the 3D environment or the virtual objects. Haptic devices can be used to enhance the realism and immersion of the 3D environment, or to provide guidance or assistance to the user. Haptic devices can be based on different technologies such as motors, pneumatics, or shape-memory alloys. Haptic devices can be integrated with trackers, controllers, or gloves, or they can be standalone devices that provide feedback independent of the user's input.
