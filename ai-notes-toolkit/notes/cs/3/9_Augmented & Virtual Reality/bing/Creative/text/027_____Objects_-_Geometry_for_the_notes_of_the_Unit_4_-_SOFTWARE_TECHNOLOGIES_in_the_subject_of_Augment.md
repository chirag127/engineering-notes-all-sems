### Objects - Geometry

- In computer graphics, an object is a collection of geometric primitives that define its shape, appearance, and behavior.
- Geometric primitives are the simplest elements that can be used to create more complex shapes, such as points, lines, triangles, polygons, curves, and surfaces.
- Objects can be classified into two types: **meshes** and **parametric** objects.
- A mesh is an object that consists of a set of vertices, edges, and faces that form a polygonal surface. A mesh can be represented by a data structure that stores the coordinates of the vertices, the connectivity of the edges, and the attributes of the faces, such as color, texture, and normal vectors.
- A parametric object is an object that is defined by a set of parameters that control its shape, such as radius, height, width, and angle. A parametric object can be generated by a mathematical function that maps the parameters to a set of points on the object's surface. Examples of parametric objects are spheres, cylinders, cones, tori, and NURBS surfaces.
- Objects can be transformed by applying operations that change their position, orientation, size, or shape, such as translation, rotation, scaling, shearing, and deformation. These operations can be represented by matrices that multiply the coordinates of the vertices of the object.
- Objects can be rendered by projecting their vertices onto a 2D image plane, and filling the pixels that correspond to the faces of the object with colors, textures, and lighting effects. The rendering process can be performed by different algorithms, such as rasterization, ray tracing, or ray casting.
