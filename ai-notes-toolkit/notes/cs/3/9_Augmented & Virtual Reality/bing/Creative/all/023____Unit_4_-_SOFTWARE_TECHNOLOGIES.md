# Unit 4 - SOFTWARE TECHNOLOGIES

- Software technologies are the tools and methods used to create, maintain, and improve software systems.
- Software technologies can be classified into different categories, such as programming languages, software development methodologies, software engineering principles, software testing techniques, software quality assurance, software security, software maintenance, and software evolution.
- Programming languages are the formal languages used to specify the instructions and data for software systems. Programming languages can be divided into low-level and high-level languages, depending on the level of abstraction and closeness to the hardware. Examples of low-level languages are assembly and machine code, while examples of high-level languages are C, Java, Python, and Ruby.
- Software development methodologies are the frameworks and processes used to organize and manage software projects. Software development methodologies can be classified into traditional and agile approaches, depending on the degree of flexibility and adaptability to changing requirements. Examples of traditional methodologies are waterfall, spiral, and V-model, while examples of agile methodologies are Scrum, Kanban, and Extreme Programming (XP).
- Software engineering principles are the guidelines and best practices used to ensure the quality and reliability of software systems. Software engineering principles can be grouped into different aspects, such as software design, software architecture, software reuse, software documentation, software configuration management, and software project management. Examples of software design principles are cohesion, coupling, abstraction, encapsulation, inheritance, and polymorphism. Examples of software architecture principles are modularity, scalability, performance, availability, and security.
- Software testing techniques are the methods used to verify and validate the functionality and quality of software systems. Software testing techniques can be categorized into different types, such as static and dynamic testing, white-box and black-box testing, unit testing, integration testing, system testing, and acceptance testing. Examples of static testing techniques are code reviews, inspections, and walkthroughs. Examples of dynamic testing techniques are test cases, test suites, test data, test drivers, and test stubs.
- Software quality assurance is the process of ensuring that software systems meet the specified requirements and standards. Software quality assurance can be performed at different stages of software development, such as planning, analysis, design, implementation, testing, deployment, and maintenance. Software quality assurance can involve different activities, such as quality planning, quality control, quality audit, quality improvement, and quality measurement. Examples of software quality standards are ISO 9000, ISO 25000, and CMMI.
- Software security is the aspect of software engineering that deals with the protection of software systems from unauthorized access, use, modification, or destruction. Software security can be achieved by applying different techniques, such as encryption, authentication, authorization, access control, firewalls, intrusion detection, and intrusion prevention. Examples of software security threats are viruses, worms, trojans, spyware, malware, denial-of-service attacks, and phishing.
- Software maintenance is the process of modifying and updating software systems after they are deployed. Software maintenance can be performed for different reasons, such as correcting errors, improving performance, adding features, or adapting to changes in the environment. Software maintenance can be classified into different types, such as corrective, adaptive, perfective, and preventive maintenance. Examples of software maintenance tools are debuggers, profilers, code analyzers, and refactoring tools.
- Software evolution is the process of changing and improving software systems over time. Software evolution can be driven by different factors, such as user feedback, market demand, technology innovation, or legal regulations. Software evolution can involve different activities, such as software reengineering, software reverse engineering, software migration, software modernization, and software retirement. Examples of software evolution models are Lehman's laws, staged model, and spiral model.
