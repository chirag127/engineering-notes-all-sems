# Classification of 3D Interaction Techniques

3D interaction techniques are methods that allow users to perform tasks in virtual environments using 3D input devices and feedback. They can be classified according to the type of task they support, such as:

- **Selection and manipulation**: These techniques enable users to select, move, rotate, scale, or deform virtual objects in 3D space. Examples of these techniques are ray-casting, virtual hand, HOMER, Go-Go, and 3D widgets .
- **Navigation**: These techniques enable users to change their viewpoint or position in the virtual environment. Examples of these techniques are flying, walking, steering, teleporting, and world-in-miniature .
- **System control**: These techniques enable users to access menus, dialogs, or commands that control the system or the application. Examples of these techniques are 3D buttons, voice commands, gestures, and gaze-based selection .

3D interaction techniques can also be classified according to other criteria, such as:

- **Input dimensionality**: This refers to the number of degrees of freedom (DOF) of the input device or the technique. For example, a mouse has 2 DOF (x and y), a joystick has 3 DOF (x, y, and rotation), and a 6 DOF tracker has 6 DOF (x, y, z, pitch, yaw, and roll).
- **Mapping**: This refers to the relationship between the input device movement and the resulting action in the virtual environment. For example, a direct mapping means that the input device and the virtual object move in the same way, while an indirect mapping means that there is some transformation or interpretation of the input device movement.
- **Feedback**: This refers to the type and modality of the information that the system provides to the user to indicate the result of the interaction. For example, feedback can be visual, auditory, haptic, or multimodal, and it can be continuous, discrete, or adaptive.
