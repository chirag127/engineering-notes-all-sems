# Real-time computer graphics

- Real-time computer graphics is the sub-field of computer graphics focused on producing and analyzing images in real time .
- Real-time rendering is the process of generating images from 3D data and displaying them on a screen at a high frame rate.
- Real-time rendering is used for interactive applications such as video games, simulations, virtual reality, augmented reality, and mixed reality .
- Real-time rendering requires a trade-off between quality and performance, as the images must be generated within a limited time budget.
- Real-time rendering engines are software systems that handle the various tasks involved in real-time rendering, such as scene management, geometry processing, shading, lighting, texturing, post-processing, and output.
- Real-time rendering engines can be classified into different types based on their architecture, such as forward rendering, deferred rendering, tiled rendering, and ray tracing.
- Real-time rendering engines can also be adapted to support autostereoscopy, which is a technique for creating 3D images without the need for special glasses or headsets.
