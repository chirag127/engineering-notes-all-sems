# Design Guidelines - System Control

System control is the task of issuing commands to the system or changing system parameters, such as switching modes, changing views, or adjusting settings. System control is often integrated with another 3D interaction task, such as navigation, selection, or manipulation. Therefore, system control techniques should be designed to avoid disturbing the flow of action of an interaction task.

Some design guidelines for system control are:

- Use graphical menus for 3D UIs that are easy to access, read, and select from. Graphical menus can be adapted from 2D menus, such as pop-up menus, pie menus, or toolbars, or designed specifically for 3D UIs, such as 1-DOF menus, 3D widgets, or 3D icons.
- Use natural mappings and affordances for system control techniques that are based on physical objects or gestures. For example, using a virtual camera to change the view, or using a hand gesture to switch modes.
- Use multimodal feedback for system control techniques that involve speech, gesture, or haptic input. For example, using speech recognition to confirm commands, using visual cues to indicate gesture recognition, or using haptic feedback to indicate mode changes.
- Use two-handed interaction for system control techniques that require simultaneous or sequential input from both hands. For example, using one hand to select an object and the other hand to manipulate it, or using one hand to hold a tool and the other hand to activate it.
- Use consistent and predictable system control techniques across different tasks and contexts. For example, using the same gesture or command to switch modes, or using the same menu layout or widget style for different parameters.
