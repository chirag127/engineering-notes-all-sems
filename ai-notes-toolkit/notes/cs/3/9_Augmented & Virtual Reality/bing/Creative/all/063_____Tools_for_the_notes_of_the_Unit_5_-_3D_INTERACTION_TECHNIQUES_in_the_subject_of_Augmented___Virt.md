# Tools for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- 3D interaction techniques are methods of interacting with 3D virtual objects and environments in augmented and virtual reality (AR/VR) applications.
- 3D interaction techniques can be classified into four categories: selection, manipulation, navigation, and system control.
- Selection techniques are used to select or point at a 3D object or location in the virtual scene. Examples of selection techniques are ray-casting, cone-casting, image plane, and go-go.
- Manipulation techniques are used to move, rotate, scale, or deform a 3D object in the virtual scene. Examples of manipulation techniques are direct manipulation, virtual hand, HOMER, and 3D widgets.
- Navigation techniques are used to change the viewpoint or position of the user in the virtual scene. Examples of navigation techniques are walking, flying, steering, and teleporting.
- System control techniques are used to access menus, options, or commands in the virtual scene. Examples of system control techniques are voice, gesture, gaze, and physical buttons.
- 3D interaction techniques can be implemented using various input devices and modalities, such as hand tracking, gesture recognition, eye tracking, voice recognition, and haptic feedback .
- 3D interaction techniques can enhance the user experience and performance in AR/VR applications by providing natural, intuitive, and efficient ways of interacting with the virtual scene .
