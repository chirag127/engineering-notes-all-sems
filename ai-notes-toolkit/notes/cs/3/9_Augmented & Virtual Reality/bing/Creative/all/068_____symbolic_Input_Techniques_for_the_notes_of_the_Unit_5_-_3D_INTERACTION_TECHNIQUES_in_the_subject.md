# Symbolic Input Techniques

Symbolic input is the task in which users communicate symbolic information (text, numbers, and other symbols or marks) to the system . Symbolic input is often used for tasks such as entering commands, passwords, names, annotations, or queries in 3D applications. Symbolic input techniques can be classified into four categories based on the input device or modality used  :

- Keyboard-based techniques: These techniques use a physical or virtual keyboard as the input device. The user can type the symbols using the keyboard keys, which can be mapped to different functions or commands in the application. Keyboard-based techniques are familiar, efficient, and accurate, but they require a separate device or a large screen space for the virtual keyboard. They also lack direct manipulation and spatial feedback in 3D environments.
- Pen-based techniques: These techniques use a pen or stylus as the input device. The user can write or draw the symbols using the pen on a surface or in mid-air. Pen-based techniques are natural, expressive, and intuitive, but they require a high recognition accuracy and a suitable writing surface or gesture space. They also suffer from occlusion and fatigue issues in 3D environments.
- Gesture-based techniques: These techniques use hand or body gestures as the input modality. The user can perform predefined or free-form gestures to create or select the symbols in 3D space. Gesture-based techniques are immersive, flexible, and compatible with 3D environments, but they require a reliable gesture recognition system and a clear gesture vocabulary. They also pose challenges for feedback, error correction, and memorization.
- Speech-based techniques: These techniques use voice or speech as the input modality. The user can speak the symbols or commands to the system using a microphone or a headset. Speech-based techniques are convenient, hands-free, and fast, but they require a robust speech recognition system and a suitable acoustic environment. They also raise issues of privacy, social acceptance, and ambiguity.
