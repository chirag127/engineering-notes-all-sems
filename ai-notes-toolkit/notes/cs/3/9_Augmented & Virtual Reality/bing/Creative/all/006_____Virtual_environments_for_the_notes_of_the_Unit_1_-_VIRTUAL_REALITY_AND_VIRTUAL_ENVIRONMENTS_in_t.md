# Virtual environments

- A virtual environment is a **networked application** that allows a user to interact with both the **computing environment** and the **work of other users** .
- Examples of virtual environments are **email, chat, and web-based document sharing applications** .
- A virtual environment can be defined as a **virtual world** or as a **world presented in a particular virtual reality hardware configuration**.
- Virtualization is a technique that creates a **simulated, or virtual, computing environment** as opposed to a physical environment.
- Virtualization can create **computer-generated versions of hardware, operating systems, storage devices, and more**.
- Virtualization can allow organizations to **partition a single physical computer or server into several virtual machines**.
