# Input device characteristics for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

- Input devices are hardware that allow the user to communicate with the system by providing input in 3D space  .
- Input devices can be classified according to the following characteristics :
  - Degrees of freedom (DOFs): the number and type of independent parameters that define the position and orientation of an object in 3D space. For example, a 6-DOF device can report the x, y, z coordinates and the pitch, yaw, roll angles of an object. DOFs can be integral (combined in a single device) or separable (divided among multiple devices).
  - Type of electronics: digital (binary) or analog (continuous) devices that report discrete or continuous values, respectively. For example, a keyboard is a digital device that reports discrete key presses, while a joystick is an analog device that reports continuous values of its axes.
  - Range of reported values: discrete (fixed number of values), continuous (infinite number of values), or hybrid (combination of discrete and continuous values) devices that report different levels of granularity. For example, a mouse is a hybrid device that reports discrete values for its buttons and continuous values for its movement.
  - Sensing technology: active (emit signals) or passive (receive signals) devices that use different methods to track the position and orientation of an object in 3D space. For example, a magnetic tracker is an active device that emits a magnetic field and measures its distortion, while a camera is a passive device that receives light and analyzes the image.
  - Form factor: the shape, size, weight, and ergonomics of a device that affect its usability and comfort. For example, a glove is a form factor that fits the user's hand and allows finger tracking, while a wand is a form factor that resembles a stick and allows pointing and selection.
  - Functionality: the purpose and capabilities of a device that determine its suitability for different tasks and interaction techniques. For example, a stylus is a device that functions as a pen and allows drawing and writing, while a haptic device is a device that functions as a force-feedback device and allows feeling and manipulating virtual objects.
- Input devices can be used for different types of 3D user input or manipulation, such as :
  - Navigation: moving the viewpoint or the virtual environment in 3D space.
  - Selection: choosing an object or a region of interest in 3D space.
  - Manipulation: changing the position, orientation, shape, or properties of an object in 3D space.
  - Symbolic input: entering text, numbers, commands, or gestures in 3D space.
  - System control: accessing menus, options, or modes in 3D space.
- Input devices can be combined or complemented with other input devices or output devices to create more effective and natural 3D user interfaces. For example, a head-mounted display can be used with a hand-held tracker to create an immersive and interactive 3D experience .
- Input devices can be designed or customized for specific purposes or applications, such as gaming, virtual reality, augmented reality, or 3D modeling. For example, a game controller can be designed to provide buttons, triggers, joysticks, or motion sensors for different game genres.
