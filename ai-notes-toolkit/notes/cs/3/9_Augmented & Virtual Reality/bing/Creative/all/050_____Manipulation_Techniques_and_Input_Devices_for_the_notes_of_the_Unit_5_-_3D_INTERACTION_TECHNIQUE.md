# Manipulation Techniques and Input Devices for 3D Interaction

- Manipulation techniques are methods for controlling the position, orientation, size, shape, or appearance of 3D objects in virtual environments.
- Input devices are hardware components that allow users to provide input to the system by making movements or gestures in physical or virtual 3D space.
- Manipulation techniques and input devices are important for 3D interaction because they enable users to perform common tasks such as selection, transformation, navigation, and system control in 3D environments.
- Some of the factors that affect the design and evaluation of manipulation techniques and input devices are:
  - The number and integration of control dimensions: how many degrees of freedom (DOFs) are required to manipulate an object and how they are mapped to the input device or technique.
  - The type of control: whether the input device or technique provides position control (direct manipulation) or rate control (indirect manipulation) of the object.
  - The feedback: how the system provides visual, auditory, haptic, or tactile feedback to the user about the manipulation outcome or state.
  - The tools and widgets: how the system provides additional functionality or assistance to the user through graphical or physical elements such as handles, menus, or buttons.
- Some of the examples of manipulation techniques and input devices are:
  - Mouse-based techniques: using a 2D mouse to manipulate 3D objects through techniques such as virtual trackball, ray-casting, or image plane interaction.
  - 3D input devices: using devices that can sense 3D position and orientation such as trackers, gloves, joysticks, or wands to manipulate 3D objects through techniques such as direct manipulation, virtual hand, or 3D widgets.
  - Multi-touch techniques: using a touch-sensitive surface or device to manipulate 3D objects through techniques such as pinch-to-zoom, rotate, or tilt.
  - Device movement techniques: using the orientation or motion of a mobile device to manipulate 3D objects through techniques such as tilt-to-pan, shake, or swing.
  - Biosignal techniques: using the physiological signals of the user such as brain waves, eye movements, or muscle contractions to manipulate 3D objects through techniques such as brain-computer interface, eye-tracking, or electromyography.
