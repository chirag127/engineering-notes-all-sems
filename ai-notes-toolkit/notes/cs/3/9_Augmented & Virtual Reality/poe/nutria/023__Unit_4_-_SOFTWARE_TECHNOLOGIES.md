
## Unit 4 - SOFTWARE TECHNOLOGIES

1. Software technologies are used to create, maintain, and enhance computer software. This includes programming languages, databases, operating systems, and development tools.

2. Programming languages are sets of instructions that allow developers to write programs that can be understood by computers. Common programming languages include C, C++, Java, and Python.

3. Databases are used to store and retrieve data. Common database technologies include SQL, Oracle, and MongoDB.

4. Operating systems are the software that runs on a computer and provides an environment for applications to run. Common operating systems include Windows, macOS, and Linux.

5. Development tools are used to create and maintain software. These tools include compilers, debuggers, and integrated development environments (IDEs).
