
### 2D Controls for Unit 4 - SOFTWARE TECHNOLOGIES

* 2D controls are user interface elements used in augmented and virtual reality applications. 
* They can be used to control objects in the virtual world, such as moving them around or changing their properties. 
* They can also be used to control the camera, allowing the user to move around the virtual environment. 
* Examples of 2D controls include buttons, sliders, and joysticks. 
* Buttons are used to trigger an action or event, such as opening a door or activating a switch. 
* Sliders are used to adjust the value of a parameter, such as the brightness of a light. 
* Joysticks are used to control the movement of a character or object in the virtual world. 
* 2D controls can be used to create a more immersive experience in augmented and virtual reality applications.
