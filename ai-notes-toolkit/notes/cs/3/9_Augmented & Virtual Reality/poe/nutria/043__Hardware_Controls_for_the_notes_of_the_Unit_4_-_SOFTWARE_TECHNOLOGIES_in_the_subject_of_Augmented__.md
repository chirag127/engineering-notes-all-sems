
### Hardware Controls for Unit 4 - SOFTWARE TECHNOLOGIES

1. Augmented Reality (AR) is a technology that overlays virtual objects onto the real world. It is typically accomplished by using hardware such as cameras, motion sensors, and other tracking devices.

2. Virtual Reality (VR) is a technology that creates a simulated environment in which a user can interact with virtual objects. It is typically accomplished by using hardware such as head-mounted displays, controllers, and other tracking devices.

3. Input devices are used to control the virtual environment. These devices can range from simple buttons and joysticks to more complex motion-sensing devices.

4. Output devices are used to display the virtual environment. These devices can range from simple head-mounted displays to more complex projection systems.

5. Tracking devices are used to track the position and orientation of the user’s head and body. These devices can range from simple inertial sensors to more complex optical tracking systems.

6. Audio devices are used to provide sound for the virtual environment. These devices can range from simple headphones to more complex surround sound systems.
