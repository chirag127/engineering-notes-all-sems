
### Home-Brewed Input Devices for Unit 3 – 3D User Interface Input Hardware

* 3D user interface hardware is a type of input device used to interact with a computer or other digital device.
* 3D user interface hardware can range from simple buttons and joysticks to more complex motion-sensing devices such as accelerometers, gyroscopes, and magnetometers.
* 3D user interface hardware can be used to control applications, games, and other digital experiences.
* Home-brewed input devices are custom-made input devices that are created by individuals or small teams.
* Home-brewed input devices often use simple components such as buttons, joysticks, and accelerometers to create unique and interesting user interfaces.
* Home-brewed input devices can be used to create unique and interactive experiences for augmented and virtual reality applications.
* Home-brewed input devices can also be used to create unique physical interfaces for traditional applications.
