### Engineering for the notes of the Unit 7 - VIRTUAL REALITY APPLICATIONS

1. VR Hardware
- Head-mounted displays (HMDs): Provide immersive experience by blocking out the real world. Includes lenses/displays, tracking sensors, audio.
- Motion Controllers: Allow interaction with the virtual world. Includes motion sensors to track position/orientation.
- Trackers: Provide 6DoF tracking by tracking the position and orientation of the HMD/controllers. Includes external sensors or cameras.

2. VR Software
- Application Software: The actual VR experiences/apps/games. Created using game engines or VR software development kits (SDKs).
- Middleware: Software that provides services to the application software, e.g. input handling, rendering, audio, etc.
- Drivers: Software to interface with the VR hardware.

3. Challenges
- Latency: Delay between user input and system response can cause discomfort/cybersickness. Need high refresh rates and low system latency.
- Limited Resolution: Can cause the "screen-door effect". Need high-resolution displays with high pixel density.
- Form Factor and Weight: HMDs need to be lightweight and comfortable to wear for a long duration.
- Tracking: Need accurate tracking with low latency and without gaps in coverage. Challenging using inside-out tracking.
- Ergonomics: Interactions need to be intuitive and easy to perform. Challenging for locomotion and text entry.
