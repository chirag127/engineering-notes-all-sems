## Unit 5 - 3D INTERACTION TECHNIQUES

1. Direct manipulation
- Selecting and manipulating objects directly using input devices like mouse, touch, etc.
- Example: Rotate, scale, translate objects in 3D space.

2. Widgets
- 2D or 3D graphical user interface elements that provide interaction.
- Example: Buttons, sliders, dials, etc. to control parameters of objects.

3. Navigation
- Allow users to explore 3D space and interact with 3D objects.
- Example: Walkthrough, flythrough, examine from different viewpoints.

4. Spatial input devices
- Dedicated input devices to interact in 3D space.
- Example: Data gloves, motion trackers, 3D mice. Provide intuitive interactions.

5. Constraint-based techniques
- Limiting the degrees of freedom to simplify interactions.
- Example: Specifying geometric constraints to define relationships between objects.
