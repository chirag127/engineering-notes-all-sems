## Unit 4 - SOFTWARE TECHNOLOGIES

1. Introduction
- Software is a set of instructions that tell the computer exactly what to do and how to do it. Software is what brings a computer to life and allows it to perform useful tasks.
- There are two major types of software - system software and application software. System software refers to the operating system and software that supports application software. Application software refers to programs that perform specific user-oriented tasks.

2. System Software
- The operating system is the most important system software that runs on a computer. It manages the hardware resources and provides a platform for other software to run on. Common examples are Windows, Linux, and macOS.
- Other system software includes software that supports the application and the operating system, such as library routines, compilers, loaders, and window systems.

3. Application Software
- Application software includes programs that perform specific tasks for users, such as word processors, spreadsheets, database management systems, web browsers, accounting software, and presentation software.
- Application software can be classified as general purpose, which supports a range of tasks, or tailored to specific verticals like healthcare, education, engineering, etc.
- Application software can be either commercial, open-source, or free to use. The choice of application software depends on factors such as cost, features, availability, and operating system compatibility.
