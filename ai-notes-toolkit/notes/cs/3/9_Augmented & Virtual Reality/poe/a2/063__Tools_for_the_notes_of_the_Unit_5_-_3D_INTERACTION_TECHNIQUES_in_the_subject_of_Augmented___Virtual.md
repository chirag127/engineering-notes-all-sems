### Tools for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. Raycasting: It is a technique to detect intersections between a ray (linear trajectory) and 3D geometry (objects). It is used to select/interact with objects in a 3D virtual environment. The ray is cast from the user's point of view and detects the first object intersected by the ray. That object is typically highlighted or selected.
2. Wand: A wand is a physical input device that the user holds and moves in 3D space to interact with virtual objects. The wand provides 6 degrees-of-freedom input and is typically tracked using sensors to obtain its position and orientation. Wands provide an intuitive way to specify 3D locations, directions and paths.
3. Data gloves: Data gloves are fabric gloves augmented with sensors that measure the bending of the fingers. They are used to capture hand poses and gestures to control 3D applications. For example, the user can make a grasping motion with the hand to grab a virtual object. Data gloves provide an intuitive way to interact but can be cumbersome to wear.
4. Motion trackers: Motion trackers use sensors to capture the 3D position and orientation of physical objects (including body parts) and use the movements as inputs to control applications. They enable virtual interactions through natural body motions. However, they require the user to wear sensors or markers on the body and the tracking can be prone to errors.
