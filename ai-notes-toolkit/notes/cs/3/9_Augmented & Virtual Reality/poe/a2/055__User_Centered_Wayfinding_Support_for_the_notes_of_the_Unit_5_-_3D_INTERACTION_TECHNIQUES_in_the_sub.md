### User Centered Wayfinding Support for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. User Centered Design: The design process should revolve around the user and their needs. The interactions and interfaces should be designed keeping the user in mind. Their capabilities, limitations, preferences, etc. should be considered.
2. Wayfinding: It refers to the process of navigating and finding paths in physical or virtual spaces. In AR/VR applications, wayfinding is important to help the user understand the layout and navigate the virtual environment.
3. Techniques for Wayfinding: Some techniques to support wayfinding in AR/VR are:
- Familiar landmarks: Including familiar landmarks or reference objects helps the user get a sense of orientation.
- Consistent design: Using a consistent design for interactions and interfaces makes it easy to learn and navigate.
- Navigation aids: Providing navigation aids like maps, compass, trails, etc. helps the user determine the path and understand the layout.
- Prompts: Providing prompts or cues to indicate directions or highlight paths assists the user in navigation.
- Similarity to physical world: Designing the virtual environment to have a similarity to the physical world in terms of scale, layout, etc. makes it easier to navigate as the user can draw on their physical world knowledge.
