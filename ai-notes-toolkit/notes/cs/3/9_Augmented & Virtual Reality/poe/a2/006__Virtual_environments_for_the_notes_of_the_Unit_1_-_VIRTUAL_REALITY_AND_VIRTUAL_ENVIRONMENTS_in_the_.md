### Virtual environments

1. Virtual environment is a simulated environment that is created with software and presented to the user in a very immersive manner using head-mounted displays or other display technologies.
2. It is a computer-generated environment which a person can explore and interact with. It may be similar to the real world or it may be fantasy environment.
3. The key aspects of a virtual environment are:
 - Immersion: The feeling of being physically present in the virtual world.
 - Interaction: The ability to interact with the virtual world.
 - Imagery: The virtual world is conveyed through interactive computer graphics.
4. Types of virtual environments:
 - Desktop virtual environments: Accessible through a standard computer and input devices.
 - Immersive virtual environments: Uses head-mounted displays or sensory suits to provide immersion.
 - Semi-immersive environments: Uses large displays and input devices to interact with the environment.
5. Applications of virtual environments:
 - Training and education.
 - Design and prototyping.
 - Entertainment and gaming.
 - Therapy and rehabilitation.
 - Scientific visualisation.
