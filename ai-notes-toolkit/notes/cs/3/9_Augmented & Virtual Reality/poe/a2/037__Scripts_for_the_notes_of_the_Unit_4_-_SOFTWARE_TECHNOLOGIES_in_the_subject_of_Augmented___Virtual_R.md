### Scripts for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Unity: Unity is a cross-platform game engine developed by Unity Technologies. It is primarily used to develop video games and simulations for mobile devices, consoles, PCs, and websites. The engine is capable of building Virtual Reality (VR) and Augmented Reality (AR) experiences.

2. Unreal Engine: Unreal Engine is a game engine developed by Epic Games. It provides a robust set of tools for creating interactive experiences in VR, AR, 3D simulations and more. It is free to use and enables developers to create high-end 2D and 3D games. It supports all major platforms including mobile, console, PC, VR and AR.

3. WebVR: WebVR is an open standard that makes it possible to experience VR in your browser. It provides an API for displaying VR content on any smartphone or headset. You can create VR experiences using languages like HTML, CSS and JavaScript and deploy them on the web. It works on all major browsers and platforms.

4. ARCore and ARKit: ARCore and ARKit are software development kits developed by Google and Apple respectively to enable augmented reality experiences. ARCore is for Android and ARKit is for iOS. They allow developers to use the device motion tracking sensors and cameras to overlay digital content on the real world as seen through the device's camera.

5. OpenGL: OpenGL (Open Graphics Library) is a cross-language, multi-platform application programming interface (API) for rendering 2D and 3D vector graphics. It is primarily used in video games, interactive applications, and mobile applications. The API is maintained by the OpenGL Architecture Review Board. It supports Windows, macOS, Linux, etc.
