### Auditory Displays for the notes of the Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES

1. Auditory displays provide an additional sensory channel to communicate information to the user. They can be used to:
- Provide feedback about the state of the system or the user's actions. For example, a beep to indicate that an action has been registered or a change of tone to indicate a incorrect input.
- Warn the user about important events. For example, an alarm to indicate low battery or a particular error condition.
- Augment the user's perception of the surrounding environment. For example, use of sound to indicate the location of objects outside the user's visual field or changes in the environment.

2. Appropriate use of auditory displays can reduce the need for visual displays and can allow the user to focus visual attention on the task. However, care needs to be taken to ensure that the auditory information does not become distracting or confusing. The auditory channel has limited bandwidth and the user can only listen to a limited number of distinct auditory streams simultaneously.
