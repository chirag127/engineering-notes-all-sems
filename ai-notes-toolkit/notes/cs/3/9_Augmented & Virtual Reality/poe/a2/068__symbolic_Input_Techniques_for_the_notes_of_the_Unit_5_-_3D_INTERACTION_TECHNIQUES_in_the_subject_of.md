### Symbolic Input Techniques

- Data gloves: Data gloves are input devices worn on the hand that detect finger bending and hand positions. They allow the user to input hand gestures and motions to interact with and control objects in a virtual environment.
- Wands: A wand is a hand-held input device that allows the user to point, select and manipulate objects in a virtual environment. The wand tracks its position and orientation which can be mapped to interaction tasks.
- Voice: Voice input allows the user to control and interact with the virtual environment through speech commands and voice patterns. Speech recognition is used to interpret the user's voice and map it to interaction tasks.
- Motion trackers: Motion trackers use sensors to detect the position and orientation of the user's body parts. They allow hands-free interaction where the user can control and manipulate objects through body motions and gestures.

The above points cover the key symbolic input techniques used for 3D interaction in augmented and virtual reality. These techniques allow the user to interact with and control virtual objects and environments through tangible inputs that map to certain interactions. The techniques make the interaction more natural and intuitive compared to other input methods.
