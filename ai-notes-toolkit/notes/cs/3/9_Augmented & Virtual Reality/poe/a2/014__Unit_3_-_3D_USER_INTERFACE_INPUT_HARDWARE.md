## Unit 3 - 3D USER INTERFACE INPUT HARDWARE

1. Trackers
- Position trackers: Track the position and orientation of objects or bodies in 3D space. Examples: Magnetic trackers, Optical trackers, Inertial trackers.
- Gesture trackers: Detect gestures and hand movements. Examples: Data gloves, Motion tracking suits.

2. 3D Input Devices
- 3D mice: Navigates and interacts with 3D environments. Example: SpaceNavigator
- Motion controllers: Detects motion and gestures to interact with virtual environments. Example: Wii remote, Playstation move controller.
- Data gloves: Track finger movements to interact with virtual objects. Example: CyberGlove

3. Stereo Displays
- Provide binocular depth cues to perceive 3D effects.
- Examples: Stereo glasses, Autostereoscopic displays (no glasses required), Holographic displays.
