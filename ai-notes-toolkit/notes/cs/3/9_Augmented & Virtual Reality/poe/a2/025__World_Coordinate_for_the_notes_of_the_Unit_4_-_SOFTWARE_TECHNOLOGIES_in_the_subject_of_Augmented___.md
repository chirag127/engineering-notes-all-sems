### World Coordinate for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. In augmented and virtual reality, a 3D coordinate system is used to represent the virtual world. This system is called the world coordinate system.
2. The world coordinate system is a 3D Cartesian coordinate system having an origin (0, 0, 0) and X, Y and Z axes. The X and Y axes define the horizontal plane and the Z axis defines the vertical axis.
3. Objects in the virtual world are represented by defining their position in the world coordinate system. For example, the position of an object can be defined as (X = 5, Y = 10, Z = 15) which means the object is 5 units along the X axis, 10 units along the Y axis and 15 units along the Z axis from the origin.
4. The world coordinate system is relative to the user's viewpoint. As the user moves or changes their viewpoint, the coordinate system also changes to represent the objects relative to the new viewpoint. This is necessary to provide an immersive experience to the user.
5. The process of determining the coordinates of virtual objects relative to a moving user viewpoint and updating the display accordingly is called coordinate transformation. This is done by spatial tracking systems which track the user's viewpoint and spatial relationships between objects in the real world. The spatial data is then used to perform coordinate transformations and update the display.
