### Desktop input devices for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

1. Mouse: The mouse is a input device which translates the 2D movement by the user on a surface into corresponding movement of the cursor on the display. The mouse consists of a tracking ball underneath which the user places their palm to control the movement of the cursor. The mouse has buttons which enable the user to select, drag and drop objects on the display. The mouse is widely used as an input device for 2D interfaces.

2. Trackball: The trackball is a input device similar to an inverted mouse. It consists of a ball housed in a socket which can be rotated by the user's fingers or palm to control the movement of the cursor. The trackball does not require sweeping movement on a surface like the mouse and is useful in constrained spaces. However, the trackball can suffer from issues of inaccuracy and sluggish response at times.

3. Joystick: The joystick is a input device which translates the physical movement of a lever by the user into corresponding movement in the virtual environment. The joystick enables control of motion and orientation and is useful for navigation and object manipulation in 3D spaces. However, the joystick is limiting in terms of the degrees of freedom it can track and can be cumbersome to use for long durations.

4. Gesture recognition system: Gesture recognition systems enable user input through the tracking of bodily movements and hand gestures. The user can control motion, make selections and manipulate objects through gestures recognized by motion tracking cameras and sensors. Gesture recognition provides an intuitive form of input but can be limited in accuracy and prone to misinterpretations. It requires unencumbered movement space and cannot be used in highly constrained environments.
