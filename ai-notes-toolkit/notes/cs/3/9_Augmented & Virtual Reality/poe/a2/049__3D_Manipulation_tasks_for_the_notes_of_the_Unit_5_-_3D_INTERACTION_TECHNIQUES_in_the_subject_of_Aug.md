### 3D Manipulation tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. Rotation - Rotating an object around a fixed axis or in freeform. This allows user to change the orientation of an object.
2. Translation - Moving an object from one point to another in 3D space. This allows user to change the position of an object.
3. Scaling - Resizing an object uniformly or non-uniformly. This allows user to change the size of an object.
4. Deformation - Bending, twisting or stretching an object. This modifies the shape of an object.
5. Selection - Choosing/picking an object from a set of objects. This is required to perform other manipulation tasks on the chosen object.

The manipulation tasks can be performed using input devices like mouse, tracked wands or hands. The manipulation of virtual objects provides an interface to achieve user goals in an augmented/virtual environment. The ease and effectiveness of performing the manipulation tasks impacts the usability of the 3D application.
