### 3D Manipulation tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

In this unit, we will cover the essential 3D manipulation tasks that are used in the field of augmented and virtual reality. These tasks are crucial in creating immersive and interactive experiences for users. Here are some of the tasks that we will go through:

1. **Translation:** Translation refers to moving an object in a particular direction. In 3D manipulation, this task involves moving an object along the x, y, and z-axes. This task is necessary for creating dynamic and interactive objects that need to be moved around in a virtual or augmented environment. 

2. **Scaling:** Scaling is the process of changing the size of an object. This task is useful for creating objects of different sizes, such as buildings, cars, and furniture. Scaling is also used to make objects appear closer or further away from the user.

3. **Rotation:** Rotation is the process of turning an object around an axis. This task is useful for creating objects that need to be viewed from various angles. In augmented and virtual reality, rotation is essential for creating immersive experiences that allow users to explore objects from different perspectives.

4. **Manipulating Multiple Objects:** Manipulating multiple objects involves performing the above tasks on multiple objects simultaneously. This task is useful for creating complex scenes that involve multiple objects, such as a cityscape or a room with furniture. 

5. **Object Constraints:** Object constraints refer to limiting the movement of an object in a particular direction. This task is useful for creating objects that need to stay within a particular boundary, such as a fence or a building. 

6. **Object Snapping:** Object snapping is the process of aligning an object with another object or a grid. This task is useful for creating precise and accurate objects that need to fit together seamlessly. 

By mastering these 3D manipulation tasks, you will be able to create immersive and interactive experiences for users in augmented and virtual reality. It is essential to understand these tasks thoroughly as they are the building blocks of creating a realistic and engaging environment.
