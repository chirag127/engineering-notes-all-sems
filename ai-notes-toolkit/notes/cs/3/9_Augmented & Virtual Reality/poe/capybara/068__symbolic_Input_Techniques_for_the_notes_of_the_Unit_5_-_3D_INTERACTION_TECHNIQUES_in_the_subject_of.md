### Symbolic Input Techniques for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

In the field of Augmented & Virtual Reality, Symbolic Input Techniques are used to provide users with a way to interact with virtual environments. - Symbolic Input Techniques are used in Augmented & Virtual Reality to provide users with a more natural way to interact with virtual environments.
- These techniques utilize symbols or gestures to input data into the system.
- Symbolic Input Techniques are often used in conjunction with other input devices such as a keyboard or mouse.
- One example of a Symbolic Input Technique is the use of hand gestures to control a virtual object.
- Another example is the use of a stylus to draw or write in a virtual environment.
- Symbolic Input Techniques can be used to provide users with a more intuitive way to interact with virtual environments, reducing the learning curve associated with traditional input devices.
- These techniques can also enhance the overall user experience by providing a more immersive and engaging environment.
- Symbolic Input Techniques require a certain level of training and practice to become proficient in their use.
- They may also require specialized hardware or software to be implemented effectively.
