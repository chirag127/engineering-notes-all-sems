### Computer Graphics for the notes of the Unit 1 - VIRTUAL REALITY AND VIRTUAL ENVIRONMENTS in the subject of Augmented & Virtual Reality

In the field of Augmented and Virtual Reality, computer graphics play a crucial role. Computer graphics help to create realistic and immersive virtual environments that can be used for various purposes such as education, entertainment, training, and more. In this unit, we will learn about the basics of computer graphics and how they are used in the context of virtual reality and virtual environments.

Here are some important points to remember:

- Computer graphics refer to the creation, manipulation, and rendering of images using computers.

- Computer graphics can be divided into two main categories: raster graphics and vector graphics.

- Raster graphics are made up of pixels and are best suited for photographs and other realistic images.

- Vector graphics are made up of lines and curves and are best suited for logos and other simple graphics.

- In the context of virtual reality and virtual environments, 3D computer graphics are used to create realistic and immersive environments.

- 3D computer graphics involve the creation and manipulation of 3D models, which are then rendered into 2D images or animations.

- To create 3D models, various software tools are used such as 3D modeling software, texture mapping software, and animation software.

- In addition to creating 3D models, computer graphics are also used to create various visual effects such as particle effects, lighting effects, and more.

- Computer graphics are also used to create user interfaces and other interactive elements in virtual environments.

- In order to create realistic and immersive virtual environments, computer graphics must be combined with other technologies such as motion tracking, haptic feedback, and more.

- Finally, computer graphics are also used in the context of augmented reality, where virtual objects are overlaid onto the real world.

These are some of the key concepts related to computer graphics in the context of virtual reality and virtual environments. By understanding these concepts, you will be able to create realistic and immersive virtual environments that can be used for various purposes.
