
### Various Learning Techniques for the Notes of the Unit 1 - Neural Networks-I (Introduction & Architecture) in the Subject of Application of Soft Computing

1. **Perceptron:** A perceptron is a single layer neural network which takes in multiple inputs and produces a single output. It is a supervised learning algorithm used for binary classification problems. It works by taking in input signals and weights, and then producing an output based on a linear combination of those inputs and weights.

2. **Backpropagation:** Backpropagation is a supervised learning algorithm used to train neural networks. It works by propagating the errors from the output layer to the input layer and adjusting the weights accordingly. This allows the network to learn from its mistakes and improve its accuracy over time.

3. **Stochastic Gradient Descent:** Stochastic Gradient Descent (SGD) is an optimization algorithm used to minimize the cost function of a neural network. It works by randomly selecting a subset of the training data and then updating the weights according to the gradient of the cost function with respect to the weights.

4. **Convolutional Neural Networks:** Convolutional Neural Networks (CNNs) are a type of neural network used for image recognition and classification. They are composed of a series of layers, each of which performs a convolution operation on the input data. The convolution operation is used to extract features from the input data, which are then used to classify the input image.

5. **Recurrent Neural Networks:** Recurrent Neural Networks (RNNs) are a type of neural network used for sequence prediction. They are composed of a series of layers, each of which takes in a sequence of inputs and produces an output. The output of each layer is fed back into the input of the next layer, allowing the network to learn from the previous inputs and predict the next output.
