
### Activation Functions for Unit 1 - Neural Networks-I (Introduction & Architecture)

1. Activation functions are mathematical equations that determine the output of a neural network.

2. They are used to map the desired output of a neural network given an input or set of inputs.

3. The most common activation functions are the sigmoid, hyperbolic tangent (tanh), and rectified linear unit (ReLU).

4. The sigmoid activation function takes a real-valued number and squashes it into a range between 0 and 1. It is used in the output layer of a neural network to predict the probability of an output being one of two classes.

5. The tanh activation function takes a real-valued number and squashes it into a range between -1 and 1. It is used in the hidden layers of a neural network to introduce non-linearity.

6. The ReLU activation function takes a real-valued number and squashes it into a range between 0 and the maximum value of the input. It is used in the hidden layers of a neural network to introduce non-linearity and speed up training.

7. Other activation functions include the softmax, exponential linear unit (ELU), and leaky ReLU.
