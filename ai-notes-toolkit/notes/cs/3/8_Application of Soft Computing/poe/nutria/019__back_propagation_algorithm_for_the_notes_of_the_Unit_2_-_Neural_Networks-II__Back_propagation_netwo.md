
### Back Propagation Algorithm 

Back propagation is an algorithm used in artificial neural networks to calculate a gradient that is used to update the weights of the network in order to minimize the cost function. It is commonly used in supervised learning, where the cost function is the error between the predicted output and the actual output. 

In the context of neural networks, back propagation is a way of training the network by propagating the error backward through the network. The weights of the network are adjusted in order to reduce the error. This is done by calculating the gradient of the cost function with respect to the weights of the network. 

Back propagation is an iterative process. The algorithm starts with an initial set of weights and then calculates the gradient of the cost function with respect to the weights. The weights are then adjusted according to the gradient and the process is repeated until the cost function is minimized. 

The back propagation algorithm is used in the training of deep neural networks. It is used to optimize the weights of the network in order to minimize the cost function. It is a powerful algorithm that can be used to train complex models and has been used in many applications such as computer vision, natural language processing, and robotics.
