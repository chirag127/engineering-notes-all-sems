### Object Representation

Object representation is a key concept in Unit 3 - Object Oriented Analysis of the subject Object Oriented System Design. It refers to the way objects are represented in a program or system. Here are some key points to remember:

1. Objects are instances of classes, which define the attributes and behaviors of the objects.
2. Objects can be represented using various data structures, such as arrays, linked lists, trees, and graphs.
3. The choice of data structure for object representation depends on the requirements of the system and the operations that need to be performed on the objects.
4. Object representation can also be influenced by factors such as memory usage, performance, and ease of implementation.
5. Object-oriented programming languages provide built-in support for object representation, making it easier for developers to create and manipulate objects in their programs.

These are some of the key points to remember when studying object representation in the context of object-oriented analysis and design. It is important to understand these concepts in order to effectively design and implement object-oriented systems.
