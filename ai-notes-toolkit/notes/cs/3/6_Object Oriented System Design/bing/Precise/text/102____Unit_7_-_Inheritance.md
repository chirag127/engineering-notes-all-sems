## Unit 7 - Inheritance

Inheritance is a fundamental concept in object-oriented programming (OOP) that allows the creation of hierarchical classifications. It enables the creation of new classes that reuse, extend, and modify the behavior defined in other classes.

1. **Inheritance** allows a new class to be based on an existing class, inheriting its attributes and methods.
2. The class that is being inherited from is called the **base class** or **superclass**, while the class that is inheriting is called the **derived class** or **subclass**.
3. Inheritance allows for **code reuse**, as common behavior can be defined in the base class and then inherited by the derived classes.
4. Inheritance also allows for **polymorphism**, as objects of the derived class can be treated as objects of the base class.
5. Inheritance is typically implemented using the **extends** keyword in languages such as Java and C++, or the **class** keyword in Python.
6. Inheritance can be **single** or **multiple**, depending on whether a class can inherit from more than one base class.
7. Inheritance should be used judiciously, as it can lead to complex class hierarchies and make code difficult to understand and maintain.
