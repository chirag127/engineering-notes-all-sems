### Common Mechanisms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. **Abstraction**: Abstraction is the process of identifying the essential features of an object while ignoring its inessential details. It helps to manage complexity by reducing the amount of information that needs to be considered.

2. **Encapsulation**: Encapsulation is the process of hiding the internal details of an object and providing a public interface for interacting with the object. It helps to maintain the integrity of the object by preventing external interference.

3. **Inheritance**: Inheritance is the mechanism by which a new class can be derived from an existing class, inheriting its attributes and behaviors. It helps to promote code reuse and reduce redundancy.

4. **Polymorphism**: Polymorphism is the ability of an object to take on many forms. It allows objects of different classes to be treated as objects of a common superclass, enabling the creation of more flexible and reusable code.

5. **Association**: Association is a relationship between two or more objects, where one object is connected to another object. It helps to model complex systems by representing the relationships between objects.

6. **Aggregation**: Aggregation is a special type of association where an object is composed of other objects. It helps to model complex systems by representing the part-whole relationships between objects.

7. **Composition**: Composition is a stronger form of aggregation where the lifetime of the composed objects is dependent on the lifetime of the composing object. It helps to model complex systems by representing the strong part-whole relationships between objects.

8. **Dependency**: Dependency is a relationship between two or more objects, where one object depends on another object. It helps to model complex systems by representing the dependencies between objects.
