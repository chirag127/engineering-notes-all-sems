### Object Oriented Modelling - Unit 1: Introduction: The meaning of Object Orientation

Object-oriented modeling is a method of designing and representing a system using objects, their properties, and their relationships. It is a part of the object-oriented approach to system design, which focuses on modeling real-world objects and their interactions.

Here are some key points to understand about object-oriented modeling:

1. **Objects**: Objects are the basic building blocks of an object-oriented system. They represent real-world entities or concepts, and have properties and behaviors associated with them.

2. **Classes**: A class is a blueprint for creating objects. It defines the properties and behaviors that all objects of that class will have.

3. **Inheritance**: Inheritance is a mechanism that allows a new class to be created based on an existing class. The new class inherits the properties and behaviors of the existing class, and can add or override them as needed.

4. **Encapsulation**: Encapsulation is the practice of hiding the internal details of an object and providing a public interface for interacting with the object. This helps to maintain the integrity of the object and makes it easier to use.

5. **Polymorphism**: Polymorphism is the ability of an object to take on many forms. In object-oriented modeling, this means that objects of different classes can be treated as objects of a common superclass.

Object-oriented modeling is a powerful tool for designing complex systems, as it allows for the creation of modular, reusable, and extensible designs. It is widely used in software development, but can also be applied to other fields such as business process modeling and data modeling.
