### Unit 2 - Basic Structural Modeling - Object Oriented System Design

- Basic Structural Modeling is a fundamental concept in Object Oriented System Design.
- It involves the use of classes, objects, and their relationships to represent the structure of a system.
- Classes are used to define the common properties and behaviors of a group of objects.
- Objects are instances of classes and represent the individual entities in the system.
- Relationships between classes and objects can be represented using associations, aggregations, and compositions.
- Basic Structural Modeling is an important tool for designing and understanding complex systems. It allows for the clear representation of the system's structure and the relationships between its components.
- Understanding Basic Structural Modeling is essential for anyone studying Object Oriented System Design. It provides a foundation for more advanced concepts and techniques in the field.
