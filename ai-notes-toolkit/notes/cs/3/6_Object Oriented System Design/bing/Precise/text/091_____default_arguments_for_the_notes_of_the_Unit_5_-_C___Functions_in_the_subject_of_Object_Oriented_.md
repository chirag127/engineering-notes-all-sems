### Default Arguments

- Default arguments are values that are automatically assigned to a function's parameters if no explicit values are provided when the function is called.
- Default arguments are specified in the function declaration, after the parameter's type, using the assignment operator (=).
- Default arguments can be used to make a function more flexible by allowing it to be called with fewer arguments.
- When calling a function with default arguments, the arguments must be provided in order, starting from the left. If an argument is not provided, all subsequent arguments must also be omitted.
- Default arguments can be any valid C++ expression, including function calls and calculations.
- Default arguments are evaluated at the point of the function call, not at the point of the function declaration.
- Default arguments can be used to provide backward compatibility for existing code when adding new parameters to a function.
- Default arguments can make code more readable by reducing the number of arguments that need to be explicitly specified when calling a function.
