### Pointers and Objects for the notes of the Unit 8 - Polymorphism in the subject of Object Oriented System Design

1. Pointers are variables that store the memory addresses of other variables.
2. Pointers can be used to access and manipulate the value stored at the memory address they point to.
3. In Object Oriented Programming, pointers can be used to point to objects.
4. When a pointer points to an object, it can be used to access the object's data members and member functions.
5. Polymorphism is the ability of an object to take on many forms.
6. Polymorphism can be achieved through the use of pointers and virtual functions.
7. A virtual function is a member function that is declared within a base class and redefined by a derived class.
8. When a base class pointer points to a derived class object, the virtual function call is resolved at runtime, allowing for polymorphic behavior.
9. Polymorphism allows for flexibility and code reusability in Object Oriented System Design.
