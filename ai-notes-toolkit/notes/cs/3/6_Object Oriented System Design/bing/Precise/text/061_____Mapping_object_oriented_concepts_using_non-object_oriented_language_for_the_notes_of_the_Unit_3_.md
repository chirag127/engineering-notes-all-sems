### Mapping object oriented concepts using non-object oriented language for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

1. Object-oriented concepts can be implemented in non-object-oriented languages using various techniques.
2. One technique is to use data structures to represent objects and their attributes, and to use functions to represent methods.
3. Another technique is to use modules or namespaces to group related functions and data together, simulating the behavior of classes.
4. Inheritance can be simulated by using delegation, where an object delegates some of its behavior to another object.
5. Polymorphism can be achieved by using function pointers or by passing functions as arguments to other functions.
6. Encapsulation can be achieved by using conventions for naming variables and functions, and by using access control mechanisms provided by the language.
7. These techniques allow developers to write code that is more modular, reusable, and easier to understand, even in languages that do not directly support object-oriented programming.
