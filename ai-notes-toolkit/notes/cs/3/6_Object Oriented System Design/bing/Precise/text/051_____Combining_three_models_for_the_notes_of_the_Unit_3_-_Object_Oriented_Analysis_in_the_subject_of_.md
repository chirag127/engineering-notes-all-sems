### Combining Three Models for the Notes of Unit 3 - Object Oriented Analysis in the Subject of Object Oriented System Design

1. Object-oriented analysis (OOA) is the process of analyzing a task, also known as a problem domain, to develop a conceptual model that can then be used to complete the task.
2. A typical OOA model would describe computer software that could be used to satisfy a set of customer-defined requirements.
3. During the analysis phase of problem-solving, a programmer might consider a written requirements statement, a formal vision document, or interviews with stakeholders or other interested parties.
4. The task is then analyzed to identify the constituent parts and their relationships.
5. Three common models used in OOA are use case diagrams, class diagrams, and sequence diagrams.
6. A use case diagram is a graphical representation of the interactions between the elements of a system.
7. A class diagram is a static structure diagram that describes the structure of a system by showing the system's classes, their attributes, operations (or methods), and the relationships among objects.
8. A sequence diagram is an interaction diagram that shows how objects operate with one another and in what order.
9. These three models can be combined to provide a comprehensive view of the system being analyzed.
10. The use case diagram provides an overview of the system's functionality, the class diagram provides a detailed view of the system's structure, and the sequence diagram provides a view of the system's behavior over time.
11. By combining these three models, a complete and thorough analysis of the system can be achieved, providing a solid foundation for the design and implementation of the system.
