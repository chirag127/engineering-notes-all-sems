### Unit 7 - Inheritance in Object Oriented System Design: Types of Inheritance

Inheritance is a mechanism in object-oriented programming that allows a new class to be created based on an existing class. The new class inherits the properties and methods of the existing class, and can also add new properties and methods. There are several types of inheritance, including:

1. **Single inheritance**: A class inherits from a single base class.
2. **Multiple inheritance**: A class inherits from multiple base classes.
3. **Multilevel inheritance**: A class inherits from a base class, which in turn inherits from another base class.
4. **Hierarchical inheritance**: Multiple classes inherit from a single base class.
5. **Hybrid inheritance**: A combination of two or more types of inheritance.

Each type of inheritance has its own advantages and disadvantages, and the choice of which type to use depends on the specific requirements of the system being designed. It is important to carefully consider the relationships between classes when designing an inheritance hierarchy, to ensure that the system is easy to understand, maintain, and extend.
