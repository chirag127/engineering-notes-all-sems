
### Virtual Base Class 

* A virtual base class is a class that is inherited by multiple derived classes. 
* Virtual base classes allow for the creation of a common base class that is shared by multiple derived classes. 
* This can be used to reduce code duplication and simplify the design of an object oriented system.
* Virtual base classes can be used to provide a common interface to multiple derived classes, allowing for code reuse and more efficient design.
* Virtual base classes can also be used to provide a common set of methods and properties that can be used by all derived classes.
* Inheritance is the process of creating a new class from an existing class. 
* When a class inherits from a virtual base class, it inherits all the methods and properties of the virtual base class. 
* This allows for the creation of a common interface for all derived classes. 
* Virtual base classes can also be used to provide a common set of rules and guidelines that all derived classes must follow.
