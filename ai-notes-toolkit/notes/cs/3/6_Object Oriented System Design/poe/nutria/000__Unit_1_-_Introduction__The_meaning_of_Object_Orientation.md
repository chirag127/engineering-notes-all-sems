
## Unit 1 - Introduction: The Meaning of Object Orientation

* Object Orientation is a programming paradigm that focuses on the use of objects to represent data and code.
* Objects are composed of data and code that act on the data.
* Object Orientation is a way of thinking about programming that puts the focus on objects and their relationships rather than on the instructions that make up a program.
* Object Orientation allows for the easy reuse of code, as objects can be reused in different programs.
* Object Orientation also allows for greater flexibility, as objects can be easily modified to fit different needs.
* Object Orientation also encourages code maintainability, as objects can be easily modified to fix bugs or add features.
