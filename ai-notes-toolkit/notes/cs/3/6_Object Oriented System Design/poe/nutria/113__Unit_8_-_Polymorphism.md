
## Unit 8 - Polymorphism

* Polymorphism is the process of writing code that can be used in multiple contexts. 
* In object-oriented programming, polymorphism is achieved through the use of interfaces and abstract classes. 
* An interface is a set of methods that must be implemented by a class in order to be considered an instance of that interface. 
* An abstract class is a class that cannot be instantiated, but can contain concrete methods and properties. 
* Polymorphism allows a programmer to write code that is flexible and can be used in different contexts. 
* For example, a programmer can write a single method that can be used to process different types of data, such as integers, strings, and objects. 
* Polymorphism can also be used to create more efficient code by allowing a programmer to reuse code in different contexts. 
* Polymorphism also allows for code to be more extensible, as it can be used to create new classes and objects with similar behavior.
