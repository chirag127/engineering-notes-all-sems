
## Unit 7 - Inheritance

Inheritance is a fundamental concept in object-oriented programming (OOP). It is a process by which an object acquires the properties of another object. It allows classes to be organized in a hierarchical structure, allowing for code reuse and better organization.

Inheritance is a powerful tool for designing software, but it should be used with caution. It can lead to code that is difficult to maintain and debug.

1. What is Inheritance?
Inheritance is a mechanism by which one object acquires the properties and behavior of another object. It allows for code reuse and better organization of classes.

2. How Does Inheritance Work?
Inheritance involves two classes: a parent class and a child class. The child class inherits the properties and methods of the parent class. The parent class is called the superclass, and the child class is called the subclass.

3. What are the Benefits of Inheritance?
Inheritance allows for code reuse and better organization of classes. It also allows developers to easily extend existing classes to add new functionality.

4. What are the Disadvantages of Inheritance?
Inheritance can lead to code that is difficult to maintain and debug. It can also lead to tight coupling between classes, which can make the code difficult to refactor.
