
## Unit 6 - Objects and Classes

* Objects are the fundamental building blocks of object-oriented programming. They are used to represent real-world entities such as people, places, and things.
* Classes are templates or blueprints used to create objects. They define the properties and behaviors of objects.
* An object is an instance of a class. It is created from a class and contains its properties and behaviors.
* Classes can contain data fields, methods, and constructors. Data fields are used to store data about an object. Methods are functions that define the behavior of an object. Constructors are special methods used to create an object.
* Classes can be organized into hierarchies. A class can inherit from another class, allowing it to inherit its properties and behaviors.
* Object-oriented programming is used to create software applications. It is a powerful tool that allows developers to create robust, efficient, and maintainable code.
