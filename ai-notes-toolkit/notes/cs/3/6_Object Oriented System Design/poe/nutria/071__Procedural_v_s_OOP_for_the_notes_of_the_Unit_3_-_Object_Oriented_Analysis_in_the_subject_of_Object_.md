
### Procedural v/s OOP

Object-oriented programming (OOP) is a programming language model that revolves around objects, rather than functions and logic. OOP is based on the concept of objects, which are data structures that contain data, in the form of fields, and code, in the form of procedures.

Procedural programming is a programming language model that is based on a sequence of commands, or procedures, that are executed in order. It is a top-down approach that focuses on procedure, or functions, that act on data.

The main difference between OOP and procedural programming is the way in which data is handled. In OOP, data is organized into objects, which contain both data and code. In procedural programming, data is organized into functions, which contain only code.

In OOP, objects can interact with one another through methods, which are functions that are associated with a particular object. This allows objects to communicate with each other and share data. In procedural programming, functions are not associated with any particular object, and data is passed between functions.

OOP also allows for code to be reused, by creating objects that can be used in multiple places. This means that code does not need to be written multiple times for each task. Procedural programming does not allow for code to be reused, as each task requires its own set of functions.

In conclusion, OOP is a programming language model that is based on objects and methods, while procedural programming is a language model that is based on functions and data. OOP allows for code to be reused, while procedural programming does not. OOP also allows for objects to interact with each other, while procedural programming does not.
