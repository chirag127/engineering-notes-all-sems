
### Implementation of Control for the Notes of the Unit 3 - Object Oriented Analysis in the Subject of Object Oriented System Design

- Control is a process of monitoring and regulating the activities of a system to ensure that the desired objectives are achieved. In the context of object-oriented system design, control is used to ensure that the system is designed and implemented in line with the requirements and specifications set out by the stakeholders.

- The main objective of control is to ensure that the system is performing as expected and that any changes to the system are made in accordance with the requirements and specifications. In order to achieve this, the following steps should be taken:

1. Establish a set of rules and regulations for the system.
2. Define the objectives of the system.
3. Identify the stakeholders and their roles and responsibilities.
4. Develop a system architecture that meets the requirements and specifications.
5. Design and implement the system.
6. Monitor and evaluate the system performance.
7. Make necessary changes to the system based on the evaluation.
