
### Concept of Inheritance

- Inheritance is a mechanism in object-oriented programming that allows one class to re-use the properties and methods of another class.
- It allows a class to extend the functionality of another class without having to rewrite the code.
- It is a way of creating a hierarchical relationship between classes, where one class is the parent class and the other class is the child class.
- The child class inherits all the properties and methods of the parent class, and can also add its own properties and methods.
- This allows for code reuse and reduces the amount of code that needs to be written.
- Inheritance also allows for polymorphism, which is the ability of a child class to override the methods of the parent class.
