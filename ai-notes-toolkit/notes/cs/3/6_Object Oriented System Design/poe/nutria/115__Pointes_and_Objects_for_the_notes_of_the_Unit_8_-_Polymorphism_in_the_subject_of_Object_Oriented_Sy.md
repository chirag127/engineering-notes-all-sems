
### Points and Objects for the Notes of the Unit 8 - Polymorphism in the Subject of Object Oriented System Design

1. Polymorphism is a concept in object-oriented programming that refers to the ability of an object to take on multiple forms. 
2. It allows for code to be written that is flexible and extensible and allows for the same code to be used in different situations. 
3. Polymorphism is achieved by using inheritance, interfaces, and virtual functions. 
4. Inheritance allows a class to inherit properties and methods from a parent class, while interfaces allow for objects to implement a set of methods without needing to inherit from a parent class. 
5. Virtual functions are functions that can be overridden by derived classes to provide a different implementation of the same function. 
6. Polymorphism allows for code to be written in a more efficient and maintainable way, as it reduces the need for duplicate code and allows for code to be reused in different situations.
