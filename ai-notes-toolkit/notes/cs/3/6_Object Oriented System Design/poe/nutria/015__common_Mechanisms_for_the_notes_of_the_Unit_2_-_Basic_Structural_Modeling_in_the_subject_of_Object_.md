
### Common Mechanisms for Unit 2 - Basic Structural Modeling in Object Oriented System Design

1. Abstraction: Abstraction is the process of hiding the details of an object and only displaying the essential characteristics of the object. This allows for easier understanding of the object by hiding irrelevant details.

2. Encapsulation: Encapsulation is the process of combining data and functions that manipulate the data into one unit. This allows for easier access and manipulation of data, as well as increased security and protection of the data.

3. Inheritance: Inheritance is the process of creating a new class from an existing class. This allows for the new class to have the same properties and methods of the existing class, while also allowing for additional properties and methods to be added.

4. Polymorphism: Polymorphism is the process of allowing different objects to respond differently to the same message. This allows for objects to be treated differently based on their specific needs.
