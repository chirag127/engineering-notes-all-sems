
### Overview for the notes of the Unit 4 - C++ Basics in the subject of Object Oriented System Design

1. C++ is an object-oriented, general-purpose programming language that was developed by Bjarne Stroustrup in 1985. 
2. C++ is a powerful language that allows developers to write code that is efficient, fast, and reliable. 
3. C++ enables developers to create programs that can be used on multiple platforms, such as Windows, Mac OS, and Linux. 
4. C++ supports object-oriented programming principles such as encapsulation, inheritance, and polymorphism. 
5. C++ uses a combination of procedural and object-oriented programming paradigms. 
6. C++ is a compiled language, which means that it needs to be compiled before it can be run on a computer. 
7. C++ includes a standard library, which provides a set of functions for manipulating data, such as string manipulation, file I/O, and math functions. 
8. C++ provides support for a variety of data types, including primitive types such as int, float, and char; user-defined types such as classes and structs; and pointers. 
9. C++ supports exception handling, which allows developers to handle errors in a structured manner. 
10. C++ provides support for the Standard Template Library (STL), which is a collection of classes and functions for manipulating data structures such as vectors, lists, and maps.
