
### Type Conversion for the Notes of the Unit 6 - Objects and Classes in the Object Oriented System Design

1. Type conversion is the process of converting one data type into another. 
2. In object-oriented programming, type conversion is used to convert an object of one class into another class. 
3. Type conversion can be done either implicitly or explicitly. 
4. Implicit type conversion is when the compiler automatically converts the value of one data type into another data type. 
5. Explicit type conversion is when the programmer explicitly instructs the compiler to convert the value of one data type into another data type. 
6. In object-oriented programming, type conversion can be used to convert an object of one class into another class. 
7. This type of conversion is called upcasting or downcasting. 
8. Upcasting is when an object of a subclass is converted into an object of its superclass. 
9. Downcasting is when an object of a superclass is converted into an object of its subclass. 
10. Type conversion is an important concept in object-oriented programming and it is used to ensure that objects of different classes can interact with each other.
