
### Overriding for the Notes of the Unit 7 - Inheritance in the Subject of Object Oriented System Design

1. Overriding is the process of redefining the implementation of a method in a subclass of the class that originally defined it. 
2. Overriding allows a subclass to provide its own implementation of a method, while still inheriting the behavior of the superclass. 
3. Overriding is a form of polymorphism, which allows objects of different types to respond to the same message in different ways. 
4. Overriding is a powerful tool for object-oriented programming, and allows for greater flexibility and extensibility of code. 
5. In Java, overriding is enabled by the use of the @Override annotation. This annotation ensures that the method being overridden is defined in the superclass. 
6. When overriding a method, the subclass must use the same method name, parameter types, and return type as the superclass. 
7. Overriding a method can also change the visibility of the method, allowing the subclass to make the method more or less accessible than the superclass. 
8. When overriding a method, the subclass must use the same access modifiers as the superclass, unless the subclass is making the method more accessible. 
9. It is important to remember that when overriding a method, the subclass must provide the same behavior as the superclass. 
10. If a subclass fails to provide the same behavior as the superclass, the subclass will not be able to use the overridden method.
