
### Passing arguments to methods

* When passing arguments to a method, the number and type of arguments must match the method's signature. 
* Arguments can be passed to a method in three ways: by value, by reference, and by pointer. 
* When passing arguments by value, the value of the argument is copied into the method. This means that any changes made to the argument within the method will not be reflected outside of the method. 
* When passing arguments by reference or by pointer, the method will receive a reference or pointer to the argument, rather than a copy of the argument. This means that any changes made to the argument within the method will be reflected outside of the method. 
* When passing arguments by reference or by pointer, the method must be declared with the appropriate reference or pointer type. 
* It is important to understand the differences between passing arguments by value, by reference, and by pointer in order to correctly design and implement methods.
