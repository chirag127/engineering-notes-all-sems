
### Unit 7 - Inheritance in Object Oriented System Design

1. Inheritance is a concept in object-oriented programming that allows objects to inherit properties and behavior from other objects.

2. Inheritance allows for code reuse, as objects can inherit from base classes and extend their functionality.

3. Inheritance is a powerful tool for creating complex software systems, as it allows for the creation of an inheritance hierarchy with objects inheriting from one another.

4. Inheritance also allows for polymorphism, as objects can take on different forms depending on their inheritance hierarchy.

5. Inheritance can also help to reduce code duplication, as objects can inherit methods and properties from base classes.

6. Inheritance can also help to improve code readability, as objects can be easily identified by their inheritance hierarchy.
