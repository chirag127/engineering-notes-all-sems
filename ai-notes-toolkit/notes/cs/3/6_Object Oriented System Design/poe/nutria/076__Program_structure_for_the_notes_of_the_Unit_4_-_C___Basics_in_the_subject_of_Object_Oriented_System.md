
### Program Structure for Unit 4 - C++ Basics in Object Oriented System Design

- C++ is an object-oriented programming language, which means that it is designed to allow developers to create objects that represent real-world entities.
- The basic structure of a C++ program consists of a main function, which is the starting point of the program, and other functions and classes, which are used to accomplish the tasks of the program.
- Variables are used to store data in a program and can be declared in a variety of ways.
- Operators are used to perform operations on variables and can be used to create expressions.
- Control flow statements are used to control the flow of execution in a program. These include if, switch, for, while, and do-while statements.
- Functions are used to encapsulate code and can be used to create reusable code blocks.
- Classes are used to create objects and can be used to define the properties and behaviors of an object.
- Pointers are used to store the address of a variable and can be used to access the data stored in a variable.
- Arrays are used to store multiple values in a single variable and can be used to store related data.
- Exceptions are used to handle errors in a program and can be used to ensure that the program does not crash when an error occurs.
