
### Designing algorithms for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

1. Algorithms are a set of instructions that are used to solve a problem.
2. Object-oriented analysis is a software engineering process that involves breaking down a problem into objects, which are then analyzed and designed.
3. Object-oriented system design is the process of designing a system that uses objects to represent data and operations.
4. The key elements of object-oriented analysis and design are abstraction, encapsulation, inheritance, and polymorphism.
5. Abstraction is the process of identifying the essential characteristics of an object and ignoring the details.
6. Encapsulation is the process of wrapping data and operations together in an object.
7. Inheritance is the process of creating new classes from existing classes.
8. Polymorphism is the process of allowing objects to take on different forms depending on the context.
9. Algorithms can be designed to take advantage of object-oriented principles, such as abstraction, encapsulation, inheritance, and polymorphism.
