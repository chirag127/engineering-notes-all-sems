
### Constructors and their Types

Constructors are special methods of a class which are used to initialize the objects of that class. A constructor is called when an object of a class is created. It is usually used to assign initial values to the instance variables of an object. 

There are three types of constructors:

1. Default Constructor: A constructor which does not take any parameters is known as a default constructor. It is used to provide the default values to the objects. If no constructor is defined in a class then the compiler provides a default constructor to the class.

2. Parameterized Constructor: A constructor which takes parameters is known as a parameterized constructor. It is used to provide different values to the different objects.

3. Copy Constructor: A constructor which takes an object of the same class as a parameter is known as a copy constructor. It is used to initialize the new object with the values of an existing object.
