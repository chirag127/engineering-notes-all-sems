
### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Object-oriented programming (OOP): A programming paradigm that uses objects and classes to represent data and operations.
2. Classes: A blueprint for creating objects, which contain data and methods.
3. Objects: Instances of a class, which contain data and methods.
4. Encapsulation: The process of hiding implementation details of an object.
5. Abstraction: The process of hiding the details of an object and exposing only the relevant information.
6. Inheritance: The process of creating a new class from an existing class, which inherits the properties of the parent class.
7. Polymorphism: The ability of an object to take on multiple forms.
8. Message passing: The process of sending messages between objects to invoke methods.
9. Modules: A collection of related classes and objects.
10. Structural Modeling: The process of designing the structure of an object-oriented system.
