
### Protected Members in Object Oriented System Design

* Protected members are class members that are accessible only by the class itself, its subclasses, and any class in the same package. 
* Protected members are declared using the `protected` keyword. 
* Protected members are useful when you want to share data or methods between classes in a package, while still keeping them private from the outside world. 
* Inheritance is a powerful tool for creating a hierarchy of classes. It allows a subclass to inherit methods and data from its parent class, while also adding its own unique functionality. 
* Protected members can be used to give the subclass access to data or methods that it would not normally have access to. 
* This can be useful for implementing complex behavior without having to duplicate code. 
* It is important to remember that protected members should only be used when necessary, as they can lead to tight coupling between classes.
