

## Unit 3 - Object Oriented Analysis

* Object-oriented analysis (OOA) is a process of analyzing a problem domain to identify the objects that the problem comprises and the relationships between them.
* OOA is the first step in the software development process and is often referred to as the "requirements phase".
* The goal of OOA is to develop a model of the problem domain, which can then be used to design a solution.
* OOA involves the identification of objects, their attributes, and the relationships between them.
* OOA also involves the identification of the behavior of objects, which is often referred to as the "operations" of the object.
* OOA is a top-down approach to software development, which allows developers to focus on the problem domain rather than the details of the implementation.
* OOA can be used to identify potential problems in the problem domain, which can then be addressed during the design phase.
* OOA is often used in conjunction with object-oriented design (OOD) to create a complete software solution.
