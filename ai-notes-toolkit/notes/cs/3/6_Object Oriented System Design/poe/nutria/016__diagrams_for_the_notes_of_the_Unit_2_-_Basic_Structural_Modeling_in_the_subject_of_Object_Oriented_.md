
### Diagrams for the Notes of the Unit 2 - Basic Structural Modeling in the Subject of Object Oriented System Design

1. Structural modeling is the process of creating a model of a system's structure. This includes the components of the system, the relationships between them, and the behavior of the system.

2. UML (Unified Modeling Language) is a graphical language used to create structural models. It consists of a set of symbols, or diagrams, that represent the components and relationships of a system.

3. The most commonly used UML diagrams are class diagrams, object diagrams, sequence diagrams, and state diagrams. Class diagrams are used to represent the structure of a system, object diagrams are used to represent the objects in a system, sequence diagrams are used to represent the order of events in a system, and state diagrams are used to represent the states of a system.

4. Structural modeling is important because it helps to identify and document the components of a system and their relationships. This makes it easier to understand how the system works and to make changes if necessary.
