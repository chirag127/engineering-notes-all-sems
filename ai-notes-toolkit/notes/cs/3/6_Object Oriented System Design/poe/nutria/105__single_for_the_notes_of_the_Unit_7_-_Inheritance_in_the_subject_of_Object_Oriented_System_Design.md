
### Unit 7 - Inheritance in Object Oriented System Design

1. Inheritance is a mechanism in object-oriented programming that allows a class to derive properties and methods from another class.

2. Inheritance allows a class to extend the functionality of another class without having to rewrite the code from scratch.

3. Inheritance allows for the reuse of code, which is especially useful when creating complex systems.

4. Inheritance allows for the sharing of data and methods between classes, which helps to reduce the complexity of the code.

5. Inheritance can be used to create a hierarchy of classes, allowing for more efficient code organization.

6. Inheritance can be used to create polymorphism, which allows for a single method to be used with multiple types of objects.

7. Inheritance can be used to create abstract classes, which are classes that cannot be instantiated but can be extended by other classes.
