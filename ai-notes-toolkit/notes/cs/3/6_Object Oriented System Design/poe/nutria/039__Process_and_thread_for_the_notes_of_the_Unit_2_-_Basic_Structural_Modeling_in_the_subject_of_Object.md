
### Process and thread for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

* Processes are the basic unit of execution in an object-oriented system. They are independent entities that can be scheduled, monitored, and managed. 
* A thread is a lightweight process that shares the same address space as the process it belongs to. 
* Threads are useful for parallelizing tasks, as they can be independently scheduled and managed. 
* Threads can communicate with each other via shared memory or other synchronization mechanisms. 
* In an object-oriented system, threads are typically used to execute tasks in parallel, such as executing multiple requests for a web service. 
* Threads can also be used to coordinate activities between different processes, such as coordinating the activities of multiple web services. 
* Threads can also be used to improve the performance of an application by allowing it to take advantage of multiple processors. 
* Threads can also be used to improve the scalability of an application by allowing it to take advantage of multiple machines. 
* Threads can also be used to improve the robustness of an application by allowing it to handle multiple requests simultaneously.
