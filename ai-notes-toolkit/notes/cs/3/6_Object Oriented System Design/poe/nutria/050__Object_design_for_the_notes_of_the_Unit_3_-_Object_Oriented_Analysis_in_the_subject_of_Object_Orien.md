
### Object Design for the Notes of the Unit 3 - Object Oriented Analysis in the Subject of Object Oriented System Design

* Object-oriented design is a process that involves the creation of objects and their relationships in order to solve a problem. 
* It is based on the concepts of abstraction, encapsulation, inheritance, and polymorphism. 
* Abstraction is the process of simplifying a problem by identifying the essential elements and ignoring the non-essential details. 
* Encapsulation is the process of combining related data and functions into a single unit. 
* Inheritance is the process of creating a new class from an existing class, which allows the new class to inherit the attributes and behaviors of the existing class. 
* Polymorphism is the process of creating multiple implementations of the same interface. 
* Object-oriented design is used to design software systems that are efficient, robust, and extensible. 
* It is also used to create reusable components that can be used in multiple applications. 
* Object-oriented design is based on the principles of modularity, reusability, and extensibility. 
* Modularity is the process of creating multiple components that are independent but can be combined to form a larger system. 
* Reusability is the process of creating components that can be reused in multiple applications. 
* Extensibility is the process of creating components that can be easily extended to meet the changing needs of the application.
