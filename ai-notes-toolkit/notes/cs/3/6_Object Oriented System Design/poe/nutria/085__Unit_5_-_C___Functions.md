

## Unit 5 - C++ Functions

- A function is a block of code that performs a specific task. It is a way of organizing code into smaller, more manageable chunks.
- Functions are declared by using the keyword `void` followed by the name of the function.
- The syntax of a function is as follows: `void function_name(parameter_list) { statements; }`
- Parameters are the variables that are passed to the function when it is called.
- The statements inside the function are the instructions that the function executes when it is called.
- The function can return a value back to the calling program by using the `return` keyword.
- Functions can be called from within other functions, allowing for the creation of complex programs.
- Functions can also be overloaded, meaning that two functions with the same name can be declared with different parameters.
- C++ also allows for the creation of inline functions, which are functions that are defined within a single line of code.
- Finally, C++ also allows for the creation of recursive functions, which are functions that call themselves.
