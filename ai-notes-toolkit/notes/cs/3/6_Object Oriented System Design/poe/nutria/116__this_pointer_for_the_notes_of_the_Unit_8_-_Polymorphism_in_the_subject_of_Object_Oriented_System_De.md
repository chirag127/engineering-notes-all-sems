
### Unit 8 - Polymorphism in Object Oriented System Design

* Polymorphism is a programming language feature that allows for the same code to be used with different types of data. 
* It is an important concept in object-oriented programming (OOP) and enables code reuse. 
* In OOP, polymorphism is achieved by creating classes that share a common interface and then implementing that interface in different ways. 
* For example, a class that implements a “draw” method could be used to draw different shapes such as circles, squares, and triangles. 
* Polymorphism can also be used to create generic functions that can be used with different types of data. 
* This allows for code to be written once and used with different types of data, reducing the amount of code needed to be written. 
* Polymorphism is also useful for creating extensible code, as it allows for new types of data to be added to a program without having to rewrite existing code.
