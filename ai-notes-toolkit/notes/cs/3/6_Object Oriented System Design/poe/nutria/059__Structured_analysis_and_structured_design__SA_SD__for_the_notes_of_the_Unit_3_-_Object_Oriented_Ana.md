
### Structured Analysis and Structured Design (SA/SD)

1. Structured Analysis is the process of understanding a problem and the system which is used to solve it. It involves the identification of the components of the system and the relationships between them.

2. Structured Design is the process of designing a system that meets the requirements identified in the Structured Analysis phase. It involves the specification of the components of the system and the relationships between them.

3. Object Oriented Analysis is the process of analyzing an existing system to determine what changes need to be made to it. It involves the identification of objects, their attributes and their relationships.

4. Object Oriented System Design is the process of designing a system that meets the requirements identified in the Object Oriented Analysis phase. It involves the specification of objects, their attributes and their relationships.
