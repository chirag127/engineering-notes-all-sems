
### Variables

Variables are an essential part of any programming language, and C++ is no exception. Variables are used to store data and can be referenced throughout the program. Variables must be declared before they can be used, and they can be declared in different ways depending on the type of data they will store.

**Types of Variables**

1. Primitive Variables: These are the simplest type of variables and are used to store basic data such as numbers, characters, and boolean values.
2. Reference Variables: These variables store the address of another variable in memory.
3. Pointer Variables: These variables store the address of another variable in memory, but can also be used to manipulate the data stored in the variable.
4. Constant Variables: These variables are declared with the const keyword and can only be assigned a value once.

**Variable Declaration**

Variables must be declared before they can be used. In C++, variables are declared using the following syntax:

`type variable_name;`

For example, to declare an integer variable called `my_variable`, the following syntax would be used:

`int my_variable;`

It is also possible to assign a value to a variable when it is declared. This is done using the following syntax:

`type variable_name = value;`

For example, to declare an integer variable called `my_variable` and assign it the value `5`, the following syntax would be used:

`int my_variable = 5;`
