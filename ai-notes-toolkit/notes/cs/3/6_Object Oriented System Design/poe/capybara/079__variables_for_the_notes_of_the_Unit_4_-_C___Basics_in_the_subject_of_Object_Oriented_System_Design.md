### Variables for the Notes of Unit 4 - C++ Basics in Object Oriented System Design

In this unit, we will focus on the basics of variables in C++ programming language. Variables are the fundamental building blocks of any program, and their proper usage is essential for efficient and effective programming. Here are some important points to keep in mind while studying variables in C++:

- A variable is a named memory location that stores values of a particular data type.
- In C++, variables must be declared before they can be used.
- The syntax for declaring a variable is: `data_type variable_name;`
- C++ provides several data types to represent different kinds of values, such as integers, floating-point numbers, characters, and boolean values.
- Integer data types include `int`, `short`, `long`, and `long long`.
- Floating-point data types include `float`, `double`, and `long double`.
- The `char` data type is used to represent single characters, while the `string` data type is used to represent strings of characters.
- Boolean data type is used to represent logical values, i.e., true or false.
- C++ also provides modifiers to these data types, such as `unsigned`, `signed`, and `const`.
- The `unsigned` modifier is used to represent only positive numbers, while `signed` can represent both positive and negative numbers. The `const` modifier is used to make a variable unmodifiable.
- Variables can be initialized at the time of declaration, using the syntax `data_type variable_name = value;`
- Variables can be assigned new values using the assignment operator `=`.

These are some of the essential points that you should keep in mind while studying variables in C++. By understanding these concepts thoroughly, you will be able to use variables effectively in your programs and create more efficient and robust code.
