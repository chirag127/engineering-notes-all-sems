### Common Mechanisms for the Notes of the Unit 2 - Basic Structural Modeling in the Subject of Object Oriented System Design

In this unit, we will learn about the fundamental concepts of basic structural modeling in Object Oriented System Design. The following are some of the common mechanisms for the notes of this unit:

1. **Class Diagrams:** Class diagrams are the most commonly used diagrams in Object Oriented System Design. They represent the static structure of the system by showing the classes, their attributes, and their relationships. Class diagrams are an essential tool for designing object-oriented systems.

2. **Object Diagrams:** Object diagrams represent instances of classes and the relationships between them. They are used to show the state of the system at a particular moment in time. Object diagrams are helpful in understanding how objects interact with each other.

3. **Package Diagrams:** Package diagrams are used to organize classes into logical groups. They help in managing complexity by dividing a large system into smaller, more manageable parts. Package diagrams are also useful in showing dependencies between packages.

4. **Composite Structure Diagrams:** Composite structure diagrams show the internal structure of a class. They are used to represent complex objects that have a hierarchical structure. Composite structure diagrams help in understanding the internal workings of a class.

5. **Component Diagrams:** Component diagrams represent the physical components of a system, such as modules or libraries. They are used to show how the system is built and how the components interact with each other.

6. **Deployment Diagrams:** Deployment diagrams show how the system is deployed on hardware. They represent the physical architecture of the system and the distribution of components across different nodes. Deployment diagrams are useful in understanding the scalability and performance of the system.

In conclusion, the common mechanisms for the notes of the Unit 2 - Basic Structural Modeling in Object Oriented System Design include class diagrams, object diagrams, package diagrams, composite structure diagrams, component diagrams, and deployment diagrams. These diagrams help in understanding the static and dynamic structures of a system and are essential tools for designing object-oriented systems.
