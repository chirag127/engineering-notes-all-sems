## Unit 3 - Object Oriented Analysis

Object Oriented Analysis (OOA) is a software engineering technique that involves modeling a system as objects, their attributes, and their relationships. OOA is the first step in Object Oriented Design (OOD).

### Benefits of Object Oriented Analysis

- OOA helps to identify the objects, attributes, and relationships of a system, which ultimately leads to a better understanding of the system.
- It helps to identify the requirements of a system and how they relate to each other.
- It helps to identify the components of a system and how they interact with each other.
- OOA helps to identify the constraints of a system, which can help in avoiding potential problems.
- It helps to identify the problems in the system design before implementation, which can save time and money.

### Steps in Object Oriented Analysis

1. Identify the objects of the system - The first step in OOA is to identify the objects of the system. Objects are entities that have a unique identity, attributes, and behaviors. The objects can be physical or conceptual.

2. Identify the attributes of the objects - Once the objects are identified, the next step is to identify the attributes of the objects. Attributes are the properties of an object that describe its characteristics.

3. Identify the relationships between the objects - The next step is to identify the relationships between the objects. Relationships can be one-to-one, one-to-many, or many-to-many.

4. Identify the behaviors of the objects - The final step is to identify the behaviors of the objects. Behaviors are the actions that an object can perform.

### Techniques for Object Oriented Analysis

1. Use case modeling - Use case modeling is a technique that is used to identify the use cases of a system. A use case is a description of a particular task or function that a user performs with the system.

2. Class modeling - Class modeling is a technique that is used to identify the classes of a system. A class is a blueprint for creating objects.

3. Object modeling - Object modeling is a technique that is used to identify the objects of a system and their relationships.

4. Behavioral modeling - Behavioral modeling is a technique that is used to identify the behaviors of the objects in the system.

### Conclusion

Object Oriented Analysis is an important technique for software engineering. It helps to identify the objects, attributes, and relationships of a system, which ultimately leads to a better understanding of the system. By following the steps and techniques outlined in this unit, you can ensure that you are performing effective Object Oriented Analysis.
