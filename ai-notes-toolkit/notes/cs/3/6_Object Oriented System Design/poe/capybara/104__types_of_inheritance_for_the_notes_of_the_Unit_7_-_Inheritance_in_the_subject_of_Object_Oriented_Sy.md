### Types of Inheritance

In Object Oriented System Design, inheritance is a powerful mechanism that allows classes to inherit properties and behaviors from other classes. There are different types of inheritance that can be used in Object Oriented Programming:

1. Single Inheritance:
   - A class can inherit from only one parent class.
   - The child class inherits all the properties and behaviors of the parent class.
   - It can add additional properties and behaviors of its own.

2. Multi-level Inheritance:
   - A class can inherit from a parent class, which in turn can inherit from another parent class.
   - The child class inherits all the properties and behaviors of its parent classes.
   - It can add additional properties and behaviors of its own.

3. Hierarchical Inheritance:
   - A class can have multiple child classes, but only one parent class.
   - Each child class inherits all the properties and behaviors of the parent class.
   - Each child class can add additional properties and behaviors of its own.

4. Multiple Inheritance:
   - A class can inherit from multiple parent classes.
   - The child class inherits all the properties and behaviors of its parent classes.
   - It can add additional properties and behaviors of its own.

5. Hybrid Inheritance:
   - It is a combination of multiple inheritance and hierarchical inheritance.
   - A class can inherit from multiple parent classes, and also have multiple child classes.
   - The child class inherits all the properties and behaviors of its parent classes.
   - It can add additional properties and behaviors of its own.

Understanding the different types of inheritance is important in Object Oriented System Design as it allows for the creation of complex and flexible class hierarchies. It is important to choose the appropriate type of inheritance based on the specific requirements of the system being designed.
