### Mapping Object Oriented Concepts Using Non-Object Oriented Language

In Unit 3 of Object Oriented Analysis, we will be learning about mapping object oriented concepts using non-object oriented language. This is an important topic that will help us better understand object oriented system design. Here are some key points to keep in mind:

- Object-oriented programming (OOP) is a programming paradigm based on the concept of "objects," which can contain data and code to manipulate that data. In OOP, objects are instances of classes, which define the properties and behaviors of the object.
- Non-object oriented languages, such as C or Pascal, don't have the concept of objects. Instead, they use data structures and functions to manipulate that data. 
- When mapping object oriented concepts to non-object oriented languages, we can represent objects as a structure in C or a record in Pascal. The properties of the object become fields in the structure or record, and the behaviors become functions that operate on the object. 
- In non-object oriented languages, inheritance can be represented using pointers or references to other structures or records. This allows us to reuse code and create hierarchies of related data structures. 
- Polymorphism can be represented in non-object oriented languages using function pointers or interfaces. This allows us to write generic code that can work with different types of data structures. 
- Encapsulation, which is a key concept in OOP, can be achieved in non-object oriented languages using access modifiers. For example, we can use the "private" keyword in C to hide the implementation details of a data structure from the user. 

By understanding how to map object oriented concepts to non-object oriented languages, we can better understand the underlying principles of OOP and how they can be applied in different programming paradigms. This will help us become better software engineers and design more robust and efficient systems.
