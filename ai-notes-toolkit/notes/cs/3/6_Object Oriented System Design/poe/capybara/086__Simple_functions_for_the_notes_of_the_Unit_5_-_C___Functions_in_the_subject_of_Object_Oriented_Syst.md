### Simple functions for the notes of the Unit 5 - C++ Functions in the subject of Object Oriented System Design

In the study of Object Oriented System Design, it is important to have a good understanding of C++ functions, which are an essential component of the language. Here are some simple functions to consider when studying the topic:

1. **Function declaration**: A function declaration in C++ specifies the name of the function, the type of its return value, and the types of its parameters. It is important to note that the declaration does not include the function's body.

2. **Function definition**: A function definition in C++ provides the body of the function, which contains the code that is executed when the function is called.

3. **Function call**: A function call in C++ is a statement that invokes the function and passes arguments to it. The arguments are values or variables that are passed to the function.

4. **Function overloading**: Function overloading in C++ allows multiple functions to have the same name, as long as their parameters are different. This can be useful when you need to perform the same operation on different types of data.

5. **Default parameters**: Default parameters in C++ allow you to specify a default value for a parameter, which is used if no value is provided when the function is called. This can make your code more concise and easier to read.

6. **Inline functions**: Inline functions in C++ are functions that are expanded in line with the code when they are called, rather than being executed as separate functions. This can improve performance by reducing the overhead of function calls.

7. **Recursive functions**: Recursive functions in C++ are functions that call themselves. They can be useful for solving problems that can be broken down into smaller sub-problems.

By mastering these basic functions, you will have a solid foundation for understanding more advanced concepts in C++ functions.
