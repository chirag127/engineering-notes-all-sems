### Hierarchical Notes for Unit 7 - Inheritance in Object Oriented System Design

Inheritance is an important concept in Object Oriented System Design. It allows a class to inherit the properties and methods of another class. In this unit, we will explore the following topics related to inheritance:

1. **What is Inheritance?** 
   - Inheritance is a process where one class acquires the properties and methods of another class.
   - The class that inherits the properties is called the **sub-class** or **child class**.
   - The class from which the properties are inherited is called the **super-class** or **parent class**.

2. **Types of Inheritance**
   - Single Inheritance: In this type of inheritance, a class inherits the properties of only one class.
   - Multiple Inheritance: In this type of inheritance, a class inherits the properties of multiple classes.
   - Multilevel Inheritance: In this type of inheritance, a class inherits from a parent class, which in turn inherits from another parent class.
   - Hierarchical Inheritance: In this type of inheritance, multiple classes inherit from a single parent class.

3. **Access Modifiers in Inheritance**
   - Public Access Modifier: The public members of the parent class are accessible to the child class.
   - Private Access Modifier: The private members of the parent class are not accessible to the child class.
   - Protected Access Modifier: The protected members of the parent class are accessible to the child class.

4. **Method Overriding**
   - Method overriding is a process where a subclass provides its own implementation of a method that is already present in the parent class.
   - This allows the subclass to modify the behavior of the method without changing its signature.

5. **Super Keyword**
   - The super keyword is used to refer to the parent class.
   - It can be used to call the constructor or the method of the parent class.

6. **Polymorphism**
   - Polymorphism is the ability to use an object of a subclass wherever an object of the parent class is expected.
   - This allows for more flexibility and reusability in code.

In conclusion, inheritance is a powerful concept that allows for code reuse and flexibility in Object Oriented System Design. Understanding the different types of inheritance, access modifiers, method overriding, super keyword, and polymorphism is crucial for writing efficient and effective code.
