### Modelling Techniques for Class & Object Diagrams

In the Unit 2 - Basic Structural Modeling of Object Oriented System Design, we will learn about modelling techniques for Class & Object Diagrams. Here are some important points to keep in mind:

- Class Diagrams are used to represent the static structure of a system. They show the classes, interfaces, and their relationships with each other in a system.
- The classes in a Class Diagram are represented by rectangles, and the relationships between them are shown using lines and symbols.
- There are several types of relationships that can be shown in a Class Diagram, such as inheritance, association, aggregation, and composition.
- Inheritance represents an "is-a" relationship between two classes, where one class is a subclass of another. It is shown using an arrow with an open triangle.
- Association represents a "has-a" relationship between two classes, where one class uses the functionality of another. It is shown using a line with an arrow.
- Aggregation represents a "has-a" relationship between two classes, where one class contains another class as a part. It is shown using a line with a diamond-shaped arrow.
- Composition represents a "has-a" relationship between two classes, where one class cannot exist without the other. It is shown using a line with a filled diamond-shaped arrow.

- Object Diagrams are used to represent the instances of classes and the relationships between them. They show the objects, their attributes, and their relationships with each other in a system.
- The objects in an Object Diagram are represented by rectangles, and the relationships between them are shown using lines and symbols, similar to a Class Diagram.
- Object Diagrams are used to model the dynamic behavior of a system, and they can be used to verify and validate Class Diagrams.

In summary, Class & Object Diagrams are important modelling techniques in Object Oriented System Design. They help us to represent the static and dynamic structure of a system and understand the relationships between classes and objects. Understanding these concepts is crucial for designing and developing robust and scalable software systems.
