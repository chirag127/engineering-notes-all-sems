### Basics of object and class in C++ 

- Object-oriented programming (OOP) is a programming paradigm that revolves around the concept of objects, which are instances of classes. 
- A class is a blueprint for creating objects with a specific set of attributes and behaviors. 
- In C++, a class can contain data members (attributes) and member functions (behaviors). 
- An object is an instance of a class, which means it contains its own set of data members and can invoke its own set of member functions. 
- When an object is created, memory is allocated for its data members, and its constructor is called to initialize them. 
- Objects interact with each other by calling each other's member functions or by accessing each other's data members. 
- A class can also contain static data members and static member functions, which are shared by all instances of the class. 
- The access specifiers in C++ (public, private, and protected) determine the visibility of a class's data members and member functions. 
- The public members can be accessed by any code that has access to the object, while the private members can only be accessed by member functions of the same class. 
- Inheritance is a mechanism in OOP that allows a new class to be based on an existing class, inheriting its attributes and behaviors. 
- Polymorphism is another important concept in OOP, which allows objects of different classes to be treated as if they were of the same class. 
- Encapsulation is the idea of hiding the implementation details of a class from its users, and only exposing a public interface for interacting with the object. 

These are the basics of object and class in C++ that are important to know for the Unit 6 - Objects and Classes in the subject of Object Oriented System Design.
