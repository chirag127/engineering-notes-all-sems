### Component for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In this unit, we will be exploring the basics of structural modeling in the context of Object Oriented System Design. Structural modeling is an important aspect of designing software systems and understanding how different components of a system interact with each other.

Here are some key components that you should focus on while taking notes for this unit:

- **Classes:** Classes are the building blocks of Object Oriented System Design. They represent the blueprint for creating objects that share common characteristics and behaviors. While taking notes on this topic, make sure to focus on the different types of classes, their attributes, and the methods that they contain.

- **Objects:** Objects are instances of classes and are used to represent real-world entities in a software system. When taking notes on this topic, focus on the different characteristics of objects, how they interact with each other, and how they can be created and manipulated.

- **Inheritance:** Inheritance is a key concept in Object Oriented System Design that enables classes to inherit attributes and behaviors from other classes. When taking notes on this topic, focus on the different types of inheritance, how it is implemented, and its advantages and disadvantages.

- **Composition:** Composition is another important concept in Object Oriented System Design that enables classes to be composed of other classes. When taking notes on this topic, focus on the different types of composition, how it is implemented, and its advantages and disadvantages.

- **UML Diagrams:** UML diagrams are graphical representations of Object Oriented System Design that are used to model the structure and behavior of a software system. When taking notes on this topic, focus on the different types of UML diagrams, their components, and how they can be used to represent different aspects of a software system.

By focusing on these key components, you will be able to gain a better understanding of the basics of structural modeling in Object Oriented System Design. Make sure to take detailed and organized notes, as they will be essential for studying and preparing for exams.
