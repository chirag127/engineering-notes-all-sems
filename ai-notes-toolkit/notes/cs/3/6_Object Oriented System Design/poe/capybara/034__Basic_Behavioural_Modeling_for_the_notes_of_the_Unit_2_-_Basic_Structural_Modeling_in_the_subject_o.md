### Basic Behavioural Modeling

Object-oriented systems are designed with the intention of modelling real-world objects and their behaviour. Basic Behavioural Modeling is an essential part of Object Oriented System Design. It is used to model the behaviour of an object in a system. Here are some important points to remember when creating a behavioural model:

- Identify the behaviour of the object: The first step in creating a behavioural model is to identify the behaviour of the object. Behaviour can be defined as a set of actions or activities that the object can perform. These actions can be triggered by events or messages.

- Use Use Case Diagrams: Use Case Diagrams are a great way to identify the various behaviours of an object. They help in identifying the actors, the use cases and the relationships between them. This helps in understanding the overall behaviour of the object.

- Create Sequence Diagrams: Once the behaviours of the object have been identified, the next step is to create Sequence Diagrams. Sequence diagrams help in visualising the various activities and interactions between different objects.

- Use Activity Diagrams: Activity Diagrams are another way of visualising the behaviour of an object. They help in identifying the various activities and the flow of control between them.

- Identify the States: Objects can have multiple states, and the behaviour of the object can change depending on the state it is in. It is important to identify the different states and the transitions between them.

- Use State Diagrams: State Diagrams are used to model the states and the transitions between them. They help in understanding the behaviour of the object in different states.

- Use Collaboration Diagrams: Collaboration Diagrams help in visualising the interactions between different objects. They help in understanding the overall behaviour of the system and the different objects in it.

- Use Communication Diagrams: Communication Diagrams are another way of visualising the interactions between different objects. They help in identifying the messages exchanged between different objects and the order in which they are exchanged.

These are some basic points to remember when creating a behavioural model for an object-oriented system. By following these guidelines, you can create a detailed and accurate model that accurately represents the behaviour of the object in the system.
