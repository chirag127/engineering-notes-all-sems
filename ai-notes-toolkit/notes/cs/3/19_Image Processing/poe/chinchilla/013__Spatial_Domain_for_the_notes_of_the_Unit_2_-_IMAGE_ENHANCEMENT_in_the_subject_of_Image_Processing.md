### Spatial Domain

Image enhancement is a process of improving the visual quality of an image. Spatial domain image enhancement techniques operate directly on the pixel values of the image. In this unit, we will discuss various spatial domain techniques used for image enhancement.

1. Histogram Equalization: 
Histogram equalization is a widely used technique for image enhancement. It is a method of adjusting the intensity distribution of an image by transforming the image histogram into a uniform distribution. This technique is useful for enhancing contrast in images.

2. Contrast Stretching: 
Contrast stretching is a process of increasing the contrast of an image. It involves stretching the intensity values of an image to the full dynamic range. This technique is useful for images with low contrast.

3. Spatial Filtering: 
Spatial filtering is a technique of modifying the pixel values of an image based on their spatial relationships. It involves applying a filter kernel to the image pixels. This technique is useful for smoothing or sharpening an image.

4. Smoothing Filters:
Smoothing filters are used to reduce noise in an image. These filters work by averaging the pixel values in a neighborhood. Examples of smoothing filters include the mean filter, median filter, and Gaussian filter.

5. Sharpening Filters:
Sharpening filters are used to enhance the edges and details in an image. These filters work by enhancing the difference between neighboring pixel values. Examples of sharpening filters include the Laplacian filter and the Sobel filter.

6. Image Restoration:
Image restoration is a technique of removing noise and other distortions from an image. It involves the use of mathematical models to estimate the original image from the degraded image. This technique is useful for restoring images that have been degraded by factors such as noise or blur.

In conclusion, spatial domain techniques are powerful tools for image enhancement. These techniques are used to improve the visual quality of an image by directly modifying the pixel values. Understanding the various spatial domain techniques is essential for any image processing application.
