## Unit 1 - DIGITAL IMAGE FUNDAMENTALS

In this unit, we will cover the basics of digital image processing. Digital images are ubiquitous in today's world, and understanding their fundamentals is essential for anyone working with images in various fields, including photography, computer vision, and graphics.

### What is a Digital Image?

A digital image is a representation of a two-dimensional image in a computer. It consists of a grid of pixels, where each pixel represents a specific color or intensity value. The size of the image is determined by the number of pixels in the grid. The resolution of the image is determined by the number of pixels per inch (ppi) or dots per inch (dpi) in the image.

### Color Spaces

Color spaces are mathematical models that describe how colors are represented in a digital image. Some common color spaces include RGB, CMYK, and HSL. 

- RGB (Red, Green, Blue) is an additive color space used for displaying images on screens. In this color space, each pixel is represented by three values that describe the intensity of red, green, and blue light required to produce that color.

- CMYK (Cyan, Magenta, Yellow, Black) is a subtractive color space used for printing. In this color space, each pixel is represented by four values that describe the amount of cyan, magenta, yellow, and black ink required to produce that color.

- HSL (Hue, Saturation, Lightness) is a color space that describes colors in terms of their hue, saturation, and lightness. Hue refers to the actual color, saturation refers to the intensity of the color, and lightness refers to how light or dark the color is.

### Image File Formats

Image file formats are used to store digital images on a computer. Some common file formats include JPEG, PNG, and GIF.

- JPEG (Joint Photographic Experts Group) is a lossy compression format used to store photographs. It is a popular format for web images because it creates small file sizes while still maintaining high-quality images.

- PNG (Portable Network Graphics) is a lossless compression format used to store images with transparent backgrounds. It is a popular format for logos and graphics.

- GIF (Graphics Interchange Format) is a lossless compression format used to store animated images. It is a popular format for web animations.

### Image Processing Operations

Image processing operations are used to manipulate digital images. Some common operations include resizing, cropping, and filtering.

- Resizing changes the size of the image by adding or removing pixels from the grid.

- Cropping removes portions of the image by selecting a specific region of the grid.

- Filtering modifies the pixel values in the image to achieve a specific effect, such as blurring or sharpening.

### Conclusion

In this unit, we have covered the basics of digital image processing, including color spaces, image file formats, and image processing operations. Understanding these fundamentals is essential for anyone working with digital images in various fields.
