### Components for the notes of the Unit 1 - DIGITAL IMAGE FUNDAMENTALS in the subject of Image Processing

In this unit, we will be discussing the fundamentals of digital images in the context of image processing. To fully understand the concepts, it is important to have a solid grasp of the following components:

- **Pixels**: The smallest unit of an image is called a pixel. It represents a single point in the image and can be thought of as a tiny square with a specific color value. The resolution of an image is determined by the number of pixels it contains.
- **Digital image formats**: There are several formats in which digital images can be stored, including JPEG, PNG, BMP, and GIF. Each format has unique features and is suitable for different types of images.
- **Color models**: To represent color in digital images, we use different color models, such as RGB, CMYK, and HSL. Each model has its own unique advantages and is used in various applications.
- **Image acquisition**: The process of capturing an image using a camera or scanner is called image acquisition. This process involves converting analog data into digital data that can be processed by a computer.
- **Image enhancement**: Image enhancement techniques are used to improve the quality of an image. These techniques include contrast adjustment, sharpening, noise reduction, and color correction.
- **Image segmentation**: Image segmentation involves dividing an image into multiple regions or segments. This process is useful in object recognition, image editing, and computer vision applications.
- **Image compression**: Image compression techniques are used to reduce the size of an image file without significantly reducing its quality. This is useful for storing and transmitting images efficiently.

By understanding these components, you will be able to comprehend the fundamental concepts of digital image processing. It is recommended that you review these components thoroughly before moving on to more advanced topics in the subject.
