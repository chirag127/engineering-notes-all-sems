## Unit 2 - IMAGE ENHANCEMENT

Image enhancement is the process of improving the quality of an image by applying various techniques. Image enhancement is an important topic in image processing and plays a significant role in various fields such as medical imaging, satellite imaging, security systems, and many more. In this unit, we will learn about the different techniques used for image enhancement.

### Histogram Equalization
- Histogram equalization is a technique that is used to adjust the contrast of an image.
- It works by spreading out the pixel values in an image, resulting in a more evenly distributed histogram.
- The process involves computing the histogram of the image and then transforming the pixel values to create a new image with a more uniform histogram.
- Histogram equalization can be used to enhance the visibility of details in an image.

### Spatial Filtering
- Spatial filtering is a technique used to enhance the quality of an image by applying filters to the pixels in the image.
- The filters are used to modify the values of the pixels in the image based on their surrounding pixels.
- The most common types of filters used in spatial filtering are low-pass filters, high-pass filters, and median filters.
- Low-pass filters are used to smooth an image, while high-pass filters are used to enhance the edges in an image.
- Median filters are used to remove noise from an image.

### Frequency Domain Filtering
- Frequency domain filtering is a technique that is used to enhance the quality of an image by analyzing its frequency components.
- The Fourier transform is used to convert an image from the spatial domain to the frequency domain.
- Filters are applied to the frequency components of the image to remove noise or enhance certain features.
- After filtering, the image is transformed back to the spatial domain using the inverse Fourier transform.

### Edge Detection
- Edge detection is a technique used to identify the edges in an image.
- Edges represent the boundaries between different regions in an image and can be used to segment an image into different regions.
- There are several edge detection algorithms, including the Sobel, Prewitt, and Canny edge detection algorithms.
- These algorithms work by detecting changes in the intensity of the pixels in an image.

### Conclusion
Image enhancement is an important topic in image processing and plays a crucial role in various fields. In this unit, we have learned about the different techniques used for image enhancement, including histogram equalization, spatial filtering, frequency domain filtering, and edge detection. By applying these techniques, we can improve the quality of images and make them more useful for various applications.
