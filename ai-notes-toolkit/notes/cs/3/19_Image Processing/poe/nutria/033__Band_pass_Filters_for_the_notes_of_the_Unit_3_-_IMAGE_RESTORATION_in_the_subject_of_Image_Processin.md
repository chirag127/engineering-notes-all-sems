
### Band Pass Filters 

* Band pass filters are used to allow only certain frequencies to pass through while blocking all other frequencies. 
* These filters are used in image processing to enhance the image by removing noise and other unwanted frequencies.
* The pass band of a band pass filter is determined by the range of frequencies that it allows to pass through.
* The cut-off frequency is the frequency at which the filter starts to attenuate the signal.
* The transfer function of the filter determines the frequency response of the filter.
* The filter can be designed to be either a low pass filter, a high pass filter, or a band pass filter.
* The filter can be designed to have a sharp or a gradual transition between the pass band and the stop band.
* The filter can also be designed to have a constant or a variable gain in the pass band.
* The filter can be implemented using analog or digital techniques.
* The filter can be applied to a signal in either the time domain or the frequency domain.
