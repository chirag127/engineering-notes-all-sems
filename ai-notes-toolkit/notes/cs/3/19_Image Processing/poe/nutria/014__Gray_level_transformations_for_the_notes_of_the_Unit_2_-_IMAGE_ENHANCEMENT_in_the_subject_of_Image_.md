
### Gray Level Transformations for Unit 2 - Image Enhancement in Image Processing

1. Gray level transformations are techniques used to improve the appearance of an image by altering its contrast and brightness.

2. Histogram equalization is a gray level transformation technique which adjusts the contrast of an image by redistributing the gray levels in the image.

3. Histogram matching is a gray level transformation technique which adjusts the contrast of an image by matching the histogram of the image to a reference histogram.

4. Gamma correction is a gray level transformation technique which adjusts the brightness of an image by applying a non-linear transformation to the pixel values.

5. Logarithmic transformation is a gray level transformation technique which adjusts the brightness of an image by applying a logarithmic transformation to the pixel values.

6. Adaptive histogram equalization is a gray level transformation technique which adjusts the contrast of an image by redistributing the gray levels in the image based on a region-by-region basis.
