### Boundary representation

- Boundary representation (B-rep) is a method for representing a 3D shape by defining the limits of its volume.
- A solid is represented as a collection of connected surface elements, which define the boundary between interior and exterior points.
- A boundary representation of a model comprises topological components (faces, edges and vertices) and the connections between them, along with geometric definitions for those components (surfaces, curves and points, respectively).
- A face is a bounded portion of a surface; an edge is a bounded piece of a curve and a vertex lies at a point.
- Boundary representation is useful for image processing and computer-aided design, as it allows for efficient manipulation and analysis of 3D shapes.
- Boundary extraction is the process of finding the boundary of an object or a region in an image.
- Boundary extraction can be done by using morphological operations, such as erosion and dilation, on binary images .
- A binary image is obtained from a grey-scale image by following a process of information abstraction. Thresholding is the main technique used at this stage. The main goal of thresholding is to extract the foreground from the background.
- Boundary extraction can help to gain information and understand the features of an image. It is the first process in preprocessing to present the image’s characteristics. This process can help the researcher to acquire data from the image.
- Boundary representation and extraction can also be used for image description and recognition, by using features such as shape, size, orientation, and curvature of the boundary.
- The polynomial transform is an image representation model that mimics some properties of the human visual system, and which can be used to model edges in terms of their characteristic parameters.
