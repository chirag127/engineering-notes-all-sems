# Order Statistics for the notes of the Unit 3 - IMAGE RESTORATION in the subject of Image Processing

- Image restoration is the process of recovering an image that has been degraded by a degradation phenomenon, such as noise, blur, or distortion.
- Order statistics are the values obtained by sorting a set of data in ascending or descending order. For example, the minimum, maximum, and median are order statistics of a data set.
- Order statistic filters are non-linear spatial filters that operate on the order statistics of the pixels in a neighborhood of the image. They can be used to remove noise, enhance edges, or smooth regions in an image.
- Some common order statistic filters are:

  - Linear average filter: This filter replaces the center pixel with the average of all the pixels in the neighborhood. It is equivalent to an order statistic filter with equal coefficients for all the pixels. It can reduce noise, but also blurs edges and details.
  - Median filter: This filter replaces the center pixel with the median of the pixels in the neighborhood. It is equivalent to an order statistic filter with coefficients of 1 for the middle pixel and 0 for the rest. It can remove salt-and-pepper noise, but also reduces contrast and sharpness.
  - Max and min filters: These filters replace the center pixel with the maximum or minimum of the pixels in the neighborhood. They are equivalent to order statistic filters with coefficients of 1 for the max or min pixel and 0 for the rest. They can enhance edges, but also introduce artifacts and noise.
  - Midpoint filter: This filter replaces the center pixel with the average of the maximum and minimum of the pixels in the neighborhood. It is equivalent to an order statistic filter with coefficients of 0.5 for the max and min pixels and 0 for the rest. It can reduce noise, but also blurs edges and details.
  - Alpha-trimmed mean filter: This filter replaces the center pixel with the average of the pixels in the neighborhood after discarding the highest and lowest alpha percent of the pixels. It is equivalent to an order statistic filter with coefficients of 1/(n-2a) for the remaining pixels and 0 for the rest, where n is the number of pixels in the neighborhood and a is the number of pixels to be trimmed. It can remove noise and preserve edges, but also reduces contrast and sharpness.

- Order statistic filters can be generalized by assigning different coefficients to different pixels in the neighborhood, depending on their rank. This allows for more flexibility and control over the filtering effect. For example, a weighted median filter assigns weights to the pixels in the neighborhood and replaces the center pixel with the weighted median. A rank-order filter assigns ranks to the pixels in the neighborhood and replaces the center pixel with the pixel with the desired rank. A percentile filter assigns percentiles to the pixels in the neighborhood and replaces the center pixel with the pixel with the desired percentile.
- Order statistic filters can also be applied to color images, either by filtering each color channel separately or by using a vector order statistic filter that operates on the color vectors of the pixels in the neighborhood. A vector order statistic filter can use different distance measures to compare the color vectors, such as Euclidean, Manhattan, or Mahalanobis distance.
- Order statistic filters can be combined with other image restoration techniques, such as blind deconvolution, nonlocal image averaging, or higher order statistics, to improve the quality of the restored image. Blind deconvolution is a technique that estimates the blur kernel and the original image from the degraded image without prior knowledge of the blur. Nonlocal image averaging is a technique that averages similar patches in the image to reduce noise and preserve details. Higher order statistics are measures that capture the higher moments of the data distribution, such as skewness and kurtosis, and can be used to identify and remove noise pixels.
