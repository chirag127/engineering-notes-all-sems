# Unit 5 - IMAGE COMPRESSION AND RECOGNITION

- Image compression is the process of reducing the file size of an image while still trying to preserve the quality of the image.
- Image compression is useful for saving storage space, reducing bandwidth requirements, and facilitating image processing algorithms.
- Image compression can be classified into two types: lossless and lossy.
  - Lossless compression preserves the exact information of the original image, but achieves a lower compression ratio.
  - Lossy compression discards some information of the original image, but achieves a higher compression ratio.
- Image compression can be performed by applying different techniques, such as image transform, quantization, and encoding.
  - Image transform converts the image from one domain (such as spatial or pixel domain) to another domain (such as frequency or transform domain) that is more suitable for compression.
  - Quantization reduces the number of levels or values that represent the image in the transform domain.
  - Encoding assigns codes to the quantized values to reduce the number of bits required to store or transmit the image.
- Image recognition is the process of identifying and classifying objects or features in an image using machine learning or deep learning techniques.
- Image recognition can be used for various tasks, such as face recognition, object detection, scene segmentation, and image captioning.
- Image recognition can be performed by applying different techniques, such as convolutional neural networks (CNNs), generative adversarial networks (GANs), and attention mechanisms .
  - CNNs are a type of neural network that can learn features from images using multiple layers of filters or kernels that convolve with the input image.
  - GANs are a type of neural network that can generate realistic images from noise or latent vectors using two competing networks: a generator and a discriminator .
  - Attention mechanisms are a type of neural network that can focus on specific regions or parts of an image that are relevant for a given task or query.
- Image compression and recognition can be combined to achieve better performance and efficiency .
  - Image compression can reduce the input size and complexity for image recognition, which can speed up the inference and reduce the computational cost.
  - Image recognition can provide feedback or guidance for image compression, which can optimize the compression quality and rate for a specific task or application .
