### Patterns and Pattern Classes

- A pattern is an arrangement of descriptors, which are measurable properties of an object or phenomenon .
- A descriptor can be a feature, which is a distinctive or characteristic attribute of a pattern .
- A pattern class is a family of patterns that share some common properties .
- Pattern classes are denoted by ω1, ω2, …, ωW, where W is the number of classes.
- Pattern recognition is an information-reduction process that assigns patterns to their respective classes based on the features of these patterns and their relationships .
- Pattern recognition by machine involves techniques for assigning patterns to their classes automatically and with as little human intervention as possible.
- Three common pattern arrangements used in practice are vectors (for quantitative descriptions), strings (for structural descriptions), and trees (for hierarchical descriptions).
- Pattern vectors are ordered sets of numerical values that represent the features of a pattern. For example, a pattern vector for an image can be the pixel values or the color histogram of the image.
- Pattern strings are sequences of symbols that represent the structure of a pattern. For example, a pattern string for an image can be the contour or the shape of the image.
- Pattern trees are graphs that represent the hierarchical or nested structure of a pattern. For example, a pattern tree for an image can be the segmentation or the region hierarchy of the image.
- Pattern recognition can be classified into two types: supervised and unsupervised.
- Supervised pattern recognition is when the classes of the patterns are known in advance and the machine is trained with labeled examples of each class.
- Unsupervised pattern recognition is when the classes of the patterns are unknown and the machine has to discover them from the data without any prior knowledge.
- Image processing is a set of computational techniques for analyzing, enhancing, compressing, and reconstructing images.
- Image analysis is a subfield of image processing that focuses on extracting information from images, such as objects, features, regions, shapes, textures, etc..
- Image compression is a technique for reducing the size of an image by removing redundant or irrelevant information.
- Image recognition is a technique for identifying or classifying an image or its contents based on the features or patterns extracted from the image .
- Image recognition is an application of pattern recognition in image processing.
