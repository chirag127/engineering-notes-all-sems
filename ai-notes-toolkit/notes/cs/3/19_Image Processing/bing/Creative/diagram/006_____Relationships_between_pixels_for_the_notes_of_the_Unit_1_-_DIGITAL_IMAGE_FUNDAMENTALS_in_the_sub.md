### Relationships between pixels

- A digital image is composed of a finite number of pixels arranged in rows and columns.
- Each pixel has a location and a value, which represents its intensity or color.
- The location of a pixel is given by its coordinates (x, y), where x is the column index and y is the row index.
- The value of a pixel is given by a number in a certain range, depending on the bit depth of the image. For example, a binary image has pixels with values 0 or 1, while a grayscale image has pixels with values from 0 to 255.
- The pixels in a digital image are related to each other in various ways, such as:

  - **Neighborhood**: The set of pixels that are adjacent to a given pixel. There are different types of neighborhoods, such as 4-neighborhood, 8-neighborhood, or m x n-neighborhood.
  - **Connectivity**: The property of a pixel being connected to another pixel by a path of pixels with the same value. There are different types of connectivity, such as 4-connectivity, 8-connectivity, or m-connectivity.
  - **Distance**: The measure of how far apart two pixels are. There are different ways to define distance, such as Euclidean distance, city-block distance, or chessboard distance.
  - **Region**: A set of pixels that share a common property, such as value, color, or texture. A region can be defined by a threshold, a boundary, or a mask.
  - **Boundary**: The set of pixels that separate one region from another. A boundary can be defined by an edge, a contour, or a border.
  - **Edge**: A pixel that has a significant change in value or color from its neighbors. An edge can be detected by using filters, gradients, or operators.
  - **Contour**: A curve that traces the boundary of a region. A contour can be extracted by using algorithms, such as chain code, polygonal approximation, or spline fitting.
  - **Border**: A set of pixels that lie on the boundary of a region, but are not part of the region. A border can be obtained by using morphological operations, such as erosion, dilation, or opening.
