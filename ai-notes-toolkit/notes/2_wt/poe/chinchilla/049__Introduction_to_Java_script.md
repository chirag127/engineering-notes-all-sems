#### Introduction to Java script

Java script is a widely used programming language that is used to make web pages interactive. Here are some important points to understand about Java script:

1. Java script is a scripting language that is used to make web pages more dynamic and interactive.

2. Java script can be embedded into HTML pages and can interact with the Document Object Model (DOM) to manipulate and change the content of the web page.

3. Java script is a client-side language, meaning that it runs on the user's computer rather than the web server.

4. Java script can be used for a variety of tasks, including form validation, creating animations, and handling user events like mouse clicks and keyboard input.

5. Java script has a simple and easy-to-learn syntax, making it a popular choice for beginners.

6. Java script is supported by all major web browsers, including Chrome, Firefox, Safari, and Internet Explorer.

7. Java script can also be used on the server-side with Node.js, a platform built on Chrome's V8 JavaScript engine.

8. Java script is an interpreted language, meaning that the code is executed by the browser as it is read rather than being compiled into machine code.

9. Java script has a vast community of developers who contribute to open-source libraries and frameworks, making it easy to find pre-built solutions for common problems.

10. Java script is constantly evolving with new updates and features being added to the language, making it an exciting language to learn and work with.

By understanding the basics of Java script, you can create dynamic and interactive web pages that provide a great user experience for your visitors.
