## Unit 4 - Enterprise Java Bean

Enterprise Java Beans (EJBs) are server-side components used to develop distributed, scalable, and transactional applications in Java. EJBs are the backbone of Java Enterprise Edition (Java EE) and provide a robust framework for building enterprise applications. In this unit, we will cover the following topics related to EJBs:

1. Introduction to EJBs
- Definition of EJBs
- Types of EJBs
- Advantages of using EJBs

2. Session Beans
- Definition of Session Beans
- Types of Session Beans
- Lifecycle of Session Beans
- Stateless Session Beans
- Stateful Session Beans

3. Entity Beans
- Definition of Entity Beans
- Types of Entity Beans
- Lifecycle of Entity Beans
- Bean-Managed Persistence (BMP)
- Container-Managed Persistence (CMP)

4. Message-Driven Beans
- Definition of Message-Driven Beans
- Lifecycle of Message-Driven Beans
- Message-Driven Bean Types
- Message-Driven Bean Activation Configurations

5. EJB Container and Deployment Descriptor
- Definition of EJB Container
- EJB Deployment Descriptor (ejb-jar.xml)
- EJB Annotations

6. EJB Transactions
- Definition of Transactions
- Types of Transactions
- EJB Transaction Attributes
- Transaction Management in EJBs

7. EJB Security
- Definition of Security in EJBs
- EJB Security Annotations
- EJB Security Roles
- EJB Security Constraints

8. EJB Interceptors
- Definition of Interceptors
- Types of Interceptors
- EJB Interceptor Annotations
- Interceptor Chain

By the end of this unit, you will have a comprehensive understanding of EJBs, their types, and their uses in building enterprise applications. You will also learn about the EJB container, deployment descriptors, transactions, security, and interceptors. With this knowledge, you will be able to develop robust and scalable enterprise applications using EJBs in Java.
