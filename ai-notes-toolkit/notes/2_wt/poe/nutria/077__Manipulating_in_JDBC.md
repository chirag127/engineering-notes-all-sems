
#### Manipulating in JDBC

1. JDBC (Java Database Connectivity) is a Java API used to connect and execute queries to a database. It is a standard API and is included in the Java Standard Edition (SE) platform.

2. JDBC provides a set of classes and interfaces that allow developers to write Java code to access and manipulate data stored in a database.

3. To connect to a database, developers must provide a JDBC driver. A JDBC driver is a software component that enables Java applications to interact with a database.

4. Once connected, developers can use the JDBC API to execute SQL statements, retrieve results and process them.

5. JDBC also provides support for transactions, which allow developers to execute multiple statements as a single unit of work.

6. JDBC is a powerful tool for accessing and manipulating data in a database. It is a standard API and is included in the Java Standard Edition (SE) platform.
