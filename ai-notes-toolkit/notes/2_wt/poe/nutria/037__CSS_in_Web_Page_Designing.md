
### CSS in Web Page Designing

* CSS stands for Cascading Style Sheets and is a language that is used to describe the look and formatting of a web page. 
* CSS is used to control the presentation of content on a web page, including font size, color, layout, and other aspects of the page's visual design.
* CSS is written in a style sheet that is linked to the HTML document. This style sheet contains all the information needed to describe the presentation of the web page.
* CSS can be used to create responsive web design, which allows a web page to adapt to different screen sizes and devices.
* CSS can also be used to create animations and other dynamic effects on a web page.
* CSS can be used to create interactive elements on a web page, such as dropdown menus, accordions, and other user interface elements. 
* CSS can also be used to create printable versions of web pages.
