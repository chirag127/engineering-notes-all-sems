
### HTML in Web Page Designing

1. HTML stands for Hypertext Markup Language and is the standard markup language for creating web pages and web applications.
2. HTML is written in the form of HTML elements consisting of tags enclosed in angle brackets (like <html>).
3. HTML elements form the building blocks of all websites.
4. HTML allows images and objects to be embedded and can be used to create interactive forms.
5. CSS and JavaScript are used to define the look and behavior of web pages.
6. HTML can be used to create structured documents by denoting structural semantics for text such as headings, paragraphs, lists, links, quotes and other items.
