
### Core Java 

1. Java is a general-purpose, object-oriented programming language developed by Sun Microsystems in 1995.
2. It is designed to have few implementation dependencies as possible.
3. Java programs are compiled into bytecode which can then be run on any Java Virtual Machine (JVM).
4. Java has a large standard library which provides a wide range of functionality, including networking, graphical user interface (GUI) development, and database access.
5. Java also has a large number of open source libraries and frameworks which can be used to create powerful applications.
6. Java is platform independent and can be used to create applications that can run on any operating system.
7. Java is a strongly typed language which means that all variables must be declared with their type before they can be used.
8. Java has a garbage collection system which automatically reclaims memory which is no longer used.
9. Java has a powerful exception handling system which allows developers to handle errors in a more structured way.
10. Java also has a range of features which make it suitable for creating distributed applications.
