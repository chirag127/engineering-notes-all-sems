
## Unit 2 - Web Page Designing

1. Web page design is the process of creating and styling web pages to create a website.

2. Web page design requires knowledge of HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) to create the structure and layout of a web page.

3. HTML is used to define the structure of a web page, while CSS is used to define the styling of a web page.

4. Web page design also requires knowledge of web design principles to create an aesthetically pleasing and effective page.

5. Web page design principles include the use of typography, color, imagery, and white space.

6. Web page design also requires knowledge of usability principles to create a page that is easy to use and navigate.

7. Usability principles include the use of intuitive navigation, clear labeling, and helpful error messages.

8. Web page design also requires knowledge of accessibility principles to create a page that is accessible to all users, regardless of ability.

9. Accessibility principles include the use of semantic HTML, alternative text for images, and keyboard navigation.
