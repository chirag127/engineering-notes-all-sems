
#### Statements in JavaScript
* JavaScript statements are instructions that are executed by the browser.
* JavaScript statements are composed of values, operators, expressions, keywords, and comments.
* Values can be strings, numbers, Booleans (true or false), or objects.
* Operators are used to assign, compare, and perform mathematical and logical operations on values.
* Expressions are combinations of values, variables, and operators, which are evaluated to a single value.
* Keywords are used to control the flow of a program and to declare variables.
* Comments are used to explain code and make it more readable. They are ignored by the browser.
