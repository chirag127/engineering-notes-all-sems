
#### Joining in JDBC

* Joining in JDBC is a method of combining data from multiple tables in a relational database. 
* It is used to query data from multiple tables and return results in a single result set.
* Joining is done by specifying a join condition in the query. This condition specifies how the data in the tables is related.
* The most common types of joins are inner join, left join, right join, and full join.
* An inner join returns rows when there is at least one row in both tables that matches the join condition.
* A left join returns all rows from the left table, even if there are no matches in the right table.
* A right join returns all rows from the right table, even if there are no matches in the left table.
* A full join returns all rows from both tables, even if there are no matches in either table.
