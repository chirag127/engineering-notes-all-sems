

#### Arrays in Core Java

* An array is a data structure that stores a collection of elements of the same type in a contiguous block of memory.
* Arrays in Java are objects that store multiple values of the same type.
* The elements of an array are accessed using an index, which is an integer value that indicates the position of the element in the array.
* Arrays are declared using the `int[]` syntax, where the `int` indicates the type of the elements stored in the array.
* The size of an array must be specified when it is declared, and it cannot be changed after the array is created.
* Arrays can be initialized using the `new` keyword, followed by the type of the array, the size of the array, and the values of the elements.
* Arrays can also be initialized using the `{}` syntax, where the values of the elements are specified in a comma-separated list.
* Arrays can be passed as arguments to methods, and can also be returned from methods.
* The `length` field of an array can be used to determine the size of the array.
* The `Arrays` class in the `java.util` package can be used to sort, search, and manipulate arrays.
