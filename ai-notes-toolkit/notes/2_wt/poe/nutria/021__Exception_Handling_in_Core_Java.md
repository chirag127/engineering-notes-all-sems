

#### Exception Handling in Core Java

1. Exceptions are conditions that disrupt the normal flow of a program.
2. Java provides a robust and object-oriented way to handle exceptions.
3. When an exception occurs, an object representing that exception is created and thrown in the method that caused the error.
4. The exception object contains information about the type of exception and the state of the program when the exception occurred.
5. Exceptions can be handled in Java using try-catch blocks.
6. A try block contains code that might throw an exception and a catch block contains code to handle the exception.
7. The catch block is executed when an exception is thrown from the try block.
8. Java also provides finally blocks, which are used to execute code regardless of whether an exception is thrown or not.
9. Java provides several built-in exceptions that correspond to different types of errors.
10. Java also allows developers to create their own custom exceptions.
