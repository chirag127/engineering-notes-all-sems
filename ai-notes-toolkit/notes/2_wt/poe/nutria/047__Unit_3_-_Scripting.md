
## Unit 3 - Scripting

* Scripting is a type of programming that is used to automate processes and create applications.
* Scripts are written in a scripting language, such as JavaScript, Python, Ruby, or Bash.
* Scripts can be used to automate tasks, such as creating webpages, running tests, or performing calculations.
* Scripts are usually written in a text editor and then executed in a command-line environment.
* Scripts can be used to create interactive user interfaces, such as web forms or graphical user interfaces.
* Scripts can be used to access and manipulate data, such as databases or web services.
* Scripts can be used to create custom applications, such as web applications or desktop applications.
