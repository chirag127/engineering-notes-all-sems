
#### Data Type in Core Java

- In Core Java, there are two types of data: primitive and reference. 
- Primitive data types are basic types of data that are built into the language and include boolean, char, byte, short, int, long, float, and double. 
- Reference data types are objects that are created by the programmer or by the Java API. 
- Primitive data types are stored directly in the locations allocated by the compiler and are allocated on the stack. 
- Reference data types are stored in the heap and are allocated through the new operator. 
- Primitive data types have a fixed size and they cannot be changed. 
- Reference data types can be changed, and they can also be null. 
- Primitive data types are passed by value, while reference data types are passed by reference. 
- Primitive data types are faster and more memory-efficient than reference data types. 
- Primitive data types are immutable, meaning they cannot be changed once they are created. 
- Reference data types are mutable, meaning they can be changed after they are created.
