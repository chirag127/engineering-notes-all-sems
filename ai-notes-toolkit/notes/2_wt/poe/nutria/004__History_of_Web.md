
### History of Web

1. The World Wide Web was invented in 1989 by Tim Berners-Lee. 
2. Berners-Lee developed the first web browser in 1990, which he called WorldWideWeb. 
3. In 1993, the first graphical web browser, Mosaic, was released. 
4. In 1994, the first search engine, WebCrawler, was released. 
5. In 1995, the first web-based email service, Hotmail, was released. 
6. In 1996, the first web-based chat service, ICQ, was released. 
7. In 1998, the first version of the web-based encyclopedia, Wikipedia, was launched. 
8. In 1999, the first version of the web-based auction site, eBay, was launched. 
9. In 2000, the first version of the web-based social networking site, Friendster, was launched. 
10. In 2003, the first version of the web-based blogging platform, Blogger, was launched. 
11. In 2004, the first version of the web-based video sharing site, YouTube, was launched. 
12. In 2006, the first version of the web-based microblogging platform, Twitter, was launched. 
13. In 2007, the first version of the web-based social networking site, Facebook, was launched. 
14. In 2009, the first version of the web-based mobile operating system, Android, was released. 
15. In 2010, the first version of the web-based mobile messaging app, WhatsApp, was released. 
16. In 2011, the first version of the web-based streaming service, Netflix, was released. 
17. In 2012, the first version of the web-based virtual assistant, Siri, was released. 
18. In 2013, the first version of the web-based ride-hailing service, Uber, was launched. 
19. In 2014, the first version of the web-based virtual reality platform, Oculus, was released. 
20. In 2015, the first version of the web-based augmented reality platform, Pokémon Go, was released. 
21. In 2016, the first version of the web-based voice assistant, Alexa, was released. 
22. In 2017, the first version of the web-based artificial intelligence platform, TensorFlow, was released. 
23. In 2018, the first version of the web-based blockchain platform, Ethereum, was released. 
24. In 2019, the first version of the web-based cloud gaming platform, Google Stadia, was released. 
25. In 2020, the first version of the web-based digital currency, Bitcoin, was released.
