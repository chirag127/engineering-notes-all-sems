
#### String handling in Core Java

1. Strings in Java are immutable, meaning that once created, their values cannot be changed.
2. Strings are objects in Java, and the String class is used to create and manipulate strings.
3. The String class provides methods for comparing, searching, and manipulating strings.
4. The + operator is used to concatenate strings.
5. The substring() method can be used to extract a substring from a string.
6. The split() method can be used to split a string into an array of substrings.
7. The trim() method can be used to remove leading and trailing white space from a string.
8. The replace() method can be used to replace a substring with another substring.
9. The toUpperCase() and toLowerCase() methods can be used to convert a string to uppercase or lowercase.
10. The StringBuilder class is used to create and manipulate strings more efficiently.
