

## Unit 4 - Enterprise Java Bean

* Enterprise Java Beans (EJB) is a server-side component architecture for Java-based applications.
* EJB components are written in Java and deployed to an application server, which provides a secure and managed runtime environment.
* The EJB architecture defines a set of services, such as transaction management and security, that can be used by EJB components.
* EJB components are divided into two categories: session beans and message-driven beans.
* Session beans are used to perform operations on behalf of a user, such as creating, updating, and deleting data.
* Message-driven beans are used to receive and process messages sent by other applications.
* EJB components can be deployed to an application server either as part of an application or as a standalone component.
* EJB components can be accessed remotely via the Java Remote Method Invocation (RMI) protocol.
