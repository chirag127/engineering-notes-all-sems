
#### Operator in Core Java

1. Operators in Java are special symbols that perform specific operations on one, two, or three operands, and then return a result.

2. Operators are used to manipulate variables and values in a program.

3. Java has a wide range of operators including arithmetic, logical, bitwise, assignment, and more.

4. Arithmetic operators are used to perform basic mathematical operations such as addition, subtraction, multiplication, and division.

5. Logical operators are used to compare two values and return either true or false.

6. Bitwise operators are used to perform operations on individual bits of a number.

7. Assignment operators are used to assign a value to a variable.

8. Other operators include increment, decrement, ternary, and type comparison operators.
