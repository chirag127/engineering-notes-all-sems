
### Document Type Definition in Web Page Designing

* Document Type Definition (DTD) is a set of rules used to describe a markup language document's structure. 
* It is used to define the structure of an XML or HTML document, by specifying the elements and attributes that can appear in the document, and the order in which they must appear.
* DTDs are written in a special language called Document Type Definition language, which is an extension of the Standard Generalized Markup Language (SGML). 
* DTDs are used to define the structure of a web page, such as the elements and attributes that are allowed in the page, the order in which they must appear, and the types of data that can be stored in the page. 
* DTDs are also used to validate the structure of a web page, ensuring that the page is well-formed and that all elements are correctly nested. 
* DTDs are also used to define the behavior of a web page, such as how it should respond to user input and how it should render content.
