
#### Variable in Core Java

* Variables are used to store data in a program. 
* In Java, a variable is a piece of memory that can contain a data value. 
* Variables are used to store data such as numbers, text, and other types of data. 
* Variables can be declared using the following syntax: 
  * `<data type> <variable name>;` 
* The data type specifies the type of data that a variable can hold. 
* The variable name is the name given to the variable. 
* Variables must be declared before they can be used. 
* Java has several primitive data types, including int, double, char, and boolean. 
* Variables of type int are used to store whole numbers, such as 5 or 10. 
* Variables of type double are used to store decimal numbers, such as 3.14 or 2.718. 
* Variables of type char are used to store single characters, such as 'a' or 'b'. 
* Variables of type boolean are used to store true or false values. 
* Variables can also be declared using a class type, such as String or Scanner. 
* Variables declared using a class type can store an object of that class type. 
* Variables must be assigned a value before they can be used. 
* Variables can be assigned a value using the following syntax: 
  * `<variable name> = <value>;` 
* Variables can be used in expressions and statements. 
* Variables can be reassigned a new value at any time.
