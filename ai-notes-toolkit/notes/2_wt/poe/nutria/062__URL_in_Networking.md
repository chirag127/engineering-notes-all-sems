
#### URL in Networking

* A URL (Uniform Resource Locator) is a unique identifier used to locate a resource on the internet. It is a combination of the protocol used to access the resource, the domain name, and the path to the specific resource. 
* URLs are used to access websites, download files, and access other resources on the internet.
* URLs are typically composed of three parts: the protocol, the domain name, and the path. The protocol is the type of connection used to access the resource, such as HTTP or FTP. The domain name is the address of the server on which the resource is located. The path is the specific location of the resource on the server.
* URLs are case-sensitive and must be entered exactly as they appear. 
* URLs can also contain parameters, which are additional pieces of information that are passed to the resource. Parameters are usually used to specify the format of the data being requested or the type of action that should be taken.
