# Protocols Governing Web

- Protocols are a set of rules or standards that enable communication between different devices or applications on a network.
- The web is a system of interconnected documents and resources that are accessed through the internet using web browsers and web servers.
- The web relies on various protocols to function properly and efficiently. Some of the most common protocols governing the web are:

  - **TCP/IP (Transmission Control Protocol/Internet Protocol)**: This is the fundamental protocol suite that enables data transmission across the internet and other networks. It consists of four layers: application, transport, internet, and network interface. TCP/IP provides reliable, ordered, and error-checked delivery of data packets between devices .
  - **HTTP (HyperText Transfer Protocol)**: This is the protocol that defines how web browsers and web servers communicate and exchange information. HTTP uses a request-response model, where a browser sends a request for a web resource (such as a webpage, an image, or a video) to a server, and the server responds with the requested resource or an error message. HTTP also supports methods such as GET, POST, PUT, and DELETE to perform different operations on web resources.
  - **DNS (Domain Name System)**: This is the protocol that translates domain names (such as www.example.com) into IP addresses (such as 192.168.1.1) that identify the location of web servers on the internet. DNS allows users to access web resources using human-readable names instead of numerical addresses. DNS also maintains a hierarchical structure of domain names and distributes the responsibility of name resolution among various servers.
  - **SMTP (Simple Mail Transfer Protocol)**: This is the protocol that enables the sending and receiving of email messages over the internet. SMTP uses a client-server model, where a mail client (such as an email application or a webmail service) connects to a mail server (such as Gmail or Outlook) and sends or receives email messages. SMTP also supports commands such as HELO, MAIL, RCPT, DATA, and QUIT to perform different functions related to email communication.
  - **FTP (File Transfer Protocol)**: This is the protocol that allows the transfer of files between devices or applications on a network. FTP uses a client-server model, where a FTP client (such as a file manager or a web browser) connects to a FTP server (such as a web server or a cloud storage service) and uploads or downloads files. FTP also supports commands such as USER, PASS, LIST, RETR, and STOR to perform different operations on files.
