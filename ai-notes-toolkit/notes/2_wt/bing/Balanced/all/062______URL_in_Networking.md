#### URL in Networking

- A URL (Uniform Resource Locator) is a string of characters that identifies a resource on the Internet and provides a way to locate it.
- A URL consists of several components, such as the scheme, the authority, the path, the query, and the fragment.
- The scheme specifies the protocol or method used to access the resource, such as http, https, ftp, mailto, etc.
- The authority identifies the host or server that provides the resource, and may include a username, a password, a port number, or a domain name.
- The path specifies the location of the resource on the host, and may consist of one or more segments separated by slashes (/).
- The query is an optional part that contains additional information or parameters for the resource, and is usually formatted as a series of key-value pairs separated by ampersands (&).
- The fragment is another optional part that identifies a specific part or section of the resource, and is usually preceded by a hash sign (#).
- A URL can be absolute or relative. An absolute URL contains all the components and starts with the scheme. A relative URL omits some components and is interpreted based on the context or the base URL.
- A URL can be encoded or decoded to handle special characters or spaces. Encoding replaces the characters with percent signs (%) followed by two hexadecimal digits. Decoding reverses the process and restores the original characters.
- A URL can be normalized or canonicalized to remove any ambiguity or redundancy. Normalization may involve converting the scheme and the host to lowercase, removing the default port number, removing dot-segments or trailing slashes from the path, sorting the query parameters, etc.
