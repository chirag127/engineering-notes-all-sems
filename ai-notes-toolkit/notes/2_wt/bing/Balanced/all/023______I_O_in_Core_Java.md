#### I/O in Core Java

- I/O stands for input/output, which refers to the process of reading and writing data from and to various sources and destinations, such as files, network, memory, console, etc.
- Java provides a rich set of classes and interfaces in the `java.io` package to handle different types of I/O operations.
- The main concepts and components of I/O in Java are:

  - Streams: A stream is an abstraction that represents a sequence of bytes that can be read from or written to a source or destination. Streams can be categorized into two types: input streams and output streams. Input streams are used to read data from a source, while output streams are used to write data to a destination. Streams can also be classified based on the type of data they handle: byte streams and character streams. Byte streams deal with raw bytes, while character streams deal with Unicode characters.
  - Readers and Writers: Readers and writers are subclasses of character streams that provide additional methods and features for handling text data. Readers are used to read characters from a source, while writers are used to write characters to a destination. Readers and writers can also be buffered, which means they use an internal buffer to store data and improve performance. Some examples of readers and writers are: `FileReader`, `FileWriter`, `BufferedReader`, `BufferedWriter`, `InputStreamReader`, `OutputStreamWriter`, etc.
  - Files and Directories: Files and directories are objects that represent the physical files and folders on the disk or other storage devices. Java provides the `File` class to manipulate files and directories, such as creating, deleting, renaming, checking permissions, etc. Java also provides the `Path` and `Files` classes in the `java.nio.file` package to perform more advanced operations on files and directories, such as copying, moving, linking, searching, etc.
  - Serialization: Serialization is the process of converting an object into a stream of bytes that can be stored or transmitted. Deserialization is the reverse process of converting a stream of bytes back into an object. Java provides the `Serializable` interface to mark an object as serializable, and the `ObjectOutputStream` and `ObjectInputStream` classes to perform serialization and deserialization. Serialization can be used to persist objects, send objects over the network, or clone objects.
  - Console: Console is a class that represents the standard input and output streams of the Java application. It can be used to read and write text data from and to the console. Console can be obtained by calling the `System.console()` method, which returns `null` if the application is not running in a console environment. Console provides methods such as `readLine()`, `readPassword()`, `format()`, `printf()`, etc. to perform various I/O operations on the console.
