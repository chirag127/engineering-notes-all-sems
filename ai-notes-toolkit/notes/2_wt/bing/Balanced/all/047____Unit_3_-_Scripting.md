## Unit 3 - Scripting

- A scripting language is a programming language that is used to manipulate, customize, and automate the facilities of an existing system.
- A scripting language is interpreted at runtime rather than compiled, which means it is translated into machine code when the code is run, rather than beforehand .
- Scripting languages are often used for short scripts over full computer programs, such as web development, data analysis, system administration, and automation .
- Some examples of scripting languages are JavaScript, Python, Ruby, Perl, Bash, and Lua .

### Advantages of scripting languages

- Scripting languages are easy to learn and use, as they have a high-level syntax and abstract away low-level details.
- Scripting languages are portable, as they can run on different platforms and environments without requiring recompilation.
- Scripting languages are flexible, as they can interact with other programming languages and systems through various interfaces and libraries.
- Scripting languages are dynamic, as they can support features such as dynamic typing, reflection, and metaprogramming.

### Disadvantages of scripting languages

- Scripting languages are slower than compiled languages, as they incur an overhead of interpretation and runtime checks.
- Scripting languages are less secure than compiled languages, as they expose the source code and may allow malicious injection or modification.
- Scripting languages are less reliable than compiled languages, as they may have more errors and bugs that are not detected until runtime.

### Examples of scripting languages

- JavaScript is a scripting language that is widely used for web development, especially for creating dynamic and interactive web pages. It can run on both the client-side and the server-side, and it can interact with HTML, CSS, and other web technologies.
- Python is a scripting language that is popular for data analysis, machine learning, web development, and general-purpose programming. It has a simple and expressive syntax, a large standard library, and many third-party modules and frameworks.
- Ruby is a scripting language that is known for its elegance and productivity. It supports multiple programming paradigms, such as object-oriented, functional, and metaprogramming. It is mainly used for web development, especially with the Ruby on Rails framework.

### Mnemonics and learning tricks for scripting languages

- A mnemonic to remember some of the common scripting languages is **J**ust **P**lay **R**eally **P**retty **B**eautiful **L**ullabies, which stands for JavaScript, Python, Ruby, Perl, Bash, and Lua.
- A learning trick to understand the difference between scripting and compiled languages is to think of them as cooking recipes. A scripting language is like a recipe that you follow step by step as you cook, while a compiled language is like a recipe that you prepare beforehand and then put in the oven.
- A learning trick to practice scripting languages is to use online tools and platforms, such as CodePen, Repl.it, Codecademy, and Coursera, that allow you to write and run scripts in various languages and environments without installing anything on your computer.
