### List in Web Page Designing

- A list is a collection of items that are related in some way and displayed in a specific order.
- Lists are useful for organizing and presenting information in a clear and concise way.
- There are two types of lists in web page designing: ordered lists and unordered lists.
- Ordered lists are numbered lists that show the sequence or priority of the items. They are created using the `<ol>` tag and each item is enclosed in a `<li>` tag.
- Unordered lists are bulleted lists that show the grouping or categorization of the items. They are created using the `<ul>` tag and each item is enclosed in a `<li>` tag.
- Lists can be nested inside other lists to create sublists. To do this, a new list tag is placed inside a `<li>` tag of the parent list.
- Lists can also be styled using CSS properties such as list-style-type, list-style-image, list-style-position, margin, padding, etc.
- Lists are commonly used for navigation menus, table of contents, glossaries, FAQs, etc.
