#### Introduction to AWT in Core Java

- AWT stands for Abstract Window Toolkit. It is a package of classes and interfaces that provides the basic functionality for creating graphical user interfaces (GUIs) in Java.
- AWT is part of the Java Foundation Classes (JFC), which also includes Swing, Java 2D, and Accessibility.
- AWT provides the following components for building GUIs:
  - Containers: These are components that can hold other components, such as windows, frames, panels, and dialogs.
  - Components: These are the basic elements of a GUI, such as buttons, labels, text fields, checkboxes, radio buttons, lists, menus, and scrollbars.
  - Layout Managers: These are objects that control the size and position of components within a container, such as FlowLayout, BorderLayout, GridLayout, and GridBagLayout.
  - Event Handling: This is the mechanism that allows components to respond to user actions, such as mouse clicks, keyboard inputs, and window events.
  - Graphics: This is the class that provides methods for drawing shapes, images, and text on a component or an off-screen image.
  - Fonts and Colors: These are classes that represent the appearance of text and graphics on a component or an image.
  - Images and Media: These are classes that support loading, displaying, and manipulating images, sounds, and videos in a GUI.
- AWT is platform-dependent, meaning that it relies on the native GUI toolkit of the operating system to render the components. This makes AWT components look and behave differently on different platforms, but also ensures compatibility and performance.
