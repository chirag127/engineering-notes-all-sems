#### URL in Networking

- A URL (Uniform Resource Locator) is a string of characters that identifies a resource on the Internet and how to access it.
- A URL consists of several components, such as the scheme, the authority, the path, the query, and the fragment.
- The scheme specifies the protocol used to communicate with the resource, such as http, https, ftp, etc.
- The authority identifies the host name and the port number of the server that hosts the resource, such as www.example.com:80.
- The path specifies the location of the resource on the server, such as /index.html or /images/logo.png.
- The query contains optional parameters that are sent to the server along with the request for the resource, such as ?q=keyword or ?page=2.
- The fragment identifies a specific part of the resource, such as #section1 or #top. The fragment is not sent to the server, but is processed by the browser.
- A URL can be absolute or relative. An absolute URL contains all the components, while a relative URL omits some of them and is resolved based on the context of the current document or base URL.
- A URL can be encoded or decoded to handle special characters that are not allowed or have special meanings in the URL syntax, such as spaces, slashes, or colons. The encoding and decoding process uses the percent sign (%) followed by two hexadecimal digits to represent the ASCII code of the character, such as %20 for space or %3A for colon.
- A URL can be normalized or canonicalized to remove any ambiguity or redundancy in the URL components, such as converting uppercase letters to lowercase, removing default port numbers, adding or removing trailing slashes, etc. The normalized or canonicalized URL is equivalent to the original URL in terms of identifying the same resource, but is more consistent and easier to compare.
