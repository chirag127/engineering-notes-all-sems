### Types of beans in Enterprise Java Bean

Enterprise Java Bean (EJB) is a server-side software component that encapsulates the business logic of an application. It is a specification for developing a distributed business application on the Java platform. There are three types of beans in EJB:

- **Session Bean**: A session bean contains business logic that can be invoked by local, remote or web service client. There are two types of session beans: stateful and stateless. A stateful session bean maintains the conversational state with the client across multiple method calls. A stateless session bean does not maintain any state and can be reused by different clients. A singleton session bean is a special type of stateless session bean that is instantiated only once per application and shared by all clients.
- **Entity Bean**: An entity bean represents a persistent object that can be stored in a database. It provides an object-oriented view of the data and encapsulates the access to the data source. There are two types of entity beans: container-managed persistence (CMP) and bean-managed persistence (BMP). A CMP entity bean delegates the persistence logic to the container, which automatically generates the database access code. A BMP entity bean implements the persistence logic by itself, using JDBC or other APIs.
- **Message-Driven Bean**: A message-driven bean is a type of session bean that acts as a message consumer and asynchronously processes messages from a message queue or topic. It implements the Jakarta Messaging API and can receive messages from any Java Message Service (JMS) provider. A message-driven bean is stateless and does not interact directly with the client.
