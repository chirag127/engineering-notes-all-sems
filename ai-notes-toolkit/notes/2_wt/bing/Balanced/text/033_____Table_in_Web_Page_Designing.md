### Table in Web Page Designing

- A table is a way of displaying and describing data in the form of rows and columns.
- A table can be used for various purposes, such as presenting tabular data, creating page layouts, or adding visual effects.
- A table is created using the `<table>` tag in HTML, which contains one or more `<tr>` tags for table rows, and one or more `<td>` tags for table cells.
- A table can also have a `<thead>` tag for table header, a `<tbody>` tag for table body, and a `<tfoot>` tag for table footer.
- A table can also have a `<caption>` tag for table caption, a `<colgroup>` tag for table column group, and a `<col>` tag for table column.
- A table can be styled using CSS properties, such as `border`, `padding`, `margin`, `background`, `color`, `font`, `text-align`, `vertical-align`, etc.
- A table can also use CSS pseudo-classes, such as `:hover`, `:active`, `:first-child`, `:last-child`, etc., to create dynamic effects.
- A table can also use CSS pseudo-elements, such as `::before`, `::after`, `::first-line`, `::first-letter`, etc., to add content or decoration.
- A table can also use CSS selectors, such as `#id`, `.class`, `[attribute]`, `:nth-child()`, `:not()`, etc., to target specific elements or groups of elements.
- A table can also use CSS media queries, such as `@media`, to adapt to different screen sizes or devices.
