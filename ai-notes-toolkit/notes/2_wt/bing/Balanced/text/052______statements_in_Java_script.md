#### Statements in JavaScript
- A statement is a syntactic unit of code that expresses an action to be carried out by the JavaScript interpreter.
- A statement can be simple or complex, depending on the number of sub-statements it contains.
- A simple statement is a statement that ends with a semicolon (;), such as a variable declaration, an assignment, or a function call.
- A complex statement is a statement that contains other statements within curly braces ({ }), such as an if statement, a for loop, or a function definition.
- A statement can also be labeled with an identifier followed by a colon (:), such as a break statement, a continue statement, or a switch statement.
- A statement can be terminated by a semicolon (;), a newline character (\n), or the end of the script file.
- A statement can be grouped with other statements into a block, which is a sequence of statements enclosed by curly braces ({ }).
- A block can be used as a single statement in a complex statement, such as an if statement or a for loop.
- A block can also be used as a standalone statement, such as a script block or a function body.
