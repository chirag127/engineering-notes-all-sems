### Introduction to client-server computing

- Client-server computing is a software architecture model that divides an application into two parts: client systems and server systems .
- A client system is a computing device or a program that requests a service or a resource from a server system .
- A server system is a computing device or a program that provides a service or a resource to one or more client systems .
- Client systems and server systems can communicate over a computer network or on the same computer .
- Client-server computing enables the distribution of tasks or workloads among different computers, which can improve the performance, scalability, security, and reliability of the application .
- Examples of client-server applications are web browsers and web servers, email clients and email servers, online games, and database systems .
