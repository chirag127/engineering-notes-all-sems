## Unit 1 - Introduction to Web Technology

- Web technology is the use of various tools and protocols to create, store, transmit, and display information on the World Wide Web (WWW).
- The WWW is a global network of interconnected documents, called web pages, that are accessed through web browsers and linked by hyperlinks.
- Web pages are composed of different elements, such as text, images, audio, video, and interactive features, that are formatted using a markup language, such as HTML (Hypertext Markup Language).
- Web pages can also contain scripts, such as JavaScript, that are executed by the browser to provide dynamic functionality and interactivity.
- Web pages are hosted on web servers, which are computers that store and deliver web pages to web browsers upon request.
- Web servers use a protocol, such as HTTP (Hypertext Transfer Protocol), to communicate with web browsers and exchange information.
- Web browsers are software applications that allow users to view and interact with web pages. Web browsers can also support other web technologies, such as CSS (Cascading Style Sheets), XML (Extensible Markup Language), and AJAX (Asynchronous JavaScript and XML).
- Web technology enables various applications and services on the web, such as e-commerce, social media, online education, gaming, and cloud computing.
