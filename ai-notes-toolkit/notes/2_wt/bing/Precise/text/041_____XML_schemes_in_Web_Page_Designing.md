### XML schemes in Web Page Designing

1. XML (eXtensible Markup Language) is a markup language used to store and transport data.
2. XML is a popular format for exchanging data between applications and organizations due to its ability to represent complex data structures in a human-readable format.
3. In web page designing, XML can be used to separate data from presentation. This allows for the creation of dynamic web pages where the content can be updated independently of the page layout.
4. XML data can be transformed into HTML using XSLT (eXtensible Stylesheet Language Transformations), allowing for the creation of web pages that display XML data in a user-friendly format.
5. XML schemas are used to define the structure and content of XML documents. They provide a way to validate the data in an XML document, ensuring that it conforms to a specific format.
6. Using XML schemas in web page designing can help to ensure that the data being displayed on a web page is accurate and consistent.
7. There are several tools available for creating and validating XML schemas, including the W3C's XML Schema Definition (XSD) language.
8. Overall, the use of XML and XML schemas in web page designing can help to create dynamic, data-driven web pages that are easy to update and maintain.
