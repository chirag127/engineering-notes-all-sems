#### Introduction to AWT in Core Java

- AWT stands for Abstract Window Toolkit.
- It is a platform-dependent API for creating Graphical User Interface (GUI) for Java programs.
- AWT was introduced in JDK 1.0.
- It provides a rich set of user interface components such as buttons, text fields, labels, checkboxes, etc.
- AWT also provides layout managers to arrange these components in a container.
- AWT is not commonly used today as it has been largely superseded by the Swing toolkit.
- However, it is still important to have a basic understanding of AWT as it forms the foundation for understanding GUI programming in Java.
