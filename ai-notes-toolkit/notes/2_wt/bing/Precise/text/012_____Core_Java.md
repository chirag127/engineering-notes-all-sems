### Core Java

Core Java refers to the fundamental concepts and features of the Java programming language. It is the foundation upon which all Java applications are built. Some of the key features of Core Java include:

1. Object-Oriented: Java is an object-oriented language, meaning that it is based on the concept of objects, which contain data and methods that operate on that data.

2. Platform-Independent: Java is platform-independent, meaning that code written in Java can run on any platform that has a Java Virtual Machine (JVM) installed.

3. Robust: Java is a robust language, meaning that it has strong memory management and error-handling capabilities.

4. Secure: Java is designed to be secure, with features such as bytecode verification and sandboxing to protect against malicious code.

5. Simple: Java is designed to be easy to learn and use, with a syntax that is similar to other popular programming languages such as C and C++.

6. Multithreaded: Java supports multithreading, meaning that it can execute multiple threads of execution simultaneously, allowing for the development of highly concurrent applications.

These are just a few of the key features of Core Java. It is a powerful and versatile language that is widely used for developing a wide range of applications, from web and mobile applications to enterprise and scientific software.
