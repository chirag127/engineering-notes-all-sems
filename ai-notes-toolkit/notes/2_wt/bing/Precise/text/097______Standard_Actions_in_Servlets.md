#### Standard Actions in Servlets

Standard actions are predefined tags that are used to perform common tasks in JSP pages. These actions are defined by the JSP specification and are available to all JSP pages. Some of the standard actions available in JSP are:

1. `<jsp:include>`: This action is used to include the content of another resource, such as a JSP page or an HTML file, in the current JSP page.
2. `<jsp:forward>`: This action is used to forward the request to another resource, such as a JSP page or a servlet.
3. `<jsp:useBean>`: This action is used to create or locate a JavaBean component and make it available to the JSP page.
4. `<jsp:setProperty>`: This action is used to set the properties of a JavaBean component.
5. `<jsp:getProperty>`: This action is used to get the properties of a JavaBean component.
6. `<jsp:plugin>`: This action is used to include a Java applet or a JavaBeans component in the JSP page.
7. `<jsp:param>`: This action is used to pass parameters to the included or forwarded resource.

These standard actions provide a convenient way to perform common tasks in JSP pages and can help to simplify the development of web applications. They are easy to use and can be combined with other JSP elements, such as expressions and scriptlets, to create dynamic and interactive web pages.
