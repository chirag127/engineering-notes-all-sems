#### Data type in Core Java
In Core Java, data types are used to define the type of data that can be stored in a variable. There are two types of data types in Java: primitive and non-primitive.

1. **Primitive data types**: These are the most basic data types in Java and are used to store simple values. There are eight primitive data types in Java: `byte`, `short`, `int`, `long`, `float`, `double`, `char`, and `boolean`.
    - `byte`: used to store integer values in the range of -128 to 127.
    - `short`: used to store integer values in the range of -32,768 to 32,767.
    - `int`: used to store integer values in the range of -2,147,483,648 to 2,147,483,647.
    - `long`: used to store integer values in the range of -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807.
    - `float`: used to store floating-point numbers with single precision.
    - `double`: used to store floating-point numbers with double precision.
    - `char`: used to store a single character.
    - `boolean`: used to store a value of either `true` or `false`.

2. **Non-primitive data types**: These are also known as reference data types and are used to store objects. Non-primitive data types include classes, interfaces, and arrays. Unlike primitive data types, non-primitive data types do not have a fixed size and can store complex data structures.

It is important to choose the appropriate data type for a variable based on the data it will store to ensure efficient use of memory and to avoid errors.
