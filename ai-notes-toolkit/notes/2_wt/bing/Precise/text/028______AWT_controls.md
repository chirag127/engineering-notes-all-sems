#### AWT controls

- AWT (Abstract Window Toolkit) is a set of Java APIs used to develop GUI (Graphical User Interface) components.
- AWT controls are also known as components or widgets.
- AWT controls are platform-dependent, meaning they are rendered differently on different operating systems.
- Some common AWT controls include buttons, labels, text fields, checkboxes, and lists.
- AWT controls can be added to containers such as panels or frames.
- AWT controls can be customized by setting their properties such as size, color, and font.
- AWT controls can respond to user events such as mouse clicks or key presses through the use of event listeners.
- AWT controls are part of the `java.awt` package. To use them, you must import this package in your code.
