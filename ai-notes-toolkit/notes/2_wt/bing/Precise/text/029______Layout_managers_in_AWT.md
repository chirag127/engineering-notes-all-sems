#### Layout managers in AWT

- AWT (Abstract Window Toolkit) is a Java API that provides a graphical user interface (GUI) for Java programs.
- Layout managers are used to arrange components in a container.
- AWT provides several layout managers, including BorderLayout, FlowLayout, GridLayout, GridBagLayout, and CardLayout.
- Each layout manager has its own rules for arranging components.
- BorderLayout divides the container into five regions: North, South, East, West, and Center.
- FlowLayout arranges components in a row, wrapping to the next row if there is not enough space.
- GridLayout arranges components in a grid of rows and columns.
- GridBagLayout is a flexible layout manager that allows components to be arranged in a grid with varying row and column sizes.
- CardLayout allows multiple components to occupy the same space, with only one component visible at a time.
- The choice of layout manager depends on the desired layout of the components in the container.
