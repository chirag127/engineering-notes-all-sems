#### Variable in Core Java
A variable in Java is a container that holds a value. It is a named memory location that can store a value of a specific data type. Here are some key points to remember about variables in Core Java:

1. Variables have a specific data type, which determines the kind of values it can hold.
2. The value of a variable can be changed during the execution of a program.
3. Variables must be declared before they can be used in a program.
4. The name of a variable must be unique within its scope.
5. Variable names are case-sensitive in Java.
6. There are different types of variables in Java, including instance variables, class variables, and local variables.
7. The value of a variable can be assigned using the assignment operator (=).
8. Variables can be initialized at the time of declaration or later in the program.
