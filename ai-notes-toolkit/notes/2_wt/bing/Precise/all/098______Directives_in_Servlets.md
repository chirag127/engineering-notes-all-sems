#### Directives in Servlets

Directives are instructions that are processed by the JSP engine when the page is compiled into a servlet. There are three types of directives in JSP: page, include, and taglib.

1. **Page directive:** The page directive is used to define page-specific attributes such as the scripting language, error page, and buffer size. The syntax for the page directive is as follows:
```
<%@ page attribute="value" %>
```
Some common attributes of the page directive are:
- `language`: Specifies the scripting language used in the JSP page. The default value is `java`.
- `import`: Specifies the packages and classes to be imported.
- `contentType`: Specifies the MIME type of the response generated by the JSP page.
- `isErrorPage`: Specifies whether the current JSP page is an error page or not.
- `errorPage`: Specifies the location of the error page to be displayed in case of an exception.

2. **Include directive:** The include directive is used to include the content of another file in the current JSP page. The syntax for the include directive is as follows:
```
<%@ include file="filename" %>
```
The included file can be a static file or another JSP page. The content of the included file is inserted into the JSP page at the location of the include directive during the translation phase.

3. **Taglib directive:** The taglib directive is used to specify the location of a tag library containing custom tags. The syntax for the taglib directive is as follows:
```
<%@ taglib uri="uri" prefix="prefix" %>
```
The `uri` attribute specifies the location of the tag library, and the `prefix` attribute specifies the prefix used to reference the custom tags in the JSP page.

These are the three types of directives in JSP. They provide a way to specify page-specific attributes, include content from other files, and use custom tags in JSP pages.
