## Unit 1 - Introduction to Web Technology

1. **Web Technology** refers to the tools, techniques, and standards used to develop and deliver content over the internet.
2. The **World Wide Web** (WWW) is a global information space where documents and other web resources are identified by Uniform Resource Locators (URLs), interlinked by hypertext links, and can be accessed via the internet.
3. The **internet** is a global system of interconnected computer networks that use the standard Internet Protocol Suite (TCP/IP) to link devices worldwide.
4. **Web browsers** are software applications that allow users to access, view, and interact with web content.
5. **Web servers** are computer programs that store, process, and deliver web pages to clients.
6. **HTML** (Hypertext Markup Language) is the standard markup language for creating web pages and other information that can be displayed in a web browser.
7. **CSS** (Cascading Style Sheets) is a style sheet language used for describing the look and formatting of a document written in a markup language.
8. **JavaScript** is a high-level, interpreted programming language that is commonly used to create interactive effects within web browsers.
9. **Web development** is the work involved in developing a website for the internet or an intranet.
10. **Web design** is the process of planning, conceptualizing, and arranging content intended for the internet.
