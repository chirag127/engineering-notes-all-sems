#### Introduction to AWT in Core Java

- AWT stands for **Abstract Window Toolkit**, which is an API (Application Programming Interface) for creating **Graphical User Interface (GUI)** or window-based applications in Java    .
- AWT provides various components like button, label, checkbox, etc. used as objects inside a Java program. AWT also provides classes for **layout management**, **event handling**, **graphics**, **images**, **fonts**, and **colors**  .
- AWT components are **platform-dependent** i.e. components are displayed according to the view of the operating system (OS) . AWT uses the **native** GUI of the underlying OS, which means that the look and feel of the AWT components may vary from one platform to another  .
- AWT is **heavyweight** i.e. its components are using the resources of the underlying OS. AWT components may **overlap** or **interfere** with other GUI elements of the OS, such as the taskbar or the desktop.
- AWT was Java’s first GUI framework, which was introduced in Java 1.0. It is the **foundation** of other GUI frameworks like Swing and JavaFX, which are built on top of AWT .
- AWT is **simple** and **easy** to use, but it has **limited** features and **poor** portability compared to Swing and JavaFX . AWT is mainly used for **educational** purposes or for creating **basic** GUI applications .
