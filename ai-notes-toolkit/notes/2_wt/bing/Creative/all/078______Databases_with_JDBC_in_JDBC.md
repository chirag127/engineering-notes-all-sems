#### Databases with JDBC in Java

- JDBC stands for Java Database Connectivity, which is a Java API that enables Java programs to interact with databases.
- JDBC defines a common interface for Java programs to use when interacting with databases, regardless of the underlying database management system (DBMS).
- JDBC allows Java programs to execute SQL queries, update data, and retrieve results from databases.
- JDBC consists of two main components: the JDBC API and the JDBC driver.
- The JDBC API provides a set of classes and interfaces that define the methods and constants for connecting to databases, executing statements, processing results, and handling errors.
- The JDBC driver is a software component that implements the JDBC API for a specific DBMS. The driver translates the JDBC calls into the native protocol of the DBMS and communicates with the database server.
- There are four types of JDBC drivers, each with different advantages and disadvantages:
  - Type-1 driver or JDBC-ODBC bridge driver: This driver uses the ODBC (Open Database Connectivity) driver to connect to the database. It is platform-dependent and requires an ODBC driver to be installed on the client machine.
  - Type-2 driver or Native-API driver: This driver uses the native libraries of the DBMS to connect to the database. It is also platform-dependent and requires the native libraries to be available on the client machine.
  - Type-3 driver or Network Protocol driver: This driver uses a middleware server to connect to the database. The driver communicates with the middleware server using a network protocol, and the middleware server communicates with the database using the native protocol. This driver is platform-independent but requires the middleware server to be installed and configured.
  - Type-4 driver or Thin driver: This driver uses the native protocol of the DBMS to connect to the database directly. It is platform-independent and does not require any additional software on the client machine. It is the most preferred driver for Java applications.
- To use JDBC in a Java application, the following steps are required:
  - Step 1: Download and install the JDBC driver for the DBMS that you want to use. You can find the drivers from the official websites of the DBMS vendors or from third-party sources.
  - Step 2: Import the JDBC classes and interfaces into your Java application. The most common classes and interfaces are java.sql.Connection, java.sql.Statement, java.sql.ResultSet, java.sql.PreparedStatement, java.sql.CallableStatement, and java.sql.DriverManager.
  - Step 3: Add the JDBC driver to your classpath. The classpath is a list of directories and files that the Java compiler and runtime use to locate the classes and resources needed by the application. You can set the classpath using the -cp or -classpath option of the java command, or by using an environment variable.
  - Step 4: Establish a connection to the database using the DriverManager class. The DriverManager class manages the loading and registration of the JDBC drivers. You can use the getConnection method of the DriverManager class to obtain a Connection object, which represents a logical connection to the database. You need to provide the URL, username, and password of the database as parameters to the getConnection method.
  - Step 5: Create a Statement object using the createStatement method of the Connection object. A Statement object represents a SQL statement that can be executed against the database. You can use the executeQuery method of the Statement object to execute a SQL query and obtain a ResultSet object, which represents the result set of the query. You can use the executeUpdate method of the Statement object to execute a SQL update and obtain an int value, which represents the number of rows affected by the update.
  - Step 6: Process the ResultSet object using the methods and properties of the ResultSet interface. The ResultSet interface provides methods to move the cursor to different rows of the result set, and to retrieve the values of the columns of the current row. You can use the next method of the ResultSet object to move the cursor to the next row, and the getXXX methods of the ResultSet object to get the values of the columns, where XXX is the data type of the column (such as getInt, getString, getDouble, etc.).
