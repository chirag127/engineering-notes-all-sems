#### Event handling in Core Java

- Event handling is the mechanism that controls the behavior of an application when the user performs certain actions, such as clicking a button, typing a character, moving the mouse, etc.
- Event handling involves three components: event sources, event listeners, and event objects.
- Event sources are the components that generate events, such as buttons, text fields, menus, etc. Event sources have methods to register and unregister event listeners.
- Event listeners are the components that handle events, such as classes, objects, methods, etc. Event listeners implement interfaces that define the methods to handle specific types of events.
- Event objects are the instances of classes that encapsulate the information about an event, such as the source, the type, the time, the location, etc. Event objects are passed as parameters to the event listener methods.
- Event handling in Core Java follows the delegation model, which means that the event source delegates the responsibility of handling an event to a separate event listener.
- The delegation model has several advantages, such as:
  - It separates the logic of event handling from the logic of event generation, making the code more modular and reusable.
  - It allows multiple event listeners to handle the same event, enabling collaboration and customization.
  - It avoids the need for event sources to inherit from a common superclass or implement a common interface, allowing more flexibility and diversity.
- The delegation model has several steps, such as:
  1. Define the event listener interface that specifies the methods to handle the events of interest.
  2. Implement the event listener interface by providing the logic for each event handler method.
  3. Register the event listener object with the event source using the appropriate method.
  4. Override the event handler methods in the event listener object to handle the events generated by the event source.
- An example of event handling in Core Java is:

```java
// Define the event listener interface
interface MyListener extends ActionListener {
  // Specify the event handler method
  void actionPerformed(ActionEvent e);
}

// Implement the event listener interface
class MyListenerImpl implements MyListener {
  // Provide the logic for the event handler method
  public void actionPerformed(ActionEvent e) {
    // Get the source of the event
    Object source = e.getSource();
    // Perform some action based on the source
    if (source instanceof JButton) {
      // Cast the source to a JButton
      JButton button = (JButton) source;
      // Get the text of the button
      String text = button.getText();
      // Print the text to the console
      System.out.println(text);
    }
  }
}

// Create the event source
JButton button = new JButton("Click me");

// Create the event listener object
MyListenerImpl listener = new MyListenerImpl();

// Register the event listener object with the event source
button.addActionListener(listener);

// Add the button to a frame and display it
JFrame frame = new JFrame("Event handling example");
frame.add(button);
frame.pack();
frame.setVisible(true);
```
- A mnemonic to remember the steps of event handling in Core Java is:

  - **DIRE** - Define, Implement, Register, and Override the event listener interface.
