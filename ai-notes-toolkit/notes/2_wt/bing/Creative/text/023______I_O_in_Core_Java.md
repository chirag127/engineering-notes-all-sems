#### I/O in Core Java

- I/O stands for input/output, which refers to the process of reading and writing data from and to various sources and destinations, such as files, network, console, etc.
- Core Java provides a rich set of classes and interfaces in the `java.io` package to handle different types of I/O operations, such as byte streams, character streams, buffered streams, data streams, object streams, file streams, etc.
- Byte streams are the lowest level of I/O abstraction, which operate on single bytes of data. They are useful for reading and writing binary data, such as images, audio, video, etc. The abstract classes `InputStream` and `OutputStream` are the base classes for all byte stream classes.
- Character streams are higher level of I/O abstraction, which operate on characters of data. They are useful for reading and writing text data, such as documents, source code, etc. The abstract classes `Reader` and `Writer` are the base classes for all character stream classes.
- Buffered streams are wrappers around other streams, which provide buffering functionality to improve the performance of I/O operations. They store data in an internal buffer and reduce the number of system calls to the underlying source or destination. The classes `BufferedInputStream`, `BufferedOutputStream`, `BufferedReader`, and `BufferedWriter` are examples of buffered streams.
- Data streams are wrappers around other streams, which provide methods to read and write primitive data types and strings in a platform-independent way. They are useful for storing and transferring binary data, such as numbers, booleans, etc. The classes `DataInputStream` and `DataOutputStream` are examples of data streams.
- Object streams are wrappers around other streams, which provide methods to read and write objects in a serialized form. They are useful for storing and transferring complex data structures, such as arrays, collections, etc. The classes `ObjectInputStream` and `ObjectOutputStream` are examples of object streams.
- File streams are streams that read and write data from and to files on the disk. They are subclasses of byte streams or character streams, depending on the type of data. The classes `FileInputStream`, `FileOutputStream`, `FileReader`, and `FileWriter` are examples of file streams.
