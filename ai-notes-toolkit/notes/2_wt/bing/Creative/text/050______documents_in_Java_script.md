#### Documents in JavaScript

- A document in JavaScript is an object that represents a web page loaded in a browser and provides access to its content, such as HTML elements, images, scripts, etc. 
- A document is an instance of the Document interface, which is part of the Document Object Model (DOM), a programming interface that describes the structure and behavior of documents. 
- The document object has many properties and methods that can be used to manipulate the web page, such as document.title, document.body, document.getElementById(), document.createElement(), document.write(), etc. 
- The document object is a global object that can be accessed from any JavaScript code within the web page, using the keyword document or the window.document property. 
- The document object can also be used to create new documents, such as XML or HTML documents, using the document.implementation.createDocument() or document.implementation.createHTMLDocument() methods.
