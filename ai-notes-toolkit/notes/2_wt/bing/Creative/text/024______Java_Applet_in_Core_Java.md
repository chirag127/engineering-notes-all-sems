#### Java Applet in Core Java

- An applet is a small Java program that runs inside a web browser or an applet viewer.
- An applet can perform various tasks such as animation, calculation, games, etc.
- An applet has a limited access to the resources of the host system, such as files, network, etc. for security reasons.
- An applet follows a life cycle that consists of four stages: initialization, start, stop, and destroy.
- An applet can be embedded in an HTML page using the `<applet>` tag or the `<object>` tag.
- An applet can communicate with other applets running on the same page or different pages using the `AppletContext` class.
- An applet can also communicate with the web server using the `URL` and `URLConnection` classes.
- An applet can receive parameters from the HTML page using the `<param>` tag and the `getParameter()` method.
- An applet can override the methods of the `Applet` class or the `JApplet` class to perform various tasks.
- An applet can use the methods of the `Graphics` class or the `Graphics2D` class to draw graphics on the applet window.
- An applet can handle user events such as mouse clicks, keyboard inputs, etc. using the `Event` class or the `AWTEvent` class and the `EventListener` interface or the `AWTEventListener` interface.
- An applet can use the methods of the `AudioClip` interface or the `Clip` interface to play sound files on the applet window.
- An applet can use the methods of the `Image` class or the `BufferedImage` class to load and display images on the applet window.
- An applet can use the methods of the `Thread` class or the `Runnable` interface to create and run multiple threads on the applet window.
- An applet can use the methods of the `AppletStub` interface or the `AppletContext` interface to get information about the applet environment.
