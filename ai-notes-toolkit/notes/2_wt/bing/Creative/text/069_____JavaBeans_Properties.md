### JavaBeans Properties

- JavaBeans properties are attributes of a Java class that follow a naming convention and can be accessed by methods called getters and setters.
- A property can be of any Java type, such as int, String, boolean, or an object of another class.
- A property can be read-only, write-only, or read-write, depending on the availability of the getter and setter methods.
- A property can be bound, meaning that it notifies other objects when its value changes, or constrained, meaning that it allows other objects to veto its value changes.
- A property can be indexed, meaning that it represents an array or a collection of values, and can be accessed by an index parameter in the getter and setter methods.
