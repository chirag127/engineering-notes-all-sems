# Social Media Sentiment Analysis

Social Media Sentiment Analysis is the process of analyzing public opinions and emotions towards a particular brand or product by using social media data. This can be achieved by using various libraries such as Tweepy, TextBlob, and SentimentIntensityAnalyzer.

1. **Tweepy**: This library is used to access the Twitter API and extract tweets related to the brand or product being analyzed.
2. **TextBlob**: This library is used to perform natural language processing tasks such as sentiment analysis on the extracted tweets.
3. **SentimentIntensityAnalyzer**: This is a tool from the nltk library that can be used to calculate the sentiment scores of the tweets.

By using these libraries, one can extract tweets related to the brand or product, perform sentiment analysis on the tweets, and calculate the overall sentiment score. This score can then be used to gauge public opinion and emotions towards the brand or product.
