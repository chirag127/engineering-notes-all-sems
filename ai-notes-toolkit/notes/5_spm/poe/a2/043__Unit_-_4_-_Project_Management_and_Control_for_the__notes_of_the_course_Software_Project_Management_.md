## Unit - 4 - Project Management and Control

1. Project Management Process
- Project initiation: Identifying and defining the project
- Project planning: Breaking down the project into manageable components and planning the work
- Project execution: Carrying out the project plan
- Monitoring and control: Monitoring project progress and taking corrective actions
- Project closure: Formal acceptance of the project and disbanding the team

2. Project Planning
- Work breakdown structure: Breaking down the project into a hierarchy of deliverables
- Project schedule: Estimating task durations and sequencing tasks
- Resource planning: Estimating resource requirements and availability
- Cost estimation: Estimating costs of project tasks and the overall project
- Risk management: Identifying and mitigating potential risks that can impact the project

3. Project Monitoring and Control
- Tracking project progress: Comparing actual progress to the project plan and schedule
- Managing changes: Processing change requests and managing changes to project scope, schedule, and costs
- Taking corrective actions: Taking necessary actions to address issues, risks, and changes to bring the project back on track
- Final acceptance: Getting formal acceptance of the completed project work from the customer or sponsor
