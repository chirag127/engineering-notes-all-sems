### Change Control in spm

1. Change Requests: Any change to the project scope, schedule or resources is requested through a formal change request document. This ensures that all changes are properly documented and evaluated.
2. Change Review Board: The Change Review Board comprises of key stakeholders who evaluate the change requests and assess the impact of accepting the change on the project objectives. They approve or reject change requests.
3. Change Management Plan: The Change Management Plan outlines the process of how change requests will be submitted, reviewed, evaluated and approved or rejected. It defines the composition of the Change Review Board and their decision making process.
4. Configuration Management: Approved changes are incorporated into the project through configuration management which ensures that the latest versions of all project documents are updated with the changes. This maintains integrity of the project information.
5. Communication: Any approved changes are communicated to all the stakeholders who may get impacted. This ensures that all project participants are on the same page about the accepted changes.

The above points cover the key steps involved in managing changes to the project in a formal manner as required. A disciplined change control process helps to minimize arbitrary changes and only approve those changes which are necessary and add value to the project.
