### Dynamic System Development Method in spm

1. Gather system requirements: First step is to gather requirements of the system to be developed from the user or client. This is done through interviews, questionnaires, observing current system, etc.

2. Feasibility study: Next feasibility of the system is checked. Technical, operational and economic feasibility is evaluated. If not feasible, requirements are re-analyzed.

3. System design: If feasible, design of the new system is prepared. Prototypes and diagrams like use case, class, sequence, etc. are created.

4. System implementation: The system is implemented using a suitable programming language and database. Testing is done to fix errors.

5. System testing: The developed system is rigorously tested to identify and rectify any bugs or errors. Alpha and beta testing is done before final deployment.

6. System deployment: The final system is deployed and the user is trained to use it. Feedback is taken and improvements are done in next release.

7. System maintenance: The system is continuously monitored and maintained to make required changes and upgrade as needed to meet changing requirements.

The steps are followed sequentially in a waterfall model to develop a dynamic system using spm or system prototyping model. The key advantage is that user is actively involved throughout the process resulting in development of exact requirements. However, it is less flexible to changes and suits smaller projects.
