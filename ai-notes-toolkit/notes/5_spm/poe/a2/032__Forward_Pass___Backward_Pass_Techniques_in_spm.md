### Forward Pass & Backward Pass Techniques in spm

1. Forward Pass - In forward pass, the weights are initialized randomly and the output is calculated for the given input. The error is then calculated by comparing the output with the expected output. This error is then propagated back to update the weights. This process is repeated several times until the error is minimized.

2. Backward Pass - In backward pass, the weights are updated by calculating the gradients of the loss function with respect to the weights. The gradients show how the weights should be changed to minimize the loss function. The weights are updated in the direction of negative gradients.

3. These two passes are done iteratively several times to minimize the error and train the network. Forward pass helps in calculating the output and error while backward pass helps in updating the weights to reduce the error. Repeating these passes helps the network learn the mapping between input and output.
