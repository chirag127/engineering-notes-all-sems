### Creation of Critical Paths in spm

1. Identify all activities and dependencies: First step is to identify all the activities of the project and the dependencies between them. Dependencies can be broadly classified into FS relationships (Finish-to-Start), SS relationships (Start-to-Start), etc. All the activities and dependencies need to be mapped out to create a project network diagram.

2. Draw the project network diagram: The project network diagram is drawn based on the identified activities and dependencies. The activities are represented by nodes and the dependencies are shown as arrows indicating the relationship. The network diagram gives a visual representation of the project schedule.

3. Determine the critical path: The critical path is the longest path of activities which determines the shortest possible duration to complete the project. To determine the critical path, first calculate the duration of all paths by adding the durations of the activities in each path. The path with the longest duration is the critical path. The activities on the critical path have zero slack and any delays will impact the project completion time.

4. Update for resource constraints and risks: Once the critical path is identified, it needs to be updated by considering resource constraints and potential risks. If there are limited resources, the critical path may change. Also, if there are risks of delays or acceleration of activities, the critical path may change. The critical path needs to be frequently updated as the project progresses to ensure the project is on track to complete on time.
