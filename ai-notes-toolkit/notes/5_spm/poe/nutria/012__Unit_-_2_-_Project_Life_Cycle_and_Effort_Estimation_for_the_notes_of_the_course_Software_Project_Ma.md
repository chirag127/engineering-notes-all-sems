
## Unit - 2 - Project Life Cycle and Effort Estimation

Project life cycle is the process of planning, organizing, and controlling the activities of a project from start to finish. It is an important part of software project management and is used to ensure the successful completion of a project.

Effort estimation is the process of predicting the amount of effort (time and resources) required to complete a project. It is an important part of project planning and is used to determine the cost, duration, and resource allocation for the project.

1. **Project Initiation:** This is the first phase of the project life cycle and includes the identification of the project goals and objectives, the establishment of project requirements, and the development of the project plan.

2. **Project Planning:** This phase involves the development of the project plan, which includes the scope, schedule, budget, and resources needed to complete the project.

3. **Project Execution:** This phase involves the implementation of the project plan and the execution of the project activities.

4. **Project Monitoring and Control:** This phase involves the monitoring and control of the project activities to ensure that the project is completed within the specified time, budget, and quality parameters.

5. **Project Closure:** This phase involves the completion of the project activities, the evaluation of the project results, and the closure of the project.

6. **Effort Estimation:** This is the process of predicting the amount of effort (time and resources) required to complete a project. It involves the estimation of the number of hours and resources needed to complete the project activities.
