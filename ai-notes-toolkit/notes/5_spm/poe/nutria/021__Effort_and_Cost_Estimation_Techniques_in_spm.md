
### Effort and Cost Estimation Techniques in SPM

1. Parametric Estimation: This is a technique that uses mathematical models to estimate the effort and cost of a project. This technique is based on historical data and requires statistical analysis.

2. Delphi Technique: This is a consensus-based approach to estimating effort and cost of a project. It involves a series of rounds of questioning, with experts providing their estimates for each round.

3. Bottom-Up Estimation: This is a technique that involves breaking down the project into smaller tasks and estimating the effort and cost for each task. This technique is more accurate than parametric estimation and is suitable for projects with well-defined tasks.

4. Expert Judgment: This is a technique that involves using the knowledge and experience of experts to estimate the effort and cost of a project. This technique is suitable for projects with complex tasks and is more accurate than parametric estimation.

5. Function Point Analysis: This is a technique that uses a set of metrics to measure the size and complexity of a project. This technique is suitable for projects with well-defined requirements and can be used to estimate the effort and cost of a project.
