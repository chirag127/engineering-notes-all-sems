

### Forward Pass & Backward Pass Techniques in SPM

1. **Forward Pass:** This technique is used to calculate the critical path of a given project. It involves calculating the earliest start and finish times for each activity in the project, in order to determine the longest duration of the project. The forward pass is also used to identify the critical activities in the project, which are those activities that have the least amount of slack and the longest duration.

2. **Backward Pass:** This technique is used to calculate the latest start and finish times for each activity in the project. It involves determining the latest start and finish times for each activity by subtracting the duration of the activity from the earliest finish time of the activity. The backward pass is also used to identify the critical activities in the project, which are those activities that have the least amount of slack and the longest duration.

3. **Float:** Float is the amount of time an activity can be delayed without delaying the entire project. It is calculated by subtracting the earliest start time of the activity from the latest start time of the activity. The activities with the least amount of float are the critical activities in the project.
