### Forward Pass & Backward Pass Techniques in SPM

In SPM, there are two main techniques used for scheduling and evaluating project activities. These techniques are known as Forward Pass and Backward Pass. Both of these techniques are crucial for creating a project schedule and determining the critical path of a project. Here are some key points to remember about these techniques:

#### Forward Pass Technique

- The Forward Pass Technique is used to determine the earliest possible start and finish times for each activity in a project.
- This technique starts from the project's start date and moves forward to calculate the earliest possible start and finish times for each activity.
- The Forward Pass Technique takes into account the duration of each activity, as well as any dependencies between activities.
- The earliest start and finish times calculated through the Forward Pass Technique are used to create a schedule for the project.
- This schedule can then be used to determine the critical path of the project.

#### Backward Pass Technique

- The Backward Pass Technique is used to determine the latest possible start and finish times for each activity in a project.
- This technique starts from the project's end date and moves backward to calculate the latest possible start and finish times for each activity.
- The Backward Pass Technique takes into account the duration of each activity, as well as any dependencies between activities.
- The latest start and finish times calculated through the Backward Pass Technique are used to determine the float or slack time for each activity.
- The float or slack time for an activity is the amount of time that the activity can be delayed without affecting the project's completion date.

Both the Forward Pass and Backward Pass Techniques are essential for creating a project schedule and determining the critical path of a project. By using these techniques, project managers can ensure that their projects are completed on time and within budget.
