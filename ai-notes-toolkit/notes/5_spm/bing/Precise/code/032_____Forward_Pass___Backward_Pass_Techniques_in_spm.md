### Forward Pass & Backward Pass Techniques in SPM

- Forward Pass and Backward Pass are techniques used in the critical path method (CPM) of project management.
- The Forward Pass technique is used to determine the earliest start and finish times for each activity in the project schedule.
- The Backward Pass technique is used to determine the latest start and finish times for each activity in the project schedule.
- These techniques are used to identify the critical path of the project, which is the sequence of activities that determines the shortest possible duration of the project.
- The Forward Pass is performed by starting at the first activity in the project schedule and moving forward through the network diagram, calculating the earliest start and finish times for each activity.
- The Backward Pass is performed by starting at the last activity in the project schedule and moving backward through the network diagram, calculating the latest start and finish times for each activity.
- The difference between the earliest and latest start times, and the earliest and latest finish times, for each activity is called the float or slack. Activities with zero float or slack are on the critical path.
- These techniques are important for project managers to effectively plan, schedule, and control their projects. They help to identify the critical activities that must be completed on time to avoid delays in the project schedule.
