## Unit - 1 - Project Evaluation and Project Planning

### Project Evaluation
Project evaluation is the process of assessing the feasibility and potential success of a proposed project. It involves the following steps:
1. Identifying the project objectives and goals.
2. Assessing the project's potential impact on the organization and its stakeholders.
3. Evaluating the project's technical feasibility.
4. Assessing the project's financial feasibility.
5. Evaluating the project's risks and uncertainties.

### Project Planning
Project planning is the process of defining the scope, objectives, and deliverables of a project, and developing a detailed plan for achieving those objectives. It involves the following steps:
1. Defining the project scope and objectives.
2. Identifying the project deliverables and milestones.
3. Developing a work breakdown structure (WBS) to organize and define the project tasks.
4. Estimating the project resources, including time, cost, and personnel.
5. Developing a project schedule and budget.
6. Identifying and managing project risks.

Project evaluation and planning are critical components of software project management, as they help to ensure that the project is feasible, well-defined, and has a clear path to success. Proper evaluation and planning can help to minimize project risks and uncertainties, and increase the likelihood of project success.
