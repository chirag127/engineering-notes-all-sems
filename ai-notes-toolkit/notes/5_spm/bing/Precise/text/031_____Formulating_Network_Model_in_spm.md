### Formulating Network Model in SPM

1. A network model in SPM (Statistical Parametric Mapping) is a mathematical representation of the interactions between different brain regions.
2. The first step in formulating a network model is to define the nodes, which represent the brain regions of interest.
3. The next step is to define the edges, which represent the connections or interactions between the nodes.
4. The edges can be directed or undirected, and can be weighted to represent the strength of the connection.
5. The network model can be represented as a graph, with the nodes as vertices and the edges as lines connecting the vertices.
6. The network model can be used to analyze the functional connectivity between brain regions, and to identify patterns of interactions that may be associated with specific cognitive processes or behaviors.
7. Various statistical methods can be used to analyze the network model, including graph theory measures and network-based statistics.
8. The formulation of a network model in SPM requires a good understanding of the underlying neurophysiology and the statistical methods used to analyze the data.
