## Unit - 2 - Project Life Cycle and Effort Estimation

- A software project is a complex undertaking that involves various activities, resources, and stakeholders.
- A software project life cycle is a framework that defines the phases, tasks, and deliverables of a software project from inception to completion.
- A software project effort estimation is a process of predicting the amount of time, effort, and cost required to complete a software project based on its scope, size, and complexity.

### Software Project Life Cycle

- There are different models of software project life cycle, such as waterfall, agile, iterative, spiral, etc. Each model has its own advantages and disadvantages depending on the nature, size, and requirements of the project.
- However, most software project life cycle models share some common phases, such as:

  - **Planning**: This phase involves defining the project objectives, scope, schedule, budget, risks, quality, and stakeholders. It also involves selecting the appropriate life cycle model, development methodology, and tools for the project.
  - **Analysis**: This phase involves gathering and analyzing the requirements of the project from the stakeholders, users, and customers. It also involves defining the functional and non-functional specifications, use cases, and user stories of the project.
  - **Design**: This phase involves designing the architecture, components, interfaces, data structures, algorithms, and user interfaces of the project. It also involves creating the design documents, prototypes, and mockups of the project.
  - **Implementation**: This phase involves coding, testing, debugging, and integrating the software components of the project. It also involves creating the executable, documentation, and configuration files of the project.
  - **Testing**: This phase involves verifying and validating the functionality, performance, reliability, security, and usability of the project. It also involves conducting various types of testing, such as unit, integration, system, acceptance, and regression testing of the project.
  - **Deployment**: This phase involves delivering and installing the software product to the end-users or customers. It also involves providing training, support, and maintenance of the product.
  - **Maintenance**: This phase involves fixing the defects, enhancing the features, and updating the software product according to the changing needs and feedback of the users or customers. It also involves monitoring and evaluating the performance and quality of the product.

### Software Project Effort Estimation

- Software project effort estimation is a crucial activity that affects the success and failure of a software project. It helps in planning, managing, and controlling the resources, time, and cost of a software project.
- Software project effort estimation is a challenging and uncertain task due to the inherent complexity, variability, and unpredictability of software development. It involves many factors, such as:

  - **Project scope**: The project scope defines the boundaries, objectives, deliverables, and expectations of the project. It affects the effort estimation by determining the amount and level of work required to complete the project.
  - **Project size**: The project size measures the quantity and quality of the software product to be developed. It affects the effort estimation by indicating the amount of code, data, and documentation to be produced for the project.
  - **Project complexity**: The project complexity reflects the difficulty and uncertainty of the software development. It affects the effort estimation by influencing the amount of skills, knowledge, and experience required to complete the project.
  - **Project quality**: The project quality denotes the degree of satisfaction and value of the software product to the stakeholders, users, and customers. It affects the effort estimation by specifying the amount of standards, testing, and verification to be applied to the project.
  - **Project resources**: The project resources include the human, technical, and organizational factors that support the software development. They affect the effort estimation by determining the availability, capability, and productivity of the resources for the project.

- There are different techniques of software project effort estimation, such as:

  - **Expert judgment**: This technique involves consulting one or more experts who have relevant experience and knowledge of similar projects. It is based on the intuition, opinion, and judgment of the experts.
  - **Analogous estimation**: This technique involves comparing the current project with the past or existing projects that have similar characteristics and features. It is based on the historical data, analogy, and similarity of the projects.
  - **Parametric estimation**: This technique involves using mathematical models and formulas that relate the project effort to one or more project parameters, such as size, complexity, quality, etc. It is based on the statistical analysis, regression, and correlation of the project data.
