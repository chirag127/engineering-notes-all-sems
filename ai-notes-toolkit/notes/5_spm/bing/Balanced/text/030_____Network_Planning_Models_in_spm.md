### Network Planning Models in SPM

- Network planning models are models that use graphical representations of activities and events to visualize the sequence of tasks necessary to complete the project.
- They are used to identify the duration, order of activities, and dependencies among tasks.
- They help to plan, monitor, and control the project progress and resources.
- They can also be used to analyze the impact of changes, risks, and uncertainties on the project outcome.
- Some examples of network planning models are:
  - Techamark's Planning Model: This model is focused on connecting disparate systems, such as legacy systems, cloud services, and mobile devices. It uses a network diagram to show the interfaces, protocols, and data flows among the systems. It also uses a matrix to show the compatibility, security, and performance requirements of each system.
  - Crystal's Planning Model: This model is focused on creating high-level designs, such as architectures, modules, and components. It uses a network diagram to show the relationships, dependencies, and interactions among the design elements. It also uses a matrix to show the quality attributes, such as reliability, usability, and maintainability of each design element.
  - Conway's Planning Model: This model is focused on network reliability and scalability. It uses a network diagram to show the nodes, links, and paths of the network. It also uses a matrix to show the availability, capacity, and cost of each node and link. It also uses a formula to calculate the optimal network configuration based on the demand and budget constraints.
