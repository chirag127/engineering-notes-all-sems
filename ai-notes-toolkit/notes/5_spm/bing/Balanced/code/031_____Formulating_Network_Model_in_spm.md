### Formulating Network Model in SPM

- A network model in software project management (SPM) is a graphical representation of the activities and events involved in a project and their interrelationships.
- It is used to plan, monitor, and control the project by identifying the duration, order, and dependencies of the tasks.
- There are two main types of network models in SPM: activity-on-node (AON) and activity-on-arrow (AOA).
- In AON, the activities are represented by nodes (boxes) and the dependencies are represented by arrows (lines) between the nodes.
- In AOA, the activities are represented by arrows and the events (start or end of an activity) are represented by nodes.
- A network model can be formulated by following these steps:
  - Identify the activities and events that are required to complete the project.
  - Determine the duration and resources for each activity.
  - Establish the logical relationships and dependencies among the activities and events.
  - Draw the network diagram using either AON or AOA notation.
  - Calculate the critical path and the slack time for each activity and event.
  - Update the network model as the project progresses and changes occur.
