### Project Schedules in SPM

- Project schedules are the tools that help project managers plan, monitor, and control the execution of project activities.
- Project schedules show the sequence and duration of project tasks, the dependencies among them, the resources assigned to them, and the milestones and deliverables of the project.
- Project schedules are usually created using software tools such as Microsoft Project, Primavera, or Gantt charts.
- Project schedules are based on the project scope, work breakdown structure, activity list, activity attributes, resource requirements, resource availability, activity duration estimates, and project calendar.
- Project schedules are updated and revised throughout the project life cycle to reflect the actual progress and changes in the project.
- Project schedules are used to communicate the project plan to the project team and stakeholders, to track the project performance and status, to identify and resolve schedule issues and risks, and to control and optimize the project time and resources.
