
#### Data Flow in HDFS

1. HDFS is a distributed file system that stores data on commodity hardware.
2. HDFS is designed to run on clusters of commodity hardware, with each node in the cluster storing a portion of the data.
3. HDFS is designed to be fault tolerant and highly available, meaning it can withstand node failures and still provide access to data.
4. HDFS is designed to be scalable, meaning it can handle large volumes of data and large numbers of nodes.
5. HDFS stores data in blocks, which are distributed across the nodes in the cluster.
6. HDFS replicates each block of data across multiple nodes in the cluster to ensure data availability and reliability.
7. HDFS provides access to data through a client-server model, where clients access data stored on the server.
8. HDFS provides an API for clients to access data stored on the server.
9. HDFS provides a command line interface (CLI) for interacting with the HDFS file system.
10. HDFS provides a web-based user interface (UI) for managing and monitoring the HDFS file system.
