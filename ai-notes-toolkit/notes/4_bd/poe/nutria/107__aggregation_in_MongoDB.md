
### Aggregation in MongoDB

* Aggregation in MongoDB is a process of collecting and combining data from multiple documents into a single result.
* It is used to perform operations such as calculating average, finding the total count of records, finding the maximum and minimum values in a set of documents, etc.
* Aggregation operations are performed using the Aggregation Pipeline, which is a framework for data aggregation operations.
* The Aggregation Pipeline consists of stages, where each stage transforms the documents as they pass through.
* The stages of the Aggregation Pipeline can be used to filter, project, group, sort, limit, and/or skip documents.
* Aggregation operations can be used to perform complex data analysis and generate reports.
