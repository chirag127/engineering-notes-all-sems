
#### History of Hadoop

1. Hadoop was created in 2006 by Doug Cutting, the creator of Apache Lucene.
2. Hadoop was initially developed to support distribution for the Nutch web search engine project.
3. Hadoop's core components are the Hadoop Distributed File System (HDFS), a distributed file system that provides high-throughput access to application data, and YARN, a resource-management platform that enables applications to process data in parallel on large clusters of nodes.
4. Hadoop is designed to scale from single servers to thousands of machines, each offering local computation and storage.
5. Hadoop is written in Java and is open source software released under the Apache License.
6. Hadoop is used for data storage, analysis, and processing of large datasets in distributed computing environments.
7. Hadoop is used in a variety of applications, including search engines, recommendation systems, machine learning, natural language processing, and more.
8. Apache Hadoop is the most popular implementation of Hadoop and is used by many organizations, including Yahoo, Facebook, and Amazon.
