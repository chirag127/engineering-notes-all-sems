
#### Output Formats in Map Reduce

* MapReduce is a programming model for processing large datasets in parallel across a cluster of computers. 
* The output of the MapReduce job is stored in an output format. 
* The output format can be either a text file, a sequence file, or a binary file. 
* Text files are the most common output format and are used when the output data needs to be read by humans. 
* Sequence files are often used when the output data needs to be read by other MapReduce jobs. 
* Binary files are used when the output data needs to be read by non-MapReduce applications. 
* The output format can also be configured to store the output data in a database.
