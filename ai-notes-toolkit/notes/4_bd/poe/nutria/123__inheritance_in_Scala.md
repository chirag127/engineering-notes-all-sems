
#### Inheritance in Scala 

- Inheritance is a fundamental concept in object-oriented programming languages such as Scala. It allows a class to inherit the properties and methods of another class. 
- A class that inherits from another class is called a subclass, while the class it inherits from is called the superclass. 
- Inheritance allows a subclass to use the methods and properties of its superclass, and even override them if necessary. 
- Scala supports single inheritance, where a class can only have one superclass. 
- In Scala, a class can be declared abstract, meaning that it cannot be instantiated. Abstract classes are useful for creating a base class that other classes can inherit from. 
- Traits are another way to share behavior between classes. A trait is a collection of methods and fields that can be mixed into a class. 
- Scala also supports multiple inheritance, where a class can inherit from multiple traits. 
- Finally, Scala supports the concept of type parameters, which allow a class to accept a type as a parameter. This is useful for creating generic classes that can be used with a variety of types.
