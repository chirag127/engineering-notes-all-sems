
#### Hive Shell

* Hive Shell is a command line interface used to interact with the Apache Hive data warehouse system.
* It is used to execute HiveQL statements, manage the Hive warehouse and perform administrative tasks.
* Hive Shell can be used to create, alter, drop, and query databases, tables, views and other objects.
* It also provides a number of built-in functions for data manipulation, such as string functions, date functions, mathematical functions, etc.
* Hive Shell supports a number of commands, including SHOW, DESCRIBE, EXPLAIN, and SET.
* Hive Shell is a powerful tool for data analysis and data manipulation. It can be used to create complex queries, perform data transformations, and analyze large datasets.
