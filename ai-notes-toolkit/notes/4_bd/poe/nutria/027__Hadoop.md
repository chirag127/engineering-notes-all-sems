
### Hadoop

Hadoop is an open-source software framework for distributed storage and distributed processing of large data sets on computer clusters built from commodity hardware. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

Hadoop is designed to detect and handle failures at the application layer, so delivering a highly-available service on top of a cluster of computers, each of which may be prone to failures.

Hadoop can be used to process and analyze data stored in HDFS, the Hadoop Distributed File System. It can also be used to process data stored in other file systems such as local file systems, Amazon S3, Cassandra, and HBase.

Hadoop is written in Java and is an Apache open source project. It is maintained and developed by the Apache Software Foundation.
