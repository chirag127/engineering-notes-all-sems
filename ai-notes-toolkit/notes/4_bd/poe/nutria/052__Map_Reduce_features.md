

#### Map Reduce Features

1. Map Reduce is a programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster. 
2. It is a framework for processing large datasets with a parallel, distributed algorithm on a cluster. 
3. Map Reduce divides the processing into two phases: the map phase and the reduce phase. 
4. During the map phase, the data is split into smaller chunks and each chunk is processed by a separate process. 
5. During the reduce phase, the results of the map phase are combined into a single result. 
6. Map Reduce is designed to scale to large datasets and can be used to process petabytes of data. 
7. It is used in many large-scale data processing applications, such as web indexing, data mining, log file analysis, machine learning, and scientific computing.
