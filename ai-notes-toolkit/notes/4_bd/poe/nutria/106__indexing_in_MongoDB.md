
#### Indexing in MongoDB
1. Indexes are special data structures used to improve the performance of read operations in MongoDB.
2. Indexes can be created on any field in a collection, including fields within embedded documents.
3. Indexes are created in ascending order by default, but can also be created in descending order.
4. Indexes can be used to enforce unique constraints on fields, ensuring that no two documents have the same value for the indexed field.
5. Indexes can also be used to enforce partial or compound unique constraints on multiple fields.
6. Indexes can be used to support efficient sorting operations, allowing documents to be retrieved in a particular order.
7. Indexes can be used to support efficient range queries, allowing documents to be retrieved based on a range of values.
8. Indexes can be created on multiple fields, allowing for efficient queries that use multiple criteria.
9. Indexes can be used to support efficient text search operations, allowing documents to be retrieved based on a search query.
10. Indexes are stored in RAM, so they must be rebuilt if the server is restarted.
