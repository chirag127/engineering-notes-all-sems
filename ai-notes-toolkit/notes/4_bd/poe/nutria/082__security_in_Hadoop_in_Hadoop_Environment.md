

#### Security in Hadoop Environment

1. Hadoop provides security through authentication, authorization, and encryption. 
2. Authentication is the process of verifying the identity of a user. Hadoop supports two types of authentication: Simple Authentication and Kerberos Authentication. 
3. Authorization is the process of granting access to users based on their identity. Hadoop supports two types of authorization: Role-based Authorization and Access Control Lists (ACLs). 
4. Encryption is the process of protecting data from unauthorized access. Hadoop supports two types of encryption: Transparent Encryption and Kerberos Encryption. 
5. Hadoop also provides security through secure data storage and secure data transfer. 
6. Secure data storage is achieved through encryption of data at rest and secure data transfer is achieved through encryption of data in transit.
