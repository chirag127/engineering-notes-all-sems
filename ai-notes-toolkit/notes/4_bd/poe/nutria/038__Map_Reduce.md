
### Map Reduce

Map Reduce is a programming model for processing large datasets. It is based on the concept of dividing a large task into smaller tasks, which are then performed in parallel. The Map Reduce model consists of two phases: the map phase and the reduce phase. 

In the map phase, the dataset is divided into smaller chunks, which are then processed in parallel. The output of the map phase is a set of key-value pairs.

In the reduce phase, the key-value pairs are grouped together by their keys and then a function is applied to each group. The output of the reduce phase is a set of values.

Map Reduce is used to process large datasets in distributed systems. It is also used to process data in cloud computing environments.
