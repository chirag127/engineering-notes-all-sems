
#### Querying Documents in MongoDB

1. Querying documents in MongoDB is a process of retrieving data from a MongoDB database.

2. To query documents in MongoDB, you must use the `find()` method. This method returns a cursor object that can be used to iterate over the documents in the collection.

3. The `find()` method takes an optional argument that specifies a query filter. This filter can be used to find documents that match certain criteria.

4. The `sort()` method can be used to sort the results of a query. This method takes an argument that specifies the field that should be used for sorting.

5. The `limit()` method can be used to limit the number of documents returned by a query. This method takes an argument that specifies the maximum number of documents to return.

6. The `skip()` method can be used to skip a certain number of documents before returning the results of a query. This method takes an argument that specifies the number of documents to skip.

7. The `count()` method can be used to count the number of documents that match a query. This method takes an optional argument that specifies a query filter.
