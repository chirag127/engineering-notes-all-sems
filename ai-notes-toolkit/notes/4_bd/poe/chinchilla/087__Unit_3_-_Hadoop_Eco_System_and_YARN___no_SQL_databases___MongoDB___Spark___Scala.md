## Unit 3 - Hadoop Eco System and YARN, NoSQL Databases, MongoDB, Spark, Scala

In this unit, we will explore the Hadoop ecosystem and some of the tools and technologies that are commonly used in conjunction with Hadoop. We will also look at NoSQL databases, specifically MongoDB, and how it can be used with Hadoop. Finally, we will explore Spark and Scala, which are popular tools for working with large datasets.

### Hadoop Ecosystem

The Hadoop ecosystem is a collection of tools and technologies that are used for storing, processing, and analyzing large datasets. Some of the key components of the Hadoop ecosystem include:

- Hadoop Distributed File System (HDFS): A distributed file system that is used for storing large datasets across multiple machines.
- MapReduce: A programming model that is used for processing large datasets in parallel across multiple machines.
- Yet Another Resource Negotiator (YARN): A resource management system that is used for scheduling and managing resources in a Hadoop cluster.
- HBase: A NoSQL database that is used for storing and retrieving large amounts of structured data.
- Pig: A high-level programming language that is used for querying and analyzing large datasets.
- Hive: A data warehouse system that is used for querying and analyzing large datasets using SQL-like queries.

### YARN

YARN is a key component of the Hadoop ecosystem that is used for resource management and job scheduling. YARN allows multiple applications to run simultaneously on a single Hadoop cluster, which helps to maximize resource utilization and improve cluster performance. Some of the key features of YARN include:

- Resource management: YARN provides a centralized resource management system that allows multiple applications to run concurrently on a Hadoop cluster.
- Job scheduling: YARN schedules jobs based on available resources and priorities, ensuring that the most important jobs are executed first.
- Fault tolerance: YARN provides fault tolerance by automatically restarting failed tasks and ensuring that jobs are completed even if some nodes in the cluster fail.

### NoSQL Databases

NoSQL databases are a type of database that are designed for storing and retrieving large amounts of unstructured or semi-structured data. Unlike traditional relational databases, NoSQL databases do not use a fixed schema, which makes them more flexible and scalable. Some of the key features of NoSQL databases include:

- Scalability: NoSQL databases are designed to be horizontally scalable, which means that they can handle large amounts of data by adding more nodes to the cluster.
- High availability: NoSQL databases are designed to be highly available, which means that they can continue to operate even if some nodes in the cluster fail.
- Flexible schema: NoSQL databases do not use a fixed schema, which makes them more flexible and adaptable to changing data requirements.

### MongoDB

MongoDB is a popular NoSQL database that is used for storing and retrieving large amounts of unstructured data. Some of the key features of MongoDB include:

- Document-based: MongoDB stores data as JSON-like documents, which makes it easy to work with unstructured or semi-structured data.
- High availability: MongoDB provides automatic failover and replication, ensuring that data is always available even if some nodes in the cluster fail.
- Scalability: MongoDB is designed to be horizontally scalable, which means that it can handle large amounts of data by adding more nodes to the cluster.

### Spark

Spark is a fast and powerful data processing engine that is designed for working with large datasets. Spark provides a unified API for working with data in a variety of formats, including Hadoop Distributed File System (HDFS), NoSQL databases, and other data sources. Some of the key features of Spark include:

- In-memory processing: Spark processes data in memory, which makes it much faster than traditional disk-based processing systems.
- Fault tolerance: Spark provides fault tolerance by automatically restarting failed tasks and ensuring that jobs are completed even if some nodes in the cluster fail.
- Easy to use: Spark provides a simple and intuitive API that makes it easy to work with large datasets, even for users with little or no experience with distributed computing.

### Scala

Scala is a programming language that is designed for working with large datasets and distributed computing systems. Scala is designed to be highly scalable and efficient, making it a popular choice for working with Hadoop, Spark, and other large-scale data processing systems. Some of the key features of Scala include:

- Object-oriented: Scala is an object-oriented programming language, which makes it easy to work with large and complex datasets.
- Functional programming: Scala supports functional programming, which makes it easier to write code that is both efficient and easy to read.
- Interoperability: Scala is designed to be highly interoperable with other programming languages, making it easy to integrate with existing systems and technologies.

In conclusion, the Hadoop ecosystem, YARN, NoSQL databases like MongoDB, Spark, and Scala are popular tools and technologies that are commonly used for working with large datasets. Understanding these tools and technologies is essential for anyone working with big data and distributed computing systems.
