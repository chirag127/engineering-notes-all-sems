## Hadoop Eco System Frameworks, Pig, Hive and HBase

Hadoop Eco System Frameworks, Pig, Hive and HBase are essential components of Hadoop, a popular big data processing platform. Here are some key points to understand about these frameworks:

### Hadoop Eco System Frameworks
- Hadoop Eco System Frameworks refer to a collection of tools and technologies that work together to enable big data processing on the Hadoop platform.
- These frameworks provide a wide range of functionalities such as data storage, data processing, data analysis, and data visualization.
- Some of the popular Hadoop Eco System Frameworks include Pig, Hive, HBase, Sqoop, Flume, Oozie, and Mahout.

### Pig
- Pig is a high-level data processing language that runs on the Hadoop platform.
- It allows users to write complex map-reduce tasks using a simple scripting language.
- Pig is used for data processing, data analysis, and ETL (Extract, Transform, Load) operations.
- It supports various data types such as strings, numbers, and complex data structures like maps and arrays.

### Hive
- Hive is a data warehousing and SQL-like query language for the Hadoop platform.
- It allows users to write SQL-like queries over large datasets stored in Hadoop's distributed file system (HDFS).
- Hive translates SQL-like queries into map-reduce jobs, which run on the Hadoop cluster.
- Hive supports various data formats such as CSV, JSON, and Avro.

### HBase
- HBase is a NoSQL database that runs on the Hadoop platform.
- It provides real-time read/write access to large datasets stored in Hadoop's distributed file system (HDFS).
- HBase is a column-oriented database that stores data in tables with rows and columns.
- It supports various data types such as strings, numbers, and binary data.

In conclusion, Hadoop Eco System Frameworks such as Pig, Hive, and HBase provide essential functionalities for big data processing on the Hadoop platform. Understanding these frameworks is crucial for anyone working with big data on Hadoop.
