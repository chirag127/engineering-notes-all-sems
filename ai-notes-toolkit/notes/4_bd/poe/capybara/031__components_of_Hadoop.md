#### Components of Hadoop

Hadoop is an open-source software framework that is used to store and process large datasets. It is a distributed computing system that is designed to handle big data. There are four main components of Hadoop:

1. Hadoop Distributed File System (HDFS)
    - HDFS is a distributed file system that is used to store data across multiple nodes in a Hadoop cluster.
    - It is designed to handle large datasets and provides high throughput access to data.
    - HDFS is fault-tolerant, meaning that it can recover from failures and continue to provide access to data.

2. MapReduce
    - MapReduce is a programming model that is used to process large datasets in a distributed environment.
    - It consists of two phases: the map phase and the reduce phase.
    - The map phase takes input data and converts it into a key-value pair.
    - The reduce phase takes the output of the map phase and combines the values based on the key.

3. YARN
    - YARN stands for Yet Another Resource Negotiator.
    - It is a resource management system that is used to manage resources in a Hadoop cluster.
    - YARN is responsible for allocating resources to applications and scheduling tasks.

4. Hadoop Common
    - Hadoop Common is a set of common utilities and libraries that are used by other Hadoop components.
    - It includes tools for managing and monitoring Hadoop clusters, as well as utilities for working with HDFS and MapReduce.
    - Hadoop Common provides a consistent set of APIs and interfaces that can be used by other Hadoop components.
