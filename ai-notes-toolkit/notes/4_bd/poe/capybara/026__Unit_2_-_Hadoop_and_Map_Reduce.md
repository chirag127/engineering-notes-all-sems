## Unit 2 - Hadoop and Map Reduce

Hadoop is an open-source framework developed by Apache to store and process large datasets in a distributed environment. MapReduce is a programming model used to perform parallel processing on large datasets.

### Hadoop

- Hadoop consists of two main components: Hadoop Distributed File System (HDFS) and MapReduce.
- HDFS is a distributed file system used to store data across multiple machines in a Hadoop cluster.
- MapReduce is a programming model used to process large datasets in parallel across a cluster of machines.
- Hadoop is designed to handle big data, which is characterized by large volume, velocity, and variety.
- Hadoop provides fault tolerance and scalability, which means it can continue to function even if some nodes in the cluster fail.
- Hadoop also supports data processing using other frameworks such as Apache Spark and Apache Storm.

### MapReduce

- MapReduce is a programming model used to process large datasets in parallel across a cluster of machines.
- MapReduce consists of two main functions: Map and Reduce.
- Map function is used to process input data and generate intermediate key-value pairs.
- Reduce function is used to aggregate the intermediate key-value pairs and generate output data.
- MapReduce can be used to process structured, semi-structured, and unstructured data.
- MapReduce is highly scalable and fault-tolerant, which means it can handle large datasets and continue to function even if nodes in the cluster fail.
- MapReduce is used in various industries such as finance, healthcare, and social media to process large datasets and generate insights.

In conclusion, Hadoop and MapReduce are powerful tools for processing and analyzing big data. With their scalability and fault tolerance, they have become essential components in many industries for processing and generating insights from large datasets.
