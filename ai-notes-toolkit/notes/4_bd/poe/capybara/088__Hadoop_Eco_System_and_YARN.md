### Hadoop Eco System and YARN

Hadoop Eco System is a collection of open-source software utilities that are used to process large data sets. It includes various components, one of which is YARN (Yet Another Resource Negotiator).

Below are the features and components of the Hadoop Eco System and YARN:

#### Features of Hadoop Eco System:

- Distributed file system: Hadoop Distributed File System (HDFS) is a distributed file system that provides high-throughput access to application data.

- Data processing: Hadoop provides a distributed computing framework for processing large data sets. Hadoop MapReduce is a programming model and software framework for writing applications that process large amounts of data in parallel.

- Resource management: YARN provides a central platform for managing resources in a Hadoop cluster.

- Scalability: Hadoop is designed to scale horizontally, meaning that it can handle large amounts of data by adding more nodes to the cluster.

#### Components of Hadoop Eco System:

- HDFS: Hadoop Distributed File System is a distributed file system that provides high-throughput access to application data.

- MapReduce: Hadoop MapReduce is a programming model and software framework for writing applications that process large amounts of data in parallel.

- YARN: Yet Another Resource Negotiator is a central platform for managing resources in a Hadoop cluster.

- HBase: HBase is a distributed, scalable, NoSQL database that is designed to store and manage large amounts of data.

- Hive: Hive is a data warehousing and SQL-like query language that is used to analyze data stored in Hadoop.

- Pig: Pig is a high-level platform for creating MapReduce programs that are used for analyzing large data sets.

- Sqoop: Sqoop is a tool that is used to transfer data between Hadoop and relational databases.

- Oozie: Oozie is a workflow scheduler that is used to manage Hadoop jobs.

- Flume: Flume is a distributed, reliable, and available service for efficiently collecting, aggregating, and moving large amounts of log data.

In conclusion, the Hadoop Eco System is a collection of open-source software utilities that are used to process large data sets. YARN is a key component of the Hadoop Eco System that provides resource management in a Hadoop cluster.
