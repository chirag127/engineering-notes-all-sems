#### Installing Spark

1. Download Spark from the official website - https://spark.apache.org/downloads.html. Choose a package type (pre-built for Apache Hadoop, source code, etc.) and download the corresponding compressed file.

2. Extract the compressed file. This will give you a folder called "spark-2.4.3-bin-hadoop2.7" which contains the Spark files.

3. Set up the environment variables -

    a. SPARK_HOME - Point this variable to the extracted Spark folder path.
    b. Add SPARK_HOME/bin to PATH. This will allow you to run Spark commands from any directory.

4. (Optional) Install a Python or Scala package to write Spark applications. Spark supports applications written in Java, Python or Scala. Install the desired package/language as required to write and run Spark applications.

5. Ensure Hadoop is installed and configured (if using a Hadoop-dependent package). Spark can run on Apache Hadoop, standalone or in-memory. Install and configure Hadoop if using the Hadoop-dependent Spark package.

6. Test the installation - Run a sample Spark application ( written in the chosen language) to verify the installation and that the environment variables are set up correctly.
