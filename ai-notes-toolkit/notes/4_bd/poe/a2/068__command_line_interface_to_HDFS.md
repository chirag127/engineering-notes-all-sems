#### Command Line Interface to HDFS

1. HDFS has a command-line interface that allows you to interact with the filesystem.
2. The HDFS commands are accessed through the hdfs dfs shell.
3. To create a file, use the put command. For example, hdfs dfs -put <local-file> <hdfs-path>.
4. To read a file, use the get command. For example, hdfs dfs -get <hdfs-path> <local-file>.
5. To list the files in HDFS, use the ls command. For example, hdfs dfs -ls <hdfs-path>.
6. To remove a file, use the rm command. For example, hdfs dfs -rm <hdfs-path>.
7. To remove an empty directory, use the rmdir command. For example, hdfs dfs -rmdir <hdfs-path>.
8. To change permissions of a file/directory, use the chmod command. For example, hdfs dfs -chmod <permissions> <hdfs-path>.
