#### Introduction to NoSQL databases.

1. NoSQL databases are non-tabular databases and store data differently than relational tables.
2. They have dynamic schemas and scale horizontally.
3. The following are the main types of NoSQL databases:

- Key-Value store: Data is stored in an array of key-value pairs. Ex: Redis
- Document databases: Data is stored in documents (instead of rows & columns in a table) Ex: MongoDB, CouchDB
- Wide-column stores: Stores data in columns instead of rows. Ex: Cassandra, HBase
- Graph databases: Uses graph structures to store data and relationships. Ex: Neo4J, InfiniteGraph

4. The reasons to use NoSQL databases are:

- Large amount of data: NoSQL can scale to large data sets and high throughput
- Schema-less: The schema is dynamic and can evolve as app requirements change
- Distributed: They are designed to run on clusters of machines
- Open source: Most NoSQL DBs are open source and have active communities

5. Key limitations are:

- Limited query capabilities: Limited to key-value lookups, range queries, etc. No complex joins
- Eventual consistency: Data may not be consistent across all nodes at all times
- Less standardization: Different databases have different capabilities and query languages
