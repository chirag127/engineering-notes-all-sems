#### Basic Types and Operators in Scala

1. Int: Represents integer numbers without decimal points. For example: 123, -56
2. Long: Represents larger integer numbers than Int. For example: 123456789L (L suffix is mandatory)
3. Float: Represents decimal numbers with single precision. For example: 12.3f (f suffix is mandatory)
4. Double: Represents decimal numbers with double precision. For example: 12.3
5. Boolean: Represents logical entities true and false
6. Char: Represents a single character. For example: 'a'
7. String: Represents a sequence of characters. For example: "Hello"

Arithmetic Operators: +, -, *, /, %

Relational Operators: >, <, >=, <=

Equality Operators: ==, !=

Logical Operators: &&, ||, !
