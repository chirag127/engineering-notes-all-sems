### Spark

1. Spark is a fast and general engine for large-scale data processing.

2. It has an easy-to-use API for streaming analytics and ETL applications.

3. Spark runs on Hadoop, Apache Mesos, Kubernetes, standalone, or in the cloud.

4. It can access diverse data sources including HDFS, Cassandra, HBase, and S3.

5. Spark provides DataFrames, Dataset and SQL APIs.

6. It has high-level APIs in Scala, Java, Python, and R, and an optimized engine that supports general execution graphs.

7. Spark's core abstraction is a resilient distributed dataset (RDD), which represents an immutable, partitioned collection of elements that can be operated on in parallel.

8. Spark applications are run as independent sets of processes on a cluster, coordinated by the SparkContext.

9. Apart from RDDs, Spark 2.0 introduced a DataFrames API, which provides a richer, more structured alternative to RDDs.

10. The newer Dataset API, introduced in Spark 2.0, natively supports both strongly typed JVM languages and the Python/R experience of DataFrames while providing the performance benefits of optimized Spark SQL execution.
