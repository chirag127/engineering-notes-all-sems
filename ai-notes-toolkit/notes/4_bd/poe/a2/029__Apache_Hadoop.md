#### Apache Hadoop

1. Apache Hadoop is an open-source software framework used for distributed storage and processing of big data using the MapReduce programming model.

2. Hadoop has two main components:
- Hadoop Distributed File System (HDFS): A distributed file system that stores data on commodity machines, providing very high aggregate bandwidth across the cluster.
- Hadoop MapReduce: A software framework for distributed processing of large data sets on compute clusters.

3. The advantages of Hadoop are:
- Scalable: Hadoop can scale up from single servers to thousands of machines, each offering local computation and storage.
- Economical: Hadoop runs on commodity hardware and offers a cost-effective solution for storing and processing huge amounts of data.
- Fault tolerant: Hadoop has mechanisms to detect and handle failures at the application layer.
- Flexible: Hadoop supports different types of data such as structured, unstructured, and semi-structured data.

4. Hadoop's applications include:
- Web indexing
- Log processing
- Social network analysis
- Data mining
- Machine learning
- Graph processing

5. The limitations of Hadoop are:
- Not suitable for low-latency data processing.
- Limited support for iterative machine learning algorithms.
- Expertise required to tune the MapReduce jobs.
- Security issues.
