### Intelligent Data Analysis in Big Data

1. Data preprocessing - The initial step is to clean and preprocess the data. This involves steps like removing noise, handling missing values, scaling features, etc. This makes the data ready for analysis.
2. Feature extraction - Derive features from the data that can be fed into machine learning models. This could be statistical measures, transformations, aggregations, etc. that highlight key characteristics of the data.
3. Selecting algorithms - Choose suitable machine learning algorithms based on the type of problem, availability of data, complexity, etc. Some options for analysis on Big Data include linear regression, logistic regression, decision trees, naive Bayes, and neural networks.
4. Training and evaluation - Train the models on the data and evaluate them using metrics suited for the problem type. Some examples are accuracy, F1 score, ROC curve, etc. Tuning hyperparameters may be required to get the best performance out of a model.
5. Deployment - Deploy the best model on new data to get predictions or insights. This could be batch processing or real-time predictions. The model can be retrained on a scheduled basis as new data comes in.

The key advantages of intelligent data analysis on Big Data are:
- Identify patterns and relationships that would be hard to see manually.
- Make predictions and decisions faster and more accurately.
- Gain new insights that lead to business benefits and opportunities.
- Automate and optimize processes.
