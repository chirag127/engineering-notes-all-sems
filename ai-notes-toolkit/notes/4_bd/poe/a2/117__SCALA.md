### SCALA

1. Scala is a general-purpose programming language that runs on the Java Virtual Machine (JVM).
2. It is designed to be concise, many of Scala's design decisions aimed to address criticisms of Java.
3. Scala source code is intended to be compiled to Java bytecode, so that the resulting executable code runs on a Java virtual machine.
4. Scala provides language interoperability with Java, so that libraries written in either language may be referenced directly in Scala or Java code.
5. The name Scala is a portmanteau meaning "scalable language", signifying that it is designed to grow with the demands of its users.
6. Scala's design emphasizes scalability, type safety, conciseness, immutability and Java/JavaScript interoperability.
7. The language has a strong static type system and supports several programming paradigms including functional, imperative, object-oriented and concurrent programming.
8. The Hello World program in Scala is: object HelloWorld extends App { println("Hello, World!") }
9. Scala runs on the JVM and can access existing Java libraries. The compiler produces Java byte code, making Scala code compatible with Java.
10. Some of the companies using Scala are Twitter, LinkedIn, Foursquare, Amazon, and Sony.
