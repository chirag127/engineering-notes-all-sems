#### Jobs in Spark

1. Spark Driver: The driver program contains the main() function and is responsible for initiating the Spark application. It acquires resources on a cluster and converts user applications into tasks that get executed on executor nodes.

2. Spark Executor: Executors are the nodes in the cluster that run the individual tasks of a Spark application. Each application has its own executors that stay up for the duration of the whole application.

3. Spark Application Master: The Application Master is a special type of executor that negotiates resources from the cluster manager and works with the driver program to schedule and execute tasks on the executors.

The key jobs in a Spark application are the driver program, executors, and application master. The driver program contains the user application and is responsible for initiating and coordinating the application. Executors run the individual tasks of the application and stay up for the application's duration. The application master negotiates resources from the cluster manager and helps schedule and execute tasks on the executors.
