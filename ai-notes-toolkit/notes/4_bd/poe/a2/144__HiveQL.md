#### HiveQL

1. HiveQL is a query language for Apache Hive to query data stored in Hadoop Distributed File System (HDFS) or Apache HBase.
2. It is designed to be easy to learn for users familiar with SQL.
3. HiveQL queries are translated into MapReduce or Tez jobs which are executed on the Hadoop cluster.
4. HiveQL supports queries such as:
- SELECT - to retrieve data
- INSERT - to insert data
- UPDATE and DELETE - to update and delete data
- CREATE TABLE - to create a table
- ALTER TABLE - to change the table schema
- DROP TABLE - to delete a table
5. Data types supported in Hive include:
- Primitives: BOOLEAN, TINYINT, SMALLINT, INT, BIGINT, FLOAT, DOUBLE, STRING, BINARY
- Collections: ARRAY, MAP, STRUCT
- Complex types: union type, tuple
6. HiveQL provides extensions to support windows functions, regex, division by zero handling, etc.
7. HiveQL can be run from the command line or by using the Hive Thrift server. It can also be embedded into custom applications.
