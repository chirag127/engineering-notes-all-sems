### Modern Data Analytics Tools for Big Data

1. Hadoop Ecosystem - Hadoop is a framework for distributed storage and processing of very large data sets. It comprises of various components like HDFS, MapReduce, Pig, Hive, HBase, Oozie, etc. which can be used for data storage, processing, analysis and more.
2. Spark - Apache Spark is a fast and general-purpose cluster computing system. It provides APIs in Java, Python, Scala and R and can be used for processing large data sets with high-level functions. It is faster than Hadoop and can be used for streaming, machine learning, graph processing and SQL queries.
3. Flink - Apache Flink is a framework and distributed processing engine for stateful computations over unbounded and bounded data streams. It has a high throughput and low latency, supports batch and streaming analytics and has APIs in Java and Scala.
4. Dask - Dask is a flexible library for parallel computing in Python. It can scale to large clusters and data sets and provides advanced parallelism for analytics. It extends the functionality of Pandas and Numpy libraries and can be deployed on Hadoop and Spark.
5. Presto - Presto is a distributed SQL query engine for running interactive analytic queries against data sources of all sizes ranging from gigabytes to petabytes. It can query a variety of data sources like Hive, Cassandra, relational databases, etc. and return results at fast speeds.
