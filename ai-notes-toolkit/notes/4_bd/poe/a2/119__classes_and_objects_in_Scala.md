#### Classes and Objects in Scala

- A class is a blueprint that defines the structure and behavior of the objects.
- To define a class, use the `class` keyword followed by the name of the class.
- The code inside the class defines its members which include attributes and methods.
- Attributes are the characteristics of an object and are defined using `val` or `var`.
- Methods are the actions that an object can perform and are defined using `def`.
- To create an object from a class, invoke the class name followed by parentheses `()`.
- The state of an object can be accessed or modified through its attributes.
- The behavior of an object is defined by calling its methods.
- In Scala, every value is an object, including numbers, strings, functions, etc. They belong to pre-defined classes.
- Objects can also be created from top-level definitions using the `object` keyword.
- Top-level objects are singletons as only one instance of the object can exist.
- The members of a top-level object can be accessed using the object name.
