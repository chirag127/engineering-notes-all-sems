#### Apache Hive architecture

1. Metastore: It stores the metadata about the schema/structure of the tables, partitions, databases in a relational database (MySQL/Derby).
2. Drivers: Hive supports multiple drivers to interface with different storage types - HDFS, HBase, Cassandra, Amazon S3, etc. The driver is responsible for translating the queries to the underlying storage format.
3. Query Compiler: It compiles the HiveQL statements into a directed acyclic graph of MapReduce and Tez jobs.
4. Query Execution Engine: It executes the jobs generated by the compiler on Hadoop.
5. CLI/Web Interface: It provides interfaces to submit queries, query status, get results, etc.
6. Optimizer: It performs optimizations like merge-join, bucketing, indexing, etc. to improve query performance.

The key components are the Metastore to store metadata, Drivers to interface with storage, Query compiler to convert queries to jobs, Query execution engine to run jobs on Hadoop and CLI/Web interface to interact with the system. Hive abstracts the complexity of MapReduce/Tez and provides a SQL-like interface (HiveQL) to perform analytics on large data sets.
