#### Data Formats

1. Text: Plain text files containing characters. Eg. `.txt` files.
2. CSV: Comma Separated Values files containing data separated by commas. Eg. `.csv` files. Used to store tabular data.
3. JSON: JavaScript Object Notation files containing data in key-value pairs and arrays. Eg. `.json` files.
4. XML: Extensible Markup Language files containing data in a tree structure. Eg. `.xml` files.
5. YAML: YAML Ain't Markup Language files containing data in a hierarchical structure. Eg. `.yaml` or `.yml` files.
6. PDF: Portable Document Format files containing formatted text and images. Eg. `.pdf` files.
7. Word Processing files: Files containing formatted text, images and other elements. Eg. `.doc`, `.docx`, `.pages` files.
8. Spreadsheets: Files containing data organized in a tabular structure. Eg. `.xlsx`, `.xls`, `.ods` files.
9. Presentations: Files containing slides with text, images, videos and other elements. Eg. `.ppt`, `.pptx`, `.odp` files.
10. Databases: Software applications used to store and manage data. Eg. MySQL, PostgreSQL, MongoDB databases.

The data formats can be used for different use cases based on the structure and features of the formats. The choice of data format depends on the nature of the data and how it is to be used.
