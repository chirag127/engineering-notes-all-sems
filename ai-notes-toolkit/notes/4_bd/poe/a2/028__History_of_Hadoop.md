#### History of Hadoop

1. Hadoop was created by Doug Cutting in 2005. He named it after his son's toy elephant.
2. Hadoop was created to solve the problem of processing huge amounts of data efficiently. It is inspired by Google's MapReduce and Google File System (GFS) papers.
3. In 2006, Hadoop was moved to Apache Software Foundation and renamed as Apache Hadoop.
4. In 2008, Hadoop 0.20.2 was released which included MapReduce, HDFS, and Hadoop Common. This is considered as the first stable release of Hadoop.
5. In 2009, Hadoop 1.0 was released which included security features and other enhancements.
6. In 2011, Hadoop 2.0 (YARN) was released which replaced the existing resource management framework. YARN (Yet Another Resource Negotiator) splits up resource management and job scheduling/monitoring.
7. In 2015, Hadoop 3.0 was released which included erasure coding, tiered storage capabilities and other features.
8. Currently, Hadoop 3.3 is the latest stable release of Apache Hadoop. Hadoop has become very popular for big data processing and has a strong ecosystem and community around it.
