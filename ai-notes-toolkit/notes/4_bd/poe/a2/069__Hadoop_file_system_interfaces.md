#### Hadoop file system interfaces

1. HDFS: Hadoop Distributed File System is the primary storage system used by Hadoop. It is highly fault-tolerant and is designed to be deployed on low-cost hardware. It provides high throughput access to application data and is suitable for applications that have large data sets.

2. MapReduce: The MapReduce programming model is a software framework for distributed processing of large data sets on compute clusters. It consists of two major tasks - the Map task and the Reduce task. The Map task splits the input into key-value pairs and the Reduce task merges the mapped outputs.

3. YARN: Yet Another Resource Negotiator is a cluster management technology. It separates the resource management and job scheduling/monitoring functions. It has a ResourceManager, ApplicationMaster, NodeManager and Container components. YARN helps to utilize the capabilities of Hadoop more effectively as it can be used for data processing with more than just MapReduce jobs.

The above points cover the key Hadoop file system interfaces - HDFS for storage, MapReduce for distributed data processing and YARN for cluster resource management.
