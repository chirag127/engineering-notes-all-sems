#### Data Processing operators in Pig

1. Load: Used to import data from HDFS into Pig. It specifies the input data location and format.
2. Store: Used to store the output of a Pig job into HDFS. It specifies the output location and format.
3. Filter: Used to filter tuples from a relation based on some condition. It is similar to a WHERE clause in SQL.
4. Group: Used to group tuples in a relation based on one or more expressions. It is similar to a GROUP BY clause in SQL.
5. Join: Used to join two or more relations based on some common field(s). It is similar to a JOIN clause in SQL.
6. Limit: Used to constrain the number of tuples in a relation. It is useful for debugging and fetching a sample of data.
7. Order: Used to sort tuples in a relation in ascending or descending order based on one or more expressions. It is similar to an ORDER BY clause in SQL.
8. Project: Used to specify the fields to retain (or project) from a relation. It is similar to a SELECT clause in SQL.
9. Distinct: Used to remove duplicate tuples from a relation. It is similar to a DISTINCT clause in SQL.
10. Foreach: Used to apply a relational operator to each input tuple/bag and generate a resulting bag. It iterates over input tuples/bags and applies the relational operator specified inside the foreach loop.
11. Union: Used to combine two relations having the same schema. It is similar to a UNION clause in SQL.
12. Cross: Used to generate the Cartesian product (cross product) of two (or more) relations.
