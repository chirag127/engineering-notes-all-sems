### Hadoop Eco System Frameworks

1. Hadoop Common: It provides the common Java libraries and utilities that distributed application
on the Hadoop framework requires.
2. Hadoop Distributed File System (HDFS): It is a distributed file system that provides high-throughput access to application data.
3. Hadoop YARN: It is a resource management platform that enables processing engines like MapReduce to request and receive resources from a cluster manager.
4. Hadoop MapReduce: It is a software framework for distributed processing of large data sets on compute clusters. It enables easy writing of applications to process data in parallel.
5. HCatalog: It is a table and storage management layer for Hadoop which allows users with different data processing tools to read and write data on the grid.
6. Pig: It is a high-level data flow language and execution framework for parallel computation. It is used to analyze large data sets in a manner similar to SQL queries.
7. Hive: It is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis. It is used to manage and query large datasets.
8. Mahout: It is a scalable machine learning and data mining library. It provides algorithms such as clustering, classification, and collaborative filtering.
9. ZooKeeper: It is a centralized service for maintaining configuration information, naming, providing distributed synchronization, and providing group services.
10. Oozie: It is a workflow scheduler system to manage Hadoop jobs. It manages and schedules clusters based on time and data availability.
