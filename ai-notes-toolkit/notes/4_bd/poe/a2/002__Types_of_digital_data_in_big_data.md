### Types of digital data in big data

1. Structured data: Data that is organized in a predefined model with a fixed schema is called structured data. For example, data in relational databases with fixed tables and columns is structured data.

2. Unstructured data: Data that does not have a fixed schema or model is called unstructured data. For example, text documents, audio, video, images, log files, etc. are unstructured data. Unstructured data does not have a predefined data model or organization.

3. Semi-structured data: Data that does not have a strict data model but has tags or other markers to separate elements is called semi-structured data. For example, XML, JSON, YAML, etc. are semi-structured data formats. The data may not have fixed schema but has tags to denote fields.

The above lists the major types of digital data that are analyzed in big data. Structured data can be easily analyzed using traditional databases and tools. However, unstructured and semi-structured data require specialized tools and techniques to analyze.
