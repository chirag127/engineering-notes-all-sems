### Map Reduce

1. Map Reduce is a programming model for processing and generating large data sets.
2. It works on the principle of divide and conquer. The input is divided into smaller chunks which are processed in parallel by multiple nodes in a cluster.
3. The two main tasks in Map Reduce are:
- Map: The master node takes the input and partitions it into smaller sub-problems and distributes them to the worker nodes. The worker nodes process the smaller problems and return the results.
- Reduce: The master node then collects the results from the worker nodes and aggregates them to produce the final output.
4. The benefits of Map Reduce are:
- Scalability: It can process huge amounts of data by increasing the number of nodes in the cluster.
- Fault Tolerance: If a node fails, the master node can reschedule the task on another node. The job is completed even if there are node failures.
- Low Cost: Commodity hardware can be used to build the cluster leading to low costs.
- Efficient processing: The tasks are processed in parallel leading to fast execution times.
