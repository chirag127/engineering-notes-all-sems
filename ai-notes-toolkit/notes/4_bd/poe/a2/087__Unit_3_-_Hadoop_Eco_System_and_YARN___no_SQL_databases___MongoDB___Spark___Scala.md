## Unit 3 - Hadoop Eco System and YARN , NoSQL databases , MongoDB , Spark , Scala

1. Hadoop Ecosystem
- Hadoop Common: The common utilities that support other Hadoop modules.
- Hadoop Distributed File System (HDFS): A distributed file system that provides high-throughput access to application data.
- YARN: A framework for job scheduling and cluster resource management.
- Hadoop MapReduce: A YARN-based system for parallel processing of large data sets.

2. NoSQL Databases
- Key-value store: Data is stored in an array of key-value pairs. Ex: Redis
- Document databases: Data is stored in documents (instead of rows & columns in a table). Ex: MongoDB, CouchDB
- Wide-column stores: Data is stored in columns instead of rows. Ex: Cassandra, HBase
- Graph databases: Data is stored in graphs with nodes, properties, and lines. Ex: Neo4J, InfiniteGraph

3. MongoDB
- A document-oriented NoSQL database.
- Data is stored in JSON-like documents.
- Dynamic schemas.
- Indexes support fast queries.
- Replication provides high availability.
- Used for content management, real-time analytics, high volume data storage.

4. Apache Spark
- A fast and general engine for large-scale data processing.
- Supports Java, Python, R, and Scala.
- Runs on Hadoop, standalone, or in the cloud.
- Often employed for streaming, machine learning, and graph processing use cases.

5. Scala
- A general-purpose programming language that runs on the JVM.
- Combines object-oriented and functional programming concepts.
- Concise, type-interference, and scalable language.
- Used for building Spark applications and by several companies for performance-critical applications.
