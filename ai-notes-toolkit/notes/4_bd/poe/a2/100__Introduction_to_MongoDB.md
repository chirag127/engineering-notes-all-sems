#### Introduction to MongoDB

1. MongoDB is a document-oriented NoSQL database.
2. MongoDB stores data in JSON-like documents.
3. MongoDB is scalable and distributed. It has the capability to store large volumes of data and scale horizontally.
4. MongoDB is schema-less, which means that documents in a collection do not have to share the same structure.
5. Some key features of MongoDB are:
- Indexes (for fast queries)
- Replication (for high availability and scaling)
- Auto-sharding
- Rich query language
6. Some pros of MongoDB are:
- Schema-less and scalable
- High performance
- Easy to learn and use
7. Some cons of MongoDB are:
- Limited query capabilities (compared to SQL)
- Weak consistency (compared to traditional RDBMS)
- Managing sharded clusters and replica sets can be complex
