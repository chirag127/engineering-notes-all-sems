#### Security of Big Data

1. Access control: Big data systems should have strong access control mechanisms to restrict access to sensitive data. Access should be given based on the principle of least privilege. Authentication and authorization of users should be strictly enforced.

2. Data encryption: Data in transit as well as data at rest should be encrypted to protect against unauthorized access. Keys should be managed securely.

3. Data masking: Sensitive data should be masked or tokenized before using it for analytics to minimize privacy risks. De-identification of data is not sufficient as re-identification is often possible.

4. Data governance: There should be strict data governance policies and processes in place to ensure that data is handled responsibly and ethically. This includes data classification, compliance with regulations, and oversight of data use.

5. Software vulnerabilities: The software tools and systems used for big data processing are prone to vulnerabilities that can be exploited by attackers. Regular patching of software and use of secure, updated versions is important.

6. Insider threats: Insiders with legitimate access to data can intentionally or unintentionally compromise data security. Privileged users require monitoring and data access should be tied to job roles.

7. Cloud security: If big data systems are deployed in the cloud, cloud security measures should be taken like enforcing isolation, using trusted networks, monitoring data and access, etc. Shared security responsibility of the cloud providers and tenants needs to be clearly understood.
