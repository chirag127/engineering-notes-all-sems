#### Introduction to Big SQL

Big SQL is a SQL engine for Hadoop that allows you to query and analyze data from various sources using standard SQL syntax. Some of the features and benefits of Big SQL are:

- It is based on IBM common SQL database technology, which provides high performance, reliability, and compatibility with other IBM SQL products.
- It is a massively parallel processing (MPP) engine that can scale horizontally and vertically to handle large volumes of data and complex queries.
- It supports a variety of data sources, including HDFS, RDBMS, NoSQL databases, object stores, and WebHDFS, and allows you to access them with a single query using federated query capabilities.
- It supports ANSI SQL-2011 and many SQL extensions, such as window functions, common table expressions, and user-defined functions.
- It provides security features, such as authentication, authorization, encryption, and auditing, to protect your data and comply with regulations.
- It provides connectivity options, such as JDBC, ODBC, and REST APIs, to integrate with various applications and tools, such as spreadsheets, BI tools, and notebooks.
- It provides a web-based user interface, called Big SQL Console, to manage and monitor your Big SQL environment and run SQL queries interactively.

Big SQL is a component of IBM Db2 Big SQL, which is a comprehensive solution for SQL-on-Hadoop that also includes other components, such as Big SQL Scheduler, Big SQL Sandbox, and Big SQL Service. For more information, see [IBM Db2 Big SQL](https://www.ibm.com/products/db2/big-sql).
