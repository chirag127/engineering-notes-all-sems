#### Introduction to Big SQL

- Big SQL is a high performance massively parallel processing (MPP) SQL engine for Hadoop that makes querying enterprise data from across the organization an easy and secure experience .
- Big SQL can quickly access a variety of data sources including HDFS, RDBMS, NoSQL databases, object stores, and WebHDFS by using a single database connection or query.
- Big SQL is built on the world class IBM common SQL database technology and has all the standard RDBMS features such as transactions, concurrency, security, and optimization.
- Big SQL supports the ANSI SQL standard and provides compatibility with many SQL dialects such as Oracle, DB2, and Netezza.
- Big SQL provides connectivity for some applications through either a 32-bit or a 64-bit ODBC driver, on either Linux or Windows, that conforms to the Microsoft Open Database Connectivity 3.0.0 specification.
- Big SQL also provides a command line interface (CLI) and a web-based user interface (UI) for executing and managing SQL queries.
- Big SQL leverages the distributed processing power of the Hadoop cluster and the scalability of the Hadoop Distributed File System (HDFS) to handle large volumes of structured and semi-structured data.
- Big SQL can also integrate with other components of the Hadoop ecosystem such as Hive, Spark, HBase, and Kafka to enable advanced analytics and data processing .
