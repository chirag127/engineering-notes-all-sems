### Map Reduce

- MapReduce is a programming model introduced by Google for processing and generating large data sets on clusters of computers .
- MapReduce consists of two phases: map and reduce. The map phase applies a user-defined function to each input record and produces a set of intermediate key-value pairs. The reduce phase aggregates the intermediate values associated with the same key and produces the final output.
- MapReduce is designed to handle large-scale data analysis in a distributed and fault-tolerant manner. It can run on commodity hardware and scale up to thousands of nodes  .
- MapReduce is often used with Apache Hadoop, a data analytics engine widely used for Big Data. Hadoop provides a distributed file system (HDFS) and a resource management framework (YARN) for MapReduce applications .
- MapReduce can be used for various applications, such as web indexing, data mining, machine learning, log analysis, text processing, and image processing  .
