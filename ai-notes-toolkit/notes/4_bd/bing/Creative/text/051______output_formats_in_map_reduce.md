#### Output Formats in Map Reduce

Output formats in Map Reduce are the classes that define how the output files of a Map Reduce job are stored in a file system. They also provide the RecordWriter implementation to write the output records of the mappers and reducers. The output format can be specified by the FileOutputFormat.setOutputPath() method in the job configuration. Some of the common output formats in Map Reduce are:

- TextOutputFormat: This is the default output format that writes plain text files. Each record is a line of text that consists of the key and the value separated by a tab character. The keys and values are converted to strings using the toString() method.
- SequenceFileOutputFormat: This output format writes sequence files, which are binary files that store serialized key-value pairs. Sequence files are efficient and compact, and can be compressed and split. They are suitable for storing intermediate data between Map Reduce jobs or for storing large amounts of data that need fast random access.
- SequenceFileAsBinaryOutputFormat: This is a variant of SequenceFileOutputFormat that writes the keys and values as binary data instead of using serialization. This can be useful for performance reasons or for handling complex data types that are not easily serialized.
- MapFileOutputFormat: This output format writes map files, which are a special type of sequence files that support random access by key. Map files consist of two sequence files: a data file that stores the key-value pairs and an index file that stores the keys and their offsets in the data file. Map files are useful for creating indexes or lookup tables that can be queried by key.
- MultipleOutputs: This is a utility class that allows writing to multiple output files from a single Map Reduce job. It can be used to write different types of output files based on the keys or values, or to write to different directories or file systems. MultipleOutputs can be used with any output format, and it provides methods to create and write to named outputs.
- LazyOutputFormat: This is a wrapper output format that prevents the creation of empty output files. It can be used with any output format, and it delays the creation of the output file until the first record is written to it. This can be useful for reducing the number of output files when the number of reducers is large or when the output is filtered or sparse.
- DBOutputFormat: This output format writes the output records to a relational database table using JDBC. It can be used to export data from Hadoop to a database, or to perform aggregation or join operations with database tables. DBOutputFormat requires specifying the database connection parameters, the table name, and the column names in the job configuration.
