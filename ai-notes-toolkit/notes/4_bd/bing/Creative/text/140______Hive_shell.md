#### Hive shell

- Hive shell is a command-line interface that allows users to interact with Hive and execute HiveQL queries.
- Hive shell can be run in two modes: interactive and non-interactive.
- In interactive mode, users can enter HiveQL commands directly in the shell and see the results on the screen. To start the interactive mode, users need to type `hive` in the terminal and press enter.
- In non-interactive mode, users can specify a file that contains HiveQL commands and run them in batch mode. To start the non-interactive mode, users need to type `hive -f filename` in the terminal and press enter, where filename is the name of the file that contains the HiveQL commands.
- Hive shell supports various options and commands that can be used to configure and control the shell behavior. For example, users can use `set` to set or view the value of a Hive configuration variable, or use `quit` to exit the shell. To see the full list of options and commands, users can type `help` in the shell and press enter.
