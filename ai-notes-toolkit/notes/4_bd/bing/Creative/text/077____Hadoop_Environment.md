## Hadoop Environment

- Hadoop is an open source software framework that allows for the distributed storage and processing of large data sets across clusters of computers using simple programming models  .
- Hadoop is based on the MapReduce programming model, which enables parallel processing of large data sets by dividing them into smaller chunks and assigning them to different nodes in the cluster.
- Hadoop has two main components: Hadoop Distributed File System (HDFS) and Hadoop MapReduce.
  - HDFS is a distributed file system that provides high availability, fault tolerance, scalability, and data locality for large data sets.
  - Hadoop MapReduce is a software framework that supports the execution of user-defined Map and Reduce functions on the data stored in HDFS.
- Hadoop also has a rich ecosystem of tools and applications that extend its functionality and provide additional features, such as data ingestion, data integration, data analysis, data visualization, machine learning, etc .
  - Some of the popular tools and applications in the Hadoop ecosystem are: Apache Hive, Apache Pig, Apache Spark, Apache HBase, Apache Sqoop, Apache Flume, Apache Kafka, Apache Oozie, Apache ZooKeeper, etc .
- Hadoop requires the Java Runtime Environment (JRE) 1.6 or higher to run. It also requires that Secure Shell (SSH) be set up between nodes in the cluster for the standard startup and shutdown scripts.
- Hadoop can run on various platforms, such as Linux, Windows, Mac OS X, etc. It can also run on cloud platforms, such as Google Cloud, Amazon Web Services, Microsoft Azure, etc.
