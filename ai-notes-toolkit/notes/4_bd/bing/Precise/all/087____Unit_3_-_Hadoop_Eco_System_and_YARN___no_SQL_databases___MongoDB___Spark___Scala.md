## Unit 3 - Hadoop Eco System and YARN, NoSQL databases, MongoDB, Spark, Scala

1. **Hadoop Eco System and YARN**: Hadoop is an open-source software framework for storing and processing large datasets. The Hadoop ecosystem includes a variety of tools and technologies that can be used to work with Hadoop, including YARN (Yet Another Resource Negotiator), which is a resource management platform responsible for managing compute resources in clusters and using them for scheduling of users' applications.

2. **NoSQL databases**: NoSQL databases are non-relational databases that are designed to handle large amounts of unstructured data. They are often used in big data and real-time web applications. Some popular NoSQL databases include MongoDB, Cassandra, and CouchDB.

3. **MongoDB**: MongoDB is a document-based NoSQL database that stores data in flexible, JSON-like documents. It is designed to be scalable, high-performance, and easy to use.

4. **Spark**: Apache Spark is an open-source distributed computing system that can process large amounts of data quickly. It is designed to be fast and general-purpose, and can be used for a variety of tasks, including data processing, machine learning, and graph processing.

5. **Scala**: Scala is a programming language that combines object-oriented and functional programming. It is designed to be concise, expressive, and scalable, and is often used with Apache Spark for big data processing.
