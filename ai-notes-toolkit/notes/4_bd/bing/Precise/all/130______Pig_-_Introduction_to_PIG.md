#### Pig - Introduction to PIG

1. Apache Pig is a high-level platform for creating programs that run on Apache Hadoop.
2. The language for this platform is called Pig Latin.
3. Pig can execute its Hadoop jobs in MapReduce, Apache Tez, or Apache Spark.
4. Pig Latin abstracts the programming from the Java MapReduce idiom into a notation which makes MapReduce programming high level, similar to that of SQL for RDBMS systems.
5. Pig Latin can be extended using User Defined Functions (UDFs) which the user can write in Java, Python, JavaScript, Ruby or Groovy and then call directly from the language.
6. Pig was originally developed at Yahoo Research around 2006 for researchers to have an ad-hoc way of creating and executing MapReduce jobs on very large data sets.
7. In 2007, Pig became an open source project of the Apache Software Foundation.
8. Pig is intended to handle any kind of data, including structured and unstructured data and relational and nested data. This includes data stored in HDFS (Hadoop Distributed File System), HBase (Hadoop's version of a NoSQL database), and other data storage systems.
