#### Design of HDFS
- HDFS (Hadoop Distributed File System) is a big data distributed file system storage by Apache .
- The design of HDFS was based on the Google File System  .
- It was originally built as infrastructure for the Apache Nutch web search engine project but has since become a member of the Hadoop Ecosystem  .
- HDFS is designed for storing very large files with streaming data access patterns, running on clusters of commodity hardware .
- HDFS is designed more for batch processing rather than interactive use by users .
- The emphasis is on high throughput of data access rather than low latency of data access .
- HDFS is designed to reliably store very large files across machines in a large cluster .
