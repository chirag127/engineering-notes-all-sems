#### Introduction to Big Sheets

- Big Sheets is a user interface program developed for non-technical business users to enable data gathering and analysis .
- It provides new insights by comparing various data from different resources .
- It allows the users to explore the risk factor .
- Big Sheets generates actionable workflow by gathering the information, extracting or analyzing the information, and exploring or visualizing the data in a creative way which enables the users to work .
- Big Sheets can translate untapped data into actionable business insights, which is one of the common requirements .
- Big Sheets is part of IBM's InfoSphere BigInsights platform, which is based on open-source technologies (e.g., Apache Hadoop) and IBM-specific technologies .
