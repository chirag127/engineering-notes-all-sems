#### Pig - Introduction to PIG

1. Pig is a high-level platform for creating MapReduce programs used with Hadoop.
2. The language for this platform is called Pig Latin.
3. Pig Latin abstracts the programming from the Java MapReduce idiom into a notation which makes MapReduce programming high level, similar to that of SQL for RDBMS systems.
4. Pig Latin can be extended using UDF (User Defined Functions).
5. Pig is generally used with Hadoop; you can perform all the data manipulation operations in Hadoop using Pig.
6. Pig is an open-source project under the Apache Software Foundation.
7. Pig is a data flow language.
8. Pig is designed to handle any kind of data, structured or unstructured.
9. Pig is a procedural language, where the programmer has to define the steps to achieve the desired result.
10. Pig is a platform to analyze large data sets that consist of a high-level language for expressing data analysis programs, coupled with infrastructure for evaluating these programs.
