## Unit 3 - Hadoop Eco System and YARN, NoSQL databases, MongoDB, Spark, Scala

- **Hadoop Eco System:** Hadoop is an open-source software framework for storing and processing large datasets. The Hadoop ecosystem includes a variety of tools and technologies that can be used to work with Hadoop, including Hadoop Distributed File System (HDFS), MapReduce, Pig, Hive, HBase, and others.

- **YARN:** YARN (Yet Another Resource Negotiator) is a resource management layer in Hadoop that allows multiple data processing engines to share resources in a cluster. It is responsible for managing and allocating resources to applications running on the Hadoop cluster.

- **NoSQL databases:** NoSQL databases are non-relational databases that are designed to handle large amounts of unstructured or semi-structured data. They are often used in big data and real-time web applications. Some popular NoSQL databases include MongoDB, Cassandra, and Redis.

- **MongoDB:** MongoDB is a document-based NoSQL database that stores data in flexible, JSON-like documents. It is designed to be scalable, high-performance, and easy to use.

- **Spark:** Apache Spark is an open-source, distributed computing system that is designed to process large amounts of data quickly. It can be used for a variety of tasks, including data processing, machine learning, and graph processing.

- **Scala:** Scala is a programming language that combines object-oriented and functional programming. It is often used with Apache Spark to write scalable and efficient data processing code.
