#### Map Reduce types in map reduce

MapReduce is a programming model and an associated implementation for processing and generating large data sets. There are two main types of MapReduce jobs: batch and streaming.

1. **Batch MapReduce**: Batch MapReduce jobs are used to process large amounts of data in a single run. These jobs are typically scheduled to run at regular intervals, such as daily or weekly, and are used to perform tasks such as data analysis, data aggregation, and data transformation.

2. **Streaming MapReduce**: Streaming MapReduce jobs are used to process data in real-time as it is generated. These jobs are typically used to perform tasks such as data filtering, data enrichment, and data transformation on data streams.

Both types of MapReduce jobs can be used to process structured, semi-structured, and unstructured data. The choice of which type of MapReduce job to use depends on the specific requirements of the data processing task at hand.
