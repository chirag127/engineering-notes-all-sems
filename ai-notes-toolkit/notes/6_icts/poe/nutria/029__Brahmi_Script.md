

#### Brahmi Script

* Brahmi script is one of the oldest writing systems in India, dating back to the 3rd century BCE. It is believed to have been derived from the Aramaic script.
* Brahmi script was used to write the ancient Indian language of Sanskrit, as well as other languages such as Pali, Prakrit, and Magadhi.
* Brahmi script is a syllabic script, meaning that each character represents a single syllable.
* The characters of Brahmi script are generally composed of a base consonant, a vowel, and a diacritic mark.
* Brahmi script is written from left to right, and is composed of various symbols, such as circles, lines, and dots.
* Brahmi script is still used today, mainly in India and Sri Lanka, to write the languages of Pali, Sanskrit, and Sinhala.
