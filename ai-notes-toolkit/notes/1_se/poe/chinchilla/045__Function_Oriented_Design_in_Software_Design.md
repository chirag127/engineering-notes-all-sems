#### Function Oriented Design in Software Design

Function oriented design is a software design approach that focuses on the functions or tasks that a program needs to perform. It is a systematic and structured approach to software design, which helps in developing software that is efficient, reliable, and easy to maintain. The following are the main features of function oriented design:

1. Modular Design: The software is divided into smaller modules or functions, which can be developed independently. Each function is designed to perform a specific task, and it can be reused in other parts of the software.

2. Top-Down Design: The design process starts with the main function or module, which is then divided into smaller functions. This process is repeated until the functions are simple enough to be implemented.

3. Data Flow Diagrams: Function oriented design uses data flow diagrams to represent the flow of data between functions. These diagrams show how data is passed from one function to another and how it is transformed.

4. Structured Programming: Function oriented design follows structured programming principles, which emphasize the use of control structures, such as loops and conditionals, to control the flow of execution.

5. Data Abstraction: Function oriented design promotes data abstraction, which means hiding the implementation details of a function and exposing only the necessary information.

6. Ease of Maintenance: Function oriented design helps in developing software that is easy to maintain because each function is designed to perform a specific task, and changes can be made to a function without affecting the rest of the software.

In conclusion, function oriented design is a software design approach that focuses on the functions or tasks that a program needs to perform. It promotes modular design, top-down design, data flow diagrams, structured programming, data abstraction, and ease of maintenance. By following these principles, function oriented design helps in developing software that is efficient, reliable, and easy to maintain.
