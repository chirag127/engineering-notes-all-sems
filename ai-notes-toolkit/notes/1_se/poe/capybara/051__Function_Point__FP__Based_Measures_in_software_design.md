##### Function Point (FP) Based Measures in software design

Function Point (FP) based measures are a widely used method for measuring the size and complexity of software applications. They are used to estimate the cost, effort, and schedule required to develop and maintain software applications. Here are some key points to keep in mind when working with Function Point based measures:

- Function Points are a measure of the functionality provided by a software application. They are determined by assessing the functional requirements of the application, such as input, output, data storage, and processing.
- Function Points are independent of the technology used to implement the application. This means that they can be used to compare software applications developed using different programming languages, platforms, and development methodologies.
- The process of determining Function Points is based on a set of rules and guidelines that have been established by the International Function Point Users Group (IFPUG). These rules and guidelines are designed to ensure consistent and accurate measurement of software applications.
- There are two primary methods for determining Function Points: the Counting Method and the Estimation Method. The Counting Method involves a detailed analysis of the functional requirements of the application, while the Estimation Method uses historical data to estimate the number of Function Points required for a given project.
- Function Points can be used to estimate the effort required to develop and maintain software applications. This can be useful for project planning and resource allocation.
- Function Points can also be used to compare the productivity of software development teams, as well as the quality and maintainability of software applications.
- Function Point metrics can be used to identify areas of improvement in software development processes, such as design, coding, and testing.
- There are several tools available for automating the process of determining Function Points. These tools can help to reduce the time and effort required to measure the size and complexity of software applications.
- Function Point based measures are widely used in industry and academia, and are considered to be a reliable and accurate method for measuring the size and complexity of software applications.

In summary, Function Point based measures are a widely used and reliable method for measuring the size and complexity of software applications. They can be used to estimate the cost, effort, and schedule required to develop and maintain software applications, as well as to identify areas of improvement in software development processes.
