### Review and Management of User Needs in Requirement Engineering Process in SRS

Requirement Engineering (RE) is a critical phase in the software development life cycle (SDLC). It is the process of identifying, analyzing, documenting, and verifying the requirements for a software system. The success of the software development project depends on how well the requirement engineering process is performed. User Needs are the fundamental requirements that have to be fulfilled. Here are some points about Review and Management of User Needs in Requirement Engineering Process in SRS:

- User Needs should be collected from various sources like customers, end-users, stakeholders, domain experts, marketing teams, and sales personnel.
- The collected User Needs should be analyzed and prioritized based on their importance and feasibility.
- The prioritized User Needs should be documented in a clear and concise manner in the Software Requirements Specification (SRS) document.
- The SRS document should be reviewed thoroughly by the stakeholders, domain experts, and the development team to ensure that all the User Needs are captured correctly.
- Any ambiguity or inconsistency in the User Needs should be identified and resolved during the review process.
- The SRS document should be updated whenever there is a change in the User Needs.
- The updated SRS document should be reviewed again to ensure that the changes are incorporated correctly.
- The SRS document should be managed properly throughout the software development life cycle to ensure that the software system meets the User Needs.
- The User Needs should be traced throughout the development process to ensure that they are met in the final product.
- The User Needs should be validated through testing and other verification techniques to ensure that they are met satisfactorily.

In conclusion, Review and Management of User Needs in Requirement Engineering Process in SRS is a critical aspect of the software development process. It ensures that the software system meets the User Needs and satisfies the stakeholders. Proper review and management of User Needs can lead to a successful software development project.
