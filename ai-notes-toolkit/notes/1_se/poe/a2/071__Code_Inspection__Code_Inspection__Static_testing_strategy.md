#### Code Inspection (Code Inspection) Static testing strategy

- Code inspection is a static testing technique where the code is examined by a group of reviewers to find defects manually.
- The code is inspected without actually executing it. The reviewers go through the code line by line and check for violations from coding standards, potential bugs, design issues etc.
- It is a cheap and easy to perform technique. However, it is subjective and depends on the expertise and diligence of the reviewers. There is a possibility of missing defects or introducing new defects into the code.
- Guidelines for effective code inspection:
-- Reviewers should be technically competent and familiar with the language and domain
-- Code should be reviewed in small chunks (around 200-400 lines) to maintain focus
-- Defects found should be clearly documented with severity levels assigned
-- Meeting should be conducted to discuss anomalies and arrive at a consensus
-- Author of the code should be present to clarify questions and accept/reject suggestions
-- Inspections should be performed iteratively as the code evolves
