#### Test Data Suit Preparation software testing strategy

1. Understand the software application and its functionalities thoroughly. Analyze the inputs and outputs of each module and identify the key data flows.
2. Identify the data ranges and data types for each input field of the application. Determine the maximum and minimum values accepted for numeric inputs. For text inputs, determine the valid and invalid formats.
3. Prepare the test data suit to include both valid and invalid data for testing. Include data that lies on the boundaries of different ranges and formats. Include data that can trigger errors or unexpected behaviors.
4. Prepare data for both happy path and exception path testing. Include data to test normal application flows as well as data to trigger validation errors, database errors, etc.
5. Ensure the test data suit includes diverse data which can test localization, internationalization, and cultural aspects if applicable.
6. Maintain the test data suit continuously as the application is updated. Retest the application with the existing test data and add or modify the data as required to keep it relevant.
7. Store the test data suit securely and share it with the testing team for effectively evaluating the software application.

The above content summarizes the key steps to follow for preparing an effective test data suit to test a software application. The focus is on understanding the application, identifying data requirements, preparing diverse data for testing both happy and exception paths, and maintaining the test data suit continuously.
