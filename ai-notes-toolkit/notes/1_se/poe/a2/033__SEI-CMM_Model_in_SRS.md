### SEI-CMM Model in SRS

* The Software Engineering Institute's Capability Maturity Model (SEI-CMM) is a framework that describes the key practices of a software organization.
* It defines 5 levels of maturity for a software organization - Initial, Repeatable, Defined, Managed, Optimizing.
* Each higher maturity level has additional practices that build on the lower level practices.
* The SEI-CMM model helps in evaluating and improving the software development processes of an organization.
* It encourages the use of documented processes, data collection, and statistical techniques to control projects and improve the processes.
* For Requirements Specification, the SEI-CMM prescribes practices like:
** Requirements Management process to track requirements changes
** Requirements analysis techniques like prototyping, scenarios, use cases, etc.
** Requirements documentation with attributes like source, priority, version history, etc.
** Reviews and verification of requirements
** Requirements tracing and mapping to other software artifacts

* Following the SEI-CMM prescribed practices leads to better process control, quality software, and reduced rework. Hence, it is useful to incorporate SEI-CMM principles while developing the SRS.
