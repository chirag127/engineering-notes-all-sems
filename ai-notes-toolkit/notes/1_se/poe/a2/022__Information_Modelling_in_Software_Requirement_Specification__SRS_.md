### Information Modelling in Software Requirement Specification (SRS)

- Information modelling is an important part of SRS. It specifies the data structure that is required for the software system.
- The key elements that are specified in information modelling are:
- Entities: The objects or concepts that are important for the system to track or store information about. For example, customers, products, accounts, etc.
- Attributes: The properties of each entity that are relevant to the system. For example, name, age, address, price, etc.
- Relationships: The associations between different entities. For example, a customer places an order, an order contains multiple products, etc.
- Constraints: The restrictions or rules that govern the data. For example, an age cannot be negative, a customer name cannot be blank, etc.
- Specifying the information model in SRS helps understand the core data that drives the functional requirements and the interactions in the system. It forms the basis for the database design of the system. A properly specified information model leads to a robust and accurate software product.
