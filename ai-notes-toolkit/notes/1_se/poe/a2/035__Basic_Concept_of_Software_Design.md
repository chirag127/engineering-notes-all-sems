### Basic Concept of Software Design

1. Modularity - Divide the system into multiple modules that are interconnected. Each module should have a specific functionality. This increases organization and makes isolating issues easier.
2. Abstraction - Hide the complexity of lower level details and expose only essential interfaces. This makes the system easier to understand and use.
3. Layering - Organize modules into hierarchical layers where each layer provides services to the layer above and serves the layer below. This enforces modularity and separation of concerns.
4. Information Hiding - Hide the internal details of a module and expose only the essential interfaces to interact with it. This reduces coupling between modules and increases flexibility to change.
5. Separation of Concerns - Separate the functionality of a system into distinct sections that overlap in functionality as little as possible. This increases cohesion, reusability and maintainability.
6. Coupling - The degree of dependence between modules. Aim for low coupling which reduces the impact of changes and increases independence of modules.
7. Cohesion - The degree to which the elements inside a module belong together. Aim for high cohesion where all elements of a module serve a common purpose. This increases understandability and maintainability.

The points above cover key concepts that can be applied to designing software with a structured methodology. Following these concepts leads to software that is modular, flexible, maintainable and understandable.
