##### Function Point (FP) Based Measures in software design

1. Function Point Analysis (FPA) is a technique to measure the size of software based on its functionality.
2. It counts the number of functions or components of the software based on defined criteria and assigns weightage to them to arrive at an aggregate score called Function Point (FP).
3. The five major components considered in FPA are -
- Inputs: User inputs to the system like input screens or interfaces.
- Outputs: Outputs provided by the system like reports or output screens.
- Files: Logical files maintained by the system like databases or files.
- External interfaces: Interfaces with other systems.
- Enquiries: Complex logic processing done in the system.
4. Each component is assigned a weightage and the total weighted count provides the Function Point count for the software.
5. FP count can then be used to estimate effort and cost for software development using empirically derived productivity rates.
6. FPA is a logical and structured technique to provide size-based software metrics without relying on lines of code which can be misleading at times. However, accurate assessment of weightage for components requires experience.
