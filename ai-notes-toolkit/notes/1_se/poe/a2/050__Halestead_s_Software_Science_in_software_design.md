##### Halstead's Software Science in Software Design

1. Halstead's Software Science is a quantitative method to measure the complexity and quality of a software program based on the length and difficulty of the vocabulary used.
2. It measures the software complexity in terms of:
- Program length: Measured in terms of distinct operators and operands used.
- Program vocabulary: Measured in terms of total number of distinct symbolic names or identifiers used.
3. Using the measures of program length and vocabulary, Halstead's Software Science calculates the following software metrics:
- Program difficulty: Computed using the program length. Higher length indicates higher difficulty to write and understand the program.
- Program effort: Estimated person-months required to develop the software. Computed based on program difficulty. Higher difficulty leads to higher effort.
- Program time: Estimated elapsed time in months to develop the software.
- Program bugs: Estimated number of bugs in the software. Computed based on program difficulty and length. More complex and longer software tends to have more bugs.
4. These software metrics can help designers and programmers make early estimates of resources and time required for software projects. They also indicate the complexity and quality of software which impacts maintenance and evolution.
5. However, Halstead's Software Science has some limitations:
- It only considers the syntactic features of the software and ignores the semantic aspects.
- It may not be very accurate for modern software built using ready-made libraries and tools.
- The computed metrics are only rough estimates and not precise measures.
- The vocabulary measure can be misleading for software using shorthand notations.
