### Architectural Design in Software Design

1. Introduction
- Software architecture refers to the fundamental structures of a software system and the discipline of creating such structures and systems.
- It involves decisions regarding the organization of a software system into components and connectors and the composition of these elements into a successful system.

2. Goals of Software Architecture
- The primary goals of software architecture are:
-- Functionality: The architecture must satisfy functional requirements of the system.
-- Performance: The architecture must enable the system to meet performance goals.
-- Modifiability: The architecture must be structured to accommodate changes in requirements and environment.
-- Reliability: The architecture must enable the system to meet availability and other reliability goals.
-- Cost-effectiveness: The architecture must enable the system to be developed and maintained cost-effectively.

3. Architectural Styles
- The architectural style refers to a generic template or pattern followed in designing the architecture of a software system. Some of the key architectural styles are:
-- Client-Server: Separates the system into servers that provide resources or services and clients that consume the resources or services.
-- Layered: Organizes components into hierarchical layers, each layer providing service to the next higher layer.
-- Event-driven: Systems where components interact by generating, detecting, and reacting to events.
-- Microkernel: The idea is to minimize the functionalities in the kernel and implement most of the system's functionality outside the kernel.
-- Pipe and filter: Components are connected in a pipeline, and the output of each component is the input of the next one.
