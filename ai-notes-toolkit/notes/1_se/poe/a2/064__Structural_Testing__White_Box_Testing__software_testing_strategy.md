#### Structural Testing (White Box Testing) software testing strategy

- Focuses on the internal structure of the software to identify issues.
- Tests are designed based on the internal logic and structure of the code.
- Helps to identify issues related to bad programming practices and logical errors.
- Usually done by the developers as they have access to the code.
- Various techniques used:
-- Statement coverage - ensuring each line of code is executed.
-- Branch coverage - ensuring each branch of every conditional statement is executed.
-- Path coverage - ensuring each possible route through a code is executed.
-- Syntax checking - checking the code follows the language syntax rules.
- Challenges:
-- Complex paths and iterations make exhaustive testing impossible.
-- Presence of loops and conditions makes it difficult to determine test coverage.
-- Additional effort required to write structural tests compared to black box tests.
