#### Various Size Oriented Measures in Software Design

1. Lines of Code (LOC): It refers to the number of lines of code in a software. It is a basic measure to get an idea of the size of software. However, it does not consider the complexity of individual lines of code.

2. Function Points (FP): It refers to a functional size measurement of software. It counts various functional components of software like inputs, outputs, inquiries, files, etc. It aims to quantify the functionality of software in a standardized manner. However, it may not be applicable to software using new technologies or programming languages.

3. Object Points (OP): It is an object-oriented equivalent of function points. It counts various objects and their interactions in software to determine the functional size. However, it faces challenges in dealing with newer object-oriented concepts and technologies.

The above points describe some common size oriented measures in software design. However, they have their own limitations and may not be sufficient to determine the exact effort and cost required for software development. They can be used along with other attributes like complexity, reusability, etc. to get a holistic view of software size and cost.
