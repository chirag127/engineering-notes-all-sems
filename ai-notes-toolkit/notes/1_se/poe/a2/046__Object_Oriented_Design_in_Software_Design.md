#### Object Oriented Design in Software Design

1. Classes and Objects: Software applications are designed using classes and objects. A class is a blueprint that defines the structure and behaviors of a type of object. An object is an instance of a class that has its own state, data, and behaviors.

2. Encapsulation: The process of hiding the internal details of a class from the outside world. Only the required interfaces are exposed in the form of public methods. This helps in maintaining the integrity of the object.

3. Inheritance: The process of creating a child class from a parent class. The child class inherits all the properties and behaviors of the parent class and can also have its own additional properties and behaviors. This helps in reusability of code.

4. Polymorphism: The ability of an object to take on multiple forms based on the context. The same interface can exhibit different behaviors in different scenarios. This allows us to perform a single action in different ways.

5. Abstraction: Hiding the complexity of lower level details and showing only essential features. This helps the user to focus on what the object does instead of how it does it.

The above are the fundamental concepts of Object Oriented Design which help in modeling real world problems in the form of software applications in an efficient, reusable, and maintainable manner. The design should be simple, loosely coupled, and extensible.
