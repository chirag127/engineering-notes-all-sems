#### Compliance with Design and Coding Standards (Coding Standards) Static testing strategy

1. Check for adherence to coding standards
- Ensure proper naming conventions are followed for variables, methods, classes, etc.
- Check for proper indentation and spacing
- Check for comments in the code wherever required
- Check for maximum line length adherence
- Check for proper use of whitespace
- Check for consistent style of braces, parentheses, etc.

2. Check for compliance with design standards
- Check if UI matches design specs in terms of spacing, fonts, colors, alignment, etc.
- Check if responsive design requirements are met
- Check if UI is intuitive and easy to use
- Check if UI is accessible
- Check if UI is consistent across pages/modules

3. Check for cross-browser compatibility
- Check visual display of the application in different browsers
- Check for any functionality issues in different browsers
- Address any cross-browser issues found

4. Check for device compatibility
- Check visual display and functionality of the app in different devices (mobile, tablet, desktop)
- Address any device-specific issues found

The above points cover some of the key things to check for as part of static testing to ensure compliance with coding and design standards. Thorough testing and fixing of issues found leads to a higher quality product.
