### Design Strategies in Software Design

1. Modular Design: Breaking down the system into multiple modules that are interconnected. Each module is designed to perform a specific task/function. This makes the system extendable and reusable.
2. Abstraction: Hiding the complexity of lower level details and showing only essential features to the user. This makes the system easy to understand and use.
3. Information Hiding: Hiding the implementation details of a module from other modules and revealing only the interfaces. This reduces dependencies between modules.
4. Layered Design: Dividing the system into multiple layers where each layer provides services to the layer above it. The layers are highly cohesive and loosely coupled. This makes the design robust, reusable and extendable.
5. Object Oriented Design: Modeling the problem as a set of objects that encapsulate data and methods. The objects interact with each other through well-defined interfaces. This makes the system modular, reusable and flexible.
6. Design Patterns: These are tested and proven solutions to commonly occurring design problems. Applying design patterns makes the design more robust, flexible and reusable. Some examples are Strategy, Observer, Factory etc.
