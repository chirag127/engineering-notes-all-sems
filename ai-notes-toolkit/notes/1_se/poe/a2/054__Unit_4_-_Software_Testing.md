## Unit 4 - Software Testing

1. Software testing is a process of evaluating a software product to identify differences between expected and actual outcomes. It helps check if the software meets the required specifications and ensures quality.
2. The key objectives of software testing are:
- Finding defects which may get unidentified otherwise.
- Determining if the software meets specifications and requirements.
- Preventing defects from reaching the customer.
- Evaluating whether the software is usable and satisfactory.
3. The different types of software testing are:
- Unit testing: Testing individual modules or components of the software.
- Integration testing: Testing combined modules or components.
- System testing: Testing the complete software product as a whole.
- Acceptance testing: Testing by the customer to accept or reject the software.
4. The steps involved in software testing process are:
- Test planning and control: Planning the testing activities and tracking progress.
- Test analysis and design: Analyzing the software and identifying test scenarios.
- Test implementation and execution: Implementing tests and executing the software.
- Evaluating exit criteria and reporting: Checking if exit criteria are met and reporting defects.
- Test closure: Finalizing testing and closing the project.
