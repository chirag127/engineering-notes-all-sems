### Design Strategies in Software Design

There are several design strategies in software design, including top-down design, bottom-up design, and iterative design. Here is an ASCII diagram that illustrates these strategies:

```
+---------------------+
|  Software Design    |
+---------------------+
|                     |
|   +-------------+   |
|   | Top-Down    |   |
|   +-------------+   |
|                     |
|   +-------------+   |
|   | Bottom-Up   |   |
|   +-------------+   |
|                     |
|   +-------------+   |
|   | Iterative   |   |
|   +-------------+   |
|                     |
+---------------------+
```

In top-down design, the overall system is first defined, and then broken down into smaller components. In bottom-up design, the individual components are first designed and then combined to form the overall system. In iterative design, the system is designed, tested, and refined in a cyclical process until the desired result is achieved.
