Function Point (FP) Based Measures in software design is a technique used to measure the size and complexity of a software system. It is based on the user's view of the system and takes into account the functionality provided by the system.

Here is an ASCII diagram that illustrates the components of Function Point (FP) Based Measures in software design:

```
+----------------+
|                |
|  User Inputs   |
|                |
+-------+--------+
        |
        |
+-------+--------+
|                |
| User Inquiries |
|                |
+-------+--------+
        |
        |
+-------+--------+
|                |
|  User Outputs  |
|                |
+-------+--------+
        |
        |
+-------+--------+
|                |
|  Internal      |
|  Logical Files |
|                |
+-------+--------+
        |
        |
+-------+--------+
|                |
| External       |
| Interface Files|
|                |
+----------------+
```

Each of these components represents a different type of functionality provided by the system. User Inputs represent the data that is entered into the system by the user. User Inquiries represent the requests for information made by the user. User Outputs represent the data that is generated by the system in response to user requests. Internal Logical Files represent the data that is stored and maintained within the system. External Interface Files represent the data that is exchanged between the system and other external systems.
