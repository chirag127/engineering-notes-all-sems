## Unit 3 - Software Design

Software design is the process of defining software methods, functions, objects, and the overall structure and interaction of the code so that the resulting functionality will satisfy the user's requirements.

1. **Design principles:** There are several design principles that are important to follow when designing software. These include modularity, abstraction, encapsulation, coupling, cohesion, and separation of concerns.

2. **Design patterns:** Design patterns are reusable solutions to common problems in software design. They provide a template for solving a problem that can be used in many different situations. Some common design patterns include the Singleton pattern, the Observer pattern, and the Factory pattern.

3. **Architecture:** The architecture of a software system refers to the overall structure of the system and the relationships between its components. There are several common architectural styles, including layered, client-server, and event-driven architectures.

4. **UML:** The Unified Modeling Language (UML) is a graphical language for visualizing, specifying, constructing, and documenting the artifacts of a software-intensive system. UML provides several types of diagrams, including use case diagrams, class diagrams, and sequence diagrams.

5. **Mnemonics and learning tricks:** A helpful mnemonic to remember the design principles is **MACCSOS** (Modularity, Abstraction, Coupling, Cohesion, Separation of concerns). Another helpful trick is to remember that design patterns provide **reusable solutions** to common problems.

6. **Advantages of good software design:** Good software design can make the code easier to understand, maintain, and extend. It can also improve the performance and reliability of the software.

7. **Disadvantages of poor software design:** Poor software design can make the code difficult to understand, maintain, and extend. It can also lead to poor performance and reliability.

8. **Examples:** An example of good software design is the use of the Model-View-Controller (MVC) pattern in web development. This pattern separates the concerns of the data (model), the user interface (view), and the control logic (controller) into separate components.

9. **Applications:** Software design is applicable to any software development project, including web development, mobile development, and desktop application development.
