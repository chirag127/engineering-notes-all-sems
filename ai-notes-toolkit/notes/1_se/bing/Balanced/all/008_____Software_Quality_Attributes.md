### Software Quality Attributes

- Software quality attributes are the non-functional requirements that describe how well a software system performs its functional requirements.
- Software quality attributes are also known as quality factors, quality characteristics, or quality criteria.
- Software quality attributes can be classified into two categories: external and internal.
  - External quality attributes are those that are visible to the users and stakeholders of the software system, such as usability, reliability, security, performance, etc.
  - Internal quality attributes are those that are related to the internal structure and design of the software system, such as modularity, maintainability, testability, reusability, etc.
- Software quality attributes can be measured using various metrics, such as defect density, mean time to failure, response time, cyclomatic complexity, cohesion, coupling, etc.
- Software quality attributes can be specified using various techniques, such as quality attribute scenarios, quality attribute trees, quality attribute checklists, etc.
- Software quality attributes can be achieved using various methods, such as design patterns, coding standards, testing strategies, refactoring, etc.
- Software quality attributes can be traded off against each other, depending on the priorities and constraints of the software project. For example, increasing performance may decrease modularity, or increasing security may decrease usability.
- Software quality attributes can be remembered using the acronym FURPS+, which stands for Functionality, Usability, Reliability, Performance, Security, and other attributes such as Compatibility, Maintainability, Portability, etc.
