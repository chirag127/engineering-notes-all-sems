### Software Re- Engineering (SR) of Software

- Software Re-Engineering is the examination and alteration of a system to reconstitute it in a new form .
- Software Re-Engineering is a process of software development which is done to improve the maintainability, quality, performance, and customer service of a software system  .
- Software Re-Engineering involves a combination of sub-processes such as reverse engineering, forward engineering, reconstructing, etc.
- Reverse engineering is the process of analyzing the existing software system to extract its design and specification.
- Forward engineering is the process of creating a new software system from the extracted design and specification.
- Reconstructing is the process of modifying the existing software system to improve its structure, readability, and documentation.
- Software Re-Engineering can be applied to any software system, regardless of its size, complexity, or technology.
- Software Re-Engineering can be beneficial for software systems that are outdated, poorly designed, poorly documented, or difficult to maintain.
- Software Re-Engineering can also be used to add new features, functionalities, or capabilities to the software system.
- Software Re-Engineering can be performed in different stages, such as inventory analysis, document restructuring, code restructuring, data restructuring, and testing.
- Inventory analysis is the process of identifying and evaluating the existing software system and its components.
- Document restructuring is the process of improving the quality and consistency of the software documentation.
- Code restructuring is the process of improving the quality and readability of the software code.
- Data restructuring is the process of improving the quality and organization of the software data.
- Testing is the process of verifying the functionality and performance of the re-engineered software system.

A possible mnemonic to remember the stages of software re-engineering is:

**I Do Code Data Testing** (Inventory analysis, Document restructuring, Code restructuring, Data restructuring, Testing)
