##### Cyclomatic Complexity Measures in software design

- Cyclomatic complexity is a software metric used to measure the complexity of a program .
- It is a count of the number of decisions in the source code. The more decisions that have to be made in code, the more complex it is.
- It is calculated by using the formula: **Cyclomatic complexity = E - N + 2**, where E is the number of edges and N is the number of nodes in the control flow graph of the program .
- Cyclomatic complexity can be used to:
  - Estimate the number of test cases required to cover all the possible paths in the program .
  - Identify the high-risk modules that are more prone to errors and need more testing and maintenance.
  - Improve the quality and readability of the code by reducing the complexity .
