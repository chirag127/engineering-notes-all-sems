#### Compliance with Design and Coding Standards (Coding Standards) Static testing strategy

- Static testing is a technique of verifying the quality and correctness of software artifacts, such as requirements, design, code, and test cases, without executing them.
- Static testing can be performed manually or with the help of tools, such as code analyzers, code reviews, inspections, walkthroughs, and audits.
- Static testing can help to detect defects, errors, inconsistencies, ambiguities, deviations, and violations of design and coding standards at an early stage of the software development life cycle.
- Design and coding standards are a set of rules, guidelines, and best practices that define how software artifacts should be created, formatted, documented, and maintained.
- Design and coding standards can help to improve the readability, maintainability, portability, reusability, testability, and security of software artifacts.
- Design and coding standards can also help to reduce the complexity, redundancy, coupling, and technical debt of software artifacts.
- Compliance with design and coding standards can be checked by using static testing techniques, such as:

  - Code analyzers: Tools that automatically scan the source code and report any violations of syntax, style, complexity, naming conventions, and other rules defined by the standards.
  - Code reviews: Processes that involve examining the source code by one or more reviewers, who can be peers, seniors, or experts, and providing feedback and suggestions for improvement.
  - Inspections: Formal and structured processes that involve a team of reviewers, who follow a predefined checklist and procedure, and identify any defects, errors, or non-compliance issues in the software artifacts.
  - Walkthroughs: Informal and unstructured processes that involve presenting the software artifacts to a group of stakeholders, who can ask questions, raise concerns, or provide comments.
  - Audits: Independent and objective processes that involve verifying the compliance of the software artifacts with the standards, as well as the effectiveness of the static testing techniques and tools used.
