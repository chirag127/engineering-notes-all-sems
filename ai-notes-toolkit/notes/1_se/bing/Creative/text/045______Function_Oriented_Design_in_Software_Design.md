#### Function Oriented Design in Software Design

- Function oriented design is a software design methodology that focuses on the decomposition of a system into a set of functions or modules that perform specific tasks.
- Function oriented design is based on the principle of abstraction, which means hiding the details of how a function works and exposing only its inputs, outputs and effects.
- Function oriented design follows a top-down approach, which means starting from the highest level of abstraction and breaking down the system into smaller and simpler functions or modules.
- Function oriented design uses techniques such as functional decomposition, data flow diagrams, structure charts and pseudocode to represent the functions or modules and their relationships.
- Function oriented design aims to achieve modularity, cohesion, coupling and reusability in software design.
- Modularity is the degree to which a system is composed of independent and interchangeable functions or modules.
- Cohesion is the degree to which a function or module performs a single and well-defined task.
- Coupling is the degree to which a function or module depends on or interacts with other functions or modules.
- Reusability is the degree to which a function or module can be used in different contexts or applications without modification.
