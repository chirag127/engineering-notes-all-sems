### Key concepts and measures in network analysis for the notes of the Unit 1 - Social Network Analysis in the subject of SOCIAL NETWORK ANALYTICS

1. **Nodes**: Nodes represent the individual entities in a network, such as people, organizations, or countries.
2. **Edges**: Edges represent the relationships or connections between nodes in a network.
3. **Degree**: Degree is a measure of the number of edges connected to a node. It is used to determine the importance or centrality of a node in a network.
4. **Betweenness Centrality**: Betweenness centrality is a measure of the extent to which a node lies on the shortest paths between other nodes in a network. It is used to identify nodes that serve as bridges or gatekeepers in a network.
5. **Closeness Centrality**: Closeness centrality is a measure of how close a node is to all other nodes in a network. It is used to identify nodes that can quickly reach other nodes in a network.
6. **Eigenvector Centrality**: Eigenvector centrality is a measure of the influence of a node in a network. It takes into account not only the number of edges connected to a node, but also the centrality of the nodes it is connected to.
7. **Clustering Coefficient**: The clustering coefficient is a measure of the extent to which nodes in a network tend to cluster together. It is used to identify tightly-knit groups or communities within a network.
8. **Modularity**: Modularity is a measure of the strength of the division of a network into communities or modules. It is used to identify the optimal division of a network into communities.
9. **Assortativity**: Assortativity is a measure of the tendency of nodes in a network to connect to other nodes that are similar to them in some way, such as having the same degree or belonging to the same community.
10. **Homophily**: Homophily is the tendency of individuals to associate and bond with others who are similar to them in some way, such as having the same race, gender, or socio-economic status.
