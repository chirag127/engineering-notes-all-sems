### Storage and Reasoning for the Notes of the Unit 5 - Evaluation of Social Network Analysis in the Subject of SOCIAL NETWORK ANALYTICS

1. Storage and reasoning are important components of social network analysis.
2. Storage refers to the methods and techniques used to store and organize data collected from social networks.
3. Reasoning refers to the process of drawing conclusions and making decisions based on the data collected from social networks.
4. Social network analysis involves the collection and analysis of large amounts of data, making efficient storage and reasoning essential for effective evaluation.
5. Various storage techniques, such as relational databases and graph databases, can be used to store and organize social network data.
6. Reasoning techniques, such as machine learning and statistical analysis, can be used to draw insights and make decisions based on the data collected from social networks.
7. The choice of storage and reasoning techniques will depend on the specific needs and goals of the social network analysis being conducted.
8. Effective storage and reasoning can help improve the accuracy and reliability of social network analysis, leading to more informed decision-making.
