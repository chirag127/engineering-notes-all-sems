### The features of Flink for the notes of the Unit 4 - Developing Social-Semantic Applications in the subject of SOCIAL NETWORK ANALYTICS

Apache Flink is a versatile processing framework that can handle any kind of stream. Here are some of its notable features:

1. **Real-time ordering**: Flink can process data in real-time, allowing for immediate ordering of data .
2. **Real-Time Tracking**: Flink can track data in real-time .
3. **Real-Time Discounts**: Flink can offer real-time discounts .
4. **Real-Time Delivery Navigation**: Flink can provide real-time delivery navigation .
5. **Real-Time Personalized Shopping**: Flink can offer real-time personalized shopping .
6. **Bounded and unbounded streams**: Streams can be unbounded or bounded, i.e., fixed-sized data sets. Flink has sophisticated features to process unbounded streams, but also dedicated operators to efficiently process bounded streams .
7. **Sophisticated state management**: Flink has sophisticated state management features .
8. **Event-time processing semantics**: Flink has event-time processing semantics .
9. **Exactly-once consistency guarantees for state**: Flink has exactly-once consistency guarantees for state .
10. **Deployment on various resource providers**: Flink can be deployed on various resource providers such as YARN and Kubernetes, but also as stand-alone cluster on bare-metal hardware .
11. **High speed with low latency**: Flink processes events at a consistently high speed with low latency .
12. **Designed to run in all common cluster environments**: Flink has been designed to run in all common cluster environments .
13. **Perform computations at in-memory speed and at any scale**: Flink can perform computations at in-memory speed and at any scale .
