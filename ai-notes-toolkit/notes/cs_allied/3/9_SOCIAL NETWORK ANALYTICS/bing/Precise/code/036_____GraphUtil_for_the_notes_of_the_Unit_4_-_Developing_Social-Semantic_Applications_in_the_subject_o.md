### GraphUtil
GraphUtil is a utility class that provides a set of methods for working with graphs in the context of social network analysis. These methods can be used to perform common operations on graphs, such as calculating centrality measures, finding communities, and generating random graphs.

Some of the key methods provided by GraphUtil include:
- `degree_centrality(graph)`: Calculates the degree centrality of each node in the given graph.
- `betweenness_centrality(graph)`: Calculates the betweenness centrality of each node in the given graph.
- `closeness_centrality(graph)`: Calculates the closeness centrality of each node in the given graph.
- `eigenvector_centrality(graph)`: Calculates the eigenvector centrality of each node in the given graph.
- `find_communities(graph)`: Finds the communities in the given graph using a community detection algorithm.
- `generate_random_graph(n, p)`: Generates a random graph with n nodes and edge probability p.

These methods can be used in the development of social-semantic applications to analyze and understand the structure and dynamics of social networks. By using GraphUtil, developers can easily incorporate social network analysis techniques into their applications and gain insights into the behavior of users and the relationships between them.
