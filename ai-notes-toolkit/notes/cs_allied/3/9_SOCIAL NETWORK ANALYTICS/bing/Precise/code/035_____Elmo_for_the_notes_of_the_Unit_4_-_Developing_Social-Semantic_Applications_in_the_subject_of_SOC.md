### Elmo for the notes of the Unit 4 - Developing Social-Semantic Applications in the subject of SOCIAL NETWORK ANALYTICS

- Elmo is a deep contextualized word representation that models both complex characteristics of word use and how these uses vary across linguistic contexts.
- Elmo is used to improve the performance of many natural language processing tasks, including sentiment analysis, named entity recognition, and machine translation.
- Elmo is a pre-trained model that can be fine-tuned for specific tasks, allowing for the development of social-semantic applications that combine human intelligence with machine processing.
- Elmo returns context-dependent token embeddings, which can be compared to estimate semantic shift. This can be done by clustering token embeddings and looking at word occurrences as belonging to several clusters .
- The use of Elmo in developing social-semantic applications can lower the threshold for developing Semantic Web applications in general and social network applications in particular .
