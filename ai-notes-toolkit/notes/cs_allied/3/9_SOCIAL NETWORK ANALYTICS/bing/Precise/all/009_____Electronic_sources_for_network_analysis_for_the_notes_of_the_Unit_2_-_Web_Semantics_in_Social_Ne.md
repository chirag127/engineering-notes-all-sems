# Electronic sources for network analysis

Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS

1. **Web crawlers:** Web crawlers are programs that automatically browse the web and collect data from web pages. They can be used to gather data on social networks for network analysis.

2. **APIs:** Many social networking sites provide APIs (Application Programming Interfaces) that allow developers to access data from their platforms. This data can be used for network analysis.

3. **Online databases:** There are many online databases that contain data on social networks. These databases can be accessed and the data can be used for network analysis.

4. **Web scraping:** Web scraping is the process of extracting data from websites. This technique can be used to gather data on social networks for network analysis.

5. **Surveys and questionnaires:** Surveys and questionnaires can be used to gather data on social networks. This data can then be used for network analysis.

6. **Published research:** There is a large body of published research on social networks. This research can be used as a source of data for network analysis.
