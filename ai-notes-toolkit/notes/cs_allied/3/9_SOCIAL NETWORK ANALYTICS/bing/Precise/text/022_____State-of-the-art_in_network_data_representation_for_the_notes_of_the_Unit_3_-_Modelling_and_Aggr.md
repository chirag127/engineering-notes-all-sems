### State-of-the-art in network data representation

1. Network representation learning (NRL) approaches have led to state-of-the-art results in network-based tasks, such as node classification, node clustering, and link prediction.
2. These approaches remove the need for painstaking feature engineering.
3. State-of-the-art network representation learning techniques can be categorized and summarized according to the underlying learning mechanisms, the network information intended to preserve, as well as the algorithmic designs and methodologies.
4. In a generic setup, a user uses a state-of-the-art pre-trained model and weights to get a useful representation of the input, which is then fed to a user-designed top model.
5. This top model is usually a much smaller model containing one or two hidden layers, thus reducing runtime and solving the problem more efficiently.
