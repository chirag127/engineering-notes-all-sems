# The features of Flink for the notes of the Unit 4 - Developing Social-Semantic Applications

- Flink is a system that uses semantic web technology to extract and analyze social networks from various electronic information sources .
- Flink can process both stream and batch data with the same semantics and results using its unified relational APIs, the Table API and SQL.
- Flink supports event-time processing, which allows applications to compute results based on the timestamps of the events, regardless of whether they are recorded or real-time.
- Flink provides sophisticated state management and exactly-once consistency guarantees for stateful applications.
- Flink can be deployed on various resource providers such as YARN and Kubernetes, as well as stand-alone clusters on bare-metal hardware.
