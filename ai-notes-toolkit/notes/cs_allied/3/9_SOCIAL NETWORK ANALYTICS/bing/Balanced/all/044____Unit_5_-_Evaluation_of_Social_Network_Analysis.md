## Unit 5 - Evaluation of Social Network Analysis

- Social network analysis (SNA) is a method of studying the structure, dynamics, and effects of social relationships among actors (individuals, groups, organizations, etc.).
- SNA can be used for various purposes, such as understanding social phenomena, identifying influential actors, detecting communities, predicting behaviors, and designing interventions.
- Evaluation of SNA involves assessing the quality, validity, reliability, and usefulness of the data, methods, models, and results of SNA.
- Evaluation of SNA can be done at different stages of the research process, such as data collection, data analysis, data visualization, and data interpretation.
- Evaluation of SNA can be done by using different criteria, such as accuracy, completeness, consistency, relevance, timeliness, and ethics.
- Evaluation of SNA can be done by using different methods, such as descriptive statistics, inferential statistics, network metrics, network models, network algorithms, and network simulations.
- Evaluation of SNA can be done by using different tools, such as software, frameworks, standards, and guidelines.
- Evaluation of SNA can be done by using different perspectives, such as internal, external, formative, summative, process, outcome, and impact.
- Evaluation of SNA can be done by using different sources, such as self-evaluation, peer review, expert review, stakeholder feedback, and user feedback.
- Evaluation of SNA can be done by using different strategies, such as triangulation, validation, verification, replication, and generalization.
