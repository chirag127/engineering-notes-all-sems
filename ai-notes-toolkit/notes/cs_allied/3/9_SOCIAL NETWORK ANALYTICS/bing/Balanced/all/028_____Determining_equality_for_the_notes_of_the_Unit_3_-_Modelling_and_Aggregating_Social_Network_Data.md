# Determining Equality for the Notes of the Unit 3 - Modelling and Aggregating Social Network Data in the Subject of Social Network Analytics

- In this unit, we will learn how to model and aggregate social network data using ontologies and semantic web technologies.
- Ontologies are formal representations of the concepts and relationships in a domain of interest, such as social networks.
- Semantic web technologies are standards and tools that enable the representation, exchange, and reasoning with ontologies and data on the web.
- Some of the semantic web technologies we will use are:
  - Resource Description Framework (RDF): a language for expressing data as triples of subject, predicate, and object.
  - Web Ontology Language (OWL): a language for defining and reasoning with ontologies.
  - SPARQL Protocol and RDF Query Language (SPARQL): a language for querying and manipulating RDF data.
- We will also learn how to use some ontology-based tools, such as Protégé and Jena, to create and manipulate ontologies and RDF data.
- The main objectives of this unit are:
  - To understand the role and benefits of ontologies and semantic web technologies for modelling and aggregating social network data.
  - To learn how to represent social network data as RDF triples and store them in an ontology store.
  - To learn how to define and use ontologies to describe the concepts and relationships in social networks.
  - To learn how to query and manipulate RDF data using SPARQL.
  - To learn how to apply ontology-based reasoning to infer new knowledge from social network data.
