# Representing identity

- Identity is the set of attributes and characteristics that define who a person or an entity is in a social network.
- Identity can be represented by nodes in a graph, where each node has a unique identifier and a set of features or properties that describe it.
- Identity can also be represented by the relationships or interactions that a node has with other nodes in the network, which are captured by edges in the graph.
- Identity can be influenced by the structure and dynamics of the network, such as the degree, centrality, clustering, and community of a node.
- Identity can be learned and inferred from the network data using various methods, such as network analysis, network science, and deep representation learning.

## Network analysis
- Network analysis is the practice of representing networks of people as graphs and then exploring these graphs.
- Network analysis can help measure and visualize the set of actors (nodes) that comprise the network, with a series of lines (edges) that represent relationships or engagement between two entities.
- Network analysis can also help identify the important or influential nodes in a network, which is called measuring network centrality.
- Network analysis can be applied to different domains and types of networks, such as social, communication, learning, epidemiology, and terrorist networks.

## Network science
- Network science is a field of data analytics that uses networks and graph theory to understand social structures.
- Network science can help discover patterns and phenomena from the interactions between nodes, such as diffusion, contagion, cascades, and homophily.
- Network science can also help model and simulate the behavior and evolution of networks, such as network formation, growth, and dynamics.
- Network science can be used to study networks outside of the societal realm, such as biological, ecological, technological, and physical networks.

## Deep representation learning
- Deep representation learning is a method of learning and extracting features or representations from network data using deep neural networks.
- Deep representation learning can help summarize the interests and opinions of nodes, as well as the strength and type of edges, in a low-dimensional vector space.
- Deep representation learning can also help perform various tasks on network data, such as node classification, link prediction, community detection, and anomaly detection.
- Deep representation learning can be used to analyze social networks, as well as other complex and heterogeneous networks, such as knowledge graphs, citation networks, and recommender systems.
