### Descriptive analysis for the notes of the Unit 5 - Evaluation of Social Network Analysis

- Social network analysis (SNA) is a research method that studies the patterns of relations among social entities, such as individuals, groups, organizations, or states  .
- SNA can be used to understand the structure, dynamics, and outcomes of social networks, and how they influence various phenomena, such as health, communication, innovation, or conflict  .
- SNA relies on mathematical and graphical tools, such as graph theory, matrices, and network diagrams, to represent and analyze social networks   .
- Descriptive analysis is a basic step in SNA that aims to summarize the main features and properties of a social network, such as its size, density, centrality, clustering, and cohesion.
- Descriptive analysis can provide useful information about the characteristics and roles of the network actors, the distribution and strength of the network ties, and the overall shape and complexity of the network structure.
- Descriptive analysis can also help to identify potential problems or limitations of the network data, such as missing values, outliers, or errors.
- Descriptive analysis can be performed using various software tools, such as UCINET, Pajek, Gephi, or R, that can handle different types of network data, such as binary, valued, directed, or weighted.
- Descriptive analysis can be complemented by inferential analysis, which aims to test hypotheses and causal relationships among network variables, using statistical techniques, such as regression, correlation, or ANOVA.
- Descriptive analysis can also be followed by exploratory analysis, which aims to discover patterns and insights from the network data, using methods such as clustering, community detection, or visualization.
- Descriptive analysis is an essential and foundational skill for any SNA researcher or practitioner, as it provides a comprehensive and systematic overview of the network under study.
