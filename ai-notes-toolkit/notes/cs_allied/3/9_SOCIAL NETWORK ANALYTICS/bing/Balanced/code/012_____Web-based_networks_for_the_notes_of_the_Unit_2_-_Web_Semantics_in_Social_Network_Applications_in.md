### Web-based networks for the notes of the Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS

- Web-based networks are networks that are hosted on the web and connect people and organizations through various online platforms and channels.
- Web semantics is the study of the meaning and structure of the data and information on the web, such as web pages, hyperlinks, tags, metadata, etc.
- Social network applications are applications that use web-based networks to enable social interactions, communication, collaboration, and information sharing among users and groups.
- Social network analytics is the field of data analytics that uses web semantics and network science to understand and analyze the patterns, dynamics, and outcomes of social network applications.
- Some of the topics covered in this unit are:

  - Web-based social network models: how to represent and measure the structure and properties of web-based networks, such as nodes, links, attributes, centrality, density, clustering, etc.
  - Web-based social network analysis: how to use web semantics and network science techniques to discover and visualize the patterns and relationships in web-based networks, such as communities, influencers, topics, sentiments, etc.
  - Web-based social network applications: how to design and evaluate web-based social network applications that support various social and organizational goals, such as information diffusion, recommendation, collaboration, innovation, etc.

- Some of the tools and methods used in this unit are:

  - Web scraping and crawling: how to collect and extract data and information from web-based networks using APIs, libraries, and frameworks.
  - Web ontology and RDF: how to represent and query the meaning and structure of web-based data and information using web standards and languages.
  - Network analysis and graph algorithms: how to apply network science and graph theory concepts and methods to analyze and optimize web-based networks using software and libraries.
  - Social media analytics and visualization: how to use social media analytics tools and platforms to measure and visualize the performance and impact of web-based social network applications.
