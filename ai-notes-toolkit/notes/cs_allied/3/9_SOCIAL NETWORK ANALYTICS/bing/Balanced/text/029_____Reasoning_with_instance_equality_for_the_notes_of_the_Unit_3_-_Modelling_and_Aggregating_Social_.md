### Reasoning with instance equality

- Reasoning is the inference of new statements (facts) that necessarily follow from the set of known statements.
- Instance equality is the assumption that two entities in a social network are the same if they have the same name or identifier.
- Reasoning with instance equality can help us to aggregate and analyze social network data by:
  - Reducing the complexity and redundancy of the data by merging nodes that represent the same entity.
  - Enabling the application of logical rules and inference methods to derive new facts and relations from the data.
  - Enhancing the quality and accuracy of the data by resolving inconsistencies and conflicts among different sources.
- Some examples of reasoning with instance equality are:
  - If Alice follows Bob on Twitter and Bob follows Alice on Instagram, then we can infer that Alice and Bob are the same person on both platforms.
  - If John is a friend of Mary on Facebook and Mary is a friend of Jane on LinkedIn, then we can infer that John, Mary and Jane are all friends on both platforms.
  - If a supply chain network has two nodes with the same name or identifier, then we can infer that they are the same supplier or consumer and merge them into one node.
