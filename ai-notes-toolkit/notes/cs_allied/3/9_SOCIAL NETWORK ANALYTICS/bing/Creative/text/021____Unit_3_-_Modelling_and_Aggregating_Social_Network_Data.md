## Unit 3 - Modelling and Aggregating Social Network Data

- In this unit, you will learn how to model and aggregate social network data using various techniques and tools.
- You will learn how to represent social networks as graphs, where nodes are entities and edges are relationships.
- You will learn how to measure various properties of social networks, such as degree, centrality, clustering, and community structure.
- You will learn how to use network analysis tools, such as Gephi and NetworkX, to visualize and analyze social network data.
- You will learn how to use aggregation methods, such as sentiment analysis, topic modelling, and text summarization, to extract insights from social media data.
- You will learn how to apply these methods to real-world social network data sets, such as Twitter, Facebook, and Reddit.
