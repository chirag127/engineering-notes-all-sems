### Network analysis for the notes of the Unit 1 - Social Network Analysis in the subject of SOCIAL NETWORK ANALYTICS

- Network analysis means the mathematical analysis of complex working procedures in terms of a network of related activities.
- Network analysis is any process where network data is collected and analyzed to improve the performance, reliability, visibility, or security of the network.
- Network analysis is a set of techniques derived from network theory, which has evolved from computer science to demonstrate the power of social network influences.
- Network analysis can be used to depict relations among actors and to analyze the social structures that emerge from the recurrence of these relations.
- Network analysis can be applied to various domains, such as communication, transportation, epidemiology, sociology, economics, biology, etc.
- Network analysis can be performed using different methods, such as graph theory, matrix algebra, statistical inference, machine learning, etc.
- Network analysis can provide insights into the properties, patterns, dynamics, and functions of networks and their components, such as nodes, links, clusters, paths, centrality, density, etc.
- Network analysis can help to identify the key actors, groups, and roles in a network, as well as the sources, flows, and impacts of information, resources, and influence in a network.
- Network analysis can help to design, optimize, monitor, and troubleshoot networks, as well as to predict and prevent network failures, attacks, and anomalies.
- Network analysis can help to understand and improve the social and organizational aspects of networks, such as collaboration, cooperation, competition, trust, reputation, etc.
