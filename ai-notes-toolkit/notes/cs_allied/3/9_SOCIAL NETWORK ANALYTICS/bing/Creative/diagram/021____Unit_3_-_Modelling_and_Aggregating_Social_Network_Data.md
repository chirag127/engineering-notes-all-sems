## Unit 3 - Modelling and Aggregating Social Network Data

In this unit, you will learn how to:

- Represent social networks as graphs and matrices
- Analyze the structure and properties of social networks using graph theory and linear algebra
- Apply centrality measures, clustering algorithms, and community detection methods to identify important nodes and groups in social networks
- Aggregate and summarize social network data using descriptive statistics and visualization techniques

Some of the key concepts and methods covered in this unit are:

- Graphs and matrices: A graph is a mathematical object that consists of a set of nodes (or vertices) and a set of edges (or links) that connect pairs of nodes. A matrix is a rectangular array of numbers that can be used to store and manipulate graph data. Graphs and matrices can be used to model various types of social networks, such as friendship networks, citation networks, collaboration networks, etc.
- Graph theory and linear algebra: Graph theory is a branch of mathematics that studies the properties and patterns of graphs. Linear algebra is a branch of mathematics that deals with the operations and transformations of matrices and vectors. Graph theory and linear algebra can be used to analyze the structure and dynamics of social networks, such as the degree distribution, the shortest path, the diameter, the adjacency matrix, the Laplacian matrix, the eigenvalues and eigenvectors, etc.
- Centrality measures, clustering algorithms, and community detection methods: Centrality measures are numerical values that quantify the importance or influence of nodes in a graph. Clustering algorithms are methods that partition a graph into groups of nodes that are more densely connected within than between. Community detection methods are methods that identify groups of nodes that share some common attributes or properties. Centrality measures, clustering algorithms, and community detection methods can be used to identify key actors and subgroups in social networks, such as the hubs, the authorities, the bridges, the cliques, the k-cores, the modularity, the Louvain method, etc.
- Descriptive statistics and visualization techniques: Descriptive statistics are numerical values that summarize the characteristics of a data set, such as the mean, the median, the standard deviation, the skewness, the kurtosis, etc. Visualization techniques are methods that display data in graphical or pictorial forms, such as histograms, boxplots, scatterplots, heatmaps, network diagrams, etc. Descriptive statistics and visualization techniques can be used to aggregate and present social network data in a concise and informative way.
