### Comparison to the Entity/Relationship (E/R) model and the relational model

- The E/R model and the relational model are two popular data models in DBMS .
- The E/R model is an entity-specific data model that describes the data with entity set, relationship set and attributes . It is used to model the logical view of the system from a data perspective.
- The relational model is a table-specific data model that represents the data in the form of tables and relation between the data of those tables . It is used to map the structure and constraints of a database.
- The main differences between the E/R model and the relational model are  :
  - The E/R model deals with entities and their relations, while the relational model deals with tables and relation between the data of those tables.
  - The E/R model is a conceptual model that can be used as a blueprint in the initial phases of database development, while the relational model is a logical model that can be used to implement the database.
  - The E/R model supports complex data types and relationships, while the relational model supports simple data types and relationships.
  - The E/R model is more expressive and flexible, while the relational model is more structured and rigid.
  - The E/R model is more suitable for designing and analyzing the data requirements, while the relational model is more suitable for programming and querying the data.
