# Predicting the goodness of fit for the notes of the Unit 5 - Evaluation of Social Network Analysis

- Social network analysis (SNA) is a method of studying the patterns and structures of relationships between individuals or groups in a network.
- SNA can be used to understand various social phenomena, such as diffusion of information, influence, cooperation, conflict, and community formation.
- SNA can also be used to evaluate the effectiveness and impact of interventions that aim to change or improve the network structure or behavior of the actors.
- To evaluate SNA, one needs to compare the observed network data with some expected or theoretical network model that represents the underlying social process or mechanism that generates the network.
- A network model can be specified by a set of parameters that determine the probability of forming or maintaining a tie between any pair of actors in the network.
- A common way of estimating the parameters of a network model is to use maximum likelihood estimation (MLE), which finds the values of the parameters that maximize the likelihood of observing the given network data.
- However, MLE does not provide any information about how well the network model fits the data, or how well the model captures the salient features and characteristics of the network.
- Therefore, one needs to use some goodness-of-fit (GOF) measures or tests to assess the adequacy and validity of the network model.
- GOF measures or tests compare the observed network data with the expected network data generated by the model, and quantify the degree of similarity or discrepancy between them.
- There are different types of GOF measures or tests, depending on the level of analysis, the type of network model, and the type of network data.
- Some examples of GOF measures or tests are:

  - Chi-square test: A statistical test that compares the observed and expected frequencies of ties or attributes in the network, and tests whether the difference is significant or due to chance. The test statistic follows a chi-square distribution, and the null hypothesis is that the observed and expected frequencies are equal. The test is usually right-tailed, and the expected frequency for each cell needs to be at least five. 
  - Kolmogorov-Smirnov test: A non-parametric test that compares the observed and expected cumulative distribution functions (CDFs) of network statistics, such as degree, clustering, or distance, and tests whether the difference is significant or due to chance. The test statistic is the maximum absolute difference between the two CDFs, and the null hypothesis is that the two CDFs are equal. The test is sensitive to any deviation in the shape or location of the two CDFs. 
  - Stochastic blockmodel: A network model that partitions the actors into a predefined number of groups or blocks, and assumes that the probability of forming a tie between any pair of actors depends only on their block membership. The model can capture the heterogeneity and homophily of the network, and can be used to test the fit of different block structures to the network data. The model parameters can be estimated by MLE or other methods, such as variational inference or Markov chain Monte Carlo. 
  - GOF indices: Numerical measures that summarize the fit of a network model to the network data, based on some criteria or objectives. The indices can be based on the likelihood, the distance, the entropy, or the information of the network model and the network data. The indices can be used to compare different network models or different specifications of the same network model, and to select the best-fitting model. Some examples of GOF indices are Akaike information criterion (AIC), Bayesian information criterion (BIC), deviance information criterion (DIC), and minimum description length (MDL).
