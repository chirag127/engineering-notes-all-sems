# Web-based networks for the notes of the Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS

- Web-based networks are networks that use the web as a platform for connecting people and organizations, and for sharing and distributing information.
- Web-based networks can be analyzed using social network analysis (SNA), which is a research method that focuses on patterns of relations among nodes (such as individuals, groups, or websites) and edges (such as links, interactions, or flows) in a network.
- SNA can help understand the structure, dynamics, and functions of web-based networks, and how they affect and are affected by social phenomena such as communication, collaboration, influence, diffusion, and innovation.
- SNA can also help identify key actors, communities, and subgroups in web-based networks, and measure their properties, such as centrality, density, cohesion, diversity, and homophily.
- SNA can be applied to various types of web-based networks, such as:
  - Web hyperlink networks, which are networks of websites connected by hyperlinks, and can reflect the authority, popularity, and relevance of web pages and domains.
  - Web content networks, which are networks of web pages or documents that share similar or related content, and can reveal the topics, themes, and sentiments of web information.
  - Web social media networks, which are networks of users and content on social media platforms, such as Twitter, Facebook, YouTube, and Instagram, and can capture the online interactions, behaviors, and opinions of social media users.
  - Web semantic networks, which are networks of concepts and entities that are annotated or linked by semantic web technologies, such as RDF, OWL, and SPARQL, and can enable the integration, interoperability, and reasoning of web data.
- SNA can use various tools and techniques to collect, process, visualize, and analyze web-based network data, such as:
  - Web crawlers, which are programs that automatically retrieve web pages and follow hyperlinks to discover new web pages.
  - Web APIs, which are interfaces that allow access to web data and services from different platforms and applications, such as social media APIs that provide access to social media posts and metadata.
  - Web scraping, which is the process of extracting data from web pages using techniques such as parsing, filtering, and regular expressions.
  - Web mining, which is the application of data mining methods to web data, such as web content mining, web structure mining, and web usage mining.
  - Network analysis software, which are tools that can perform various network analysis tasks, such as network construction, network visualization, network metrics, network models, and network algorithms. Examples of network analysis software include Gephi, NodeXL, Pajek, UCINET, and Netlytic.
  - Network science, which is a field of data analytics that uses networks and graph theory to understand complex systems, such as web-based networks, and their properties, such as network topology, network robustness, network evolution, and network dynamics.
