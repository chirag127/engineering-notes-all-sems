### The Resource Description Framework (RDF) and RDF Schema for the notes of the Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS

- RDF is a standard model for data interchange on the Web.
- RDF represents data as a graph of nodes and edges, where nodes are resources (such as web pages, people, concepts, etc.) and edges are properties (such as labels, attributes, relations, etc.).
- RDF uses URIs (Uniform Resource Identifiers) to identify resources and properties, and XML (Extensible Markup Language) to serialize the data.
- RDF uses the idea of the XML namespace to effectively allow RDF statements to reference a particular RDF vocabulary or 'schema'.
- RDF Schema is a set of classes and properties using the RDF data model, providing basic elements for the description of ontologies.
- Ontologies are formal specifications of the concepts and relations in a domain of interest.
- RDF Schema defines the concepts of rdfs:Class, rdfs:subClassOf, rdfs:Property, rdfs:subPropertyOf, rdfs:domain, rdfs:range, and rdfs:label, among others.
- RDF Schema allows users to define their own vocabularies and hierarchies, and to reuse existing ones.
- RDF and RDF Schema are the foundation of the Semantic Web, which aims to make web data more meaningful and interoperable.
