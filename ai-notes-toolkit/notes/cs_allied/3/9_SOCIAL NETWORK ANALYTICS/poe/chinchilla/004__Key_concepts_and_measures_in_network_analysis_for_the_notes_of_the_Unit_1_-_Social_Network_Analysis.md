### Key concepts and measures in network analysis for the notes of the Unit 1 - Social Network Analysis in the subject of SOCIAL NETWORK ANALYTICS

In the field of social network analysis, there are several key concepts and measures that are important to understand. These concepts and measures are used to explore the structure and dynamics of social networks. Here are some of the most important ones:

1. Nodes: Nodes, also referred to as vertices, are the individual actors or entities within a network. These can be people, organizations, or any other type of entity that can be connected to others within the network.

2. Edges: Edges, also known as ties or links, are the connections between nodes in a network. These connections can be directed, where the connection flows in one direction, or undirected, where the connection is bidirectional.

3. Degree: The degree of a node is the number of edges that are connected to it. This measure is important because it indicates the level of connectivity that a node has within the network.

4. Centrality: Centrality measures the importance of a node within a network. There are several different types of centrality measures, including degree centrality, betweenness centrality, and eigenvector centrality.

5. Clustering: Clustering measures the extent to which nodes within a network tend to be connected to each other. This measure is important because it can indicate the presence of subgroups or cliques within the network.

6. Path length: Path length is the number of edges that must be traversed in order to move from one node to another within a network. This measure is important because it can indicate the ease or difficulty of information or influence flowing between nodes within the network.

7. Density: Density measures the extent to which the nodes within a network are interconnected. This measure is important because it can indicate the overall cohesion or fragmentation of the network.

8. Modularity: Modularity measures the degree to which the nodes within a network tend to be organized into distinct communities or modules. This measure is important because it can help identify the underlying structure of the network.

9. Network visualization: Network visualization techniques are used to help explore and understand the structure of a network. These techniques can include node-link diagrams, matrix representations, and other types of visualizations.

Understanding these key concepts and measures is essential for conducting social network analysis. By applying these measures to a given network, researchers can gain insights into the structure and dynamics of the social relationships that underlie the network.
