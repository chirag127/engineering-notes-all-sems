### Storage and Reasoning for the notes of the Unit 5 - Evaluation of Social Network Analysis

1. Storage of data
- Data collected from social networks is often very large in volume. Hence, scalable storage mechanisms are required to store the data.
- Distributed storage systems like Hadoop HDFS, MongoDB, CouchDB,etc. are used to store large volumes of social network data.
- The data has to be stored in a way that facilitates fast retrieval and analysis. Hence, optimized database schemas and indexing techniques are employed.

2. Reasoning over the data
- The stored data has to be analyzed to extract insights and derive meaning.
- Graph based algorithms are heavily used to analyze the connectivity and relationships in the social network. Metrics like degree centrality, betweenness centrality, PageRank, etc. are calculated.
- Machine learning and deep learning techniques are used to analyze the attributes and behaviors of users as well as to detect patterns and communities.
- Visualization techniques are utilized to represent the data and analysis in a easy to comprehend manner. Tools like Gephi, Sigmajs, etc. are used for network data visualization.

The above points summarize the key steps involved in storing and reasoning over the data obtained from social networks. The scale of the data necessitates distributed and optimized storage mechanisms. The data is then analyzed using graph algorithms and machine learning techniques to understand the networks and derive insights. Visualization tools aide in data exploration and comprehension.
