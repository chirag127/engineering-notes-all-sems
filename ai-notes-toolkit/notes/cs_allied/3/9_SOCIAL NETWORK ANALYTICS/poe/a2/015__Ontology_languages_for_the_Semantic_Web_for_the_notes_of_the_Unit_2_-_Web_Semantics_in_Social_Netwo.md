### Ontology languages for the Semantic Web

- RDF: Resource Description Framework is a framework for representing information in the Web. RDF uses statements to represent information in the form of subject-predicate-object expressions.
- RDF Schema: RDF Schema is a vocabulary description language. It provides basic elements to describe classes and properties used in RDF and enables simple reasoning about the RDF data.
- OWL: Web Ontology Language is a vocabulary extension of RDF Schema which provides additional vocabulary along with formal semantics. OWL enables more automated reasoning about Web data than RDF Schema.
- There are three increasingly expressive sublanguages of OWL:
	- OWL Lite: Used when simple ontological statements are needed.
	- OWL DL: Used when more expressive power is required along with computational completeness (all conclusions are guaranteed to be computable) and decidability (all statements have a yes/no answer).
	- OWL Full: Most powerful but reasoning (computability and decidability) is no longer guaranteed.

The points listed above cover the key Ontology languages for the Semantic Web to understand the concepts and usage of different languages for different purposes.
