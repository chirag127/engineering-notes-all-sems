### Evaluation through analysis for the notes of the Unit 5 - Evaluation of Social Network Analysis in the subject of SOCIAL NETWORK ANALYTICS.

1. Centrality measures: Degree centrality, Betweenness centrality, Closeness centrality.
- Degree centrality: Number of direct connections a node has. Nodes with high degree centrality are more influential.
- Betweenness centrality: Number of shortest paths between all pairs of nodes that pass through a given node. Nodes with high betweenness centrality act as bridges and are more powerful.
- Closeness centrality: Average length of shortest paths between a node and all other nodes. Nodes with high closeness centrality can access information and resources quickly.

2. Clustering coefficient: Measure of the degree to which nodes in a graph tend to cluster together. A higher clustering coefficient indicates a more tightly knit community.

3. Components: Weakly connected component, Strongly connected component.
- Weakly connected component: Largest subgraph where every pair of nodes is connected by a path, regardless of direction.
- Strongly connected component: Largest subgraph where every pair of nodes is connected by a directed path in both directions.

4. Network parameters: Density, Diameter, Average path length.
- Density: Proportion of possible ties that are actual ties. Higher density indicates a more closely connected network.
- Diameter: Longest of all shortest paths in a network. Lower diameter indicates faster spread of information or resources.
- Average path length: Average number of steps along the shortest paths for all possible pairs of network nodes. Lower average path length also indicates faster spread of information or resources.
