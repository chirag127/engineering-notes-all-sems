### Sesame for the notes of the Unit 4 - Developing Social-Semantic Applications

1.  RDF - Resource Description Framework
    - RDF is a framework for representing information in the Web.
    - RDF uses statements to represent information. A statement contains a subject, predicate and object.
    - Subject - The thing being described. Predicate - A property or characteristic of the subject. Object - The value of the property.
2.  RDF Schema
    - RDF Schema is a vocabulary for describing properties and classes of RDF resources, which allows to define relationships between these resources.
    - It provides basic elements to describe ontologies, like classes, properties and their relationships.
3.  OWL - Web Ontology Language
    - OWL is a semantic markup language for defining and instantiating web ontologies.
    - It adds more vocabulary for describing properties and classes: equivalence relations, cardinality, equality, richer typing of properties, characteristics of properties, etc.
    - It allows to define richer ontologies and enables reasoning about the ontology content and consistency verification.
4.  Sesame
    - Sesame is a Java framework for storage, inferencing and querying of RDF data.
    - It provides API for:
    - Storing RDF data (in memory, on disk, remote repositories)
    - Inferencing (support for RDFS and OWL inferencing)
    - Querying (SPARQL endpoint)
