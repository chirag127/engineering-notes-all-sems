## Unit 4 - Developing Social-Semantic Applications

1. Introduction to Social Semantic Web
- The social web allows people to connect, create and share content.
- The semantic web provides meaning to the content through metadata and ontologies.
- The social semantic web combines the social web and the semantic web to create meaningful connections between people and content.
- Applications of the social semantic web include:
    - Social networks with semantic data
    - Semantic tagging of content
    - Semantic searches
    - Recommendation systems

2. Building Social Semantic Applications
- Choose an application type: social network, content sharing, Q&A, etc.
- Choose semantic technologies to use: RDF, OWL, SPARQL, etc.
- Define the data model using ontologies to add semantic meaning
- Use semantic APIs and queries to integrate semantic data
- Apply social features like connections, sharing and recommendations
- Handle issues like ambiguity, inconsistency, privacy, scale, etc.

3. Examples of Social Semantic Applications
- FOAF: Used to create social networks of people and their connections
- DBpedia: Extracts semantic data from Wikipedia to connect topics and content
- LinkedIn: Professional social network using semantic data
- Facebook: Popular social network slowly adding more semantic data
- Stack Overflow: Q&A site using tags and associations as semantic data
