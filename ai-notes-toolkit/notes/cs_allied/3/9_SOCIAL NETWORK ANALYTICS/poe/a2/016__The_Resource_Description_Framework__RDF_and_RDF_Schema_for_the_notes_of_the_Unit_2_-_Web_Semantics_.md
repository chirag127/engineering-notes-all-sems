### The Resource Description Framework (RDF)and RDF Schema

- RDF is a framework for representing information in the Web.
- RDF uses statements to represent information. A statement contains a subject, a predicate and an object.
- Subject: The thing being described.
- Predicate: Aspect, property or relation of the subject.
- Object: Thing that the statement is about.
- RDF Schema provides the vocabulary for describing properties and classes of RDF resources, just as XML Schema describes the structure of XML documents.
- RDF Schema includes rdfs:Class to describe groups of resources with common properties.
- RDF Schema includes rdfs:Property to link resources to attributes.
- RDF Schema includes rdfs:subClassOf to describe class hierarchies.
- RDF Schema includes rdfs:subPropertyOf to describe property hierarchies.
- RDF Schema includes rdfs:domain and rdfs:range to describe the domain and range constraints of properties.
- RDF and RDF Schema are W3C recommendations designed to provide a common framework for processing and exchanging metadata on the Web.
