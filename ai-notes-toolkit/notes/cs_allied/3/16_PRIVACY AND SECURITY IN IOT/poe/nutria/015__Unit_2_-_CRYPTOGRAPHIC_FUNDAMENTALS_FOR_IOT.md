
## Unit 2 - CRYPTOGRAPHIC FUNDAMENTALS FOR IOT

1. Cryptography is the practice of using mathematical techniques to secure data and communications. It is used extensively in the Internet of Things (IoT) to ensure that data is secure and private.
2. Cryptography is used to protect data from unauthorized access, tampering, and alteration. It can also be used to authenticate the identity of the sender or receiver of the data.
3. Cryptography can be used to encrypt data, which means that it is converted into a form that cannot be read by anyone other than the intended recipient. This ensures that the data remains confidential.
4. Cryptography can also be used to digitally sign data, which is a way of proving the identity of the sender of the data. This helps to ensure that the data has not been altered in transit.
5. Cryptographic algorithms are used to generate keys, which are used to encrypt and decrypt data. The most commonly used algorithms are symmetric key algorithms, which use the same key for both encryption and decryption, and asymmetric key algorithms, which use different keys for encryption and decryption.
6. Cryptographic hash functions are used to generate a unique value, called a message digest, from a piece of data. This is used to verify the integrity of the data, as any changes to the data will result in a different message digest.
7. Cryptography is an important tool for ensuring the security of data and communications in the IoT. It is used to ensure that data is kept secure, private, and unaltered, and to authenticate the identity of the sender and receiver.
