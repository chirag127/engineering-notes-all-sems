
## Unit 5 - CLOUD SECURITY FOR IOT

1. Cloud security is a set of policies, technologies, and controls designed to protect cloud-based systems, data, applications, and services from unauthorized access, malicious attacks, and data breaches. 
2. Cloud security is a shared responsibility between the cloud provider and the customer, as the customer is responsible for the security of the data and applications in the cloud, while the cloud provider is responsible for the security of the cloud infrastructure. 
3. Cloud security consists of several layers, including physical security, network security, authentication, authorization, encryption, and other security measures. 
4. The Internet of Things (IoT) is an emerging technology that enables devices to communicate with each other over the internet. 
5. IoT devices are vulnerable to security threats, such as eavesdropping, spoofing, and man-in-the-middle attacks. 
6. To ensure the security of IoT devices and data, cloud security solutions such as encryption, authentication, and authorization can be used. 
7. Additionally, organizations should implement security policies and procedures, such as restricting access to sensitive data, monitoring user activity, and patching vulnerabilities. 
8. Organizations should also use secure development practices to ensure that IoT devices are secure from the start.
