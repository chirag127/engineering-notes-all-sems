
### Random Number Generation for the Notes of Unit 2 - Cryptographic Fundamentals for IoT in the Subject of Privacy and Security in IoT

- Random number generation is an important concept in cryptography, as it is used to create cryptographic keys. 
- Random numbers are generated using algorithms that take unpredictable inputs and output a sequence of unpredictable numbers. 
- A cryptographically secure random number generator (CSPRNG) is a type of random number generator that is designed to be secure enough for cryptographic applications. 
- The most common way to generate a CSPRNG is by using a cryptographic hash function, such as SHA-256, to generate a random number from a seed. 
- Another way to generate a CSPRNG is by using a true random number generator (TRNG), which uses physical sources of entropy, such as thermal noise or radioactive decay, to generate truly random numbers. 
- Random numbers can also be generated using pseudorandom number generators (PRNGs), which use deterministic algorithms to generate numbers that appear random, but are not truly random. 
- It is important to note that PRNGs are not suitable for cryptographic applications, as they can be easily cracked by an attacker. 
- When using a CSPRNG, it is important to ensure that the random numbers generated are of sufficient length and entropy to be secure.
