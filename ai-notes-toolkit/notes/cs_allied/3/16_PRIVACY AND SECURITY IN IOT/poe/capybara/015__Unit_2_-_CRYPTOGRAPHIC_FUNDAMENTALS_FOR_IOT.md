## Unit 2 - CRYPTOGRAPHIC FUNDAMENTALS FOR IOT

In this unit, we will discuss the cryptographic fundamentals for IoT. Cryptography is a technique used to secure communication between two entities. In the context of IoT, cryptography is used to protect devices and data from unauthorized access.

Here are some key concepts related to cryptographic fundamentals for IoT:

- **Encryption:** Encryption is the process of converting plain text into ciphertext using an encryption algorithm. The ciphertext is then transmitted over the network, and the recipient uses a decryption algorithm to convert it back into plain text. Encryption is used to protect data from unauthorized access.

- **Symmetric Key Encryption:** Symmetric key encryption is a type of encryption where the same key is used for encryption and decryption. This type of encryption is faster than asymmetric key encryption, but it is less secure.

- **Asymmetric Key Encryption:** Asymmetric key encryption is a type of encryption where different keys are used for encryption and decryption. This type of encryption is more secure than symmetric key encryption, but it is slower.

- **Digital Signatures:** Digital signatures are used to verify the authenticity of a message. A digital signature is created using a private key, and it can only be verified using the corresponding public key. Digital signatures are used to ensure that a message has not been tampered with during transmission.

- **Hash Functions:** Hash functions are used to create a unique digital fingerprint of a message. This fingerprint is called a hash value. Hash functions are used to ensure the integrity of a message. If the message has been tampered with, the hash value will be different.

- **Public Key Infrastructure (PKI):** PKI is a system used to manage public and private keys. PKI is used to ensure the authenticity of digital certificates, which are used to verify the identity of a device or a user.

- **Secure Sockets Layer (SSL)/Transport Layer Security (TLS):** SSL/TLS is a protocol used to secure communication over the internet. SSL/TLS uses encryption and digital certificates to ensure the confidentiality and authenticity of data transmitted over the network.

In conclusion, cryptographic fundamentals are essential for securing IoT devices and data. Encryption, digital signatures, hash functions, PKI, and SSL/TLS are some of the key concepts related to cryptographic fundamentals for IoT. By understanding these concepts, you can ensure the security and privacy of your IoT devices and data.
