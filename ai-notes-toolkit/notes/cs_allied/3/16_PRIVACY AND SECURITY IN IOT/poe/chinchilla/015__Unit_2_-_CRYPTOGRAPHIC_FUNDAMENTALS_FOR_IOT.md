## Unit 2 - CRYPTOGRAPHIC FUNDAMENTALS FOR IOT

In this unit, we will explore the cryptographic fundamentals that are essential for securing the Internet of Things (IoT). Cryptography is the practice of securing communication from adversaries by encoding the message such that it can only be understood by authorized entities.

### Cryptography Fundamentals

1. **Symmetric Key Cryptography:** It is a method of encryption where a single key is used for both encryption and decryption. The sender and receiver must have the same key to communicate securely. It is a faster method of encryption, but the key must be kept secret.

2. **Asymmetric Key Cryptography:** It is a method of encryption where a public key is used to encrypt data, and a private key is used to decrypt it. The public key is shared with everyone, but the private key must be kept secret. It is a slower method of encryption, but it provides better security.

3. **Hash Functions:** It is a method of cryptography that transforms data into a fixed-length string of characters. The hash function is a one-way function that cannot be reversed. It is used to verify the integrity of data and to ensure that the data has not been altered.

4. **Digital Signatures:** It is a method of cryptography that provides authentication and non-repudiation. It is created using a private key and can be verified using a public key. It is used to ensure that the message has not been altered and that it came from the sender.

### Cryptography Applications for IoT

1. **Secure Communication:** Cryptography is used to secure communication between IoT devices and the server. It ensures that the data is not intercepted, modified, or read by unauthorized entities.

2. **Device Authentication:** Cryptography is used to authenticate IoT devices to ensure that only authorized devices can connect to the network. It prevents unauthorized devices from gaining access to the network and compromising security.

3. **Data Integrity:** Cryptography is used to ensure the integrity of data transmitted between IoT devices and the server. It prevents unauthorized entities from altering the data and compromising the integrity of the system.

4. **Privacy:** Cryptography is used to protect the privacy of IoT users by encrypting their data. It ensures that the data is not accessible to unauthorized entities and protects the user's privacy.

In conclusion, cryptography is an essential component of securing the IoT. It provides confidentiality, integrity, authentication, and non-repudiation, which are essential for securing communication between IoT devices and the server. Understanding the cryptographic fundamentals is crucial for designing secure IoT systems.
