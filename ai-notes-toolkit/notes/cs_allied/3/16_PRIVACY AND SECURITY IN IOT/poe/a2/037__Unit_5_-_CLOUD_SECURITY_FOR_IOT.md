## Unit 5 - CLOUD SECURITY FOR IOT

1. Introduction to Cloud for IoT
- IoT devices have limited computing and storage capabilities
- Cloud provides scalable computing and storage resources for IoT devices to offload tasks
- IoT devices can access powerful cloud services for processing, storage, machine learning, etc.
- Collaboration between IoT devices and cloud brings new security challenges

2. Cloud Security Threats for IoT
- Data breaches: Sensitive data from IoT devices and clouds can be stolen
- Account hijacking: Accounts can be compromised to access IoT devices and cloud resources
- Malware infections: Malware can infect IoT devices and cloud servers
- DDoS attacks: Large number of IoT devices can be hacked to launch DDoS attacks on clouds and servers
- Vulnerabilities in APIs and interfaces: Security flaws in interfaces connecting IoT and cloud can be exploited

3. Recommendations to Secure IoT and Cloud
- Ensure strong authentication and access control for IoT devices and cloud resources
- Apply security patches and updates promptly on IoT devices and cloud infrastructure
- Use encryption for data in transit and at rest
- Monitor IoT device and cloud activities to detect anomalies
- Use firewalls and other network security mechanisms
- Train users on cybersecurity best practices
- Adopt strong API security methods: rate limiting, automation of API key rotation, etc.
