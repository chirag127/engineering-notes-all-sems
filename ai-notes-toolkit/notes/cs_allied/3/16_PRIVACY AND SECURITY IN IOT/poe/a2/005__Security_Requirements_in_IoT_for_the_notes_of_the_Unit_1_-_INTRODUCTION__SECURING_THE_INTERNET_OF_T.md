 Here are the points on Security Requirements in IoT for the notes of the Unit 1 - INTRODUCTION: SECURING THE INTERNET OF THINGS:

1. Encryption: Data in transit and at rest should be encrypted to protect confidentiality of sensitive data. Cryptographic algorithms and protocols should be used to encrypt data between IoT devices and cloud services.
2. Authentication and Authorization: Strong authentication and authorization mechanisms should be in place to control access to IoT devices and data. This could include use of passwords, certificates, tokens, etc. based on the security requirements.
3. Access Control: Appropriate access control and permission mechanisms should be implemented to restrict access to IoT devices, data and services. This could include role-based access control, attribute-based access control, etc.
4. Device Management: Proper management of lifecycle of IoT devices including secure bootstrapping, software updates, decommissioning, etc. is important to ensure security. Automated and secure remote management of devices should be implemented.
5. Privacy: Privacy of user data and personal information should be maintained through use of privacy-preserving techniques like anonymization, aggregation, minimization of data, etc. Transparency on how the data is collected and used should be provided to users.
6. Resilience: IoT systems should be designed to be resilient against attacks and other disruptions. This could include use of failovers, redundancy, securely storing backups, etc. to ensure continuous and reliable operation.
7. Software and Patch Management: Vulnerabilities in software should be patched in a timely manner to reduce the attack surface. Automated and secure software update mechanisms should be implemented for IoT devices.
