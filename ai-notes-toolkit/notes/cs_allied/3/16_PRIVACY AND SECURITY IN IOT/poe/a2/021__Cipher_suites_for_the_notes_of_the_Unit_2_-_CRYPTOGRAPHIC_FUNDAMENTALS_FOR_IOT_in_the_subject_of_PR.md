### Cipher suites for the notes of the Unit 2 - CRYPTOGRAPHIC FUNDAMENTALS FOR IOT in the subject of PRIVACY AND SECURITY IN IOT

1. AES-128-CBC: AES algorithm with a 128-bit key and Cipher Block Chaining mode
2. AES-256-CBC: AES algorithm with a 256-bit key and Cipher Block Chaining mode
3. AES-128-GCM: AES algorithm with a 128-bit key and Galois/Counter Mode
4. AES-256-GCM: AES algorithm with a 256-bit key and Galois/Counter Mode
5. CHACHA20-POLY1305: A fast, modern stream cipher suite

These cipher suites provide confidentiality by encrypting the data using a symmetric key algorithm. The stronger suites (AES-256-*) provide greater security but at the cost of performance, so selection depends on specific requirements and constraints.
