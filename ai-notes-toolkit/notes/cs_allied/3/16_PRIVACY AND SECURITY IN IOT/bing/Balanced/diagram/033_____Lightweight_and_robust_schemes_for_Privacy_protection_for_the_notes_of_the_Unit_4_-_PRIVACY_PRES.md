### Lightweight and Robust Schemes for Privacy Protection for the Notes of the Unit 4 - PRIVACY PRESERVATION AND TRUST MODELS FOR IOT in the Subject of PRIVACY AND SECURITY IN IOT

- Privacy protection is a crucial issue in IoT applications and services, especially for those involving sensitive personal data, such as mobile wireless body sensor networks (WBSNs) and participatory sensing.
- Lightweight and robust schemes are needed to ensure the confidentiality, integrity, and authenticity of the data, as well as the anonymity and unlinkability of the users, while minimizing the computation and communication overheads.
- Some of the existing lightweight and robust schemes for privacy protection in IoT are:

  - A smart lightweight privacy preservation scheme for IoT-based UAV applications, which uses a lightweight privacy-preserving scheme (L-PPS) to provide robust authentication between the IoT devices with a valid authentication period. The L-PPS uses a one-time pseudonym and a dynamic secret key to achieve anonymity and unlinkability, and a hash-based message authentication code (HMAC) to ensure integrity and freshness.
  - A lightweight privacy-preserving scheme using homomorphic encryption in IoT, which uses a homomorphic encryption scheme to encrypt the data before sending it to the untrustworthy cloud servers, and allows the data users to perform computations on the encrypted data without decrypting it. The scheme also uses a proxy re-encryption technique to enable the data owners to delegate the access rights to the data users without revealing their identities or keys.
  - A lightweight and compromise-resilient authentication scheme for IoTs, which uses a lightweight hash and XOR operations to achieve mutual authentication and key agreement between the IoT devices and the server. The scheme also uses a secret update mechanism to prevent the compromise of the secret keys, and a nonce-based challenge-response protocol to resist replay and impersonation attacks.
  - Lightweight and robust schemes for privacy protection in key personal IoT applications: mobile WBSN and participatory sensing, which propose two schemes for different IoT scenarios. The first scheme is a lightweight and robust privacy-preserving authentication and key agreement scheme for mobile WBSNs, which uses elliptic curve cryptography (ECC) and identity-based encryption (IBE) to achieve mutual authentication and secure data transmission. The second scheme is a lightweight and robust privacy-preserving data aggregation scheme for participatory sensing, which uses a homomorphic encryption scheme and a ring signature scheme to achieve data aggregation and user anonymity.
  - Lightweight NFC protocol for privacy protection in mobile IoT, which uses a lightweight NFC protocol to achieve mutual authentication and secure data exchange between the mobile devices and the IoT devices. The protocol uses a pseudonym-based technique and a hash chain technique to achieve user anonymity and unlinkability, and a HMAC technique to ensure data integrity and freshness. The protocol also uses a session key technique to prevent replay and relay attacks.
