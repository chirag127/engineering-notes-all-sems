# IoT IAM infrastructure

Identity and Access Management (IAM) is an important aspect of IoT security. It is focused on identifying people and managing access to different data types, such as sensitive data, non-sensitive data, or device data.

One of the key components of IoT IAM infrastructure is Public Key Infrastructure (PKI). PKI is a system that is used to secure IAM deployments for the IoT .

Some IoT platforms, such as AWS IoT, provide their own IAM solutions. AWS Identity and Access Management (IAM) is an AWS service that helps an administrator securely control access to AWS resources. IAM administrators control who can be authenticated (signed in) and authorized (have permissions) to use AWS IoT resources.

AWS IoT also includes a thing registry service that allows an administrator to register IoT devices, capturing for each the name of the thing and various attributes of it. The attributes can include data items such as manufacturer, type, serial number, deployment date, and location.
