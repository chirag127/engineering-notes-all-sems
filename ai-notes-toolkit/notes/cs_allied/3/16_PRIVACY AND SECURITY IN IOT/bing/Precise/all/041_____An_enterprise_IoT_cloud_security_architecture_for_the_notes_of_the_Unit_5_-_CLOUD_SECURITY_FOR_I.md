# An enterprise IoT cloud security architecture

An enterprise IoT cloud security architecture is a framework that focuses on the appropriate security controls for cloud-enabling an IoT system. There are many architectural aspects and options to consider when tailoring an enterprise IoT cloud security architecture. CSPs, IoT service providers, and enterprise adopters must examine the capabilities being provided to focus the appropriate security controls in an architecturally supportive framework.

It is helpful to divide the IoT architecture into several zones as part of the threat modeling exercise. These zones may include the device, field gateway, cloud gateway, and service. Each zone often has its own data and authentication and authorization requirements. Zones can also be used to isolate damage and restrict the impact of low trust zones on higher trust zones.

The design of a corporate IoT security architecture depends on the IoT architecture in place. Consumer IoT solutions, for example, typically operate under a four-tier architecture model that includes the sensor, network, data pre-processing, and cloud analysis layers.

Enterprise IoT Security can eliminate IoT device blind spots across existing IT and security solutions with playbook-driven, built-in integrations. A simplified cloud-delivery means Enterprise IoT Security can be deployed across any architecture without requiring multiple sensors and network redesign.
