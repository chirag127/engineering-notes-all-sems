### Authorization with Publish / Subscribe schemes

- The publish-subscribe (pub-sub) model is used for delivering authorization requests and responses between applications and authorization servers.
- Using the pub-sub architecture improves authorization system availability and reduces system administration overhead .
- The goal of using a pub-sub architecture is to reduce system administration overhead, thus improving system manageability, and to increase system availability, thus improving overall system robustness .
