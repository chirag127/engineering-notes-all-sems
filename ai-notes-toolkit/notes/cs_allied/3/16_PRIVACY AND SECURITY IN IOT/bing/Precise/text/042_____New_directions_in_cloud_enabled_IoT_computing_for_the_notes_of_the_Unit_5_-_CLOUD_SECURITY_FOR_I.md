### New directions in cloud enabled IoT computing

1. **Edge computing**: Edge computing is a new approach to cloud computing that brings computation and data storage closer to the location where it is needed, to improve response times and save bandwidth. This is particularly useful for IoT devices, which often generate large amounts of data that need to be processed quickly.

2. **Fog computing**: Fog computing is a decentralized computing infrastructure in which data, compute, storage, and applications are distributed in the most logical, efficient place between the data source and the cloud. This can help to reduce the amount of data that needs to be transmitted to the cloud, improving performance and reducing costs.

3. **Serverless computing**: Serverless computing is a cloud computing execution model in which the cloud provider dynamically manages the allocation of machine resources. This can help to reduce the complexity and cost of managing IoT devices, as the cloud provider takes care of the underlying infrastructure.

4. **Blockchain technology**: Blockchain technology is being explored as a way to improve the security and privacy of IoT devices. By using a decentralized, distributed ledger, it is possible to create a tamper-proof record of all transactions and data exchanges between IoT devices.

5. **Artificial intelligence and machine learning**: The use of artificial intelligence and machine learning is becoming increasingly important in the field of IoT. These technologies can be used to analyze the large amounts of data generated by IoT devices, to identify patterns and make predictions, and to automate decision-making processes.

These are some of the new directions in cloud enabled IoT computing that are being explored to improve the performance, security, and privacy of IoT devices. They represent exciting developments in the field, and are likely to play an increasingly important role in the future of IoT.
