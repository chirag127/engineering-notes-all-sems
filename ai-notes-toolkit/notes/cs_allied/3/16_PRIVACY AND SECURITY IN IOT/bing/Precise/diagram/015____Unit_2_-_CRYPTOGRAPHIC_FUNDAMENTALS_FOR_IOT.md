## Unit 2 - Cryptographic Fundamentals for IoT

1. **Introduction to Cryptography:** Cryptography is the practice of secure communication in the presence of third parties. It involves techniques for secure data storage and transmission, and for verifying the authenticity of data.

2. **Symmetric Key Cryptography:** Symmetric key cryptography, also known as secret key cryptography, involves the use of a single key for both encryption and decryption. The key must be kept secret and is shared only between the sender and the receiver.

3. **Asymmetric Key Cryptography:** Asymmetric key cryptography, also known as public key cryptography, involves the use of a pair of keys: a public key and a private key. The public key is used for encryption and can be shared with anyone, while the private key is used for decryption and must be kept secret.

4. **Hash Functions:** A hash function is a mathematical function that takes an input and produces a fixed-size output, known as a hash value. Hash functions are used for verifying the integrity of data and for indexing data in hash tables.

5. **Digital Signatures:** A digital signature is a mathematical scheme for verifying the authenticity of digital messages or documents. It involves the use of a private key to sign a message, and a public key to verify the signature.

6. **Key Management:** Key management refers to the process of generating, storing, distributing, and revoking cryptographic keys. It is an essential aspect of cryptography, as the security of cryptographic systems depends on the security of the keys.

7. **Cryptographic Protocols for IoT:** Cryptographic protocols are used to secure communication in IoT systems. These protocols include key exchange protocols, authentication protocols, and secure data transmission protocols.

8. **Security Challenges in IoT:** IoT systems face many security challenges, including the need to secure a large number of devices, the need to secure communication over wireless networks, and the need to protect against attacks on the system.

9. **Conclusion:** Cryptography is an essential tool for securing communication in IoT systems. It involves the use of techniques such as symmetric and asymmetric key cryptography, hash functions, digital signatures, and key management. Cryptographic protocols are used to secure communication in IoT systems, and there are many security challenges that must be addressed in order to ensure the security of these systems.
