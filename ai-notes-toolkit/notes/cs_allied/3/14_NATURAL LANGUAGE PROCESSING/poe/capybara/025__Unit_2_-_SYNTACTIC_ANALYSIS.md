## Unit 2 - SYNTACTIC ANALYSIS

In this unit, we will be studying the following topics related to syntactic analysis:

1. Introduction to Syntactic Analysis:
   - Definition of Syntactic Analysis.
   - Importance of Syntactic Analysis.
   - Syntactic Analysis vs. Semantic Analysis.

2. Syntax Trees:
   - Definition of Syntax Trees.
   - Types of Syntax Trees.
   - Construction of Syntax Trees.
   - Examples of Syntax Trees.

3. Context-Free Grammars:
   - Definition of Context-Free Grammars.
   - Components of Context-Free Grammars.
   - Types of Context-Free Grammars.
   - Examples of Context-Free Grammars.

4. Parsing Techniques:
   - Definition of Parsing.
   - Types of Parsing Techniques.
   - Examples of Parsing Techniques.

5. Ambiguity in Grammar:
   - Definition of Ambiguity in Grammar.
   - Types of Ambiguity in Grammar.
   - Techniques to Resolve Ambiguity in Grammar.

6. Applications of Syntactic Analysis:
   - Natural Language Processing.
   - Compiler Design.
   - Syntax Highlighting in Text Editors.
   - Sentence Correction in Text Editors.

By the end of this unit, you will have a clear understanding of the concepts related to syntactic analysis. You will be able to differentiate between syntax and semantics, construct syntax trees, define context-free grammars, apply various parsing techniques, resolve ambiguity in grammar and understand the various applications of syntactic analysis.
