

### WSD Using Supervised for Unit 3 - Semantics and Pragmatics in Natural Language Processing

* Word Sense Disambiguation (WSD) is the process of determining the correct meaning of a word in a given context.
* Supervised WSD uses a corpus of labeled examples to learn how to disambiguate a given word.
* Supervised WSD can be used to build a classifier which can then be used to label new words in a given context.
* Supervised WSD can also be used to build a sense inventory, which is a list of all the senses of a given word.
* Semantics is the study of the meaning of words and sentences. It is concerned with how words and sentences are interpreted in different contexts.
* Pragmatics is the study of how language is used in context. It is concerned with how people use language to communicate in different contexts.
* Natural Language Processing (NLP) is a field of computer science which is concerned with the understanding and manipulation of natural language. NLP techniques can be used to analyze and interpret natural language.
