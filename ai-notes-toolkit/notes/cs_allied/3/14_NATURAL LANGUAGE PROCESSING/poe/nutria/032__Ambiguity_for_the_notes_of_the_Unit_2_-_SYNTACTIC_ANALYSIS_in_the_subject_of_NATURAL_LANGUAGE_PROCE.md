
### Ambiguity for the Notes of Unit 2 - Syntactic Analysis in Natural Language Processing

1. Ambiguity in language is a common phenomenon, and it can cause problems for natural language processing (NLP) systems.
2. Ambiguity can arise at different levels of language, such as lexical, syntactic, and semantic.
3. Ambiguity in syntax can be caused by the same word having multiple meanings, or by the same phrase having multiple syntactic structures.
4. Syntactic ambiguity is particularly difficult to disambiguate, as it requires the NLP system to understand the context of the sentence.
5. Syntactic ambiguity can be resolved using various methods, such as context-based disambiguation, rule-based disambiguation, and statistical disambiguation.
6. NLP systems can use techniques such as part-of-speech tagging and dependency parsing to identify ambiguous phrases and resolve them.
7. Syntactic ambiguity can also be resolved using machine learning techniques, such as supervised learning and unsupervised learning.
8. Syntactic ambiguity can be further reduced by using semantic information and by incorporating world knowledge into the NLP system.
