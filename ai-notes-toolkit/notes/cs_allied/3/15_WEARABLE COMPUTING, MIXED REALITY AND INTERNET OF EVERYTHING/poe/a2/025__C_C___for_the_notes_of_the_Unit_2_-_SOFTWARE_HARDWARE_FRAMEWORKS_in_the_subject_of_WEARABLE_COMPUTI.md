### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. C/C++ is a low-level programming language that is used to develop system software, firmware or software applications that interface with the hardware.
2. It gives the programmer control over the memory usage and hardware resources, enabling efficient memory management and high performance.
3. Key features of C/C++ are:
- Flexibility and efficiency
- Control over resources
- Support for functional and procedural programming
- Strong typing and type checking
- Generic and meta-programming support
4. C/C++ is used to program microcontrollers, operating systems, application software and firmware. Some examples are:
- Arduino uses C/C++ to program its microcontrollers
- Windows, Linux and other OSs have components written in C/C++
- Adobe Photoshop and hardware device drivers use C/C++
5. To summarize, C/C++ is a powerful and efficient programming language that gives low-level access and control, enabling customization and high performance which makes it suitable for programming software and systems that interact with hardware.
