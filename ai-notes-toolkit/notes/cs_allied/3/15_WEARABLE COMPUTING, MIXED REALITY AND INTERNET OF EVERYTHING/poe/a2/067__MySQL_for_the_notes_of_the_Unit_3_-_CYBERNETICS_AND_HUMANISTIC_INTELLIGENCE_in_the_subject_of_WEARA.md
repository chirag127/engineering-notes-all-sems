### MySQL for the notes of the Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. MySQL is an open-source relational database management system (RDBMS). It is used to store and manage data.
2. Some key features of MySQL are:
- Open source and free to download and use
- Wide platform support - Windows, Linux, macOS, etc.
- Scalable - can handle small to large data sizes
- SQL as the language to query the database
- Secure - supports authentication and privileges
- High performance - efficient and fast
- Highly configurable - many options to tune performance
3. Some common uses of MySQL are:
- Content management systems like WordPress use MySQL to store data
- Many web applications use MySQL as the database to store and manage user data
- Mobile apps can use MySQL to sync and store data on the cloud
- Store sensor data from IoT devices
- Perform data analytics and data mining on the data stored in MySQL
