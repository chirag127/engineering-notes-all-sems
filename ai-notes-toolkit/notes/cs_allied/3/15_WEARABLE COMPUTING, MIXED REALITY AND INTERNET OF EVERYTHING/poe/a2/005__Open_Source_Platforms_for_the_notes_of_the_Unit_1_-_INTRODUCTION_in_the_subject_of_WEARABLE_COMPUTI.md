### Open Source Platforms

- Arduino: Open-source electronic prototyping platform allowing to create interactive electronic objects. It consists of hardware (board) and software (IDE) and a programming language based on Wiring. It allows to connect various sensors and actuators and to create interactive objects and environments.
- Raspberry Pi: Credit-card sized computer created to promote teaching of basic computer science in schools and developing countries. It allows to create many connected objects and solutions thanks to its GPIO connectors. It runs on Linux and can be programmed in many languages (Python, C/C++, Java, Scratch...).
- BeagleBone: Open source hardware single board computer, capable of running Linux and Android, providing access to its PRUs microcontrollers as well as to various communication interfaces (GPIO, I2C, SPI...). It allows rapid prototyping and creation of connected objects and appliances.
- micro:bit: Small programmable microcontroller board designed for education. It integrates many sensors (accelerometer, compass...) and has LEDs and buttons that can be programmed in various languages (Block editor, JavaScript, Python...). It allows to create simple interactive objects and robots.
