### Arduino for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. Arduino is an open-source hardware and software company, project, and user community that designs and manufactures single-board microcontrollers and microcontroller kits for building digital devices.
2. Arduino boards are able to read inputs from sensors, and control outputs like LEDs, motors, etc. This makes them suited for interactive projects where devices are controlled physically or information is presented to the user.
3. The hardware consists of an Atmel AVR microcontroller, or a microcontroller from other manufacturers like the ARM Cortex-M series. The software consists of a standard programming language compiler and a boot loader that executes on the microcontroller.
4. Arduino boards are inexpensive, small, and flexible which enables fast prototyping. The software is easy to learn which makes it suited for students, hobbyists, and professionals. Compatible hardware and software are available for free which enables a low cost of entry.
5. The Arduino integrated development environment (IDE) is a cross-platform application (for Windows, macOS, and Linux) that is written in the programming languages Java and C++. It is used to write, compile, and upload programs to Arduino boards. The programming language is called Arduino Sketch which is a simplified subset of C/C++.
