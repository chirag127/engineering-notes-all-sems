

### Open Source Platforms for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. Arduino: Arduino is an open-source electronics platform that enables users to create interactive electronic objects. It is based on a microcontroller board and a software development environment. Arduino can be used to create a variety of projects, from simple LED displays to complex robots.

2. Raspberry Pi: Raspberry Pi is an open-source single-board computer developed for educational purposes. It is based on a Broadcom system on a chip (SoC) and can be used to create a variety of projects, from simple LED displays to complex robots.

3. OpenCV: OpenCV is an open-source computer vision library that enables users to create applications that can recognize and track objects in real-time. It is used in a variety of applications, such as facial recognition, object detection, and motion tracking.

4. Unity: Unity is an open-source game engine developed for creating 3D and 2D games and applications. It is used in a variety of applications, from virtual reality to augmented reality, and is used by developers to create immersive experiences.

5. Myo: Myo is an open-source wearable computing platform developed for gesture recognition. It enables users to control devices with natural hand gestures, such as swipes, taps, and circles.
