
### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

* C/C++ is a general-purpose programming language that is used to create software for a variety of applications. It is widely used in the development of embedded systems, operating systems, and other applications.
* C/C++ is a compiled language, meaning that code written in C/C++ must be compiled before it can be executed. The compilation process converts the source code into machine code, which can then be executed by the computer.
* C/C++ is an object-oriented programming language, meaning that code written in C/C++ can be organized into classes and objects. This allows for code to be reused and shared between different programs.
* C/C++ is a low-level language, meaning that it provides direct access to the computer's hardware and memory. This makes it a powerful language for developing applications that need to interact directly with the hardware.
* C/C++ is used in the development of wearable computing, mixed reality, and the Internet of Things. It is used to create applications that can interact with the physical world, such as sensors, actuators, and other devices.
