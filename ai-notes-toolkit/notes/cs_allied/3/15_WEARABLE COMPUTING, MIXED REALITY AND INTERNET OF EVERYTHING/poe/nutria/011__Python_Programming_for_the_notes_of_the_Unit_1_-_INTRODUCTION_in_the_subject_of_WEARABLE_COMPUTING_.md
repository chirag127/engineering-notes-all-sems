
### Python Programming for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

* Python is a programming language used to create software applications. It is a high-level language, meaning that it is easier to learn than other languages such as C or Java.
* Python is an interpreted language, meaning that the code is not compiled into machine language, but instead is executed by an interpreter.
* Python is a cross-platform language, meaning that it can be used on multiple operating systems such as Windows, Mac, and Linux.
* Python is an object-oriented language, meaning that it allows for the creation of objects and classes that can be used to model real-world systems.
* Python is well-suited for wearable computing, mixed reality, and the Internet of Things (IoT), as it is designed to be lightweight and efficient.
* Python can be used to create applications that interact with sensors, cameras, and other devices.
* Python is an open-source language, meaning that it is free to use and modify.
