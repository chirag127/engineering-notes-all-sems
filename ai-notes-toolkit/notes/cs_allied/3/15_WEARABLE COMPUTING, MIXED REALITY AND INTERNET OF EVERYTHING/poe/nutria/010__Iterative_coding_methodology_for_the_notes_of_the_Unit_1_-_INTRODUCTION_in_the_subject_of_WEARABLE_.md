
### Iterative coding methodology for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. Iterative coding methodology is a process of software development that involves breaking down a task into smaller, more manageable parts.
2. This approach allows developers to test and adjust their code as they go, making the development process faster and more efficient.
3. Wearable computing, mixed reality, and Internet of Everything are all technologies that enable users to interact with digital information in a physical environment.
4. Wearable computing can be used to monitor health, track location, and even control devices.
5. Mixed reality combines the physical and digital worlds, allowing users to interact with virtual objects in the real world.
6. The Internet of Everything is a concept that connects physical objects to the Internet, allowing them to communicate with each other and with users.
7. All of these technologies require coding to develop applications and programs that make use of them.
8. Iterative coding methodology is a useful approach for developing applications and programs for these technologies because it allows developers to quickly test and adjust their code.
