
## Unit 2 - SOFTWARE HARDWARE FRAMEWORKS

1. Software frameworks are collections of software that provide a common platform for developing applications.
2. Hardware frameworks are a combination of hardware and software components that provide a platform for developing applications.
3. Software frameworks can be used to build applications that run on a single computer or across multiple computers.
4. Hardware frameworks can be used to build applications that run on a single device or across multiple devices.
5. Software frameworks typically include a variety of components, such as libraries, compilers, interpreters, and debuggers.
6. Hardware frameworks typically include a variety of components, such as processors, memory, storage, and input/output devices.
7. Software frameworks are typically designed to be extensible, allowing developers to add new features and functionality.
8. Hardware frameworks are typically designed to be modular, allowing developers to add new components and features.
9. Software frameworks can be used to develop applications for a variety of platforms, including desktop, mobile, and web.
10. Hardware frameworks can be used to develop applications for a variety of platforms, including embedded systems, consumer electronics, and automotive systems.
