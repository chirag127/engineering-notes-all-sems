
### Variables and Flow Control

Variables and flow control are two of the most important concepts in Wearable Computing, Mixed Reality and Internet of Everything (IoE).

* Variables are used to store data and can be used to store a variety of data types including strings, numbers, and objects. Variables can be used to control the flow of a program.

* Flow control is used to determine how a program runs. It is used to execute different parts of a program based on certain conditions. Flow control can be used to create loops, if-else statements, and other conditional statements.

* In Wearable Computing, Mixed Reality and Internet of Everything (IoE), variables and flow control are used to create applications that are able to interact with the user in a meaningful way. For example, a program can use variables and flow control to detect when a user's wristband is worn and to display notifications accordingly.
