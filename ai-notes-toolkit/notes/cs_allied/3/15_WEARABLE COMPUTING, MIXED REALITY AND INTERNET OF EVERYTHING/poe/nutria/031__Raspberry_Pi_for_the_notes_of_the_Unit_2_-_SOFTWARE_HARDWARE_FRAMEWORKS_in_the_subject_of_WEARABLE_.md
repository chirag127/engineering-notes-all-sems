
### Raspberry Pi for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

* The Raspberry Pi is a single-board computer developed in the United Kingdom by the Raspberry Pi Foundation. It is a credit-card sized computer that can be used for a variety of tasks, such as programming, web browsing, and multimedia.

* The Raspberry Pi is powered by an ARM processor, which is a type of processor commonly used in mobile phones and other embedded devices. This processor allows the Raspberry Pi to run a variety of operating systems, including Linux, Windows, and Android.

* The Raspberry Pi comes with a variety of ports, including HDMI, USB, and Ethernet, allowing it to be connected to a variety of external devices. It also has a GPIO (general-purpose input/output) port, which allows it to be connected to sensors and other electronic components.

* The Raspberry Pi can be used to create wearable computing devices, such as smartwatches, fitness trackers, and virtual/augmented reality headsets. It can also be used to create mixed reality applications, such as interactive games and educational content.

* The Raspberry Pi can also be used to create Internet of Things (IoT) devices, such as home automation systems and connected appliances. The Raspberry Pi can be programmed to interact with other devices on a network, allowing it to be used to control and monitor devices remotely.
