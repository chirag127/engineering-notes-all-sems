### Unit 2 - SOFTWARE HARDWARE FRAMEWORKS
#### openFrameworks as our IDE

- openFrameworks is an open-source C++ toolkit designed to assist the creative process by providing a simple and intuitive framework for experimentation.
- It is designed for artists, designers, and researchers who want to create interactive installations, visualizations, and prototypes.
- openFrameworks is built on top of several commonly used libraries, including OpenGL, FreeType, and Boost, and provides a simple and consistent API for working with graphics, sound, and input devices.
- It is cross-platform and can be used to develop applications for Windows, macOS, Linux, iOS, and Android.
- openFrameworks is community-driven, with a large and active user base contributing to its development and providing support to new users.
- It is well-documented, with extensive tutorials and examples available online, making it easy to get started and learn how to use its features.
- In the context of wearable computing, mixed reality, and the Internet of Everything, openFrameworks can be used to develop applications that interface with sensors, actuators, and other hardware devices, and to create rich and interactive user experiences.
