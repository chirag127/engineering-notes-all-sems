## Unit 2 - SOFTWARE HARDWARE FRAMEWORKS

1. **Software** refers to the programs and data that run on a computer or other device. It includes operating systems, applications, and utilities.
2. **Hardware** refers to the physical components of a computer or other device, such as the central processing unit (CPU), memory, storage, and input/output devices.
3. A **framework** is a set of guidelines or rules that define how software and hardware should interact. It provides a structure for developers to build upon and ensures consistency and compatibility between different systems.
4. **Software frameworks** provide a foundation for building applications, often including pre-built components and libraries that can be reused to speed up development.
5. **Hardware frameworks** define the physical architecture of a system, including the layout of components and the connections between them. They can also include standards for communication between devices.
6. **Software-hardware co-design** is an approach to system design that considers both software and hardware requirements from the beginning, allowing for more efficient and optimized systems.
7. **Virtualization** is a technology that allows multiple operating systems to run on a single physical machine, by creating virtual machines that share the underlying hardware resources.
8. **Cloud computing** is a model of delivering computing resources over the internet, allowing users to access software, storage, and processing power on demand, without having to manage their own hardware.
