# Unit 1 - INTRODUCTION
## Variables and Flow Control in Wearable Computing, Mixed Reality and Internet of Everything

### Variables
- Variables are used to store data in a program.
- They can be assigned different values and data types.
- Variables can be used to store and manipulate data in a program.

### Flow Control
- Flow control refers to the order in which statements in a program are executed.
- Flow control structures, such as conditional statements and loops, can be used to control the flow of a program.
- Conditional statements, such as if-else statements, allow a program to make decisions based on certain conditions.
- Loops, such as for and while loops, allow a program to repeat a set of statements until a certain condition is met.

In the context of wearable computing, mixed reality, and the Internet of Everything, variables and flow control are essential for creating interactive and responsive programs. They allow for the manipulation of data and the control of program flow, enabling the creation of complex and dynamic systems.
