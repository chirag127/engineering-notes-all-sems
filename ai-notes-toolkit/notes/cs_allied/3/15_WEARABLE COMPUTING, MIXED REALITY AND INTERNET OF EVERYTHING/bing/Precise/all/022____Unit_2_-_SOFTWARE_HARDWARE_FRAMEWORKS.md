## Unit 2 - SOFTWARE HARDWARE FRAMEWORKS

1. **Software** refers to the programs and data that run on a computer or other device. It includes operating systems, applications, and utilities.
2. **Hardware** refers to the physical components of a computer or other device, such as the central processing unit (CPU), memory, storage, and input/output (I/O) devices.
3. A **framework** is a set of guidelines, concepts, and tools that provide a structure for developing software or hardware systems.
4. Software and hardware frameworks are used to standardize the development process and ensure compatibility and interoperability between different systems.
5. Examples of software frameworks include the .NET Framework, the Java Platform, and the Ruby on Rails web application framework.
6. Examples of hardware frameworks include the Advanced Micro Devices (AMD) and Intel x86 processor architectures, and the ARM architecture used in many mobile devices.
7. Frameworks can provide a foundation for building complex systems, allowing developers to focus on the specific functionality of their application rather than the underlying infrastructure.
8. The use of frameworks can also improve the reliability and maintainability of systems, as they provide a consistent and well-tested foundation for development.
