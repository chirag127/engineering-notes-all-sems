# C/C++ for Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- C and C++ are both programming languages.
- C is a procedural language, while C++ is an object-oriented language.
- C++ is an extension of C, with additional features such as classes, inheritance, and polymorphism.
- Both languages are widely used in the development of software and hardware frameworks for wearable computing, mixed reality, and the Internet of Everything.
- C and C++ provide low-level control over hardware, making them suitable for developing efficient and high-performance systems.
- C and C++ are commonly used in the development of operating systems, device drivers, and embedded systems.
- C and C++ have a large and active developer community, with many libraries and tools available for use in development.
- C and C++ have a steep learning curve, but mastery of these languages can provide a strong foundation for further learning and development in the field of wearable computing, mixed reality, and the Internet of Everything.
