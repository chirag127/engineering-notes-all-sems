# PHP/Web for Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE in WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- PHP is a server-side scripting language designed for web development.
- PHP code is executed on the server, and the result is returned to the client as plain HTML.
- PHP can be used to create dynamic and interactive websites.
- PHP can be embedded into HTML, or it can be used in combination with various web template systems, web content management systems, and web frameworks.
- PHP supports a wide range of databases, including MySQL, Oracle, and Microsoft SQL Server.
- PHP is free software released under the PHP License.
- PHP has a large and active community of developers, with many resources available for learning and support.
- PHP is used by many popular websites, including Facebook and Wikipedia.
- PHP has many built-in functions for handling common web tasks, such as handling forms, cookies, and sessions.
- PHP can be used to create a wide range of web applications, including content management systems, e-commerce systems, and social networking sites.
