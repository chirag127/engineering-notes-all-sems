# Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE

## Open Frameworks

OpenFrameworks is an open-source C++ toolkit designed to assist the creative process by providing a simple and intuitive framework for experimentation. It is commonly used in the development of projects that involve real-time processing of audio and visual media.

In the context of wearable computing, mixed reality, and the Internet of Everything, openFrameworks can be used to develop applications that embody humanistic intelligence (HI). HI is intelligence that arises when a human is part of the feedback loop of a computational process in which the human and computer are inextricably intertwined.

Some examples of projects that can be developed using openFrameworks in this context include:

- Wearable devices that use sensors to gather data about the user's environment and provide real-time feedback to the user.
- Mixed reality applications that use computer vision and machine learning to enhance the user's perception of their surroundings.
- Internet of Everything applications that use data from multiple sources to provide the user with context-aware information and services.

Overall, openFrameworks provides a powerful and flexible tool for developing applications that leverage the latest advances in wearable computing, mixed reality, and the Internet of Everything to create new forms of humanistic intelligence.
