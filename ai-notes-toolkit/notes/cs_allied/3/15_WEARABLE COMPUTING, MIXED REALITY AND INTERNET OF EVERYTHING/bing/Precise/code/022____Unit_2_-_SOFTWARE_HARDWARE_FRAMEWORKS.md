## Unit 2 - SOFTWARE HARDWARE FRAMEWORKS

1. **Software** refers to the programs and data that run on a computer or other device. It includes operating systems, applications, and utilities.

2. **Hardware** refers to the physical components of a computer or other device, such as the central processing unit (CPU), memory, storage, and input/output devices.

3. A **framework** is a set of guidelines, concepts, and tools that provide a structure for developing software applications.

4. **Software frameworks** provide a reusable structure for common tasks, such as user interface design, data management, and network communication.

5. **Hardware frameworks** provide a standardized way of interfacing with hardware components, such as sensors, actuators, and displays.

6. **Software-hardware frameworks** combine the benefits of both software and hardware frameworks, allowing developers to create applications that can interact with hardware in a standardized way.

7. Examples of software-hardware frameworks include the Android operating system, which provides a standardized way for developers to create applications that can run on a wide range of devices, and the Arduino platform, which provides a standardized way for developers to create applications that can interact with sensors and other hardware components.

8. The use of software-hardware frameworks can greatly simplify the development process, allowing developers to focus on creating innovative applications rather than dealing with the complexities of hardware and software integration.
