### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- C and C++ are both programming languages.
- C is a procedural language, while C++ is an object-oriented language.
- C++ is an extension of C, with additional features such as classes, inheritance, and polymorphism.
- Both languages are widely used in the development of software and hardware frameworks for wearable computing, mixed reality, and the Internet of Everything.
- C and C++ are known for their efficiency and performance, making them suitable for use in resource-constrained environments such as wearable devices.
- C and C++ provide low-level access to hardware, allowing developers to write code that interacts directly with the device's sensors and other hardware components.
- Many libraries and frameworks are available for C and C++ that can be used to develop applications for wearable computing, mixed reality, and the Internet of Everything.
- C and C++ are widely taught in computer science and engineering programs, and there is a large community of developers who use these languages.
