### Unit 1 - INTRODUCTION: Variables and Flow Control in Wearable Computing, Mixed Reality and Internet of Everything

#### Variables
- A variable is a named storage location that can hold a value.
- The value of a variable can change during the execution of a program.
- Variables are used to store and manipulate data in a program.
- In wearable computing, mixed reality, and the Internet of Everything, variables can be used to store sensor data, user input, and other information.

#### Flow Control
- Flow control refers to the order in which statements in a program are executed.
- Flow control structures, such as conditional statements and loops, allow a program to make decisions and repeat actions.
- In wearable computing, mixed reality, and the Internet of Everything, flow control can be used to respond to sensor data, user input, and other events.
- Common flow control structures include if-else statements, for loops, and while loops.
