### Open Source Platforms for Wearable Computing, Mixed Reality and Internet of Everything

- Open source platforms are software or hardware systems that are publicly available and can be modified, distributed, and used by anyone.
- Open source platforms can facilitate the development, deployment, and integration of wearable computing, mixed reality, and internet of everything applications.
- Some examples of open source platforms for wearable computing, mixed reality, and internet of everything are:

  - **Eclipse Kura**: A platform for building IoT gateways that can connect, manage, and control devices and sensors.
  - **ThingSpeak**: An IoT platform and API for data collection and analytics that can be used for wearable computing and internet of everything applications.
  - **Zetta**: An API-first platform for the internet of things that uses JavaScript to express devices as state machines and generate HTTP APIs for them .
  - **Open Hybrid**: A platform for interacting with everyday objects using augmented reality and web technologies.
  - **Node-RED**: A flow-based programming tool for wiring together devices, APIs, and online services for IoT applications.
  - **Wio Link**: A platform for creating IoT devices using plug-and-play modules and a mobile app.
  - **Macchina.io**: A platform for building IoT edge applications using JavaScript and C++ that can run on Linux-based devices.
  - **Physical Web**: A platform for interacting with physical objects using web URLs and Bluetooth Low Energy beacons.
  - **Azure IoT**: A cloud-based platform for building and managing IoT solutions that can integrate with mixed reality and wearable computing devices.
  - **8th Wall**: A phone-based augmented reality platform that uses JavaScript and WebGL to create AR experiences that run on a mobile browser.
