# Software for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Software hardware frameworks are the systems and tools that enable the development and deployment of applications for wearable computing, mixed reality and internet of everything.
- Wearable computing is the integration of computing devices into clothing or accessories that can be worn by users, such as smart watches, glasses, headsets, etc.
- Mixed reality is the blending of physical and digital worlds, where users can interact with both real and virtual objects and environments, such as augmented reality, virtual reality, etc.
- Internet of everything is the concept of connecting any device or entity to the internet and to each other, such as sensors, actuators, machines, people, etc.
- Some examples of software hardware frameworks for wearable computing, mixed reality and internet of everything are:

  - **Azure IoT**: A cloud platform that provides various services and solutions for connecting, managing, and analyzing data from IoT devices and applications.
  - **UbiVis**: A framework that enables ubiquitous mixed reality applications that can run on different hardware devices and support collaborative scenarios.
  - **MRCP**: A secure mixed reality framework that allows users to interact with headless IoT devices using a vendor-neutral, open-source, cross-platform software.
  - **Unity**: A game engine and development platform that supports various platforms and devices for creating immersive and interactive 3D and 2D content, such as games, simulations, etc.
  - **Android Wear**: An operating system and software development kit that extends the Android platform to wearable devices, such as smart watches, fitness trackers, etc.
  - **Arduino**: An open-source hardware and software platform that consists of microcontroller boards, sensors, actuators, and a programming environment for creating interactive electronic projects.
