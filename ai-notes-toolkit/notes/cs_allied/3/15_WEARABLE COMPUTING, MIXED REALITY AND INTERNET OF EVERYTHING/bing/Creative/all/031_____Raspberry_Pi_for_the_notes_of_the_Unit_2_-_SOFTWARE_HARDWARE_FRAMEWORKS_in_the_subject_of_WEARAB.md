# Raspberry Pi

- Raspberry Pi is a small, low-cost, single-board computer the size of a credit card that allows people from different backgrounds and levels of expertise to experience and learn to compute  .
- Raspberry Pi uses what's called a system on a chip, which integrates the CPU and GPU in a single integrated circuit, with the RAM, USB ports, and other components soldered onto the board for an all-in-one package.
- Raspberry Pi can plug into a computer monitor or TV, and use a standard keyboard and mouse. It can also connect to the internet via Ethernet or Wi-Fi.
- Raspberry Pi can run various operating systems, such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, and others. It can also run various programming languages, such as Scratch, Python, Java, C, and others.
- Raspberry Pi can be used for various purposes, such as education, gaming, robotics, media, home automation, and more  . It can also interface with various sensors, cameras, and other devices via the 40-pin GPIO header  .
- Raspberry Pi is developed and supported by the Raspberry Pi Foundation, a UK-based charity that aims to make computing accessible and affordable for everybody . The Raspberry Pi Foundation also provides various resources, such as online courses, magazines, books, and projects, to help users learn and create with Raspberry Pi.
