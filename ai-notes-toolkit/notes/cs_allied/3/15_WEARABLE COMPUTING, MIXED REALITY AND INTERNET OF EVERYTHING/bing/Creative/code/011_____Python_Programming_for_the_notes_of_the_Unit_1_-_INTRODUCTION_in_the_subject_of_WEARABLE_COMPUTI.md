### Python Programming for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Python is a popular, general-purpose, high-level, and object-oriented programming language that was created by Guido van Rossum in 1991   .
- Python has a simple and expressive syntax that is similar to the English language and allows developers to write programs with fewer lines of code than some other programming languages .
- Python is an interpreted language, which means that the source code is executed line by line by an interpreter without the need for compilation .
- Python supports multiple programming paradigms, such as procedural, object-oriented, functional, and imperative programming .
- Python has a large and comprehensive standard library that provides built-in modules and functions for various tasks, such as file handling, database connectivity, web development, data analysis, machine learning, etc  .
- Python is a cross-platform language that can run on different operating systems, such as Windows, Mac, Linux, Raspberry Pi, etc .
- Python is widely used in various domains, such as web development, data science, machine learning, artificial intelligence, automation, game development, etc .
- Python is also suitable for developing applications for wearable computing, mixed reality, and internet of things, as it can interact with sensors, cameras, microcontrollers, and other devices using libraries and frameworks, such as PySerial, OpenCV, PyGame, PyTorch, TensorFlow, etc .
