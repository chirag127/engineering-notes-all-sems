# Creative Coding Platforms

- Creative coding is the practice of using programming languages and techniques to create artistic expressions, such as animations, games, music, interactive design, and generative art.
- Creative coding platforms are tools or environments that enable and support creative coding, by providing features such as libraries, frameworks, editors, compilers, debuggers, and online communities.
- Some examples of creative coding platforms are:

  - **Processing**: A flexible software sketchbook and a language for learning how to code within the context of the visual arts. Processing is based on Java and can run on multiple platforms. It has a large and active community of users and contributors, and many libraries and modes for extending its functionality. 
  - **p5.js**: A JavaScript library that makes coding accessible and inclusive for artists, designers, educators, beginners, and anyone else. p5.js is based on the core principles of Processing and can be used to create graphics, animations, and interactive web pages. p5.js also has a web editor and a collection of examples and tutorials. 
  - **Scratch**: A free creative coding platform and online community that allows children of all ages to code, share, and remix their own stories, games, and animations. Scratch is translated into 50+ languages and available both online and offline. Scratch uses a block-based programming language that is easy to learn and use. 
  - **Tynker**: A leading K-12 creative coding platform that enables students of all ages to develop the coding skills to design and power animations, games, music, robots and drones, smart devices, virtual worlds like Minecraft, and more. Tynker offers a variety of courses, activities, and projects for different levels and interests. 
  - **OpenProcessing**: A platform that empowers artists, designers, students, and anyone to learn to code and express themselves creatively on the web. OpenProcessing allows users to create and share sketches using Processing or p5.js, and to explore and remix the work of others. OpenProcessing also has a classroom mode for teachers and students. 

- Creative coding platforms can be used for various purposes, such as:

  - Learning and teaching programming concepts and skills in a fun and engaging way.
  - Exploring and experimenting with different forms of digital art and media.
  - Developing and showcasing personal or collaborative projects and portfolios.
  - Participating and contributing to online communities and events of creative coders.
