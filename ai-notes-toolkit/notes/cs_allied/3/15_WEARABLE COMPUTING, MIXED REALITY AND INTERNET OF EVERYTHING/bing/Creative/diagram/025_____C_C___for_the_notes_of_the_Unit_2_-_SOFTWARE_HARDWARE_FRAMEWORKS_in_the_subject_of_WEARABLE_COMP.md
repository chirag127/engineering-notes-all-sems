### C/C++ for Wearable Computing

- C/C++ is a low-level programming language that allows direct access to hardware components and memory management.
- C/C++ is widely used for developing drivers and middleware for camera and wearable computing on cutting edge new hardware components.
- C/C++ is also suitable for optimizing for constrained environments of low power mobile devices by writing efficient and fast code.
- C/C++ can be used with Arduino development kits to experiment with building wearable devices from scratch.
- C/C++ can also be used with various frameworks and libraries that support wearable computing, such as:
  - OpenCV: a computer vision library that can be used for face detection, gesture recognition, object tracking, etc. on wearable devices.
  - TensorFlow Lite: a lightweight machine learning framework that can run on-device inference for speech recognition, natural language processing, image classification, etc. on wearable devices.
  - Wearable Computing Framework (WCF): a software framework for intelligence augmentation research and applications that provides built-in voice command, speech recognition, computer vision, UI, sensors, smart phone connection, NLP, facial recognition, database, cloud connection, and more.
