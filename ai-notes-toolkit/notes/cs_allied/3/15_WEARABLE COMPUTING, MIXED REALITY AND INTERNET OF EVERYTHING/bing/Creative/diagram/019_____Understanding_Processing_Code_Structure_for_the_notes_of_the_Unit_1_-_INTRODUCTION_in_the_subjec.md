### Understanding Processing Code Structure

- Processing is a programming language and environment for creating interactive graphics, animations, and games.
- Processing code consists of two main parts: setup() and draw() blocks .
  - The setup() block runs once when the code gets executed, and it is used to initialize variables, load images, set the window size, etc.
  - The draw() block runs continuously, and it is used to update the screen with graphics, animations, and user interactions.
  - The main idea behind Processing is, what you write within the draw() block will be executed 60 times per second from top to bottom, until your program terminates.
- Processing also supports other types of blocks, such as mousePressed(), keyPressed(), and other event handlers, that can respond to user input and modify the state of the program.
- Processing code can be organized into functions, classes, and libraries, to make it more modular, reusable, and readable.
  - Functions are blocks of code that perform a specific task, and can be called from other parts of the code. Functions can have parameters and return values, to pass data between them.
  - Classes are templates for creating objects, which are data structures that have properties and methods. Objects can encapsulate data and behavior, and interact with other objects.
  - Libraries are collections of classes and functions that provide additional functionality, such as sound, video, networking, etc. Libraries can be imported into a Processing sketch using the import statement.
- Processing code can be written and run in different modes, such as Java mode, Python mode, Android mode, etc., to target different platforms and languages.
  - Java mode is the default mode, and it uses the Java syntax and the Processing core library. Java mode can run on desktop computers and web browsers, using the Java Runtime Environment (JRE).
  - Python mode uses the Python syntax and the Processing core library. Python mode can run on desktop computers and web browsers, using the Python interpreter.
  - Android mode uses the Java syntax and the Processing core library, along with the Android SDK. Android mode can run on Android devices, such as smartphones and tablets.
- Processing code can be written and edited in different environments, such as the Processing Development Environment (PDE), the Processing IDE (p5.js), or other text editors and IDEs.
  - The Processing Development Environment (PDE) is the official editor for Processing, and it provides features such as syntax highlighting, auto-completion, error checking, etc. The PDE can run and export Processing sketches, and manage libraries and modes.
  - The Processing IDE (p5.js) is a web-based editor for Processing, and it uses the p5.js library, which is a JavaScript implementation of the Processing core library. The Processing IDE can run Processing sketches in the web browser, and share them online.
  - Other text editors and IDEs, such as Sublime Text, Atom, Eclipse, etc., can also be used to write and edit Processing code, with the help of plugins and extensions that support Processing syntax and features.
