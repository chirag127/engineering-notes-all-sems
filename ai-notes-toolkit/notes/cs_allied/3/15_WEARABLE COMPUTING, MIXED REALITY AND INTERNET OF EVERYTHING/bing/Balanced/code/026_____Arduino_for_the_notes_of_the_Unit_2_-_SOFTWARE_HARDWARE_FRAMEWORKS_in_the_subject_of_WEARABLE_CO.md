### Arduino for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Arduino is an open-source electronics platform that allows users to create interactive projects using various sensors, actuators, and communication modules.
- Arduino boards are based on microcontrollers that can be programmed using the Arduino IDE, a cross-platform software that supports C and C++ languages.
- Arduino boards can be connected to other devices such as computers, smartphones, or wearables using serial, USB, Bluetooth, Wi-Fi, or other protocols.
- Arduino boards can also be extended with shields, which are additional boards that provide specific functionalities such as GPS, Ethernet, LCD, etc.
- Arduino boards are suitable for wearable computing projects because they have a small form factor, low power consumption, and a large community of users and developers .
- Some examples of wearable computing projects using Arduino are:
  - Arduino Lightsaber: a project that uses an Arduino Nano, a WS2812B LED strip, a speaker, and a battery to create a realistic lightsaber with sound and light effects.
  - Arduino Motion Control: a project that uses an Arduino Uno, a Tactigon ONE, and an Alphabot2 to create a gesture-controlled robot car.
  - Arduino FLORA: a wearable microcontroller board that has a micro USB port and an onboard programmable NeoPixel for color-changing effects. It can be used with conductive thread or wire to create wearable projects such as LED bracelets, jackets, hats, etc.
  - Arduino AIfES: a standalone AI framework written in C that allows on-device training of artificial neural networks (ANNs) on almost any hardware, including 8-bit controllers. It can be used for applications such as gesture recognition, voice control, etc.
  - Arduino Fall Detector: a project that uses an Arduino Nano 33 BLE Sense, an accelerometer, and a buzzer to create a wearable device that sends an alert whenever it detects a fall.
