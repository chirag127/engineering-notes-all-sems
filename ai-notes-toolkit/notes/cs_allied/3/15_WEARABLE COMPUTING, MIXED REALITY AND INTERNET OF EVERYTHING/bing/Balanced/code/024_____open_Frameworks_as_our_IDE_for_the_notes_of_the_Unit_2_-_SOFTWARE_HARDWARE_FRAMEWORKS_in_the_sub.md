### openFrameworks as our IDE

- openFrameworks is an open source C++ toolkit for creative coding.
- It is designed to simplify the process of creating applications that use graphics, sound, video, computer vision, networking and other interactive elements.
- It supports multiple platforms, such as Windows, Linux, macOS, iOS, Android, Raspberry Pi, etc.
- It also supports multiple development environments, such as Visual Studio, Xcode, Code::Blocks, Eclipse, etc.
- To use openFrameworks, you need to download the appropriate version for your platform and IDE from the official website.
- You also need to follow the setup guide for your platform and IDE, which will walk you through the steps of creating and running an openFrameworks project.
- openFrameworks comes with a set of core libraries that provide basic functionality, such as graphics, sound, video, math, events, etc.
- It also comes with a collection of addons that extend the functionality of openFrameworks, such as computer vision, networking, physics, etc.
- You can also create your own addons or use addons created by the openFrameworks community.
- openFrameworks follows a convention over configuration approach, which means that it has a predefined structure and naming for files and folders, and it expects you to follow them.
- openFrameworks uses a simple and consistent API, which makes it easy to learn and use.
- openFrameworks is distributed under the MIT License, which means that you can use it for any purpose, including commercial projects, without any restrictions.
- openFrameworks is a community-driven project, which means that you can contribute to its development, report bugs, request features, or ask questions on its GitHub repository or forum .
- openFrameworks is inspired by other creative coding frameworks, such as Processing, Cinder, and openFrameworks.
