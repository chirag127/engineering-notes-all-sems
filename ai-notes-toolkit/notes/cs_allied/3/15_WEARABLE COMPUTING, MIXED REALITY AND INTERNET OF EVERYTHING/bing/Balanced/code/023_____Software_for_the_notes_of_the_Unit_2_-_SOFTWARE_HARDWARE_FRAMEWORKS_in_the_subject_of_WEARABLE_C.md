### Software for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS

- Software is the set of instructions, data, and programs that enable a computer system or device to perform specific tasks.
- Software can be classified into two main categories: system software and application software.
- System software is the software that provides the basic functions and services for the hardware and other software, such as operating systems, drivers, firmware, and utilities.
- Application software is the software that performs specific tasks for the user, such as word processors, games, browsers, and apps.
- Software can also be categorized by the level of abstraction, such as low-level software and high-level software.
- Low-level software is the software that directly interacts with the hardware, such as machine code, assembly language, and device drivers.
- High-level software is the software that is more abstract and human-readable, such as programming languages, libraries, and frameworks.
- Software can also be categorized by the mode of delivery, such as installed software and web-based software.
- Installed software is the software that is stored and executed on the local device, such as desktop applications, mobile apps, and embedded software.
- Web-based software is the software that is accessed and executed over the internet, such as web applications, cloud services, and web APIs.
- Software can also be categorized by the type of interaction, such as graphical user interface (GUI) software and command-line interface (CLI) software.
- GUI software is the software that uses graphical elements, such as windows, icons, menus, and buttons, to interact with the user, such as Windows, macOS, and Android.
- CLI software is the software that uses text commands and responses to interact with the user, such as Linux, DOS, and PowerShell.
- Software can also be categorized by the type of development, such as proprietary software and open source software.
- Proprietary software is the software that is owned and controlled by a specific entity, such as a company or an individual, and has restricted access and distribution, such as Microsoft Office, Adobe Photoshop, and iOS.
- Open source software is the software that is publicly available and can be modified and distributed by anyone, such as Linux, Firefox, and Android.
