# Push and Pull for the Notes of the Unit 3 - Cybernetics and Humanistic Intelligence in the Subject of Wearable Computing, Mixed Reality and Internet of Everything

- Push and pull are two different modes of communication and interaction between agents in a cybernetic system.
- Push mode is when an agent initiates a message or an action to another agent, without waiting for a request or a response from the receiver. For example, a push notification on a smartphone, a push email, or a push GitOps agent that deploys code to a target environment .
- Pull mode is when an agent requests a message or an action from another agent, and waits for a response or a confirmation from the provider. For example, a pull request on GitHub, a pull email, or a pull GitOps agent that synchronizes the state of a target environment with a source of truth .
- Push and pull modes have different advantages and disadvantages, depending on the context and the goal of the communication and interaction.
- Push mode can be more efficient, proactive, and timely, as it does not depend on the availability or the readiness of the receiver. However, push mode can also be more intrusive, disruptive, and wasteful, as it may send unwanted or unnecessary messages or actions to the receiver, or overload the receiver's capacity or attention.
- Pull mode can be more selective, responsive, and flexible, as it allows the receiver to choose when and what to request or receive from the provider. However, pull mode can also be more passive, reactive, and delayed, as it may miss important or urgent messages or actions from the provider, or depend on the provider's availability or reliability.
- Push and pull modes can work together in a cybernetic system, creating a balance between demand and supply, or between control and autonomy. For example, push and pull marketing strategies can complement each other, creating demand for a product or service with a push, and satisfying that demand with a pull. Similarly, push and pull security strategies can work together, preventing or detecting threats with a push, and responding or recovering from them with a pull.
- Push and pull modes can also create tensions or conflicts in a cybernetic system, as different agents may have different preferences, expectations, or interests in the communication and interaction. For example, push and pull visibility on social media platforms can generate a constant push-and-pull between digital users and the platform, as they co-define the algorithmic power and the algorithmic imaginary.
