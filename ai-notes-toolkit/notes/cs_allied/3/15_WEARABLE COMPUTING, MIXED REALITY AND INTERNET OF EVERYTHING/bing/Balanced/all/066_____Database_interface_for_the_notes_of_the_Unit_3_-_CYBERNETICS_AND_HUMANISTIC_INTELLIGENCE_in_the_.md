# Database interface for the notes of the Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Cybernetics is the science of communication and control in living organisms and machines.
- Humanistic intelligence (HI) is a new signal processing framework in which intelligence arises by having the human being in the feedback loop of the computational process, and the processing apparatus is inextricably intertwined with the natural capabilities of the human mind and body .
- Wearable computing is the perfect tool for embodying HI, as it allows the human and the computer to be closely coupled and mutually adaptive .
- Wearable computing can facilitate new forms of communication through collective connected HI, in which multiple humans and computers form a network of intelligence and interaction .
- Mixed reality (MR) is the blending of physical and digital worlds, creating new environments and visualizations where physical and digital objects co-exist and interact in real time.
- Internet of everything (IoE) is the network of physical objects, people, processes and data that are interconnected and communicate with each other through the internet.
- A database interface is a software component that allows users to interact with a database system, such as creating, querying, updating and deleting data.
- A database interface for the notes of the Unit 3 can be designed using the following steps:
  - Define the data model and schema for the notes, such as the attributes, types, constraints and relationships of the data entities.
  - Choose a database management system (DBMS) that supports the data model and schema, such as relational, document, graph or key-value DBMS.
  - Implement the database interface using a programming language and a database driver or library that can connect to the DBMS and execute database operations.
  - Design the user interface and the application logic for the database interface, such as the input forms, output displays, navigation menus and error handling.
  - Test and debug the database interface to ensure its functionality, usability, security and performance.
