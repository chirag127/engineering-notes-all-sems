# Python Programming for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Python is a versatile, object-oriented programming language that can be used for various applications, such as web development, data analysis, machine learning, and Internet of Things (IoT) .
- IoT is the network of physical devices, sensors, and actuators that can communicate and exchange data over the internet, enabling new possibilities for automation, monitoring, and control .
- Wearable computing is a subset of IoT that focuses on devices that can be worn on the body, such as smartwatches, fitness trackers, smart glasses, and augmented reality (AR) headsets .
- Mixed reality is a term that encompasses both augmented reality and virtual reality (VR), which are technologies that create immersive and interactive experiences by overlaying or replacing the real world with digital content .
- Python can be used to program IoT and wearable devices, as well as to create mixed reality applications, using various libraries, frameworks, and platforms, such as Arduino, Raspberry Pi, Hexiwear, Wireshark, PyGame, and PyOpenGL   .
- In this unit, we will learn the basics of Python programming, such as syntax, data types, operators, control structures, functions, and modules, and how to apply them to IoT, wearable computing, and mixed reality scenarios. We will also learn how to use Python to communicate with IoT and wearable devices, and how to create simple mixed reality applications using PyGame and PyOpenGL.
