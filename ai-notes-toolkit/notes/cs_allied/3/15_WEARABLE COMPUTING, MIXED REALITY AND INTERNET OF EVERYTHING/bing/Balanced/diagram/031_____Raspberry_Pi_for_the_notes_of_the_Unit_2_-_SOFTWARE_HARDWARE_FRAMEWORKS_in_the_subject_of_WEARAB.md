### Raspberry Pi

- Raspberry Pi is a **low-cost, credit-card sized computer** that can be used for various purposes such as physical computing, Internet of Things, education, gaming, and media   .
- Raspberry Pi uses a **system on a chip (SoC)**, which integrates the CPU and GPU in a single integrated circuit, with the RAM, USB ports, and other components soldered onto the board.
- Raspberry Pi has various **input and output ports** such as HDMI, USB, Ethernet, audio, camera, display, and GPIO (general-purpose input/output) to connect to peripherals and sensors .
- Raspberry Pi can run various **operating systems** such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, and others, depending on the model and the user's preference .
- Raspberry Pi can be programmed in various **languages** such as Scratch, Python, C, Java, and others, using various tools and frameworks such as Thonny, PyCharm, Visual Studio Code, and others .
- Raspberry Pi can be used for various **projects** such as home automation, robotics, gaming, web servers, security cameras, digital art, and others, depending on the user's creativity and skills   .
- Raspberry Pi is supported by the **Raspberry Pi Foundation**, a UK-based charity that aims to make computing accessible and affordable for everybody, and provides various resources and programs for learning and teaching .
