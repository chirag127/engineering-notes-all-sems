# Variables and Flow Control

## Variables
- Variables are named containers that store data or values in a program.
- Variables can have different data types, such as integers, floats, strings, booleans, etc.
- Variables can be declared, assigned, and used in a program to perform operations, store results, and pass arguments.
- Variables can have different scopes, such as global, local, or static, depending on where and how they are defined and accessed.
- Variables can be modified, deleted, or reused in a program, depending on the rules and logic of the programming language.

## Flow Control
- Flow control is the process of determining the order and direction of execution of statements in a program based on certain conditions or parameters.
- Flow control can be achieved by using control structures, which are blocks of code that analyze variables and choose a path to follow.
- There are three basic types of control structures: sequence, selection, and iteration.
- Sequence is the default flow of control, where statements are executed one after another in the order they appear in the program.
- Selection is the conditional flow of control, where statements are executed based on the evaluation of a condition or expression. Examples of selection structures are if, if-else, switch, etc.
- Iteration is the repetitive flow of control, where statements are executed multiple times until a condition or expression is met or a break statement is encountered. Examples of iteration structures are for, while, do-while, etc.
