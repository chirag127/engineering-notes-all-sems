### MAC 802.15.4

- MAC 802.15.4 is a standard for low-rate wireless personal area networks (LR-WPANs) that defines the physical layer (PHY) and medium access control (MAC) sublayer specifications  .
- MAC 802.15.4 supports low-data-rate wireless connectivity with fixed, portable, and moving devices with no battery or very limited battery consumption requirements .
- MAC 802.15.4 provides the basis of other higher-layer standards, such as ZigBee, WirelessHart, 6LoWPAN and MiWi.
- MAC 802.15.4 supports multiple PHY options, such as frequency shift keying (FSK), orthogonal frequency division multiplexing (OFDM), and high-rate pulse (HRP) ultra-wideband (UWB) .
- MAC 802.15.4 uses a frame structure that consists of a MAC header, a MAC payload, and a MAC footer. The MAC header contains information such as frame type, frame control, sequence number, addressing fields, and security fields. The MAC payload contains the network-layer frame or the MAC command frame. The MAC footer contains a cyclic redundancy check (CRC) for error detection .
- MAC 802.15.4 supports two types of network topologies: star and peer-to-peer. In a star topology, a central coordinator node controls the communication among the other nodes. In a peer-to-peer topology, any node can communicate with any other node within its radio range.
- MAC 802.15.4 supports two types of channel access methods: beacon-enabled and non-beacon-enabled. In a beacon-enabled mode, the coordinator node periodically broadcasts beacons to synchronize the nodes and define the superframe structure. The superframe consists of an active period and an inactive period. The active period is divided into 16 equally sized slots, which can be allocated for contention-based or contention-free access. The inactive period is used for power saving. In a non-beacon-enabled mode, there is no superframe structure and the nodes use a slotted or unslotted carrier sense multiple access with collision avoidance (CSMA-CA) algorithm to access the channel.
- MAC 802.15.4 supports various security features, such as encryption, authentication, integrity, replay protection, and freshness. MAC 802.15.4 uses the advanced encryption standard (AES) with a 128-bit key for encryption and authentication. MAC 802.15.4 also supports different security levels and security modes, such as unsecured, secured with MAC sublayer security, and secured with network layer security.
