# IPv4

IPv4 (Internet Protocol version 4) is the fourth version of the Internet Protocol (IP). It is one of the core protocols of standards-based internetworking methods in the Internet and other packet-switched networks. IPv4 was the first version of the Internet Protocol to be widely deployed, and forms the basis for much of the current Internet infrastructure.

Some key points to note about IPv4 are:

- IPv4 is a connectionless protocol, meaning that it does not establish a connection before sending data.
- IPv4 uses 32-bit addresses, which limits the address space to 4,294,967,296 (2^32) addresses.
- IPv4 addresses are typically written in dotted-decimal notation, with four 8-bit numbers separated by periods, such as 192.168.1.1.
- IPv4 includes a checksum to verify the integrity of the header, but does not include any error correction or recovery mechanisms.
- IPv4 includes a Time to Live (TTL) field, which specifies the maximum number of hops a packet can take before being discarded.
- IPv4 supports fragmentation, which allows a large packet to be split into smaller packets for transmission over a network with a smaller maximum transmission unit (MTU).
- IPv4 includes options for security, source routing, and other special features, but these are not commonly used.
