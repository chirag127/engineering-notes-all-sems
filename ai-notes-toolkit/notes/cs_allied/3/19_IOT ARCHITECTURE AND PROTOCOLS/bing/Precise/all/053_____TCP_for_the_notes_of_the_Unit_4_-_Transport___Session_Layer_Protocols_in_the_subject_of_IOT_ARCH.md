# TCP - Transport Control Protocol

TCP is one of the main protocols in the Transport Layer of the Internet Protocol Suite. It is used to provide reliable, ordered, and error-checked delivery of data between applications running on different hosts.

Some key features of TCP include:

1. Connection-oriented: TCP is a connection-oriented protocol, which means that a connection must be established between the two endpoints before data can be transmitted.

2. Reliable data transfer: TCP uses a number of mechanisms to ensure that data is transmitted reliably, including error detection, retransmission of lost packets, and flow control.

3. Ordered data transfer: TCP ensures that data is delivered in the order in which it was sent.

4. Congestion control: TCP uses a number of mechanisms to avoid overwhelming the network with too much data, including slow start, congestion avoidance, and congestion recovery.

5. Flow control: TCP uses a sliding window mechanism to control the flow of data between the two endpoints, ensuring that the sender does not overwhelm the receiver with too much data.

TCP is widely used in many applications, including the World Wide Web, email, and file transfer. It is a key component of the Internet Protocol Suite and is essential for the reliable transmission of data over the Internet.
