# 6TiSCH

6TiSCH is a standard developed by the Internet Engineering Task Force (IETF) for the 802.15.4 MAC layer protocols. It stands for IPv6 over the Time-Slotted Channel Hopping (TSCH) mode of IEEE 802.15.4e MAC layer. This standard allows IPv6 addresses to pass through the TSCH mode, so that the IPv6 adaptation layer can be used for industrial automation and Low Power Lossy Networks (LLN).

The 6TiSCH architecture and protocol suite includes the 6TiSCH Operation Sublayer (6top), the 6top Protocol (6P), and how it uses 6LoWPAN, IP-in-IP encapsulation, and RPL. The suite also defined protocol extensions to transport routing information (RFC6553) and enable downward source routes (RFC6554). 6TiSCH provides a mechanism by which the link layer topology is matched with the routing topology, enabling the nodes to maintain synchronization with their best-connected parent.

The 6TiSCH network is intended to provide reliable and delay bounded communication in multi-hop and scalable Industrial Internet of Things (IIoT).
