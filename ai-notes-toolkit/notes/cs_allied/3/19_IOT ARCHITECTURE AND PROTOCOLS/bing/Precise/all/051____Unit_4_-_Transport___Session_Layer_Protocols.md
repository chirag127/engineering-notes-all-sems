## Unit 4 - Transport & Session Layer Protocols

The transport layer is responsible for providing end-to-end communication services for applications. It provides services such as connection-oriented data stream support, reliability, flow control, and multiplexing.

Some of the key protocols in the transport layer include:

1. **Transmission Control Protocol (TCP)**: This is a connection-oriented protocol that provides reliable, ordered, and error-checked delivery of data between applications running on different hosts. It is widely used in applications such as the World Wide Web, email, and file transfer.

2. **User Datagram Protocol (UDP)**: This is a connectionless protocol that provides a simple, unreliable datagram service. It is used in applications where speed is more important than reliability, such as online gaming, voice over IP, and video streaming.

The session layer is responsible for establishing, managing, and terminating connections between applications. It provides services such as authentication, authorization, and session restoration.

Some of the key protocols in the session layer include:

1. **Session Initiation Protocol (SIP)**: This is a signaling protocol used for initiating, maintaining, modifying, and terminating real-time sessions of multimedia communication over the Internet.

2. **Remote Procedure Call (RPC)**: This is a protocol that allows a program to request a service from a program located on another computer in a network without having to understand the network's details.

These are some of the key protocols in the transport and session layers. They play a crucial role in enabling communication between applications over a network.
