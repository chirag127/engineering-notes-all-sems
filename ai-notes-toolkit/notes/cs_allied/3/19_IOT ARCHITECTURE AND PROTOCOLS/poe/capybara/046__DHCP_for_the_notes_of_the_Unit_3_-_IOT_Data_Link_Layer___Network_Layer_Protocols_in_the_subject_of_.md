### DHCP

- DHCP stands for Dynamic Host Configuration Protocol, which is a network management protocol used to assign IP addresses and other network configuration parameters dynamically to devices on a network.
- DHCP is commonly used in Internet of Things (IoT) networks to simplify the process of configuring devices that may not have a user interface or may be difficult to configure manually.
- DHCP operates at the data link layer and network layer of the OSI model.
- DHCP consists of two main components: the DHCP server and the DHCP client.
- The DHCP server is responsible for assigning IP addresses and other network configuration parameters to DHCP clients on the network.
- The DHCP client is the device that requests an IP address and other configuration parameters from the DHCP server.
- When a DHCP client connects to a network, it sends a DHCP discovery message to the network to locate a DHCP server.
- The DHCP server responds with a DHCP offer message, which includes an IP address and other configuration parameters that the client can use.
- The client then sends a DHCP request message to accept the offered IP address and other configuration parameters.
- The DHCP server sends a DHCP acknowledgement message to confirm that the client has been assigned the requested IP address and configuration parameters.
- DHCP can also be used to assign IP addresses dynamically to devices on a temporary basis, which is known as DHCP leasing.
- DHCP leasing allows network administrators to manage IP addresses more efficiently and avoid IP address conflicts.
- DHCP can also be used to assign other network configuration parameters to devices, such as subnet masks, default gateways, and Domain Name System (DNS) servers.
- Overall, DHCP is an important protocol in IoT networks, as it simplifies the process of configuring network devices and helps to ensure that devices are assigned unique IP addresses and other network configuration parameters.
