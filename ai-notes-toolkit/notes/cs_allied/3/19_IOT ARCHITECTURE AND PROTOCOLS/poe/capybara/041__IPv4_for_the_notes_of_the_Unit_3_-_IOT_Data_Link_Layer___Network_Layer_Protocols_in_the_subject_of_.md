### IPv4

IPv4 stands for Internet Protocol Version 4. It is the fourth version of the Internet Protocol (IP), which is used to identify devices on a network. IPv4 is the most widely used protocol for connecting devices to the internet.

Here are some key points to remember about IPv4:

- IPv4 addresses are made up of 32 bits, divided into four 8-bit octets.
- Each octet is represented by a decimal number between 0 and 255.
- An IPv4 address is written in dotted decimal notation, with each octet separated by a period. For example, 192.168.0.1.
- IPv4 addresses are used to identify devices on a network and to route data between them.
- IPv4 is a connectionless protocol, which means that data is sent in packets that are treated independently by the network.
- IPv4 packets have a maximum size of 64 kilobytes.
- IPv4 includes several protocols for addressing, routing, and transmitting data, including the User Datagram Protocol (UDP) and the Transmission Control Protocol (TCP).
- IPv4 has several limitations, including a finite number of available addresses and security vulnerabilities.

Overall, IPv4 is an important protocol for connecting devices to the internet and enabling communication between them. However, as the number of connected devices continues to grow, the limitations of IPv4 are becoming more apparent, and newer protocols like IPv6 are being developed to address these challenges.
