## Unit 4 - Transport & Session Layer Protocols

In this unit, we will discuss the Transport and Session Layer Protocols, which are essential components of the TCP/IP protocol suite. These protocols enable communication between applications running on different hosts and ensure that data is transmitted reliably and efficiently across the network.

### Transport Layer Protocols

The Transport Layer is responsible for providing end-to-end communication between applications running on different hosts. The two most commonly used Transport Layer protocols are:

1. **Transmission Control Protocol (TCP)** - TCP is a connection-oriented protocol that provides reliable, ordered, and error-checked delivery of data between applications. It establishes a virtual circuit between the two endpoints before transmitting data and ensures that all data is received in the correct order.

2. **User Datagram Protocol (UDP)** - UDP is a connectionless protocol that provides fast, unreliable, and unordered delivery of data between applications. It does not establish a virtual circuit before transmitting data and does not guarantee that all data will be received or received in the correct order.

### Session Layer Protocols

The Session Layer is responsible for managing and establishing sessions between applications running on different hosts. The two most commonly used Session Layer protocols are:

1. **Remote Procedure Call (RPC)** - RPC is a protocol that allows a program on one computer to execute code on a remote computer over the network. It enables applications to communicate with each other across different systems in a transparent manner.

2. **Session Initiation Protocol (SIP)** - SIP is a protocol that is used for initiating, modifying, and terminating multimedia sessions between two or more endpoints on the network. It is commonly used for voice and video conferencing, instant messaging, and online gaming.

In conclusion, understanding the Transport and Session Layer Protocols is essential to building and maintaining a reliable network. TCP and UDP are the two most commonly used Transport Layer Protocols, while RPC and SIP are the two most commonly used Session Layer Protocols. Each of these protocols plays a critical role in ensuring that data is transmitted reliably and efficiently across the network.
