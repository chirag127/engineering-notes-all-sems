
### AMQP for the Notes of Unit 4 - Transport & Session Layer Protocols in the Subject of IOT ARCHITECTURE AND PROTOCOLS

- Advanced Message Queuing Protocol (AMQP) is a messaging protocol that enables applications to communicate with each other using a message broker.
- It is an open standard wire-level protocol that is used to facilitate the exchange of messages between applications.
- AMQP defines the structure of the messages and how they are routed between the applications.
- AMQP provides a reliable, secure, and scalable messaging infrastructure for the Internet of Things (IoT) applications.
- AMQP is a reliable messaging protocol that supports asynchronous communication between applications and devices.
- It is used to send messages between applications and devices in a distributed system.
- AMQP is used to facilitate the exchange of data between distributed systems in a secure and reliable manner.
- AMQP supports reliable and secure message delivery, message queuing, message routing, and message exchange.
- AMQP is designed to be platform-independent and can be implemented on any operating system.
- It is an efficient protocol for exchanging messages between applications and devices in a distributed system.
