
## Unit 1 - IoT-An Architectural Overview
 
1. IoT stands for Internet of Things, which is a network of physical objects that are embedded with sensors, software, and other technologies for the purpose of connecting and exchanging data with other devices and systems over the Internet.

2. IoT architecture is a framework for building and deploying IoT solutions. It typically consists of three main components: sensors and devices, a network infrastructure, and an application platform.

3. Sensors and devices are the physical objects that are embedded with sensors, software, and other technologies. These objects are connected to the network infrastructure, which includes the communication protocols, gateways, and other components that allow the objects to communicate with each other and with other systems.

4. The application platform is the software layer that enables the collection and analysis of data from the sensors and devices, and the creation of applications that can interact with the objects.

5. IoT architecture also includes security protocols, data storage, and other components that are necessary for the successful deployment of IoT solutions.
