

### CORPL for the notes of the Unit 3 - IOT Data Link Layer & Network Layer Protocols in the subject of IOT ARCHITECTURE AND PROTOCOLS

* **CORPL** stands for **C**onnected **O**bjects **R**outing **P**rotocol **L**ayer. It is a network layer protocol used in the Internet of Things (IoT) architecture.

* CORPL is responsible for routing data packets between different nodes in an IoT network. It is designed to be lightweight and energy-efficient, making it suitable for small and low-power devices.

* CORPL uses a distributed routing algorithm to determine the best route for data packets. It also provides features such as congestion control and flow control, which help to ensure that data is delivered reliably and efficiently.

* CORPL is an open standard, meaning that it can be used with any device or platform that is compatible with the protocol. This makes it an ideal choice for IoT applications that require interoperability between different devices and platforms.
