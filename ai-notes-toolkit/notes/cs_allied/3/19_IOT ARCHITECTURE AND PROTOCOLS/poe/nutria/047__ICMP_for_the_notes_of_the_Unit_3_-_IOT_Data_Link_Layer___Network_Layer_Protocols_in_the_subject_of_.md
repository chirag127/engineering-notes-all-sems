
### ICMP

* ICMP (Internet Control Message Protocol) is a network layer protocol that is used to manage network communication and provide feedback. 
* It is used to report errors in the IP layer and send control messages. 
* ICMP messages are sent in response to errors in IP layer packets, such as when a packet is too large or when a packet cannot reach its destination. 
* ICMP can also be used to send echo request and reply messages, which are used to measure network latency and check for connectivity. 
* ICMP can also be used to send redirect messages, which are used to inform hosts of better routes to a destination. 
* ICMP messages are sent as IP datagrams with an IP protocol number of 1.
