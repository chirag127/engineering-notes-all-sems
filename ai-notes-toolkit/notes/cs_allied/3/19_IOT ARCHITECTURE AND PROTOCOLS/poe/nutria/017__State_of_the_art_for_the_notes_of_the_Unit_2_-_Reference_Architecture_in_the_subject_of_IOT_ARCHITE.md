
### State of the Art for the Notes of the Unit 2 - Reference Architecture in the Subject of IOT ARCHITECTURE AND PROTOCOLS

1. Internet of Things (IoT) is a network of physical devices, vehicles, home appliances, and other items embedded with electronics, software, sensors, actuators, and connectivity which enable these objects to connect and exchange data. 
2. Reference architecture for IoT defines the architecture of the system as a whole, including the hardware, software, communication protocols and data management components.
3. The reference architecture for IoT should include a secure, reliable, and robust communication protocol that can be used to connect devices, sensors and actuators to the cloud or the Internet. 
4. It should also include a data management system that can collect, store and process data from the connected devices.
5. The reference architecture should also include a security layer to protect the data from unauthorized access and ensure data integrity.
6. The reference architecture should also include a system for managing and controlling the connected devices, such as a device management system, and a system for monitoring the performance and health of the connected devices.
7. Finally, the reference architecture should include a system for monitoring and analyzing the data from the connected devices, such as a data analytics system.
