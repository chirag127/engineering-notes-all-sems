
### IEEE 802.11

- IEEE 802.11 is a set of standards for wireless local area network (WLAN) communication, also known as Wi-Fi. 
- It is the most widely used standard for WLANs, with over 90% of WLANs using the IEEE 802.11 protocol.
- IEEE 802.11 defines the physical layer (PHY) and the media access control (MAC) layer for WLANs. 
- The PHY layer defines the physical characteristics of the wireless communication, such as the frequency, data rate, and modulation techniques. 
- The MAC layer defines the protocol used to access the wireless medium, such as the access control mechanisms, data frame formats, and the control frames used to manage the WLAN. 
- IEEE 802.11 has been revised several times, and currently the latest version is IEEE 802.11ax. 
- IEEE 802.11ax is optimized for high-density environments, and can achieve up to 10 times the throughput of the previous version, IEEE 802.11ac.
