
### Information View for the notes of the Unit 2 - Reference Architecture in the subject of IOT ARCHITECTURE AND PROTOCOLS

* Reference Architecture is a blueprint of a system that is used to guide the design and implementation of an Internet of Things (IoT) system. 
* It provides a common language and a shared understanding of the system components, their relationships, and how they interact with each other. 
* It defines the system components, their functions, and their relationships.
* It also describes the protocols and standards that are used to communicate between components. 
* It is important to note that the reference architecture should be flexible enough to accommodate changes in the system over time. 
* The reference architecture should also be able to support the integration of different technologies and components. 
* Additionally, it should provide guidance on the security and privacy of the system.
