
### Stateless and Stateful Processing

1. Stateless Processing: In this type of processing, data is processed as it arrives and no information is stored in the system. This means that the system has no knowledge of the past data and only works with the current data.

2. Stateful Processing: In this type of processing, the system stores the data in a state and uses the stored data to process the current data. This means that the system can use the past data to make decisions about the current data.

3. Stream-Processing Model: Stream Processing model is a type of distributed system which can process data in real-time. It is designed to process high volumes of data with low latency. It is used to process data from multiple sources and can process data in a distributed and fault tolerant manner.

4. Benefits of Stream-Processing Model: Stream Processing model provides real-time insights into data and can be used to make decisions quickly. It can also be used for predictive analytics and machine learning. It also provides scalability and fault tolerance.
