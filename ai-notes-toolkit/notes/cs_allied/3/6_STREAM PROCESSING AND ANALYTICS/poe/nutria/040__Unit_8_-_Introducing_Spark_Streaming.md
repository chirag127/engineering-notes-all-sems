
## Unit 8 - Introducing Spark Streaming

* Apache Spark is an open-source distributed data processing framework that can be used for large-scale data processing.
* Spark Streaming is a component of Spark that enables real-time data processing. It enables users to process data in real-time using the same programming model as batch processing.
* Spark Streaming operates on a micro-batch system, which processes data in batches of a few seconds. This allows for low-latency processing of data.
* Spark Streaming uses a Directed Acyclic Graph (DAG) to process data streams. This DAG is composed of a series of transformations and actions that are applied to the data.
* Spark Streaming can be used for a variety of tasks, such as real-time analytics, machine learning, and stream processing.
* Spark Streaming is highly scalable and can be deployed on multiple nodes. It is also fault-tolerant and can recover from failure.
