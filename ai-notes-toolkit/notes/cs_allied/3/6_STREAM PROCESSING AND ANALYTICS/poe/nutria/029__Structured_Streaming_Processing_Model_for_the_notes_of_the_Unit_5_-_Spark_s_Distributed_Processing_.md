
### Structured Streaming Processing Model

1. Structured streaming is a stream processing engine built on top of Spark's distributed processing model. 
2. It allows users to express streaming computations the same way they would express a batch computation on static data. 
3. Structured streaming provides an API to express streaming computations, which are then translated into an execution graph that is sent to the underlying engine for execution.
4. Structured streaming provides a fault-tolerant, consistent, and predictable execution model for streaming applications. 
5. Structured streaming supports a variety of data sources, including Kafka, HDFS, and AWS S3.
6. Structured streaming supports a wide range of transformations, including windowing, aggregation, and joins. 
7. Structured streaming provides a rich set of APIs for monitoring and managing streaming applications. 
8. Structured streaming applications are easy to deploy and manage in distributed environments.
