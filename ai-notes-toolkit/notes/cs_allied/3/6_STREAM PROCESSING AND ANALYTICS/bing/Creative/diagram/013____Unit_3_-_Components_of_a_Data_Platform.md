## Unit 3 - Components of a Data Platform

A data platform is a collection of tools and technologies that enable data-driven decision making in an organization. A data platform typically consists of the following components:

- Data sources: These are the original sources of data, such as databases, files, web services, sensors, etc. Data sources can be internal or external to the organization, and can have different formats, structures, and quality levels.
- Data ingestion: This is the process of collecting, transforming, and loading data from data sources into a data platform. Data ingestion can be batch or streaming, depending on the frequency and latency of data updates. Data ingestion can also involve data validation, cleansing, enrichment, and encryption.
- Data storage: This is the component that stores the ingested data in a data platform. Data storage can be relational or non-relational, depending on the nature and schema of the data. Data storage can also be categorized into hot, warm, or cold, depending on the frequency and speed of data access. Data storage can also support different data models, such as tabular, hierarchical, graph, or document.
- Data processing: This is the component that performs various operations on the stored data, such as querying, filtering, aggregating, joining, transforming, analyzing, and modeling. Data processing can be batch or streaming, depending on the use case and the desired output. Data processing can also involve different paradigms, such as SQL, MapReduce, Spark, or Databricks.
- Data visualization: This is the component that presents the processed data in a graphical or interactive form, such as charts, dashboards, reports, or maps. Data visualization can help users explore, understand, and communicate the insights derived from the data. Data visualization can also support different audiences, such as analysts, managers, or customers.
- Data governance: This is the component that ensures the quality, security, privacy, and compliance of the data in a data platform. Data governance can involve policies, standards, roles, and procedures that define how data is collected, stored, processed, and used. Data governance can also involve tools and techniques that monitor, audit, and protect the data from unauthorized or inappropriate access, modification, or deletion.
