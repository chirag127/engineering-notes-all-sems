# The Effect of Time for the notes of the Unit 2 - Stream-Processing Model in the subject of STREAM PROCESSING AND ANALYTICS

- Stream processing is a programming paradigm that views data streams, or sequences of events in time, as the central input and output objects of computation.
- Stream processing enables programs to react to new data events in real-time, rather than aggregating and processing them at a predetermined frequency as batch processing does.
- Stream processing is designed for instant data processing and real-time analytics, providing current, up-to-the-millisecond insights into what is happening within a system and helping to respond to critical events as soon as they occur.
- Stream processing is a compromise, driven by a data-centric model that works well for traditional DSP or GPU-type applications (such as image, video and digital signal processing) but less so for general purpose processing with more randomized data access (such as databases).
- The effect of time in stream processing is that it introduces challenges and opportunities for data processing and analytics, such as:
  - Handling out-of-order, late, or missing data events that may affect the correctness and completeness of the results.
  - Applying windowing, aggregation, and join operations on data streams based on event time, processing time, or ingestion time.
  - Detecting patterns, trends, and anomalies in data streams over time, such as spikes, dips, or seasonality.
  - Leveraging temporal context and history to enrich and refine data streams, such as using stateful processing, checkpoints, or external sources.
  - Optimizing performance, scalability, and fault-tolerance of stream processing systems, such as using parallelism, partitioning, or replication.
