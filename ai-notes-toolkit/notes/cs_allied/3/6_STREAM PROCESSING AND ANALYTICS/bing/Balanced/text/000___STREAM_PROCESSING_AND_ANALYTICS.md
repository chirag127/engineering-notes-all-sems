# Stream Processing and Analytics

- Stream processing and analytics is the processing and analyzing of data records continuously rather than in batches.
- Stream processing and analytics is useful for the types of data sources that send data in small sizes (often in kilobytes) in a continuous flow as the data is generated.
- Stream processing and analytics allows users to gain insights at a faster rate than before, without storing the data in a database and prepping it for analysis.
- Stream processing and analytics requires specific hardware and software, such as event stream processors (ESP) that are able to ingest data streams and process them with a small response time and no data loss.
- Stream processing and analytics can be combined with batch processing into one analytical platform, enabling concurrent processing of multiple streams.
- Stream processing and analytics can be implemented using various tools and platforms, such as Azure Stream Analytics, which is a cloud-based service that is built on Trill, a high-performance in-memory streaming analytics engine  .
- Stream processing and analytics can be applied to various scenarios and domains, such as IoT, social media, fraud detection, anomaly detection, sentiment analysis, etc  .
