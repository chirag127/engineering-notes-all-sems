## Unit 1 - Fundamentals of Stream Processing

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, social media, etc.
- Stream processing systems ingest, process, and output data streams in real-time, without storing the entire data set in memory or disk.
- Stream processing systems can provide low-latency, high-throughput, and scalable solutions for applications such as anomaly detection, fraud detection, real-time analytics, complex event processing, etc.
- Stream processing systems can be classified into two categories: stateless and stateful.
  - Stateless stream processing systems do not maintain any information about the past or future data elements in the stream. They process each data element independently and produce an output based on the current input only.
  - Stateful stream processing systems keep track of some information about the past or future data elements in the stream. They process each data element in the context of the state and update the state accordingly. They can produce outputs based on the current input and the state.
- Stream processing systems can also be classified into two categories based on the processing model: batch and streaming.
  - Batch processing systems process data in fixed-sized batches or windows, which are periodically generated from the data stream. They can provide high accuracy and completeness, but at the cost of high latency and low responsiveness.
  - Streaming processing systems process data in an incremental and continuous manner, without waiting for a complete batch or window. They can provide low latency and high responsiveness, but at the cost of lower accuracy and completeness.
