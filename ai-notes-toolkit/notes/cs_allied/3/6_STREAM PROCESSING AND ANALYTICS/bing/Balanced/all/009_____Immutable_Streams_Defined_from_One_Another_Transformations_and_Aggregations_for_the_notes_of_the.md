# Immutable Streams Defined from One AnotherTransformations and Aggregations

- A stream is a sequence of data items that are produced and consumed over time.
- A stream can be defined from another stream by applying a transformation or an aggregation function.
- A transformation is a function that maps each data item in the input stream to one or more data items in the output stream.
- A transformation preserves the order of the data items in the stream.
- Examples of transformations are: filter, map, flatMap, join, union, etc.
- An aggregation is a function that combines multiple data items in the input stream into a single data item in the output stream.
- An aggregation reduces the size of the stream and may change the order of the data items.
- Examples of aggregations are: reduce, fold, groupBy, count, sum, average, etc.
- Streams are immutable, meaning that once a data item is produced, it cannot be modified or deleted.
- Streams can be defined from one another in a declarative way, using a stream-processing language or a library.
- Streams can be composed of multiple transformations and aggregations, forming a stream-processing pipeline or a dataflow graph.
