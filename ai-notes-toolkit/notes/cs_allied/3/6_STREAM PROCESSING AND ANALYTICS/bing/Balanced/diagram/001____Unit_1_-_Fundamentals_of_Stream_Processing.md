## Unit 1 - Fundamentals of Stream Processing

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, social media, etc.
- Stream processing systems ingest, process, and output data streams in real-time or near-real-time, without storing the entire data set in memory or disk.
- Stream processing systems can handle high-volume, high-velocity, and high-variety data, and can provide low-latency, scalable, and fault-tolerant solutions for various applications such as analytics, monitoring, alerting, etc.
- Stream processing systems can be classified into two categories: stateless and stateful.
  - Stateless stream processing systems do not maintain any information about the past or future data elements in the stream, and process each data element independently. Examples of stateless operations are filtering, mapping, sampling, etc.
  - Stateful stream processing systems keep track of some information about the past or future data elements in the stream, and process each data element in the context of that information. Examples of stateful operations are aggregation, windowing, joining, etc.
- Stream processing systems can also be classified into two categories based on the data model: record-based and event-based.
  - Record-based stream processing systems treat each data element in the stream as a record, which is a collection of key-value pairs. Records do not have any inherent temporal semantics, and the order of records in the stream is not important. Examples of record-based stream processing systems are Apache Kafka, Apache Flink, etc.
  - Event-based stream processing systems treat each data element in the stream as an event, which is a representation of something that happened at a specific point in time. Events have temporal semantics, and the order of events in the stream is important. Examples of event-based stream processing systems are Apache Spark, Apache Storm, etc.
