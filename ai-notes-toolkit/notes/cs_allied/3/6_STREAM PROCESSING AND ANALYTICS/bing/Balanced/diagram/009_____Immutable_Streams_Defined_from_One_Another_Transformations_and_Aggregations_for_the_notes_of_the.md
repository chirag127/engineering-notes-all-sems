### Immutable Streams Defined from One Another

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, or social media platforms.
- Stream processing applications consume data from one or more input streams, apply transformations and aggregations, and produce output streams that can be consumed by other applications or stored for later analysis.
- Streams are immutable collections of facts or events that occur over time. Each event has a timestamp that indicates when it was generated by the source.
- Streams can be defined from one another by applying transformations and aggregations. Transformations are operations that change the structure or content of the events in a stream, such as filtering, mapping, or joining. Aggregations are operations that summarize the events in a stream, such as counting, summing, or averaging.
- Transformations and aggregations can be stateless or stateful. Stateless operations do not depend on any previous or future events in the stream, and can be applied independently to each event. Stateful operations require maintaining some state across events in the stream, and can be affected by the order and timing of the events.
- Window aggregations are a special type of stateful operation that group events in a stream based on a fixed or dynamic time interval, and apply an aggregation function to each group. Window aggregations can be used to analyze trends or patterns in the stream over time. There are different types of windows, such as tumbling, sliding, or session windows, depending on how the events are grouped.
