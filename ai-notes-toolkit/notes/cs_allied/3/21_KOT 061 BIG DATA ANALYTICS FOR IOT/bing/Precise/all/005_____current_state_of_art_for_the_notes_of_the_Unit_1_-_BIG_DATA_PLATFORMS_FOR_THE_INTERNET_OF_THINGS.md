### Current State of Art for the Notes of the Unit 1 - BIG DATA PLATFORMS FOR THE INTERNET OF THINGS in the Subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

- Big Data is a term used to describe large, complex data sets that traditional data processing methods are unable to handle.
- The current state of the art with respect to 'Big Data' frameworks and libraries is constantly evolving .
- Big Data System Benchmarking is classified into five categories: Map-Reduce based system benchmarking, SQL-based analytical system benchmarking, NoSQL-based database bench-marking, Big graph system benchmarking .
- Data is nothing but facts and statistics stored or free flowing over a network, generally. It's raw and unprocessed. When data are processed, organized, structured or presented in a given context so as to make it useful, it is called information .
