# Unit 3 - FOG COMPUTING in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

Fog computing is a distributed computing paradigm that provides data, compute, storage, and application services closer to the end-users along the cloud-to-things continuum. It is a suitable platform for new proliferating IoT devices, services, and applications .

- **Fog Challenges and Opportunities**: The key characteristics in some proposed research works make the fog computing a suitable platform for new proliferating IoT devices, services, and applications .
- **Fog and IoT**: The fog provides IoT data processing and storage locally at IoT devices instead of sending them to the cloud. In contrast to the cloud, the fog provides services with faster response and greater quality .
- **Big Data Analytics with Fog Computing**: Fog Computing enhances Big Data Analytics capabilities in Cloud – IoT architecture for smart devices of IoT environment .
- **IoT Sensor Data**: IoT sensor produces data for big data analytics, and it also highlights the existing challenges of intelligent solutions .
