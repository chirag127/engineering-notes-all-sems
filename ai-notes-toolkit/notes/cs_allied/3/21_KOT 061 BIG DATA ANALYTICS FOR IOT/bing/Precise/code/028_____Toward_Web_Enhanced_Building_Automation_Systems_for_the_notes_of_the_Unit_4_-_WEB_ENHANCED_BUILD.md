### Toward Web Enhanced Building Automation Systems

1. Building automation systems (BAS) are centralized, interlinked, networks of hardware and software, which monitor and control the environment in commercial, industrial, and institutional facilities.
2. BAS are used to control and monitor various building systems, including heating, ventilation, and air conditioning (HVAC), lighting, fire, and security systems.
3. The integration of web technologies into BAS has the potential to enhance the capabilities of these systems, allowing for remote monitoring and control, improved data analysis, and more efficient building management.
4. Web-enabled BAS can provide building managers with real-time data on building performance, allowing them to make informed decisions about energy usage and maintenance.
5. The use of web technologies also allows for the integration of BAS with other building systems, such as security and fire systems, providing a more comprehensive approach to building management.
6. The development of web-enhanced BAS is an ongoing process, with new technologies and capabilities being added as they become available.
7. The use of web-enhanced BAS has the potential to improve building efficiency, reduce energy consumption, and provide a more comfortable and safe environment for building occupants.
