## Unit 3 - FOG COMPUTING

Fog computing is a decentralized computing infrastructure in which data, compute, storage, and applications are located somewhere between the data source and the cloud. It is designed to improve efficiency and reduce the amount of data transported to the cloud for processing, analysis, and storage.

Some key points to consider when studying fog computing are:

1. Fog computing is a distributed computing paradigm that provides resources and services to the edge of the network, near the source of data.
2. It is an extension of cloud computing, and aims to bring the advantages of cloud computing closer to the edge of the network.
3. Fog computing can reduce latency, improve network bandwidth utilization, and provide real-time data processing and analysis.
4. It is particularly useful for Internet of Things (IoT) applications, where large amounts of data are generated at the edge of the network.
5. Fog computing can also provide enhanced security and privacy, as data can be processed locally rather than being transmitted to the cloud.
