## Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure that uses edge devices to perform computation, storage, and communication locally and routed over the Internet backbone.
- Fog computing is also known as edge computing or fogging  .
- Fog computing aims to bring the advantages and power of the cloud closer to where data is created and acted upon, such as IoT devices .
- Fog computing is not a substitute, but a complement to cloud computing. Fog computing is more energy-efficient than cloud computing.
- Fog computing can provide low latency, high bandwidth, real-time data processing, security, and privacy for applications that require them  .
- Some examples of fog computing applications are smart cities, smart grids, smart transportation, smart healthcare, and smart manufacturing .
- IEEE adopted the fog computing standards proposed by OpenFog Consortium.
