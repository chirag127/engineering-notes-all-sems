# Unit 1 - BIG DATA PLATFORMS FOR THE INTERNET OF THINGS

- The Internet of Things (IoT) is a network of physical objects that are embedded with sensors, actuators, and communication devices that can collect, process, and exchange data over the internet.
- Big data platforms are software systems that enable the storage, processing, analysis, and visualization of large and complex datasets generated by IoT devices and applications.
- Big data platforms for the IoT can be classified into three main categories: connectivity platforms, application platforms, and analytics platforms.

## Connectivity Platforms
- Connectivity platforms provide communication technologies to connect physical objects with the data center (on-premise or cloud) and transmit information between them.
- Among popular connectivity protocols and standards for the Internet of Things are MQTT, DDS, AMQP, Bluetooth, ZigBee, WiFi, Cellular, LoRaWAN and more.
- Connectivity platforms also provide device management, security, and authentication features to ensure the reliability and integrity of the IoT network.

## Application Platforms
- Application platforms provide tools and services to develop, deploy, and manage IoT applications that run on top of the connectivity layer.
- Application platforms can offer features such as device provisioning, data ingestion, data transformation, data integration, data storage, data access, data visualization, and data governance.
- Application platforms can also support various types of IoT applications, such as smart home, smart city, smart industry, smart agriculture, smart health, and smart mobility.
- Some examples of application platforms are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform, Artik from Samsung Electronics, Cisco Cloud Connect, Salesforce Cloud, Watson and BlueMix from IBM, and OpenStack.

## Analytics Platforms
- Analytics platforms provide techniques and tools to extract insights and value from the IoT data collected by the application layer.
- Analytics platforms can perform various types of data analysis, such as descriptive, diagnostic, predictive, prescriptive, and cognitive analytics, using methods such as statistics, machine learning, artificial intelligence, and natural language processing.
- Analytics platforms can also enable real-time or near-real-time data processing and decision making, using technologies such as stream processing, complex event processing, and edge computing.
- Some examples of analytics platforms are Apache Hadoop, Apache Spark, Apache Flink, Apache Kafka, Apache Storm, Apache Samza, and Apache NiFi .
