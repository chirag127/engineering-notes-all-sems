## Unit 4 - WEB ENHANCED BUILDING

- Web enhanced building is a concept that integrates web technologies and building automation systems to provide more efficient and user-friendly services in buildings.
- Web enhanced building can be applied to various domains, such as energy management, security, comfort, maintenance, and emergency response.
- Web enhanced building can benefit both building owners and occupants, by reducing operational costs, improving performance, increasing convenience, and enhancing safety.
- Web enhanced building can be implemented using different approaches, such as web services, web portals, web applications, and web of things.
- Web services are software components that can be accessed over the internet using standard protocols, such as SOAP and REST. Web services can enable interoperability and integration of different building automation systems and devices.
- Web portals are web-based interfaces that can provide centralized access and control of building automation systems and devices. Web portals can also provide information and feedback to users, such as energy consumption, indoor environment quality, and alerts.
- Web applications are web-based software programs that can run on browsers or mobile devices. Web applications can provide customized and interactive services to users, such as remote control, scheduling, and personalization of building automation systems and devices.
- Web of things is a concept that extends the internet of things to the web domain, by using web standards and technologies to connect and communicate with physical objects. Web of things can enable easy and ubiquitous access and control of building automation systems and devices, using web browsers or mobile applications.
