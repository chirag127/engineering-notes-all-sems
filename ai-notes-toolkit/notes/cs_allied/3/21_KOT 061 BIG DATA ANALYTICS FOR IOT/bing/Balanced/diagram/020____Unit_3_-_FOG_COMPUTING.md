## Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure that uses edge devices to perform computation, storage, and communication locally and over the Internet backbone.
- Fog computing is also known as edge computing or fogging .
- Fog computing aims to bring the advantages and power of the cloud closer to where data is created and acted upon.
- Fog computing is often a complement to cloud computing, rather than a substitute.
- Fog computing is more energy-efficient than cloud computing.
- Fog computing can support IoT applications that require low latency, high bandwidth, real-time analytics, and security .
- Fog computing can also enable data processing and management at the edge, reducing the network congestion and the cloud workload .
- Fog computing follows the standards proposed by the OpenFog Consortium, which is now part of the IEEE.
