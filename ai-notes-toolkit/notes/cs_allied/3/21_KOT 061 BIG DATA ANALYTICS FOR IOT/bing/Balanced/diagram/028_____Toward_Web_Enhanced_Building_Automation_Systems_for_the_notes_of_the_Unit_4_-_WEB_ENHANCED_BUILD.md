### Toward Web Enhanced Building Automation Systems

- Building automation systems (BAS) are systems that control and monitor the mechanical, electrical, and plumbing systems of a building, such as heating, ventilation, air conditioning, lighting, security, fire alarms, etc.
- BAS are typically proprietary and closed systems that use specific protocols and interfaces that are not compatible with the web or the Internet of Things (IoT) paradigms.
- Web enhanced building automation systems (WEBAS) are systems that aim to integrate BAS with the web and IoT technologies, such as web services, RESTful APIs, semantic web, cloud computing, etc.
- WEBAS can provide several benefits, such as:
  - Improved interoperability and integration of different BAS devices and systems, as well as other web-based applications and services.
  - Enhanced functionality and scalability of BAS, as they can leverage the web resources and capabilities, such as data storage, processing, analytics, visualization, etc.
  - Reduced cost and complexity of BAS deployment and maintenance, as they can use standard web protocols and platforms, such as HTTP, TCP/IP, XML, JSON, etc.
  - Increased user accessibility and convenience of BAS, as they can be accessed and controlled from any web-enabled device, such as smartphones, tablets, laptops, etc.
- Some examples of WEBAS are:
  - WebCTRL® building automation system by Automated Logic, which is a web-based platform that provides facility managers with software tools to keep occupants comfortable, manage energy conservation measures, identify key operational problems, and analyze the results.
  - APOGEE automation system by Siemens, which is a flexible and scalable system that integrates with web-based applications and services, such as BACnet, OPC, Modbus, etc., and provides web access to system data and control functions.
  - BMS by Honeywell, which is a building management solution that uses web-based controllers, field devices, and software to customize a system that fits the building and its future needs.
