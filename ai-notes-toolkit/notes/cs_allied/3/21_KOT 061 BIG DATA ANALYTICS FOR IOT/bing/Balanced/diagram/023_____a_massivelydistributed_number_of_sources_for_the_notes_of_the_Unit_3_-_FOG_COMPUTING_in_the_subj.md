### Unit 3 - FOG COMPUTING

- Fog computing is also known as real-time edge computing. It emerged from cloud computing and implemented close to the end user’s devices to deal with network latency .
- Fog computing analyzes the most time-sensitive data at the network edge, close to where it is generated, instead of sending vast amounts of IoT data to the cloud. It acts on IoT data in milliseconds, based on policy.
- Fog computing can enhance the performance and reliability of big data analytics in IoT systems, by shifting the computational load to the edge devices. It can also reduce the bandwidth and energy consumption of IoT devices, and improve the security and privacy of the data  .
- Fog computing nodes are intermediary devices that distribute the cloud resources, such as network gateways, battery powered servers, access points, etc. They can communicate with each other and with the cloud, forming a hierarchical and decentralized architecture .
- Fog computing can support various applications of big data analytics in IoT, such as smart grid, smart city, smart health, smart transportation, etc. It can provide real-time, context-aware, and adaptive solutions for these applications .
