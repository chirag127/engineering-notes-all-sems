# Big Data Platforms for the Internet of Things

- Big data platforms are software systems that enable the collection, processing, analysis, and visualization of large and complex data sets generated by the Internet of Things (IoT) devices and applications.
- IoT devices are physical objects that are embedded with sensors, actuators, and communication capabilities that allow them to interact with each other and with the environment.
- IoT applications are software programs that use the data from IoT devices to provide various services and functionalities, such as smart home, smart city, smart health, smart agriculture, etc.
- Big data platforms for the IoT can be classified into three main types: connectivity platforms, cloud platforms, and analytics platforms.

## Connectivity Platforms
- Connectivity platforms provide communication technologies to connect physical objects with the data center (on-premise or cloud) and transmit information between them.
- Among popular connectivity protocols and standards for the Internet of Things are MQTT, DDS, AMQP, Bluetooth, ZigBee, WiFi, Cellular, LoRaWAN and more.
- Connectivity platforms also provide device management, security, and authentication features to ensure the reliability and integrity of the data transmission.

## Cloud Platforms
- Cloud platforms provide storage, computing, and networking resources to host and run IoT applications and services on the internet.
- Cloud platforms also provide scalability, elasticity, and availability features to handle the large and dynamic data volumes and workloads generated by the IoT devices and applications.
- The most popular cloud platforms for creating Internet of Things systems are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform, Artik from Samsung Electronics, Cisco Cloud Connect, Salesforce Cloud, Watson and BlueMix from IBM, OpenStack .

## Analytics Platforms
- Analytics platforms provide tools and techniques to analyze, process, and visualize the data collected by the IoT devices and applications.
- Analytics platforms also provide machine learning, artificial intelligence, and data mining capabilities to extract insights, patterns, and predictions from the data.
- Big Data plays the role of an analytics platform for data collected by IoT-connected devices .
- Some examples of analytics platforms for the IoT are Apache Hadoop, Apache Spark, Apache Storm, Apache Kafka, Apache Flink, etc.
