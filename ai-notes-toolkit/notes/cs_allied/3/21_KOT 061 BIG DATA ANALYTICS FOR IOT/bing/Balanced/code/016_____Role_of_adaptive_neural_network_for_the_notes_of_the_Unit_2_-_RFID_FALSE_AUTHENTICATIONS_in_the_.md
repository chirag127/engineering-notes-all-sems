### Role of adaptive neural network for the notes of the Unit 2 - RFID FALSE AUTHENTICATIONS in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

- Radio frequency identification (RFID) is a technology that uses radio waves to identify objects or people by attaching tags to them. RFID tags can store and transmit data to RFID readers, which can then process and analyze the data.
- RFID false authentication is a security problem that occurs when an unauthorized tag or reader pretends to be a legitimate one and gains access to the system or the data. RFID false authentication can lead to data leakage, privacy violation, or malicious manipulation of the system.
- Adaptive neural network is a type of artificial neural network that can adjust its structure or parameters according to the input data or the environment. Adaptive neural network can learn from the data and improve its performance over time.
- Adaptive neural network can be used to detect and prevent RFID false authentication by:
  - Classifying the RFID tags based on their features and behaviors, and identifying the false-positive reads that do not match the expected patterns.
  - Updating the encryption keys of the RFID tags and readers dynamically and securely, and verifying the authenticity of the communication partners.
  - Detecting the environmental factors that affect the RFID system, such as noise, interference, or multipath, and adjusting the system parameters accordingly to reduce the false-positive reads.
  - Using machine learning techniques, such as support vector machine, decision tree, or random forest, to analyze the RFID data and identify the anomalies or outliers that indicate false authentication.
