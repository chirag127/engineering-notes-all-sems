## Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure that uses edge devices to perform computation, storage, and communication locally and over the Internet backbone.
- Fog computing is also known as edge computing or fogging  .
- Fog computing aims to bring the advantages and power of the cloud closer to where data is created and acted upon, especially for Internet of Things (IoT) devices .
- Fog computing is not a substitute, but a complement to cloud computing. Fog computing is more energy-efficient and responsive than cloud computing .
- Fog computing has some challenges, such as security, privacy, scalability, and interoperability.
- Fog computing has some applications, such as smart cities, smart grids, smart healthcare, smart transportation, and smart agriculture .
