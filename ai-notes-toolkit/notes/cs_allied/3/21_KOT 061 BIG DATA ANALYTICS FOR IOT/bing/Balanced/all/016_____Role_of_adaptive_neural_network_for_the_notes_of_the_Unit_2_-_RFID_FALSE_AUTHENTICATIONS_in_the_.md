# Role of adaptive neural network for the notes of the Unit 2 - RFID False Authentications in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

- RFID (Radio Frequency Identification) is a technology that uses radio waves to identify objects, such as tags attached to products, vehicles, or animals.
- RFID false authentication is a security problem that occurs when an unauthorized tag or reader pretends to be a legitimate one, or when a legitimate tag or reader is fooled by a malicious one.
- RFID false authentication can lead to data leakage, privacy violation, inventory error, or financial loss.
- Adaptive neural network is a type of artificial neural network that can adjust its structure or parameters according to the input data or the environment.
- Adaptive neural network can be used to detect and prevent RFID false authentication by learning the features and patterns of normal and abnormal RFID signals, and by classifying or filtering out the false readings in real time.
- Some examples of adaptive neural network applications for RFID false authentication are:

  - Environmentally adaptive real-time detection of RFID false readings in a new practical scenario: This method uses a recurrent neural network (RNN) to model the temporal and spatial correlations of RFID readings, and a convolutional neural network (CNN) to extract the environmental features. The RNN-CNN model can adapt to different environments and detect false readings with high accuracy and low latency.
  - Self-adaptive RFID authentication for Internet of Things: This method uses a lightweight hash function and a dynamic key update scheme to generate a unique authentication code for each tag and reader. The authentication code is verified by a neural network that can self-adapt to different security levels and communication conditions. The neural network can resist jamming and cloning attacks, and reduce the computation and communication overhead.
  - RFID tag classification for false-positive reads identification via deep learning with multidimensional signal fusion: This method uses a deep neural network (DNN) to fuse the multidimensional signals of RFID tags, such as the received signal strength indicator (RSSI), the phase, and the Doppler shift. The DNN can learn the complex and nonlinear relationships among the signals, and classify the tags into true-positive and false-positive reads with high accuracy and robustness.
  - Automatic detection of false positive RFID readings using machine learning: This method uses a support vector machine (SVM) to classify the RFID readings based on the features extracted from the tag identification number, the RSSI, and the time interval. The SVM can detect the false positive readings that are caused by the interference of nearby tags or readers, or by the environmental noise.
