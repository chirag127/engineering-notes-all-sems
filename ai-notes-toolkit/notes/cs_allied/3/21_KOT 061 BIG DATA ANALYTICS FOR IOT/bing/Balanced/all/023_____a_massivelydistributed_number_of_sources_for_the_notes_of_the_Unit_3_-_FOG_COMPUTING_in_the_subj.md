# Unit 3 - Fog Computing

- Fog computing is a type of distributed computing that connects a cloud to a number of "peripheral" devices.
- Fog computing brings the advantages and power of the cloud closer to where data is created and acted upon.
- Fog computing works by utilizing local devices termed fog nodes and edge devices.
- Fog computing is also known as edge computing or fogging.
- Fog computing aims to provide quicker and more localized computing services for the connected smart devices that make up the Internet of Things (IoT) ecosystem.

## Components of Fog Computing

- Fog computing consists of three main components: fog nodes, edge devices, and cloud servers.
- Fog nodes are devices that have computing, storage, and networking capabilities. They are located near the data sources and can process and store data locally or forward it to the cloud .
- Edge devices are devices that generate or consume data, such as sensors, actuators, smartphones, or laptops. They are connected to fog nodes or directly to the cloud .
- Cloud servers are remote servers that provide centralized computing, storage, and networking services. They are connected to fog nodes via the internet or other networks .

## Examples of Fog Computing

- Fog computing can be applied to various domains and scenarios, such as smart cities, smart grids, smart healthcare, smart transportation, and smart manufacturing.
- Some examples of fog computing are:

  - Traffic management: Fog nodes can collect and analyze data from traffic cameras, sensors, and GPS devices to optimize traffic flow, reduce congestion, and improve safety.
  - Video surveillance: Fog nodes can perform face recognition, object detection, and anomaly detection on video streams from cameras and send alerts or actions to the cloud or edge devices.
  - Augmented reality: Fog nodes can provide low-latency and high-bandwidth services for augmented reality applications, such as gaming, education, and entertainment.
  - Healthcare monitoring: Fog nodes can collect and process data from wearable devices, such as heart rate monitors, blood pressure sensors, and glucose meters, and provide feedback or emergency response to the users or the cloud.

## Best Practices for Fog Computing

- Some best practices for fog computing are:

  - Design fog nodes to be scalable, reliable, and secure.
  - Use fog nodes to perform data filtering, aggregation, and compression to reduce network traffic and bandwidth consumption.
  - Use fog nodes to perform data encryption, authentication, and authorization to protect data privacy and integrity.
  - Use fog nodes to perform data analytics, machine learning, and decision making to provide real-time and context-aware services.
  - Use fog nodes to coordinate and collaborate with other fog nodes, edge devices, and cloud servers to optimize resource utilization and performance.
