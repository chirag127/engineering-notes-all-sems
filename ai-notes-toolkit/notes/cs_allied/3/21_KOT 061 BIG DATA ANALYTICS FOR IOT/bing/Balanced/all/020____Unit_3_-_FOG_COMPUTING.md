# Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure that uses edge devices to carry out computation, storage, and communication locally and routed over the Internet backbone.
- Fog computing is also known as edge computing or fogging .
- Fog computing is intended for distributed computing where numerous devices connect to a cloud, but perform some processing and analysis closer to the data source and the end users .
- Fog computing is a medium weight and intermediate level of computing power that complements cloud computing.
- Fog computing is more energy-efficient, scalable, and responsive than cloud computing  .
- Fog computing can support applications that require low latency, mobility, location awareness, and real-time analytics .
- Fog computing can also enhance security and privacy by reducing the amount of data transferred to the cloud .
- Fog computing is based on the standards proposed by the OpenFog Consortium and adopted by IEEE.
- Fog computing can be applied to various domains such as smart cities, smart grids, smart healthcare, smart transportation, and smart agriculture .
