## Unit 4 - WEB ENHANCED BUILDING

1. HTML: Hypertext Markup Language is the main markup language used to create web pages. It uses a series of elements consisting of tags enclosed in angle brackets. HTML tags tell the browser how to display the content. Some important HTML tags are:
- <html>: Defines the root of an HTML document
- <head>: Contains metadata about the HTML document
- <title>: Specifies the title of the HTML document
- <body>: Contains the visible page content
- <h1>: Defines a section heading
- <p>: Defines a paragraph
- <a>: Defines a hyperlink

2. CSS: Cascading Style Sheets is used to style the HTML document. It separates the presentation of a document from the structure and content. CSS uses a series of rules that are made up of selectors and declarations. The selectors specify the HTML elements to be styled and the declarations specify the styling to apply using properties and values. Some important CSS properties are:
- color: Specifies the text color
- background-color: Specifies the background color
- font-family: Specifies the font face
- font-size: Specifies the text size
- padding: Specifies the internal spacing of an element
- margin: Specifies the external spacing of an element

3. JavaScript: JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It allows web pages to be interactive and dynamic. JavaScript can modify and control web page content and layout as the user interacts with the page. It can detect keystrokes and mouse movements, detect events like button clicks, and trigger processes in response. Some important concepts in JavaScript are variables, data types, operators, control flows, functions, objects, and DOM manipulation.
