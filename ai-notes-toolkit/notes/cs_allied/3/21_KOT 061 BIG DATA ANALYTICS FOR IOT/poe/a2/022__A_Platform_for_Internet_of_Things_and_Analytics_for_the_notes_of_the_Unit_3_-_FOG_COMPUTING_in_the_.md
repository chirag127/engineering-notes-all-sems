### A Platform for Internet of Things and Analytics for the notes of the Unit 3 - FOG COMPUTING in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

1. Fog computing is a distributed computing infrastructure where computing resources and application services are placed at the edge of the network, closer to the data sources and clients.
2. Fog computing complements cloud computing and enables IoT applications that require real-time interactions and local computing resources.
3. The key characteristics of fog computing are:
- Low latency: Computing is done closer to the data source to reduce latency.
- Location awareness: Services are location-aware and able to utilize location data.
- Mobility support: Services can be migrated to follow the movement of mobile data sources and clients.
- Wide geographical distribution: Computing resources and services are distributed in a wide geographical area.
- Heterogeneity: The fog may consist of diverse nodes with different characteristics in terms of computing power, storage capacity, and network capacity.
4. The key benefits of fog computing are:
- Reduced latency: Real-time applications with strict latency requirements can be supported.
- Location awareness: Location data can be fully utilized.
- Load balancing: Workloads can be distributed to balance loads.
- Privacy and security: Sensitive data can be processed locally without being sent to the cloud.
- Scalability: The fog can scale to a large number of endpoints and high volumes of data.
