
### Unit 3 - Fog Computing 
* Fog computing is a distributed computing infrastructure in which computing resources and services are located between the data source and the cloud. 
* It is used to extend the cloud computing capabilities to the edge of the network, and can be deployed in a variety of scenarios such as smart cities, industrial automation, and the Internet of Things (IoT). 
* Fog computing reduces latency by bringing the computing resources closer to the data source, and can provide more efficient data processing and storage. 
* It also enables real-time analytics and decision making, and can be used to improve the reliability, scalability, and security of data processing. 
* Fog computing also provides a platform for distributed applications, allowing for the development of applications that span multiple devices and networks. 
* Fog computing can be used to build applications that are resilient to network outages, and can provide better performance in environments with limited network connectivity.
