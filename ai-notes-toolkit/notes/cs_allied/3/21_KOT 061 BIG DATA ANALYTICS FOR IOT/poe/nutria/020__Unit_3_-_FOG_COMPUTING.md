
## Unit 3 - FOG COMPUTING

1. Fog computing is a distributed computing architecture that provides data, compute, storage and application services closer to the users and edge devices.

2. It is a type of edge computing, which is a distributed computing model that brings computing capabilities and services closer to the end user.

3. Fog computing is used in a variety of applications, including smart cities, industrial automation, and the Internet of Things (IoT).

4. It is also used in healthcare, transportation, and other areas where data needs to be processed quickly and securely.

5. Fog computing is different from cloud computing in that it is more localized and does not require an internet connection to operate.

6. It is also more secure, as data is stored and processed closer to the source.

7. Fog computing is also more cost-effective, as it eliminates the need for expensive cloud infrastructure.

8. Finally, fog computing is more reliable, as it is not affected by network outages or slowdowns.
