
## Unit 2 - RFID FALSE AUTHENTICATIONS

1. **Radio Frequency Identification (RFID)** is a technology that uses radio waves to identify and track tags attached to objects. It is commonly used in retail stores to track inventory and in access control systems to restrict access to certain areas.

2. **False authentication** is a type of security vulnerability that occurs when an RFID system is tricked into believing that an unauthorized user has been authenticated. This can occur due to a variety of factors, such as weak encryption, poor implementation of security protocols, or the use of outdated technology.

3. **Common methods of false authentication** include cloning an authorized user's tag, using a signal jammer to disrupt the authentication process, and using a replay attack to replay an authorized user's authentication signal.

4. **Preventing false authentication** requires the use of strong encryption, secure authentication protocols, and up-to-date hardware and software. It is also important to regularly monitor RFID systems for signs of tampering or malicious activity.
