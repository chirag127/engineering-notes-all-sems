
### A Platform for Internet of Things and Analytics for the notes of the Unit 3 - FOG COMPUTING in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

* Fog computing is a distributed computing infrastructure that facilitates the processing of data and applications close to the edge of the network. 
* It is a type of distributed computing architecture which provides computing, storage, and networking services between the edge of the network and the cloud. 
* Fog computing is designed to reduce the latency and bandwidth consumption of cloud computing by bringing the computing resources closer to the source of the data.
* It enables the deployment of applications and services such as analytics, machine learning, and artificial intelligence to the edge of the network, allowing for faster response times and improved user experience.
* Fog computing can also be used to provide security and privacy for data that is stored or transmitted over the network.
* It can be used to improve the reliability of the network by providing redundancy and fault tolerance.
* Fog computing can also be used to reduce the cost of deploying and managing applications and services in the cloud.
