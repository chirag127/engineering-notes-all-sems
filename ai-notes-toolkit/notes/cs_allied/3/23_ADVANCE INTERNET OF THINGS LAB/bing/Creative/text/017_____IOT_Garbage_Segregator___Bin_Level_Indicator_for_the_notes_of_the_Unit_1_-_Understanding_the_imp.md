### IOT Garbage Segregator & Bin Level Indicator

- This is a project that aims to implement an IOT-based system for garbage segregation and bin level monitoring.
- The system consists of the following components:
  - A garbage segregator device that can sort the waste into different categories (such as metal, plastic, paper, organic, etc.) using sensors and actuators.
  - A bin level indicator device that can measure the fill level of each bin and send the data to a cloud server using a Wi-Fi module.
  - A web application that can display the bin level data and provide alerts and notifications to the users and authorities.
  - A mobile application that can allow the users to access the web application from their smartphones.
- The main objectives of the project are:
  - To reduce the manual labor and human errors involved in garbage segregation and collection.
  - To improve the efficiency and accuracy of waste management and recycling.
  - To raise awareness and encourage participation among the citizens and stakeholders.
  - To reduce the environmental impact and health hazards caused by improper waste disposal.
