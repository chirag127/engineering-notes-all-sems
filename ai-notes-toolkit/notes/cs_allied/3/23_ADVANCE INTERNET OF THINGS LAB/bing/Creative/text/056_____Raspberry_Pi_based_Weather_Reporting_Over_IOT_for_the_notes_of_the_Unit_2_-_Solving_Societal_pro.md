### Raspberry Pi based Weather Reporting Over IOT

- This system can be used to monitor and update weather conditions over the internet using Raspberry Pi and various sensors.
- The system monitors 3 parameters namely temperature, humidity and rainfall these values are then displayed on LCD and also updated over the IoT gecko.
- The system uses DHT11 sensor for temperature and humidity, rain sensor for rainfall and BMP180 sensor for pressure and altitude.
- The system uses Raspberry Pi as a base station that collects the data from the sensors and sends it to the IoT gecko server using Wi-Fi module.
- The IoT gecko server provides a web interface for the user to view the weather data in real time and also provides graphs and charts for analysis.
- The system is cost effective and has low power consumption in order to save money as well as power utilization.
- The system can be used to provide accurate and precise weather-related data of a specific area as opposed to the generic type regional weather forecasts.
- The system can also be used to alert the user about any abnormal weather conditions or natural disasters using SMS or email.
