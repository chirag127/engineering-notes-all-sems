### IOT based Three Phase Power Failure Monitoring with SMS Alerts

- This is an advanced system that monitors power failure in a three-phase system.
- A three-phase system consists of three alternating currents of equal frequency and amplitude that are out of phase by 120 degrees.
- When one phase of a three-phase system gets lost, a phase loss occurs. This is referred as a ‘single phasing’.
- Single phasing can cause severe damage to the electrical equipment and appliances connected to the system.
- This failure can be caused by a blown fuse, thermal overload, broken wire, worn contact or mechanical failure.
- This system uses an IOT device that is connected to the three phases and measures the voltage of each phase.
- The IOT device sends the voltage data to a cloud server using Wi-Fi or Ethernet.
- The cloud server processes the data and detects any phase loss or abnormality in the voltage levels.
- The cloud server also sends the data to a web application or a mobile application that can be accessed by the user or the authorized person.
- The user can monitor the status of the three phases and the power consumption of the system using the web or mobile application.
- When the cloud server detects a phase loss, it sends an SMS alert to the user or the authorized person using a GSM module.
- The SMS alert contains the information about the phase that is lost and the time of the failure.
- The user can take appropriate action to restore the power or to protect the equipment and appliances from damage.
- This system can also display the voltage values of the three phases on an LCD display that is connected to the IOT device.
- This system can be useful for industrial, commercial and residential applications where three-phase power is used.
- This system can prevent equipment damage, reduce power wastage, improve power quality and reliability, and enhance safety and security.
