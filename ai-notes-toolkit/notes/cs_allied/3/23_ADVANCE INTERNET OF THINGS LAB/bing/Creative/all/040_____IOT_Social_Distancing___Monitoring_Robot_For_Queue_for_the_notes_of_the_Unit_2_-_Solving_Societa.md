# IOT Social Distancing & Monitoring Robot For Queue

- This is a project that aims to prevent the spread of COVID-19 by enforcing social distancing rules in public places where queues are formed, such as banks, malls, schools, etc.  
- The project uses a four-wheel robot that follows a line on the ground and moves along with the queue. The robot has a camera and an ultrasonic sensor to measure the distance between the people in the queue and detect any violations of the social distancing norms. 
- The robot also has a buzzer and an LCD display to alert the violators and display the number of violations detected. The robot can also send the data to a cloud server using an ESP8266 module and a Wi-Fi connection. The data can be accessed and monitored by the authorities or the public using a web or mobile application.  
- The project uses Arduino IDE to program the robot and the ESP8266 module. The project also uses OpenCV library to process the images captured by the camera and calculate the distance between the people. The project also uses Firebase as the cloud platform to store and retrieve the data.  
- The project has the following advantages:
  - It can help reduce the risk of COVID-19 transmission by enforcing social distancing rules in public places.
  - It can provide real-time data and feedback to the authorities and the public about the social distancing compliance and violations.
  - It can improve the awareness and responsibility of the people to follow the social distancing norms.
  - It can be easily implemented and deployed in various locations and scenarios.
