# IOT based Manhole Detection and Monitoring System

- IOT based Manhole Detection and Monitoring System is a project that aims to improve the safety and efficiency of the drainage system in urban areas by using sensors, GSM, GPS and Arduino modules.
- The main objectives of this project are:
  - To detect and alert the authorities about the open or broken manholes that can cause accidents or blockages in the drainage system.
  - To monitor the water level and flow rate in the manholes and prevent overflow or contamination of fresh water sources.
  - To reduce the manual intervention and risk of manual scavengers who clean the underground drainage system.
  - To enhance the smart city infrastructure and management by using IOT technology and cloud services.
- The main components of this project are:
  - Sensors: Water level sensor, water flow sensor, ultrasonic sensor, gas sensor and temperature sensor are used to measure the physical parameters of the manholes and send the data to the Arduino module.
  - Arduino module: Arduino Uno is used as the microcontroller to process the sensor data and send it to the cloud server via GSM module.
  - GSM module: SIM900A GSM module is used to establish the communication between the Arduino module and the cloud server using SMS or GPRS protocols.
  - GPS module: NEO-6M GPS module is used to obtain the location coordinates of the manholes and send them to the cloud server along with the sensor data.
  - Cloud server: Firebase or Thingspeak are used as the cloud platforms to store and display the sensor data and location information of the manholes on a web dashboard or a mobile application.
  - Web dashboard or mobile application: A web dashboard or a mobile application is used to visualize the sensor data and location information of the manholes and alert the authorities or the public about the status of the manholes.
