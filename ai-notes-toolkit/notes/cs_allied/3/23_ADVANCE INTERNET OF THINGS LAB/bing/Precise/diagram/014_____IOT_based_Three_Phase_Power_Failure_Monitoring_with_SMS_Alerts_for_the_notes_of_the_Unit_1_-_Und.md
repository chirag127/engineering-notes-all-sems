### IOT based Three Phase Power Failure Monitoring with SMS Alerts

#### Unit 1 - Understanding the implementation of IOT

- IOT stands for Internet of Things, which refers to the interconnection of physical devices, vehicles, home appliances, and other items embedded with electronics, software, sensors, and connectivity, enabling these objects to collect and exchange data.

- An IOT based Three Phase Power Failure Monitoring system with SMS Alerts is a system that monitors the power supply of a three-phase power system and sends SMS alerts to the user in case of a power failure.

- The system consists of a microcontroller, a GSM module, and sensors to detect the power supply of each phase.

- The microcontroller is programmed to continuously monitor the power supply of each phase using the sensors.

- If the power supply of any phase fails, the microcontroller sends an SMS alert to the user using the GSM module.

- The user can then take appropriate action to restore the power supply.

- This system is useful in industries, hospitals, and other places where a continuous power supply is critical.

- The implementation of IOT in this system allows for remote monitoring and control, making it more efficient and convenient for the user.

- The use of SMS alerts ensures that the user is immediately notified of any power failure, allowing for quick action to be taken.

- Overall, an IOT based Three Phase Power Failure Monitoring system with SMS Alerts is a reliable and efficient way to monitor and manage the power supply of a three-phase power system.
