### IOT Smart Parking Using RFID

1. **Introduction:** IoT has made the idea of smart cities possible. It also plays a crucial role in smart parking systems. Here, we propose an idea on smart parking system using Radio Frequency Identification (RFID) technology. This system aims at replacing the traditional parking system with high technological, IoT based smart parking using RFID.

2. **Problem:** With the rapid growth in the number of vehicles and the world’s population day by day, simple tasks like parking has become laborious. In the coming years, it is expected to get only worse, leading to conflicts like lack of parking space and traffic problems.

3. **Solution:** An IoT-based smart parking system using RFID and ESP8266 can be implemented. To access the parking space, the users are designated with a smart card. An android application has to be installed in order to check the availability of parking slots.

4. **Advantages:** This system aims at replacing the conventional parking system with an IoT-based smart parking system by using RFID (radio-frequency identification). The users will be provided an entry card for getting access to the parking slot.

5. **Applications:** This system can be used in urban cities where the population is dense and there are lots of vehicles running on the road, leading to parking and traffic problems.
