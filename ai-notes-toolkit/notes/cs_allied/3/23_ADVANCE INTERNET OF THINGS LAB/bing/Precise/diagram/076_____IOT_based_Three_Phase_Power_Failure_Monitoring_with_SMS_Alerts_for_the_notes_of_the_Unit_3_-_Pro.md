### IOT based Three Phase Power Failure Monitoring with SMS Alerts

1. An IOT based system that monitors power failure in a three-phase system.
2. When one phase of a three-phase system gets lost, a phase loss occurs. This is referred to as a ‘single phasing’ .
3. This failure is generally caused by a blown fuse, thermal overload, broken wire, worn contact or mechanical failure .
4. The system alerts the authorized person through an SMS when there is a failure in one among the three phases.
5. The system is connected to the GSM module for configuration purpose.
6. The system indicates the power failure by displaying the value of voltage on the LCD display.
7. The three phases are R, Y, and B .
