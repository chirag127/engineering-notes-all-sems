# Greenhouse Monitoring and Control System using IOT Project

A greenhouse monitoring and control system using IOT is a project that aims to solve societal problems with the help of IOT. This project is part of the Unit 2 - Solving Societal problems with the help of IOT in the subject of ADVANCE INTERNET OF THINGS LAB.

The main objective of this project is to monitor and control the environmental conditions inside a greenhouse using IOT technology. This includes monitoring parameters such as temperature, humidity, light intensity, and soil moisture, and controlling the environment by adjusting the ventilation, heating, cooling, and irrigation systems.

The system consists of various sensors and actuators that are connected to a central control unit. The control unit is responsible for collecting data from the sensors, processing the data, and sending commands to the actuators to adjust the environment inside the greenhouse.

The system can be accessed and controlled remotely using a mobile or web application. This allows the user to monitor the conditions inside the greenhouse in real-time and make adjustments as needed.

Some of the benefits of using a greenhouse monitoring and control system using IOT include:
- Improved crop yield and quality
- Reduced water and energy consumption
- Reduced labor costs
- Increased efficiency and productivity

Overall, a greenhouse monitoring and control system using IOT is a powerful tool that can help farmers and greenhouse operators to optimize the growing conditions inside their greenhouses, leading to improved crop yield and quality, and reduced costs.
