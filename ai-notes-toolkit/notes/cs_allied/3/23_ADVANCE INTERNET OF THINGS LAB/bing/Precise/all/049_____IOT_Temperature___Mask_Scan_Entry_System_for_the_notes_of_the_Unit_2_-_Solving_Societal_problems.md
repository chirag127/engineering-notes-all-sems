# IOT Temperature & Mask Scan Entry System

The IOT Temperature & Mask Scan Entry System is a solution to the societal problem of preventing the spread of infectious diseases. This system can be used in public places such as schools, offices, and shopping malls to ensure that individuals entering the premises are wearing masks and do not have a fever.

The system consists of the following components:

1. **Temperature sensor**: This sensor measures the body temperature of individuals entering the premises. If an individual's temperature is above a certain threshold, an alarm is triggered, and the individual is not allowed to enter.

2. **Mask detection**: This component uses a camera and image recognition algorithms to detect whether an individual is wearing a mask. If an individual is not wearing a mask, an alarm is triggered, and the individual is not allowed to enter.

3. **Entry control**: This component controls the entry of individuals into the premises. If an individual triggers an alarm, the entry control system will prevent the individual from entering.

4. **Data collection and analysis**: This component collects data on the number of individuals entering the premises, the number of individuals wearing masks, and the number of individuals with a fever. This data can be analyzed to monitor the effectiveness of the system and to make data-driven decisions.

The IOT Temperature & Mask Scan Entry System is an effective solution to prevent the spread of infectious diseases. By using this system, public places can ensure that individuals entering the premises are taking the necessary precautions to prevent the spread of diseases. This system can be used in conjunction with other measures such as social distancing and hand hygiene to create a safe and healthy environment.
