### IOT based Anti-theft Flooring System using Raspberry Pi

- The IOT based Anti-theft detection and alert System using Raspberry Pi is a system that monitors the entire floor for movement.
- One single step anywhere on the floor is tracked and the user is alarmed through mail over IOT.
- The system uses secure flooring tiles connected with IOT.
- When the system is turned on, whoever comes inside the house, it passes the information over IOT.
- Whenever a thief enters the house and steps on the floor, it is immediately sensed by the sensor which passes on the signal to the raspberry pi controller.
- The controller processes it to be a valid signal and then moves the camera to the area where movement was detected and then transmits it over the Internet for the homeowner to check the image.
