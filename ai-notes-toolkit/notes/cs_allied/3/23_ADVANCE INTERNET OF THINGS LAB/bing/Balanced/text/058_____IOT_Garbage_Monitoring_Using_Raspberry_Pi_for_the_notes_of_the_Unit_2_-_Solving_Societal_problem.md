### IOT Garbage Monitoring Using Raspberry Pi

- IOT Garbage Monitoring Using Raspberry Pi is a project that aims to solve the problem of waste management and disposal by using sensors, internet, and a digital controller.
- The project uses two ultrasonic sensors to monitor the garbage level of two bins. The ultrasonic sensors consist of a transmitter and a receiver. They work on the principle of Doppler’s effect.
- The sensors are fixed over the dustbins and measure the distance between the waste and the sensors. When the waste is filled in the bins, the distance will be decreased and the sensors will send data to the Raspberry Pi digital controller  .
- The Raspberry Pi digital controller is a small computer that processes the data from the sensors and displays the garbage level on an LCD screen. It also sends the data to a remote server using the internet .
- The remote server is a web application that stores the data and shows the garbage level of the bins on a dashboard. The user can access the dashboard from any device and get alerts when the bins are full.
- The project can be used for the monitoring and management of garbage in big organizations and industries where dozens of bins are present. It can also be used in homes for the purpose of automatic garbage disposal reminders.
- The project can be extended by using a camera and a machine learning model to classify the trash into recyclable, compostable, or garbage categories. This can help in reducing the environmental impact of waste and promoting proper waste segregation.
