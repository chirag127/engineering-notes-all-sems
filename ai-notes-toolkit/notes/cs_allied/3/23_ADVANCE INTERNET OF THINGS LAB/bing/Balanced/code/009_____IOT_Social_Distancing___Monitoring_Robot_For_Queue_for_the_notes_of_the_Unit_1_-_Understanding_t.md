### IOT Social Distancing & Monitoring Robot For Queue

- IOT Social Distancing & Monitoring Robot For Queue is a project that aims to prevent the spread of COVID-19 by enforcing social distancing rules in public places where people form queues, such as banks, malls, schools, theatres, etc.  
- The robot consists of a four-wheel drive system, a line follower sensor, an ultrasonic sensor, a buzzer, an LCD display, and a NodeMCU microcontroller. 
- The robot follows the line drawn on the floor along the queue and measures the distance between the people using the ultrasonic sensor. If the distance is less than the recommended value (e.g. 6 feet), the robot alerts the people by sounding the buzzer and displaying a warning message on the LCD. 
- The robot also sends the data to a web server using the NodeMCU, which is connected to the internet via Wi-Fi. The web server displays the number of people in the queue, the average distance between them, and the number of violations detected by the robot. 
- The robot can be controlled remotely using a web interface or a mobile app, which allows the user to start, stop, or change the speed of the robot.
- The robot is powered by a rechargeable battery, which can last for about 8 hours.
- The robot is a low-cost and effective solution to monitor and enforce social distancing in queues, which can help reduce the risk of COVID-19 transmission and save lives.
