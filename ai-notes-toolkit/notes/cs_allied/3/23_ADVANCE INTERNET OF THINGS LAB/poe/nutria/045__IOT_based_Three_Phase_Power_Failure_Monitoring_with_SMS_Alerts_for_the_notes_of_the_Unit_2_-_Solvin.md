
### IOT based Three Phase Power Failure Monitoring with SMS Alerts

1. IOT based Three Phase Power Failure Monitoring is a system that enables the monitoring of three-phase power failure and sends SMS alerts to users when a failure occurs. 
2. This system is especially useful for industrial and commercial applications, where power failure can cause costly downtime and disruption.
3. The system consists of three main components: a sensor array, an IOT gateway, and an SMS alert system. 
4. The sensor array is used to detect any changes in the three-phase power supply, such as voltage, current, and frequency. 
5. The IOT gateway is used to connect the sensor array to the internet and send data to the SMS alert system. 
6. The SMS alert system then sends an SMS alert to the user when a power failure is detected. 
7. This system can be used to help solve societal problems, such as power outages in remote areas, by providing timely alerts. 
8. It can also be used to monitor energy consumption and detect energy theft. 
9. IOT based Three Phase Power Failure Monitoring with SMS Alerts is a cost-effective and reliable solution for monitoring power failures.
