
### IOT based Three Phase Power Failure Monitoring with SMS Alerts 

1. Three phase power failure monitoring is a process of monitoring the power supply of a three-phase system. It can detect any power failure or overload and send an alert to the user. 
2. An IoT-based system can be used for this purpose. It consists of a sensor, a microcontroller, and a GSM modem. The sensor detects the power failure and sends the signal to the microcontroller. 
3. The microcontroller processes the signal and sends it to the GSM modem, which sends an SMS alert to the user. 
4. The system also consists of a web interface, which allows the user to monitor the power supply remotely. 
5. The system can be used in industrial, commercial, and residential applications. It can be used to detect power failures and send alerts to the user in case of any power failures or overloads. 
6. The system can also be used to monitor the power supply of a single phase system. It can detect any power failure or overload and send an alert to the user. 
7. The system is cost-effective and easy to maintain. It can be used to monitor the power supply in a wide range of applications.
