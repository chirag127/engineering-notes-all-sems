### Greenhouse Monitoring and Control System using IOT Project

- The project aims to monitor and control the greenhouse environment parameters like temperature, humidity, soil moisture, light intensity, etc. using IOT sensors and devices.
- The sensors like DHT11 for temperature and humidity, soil moisture sensor and LDR for light intensity are used to sense the parameters.
- The sensed data is sent to the microcontroller which is programmed to take actions like turning ON/OFF the motors, heaters, humidifiers, LEDs, etc. based on the threshold values of the parameters to maintain the optimal greenhouse environment conditions.
- The microcontroller is connected to the cloud using WiFi and the sensor data and status of the control devices can be monitored and controlled remotely from anywhere using a web application or mobile application.
- This project demonstrates the use of IOT in precision agriculture to monitor and control the greenhouse environment leading to increased crop yields and productivity.
- The core components of the project are sensors, microcontroller, motors, heaters, WiFi module and cloud connectivity.
- Programming the microcontroller, connecting the various components and configuring the cloud connectivity are involved in implementing this project.
