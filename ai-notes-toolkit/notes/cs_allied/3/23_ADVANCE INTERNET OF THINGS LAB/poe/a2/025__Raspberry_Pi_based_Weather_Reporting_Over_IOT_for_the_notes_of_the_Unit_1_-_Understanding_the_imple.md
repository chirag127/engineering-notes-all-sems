### Raspberry Pi based Weather Reporting Over IOT for the notes of the Unit 1 - Understanding the implementation of IOT in the subject of ADVANCE INTERNET OF THINGS LAB.

1. Introduction
- Raspberry Pi is a small computer that can be used to learn programming and build digital projects.
- Using sensors and modules, weather data can be sensed and collected using Raspberry Pi.
- This weather data can be transmitted over the internet using IoT implementation.
- This project aims to understand the implementation of IoT using Raspberry Pi and reporting weather data over the internet.

2. Components required
- Raspberry Pi
- DHT11/DHT22 temperature and humidity sensor
- Jumpers
- Breadboard

3. Circuit connections
- Connect the sensor to the breadboard and connect the breadboard to Raspberry Pi using jumpers
- Connect the power supply, ground, data pin of sensor to Raspberry Pi

4. Code
- Import required libraries for sensor and wifi
- Initialize the sensor and wifi
- Continuously sense the temperature and humidity data from the sensor
- Send this data over the internet using wifi/ethernet and IoT implementation
- Display the data on a local web server

5. Working and output
- The circuit senses the temperature and humidity data continuously
- This data is sent over the internet using IoT
- The data can be viewed on a local web server
- The data can be monitored from anywhere over the internet
