#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server are two types of computing platforms that can store, process, and analyze sensor data remotely over the internet.
- Cloud is a distributed network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer or a group of computers that provide specific services or applications such as web hosting, email, etc.
- To upload sensor data to cloud or server, the following steps are usually involved:
  - The sensor device collects the data and converts it into a digital format that can be transmitted over the internet.
  - The sensor device connects to a network interface such as Wi-Fi, Ethernet, cellular, satellite, etc. that provides internet access.
  - The sensor device sends the data to a cloud or server platform using a communication protocol such as HTTP, MQTT, CoAP, etc. that defines the rules and formats for data exchange.
  - The cloud or server platform receives the data and stores it in a database or a file system that can be accessed by authorized users or applications.
- To download sensor data from cloud or server, the following steps are usually involved:
  - The user or application requests the data from the cloud or server platform using a web browser, an API, or a software tool that supports the communication protocol used by the platform.
  - The cloud or server platform retrieves the data from the database or the file system and sends it back to the user or application using the same communication protocol.
  - The user or application receives the data and displays it on a screen, a dashboard, a chart, etc. or performs further analysis or processing on it.
- Some examples of cloud and server platforms that can be used for uploading and downloading sensor data are:
  - Microsoft Defender for IoT: A cloud-based platform that provides security and visibility for industrial and critical infrastructure networks. It allows users to upload sensor data from OT devices using a sensor console and download sensor activation files from the Azure portal.
  - ThingSpeak: A cloud-based platform that provides data collection, analysis, and visualization for IoT projects. It allows users to upload sensor data from devices such as Raspberry Pi using HTTP or MQTT and download sensor data using a web browser or an API.
  - SAPHI: A server-based platform that provides custom software development and integration for IoT projects. It allows users to upload sensor data from devices such as Arduino using Wi-Fi, cellular, or satellite and download sensor data using a web browser or an API.
