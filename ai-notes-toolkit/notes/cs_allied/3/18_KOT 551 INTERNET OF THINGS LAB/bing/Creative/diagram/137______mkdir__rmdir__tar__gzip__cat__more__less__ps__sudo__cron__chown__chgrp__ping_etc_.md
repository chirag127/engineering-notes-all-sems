#### mkdir, rmdir, tar, gzip, cat, more, less, ps, sudo, cron, chown, chgrp, ping etc.

- **mkdir**: This command is used to create a new directory in the current working directory or in a specified path. The syntax is `mkdir [options] directory_name`. Some common options are `-p` to create parent directories if they do not exist, `-v` to print a message for each created directory, and `-m` to set the mode or permissions of the directory.
- **rmdir**: This command is used to remove an empty directory. The syntax is `rmdir [options] directory_name`. Some common options are `-p` to remove parent directories if they are empty, `-v` to print a message for each removed directory, and `--ignore-fail-on-non-empty` to ignore errors when trying to remove non-empty directories.
- **tar**: This command is used to create or extract compressed archive files. The syntax is `tar [options] [archive_file] [file_or_directory ...]`. Some common options are `-c` to create a new archive, `-x` to extract files from an archive, `-z` to use gzip compression, `-v` to print the names of the files being processed, and `-f` to specify the name of the archive file.
- **gzip**: This command is used to compress or decompress files using the gzip algorithm. The syntax is `gzip [options] [file ...]`. Some common options are `-c` to write the output to the standard output, `-d` to decompress the files, `-k` to keep the original files, `-l` to list the compressed file information, and `-r` to recursively compress files in directories.
- **cat**: This command is used to concatenate and print files to the standard output. The syntax is `cat [options] [file ...]`. Some common options are `-n` to number the output lines, `-b` to number the non-blank output lines, `-s` to suppress repeated empty output lines, `-E` to display a `$` at the end of each line, and `-T` to display tabs as `^I`.
- **more**: This command is used to display the contents of a file or the output of another command one screen at a time. The syntax is `more [options] [file ...]`. Some common options are `-d` to display a help message, `-l` to ignore form feed characters, `-s` to squeeze multiple blank lines into one, `-u` to suppress underlining, and `+n` to start from the nth line of the file.
- **less**: This command is similar to more, but with more features and flexibility. It allows the user to scroll forward and backward, search for patterns, and perform other operations on the displayed text. The syntax is `less [options] [file ...]`. Some common options are `-N` to show line numbers, `-i` to ignore case in searches, `-S` to chop long lines, `-X` to keep the current screen, and `-F` to quit if the entire file fits on one screen.
- **ps**: This command is used to display information about the processes running on the system. The syntax is `ps [options]`. Some common options are `-a` to show all processes, `-u` to show user-oriented information, `-x` to show processes without a controlling terminal, `-e` to show the environment variables, and `-f` to show full format information.
- **sudo**: This command is used to execute a command as another user, usually the superuser or root. The syntax is `sudo [options] command`. Some common options are `-u` to specify the user to run as, `-l` to list the commands the user can run, `-p` to specify the password prompt, `-v` to validate the user's credentials, and `-k` to invalidate the user's credentials.
- **cron**: This command is used to schedule commands or scripts to run at a specified time or interval. The syntax is `cron [options]`.
