#### mkdir, rmdir, tar, gzip, cat, more, less, ps, sudo, cron, chown, chgrp, ping etc.

- `mkdir` is a command that creates a new directory in the current or specified location. The syntax is `mkdir [options] directory_name`. Some common options are `-p` to create parent directories if they do not exist, `-v` to display a message for each created directory, and `-m` to set the permissions of the new directory.
- `rmdir` is a command that removes an empty directory. The syntax is `rmdir [options] directory_name`. Some common options are `-p` to remove parent directories if they are empty, `-v` to display a message for each removed directory, and `--ignore-fail-on-non-empty` to ignore errors when trying to remove non-empty directories.
- `tar` is a command that creates or extracts compressed archive files. The syntax is `tar [options] [archive_file] [file_or_directory ...]`. Some common options are `-c` to create a new archive, `-x` to extract files from an archive, `-z` to use gzip compression, `-v` to display the progress, and `-f` to specify the archive file name.
- `gzip` is a command that compresses or decompresses files using the gzip algorithm. The syntax is `gzip [options] [file ...]`. Some common options are `-c` to write the output to the standard output, `-d` to decompress the files, `-k` to keep the original files, `-l` to list the compressed file information, and `-r` to recursively compress files in directories.
- `cat` is a command that concatenates and displays files. The syntax is `cat [options] [file ...]`. Some common options are `-n` to number the output lines, `-b` to number the non-blank output lines, `-s` to suppress repeated empty output lines, `-E` to display a `$` at the end of each line, and `-T` to display tabs as `^I`.
- `more` is a command that displays the contents of a file or the standard input one screen at a time. The syntax is `more [options] [file ...]`. Some common options are `-d` to display a help message, `-l` to ignore form feed characters, `-p` to clear the screen before displaying each file, `-s` to squeeze multiple blank lines into one, and `-u` to suppress underlining.
- `less` is a command that displays the contents of a file or the standard input in a scrollable manner. The syntax is `less [options] [file ...]`. Some common options are `-N` to display line numbers, `-i` to ignore case in searches, `-M` to display more information about the file, `-S` to chop long lines instead of wrapping them, and `-X` to keep the current screen when exiting.
- `ps` is a command that displays information about the current processes. The syntax is `ps [options]`. Some common options are `-a` to show all processes except session leaders and processes not associated with a terminal, `-u` to show user-oriented format, `-x` to show processes without controlling terminals, `-e` to show all processes, and `-f` to show full format.
- `sudo` is a command that allows a user to execute commands as another user, usually the superuser or root. The syntax is `sudo [options] [command]`. Some common options are `-u` to specify the user to run the command as, `-l` to list the commands the user can run, `-s` to run a shell as the specified user, `-v` to update the user's cached credentials, and `-k` to invalidate the user's cached credentials.
- `cron` is a daemon that runs scheduled commands at specified intervals. The syntax is `cron [options]`. Some common options are `-l` to list the user's crontab entries, `-e` to edit the user's crontab entries, `-r` to remove the user's crontab entries, and `-u` to specify the user name. The crontab entries are written in the format `minute hour day month weekday command`.
