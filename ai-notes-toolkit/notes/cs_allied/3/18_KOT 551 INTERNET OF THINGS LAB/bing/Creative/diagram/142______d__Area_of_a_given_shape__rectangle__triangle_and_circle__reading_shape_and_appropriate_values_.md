#### d) Area of a given shape (rectangle, triangle and circle) reading shape and appropriate values from standard input

The area of a shape is the amount of space that it occupies. Different shapes have different formulas for calculating their areas. In this topic, we will learn how to find the area of three common shapes: rectangle, triangle and circle. We will also learn how to read the shape and the appropriate values from standard input using Python.

- Rectangle: A rectangle is a four-sided shape with opposite sides equal and right angles. The area of a rectangle is given by the formula:

  `area = length * width`

  where length and width are the dimensions of the rectangle. To read the shape and the values from standard input, we can use the `input()` function in Python. For example:

  ```python
  # Read the shape from standard input
  shape = input("Enter the shape: ")

  # Check if the shape is rectangle
  if shape == "rectangle":
    # Read the length and width from standard input
    length = float(input("Enter the length: "))
    width = float(input("Enter the width: "))

    # Calculate the area using the formula
    area = length * width

    # Print the area
    print("The area of the rectangle is", area)
  ```

- Triangle: A triangle is a three-sided shape with three angles. The area of a triangle is given by the formula:

  `area = (base * height) / 2`

  where base and height are the dimensions of the triangle. The base is any side of the triangle and the height is the perpendicular distance from the opposite vertex to the base. To read the shape and the values from standard input, we can use the same `input()` function in Python. For example:

  ```python
  # Read the shape from standard input
  shape = input("Enter the shape: ")

  # Check if the shape is triangle
  if shape == "triangle":
    # Read the base and height from standard input
    base = float(input("Enter the base: "))
    height = float(input("Enter the height: "))

    # Calculate the area using the formula
    area = (base * height) / 2

    # Print the area
    print("The area of the triangle is", area)
  ```

- Circle: A circle is a shape with all points equidistant from a fixed point called the center. The area of a circle is given by the formula:

  `area = pi * radius * radius`

  where pi is a constant value approximately equal to 3.14 and radius is the distance from the center to any point on the circle. To read the shape and the values from standard input, we can use the same `input()` function in Python. For example:

  ```python
  # Read the shape from standard input
  shape = input("Enter the shape: ")

  # Check if the shape is circle
  if shape == "circle":
    # Read the radius from standard input
    radius = float(input("Enter the radius: "))

    # Calculate the area using the formula
    area = 3.14 * radius * radius

    # Print the area
    print("The area of the circle is", area)
  ```
