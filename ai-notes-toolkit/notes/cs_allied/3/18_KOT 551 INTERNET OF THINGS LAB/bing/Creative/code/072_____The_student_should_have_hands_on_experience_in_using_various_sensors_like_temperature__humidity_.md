### The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc. and

- understand the principles and applications of different types of sensors
- learn how to connect and interface sensors with microcontrollers or computers
- acquire and process sensor data using appropriate software tools and libraries
- design and implement sensor-based projects for various domains and scenarios
- evaluate the performance and limitations of sensors and sensor systems

Some of the benefits of having hands on experience in using sensors are:

- It enhances the student's practical skills and problem-solving abilities
- It exposes the student to real-world challenges and opportunities in sensor technology
- It fosters the student's creativity and innovation
- It prepares the student for future careers or studies in sensor-related fields
