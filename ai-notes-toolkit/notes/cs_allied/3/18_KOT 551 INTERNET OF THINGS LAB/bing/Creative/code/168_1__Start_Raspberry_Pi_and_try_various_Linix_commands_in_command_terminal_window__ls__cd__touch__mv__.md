# 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, affordable computer that can run Linux, a free and open-source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) with icons and menus. You can use the mouse and keyboard to interact with the GUI.
- To open a command terminal window, you can either click on the terminal icon on the desktop or the menu bar, or press Ctrl+Alt+T on the keyboard.
- A command terminal window is a text-based interface that allows you to enter commands and see the output. You can use the terminal to perform various tasks and operations on Raspberry Pi.
- Some of the basic Linux commands that you can try in the terminal are:

  - `ls`: This command lists the files and directories in the current working directory. You can use various options with `ls` to change the format and details of the output. For example, `ls -l` shows the long listing format with permissions, size, date, and owner of each file and directory. `ls -a` shows the hidden files and directories that start with a dot (.). `ls -R` shows the files and directories recursively, including the subdirectories. You can also use `ls` with a specific path or name to list only the files and directories that match. For example, `ls /home/pi` lists the files and directories in the `/home/pi` directory. `ls *.txt` lists the files that end with `.txt` in the current working directory.
  - `cd`: This command changes the current working directory to the one specified. You can use `cd` with an absolute path or a relative path. An absolute path starts with a slash (/) and specifies the exact location of a directory from the root of the file system. A relative path starts with the name of a directory or a dot (.) and specifies the location of a directory relative to the current working directory. For example, `cd /home/pi` changes the current working directory to `/home/pi`. `cd Documents` changes the current working directory to `Documents`, which is a subdirectory of the current working directory. `cd ..` changes the current working directory to the parent directory of the current working directory. `cd` without any argument changes the current working directory to the home directory of the current user, which is `/home/pi` by default.
  - `touch`: This command creates a new, empty file with the name specified. You can use `touch` with one or more file names as arguments. For example, `touch hello.txt` creates a new file named `hello.txt` in the current working directory. `touch file1 file2 file3` creates three new files named `file1`, `file2`, and `file3` in the current working directory. If the file already exists, `touch` does not overwrite it, but updates its access and modification times to the current time.
  - `mv`: This command moves or renames a file or a directory. You can use `mv` with two arguments: the source and the destination. The source can be a file or a directory name, and the destination can be a file or a directory name, or a path. For example, `mv hello.txt goodbye.txt` renames the file `hello.txt` to `goodbye.txt` in the current working directory. `mv hello.txt /home/pi/Documents` moves the file `hello.txt` from the current working directory to the `/home/pi/Documents` directory. `mv Documents Backup` renames the directory `Documents` to `Backup` in the current working directory. If the destination already exists and is a file, `mv` overwrites it. If the destination already exists and is a directory, `mv` moves the source into the destination directory.
  - `rm`: This command removes or deletes a file or a directory. You can use `rm` with one or more file or directory names as arguments. For example, `rm hello.txt` removes the file `hello.txt` from the current working directory. `rm file1 file2 file3` removes the files `file1`, `file2`, and `file3` from the current working directory. `rm -r Documents` removes the directory `Documents` and all its contents recursively from the current working directory. `rm -i` prompts for confirmation before removing each file or directory.
