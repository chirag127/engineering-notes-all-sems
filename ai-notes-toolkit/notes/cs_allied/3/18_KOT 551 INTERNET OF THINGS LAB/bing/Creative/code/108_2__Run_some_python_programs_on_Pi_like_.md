# 2. Run some python programs on Pi like:

- Python is a popular programming language that can be used to create various applications on Raspberry Pi, such as games, web servers, robots, etc.
- To run a python program on Pi, you need to have a text editor, a terminal, and a python interpreter installed on your Pi.
- A text editor is a software that allows you to write and edit code. Some examples of text editors are Thonny, IDLE, nano, etc.
- A terminal is a software that allows you to interact with your Pi using commands. You can open a terminal by clicking on the black icon on the top left corner of the desktop or by pressing Ctrl+Alt+T on the keyboard.
- A python interpreter is a software that executes your code and displays the output. Python is pre-installed on Raspberry Pi OS, so you don't need to install it separately. You can check the version of python by typing `python --version` or `python3 --version` in the terminal.
- To run a python program on Pi, you need to follow these steps:

  - Write your code in a text editor and save it with a `.py` extension. For example, you can write a simple program that prints "Hello, world!" and save it as `hello.py`.
  - Open a terminal and navigate to the directory where you saved your file. You can use commands like `cd`, `ls`, `pwd`, etc. to move around the file system. For example, if you saved your file on the desktop, you can type `cd Desktop` to go to the desktop directory.
  - Run your program by typing `python` or `python3` followed by the name of your file. For example, you can type `python hello.py` or `python3 hello.py` to run your program. You should see the output on the terminal.
  - If you want to exit the python interpreter, you can type `exit()` or press Ctrl+D on the keyboard.
