### The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc. and

- understand the basic principles and working of each sensor
- learn how to connect the sensors to a microcontroller or a computer using appropriate wires, pins, and protocols
- write and upload code to read and process the sensor data using suitable programming languages and libraries
- display and visualize the sensor data on a screen or a dashboard using graphs, charts, or indicators
- analyze and interpret the sensor data to infer meaningful information and insights
- apply the sensor data to control other devices or systems using actuators, relays, or switches
- design and implement projects or experiments that use sensors to solve real-world problems or demonstrate scientific concepts
- evaluate the performance and accuracy of the sensors and the systems using appropriate metrics and methods
- document and present the sensor projects or experiments using reports, posters, or videos
