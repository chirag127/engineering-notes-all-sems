# CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server are two types of computing platforms that can store, process, and analyze sensor data remotely over the internet.
- Cloud is a network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer that hosts a specific application or service such as a web server, a database server, etc.
- To upload sensor data to cloud or server, the sensor device needs to have a network connection such as Wi-Fi, Ethernet, cellular, satellite, etc. and a protocol such as HTTP, MQTT, CoAP, etc. to communicate with the cloud or server.
- To download sensor data from cloud or server, the sensor device or another device such as a laptop, a smartphone, etc. needs to have a network connection and a protocol to communicate with the cloud or server, and a method to access the data such as a web browser, an API, a dashboard, etc.
- Some examples of uploading and downloading sensor data on cloud and server are:

  - Using a Raspberry Pi and a DHT22 sensor to measure humidity and temperature and send the data to ThingSpeak cloud platform using HTTP protocol. The data can be downloaded from ThingSpeak using a web browser or an API.
  - Using an Arduino and a light sensor to measure light intensity and send the data to AWS DynamoDB cloud database using MQTT protocol. The data can be downloaded from DynamoDB using an API or a dashboard.
  - Using a Microsoft Defender for IoT sensor to monitor network traffic and send the data to Azure cloud platform using HTTPS protocol. The data can be downloaded from Azure using a web browser or an API.
  - Using a satellite modem and a GPS sensor to measure location and send the data to a web server using TCP/IP protocol. The data can be downloaded from the web server using a web browser or an API.
