# Reading your name and printing a hello message with your name

- To read your name from the keyboard, you need to use an input function that takes a string as an argument and returns the user's input as a string.
- Different programming languages have different input functions, such as `input()` in Python, `Scanner.nextLine()` in Java, `Console.ReadLine()` in C#, etc.
- To print a hello message with your name, you need to use an output function that takes a string as an argument and displays it on the screen.
- Different programming languages have different output functions, such as `print()` in Python, `System.out.println()` in Java, `Console.WriteLine()` in C#, etc.
- You can use string concatenation or formatting to combine the hello message and your name into one string.
- String concatenation means joining two or more strings together using the `+` operator, such as `"Hello " + name`.
- String formatting means inserting variables or expressions into placeholders in a string, such as `"Hello {}".format(name)` in Python, `"Hello %s".format(name)` in Java, `"Hello {0}".format(name)` in C#, etc.

Here are some examples of code snippets that read your name and print a hello message with your name in different programming languages:

## Python

```python
# Read your name from the keyboard
name = input("Enter your name: ")

# Print a hello message with your name
print("Hello " + name)
```

