# KOT 552 INTERNET OF THINGS LAB KCS

- Internet of Things (IoT) is the concept of connecting physical objects and devices to the internet and enabling them to communicate and exchange data with other devices and applications.
- IoT has many applications in various domains, such as smart homes, smart cities, healthcare, agriculture, industry, etc.
- IoT devices can collect data about the physical world and make these data available in the Cloud. In the laboratory, such connectivity can be exploited for tasks such as continual monitoring of laboratory environment and instruments, inventory management, and data collection .
- IoT devices can also be used to control and automate laboratory processes, such as adjusting temperature, lighting, ventilation, etc.
- IoT devices can be designed and developed using various hardware and software platforms, such as Arduino, Raspberry Pi, NodeMCU, etc. These platforms provide different features and capabilities, such as sensors, actuators, wireless communication, cloud integration, etc.
- IoT devices can be programmed using various languages and frameworks, such as Python, C, Java, Node.js, etc. These languages and frameworks provide different libraries and tools to facilitate the development and deployment of IoT applications.
- IoT devices can be connected to the internet using various protocols and standards, such as Wi-Fi, Bluetooth, Zigbee, MQTT, CoAP, etc. These protocols and standards provide different levels of security, reliability, scalability, and interoperability for IoT communication.
- IoT devices can be integrated with various cloud services and platforms, such as AWS, Google Cloud, Azure, etc. These cloud services and platforms provide different functionalities and benefits, such as data storage, data analysis, data visualization, machine learning, etc.

## Lab Objectives

- The main objective of this lab course is to provide hands-on experience and practical skills in designing, developing, and deploying IoT devices and applications.
- The lab course will cover the following topics:
  - Introduction to IoT and its applications
  - IoT hardware and software platforms
  - IoT programming languages and frameworks
  - IoT communication protocols and standards
  - IoT cloud services and platforms
- The lab course will consist of a series of lab exercises and mini-projects that will require the students to use various IoT devices and platforms to implement different IoT scenarios and applications.
- The lab course will also require the students to document and present their work and results in a clear and concise manner.

## Lab Requirements

- The students will need the following hardware and software components to complete the lab exercises and mini-projects:
  - A laptop or desktop computer with internet access and a USB port
  - A Raspberry Pi Zero W board with a microSD card, a micro USB cable, and a power adapter
  - A breadboard, jumper wires, LEDs, resistors, push buttons, and a buzzer
  - A DHT11 temperature and humidity sensor, a BMP180 pressure and altitude sensor, and an MQ-2 gas sensor
  - A camera module for Raspberry Pi
  - A Wi-Fi dongle or a Wi-Fi router
  - A free account on AWS, Google Cloud, or Azure
- The students will also need to install the following software tools on their computer:
  - PuTTY or any other SSH client
  - WinSCP or any other FTP client
  - Python 3 and pip
  - Node.js and npm
  - Arduino IDE
  - Visual Studio Code or any other code editor
