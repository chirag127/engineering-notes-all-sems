# 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, affordable computer that can run Linux, a free and open-source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) with icons and menus. You can use the mouse and keyboard to interact with the GUI.
- To open a command terminal window, you can either click on the terminal icon on the desktop or the menu bar, or press Ctrl+Alt+T on the keyboard.
- A command terminal window is a text-based interface that allows you to enter commands and see the output. You can use the terminal to perform various tasks on Raspberry Pi, such as creating, moving, deleting, and viewing files and folders.
- Some of the basic Linux commands that you can try in the terminal are:

  - `ls`: This command lists the files and folders in the current directory. You can use the `-l` option to see more details, such as the size, permissions, owner, and modification date of each file and folder. You can also use the `-a` option to see hidden files and folders, which start with a dot (.).
  - `cd`: This command changes the current directory to the one specified. You can use `cd ..` to go up one level, or `cd /` to go to the root directory. You can also use `cd ~` to go to your home directory, which is `/home/pi` by default.
  - `touch`: This command creates a new, empty file with the name specified. For example, `touch hello.txt` will create a file named hello.txt in the current directory. You can also use `touch` to update the modification date of an existing file, without changing its content.
  - `mv`: This command moves or renames a file or folder. You need to specify the source and the destination. For example, `mv hello.txt Documents` will move the file hello.txt from the current directory to the Documents folder. You can also use `mv` to rename a file or folder, by specifying a different name as the destination. For example, `mv hello.txt goodbye.txt` will rename the file hello.txt to goodbye.txt.
  - `rm`: This command removes or deletes a file or folder. You need to specify the name of the file or folder to delete. For example, `rm goodbye.txt` will delete the file goodbye.txt from the current directory. You can also use the `-r` option to delete a folder and all its contents recursively. For example, `rm -r Documents` will delete the Documents folder and everything inside it. Be careful with this command, as there is no undo option.
  - `man`: This command shows the manual page for a command or a topic. You can use it to learn more about how to use a command, what options and arguments it accepts, and what output it produces. For example, `man ls` will show the manual page for the `ls` command. You can use the arrow keys to scroll up and down, and press Q to quit. You can also use `man -k` to search for a keyword in all the manual pages. For example, `man -k file` will show all the manual pages that contain the word file.
