# Input

- Input is the process of receiving data or information from an external source, such as a user, a device, a file, or a network.
- Input can be categorized into different types, such as:
  - Keyboard input: The user enters data or commands using a keyboard, such as typing text, numbers, or symbols.
  - Mouse input: The user moves or clicks a mouse to perform actions, such as selecting, dragging, or scrolling.
  - Touch input: The user touches a screen or a pad to interact with a graphical user interface, such as tapping, swiping, or pinching.
  - Voice input: The user speaks to a microphone or a device to provide data or instructions, such as dictating text, asking questions, or giving commands.
  - Scanner input: A device scans an image or a document and converts it into digital data, such as a barcode, a photo, or a text.
  - Sensor input: A device measures a physical quantity or a condition and converts it into electrical signals, such as temperature, pressure, or motion.
- Input can be processed by different methods, such as:
  - Buffering: The input data is temporarily stored in a memory area called a buffer until it is ready to be processed by the CPU or another device.
  - Parsing: The input data is analyzed and divided into meaningful units, such as words, sentences, or commands, according to a set of rules or a grammar.
  - Validation: The input data is checked for errors, accuracy, or completeness, such as verifying the format, the range, or the existence of the data.
  - Encryption: The input data is transformed into a secret code that can only be decoded by authorized parties, such as using a key, a password, or an algorithm.
