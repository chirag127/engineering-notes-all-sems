#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server are two types of computing platforms that can store, process and analyze sensor data remotely over the internet.
- Cloud is a network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer that hosts a specific application or service such as a web server, a database server, etc.
- To upload sensor data to cloud or server, the sensor device needs to have a network connection such as Wi-Fi, Ethernet, cellular, satellite, etc. and a protocol such as HTTP, MQTT, CoAP, etc. to communicate with the cloud or server.
- To download sensor data from cloud or server, the sensor device or another device such as a laptop, a smartphone, etc. needs to have a network connection and a protocol to communicate with the cloud or server. The device can also use a web browser or an application to access the sensor data from the cloud or server.
- Some examples of uploading and downloading sensor data on cloud and server are:

  - Using a Raspberry Pi and a DHT22 sensor to measure humidity and temperature and send the readings to the ThingSpeak cloud platform using HTTP protocol. The sensor data can be viewed and analyzed on the ThingSpeak web interface or using MATLAB.
  - Using an Arduino and a light sensor to measure light intensity and send the readings to the AWS DynamoDB cloud service using MQTT protocol. The sensor data can be queried and processed using AWS IoT rules and actions.
  - Using a Microsoft Defender for IoT sensor to monitor and protect industrial networks and devices and upload the sensor data to the Azure cloud platform using a subscription and activation file. The sensor data can be accessed and managed using the Azure portal or the Defender for IoT sensor console.
- Some benefits of uploading and downloading sensor data on cloud and server are:

  - Scalability: Cloud and server can handle large and/or frequent amounts of sensor data without affecting the performance of the sensor device or the network.
  - Availability: Cloud and server can provide reliable and continuous access to sensor data from anywhere and anytime using the internet.
  - Security: Cloud and server can protect sensor data from unauthorized access, modification or deletion using encryption, authentication and authorization mechanisms.
  - Analytics: Cloud and server can offer advanced tools and techniques to analyze sensor data and generate insights, predictions and recommendations.
