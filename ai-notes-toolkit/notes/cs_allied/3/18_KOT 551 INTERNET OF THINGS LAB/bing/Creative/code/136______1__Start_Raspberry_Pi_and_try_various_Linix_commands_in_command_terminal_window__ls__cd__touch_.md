#### 1. Start Raspberry Pi and try various Linix commands in command terminal window: ls, cd, touch, mv, rm, man,

- Raspberry Pi is a small computer that can run Linux operating system and perform various tasks.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- Once Raspberry Pi boots up, you will see a desktop environment or a command terminal window, depending on the operating system you have chosen.
- A command terminal window is a text-based interface that allows you to interact with the operating system using commands. You can type commands and press enter to execute them. You can also see the output of the commands on the screen.
- Some of the basic Linux commands that you can try in the command terminal window are:

  - `ls`: This command lists the files and directories in the current working directory. You can use options like `-l` to see more details, `-a` to see hidden files, or `-h` to see human-readable sizes.
  - `cd`: This command changes the current working directory to the one specified. You can use `..` to go up one level, `.` to stay in the same directory, or `~` to go to your home directory.
  - `touch`: This command creates a new empty file with the name specified. You can also use it to update the timestamp of an existing file.
  - `mv`: This command moves or renames a file or directory. You need to specify the source and the destination. You can also use options like `-i` to prompt before overwriting, or `-n` to not overwrite.
  - `rm`: This command removes a file or directory. You need to specify the name of the file or directory to delete. You can also use options like `-i` to prompt before deleting, `-r` to delete recursively, or `-f` to force delete.
  - `man`: This command shows the manual page for a command or a topic. You can use it to learn more about the syntax, options, and examples of a command. You can also use keywords to search for a topic. You can navigate the manual page using the arrow keys, spacebar, or enter. You can quit the manual page by pressing `q`.

- To try these commands, you can open a command terminal window by clicking on the terminal icon on the desktop or by pressing `Ctrl+Alt+T`. You can also use multiple terminal windows by opening new tabs or windows. You can close a terminal window by typing `exit` or by clicking on the close button.
