### The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc. and

- understand the basic principles and working of each sensor
- learn how to connect the sensors to a microcontroller or a computer using appropriate wires, pins, and protocols
- write and upload code to read and process the sensor data using suitable programming languages and libraries
- display and visualize the sensor data on a screen or a dashboard using graphs, charts, or indicators
- analyze and interpret the sensor data to draw meaningful conclusions and insights
- apply the sensor data to solve real-world problems or create innovative projects
- evaluate the performance and accuracy of the sensors and troubleshoot any issues or errors
- compare and contrast the advantages and disadvantages of different sensors and their applications
