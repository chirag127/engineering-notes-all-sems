#### Input

- Input is the process of providing data or instructions to a computer system so that it can perform a task or operation .
- Input is important because it allows users to interact with a computer system and provide information that can be processed and analyzed.
- Input can be given in various forms, such as text, images, sound, video, gestures, etc .
- Input devices are hardware components that enable users to input data or instructions to a computer system .
- The most common input devices are the keyboard, mouse, and touch screen. There are hundreds of other input devices, such as microphones, scanners, cameras, sensors, etc.
- Input devices can be classified into different categories based on their functionality, such as pointing devices, scanning devices, audio devices, etc .
- Input devices can also be categorized based on their mode of interaction, such as direct input devices, which allow users to directly manipulate objects on the screen, or indirect input devices, which require an intermediate device or software to translate the input into commands .
- Input devices can also be categorized based on their level of abstraction, such as discrete input devices, which provide discrete values or symbols, or continuous input devices, which provide continuous values or signals .
- Input devices can also be categorized based on their degree of naturalness, such as natural input devices, which use natural human modalities, such as speech or gestures, or artificial input devices, which use artificial or conventional modalities, such as keyboards or mice .
