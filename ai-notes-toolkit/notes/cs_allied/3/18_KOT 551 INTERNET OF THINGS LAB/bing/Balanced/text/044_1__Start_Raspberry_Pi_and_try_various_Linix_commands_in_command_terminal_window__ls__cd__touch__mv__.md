# Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small computer that runs on Linux, a free and open source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux distribution installed on it, such as Raspberry Pi OS.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) with icons and menus. You can use the mouse and keyboard to interact with the GUI, or you can open a command terminal window to type commands.
- A command terminal window is a text-based interface that allows you to execute commands and programs on Raspberry Pi. You can open a command terminal window by clicking on the terminal icon on the taskbar, or by pressing Ctrl+Alt+T on the keyboard.
- In the command terminal window, you will see a prompt that looks something like this: `pi@raspberrypi:~ $`. This indicates your username (`pi`), your hostname (`raspberrypi`), your current working directory (`~`, which means your home directory), and a dollar sign (`$`, which means you are a regular user, not an administrator).
- You can type commands after the prompt and press Enter to execute them. Commands are case-sensitive, meaning that `ls` and `LS` are different commands. You can also use options and arguments to modify the behavior of commands. Options usually start with a dash (`-`), and arguments are the values or names that the command operates on.
- Here are some examples of common Linux commands that you can try on Raspberry Pi:

  - `ls`: This command lists the files and directories in your current working directory. You can use the option `-l` to see more details, such as the size, owner, permissions, and modification date of each file and directory. You can also use the option `-a` to see hidden files and directories, which start with a dot (`.`). For example, `ls -la` will list all files and directories, including hidden ones, with details.
  - `cd`: This command changes your current working directory to another one. You can use an absolute path, which starts with a slash (`/`), or a relative path, which starts with the name of a subdirectory or a dot (`.`). For example, `cd /home/pi/Documents` will change your current working directory to `/home/pi/Documents`, and `cd ..` will change your current working directory to the parent directory of the current one.
  - `touch`: This command creates a new empty file with the given name. For example, `touch hello.txt` will create a new file named `hello.txt` in your current working directory. You can also use this command to update the modification date of an existing file, without changing its content.
  - `mv`: This command moves or renames a file or directory. You need to specify the source and the destination of the file or directory. For example, `mv hello.txt goodbye.txt` will rename the file `hello.txt` to `goodbye.txt`, and `mv goodbye.txt Documents` will move the file `goodbye.txt` to the `Documents` directory.
  - `rm`: This command removes or deletes a file or directory. You need to specify the name of the file or directory that you want to remove. For example, `rm goodbye.txt` will delete the file `goodbye.txt`. You can use the option `-r` to remove a directory and all its contents recursively. For example, `rm -r Documents` will delete the `Documents` directory and everything inside it. Be careful with this command, as there is no undo option for it.
  - `man`: This command shows the manual page for a command or a topic. A manual page is a document that explains the usage, syntax, options, and examples of a command or a topic. You can use the arrow keys or the space bar to scroll through the manual page, and press Q to quit. For example, `man ls` will show the manual page for the `ls` command. You can also use the option `-k` to search for a keyword in all the manual pages. For example, `man -k file` will show a list of manual pages that contain the word `file`.
