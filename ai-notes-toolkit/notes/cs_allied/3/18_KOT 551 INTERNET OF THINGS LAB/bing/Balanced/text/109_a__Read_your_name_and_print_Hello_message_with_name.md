# Read your name and print Hello message with name

- This is a simple program that takes the user's name as an input and prints a greeting message with the name.
- To read the user's name, we can use the `input()` function in Python, which returns a string value entered by the user.
- To print the greeting message, we can use the `print()` function in Python, which displays the value passed as an argument to the standard output device (such as the screen).
- We can use the `+` operator to concatenate (join) two strings together, such as the greeting and the name.
- Here is an example of the program in Python:

```python
# Read the user's name
name = input("Enter your name: ")

# Print the greeting message with the name
print("Hello, " + name + "!")
```

- If the user enters `Sydney` as the name, the output of the program will be:

```
Hello, Sydney!
```
