#### Input

- Input is the process of providing data or instructions to a computer system so that it can perform a task or operation.
- Input is important because it allows users to interact with a computer system and provide information that can be processed and analyzed.
- Input can be given in various forms, such as text, images, sound, video, gestures, etc.
- Input devices are hardware components that enable users to input data or instructions to a computer system.
- The most common input devices are the keyboard, mouse, and touch screen. There are hundreds of other input devices, such as microphones, scanners, cameras, joysticks, etc.
- Input devices can be classified into different categories based on their functions, such as pointing devices, scanning devices, audio devices, etc.
- Input devices can also be categorized based on their modes of interaction, such as direct input devices, indirect input devices, and hybrid input devices.
- Direct input devices allow users to directly manipulate objects on the screen, such as touch screens, styluses, etc.
- Indirect input devices require users to move a cursor or pointer on the screen, such as mice, trackballs, etc.
- Hybrid input devices combine both direct and indirect modes of interaction, such as touchpads, touch mice, etc.
- Input devices can also be categorized based on their physical properties, such as mechanical, optical, magnetic, etc.
