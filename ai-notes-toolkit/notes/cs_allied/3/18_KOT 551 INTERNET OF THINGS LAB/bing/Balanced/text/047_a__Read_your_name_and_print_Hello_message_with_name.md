# Read your name and print Hello message with name

- This is a simple program that takes the user's name as an input and prints a greeting message with the name.
- To write this program, you need to know how to use variables, input function, and print function in Python.
- A variable is a name that refers to a value stored in the memory. You can assign a value to a variable using the equal sign (=).
- The input function allows you to get a string from the user through the keyboard. You can use a prompt inside the parentheses to tell the user what to enter.
- The print function displays a message on the screen. You can use the plus sign (+) to concatenate strings together.

- Here is an example of the program:

```python
# Read the user's name
name = input("Enter your name: ")

# Print a greeting message with the name
print("Hello, " + name + "!")
```

- Here is a sample output of the program:

```text
Enter your name: Sydney
Hello, Sydney!
```
