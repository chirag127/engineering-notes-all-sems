# Get the status of a bulb at a remote place (on the LAN) through web

- To get the status of a bulb at a remote place (on the LAN) through web, one needs to have a web server, a web client, and a smart bulb that can communicate over the LAN.
- A web server is a software or hardware device that can host and serve web pages and resources to web clients over a network protocol, such as HTTP or HTTPS.
- A web client is a software or hardware device that can request and receive web pages and resources from a web server over a network protocol, such as HTTP or HTTPS.
- A smart bulb is a light bulb that can be controlled remotely through a network protocol, such as Wi-Fi, Bluetooth, Zigbee, or Z-Wave.
- The steps to get the status of a bulb at a remote place (on the LAN) through web are as follows:

  1. Connect the web server, the web client, and the smart bulb to the same LAN, either through wired or wireless connections.
  2. Configure the web server to host a web page that can display the status of the smart bulb, such as on, off, dim, color, etc. The web page can also have buttons or sliders to control the smart bulb.
  3. Configure the web server to communicate with the smart bulb over the network protocol that the smart bulb supports, such as Wi-Fi, Bluetooth, Zigbee, or Z-Wave. The web server can use APIs or libraries to send commands and receive responses from the smart bulb.
  4. Configure the web client to access the web page hosted by the web server over the network protocol that the web server supports, such as HTTP or HTTPS. The web client can use a web browser or a dedicated app to request and render the web page.
  5. On the web client, open the web page hosted by the web server and view the status of the smart bulb. The web page can also allow the user to control the smart bulb by clicking or sliding the buttons or sliders on the web page.
  6. The web server can update the web page dynamically based on the feedback from the smart bulb, such as changing the color or brightness of the web page to reflect the color or brightness of the smart bulb. The web client can also refresh the web page periodically or manually to get the latest status of the smart bulb.
