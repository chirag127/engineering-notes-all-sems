#### CO 5 Examine various SQL queries from MySQL database K4, K5

- SQL stands for Structured Query Language and is a standard language for accessing and manipulating data in relational databases.
- MySQL is an open-source relational database management system that uses SQL as its query language.
- SQL queries are expressions that define the set of data to be retrieved from the database. They can be written in a database management application (such as MySQL Workbench) or in a programming language (such as PHP) that connects to the database.
- SQL queries can be classified into five types based on their purpose and syntax:
  - DDL (Data Definition Language): These queries are used to create, alter, rename, drop, or truncate the physical structure of the tables in the database. For example, `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, etc.
  - DML (Data Manipulation Language): These queries are used to insert, update, delete, or select the data in the tables. For example, `INSERT INTO`, `UPDATE`, `DELETE`, `SELECT`, etc.
  - DCL (Data Control Language): These queries are used to grant or revoke the permissions or access rights to the users or roles in the database. For example, `GRANT`, `REVOKE`, etc.
  - TCL (Transaction Control Language): These queries are used to manage the transactions in the database, such as committing or rolling back the changes made by the queries. For example, `COMMIT`, `ROLLBACK`, `SAVEPOINT`, etc.
  - DQL (Data Query Language): These queries are used to retrieve the data from the database based on certain conditions or criteria. For example, `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, etc.
- To examine various SQL queries from MySQL database, one needs to understand the following concepts:
  - Database: A database is a collection of related data that is organized in a logical way. A database can have one or more tables that store the data.
  - Table: A table is a structure that consists of rows and columns that store the data. A table can have a primary key that uniquely identifies each row, and a foreign key that references another table.
  - Column: A column is a vertical segment of a table that stores a specific type of data. A column can have a name, a data type, and a constraint that defines the rules for the data in the column.
  - Row: A row is a horizontal segment of a table that stores a single record of data. A row can have one or more values that correspond to the columns in the table.
  - Query: A query is a request for data from the database. A query can have one or more clauses that specify the details of the data to be retrieved, such as the table name, the column name, the condition, the grouping, the ordering, etc.
  - Result: A result is the output of a query that shows the data that matches the query criteria. A result can be displayed in a tabular format or in a graphical format.
