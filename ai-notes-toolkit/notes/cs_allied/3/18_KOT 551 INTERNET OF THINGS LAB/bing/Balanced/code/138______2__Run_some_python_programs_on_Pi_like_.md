#### 2. Run some python programs on Pi like:

- To run a python program on Pi, you need to have a python interpreter installed on your device. Python is a high-level, interpreted, and general-purpose programming language that can run on different platforms, including Pi.
- You can check if you have python installed by typing `python --version` or `python3 --version` in the terminal. If you see a version number, such as 3.9.2, then you have python installed. If not, you can install it by typing `sudo apt install python3` or `sudo apt install python` depending on the version you want.
- To write a python program, you can use any text editor, such as nano, vim, or idle. You can also use an integrated development environment (IDE), such as Thonny, which is a simple and beginner-friendly IDE for python that comes pre-installed on Pi.
- To create a new python file, you can type `nano hello.py` in the terminal, where hello.py is the name of your file. This will open the nano text editor, where you can write your python code. For example, you can write `print("Hello, world!")` as your first python program. To save and exit the nano editor, you can press Ctrl+X, then Y, then Enter.
- To run your python file, you can type `python hello.py` or `python3 hello.py` in the terminal, depending on the version of python you are using. This will execute your code and display the output on the screen. For example, you should see `Hello, world!` as the output of your program.
- You can also run your python file from the Thonny IDE, by opening it from the main menu or by typing `thonny` in the terminal. Then, you can click on File -> New, and write your python code in the editor. To run your code, you can click on the green arrow button or press F5. This will display the output in the shell window below the editor. For example, you should see `Hello, world!` as the output of your program.
