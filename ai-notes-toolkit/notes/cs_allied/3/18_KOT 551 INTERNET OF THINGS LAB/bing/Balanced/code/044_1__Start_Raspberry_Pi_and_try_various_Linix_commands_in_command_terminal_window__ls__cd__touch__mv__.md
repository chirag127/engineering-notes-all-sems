# 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, affordable computer that can run Linux, a free and open source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) with icons and menus. You can use the mouse and keyboard to interact with the GUI.
- Alternatively, you can use the command terminal window, which is a text-based interface that allows you to enter commands and see the output. You can open the command terminal window by clicking on the icon that looks like a black screen with a white cursor, or by pressing Ctrl+Alt+T on the keyboard.
- In the command terminal window, you can enter various Linux commands to perform different tasks. Some of the common Linux commands are:

  - `ls`: This command lists the files and folders in the current directory. You can use the `-l` option to see more details, such as the size, permissions, and modification date of each file and folder. You can also use the `-a` option to see the hidden files and folders, which start with a dot (.).
  - `cd`: This command changes the current directory to another directory. You can use the name of the directory as an argument, such as `cd Documents` to go to the Documents directory. You can also use the `..` symbol to go to the parent directory, such as `cd ..` to go one level up. You can use the `~` symbol to go to your home directory, such as `cd ~` to go to /home/pi.
  - `touch`: This command creates a new, empty file with the name you specify as an argument, such as `touch hello.txt` to create a file named hello.txt. You can also use this command to update the modification date of an existing file, without changing its content.
  - `mv`: This command moves or renames a file or folder. You can use the name of the source file or folder and the name of the destination file or folder as arguments, such as `mv hello.txt goodbye.txt` to rename hello.txt to goodbye.txt, or `mv hello.txt Documents` to move hello.txt to the Documents directory. You can also use the `-i` option to prompt for confirmation before overwriting an existing file or folder.
  - `rm`: This command removes or deletes a file or folder. You can use the name of the file or folder as an argument, such as `rm hello.txt` to delete hello.txt. You can also use the `-r` option to delete a folder and all its contents recursively, such as `rm -r Documents` to delete the Documents directory and everything inside it. You can also use the `-i` option to prompt for confirmation before deleting a file or folder.
  - `man`: This command shows the manual page for a command or a topic. You can use the name of the command or the topic as an argument, such as `man ls` to see the manual page for the ls command, or `man intro` to see the introduction to Linux commands. You can use the arrow keys or the space bar to scroll through the manual page, and the Q key to quit.
