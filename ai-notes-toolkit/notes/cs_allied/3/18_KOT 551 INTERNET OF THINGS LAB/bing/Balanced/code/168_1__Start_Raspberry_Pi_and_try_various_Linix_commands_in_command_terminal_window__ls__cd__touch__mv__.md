# 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, affordable computer that can run Linux, a free and open source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- To open the command terminal window, you can either click on the terminal icon on the desktop, or press Ctrl+Alt+T on the keyboard.
- The command terminal window is where you can type commands to interact with the Linux system. Commands are case-sensitive and must be followed by the Enter key.
- Some of the basic Linux commands are:

  - `ls`: This command lists the files and folders in the current directory. You can use the `-l` option to see more details, such as the size, permissions, and modification date of each file or folder. You can also use the `-a` option to see hidden files and folders, which start with a dot (.).
  - `cd`: This command changes the current directory to the one specified. You can use `..` to go up one level, or `~` to go to your home directory. You can also use the absolute path, which starts with a slash (/), or the relative path, which is relative to the current directory.
  - `touch`: This command creates a new, empty file with the name specified. You can also use it to update the modification date of an existing file.
  - `mv`: This command moves or renames a file or folder. You need to specify the source and the destination. If the destination is a folder, the file or folder will be moved into it. If the destination is a file, the source will be renamed to it. You can use the `-i` option to prompt before overwriting an existing file.
  - `rm`: This command removes a file or folder. You need to specify the name of the file or folder to be removed. You can use the `-r` option to remove a folder and all its contents recursively. You can use the `-i` option to prompt before removing each file or folder.
  - `man`: This command shows the manual page for a command or a topic. You can use the space bar to scroll down, the b key to scroll up, or the q key to quit. You can also use the slash (/) to search for a keyword, or the n key to go to the next occurrence of the keyword.

- To exit the command terminal window, you can either type `exit` and press Enter, or click on the X button on the top right corner.
