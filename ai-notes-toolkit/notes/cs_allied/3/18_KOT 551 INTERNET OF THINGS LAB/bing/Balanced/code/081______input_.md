#### Input

Input is the process of providing data or instructions to a computer system so that it can perform a task or operation. Input is important because it allows users to interact with a computer system and provide information that can be processed and analyzed .

Some of the main points to learn about input are:

- Input can be given in different forms, such as text, images, sound, or gestures.
- Input can be given through different devices, such as keyboard, mouse, touch screen, microphone, scanner, or virtual reality device .
- Input can be given in different formats, such as binary, ASCII, Unicode, or XML.
- Input can be validated, filtered, or transformed before being processed by the computer system.
- Input can be stored, retrieved, or transmitted by the computer system using memory, disk, or network.
