#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, etc.
- Cloud and server are two types of computing platforms that can store, process, and analyze sensor data remotely over the internet.
- Cloud is a network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer that hosts applications and data for a specific purpose or domain.
- To upload sensor data to cloud or server, the sensor device needs to have a network connection such as Wi-Fi, Ethernet, cellular, satellite, etc. and a protocol such as HTTP, MQTT, CoAP, etc. to communicate with the cloud or server.
- To download sensor data from cloud or server, the sensor device or another device such as a laptop, smartphone, tablet, etc. needs to have a network connection and a protocol to request and receive the data from the cloud or server.
- Some examples of uploading and downloading sensor data on cloud and server are:

  - Using a Raspberry Pi and a DHT22 sensor to measure humidity and temperature and send the readings to ThingSpeak, a cloud platform for IoT data visualization and analysis.
  - Using a NodeMCU and a soil moisture sensor to measure the water level of a plant and send the readings to AWS DynamoDB, a cloud database service for storing and querying data.
  - Using a Defender for IoT sensor to monitor the network traffic and security of an industrial system and upload the data to Azure, a cloud platform for IoT solutions and services. The sensor can also download activation files and updates from Azure.
  - Using a satellite modem and a GPS sensor to track the location and movement of a vehicle and send the data to a cloud server. The data can be accessed and downloaded from a web application on any device.
