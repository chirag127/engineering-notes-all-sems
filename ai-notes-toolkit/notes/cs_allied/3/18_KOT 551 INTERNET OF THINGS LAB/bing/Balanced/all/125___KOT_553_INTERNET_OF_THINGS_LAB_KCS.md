# KOT 553 INTERNET OF THINGS LAB KCS

- This is a course offered by Dr. A.P.J. Abdul Kalam Technical University for the third year students of Computer Science and Engineering (IoT) branch.
- The course code is KOT 553 and the course name is Internet of Things Lab.
- The course aims to provide practical exposure to the students on the concepts, principles and challenges of Internet of Things (IoT).
- The course covers the following topics:

  - Introduction to IoT and its applications.
  - Hardware devices and sensors used for IoT.
  - Communication protocols and standards for IoT.
  - Cloud computing and data analytics for IoT.
  - Security and privacy issues in IoT.

- The course has a total of 50 marks, out of which 30 marks are for internal assessment and 20 marks are for external examination.
- The internal assessment consists of 10 marks for attendance, 10 marks for lab performance and 10 marks for lab record.
- The external examination consists of a practical exam of 20 marks, in which the students have to perform one experiment from the prescribed list of experiments and answer viva questions.
- The list of experiments for the course are:

  - Experiment 1: Setting up an IoT device using Arduino/Raspberry Pi and interfacing with sensors and actuators.
  - Experiment 2: Programming an IoT device using Python/C/C++ and sending/receiving data to/from a cloud platform.
  - Experiment 3: Implementing a communication protocol for IoT using MQTT/CoAP/HTTP.
  - Experiment 4: Analyzing IoT data using Python libraries and tools such as NumPy, Pandas, Matplotlib, etc.
  - Experiment 5: Implementing a security mechanism for IoT using encryption/decryption, authentication, authorization, etc.

- The course requires the students to have basic knowledge of programming, electronics, networking and data structures.
- The course also requires the students to have access to the following hardware and software resources:

  - Hardware: Arduino/Raspberry Pi, sensors (temperature, humidity, light, etc.), actuators (LED, buzzer, etc.), breadboard, jumper wires, etc.
  - Software: Arduino IDE/Python IDE, MQTT/CoAP/HTTP client and broker, cloud platform (AWS, Google Cloud, etc.), data analysis tools (Jupyter Notebook, Anaconda, etc.), security tools (OpenSSL, PyCrypto, etc.).
