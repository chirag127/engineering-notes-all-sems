#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small computer that runs on Linux, a free and open source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a pre-installed operating system image into the slot on the board.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) with icons and menus. You can use the mouse and keyboard to interact with the GUI, or you can switch to a command terminal window by pressing Ctrl+Alt+T on the keyboard.
- A command terminal window is a text-based interface that allows you to enter commands and see the output. Commands are instructions that tell the computer what to do. You can use commands to perform various tasks, such as navigating the file system, creating and deleting files, and getting help.
- Here are some common Linux commands that you can try in the command terminal window:

  - `ls`: This command lists the files and directories in the current working directory. A directory is a folder that contains files and other directories. The current working directory is the location where you are currently working. You can use the `ls` command with various options to change the output, such as `-l` for a long listing, `-a` for showing hidden files, and `-h` for human-readable sizes. For example, `ls -lah` will list all the files and directories in the current working directory, along with their permissions, owners, sizes, and modification dates.
  - `cd`: This command changes the current working directory to the one specified. You can use the `cd` command with an absolute path or a relative path. An absolute path starts with a slash (`/`) and specifies the exact location of a directory from the root of the file system. A relative path starts with a dot (`.`) or a dot-dot (`..`) and specifies the location of a directory relative to the current working directory. For example, `cd /home/pi` will change the current working directory to the home directory of the user pi, while `cd ..` will move up one level in the file system hierarchy.
  - `touch`: This command creates a new empty file with the name specified. You can use the `touch` command with one or more file names as arguments. For example, `touch hello.txt` will create a new file called hello.txt in the current working directory. You can also use the `touch` command to update the modification time of an existing file, without changing its content.
  - `mv`: This command moves or renames a file or directory. You can use the `mv` command with two arguments: the source and the destination. The source is the file or directory that you want to move or rename, and the destination is the new location or name for the file or directory. For example, `mv hello.txt goodbye.txt` will rename the file hello.txt to goodbye.txt, while `mv hello.txt /home/pi/Documents` will move the file hello.txt to the Documents directory under the home directory of the user pi.
  - `rm`: This command removes or deletes a file or directory. You can use the `rm` command with one or more file or directory names as arguments. For example, `rm hello.txt` will delete the file hello.txt from the current working directory. You can also use the `rm` command with the `-r` option to recursively delete a directory and all its contents. For example, `rm -r Documents` will delete the Documents directory and everything inside it. Be careful when using the `rm` command, as there is no undo option for deleting files or directories.
  - `man`: This command displays the manual page for a command or a topic. A manual page is a document that explains the usage, syntax, options, and examples of a command or a topic. You can use the `man` command with the name of a command or a topic as an argument. For example, `man ls` will show the manual page for the `ls` command, while `man intro` will show the introduction to Linux commands. You can use the arrow keys, the Page Up and Page Down keys, or the space bar to scroll through the manual page. You can also use the slash (`/`) key to search for a keyword in the manual page. To exit the manual page, press the Q key.
