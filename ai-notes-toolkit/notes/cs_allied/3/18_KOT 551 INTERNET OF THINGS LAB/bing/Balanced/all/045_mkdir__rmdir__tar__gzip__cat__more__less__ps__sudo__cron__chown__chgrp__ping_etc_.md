# Linux Commands

Linux commands are instructions that can be executed in a terminal or a shell to perform various tasks. Some of the common Linux commands are:

- **mkdir**: This command creates one or more directories. The syntax is `mkdir [options] [directory names]`. For example, `mkdir newDir` creates a directory called newDir. To create multiple directories at once, we can use `mkdir newDir1 newDir2 newDir3`. To create a directory with a specific permission, we can use the `-m` option, such as `mkdir -m 755 newDir4`. To create a directory and its parent directories if they do not exist, we can use the `-p` option, such as `mkdir -p newDir5/newDir6/newDir7`. To print a message for each created directory, we can use the `-v` option, such as `mkdir -v newDir8` .

- **rmdir**: This command removes one or more empty directories. The syntax is `rmdir [options] [directory names]`. For example, `rmdir newDir` removes the directory called newDir if it is empty. To remove multiple directories at once, we can use `rmdir newDir1 newDir2 newDir3`. To remove a directory and its parent directories if they are empty, we can use the `-p` option, such as `rmdir -p newDir5/newDir6/newDir7`. To print a message for each removed directory, we can use the `-v` option, such as `rmdir -v newDir8`.

- **tar**: This command creates or extracts compressed archive files. The syntax is `tar [options] [archive file] [files or directories]`. For example, `tar -cvf archive.tar file1 file2 dir1` creates a tar archive file called archive.tar that contains file1, file2 and dir1. The options `-c`, `-v` and `-f` mean create, verbose and file, respectively. To extract a tar archive file, we can use the `-x` option, such as `tar -xvf archive.tar`. To create a compressed archive file using gzip or bzip2, we can use the `-z` or `-j` option, respectively, such as `tar -cvzf archive.tar.gz file1 file2 dir1` or `tar -cvjf archive.tar.bz2 file1 file2 dir1`.

- **gzip**: This command compresses or decompresses files using the gzip algorithm. The syntax is `gzip [options] [files]`. For example, `gzip file1` compresses file1 and renames it to file1.gz. To decompress a file, we can use the `-d` option, such as `gzip -d file1.gz`. To keep the original file after compression or decompression, we can use the `-k` option, such as `gzip -k file1` or `gzip -dk file1.gz`. To compress or decompress multiple files at once, we can use `gzip file1 file2 file3` or `gzip -d file1.gz file2.gz file3.gz`.

- **cat**: This command concatenates and displays files. The syntax is `cat [options] [files]`. For example, `cat file1` displays the content of file1. To display multiple files, we can use `cat file1 file2 file3`. To create a new file with the content of another file, we can use `cat file1 > file2`. To append the content of one file to another file, we can use `cat file1 >> file2`. To display the line numbers of a file, we can use the `-n` option, such as `cat -n file1`.

- **more**: This command displays the content of a file one screen at a time. The syntax is `more [options] [file]`. For example, `more file1` displays the content of file1 and pauses at the end of each screen. To move to the next screen, we can press the spacebar. To move to the next line, we can press the enter key. To quit, we can press the q key. To search for a pattern in the file, we can press the / key and enter the pattern. To display the percentage of the file shown, we can use the `-d` option, such as `more -d file1`
