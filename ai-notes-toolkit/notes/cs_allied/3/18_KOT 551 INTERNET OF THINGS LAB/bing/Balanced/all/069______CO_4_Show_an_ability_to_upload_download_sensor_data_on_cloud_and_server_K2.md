#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server are two types of platforms that can store and process sensor data remotely over the internet.
- Cloud is a network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer that hosts a specific application or service such as a web server, a database server, etc.
- To upload sensor data to cloud or server, the following steps are usually required:
  - Connect the sensor to a device that can communicate with the internet, such as a microcontroller, a computer, a smartphone, etc.
  - Configure the device to send the sensor data to a specific cloud or server address, such as a URL, an IP address, a port number, etc.
  - Choose a protocol or a method for sending the sensor data, such as HTTP, MQTT, CoAP, etc.
  - Choose a format or a structure for the sensor data, such as JSON, XML, CSV, etc.
  - Choose a frequency or a trigger for sending the sensor data, such as every second, every minute, every hour, etc.
  - Choose a security or an encryption mechanism for protecting the sensor data, such as SSL, TLS, AES, etc.
- To download sensor data from cloud or server, the following steps are usually required:
  - Connect to the internet using a device that can receive and process the sensor data, such as a computer, a smartphone, a tablet, etc.
  - Access the cloud or server address where the sensor data is stored, such as a URL, an IP address, a port number, etc.
  - Choose a protocol or a method for receiving the sensor data, such as HTTP, MQTT, CoAP, etc.
  - Choose a format or a structure for the sensor data, such as JSON, XML, CSV, etc.
  - Choose a frequency or a trigger for receiving the sensor data, such as every second, every minute, every hour, etc.
  - Choose a security or an encryption mechanism for protecting the sensor data, such as SSL, TLS, AES, etc.
- Some examples of cloud and server platforms that can be used for uploading and downloading sensor data are:
  - Microsoft Azure: A cloud platform that provides various services for IoT applications, such as IoT Hub, IoT Central, Stream Analytics, etc.
  - AWS IoT: A cloud platform that provides various services for IoT applications, such as IoT Core, IoT Analytics, IoT Device Management, etc.
  - ThingSpeak: A cloud platform that provides a simple way to store and visualize sensor data using channels, fields, and charts.
  - Raspberry Pi: A single-board computer that can act as a server for hosting web applications or databases that can store and display sensor data.
