### Should be able to use control web camera, network, and relays connected to the Pi

1. **Web Camera Control**: The Raspberry Pi can be used to control a web camera connected to it. This can be done using various libraries and tools available for the Raspberry Pi, such as `fswebcam` or `motion`.
2. **Network Control**: The Raspberry Pi can also be used to control and monitor the network it is connected to. This can be done using various networking tools and libraries available for the Raspberry Pi, such as `nmap` or `tcpdump`.
3. **Relay Control**: The Raspberry Pi can be used to control relays connected to it. This can be done using the GPIO pins on the Raspberry Pi and various libraries and tools available for the Raspberry Pi, such as `RPi.GPIO` or `wiringPi`.
