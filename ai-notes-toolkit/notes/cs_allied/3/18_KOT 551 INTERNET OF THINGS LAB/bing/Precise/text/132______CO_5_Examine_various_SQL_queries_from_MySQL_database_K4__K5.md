#### CO 5 Examine various SQL queries from MySQL database K4, K5

- SQL (Structured Query Language) is a standard language for managing and querying relational databases.
- MySQL is an open-source relational database management system that uses SQL.
- SQL queries are used to perform various tasks, such as retrieving, inserting, updating, and deleting data from a database.
- Some common SQL queries used in MySQL include:
  - SELECT: used to retrieve data from one or more tables.
  - INSERT: used to add new records to a table.
  - UPDATE: used to modify existing records in a table.
  - DELETE: used to remove records from a table.
  - CREATE: used to create new tables, views, or indexes.
  - ALTER: used to modify the structure of an existing table.
  - DROP: used to delete tables, views, or indexes.
- These queries can be combined with various clauses and operators to perform more complex tasks and retrieve specific data from the database.
- It is important to carefully construct and test SQL queries to ensure that they return the desired results and do not inadvertently modify or delete data.
