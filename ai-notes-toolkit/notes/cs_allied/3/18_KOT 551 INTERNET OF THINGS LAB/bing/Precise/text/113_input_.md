# Input

- Input refers to the data or information that is entered into a computer system for processing.
- Input devices are used to enter data into a computer. Examples of input devices include a keyboard, mouse, microphone, and scanner.
- Input can also come from other sources, such as a network connection or a storage device.
- The input data is processed by the computer's central processing unit (CPU) and then stored in memory or on a storage device.
- Input is an essential part of any computer system, as it allows users to interact with the computer and provide it with the data it needs to perform tasks.
