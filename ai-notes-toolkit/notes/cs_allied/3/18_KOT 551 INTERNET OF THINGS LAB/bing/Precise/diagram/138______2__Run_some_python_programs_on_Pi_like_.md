#### 2. Run some python programs on Pi like:

- **Blinking an LED:** You can write a simple python program to control the GPIO pins on the Raspberry Pi and make an LED blink.
- **Reading sensor data:** You can connect sensors like temperature, humidity, or motion sensors to the Raspberry Pi and write a python program to read the data from these sensors.
- **Controlling a servo motor:** You can write a python program to control the position of a servo motor connected to the Raspberry Pi.
- **Creating a simple game:** You can use python libraries like Pygame to create simple games that can be played on the Raspberry Pi.
- **Building a web server:** You can use python libraries like Flask or Django to build a simple web server that can run on the Raspberry Pi.
