# b) Read two numbers and print their sum, difference, product and division.

1. To read two numbers, you can use the `input()` function in Python. This function reads a line from input, converts it to a string, and returns it.
2. You can then convert the input strings to integers using the `int()` function.
3. To calculate the sum of the two numbers, you can use the `+` operator.
4. To calculate the difference between the two numbers, you can use the `-` operator.
5. To calculate the product of the two numbers, you can use the `*` operator.
6. To calculate the division of the two numbers, you can use the `/` operator.
7. Finally, you can use the `print()` function to display the results.

Here is an example code that implements the above steps:

```python
# Read two numbers
num1 = int(input("Enter the first number: "))
num2 = int(input("Enter the second number: "))

# Calculate the sum, difference, product, and division
sum = num1 + num2
difference = num1 - num2
product = num1 * num2
division = num1 / num2

# Print the results
print("Sum:", sum)
print("Difference:", difference)
print("Product:", product)
print("Division:", division)
```

This code reads two numbers from the user, calculates their sum, difference, product, and division, and then prints the results. You can run this code and enter two numbers to see the results.
