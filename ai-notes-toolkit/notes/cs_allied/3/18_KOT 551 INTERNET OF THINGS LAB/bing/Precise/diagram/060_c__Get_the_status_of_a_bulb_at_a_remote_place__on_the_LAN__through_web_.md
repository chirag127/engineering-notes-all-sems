# Get the status of a bulb at a remote place (on the LAN) through web

To get the status of a bulb at a remote place on the LAN through the web, the following steps can be taken:

1. **Connect the bulb to the network**: The bulb must be connected to the local area network (LAN) and have an IP address assigned to it. This can be done by connecting the bulb to a smart home hub or directly to the router.

2. **Set up a web server**: A web server must be set up on the network to communicate with the bulb. This can be done using a computer or a dedicated device such as a Raspberry Pi.

3. **Create a web page**: A web page must be created to display the status of the bulb. This can be done using HTML, CSS, and JavaScript.

4. **Send a request to the bulb**: The web page must send a request to the bulb to get its status. This can be done using a protocol such as HTTP or MQTT.

5. **Display the status of the bulb**: The web page must display the status of the bulb based on the response received from the bulb.

By following these steps, the status of a bulb at a remote place on the LAN can be obtained through the web.
