# Starting Raspberry Pi and trying various Linux commands in the command terminal window

1. **ls**: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
2. **cd**: This command is used to change the current directory. For example, `cd Documents` would change the current directory to the Documents directory.
3. **touch**: This command is used to create a new, empty file. For example, `touch newfile.txt` would create a new file called `newfile.txt` in the current directory.
4. **mv**: This command is used to move or rename files or directories. For example, `mv oldfile.txt newfile.txt` would rename `oldfile.txt` to `newfile.txt`.
5. **rm**: This command is used to remove files or directories. For example, `rm file.txt` would remove the file `file.txt` from the current directory.
6. **man**: This command is used to display the manual page for a command. For example, `man ls` would display the manual page for the `ls` command.

These are some basic Linux commands that can be used in the command terminal window of a Raspberry Pi. It is important to familiarize oneself with these commands in order to effectively navigate and manipulate the file system on a Raspberry Pi.
