#### a) Read your name and print Hello message with name

1. To read your name, you can use the `input()` function in Python. This function prompts the user to enter a value and returns the value entered by the user as a string.
2. You can store the value returned by the `input()` function in a variable. For example, you can store the user's name in a variable called `name` like this: `name = input("Enter your name: ")`.
3. Once you have the user's name stored in a variable, you can use the `print()` function to print a message that includes the user's name. For example, you can print a hello message like this: `print("Hello, " + name + "!")`.

Here is an example program that reads the user's name and prints a hello message with the name:

```python
name = input("Enter your name: ")
print("Hello, " + name + "!")
```

When you run this program, it will prompt you to enter your name. After you enter your name and press enter, the program will print a hello message that includes your name. For example, if you enter "John" as your name, the program will print "Hello, John!".
