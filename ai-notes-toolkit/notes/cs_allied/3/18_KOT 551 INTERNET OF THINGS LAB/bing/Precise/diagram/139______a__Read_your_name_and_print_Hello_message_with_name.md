#### a) Read your name and print Hello message with name

To read your name and print a Hello message with your name, you can follow these steps:

1. Declare a variable to store your name. For example, in Python, you can use the `input()` function to read the user's name and store it in a variable:
```python
name = input("Enter your name: ")
```
2. Use the stored name to print a Hello message. For example, in Python, you can use the `print()` function to display the message:
```python
print("Hello, " + name + "!")
```

This will read the user's name and print a Hello message with the entered name. For example, if the user enters "John" as their name, the output will be:
```
Hello, John!
```
