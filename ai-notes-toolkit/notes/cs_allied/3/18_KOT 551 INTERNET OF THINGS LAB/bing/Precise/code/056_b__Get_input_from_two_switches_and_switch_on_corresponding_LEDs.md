# Get input from two switches and switch on corresponding LEDs

To get input from two switches and switch on corresponding LEDs, follow these steps:

1. Connect the two switches to the input pins of the microcontroller.
2. Connect the two LEDs to the output pins of the microcontroller.
3. Write a program to read the input from the switches.
4. In the program, use conditional statements to check the state of the switches.
5. If a switch is pressed, turn on the corresponding LED by setting the output pin to high.
6. If a switch is not pressed, turn off the corresponding LED by setting the output pin to low.
7. Upload the program to the microcontroller and run it.
8. Test the circuit by pressing the switches and observing the behavior of the LEDs.

This is a basic example of how to get input from two switches and switch on corresponding LEDs. The specific details may vary depending on the microcontroller and other components used. It is important to consult the datasheets and documentation for the specific components to ensure proper operation.
