# b) Read two numbers and print their sum, difference, product and division.

1. To read two numbers, you can use the input function in Python. For example:
```python
num1 = int(input("Enter the first number: "))
num2 = int(input("Enter the second number: "))
```
2. To print the sum of the two numbers, you can use the `+` operator. For example:
```python
sum = num1 + num2
print("The sum of the two numbers is:", sum)
```
3. To print the difference of the two numbers, you can use the `-` operator. For example:
```python
difference = num1 - num2
print("The difference of the two numbers is:", difference)
```
4. To print the product of the two numbers, you can use the `*` operator. For example:
```python
product = num1 * num2
print("The product of the two numbers is:", product)
```
5. To print the division of the two numbers, you can use the `/` operator. For example:
```python
division = num1 / num2
print("The division of the two numbers is:", division)
```
