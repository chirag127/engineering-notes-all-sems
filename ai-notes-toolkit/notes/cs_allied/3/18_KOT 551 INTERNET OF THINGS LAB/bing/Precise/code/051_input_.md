# Input

Input refers to the data or information that is entered into a computer system for processing. It can come from various sources, such as a keyboard, mouse, microphone, scanner, or other input devices. Here are some key points to remember about input:

1. Input devices are used to enter data into a computer system.
2. Common input devices include keyboards, mice, touchscreens, and microphones.
3. Input can also come from external sources, such as a file or a network connection.
4. The quality of the input data can affect the accuracy of the output.
5. Input data must be in a format that the computer can understand and process.
6. Input can be either manual or automatic.
7. Manual input involves a user entering data directly into the computer, while automatic input involves the computer receiving data from an external source without human intervention.
