#### a) Read your name and print Hello message with name

To read your name and print a Hello message with your name, you can follow these steps:

1. Declare a variable to store your name. For example, in Python, you can use the `input()` function to read your name from the standard input and store it in a variable called `name`:
```python
name = input("Enter your name: ")
```
2. Use the `print()` function to print the Hello message with your name. You can use string concatenation or string formatting to include your name in the message. For example:
```python
print("Hello, " + name + "!")
```
or
```python
print(f"Hello, {name}!")
```

This will read your name from the standard input and print a Hello message with your name. For example, if you enter `John` as your name, the output will be `Hello, John!`.
