# Read your name and print Hello message with name

1. To read your name, you can use the `input()` function in Python. This function prompts the user to enter some text and returns the text entered by the user as a string.
2. To print the Hello message with the name, you can use the `print()` function in Python. This function outputs the text passed to it as an argument to the console.
3. You can combine the `input()` and `print()` functions to read the user's name and print the Hello message with the name.

Here is an example code that demonstrates how to read the user's name and print the Hello message with the name:

```python
name = input("Enter your name: ")
print("Hello, " + name + "!")
```

In this code, the `input()` function prompts the user to enter their name. The entered name is then stored in the `name` variable. The `print()` function is then used to output the Hello message with the name to the console.

When you run this code, it will prompt you to enter your name. After you enter your name and press Enter, it will print the Hello message with your name. For example, if you enter "John" as your name, the output will be "Hello, John!".
