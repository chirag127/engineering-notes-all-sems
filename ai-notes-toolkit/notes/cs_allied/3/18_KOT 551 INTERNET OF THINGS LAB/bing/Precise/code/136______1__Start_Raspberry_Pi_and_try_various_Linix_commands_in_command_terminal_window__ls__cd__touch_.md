#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- **ls**: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
- **cd**: This command is used to change the current directory. It is used in conjunction with a directory path to navigate to a specific directory.
- **touch**: This command is used to create a new, empty file. It can also be used to update the timestamps on an existing file.
- **mv**: This command is used to move or rename files and directories. It takes two arguments: the source file or directory, and the destination.
- **rm**: This command is used to remove files and directories. It can be used with the `-r` flag to remove directories and their contents recursively.
- **man**: This command is used to display the manual page for a given command. It provides detailed information on how to use the command and its various options.

These are some basic Linux commands that can be used in the command terminal window of a Raspberry Pi. It is recommended to try these commands and experiment with their various options to become familiar with the Linux command line.
