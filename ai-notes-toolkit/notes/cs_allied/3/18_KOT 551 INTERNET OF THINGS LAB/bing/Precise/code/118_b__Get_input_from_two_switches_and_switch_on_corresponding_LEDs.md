# Get input from two switches and switch on corresponding LEDs

To get input from two switches and switch on corresponding LEDs, you can follow these steps:

1. Connect the two switches to the input pins of a microcontroller, such as an Arduino or Raspberry Pi.
2. Connect the two LEDs to the output pins of the microcontroller.
3. Write a program for the microcontroller that reads the state of the switches and turns on the corresponding LED when the switch is pressed.
4. Upload the program to the microcontroller and run it.

When the program is running, pressing one of the switches will turn on the corresponding LED. This can be used to create a simple interactive system where the user can control the state of the LEDs using the switches.
