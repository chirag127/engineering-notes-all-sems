# CO 5 Examine various SQL queries from MySQL database K4, K5

- SQL (Structured Query Language) is a standard language for managing and querying relational databases.
- MySQL is an open-source relational database management system that uses SQL.
- Some common SQL queries used in MySQL include:
  - SELECT: used to retrieve data from a database table.
  - INSERT: used to add new records to a database table.
  - UPDATE: used to modify existing records in a database table.
  - DELETE: used to remove records from a database table.
  - CREATE: used to create new database objects such as tables, views, and indexes.
  - ALTER: used to modify the structure of existing database objects.
  - DROP: used to delete database objects.
- These queries can be used in various combinations and with various clauses and conditions to perform complex database operations.
- It is important to carefully examine and test SQL queries to ensure that they produce the desired results and do not have unintended consequences.
