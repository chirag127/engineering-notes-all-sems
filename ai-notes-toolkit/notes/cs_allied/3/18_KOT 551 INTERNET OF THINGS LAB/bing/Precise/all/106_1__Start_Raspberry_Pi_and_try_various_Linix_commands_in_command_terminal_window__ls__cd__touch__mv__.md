# Starting Raspberry Pi and trying various Linux commands in the command terminal window

1. **Starting Raspberry Pi**: To start the Raspberry Pi, connect the power supply to the micro USB port on the board. The device should boot up and display the desktop or command line interface.

2. **Using the command terminal window**: To access the command terminal window, click on the terminal icon on the desktop or use the keyboard shortcut `Ctrl + Alt + T`.

3. **Linux commands**:
    - `ls`: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
    - `cd`: This command is used to change the current directory. For example, `cd Documents` would change the current directory to the `Documents` directory.
    - `touch`: This command is used to create a new, empty file. For example, `touch newfile.txt` would create a new file named `newfile.txt` in the current directory.
    - `mv`: This command is used to move or rename files or directories. For example, `mv oldfile.txt newfile.txt` would rename the file `oldfile.txt` to `newfile.txt`.
    - `rm`: This command is used to remove files or directories. For example, `rm file.txt` would remove the file `file.txt` from the current directory.
    - `man`: This command is used to display the manual page for a command. For example, `man ls` would display the manual page for the `ls` command.

These are some basic Linux commands that can be used in the command terminal window on a Raspberry Pi. It is recommended to refer to the manual pages for more detailed information on each command.
