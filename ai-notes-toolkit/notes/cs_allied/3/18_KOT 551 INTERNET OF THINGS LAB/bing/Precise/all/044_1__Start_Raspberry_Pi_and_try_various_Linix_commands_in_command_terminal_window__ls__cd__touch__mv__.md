# Starting Raspberry Pi and trying various Linux commands in the command terminal window

1. **Starting Raspberry Pi**: To start Raspberry Pi, connect it to a power source and a display. Once it boots up, you should see the desktop or command line interface, depending on the configuration.

2. **Linux commands**: Linux commands are used to perform various tasks on the operating system. Here are some commonly used commands:

    - `ls`: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
    - `cd`: This command is used to change the current directory. For example, `cd Documents` will change the current directory to the `Documents` directory.
    - `touch`: This command is used to create an empty file. For example, `touch newfile.txt` will create an empty file named `newfile.txt`.
    - `mv`: This command is used to move or rename files or directories. For example, `mv oldfile.txt newfile.txt` will rename `oldfile.txt` to `newfile.txt`.
    - `rm`: This command is used to remove files or directories. For example, `rm file.txt` will remove the file named `file.txt`.
    - `man`: This command is used to display the manual page for a command. For example, `man ls` will display the manual page for the `ls` command.

These are just a few of the many Linux commands available. You can learn more about them by using the `man` command or by searching online.
