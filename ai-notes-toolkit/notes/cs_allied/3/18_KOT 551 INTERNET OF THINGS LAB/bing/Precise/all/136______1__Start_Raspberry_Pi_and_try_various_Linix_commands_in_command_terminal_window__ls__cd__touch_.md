#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

To start using your Raspberry Pi, you will need to connect it to a power source and a display. Once it is powered on, you can access the command terminal window to try various Linux commands.

Here are some basic Linux commands that you can try in the command terminal window:

- `ls`: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
- `cd`: This command is used to change the current directory. You can use it to navigate through the file system.
- `touch`: This command is used to create a new, empty file. You can specify the name of the file you want to create as an argument.
- `mv`: This command is used to move or rename files or directories. You can specify the source and destination as arguments.
- `rm`: This command is used to remove files or directories. You can specify the file or directory you want to remove as an argument.
- `man`: This command is used to display the manual page for a command. You can specify the command you want to learn more about as an argument.

These are just a few of the many Linux commands that you can try on your Raspberry Pi. You can use the `man` command to learn more about each command and its usage.
