#### c) Get the status of a bulb at a remote place (on the LAN) through web.

To get the status of a bulb at a remote place on the LAN through the web, the following steps can be followed:

1. **Connect to the LAN:** Ensure that the device being used to check the status of the bulb is connected to the same LAN as the bulb.

2. **Access the bulb's web interface:** The bulb should have a web interface that can be accessed through a web browser. Enter the IP address of the bulb in the web browser to access its web interface.

3. **Check the bulb's status:** The bulb's web interface should display its current status, whether it is on or off. If the bulb's status is not displayed, there may be an option to request the status.

4. **Troubleshooting:** If the bulb's status cannot be determined, ensure that the bulb is properly connected to the LAN and that its web interface is functioning correctly. If the issue persists, contact the manufacturer for support.
