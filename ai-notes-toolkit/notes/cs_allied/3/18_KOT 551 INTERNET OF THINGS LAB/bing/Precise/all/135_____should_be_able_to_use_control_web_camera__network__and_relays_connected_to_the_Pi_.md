# Control Web Camera, Network, and Relays Connected to the Pi

- The Raspberry Pi is a versatile single-board computer that can be used for a variety of purposes, including controlling a web camera, network, and relays.
- To control a web camera connected to the Pi, you can use the `fswebcam` command to capture images or the `motion` package to stream video.
- To control the network on the Pi, you can use the `ifconfig` command to configure the network interface or the `iwconfig` command to configure wireless networking.
- To control relays connected to the Pi, you can use the `gpio` command to control the GPIO pins on the Pi, which can be used to turn the relays on and off.
- By combining these commands and packages, you can create a powerful system for controlling a web camera, network, and relays connected to the Pi.
