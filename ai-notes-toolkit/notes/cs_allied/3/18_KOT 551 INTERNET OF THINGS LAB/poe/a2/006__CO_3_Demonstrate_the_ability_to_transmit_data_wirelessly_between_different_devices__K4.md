#### CO 3 Demonstrate the ability to transmit data wirelessly between different devices. K4

- Wireless transmission of data between devices is done using wireless communication technologies like Wi-Fi, Bluetooth, NFC, etc.
- Wi-Fi is used to create wireless local area networks allowing devices to access the internet and also communicate with each other wirelessly. Data is transmitted using radio waves with a frequency of 2.4 GHz or 5 GHz.
- Bluetooth is a wireless technology standard that allows nearby devices to establish short-range wireless connections. It is mainly used to connect peripherals like headphones, speakers, keyboards, etc to devices. Data is transmitted using radio waves with a frequency of 2.4 GHz.
- Near Field Communication or NFC allows devices brought in close proximity to establish wireless communication. It is a set of contactless communication protocols used for smartphones, credit cards, electronic toll collection systems, etc. to transfer data over a distance of 4 cm.
- To transmit data wirelessly between two devices, they must support a common wireless technology and must be paired or connected to each other using the technology. The devices must be within the range of the wireless technology and should not have any physical obstructions between them to enable effective data transmission.
- Some use cases of wireless data transmission between devices are connecting wireless speakers to a phone, connecting a wireless keyboard/mouse to a laptop, file transfer between two phones, etc.
