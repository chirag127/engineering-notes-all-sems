### Controlling a Raspberry Pi's peripherals

1. Web Camera
- Connect a web camera to the Raspberry Pi.
- Write Python code to access the camera and control its parameters like brightness, contrast, etc.
- Capture and store images from the camera.
- Stream live video from the camera.

2. Network
- Control the WiFi adapter to connect to a network and access the internet.
- Control the Ethernet adapter.
- Scan for available WiFi networks.
- Detect network status changes.

3. Relays
- Connect relays to the Raspberry Pi GPIO pins.
- Write code to control the relays - turn on and off.
- Read the status of the relay - whether it is on or off.

The Raspberry Pi can be programmed to control and access its peripherals like web camera, network adapters and relays. Appropriate Python libraries can be used to write code to handle each peripheral and control various aspects of them. With programming, the Raspberry Pi can be customized to build many hardware projects.
