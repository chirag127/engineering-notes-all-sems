# Area of Given Shapes

## Rectangle
- Length and breadth values are taken as input
- Area = Length x Breadth
- For example, if length = 10 inches and breadth = 5 inches, then area = 10 x 5 = 50 square inches

## Triangle
- Base and height values are taken as input
- Area = (Base x Height) / 2
- For example, if base = 6 inches and height = 8 inches, then area = (6 x 8) / 2 = 32 square inches

## Circle
- Radius value is taken as input
- Area = pi x Radius^2
- Where, pi = 3.14 (approximately)
- For example, if radius = 5 inches, then area = 3.14 x 5^2 = 78.5 square inches (approximately)
