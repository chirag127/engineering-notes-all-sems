# Start Raspberry Pi and try various Linux commands in command terminal window:

1. Connect the Raspberry Pi to a monitor and keyboard.
2. Power on the Raspberry Pi and wait for it to boot up.
3. Once booted, you will be presented with the command line interface or terminal.
4. To see the list of files and folders in the current directory, type `ls` and press Enter.
5. To change directory, type `cd directory_name` and press Enter. For example, `cd Documents` will change directory to Documents.
6. To create a new file, type `touch file_name.extension` and press Enter. For example, `touch output.txt` will create a file called output.txt.
7. To move or rename a file, type `mv existing_file_name new_file_name` and press Enter.
8. To remove or delete a file, type `rm file_name` and press Enter.
9. To read the manual for a command and understand its usage, type `man command_name` and press Enter. For example, `man ls` will show the manual for the ls command.
