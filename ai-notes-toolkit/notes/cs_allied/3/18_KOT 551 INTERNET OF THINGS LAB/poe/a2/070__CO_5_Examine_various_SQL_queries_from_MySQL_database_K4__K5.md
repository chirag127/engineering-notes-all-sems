#### CO 5 Examine various SQL queries from MySQL database K4, K5

1. SELECT - Used to fetch data from the database table which returns the data in the form of result table.
- Syntax: SELECT column1, column2, ... FROM table_name;

2. UPDATE - Used to update existing data within a table.
- Syntax: UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;

3. DELETE - Used to delete existing data from a table.
- Syntax: DELETE FROM table_name WHERE condition;

4. INSERT INTO - Used to insert new data into a table.
- Syntax: INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);

5. CREATE DATABASE - Used to create a new database.
- Syntax: CREATE DATABASE database_name;

6. ALTER DATABASE - Used to modify a database.
- Syntax: ALTER DATABASE database_name [OPTIONS];

7. CREATE TABLE - Used to create a new table in a database.
- Syntax:
   CREATE TABLE table_name (
      column1 datatype,
      column2 datatype,
      ...
   );

8. ALTER TABLE - Used to modify an existing table.
- Syntax: ALTER TABLE table_name [OPTIONS];

9. DROP DATABASE - Used to delete an existing database.
- Syntax: DROP DATABASE database_name;

10. DROP TABLE - Used to delete an existing table.
- Syntax: DROP TABLE table_name;
