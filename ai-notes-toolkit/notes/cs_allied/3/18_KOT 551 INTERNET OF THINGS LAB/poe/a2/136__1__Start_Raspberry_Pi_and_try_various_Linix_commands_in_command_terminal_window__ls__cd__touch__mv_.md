#### 1. Start Raspberry Pi and try various Linix commands in command terminal window:

1. Connect the Raspberry Pi to a display using HDMI cable and connect a keyboard and mouse.
2. Connect the power supply and turn on the Raspberry Pi.
3. After the boot process is complete, you will see the command prompt. This is where you can enter Linux commands.
4. Try the following basic Linux commands:

- ls: Lists all the files and directories in the current directory.
- cd: Changes the directory. For example, cd desktop will change the directory to desktop.
- touch: Creates a new empty file. For example, touch test.txt will create a file named test.txt.
- mv: Moves a file or renames a file. For example, mv test.txt demo.txt will rename the test.txt file to demo.txt.
- rm: Removes a file. For example, rm demo.txt will remove the demo.txt file.
- man: Shows the manual for a command. For example, man ls will show the manual for the ls command.

5. Keep practicing various Linux commands to get familiar with the capabilities and uses of each command. With practice, you can master the basic Linux commands.
