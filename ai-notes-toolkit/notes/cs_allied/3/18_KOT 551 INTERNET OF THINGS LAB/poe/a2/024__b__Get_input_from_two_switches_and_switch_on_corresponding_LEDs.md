#### b) Get input from two switches and switch on corresponding LEDs.

1. Connect two switches to the microcontroller. The switches can be connected to any two input pins of the microcontroller.
2. Connect two LEDs to the microcontroller. The LEDs can be connected to any two output pins of the microcontroller.
3. Write a program to continuously monitor the status of the two switches.
4. Whenever the first switch is pressed, the LED connected to the corresponding output pin should glow. Similarly, when the second switch is pressed, the LED connected to the other output pin should glow.
5. The LEDs should glow only when the corresponding switches are being pressed. Once the switch is released, the LED should turn off.

The program should detect the switch status and control the LEDs accordingly. Proper programming can be done to achieve the desired results. The switches can be normally open or normally closed based on the application. The programming can be done in any programming language as per the microcontroller in use.
