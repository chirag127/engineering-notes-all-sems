# Get input from two switches and switch on corresponding LEDs

1. Connect two switches SW1 and SW2 to the microcontroller. Also, connect two LEDs, LED1 and LED2 to the microcontroller.

2. Program the microcontroller to continuously check the status of the switches SW1 and SW2.

3. When SW1 is pressed, LED1 should glow. Similarly, when SW2 is pressed, LED2 should glow.

4. If both the switches are pressed together, both LED1 and LED2 should glow.

5. If none of the switches are pressed, both the LEDs should remain off.

This is how the microcontroller can get input from two switches and switch on the corresponding LEDs based on the switch input. The program should continuously check the switch status and control the LEDs accordingly.
