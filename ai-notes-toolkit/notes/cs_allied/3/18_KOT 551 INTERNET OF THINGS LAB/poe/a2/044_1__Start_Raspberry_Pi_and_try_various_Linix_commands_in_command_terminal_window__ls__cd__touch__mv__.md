# Start Raspberry Pi and try various Linux commands in command terminal window:

1.  Start the Raspberry Pi and open the command terminal window.
2.  Use the `ls` command to list the files and directories in the current location. For example, `ls /home/pi` will list the files and directories in the home directory of the Pi user.
3.  Use the `cd` command to change the directory. For example, `cd Documents` will change the directory to the Documents folder.
4.  Use the `touch` command to create a new empty file. For example, `touch test.txt` will create a new file called `test.txt`.
5.  Use the `mv` command to move a file or directory from one location to another. For example, `mv test.txt /home/pi/Documents` will move the `test.txt` file to the Documents folder.
6.  Use the `rm` command to remove a file. For example, `rm test.txt` will remove the `test.txt` file.
7.  Use the `man` command to read the manual of a command and learn about its usage. For example, `man ls` will display the manual for the `ls` command.

The above points cover the basic Linux commands to get started with the Raspberry Pi command line interface. Learn and practice these commands to get familiar with the Linux operating system.
