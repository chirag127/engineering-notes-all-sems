# Hello World Program

## Objective

a) Read your name and print Hello message with name

## Steps

1. Take input - Ask user to enter their name and store it in a variable called `name`
2. Print Hello message - Print `Hello` followed by the value stored in the `name` variable
3. Example - If user enters `John` as input, print `Hello John`

## Pseudocode

```
get input from user and store in variable name
print("Hello")
print(name)
```

## Sample Code

```python
name = input("Enter your name: ")
print("Hello", name)
```
