#### c) Word and character count of a given string.

I. Take the input string.
II. Initialize word count variable to 0 and character count variable to 0.
III. Loop over each character in the input string.
    1. If the current character is a letter, increment the word count.
    2. Increment the character count.
IV. Print the final word count and character count.

This program counts the number of words and characters in a given string. The word is counted whenever a letter is encountered in the string. The total character count is incremented for every character in the input string. At the end, both the word count and character count are displayed as the output.
