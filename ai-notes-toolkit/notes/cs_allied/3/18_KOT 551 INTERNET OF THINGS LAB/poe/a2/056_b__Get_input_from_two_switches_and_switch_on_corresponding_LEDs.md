# Get input from two switches and switch on corresponding LEDs

1. Take two switches as input
2. Connect the switches to a microcontroller like Arduino
3. Connect two LEDs to the microcontroller
4. Write a program to get the input from the two switches
5. If switch 1 is ON, turn ON LED 1
6. If switch 2 is ON, turn ON LED 2
7. If both switches are ON, turn ON both LEDs
8. If both switches are OFF, turn OFF both LEDs

The program should get the input from the two switches continuously and control the LEDs as per the switch conditions. This is a basic example to get inputs and control outputs based on the logic. The same concept can be extended to more number of inputs and outputs.
