#### Input

1. Input is the data or instructions entered into a computer system to get processed and generate output.
2. The input is collected using input devices such as keyboard, mouse, microphone, etc.
3. The input is then processed by the CPU using instructions from the software and programming.
4. The processed input is then sent to output devices such as display screens, speakers, etc. to generate output.
5. The input needs to be in a format that can be understood by the software and processed by the CPU. For example, data entered using the keyboard needs to be in alphanumeric format, voice input needs to be in the understandable language, images as pixels, etc.
6. The accuracy and quality of input determine the accuracy of the output. Therefore, it is important to enter the correct input to get the desired output.
7. Input is the first step in the process of computing. Without input, the CPU remains idle and no processing or output generation takes place.
