# CO 5 Examine various SQL queries from MySQL database K4, K5

## Topic 1: Basic SQL queries

1. SELECT - retrieves data from the database
2. UPDATE - updates data in the database
3. DELETE - deletes data from the database
4. INSERT INTO - inserts new data into the database

## Topic 2: Filtering and sorting

1. WHERE - filters records that fulfill a specified condition
2. ORDER BY - sorts the result-set in ascending or descending order

## Topic 3: Joins

1. INNER JOIN - returns records that have matching values in both tables
2. LEFT (OUTER) JOIN - returns all records from the left table, and the matched records from the right table
3. RIGHT (OUTER) JOIN - returns all records from the right table, and the matched records from the left table
4. FULL (OUTER) JOIN - returns all records when there is a match in either left or right table

## Topic 4: Grouping

1. GROUP BY - groups records into summary rows
2. HAVING - filters groups that match a specified condition

## Topic 5: Aggregate functions

1. COUNT - returns the number of records
2. SUM - returns the sum of a numeric column
3. AVG - returns the average of a numeric column
4. MIN - returns the minimum value of a column
5. MAX - returns the maximum value of a column
