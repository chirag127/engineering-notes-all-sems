 Here is the formal content on the given Linux commands in points:

mkdir:
- Used to create directories.
- Syntax: mkdir <directory name>
- Can create multiple directories at once.
- Options available: -p (create parent directories as needed), -m (set permission).

rmdir:
- Used to remove empty directories.
- Syntax: rmdir <directory name>
- Will throw an error if trying to remove a non-empty directory.

tar:
- Used to create and extract archive files (tar files).
- Syntax: tar <options> <file/directory name>
- Commonly used options: -c (create archive), -x (extract archive), -f ( specify archive file name), -v (verbose), -z (filter archive through gzip).
- Used to bundle multiple files/directories into a single archive file.

gzip:
- Used to compress and decompress files.
- Syntax: gzip <file name> (to compress), gunzip <file name> (to decompress)
- Compresses files using Lempel-Ziv coding (LZ77).
- Commonly used to compress tar files and reduce size.
