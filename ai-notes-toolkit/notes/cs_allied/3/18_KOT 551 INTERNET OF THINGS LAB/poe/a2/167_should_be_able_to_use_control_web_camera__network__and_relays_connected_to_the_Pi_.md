# Controlling Peripherals Connected to Raspberry Pi

1. Web Camera
- Connect the web camera to the Raspberry Pi
- Install the picamera library to access the camera
- Write Python script to access the camera and control its parameters like brightness, contrast, resolution, etc.
- Capture images or videos from the camera and save them to the Pi

2. Network
- Raspberry Pi has inbuilt Ethernet and Wi-Fi connectivity
- Use Python libraries like socket programming or requests library to send and receive data over the network
- Control other devices over the network by sending commands and data to them
- Host a web server on the Pi to access it over the network

3. Relays
- Connect relays to the GPIO pins of the Raspberry Pi
- Write Python script to control the relay ON and OFF
- Use relays to control high voltage devices from the Raspberry Pi
- Precaution: Use relay boards that can handle the required voltage and current of the device
