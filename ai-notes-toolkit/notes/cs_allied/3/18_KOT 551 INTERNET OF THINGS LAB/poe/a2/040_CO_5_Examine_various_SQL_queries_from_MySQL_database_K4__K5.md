# CO 5 Examine various SQL queries from MySQL database K4, K5

1. SELECT - retrieves data from the database table which matches the criteria specified

- `SELECT column1, column2, ... FROM table_name;` - retrieves all columns
- `SELECT * FROM table_name;` - retrieves specific columns
- `SELECT column1, column2, ... FROM table_name WHERE condition;` - retrieves data based on a specified condition

2. UPDATE - updates existing data within a table

- `UPDATE table_name SET column1 = value1, column2 = value2,... WHERE condition;`
- Updates multiple columns based on a specified condition

3. DELETE - deletes existing data from within a table

- `DELETE FROM table_name WHERE condition;` - deletes data from a table based on a specified condition

4. CREATE DATABASE - creates a new database

- `CREATE DATABASE database_name;`

5. CREATE TABLE - creates a new table within a database

- `CREATE TABLE table_name (column_name1 data_type, column_name2 data_type, ...);`
- Defines the name of the table and its column names along with the data type for each column
