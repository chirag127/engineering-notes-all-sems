#### mkdir, rmdir, tar, gzip, cat, more, less, ps, sudo, cron, chown, chgrp, ping etc.

- **mkdir:** Used to create directories or folders.
    - Syntax: mkdir [folder name]
    - Example: mkdir myfolder (creates a folder with name myfolder)
- **rmdir:** Used to remove directories or folders.
    - Syntax: rmdir [folder name]
    - Example: rmdir myfolder (removes the folder with name myfolder if empty)
- **tar:** Used to create and extract tar archives. Tar archives store multiple files in a single file.
    - Syntax: tar [options] [file/folder names]
- **gzip:** Used to compress and uncompress files. It uses lossless data compression algorithm.
    - Syntax: gzip [options] [file name] (compresses a file)
    - gunzip [file name].gz (uncompresses a gzipped file)
- **cat:** Used to display and concatenate contents of a file.
    - Syntax: cat [file name]
    - Example: cat sample.txt (displays the contents of sample.txt file)
- **more:** Used to display the contents of a file one page at a time.
    - Syntax: more [file name]
- **less:** Similar to more but allows scrolling backwards and forwards in the file.
    - Syntax: less [file name]
