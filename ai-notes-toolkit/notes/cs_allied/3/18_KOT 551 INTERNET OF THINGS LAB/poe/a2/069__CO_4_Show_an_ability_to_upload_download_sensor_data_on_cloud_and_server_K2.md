#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

1. Uploading sensor data to cloud
- Connect the sensors to the cloud platform like AWS, Azure or Google Cloud.
- Code to fetch the data from the sensors and upload it to the cloud storage.
- Choose an appropriate data format like CSV, JSON or XML to store the data.
- Schedule the data upload process to run periodically to keep the cloud data up-to-date.

2. Downloading sensor data from cloud
- Connect to the cloud platform and authenticate to access the stored data.
- Download the data from cloud storage to the local system.
- Parse the data and process it as required for analysis or display.
- The data can be downloaded on-demand or periodically based on the application requirements.

3. Managing sensor data on server
- Store the sensor data on a dedicated server instead of cloud.
- Design a database schema to organize the data efficiently.
- Implement necessary security and access control mechanisms.
- Schedule data processing and analytics jobs to extract insights from the data.
- The server can be on-premises or a rented cloud/virtual private server.
