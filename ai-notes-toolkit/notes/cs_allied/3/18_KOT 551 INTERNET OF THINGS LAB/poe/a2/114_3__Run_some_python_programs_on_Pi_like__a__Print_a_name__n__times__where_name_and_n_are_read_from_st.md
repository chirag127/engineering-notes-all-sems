### 3. Run some python programs on Pi like:

a) Print a name 'n' times, where name and n are read from standard input,

- Take input for name and n from standard input.
- Print the name n times using loop.
- For example:
  - Enter name: John
  - Enter n: 5
  - Output: John John John John John

- Python program:

  name = input("Enter name: ")
  n = int(input("Enter n: "))
  for i in range(n):
    print(name)

- This is a basic python program to demonstrate taking input and printing output n number of times.

- The input() function takes input from the user and stores it in a variable.
- The int() function converts the input to an integer.
- The for loop iterates n number of times and prints the name in each iteration.

- This program can be used to print any text n number of times by taking the text as input instead of name.
