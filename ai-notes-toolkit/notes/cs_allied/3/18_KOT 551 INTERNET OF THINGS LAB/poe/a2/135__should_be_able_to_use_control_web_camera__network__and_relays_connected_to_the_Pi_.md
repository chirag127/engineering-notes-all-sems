### Controlling peripherals connected to Raspberry Pi

- Web camera: Raspberry Pi can be used to control a web camera and capture images/videos. This can be achieved using Python libraries like picamera that provide an interface to the camera module. The code can control properties like resolution, frame rate, exposure, etc. and capture images/videos and store them locally or stream over a network.
- Network: The network interfaces of the Raspberry Pi can be controlled programmatically using Python libraries like RPi.GPIO and networking modules. This allows controlling connectivity, modifying network settings, and more. The Pi can be used as a wireless access point or client and to interface with other network devices.
- Relays: Relays can be connected to the GPIO pins of the Raspberry Pi and controlled using Python code. This allows switching AC appliances and devices on/off based on programmed logic or external events/signals. The relay logic can be used to build smart home automation systems and more. The GPIO pins can be toggled on/off programmatically to switch the relays.
