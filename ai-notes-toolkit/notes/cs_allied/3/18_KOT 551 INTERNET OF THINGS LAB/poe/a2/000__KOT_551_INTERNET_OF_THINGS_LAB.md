# KOT 551 INTERNET OF THINGS LAB

1. Introduction to IoT
- Internet of Things (IoT) refers to the interconnection of everyday physical objects and appliances via the internet.
- These devices are equipped with sensors, software, and network connectivity that allows them to send and receive data.
- IoT enables these devices to be sensed and controlled remotely across existing network infrastructure.

2. IoT Architecture
- The IoT system consists of sensors/devices, connectivity, cloud, and applications.
- Sensors/devices capture data from the physical environment and transmit it over the connectivity layer.
- The connectivity layer provides network capabilities to transport the data to the cloud.
- The cloud stores, processes, and analyzes the data. Applications access the data and present useful information to the users.

3. IoT Protocols and Standards
- IoT protocols and standards enable the components of the IoT system to communicate with each other. Some of the common IoT protocols and standards are:
-- MQTT: Message Queue Telemetry Transport protocol for lightweight publish/subscribe messaging
-- CoAP: Constrained Application Protocol for constrained nodes and networks
-- HTTP: Hypertext Transfer Protocol can be used for some IoT devices and networks
-- IEEE 802.15.4: Wireless personal area network standard
-- Bluetooth/BLE: Bluetooth Low Energy for short-range wireless communication
-- Zigbee: Low-power wireless protocol built on top of IEEE 802.15.4
