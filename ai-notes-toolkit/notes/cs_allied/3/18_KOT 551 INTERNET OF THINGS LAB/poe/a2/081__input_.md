#### Input

1. Input refers to the data or instructions entered into a computer system to get processed and generate an output.
2. The input data is the raw information that is fed into the system. It acts as a trigger to get the processing started. The input could be in the form of text, numbers, images, audio, etc. depending on the type of processing required.
3. The input is first received and then stored by the system temporarily in the input devices such as keyboard, mouse, microphone, etc. The data is then transferred to the memory for processing.
4. The processing of input involves various steps like validation, formatting, conversion, etc. to make the data suitable for processing. The processed data is then used to generate the desired output.
5. The output generated depends completely on the input provided. If the input is incorrect or inappropriate, the output will also be erroneous. So, it is important to provide accurate and appropriate input to obtain the correct output.
