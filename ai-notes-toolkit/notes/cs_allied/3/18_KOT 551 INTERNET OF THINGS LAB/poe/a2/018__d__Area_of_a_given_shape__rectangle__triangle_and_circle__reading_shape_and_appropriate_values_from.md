#### d) Area of a given shape (rectangle, triangle and circle) reading shape and appropriate values from standard

-   **Rectangle:** Area = Length x Breadth
    -   Read length and breadth values from standard input
    -   Calculate area by multiplying length and breadth
-   **Triangle:** Area = (base x height)/2
    -   Read base and height values from standard input
    -   Calculate area by multiplying base and height and dividing by 2
-   **Circle:** Area = πr2
    -   Read radius (r) value from standard input
    -   Calculate area by squaring the radius and multiplying by π (π = 3.14)
