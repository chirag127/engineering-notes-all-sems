#### d) Area of a given shape (rectangle, triangle and circle) reading shape and appropriate values from standard

When it comes to calculating the area of a shape, it is important to know the appropriate formula for the given shape. In this section, we will discuss the formulas for calculating the area of a rectangle, triangle, and circle, as well as the process for reading the appropriate values from standard.

##### Area of a Rectangle

To calculate the area of a rectangle, we use the formula:

```
Area = length x width
```

To read the appropriate values from standard, we need to know the length and width of the rectangle. These values can be read from the sides of the rectangle, which should be labeled with their respective measurements.

##### Area of a Triangle

To calculate the area of a triangle, we use the formula:

```
Area = (base x height) / 2
```

To read the appropriate values from standard, we need to know the base and height of the triangle. These values can be read from the base and height of the triangle, which should be labeled with their respective measurements.

##### Area of a Circle

To calculate the area of a circle, we use the formula:

```
Area = pi x radius^2
```

To read the appropriate values from standard, we need to know the radius of the circle. This value can be read from the diameter of the circle, which should be labeled with its respective measurement. The radius can be calculated by dividing the diameter by 2.

In conclusion, knowing the appropriate formula for calculating the area of a shape and being able to read the appropriate values from standard is essential for solving problems related to geometry. By following the guidelines outlined above, you can confidently calculate the area of a rectangle, triangle, or circle given the appropriate values.
