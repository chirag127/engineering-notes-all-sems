# KOT 551 INTERNET OF THINGS LAB

In this lab, students will learn about the Internet of Things (IoT) and its various applications. The lab is designed to provide hands-on experience to the students in building IoT systems, using various hardware platforms and software tools. Here are the topics that will be covered in the lab:

## 1. Introduction to IoT

- Definition and overview of IoT
- Architecture of an IoT system
- Applications of IoT in various domains

## 2. Hardware Platforms for IoT

- Arduino boards and shields
- Raspberry Pi and its accessories
- ESP8266 and ESP32 boards

## 3. Sensors and Actuators

- Types of sensors and their applications
- Interfacing sensors with microcontrollers
- Types of actuators and their applications
- Interfacing actuators with microcontrollers

## 4. Communication Protocols for IoT

- Wi-Fi and Bluetooth protocols
- MQTT protocol and its applications
- HTTP and HTTPS protocols

## 5. IoT Cloud Platforms

- AWS IoT platform
- Microsoft Azure IoT platform
- Google Cloud IoT platform
- IBM Watson IoT platform

## 6. IoT Security

- Introduction to IoT security
- Common security threats in IoT systems
- Security measures for IoT systems

In this lab, students will work on various projects to develop their skills in building IoT systems. Some of the projects that will be covered in the lab include:

- Smart home automation system using Arduino and sensors
- Weather monitoring system using Raspberry Pi and sensors
- Health monitoring system using ESP8266 and cloud platform

By the end of the lab, students will have gained a solid understanding of IoT and its applications, as well as practical experience in building IoT systems using various hardware platforms and software tools.
