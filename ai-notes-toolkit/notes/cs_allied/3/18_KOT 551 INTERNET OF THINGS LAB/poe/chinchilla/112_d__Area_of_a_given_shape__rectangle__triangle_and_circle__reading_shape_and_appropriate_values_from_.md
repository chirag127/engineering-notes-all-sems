# Area of a Given Shape

In this section, we will discuss the calculation of the area of various shapes, including rectangles, triangles, and circles. We will also explore how to read the shape and appropriate values from standard.

## Rectangle

A rectangle is a four-sided shape with opposite sides parallel and equal in length. To calculate the area of a rectangle, we need to know its length and width.

The formula for calculating the area of a rectangle is:

```
Area = length x width
```

## Triangle

A triangle is a three-sided shape. To calculate the area of a triangle, we need to know its base and height.

The formula for calculating the area of a triangle is:

```
Area = 1/2 x base x height
```

## Circle

A circle is a shape with a curved boundary that is equidistant from its center. To calculate the area of a circle, we need to know its radius.

The formula for calculating the area of a circle is:

```
Area = π x radius^2
```

where π is a constant and is approximately equal to 3.14.

## Reading Shape and Appropriate Values from Standard

To calculate the area of a given shape, we need to read the shape and appropriate values from standard. The standard will specify the required measurements for each shape.

For a rectangle, we need to read the length and width from standard. The length and width are usually given in units such as meters, centimeters, or feet.

For a triangle, we need to read the base and height from standard. The base and height are usually given in the same units as the rectangle.

For a circle, we need to read the radius from standard. The radius is usually given in the same units as the rectangle and triangle.

After reading the appropriate values, we can use the formulas mentioned above to calculate the area of the given shape.
