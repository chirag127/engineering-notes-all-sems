# CO 5 Examine various SQL queries from MySQL database K4, K5

In this topic, we will be examining various SQL queries that can be used in MySQL database. SQL (Structured Query Language) is a powerful tool for working with relational databases, and MySQL is one of the most popular open-source relational database management systems.

Here are some of the most common SQL queries used in MySQL:

1. SELECT: The SELECT statement is used to retrieve data from one or more tables in a database. It is used in conjunction with other clauses such as WHERE, ORDER BY, and GROUP BY to filter and sort the data as required.

2. INSERT: The INSERT statement is used to add new rows to a table in the database. The statement includes the name of the table to which the data will be added, and the values for each column in the new row.

3. UPDATE: The UPDATE statement is used to modify existing rows in a table. It includes the name of the table to be updated, the columns to be modified, and the new values for each column.

4. DELETE: The DELETE statement is used to remove rows from a table in the database. It includes the name of the table from which the data will be deleted, and a WHERE clause that specifies the conditions for deleting the rows.

5. JOIN: The JOIN statement is used to combine data from two or more tables in the database. There are several types of JOIN statements, including INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN, which determine how the data is combined.

6. GROUP BY: The GROUP BY statement is used to group rows in a table based on the values in one or more columns. It is often used in conjunction with aggregate functions such as COUNT, SUM, AVG, and MAX to calculate summary statistics for each group.

7. ORDER BY: The ORDER BY statement is used to sort the rows in a table based on the values in one or more columns. It can be used to sort the data in ascending or descending order.

8. LIMIT: The LIMIT statement is used to limit the number of rows returned by a query. It is often used in conjunction with ORDER BY to retrieve the top or bottom N rows based on a specific criteria.

In conclusion, SQL is a powerful tool for working with relational databases, and MySQL is one of the most popular open-source relational database management systems. By mastering these SQL queries, you will be able to retrieve, modify, and manipulate data in MySQL databases with ease.
