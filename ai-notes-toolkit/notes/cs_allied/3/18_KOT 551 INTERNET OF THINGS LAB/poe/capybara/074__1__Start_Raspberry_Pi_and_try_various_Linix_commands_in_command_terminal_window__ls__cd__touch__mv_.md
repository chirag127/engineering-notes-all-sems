#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man.

When it comes to working with a Raspberry Pi, the command terminal window is an essential tool that allows you to interact with the system and perform various tasks. Here are some of the most commonly used Linux commands that you can try out in the command terminal window:

- `ls`: This command is used to list the files and directories in the current working directory. To use this command, simply type `ls` and press enter. You should see a list of files and directories displayed on the screen.

- `cd`: This command is used to change the current working directory. To use this command, type `cd` followed by the name of the directory you want to switch to. For example, if you want to switch to the "Documents" directory, you would type `cd Documents`.

- `touch`: This command is used to create a new file in the current working directory. To use this command, type `touch` followed by the name of the file you want to create. For example, if you want to create a file called "test.txt", you would type `touch test.txt`.

- `mv`: This command is used to move or rename files and directories. To use this command, type `mv` followed by the name of the file or directory you want to move or rename, and then the destination directory or new name. For example, if you want to rename a file called "old.txt" to "new.txt", you would type `mv old.txt new.txt`.

- `rm`: This command is used to delete files and directories. To use this command, type `rm` followed by the name of the file or directory you want to delete. For example, if you want to delete a file called "test.txt", you would type `rm test.txt`.

- `man`: This command is used to display the manual page for a specific command. To use this command, type `man` followed by the name of the command you want to learn more about. For example, if you want to learn more about the `ls` command, you would type `man ls`.

By practicing these commands in the command terminal window of your Raspberry Pi, you will gain a better understanding of how the Linux operating system works and become more comfortable with using the command line interface.
