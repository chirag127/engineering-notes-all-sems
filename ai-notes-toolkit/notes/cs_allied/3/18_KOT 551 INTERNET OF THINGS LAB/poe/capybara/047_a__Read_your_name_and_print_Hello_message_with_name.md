# Read Your Name and Print Hello Message with Name

When it comes to programming, one of the most basic tasks is to read input from the user and display output on the screen. In this tutorial, we will learn how to read the user's name as input and print a personalized hello message using that name.

Here are the steps to read the user's name and print a hello message:

1. First, we need to create a variable to store the user's name. We can use the `input()` function to read the user's name as input from the keyboard.

2. Once we have the user's name, we can use string concatenation to create a personalized hello message with the user's name. We can use the `print()` function to display the message on the screen.

3. Here's an example code snippet that demonstrates how to read the user's name and print a personalized hello message:

   ```
   name = input("Enter your name: ")
   message = "Hello, " + name + "!"
   print(message)
   ```

4. In the above example, we first read the user's name using the `input()` function and store it in the `name` variable.

5. Next, we create a personalized hello message using string concatenation. We concatenate the string "Hello, " with the value of the `name` variable and the string "!" to create the message.

6. Finally, we use the `print()` function to display the message on the screen.

7. It's important to note that when we use the `input()` function to read the user's name, we need to make sure to include a prompt message to tell the user what input is expected.

By following these simple steps, you can easily read the user's name and print a personalized hello message with their name. This is a basic programming task that is commonly used in many different applications.
