#### CO 5 Examine various SQL queries from MySQL database K4, K5

In this section, we will explore various SQL queries that can be used in MySQL database. It is essential to understand the different types of SQL queries that can be used while working with databases. Here are some of the most commonly used SQL queries that you should know:

- **SELECT:** This query is used to retrieve data from one or more tables in a database. It is the most commonly used query in SQL. The syntax to use this query is as follows:

    `SELECT column_1, column_2, ... FROM table_name;`

- **INSERT:** This query is used to insert data into a table. It is used with the **VALUES** keyword, which specifies the values to be inserted into the table. The syntax to use this query is as follows:

    `INSERT INTO table_name (column_1, column_2, ...) VALUES (value_1, value_2, ...);`

- **UPDATE:** This query is used to update existing data in a table. It is used with the **SET** keyword, which specifies the new values to be updated. The syntax to use this query is as follows:

    `UPDATE table_name SET column_1 = value_1, column_2 = value_2, ... WHERE condition;`

- **DELETE:** This query is used to delete data from a table. It is used with the **WHERE** keyword, which specifies the condition for deleting the data. The syntax to use this query is as follows:

    `DELETE FROM table_name WHERE condition;`

- **CREATE:** This query is used to create a new table in a database. It is used with the **TABLE** keyword, which specifies the name of the new table and the columns it will contain. The syntax to use this query is as follows:

    `CREATE TABLE table_name (column_1 data_type_1, column_2 data_type_2, ...);`

- **ALTER:** This query is used to modify the structure of an existing table. It is used with the **TABLE** keyword, which specifies the name of the table and the modifications to be made. The syntax to use this query is as follows:

    `ALTER TABLE table_name ADD column_name data_type;`

These are the most commonly used SQL queries in MySQL databases. By mastering these queries, you will be able to work with databases with ease.
