# Starting Raspberry Pi and Trying Various Linux Commands in Command Terminal Window

To begin with, let's start by powering on your Raspberry Pi and connecting it to your monitor, keyboard and mouse. Once you have done that, follow these steps to start your Raspberry Pi:

1. Connect the power supply to your Raspberry Pi and plug it in.
2. Once the Raspberry Pi boots up, you will be prompted to login. Enter the default username and password, which are "pi" and "raspberry" respectively.
3. After you have successfully logged in, you will be taken to the command line interface (CLI).

Now that you have successfully started your Raspberry Pi, it's time to try out some basic Linux commands in the command terminal window. Here are some of the most commonly used Linux commands that you can try out:

1. **ls** - This command is used to list the files and directories in the current directory. For example, if you type "ls" and hit enter, you will see a list of all the files and directories in the current directory.
2. **cd** - This command is used to change directories. For example, if you want to change to a directory called "Documents", you can type "cd Documents" and hit enter. This will take you into the "Documents" directory.
3. **touch** - This command is used to create a new file. For example, if you want to create a file called "test.txt", you can type "touch test.txt" and hit enter. This will create a new file called "test.txt".
4. **mv** - This command is used to move or rename files and directories. For example, if you want to rename a file called "old.txt" to "new.txt", you can type "mv old.txt new.txt" and hit enter. This will rename the file from "old.txt" to "new.txt".
5. **rm** - This command is used to delete files and directories. For example, if you want to delete a file called "test.txt", you can type "rm test.txt" and hit enter. This will delete the file from the current directory.
6. **man** - This command is used to display the manual pages for a particular command. For example, if you want to learn more about the "ls" command, you can type "man ls" and hit enter. This will display the manual pages for the "ls" command.

By practicing these basic Linux commands, you will become more comfortable with using the command terminal window and navigating through your Raspberry Pi's file system. Good luck!
