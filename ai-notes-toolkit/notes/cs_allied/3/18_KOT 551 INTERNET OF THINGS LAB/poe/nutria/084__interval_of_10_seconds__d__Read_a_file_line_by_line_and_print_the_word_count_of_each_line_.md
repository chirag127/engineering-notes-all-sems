

#### Interval of 10 Seconds
1. A file can be read line by line using a loop. 
2. Within the loop, the `length` method can be used to determine the number of words in the current line. 
3. The word count can then be stored in a variable and printed after the loop is complete. 
4. This process can be repeated for each line of the file, allowing for the word count of each line to be printed.
