
# 1. Start Raspberry Pi and try various Linux commands in command terminal window: 
* `ls` - This command is used to list the contents of a directory.
* `cd` - This command is used to change the current working directory.
* `touch` - This command is used to create an empty file.
* `mv` - This command is used to move or rename files and directories.
* `rm` - This command is used to delete files and directories.
* `man` - This command is used to display the manual page of a command.
