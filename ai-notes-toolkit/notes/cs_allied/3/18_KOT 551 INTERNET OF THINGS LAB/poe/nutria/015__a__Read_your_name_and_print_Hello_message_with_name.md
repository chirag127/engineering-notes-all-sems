
#### a) Read your name and print Hello message with name

1. In order to read a name and print a hello message with the name, we need to first create a program that can read user input. This can be done using the `input()` function in Python.

2. Once the program has read the user input, we need to store it in a variable. For example, if we want to store the user's name, we can use the following code: `name = input("What is your name? ")`.

3. Now that we have stored the user's name in a variable, we can use it to print a hello message. We can do this using the `print()` function in Python, as follows: `print("Hello, " + name + "!")`.

4. Finally, we need to execute the program in order to read the user's name and print the hello message. This can be done using the `python` command in the terminal or command prompt.
