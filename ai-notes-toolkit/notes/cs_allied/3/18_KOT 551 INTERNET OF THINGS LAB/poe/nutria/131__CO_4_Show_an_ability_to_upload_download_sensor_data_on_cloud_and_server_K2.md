

#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

1. Cloud computing is a type of computing that utilizes a network of remote servers hosted on the Internet to store, manage, and process data, rather than a local server or a personal computer.

2. Cloud servers are accessible from any device with an internet connection, making them ideal for storing and accessing large amounts of data.

3. Sensor data is often stored on cloud servers due to its large size and the need for real-time access.

4. To upload data to a cloud server, the data must first be converted into a format that can be sent over the internet.

5. Once the data is uploaded, it can be accessed and manipulated in real-time by users connected to the server.

6. To download data from a cloud server, users must have access to the server and the data must be in a format that can be downloaded.

7. Server K2 is a cloud server that is designed to store and process sensor data.

8. It is optimized to store large amounts of data, and to provide users with real-time access to the data.

9. Server K2 also provides users with the ability to securely upload and download data from the server.
