
#### Input

- Input is the information that is sent to a computer or other device so that the device can process it.
- Input can come in many forms, including text, numbers, images, audio, and video.
- Input can be entered manually, through a keyboard or mouse, or it can be sent from another device, such as a scanner or microphone.
- The device then processes the input and produces an output, which can be displayed on a screen, printed out, or sent to another device.
- Input devices, such as keyboards and mice, are designed to make it easier for people to enter data into a computer.
- Input validation is an important part of programming, as it ensures that only valid data is accepted by the computer.
- Input can also be used to control the behavior of a computer program, such as a game or a web browser.
