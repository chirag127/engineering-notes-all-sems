
#### b) Read two numbers and print their sum, difference, product and division.

1. To read two numbers from the user, the program should use the `input()` function to get the numbers as strings.

2. To convert the strings to numbers, the program should use the `int()` function.

3. To calculate the sum of the two numbers, the program should use the `+` operator.

4. To calculate the difference of the two numbers, the program should use the `-` operator.

5. To calculate the product of the two numbers, the program should use the `*` operator.

6. To calculate the division of the two numbers, the program should use the `/` operator.

7. To print the results, the program should use the `print()` function.
