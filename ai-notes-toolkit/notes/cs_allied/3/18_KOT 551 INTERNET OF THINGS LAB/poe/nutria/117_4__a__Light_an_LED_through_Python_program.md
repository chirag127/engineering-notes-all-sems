

# 4. a) Light an LED through Python Program

1. LEDs (Light-emitting diodes) are small electronic components that emit light when an electrical current passes through them.

2. LEDs are used in a variety of applications, including lighting, displays, and indicators.

3. To control an LED with Python, you will need to import the appropriate libraries and create a few variables to store the GPIO pin numbers and the LED's state.

4. Once the variables have been created, you can use the GPIO library to set the GPIO pin to output mode and then set the pin's state to HIGH or LOW to turn the LED on or off.

5. You can also use the time library to create a delay between turning the LED on and off, allowing you to create a blinking effect.

6. To turn off the LED, simply set the pin's state to LOW.
