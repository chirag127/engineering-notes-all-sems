
#### 2. Run some Python Programs on Pi: 
- Install Python 3 on Raspberry Pi: To install Python 3 on Raspberry Pi, first open the terminal window and enter the following command: `sudo apt-get install python3`. 
- Access the Python Interpreter: You can access the Python interpreter by running the command `python3` in the terminal window.
- Create and Run a Python Program: To create a program, open a text editor and create a file called `program.py`. Then type the following code: `print("Hello, World!")`. Save the file and run the program by entering the command `python3 program.py`.
- Install Libraries: To install additional libraries, use the `pip` command. For example, to install the `matplotlib` library, enter the command `pip install matplotlib`.
- Debugging: To debug a program, use the `pdb` command in the terminal window. This will open the Python debugger, allowing you to step through your program line-by-line.
