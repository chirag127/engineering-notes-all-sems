

#### c) Word and Character Count of a Given String

1. A **word** is a unit of language that is composed of a combination of one or more characters.
2. A **character** is a single unit of a language, such as a letter, number, punctuation mark, or space.
3. To calculate the **word count** of a given string, one must first identify the individual words within the string. This can be done by counting the number of spaces between words, or using a text editor to do the counting.
4. To calculate the **character count** of a given string, one must first identify the individual characters within the string. This can be done by counting each character, or using a text editor to do the counting.
5. The **total word count** of a given string is the sum of the number of words in the string.
6. The **total character count** of a given string is the sum of the number of characters in the string.
