
#### 3. Run some Python Programs on Pi
1. To print a name 'n' times, where name and n are read from standard input, you can use the following code:
```python
name = input("What is your name? ")
n = int(input("How many times do you want to print your name? "))

for i in range(n):
    print(name)
```
2. To read the values of two variables `a` and `b` from standard input, you can use the following code:
```python
a = int(input("Enter the value of a: "))
b = int(input("Enter the value of b: "))
```
3. To print the sum of two numbers `a` and `b` read from standard input, you can use the following code:
```python
a = int(input("Enter the value of a: "))
b = int(input("Enter the value of b: "))

print("The sum of a and b is:", a + b)
```
