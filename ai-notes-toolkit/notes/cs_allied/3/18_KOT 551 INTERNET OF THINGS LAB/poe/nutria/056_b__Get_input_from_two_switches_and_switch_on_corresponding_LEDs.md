

# Get Input from Two Switches and Switch on Corresponding LEDs

1. Connect two switches to the microcontroller board.
2. Set up the corresponding pins on the microcontroller board to read the input from the switches.
3. Write a program that reads the input from the switches and stores it in a variable.
4. Depending on the input, turn on the corresponding LEDs.
5. Monitor the input from the switches and update the output to the LEDs accordingly.
