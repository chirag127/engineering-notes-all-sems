

#### b) Switch on a Relay at a Given Time Using Cron 

1. Cron is a time-based job scheduler used to execute commands or scripts at specified times.
2. When setting up a cron job, the user specifies the time and date when the job should be executed.
3. A relay is an electrically operated switch which can be used to control a load.
4. The contact terminals of the relay are connected to the load.
5. To switch on the relay at a given time using cron, the user can set up a cron job to execute a command to switch on the relay at the specified time.
