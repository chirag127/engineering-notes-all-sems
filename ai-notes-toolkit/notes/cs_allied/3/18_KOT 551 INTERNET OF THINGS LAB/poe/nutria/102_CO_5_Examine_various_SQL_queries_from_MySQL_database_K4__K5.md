
# CO 5 Examine various SQL queries from MySQL database K4, K5

1. A `SELECT` query is used to retrieve data from a database. It is written in the form of `SELECT <columns> FROM <table>`, where `<columns>` is a comma-separated list of the columns you want to retrieve data from, and `<table>` is the name of the table you are retrieving data from.

2. A `INSERT` query is used to add data to a database. It is written in the form of `INSERT INTO <table> (<columns>) VALUES (<values>)`, where `<table>` is the name of the table you are adding data to, `<columns>` is a comma-separated list of the columns you want to add data to, and `<values>` is a comma-separated list of the values you want to add.

3. An `UPDATE` query is used to modify data in a database. It is written in the form of `UPDATE <table> SET <columns> = <values> [WHERE <condition>]`, where `<table>` is the name of the table you are modifying data in, `<columns>` is a comma-separated list of the columns you want to modify, `<values>` is a comma-separated list of the values you want to set, and `<condition>` is an optional condition that specifies which rows should be modified.

4. A `DELETE` query is used to remove data from a database. It is written in the form of `DELETE FROM <table> [WHERE <condition>]`, where `<table>` is the name of the table you are deleting data from, and `<condition>` is an optional condition that specifies which rows should be deleted.

5. A `JOIN` query is used to combine data from two or more tables in a database. It is written in the form of `SELECT <columns> FROM <table1> JOIN <table2> [ON <condition>]`, where `<columns>` is a comma-separated list of the columns you want to retrieve data from, `<table1>` and `<table2>` are the names of the tables you are joining, and `<condition>` is an optional condition that specifies how the tables should be joined.
