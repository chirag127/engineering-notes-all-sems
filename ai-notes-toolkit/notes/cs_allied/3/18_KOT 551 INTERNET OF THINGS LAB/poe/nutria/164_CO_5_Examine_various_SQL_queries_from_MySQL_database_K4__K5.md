
# CO 5 Examine various SQL queries from MySQL database K4, K5

1. Queries can be written in Structured Query Language (SQL) to access data from a MySQL database.

2. The syntax for SQL queries is similar across all database systems.

3. MySQL databases can be queried using the following commands: SELECT, INSERT, UPDATE, DELETE, CREATE, DROP, and ALTER.

4. The SELECT command is used to retrieve data from a MySQL database.

5. The INSERT command is used to add new records to a MySQL database.

6. The UPDATE command is used to modify existing records in a MySQL database.

7. The DELETE command is used to delete records from a MySQL database.

8. The CREATE command is used to create a new table in a MySQL database.

9. The DROP command is used to delete an existing table in a MySQL database.

10. The ALTER command is used to modify the structure of an existing table in a MySQL database.
