
#### 4. a) Light an LED through Python program

1. Connect an LED to your Raspberry Pi. The LED should have two legs, one longer than the other. The longer leg is the positive side of the LED and should be connected to a GPIO pin. 
2. Create a Python program that will turn the LED on and off. This can be done by using the RPi.GPIO library and setting the GPIO pin to either HIGH or LOW.
3. Once the program is written, it can be run from the command line or from the terminal. 
4. To turn the LED on, set the GPIO pin to HIGH. To turn the LED off, set the GPIO pin to LOW. 
5. Once the program is running, the LED should turn on and off as expected.
