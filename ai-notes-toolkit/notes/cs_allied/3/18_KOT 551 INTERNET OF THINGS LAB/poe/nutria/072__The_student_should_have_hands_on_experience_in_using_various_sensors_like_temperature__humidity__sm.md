
### The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc.:

- Temperature sensors measure the temperature of an environment and can be used to detect changes in temperature.
- Humidity sensors measure the amount of moisture in the air and can be used to detect changes in humidity.
- Smoke sensors detect smoke particles in the air and can be used to detect the presence of smoke.
- Light sensors detect the amount of light in an environment and can be used to detect changes in light levels.
