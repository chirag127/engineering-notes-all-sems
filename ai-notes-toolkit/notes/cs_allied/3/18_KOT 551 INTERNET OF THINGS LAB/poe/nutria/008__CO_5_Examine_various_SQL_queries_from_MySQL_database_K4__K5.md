

#### CO 5 Examine various SQL Queries from MySQL Database K4, K5

1. Understanding the basics of SQL queries: SQL queries are used to retrieve and manipulate data stored in a relational database. They are written in a special language called Structured Query Language (SQL).

2. Querying data from a MySQL database: A MySQL database can be queried using the SELECT statement. This statement can be used to retrieve data from one or more tables in the database.

3. Using the WHERE clause: The WHERE clause can be used to filter the results of a query. It can be used to specify conditions that must be met for a record to be included in the result set.

4. Joining tables: Joining tables is a way to combine data from multiple tables into one result set. The JOIN clause can be used to join tables together.

5. Using aggregate functions: Aggregate functions are used to calculate values from multiple records. Examples of aggregate functions include SUM, AVG, MIN, and MAX.

6. Using subqueries: Subqueries are used to embed one query inside another. This can be used to create complex queries that are not possible with just the SELECT statement.

7. Using stored procedures: Stored procedures are used to execute a set of SQL statements. They can be used to perform complex tasks that would be difficult to do with just the SELECT statement.
