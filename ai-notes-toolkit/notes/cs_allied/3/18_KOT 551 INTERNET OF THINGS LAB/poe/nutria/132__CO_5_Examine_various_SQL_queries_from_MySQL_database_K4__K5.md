
#### CO 5 Examine various SQL queries from MySQL Database K4, K5

1. SQL queries are used to retrieve data from a MySQL database.
2. The SELECT statement is used to select data from a table in a MySQL database.
3. The WHERE clause is used to filter the results of a SELECT statement.
4. The ORDER BY clause is used to sort the results of a SELECT statement.
5. The LIKE clause is used to search for patterns in strings.
6. The LIMIT clause is used to limit the number of rows returned by a SELECT statement.
7. The GROUP BY clause is used to group the results of a SELECT statement by one or more columns.
8. The HAVING clause is used to filter the results of a GROUP BY clause.
9. The JOIN clause is used to join tables in a MySQL database.
10. The UNION clause is used to combine the results of two or more SELECT statements.
