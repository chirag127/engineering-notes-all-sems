
#### 4. a) Light an LED through Python program

* To light an LED through a Python program, you need to have a Raspberry Pi, an LED and two wires.
* First, connect the LED to the Raspberry Pi using the two wires. The longer wire should be connected to the positive terminal and the shorter wire to the negative terminal.
* Next, write a Python program that will turn on the LED. This can be done using the `GPIO` library.
* In the program, set the GPIO pin to output mode and then set the pin to high to turn on the LED.
* Finally, run the program to turn on the LED.
