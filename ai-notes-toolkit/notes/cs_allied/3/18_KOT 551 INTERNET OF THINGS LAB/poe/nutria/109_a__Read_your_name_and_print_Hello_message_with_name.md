
# a) Read your name and print Hello message with name

1. To read a user's name, you can use the `input()` function. This function allows the user to type in their name and store it as a string.

2. To print a message with the user's name, you can use the `print()` function. This function will take a string as an argument and print it to the console. To include the user's name in the message, you can use string concatenation. For example, `print("Hello, " + user_name + "!")` will print a message with the user's name.
