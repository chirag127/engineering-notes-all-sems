
#### Input

1. Input is the information that is sent to a computer system in order to produce an output.
2. Input can come in the form of data, text, commands, images, sound, and other media.
3. The input device is the hardware device used to send information to the computer. Examples of input devices include keyboards, mice, scanners, and microphones.
4. Input is processed by the computer's central processing unit (CPU) and stored in the computer's memory.
5. The output is the result of the processing of the input. Output can be displayed on a screen or sent to a printer.
