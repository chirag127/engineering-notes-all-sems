
#### 2. Run some Python Programs on Pi:
1. Install Python on your Pi: 
   * Download the latest version of Python from the [Python website](https://www.python.org/downloads/).
   * Follow the instructions to install the version of Python that you downloaded.
2. Create a Python Program:
   * Open a text editor and create a new file.
   * Type in your Python code.
   * Save your file as a .py file.
3. Run the Python Program on your Pi:
   * Open the terminal on your Pi.
   * Type in `python <your_file_name>.py` and press enter.
   * The program should run.
