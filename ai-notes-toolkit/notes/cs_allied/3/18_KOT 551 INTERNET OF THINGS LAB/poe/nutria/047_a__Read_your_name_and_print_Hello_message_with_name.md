

# A) Read Your Name and Print Hello Message with Name

1. To read a name and print a greeting, you must first create a variable to store the name. This can be done using the following code:

```
name = input("What is your name? ")
```

2. Once the name is stored in the variable, you can print a greeting using the following code:

```
print("Hello, " + name + "!")
```

3. This code can be combined into a single line as follows:

```
print("Hello, " + input("What is your name? ") + "!")
```

4. The code can be tested by running it in a Python interpreter. The interpreter will prompt for a name and then print the greeting.
