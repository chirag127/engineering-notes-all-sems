# Raspberry Pi for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- Raspberry Pi is a low cost, credit-card sized computer that plugs into a computer monitor or TV, and uses a standard keyboard and mouse.
- Raspberry Pi was developed by the Raspberry Pi Foundation, based in the U.K., to promote the teaching of computer science and programming to high school students in developing countries .
- Raspberry Pi was first released to the public in February of 2012.
- Raspberry Pi is a capable little device that enables people of all ages to explore computing, and to learn how to program in languages like Scratch and Python.
- Raspberry Pi can also be used to interact with the physical world, using basic digital, analogue, and electromechanical components.
- Raspberry Pi has different models and versions, each with different specifications, such as CPU speed, RAM, weight, etc.
- Raspberry Pi 4 Model B is the latest and most powerful model, with a 1.5 GHz CPU and up to 8 GB of RAM.
- Raspberry Pi can run various operating systems, such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, etc.
- Raspberry Pi can be used for various projects, such as media center, web server, gaming console, robot, etc.
- Raspberry Pi has a large and active community of users and developers, who share their projects, tutorials, and resources online.
