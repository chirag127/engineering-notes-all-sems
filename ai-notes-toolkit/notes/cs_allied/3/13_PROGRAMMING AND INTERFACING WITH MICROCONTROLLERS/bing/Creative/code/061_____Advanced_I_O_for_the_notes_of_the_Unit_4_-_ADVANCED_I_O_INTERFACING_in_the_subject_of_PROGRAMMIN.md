### Advanced I/O

- Advanced I/O refers to the techniques and devices that enable a microcontroller to communicate with external peripherals, such as sensors, actuators, displays, keyboards, etc.
- Advanced I/O devices can be classified into two categories: parallel and serial.
- Parallel I/O devices use multiple data lines to transfer data simultaneously, while serial I/O devices use a single data line to transfer data sequentially, bit by bit.
- Parallel I/O devices are faster than serial I/O devices, but they require more pins and wires, which increases the cost and complexity of the system.
- Serial I/O devices are slower than parallel I/O devices, but they require fewer pins and wires, which reduces the cost and complexity of the system.
- Some examples of parallel I/O devices are LCD displays, LED matrices, and memory chips.
- Some examples of serial I/O devices are UART, SPI, I2C, and USB.
- UART stands for Universal Asynchronous Receiver/Transmitter. It is a serial communication protocol that uses two data lines: TX (transmit) and RX (receive). It allows the microcontroller to communicate with other devices, such as computers, modems, GPS modules, etc. UART does not require a clock signal, but it requires both devices to agree on the data rate (baud rate) and the data format (start bit, stop bit, parity bit, etc.).
- SPI stands for Serial Peripheral Interface. It is a serial communication protocol that uses four data lines: SCK (serial clock), MOSI (master out slave in), MISO (master in slave out), and SS (slave select). It allows the microcontroller to communicate with other devices, such as sensors, ADCs, DACs, etc. SPI requires a clock signal, which is generated by the master device. The master device can select one or more slave devices by toggling the SS line. The data is transferred in both directions, simultaneously, on the MOSI and MISO lines.
- I2C stands for Inter-Integrated Circuit. It is a serial communication protocol that uses two data lines: SDA (serial data) and SCL (serial clock). It allows the microcontroller to communicate with other devices, such as sensors, EEPROMs, RTCs, etc. I2C requires a clock signal, which is generated by the master device. The master device can address one or more slave devices by sending their unique addresses on the SDA line. The data is transferred in both directions, sequentially, on the SDA line.
- USB stands for Universal Serial Bus. It is a serial communication protocol that uses two data lines: D+ and D-. It allows the microcontroller to communicate with other devices, such as computers, keyboards, mice, cameras, etc. USB requires a clock signal, which is embedded in the data stream. The USB devices can be classified into two roles: host and device. The host device initiates and controls the communication, while the device responds to the host requests. The USB devices can also be classified into four speeds: low-speed (1.5 Mbps), full-speed (12 Mbps), high-speed (480 Mbps), and super-speed (5 Gbps).
