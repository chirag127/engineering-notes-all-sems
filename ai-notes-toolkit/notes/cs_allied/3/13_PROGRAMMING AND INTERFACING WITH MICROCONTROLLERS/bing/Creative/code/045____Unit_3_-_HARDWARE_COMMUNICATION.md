## Unit 3 - HARDWARE COMMUNICATION

Hardware communication is the process of transferring data between different hardware devices or components. Hardware communication can be classified into two types: internal and external.

- Internal communication refers to the data transfer within a single device or system, such as between the CPU and the memory, or between the motherboard and the peripherals. Internal communication uses various buses, such as the system bus, the data bus, the address bus, and the control bus, to connect different components and enable data exchange. Internal communication also depends on the clock speed, the bus width, and the bus protocol of the system.

- External communication refers to the data transfer between different devices or systems, such as between a computer and a printer, or between a network of computers. External communication uses various interfaces, such as serial, parallel, USB, Ethernet, Bluetooth, and Wi-Fi, to connect different devices and enable data exchange. External communication also depends on the transmission mode, the transmission speed, the transmission medium, and the transmission protocol of the interface.

Some of the key concepts and terms related to hardware communication are:

- Bit: A binary digit, either 0 or 1, that represents the smallest unit of data.
- Byte: A group of eight bits that represents a unit of data, such as a character or a number.
- Word: A group of bytes that represents a unit of data, such as an instruction or an address. The word size of a system depends on the number of bits that the CPU can process at a time, such as 32 bits or 64 bits.
- Bit rate: The number of bits that can be transmitted or received per second, measured in bits per second (bps). Bit rate indicates the speed of data transfer.
- Bandwidth: The maximum amount of data that can be transmitted or received per second, measured in bits per second (bps). Bandwidth indicates the capacity of data transfer.
- Latency: The time delay between the transmission and the reception of data, measured in milliseconds (ms). Latency indicates the performance of data transfer.
- Synchronous transmission: A type of data transmission that uses a common clock signal to synchronize the sender and the receiver, and to indicate the start and the end of each bit or byte. Synchronous transmission is faster and more efficient, but requires more hardware and coordination.
- Asynchronous transmission: A type of data transmission that does not use a common clock signal, but uses special bits or bytes, such as start bit, stop bit, and parity bit, to indicate the start and the end of each byte. Asynchronous transmission is slower and less efficient, but requires less hardware and coordination.
- Serial transmission: A type of data transmission that sends one bit at a time over a single wire or channel. Serial transmission is simpler and cheaper, but slower and more prone to errors.
- Parallel transmission: A type of data transmission that sends multiple bits at a time over multiple wires or channels. Parallel transmission is faster and more reliable, but more complex and expensive.
- Simplex transmission: A type of data transmission that allows data to flow in one direction only, such as from a keyboard to a computer.
- Duplex transmission: A type of data transmission that allows data to flow in both directions, either simultaneously or alternately, such as between a computer and a printer.
- Half-duplex transmission: A type of duplex transmission that allows data to flow in both directions, but not at the same time, such as between a walkie-talkie and another walkie-talkie.
- Full-duplex transmission: A type of duplex transmission that allows data to flow in both directions at the same time, such as between a telephone and another telephone.
