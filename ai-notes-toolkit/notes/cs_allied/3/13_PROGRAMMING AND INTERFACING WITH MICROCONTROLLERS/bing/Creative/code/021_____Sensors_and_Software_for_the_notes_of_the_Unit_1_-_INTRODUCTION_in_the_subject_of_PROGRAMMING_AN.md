### Sensors and Software for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- A sensor is a device that converts a physical quantity into an electrical signal that can be measured or processed by a microcontroller.
- Sensors can be classified into different types based on their working principle, output type, application, etc. Some common types of sensors are:
  - Analog sensors: produce a continuous output voltage that is proportional to the physical quantity being measured, such as temperature, light, pressure, etc.
  - Digital sensors: produce a discrete output signal that is either high or low, such as switches, buttons, encoders, etc.
  - Active sensors: require an external power source to operate, such as ultrasonic, infrared, magnetic, etc.
  - Passive sensors: do not require an external power source and generate their own output signal, such as thermocouples, piezoelectric, etc.
  - Contact sensors: require physical contact with the object or medium being measured, such as touch, force, strain, etc.
  - Non-contact sensors: do not require physical contact and can measure from a distance, such as optical, radar, ultrasonic, etc.
- A microcontroller is a small computer on a single integrated circuit that contains a processor, memory, input/output ports, and peripherals.
- Microcontrollers are widely used for sensor-based systems in both industrial and commercial applications, as they can perform complex tasks, communicate with other devices, and interface with various sensors and actuators.
- Microcontrollers can be programmed using different software tools and languages, such as assembly, C, C++, Python, Arduino, etc. The choice of software depends on the type, features, and specifications of the microcontroller and the sensor system.
- Sensor software is a software module that controls the sensor product and acquires the measurement data. It consists of two layers:
  - Sensor driver: a low-level software that communicates with the sensor product via a specific interface, such as I2C, SPI, UART, etc. It provides basic functions, such as initialization, configuration, calibration, data acquisition, etc.
  - Sensor library: a high-level software that provides an abstract interface for the sensor product, such as sensor type, unit, range, resolution, etc. It also provides advanced functions, such as filtering, conversion, compensation, etc.
