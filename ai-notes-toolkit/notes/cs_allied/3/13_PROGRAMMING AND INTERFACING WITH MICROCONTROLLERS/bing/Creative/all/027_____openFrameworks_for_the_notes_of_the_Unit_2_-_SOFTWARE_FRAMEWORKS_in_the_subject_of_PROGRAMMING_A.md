# openFrameworks

openFrameworks is an open source C++ toolkit for creative coding. It is designed to assist the creative process by providing a simple and intuitive framework for experimentation. It can be used to create applications, games, interactive art, generative design, data visualization, computer vision, and more.

Some of the features of openFrameworks are:

- It is cross-platform and supports Windows, macOS, Linux, iOS, Android, Raspberry Pi, and other ARM boards.
- It wraps together several commonly used libraries, such as OpenGL, GLEW, GLUT, libtess2, cairo, FreeType, FreeImage, OpenCV, Poco, Boost, and others.
- It has a large and active community of developers, artists, and educators who contribute to the project and provide support, documentation, tutorials, and examples.
- It is modular and extensible, and allows users to create their own addons or use existing ones from the official repository or the ofxAddons website.
- It follows a set of coding conventions and style guidelines that make the code consistent and easy to read and write.
- It is free and open source, and licensed under the MIT license, which means that anyone can use it for any purpose, commercial or non-commercial, without any restrictions.
