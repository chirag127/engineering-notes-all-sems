### Git/GitHub

- Git is a **version control system** that manages and keeps track of your code .
- GitHub is a **service** that let you host, share, and manage your code files on the internet .
- GitHub uses Git underneath, and lets you manage your Git **repositories** or folders easily on its platform .
- Git and GitHub are useful for **collaborating** with other developers, **tracking** changes and **reverting** to previous versions of your code, and **publishing** your projects online .

#### Basic Git Commands

- `git init`: Initializes a new Git repository in your current directory.
- `git clone <url>`: Copies an existing Git repository from a remote location to your local machine.
- `git status`: Shows the current state of your local repository, such as which files are modified, staged, or untracked.
- `git add <file>`: Adds a file or a group of files to the staging area, which is a temporary area where you can prepare your changes before committing them.
- `git commit -m "<message>"`: Records your changes in the local repository with a descriptive message.
- `git push <remote> <branch>`: Sends your local commits to a remote repository, such as GitHub.
- `git pull <remote> <branch>`: Fetches and merges the changes from a remote repository to your local repository.
- `git branch <name>`: Creates a new branch, which is a separate line of development in your repository.
- `git checkout <branch>`: Switches to a different branch in your repository.
- `git merge <branch>`: Combines the changes from one branch to another branch.

#### Basic GitHub Features

- **Fork**: Creates a copy of another user's repository in your own GitHub account.
- **Pull request**: Requests the owner of a repository to review and merge your changes from a fork or a branch.
- **Issue**: Reports a bug, suggests a feature, or asks a question about a repository.
- **GitHub Pages**: Hosts your static website files directly from your repository.
- **GitHub Actions**: Automates your workflows, such as testing, building, and deploying your code.
- **GitHub Discussions**: Enables you to have conversations with other members of your community about your project.
