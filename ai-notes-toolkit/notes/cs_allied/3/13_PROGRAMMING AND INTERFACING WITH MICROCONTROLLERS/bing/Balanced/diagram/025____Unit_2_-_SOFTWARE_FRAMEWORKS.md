## Unit 2 - SOFTWARE FRAMEWORKS

- A software framework is a reusable set of libraries or classes that provide a standard way to perform a specific task or implement a solution to a common problem.
- A software framework typically defines an **architecture**, a **design pattern**, and a **programming model** for a domain of software development.
- A software framework may also provide **tools**, **templates**, **documentation**, and **examples** to help developers use the framework effectively.
- A software framework differs from a software library in that a framework **inverts the control flow** between the application and the framework. In other words, the framework **calls** the application code, rather than the application code **calling** the framework.
- A software framework may also be **opinionated**, meaning that it enforces a certain way of doing things and restricts the choices and flexibility of the developers.
- Some examples of software frameworks are:
  - **Web frameworks**, such as Django, Flask, Ruby on Rails, and Spring Boot, that provide a standard way to build web applications and handle common tasks such as routing, templating, authentication, and database access.
  - **Game frameworks**, such as Unity, Unreal Engine, Phaser, and Godot, that provide a standard way to create and run video games and handle common tasks such as rendering, physics, input, audio, and networking.
  - **Machine learning frameworks**, such as TensorFlow, PyTorch, Keras, and Scikit-learn, that provide a standard way to build and train machine learning models and handle common tasks such as data processing, optimization, evaluation, and deployment.
  - **Testing frameworks**, such as JUnit, PyTest, Mocha, and Jasmine, that provide a standard way to write and run automated tests and handle common tasks such as assertions, fixtures, mocks, and reporting.
