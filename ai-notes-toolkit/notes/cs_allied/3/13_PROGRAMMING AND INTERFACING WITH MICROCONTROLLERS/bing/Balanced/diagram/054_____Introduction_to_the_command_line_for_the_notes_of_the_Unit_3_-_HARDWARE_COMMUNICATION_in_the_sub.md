### Introduction to the command line

- The command line is a text-based interface that allows you to interact with your computer using commands.
- Commands are instructions that tell the computer what to do, such as creating, deleting, or moving files and folders, running programs, or changing settings.
- The command line is also known as the terminal, console, shell, or prompt.
- The command line can be accessed from different programs, such as Command Prompt, PowerShell, or Terminal, depending on your operating system.
- The command line has some advantages over graphical user interfaces (GUIs), such as:
  - It can perform complex tasks with fewer steps and less typing.
  - It can automate repetitive tasks with scripts and batch files.
  - It can access hidden or system files and settings that are not available in GUIs.
  - It can troubleshoot and fix problems that are not solvable in GUIs.
- The command line also has some disadvantages, such as:
  - It has a steep learning curve and requires memorizing commands and syntax.
  - It can be prone to errors and typos that can have serious consequences.
  - It can be intimidating and unfriendly for beginners and non-technical users.
- The command line uses different symbols and conventions to indicate the status and structure of the commands, such as:
  - The prompt, which is a symbol or text that indicates where you can type commands. For example, `C:\>` or `$`.
  - The cursor, which is a blinking symbol that shows where your input will appear. For example, `|`.
  - The arguments, which are additional information that modify or specify the commands. For example, `dir /w` or `ls -l`.
  - The options, which are flags that change the behavior or output of the commands. For example, `/w` or `-l`.
  - The switches, which are alternative names for options. For example, `/w` or `/wide`.
  - The parameters, which are variables that hold values for the commands. For example, `%1` or `$1`.
  - The operators, which are symbols that perform logical or mathematical operations on the commands. For example, `&&` or `|`.
  - The redirection, which is a way of sending the output of one command to another command or file. For example, `dir > list.txt` or `ls > list.txt`.
  - The piping, which is a way of connecting the output of one command to the input of another command. For example, `dir | find "test"` or `ls | grep "test"`.
  - The quotation marks, which are used to enclose arguments or options that contain spaces or special characters. For example, `dir "My Documents"` or `ls "My Documents"`.
  - The escape character, which is used to indicate that the following character should be treated literally and not as a symbol. For example, `dir My\ Documents` or `ls My\ Documents`.
  - The wildcard characters, which are used to match any character or group of characters in a file or folder name. For example, `dir *.txt` or `ls *.txt`.
  - The environment variables, which are variables that store information about the system or user settings. For example, `%PATH%` or `$PATH`.
