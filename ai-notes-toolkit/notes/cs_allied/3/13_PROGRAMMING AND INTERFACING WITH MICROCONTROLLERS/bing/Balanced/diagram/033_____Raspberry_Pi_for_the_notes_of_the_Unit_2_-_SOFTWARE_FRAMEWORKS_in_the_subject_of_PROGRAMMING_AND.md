### Raspberry Pi for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- A software framework is a set of tools, libraries, and conventions that provide a common structure and functionality for developing applications on a specific platform or environment.
- A software framework can simplify the development process by providing reusable components, abstracting low-level details, and enforcing best practices and standards.
- Raspberry Pi is a single-board computer that can run various operating systems, such as Raspberry Pi OS (previously called Raspbian), Ubuntu, Windows 10 IoT Core, etc.
- Raspberry Pi can also support various software frameworks that enable developers to create applications for different purposes, such as graphics, multimedia, web, gaming, robotics, etc.
- Some examples of software frameworks that can run on Raspberry Pi are:

  - openFrameworks: a cross-platform framework for creative coding, which uses C++ as the programming language and provides access to graphics, sound, video, networking, and hardware peripherals.
  - Duet Software Framework (DSF): a bundle of software programs that connects to and controls the Duet 3, a 32-bit controller board for 3D printers and CNC machines, which uses G-code as the programming language and provides a web interface for configuration and monitoring.
  - Framework Mainboards: a series of standalone x86 mainboards that can be used to build small form factor (SFF) PCs, which use Intel Core processors and support Windows, Linux, and other operating systems.
  - Mono: an open-source and cross-platform framework for developing applications using C# and other .NET languages, which provides compatibility with the .NET Framework and supports various libraries and tools.
  - Raspberry Pi Apps: a collection of applications that can be installed on Raspberry Pi OS using the Raspberry Pi Software tool, which include games, utilities, educational software, and more.
