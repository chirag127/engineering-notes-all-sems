# Python Programming for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- Python is a general-purpose, interpreted, interactive, object-oriented, and high-level programming language .
- It was created by Guido van Rossum during 1985- 1990 at the National Research Institute for Mathematics and Computer Science in the Netherlands .
- Python is designed to be easy to learn, read, and write, with a clear and consistent syntax, indentation, and naming conventions .
- Python supports multiple programming paradigms, such as procedural, functional, and object-oriented programming, as well as dynamic typing, automatic memory management, and exception handling .
- Python has a rich set of built-in data types, such as numbers, strings, lists, tuples, dictionaries, and sets, as well as operators and functions to manipulate them .
- Python also has a large and comprehensive standard library, which provides modules and packages for various tasks, such as file handling, networking, database access, web development, GUI programming, and scientific computing .
- Python can be used as a scripting language, which means it can be executed directly from the command line or a file, without the need for compilation .
- Python can also be used as a stand-alone development language, which means it can be used to create executable programs and applications, with the help of tools such as py2exe, pyinstaller, or cx_Freeze.
- Python is widely used in both academic and industrial settings, for various purposes, such as data analysis, web development, machine learning, artificial intelligence, robotics, game development, and more .
- Python is an open source language, which means its source code is freely available and can be modified and distributed by anyone.
- Python is also a cross-platform language, which means it can run on different operating systems, such as Windows, Linux, Mac OS, and more.
