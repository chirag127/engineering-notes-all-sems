### Sensors and Actuators

- Sensors and actuators are devices that interact with the physical world.
- Sensors measure physical quantities such as temperature, pressure, light, sound, etc. and convert them into electrical signals that can be processed by microcontrollers or other devices.
- Actuators receive electrical signals from microcontrollers or other devices and convert them into physical actions such as movement, rotation, heating, cooling, etc.
- Sensors and actuators often work together to perform tasks such as monitoring, controlling, or automating systems or processes.
- Some examples of sensors are thermometers, photodiodes, microphones, accelerometers, etc.
- Some examples of actuators are motors, solenoids, LEDs, speakers, heaters, etc.

#### Types of Sensors

- Sensors can be classified into different types based on the physical quantity they measure, the principle of operation, the output signal, the power requirement, etc.
- Some common types of sensors are:

  - Analog sensors: These sensors produce a continuous output signal that varies proportionally to the input quantity. For example, a potentiometer is an analog sensor that produces a voltage output that varies with the rotation angle.
  - Digital sensors: These sensors produce a discrete output signal that has only two states: high or low. For example, a switch is a digital sensor that produces a high output when pressed and a low output when released.
  - Passive sensors: These sensors do not require an external power source to operate. They generate their own output signal by using the energy of the input quantity. For example, a thermocouple is a passive sensor that produces a voltage output that depends on the temperature difference between two junctions.
  - Active sensors: These sensors require an external power source to operate. They use the input quantity to modulate the output signal of the power source. For example, a piezoelectric sensor is an active sensor that produces a voltage output that varies with the applied pressure or vibration.
  - Contact sensors: These sensors require physical contact with the input quantity to measure it. For example, a strain gauge is a contact sensor that measures the deformation of a material by changing its electrical resistance.
  - Non-contact sensors: These sensors do not require physical contact with the input quantity to measure it. They use electromagnetic waves, sound waves, or other means to detect the input quantity. For example, a radar is a non-contact sensor that measures the distance and speed of an object by using radio waves.

#### Types of Actuators

- Actuators can be classified into different types based on the physical action they perform, the principle of operation, the input signal, the power requirement, etc.
- Some common types of actuators are:

  - Linear actuators: These actuators produce a linear motion along a single axis. For example, a hydraulic cylinder is a linear actuator that moves a piston by using pressurized fluid.
  - Rotary actuators: These actuators produce a rotational motion around a single axis. For example, a stepper motor is a rotary actuator that rotates a shaft by using discrete steps of current.
  - Oscillatory actuators: These actuators produce a periodic motion that alternates between two positions or angles. For example, a piezoelectric buzzer is an oscillatory actuator that produces a sound by vibrating a thin plate.
  - Electromagnetic actuators: These actuators use the magnetic force generated by electric currents to produce motion. For example, a solenoid is an electromagnetic actuator that moves a plunger by using a coil of wire.
  - Electrostatic actuators: These actuators use the electrostatic force generated by electric charges to produce motion. For example, a microelectromechanical system (MEMS) is an electrostatic actuator that moves a tiny structure by using a capacitor.
  - Pneumatic actuators: These actuators use the pressure of compressed air or gas to produce motion. For example, a pneumatic valve is a pneumatic actuator that controls the flow of fluid by using a diaphragm.
  - Hydraulic actuators: These actuators use the pressure of liquid to produce motion. For example, a hydraulic brake is a hydraulic actuator that stops a vehicle by using a fluid-filled cylinder.
