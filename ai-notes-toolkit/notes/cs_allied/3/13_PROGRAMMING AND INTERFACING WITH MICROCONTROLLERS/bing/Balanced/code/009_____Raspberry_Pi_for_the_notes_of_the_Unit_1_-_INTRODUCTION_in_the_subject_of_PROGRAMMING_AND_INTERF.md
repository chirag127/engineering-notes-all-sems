### Raspberry Pi for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- Raspberry Pi is a low-cost, credit-card-sized single-board computer that can connect to a monitor, keyboard, mouse, and various sensors and modules .
- Raspberry Pi was developed by the Raspberry Pi Foundation, a UK-based charity, to promote computing education and digital making for people of all ages .
- Raspberry Pi can run different operating systems, such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, etc. It can also run various programming languages, such as Python, Scratch, C, Java, etc .
- Raspberry Pi has different models and versions, each with different specifications, such as CPU speed, RAM size, weight, etc. The latest model is Raspberry Pi 4 Model B, which has a 1.5 GHz quad-core processor, 1, 2, 4, or 8 GB of RAM, and supports dual 4K displays .
- Raspberry Pi can be used for various projects and applications, such as web servers, media centers, robots, smart home devices, gaming consoles, etc. It can also interact with other devices and components, such as cameras, speakers, LEDs, motors, sensors, etc  .
