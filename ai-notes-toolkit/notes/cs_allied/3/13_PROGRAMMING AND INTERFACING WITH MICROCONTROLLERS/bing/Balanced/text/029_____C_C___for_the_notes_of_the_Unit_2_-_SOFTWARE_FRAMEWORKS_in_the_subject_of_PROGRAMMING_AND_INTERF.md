### C/C++ for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- A software framework is a reusable set of libraries or classes that provide a standard way to perform a specific task, such as communication, input/output, or graphical user interface.
- Software frameworks can simplify the development of embedded software for microcontrollers, which are small computers that control hardware devices.
- C and C++ are two of the most popular programming languages for microcontrollers, because they offer low-level access to the hardware, high performance, and portability across different platforms.
- Some of the software frameworks that can be used with C or C++ for microcontroller programming are:

  - **TensorFlow Lite for Microcontrollers**: A framework for running machine learning models on microcontrollers, based on the TensorFlow Lite library. It supports many processors based on the Arm Cortex-M Series architecture, and can be used as an Arduino library.
  - **QP/C and QP/C++**: Real-time embedded frameworks based on event-driven active objects and hierarchical state machines. They provide a modern, open source architecture and runtime environment for microcontroller applications.
  - **Advanced Software Framework (ASF)**: A framework developed by Microchip Technology that provides a rich set of proven drivers and code modules for various microcontroller families. It simplifies the usage of microcontrollers by providing an abstraction to the hardware through drivers and high-value middlewares.
  - **Visual C++ for IoT Development**: An extension for Visual Studio that enables programmers to debug native C/C++ code either locally on Windows, or on microcontrollers, or on remote Linux machines. It supports embedded development, CUDA, and game development with Unreal Engine.
  - **JetBrains C++ Tools**: A set of tools from JetBrains that help programmers modernize their C++ code and eliminate inefficiencies. They include CLion, a cross-platform IDE for C and C++ development, and ReSharper C++, a productivity tool for Visual Studio C++ projects.
