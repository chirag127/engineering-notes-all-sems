### Wired/Wireless Networking

- Wired and wireless networking are two ways of connecting microcontrollers to other devices or networks using different communication protocols and physical media.
- Wired networking uses cables or wires to transmit data signals between microcontrollers and peripherals, such as sensors, actuators, displays, etc. Wired networking can provide high-speed, reliable and secure data transfer over short or long distances.
- Wireless networking uses radio waves or other electromagnetic waves to transmit data signals between microcontrollers and peripherals, such as wireless sensors, actuators, displays, etc. Wireless networking can provide low-power, flexible and scalable data transfer over short or long distances.
- Some of the common wired networking protocols for microcontrollers are:
  - CAN (Controller Area Network): A serial bus protocol that allows multiple microcontrollers and devices to communicate with each other without a host computer. CAN is widely used in automotive, industrial and medical applications. CAN supports data rates up to 1 Mbps and can handle up to 2048 nodes on a single network.
  - I2C (Inter-Integrated Circuit): A serial bus protocol that allows multiple microcontrollers and devices to communicate with each other using only two wires: a clock line and a data line. I2C is widely used in embedded systems, sensors and peripherals. I2C supports data rates up to 3.4 Mbps and can handle up to 127 devices on a single bus.
  - Ethernet: A network protocol that allows multiple microcontrollers and devices to communicate with each other using a common physical layer, such as twisted pair, coaxial or optical fiber cables. Ethernet is widely used in local area networks (LANs), internet and cloud computing. Ethernet supports data rates up to 10 Gbps and can handle up to 1024 nodes on a single network.
- Some of the common wireless networking protocols for microcontrollers are:
  - Bluetooth: A wireless protocol that allows microcontrollers and devices to communicate with each other using short-range radio waves. Bluetooth is widely used in personal area networks (PANs), such as wireless headphones, keyboards, mice, etc. Bluetooth supports data rates up to 24 Mbps and can handle up to 7 devices on a single piconet.
  - Wi-Fi: A wireless protocol that allows microcontrollers and devices to communicate with each other using radio waves in the 2.4 GHz or 5 GHz bands. Wi-Fi is widely used in wireless local area networks (WLANs), internet and cloud computing. Wi-Fi supports data rates up to 600 Mbps and can handle up to 255 devices on a single network.
  - LoRa: A wireless protocol that allows microcontrollers and devices to communicate with each other using long-range, low-power radio waves. LoRa is widely used in low-power wide area networks (LPWANs), such as smart cities, agriculture, environment, etc. LoRa supports data rates up to 50 kbps and can handle up to millions of devices on a single network.
