### Python Programming for the notes of the Unit 1 - INTRODUCTION

- Python is a widely used general-purpose, high level programming language that was created by Guido van Rossum in 1991 and further developed by the Python Software Foundation.
- Python has a simple syntax that is similar to the English language and allows developers to write programs with fewer lines of code than some other programming languages.
- Python is an interpreted language, which means that the source code is executed line by line by an interpreter, without the need for compilation.
- Python is a dynamic and strongly typed language, which means that the type of a variable is determined at runtime and can change during the execution of the program.
- Python supports multiple programming paradigms, such as procedural, object-oriented, functional and imperative.
- Python has a large and comprehensive standard library that provides built-in modules for various tasks, such as text processing, file handling, networking, database access, etc.
- Python also supports the use of external modules that can be installed from third-party sources, such as the Python Package Index (PyPI), which contains over 300,000 packages for various purposes.
- Python is a cross-platform language that can run on different operating systems, such as Windows, Mac, Linux, etc.
- Python is widely used for various applications, such as web development, data analysis, machine learning, artificial intelligence, automation, etc .
- Python is an open source language that has a large and active community of developers and users who contribute to its improvement and documentation.
