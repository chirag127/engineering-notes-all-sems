# Python Programming for Microcontrollers

## Unit 1 - Introduction

- Python is a high-level, interpreted, and general-purpose programming language that is widely used for various applications.
- MicroPython is a version of Python that is designed to run on microcontrollers, which are small, low-power, and embedded devices that can interact with sensors, actuators, and other hardware.
- MicroPython is based on Python 3 and supports most of the core Python features, such as data types, control structures, functions, classes, modules, and exceptions.
- MicroPython also provides hardware-specific modules and functions that allow the programmer to access and control the features of the microcontroller, such as GPIO pins, ADC, DAC, PWM, I2C, SPI, UART, and more.
- MicroPython can run on various microcontroller boards, such as the Pyboard, the ESP8266, the ESP32, the BBC Micro:Bit, and others. Each board may have different capabilities and features, so the programmer should consult the documentation of the specific board they are using.
- To program a microcontroller with MicroPython, the programmer needs to connect the board to a computer via a USB cable, and use a serial terminal or an IDE to communicate with the board. The programmer can then write and execute Python code on the board, either interactively or by loading files and modules.
- MicroPython is an open source project that is developed and maintained by a community of volunteers. The official website of MicroPython is https://micropython.org/, where the programmer can find more information, documentation, tutorials, and downloads.
