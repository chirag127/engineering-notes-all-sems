# Raspberry Pi

## Unit 1 - Introduction

### What is a Raspberry Pi?

- A Raspberry Pi is a low-cost, credit-card-sized single-board computer that can connect to a computer monitor or TV, and uses a standard keyboard and mouse.
- It is a capable little device that enables people of all ages to explore computing, and to learn how to program in languages like Scratch and Python.
- It can also interact with a variety of sensors and other modules like LCD displays, servos, and motors.
- It was developed by the Raspberry Pi Foundation, based in the U.K., with the aim of imparting knowledge about computing to even younger students at the cheapest possible price.

### What are the features of a Raspberry Pi?

- A Raspberry Pi has a central processing unit (CPU), a graphics processing unit (GPU), a random access memory (RAM), and various input/output (I/O) ports and connectors.
- The CPU is the brain of the Raspberry Pi, which executes the instructions of the programs. The CPU speed varies depending on the model of the Raspberry Pi.
- The GPU is responsible for rendering the graphics on the screen. The GPU also has a dedicated memory, which is shared with the CPU.
- The RAM is the temporary storage for the data and programs that are currently running on the Raspberry Pi. The RAM size also varies depending on the model of the Raspberry Pi.
- The I/O ports and connectors allow the Raspberry Pi to communicate with other devices, such as keyboards, mice, cameras, speakers, etc. Some of the common I/O ports and connectors are:
  - HDMI port: for connecting to a monitor or TV
  - USB ports: for connecting to keyboards, mice, cameras, etc.
  - Ethernet port: for connecting to a network or the internet
  - Audio jack: for connecting to speakers or headphones
  - GPIO pins: for connecting to sensors and other modules
  - Micro SD card slot: for storing the operating system and files
  - Micro USB power port: for supplying power to the Raspberry Pi

### What are the applications of a Raspberry Pi?

- A Raspberry Pi can be used for a wide range of applications, such as :
  - Learning how to code and program in various languages
  - Making games and animations
  - Creating digital art and music
  - Building robots and smart devices
  - Controlling home appliances and automation
  - Developing web and mobile apps
  - Streaming media and entertainment
  - And much more!
