### Unit 1 - INTRODUCTION: Variables and Flow Control in Programming and Interfacing with Microcontrollers

#### Variables
- A variable is a named storage location in a computer's memory that can hold a value.
- The value of a variable can change during the execution of a program.
- Variables are used to store and manipulate data in a program.
- The type of a variable determines the kind of data it can hold and the operations that can be performed on it.
- Common data types include integers, floating-point numbers, characters, and strings.

#### Flow Control
- Flow control refers to the order in which statements in a program are executed.
- Flow control structures allow a program to make decisions and repeat actions.
- Common flow control structures include if-else statements, for loops, and while loops.
- If-else statements allow a program to make a decision based on a condition.
- For loops and while loops allow a program to repeat a set of statements a specific number of times or until a condition is met.
