## Unit 2 - SOFTWARE FRAMEWORKS

A software framework is a reusable environment that provides a structure for developing software applications. It includes support programs, libraries, and APIs that developers can use to build and manage their applications.

Some key points to consider when discussing software frameworks include:

1. **Abstraction:** Frameworks provide a level of abstraction that allows developers to focus on the unique aspects of their application, rather than the underlying details of the platform or technology.

2. **Reusability:** Frameworks are designed to be reused across multiple projects, reducing the amount of time and effort required to develop new applications.

3. **Extensibility:** Frameworks are often designed to be extensible, allowing developers to add new functionality or modify existing behavior to meet the needs of their application.

4. **Standardization:** Frameworks can help standardize the development process by providing a common set of tools and practices that can be used across multiple projects.

Some popular software frameworks include:

- **Angular:** A front-end framework for building web applications.
- **React:** A JavaScript library for building user interfaces.
- **Django:** A high-level Python web framework that encourages rapid development and clean, pragmatic design.
- **Ruby on Rails:** A web application framework written in the Ruby programming language.
