### Unit 1 - INTRODUCTION: Parts Identification

1. **Microcontroller**: A microcontroller is a small computer on a single integrated circuit that contains a processor core, memory, and programmable input/output peripherals.
2. **Processor**: The processor, also known as the CPU (Central Processing Unit), is the brain of the microcontroller and is responsible for executing instructions.
3. **Memory**: Memory is used to store data and instructions. There are two types of memory in a microcontroller: program memory and data memory.
4. **Input/Output Peripherals**: Input/output peripherals allow the microcontroller to interact with the outside world. Examples of input peripherals include buttons, switches, and sensors. Examples of output peripherals include LEDs, buzzers, and motors.
5. **Power Supply**: The power supply provides the necessary voltage and current to the microcontroller and its peripherals.
6. **Clock**: The clock provides a timing signal to the microcontroller, which is used to synchronize its operations.
7. **Reset Circuit**: The reset circuit is used to reset the microcontroller to its initial state when it is first powered on or when a reset button is pressed.
8. **Programming Interface**: The programming interface is used to load programs onto the microcontroller.
