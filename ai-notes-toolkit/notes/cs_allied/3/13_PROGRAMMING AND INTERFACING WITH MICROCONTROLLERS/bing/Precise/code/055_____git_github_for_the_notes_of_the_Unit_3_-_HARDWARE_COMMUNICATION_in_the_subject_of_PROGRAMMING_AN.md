### Unit 3 - HARDWARE COMMUNICATION: Git/GitHub

1. **Git** is a distributed version control system that allows multiple developers to collaborate on a single codebase.
2. **GitHub** is a web-based platform that uses Git for version control and provides additional features such as issue tracking, project management, and team collaboration.
3. Git allows developers to create and switch between different versions of the code, called **branches**, to work on new features or bug fixes without affecting the main codebase.
4. Changes made to the code are saved as **commits**, which contain a snapshot of the code at a specific point in time along with a message describing the changes made.
5. Developers can **push** their changes to a remote repository, such as one hosted on GitHub, to share their changes with others.
6. Developers can also **pull** changes made by others from the remote repository to update their local copy of the code.
7. Git and GitHub are commonly used in open-source projects, where anyone can contribute to the development of the software.
8. Git and GitHub can also be used in closed-source projects, where access to the code is restricted to a specific group of developers.
9. Git and GitHub provide tools for **code review**, allowing developers to review and comment on each other's changes before they are merged into the main codebase.
10. Git and GitHub also provide tools for **continuous integration** and **continuous deployment**, allowing developers to automatically build, test, and deploy their code changes.
