### C/C++ for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- C and C++ are both programming languages.
- C is a procedural language, while C++ is an object-oriented language.
- C++ is an extension of C, with additional features such as classes, inheritance, and polymorphism.
- Both languages are widely used for system programming, including the development of operating systems and device drivers.
- C and C++ are also used for developing applications, including desktop, mobile, and web applications.
- C and C++ have a rich set of libraries and frameworks that can be used to develop software.
- Some popular C and C++ frameworks include the Standard Template Library (STL) for C++, and the C Standard Library for C.
- C and C++ are also used for interfacing with microcontrollers, which are small computers used in embedded systems.
- C and C++ can be used to write low-level code that interacts directly with the hardware of a microcontroller.
- C and C++ are widely used in the development of firmware for microcontrollers, which is the software that controls the behavior of the microcontroller and its peripherals.
- C and C++ are also used to develop software that runs on microcontrollers, including applications that interact with sensors, actuators, and other hardware.
- C and C++ provide a high level of control over the hardware, making them well-suited for developing software for microcontrollers.
