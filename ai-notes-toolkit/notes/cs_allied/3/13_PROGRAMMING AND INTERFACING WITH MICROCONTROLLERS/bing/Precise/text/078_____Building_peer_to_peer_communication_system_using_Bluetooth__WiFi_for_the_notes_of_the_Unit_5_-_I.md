### Building peer to peer communication system using Bluetooth & WiFi for the notes of the Unit 5 - IoT, FUTURE AND PERSPECTIVES

1. **Introduction:** Peer-to-peer (P2P) communication is a type of networking where devices communicate directly with each other without the need for a central server. This can be achieved using various wireless technologies such as Bluetooth and WiFi.

2. **Bluetooth:** Bluetooth is a short-range wireless technology that allows devices to communicate with each other over a distance of up to 100 meters. It is commonly used for wireless communication between devices such as smartphones, tablets, and laptops.

3. **WiFi:** WiFi is a wireless networking technology that allows devices to communicate with each other over a local area network (LAN). It is commonly used for wireless internet access and can also be used for P2P communication between devices.

4. **P2P communication using Bluetooth:** To establish a P2P communication using Bluetooth, the devices must first be paired. This involves exchanging a security key between the devices to establish a secure connection. Once paired, the devices can communicate directly with each other using the Bluetooth protocol.

5. **P2P communication using WiFi:** To establish a P2P communication using WiFi, the devices must be connected to the same WiFi network. This can be achieved by configuring the devices to connect to the same wireless access point or by creating an ad-hoc network between the devices. Once connected, the devices can communicate directly with each other using the WiFi protocol.

6. **Applications:** P2P communication using Bluetooth and WiFi has many applications, including file sharing, multiplayer gaming, and remote control. It is also used in IoT (Internet of Things) applications to allow devices to communicate with each other and share data.

7. **Conclusion:** Building a P2P communication system using Bluetooth and WiFi is a useful and practical way to enable direct communication between devices. It has many applications and is an important technology in the field of IoT.
