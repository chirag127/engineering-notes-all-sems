### Unit 3 - HARDWARE COMMUNICATION: Git/GitHub

1. **Git** is a distributed version control system that allows multiple developers to collaborate on a project.
2. **GitHub** is a web-based platform that uses Git for version control and provides a place for developers to host and share their code.
3. Git allows developers to track changes to their code, create branches to work on new features, and merge changes from different branches.
4. GitHub provides additional features such as issue tracking, project management, and team collaboration tools.
5. Git and GitHub are commonly used in software development, but can also be used for managing and collaborating on other types of projects.
6. To use Git, developers must first install it on their local machine and configure it with their user information.
7. Basic Git commands include `git init` to initialize a new repository, `git add` to stage changes, `git commit` to save changes, and `git push` to upload changes to a remote repository.
8. GitHub provides a user-friendly interface for managing repositories, creating pull requests, and reviewing code changes.
9. Git and GitHub can be used with various programming languages and development environments, including microcontroller programming and interfacing.
10. Using Git and GitHub can improve the efficiency and organization of hardware communication projects by allowing developers to track changes, collaborate, and share their work.
