# Unit 3 - HARDWARE COMMUNICATION: Git/GitHub

1. **Git** is a distributed version control system that allows multiple developers to collaborate on a project.
2. **GitHub** is a web-based platform that uses Git for version control and provides a place for developers to host and share their code.
3. Git allows developers to track changes to their code, revert to previous versions, and create branches to work on new features without affecting the main codebase.
4. GitHub provides additional features such as issue tracking, project management, and team collaboration tools.
5. Git and GitHub are commonly used in software development, but can also be used for managing any type of project that involves collaborative editing of files.
6. To use Git, developers must first install it on their local machine and configure it with their user information.
7. Developers can then create a new repository or clone an existing one from GitHub or another remote repository.
8. Changes to the code are committed to the local repository and can be pushed to the remote repository on GitHub.
9. Other developers can then pull the changes from the remote repository and merge them into their local repository.
10. Conflicts can arise when multiple developers make changes to the same code, but Git provides tools for resolving these conflicts and merging the changes.
