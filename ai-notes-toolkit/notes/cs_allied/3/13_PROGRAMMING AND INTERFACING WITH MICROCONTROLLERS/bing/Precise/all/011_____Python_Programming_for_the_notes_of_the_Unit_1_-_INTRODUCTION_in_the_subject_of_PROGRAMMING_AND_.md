# Unit 1 - INTRODUCTION

### Python Programming

- Python is a high-level, interpreted, and general-purpose programming language.
- It was created by Guido van Rossum and first released in 1991.
- Python's design philosophy emphasizes code readability and ease of use, with its use of significant whitespace.
- Its language constructs and object-oriented approach aim to help programmers write clear, logical code for small and large-scale projects.
- Python is dynamically typed and garbage-collected, which means that the programmer does not have to explicitly declare the data type of a variable or manage memory allocation.
- It supports multiple programming paradigms, including procedural, object-oriented, and functional programming.
- Python has a large and comprehensive standard library, which provides tools for a wide range of tasks, including string manipulation, data processing, and web development.
- It is widely used in various fields, including scientific computing, data analysis, artificial intelligence, and web development.
- Python has a large and active community, which contributes to its development and provides support to its users.
