### Unit 1 - INTRODUCTION: Variables and Flow Control in Programming and Interfacing with Microcontrollers

#### Variables
- A variable is a named location in memory that stores a value.
- The value of a variable can change during the execution of a program.
- Variables have a data type, which determines the type of values that can be stored in the variable.
- Common data types include integers, floating-point numbers, characters, and strings.

#### Flow Control
- Flow control refers to the order in which statements in a program are executed.
- Conditional statements, such as if and else, allow the program to make decisions based on the value of a variable or expression.
- Looping statements, such as for and while, allow the program to repeat a block of code a certain number of times or until a condition is met.
- Functions allow the program to break up code into reusable blocks, which can be called from multiple places in the program.
