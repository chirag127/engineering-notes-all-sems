### Unit 1 - INTRODUCTION

#### Python Programming

1. Python is a high-level, interpreted, general-purpose programming language.
2. It was created by Guido van Rossum and first released in 1991.
3. Python's design philosophy emphasizes code readability, and its syntax allows programmers to express concepts in fewer lines of code than would be possible in languages such as C++ or Java.
4. The language provides constructs intended to enable clear programs on both a small and large scale.
5. Python is dynamically typed and garbage-collected.
6. It supports multiple programming paradigms, including procedural, object-oriented, and functional programming.
7. Python is often described as a "batteries included" language due to its comprehensive standard library.
8. Python interpreters are available for many operating systems.
9. A global community of programmers develops and maintains CPython, a free and open-source reference implementation.
10. A non-profit organization, the Python Software Foundation, manages and directs resources for Python and CPython development.
