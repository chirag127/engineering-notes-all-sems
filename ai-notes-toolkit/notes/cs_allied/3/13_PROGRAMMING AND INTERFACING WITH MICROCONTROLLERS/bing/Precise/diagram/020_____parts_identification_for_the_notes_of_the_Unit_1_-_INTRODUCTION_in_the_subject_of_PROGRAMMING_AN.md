### Unit 1 - INTRODUCTION: Parts Identification

- **Microcontroller**: A microcontroller is a small computer on a single integrated circuit that is designed to control specific devices or systems.
- **CPU**: The Central Processing Unit (CPU) is the part of the microcontroller that executes instructions and performs calculations.
- **Memory**: Memory is used to store data and program instructions. There are two types of memory in a microcontroller: program memory and data memory.
- **Input/Output Ports**: Input/Output (I/O) ports are used to connect the microcontroller to external devices. These ports can be configured as inputs to read data from sensors or as outputs to control actuators.
- **Timers and Counters**: Timers and counters are used to measure time intervals and count events. They can be used to generate precise time delays or to measure the frequency of a signal.
- **Analog to Digital Converter**: An Analog to Digital Converter (ADC) is used to convert an analog signal into a digital value. This is useful when reading data from analog sensors.
- **Serial Communication Interface**: A serial communication interface is used to exchange data between the microcontroller and other devices. Common serial communication protocols include UART, SPI, and I2C.
- **Interrupts**: Interrupts are used to temporarily halt the normal execution of the microcontroller and execute a specific routine. This is useful when an external event needs to be handled immediately.
