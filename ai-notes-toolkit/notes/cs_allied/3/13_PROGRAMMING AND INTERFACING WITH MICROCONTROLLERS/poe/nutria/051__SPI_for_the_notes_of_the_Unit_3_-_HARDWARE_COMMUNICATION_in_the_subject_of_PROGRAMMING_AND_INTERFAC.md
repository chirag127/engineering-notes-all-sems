
### SPI for the notes of the Unit 3 - HARDWARE COMMUNICATION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

* SPI stands for Serial Peripheral Interface and is a communication protocol used to transfer data between two or more devices. 
* It is a full-duplex protocol, meaning that data can be sent and received simultaneously. 
* SPI is a synchronous protocol, which means that a clock signal is used to synchronize the data transfer between devices. 
* The SPI protocol requires four wires for communication: a clock wire, a data in wire, a data out wire, and a chip select wire. 
* The clock wire is used to synchronize the data transfer between the devices. 
* The data in wire is used to send data from the master device to the slave device. 
* The data out wire is used to send data from the slave device to the master device. 
* The chip select wire is used to select the slave device that the master device wants to communicate with. 
* The SPI protocol is a master-slave protocol, meaning that one device is designated as the master device, and the other device is designated as the slave device. 
* The master device is responsible for initiating the communication and controlling the data transfer. 
* The slave device is responsible for responding to the communication requests from the master device.
