
### Hardware for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. Microcontrollers are small computer systems that are used to control various electronic devices. 
2. Microcontrollers are usually programmed in a specific language, such as C or assembly. 
3. The microcontroller is connected to other components, such as sensors and actuators, to create a complete system. 
4. To make programming easier, software frameworks are used. 
5. Software frameworks provide a set of tools and libraries that can be used to create applications for microcontrollers. 
6. The most common software frameworks are Arduino, mbed, and PIC microcontrollers. 
7. These frameworks provide a simple way to create applications and make programming easier. 
8. The frameworks also provide access to a wide range of libraries and resources that can be used to create more complex applications.
