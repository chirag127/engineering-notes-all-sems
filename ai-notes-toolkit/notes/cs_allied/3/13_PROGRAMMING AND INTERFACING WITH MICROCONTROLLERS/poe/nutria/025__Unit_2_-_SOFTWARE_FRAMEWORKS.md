
## Unit 2 - SOFTWARE FRAMEWORKS

* Software frameworks are collections of pre-written code that provide a structure for developing applications. 
* They are designed to simplify the development process by providing a set of tools, libraries, and APIs that can be used to develop applications quickly and with little effort. 
* Software frameworks can be divided into two main categories: client-side and server-side. 
* Client-side frameworks are used to create applications that run on the user's device, such as web browsers and mobile devices. 
* Server-side frameworks are used to create applications that run on a web server, such as web applications and web services. 
* Software frameworks are often divided into layers, each of which provides a different set of features and functionality. 
* Common layers include the presentation layer, the business logic layer, and the data access layer. 
* Each layer is responsible for a different aspect of the application and can be used to create applications that are more robust and maintainable.
