### Building peer to peer communication system using Bluetooth & WiFi

Peer to peer communication is an essential aspect of the Internet of Things (IoT) and is used to connect devices directly without the need for a centralized server. This is particularly useful for low power devices that have limited processing power and memory. In this unit, we will explore how to build a peer to peer communication system using Bluetooth and WiFi.

#### Bluetooth

Bluetooth is a wireless communication technology that is widely used for short-range communication between devices. It uses radio waves in the 2.4 GHz frequency range to transmit data between devices. Bluetooth has a range of up to 10 meters and is suitable for connecting devices in close proximity.

Here are the steps to build a peer to peer communication system using Bluetooth:

1. Enable Bluetooth on both devices that need to be connected.
2. Pair the devices by selecting the device name from the list of available devices on the device you want to connect to.
3. Once paired, the devices can communicate with each other using Bluetooth.

#### WiFi

WiFi is a wireless communication technology that is widely used for long-range communication between devices. It uses radio waves in the 2.4 GHz and 5 GHz frequency ranges to transmit data between devices. WiFi has a range of up to 100 meters and is suitable for connecting devices over a larger distance.

Here are the steps to build a peer to peer communication system using WiFi:

1. Connect both devices to the same WiFi network.
2. Obtain the IP address of both devices.
3. Create a socket connection between the devices using the IP address and port number of the destination device.
4. Once the connection is established, the devices can communicate with each other using WiFi.

In conclusion, building a peer to peer communication system using Bluetooth and WiFi is a simple and efficient way to connect devices without the need for a centralized server. By following the steps outlined above, you can easily build a peer to peer communication system for your IoT devices.
