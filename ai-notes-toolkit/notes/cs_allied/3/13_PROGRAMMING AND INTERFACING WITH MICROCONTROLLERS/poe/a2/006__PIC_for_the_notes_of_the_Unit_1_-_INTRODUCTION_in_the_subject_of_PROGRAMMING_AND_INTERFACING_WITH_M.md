### PIC for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. PIC microcontrollers are 8-bit microcontrollers designed by Microchip Technology.
2. PIC microcontrollers are widely used in many electronic applications and projects due to their low-cost, wide availability, large user base, extensive collection of application notes, availability of low-cost or free development tools, and serial programming capability.
3. The PIC microcontroller family includes over 900 variations of microcontrollers with different memory, peripheral, and speed variations.
4. The PIC microcontroller architecture is based on the Harvard architecture with a separate instruction memory bus and data memory bus. This improves the bandwidth for both accessing instructions and reading/writing data.
5. PIC microcontrollers use RISC architecture which requires fewer instructions per program as compared to CISC architecture, leading to faster execution of instructions.
6. The PIC programming language is called PIC Assembly or PIC Assembly Language (PAL). However, many high-level languages such as C, BASIC, and Pascal are also available to program PIC microcontrollers.
7. PICkit is a low-cost development programmer tool used to program PIC microcontrollers. It can be connected to a PC to download the program code to the PIC microcontrollers.
