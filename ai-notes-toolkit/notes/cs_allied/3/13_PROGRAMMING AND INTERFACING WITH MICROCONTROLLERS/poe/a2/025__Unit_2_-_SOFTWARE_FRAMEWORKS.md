## Unit 2 - SOFTWARE FRAMEWORKS

1. Software frameworks are reusable code libraries that provide generic functionality for common software tasks. They provide a generic set of interfaces and abstract classes and make it easier and quicker to develop software applications.

2. Some benefits of using software frameworks are:
- Increased productivity due to reuse of code
- Better quality software as the frameworks are well tested
- Reduced time to market as a lot of functionality is pre-built
- Consistency in software applications built using the same framework leading to easier maintenance

3. Examples of software frameworks are:
- Spring framework for enterprise Java applications
- Django and Flask for web development using Python
- Angular and React for front-end web development
- Node.js for back-end JavaScript applications
- .NET framework from Microsoft for enterprise applications

4. When evaluating software frameworks, some key criteria to consider are:
- Language and platform support: Ensure the framework supports your chosen programming language and deployment platform
- Community and documentation: Look at the size and activity of the developer community and quality of documentation to get help
- Licensing and commercial support: Check if the framework is open source or commercial and the availability of paid support if required
- Performance: Evaluate the performance and scalability of the framework for your application requirements
- Learning curve: Assess the ease of learning and using the framework with your team's skills and timelines
