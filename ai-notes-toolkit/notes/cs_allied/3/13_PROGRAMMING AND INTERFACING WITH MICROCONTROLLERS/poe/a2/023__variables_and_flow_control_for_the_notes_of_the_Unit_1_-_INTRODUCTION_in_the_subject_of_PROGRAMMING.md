### Variables and Flow Control

- Variables: Variables are used to store data temporarily in the memory. They have a name and a value. The name is used to access the value stored in it. Variables can be of multiple types like int, float, char, etc. depending on the type of data to be stored.
- Flow Control: The flow of execution of a program can be controlled using flow control statements. The major types are:

1. Sequence: Statements are executed sequentially one after the other in the order they appear in the code.
2. Selection: Conditional execution of code is done using if-else statements and switch statements. If a particular condition is met, a block of code is executed.
3. Looping: A set of statements is executed repeatedly until a condition is met using loops like for loop, while loop and do-while loop. Looping is used to repeat a block of code.

The flow control statements alter the flow of execution of a program based on conditions and ensure that the right block of code is executed at the right time. Proper use of flow control and variables makes a program efficient, bug-free and easy to understand.
