### Saving Data and Preferences for Notes on Unit 4 - Advanced I/O Interfacing

1. EEPROM: Electrically Erasable Programmable Read-Only Memory
- Non-volatile memory that can be reprogrammed by applying an electric voltage
- Retains data even after power cycle
- Limited number of write cycles (10,000-100,000)
- Used to store:
    - Configuration settings
    - Calibration values
    - User preferences

2. Flash Memory
- Also non-volatile
- Can be quickly reprogrammed and erased electronically
- Higher number of write cycles than EEPROM (100,000-1,000,000+)
- Often used for data and program storage
- More expensive than EEPROM

3. SD Cards
- Provide removable flash-based storage
- Very high capacity storage (GB-TB range)
- Can be used to store:
    - Data logs
    - User files (images, audio, documents)
    - Program storage for updating microcontroller firmware
- Requires interface hardware and software to integrate with microcontrollers

This content summarizes some common ways to save data and preferences when working with microcontrollers. The options cover different use cases in terms of capacity, cost, and number of write cycles. The choice of storage method depends on the specific application and requirements.
