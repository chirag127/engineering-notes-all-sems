### Database interface for the notes of the Unit 4 - ADVANCED I/O INTERFACING

1. Introduction
- Database is a organized collection of data stored and accessed electronically from a computer system.
- Database interface is the software that interacts with the database and allows the user to access the data.
- For microcontrollers, the data can be stored in the internal memory or external EEPROM and the database interface can be written in the programming language used for the microcontroller.

2. Steps to create a database interface
- Define the data to be stored - Decide on the variables and data types of the quantities to store in the database.
- Choose a database structure - Can be array, struct, etc. Define the organization of the data.
- Create functions to initialize, read, update and delete - Write functions to initially set up the database, to read the values from database, to update the values in the database and to delete the database.
- Error handling - Include steps to handle errors and invalid inputs.
