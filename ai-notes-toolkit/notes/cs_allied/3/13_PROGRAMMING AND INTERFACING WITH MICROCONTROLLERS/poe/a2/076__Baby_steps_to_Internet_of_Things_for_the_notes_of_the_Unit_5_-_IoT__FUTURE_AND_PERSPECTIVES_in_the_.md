### Baby steps to Internet of Things for the notes of the Unit 5 - IoT, FUTURE AND PERSPECTIVES in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. Introduction to IoT
- IoT refers to the interconnection of everyday physical objects and appliances via the internet.
- These devices are equipped with sensors, software and network connectivity that allow them to send and receive data.
- IoT enables everyday objects to be sensed and controlled remotely across existing network infrastructure.

2. IoT Architecture
- The key components of an IoT system are:
-- Sensors and actuators: Convert physical inputs to digital data and vice-versa
-- Connectivity: Wired or wireless network connectivity to transmit data
-- Cloud: Store, process and analyze data using computing resources
-- Applications: Access data and control devices using apps or interfaces

3. IoT Protocols
- IoT systems use a variety of protocols at different layers to enable devices, networks and applications to communicate with each other.
- Some common IoT protocols are:
-- MQTT, CoAP: Lightweight messaging protocols for device communications
-- HTTP, WebSockets: For web connectivity and data transmission
-- Zigbee, Bluetooth, Wi-Fi: For local wireless connectivity between devices
-- cellular (4G/5G), LoRaWAN: For wide area network connectivity
