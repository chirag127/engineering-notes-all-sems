### Raspberry Pi for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. Raspberry Pi is a small single-board computer developed in the UK by the Raspberry Pi Foundation to promote teaching of basic computer science in schools and developing countries.
2. It provides a small and inexpensive platform to learn programming and interfacing with hardware.
3. It comes with a Broadcom BCM2835 system on a chip (SoC), which includes an ARM1176JZF-S 700 MHz processor, VideoCore IV GPU, and was originally shipped with 256 megabytes of RAM, later upgraded to 512 MB.
4. The Raspberry Pi is capable of running a range of operating systems, including Raspbian, a Debian-based Linux distribution. It has USB and Ethernet ports, an SD card slot, and a HDMI output to connect to a display.
5. It can be used for various electronic and education purposes, including robotics, automation, and remote monitoring. The small size and low cost make it ideal for embedded systems and IoT applications.
6. Some of the software frameworks and libraries available for Raspberry Pi application development are:
    - Python: The Raspberry Pi supports Python and comes with the Pygame and Tkinter libraries pre-installed.
    - Java: The Pi4J library provides APIs for interacting with the GPIO pins and other inputs/outputs using Java.
    - Node.js: The Johnny-Five and Onion Omega libraries enable programming the Raspberry Pi in Node.js.
    - C/C++: The WiringPi and BCM2835 libraries allow interfacing with the Raspberry Pi in C/C++.
