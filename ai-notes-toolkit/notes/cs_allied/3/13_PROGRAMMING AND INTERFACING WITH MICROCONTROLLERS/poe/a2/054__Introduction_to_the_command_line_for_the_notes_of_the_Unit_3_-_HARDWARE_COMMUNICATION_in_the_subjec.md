### Introduction to the command line for the notes of the Unit 3 - HARDWARE COMMUNICATION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. The command line interface (CLI) is a text-based interface to operating system where users can input commands to perform specific tasks.
2. It is an alternative to using a graphical user interface (GUI).
3. The commands are entered via a prompt, and the system responds by executing the command and displaying its output.
4. Basic commands include:
 - cd - Change directory - to change the current directory
 - ls - List - to list files and directories
 - mkdir - Make directory - to create a new directory
 - rm - Remove - to delete files and directories
 - touch - Create - to create or update a file
 - man - Manual - to read documentation for a command
5. The CLI may seem archaic in this era of graphical user interfaces, but it provides some advantages:
    - Speed and efficiency - more direct way to execute tasks without navigating through menus
    - Scripting and automation - allows commands to be grouped and automated
    - Remote access - ability to access system and run commands from another location
6. To get started with the command line, you will first need a terminal emulator - a program that provides access to the command line interface. Popular options include Terminal on macOS, CMD on Windows, and GNOME Terminal on Linux. Then you can start exploring the different commands and their uses.
