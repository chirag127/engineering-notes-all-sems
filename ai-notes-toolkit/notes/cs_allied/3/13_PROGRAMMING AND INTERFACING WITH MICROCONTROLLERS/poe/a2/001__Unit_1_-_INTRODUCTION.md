## Unit 1 - INTRODUCTION

1. Introduction to Programming
- Programming is the process of creating a set of instructions for a computer to follow in order to solve a problem or achieve some goal.
- The program is written in a programming language which is translated into machine language that a computer can execute.
- There are many different programming languages that are designed to solve different types of problems.
- Programming allows us to create applications, algorithms, and automation to solve complex problems.

2. How Computers Work
- At a high level, computers receive input, store and manipulate data, and provide output in a process known as the input-process-output cycle or IPO cycle.
- The key components of a computer include input devices, output devices, memory, processors, and storage.
- Data is represented in a computer using the binary numeral system with only 0s and 1s which is more resilient to errors and is easier for computers to process than other bases.
- Programs are a set of instructions stored in the computer's memory that tell the computer exactly what steps to take and what order to take them in to solve a problem or achieve a goal.
