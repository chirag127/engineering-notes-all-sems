### Wired/Wireless Networking

#### Wired Networking
- Physical connection between devices using cables
- Fast speed and reliable
- Limited by cable length
- Examples: Ethernet, Token Ring

#### Wireless Networking
- No physical cables, uses radio waves
- Convenient but can be unreliable
- Speed and range can vary
- Examples: WiFi, Bluetooth, Zigbee

To set up a wired network:
- Connect devices to a router using Ethernet cables
- Configure router and device settings to be on the same network with unique IP addresses
- Test network connectivity

To set up a wireless network:
- Connect router to internet source and power
- Configure router wireless settings (SSID, password, security)
- Connect devices to wireless network using SSID and password
- Test wireless connectivity and speed

Factors affecting wireless performance:
- Distance from access point
- Interference (physical obstructions, other wireless networks)
- Wireless signal strength
- Device compatibility
