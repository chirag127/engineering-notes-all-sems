### PHP/Web for the notes of the Unit 4 - ADVANCED I/O INTERFACING

1. PHP is a server-side scripting language primarily suited for web development.
2. It can be embedded into HTML code and interpreted by a web server with a PHP processor module.
3. PHP scripts are executed on the server, and the results are sent to the browser as plain HTML.
4. PHP can collect form data, generate dynamic page content, and modify/create cookies and sessions.
5. PHP can interface with databases like MySQL and PostgreSQL to store and retrieve data.
6. For interfacing microcontrollers to the web, PHP scripts can be used to receive data from the microcontroller and display it on a web page. The microcontroller can send data to the PHP script running on the web server using HTTP GET or POST requests.
7. The PHP script can then process the received data and store it in a database or display it on the web page. This allows the microcontroller to send sensor data to a web server to create an Internet of Things application.
