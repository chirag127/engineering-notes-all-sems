### MySQL for the notes of the Unit 4 - ADVANCED I/O INTERFACING

1. MySQL is an open-source relational database management system (RDBMS). It is designed for storing and retrieving data and can be easily integrated into websites.
2. It uses SQL (Structured Query Language) for accessing and manipulating the database. SQL is a standard language for relational database management systems.
3. Some key features of MySQL are:
- Open source and free to use under the GNU General Public License.
- Portable and easy to integrate with multiple platforms and languages like PHP, Python, C, C++, Java, etc.
- Secure and robust with features like access control and authentication mechanisms.
- Scalable and capable of handling large volumes of data and transactions.
- Provides APIs for different languages to connect to MySQL.
4. To access MySQL database from a microcontroller, we need to:
- Install MySQL database on a system.
- Connect the microcontroller to the system running MySQL database.
- Write code for the microcontroller to access the database using MySQL client libraries and APIs.
- The microcontroller can send SQL queries to perform operations like creating, reading, updating and deleting database entries.
