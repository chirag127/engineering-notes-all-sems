### Microcontrollers for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. Microcontroller: A microcontroller is a small computer on a single integrated circuit containing a processor core, memory, and programmable input/output peripherals. Program memory in the form of NOR flash or OTP ROM is also often included on chip, as well as a typically small amount of RAM.

2. Microcontroller Applications: Microcontrollers are used in automatically controlled products and devices, such as automobile engine control systems, implantable medical devices, remote controls, office machines, appliances, power tools, and other embedded systems.

3. Programming a Microcontroller: Microcontrollers are programmed using various programming languages and programming techniques like:
- Assembly language: Low-level language specific to a processor architecture.
- C/C++: General-purpose programming languages.
- Arduino IDE: Easy to use programming environment based on C/C++.
The program is compiled and then transferred to the microcontroller, which executes the instructions.

4. Interfacing with Microcontrollers: Microcontrollers interact with the outside world using specific hardware interfaces for:
- Inputs: Buttons, switches, sensors, etc.
- Outputs: LEDs, motors, displays, etc.
- Communications: UART, I2C, SPI, USB, etc.
The interfaces are configured and controlled by software running on the microcontroller.
