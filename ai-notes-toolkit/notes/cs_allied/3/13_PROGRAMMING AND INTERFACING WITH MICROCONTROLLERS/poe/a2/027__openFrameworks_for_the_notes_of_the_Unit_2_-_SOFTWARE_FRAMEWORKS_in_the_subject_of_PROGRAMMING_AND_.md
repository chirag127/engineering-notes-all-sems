### openFrameworks for the notes of the Unit 2 - SOFTWARE FRAMEWORKS

- openFrameworks is a C++ software framework designed for creative coding. It is open source and cross platform, intended for artists, designers and developers.
- It provides a simple and consistent structure for developing interactive graphics and audio applications. It wraps up a collection of libraries including OpenGL for graphics, OpenAL for audio, FreeType for fonts and more.
- Some key features of openFrameworks are:
-- Cross platform support: Works on Windows, macOS and Linux.
-- Simple and easy to use: Has a minimal and intuitive structure.
-- OpenGL accelerated: Has wrappers for OpenGL to easily create graphics.
-- Large community: Has a large and supportive community forum and lots of examples.
-- Extensible: Can add own libraries or use many additional libraries created by the community.
-- Open source and free: The source code is freely available on GitHub under the MIT license.
- openFrameworks can be used to create a wide variety of applications like interactive art installations, data visualizations, projection mapping, computer vision and more. It is a good option for learning programming concepts and creative coding.
