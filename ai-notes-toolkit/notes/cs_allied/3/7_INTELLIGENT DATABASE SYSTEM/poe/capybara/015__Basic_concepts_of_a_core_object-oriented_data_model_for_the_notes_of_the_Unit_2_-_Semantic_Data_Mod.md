### Basic Concepts of a Core Object-Oriented Data Model

In the realm of Semantic Data Models, Object-Oriented Data Models (OODM) play a crucial role. Here are some basic concepts related to OODM for the notes of Unit 2 in the subject, Intelligent Database System:

- **Objects** - OODM revolves around the concept of objects, which are instances of classes. An object has a unique identity, attributes, and can perform actions through its methods.
- **Classes** - A class is a blueprint for creating objects. It defines the attributes and methods that an object can have. A class can have subclasses and can inherit properties from its parent class.
- **Inheritance** - Inheritance is a mechanism by which a class can inherit properties and methods from its parent class. This helps to reduce redundancy and improve code reusability.
- **Polymorphism** - Polymorphism refers to the ability of objects of different classes to be used interchangeably. This is achieved through method overriding and method overloading.
- **Encapsulation** - Encapsulation refers to the practice of hiding the internal details of an object from the outside world. This helps to maintain the integrity of the object and its data.
- **Abstraction** - Abstraction involves the extraction of essential features of an object, while ignoring its non-essential details. This helps to simplify the design and implementation of the system.

By mastering these basic concepts of a core Object-Oriented Data Model, you can lay a strong foundation for understanding more complex concepts and applications of Semantic Data Models.
