### The nested relational model for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. The nested relational model is an extension of the relational model.
2. In the nested relational model, relations can have relations as attribute values. These embedded relations are called nested relations.
3. Allowing nested relations removes the constraint that all relations must be made up of atomic values.
4. The nested relational model is well suited for representing hierarchical data and for modeling "has-a" and "part-of" relationships between entities.
5. The nested relational model can capture additional semantics in the data that cannot be easily represented in the standard relational model.
6. The nested relational model increases the expressive power of the relational model at the cost of increased complexity in processing nested relations.
7. The nested relational model forms the basis for the object-relational database systems that are widely used in practice.
