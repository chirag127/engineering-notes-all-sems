### Query languages and query processing

1. Query languages: Languages used to retrieve data from databases. Examples are SQL, XQuery, etc.
- They allow users to specify what data they want and in what format.
- They should be easy to learn and use, understandable, and flexible.
- They go through a compiler that converts the query into an optimal execution plan.

2. Query processing: The process of executing a query and returning results to the user. It involves the following steps:

- Query optimization: Choosing the most efficient way to execute the query. It considers the available access paths and chooses the least cost one.
- Query evaluation: This step uses the optimized query plan to get the query results. It accesses the data and performs selections/projections as needed.
- Result formatting: The output is formatted as per the query and returned to the user.

The goal of query processing is fast and efficient retrieval of only the desired data. It is a key function of database systems to support users and applications.
