### Data mining for the notes of the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM.

1. Data mining is the process of discovering patterns in large data sets in order to extract useful information and insights.

2. Some of the core steps in data mining process are:

- Data Collection: Gathering data from various sources.
- Data Preprocessing: Cleaning and preparing the data. Eg. handling missing values, outliers, etc.
- Data Transformation: Converting the data into appropriate forms for mining. Eg. discretization, normalization, etc.
- Data Mining: Applying algorithms to extract patterns from the data.
- Pattern Evaluation: Evaluating and interpreting the mined patterns.
- Knowledge Presentation: Presenting the data in a understandable format.

3. Some of the applications of data mining are:

- Market Basket Analysis: Identifying products frequently bought together.
- Fraud Detection: Identifying suspicious activity or outliers.
- Recommendation Systems: Recommending products or content to users based on their past behaviour and interests.
- Clustering: Grouping similar data points together.
- Classification: Predicting a class or category for new data points.
- Regression: Predicting a value for new data points.

4. The goal of data mining in intelligent database systems is to extract hidden predictive information from large databases in order to make proactive knowledge-driven decisions. Data mining helps in gaining business intelligence and competitive advantages.
