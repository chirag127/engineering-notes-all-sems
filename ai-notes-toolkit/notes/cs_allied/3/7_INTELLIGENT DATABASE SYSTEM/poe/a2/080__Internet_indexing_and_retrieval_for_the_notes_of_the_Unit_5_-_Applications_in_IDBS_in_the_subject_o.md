### Internet indexing and retrieval for the notes of the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM

1. Internet indexing: The process of indexing the data available on the internet is known as internet indexing. The huge amount of data on the internet is indexed by crawlers or spiders which crawl the web pages and index the words or terms into an index. This index is then used to retrieve the relevant data as per the user's query. The indexing is done to make the data retrieval efficient and easy. Some of the popular internet indexing techniques are:
- Breadth-first crawling: Crawls the neighboring web pages first before going into the deeper levels.
- Depth-first crawling: Goes deeper into the web pages level by level.
- Best-first crawling: Crawls the web pages with high connectivity first.

2. Retrieval models: The indexed data is retrieved using various retrieval models like:
- Boolean model: Uses Boolean operators like AND, OR, NOT to retrieve the data.
- Vector space model: Represents each document as a vector of terms and calculates similarity between the query vector and document vectors to retrieve relevant results.
- Probabilistic model: Calculates the probability of a document being relevant to a query and retrieves the documents with highest probability.

3. Evaluation measures: The performance of retrieval systems is evaluated using measures like:
- Precision: Percentage of retrieved documents that are relevant.
- Recall: Percentage of relevant documents that are retrieved.
- F-measure: Harmonic mean of precision and recall.

The content summarizes the key points around internet indexing which involves indexing the web data using crawlers and retrieval of the indexed data using different retrieval models. The performance of the retrieval systems is evaluated using precision, recall and F-measure.
