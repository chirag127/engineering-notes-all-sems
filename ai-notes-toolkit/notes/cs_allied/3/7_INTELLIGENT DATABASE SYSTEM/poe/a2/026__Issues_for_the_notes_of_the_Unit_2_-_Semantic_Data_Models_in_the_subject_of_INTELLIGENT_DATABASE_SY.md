### Issues for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Need for Semantic Data Models
- Traditional relational data models are not sufficient to represent complex data and relationships.
- Semantic data models are required to represent the meaning of data and relationships.
- Semantic data models provide a richer meaning of data.

2. Types of Semantic Data Models
- Object-oriented data models
- Frame-based data models
- Entity-relationship data models
- Graph-based data models

3. Features of Semantic Data Models
- Classes, objects, attributes, methods to represent data and relationships
- Is-a relationships to show inheritance
- Has-a relationships to show compositions
- Explicit representation of relationships
- Support for complex data types and structures

4. Applications of Semantic Data Models
- Artificial Intelligence
- Expert Systems
- Natural Language Processing
- Databases
- Knowledge Representation
