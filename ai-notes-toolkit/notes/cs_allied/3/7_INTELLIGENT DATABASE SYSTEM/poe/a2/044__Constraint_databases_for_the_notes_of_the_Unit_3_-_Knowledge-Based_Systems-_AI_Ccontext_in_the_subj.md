### Constraint databases for the notes of the Unit 3 - Knowledge-Based Systems- AI Ccontext in the subject of INTELLIGENT DATABASE SYSTEM

1. Constraints are restrictions on the possible values that variables can take. They are used to represent domain knowledge in a concise manner.
2. Constraints can be classified into different types:
- Type constraints: Restrict data values to a specific data type, e.g. age must be an integer.
- Range constraints: Restrict data values to a specified range, e.g. age must be between 0 and 120.
- Sum constraints: Restrict the sum of a set of variables to a specific value, e.g. total_cost = cost1 + cost2 + cost3.
- Comparison constraints: Restrict a variable to be greater than, less than or equal to another variable, e.g. salary >= min_salary.
3. Constraint databases allow constraints to be specified in the database schema. The database ensures that only data that satisfies the constraints is inserted or updated in the database.
4. Constraint databases facilitate validation and consistency checking. They are useful for applications where data integrity is critical, e.g. financial, medical, and geographical databases.
5. However, specifying and processing constraints can degrade performance. Also, ensuring consistency and correctness of constraints is difficult. Constraints may conflict with each other or may be too restrictive.
