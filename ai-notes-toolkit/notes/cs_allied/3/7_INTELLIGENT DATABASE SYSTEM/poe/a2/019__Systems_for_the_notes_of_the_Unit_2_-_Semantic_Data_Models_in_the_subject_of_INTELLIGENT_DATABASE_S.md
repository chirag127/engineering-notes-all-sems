### Systems for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Resource Description Framework (RDF):
- RDF is a framework for representing information in the Web.
- It uses statements to represent information in the form of subject-predicate-object expressions (triples).
- The subject denotes the resource, and the predicate denotes traits or aspects of the resource and expresses a relationship between the subject and the object.
- RDF Schema (RDFS) and OWL are built on top of RDF to describe classes and properties used to describe resources.

2. Web Ontology Language (OWL):
- OWL is a semantic markup language for publishing and sharing ontologies on the World Wide Web.
- It is designed for use by applications that need to process the content of information instead of just presenting information to humans.
- OWL facilitates greater machine interpretability of Web content than XML, RDF, and RDFS by providing additional vocabulary along with formal semantics.
- It includes properties and classes, and has facilities for expressing restrictions on properties and classes.

3. SPARQL:
- SPARQL is a query language for RDF.
- It is used to retrieve and manipulate data stored in RDF format.
- SPARQL queries can be used to query required and relevant data from RDF graphs and datasets.
- It is a W3C standard and is supported by many RDF databases and Triplestores.
