### Deductive database systems

- Deductive databases extend relational databases with logic-based capabilities. They provide rules to derive additional facts (implicit knowledge) from explicitly stored data (explicit knowledge).
- Deductive databases allow rules and logical expressions to be stored along with data. New facts can be inferred from the rules and the data.
- Deductive databases provide more expressive power than relational databases and can capture richer semantics about the stored data. They are suitable for domains where implicit relationships between data are important.
- However, deductive databases have some disadvantages:
    - Processing queries can be slower due to the need for rule application.
    - It can be difficult to optimize rule applications.
    - There is a tradeoff between expressiveness and efficiency. Very complex rules can impact performance.
- Some examples of deductive database systems are:
    - LDL++
    - Clark's completion
    - Datalog
- Applications of deductive databases include:
    - Configuration systems
    - Diagnostic systems
    - Design systems
    - Information integration
