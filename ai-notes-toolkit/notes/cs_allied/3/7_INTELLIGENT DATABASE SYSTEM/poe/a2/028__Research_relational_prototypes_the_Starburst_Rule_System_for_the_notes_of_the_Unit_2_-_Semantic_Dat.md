### Research relational prototypes—the Starburst Rule System

- The Starburst project at IBM Research aimed to build an extensible relational database system that could support advanced database applications.
- The Starburst Rule System was designed to allow users to define integrity constraints, triggers, methods, and other database features using a declarative rule language.
- Rules in the Starburst Rule System could be written to refer to the whole database state, including the schema. This allowed the modeling of advanced database features that rely on the schema, such as schema evolution and view management.
- The rule system included a rule optimizer that could reorder and optimize rules. It included features for specifying rules that should not be optimized.
- The Starburst project demonstrated the feasibility and power of rule-based approaches to advanced database features. However, the Starburst system was never commercialized, in part because of the complexity of the rule system.
- The rule approach has influenced subsequent work on extensible database systems, and rule-based systems have been developed for other database features, such as security constraints. However, most commercial database systems today do not provide a general rule facility.
