 Here are the notes on Structured, semi-structured and unstructured data for the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM:

### Structured Data

- Data that conforms to a fixed schema/format.
- Examples: Numeric data, alphanumerical data, dates, etc. stored in tables with predetermined column structure.
- Easy to query and analyze using SQL.
- Databases like MySQL, Oracle, SQL Server handle structured data well.

### Semi-structured Data

- Does not conform to a fixed schema.
- Examples: XML, JSON, HTML, etc.
- Schema can be inferred from the data.
- Data may be self-describing but not strictly typed.
- NoSQL databases like MongoDB can handle semi-structured data effectively.

### Unstructured Data

- Does not have a defined data model or is not organized in a pre-defined manner.
- Examples: Text documents, PDF files, images, audio, video, etc.
- Difficult to query and analyze.
- Requires preprocessing to extract information and derive insights.
- Big data technologies like Hadoop, Spark help analyze unstructured data.
