### Temporal query languages for the notes of the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM.

1. TQuel: It is a temporal query language which extends the standard SQL to support temporal data. It introduces new temporal data types and operators to query the temporal attributes.

Some of the extensions are:

- TEMPORAL TYPE: To specify the start and end time of a temporal tuple.
- AS OF: To specify the time point at which the database is to be queried.
- BETWEEN: To specify a time interval.
- CONTAINS: To check if a time interval contains another time interval.

2. TSQL2: It is also a temporal extension of SQL which provides additional temporal data types and predicates. Some of the key extensions are:

- TIMESTAMP data type: To store time-varying data.
- COMPARISON predicates on timestamps: =, <, >, <>, >=, <=.
- TEMPORAL EXISTS and TEMPORAL SELECT: To query temporal data.
- modifiers: AS OF, FROM, TO, BETWEEN, Contains.

3. Other temporal query languages: There are few other temporal query languages as well like Starburst's Temporal SQL, MySQL's Temporal Engine, etc. But TQuel and TSQL2 are the most popular and widely used temporal query languages.
