### Internet spiders for the notes of the Unit 5 - Applications in IDBS

1. Internet spiders or web crawlers are programs that browse the World Wide Web in a methodical, automated manner.
2. They are mainly used to create a copy of all the visited pages for later processing by a search engine.
3. The pages are downloaded and indexed to create large databases that are used to power the search engine.
4. The major tasks performed by a web crawler are:
- Fetch a URL from the queue of unvisited URLs.
- Download and parse the contents of the web page at the URL.
- Extract useful information like keywords, links etc. from the web page.
- Add the links found in the web page to the queue of unvisited URLs.
- Re-enqueue links marked for revisiting.
- Update the search engine's database with information from the downloaded page.
5. The efficiency and performance of a web crawler depends on parameters like network bandwidth, number of simultaneous downloads, politeness delay, parsing speed etc.
6. Distributed and multithreaded crawlers with optimizations like URL filters and bloom filters are used by large search engines to crawl the web efficiently.
