## Unit 5 - Applications in IDBS

1. Database Management Systems
- Databases store and organize data. A Database Management System (DBMS) is software that manages and controls access to a database. Examples of DBMSs include MySQL, Oracle, Microsoft SQL Server, etc.
- A DBMS performs tasks such as creating/deleting tables, views, and indexes; enforcing data integrity constraints; handling user authentication; and optimizing query performance.

2. Data Warehousing
- A data warehouse is a central repository of integrated data from one or more sources. It is designed for querying and analysis rather than for transaction processing.
- Data warehouses contain historical data derived from transaction data, and are optimized for query performance. The processes of extracting data from source systems, transforming it, and then loading it into the data warehouse are together known as ETL.

3. Data Mining
- Data mining is the process of discovering patterns in large data sets in order to extract useful information and insights.
- Some common data mining techniques are clustering, classification, association rule learning, and anomaly detection. Data mining is often used by companies to discover hidden patterns in customer data that can be used for applications such as targeted marketing.

4. Enterprise Resource Planning (ERP)
- An ERP system is business management software that integrates all facets of a business, including planning, purchasing, inventory, sales, marketing, finance, and HR.
- By storing data in a single system and sharing a common database, ERP software can facilitate better communication and data sharing between different departments. This can help reduce redundancy and improve business efficiency. Examples of popular ERP systems include SAP, Oracle ERP, and Microsoft Dynamics.
