### A taxonomy of intelligent database systems for the notes of the Unit 1 - Introduction to IDBS in the subject of INTELLIGENT DATABASE SYSTEM

1. Traditional database systems
- Standard SQL-based database systems
- Limited machine learning capabilities

2. Database systems with machine learning
- Incorporate machine learning models for specific tasks
- e.g. prediction, classification, clustering
- Machine learning models are predefined and static

3. Intelligent database systems
- Combine database technology with artificial intelligence
- Use machine learning to automate multiple tasks
- Machine learning models can be trained on data and evolve over time
- Examples: IBM's Watson, Microsoft's CNTK and TensorFlow

4. Future trends
- Deep integration of machine learning and database systems
- Automation of more and more database tasks (query optimization, schema design, etc.)
- Use of deep learning and reinforcement learning
- Scaling machine learning to large data volumes and high throughput
- Seamless integration of analytical and transactional processing

The above points cover the key types of database systems with a taxonomy from traditional to intelligent database systems along with future trends in this domain.
