### Hyper-semantic data models for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. RDF: Resource Description Framework
- RDF is a framework for representing information in the Web.
- It is a directed, labeled graph data format.
- It is used to represent metadata about Web resources.
- RDF uses URIs to name the nodes and edges of the graph.
- RDFS: RDF Schema - Provides additional vocabulary for describing properties and classes of RDF resources.

2. OWL: Web Ontology Language
- OWL is a semantic markup language for publishing and sharing ontologies on the World Wide Web.
- OWL adds more vocabulary for describing properties and classes: cardinality, equality, richer typing, characteristics of properties, characteristics of classes, etc.
- OWL comes in different flavors with increasing expressivity: OWL Lite, OWL DL, OWL Full.
- OWL DL supports the maximum expressiveness while retaining computational completeness and decidability.

3. SKOS: Simple Knowledge Organization System
- SKOS is a W3C recommendation designed for representation of thesauri, classification schemes, taxonomies, subject heading systems, and other types of structured vocabularies.
- SKOS allows vocabularies to be mapped and aligned to each other.
- The main concepts in SKOS are concepts, concept schemes, and lexical labels.
