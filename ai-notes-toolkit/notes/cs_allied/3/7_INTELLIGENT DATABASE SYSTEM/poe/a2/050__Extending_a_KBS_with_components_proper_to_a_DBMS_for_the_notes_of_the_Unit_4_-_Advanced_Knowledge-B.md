Extending a KBS with components proper to a DBMS for the notes of the Unit 4 - Advanced Knowledge-Based Systems in the subject of INTELLIGENT DATABASE SYSTEM:

1. Introduction
- A Knowledge-Based System (KBS) is a system that uses artificial intelligence techniques to solve complex problems that normally require human expertise.
- A Database Management System (DBMS) is a system that manages the storage and retrieval of data from a database.
- Integrating a KBS with components of a DBMS leads to an Intelligent Database System (IDS) which provides intelligent access and management of data.

2. Components of a DBMS integrated into a KBS
- Data Definition Language (DDL): To define the data and database schema. Used by a KBS to define its domain knowledge.
- Data Manipulation Language (DML): To query and manipulate data. Used by a KBS to retrieve and update its knowledge base.
- Transaction Management: To handle concurrent access and maintain data consistency. Used by a KBS to handle multiple queries and updates concurrently while maintaining consistency of its knowledge base.
- Security & Authorization: To control access to data. Used by a KBS to control access to its knowledge and reason about access permissions.
- Backup & Recovery: To recover from failures and disasters. Used by a KBS to back up and recover its knowledge base.

3. Advantages of integrating a KBS with DBMS components
- Provides persistent storage for the knowledge base. The knowledge is stored permanently in a database.
- Provides efficient management of large volumes of data (knowledge). DBMS techniques like indexing and caching can be utilized.
- Provides concurrency and robustness. Features like transactions and recovery provide concurrency control and robustness to deal with failures.
- Provides security mechanisms to control access to knowledge. Authorization and access control mechanisms can restrict access to knowledge.
- Standards-based. Using standard DBMS components makes the system more interoperable and compatible with existing databases and applications.
