## Unit 1 - Introduction to IDBS

1. IDBS stands for Integrated Database Management System. It is a software system that manages and facilitates access to large structured data collections.

2. IDBS has a centralized and integrated database which stores and manages data as a single repository. This avoids data redundancy and inconsistency which may occur if data is stored in multiple locations.

3. IDBS provides capabilities to define, query and manipulate data. It allows users to share data and database resources. It provides backup and recovery functions to prevent data loss.

4. The core components of an IDBS are:

- Data Dictionary: Contains metadata about the database such as table definitions and table relationships.
- Data Manipulation Language (DML): Used to add, update, delete and retrieve data. Example: SQL.
- Data Control Language (DCL): Used to control access to data. Example: GRANT and REVOKE statements in SQL.
- Data Definition Language (DDL): Used to define database schemas. Example: CREATE, ALTER, DROP statements in SQL.
- Query Language: Used to retrieve data from the database. Example: SQL.

5. IDBS has a multi-user and multi-tasking architecture. It allows multiple users to access the database simultaneously while ensuring data integrity, security and consistency. It handles memory and process management to prevent issues like deadlocks that may occur with concurrent access.

6. Popular commercial IDBS products are Oracle Database, Microsoft SQL Server, IBM DB2, etc. Open-source IDBS include MySQL, PostgreSQL, etc. IDBS are widely used to store and manage data in applications such as banking systems, airline reservation systems, enterprise resource planning systems, etc.
