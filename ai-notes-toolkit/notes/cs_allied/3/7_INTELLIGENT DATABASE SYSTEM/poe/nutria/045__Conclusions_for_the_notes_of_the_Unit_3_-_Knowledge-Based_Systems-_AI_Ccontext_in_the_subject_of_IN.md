
### Conclusions for the notes of the Unit 3 - Knowledge-Based Systems- AI Ccontext in the subject of INTELLIGENT DATABASE SYSTEM

1. Knowledge-based systems are computer systems that are designed to store, reason with and act on knowledge.
2. AI context is the application of AI techniques to the development of knowledge-based systems.
3. AI techniques such as natural language processing, machine learning and deep learning can be used to develop knowledge-based systems.
4. Knowledge-based systems are used in many different areas, such as healthcare, finance, and robotics.
5. Knowledge-based systems can be used to automate processes and reduce the need for human intervention.
6. Knowledge-based systems can be used to make decisions based on data, which can improve decision-making accuracy.
7. Knowledge-based systems can be used to create intelligent databases that can store, query and analyze data.
8. Knowledge-based systems can be used to create intelligent agents that can interact with users and provide personalized services.
