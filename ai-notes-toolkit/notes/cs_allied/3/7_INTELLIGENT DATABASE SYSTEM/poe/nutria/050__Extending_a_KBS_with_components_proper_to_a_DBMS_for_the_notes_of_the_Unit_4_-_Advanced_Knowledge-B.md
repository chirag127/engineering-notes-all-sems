
### Extending a KBS with components proper to a DBMS 

1. Knowledge-based systems (KBS) are artificial intelligence (AI) systems that are used to store and retrieve knowledge.
2. KBSs are typically structured as a hierarchy of rules and facts, and can be used to answer questions or provide advice.
3. A KBS can be extended with components proper to a database management system (DBMS) such as triggers, stored procedures and views.
4. Triggers are pieces of code that are executed when certain conditions are met. They can be used to automate tasks or to ensure data integrity.
5. Stored procedures are pre-compiled pieces of code that can be used to perform complex operations on a database.
6. Views are virtual tables that can be used to simplify the structure of a database and to provide an abstraction layer for users.
7. By extending a KBS with components proper to a DBMS, it is possible to create a powerful system that can be used to store, retrieve and manipulate knowledge.
