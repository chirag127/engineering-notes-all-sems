
## Unit 1 - Introduction to IDBS

1. **What is IDBS?** IDBS stands for Integrated Database System. It is a comprehensive database system that provides a single platform for the storage, retrieval, and analysis of data. 

2. **What are the components of IDBS?** IDBS consists of three main components: the Database Management System (DBMS), the Data Dictionary (DD), and the Query Language (QL). 

3. **What are the benefits of using IDBS?** IDBS provides a single platform for the storage, retrieval, and analysis of data. It also provides a secure and consistent platform for the management of data. Additionally, IDBS allows for the integration of multiple data sources, making it easier to access and analyze data from different sources. Finally, IDBS enables the user to easily create and modify data structures, making it easier to manage and analyze data.
