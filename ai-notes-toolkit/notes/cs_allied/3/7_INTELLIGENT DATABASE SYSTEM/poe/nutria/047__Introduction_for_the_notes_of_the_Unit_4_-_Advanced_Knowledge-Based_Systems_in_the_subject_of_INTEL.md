
### Introduction for the notes of the Unit 4 - Advanced Knowledge-Based Systems in the subject of INTELLIGENT DATABASE SYSTEM

1. Knowledge-based systems are computerized systems that are designed to store, organize and analyze data in order to provide useful information and insights.
2. These systems can be used to solve problems, make decisions, and provide advice to decision makers.
3. Intelligent database systems are a type of knowledge-based system that uses artificial intelligence (AI) techniques to store, manage and query large databases.
4. Intelligent database systems can be used to identify patterns and relationships in data, as well as to provide insights and recommendations.
5. AI techniques such as machine learning, natural language processing, and cognitive computing are used to extract knowledge from data and to make decisions.
6. Intelligent database systems can be used to improve the accuracy and speed of decision making in a variety of industries.
