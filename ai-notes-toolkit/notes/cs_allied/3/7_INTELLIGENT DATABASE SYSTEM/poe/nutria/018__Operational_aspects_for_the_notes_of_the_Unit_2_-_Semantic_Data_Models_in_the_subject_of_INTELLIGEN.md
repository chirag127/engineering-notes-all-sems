
### Operational aspects for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Semantic data models are used to represent the meaning of data in a database.
2. Semantic data models are used to represent the relationships between different pieces of data.
3. Semantic data models help to identify the data elements that are related to each other.
4. Semantic data models are used to provide a structure to the database which helps to make it easier to query and manipulate the data.
5. Semantic data models are used to represent the data in a way that is understandable by humans.
6. Semantic data models are used to ensure that the data is consistent and accurate.
7. Semantic data models are used to ensure that the data is secure and compliant with the applicable laws and regulations.
8. Semantic data models are used to ensure that the data can be accessed and used in a consistent and efficient manner.
