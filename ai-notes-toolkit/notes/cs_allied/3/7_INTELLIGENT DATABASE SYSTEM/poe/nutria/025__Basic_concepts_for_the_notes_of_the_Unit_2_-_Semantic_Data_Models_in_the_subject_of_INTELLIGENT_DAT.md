
### Basic concepts for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Semantic data models are database models that represent the meaning of data and the relationships between data elements.
2. Semantic data models are used to represent the structure of the data in a database, as well as the relationships between data elements.
3. Semantic data models are based on the concept of entities and relationships. An entity is a real-world object, such as a person, place, or thing, and a relationship is an association between two or more entities.
4. Semantic data models are used to define the structure of a database, which includes the entities, attributes, and relationships that comprise the database.
5. Semantic data models are used to define the rules that govern the data in a database, such as the types of data that can be stored in a database, the relationships between data elements, and the constraints that must be followed.
6. Semantic data models are used to define the access rights to a database, which includes the types of users who can access the database, the types of operations that users can perform on the database, and the types of data that users can access.
