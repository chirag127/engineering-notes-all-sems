### Other projects based on a 'conceptual representation' approach

1. **Cyc**: Cyc is a long-term artificial intelligence project that aims to assemble a comprehensive ontology and knowledge base of everyday common sense knowledge, with the goal of enabling AI applications to perform human-like reasoning.
2. **WordNet**: WordNet is a lexical database for the English language. It groups English words into sets of synonyms called synsets, provides short definitions and usage examples, and records a number of relations among these synonym sets or their members.
3. **ConceptNet**: ConceptNet is a semantic network containing lots of things computers should know about the world, especially when understanding text written by people.
4. **DBpedia**: DBpedia is a project aiming to extract structured content from the information created in the Wikipedia project. This structured information is made available on the World Wide Web and can be used by other applications and services to enrich their data and provide a better user experience.
5. **YAGO**: YAGO is a large semantic knowledge base, derived from Wikipedia, WordNet and GeoNames. It contains information about more than 10 million entities (like people, organizations, cities, etc.) and contains more than 120 million facts about these entities.
