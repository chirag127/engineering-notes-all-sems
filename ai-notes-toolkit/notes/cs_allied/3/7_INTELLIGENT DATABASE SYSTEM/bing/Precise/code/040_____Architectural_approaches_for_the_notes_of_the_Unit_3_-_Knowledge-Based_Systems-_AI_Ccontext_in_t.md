### Architectural approaches for the notes of the Unit 3 - Knowledge-Based Systems- AI Context in the subject of INTELLIGENT DATABASE SYSTEM

1. **Rule-based systems:** These systems use a set of rules to represent the knowledge base. The rules are in the form of IF-THEN statements, where the IF part represents the condition and the THEN part represents the action to be taken if the condition is true.

2. **Frame-based systems:** These systems use frames to represent the knowledge base. A frame is a data structure that represents a stereotypical situation, such as a room in a house. The frame contains slots that represent the attributes of the situation, such as the color of the walls and the type of furniture.

3. **Semantic networks:** These systems use a graph to represent the knowledge base. The nodes in the graph represent concepts and the edges represent relationships between the concepts.

4. **Object-oriented systems:** These systems use objects to represent the knowledge base. An object is an instance of a class, which defines the attributes and methods of the object.

5. **Neural networks:** These systems use a network of artificial neurons to represent the knowledge base. The neurons are connected by weighted links, and the weights are adjusted during training to improve the performance of the system.

6. **Fuzzy systems:** These systems use fuzzy logic to represent the knowledge base. Fuzzy logic allows for the representation of uncertainty and vagueness in the knowledge base.

7. **Expert systems:** These systems use a combination of the above approaches to represent the knowledge base. They often include a rule-based system and a frame-based system, as well as other components such as a natural language processing module and an inference engine.
