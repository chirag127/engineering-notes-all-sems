### Introduction

- Semantic data models are high-level conceptual data models that capture the meaning and structure of data in a domain of interest.
- Semantic data models use concepts such as entities, attributes, relationships, and constraints to represent data and their semantics.
- Semantic data models are more expressive and intuitive than traditional data models, such as relational or hierarchical models, which focus on the physical representation and storage of data.
- Semantic data models can be used for various purposes, such as database design, query formulation, data integration, data analysis, and knowledge representation.
- Semantic data models can be classified into two main categories: object-based and logic-based models.
- Object-based semantic data models use objects as the basic unit of data abstraction. Objects have identity, properties, and behavior. Objects can be organized into classes, hierarchies, and networks. Examples of object-based semantic data models are Entity-Relationship Model, Object-Oriented Model, and Semantic Network Model.
- Logic-based semantic data models use logic as the basis for data representation and manipulation. Logic-based models use predicates, variables, constants, and quantifiers to express facts, rules, and queries about data. Examples of logic-based semantic data models are Functional Data Model, Deductive Database Model, and Ontology Model.
