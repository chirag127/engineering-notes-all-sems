### Disk imaging for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

- Disk imaging is the process of creating an electronic copy of a drive (e.g. a hard drive, USB, etc.) that preserves all the data and metadata in a forensically sound manner .
- A disk image is a bit-by-bit or bitstream file that is an exact, unaltered copy of the media being duplicated . It can be stored in various formats, such as raw, E01, AFF, etc.
- Disk imaging is an essential step in digital forensic investigations, as it allows the examiner to analyze the data without altering or damaging the original evidence .
- Disk imaging can be performed using various tools, such as hardware or software imagers, that can read and write data to a forensics image format . Some examples of disk imaging tools are Tableau TD3, Computer Forensic Tool (CFT), Dc3dd, etc.
- Disk imaging can pose some challenges, such as handling large or encrypted drives, verifying the integrity of the image, dealing with errors or bad sectors, etc. These challenges can be addressed by using appropriate methods and techniques, such as compression, hashing, error handling, etc.
