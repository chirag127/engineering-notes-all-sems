### Port scans

- A port scan is a technique used by cybercriminals to find out information about a system they are going to target .
- A port scan involves scanning through a network system and determining which ports are open, which are sending data, and which are receiving data .
- A port scan can also reveal whether active security devices like firewalls are being used by an organization.
- A port scan is a popular method cyber criminals use to search for vulnerable servers. They often use it to discover organizations’ security levels, determine whether businesses have effective firewalls, and detect vulnerable networks or servers.
- Port scanning is a fundamental part of the pre-attack phase of a penetration test. Ethical hackers and penetration testers frequently use port scanning techniques to locate vulnerabilities in a network that malicious hackers can use to gain access.
- Port scanning techniques can be classified into different types, such as TCP SYN scan, TCP connect scan, TCP ACK scan, TCP FIN scan, TCP Xmas scan, TCP NULL scan, UDP scan, and stealth scan.
- Port scanning can be detected by monitoring network traffic and looking for signs of abnormal or suspicious activity, such as a large number of packets sent to different ports, packets with unusual flags or options, or packets from unknown or spoofed sources.
- Port scanning can be prevented by using firewalls, intrusion detection systems, intrusion prevention systems, or honeypots to block, alert, or deceive port scan attempts.
