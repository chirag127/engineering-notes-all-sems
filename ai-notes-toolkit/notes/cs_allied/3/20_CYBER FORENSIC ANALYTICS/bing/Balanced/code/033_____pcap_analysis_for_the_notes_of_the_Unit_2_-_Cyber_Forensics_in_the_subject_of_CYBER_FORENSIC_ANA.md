# PCAP Analysis for the Notes of the Unit 2 - Cyber Forensics

- PCAP stands for Packet Capture, which is a file format that stores network traffic data, including both metadata and content of each packet.
- PCAP analysis is the process of examining the captured network traffic data for forensic purposes, such as identifying, extracting, and preserving digital evidence, detecting malicious network activity and behavior, and investigating cyber incidents and threats.
- PCAP analysis can be performed using various tools, such as Wireshark, Zeek, tcpdump, and ExtraHop Reveal(x) Cloud.
- PCAP analysis can provide valuable insights into the network communication patterns, protocols, devices, applications, and users involved in a cyber event, as well as the content and context of the network traffic.
- PCAP analysis can help forensic investigators to answer questions such as:
  - Who are the sources and destinations of the network traffic?
  - What are the timestamps and durations of the network sessions?
  - What are the types and sizes of the network packets?
  - What are the network protocols and ports used by the network traffic?
  - What are the payloads and headers of the network packets?
  - What are the anomalies and indicators of compromise in the network traffic?
  - What are the possible causes and impacts of the network traffic?
- PCAP analysis can also help forensic investigators to reconstruct the network events, identify the evidence chain, and correlate the network data with other sources of information, such as logs, files, and metadata.
