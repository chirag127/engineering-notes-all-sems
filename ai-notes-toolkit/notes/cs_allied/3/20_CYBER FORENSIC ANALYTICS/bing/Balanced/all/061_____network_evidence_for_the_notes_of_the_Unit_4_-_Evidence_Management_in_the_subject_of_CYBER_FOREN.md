# Network Evidence

Network evidence is the information that can be obtained from the analysis of network traffic data, which can be used to establish the source, nature, and impact of cyberattacks or cybercrimes  . Network evidence can be collected from different sources, such as:

- **Network devices**: These include routers, switches, firewalls, intrusion detection systems (IDS), intrusion prevention systems (IPS), and other network equipment that can capture, record, or log network traffic data .
- **Network hosts**: These include computers, servers, mobile devices, and other network endpoints that can generate, receive, or store network traffic data .
- **Network applications**: These include web browsers, email clients, chat programs, and other network applications that can communicate, transmit, or exchange network traffic data .

Network evidence can be classified into two types, depending on the method of collection:

- **Live network evidence**: This is the network evidence that is collected in real time, while the network is operational and the network traffic data is volatile and dynamic. Live network evidence can be obtained by using network monitoring tools, such as packet sniffers, network analyzers, or network forensics software .
- **Stored network evidence**: This is the network evidence that is collected from the storage media of network devices, hosts, or applications, after the network traffic data has been recorded or logged. Stored network evidence can be obtained by using disk forensics tools, such as disk imaging, disk cloning, or disk analysis software .

Network evidence can be used for various purposes, such as:

- **Information gathering**: This is the process of collecting and analyzing network evidence to gain insight into the network environment, such as the network topology, the network protocols, the network services, the network users, and the network activities .
- **Legal evidence**: This is the process of collecting and preserving network evidence to support legal actions, such as criminal prosecution, civil litigation, or regulatory compliance  . Legal evidence must follow the rules of evidence, such as the chain of custody, the authenticity, the integrity, and the admissibility of the network evidence .
- **Intrusion detection**: This is the process of collecting and analyzing network evidence to detect and identify network attacks, such as malware infection, denial-of-service attack, or data breach  . Intrusion detection can be performed by using network security tools, such as firewalls, IDS, IPS, or antivirus software .

Network evidence management is the process of handling network evidence throughout its lifecycle, from collection to analysis to presentation to disposal. Network evidence management involves the following steps:

- **Planning**: This is the step of defining the objectives, scope, and methods of the network forensic investigation, such as the sources, types, and formats of network evidence to be collected, the tools and techniques to be used, and the legal and ethical issues to be considered .
- **Collection**: This is the step of acquiring network evidence from the network sources, using the appropriate network forensic tools, such as packet sniffers, network analyzers, disk imaging software, etc. The collection process must ensure the completeness, accuracy, and reliability of the network evidence .
- **Preservation**: This is the step of protecting network evidence from unauthorized access, modification, or deletion, using the appropriate network forensic techniques, such as encryption, hashing, digital signature, etc. The preservation process must ensure the confidentiality, integrity, and authenticity of the network evidence  .
- **Analysis**: This is the step of examining network evidence to extract relevant information, using the appropriate network forensic tools, such as network forensics software, disk analysis software, etc. The analysis process must ensure the validity, relevance, and reliability of the network evidence .
