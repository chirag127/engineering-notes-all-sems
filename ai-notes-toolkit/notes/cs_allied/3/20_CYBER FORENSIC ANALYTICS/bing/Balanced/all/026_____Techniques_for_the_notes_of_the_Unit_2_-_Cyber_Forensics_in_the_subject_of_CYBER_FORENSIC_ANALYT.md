# Techniques for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

Cyber forensics is the process of gathering and documenting proof from a computer or a computing device in a form presentable to the court by applying the techniques of investigation and analysis . Cyber forensics is also known as digital forensics or computer forensics .

Some of the commonly used techniques in cyber forensics are:

- **Live forensics**: Live forensics, otherwise known as live response, attempts to discover, control, and eliminate threats in a live, running system environment. Live forensics can collect volatile data such as running processes, network connections, memory contents, and registry entries that may be lost or altered after the system is shut down.
- **Data recovery**: Data recovery is the process of retrieving data from damaged, corrupted, or inaccessible storage media. Data recovery can be used to recover deleted, formatted, or overwritten files, as well as data from damaged or failed devices.
- **Password recovery**: Password recovery is the process of cracking or bypassing passwords that protect access to data or systems. Password recovery can be used to unlock encrypted files, folders, or drives, as well as to access password-protected accounts or devices.
- **File carving**: File carving is the process of extracting files from raw data based on their file signatures or headers. File carving can be used to recover files that have no file system metadata, such as deleted or fragmented files, or files from unknown or unsupported file systems.
- **Known file filtering**: Known file filtering is the process of excluding files that are known to be irrelevant or benign from the analysis. Known file filtering can be used to reduce the amount of data to be examined, and to focus on the files that are potentially relevant or malicious. Known file filtering can be done by using hash values or file names of known files.
- **String and keyword searching**: String and keyword searching is the process of finding specific words or phrases in the data. String and keyword searching can be used to locate evidence of interest, such as names, dates, locations, email addresses, or keywords related to the case. String and keyword searching can be done by using regular expressions or wildcard characters.
- **Header analysis**: Header analysis is the process of examining the metadata or information that is embedded in the files or data packets. Header analysis can be used to determine the origin, destination, format, or content of the files or data packets. Header analysis can be done by using tools that can read and interpret the header information.
- **Reverse steganography**: Reverse steganography is the process of finding and extracting hidden data that is embedded in other files, images, or media. Reverse steganography can be used to uncover covert communication, hidden messages, or concealed evidence. Reverse steganography can be done by using tools that can detect and decode the steganographic techniques.
