# PCAP Analysis for the Notes of the Unit 2 - Cyber Forensics

- PCAP stands for Packet Capture, which is a file format that stores network traffic data, including both metadata and content of each packet.
- PCAP analysis is the process of examining the captured network traffic data for various purposes, such as digital forensics, incident response, threat hunting, and network security.
- PCAP analysis can help identify, extract, and preserve evidence of network activities, such as malware infections, intrusions, data exfiltration, and network misuse.
- PCAP analysis can also help detect and analyze malicious network traffic and behavior, such as man-in-the-middle attacks, ransomware, and denial-of-service attacks.
- PCAP analysis can be performed using various tools, such as Wireshark, Zeek, tcpdump, and ExtraHop.
- Wireshark is a popular and widely used tool for PCAP analysis, which provides a graphical user interface and various features, such as filters, statistics, graphs, and protocol decoders.
- Zeek is another powerful tool for PCAP analysis, which converts the captured network traffic data into structured logs that can be easily queried and analyzed using scripting languages, such as Python and R.
- tcpdump is a command-line tool for PCAP analysis, which allows users to capture and display network traffic data using various options and filters.
- ExtraHop is a cloud-based tool for PCAP analysis, which provides real-time visibility and analytics of network traffic data, as well as forensic investigation and threat detection capabilities.
