# Investigating audit logs for the notes of the Unit 3 - Cyber Investigation in the subject of CYBER FORENSIC ANALYTICS

- Audit logs are records of events that occur on a system or an application, such as user actions, system changes, network connections, errors, etc.
- Audit logs are essential for cyber investigation, as they can provide evidence of malicious activities, security breaches, compliance violations, user behavior, system performance, etc.
- Audit logs can be collected from various sources, such as operating systems, databases, web servers, firewalls, routers, applications, etc.
- Audit logs can be stored in different formats, such as text files, binary files, databases, etc.
- Audit logs can be analyzed using various tools, such as log management software, log analysis software, log visualization software, etc.
- Audit logs can be used for various purposes, such as:
  - Detecting and responding to cyber incidents, such as unauthorized access, data theft, malware infection, denial-of-service attack, etc.
  - Identifying and resolving system issues, such as configuration errors, performance problems, resource utilization, etc.
  - Monitoring and improving system security, such as enforcing policies, verifying compliance, auditing user actions, etc.
  - Understanding and optimizing user experience, such as tracking user behavior, measuring user satisfaction, identifying user needs, etc.
- Audit logs should follow some best practices, such as:
  - Enabling and configuring audit logging on all relevant systems and applications, according to the organizational and regulatory requirements.
  - Collecting and storing audit logs in a secure and centralized location, with proper access control and encryption.
  - Retaining audit logs for a sufficient period of time, depending on the legal and operational needs.
  - Reviewing and analyzing audit logs regularly, using automated and manual methods, to identify and report any anomalies or incidents.
  - Protecting and preserving audit logs as digital evidence, following the forensic principles of integrity, authenticity, chain of custody, etc.
