# Port Scans

Port scanning is the process of sending packets to specific ports on a host and analyzing the responses to identify open ports. Port scanning is used by network administrators to verify security policies and by attackers to identify network services running on a host and exploit vulnerabilities.

Here are some key points to remember about port scanning:

1. Port scanning is a technique used to identify open ports and services available on a network host.
2. Port scanning can be used for both legitimate and malicious purposes.
3. Common port scanning techniques include TCP connect scanning, SYN scanning, and UDP scanning.
4. Port scanning can be detected and prevented using firewalls and intrusion detection systems.
5. Port scanning is an important tool in the arsenal of a network administrator for maintaining the security of a network.

This is a brief overview of port scanning in the context of Cyber Forensics. It is important to understand the techniques and tools used in port scanning to effectively analyze and respond to potential security threats.
