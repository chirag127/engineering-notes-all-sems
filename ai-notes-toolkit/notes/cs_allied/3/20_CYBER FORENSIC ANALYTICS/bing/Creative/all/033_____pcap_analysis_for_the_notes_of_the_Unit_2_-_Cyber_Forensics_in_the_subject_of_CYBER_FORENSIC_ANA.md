# PCAP Analysis for the Notes of the Unit 2 - Cyber Forensics

- PCAP stands for **Packet Capture**, which is a file format that stores network traffic data for analysis.
- PCAP analysis is the process of examining the contents of PCAP files to identify, extract, and preserve digital evidence for cyber forensics investigations.
- PCAP analysis can help to solve crimes committed using internet connected infrastructure, such as malware infections, data breaches, network misuse, intrusion attempts, and man-in-the-middle attacks .
- PCAP analysis can also help to detect and prevent malicious network activity, such as ransomware, botnets, denial-of-service attacks, and phishing campaigns .
- PCAP analysis requires the use of specialized tools that can capture, filter, decode, and display network packets and their metadata and content.
- Some of the common tools for PCAP analysis are **Wireshark**, **tcpdump**, **Zeek**, and **ExtraHop** .
- PCAP analysis involves the following steps:
  - Capturing network traffic from a source, such as a network interface card, a router, a switch, or a cloud service provider.
  - Saving the captured traffic in a PCAP file, which can be compressed or encrypted for storage and transmission.
  - Opening the PCAP file in a PCAP analysis tool, which can read and interpret the network protocols and data formats.
  - Applying filters and queries to narrow down the scope of analysis and focus on the relevant packets and fields.
  - Examining the packet details, such as source and destination addresses, ports, timestamps, flags, checksums, payloads, and application data.
  - Extracting and exporting artifacts, such as files, images, URLs, emails, passwords, and encryption keys, from the packet data.
  - Correlating and comparing the packet data with other sources of evidence, such as logs, databases, and threat intelligence feeds, to reconstruct the network events and identify the actors and actions involved.
  - Generating and presenting reports and visualizations that summarize the findings and conclusions of the PCAP analysis.
