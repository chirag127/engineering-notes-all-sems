### Disk characteristics

- Disk forensics is a branch of cyber forensics that deals with extracting data from storage media by searching active, modified, or deleted files  .
- Disk forensics can be applied to various types of storage media, such as hard disk drives, solid state drives, optical disks, flash drives, memory cards, etc.
- Disk forensics involves the following steps:
  - Acquiring a physical or logical image of the disk, which is a bit-by-bit copy of the original data.
  - Analyzing the disk image using specialized tools and techniques, such as file system analysis, file carving, data recovery, metadata extraction, etc.
  - Reporting the findings and presenting the evidence in a forensically sound manner.
- Disk forensics requires the following skills and knowledge:
  - Understanding the structure and format of different types of storage media and file systems.
  - Knowing how to use various disk imaging tools and forensic software, such as FTK Imager, EnCase, Autopsy, etc.
  - Being able to identify and recover deleted, hidden, or encrypted files and partitions.
  - Being able to interpret and correlate the metadata and timestamps of files and directories.
  - Being aware of the legal and ethical issues and standards related to disk forensics.
