### Wireshark for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

In this unit, we will be discussing how to use Wireshark for cyber forensic analysis. Wireshark is a powerful tool that allows us to capture and analyze network traffic, making it an essential tool for cyber forensic investigations. Here are some key points to keep in mind when using Wireshark:

- **Capturing network traffic:** Wireshark allows us to capture network traffic in real-time or from a saved file. When capturing live traffic, it is important to select the correct network interface and set appropriate filters to capture only the traffic of interest.

- **Analyzing network traffic:** Once network traffic is captured, Wireshark provides a variety of tools to analyze the data. These tools include filters, graphs, and statistics that allow us to identify patterns, anomalies, and potential security threats.

- **Identifying network protocols:** Wireshark has the ability to identify and decode a wide variety of network protocols, including TCP, UDP, HTTP, DNS, and many more. This allows us to gain a better understanding of the network traffic we are analyzing.

- **Exporting data:** Wireshark allows us to export captured data in a variety of formats, including CSV, PDF, and plain text. This can be useful for sharing data with other investigators or for further analysis using other tools.

- **Using Wireshark in investigations:** When using Wireshark in an investigation, it is important to follow proper forensic procedures to ensure the integrity of the evidence. This includes creating a forensic image of the device being analyzed, analyzing the image in a separate environment to avoid contamination, and properly documenting all steps taken during the investigation.

In conclusion, Wireshark is a powerful tool for cyber forensic analysis that allows us to capture and analyze network traffic. By following proper forensic procedures and using the tools provided by Wireshark, we can gain valuable insights into potential security threats and other network-related issues.
