### Network Evidence for Unit 4 - Evidence Management Notes

1. Network traffic: The data flowing through a network can be a significant source of evidence. This could include:
- Logs from routers, switches, and servers
- Packet captures containing header information and payload data
- Netflow records showing IP connections
- Web server logs
- Email server logs

2. Network devices: The configuration and data on network infrastructure devices may contain useful evidence, such as:
- Router and switch configuration files
- DHCP server databases showing IP address assignments
- DNS server databases
- Wireless access point configurations and associated client lists

3. Network security devices: Devices implementing network security controls can generate logs and data useful as evidence, such as:
- Firewall logs
- Intrusion detection system logs
- Web filtering logs

4. Endpoint connections: Evidence of how endpoints connected to a network can be useful, such as:
- DHCP leases and IP address assignments showing what devices were on the network and when
- MAC address tables from switches showing what devices were connected to each switch port
- Wireless network association and authentication logs

The above points cover the key types of network evidence that could be relevant for forensic analysis. This evidence allows reconstruction and analysis of network activity, potentially linking devices, people, and events.
