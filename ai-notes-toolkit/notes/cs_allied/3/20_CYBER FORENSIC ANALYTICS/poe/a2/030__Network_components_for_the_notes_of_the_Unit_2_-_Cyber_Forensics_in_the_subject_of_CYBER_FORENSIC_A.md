### Network components for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

1. Network interface card (NIC): The NIC is a computer hardware component that connects a computer or computer-based device to a local area network (LAN) or wide area network (WAN) and facilitates data transmission. The NIC converts data into packets that are transmitted over the network to another NIC that reassembles the packets into the original data.
2. Router: A router is a networking device that forwards data packets between computer networks based on network addresses and routing tables. Routers operate at the network layer of the OSI model and use routing protocols and routing tables to determine the best path for forwarding the data packets between networks.
3. Switch: A switch is a networking device that connects multiple computers or other network devices and forwards traffic based on MAC addresses. Switches operate at the data link layer (layer 2) of the OSI model. Unlike less advanced network hubs, switches forward traffic only to the specific devices that need to receive the data. This increases network efficiency.
4. Cables: Network cables physically connect devices on a network. The most common types are twisted pair cables, coaxial cables and fiber optic cables. Twisted pair cables include unshielded twisted pair (UTP) and shielded twisted pair (STP). The type of cable used depends on the network's specifications.
5. Protocols: Network protocols are formal rules and procedures for communicating that determine how data is formatted, transmitted, routed and received. Common protocols include Ethernet, Transmission Control Protocol/Internet Protocol (TCP/IP), File Transfer Protocol (FTP) and Simple Mail Transfer Protocol (SMTP). Protocols are implemented in software and hardware to enable and facilitate network communication.
