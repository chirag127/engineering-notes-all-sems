### Investigating Web attacks for the notes of the Unit 3 - Cyber Investigation in the subject of CYBER FORENSIC ANALYTICS

1. Cross-site Scripting (XSS) attack
- XSS attacks inject client-side scripts into web pages viewed by other users.
- Attackers can bypass access controls such as same-origin policy.
- Payloads are executed in the victim's browser with the privileges of the vulnerable web application.
- Attackers can steal cookies, deface sites, or redirect users to other pages.

2. SQL Injection attack
- SQL injection attacks are a type of injection attack where malicious SQL statements are inserted into an entry field for execution by the underlying SQL database.
- Attackers can read sensitive data from the database, modify database data, execute administration operations on the database, recover the content of a given file present on the DB server and in some cases issue commands to the operating system.
- It occurs when user input is not properly filtered.

3. Cross-site Request Forgery (CSRF) attack
- CSRF attacks force authenticated users to send requests from their account without their knowledge or intent.
- Attackers exploit the trust that a web site has for a user's browser.
- Attackers get the user's browser to send HTTP requests to a web application in which the user is currently authenticated.
- It can be prevented by using random tokens or CAPTCHAs.
