
### Network Investigation

1. Network investigation is a process of collecting data from a network in order to identify any malicious activities or security breaches.
2. It is important to have a clear understanding of the network architecture before beginning a network investigation.
3. Network forensics involves analyzing network traffic to identify suspicious activity, such as port scans, remote access attempts, and data exfiltration.
4. Network traffic analysis can be used to identify the source of an attack, the type of attack, and the data that was exfiltrated.
5. Network security tools, such as intrusion detection systems (IDS) and firewalls, can be used to detect suspicious activity and block malicious traffic.
6. Network investigation can also involve analyzing log files, packet captures, and other data sources to identify malicious activity.
7. In addition to identifying malicious activity, network investigations can also be used to identify potential vulnerabilities in the network architecture.
8. Network investigations should be conducted in a secure environment to ensure the integrity of the data collected.
