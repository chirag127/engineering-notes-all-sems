
### Regression Modeling 

* Regression modeling is a statistical process used to estimate the relationships between variables. 
* It is used to predict the value of a dependent variable based on the values of one or more independent variables.
* Regression models can be used to identify patterns in data and make predictions about future values.
* Regression models can be linear, polynomial, or nonlinear. 
* Linear regression models are the most commonly used models for data analysis and visualization. 
* Polynomial regression models can be used to identify more complex relationships between variables. 
* Nonlinear regression models can be used to identify patterns in data that cannot be captured by linear or polynomial models.
* In order to build a regression model, data must be collected and analyzed. 
* Data must be cleaned and transformed before it can be used in a regression model.
* Once the data is ready, a regression model can be built using a variety of techniques, such as least squares, maximum likelihood, or Bayesian estimation. 
* Regression models can then be used to make predictions about the value of a dependent variable based on the values of one or more independent variables.
