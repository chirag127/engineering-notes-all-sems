
### Model Building for the Notes of the Unit 2 - Data Analytics Lifecycle in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. Model building is an essential part of the data analytics lifecycle. It involves the process of creating a model that can be used to make predictions or decisions based on data.

2. The model building process involves data pre-processing, feature engineering, and model selection. Data pre-processing involves cleaning and transforming data to make it suitable for modeling. Feature engineering involves selecting and creating features that can be used as input to the model. Model selection involves choosing the best model to use for a given task.

3. Once a model is built, it can be tested and evaluated using various metrics. These metrics can help determine the accuracy and performance of the model.

4. Model building is an iterative process. The model may need to be tuned and re-trained to improve its performance. This is done by making changes to the data pre-processing, feature engineering, and model selection steps.

5. Finally, the model should be deployed in a production environment. This involves making sure the model is secure and can scale to handle large amounts of data.
