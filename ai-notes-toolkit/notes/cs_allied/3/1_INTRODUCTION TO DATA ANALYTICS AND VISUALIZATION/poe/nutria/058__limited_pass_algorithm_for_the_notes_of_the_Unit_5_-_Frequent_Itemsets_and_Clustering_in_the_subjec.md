
### Limited Pass Algorithm

* Limited Pass Algorithm is a type of clustering algorithm used in data analytics and visualization.
* It is used to find frequent itemsets and clusters in a given dataset.
* The algorithm works by iteratively scanning the dataset, counting the occurrences of each item and then grouping them into clusters.
* The algorithm is based on the Apriori principle, which states that if an itemset is frequent, then all its subsets must also be frequent.
* The algorithm uses a threshold value to determine the minimum support of an itemset before it is considered frequent.
* The algorithm works best on datasets with a large number of items and relatively few frequent itemsets.
* The algorithm is computationally expensive and can take a long time to run on large datasets.
