
### Different Types of Tasks for the notes of the Unit 6 - Introduction to Visualization in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. Exploratory Data Analysis: This type of task involves exploring the data to identify patterns and relationships. This can be done through visualizations such as scatter plots, bar charts, and histograms.

2. Predictive Modeling: This type of task involves building a model to predict the outcome of a given situation. This can be done through machine learning algorithms such as linear regression, decision trees, and neural networks.

3. Classification: This type of task involves classifying data into different categories. This can be done through algorithms such as Naive Bayes and Support Vector Machines.

4. Clustering: This type of task involves grouping similar data points together. This can be done through algorithms such as K-means and hierarchical clustering.

5. Dimension Reduction: This type of task involves reducing the number of features in a dataset. This can be done through techniques such as principal component analysis and singular value decomposition.
