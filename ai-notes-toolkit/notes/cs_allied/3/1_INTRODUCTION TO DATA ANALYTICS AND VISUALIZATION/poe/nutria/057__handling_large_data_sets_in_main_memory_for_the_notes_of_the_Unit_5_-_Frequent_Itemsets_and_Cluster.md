
### Handling Large Data Sets in Main Memory for the Notes of Unit 5 - Frequent Itemsets and Clustering in the Subject of Introduction to Data Analytics and Visualization

1. Large datasets can be stored in main memory for faster access times. 
2. Main memory is a form of computer storage that holds data and instructions for immediate use.
3. To handle large datasets in main memory, the data must be split into smaller chunks or blocks. 
4. The data should also be organized into a data structure that is suitable for the task at hand.
5. Common data structures used for large datasets include hash tables, heaps, trees, and graphs.
6. A hash table is a data structure that stores data in an array-like structure and is used to quickly find and retrieve data.
7. Heaps are a type of tree data structure that can be used to store large datasets.
8. Trees are a data structure that stores data in a hierarchical structure.
9. Graphs are a data structure that stores data as a network of nodes and edges.
10. To efficiently store large datasets in main memory, it is important to use an appropriate data structure and to store the data in blocks.
