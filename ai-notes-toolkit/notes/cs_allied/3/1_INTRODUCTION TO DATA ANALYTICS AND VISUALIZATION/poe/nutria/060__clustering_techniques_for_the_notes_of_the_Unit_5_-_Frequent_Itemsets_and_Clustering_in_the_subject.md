
### Clustering Techniques for Unit 5 - Frequent Itemsets and Clustering in Introduction to Data Analytics and Visualization

1. Clustering is a type of unsupervised learning that groups data points based on similarity. It is used to identify patterns and relationships in data that may not be obvious to the naked eye.

2. K-means clustering is a popular clustering algorithm that works by assigning data points to a pre-defined number of clusters. It uses an iterative approach to minimize the sum of squared errors within each cluster.

3. Hierarchical clustering works by creating a hierarchy of clusters based on similarity. It can be used to identify clusters at different levels of granularity.

4. Density-based clustering works by identifying clusters of data points that are close together in a given space. It is useful for identifying clusters of data points that are not necessarily circular in shape.

5. Model-based clustering works by using a statistical model to identify clusters in data. It is useful for identifying clusters of data points that are not necessarily spherical in shape.

6. Clustering can be used to identify patterns and relationships in data that may not be obvious to the naked eye. It is a powerful tool for data analysis and can be used to make better decisions.
