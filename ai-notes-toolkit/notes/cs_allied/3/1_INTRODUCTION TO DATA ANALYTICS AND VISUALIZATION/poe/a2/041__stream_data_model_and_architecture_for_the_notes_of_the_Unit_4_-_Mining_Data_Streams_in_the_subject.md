### Stream Data Model and Architecture

1. Data streams are continuous, unbounded sequences of data records.
2. The data streams are potentially unending and the data arrives at high velocity.
3. The stream data model consists of:
    - Data stream: The continuous flow of data records.
    - Windows: Finite subsets of the data stream used for analysis.
    - Queries: Continuous queries that process the data stream.
4. The stream processing architecture consists of:
    - Data stream source: Generates the data stream.
    - Stream processor: Performs continuous queries on windows of the data stream.
    - Sink: Consumes the output of the stream processor.
5. Challenges in stream processing:
    - High volume, velocity, and variability of data.
    - Resource constraints.
    - Latency requirements.
    - Handling concept drift in data streams.
