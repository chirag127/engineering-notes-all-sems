### Limited Pass Algorithm

- Scans the database a limited number of times to find frequent itemsets.
- Uses a candidate generation function which generates a new set of candidate itemsets in each pass.
- Terminates after a fixed number of passes or when no more frequent itemsets are found.
- Advantages: Requires less time and space than Apriori algorithm as database is scanned limited number of times.
- Disadvantages: May miss some infrequent itemsets.

Points to remember:

- Limited number of passes reduces time complexity.
- May miss some infrequent itemsets as database is not scanned exhaustively.
- Fixed number of passes or no frequent itemsets found termination condition is used.
- Uses candidate generation function to generate new candidate itemsets in each pass.
