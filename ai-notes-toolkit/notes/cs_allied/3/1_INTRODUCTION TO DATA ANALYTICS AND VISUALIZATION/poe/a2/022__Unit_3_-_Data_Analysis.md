## Unit 3 - Data Analysis

1. Overview of Data Analysis
- Data analysis is the process of inspecting, cleaning, transforming and modeling data with the goal of discovering useful information, informing conclusions and supporting decision-making.
- The key steps in data analysis are:
-- Understanding the problem and determining the data needed
-- Retrieving and extracting the data
-- Cleaning and preparing the data
-- Exploring and visualizing the data
-- Modeling the data
-- Evaluating and optimizing the model
-- Drawing conclusions and communicating results

2. Data Cleaning
- Raw data is often messy, incomplete, inconsistent and inaccurate. Data cleaning is the process of fixing or removing incorrect, corrupted or incorrectly formatted data.
- Common data cleaning steps include:
-- Handling missing values: Fill in, drop or infer missing values
-- Fixing inconsistencies: Standardize formats and representations
-- Removing duplicates: Identify and remove duplicate records
-- Correcting errors: Fix typos and other errors
-- Normalizing data: Resolve inconsistencies in units or scales

3. Data Visualization
- Data visualization is the presentation of data in a pictorial or graphical format. It enables us to see trends, patterns and relationships in data that might not be apparent from numbers or charts alone.
- Some common types of data visualizations are:
-- Bar charts: Compare quantities or proportions across categories
-- Line charts: Show change over time
-- Histograms: View distributions of variables
-- Heat maps: Highlight patterns in a data matrix
-- Scatter plots: Show relationship between two quantitative variables
-- Box plots: Summarize distribution of a quantitative variable
