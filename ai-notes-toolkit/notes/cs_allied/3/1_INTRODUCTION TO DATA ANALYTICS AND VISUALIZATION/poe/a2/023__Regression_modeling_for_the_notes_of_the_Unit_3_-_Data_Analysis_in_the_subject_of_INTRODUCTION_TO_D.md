### Regression modeling

1. Regression is a statistical technique to analyze the relationship between a dependent variable and one or more independent variables.
2. It helps in modeling the relationship between variables and finding out how the dependent variable changes with the change in the independent variable(s).
3. The goal of regression is to minimize the difference between the observed values and the predicted values of the dependent variable.
4. Types of regression:
- Linear regression: Relationship between variables is linear. It estimates a straight-line relationship between dependent and independent variables.
- Multiple regression: Relationship between dependent and independent variables is linear. It includes multiple independent variables to predict the dependent variable.
- Logistic regression: Used to predict a binary dependent variable (1 / 0, yes / no, true / false) using independent variables. The dependent variable is fitted to a logistic function.
5. Steps in regression modeling:
- Collect the data
- Plot the variables to check for linear relationship
- Split the data into training and test sets
- Train the model on the training set
- Evaluate the model on the test set
- Improve the model by minimizing error/adding regularization etc.
6. Evaluate regression models using:
- R-squared: Proportion of variance in the dependent variable explained by the independent variable(s). Higher the better.
- Adjusted R-squared: Modified version of R-squared that adjusts for the number of variables in the model. Higher the better.
- Mean Absolute Error (MAE): Average of absolute differences between predictions and actual values. Lower the better.
- Mean Squared Error (MSE): Average squared difference between predictions and actual values. Lower the better.
- Root Mean Squared Error (RMSE): Square root of MSE. Lower the better.
