# Filtering Streams

Filtering streams is a technique used in data stream mining to extract useful information from a continuous stream of data. It is a part of the Unit 4 - Mining Data Streams in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION. Here are some key points to remember:

1. Filtering streams involves selecting only the relevant data from a stream based on certain criteria.
2. This technique is useful when dealing with large volumes of data, as it allows for the efficient processing of the data by reducing the amount of data that needs to be analyzed.
3. Common filtering techniques include sampling, where a subset of the data is selected for analysis, and windowing, where only the most recent data is considered.
4. Filtering can also be used to remove noise or irrelevant data from the stream, improving the quality of the data for analysis.
5. It is important to carefully choose the filtering criteria to ensure that the relevant data is not lost during the filtering process.
