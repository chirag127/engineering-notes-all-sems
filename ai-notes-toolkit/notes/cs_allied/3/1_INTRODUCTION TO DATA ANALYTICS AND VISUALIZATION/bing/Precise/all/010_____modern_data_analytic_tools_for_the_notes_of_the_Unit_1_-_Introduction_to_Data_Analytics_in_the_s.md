# Unit 1 - Introduction to Data Analytics

### Modern Data Analytic Tools

Data analytics is the process of examining, cleaning, transforming, and modeling data to discover useful information, draw conclusions, and support decision-making. There are several modern data analytic tools available to help with this process. Some of the most popular tools include:

1. **Python**: A high-level, general-purpose programming language that is widely used for data analysis and scientific computing.
2. **R**: A programming language and software environment for statistical computing and graphics.
3. **SAS**: A software suite for advanced analytics, multivariate analysis, business intelligence, data management, and predictive analytics.
4. **Excel**: A spreadsheet program that is widely used for data analysis and visualization.
5. **Power BI**: A business analytics service by Microsoft that provides interactive visualizations and business intelligence capabilities.
6. **Tableau**: A data visualization software that helps people see and understand data.
7. **Apache Spark**: An open-source, distributed computing system for big data processing.

These tools offer a range of capabilities, from data cleaning and preprocessing to advanced analytics and visualization. They can be used individually or in combination to support data-driven decision-making.
