### Different Types of Tasks for the notes of the Unit 6 - Introduction to Visualization in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. **Data Exploration:** This task involves exploring the data to identify patterns, trends, and relationships between variables. This can be done through visualizations such as scatter plots, histograms, and box plots.

2. **Data Analysis:** This task involves analyzing the data to draw conclusions and make decisions. This can be done through statistical methods such as regression analysis, hypothesis testing, and correlation analysis.

3. **Data Presentation:** This task involves presenting the data in a clear and concise manner to communicate the results of the analysis to others. This can be done through visualizations such as bar charts, pie charts, and line graphs.

4. **Data Cleaning:** This task involves cleaning the data to remove any errors or inconsistencies. This can be done through methods such as removing outliers, handling missing data, and transforming data.

5. **Data Transformation:** This task involves transforming the data to make it suitable for analysis. This can be done through methods such as normalization, standardization, and encoding categorical variables.

6. **Data Modeling:** This task involves building models to represent the data and make predictions. This can be done through methods such as regression, classification, and clustering.

7. **Data Evaluation:** This task involves evaluating the results of the analysis to determine their validity and reliability. This can be done through methods such as cross-validation, confusion matrix, and ROC curve.

8. **Data Reporting:** This task involves reporting the results of the analysis to others. This can be done through methods such as writing reports, creating presentations, and publishing articles.
