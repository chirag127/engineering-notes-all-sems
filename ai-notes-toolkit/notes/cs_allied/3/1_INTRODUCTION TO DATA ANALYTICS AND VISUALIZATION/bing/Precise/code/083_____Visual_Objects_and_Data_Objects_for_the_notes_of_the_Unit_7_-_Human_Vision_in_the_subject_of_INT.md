### Visual Objects and Data Objects

In the context of data analytics and visualization, visual objects and data objects are two important concepts.

1. **Visual Objects**: Visual objects refer to the graphical elements used to represent data in a visualization. These can include points, lines, bars, pie slices, and other shapes. The choice of visual objects can greatly affect the readability and effectiveness of a visualization.

2. **Data Objects**: Data objects refer to the individual units of data being represented in a visualization. Each data object typically corresponds to a row in a data table, with each column representing a different attribute of the data object. The attributes of a data object can be mapped to the properties of a visual object, such as its position, size, color, or shape.

In summary, visual objects are the graphical elements used to represent data, while data objects are the individual units of data being represented. The mapping between data objects and visual objects is a key aspect of data visualization design.
