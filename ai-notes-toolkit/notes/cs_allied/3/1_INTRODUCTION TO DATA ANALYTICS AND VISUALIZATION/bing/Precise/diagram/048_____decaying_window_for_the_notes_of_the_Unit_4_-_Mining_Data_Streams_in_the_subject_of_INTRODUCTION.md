### Decaying Window

Decaying window is a technique used in mining data streams. It is a part of Unit 4 - Mining Data Streams in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION. Here are some key points to note about decaying window:

1. Decaying window is a method of giving more importance to recent data in a data stream.
2. It is used to analyze data that changes over time, where more recent data is more relevant.
3. The technique involves applying a decay function to the data, which reduces the importance of older data.
4. The decay function can be exponential, linear, or any other function that reduces the importance of older data.
5. Decaying window is useful in applications such as financial analysis, where recent stock prices are more relevant than older prices.
6. It can also be used in social media analysis, where recent posts and interactions are more relevant than older ones.
