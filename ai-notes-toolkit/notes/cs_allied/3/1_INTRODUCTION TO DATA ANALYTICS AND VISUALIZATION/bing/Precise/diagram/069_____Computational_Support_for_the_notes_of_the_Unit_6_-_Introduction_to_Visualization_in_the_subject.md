### Computational Support for the notes of the Unit 6 - Introduction to Visualization in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. Visualization is the process of representing data graphically to uncover patterns and relationships.
2. Computational support for visualization includes tools and techniques for data processing, analysis, and presentation.
3. Data processing involves cleaning, transforming, and organizing data to prepare it for analysis.
4. Data analysis involves using statistical and mathematical methods to identify patterns and relationships in the data.
5. Data presentation involves using visual encodings such as charts, graphs, and maps to communicate the results of the analysis.
6. Common tools for computational support for visualization include programming languages such as R and Python, and software packages such as Tableau and Excel.
7. These tools provide a range of functionality for data processing, analysis, and presentation, and can be used to create custom visualizations.
8. Effective visualization requires an understanding of the data, the audience, and the message to be communicated, as well as the appropriate use of visual encodings and design principles.
