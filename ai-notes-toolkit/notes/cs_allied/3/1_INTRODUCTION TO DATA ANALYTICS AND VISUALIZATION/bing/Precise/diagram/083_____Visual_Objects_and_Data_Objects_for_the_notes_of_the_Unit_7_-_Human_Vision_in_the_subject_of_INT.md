### Visual Objects and Data Objects

Unit 7 - Human Vision in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. Visual objects are the graphical representations of data that are used to convey information to the viewer. These can include charts, graphs, diagrams, and other visual aids.
2. Data objects, on the other hand, are the underlying data structures that store and organize the data used to create visual objects. These can include tables, arrays, and other data structures.
3. The relationship between visual objects and data objects is important in data analytics and visualization. Visual objects are used to present data in a way that is easy for the viewer to understand, while data objects provide the structure and organization necessary to support the creation of visual objects.
4. In order to create effective visualizations, it is important to understand the relationship between visual objects and data objects, and to choose the appropriate data structures and visual representations to convey the desired information.
