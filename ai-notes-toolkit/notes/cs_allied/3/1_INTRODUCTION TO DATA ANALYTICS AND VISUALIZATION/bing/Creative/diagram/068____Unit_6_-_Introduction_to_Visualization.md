## Unit 6 - Introduction to Visualization

- Visualization is the process of creating and displaying graphical representations of data or information.
- Visualization can help users to explore, analyze, communicate, and understand data or information more effectively and efficiently.
- Visualization can be classified into different types based on the purpose, audience, data, and technique of the visualization.
- Some common types of visualization are:

  - **Charts**: Charts are graphical representations of numerical data, such as bar charts, pie charts, line charts, scatter plots, etc. Charts can show trends, patterns, distributions, comparisons, and correlations of data.
  - **Maps**: Maps are graphical representations of spatial data, such as geographic locations, regions, routes, etc. Maps can show the relative position, size, shape, and distance of spatial features, as well as thematic information such as population, climate, etc.
  - **Diagrams**: Diagrams are graphical representations of abstract or conceptual data, such as processes, systems, structures, relationships, etc. Diagrams can show the components, functions, flows, hierarchies, and interactions of data.
  - **Infographics**: Infographics are graphical representations of complex or diverse data, such as facts, statistics, stories, etc. Infographics can combine different types of visualization, such as charts, maps, diagrams, icons, text, etc., to convey a message or a story to the audience.
  - **Dashboards**: Dashboards are graphical representations of key performance indicators (KPIs), metrics, or summaries of data, such as business, health, education, etc. Dashboards can provide an overview, a snapshot, or a drill-down of data, as well as alerts, notifications, or recommendations to the users.

- Visualization can be created and displayed using different tools, such as software applications, web platforms, programming languages, libraries, etc.
- Some common tools for visualization are:

  - **Microsoft Excel**: Microsoft Excel is a spreadsheet application that can create and display various types of charts, such as bar charts, pie charts, line charts, etc., using the data in the spreadsheet cells.
  - **Tableau**: Tableau is a data visualization platform that can create and display interactive and dynamic visualizations, such as maps, dashboards, etc., using data from various sources, such as databases, files, web services, etc.
  - **Python**: Python is a programming language that can create and display various types of visualizations, such as charts, maps, diagrams, etc., using libraries, such as matplotlib, seaborn, plotly, etc.
  - **R**: R is a programming language that can create and display various types of visualizations, such as charts, maps, diagrams, etc., using libraries, such as ggplot2, leaflet, shiny, etc.
  - **D3.js**: D3.js is a JavaScript library that can create and display various types of web-based visualizations, such as charts, maps, diagrams, etc., using data from various formats, such as JSON, CSV, XML, etc.
