### Need of data analytics

- Data analytics is the science of analyzing raw data to make conclusions about that information.
- Data analytics can help a business optimize its performance, perform more efficiently, maximize profit, or make more strategically-guided decisions.
- Data analytics can also reveal trends and metrics that would otherwise be lost in the mass of information, and provide insights that can be used to improve things.
- Data analytics is a broad term that encompasses many diverse types of data analysis, such as descriptive, diagnostic, predictive, and prescriptive analytics.
- Data analytics can be applied to any type of information, such as customer data, financial data, social media data, health data, etc.
- Data analytics requires various skills, such as data collection, data transformation, data organization, data visualization, data interpretation, and data communication.
- Data analytics is a fast-growing and high-demand field, with many career opportunities for data analysts, data scientists, data engineers, data architects, etc.
