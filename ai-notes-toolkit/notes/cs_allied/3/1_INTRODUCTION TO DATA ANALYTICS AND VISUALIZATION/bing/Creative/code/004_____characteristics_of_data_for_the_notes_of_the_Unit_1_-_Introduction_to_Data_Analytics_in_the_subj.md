### Characteristics of Data

- Data is any information that can be collected, stored, processed, analyzed, and communicated.
- Data can be classified into different types based on its nature, source, format, and quality.
- Some common types of data are:
  - **Quantitative data**: Data that can be measured or counted, such as numbers, percentages, or ratios. Examples: height, weight, temperature, sales, etc.
  - **Qualitative data**: Data that can be described or categorized, such as words, images, sounds, or opinions. Examples: color, shape, taste, feedback, etc.
  - **Structured data**: Data that has a predefined format or schema, such as tables, spreadsheets, or databases. Examples: student records, inventory, transactions, etc.
  - **Unstructured data**: Data that has no fixed format or schema, such as text, audio, video, or social media posts. Examples: emails, tweets, blogs, videos, etc.
  - **Primary data**: Data that is collected directly from the source or original observation, such as surveys, interviews, or experiments. Examples: customer feedback, product testing, market research, etc.
  - **Secondary data**: Data that is collected from other sources or existing data, such as reports, publications, or websites. Examples: census data, industry data, academic data, etc.
- Data can have different characteristics that affect its quality, usability, and value, such as:
  - **Accuracy**: The degree to which the data reflects the true or correct value of the phenomenon or attribute it represents. Examples: spelling errors, measurement errors, rounding errors, etc.
  - **Completeness**: The degree to which the data covers all the relevant aspects or dimensions of the phenomenon or attribute it represents. Examples: missing values, incomplete records, insufficient samples, etc.
  - **Consistency**: The degree to which the data follows the same rules, standards, or formats across different sources, systems, or time periods. Examples: different units, different scales, different formats, etc.
  - **Relevance**: The degree to which the data is useful or applicable for the purpose or context of the analysis or decision making. Examples: outdated data, irrelevant data, redundant data, etc.
  - **Timeliness**: The degree to which the data is available or updated at the right time or frequency for the analysis or decision making. Examples: real-time data, historical data, periodic data, etc.
  - **Validity**: The degree to which the data conforms to the rules, constraints, or expectations of the domain or application it belongs to. Examples: data types, data ranges, data formats, data relationships, etc.
