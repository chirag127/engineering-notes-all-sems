## Unit 6 - Introduction to Visualization

- Visualization is the process of creating and displaying graphical representations of data or information.
- Visualization can help users to explore, analyze, communicate, and understand data or information more effectively and efficiently.
- Visualization can be classified into different types based on the purpose, audience, data, and technique of the visualization.
- Some common types of visualization are:

  - **Descriptive visualization**: This type of visualization aims to summarize and present the main features or characteristics of a data set, such as its distribution, trends, outliers, or patterns. Examples of descriptive visualization are histograms, bar charts, line charts, pie charts, scatter plots, etc.
  - **Exploratory visualization**: This type of visualization aims to support users in discovering new insights or hypotheses from a data set, such as its relationships, correlations, clusters, or anomalies. Examples of exploratory visualization are parallel coordinates, scatter plot matrices, heat maps, treemaps, etc.
  - **Explanatory visualization**: This type of visualization aims to convey a specific message or argument based on a data set, such as its significance, causality, or implication. Examples of explanatory visualization are infographics, dashboards, maps, charts with annotations, etc.
  - **Narrative visualization**: This type of visualization aims to tell a story or a sequence of events based on a data set, such as its evolution, progression, or comparison. Examples of narrative visualization are timelines, flow charts, comic strips, slideshows, etc.

- Visualization can also be classified into different types based on the dimensionality, interactivity, and modality of the visualization.
- Some common types of visualization are:

  - **2D visualization**: This type of visualization uses two spatial dimensions (x and y) to represent data or information. Examples of 2D visualization are maps, charts, diagrams, etc.
  - **3D visualization**: This type of visualization uses three spatial dimensions (x, y, and z) to represent data or information. Examples of 3D visualization are models, sculptures, landscapes, etc.
  - **Static visualization**: This type of visualization does not change over time or in response to user input. Examples of static visualization are posters, books, magazines, etc.
  - **Dynamic visualization**: This type of visualization changes over time or in response to user input. Examples of dynamic visualization are animations, simulations, games, etc.
  - **Interactive visualization**: This type of visualization allows users to manipulate, explore, or control the data or information displayed. Examples of interactive visualization are widgets, menus, sliders, buttons, etc.
  - **Multimodal visualization**: This type of visualization uses more than one sensory modality (such as vision, hearing, touch, etc.) to represent data or information. Examples of multimodal visualization are soundscapes, haptic devices, virtual reality, etc.

- Visualization can be created and displayed using various tools, techniques, and platforms, such as software applications, programming languages, libraries, frameworks, web browsers, etc.
- Some common tools, techniques, and platforms for visualization are:

  - **Microsoft Excel**: This is a spreadsheet application that can create and display various types of charts and graphs based on tabular data.
  - **Tableau**: This is a software application that can create and display various types of interactive and dynamic visualizations based on various sources of data.
  - **Python**: This is a programming language that can create and display various types of visualizations using various libraries, such as matplotlib, seaborn, plotly, etc.
  - **R**: This is a programming language that can create and display various types of visualizations using various libraries, such as ggplot2, lattice, shiny, etc.
  - **D3.js**: This is a JavaScript library that can create and display various types of interactive and dynamic visualizations based on web standards, such as HTML, CSS, and SVG.
  - **Processing**: This is a programming language and environment that can create and display various types of visualizations using various modes, such as Java, Python, JavaScript, etc.
