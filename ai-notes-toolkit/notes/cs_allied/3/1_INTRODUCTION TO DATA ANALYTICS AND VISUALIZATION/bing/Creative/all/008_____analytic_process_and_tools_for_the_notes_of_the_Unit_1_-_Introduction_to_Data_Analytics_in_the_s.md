# Analytic Process and Tools

## What is an analytic process?

- An analytic process is a systematic and logical approach to solving a problem or answering a question using data and evidence.
- An analytic process typically involves the following steps:
  - Define the problem or question
  - Collect and prepare the data
  - Explore and analyze the data
  - Interpret and communicate the results
  - Implement and evaluate the solution or answer

## What are some analytic tools?

- Analytic tools are software applications or platforms that help analysts perform the analytic process more efficiently and effectively.
- Analytic tools can vary in their functionality, complexity, and cost, depending on the type and size of the problem or question, the data sources and formats, and the desired output and presentation.
- Some examples of analytic tools are:
  - Spreadsheet software, such as Microsoft Excel or Google Sheets, that can store, manipulate, and visualize data using formulas, functions, charts, and graphs.
  - Database management systems, such as Microsoft Access or MySQL, that can store, query, and manipulate large and complex data sets using structured query language (SQL).
  - Statistical software, such as R or SPSS, that can perform descriptive and inferential statistics, such as summary measures, hypothesis testing, and regression analysis, on numerical data.
  - Data visualization software, such as Tableau or Power BI, that can create interactive and dynamic dashboards and reports using various types of charts, maps, and graphics.
  - Data mining software, such as RapidMiner or Weka, that can apply machine learning and artificial intelligence techniques, such as classification, clustering, and association rules, to discover patterns and insights from large and complex data sets.
  - Text analysis software, such as NVivo or Leximancer, that can analyze qualitative data, such as text, audio, or video, using natural language processing and content analysis methods, such as sentiment analysis, topic modeling, and word clouds.
