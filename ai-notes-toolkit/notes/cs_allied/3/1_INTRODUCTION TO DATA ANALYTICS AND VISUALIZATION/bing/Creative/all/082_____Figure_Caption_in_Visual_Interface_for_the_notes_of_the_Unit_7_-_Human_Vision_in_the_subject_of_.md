# Figure Caption in Visual Interface

- A figure caption is a text that accompanies a figure in a visual interface, such as a chart, a graph, a map, or an image.
- A figure caption serves several purposes, such as:
  - Providing a title or a summary of the figure
  - Explaining the data source, the variables, the units, the scale, or the legend of the figure
  - Highlighting the main findings, trends, patterns, or insights from the figure
  - Providing additional information or context that is not visible in the figure
  - Citing the original source or author of the figure, if applicable
- A figure caption should be concise, clear, accurate, and informative. It should not repeat the information that is already shown in the figure, but rather complement it or add value to it.
- A figure caption should be placed close to the figure, preferably below it, and aligned with the left edge of the figure. It should be formatted differently from the main text, such as using a smaller font size, a different font style, or a different color.
- A figure caption should follow a consistent style and format throughout the document or the interface. It should use proper punctuation, capitalization, and grammar. It should also use the same terminology and notation as the figure and the main text.
- A figure caption should be numbered sequentially if there are multiple figures in the document or the interface. The number should be preceded by the word "Figure" and followed by a period. The number should also be referenced in the main text when the figure is mentioned or discussed.
- A figure caption should be tested for readability, comprehension, and accessibility. It should be easy to read and understand by the intended audience, and it should not create confusion or ambiguity. It should also be accessible to people with visual impairments, such as using alternative text or audio descriptions.
