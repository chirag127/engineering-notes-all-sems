### Computational Support for Visualization

- Visualization is the process of creating and manipulating graphical representations of data to enhance human understanding and communication .
- Visualization can be classified into two broad categories: data visualization and computational visualization.
- Data visualization deals with abstract data, such as numbers, text, or symbols, that do not have a direct mapping to the physical world. Examples of data visualization are charts, graphs, infographics, and dashboards.
- Computational visualization deals with physical data, such as images, sounds, or videos, that have a direct mapping to the physical world. Examples of computational visualization are volume rendering, surface rendering, and ray tracing.
- Computational support for visualization refers to the hardware and software tools that enable the creation and manipulation of visual representations of data.
- Computational support for visualization can be divided into three levels: low-level, mid-level, and high-level.
- Low-level computational support provides the basic building blocks for visualization, such as graphics primitives, coordinate systems, transformations, and rendering algorithms. Examples of low-level computational support are OpenGL, DirectX, and Vulkan.
- Mid-level computational support provides the common functionalities and abstractions for visualization, such as data structures, data models, data formats, and data manipulation operations. Examples of mid-level computational support are VTK, ITK, and GDAL.
- High-level computational support provides the domain-specific solutions and applications for visualization, such as data analysis, data exploration, data presentation, and data storytelling. Examples of high-level computational support are Tableau, MATLAB, and Paraview.
- Computational support for visualization can also be categorized by the type of platform and environment that it runs on, such as desktop, web, mobile, cloud, or cluster.
- Desktop computational support runs on a single computer and provides a rich and interactive user interface for visualization. Examples of desktop computational support are Excel, R, and Blender.
- Web computational support runs on a web browser and provides a portable and accessible user interface for visualization. Examples of web computational support are D3.js, Plotly, and Google Charts.
- Mobile computational support runs on a smartphone or tablet and provides a convenient and personal user interface for visualization. Examples of mobile computational support are Power BI, Qlik Sense, and SAP Roambi.
- Cloud computational support runs on a remote server and provides a scalable and collaborative user interface for visualization. Examples of cloud computational support are IBM Cognos, Amazon QuickSight, and Microsoft Azure.
- Cluster computational support runs on a distributed system and provides a parallel and high-performance user interface for visualization. Examples of cluster computational support are VisIt, ParaView, and EnSight.
