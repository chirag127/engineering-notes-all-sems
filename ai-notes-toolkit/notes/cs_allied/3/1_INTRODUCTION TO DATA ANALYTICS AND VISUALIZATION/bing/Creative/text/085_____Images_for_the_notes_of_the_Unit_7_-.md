### Images for the notes of the Unit 7

- Unit 7 is about **digital image processing**, which is the use of computer algorithms to perform image processing on digital images.
- Digital images are composed of **pixels**, which are the smallest units of information in an image. Each pixel has a numerical value that represents its color or intensity.
- Digital images can be represented in different **color models**, such as RGB, CMYK, HSV, etc. Each color model has a different way of encoding the color information of an image.
- Digital images can also be classified into different **types**, such as binary, grayscale, color, etc. Each type has a different number of bits per pixel, which affects the quality and size of the image.
- Some common **operations** on digital images are:

  - **Image enhancement**, which is the process of improving the appearance or quality of an image by modifying its contrast, brightness, sharpness, etc.
  - **Image restoration**, which is the process of recovering an image that has been degraded by noise, blur, distortion, etc.
  - **Image segmentation**, which is the process of dividing an image into meaningful regions or objects based on some criteria, such as color, texture, shape, etc.
  - **Image compression**, which is the process of reducing the size of an image by removing some redundant or irrelevant information, while preserving the essential features of the image.
  - **Image recognition**, which is the process of identifying or classifying an image based on its content, such as faces, objects, scenes, etc.
