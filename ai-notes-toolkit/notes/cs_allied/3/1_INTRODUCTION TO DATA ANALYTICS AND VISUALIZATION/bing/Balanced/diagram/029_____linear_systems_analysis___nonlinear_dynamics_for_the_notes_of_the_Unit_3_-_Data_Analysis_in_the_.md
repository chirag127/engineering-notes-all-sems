# Unit 3 - Data Analysis

## Linear Systems Analysis & Nonlinear Dynamics

- A linear system is a system whose output is proportional to its input, and whose behavior can be described by a set of linear equations or a linear operator.
- A nonlinear system is a system whose output is not proportional to its input, and whose behavior can be described by a set of nonlinear equations or a nonlinear operator.
- Linear systems can be solved exactly, in contrast to most nonlinear systems. Occasionally, a nonlinear system can be solved exactly by a change of variables to a linear system. Moreover, the solutions of (almost) any nonlinear system can be well-approximated by an equivalent linear system near its fixed points.
- A fixed point of a system is a state where the system does not change over time. The stability of a fixed point is determined by the behavior of the system near the fixed point. A fixed point is stable if the system returns to it after a small perturbation, and unstable if the system moves away from it after a small perturbation.
- Linear stability analysis is a method to determine the stability of a fixed point of a nonlinear system by linearizing the system around the fixed point and analyzing the eigenvalues of the Jacobian matrix of the system. The Jacobian matrix is a matrix of partial derivatives that represents the local behavior of the system near the fixed point.
- The eigenvalues of the Jacobian matrix indicate the rate and direction of change of the system near the fixed point. If the real part of the dominant eigenvalue is negative, the fixed point is stable. If the real part of the dominant eigenvalue is positive, the fixed point is unstable. If the real part of the dominant eigenvalue is zero, the fixed point is marginally stable and the stability depends on the higher-order terms of the system.
- Nonlinear systems can exhibit complex and chaotic behavior, such as bifurcations, limit cycles, strange attractors, and sensitivity to initial conditions. Bifurcations are sudden changes in the qualitative behavior of the system as a parameter is varied. Limit cycles are periodic orbits of the system that are stable and attract nearby trajectories. Strange attractors are fractal-like sets of states that the system visits chaotically and never repeats. Sensitivity to initial conditions means that small differences in the initial state of the system can lead to large differences in the long-term behavior of the system.
- Data analysis is the process of extracting useful information from data, such as patterns, trends, correlations, and causal relationships. Data analysis can be performed using various methods and tools, such as statistics, machine learning, visualization, and simulation.
- Linear systems analysis is a data analysis method that assumes that the data can be modeled by a linear system, and uses techniques such as regression, correlation, and principal component analysis to find the best linear fit and the linear relationships among the variables.
- Nonlinear dynamics is a data analysis method that assumes that the data can be modeled by a nonlinear system, and uses techniques such as phase space reconstruction, Lyapunov exponents, bifurcation diagrams, and Poincaré maps to find the nonlinear behavior and the nonlinear relationships among the variables.
