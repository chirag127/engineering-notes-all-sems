### Stream Data Model and Architecture

- Stream data model is a way of representing and processing data that arrives continuously and rapidly from various sources.
- Stream data architecture is an information technology framework that focuses on processing data in motion and treats batch processing as just one more event in a continuous stream of events.
- The basic components of a streaming data architecture are :
  - An aggregator that gathers event streams and batch files from a variety of data sources, such as IoT sensors, web applications, logs, etc.
  - A broker that makes data available for consumption by different applications and services, such as Kafka, Kinesis, Pub/Sub, etc.
  - An analytics engine that analyzes the data, correlates values and generates insights, such as Spark, Flink, Beam, etc.
- The benefits of stream data processing are:
  - Real-time insight into the data and the ability to react quickly to changing conditions and events.
  - Reduced latency and increased throughput compared to batch processing.
  - Scalability and fault-tolerance of distributed systems and parallel processing.
  - Flexibility and adaptability of data pipelines and applications.
