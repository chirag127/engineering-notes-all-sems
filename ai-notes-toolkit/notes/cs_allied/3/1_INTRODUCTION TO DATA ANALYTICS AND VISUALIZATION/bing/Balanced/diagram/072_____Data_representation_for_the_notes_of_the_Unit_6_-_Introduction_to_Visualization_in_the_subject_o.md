### Data representation for the notes of the Unit 6 - Introduction to Visualization

- Data representation is the process of transforming data into a form that can be easily understood and communicated by using visual elements such as charts, graphs, maps, etc.
- Data representation is an essential part of data visualization, which is the science and art of presenting data in a meaningful and engaging way.
- Data representation can help users to:
  - Explore and analyze data to discover patterns, trends, outliers, and relationships.
  - Communicate and share data insights with others in a clear and concise manner.
  - Make informed and evidence-based decisions based on data.
- Data representation can be classified into two main types: static and dynamic.
  - Static data representation is a fixed and unchanging display of data, such as a printed report or a screenshot.
  - Dynamic data representation is an interactive and responsive display of data, such as a live dashboard or an animation.
- Data representation can also be categorized based on the level of abstraction: low-level and high-level.
  - Low-level data representation is a direct and literal display of data, such as a table or a scatter plot.
  - High-level data representation is an indirect and symbolic display of data, such as a map or an infographic.
- Data representation can involve different techniques and tools, depending on the type, size, and complexity of the data, and the purpose and audience of the visualization.
  - Some common data representation techniques are: pie chart, bar chart, histogram, line chart, area chart, box plot, heat map, tree map, network diagram, etc.
  - Some common data representation tools are: Microsoft Excel, Tableau, Power BI, R, Python, etc.
