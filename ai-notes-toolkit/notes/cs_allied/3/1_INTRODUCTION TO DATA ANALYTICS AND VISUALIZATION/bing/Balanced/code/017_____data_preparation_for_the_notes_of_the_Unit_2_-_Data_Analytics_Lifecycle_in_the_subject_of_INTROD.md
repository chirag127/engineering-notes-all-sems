### Data Preparation for the Notes of the Unit 2 - Data Analytics Lifecycle

Data preparation is the process of transforming raw data into a format that is suitable for analysis and modeling. Data preparation is an essential step in the data analytics lifecycle, which is a systematic approach to conducting a data analytics project. The data analytics lifecycle consists of six phases  :

- **Business understanding**: Define the problem, objectives, and requirements of the project.
- **Data understanding**: Collect, explore, and describe the data sources and quality.
- **Data preparation**: Clean, integrate, and transform the data for analysis.
- **Modeling**: Apply analytical techniques and algorithms to the data to discover patterns and insights.
- **Evaluation**: Assess the validity, reliability, and usefulness of the results and compare different models.
- **Deployment**: Communicate and implement the findings and recommendations to the stakeholders.

Data preparation is often the most time-consuming and challenging phase in the data analytics lifecycle, as it involves dealing with various data issues, such as missing values, outliers, inconsistencies, duplicates, errors, and noise. Data preparation also requires selecting the relevant variables, features, and samples for the analysis, as well as creating new variables or features from the existing data. Data preparation can be done using various tools and methods, such as spreadsheets, databases, programming languages, and software applications.

Some of the common tasks and steps involved in data preparation are  :

- **Data access**: Connect to the data sources and extract the data needed for the project.
- **Data loading**: Load the data into a suitable platform or environment for analysis, such as an analytical sandbox, which is a scalable and flexible space for data processing and exploration.
- **Data structuring**: Organize the data into a consistent and logical format, such as tables, matrices, or arrays, and define the data types, labels, and units.
- **Data cleansing**: Identify and correct or remove any errors, anomalies, or inconsistencies in the data, such as spelling mistakes, invalid values, or mismatched formats.
- **Data integration**: Combine data from different sources or tables into a single view or table, and resolve any conflicts or redundancies in the data, such as different names or codes for the same entity or attribute.
- **Data transformation**: Apply mathematical or statistical operations to the data to change its scale, distribution, or shape, such as normalization, standardization, binning, or encoding.
- **Data reduction**: Reduce the size or complexity of the data by selecting or extracting the most relevant or informative variables, features, or samples for the analysis, such as using filters, aggregations, or dimensionality reduction techniques.
- **Data enrichment**: Enhance the data by adding new variables or features derived from the existing data or from external sources, such as using calculations, functions, or lookups.

Data preparation is an iterative and interactive process that requires constant evaluation and refinement of the data quality and suitability for the analysis. Data preparation is also influenced by the business understanding and the modeling objectives of the project, as different analytical techniques and algorithms may require different types of data inputs and outputs. Data preparation is a critical step in ensuring the validity, reliability, and usefulness of the results and recommendations of the data analytics project.
