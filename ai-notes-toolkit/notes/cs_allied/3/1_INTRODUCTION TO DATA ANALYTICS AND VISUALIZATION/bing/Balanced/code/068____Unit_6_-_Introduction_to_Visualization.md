## Unit 6 - Introduction to Visualization

- Visualization is the process of creating and displaying graphical representations of data or information.
- Visualization can help users to explore, analyze, communicate, and understand data or information more effectively and efficiently.
- Visualization can be classified into different types based on the purpose, audience, data, and technique of the visual representation.
- Some common types of visualization are:

  - **Charts**: Charts are graphical displays of quantitative data, such as bar charts, pie charts, line charts, scatter plots, etc. Charts can show trends, patterns, distributions, correlations, or comparisons of data.
  - **Maps**: Maps are graphical displays of spatial data, such as geographic locations, regions, routes, or boundaries. Maps can show the physical features, cultural aspects, or statistical attributes of a place or area.
  - **Diagrams**: Diagrams are graphical displays of abstract or conceptual data, such as flowcharts, network diagrams, tree diagrams, etc. Diagrams can show the structure, process, or relationship of data or information.
  - **Infographics**: Infographics are graphical displays of mixed data or information, such as icons, symbols, text, images, etc. Infographics can show the overview, context, or story of data or information.
  - **Dashboards**: Dashboards are graphical displays of multiple data or information, such as charts, maps, diagrams, indicators, etc. Dashboards can show the summary, status, or performance of data or information.

- Visualization can be created and displayed using various tools, such as software applications, web platforms, programming languages, or libraries.
- Some common tools for visualization are:

  - **Excel**: Excel is a spreadsheet application that can create and display charts, tables, and pivot tables from data.
  - **Power BI**: Power BI is a business intelligence platform that can create and display interactive dashboards, reports, and visualizations from data.
  - **Tableau**: Tableau is a data visualization software that can create and display interactive dashboards, stories, and visualizations from data.
  - **Python**: Python is a programming language that can create and display visualizations using libraries such as matplotlib, seaborn, plotly, etc.
  - **R**: R is a programming language that can create and display visualizations using libraries such as ggplot2, shiny, leaflet, etc.
