### Introduction to streams concepts

- A data stream is an existing, continuous, ordered (implicitly by entrance time or explicitly by timestamp) chain of items.
- Data streams capture the data processing needs of today, where data is generated at high volumes and velocities from various sources, such as sensors, clickstreams, social media, etc .
- Stream processing is a data management technique that involves ingesting a continuous data stream to quickly analyze, filter, transform or enhance the data in real time.
- Streaming analytics is the continuous processing and analysis of big data in motion, using methods that result in a latency period defined as “real-time”.
- Streaming analytics can enable various use cases, such as fraud detection, anomaly detection, sentiment analysis, real-time dashboards, etc .
- Streaming data architecture is the design and implementation of a system that can ingest, process, and store data streams in a scalable and reliable way.
- Streaming data architecture typically consists of the following components:
  - Data sources: the origin of the data streams, such as sensors, web servers, applications, etc.
  - Data ingestion: the process of collecting and transferring the data streams from the sources to the processing engine, using tools such as Kafka, Flume, etc.
  - Data processing: the process of applying logic and analytics to the data streams in real time, using tools such as Spark, Flink, Storm, etc.
  - Data storage: the process of storing the processed data streams in a data store, such as HDFS, S3, Cassandra, etc.
  - Data consumption: the process of accessing and visualizing the stored data streams, using tools such as Tableau, Power BI, Grafana, etc.
