### Auto-associative and hetero-associative memory

- Auto-associative memory is a type of memory that retrieves the same pattern Y given an input pattern X, i.e., Y = X  .
- Auto-associative memory can be implemented by a single layer neural network with the input and output vectors being the same.
- Auto-associative memory can de-noise or remove interference from the input and can determine whether the input is known or unknown.
- Hetero-associative memory is a type of memory that retrieves a different pattern Y given an input pattern X, i.e., Y ≠ X  .
- Hetero-associative memory can be implemented by a bidirectional associative memory (BAM) network, which is a two-layer neural network with feedback connections.
- Hetero-associative memory can associate patterns of different sizes, types, formats and contents .
