

### Auto-associative and Hetero-associative Memory

Auto-associative and hetero-associative memory are two important types of memory used in neural networks.

**Auto-associative Memory** is a type of memory where the same input is used to generate the output. This type of memory is used for pattern recognition and is used to store information about a particular pattern.

**Hetero-associative Memory** is a type of memory where different inputs are used to generate the output. This type of memory is used for pattern association and is used to store information about the relationship between two different patterns.

Both auto-associative and hetero-associative memory are used in neural networks to store information and to recognize patterns. They are used in applications such as image recognition, speech recognition and natural language processing.
