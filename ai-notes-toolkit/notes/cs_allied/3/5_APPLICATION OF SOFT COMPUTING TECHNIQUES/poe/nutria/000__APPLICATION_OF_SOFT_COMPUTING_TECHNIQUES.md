
# APPLICATION OF SOFT COMPUTING TECHNIQUES

* Soft computing is a branch of computer science which deals with the development of algorithms and techniques that are used to approximate solutions to complex problems. 
* It is a collection of techniques which includes fuzzy logic, neural networks, evolutionary computing, and probabilistic reasoning.
* Soft computing techniques are used in many applications such as robotics, image processing, speech recognition, natural language processing, and data mining.
* Fuzzy logic is a form of approximate reasoning which deals with vague terms such as “high”, “low”, and “medium”. It is used to make decisions in uncertain situations.
* Neural networks are used to solve problems which involve pattern recognition and classification. They are used in applications such as image recognition, speech recognition, and natural language processing.
* Evolutionary computing is a type of artificial intelligence which uses evolutionary algorithms to find optimal solutions to complex problems. It is used in applications such as robotics and data mining.
* Probabilistic reasoning is a form of reasoning which deals with uncertain situations. It is used to make decisions in uncertain situations.
