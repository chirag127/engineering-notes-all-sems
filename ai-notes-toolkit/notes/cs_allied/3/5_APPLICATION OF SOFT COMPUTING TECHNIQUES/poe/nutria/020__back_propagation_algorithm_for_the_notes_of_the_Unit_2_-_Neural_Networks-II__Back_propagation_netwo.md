
### Back Propagation Algorithm

Back propagation is a supervised learning algorithm used in the training of neural networks. It is used to adjust the weights of the neurons in a neural network in order to minimize the error between the predicted output and the desired output.

The algorithm works by propagating the error backwards through the network, adjusting the weights of the neurons to minimize the error. This is done in two steps:

1. **Forward Pass:** The input is passed through the network and the output is calculated.
2. **Backward Pass:** The error is calculated by comparing the predicted output and the desired output. The error is then propagated backwards through the network and the weights are adjusted accordingly.

Back propagation is an iterative process, meaning that it is repeated until the desired output is achieved. The number of iterations required depends on the complexity of the network and the amount of data being used.

The back propagation algorithm is used in many different applications such as computer vision, natural language processing and robotics. It is also used in deep learning networks, where it is used to train the network to recognize patterns and make predictions.
