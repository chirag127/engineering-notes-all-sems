### Measures of Central Tendency

- Measures of central tendency are numerical values that summarize the distribution of a variable by indicating its center or typical value.
- There are three common measures of central tendency: mean, median and mode.
- Mean: The mean of a variable is the sum of all its values divided by the number of values. It is also called the average or the arithmetic mean. The mean is sensitive to outliers or extreme values in the data. The formula for the mean of a variable x is:

```
mean(x) = sum(x) / n
```
where n is the number of values in x.

- Median: The median of a variable is the middle value when the values are arranged in ascending or descending order. If there is an even number of values, the median is the average of the middle two values. The median is not affected by outliers or extreme values in the data. The formula for the median of a variable x is:

```
median(x) = x[(n+1)/2] if n is odd
median(x) = (x[n/2] + x[n/2 + 1]) / 2 if n is even
```
where n is the number of values in x.

- Mode: The mode of a variable is the most frequent value in the data. There can be more than one mode if there are multiple values with the same frequency. The mode is not affected by outliers or extreme values in the data. The formula for the mode of a variable x is:

```
mode(x) = the value(s) of x that have the highest frequency
```

- Example: Consider the following data on the heights (in cm) of 10 students:

```
x = [160, 165, 170, 175, 180, 185, 190, 195, 200, 205]
```

- The mean of x is:

```
mean(x) = sum(x) / n
mean(x) = (160 + 165 + ... + 205) / 10
mean(x) = 182.5
```

- The median of x is:

```
median(x) = (x[n/2] + x[n/2 + 1]) / 2 if n is even
median(x) = (x[10/2] + x[10/2 + 1]) / 2
median(x) = (x[5] + x[6]) / 2
median(x) = (180 + 185) / 2
median(x) = 182.5
```

- The mode of x is:

```
mode(x) = the value(s) of x that have the highest frequency
```
Since all the values in x have the same frequency of 1, there is no mode for x.
