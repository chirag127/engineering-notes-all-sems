### Vector Space

- A vector space is a set of objects called vectors, which can be added together and multiplied by scalars (numbers), satisfying certain rules.
- The rules are called axioms and they ensure that the operations of vector addition and scalar multiplication are well-defined and have the properties we expect from linear algebra.
- A vector space has two operations: vector addition and scalar multiplication.
- Vector addition is a way of combining two vectors to get a new vector. It is denoted by the symbol + and it is commutative, associative, and has an identity element and an inverse element.
- Scalar multiplication is a way of scaling a vector by a number. It is denoted by the symbol * and it is distributive over vector addition and scalar addition, and has an identity element and a zero element.
- A vector space also has a set of scalars, which are usually real or complex numbers, that can be used to multiply vectors.
- A vector space must satisfy the following eight axioms for any vectors u, v, w and any scalars a, b:

  1. u + v = v + u (commutativity of vector addition)
  2. (u + v) + w = u + (v + w) (associativity of vector addition)
  3. There exists a vector 0 such that u + 0 = u for any u (existence of additive identity)
  4. For any u, there exists a vector -u such that u + (-u) = 0 (existence of additive inverse)
  5. a * (u + v) = a * u + a * v (distributivity of scalar multiplication over vector addition)
  6. (a + b) * u = a * u + b * u (distributivity of scalar multiplication over scalar addition)
  7. a * (b * u) = (a * b) * u (associativity of scalar multiplication)
  8. There exists a scalar 1 such that 1 * u = u for any u (existence of multiplicative identity)

- A vector space can have different dimensions, depending on how many independent vectors are needed to span the space. A vector space with n dimensions is called an n-dimensional vector space or R^n.
- A vector space can also have different bases, which are sets of linearly independent vectors that span the space. A basis can be used to represent any vector in the space as a linear combination of the basis vectors. A basis is not unique, but the number of basis vectors is always equal to the dimension of the space.
