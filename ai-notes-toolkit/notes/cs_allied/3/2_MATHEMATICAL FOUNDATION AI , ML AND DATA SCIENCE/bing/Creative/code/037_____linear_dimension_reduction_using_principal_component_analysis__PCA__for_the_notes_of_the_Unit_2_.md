### Linear dimension reduction using principal component analysis (PCA)

- Linear dimension reduction is a technique that aims to reduce the number of features or variables in a data set while preserving as much information as possible.
- Principal component analysis (PCA) is one of the most popular linear dimension reduction algorithms. It is a projection based method that transforms the data by projecting it onto a set of orthogonal (perpendicular) axes .
- The axes are called principal components (PCs) and they are ordered by the amount of variance they explain in the data. The first PC explains the most variance, the second PC explains the second most variance, and so on.
- The PCs are linear combinations of the original features, and they are uncorrelated with each other. The coefficients of the linear combinations are called loadings and they indicate how much each feature contributes to each PC .
- The PCs can be computed by using eigenvalue decomposition or singular value decomposition on the covariance matrix or the correlation matrix of the data  .
- The number of PCs is equal to the number of original features, but usually only a few PCs are needed to capture most of the information in the data. The optimal number of PCs can be determined by using various criteria, such as the proportion of variance explained, the scree plot, the Kaiser rule, or the elbow method  .
- PCA can be used for various purposes, such as data visualization, data compression, feature extraction, noise reduction, or data preprocessing  .
- PCA has some limitations, such as being sensitive to outliers, being affected by scaling of the features, and being unable to capture nonlinear relationships in the data  .
- PCA can be extended or modified by using different methods, such as kernel PCA, sparse PCA, robust PCA, or nonlinear PCA  .
