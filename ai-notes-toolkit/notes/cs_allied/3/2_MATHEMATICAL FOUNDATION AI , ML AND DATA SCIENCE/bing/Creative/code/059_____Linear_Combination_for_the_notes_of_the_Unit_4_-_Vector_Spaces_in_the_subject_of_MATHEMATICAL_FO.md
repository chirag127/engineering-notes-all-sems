### Linear Combination

- A linear combination of a set of vectors $\{v_1, v_2, ..., v_n\}$ is a vector that can be expressed as a sum of scalar multiples of those vectors, i.e., $c_1v_1 + c_2v_2 + ... + c_nv_n$, where $c_1, c_2, ..., c_n$ are scalars.
- A linear combination can also be written in matrix form as $Ax$, where $A$ is a matrix whose columns are the vectors $\{v_1, v_2, ..., v_n\}$ and $x$ is a column vector whose entries are the scalars $\{c_1, c_2, ..., c_n\}$.
- A linear combination is a way of creating new vectors from existing ones, and it is useful for studying properties of vector spaces, such as span, linear independence, basis, and dimension.
- The span of a set of vectors $\{v_1, v_2, ..., v_n\}$ is the set of all possible linear combinations of those vectors, i.e., $\{c_1v_1 + c_2v_2 + ... + c_nv_n | c_1, c_2, ..., c_n \in \mathbb{R}\}$.
- A set of vectors $\{v_1, v_2, ..., v_n\}$ is linearly independent if the only linear combination that gives the zero vector is the trivial one, i.e., $c_1v_1 + c_2v_2 + ... + c_nv_n = 0$ implies $c_1 = c_2 = ... = c_n = 0$.
- A set of vectors $\{v_1, v_2, ..., v_n\}$ is linearly dependent if it is not linearly independent, i.e., there exists a nontrivial linear combination that gives the zero vector, i.e., $c_1v_1 + c_2v_2 + ... + c_nv_n = 0$ for some $c_1, c_2, ..., c_n$ not all zero.
- A basis of a vector space is a linearly independent set of vectors that spans the whole space, i.e., any vector in the space can be written as a unique linear combination of the basis vectors.
- The dimension of a vector space is the number of vectors in any basis of the space, i.e., the minimum number of vectors needed to span the space.
