# Random Variable

A random variable is a variable whose values are determined by the outcomes of a random event. In other words, it is a function that assigns a numerical value to each outcome of a random event.

There are two types of random variables: discrete and continuous.

## Discrete Random Variable

A discrete random variable is one that can take on a finite or countably infinite number of values. For example, the number of heads that come up when flipping a coin three times is a discrete random variable, as it can take on the values 0, 1, 2, or 3.

The probability distribution of a discrete random variable is given by a probability mass function, which assigns a probability to each possible value of the random variable.

## Continuous Random Variable

A continuous random variable is one that can take on any value within a certain range or set of ranges. For example, the time it takes for a particular machine to complete a task is a continuous random variable, as it can take on any positive real value.

The probability distribution of a continuous random variable is given by a probability density function, which assigns a probability to each interval of values that the random variable can take on.

In summary, a random variable is a variable whose values are determined by the outcomes of a random event, and can be either discrete or continuous. The probability distribution of a random variable is given by either a probability mass function or a probability density function, depending on whether the random variable is discrete or continuous. This is an important concept in the study of statistics and probability, and is a fundamental building block for understanding more advanced topics in these fields.
