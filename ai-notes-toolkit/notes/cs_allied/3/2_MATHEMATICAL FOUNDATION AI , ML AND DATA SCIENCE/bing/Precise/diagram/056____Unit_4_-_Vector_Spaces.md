# Unit 4 - Vector Spaces

A vector space is a collection of vectors that can be added together and multiplied by scalars to produce another vector in the same space. Some important properties of vector spaces are:

1. Closure under addition: If u and v are vectors in the space, then u + v is also in the space.
2. Closure under scalar multiplication: If u is a vector in the space and c is a scalar, then cu is also in the space.
3. Commutativity of addition: If u and v are vectors in the space, then u + v = v + u.
4. Associativity of addition: If u, v, and w are vectors in the space, then (u + v) + w = u + (v + w).
5. Additive identity: There exists a vector 0 in the space such that for any vector u in the space, u + 0 = u.
6. Additive inverse: For any vector u in the space, there exists a vector -u in the space such that u + (-u) = 0.
7. Distributivity of scalar multiplication over vector addition: If u and v are vectors in the space and c is a scalar, then c(u + v) = cu + cv.
8. Distributivity of scalar multiplication over scalar addition: If u is a vector in the space and c and d are scalars, then (c + d)u = cu + du.
9. Associativity of scalar multiplication: If u is a vector in the space and c and d are scalars, then (cd)u = c(du).
10. Multiplicative identity: There exists a scalar 1 such that for any vector u in the space, 1u = u.

These properties define the structure of a vector space and allow us to perform algebraic operations on vectors. Some common examples of vector spaces include the set of all n-dimensional real vectors, the set of all polynomials of degree n or less, and the set of all continuous functions on a given interval.
