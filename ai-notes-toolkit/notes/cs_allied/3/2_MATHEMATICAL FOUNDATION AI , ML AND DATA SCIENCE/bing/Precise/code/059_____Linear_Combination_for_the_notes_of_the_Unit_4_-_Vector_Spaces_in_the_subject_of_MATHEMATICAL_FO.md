### Linear Combination

- A linear combination is an expression constructed from a set of terms by multiplying each term by a constant and adding the results.
- In the context of vector spaces, a linear combination is a sum of scalar multiples of vectors.
- For example, if `v1`, `v2`, and `v3` are vectors in a vector space, then any expression of the form `a1*v1 + a2*v2 + a3*v3`, where `a1`, `a2`, and `a3` are scalars, is a linear combination of `v1`, `v2`, and `v3`.
- The set of all linear combinations of a set of vectors is called the span of the set.
- If the set of vectors is linearly independent, then the span of the set is a vector space.
- Linear combinations are important in many areas of mathematics, including linear algebra, geometry, and functional analysis.
- In particular, linear combinations are used to define linear transformations, which are fundamental in the study of vector spaces.
