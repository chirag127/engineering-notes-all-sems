## Unit 5 - Linear Transformations

A linear transformation is a function that maps vectors from one vector space to another vector space, preserving the operations of vector addition and scalar multiplication. 

Some examples of linear transformations are:

- Scaling: multiplying a vector by a scalar to change its magnitude or direction.
- Rotation: rotating a vector by an angle to change its direction.
- Projection: projecting a vector onto a subspace to reduce its dimension.
- Reflection: reflecting a vector across a line or a plane to change its direction.

To define a linear transformation, we need to specify two things:

- The domain: the vector space from which the input vectors are taken.
- The codomain: the vector space to which the output vectors are mapped.

A linear transformation can be represented by a matrix, which is a rectangular array of numbers that encodes how the basis vectors of the domain are mapped to the codomain. 

The matrix of a linear transformation can be found by applying the transformation to the standard basis vectors of the domain and writing the resulting vectors as the columns of the matrix.

The matrix of a linear transformation can also be used to find the image of any vector in the domain by multiplying the matrix by the vector.

Some properties of linear transformations are:

- The zero vector is always mapped to the zero vector.
- The identity transformation maps every vector to itself.
- The composition of two linear transformations is also a linear transformation.
- The inverse of a linear transformation, if it exists, is also a linear transformation.
