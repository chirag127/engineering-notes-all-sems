
### Orthogonalization by Householder Transformations (QR)

* Orthogonalization is a process of transforming a set of vectors into a set of orthogonal vectors.
* Householder transformations are a type of orthogonal transformation that can be used to orthogonalize a set of vectors.
* QR decomposition is a type of Householder transformation that is used to decompose a matrix into a product of two matrices: an orthogonal matrix and an upper triangular matrix.
* QR decomposition can be used to find the least squares solution to a system of linear equations.
* QR decomposition can also be used to calculate the eigenvalues and eigenvectors of a matrix.
