

## Unit 5 - Linear Transformations

1. A linear transformation is a mathematical operation that takes an input vector and produces an output vector with the same number of elements. 
2. Linear transformations can be represented as matrices, which are collections of numbers arranged in rows and columns. 
3. The matrix of a linear transformation contains information about how the output vector is related to the input vector. 
4. A linear transformation can be thought of as a function that takes an input vector and produces an output vector. 
5. The matrix of a linear transformation is called the transformation matrix. 
6. The transformation matrix can be used to determine the output vector of a linear transformation given an input vector. 
7. Linear transformations can be used to transform a set of points in the plane from one coordinate system to another. 
8. Linear transformations can also be used to transform a set of vectors from one coordinate system to another. 
9. Linear transformations can be used to rotate, scale, and reflect points and vectors in the plane. 
10. Linear transformations can be used to solve systems of linear equations.
