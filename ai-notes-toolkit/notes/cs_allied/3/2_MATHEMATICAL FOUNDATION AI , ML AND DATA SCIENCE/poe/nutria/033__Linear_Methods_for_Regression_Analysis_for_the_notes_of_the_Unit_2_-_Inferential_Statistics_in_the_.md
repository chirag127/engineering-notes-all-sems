
### Linear Methods for Regression Analysis

Regression analysis is a statistical technique used to model and analyze relationships between variables. It can be used to make predictions about the future based on past data. Linear regression is one of the most commonly used methods for regression analysis.

1. Simple Linear Regression: Simple linear regression is a technique used to predict the value of a dependent variable (Y) based on the value of an independent variable (X). It assumes a linear relationship between the two variables.

2. Multiple Linear Regression: Multiple linear regression is a technique used to predict the value of a dependent variable (Y) based on the values of two or more independent variables (X1, X2, X3, etc.). It assumes a linear relationship between the variables.

3. Polynomial Regression: Polynomial regression is a technique used to predict the value of a dependent variable (Y) based on the values of an independent variable (X). It assumes a non-linear relationship between the variables.

4. Logistic Regression: Logistic regression is a technique used to predict the probability of an event occurring based on the values of one or more independent variables (X1, X2, X3, etc.). It assumes a logistic (sigmoid) relationship between the variables.

5. Stepwise Regression: Stepwise regression is a technique used to select the best subset of independent variables (X1, X2, X3, etc.) for predicting the value of a dependent variable (Y). It uses a stepwise approach to identify the most important variables.
