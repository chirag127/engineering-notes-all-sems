
### Dimension for the Notes of Unit 4 - Vector Spaces in Mathematical Foundations of AI, ML and Data Science

1. A **vector space** is a set of objects that can be added and multiplied by scalars. It is a mathematical structure that allows for the manipulation of vectors.

2. **Linear combinations** of vectors are used to represent any vector in the space. These linear combinations are the basis for many operations, such as matrix multiplication, that are used in AI, ML and data science.

3. The **dimension** of a vector space is the number of vectors that are needed to span the space. This can be thought of as the number of degrees of freedom that a vector has in the space.

4. A **basis** is a set of vectors that span the space. These vectors are linearly independent, meaning that none of them can be expressed as a linear combination of the other vectors.

5. The **span** of a set of vectors is the set of all vectors that can be expressed as a linear combination of the given vectors.

6. A **subspace** is a subset of a vector space that is also a vector space. It is defined by a set of constraints on the vectors in the space.

7. **Linear transformations** are functions that map vectors in one vector space to vectors in another vector space. These are used to describe operations on vectors such as rotation, scaling and reflection.

8. **Eigenvectors** are vectors whose direction is unchanged by a linear transformation. They are used to describe the properties of a linear transformation.
