### Markov chains for the notes of the Unit 3 - Pseudo-Random Numbers

1. A Markov chain is a mathematical model of how a random process changes from one state to the next. It is often used to simulate a random process over time.
2. A Markov chain has the Markov property which states that the probability of transitioning to a future state depends only on the present state and not on the sequence of events that led to the present state.
3. Markov chains are often used to model sequences of decisions or transitions in sequential systems or processes. They are used in various applications such as speech recognition, robotic systems, optimization algorithms etc.
4. To define a Markov chain, we need to specify the following:

- A finite set of states. For example, S = {Sunny, Rainy, Cloudy} could represent weather states.
- Transition probabilities. For each pair of states i and j, we specify the probability of transitioning from state i to state j. These probabilities are represented using a transition probability matrix P.
- An initial state distribution. This specifies the probability distribution over the states at the initial time step.

5. To simulate a Markov chain, we simulate transitions from one state to the next using the transition probabilities. At each step, we generate a random number to determine the next state based on the probabilities in the transition matrix P. This process is repeated to generate a sample path or trajectory of the Markov chain.
