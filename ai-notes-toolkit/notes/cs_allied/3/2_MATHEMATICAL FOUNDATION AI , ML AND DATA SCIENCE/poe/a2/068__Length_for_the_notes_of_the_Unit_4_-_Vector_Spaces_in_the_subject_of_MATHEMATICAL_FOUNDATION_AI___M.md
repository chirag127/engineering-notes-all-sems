### Vector Spaces

- A vector space is a collection of vectors where vector addition, scalar multiplication and the operations of addition and scalar multiplication satisfy the requirements of closure, associativity, identity, and distributivity.
- Examples of vector spaces: Rn, Cn, functions, sequences, matrices, etc.
- Basis: A basis for a vector space is a set of linearly independent vectors that span the vector space. Every vector in the vector space can be written as a unique linear combination of the basis vectors.
- Dimension: The dimension of a vector space is the number of vectors in any basis for the vector space. All bases for a vector space have the same number of vectors and this is the dimension of the vector space.
- Subspaces: A subspace of a vector space is a subset of vectors that is itself a vector space. The subspace must be spanned by the vectors it contains and must be closed under vector addition and scalar multiplication.
- Linear dependence and independence: A set of vectors {v1, v2, ..., vk} is linearly dependent if at least one vector can be written as a linear combination of the others. The vectors are linearly independent if no vector can be written as a linear combination of the others.
- Spanning sets and bases: A spanning set for a vector space is a set of vectors whose linear combinations span the vector space. A basis is a spanning set of linearly independent vectors.
- Linear transformations: A function T: V → W between two vector spaces is a linear transformation if T(v + w) = T(v) + T(w) and T(cv) = cT(v) for all vectors v and w in V and all scalars c. The matrix of a linear transformation with respect to certain bases is the matrix representing the transformation of the basis vectors.
