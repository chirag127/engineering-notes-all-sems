## Unit 2 - Inferential Statistics

1. Point Estimation - Producing a single value that estimates some unknown parameter based on a sample. For example, calculating the sample mean as an estimate of the population mean.

2. Confidence Intervals - Producing a range of values that is likely to contain the unknown parameter. For example, calculating a 95% confidence interval for the population mean. This incorporates the sampling variability into the estimate.

3. Hypothesis Testing - Making judgments about potential values of a population parameter. The null hypothesis is a claim about the parameter value, and the alternative hypothesis is the opposite. A p-value is calculated to determine if the sample evidence supports rejecting the null hypothesis. For example, testing if the population mean is equal to a certain value.

4. Analysis of Variance (ANOVA) - Testing if the means of multiple groups are equal. The F-test is used to determine if there is a statistically significant difference between at least two of the group means. For example, testing if exam scores differ based on three different teaching methods.

5. Regression Analysis - Examining the relationship between a dependent variable and one or more independent variables using a line of best fit. The goal is to predict the value of the dependent variable given the independent variables. For example, determining if exam scores can be predicted based on hours of studying and hours of sleep per night.
