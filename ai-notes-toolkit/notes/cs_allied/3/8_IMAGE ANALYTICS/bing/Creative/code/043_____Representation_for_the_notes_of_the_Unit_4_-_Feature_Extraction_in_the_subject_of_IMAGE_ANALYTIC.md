# Representation for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

- Feature extraction is the process of transforming an initial set of measured data (such as pixel values of an image) into a set of derived values (features) that are informative, non-redundant, and suitable for subsequent learning and generalization tasks .
- Features are the characteristics or properties of an image that can be used for identification, classification, diagnosis, recognition, clustering, detection, etc. Examples of features are edges, corners, textures, colors, shapes, etc.
- Feature extraction can be performed by different methods, depending on the type and purpose of the data. Some of the common methods are :
  - Calculation-based: These methods use mathematical operations and formulas to compute features from the data. Examples are histogram, Fourier transform, wavelet transform, etc.
  - Recognition-based: These methods use machine learning models and algorithms to learn and recognize features from the data. Examples are principal component analysis, linear discriminant analysis, convolutional neural networks, etc.
  - Simulation-based: These methods use physical or biological models and simulations to generate features from the data. Examples are optical flow, saliency map, deep dream, etc.
- Feature extraction can be done at different levels of abstraction, such as low-level, mid-level, and high-level. Low-level features are the basic and simple features that can be directly computed from the data, such as edges, colors, gradients, etc. Mid-level features are the intermediate and complex features that can be derived from the low-level features, such as contours, regions, textures, etc. High-level features are the abstract and semantic features that can be inferred from the mid-level features, such as objects, faces, scenes, etc.
- Feature extraction can be done in different domains, such as spatial, frequency, time, etc. Spatial features are the features that are extracted from the spatial arrangement and distribution of the data, such as shape, size, location, etc. Frequency features are the features that are extracted from the frequency spectrum and components of the data, such as energy, amplitude, phase, etc. Time features are the features that are extracted from the temporal variation and dynamics of the data, such as speed, acceleration, motion, etc.
- Feature extraction can be done in different modes, such as global, local, or hybrid. Global features are the features that are extracted from the whole data, such as mean, variance, entropy, etc. Local features are the features that are extracted from the parts or regions of the data, such as keypoints, descriptors, patches, etc. Hybrid features are the features that are extracted from the combination of global and local features, such as bag of words, Fisher vectors, etc.
