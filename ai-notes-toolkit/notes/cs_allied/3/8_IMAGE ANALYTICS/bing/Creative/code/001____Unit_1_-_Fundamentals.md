## Unit 1 - Fundamentals

This unit covers the basic concepts and principles of computer science, such as:

- Data representation: how different types of data, such as numbers, text, images, sound, and video, are stored and manipulated by computers using binary digits (bits).
- Data structures: how data can be organized and accessed efficiently using different abstract data types, such as arrays, lists, stacks, queues, trees, graphs, and hash tables.
- Algorithms: how to design, analyze, and implement step-by-step procedures to solve problems and perform tasks using computers, such as sorting, searching, encryption, compression, and artificial intelligence.
- Programming paradigms: how to choose and use different programming languages and styles, such as imperative, declarative, functional, object-oriented, and logic programming, to express algorithms and data structures.
- Software engineering: how to apply engineering principles and practices to develop high-quality software systems, such as requirements analysis, design, testing, debugging, documentation, and maintenance.
- Hardware architecture: how the physical components and devices of a computer system, such as the central processing unit (CPU), memory, input/output (I/O) devices, and buses, work together to execute instructions and process data.
- Operating systems: how the software that manages the resources and activities of a computer system, such as the kernel, file system, process management, memory management, device drivers, and user interface, provides an abstraction layer between the hardware and the applications.
- Networks: how computers communicate and share data and resources over a network, such as the Internet, using protocols, such as the Transmission Control Protocol/Internet Protocol (TCP/IP), the Hypertext Transfer Protocol (HTTP), and the Domain Name System (DNS).
- Security: how to protect the confidentiality, integrity, and availability of data and systems from unauthorized access, modification, or damage, using techniques, such as encryption, authentication, authorization, and firewalls.
- Ethics: how to identify and analyze the ethical and social implications of computing, such as privacy, intellectual property, digital divide, and artificial intelligence, and how to apply ethical principles and codes of conduct to make responsible decisions.
