### Image Negatives

- An image negative is a type of image that has the opposite colors of the original image. 
- In a negative image, the dark areas appear light and the light areas appear dark. 
- An image negative can be created by subtracting each pixel value from the maximum pixel value in the image. 
- For example, if the maximum pixel value is 255, then the negative of a pixel with value 100 is 255 - 100 = 155. 
- An image negative can be used for various purposes, such as enhancing the contrast, revealing hidden details, creating artistic effects, or reversing the effects of old film negatives. 
- An image negative can be applied to grayscale, color, or binary images. 
- For grayscale images, the negative is obtained by subtracting each pixel value from 255. 
- For color images, the negative is obtained by subtracting each pixel value from the maximum value in each color channel. For example, if the maximum value in the red channel is 255, then the negative of a pixel with red value 100 is 255 - 100 = 155. The same applies to the green and blue channels. 
- For binary images, the negative is obtained by inverting each pixel value. For example, if the pixel value is 0 (black), then the negative is 1 (white), and vice versa.
