## Unit 4 - Feature Extraction

- Feature extraction is the process of transforming raw data into a set of features that can be used for machine learning tasks, such as classification, clustering, or regression.
- Features are the attributes or characteristics of the data that are relevant for the task at hand. They can be numerical, categorical, or textual.
- Feature extraction aims to reduce the dimensionality of the data, remove noise and redundancy, and enhance the interpretability and generalization of the models.
- Feature extraction can be done in different ways, depending on the type and structure of the data. Some common methods are:

  - **Statistical methods**: These methods use descriptive statistics, such as mean, standard deviation, skewness, kurtosis, etc., to summarize the distribution and variability of the data. They can also use correlation, covariance, or mutual information to measure the relationship between variables.
  - **Transform methods**: These methods use mathematical functions, such as Fourier transform, wavelet transform, principal component analysis, etc., to project the data into a lower-dimensional space, where the most important features are preserved and the noise and redundancy are reduced.
  - **Feature selection methods**: These methods use criteria, such as information gain, chi-square, or Fisher score, to rank and select the most relevant features from the original data. They can also use algorithms, such as greedy search, genetic algorithms, or recursive feature elimination, to find the optimal subset of features that maximize the performance of the models.
  - **Feature engineering methods**: These methods use domain knowledge, creativity, and intuition to create new features from the existing data, or to combine or transform existing features into more meaningful ones. They can also use techniques, such as binning, scaling, encoding, or embedding, to preprocess the data and make it suitable for the models.
