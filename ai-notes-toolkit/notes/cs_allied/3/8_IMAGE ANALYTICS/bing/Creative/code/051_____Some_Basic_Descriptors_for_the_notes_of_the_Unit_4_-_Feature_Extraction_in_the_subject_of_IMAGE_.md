### Some Basic Descriptors

- Descriptors are numerical or symbolic values that represent some characteristic or property of an image or its regions.
- Descriptors can be used for various purposes, such as image classification, retrieval, segmentation, recognition, etc.
- Descriptors can be classified into two types: global and local.
- Global descriptors capture the overall information of the image, such as color, texture, shape, etc. They are usually computed from the whole image or a large region of interest.
- Local descriptors capture the details of the image, such as edges, corners, keypoints, etc. They are usually computed from small patches or windows around specific locations of interest.
- Some examples of global descriptors are:
  - Color histogram: a representation of the distribution of colors in an image, which can be computed in different color spaces, such as RGB, HSV, LAB, etc.
  - Texture features: a representation of the patterns or variations of intensity or color in an image, which can be computed using different methods, such as co-occurrence matrix, Gabor filters, wavelets, etc.
  - Shape features: a representation of the contour or boundary of an object or region in an image, which can be computed using different methods, such as moments, Fourier descriptors, Hu invariants, etc.
- Some examples of local descriptors are:
  - Edge detector: a method to identify the pixels where there is a significant change of intensity or color in an image, which can be computed using different operators, such as Sobel, Canny, Laplacian, etc.
  - Corner detector: a method to identify the pixels where there are two or more edges meeting at an angle in an image, which can be computed using different methods, such as Harris, FAST, SIFT, etc.
  - Keypoint detector: a method to identify the pixels that are distinctive or salient in an image, which can be computed using different methods, such as SIFT, SURF, ORB, etc.
  - Feature descriptor: a method to extract a vector of values that describe the appearance or properties of a keypoint or a patch in an image, which can be computed using different methods, such as SIFT, SURF, ORB, HOG, etc.
