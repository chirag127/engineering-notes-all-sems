### Some Basic Intensity Transformation Functions for the notes of the Unit 1 - Fundamentals in the subject of IMAGE ANALYTICS

- Intensity transformation is a basic digital image processing technique, where the pixel intensity levels of an image are transformed to new values using a mathematical transformation function, so as to get a new output image.
- Intensity transformations are in the spatial domain, i.e. they are performed directly on the pixels of the image at hand, as opposed to being performed on the Fourier transform of the image.
- Intensity transformations are applied on images for contrast manipulation or image thresholding.
- The following are some commonly used intensity transformation functions  :

  - **Linear transformation**: This is the simplest form of intensity transformation, where the output pixel value is a linear function of the input pixel value. For example, the negative transformation is a linear transformation that reverses the intensity levels of an image, i.e. s = L - 1 - r, where s is the output pixel value, r is the input pixel value, and L is the number of intensity levels. The negative transformation can be used to enhance white or gray detail embedded in dark regions of an image.
  - **Logarithmic transformation**: This is a nonlinear transformation that maps a narrow range of low intensity values to a wider range of output values, and vice versa. For example, the log transformation is given by s = c log(1 + r), where c is a constant. The log transformation can be used to expand the values of dark pixels in an image while compressing the higher-level values. The log transformation also reduces the dynamic range of an image.
  - **Power-law (gamma) transformation**: This is another nonlinear transformation that has the form s = c r^γ, where c and γ are positive constants. The power-law transformation can be used to perform contrast stretching or compression, depending on the value of γ. For example, when γ < 1, the transformation is a curve that maps a narrow range of dark input values into a wider range of output values, with the opposite being true for higher values of input levels. This can be used to enhance dark details in an image. When γ > 1, the opposite is true, and the transformation can be used to enhance light details in an image.
  - **Piecewise-linear transformation**: This is a transformation that consists of several linear segments, each with a different slope and intercept. For example, the contrast stretching transformation is a piecewise-linear transformation that increases the contrast of an image by mapping the low and high input values to the minimum and maximum output values, respectively, and linearly interpolating the values in between. Another example is the thresholding transformation, which sets the output value to either 0 or 1 depending on whether the input value is below or above a certain threshold.
  - **Histogram equalization**: This is a transformation that aims to produce an output image that has a uniform histogram, i.e. the output image has approximately the same number of pixels at each gray level. Histogram equalization can be used to enhance the contrast of an image by spreading out the most frequent intensity values. The histogram equalization transformation is given by s = T(r), where T(r) is the cumulative distribution function of the input image.
