### Regional Feature Descriptors

- Regional feature descriptors are methods to extract and describe distinctive points or regions in an image that can be used for image analysis tasks such as matching, retrieval, and classification.
- Regional feature descriptors consist of two steps: feature detection and feature description.
- Feature detection is the process of finding salient points or regions in an image that are invariant to changes in scale, rotation, illumination, and viewpoint. Examples of feature detectors are Harris corner detector, SIFT, SURF, FAST, ORB, etc.
- Feature description is the process of computing a signature or a vector for each detected feature that captures its local appearance and geometry. Examples of feature descriptors are SIFT, SURF, ORB, BRIEF, FREAK, LBP, etc.
- Regional feature descriptors can be classified into two types: local and global.
- Local feature descriptors are computed for each detected feature independently and describe a small neighborhood around the feature. Local feature descriptors are suitable for image matching and registration tasks, as they can handle partial occlusions and large viewpoint changes. However, local feature descriptors are not very discriminative and require a large number of features to represent an image.
- Global feature descriptors are computed for the whole image or a large region of the image and describe its overall characteristics. Global feature descriptors are suitable for image retrieval and classification tasks, as they can capture the semantic content and the style of the image. However, global feature descriptors are not very robust to occlusions and viewpoint changes and may lose some fine details of the image.
- Some methods to combine local and global feature descriptors are:
  - Bag-of-words (BoW): A method to represent an image as a histogram of visual words, where each visual word is a cluster of similar local feature descriptors. BoW can capture the distribution of local features in an image, but it ignores their spatial arrangement and geometry.
  - Spatial pyramid matching (SPM): A method to extend BoW by dividing the image into a hierarchical grid of sub-regions and computing a BoW histogram for each sub-region. SPM can preserve some spatial information of the local features, but it is still sensitive to the choice of the grid size and the visual vocabulary size.
  - Vector of locally aggregated descriptors (VLAD): A method to encode the local feature descriptors by computing the residual vectors between each descriptor and its nearest visual word in a codebook. VLAD can reduce the dimensionality of the feature representation and retain some geometric information of the local features, but it is still dependent on the codebook size and the quantization error.
  - Fisher vector (FV): A method to encode the local feature descriptors by computing the gradient vectors of a Gaussian mixture model (GMM) fitted to the descriptors. FV can capture the distribution and the variance of the local features and is less sensitive to the codebook size and the quantization error, but it has a high dimensionality and requires a large training set to estimate the GMM parameters.
