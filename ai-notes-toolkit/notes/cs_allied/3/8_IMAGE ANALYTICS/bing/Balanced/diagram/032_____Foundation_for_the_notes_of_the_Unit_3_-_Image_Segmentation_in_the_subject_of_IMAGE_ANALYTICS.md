### Foundation for the notes of the Unit 3 - Image Segmentation in the subject of IMAGE ANALYTICS

- Image segmentation is the process of dividing a digital image into subgroups called image segments, reducing the complexity of the image and enabling further processing or analysis of each image segment.
- Image segmentation is typically used to locate objects and boundaries (lines, curves, etc.) in images .
- Image segmentation is the assignment of labels to pixels to identify objects, people, or other important elements in the image.
- Image segmentation can be done based on various heuristics, or high-level image features, such as color, intensity, texture, shape, etc.
- Image segmentation can be classified into two main types: supervised and unsupervised.
  - Supervised image segmentation uses a set of labeled images as training data to learn a model that can segment new images.
  - Unsupervised image segmentation does not use any labeled data, but relies on clustering algorithms to group pixels based on their similarity.
- Image segmentation can be further categorized into several techniques, such as thresholding, region-based, edge-based, graph-based, etc.
  - Thresholding is a simple technique that segments an image based on a predefined threshold value for pixel intensity.
  - Region-based segmentation is a technique that segments an image by growing regions from seed pixels based on some homogeneity criteria.
  - Edge-based segmentation is a technique that segments an image by detecting edges or boundaries between regions using filters or gradients.
  - Graph-based segmentation is a technique that segments an image by representing it as a graph, where nodes are pixels and edges are weights based on pixel similarity, and then partitioning the graph into subgraphs using algorithms such as minimum spanning tree or normalized cuts.
- Image segmentation is an important and challenging task in image analytics, as it can be used for various applications, such as object detection, face recognition, medical imaging, etc.
