### Some Basic Descriptors

- Descriptors are numerical or symbolic representations of image features that can be used for various tasks such as classification, recognition, retrieval, etc.
- Descriptors can be categorized into two types: global and local.
- Global descriptors capture the overall characteristics of an image, such as color, texture, shape, etc. They are usually computed from the whole image or a large region of interest.
- Local descriptors capture the details of specific image regions, such as corners, edges, keypoints, etc. They are usually computed from small patches or windows around the regions of interest.
- Some examples of global descriptors are:
  - Color histogram: a representation of the distribution of colors in an image, which can be used to measure color similarity or contrast between images.
  - Texture features: a representation of the spatial variation of pixel intensities in an image, which can be used to measure texture similarity or diversity between images. Some common methods to extract texture features are gray-level co-occurrence matrix (GLCM), local binary patterns (LBP), Gabor filters, etc.
  - Shape features: a representation of the contour or boundary of an object or region in an image, which can be used to measure shape similarity or difference between images. Some common methods to extract shape features are Fourier descriptors, moment invariants, Hu moments, etc.
- Some examples of local descriptors are:
  - Edge features: a representation of the locations and orientations of edges in an image, which can be used to detect boundaries, contours, or salient regions in an image. Some common methods to extract edge features are Canny edge detector, Sobel operator, Laplacian of Gaussian (LoG), etc.
  - Corner features: a representation of the locations and orientations of corners in an image, which can be used to detect interest points, keypoints, or landmarks in an image. Some common methods to extract corner features are Harris corner detector, Shi-Tomasi corner detector, FAST detector, etc.
  - Keypoint features: a representation of the locations and descriptors of keypoints in an image, which can be used to match or align images based on local similarity or correspondence. Some common methods to extract keypoint features are SIFT, SURF, ORB, etc.
