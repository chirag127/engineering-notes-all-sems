### Fundamentals of Spatial Filtering

- Spatial filtering is a technique for modifying or enhancing an image by applying a filter or a mask to each pixel of the image.
- A filter or a mask is a small matrix of numbers, usually of odd size, such as 3x3, 5x5, etc.
- The filter or mask is moved over the image, pixel by pixel, and a new value for each pixel is calculated by applying some operation to the values of the pixels under the filter or mask.
- The operation can be a linear combination, such as a weighted average, or a nonlinear function, such as a median or a threshold.
- The result of applying a filter or mask to an image is a new image, called the filtered image or the output image.
- The purpose of spatial filtering can be to enhance certain features of the image, such as edges, textures, or details, or to suppress noise, blur, or artifacts.
- Spatial filtering can be classified into two types: linear filtering and nonlinear filtering.
- Linear filtering is when the output pixel value is a linear function of the input pixel values under the filter or mask. For example, a linear filter can be a smoothing filter, which reduces noise by averaging the neighboring pixel values, or a sharpening filter, which enhances edges by subtracting a smoothed version of the image from the original image.
- Nonlinear filtering is when the output pixel value is a nonlinear function of the input pixel values under the filter or mask. For example, a nonlinear filter can be a median filter, which replaces each pixel value by the median of the neighboring pixel values, or a thresholding filter, which assigns a binary value to each pixel based on whether it is above or below a certain threshold.
