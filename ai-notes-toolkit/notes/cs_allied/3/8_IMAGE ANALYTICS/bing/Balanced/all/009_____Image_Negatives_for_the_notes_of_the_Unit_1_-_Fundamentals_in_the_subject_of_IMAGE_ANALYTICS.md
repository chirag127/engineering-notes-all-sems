# Image Negatives

- An image negative is an image that has the opposite colors and brightness values of the original image.  
- An image negative can be created by inverting the pixel values of the original image. For example, if the original image has RGB values of (255, 0, 0), the negative image will have RGB values of (0, 255, 255). 
- An image negative can be used for various purposes, such as:
  - Enhancing the contrast and details of the original image. 
  - Creating artistic effects or mood. 
  - Detecting defects or anomalies in the original image. 
  - Preparing the image for printing or scanning. 
- An image negative can be created using different methods, such as:
  - Using a negative film or paper, which reverses the tones of the original scene when exposed to light.  
  - Using a digital camera, which can capture the raw data of the image sensor and store it as a negative file. 
  - Using an image editing software, which can apply an inversion filter or function to the original image.
