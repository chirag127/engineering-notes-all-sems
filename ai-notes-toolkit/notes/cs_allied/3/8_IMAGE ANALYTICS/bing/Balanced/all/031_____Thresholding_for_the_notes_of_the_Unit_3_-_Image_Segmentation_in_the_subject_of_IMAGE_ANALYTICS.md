# Thresholding for the notes of the Unit 3 - Image Segmentation in the subject of IMAGE ANALYTICS

- Thresholding is one of the segmentation techniques that generates a binary image (a binary image is one whose pixels have only two values – 0 and 1 and thus requires only one bit to store pixel intensity) from a given grayscale image by separating it into two regions based on a threshold value.
- Image thresholding is a type of image segmentation that divides the foreground from the background in an image. In this technique, the pixel values are assigned corresponding to the provided threshold values. In computer vision, thresholding is done in grayscale images.
- Thresholding can be classified into two types: global and local. Global thresholding applies a single threshold value to the whole image, while local thresholding applies different threshold values to different regions of the image.
- Global thresholding can be further divided into two categories: histogram-based and entropy-based. Histogram-based methods use the statistical properties of the image histogram to determine the optimal threshold value, such as Otsu's method, Kapur's method, and Kittler's method. Entropy-based methods use the information theory concepts to measure the uncertainty or disorder of the image, such as Shannon's entropy, Renyi's entropy, and Tsallis entropy.
- Local thresholding can be further divided into two categories: adaptive and non-adaptive. Adaptive methods adjust the threshold value according to the local characteristics of the image, such as the mean, variance, or standard deviation of the pixel intensities. Non-adaptive methods use a fixed threshold value for each region, such as Niblack's method, Sauvola's method, and Bernsen's method.
- Thresholding can also be performed in a multilevel or multithresholding manner, where more than two regions are segmented from the image. Multithresholding can be achieved by using multiple threshold values or by using a weighted combination of different thresholding methods.
- Thresholding is the simplest method of image segmentation, but it has some limitations, such as sensitivity to noise, illumination variations, and histogram shape. Therefore, some preprocessing steps, such as smoothing, contrast enhancement, or histogram equalization, may be required before applying thresholding to improve the segmentation results.
