## Unit 3 - Image Segmentation

- Image segmentation is the process of dividing an image into meaningful regions or segments based on some criteria, such as color, texture, shape, or intensity.
- Image segmentation can be used for various applications, such as object detection, face recognition, medical imaging, scene understanding, and image editing.
- Image segmentation can be classified into two main types: supervised and unsupervised.
  - Supervised segmentation uses a set of labeled images as training data to learn a model that can segment new images based on the given labels. Examples of supervised segmentation methods are pixel classification, semantic segmentation, and instance segmentation.
  - Unsupervised segmentation does not use any labeled data, but relies on the intrinsic properties of the image pixels or regions to group them into segments. Examples of unsupervised segmentation methods are thresholding, clustering, region growing, and graph-based methods.
- Image segmentation can be evaluated using various metrics, such as accuracy, precision, recall, F1-score, IoU (intersection over union), and Dice coefficient. These metrics compare the predicted segments with the ground truth segments and measure how well they match.
