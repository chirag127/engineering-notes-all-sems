### Background for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

Feature extraction is an essential technique used in the field of image analytics to extract meaningful information from images. In this unit, we will cover the basic concepts related to feature extraction and its various techniques. Here are some important background points to keep in mind:

- Image analytics is a field of study that involves analyzing images to extract useful information. It is an interdisciplinary field that combines computer science, mathematics, and engineering.

- Feature extraction is a process of analyzing images to identify and extract important features, such as edges, corners, and textures. These features can be used to classify images, recognize objects, and perform various other tasks.

- Feature extraction is a critical step in many image processing applications, including object detection, recognition, and tracking, medical image analysis, and surveillance systems.

- There are several techniques used for feature extraction, including statistical methods, transform methods, and model-based methods. Each technique has its advantages and disadvantages and is suitable for different types of images and applications.

- Statistical methods involve analyzing the statistical properties of the image, such as mean, variance, and correlation. These methods are simple and computationally efficient but may not always be able to capture all the important features in the image.

- Transform methods involve applying mathematical transforms, such as Fourier transform, wavelet transform, and PCA, to the image. These methods can capture both spatial and frequency information in the image and are useful for detecting features at different scales.

- Model-based methods involve using a predefined model to extract features from the image. These models can be trained using machine learning techniques and can be customized for specific applications.

- Feature extraction is often followed by feature selection, which involves selecting the most relevant features for a particular application. This can help reduce the dimensionality of the feature space and improve the performance of the image processing system.

- In conclusion, feature extraction is a critical technique in image analytics that involves extracting meaningful information from images. Understanding the basic concepts and techniques of feature extraction is essential for developing effective image processing systems for various applications.
