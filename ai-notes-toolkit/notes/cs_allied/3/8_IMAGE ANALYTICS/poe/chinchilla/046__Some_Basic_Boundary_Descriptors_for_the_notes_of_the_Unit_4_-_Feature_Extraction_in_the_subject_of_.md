### Some Basic Boundary Descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

Boundary descriptors are used to extract important features from an image's boundary or contour. These features can help in identifying and classifying objects in the image. Some basic boundary descriptors include:

1. Perimeter: It is the length of the boundary of an object and is calculated by adding the distances between consecutive boundary points.

2. Area: It is the total number of pixels inside the boundary of an object.

3. Compactness: It is a measure of how closely an object's boundary is packed. It is calculated as the square of the perimeter divided by the area.

4. Convex Hull: It is the smallest convex polygon that encloses the object's boundary. It can be used to describe the shape of the object.

5. Eccentricity: It is a measure of how elongated an object is. It is calculated by dividing the distance between the foci of the ellipse that best fits the object by its major axis length.

6. Solidity: It is the ratio of the area of the object to the area of its convex hull. It can be used to distinguish between solid and hollow objects.

7. Orientation: It is the angle between the major axis of the ellipse that best fits the object and the x-axis.

8. Hu Moments: They are a set of seven invariant moments that can be used to describe the shape of an object. They are calculated using the normalized central moments of the object.

These boundary descriptors can be used in various image analysis applications such as object recognition, shape analysis, and segmentation. They provide a quantitative measure of the object's shape and can help in identifying and distinguishing between different objects in the image.
