### Some Basic Boundary Descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

In image analytics, boundary descriptors are used to extract useful features from the image. These features can be used for various applications such as object recognition, image segmentation, and pattern recognition. Here are some basic boundary descriptors that are commonly used:

1. Chain Code: Chain code is a simple boundary descriptor that represents the boundary of an object as a sequence of codes. Each code represents a direction of the boundary from one point to the next. Chain codes are easy to compute and are useful for simple objects.

2. Fourier Descriptors: Fourier descriptors are used to capture the shape of an object by representing the boundary as a sum of sine and cosine functions. Fourier descriptors are useful for objects with smooth boundaries and can capture the shape of the object with high accuracy.

3. Curvature Scale Space: Curvature scale space is a method that represents the boundary of an object as a series of curves with varying curvature. This method is useful for objects with complex boundaries and can capture the boundary at different scales.

4. Zernike Moments: Zernike moments are used to represent the shape of an object by decomposing the boundary into a series of orthogonal polynomials. Zernike moments are useful for objects with rotational symmetry and can capture the shape of the object with high accuracy.

5. Shape Context: Shape context is a method that represents the shape of an object by considering the distribution of the boundary points relative to each other. This method is useful for objects with complex shapes and can capture the shape of the object with high accuracy.

In conclusion, boundary descriptors are essential in image analytics for extracting useful features from an image. Understanding these basic boundary descriptors can help in selecting the appropriate method for a particular application.
