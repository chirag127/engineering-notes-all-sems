### Functionalities & Classifications of Data Mining

Data mining is the process of discovering useful patterns and insights from large and complex data sets. Data mining can help organizations make better decisions, improve customer satisfaction, enhance product quality, and optimize business processes.

Data mining functionalities are used to represent the type of patterns that have to be discovered in data mining tasks. In general, data mining tasks can be classified into two types including descriptive and predictive.

- Descriptive mining tasks define the common features of the data in the database and summarize the characteristics of the data. Examples of descriptive mining tasks are:

  - Association analysis: finding frequent patterns, associations, or correlations among a set of items or attributes.
  - Clustering: grouping a set of data objects into clusters such that objects within a cluster are similar to each other and dissimilar to objects in other clusters.
  - Summarization: providing a concise and general description of the data, such as statistics, charts, graphs, or reports.
  - Outlier analysis: identifying data objects that deviate significantly from the normal behavior or expectation.

- Predictive mining tasks act inference on the current data in order to make predictions about future or unknown data. Examples of predictive mining tasks are:

  - Classification: determining a model that describes and differentiates data classes with the intention of using it to predict a class of unknown or anonymous objects.
  - Regression: estimating or predicting a numeric value based on the input variables.
  - Time series analysis: analyzing and modeling temporal data, such as trends, cycles, or seasonal patterns.

Data mining can also be classified based on the kind of data to be mined, such as relational, transactional, spatial, temporal, text, multimedia, web, or social data. Each type of data has its own characteristics, challenges, and methods for data mining.

Data mining usually consists of four main steps: setting objectives, data gathering and preparation, applying data mining algorithms, and evaluating results.

- Setting objectives: This can be the hardest part of the data mining process, and many organizations spend too little time on this important step. The objectives should be clear, measurable, and aligned with the business goals.
- Data gathering and preparation: This involves collecting and integrating data from various sources, such as databases, files, web pages, or sensors. The data should be cleaned, transformed, and formatted to make it suitable for data mining.
- Applying data mining algorithms: This involves selecting and applying appropriate data mining techniques, such as classification, clustering, association, or regression, to the prepared data. The algorithms should be chosen based on the data type, the mining task, and the objectives.
- Evaluating results: This involves assessing the quality and usefulness of the data mining results, such as the accuracy, validity, reliability, and relevance of the patterns or models. The results should be interpreted, visualized, and communicated to the stakeholders.

Data mining is a key component of business intelligence. Data mining tools are built into executive dashboards, harvesting insight from Big Data, including data from social media, Internet of Things (IoT) sensor feeds, location-aware devices, unstructured text, video, and more. Data mining can help organizations gain competitive advantage, improve customer loyalty, reduce costs, increase revenue, and enhance innovation.
