## Unit 2 - BI – DATA MINING & WAREHOUSING

- Data mining is the process of discovering patterns, trends, and insights from large and complex data sets using various techniques and algorithms.
- Data warehousing is the process of designing, building, and maintaining a centralized repository of integrated, consistent, and reliable data from multiple sources for business intelligence purposes.
- The main objectives of data mining and warehousing are to support decision making, enhance business performance, and gain competitive advantage.
- The main components of a data warehouse are:
  - Data sources: The external or internal systems that provide the raw data for the data warehouse.
  - Data integration: The process of extracting, transforming, and loading (ETL) the data from the sources to the data warehouse.
  - Data storage: The physical or logical structure that stores the data in the data warehouse, such as relational databases, multidimensional databases, or data lakes.
  - Data access: The tools and applications that allow users to query, analyze, and visualize the data in the data warehouse, such as online analytical processing (OLAP), data mining, reporting, and dashboards.
- The main steps of data mining are:
  - Data preparation: The process of cleaning, transforming, and selecting the data for data mining.
  - Data exploration: The process of understanding the characteristics, distribution, and relationships of the data using descriptive statistics and visualization techniques.
  - Data modeling: The process of applying data mining algorithms to the data to discover patterns, trends, and insights.
  - Data evaluation: The process of assessing the quality, validity, and usefulness of the data mining results using various criteria and metrics.
  - Data deployment: The process of integrating, presenting, and applying the data mining results to support decision making and business actions.
- The main types of data mining techniques are:
  - Classification: The process of assigning a label or category to an instance based on its attributes, such as spam detection, credit scoring, or medical diagnosis.
  - Regression: The process of predicting a numerical value for an instance based on its attributes, such as sales forecasting, stock price prediction, or house price estimation.
  - Clustering: The process of grouping instances that are similar to each other based on their attributes, such as customer segmentation, market basket analysis, or image segmentation.
  - Association: The process of finding rules that describe the co-occurrence or dependency of items or events, such as product recommendation, web mining, or fraud detection.
  - Anomaly detection: The process of identifying instances that deviate from the normal or expected behavior, such as intrusion detection, fraud detection, or outlier detection.
  - Text mining: The process of extracting information, concepts, and sentiments from unstructured text data, such as document classification, sentiment analysis, or topic modeling.
  - Web mining: The process of applying data mining techniques to web data, such as web content, web structure, and web usage, to discover useful information and knowledge, such as web page ranking, web personalization, or web community detection.
