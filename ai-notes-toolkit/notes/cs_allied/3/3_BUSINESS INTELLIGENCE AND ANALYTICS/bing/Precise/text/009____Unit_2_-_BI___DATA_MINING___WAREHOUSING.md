## Unit 2 - BI – DATA MINING & WAREHOUSING

1. **Data Mining** is the process of discovering patterns and knowledge from large amounts of data. The data sources can include databases, data warehouses, the internet, and other sources.
2. The main goal of data mining is to extract information from data and transform it into an understandable structure for further use.
3. There are several key data mining techniques including association, classification, clustering, prediction, and sequential patterns.
4. **Data Warehousing** is the process of collecting, storing, and managing large amounts of data from various sources in a single, central repository.
5. The main goal of data warehousing is to provide a consistent, reliable, and easily accessible source of data for analysis and reporting.
6. Data warehousing involves the use of various technologies and tools, including data integration, data quality, data modeling, and data visualization.
7. Data mining and data warehousing are closely related, as data mining can be used to analyze data stored in a data warehouse, and the results of data mining can be used to improve the quality and usefulness of the data stored in the data warehouse.
