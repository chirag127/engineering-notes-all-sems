### Types of Analytical Techniques in BI – Descriptive

Descriptive analytics is one of the main types of analytical techniques used in Business Intelligence (BI). It is used to summarize and describe historical data to identify patterns, relationships, and trends. Descriptive analytics is often the first step in the data analytics process and provides a foundation for more advanced analytical techniques.

Some common techniques used in descriptive analytics include:

1. **Data Aggregation:** This involves combining data from multiple sources to create a summary view of the data. This can help to identify trends and patterns in the data.

2. **Data Mining:** This involves using algorithms to identify patterns and relationships in large datasets. Data mining can help to uncover hidden insights in the data.

3. **Data Visualization:** This involves using graphical representations of data to help users understand and explore the data. Data visualization can help to identify trends and patterns in the data.

4. **Statistical Analysis:** This involves using statistical methods to analyze data and draw conclusions. Statistical analysis can help to identify relationships and trends in the data.

Descriptive analytics is a powerful tool for understanding historical data and can provide valuable insights for decision-making in business. It is an essential part of the BI data analytics process.
