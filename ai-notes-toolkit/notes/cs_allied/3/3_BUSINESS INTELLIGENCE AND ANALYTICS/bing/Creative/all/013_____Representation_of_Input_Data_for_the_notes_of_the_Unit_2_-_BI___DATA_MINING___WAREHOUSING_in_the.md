# Representation of Input Data

- Data mining is the process of discovering patterns and knowledge from large amounts of data.
- The input data for data mining can be of various types, such as structured, unstructured, or semi-structured data, and can have different formats, such as relational tables, text documents, images, audio, video, etc.
- The representation of input data is an important step in data mining, as it affects the quality and efficiency of the data mining process and the results.
- The representation of input data involves choosing the appropriate data types, formats, and structures to store and manipulate the data, as well as applying various techniques to preprocess, transform, and reduce the data to make it suitable for data mining.
- Some of the common techniques for data representation are:

  - Data cleaning: This technique aims to remove noise, outliers, missing values, and inconsistencies from the data, and to improve the accuracy and reliability of the data.
  - Data integration: This technique aims to combine data from multiple sources and formats into a unified and consistent data set, and to resolve any conflicts or redundancies in the data.
  - Data transformation: This technique aims to convert the data from one format or structure to another, and to normalize, scale, or discretize the data values to make them comparable and compatible.
  - Data reduction: This technique aims to reduce the size and complexity of the data, and to retain the most relevant and important information for data mining. Data reduction can be performed by using techniques like data cube aggregation, dimension reduction, data compression, etc.
  - Data discretization: This technique aims to transform continuous or numerical data into discrete or categorical data, and to create intervals or bins for the data values. Data discretization can help to simplify the data and to reduce the noise and outliers in the data.
  - Data encoding: This technique aims to transform the data into a numerical or symbolic form that can be easily processed by data mining algorithms. Data encoding can involve techniques like one-hot encoding, label encoding, hashing, etc.
  - Data visualization: This technique aims to represent the data in a graphical or visual form that can be easily understood and interpreted by humans. Data visualization can help to explore the data, to identify patterns and trends, and to communicate the data mining results. Data visualization can use techniques like pie charts, histograms, scatter plots, bar charts, etc.
