# Predictive Analytics

Predictive analytics is a set of business intelligence (BI) technologies that uncovers relationships and patterns within large volumes of data that can be used to predict behavior and events. Unlike other BI technologies, predictive analytics is forward-looking, using past events to anticipate the future.

Some of the notes for the Unit 4 - BI – DATA ANALYTICS PROCESS in the subject of BUSINESS INTELLIGENCE AND ANALYTICS KCS are:

- Predictive analytics uses statistical modeling, data mining techniques and machine learning to find patterns in data and make predictions about future outcomes and performance.
- Predictive analytics can be applied to various domains, such as marketing, finance, healthcare, security, risk management, operations, etc.
- Predictive analytics can provide benefits such as security, risk reduction, operational efficiency, customer satisfaction, revenue growth, etc.
- Predictive analytics can be divided into different types of models, such as:

  - Machine learning: Machine learning can be defined as the ability of a machine to learn and then mimic human intelligence without explicit programming. Machine learning can use supervised, unsupervised or reinforcement learning methods to learn from data and make predictions.
  - Predictive modeling: Predictive modeling is a statistical technique used to predict future behavior. It utilizes historical data and various algorithms, such as regression, classification, clustering, etc., to build a model that can be applied to new data.
  - Regression techniques: Regression techniques are used to estimate the relationship between a dependent variable and one or more independent variables. Regression techniques can be linear or nonlinear, and can be used for prediction, inference or hypothesis testing.
  - Data mining: Data mining is the process of discovering hidden patterns and insights from large and complex data sets. Data mining can use various techniques, such as association rules, decision trees, neural networks, etc., to extract useful information and knowledge from data.
