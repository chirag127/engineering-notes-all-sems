## Unit 3 - BI – DATA PREPARTTION

- Data preparation is the process of transforming raw data into a format that is suitable for analysis, visualization, and reporting.
- Data preparation involves various steps, such as data collection, data cleaning, data integration, data transformation, data enrichment, and data quality assessment.
- Data preparation is an essential and often time-consuming task in business intelligence (BI), as it ensures the accuracy, completeness, consistency, and relevance of the data for the intended purpose.
- Data preparation can be done manually or with the help of tools and techniques, such as data profiling, data validation, data standardization, data deduplication, data imputation, data aggregation, data normalization, data encoding, data scaling, data binning, data discretization, data sampling, and data anonymization.
- Data preparation can be performed on different types of data, such as structured, semi-structured, or unstructured data, and on different sources of data, such as internal or external, online or offline, static or dynamic, and historical or real-time data.
- Data preparation can have various benefits, such as improving data quality, reducing data errors, enhancing data usability, increasing data value, facilitating data analysis, and supporting data-driven decision making.
