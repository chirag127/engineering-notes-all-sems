### Data Modelling for the notes of the Unit 2 - BI – DATA MINING & WAREHOUSING in the subject of BUSINESS INTELLIGENCE AND ANALYTICS KCS

1. Data modelling is the process of creating a data model for the data to be stored in a database.
2. A data model is a conceptual representation of data structures required for a database and is the diagrammatic representation of the data structures, data types, relationships, constraints etc. of an organization.
3. The main types of data models are:
	1. Hierarchical model
	2. Network model
	3. Relational model
	4. Object oriented data model
4. The relational model is the most widely used data model for data storage and processing.
5. Some key terms in relational model are: relation, tuples, attributes, schemas etc.
6. Data modelling is an iterative process and the data models evolve as new requirements emerge or as the understanding of the problem domain improves.
7. The objectives of data modelling are:
	1. To achieve a common understanding of the data structures and associated semantics of an organization.
	2. To communicate with the user and the developer.
	3. To provide a basis for the design of the database.
8. The data modelling process involves four steps:
	1. Collecting the data requirements
	2. Identifying the data entities and relationships
	3. Classifying and sorting the data entities into hierarchies
	4. Representing the data model using a modelling technique like E-R diagrams or UML
