### Data Warehousing - Introduction to Data Warehousing

1. A data warehouse is a central repository of integrated data from one or more disparate sources. Data warehousing is the process of building and using a data warehouse.
2. The data in a data warehouse is usually derived from multiple online transaction processing (OLTP) database systems. The data may pass through an operational data store on its way into the data warehouse.
3. Data warehouses contain unified information on dimensional data marts suited for query and analysis rather than for transaction processing. This data can be used for trend analysis, data mining, and other decision support activities.
4. The data in data warehouses is usually derived by extracting, cleaning, transforming and integrating data from multiple source systems. This may involve data scrubbing or data auditing to ensure correctness and completeness of the data.
5. Data warehousing emphasizes the capture of data, mostly from internal systems, and stores the data in a standard format for further data processing and analysis. In contrast, data mining emphasizes the analysis of data for decision-making. However, data mining uses the data prepared by data warehousing.
