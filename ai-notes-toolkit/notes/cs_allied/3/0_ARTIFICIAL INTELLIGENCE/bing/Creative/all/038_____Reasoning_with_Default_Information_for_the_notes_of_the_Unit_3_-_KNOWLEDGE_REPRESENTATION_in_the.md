# Reasoning with Default Information

- Reasoning with default information is a type of nonmonotonic reasoning that allows an agent to draw conclusions based on incomplete or uncertain information, using default rules or assumptions that can be overridden by more specific or reliable information.
- Default rules are conditional statements of the form: if P then normally Q, where P is the antecedent and Q is the consequent. Normally means that Q is true in most cases, but not necessarily in all cases. For example, if X is a bird then normally X can fly.
- Default rules can be applied to derive default conclusions, which are tentative and defeasible, meaning that they can be withdrawn or revised if new information contradicts them or provides a better explanation. For example, if we know that Tweety is a bird, we can apply the default rule and conclude that Tweety can fly, unless we learn later that Tweety is a penguin or has a broken wing.
- Default logic is a formalism for representing and reasoning with default rules and conclusions. It consists of a set of facts, a set of default rules, and a set of extensions. An extension is a consistent set of facts and default conclusions that can be derived from the facts and the default rules, without violating any of the facts. For example, one possible extension for the Tweety example is {Tweety is a bird, Tweety can fly}, while another possible extension is {Tweety is a bird, Tweety is a penguin, Tweety cannot fly}.
- Default logic is nonmonotonic, because adding new facts can change the set of extensions or the set of default conclusions. For example, adding the fact that Tweety is a penguin eliminates the first extension and the default conclusion that Tweety can fly.
- Default logic is also nonmonotonic, because it allows for multiple extensions or multiple default conclusions, which may be incompatible or incomparable. For example, if we have two default rules: if X is a bird then normally X can fly, and if X is a bird then normally X can sing, and we know that Tweety is a bird, then we have two possible extensions: {Tweety is a bird, Tweety can fly, Tweety can sing}, and {Tweety is a bird, Tweety can fly, Tweety cannot sing}. Neither extension is more preferable or more justified than the other, unless we have more information to resolve the conflict.
- Default logic can be used to model common sense reasoning, where an agent uses general knowledge and assumptions to make plausible inferences, but is also able to revise or retract them when faced with exceptions or contradictions. It can also be used to model non-deterministic or probabilistic reasoning, where an agent considers multiple possible outcomes or explanations, but does not assign any numerical probabilities or preferences to them.
