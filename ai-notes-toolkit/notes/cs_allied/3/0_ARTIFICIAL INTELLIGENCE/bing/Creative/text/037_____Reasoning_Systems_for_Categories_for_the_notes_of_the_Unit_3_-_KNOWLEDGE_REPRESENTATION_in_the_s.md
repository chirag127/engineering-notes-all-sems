### Reasoning Systems for Categories

- Reasoning is the process of drawing logical conclusions from a set of facts, rules, and beliefs.
- In artificial intelligence, reasoning systems are used to represent and manipulate knowledge, and to infer new information from existing knowledge.
- Reasoning systems can be classified into different categories based on the type of logic, the type of knowledge, and the type of inference they use.
- Some of the common categories of reasoning systems are:

  - **Deductive reasoning systems**: These systems use rules of logic to derive conclusions from a set of premises. For example, if A implies B, and A is true, then B is true. Deductive reasoning systems are sound, meaning that they always produce valid conclusions, but they are not complete, meaning that they may not be able to derive all possible conclusions from a given set of premises. Deductive reasoning systems are also called rule-based systems or production systems .
  - **Inductive reasoning systems**: These systems use examples or observations to generalize patterns or rules. For example, if all the observed birds can fly, then one can induce that all birds can fly. Inductive reasoning systems are not sound, meaning that they may produce invalid conclusions, but they are complete, meaning that they can derive any possible conclusion from a given set of premises. Inductive reasoning systems are also called learning systems or data-driven systems .
  - **Abductive reasoning systems**: These systems use a set of facts and a goal to infer the most likely explanation or hypothesis. For example, if one observes that the grass is wet, and the goal is to explain why, then one can abduce that it rained. Abductive reasoning systems are neither sound nor complete, meaning that they may produce invalid or incomplete conclusions, but they are useful for generating plausible hypotheses or solutions. Abductive reasoning systems are also called diagnostic systems or hypothesis-driven systems .
  - **Common sense reasoning systems**: These systems use general knowledge about the world and human behavior to reason about everyday situations. For example, if one sees a person holding an umbrella, one can infer that it is raining or that the person expects rain. Common sense reasoning systems are based on heuristics, analogies, and default assumptions, and they can handle uncertainty, ambiguity, and inconsistency. Common sense reasoning systems are also called natural language understanding systems or cognitive systems.
  - **Monotonic reasoning systems**: These systems assume that the knowledge base is consistent and complete, and that new information does not contradict or invalidate existing information. For example, if one knows that all birds can fly, and one learns that a penguin is a bird, then one can still conclude that all birds can fly. Monotonic reasoning systems are simpler and faster, but they are not realistic or flexible. Monotonic reasoning systems are also called classical logic systems or closed-world systems .
  - **Non-monotonic reasoning systems**: These systems allow the knowledge base to be inconsistent and incomplete, and that new information can contradict or invalidate existing information. For example, if one knows that all birds can fly, and one learns that a penguin is a bird, then one has to retract the previous conclusion that all birds can fly. Non-monotonic reasoning systems are more complex and slower, but they are more realistic and flexible. Non-monotonic reasoning systems are also called non-classical logic systems or open-world systems .

- These categories are not mutually exclusive, and some reasoning systems can combine or switch between different types of reasoning depending on the context and the task. For example, a procedural reasoning system (PRS) is a framework for constructing real-time reasoning systems that can perform complex tasks in dynamic environments. It is based on the notion of a rational agent or intelligent agent using the belief–desire–intention software model. A user application is predominately defined by a set of procedural knowledge, called plans, that specify how to achieve goals or react to events. A PRS can use deductive, inductive, abductive, or common sense reasoning depending on the situation and the available knowledge.
