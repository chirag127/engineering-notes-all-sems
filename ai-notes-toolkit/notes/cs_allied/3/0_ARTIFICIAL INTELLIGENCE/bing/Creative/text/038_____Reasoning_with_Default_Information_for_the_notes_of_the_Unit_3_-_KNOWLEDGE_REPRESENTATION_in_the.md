### Reasoning with Default Information

- Reasoning with default information is a form of non-monotonic reasoning that allows for drawing plausible conclusions from incomplete or uncertain information, based on general rules that may have exceptions .
- Non-monotonic reasoning is a type of reasoning that does not follow the principle of monotonicity, which states that adding new information to a set of premises cannot reduce the set of conclusions that can be derived from them. In other words, non-monotonic reasoning allows for revising or retracting conclusions when new information contradicts or invalidates them .
- Reasoning with default information is useful in artificial intelligence, as it can model common sense reasoning, handle uncertainty and inconsistency, and cope with incomplete knowledge  .
- One of the most influential formalisms for reasoning with default information is default logic, proposed by Raymond Reiter in 1980  . Default logic consists of a set of facts (the background theory) and a set of default rules, each of the form: p:q/r, where p is the prerequisite, q is the justification, and r is the consequent. A default rule can be read as: if p is true and q is consistent with the facts, then assume r. However, r can be withdrawn if new facts contradict it  .
- For example, consider the following default rule: Bird:Flies/Flies. This means that if something is a bird and it is consistent with the facts that it flies, then assume that it flies. However, this assumption can be retracted if new facts show that the bird is exceptional, such as a penguin or an ostrich  .
- A default theory is a pair of a background theory and a set of default rules. A default theory can have multiple extensions, which are sets of conclusions that can be derived from applying the default rules in a consistent way. An extension is said to be normal if it contains the consequent of every default rule whose prerequisite and justification are in the extension. A default theory is said to be normal if it has at least one normal extension  .
- For example, consider the following default theory: {Tweety is a bird, Bird:Flies/Flies}. This theory has two extensions: {Tweety is a bird, Tweety flies} and {Tweety is a bird}. The first extension is normal, as it contains the consequent of the default rule whose prerequisite and justification are in the extension. The second extension is not normal, as it does not contain the consequent of the default rule. However, both extensions are consistent with the facts  .
- Reasoning with default information can be applied to various domains and tasks in artificial intelligence, such as natural language understanding, planning, diagnosis, learning, and knowledge representation  . However, it also faces some challenges and limitations, such as computational complexity, non-uniqueness of extensions, and lack of expressiveness for some types of defaults  .
