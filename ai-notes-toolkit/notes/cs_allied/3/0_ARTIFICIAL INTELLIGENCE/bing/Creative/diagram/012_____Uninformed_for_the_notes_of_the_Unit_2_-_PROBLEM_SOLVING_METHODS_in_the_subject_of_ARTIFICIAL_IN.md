### Uninformed Search Methods

Uninformed search methods are also known as blind search methods. They are search algorithms that do not use any additional information to guide the search process. They only use the problem definition, which consists of the initial state, the goal state, and the actions that can be performed to move from one state to another. Uninformed search methods explore the search space in a systematic, but blind, manner, without considering the cost of reaching the goal or the likelihood of finding a solution. Some of the key features of uninformed search methods are:

- Systematic exploration: Uninformed search methods explore the search space systematically, either by expanding all children of a node (e.g. breadth-first search) or by exploring as deep as possible in a single path before backtracking (e.g. depth-first search).
- No heuristics: Uninformed search methods do not use any additional information, such as heuristics or cost functions, to estimate the quality of a state or a path. They only check if a state is a goal state or not.
- Completeness: Uninformed search methods are guaranteed to find a solution if one exists, as long as the search space is finite and the branching factor is bounded.
- Optimality: Uninformed search methods are not guaranteed to find the optimal solution, unless they explore all possible paths with the same cost (e.g. uniform-cost search).
- Time and space complexity: Uninformed search methods have high time and space complexity, as they may generate and store a large number of nodes in memory, especially if the search space is large and the solution is deep.

Some of the common uninformed search methods are:

- Breadth-first search (BFS): It is a search algorithm that traverses the search space breadthwise, by expanding all the nodes at a given depth before moving to the next depth level. It uses a queue data structure to store the nodes to be expanded. It is complete and optimal for problems with constant step costs, but it has high time and space complexity, as it may generate and store a large number of nodes in memory.
- Depth-first search (DFS): It is a search algorithm that traverses the search space depthwise, by exploring as deep as possible in a single path before backtracking to the previous node and exploring another path. It uses a stack data structure to store the nodes to be expanded. It is not complete, as it may get stuck in an infinite loop or miss a shallow solution, and it is not optimal, as it may find a suboptimal solution. It has low space complexity, as it only stores a single path in memory, but it has high time complexity, as it may explore a large number of nodes in the search space.
- Uniform-cost search (UCS): It is a search algorithm that expands the node with the lowest path cost from the initial state to the current state. It uses a priority queue data structure to store the nodes to be expanded, where the priority is the path cost. It is complete and optimal for any problem with positive step costs, but it has high time and space complexity, as it may generate and store a large number of nodes in memory, especially if the solution is deep or the step costs are small.
- Depth-limited search (DLS): It is a search algorithm that applies a depth limit to the depth-first search, by cutting off the search at a specified depth level. It is not complete, as it may miss a solution that is deeper than the depth limit, and it is not optimal, as it may find a suboptimal solution. It has low space complexity, as it only stores a single path in memory, but it has high time complexity, as it may explore a large number of nodes in the search space.
- Iterative deepening search (IDS): It is a search algorithm that combines the advantages of breadth-first search and depth-first search, by applying depth-first search with increasing depth limits until a solution is found or the search space is exhausted. It is complete and optimal for problems with constant step costs, and it has low space complexity, as it only stores a single path in memory, but it has high time complexity, as it may repeat the search for the same nodes at different depth levels.
