### Typical Intelligent Agents

- An **intelligent agent** is an entity that makes a decision, that enables artificial intelligence to be put into action.
- It can also be described as a software entity that conducts operations in the place of users or programs after sensing the environment.
- It uses **sensors** to perceive the environment and **actuators** to initiate action in that environment.
- In addition, intelligent agents may **learn** from the environment to achieve their goals.
- Intelligent agents in artificial intelligence are closely related to agents in economics, and versions of the intelligent agent paradigm are studied in cognitive science, ethics, the philosophy of practical reason, as well as in many interdisciplinary socio-cognitive modeling and computer social simulations.
- Driverless cars and the Siri virtual assistant are examples of intelligent agents in AI.

- There are different types of intelligent agents based on their characteristics and capabilities. Some of the common types are:

  - **Simple reflex agents**: These agents act based on the current state of the environment, without considering the history or the future consequences of their actions. They use a set of rules or condition-action pairs to determine the best action for each state. For example, a simple reflex agent for a vacuum cleaner would suck dirt when it senses dirt and move to another location when it does not sense dirt.
  - **Model-based reflex agents**: These agents act based on the current state of the environment as well as a model of how the environment works. They use the model to keep track of the changes in the environment and predict the outcomes of their actions. For example, a model-based reflex agent for a vacuum cleaner would also consider the layout of the room and the location of the obstacles when choosing the best action.
  - **Goal-based agents**: These agents act based on the current state of the environment, a model of how the environment works, and a goal or set of goals that they want to achieve. They use the model to search for the sequence of actions that will lead them to the goal. For example, a goal-based agent for a vacuum cleaner would also have a goal of cleaning the entire room and would plan the actions accordingly.
  - **Utility-based agents**: These agents act based on the current state of the environment, a model of how the environment works, a goal or set of goals that they want to achieve, and a utility function that measures how desirable each state is. They use the utility function to evaluate the outcomes of their actions and choose the best one. For example, a utility-based agent for a vacuum cleaner would also have a utility function that assigns higher values to states where the room is cleaner and the battery is fuller.
  - **Learning agents**: These agents act based on the current state of the environment, a model of how the environment works, a goal or set of goals that they want to achieve, a utility function that measures how desirable each state is, and a learning component that improves the agent's performance over time. They use the learning component to update the model, the goal, the utility function, or the action selection mechanism based on the feedback from the environment. For example, a learning agent for a vacuum cleaner would also learn from its own experience and adapt to the changes in the environment or the user's preferences.
