### Local Search Algorithms and Optimization Problems

- Local search algorithms are a type of heuristic search methods that iteratively improve a solution by only considering those solutions that are close to the current solution.
- Local search algorithms are widely used for very big problems that cannot be solved by exhaustive search or other methods.
- Local search algorithms return good but not optimal solutions, and usually very slow, but can yield good solutions if you wait.
- Local search algorithms are important in artificial intelligence because they enhance the solving of problems through logical search mechanisms such as problem definition, actions, and search space.
- Optimization problems are problems that can be formulated as finding a solution maximizing a criterion among a number of candidate solutions.
- Optimization problems are common in artificial intelligence, such as planning, scheduling, routing, machine learning, etc.
- Local search algorithms can be applied to optimization problems by defining a state space, a goal test, a cost function, and a neighborhood function.
- A state space is the set of "complete" configurations that define a possible solution.
- A goal test is a function that determines whether a given state is a goal state or not.
- A cost function is a function that assigns a numerical value to each state, representing how good or bad the state is.
- A neighborhood function is a function that generates a set of states that are close to the current state, called the neighbors.
- A local search algorithm starts with an initial state, and then repeatedly moves to a neighbor state that has a lower cost than the current state, until no such neighbor exists or a time limit is reached.
- A local search algorithm can be implemented using different strategies, such as hill climbing, simulated annealing, tabu search, genetic algorithms, etc.
- A local search algorithm has two major drawbacks: it is very sensitive to the initial solution, and it has a high probability of getting trapped in a local optima.
- A local optima is a state that has a lower cost than all its neighbors, but not the lowest cost in the state space.
- A global optima is a state that has the lowest cost in the state space.
- To overcome the drawbacks of local search algorithms, some techniques can be used, such as random restarts, stochastic moves, diversification, intensification, etc.
