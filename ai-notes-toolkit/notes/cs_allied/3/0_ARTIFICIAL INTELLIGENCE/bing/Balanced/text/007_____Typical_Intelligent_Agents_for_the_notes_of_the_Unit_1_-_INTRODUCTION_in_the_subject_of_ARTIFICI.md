### Typical Intelligent Agents

- An **intelligent agent** is an entity that makes a decision, that enables artificial intelligence to be put into action.
- It can also be described as a software entity that conducts operations in the place of users or programs after sensing the environment.
- It uses **sensors** to perceive the environment and **actuators** to initiate action in that environment.
- In addition, intelligent agents may **learn** from the environment to achieve their goals.
- Intelligent agents in artificial intelligence are closely related to agents in economics, and versions of the intelligent agent paradigm are studied in cognitive science, ethics, the philosophy of practical reason, as well as in many interdisciplinary socio-cognitive modeling and computer social simulations.
- Driverless cars and the Siri virtual assistant are examples of intelligent agents in AI.

- There are different types of intelligent agents based on their characteristics and capabilities. Some of the common types are:

  - **Simple reflex agents**: These agents act based on the current state of the environment, without considering the consequences of their actions. They use condition-action rules to select an action based on the perceived state. For example, a vacuum cleaner agent that cleans the dirt when it senses it.
  - **Model-based reflex agents**: These agents act based on the current state of the environment, as well as a model of how the environment works. They use condition-action rules to select an action based on the perceived state and the model. For example, a vacuum cleaner agent that cleans the dirt when it senses it, and also avoids obstacles based on a map of the room.
  - **Goal-based agents**: These agents act based on the current state of the environment, as well as a goal or set of goals that they want to achieve. They use a search or planning algorithm to find a sequence of actions that leads to the goal state. For example, a chess-playing agent that chooses a move that maximizes the chances of winning the game.
  - **Utility-based agents**: These agents act based on the current state of the environment, as well as a utility function that measures how desirable each state is. They use a search or planning algorithm to find a sequence of actions that maximizes the expected utility. For example, a stock-trading agent that chooses a portfolio that maximizes the expected profit.
  - **Learning agents**: These agents act based on the current state of the environment, as well as a learning component that allows them to improve their performance over time. They use feedback from the environment or a teacher to update their knowledge, model, goal, utility function, or action selection mechanism. For example, a speech recognition agent that learns from the user's corrections.
