### Problem solving Methods

- Problem solving is the process of finding a solution to a given situation or task that satisfies some criteria or constraints.
- Problem solving methods are systematic and general approaches that can be applied to different types of problems in various domains.
- Problem solving methods typically involve the following steps:
  - Problem formulation: defining the problem, its goals, and its constraints.
  - Problem representation: choosing a suitable way to encode the problem and its elements, such as states, actions, operators, etc.
  - Search strategy: selecting a method to explore the problem space and find a path from the initial state to the goal state.
  - Solution evaluation: checking if the solution is correct, optimal, and feasible.
- Some examples of problem solving methods are:
  - Uninformed search: a search strategy that does not use any domain-specific knowledge or heuristics, such as breadth-first search, depth-first search, uniform-cost search, etc.
  - Informed search: a search strategy that uses some domain-specific knowledge or heuristics to guide the search, such as greedy search, A* search, hill-climbing, etc.
  - Constraint satisfaction: a problem representation that involves a set of variables, domains, and constraints, and a search strategy that tries to assign values to the variables that satisfy all the constraints, such as backtracking, forward checking, arc consistency, etc.
  - Logic-based methods: a problem representation that involves a set of facts, rules, and queries, and a search strategy that tries to infer new facts or prove queries using logical reasoning, such as resolution, unification, modus ponens, etc.
  - Planning: a problem representation that involves a set of actions, preconditions, and effects, and a search strategy that tries to find a sequence of actions that achieves the goal, such as STRIPS, partial-order planning, hierarchical planning, etc.
  - Game playing: a problem representation that involves a set of states, actions, and outcomes, and a search strategy that tries to find the best action for a player in a competitive or cooperative situation, such as minimax, alpha-beta pruning, expectimax, etc.
