# Searching with Partial Observations

- Searching with partial observations is a problem-solving method in artificial intelligence that deals with environments that are **partially observable**, meaning that the agent cannot access the complete state of the environment at any given time.
- Partial observability can arise due to **limited sensors**, **noise**, **uncertainty**, or **hidden variables** in the environment.
- A partial observation is a **subset** of the information that is available in a fully observable environment. For example, a vacuum agent may only have a position and a local dirt sensor, but not a dirt sensor for other squares.
- To search with partial observations, an agent needs to maintain a **belief state**, which is a set of possible states that are consistent with the observations so far. A belief state can be represented as a **probability distribution** over the states, or as a **logical formula** that captures the constraints on the states.
- An action in a partially observable environment can lead to one of several possible **outcomes**, depending on the actual state of the environment and the effects of the action. An outcome can be represented as a **transition function** that maps a belief state and an action to a new belief state, or as a **conditional plan** that specifies what to do for each possible outcome.
- A goal in a partially observable environment can be specified as a **belief goal**, which is a condition on the belief state that the agent wants to achieve. For example, a vacuum agent may want to reach a belief state where it is certain that all squares are clean.
- A solution to a partially observable search problem is a **policy**, which is a function that maps a belief state to an action. A policy can be represented as a **decision tree**, a **finite state machine**, or a **neural network**.
- Searching with partial observations can be done using various algorithms, such as **AND-OR search**, **belief state search**, **belief space planning**, **partially observable Markov decision processes (POMDPs)**, or **reinforcement learning**. These algorithms differ in how they represent and update the belief state, how they evaluate and compare the outcomes, and how they generate and execute the policy.
