## Unit 2 - PROBLEM SOLVING METHODS

- Problem solving is the process of finding a solution to a given situation or task that meets some criteria or constraints.
- Problem solving methods are systematic approaches or strategies that can be applied to different types of problems.
- Some common problem solving methods are:

  - Trial and error: Trying different solutions until one works or the problem is solved.
  - Algorithm: Following a fixed set of rules or steps that guarantee a solution.
  - Heuristic: Using a rule of thumb or a shortcut that may not guarantee a solution but can help find one faster or easier.
  - Divide and conquer: Breaking down a complex problem into smaller and simpler subproblems that can be solved separately and then combined.
  - Backtracking: Going back to a previous state or decision point and trying a different option or path.
  - Recursion: Solving a problem by using the same method or function on a smaller or simpler version of the problem.
  - Simulation: Creating a model or representation of the problem and testing different scenarios or outcomes.
  - Optimization: Finding the best or optimal solution among a set of possible solutions that satisfy some criteria or constraints.
  - Search: Exploring a space of possible solutions or states and finding the one that meets some goal or condition.
  - Constraint satisfaction: Finding a solution that satisfies a set of constraints or rules that limit the possible solutions or states.
