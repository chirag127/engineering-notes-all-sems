# Unit 2 - PROBLEM SOLING METHODS

### Problem Solving Methods

1. **Problem Decomposition:** This method involves breaking down a complex problem into smaller, more manageable sub-problems. This can make it easier to understand and solve the problem.

2. **Heuristics:** Heuristics are rules of thumb or shortcuts that can be used to quickly find a solution to a problem. They may not always provide the optimal solution, but can be useful when time is limited.

3. **Means-Ends Analysis:** This method involves identifying the current state, the desired end state, and the actions that can be taken to move from the current state to the end state. The problem solver then selects the action that brings them closest to the end state.

4. **Backtracking:** This method involves trying different solutions to a problem and, if a solution is found to be incorrect, undoing the steps taken and trying a different solution.

5. **Hill Climbing:** This method involves selecting the solution that appears to be the best at the current time, and then continuing to improve upon that solution until a satisfactory solution is found.

6. **Simulated Annealing:** This method involves starting with a random solution and then making small changes to the solution to improve it. As the solution improves, the changes become smaller and smaller until the solution converges to an optimal solution.

7. **Genetic Algorithms:** This method involves using principles of natural selection and genetics to find a solution to a problem. A population of potential solutions is created and then evolved over time through selection, crossover, and mutation to find the best solution.

8. **Constraint Satisfaction:** This method involves identifying the constraints that must be satisfied in order to solve the problem, and then finding a solution that satisfies all of the constraints.

These are some of the common problem-solving methods used in the field of Artificial Intelligence. Each method has its own strengths and weaknesses, and the appropriate method to use will depend on the specific problem being solved.
