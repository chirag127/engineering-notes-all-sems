## Unit 2 - PROBLEM SOLVING METHODS

Problem solving is the process of finding a solution to a problem. There are several methods that can be used to solve problems, including:

1. **Trial and Error:** This method involves trying different solutions until the problem is solved. It is often used when there is no clear solution to the problem.

2. **Algorithm:** An algorithm is a step-by-step procedure for solving a problem. It is often used when the problem can be broken down into smaller, more manageable parts.

3. **Heuristics:** Heuristics are rules of thumb or mental shortcuts that can be used to solve problems. They are often used when there is no clear solution to the problem and time is limited.

4. **Divide and Conquer:** This method involves breaking the problem down into smaller, more manageable parts and solving each part separately. It is often used when the problem is complex.

5. **Backtracking:** Backtracking involves trying different solutions and then undoing or "backtracking" if the solution does not work. It is often used when there are multiple possible solutions to the problem.

6. **Brainstorming:** Brainstorming involves generating a large number of ideas in a short amount of time. It is often used when the problem requires creative thinking.

7. **Root Cause Analysis:** Root cause analysis involves identifying the underlying cause of the problem and addressing it. It is often used when the problem is recurring or complex.

Each of these methods has its own strengths and weaknesses, and the best method to use will depend on the specific problem and situation. It is important to choose the right method for the problem at hand in order to find an effective solution.
