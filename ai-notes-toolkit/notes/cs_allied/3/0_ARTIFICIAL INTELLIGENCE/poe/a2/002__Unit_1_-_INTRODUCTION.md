## Unit 1 - INTRODUCTION

1. Introduction to Programming
- Programming is a process of designing and developing various sets of instructions to enable a computer to perform a specific task.
- Programming languages act as mediators between the programmer and the computer. They translate the instructions given by the programmer into a form that can be understood by the computer.
- The first electronic digital computers were developed in the 1940s. The initial programming languages were machine level languages that were complex and difficult to learn. Assembly languages were later developed to simplify the programming process.
- In the 1950s, high-level programming languages such as FORTRAN and COBOL were created. These could be easily understood by humans but needed to be translated into machine language by compilers and interpreters.
- Modern programming languages such as Java, C++, Python, etc. are now object-oriented and designed to be easy to read, learn and use. They are translated into machine language by compilers and interpreters.

2. Software and Programming
- Software refers to the set of instructions that tell a computer what to do and how to perform a task. It acts as an interface between the user and the hardware.
- Programming is the process of creating and developing software. Programmers write code in a programming language, which is then compiled into machine language that is understood by computers.
- The two major types of software are system software and application software. System software controls a computer's internal functioning, while application software is designed to perform specific user-oriented tasks.
