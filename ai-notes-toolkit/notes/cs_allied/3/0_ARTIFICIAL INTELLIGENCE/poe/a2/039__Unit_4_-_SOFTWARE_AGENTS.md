## Unit 4 - SOFTWARE AGENTS

1. Software Agents: Software agents are computer programs that perform tasks or make decisions for a user. They are autonomous and exhibit some form of intelligence.
2. Types of Software Agents:
    - Interface Agents: Help users to interface with computer systems. Example: Apple's Siri.
    - Information Agents: Help users to locate information on the Internet. Example: Google's PageRank algorithm.
    - Transaction Agents: Help users to conduct commercial transactions on the Internet. Example: Shopping bots.
3. Capabilities of Software Agents:
    - Autonomy: Ability to operate without direct human supervision.
    - Adaptability: Ability to change behaviour based on experience.
    - Collaboration: Ability to work with other agents or humans.
    - Learning: Ability to improve performance based on experience.
4. Applications of Software Agents:
    - Personal Assistants: Manage tasks like scheduling meetings, locating information, etc.
    - E-Commerce: Help users shop online by recommending and filtering products.
    - Network Management: Configure networks, detect faults, and take corrective actions.
    - Information Filtering: Select information from the Internet based on user preferences.
