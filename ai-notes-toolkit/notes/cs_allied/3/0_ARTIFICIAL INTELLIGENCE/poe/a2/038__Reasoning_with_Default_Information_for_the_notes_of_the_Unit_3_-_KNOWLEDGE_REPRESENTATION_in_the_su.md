### Reasoning with Default Information for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Default reasoning is used when there is incomplete information. It uses default assumptions to derive conclusions.
2. It is useful when there are many possible scenarios and we want to draw inferences even with partial information.
3. The two types of defaults are:
- Penalty defaults: These assume a negative outcome in the absence of information. For example, assuming a student has failed if their exam scores are not available.
- Preference defaults: These assume a normal or standard outcome in the absence of information. For example, assuming a customer wants a medium size product if size preference is not specified.
4. Circumstances and priorities determine which type of default is selected. The defaults can be overridden if more information becomes available.
5. Defaults make reasoning possible with limited information but can lead to erroneous conclusions if the assumptions are incorrect. They need to be used judiciously by determining suitable defaults for each situation.
