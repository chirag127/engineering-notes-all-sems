### First Order Predicate Logic

- First order predicate logic is a formal system used to represent knowledge.
- It consists of variables, constants, logical connectives, quantifiers and predicate symbols.
- Variables are placeholders for entities whose values are not known. They can take on different values.
- Constants represent specific entities. They have fixed values.
- Logical connectives like and, or, not are used to combine propositions.
- Quantifiers like for all and there exists are used to express the scope of variables.
- Predicate symbols are used to represent relations between entities. They take variables as inputs and produce propositions as outputs.
- Statements in first order predicate logic are evaluated as either true or false.
- It is a restricted form of logic that allows variables to vary over individuals only. Relations and functions cannot be used as inputs.
- It is commonly used in artificial intelligence to represent structured knowledge. Automated reasoning can be applied on the logical statements to derive new knowledge.
