# IoT/M2M systems layers and design standardization

- IoT/M2M systems are composed of devices, networks, platforms, and applications that enable communication and data exchange between machines and humans.
- IoT/M2M systems can be divided into three major domains: the application layer, the service layer, and the network layer .
- The application layer is the domain where the end-user interacts with the IoT/M2M system, such as through a web interface, a mobile app, or a voice command. The application layer provides the functionality and logic for the IoT/M2M system, such as data analysis, visualization, control, and automation.
- The service layer is the domain where the IoT/M2M system manages the resources, devices, and data. The service layer provides the common services and capabilities for the IoT/M2M system, such as device registration, discovery, management, security, data storage, processing, and aggregation.
- The network layer is the domain where the IoT/M2M system connects the devices and the service layer. The network layer provides the communication protocols and technologies for the IoT/M2M system, such as cellular, Wi-Fi, Bluetooth, Zigbee, LoRa, etc.
- IoT/M2M systems layers and design standardization aim to ensure interoperability, scalability, security, and reliability of the IoT/M2M system across different domains, platforms, and technologies.
- IoT/M2M systems layers and design standardization can be achieved through various approaches, such as using open standards, common APIs, reference architectures, and best practices.
- Some examples of IoT/M2M systems layers and design standardization initiatives are:
  - oneM2M, a global initiative that defines a common service layer for IoT/M2M systems .
  - Open Geospatial Consortium (OGC), an international consortium that defines open standards for geospatial information and sensor web.
  - ETSI, a European standards organization that develops standards for IoT/M2M systems, such as Smart M2M and 3GPP.
  - Application Layer Protocol Options for M2M & IoT, a DigiKey article that compares different application layer protocols for IoT/M2M systems, such as MQTT, CoAP, HTTP, and AMQP.
