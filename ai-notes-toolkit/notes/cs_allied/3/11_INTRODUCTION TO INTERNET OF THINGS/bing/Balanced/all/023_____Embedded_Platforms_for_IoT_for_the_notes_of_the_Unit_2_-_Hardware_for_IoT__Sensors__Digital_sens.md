# Embedded Platforms for IoT

## Embedded Computing Basics

- Embedded computing is the process of designing and implementing a system that performs a specific function using a combination of hardware and software components.
- Embedded systems are typically constrained by factors such as power consumption, memory size, processing speed, and cost.
- Embedded systems are often used in IoT applications, such as smart home devices, wearable devices, industrial automation, and environmental monitoring.
- Embedded systems usually consist of four main components: a microcontroller, a memory, a sensor or actuator, and a communication interface.

## Overview of IoT Supported Hardware Platforms

- There are many hardware platforms that can be used to develop IoT applications, depending on the requirements and preferences of the developers.
- Some of the most popular and widely used hardware platforms for IoT are:

### Arduino

- Arduino is an open-source platform that consists of a microcontroller board and a software development environment.
- Arduino boards are easy to use and program, and support a variety of sensors, actuators, and communication modules through standard or custom shields.
- Arduino boards are suitable for prototyping and testing IoT applications that do not require high performance or complex functionality.

### Netduino

- Netduino is a platform that is compatible with Arduino, but uses a microcontroller that runs the .NET Micro Framework, a subset of the .NET Framework for embedded devices.
- Netduino boards can be programmed using C# or Visual Basic, and support the same sensors, actuators, and communication modules as Arduino.
- Netduino boards are suitable for IoT applications that require more advanced features, such as multitasking, networking, and web services.

### Raspberry Pi

- Raspberry Pi is a platform that consists of a single-board computer that runs a Linux-based operating system, such as Raspbian or Ubuntu.
- Raspberry Pi boards have a high processing power and memory capacity, and support a variety of peripherals, such as cameras, keyboards, and displays, through standard or custom expansion boards.
- Raspberry Pi boards are suitable for IoT applications that require complex functionality, such as image processing, data analysis, and graphical user interfaces.

### BeagleBone

- BeagleBone is a platform that consists of a single-board computer that runs a Linux-based operating system, such as Debian or Android.
- BeagleBone boards have a similar processing power and memory capacity as Raspberry Pi, but also have a microcontroller that can be used for real-time tasks, such as sensor reading and actuator control.
- BeagleBone boards are suitable for IoT applications that require a combination of high performance and low latency, such as robotics, automation, and gaming.

### Intel Galileo

- Intel Galileo is a platform that consists of a single-board computer that runs a Linux-based operating system, such as Yocto or Wind River.
- Intel Galileo boards have a similar processing power and memory capacity as Raspberry Pi and BeagleBone, but also have a microcontroller that is compatible with Arduino, and can be programmed using the Arduino software development environment.
- Intel Galileo boards are suitable for IoT applications that require a combination of high performance and Arduino compatibility, such as smart home devices, wearable devices, and environmental monitoring.

### ARM Cortex

- ARM Cortex is a family of microcontrollers that are based on the ARM architecture, a widely used instruction set for embedded devices.
- ARM Cortex microcontrollers have a low power consumption and a high processing speed, and support a variety of sensors, actuators, and communication modules through standard or custom boards.
- ARM Cortex microcontrollers are suitable for IoT applications that require high performance and low power consumption, such as medical devices, security systems, and wireless sensor networks.
