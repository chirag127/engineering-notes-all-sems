# Overview of IOT supported Hardware platforms such as Arduino, NetArduino, Raspberry pi, Beagle Bone, Intel Galileo boards and ARM cortex

- Internet of Things (IoT) is the concept of connecting various devices and sensors to the internet, enabling data collection, processing, and communication.
- IoT devices require hardware platforms that can support the functionalities and requirements of IoT applications, such as low power consumption, wireless connectivity, embedded computing, and sensor integration.
- There are many hardware platforms available for IoT development, each with different features, capabilities, and costs. Some of the common IoT hardware platforms are:

  - **Arduino**: Arduino is an open-source platform that consists of a microcontroller board and a software development environment. Arduino boards are easy to use, inexpensive, and compatible with various sensors and modules. Arduino can run simple IoT applications that do not require complex processing or networking .
  - **Netduino**: Netduino is a platform that is similar to Arduino, but runs on the .NET Micro Framework. Netduino boards can use the same sensors and modules as Arduino, but also support more advanced features, such as multitasking, debugging, and encryption. Netduino can run IoT applications that require more functionality and security.
  - **Raspberry Pi**: Raspberry Pi is a single-board computer that runs Linux or other operating systems. Raspberry Pi has a powerful processor, memory, and various ports and interfaces. Raspberry Pi can run complex IoT applications that require high performance, multimedia, or web services .
  - **BeagleBone**: BeagleBone is another single-board computer that runs Linux or other operating systems. BeagleBone has a similar processor and memory as Raspberry Pi, but also has more input/output pins and supports real-time processing. BeagleBone can run IoT applications that require fast and precise control of hardware .
  - **Intel Galileo**: Intel Galileo is a platform that combines the features of Arduino and Raspberry Pi. Intel Galileo has a microcontroller and a processor, and can run both Arduino sketches and Linux applications. Intel Galileo can run IoT applications that require both simplicity and complexity .
  - **ARM Cortex**: ARM Cortex is a family of microcontroller cores that are widely used in embedded systems. ARM Cortex cores have low power consumption, high performance, and support various architectures and instruction sets. ARM Cortex can run IoT applications that require energy efficiency, scalability, and flexibility.
