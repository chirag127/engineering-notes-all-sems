### Conceptual Framework for the notes of the Unit 1 - Internet of Things (IoT)

1. **Vision**: The vision of IoT is to create a world where all devices and objects are connected and can communicate with each other to improve the quality of life and efficiency of systems.
2. **Definition**: IoT refers to the interconnection of physical devices, vehicles, buildings, and other items embedded with electronics, software, sensors, and network connectivity, which enables these objects to collect and exchange data.
3. **Conceptual Framework**: The conceptual framework of IoT includes the following components:
    - **Sensors/Devices**: These are the physical objects that collect data from the environment and send it to the network.
    - **Connectivity**: This refers to the network that connects the sensors/devices to the cloud or other systems.
    - **Data Processing**: This is where the collected data is processed and analyzed to extract useful information.
    - **User Interface**: This is where the user can interact with the IoT system and receive information or control the devices.
4. **Architectural View**: The architectural view of IoT includes the following layers:
    - **Perception Layer**: This is where the data is collected by the sensors/devices.
    - **Network Layer**: This is where the data is transmitted from the sensors/devices to the cloud or other systems.
    - **Middleware Layer**: This is where the data is processed and analyzed.
    - **Application Layer**: This is where the user interacts with the IoT system.
5. **Technology behind IoT**: The technology behind IoT includes sensors, connectivity, data processing, and user interface. Some of the technologies used in IoT include RFID, NFC, Bluetooth, Wi-Fi, cellular, and satellite communication.
6. **Sources of IoT**: The sources of IoT data can include sensors, devices, social media, and other sources of data.
7. **M2M Communication**: M2M (Machine to Machine) communication refers to the communication between devices without human intervention. This is an important aspect of IoT as it allows devices to communicate and share data with each other.
8. **IoT Examples**: Some examples of IoT include smart homes, smart cities, wearable devices, and connected cars.
9. **Design Principles for Connected Devices**: The design principles for connected devices in IoT/M2M systems include layers and design standardization, communication technologies, data enrichment and consolidation, ease of designing, and affordability.
