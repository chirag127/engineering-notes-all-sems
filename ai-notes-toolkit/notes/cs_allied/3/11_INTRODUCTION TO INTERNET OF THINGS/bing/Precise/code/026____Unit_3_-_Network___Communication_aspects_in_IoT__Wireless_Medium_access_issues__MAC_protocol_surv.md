## Unit 3 - Network & Communication aspects in IoT

### Wireless Medium access issues
- Wireless medium access control (MAC) is responsible for coordinating access to the shared wireless medium.
- In IoT, wireless medium access issues arise due to the large number of devices competing for access to the shared wireless medium.
- Some common wireless medium access issues in IoT include interference, congestion, and collisions.

### MAC protocol survey
- MAC protocols are used to coordinate access to the shared wireless medium.
- There are several MAC protocols that can be used in IoT, including TDMA, FDMA, CDMA, and CSMA/CA.
- Each MAC protocol has its own advantages and disadvantages, and the choice of MAC protocol depends on the specific requirements of the IoT application.

### Survey routing protocols
- Routing protocols are used to determine the best path for data to travel from the source to the destination.
- In IoT, routing protocols must be able to handle the large number of devices and the dynamic nature of the network.
- Some common routing protocols used in IoT include AODV, DSR, and OLSR.

### Sensor deployment & Node discovery
- Sensor deployment refers to the process of placing sensors in the environment to collect data.
- In IoT, sensors must be deployed in a way that ensures good coverage and connectivity.
- Node discovery is the process of discovering and identifying the nodes in the network.
- In IoT, node discovery is important for establishing and maintaining the network topology.

### Data aggregation & dissemination
- Data aggregation refers to the process of combining data from multiple sources to provide a more complete view of the data.
- In IoT, data aggregation is important for reducing the amount of data that needs to be transmitted and for improving the quality of the data.
- Data dissemination refers to the process of distributing data to the nodes in the network.
- In IoT, data dissemination is important for ensuring that the data is available to the nodes that need it.
