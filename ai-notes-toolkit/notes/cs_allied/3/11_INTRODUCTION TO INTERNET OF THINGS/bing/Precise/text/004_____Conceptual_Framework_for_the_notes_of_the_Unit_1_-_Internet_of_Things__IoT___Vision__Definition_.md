### Conceptual Framework for the notes of the Unit 1 - Internet of Things (IoT)

1. **Vision:** The vision of IoT is to create a world where all objects are connected and can communicate with each other to improve the quality of life and efficiency of systems.
2. **Definition:** IoT refers to the interconnection of physical objects, such as devices, vehicles, and buildings, through the internet, allowing them to collect and exchange data.
3. **Conceptual Framework:** The conceptual framework of IoT includes the following components:
    - **Sensors/Actuators:** These are the devices that collect data from the environment or perform actions based on the data received.
    - **Connectivity:** This refers to the communication technologies used to transmit data between the sensors/actuators and the cloud or other devices.
    - **Data Processing:** This involves the analysis and processing of the data collected by the sensors/actuators to extract useful information.
    - **User Interface:** This is the interface through which the user can interact with the IoT system, such as a mobile app or a web dashboard.
4. **Architectural View:** The architectural view of IoT includes the following layers:
    - **Perception Layer:** This layer is responsible for collecting data from the environment through sensors and actuators.
    - **Network Layer:** This layer is responsible for transmitting the data collected by the perception layer to the processing layer.
    - **Processing Layer:** This layer is responsible for processing and analyzing the data received from the network layer to extract useful information.
    - **Application Layer:** This layer is responsible for providing the user with an interface to interact with the IoT system and to receive the information extracted by the processing layer.
5. **Technology behind IoT:** The technology behind IoT includes sensors, communication technologies, data processing and analysis techniques, and user interface design.
6. **Sources of the IoT:** The sources of the IoT include sensors and actuators that collect data from the environment, as well as data generated by users through their interactions with the IoT system.
7. **M2M Communication:** M2M (machine-to-machine) communication refers to the communication between devices without the need for human intervention. This is an essential component of IoT systems.
8. **IoT Examples:** Some examples of IoT applications include smart homes, smart cities, healthcare, transportation, and agriculture.
9. **Design Principles for Connected Devices:** The design principles for connected devices in IoT systems include the following:
    - **IoT/M2M systems layers and design standardization:** The design of IoT systems should follow a standardized layered architecture to ensure interoperability between devices.
    - **Communication technologies:** The choice of communication technology should be based on the requirements of the IoT application, such as data rate, range, and power consumption.
    - **Data enrichment and consolidation:** The data collected by the IoT system should be enriched and consolidated to extract useful information.
    - **Ease of designing and affordability:** The design of IoT systems should be easy and affordable to ensure widespread adoption.
