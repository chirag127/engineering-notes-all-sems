## Unit 3 - Network & Communication aspects in IoT

1. **Wireless Medium access issues:** In wireless communication, multiple devices share the same communication medium, which can lead to interference and collisions. To avoid these issues, various medium access control (MAC) protocols are used to coordinate the access of multiple devices to the wireless medium.

2. **MAC protocol survey:** There are several MAC protocols used in wireless communication, including Time Division Multiple Access (TDMA), Frequency Division Multiple Access (FDMA), and Code Division Multiple Access (CDMA). Each protocol has its own advantages and disadvantages, and the choice of protocol depends on the specific requirements of the network.

3. **Survey routing protocols:** Routing protocols are used to determine the best path for data to travel from one device to another in a network. There are several routing protocols used in wireless communication, including Ad hoc On-Demand Distance Vector (AODV), Dynamic Source Routing (DSR), and Optimized Link State Routing (OLSR). Each protocol has its own advantages and disadvantages, and the choice of protocol depends on the specific requirements of the network.

4. **Sensor deployment & Node discovery:** In a wireless sensor network, sensors are deployed to collect data from the environment. Once deployed, the sensors must be able to discover other nodes in the network in order to communicate and share data. Various techniques are used for node discovery, including broadcasting, neighbor discovery, and beaconing.

5. **Data aggregation & dissemination:** In a wireless sensor network, data is collected by individual sensors and then aggregated to reduce the amount of data that needs to be transmitted. Data dissemination is the process of distributing the aggregated data to the appropriate devices in the network. Various techniques are used for data aggregation and dissemination, including clustering, data fusion, and data compression.
