### Arduino Platform Boards Anatomy

- Arduino boards are the microcontroller development platform that will be at the heart of your projects. They sense the environment by receiving inputs from many sensors, and affect their surroundings by controlling lights, motors, and other actuators  .
- Arduino Uno is one of the most popular Arduino boards. It is based on the ATmega328P microcontroller, which has 32 KB of flash memory, 2 KB of SRAM, and 1 KB of EEPROM.
- Arduino Uno has 14 digital input/output pins, of which 6 can be used as PWM outputs. These pins can be used to read or write digital signals, such as HIGH or LOW, or to generate or modulate analog signals, such as varying the brightness of an LED.
- Arduino Uno also has 6 analog input pins, which can be used to read analog signals, such as the voltage from a potentiometer or a temperature sensor. These pins have a 10-bit resolution, which means they can measure 1024 different levels of voltage, from 0 to 5 V.
- Arduino Uno has a 16 MHz ceramic resonator, which provides the clock signal for the microcontroller. It also has a USB connection, which can be used to power the board, upload the code, or communicate with the computer or other devices.
- Arduino Uno has a power jack, which can be used to supply external power to the board, from 7 to 12 V. It also has an ICSP header, which can be used to program the microcontroller using an external programmer.
- Arduino Uno has a reset button, which can be used to restart the microcontroller and run the code from the beginning.
