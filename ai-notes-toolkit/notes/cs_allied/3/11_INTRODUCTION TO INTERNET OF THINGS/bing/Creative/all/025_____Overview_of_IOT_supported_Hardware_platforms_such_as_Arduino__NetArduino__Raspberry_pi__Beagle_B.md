# Overview of IOT supported Hardware platforms such as Arduino, NetArduino, Raspberry pi, Beagle Bone, Intel Galileo boards and ARM cortex

- Internet of Things (IoT) is the network of physical devices, sensors, actuators, and other embedded systems that can communicate and exchange data over the internet or other networks.
- IoT devices require hardware platforms that can support the functionalities and requirements of IoT applications, such as low power consumption, wireless connectivity, data processing, and security.
- There are many hardware platforms available for IoT development, each with its own features, advantages, and limitations. Some of the common IoT hardware platforms are:

  - **Arduino**: Arduino is an open-source platform that consists of a microcontroller board and a software development environment. Arduino boards are easy to use, inexpensive, and compatible with various sensors and actuators. Arduino supports various communication protocols, such as Wi-Fi, Bluetooth, Ethernet, and LoRa. Arduino is suitable for beginners and hobbyists who want to create simple IoT projects. 
  - **Netduino**: Netduino is a platform that is similar to Arduino, but runs on the .NET Micro Framework. Netduino boards can be programmed using C# and Visual Studio. Netduino supports Wi-Fi, Ethernet, and CAN bus communication. Netduino is suitable for developers who are familiar with the .NET framework and want to create more complex IoT applications. 
  - **Raspberry Pi**: Raspberry Pi is a single-board computer that runs on Linux or Windows operating systems. Raspberry Pi can perform various tasks, such as web browsing, video streaming, image processing, and machine learning. Raspberry Pi supports Wi-Fi, Bluetooth, Ethernet, and USB communication. Raspberry Pi is suitable for advanced users and professionals who want to create powerful and versatile IoT applications.  
  - **BeagleBone**: BeagleBone is a single-board computer that runs on Linux operating systems. BeagleBone can perform real-time processing, data acquisition, and control applications. BeagleBone supports Wi-Fi, Bluetooth, Ethernet, and USB communication. BeagleBone is suitable for developers who want to create high-performance and industrial IoT applications.  
  - **Intel Galileo**: Intel Galileo is a single-board computer that runs on Linux operating systems. Intel Galileo can perform data analysis, cloud computing, and edge computing applications. Intel Galileo supports Wi-Fi, Bluetooth, Ethernet, and USB communication. Intel Galileo is suitable for developers who want to create scalable and secure IoT applications.  
  - **ARM Cortex**: ARM Cortex is a family of microcontroller cores that are widely used in embedded systems. ARM Cortex cores can perform low-power, high-efficiency, and real-time processing applications. ARM Cortex cores support various communication protocols, such as Wi-Fi, Bluetooth, Zigbee, and Z-Wave. ARM Cortex cores are suitable for developers who want to create customized and optimized IoT applications.
