# Embedded Computing Basics

- An embedded system is a special-purpose computer system designed to perform a dedicated function.
- Unlike a general-purpose computer, such as a personal computer, an embedded system performs one or a few pre-defined tasks, usually with very specific requirements, and often includes task-specific hardware and mechanical parts not usually found in a general-purpose computer.
- Embedded systems are typically characterized by low cost, low power, small size, high reliability, and real-time performance.
- Embedded systems are widely used in various domains, such as consumer electronics, industrial automation, automotive, aerospace, medical, telecommunications, and Internet of Things (IoT).
- There are four types of embedded systems: standalone, networked, mobile, and real-time.
  - Standalone embedded systems operate independently and do not require any external resources or connections.
  - Networked embedded systems rely on a network connection to communicate with other systems or devices.
  - Mobile embedded systems are portable and can move from one location to another.
  - Real-time embedded systems have strict timing constraints and must respond to events within a specified deadline.
- Embedded systems are designed and developed using various software and hardware tools, such as programming languages, compilers, debuggers, simulators, emulators, microcontrollers, microprocessors, sensors, actuators, and communication protocols.
- Embedded systems are composed of three main components: hardware, software, and firmware.
  - Hardware refers to the physical devices and circuits that make up the embedded system, such as the processor, memory, input/output devices, and peripherals.
  - Software refers to the programs and applications that run on the embedded system, such as the operating system, drivers, middleware, and user interface.
  - Firmware refers to the software that is stored in the non-volatile memory of the embedded system, such as the boot loader, BIOS, and device drivers.
