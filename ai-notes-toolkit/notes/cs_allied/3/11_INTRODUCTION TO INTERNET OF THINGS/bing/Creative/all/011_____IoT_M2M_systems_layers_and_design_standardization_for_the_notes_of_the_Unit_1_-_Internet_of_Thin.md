# IoT/M2M systems layers and design standardization

- IoT/M2M systems are composed of different layers that perform different functions and communicate with each other using various protocols and standards.
- The most common layer model for IoT/M2M systems is the three-layer model, which consists of the application layer, the service layer, and the network layer .
- The application layer is the top layer that provides the user interface and the business logic for the IoT/M2M applications. It interacts with the service layer through APIs and protocols such as HTTP, MQTT, CoAP, etc.
- The service layer is the middle layer that provides the common services and functionalities for the IoT/M2M applications, such as device management, data management, security, discovery, etc. It interacts with the network layer through protocols such as TCP/IP, UDP, etc.
- The network layer is the bottom layer that provides the connectivity and transport for the IoT/M2M devices and data. It supports various technologies such as cellular, Wi-Fi, Bluetooth, Zigbee, LoRa, etc.
- One of the main challenges for IoT/M2M systems is to achieve interoperability and scalability among different devices, applications, and platforms. Therefore, standardization is essential to ensure compatibility and efficiency.
- One of the leading initiatives for IoT/M2M standardization is oneM2M, which is a global partnership project that aims to develop a common service layer framework for IoT/M2M applications .
- oneM2M defines a set of functional entities, interfaces, and protocols for the service layer, which can be implemented on various platforms and devices. It also provides a reference architecture and a set of use cases and requirements for IoT/M2M applications.
- Some of the benefits of oneM2M are:

  - It enables cross-domain and cross-platform interoperability for IoT/M2M applications.
  - It reduces the complexity and cost of developing and deploying IoT/M2M applications.
  - It enhances the security and privacy of IoT/M2M data and devices.
  - It supports various communication technologies and protocols for the network layer.
  - It facilitates the integration and reuse of existing IoT/M2M solutions and services.

- Besides oneM2M, there are other standardization efforts and organizations for IoT/M2M systems, such as:

  - Open Geospatial Consortium (OGC), which provides standards for geospatial information and sensor web.
  - IEEE, which provides standards for wireless communication, networking, and security for IoT/M2M devices.
  - IETF, which provides standards for internet protocols and architectures for IoT/M2M systems.
  - W3C, which provides standards for web technologies and semantic web for IoT/M2M applications.
  - ISO/IEC, which provides standards for information technology and quality management for IoT/M2M systems.
