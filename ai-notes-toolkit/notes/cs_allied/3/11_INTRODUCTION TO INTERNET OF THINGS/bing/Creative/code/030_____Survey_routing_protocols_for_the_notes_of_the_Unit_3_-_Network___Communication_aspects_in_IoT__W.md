### Survey routing protocols for IoT

- Routing protocols are responsible for finding and maintaining routes between nodes in a network, especially in wireless and dynamic environments.
- IoT networks are characterized by low-power, lossy, heterogeneous, and constrained devices that communicate over various wireless technologies and protocols.
- Routing protocols for IoT must address the challenges of scalability, mobility, energy efficiency, reliability, security, and interoperability.
- Several routing protocols have been proposed and standardized for IoT, such as:
  - Routing Protocol for Low-Power and Lossy Networks (RPL): A distance-vector protocol that organizes nodes into a Directed Acyclic Graph (DAG) based on a routing metric and an objective function. RPL supports both point-to-point and point-to-multipoint traffic, and can adapt to network dynamics and link failures. RPL is the main routing protocol for IPv6 over Low-Power Wireless Personal Area Networks (6LoWPAN)  .
  - Constrained Application Protocol (CoAP): A lightweight application layer protocol that enables RESTful communication between resource-constrained devices. CoAP uses UDP as the transport layer protocol and supports reliable message delivery, asynchronous notifications, resource discovery, and security. CoAP is designed to interoperate with HTTP and the web .
  - Geographic Routing Protocol (GRP): A position-based protocol that uses the location information of nodes to make routing decisions. GRP does not require any topology information or route discovery, and can cope with node mobility and network partitioning. GRP is suitable for scenarios where GPS or other localization techniques are available .
  - Ad hoc On-Demand Distance Vector Routing (AODV): A reactive protocol that establishes routes on-demand when a source node wants to communicate with a destination node. AODV uses route requests and route replies to discover and maintain routes, and uses sequence numbers to avoid loops and stale routes. AODV is widely used in mobile ad hoc networks (MANETs) and can be adapted for IoT .
  - Dynamic Source Routing (DSR): Another reactive protocol that uses source routing, where the source node specifies the complete route to the destination node in the packet header. DSR uses route discovery and route maintenance mechanisms to find and repair routes, and uses route caching to store and reuse routes. DSR is also a popular protocol for MANETs and can be applied to IoT .
- Other routing protocols for IoT include Cluster-Based Routing Protocol (CBRP), Hierarchical Routing Protocol (HRP), Ant Colony Optimization (ACO), and Bio-Inspired Routing Protocol (BIRP)   .
- Routing protocols for IoT must also consider the security aspects, such as authentication, confidentiality, integrity, availability, and non-repudiation. Some of the security threats and attacks that can affect IoT routing are spoofing, replay, modification, wormhole, blackhole, sinkhole, Sybil, and selective forwarding .
- Routing protocols for IoT are an active and evolving research area, and there is no one-size-fits-all solution for all IoT scenarios and applications. The choice of a routing protocol depends on the network characteristics, the application requirements, and the trade-offs between performance and complexity.     .
