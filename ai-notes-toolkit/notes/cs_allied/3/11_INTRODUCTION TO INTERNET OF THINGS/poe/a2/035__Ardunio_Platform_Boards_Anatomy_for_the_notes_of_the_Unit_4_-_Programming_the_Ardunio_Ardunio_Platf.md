### Arduino Platform Boards Anatomy

1. Microcontroller: The brain of the Arduino board is the microcontroller. It is responsible for processing the inputs and sending the appropriate outputs. The most common microcontrollers used in Arduino boards are ATmega 328 and ATmega2560.
2. Input and Output Pins: The Arduino board contains input and output pins that can be interfaced with various sensors and actuators. The pins can be configured as either input or output pins based on the requirement.
3. Power Supply: The Arduino board requires a power supply to power the microcontroller and other components. The power can be supplied via USB cable or an external power supply. The operating voltage of different Arduino boards can vary from 3.3V to 5V.
4. Clock: The microcontroller requires a clock signal to synchronise its operation. The Arduino board contains an onboard oscillator that generates the required clock signal. The frequency of the clock signal can vary based on the microcontroller and board type.
5. Memory: The Arduino board contains memory in the form of SRAM and Flash memory. The SRAM is used for storing variables and other runtime data. The Flash memory is used for storing the Arduino program. The amount of on-board memory can vary based on the Arduino board type.
6. Interfaces: The Arduino board provides various interfaces to communicate with other devices and components. The common interfaces include USB, I2C, SPI, UART, etc. The available interfaces can vary based on the Arduino board type.
