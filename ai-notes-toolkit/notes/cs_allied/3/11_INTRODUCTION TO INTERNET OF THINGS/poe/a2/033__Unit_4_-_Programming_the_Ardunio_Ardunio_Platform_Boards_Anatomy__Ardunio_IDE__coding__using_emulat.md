## Unit 4 - Programming the Ardunio:

1. Ardunio Platform Boards Anatomy
- Microcontroller: Atmel AVR ATmega or ARM Cortex M0/M3/M4
- Input/Output Pins: Digital I/O Pins and Analog Input Pins
- Power Supply: USB port/External power jack
- Memory: Flash memory to store the program
- Clock: Internal oscillator/External crystal

2. Ardunio IDE
- Open source IDE to write, compile and upload the code to Ardunio
- Has a simple and easy to use interface with options to:
-- Write code in Ardunio programming language (based on C/C++)
-- Verify and compile the code
-- Upload the code to the Ardunio board
-- Serial monitor to display the output

3. Coding in Ardunio
- Ardunio programming language is based on C/C++
- Keywords: void, pinMode, digitalWrite, int, float, string, if, else, for, while etc.
- Blink LED program to get started
- Comments, functions, arrays and libraries can be used

4. Using Emulator
- Ardunio IDE has a built-in emulator to test the code without connecting the actual hardware
- Helps to debug the code and check for errors before uploading to the board

5. Using Libraries
- Pre-written code libraries available for add-on hardware modules like LCD, servo motor etc.
- Reduces the programming effort and time
- Includes .h files to access the library functions

6. Additions in Ardunio
- Variety of shields to add more features: Ethernet, motor, relay, GPS etc.
- Boards in different sizes, processing power and connectivity options
- Interfacing with sensors and modules through I2C, SPI, UART, PWM etc.

7. Programming Ardunio for IoT
- Connect to WiFi/internet using Ethernet shield or ESP8266/ESP32
- Read data from sensors and upload to cloud platforms like ThingSpeak, AWS IoT etc.
- Control devices from web apps/mobile apps by making API calls
