### Data aggregation & dissemination for the notes of the Unit 3 - Network & Communication aspects in IoT: Wireless Medium access issues, MAC protocol survey, Survey routing protocols, Sensor deployment & Node discovery, Data aggregation & dissemination in the subject of INTRODUCTION TO INTERNET OF THINGS.

- Data aggregation: Collecting and combining data from multiple sources to provide a unified view of the data. This is done to remove redundancy, provide a complete picture, and help in faster decision making. Some methods for data aggregation are:
-- Event-based aggregation: Data is aggregated when an event occurs like threshold breach.
-- Periodic aggregation: Data is aggregated at regular intervals.
-- Query-based aggregation: Data is aggregated on-demand when a query is received.

- Data dissemination: Transmitting the aggregated data to the nodes that need it. This can be:
-- Single-path: Data is sent over a single path to the destination.
-- Multi-path: Data is sent over multiple paths to the destination and the first copy to arrive is used. This provides robustness against path failures.
-- Flooding: Data is broadcast to all nodes in the network. This is simple but can lead to implosion and overlap.
-- Gossiping: Nodes randomly exchange information with nearby neighbors. This avoids implosion and overlap but may be slow.

- Medium access issues: Contention between nodes to access the shared wireless medium. This can lead to collisions, transmission delays, and reduced throughput. Some ways to address this are:
-- Carrier sense multiple access (CSMA): Nodes sense the medium and transmit when it is free. This can still lead to collisions.
-- Time division multiple access (TDMA): The medium is divided into time slots and assigned to nodes. This avoids collisions but requires tight synchronization.
-- Frequency division multiple access (FDMA): The medium is divided into frequency bands and assigned to nodes. This also avoids collisions but can be inefficient.
-- Code division multiple access (CDMA): Nodes are assigned codes to spread their signals and share the medium. Complex to implement but provides robustness and flexibility.
