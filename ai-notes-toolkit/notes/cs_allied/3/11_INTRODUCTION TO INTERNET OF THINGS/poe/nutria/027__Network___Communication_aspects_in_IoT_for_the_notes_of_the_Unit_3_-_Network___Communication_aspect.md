
### Network & Communication aspects in IoT

* Wireless Medium Access Issues: Wireless medium access issues refer to the challenges associated with sharing a limited wireless medium among multiple devices. These issues can be addressed using a variety of techniques such as carrier sense multiple access (CSMA) and time division multiple access (TDMA).

* MAC Protocol Survey: A MAC protocol survey provides an overview of the various MAC protocols that are used to manage the access of multiple devices to a shared wireless medium. These protocols include IEEE 802.11, Bluetooth, Zigbee, and WiMAX.

* Survey Routing Protocols: A survey of routing protocols provides an overview of the various routing protocols that are used to route data in a wireless network. These protocols include shortest path routing, flooding, and link-state routing.

* Sensor Deployment and Node Discovery: Sensor deployment and node discovery refer to the process of deploying sensors in an environment and discovering nodes in a wireless network. This process is important for gathering data from the environment and communicating with other nodes.

* Data Aggregation and Dissemination: Data aggregation and dissemination refer to the process of collecting data from multiple sources and disseminating it to other nodes. This process is important for collecting and disseminating data in a distributed environment.
