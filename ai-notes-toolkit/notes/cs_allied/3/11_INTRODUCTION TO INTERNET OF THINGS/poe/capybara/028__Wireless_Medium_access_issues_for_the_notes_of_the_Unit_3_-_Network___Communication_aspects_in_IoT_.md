### Wireless Medium Access Issues

Wireless medium access is one of the most critical aspects of IoT communication. Due to the increasing number of IoT devices and their diverse applications, the wireless medium access issues have become more complex. Here are some of the key issues related to wireless medium access in IoT:

- **Limited Bandwidth**: IoT applications require low power and low data rate communication, but the available bandwidth is limited, which can cause interference and congestion.

- **Interference**: In a wireless network, interference can occur due to overlapping channels, multiple transmissions, or other devices in the same frequency range.

- **Latency**: The latency of wireless communication can affect the performance of IoT applications. Real-time applications such as remote surgery, autonomous vehicles, and industrial automation require low latency.

- **Security**: IoT devices are vulnerable to security threats such as eavesdropping, hacking, and denial-of-service attacks. Wireless medium access protocols need to ensure secure communication.

### MAC Protocol Survey

Medium Access Control (MAC) protocols are responsible for managing the access to the wireless medium. There are various MAC protocols available, each with its advantages and limitations. Here are some of the commonly used MAC protocols for IoT:

- **CSMA/CA**: Carrier Sense Multiple Access with Collision Avoidance is a contention-based MAC protocol that ensures fair access to the wireless medium by avoiding collisions among nodes.

- **TDMA**: Time Division Multiple Access is a deterministic MAC protocol that divides the time into slots and assigns each node a specific slot for transmission.

- **FDMA**: Frequency Division Multiple Access is a bandwidth allocation MAC protocol that divides the frequency band into sub-channels and assigns each node a specific sub-channel for transmission.

- **CDMA**: Code Division Multiple Access is a spread spectrum MAC protocol that allows multiple nodes to transmit simultaneously by using different codes.

### Survey Routing Protocols

Routing protocols are responsible for finding the best path for data transmission between nodes. There are various routing protocols available for IoT networks, each with its advantages and limitations. Here are some of the commonly used routing protocols for IoT:

- **Flat routing**: In flat routing, all nodes are at the same level, and any node can communicate with any other node directly.

- **Hierarchical routing**: In hierarchical routing, nodes are organized into a hierarchy, and only nodes at the same or adjacent levels can communicate directly.

- **Location-based routing**: In location-based routing, nodes use their physical location to determine the best path for data transmission.

- **Content-based routing**: In content-based routing, nodes use the content of the data to determine the best path for data transmission.

### Sensor Deployment & Node Discovery

Sensor deployment and node discovery are critical aspects of IoT communication. Here are some of the key points related to sensor deployment and node discovery:

- **Sensor Placement**: The placement of sensors should be such that they cover the entire area of interest and provide accurate data.

- **Node Discovery**: Nodes need to discover each other to establish communication. Various techniques such as broadcasting, scanning, and clustering can be used for node discovery.

### Data Aggregation & Dissemination

Data aggregation and dissemination are critical aspects of IoT communication. Here are some of the key points related to data aggregation and dissemination:

- **Data Aggregation**: Data from multiple sensors can be aggregated to reduce the amount of data transmitted and save energy.

- **Data Dissemination**: Data can be disseminated using various techniques such as unicast, multicast, and broadcast. The choice of technique depends on the application requirements.
