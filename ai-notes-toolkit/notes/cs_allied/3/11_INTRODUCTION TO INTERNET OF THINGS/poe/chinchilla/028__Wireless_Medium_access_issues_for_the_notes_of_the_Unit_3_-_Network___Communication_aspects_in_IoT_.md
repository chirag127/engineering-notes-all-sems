### Wireless Medium access issues

In the world of IoT, wireless medium access is crucial for efficient communication between devices. However, there are several challenges that need to be addressed to ensure smooth communication. Here are some of the wireless medium access issues that need attention:

1. Interference: The presence of other wireless devices transmitting in the same frequency range can cause interference and affect the quality of communication. This is particularly true in crowded environments.

2. Limited bandwidth: Wireless networks have limited bandwidth. As the number of devices increases, the available bandwidth per device decreases, leading to slower communication.

3. Power consumption: Wireless devices rely on batteries for power, which can limit their capacity to transmit and receive data. Therefore, it is crucial to optimize power consumption to ensure longer battery life.

4. Latency: Wireless networks can experience latency, which can affect the real-time nature of IoT applications that require near-instantaneous responses.

5. Security: Wireless networks are susceptible to security breaches, and IoT devices are no exception. It is crucial to ensure that the wireless medium is secured to prevent unauthorized access and data breaches.

### MAC protocol survey

Media Access Control (MAC) protocols are used to regulate access to the wireless medium. They are responsible for ensuring that multiple devices can communicate without interference. Here are some of the commonly used MAC protocols in IoT:

1. Carrier Sense Multiple Access with Collision Avoidance (CSMA/CA): This protocol avoids collisions by checking if the medium is free before transmitting data.

2. Time Division Multiple Access (TDMA): This protocol divides the available bandwidth into time slots, with each device allocated a slot for communication.

3. Frequency Division Multiple Access (FDMA): This protocol divides the available bandwidth into frequency channels, with each device allocated a channel for communication.

### Survey routing protocols

Routing protocols are used to determine the best path for data transmission between devices. Here are some of the commonly used routing protocols in IoT:

1. Ad-hoc On-Demand Distance Vector (AODV): This protocol creates a route on-demand when data needs to be transmitted between devices.

2. Destination-Sequenced Distance Vector (DSDV): This protocol maintains a table of all the possible routes between devices and selects the best route for data transmission.

3. Routing Information Protocol (RIP): This protocol uses hop count as the metric for selecting the best route between devices.

### Sensor deployment & Node discovery

Sensor deployment and node discovery are crucial for efficient communication in IoT. Here are some of the considerations for sensor deployment and node discovery:

1. Sensor placement: Sensors need to be placed in locations where they can collect the required data efficiently.

2. Network topology: The network topology needs to be designed to ensure that communication between devices is efficient.

3. Node discovery: Devices need to be able to discover and connect to other devices on the network to facilitate communication.

### Data aggregation & dissemination

Data aggregation and dissemination are critical components of IoT communication. Here are some of the considerations for data aggregation and dissemination:

1. Data processing: Data needs to be processed to extract meaningful insights.

2. Data aggregation: Data from multiple devices needs to be aggregated to provide a holistic view of the system.

3. Data dissemination: Data needs to be disseminated to the relevant stakeholders in a timely and efficient manner.

In conclusion, wireless medium access issues are critical considerations in IoT communication. Effective MAC protocols, routing protocols, sensor deployment, and data aggregation are crucial for efficient communication between devices.
