## Unit 3 - Network & Communication aspects in IoT: Wireless Medium access issues, MAC protocol survey, Survey routing protocols, Sensor deployment & Node discovery, Data aggregation & dissemination

In this unit, we will be discussing various aspects of network and communication in the context of IoT. The Internet of Things (IoT) has revolutionized the way we interact with technology and devices. It has opened up new opportunities for businesses and individuals alike, enabling us to monitor and control devices remotely, automate processes, and gather data for analysis. However, to make this all possible, there are a number of challenges that must be addressed, particularly in the area of network and communication.

### Wireless Medium Access Issues

Wireless Medium Access Control (MAC) is a key component of wireless communication in IoT. It deals with how devices access and use the wireless medium for communication. There are a number of issues that arise in this context, including:

- Interference: Interference can occur when multiple devices are trying to use the same wireless medium at the same time. This can cause collisions and result in data loss or corruption.
- Scalability: As the number of devices on a network increases, the network can become congested, resulting in slower data transfer rates and increased latency.
- Energy efficiency: Many IoT devices are battery-powered, so it is important to minimize the energy required for communication to extend battery life.

### MAC Protocol Survey

There are a number of MAC protocols that have been developed for IoT devices. These include:

- CSMA/CA: This protocol is commonly used in Wi-Fi networks and involves devices waiting for a clear channel before transmitting data.
- TDMA: This protocol divides the wireless medium into time slots and allocates each device a specific time slot for communication.
- ALOHA: This protocol involves devices transmitting data randomly and then checking to see if the data was received correctly. If not, the device will retransmit the data.

### Survey Routing Protocols

Routing is the process of determining the best path for data to take between devices on a network. There are a number of routing protocols that have been developed for IoT devices, including:

- Distance vector: This protocol involves each node sending its routing table to its neighbors, which in turn send their routing tables to their neighbors. This process continues until all nodes have a complete view of the network.
- Link state: This protocol involves each node sending information about its connections to all other nodes on the network. This information is used to build a complete map of the network.
- Hierarchical: This protocol involves dividing the network into smaller sub-networks, with each sub-network having its own routing protocol. This can improve scalability and reduce network congestion.

### Sensor Deployment & Node Discovery

Sensor deployment and node discovery are important aspects of IoT network and communication. Sensor deployment involves placing sensors in strategic locations to gather data, while node discovery involves identifying and connecting new devices to the network. There are a number of techniques that can be used for sensor deployment and node discovery, including:

- Beacon-based: This involves devices broadcasting beacon signals that can be detected by other devices on the network.
- Proximity-based: This involves devices detecting each other's proximity and automatically connecting to each other.
- IP-based: This involves devices using IP addresses to identify and connect to each other on the network.

### Data Aggregation & Dissemination

Data aggregation and dissemination are key components of IoT network and communication. Data aggregation involves collecting and processing data from multiple sources, while data dissemination involves distributing that data to other devices or systems. There are a number of techniques that can be used for data aggregation and dissemination, including:

- Publish/subscribe: This involves devices publishing data to a central broker or server, which can then disseminate that data to other devices that have subscribed to it.
- Peer-to-peer: This involves devices communicating with each other directly to share data.
- Cloud-based: This involves storing data in the cloud and accessing it via APIs or other web-based interfaces.

In conclusion, network and communication are critical components of IoT. In this unit, we have discussed a number of issues, protocols, and techniques related to wireless medium access, routing, sensor deployment, node discovery, and data aggregation and dissemination. By understanding these concepts, you can better design and manage IoT networks to ensure optimal performance and reliability.
