Fields:
A field is a mathematical structure that has two operations, addition and multiplication, that behave similarly to the real numbers. 

Finite Field of the form GF(p):
A finite field is a field with a finite number of elements. The notation GF(p) represents a finite field with p elements, where p is a prime number.

Modular Arithmetic:
A mathematical system that involves performing arithmetic operations in a finite set of residues modulo a fixed integer.

Prime and Relative Prime Numbers:
A prime number is a positive integer greater than 1 that has no positive integer divisors other than 1 and itself. Two numbers are relatively prime if they have no common positive factors other than 1.

Extended Euclidean Algorithm:
An algorithm that finds the greatest common divisor of two numbers and also finds integers x and y such that gcd(a,b) = ax + by.

Advanced Encryption Standard (AES) Encryption and Decryption:
A symmetric encryption algorithm that uses a fixed-length key to encrypt and decrypt data. AES is widely used for secure data transmission.

Fermat's and Euler's Theorem:
Fermat's theorem states that if p is a prime number and a is an integer not divisible by p, then ap-1 = 1 (mod p). Euler's theorem states that if n and a are relatively prime, then a^φ(n) = 1 (mod n), where φ(n) is Euler's totient function.

Primarily Testing:
A primality test is an algorithm for determining whether a given number is prime.

Chinese Remainder Theorem:
A theorem that states that if n1, n2, ..., nk are pairwise relatively prime positive integers, and a1, a2, ..., ak are any integers, then there exists a unique solution x (mod N) where N = n1n2...nk and x ≡ ai (mod ni) for i = 1, 2, ..., k.

Discrete Logarithmic Problem:
The problem of finding the integer x such that a^x = b (mod p) given positive integers a, b, and p where p is a prime number.

Principals of Public Key Crypto Systems:
Public key cryptography is a cryptographic system that uses two keys, a public key and a private key. The public key is used for encryption, and the private key is used for decryption.

RSA Algorithm:
A widely used public key encryption algorithm that is based on the mathematical properties of large prime numbers.

Security of RSA:
The security of RSA is based on the difficulty of factoring large numbers and the discrete logarithmic problem.
