### Cluster Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject
Cluster Grids are a type of Grid Computing technology that utilizes multiple computers connected in a network to perform large scale processing tasks. They are designed to be highly scalable and provide high performance computing capabilities. Cluster Grids can be used for a variety of applications, including scientific simulations, data analysis, and large scale data processing. Key features of Cluster Grids include:

- Resource sharing: Cluster Grids allow multiple computers to share resources, such as CPU, memory, and storage, to perform complex computing tasks.

- Load balancing: Cluster Grids distribute processing tasks across multiple computers to ensure that no single computer is overburdened, resulting in improved performance and reliability.

- Fault tolerance: Cluster Grids are designed to be highly reliable, with built-in mechanisms to detect and recover from failures.

- Scalability: Cluster Grids can be easily expanded by adding additional computers to the network, allowing for increased processing power and capacity.

Cluster Grids are a popular choice for organizations that require high performance computing capabilities, as they offer a cost-effective solution compared to traditional supercomputing systems.
