### Infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject
Infrastructure for Cloud Computing:
- Physical servers, storage systems, and network resources that make up the underlying foundation of a cloud computing environment.
- Virtualized using software to provide scalable and flexible computing resources on-demand.
- Can be owned and operated by the organization using the cloud or by a third-party provider.
- Typically housed in data centers, with redundant power and network connections for high availability.

Types of Cloud Infrastructures:
- Public Cloud: owned and operated by a third-party provider, with resources shared among multiple customers over the internet.
- Private Cloud: owned and operated by a single organization, with resources dedicated to that organization's use.
- Hybrid Cloud: combination of public and private clouds, allowing for the flexibility and cost savings of public clouds with the security and control of a private cloud.
