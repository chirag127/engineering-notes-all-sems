### Components for Clusters for the notes of the Unit 3 - Overview of Cluster Computing in the subject
Components for Clusters:
1. Nodes: physical servers or computers that perform processing tasks
2. Networking: interconnects nodes, enables communication between nodes
3. Cluster Management Software: manages and monitors cluster resources, schedules tasks
4. Storage: provides shared storage for data, often network-attached storage (NAS) or storage area network (SAN)
5. Job Scheduler: schedules and manages tasks across the cluster
6. Load Balancer: distributes workloads evenly across nodes to optimize performance
7. Monitoring Tools: monitor cluster performance and resource utilization.
