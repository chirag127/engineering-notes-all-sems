### Cluster Computer and its Architecture for the notes of the Unit 3 - Overview of Cluster Computing in the subject
Cluster computing refers to the practice of connecting multiple computers together to work as a single system. The architecture of a cluster computer consists of multiple nodes, each of which is a separate computer. These nodes communicate with each other using high-speed interconnects and are managed by a cluster manager. The cluster manager is responsible for distributing tasks among the nodes, monitoring their performance, and ensuring that the cluster remains available even if one or more nodes fail.

In terms of hardware, each node in a cluster computer typically consists of a central processing unit (CPU), memory, and storage. The nodes may also have other components such as graphics processing units (GPUs) or field-programmable gate arrays (FPGAs) to support specific types of workloads.

In terms of software, cluster computers typically use a distributed operating system such as Linux or Windows HPC Server to manage the nodes and distribute tasks. The cluster manager software is responsible for scheduling tasks, monitoring the status of the nodes, and providing a single point of control for the cluster.

Cluster computing is used for a variety of applications, including scientific simulations, financial modeling, and data analytics. By combining the processing power of multiple nodes, cluster computers can perform complex computations much faster than a single computer could.
