### Cluster Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject
Cluster Computing is a type of parallel computing that involves a group of interconnected computers working together as a single system to perform large-scale computing tasks. The computers in a cluster are connected through a fast interconnect, like Infiniband or 10 Gigabit Ethernet, and work together to divide a large computing task into smaller, more manageable subtasks. Each computer in the cluster is called a node and each node runs its own instance of an operating system and has its own CPU, memory, and storage.

In cluster computing, the nodes work together to perform the task, with each node taking on a portion of the work. The nodes communicate with each other to coordinate their efforts and share data as needed. The result is a system that can perform much faster and more efficiently than a single computer working alone.

Cluster computing is often used in high-performance computing (HPC) applications, such as scientific simulations, weather forecasting, and molecular modeling. It is also used in data centers for large-scale data processing, such as in search engines and online advertising.

Advantages of cluster computing include increased performance, scalability, and reliability. Because the nodes in a cluster can work together to perform a task, the overall performance of the system can be much higher than that of a single computer. Additionally, the cluster can be scaled by adding more nodes, allowing it to handle even larger computing tasks. Finally, because there are multiple nodes in the cluster, if one node fails, the others can continue to work, providing a high level of reliability.

In conclusion, cluster computing is a powerful tool for large-scale computing tasks that require high performance, scalability, and reliability. It is widely used in HPC and data center applications and continues to be an important area of research and development.
