### Service Oriented Architecture for the notes of the Unit 5 - Overview of Cloud Computing in the subject
Service Oriented Architecture (SOA) is a design pattern for building software systems that are composed of loosely coupled, independent services that communicate with each other through well-defined interfaces. The goal of SOA is to create a flexible, scalable, and reusable architecture that can support the changing needs of an organization.

Advantages of SOA:
- Flexibility: Services can be easily added, modified, or removed without affecting the rest of the system.
- Reusability: Services can be reused across multiple applications, reducing development time and cost.
- Scalability: Services can be scaled independently, allowing the system to accommodate changes in demand.
- Interoperability: Services can be implemented in different technologies and can communicate with each other through well-defined interfaces.

Disadvantages of SOA:
- Complexity: The design and implementation of SOA can be complex and requires a deep understanding of the architecture and the services being developed.
- Integration: Integrating services from different sources can be challenging and requires a robust integration strategy.
- Security: Securing communication between services can be difficult, and requires a comprehensive security plan.

SOA is often used in cloud computing to build scalable, flexible, and reusable systems that can take advantage of the benefits of cloud computing. In cloud computing, services can be hosted in the cloud and accessed by users over the internet, allowing for a highly scalable and flexible architecture.
