### Cloud Computing Components for the notes of the Unit 5 - Overview of Cloud Computing in the subject
Cloud Computing components are:

1. Infrastructure as a Service (IaaS): This component provides virtualized computing resources like servers, storage, and networking.

2. Platform as a Service (PaaS): This component provides a platform for developing, testing, and deploying applications without the need to manage the underlying infrastructure.

3. Software as a Service (SaaS): This component provides software applications over the internet, eliminating the need to install and run software on local computers.

4. Data as a Service (DaaS): This component provides access to data storage, management, and analytics services over the internet.

5. Function as a Service (FaaS): This component allows users to execute functions in response to events, without having to manage the underlying infrastructure.

All these components are delivered over the internet and are managed by service providers, allowing users to access and use them on-demand.
