### Data persistence using Core Data and SQLite for the notes of the Unit 5 - Technology II –iOS of Design & Development Of Applications ( KCS075) in the subject of Design & Development Of Applications ( KCS075)
Data persistence refers to the ability of an application to store and retrieve data even after it has been closed. In iOS, two common methods for data persistence are Core Data and SQLite.

Core Data is an object-relational mapping (ORM) framework that provides a way to manage and persist data in a structured way. It provides a high-level API for working with data and automatically handles low-level details such as database creation and schema migrations. With Core Data, data is represented as objects and relationships between objects, making it easier to work with than raw SQL.

SQLite is a lightweight, file-based database that can be used to store data in a structured way. It provides a low-level API for working with data and requires manual management of database creation and schema migrations. SQLite is a good choice for applications that need to store large amounts of structured data, but it can be more complex to work with than Core Data.

For the notes of Unit 5 - Technology II – iOS of Design & Development Of Applications (KCS075), you can use either Core Data or SQLite to persist data for your notes application. However, if you are looking for a more straightforward and easier-to-use solution, Core Data may be a better choice.
