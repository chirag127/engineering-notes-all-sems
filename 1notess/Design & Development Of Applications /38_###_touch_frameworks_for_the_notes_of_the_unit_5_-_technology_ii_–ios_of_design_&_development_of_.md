### Touch frameworks for the notes of the Unit 5 - Technology II –iOS of Design & Development Of Applications ( KCS075) in the subject of Design & Development Of Applications ( KCS075)
Touch frameworks for iOS:
1. UIKit: The default framework for building user interfaces on iOS. It provides basic UI elements, animations, and event handling.
2. Core Animation: A powerful animation framework for creating rich and smooth animations.
3. Core Graphics: A low-level framework for drawing graphics and handling images.
4. Core Text: A framework for working with text, including font management and text layout.
5. Core Location: A framework for working with location data, including GPS and Wi-Fi positioning.
6. MapKit: A framework for displaying maps and working with geographical data.
7. EventKit: A framework for working with calendars and events.
8. GameKit: A framework for building games on iOS.
9. iAd: A framework for integrating advertisements into iOS apps.
