### Location aware applications using Core Location and Map Kit for the notes of the Unit 5 - Technology II –iOS of Design & Development Of Applications ( KCS075) in the subject of Design & Development Of Applications ( KCS075)
Location aware applications use Core Location and Map Kit frameworks to access device's GPS and provide location-based services.

Core Location:
- Determines device's current location
- Monitors changes in location
- Can run in background

Map Kit:
- Displays maps and annotations on a map
- Provides turn-by-turn directions
- Can show current location on a map

Examples of location aware applications:
- Maps: show location, directions, and points of interest
- Weather apps: show weather information based on current location
- Social media apps: show nearby friends or events based on location

Note: To use Core Location and Map Kit, developers need to have a good understanding of iOS development and the iOS SDK.
