### Android architecture for the notes of the Unit 4 - Technology I – ANDROID of Design & Development Of Applications ( KCS075) in the subject of Design & Development Of Applications ( KCS075)
Android architecture consists of 4 layers:

1. Linux kernel: provides low-level system services such as memory management, process management, and network stack.

2. Libraries: provide a set of reusable components, including media, graphics, and database libraries.

3. Android framework: provides APIs for developers to build apps, including activities, services, content providers, and broadcast receivers.

4. Application layer: contains the actual apps installed on the device.

Each layer builds on the previous one, providing more functionality and abstraction for developers. The Android framework is designed to be flexible and extensible, allowing developers to create custom components and extend existing ones.
