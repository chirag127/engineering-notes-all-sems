### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing
An oracle is a mechanism used in software testing to determine if the output of a system under test is correct. It acts as a reference point for comparison between expected and actual results. There are several types of oracles:

1. Code-based oracle: compares the output of the system under test with the source code.

2. Expert oracle: relies on the knowledge and expertise of a human tester to determine if the output is correct.

3. Documentation-based oracle: compares the output of the system under test with documentation.

4. Model-based oracle: uses a model of the system to determine if the output is correct.

5. Test oracle: compares the output of the system under test with test data.
