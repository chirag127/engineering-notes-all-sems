## Unit 2 - Functional Testing
Functional Testing is a type of software testing that verifies if the system under test (SUT) meets the specified requirements and works as expected. It tests the functionality of the system, ensuring that it performs the tasks it was designed to perform. It is usually performed by manual testers, but can also be automated. The goal of functional testing is to identify any defects in the SUT that could impact its functionality. This type of testing is usually done before non-functional testing, such as performance or security testing, to ensure that the SUT is functioning correctly before those tests are performed.
