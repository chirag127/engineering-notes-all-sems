### Scheme for the notes of the Unit 4 - Regression Testing in the subject of Software Testing
Regression Testing:
- Purpose: Confirm that changes to the software have not impacted previously working functionality
- Types: Retest-All, Re-execution, Selective Regression
- Techniques: Test Case Prioritization, Test Suite Reduction, Automation 
- Benefits: Early detection of defects, Improved software quality, Reduced time and cost
- Challenges: Maintenance of regression test suite, Test case selection, Test environment setup.
