## Unit 4 - Regression Testing
Regression testing is a type of software testing that verifies that changes to the codebase (such as bug fixes or new features) haven't affected existing functionality. The goal is to catch any unintended consequences of changes and ensure the software continues to work as expected. Regression tests are usually automated and run regularly as part of a continuous integration/continuous delivery pipeline. They can be performed at various levels, including unit, integration, and system testing. Regression testing helps to maintain software quality and prevent regressions (i.e. previously fixed bugs reappearing).
