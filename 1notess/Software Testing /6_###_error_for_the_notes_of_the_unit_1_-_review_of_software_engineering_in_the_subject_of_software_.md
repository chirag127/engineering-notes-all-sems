### Error for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing
Error: A mistake or flaw in a software program that produces unintended or undesirable results.

Types of Errors:
1. Syntax Error: Occurs when code violates the rules of a programming language.
2. Logical Error: A mistake in the logic of the program that produces incorrect results.
3. Run-time Error: Occurs during execution of a program and can cause the program to crash.
4. Semantic Error: A mistake in the meaning of the code, which may not cause an immediate error but can lead to unintended results.

Impact of Errors:
1. Decreased software quality
2. Increased cost of development and maintenance
3. Decreased user satisfaction
4. Delayed delivery schedules

Prevention of Errors:
1. Adequate testing and debugging
2. Code reviews and walkthroughs
3. Use of software development methodologies
4. Proper documentation and design specifications.
