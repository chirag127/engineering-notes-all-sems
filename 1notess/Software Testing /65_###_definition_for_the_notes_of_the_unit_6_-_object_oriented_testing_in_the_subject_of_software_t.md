### Definition for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing
Unit 6: Object Oriented Testing 
- Definition: A testing method that focuses on testing the behavior and interactions of objects within an object-oriented software system. 
- Object-oriented programming (OOP) concepts: Classes, objects, inheritance, polymorphism, encapsulation. 
- Benefits: Improved code reuse, modularity, and maintainability. 
- Techniques: Black-box testing, white-box testing, grey-box testing, use case testing. 
- Tools: JUnit, TestNG, NUnit, PyUnit.
