### System Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing
System Testing:
- Verifies that the entire system meets specified requirements
- Tests the system as a whole, not individual components
- Includes functional, performance, security, and other types of testing
- Involves both manual and automated testing methods
- Can be done by in-house team or third-party testers
- Should be performed after unit, integration, and acceptance testing.
