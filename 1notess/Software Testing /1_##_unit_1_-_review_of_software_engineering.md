## Unit 1 - Review of Software Engineering
Software Engineering is the process of designing, creating, testing, and maintaining software systems. Unit 1 covers the basics of software engineering, including:

1. Software Development Life Cycle (SDLC) - the process of creating software, including requirements gathering, design, implementation, testing, and maintenance.

2. Software Requirements - the needs and constraints that the software must meet.

3. Software Design - the process of defining the architecture, components, modules, interfaces, and data for a software system.

4. Software Testing - the process of evaluating software to identify and fix defects.

5. Software Maintenance - the process of updating and fixing software after it has been released.

6. Agile and Waterfall methodologies - two popular project management approaches for software development.

The unit also covers important software engineering concepts such as software quality, software architecture, software reuse, and software evolution.
