### Cyclomatic Complexity for the notes of the Unit 3 - Structural Testing in the subject of Software Testing
Cyclomatic Complexity is a software metric used to measure the complexity of a program. It is defined as the number of independent paths through a program's source code. The higher the cyclomatic complexity, the more complex the program is considered to be, and the more difficult it is to test. The goal of structural testing is to ensure that all independent paths through the code are executed, and that all branches and conditions are tested. This helps to uncover hidden bugs and improve the overall quality of the software. The cyclomatic complexity metric can be used to guide the design of test cases and to measure the effectiveness of testing efforts. It is important to keep cyclomatic complexity as low as possible to make the software easier to maintain and test.
