## Unit 3 - Structural Testing
Structural testing is a type of software testing that focuses on verifying the design and architecture of a system. It aims to ensure that the software is built in accordance with the specifications and that it meets the requirements for stability, reliability, and scalability. This type of testing is performed early in the development process and is typically done by developers or architects. It involves analyzing the code, data structures, and algorithms to identify potential issues, and then creating and executing tests to validate the design. Common techniques used in structural testing include code reviews, white-box testing, and static code analysis. The goal of structural testing is to catch issues early in the development process, saving time and resources, and improving the overall quality of the software.
