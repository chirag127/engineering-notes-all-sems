IBM Big Data strategy is a set of solutions and services that help organizations store, manage, and analyze large and diverse data sets from various sources. IBM Big Data strategy aims to enable data-driven decision making, innovation, and competitive advantage. IBM Big Data strategy consists of four main components: 

- IBM InfoSphere BigInsights: A platform that combines Apache Hadoop and IBM technologies to handle large-scale data processing and analytics.
- IBM InfoSphere Streams: A platform that enables real-time analysis of streaming data from sensors, devices, social media, and other sources.
- IBM PureData System for Analytics: A high-performance appliance that integrates database, server, and storage technologies to deliver fast and scalable analytics.
- IBM PureData System for Operational Analytics: An appliance that supports operational intelligence and real-time decision making for transactional data.
