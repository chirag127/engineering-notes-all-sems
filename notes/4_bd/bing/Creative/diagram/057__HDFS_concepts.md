HDFS stands for Hadoop Distributed File System, which is a distributed file system designed to run on commodity hardware and to handle large data sets with high throughput. HDFS is one of the major components of Apache Hadoop, along with MapReduce and YARN. HDFS has a master-slave architecture, where one node acts as the NameNode (master) and the rest of the nodes are DataNodes (slaves). The NameNode manages the file system namespace and the metadata of the files and directories, while the DataNodes store the actual data in blocks of fixed size (usually 128 MB). HDFS replicates each block across multiple DataNodes for fault tolerance and load balancing. HDFS also supports data locality, which means that the computation is moved to the nodes where the data resides, rather than moving the data across the network.
