#### Introduction to Big SQL

Big SQL is a high performance massively parallel processing (MPP) SQL engine for Hadoop that can query data from various sources, such as HDFS, RDBMS, NoSQL databases, object stores, and WebHDFS. Big SQL is built on the IBM common SQL database technology and has all the standard RDBMS features. Big SQL can process complex queries for relational and Hadoop data using an advanced SQL compiler and a cost-based optimizer. Big SQL also supports federated access to data outside of Hadoop using IBM Fluid Query technology and Spark connectors.
