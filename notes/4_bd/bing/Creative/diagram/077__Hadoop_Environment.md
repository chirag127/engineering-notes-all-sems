Hadoop is an open source software framework that allows for the distributed processing of large data sets across clusters of computers using simple programming models. It consists of four main modules: Hadoop Distributed File System (HDFS), Yet Another Resource Negotiator (YARN), MapReduce, and Hadoop Common. Hadoop also has a rich ecosystem of tools and applications that help collect, store, process, analyze, and manage big data, such as Apache Pig, Apache Hive, Apache HBase, Apache Spark, Presto, and Apache Zeppelin.
