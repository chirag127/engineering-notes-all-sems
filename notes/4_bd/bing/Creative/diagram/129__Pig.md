Pig is a high-level platform or tool which is used to process large datasets on Hadoop using a scripting language called Pig Latin. Pig Latin scripts are internally converted into a series of MapReduce jobs by the Pig framework, which provides a high-level of abstraction and optimization for data analysis. Pig has two main components: Pig Latin and Pig Engine. Pig Latin is the language used to write the scripts, and Pig Engine is the component that executes the scripts on Hadoop.

```
+----------------+        +----------------+        +----------------+
|                |        |                |        |                |
|  Pig Script    |------->|  Pig Latin     |------->|  MapReduce     |
|                |        |  Compiler      |        |  Jobs          |
+----------------+        +----------------+        +----------------+
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
     |                         |                          |
+----------------+        +----------------+        +----------------+
|                |        |                |        |                |
|  Grunt Shell   |------->|  Parser        |------->|  Optimizer     |
|                |        |                |        |                |
+----------------+        +----------------+        +----------------+
```

The Pig script can be written in a file or entered interactively in the Grunt shell. The script is then parsed by the Parser, which checks the syntax and semantics of the script, and generates a logical plan (a DAG of logical operators). The logical plan is then passed to the Optimizer, which applies various optimizations such as projection and pushdown. The optimized logical plan is then compiled by the Pig Latin Compiler into a series of MapReduce jobs, which are executed on Hadoop. The output of the MapReduce jobs is stored in HDFS.
