Compliance of Big Data refers to the process of meeting the data protection regulations and standards that apply to the collection, processing, and storage of large and complex data sets. Compliance of Big Data involves implementing appropriate technical and organizational measures to protect personal data, ensure transparency, minimize data collection, and respect the rights of data subjects. Compliance of Big Data also requires sharing the responsibility for data security with the cloud service provider, if the data is stored in the cloud.

#### Compliance of Big Data

```
+-----------------+      +-----------------+      +-----------------+
| Data Collection | ---> | Data Processing | ---> | Data Storage    |
+-----------------+      +-----------------+      +-----------------+
|                 |      |                 |      |                 |
| - Obtain        |      | - Anonymize     |      | - Encrypt       |
|   consent       |      | - Pseudonymize  |      | - Backup        |
| - Inform        |      | - Aggregate     |      | - Secure        |
|   purpose       |      | - Filter        |      | - Delete        |
| - Limit         |      | - Audit         |      | - Retain        |
|   scope         |      | - Monitor       |      | - Access        |
| - Validate      |      | - Report        |      | - Restore       |
| - Update        |      |                 |      |                 |
+-----------------+      +-----------------+      +-----------------+
```

The diagram above illustrates the basic stages of data handling and some of the compliance measures that can be applied at each stage. The compliance measures are not exhaustive and may vary depending on the specific regulations and standards that apply to the data. For example, the General Data Protection Regulation (GDPR) and the Protection of Personal Information Act (POPIA) are two data protection laws that have different requirements for data collection, processing, and storage. Therefore, it is important to understand the legal and ethical obligations of working with big data and to implement compliance by design into any big data project.
