MRv2 in Hadoop ecosystem is also known as YARN (Yet Another Resource Negotiator). It is a framework that separates the resource management and scheduling tasks from the MapReduce layer. It allows multiple applications to run on the same Hadoop cluster, not only batch processing jobs. It also improves the scalability and availability of the system by introducing a Resource Manager, a Node Manager, and an Application Master for each job .
