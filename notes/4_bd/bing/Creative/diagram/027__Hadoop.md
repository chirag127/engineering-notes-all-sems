Hadoop is a framework for distributed computation and storage of very large data sets on computer clusters. It consists of three core components: Hadoop Distributed File System (HDFS), MapReduce, and Yet Another Resource Negotiator (YARN). HDFS is a distributed file system that stores data in blocks across multiple nodes. MapReduce is a programming model that processes data in parallel using two types of tasks: map and reduce. YARN is a resource management layer that allocates resources and schedules tasks for applications running on Hadoop.
