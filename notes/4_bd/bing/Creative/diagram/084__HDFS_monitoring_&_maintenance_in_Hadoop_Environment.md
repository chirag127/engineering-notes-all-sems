#### HDFS monitoring & maintenance in Hadoop Environment

HDFS is the primary distributed storage used by Hadoop applications. A HDFS cluster primarily consists of a NameNode that manages the file system metadata and DataNodes that store the actual data. The NameNode and DataNodes have built-in web servers that make it easy to check the current status of the cluster. HDFS also provides various commands and tools for monitoring and maintaining the cluster, such as fsck, balancer, dfsadmin, etc.
