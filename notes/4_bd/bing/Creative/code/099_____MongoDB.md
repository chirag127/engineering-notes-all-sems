### MongoDB

MongoDB is a database management system that uses documents instead of tables and rows to store and process data. It is a nonrelational or NoSQL database, which means that it does not enforce a fixed schema or structure for the data. MongoDB is open source and distributed, which means that it can run on multiple servers and provide high availability, scalability, and performance. Some of the features and characteristics of MongoDB are:

- **Document model**: MongoDB stores data as documents, which are JSON-like objects that can have different fields and values. Documents are grouped in collections, which are analogous to tables in relational databases. Documents are flexible and can be modified without affecting other documents in the same collection.
- **Query language**: MongoDB supports a rich and expressive query language that allows users to filter, sort, aggregate, and manipulate data. MongoDB also supports secondary indexes, which can improve the performance of queries by creating additional data structures based on the document fields.
- **Aggregation framework**: MongoDB provides a powerful aggregation framework that allows users to perform complex data analysis and transformation on the server side. The aggregation framework consists of a series of stages that can apply various operations on the documents, such as grouping, filtering, projecting, sorting, and joining.
- **Replication**: MongoDB supports replication, which is the process of synchronizing data across multiple servers. Replication provides data redundancy and fault tolerance, as well as increased read capacity. MongoDB uses a replica set, which is a group of servers that maintain the same data set and elect a primary server to handle write operations. The other servers, called secondaries, replicate the data from the primary and can serve read requests.
- **Sharding**: MongoDB supports sharding, which is the process of distributing data across multiple servers based on a partition key. Sharding allows MongoDB to scale horizontally and handle large data sets and high throughput. MongoDB uses a sharded cluster, which consists of shards, config servers, and mongos routers. Shards are replica sets that store a subset of the data, config servers store the metadata of the cluster, and mongos routers route the requests to the appropriate shards.
