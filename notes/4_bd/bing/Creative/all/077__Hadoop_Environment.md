## Hadoop Environment

- Hadoop is an open source software framework that allows for the distributed processing of large data sets across clusters of commodity computers using simple programming models .
- Hadoop consists of four main modules: Hadoop Distributed File System (HDFS), Yet Another Resource Negotiator (YARN), MapReduce, and Hadoop Common.
- HDFS is a distributed file system that provides high-throughput access to application data with no need for schemas to be defined up front.
- YARN is a resource-management platform that manages compute resources in clusters and uses them to schedule user applications.
- MapReduce is a programming model for large-scale data processing that uses distributed and parallel computation algorithms.
- Hadoop Common includes the libraries and utilities used and shared by other Hadoop modules.
- Hadoop is designed to scale up from single servers to thousands of machines, each offering local computation and storage .
- Hadoop is fault-tolerant, cost-effective, and open source.
- Hadoop requires the Java Runtime Environment (JRE) 1.6 or higher and Secure Shell (SSH) set up between nodes in the cluster.
- Hadoop is part of a larger ecosystem of tools and applications that help collect, store, process, analyze, and manage big data. Some of these include Apache Pig, Apache Hive, Apache HBase, Apache Spark, Presto, and Apache Zeppelin.
