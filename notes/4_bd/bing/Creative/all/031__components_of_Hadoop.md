#### Components of Hadoop

Hadoop is a framework that uses distributed storage and parallel processing to store and manage big data. It consists of three core components: HDFS, MapReduce, and YARN.

- HDFS (Hadoop Distributed File System) is the storage unit of Hadoop. It is a Java-based distributed file system that can store all kinds of data without prior organization. It divides the data into blocks and distributes them across multiple nodes in a cluster. It also replicates the blocks for fault tolerance and high availability. HDFS has two types of nodes: NameNode and DataNode. NameNode is the master node that manages the metadata and the namespace of the file system. DataNode is the slave node that stores the actual data blocks and communicates with the NameNode.

- MapReduce is the processing unit of Hadoop. It is a software programming model for processing large sets of data in parallel. It consists of two phases: Map and Reduce. Map phase takes the input data and transforms it into key-value pairs. Reduce phase takes the output of the Map phase and aggregates the values based on the keys. MapReduce also has two types of nodes: JobTracker and TaskTracker. JobTracker is the master node that coordinates the execution of the MapReduce jobs. TaskTracker is the slave node that runs the map and reduce tasks assigned by the JobTracker.

- YARN (Yet Another Resource Negotiator) is the resource management unit of Hadoop. It is a framework for scheduling and handling resource requests from distributed applications. It consists of two components: ResourceManager and NodeManager. ResourceManager is the master node that allocates resources to the applications and monitors their status. NodeManager is the slave node that reports the resource utilization and executes the tasks on the containers. YARN enables Hadoop to support various data processing tools besides MapReduce, such as Spark, Hive, Pig, etc.

A mnemonic to remember the three components of Hadoop is: **H**ave **Y**our **M**apReduce **D**one **F**ast.
