#### Introduction to MongoDB

- MongoDB is a **document-oriented database** that stores data in **JSON-like** format.
- MongoDB is a **NoSQL** database, which means it does not use the **relational model** or **SQL** to store and query data.
- MongoDB is **schema-less**, which means it does not enforce a fixed structure or data types for the documents in a collection.
- MongoDB is **scalable**, which means it can handle large amounts of data and high concurrency by using **sharding** and **replication** techniques.
- MongoDB is **flexible**, which means it can support various data models and use cases, such as **key-value**, **graph**, **text**, **geospatial**, and **aggregation**.
- MongoDB is **open-source** and **cross-platform**, which means it can run on various operating systems and hardware configurations.
