#### History of Hadoop

- Hadoop is an open-source software framework for storing and processing large datasets ranging in size from gigabytes to petabytes using the MapReduce programming model. 
- Hadoop was originally designed for computer clusters built from commodity hardware, which is still the common use. 
- Hadoop splits files into large blocks and distributes them across nodes in a cluster. It then transfers packaged code into nodes to process the data in parallel. 
- Hadoop was developed at the Apache Software Foundation, based on two papers published by Google in 2003 and 2004, describing the Google File System (GFS) and the MapReduce programming model.  
- Hadoop was initially a subproject of Apache Nutch, a web search engine project, started by Doug Cutting and Mike Cafarella in 2002.  
- The name Hadoop was derived from the name of Doug Cutting's son's yellow toy elephant.  
- In 2006, Hadoop became an independent project of Apache and Doug Cutting joined Yahoo to scale Hadoop to thousands of nodes.  
- In 2008, Hadoop became a top-level project at Apache and also achieved a record of sorting one terabyte of data in 68 seconds, beating the previous record of 209 seconds by a supercomputer.  
- Since then, Hadoop has been widely adopted by many companies and organizations, such as Facebook, Twitter, LinkedIn, Amazon, IBM, and Netflix, for various big data applications.  
- Hadoop has also evolved over time, adding new components and features, such as Hadoop Distributed File System (HDFS), Hadoop YARN, Hadoop Ozone, and Hadoop Ecosystem, which consists of various tools and frameworks that can be used with Hadoop, such as Apache Pig, Apache Hive, Apache HBase, Apache Spark, Apache ZooKeeper, and Apache Storm.
