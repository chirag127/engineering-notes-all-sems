### Hadoop Eco System Frameworks

- Hadoop Eco System Frameworks are a platform or a suite that provides various services to solve the big data problems. It includes Apache projects and various commercial tools and solutions .
- Hadoop is an open source framework that allows for the distributed storage and processing of large datasets across clusters of computers using simple programming models.
- Hadoop is designed to scale up from a single computer to thousands of clustered computers, with each machine offering local computation and storage.
- Hadoop can efficiently store and process large datasets ranging in size from gigabytes to petabytes of data.
- Hadoop is made up of four major elements: HDFS, MapReduce, YARN, and Hadoop Common .
- HDFS (Hadoop Distributed File System) is the primary component of the Hadoop ecosystem and is responsible for storing large data sets of structured or unstructured data across various nodes and thereby maintaining the metadata in the form of log files.
- HDFS consists of two core components: Name node and Data node. Name node is the prime node which contains metadata (data about data) requiring comparatively fewer resources than the data nodes that store the actual data.
- HDFS provides high-throughput access to application data with no need for schemas to be defined up front.
- YARN (Yet Another Resource Negotiator) is a resource-management platform responsible for managing compute resources in clusters and using them to schedule users’ applications .
- YARN performs scheduling and resource allocation across the Hadoop system .
- YARN consists of three major components: Resource Manager, Node Manager, and Application Manager.
- MapReduce is a programming model for large-scale data processing. Using distributed and parallel computation algorithms, MapReduce makes it possible to carry over processing logic and helps to write applications that transform big datasets into one manageable set .
- MapReduce consists of two phases: Map and Reduce. Map phase takes input data and transforms it into key-value pairs. Reduce phase takes the output of the map phase and aggregates the values based on the keys.
- Hadoop Common includes the libraries and utilities used and shared by other Hadoop modules .
- All Hadoop modules are designed with a fundamental assumption that hardware failures of individual machines or racks of machines are common and should be automatically handled in software by the framework.
- The Apache Hadoop MapReduce and HDFS components were originally derived from Google MapReduce and Google File System (GFS) papers.
- Beyond HDFS, YARN, and MapReduce, the entire Hadoop open source ecosystem continues to grow and includes many tools and applications to help collect, store, process, analyze, and manage big data.
- Some of the popular tools and applications in the Hadoop ecosystem are:
  - Apache Pig: A high-level scripting language for data analysis and manipulation. Pig scripts are translated into MapReduce jobs and executed on Hadoop clusters.
  - Apache Hive: A data warehouse system that provides a SQL-like query language (HiveQL) for data analysis and reporting. Hive converts HiveQL queries into MapReduce jobs and executes them on Hadoop clusters.
  - Apache HBase: A NoSQL database that provides random access and strong consistency for large amounts of sparse and structured data. HBase is built on top of HDFS and supports MapReduce processing.
  - Apache Spark: An in-memory data processing framework that provides faster and more flexible data analysis than MapReduce. Spark supports various languages (Scala, Python, Java, R) and libraries (Spark SQL, Spark Streaming, Spark MLlib, Spark GraphX) for different types of data processing.
  - Presto: A distributed SQL query engine that allows interactive analysis of large datasets stored in various sources, such as HDFS, HBase, Cassandra, MongoDB, etc. Presto can run queries across multiple data sources and join data from different systems.
  - Apache Zeppelin: A web-based notebook that enables interactive data analytics and visualization. Zeppelin supports various languages (Scala, Python, SQL, etc.) and interpreters (Spark, Hive, HBase, etc.) for data exploration and collaboration.
