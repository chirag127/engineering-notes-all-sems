#### Task execution in map reduce

- Map reduce is a programming model for processing large-scale data sets in parallel and distributed environments.
- Map reduce consists of two phases: map and reduce, each of which can be executed by multiple tasks on different nodes of a cluster.
- A map task takes an input key-value pair and produces a set of intermediate key-value pairs as output. The map function defines how to transform the input data into the intermediate data.
- A reduce task takes a set of intermediate key-value pairs that share the same key and produces a set of output key-value pairs as the final result. The reduce function defines how to aggregate the intermediate data for each key.
- The map reduce framework handles the partitioning, shuffling, sorting, and fault tolerance of the data and tasks, allowing the programmer to focus on the logic of the map and reduce functions.
- The map reduce framework consists of a master node and multiple worker nodes. The master node is responsible for coordinating the execution of the map and reduce tasks, while the worker nodes are responsible for running the tasks assigned by the master node.
- The master node splits the input data into fixed-size chunks called input splits, and assigns each input split to a map task. The map task reads the input split and applies the map function to each key-value pair in the input split, generating a set of intermediate key-value pairs. The map task then partitions the intermediate key-value pairs by their keys and writes them to local disk.
- The master node also assigns a set of reduce tasks to the worker nodes, each reduce task corresponding to a partition of the intermediate key-value pairs. The reduce task fetches the intermediate key-value pairs from the local disks of the map tasks, sorts them by their keys, and applies the reduce function to each group of key-value pairs with the same key, generating a set of output key-value pairs. The reduce task then writes the output key-value pairs to the distributed file system.
- The master node monitors the progress and status of the map and reduce tasks, and handles any failures or stragglers by reassigning the tasks to other worker nodes. The master node also notifies the user when the map reduce job is completed.

- A possible mnemonic to remember the steps of map reduce is: **M**ap, **P**artition, **S**huffle, **S**ort, **R**educe, **W**rite. The first letters of each step form the word **MPSSRW**.
