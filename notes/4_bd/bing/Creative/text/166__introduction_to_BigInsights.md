#### Introduction to BigInsights

BigInsights is a product from IBM that provides a platform for managing and analyzing big data. BigInsights is based on Apache Hadoop, an open source framework for distributed storage and processing of large volumes of data. BigInsights enhances Hadoop with additional features and services, such as:

- IBM Open Platform with Apache Hadoop, which includes the core Hadoop components and other open source projects, such as Apache Spark, Apache Hive, Apache HBase, Apache Kafka, and Apache ZooKeeper.
- IBM BigInsights Analyst module, which provides SQL-based analytics with Big SQL and spreadsheet-like analytics with BigSheets.
- IBM BigInsights Data Scientist module, which provides text analytics, machine learning, and statistical analysis with Big R and IBM Text Analytics.
- IBM BigInsights Enterprise Management module, which provides security, governance, and administration tools for Hadoop clusters.
- IBM BigInsights for Apache Hadoop for Non-Production Environment module, which includes all the above modules in a non-production edition.

BigInsights can be deployed on-premises, on cloud, or in a hybrid mode. BigInsights on Cloud is a fully managed Hadoop service that offers the performance and security of an on-premises deployment without the cost or complexity of managing the infrastructure. BigInsights on Cloud also provides access to big data experts and support from IBM.

BigInsights can help organizations to:

- Harness the power of open source innovation and benefit from the latest developments in the Hadoop ecosystem.
- Efficiently manage and mine big data and gain insights from structured, semi-structured, and unstructured data sources.
- Integrate and analyze data from various sources and formats, such as social media, web logs, sensor data, text documents, images, and videos.
- Develop and deploy a variety of analytics applications for different skillsets and use cases, such as customer segmentation, sentiment analysis, fraud detection, recommendation systems, and predictive modeling.
- Scale up and down as needed and handle data growth and changing business requirements.
- Reduce the time and cost of data management and analytics and improve the return on investment (ROI) of big data projects.
