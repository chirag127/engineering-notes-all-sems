#### Java interfaces to HDFS

- HDFS is a distributed file system that is implemented in Java and can be accessed by Java applications through the Hadoop FileSystem class and its subclasses.
- The FileSystem class is an abstract class that represents the client interface to a file system in Hadoop. It provides methods for creating, deleting, reading, writing, and listing files and directories.
- The FileSystem class has several static factory methods for getting an instance of a specific file system implementation, such as HDFS, local file system, or webHDFS. The most common way is to use the `FileSystem.get(Configuration conf)` method, which returns a file system instance based on the configuration properties.
- A file or a directory in a Hadoop file system is represented by a Path object, which encapsulates the URI of the file or directory. A Path object can be created by passing a string or a URI to its constructor.
- To read data from a file in HDFS, one can use the `FileSystem.open(Path path)` method, which returns an FSDataInputStream object that can be used to read bytes from the file. Similarly, to write data to a file in HDFS, one can use the `FileSystem.create(Path path)` method, which returns an FSDataOutputStream object that can be used to write bytes to the file.
- To perform other file system operations, such as deleting, renaming, copying, or moving files and directories, one can use the corresponding methods in the FileSystem class, such as `FileSystem.delete(Path path, boolean recursive)`, `FileSystem.rename(Path src, Path dst)`, `FileSystem.copyFromLocalFile(Path src, Path dst)`, or `FileSystem.moveToLocalFile(Path src, Path dst)`.
- To list the files and directories in a given path, one can use the `FileSystem.listStatus(Path path)` method, which returns an array of FileStatus objects that contain the metadata of the files and directories. Alternatively, one can use the `FileSystem.listFiles(Path path, boolean recursive)` method, which returns a RemoteIterator of LocatedFileStatus objects that also include the block locations of the files.
- To get the information about the file system, such as the capacity, the used space, the remaining space, or the default block size, one can use the methods in the FileSystem class, such as `FileSystem.getCapacity()`, `FileSystem.getUsed()`, `FileSystem.getRemaining()`, or `FileSystem.getDefaultBlockSize(Path path)`.
- To close the file system instance and release the resources, one can use the `FileSystem.close()` method.
