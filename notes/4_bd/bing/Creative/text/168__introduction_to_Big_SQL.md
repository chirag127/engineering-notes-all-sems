#### Introduction to Big SQL

Big SQL is a SQL engine for Hadoop that allows you to query and analyze data from various sources using a single database connection or query. Some of the features and benefits of Big SQL are:

- It supports ANSI-compliant SQL syntax and functions, making it compatible with many existing SQL applications and tools.
- It can access data from HDFS, RDBMS, NoSQL databases, object stores, and WebHDFS using a federated query mechanism that enables data virtualization and integration.
- It leverages the IBM common SQL database technology and a massively parallel processing (MPP) engine to provide high performance, scalability, and reliability for complex queries and large data sets.
- It integrates with Spark and other components of the Apache Hadoop ecosystem, such as Hive, HBase, and Ranger, to provide advanced analytics, machine learning, and security capabilities.
- It offers easy-to-use tools, flexible security options, and improved performance, usability, serviceability, and consumability in the latest version (v5.0.2).

Big SQL is available in two variations: as an integrated component of Cloudera Data Platform, or as a cloud-native service on the IBM Cloud Pak for Data platform. Big SQL can be used for various use cases, such as enterprise data warehouse offloading, federated access to relational and NoSQL data, and real-time analytics. Big SQL can be accessed through a command-line interface, a web console, or an ODBC driver that conforms to the Microsoft Open Database Connectivity 3.0.0 specification   .
