#### Introduction to BigInsights

- BigInsights is a software platform that provides a comprehensive solution for managing and analyzing big data.
- BigInsights is based on Apache Hadoop, an open source framework that enables distributed processing of large and diverse data sets across clusters of commodity hardware.
- BigInsights enhances Hadoop with enterprise-grade features such as security, administration, governance, performance, and integration.
- BigInsights also includes value-added components such as IBM Big SQL, IBM BigSheets, IBM Big R, IBM Text Analytics, and IBM BigInsights Analyst and Data Scientist modules.
- BigInsights can help organizations gain insights from various types of data, such as structured, unstructured, semi-structured, streaming, and geospatial data.
- BigInsights can be deployed on-premises, on cloud, or in a hybrid environment.
