## Unit 2 - Hadoop and Map Reduce

- Hadoop is a platform for distributed storage and processing of large-scale data using a cluster of commodity hardware.
- MapReduce is a programming model and a software framework for writing applications that can run on Hadoop.
- MapReduce consists of two phases: map and reduce.
- The map phase takes an input dataset and splits it into key-value pairs that are processed by user-defined functions in parallel on different nodes of the cluster.
- The reduce phase takes the output of the map phase and combines the key-value pairs into a smaller set of results, also using user-defined functions.
- MapReduce provides scalability, fault-tolerance, and reliability for data processing on Hadoop.
- MapReduce applications can be written in various languages, such as Java, Python, Ruby, etc. using Hadoop Streaming or other APIs.
- MapReduce also provides features such as counters, distributed cache, profiling, debugging, data compression, and skipping bad records.
