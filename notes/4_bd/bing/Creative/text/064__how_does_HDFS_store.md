#### How does HDFS store

HDFS stands for Hadoop Distributed File System, which is a distributed file system designed to run on commodity hardware. It is a key component of the Hadoop framework, which can store, process and analyze large data sets. HDFS has the following characteristics:

- It stores data in a distributed manner. It divides the data into small pieces, called blocks, and stores them on different DataNodes in the cluster. Each block has a default size of 128 MB, which can be configured in the hdfs-site.xml file. The blocks are replicated across multiple DataNodes for fault tolerance and high availability. The default replication factor is 3, which can also be configured in the hdfs-site.xml file.
- It has a master-slave architecture. The master node, called NameNode, manages the file system namespace and the metadata of the files and blocks. It also coordinates the access and operations on the files and blocks among the DataNodes. The slave nodes, called DataNodes, store the actual data blocks and perform read and write operations on them as instructed by the NameNode. The NameNode and DataNodes communicate through heartbeats and block reports.
- It provides high throughput data access. It is optimized for batch processing rather than interactive use. It supports streaming access to file system data, which means that the data can be read or written sequentially without seeking. It also supports parallel processing of data by allowing multiple clients to access the same file or block at the same time.
- It relaxes some POSIX requirements to achieve high performance and scalability. It does not support random write access to files, which means that the files can only be written once and appended later. It also does not support file locking or hard links. It does support atomic rename and delete operations on files and directories.
