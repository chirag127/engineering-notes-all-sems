## Unit 2 - Hadoop and Map Reduce

- Hadoop is an open-source framework that allows distributed processing of large-scale data sets across clusters of computers using simple programming models.
- Hadoop consists of two main components: Hadoop Distributed File System (HDFS) and Hadoop MapReduce.
- HDFS is a distributed file system that provides high-throughput access to data stored on multiple nodes in a cluster. HDFS replicates data blocks across different nodes to ensure fault tolerance and reliability.
- MapReduce is a programming model that enables parallel processing of large data sets by dividing them into smaller chunks called splits. Each split is processed by a mapper function that transforms the input data into key-value pairs. The key-value pairs are then shuffled and sorted by a reducer function that aggregates the values for each key and produces the final output.
- Hadoop MapReduce follows a master-slave architecture, where a single node called the JobTracker coordinates the execution of multiple tasks across different nodes called TaskTrackers. The JobTracker assigns tasks to TaskTrackers based on their availability and data locality. The TaskTrackers report their progress and status to the JobTracker periodically.
- Hadoop MapReduce supports two types of tasks: map tasks and reduce tasks. Map tasks run the mapper function on each split and generate intermediate key-value pairs. Reduce tasks run the reducer function on each group of key-value pairs with the same key and generate the final output. The number of map tasks is determined by the number of splits, while the number of reduce tasks is specified by the user.
- Hadoop MapReduce provides a Java API for writing custom mapper and reducer classes, as well as a set of built-in classes for common operations such as sorting, filtering, joining, etc. Hadoop MapReduce also supports other languages such as Python, Ruby, etc. through the Hadoop Streaming interface, which allows users to write mapper and reducer scripts using standard input and output streams.
- Hadoop MapReduce is suitable for batch processing of large and structured data sets that can be easily partitioned and parallelized. Hadoop MapReduce is not suitable for real-time or interactive processing of data that requires low latency or complex logic. Hadoop MapReduce is also not efficient for processing small or sparse data sets that do not benefit from parallelization or data locality.
