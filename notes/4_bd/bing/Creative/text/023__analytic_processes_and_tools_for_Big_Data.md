### Analytic processes and tools for Big Data

Big data analytics is the use of advanced analytic techniques against very large, diverse big data sets that include structured, semi-structured and unstructured data, from different sources, and in different sizes from terabytes to zettabytes. Big data analytics can help organizations gain new insights and take action to improve operations, customer satisfaction, product development, risk management and other business outcomes .

The analytic processes for big data typically involve the following steps :

- Collection and storage: This step involves acquiring and storing the data from various sources, such as sensors, devices, web, social media, logs, transactional applications, etc. The data can be stored in different formats, such as relational databases, NoSQL databases, data lakes, data warehouses, cloud storage, etc. One of the most popular frameworks for storing and processing large data sets is Apache Hadoop, which is an open-source ecosystem that consists of several components, such as HDFS, MapReduce, YARN, Hive, Pig, Spark, etc .
- Processing: This step involves transforming, integrating, cleaning, and preparing the data for analysis. Data integration software can help to combine data from different sources and formats, and to ensure data quality and consistency. Data preprocessing and scrubbing tools can help to remove noise, outliers, missing values, and errors from the data, and to apply feature engineering, normalization, scaling, and other techniques to make the data suitable for analysis .
- Scrubbing: This step involves applying various analytic techniques to the data to discover patterns, trends, correlations, and insights. Data mining is the process of applying statistical methods, machine learning algorithms, artificial intelligence, and other techniques to extract useful information from the data. Data mining can be used for various purposes, such as classification, clustering, regression, association, anomaly detection, sentiment analysis, etc .
- Analysis: This step involves presenting and communicating the results of the analysis to the stakeholders, and using the insights to make data-informed decisions and actions. Data visualization is the process of creating graphical representations of the data, such as charts, graphs, maps, dashboards, etc., to make the data easier to understand and explore. Data visualization tools can help to create interactive and dynamic visualizations that can be customized and shared with others. Some of the most popular data visualization tools are Tableau, Power BI, QlikView, Excel, etc .

Some of the benefits of big data analytics are :

- It can help to access and analyze a large volume and variety of data from different sources, and to gain new insights that were not possible with traditional data analytics.
- It can help to start small and scale up to handle data from historical records and in real-time, and to use flexible and cost-effective data processing and storage tools, such as open source software and cloud services.
- It can help to discover patterns and insights that can help to improve business efficiency, productivity, innovation, and competitiveness.
- It can help to gauge customer needs and preferences, and to create new products and services that meet their expectations and demands.
- It can help to identify and mitigate potential risks and threats, and to enhance security and compliance.
