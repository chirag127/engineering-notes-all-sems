#### Components of Hadoop

Hadoop is a framework that uses distributed storage and parallel processing to store and manage big data. It consists of three core components: HDFS, MapReduce, and YARN.

- **HDFS** stands for Hadoop Distributed File System. It is the storage unit of Hadoop that can store all kinds of data without prior organization. It distributes the data across multiple nodes in a cluster, providing fault tolerance and high availability. HDFS has two main components: NameNode and DataNode. NameNode is the master node that manages the metadata and the namespace of the file system. DataNode is the slave node that stores the actual data blocks and communicates with the NameNode.
- **MapReduce** is the processing unit of Hadoop that implements a software programming model for processing large sets of data in parallel. It divides the data into smaller chunks and assigns them to different nodes for processing. MapReduce has two main phases: Map and Reduce. Map phase takes the input data and transforms it into key-value pairs. Reduce phase takes the output of the Map phase and aggregates the values based on the keys.
- **YARN** stands for Yet Another Resource Negotiator. It is the resource management unit of Hadoop that schedules and handles resource requests from distributed applications. It allocates resources such as CPU, memory, disk, and network to the applications based on their requirements and availability. YARN has two main components: ResourceManager and NodeManager. ResourceManager is the master node that oversees the resource allocation and the application lifecycle. NodeManager is the slave node that monitors the resource usage and the health of the node.
