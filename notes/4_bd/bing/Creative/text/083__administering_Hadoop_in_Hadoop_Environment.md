#### Administering Hadoop in Hadoop Environment

- Administering Hadoop in Hadoop environment involves setting up, configuring, managing, and monitoring Hadoop clusters and other resources in the Hadoop ecosystem.
- A Hadoop administrator is responsible for performing Hadoop administration jobs such as :
  - Installing and configuring Hadoop software and its components such as HDFS, YARN, MapReduce, Hive, HBase, Spark, etc.
  - Managing and reviewing Hadoop log files and troubleshooting issues.
  - Setting up new Hadoop users and granting them permissions and access rights.
  - Performing backup and recovery of Hadoop data and metadata.
  - Ensuring high availability, security, and performance of Hadoop clusters and applications.
  - Applying patches and updates to Hadoop software and operating system.
  - Scaling up or down Hadoop clusters as per the workload and resource requirements.
  - Collaborating with application teams, vendors, and other stakeholders to ensure smooth operation of Hadoop environment.
- To administer Hadoop in Hadoop environment, a Hadoop administrator needs to have the following skills and knowledge:
  - Proficiency in Linux/Unix operating system and shell scripting.
  - Familiarity with Hadoop architecture, components, and configuration parameters.
  - Ability to use Hadoop commands and tools such as hadoop fs, hadoop jar, hadoop classpath, hadoop distcp, etc.
  - Understanding of Hadoop security mechanisms such as Kerberos, ACLs, encryption, etc.
  - Experience in using Hadoop cluster management tools such as Ambari, Cloudera Manager, etc.
  - Knowledge of Hadoop performance tuning and optimization techniques such as compression, partitioning, caching, etc.
  - Awareness of Hadoop best practices and standards for administration and development.
- To configure the Hadoop environment, a Hadoop administrator needs to modify the following types of configuration files:
  - Read-only default configuration files such as core-default.xml, hdfs-default.xml, yarn-default.xml, and mapred-default.xml that define the default values for Hadoop parameters.
  - Site-specific configuration files such as core-site.xml, hdfs-site.xml, yarn-site.xml, and mapred-site.xml that override the default values for Hadoop parameters according to the site requirements.
  - Environment configuration files such as hadoop-env.sh, mapred-env.sh, and yarn-env.sh that set the environment variables for Hadoop daemons such as JAVA_HOME, HADOOP_CLIENT_OPTS, HADOOP_CLASSPATH, etc.
- To monitor the Hadoop environment, a Hadoop administrator needs to use the following web interfaces:
  - NameNode web UI that shows the status and statistics of the HDFS cluster such as the number of live and dead DataNodes, the total and used capacity, the number of files and blocks, etc.
  - ResourceManager web UI that shows the status and statistics of the YARN cluster such as the number of active and inactive NodeManagers, the available and allocated resources, the running and completed applications, etc.
  - JobHistory web UI that shows the history and details of the MapReduce jobs such as the job ID, name, status, duration, counters, tasks, etc.
  - WebAppProxy web UI that shows the proxy information for the applications running on the YARN cluster such as the application ID, name, user, queue, tracking URL, etc.
