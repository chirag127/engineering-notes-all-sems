#### Hadoop I/O

Hadoop I/O is the set of primitives and tools that Hadoop provides for data input and output operations. Hadoop I/O covers the following topics:

- Data integrity: Hadoop ensures that data is not corrupted or lost during storage or processing by using checksums and replication. Hadoop uses CRC-32 (cyclic redundancy check) to compute a 32-bit checksum for every 512 bytes of data by default. Datanodes verify the checksums of the data they receive from clients or other datanodes, and report any errors to the client or the namenode. Clients also verify the checksums of the data they read from datanodes, and request another replica if the data is corrupt. Hadoop also periodically scans the stored blocks for corruption using a DataBlockScanner thread running on each datanode .
- Compression: Hadoop supports various compression codecs and formats to reduce the storage space and network bandwidth required for data. Compression can be applied at different levels, such as the file level, the block level, or the record level. Hadoop also supports splittable compression formats, such as bzip2, which allow MapReduce to process compressed files in parallel by splitting them into smaller chunks .
- Serialization: Hadoop uses serialization to convert data into a binary format that can be stored or transmitted efficiently. Serialization is used for data exchange between MapReduce tasks, as well as for persisting data to disk or HDFS. Hadoop has its own compact and fast serialization format, Writables, that MapReduce programs use to generate keys and value types. Hadoop also supports other serialization frameworks, such as Avro, Thrift, and Protocol Buffers, which offer more features and flexibility .
- File-based data structures: Hadoop provides several file-based data structures that can store large amounts of data efficiently and support random access and updates. These data structures include SequenceFile, MapFile, SetFile, ArrayFile, and BloomMapFile. SequenceFile is a simple key-value pair file format that supports compression and synchronization. MapFile is a sorted key-value pair file format that supports random lookups. SetFile and ArrayFile are specialized versions of MapFile that store only keys or values, respectively. BloomMapFile is an extension of MapFile that uses a Bloom filter to speed up the lookup of non-existent keys .
