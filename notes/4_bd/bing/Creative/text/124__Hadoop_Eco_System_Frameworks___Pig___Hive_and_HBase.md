## Hadoop Eco System Frameworks, Pig, Hive and HBase

- Hadoop is a framework for distributed storage and processing of large-scale data using a cluster of commodity hardware. Hadoop consists of two main components: Hadoop Distributed File System (HDFS) and MapReduce.
- HDFS is a distributed file system that stores data across multiple nodes in a cluster, providing high availability, fault tolerance, scalability and data locality. HDFS supports both structured and unstructured data, and allows users to access data using various interfaces, such as Java, C, Python, etc.
- MapReduce is a programming model and execution engine for parallel processing of large data sets. MapReduce consists of two phases: map and reduce. In the map phase, data is split into key-value pairs and processed by user-defined functions. In the reduce phase, the output of the map phase is aggregated by key and processed by another user-defined function. MapReduce can run on top of HDFS or other file systems, such as S3, FTP, etc.
- Hadoop also includes several additional modules that provide additional functionality, such as:
  - Hive: a data warehouse infrastructure that provides data summarization and ad-hoc querying using a SQL-like query language called HiveQL. Hive allows users to create tables and partitions on HDFS and perform various operations, such as join, filter, group by, etc. Hive also supports user-defined functions and custom data types. Hive can run on top of HDFS or other file systems, such as S3, FTP, etc.
  - Pig: a high-level data-flow language and execution framework for parallel computation. Pig allows users to write scripts in a language called Pig Latin, which are compiled into MapReduce jobs and executed on a Hadoop cluster. Pig supports various data types, such as tuples, bags, maps, etc. and provides various operators, such as load, store, filter, join, group, etc. Pig also supports user-defined functions and custom data types. Pig can run on top of HDFS or other file systems, such as S3, FTP, etc.
  - HBase: a distributed, scalable, column-oriented database that supports structured data storage for large tables. HBase provides random read and write access to data, as well as scan and range queries. HBase also supports transactions, versioning, compression, and replication. HBase is built on top of HDFS and ZooKeeper, and can be accessed using various interfaces, such as Java, REST, Thrift, etc. HBase can also be integrated with Hive and Pig for data analysis.
