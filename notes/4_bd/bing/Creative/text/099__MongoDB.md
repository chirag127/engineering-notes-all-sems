### MongoDB

- MongoDB is an open source, nonrelational database management system (DBMS) that uses flexible documents instead of tables and rows to process and store various forms of data.
- MongoDB is a distributed database at its core, so high availability, horizontal scaling, and geographic distribution are built in and easy to use.
- MongoDB uses a document data model that maps to how developers think and code and a powerful, unified query API, MongoDB powers faster, more flexible application development.
- MongoDB supports transactional, search, analytics, and mobile use cases while using a common query interface and the data model developers love.
- MongoDB is free to use. Versions released prior to October 16, 2018 are published under the AGPL.
- MongoDB can be deployed in the cloud with MongoDB Atlas, a fully-managed service that offers auto-scaling, serverless instances, full-text search, and data distribution across regions and clouds .
- MongoDB can also be run on self-managed infrastructure, whether on-premises or in the cloud, with MongoDB Community Server or MongoDB Enterprise Advanced.
- MongoDB provides various tools and operators for working with data, such as MongoDB Shell, MongoDB Compass, Atlas CLI, MongoDB Cluster-to-Cluster Sync, MongoDB Connector for BI, and more .
- MongoDB also offers Kubernetes Operators for deploying and managing MongoDB clusters on self-managed infrastructure or in the cloud.
