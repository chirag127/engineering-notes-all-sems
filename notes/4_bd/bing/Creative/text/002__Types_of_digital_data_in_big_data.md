### Types of digital data in big data

Big data refers to high-volume, high-speed, or high-variety information that needs sophisticated processing and analysis. The data alone isn't helpful—it's analysis of it that is key to improving business processes. Businesses use several techniques to analyze big data, such as data mining, which highlights patterns in the data.

Big data can be classified into three main types: structured, unstructured, and semi-structured .

- **Structured data** is data that can be processed, is easily accessible, and can be stored in a fixed format. Examples of structured data include relational databases, spreadsheets, and CSV files. Structured data is usually numeric or categorical, and can be queried using SQL or other languages .
- **Unstructured data** is data that has no predefined format or structure, and is not easily accessible or searchable. Examples of unstructured data include images, audio, video, text, social media posts, and web pages. Unstructured data is usually textual or multimedia, and can be analyzed using natural language processing, computer vision, or machine learning .
- **Semi-structured data** is data that has some level of organization or structure, but not enough to fit into a relational database. Examples of semi-structured data include JSON, XML, HTML, and log files. Semi-structured data is usually a mix of structured and unstructured data, and can be processed using both SQL and NoSQL techniques .

Big data, at its core, involves vast amounts of digital data, but in a wide variety of formats and gathered at mind-boggling speeds. Different types of digital data, including batch or streaming, can be collected and processed for consumption by machines or people, through big data integration.
