### Types of digital data in big data

Big data refers to the large, diverse sets of information that grow at ever-increasing rates. It encompasses the volume of information, the velocity or speed at which it is created and collected, and the variety or scope of the data points being covered. Digital data can be categorized into several types, including:

1. **Structured data**: This type of data is organized into a specific format or schema, such as a database or spreadsheet. It is easy to analyze and can be processed by computers quickly. Examples include customer names, addresses, and purchase histories.

2. **Unstructured data**: This type of data has no specific format or structure and is often text-heavy. It can be difficult to analyze and process, but can contain valuable insights. Examples include social media posts, emails, and documents.

3. **Semi-structured data**: This type of data falls between structured and unstructured data. It has some organizational properties, but not enough to be considered fully structured. Examples include XML and JSON files.

4. **Time-series data**: This type of data is collected over time and is used to track changes and trends. It is often used in finance, economics, and weather forecasting. Examples include stock prices, GDP, and temperature readings.

5. **Geospatial data**: This type of data is used to represent geographical locations and features. It is often used in mapping and navigation. Examples include GPS coordinates, satellite images, and street addresses.

6. **Multimedia data**: This type of data includes images, videos, and audio files. It can be difficult to analyze and process, but can provide valuable insights. Examples include photographs, videos, and music files.

A helpful mnemonic to remember the types of digital data in big data is **SUSTGM** (Structured, Unstructured, Semi-structured, Time-series, Geospatial, Multimedia).
