#### Grunt in Pig

Grunt is a term that can refer to two different things in the context of pigs. It can refer to the sound that pigs make or to a shell command in Apache Pig.

1. **Grunt as a sound made by pigs:** A study into pig behavior has found that grunts reflect their environment and reveal their personalities. Proactive pigs grunt faster than reactive pigs. Male pigs grunt less if their environment is not enriching . The grunts made by pigs vary depending on the pig's personality and can convey important information about the welfare of this highly social species .

2. **Grunt as a shell command in Apache Pig:** The Grunt shell of Apache Pig is mainly used to write Pig Latin scripts. Pig script can be executed with the Grunt shell, which is a native shell provided by Apache Pig to execute Pig queries  . Prior to that, we can invoke any shell commands using `sh` and `fs` . Using the `sh` command, we can invoke any shell commands from the Grunt shell. However, using the `sh` command from the Grunt shell, we cannot execute the commands that are a part of the shell environment (e.g. `cd`) .
