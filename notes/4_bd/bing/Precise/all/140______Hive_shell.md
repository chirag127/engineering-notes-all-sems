#### Hive Shell

1. Hive shell is a command line interface (CLI) provided by Apache Hive.
2. It is used to interact with the Hive system and execute Hive queries and commands.
3. The Hive shell can be accessed by running the `hive` command in the terminal.
4. The Hive shell supports various commands, including Data Definition Language (DDL) commands, Data Manipulation Language (DML) commands, and HiveQL queries.
5. The Hive shell also supports various configuration options and settings that can be used to customize the behavior of the Hive system.
6. The Hive shell provides a convenient and easy-to-use interface for interacting with the Hive system and performing various data analysis tasks.
