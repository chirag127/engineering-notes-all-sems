#### Map Reduce scripts in Hive

- Hive is a platform used to develop SQL type scripts to do MapReduce operations.
- Users can plug in their own custom mappers and reducers in the data stream by using features natively supported in the Hive language  .
- In order to run a custom mapper script - map_script - and a custom reducer script - reduce_script - the user can issue a command which uses the TRANSFORM clause to embed the mapper and the reducer scripts  .
- There are various ways to execute MapReduce operations, including the traditional approach using Java MapReduce program for structured, semi-structured, and unstructured data.
- Hive is designed to enable easy data summarization, ad-hoc querying and analysis of large volumes of data.
