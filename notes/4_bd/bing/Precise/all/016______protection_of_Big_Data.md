#### Protection of Big Data

1. Encryption: Encrypting data at rest and in transit can help protect against unauthorized access and tampering.
2. Access Control: Implementing strict access control measures, such as role-based access control, can help ensure that only authorized users have access to sensitive data.
3. Data Masking: Data masking techniques can be used to obscure sensitive data, such as personally identifiable information, while still allowing it to be used for analysis.
4. Auditing and Monitoring: Regular auditing and monitoring of data access and usage can help detect and prevent unauthorized access or misuse of data.
5. Data Backup and Recovery: Regularly backing up data and having a robust data recovery plan in place can help protect against data loss due to accidental deletion, hardware failure, or other causes.
6. Secure Data Disposal: Properly disposing of data when it is no longer needed can help prevent unauthorized access to sensitive information.

A mnemonic to remember these points is **EADADS** - **E**ncryption, **A**ccess Control, **D**ata Masking, **A**uditing and Monitoring, **D**ata Backup and Recovery, **S**ecure Data Disposal. This mnemonic is easy to remember as it spells out the word "EADADS".
