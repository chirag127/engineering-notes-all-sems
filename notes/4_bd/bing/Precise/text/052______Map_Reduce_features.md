#### Map Reduce features
- **Scalability:** MapReduce can process large amounts of data by dividing the work among multiple nodes in a cluster.
- **Fault tolerance:** MapReduce can handle node failures by reassigning tasks to other nodes in the cluster.
- **Data locality:** MapReduce tries to move computation to the data, rather than moving data to the computation, to reduce network traffic and increase performance.
- **Simplicity:** MapReduce provides a simple programming model that abstracts away many of the complexities of distributed computing.
- **Flexibility:** MapReduce can be used to process data in many different formats and can be used for a wide variety of tasks, including data filtering, sorting, and aggregation.
- **Parallelism:** MapReduce can process data in parallel, taking advantage of the multiple cores and processors in modern computers to speed up processing.
