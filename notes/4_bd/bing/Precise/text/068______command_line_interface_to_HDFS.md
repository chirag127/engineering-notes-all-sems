#### Command Line Interface to HDFS

- HDFS, or Hadoop Distributed File System, is a distributed file system designed to run on commodity hardware.
- The command line interface (CLI) to HDFS is a way to interact with the file system using commands entered in a terminal or command prompt.
- Some common commands for interacting with HDFS include:
  - `hadoop fs -ls`: lists the contents of a directory in HDFS
  - `hadoop fs -mkdir`: creates a new directory in HDFS
  - `hadoop fs -put`: copies a file from the local file system to HDFS
  - `hadoop fs -get`: copies a file from HDFS to the local file system
  - `hadoop fs -rm`: deletes a file or directory in HDFS
- These commands can be used to perform basic file system operations such as creating, deleting, and moving files and directories.
- The CLI can also be used to perform more advanced operations such as setting permissions and replication factors for files and directories.
- To use the CLI, the Hadoop client must be installed and configured on the local machine.
- The CLI provides a powerful and flexible way to interact with HDFS, making it a valuable tool for managing and working with data stored in the file system.
