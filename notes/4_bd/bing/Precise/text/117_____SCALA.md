### SCALA

Scala is a general-purpose, high-level, multi-paradigm programming language. It is a pure object-oriented programming language which also provides support to the functional programming approach. Scala combines object-oriented and functional programming in one concise, high-level language. Scala's static types help avoid bugs in complex applications, and its JVM and JavaScript runtimes let you build high-performance systems with easy access to huge ecosystems of libraries. Scala programs can convert to bytecodes and can run on the JVM (Java Virtual Machine). Designed to be concise, many of Scala's design decisions are aimed to address criticisms of Java.

- Scala is a strong statically typed high-level general-purpose programming language.
- Scala supports both object-oriented programming and functional programming.
- Scala's design decisions are aimed to address criticisms of Java.
- Scala's static types help avoid bugs in complex applications.
- Scala's JVM and JavaScript runtimes let you build high-performance systems with easy access to huge ecosystems of libraries.
- Scala programs can convert to bytecodes and can run on the JVM (Java Virtual Machine).
