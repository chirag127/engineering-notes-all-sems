## Unit 3 - Hadoop Eco System and YARN, No SQL Databases, MongoDB, Spark, Scala

In this unit, we will be discussing the Hadoop ecosystem, YARN, No SQL databases, MongoDB, Spark, and Scala. Here are the key points you should know:

### Hadoop Eco System

- Hadoop is an open-source framework that is used to store and process large datasets.
- The Hadoop ecosystem consists of various tools and technologies that make it easier to work with big data.
- Some of the essential components of the Hadoop ecosystem are HDFS, MapReduce, and YARN.
- Hadoop Distributed File System (HDFS) is used to store large datasets across multiple machines.
- MapReduce is a programming model used to process large datasets in parallel.
- Yet Another Resource Negotiator (YARN) is a cluster management technology that is used to manage resources and allocate tasks to various nodes in the cluster.

### YARN

- YARN is a framework that manages resources in a Hadoop cluster.
- It allows multiple data processing engines such as MapReduce, Spark, and others to run simultaneously on the same cluster.
- YARN provides a central platform to manage resources and allocate them to different applications running on the cluster.
- With YARN, you can easily scale your applications up or down based on your needs.

### No SQL Databases

- No SQL databases are non-relational databases that are designed to handle large amounts of unstructured data.
- They allow for flexible and scalable data models that can adapt to changing requirements.
- Some of the popular No SQL databases include MongoDB, Cassandra, and Couchbase.

### MongoDB

- MongoDB is a document-oriented No SQL database that is designed to store and manage large amounts of unstructured data.
- It is highly scalable and can be used for a variety of applications such as content management, mobile apps, and social networking.
- MongoDB uses a flexible document data model and provides a powerful query language to search and retrieve data.

### Spark

- Spark is an open-source big data processing engine that is designed to run on top of the Hadoop ecosystem.
- It allows you to write applications in various languages such as Java, Scala, and Python.
- Spark provides a high-level API for distributed data processing and can process large amounts of data in memory.
- It is widely used for machine learning, data analytics, and real-time processing.

### Scala

- Scala is a programming language that is designed to run on the Java Virtual Machine (JVM).
- It is a functional programming language that combines object-oriented and functional programming features.
- Scala is widely used for developing big data applications on the Hadoop ecosystem, including Spark.
- It provides a concise syntax and powerful features that make it easier to write complex applications.

In conclusion, the Hadoop ecosystem, YARN, No SQL databases, MongoDB, Spark, and Scala are essential tools and technologies for processing and managing big data. Understanding these technologies will help you develop scalable and efficient applications for processing large datasets.
