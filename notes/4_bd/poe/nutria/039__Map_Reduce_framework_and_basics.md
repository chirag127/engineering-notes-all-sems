
#### Map Reduce Framework and Basics

1. Map Reduce is a programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster.
2. The Map Reduce programming model consists of two main functions: Map and Reduce. 
3. The Map function takes a set of data and converts it into another set of data, where individual elements are broken down into tuples (key/value pairs). 
4. The Reduce function takes the output from a Map function and combines those data tuples into a smaller set of tuples. 
5. Map Reduce is often used for distributed computing on large data sets on clusters of computers. 
6. Map Reduce is used for applications such as sorting, searching, filtering, aggregation, and machine learning algorithms. 
7. The Map Reduce framework is designed to process large data sets in parallel across a cluster of computers. 
8. The framework is designed to be fault-tolerant, so that if one node in the cluster fails, the data processing can continue on the remaining nodes.
