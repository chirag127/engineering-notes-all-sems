
### Hadoop Eco System Frameworks

1. Apache Hadoop: Apache Hadoop is a framework for distributed storage and distributed processing of large datasets. It consists of two components: HDFS (Hadoop Distributed File System) and YARN (Yet Another Resource Negotiator). HDFS is a distributed file system that allows users to store large amounts of data across multiple servers. YARN is a resource management system that allows users to manage resources across multiple nodes.

2. Apache Hive: Apache Hive is a data warehouse system for Hadoop. It provides a SQL-like language called HiveQL to query data stored in HDFS. Hive also provides a set of tools for managing, transforming, and analyzing large datasets stored in HDFS.

3. Apache Pig: Apache Pig is a high-level data-flow language and execution framework for parallel computation. It is used for analyzing large datasets stored in HDFS. Pig provides a set of operators for transforming and combining data stored in HDFS.

4. Apache Spark: Apache Spark is an in-memory distributed computing framework for large-scale data processing. It provides a set of APIs for creating distributed applications. Spark can be used to process large datasets stored in HDFS.

5. Apache Flume: Apache Flume is a distributed, reliable, and available service for efficiently collecting, aggregating, and moving large amounts of streaming data into the Hadoop Distributed File System (HDFS). Flume provides a set of components for collecting, aggregating, and transporting large amounts of streaming data.

6. Apache Sqoop: Apache Sqoop is a tool for transferring data between relational databases and HDFS. It provides a set of command-line tools for importing and exporting data from relational databases to HDFS.
