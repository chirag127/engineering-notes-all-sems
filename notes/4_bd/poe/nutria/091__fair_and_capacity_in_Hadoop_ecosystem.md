
#### Fair and Capacity in Hadoop Ecosystem

1. Hadoop is an open source software framework that enables distributed storage and processing of large datasets across clusters of computers.
2. The Hadoop Ecosystem consists of components that provide various functionalities for data analysis and data storage.
3. The core components of the Hadoop Ecosystem include the Hadoop Common, Hadoop Distributed File System (HDFS), YARN, MapReduce, and Pig.
4. The concept of capacity and fairness in the Hadoop Ecosystem is related to how resources are allocated to different jobs.
5. Capacity Scheduler is responsible for allocating resources to jobs and is used to ensure that all jobs get a fair share of resources.
6. Fair Scheduler is used to ensure that all jobs get a fair share of resources and it is used to set up queues for different types of jobs.
7. The Hadoop Ecosystem also provides tools for monitoring and managing resources in the cluster, such as the Ganglia monitoring system and the Cloudera Manager.
8. Hadoop also provides tools for data analysis, such as Hive, Pig, and Spark.
