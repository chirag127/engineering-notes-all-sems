

#### Spark on YARN

* Apache Spark is an open-source distributed general-purpose cluster-computing framework.
* YARN (Yet Another Resource Negotiator) is a resource-management platform responsible for managing compute resources in clusters and using them for scheduling of users' applications.
* Spark on YARN is a way of running Spark applications on YARN clusters. It allows users to run Spark applications on existing Hadoop clusters.
* Spark on YARN supports both batch and interactive workloads, and provides fault-tolerance, scalability, and high availability.
* Spark on YARN supports different types of applications, including Spark SQL, Spark Streaming, MLlib, GraphX, and Structured Streaming.
* It also supports different types of resource scheduling, including capacity scheduling, fair scheduling, and long-running applications.
* Spark on YARN provides a unified resource management platform for running multiple applications on a single cluster.
* It also provides a unified security model for all applications running on the cluster.
