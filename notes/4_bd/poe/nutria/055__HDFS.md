
### HDFS

HDFS (Hadoop Distributed File System) is a distributed file system that runs on commodity hardware. It is designed to provide high-throughput access to data stored in the Hadoop cluster. HDFS provides fault tolerance and scalability, allowing applications to store and process large amounts of data quickly and reliably.

- HDFS is a distributed file system that runs on commodity hardware.
- HDFS provides high-throughput access to data stored in the Hadoop cluster.
- HDFS is designed to provide fault tolerance and scalability, allowing applications to store and process large amounts of data quickly and reliably.
- HDFS is composed of a NameNode and DataNodes. The NameNode is the master node that manages the file system namespace and maintains the file system tree. The DataNodes are the slave nodes that store the actual data.
- HDFS is optimized for streaming reads and writes, and is not suitable for random reads and writes.
- HDFS is optimized for large files and is not suitable for small files.
- HDFS is not suitable for low latency applications.
