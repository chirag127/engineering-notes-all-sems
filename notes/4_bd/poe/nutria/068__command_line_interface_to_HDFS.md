
#### Command Line Interface to HDFS

- HDFS (Hadoop Distributed File System) is a distributed file system that allows for the storage of large amounts of data across a cluster of computers.
- The command line interface (CLI) is a way to interact with HDFS without the need for a graphical user interface.
- The CLI for HDFS allows users to perform various operations such as creating and deleting files, changing permissions, and listing the contents of a directory.
- The most commonly used commands are put, get, and ls. 
- The put command is used to copy files from the local file system to HDFS.
- The get command is used to copy files from HDFS to the local file system.
- The ls command is used to list the contents of a directory in HDFS.
- Other commands include mkdir, which is used to create a directory, and rm, which is used to delete a file or directory.
