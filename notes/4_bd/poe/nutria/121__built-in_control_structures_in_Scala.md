

#### Built-in Control Structures in Scala

1. Conditionals: Scala provides the `if` and `else` control structures for conditional branching.
2. Loops: Scala provides `while` and `for` loops for iterating over collections of data.
3. Match Expressions: Scala provides a `match` expression which is similar to a `switch` statement in other languages. It allows for concise and powerful pattern matching.
4. Exception Handling: Scala provides exception handling with the `try`, `catch`, and `finally` control structures.
