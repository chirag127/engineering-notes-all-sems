
### SCALA

* Scala is a general-purpose programming language designed to be concise, elegant, and type-safe. 
* It is a statically typed language, which means that the type of a variable must be known at compile time.
* Scala is object-oriented, and the language supports functional programming.
* Scala has a strong static type system and provides a rich set of libraries and frameworks that enable developers to build robust applications.
* Scala has a sophisticated type system that enables developers to express complex domain models in a concise, type-safe manner.
* Scala is designed to be highly extensible and can be used to create a wide variety of applications, from web applications to distributed systems.
* Scala is a platform-independent language, and can be used to create applications for the JVM, the browser, and the server.
