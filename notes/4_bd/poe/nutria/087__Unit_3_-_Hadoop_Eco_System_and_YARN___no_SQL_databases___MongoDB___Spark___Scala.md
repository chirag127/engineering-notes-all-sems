
## Unit 3 - Hadoop Eco System and YARN 

1. Hadoop is an open source distributed computing framework that allows for the storage and processing of large amounts of data. It is made up of several components, including a distributed file system (HDFS), a resource manager (YARN), and a data processing framework (MapReduce).

2. YARN (Yet Another Resource Negotiator) is a resource management platform responsible for managing computing resources in clusters and using them for scheduling of users' applications. It is the core of the Hadoop platform and is responsible for allocating resources to applications running on a Hadoop cluster.

3. NoSQL databases are non-relational databases that are designed to store and access large amounts of data in a distributed environment. Examples of NoSQL databases include MongoDB, Apache Cassandra, and Redis.

4. MongoDB is an open-source document-oriented NoSQL database used for storing and managing large amounts of data. It is designed to scale horizontally, allowing for the storage and retrieval of large amounts of data.

5. Apache Spark is an open-source distributed computing framework used for processing and analyzing large amounts of data. It is designed to be fast and efficient, allowing for the processing of data in real-time.

6. Scala is a programming language designed to be both object-oriented and functional. It is used for developing distributed applications and is well-suited for working with large datasets.
