

## Unit 4 - HDFS (Hadoop Distributed File System) and Hadoop Environment

* HDFS is a distributed file system that is designed to store large amounts of data across multiple servers, and is used by Hadoop applications.
* HDFS is composed of two components: a NameNode and a DataNode. The NameNode is the master node that manages the file system namespace and regulates access to files by clients. The DataNode stores and retrieves data from the file system.
* HDFS is designed to be highly fault-tolerant, meaning that it can continue to operate even if one or more nodes fail.
* Hadoop is an open-source framework for distributed computing that is designed to store and process large amounts of data.
* Hadoop consists of two components: the Hadoop Distributed File System (HDFS) and the Hadoop MapReduce.
* Hadoop MapReduce is a software framework for distributed computing that is used to process large amounts of data in parallel.
* The Hadoop environment is composed of several components, including the Hadoop Distributed File System (HDFS), the Hadoop MapReduce framework, and the Hadoop Common utilities.
