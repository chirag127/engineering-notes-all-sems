

#### Hadoop Distributed File System

- Hadoop Distributed File System (HDFS) is a distributed, scalable, and portable file-system written in Java for the Hadoop framework. 
- It is designed to run on commodity hardware and provide access to applications that require large data sets.
- HDFS stores data in a distributed manner on commodity machines, providing very high aggregate bandwidth across the cluster.
- HDFS is built on top of the native file system of the operating system, and provides scalability and fault tolerance by distributing data and metadata across multiple hosts.
- HDFS is designed to be highly fault-tolerant and is able to detect and handle failures at the application layer.
- HDFS provides high throughput access to application data and is suitable for applications that have large data sets.
