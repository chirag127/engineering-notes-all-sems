
### Types of Digital Data in Big Data

1. Structured Data: This type of data is organized into a specific format and follows a predefined model. Examples of structured data include numbers, dates, and other data types stored in a database.

2. Unstructured Data: This type of data does not follow any predefined model and is not organized in any specific format. Examples of unstructured data include text, images, audio, and video.

3. Semi-structured Data: This type of data is partially structured and partially unstructured. Examples of semi-structured data include XML, JSON, and other formats.

4. Streaming Data: This type of data is generated in real-time and is used to analyze and respond to events as they happen. Examples of streaming data include sensor data, stock market data, and other time-sensitive data.
