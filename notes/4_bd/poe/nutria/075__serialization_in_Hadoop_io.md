
# Serialization in Hadoop IO

1. Serialization is the process of converting an object into a stream of bytes in order to store or transmit it over a network.
2. In Hadoop, serialization is used to convert data into a format that can be stored in HDFS or processed by MapReduce.
3. Hadoop provides two serialization APIs: Writable and Serialization.
4. Writable is a simple interface that allows objects to be serialized and deserialized.
5. Serialization is a more complex API that allows for custom serialization and deserialization.
