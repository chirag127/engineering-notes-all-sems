
#### Running MRv1 in YARN

1. Apache Hadoop MapReduce (MRv1) is a distributed computing framework for processing large data sets.
2. It is designed to run on a cluster of computers, each of which has a copy of the data.
3. MRv1 is based on the MapReduce programming model, which divides a task into two phases: map and reduce.
4. The map phase takes a set of input data and processes it to create a set of intermediate key-value pairs.
5. The reduce phase takes the output of the map phase and combines it into a single output.
6. Apache Hadoop YARN (Yet Another Resource Negotiator) is a resource management platform that allows MRv1 to run on a cluster of computers.
7. YARN provides a distributed computing platform with a resource scheduling layer and a distributed application framework.
8. YARN is responsible for allocating resources to applications, scheduling tasks, and monitoring the progress of applications.
9. YARN provides a distributed computing platform that can be used to run MRv1 applications.
10. To run an MRv1 application on YARN, the user must first submit the application to the ResourceManager.
11. The ResourceManager then allocates resources to the application and schedules tasks.
12. The tasks are then executed on the allocated resources and the output is returned to the user.
