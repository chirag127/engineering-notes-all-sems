
### Hadoop Eco System and YARN

- Hadoop is an open-source software framework used for distributed storage and processing of large datasets on clusters of computers.
- Hadoop Eco System consists of various components such as HDFS, MapReduce, YARN, Hive, Pig, HBase, and Spark.
- YARN (Yet Another Resource Negotiator) is a resource management platform responsible for managing computing resources in clusters and using them for scheduling of users' applications.
- YARN enables multiple data processing engines such as interactive SQL, real-time streaming, data science and batch processing to run and process data stored in HDFS.
- YARN also supports the concept of containerization, which allows it to allocate resources to applications dynamically, thus making it more efficient.
- YARN is responsible for allocating resources to applications and scheduling tasks to be executed on different nodes in the cluster. It also monitors the progress of running applications and provides fault tolerance by restarting failed tasks.
