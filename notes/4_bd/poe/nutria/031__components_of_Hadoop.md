
#### Components of Hadoop
1. Hadoop Common: This is a set of common utilities and libraries that support other Hadoop modules.
2. Hadoop Distributed File System (HDFS): This is the distributed storage system used by Hadoop applications.
3. Hadoop YARN: This is the resource management platform of Hadoop.
4. Hadoop MapReduce: This is the processing framework of Hadoop.
5. Hadoop Ozone: This is the object store of Hadoop.
6. Hadoop Spark: This is the distributed processing engine of Hadoop.
7. Hadoop Hive: This is the data warehouse of Hadoop.
8. Hadoop Pig: This is the data processing language of Hadoop.
9. Hadoop ZooKeeper: This is the coordination service of Hadoop.
