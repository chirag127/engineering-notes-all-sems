
## Hadoop Eco System Frameworks

Hadoop is an open-source software framework used for distributed storage and processing of large datasets. It is composed of four main components:

- **Pig**: A platform for analyzing large datasets using a high-level data flow language. Pig enables developers to write complex data analysis programs without having to write extensive Java or MapReduce code.

- **Hive**: A data warehouse system for managing and querying large datasets stored in Hadoop. Hive provides an SQL-like language for querying and manipulating data.

- **HBase**: A distributed, column-oriented database that runs on top of Hadoop. HBase provides real-time read/write access to large datasets.

- **YARN**: A resource management platform for scheduling applications running on Hadoop clusters. YARN enables applications to run on a Hadoop cluster without requiring manual configuration of resources.
