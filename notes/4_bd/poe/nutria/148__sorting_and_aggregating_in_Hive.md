

#### Sorting and Aggregating in Hive

* Hive provides the `ORDER BY` clause to sort query results.
* The `GROUP BY` clause is used to aggregate data into groups.
* Hive supports various aggregate functions, such as `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `VARIANCE`, and `STDDEV`.
* Aggregate functions can be used in combination with the `GROUP BY` clause.
* Hive also supports user-defined aggregate functions (UDAF).
* The `ROLLUP` and `CUBE` clauses can be used to generate multiple levels of aggregation.
* The `DISTRIBUTE BY` and `SORT BY` clauses can be used to control the order and distribution of the data.
