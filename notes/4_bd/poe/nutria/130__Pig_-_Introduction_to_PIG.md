

#### Pig - Introduction to PIG

1. Pig is a high-level platform for creating programs that run on Apache Hadoop. It is designed to make programming easier for data analysts and data scientists. 
2. Pig is a data flow language, which means that it allows developers to write code that specifies the flow of data from one operation to the next. 
3. Pig provides a simple language called Pig Latin that is used to write data processing programs. Pig Latin programs are translated into MapReduce jobs that run on the Hadoop cluster. 
4. Pig also provides a set of built-in functions that allow developers to manipulate data easily. These functions can be used to perform operations such as filtering, sorting, and joining data sets. 
5. Pig is an open source project and is available for free. It is supported by the Apache Software Foundation and is used by a variety of organizations, including Yahoo!, Facebook, and Twitter.
