
#### Map Reduce scripts in Hive

1. Map Reduce is a programming model used for processing large amounts of data that is divided into smaller parts and then processed in parallel.
2. Hive is an open source data warehouse system for Hadoop that provides an SQL-like interface for querying and managing large amounts of data stored in Hadoop.
3. Hive uses Map Reduce scripts to process queries written in HiveQL, which is a SQL-like language.
4. HiveQL is translated into Map Reduce jobs which are then executed on the Hadoop cluster.
5. Map Reduce scripts in Hive can be used to perform various data processing tasks such as filtering, sorting, grouping, and joining.
6. Hive also provides support for user-defined functions (UDFs) which can be used to extend the capabilities of HiveQL.
7. Hive provides a number of built-in functions which can be used to perform various data processing tasks.
8. Hive also provides support for user-defined aggregate functions (UDAFs) which can be used to perform custom aggregations on data.
9. Hive also provides support for user-defined table functions (UDTFs) which can be used to generate multiple rows from a single row.
