#### YARN
YARN stands for Yet Another Resource Negotiator. It is a cluster management technology developed by Apache to manage data processing in clusters.
 salient points about YARN are:
1. It separates the resource management and job scheduling/monitoring functions.
2. It has a global ResourceManager (RM) and per-application ApplicationMaster (AM).
3. The RM allocates resources to the AMs, while the AMs select resources for containers and monitor their status.
4. It has a hierarchical architecture with pluggable components.
5. It supports both batch processing and interactive queries on the same system.
6. It has high scalability and can manage clusters with thousands of nodes and applications
7. It has features like capacity scheduling, ACLs, and reservation systems to allocate and manage cluster resources efficiently.
