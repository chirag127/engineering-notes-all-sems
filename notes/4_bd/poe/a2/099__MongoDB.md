### MongoDB

1. MongoDB is a cross-platform, document-oriented database.
2. It eschews the traditional table-based relational database structure in favor of JSON-like documents with dynamic schemas (MongoDB calls the format BSON), making the integration of data in certain types of applications easier and faster.
3. Replication and high availability. MongoDB replicates data across multiple servers for high availability, scaling, and durability.
4. Auto-sharding. MongoDB enables automatic partitioning of data across a cluster of machines. This allows you to scale out to large data sets and high throughput.
5. Rich queries. MongoDB supports rich queries, indexing, and geospatial data.
6. Fast in-place updates. MongoDB's update-in-place capability enables atomic updates to documents, avoiding synchronization issues.
7. Language drivers. MongoDB has official drivers for major programming languages and development platforms.
8. Open source. MongoDB is open source and developed by MongoDB, Inc.
