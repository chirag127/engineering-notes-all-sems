### Hadoop

1. Hadoop is an open-source software framework for storing and processing big data in a distributed manner across clusters of computers.
2. The core components of Hadoop are HDFS (Hadoop Distributed File System) and MapReduce.
3. HDFS is a distributed file system that stores data on commodity machines, providing very high aggregate bandwidth across the cluster.
4. MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
5. Hadoop's ecosystem includes many additional components to process data in various ways, including Pig, Hive, HBase, Spark, Oozie, ZooKeeper, etc.
6. Hadoop's key benefits are scalability, cost effectiveness, high fault tolerance, and flexibility. It has become a dominant platform for big data storage and processing.
