#### Hadoop ecosystem components

1. Hadoop Common: Hadoop Common contains libraries and utilities needed by other Hadoop modules. It includes filesystem interface, a Java Archive (Jar) component to manage code dependencies, configuration utilities, logging mechanisms, and other basics.

2. Hadoop Distributed File System (HDFS): HDFS is the primary storage system used by Hadoop. It splits files into large blocks and distributes them across multiple nodes in a cluster. It is designed to handle large data sets and streaming access patterns.

3. MapReduce: MapReduce is a programming model for processing large data sets. It consists of two main tasks, namely Map and Reduce. The Map task portions the input into key/value pairs and the Reduce task aggregates the pairs. Hadoop's implementation of MapReduce can process data in parallel across a Hadoop cluster.

4. Hadoop YARN: YARN is the cluster management technology in Hadoop that lets you use the capabilities of the Hadoop cluster for various distributed computing needs beyond just MapReduce. It decouples resource management and job scheduling/monitoring from the programming framework.

The above points cover the key Hadoop ecosystem components - Hadoop Common, HDFS, MapReduce, and YARN.
