#### Hive services

1. Hive metastore: It is a central repository of metadata for Hive. It stores metadata about tables, partitions, databases, columns, etc. It can be embedded in the Hive server or run as a standalone service.
2. Hive server: It accepts HiveQL statements from clients and translates them into MapReduce, Tez or Spark jobs which are executed on the Hadoop cluster. It also monitors the status of the running jobs.
3. Hive driver: It is the client-side component that compiles the HiveQL statements and sends them to the Hive server.
4. Hive command line interface (CLI): It is a command line interface to interact with Hive. We can run queries and commands to create tables, databases, etc. using the CLI.
5. Web interface (Hue): It provides a web UI to interact with Hive. We can create tables, run queries, analyze data, etc. using the Hue interface without writing any code.
