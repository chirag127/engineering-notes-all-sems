#### Pig - Introduction to PIG

1. Pig is a high-level scripting language for analyzing large data sets.
2. It is developed by Yahoo Research.
3. Pig Latin is the language used to write Pig scripts.
4. Pig translates the Pig Latin scripts into MapReduce jobs which are executed on a Hadoop cluster.
5. Some of the key features of Pig are:

- Ability to handle nested data structures.
- ETL (Extract, Transform, Load) capabilities.
- Abstraction over MapReduce, making the development process easier.
- Optimization opportunities through Pig's execution engine.
- Extensibility to user-defined functions (UDF) for custom operations.

6. Some of the key benefits of using Pig are:

- Increased productivity due to the simplicity of the language.
- Processing large data sets in parallel easily without extensive Java programming.
- Opportunity for optimization using statistics and sampling.
- Ability to integrate with other components of Hadoop ecosystem like Hive.

7. The major applications of Pig include:

- Data mining tasks like clustering, classification, frequent itemset mining, etc.
- Processing raw web logs and transforming them into analytic-ready data sets.
- preprocessing data before loading into a data warehouse or Hive tables.
- Research on large data sets to find unseen patterns or insights.
