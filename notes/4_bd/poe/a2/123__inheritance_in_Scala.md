#### Inheritance in Scala

1. Scala supports single inheritance, meaning a class can inherit from only one superclass.
2. The extends keyword is used to inherit from a superclass. For example:
class Animal
class Dog extends Animal

3. A subclass inherits all non-private members from its superclass. This includes methods, properties, and fields.
4. A subclass can override methods defined in its superclass. To override a method, redefine a method with the same name and signature in the subclass.
5. Abstract classes can be used to define an interface, then have subclasses implement it. A class with unimplemented methods must be marked as abstract.
6. Scala has a type called Any which is a superclass of all other types. This can be used to check if an object is an instance of a certain class or of a subclass of that class.
