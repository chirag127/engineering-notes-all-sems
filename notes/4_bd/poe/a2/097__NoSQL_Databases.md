### NoSQL Databases

1. NoSQL databases are non-relational databases that do not require a fixed schema. They have dynamic schemas for unstructured data.
2. The data in NoSQL databases is stored in many ways - Key-Value store, Document store, Wide-column store and Graph database.
3. Key-Value store - Data is stored in an array of key-value pairs. Examples are DynamoDB, Riak.
4. Document store - Data is stored in documents (instead of rows/columns in a table) encoded in formats like JSON, BSON, XML, etc. Examples are MongoDB, CouchDB.
5. Wide-column store - Stores data in columns instead of rows. Examples are Cassandra, HBase.
6. Graph database - Stores data in graphs with nodes, properties and lines. Examples are Neo4j, Infinite Graph.
7. Some advantages of NoSQL databases are scalability, schema-less design, low cost and high performance. However, they may lack some ACID transaction properties and query capabilities as compared to SQL databases.
8. Use cases of NoSQL databases are - Content management systems, E-commerce applications, Real-time analytics, IoT applications, etc.
