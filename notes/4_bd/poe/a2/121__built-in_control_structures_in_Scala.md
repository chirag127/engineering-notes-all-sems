#### Built-in Control Structures in Scala

1. If-else - Scala has if-else expression that evaluates a condition and executes code based on whether the condition is true or false.
Syntax:
if (condition) {
  // code to execute if condition is true
} else {
  // code to execute if condition is false
}

2. For loop - Scala has for loop to iterate over a range of values or collection elements.
Syntax:
for (i <- 1 to 10) {
  // code to execute in loop
}

for (elem <- list) {
  // code to execute in loop
}

3. While loop - Scala has while loop to execute code repeatedly as long as a given condition is true.
Syntax:
while (condition) {
  // code to execute in loop
}

4. Do-While loop - Scala has do-while loop that executes code once and then repeats the loop while a given condition is true. The condition is checked after first execution.
Syntax:
do {
  // code to execute in loop
} while (condition)
