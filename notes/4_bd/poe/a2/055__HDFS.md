### HDFS

1. HDFS stands for Hadoop Distributed File System. It is the primary storage system used by Hadoop applications.
2. HDFS is designed to store very large data sets reliably, and to stream those data sets at high bandwidth to user applications.
3. HDFS creates multiple replicas of data blocks and distributes them on compute nodes throughout a cluster to enable reliable, extremely rapid computations.
4. The HDFS architecture consists of a NameNode, DataNodes, and Clients. The NameNode manages the file system namespace and regulates access to files. DataNodes store data blocks and serve read/write requests from clients. Clients interact with the NameNode and DataNodes.
5. Files in HDFS are broken into block-sized chunks, typically 128MB. Blocks are stored redundantly on multiple DataNodes for fault tolerance. The NameNode tracks the location of all blocks.
6. HDFS provides high throughput access to application data and is suitable for applications that have large data sets. It is designed to be deployed on low-cost hardware. HDFS is highly fault-tolerant and designed to be deployed on low-cost hardware.
