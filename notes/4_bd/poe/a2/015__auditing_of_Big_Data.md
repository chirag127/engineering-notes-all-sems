#### Auditing of Big Data

1. Integrity of Data: It is important to check if the data is complete, accurate and consistent. The auditor should check for any missing data, incorrect data entries, inconsistencies in data formats or schemas, etc. This ensures data integrity.

2. Compliance: The auditor should check if the data complies with internal data policies and external regulations like GDPR. This includes checking for proper consent before data collection, ensuring personal data is secured, not using data for unfair practices, etc.

3. Data Mining Bias: The auditor should check for any bias in data mining process like imbalanced datasets, correlated attributes, leakage, etc. This ensures that the insights and models derived from the data are fair and unprejudiced.

4. Data Security: The auditor should verify that proper security controls are in place to protect the data. This includes checks like access controls, encryption of data, perimeter security, monitoring, backups, etc. This ensures the data is secured from potential threats and vulnerabilities.

5. Data Quality: The auditor should evaluate the quality of data by checking metrics like accuracy, completeness, consistency, timeliness, validity, etc. Poor data quality can lead to erroneous insights and decisions. The auditor can suggest ways to improve the data quality.

In summary, the key aspects of auditing Big Data include evaluating data integrity, compliance, biases in data mining process, data security mechanisms and data quality. A formal audit helps identify gaps and risks in the Big Data system which can then be addressed to harness the power of data in a reliable and responsible way.
