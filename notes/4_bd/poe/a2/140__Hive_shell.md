#### Hive shell

1. Hive shell is the command line interface to interact with Hive.
2. It is used to run queries, scripts and analyze data.
3. The shell gets activated once we start the Hive service and run the command "hive" in the terminal.
4. The prompt changes to "hive>" once the shell is activated indicating that we can run Hive commands.
5. Some of the frequently used commands in Hive shell are:

- show databases; - to show all databases
- use database_name; - to select a database
- show tables; - to show all tables in a database
- select * from table_name; - to fetch all columns from a table
- create table table_name(col_name data_type, ...); - to create a table

6. We can run multiple Hive queries in a script file with .hql extension and execute the script file in Hive shell using the command "source script_file_name.hql".
7. The results of select queries are displayed in a table format. The mode of result display can be configured to other formats like CSV, TSV, etc. using set command.
8. Hive shell can be used for basic data analysis by running simple aggregations, filtering records, sorting result, etc. on tables.
9. Hive shell is easy to use and a great option for interactive analysis of data in Hive.
