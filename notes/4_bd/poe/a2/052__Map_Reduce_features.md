#### Map Reduce features:

1. Scalability: MapReduce is highly scalable as it splits the large data into independent chunks which are processed parallelly on multiple machines. This makes it capable of processing huge volumes of data on a cluster of machines.

2. Fault Tolerance: MapReduce has in-built fault tolerance capabilities. If any machine fails, the job is re-assigned to another machine. This ensures that the job is completed even in the event of failures.

3. Distributed Processing: MapReduce handles distributed processing of large data sets automatically. It takes care of partitioning the data and scheduling the tasks on a cluster of machines.

4. Simplicity: Although MapReduce runs on a distributed system, its programming model is quite simple. The users just need to write mapper and reducer functions to implement their logic. The complexities of distributed and parallel processing are abstracted from the user.

5. Scalable Data Storage: The MapReduce framework works on top of a scalable distributed file system like HDFS which stores the data reliably even in the event of machine failures. This complements the fault tolerance capabilities of MapReduce.

The above points highlight the key features of MapReduce which make it a powerful framework for processing large volumes of data in a scalable and fault-tolerant manner.
