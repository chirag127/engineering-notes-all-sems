### Big Data features – security, compliance, auditing and protection.

1. Data Security - Big Data systems store large volumes of data which can be sensitive in nature. Hence, strong security measures like authentication, authorization, encryption, etc. need to be in place to prevent unauthorized access and data breaches.

2. Compliance - Depending on the industry and data type, there are various compliances like HIPAA, GDPR, PCI-DSS, etc. that need to be adhered to. Big Data systems should have the necessary controls and measures to ensure compliance to these regulations.

3. Auditing - There needs to be proper auditing trails to track data access, changes, and deletions. This helps with monitoring, identifying anomalies, and taking necessary actions. Comprehensive auditing is important for security and compliance.

4. Data Protection - Data needs to be protected from threats like malware, ransomware, etc. by having controls like firewalls, anomaly detection systems, backup and disaster recovery plans, etc. Data should be resilient and protected against corruption or loss.

The above points summarise some of the key features of Big Data systems related to security, compliance, auditing and data protection. Strict implementation of these controls and measures is necessary to ensure the safe and responsible use of data at scale.
