#### Map Reduce framework and basics

1. Map Reduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
2. It consists of two major tasks -
	1. Map - It divides the input data into smaller chunks which are processed in parallel by multiple nodes in the cluster.
	2. Reduce - It collects and combines the output of the maps and produces the final outcome.
3. The framework takes care of scheduling the jobs, monitoring them and re-executes the failed tasks.
4. The key benefits of Map Reduce are -
	1. Scalability - It can handle huge volumes of data by increasing the number of nodes in the cluster.
	2. Fault Tolerance - It handles failures gracefully by re-executing the failed tasks on other nodes.
	3. Distributed processing - It processes the data in parallel on multiple nodes to achieve fast execution times.
5. The input and output of Map Reduce jobs are stored in a distributed file system like HDFS.
6. Some popular implementations of Map Reduce are Hadoop Map Reduce and Spark.
