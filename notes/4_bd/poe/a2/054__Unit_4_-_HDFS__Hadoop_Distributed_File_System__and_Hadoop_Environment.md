## Unit 4 - HDFS (Hadoop Distributed File System) and Hadoop Environment

1. HDFS - Hadoop Distributed File System
- HDFS is the primary storage system used by Hadoop applications.
- It is highly fault-tolerant and is designed to be deployed on low-cost hardware.
- It provides high throughput access to application data and is suitable for applications that have large data sets.
- Data in HDFS is stored in blocks and replicated for fault tolerance.
- HDFS follows a master/slave architecture. The NameNode is the master that manages the file system namespace and regulates access to files by clients. DataNodes are slaves that store the blocks and serve read/write requests from clients.

2. Hadoop Environment
- Hadoop runs on a cluster of commodity machines.
- The Hadoop environment consists of the following components:
-- HDFS to store data
-- MapReduce to process data
-- YARN to allocate resources and schedule applications
-- Hadoop Common with libraries and utilities
-- Oozie to manage and coordinate workflow
-- Hive and Pig for data analysis using SQL-like and scripting languages respectively.
- Hadoop ecosystem tools like Flume, Sqoop, ZooKeeper, HBase, Mahout, etc extend the capabilities of Hadoop.
