### Mobile IP for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing
Mobile IP is a protocol that enables a mobile device to maintain an IP address while roaming across different networks. It enables seamless communication and access to the internet by allowing the device to switch between networks without losing its IP address.

Mobile IP works by assigning a home agent to the mobile device, which acts as a proxy for the device when it is away from its home network. When the device moves to a new network, it sends a registration request to the home agent, which then forwards the request to a foreign agent on the new network. The foreign agent then assigns a temporary IP address to the device, which is used for communication while the device is on the new network.

IEEE 802.11 is a standard for wireless local area networks (WLANs). It defines the physical and data link layers of the network, including the radio frequency (RF) specifications and data transmission methods.

Bluetooth is a wireless technology standard for exchanging data over short distances. It is designed for low-power, low-bandwidth applications and is commonly used for connecting devices such as smartphones, laptops, and headphones.

Wireless in the subject of mobile computing refers to the use of wireless networks and technologies for accessing and transmitting information and data on mobile devices. This includes the use of cellular networks, Wi-Fi, and Bluetooth, among others.
