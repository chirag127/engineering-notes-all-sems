### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing
WAP (Wireless Application Protocol) is a standard for wireless communication between mobile devices and the internet. It provides a secure and efficient way to access information on the internet from a mobile device.

WAP Architecture:
1. WAP Gateway: Acts as a bridge between the mobile device and the internet.
2. WAP Microbrowser: A small and efficient web browser on the mobile device.
3. WAP Protocol Stack: A set of protocols that handle the communication between the mobile device and the WAP Gateway.

Wireless Networking:
1. Wireless LAN (WLAN): A local area network that uses wireless communication to connect devices.
2. MAC Issues: Media Access Control is responsible for managing the access of devices to the WLAN. It can cause problems with network congestion and security.
3. IEEE 802.11: A set of standards for WLAN communication.
4. Bluetooth: A short-range wireless communication technology for connecting devices.

Wireless in Mobile Computing:
1. Wireless technology allows for seamless communication between mobile devices and the internet.
2. Mobile devices can access the internet, exchange data, and use various applications without the need for cables or wires.
3. Wireless technology is essential for the growth and development of mobile computing.
