### protocol stack for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing
Protocol Stack: A protocol stack refers to the set of protocols used for communication between devices in a network. 

Wireless Networking: Wireless networking is a method of communication that uses radio waves to transmit data between devices. 

Wireless LAN Overview: A wireless local area network (WLAN) is a type of wireless network that allows devices to connect to the internet or a local network without the use of cables. 

MAC Issues: Media access control (MAC) issues refer to problems that can occur when multiple devices try to access the same wireless network simultaneously. 

IEEE 802.11: IEEE 802.11 is a set of standards for wireless local area networks (WLANs). It defines how wireless devices communicate with each other. 

Bluetooth: Bluetooth is a wireless technology that allows devices to communicate with each other over short distances. 

Wireless in Mobile Computing: Wireless technology is used in mobile computing to allow devices to connect to the internet or other networks without the use of cables.
