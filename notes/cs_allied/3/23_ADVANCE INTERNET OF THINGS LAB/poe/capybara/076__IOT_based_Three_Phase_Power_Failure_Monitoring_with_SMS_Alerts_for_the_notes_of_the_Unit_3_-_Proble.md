### IOT based Three Phase Power Failure Monitoring with SMS Alerts

In the field of IoT, one of the most important applications is monitoring and controlling the power supply. Here we will discuss the three-phase power failure monitoring system with SMS alerts using IoT.

#### Introduction

The three-phase power supply system is widely used in industries and households. In case of power failure, it is essential to detect the fault and take necessary action immediately. The conventional method of fault detection is time-consuming and not efficient. But with the help of IoT, the fault detection process can be automated, and the required action can be taken instantly.

#### System Architecture

The system consists of the following components:

- Three-phase power supply
- Current transformers (CTs)
- Microcontroller
- GSM module
- Power supply
- LCD display

#### Working

The CTs are connected to the three-phase power supply to measure the current. The microcontroller receives the current readings from the CTs and processes the data. If the current reading is zero for a specific period, the microcontroller sends a signal to the GSM module to send an SMS alert to the user indicating a power failure.

#### Advantages

- Quick and efficient fault detection
- Real-time monitoring
- SMS alerts to the user
- Automated process

#### Applications

- Industries
- Hospitals
- Data centers
- Residential areas

#### Conclusion

The IoT-based three-phase power failure monitoring system with SMS alerts is a crucial application in the field of IoT. It provides real-time monitoring of the power supply system and quick fault detection. This system can be used in various fields such as industries, hospitals, and residential areas to ensure uninterrupted power supply.
