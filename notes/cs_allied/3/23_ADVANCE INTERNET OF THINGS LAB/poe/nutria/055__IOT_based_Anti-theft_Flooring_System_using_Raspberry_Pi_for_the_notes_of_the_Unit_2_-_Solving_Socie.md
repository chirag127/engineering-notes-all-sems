
### IOT based Anti-theft Flooring System using Raspberry Pi

This system is designed to provide an efficient and secure way to protect valuable items from theft. It uses a Raspberry Pi microcontroller and a variety of sensors to detect the presence of an intruder. The system is designed to be easy to install and use, and is suitable for both indoor and outdoor use.

The system consists of a Raspberry Pi microcontroller, a variety of sensors, a power source, and a wireless communication module. The Raspberry Pi is used to control the sensors, detect the presence of an intruder, and send a signal to the wireless communication module. This module then sends an alert to the user's mobile device or computer.

The sensors used in the system are infrared, motion, and vibration sensors. These sensors are used to detect the presence of an intruder in the area. The infrared sensor is used to detect the presence of a person in the vicinity. The motion sensor is used to detect any motion in the area, while the vibration sensor is used to detect any vibration in the area.
