
### IOT Social Distancing & Monitoring Robot For Queue

1. Problem Analysis: The purpose of this project is to create a robot that can monitor social distancing in a queue and alert people when they are not following the rules.

2. Designing a Solution: The robot will use sensors to detect the distance between people in a queue and alert them when they are too close. It will also have a display that will inform people of the rules of social distancing.

3. Implementation: The robot will be built using a Raspberry Pi, a camera, and an ultrasonic sensor. It will also use a LCD display to inform people of the rules. The robot will be programmed using Python.
