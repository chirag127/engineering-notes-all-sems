
### IOT Covid Patient Health Monitor in Quarantine

1. The goal of the project is to design a health monitoring system for COVID-19 patients in quarantine.

2. The system should be able to monitor the vital signs of the patient such as heart rate, temperature, and blood pressure.

3. The system should also be able to detect any changes in the patient's condition and alert medical personnel.

4. The system should be able to record the patient's data and provide medical personnel with a detailed report.

5. The system should be able to connect to other medical devices and systems, such as an EKG machine or an oxygen monitor.

6. The system should be able to provide real-time data to medical personnel, so they can make informed decisions about the patient's care.

7. The system should be secure and reliable, so that the patient's data is not compromised.

8. The system should be easy to use and understand, so that medical personnel can quickly and accurately assess the patient's condition.
