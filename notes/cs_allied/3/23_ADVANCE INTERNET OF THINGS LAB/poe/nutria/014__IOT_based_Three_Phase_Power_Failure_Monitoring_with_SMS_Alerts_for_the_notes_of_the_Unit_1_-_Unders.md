
### IOT based Three Phase Power Failure Monitoring with SMS Alerts 

1. IOT is a technology that enables the connection of devices to the internet, allowing them to communicate and exchange data with each other. 
2. Three phase power failure monitoring is a system that monitors the power supply of a three phase system and sends an alert to the user in case of a power failure. 
3. SMS alerts are messages sent to a user's mobile device to inform them of a power failure or any other event. 
4. The implementation of IOT in the subject of ADVANCE INTERNET OF THINGS LAB involves the use of sensors, microcontrollers, and other hardware components to build an IOT system. 
5. The system is then connected to the internet and programmed to send SMS alerts in the event of a power failure. 
6. The system can also be used to monitor other events such as temperature, humidity, and pressure. 
7. The system can be used in various applications such as factories, hospitals, and homes.
