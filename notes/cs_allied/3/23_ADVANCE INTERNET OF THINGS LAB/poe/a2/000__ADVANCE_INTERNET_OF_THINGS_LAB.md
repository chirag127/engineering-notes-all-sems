# ADVANCE INTERNET OF THINGS LAB

1. Introduction to IoT Hardware
- Raspberry Pi: Credit card sized computer which can be used to build basic to advanced IoT projects. It has inbuilt wifi and bluetooth connectivity.
- Arduino: Open source hardware platform used to build interactive objects and environments. It is easy to use and can be programmed using Arduino IDE. It has a variety of sensors and shields available to build IoT projects.
- ESP8266: Low cost WiFi enabled microchip which can be programmed to build WiFi based IoT projects. It has limited GPIO pins but is flexible and can be used with Arduino IDE.

2. IoT Protocols and Communication
- MQTT: Lightweight messaging protocol for IoT focused on minimizing network bandwidth and power usage. It facilitates communication between IoT devices and servers.
- CoAP: Web transfer protocol designed for constrained nodes and networks. It is similar to HTTP but more lightweight and suitable for IoT devices.
- XML, JSON: Data serialization formats used to send and receive data in IoT projects. JSON is more popular for its smaller size and easier parsing.
- WebSocket: Enables full-duplex, bidirectional communication between the client and the server. It is useful for real time IoT applications.

3. IoT Cloud Platforms
- AWS IoT: Enables secure, bi-directional communication between Internet-connected devices such as sensors, actuators, embedded systems, or smart appliances and the AWS Cloud.
- Azure IoT Hub: Fully managed service that enables reliable and secure bi-directional communications between millions of IoT devices and a cloud-based solution backend.
- Google Cloud IoT: Allows you to easily and securely connect and manage IoT devices at scale. You can ingest data from globally distributed devices, then store, process, and visualize it in real-time.
