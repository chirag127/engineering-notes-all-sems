### IOT based Manhole Detection and Monitoring System

- IOT sensors are placed inside the manholes to detect various parameters like:
- Presence of harmful gases like hydrogen sulfide, carbon monoxide, etc.
- Water level inside the manhole.
- Tilt angle - To detect if the manhole is tilting which could lead to structural damages.
- Vibration sensors - To detect vibrations in the manhole which could indicate unauthorized access or damages.
- All the sensor data is collected by IoT devices placed inside the manhole which transmit the data over internet to a central server.
- The server analyzes the data and generates alerts if any of the parameters cross the threshold limits.
- The server also records the data over time which could be used to analyze trends and take preventive actions.
- The system helps in monitoring manholes continuously and taking prompt actions in case of any issues to avoid adverse events like manhole explosions or collapses leading to loss of life or property.
- The system utilizes the features of Internet of Things like sensors, connectivity and cloud computing to enable manhole monitoring.
