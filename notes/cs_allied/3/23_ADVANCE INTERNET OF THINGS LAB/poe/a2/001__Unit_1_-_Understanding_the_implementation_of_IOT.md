## Unit 1 - Understanding the implementation of IOT

1. What is IOT?
 - IOT stands for Internet of Things. It refers to the interconnection of everyday physical objects/devices via the internet. These devices are equipped with sensors, software and network connectivity that allows them to send and receive data.

2. How does IOT work?
 - The key components of IOT are:
     - Sensors: Detect and measure various parameters like temperature, motion, pressure etc. and convert the physical parameter into an electric signal.
     - Connectivity: The electric signal is sent to a wireless network for internet connectivity using protocols like Wi-Fi, Bluetooth, cellular etc.
     - Data processing: The data is processed and analyzed locally or in the cloud to derive insights and take actions.
     - User applications: The analyzed data can be viewed and used in various applications to serve human needs.

3. IOT architecture
 - The architecture of IOT systems consists of:
     - Perception layer: The sensors that detect and transmit data.
     - Network layer: The connectivity components that enable data transmission.
     - Processing layer: The components that process and analyze the data.
     - Application layer: The components that make use of the data via user interfaces.

4. Applications of IOT
 - Some key applications of IOT are:
     - Smart homes: Automated control of lights, temperature, appliances etc.
     - Smart cities: Efficient management of transportation, energy, infrastructure etc.
     - Healthcare: Remote monitoring of patients and automated delivery of medicines.
     - Industrial automation: Monitoring and optimization of manufacturing processes.
     - Agriculture: Monitoring crop conditions and automating irrigation.
