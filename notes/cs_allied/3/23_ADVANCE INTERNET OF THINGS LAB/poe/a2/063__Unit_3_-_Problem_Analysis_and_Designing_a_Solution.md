## Unit 3 - Problem Analysis and Designing a Solution

1. Identify the problem
- Clearly define the problem. Ask questions to understand the root cause.
- Do not make assumptions. Look at the problem from multiple perspectives.
- Break down the problem into smaller components if needed for better understanding.

2. Analyze the problem
- List all the factors affecting the problem.
- Study the implications and impact of the problem.
- Check for any constraints and dependencies.

3. Come up with solutions
- Brainstorm and come up with as many solutions as possible. Do not criticize any solution at this stage.
- Narrow down to top few solutions that are practical and feasible.
- Evaluate the pros and cons of each solution.

4. Choose the best solution
- Choose the solution that is simple, cost-effective, reduces risk and solves the root problem.
- Take feedback from others if required.
- If no solution is optimal, combine approaches from multiple solutions.

5. Plan the implementation
- List down the tasks and steps required. Estimate time and resources needed.
- Schedule the tasks and allot responsibilities.
- Prepare for any risks or obstacles and have contingency plans.

6. Implement the solution
- Execute as per the plan.
- Monitor progress and make adjustments if required.
- Test the solution under various conditions. Get user feedback.

7. Review and monitor
- Analyze the results and impact of the implemented solution.
- Check if the solution has solved the problem on a long-term basis.
- Repeat the cycle if the problem recurs or if a new problem is discovered.
