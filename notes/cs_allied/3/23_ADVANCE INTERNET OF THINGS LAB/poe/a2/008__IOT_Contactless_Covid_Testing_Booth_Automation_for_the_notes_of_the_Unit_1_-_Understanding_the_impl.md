### IOT Contactless Covid Testing Booth Automation

1. Sensors - Temperature sensor, Proximity sensor
2. Microcontroller - Arduino/Raspberry Pi
3. Actuators - Servo motor, LED
4. Communication - WiFi/Ethernet

The automation process is as follows:
1. The person approaches the testing booth. The proximity sensor detects the person's presence.
2. The temperature sensor measures the person's body temperature. If the temperature is above the threshold, the LED glows red and the person is denied entry.
3. If the temperature is normal, the servo motor opens the door of the booth. The person enters and undergoes the COVID-19 testing process.
4. Once done, the person exits and the servo motor closes the door.

The automation reduces the need for human intervention and contact, thus ensuring safety. The data from multiple booths can be transmitted to a central server using WiFi/Ethernet for monitoring and analysis.

The implementation of sensors, microcontrollers, actuators and communication technologies demonstrates the use of IOT in building smart automated systems for contactless operations amid the pandemic.
