### IOT based Anti-theft Flooring System using Raspberry Pi

- Theft is a major issue in shops and showrooms. Shoplifting and theft leads to huge losses for shop owners.
- An IOT based anti-theft system can be implemented using sensors and Raspberry Pi to detect and prevent theft.
- Pressure sensors can be installed below the flooring of the shop which detects the pressure applied on the floor. Whenever a person walks, the pressure sensors detect the footprints and the path.
- If the sensors detect the footprints leading to the exit but not returning, it indicates theft. The Raspberry Pi detects this abnormal pattern and triggers an alarm and alerts the owner.
- The Raspberry Pi can also trigger cameras to capture the images of the intruder and share it with the owner. This acts as an evidence for identifying the thief.
- The sensors and Raspberry Pi based IOT system can monitor the shop 24/7 and immediately alert in case of any theft attempts. This can significantly reduce shoplifting and theft.
- The IOT system is cost effective and easy to implement. It does not require any human monitoring and performs automatic theft detection and alerting.
