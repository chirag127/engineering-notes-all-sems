### IOT Contactless Covid Testing Booth Automation

- IOT devices like sensors, microcontrollers, actuators, etc. can be used to automate the covid-19 testing process and make it contactless.
- A testing booth can be set up with an automatic door operated using a servo motor. Once a person enters, the door closes automatically.
- Inside, a temperature sensor can check the body temperature and if it is above the threshold, the person can be denied entry. If the temperature is normal, the person can proceed to the testing stage.
- At the testing stage, an automatic swab collection machine can rotate a sterile swab to collect samples from nose & throat. The samples thus collected can fall into a collection container.
- The samples can then be collected and tested in a lab. The results can be communicated to the person via an LCD display, buzzer or by automatically opening the exit door if the result is negative.
- This automation using IOT ensures minimal contact and faster, more efficient testing. The devices can be configured to sanitize themselves automatically too for safety.
- Using IOT and automation, high volume covid testing can be done while ensuring safety of healthcare workers and individuals. It can reduce the workload and risk of infection for healthcare teams.
