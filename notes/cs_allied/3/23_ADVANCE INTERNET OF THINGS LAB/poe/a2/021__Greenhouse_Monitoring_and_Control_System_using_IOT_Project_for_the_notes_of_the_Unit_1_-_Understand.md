### Greenhouse Monitoring and Control System using IOT Project

#### For the notes of the Unit 1 - Understanding the implementation of IOT in the subject of ADVANCE INTERNET OF THINGS LAB.

1. Introduction to Greenhouse and Monitoring Requirements
- A greenhouse is a structure with walls and roof made chiefly of transparent material, such as glass, in which plants requiring regulated climate conditions are grown.
- Monitoring requirements in a greenhouse include temperature, humidity, light, soil moisture, fertilizer, pH, etc. These parameters need to be monitored continuously to maintain optimal conditions for plant growth.

2. Implementing IOT for Monitoring
- IOT devices such as sensors and microcontrollers can be used to monitor the parameters in a greenhouse.
- Temperature and humidity can be monitored using DHT11/DHT22 sensors.
- Soil moisture can be monitored using soil moisture sensors.
- Light intensity can be monitored using LDRs or light dependent resistors.
- The monitored data can be sent to a cloud platform using ESP8266/ESP32 microcontrollers for analysis and control.

3. Implementing IOT for Control
- The control mechanisms in a greenhouse can also be automated using IOT devices.
- Microcontrollers can be used to control exhaust fans, misting, irrigation, grow lights, etc. based on the monitored parameters to maintain optimal conditions.
- The set points for control can be adjusted as per the requirements of the plants in the greenhouse.

4. Conclusion
- IOT can be effectively used to automate the monitoring and control mechanisms in a greenhouse.
- This leads to more efficient management and optimal conditions for plant growth in a cost effective and scalable manner.
