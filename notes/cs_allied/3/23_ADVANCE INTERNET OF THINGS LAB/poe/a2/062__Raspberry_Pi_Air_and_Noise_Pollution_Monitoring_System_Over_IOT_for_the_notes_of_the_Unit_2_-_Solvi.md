### Raspberry Pi Air and Noise Pollution Monitoring System Over IOT for the notes of the Unit 2 - Solving Societal problems with the help of IOT in the subject of ADVANCE INTERNET OF THINGS LAB.

- Raspberry Pi is used as a microcontroller to monitor air and noise pollution levels.
- Sensors like MQ135, DHT11 and sound sensor are used to sense air pollutants like carbon monoxide, nitrogen dioxide and noise levels respectively.
- The sensed data is displayed on a 16x2 LCD display and also uploaded to a cloud server like ThingSpeak for real-time monitoring.
- Alerts can be generated if the pollution levels cross a threshold limit using IFTTT.
- A web server can be integrated to view the pollution levels using data visualization tools like charts and graphs.
- The system can be placed in sensitive areas like hospitals, schools, industrial areas to continuously monitor and control pollution levels.
- Real-time data can help in taking necessary actions to reduce pollution and creating awareness among people.
