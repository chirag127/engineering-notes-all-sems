### IOT Based Heart Monitoring System Using ECG for the notes of the Unit 1 - Understanding the implementation of IOT in the subject of ADVANCE INTERNET OF THINGS LAB.

- An ECG or Electrocardiogram is a diagnostic tool that measures and records the electrical activity of the heart using electrodes placed on the skin.
- An IOT based ECG system consists of ECG electrodes, ECG circuit, microcontroller and WiFi module.
- The ECG electrodes are placed on the chest to capture the tiny electrical changes that occur during each heartbeat.
- The ECG circuit processes the signal and the microcontroller digitizes the ECG signal and transmits it over WiFi using the WiFi module.
- The ECG data is sent to a server which stores and displays the ECG data for analysis to detect any abnormal heart rhythms.
- This system enables continuous monitoring of heart activity and alerts for any critical conditions from remote locations using internet connectivity.
- The implementation of IOT allows remote health monitoring and access to health data from anywhere using devices connected over internet.
