# IOT Prison Break Monitoring & Alerting System

- The system is designed to prevent and detect prison breaks using Internet of Things (IoT) and radio frequency (RF) technology.
- The system consists of the following components:
  - A microcontroller-based circuit that acts as the central monitoring unit for the prison facility.
  - A RF module that is installed on each inmate and transmits a unique prisoner code wirelessly.
  - A web portal that displays the alert and sound alarm when a prison break is detected.
- The system works as follows:
  - The central monitoring unit scans through all the inmates and tracks their location using the RF signals from the RF modules.
  - The system validates the location of each inmate based on the predefined boundaries of the prison facility.
  - If an inmate is out of the valid location, the system sends an alert signal to the web portal and the prison authorities.
  - The web portal shows the details of the escaped prisoner and sounds an alarm to notify the officers.
  - The system aims to catch the prisoner before he/she runs away from the facility.
- The system has the following advantages:
  - It enhances the security and safety of the prison facility and the society.
  - It reduces the manpower and cost required for monitoring the inmates.
  - It provides real-time and accurate information about the inmates' location and status.
  - It enables quick and effective response to prison breaks.
