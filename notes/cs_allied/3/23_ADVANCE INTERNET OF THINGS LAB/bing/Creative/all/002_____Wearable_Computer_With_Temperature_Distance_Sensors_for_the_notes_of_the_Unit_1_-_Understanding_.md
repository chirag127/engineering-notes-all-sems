# Wearable Computer With Temperature Distance Sensors

- A wearable computer is a device that can be worn on the body and can perform computing tasks such as processing, storing, displaying, and communicating information.
- A wearable computer with temperature distance sensors is a type of wearable computer that can measure the temperature and distance of objects or environments using sensors such as lidar and thermopile.
- A lidar sensor is a device that uses laser pulses to measure the distance and shape of objects by measuring the time of flight and reflection of the light.
- A thermopile sensor is a device that uses an array of thermocouples to measure the temperature difference between two surfaces by generating a voltage proportional to the temperature gradient.
- A wearable computer with temperature distance sensors can have various applications such as:
  - Contactless temperature sensing anywhere, such as for medical, industrial, or environmental purposes.
  - Contactless and accurate distance measurement using lidar, such as for navigation, obstacle detection, or mapping.
  - Smart and easy to carry wearable computer, such as for personal, educational, or entertainment purposes.
- A wearable computer with temperature distance sensors can be developed using a Raspberry Pi controller with a battery, touch screen display, lidar sensor, temperature sensor all together mounted in a compact way over wrist strap .
- The display is used to interact on the computer and show the sensor data.
- The Raspberry Pi controller is used to run the software and communicate with the sensors and the display.
- The battery is used to power the device and make it portable.
- The wrist strap is used to attach the device to the user's arm and make it wearable.
