# Greenhouse Monitoring and Control System using IOT Project

## Unit 1 - Understanding the implementation of IOT in the subject of ADVANCE INTERNET OF THINGS LAB

- A greenhouse is a structure where plants such as flowers and vegetables are grown under controlled environmental conditions.
- A greenhouse monitoring and control system using IOT project is a system that uses sensors, actuators, microcontrollers, and internet connectivity to monitor and control the environmental parameters inside the greenhouse, such as temperature, humidity, light intensity, soil moisture, etc.
- The main objectives of the project are:
  - To improve the productivity and quality of the plants by providing optimal conditions for their growth.
  - To reduce the human intervention and labor cost by automating the monitoring and control processes.
  - To enable remote access and data visualization of the greenhouse conditions using a web or mobile application.
- The main components of the project are:
  - Sensors: These are devices that measure the physical quantities of the environment, such as temperature, humidity, light intensity, soil moisture, etc. and convert them into electrical signals. Some of the commonly used sensors for this project are DHT11 (temperature and humidity sensor), LDR (light dependent resistor), soil moisture sensor, etc.
  - Actuators: These are devices that perform actions based on the commands from the microcontroller, such as turning on or off a fan, a heater, a water pump, a light, etc. Some of the commonly used actuators for this project are relay modules, DC motors, LED lights, etc.
  - Microcontroller: This is a device that processes the data from the sensors and sends commands to the actuators based on the predefined logic or algorithm. It also communicates with the internet using a Wi-Fi module or an Ethernet shield. Some of the commonly used microcontrollers for this project are Arduino Uno, NodeMCU, Raspberry Pi, etc.
  - Internet: This is a network that connects the microcontroller to a cloud platform or a web server, where the data from the sensors can be stored, analyzed, and visualized. It also enables remote access and control of the actuators using a web or mobile application. Some of the commonly used cloud platforms or web servers for this project are ThingSpeak, Firebase, Blynk, etc.
- The main steps involved in the implementation of the project are:
  - Designing the circuit diagram and the hardware layout of the system, using the sensors, actuators, microcontroller, and internet connectivity components.
  - Programming the microcontroller using an IDE (integrated development environment), such as Arduino IDE, Python, etc. to read the data from the sensors, process it, and send commands to the actuators based on the predefined logic or algorithm.
  - Setting up the cloud platform or the web server, using an account, an API key, a channel, etc. to receive, store, analyze, and visualize the data from the microcontroller. Also, creating a web or mobile application, using HTML, CSS, JavaScript, etc. to enable remote access and control of the actuators.
  - Testing and debugging the system, using a multimeter, a serial monitor, a web browser, etc. to check the functionality and performance of the system. Also, making necessary modifications or improvements to the system based on the feedback or results.
