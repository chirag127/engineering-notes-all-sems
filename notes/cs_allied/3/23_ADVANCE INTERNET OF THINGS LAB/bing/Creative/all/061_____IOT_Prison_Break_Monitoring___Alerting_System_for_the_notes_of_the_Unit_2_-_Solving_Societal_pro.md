# IOT Prison Break Monitoring & Alerting System

- The system is designed to prevent prison breaks and alert the authorities in case of any attempt by the inmates.
- The system uses radio frequency (RF) technology to track the location and movement of each inmate using a RF tracker attached to them.
- The system consists of two central monitoring units that scan through all the inmates' codes and compare them with the data fed to them.
- The system also uses a web portal developed using IoTGecko to display the alert and sound an alarm through the internet.
- The system works as follows:
  - Each inmate is assigned a unique code and a RF tracker that transmits the code wirelessly.
  - The central monitoring units receive the codes and check if they match with the valid locations of the inmates.
  - If any inmate is out of his/her validated location, the system sends an alert signal to the web portal and the authorities.
  - The web portal displays the details of the inmate and the location of the breach and sounds an alarm.
  - The authorities can take immediate action to catch the inmate before he/she escapes from the facility.
- The system has the following advantages:
  - It enhances the security and safety of the prison and the society.
  - It reduces the manpower and cost required for manual monitoring and surveillance.
  - It provides real-time and accurate information about the inmates and their activities.
  - It enables quick and effective response to any prison break situation.
