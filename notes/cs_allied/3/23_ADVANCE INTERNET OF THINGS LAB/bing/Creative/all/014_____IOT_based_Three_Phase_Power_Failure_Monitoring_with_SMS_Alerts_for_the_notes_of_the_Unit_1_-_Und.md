# IOT based Three Phase Power Failure Monitoring with SMS Alerts

- This is a system that monitors the power supply of a three-phase system and alerts the authorized person through SMS in case of any failure in one or more phases.
- A three-phase system is a common method of alternating current electric power generation, transmission, and distribution. It consists of three wires or phases (R, Y, and B) that carry equal currents and are offset by 120 degrees from each other.
- A phase loss or single phasing occurs when one of the phases gets disconnected or damaged due to a blown fuse, thermal overload, broken wire, worn contact, or mechanical failure. This can cause serious damage to the equipment and appliances connected to the system, as well as increase the power consumption and the risk of fire.
- The system uses an IOT device (such as Arduino, Raspberry Pi, or ESP8266) that is connected to the three-phase system through voltage sensors or transformers. The device measures the voltage of each phase and displays it on an LCD screen. The device is also connected to a GSM module that can send SMS messages to a predefined phone number.
- The system can be configured to set a threshold voltage for each phase, below which the system will consider it as a failure. The system can also be programmed to send SMS messages with the details of the failure, such as the phase name, the voltage value, and the time of occurrence.
- The system can be accessed and controlled remotely through a web or mobile application that uses the IOT device's IP address or cloud service. The application can show the real-time status of the three-phase system, as well as the history of failures and SMS alerts. The application can also allow the user to change the threshold voltage and the phone number for SMS alerts.
