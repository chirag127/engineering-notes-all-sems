# IOT Weather Station Airship

- An IOT Weather Station Airship is a device that can measure and transmit weather data from the upper atmosphere using a drone or a balloon.
- It can be used for weather forecasting, climate research, disaster management, and other applications that require real-time and accurate weather information.
- An IOT Weather Station Airship typically consists of the following components:
  - A sensor package that measures atmospheric pressure, temperature, humidity, wind speed and direction, and other parameters.
  - A wireless communication module that connects the sensor package to the internet using LoRaWAN, WiFi, cellular, or satellite networks.
  - A power supply that provides energy to the sensor package and the communication module, such as a battery, a solar panel, or a fuel cell.
  - A drone or a balloon that carries the sensor package and the communication module to the desired altitude and location.
- Some examples of IOT Weather Station Airships are:
  - The Live Upper Atmosphere weather station, which uses a helium balloon to reach any height as controlled by the user.
  - The Milesight IoT Weather Station, which uses a LoRaWAN network to transmit weather data from a wireless sensor package.
  - The RPi IoT Weather Station, which uses a Raspberry Pi and a WiFi module to send weather data from a sensor package attached to a drone.
