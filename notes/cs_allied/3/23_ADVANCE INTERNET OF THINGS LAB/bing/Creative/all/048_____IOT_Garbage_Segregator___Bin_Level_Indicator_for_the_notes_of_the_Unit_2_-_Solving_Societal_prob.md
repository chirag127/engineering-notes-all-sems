# IOT Garbage Segregator & Bin Level Indicator

- IOT Garbage Segregator & Bin Level Indicator is a system that uses Internet of Things (IOT) to automate the process of garbage segregation and level monitoring in dustbins.
- The system consists of multiple dustbins that are equipped with sensors, actuators, microcontrollers and wireless modules to detect the type and level of garbage in each bin.
- The system uses image processing, machine learning and ultrasonic sensors to classify the garbage into different categories, such as wet, dry, metal, plastic, paper, etc.
- The system also uses servo motors to open and close the lids of the dustbins according to the type of garbage detected by the camera.
- The system transmits the data of the garbage level and type to an IOT platform, such as IOT gecko, over the internet using Wi-Fi or GSM modules.
- The IOT platform displays the data on a web dashboard or a mobile app, which can be accessed by the authorities or the users to monitor the status of the dustbins and plan the waste collection and disposal accordingly.
- The system aims to solve the societal problems of waste management, such as overflowing dustbins, unhygienic conditions, environmental pollution, inefficient recycling, etc. by using IOT.
