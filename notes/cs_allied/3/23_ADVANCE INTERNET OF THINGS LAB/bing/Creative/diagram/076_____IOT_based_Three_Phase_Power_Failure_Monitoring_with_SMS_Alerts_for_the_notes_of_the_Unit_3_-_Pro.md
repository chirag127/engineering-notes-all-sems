### IOT based Three Phase Power Failure Monitoring with SMS Alerts

- This is an advanced system that monitors power failure in a three-phase system.
- A three-phase system is a common method of alternating current electric power generation, transmission, and distribution. It consists of three wires or phases (R, Y, and B) that carry equal currents and are offset in time by one-third of the period.
- When one phase of a three-phase system gets lost, a phase loss occurs. This is referred to as a ‘single phasing’, this failure generally caused by a blown fuse, thermal overload, broken wire, worn contact or mechanical failure .
- A phase loss can cause serious damage to the equipment and appliances connected to the system, such as motors, compressors, pumps, etc. It can also result in overheating, reduced efficiency, increased power consumption, and fire hazards.
- To prevent such consequences, it is important to detect and alert the phase loss as soon as possible. This is where the IOT based system comes in handy.
- The IOT based system consists of the following components:
  - A voltage sensor module that measures the voltage of each phase and sends the data to the microcontroller.
  - A microcontroller that processes the data and compares it with a threshold value. If the voltage of any phase falls below the threshold, it indicates a phase loss and triggers the GSM module.
  - A GSM module that sends an SMS alert to the authorized person with the details of the phase loss and the location of the system.
  - An LCD display that shows the voltage of each phase and the status of the system.
  - An IOT module that connects the system to the internet and uploads the data to a cloud server for remote monitoring and analysis.
- The system works as follows:
  - The voltage sensor module continuously measures the voltage of each phase and sends the data to the microcontroller via analog pins.
  - The microcontroller converts the analog data to digital data and compares it with a predefined threshold value. If the voltage of any phase is lower than the threshold, it indicates a phase loss and sets a flag for that phase.
  - The microcontroller then sends a command to the GSM module to send an SMS alert to the authorized person with the details of the phase loss and the location of the system. The GSM module uses a SIM card and a network service provider to send the SMS.
  - The microcontroller also sends the data to the LCD display via digital pins. The LCD display shows the voltage of each phase and the status of the system (OK or FAIL).
  - The microcontroller also sends the data to the IOT module via serial communication. The IOT module connects the system to the internet using Wi-Fi or Ethernet and uploads the data to a cloud server for remote monitoring and analysis. The cloud server can be accessed by a web browser or a mobile app.
- The system has the following advantages:
  - It can detect and alert the phase loss in real time and prevent further damage to the equipment and appliances.
  - It can send the SMS alert to the authorized person regardless of the distance and location of the system.
  - It can upload the data to the cloud server for remote monitoring and analysis and provide historical and statistical information on the system performance and power quality.
  - It can be easily installed and configured and does not require any additional wiring or hardware.
  - It can be integrated with other IOT devices and applications for smart grid and smart home solutions.
