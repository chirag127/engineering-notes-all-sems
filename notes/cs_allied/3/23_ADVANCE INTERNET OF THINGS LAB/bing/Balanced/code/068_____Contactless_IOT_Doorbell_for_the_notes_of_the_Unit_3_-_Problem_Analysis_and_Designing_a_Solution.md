### Contactless IOT Doorbell

- A contactless IOT doorbell is a device that uses internet of things (IOT) technology to perform various functions such as ringing the bell, scanning the temperature, recognizing the face, and alerting the owner of the visitor without any physical contact.
- A contactless IOT doorbell can be useful for preventing the spread of infectious diseases such as Covid-19, enhancing the security and convenience of the household, and providing a voice and visual interface for the user.
- A contactless IOT doorbell can be designed using various components such as a microcontroller, a camera, a speaker, a temperature sensor, a buzzer, a button, and a display.
- A contactless IOT doorbell can be connected to a cloud service, a mobile app, or a web portal to store and access the data, send and receive notifications, and control the device remotely.
- A contactless IOT doorbell can be programmed using various software tools such as Arduino IDE, Blynk, Firebase, OpenCV, etc.

#### Problem Analysis

- The problem statement for designing a contactless IOT doorbell is to create a device that can perform the following functions:
  - Ring the bell when a visitor presses the button or approaches the door.
  - Scan the temperature of the visitor using a non-contact infrared sensor and display it on the screen.
  - Recognize the face of the visitor using a camera and a machine learning algorithm and announce the name or status of the visitor using a speaker.
  - Alert the owner of the visitor using a mobile app or a web portal and allow the owner to view the live video feed of the visitor and communicate with them using a speaker and a microphone.
  - Log the data of the visitors such as the date, time, temperature, and face in a cloud database and allow the owner to access it anytime.
  - Provide a voice and visual interface for the user to interact with the device and customize the settings.

#### Designing a Solution

- The solution for designing a contactless IOT doorbell can be divided into the following steps:
  - Hardware Design: This involves selecting and assembling the hardware components such as the microcontroller, the camera, the speaker, the temperature sensor, the buzzer, the button, and the display. The microcontroller can be a NodeMCU, a Raspberry Pi, or an Arduino board. The camera can be a Pi camera, a USB camera, or a webcam. The speaker can be a simple buzzer or a voice module. The temperature sensor can be a MLX90614, a DHT11, or a TMP36. The button can be a simple push button or a touch sensor. The display can be a LCD, a LED, or a OLED screen.
  - Software Design: This involves programming the microcontroller using the software tools such as Arduino IDE, Blynk, Firebase, OpenCV, etc. The program should be able to perform the following tasks:
    - Read the input from the button or the motion sensor and trigger the buzzer and the camera.
    - Read the input from the temperature sensor and display it on the screen.
    - Capture the image from the camera and process it using the machine learning algorithm to recognize the face and announce the name or status of the visitor using the speaker.
    - Send the data of the visitor such as the date, time, temperature, and face to the cloud service using the internet connection and receive the notifications from the owner using the mobile app or the web portal.
    - Provide a voice and visual interface for the user to interact with the device and customize the settings.
  - Testing and Evaluation: This involves testing the functionality and performance of the device and evaluating the results. The testing can be done using various scenarios such as different visitors, different temperatures, different lighting conditions, different distances, etc. The evaluation can be done using various metrics such as accuracy, reliability, usability, security, etc.
