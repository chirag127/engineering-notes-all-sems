### Mountain Climber Health & GPS Tracker

- Mountain Climber Health & GPS Tracker is a project that aims to use the Internet of Things (IoT) to monitor the health and location of mountain climbers in real time.
- IoT is the network of physical objects that can communicate and exchange data with each other or with the cloud through the internet.
- The project consists of the following components:
  - A wearable device that measures the heartbeat, temperature and GPS coordinates of the climber and sends them to a microcontroller.
  - A microcontroller that processes the data and sends it to a web server through a GSM module.
  - A web server that stores and displays the data on a web page and sends SMS alerts to the emergency contacts if the climber's vitals cross the predefined limits.
- The project provides the following advantages:
  - Live heartbeat monitoring and upper and lower limit settings to detect any abnormality or distress in the climber's condition.
  - Live GPS location tracking to locate the climber's position and movement on a map.
  - Live vitals display on a web page that can be accessed by the climber's team or family members.
  - SMS alert system that notifies the emergency contacts in case of limit crossings or loss of signal.
  - Automatic operation that does not require any manual intervention from the climber.
- The project can be improved by using other sensors or devices to measure more parameters such as oxygen saturation, blood pressure, altitude, etc .
- The project can also be enhanced by using a more reliable and efficient communication system such as satellite or radio instead of GSM.
