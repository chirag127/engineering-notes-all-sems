### IOT based Anti-theft Flooring System using Raspberry Pi

Unit 2 - Solving Societal problems with the help of IOT in the subject of ADVANCE INTERNET OF THINGS LAB

1. The IOT based Anti-theft Flooring System is a security system that uses Raspberry Pi and sensors to detect any unauthorized entry into a building or room.
2. The system is installed under the flooring and uses pressure sensors to detect any changes in weight on the floor.
3. When an unauthorized entry is detected, the system sends an alert to the owner or security personnel through a mobile application or other communication methods.
4. The system can be integrated with other security systems such as cameras and alarms to provide a comprehensive security solution.
5. The use of Raspberry Pi and IOT technology allows for remote monitoring and control of the system, making it a convenient and cost-effective solution for building security.
6. The system can be customized to meet the specific needs of the building or room, such as setting different sensitivity levels for different areas.
7. The IOT based Anti-theft Flooring System is a practical solution for preventing theft and unauthorized entry in both residential and commercial buildings.
