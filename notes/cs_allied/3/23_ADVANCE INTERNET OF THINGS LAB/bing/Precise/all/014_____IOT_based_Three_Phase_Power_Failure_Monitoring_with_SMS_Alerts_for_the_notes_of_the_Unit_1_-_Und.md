# IOT based Three Phase Power Failure Monitoring with SMS Alerts

## Unit 1 - Understanding the implementation of IOT

- IOT stands for Internet of Things, which refers to the interconnection of physical devices, vehicles, buildings, and other items embedded with electronics, software, sensors, and network connectivity that enables these objects to collect and exchange data.

- An IOT based Three Phase Power Failure Monitoring system with SMS Alerts is a system that monitors the power supply of a three-phase electrical system and sends SMS alerts to the user in case of a power failure.

- The system uses sensors to detect the power supply status of each phase and sends the data to a microcontroller.

- The microcontroller processes the data and sends an SMS alert to the user's mobile phone if a power failure is detected in any of the phases.

- The system can be implemented using various IOT platforms and technologies such as Arduino, Raspberry Pi, GSM modules, and cloud services.

- The system can be useful in various applications such as industrial plants, data centers, and residential buildings where continuous power supply is critical.

- The system can help in reducing downtime and improving the reliability of the power supply by providing timely alerts to the user in case of a power failure.

- The system can be further enhanced by integrating it with other IOT devices and systems such as smart home automation systems, energy management systems, and remote monitoring systems.

- The implementation of IOT in this system enables real-time monitoring and remote control of the power supply, providing a more efficient and reliable solution for power failure monitoring.
