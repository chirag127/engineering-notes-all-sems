### Greenhouse Monitoring and Control System using IOT Project

A greenhouse monitoring and control system using IOT is a project that aims to solve societal problems with the help of the Internet of Things (IOT). This project falls under Unit 2 - Solving Societal problems with the help of IOT in the subject of ADVANCE INTERNET OF THINGS LAB.

The main objective of this project is to monitor and control the environmental conditions inside a greenhouse to ensure optimal growth of plants. This is achieved by using various sensors to collect data on temperature, humidity, soil moisture, and light intensity. The data is then transmitted to a central control system via the Internet of Things (IOT) where it is analyzed and used to control the greenhouse environment.

Some of the key features of this project include:
- Real-time monitoring of environmental conditions inside the greenhouse.
- Automatic control of temperature, humidity, soil moisture, and light intensity.
- Remote access to the greenhouse monitoring and control system via the Internet.
- Data analysis and visualization to help optimize plant growth.

This project has the potential to greatly improve the efficiency and productivity of greenhouse farming, leading to increased food production and improved food security. It is an excellent example of how the Internet of Things (IOT) can be used to solve societal problems.
