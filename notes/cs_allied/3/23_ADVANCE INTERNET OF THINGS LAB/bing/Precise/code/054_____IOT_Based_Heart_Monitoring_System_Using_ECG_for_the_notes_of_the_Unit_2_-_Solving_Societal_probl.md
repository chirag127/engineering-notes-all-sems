### IOT Based Heart Monitoring System Using ECG

- An IOT based heart monitoring system using ECG is a progressive method for monitoring the heart's electrical activity based on the Internet of Things (IoT).
- This system is widely used in the diagnosis of heart disease.
- The system collects ECG data using a single-lead heart rate monitor sensor and an Arduino microcontroller.
- The collected data is then processed, analyzed, and uploaded to databases and web servers for remote monitoring.
- The system can provide a graphical description of the heart rhythm and measure the heart rate.
- It can also detect various parameters such as heartbeat, PQRST wave, and QRS complex intervals along with respiration rate.
- The system has been tested and validated for reliable remote real-time ECG monitoring.
