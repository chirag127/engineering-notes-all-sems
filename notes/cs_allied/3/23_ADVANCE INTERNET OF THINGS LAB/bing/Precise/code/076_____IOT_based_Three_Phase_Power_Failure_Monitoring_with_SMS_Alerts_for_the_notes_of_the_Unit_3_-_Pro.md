### IOT based Three Phase Power Failure Monitoring with SMS Alerts

Unit 3 - Problem Analysis and Designing a Solution in the subject of ADVANCE INTERNET OF THINGS LAB

- IOT based Three Phase Power Failure Monitoring with SMS Alerts is a system that monitors the power supply of three-phase systems and sends SMS alerts in case of power failure.
- The system uses an IOT device to monitor the power supply and detect any power failure.
- In case of power failure, the system sends an SMS alert to the registered mobile number.
- The system can be used in industries, factories, and other places where three-phase power supply is used.
- The system helps in reducing downtime and increasing productivity by providing timely alerts in case of power failure.
- The system can be easily integrated with existing power supply systems and does not require any major changes to the existing infrastructure.
- The system is easy to use and can be operated by anyone with basic knowledge of IOT devices.
- The system is cost-effective and provides a reliable solution for monitoring power supply in three-phase systems.
