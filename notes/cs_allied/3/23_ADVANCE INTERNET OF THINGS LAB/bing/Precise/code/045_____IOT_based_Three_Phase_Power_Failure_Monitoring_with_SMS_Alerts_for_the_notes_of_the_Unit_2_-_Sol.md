### IOT based Three Phase Power Failure Monitoring with SMS Alerts

IOT based Three Phase Power Failure Monitoring with SMS Alerts is a system that uses the Internet of Things (IoT) technology to monitor the power supply of three-phase systems and send SMS alerts in case of power failure.

The main components of this system are:
1. **Sensors**: These are used to detect the power supply in each of the three phases.
2. **Microcontroller**: This is the brain of the system that processes the data from the sensors and sends the SMS alerts.
3. **GSM Module**: This is used to send the SMS alerts to the user's mobile phone.
4. **Power Supply**: This is used to power the system.

The working of the system is as follows:
1. The sensors continuously monitor the power supply in each of the three phases.
2. If there is a power failure in any of the phases, the sensors send a signal to the microcontroller.
3. The microcontroller processes the data and sends an SMS alert to the user's mobile phone using the GSM module.
4. The user receives the SMS alert and can take appropriate action.

This system is useful in solving societal problems as it helps in preventing damage to electrical equipment due to power failure and also helps in reducing downtime. It is particularly useful in industries and factories where continuous power supply is essential. It can also be used in residential and commercial buildings to monitor the power supply and prevent damage to electrical appliances.
