### Greenhouse Monitoring and Control System using IOT Project

- The Greenhouse Monitoring and Control System using IOT Project is a system that uses sensors to detect the temperature, light, humidity, and soil moisture in the greenhouse.
- A temperature sensor is used to detect the temperature inside the greenhouse. The readings from the sensor are sent to the microcontroller.
- The system monitors various environmental conditions such as humidity, soil moisture, temperature, and presence of fire, etc.
- The system is based on the Internet of Things (IOT) and can be used to monitor and control the greenhouse environment remotely.
- The system can help farmers to obtain high productivity by monitoring and controlling the environmental parameters in the greenhouse.
