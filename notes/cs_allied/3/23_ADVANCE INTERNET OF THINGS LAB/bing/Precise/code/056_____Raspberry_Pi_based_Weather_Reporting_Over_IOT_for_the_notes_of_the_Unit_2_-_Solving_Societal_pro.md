### Raspberry Pi based Weather Reporting Over IOT

Raspberry Pi based Weather Reporting Over IOT is a project that uses the Raspberry Pi, a low-cost, credit-card sized computer, to collect weather data and report it over the Internet of Things (IOT).

1. The Raspberry Pi is equipped with sensors that can measure temperature, humidity, air pressure, and other weather-related data.
2. The data collected by the sensors is processed by the Raspberry Pi and sent to a cloud-based service over the IOT.
3. The cloud-based service stores the data and makes it available to users through a web interface or mobile app.
4. Users can access the weather data in real-time and use it to make informed decisions about their daily activities.
5. The project is an example of how the IOT can be used to solve societal problems by providing real-time, accurate, and accessible weather data to the public.

This project is part of Unit 2 - Solving Societal problems with the help of IOT in the subject of ADVANCE INTERNET OF THINGS LAB. It demonstrates the potential of the IOT to improve our daily lives by providing us with timely and accurate information.
