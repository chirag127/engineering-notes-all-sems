### Greenhouse Monitoring and Control System using IOT Project for the notes of the Unit 2 - Solving Societal problems with the help of IOT in the subject of ADVANCE INTERNET OF THINGS LAB

The Greenhouse Monitoring and Control System using IoT project is a system that is designed to monitor and control the environment within a greenhouse. The system is part of the Internet of Things (IoT) and uses a network of sensors, wireless communication technologies, and data analytics to monitor and control the temperature, humidity, soil moisture, and light levels within the greenhouse.

The Greenhouse Monitoring and Control System typically includes sensors for monitoring various environmental parameters, such as temperature, humidity, soil moisture, and light levels, as well as actuators for controlling the environment within the greenhouse, such as fans, heaters, and irrigation systems. The data collected by the sensors is transmitted to a central monitoring system, where it is analyzed using data analytics techniques to provide insights into the environment within the greenhouse.

The central monitoring system is used to control the environment within the greenhouse, and to provide real-time alerts and insights about the environmental parameters being monitored. This information can be used to optimize the growing conditions within the greenhouse, to improve the health and quality of the plants, and to reduce the use of resources, such as water and energy.
