# CO 5: Examine various SQL queries from MySQL database K4, K5

In this module, we will learn about SQL queries and their application in the MySQL database. SQL queries are used to retrieve data from a database and manipulate it as required. MySQL is an open-source database management system that uses SQL to manage data.

Here are some important points to keep in mind when examining SQL queries from the MySQL database:

- **SELECT**: The SELECT statement is used to retrieve data from one or more tables in the database. It is one of the most commonly used SQL statements.
- **FROM**: The FROM statement specifies the table or tables from which the data is to be retrieved.
- **WHERE**: The WHERE statement is used to filter the data based on a specific condition. For example, we can retrieve all the records where the age is greater than 30.
- **ORDER BY**: The ORDER BY statement is used to sort the data in ascending or descending order based on one or more columns.
- **GROUP BY**: The GROUP BY statement is used to group the data based on one or more columns.
- **JOIN**: The JOIN statement is used to combine two or more tables into a single result set based on a related column.
- **UNION**: The UNION statement is used to combine the results of two or more SELECT statements into a single result set.

In addition to these basic SQL statements, MySQL also supports various other functions and operators that can be used to manipulate data. Some of these include:

- **COUNT**: The COUNT function is used to count the number of rows in a table.
- **SUM**: The SUM function is used to calculate the sum of a column.
- **AVG**: The AVG function is used to calculate the average of a column.
- **MAX**: The MAX function is used to retrieve the maximum value from a column.
- **MIN**: The MIN function is used to retrieve the minimum value from a column.

Overall, understanding SQL queries and their application in the MySQL database is essential for anyone working with data management and analysis. By mastering these concepts, you will be able to retrieve and manipulate data efficiently and effectively.
