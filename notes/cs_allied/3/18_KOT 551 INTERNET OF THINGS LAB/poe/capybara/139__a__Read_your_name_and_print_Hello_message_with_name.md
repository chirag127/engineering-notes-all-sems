#### a) Read your name and print Hello message with name

To read your name and print a hello message with your name, follow these steps:

1. Open a text editor such as Notepad or Sublime Text.
2. Create a new file and save it with a .py extension.
3. Type the following code:

```python
name = input("Enter your name: ")
print("Hello,", name)
```

4. Save the file and exit the text editor.
5. Open a command prompt or terminal.
6. Navigate to the directory where the file is saved.
7. Type `python <filename>.py` where `<filename>` is the name of the file you saved.
8. Press Enter to run the file.
9. The program will prompt you to enter your name. Type your name and press Enter.
10. The program will print a hello message with your name.

Note: The input() function in Python is used to read input from the user. Whatever the user enters is stored in the variable 'name'. The print() function is used to display output to the user. In this case, it displays a hello message along with the name entered by the user.
