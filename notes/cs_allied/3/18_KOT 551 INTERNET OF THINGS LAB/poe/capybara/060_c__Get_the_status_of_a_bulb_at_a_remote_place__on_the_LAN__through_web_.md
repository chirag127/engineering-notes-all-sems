## c) Get the status of a bulb at a remote place (on the LAN) through web.

In a Local Area Network (LAN), it is possible to control and monitor devices remotely using web technology. Here are the steps to get the status of a bulb at a remote place on the LAN through web:

1. Identify the IP address of the bulb: The first step is to determine the IP address of the bulb that needs to be monitored. This can be done by accessing the router's web interface and looking for the connected devices section. 

2. Use a web-enabled bulb: The bulb that is being monitored must be web-enabled, which means it must have a built-in web server that allows it to communicate over the LAN.

3. Access the bulb's web interface: Once the IP address of the bulb is known, it can be accessed through a web browser. Simply enter the IP address into the address bar of the browser and press enter. 

4. Check the status of the bulb: The bulb's web interface should display the current status of the bulb. This could be either on or off. If the bulb is on, it may also display the brightness level.

5. Control the bulb: If the bulb's web interface allows it, the bulb can also be controlled remotely. This can be done by using the controls on the web page to turn the bulb on or off, or to adjust its brightness level.

6. Use an app: Some web-enabled bulbs may also have a dedicated app that can be used to monitor and control them remotely. These apps are typically available for both Android and iOS devices.

In conclusion, getting the status of a bulb at a remote place on the LAN through web is a simple process that involves identifying the IP address of the bulb, accessing its web interface through a web browser, and checking its status. With the right setup, it is also possible to control the bulb remotely using the web.
