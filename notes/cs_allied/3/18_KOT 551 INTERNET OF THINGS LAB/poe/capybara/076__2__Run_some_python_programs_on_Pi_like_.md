## 2. Run some python programs on Pi like:

Here are some steps to help you run Python programs on your Raspberry Pi:

1. Install Python on your Raspberry Pi by typing the following command in the terminal:

   ```
   sudo apt-get install python3
   ```

2. Write or download a Python program that you want to run on your Raspberry Pi. You can use any text editor to write your program.

3. Save your Python program with a .py file extension. For example, if your program is called "myprogram.py", you would save it as "myprogram.py".

4. Open the terminal and navigate to the directory where your Python program is saved.

5. To run your Python program, type the following command in the terminal:

   ```
   python3 myprogram.py
   ```

6. Your Python program should now run on your Raspberry Pi. You should see the output of your program in the terminal.

7. To exit the program, press Ctrl+C in the terminal.
