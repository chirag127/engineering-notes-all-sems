#### a) Read your name and print Hello message with name

To execute this task, follow these steps:

1. Open a text editor or an integrated development environment (IDE) of your choice.
2. Create a new file and save it with a meaningful name and a ".py" extension.
3. In the first line of the file, write the following code snippet:

```python
name = input("Enter your name: ")
print("Hello, " + name + "!")
```

4. Save the file and run it in the terminal or the IDE's console.
5. Enter your name when prompted.
6. The program will read your name and print a "Hello" message with your name in it.

Note: The code uses the `input()` function to read the user's input from the terminal or the console. The input is stored in the `name` variable as a string. The `print()` function then concatenates the "Hello" message with the `name` variable and outputs it to the console.

Make sure to test the program with different names and observe the output. This task is a simple yet essential building block for any beginner programmer as it demonstrates the use of input and output functions in Python.
