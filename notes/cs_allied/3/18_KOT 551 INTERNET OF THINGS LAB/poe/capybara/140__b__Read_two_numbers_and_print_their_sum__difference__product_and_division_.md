#### b) Read two numbers and print their sum, difference, product and division.

When working with programming, it's common to need to perform mathematical operations. In this case, we will focus on reading two numbers and printing their sum, difference, product, and division.

To do this, we need to follow a few steps:

1. Ask the user to input the first number: To read the first number, we can use the `input()` function in Python. This function allows the user to input a value that we can then store in a variable.

2. Ask the user to input the second number: We will use the same method as in step 1 to read the second number.

3. Calculate the sum: To calculate the sum of the two numbers, we simply need to add them together. We can store the result in a variable.

4. Calculate the difference: To calculate the difference of the two numbers, we need to subtract the second number from the first number. We can also store the result in a variable.

5. Calculate the product: To calculate the product of the two numbers, we need to multiply them together. We will store the result in a variable.

6. Calculate the division: To calculate the division of the two numbers, we need to divide the first number by the second number. We can store the result in a variable.

7. Print the results: Finally, we will print the results of our calculations using the `print()` function. We can also format the output using f-strings to make it more readable.

Here's an example code snippet that implements the above steps:

```python
# Step 1
num1 = float(input("Enter the first number: "))

# Step 2
num2 = float(input("Enter the second number: "))

# Step 3
sum = num1 + num2

# Step 4
diff = num1 - num2

# Step 5
prod = num1 * num2

# Step 6
div = num1 / num2

# Step 7
print(f"Sum: {sum}")
print(f"Difference: {diff}")
print(f"Product: {prod}")
print(f"Division: {div}")
```

Once you run this code, you should see the output with the results of the calculations.

Remember to always test your code with different inputs to ensure it works as expected.
