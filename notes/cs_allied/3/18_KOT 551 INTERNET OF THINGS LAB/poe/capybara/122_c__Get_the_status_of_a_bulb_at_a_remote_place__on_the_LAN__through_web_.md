# Get the status of a bulb at a remote place (on the LAN) through web

To get the status of a bulb at a remote place on the LAN, the following steps can be taken:

1. Connect the bulb to the LAN: The bulb should be connected to the same LAN as the device from which the status is to be checked. This can be done by connecting the bulb to the same router or switch as the device.

2. Assign a static IP address to the bulb: To access the bulb from a remote location, it is recommended to assign a static IP address to the bulb. This can be done by accessing the router settings and assigning a static IP address to the bulb's MAC address.

3. Use a web-based interface: Once the bulb is connected to the LAN and assigned a static IP address, a web-based interface can be used to check its status. This can be done by accessing the IP address of the bulb through a web browser.

4. Check the status of the bulb: Once the web-based interface is accessed, the status of the bulb can be checked. This can be done by looking for the status indicator on the interface or by checking the logs of the bulb.

5. Use a mobile app: Some bulbs come with mobile apps that can be used to check their status. These apps can be downloaded from the app store and used to access the bulb from a remote location.

6. Use a third-party service: There are third-party services that can be used to access the status of a bulb at a remote location. These services typically require the installation of a client on the device and provide a web-based interface to access the bulb's status.

By following these steps, it is possible to get the status of a bulb at a remote place on the LAN through web.
