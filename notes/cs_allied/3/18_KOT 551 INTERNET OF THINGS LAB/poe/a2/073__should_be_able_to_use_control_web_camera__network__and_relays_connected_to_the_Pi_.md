### Controlling Devices Connected to Raspberry Pi

1. Web Camera: Raspberry Pi has CSI interface which can be used to connect a web camera. The camera module can be controlled using the picamera library in Python. The camera can be used to capture images and videos which can be streamed on a web server or used for computer vision projects.

2. Network: Raspberry Pi has an inbuilt Ethernet/Wi-Fi adapter which can be controlled using Python libraries like socket programming or requests library. The network interface can be used to send and receive data over the network, access web servers, etc. This can be used for IoT projects to send sensor data over the internet.

3. Relays: Raspberry Pi has GPIO pins which can be used to connect relay modules. The GPIO pins can be controlled using GPIO libraries in Python to switch the relay modules ON and OFF. The relay modules can be used to control high voltage devices since Raspberry Pi can only provide 3.3V/5V on the GPIO pins. This can be used for home automation projects to control lights, motors, pumps, etc.
