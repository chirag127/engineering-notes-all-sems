#### c) Get the status of a bulb at a remote place (on the LAN) through web.

1. Connect the bulb to a microcontroller (like Arduino) which can detect the on/off status of the bulb.
2. The microcontroller is connected to the local network (LAN) via WiFi or Ethernet.
3. A web server is running on the microcontroller which serves a webpage.
4. The web page displays the current status of the bulb - on or off.
5. You can access this web page from any other computer/device on the same LAN to get the status of the bulb.
6. This allows you to get the status of a physically remote bulb over the local network through a web interface.
