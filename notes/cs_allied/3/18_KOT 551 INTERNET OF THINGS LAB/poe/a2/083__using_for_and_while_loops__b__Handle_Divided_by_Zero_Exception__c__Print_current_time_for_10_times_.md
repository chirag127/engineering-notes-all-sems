#### Using For and While Loops

1. For Loop
- For loop is used to iterate over a sequence (list, tuple, string)
- Syntax: for <variable> in <sequence>:
    <statements>
- Example: for i in range(10):
    print(i)  # Prints 0 to 9

2. While Loop
- While loop executes a set of statements as long as a condition is true
- Syntax: while <condition>:
    <statements>
- Example: count = 0
while count < 10:
    count += 1
    print(count)  # Prints 1 to 10

3. Handling Divide By Zero Exception
- An exception occurs when a divide by zero happens
- To handle, use a try/except block
- Example: try:
    result = a/b
except ZeroDivisionError:
    print("Can't divide by zero!")

4. Printing Current Time
- Use the time module to get the current time
- Example: import time
for i in range(10):
    print(time.ctime())  # Prints current time 10 times
