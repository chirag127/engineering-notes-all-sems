# Controlling Devices Connected to Raspberry Pi

1. Web Camera
- Raspberry Pi can be connected to a web camera to capture and stream video
- OpenCV library can be used to control properties of the camera like brightness, contrast, etc. and capture images and videos
- The streaming video can be accessed remotely over the network via a web server running on the Pi

2. Network
- Raspberry Pi can be connected to a network via WiFi or Ethernet
- The Pi can be used to monitor the network, block certain websites or devices, set up a wireless access point, etc.
- Python libraries like scapy can be used to sniff packets, conduct man-in-the-middle attacks, and perform other network actions

3. Relays
- Raspberry Pi has GPIO pins that can be connected to relays to control high voltage devices
- A relay is an electromagnet that can be switched on/off using the GPIO pins to close/open the relay contact and control the device
- Some examples of devices that can be controlled via relays: lamps, motors, water pumps, etc.
- Libraries like RPi.GPIO can be used to easily control the GPIO pins and the connected relays
