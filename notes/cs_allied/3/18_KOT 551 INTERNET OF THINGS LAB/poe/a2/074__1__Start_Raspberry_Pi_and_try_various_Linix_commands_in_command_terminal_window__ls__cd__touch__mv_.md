#### 1. Start Raspberry Pi and try various Linix commands in command terminal window:

1. Connect the Raspberry Pi to power supply and connect to a monitor using HDMI cable.
2. Once the Raspberry Pi boots up, you will see the command terminal.
3. Try the following Linux commands:

- `ls`: Lists all the files and folders in the current directory.
- `cd <folder name>`: Changes the directory to the specified folder name.
- `touch <file name>`: Creates a new file with the given file name.
- `mv <file1> <file2>`: Renames the file1 to file2.
- `rm <file name>`: Deletes the file with the given file name.
- `man <command>`: Shows the manual for the given command.

4. Practice the commands and understand their usage by referring to online tutorials or guides.
