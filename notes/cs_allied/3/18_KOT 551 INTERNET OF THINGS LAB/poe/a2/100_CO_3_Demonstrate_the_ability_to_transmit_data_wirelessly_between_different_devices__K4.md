# CO 3 Demonstrate the ability to transmit data wirelessly between different devices. K4

1. WiFi: WiFi or Wireless Fidelity is a popular wireless networking technology that allows digital devices to wirelessly connect to the internet and network with each other using radio waves. Many modern devices like laptops, smartphones, tablets, etc. support WiFi which allows users to access the internet and share data like files, music, videos, etc. without any cables.

2. Bluetooth: Bluetooth is a wireless technology standard for exchanging data over short distances using radio waves in the frequency range of 2.4 gigahertz from fixed and mobile devices, and building personal area networks. Bluetooth allows devices like headphones, speakers, and other peripherals to connect wirelessly to phones, tablets, and computers enabling data transmission between them. Bluetooth uses a technique called spread-spectrum frequency hopping to prevent interference.

3. NFC: Near Field Communication or NFC is a wireless technology that allows devices in close proximity to establish radio communication with each other. NFC allows devices to share small data packets like URLs, contact info, payment info, etc. when tapped together or brought within a few centimeters of each other. NFC is commonly used for contactless payments, data sharing between devices, and other applications requiring close-range wireless data transmission.

4. Infrared: Infrared or IR is a wireless technology that uses infrared light to transmit data between devices. Many remote controls use infrared to control devices like TVs. While IR can be useful for short-range communication, it requires a line of sight between devices and the range is limited. IR is less commonly used now with the popularity of WiFi and Bluetooth.
