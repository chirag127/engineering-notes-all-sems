# Study Notes on Machine Learning

1. Machine Learning is a field of computer science that gives computers the ability to learn without being explicitly programmed. ML algorithms build a mathematical model based on sample data, known as "training data", in order to make predictions or decisions without being explicitly programmed to perform the task.

2. Machine Learning algorithms are often categorized as supervised learning, unsupervised learning, or reinforcement learning. Supervised learning uses labeled examples to learn a function that maps inputs to outputs. Unsupervised learning finds hidden patterns in unlabeled data. Reinforcement learning learns by interacting with a dynamic environment.

3. Examples of Machine Learning applications include:

- Image Classification: Identifying objects, scenes or people in images.
- Speech Recognition: Transcribing speech to text.
- Recommendation Systems: Recommending products or content to users based on their past behaviors or likes.
- Robotics: Navigating robots and controlling their actuators.
- Medical Diagnosis: Identifying diseases based on medical imaging scans or symptoms.

4. The key steps in Machine Learning are:

1. Gathering data
2. Preprocessing data
3. Choosing an ML algorithm
4. Training and evaluating the model
5. Making predictions on new data

5. Some of the popular Machine Learning libraries in Python are:

- Scikit-Learn: For supervised and unsupervised learning.
- TensorFlow: For deep learning and neural networks.
- Keras: A high-level API for building and training neural networks.
- PyTorch: For deep learning with strong support for deep neural networks.
