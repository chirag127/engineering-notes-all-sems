- Initialize word count to 0 and character count to 0.
- Traverse the string character by character.
- If the current character is a letter or number, increment the character count.
- If the current character is a space, increment the word count.
- Print the final word count and character count.

Some key points to note:

- Spaces are considered as delimiters for words.
- Special characters like !, @, #, $, etc. are also counted as characters.
- The numbers of words and characters in a string can be easily calculated using a loop.
