### 3. Run some python programs on Pi like:

a) Print a name 'n' times, where name and n are read from standard input,

I. Take input for name and n from standard input.
II. Use a for loop to print the name n times.
III. Example:
Name: John
n: 5
Output:
John
John
John
John
John

b) Find the sum of first n natural numbers, where n is read from standard input.

I. Take input for n from standard input.
II. Initialize sum = 0.
III. Use a for loop to calculate the sum:
for i = 1 to n:
    sum = sum + i
IV. Print the sum.
Example:
n: 10
Output:
55

c) Find factorial of a number n, where n is read from standard input.

I. Take input for n from standard input.
II. Initialize factorial = 1.
III. Use a for loop to calculate the factorial:
for i = 2 to n:
    factorial = factorial * i
IV. Print the factorial.
Example:
n: 5
Output:
120
