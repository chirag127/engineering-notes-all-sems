#### CO 5 Examine various SQL queries from MySQL database K4, K5.

1. Select query - Retrieves data from the database table which matches the criteria specified in the WHERE clause.
Syntax: SELECT column1, column2, ... FROM table_name;

2. Insert query - Inserts new rows into a table.
Syntax: INSERT INTO table_name (column1, column2, ...) VALUES (value1, value2, ...);

3. Update query - Modifies the existing records in a table.
Syntax: UPDATE table_name SET column1 = value1, column2 = value2, ... WHERE condition;

4. Delete query - Deletes existing records from a table.
Syntax: DELETE FROM table_name WHERE condition;

5. Create database - Creates a new database.
Syntax: CREATE DATABASE database_name;

6. Create table - Creates a new table in the database.
Syntax: CREATE TABLE table_name (column_name column_type);

7. ALTER query - Alters the schema of an existing table.
Syntax: ALTER TABLE table_name ADD column_name column_definition;

8. DROP query - Deletes an existing database, table, index or view.
Syntax:
DROP DATABASE database_name;
DROP TABLE table_name;
