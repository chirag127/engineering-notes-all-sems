# KOT 553 INTERNET OF THINGS LAB KCS

1. Introduction to Internet of Things (IoT):
- IoT refers to the interconnection of everyday physical objects and appliances via the internet.
- These devices are equipped with sensors, software, and network connectivity that allow them to send and receive data.
- IoT allows objects to be sensed and controlled remotely across existing network infrastructure.

2. IoT Architecture:
- IoT architecture consists of sensors and devices, connectivity, cloud services, and applications.
- Sensors and devices collect data and communicate with the cloud through connectivity mediums.
- The cloud stores and processes data and manages the devices.
- Applications access the data and services provided by the cloud and control the devices.

3. IoT enabling technologies:
- Hardware technologies: Sensors, microcontrollers, network interfaces
- Connectivity technologies: Wi-Fi, Bluetooth, cellular networks, LPWAN
- Software technologies: Protocols, cloud platforms, analytics, security
