# KOT 553 INTERNET OF THINGS LAB KCS

1. Introduction to Internet of Things (IoT):
- IoT refers to the interconnection of everyday physical objects and devices via the internet.
- These devices are equipped with sensors, software, and network connectivity that enable them to send and receive data.
- IoT allows these devices to be sensed and controlled remotely across existing network infrastructure.
- This creates opportunities for more direct integration between the physical world and computer-based systems.

2. IoT Architecture:
- IoT architecture consists of sensors, connectivity, data management and applications.
- Sensors detect events or changes in the physical environment and report the data to be analyzed or logged.
- Connectivity provides the link between sensors and networks using protocols like Wi-Fi, Bluetooth, Zigbee, etc.
- Data management involves processing, storing and analyzing data from sensors in databases or cloud platforms.
- Applications interface with users to display data and enable device control.

3. IoT Applications:
- Some common IoT applications are smart homes, smart cities, industrial IoT, connected vehicles, healthcare, etc.
- In smart homes, devices like lights, thermostats, appliances, etc. can be controlled and monitored remotely.
- In smart cities, applications include smart parking, traffic management, environmental monitoring, etc.
- Industrial IoT enables monitoring and optimization of industrial equipment and processes leading to cost reduction and increased efficiency.
- Connected vehicles facilitate navigation, remote diagnostics and safety applications.
- In healthcare, wearable devices and remote monitoring enable continuous tracking of patient health.
