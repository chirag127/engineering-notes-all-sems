# KOT 552 INTERNET OF THINGS LAB KCS

1. Introduction to Internet of Things (IoT): IoT refers to the interconnection of everyday physical objects and appliances via the internet. These devices are equipped with sensors, software, and network connectivity that enable them to send and receive data. IoT allows these devices to be sensed and controlled remotely across existing network infrastructure. This creates opportunities for more direct integration between the physical world and computer-based systems.

2. IoT Architecture: The architecture of IoT consists of sensors and actuators, IoT gateway, IoT cloud platform, and applications. Sensors and actuators are physical devices that collect data from the environment and trigger actions. The IoT gateway connects the sensors and actuators to the cloud. The IoT cloud platform stores and processes data from the sensors and actuators. Applications access the data and functionalities of the IoT cloud platform.

3. IoT Protocols: IoT protocols establish communication between IoT devices and the gateway/cloud. Some common IoT protocols are MQTT, CoAP, AMQP, XMPP, HTTP, etc. These protocols differ in terms of messaging patterns, working models, bandwidth usage, etc. The choice of IoT protocol depends on the specific use case and requirements.

4. IoT Security: IoT systems face various security threats and vulnerabilities due to the connectivity of devices and data over the internet. Some key IoT security challenges are device authentication, data encryption, privacy concerns, software vulnerabilities, DNS attacks, DDoS attacks, etc. Implementation of secure communication protocols and additional security layers is necessary to ensure the security of IoT systems and data.
