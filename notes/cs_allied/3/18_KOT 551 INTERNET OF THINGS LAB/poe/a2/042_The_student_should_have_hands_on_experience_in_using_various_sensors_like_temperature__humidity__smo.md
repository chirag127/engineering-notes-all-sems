# The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc.

1. Temperature sensors: Students should learn to interface temperature sensors like LM35, DS18B20, etc. and measure ambient temperature and display it on LCD or capture temperature data using microcontrollers/microprocessors. They should understand calibration, accuracy, precision, units, etc. related to temperature sensing.

2. Humidity sensors: Students should learn to interface humidity sensors like DHT11, DHT22, etc. and measure relative humidity in the air. They should understand humidity percentage, dew point, comfort level, etc. They should capture humidity data and display on LCD or log it using controllers.

3. Smoke and gas sensors: Students should learn to interface smoke and gas sensors like MQ-2, MQ-135, etc. and detect smoke, LPG gas, alcohol, etc. They should understand working principles of different types of gas sensors. They should design circuits to detect gas concentrations and sound alarm upon detection.

4. Light sensors: Students should learn to interface light dependent resistors (LDRs) and photodiodes to measure ambient light intensity. They should understand working principles of different light sensors, applications like light monitors, street light controllers, etc. They should design circuits to capture light data and take appropriate actions like switching on lights when dark.

The above points cover the key aspects of gaining hands on experience with different types of sensors like temperature, humidity, smoke, and light sensors. The students should be able to interface the sensors, understand their working principles, capture sensor data, and take appropriate actions based on the sensor outputs. This will enable them to design basic environmental monitoring systems using sensors.
