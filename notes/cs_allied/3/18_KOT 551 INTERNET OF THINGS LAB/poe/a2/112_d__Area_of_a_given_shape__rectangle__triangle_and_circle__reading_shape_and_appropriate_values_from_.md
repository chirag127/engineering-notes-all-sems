# Area of Given Shapes

## Rectangle
- Read length and breadth values from standard input
- Formula: Area = Length x Breadth
- Calculate area using the formula
- Print area

## Triangle
- Read base and height values from standard input
- Formula: Area = (Base x Height) / 2
- Calculate area using the formula
- Print area

## Circle
- Read radius value from standard input
- Formula: Area = πr2
- Calculate area using the formula
- Print area
