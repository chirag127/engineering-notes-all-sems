# CO 5 Examine various SQL queries from MySQL database K4, K5

1. SELECT - retrieves data from the database table which returns this data in the form of a result table.

- SELECT * - retrieves all columns from the table
- SELECT column1, column2 - retrieves only the selected columns from the table
- SELECT ... FROM table_name - selects columns from a specific table

2. UPDATE - updates existing data within a table.

- UPDATE table_name SET column1 = value1, column2 = value2,... WHERE condition
- The WHERE clause specifies which record(s) that should be updated. If you omit the WHERE clause, all records will be updated.

3. DELETE - deletes existing records from a table.

- DELETE FROM table_name WHERE condition
- The WHERE clause specifies which record(s) should be deleted. If you omit the WHERE clause, all records will be deleted.

4. INSERT INTO - inserts new data into a table.

- INSERT INTO table_name (column1, column2,...) VALUES (value1, value2,...)
- The COLUMN list specifies the names of the columns where the column values will be inserted.
