#### c) Get the status of a bulb at a remote place (on the LAN) through web.

1. Use an IoT enabled smart bulb that can be controlled over the network.
2. Connect the bulb to the local area network (LAN) so that it can be accessed over the network.
3. Learn the API or protocol used by the bulb to get its status over the network. Usually, IoT devices use protocols like MQTT, HTTP, CoAP, etc. to transmit data over the network.
4. Write a small web application that can access the bulb over the network using the appropriate protocol and API.
5. The web application will return the status of the bulb (on/off) which can be displayed on a web page.
6. Access the web application over the network (LAN) to get the updated status of the bulb from a remote location.

The above steps can help get the status of a smart bulb at a remote location over the local network through a web application. The key steps are connecting the bulb to the network, learning its network API and writing a web app to access its status over the network which can be viewed from a remote place.
