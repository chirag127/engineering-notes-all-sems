 Here is the formal content on the given Linux commands in points:

#### mkdir:
- Used to create directories or folders.
- Syntax: mkdir <directory_name>
- Options: -p (to create parent directories as needed), -m (to set permissions)

#### rmdir:
- Used to remove empty directories.
- Syntax: rmdir <directory_name>
- Will throw an error if the directory is not empty.

#### tar:
- Used to create/extract archives (tape archive).
- Syntax: tar -cf (create), tar -xf (extract), tar -czf (compress), tar -xzf (extract compressed)
- Common options: -v (verbose), -f (archive name)
- Used to package multiple files into one archive for easier compression or transfer.

#### gzip:
- Used to compress files.
- Syntax: gzip <file_name>
- The compressed file has .gz extension.
- gunzip is used to decompress.
