# Start Raspberry Pi and try various Linux commands in command terminal window:

1. Connect the Raspberry Pi to power supply and monitor.

2. Once booted, open the command terminal window.

3. Try the following Linux commands:

- `ls`: Lists all the files and directories in the current location.
- `cd`: Changes the directory. For example, `cd Documents` changes to Documents directory.
- `touch`: Creates a new file. For example, `touch file.txt` creates a file named file.txt.
- `mv`: Moves a file or renames a file. For example, `mv file.txt file2.txt` renames file.txt to file2.txt.
- `rm`: Removes a file. For example, `rm file2.txt` removes the file2.txt file.
- `man`: Displays the manual for a command. For example, `man ls` displays information on how to use the `ls` command.

4. Practice the commands and observe their outputs to get familiar with the Linux terminal and commands.
