#### a) Read your name and print Hello message with name.

I. Take the input of the user's name and store it in a variable called `name`.
II. Print the greeting message with the user's name:
`Hello <name>, welcome!`
III. Example: If the user enters `John` as the name, the output should be:
`Hello John, welcome!`

This is a simple program to take the user's name as input and print a personalized greeting message welcoming the user. The logic involves taking the input, storing it in a variable and then printing the message with the input variable to customize the message for each user.
