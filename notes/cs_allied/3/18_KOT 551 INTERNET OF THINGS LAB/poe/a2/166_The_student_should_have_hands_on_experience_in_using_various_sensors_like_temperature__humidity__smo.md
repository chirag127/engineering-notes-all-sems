# The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc. and

- Learn how to connect sensors to microcontrollers and read sensor data
- Gain practical experience interfacing different types of sensors like:
** Temperature sensors - to measure ambient temperature
** Humidity sensors - to measure relative humidity
** Smoke detectors - to detect smoke and fire
** Light sensors - to detect ambient light levels
** Other sensors like ultrasonic rangefinders, IR sensors, potentiometers, etc.
- Write code to read data from the sensors and display it on a LCD display
- Learn to calibrate sensors and troubleshoot if there are any issues with sensor data readings
- Use the knowledge of interfacing sensors to build simple real-world projects like a temperature monitor, light intensity meter, etc.
- Hands-on experience working with sensors will help strengthen understanding of sensing concepts and applications.
