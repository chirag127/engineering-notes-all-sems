#### c) Flash an LED at a given on time and off time cycle, where the two times are taken from a file.

1. Take two input times from a file - On time (TON) and Off time (TOFF)
2. Initialize the LED pin as output
3. Start an infinite loop
4. Turn ON the LED for TON seconds
5. Turn OFF the LED for TOFF seconds
6. Repeat steps 4 and 5 continuously to flash the LED at the given on-off cycle
7. The blinking rate can be controlled by changing the On and Off times in the input file

The above solution flashes an LED at a given on-off cycle whose times are taken as input from a file. The on and off times can be modified in the input file to control the blinking rate of the LED.
