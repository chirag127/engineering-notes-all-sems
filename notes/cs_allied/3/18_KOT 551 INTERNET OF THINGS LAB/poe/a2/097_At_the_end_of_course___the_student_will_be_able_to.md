# At the end of course , the student will be able to:

1. Understand the basic concepts of Machine Learning and its applications.
2. Get familiar with different machine learning algorithms like linear regression, logistic regression, decision tree, naive bayes, SVM, KNN, etc.
3. Learn to evaluate and optimize the performance of machine learning algorithms.
4. Gain practical experience in solving machine learning problems using Python's Scikit-learn library.
5. Apply machine learning to real-world problems like prediction, classification, clustering, etc.
6. Understand the future scope and trends in Machine Learning.
