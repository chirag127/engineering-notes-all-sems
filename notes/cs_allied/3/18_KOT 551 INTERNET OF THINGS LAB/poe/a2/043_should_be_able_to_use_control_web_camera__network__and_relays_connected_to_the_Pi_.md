# Controlling Devices Connected to Raspberry Pi

## Web Camera
- Raspberry Pi has CSI interface to connect web cameras
- Can access camera through libraries like OpenCV or SimpleCV
- Can control properties like brightness, contrast, resolution, etc. through code
- Can capture and store images or videos at specified intervals or on events

## Network
- Raspberry Pi has built-in Ethernet and Wi-Fi connectivity
- Can control and configure network settings through code and networking libraries
- Can access Internet and other network resources to send/receive data
- Can be configured as a wireless access point or client

## Relays
- Relays can be connected to Raspberry Pi GPIO pins
- Relays can control high voltage devices since Pi pins are only 5V tolerant
- Code can control the relay on/off states to control connected devices
- Example devices to control: lights, motors, pumps, heaters, etc.
