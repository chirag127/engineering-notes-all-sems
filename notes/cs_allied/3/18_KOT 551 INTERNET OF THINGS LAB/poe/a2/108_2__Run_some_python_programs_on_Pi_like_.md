## 2. Run some python programs on Pi like:

1. Blink an LED:

- Import the GPIO library
- Set the GPIO pin numbering mode to BCM
- Define the pin which the LED is connected to (say pin 18)
- Set the pin as an output pin
- In a loop, turn the LED on for one second and off for one second

2. Read a button press:

- Import the GPIO library
- Set the GPIO pin numbering mode to BCM
- Define the pin which the button is connected to (say pin 12)
- Set the pin as an input pin
- In a loop, check if the input is HIGH (button pressed) or LOW (button not pressed)

3. Measure distance using Ultrasonic sensor:

- Import the time and GPIO libraries
- Set the GPIO pin numbering mode to BCM
- Define the trigger and echo pins of the Ultrasonic sensor
- Set the trigger pin as an output and echo pin as an input
- In a loop, send a pulse on the trigger pin, measure the time taken for the echo and calculate the distance
