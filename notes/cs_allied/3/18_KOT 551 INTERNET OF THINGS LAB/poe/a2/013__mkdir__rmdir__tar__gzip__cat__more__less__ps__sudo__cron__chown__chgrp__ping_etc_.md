#### mkdir, rmdir

- `mkdir` creates a new directory.
- `rmdir` removes an empty directory.

#### tar, gzip

- `tar` is used to create an archive of files and directories.
- `gzip` compresses a file/directory and reduces its size.
- `tar` and `gzip` are often used together to create compressed archives (`.tar.gz` files).

#### cat, more, less

- `cat` displays the contents of a file.
- `more` displays the contents of a file one page at a time.
- `less` is similar to `more` but allows backwards navigation and searching within the file.

#### ps, sudo, cron

- `ps` displays information about running processes.
- `sudo` runs a command with admin/root privileges.
- `cron` is used to schedule tasks/jobs to run at specific times/intervals.

#### chown, chgrp, ping

- `chown` changes the owner of a file/directory.
- `chgrp` changes the group ownership of a file/directory.
- `ping` sends ICMP ECHO_REQUEST packets to a host to check connectivity and round-trip time.
