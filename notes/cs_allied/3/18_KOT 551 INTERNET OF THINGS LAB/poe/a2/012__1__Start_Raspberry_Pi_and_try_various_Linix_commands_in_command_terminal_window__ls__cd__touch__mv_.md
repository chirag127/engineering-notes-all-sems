#### 1. Start Raspberry Pi and try various Linux commands in command terminal window:

1. Connect the Raspberry Pi to a monitor and boot it up.
2. Open the command terminal window.
3. Try the 'ls' command to list the files and folders in the current directory.
4. Use the 'cd' command to change the directory. For example, 'cd Desktop' will change the directory to Desktop.
5. The 'touch' command is used to create a new empty file. For example, 'touch file.txt' will create a file named 'file.txt'.
6. The 'mv' command is used to move a file or folder from one location to another. For example, 'mv file.txt Desktop' will move the file 'file.txt' to the Desktop directory.
7. The 'rm' command is used to remove a file. For example, 'rm file.txt' will remove the file named 'file.txt'.
8. The 'man' command is used to read the manual and get help for a command. For example, 'man ls' will display the manual for the 'ls' command.

The commands can be explored in further details by referring to online documentation. The above steps help get familiar with some basic Linux commands to navigate the directory structure and perform basic file operations.
