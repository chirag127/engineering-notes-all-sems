#### c) Get the status of a bulb at a remote place (on the LAN) through web:

1.  Connect the bulb to a microcontroller (ESP8266/ESP32) which is connected to the LAN.
2.  Write a code for the microcontroller to serve a web page which can toggle the bulb ON and OFF.
3.  Access the web server hosted by the microcontroller from any system on the LAN using the microcontroller's IP address.
4.  The web page served by the microcontroller should have buttons to toggle the bulb ON and OFF.
5.  On clicking the buttons, the microcontroller toggles the bulb's state and updates the web page to show the latest state of the bulb.
6.  This way, one can get the status of the bulb at a remote place on the LAN through the web and also control the bulb.
