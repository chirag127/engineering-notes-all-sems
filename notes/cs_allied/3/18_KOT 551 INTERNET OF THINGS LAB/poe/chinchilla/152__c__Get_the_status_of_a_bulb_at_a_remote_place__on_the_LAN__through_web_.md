#### Introduction

In this topic, we will learn about how to get the status of a bulb at a remote place (on the LAN) through web. This is a useful skill for anyone who wants to control their home lighting remotely or monitor the status of their bulbs from a different location.

#### Steps to Get the Status of a Bulb at a Remote Place (on the LAN) Through Web

1. Connect the bulb to the LAN: Before you can access the bulb remotely, you need to connect it to your local area network (LAN). This can be done by connecting the bulb to your Wi-Fi network using its inbuilt Wi-Fi module or by using a smart hub.

2. Assign a static IP address to the bulb: To access the bulb remotely, you need to assign a static IP address to it. This ensures that the bulb always has the same IP address, which makes it easier to access from a remote location. You can do this by assigning a fixed IP address to the bulb in your router settings.

3. Configure port forwarding: To access the bulb from a remote location, you need to configure port forwarding in your router settings. This allows you to access the bulb from outside your LAN by forwarding the traffic to the bulb's IP address.

4. Access the bulb through a web interface: Once you have completed the above steps, you can access the bulb through a web interface. You can do this by typing the bulb's IP address into a web browser on any device connected to the internet. This will bring up the bulb's web interface, which allows you to control the bulb remotely.

5. Get the status of the bulb: To get the status of the bulb, you need to check its status in the web interface. The web interface will show you whether the bulb is on or off, the brightness level, and other important details about the bulb.

#### Conclusion

Getting the status of a bulb at a remote place (on the LAN) through web is a useful skill that allows you to control your home lighting remotely or monitor the status of your bulbs from a different location. By following the above steps, you can easily access and control your bulbs from anywhere with an internet connection.
