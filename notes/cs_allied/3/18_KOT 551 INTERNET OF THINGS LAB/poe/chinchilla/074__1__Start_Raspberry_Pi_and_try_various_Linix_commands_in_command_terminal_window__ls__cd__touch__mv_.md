#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man.

When using a Raspberry Pi, it is important to have a basic understanding of Linux commands. Here are some common Linux commands to get started:

1. `ls`: This command lists the files and directories in the current working directory. To use it, simply type `ls` in the terminal window.

2. `cd`: This command changes the current working directory. To use it, type `cd` followed by the name of the directory you want to navigate to. For example, `cd Documents` will take you to the Documents directory.

3. `touch`: This command creates a new file in the current working directory. To use it, type `touch` followed by the name of the file you want to create. For example, `touch myfile.txt` will create a new file called `myfile.txt`.

4. `mv`: This command moves a file or directory from one location to another. To use it, type `mv` followed by the name of the file or directory you want to move, followed by the destination directory. For example, `mv myfile.txt Documents/` will move the file `myfile.txt` to the `Documents` directory.

5. `rm`: This command removes a file or directory. To use it, type `rm` followed by the name of the file or directory you want to remove. For example, `rm myfile.txt` will remove the file `myfile.txt`.

6. `man`: This command displays the manual page for a particular command. To use it, type `man` followed by the name of the command you want to learn more about. For example, `man ls` will display the manual page for the `ls` command.

By practicing these commands in the command terminal window, you will become more familiar with the Linux operating system and be better equipped to use your Raspberry Pi effectively. Remember to always be careful when using these commands, as they have the potential to delete or modify important files on your system.
