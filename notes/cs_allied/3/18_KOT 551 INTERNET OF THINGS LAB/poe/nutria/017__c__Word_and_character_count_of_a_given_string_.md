

#### c) Word and Character Count of a Given String

1. A given string is a sequence of characters that form a set of words.

2. To calculate the word count of a given string, one can use the `String.split()` method in JavaScript. This method takes a string and splits it up into an array of words. The length of the array is the word count.

3. To calculate the character count of a given string, one can use the `String.length` property in JavaScript. This property returns the number of characters in the string.

4. It is also possible to calculate both the word and character count of a given string by combining the two methods. The `String.split()` method can be used to split the string into an array of words, and the `String.length` property can be used to calculate the length of each word in the array. The sum of all the lengths is the character count.
