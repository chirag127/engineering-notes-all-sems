
# Unix/Linux Commands

* **mkdir** - This command is used to create a directory.
* **rmdir** - This command is used to remove a directory.
* **tar** - This command is used to create archives from multiple files and directories.
* **gzip** - This command is used to compress files.
* **cat** - This command is used to display the contents of a file.
* **more** - This command is used to display the contents of a file one page at a time.
* **less** - This command is used to display the contents of a file one line at a time.
* **ps** - This command is used to display the processes running on the system.
* **sudo** - This command is used to execute a command as a superuser.
* **cron** - This command is used to schedule tasks to be executed at a specified time.
* **chown** - This command is used to change the owner of a file or directory.
* **chgrp** - This command is used to change the group ownership of a file or directory.
* **ping** - This command is used to test the connectivity between two systems.
