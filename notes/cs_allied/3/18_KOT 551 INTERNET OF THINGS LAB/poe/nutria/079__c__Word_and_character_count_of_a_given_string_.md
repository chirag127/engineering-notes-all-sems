
#### c) Word and Character Count of a Given String

1. Word Count: The word count of a given string is the total number of words contained within the string. To calculate the word count, one must first identify the individual words within the string, and then count the number of words.

2. Character Count: The character count of a given string is the total number of characters contained within the string. To calculate the character count, one must first identify the individual characters within the string, and then count the number of characters. This includes all letters, numbers, punctuation marks, and any other symbols contained within the string.
