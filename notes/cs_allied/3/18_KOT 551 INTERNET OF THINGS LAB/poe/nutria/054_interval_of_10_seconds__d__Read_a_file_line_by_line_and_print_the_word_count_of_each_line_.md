

# Interval of 10 Seconds

1. A file can be read line by line using the `readline()` function.
2. This function will return each line of the file as a string.
3. To count the number of words in each line, the `split()` function can be used.
4. This function will split the string into a list of words.
5. The `len()` function can then be used to count the number of words in the list.
6. The `len()` function will return the number of words in the list, which is the word count of the line.
