
#### b) Switch on a Relay at a Given Time Using Cron
* A relay is an electrical device that is used to control a circuit by opening and closing it.
* When a relay's contact terminals are connected to a load, it can be used to switch on the load at a given time.
* The most common way of scheduling a relay to switch on at a given time is by using cron, which is a time-based job scheduler.
* To use cron, you need to create a cron job that specifies the time when the relay should be switched on.
* The cron job should include the command to switch on the relay and the time when the command should be executed.
* The command to switch on the relay depends on the type of relay being used.
* After creating the cron job, it needs to be activated so that it can start executing the command at the specified time.
