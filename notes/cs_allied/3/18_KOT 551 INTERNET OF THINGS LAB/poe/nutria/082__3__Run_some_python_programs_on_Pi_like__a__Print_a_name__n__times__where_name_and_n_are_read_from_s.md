
#### 3. Run some Python programs on Pi
1. To print a name 'n' times, where name and n are read from standard input, you should use a for loop. The for loop should iterate over a range of numbers from 0 to n. Inside the for loop, you should use the `print` function to output the name.

2. To read the name and n from standard input, you should use the `input` function. This function takes a string as an argument, which should be a prompt for the user to enter the name and n. The `input` function returns a string which can be converted to an integer using the `int` function.
