

## Word and Character Count of a Given String

1. A string is a sequence of characters, such as letters, numbers, and symbols.
2. To count the number of words in a string, we can use the `split()` method. This method takes a string as an argument and returns an array of words from the string.
3. To count the number of characters in a string, we can use the `length` property. This property returns the number of characters in the string.
4. We can also use the `trim()` method to remove leading and trailing whitespace from the string before counting its words and characters.
5. We can also use the `replace()` method to remove all whitespace from the string before counting its words and characters.
