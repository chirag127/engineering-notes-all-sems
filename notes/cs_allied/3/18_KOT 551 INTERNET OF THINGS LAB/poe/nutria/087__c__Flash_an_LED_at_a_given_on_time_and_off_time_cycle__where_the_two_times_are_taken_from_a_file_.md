

#### c) Flash an LED at a Given On Time and Off Time Cycle, Where the Two Times are Taken from a File

1. Connect the LED to a power source and a microcontroller.
2. Create a text file containing the on and off times for the LED.
3. Write the code in the microcontroller to read the text file and store the on and off times in a variable.
4. Create a loop in the code to turn the LED on and off according to the times stored in the variable.
5. Test the code and adjust as necessary.
