
### 3. Run some python programs on Pi like: a) Print a name 'n' times, where name and n are read from standard input
* To print a name 'n' times, the user must first define two variables: a string variable to store the name, and an integer variable to store the number of times the name should be printed.
* The user must then use a `for` loop to iterate over the range of numbers from 0 up to the value of the integer variable. 
* For each iteration, the program should print the string variable.
* After the loop is completed, the program should terminate.
