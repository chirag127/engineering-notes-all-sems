

# b) Read two numbers and print their sum, difference, product and division

1. To read two numbers, we can use the `input()` function in Python. 
2. The `input()` function will return the user's input as a string. 
3. To convert the string to a number, we can use the `int()` or `float()` function, depending on the type of number we need. 
4. To print the sum, difference, product and division of the two numbers, we can use the `+`, `-`, `*` and `/` operators, respectively. 
5. For example, if we have two numbers `a` and `b`, we can print their sum, difference, product and division as follows: 

```
sum = a + b
difference = a - b
product = a * b
division = a / b
```
