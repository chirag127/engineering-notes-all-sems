
#### c) Flash an LED at a Given On Time and Off Time Cycle, Where the Two Times are Taken from a File 

1. Connect the LED to the GPIO pins of the Raspberry Pi
2. Create a file containing the on time and off time cycle
3. Read the file to get the on time and off time cycle
4. Use the `time.sleep()` function in Python to set the on time and off time
5. Use the `GPIO.output()` function to turn the LED on and off according to the on time and off time cycle
