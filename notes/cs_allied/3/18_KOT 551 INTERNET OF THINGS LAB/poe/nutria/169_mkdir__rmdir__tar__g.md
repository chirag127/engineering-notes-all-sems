
# Mkdir, Rmdir, Tar, G

1. **Mkdir**: Mkdir stands for Make Directory and is a command used in Unix-based operating systems to create a new directory (or folder). It takes one argument, the name of the directory to be created.

2. **Rmdir**: Rmdir stands for Remove Directory and is a command used in Unix-based operating systems to delete an existing directory (or folder). It takes one argument, the name of the directory to be deleted.

3. **Tar**: Tar stands for Tape Archive and is a command used in Unix-based operating systems to create an archive of multiple files or directories. It takes one argument, the name of the archive to be created.

4. **G**: G is a command used in Unix-based operating systems to execute a program. It takes one argument, the name of the program to be executed.
