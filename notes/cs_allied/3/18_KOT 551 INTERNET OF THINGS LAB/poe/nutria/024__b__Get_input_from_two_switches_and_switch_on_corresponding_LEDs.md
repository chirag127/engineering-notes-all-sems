

#### b) Get input from two switches and switch on corresponding LEDs

1. Connect two switches to the input pins of a microcontroller.
2. Configure the input pins of the microcontroller to be in the input mode.
3. Create a program to read the input from the two switches.
4. Based on the input from the two switches, switch on the corresponding LEDs.
5. The program should be able to detect the state of the switches and switch on the corresponding LEDs accordingly.
6. Once the program is written, upload it to the microcontroller.
7. Test the program to ensure that the LEDs switch on correctly based on the input from the two switches.
