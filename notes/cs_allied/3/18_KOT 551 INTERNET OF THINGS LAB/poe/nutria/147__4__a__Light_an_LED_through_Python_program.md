

#### 4. a) Light an LED through Python program

1. Connect the LED to the board. Connect the long leg to the positive rail and the short leg to the negative rail. 
2. Download and install Python 3.7 or higher.
3. Install the GPIO Zero library.
4. Create a new Python program and import the GPIO Zero library.
5. Create an LED object, specifying the pin number the LED is connected to.
6. Turn the LED on and off using the LED object's on() and off() methods.
7. Run the program. The LED should turn on and off.
