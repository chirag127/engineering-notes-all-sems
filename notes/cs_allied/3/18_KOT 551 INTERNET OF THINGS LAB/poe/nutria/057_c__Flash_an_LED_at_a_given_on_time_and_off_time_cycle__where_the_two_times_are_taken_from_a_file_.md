

# c) Flash an LED at a given on time and off time cycle, where the two times are taken from a file

1. Connect the LED to the appropriate pins on the microcontroller.
2. Create a file with two columns: one for the on time, and one for the off time.
3. Read the on and off times from the file.
4. Use a loop to flash the LED at the given on and off times.
5. Make sure to include the appropriate delays to ensure accurate timing.
6. When the end of the file is reached, loop back to the beginning of the file.
