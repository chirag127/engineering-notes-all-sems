
#### 4. a) Light an LED through Python program

1. To light an LED using Python, you will need the following components:
   - An LED
   - A breadboard
   - A resistor
   - Jumper wires
   - A Raspberry Pi
2. Connect the LED to the breadboard. Connect one end of the resistor to the negative rail on the breadboard and the other end to the LED's negative terminal.
3. Connect one end of the jumper wire to the positive rail on the breadboard and the other end to the LED's positive terminal.
4. Connect the Raspberry Pi to the breadboard.
5. Write a Python program to control the LED. Use the GPIO library to set the GPIO pin connected to the LED as an output and set it to HIGH to turn on the LED, or LOW to turn it off.
