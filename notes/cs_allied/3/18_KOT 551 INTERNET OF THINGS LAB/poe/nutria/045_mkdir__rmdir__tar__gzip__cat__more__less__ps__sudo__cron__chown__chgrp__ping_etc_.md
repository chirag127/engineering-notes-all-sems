

# Linux Commands

1. **mkdir**: Creates a new directory.
2. **rmdir**: Removes an existing directory.
3. **tar**: Creates an archive of multiple files or directories.
4. **gzip**: Compresses a file or directory.
5. **cat**: Displays the contents of a file.
6. **more**: Displays the contents of a file one page at a time.
7. **less**: Displays the contents of a file one line at a time.
8. **ps**: Displays information about running processes.
9. **sudo**: Executes a command as another user.
10. **cron**: Schedules commands to be executed at specific times.
11. **chown**: Changes the owner of a file or directory.
12. **chgrp**: Changes the group of a file or directory.
13. **ping**: Tests the connection between two computers.
