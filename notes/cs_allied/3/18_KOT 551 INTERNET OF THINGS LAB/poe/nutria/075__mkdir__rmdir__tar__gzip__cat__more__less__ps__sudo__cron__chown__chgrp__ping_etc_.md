
#### `mkdir`

This command is used to create a new directory. It takes one argument, which is the name of the directory to create.

#### `rmdir`

This command is used to delete an empty directory. It takes one argument, which is the name of the directory to delete.

#### `tar`

This command is used to create an archive file from a group of files. It takes one argument, which is the name of the archive file to create.

#### `gzip`

This command is used to compress a file. It takes one argument, which is the name of the file to compress.

#### `cat`

This command is used to display the contents of a file. It takes one argument, which is the name of the file to display.

#### `more`

This command is used to display the contents of a file one page at a time. It takes one argument, which is the name of the file to display.

#### `less`

This command is used to display the contents of a file one line at a time. It takes one argument, which is the name of the file to display.

#### `ps`

This command is used to display information about running processes. It takes no arguments.

#### `sudo`

This command is used to execute a command with root privileges. It takes one argument, which is the command to execute.

#### `cron`

This command is used to schedule a command to run at a specific time. It takes one argument, which is the command to execute.

#### `chown`

This command is used to change the ownership of a file. It takes two arguments, which are the name of the file and the name of the new owner.

#### `chgrp`

This command is used to change the group ownership of a file. It takes two arguments, which are the name of the file and the name of the new group.

#### `ping`

This command is used to check if a host is reachable over the network. It takes one argument, which is the IP address or hostname of the host to ping.
