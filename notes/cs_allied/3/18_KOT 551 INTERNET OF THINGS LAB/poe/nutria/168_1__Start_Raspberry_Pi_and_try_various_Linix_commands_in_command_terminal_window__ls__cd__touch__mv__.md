
# 1. Start Raspberry Pi and try various Linux commands in command terminal window: 

* `ls`: This command is used to list the contents of the current working directory. 
* `cd`: This command is used to change the current working directory.
* `touch`: This command is used to create an empty file.
* `mv`: This command is used to move or rename a file or directory.
* `rm`: This command is used to remove a file or directory.
* `man`: This command is used to view the manual page of a command.
