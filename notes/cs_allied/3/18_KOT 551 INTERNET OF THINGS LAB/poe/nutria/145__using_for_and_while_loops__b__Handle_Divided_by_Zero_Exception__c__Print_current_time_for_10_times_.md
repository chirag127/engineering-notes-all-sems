

#### Using For and While Loops

- For loops allow you to iterate through a sequence of values, executing a block of code for each value in the sequence. 
- While loops allow you to execute a block of code while a condition is true.
- When using for and while loops, it is important to handle exceptions that may arise. One such exception is when a variable is divided by zero. This can be handled by using a try/catch block, which will catch the error and allow the program to continue executing. 
- It is also possible to print the current time for 10 times with an increment of 1 second. This can be done using a for loop and the `time.sleep()` function, which pauses the program for a specified amount of time.
