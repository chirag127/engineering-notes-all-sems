

# Interval of 10 Seconds

1. A file can be read line by line by using a looping statement such as a `for` loop. 
2. Within the loop, a variable can be used to store the line that is being read. 
3. The `length()` function can be used to count the number of words in the line. 
4. The result of the `length()` function can then be stored in a variable and printed. 
5. This process can be repeated for each line in the file.
