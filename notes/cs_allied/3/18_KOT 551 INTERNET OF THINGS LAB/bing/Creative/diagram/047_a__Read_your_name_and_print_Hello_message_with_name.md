# Reading your name and printing a hello message with your name

- A variable is a name that refers to a value that can be changed or assigned by the program. For example, you can create a variable called `name` and assign it the value of your name.
- Input is the process of getting data from the user or another source, such as the keyboard, a file, or a website. For example, you can use the `input()` function in Python to get a string from the user and store it in a variable.
- Output is the process of displaying data to the user or another destination, such as the screen, a file, or a website. For example, you can use the `print()` function in Python to print a string to the screen.
