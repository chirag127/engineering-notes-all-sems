# KOT 552 INTERNET OF THINGS LAB KCS

## Introduction

- The Internet of Things (IoT) is the network of physical objects that can communicate and interact with each other through the internet.
- IoT devices can collect, process, and share data from sensors, actuators, cameras, and other sources.
- IoT applications can range from smart homes, smart cities, smart health, smart agriculture, smart industry, and more.
- IoT devices can use different communication protocols, such as Wi-Fi, Bluetooth, Zigbee, LoRa, MQTT, CoAP, etc.
- IoT devices can use different platforms, such as Arduino, Raspberry Pi, ESP32, etc.

## Objectives

- To understand the basic concepts and principles of IoT.
- To learn how to design, develop, and deploy IoT solutions using various hardware and software components.
- To gain hands-on experience with IoT devices, sensors, actuators, communication protocols, and cloud services.
- To explore the challenges and opportunities of IoT in different domains and scenarios.

## Course Outcomes

- CO1: Explain the architecture, components, and applications of IoT.
- CO2: Demonstrate the use of various IoT devices, sensors, actuators, and communication protocols.
- CO3: Develop and test IoT solutions using Arduino, Raspberry Pi, ESP32, or other platforms.
- CO4: Integrate IoT solutions with cloud services, such as AWS IoT, Google Cloud IoT, Microsoft Azure IoT, etc.
- CO5: Analyze the security, privacy, and ethical issues of IoT.

## Course Content

- Unit 1: Introduction to IoT
  - Definition, characteristics, and evolution of IoT
  - IoT architecture, components, and layers
  - IoT applications and domains
  - IoT challenges and opportunities
- Unit 2: IoT Devices and Sensors
  - IoT devices, such as Arduino, Raspberry Pi, ESP32, etc.
  - IoT sensors, such as temperature, humidity, light, motion, etc.
  - IoT actuators, such as LED, buzzer, relay, motor, etc.
  - IoT device programming and interfacing
- Unit 3: IoT Communication and Protocols
  - IoT communication technologies, such as Wi-Fi, Bluetooth, Zigbee, LoRa, etc.
  - IoT communication protocols, such as MQTT, CoAP, HTTP, etc.
  - IoT communication models, such as publish-subscribe, request-response, etc.
  - IoT communication security and encryption
- Unit 4: IoT Cloud and Services
  - IoT cloud platforms, such as AWS IoT, Google Cloud IoT, Microsoft Azure IoT, etc.
  - IoT cloud services, such as device management, data storage, data processing, data visualization, etc.
  - IoT cloud integration and APIs
  - IoT cloud security and authentication
- Unit 5: IoT Applications and Case Studies
  - IoT applications in smart home, smart city, smart health, smart agriculture, smart industry, etc.
  - IoT case studies and best practices
  - IoT security, privacy, and ethical issues
  - IoT trends and future directions

## Lab Exercises

- Lab 1: Setting up the IoT devices and sensors
  - Objective: To learn how to set up and use various IoT devices and sensors, such as Arduino, Raspberry Pi, ESP32, temperature sensor, humidity sensor, light sensor, motion sensor, etc.
  - Procedure: Follow the instructions given in the lab manual or online resources to connect the IoT devices and sensors, and test their functionality using simple programs.
  - Expected Outcome: The IoT devices and sensors should be able to collect and display the data from the environment.
- Lab 2: IoT communication using Wi-Fi and MQTT
  - Objective: To learn how to use Wi-Fi and MQTT protocol to communicate between IoT devices and a broker server.
  - Procedure: Follow the instructions given in the lab manual or online resources to configure the Wi-Fi and MQTT settings on the IoT devices, and use a broker server, such as Mosquitto, to publish and subscribe to messages.
  - Expected Outcome: The IoT devices should be able to send and receive messages using Wi-Fi and MQTT protocol.
- Lab 3: IoT communication using Bluetooth and CoAP
  - Objective: To learn how to use Bluetooth and CoAP protocol to communicate between IoT devices and a client application.
  - Procedure: Follow the instructions given in the lab manual or online resources to configure the Bluetooth and CoAP settings on the IoT devices, and use a client application, such as Copper, to request and respond to messages.
