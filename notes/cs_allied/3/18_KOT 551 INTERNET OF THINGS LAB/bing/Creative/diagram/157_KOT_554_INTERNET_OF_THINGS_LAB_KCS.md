# KOT 554 INTERNET OF THINGS LAB KCS

- Internet of Things (IoT) is the concept of connecting physical devices, sensors, actuators, and other objects to the internet and enabling data exchange and communication among them.
- IoT applications can be found in various domains, such as smart homes, smart cities, smart health, smart agriculture, smart industry, and smart education.
- IoT devices can be controlled and monitored remotely using smartphone apps, web interfaces, voice assistants, or other methods.
- IoT devices can also communicate with each other and form networks, such as wireless sensor networks, mesh networks, or peer-to-peer networks.
- IoT devices can use different protocols and standards for connectivity, such as Wi-Fi, Bluetooth, Zigbee, LoRa, 5G, MQTT, CoAP, etc.
- IoT devices can also use cloud computing and edge computing to store, process, and analyze the data generated by them.
- IoT devices can also use artificial intelligence and machine learning to perform tasks such as object recognition, face recognition, speech recognition, natural language processing, etc.
- IoT devices can also use blockchain and cryptography to ensure security, privacy, and trust in the data and transactions among them.
- KOT 554 is a lab course that teaches the students the fundamental concepts and practical skills of IoT using the KOHLER® Konnect platform and the Arm Mbed platform.
- KOHLER® Konnect is a collection of smart kitchen and bath products that can be controlled and customized using voice commands, smartphone apps, or touchless sensors.
- Arm Mbed is an open source platform that provides hardware, software, and cloud services for developing and deploying IoT devices.
- The lab course consists of the following modules:

  - Module 1: Introduction to IoT and KOHLER® Konnect
  - Module 2: IoT Hardware and Software using Arm Mbed
  - Module 3: IoT Connectivity and Protocols
  - Module 4: IoT Cloud Computing and Services
  - Module 5: IoT Artificial Intelligence and Machine Learning
  - Module 6: IoT Security and Blockchain
  - Module 7: IoT Project Development and Presentation

- The lab course aims to provide the students with the following learning outcomes:

  - Understand the basic concepts and principles of IoT and its applications in various domains.
  - Learn how to use the KOHLER® Konnect platform and the Arm Mbed platform to design, develop, and deploy IoT devices and systems.
  - Learn how to use different connectivity and communication protocols and standards for IoT devices and systems.
  - Learn how to use cloud computing and edge computing to store, process, and analyze the data generated by IoT devices and systems.
  - Learn how to use artificial intelligence and machine learning to perform tasks such as object recognition, face recognition, speech recognition, natural language processing, etc. using IoT devices and systems.
  - Learn how to use blockchain and cryptography to ensure security, privacy, and trust in the data and transactions among IoT devices and systems.
  - Learn how to work in teams and present the IoT projects in a professional manner.
