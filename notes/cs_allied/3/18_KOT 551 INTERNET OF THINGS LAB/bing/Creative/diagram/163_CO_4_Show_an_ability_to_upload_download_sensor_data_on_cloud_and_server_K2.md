# CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server are two types of computing platforms that can store, process, and analyze sensor data remotely over the internet.
- Cloud is a network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer that hosts a specific application or service such as a web server, a database server, etc.
- To upload sensor data to cloud or server, the sensor device needs to have a network connection such as Wi-Fi, Ethernet, cellular, satellite, etc. and a protocol such as HTTP, MQTT, CoAP, etc. to communicate with the cloud or server platform.
- To download sensor data from cloud or server, the sensor device or another device such as a laptop, a smartphone, etc. needs to have a network connection and a protocol to access the cloud or server platform and retrieve the sensor data.
- Some examples of cloud and server platforms that can handle sensor data are:
  - Microsoft Azure Defender for IoT: A cloud-based security solution that monitors and protects industrial IoT devices and networks. It allows users to upload sensor data from OT sensors to the cloud using an activation file and a sensor console.
  - AWS DynamoDB: A cloud-based NoSQL database service that can store and query sensor data. It allows users to upload sensor data from IoT devices to the cloud using AWS IoT Core and AWS IoT Rules.
  - ThingSpeak: A cloud-based IoT platform that can store, visualize, and analyze sensor data. It allows users to upload sensor data from Raspberry Pi devices to the cloud using HTTP or MQTT protocols.
  - SAPHI: A cloud-based IoT platform that can store, visualize, and analyze sensor data. It allows users to upload sensor data from various types of sensors to the cloud using different network options such as Wi-Fi, cellular, LoRaWAN, satellite, etc.
  - Apache Tomcat: A server-based web application server that can host Java-based web applications. It allows users to upload and download sensor data from IoT devices to the server using HTTP or WebSocket protocols.
