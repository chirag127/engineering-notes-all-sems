#### CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server K2 are two different platforms for storing and processing sensor data. Cloud is a network of remote servers that provide on-demand computing resources and services over the internet. Server K2 is a specific type of server that runs on the Kubernetes platform and supports containerized applications.
- To upload sensor data on cloud and server K2, one needs to follow these steps:
  - Connect the sensor to a device that can communicate with the cloud or server K2, such as a microcontroller, a computer, a smartphone, etc.
  - Choose a protocol and a format for sending the sensor data, such as MQTT, HTTP, JSON, CSV, etc.
  - Establish a connection with the cloud or server K2 using the appropriate credentials and parameters, such as the endpoint, the port, the topic, the authentication token, etc.
  - Publish the sensor data to the cloud or server K2 using the chosen protocol and format, such as by calling a REST API, publishing to a MQTT broker, sending a HTTP request, etc.
  - Confirm that the sensor data has been successfully uploaded by checking the response from the cloud or server K2, such as the status code, the message, the acknowledgment, etc.
- To download sensor data from cloud and server K2, one needs to follow these steps:
  - Connect to the cloud or server K2 using a device that can receive and process the sensor data, such as a computer, a smartphone, a tablet, etc.
  - Choose a protocol and a format for receiving the sensor data, such as MQTT, HTTP, JSON, CSV, etc.
  - Subscribe to the sensor data from the cloud or server K2 using the appropriate credentials and parameters, such as the endpoint, the port, the topic, the authentication token, etc.
  - Receive the sensor data from the cloud or server K2 using the chosen protocol and format, such as by listening to a MQTT broker, fetching from a REST API, receiving a HTTP response, etc.
  - Confirm that the sensor data has been successfully downloaded by checking the content and the quality of the data, such as the timestamp, the value, the unit, the accuracy, etc.
