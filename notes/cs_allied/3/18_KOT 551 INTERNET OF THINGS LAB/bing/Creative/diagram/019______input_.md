#### Input
- Input is the process of transferring data or instructions from an external source to a computer system or device.
- Input devices are hardware components that allow users to interact with a computer system or device, such as keyboards, mice, scanners, cameras, microphones, etc.
- Input data can be in different forms, such as text, images, audio, video, etc.
- Input data can be processed by the computer system or device in different ways, such as storing, displaying, manipulating, analyzing, etc.
- Input data can be used for different purposes, such as creating documents, playing games, browsing the web, communicating, etc.

Some examples of input are:

- Typing a document on a word processor using a keyboard.
- Scanning a barcode using a barcode scanner.
- Taking a picture using a digital camera.
- Recording a voice message using a microphone.
- Clicking a link on a web page using a mouse.
