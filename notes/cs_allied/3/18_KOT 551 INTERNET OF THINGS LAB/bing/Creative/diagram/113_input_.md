# Input

- Input is the process of providing data and instructions to a computer or a device.
- Input devices are the hardware components that allow users to enter data and commands into a computer or a device. Examples of input devices are keyboard, mouse, microphone, scanner, webcam, etc.
- Input data can be in different forms, such as text, graphics, audio, video, etc.
- Input data can be stored in different formats, such as binary, ASCII, Unicode, etc.
- Input data can be processed by different methods, such as batch processing, online processing, real-time processing, etc.
- Input data can be validated and verified to ensure its accuracy and completeness. Validation checks if the data meets certain criteria, such as range, format, length, etc. Verification checks if the data matches the original source, such as by using checksums, parity bits, etc.
