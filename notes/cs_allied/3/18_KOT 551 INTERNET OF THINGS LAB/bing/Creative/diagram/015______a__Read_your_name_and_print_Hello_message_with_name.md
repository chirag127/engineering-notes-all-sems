#### a) Read your name and print Hello message with name

- This topic is about how to write a simple program that can read your name from the input and print a hello message with your name on the output.
- To write such a program, you need to use some basic concepts of programming, such as variables, data types, input/output functions, and string concatenation.
- A variable is a name that can store a value of a certain data type, such as a number, a text, or a boolean. For example, you can create a variable called name and assign it a value of "Alice".
- A data type is a category of values that have certain properties and operations. For example, a number can be added, subtracted, multiplied, or divided, while a text can be joined, split, or searched.
- An input/output function is a special type of function that can read data from the user or display data to the user. For example, you can use the input() function to read a text from the user and store it in a variable, or use the print() function to display a text to the user on the screen.
- A string concatenation is an operation that can join two or more texts together to form a new text. For example, you can use the + operator to concatenate "Hello" and "Alice" to get "Hello Alice".
- Here is an example of a program that can read your name and print a hello message with your name:

```python
# This is a comment that explains the code
# Ask the user to enter their name and store it in a variable called name
name = input("What is your name? ")

# Print a hello message with the name using string concatenation
print("Hello " + name)
```

- Here is an example of the output of the program:

```
What is your name? Bob
Hello Bob
```

- Here are some points to remember about the program:

  - The input() function returns a text, so the name variable is a text data type.
  - The print() function can take one or more arguments, separated by commas, and display them on the screen with a space between them. For example, print("Hello", name) would also work.
  - The + operator can concatenate texts, but not texts and numbers. For example, print("Hello" + 42) would cause an error.
  - The # symbol is used to write comments, which are ignored by the program but can help explain the code to other programmers or yourself.
