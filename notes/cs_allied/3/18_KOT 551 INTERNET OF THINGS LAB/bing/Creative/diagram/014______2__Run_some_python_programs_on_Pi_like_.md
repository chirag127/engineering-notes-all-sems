#### 2. Run some python programs on Pi like:

- Python is a popular programming language that can be used to create various applications on Raspberry Pi, such as games, web servers, robots, etc.
- To run a python program on Pi, you need to have a text editor and a terminal window open.
- A text editor is a software that allows you to write and edit code. You can use any text editor you like, such as nano, vim, or IDLE.
- A terminal window is a software that allows you to execute commands and run programs on Pi. You can open a terminal window by clicking on the icon on the top left corner of the screen or by pressing Ctrl+Alt+T.
- To create a python program, you need to write your code in a text editor and save it with a .py extension, such as hello.py.
- To run a python program, you need to type python followed by the name of your program in a terminal window, such as python hello.py.
- You can also run a python program by making it executable and adding a shebang line at the beginning of your code. A shebang line is a special comment that tells the system which interpreter to use to run the program. For example, #!/usr/bin/env python3.
- To make a python program executable, you need to change its permissions by typing chmod +x followed by the name of your program in a terminal window, such as chmod +x hello.py.
- To run an executable python program, you need to type ./ followed by the name of your program in a terminal window, such as ./hello.py.
- You can also run a python program by using an IDE (Integrated Development Environment), such as Thonny or PyCharm. An IDE is a software that provides a graphical user interface for writing, editing, debugging, and running code. You can install an IDE on Pi by using the command sudo apt install followed by the name of the IDE in a terminal window, such as sudo apt install thonny.
- To run a python program using an IDE, you need to open the IDE, create a new file, write your code, save it with a .py extension, and click on the run button.
