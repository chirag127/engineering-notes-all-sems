### The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc. and

- Understand the basic principles and working of different types of sensors.
- Learn how to connect and interface sensors with microcontrollers or computers using appropriate circuits and protocols.
- Acquire and process sensor data using programming languages and software tools.
- Analyze and visualize sensor data using statistical and graphical methods.
- Apply sensor data to various applications and scenarios such as home automation, environmental monitoring, security, etc.
- Evaluate the performance and limitations of sensors and sensor systems.
