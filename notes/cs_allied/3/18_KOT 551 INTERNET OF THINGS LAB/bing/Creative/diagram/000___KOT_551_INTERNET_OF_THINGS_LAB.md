# KOT 551 INTERNET OF THINGS LAB

## Introduction

The Internet of Things (IoT) is defined as the network of physical objects, things that are embedded, with sensors, software and other technologies for the purpose of connecting and exchanging data with other devices and systems over the internet. IoT can enable various applications such as smart home, smart city, smart health, smart agriculture, smart industry, etc.

## Objectives

The objectives of this lab are:

- To understand the basic concepts and principles of IoT
- To learn how to use various IoT devices and platforms
- To design and implement IoT solutions for different scenarios
- To evaluate the performance and challenges of IoT systems

## Lab Outline

The lab consists of the following modules:

- Module 1: Introduction to IoT and Arduino
- Module 2: Sensors and Actuators
- Module 3: Communication Protocols and Networks
- Module 4: Cloud Computing and IoT Services
- Module 5: Data Analytics and Visualization
- Module 6: Security and Privacy in IoT
- Module 7: IoT Applications and Case Studies

## Lab Requirements

The lab requires the following hardware and software components:

- Arduino Uno board and USB cable
- Breadboard and jumper wires
- Various sensors and actuators (e.g., temperature, humidity, light, motion, sound, LED, buzzer, etc.)
- Wi-Fi module (e.g., ESP8266 or ESP32)
- Laptop or desktop computer with internet access
- Arduino IDE and Python IDE
- IoT platforms and services (e.g., ThingSpeak, Firebase, AWS IoT, etc.)
- Data analysis and visualization tools (e.g., MATLAB, Excel, Power BI, etc.)

## Lab Evaluation

The lab evaluation will be based on the following criteria:

- Attendance and participation
- Lab reports and assignments
- Quizzes and tests
- Final project and presentation
