#### mkdir, rmdir, tar, gzip, cat, more, less, ps, sudo, cron, chown, chgrp, ping etc.

- `mkdir` is a command that creates a new directory in the current or specified location. The syntax is `mkdir [options] directory_name`. Some common options are `-p` to create parent directories if they do not exist, `-v` to display a message for each created directory, and `-m` to set the permissions of the new directory.
- `rmdir` is a command that removes an empty directory. The syntax is `rmdir [options] directory_name`. Some common options are `-p` to remove parent directories if they are empty, `-v` to display a message for each removed directory, and `--ignore-fail-on-non-empty` to ignore errors when trying to remove non-empty directories.
- `tar` is a command that creates or extracts compressed archive files. The syntax is `tar [options] [archive_file] [file_or_directory ...]`. Some common options are `-c` to create a new archive, `-x` to extract an existing archive, `-z` to use gzip compression, `-v` to display the progress, and `-f` to specify the archive file name.
- `gzip` is a command that compresses or decompresses files using the gzip algorithm. The syntax is `gzip [options] [file ...]`. Some common options are `-c` to write the output to the standard output, `-d` to decompress the input files, `-k` to keep the original files, `-l` to list the compressed file information, and `-r` to recursively compress or decompress files in directories.
- `cat` is a command that concatenates and displays files. The syntax is `cat [options] [file ...]`. Some common options are `-n` to number the output lines, `-b` to number the non-blank output lines, `-s` to suppress repeated blank lines, `-E` to display a `$` at the end of each line, and `-T` to display tabs as `^I`.
- `more` is a command that displays the contents of a file or the standard input one screen at a time. The syntax is `more [options] [file ...]`. Some common options are `-d` to display a help message, `-l` to ignore form feed characters, `-p` to clear the screen before displaying each file, `-s` to squeeze multiple blank lines into one, and `+n` to start from the nth line of the first file.
- `less` is a command that displays the contents of a file or the standard input in a scrollable manner. The syntax is `less [options] [file ...]`. Some common options are `-N` to display line numbers, `-i` to ignore case in searches, `-M` to display more information about the file, `-S` to chop long lines instead of wrapping them, and `+F` to follow the end of the file as it grows.
- `ps` is a command that displays information about the processes running on the system. The syntax is `ps [options]`. Some common options are `-e` to display all processes, `-f` to display full format information, `-u` to display processes owned by a specific user, `-a` to display processes associated with a terminal, and `-x` to display processes without a controlling terminal.
- `sudo` is a command that executes another command as a different user, usually the superuser or root. The syntax is `sudo [options] command [arguments ...]`. Some common options are `-u` to specify the user to run as, `-l` to list the commands the current user can run, `-p` to specify the prompt to display, `-v` to validate the user's credentials, and `-k` to invalidate the user's credentials.
- `cron` is a daemon that runs commands at specified intervals or times. The syntax is `cron [options]`. Some common options are `-l` to list the user's crontab file, `-e` to edit the user's crontab file, `-r` to remove the user's crontab file, and `-u` to specify the user whose crontab file to operate on. The crontab file contains lines of the form `minute hour day month weekday command`, where each field can be a number, a range, a list, or a special character.
