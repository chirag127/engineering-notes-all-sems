# KOT 554 INTERNET OF THINGS LAB KCS

- KOT 554 is a course code for Internet of Things Lab offered by KCS Technologies Inc., a company that provides IoT solutions and services.
- Internet of Things (IoT) is a term that describes the network of physical objects that are embedded with sensors, software, and other technologies to connect and exchange data with other devices and systems over the internet.
- The main objectives of the course are to teach the students the fundamental concepts of IoT, such as embedded systems, connectivity, cloud computing, and security, and to provide them with practical experience in creating smartphone apps and controlling a wearable device using the Arm Mbed platform and Android SDK.
- The course consists of the following topics and experiments:

  - Introduction to IoT and its applications
  - IoT architecture and components
  - IoT protocols and standards
  - IoT security and privacy issues
  - IoT platforms and cloud services
  - IoT devices and sensors
  - IoT development tools and environments
  - IoT programming and debugging
  - IoT project design and implementation

- The course requires the students to have the following prerequisites:

  - Basic knowledge of computer networks and internet technologies
  - Basic knowledge of programming languages such as C, C++, Java, or Python
  - Basic knowledge of Android development and Android Studio
  - Access to a computer with internet connection and a smartphone with Android OS
  - Access to an Arm Mbed enabled device such as a FRDM-K64F board and a Hexiwear wearable device
  - Access to an Internet of Things Education Kit from Arm or a similar IoT kit

- The course is assessed by the following methods:

  - Lab assignments and quizzes
  - Midterm and final exams
  - Project presentation and report

- The course is expected to provide the students with the following outcomes:

  - Understand the concepts and principles of IoT and its applications
  - Identify the components and architecture of an IoT system
  - Compare and contrast the IoT protocols and standards
  - Analyze the IoT security and privacy challenges and solutions
  - Evaluate the IoT platforms and cloud services
  - Select and use the IoT devices and sensors
  - Apply the IoT development tools and environments
  - Develop and test IoT programs and applications
  - Design and implement IoT projects
