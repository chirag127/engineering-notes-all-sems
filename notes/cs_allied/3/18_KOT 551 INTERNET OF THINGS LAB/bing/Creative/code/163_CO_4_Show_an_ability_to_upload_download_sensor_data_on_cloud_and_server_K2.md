# CO 4 Show an ability to upload/download sensor data on cloud and server K2

- Sensor data is the information collected by various types of sensors that measure physical phenomena such as temperature, humidity, pressure, light, sound, motion, etc.
- Cloud and server are two types of platforms that can store and process sensor data remotely over the internet.
- Cloud is a network of servers that provide on-demand computing resources and services such as storage, databases, analytics, etc. Server is a single computer that hosts a specific application or service such as a web server, a database server, etc.
- To upload sensor data to cloud or server, the following steps are usually required:
  - Connect the sensor to a device that can communicate with the internet, such as a microcontroller, a computer, a smartphone, etc. This device is called the gateway or the edge device.
  - Configure the gateway device to read the sensor data and format it according to the protocol and format required by the cloud or server platform. For example, JSON, XML, MQTT, HTTP, etc.
  - Establish a secure and reliable connection between the gateway device and the cloud or server platform using the appropriate network technology and authentication method. For example, Wi-Fi, Ethernet, cellular, satellite, etc.
  - Send the sensor data to the cloud or server platform using the appropriate API or service. For example, AWS IoT Core, Azure IoT Hub, ThingSpeak, etc.
  - Receive an acknowledgement or a response from the cloud or server platform to confirm the successful upload of the sensor data.
- To download sensor data from cloud or server, the following steps are usually required:
  - Connect to the cloud or server platform using a device that can communicate with the internet, such as a computer, a smartphone, a tablet, etc. This device is called the client or the user device.
  - Authenticate the client device to access the cloud or server platform using the appropriate method. For example, username and password, API key, token, etc.
  - Request the sensor data from the cloud or server platform using the appropriate API or service. For example, AWS IoT Core, Azure IoT Hub, ThingSpeak, etc.
  - Receive the sensor data from the cloud or server platform in the desired format and protocol. For example, JSON, XML, MQTT, HTTP, etc.
  - Process, analyze, visualize, or store the sensor data on the client device as needed.
