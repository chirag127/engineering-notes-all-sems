# 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, affordable computer that can run Linux, a free and open-source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) with icons and menus. You can use the mouse and keyboard to interact with the GUI.
- Alternatively, you can use the command terminal window, which is a text-based interface that allows you to enter commands and see the output. You can open the command terminal window by clicking on the icon that looks like a black screen with a white cursor, or by pressing Ctrl+Alt+T on the keyboard.
- In the command terminal window, you can enter various Linux commands to perform different tasks. Some of the common Linux commands are:

  - `ls`: This command lists the files and folders in the current directory. You can use the `-l` option to see more details, such as the size, permissions, and modification date of each file and folder. You can also use the `-a` option to see the hidden files and folders, which start with a dot (.).
  - `cd`: This command changes the current directory to the one specified. You can use `cd ..` to go up one level, or `cd /` to go to the root directory. You can also use `cd ~` to go to your home directory, which is where your personal files and settings are stored.
  - `touch`: This command creates a new, empty file with the name specified. For example, `touch hello.txt` will create a file named hello.txt in the current directory. You can also use `touch` to update the modification date of an existing file, without changing its content.
  - `mv`: This command moves or renames a file or folder. You need to specify the source and the destination of the file or folder. For example, `mv hello.txt goodbye.txt` will rename the file hello.txt to goodbye.txt. You can also use `mv` to move a file or folder to another directory, by specifying the full or relative path of the destination. For example, `mv hello.txt ~/Documents` will move the file hello.txt to the Documents folder in your home directory.
  - `rm`: This command removes or deletes a file or folder. You need to specify the name of the file or folder to be removed. For example, `rm hello.txt` will delete the file hello.txt. You can also use the `-r` option to remove a folder and all its contents recursively. For example, `rm -r Documents` will delete the Documents folder and everything inside it. Be careful when using this command, as there is no undo option.
  - `man`: This command shows the manual page for a given command. The manual page contains information about the syntax, options, and examples of using the command. You can use the arrow keys or the space bar to scroll through the manual page, and press Q to quit. For example, `man ls` will show the manual page for the `ls` command.

- These are some of the basic Linux commands that you can try on your Raspberry Pi. There are many more commands that you can learn and use to explore and manipulate the files and folders on your system. You can also use the `help` command to see a list of available commands, or the `apropos` command to search for commands related to a keyword.
