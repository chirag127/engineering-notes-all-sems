# Reading your name and printing a hello message with your name

- One of the simplest tasks you can do with a computer program is to read your name from the keyboard and print a hello message with your name on the screen.
- To do this, you need to use some basic concepts and commands of the programming language you are using. In this content, we will use Python as an example, but you can use any other language you prefer.
- The steps to read your name and print a hello message with your name are:

  1. Import the `input` function from the `builtins` module. This function allows you to read a string from the keyboard and store it in a variable.
  2. Declare a variable called `name` and assign it the value returned by the `input` function. You can also provide a prompt message inside the parentheses of the `input` function to tell the user what to enter.
  3. Print a hello message with your name using the `print` function. You can use the `+` operator to concatenate strings, or use the `f` string format to insert the value of the `name` variable inside the message.
  4. Save your program in a file with the `.py` extension and run it using the Python interpreter. You will see the output on the screen.

- Here is an example of a Python program that reads your name and prints a hello message with your name:

```python
# Import the input function
from builtins import input

# Read your name from the keyboard and store it in a variable
name = input("Enter your name: ")

# Print a hello message with your name
print("Hello, " + name + "!") # Using the + operator
print(f"Hello, {name}!") # Using the f string format
```
