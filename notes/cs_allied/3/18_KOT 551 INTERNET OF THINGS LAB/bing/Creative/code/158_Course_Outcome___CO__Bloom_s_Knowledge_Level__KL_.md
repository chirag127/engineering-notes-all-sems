# Course Outcome (CO) Bloom's Knowledge Level (KL)

- Course Outcome (CO) is a statement that describes what a learner should be able to do at the end of a course or a unit of instruction.
- Bloom's Knowledge Level (KL) is a classification of cognitive skills that learners can demonstrate in different domains of learning, such as remembering, understanding, applying, analyzing, evaluating, and creating.
- CO and KL are related because they both help to define the learning objectives and assessment criteria for a course or a unit of instruction.
- CO and KL can be aligned by using verbs that match the appropriate level of cognitive skill in the CO statement, and by using assessment methods that measure the same level of cognitive skill in the KL.
- For example, a CO statement that says "Students will be able to analyze the impact of social media on political campaigns" aligns with the KL of analyzing, and can be assessed by using methods such as case studies, essays, or debates.
