#### 2. Run some python programs on Pi like:

- To run a python program on Pi, you need to have a python interpreter installed on your Pi. You can check if you have one by typing `python3 --version` in the terminal. If you see a version number, you have python3 installed. If not, you can install it by typing `sudo apt install python3`.
- You also need to have a text editor or an IDE (Integrated Development Environment) to write and edit your python code. You can use the default text editor on Pi, which is called `nano`, or you can install other editors like `Thonny` or `Mu`. To install Thonny, type `sudo apt install thonny`. To install Mu, type `pip3 install mu-editor`.
- To write a python program, you need to create a file with the `.py` extension, such as `hello.py`. You can use any text editor to create and save the file in your Pi directory. To open the file with nano, type `nano hello.py` in the terminal. To open the file with Thonny, type `thonny hello.py` in the terminal. To open the file with Mu, type `mu hello.py` in the terminal.
- To write a simple python program that prints "Hello, world!" to the screen, you can type the following code in your file:

```python
# This is a comment. It starts with a # symbol and is ignored by the interpreter.
print("Hello, world!") # This is a print statement. It displays the text inside the parentheses to the screen.
```

- To run the python program, you need to save the file and then type `python3 hello.py` in the terminal. You should see the output "Hello, world!" on the screen.
- You can write more complex python programs by using variables, data types, operators, expressions, statements, functions, modules, classes, objects, and other features of the python language. You can learn more about python by reading the official documentation at https://docs.python.org/3/ or by following some online tutorials or courses.
