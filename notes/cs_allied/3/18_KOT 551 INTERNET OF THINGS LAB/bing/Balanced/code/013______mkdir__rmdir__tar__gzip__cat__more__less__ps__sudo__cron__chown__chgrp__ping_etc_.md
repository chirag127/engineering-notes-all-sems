#### mkdir, rmdir, tar, gzip, cat, more, less, ps, sudo, cron, chown, chgrp, ping etc.

These are some of the common Linux commands that can be used to perform various tasks in the command terminal window. Here is a brief description of each command and some examples of their usage:

- `mkdir`: This command creates one or more directories (folders) in the current or specified location. The syntax is `mkdir [options] [directory_name]`. For example, `mkdir new_folder` creates a directory called `new_folder` in the current working directory. `mkdir -p dir1/dir2/dir3` creates a directory tree with `dir1` as the parent and `dir2` and `dir3` as the subdirectories.
- `rmdir`: This command removes one or more empty directories from the file system. The syntax is `rmdir [options] [directory_name]`. For example, `rmdir dir1` removes the directory `dir1` if it is empty. `rmdir -p dir1/dir2/dir3` removes the directory tree with `dir1` as the parent and `dir2` and `dir3` as the subdirectories, if they are all empty.
- `tar`: This command creates or extracts compressed archive files that contain multiple files or directories. The syntax is `tar [options] [archive_name] [file_name]`. For example, `tar -cvzf archive.tar.gz file1 file2 dir1` creates a compressed archive file called `archive.tar.gz` that contains `file1`, `file2` and `dir1`. `tar -xvzf archive.tar.gz` extracts the contents of `archive.tar.gz` in the current working directory.
- `gzip`: This command compresses or decompresses files using the GNU zip algorithm. The syntax is `gzip [options] [file_name]`. For example, `gzip file1` compresses `file1` and renames it to `file1.gz`. `gzip -d file1.gz` decompresses `file1.gz` and renames it to `file1`.
- `cat`: This command concatenates and displays the contents of one or more files to the standard output. The syntax is `cat [options] [file_name]`. For example, `cat file1 file2` displays the contents of `file1` and `file2` in the terminal. `cat file1 file2 > file3` redirects the output of `cat` to a new file called `file3`.
- `more`: This command displays the contents of a file or the output of another command one screen at a time. The syntax is `more [options] [file_name]`. For example, `more file1` displays the contents of `file1` and pauses after each screen. The user can press the space bar to continue or q to quit. `ls -l | more` pipes the output of `ls -l` to `more` and displays the long listing of files and directories one screen at a time.
- `less`: This command is similar to `more` but provides more features. It allows backward as well as forward movement in the file or output, even with pipes. It also does not read the entire file or output before starting, so it starts up faster compared to text editors. The syntax is `less [options] [file_name]`. For example, `less file1` displays the contents of `file1` and allows the user to scroll up and down using the arrow keys or the page up and page down keys. The user can also search for a pattern using / or ? and quit using q. `ps -ef | less` pipes the output of `ps -ef` to `less` and displays the information about the processes running on the system one screen at a time.
- `ps`: This command displays information about the processes running on the system. The syntax is `ps [options]`.
