## Course Outcome (CO) Bloom's Knowledge Level (KL)

- Course outcome (CO) is a statement that describes what students are expected to know, understand, or be able to do at the end of a course.
- Bloom's knowledge level (KL) is a classification of cognitive skills that students can demonstrate in relation to a given topic or domain.
- Bloom's taxonomy consists of six levels of knowledge: remember, understand, apply, analyze, evaluate, and create.
- Each level of knowledge requires a different type of cognitive process and has a different degree of complexity and difficulty.
- The higher the level of knowledge, the more challenging and sophisticated the learning outcome is.
- Course outcomes should be aligned with the appropriate level of knowledge that matches the course objectives and the intended learning experiences.
- Course outcomes should also be measurable, observable, and achievable by the students within the duration of the course.
- Course outcomes should be written using action verbs that indicate the level of knowledge and the cognitive process involved.
- For example, a course outcome that requires students to remember factual information can be written as: "Identify the main components of a computer system."
- A course outcome that requires students to apply conceptual knowledge can be written as: "Solve problems using different programming languages and paradigms."
- A course outcome that requires students to create original products or solutions can be written as: "Design and implement a software project that meets the specifications and requirements of a client."
- The following table shows some examples of action verbs for each level of knowledge:

| Level of Knowledge | Action Verbs |
| ------------------ | ------------ |
| Remember           | Define, list, name, recall, recognize, state, etc. |
| Understand         | Classify, describe, explain, interpret, summarize, etc. |
| Apply              | Apply, demonstrate, perform, use, etc. |
| Analyze            | Analyze, compare, contrast, differentiate, etc. |
| Evaluate           | Assess, critique, evaluate, justify, etc. |
| Create             | Create, design, develop, generate, etc. |

- Course outcomes should be assessed using appropriate methods and tools that match the level of knowledge and the cognitive process involved.
- For example, a course outcome that requires students to remember factual information can be assessed using multiple-choice questions, fill-in-the-blanks, or matching exercises.
- A course outcome that requires students to apply conceptual knowledge can be assessed using case studies, simulations, or projects.
- A course outcome that requires students to create original products or solutions can be assessed using portfolios, presentations, or peer reviews.
