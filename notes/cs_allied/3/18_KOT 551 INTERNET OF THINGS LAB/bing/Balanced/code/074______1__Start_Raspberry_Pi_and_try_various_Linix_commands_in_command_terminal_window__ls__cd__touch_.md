#### 1. Start Raspberry Pi and try various Linix commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, low-cost computer that can run Linux, a free and open-source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it.
- Once Raspberry Pi boots up, you will see a desktop environment with icons and menus. You can launch applications from the menu or the icons, or you can open a command terminal window to type commands.
- A command terminal window is a text-based interface that allows you to interact with the operating system and the files and folders on your Raspberry Pi. You can open a command terminal window by clicking on the icon that looks like a black screen with a white cursor, or by pressing Ctrl+Alt+T on your keyboard.
- In the command terminal window, you can type various Linux commands to perform different tasks. Here are some of the common Linux commands and their functions:

  - `ls`: This command lists the files and folders in the current directory. You can use the `-l` option to see more details, such as the size, date, and permissions of each file and folder. You can also use the `-a` option to see hidden files and folders, which start with a dot (.).
  - `cd`: This command changes the current directory to another directory. You can use the name of the directory as an argument, such as `cd Documents` to go to the Documents directory. You can also use the `..` symbol to go up one level, such as `cd ..` to go to the parent directory. You can use the `~` symbol to go to your home directory, such as `cd ~` to go to /home/pi.
  - `touch`: This command creates a new, empty file with the name you specify as an argument, such as `touch hello.txt` to create a file named hello.txt. You can also use this command to update the date and time of an existing file, without changing its content.
  - `mv`: This command moves or renames a file or a folder. You can use the name of the source file or folder and the name of the destination file or folder as arguments, such as `mv hello.txt goodbye.txt` to rename hello.txt to goodbye.txt, or `mv hello.txt Documents` to move hello.txt to the Documents directory. You can also use the `-i` option to ask for confirmation before overwriting an existing file or folder, such as `mv -i hello.txt goodbye.txt`.
  - `rm`: This command removes or deletes a file or a folder. You can use the name of the file or folder as an argument, such as `rm hello.txt` to delete hello.txt. You can also use the `-r` option to delete a folder and all its contents recursively, such as `rm -r Documents` to delete the Documents directory and everything inside it. You can also use the `-i` option to ask for confirmation before deleting a file or folder, such as `rm -i hello.txt`.
  - `man`: This command shows the manual page for a command or a topic. You can use the name of the command or the topic as an argument, such as `man ls` to see the manual page for the ls command. You can use the arrow keys to scroll up and down, and the Q key to quit the manual page. You can also use the `/` key to search for a keyword, and the N key to go to the next occurrence of the keyword.
