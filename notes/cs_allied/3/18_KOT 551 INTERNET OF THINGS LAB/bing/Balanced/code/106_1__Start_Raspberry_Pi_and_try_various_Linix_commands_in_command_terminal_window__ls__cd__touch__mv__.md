# 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, low-cost computer that can run Linux and other operating systems. It can be used for various projects, such as robotics, gaming, web servers, etc.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a compatible operating system image, such as Raspberry Pi OS, into the slot on the board.
- Once the Raspberry Pi boots up, you will see a desktop environment with icons and menus. You can launch applications from the menu or the icons, or you can open a command terminal window by clicking on the black icon with a white ">_" symbol on the top left corner of the screen.
- A command terminal window is a text-based interface that allows you to interact with the operating system using commands. Commands are instructions that tell the computer what to do. You can type commands and press Enter to execute them. You will see the output of the commands on the screen, or you will see a prompt that indicates that the command is waiting for more input or has finished.
- Linux commands are case-sensitive, meaning that uppercase and lowercase letters matter. For example, "ls" and "LS" are different commands. You can also use options and arguments with commands to modify their behavior or specify what they operate on. Options usually start with a "-" or a "--" and are followed by a letter or a word. Arguments are usually the names of files or directories that the command works with. For example, "ls -l /home/pi" is a command that lists the files and directories in the /home/pi directory in a long format.
- Some of the most common and useful Linux commands are:

  - ls: lists the files and directories in the current directory or in a specified directory. You can use options such as "-l" to show more details, "-a" to show hidden files, "-h" to show human-readable sizes, etc.
  - cd: changes the current directory to a specified directory. You can use "." to refer to the current directory, ".." to refer to the parent directory, "~" to refer to your home directory, or an absolute or relative path to specify a directory. For example, "cd .." moves you one level up in the directory hierarchy, "cd ~" moves you to your home directory, "cd /usr/bin" moves you to the /usr/bin directory, etc.
  - touch: creates a new, empty file with a specified name, or updates the modification time of an existing file. For example, "touch test.txt" creates a new file named test.txt in the current directory, or updates its modification time if it already exists.
  - mv: moves or renames a file or a directory. You need to specify the source and the destination of the file or the directory. For example, "mv test.txt test2.txt" renames the file test.txt to test2.txt in the current directory, "mv test.txt /home/pi/Documents" moves the file test.txt to the /home/pi/Documents directory, etc.
  - rm: removes a file or a directory. You need to specify the name of the file or the directory to remove. You can use options such as "-r" to remove directories recursively, "-f" to force removal without confirmation, "-i" to prompt for confirmation before removal, etc. For example, "rm test.txt" removes the file test.txt in the current directory, "rm -r test" removes the directory test and all its contents in the current directory, etc.
  - man: shows the manual page for a command or a topic. You need to specify the name of the command or the topic to view its manual page. You can use the arrow keys, the Page Up and Page Down keys, or the Space bar to scroll through the manual page. You can use the "/" key to search for a keyword in the manual page. You can use the "q" key to quit the manual page. For example, "man ls" shows the manual page for the ls command, "man man" shows the manual page for the man command, etc.
