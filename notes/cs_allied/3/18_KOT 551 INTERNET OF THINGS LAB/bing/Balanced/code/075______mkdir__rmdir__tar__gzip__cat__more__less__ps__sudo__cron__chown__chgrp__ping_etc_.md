- `mkdir` is a command that creates a new directory with the specified name and options. For example, `mkdir newdir` will create a directory called `newdir` in the current working directory. Some options are `-p` to create parent directories if they do not exist, `-m` to set the permissions of the new directory, and `-v` to print a message for each created directory.
- `rmdir` is a command that removes an empty directory with the specified name and options. For example, `rmdir newdir` will remove the directory called `newdir` if it is empty. Some options are `-p` to remove parent directories if they are empty, and `-v` to print a message for each removed directory.
- `tar` is a command that creates or extracts compressed archive files. For example, `tar czvf archive.tar.gz files` will create a compressed archive file called `archive.tar.gz` containing the files specified. Some options are `-c` to create a new archive, `-x` to extract an archive, `-z` to use gzip compression, `-v` to print the names of the files processed, and `-f` to specify the name of the archive file.
- `gzip` is a command that compresses or decompresses files using the gzip algorithm. For example, `gzip file.txt` will compress the file `file.txt` and rename it to `file.txt.gz`. Some options are `-d` to decompress a file, `-k` to keep the original file, `-l` to list the compressed file information, and `-r` to recursively compress files in a directory.
- `cat` is a command that concatenates and prints files to the standard output. For example, `cat file1 file2` will print the contents of `file1` and `file2` to the screen. Some options are `-n` to number the output lines, `-b` to number the non-blank output lines, and `-s` to suppress repeated empty output lines.
- `more` is a command that displays the contents of a file or the output of another command one screen at a time. For example, `more file.txt` will show the first screen of `file.txt` and wait for the user to press a key to continue. Some commands that can be used while viewing the file are `space` to show the next screen, `b` to show the previous screen, `/` to search for a pattern, and `q` to quit.
- `less` is a command that is similar to `more` but with more features and flexibility. For example, `less file.txt` will show the first screen of `file.txt` and allow the user to scroll up and down, search, and perform other actions.
