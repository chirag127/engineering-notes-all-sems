### The student should have hands on experience in using various sensors like temperature, humidity, smoke, light, etc. and

- understand the principles and applications of different types of sensors
- learn how to interface sensors with microcontrollers or computers using appropriate circuits and protocols
- acquire skills in programming, data acquisition, processing, and visualization using sensors
- design and implement projects that involve sensors for solving real-world problems or creating innovative products

Some of the benefits of having hands on experience in using sensors are:

- It enhances the student's practical knowledge and problem-solving skills
- It fosters the student's creativity and curiosity
- It exposes the student to various domains and disciplines that use sensors
- It prepares the student for future careers or studies that require sensor skills
