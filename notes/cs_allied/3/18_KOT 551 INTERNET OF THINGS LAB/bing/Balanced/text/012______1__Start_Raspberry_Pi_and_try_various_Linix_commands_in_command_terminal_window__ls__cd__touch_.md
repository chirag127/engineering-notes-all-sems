#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small computer that runs on Linux, a free and open-source operating system.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with the operating system installed on it.
- Once Raspberry Pi boots up, you will see a desktop environment with icons and menus. You can use the mouse and keyboard to interact with the graphical user interface (GUI).
- However, you can also use the command terminal window to enter text commands that control the system. The command terminal window is a black or white box with a prompt that looks like this: `pi@raspberrypi:~ $`
- To open the command terminal window, you can either click on the icon that looks like a monitor with a black screen, or press Ctrl+Alt+T on the keyboard.
- In the command terminal window, you can type various Linux commands to perform different tasks. Here are some examples of common Linux commands:

  - `ls`: This command lists the files and folders in the current directory. You can use the `-l` option to see more details, such as the size, date, and permissions of each file and folder. You can also use the `-a` option to see hidden files and folders, which start with a dot (.).
  - `cd`: This command changes the current directory to another one. You can use the name of the directory as an argument, such as `cd Documents` to go to the Documents folder. You can also use `..` to go up one level, or `~` to go to your home directory. You can use `pwd` to print the current directory.
  - `touch`: This command creates a new empty file with the given name. For example, `touch hello.txt` will create a file named hello.txt in the current directory. You can use the `-t` option to specify the date and time of the file, such as `touch -t 202103160242 hello.txt` to create a file with the timestamp of 16 March 2023, 02:42.
  - `mv`: This command moves or renames a file or folder. You can use the name of the source and the destination as arguments, such as `mv hello.txt goodbye.txt` to rename hello.txt to goodbye.txt, or `mv hello.txt Documents` to move hello.txt to the Documents folder. You can also use the `-i` option to ask for confirmation before overwriting an existing file, or the `-n` option to prevent overwriting an existing file.
  - `rm`: This command removes or deletes a file or folder. You can use the name of the file or folder as an argument, such as `rm goodbye.txt` to delete goodbye.txt, or `rm -r Documents` to delete the Documents folder and all its contents. You can also use the `-i` option to ask for confirmation before deleting, or the `-f` option to force deleting without confirmation.
  - `man`: This command shows the manual page for a given command. You can use the name of the command as an argument, such as `man ls` to see the manual page for the ls command. You can use the arrow keys or the space bar to scroll through the manual page, and press Q to quit. You can also use the `-k` option to search for a keyword in all the manual pages, such as `man -k file` to see all the commands related to file operations.
