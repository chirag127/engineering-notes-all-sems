#### CO 5 Examine various SQL queries from MySQL database K4, K5

- SQL stands for Structured Query Language and is a standard language for accessing and manipulating data in relational databases.
- MySQL is an open-source relational database management system that uses SQL as its query language.
- SQL queries are expressions that define the set of data to be retrieved from the database. They can be written in a database management application (such as MySQL Workbench) or in a programming language (such as PHP) that connects to the database.
- There are different types of SQL queries, depending on the purpose and complexity of the data manipulation. Some of the common types are:
  - DDL (Data Definition Language): These queries are used to create, alter, rename, drop, or truncate the physical structure of the tables in the database. For example, `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`, etc.
  - DML (Data Manipulation Language): These queries are used to insert, update, delete, or select the data in the tables. For example, `INSERT INTO`, `UPDATE`, `DELETE`, `SELECT`, etc.
  - DCL (Data Control Language): These queries are used to grant or revoke permissions to access or modify the data in the database. For example, `GRANT`, `REVOKE`, etc.
  - TCL (Transaction Control Language): These queries are used to manage the transactions that affect the data in the database. For example, `COMMIT`, `ROLLBACK`, `SAVEPOINT`, etc.
  - DQL (Data Query Language): These queries are used to retrieve the data from the database based on certain conditions or criteria. For example, `SELECT`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, etc.
- To examine various SQL queries from MySQL database, one needs to understand the syntax, keywords, operators, functions, clauses, and parameters that are used to construct the queries. Some of the general rules are:
  - SQL keywords are not case-sensitive, but it is a good practice to write them in uppercase for readability.
  - SQL queries end with a semicolon (;) to indicate the end of the statement.
  - SQL queries can be written in one line or multiple lines, depending on the complexity and readability of the query.
  - SQL queries can use single quotes (') or double quotes (") to enclose string values, but it is recommended to use single quotes for consistency.
  - SQL queries can use comments to explain the purpose or logic of the query. Comments can be written in two ways: using -- for single-line comments, or using /* and */ for multi-line comments.
  - SQL queries can use variables, constants, expressions, or functions to manipulate the data in the database. Variables are placeholders for values that can change, constants are fixed values, expressions are combinations of values and operators, and functions are predefined or user-defined routines that perform specific tasks.
  - SQL queries can use clauses to specify the conditions or criteria for the data manipulation. Clauses are keywords that are followed by expressions or parameters. Some of the common clauses are: `FROM`, `WHERE`, `GROUP BY`, `HAVING`, `ORDER BY`, `LIMIT`, `JOIN`, `UNION`, etc.
