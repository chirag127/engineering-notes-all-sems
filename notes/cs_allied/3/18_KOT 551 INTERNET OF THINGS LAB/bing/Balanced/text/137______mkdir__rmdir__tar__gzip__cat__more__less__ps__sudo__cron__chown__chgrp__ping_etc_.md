#### mkdir, rmdir, tar, gzip, cat, more, less, ps, sudo, cron, chown, chgrp, ping etc.

These are some of the common Linux commands that can be used to perform various tasks in the command terminal window. Here is a brief description of each command and some examples of their usage:

- **mkdir**: This command creates one or more directories. The syntax is `mkdir [options] [directory names]`. For example, `mkdir newDir` creates a directory called newDir, and `mkdir -p dir1/dir2/dir3` creates a directory tree with dir1 as the parent and dir3 as the child.
- **rmdir**: This command removes one or more empty directories. The syntax is `rmdir [options] [directory names]`. For example, `rmdir newDir` removes the directory newDir, and `rmdir -p dir1/dir2/dir3` removes the directory tree with dir1 as the parent and dir3 as the child.
- **tar**: This command creates or extracts compressed archive files. The syntax is `tar [options] [archive file] [files or directories]`. For example, `tar -cvzf backup.tar.gz dir1` creates a compressed archive file called backup.tar.gz that contains the contents of dir1, and `tar -xvzf backup.tar.gz` extracts the contents of backup.tar.gz to the current directory.
- **gzip**: This command compresses or decompresses files. The syntax is `gzip [options] [files]`. For example, `gzip file.txt` compresses the file file.txt and renames it to file.txt.gz, and `gzip -d file.txt.gz` decompresses the file file.txt.gz and renames it to file.txt.
- **cat**: This command concatenates and displays files. The syntax is `cat [options] [files]`. For example, `cat file1 file2` displays the contents of file1 and file2, and `cat file1 file2 > file3` concatenates file1 and file2 and redirects the output to file3.
- **more**: This command displays the contents of a file or the output of another command one screen at a time. The syntax is `more [options] [file or command]`. For example, `more file.txt` displays the file file.txt one screen at a time, and `ls -l | more` displays the output of the command `ls -l` one screen at a time.
- **less**: This command is similar to more, but it allows backward and forward movement in the file or the output. The syntax is `less [options] [file or command]`. For example, `less file.txt` displays the file file.txt and allows the user to scroll up and down using the arrow keys, and `ps -aux | less` displays the output of the command `ps -aux` and allows the user to scroll up and down using the arrow keys.
- **ps**: This command displays information about the processes running on the system. The syntax is `ps [options]`. For example, `ps` displays information about the processes associated with the current terminal, and `ps -aux` displays information about all the processes on the system.
- **sudo**: This command executes another command as the superuser or another user. The syntax is `sudo [options] [command]`. For example, `sudo apt-get update` executes the command `apt-get update` as the superuser, and `sudo -u bob ls -l` executes the command `ls -l` as the user bob.
- **cron**: This command schedules commands or scripts to run at a specified time or interval. The syntax is `cron [options] [file]`. For example, `cron -e` edits the crontab file of the current user, and `cron -l` lists the crontab file of the current user.
