# Input

- Input is the process of receiving data or information from an external source, such as a keyboard, mouse, microphone, scanner, etc.
- Input devices are hardware components that allow users to interact with a computer or a program by sending commands, entering data, or selecting options.
- Input can be categorized into different types, such as text, graphics, audio, video, etc. depending on the format and purpose of the data or information.
- Input can also be classified into manual or automatic, depending on whether the user has to perform any action or not to provide the input.
- Input is essential for any computer system or program to function properly, as it enables the user to specify the desired output, control the execution, or modify the behavior of the system or program.
