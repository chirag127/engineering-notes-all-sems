# Linux Commands

Linux commands are instructions that can be executed in a terminal or a shell to perform various tasks. Some of the common Linux commands are:

- **mkdir**: This command creates one or more directories. The syntax is `mkdir [options] [directory names]`. For example, `mkdir newDir` creates a directory called newDir. To create multiple directories at once, we can use `mkdir newDir1 newDir2 newDir3`. To create a directory with a specific permission, we can use the `-m` option, such as `mkdir -m 755 newDir` .
- **rmdir**: This command removes one or more empty directories. The syntax is `rmdir [options] [directory names]`. For example, `rmdir newDir` removes the directory newDir if it is empty. To remove multiple directories at once, we can use `rmdir newDir1 newDir2 newDir3`. To remove directories recursively, we can use the `-p` option, such as `rmdir -p newDir/subDir`.
- **tar**: This command creates or extracts compressed archive files. The syntax is `tar [options] [archive file] [files or directories]`. For example, `tar -cvf archive.tar file1 file2` creates a tar archive file called archive.tar containing file1 and file2. To extract a tar archive file, we can use `tar -xvf archive.tar`. To create a compressed archive file using gzip or bzip2, we can use the `-z` or `-j` option, such as `tar -cvzf archive.tar.gz file1 file2` or `tar -cvjf archive.tar.bz2 file1 file2`.
- **gzip**: This command compresses or decompresses files using the gzip algorithm. The syntax is `gzip [options] [files]`. For example, `gzip file1` compresses file1 and renames it to file1.gz. To decompress a gzip file, we can use `gzip -d file1.gz` or `gunzip file1.gz`. To compress multiple files at once, we can use `gzip file1 file2 file3`. To compress a directory, we can use `gzip -r directory`.
- **cat**: This command concatenates and displays files. The syntax is `cat [options] [files]`. For example, `cat file1` displays the contents of file1. To concatenate multiple files and display them, we can use `cat file1 file2 file3`. To create a new file with the contents of another file, we can use `cat file1 > file2`. To append the contents of one file to another file, we can use `cat file1 >> file2`.
- **more**: This command displays the contents of a file or a command output one screen at a time. The syntax is `more [options] [file or command]`. For example, `more file1` displays the contents of file1 and pauses after each screen. To scroll down, we can press the spacebar or the Enter key. To quit, we can press Q. To display the output of a command, we can use `command | more`. For example, `ls -l | more` displays the output of the `ls -l` command and pauses after each screen.
- **less**: This command is similar to the more command but provides more features. The syntax is `less [options] [file or command]`. For example, `less file1` displays the contents of file1 and allows backward and forward movement in the file using the arrow keys or the Page Up and Page Down keys. To quit, we can press Q. To display the output of a command, we can use `command | less`. For example, `ps -ef | less` displays the output of the `ps -ef` command and allows scrolling up and down.
- **ps**: This command displays information about the processes running on the system. The syntax is `ps [options]`. For example, `ps` displays information about the processes running in the current terminal. To display information about all the processes running on the system, we can use `ps -e` or `ps -A`.
