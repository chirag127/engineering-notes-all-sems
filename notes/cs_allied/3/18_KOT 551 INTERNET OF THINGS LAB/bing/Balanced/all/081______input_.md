# Input

- Input is the process of receiving data or information from an external source, such as a keyboard, mouse, microphone, scanner, etc.
- Input devices are hardware components that allow users to interact with a computer or other electronic device by sending signals or commands.
- Input can also refer to the data or information that is entered or provided to a program, function, or algorithm for processing or manipulation.
- Input can be categorized into different types, such as text, numeric, audio, image, video, etc. depending on the format and content of the data or information.
- Input can be validated, filtered, or transformed before being processed or stored by a computer or other electronic device. This can help prevent errors, improve security, or enhance performance.
