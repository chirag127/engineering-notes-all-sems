# Course Outcome (CO) Bloom's Knowledge Level (KL)

- Course outcome (CO) is a statement that describes what students are expected to know, understand, or be able to do by the end of a course.
- Bloom's knowledge level (KL) is a classification of the cognitive domain of learning, which refers to the mental processes involved in acquiring and applying knowledge.
- Bloom's knowledge level (KL) consists of six levels: remember, understand, apply, analyze, evaluate, and create. Each level represents a different degree of complexity and difficulty in learning.
- The following table shows the relationship between course outcome (CO) and Bloom's knowledge level (KL):

| Course Outcome (CO) | Bloom's Knowledge Level (KL) | Example |
| ------------------- | ---------------------------- | ------- |
| CO1: Define the basic concepts and principles of computer science. | Remember | Recall the definition of algorithm, data structure, or programming language. |
| CO2: Explain the working of various algorithms and data structures. | Understand | Describe how a sorting algorithm works, or how a binary tree is implemented. |
| CO3: Apply the appropriate algorithms and data structures to solve problems. | Apply | Implement a sorting algorithm in a programming language, or use a binary tree to store and search data. |
| CO4: Analyze the efficiency and correctness of algorithms and data structures. | Analyze | Compare the time and space complexity of different algorithms, or verify the correctness of an algorithm using mathematical proofs. |
| CO5: Evaluate the suitability and trade-offs of algorithms and data structures for different applications. | Evaluate | Critique the advantages and disadvantages of using a certain algorithm or data structure, or suggest alternative solutions. |
| CO6: Create new algorithms and data structures based on existing ones or from scratch. | Create | Design a new algorithm or data structure to solve a novel problem, or modify an existing one to improve its performance or functionality. |
