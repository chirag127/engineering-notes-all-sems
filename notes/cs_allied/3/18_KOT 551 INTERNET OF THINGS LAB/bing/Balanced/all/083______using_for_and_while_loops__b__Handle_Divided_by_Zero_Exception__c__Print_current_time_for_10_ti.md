# Using for and while loops, handling divided by zero exception, and printing current time for 10 times with an interval of 1 second

- For and while loops are two types of control structures that allow a program to execute a block of code repeatedly based on a condition.
- A for loop has a fixed number of iterations, determined by a starting value, an ending value, and a step value. For example, `for i in range(1, 11, 2):` means that the loop will run 5 times, with i taking the values 1, 3, 5, 7, and 9.
- A while loop has an indefinite number of iterations, determined by a boolean expression that is evaluated before each iteration. For example, `while i < 10:` means that the loop will run until i is no longer less than 10.
- A divided by zero exception is an error that occurs when a program tries to perform a division operation with zero as the divisor. This is an invalid mathematical operation and can cause the program to crash or produce incorrect results.
- To handle a divided by zero exception, a program can use a try-except block, which allows it to execute a block of code and catch any errors that may occur. For example, `try: result = a / b except ZeroDivisionError: print("Cannot divide by zero")` means that the program will try to perform the division and print the result, but if a ZeroDivisionError occurs, it will print a message instead of crashing.
- To print the current time for 10 times with an interval of 1 second, a program can use the datetime module, which provides functions and classes for working with dates and times. For example, `import datetime import time for i in range(10): print(datetime.datetime.now()) time.sleep(1)` means that the program will import the datetime and time modules, then use a for loop to print the current time 10 times, and use the time.sleep function to pause the execution for 1 second between each print.
