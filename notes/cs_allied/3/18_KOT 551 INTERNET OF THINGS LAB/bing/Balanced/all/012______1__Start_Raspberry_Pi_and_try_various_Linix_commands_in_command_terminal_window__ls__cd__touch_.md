#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- Raspberry Pi is a small, low-cost computer that can run Linux and other operating systems. It can be used for various projects, such as robotics, gaming, web development, etc.
- To start Raspberry Pi, you need to connect it to a power source, a monitor, a keyboard, and a mouse. You also need to insert a microSD card with a Linux operating system installed on it. You can download various Linux distributions for Raspberry Pi from https://www.raspberrypi.org/software/operating-systems/.
- Once Raspberry Pi boots up, you will see a graphical user interface (GUI) or a command line interface (CLI), depending on the Linux distribution you are using. You can switch between them by pressing Ctrl+Alt+F1 (for CLI) or Ctrl+Alt+F7 (for GUI).
- To open a command terminal window in the GUI, you can click on the icon that looks like a black screen with a white cursor, or press Ctrl+Alt+T. A command terminal window is a text-based interface that allows you to interact with the Linux operating system by typing commands and seeing the output.
- Some of the basic Linux commands that you can try in the command terminal window are:

  - `ls`: This command lists the files and directories in the current working directory. You can use various options with this command, such as `-l` (for long listing), `-a` (for showing hidden files), `-h` (for human-readable sizes), etc. For example, `ls -lah` will list all the files and directories in the current working directory, along with their permissions, owners, sizes, and modification dates.
  - `cd`: This command changes the current working directory to the one specified as an argument. You can use absolute paths (starting with `/`) or relative paths (starting with `.` or `..`) to specify the destination directory. For example, `cd /home/pi` will change the current working directory to `/home/pi`, while `cd ..` will move one level up in the directory hierarchy.
  - `touch`: This command creates an empty file with the name specified as an argument. If the file already exists, it updates its modification date. For example, `touch test.txt` will create an empty file named `test.txt` in the current working directory, or update its modification date if it already exists.
  - `mv`: This command moves or renames a file or directory. You need to specify the source and the destination as arguments. If the destination is a directory, the source will be moved into that directory. If the destination is a file, the source will be renamed to that file. For example, `mv test.txt test2.txt` will rename the file `test.txt` to `test2.txt`, while `mv test.txt /home/pi/Documents` will move the file `test.txt` to the `/home/pi/Documents` directory.
  - `rm`: This command removes a file or directory. You need to specify the name of the file or directory as an argument. You can use the `-r` option to recursively remove a directory and all its contents. You can use the `-f` option to force the removal without asking for confirmation. Be careful with this command, as there is no undo option. For example, `rm test.txt` will remove the file `test.txt`, while `rm -rf test` will remove the directory `test` and all its contents.
  - `man`: This command shows the manual page for a command or a topic. You need to specify the name of the command or the topic as an argument. The manual page will provide a description, syntax, options, examples, and other information about the command or the topic. You can use the arrow keys, Page Up, Page Down, Home, End, and other keys to navigate the manual page. You can press `q` to quit the manual page. For example, `man ls` will show the manual page for the `ls` command, while `man man` will show the manual page for the `man` command.
