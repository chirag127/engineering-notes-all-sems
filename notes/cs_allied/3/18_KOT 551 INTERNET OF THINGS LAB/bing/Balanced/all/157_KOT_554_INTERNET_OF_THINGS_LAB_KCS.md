# KOT 554 INTERNET OF THINGS LAB KCS

- KOT 554 is a course code for Internet of Things Lab offered by KCS Technologies Inc., a company that provides IoT solutions and services.
- Internet of Things (IoT) is a term that describes the network of physical objects that are embedded with sensors, software, and other technologies to connect and exchange data with other devices and systems over the internet.
- The main objectives of the course are to:
  - Teach the fundamental concepts of IoT, such as embedded systems, connectivity, cloud computing, and security.
  - Provide practical experience in creating smartphone apps and controlling a wearable device using the Arm Mbed platform and Android SDK.
  - Develop skills in designing, prototyping, testing, and deploying IoT applications for various domains and scenarios.
- The course consists of the following modules:
  - Module 1: Introduction to IoT and Arm Mbed
    - This module covers the basics of IoT, such as its definition, characteristics, applications, and challenges. It also introduces the Arm Mbed platform, which is a device management service that provides a secure and scalable way to connect and manage IoT devices.
  - Module 2: IoT Connectivity and Protocols
    - This module covers the various types of connectivity and protocols used in IoT, such as Wi-Fi, Bluetooth, Zigbee, LoRa, MQTT, CoAP, and HTTP. It also explains how to use the Arm Mbed OS and the Mbed Cloud Client to connect and communicate with IoT devices.
  - Module 3: IoT Cloud Services and Data Analytics
    - This module covers the various cloud services and data analytics tools that are used in IoT, such as AWS IoT, Google Cloud IoT, Azure IoT, IBM Watson IoT, and ThingSpeak. It also explains how to use the Arm Pelion Device Management service to manage and update IoT devices remotely.
  - Module 4: IoT Security and Privacy
    - This module covers the various security and privacy issues and solutions in IoT, such as encryption, authentication, authorization, access control, and data protection. It also explains how to use the Arm Mbed TLS library and the Arm TrustZone technology to secure IoT devices and data.
  - Module 5: IoT Application Development and Deployment
    - This module covers the various steps and tools involved in developing and deploying IoT applications, such as design thinking, prototyping, testing, debugging, and publishing. It also provides a case study of an IoT application for a smart home scenario using the Arm Mbed platform and the Android SDK.
