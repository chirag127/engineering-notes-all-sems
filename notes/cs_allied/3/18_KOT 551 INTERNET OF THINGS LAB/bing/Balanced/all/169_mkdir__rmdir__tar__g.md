# mkdir, rmdir, tar, g

- mkdir is a command that creates a new directory in the file system.
- rmdir is a command that removes an empty directory from the file system.
- tar is a command that creates or extracts compressed archive files.
- g is a command that invokes the GNU Compiler Collection (GCC) to compile source code files.

Some examples of using these commands are:

- To create a directory named "project" in the current working directory, use `mkdir project`.
- To remove a directory named "project" from the current working directory, use `rmdir project`.
- To create a compressed archive file named "project.tar.gz" from the contents of the "project" directory, use `tar czvf project.tar.gz project`.
- To extract the contents of the "project.tar.gz" archive file into the current working directory, use `tar xzvf project.tar.gz`.
- To compile a C source code file named "main.c" into an executable file named "main", use `g main.c -o main`.
