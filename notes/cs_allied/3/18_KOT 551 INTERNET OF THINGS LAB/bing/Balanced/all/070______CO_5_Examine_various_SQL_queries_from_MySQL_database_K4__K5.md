#### CO 5 Examine various SQL queries from MySQL database K4, K5

SQL stands for Structured Query Language and it is a standard language for accessing and manipulating data in relational databases. MySQL is one of the most popular open-source relational database management systems (RDBMS) that uses SQL to perform various operations on the data.

Some of the objectives of this topic are:

- To understand the basic syntax and structure of SQL queries.
- To learn how to create, use, and drop databases and tables in MySQL.
- To learn how to insert, update, delete, and select data from tables in MySQL.
- To learn how to use various clauses, operators, functions, and keywords in SQL queries to filter, sort, group, and aggregate data in MySQL.
- To learn how to join multiple tables and perform subqueries and nested queries in MySQL.

Some of the key points of this topic are:

- A SQL query is an expression that defines the set of data to be retrieved from the database. A SQL query consists of one or more statements that follow a specific syntax and order. A SQL query can be executed using a database management application (such as MySQL Workbench) or a command-line interface (such as mysql).
- A SQL query can be classified into two types: Data Definition Language (DDL) and Data Manipulation Language (DML). DDL queries are used to create, alter, rename, drop, and truncate databases and tables. DML queries are used to insert, update, delete, and select data from tables.
- A database is a collection of related data organized in a logical structure. A table is a set of data arranged in rows and columns. A column is a named attribute of a table that defines the type and format of the data. A row is a record of data that contains values for each column. A primary key is a column or a combination of columns that uniquely identifies each row in a table. A foreign key is a column or a combination of columns that references the primary key of another table to establish a relationship between the tables.
- To create a database in MySQL, the CREATE DATABASE statement is used. For example, `CREATE DATABASE db1;` creates a database named db1. To use a database in MySQL, the USE statement is used. For example, `USE db1;` selects the database db1 as the current database. To drop a database in MySQL, the DROP DATABASE statement is used. For example, `DROP DATABASE db1;` deletes the database db1 and all its tables.
- To create a table in MySQL, the CREATE TABLE statement is used. For example, `CREATE TABLE students (id INT PRIMARY KEY, name VARCHAR(50), age INT);` creates a table named students with three columns: id, name, and age. The id column is the primary key and the name column is a variable-length string with a maximum of 50 characters. To alter a table in MySQL, the ALTER TABLE statement is used. For example, `ALTER TABLE students ADD COLUMN email VARCHAR(50);` adds a new column named email to the students table. To rename a table in MySQL, the RENAME TABLE statement is used. For example, `RENAME TABLE students TO learners;` renames the students table to learners. To drop a table in MySQL, the DROP TABLE statement is used. For example, `DROP TABLE students;` deletes the students table and all its data. To truncate a table in MySQL, the TRUNCATE TABLE statement is used. For example, `TRUNCATE TABLE students;` deletes all the data from the students table but keeps the table structure.
- To insert data into a table in MySQL, the INSERT INTO statement is used. For example, `INSERT INTO students (id, name, age) VALUES (1, 'Alice', 20);` inserts a new row into the students table with the values 1, 'Alice', and 20 for the id, name, and age columns respectively. To update data in a table in MySQL, the UPDATE statement is used. For example, `UPDATE students SET age = 21 WHERE id = 1;` updates the age column to 21 for the row where the id column is 1. To delete data from a table in MySQL, the DELETE FROM statement is used. For example, `DELETE FROM students WHERE id = 1;` deletes the row where the id column is 1 from the students table.
