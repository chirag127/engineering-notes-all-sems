# Input

- Input is the process of receiving data or information from an external source, such as a keyboard, mouse, microphone, scanner, etc.
- Input devices are hardware components that allow users to interact with a computer or a program by sending signals or commands.
- Input can be categorized into different types, such as text, graphics, audio, video, etc., depending on the format and content of the data or information.
- Input can also be classified into manual or automatic, depending on the level of human intervention required to provide the data or information.
- Input is essential for any computer system or program to function properly, as it enables users to specify their needs, preferences, queries, etc., and receive the desired output or feedback.
