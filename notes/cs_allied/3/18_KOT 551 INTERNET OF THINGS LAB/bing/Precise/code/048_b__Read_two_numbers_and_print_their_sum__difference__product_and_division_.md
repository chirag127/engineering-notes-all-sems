# b) Read two numbers and print their sum, difference, product and division.

1. To read two numbers, you can use the `input()` function in Python. This function reads a line from input, converts it to a string, and returns it. You can then convert the string to an integer or float using the `int()` or `float()` functions, respectively.

```python
num1 = int(input("Enter the first number: "))
num2 = int(input("Enter the second number: "))
```

2. To print the sum of the two numbers, you can use the `+` operator.

```python
sum = num1 + num2
print("The sum of the two numbers is:", sum)
```

3. To print the difference of the two numbers, you can use the `-` operator.

```python
difference = num1 - num2
print("The difference of the two numbers is:", difference)
```

4. To print the product of the two numbers, you can use the `*` operator.

```python
product = num1 * num2
print("The product of the two numbers is:", product)
```

5. To print the division of the two numbers, you can use the `/` operator.

```python
division = num1 / num2
print("The division of the two numbers is:", division)
```
