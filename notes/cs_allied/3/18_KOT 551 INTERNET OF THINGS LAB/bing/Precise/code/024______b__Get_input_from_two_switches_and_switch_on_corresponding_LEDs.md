#### b) Get input from two switches and switch on corresponding LEDs

To get input from two switches and switch on corresponding LEDs, the following steps can be followed:

1. Connect the two switches to the input pins of the microcontroller.
2. Connect the two LEDs to the output pins of the microcontroller.
3. Write a program to read the input from the switches.
4. In the program, use conditional statements to check the state of the switches.
5. If a switch is in the ON state, turn on the corresponding LED by sending a HIGH signal to the output pin connected to the LED.
6. If a switch is in the OFF state, turn off the corresponding LED by sending a LOW signal to the output pin connected to the LED.
7. Upload the program to the microcontroller and test the circuit.

This is a basic approach to getting input from two switches and switching on corresponding LEDs. The specific details and implementation may vary depending on the microcontroller and other components used. It is important to consult the datasheets and documentation for the specific components to ensure proper operation.
