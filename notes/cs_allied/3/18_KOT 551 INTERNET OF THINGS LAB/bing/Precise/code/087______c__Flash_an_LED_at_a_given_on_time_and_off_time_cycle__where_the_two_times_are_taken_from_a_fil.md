To flash an LED at a given on time and off time cycle, where the two times are taken from a file, the following steps can be followed:

1. **Read the on and off times from the file:** The first step is to read the on and off times from the file. This can be done using file input/output operations in the programming language being used.

2. **Set up the LED:** The next step is to set up the LED. This involves connecting the LED to the appropriate pins on the microcontroller or development board being used.

3. **Create a loop:** A loop should be created to continuously turn the LED on and off. The loop should run indefinitely, or until a certain condition is met.

4. **Turn the LED on:** Within the loop, the first step is to turn the LED on. This can be done by setting the appropriate pin to a high voltage.

5. **Wait for the on time:** After turning the LED on, the program should wait for the on time specified in the file. This can be done using a delay function.

6. **Turn the LED off:** After the on time has elapsed, the LED should be turned off. This can be done by setting the appropriate pin to a low voltage.

7. **Wait for the off time:** After turning the LED off, the program should wait for the off time specified in the file. This can be done using a delay function.

8. **Repeat:** The loop should then repeat, turning the LED on and off according to the on and off times specified in the file.

By following these steps, an LED can be flashed at a given on time and off time cycle, where the two times are taken from a file. This can be useful for creating various lighting effects or for indicating the status of a system.
