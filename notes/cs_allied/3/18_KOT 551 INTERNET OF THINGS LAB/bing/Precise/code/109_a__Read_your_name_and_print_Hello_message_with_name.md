# Reading your name and printing a Hello message with name

1. To read your name, you can use the `input()` function in Python. This function prompts the user to enter a value and returns the value entered by the user as a string.
2. To print a Hello message with the name entered by the user, you can use the `print()` function in Python. This function outputs the specified message to the screen.
3. Here is an example of how you can read your name and print a Hello message with the name in Python:

```python
name = input("Enter your name: ")
print("Hello, " + name + "!")
```

In this example, the `input()` function prompts the user to enter their name. The value entered by the user is then stored in the `name` variable. The `print()` function is then used to output a Hello message with the name entered by the user.
