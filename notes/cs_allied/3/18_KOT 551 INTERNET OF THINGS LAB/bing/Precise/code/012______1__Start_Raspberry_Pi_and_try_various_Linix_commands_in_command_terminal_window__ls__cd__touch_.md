#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- **ls**: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
- **cd**: This command is used to change the current directory. It stands for "change directory".
- **touch**: This command is used to create a new, empty file. It can also be used to update the timestamp of an existing file.
- **mv**: This command is used to move or rename files or directories. It stands for "move".
- **rm**: This command is used to remove files or directories. It stands for "remove".
- **man**: This command is used to display the manual page for a command. It stands for "manual".

These are some basic Linux commands that can be used in the command terminal window of a Raspberry Pi. It is recommended to try these commands and experiment with them to become familiar with the Linux command line interface.
