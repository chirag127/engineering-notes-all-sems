# Get the status of a bulb at a remote place (on the LAN) through web

1. To get the status of a bulb at a remote place on the LAN through the web, the bulb must be connected to a device that is capable of communicating its status over the network.
2. This can be achieved by using a smart bulb that is connected to a home automation system or by connecting a regular bulb to a smart plug or switch that is capable of communicating its status over the network.
3. Once the bulb is connected to a device that can communicate its status, the status can be accessed through a web interface or an API provided by the device or the home automation system.
4. The user can then log in to the web interface or use the API to retrieve the current status of the bulb, such as whether it is on or off.
5. This can be useful for remotely monitoring and controlling the lighting in a building or for automating lighting based on certain conditions or events.
