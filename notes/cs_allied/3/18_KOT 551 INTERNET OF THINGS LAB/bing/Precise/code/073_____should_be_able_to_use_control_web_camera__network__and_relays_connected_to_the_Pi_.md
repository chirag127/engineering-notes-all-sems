### Control Web Camera, Network, and Relays Connected to the Pi

1. **Web Camera**: The Raspberry Pi can be used to control a web camera. This can be done by connecting the camera to the Pi via USB and using software such as `motion` or `fswebcam` to capture images or video.
2. **Network**: The Raspberry Pi can be connected to a network via Ethernet or Wi-Fi. This allows the Pi to communicate with other devices on the network and access the internet. The `ifconfig` and `iwconfig` commands can be used to configure the network settings on the Pi.
3. **Relays**: Relays can be connected to the Raspberry Pi's GPIO pins to control devices such as lights or motors. The `gpio` command can be used to control the state of the GPIO pins and, in turn, the state of the connected relay.

By using these features, the Raspberry Pi can be used as a versatile and powerful tool for controlling a wide range of devices and systems.
