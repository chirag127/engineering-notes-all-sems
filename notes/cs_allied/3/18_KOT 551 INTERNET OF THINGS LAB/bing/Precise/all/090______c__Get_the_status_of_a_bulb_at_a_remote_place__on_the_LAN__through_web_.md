#### c) Get the status of a bulb at a remote place (on the LAN) through web.

To get the status of a bulb at a remote place on the LAN through the web, the following steps can be taken:

1. **Connect the bulb to the network:** The bulb must be connected to the local area network (LAN) and have an IP address assigned to it.

2. **Set up a web server:** A web server must be set up on the network, which can communicate with the bulb and retrieve its status.

3. **Create a web page:** A web page must be created, which can send a request to the web server to retrieve the status of the bulb.

4. **Send a request to the web server:** The web page sends a request to the web server to retrieve the status of the bulb.

5. **Retrieve the status of the bulb:** The web server communicates with the bulb and retrieves its status.

6. **Display the status of the bulb:** The web server sends the status of the bulb back to the web page, which displays it to the user.

In summary, to get the status of a bulb at a remote place on the LAN through the web, the bulb must be connected to the network, a web server must be set up to communicate with the bulb, a web page must be created to send a request to the web server, and the web server must retrieve and send the status of the bulb back to the web page for display to the user.
