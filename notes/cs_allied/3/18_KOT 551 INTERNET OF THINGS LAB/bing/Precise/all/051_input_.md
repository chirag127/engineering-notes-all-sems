# Input

- Input refers to the data or information that is entered into a computer system for processing.
- Input devices are the hardware components that allow users to enter data into a computer. Examples of input devices include keyboards, mice, touchscreens, and microphones.
- Input can also come from other sources, such as files, network connections, or sensors.
- The input data is processed by the computer's central processing unit (CPU) and then stored in memory or on a storage device.
- Input is an essential part of any computer system, as it allows users to interact with the system and provide the data needed for the system to perform its functions.
- The type of input required by a computer system depends on the tasks it is designed to perform. For example, a word processing program requires text input, while a graphics program requires input in the form of images or drawings.
- Input can be entered into a computer system in a variety of ways, including typing on a keyboard, speaking into a microphone, or using a touchscreen to draw or select options.
- The quality of the input data can affect the accuracy and reliability of the computer system's output. It is important to ensure that the input data is accurate and free from errors.
