# Get the status of a bulb at a remote place (on the LAN) through web

To get the status of a bulb at a remote place (on the LAN) through the web, the following steps can be followed:

1. **Connect to the LAN:** Ensure that the device used to check the status of the bulb is connected to the same Local Area Network (LAN) as the bulb.

2. **Access the bulb's web interface:** The bulb should have a web interface that can be accessed through a web browser. Enter the IP address of the bulb in the web browser to access its web interface.

3. **Check the bulb's status:** Once the web interface is accessed, the status of the bulb can be checked. The status may be displayed on the web interface, or it may be necessary to navigate through the interface to find the status.

4. **Interpret the status:** The status of the bulb may be displayed in different ways, such as text, color, or an icon. Interpret the status according to the bulb's documentation.
