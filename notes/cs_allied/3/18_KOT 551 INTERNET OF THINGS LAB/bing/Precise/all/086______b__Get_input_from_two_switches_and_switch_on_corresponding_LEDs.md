#### b) Get input from two switches and switch on corresponding LEDs

To get input from two switches and switch on corresponding LEDs, follow these steps:

1. Connect the two switches to the input pins of the microcontroller.
2. Connect the two LEDs to the output pins of the microcontroller.
3. Write a program to read the input from the switches.
4. If the first switch is pressed, turn on the first LED.
5. If the second switch is pressed, turn on the second LED.
6. If both switches are pressed, turn on both LEDs.
7. If neither switch is pressed, turn off both LEDs.

This is a simple way to get input from two switches and switch on corresponding LEDs. You can modify the program to add more functionality or to change the behavior of the LEDs. For example, you could make the LEDs blink or change color depending on the input from the switches.
