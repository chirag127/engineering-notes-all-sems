#### c) Word and character count of a given string.

- Word count refers to the number of words in a given string.
- Character count refers to the number of characters in a given string.
- To count the number of words in a string, one can split the string into a list of words using a delimiter such as a space, and then find the length of the list.
- To count the number of characters in a string, one can simply find the length of the string.
- For example, consider the string "Hello, world!". The word count of this string is 2, as it contains two words separated by a space. The character count of this string is 13, as it contains 13 characters including punctuation and spaces.
- It is important to note that the definition of a "word" may vary depending on the context. Some may consider only alphabetic characters as words, while others may include numbers and punctuation as well.
- Similarly, the definition of a "character" may also vary. Some may consider only visible characters, while others may include whitespace and control characters as well.
