#### Interval of 10 seconds

#### Read a file line by line and print the word count of each line
- To read a file line by line, one can use a loop to iterate over each line in the file.
- The word count of each line can be calculated by splitting the line into words using a delimiter such as a space or a comma, and counting the number of resulting words.
- The word count can then be printed for each line as it is read from the file.
- This can be useful for analyzing the contents of a text file, such as counting the frequency of words or identifying patterns in the text.
