# Get the status of a bulb at a remote place (on the LAN) through web

1. To get the status of a bulb at a remote place on the LAN through the web, the bulb must be a smart bulb that can connect to the internet.
2. The smart bulb must be connected to the same LAN as the device being used to check its status.
3. The smart bulb must have an IP address assigned to it on the LAN.
4. The user must know the IP address of the smart bulb.
5. The user can then use a web browser to navigate to the IP address of the smart bulb.
6. The web page of the smart bulb should display its current status, whether it is on or off.
7. The user can also use a mobile application provided by the manufacturer of the smart bulb to check its status.
8. The mobile application must be connected to the same LAN as the smart bulb.
9. The mobile application will display the current status of the smart bulb.
10. The user can also use a home automation system to check the status of the smart bulb.
11. The home automation system must be connected to the same LAN as the smart bulb.
12. The home automation system will display the current status of the smart bulb.
