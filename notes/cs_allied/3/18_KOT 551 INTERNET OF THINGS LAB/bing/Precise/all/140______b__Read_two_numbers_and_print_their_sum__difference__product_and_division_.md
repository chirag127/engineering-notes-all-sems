#### b) Read two numbers and print their sum, difference, product and division.

To solve this problem, we need to follow these steps:

1. Read two numbers from the user. This can be done using the `input()` function in Python, for example.
2. Calculate the sum of the two numbers by adding them together using the `+` operator.
3. Calculate the difference of the two numbers by subtracting one from the other using the `-` operator.
4. Calculate the product of the two numbers by multiplying them together using the `*` operator.
5. Calculate the division of the two numbers by dividing one by the other using the `/` operator.
6. Print the results of the calculations to the screen using the `print()` function.

Here is an example of how this can be implemented in Python:

```python
# Read two numbers from the user
num1 = float(input("Enter the first number: "))
num2 = float(input("Enter the second number: "))

# Calculate the sum, difference, product, and division
sum = num1 + num2
difference = num1 - num2
product = num1 * num2
division = num1 / num2

# Print the results
print("Sum:", sum)
print("Difference:", difference)
print("Product:", product)
print("Division:", division)
```

This code reads two numbers from the user, performs the necessary calculations, and prints the results to the screen. The user can then see the sum, difference, product, and division of the two numbers they entered.
