# Get the status of a bulb at a remote place (on the LAN) through web

To get the status of a bulb at a remote place on the LAN through the web, the following steps can be followed:

1. **Connect the bulb to the LAN**: The bulb must be connected to the Local Area Network (LAN) through a wired or wireless connection.

2. **Assign an IP address to the bulb**: The bulb must be assigned an IP address on the LAN so that it can be accessed remotely.

3. **Set up a web server on the bulb**: A web server must be set up on the bulb to allow remote access to its status.

4. **Access the bulb's web server**: The bulb's web server can be accessed by entering its IP address into a web browser.

5. **View the bulb's status**: The bulb's status can be viewed on the web page served by its web server.

By following these steps, the status of a bulb at a remote place on the LAN can be accessed through the web.
