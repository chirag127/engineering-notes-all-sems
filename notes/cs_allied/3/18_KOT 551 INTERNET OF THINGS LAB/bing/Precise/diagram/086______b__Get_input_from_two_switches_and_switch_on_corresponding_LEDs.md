#### b) Get input from two switches and switch on corresponding LEDs

To get input from two switches and switch on corresponding LEDs, the following steps can be followed:

1. Connect the two switches to the input pins of the microcontroller.
2. Connect the two LEDs to the output pins of the microcontroller.
3. Write a program to read the input from the switches and turn on the corresponding LED based on the switch input.
4. Upload the program to the microcontroller and run it.
5. When a switch is pressed, the corresponding LED should turn on.

This is a simple example of how to get input from switches and control LEDs using a microcontroller. The specific details of the implementation may vary depending on the microcontroller and the programming language used.
