#### a) Read your name and print Hello message with name

To read your name and print a Hello message with your name, you can follow these steps:

1. Ask the user for their name using an input prompt. For example, in Python, you can use the `input()` function to read the user's name as a string.
2. Store the user's name in a variable.
3. Use the stored name to print a personalized Hello message. For example, in Python, you can use the `print()` function to display the message.

Here is an example code snippet in Python that demonstrates how to read the user's name and print a Hello message with their name:

```python
name = input("What is your name? ")
print("Hello, " + name + "!")
```

In this example, the `input()` function is used to prompt the user for their name, which is then stored in the `name` variable. The `print()` function is then used to display a personalized Hello message that includes the user's name.
