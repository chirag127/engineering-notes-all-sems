# Read your name and print Hello message with name

1. To read your name, you can use the `input()` function in Python. This function prompts the user to enter a value, which is then stored as a string.
2. To print the Hello message with the name, you can use the `print()` function in Python. This function outputs the specified message to the screen.
3. You can combine the two functions to read the user's name and then print the Hello message with the name.

Here is an example of how this can be done:

```python
name = input("Enter your name: ")
print("Hello, " + name + "!")
```

In this example, the user is prompted to enter their name. The entered name is then stored in the `name` variable. The `print()` function is then used to output the Hello message with the name.
