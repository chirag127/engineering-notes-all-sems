#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- **ls**: This command is used to list the contents of a directory. By default, it lists the contents of the current directory.
- **cd**: This command is used to change the current working directory. For example, `cd Documents` will change the current working directory to the `Documents` directory.
- **touch**: This command is used to create a new, empty file. For example, `touch newfile.txt` will create a new file named `newfile.txt` in the current working directory.
- **mv**: This command is used to move or rename files or directories. For example, `mv file1.txt file2.txt` will rename `file1.txt` to `file2.txt`, while `mv file.txt Documents/` will move `file.txt` to the `Documents` directory.
- **rm**: This command is used to remove files or directories. For example, `rm file.txt` will remove the file named `file.txt` from the current working directory.
- **man**: This command is used to display the manual page for a command. For example, `man ls` will display the manual page for the `ls` command, which provides detailed information about the command and its usage.

These are some basic Linux commands that can be used in the command terminal window of a Raspberry Pi. It is recommended to try these commands and experiment with their usage to become familiar with the Linux command line interface.
