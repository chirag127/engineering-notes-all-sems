#### b) Get input from two switches and switch on corresponding LEDs

To get input from two switches and switch on corresponding LEDs, the following steps can be followed:

1. Connect the two switches to the input pins of the microcontroller.
2. Connect the two LEDs to the output pins of the microcontroller.
3. Write a program to read the input from the switches and turn on the corresponding LEDs based on the input.
4. Upload the program to the microcontroller and run it.
5. When the switches are pressed, the corresponding LEDs should turn on.

This is a simple example of how to get input from switches and control LEDs using a microcontroller. More complex programs can be written to achieve more advanced functionality.
