#### 1. Start Raspberry Pi and try various Linux commands in command terminal window: ls, cd, touch, mv, rm, man

- **ls**: This command is used to list the contents of a directory. By default, it will list the contents of the current directory.
- **cd**: This command is used to change the current directory. You can navigate to a different directory by specifying its path as an argument to the `cd` command.
- **touch**: This command is used to create a new, empty file. You can specify the name of the file you want to create as an argument to the `touch` command.
- **mv**: This command is used to move or rename files and directories. You can specify the source and destination as arguments to the `mv` command.
- **rm**: This command is used to remove files and directories. You can specify the name of the file or directory you want to remove as an argument to the `rm` command.
- **man**: This command is used to display the manual page for a command. You can specify the name of the command you want to learn more about as an argument to the `man` command.

These are some basic Linux commands that you can try on your Raspberry Pi. They can help you navigate the file system, create and manage files, and learn more about the commands available on your system.
