# CO 5 Examine various SQL queries from MySQL database K4, K5

- SQL (Structured Query Language) is a standard language used to manage and manipulate data stored in relational databases.
- MySQL is an open-source relational database management system that uses SQL to interact with the data stored in its databases.
- There are several types of SQL queries that can be used to interact with a MySQL database, including:
  - SELECT: used to retrieve data from one or more tables in the database.
  - INSERT: used to add new records to a table in the database.
  - UPDATE: used to modify existing records in a table in the database.
  - DELETE: used to remove records from a table in the database.
  - CREATE: used to create new tables, views, or other objects in the database.
  - ALTER: used to modify the structure of an existing table or other object in the database.
  - DROP: used to remove tables, views, or other objects from the database.
- These queries can be combined with various clauses and operators to perform complex operations on the data stored in a MySQL database.
- It is important to carefully examine and test SQL queries before executing them on a live database to ensure that they produce the desired results and do not cause unintended consequences.
