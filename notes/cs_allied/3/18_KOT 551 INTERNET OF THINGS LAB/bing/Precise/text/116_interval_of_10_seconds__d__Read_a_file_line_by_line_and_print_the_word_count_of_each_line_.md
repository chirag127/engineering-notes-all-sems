# Reading a file line by line and printing the word count of each line

To read a file line by line and print the word count of each line, the following steps can be followed:

1. Open the file in read mode using a file handling function.
2. Use a loop to iterate over each line in the file.
3. For each line, use a string function to split the line into words.
4. Count the number of words in the line.
5. Print the word count for the line.
6. Continue iterating over the remaining lines in the file until the end of the file is reached.
7. Close the file.

This process allows for the efficient reading and processing of a file, line by line, to determine the word count of each line. It can be useful for text analysis and processing tasks.
