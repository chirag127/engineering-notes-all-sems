#### Using for and while loops
- `for` and `while` loops are used to iterate over a block of code multiple times.
- The `for` loop is used when the number of iterations is known beforehand.
- The `while` loop is used when the number of iterations is not known beforehand and the loop continues until a certain condition is met.

#### Handle Divided by Zero Exception
- Dividing by zero is not allowed in mathematics and will result in an error in most programming languages.
- To handle a divided by zero exception, you can use a conditional statement to check if the denominator is zero before performing the division.
- If the denominator is zero, you can handle the exception by displaying an error message or performing an alternative calculation.

#### Print current time for 10 times with an interval
- To print the current time for 10 times with an interval, you can use a `for` loop to iterate 10 times.
- Inside the loop, you can use the `time` module to get the current time and print it.
- You can use the `sleep` function from the `time` module to introduce a delay between each iteration of the loop.
