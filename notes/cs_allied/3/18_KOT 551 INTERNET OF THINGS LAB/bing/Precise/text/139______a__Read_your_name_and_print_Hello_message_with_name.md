#### a) Read your name and print Hello message with name

1. To read your name, you can use the `input()` function in Python. This function prompts the user to enter some data and returns the data as a string.
2. To print the Hello message with your name, you can use the `print()` function in Python. This function outputs the specified message to the screen.
3. Here is an example of how you can read your name and print a Hello message with your name in Python:

```python
name = input("Enter your name: ")
print("Hello, " + name + "!")
```

In this example, the `input()` function prompts the user to enter their name. The entered name is then stored in the `name` variable. The `print()` function is then used to output the Hello message with the user's name.
