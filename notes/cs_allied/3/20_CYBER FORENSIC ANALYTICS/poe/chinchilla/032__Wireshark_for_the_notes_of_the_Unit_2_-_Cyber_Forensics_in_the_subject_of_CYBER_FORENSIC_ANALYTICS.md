### Wireshark for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

Wireshark is a widely used network protocol analyzer tool that is used in the field of cyber forensics for capturing and analyzing network traffic. It is an open-source tool that can be used on different operating systems like Windows, Linux, and macOS. Here are some important points to keep in mind while using Wireshark for cyber forensic analysis:

- Wireshark can capture network traffic in real-time or from a saved file. It can capture traffic from various sources like Ethernet, WLAN, Bluetooth, and USB.
- Wireshark provides various filters that can be used to analyze specific network traffic. These filters include filters based on network addresses, protocols, and ports.
- Wireshark can also be used to decrypt SSL/TLS encrypted traffic by using the appropriate private key or session key.
- Wireshark provides various statistical tools that can be used to analyze network traffic. These tools include protocol hierarchy, endpoint statistics, and conversation statistics.
- Wireshark can also be used to extract files that are transmitted over the network. It can extract files from protocols like HTTP, FTP, and SMB.
- Wireshark provides various output formats that can be used to export the captured data for further analysis. These output formats include CSV, XML, and JSON.
- Wireshark can be used to analyze network traffic for different purposes like intrusion detection, network troubleshooting, and cyber forensic investigations.
- Wireshark can also be extended by using various plugins and scripts, which can be used to add new features and functionality to the tool.

In conclusion, Wireshark is an essential tool for cyber forensic analysts as it provides a comprehensive set of features for analyzing network traffic. By familiarizing oneself with Wireshark and its capabilities, one can conduct effective cyber forensic investigations and identify potential security threats.
