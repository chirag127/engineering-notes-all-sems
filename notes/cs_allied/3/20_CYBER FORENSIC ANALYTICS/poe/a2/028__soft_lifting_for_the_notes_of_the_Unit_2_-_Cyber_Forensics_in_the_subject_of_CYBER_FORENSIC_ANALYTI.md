### Soft lifting for the notes of the Unit 2 - Cyber Forensics

1. Data Acquisition: The process of legally obtaining data or evidence from computing devices to forensically analyze. This is done using write blockers to prevent modification of original evidence. Image acquisition and live acquisition are two methods.
2. Data Analysis: The process of inspecting data to find relevant information for a forensic investigation. This is done using various tools and techniques to uncover hidden, deleted, or encrypted data. Databases, logs, and metadata are analyzed.
3. Media Analysis: The analysis of storage media to recover deleted or hidden data. This involves analyzing the internal structure of the media to find traces of old data. Common tools include disk editors, file carvers, and data recovery tools.
4. Network Forensics: The process of investigating network traffic and network devices to find network-related attacks or anomalies. This involves capturing network traffic and analyzing it to find suspicious behavior and extract artifacts. Network devices are also analyzed for configuration issues or other problems.
5. Software Forensics: The analysis of software on a system to find security issues, malware, or other relevant information for a forensic investigation. This includes analyzing running processes, installed applications, and domain name system (DNS) data.
