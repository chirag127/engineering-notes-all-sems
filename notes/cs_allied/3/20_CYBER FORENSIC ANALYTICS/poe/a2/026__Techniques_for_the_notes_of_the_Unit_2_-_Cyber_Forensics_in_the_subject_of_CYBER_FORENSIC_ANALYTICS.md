### Techniques for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS.

1. Live Forensics: Examining a running system to collect volatile data like running processes, network connections, etc. This is done using live forensics tools.
2. Dead Forensics: Examining a non-running system to collect data from the hard drive. This is done using forensic imaging tools to take a bit-by-bit copy of the hard drive and then analyze it.
3. Network Forensics: Examining network traffic to look for anomalies and collect data for forensic analysis. This is done using network monitoring and packet capture tools.
4. Memory Forensics: Examining the computer memory (RAM) to collect evidence. This volatile data is captured using memory acquisition tools and analyzed using memory forensics tools.
5. Software Forensics: Examining software-related artifacts like installed applications, log files, etc. to gather forensic evidence. This is done using tools to analyze the hard drive and registry.
6. Multimedia Forensics: Examining multimedia files like images, videos, audio, etc. to gather forensic evidence. This is done using multimedia forensics tools to recover metadata and analyze the files.

The above points cover the major techniques used in digital forensics to gather evidence from a system or device. The appropriate tools and techniques are applied based on the specific requirements of an investigation.
