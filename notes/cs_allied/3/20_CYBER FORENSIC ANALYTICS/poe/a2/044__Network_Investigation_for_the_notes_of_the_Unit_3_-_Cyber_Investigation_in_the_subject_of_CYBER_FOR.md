### Network Investigation

Notes for Unit 3 - Cyber Investigation, Cyber Forensic Analytics

1. Collect network data: Analyze router, firewall and proxy logs to understand network traffic and reconstruct user activity. Correlate network data with data from other sources like system logs and application logs.
2. Analyze network traffic: Use packet capturing and network monitoring tools to capture network traffic and analyze protocols, source/destination addresses and ports etc. to detect anomalies and malicious traffic.
3. Trace network connections: Trace connections between different systems/devices in the network to map out the network, detect unauthorized devices and analyze connectivity during specific time periods of interest.
4. Analyze network devices: Forensically analyze router, switch, firewall and other network devices to recover configuration details, connection logs, VPN logs etc. that can provide contextual information about the network and user activity.
5. Correlate data across network layers: Correlate data from different layers of the network stack like packets, logs, device configurations, application activity etc. to get a holistic view of the network and user behavior. This can help in detecting complex attacks or malicious insider activity traversing the network.

The above points cover the key steps involved in network investigation as part of cyber forensic analysis. Detailed tools and techniques can be explored under each step for collecting and analyzing data from the various components of a computer network. Network investigation, when combined with other data sources, can provide a more comprehensive view of the cyber attack lifecycle or suspicious user activity.
