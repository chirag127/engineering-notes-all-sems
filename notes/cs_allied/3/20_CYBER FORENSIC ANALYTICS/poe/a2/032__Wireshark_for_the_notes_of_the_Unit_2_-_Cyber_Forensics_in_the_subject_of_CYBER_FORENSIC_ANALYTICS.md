### Wireshark for the notes of the Unit 2 - Cyber Forensics

1. Wireshark is a network protocol analyzer. It lets you see what's happening on your network at a microscopic level. It is the de facto (and often de jure) standard across many industries and educational institutions.

2. Wireshark uses a simple, efficient user interface to capture and interactively browse packets sent or received on a network. It can filter and color rules the packets to highlight important information.

3. Some uses of Wireshark are:

- Troubleshooting network issues.
- Monitoring network usage.
- Analysis of network attacks like MITM, sniffing etc.
- Forensic analysis of network traffic.
- Learning about network protocols by observing real world traffic.

4. To use Wireshark, you need to:

- Install Wireshark on your system.
- Select an appropriate network interface to capture traffic from. Either wired or wireless.
- Start capture by clicking on the capture options and then Start.
- Analyze the packets in the hierarchical tree-like view, filter and apply coloring rules to focus on the relevant packets.
- Decode the packets to understand the network conversation.

5. Some important features of Wireshark are:

- It can decode too many protocols to list. Almost every protocol in use on networks today is supported.
- It provides very efficient filtering and coloring rules. This enables you to drill down to the exact traffic you want to analyze.
- It can export captured data to various formats to analyze in other tools. This enables advanced analysis or integration with other tools.
- It has a rich system of dissectors which can decode application level data for many protocols. So you can see not just raw network data but actual email messages, web pages, chat messages etc.
