### Digital signature for the notes of the Unit 5 - Cyber Laws and Authorities in the subject of CYBER FORENSIC ANALYTICS.

1. A digital signature is an electronic signature based on cryptographic methods of originator authentication, computed by using a set of rules and a pair of keys, each having mathematical properties.
2. Digital signatures provide integrity, authenticity as well as non-repudiation.
3. The components of a digital signature are:
- Message: The information being signed.
- Signature algorithm: An algorithm for generating signatures.
- Private key: A key known only to the signer used to generate the signature.
- Digital signature: A value generated from the message and private key that binds them together.
4. Steps to generate a digital signature:
- Hash the message using SHA-1 or SHA-256 to get a message digest.
- Encrypt the message digest using the private key to get the digital signature.
- Attach the digital signature to the message.
5. Steps to verify a digital signature:
- Extract the message digest from the digital signature using the public key.
- Hash the message using the same algorithm as the sender.
- Compare the two message digests. If same, the signature is valid. If not, the message has been tampered with.
