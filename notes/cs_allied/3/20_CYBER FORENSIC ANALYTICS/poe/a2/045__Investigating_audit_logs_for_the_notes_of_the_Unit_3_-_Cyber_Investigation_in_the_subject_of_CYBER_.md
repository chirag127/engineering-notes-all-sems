### Investigating audit logs for the notes of the Unit 3 - Cyber Investigation in the subject of CYBER FORENSIC ANALYTICS

1. Audit logs are records of system activities, changes, access attempts, etc. They can provide a valuable timeline of events and help in investigating cybercrimes.
2. Some common types of audit logs to look for in an investigation are:
- Authentication logs: Logs of successful and failed login attempts which can indicate breaches or hacking attempts.
- Account management logs: Logs of account creation, modification, disabling which can indicate insider threats or compromised accounts.
- File access logs: Logs of file accesses, modifications or deletions which can indicate data exfiltration or tampering.
- Network activity logs: Logs of incoming and outgoing network connections which can indicate data transfer or connections to malicious domains.
3. Analyzing audit logs requires looking for anomalous patterns or suspicious activity trails. Some techniques for analyzing audit logs are:
- Sorting and filtering: Sorting by time, user, activity, outcome, etc. and filtering by specific users, time periods or activities can reveal significant events.
- Correlation: Correlating between different log types or from multiple systems can reveal linked malicious events.
- Baselining: Analyzing regular activity patterns and flagging significant deviations from the baseline can identify abnormal activity.
- Payload analysis: Log entries may contain user input data or extracted payload which can be analyzed for malicious content.

4. Challenges in investigating audit logs include large volume of logs, disparate log formats, missing logs, log tampering, etc. Appropriate tools and techniques need to be employed to efficiently analyze audit logs and uncover relevant evidence.
