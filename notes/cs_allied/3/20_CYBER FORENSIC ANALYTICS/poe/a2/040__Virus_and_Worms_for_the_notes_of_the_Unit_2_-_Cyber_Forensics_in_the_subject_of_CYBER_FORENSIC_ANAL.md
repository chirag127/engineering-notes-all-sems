### Virus and Worms

- **Virus**: A virus is a malicious program that attaches itself to a host program and gets executed when the host program is run. It then infects other programs or files and spreads. Some of the activities performed by viruses are corrupting or deleting data, modifying programs, etc.
- **Worms**: A worm is a standalone malicious program that replicates itself and spreads independently over a network, without attaching itself to a host program. Worms spread by exploiting security vulnerabilities in the target systems. Some activities performed by worms are using up computer resources, sending out spam emails, etc.
- Differences between virus and worms:
    - Viruses attach themselves to host programs while worms are standalone programs.
    - Viruses require the host program to execute and spread while worms can spread independently.
    - Viruses infect other programs or files while worms replicate themselves.
- Both viruses and worms are types of malware that can have malicious intents and consequences like corrupting data, modifying programs, spamming, etc. Proper security measures should be taken to prevent infection from such malicious software.
