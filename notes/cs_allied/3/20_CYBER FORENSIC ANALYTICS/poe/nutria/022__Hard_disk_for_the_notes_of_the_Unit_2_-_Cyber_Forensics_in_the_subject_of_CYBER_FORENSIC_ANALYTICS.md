
### Hard Disk for the Notes of the Unit 2 - Cyber Forensics in the Subject of CYBER FORENSIC ANALYTICS 

1. A hard disk is a physical storage device used to store digital data. It is made up of magnetic media, which can be read and written to by a computer. 
2. Hard disks are used to store large amounts of data, such as operating systems, programs, and user data. 
3. Hard disks are divided into sectors, which are the smallest addressable unit of data on the disk. Each sector contains 512 bytes of data. 
4. Hard disks can be divided into partitions, which are logical divisions of the disk. Each partition can be used to store different types of data.
5. Data stored on a hard disk is organized into files and folders. Files are the smallest unit of data that can be stored on a hard disk. 
6. Data stored on a hard disk can be accessed using file systems, which are used to store and organize files and folders. 
7. Data stored on a hard disk can be protected using encryption, which is used to make the data unreadable to unauthorized users. 
8. Data stored on a hard disk can be backed up, which is the process of creating a copy of the data to protect against data loss. 
9. Cyber forensics is the process of using digital forensic techniques to investigate cybercrime. 
10. Cyber forensics involves the collection, analysis, and preservation of digital evidence from computers and digital storage devices. 
11. Cyber forensics can be used to investigate cybercrimes such as data theft, fraud, and cyberbullying. 
12. Cyber forensic analysts use a variety of tools and techniques to analyze digital evidence, such as disk imaging and file carving. 
13. Cyber forensic analysts must be familiar with the legal aspects of cybercrime, such as the laws and regulations related to data privacy and digital evidence.
