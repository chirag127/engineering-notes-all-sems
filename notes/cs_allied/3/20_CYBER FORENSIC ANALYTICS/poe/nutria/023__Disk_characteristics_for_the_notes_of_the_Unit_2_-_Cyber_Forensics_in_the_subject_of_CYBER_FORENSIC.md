
### Disk Characteristics for Unit 2 - Cyber Forensics

1. Hard Disk Drives (HDD): Hard Disk Drives are the most common type of disk drive used for storing data. They are composed of multiple spinning disks, or platters, that store data magnetically. HDDs are relatively inexpensive, but they are slower and less reliable than other types of disk drives.

2. Solid-State Drives (SSD): Solid-State Drives are a newer type of disk drive that use non-volatile memory chips to store data. SSDs are much faster than HDDs, but they are also more expensive.

3. Hybrid Drives: Hybrid Drives combine the speed of SSDs with the storage capacity of HDDs. They are more expensive than either type of drive alone, but they offer a good balance of performance and capacity.

4. RAID: RAID stands for Redundant Array of Independent Disks. It is a technology that allows multiple disks to be combined into a single logical drive. RAID provides improved performance, reliability, and data redundancy.

5. File System: A file system is a set of rules and conventions for organizing and storing data on a disk. Popular file systems include NTFS, FAT32, and ext4.

6. Data Recovery: Data recovery is the process of retrieving data from a damaged or corrupted disk. Data recovery tools can be used to recover data from a malfunctioning drive or to restore data that was accidentally deleted.
