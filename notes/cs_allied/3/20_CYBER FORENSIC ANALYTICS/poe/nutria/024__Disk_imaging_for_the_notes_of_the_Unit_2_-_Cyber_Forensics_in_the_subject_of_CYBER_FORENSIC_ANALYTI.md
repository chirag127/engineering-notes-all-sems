
### Disk Imaging for the Notes of Unit 2 - Cyber Forensics in the Subject of CYBER FORENSIC ANALYTICS

1. Disk imaging is the process of creating an exact copy of a storage device, such as a hard disk drive, or a logical volume. 
2. The disk image contains all the data stored on the disk, including the operating system, applications, and user data. 
3. Disk imaging is used in cyber forensics to preserve evidence and to create a backup of data that can be used if the original data is lost or damaged.
4. Disk imaging can be done using specialized software or hardware tools.
5. The imaging process involves reading the data from the disk and writing it to a file, which is known as an image file.
6. The image file can be compressed to save disk space, or it can be split into multiple files for easier storage.
7. Once the disk image is created, it can be used to restore the disk to its original state.
8. Disk imaging is also used to clone disks for backup and disaster recovery purposes.
