### Network Components for the Notes of Unit 2 - Cyber Forensics

In the field of cyber forensics, understanding the different network components is important. Here are the key components to consider:

- **Switches:** These are devices that connect multiple computers together in a network. They are responsible for forwarding data packets between devices and can be used to monitor network traffic.

- **Routers:** Routers are responsible for directing network traffic between different networks. They can also be used to filter and monitor traffic.

- **Firewalls:** Firewalls are security devices that monitor and control incoming and outgoing network traffic. They can be used to block unauthorized access and to detect and prevent attacks.

- **Intrusion Detection Systems (IDS):** IDSs are devices that monitor network traffic for signs of unauthorized access or malicious activity. They can be used to alert administrators to potential security threats.

- **Intrusion Prevention Systems (IPS):** IPSs are similar to IDSs, but they also have the ability to take action to prevent attacks. They can be used to block traffic from specific IP addresses or to stop certain types of traffic altogether.

- **Virtual Private Networks (VPNs):** VPNs are used to create a secure connection between two networks over the internet. They can be used to protect sensitive data from unauthorized access.

- **Domain Name System (DNS):** DNS is a system that translates domain names into IP addresses. It is essential for navigating the internet and can also be used to monitor network traffic.

- **Network Address Translation (NAT):** NAT is a technique used to map public IP addresses to private IP addresses. It is used to conserve public IP addresses and can also be used to hide the identity of devices on a network.

By understanding these network components, cyber forensic analysts can better investigate security incidents and identify potential threats.
