### Port Scans

Port scanning is a technique used to identify open ports and services available on a network host. It is commonly used for reconnaissance and is one of the first steps an attacker takes to find potential vulnerabilities on a target system.

Here are some key points to remember about port scanning:

1. Port scanning can be done using various tools, such as Nmap, which is a popular open-source tool for network exploration and security auditing.
2. Port scanning can be performed on both TCP and UDP ports.
3. There are several types of port scans, including TCP connect scan, SYN scan, FIN scan, Xmas scan, and Null scan.
4. Port scanning can be detected and prevented using firewalls and intrusion detection systems.
5. Port scanning is not illegal, but it can be considered suspicious activity and may violate the terms of service of some networks.
