# Stored Values Cards

Stored value cards are a type of electronic payment card that stores a monetary value on the card itself. They are commonly used for transactions where anonymity is desired, such as online purchases or gift cards. Stored value cards can be reloadable or non-reloadable, and can be used at a variety of merchants.

## Types of Stored Value Cards

There are two main types of stored value cards: closed system and open system.

1. **Closed System Stored Value Cards** are cards that can only be used at a specific merchant or group of merchants. Examples of closed system stored value cards include gift cards and transit cards.

2. **Open System Stored Value Cards** are cards that can be used at any merchant that accepts the card brand. Examples of open system stored value cards include prepaid debit cards and some types of travel cards.

## Use in Cyber Crime

Stored value cards can be used in various types of cyber crime, including:

1. **Money Laundering:** Criminals can use stored value cards to move funds anonymously, making it difficult for law enforcement to trace the source of the funds.

2. **Fraud:** Criminals can use stolen credit card information to purchase stored value cards, which can then be used to make purchases without being traced.

3. **Identity Theft:** Criminals can use stored value cards to make purchases using a stolen identity, without the need for a bank account or credit check.

## Prevention and Detection

There are several measures that can be taken to prevent and detect the use of stored value cards in cyber crime, including:

1. **Monitoring:** Financial institutions and merchants can monitor transactions for suspicious activity, such as large or frequent purchases of stored value cards.

2. **Verification:** Merchants can require identification or other forms of verification when selling stored value cards, to prevent the use of stolen credit card information.

3. **Reporting:** Financial institutions and merchants are required to report suspicious activity to the appropriate authorities, to aid in the detection and prevention of cyber crime.

In summary, stored value cards are a type of electronic payment card that can be used for anonymous transactions. They can be used in various types of cyber crime, including money laundering, fraud, and identity theft. Measures such as monitoring, verification, and reporting can help prevent and detect the use of stored value cards in cyber crime.
