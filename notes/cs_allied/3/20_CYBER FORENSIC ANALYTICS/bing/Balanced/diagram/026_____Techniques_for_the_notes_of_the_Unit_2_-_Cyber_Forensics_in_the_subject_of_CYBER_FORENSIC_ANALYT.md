### Techniques for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

Cyber forensics is the process of collecting, analyzing, and presenting digital evidence from electronic devices in a way that is legally admissible and scientifically valid. Cyber forensics can be used for various purposes, such as investigating cybercrimes, recovering lost or damaged data, or auditing security systems. 

Some of the techniques that cyber forensic analysts use are:

- **Disk Wiping**: This technique involves deleting all of the data on a hard drive or media storage device, either by overwriting it with random data or by physically destroying the device. Disk wiping can be used to prevent unauthorized access to sensitive data or to erase any traces of illegal activity. However, disk wiping can also be used by cybercriminals to cover their digital footprints and evade detection by forensic tools. 

- **File Encryption**: This technique involves transforming readable data into an unreadable format using various encryption algorithms and keys. File encryption can be used to protect data from unauthorized access or modification, or to comply with data privacy regulations. However, file encryption can also be used by cybercriminals to hide their malicious activities or to avoid decryption by forensic tools. 

- **Steganography**: This technique involves hiding data inside another digital file, such as an image, audio, or video file, without altering its appearance or functionality. Steganography can be used to conceal confidential information or to communicate covertly. However, steganography can also be used by cybercriminals to embed malware or to evade detection by forensic tools.   

- **Compression**: This technique involves reducing the size of a digital file by removing redundant or irrelevant data or by using mathematical algorithms. Compression can be used to save storage space or to improve transmission speed. However, compression can also be used by cybercriminals to obfuscate their data or to make it harder for forensic tools to recover or analyze it. 

- **Malware**: This technique involves using malicious software, such as viruses, worms, trojans, or ransomware, to infect, damage, or control a computer system or network. Malware can be used to steal, modify, or destroy data, or to disrupt or deny services. However, malware can also be used by cybercriminals to interfere with forensic tools or to erase or alter evidence. 

- **Recovery of Deleted Files**: This technique involves restoring data that has been deleted from a computer system or storage device, either intentionally or accidentally. Recovery of deleted files can be used to retrieve lost or corrupted data, or to recover evidence of cybercrimes. However, recovery of deleted files can also be used by cybercriminals to access data that has been erased by forensic tools or by disk wiping. 

- **Reverse Steganography**: This technique involves detecting and extracting data that has been hidden inside another digital file using steganography. Reverse steganography can be used to uncover confidential information or to expose covert communication. However, reverse steganography can also be used by cybercriminals to access data that has been concealed by forensic tools or by encryption.   

- **File Carving**: This technique involves recovering data from a storage device by scanning its raw data and identifying file headers, footers, or structures. File carving can be used to restore data that has been damaged, fragmented, or overwritten, or to recover evidence of cybercrimes. However, file carving can also be used by cybercriminals to access data that has been hidden by forensic tools or by compression. 

- **Memory Forensics**: This technique involves analyzing the data stored in the volatile memory (RAM) of a computer system or device. Memory forensics can be used to capture data that is not stored on the disk, such as passwords, encryption keys, or malware code, or to investigate the current state of a system or process. However, memory forensics can also be used by cybercriminals to access data that has been erased by forensic tools or by disk wiping.
