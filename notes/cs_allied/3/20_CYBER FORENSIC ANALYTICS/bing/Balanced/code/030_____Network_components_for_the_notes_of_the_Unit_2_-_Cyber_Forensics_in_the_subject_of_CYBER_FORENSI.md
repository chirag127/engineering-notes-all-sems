### Network components for the notes of the Unit 2 - Cyber Forensics

- Network forensics is a science that centers on the discovery and retrieval of information surrounding a cybercrime within a networked environment.
- Network forensics can help draw several conclusions during an investigation, such as the source, target, motive, and impact of cyberattacks.
- Network forensics involves the capture, recording and analysis of network packets in order to establish the evidence of cyberattacks.
- Network forensics can be performed in two modes: live and post-mortem.
  - Live forensics involves monitoring and analyzing network traffic in real-time, using tools such as network sniffers, firewalls, and intrusion detection systems (IDS).
  - Post-mortem forensics involves examining network logs, backups, and other data sources after an incident has occurred, using tools such as network analyzers, packet reconstructors, and forensic software.
- Network forensics requires a systematic approach that follows the following steps:
  - Identification: Identify the scope, nature, and source of the network incident.
  - Preservation: Preserve the network data and evidence in a secure and tamper-proof manner.
  - Extraction: Extract the relevant information from the network data and evidence.
  - Interpretation: Interpret the extracted information and reconstruct the network events and activities.
  - Documentation: Document the findings and conclusions of the network forensics analysis.
  - Presentation: Present the network forensics report and evidence to the relevant stakeholders or authorities.
- Network forensics faces several challenges, such as the large volume and complexity of network data, the dynamic and volatile nature of network traffic, the encryption and obfuscation techniques used by attackers, the legal and ethical issues of network monitoring and data collection, and the need for specialized skills and tools .
- Network forensics is a key component of digital forensics, which is the broader discipline of collecting, analyzing and presenting digital evidence in court.
- Digital forensics can be applied to various domains, such as computer forensics, mobile forensics, cloud forensics, IoT forensics, and malware forensics.
- Digital forensics is closely related to incident response, which is the process of identifying, containing, eradicating, and recovering from cyberattacks.
