### Wireshark for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

- Wireshark is a free and open-source network protocol analyzer that can capture and examine network packets and their behavior     .
- Wireshark is an essential tool for network forensics, as it can help identify network anomalies, malicious traffic, malware infections, and other network-related threats    .
- Wireshark can also be used for network troubleshooting, performance analysis, protocol development, and education .
- Wireshark has a graphical user interface (GUI) that allows users to filter, search, and visualize network data in various formats, such as tables, graphs, charts, and maps .
- Wireshark can also be run in command-line mode, using the tshark utility, which offers similar functionality as the GUI, but with more options and flexibility .
- Wireshark supports hundreds of network protocols, such as TCP, IP, HTTP, DNS, FTP, SMTP, and many more .
- Wireshark can capture network data from various sources, such as live network interfaces, offline capture files, named pipes, and remote capture devices .
- Wireshark can also export network data to various formats, such as plain text, CSV, XML, JSON, and PCAP .
- Wireshark can be extended and customized with plugins, scripts, and dissectors, which can add new functionality, protocols, and features to the tool .
- Wireshark is available for various operating systems, such as Windows, Linux, macOS, and BSD .
