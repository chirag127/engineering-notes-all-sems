### Disk characteristics for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

- Disk forensics is a branch of cyber forensics that deals with extracting data from storage media by searching active, modified, or deleted files  .
- Disk forensics can be applied to various types of storage media, such as hard disks, solid-state drives, optical disks, flash drives, memory cards, etc.
- Disk forensics can help recover evidence of cybercrimes, such as malware infection, data theft, unauthorized access, fraud, etc.
- Disk forensics can also help reconstruct the timeline of events, identify the source and destination of data, and analyze the behavior and intent of the suspects.
- Disk forensics involves several steps, such as:
  - Acquiring the disk image: This is the process of creating a bit-by-bit copy of the original storage media, which preserves the integrity and authenticity of the data .
  - Analyzing the disk image: This is the process of examining the disk image using various tools and techniques, such as file system analysis, file carving, hashing, keyword searching, etc.
  - Reporting the findings: This is the process of documenting and presenting the results of the disk analysis, such as evidence, artifacts, metadata, etc.
- Disk forensics requires specialized tools and skills, such as:
  - Disk imaging tools: These are software or hardware devices that can create and verify disk images, such as FTK Imager, dd, EnCase, etc.
  - Disk analysis tools: These are software or hardware devices that can examine and extract data from disk images, such as Autopsy, X-Ways, Sleuth Kit, etc.
  - Disk forensics knowledge: This is the understanding of the principles and methods of disk forensics, such as disk structures, file systems, data recovery, etc.
