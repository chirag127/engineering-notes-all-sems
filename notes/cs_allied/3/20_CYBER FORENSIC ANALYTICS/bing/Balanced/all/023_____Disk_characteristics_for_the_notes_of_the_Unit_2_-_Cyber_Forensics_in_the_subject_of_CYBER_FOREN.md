# Disk characteristics for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

- Disk forensics is a branch of cyber forensics that deals with extracting data from storage media by searching active, modified, or deleted files  .
- Disk forensics can be applied to various types of storage media, such as hard disks, solid state drives, optical disks, flash drives, memory cards, etc.
- Disk forensics can help in recovering evidence of cyber crimes, such as malware infection, data theft, unauthorized access, fraud, etc.
- Disk forensics can also help in identifying the source, origin, and authenticity of digital evidence, as well as the timeline and sequence of events that occurred on the storage media.
- Disk forensics involves the following steps :
  - Acquisition: This is the process of creating a copy or an image of the storage media, without altering or damaging the original data. The copy or image should be verified and authenticated using hash values or digital signatures.
  - Preservation: This is the process of storing and protecting the copy or image of the storage media from unauthorized access, modification, or deletion. The copy or image should be encrypted and stored in a secure location.
  - Analysis: This is the process of examining and interpreting the data from the copy or image of the storage media, using various tools and techniques. The analysis can reveal the file system structure, file metadata, file content, deleted files, hidden files, etc.
  - Reporting: This is the process of documenting and presenting the findings and conclusions of the analysis, using clear and concise language. The report should include the details of the acquisition, preservation, and analysis processes, as well as the evidence and its relevance to the case.
