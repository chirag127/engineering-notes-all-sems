# Investigating Web Attacks

- Web attacks are cyberattacks that target web applications, such as websites, web servers, web browsers, or web services.
- Web attacks can have various motives, such as stealing data, defacing web pages, disrupting services, extorting money, or spreading malware.
- Web attacks can exploit various vulnerabilities, such as SQL injection, cross-site scripting, cross-site request forgery, file inclusion, or denial-of-service.
- Web application forensics is the process of examining web applications and their contents to trace back the attack, identify the origin of the attack, and determine how the attack was propagated along with the devices and persons involved .
- Web application forensics involves the following steps:
  - Collecting evidence from web application logs, www directory, config files, databases, backups, and network traffic.
  - Analyzing evidence using tools, such as web proxies, web scanners, web debuggers, or web browsers.
  - Investigating evidence using techniques, such as timeline analysis, malware analysis, network analysis, or user analysis.
  - Reporting findings and recommendations using standards, such as NIST, ISO, or RFC.
- Web application forensics can help in preventing future attacks, improving web security, prosecuting cybercriminals, or recovering from damages.
