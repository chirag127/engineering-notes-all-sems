### Techniques for the notes of the Unit 2 - Cyber Forensics in the subject of CYBER FORENSIC ANALYTICS

- Cyber forensics is the process of collecting, preserving, analyzing and presenting digital evidence in a legally acceptable manner.
- Cyber forensics can be applied to various domains, such as computer forensics, network forensics, mobile forensics, cloud forensics, etc.
- Some of the techniques for cyber forensics are:

  - Data acquisition: This is the process of obtaining a copy or an image of the digital evidence from the original source, such as a hard disk, a memory card, a smartphone, etc. Data acquisition can be done in two ways: static or live. Static acquisition involves powering off the device and creating a bit-by-bit copy of the data. Live acquisition involves capturing the data from the device while it is still running, which may be necessary to preserve volatile data, such as RAM contents, network connections, etc.
  - Data preservation: This is the process of ensuring the integrity and authenticity of the digital evidence by using techniques such as hashing, encryption, write protection, etc. Data preservation prevents the evidence from being altered, deleted, or tampered with during the investigation.
  - Data analysis: This is the process of examining the digital evidence to identify, recover, and interpret relevant information. Data analysis can be done using various tools and methods, such as file carving, keyword searching, timeline analysis, malware analysis, etc. Data analysis can also involve applying different techniques depending on the type and format of the data, such as file system analysis, registry analysis, network analysis, etc.
  - Data presentation: This is the process of reporting and presenting the findings and conclusions of the cyber forensic investigation. Data presentation can be done in various formats, such as written reports, oral testimony, graphical displays, etc. Data presentation should be clear, concise, accurate, and understandable to the intended audience, such as judges, lawyers, juries, etc.
