### PCAP Analysis for the Notes of the Unit 2 - Cyber Forensics

- PCAP stands for **Packet Capture**, which is a file format that stores network traffic data, including both metadata and content of each packet .
- PCAP analysis is the process of examining the captured network traffic data using various tools and techniques, such as Wireshark, Zeek, tcpdump, etc.
- PCAP analysis can be used for various purposes in cyber forensics, such as:
  - **Collecting evidence** for investigations of digital activities, such as malware infections, network intrusions, data exfiltration, etc  .
  - **Detecting malicious network traffic and behavior**, such as intrusion attempts, network misuse, man-in-the-middle attacks, ransomware, etc.
  - **Reconstructing network events and activities**, such as web browsing, file transfers, email communications, etc .
  - **Identifying network anomalies and patterns**, such as unusual traffic volume, frequency, source, destination, protocol, etc .
  - **Troubleshooting network performance and security issues**, such as packet loss, latency, congestion, misconfiguration, etc .
- PCAP analysis can be performed in different environments, such as on-premise, cloud, hybrid, etc. However, different environments may have different challenges and requirements for capturing and analyzing network traffic data, such as access, storage, bandwidth, encryption, etc.
- PCAP analysis can be performed in different modes, such as live, offline, or hybrid. Live mode means analyzing network traffic data in real-time as it is captured, while offline mode means analyzing network traffic data that has been previously captured and stored. Hybrid mode means combining both live and offline modes.
- PCAP analysis can be performed in different levels, such as packet level, flow level, or session level. Packet level means analyzing individual packets and their headers and payloads, while flow level means analyzing aggregated packets that belong to the same network communication, such as TCP or UDP flows. Session level means analyzing higher-level network protocols and applications that use multiple flows, such as HTTP, FTP, SMTP, etc.
