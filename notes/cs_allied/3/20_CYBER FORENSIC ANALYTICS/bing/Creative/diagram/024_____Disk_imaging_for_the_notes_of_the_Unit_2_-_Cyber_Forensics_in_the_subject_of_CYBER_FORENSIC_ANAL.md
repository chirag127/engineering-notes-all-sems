### Disk imaging

- Disk imaging is the process of creating an electronic copy of a drive (e.g. a hard drive, USB, etc.) that preserves all the data and metadata in a forensics image format .
- A forensics image format is a file format that supports storing the exact, unaltered, and complete contents of a drive, including deleted or hidden data, slack space, and unallocated space .
- Some examples of forensics image formats are: E01, AFF, RAW, and DMG.
- Disk imaging is an essential step in digital forensics, as it allows investigators to analyze the data without modifying the original evidence, and to preserve the integrity and admissibility of the data in court  .
- Disk imaging can be performed using various tools, such as hardware or software imagers, that can read the drive and write the data to a forensics image file  .
- Some examples of disk imaging tools are: Tableau TD3, Computer Forensic Tool (CFT), Dc3dd, and FTK Imager.
- Disk imaging should follow some best practices, such as: verifying the hash values of the source and the image, documenting the imaging process and the chain of custody, using write blockers to prevent data alteration, and handling the drive with care to avoid physical damage  .
