### Port scans

- A port scan is a technique used by cybercriminals to find out information about a system they are going to target .
- It involves scanning through a network system and determining which ports are open, which are sending data, and which are receiving data .
- A port is a logical endpoint of communication in a network, identified by a number from 0 to 65535.
- A port scan can reveal the services, applications, and operating systems running on a system, as well as the security devices such as firewalls and intrusion detection systems .
- Port scanning can be used for legitimate purposes, such as network auditing and vulnerability assessment, but it can also be used for malicious purposes, such as reconnaissance and exploitation.
- Port scanning can be detected by monitoring network traffic and looking for anomalies, such as a large number of connection requests, unusual port numbers, or incomplete connections.
- Port scanning can be prevented by using security measures, such as blocking unused ports, filtering incoming and outgoing traffic, encrypting data, and updating software patches .
