
### Context Free Grammars

* Context Free Grammars (CFG) are a type of formal grammar used to describe the structure of a natural language.
* CFGs are composed of a set of rules that describe the structure of a sentence. 
* Each rule contains a left-hand side (LHS) and a right-hand side (RHS). The LHS is a single non-terminal symbol, while the RHS is a sequence of symbols, which can be either terminals or non-terminals.
* The non-terminal symbols represent the higher-level structure of a sentence, while the terminal symbols represent the words that make up the sentence.
* CFGs can be used to generate valid sentences from a given set of rules, as well as to parse a given sentence and determine its structure.
* CFGs are used in Natural Language Processing (NLP) to generate and parse natural language sentences.
