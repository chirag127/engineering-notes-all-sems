
### Evaluating N-grams for the notes of the Unit 1 - INTRODUCTION in the subject of NATURAL LANGUAGE PROCESSING

* N-grams are a type of language model used in Natural Language Processing (NLP). They are used to describe the probability of a sequence of words or characters.
* N-grams can be used to evaluate the performance of a language model by measuring the accuracy of the predictions.
* The accuracy of an N-gram model can be measured using various metrics such as precision, recall, and F-measure.
* N-grams can also be used to identify patterns in text and to generate new text.
* N-grams can be used to identify the most common words or phrases in a text, which can be useful for language understanding tasks such as sentiment analysis and topic identification.
* N-grams can also be used to identify the most important words in a sentence, which can be useful for tasks such as summarization and question answering.
