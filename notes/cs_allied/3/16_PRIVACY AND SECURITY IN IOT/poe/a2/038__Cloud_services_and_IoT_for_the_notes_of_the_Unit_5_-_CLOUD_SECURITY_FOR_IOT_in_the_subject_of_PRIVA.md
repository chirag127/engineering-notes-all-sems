### Cloud services and IoT for the notes of the Unit 5 - CLOUD SECURITY FOR IOT

1. Cloud services provide storage, computing power and other resources for Internet of Things (IoT) devices and applications. IoT devices can store and process data in the cloud and access powerful computing and storage resources as needed.
2. However, cloud services also introduce new security risks for IoT systems:
- Data from IoT devices is transferred to and stored in the cloud, which can be a target for attacks to steal or tamper with the data.
- IoT devices and software has to trust that the cloud service has strong security measures in place to protect their data and services. Vulnerabilities or misconfigurations in the cloud service could compromise IoT devices and applications.
- Using a cloud service means IoT systems depend on the availability and security of the service. Issues with the service could make devices or applications unusable.
3. To address these additional security risks, IoT systems using cloud services should:
- Encrypt all data in transit and at rest in the cloud
- Use strong authentication and access control for cloud services
- Ensure software updates are applied promptly to cloud services
- Have contingency plans in place for potential downtimes or issues with the cloud service
- Monitor for and respond to any suspected security incidents with the cloud service
