## Unit 2 - CRYPTOGRAPHIC FUNDAMENTALS FOR IOT

1. Symmetric-key cryptography
- Uses a single shared key to encrypt and decrypt data
- Fast and efficient but key exchange is a challenge
- Examples: AES, DES, 3DES

2. Asymmetric-key cryptography (public-key cryptography)
- Uses a public/private key pair
- Public key is shared, private key is kept secret
- Used for key exchange and digital signatures
- Examples: RSA, ECC, DSA

3. Hashing
- Uses a algorithm to create a fixed-length hash value from variable-length data
- Hash values are unique and cannot be reversed to obtain the original data
- Used to verify data integrity and authenticate data origin
- Examples: SHA-256, MD5, HMAC

4. Key management
- Generation, distribution, storage, and replacement of keys
- If keys are compromised, all data encrypted with those keys is vulnerable
- Proper key management is critical for security of cryptographic systems
