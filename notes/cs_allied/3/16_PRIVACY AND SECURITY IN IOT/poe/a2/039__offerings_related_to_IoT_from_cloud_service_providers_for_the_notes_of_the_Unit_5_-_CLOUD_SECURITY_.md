 Here are the offerings related to IoT from cloud service providers for the notes of Unit 5 - CLOUD SECURITY FOR IOT:

### Amazon Web Services (AWS)

- AWS IoT: A managed cloud platform that lets connected devices easily and securely interact with cloud applications and other devices.
- AWS IoT Device Management: Lets you securely onboard, organize, monitor, and manage IoT devices at scale.
- AWS IoT Analytics: Lets you process and analyze IoT device data at scale and get insights.
- AWS IoT Device Defender: Monitors IoT fleets for abnormal behavior and vulnerabilities to help secure IoT devices and networks.

### Microsoft Azure

- Azure IoT Hub: A managed service that lets you ingest and manage massive quantities of IoT device data. Securely connect and monitor millions of IoT devices.
- Azure IoT Central: A SaaS offering to connect IoT devices. It provides a preconfigured solution to get started in minutes with remote monitoring, device management, and predictive analytics.
- Azure IoT Security: Provides security controls and options to help protect IoT solutions from threats and vulnerabilities.
- Azure Digital Twins: A service enabling the creation of digital representations of physical environments. Model the entire physical environment and how it interacts with people and devices.

### Google Cloud

- Cloud IoT Core: A fully managed service that lets you easily and securely connect, manage, and ingest data from millions of globally dispersed devices.
- Cloud IoT Edge: Extends Cloud IoT Core capabilities to edge devices, allowing you to run machine learning and analytics code on edge devices.
- BigQuery: A data warehouse for analytics and lets you run SQL queries on IoT data.
- Pub/Sub: A messaging service to ingest and distribute IoT events and telemetry.
