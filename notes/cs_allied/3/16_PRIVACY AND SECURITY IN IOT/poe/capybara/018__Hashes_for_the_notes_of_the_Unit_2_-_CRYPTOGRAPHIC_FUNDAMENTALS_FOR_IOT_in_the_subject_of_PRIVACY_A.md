### Hashes for the notes of the Unit 2 - CRYPTOGRAPHIC FUNDAMENTALS FOR IOT in the subject of PRIVACY AND SECURITY IN IOT

- Hash functions are one of the most important cryptographic tools used in IoT security.
- A hash function is a mathematical function that takes input data of arbitrary size and produces a fixed-size output.
- The output of a hash function is often called a hash or a message digest.
- Hash functions are used to verify message integrity, ensure data authenticity, and provide non-repudiation.
- A hash function should always produce the same output for the same input, and a small change in the input should result in a completely different output.
- Some popular hash functions used in IoT security include SHA-256, SHA-384, and SHA-512.
- Hash functions are commonly used in digital signatures, password storage, and data verification.
- The security of a hash function depends on its resistance to collision attacks, preimage attacks, and second preimage attacks.
- Collision attacks occur when two different inputs produce the same hash output.
- Preimage attacks occur when an attacker tries to find an input that produces a specific hash output.
- Second preimage attacks occur when an attacker tries to find a second input that produces the same hash output as a given input.
- It is important to choose a hash function that is resistant to these types of attacks to ensure the security of IoT systems.
- When using a hash function, it is important to store the original input securely to prevent tampering or modification.
- In summary, hash functions are a critical tool in IoT security, providing message integrity, data authenticity, and non-repudiation. It is important to choose a secure hash function and properly store the original input to ensure the security of IoT systems.
