### Cryptographic Controls Built into IoT Messaging and Communication Protocols

1. **Transport Layer Security (TLS)**: TLS is a cryptographic protocol that provides secure communication over a network. It is commonly used in IoT messaging and communication protocols to provide confidentiality, integrity, and authentication.

2. **Advanced Encryption Standard (AES)**: AES is a symmetric encryption algorithm that is widely used in IoT messaging and communication protocols to provide confidentiality.

3. **Elliptic Curve Cryptography (ECC)**: ECC is an asymmetric encryption algorithm that is used in IoT messaging and communication protocols to provide authentication and key exchange.

4. **Message Authentication Code (MAC)**: MAC is a cryptographic function that is used in IoT messaging and communication protocols to provide integrity and authentication.

5. **Diffie-Hellman Key Exchange (DHKE)**: DHKE is a cryptographic protocol that is used in IoT messaging and communication protocols to provide secure key exchange.

6. **Public Key Infrastructure (PKI)**: PKI is a system that is used in IoT messaging and communication protocols to provide authentication, confidentiality, and integrity through the use of digital certificates and public key cryptography.

These are some of the cryptographic controls built into IoT messaging and communication protocols to provide security in the transmission of data. They are essential for ensuring the privacy and security of data in IoT systems.
