### Smoothing Spatial Filters for the notes of the Unit 1 - Fundamentals in the subject of IMAGE ANALYTICS

Smoothing Spatial Filters are image processing techniques used to reduce noise and smooth images. They work by replacing the intensity value of each pixel with an average of the intensity values of its surrounding pixels.

Smoothing Spatial Filters can be implemented using various methods, including:
1. Mean Filters: replace the intensity value of each pixel with the average of the intensity values of its surrounding pixels.
2. Median Filters: replace the intensity value of each pixel with the median of the intensity values of its surrounding pixels.
3. Gaussian Filters: use a Gaussian function to weight the intensity values of surrounding pixels, and replace the intensity value of each pixel with a weighted average of the intensity values of its surrounding pixels.

Smoothing Spatial Filters are widely used in image processing, and are particularly useful for reducing noise, smoothing images, and improving the visual quality of images.

In summary, Smoothing Spatial Filters are image processing techniques used to reduce noise and smooth images. They can be implemented using mean filters, median filters, and Gaussian filters, and are widely used in image processing for reducing noise, smoothing images, and improving the visual quality of images.
