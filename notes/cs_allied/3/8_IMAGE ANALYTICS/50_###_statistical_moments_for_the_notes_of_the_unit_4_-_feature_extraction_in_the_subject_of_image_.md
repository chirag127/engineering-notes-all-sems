### Statistical Moments for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

Statistical Moments are mathematical expressions that describe the distribution of values in an image or dataset. They are used in image analysis to describe the shape, size, and orientation of objects or features in an image.

The following are the commonly used statistical moments in image analysis:

1. Mean: The average value of all the pixels in an image.

2. Variance: A measure of the spread of the pixel values in an image.

3. Skewness: A measure of the asymmetry of the pixel values in an image.

4. Kurtosis: A measure of the peakedness of the pixel values in an image.

5. Hu Moments: A set of seven moments that are invariant to translation, rotation, and scaling, and are used to describe the shape of an object in an image.

Statistical moments are used to extract features from images, and they can be used to compare images and to perform image recognition and classification.

In summary, Statistical Moments are mathematical expressions that describe the distribution of values in an image or dataset, and are used in image analysis to describe the shape, size, and orientation of objects or features in an image. The commonly used statistical moments include mean, variance, skewness, kurtosis, and Hu Moments.
