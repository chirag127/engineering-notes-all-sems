### Statistical Moments for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

Statistical Moments are used in the field of Image Analytics to extract features from an image. They are used to determine the distribution of pixel values in an image, which can provide information about the texture, contrast, and other characteristics of the image.

Here are the different types of Statistical Moments that are commonly used in Image Analytics:

1. Mean: The mean of an image is the average pixel value across all the pixels in the image. It provides information about the overall brightness of the image.

2. Variance: The variance of an image is a measure of how spread out the pixel values are from the mean. It provides information about the contrast of the image.

3. Skewness: Skewness is a measure of the asymmetry of the pixel value distribution. It provides information about the shape of the image.

4. Kurtosis: Kurtosis is a measure of the peakedness of the pixel value distribution. It provides information about the sharpness of the image.

5. Energy: The energy of an image is a measure of the overall magnitude of the pixel values. It provides information about the overall complexity of the image.

6. Entropy: Entropy is a measure of the amount of information in an image. It provides information about the randomness of the image.

7. Contrast: Contrast is a measure of the difference between the maximum and minimum pixel values in an image. It provides information about the sharpness of the image.

8. Correlation: Correlation is a measure of the linear relationship between the pixel values in an image. It provides information about the texture of the image.

By using Statistical Moments, we can extract useful features from an image that can be used for various applications like object recognition, image segmentation, and image compression. It is an important concept to master in the field of Image Analytics.
