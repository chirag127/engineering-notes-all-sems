### Some Basic Descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

In the field of image analytics, feature extraction is a critical process that involves identifying and extracting meaningful information from images. This process is essential for a variety of applications, including object recognition, image retrieval, and image classification.

Here are some basic descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS:

- **Feature extraction:** Feature extraction is the process of identifying and extracting relevant information from an image. This information can be used to classify or recognize objects in an image or to extract other useful information from the image.
- **Feature descriptor:** A feature descriptor is a mathematical representation of a feature in an image. This descriptor is used to compare the feature to other features in the image or to features in other images.
- **Local feature:** A local feature is a feature that is present in a small region of an image. Local features are often used to identify objects in an image or to track the movement of objects in a video.
- **Global feature:** A global feature is a feature that is present throughout an entire image. Global features are often used to classify images or to extract information about the overall content of an image.
- **Scale-invariant feature:** A scale-invariant feature is a feature that remains the same regardless of changes in the scale of an image. These features are useful for object recognition and image retrieval, as they can be matched to similar features in other images.
- **Orientation-invariant feature:** An orientation-invariant feature is a feature that remains the same regardless of changes in the orientation of an image. These features are useful for object recognition and image retrieval, as they can be matched to similar features in other images.
- **Histogram of oriented gradients (HOG):** HOG is a feature descriptor that is used to identify the shapes and edges of objects in an image. This descriptor is often used for object recognition in computer vision applications.
- **Scale-space extrema (SIFT):** SIFT is a feature extraction algorithm that is used to identify local features in an image. This algorithm is scale-invariant and orientation-invariant, making it useful for object recognition and image retrieval.

These basic descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS are essential for understanding the process of feature extraction and its applications in image analytics. By mastering these descriptors, students can gain a deeper understanding of how feature extraction works and how it can be used to analyze images in a variety of contexts.
