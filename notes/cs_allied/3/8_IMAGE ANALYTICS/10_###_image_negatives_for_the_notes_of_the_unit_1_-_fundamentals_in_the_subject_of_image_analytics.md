### Image Negatives for the notes of the Unit 1 - Fundamentals in the subject of IMAGE ANALYTICS

An image negative is a representation of an image where the values of the pixels are inverted. In an image negative, the lightest pixels in the original image become the darkest pixels in the negative, and vice versa. Image negatives are used in image processing and computer vision for various purposes, including:

1. Image enhancement: Image negatives can be used to enhance images by making features that were previously difficult to see more visible.

2. Image segmentation: Image negatives can be used to segment images into different regions based on their intensity values.

3. Image recognition: Image negatives can be used to improve the performance of image recognition algorithms by making features that are important for recognition more distinguishable.

4. Image compression: Image negatives can be used to reduce the size of images by compressing the data in the negative representation.

In conclusion, an image negative is a representation of an image where the values of the pixels are inverted. Image negatives are used in image processing and computer vision for various purposes, including image enhancement, image segmentation, image recognition, and image compression.
