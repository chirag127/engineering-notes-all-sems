### Some Basic Boundary Descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

Unit 4 - Feature Extraction covers some basic boundary descriptors, which are mathematical representations of the boundaries of objects in an image.

Boundary descriptors are used in image analytics to represent the boundaries of objects in an image, and to extract meaningful features from the boundaries for further analysis.

The following are some basic boundary descriptors in image analytics:

1. Bounding Box: Bounding box is a rectangular region that encloses an object in an image. Bounding box is used to represent the boundaries of objects in an image.

2. Convex Hull: Convex hull is the smallest convex polygon that encloses an object in an image. Convex hull is used to represent the boundaries of objects in an image.

3. Contour: Contour is a continuous curve that represents the boundary of an object in an image. Contour is used to represent the boundaries of objects in an image.

4. Shape Descriptors: Shape descriptors are mathematical representations of the shape of an object in an image. Shape descriptors are used to extract meaningful features from the boundaries of objects in an image.

5. Moments: Moments are mathematical representations of the shape and orientation of an object in an image. Moments are used to extract meaningful features from the boundaries of objects in an image.

By understanding these concepts, organizations can effectively use boundary descriptors in image analytics to represent the boundaries of objects in an image, and to extract meaningful features from the boundaries for further analysis.
