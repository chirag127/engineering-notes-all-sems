### Some Basic Boundary Descriptors for the notes of the Unit 4 - Feature Extraction in the subject of IMAGE ANALYTICS

1. **Chain Codes**: Chain codes are used to represent the boundary of an object in an image. They are a sequence of numbers that represent the direction of the boundary from one pixel to the next.

2. **Fourier Descriptors**: Fourier descriptors are used to represent the shape of an object in an image. They are calculated by taking the Fourier transform of the boundary of the object.

3. **Moments**: Moments are used to describe the shape of an object in an image. They are calculated by taking the weighted average of the pixel values in the image.

4. **Invariant Moments**: Invariant moments are a type of moment that is invariant to translation, rotation, and scaling. They are used to describe the shape of an object in an image, regardless of its position, orientation, or size.

5. **Shape Number**: Shape number is a numerical representation of the shape of an object in an image. It is calculated by counting the number of times the boundary of the object intersects a set of lines drawn at different angles.

6. **Boundary Signatures**: Boundary signatures are used to represent the shape of an object in an image. They are calculated by measuring the distance from the centroid of the object to the boundary at different angles.

7. **Eccentricity**: Eccentricity is a measure of how elongated an object is. It is calculated by dividing the length of the major axis of the object by the length of the minor axis.

8. **Compactness**: Compactness is a measure of how compact an object is. It is calculated by dividing the area of the object by the square of its perimeter.

9. **Rectangularity**: Rectangularity is a measure of how rectangular an object is. It is calculated by dividing the area of the object by the area of the smallest rectangle that can enclose the object.

10. **Convexity**: Convexity is a measure of how convex an object is. It is calculated by dividing the perimeter of the convex hull of the object by the perimeter of the object.

11. **Solidity**: Solidity is a measure of how solid an object is. It is calculated by dividing the area of the object by the area of its convex hull.

12. **Extent**: Extent is a measure of how much of the bounding box of an object is filled by the object. It is calculated by dividing the area of the object by the area of its bounding box.

13. **Orientation**: Orientation is the angle between the major axis of an object and the x-axis of the image.

14. **Euler Number**: Euler number is a topological property of an object in an image. It is calculated by subtracting the number of holes in the object from the number of connected components in the object.

These are some of the basic boundary descriptors used in feature extraction in image analytics. They can be used to describe the shape and other properties of objects in an image.
