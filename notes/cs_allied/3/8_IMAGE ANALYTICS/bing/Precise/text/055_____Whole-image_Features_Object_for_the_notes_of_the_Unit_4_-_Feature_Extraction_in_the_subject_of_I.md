### Whole-image Features Object

Whole-image features are used to describe the global characteristics of an image. These features are extracted from the entire image rather than from local regions or objects within the image. Some common whole-image features include:

1. **Color Histograms:** A color histogram represents the distribution of colors in an image. It is a statistical representation of the color content of an image and is commonly used for image indexing and retrieval.

2. **Texture Features:** Texture features describe the visual patterns in an image. These features can be used to distinguish between different types of surfaces or materials within an image. Common texture features include coarseness, contrast, and directionality.

3. **Shape Features:** Shape features describe the geometric properties of objects within an image. These features can be used to distinguish between different types of objects or to identify specific objects within an image. Common shape features include area, perimeter, and circularity.

4. **Spatial Relationships:** Spatial relationships describe the relative positions of objects within an image. These features can be used to identify the arrangement of objects within an image or to distinguish between different types of scenes. Common spatial relationships include distance, angle, and orientation.

Whole-image features are commonly used in image classification, retrieval, and recognition tasks. They provide a global representation of the image content and can be used to quickly identify images with similar characteristics. However, whole-image features may not be sufficient for tasks that require a more detailed analysis of the image content, such as object detection or segmentation. In these cases, local features may be more appropriate.
