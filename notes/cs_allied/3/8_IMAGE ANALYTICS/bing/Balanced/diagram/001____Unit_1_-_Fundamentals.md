## Unit 1 - Fundamentals

This unit covers the basic concepts and principles of computer science, such as:

- Data representation: how different types of data, such as numbers, text, images, sound, and video, are stored and manipulated by computers using binary digits (bits).
- Data structures: how data can be organized and accessed efficiently using different abstract data types, such as arrays, lists, stacks, queues, trees, graphs, and hash tables.
- Algorithms: how to design, analyze, and implement step-by-step instructions to solve a specific problem or perform a specific task using a computer.
- Programming paradigms: how to choose and apply different styles and approaches of programming, such as imperative, declarative, functional, object-oriented, and concurrent programming.
- Programming languages: how to use different syntax, semantics, and features of programming languages, such as variables, data types, operators, expressions, statements, control structures, functions, classes, objects, inheritance, polymorphism, and concurrency.
- Software engineering: how to apply systematic and disciplined methods and tools to develop, maintain, and improve software systems, such as software development life cycle, software design patterns, software testing, and software documentation.
- Computer architecture: how the hardware components and organization of a computer system affect its performance and functionality, such as central processing unit (CPU), memory, input/output (I/O) devices, buses, instruction set, and assembly language.
- Operating systems: how the software that manages the resources and operations of a computer system provides services and interfaces to users and applications, such as process management, memory management, file system, device drivers, system calls, and shell commands.
- Networks: how computers communicate and exchange data over a network using different protocols, standards, and technologies, such as network topology, network architecture, network models, network layers, network devices, network addressing, network routing, and network security.
- Databases: how data can be stored, retrieved, and manipulated using a database system that supports different data models, such as relational, hierarchical, network, and object-oriented data models, and different query languages, such as structured query language (SQL).
- Artificial intelligence: how computers can perform tasks that require human intelligence, such as reasoning, learning, planning, decision making, problem solving, natural language processing, computer vision, and machine learning.
- Ethics: how to identify and evaluate the ethical, social, and legal implications and responsibilities of using computers and technology in different contexts and scenarios, such as privacy, security, intellectual property, digital citizenship, and digital divide.
