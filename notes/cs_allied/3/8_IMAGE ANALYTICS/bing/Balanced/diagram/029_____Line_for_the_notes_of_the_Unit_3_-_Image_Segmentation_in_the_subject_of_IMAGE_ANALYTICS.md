### Line for the notes of the Unit 3 - Image Segmentation in the subject of IMAGE ANALYTICS

- Image segmentation is the process of dividing a digital image into subgroups called image segments, reducing the complexity of the image and enabling further processing or analysis of each image segment.
- Image segmentation is typically used to locate objects and boundaries (lines, curves, etc.) in images .
- Image segmentation can be done based on different criteria, such as pixel intensity, color, texture, edge, region, shape, etc.
- Image segmentation can be classified into two main types: supervised and unsupervised.
  - Supervised image segmentation uses prior knowledge or labels to guide the segmentation process. Examples of supervised image segmentation techniques are thresholding, region growing, region merging, edge detection, etc.
  - Unsupervised image segmentation does not use any prior knowledge or labels and relies on the inherent properties of the image data. Examples of unsupervised image segmentation techniques are clustering, histogram analysis, watershed, mean shift, etc.
- Image segmentation can also be classified into two main levels: semantic and instance.
  - Semantic image segmentation assigns a class label to each pixel in the image, such as sky, road, car, person, etc. Semantic image segmentation does not distinguish between different instances of the same class.
  - Instance image segmentation assigns a unique identifier to each pixel in the image, such as car1, car2, person1, person2, etc. Instance image segmentation distinguishes between different instances of the same class.
- Image segmentation can be evaluated using different metrics, such as accuracy, precision, recall, F1-score, IoU (intersection over union), etc.
- Image segmentation has many applications in various domains, such as medical imaging, autonomous driving, face recognition, object detection, etc.
