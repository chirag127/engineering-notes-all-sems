### Fundamentals

- Morphological image processing is a branch of image processing that deals with the shape and structure of objects in an image.
- Morphological operations are based on the concepts of sets, logic, and geometry, and can be applied to binary or grayscale images.
- The basic morphological operations are erosion, dilation, opening, and closing, which can be used to perform various tasks such as noise removal, edge detection, boundary extraction, thinning, skeletonization, etc.
- The main tool for morphological operations is the structuring element, which is a small binary image that defines the neighborhood of a pixel.
- The structuring element is used to probe the input image and modify the output image according to some rules.
- The choice of the structuring element depends on the shape and size of the objects of interest in the image, and the desired effect of the operation.
- The structuring element can be defined by its origin, which is the reference pixel, and its domain, which is the set of pixels relative to the origin.
- The structuring element can be flat or non-flat. A flat structuring element has only binary values (0 or 1), while a non-flat structuring element has grayscale values that can be used to weight the pixels in the neighborhood.
- The structuring element can be symmetric or asymmetric. A symmetric structuring element has the same shape when rotated by 180 degrees, while an asymmetric structuring element does not.
- The structuring element can be isotropic or anisotropic. An isotropic structuring element has the same shape when rotated by any angle, while an anisotropic structuring element does not.
