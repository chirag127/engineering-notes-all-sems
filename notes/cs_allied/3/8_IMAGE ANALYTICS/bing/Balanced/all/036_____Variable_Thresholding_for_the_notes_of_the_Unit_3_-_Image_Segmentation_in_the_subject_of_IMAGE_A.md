- Image segmentation is the process of dividing an image into meaningful regions or segments based on some criteria, such as pixel intensity, color, texture, etc.
- Image thresholding is one of the simplest and most common techniques for image segmentation, which converts a grayscale image into a binary image by assigning pixels to either foreground or background based on a threshold value.
- Variable thresholding is a type of image thresholding that adapts the threshold value to different regions of the image, instead of using a single global value for the whole image. This can improve the segmentation results for images that have varying illumination, contrast, or noise levels.
- Variable thresholding can be classified into two categories: local and adaptive.
  - Local thresholding divides the image into smaller sub-regions and applies a different threshold value to each sub-region, based on some statistical measure of the pixel intensities, such as mean, median, mode, standard deviation, etc. Local thresholding can be sensitive to the choice of the sub-region size and shape, and may produce artifacts at the boundaries of the sub-regions.
  - Adaptive thresholding computes the threshold value for each pixel based on a local neighborhood of pixels around it, using a predefined function or algorithm. Adaptive thresholding can be more robust and flexible than local thresholding, as it can adjust to local variations in the image without creating sub-regions. However, adaptive thresholding can be more computationally expensive and may require fine-tuning of the parameters of the function or algorithm.
- Some examples of variable thresholding methods are:
  - Niblack method: This is a local thresholding method that uses the mean and standard deviation of the pixel intensities in each sub-region to compute the threshold value as: T = m + k * s, where m is the mean, s is the standard deviation, and k is a constant that controls the sensitivity of the thresholding.
  - Bernsen method: This is a local thresholding method that uses the minimum and maximum of the pixel intensities in each sub-region to compute the threshold value as: T = (min + max) / 2, where min and max are the minimum and maximum values, respectively. This method can handle high-contrast images well, but may fail for low-contrast images.
  - Otsu method: This is a global thresholding method that can be extended to a variable thresholding method by applying it to each sub-region separately. The Otsu method finds the optimal threshold value that maximizes the between-class variance of the pixel intensities, assuming that the image has two classes: foreground and background. The Otsu method can handle bimodal histograms well, but may not work well for multimodal or unimodal histograms.
  - Sauvola method: This is an adaptive thresholding method that is a modification of the Niblack method, which uses a dynamic value of k instead of a constant one. The Sauvola method computes the threshold value for each pixel as: T = m * (1 + k * (s / R - 1)), where m and s are the mean and standard deviation of the pixel intensities in a local neighborhood around the pixel, k is a positive constant, and R is the maximum value of s. The Sauvola method can handle low-contrast and noisy images well, but may produce noisy results for high-contrast images.
