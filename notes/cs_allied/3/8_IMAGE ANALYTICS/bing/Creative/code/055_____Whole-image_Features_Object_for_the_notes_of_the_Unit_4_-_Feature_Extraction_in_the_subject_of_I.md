### Whole-image Features Object

- Whole-image features object is a term that refers to the global features of an image that describe the image as a whole, rather than the local features that describe specific regions or elements of the image.
- Whole-image features object can be used to generalize the complete thing, such as the shape, contour, texture, color, or histogram of the image .
- Whole-image features object can be extracted by applying various methods, such as:
  - **Contour representations**: These are methods that capture the outline or boundary of the image, such as chain codes, Fourier descriptors, or shape signatures.
  - **Shape descriptors**: These are methods that measure the geometric properties of the image, such as area, perimeter, compactness, eccentricity, or moments.
  - **Texture features**: These are methods that quantify the spatial variation of pixel intensities in the image, such as co-occurrence matrices, local binary patterns, or wavelets.
  - **Color features**: These are methods that represent the distribution or statistics of colors in the image, such as color histograms, color moments, or color correlograms.
- Whole-image features object can be used for various applications, such as:
  - **Image classification**: This is the task of assigning a label to an image based on its global features, such as face recognition, scene recognition, or medical image diagnosis.
  - **Image retrieval**: This is the task of finding images that are similar to a query image based on its global features, such as content-based image retrieval, image search engines, or image annotation.
  - **Image segmentation**: This is the task of dividing an image into meaningful regions based on its global features, such as background subtraction, object detection, or semantic segmentation .
