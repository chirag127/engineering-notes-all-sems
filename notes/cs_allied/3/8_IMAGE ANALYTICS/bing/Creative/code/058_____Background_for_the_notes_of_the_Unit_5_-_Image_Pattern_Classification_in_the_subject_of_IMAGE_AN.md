### Background for the notes of the Unit 5 - Image Pattern Classification in the subject of IMAGE ANALYTICS

- Image pattern classification is the task of categorizing images into one or multiple predefined classes based on their content, such as objects, scenes, textures, etc. 
- Image pattern classification is a subfield of computer vision and machine learning that deals with the analysis and understanding of visual data. 
- Image pattern classification has many applications in various domains, such as face recognition, medical imaging, biometrics, remote sensing, security, etc. 
- Image pattern classification can be performed using different methods, such as supervised, unsupervised, or semi-supervised learning. 
- Supervised learning is the process of learning from labeled data, where each image is associated with a class label. The goal is to learn a function that maps an image to its correct label. 
- Unsupervised learning is the process of learning from unlabeled data, where the class labels are unknown. The goal is to discover the underlying structure or patterns in the data, such as clusters or groups of similar images. 
- Semi-supervised learning is the process of learning from partially labeled data, where some images have labels and some do not. The goal is to leverage the labeled data to improve the performance on the unlabeled data. 
- Image pattern classification can be performed using different techniques, such as classic or deep learning. 
- Classic techniques are based on extracting handcrafted features from images, such as color, shape, texture, etc., and using them as inputs to a classifier, such as k-nearest neighbors, support vector machines, decision trees, etc. 
- Deep learning techniques are based on learning features from images automatically using neural networks, such as convolutional neural networks, recurrent neural networks, generative adversarial networks, etc. 
- Image pattern classification can be performed at different levels of granularity, such as pixel, region, or image level. 
- Pixel level classification is the process of assigning a class label to each pixel in an image, such as in image segmentation or semantic segmentation. 
- Region level classification is the process of assigning a class label to a sub-image or a window in an image, such as in object detection or face detection. 
- Image level classification is the process of assigning a class label to the whole image, such as in scene recognition or image retrieval. 
- Image pattern classification can be performed using different criteria, such as plain, edge, or texture. 
- Plain classification is the process of distinguishing images based on their overall color or brightness, such as in color image segmentation or grayscale image segmentation. 
- Edge classification is the process of distinguishing images based on their edge features, such as in edge detection or contour detection. 
- Texture classification is the process of distinguishing images based on their texture features, such as in texture segmentation or texture recognition.
