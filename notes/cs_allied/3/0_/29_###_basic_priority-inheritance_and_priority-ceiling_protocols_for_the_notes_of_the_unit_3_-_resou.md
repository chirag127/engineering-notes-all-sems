### Basic Priority-Inheritance and Priority-Ceiling Protocols for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

Basic Priority-Inheritance and Priority-Ceiling Protocols:
- Priority-inheritance and priority-ceiling protocols are methods for managing resource sharing in real-time systems.
- These protocols are used to prevent priority inversion, where a lower priority task blocks the execution of a higher priority task.
- In a priority-inheritance protocol, the priority of a task that is holding a resource is temporarily raised to the priority of the highest priority task that is waiting for the resource.
- In a priority-ceiling protocol, the priority of a resource is set to the priority of the highest priority task that uses the resource.
- Both priority-inheritance and priority-ceiling protocols can be used to ensure that the system meets its timing constraints and to prevent priority inversion.
- Understanding the basic priority-inheritance and priority-ceiling protocols is important for the design and development of real-time systems that can effectively manage resource sharing and for the implementation of effective resource allocation algorithms.
