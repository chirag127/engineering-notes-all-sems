In the context of Unit 3 - Real Time Kernel Basics in the subject of Embedded Systems and Real Time Operating Systems, the term "process based" refers to the way in which a real-time operating system (RTOS) manages processes.

A process is a program in execution, and it is the basic unit of work in a computer system. A process-based RTOS manages processes by creating, scheduling, and executing processes in a way that meets the real-time requirements of the system.

In a process-based RTOS, each process has its own address space, and the RTOS provides mechanisms for inter-process communication and synchronization. This allows multiple processes to run concurrently and to share resources, such as memory and I/O devices.

The process-based approach provides several advantages for real-time systems, including:

1. Isolation: Each process runs in its own address space, which provides isolation between processes. This helps to prevent errors in one process from affecting other processes, and makes it easier to debug and maintain the system.

2. Concurrency: Multiple processes can run concurrently, which allows the RTOS to take advantage of multi-core processors and to improve system performance.

3. Resource sharing: Processes can share resources, such as memory and I/O devices, which makes it easier to develop and maintain complex real-time systems.

4. Inter-process communication: Processes can communicate with each other using inter-process communication mechanisms, such as pipes, message queues, and semaphores. This allows processes to coordinate their behavior and to share information.
