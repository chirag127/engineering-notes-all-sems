### interference in fuzzy logic for the notes of the Unit 4 - Fuzzy Logic –II (Fuzzy Membership, Rules) in the subject of APPLICATION OF SOFT COMPUTING TECHNIQUES

Interference in fuzzy logic refers to the process of combining fuzzy rules to make a decision. Fuzzy rules are if-then statements that define the relationships between inputs and outputs in a fuzzy system. Interference combines the results of multiple fuzzy rules to determine the overall output.

There are two main approaches to interference in fuzzy logic:

1. Mamdani inference: This approach uses the max-min composition method to combine the results of multiple fuzzy rules. The max-min composition method determines the minimum value of the antecedents of all rules that match a particular input.

2. Sugeno inference: This approach uses a weighted average of the consequents of all rules that match a particular input. The weights are determined by the degree of match between the input and the antecedent of each rule.

In summary, interference in fuzzy logic refers to the process of combining fuzzy rules to make a decision, and can be performed using either the Mamdani or Sugeno inference approach. The Mamdani approach uses the max-min composition method, while the Sugeno approach uses a weighted average of the consequents of all matching rules.
