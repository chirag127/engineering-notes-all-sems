
## Unit 2 - Neural Networks-II (Back propagation networks)

1. Back propagation networks are a type of artificial neural networks that are used for supervised learning. 
2. They are composed of an input layer, one or more hidden layers, and an output layer. 
3. Each layer contains nodes, which are connected to the nodes in the other layers. 
4. The input layer receives input data, which is then passed through the hidden layers and to the output layer. 
5. The output layer produces the output. 
6. The weights of the connections between the nodes are adjusted during the training process. 
7. The adjustment of the weights is done using a learning algorithm, such as the backpropagation algorithm. 
8. The backpropagation algorithm is an iterative process that adjusts the weights based on the difference between the desired output and the actual output. 
9. The weights are adjusted until the desired output is achieved. 
10. Back propagation networks can be used for a variety of tasks, such as classification, regression, and clustering.
