
### Activation Functions

1. **Sigmoid Function**: This is a non-linear activation function which takes any real-valued number and outputs a value between 0 and 1. It is widely used in logistic regression and neural networks.

2. **ReLU Function**: This is a linear activation function which takes any real-valued number and outputs either 0 or the same number. It is widely used in deep learning networks and is considered to be a more efficient activation function than sigmoid.

3. **Tanh Function**: This is a non-linear activation function which takes any real-valued number and outputs a value between -1 and 1. It is widely used in recurrent neural networks.

4. **Softmax Function**: This is a non-linear activation function which takes any real-valued number and outputs a value between 0 and 1. It is widely used in classification tasks and is considered to be a more efficient activation function than sigmoid and tanh.
