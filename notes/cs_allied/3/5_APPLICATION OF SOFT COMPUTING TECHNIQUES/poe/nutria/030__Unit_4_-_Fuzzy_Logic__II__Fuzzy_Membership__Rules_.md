
## Unit 4 - Fuzzy Logic –II (Fuzzy Membership, Rules)

1. Fuzzy Membership: Fuzzy membership is a concept used to represent the degree of truth of a given statement. It is a numerical representation of the truth of a statement, which can range from 0 (completely false) to 1 (completely true). Membership functions are used to define the degree of truth of a statement.

2. Fuzzy Rules: Fuzzy rules are a set of IF-THEN statements that are used to define the behavior of a fuzzy system. The IF part of the statement is the antecedent, which is a set of conditions that must be met for the THEN part of the statement, the consequent, to be executed. The consequent is the action that will be taken if the antecedent is true. 

3. Fuzzy Inference System (FIS): A Fuzzy Inference System (FIS) is a type of computing system that uses fuzzy logic to make decisions. It consists of a set of fuzzy rules, a set of fuzzy membership functions, and a set of fuzzy operators. The FIS uses the fuzzy rules and membership functions to determine the output of the system.

4. Fuzzy Control System (FCS): A Fuzzy Control System (FCS) is a type of computing system that uses fuzzy logic to control the behavior of a system. It consists of a set of fuzzy rules, a set of fuzzy membership functions, and a set of fuzzy operators. The FCS uses the fuzzy rules and membership functions to determine the output of the system.

5. Fuzzy Logic Toolbox (FLT): The Fuzzy Logic Toolbox (FLT) is a collection of software tools used to design, simulate, and analyze fuzzy logic systems. The FLT includes a graphical user interface (GUI) that allows users to design and simulate fuzzy systems, as well as a library of fuzzy logic functions and operators.
