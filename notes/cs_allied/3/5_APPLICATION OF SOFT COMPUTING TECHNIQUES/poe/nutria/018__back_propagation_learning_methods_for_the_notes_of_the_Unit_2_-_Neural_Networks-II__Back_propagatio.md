
### Back Propagation Learning Methods

Back propagation is a supervised learning technique used in artificial neural networks to adjust weights in the network in order to minimize the error between the desired output and the actual output of the network. Back propagation is based on the concept of gradient descent and involves the calculation of the gradient of the error function with respect to the weights of the network.

1. Forward Pass: In the forward pass, the input is propagated through the network and the output is calculated.
2. Error Calculation: The error between the desired output and the actual output of the network is calculated.
3. Backward Pass: In the backward pass, the error is propagated back through the network and the weights are adjusted accordingly.
4. Weight Update: The weights are updated using the gradient of the error function with respect to the weights.
5. Iteration: The process is repeated until the error is minimized.
