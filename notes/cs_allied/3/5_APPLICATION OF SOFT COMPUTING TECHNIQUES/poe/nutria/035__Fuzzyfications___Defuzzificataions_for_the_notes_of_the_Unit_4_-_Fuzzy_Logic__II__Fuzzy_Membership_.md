
### Fuzzyfications & Defuzzificataions

Fuzzyfication is the process of converting a crisp input value into a fuzzy value. It is the process of assigning a fuzzy set to a given input value.

Defuzzification is the process of converting a fuzzy output value into a crisp output value. It is the process of determining the centroid of a fuzzy set.

Fuzzy Logic –II (Fuzzy Membership, Rules) is a branch of fuzzy logic that deals with the membership of data to a given set and the rules associated with it.

Fuzzy Membership: It is the process of assigning membership values to the data points in a given set. It is used to determine the degree of membership of a data point to a given set.

Fuzzy Rules: Fuzzy rules are used to determine the degree of membership of a data point to a given set. They are used to determine the output of a fuzzy system based on the input.

The application of fuzzy logic can be found in various areas such as control systems, image processing, robotics, etc. Fuzzy logic is used to make decisions based on fuzzy input data.
