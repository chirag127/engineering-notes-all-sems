### Various learning techniques for the notes of the Unit 1 - Neural Networks-I (Introduction & Architecture)

- Neural networks are computational models that try to emulate the human brain, combining computer science and statistics to solve common problems in the field of AI.
- Neural networks consist of layers of interconnected nodes or neurons, each with a weight and a bias, that process the input and output signals.
- The learning of neural network basically refers to the adjustment in the free parameters i.e. weights and bias. The learning rule modifies the weights and thresholds of the variables in the network.
- There are a number of different learning techniques used in neural networks, including supervised and unsupervised learning, reinforcement learning, and semi-supervised learning.
- Supervised learning is a type of learning where the network is trained with labeled data, i.e. the input and the desired output are given. The network learns to map the input to the output by minimizing the error between the actual and the desired output. Examples of supervised learning algorithms are backpropagation, gradient descent, and perceptron.
- Unsupervised learning is a type of learning where the network is trained with unlabeled data, i.e. only the input is given. The network learns to discover the hidden patterns and structures in the data without any external guidance. Examples of unsupervised learning algorithms are clustering, self-organizing maps, and autoencoders.
- Reinforcement learning is a type of learning where the network is trained with feedback from the environment, i.e. the input and the reward or penalty are given. The network learns to optimize its behavior by maximizing the reward or minimizing the penalty. Examples of reinforcement learning algorithms are Q-learning, SARSA, and policy gradient.
- Semi-supervised learning is a type of learning where the network is trained with partially labeled data, i.e. some of the input and output pairs are given and some are not. The network learns to leverage both the labeled and the unlabeled data to improve its performance. Examples of semi-supervised learning algorithms are co-training, self-training, and generative adversarial networks.
- Multi-layer feedforward network is a commonly used architecture. It has been observed that a neural network with even one hidden layer can be used to reasonably approximate any continuous function. The learning methodology adopted to train a multi-layer feedforward network is backpropagation.
- Backpropagation is a supervised learning algorithm that uses the chain rule of calculus to propagate the error from the output layer to the input layer, and updates the weights and biases accordingly. Backpropagation consists of two phases: forward propagation and backward propagation.
- Forward propagation computes the input and outputs the output and sums the predecessor neurons function with the weight.
- Backward propagation computes the error and updates the weights and biases by using the gradient descent algorithm, which moves the weights and biases in the opposite direction of the gradient of the error function.
