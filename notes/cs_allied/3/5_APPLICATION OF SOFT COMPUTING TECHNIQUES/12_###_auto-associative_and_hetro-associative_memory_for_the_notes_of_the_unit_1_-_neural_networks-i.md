### Auto-associative and hetro-associative memory for the notes of the Unit 1 - Neural Networks-I (Introduction & Architecture) in the subject of APPLICATION OF SOFT COMPUTING TECHNIQUES

Auto-associative and hetero-associative memory are two types of memory used in artificial neural networks.

Auto-associative memory is a type of memory in which a neural network is trained to recall a complete pattern from a partial input. The network is trained to associate an input pattern with its corresponding output pattern, and to recall the complete output pattern from a partial input. This type of memory is commonly used for pattern completion, such as predicting the missing part of a partially observed image.

Hetero-associative memory is a type of memory in which a neural network is trained to associate two different patterns. The network is trained to associate an input pattern with a corresponding output pattern, and to recall the output pattern from the input pattern. This type of memory is commonly used for pattern recognition and classification, such as recognizing objects in an image.

In conclusion, auto-associative and hetero-associative memory are two types of memory used in artificial neural networks. Auto-associative memory is used for pattern completion, while hetero-associative memory is used for pattern recognition and classification. Understanding these types of memory is important for designing and training neural networks for various applications in the field of Soft Computing Techniques.
