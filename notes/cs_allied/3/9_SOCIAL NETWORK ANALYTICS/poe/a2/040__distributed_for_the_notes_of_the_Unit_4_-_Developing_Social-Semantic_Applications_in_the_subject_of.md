### Distributed Processing for Social-Semantic Applications

1. Distributed processing is the division of a complex task into multiple smaller tasks that are processed in parallel by multiple processors to achieve faster processing and scalability.
2. Some of the distributed processing frameworks for social-semantic applications are:
- Apache Spark: General-purpose distributed processing framework that can be used for streaming, graph processing and machine learning on large data. It has APIs in Java, Python, R and Scala.
- GraphLab: A machine learning framework with APIs in C++, Python and CLI for parallel machine learning tasks like collaborative filtering, clustering, classification on graphs and social networks.
- GraphX: A graph processing framework built on Apache Spark for analyzing graphs and performing graph-parallel computations. It has APIs in Python and Scala.
3. The advantages of distributed processing for social-semantic applications are:
- Faster processing of huge volumes of social data and semantic data.
- Scalability to analyze graphs and networks with millions or billions of nodes and relationships.
- Ability to run multiple machine learning algorithms in parallel for more accurate models.
- Fault tolerance as the tasks are divided into multiple smaller tasks across processors. If one fails, the other tasks can continue processing.
