## Unit 3 - Modelling and Aggregating Social Network Data

3. Edge attributes - Edges in a network can have attributes like weight, type of relationship, duration, etc. which provide more context to the connections between nodes.
4. Network models - Models to generate synthetic networks and simulate processes on networks - Erdos-Renyi model, Barabasi-Albert model, Watts-Strogatz model, etc.
5. Aggregation methods - Methods to aggregate network data to understand macro-level properties - Degree distribution, average path length, diameter, clustering coefficient, centralization, etc.
6. Applications - Analysis of social networks to understand information diffusion, influence, communities, robustness, etc. Analysis of other networks like biological networks, technological networks, etc.
