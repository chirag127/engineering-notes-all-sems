### Reasoning with instance equality for the notes of the Unit 3 - Modelling and Aggregating Social Network Data in the subject of SOCIAL NETWORK ANALYTICS

1. Instance equality: Two nodes are instance equal if they represent the exact same entity. For example, if two nodes both represent “Barack Obama”, then they are instance equal.
2. Reasoning with instance equality: Instance equality allows us to reason about identities in a network. For example, we can find all mentions of a particular person, or merge multiple representations of the same entity into a single node.
3. Uses:
 - Finding influence or prominence of a particular entity
 - Correcting for duplicate representations of entities
 - Tracking entities across time
4. Challenges:
 - Determining instance equality is not always straightforward
 - There may be ambiguity (e.g. two people with the same name)
 - Scalability to large networks
