### Network analysis for the notes of the Unit 1 - Social Network Analysis

1. Network: A network is a set of nodes connected by edges. In social network analysis, nodes are actors or entities and edges are the relationships or interactions between the actors.

2. Nodes: Nodes are the basic building blocks of a network. They can be individuals, organizations, groups, etc. The properties of nodes like degree, betweenness, closeness, etc. are analyzed in network analysis.

3. Edges: Edges refer to the connections or links between nodes. The presence of an edge indicates that there is a relationship or interaction between two nodes. The properties of edges like weight, direction, etc. are also analyzed in network analysis.

4. Degree: The degree of a node refers to the number of edges connected to that node. Nodes with a high degree are more influential in a network.

5. Density: The density of a network refers to the proportion of possible connections between nodes that are actually present. A dense network has a high density while a sparse network has a low density.

6. Centrality: Centrality measures the relative importance of a node in a network. Various measures of centrality are degree centrality, betweenness centrality, closeness centrality, eigenvector centrality, etc.
