### Electronic sources for network analysis for the notes of the Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS.

1. Data sources
- Web APIs: Many social networks like Twitter, Facebook, LinkedIn, etc provide API access to extract user data and connections. This can be used to extract network data for analysis.
- Web scraping: If APIs are not available, web scraping techniques can be used to extract data from websites and web pages. Tools like Scrapy, Selenium, etc can be used for web scraping.
- Online datasets: Many datasets of networks are available online on repositories like Kaggle, UCI Machine Learning Repository, etc which can be directly downloaded and used for analysis.

2. Analysis tools
- NetworkX: NetworkX is a Python library for analysis of networks and network algorithms. It can be used to create, manipulate and study the structure and dynamics of networks.
- Gephi: Gephi is an interactive visualization and exploration software for all kinds of networks and complex systems. It can be used to analyze and visualize networks with powerful algorithms and filters.
- Cytoscape: Cytoscape is also a software platform for visualizing molecular interaction networks and integrating with gene expression profiles and other state data.
- Others: There are many other tools and libraries available for network analysis in Python, R, etc.

3. Centrality measures
- Degree centrality: Degree centrality of a node is its number of connections. Nodes with high degree centrality are important.
- Betweenness centrality: Betweenness centrality of a node is the number of shortest paths going through the node. Nodes with high betweenness centrality control information flow in the network.
- Closeness centrality: Closeness centrality of a node is the average distance from the node to every other node. Nodes with high closeness centrality are closer to other nodes.
- Eigenvector centrality: Eigenvector centrality of a node depends on the centrality scores of its neighbors. Important neighbors contribute more to the centrality score.
