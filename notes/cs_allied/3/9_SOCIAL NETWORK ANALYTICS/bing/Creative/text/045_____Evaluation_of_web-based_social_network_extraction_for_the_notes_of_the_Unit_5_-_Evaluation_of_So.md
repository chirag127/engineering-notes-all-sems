### Evaluation of web-based social network extraction

- Web-based social network extraction is the process of identifying and describing the actors and their relations from online sources, such as web pages, social media platforms, blogs, etc.  
- Web-based social network extraction can benefit many web mining and social network analysis applications, such as community detection, sentiment analysis, recommendation systems, etc. 
- Web-based social network extraction can be performed using different techniques, such as superficial methods, supervised methods, semi-supervised methods, and unsupervised methods.   
- Superficial methods rely on the textual similarity between web pages to determine the actors and their relations, without using any prior knowledge or external resources.  
- Supervised methods use labeled data and machine learning algorithms to extract the actors and their relations from web pages, based on predefined features and rules. 
- Semi-supervised methods use a small amount of labeled data and a large amount of unlabeled data to extract the actors and their relations from web pages, by leveraging the structure and content of the web pages. 
- Unsupervised methods use clustering or graph-based techniques to extract the actors and their relations from web pages, without using any labeled data or predefined features. 
- Web-based social network extraction can be evaluated using different criteria, such as accuracy, precision, recall, F1-score, etc.    
- Accuracy measures the proportion of correctly extracted actors and relations among all the extracted ones.    
- Precision measures the proportion of correctly extracted actors and relations among all the relevant ones.    
- Recall measures the proportion of correctly extracted actors and relations among all the existing ones.    
- F1-score measures the harmonic mean of precision and recall, which balances the trade-off between them.    
- Web-based social network extraction can also be evaluated using qualitative criteria, such as the validity, reliability, and usefulness of the extracted social networks.    
- Validity measures the extent to which the extracted social networks reflect the real-world social structures and behaviors.    
- Reliability measures the extent to which the extracted social networks are consistent and reproducible across different sources and methods.    
- Usefulness measures the extent to which the extracted social networks can support the intended web mining and social network analysis applications.
