## Unit 3 - Modelling and Aggregating Social Network Data

- This unit covers the methods and techniques for representing, analysing and aggregating social network data.
- The main topics are:

  - Graph theory and network models: how to use graphs and matrices to represent social networks and their properties, such as degree, centrality, clustering, paths, cycles, components, etc.
  - Network measures and metrics: how to quantify and compare the structural features of networks, such as density, diameter, average shortest path length, modularity, assortativity, etc.
  - Network analysis and visualization: how to use software tools and algorithms to explore, manipulate and display network data, such as networkx, igraph, Gephi, etc.
  - Network aggregation and inference: how to combine and extract information from multiple networks, such as network alignment, network comparison, network projection, network embedding, etc.

- The learning outcomes are:

  - To understand the basic concepts and terminology of graph theory and network models.
  - To apply network measures and metrics to analyse and compare social networks.
  - To use network analysis and visualization tools to explore and present network data.
  - To perform network aggregation and inference tasks to combine and extract information from multiple networks.
