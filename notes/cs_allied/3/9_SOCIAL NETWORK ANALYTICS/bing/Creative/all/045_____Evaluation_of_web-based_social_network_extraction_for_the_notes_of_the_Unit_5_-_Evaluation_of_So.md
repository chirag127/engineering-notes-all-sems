# Evaluation of web-based social network extraction

Web-based social network extraction is the process of identifying and extracting social actors and their relations from online sources, such as web pages, blogs, social media platforms, etc.  . It is a useful technique for web mining and social network analysis applications, such as community detection, sentiment analysis, recommendation systems, etc. .

However, web-based social network extraction faces many challenges, such as:

- The heterogeneity and diversity of web data formats and structures  .
- The ambiguity and incompleteness of web data content and semantics  .
- The scalability and efficiency of web data processing and analysis  .

Therefore, web-based social network extraction requires careful evaluation to assess its quality and performance. Some of the evaluation criteria and methods are:

- The accuracy and completeness of the extracted social actors and their relations  . This can be measured by comparing the extracted network with a ground truth network, or by using external validation measures, such as precision, recall, F-measure, etc.  .
- The relevance and usefulness of the extracted social network for a specific application or domain  . This can be measured by using application-specific metrics, such as user satisfaction, user engagement, user retention, etc.  .
- The efficiency and scalability of the extraction algorithm or system  . This can be measured by using performance metrics, such as running time, memory usage, throughput, etc.  .

Additionally, web-based social network extraction can be evaluated by using a framework that describes the steps and components involved in the extraction process . Such a framework can help to:

- Systematize and standardize the extraction process .
- Identify and compare different extraction methods and techniques .
- Analyze and improve the extraction results and outcomes .

In summary, web-based social network extraction is a challenging but valuable technique for web mining and social network analysis. It requires careful evaluation to ensure its quality and performance.
