### Determining equality for the notes of the Unit 3 - Modelling and Aggregating Social Network Data in the subject of SOCIAL NETWORK ANALYTICS

- The main objective of this unit is to learn how to model and aggregate social network data using ontologies and semantic web technologies.
- Ontologies are formal representations of the concepts and relationships in a domain of interest, such as social networks, that can be used for reasoning and querying.
- Semantic web technologies are standards and tools that enable the representation, exchange, and integration of data and knowledge on the web, such as RDF, OWL, and SPARQL.
- Modelling and aggregating social network data involves the following steps:
  - Converting data from traditional formats (such as relational databases, Excel sheets, XML files, etc.) into RDF-based syntax, which allows to store the data in an ontology store and manipulate it with ontology-based tools.
  - Defining or reusing existing ontologies to capture the semantics of the social network data, such as the types of entities, attributes, and relationships involved.
  - Mapping the data to the ontologies using ontology alignment techniques, such as schema matching, instance matching, or rule-based methods.
  - Querying and reasoning with the data using SPARQL, a query language for RDF, and OWL, a logic-based language for ontologies, to perform tasks such as finding patterns, discovering communities, or inferring new knowledge.
- Some of the challenges and open issues in modelling and aggregating social network data are:
  - Dealing with the heterogeneity and diversity of the data sources, formats, and schemas, which may require complex and dynamic mappings and alignments.
  - Handling the uncertainty and incompleteness of the data, which may affect the quality and reliability of the results.
  - Preserving the privacy and security of the data and the users, which may require anonymization, encryption, or access control mechanisms.
  - Scaling up to large and dynamic social networks, which may require distributed and parallel processing, indexing, and caching techniques.
