### Visualization and Analysis for the notes of the Unit 5 - Evaluation of Social Network Analysis

- Social network analysis (SNA) is the study of structure, and how it influences health, and it is based on theoretical constructs of sociology and mathematical foundations of graph theory.
- Structure refers to the regularities in the patterning of relationships among individuals, groups and/or organizations.
- SNA uses various methods to measure and describe the properties of network actors, subgroups and complete networks.
- Visualization is an important aspect of SNA, as it helps to display the network structure and identify patterns, clusters, outliers and anomalies.
- Visualization also facilitates qualitative interpretation of network data and communication of network insights.
- SNA software tools are used to change the layout, colors, size and other properties of the network representation, as well as to perform predictive analysis.
- Some examples of SNA software tools are Gephi, NodeXL, UCINET, Pajek, NetDraw, etc.
- Social network analysis also involves the use of social network measures, which are numerical values that capture the characteristics of network actors, subgroups and complete networks.
- Some examples of social network measures are degree centrality, closeness centrality, betweenness centrality, eigenvector centrality, clustering coefficient, modularity, density, diameter, etc.
- Social network measures help to calculate the relative importance of nodes in a network, which helps explain how the network interacts.
- Social network analysis also involves the use of community detection algorithms, which are methods to identify groups of nodes that are more densely connected to each other than to the rest of the network.
- Community detection algorithms help to reveal the underlying structure of the network, as well as the potential homophily, influence and diffusion processes among the nodes.
- Some examples of community detection algorithms are Louvain method, Girvan-Newman method, Label propagation method, etc.
- Social network analysis can be applied to various domains, such as public health, social media, marketing, politics, education, etc.
- Social network analysis can help to understand the dynamics of social phenomena, such as epidemics, information diffusion, social influence, collective behavior, etc.
