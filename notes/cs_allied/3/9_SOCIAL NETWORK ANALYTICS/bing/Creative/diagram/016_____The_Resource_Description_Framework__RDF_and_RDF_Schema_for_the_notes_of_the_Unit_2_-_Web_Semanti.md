- RDF is a standard model for data interchange on the Web that allows applications to share and reuse metadata.
- RDF represents data as a graph of triples, each consisting of a subject, a predicate, and an object, which can be identified by URIs or literals.
- RDF uses the idea of the XML namespace to effectively allow RDF statements to reference a particular RDF vocabulary or 'schema'.
- RDF Schema is a set of classes with certain properties using the RDF extensible knowledge representation data model, providing basic elements for the description of ontologies.
- RDF Schema defines the concepts of rdfs:Class, rdfs:subClassOf, rdfs:Property, rdfs:subPropertyOf, rdfs:domain, rdfs:range, and rdfs:label, among others.
- RDF Schema allows users to define their own vocabularies and hierarchies of classes and properties, as well as to infer new facts from existing data using simple rules.
