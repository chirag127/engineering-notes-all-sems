### Preparing the data for the notes of the Unit 5 - Evaluation of Social Network Analysis in the subject of SOCIAL NETWORK ANALYTICS

- Social network analysis (SNA) is an evaluation approach that uses mathematics and visualization to represent the structure of relationships between people, organizations, goals, interests, and other entities within a larger system.
- SNA helps to understand the phenomena that emerge from the interaction of individuals or institutions and is useful to assess the impact, effectiveness, and sustainability of interventions that aim to change or improve these relationships.
- SNA can be used to find the type, importance, and quantity of relationships in a social network, allowing for a graphical output in conjunction with mathematical analysis.
- SNA can be applied to various domains and contexts, such as health care, education, community development, social media, organizational development, and policy making.
- To conduct SNA, the following steps are usually involved:
  - Define the research question and the purpose of the analysis
  - Identify the network boundary and the unit of analysis (e.g., individuals, groups, organizations)
  - Collect data on the network actors and their relationships using methods such as surveys, interviews, observation, or secondary sources
  - Analyze the data using software tools such as UCINET, NetDraw, Gephi, or R
  - Visualize the network using graphs, maps, or matrices
  - Interpret the results and report the findings using network measures and indicators, such as density, centrality, cohesion, subgroups, or roles
- To evaluate SNA, the following criteria can be considered:
  - Validity: the extent to which the network data and analysis accurately reflect the reality of the network
  - Reliability: the extent to which the network data and analysis are consistent and reproducible
  - Utility: the extent to which the network data and analysis are useful and relevant for the intended users and stakeholders
  - Feasibility: the extent to which the network data and analysis are feasible and practical to conduct given the available resources and constraints
  - Ethics: the extent to which the network data and analysis respect the rights and interests of the network actors and protect their privacy and confidentiality
