# The Resource Description Framework (RDF) and RDF Schema

- RDF is a standard model for data interchange on the Web.
- RDF uses triples of subject, predicate and object to represent data as graphs.
- RDF can express data in different syntaxes, such as XML, Turtle, JSON-LD, etc.
- RDF can merge data from different sources, even if they have different schemas.
- RDF Schema (RDFS) is a set of classes and properties that extend RDF to describe ontologies.
- RDFS defines basic concepts such as rdfs:Class, rdfs:subClassOf, rdfs:Property, rdfs:domain, rdfs:range, etc.
- RDFS can be used to define vocabularies for specific domains, such as FOAF, Dublin Core, SKOS, etc.
- RDFS can also be used to infer new facts from existing data using rules and reasoning.
