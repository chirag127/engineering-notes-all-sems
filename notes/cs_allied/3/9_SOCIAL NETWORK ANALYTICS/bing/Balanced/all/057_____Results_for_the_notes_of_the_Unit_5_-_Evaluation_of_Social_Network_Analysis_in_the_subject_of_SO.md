# Unit 5 - Evaluation of Social Network Analysis

- Social network analysis (SNA) is the process of investigating social structures through the use of network and graph theories.
- SNA can be used to study various aspects of social networks, such as their structure, dynamics, patterns, properties, and outcomes.
- SNA can be applied to various domains, such as sociology, psychology, communication, economics, politics, biology, and computer science.
- SNA can be performed using various methods, such as data collection, network representation, network analysis, network visualization, and network interpretation.
- Evaluation of SNA is the process of assessing the quality, validity, reliability, and usefulness of SNA methods and results.
- Evaluation of SNA can be done using various criteria, such as:
  - Data quality: the extent to which the data used for SNA are accurate, complete, consistent, and relevant.
  - Network representation: the extent to which the network model captures the essential features and characteristics of the social network.
  - Network analysis: the extent to which the network measures and algorithms are appropriate, robust, and meaningful for the research question and the network data.
  - Network visualization: the extent to which the network graph conveys the network structure and properties in an effective, clear, and intuitive way.
  - Network interpretation: the extent to which the network results are consistent, coherent, and relevant for the research context and the network theory.
- Evaluation of SNA can be done using various methods, such as:
  - Data validation: the process of checking and verifying the data used for SNA, such as by comparing them with other sources, conducting surveys or interviews, or performing statistical tests.
  - Network comparison: the process of comparing the network model and results with other network models and results, such as by using similarity or dissimilarity measures, conducting hypothesis tests, or performing sensitivity analysis.
  - Network validation: the process of checking and verifying the network model and results, such as by using theoretical or empirical evidence, conducting experiments or simulations, or performing cross-validation.
  - Network evaluation: the process of assessing the network model and results, such as by using evaluation criteria, conducting peer review, or performing meta-analysis.
