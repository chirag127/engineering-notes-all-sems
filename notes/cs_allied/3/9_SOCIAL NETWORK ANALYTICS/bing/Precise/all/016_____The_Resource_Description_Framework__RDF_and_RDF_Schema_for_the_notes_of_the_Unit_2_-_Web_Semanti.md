# The Resource Description Framework (RDF) and RDF Schema

The Resource Description Framework (RDF) is a standard model for data interchange on the Web. It is a framework for representing information in the Web. RDF extends the linking structure of the Web to use URIs to name the relationship between things as well as the two ends of the link (this is usually referred to as a “triple”). Using this simple model, it allows structured and semi-structured data to be mixed, exposed, and shared across different applications.

RDF Schema (RDFS) is a vocabulary description language, providing basic elements for the description of ontologies, otherwise called RDF vocabularies, intended to structure RDF resources. These resources can be saved in a triplestore to reach a higher level of abstraction of data.

Some key points to remember about RDF and RDF Schema are:
- RDF is a standard model for data interchange on the Web.
- RDF extends the linking structure of the Web to use URIs to name the relationship between things.
- RDF allows structured and semi-structured data to be mixed, exposed, and shared across different applications.
- RDFS is a vocabulary description language, providing basic elements for the description of ontologies.
- RDFS is intended to structure RDF resources.
- RDF resources can be saved in a triplestore to reach a higher level of abstraction of data.
