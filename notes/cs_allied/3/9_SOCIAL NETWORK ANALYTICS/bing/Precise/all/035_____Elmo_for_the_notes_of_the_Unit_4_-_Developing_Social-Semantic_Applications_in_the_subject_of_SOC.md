# Unit 4 - Developing Social-Semantic Applications

### Elmo

- Elmo is a deep contextualized word representation model developed by Allen Institute for Artificial Intelligence (AI2).
- It is a pre-trained model that can be used to generate word embeddings for natural language processing tasks.
- Elmo embeddings are generated by combining the internal states of a deep bidirectional language model, which is pre-trained on a large text corpus.
- The model takes into account the context of the word, meaning that the same word can have different embeddings depending on the context in which it is used.
- Elmo has been shown to improve the performance of many natural language processing tasks, including named entity recognition, sentiment analysis, and question answering.
- Elmo can be easily integrated into existing natural language processing pipelines, making it a popular choice for many applications.
