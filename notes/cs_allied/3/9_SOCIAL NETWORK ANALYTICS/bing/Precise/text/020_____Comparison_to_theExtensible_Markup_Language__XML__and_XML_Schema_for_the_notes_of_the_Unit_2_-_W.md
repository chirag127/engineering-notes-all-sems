### Comparison to the Extensible Markup Language (XML) and XML Schema for the notes of the Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS

- **XML** stands for **Extensible Markup Language**. It is a markup language much like HTML.
- XML was designed to **store and transport data**.
- XML is **extensible**, which means it allows you to create your own self-descriptive tags, or language, that suits your application.
- XML carries the data, but does not present it. It allows you to store the data irrespective of how it will be presented.
- In HTML (Hyper Text Markup Language), both the tag semantics and tag sets are fixed. On the other hand, XML specifies neither semantics nor a tag set. In fact, XML is really a **meta-language** for describing markup languages.
- XML is a **strict serialization** of the Document Object Model.
- XML is a **W3C Recommendation**.
