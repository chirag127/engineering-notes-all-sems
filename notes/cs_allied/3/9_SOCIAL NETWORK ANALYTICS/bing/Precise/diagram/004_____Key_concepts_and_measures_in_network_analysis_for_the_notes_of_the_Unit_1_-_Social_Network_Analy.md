### Key Concepts and Measures in Network Analysis

#### Unit 1 - Social Network Analysis

1. **Nodes**: Nodes represent the individual actors within the networks.
2. **Edges**: Edges are the relationships between the actors in the network.
3. **Degree**: The degree of a node is the number of edges connected to it.
4. **Centrality**: Centrality measures identify the most important nodes in a network. There are several measures of centrality, including degree centrality, closeness centrality, and betweenness centrality.
5. **Density**: The density of a network is the proportion of possible edges that are present in the network.
6. **Clustering Coefficient**: The clustering coefficient measures the extent to which nodes in a network tend to cluster together.
7. **Path Length**: The path length is the number of edges in the shortest path between two nodes.
8. **Connected Components**: A connected component is a subgraph in which any two nodes are connected to each other by a path.
9. **Modularity**: Modularity is a measure of the structure of a network, specifically the degree to which the network can be divided into distinct communities.
