### Descriptive Analysis for the Notes of Unit 5 - Evaluation of Social Network Analysis in the Subject of Social Network Analytics

Descriptive analysis is a method used to summarize and describe the main features of a dataset. In the context of social network analysis, descriptive analysis can be used to evaluate the characteristics of a social network. Here are some key points to consider when conducting a descriptive analysis of a social network:

1. **Network size**: The size of the network can be measured by the number of nodes (actors) and the number of edges (relationships) in the network.

2. **Network density**: Network density is a measure of how connected the nodes in a network are. It is calculated by dividing the number of actual edges in the network by the number of possible edges.

3. **Degree centrality**: Degree centrality is a measure of the importance of a node in a network. It is calculated by counting the number of edges connected to a node.

4. **Betweenness centrality**: Betweenness centrality is a measure of the extent to which a node acts as a bridge between other nodes in the network. It is calculated by counting the number of shortest paths between pairs of nodes that pass through the node of interest.

5. **Closeness centrality**: Closeness centrality is a measure of how close a node is to all other nodes in the network. It is calculated by taking the inverse of the average shortest path length from the node of interest to all other nodes in the network.

6. **Clustering coefficient**: The clustering coefficient is a measure of the extent to which the nodes in a network tend to cluster together. It is calculated by counting the number of closed triangles in the network and dividing by the number of possible triangles.

These are some of the key metrics that can be used in a descriptive analysis of a social network. By evaluating these metrics, one can gain a better understanding of the structure and characteristics of the network. This information can be useful for identifying patterns and trends, and for making informed decisions about how to interact with the network.
