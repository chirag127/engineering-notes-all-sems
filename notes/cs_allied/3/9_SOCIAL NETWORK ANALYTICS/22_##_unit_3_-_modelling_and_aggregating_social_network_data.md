## Unit 3 - Modelling and Aggregating Social Network Data

Unit 3 - Modelling and Aggregating Social Network Data focuses on the techniques and methods for modeling and aggregating social network data. The following topics are covered in this unit:

1. Network representation: techniques for representing social network data, such as graph theory, matrix representation, and network visualization.

2. Network analysis: methods for analyzing social network data, including centrality measures, community detection, and network evolution.

3. Aggregation: techniques for aggregating social network data, such as node-level aggregation, graph-level aggregation, and temporal aggregation.

4. Modeling: methods for modeling the relationships and behaviors in social networks, including link prediction, influence maximization, and network diffusion.

In summary, Unit 3 - Modelling and Aggregating Social Network Data focuses on the techniques and methods for modeling and aggregating social network data, including network representation, network analysis, aggregation, and modeling. These techniques and methods provide a foundation for understanding the structure and behavior of social networks.
