### Electronic sources for network analysis for the notes of the Unit 2 - Web Semantics in Social Network Applications in the subject of SOCIAL NETWORK ANALYTICS

Unit 2 - Web Semantics in Social Network Applications covers the topic of electronic sources for network analysis in social network analytics. Social network analytics is the study of the relationships and connections between individuals in a social network.

The following are key electronic sources for network analysis in social network analytics:

1. Social Media Platforms: Social media platforms, such as Facebook, Twitter, and LinkedIn, are electronic sources of data for network analysis in social network analytics. Social media platforms provide data on the relationships and connections between individuals in a social network.

2. Web Logs: Web logs are records of user activity on a website. Web logs can be used as a source of data for network analysis in social network analytics.

3. APIs: APIs (Application Programming Interfaces) are interfaces that allow access to data from electronic sources. APIs can be used to access data from social media platforms and web logs for network analysis in social network analytics.

4. Data Warehouses: Data warehouses are large data stores that can be used to store and analyze data from electronic sources. Data warehouses can be used to store data from social media platforms and web logs for network analysis in social network analytics.

5. Data Mining Tools: Data mining tools are software applications that can be used to extract, transform, and load data from electronic sources. Data mining tools can be used to extract data from social media platforms and web logs for network analysis in social network analytics.

By understanding these electronic sources, organizations can effectively gather data for network analysis in social network analytics. Unit 2 - Web Semantics in Social Network Applications covers the use of these sources, including social media platforms, web logs, APIs, data warehouses, and data mining tools, in the context of social network analytics.
