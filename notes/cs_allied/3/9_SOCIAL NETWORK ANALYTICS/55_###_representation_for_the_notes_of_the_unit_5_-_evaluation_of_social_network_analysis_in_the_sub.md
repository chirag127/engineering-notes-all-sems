### Representation for the notes of the Unit 5 - Evaluation of Social Network Analysis in the subject of SOCIAL NETWORK ANALYTICS

Representation is a crucial aspect of social network analysis, as it determines how the data is visualized and analyzed. There are several commonly used representations in social network analysis, including:

1. Graph Representation: A graph representation is a visual representation of a network, where nodes represent individuals or entities and edges represent relationships or interactions between them.

2. Matrix Representation: A matrix representation is a numerical representation of a network, where rows and columns represent nodes and entries in the matrix represent edges.

3. Adjacency Matrix: An adjacency matrix is a type of matrix representation where the entries in the matrix are binary values indicating the presence or absence of an edge between two nodes.

4. Adjacency List: An adjacency list is a type of representation where each node is associated with a list of its neighbors.

5. Edge List: An edge list is a type of representation where each edge is represented as a tuple of two nodes.

6. Dynamic Representation: A dynamic representation is a type of representation that takes into account the temporal aspect of the network, such as the order and timing of interactions.

7. Multilayer Representation: A multilayer representation is a type of representation that takes into account multiple types of relationships or interactions between nodes.

In conclusion, representation is a crucial aspect of social network analysis, as it determines how the data is visualized and analyzed. There are several commonly used representations, including graph representation, matrix representation, adjacency matrix, adjacency list, edge list, dynamic representation, and multilayer representation. The choice of representation will depend on the specific requirements of the analysis and the desired outcomes.
