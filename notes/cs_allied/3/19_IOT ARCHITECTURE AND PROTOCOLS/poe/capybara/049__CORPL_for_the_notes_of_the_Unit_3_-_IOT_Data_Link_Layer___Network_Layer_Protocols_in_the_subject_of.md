### CORPL for the notes of the Unit 3 - IOT Data Link Layer & Network Layer Protocols in the subject of IOT ARCHITECTURE AND PROTOCOLS

The following points cover the main concepts related to CORPL in the context of IOT Data Link Layer & Network Layer Protocols:

- CORPL stands for Constrained-Routing Protocol for Low-Power and Lossy Networks.
- It is a network layer protocol designed for constrained devices with limited processing power and memory, such as those used in IOT applications.
- CORPL is based on the RPL (Routing Protocol for Low-Power and Lossy Networks) protocol and extends its functionality to better suit IOT requirements.
- It uses a proactive routing strategy, where nodes periodically exchange routing information to maintain an up-to-date network topology.
- CORPL supports both IPv6 and IPv4 addressing.
- It provides multiple routing metrics, such as hop count, expected transmission count, and link quality, to enable efficient and reliable routing in different network conditions.
- It also supports multicast and anycast communication, allowing efficient distribution of data to multiple receivers or selection of the closest receiver.
- CORPL uses a hierarchical addressing scheme, where each node has a unique address based on its position in the network topology. This allows for efficient routing and scalability in large networks.
- The protocol supports different security mechanisms, such as authentication, confidentiality, and integrity, to ensure secure communication in IOT networks.
- CORPL has been adopted by several standardization organizations, such as IETF and ETSI, and is widely used in IOT applications, such as smart homes, industrial automation, and healthcare monitoring.

Overall, CORPL is a key protocol for enabling efficient and reliable communication in IOT networks with constrained devices. Its unique features make it a suitable choice for various IOT applications, and its adoption by standardization organizations ensures its interoperability and compatibility with different IOT devices and systems.
