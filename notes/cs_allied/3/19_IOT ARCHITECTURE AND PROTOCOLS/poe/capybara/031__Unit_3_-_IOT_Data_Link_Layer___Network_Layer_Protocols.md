## Unit 3 - IOT Data Link Layer & Network Layer Protocols

In this unit, we will be discussing the various protocols used in the data link layer and network layer in IoT.

### Data Link Layer Protocols

1. **IEEE 802.15.4:** This is the most commonly used protocol for the data link layer in IoT devices. It is a low-power, wireless protocol that allows for communication between devices.

2. **ZigBee:** This is another popular protocol used in the data link layer. It is a mesh network protocol that enables communication between devices in a network.

3. **Bluetooth Low Energy (BLE):** This protocol is used for short-range communication between devices. It is commonly used in wearables and other small IoT devices.

4. **Wi-Fi:** This is a widely used protocol for data link layer communication. It allows for high-speed wireless communication between devices and is commonly used in IoT devices that require internet connectivity.

### Network Layer Protocols

1. **IPv4:** This is the most widely used network layer protocol in the world. It is a connectionless protocol that is used to route data packets between devices.

2. **IPv6:** This is the successor to IPv4 and is designed to address the limitations of the older protocol. It provides a larger address space and improved security features.

3. **6LoWPAN:** This is a protocol that is designed to allow IPv6 packets to be transmitted over low-power, wireless networks. It is commonly used in IoT devices that require low power consumption.

4. **MQTT:** This is a messaging protocol that is commonly used in IoT devices for communication between devices and servers. It is lightweight and designed for low-bandwidth networks.

In conclusion, understanding the various data link layer and network layer protocols used in IoT devices is essential for building robust and reliable IoT systems.
