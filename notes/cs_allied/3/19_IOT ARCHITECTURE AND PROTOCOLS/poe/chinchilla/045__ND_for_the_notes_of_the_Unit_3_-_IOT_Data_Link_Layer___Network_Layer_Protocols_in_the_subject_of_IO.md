### ND for the notes of the Unit 3 - IOT Data Link Layer & Network Layer Protocols in the subject of IOT ARCHITECTURE AND PROTOCOLS

The Data Link Layer and Network Layer Protocols are essential components of the Internet of Things (IoT) Architecture. These protocols are responsible for the efficient transfer of data between devices and networks. In this unit, we will discuss the different types of Data Link Layer and Network Layer Protocols used in IoT.

#### Data Link Layer Protocols

1. The Data Link Layer Protocol is responsible for transmitting data over a physical link between devices.

2. There are two types of Data Link Layer Protocols: Wired and Wireless.

3. Wired Data Link Layer Protocols include Ethernet, Token Ring, and Fiber Distributed Data Interface (FDDI).

4. Wireless Data Link Layer Protocols include Bluetooth, WiFi, Zigbee, and Z-Wave.

5. Data Link Layer Protocols provide data integrity and error control by checking for errors and retransmitting data if necessary.

6. Data Link Layer Protocols also provide flow control, which manages the rate of data transmission to prevent data loss or congestion.

#### Network Layer Protocols

1. The Network Layer Protocol is responsible for routing data between devices on different networks.

2. The most commonly used Network Layer Protocol is Internet Protocol (IP).

3. Network Layer Protocols use routing algorithms to determine the best path for data to travel.

4. Network Layer Protocols also provide addressing and fragmentation services.

5. Fragmentation services break large packets of data into smaller packets to ensure efficient transmission.

6. Addressing services assign unique addresses to each device on the network to ensure data is sent to the correct destination.

In conclusion, Data Link Layer and Network Layer Protocols are crucial components of IoT Architecture. They ensure efficient and reliable data transmission between devices and networks. Understanding these protocols is essential for designing and implementing IoT systems.
