## Unit 3 - IOT Data Link Layer & Network Layer Protocols

In this unit, we will discuss the Data Link Layer and Network Layer protocols that are commonly used in IoT devices. These protocols are responsible for establishing communication between devices and ensuring the efficient transfer of data across the network.

### Data Link Layer Protocols

1. **Ethernet**: This is a widely used protocol in IoT devices that provides a physical and data link layer for communication between devices. It uses a wired connection and supports high-speed data transfer.
2. **Wi-Fi**: This protocol provides wireless communication between devices and is commonly used in IoT devices that require remote connectivity. It operates in the 2.4 GHz and 5 GHz frequency bands and supports high-speed data transfer.
3. **Bluetooth**: This protocol is commonly used in IoT devices that require short-range connectivity. It operates in the 2.4 GHz frequency band and supports low-power data transfer.

### Network Layer Protocols

1. **IP (Internet Protocol)**: This is a widely used protocol in IoT devices that provides end-to-end communication across the network. It is responsible for routing packets between devices and ensures that data is delivered to the correct destination.
2. **IPv6 (Internet Protocol version 6)**: This is an updated version of the IP protocol that provides a larger address space and improved security features. It is becoming increasingly popular in IoT devices due to its ability to accommodate the growing number of devices connected to the network.
3. **MQTT (Message Queuing Telemetry Transport)**: This is a lightweight, publish-subscribe protocol that is commonly used in IoT devices to exchange messages between devices. It is designed to operate in low-bandwidth, high-latency networks and supports reliable message delivery.

In conclusion, the Data Link Layer and Network Layer protocols are essential for establishing communication between IoT devices and ensuring the efficient transfer of data across the network. Understanding these protocols is crucial for building reliable and secure IoT systems.
