### IPv4

IPv4 is the fourth version of the Internet Protocol (IP) which is used to identify and communicate with devices on a network. It is a connectionless protocol, which means that it does not establish a connection before transmitting data. Instead, packets of data are sent independently and are reassembled at the receiving end.

Here are some key points about IPv4:

- IPv4 addresses are 32-bit addresses, which means there are approximately 4.3 billion possible unique addresses. This may seem like a large number, but with the growth of the internet and the increasing number of devices, it is becoming more and more difficult to allocate unique addresses to all devices. This is one of the reasons why IPv6 was developed, which has a much larger address space.

- An IPv4 address is typically represented in dotted-decimal notation, which consists of four numbers separated by dots. Each number represents 8 bits of the address, and can range from 0 to 255. For example, 192.168.0.1 is a valid IPv4 address.

- IPv4 packets have a header that contains various fields, including the source and destination IP addresses, the protocol used for the payload, and a checksum for error detection. The payload can contain data from various higher-level protocols, such as TCP or UDP.

- IPv4 packets are routed between devices using routers, which examine the destination IP address and determine the next hop on the path to the destination. This process is known as forwarding. Routers also use various protocols, such as the Routing Information Protocol (RIP) or the Border Gateway Protocol (BGP), to exchange routing information with other routers.

- IPv4 also supports various other features, such as fragmentation and reassembly of packets, multicast addressing, and Quality of Service (QoS) mechanisms for prioritizing traffic.

Overall, IPv4 is a fundamental protocol for communication on the internet and is still widely used today. However, its limited address space and other limitations have led to the development of newer protocols such as IPv6, which offer improved functionality and scalability.
