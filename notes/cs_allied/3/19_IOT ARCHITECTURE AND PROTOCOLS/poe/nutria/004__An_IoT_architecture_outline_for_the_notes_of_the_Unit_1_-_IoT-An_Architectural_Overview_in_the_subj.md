
### An IoT architecture outline for the notes of the Unit 1 - IoT-An Architectural Overview in the subject of IOT ARCHITECTURE AND PROTOCOLS

1. IoT architecture consists of four main layers: physical layer, network layer, application layer, and data layer. 
2. The physical layer is the physical infrastructure of the IoT system. It includes sensors, actuators, and other hardware components.
3. The network layer is responsible for communication between the physical layer and the application layer. It includes networking protocols, such as Bluetooth, Wi-Fi, ZigBee, and 6LoWPAN.
4. The application layer is the interface between the user and the physical layer. It includes software applications, such as mobile apps, web applications, and cloud services.
5. The data layer is responsible for storing, processing, and analyzing data collected from the physical layer. It includes databases, analytics tools, and machine learning algorithms.
