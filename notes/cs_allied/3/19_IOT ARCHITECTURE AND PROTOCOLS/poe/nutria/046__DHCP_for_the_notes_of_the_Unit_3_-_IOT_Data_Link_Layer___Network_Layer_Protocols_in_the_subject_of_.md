
### DHCP for the Notes of Unit 3 - IOT Data Link Layer & Network Layer Protocols

* DHCP stands for Dynamic Host Configuration Protocol. It is a protocol used to provide IP addresses and other information to devices on a network.
* DHCP is used to assign IP addresses to devices on a network, such as computers, printers, and other IOT devices.
* DHCP is a client-server protocol. The DHCP server is responsible for assigning IP addresses to devices, while the DHCP client is responsible for requesting an IP address from the server.
* DHCP is used to assign IP addresses to devices on a network, as well as other information such as subnet mask, default gateway, and DNS server address.
* DHCP can also be used to assign additional parameters such as domain name, host name, and IP lease time.
* DHCP is a broadcast-based protocol, meaning that all DHCP messages are sent to the broadcast address.
* DHCP is a reliable protocol, meaning that it will retransmit any messages that are not received by the client.
* DHCP is a secure protocol, as it uses authentication methods such as DHCP Snooping and DHCP Relay to protect against malicious attacks.
