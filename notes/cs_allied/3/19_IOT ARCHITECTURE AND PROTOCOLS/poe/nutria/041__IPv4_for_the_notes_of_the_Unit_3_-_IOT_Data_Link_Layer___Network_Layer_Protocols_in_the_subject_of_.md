
### IPv4 

- IPv4 is a protocol used in the Internet Protocol Suite (TCP/IP) to send and receive data over the internet. 
- It is a connectionless protocol, meaning that it does not require a connection to be established before sending data. 
- It is a 32-bit addressing system, meaning it can support up to 4,294,967,296 unique addresses. 
- IPv4 is used in the Data Link Layer and Network Layer protocols of the Internet of Things (IoT). 
- It is used to identify devices on a network and route data to its destination. 
- IPv4 is an unreliable protocol, meaning that it does not guarantee that data will be delivered successfully. 
- It is also a connectionless protocol, meaning that it does not require a connection to be established before sending data. 
- IPv4 does not have built-in security features, so it is important to use other security protocols to protect data.
