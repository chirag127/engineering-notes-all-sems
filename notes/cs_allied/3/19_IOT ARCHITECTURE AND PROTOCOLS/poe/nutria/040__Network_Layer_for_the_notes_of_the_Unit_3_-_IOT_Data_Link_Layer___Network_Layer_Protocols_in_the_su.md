

### Network Layer

- The network layer is responsible for the routing of packets from the source to the destination. 
- It is responsible for the logical addressing of nodes in the network, and for the routing of packets from source to destination. 
- It provides the means for establishing, maintaining, and terminating connections between two nodes. 
- It is also responsible for flow control, error control, congestion control, and packet sequencing. 
- The network layer also provides the means for packet fragmentation and reassembly. 
- Examples of network layer protocols include IP, ICMP, and IGMP. 
- IP is used for routing and addressing, while ICMP is used for error reporting and IGMP is used for multicast group membership. 
- Network layer protocols provide the means for routing packets through the network. 
- Routers are used at the network layer to forward packets from one network to another.
