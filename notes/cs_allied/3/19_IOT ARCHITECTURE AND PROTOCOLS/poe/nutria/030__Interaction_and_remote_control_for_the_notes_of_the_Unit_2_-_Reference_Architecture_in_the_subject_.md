
### Interaction and remote control for the notes of the Unit 2 - Reference Architecture in the subject of IOT ARCHITECTURE AND PROTOCOLS

1. Interaction and remote control are two important aspects of the Internet of Things (IoT). 
2. Interaction refers to the ability of devices to communicate with each other and with other systems. 
3. Remote control refers to the ability of a user to control a device from a distance. 
4. The reference architecture for IoT is a blueprint for designing and implementing a secure, reliable, and scalable IoT system. 
5. It provides an overview of the different components of a system and how they interact with each other. 
6. The reference architecture consists of three layers: the device layer, the communication layer, and the application layer. 
7. The device layer consists of the physical devices that make up the system. 
8. The communication layer is responsible for the communication between the devices and the application layer. 
9. The application layer is responsible for the logic and user interface of the system. 
10. Protocols are used to ensure secure and reliable communication between devices and systems. 
11. Popular protocols for IoT include Bluetooth, Wi-Fi, Zigbee, and 6LoWPAN. 
12. Security is an important aspect of IoT systems and protocols should be chosen carefully to ensure secure communication.
