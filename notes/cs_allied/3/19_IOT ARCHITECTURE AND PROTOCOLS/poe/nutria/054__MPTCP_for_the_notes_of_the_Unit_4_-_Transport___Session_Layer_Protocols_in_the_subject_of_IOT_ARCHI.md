
### MPTCP for the notes of the Unit 4 - Transport & Session Layer Protocols in the subject of IOT ARCHITECTURE AND PROTOCOLS

* MPTCP (Multipath Transmission Control Protocol) is a transport layer protocol that allows multiple paths to be used simultaneously for data transmission.
* MPTCP allows data to be split into multiple streams and sent over multiple paths, allowing for more reliable and efficient data transmission.
* MPTCP also supports the use of multiple IP addresses, which can be used to increase the resilience of the connection and improve performance.
* MPTCP is designed to be backward compatible with existing TCP implementations, meaning that it can be used in existing networks without requiring any changes to the existing infrastructure.
* MPTCP is used in a variety of applications, including streaming media, remote desktop, file transfer, and gaming.
* MPTCP can also be used to provide load balancing, allowing multiple paths to be used to send data to the same destination. This can improve performance and reduce latency.
* MPTCP also provides support for Quality of Service (QoS), allowing different types of traffic to be prioritized. This can be used to ensure that important traffic is delivered without delay.
