
## Unit 5 - Service Layer Protocols & Security

1. **Service Layer Protocols** are the set of rules and regulations that govern the communication and data exchange between two or more devices on a network. These protocols are used to ensure that data is transmitted securely and efficiently.

2. **Secure Sockets Layer (SSL)** is one of the most commonly used service layer protocols. It is a cryptographic protocol used to provide secure communication between two or more devices. It encrypts the data sent between the two devices, ensuring that it is not intercepted by third parties.

3. **Transport Layer Security (TLS)** is another service layer protocol that is used to provide secure communication between two or more devices. It is an updated version of SSL, and it has improved features such as better encryption and authentication.

4. **Secure Shell (SSH)** is a network protocol that is used to securely connect two or more devices over a network. It is used to provide secure remote access to systems, as well as to securely transfer files between two or more systems.

5. **IPsec** is a network protocol that is used to provide secure communication between two or more devices over an IP network. It provides authentication, encryption, and data integrity, ensuring that data is transmitted securely and efficiently.
