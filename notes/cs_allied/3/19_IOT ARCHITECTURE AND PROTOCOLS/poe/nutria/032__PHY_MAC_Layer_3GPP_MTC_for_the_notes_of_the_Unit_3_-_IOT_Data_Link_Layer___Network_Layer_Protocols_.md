
### PHY/MAC Layer(3GPP MTC)

1. The Physical (PHY) and Media Access Control (MAC) layer of the 3GPP MTC (Machine-Type Communications) are responsible for the control and communication of the physical layer and the data link layer of the IoT devices.

2. The PHY layer is responsible for the transmission of data over the radio frequencies, and is responsible for the modulation and demodulation of data.

3. The MAC layer is responsible for the control of the data link layer, and is responsible for the scheduling of data transmissions, the control of the access to the shared medium, and the error control of the transmission.

4. The MAC layer is also responsible for the authentication of the devices, and for the control of the data flows.

5. The 3GPP MTC also includes a Network Layer Protocol (NLP) which is responsible for the control of the network layer. The NLP is responsible for the routing of data, the control of the network layer, and the control of the data flows.
