
## Unit 3 - IOT Data Link Layer & Network Layer Protocols

* The Data Link Layer is responsible for the delivery of data frames from one node to another across a physical link. It is the lowest layer of the Open System Interconnection (OSI) model.
* The Network Layer is responsible for the delivery of packets from one node to another across a network. It is the third layer of the OSI model.
* The IOT Data Link Layer Protocols are used to establish and maintain communication between two devices. Examples include Ethernet, Wi-Fi, Bluetooth, Zigbee, and Z-Wave.
* The IOT Network Layer Protocols are used to route data between two devices. Examples include IPv4, IPv6, UDP, and TCP.
* Security is an important factor when it comes to IOT Data Link Layer and Network Layer Protocols. Protocols such as TLS and DTLS are used to ensure data is transmitted securely.
