
### Unit 3 - IOT Data Link Layer & Network Layer Protocols 
1. The Internet of Things (IoT) is a network of connected devices that communicate with each other to provide data and services.
2. The Data Link Layer is responsible for the physical and logical connections between devices and is responsible for the transmission of data between them.
3. The Network Layer is responsible for providing the routing and addressing of data packets on the network.
4. Common protocols used in the Data Link Layer include Ethernet, Wi-Fi, and Bluetooth.
5. Common protocols used in the Network Layer include IP, ICMP, and TCP.
6. These protocols are designed to ensure that data is transmitted securely and reliably on the network.
