
### TCP

TCP (Transmission Control Protocol) is a session layer protocol used to establish a connection between two devices in a network. It is responsible for reliable data transfer over the network and provides reliable data transfer services. It is a connection-oriented protocol that provides a reliable, sequenced delivery of data.

- TCP is a connection-oriented protocol that uses three-way handshaking to establish a connection. 
- It uses a sliding window flow control mechanism for reliable data transfer. 
- It provides error detection and correction services. 
- It ensures that the data is received in the same order in which it was sent. 
- It provides congestion control services to prevent network congestion. 
- It provides end-to-end flow control to ensure that the data is received at the same rate as it is sent. 
- It provides reliable data transfer services by using acknowledgements and retransmissions. 
- It provides flow control services by using window size and window scaling. 
- It provides congestion control services by using slow start, congestion avoidance, and fast retransmit algorithms.
