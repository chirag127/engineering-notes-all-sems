
## Unit 4 - Transport & Session Layer Protocols

1. The transport layer is responsible for end-to-end communication between two applications on different hosts. It provides reliable data transfer and provides services such as error detection and correction, flow control, and connection management.
2. The two main protocols that operate at the transport layer are the Transmission Control Protocol (TCP) and the User Datagram Protocol (UDP).
3. TCP is a connection-oriented protocol that provides reliable data transfer by using acknowledgements and retransmission of lost packets. It also provides services such as flow control, congestion control, and connection management.
4. UDP is a connectionless protocol that provides unreliable data transfer. It does not provide any of the services that TCP provides, but it is faster than TCP due to its lack of connection setup and tear down.
5. The session layer is responsible for establishing, maintaining, and terminating communication sessions between two applications on different hosts. It also provides services such as token management and synchronization.
6. The two main protocols that operate at the session layer are the Session Initiation Protocol (SIP) and the Session Description Protocol (SDP).
7. SIP is a signaling protocol used for initiating, maintaining, and terminating multimedia sessions between two or more participants. It is used for setting up voice and video calls, as well as instant messaging sessions.
8. SDP is a protocol used to describe the properties of a multimedia session, such as the type of media being used, the codecs being used, and the IP addresses and ports of the participants. It is used to negotiate the properties of a multimedia session before it is established.
