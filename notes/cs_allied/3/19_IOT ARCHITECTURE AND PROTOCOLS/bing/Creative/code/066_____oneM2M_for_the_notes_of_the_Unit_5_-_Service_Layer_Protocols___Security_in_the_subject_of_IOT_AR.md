# oneM2M

- oneM2M is a global partnership project founded in 2012 and constituted by 8 of the world's leading ICT standards development organizations.
- oneM2M aims to develop a common service layer that can be readily embedded within various hardware and software, and relied upon to connect the myriad of devices in the field with M2M application servers worldwide.
- oneM2M service layer consists of a suite of common service functions (CSFs) that provide the necessary functionality for IoT applications across different domains and platforms.
- oneM2M service layer is based on a resource-oriented architecture (ROA) that uses RESTful principles and HTTP(S) as the main protocol for communication.
- oneM2M service layer defines a set of common resources that represent the data and functionality of IoT devices and applications, such as containers, subscriptions, access control policies, groups, etc.
- oneM2M service layer also defines a set of common procedures that specify how the resources can be created, retrieved, updated, deleted, and notified by the entities involved in the IoT system, such as applications, devices, gateways, and servers.
- oneM2M service layer supports a hierarchical and distributed architecture, where each node can host one or more common service entities (CSEs) that implement the CSFs and manage the resources.
- oneM2M service layer supports interoperability and scalability by allowing different types of CSEs to communicate with each other using standardized interfaces and protocols, such as Mca, Mcc, Mcn, etc.
- oneM2M service layer supports security and privacy by providing mechanisms for authentication, authorization, encryption, and integrity protection of the data and messages exchanged between the CSEs and the applications.
- oneM2M service layer supports flexibility and extensibility by allowing the definition of custom resources and procedures that can be registered and discovered by other entities in the IoT system.
