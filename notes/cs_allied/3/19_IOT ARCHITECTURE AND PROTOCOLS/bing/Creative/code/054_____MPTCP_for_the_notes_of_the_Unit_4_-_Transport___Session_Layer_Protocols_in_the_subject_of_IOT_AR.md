### MPTCP for the notes of the Unit 4 - Transport & Session Layer Protocols in the subject of IOT ARCHITECTURE AND PROTOCOLS

- MPTCP stands for Multipath TCP, which is an extension of TCP that allows simultaneous data transmission over multiple paths between two endpoints .
- MPTCP can improve the throughput, reliability, and security of data transmission in IoT networks, especially when the IoT devices have multiple network access interfaces, such as Wi-Fi, 4G, 5G, etc .
- MPTCP has several working modes, such as backup mode, which uses one path as the primary path and the others as backup paths in case of failure; and load balancing mode, which distributes the load among all available paths according to their bandwidth and delay.
- MPTCP requires modifications in both the sender and the receiver, as well as the intermediate routers, to support the multipath functionality. MPTCP uses a subflow abstraction to represent each path, and assigns a subflow identifier (Subflow ID) to each subflow. MPTCP also uses a connection identifier (Connection ID) to identify the whole MPTCP connection .
- MPTCP has some challenges and limitations in IoT networks, such as the overhead of maintaining multiple subflows, the compatibility issues with legacy TCP applications and devices, the security risks of exposing multiple paths to attackers, and the fairness problems with competing TCP flows .
- MPTCP has been implemented and evaluated on various platforms, such as Linux, Android, and iOS, but there are no official MPTCP kernels for IoT devices yet. Some research works have proposed and tested MPTCP-based IoT routers, which use multiple radios to connect to a server and provide resilient and high-performance Internet connections for IoT devices .
- MPTCP can also be combined with other techniques, such as opportunistic routing, which selects the best next hop for each packet based on the current network conditions, to further improve the performance and robustness of IoT communication.
