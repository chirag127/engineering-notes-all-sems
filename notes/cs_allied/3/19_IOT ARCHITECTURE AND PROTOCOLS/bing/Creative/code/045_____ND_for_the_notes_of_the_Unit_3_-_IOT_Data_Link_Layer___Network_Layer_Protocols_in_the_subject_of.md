## Data Link Layer Protocols

- The data link layer provides service to the network layer and is responsible for reliable transmission of data frames between nodes on the same network.
- There are various protocols and standard technologies specified by different organizations for data link protocols.
- Some of the common data link protocols in IoT are:
  - **Bluetooth**: A short-range wireless communication network over a radio frequency. It supports point-to-point and point-to-multipoint connections and can be used for data exchange, audio streaming, and device control.
  - **Wi-Fi**: A wireless LAN technology that uses radio waves to provide high-speed internet access and network connections. It supports various standards such as IEEE 802.11a/b/g/n/ac/ax and can be used for home automation, smart appliances, and cloud computing.
  - **ZigBee**: A low-power, low-data-rate, and low-cost wireless mesh network protocol based on IEEE 802.15.4 standard. It is designed for applications that require long battery life, network scalability, and self-healing capabilities. It can be used for smart lighting, smart metering, and industrial automation.
  - **Z-Wave**: A wireless communication protocol that operates in the sub-GHz frequency band and provides low-latency, low-power, and secure data transmission. It is mainly used for home automation and smart security systems and supports up to 232 devices per network.
  - **LoRaWAN**: A long-range, low-power, and wide-area network protocol that uses LoRa modulation technique to enable bidirectional communication between IoT devices and gateways. It supports various classes of devices and can be used for smart cities, smart agriculture, and smart logistics.

## Network Layer Protocols

- The network layer is responsible for addressing and routing of data packets between different networks.
- It provides service to the transport layer and uses various protocols and standards to enable interoperability and scalability of IoT systems.
- Some of the common network layer protocols in IoT are:
  - **IPv4**: The fourth version of the Internet Protocol that uses 32-bit addresses to identify devices and networks on the internet. It supports various features such as fragmentation, checksum, and options, but has a limited address space and does not support mobility and security natively.
  - **IPv6**: The sixth version of the Internet Protocol that uses 128-bit addresses to identify devices and networks on the internet. It supports various features such as auto-configuration, mobility, security, and multicast, and has a large address space and a simplified header format.
  - **6LoWPAN**: A protocol that enables the transmission of IPv6 packets over low-power wireless personal area networks (LoWPANs) such as IEEE 802.15.4, Bluetooth Low Energy, and NFC. It supports various mechanisms such as header compression, fragmentation, and adaptation to enable efficient and reliable communication between constrained IoT devices.
  - **RPL**: A routing protocol for low-power and lossy networks (LLNs) that uses a directed acyclic graph (DAG) structure to establish routes between IoT devices and gateways. It supports various features such as loop avoidance, multipath routing, and objective functions to optimize the performance and reliability of IoT networks.
  - **CoAP**: A lightweight application protocol that enables constrained IoT devices to communicate with web services using RESTful principles. It supports various features such as asynchronous message exchange, resource discovery, caching, and observation to enable efficient and scalable communication between IoT devices and servers.
