### Functional View for the notes of the Unit 2 - Reference Architecture in the subject of IOT ARCHITECTURE AND PROTOCOLS

The functional view of the IoT reference architecture describes the system's runtime functional components, their responsibilities, default functions, interfaces and primary interactions . The functional view is use-case- and application-independent and is therefore not compatible to the concept of views and viewpoints one-by-one. The functional view follows the modular structure of functional blocks organized into layers, as it was proposed e.g. in SENSEI.

The functional view of the IoT reference architecture consists of the following layers  :

- Device Layer: This layer contains the physical devices that are connected to the IoT system, such as sensors, actuators, RFID tags, smartphones, etc. The device layer is responsible for providing data acquisition, data processing, data storage, data transmission and actuation capabilities to the IoT system. The device layer also includes the device management functions, such as device discovery, registration, configuration, monitoring and maintenance.
- Network Layer: This layer contains the communication infrastructure that enables data exchange between the devices and the other layers of the IoT system. The network layer is responsible for providing connectivity, routing, addressing, security, quality of service and reliability functions to the IoT system. The network layer also includes the network management functions, such as network discovery, configuration, monitoring and maintenance.
- Service Layer: This layer contains the software components that provide the core functionality of the IoT system, such as data processing, data analysis, data aggregation, data fusion, data visualization, etc. The service layer is responsible for providing service discovery, service composition, service orchestration, service execution and service management functions to the IoT system. The service layer also includes the service governance functions, such as service registration, service description, service publication, service discovery, service access control and service monitoring.
- Application Layer: This layer contains the software components that provide the specific functionality of the IoT system for a particular domain or use case, such as smart home, smart city, smart health, smart agriculture, etc. The application layer is responsible for providing application logic, application presentation, application interaction and application management functions to the IoT system. The application layer also includes the application governance functions, such as application registration, application description, application publication, application discovery, application access control and application monitoring.

The functional view of the IoT reference architecture also defines the cross-layer functions that span across multiple layers of the IoT system, such as security, privacy, trust, identity, context, semantics, etc. These functions are responsible for providing the non-functional requirements of the IoT system, such as confidentiality, integrity, availability, authenticity, accountability, etc. The cross-layer functions also include the cross-layer governance functions, such as policy definition, policy enforcement, policy evaluation and policy auditing .
