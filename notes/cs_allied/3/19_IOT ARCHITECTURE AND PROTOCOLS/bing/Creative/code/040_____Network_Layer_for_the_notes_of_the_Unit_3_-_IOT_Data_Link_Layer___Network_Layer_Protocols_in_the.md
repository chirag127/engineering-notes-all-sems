# Network Layer for the notes of the Unit 3 - IOT Data Link Layer & Network Layer Protocols in the subject of IOT ARCHITECTURE AND PROTOCOLS

- The network layer is part of the infrastructure layer in the IoT reference architecture .
- The network layer is responsible for addressing and routing of data packets  .
- The network layer consists of two sub-layers: the routing layer and the encapsulation layer.
- The routing layer sends packets from origin to destination using various routing protocols.
- The encapsulation layer is responsible for creating packets by adding headers and trailers to the datagrams from the transport layer.
- The network layer uses IP addressing to identify and locate devices in the IoT system .
- The network layer can use different versions of IP, such as IPv4, IPv6, or 6LoWPAN, depending on the requirements and constraints of the IoT devices and networks  .
- The network layer can also use various network devices and communication types and protocols, such as 5G, Wi-Fi, Bluetooth, ZigBee, etc., to provide connectivity and communication between devices and the wider internet .
- The network layer is essential for enabling interoperability, scalability, and security of the IoT system  .
