## Unit 3 - IOT Data Link Layer & Network Layer Protocols

### Data Link Layer Protocols
- The data link layer is responsible for providing reliable and efficient communication between devices on the same network segment or link.
- The data link layer protocols for IOT devices include:
  - IEEE 802.15.4: A low-rate wireless personal area network (LR-WPAN) standard that defines the physical and MAC layers for low-power and low-cost devices. It supports star, mesh, and cluster-tree network topologies and provides security, channel access, and network management features. It is the basis for ZigBee, 6LoWPAN, and other IOT protocols.
  - Bluetooth Low Energy (BLE): A wireless technology that enables short-range communication between devices with low power consumption and high data rates. It supports point-to-point, broadcast, and mesh network topologies and provides security, pairing, and discovery features. It is widely used for wearable devices, smart home, and health care applications.
  - LoRa: A long-range and low-power wireless technology that uses spread spectrum modulation to enable communication between devices over distances of up to 15 km. It supports star and mesh network topologies and provides security, channel access, and network management features. It is mainly used for smart city, agriculture, and industrial IOT applications.
  - NB-IoT: A narrowband cellular technology that uses licensed spectrum to provide low-power and wide-area network (LPWAN) connectivity for IOT devices. It supports point-to-multipoint and broadcast network topologies and provides security, mobility, and quality of service features. It is mainly used for smart metering, smart parking, and smart lighting applications.

### Network Layer Protocols
- The network layer is responsible for providing routing and addressing functions for data packets across different networks or segments.
- The network layer protocols for IOT devices include:
  - IPv6: The latest version of the Internet Protocol that provides a larger address space, improved security, and enhanced mobility features for IOT devices. It supports various addressing schemes, such as global unicast, multicast, anycast, and unique local addresses, and various extension headers, such as routing, fragmentation, and hop-by-hop options.
  - 6LoWPAN: A protocol that enables the transmission of IPv6 packets over IEEE 802.15.4 networks. It provides header compression, fragmentation, and reassembly functions to reduce the overhead and adapt to the low-bandwidth and low-MTU characteristics of LR-WPANs. It also supports mesh-under and route-over forwarding modes for routing packets across multiple hops.
  - RPL: A routing protocol for low-power and lossy networks (LLNs) that are composed of IOT devices with limited resources and unreliable links. It provides a distributed and loop-free routing mechanism based on a destination-oriented directed acyclic graph (DODAG) structure. It also supports various objective functions, such as minimizing hop count, maximizing link quality, or minimizing energy consumption, to optimize the routing performance.
  - CoAP: A protocol that enables the application layer communication between IOT devices using the RESTful architecture. It provides a lightweight and asynchronous message exchange model based on request/response and observe/notify patterns. It also supports various features, such as URI, content formats, discovery, caching, and security, to enable interoperability and scalability of IOT applications.
