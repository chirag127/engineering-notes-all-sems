# IOT ARCHITECTURE AND PROTOCOLS

- IoT architecture refers to the many ways that IoT devices are structured to meet user needs. Based on complexity, IoT system elements are grouped into 3 to 7 layers, each with its own role.
- IoT protocols are the set of rules that enable communication between IoT devices, gateways, services, and data centers. Different IoT protocols have been designed and optimized for different scenarios and usage.
- A common IoT architecture consists of the following layers:
  - Perception layer: This layer is responsible for sensing, collecting, and processing data from the physical world. It consists of sensors, actuators, and embedded devices that can communicate with each other or with a gateway.
  - Network layer: This layer is responsible for transmitting data from the perception layer to the application layer or vice versa. It consists of various wireless or wired communication technologies, such as Wi-Fi, Bluetooth, Zigbee, LoRa, NB-IoT, etc.
  - Middleware layer: This layer is responsible for providing services and functions to support the application layer. It consists of cloud platforms, databases, analytics, security, and management tools that can store, process, and visualize data from the network layer.
  - Application layer: This layer is responsible for providing the interface between the user and the device within a given IoT protocol. It consists of various applications and services that can control, monitor, and optimize the IoT system, such as smart home, smart city, smart agriculture, etc.
  - Business layer: This layer is responsible for providing the value proposition and business model for the IoT system. It consists of various stakeholders, such as customers, providers, regulators, and investors, that can benefit from the IoT system.

- Some of the popular IoT protocols used in different layers are:
  - NFC: Near Field Communication (NFC) technology is used to communicate between two electronic devices within 4cm. Typical applications: Payments, Keycards, Security, etc.
  - LoRa: LoRa and related protocols are relative new comers in this growing field. They are designed for low-power, long-range, and low-bandwidth communication. Typical applications: Smart metering, Smart farming, Smart parking, etc.
  - BLE: Bluetooth 4.0 is the specification that also include BLE and it is widely deployed. It is designed for short-range, low-power, and high-bandwidth communication. Typical applications: Wearables, Health monitoring, Beacons, etc.
  - Zigbee: Zigbee is a mesh network protocol that operates in the 2.4 GHz band. It is designed for low-power, low-cost, and low-data-rate communication. Typical applications: Smart lighting, Smart home, Industrial automation, etc.
  - Z-Wave: Z-Wave is another mesh network protocol that operates in the sub-GHz band. It is designed for low-power, low-cost, and low-data-rate communication. Typical applications: Smart home, Smart security, Smart energy, etc.
  - NB-IoT: Narrowband IoT (NB-IoT) is a cellular network protocol that operates in the licensed spectrum. It is designed for low-power, wide-area, and low-bandwidth communication. Typical applications: Smart city, Smart grid, Smart logistics, etc.
  - Wi-Fi HaLow or IEEE 802.11ah: Wi-Fi HaLow is a Wi-Fi protocol that operates in the sub-GHz band. It is designed for low-power, long-range, and high-bandwidth communication. Typical applications: Smart home, Smart city, Smart agriculture, etc.
