# CORPL

CORPL (Constrained RESTful Protocol) is a protocol designed for use in the Internet of Things (IoT) Data Link Layer and Network Layer Protocols. It is part of the Unit 3 - IoT Data Link Layer & Network Layer Protocols in the subject of IoT Architecture and Protocols.

- CORPL is a lightweight protocol that is designed to be used in constrained environments, such as those found in IoT devices.
- It is based on the RESTful architecture, which means that it uses standard HTTP methods (GET, POST, PUT, DELETE) to interact with resources.
- CORPL is designed to be used with CoAP (Constrained Application Protocol), which is a protocol that is also designed for use in constrained environments.
- The main advantage of using CORPL is that it allows for the efficient transfer of data between IoT devices and the cloud, while still maintaining a high level of security.
- CORPL is still a relatively new protocol, and as such, it is still being developed and improved upon.
