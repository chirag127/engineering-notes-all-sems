# IoT Reference Model

The IoT Reference Model aims at establishing a common grounding and a common language for IoT architectures and IoT systems. It consists of several sub-models, which are used as the basis for one another .

The foundation of the IoT Reference Model is the IoT Domain Model, which introduces the main concepts of the Internet of Things like Devices, IoT Services, and Virtual Entities (VE), and it also introduces relations between these concepts .

The first major contribution of the IoT Architectural Reference Model (IoT ARM) is the IoT Reference Model itself. Besides models, the IoT Reference Model provides the concepts and definitions on which IoT architectures can be built .
