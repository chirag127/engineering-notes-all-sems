# ETSI M2M

ETSI M2M is a standard defined by the European Telecommunications Standards Institute (ETSI) for the Internet of Things (IoT) and Machine to Machine (M2M) communication. ETSI has defined a comprehensive set of common security mechanisms to protect the IoT/M2M system. These mechanisms include Service Bootstrapping, Service Connection, and mId Security. For each mechanism, there are several protocols that can be chosen .

The ETSI M2M Reference Architecture is a high-level functional architecture that consists of the Device and Gateway Domain and the Network Domain . The Device and Gateway domain includes smart devices such as sensors .

ETSI is also one of the founding partners in oneM2M, the global standards initiative that covers requirements, architecture, Application Programming Interface (API) specifications, security solutions, and interoperability for M2M and IoT technologies .
