# ZWave

ZWave is a wireless communication protocol that operates in the frequency of 900MHz. It is suitable for small messages in IoT applications for home automation, with a data transfer rate of 100kbps and a range of 30 to 100 meters .

The ZWave protocol stack contains five layers: physical layer, MAC layer, transport layer, network layer, and application layer. The physical layer is responsible for modulation and coding, and data is transferred in 8-bit blocks with the most significant bit sent first .

The ZWave Network Layer (NWK) defines a multi-hop routing protocol, which is employed by ZWave nodes to extend their communication range. This means that ZWave nodes can send frames to nodes that are not in direct radio communication range .

ZWave technology is based on low power RF (Radio Frequency) and creates a wireless Mesh network. It is a more secure technology .
