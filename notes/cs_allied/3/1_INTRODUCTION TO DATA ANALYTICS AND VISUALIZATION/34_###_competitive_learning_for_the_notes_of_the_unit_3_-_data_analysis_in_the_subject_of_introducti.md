### competitive learning for the notes of the Unit 3 - Data Analysis in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

Competitive learning is a type of unsupervised machine learning algorithm. It is used to classify data into several clusters based on their similarity. The algorithm works by having each data point compete with other data points to be the closest to a randomly initialized prototype vector. The prototype vector is then updated to be the mean of the data points assigned to it. This process is repeated until the prototypes no longer change or a stopping criterion is met. Competitive learning is useful for exploratory data analysis and can be used in conjunction with other algorithms for more complex tasks. Some popular competitive learning algorithms include the Kohonen Self-Organizing Map and the Adaptive Resonance Theory.
