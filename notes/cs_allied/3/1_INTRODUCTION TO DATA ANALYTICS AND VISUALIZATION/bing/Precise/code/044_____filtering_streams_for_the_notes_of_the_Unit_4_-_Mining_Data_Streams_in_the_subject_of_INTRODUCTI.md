### Filtering Streams

Filtering streams is a technique used in mining data streams to extract useful information from a continuous stream of data. This technique is used in the subject of Introduction to Data Analytics and Visualization, specifically in Unit 4 - Mining Data Streams. Here are some key points to remember about filtering streams:

1. Filtering streams involves selecting only the relevant data from a continuous stream of data.
2. This technique is useful when dealing with large amounts of data, as it allows for the extraction of only the most relevant information.
3. Filtering can be done in real-time, allowing for the immediate processing of data as it is received.
4. Common filtering techniques include sampling, windowing, and sketching.
5. Sampling involves selecting a representative subset of the data for analysis.
6. Windowing involves analyzing only the most recent data in the stream.
7. Sketching involves creating a summary of the data stream that can be used for analysis.

These are some of the key points to remember when studying filtering streams in the context of mining data streams. It is an important technique to understand when working with large amounts of data in real-time.
