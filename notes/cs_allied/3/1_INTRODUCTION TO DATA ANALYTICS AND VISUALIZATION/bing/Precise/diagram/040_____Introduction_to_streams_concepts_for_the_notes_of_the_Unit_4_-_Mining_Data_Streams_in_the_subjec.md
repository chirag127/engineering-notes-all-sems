### Introduction to Streams Concepts

#### Unit 4 - Mining Data Streams in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. A **data stream** is a continuous flow of data that is generated in real-time.
2. Data streams are often generated by sensors, social media platforms, financial transactions, and other sources that produce data at a high rate.
3. The data in a stream is typically unbounded, meaning that there is no predetermined end to the stream.
4. Mining data streams involves extracting useful information from the continuous flow of data.
5. Common techniques for mining data streams include classification, clustering, and anomaly detection.
6. Due to the large volume and high velocity of data in streams, traditional data mining techniques may not be suitable for mining data streams.
7. Instead, algorithms for mining data streams must be able to process data in real-time and adapt to changes in the data over time.
8. One approach to mining data streams is to use a sliding window model, where only the most recent data in the stream is considered for analysis.
9. Another approach is to use a synopsis data structure, such as a sketch or a sample, to summarize the data in the stream and enable efficient analysis.
