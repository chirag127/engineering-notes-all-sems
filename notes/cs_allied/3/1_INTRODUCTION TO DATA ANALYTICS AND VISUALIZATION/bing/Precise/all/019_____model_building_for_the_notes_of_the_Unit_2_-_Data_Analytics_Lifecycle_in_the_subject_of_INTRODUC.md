# Model Building

Model building is an important step in the Data Analytics Lifecycle, which is covered in Unit 2 of the subject Introduction to Data Analytics and Visualization. Here are some key points to remember about model building:

1. **Model building** involves selecting the appropriate algorithm and training the model using the available data.
2. The goal of model building is to create a model that accurately represents the relationship between the input variables and the output variable.
3. There are many different algorithms that can be used for model building, including regression, decision trees, and neural networks.
4. The choice of algorithm depends on the type of data, the nature of the relationship between the input and output variables, and the desired accuracy of the model.
5. Model building requires a thorough understanding of the data, including its distribution, outliers, and missing values.
6. The model should be validated using a separate dataset to ensure that it accurately represents the relationship between the input and output variables.
7. Model building is an iterative process, and the model may need to be refined and retrained multiple times before it accurately represents the relationship between the input and output variables.
