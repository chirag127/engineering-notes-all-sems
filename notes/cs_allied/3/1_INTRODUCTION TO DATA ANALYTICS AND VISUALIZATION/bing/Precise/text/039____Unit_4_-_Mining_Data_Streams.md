## Unit 4 - Mining Data Streams

1. **Introduction to Data Streams:** A data stream is a continuous flow of data, often generated in real-time by various sources. Examples of data streams include sensor data, financial transactions, and social media activity.

2. **Challenges in Mining Data Streams:** Due to the continuous and potentially infinite nature of data streams, traditional data mining techniques may not be applicable. Some challenges in mining data streams include the need for real-time processing, handling concept drift, and dealing with high-dimensional data.

3. **Sampling Techniques:** One approach to mining data streams is to use sampling techniques to extract a representative subset of the data for analysis. Common sampling techniques include reservoir sampling and sliding window sampling.

4. **Sketching Techniques:** Sketching techniques are used to create compact summaries of data streams, allowing for efficient analysis. Examples of sketching techniques include count-min sketch and bloom filters.

5. **Stream Classification:** Stream classification involves building models to classify data points in a data stream. Techniques for stream classification include decision trees, naive Bayes, and k-nearest neighbors.

6. **Stream Clustering:** Stream clustering involves grouping similar data points in a data stream. Techniques for stream clustering include density-based clustering and grid-based clustering.

7. **Change Detection:** Change detection involves identifying changes in the underlying distribution of a data stream. Techniques for change detection include cumulative sum (CUSUM) and Page-Hinkley test.

8. **Applications of Mining Data Streams:** Mining data streams has a wide range of applications, including fraud detection, network monitoring, and predictive maintenance.
