### Sources and nature of data for the notes of the Unit 1 - Introduction to Data Analytics in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. **Data sources**: Data can be obtained from various sources such as databases, data warehouses, data lakes, APIs, web scraping, surveys, and social media platforms.
2. **Structured data**: Structured data is data that is organized in a predefined manner, such as in a table with rows and columns. It is easy to search, analyze, and manipulate.
3. **Unstructured data**: Unstructured data is data that is not organized in a predefined manner, such as text, images, and videos. It is more difficult to search, analyze, and manipulate than structured data.
4. **Semi-structured data**: Semi-structured data is data that is not organized in a predefined manner, but contains some elements of structure, such as tags or metadata. It is easier to search, analyze, and manipulate than unstructured data, but more difficult than structured data.
5. **Big data**: Big data refers to data sets that are too large and complex to be processed using traditional data processing methods. It is characterized by the 3Vs: volume, variety, and velocity.
6. **Data quality**: Data quality refers to the accuracy, completeness, consistency, and reliability of data. High-quality data is essential for accurate and reliable data analysis.
7. **Data preprocessing**: Data preprocessing is the process of cleaning, transforming, and organizing data to prepare it for analysis. It includes tasks such as data cleaning, data integration, data transformation, and data reduction.
