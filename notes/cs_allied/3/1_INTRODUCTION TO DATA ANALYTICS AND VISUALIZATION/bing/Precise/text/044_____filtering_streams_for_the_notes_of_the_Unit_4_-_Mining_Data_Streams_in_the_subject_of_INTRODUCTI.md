### Filtering Streams

Filtering streams is a technique used in the field of data stream mining to extract useful information from continuous streams of data. It is a part of Unit 4 - Mining Data Streams in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION. Here are some key points to remember about filtering streams:

1. Filtering streams involves selecting only the relevant data from a continuous stream of data.
2. This technique is useful when dealing with large volumes of data, as it allows for the efficient processing of the data by only considering the relevant information.
3. Filtering can be done in real-time, allowing for the immediate processing of the data as it is generated.
4. Common filtering techniques include sampling, windowing, and aggregation.
5. Sampling involves selecting a representative subset of the data for analysis.
6. Windowing involves dividing the data stream into fixed-size segments, or windows, and processing each window individually.
7. Aggregation involves combining multiple data points into a single value, such as calculating the average or sum of the data points.
