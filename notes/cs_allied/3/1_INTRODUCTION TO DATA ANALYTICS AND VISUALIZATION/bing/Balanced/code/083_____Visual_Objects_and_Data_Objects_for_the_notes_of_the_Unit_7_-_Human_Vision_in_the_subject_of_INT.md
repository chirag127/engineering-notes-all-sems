### Visual Objects and Data Objects

- Visual objects are any identifiable, separate, and distinct parts of the visual world that have certain visual attributes, such as shape, color, size, position, orientation, texture, etc. 
- Data objects are any abstract entities that have certain data values, such as numbers, strings, categories, dates, etc. 
- Visual objects and data objects can be mapped to each other using visual encoding, which is the process of assigning data values to visual features of visual objects. 
- Visual encoding can be used to create effective visualizations that convey information about the data objects and their relationships, such as patterns, trends, outliers, clusters, etc. 
- Visual encoding can be based on different principles, such as:
  - Expressiveness: the visual features should match the data values in a meaningful way, such as using position for quantitative data, shape for categorical data, etc. 
  - Effectiveness: the visual features should be easy to perceive and compare, such as using size for ordered data, hue for nominal data, etc. 
  - Efficiency: the visual features should use the available space and resources optimally, such as using small multiples for multiple data sets, avoiding clutter and overlap, etc. 
- Visual objects and data objects can also be manipulated using interactive techniques, such as:
  - Selection: the user can select one or more visual objects to highlight or filter the corresponding data objects.
  - Navigation: the user can zoom, pan, or rotate the visual objects to change the level of detail or perspective of the data objects.
  - Transformation: the user can change the visual encoding of the visual objects to alter the representation of the data objects, such as changing the scale, color, shape, etc.
  - Annotation: the user can add text, symbols, or images to the visual objects to provide additional information or context about the data objects.
