# Visual Objects and Data Objects

- Visual objects are any identifiable, separate, and distinct parts of the visual world that have certain visual attributes, such as shape, color, size, position, orientation, texture, etc. 
- Data objects are any abstract entities that have certain data values, such as numbers, strings, categories, dates, etc.
- Visual objects and data objects can be mapped to each other using visual encoding, which is the process of assigning data values to visual features of visual objects. 
- Visual encoding can help us organize, explore, and communicate data in a meaningful and efficient way, by leveraging the human visual system and cognition. 
- Some examples of visual objects and data objects are:
  - A bar chart, where each bar is a visual object and each bar's height is a visual feature that encodes a data value (such as sales, population, etc.).
  - A pie chart, where each slice is a visual object and each slice's angle is a visual feature that encodes a data value (such as percentage, proportion, etc.).
  - A scatter plot, where each point is a visual object and each point's position is a visual feature that encodes two data values (such as x and y coordinates, income and education, etc.).
  - A map, where each region is a visual object and each region's color is a visual feature that encodes a data value (such as temperature, population density, etc.).
- Some principles and guidelines for choosing appropriate visual objects and data objects are:
  - Use visual objects that are easy to perceive, compare, and manipulate, such as simple geometric shapes, familiar icons, or natural objects. 
  - Use visual objects that are consistent with the data type, dimensionality, and structure, such as bars for quantitative data, pies for categorical data, lines for temporal data, etc. 
  - Use visual objects that are compatible with the task, goal, and audience, such as charts for summarizing data, maps for spatial data, graphs for relational data, etc. 
  - Use visual objects that are expressive, informative, and aesthetically pleasing, such as objects that convey meaning, emotion, or personality, without sacrificing clarity, accuracy, or functionality.
