# Modern Data Analytic Tools

- Data analytic tools are software applications that enable users to collect, process, analyze, and visualize data from various sources.
- Data analytic tools can help users to gain insights, make decisions, solve problems, and communicate findings based on data.
- Modern data analytic tools are designed to handle large and complex data sets, often referred to as big data, and to leverage advanced techniques such as machine learning, artificial intelligence, and cloud computing.
- Some of the modern data analytic tools that are widely used in various domains and industries are:

  - **Python**: Python is a general-purpose programming language that supports multiple paradigms such as object-oriented, functional, and procedural. Python has a rich set of libraries and frameworks for data analysis, such as NumPy, pandas, SciPy, scikit-learn, TensorFlow, PyTorch, and Keras . Python is also compatible with many other data analytic tools, such as Apache Spark, Jupyter Notebook, and Power BI.
  - **R**: R is a programming language and environment for statistical computing and graphics. R has a comprehensive collection of packages for data manipulation, visualization, modeling, and machine learning, such as dplyr, ggplot2, tidyr, caret, and mlr . R can also be integrated with other data analytic tools, such as Apache Spark, Jupyter Notebook, and Power BI.
  - **SAS**: SAS is a software suite for data management, analysis, and reporting. SAS offers various products and solutions for different data analytic needs, such as SAS Enterprise Guide, SAS Enterprise Miner, SAS Visual Analytics, and SAS Viya. SAS can handle structured and unstructured data, and perform various tasks such as data cleansing, transformation, integration, mining, modeling, and visualization.
  - **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel can perform basic and advanced calculations, create charts and graphs, and import and export data from various sources . Excel can also be enhanced with add-ins and features such as Power Query, Power Pivot, and Power View, which enable users to connect to, model, and visualize data from multiple sources.
  - **Power BI**: Power BI is a business intelligence and data visualization tool that is part of the Microsoft Power Platform. Power BI can connect to various data sources, such as databases, files, web services, and cloud platforms, and create interactive dashboards and reports that can be shared and accessed online  . Power BI can also leverage the capabilities of other Microsoft tools, such as Excel, Azure, and AI Builder .
  - **Tableau**: Tableau is a data visualization and analytics platform that enables users to create and explore data stories using intuitive and interactive visualizations. Tableau can connect to various data sources, such as files, databases, web services, and cloud platforms, and provide features such as data blending, filtering, grouping, and aggregation . Tableau can also support advanced analytics, such as predictive modeling, clustering, and natural language processing.
  - **Apache Spark**: Apache Spark is an open-source distributed computing framework that can process large-scale data sets in parallel and in memory. Apache Spark supports various programming languages, such as Scala, Java, Python, and R, and provides libraries and modules for different data analytic tasks, such as Spark SQL, Spark Streaming, Spark MLlib, and Spark GraphX . Apache Spark can also integrate with other data analytic tools, such as Hadoop, Jupyter Notebook, and Power BI.
