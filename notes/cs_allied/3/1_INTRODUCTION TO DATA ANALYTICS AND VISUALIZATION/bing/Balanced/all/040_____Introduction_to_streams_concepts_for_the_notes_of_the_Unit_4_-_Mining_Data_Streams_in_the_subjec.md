# Introduction to streams concepts

- A data stream is an existing, continuous, ordered (implicitly by entrance time or explicitly by timestamp) chain of items.
- Sources of streaming data include equipment sensors, clickstreams, social media feeds, stock market quotes, app activity, and more.
- Streaming analytics is the continuous processing and analysis of big data in motion.
- Streaming analytics is about processing data in real time, which is any method of data processing that results in a latency period defined as “real-time”.
- Streaming analytics can be used for various purposes, such as detecting anomalies, generating alerts, making decisions, and providing insights.
- Stream processing is a data management technique that involves ingesting a continuous data stream to quickly analyze, filter, transform or enhance the data in real time.
- Stream processing can be done by using various tools and frameworks, such as Apache Kafka, Apache Spark, Apache Flink, Apache Storm, and more.
- Stream processing can be integrated with other data systems, such as data lakes, data warehouses, databases, and applications.
- Stream processing can enable various benefits, such as faster insights, lower costs, higher scalability, and better customer experience.
- Stream processing can also pose various challenges, such as handling data quality, data volume, data velocity, data variety, and data veracity.
