## Unit 6 - Introduction to Visualization

- Visualization is the process of creating and displaying graphical representations of data or information.
- Visualization can help users to explore, analyze, communicate, and understand data or information more effectively and efficiently.
- Visualization can be classified into different types based on the purpose, audience, data, and technique of the visual representation.
- Some common types of visualization are:

  - **Charts**: Charts are graphical displays of quantitative data, such as bar charts, pie charts, line charts, scatter plots, etc. Charts can show trends, patterns, distributions, correlations, or comparisons of data.
  - **Maps**: Maps are graphical displays of spatial data, such as geographic locations, regions, routes, or boundaries. Maps can show the physical or abstract features of a space, such as terrain, climate, population, or political divisions.
  - **Diagrams**: Diagrams are graphical displays of conceptual data, such as processes, structures, relationships, or hierarchies. Diagrams can show the logic, order, flow, or organization of data, such as flowcharts, network diagrams, tree diagrams, etc.
  - **Infographics**: Infographics are graphical displays of mixed data, such as facts, statistics, images, icons, or text. Infographics can show the context, meaning, or story of data, such as timelines, comparisons, lists, or summaries.
  - **Dashboards**: Dashboards are graphical displays of multiple data, such as charts, maps, diagrams, or infographics. Dashboards can show the overview, status, or performance of data, such as key indicators, metrics, or goals.

- Visualization can be created and displayed using various tools, such as software applications, web platforms, or programming languages.
- Some common tools for visualization are:

  - **Excel**: Excel is a spreadsheet application that can create and display charts, tables, and pivot tables from data.
  - **Power BI**: Power BI is a business intelligence platform that can create and display dashboards, reports, and interactive visualizations from data.
  - **Tableau**: Tableau is a data visualization software that can create and display interactive and dynamic visualizations from data.
  - **Python**: Python is a programming language that can create and display visualizations from data using libraries such as matplotlib, seaborn, plotly, etc.
  - **R**: R is a programming language that can create and display visualizations from data using libraries such as ggplot2, lattice, shiny, etc.
