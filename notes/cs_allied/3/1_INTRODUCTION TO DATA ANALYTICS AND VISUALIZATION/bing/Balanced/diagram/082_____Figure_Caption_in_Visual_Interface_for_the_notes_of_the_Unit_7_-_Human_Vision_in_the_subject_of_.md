### Figure Caption in Visual Interface

- A figure caption is a text that accompanies a graphical element in a visual interface, such as a chart, a map, a diagram, or an image.
- A figure caption serves several purposes, such as:
  - Providing a title or a summary of the graphical element
  - Explaining the data source, the variables, the units, the scale, or the legend of the graphical element
  - Highlighting the main findings, the trends, the patterns, or the outliers of the graphical element
  - Providing additional information, context, or interpretation of the graphical element
- A figure caption should be concise, clear, accurate, and informative. It should not repeat the information that is already shown in the graphical element, but rather complement it and guide the reader's attention.
- A figure caption should be placed close to the graphical element, preferably below it, and aligned with it. It should use a smaller font size than the main text, but larger than the labels or the annotations of the graphical element.
- A figure caption should follow a consistent format and style throughout the document or the interface. It should use punctuation, capitalization, and numbering rules that are appropriate for the genre and the audience of the document or the interface.
- A figure caption should be tested for readability, comprehension, and accessibility. It should be easy to read and understand by the intended users, and it should not create confusion or ambiguity. It should also be accessible to users with visual impairments, such as using alternative text or audio descriptions for the graphical element.
