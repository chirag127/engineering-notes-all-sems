### Visual Objects and Data Objects

- Visual objects are any identifiable, separate, and distinct parts of the visual world that have certain visual attributes, such as shape, color, size, position, orientation, texture, etc. 
- Data objects are any abstract entities that have certain data values, such as numbers, strings, categories, dates, etc.
- Visual objects can be used to represent data objects by mapping data values to visual attributes, such as using different shapes to represent different categories, or using different colors to represent different numbers.
- Visual objects can help organize related data by cognitively grouping visual attributes, such as using the same color to indicate the same category, or using the same shape to indicate the same type. 
- Visual objects can also help compare and contrast data by highlighting differences and similarities in visual attributes, such as using different sizes to indicate different quantities, or using different positions to indicate different locations.
- The object metaphor is pervasive in the way we think about abstract data, and it can be applied to various types of data, such as hierarchical, network, temporal, spatial, etc.
- Some examples of visual objects are bars, points, lines, areas, pie slices, icons, glyphs, etc. Each visual object can encode multiple data values by using multiple visual attributes, such as using shape, color, and size to represent three data values in a glyph. 
- Some examples of data objects are customers, products, transactions, events, nodes, links, etc. Each data object can have multiple data values, such as a customer having a name, an age, and a gender. 
- Visual objects and data objects are related by a mapping function that assigns visual attributes to data values, such as using a linear scale to map numbers to colors, or using a categorical scale to map categories to shapes. 
- The mapping function can be designed to optimize the effectiveness and efficiency of the visual representation, by considering the characteristics of the data, the tasks of the users, and the principles of human vision. 
- The mapping function can also be interactive, allowing users to change the visual attributes of the visual objects, such as using filters, sliders, buttons, etc. to modify the color, size, position, etc. of the visual objects. 
- The interaction can help users explore, analyze, and understand the data, by revealing more details, highlighting patterns, and supporting queries.
