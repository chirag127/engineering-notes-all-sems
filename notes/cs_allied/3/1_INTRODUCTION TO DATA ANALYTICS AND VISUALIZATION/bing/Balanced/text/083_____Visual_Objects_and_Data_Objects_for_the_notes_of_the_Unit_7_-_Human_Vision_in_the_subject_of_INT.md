### Visual Objects and Data Objects

- Visual objects are any identifiable, separate, and distinct parts of the visual world that have certain visual attributes, such as shape, color, size, position, orientation, texture, etc.  
- Data objects are any abstract entities that have certain data values, such as numbers, text, dates, categories, etc.  
- Visual objects can be used to represent data objects by mapping data values to visual features and grouping these features into visual objects.  
- The object metaphor is pervasive in the way we think about abstract data, as it helps us organize related data and perceive patterns, trends, outliers, etc.  
- Examples of visual objects that can be used to represent data objects are:
  - Points, lines, and polygons in a scatter plot, line chart, or map.  
  - Bars, columns, and segments in a bar chart, column chart, or pie chart.  
  - Icons, symbols, and glyphs in an icon plot, symbol map, or glyph chart.  
  - Nodes, links, and labels in a node-link diagram, tree map, or network graph.  
- On-object interaction is a feature that allows users to interact with visual objects in a report, such as filtering, highlighting, drilling, or cross-filtering. 
- On-object interaction can enhance the user experience and the analytical capabilities of a report, as it allows users to explore data from different perspectives and discover insights.
