## Unit 3 - Data Analysis

- Data analysis is the process of collecting, organizing, exploring, interpreting, and presenting data to answer questions, solve problems, or support decisions.
- Data analysis can be performed using various methods, tools, and techniques, depending on the type, source, and purpose of the data.
- Data analysis can be classified into two main types: descriptive and inferential.
  - Descriptive analysis summarizes the main features and patterns of the data using statistics, graphs, tables, or charts. It does not make any conclusions or predictions about the data.
  - Inferential analysis draws conclusions or makes predictions about the data using statistical tests, models, or algorithms. It often involves sampling, hypothesis testing, confidence intervals, or regression analysis.
- Data analysis can also be categorized based on the level of measurement of the data: nominal, ordinal, interval, or ratio.
  - Nominal data are categorical data that have no inherent order or ranking. Examples are gender, color, or country.
  - Ordinal data are categorical data that have a meaningful order or ranking. Examples are grades, ratings, or preferences.
  - Interval data are numerical data that have equal intervals or differences between values, but no true zero point. Examples are temperature, time, or IQ scores.
  - Ratio data are numerical data that have equal intervals and a true zero point. Examples are height, weight, or income.
- Data analysis can also be distinguished based on the number of variables involved: univariate, bivariate, or multivariate.
  - Univariate analysis examines one variable at a time. It can be used to describe the distribution, central tendency, or variability of the data.
  - Bivariate analysis examines the relationship between two variables. It can be used to measure the correlation, association, or causation between the variables.
  - Multivariate analysis examines the relationship between more than two variables. It can be used to identify the factors, dimensions, or clusters that explain the data.
