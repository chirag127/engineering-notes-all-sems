### Modern Data Analytic Tools

- Data analytic tools are software applications that enable users to collect, process, analyze, and visualize data from various sources.
- Data analytic tools can help users to gain insights, make decisions, and solve problems based on data-driven evidence.
- Some of the modern data analytic tools that are widely used in 2023 are:

  - **Python**: Python is a general-purpose programming language that supports multiple paradigms, such as object-oriented, functional, and procedural. Python has a rich set of libraries and frameworks for data analysis, such as NumPy, pandas, SciPy, scikit-learn, TensorFlow, PyTorch, and matplotlib .
  - **R**: R is a statistical programming language that is designed for data analysis and visualization. R has a comprehensive collection of packages and tools for data manipulation, modeling, testing, and graphics, such as tidyverse, ggplot2, Shiny, and RStudio .
  - **SAS**: SAS is a software suite that offers solutions for data management, analytics, and business intelligence. SAS has a variety of tools and modules for data integration, quality, mining, forecasting, reporting, and visualization, such as SAS Enterprise Guide, SAS Visual Analytics, and SAS Viya .
  - **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel can perform basic and advanced calculations, data analysis, and visualization using formulas, functions, charts, pivot tables, and Power Query. Excel can also connect to external data sources and use Power BI to create interactive dashboards .
  - **Power BI**: Power BI is a cloud-based business intelligence platform that allows users to create, share, and consume data visualizations and reports. Power BI can connect to various data sources, such as Excel, databases, web services, and files, and use Power Query, Data Model, and DAX to transform and analyze data. Power BI can also publish and embed reports and dashboards to the web, mobile devices, and other applications .
  - **Tableau**: Tableau is a data visualization software that enables users to create and explore interactive charts, maps, dashboards, and stories. Tableau can connect to various data sources, such as files, databases, web services, and cloud platforms, and use Tableau Prep to clean and prepare data. Tableau can also publish and share visualizations and dashboards to the web, mobile devices, and other applications .
  - **Apache Spark**: Apache Spark is an open-source distributed computing framework that can process large-scale data in parallel. Spark has a core engine and a set of libraries for data analysis, such as Spark SQL, Spark MLlib, Spark Streaming, and GraphX. Spark can run on various platforms, such as Hadoop, Mesos, Kubernetes, and standalone clusters, and support multiple programming languages, such as Scala, Python, Java, and R .
