### Analytic Process and Tools

- The analytic process is a systematic approach to identify, collect, analyze, and communicate data and information to support decision making and problem solving.
- The analytic process consists of four main steps: define the problem, collect and prepare the data, analyze the data, and communicate the results.
- Define the problem: This step involves clarifying the purpose, scope, objectives, and questions of the analysis, as well as identifying the stakeholders, assumptions, and constraints.
- Collect and prepare the data: This step involves selecting the appropriate data sources, methods, and tools to gather the relevant data, as well as cleaning, transforming, and integrating the data for analysis.
- Analyze the data: This step involves applying various techniques and methods to explore, summarize, visualize, and model the data, as well as testing hypotheses, identifying patterns, and drawing insights and conclusions.
- Communicate the results: This step involves presenting and reporting the findings, recommendations, and limitations of the analysis, as well as ensuring the results are understandable, actionable, and ethical for the intended audience.
- The analytic tools are the software, hardware, and methods that enable the execution of the analytic process.
- The analytic tools can be classified into three categories: data collection and preparation tools, data analysis tools, and data communication tools.
- Data collection and preparation tools: These tools help to acquire, store, manage, and manipulate the data for analysis. Examples of these tools are databases, data warehouses, data lakes, data integration tools, data quality tools, and data wrangling tools.
- Data analysis tools: These tools help to explore, summarize, visualize, and model the data for analysis. Examples of these tools are spreadsheets, statistical software, business intelligence software, data mining software, machine learning software, and data visualization software.
- Data communication tools: These tools help to present and report the results of the analysis. Examples of these tools are dashboards, reports, infographics, charts, graphs, and maps.
