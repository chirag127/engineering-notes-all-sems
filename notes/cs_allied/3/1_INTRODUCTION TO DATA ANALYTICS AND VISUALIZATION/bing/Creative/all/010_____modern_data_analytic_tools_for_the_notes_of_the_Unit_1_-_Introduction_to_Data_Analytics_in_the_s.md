# Modern Data Analytic Tools

- Data analytic tools are software applications that enable users to collect, process, analyze, and visualize data from various sources.
- Data analytic tools can help users to gain insights, make decisions, solve problems, and communicate findings related to data.
- Data analytic tools can vary in their features, functions, capabilities, and complexity depending on the user's needs and preferences.
- Some of the modern data analytic tools that are widely used in 2023 are:

  - **Python**: Python is a general-purpose programming language that supports multiple paradigms, such as object-oriented, functional, and procedural. Python has a rich set of libraries and packages for data analysis, such as NumPy, pandas, SciPy, scikit-learn, matplotlib, seaborn, and more. Python is easy to learn, write, and read, and can handle large and complex data sets efficiently. Python can also integrate with other tools and platforms, such as Excel, R, SQL, Hadoop, Spark, and Power BI .
  - **R**: R is a programming language and environment that is designed for statistical computing and graphics. R has a comprehensive collection of packages and functions for data manipulation, analysis, modeling, visualization, and reporting. R can perform various types of data analysis, such as descriptive, inferential, predictive, and prescriptive. R can also work with other tools and platforms, such as Excel, Python, SQL, Hadoop, Spark, and Power BI.
  - **SAS**: SAS is a software suite that offers solutions for data management, analytics, and business intelligence. SAS can access, integrate, transform, and analyze data from various sources, such as databases, files, web services, and social media. SAS can perform various types of data analysis, such as data mining, machine learning, text analytics, forecasting, optimization, and simulation. SAS can also create interactive dashboards, reports, and visualizations to communicate data insights.
  - **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel can store, organize, manipulate, and analyze data in tabular and graphical forms. Excel can perform basic and advanced calculations, functions, and formulas on data, such as arithmetic, logical, statistical, financial, and date and time. Excel can also create charts, pivot tables, slicers, and sparklines to visualize data. Excel can also connect to other data sources, such as databases, files, web services, and Power BI.
  - **Power BI**: Power BI is a cloud-based service that provides tools for data analysis and visualization. Power BI can connect to various data sources, such as databases, files, web services, and Excel. Power BI can transform, model, and enrich data using Power Query and Data Model. Power BI can also create interactive reports and dashboards using Power BI Desktop and Power BI service. Power BI can also share and collaborate on data insights using Power BI app and Power BI Embedded.
  - **Tableau**: Tableau is a software platform that specializes in data visualization and business intelligence. Tableau can connect to various data sources, such as databases, files, web services, and Excel. Tableau can also blend and join data from different sources using Tableau Prep. Tableau can also create interactive and dynamic visualizations using Tableau Desktop and Tableau Online. Tableau can also publish and share data insights using Tableau Server and Tableau Public .
  - **Apache Spark**: Apache Spark is an open-source framework that provides tools for distributed data processing and analytics. Spark can handle large and complex data sets using parallel and in-memory computing. Spark can also perform various types of data analysis, such as batch, streaming, interactive, and graph. Spark can also support various programming languages, such as Python, R, Scala, and Java. Spark can also integrate with other tools and platforms, such as Hadoop, SQL, Python, R, and Power BI .
