## Unit 6 - Introduction to Visualization

- Visualization is the process of creating and displaying graphical representations of data or information.
- Visualization can help users to explore, analyze, communicate, and understand data or information more effectively and efficiently.
- Visualization can be classified into different types based on the purpose, audience, data, and technique of the graphical representation.
- Some common types of visualization are:

  - **Charts**: Charts are graphical representations of data that use symbols, such as bars, lines, or pie slices, to show the relationship between variables or categories. Charts can be used to compare, contrast, or summarize data. Examples of charts are bar charts, line charts, pie charts, scatter plots, etc.
  - **Maps**: Maps are graphical representations of spatial data that use symbols, such as points, lines, polygons, or colors, to show the location, distribution, or movement of data or information on a geographic area. Maps can be used to explore, analyze, or communicate spatial data or information. Examples of maps are choropleth maps, heat maps, flow maps, etc.
  - **Diagrams**: Diagrams are graphical representations of data or information that use symbols, such as shapes, arrows, or icons, to show the structure, process, or logic of data or information. Diagrams can be used to explain, illustrate, or simplify data or information. Examples of diagrams are flowcharts, mind maps, Venn diagrams, etc.
  - **Infographics**: Infographics are graphical representations of data or information that use a combination of symbols, such as charts, maps, diagrams, icons, text, or images, to tell a story, convey a message, or persuade an audience. Infographics can be used to inform, educate, or entertain an audience. Examples of infographics are timelines, posters, flyers, etc.

- Visualization can be created and displayed using various tools, such as software applications, web platforms, or programming languages.
- Some common tools for visualization are:

  - **Software applications**: Software applications are programs that run on a computer or a mobile device and provide a graphical user interface (GUI) for creating and displaying visualizations. Software applications can be general-purpose or domain-specific, and can offer various features and functions for visualization. Examples of software applications are Microsoft Excel, Tableau, Adobe Illustrator, etc.
  - **Web platforms**: Web platforms are online services that provide a web-based interface for creating and displaying visualizations. Web platforms can be hosted or cloud-based, and can offer various features and functions for visualization. Examples of web platforms are Google Charts, Datawrapper, Infogram, etc.
  - **Programming languages**: Programming languages are sets of rules and instructions that allow users to write code for creating and displaying visualizations. Programming languages can be general-purpose or domain-specific, and can offer various libraries and packages for visualization. Examples of programming languages are Python, R, JavaScript, etc.
