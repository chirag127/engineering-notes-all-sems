# Competitive Learning

- Competitive learning is a form of unsupervised learning in artificial neural networks, in which nodes compete for the right to respond to a subset of the input data.
- Competitive learning works by increasing the specialization of each node in the network. It is well suited to finding clusters within data.
- Competitive learning is usually implemented with neural networks that contain a hidden layer which is commonly known as “competitive layer”.
- Every competitive neuron is described by a vector of weights and calculates the similarity measure between the input data and the weight vector.
- The competitive neuron with the highest similarity measure is declared the winner and its weights are updated to become more similar to the input data. This is a variant of Hebbian learning.
- Competitive learning can be used for data compression, dimensionality reduction, feature extraction, pattern recognition, and self-organization.
- Competitive learning can be classified into two types: hard and soft. Hard competitive learning allows only one winner neuron per input, while soft competitive learning allows multiple winner neurons with different degrees of activation.
- Some examples of competitive learning algorithms are k-means clustering, vector quantization, self-organizing maps, adaptive resonance theory, and neural gas.
- Competitive learning can be contrasted with collaborative and individualized learning, which are other types of learning models used in machine learning and artificial intelligence systems .
- Collaborative learning is a learning mechanism where the components of the learning systems cooperate and share information to achieve a common goal.
- Individualized learning is a learning mechanism where the components of the learning systems learn independently and adapt to their own preferences and needs.
- Competitive learning can have some advantages and disadvantages over collaborative and individualized learning, depending on the context and the objective of the learning task.
