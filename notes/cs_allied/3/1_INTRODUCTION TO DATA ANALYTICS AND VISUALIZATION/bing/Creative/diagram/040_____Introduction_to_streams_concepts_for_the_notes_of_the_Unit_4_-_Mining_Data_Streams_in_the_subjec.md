### Introduction to streams concepts

- A data stream is a sequence of data items that arrives continuously and rapidly, and can be potentially unbounded in size.
- Examples of data streams are sensor readings, network packets, web logs, social media posts, online transactions, etc.
- Data streams pose several challenges for data analysis and mining, such as:
  - High volume and velocity: The data rate can be too high to store or process all the data items using traditional methods.
  - Dynamic and evolving: The data distribution and patterns can change over time, requiring adaptive and incremental algorithms.
  - One-pass and online: The data items can only be accessed once or a few times, and the analysis results need to be updated in real time or near real time.
  - Resource constraints: The memory, storage, and computational resources are limited and need to be used efficiently.
- Data stream mining is the process of extracting useful and timely knowledge from data streams, such as patterns, trends, anomalies, correlations, etc.
- Data stream mining techniques can be classified into four categories, based on the type of knowledge they aim to discover:
  - Stream summarization: The goal is to create compact and accurate representations of the data stream, such as sketches, histograms, synopses, etc.
  - Stream classification: The goal is to assign labels to the data items based on predefined classes, such as spam or not spam, fraud or not fraud, etc.
  - Stream clustering: The goal is to group the data items into meaningful clusters based on their similarity, such as customer segments, topic clusters, etc.
  - Stream frequent pattern mining: The goal is to find frequent or recurring patterns in the data stream, such as frequent items, itemsets, subsequences, subgraphs, etc.
