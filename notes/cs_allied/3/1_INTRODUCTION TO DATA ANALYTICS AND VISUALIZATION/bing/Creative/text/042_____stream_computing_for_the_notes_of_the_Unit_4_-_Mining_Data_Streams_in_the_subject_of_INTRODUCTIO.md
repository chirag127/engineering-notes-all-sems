### Stream Computing

- Stream computing is a programming paradigm that deals with data streams, or sequences of events in time, as the central input and output objects of computation.
- Stream computing enables organizations to process data streams that are always on and never ceasing, such as sensor data, social media data, financial data, etc.
- Stream computing helps organizations spot opportunities and risks across all data sources, by analyzing the data in real time and producing actionable results.
- Stream computing uses software algorithms that analyze the data as it streams in, without storing it in a database or a file system, to increase speed and accuracy when dealing with data handling and analysis.
- Stream computing can handle complex queries and analytics over data streams, such as filtering, aggregation, pattern matching, correlation, etc.
- Stream computing can also connect to other data sources, such as databases, files, or web services, to enrich the data streams with additional information or to output the results to other systems.
- Stream computing requires a distributed stream processing platform that can scale up and down, handle failures, and provide fault tolerance and consistency.
- Stream computing platforms can be classified into two types: stateless and stateful. Stateless platforms do not maintain any state information about the data streams, while stateful platforms do. Stateful platforms can support more complex analytics and queries, but also require more resources and coordination.
- Some examples of stream computing platforms are Apache Kafka, Apache Spark, Apache Flink, Apache Storm, IBM Streams, etc.
