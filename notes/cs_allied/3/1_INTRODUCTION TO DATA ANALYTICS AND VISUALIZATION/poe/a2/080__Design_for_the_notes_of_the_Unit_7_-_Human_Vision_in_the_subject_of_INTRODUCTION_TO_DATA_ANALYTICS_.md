### Design

1. Color: Color is one of the most important tools for visualization. Different colors can be used to distinguish different categories or values. However, color should be used judiciously as too many colors can make a visualization confusing and difficult to understand. Some best practices for using color are:
- Use a maximum of 5-6 colors.
- Use colors that have sufficient contrast and are distinguishable even by color blind people.
- Do not use red and green together as around 8% males have red-green color blindness.
- Ensure that the colors have the appropriate semantic mapping (e.g. red for losses or negative values).

2. Size: Varying the size of visual elements is another technique to display information. Our visual system is highly attuned to differences in size, so this technique works well. However, the size should be varied logically (e.g. higher values represented by larger sizes). Using size alone to represent information can be limiting so it is often used in combination with other techniques like color.

3. Position: Arranging visual elements in different positions is a simple yet effective technique. Our visual system readily detects patterns and variations in positioning. This technique works well for depicting categories or ranks (e.g. stacked bar charts, dot plots). The positions should be used consistently and logically for the visualization to be understandable.

4. Shape: Different shapes can be used to represent different types of information. For example, circles can denote one category of data while squares can denote another. Using a variety of shapes makes it possible to display more categories in the same space. However, too many shapes can make a visualization cluttered and confusing. Shape should be used selectively and shapes that have similar silhouettes should be avoided.

5. Text: Labels and annotations are crucial to make a visualization self-contained and truly informative. However, text should be used judiciously. Too much text can clutter the visualization and make it difficult to understand at a glance. The text should be legible, using an appropriate font size and color. The information conveyed via text should not be duplicated in the graphical elements.
