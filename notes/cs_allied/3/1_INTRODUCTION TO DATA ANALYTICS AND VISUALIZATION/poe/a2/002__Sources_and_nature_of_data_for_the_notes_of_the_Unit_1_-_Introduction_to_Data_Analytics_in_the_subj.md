### Sources and nature of data for the notes of the Unit 1 - Introduction to Data Analytics

1. Primary data: Collected directly from first-hand sources through surveys, experiments or direct observations. Eg. Survey data, sensor data, transaction data.
2. Secondary data: Data collected from secondary sources and already available in a usable form. Eg. Census data, stock market data, weather data.
3. Structured data: Data with a definite structure that can be easily stored and processed in a database. Eg. Database records, CSV files.
4. Unstructured data: Data with no definite structure. Eg. Text, images, videos, audio. Requires preprocessing to extract insights.
5. Qualitative data: Data consisting of words, descriptions, symbols, perceptions, opinions, etc. Eg. Interviews, essays, open-ended survey responses.
6. Quantitative data: Data consisting of numbers and measurable quantities. Eg. Stock prices, sales figures, temperature readings.
7. Static data: Data that does not change with time. Eg. Geographic data.
8. Streaming data: Data that is continuously generated at a rapid pace. Requires real-time processing. Eg. Stock prices, sensor data, web traffic data.
