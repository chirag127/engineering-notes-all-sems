### Competitive Learning for Unit 3 - Data Analysis

1. Competitive Learning is a type of unsupervised learning technique.
2. In Competitive Learning, output neurons compete amongst themselves to be activated.
3. Only one neuron gets activated for a given input pattern.
4. The neuron that gets activated is the one that is closest to the input pattern.
5. The weights of the winning neuron and its neighbors get updated to move closer to the input pattern.
6. This process continues iteratively until the weights converge and the clusters are formed.
7. Competitive Learning is useful for vector quantization and clustering problems.
8. Some examples of Competitive Learning are Kohonen Self-Organizing Maps (SOM) and Learning Vector Quantization (LVQ).
9. The main advantages of Competitive Learning are simplicity, speed, and robustness.
10. The main disadvantages are that the number of clusters needs to be predefined and the topology of the clusters depends on the initial random weights and order of presentation of the input patterns.
