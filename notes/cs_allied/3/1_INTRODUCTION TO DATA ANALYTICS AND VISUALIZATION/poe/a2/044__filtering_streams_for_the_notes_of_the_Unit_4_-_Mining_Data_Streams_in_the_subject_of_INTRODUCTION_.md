### Filtering Streams

1. Data streams are continuous and unbound. Hence, it is not possible to store and process the entire data stream. Filtering is required to extract relevant data and reduce the data volume.
2. Types of filters:
- Sliding window filter: Processes data within a fixed window size. Data outside the window is discarded. Useful for detecting recent trends or patterns.
- Dwell time filter: Data is processed only if it stays within the stream for a minimum dwell time. Useful to filter out short-lived outliers or spikes.
- Complex event processing filter: Detects complex patterns or correlations in data based on predefined rules or logic. Useful for applications like fraud detection or sensor monitoring.
3. Filtering is crucial for big data streams to extract valuable information and ensure processing and storage of only relevant data. Appropriate filters help reduce data volume and computational requirements while retaining important data.
