### Introduction to streams concepts for the notes of the Unit 4 - Mining Data Streams in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

- Data streams are sequences of data that arrive continuously at a high speed with no clear ending. They require processing continuously in chunks to derive insights and decisions without storing the entire data.
- The key characteristics of data streams are:
-- Continuous arrival of data: Data arrives continuously at high speeds.
-- Limited or no storage: It is not feasible to store the entire data stream due to the volume and velocity. Only recent data can be stored.
-- Single-pass: The data can only be processed once as it arrives. No iterative processing is possible.
-- Real-time: Processing must be done in real-time to enable real-time decisions and actions.
- Examples of data streams include:
-- Sensor data: Data from IoT sensors
-- Web logs: Logs of user activities on a website
-- Financial data: Real-time financial data
-- Location data: Data from GPS and other location tracking systems
- The key challenges in mining data streams are:
-- Limited storage: Only recent data can be stored due to the huge volume.
-- Speed: The algorithms must be very efficient to process the data in single-pass and on-the-fly.
-- Concept drift: The underlying concepts might change over time which the algorithms must adapt to.
-- High dimensionality: The data streams might include a large number of attributes or dimensions.
