 Here are the notes on Visual Objects and Data Objects for the Unit 7 - Human Vision in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION:

### Visual Objects

- Visual objects refer to the graphical elements that are used to represent data in a visualization such as bars, lines, areas, dots, etc.
- Choosing appropriate visual objects is important to make the visualization easy to understand and interpret.
- For example, use lines to show trends, bars to show comparisons, and dots to show individual data points.

### Data Objects

- Data objects refer to the pieces of data that are represented by the visual objects in a visualization.
- For example, the height of the bars represents the data objects which could be sales numbers or percentages.
- Mapping data objects to appropriate visual objects is key to an effective visualization.
- For example, do not use line charts to represent discrete data objects or bar charts to represent continuous data.
