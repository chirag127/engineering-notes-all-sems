### Analytic Process and Tools

1. Problem Definition: Clearly define the problem and the questions we want to answer. Some questions to ask are:
- What is the problem?
- Who has this problem?
- Why is this a problem?
- What information is needed to solve this problem?

2. Data Collection: Collect relevant data to solve the problem. Some steps in data collection are:
- Identify data sources
- Obtain permissions to access data
- Extract data from sources
- Clean and prepare data

3. Data Exploration: Explore the data to find trends and patterns. Some steps are:
- Check for errors and outliers
- Calculate summary statistics
- Visualize the data
- Find correlations between variables
-Look for clusters or groups in the data

4. Model Planning: Determine the analytic technique to use based on the type of problem and data. Some options are:
- Regression for predicting a continuous value
- Classification for predicting a category
- Clustering for finding hidden patterns
- Association for finding relationships between variables

5. Model Building: Train and evaluate the model to solve the problem. Some steps are:
- Split data into training and testing sets
- Train the model on the training set
- Evaluate model performance on the testing set
- Tune model parameters to optimize performance

6. Deployment: Implement the model to make predictions or decisions. Some steps are:
- Export the final model
- Integrate the model into applications
- Monitor model performance and retrain as needed

The above points cover the key steps in the analytics process to solve a problem using data. Various tools are used at each step such as SQL, Python, R, SAS, etc. for data collection and modeling.
