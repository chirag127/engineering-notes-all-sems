
## Unit 5 - Frequent Itemsets and Clustering

* **Frequent Itemsets** are sets of items that appear frequently in a given dataset. They are used in data mining to identify patterns and relationships in the data. 

* **Clustering** is the process of grouping similar items together in a dataset. Clustering can be used to identify patterns and relationships in the data, and can be used for predictive modeling. 

* **Association Rules** are rules that can be derived from frequent itemsets. Association rules are used to determine the relationships between items in a dataset and can be used to make predictions about future data. 

* **Apriori Algorithm** is an algorithm used to discover frequent itemsets in a dataset. The Apriori algorithm uses a bottom-up approach to identify frequent itemsets and association rules.

* **K-means Clustering** is an unsupervised machine learning algorithm used to partition a dataset into clusters. K-means clustering is used to identify patterns and relationships in the data, and can be used for predictive modeling.
