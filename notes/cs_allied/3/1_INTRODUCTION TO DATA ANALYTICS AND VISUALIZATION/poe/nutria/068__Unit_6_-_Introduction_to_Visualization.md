
## Unit 6 - Introduction to Visualization

1. Visualization is the process of creating and presenting data in graphical or pictorial format. It helps us to better understand patterns, trends, and relationships in data.

2. Common types of data visualization include charts, graphs, maps, diagrams, and tables. Each type of visualization is best suited for different types of data.

3. Visualization can be used to explore and analyze data, as well as to communicate the results of data analysis to others.

4. Data visualization tools and techniques are used to create interactive visualizations, which can be used to explore data and gain insights.

5. Data visualization is a powerful tool for communication, as it can be used to convey complex ideas and data in a simple and visually appealing way.
