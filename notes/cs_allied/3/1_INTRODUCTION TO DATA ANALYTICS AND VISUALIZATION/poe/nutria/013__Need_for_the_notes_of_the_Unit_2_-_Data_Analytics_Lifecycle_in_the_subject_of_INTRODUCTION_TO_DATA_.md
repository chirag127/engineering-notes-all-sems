
### Need for the notes of the Unit 2 - Data Analytics Lifecycle in the subject of INTRODUCTION TO DATA ANALYTICS AND VISUALIZATION

1. Data analytics is an increasingly important tool for businesses of all sizes. It enables them to identify and capitalize on opportunities, make informed decisions, and gain valuable insights into their customers, products, and operations.

2. The data analytics lifecycle is a structured approach to data analytics that allows businesses to maximize the value of their data. This lifecycle consists of five distinct stages: data collection, data cleansing, data analysis, data interpretation, and data presentation.

3. Data collection is the process of gathering data from various sources. This can include internal sources such as customer databases, external sources such as public data sets, or a combination of both.

4. Data cleansing is the process of removing or transforming data to make it more suitable for analysis. This can include removing outliers, correcting errors, and transforming data into a more suitable format.

5. Data analysis is the process of analyzing data to identify patterns and relationships. This can include descriptive analytics, which focuses on summarizing data, or predictive analytics, which uses data to make predictions about the future.

6. Data interpretation is the process of interpreting the results of data analysis. This can include identifying meaningful trends and insights, as well as making decisions and recommendations based on the data.

7. Data presentation is the process of presenting the results of data analysis in a meaningful way. This can include visualizations, reports, and other forms of communication.
