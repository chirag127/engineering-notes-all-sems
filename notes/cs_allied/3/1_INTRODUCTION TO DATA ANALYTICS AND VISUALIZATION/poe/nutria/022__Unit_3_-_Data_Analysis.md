
## Unit 3 - Data Analysis

Data analysis is the process of examining data sets in order to draw conclusions about the information they contain, increasingly with the aid of specialized systems and software. Data analysis has multiple facets and approaches, encompassing diverse techniques under a variety of names, in different business, science, and social science domains.

1. Data Exploration: This involves understanding the data by summarizing the main characteristics of the data, such as the mean, median, mode, and range.
2. Data Cleaning: This involves identifying and correcting errors in the data, such as outliers, missing values, and duplicates.
3. Data Transformation: This involves transforming the data into a format that is more suitable for analysis, such as converting categorical variables into numerical variables.
4. Data Visualization: This involves creating visual representations of the data, such as bar charts, line graphs, and scatter plots.
5. Data Modeling: This involves applying statistical or machine learning algorithms to the data in order to make predictions or draw inferences.
6. Data Interpretation: This involves interpreting the results of the data analysis and drawing conclusions.
