
### K-Means for the Notes of Unit 5 - Frequent Itemsets and Clustering in the Subject of Introduction to Data Analytics and Visualization

* K-Means is a clustering algorithm that is used to partition data into clusters of similar items.
* It is an unsupervised learning algorithm, meaning that it does not require labeled data.
* The algorithm works by assigning each item in the dataset to a cluster based on its similarity to other items in that cluster.
* The goal of the algorithm is to minimize the within-cluster variance, which is the sum of the squared distances between each item and the cluster's center.
* To do this, the algorithm first randomly assigns each item to a cluster. Then, it iteratively moves each item to the cluster with the closest center.
* The algorithm stops when the within-cluster variance is minimized or when a maximum number of iterations has been reached.
* K-Means can be used to find patterns in data, such as customer segmentation, market segmentation, and document clustering.
