
### Unit 5 - Frequent Itemsets and Clustering

1. **Frequent Itemset**: A frequent itemset is a set of items that appear together in a given dataset. It is used in data mining to discover patterns in data.

2. **Clustering**: Clustering is an unsupervised learning technique used to group data points into clusters based on their similarities. Clustering can be used to identify patterns in data and can be used for clustering analysis, clustering prediction and clustering optimization.

3. **Association Rule Mining**: Association rule mining is a data mining technique used to discover relationships between items in a dataset. It is used to identify frequent patterns and correlations between items in a dataset.

4. **Apriori Algorithm**: The Apriori algorithm is a popular algorithm used in data mining for finding frequent itemsets. It is based on the principle that if an itemset is frequent, then all of its subsets must also be frequent.

5. **K-Means Clustering**: K-Means clustering is a popular clustering algorithm used to group data points into clusters based on their similarities. It works by assigning each data point to the cluster with the closest mean.
