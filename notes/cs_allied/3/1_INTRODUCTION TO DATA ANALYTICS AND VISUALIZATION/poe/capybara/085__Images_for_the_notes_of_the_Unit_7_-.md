### Images for the notes of the Unit 7 -

In Unit 7, we will be discussing various aspects related to images. Understanding the different types of images and their properties is crucial for web development. Here are some important points to keep in mind while studying this topic:

- Images can be broadly classified into two categories - raster images and vector images. Raster images are made up of pixels and are resolution-dependent. Vector images, on the other hand, are made up of paths and can be scaled without losing quality.
- The format of an image determines how it is stored and displayed. Some common image formats include JPEG, PNG, GIF, and SVG. Each format has its own properties and is suited for specific use cases.
- Images can be optimized for web delivery to reduce their file size and improve loading speed. This can be done by compressing the image, reducing its dimensions, and using a format that is optimized for the web.
- Images can be styled using CSS. We can apply various CSS properties to images, such as width, height, border, and margin, to enhance their appearance on the web page.
- Accessibility is an important aspect of web development. We need to ensure that images are accessible to users with disabilities. This can be achieved by adding alt text to the image, which is a description of the image that can be read by screen readers.

By understanding these concepts related to images, you will be able to create visually appealing and accessible web pages. Make sure to practice working with images and experiment with different formats and styles. Happy learning!
