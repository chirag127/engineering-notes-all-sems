### Immutable Streams Defined from One Another Transformations and Aggregations

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, or social media platforms.
- Stream processing applications consume data from one or more input streams, apply some logic or computation to the data, and produce one or more output streams.
- Streams are sequences of immutable data records that are appended to the end of the stream. Streams can be infinite or finite, depending on the source and the application logic.
- Stream processing applications can define new streams from existing ones by applying transformations and aggregations. Transformations are operations that change the content or structure of the data records, such as filtering, mapping, or splitting. Aggregations are operations that combine multiple data records into one, such as counting, summing, or averaging.
- Stream processing applications can also define windows over the streams, which are subsets of the data records based on some criteria, such as time or key. Windows allow applications to perform aggregations or other computations over a finite set of data records that are relevant for a specific context or query. For example, an application can compute the average temperature per hour from a stream of temperature readings, or the number of clicks per user from a stream of web events.
- Stream processing applications can use different notions of time to define windows or order the data records. Event time is the time when the data record was generated by the source, which may not be the same as the time when the record was processed by the application. Processing time is the time when the record was processed by the application, which may not be the same as the event time. Event time is more accurate and consistent, but requires the data records to have timestamps and the application to handle out-of-order or late data. Processing time is simpler and faster, but may not reflect the true order or frequency of the events.
