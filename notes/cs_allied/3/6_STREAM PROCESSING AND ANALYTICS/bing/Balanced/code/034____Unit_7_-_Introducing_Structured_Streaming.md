## Unit 7 - Introducing Structured Streaming

- Structured Streaming is a high-level API for building scalable and fault-tolerant streaming applications using Spark SQL.
- Structured Streaming allows you to express your streaming computation as a batch-like query on a table, and Spark runs it incrementally and continuously on the incoming stream of data.
- Structured Streaming supports various sources and sinks, such as files, Kafka, sockets, Delta Lake, etc.
- Structured Streaming provides end-to-end exactly-once fault-tolerance guarantees, as well as event-time and late-data handling features.
- Structured Streaming can integrate with Spark's Machine Learning and Graph libraries, as well as external libraries such as TensorFlow and OpenCV.
- Structured Streaming can run on various cluster managers, such as YARN, Mesos, Kubernetes, or standalone mode.
