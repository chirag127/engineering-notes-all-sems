### The Effect of Time for the notes of the Unit 2 - Stream-Processing Model in the subject of STREAM PROCESSING AND ANALYTICS

- Stream processing is a programming paradigm that views data streams, or sequences of events in time, as the central input and output objects of computation.
- Stream processing enables programs to react to new data events in real-time, rather than aggregating and processing them in batches.
- Stream processing is designed for instant data processing and real-time analytics, providing current, up-to-the-millisecond insights into what is happening within a system.
- Stream processing is a compromise, driven by a data-centric model that works well for applications that require continuous and fast processing of data streams, such as image, video, and digital signal processing, but less so for applications that require more randomized data access, such as databases .
- Stream processing has some challenges and trade-offs, such as:
  - Handling unpredictable and bursty data streams, which may require back-pressure, buffering, or dynamic scaling mechanisms.
  - Dealing with out-of-order, late, or missing data events, which may require windowing, watermarking, or state management techniques.
  - Balancing between latency, throughput, and accuracy, which may require tuning of parameters, such as parallelism, checkpointing, and fault tolerance.
  - Choosing between different stream processing technologies and frameworks, which may have different features, architectures, and performance.
