## Unit 4 - Apache Spark as a Stream-Processing Engine

- Apache Spark is an open source data-processing engine for large data sets .
- It is designed to deliver the computational speed, scalability, and programmability required for Big Data applications.
- It supports various types of data processing, such as batch processing, stream processing, graph processing, machine learning, and artificial intelligence .
- Stream processing is the processing of data in motion, such as real-time data from sensors, web logs, social media, etc .
- Spark Streaming is the module that enables stream processing in Spark .
- It allows users to express streaming computations using the same high-level APIs as batch processing, such as Dataset, DataFrame, and SQL .
- It also provides advanced features, such as structured streaming, event-time windows, stream-to-batch joins, watermarking, stateful aggregations, etc .
- Spark Streaming leverages the core Spark engine to run streaming queries incrementally and continuously, and update the final result as streaming data arrives .
- Spark Streaming can ingest data from various sources, such as Kafka, Flume, Kinesis, Socket, etc .
- It can also output data to various sinks, such as HDFS, Hive, Cassandra, etc .
- Spark Streaming is scalable, fault-tolerant, and secure, and can handle high-throughput and low-latency streaming applications .
