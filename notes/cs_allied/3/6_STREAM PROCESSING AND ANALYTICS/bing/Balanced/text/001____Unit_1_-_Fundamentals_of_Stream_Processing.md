## Unit 1 - Fundamentals of Stream Processing

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, or social media platforms.
- Stream processing systems ingest, process, and output data streams in real-time, without storing the entire data in a database or a file system.
- Stream processing systems can handle high-volume and high-velocity data, and provide low-latency and scalable solutions for various applications such as analytics, monitoring, alerting, or machine learning.
- Stream processing systems consist of the following components:
  - Sources: The entities that produce data streams, such as sensors, web servers, or social media platforms.
  - Sinks: The entities that consume data streams, such as databases, dashboards, or external services.
  - Operators: The functions that transform data streams, such as filtering, aggregation, windowing, or joining.
  - Streams: The sequences of data records that flow between sources, sinks, and operators.
- Stream processing systems can be classified into two categories based on their execution model:
  - Stateless: The operators do not maintain any internal state, and process each data record independently of the previous or future records.
  - Stateful: The operators maintain some internal state, and process each data record based on the previous or future records, or some external context.
- Stream processing systems can also be classified into two categories based on their processing semantics:
  - At-most-once: The operators process each data record at most once, and may lose some data records due to failures or network issues.
  - At-least-once: The operators process each data record at least once, and may process some data records multiple times due to failures or network issues.
  - Exactly-once: The operators process each data record exactly once, and guarantee no data loss or duplication due to failures or network issues.
