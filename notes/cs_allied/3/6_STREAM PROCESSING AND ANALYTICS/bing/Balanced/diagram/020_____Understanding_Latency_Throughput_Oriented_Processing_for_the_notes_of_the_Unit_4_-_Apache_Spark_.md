### Understanding Latency Throughput Oriented Processing

- Latency is the delay between an input and an output in a system. It measures how long it takes for a data item to be processed and delivered. Low latency means fast response time and high performance.
- Throughput is the rate at which a system can process data items. It measures how many data items can be processed and delivered in a given time interval. High throughput means high efficiency and high capacity.
- Latency and throughput are two important metrics for evaluating the performance of a system, especially for stream processing and analytics, where data is continuously generated and processed in real time.
- Latency and throughput are often inversely related, meaning that improving one may degrade the other. For example, increasing the parallelism of a system may increase the throughput, but also introduce more communication and synchronization overhead, which may increase the latency.
- Latency oriented processing is a design approach that focuses on minimizing the latency of a system. It aims to make the results available as soon as possible, by using sophisticated control structures and techniques, such as branch prediction, data forwarding, re-order buffer, large register files and caches, etc. This is typical of most central processing units (CPU) being developed since the 1970s.
- Throughput oriented processing is a design approach that focuses on maximizing the throughput of a system. It aims to process as many data items as possible, by using parallelism and pipelining techniques, such as multiple cores, vector instructions, hardware accelerators, etc. This is typical of many graphics processing units (GPU) and field-programmable gate arrays (FPGA) being developed in recent years.
- Apache Spark is a stream processing engine that supports both latency oriented and throughput oriented processing. It allows users to choose between different levels of latency and throughput trade-offs, by using different APIs and configurations, such as Spark Streaming, Structured Streaming, micro-batch processing, continuous processing, etc. It also provides various optimization techniques, such as caching, checkpointing, watermarking, etc., to improve the performance and reliability of stream processing and analytics.
