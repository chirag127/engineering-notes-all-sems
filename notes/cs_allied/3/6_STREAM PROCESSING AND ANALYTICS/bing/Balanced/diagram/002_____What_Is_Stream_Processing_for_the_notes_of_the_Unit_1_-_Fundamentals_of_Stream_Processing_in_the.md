### What Is Stream Processing

- Stream processing is a big data technology that focuses on the real-time processing of continuous streams of data in motion.
- Stream processing is a data management technique that involves ingesting a continuous data stream to quickly analyze, filter, transform or enhance the data in real time. Once processed, the data is passed off to an application, data store or another stream processing engine.
- Stream processing is a programming paradigm which views data streams, or sequences of events in time, as the central input and output objects of computation.

Some key concepts of stream processing are:

- A data stream is an unbounded sequence of data records that are produced or consumed by a source or a sink, respectively.
- A stream processing framework simplifies parallel hardware and software by restricting the performance of parallel computation.
- A stream processing engine is a software system that executes stream processing applications, which are composed of operators that perform various operations on the data streams.
- Stream processing applications can be classified into two types: stateless and stateful. Stateless applications do not maintain any information about the past or future data records, while stateful applications do.
- Stream processing applications can also be classified into two types: analytical and operational. Analytical applications perform complex computations on the data streams to derive insights, while operational applications perform simple actions on the data streams to trigger responses.
