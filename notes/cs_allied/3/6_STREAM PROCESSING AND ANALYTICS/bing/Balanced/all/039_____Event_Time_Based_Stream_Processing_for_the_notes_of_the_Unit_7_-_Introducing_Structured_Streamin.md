# Event Time–Based Stream Processing

- Event time–based stream processing is the process of quickly analyzing time-based data as it is being created and before it is stored, even at the instant that it is streaming from one device to another .
- Event time is the time when the data was generated by the source, not when it was processed by the system.
- Event time–based stream processing enables consistent time semantics, such as joins, aggregations, and handling out-of-order and late data, in stream processing applications.
- Event time–based stream processing requires a specialized set of technologies, such as event stream processors, event hubs, and event-driven architectures .
- Event time–based stream processing can be used for various use cases, such as real-time analytics, fraud detection, anomaly detection, IoT, and personalization .
