# The Effect of Time for the notes of the Unit 2 - Stream-Processing Model

- Stream processing is a programming paradigm that views data streams, or sequences of events in time, as the central input and output objects of computation.
- Stream processing enables programs to react to new data events in real-time, rather than aggregating and processing them in batches.
- Stream processing is designed for instant data processing and real-time analytics, providing current, up-to-the-millisecond insights into what is happening within a system.
- Stream processing is a compromise, driven by a data-centric model that works well for applications that require low latency and high throughput, such as image, video and digital signal processing, but less so for applications that require more randomized data access, such as databases.
- Stream processing is more dynamic and complex than batch processing, as it has to deal with unpredictable and bursty data arrival, back-pressure, buffering, scaling, fault-tolerance, and state management.
- Stream processing can be implemented using various technologies and frameworks, such as Apache Kafka, Apache Spark, Apache Flink, Apache Storm, Azure Stream Analytics, and Splunk.
