### Structured Streaming Processing Model

- Structured Streaming is a **scalable and fault-tolerant stream processing engine** built on the Spark SQL engine   .
- Structured Streaming uses the **Dataframe and Dataset APIs** to express streaming computations the same way as batch computations on static data  .
- Structured Streaming treats a data stream as a **table that is being continuously appended**. This allows you to use SQL queries and standard operations on streaming data  .
- Structured Streaming provides **exactly-once** guarantees for end-to-end streaming applications, by ensuring that each record is processed only once, even in the case of failures  .
- Structured Streaming supports various sources and sinks for streaming data, such as Kafka, Flume, HDFS, S3, JDBC, console, etc  .
- Structured Streaming leverages the **Spark engine** to optimize the performance and cost of streaming applications and pipelines.
