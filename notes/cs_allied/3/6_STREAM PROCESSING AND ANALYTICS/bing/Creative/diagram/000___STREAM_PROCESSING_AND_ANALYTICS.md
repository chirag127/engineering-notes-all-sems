# Stream Processing and Analytics

- Stream processing and analytics is the processing and analyzing of data records continuously rather than in batches.
- Stream processing and analytics is useful for the types of data sources that send data in small sizes (often in kilobytes) in a continuous flow as the data is generated.
- Stream processing and analytics can provide real-time insights and actions from the data streams, such as detecting anomalies, triggering alerts, or making recommendations.
- Stream processing and analytics requires specific hardware and software systems that are able to ingest data streams and process them with a small response time and no data loss.
- Stream processing and analytics systems are also called event stream processors (ESP) or streaming analytics engines .
- Stream processing and analytics can be combined with batch processing and other analytical platforms to create a comprehensive data pipeline.
- Stream processing and analytics can be implemented using various tools and frameworks, such as Apache Kafka, Apache Spark, Apache Flink, Apache Storm, Azure Stream Analytics, Google Cloud Dataflow, etc   .
- Stream processing and analytics can be applied to various domains and scenarios, such as IoT, social media, e-commerce, finance, gaming, health care, etc .
