## Unit 5 - Spark’s Distributed Processing Model

- Apache Spark is a general-purpose distributed data processing engine that can handle large-scale data analysis and machine learning tasks .
- Spark provides high-level APIs in Java, Scala, Python and R, and an optimized engine that supports general execution graphs .
- Spark also supports a rich set of higher-level tools including Spark SQL for SQL and structured data processing, MLlib for machine learning, GraphX for graph processing, and Spark Streaming for stream processing .
- Spark runs on a cluster of machines, where each machine is called a node. A node can be either a master or a worker. The master node coordinates the execution of tasks across the worker nodes, and the worker nodes run the actual tasks on the data partitions .
- Spark uses a distributed data abstraction called Resilient Distributed Dataset (RDD), which is a collection of elements that can be partitioned across the nodes of the cluster and operated on in parallel .
- RDDs are immutable, meaning that they cannot be modified once created. To transform an RDD, Spark provides two types of operations: transformations and actions. Transformations create a new RDD from an existing one, such as map, filter, join, etc. Actions trigger the computation of an RDD and return a value to the driver program, such as count, collect, save, etc .
- Spark also supports a more structured and expressive data abstraction called DataFrame, which is a distributed collection of rows organized into named columns. DataFrames can be created from various sources, such as files, databases, RDDs, etc. DataFrames can be manipulated using Spark SQL, which is a declarative query language that supports both SQL and HiveQL syntax .
- Spark also supports a more advanced data abstraction called Dataset, which is a distributed collection of objects that can be manipulated using both functional and relational operations. Datasets can be created from DataFrames, RDDs, or encoders. Datasets can benefit from both the performance optimization of DataFrames and the type safety of RDDs .
- Spark uses a lazy evaluation model, meaning that it does not execute any transformation until an action is called. This allows Spark to optimize the execution plan and avoid unnecessary computation. Spark also caches intermediate results in memory or disk to speed up repeated queries .
- Spark uses a directed acyclic graph (DAG) to represent the logical execution plan of a Spark application. A DAG is a graph of nodes and edges, where each node represents an RDD or a DataFrame, and each edge represents a transformation or an action. Spark divides a DAG into stages, where each stage contains a set of tasks that can be executed in parallel. Spark then schedules and executes the tasks on the worker nodes using a DAG scheduler and a task scheduler .
