## Unit 1 - Fundamentals of Stream Processing

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, social media, etc.
- Stream processing applications can perform various tasks such as filtering, aggregation, transformation, enrichment, analysis, and visualization of streaming data in real-time or near real-time.
- Stream processing applications can also produce outputs such as alerts, notifications, recommendations, dashboards, reports, etc. for various consumers such as humans, other applications, or databases.
- Stream processing applications can be designed using different models such as stateless, stateful, windowed, or complex event processing (CEP).
- Stateless stream processing applications do not maintain any information about the past events and process each event independently.
- Stateful stream processing applications keep track of some information about the past events and use it to process the current events.
- Windowed stream processing applications group events into finite subsets based on time or count and apply some function to each window.
- CEP stream processing applications detect patterns or correlations among events and trigger actions based on complex rules or queries.
- Stream processing applications can be implemented using different frameworks or platforms such as Apache Kafka, Apache Spark, Apache Flink, Apache Storm, etc.
- Stream processing applications can face various challenges such as scalability, fault-tolerance, consistency, latency, etc. and need to adopt appropriate strategies or techniques to overcome them.
