# STREAM PROCESSING AND ANALYTICS

- Stream processing and analytics is the processing and analyzing of data records continuously rather than in batches.
- Stream processing and analytics is useful for the types of data sources that send data in small sizes (often in kilobytes) in a continuous flow as the data is generated.
- Stream processing and analytics allows users to gain insights at a faster rate than before by skipping storage and going straight into analysis.
- Stream processing and analytics can be used for various applications, such as real-time monitoring, anomaly detection, fraud prevention, personalization, and recommendation.
- Stream processing and analytics requires specific hardware and software, such as event stream processors (ESP) that are able to ingest data streams and process them with a small response time and no data loss.
- Stream processing and analytics can be combined with batch processing into one analytical platform, such as Azure Stream Analytics, which is a cloud-based service that enables real-time analytics on streaming data  .
- Stream processing and analytics can support higher performance by partitioning, allowing complex queries to be parallelized and executed on multiple streaming nodes.
- Stream processing and analytics is built on Trill, a high-performance in-memory streaming analytics engine developed in collaboration with Microsoft Research.
