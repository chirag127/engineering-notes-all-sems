## Unit 1 - Fundamentals of Stream Processing

- Stream processing is a paradigm for processing data that is continuously generated by sources such as sensors, web servers, social media, etc.
- Stream processing applications can perform various tasks such as filtering, aggregation, transformation, enrichment, analysis, and visualization of streaming data in real-time or near real-time.
- Stream processing applications can also produce outputs such as alerts, notifications, recommendations, dashboards, reports, etc. for various purposes such as monitoring, decision making, anomaly detection, etc.
- Stream processing applications can be built using various frameworks, platforms, and tools that provide different features and capabilities such as scalability, fault tolerance, state management, windowing, etc.
- Stream processing applications can be deployed on various environments such as cloud, edge, or hybrid architectures that offer different trade-offs and challenges such as latency, bandwidth, security, etc.
- Stream processing applications can be evaluated and compared using various metrics and criteria such as throughput, latency, accuracy, completeness, etc.
