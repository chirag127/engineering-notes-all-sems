## Unit 1 - Fundamentals of Stream Processing

1. **Stream Processing** is a computing paradigm that processes data streams in real-time as they arrive, in contrast to batch processing, which processes data in large batches at a later time.
2. Stream Processing is used in a variety of applications, including real-time analytics, fraud detection, and recommendation engines.
3. A **data stream** is a continuous, unbounded sequence of data elements, typically generated by sensors, web logs, or other sources that produce data in real-time.
4. Stream Processing systems must be able to handle large volumes of data with low latency, and must be able to scale horizontally to accommodate increasing data rates.
5. Common techniques used in Stream Processing include **windowing**, which divides the data stream into fixed-size windows for processing, and **aggregation**, which computes summary statistics over the data stream.
6. Stream Processing systems often use a **distributed architecture**, with data being partitioned across multiple nodes for parallel processing.
7. Popular Stream Processing frameworks include Apache Kafka, Apache Flink, and Apache Storm.
8. Stream Processing is an active area of research, with ongoing work on improving the scalability, fault-tolerance, and expressiveness of Stream Processing systems.
