## Unit 2 - Stream-Processing Model

1. The stream-processing model is a computational model that processes data in real-time as it arrives, in contrast to batch processing, which processes data in large batches at a later time.
2. This model is useful for applications that require real-time processing and analysis of data, such as financial trading, fraud detection, and sensor data analysis.
3. In the stream-processing model, data is represented as a continuous stream of records, which are processed by a series of operators.
4. Operators can perform various tasks, such as filtering, aggregation, and transformation, on the data stream.
5. The stream-processing model is typically implemented using a distributed architecture, where multiple machines work together to process the data stream.
6. This allows for high scalability and fault tolerance, as the system can handle large volumes of data and recover from failures.
7. Popular stream-processing frameworks include Apache Kafka, Apache Flink, and Apache Storm.
8. These frameworks provide a high-level API for developing stream-processing applications, as well as a runtime for executing them.
9. Stream-processing applications can be integrated with other systems, such as databases and message queues, to build complex data processing pipelines.
10. The stream-processing model is an active area of research, with ongoing work on improving its performance, scalability, and ease of use.
