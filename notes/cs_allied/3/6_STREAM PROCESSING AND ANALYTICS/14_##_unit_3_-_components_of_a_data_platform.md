## Unit 3 - Components of a Data Platform

A data platform is a system that provides the infrastructure, tools, and services for collecting, storing, processing, and analyzing data. The following are the main components of a data platform:

1. Data ingestion: the process of collecting and loading data into the platform.

2. Data storage: the component responsible for storing data, such as databases, data warehouses, or cloud storage.

3. Data processing: the component responsible for processing data, such as batch processing, stream processing, or real-time processing.

4. Data analytics: the component responsible for analyzing data, such as data visualization, machine learning, or predictive analytics.

5. Data governance: the component responsible for managing data quality, security, and privacy, such as data catalogs, metadata management, or data lineage.

6. Data access: the component responsible for providing access to data, such as APIs, data lakes, or data marts.

In summary, a data platform is a system that provides the infrastructure, tools, and services for collecting, storing, processing, and analyzing data, and its main components include data ingestion, data storage, data processing, data analytics, data governance, and data access.
