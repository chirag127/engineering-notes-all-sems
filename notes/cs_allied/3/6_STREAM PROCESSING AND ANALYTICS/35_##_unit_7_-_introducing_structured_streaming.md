## Unit 7 - Introducing Structured Streaming

Structured Streaming is a new data processing model introduced in Apache Spark 2.0 for processing real-time data streams. It provides a high-level API for processing data streams in a scalable and fault-tolerant manner. Structured Streaming is based on the Spark SQL engine, and provides a similar API to Spark SQL for processing data streams.

Structured Streaming provides several key features for processing data streams, including:

1. Event-time processing: Structured Streaming provides support for processing data streams based on event-time, allowing for correct handling of late-arriving data and out-of-order events.

2. Incremental processing: Structured Streaming provides support for incremental processing of data streams, allowing for efficient processing of large amounts of data.

3. Fault-tolerance: Structured Streaming provides fault-tolerance for data streams, allowing for the processing of data streams in the presence of failures.

4. High-level API: Structured Streaming provides a high-level API for processing data streams, allowing for easy and efficient processing of data streams.
