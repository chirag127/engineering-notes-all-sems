### Spark Components for the notes of the Unit 6 - Spark’s Resilience Model in the subject of STREAM PROCESSING AND ANALYTICS

Spark Components are the building blocks of the Apache Spark framework, and are used to process and manage data in a distributed computing environment.

The key components of Apache Spark include:
1. Spark Core: provides the basic functionality of Spark, including the Resilient Distributed Datasets (RDDs), the Spark scheduler, and the Spark executor.
2. Spark SQL: provides a SQL interface for processing structured data, and includes the Spark DataFrame and Spark SQL APIs.
3. Spark Streaming: provides a high-level API for processing data streams, and includes the Structured Streaming processing model.
4. Spark MLlib: provides a library of machine learning algorithms for use with Spark, including classification, regression, clustering, and recommendation algorithms.
5. Spark GraphX: provides a graph processing framework for use with Spark, and includes algorithms for graph analysis and manipulation.

In summary, the Spark Components are the building blocks of the Apache Spark framework, and are used to process and manage data in a distributed computing environment. The key components of Apache Spark include Spark Core, Spark SQL, Spark Streaming, Spark MLlib, and Spark GraphX.
