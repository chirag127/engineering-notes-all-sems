## Unit 2 - Stream-Processing Model

Stream-processing model is a data processing paradigm that focuses on processing large amounts of data in real-time as they are generated, rather than processing data in batches.

The basic components of a stream-processing system include:
1. Data sources: the sources of data, such as sensors, logs, or databases.
2. Stream processors: the components that perform operations on the data, such as filtering, aggregating, or transforming the data.
3. Data sinks: the destinations for the processed data, such as databases, dashboards, or alert systems.

The stream-processing model is characterized by its ability to handle high-volume, high-velocity data, and its ability to process data in real-time. This makes it well-suited for use cases such as:
- IoT and edge computing
- Fraud detection and security systems
- Financial and stock market analysis
- Real-time analytics and monitoring

In summary, the stream-processing model is a data processing paradigm that focuses on processing large amounts of data in real-time as they are generated, and is well-suited for use cases that require real-time processing of high-volume, high-velocity data.
