### Streaming Versus Batch Algorithms for the notes of the Unit 3 - Components of a Data Platform in the subject of STREAM PROCESSING AND ANALYTICS

Streaming algorithms process data in real-time as it arrives, while batch algorithms process data in large chunks at a set interval. 

Streaming algorithms are typically used in cases where data is constantly changing and real-time analysis is necessary, such as in financial or IoT applications. They are designed to handle high-velocity, high-volume data and can quickly respond to new information.

Batch algorithms, on the other hand, are used for processing large amounts of data in a single go, such as in data warehousing or data mining. These algorithms are designed to handle large data sets and can be run in parallel to process the data faster.

The main difference between the two is the processing speed and the amount of data that can be processed. Streaming algorithms are faster and can process data in real-time, while batch algorithms can process larger amounts of data but take longer to complete.

Both streaming and batch algorithms have their own advantages and disadvantages, and the choice between the two depends on the specific use case and requirements. For example, if real-time analysis is important, streaming algorithms are the better choice, but if large amounts of data need to be processed, batch algorithms may be more appropriate.
