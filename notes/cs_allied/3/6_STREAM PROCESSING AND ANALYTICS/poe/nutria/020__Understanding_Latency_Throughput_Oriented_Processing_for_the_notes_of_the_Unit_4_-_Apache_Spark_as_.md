
### Understanding Latency, Throughput, and Oriented Processing 

1. Latency is the time it takes for a process to complete. It is measured in milliseconds, seconds, or minutes.
2. Throughput is the amount of data that can be processed in a given time frame. It is measured in megabytes or gigabytes per second.
3. Oriented processing is the process of taking data and transforming it into a form that can be used in a specific application or system.
4. Apache Spark is a distributed stream processing engine that can be used to process large amounts of data in real-time.
5. Apache Spark's stream processing engine is designed to handle high-throughput and low-latency data processing.
6. Apache Spark's stream processing engine uses a variety of techniques such as batch processing, window operations, and stateful processing to process data efficiently.
7. Apache Spark's stream processing engine is highly scalable and can be used to process data from multiple sources.
8. Apache Spark's stream processing engine can be used to process data from sources such as Apache Kafka, Apache Flink, and Apache Storm.
9. Apache Spark's stream processing engine can be used to analyze data in real-time and make decisions based on the results.
10. Apache Spark's stream processing engine can be used to build applications such as real-time analytics, machine learning, and fraud detection.
