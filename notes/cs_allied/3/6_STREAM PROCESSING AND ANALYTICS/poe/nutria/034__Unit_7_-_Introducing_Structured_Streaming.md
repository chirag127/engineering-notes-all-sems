
## Unit 7 - Introducing Structured Streaming

- Structured Streaming is an extension of the Spark SQL engine that enables high-throughput, low-latency, fault-tolerant, end-to-end streaming applications. 
- It provides a unified programming model to build continuous applications that can ingest data from various sources, process and analyze it in real time, and output the results to various sinks. 
- Structured Streaming enables you to express your streaming computation the same way you would express a batch computation on static data. 
- It supports a wide range of streaming operations such as windowed aggregations, joins, and sessionization. 
- Structured Streaming also provides a powerful fault-tolerance mechanism that guarantees exactly-once semantics even in the presence of failures. 
- It also supports event-time processing, which enables applications to process data with late arrivals and out-of-order data.
