
### Architectural Models for the Unit 3 - Components of a Data Platform in the subject of STREAM PROCESSING AND ANALYTICS

1. Lambda Architecture: This architecture is used to build data pipelines which can process both batch and streaming data. It consists of three layers: a batch layer, a speed layer, and a serving layer. The batch layer is used to store and process data in batch mode, while the speed layer is used to process data in real-time. The serving layer is used to store the results of the batch and speed layers.

2. Kappa Architecture: This architecture is an extension of the Lambda architecture. It is used to build data pipelines which can process both batch and streaming data. It consists of two layers: a batch layer and a streaming layer. The batch layer is used to store and process data in batch mode, while the streaming layer is used to process data in real-time.

3. Microservices Architecture: This architecture is used to build data pipelines which can process both batch and streaming data. It consists of multiple services which are independently deployed and managed. Each service is responsible for a specific task, such as data ingestion, data processing, data storage, and data visualization.

4. Event-driven Architecture: This architecture is used to build data pipelines which can process both batch and streaming data. It consists of multiple services which are triggered by events. Each service is responsible for a specific task, such as data ingestion, data processing, data storage, and data visualization. The events can be triggered manually or by other services.
