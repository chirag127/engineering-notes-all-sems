
### Spark Components for the notes of the Unit 6 - Spark’s Resilience Model in the subject of STREAM PROCESSING AND ANALYTICS

1. Spark Core: This is the core of Apache Spark and provides distributed task dispatching, scheduling, and basic I/O functionalities.
2. Spark SQL: This module provides an API to process structured data and supports various data sources like Hive, Avro, and JSON.
3. Spark Streaming: This module enables processing of live streaming data in a distributed manner.
4. MLlib: This module provides machine learning algorithms and utilities for data analysis.
5. GraphX: This module is used for graph-parallel computation and provides an API for graph algorithms.
6. Spark’s Resilience Model: This model provides fault tolerance and high availability by replicating data across nodes. It also provides in-memory caching and data replication to ensure that data is available in case of node failure.
