
## Unit 2 - Stream-Processing Model

1. Stream-processing is a type of data processing that works with continuous, real-time data streams. 
2. Stream-processing systems process data as it is ingested, allowing for real-time analytics and decision-making. 
3. Stream-processing systems are designed to handle large volumes of data and process it quickly. 
4. Stream-processing systems are composed of a set of components that are responsible for ingesting, transforming, and routing data. 
5. Stream-processing systems are capable of processing data from multiple sources, including databases, sensor networks, and message queues. 
6. Stream-processing systems use algorithms to detect patterns in data and make decisions. 
7. Stream-processing systems can be used to detect fraud, detect anomalies, and analyze customer behavior. 
8. Stream-processing systems can be used to provide real-time insights into business operations and customer behavior.
