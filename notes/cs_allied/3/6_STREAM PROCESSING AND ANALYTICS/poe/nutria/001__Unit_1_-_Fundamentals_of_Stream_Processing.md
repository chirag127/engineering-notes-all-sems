
## Unit 1 - Fundamentals of Stream Processing

1. Stream processing is the process of collecting, analyzing, and acting on data as it is generated in real-time.
2. Stream processing systems are designed to process data in a continuous fashion, allowing for faster analysis and decision-making.
3. Stream processing systems are used in a wide variety of applications, from financial services to Internet of Things (IoT) analytics.
4. Stream processing systems can be deployed in a variety of architectures, including distributed systems, serverless architectures, and edge computing.
5. Stream processing systems have a variety of components, including data sources, data sinks, and processors.
6. Stream processing systems can be used to process data from a variety of sources, including databases, message queues, and streaming services.
7. Stream processing systems can be used to perform a variety of operations, including filtering, aggregation, and transformation.
8. Stream processing systems can be used to generate insights, detect anomalies, and trigger automated actions.
9. Stream processing systems can be used to build real-time dashboards and applications.
10. Stream processing systems can be used to build applications that can react to changes in the data in real-time.
