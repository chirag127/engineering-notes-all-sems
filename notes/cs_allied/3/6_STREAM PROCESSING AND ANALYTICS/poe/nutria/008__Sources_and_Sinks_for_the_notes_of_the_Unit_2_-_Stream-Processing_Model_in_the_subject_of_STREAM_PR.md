
### Sources and Sinks for the notes of the Unit 2 - Stream-Processing Model in the subject of STREAM PROCESSING AND ANALYTICS

* A source is a system that provides data to a stream-processing system. Sources can be any system that produces data, such as sensors, web services, databases, or message queues.
* A sink is a system that consumes data from a stream-processing system. Sinks can be any system that consumes data, such as databases, message queues, web services, or dashboards.
* Stream-processing systems can have multiple sources and multiple sinks.
* Sources and sinks can be both persistent and transient. Persistent sources and sinks are always available, while transient sources and sinks come and go.
* Sources and sinks can be both local and remote. Local sources and sinks are located on the same machine as the stream-processing system, while remote sources and sinks are located on different machines.
* Sources and sinks can be both unidirectional and bidirectional. Unidirectional sources and sinks send data in one direction, while bidirectional sources and sinks send data in both directions.
* Sources and sinks can be both synchronous and asynchronous. Synchronous sources and sinks send data at regular intervals, while asynchronous sources and sinks send data whenever they have data to send.
