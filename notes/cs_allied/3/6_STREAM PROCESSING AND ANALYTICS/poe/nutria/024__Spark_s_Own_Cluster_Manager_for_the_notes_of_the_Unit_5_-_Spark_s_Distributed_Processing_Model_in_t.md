
### Spark’s Own Cluster Manager 

* Spark's own cluster manager is a resource management system for distributed applications. It is designed to provide a unified view of resources available in a cluster and to make efficient scheduling decisions. 
* It supports a wide range of applications, from batch processing to machine learning and streaming. 
* It is capable of managing both static and dynamic resources. It can also be used to manage multiple clusters in a single environment. 
* It is designed to be highly fault-tolerant and to be able to scale up and down as needed. 
* It provides a powerful set of APIs to manage resources, such as scheduling, resource allocation, and fault tolerance. 
* It supports a wide range of resource types, including memory, CPU, disk storage, and network bandwidth. 
* It also provides a set of tools for monitoring and managing the resources in a cluster.
