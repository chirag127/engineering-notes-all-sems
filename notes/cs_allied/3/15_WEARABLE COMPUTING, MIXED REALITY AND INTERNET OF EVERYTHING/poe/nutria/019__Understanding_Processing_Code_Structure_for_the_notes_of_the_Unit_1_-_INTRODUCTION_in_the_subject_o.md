
### Understanding Processing Code Structure for Unit 1 - INTRODUCTION in Wearable Computing, Mixed Reality and Internet of Everything

- Processing is a programming language and environment used for creating interactive applications, animations, and simulations. It is based on the Java language, and is used for creating visuals, sound, and more.
- Processing code is made up of three main components: setup, draw, and events.
- The setup function is the first code that is run when a Processing application is launched. It is used for initializing variables, setting up the canvas, and other preparatory tasks.
- The draw function is the main loop of the application. It is run continuously, and is used for drawing shapes, responding to user input, and other tasks.
- The events functions are used for responding to user input, such as mouse clicks, keyboard presses, and other events.
- Processing also supports other features, such as classes, functions, and libraries, which are used for creating more complex applications.
