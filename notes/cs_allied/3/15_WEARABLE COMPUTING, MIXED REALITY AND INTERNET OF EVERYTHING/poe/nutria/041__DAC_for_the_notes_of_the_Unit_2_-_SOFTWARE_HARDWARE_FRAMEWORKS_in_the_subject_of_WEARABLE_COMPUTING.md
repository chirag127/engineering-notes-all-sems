
### DAC for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

* **DAC** (Digital-to-Analog Converter) is a device that converts digital signals into analog signals. It is commonly used in audio applications such as headphones, speakers, and amplifiers. 
* **Software** is a set of instructions that tell a computer how to perform a task. It is composed of code written in a programming language and can be used to create applications, websites, and other digital products.
* **Hardware** is the physical components of a computer system, such as the motherboard, processor, memory, and storage. It is responsible for running the software and providing the interface between the user and the computer.
* **Frameworks** are a set of tools and libraries that provide a structure for developing software applications. They are designed to simplify the development process and make it easier to create robust and reliable applications.
* **Wearable Computing** is the use of technology to create devices that are worn on the body. Examples include smartwatches, fitness trackers, and augmented reality glasses.
* **Mixed Reality** is a combination of virtual reality and augmented reality, where users can interact with both virtual objects and real-world environments.
* **Internet of Everything** (IoE) is an interconnected network of physical objects, such as sensors, devices, and machines, that are connected to the internet. This allows for the collection and sharing of data between these objects, creating a more intelligent and efficient environment.
