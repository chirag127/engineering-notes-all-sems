
### Laptop for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. Software: Software is a set of instructions that tells the computer how to perform a task. It can be used to control hardware devices, manage data, and run applications. Examples of software include operating systems, web browsers, and applications.

2. Hardware: Hardware is the physical components of a computer, such as the processor, memory, storage, and input/output devices. It is the physical components of a computer system that can be touched and interacted with.

3. Frameworks: A framework is a set of tools, libraries, and protocols that are used to create and manage software applications. Frameworks provide developers with a structure on which to build applications, and can be used to reduce development time and cost. Examples of frameworks include Ruby on Rails, AngularJS, and Node.js.

4. Wearable Computing: Wearable computing is the use of technology to create clothing and accessories that can be worn on the body and used to interact with the environment. Examples of wearable computing include smartwatches, fitness trackers, and augmented reality glasses.

5. Mixed Reality: Mixed reality combines elements of virtual reality and augmented reality to create a more immersive experience. It is a technology that uses sensors and cameras to create a bridge between the physical and digital worlds.

6. Internet of Everything: The Internet of Everything (IoE) is a concept that describes the interconnection of people, processes, data, and things. It is a network of interconnected devices and services that can be used to collect and share data, automate processes, and improve efficiency.
