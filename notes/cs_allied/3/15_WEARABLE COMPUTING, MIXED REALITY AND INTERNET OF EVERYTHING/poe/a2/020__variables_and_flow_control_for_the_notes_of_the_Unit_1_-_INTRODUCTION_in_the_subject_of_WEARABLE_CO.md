### Variables and Flow Control

- Variables: Variables are used to store values. They act as placeholders to refer to the stored values. Declare variables with keywords like var, let or const and assign values to them using =.
- Data types: JavaScript has dynamic types. This means that you do not need to specify the type of variable (number, string, boolean, etc.). The type is associated with the value.
- Constants: Use const to declare constants. Constants cannot be reassigned. They are block-scoped.
- Conditionals: Use if, else if and else statements to control the flow of execution based on conditions. The conditions are evaluated using comparison operators (>, <, ===, !==, etc.) and logical operators (&&, ||, !, etc.).
- Loops: Use for, while and do...while loops to repeat a block of code. Loops are useful to iterate over arrays or repeat statements until a condition is met.
- Functions: Functions are reusable blocks of code that perform a specific task. They allow you to organize your code, make it more readable and debug it easily. You can pass data (parameters) into a function and get a result (return value).
