### Open Frameworks for the notes of the Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE

1. Open Frameworks is a C++ toolkit designed to assist the creative process by providing a simple and intuitive framework for experimentation. It is used for rapid prototyping and creation of interactive applications, installations and software tools.
2. It provides a range of libraries for graphics, audio, video, networking, hardware interaction and more and is cross-platform, free and open source.
3. Some of the key features of Open Frameworks are:
- Easy to set up and get started. Just download and extract.
- Cross-platform support for Windows, macOS and Linux.
- C++ based which provides a lot of flexibility.
- An event-driven structure similar to Processing or openFrameworks.
- Hardware abstraction which enables interaction with webcam, kinect, wiimote etc.
- A range of add-ons available for different functionalities.
4. Open Frameworks has been used to create a variety of projects like interactive installations, live performances, data visualizations, hardware hacking etc. It is a good choice for rapid prototyping and creative coding projects where time-to-market is important.
