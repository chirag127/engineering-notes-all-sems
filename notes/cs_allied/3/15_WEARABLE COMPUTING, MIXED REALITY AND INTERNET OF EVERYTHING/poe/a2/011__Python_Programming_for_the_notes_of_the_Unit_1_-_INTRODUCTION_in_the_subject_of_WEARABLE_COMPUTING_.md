### Python Programming for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

1. Python is a popular programming language that is considered very easy to read and learn. It is a general-purpose language used for both scripting and application development.

2. Python is an interpreted language, which means that it is processed at runtime instead of being compiled into machine code in advance. This allows for faster development cycles since you don't have to wait for the code to be compiled and linked.

3. Python has a very clean and easy-to-read syntax, which makes it a good first programming language for beginners. The source code is fairly easy-to-maintain.

4. Python has a huge standard library with modules for everything from networking and GUI programming to regular expressions and unit testing. This makes it unnecessary to install additional libraries for many common tasks.

5. Python is a dynamic type language, which means that you don't need to explicitly declare variables before using them, or declare the types of function arguments. The interpreter infers types as the code is running.

6. Python features both imperative and object-oriented programming styles. New classes can be created easily by importing the "class" module and deriving from "object".

7. Python runs on Windows, Mac, Linux/Unix, has even been ported to the Java and .NET virtual machines, and has a wide variety of GUI frameworks and libraries available.
