### Creative Coding Platforms

- Processing: Open source programming language and IDE built for the electronic arts, new media art, and visual design communities. It is implemented in Java and based on the Java Processing library. Easy to learn with a simple and intuitive syntax. Used for creating images, animations, and interactions.
- p5.js: A JavaScript library for creative coding, especially focused on making coding accessible and inclusive for artists, designers, educators, and beginners. Builds on the core principles of Processing and translates them into JavaScript and the browser. Can be used with HTML, CSS, and JavaScript.
- openFrameworks: A C++ toolkit designed to assist the creative process by providing a simple and intuitive framework for experimentation. Provides cross-platform libraries for video, audio, graphics, networking, and more. Used by artists and designers for interactive art installations and data visualizations.
- Cinder: A C++ library for creative coding. Provides a low-level, easy to use set of tools to leverage the GPU and create interactive visual applications. Supports a variety of platforms including Windows, macOS, Linux, and Emscripten. Used to create interactive data visualizations, real-time video effects, and VR/AR experiences.
- Unity: A cross-platform game engine used to develop 2D and 3D games and interactive experiences. Provides a customizable and extensible architecture with components like physics, sound, navigation, cloud services, analytics, and more. Supports C#, JavaScript, Boo, and UnityScript. Used for game development, app development, architectural visualization, and machine learning.
