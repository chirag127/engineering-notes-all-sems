### XML for the notes of the Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE

1. XML stands for Extensible Markup Language. It is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
2. XML documents are made up of elements and attributes that form a tree structure. Elements have a start tag and an end tag, with content in between. Attributes provide additional information about elements.
3. XML is used for storing and transporting data because it:
- Is self-descriptive
- Is platform/language independent
- Supports Unicode
- Is hierarchical
4. Some common uses of XML include:
- RSS feeds
- Office documents (Word, Excel)
- Configuration files
- SVG images
- Android manifest files
- HTML (derived from XML)
