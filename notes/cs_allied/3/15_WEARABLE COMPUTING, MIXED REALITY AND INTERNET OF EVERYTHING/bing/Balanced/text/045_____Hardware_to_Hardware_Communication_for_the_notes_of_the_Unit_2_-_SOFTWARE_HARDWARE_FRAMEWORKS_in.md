### Hardware to Hardware Communication for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Hardware to hardware communication refers to the process of exchanging data between different devices or components of a wearable computing system.
- Hardware to hardware communication can be achieved by using various methods, such as wired or wireless connections, interrupt requests, serial or parallel ports, buses, or protocols.
- Some examples of hardware to hardware communication in wearable computing are:

  - A head mounted display (HMD) that receives video signals from a belt or backpack PC via a wireless link.
  - A one-handed chordic keyboard that sends keystrokes to a wearable computer via a serial port.
  - A sensor that triggers an interrupt request (IRQ) to the CPU when it detects a change in the environment.
  - A wearable computer that communicates with other devices or users through a personal wireless local area network (PAN) using Bluetooth or Wi-Fi.
  - A wearable device that adapts its power consumption, processing speed, and system configuration based on the context and user preferences.

- Hardware to hardware communication is essential for wearable computing because it enables:

  - Data transfer and synchronization between different devices or components of a wearable system.
  - User interaction and feedback through various input and output devices.
  - Context awareness and adaptation of the system to the user's needs and preferences.
  - Collaboration and coordination with other users or systems through networking and communication tools.
