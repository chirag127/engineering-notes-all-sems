# Raspberry Pi

- Raspberry Pi is a small, low-cost, single-board computer the size of a credit card that allows people from different backgrounds and levels of expertise to experience and learn to compute.
- Raspberry Pi uses what's called a system on a chip, which integrates the CPU and GPU in a single integrated circuit, with the RAM, USB ports, and other components soldered onto the board for an all-in-one package.
- Raspberry Pi can plug into a computer monitor or TV, and use a standard keyboard and mouse. It can run various operating systems, such as Linux, Windows, and Android.
- Raspberry Pi is developed in the United Kingdom by the Raspberry Pi Foundation, a charity that aims to make computing accessible and affordable for everybody .
- Raspberry Pi has various models and features, such as different processors, memory sizes, network capabilities, and camera modules. The latest model is the Raspberry Pi 400, which is a complete personal computer built into a compact keyboard .
- Raspberry Pi can be used for various purposes, such as education, gaming, robotics, media, home automation, and more. It can also be programmed in languages like Scratch and Python, and interact with other devices through its 40-pin GPIO header .
