# Software for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Software is the set of instructions or programs that control the operation of a computer system or a device.
- Software can be classified into two main categories: system software and application software.
- System software is the software that provides the basic functions and services for the hardware and other software, such as operating systems, device drivers, firmware, etc.
- Application software is the software that performs specific tasks for the user, such as word processors, games, browsers, etc.
- Software can also be categorized based on the level of abstraction, such as low-level software and high-level software.
- Low-level software is the software that directly interacts with the hardware, such as machine code, assembly language, etc.
- High-level software is the software that uses natural or artificial languages to express the logic and functionality of the program, such as C, Java, Python, etc.
- Software can also be categorized based on the mode of delivery, such as installed software and web-based software.
- Installed software is the software that is stored and executed on the local device, such as desktop applications, mobile apps, etc.
- Web-based software is the software that is accessed and executed over the internet, such as web applications, cloud services, etc.
- Software can also be categorized based on the type of interaction, such as graphical user interface (GUI) software and command-line interface (CLI) software.
- GUI software is the software that uses graphical elements, such as windows, icons, menus, etc., to interact with the user, such as Windows, macOS, Android, etc.
- CLI software is the software that uses text commands and responses to interact with the user, such as Linux, DOS, etc.
