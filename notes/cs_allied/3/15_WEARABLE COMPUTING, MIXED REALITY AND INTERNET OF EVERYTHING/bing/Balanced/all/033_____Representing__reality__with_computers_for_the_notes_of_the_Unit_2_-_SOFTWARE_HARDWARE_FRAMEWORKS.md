# Representing “reality” with computers

- Computers can model some aspects of reality by using data, algorithms and simulations.
- Data is a collection of facts or measurements that can be processed by a computer.
- Algorithms are a set of rules or instructions that tell a computer how to perform a specific task or solve a problem.
- Simulations are a way of imitating or mimicking a real-world system or phenomenon by using a computer model.
- A computer model is a representation or abstraction of reality that captures its essential features and behaviors.
- There are different levels of modeling reality with computers, such as:
  - Physical conversion of input signals into digital signals and vice versa. This involves using sensors, actuators and analog-to-digital converters to translate physical quantities (such as temperature, pressure, sound, light, etc.) into binary numbers that can be stored and manipulated by a computer, and vice versa.
  - Encoding schemes for representing information in binary. This involves using different methods or standards to encode different types of data (such as text, images, audio, video, etc.) into sequences of bits that can be transmitted, stored and processed by a computer.
  - Algorithmic modeling of physical processes. This involves using mathematical equations, rules or logic to describe how a system or phenomenon behaves or changes over time, and then implementing these descriptions as computer programs or software.
- There are different types of computer models, such as:
  - Raster models, which represent reality as a grid of cells or pixels, each with a value or attribute. These are commonly used for images, maps, digital elevation models, etc.
  - Vector models, which represent reality as a collection of points, lines, polygons or other geometric shapes, each with a location and an attribute. These are commonly used for geographic features, networks, diagrams, etc.
  - Object-oriented models, which represent reality as a collection of objects, each with a state and a behavior. These are commonly used for complex systems, such as games, simulations, etc.
- There are different types of simulations, such as:
  - Deterministic simulations, which produce the same outcome for the same input and model. These are commonly used for systems that follow fixed rules or laws, such as physics, chemistry, etc.
  - Stochastic simulations, which produce different outcomes for the same input and model, depending on random factors or events. These are commonly used for systems that involve uncertainty or variability, such as weather, ecology, etc.
  - Agent-based simulations, which model the interactions and behaviors of individual agents or entities within a system. These are commonly used for systems that involve emergent phenomena or collective behavior, such as social, economic, biological, etc.
