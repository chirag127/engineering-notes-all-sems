### Understanding Processing Code Structure

- Processing is a programming language and environment for creating interactive graphics, animations, and games.
- Processing code consists of two main parts, setup and draw blocks .
- Setup block runs once when the code gets executed, and the draw blocks runs continuously .
- The main idea behind Processing is, what you write within the draw block will be executed 60 times per second from top to bottom, until your program terminates.
- Processing code can also include other functions, variables, and libraries to enhance the functionality and interactivity of the program.
- Processing code can be written in two modes, Java mode and Python mode, depending on the syntax and features of the language.
- Processing code can be run on different platforms, such as desktop, web, and mobile, using different tools and frameworks, such as Processing IDE, Processing.js, p5.js, and Processing for Android.
- Processing code can be used to create various applications and projects related to wearable computing, mixed reality, and internet of everything, such as smart watches, augmented reality glasses, interactive installations, and IoT devices.
