# Push and Pull for the notes of the Unit 3 - CYBERNETICS AND HUMANISTIC INTELLIGENCE in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Push and pull are two different modes of communication and interaction in cybernetics, the science of feedback and control systems.
- Push mode is when a sender initiates a message or an action to a receiver, without waiting for a request or a demand from the receiver. For example, a push notification on a mobile device, a push marketing strategy that promotes a product to a target audience, or a push security approach that implements preventive measures to protect a system from threats.
- Pull mode is when a receiver initiates a message or an action to a sender, based on a request or a demand from the receiver. For example, a pull request on a version control system, a pull marketing strategy that attracts customers to a product by creating awareness and interest, or a pull security approach that responds to incidents and vulnerabilities as they occur.
- Push and pull modes have different advantages and disadvantages depending on the context and the goal of the communication and interaction. For instance, push mode can be more efficient, proactive, and timely, but also more intrusive, unwanted, and wasteful. Pull mode can be more responsive, personalized, and flexible, but also more reactive, delayed, and dependent.
- Push and pull modes can also work together to create a balanced and effective cybernetic system. For example, a push-pull marketing strategy can combine both methods to create demand and satisfy it, a push-pull security strategy can combine both methods to prevent and mitigate risks, or a push-pull visibility strategy can combine both methods to negotiate over the power of algorithms and platforms.
