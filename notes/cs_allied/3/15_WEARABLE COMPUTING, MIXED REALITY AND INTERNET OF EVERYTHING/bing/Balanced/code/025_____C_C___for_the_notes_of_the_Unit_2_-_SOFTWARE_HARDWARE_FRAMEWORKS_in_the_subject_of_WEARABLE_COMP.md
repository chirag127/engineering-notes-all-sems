### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- C/C++ is a general-purpose, compiled, and low-level programming language that can be used to develop software for wearable computing devices.
- C/C++ offers several advantages for wearable computing, such as:
  - High performance and efficiency, as it allows direct access to hardware resources and memory management.
  - Portability and compatibility, as it can run on different platforms and architectures with minimal changes.
  - Flexibility and extensibility, as it supports multiple programming paradigms and can be integrated with other languages and libraries.
  - Popularity and availability, as it is widely used and supported by many tools and frameworks.
- C/C++ also has some challenges and limitations for wearable computing, such as:
  - Complexity and verbosity, as it requires more code and attention to details than higher-level languages.
  - Error-proneness and security risks, as it does not have built-in features for memory safety, exception handling, or garbage collection.
  - Lack of standardization and consistency, as it has many variants and extensions that may not be compatible or interoperable.
- Some examples of frameworks and libraries that use C/C++ for wearable computing are:
  - Arduino, a platform for creating and programming microcontroller-based devices, such as smart watches, fitness trackers, or smart glasses.
  - OpenCV, a library for computer vision and machine learning, that can be used for face detection, gesture recognition, or augmented reality.
  - TensorFlow Lite, a framework for deploying deep learning models on mobile and embedded devices, that can be used for speech recognition, natural language processing, or image classification.
  - Qt, a framework for developing cross-platform applications with graphical user interfaces, that can be used for creating user-friendly and interactive wearable apps.
