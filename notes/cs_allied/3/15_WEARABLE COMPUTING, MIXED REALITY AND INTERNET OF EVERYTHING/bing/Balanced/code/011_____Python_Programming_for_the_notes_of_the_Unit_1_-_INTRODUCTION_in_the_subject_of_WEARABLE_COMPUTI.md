### Python Programming for the notes of the Unit 1 - INTRODUCTION in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Python is a popular, general-purpose, high-level, and object-oriented programming language that was created by Guido van Rossum in 1991   .
- Python has a simple and expressive syntax that is similar to the English language and allows developers to write programs with fewer lines of code than some other programming languages .
- Python is an interpreted language, which means that the source code is executed line by line by an interpreter, without the need for compilation .
- Python is a multi-paradigm language, which means that it supports multiple programming paradigms, such as procedural, object-oriented, functional, and imperative .
- Python is a cross-platform language, which means that it can run on different operating systems, such as Windows, Mac, Linux, Raspberry Pi, etc .
- Python is a versatile language, which means that it can be used for various domains and applications, such as web development, data analysis, machine learning, artificial intelligence, automation, game development, etc  .
- Python has a large and rich standard library, which provides built-in modules and functions for common tasks, such as file handling, database connectivity, networking, mathematics, etc  .
- Python also has a wide and active community of developers and users, who contribute to the development and maintenance of the language, as well as create and share various third-party libraries and frameworks for enhancing the functionality and usability of Python .
