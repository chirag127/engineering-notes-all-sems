### Open Source Platforms for Wearable Computing, Mixed Reality and Internet of Everything

- Wearable computing, mixed reality and internet of everything are emerging technologies that enable new forms of interaction, communication and data collection.
- Open source platforms are software or hardware systems that are freely available for anyone to use, modify and distribute.
- Open source platforms can provide various benefits for developing applications for wearable computing, mixed reality and internet of everything, such as:
  - Lower cost and higher flexibility compared to proprietary solutions.
  - Access to a large and diverse community of developers and users who can contribute to the improvement and innovation of the platforms.
  - Transparency and security of the source code and data.
  - Compatibility and interoperability with other open source platforms and standards.
- Some examples of open source platforms for wearable computing, mixed reality and internet of everything are:

  - **Eclipse Kura**: A platform for building IoT gateways that can connect, manage and control devices and sensors. It supports various protocols, such as MQTT, CoAP, Bluetooth, ZigBee and Modbus. It also provides a web-based user interface and a cloud integration framework.
  - **ThingSpeak**: An IoT platform and API for data collection and analytics. It allows users to send data from devices to the cloud, visualize and process the data, and trigger actions based on the data. It also supports MATLAB for advanced analytics and machine learning.
  - **Zetta**: An API-first platform for the internet of things. It allows developers to express devices as state machines using JavaScript and Node.js. It also provides a scalable and distributed architecture, a reactive programming model and a web-based dashboard .
  - **Open Hybrid**: A platform for interacting with everyday objects using augmented reality. It enables users to create and edit interfaces for physical objects using web technologies, such as HTML, CSS and JavaScript. It also supports various devices, such as smartphones, tablets, smart glasses and projectors.
  - **Node-RED**: A flow-based programming tool for wiring together devices, APIs and online services. It allows users to create applications by dragging and dropping nodes on a graphical editor and connecting them with wires. It also supports various protocols, such as HTTP, MQTT, WebSocket and TCP.
  - **Wio Link**: A hardware platform for creating IoT devices without coding. It consists of a Wi-Fi enabled board and a series of plug-and-play sensors and actuators. It also provides a mobile app and a cloud service for configuring and controlling the devices.
  - **Macchina.io**: A platform for building IoT applications using C++. It provides a modular and extensible framework for developing device drivers, protocols, web services and user interfaces. It also supports various platforms, such as Linux, Windows, macOS and Raspberry Pi.
  - **Physical Web**: A platform for discovering and interacting with nearby devices using web URLs. It allows users to access web content from devices without installing apps or pairing. It also supports various technologies, such as Bluetooth Low Energy, QR codes and NFC.
  - **Azure IoT**: A cloud-based platform for connecting, monitoring and managing IoT devices and solutions. It provides various services, such as IoT Hub, IoT Edge, IoT Central, IoT Plug and Play, IoT Device Provisioning Service and IoT Solution Accelerators. It also supports various protocols, such as MQTT, AMQP and HTTP .
  - **8th Wall**: A platform for creating augmented reality and virtual reality experiences using web technologies. It allows developers to use JavaScript and WebGL to create immersive and interactive content that runs on any device. It also provides a cloud-based editor, a hosting service and a library of components .
