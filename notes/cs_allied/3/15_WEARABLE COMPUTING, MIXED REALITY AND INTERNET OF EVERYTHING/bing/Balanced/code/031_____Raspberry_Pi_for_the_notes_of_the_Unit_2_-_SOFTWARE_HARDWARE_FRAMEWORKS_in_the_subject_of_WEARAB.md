### Raspberry Pi

- Raspberry Pi is a low-cost, credit-card-sized computer that can run various operating systems and perform various tasks.
- Raspberry Pi was developed by the Raspberry Pi Foundation, a UK-based charity that aims to promote computer science education and digital skills.
- Raspberry Pi has several models, each with different specifications and capabilities. The latest model is Raspberry Pi 4, which has a quad-core 1.5 GHz processor, up to 8 GB of RAM, dual-band Wi-Fi, Bluetooth 5.0, Gigabit Ethernet, USB 3.0, and two micro HDMI ports.
- Raspberry Pi can be used for various projects, such as web servers, media centers, robotics, gaming, education, and IoT (Internet of Things).
- Raspberry Pi can be programmed using various languages, such as Python, Scratch, C, Java, and JavaScript.
- Raspberry Pi can be connected to various peripherals, such as keyboards, mice, monitors, cameras, sensors, LEDs, and speakers.
- Raspberry Pi can be powered by a micro USB adapter, a power bank, or batteries.
- Raspberry Pi can be expanded with various add-on boards, such as HATs (Hardware Attached on Top), pHATs (partial HATs), and bonnets, which provide additional functionality and features.
- Raspberry Pi can be integrated with various software frameworks, such as TensorFlow, OpenCV, Arduino, and Node-RED, which enable advanced applications, such as machine learning, computer vision, embedded systems, and data processing.
