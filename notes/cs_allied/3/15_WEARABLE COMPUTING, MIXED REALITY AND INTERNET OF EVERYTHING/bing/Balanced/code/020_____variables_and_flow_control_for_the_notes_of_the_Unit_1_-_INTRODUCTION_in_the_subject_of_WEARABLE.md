### Variables and Flow Control

- Variables are named containers that store data or values in a program. They can have different types, such as integers, floats, strings, booleans, etc. Variables can be declared, assigned, and used in expressions or statements.
- Flow control is the process of determining the order of execution of statements or blocks of code in a program. Flow control can be influenced by conditions, loops, functions, and other constructs that alter the normal sequential flow of a program.
- There are three basic types of flow control structures in programming languages:
  - Sequence: The default flow of control, where statements are executed one after another in the order they appear in the program.
  - Selection: The conditional flow of control, where statements are executed based on some condition or choice. Examples of selection structures are if, if-else, switch, etc.
  - Iteration: The repetitive flow of control, where statements are executed multiple times until some condition is met. Examples of iteration structures are for, while, do-while, etc.
- Flow control structures can be represented by pseudocode, which is a simplified and informal way of writing a program, or by flowcharts, which are graphical diagrams that show the flow of control using symbols and arrows.
