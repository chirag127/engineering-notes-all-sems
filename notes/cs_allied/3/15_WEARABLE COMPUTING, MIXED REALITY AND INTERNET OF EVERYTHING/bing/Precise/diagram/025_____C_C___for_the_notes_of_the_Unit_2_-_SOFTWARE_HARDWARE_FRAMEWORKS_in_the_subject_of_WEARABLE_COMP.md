### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

C/C++ is a general-purpose programming language that is widely used for developing operating systems and applications. It is a compiled language, which means that the source code is translated into machine code by a compiler, allowing the program to run faster and more efficiently.

Here are some key points to consider when using C/C++ in the context of wearable computing, mixed reality, and the Internet of Everything:

1. C/C++ is a low-level language, which means that it provides a high degree of control over the hardware and system resources. This makes it well-suited for developing software for wearable devices, which often have limited processing power and memory.

2. C/C++ is a statically-typed language, which means that the type of a variable must be declared before it is used. This can help to prevent errors and improve the performance of the code.

3. C/C++ supports object-oriented programming, which allows for the creation of modular and reusable code. This can be useful when developing complex systems, such as those used in mixed reality and the Internet of Everything.

4. C/C++ has a large and active community of developers, which means that there is a wealth of resources and support available for those using the language.

In summary, C/C++ is a powerful and versatile language that is well-suited for use in the development of software for wearable computing, mixed reality, and the Internet of Everything. Its low-level nature, static typing, support for object-oriented programming, and large community of developers make it a strong choice for these applications.
