#### sqLite
- SQLite is a software library that provides a relational database management system.
- It is a popular choice for local/client storage in application software such as web browsers.
- It is a serverless, zero-configuration, transactional SQL database engine.
- SQLite is ACID-compliant and implements most of the SQL standard.
- SQLite is written in C and provides simple command-line tools to manage SQLite databases.
- SQLite databases are stored in a single file on disk.
- SQLite is used by many high-profile companies and organizations, including Apple, Google, and Mozilla.
- SQLite is also used in many mobile and embedded systems, such as Android and iOS devices.
- SQLite is open-source and has a public-domain dedication, allowing it to be used freely for any purpose.
