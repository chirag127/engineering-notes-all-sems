# Open Source Platforms for Wearable Computing, Mixed Reality and Internet of Everything

1. **Arduino**: An open-source electronics platform based on easy-to-use hardware and software. It is widely used for building wearable devices and IoT projects.

2. **Raspberry Pi**: A low-cost, credit-card-sized computer that can be used for a variety of projects, including wearable computing and IoT.

3. **Android Things**: An operating system from Google designed for IoT devices, including wearables.

4. **Zephyr**: A small, scalable, real-time operating system designed for use on resource-constrained systems, including wearables and IoT devices.

5. **Tizen**: An open-source operating system based on Linux, designed for use on a variety of devices, including wearables and IoT.

6. **Contiki**: An open-source operating system for the Internet of Things, designed for use on low-power, memory-constrained devices, including wearables.

7. **RIOT**: An open-source operating system designed for IoT devices, including wearables. It is designed to be energy-efficient and to support multiple hardware platforms.

8. **Mbed**: An open-source platform for building IoT devices, including wearables. It provides a range of tools and services to help developers build and manage their devices.

9. **FreeRTOS**: An open-source real-time operating system designed for use on microcontrollers, including those used in wearable devices and IoT projects.

10. **MicroPython**: An implementation of the Python programming language designed for use on microcontrollers, including those used in wearable devices and IoT projects.

These are some of the popular open-source platforms that can be used for developing wearable computing, mixed reality, and Internet of Everything projects. They provide a range of tools and services to help developers build and manage their devices.
