# Unit 1 - INTRODUCTION

## Creative Coding Platforms

Creative coding platforms are software tools that allow users to create and experiment with digital art, design, and interactive media. These platforms often provide a visual programming interface, making it easier for users to create complex programs without needing to write code. Some popular creative coding platforms include:

1. **Processing**: An open-source programming language and development environment for creating visual art and interactive media. It is based on the Java programming language and is widely used by artists, designers, and educators.

2. **p5.js**: A JavaScript library for creating graphics and interactive experiences in the browser. It is based on the principles of Processing and is designed to make coding accessible for artists, designers, educators, and beginners.

3. **openFrameworks**: An open-source C++ toolkit for creative coding. It provides a simple and intuitive way to create interactive installations, visualizations, and digital art.

4. **Max/MSP**: A visual programming language for music and multimedia. It allows users to create complex interactive systems using a graphical interface.

5. **TouchDesigner**: A visual development platform for creating interactive 3D art, visual effects, and immersive experiences. It is widely used in the fields of live performance, installation art, and experiential design.

These are just a few examples of the many creative coding platforms available. Each platform has its own strengths and unique features, allowing users to choose the one that best fits their needs and creative goals.
