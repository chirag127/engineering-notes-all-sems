# Unit 2 - SOFTWARE HARDWARE FRAMEWORKS
## openFrameworks as our IDE

openFrameworks is an open-source C++ toolkit designed to assist the creative process by providing a simple and intuitive framework for experimentation. It is commonly used for developing applications in the fields of art, design, and research.

Here are some key points to consider when using openFrameworks as our IDE for the subject of Wearable Computing, Mixed Reality, and the Internet of Everything:

1. openFrameworks is designed to work with a range of platforms, including Windows, macOS, Linux, iOS, and Android. This makes it a versatile choice for developing applications that can run on multiple devices.

2. The toolkit provides a large collection of libraries that can be used to develop applications. These libraries include support for graphics, sound, video, computer vision, and networking.

3. openFrameworks is designed to be easy to use, with a focus on simplicity and readability. This makes it a good choice for beginners, as well as for more experienced developers who want to work quickly and efficiently.

4. The openFrameworks community is active and supportive, with a large number of resources available to help developers get started and to continue learning. These resources include tutorials, examples, and documentation.

5. openFrameworks is well-suited for developing applications in the fields of Wearable Computing, Mixed Reality, and the Internet of Everything, as it provides a flexible and powerful framework for working with a wide range of technologies.

In summary, openFrameworks is a versatile and easy-to-use toolkit that provides a solid foundation for developing applications in the fields of Wearable Computing, Mixed Reality, and the Internet of Everything. Its support for multiple platforms, extensive libraries, and active community make it a strong choice for developers working in these fields.
