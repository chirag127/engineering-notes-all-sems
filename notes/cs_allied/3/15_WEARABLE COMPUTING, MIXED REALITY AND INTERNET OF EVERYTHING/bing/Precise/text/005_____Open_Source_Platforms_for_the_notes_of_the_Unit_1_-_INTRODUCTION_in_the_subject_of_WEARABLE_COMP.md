### Open Source Platforms for Wearable Computing, Mixed Reality and Internet of Everything

- **Eclipse Kura** is a platform for building IoT gateways.
- **ThingSpeak** is an IoT platform and API for data collection and analytics.
- **Zetta** is an API-first platform for the Internet of Things (IoT).
- **Open Hybrid** is a platform for interacting with everyday objects.
- **Node-RED** is a programming tool for wiring together hardware devices, APIs and online services.
- **Wio Link** is an ESP8266 based open-source Wi-Fi development board.
- **Macchina.io** is an open-source software toolkit for quickly building embedded applications for the Internet of Things.
- **Physical Web** is an effort to extend the core superpower of the web - the URL - to everyday physical objects.
- **PineTime** is a free and open source smartwatch capable of running custom-built open operating systems.
- **8th Wall** developed a phone-based augmented reality platform where AR experiences are created with JavaScript and WebGL.
