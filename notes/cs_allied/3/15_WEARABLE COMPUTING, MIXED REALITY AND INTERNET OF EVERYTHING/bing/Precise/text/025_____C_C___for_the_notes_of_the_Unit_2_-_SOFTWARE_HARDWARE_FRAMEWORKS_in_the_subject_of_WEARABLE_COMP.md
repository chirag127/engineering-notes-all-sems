### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- C and C++ are both programming languages that are widely used in the development of software and hardware frameworks.
- C is a procedural language, while C++ is an object-oriented language.
- C++ is an extension of C, and it adds support for object-oriented programming and other features that make it a more powerful language for developing complex software systems.
- Both C and C++ are commonly used in the development of operating systems, device drivers, and other low-level software that interacts directly with hardware.
- C and C++ are also used in the development of high-level software, such as applications and games.
- C and C++ are known for their efficiency and performance, which makes them well-suited for use in wearable computing, mixed reality, and the Internet of Everything.
- C and C++ provide a high degree of control over hardware resources, which is important in the development of software for resource-constrained devices such as wearables.
- C and C++ are widely supported on a variety of platforms, which makes them a good choice for cross-platform development.
- C and C++ have a large and active developer community, which provides a wealth of resources and support for developers working with these languages.
