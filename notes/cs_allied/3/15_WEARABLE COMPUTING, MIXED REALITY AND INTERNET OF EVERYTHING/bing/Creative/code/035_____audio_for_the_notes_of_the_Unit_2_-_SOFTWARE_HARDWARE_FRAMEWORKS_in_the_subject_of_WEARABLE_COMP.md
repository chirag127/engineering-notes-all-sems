### Audio for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- Wearable computing is the integration of computing devices into clothing or accessories that can be worn by humans.
- Mixed reality is the combination of real and virtual worlds, where physical and digital objects co-exist and interact in real time.
- Internet of everything is the concept of connecting any device or entity to the internet and to each other, enabling new levels of communication, collaboration, and data exchange.

- Software hardware frameworks are the architectures and platforms that enable the development and deployment of wearable computing, mixed reality, and internet of everything applications.
- Some examples of software hardware frameworks are:

  - Azure IoT, a cloud-based platform that provides tools and services for connecting, managing, and securing IoT devices and solutions.
  - UbiVis, an open-source framework that supports collaborative mixed reality applications across different hardware devices and platforms.
  - MRCP, a secure mixed reality framework that allows users to interact with headless IoT devices using voice and gesture commands.

- Some challenges and opportunities of software hardware frameworks are:

  - Hardware limitations: The current hardware available for wearable computing and mixed reality applications is often bulky, expensive, power-hungry, and prone to errors. There is a need for more lightweight, affordable, efficient, and reliable hardware that can support high-quality and immersive experiences.
  - Software compatibility: The software used for wearable computing, mixed reality, and internet of everything applications needs to be compatible with different hardware devices, platforms, and standards. There is a need for more interoperable, scalable, and adaptable software that can support diverse and dynamic scenarios.
  - Security and privacy: The software hardware frameworks that connect devices and entities to the internet and to each other also expose them to potential cyberattacks and data breaches. There is a need for more secure, trustworthy, and transparent software hardware frameworks that can protect the data and identity of the users and the devices.
  - User experience: The software hardware frameworks that enable wearable computing, mixed reality, and internet of everything applications also create new possibilities and challenges for the user experience. There is a need for more user-friendly, intuitive, and engaging software hardware frameworks that can enhance the interaction and collaboration between the users and the devices.
