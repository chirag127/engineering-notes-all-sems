### OpenFrameworks as our IDE

- OpenFrameworks is an open source C++ toolkit for creative coding.
- It is designed to simplify the process of creating applications that use graphics, sound, video, computer vision, networking and other interactive elements.
- It supports multiple platforms, such as Windows, Linux, macOS, iOS, Android, Raspberry Pi, etc .
- It also supports multiple development environments, such as Visual Studio, Xcode, Code::Blocks, Eclipse, etc .
- It provides a set of core classes and addons that can be used to create various types of projects, such as games, art installations, data visualizations, etc .
- It is based on OpenGL, which is a cross-platform API for rendering 2D and 3D graphics.
- It is distributed under the MIT License, which means it is free to use, modify and distribute .
- It has a large and active community of users and developers who contribute to the project and provide support, tutorials, examples and documentation .
