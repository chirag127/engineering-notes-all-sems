### C/C++ for the notes of the Unit 2 - SOFTWARE HARDWARE FRAMEWORKS in the subject of WEARABLE COMPUTING, MIXED REALITY AND INTERNET OF EVERYTHING

- C and C++ are low-level programming languages that are widely used for developing embedded software for wearable computing devices .
- C and C++ offer direct access to hardware features, such as memory management, input/output, interrupts, and registers, which are essential for controlling and optimizing the performance of wearable devices.
- C and C++ also support object-oriented programming, which allows for modular and reusable code design, as well as generic programming, which enables code to work with different types of data.
- C and C++ are compatible with many operating systems, libraries, and frameworks that are used for wearable computing, such as Android, Linux, OpenCV, TensorFlow, and Arduino .
- C and C++ are fast and efficient languages that can handle complex computations and algorithms, such as image processing, computer vision, machine learning, and augmented reality, which are common in wearable computing applications .
- C and C++ have a large and active community of developers and resources, which can help with learning, debugging, and improving the code quality and functionality .
