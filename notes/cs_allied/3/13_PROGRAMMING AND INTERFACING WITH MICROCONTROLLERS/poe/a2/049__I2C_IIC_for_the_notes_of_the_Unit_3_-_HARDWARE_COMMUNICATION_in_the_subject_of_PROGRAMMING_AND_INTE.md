### I2C/IIC for the notes of the Unit 3 - HARDWARE COMMUNICATION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. I2C (Inter-Integrated Circuit) is a synchronous serial communication protocol.
2. It is a multi-master, multi-slave protocol which means that multiple IC's can be connected to the same bus and any of them can initiate a data transfer.
3. It uses only two wires - SDA (Serial Data Line) and SCL (Serial Clock Line).
4. The devices are addressed using a 7-bit or 10-bit address scheme.
5. Data is transferred in chunks of 8-bits called bytes.
6. The I2C protocol supports data rates of up to 400 Kbps in standard mode and up to 1 Mbps in fast mode.
7. The I2C protocol relies on external pull-up resistors to hold the lines high when the bus is free.
8. The I2C protocol uses start and stop conditions to initiate and terminate a data transfer.
9. Some common applications of I2C are:
- Connecting and communicating between various sensors.
- Communicating with EEPROMs and RTC modules.
- Display controllers in LCD modules.
