### Git/GitHub for Unit 3 - Hardware Communication Notes

1. Git is a version control system that allows you to track changes made to code or other files. It enables you to revert files back to a previous version, revert the entire project back to a previous state, compare changes over time, see who last modified something that might be causing a problem, who introduced an issue and when, and more.

2. GitHub is a hosting service for Git repositories. It allows you to create repositories to store your projects and share them with others. Having a GitHub repository for your projects gives you a place to back them up, share them with collaborators, and even make your code open source.

3. To use Git and GitHub, you first need to install Git on your computer. Then you can initialize a Git repository and add files to be tracked. You'll commit changes to save versions of your files. You can push your repository to GitHub to share it, and pull from GitHub to get the latest changes others have made.

4. For microcontroller programming projects, using Git and GitHub enables you to keep versions of your code organized as you make changes, collaborate with others on code, and share your finished projects. You can track exactly what changes were made that introduced bugs or what changes fixed issues. Using GitHub also gives you a place to back up your code and files for a project so they're not lost if something happens to your local machine.

5. Here are some basic Git commands to get started:

- git init - Initialize a new Git repository
- git add - Add files to staging for commit
- git commit - Commit changes to the repository
- git status - View the status of changes
- git push - Push to a remote repository (like GitHub)
- git pull - Pull from a remote repository
