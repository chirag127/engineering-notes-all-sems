### C/C++ for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. C is a procedural programming language. It was initially developed by Dennis Ritchie in 1972.
2. C++ is an extension of C programming language. It was developed by Bjarne Stroustrup in 1979. It adds OOP features to the C language.
3. In C/C++, a program is a sequence of instructions to be executed by a CPU. These instructions are grouped into functions.
4. C/C++ programming languages provide various inbuilt functions arranged in libraries (like stdio.h, stdlib.h, etc.) for performing common programming tasks.
5. To use a library function in a C/C++ program, you need to include the library using the #include preprocessor directive.
6. A C/C++ program typically starts with the main() function. The program execution begins from the main() function.
7. Variables are used to store data/values in a C/C++ program. The types of variables can be integers, floats, double, char, etc.
8. C/C++ programming languages use different types of data structures like arrays, structures, unions, linked lists, stacks, queues, trees, graphs, etc. to store and organize data.
9. C/C++ programs can be compiled using a C/C++ compiler to generate executable binaries. The executable binaries can then be run on any machine to execute the program.
