## Unit 4 - ADVANCED I/O INTERFACING

1. Serial Peripheral Interface (SPI)
- Full duplex synchronous serial data transfer
- Uses separate clock signal
- Supports multiple slave devices
- Modes: Single/Dual/Quad data
- MOSI, MISO, SCLK, SS pins

2. Inter-Integrated Circuit (I2C)
- Synchronous serial data transfer
- Uses clock signal generated internally
- Supports multiple slave devices
- Uses addressing to select slave device
- SDA, SCL pins

3. USB interfaces
- Universal Serial Bus
- Hotswappable, plug and play
- Supports low and full speed devices (1.5Mbps/12Mbps)
- 4 wire interface: VCC, GND, D+, D-
- Enumeration: Host identifies and configures devices
- Supports control, interrupt, bulk and isochronous data transfer

4. Controller Area Network (CAN)
- Serial communication bus
- High immunity to electrical noise
- Support for multiple nodes
- Used in vehicles/industrial control
- Data transmitted in frames with unique IDs
- Different baud rates supported
