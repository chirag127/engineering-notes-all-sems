### TCP/IP and UDP

* TCP/IP stands for Transmission Control Protocol/Internet Protocol. It is a set of protocols that define how data should be processed and transmitted over the Internet.
* The two main protocols that make up TCP/IP are:
    * Transmission Control Protocol (TCP): Provides reliable, ordered, and error-checked delivery of transmitted data.
    * Internet Protocol (IP): Provides routing addressing to move data across networks.
* UDP stands for User Datagram Protocol. It is a simpler transport layer protocol, but it does not guarantee delivery or order of data packets. It provides fast transmission without the overhead of TCP.
* Applications that require high speed and low latency like real-time video/audio streaming use UDP. TCP is better suited for applications that require high reliability like email and web browsing.
* TCP provides flow control, congestion control, and reliable transmission, making it a complex but robust protocol. UDP provides fast transmission without these features, making it simpler but less reliable.
