### Mobile phones and similar devices

- Mobile phones and similar handheld devices like tablets, smart watches, etc. have become ubiquitous today.
- These devices are powered by embedded systems with microcontrollers/microprocessors at their core.
- They run operating systems like Android, iOS, etc. and apps on top of them to provide various functionality to the users.
- From a programming perspective, one can develop apps to run on these operating systems and interface with the onboard sensors, storage, display, etc. to create various use cases.
- Some examples of use cases are:
    - Health monitoring apps utilizing the sensors on the device like accelerometer, heart rate sensor, etc.
    - Apps to access location and provide location-based services using GPS and other localization techniques.
    - Apps to access the camera and storage to edit/share photos and videos.
    - Entertainment apps like music/video players, gaming apps, etc.
- To develop such apps, one needs to learn the software architecture of these devices, their operating systems, and programming languages/frameworks used to build apps for them.
- This introductory unit provides an overview of mobile phones and similar smart devices, their hardware and software architecture, and options to interface with them through programming.
