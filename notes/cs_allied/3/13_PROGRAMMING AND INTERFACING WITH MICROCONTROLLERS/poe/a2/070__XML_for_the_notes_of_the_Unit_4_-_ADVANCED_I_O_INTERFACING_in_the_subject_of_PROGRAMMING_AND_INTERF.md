### XML for the notes of the Unit 4 - ADVANCED I/O INTERFACING

1. XML stands for Extensible Markup Language. It is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
2. XML uses tags similar to HTML to mark different elements within the document. However, XML focuses on data content rather than presentation.
3. Some key features of XML are:
- It is a self-describing language. The tags provide context and structure to the data.
- It is platform independent and programming language independent. The data can be processed easily by any system or language.
- It is extensible. New tags can be defined as needed for different types of data.
- The syntax is simple and easy to understand. It uses tags enclosed in angle brackets.
4. XML is widely used for configuration files, data storage, RSS feeds, and AJAX applications. It can be used to store and transport data independent of any application.
5. For microcontroller programming, XML can be used to store sensor data or configuration parameters. The data can be easily parsed and processed due to the simple and structured format of XML.
