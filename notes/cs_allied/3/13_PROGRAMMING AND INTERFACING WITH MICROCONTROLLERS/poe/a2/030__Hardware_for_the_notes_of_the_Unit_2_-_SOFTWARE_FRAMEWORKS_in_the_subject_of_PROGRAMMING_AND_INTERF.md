### Hardware

1. Microcontroller: Microcontroller is a tiny computer that contains the components needed for a Basic CPU - processing unit, memory, and interfaces. It controls the operation of a machine and/or process. Some popular microcontrollers used are Arduino, Raspberry Pi, etc.
2. GPIO Pins: General Purpose Input Output pins are pins on a microcontroller that can be programmed to either input or output a signal. They are used to interface sensors and actuators with the microcontroller.
3. Power supply: The microcontroller needs a power supply to power itself and other components connected to it. Power supplies provide constant voltage to the microcontroller and other peripherals.
4. Crystals: Crystals provide a precise oscillating signal to the microcontroller which is used for timing and synchronization purposes. They ensure the precise working of the microcontroller.
5. USB connector: Universal Serial Bus connector is used to program the microcontroller and also interface it with a PC/laptop for communication. It provides a serial interface between the microcontroller and the outer world.
