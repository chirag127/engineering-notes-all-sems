### Arduino for the notes of the Unit 1 - INTRODUCTION

1. Arduino is an open-source electronics platform based on easy-to-use hardware and software. It consists of microcontroller boards that feature accessible IO pins as well as microcontrollers along with other components for a physical-computing system.
2. The hardware boards are pre-programmed with a boot loader firmware which allows uploading sketches onto the board without any additional hardware programmer. The Arduino Integrated Development Environment (IDE) is used to write and upload the sketches onto the Arduino board.
3. The Arduino board comes with I/O pins that can sense and control the physical world. Various sensors and actuators can be attached with these I/O pins to get input from sensors or control actuators based on the inputs. This allows one to develop interactive applications that can sense and control the physical world.
4. Some popular Arduino microcontroller boards are:
- Arduino Uno: The most popular Arduino board with 14 digital I/O pins and 6 analog pins.
- Arduino Mega: The Mega series boards with more number of I/O pins for complex projects. Mega 2560 has 54 digital I/O pins and 16 analog pins.
- Arduino Nano: A compact Arduino board for space-constrained projects. It has almost all the capabilities of the Arduino Uno.
- Arduino Leonardo: A popular Arduino board that can also act as a USB HID device.
5. The Arduino software is open-source and runs on Windows, Mac OS X, and Linux. It consists of an editor where the code is written and uploaded to the Arduino board along with a message area, a text console, a toolbar with buttons for common functions and a series of menus. The software also allows installing additional libraries to add more functionalities to the Arduino.
