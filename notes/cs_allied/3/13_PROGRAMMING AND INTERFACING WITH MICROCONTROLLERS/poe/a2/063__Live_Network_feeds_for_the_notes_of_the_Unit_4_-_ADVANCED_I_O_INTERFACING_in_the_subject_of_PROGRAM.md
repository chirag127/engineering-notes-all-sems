### Live Network feeds for the notes of the Unit 4 - ADVANCED I/O INTERFACING

1. RS-485:
- used for long distance communication
- differential signaling using twisted pair wires
- supports multiple devices on same bus with unique addresses
- wide common mode range and noise immunity
- maximum 32 devices, transmission speed up to 10 Mbps
- multidrop network, half duplex communication

2. Modbus:
- serial communication protocol
- query and command protocol for interacting with devices
- define registers for storing data
- read/write requests sent to devices to get data/control devices
- polling based so master device polls slaves continuously for data
- can use RS-232/RS-485 as physical layer

3. CAN bus:
- serial bus standard for connecting microcontrollers/devices
- high immunity to electromagnetic interference
- high transmission speed (up to 1 Mbps)
- Message based protocol (messages contain ID, data, CRC)
- Broadcast capable and receival of messages based on message ID
- Robust, fault tolerant and widely used in automotive systems
- Needs just 2 wires, can have multiple masters/slaves

4. Ethernet:
- Most popular wired networking technology
- Physical layer - cables/connectors, signal encoding/decoding
- Link layer - node addressing, error checking, flow control
- IP layer - logical addressing
- High speed (10/100/1000 Mbps), global acceptance, inexpensive
- Used for internet and local area networks
