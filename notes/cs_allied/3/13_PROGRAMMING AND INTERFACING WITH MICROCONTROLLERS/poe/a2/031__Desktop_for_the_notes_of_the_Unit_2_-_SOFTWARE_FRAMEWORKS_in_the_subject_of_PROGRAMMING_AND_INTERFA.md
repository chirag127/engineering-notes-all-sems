1. What are Software Frameworks?
- Software frameworks are reusable design and implementation for a software system or subsystem.
- They provide generic functionality that can be customized by user-written code, thus allowing software developers to focus on the specific parts of the system.
- Examples: React, Angular, Django, Laravel, etc.

2. Why Use Software Frameworks?
- Reduce complexity of programming tasks.
- Save time by reusing generic components.
- Often promote good software engineering practices (e.g. separation of concerns, code reusability).
- Large developer community and resources available for popular frameworks.
- Typically well-tested and robust.

3. Disadvantages of Using Frameworks
- Have to learn the framework's architecture/API.
- May be an overhead if framework provides more functionality than required.
- Could be dependent on third-party software and updates.
- May encourage boilerplate or one-size-fits-all approaches.

4. How to Choose a Software Framework
- Consider the use case and choose a suitable framework. For example, choose between front-end vs back-end vs full-stack frameworks.
- Evaluate framework's features and see if they meet project requirements.
- Check documentation and community support.
- Consider learning curve and developer experience.
- Evaluate performance and scalability.
- Consider licensing and deployment model.
