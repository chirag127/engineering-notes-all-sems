### Communication for the notes of the Unit 2 - SOFTWARE FRAMEWORKS

1. Software frameworks provide a common structure and starting point for software development. They allow programmers to implement the standard structure and then focus on the specifics of their application.
2. Some benefits of software frameworks are:
- Increased productivity due to reusing code and following conventions.
- Reduction in bugs as the frameworks are well-tested.
- Standardization of software architecture leading to ease of maintenance and learning.
3. However, some disadvantages of software frameworks are:
- The program may become dependent on the framework and face issues if the framework evolves or is discontinued.
- The framework may be too generic and lead to an applications with unnecessary features or complexity.
- The steep learning curve in understanding and using the framework efficiently.
4. Some popular software frameworks are:
- React for front-end web development
- Spring for enterprise Java applications
- Django for Python web apps
- Angular for mobile and web app development
