### Audio for the notes of Unit 2 - SOFTWARE FRAMEWORKS

1. Software Framework: A software framework is a reusable design for a software system (or subsystem). It provides a generic architecture which can be specialized by user code to create an application.

2. Advantages of Software Frameworks:
- Increased productivity: The framework provides all the common functionality and the developer just has to concentrate on the specific requirements of the application.
- Better quality: The framework is well tested and used by many applications. So the quality is better.
- Reduced cost: The initial cost of developing the common functionality is incurred once and is then leveraged by all the applications using the framework.
- Enforced consistency: The framework enforces some coding conventions and other practices leading to consistent design and development.

3. Examples of Software Frameworks:
- Spring framework for Java enterprise applications
- Django and Flask for Web applications using Python
- Node.js for server-side Web applications
- Qt for cross-platform GUI applications
- OpenCV for computer vision applications

4. Disadvantages of Software Frameworks:
- Learning curve: It takes time and effort to learn how to use a framework effectively.
- Heavy: The frameworks can be quite heavy and complex leading to bulkier applications.
- Constraints: The framework may impose some constraints on the design and implementation of the application to adhere to the framework's conventions.
- Version compatibility: The application has to be updated whenever the framework version is updated to maintain compatibility.
