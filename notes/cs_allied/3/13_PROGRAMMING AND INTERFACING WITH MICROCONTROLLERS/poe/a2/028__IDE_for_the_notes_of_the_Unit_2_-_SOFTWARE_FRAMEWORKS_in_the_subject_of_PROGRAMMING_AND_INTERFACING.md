### IDE for the notes of the Unit 2 - SOFTWARE FRAMEWORKS

1. An Integrated Development Environment (IDE) is a software application that provides comprehensive facilities to computer programmers for software development.
2. An IDE normally consists of a source code editor, build automation tools and a debugger.
3. The IDE provides a user-friendly interface to programmers for development activities like editing, compiling, deploying and debugging.
4. Few examples of IDEs are:
    - Eclipse for Java and C/C++ programming
    - Visual Studio for .NET and C/C++ programming
    - Arduino IDE for Arduino microcontroller programming
    - MPLAB X IDE for PIC microcontroller programming
5. The key advantages of using an IDE are:
    - It increases the productivity of programmers by providing tight-knit components.
    - It ensures a common look and feel across different programming languages.
    - It provides smart features like auto-completion of code, re-factoring support, etc. to assist the programmers.
