### Raspberry Pi for the notes of the Unit 1 - INTRODUCTION

1. Raspberry Pi is a credit card-sized single-board computer developed in the UK by the Raspberry Pi Foundation to promote teaching of basic computer science in schools and developing countries.
2. It provides an affordable and easy way to learn programming and interfacing with the real world.
3. The Raspberry Pi is capable of doing everything a desktop computer can do like spreadsheets, word-processing, browsing the Internet, playing high-definition video, etc.
4. The Raspberry Pi comes with a Broadcom BCM2835 system on a chip with an ARM1176JZF-S 700 MHz processor, VideoCore IV GPU, and 256-512 MB of RAM.
5. The GPIO (General Purpose Input Output) pins on the Raspberry Pi can be programmed to interface with the real world things like LEDs, switches, motors, sensors, etc.
6. The Raspberry Pi can run various operating systems like Raspbian (Debian-based), Ubuntu, Windows 10 IoT Core, etc. with programming languages like Python, C/C++, Java, etc.
7. The low cost and easy accessibility of the Raspberry Pi has made it popular among hobbyists, students, and educators for projects and workshops on programming and physical computing.
