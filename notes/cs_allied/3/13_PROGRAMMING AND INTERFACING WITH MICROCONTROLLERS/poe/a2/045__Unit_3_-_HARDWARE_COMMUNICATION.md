## Unit 3 - HARDWARE COMMUNICATION

1. Serial Communication
- Data is transmitted one bit at a time over a single wire
- Slow but simple and inexpensive to implement
- Examples: USB, I2C, SPI

2. Parallel Communication
- Multiple bits are transmitted simultaneously over multiple wires
- Faster than serial but more complex and requires more wires
- Example: PCI Express

3. Wired Communication Protocols
- Standards that define rules for data transmission between devices
- Ensure devices can connect and exchange data
- Examples: Ethernet, I2C, SPI, USB, PCI Express

4. Wireless Communication Protocols
- Standards that define rules for wireless data transmission and networking
- Eliminate the need for physical wires but can be less reliable
- Examples: Wi-Fi, Bluetooth, Cellular (4G/5G)
