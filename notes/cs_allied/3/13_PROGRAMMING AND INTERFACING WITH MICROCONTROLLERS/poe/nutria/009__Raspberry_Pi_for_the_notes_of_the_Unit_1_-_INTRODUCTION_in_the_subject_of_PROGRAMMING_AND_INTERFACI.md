
### Raspberry Pi for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

* Raspberry Pi is a low-cost, single-board computer developed by the Raspberry Pi Foundation in the United Kingdom. 
* It is a credit-card sized computer that can be used to learn programming, build projects, and interact with hardware. 
* Raspberry Pi is powered by a Broadcom BCM2835 system-on-chip (SoC) and includes an ARM1176JZF-S 700 MHz processor, VideoCore IV GPU, and 512 MB of RAM.
* The Raspberry Pi has a range of input and output (I/O) ports, including HDMI, USB, audio, Ethernet, and GPIO. 
* It runs on a variety of operating systems, including Raspbian, Ubuntu, and Windows 10 IoT Core. 
* Programming languages such as Python, C, and Java are supported by the Raspberry Pi.
* The Raspberry Pi can be used to create projects such as home automation, media servers, game consoles, and robots. 
* It can also be used to interface with external hardware such as sensors, motors, and servos.
