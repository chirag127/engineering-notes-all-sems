
### Raspberry Pi for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

* Raspberry Pi is a small, low-cost, single-board computer that can be used for a variety of applications. 
* It has a powerful ARM processor, which can be used to run a variety of software frameworks.
* The most popular software framework for the Raspberry Pi is Raspbian, which is based on the Debian Linux distribution.
* Raspbian comes with a wide range of pre-installed applications, such as a web browser, media player, and programming tools.
* It also provides access to the Raspberry Pi's GPIO pins, making it possible to interface with a variety of external hardware.
* Other software frameworks that can be used with the Raspberry Pi include Windows 10 IoT Core, Ubuntu Mate, and Arch Linux ARM.
* Each of these frameworks provides access to a different set of applications and tools, so it is important to choose the right one for your project.
