
### Data Persistence for the Notes of Unit 4 - Advanced I/O Interfacing

1. Data persistence is the ability of data to be stored and retrieved over time.
2. Data persistence is important in programming and interfacing with microcontrollers because it allows data to be stored and retrieved without having to re-enter it each time the program is run.
3. There are several methods of data persistence, including non-volatile memory, EEPROM, and flash memory.
4. Non-volatile memory is a type of memory that retains its data even when the power is turned off.
5. EEPROM (Electrically Erasable Programmable Read-Only Memory) is a type of non-volatile memory that can be written to and erased electronically.
6. Flash memory is a type of non-volatile memory that can be written to and erased quickly.
7. Data persistence is important for programming and interfacing with microcontrollers because it allows for data to be stored and retrieved quickly and reliably.
