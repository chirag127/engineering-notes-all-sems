
### Git/Github for the Notes of the Unit 3 - Hardware Communication in the Subject of Programming and Interfacing with Microcontrollers

1. Git is a version control system that allows developers to keep track of changes made to their code. 
2. Github is a web-based hosting service for version control using Git. It is used for storing and sharing code with other developers.
3. When working with hardware, it is important to keep track of the changes made to the code. This is where version control systems like Git and Github come in.
4. Git allows developers to keep track of their code by creating branches, committing changes, and merging branches.
5. Github allows developers to collaborate on code by creating pull requests, which can be accepted or rejected by other developers.
6. When working with hardware, developers can use Github to keep track of their code and collaborate with other developers.
7. Git and Github can be used to store and share code for projects involving hardware, such as Arduino and Raspberry Pi.
8. By using version control systems like Git and Github, developers can ensure that their code is always up-to-date and can easily track changes made to the code.
