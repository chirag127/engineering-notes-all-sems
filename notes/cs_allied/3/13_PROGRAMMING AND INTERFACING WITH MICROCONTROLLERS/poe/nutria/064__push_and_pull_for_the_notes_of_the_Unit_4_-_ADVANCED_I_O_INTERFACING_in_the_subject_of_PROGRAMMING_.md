
### Push and Pull for Unit 4 - Advanced I/O Interfacing

1. Push and pull are two types of I/O interfacing.
2. Push is when the microcontroller sends data to an external device.
3. Pull is when the external device requests data from the microcontroller.
4. Push and pull can be used in combination to send and receive data.
5. Push and pull can be used to control devices such as motors, LEDs, and sensors.
6. Push and pull provide a simple way to communicate between the microcontroller and other devices.
