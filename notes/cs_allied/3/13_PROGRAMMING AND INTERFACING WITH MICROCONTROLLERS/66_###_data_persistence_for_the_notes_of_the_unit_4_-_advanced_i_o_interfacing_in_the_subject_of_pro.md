2. Battery-backed memory: Battery-backed memory is a type of memory that is backed up by a battery. This type of memory retains its contents even when the power is turned off, and it is commonly used in microcontroller systems to store data that needs to persist across power cycles.

3. External storage: External storage is a type of storage that is separate from the microcontroller and that is used to store data that needs to persist across power cycles. This type of storage is commonly used in microcontroller systems when the amount of data that needs to be stored is too large to be stored in the microcontroller's internal memory or in a battery-backed memory.
