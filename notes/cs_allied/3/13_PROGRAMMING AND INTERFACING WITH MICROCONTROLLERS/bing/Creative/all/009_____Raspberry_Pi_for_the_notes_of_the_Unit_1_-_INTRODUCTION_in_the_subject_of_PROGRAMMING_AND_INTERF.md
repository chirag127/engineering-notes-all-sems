# Raspberry Pi

## Unit 1 - INTRODUCTION

- Raspberry Pi is a low-cost, credit-card-sized single-board computer that can connect to a computer monitor or TV, and uses a standard keyboard and mouse.
- Raspberry Pi is developed by the Raspberry Pi Foundation, based in the U.K., with the aim of imparting knowledge about computing to even younger students at the cheapest possible price.
- Raspberry Pi can run various operating systems, such as Linux, Windows, and Android, and can be used for various purposes, such as web browsing, gaming, programming, robotics, and IoT .
- Raspberry Pi has a central processing unit (CPU), a graphics processing unit (GPU), a random access memory (RAM), a micro SD card slot, a USB port, an Ethernet port, a HDMI port, a 3.5 mm audio jack, a 40-pin GPIO header, a camera interface, and a display interface .
- Raspberry Pi has different models and versions, such as Raspberry Pi 4 Model B, Raspberry Pi 3 Model B+, Raspberry Pi 3 Model A+, Raspberry Pi Zero, and Raspberry Pi Pico, each with different specifications, such as CPU speed, RAM size, weight, and power consumption .
- Raspberry Pi can be programmed in various languages, such as Python, Scratch, C, Java, and JavaScript, and can interact with various sensors and modules, such as LCD displays, servos, motors, cameras, and LEDs  .
- Raspberry Pi is a versatile and powerful device that enables people of all ages to explore computing, and to learn how to program and create projects in a fun and engaging way .
