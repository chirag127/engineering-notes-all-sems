# Creative Coding Platforms

Creative coding is a form of programming that uses code to create artistic expressions, such as animations, games, music, and interactive design. Creative coding platforms are tools or environments that enable users to write, run, and share their code easily and creatively. Some of the features of creative coding platforms are:

- They are often web-based or cross-platform, meaning they can run on different devices and browsers.
- They use languages or libraries that are designed for creative coding, such as Processing, p5.js, or Scratch.
- They have built-in editors, libraries, and examples that help users to write and debug their code.
- They have online communities where users can share, remix, and collaborate on their projects.
- They have educational resources, such as tutorials, courses, and documentation, that teach users the basics and advanced concepts of creative coding.

Some examples of creative coding platforms are:

- **Scratch**: Scratch is a free creative coding platform and online community that allows children of all ages to code, share, and remix their own stories, games, and animations. Scratch is translated into 50+ languages and available both online and offline.
- **OpenProcessing**: OpenProcessing is a creative coding platform and online community that allows users to create and share sketches using Processing or p5.js. OpenProcessing has thousands of sketches that users can browse, remix, and comment on.
- **Tynker**: Tynker is the world’s leading K-12 creative coding platform, enabling students of all ages to develop the coding skills to design and power animations, games, music, robots and drones, smart devices, virtual worlds like Minecraft, and more. Tynker has over 3,700 courses and activities that teach coding, STEM, and 21st-century skills.
- **Glitch**: Glitch is a collaborative programming environment that lives in your browser and deploys code as you type. Glitch allows users to create and remix web apps, games, bots, and more using HTML, CSS, JavaScript, and other languages. Glitch also has a friendly community where users can ask for help, give feedback, and discover new projects.
