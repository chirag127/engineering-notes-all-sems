## Unit 2 - SOFTWARE FRAMEWORKS

A software framework is a reusable set of libraries or classes that provide a standard way to perform a specific task, such as web development, database access, testing, or user interface design.

Some characteristics of software frameworks are:

- They are designed to be extensible, meaning that developers can customize or override the default behavior of the framework to suit their needs.
- They are based on the principle of inversion of control, meaning that the framework controls the flow of the application, and the developers provide the specific functionality through callbacks, listeners, or handlers.
- They often follow a specific design pattern, such as model-view-controller (MVC), which defines the roles and responsibilities of different components in the framework.
- They usually provide a consistent and coherent programming interface, which simplifies the development process and reduces the learning curve for new developers.
- They can reduce the amount of boilerplate code, errors, and bugs, by providing common functionality and best practices that have been tested and proven by many developers.

Some examples of software frameworks are:

- Spring Framework: A Java-based framework that provides a comprehensive set of features for enterprise application development, such as dependency injection, aspect-oriented programming, data access, web services, security, and testing.
- Django: A Python-based framework that follows the MVC pattern and enables rapid and clean web development, with features such as object-relational mapping, template engine, authentication, caching, and RESTful API.
- React: A JavaScript-based framework that focuses on building user interfaces, using a declarative and component-based approach, with features such as virtual DOM, hooks, state management, and routing.
- Laravel: A PHP-based framework that follows the MVC pattern and provides a simple and elegant syntax for web development, with features such as authentication, database migrations, blade templating, and artisan command-line tool.
