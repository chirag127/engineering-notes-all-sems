# openFrameworks

- openFrameworks is an open source C++ toolkit for creative coding .
- It is designed to assist the creative process by providing a simple and intuitive framework for experimentation.
- It is a cross-platform toolkit that supports as many development environments and operating systems as possible .
- It wraps together several commonly used libraries, including: OpenGL, GLEW, GLUT, libtess2 and cairo for graphics; rtAudio, PortAudio or FMOD for audio input and output; FreeType for fonts; FreeImage for image saving and loading; Quicktime, GStreamer or videoInput for video playback and grabbing; Poco for a variety of utilities; OpenCV for computer vision; Assimp for 3D model loading; and Boost for XML parsing .
- It also provides a set of core classes that deal with basic tasks such as window creation, events, timers, sound, video, image, 3D graphics, and math.
- It also offers a collection of addons that extend the functionality of the core classes, such as communication protocols, GUI elements, computer vision algorithms, and physics engines.
- It follows a few simple rules that make it easy to use and flexible, such as: everything is a class; all classes start with of (e.g. ofImage, ofSoundPlayer); all addons start with ofx (e.g. ofxOpenCV, ofxBox2d); all functions are camel case (e.g. loadImage, drawCircle); and all constants are uppercase (e.g. OF_WINDOW, OF_KEY_LEFT).
- It is a community-driven project that welcomes contributions from anyone who wants to improve or extend the toolkit.
- It is licensed under the MIT License, which means it is free to use and modify for any purpose, even commercial ones.
- It is inspired by other creative coding frameworks, such as Processing, Cinder, and openFrameworks.
