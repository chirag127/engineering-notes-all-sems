# Building Peer to Peer Communication System using Bluetooth & WiFi

## Introduction
- Peer to peer communication refers to the direct communication between two or more devices without the need for a central server or authority.
- Bluetooth and WiFi are two widely used wireless communication technologies that can be used to establish peer to peer communication.

## Bluetooth
- Bluetooth is a short-range wireless communication technology that operates in the 2.4 GHz frequency band.
- It is commonly used for communication between devices that are in close proximity to each other, such as between a smartphone and a wireless headset.
- Bluetooth supports both point-to-point and point-to-multi-point communication.

## WiFi
- WiFi is a wireless communication technology that operates in the 2.4 GHz and 5 GHz frequency bands.
- It is commonly used for communication between devices that are connected to the same local area network (LAN), such as between a laptop and a wireless router.
- WiFi supports both point-to-point and point-to-multi-point communication.

## Establishing Peer to Peer Communication
- To establish peer to peer communication using Bluetooth, the devices must first be paired.
- This involves the exchange of security information and the establishment of a secure connection between the devices.
- Once the devices are paired, they can communicate directly with each other without the need for a central server or authority.
- To establish peer to peer communication using WiFi, the devices must be connected to the same LAN.
- This can be achieved by connecting the devices to the same wireless router or by creating an ad-hoc network between the devices.
- Once the devices are connected to the same LAN, they can communicate directly with each other without the need for a central server or authority.

## Conclusion
- Both Bluetooth and WiFi can be used to establish peer to peer communication between devices.
- The choice of technology will depend on the specific requirements of the communication, such as the range and data transfer rate.
- By using these technologies, devices can communicate directly with each other without the need for a central server or authority.
