# Unit 3 - HARDWARE COMMUNICATION
## Arduino compatible Microcontrollers

- **MSP430 LaunchPad**: A low-cost, low-power-consumption microcontroller from Texas Instruments, the manufacturer of BeagleBone.
- **Nanode**: Designed to work like an Arduino, but is made specifically for Internet-connected projects.
- **Pinguino PIC32**: A solid prototyping tool originally designed for art students.
- **STM32 Discovery**: Another Arduino compatible microcontroller.
- **Teensy 2.0**: Another Arduino compatible microcontroller.
- **ATtiny Microcontrollers**: A low-cost Arduino alternative. This family of microcontrollers has a lot in common with Arduino boards. In fact, the Arduino Uno is powered by one of them: the ATmega328P.
- **PRO MICRO Development Board**: A microcontroller board based on the ATMEGA32U4-MU. It is an easy-to-use open source hardware and is fully compatible with Arduino.

There are many other microcontrollers that are compatible with Arduino, and new support packages are being produced all the time so the list is always growing. Some of these microcontrollers are provided by 3rd parties.
