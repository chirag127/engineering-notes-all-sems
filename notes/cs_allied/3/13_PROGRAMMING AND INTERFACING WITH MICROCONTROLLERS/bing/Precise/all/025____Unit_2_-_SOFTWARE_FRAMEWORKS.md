## Unit 2 - SOFTWARE FRAMEWORKS

A software framework is a reusable environment that provides a structure for developing software applications. It is a collection of libraries, tools, and conventions that help developers build software more efficiently. Some of the key features of software frameworks include:

1. **Inversion of Control:** In a software framework, the flow of control is managed by the framework itself, rather than by the application code. This allows developers to focus on writing the specific functionality of their application, rather than worrying about the underlying infrastructure.

2. **Default Behavior:** Software frameworks often provide default behavior for common tasks, such as handling user input or managing data storage. This allows developers to get up and running quickly, without having to write a lot of boilerplate code.

3. **Extensibility:** Software frameworks are designed to be extensible, allowing developers to add new functionality or modify existing behavior. This is typically done through the use of hooks or extension points, which allow developers to plug in their own code.

4. **Modularity:** Software frameworks are often modular, allowing developers to pick and choose the components they need for their application. This can help reduce the size and complexity of the application, and make it easier to maintain.

Some popular software frameworks include Angular, React, and Vue for front-end web development, and Spring, Django, and Ruby on Rails for back-end development. These frameworks provide a set of tools and conventions that help developers build robust and scalable applications.
