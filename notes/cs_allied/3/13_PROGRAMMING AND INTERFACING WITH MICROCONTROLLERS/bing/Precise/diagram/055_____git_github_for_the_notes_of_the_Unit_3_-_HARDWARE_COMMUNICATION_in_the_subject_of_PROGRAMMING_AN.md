### Unit 3 - HARDWARE COMMUNICATION: Git/GitHub

1. **Git** is a distributed version control system that allows multiple developers to collaborate on a project.
2. **GitHub** is a web-based platform that uses Git for version control and provides a place for developers to host and share their code.
3. Git allows developers to track changes to their code, create branches to work on new features, and merge changes from different branches.
4. GitHub provides additional features such as issue tracking, project management, and team collaboration tools.
5. Git and GitHub can be used to manage hardware communication code, allowing developers to collaborate on and share their work.
6. Git commands such as `git clone`, `git pull`, and `git push` can be used to interact with remote repositories on GitHub.
7. GitHub also provides a graphical user interface for managing repositories, making it easier for developers to collaborate on projects.
