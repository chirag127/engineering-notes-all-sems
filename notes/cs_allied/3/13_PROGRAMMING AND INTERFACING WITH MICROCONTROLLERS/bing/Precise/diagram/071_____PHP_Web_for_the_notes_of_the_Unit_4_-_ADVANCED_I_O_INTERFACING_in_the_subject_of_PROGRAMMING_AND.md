### PHP/Web for the notes of the Unit 4 - ADVANCED I/O INTERFACING in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

1. PHP is a server-side scripting language designed for web development.
2. PHP code is executed on the server, and the result is returned to the browser as plain HTML.
3. PHP can be used to create dynamic and interactive websites.
4. PHP can be used to interact with databases, such as MySQL, to store and retrieve data.
5. PHP can be used to create, read, update, and delete (CRUD) operations on data stored in a database.
6. PHP can be used to create forms and handle user input.
7. PHP can be used to create cookies and sessions to track user activity on a website.
8. PHP can be used to create file uploads and downloads.
9. PHP can be used to create and manipulate images.
10. PHP can be used to create and send emails.
