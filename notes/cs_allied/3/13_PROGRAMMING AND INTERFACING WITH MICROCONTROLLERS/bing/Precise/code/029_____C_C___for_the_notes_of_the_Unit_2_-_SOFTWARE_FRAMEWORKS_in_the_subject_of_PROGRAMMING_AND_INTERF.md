### Unit 2 - SOFTWARE FRAMEWORKS: C/C++

C and C++ are general-purpose programming languages that are widely used for developing operating systems, application software, and embedded systems. They are both considered to be low-level languages, meaning that they provide a high degree of control over the hardware and are often used for system-level programming.

Here are some key points to note about C and C++:

1. C is a procedural language, while C++ is an object-oriented language.
2. C++ is an extension of C, and it adds support for object-oriented programming and other features.
3. C and C++ are both compiled languages, meaning that the source code is translated into machine code by a compiler before it can be executed.
4. C and C++ are both statically-typed languages, meaning that the type of a variable must be specified at compile-time.
5. C and C++ are both widely used for system-level programming, including the development of operating systems, device drivers, and embedded systems.
