### TCP/IP and UDP for IoT

- TCP/IP and UDP are the main current transport layer protocols in IP-based IoT scenarios.
- TCP has traditionally been neglected as a transport-layer protocol for the Internet of Things (IoT).
- Unlike TCP, UDP doesn’t order data packets or directly establish a connection between the endpoints.
- UDP has no congestion control systems to optimize network resources.
- In IoT, UDP is less common than TCP but often appeals to IoT manufacturers because it uses fewer network resources to transmit and doesn’t have to maintain a constant connection between the two endpoints.
- The existing TCP/IP networking model uses a 4 layer model with protocols defined at each level.
