### Unit 2 - SOFTWARE FRAMEWORKS

1. A software framework is a reusable environment that provides a structure for developing software applications.
2. Frameworks are designed to facilitate the development process by providing pre-built components and libraries that can be used to build applications.
3. Frameworks can also provide a set of rules and guidelines for developing applications, helping to ensure consistency and maintainability.
4. Some common software frameworks include .NET, Java, Ruby on Rails, and AngularJS.
5. Frameworks can be used to develop a wide range of applications, including web, mobile, and desktop applications.
6. Using a framework can help to speed up the development process and reduce the amount of code that needs to be written.
7. Frameworks can also help to improve the quality of the code by providing pre-built components that have been tested and are known to work well.
8. When choosing a framework, it is important to consider factors such as the language it is written in, the level of support and documentation available, and the size and complexity of the applications it is designed to support.
