## Unit 2 - SOFTWARE FRAMEWORKS

A software framework is a reusable environment that provides a structure for developing software applications. It is a collection of libraries, tools, and conventions that help developers build software more efficiently. Some of the key features of software frameworks include:

1. **Inversion of Control:** In a software framework, the flow of control is managed by the framework itself, rather than by the application code. This allows developers to focus on writing the specific functionality of their application, rather than worrying about the underlying details of control flow.

2. **Default Behavior:** Software frameworks often provide default behavior for common tasks, such as handling user input or managing data storage. This allows developers to quickly build functional applications without having to write all of the code from scratch.

3. **Extensibility:** Software frameworks are designed to be extensible, meaning that developers can add new functionality or modify existing behavior to meet the specific needs of their application.

4. **Modularity:** Software frameworks are typically modular, meaning that they are composed of multiple, interchangeable components. This allows developers to easily reuse code and build applications more quickly.

Some popular software frameworks include Angular, React, and Ruby on Rails. These frameworks provide a set of tools and conventions that help developers build web applications more efficiently. By using a software framework, developers can save time and effort, and focus on building the unique features of their application.
