### Unit 1 - INTRODUCTION: Getting used to Arduino

1. **What is Arduino?** Arduino is an open-source electronics platform based on easy-to-use hardware and software. It is intended for anyone making interactive projects.
2. **How does it work?** Arduino boards are able to read inputs - light on a sensor, a finger on a button, or a Twitter message - and turn it into an output - activating a motor, turning on an LED, publishing something online.
3. **What can you do with it?** With Arduino, you can build a wide variety of projects, from simple LED circuits to complex robots and IoT devices.
4. **How to get started?** To get started with Arduino, you will need an Arduino board, a USB cable, and a computer with the Arduino software installed. You can download the software for free from the Arduino website.
5. **What are the basic components?** The basic components of an Arduino project include the Arduino board, a breadboard, jumper wires, resistors, LEDs, and various sensors and actuators.
6. **How to program it?** Arduino is programmed using the Arduino programming language, which is based on C/C++. The Arduino software includes a code editor and a serial monitor for debugging your code.
7. **Where to find resources?** There are many resources available online for learning about Arduino, including tutorials, project ideas, and forums where you can ask questions and share your projects.
