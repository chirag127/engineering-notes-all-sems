### Unit 1 - INTRODUCTION: Parts Identification

1. **Microcontroller**: A microcontroller is a small computer on a single integrated circuit that is designed to control electronic devices and systems.
2. **Central Processing Unit (CPU)**: The CPU is the brain of the microcontroller and is responsible for executing instructions.
3. **Memory**: The memory of a microcontroller is used to store data and program instructions. There are two types of memory: program memory and data memory.
4. **Input/Output (I/O) Ports**: I/O ports allow the microcontroller to interact with external devices by receiving input signals and sending output signals.
5. **Analog-to-Digital Converter (ADC)**: An ADC is used to convert analog signals into digital signals that can be processed by the microcontroller.
6. **Timers/Counters**: Timers and counters are used to measure time intervals and count events.
7. **Serial Communication Interface**: A serial communication interface is used to exchange data between the microcontroller and other devices.
8. **Interrupts**: Interrupts are used to temporarily halt the normal execution of the microcontroller and perform a specific task in response to an external or internal event.
