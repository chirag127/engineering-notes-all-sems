### Raspberry Pi for the notes of the Unit 1 - INTRODUCTION in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- Raspberry Pi is a low-cost, credit-card-sized single-board computer that can connect to a computer monitor or TV, and uses a standard keyboard and mouse .
- Raspberry Pi is developed by the Raspberry Pi Foundation, based in the U.K., with the aim of imparting knowledge about computing to even younger students at the cheapest possible price.
- Raspberry Pi can run various operating systems, such as Linux, Windows, and Android, and can be used for various purposes, such as web browsing, gaming, programming, and robotics .
- Raspberry Pi has a central processing unit (CPU), a graphics processing unit (GPU), a random access memory (RAM), a micro SD card slot, a USB port, an Ethernet port, a HDMI port, a 3.5 mm audio jack, a 40-pin GPIO header, and a power supply connector .
- Raspberry Pi has different models and versions, such as Raspberry Pi 4 Model B, Raspberry Pi 3 Model B+, Raspberry Pi 3 Model A+, etc., with different specifications, such as CPU speed, RAM size, weight, etc .
