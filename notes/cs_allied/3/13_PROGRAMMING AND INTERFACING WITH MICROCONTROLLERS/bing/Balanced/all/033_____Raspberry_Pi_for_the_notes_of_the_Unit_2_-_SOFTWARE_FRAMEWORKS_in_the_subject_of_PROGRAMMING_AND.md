# Raspberry Pi for the notes of the Unit 2 - SOFTWARE FRAMEWORKS in the subject of PROGRAMMING AND INTERFACING WITH MICROCONTROLLERS

- A software framework is a set of libraries or tools that provide a common structure and functionality for developing applications on a specific platform or environment.
- A software framework can simplify the development process by providing reusable components, abstracting low-level details, and enforcing best practices and standards.
- Raspberry Pi is a single-board computer that can run various operating systems and software frameworks, depending on the needs and preferences of the user.
- Some of the software frameworks that can be used with Raspberry Pi are:

  - **Raspberry Pi OS**: The official operating system for Raspberry Pi, based on Debian Linux. It provides a graphical user interface, a set of pre-installed applications, and access to the GPIO pins and other hardware features of the Raspberry Pi.
  - **Mono**: An open-source and cross-platform implementation of the .NET Framework, which supports C#, Visual Basic, and other .NET languages. It allows developers to create and run .NET applications on Raspberry Pi and other Linux devices.
  - **openFrameworks**: An open-source and cross-platform toolkit for creative coding, which supports C++ and other languages. It provides a set of libraries for graphics, sound, video, networking, and other domains, and enables developers to create interactive and multimedia applications on Raspberry Pi and other devices.
  - **Duet Software Framework**: A bundle of software programs that run on the Raspberry Pi and connect to and control the Duet 3, a 3D printer controller board. It allows users to configure and monitor the 3D printer via a web interface or a touchscreen.
  - **Framework Mainboards**: A series of standalone x86 mainboards that can be used with Raspberry Pi and other devices to create small form factor (SFF) PCs. They offer a higher performance and compatibility than the ARM-based Raspberry Pi, and support various operating systems and software frameworks.
