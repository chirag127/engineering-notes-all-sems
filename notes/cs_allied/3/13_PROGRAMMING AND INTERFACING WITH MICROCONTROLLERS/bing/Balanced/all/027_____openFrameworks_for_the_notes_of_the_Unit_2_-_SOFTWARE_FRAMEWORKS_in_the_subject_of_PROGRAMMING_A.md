# openFrameworks

- openFrameworks is an open source C++ toolkit for creative coding.
- It is designed to assist the creative process by providing a simple and intuitive framework for experimentation.
- It is a cross-platform toolkit that supports as many development environments and operating systems as possible.
- It wraps together several commonly used libraries, including: OpenGL, GLEW, GLUT, libtess2 and cairo for graphics; rtAudio, PortAudio or FMOD for audio input and output; FreeType for fonts; FreeImage for image saving and loading; Quicktime, GStreamer or videoInput for video playback and grabbing; Poco for a variety of utilities; OpenCV for computer vision; Assimp for 3D model loading; and Boost for XML parsing.
- It also provides a set of addons that extend the functionality of the core library, such as ofxGui for graphical user interfaces, ofxNetwork for networking, ofxOsc for open sound control, ofxKinect for Microsoft Kinect, and many more.
- It offers a collection of examples and tutorials that demonstrate the basic and advanced features of the toolkit, such as drawing, animation, interaction, sound, video, 3D, shaders, etc .
- It has a friendly and active community of developers and artists who contribute to the project, share their work, and help each other on the forum .
- It is released under the MIT License, which means it is free to use and modify for any purpose.
