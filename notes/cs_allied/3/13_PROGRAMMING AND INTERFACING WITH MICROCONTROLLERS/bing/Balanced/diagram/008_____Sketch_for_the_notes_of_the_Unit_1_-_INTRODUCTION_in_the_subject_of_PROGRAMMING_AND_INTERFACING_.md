# Unit 1 - Introduction

## What is a microcontroller?

- A microcontroller is a small computer on a single integrated circuit that contains a processor, memory, and input/output peripherals.
- Microcontrollers are designed for embedded applications, such as controlling devices, sensors, actuators, displays, etc.
- Microcontrollers are also called microprocessors, microcomputers, or microcontrollers.

## Why use microcontrollers?

- Microcontrollers offer many advantages for embedded systems, such as:
  - Low cost
  - Low power consumption
  - High performance
  - Flexibility and programmability
  - Integration and miniaturization
  - Reliability and robustness

## How to program microcontrollers?

- Microcontrollers can be programmed using different languages, such as:
  - Assembly language: a low-level language that directly corresponds to the machine instructions of the microcontroller.
  - C language: a high-level language that is widely used for microcontroller programming, as it offers portability, efficiency, and readability.
  - C++ language: an extension of C language that supports object-oriented programming, which can help to organize and reuse code.
  - Python language: an interpreted, high-level language that is easy to learn and use, and can interact with microcontrollers via serial communication or libraries.
- Microcontrollers can be programmed using different tools, such as:
  - Integrated development environment (IDE): a software application that provides a graphical user interface for writing, compiling, debugging, and uploading code to the microcontroller.
  - Compiler: a software program that translates the source code written in a high-level language into machine code that can be executed by the microcontroller.
  - Debugger: a software or hardware tool that allows the programmer to monitor and control the execution of the code on the microcontroller, and to find and fix errors.
  - Programmer: a hardware device that connects the microcontroller to the computer and transfers the machine code to the microcontroller's memory.

## How to interface microcontrollers with external devices?

- Microcontrollers can interface with external devices using different methods, such as:
  - Digital input/output (I/O): a method that allows the microcontroller to read or write binary signals (0 or 1) from or to external devices, such as switches, LEDs, relays, etc.
  - Analog input/output (I/O): a method that allows the microcontroller to read or write analog signals (continuous voltage or current) from or to external devices, such as sensors, potentiometers, motors, etc.
  - Serial communication: a method that allows the microcontroller to exchange data with external devices or other microcontrollers using a single or a few wires, such as UART, SPI, I2C, etc.
  - Parallel communication: a method that allows the microcontroller to exchange data with external devices or other microcontrollers using multiple wires, such as LCD, keypad, etc.
  - Wireless communication: a method that allows the microcontroller to exchange data with external devices or other microcontrollers without wires, such as Bluetooth, Wi-Fi, radio frequency, etc.
