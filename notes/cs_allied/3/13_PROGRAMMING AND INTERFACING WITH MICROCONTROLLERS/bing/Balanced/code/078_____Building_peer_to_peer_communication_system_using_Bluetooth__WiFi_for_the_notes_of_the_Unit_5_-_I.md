# Building peer to peer communication system using Bluetooth &WiFi

- Peer to peer (P2P) communication system is a network of devices that can communicate directly with each other without relying on any central server or infrastructure.
- Bluetooth and Wi-Fi are two wireless technologies that can be used to create P2P networks using smartphones or other devices.
- Bluetooth is a short-range wireless technology that allows devices to exchange data over a distance of up to 10 meters. Bluetooth can be used for streaming audio, transferring files, or connecting peripherals such as keyboards or mice.
- Wi-Fi is a wireless technology that allows devices to connect to the internet or a local area network (LAN) over a distance of up to 100 meters. Wi-Fi can be used for browsing the web, downloading files, or streaming video.
- Bluetooth and Wi-Fi can also be used to create P2P networks without internet or LAN access. This is called ad hoc networking or Wi-Fi Direct.
- Ad hoc networking or Wi-Fi Direct allows devices to discover and connect to each other directly using Bluetooth or Wi-Fi, forming a wireless mesh network. This can be useful for sharing data, playing games, or communicating in areas where internet or cellular service is unavailable or unreliable.
- Some examples of applications that use ad hoc networking or Wi-Fi Direct are:

  - Bridgefy: A messaging app that uses Bluetooth to chat with people nearby or with Wi-Fi Direct to chat with people further away by connecting through other Bridgefy users.
  - FireChat: A messaging app that uses Bluetooth and Wi-Fi to create a mesh network of devices and allows users to chat with each other or broadcast messages to a larger audience.
  - Wi-Fi Shoot: An app that uses Wi-Fi Direct to transfer photos, videos, or any files between devices.
  - SuperBeam: An app that uses Wi-Fi Direct to transfer large files between devices at high speed.
  - AllCast: An app that uses Wi-Fi Direct to stream media from a device to a smart TV or a Chromecast.

- To create a P2P network using Bluetooth or Wi-Fi Direct, the following steps are required:

  - Enable Bluetooth or Wi-Fi on the devices that want to join the network.
  - Discover and pair the devices using Bluetooth or Wi-Fi Direct. This can be done manually or using an app that facilitates the process.
  - Establish a connection and exchange data using Bluetooth or Wi-Fi Direct. This can be done using the built-in features of the devices or using an app that provides the functionality.

- Some advantages of using Bluetooth or Wi-Fi Direct for P2P networking are:

  - No internet or cellular service required, which can save data costs and battery life.
  - No dependence on any central server or infrastructure, which can increase privacy and security.
  - High speed and low latency, which can improve the quality and performance of data transfer or streaming.
  - Scalability and flexibility, which can allow more devices to join the network and adapt to changing conditions.

- Some disadvantages of using Bluetooth or Wi-Fi Direct for P2P networking are:

  - Limited range and coverage, which can restrict the network to a small area or a few devices.
  - Interference and compatibility issues, which can affect the reliability and stability of the network.
  - Battery consumption and device performance, which can be affected by the continuous use of Bluetooth or Wi-Fi.
  - Complexity and user experience, which can require technical knowledge and manual intervention to set up and maintain the network.
