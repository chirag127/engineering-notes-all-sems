## Unit 3 - HARDWARE COMMUNICATION

- Hardware communication is the process of sending and receiving data between different devices using physical components and protocols.
- Hardware communication can be classified into two types: wired and wireless.
- Wired communication uses cables or wires to connect devices and transmit signals. Examples of wired communication devices are modems, routers, switches, and Ethernet cables.
- Wireless communication uses electromagnetic waves or radio frequencies to connect devices and transmit signals. Examples of wireless communication devices are Wi-Fi adapters, Bluetooth devices, and cellular phones.
- Hardware communication requires both hardware devices and software protocols to function properly. Hardware devices are the physical components that enable data transmission, while software protocols are the rules and standards that govern how data is formatted, encoded, and decoded.
- Some of the common software protocols used in hardware communication are TCP/IP, HTTP, FTP, SMTP, and UART. These protocols define how data is divided into packets, how packets are addressed and routed, how packets are acknowledged and retransmitted, and how packets are converted into serial or parallel signals.
