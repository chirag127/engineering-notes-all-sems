## Unit 2 - Hardware for IoT:

1. Sensors: Detect physical quantities and convert them into signals which can be read by an electronic system. Examples: Temperature, Humidity, Motion, Pressure, Light, etc. sensors.
2. Digital sensors: Output digital signals (ON/OFF) which can be directly read by a microprocessor. Example: Switch sensors.
3. Actuators: Convert an electrical signal into a mechanical action. Examples: Motors, lamps, heaters, pumps, etc.
4. Radio Frequency Identification (RFID) technology: Use of radio waves to read and capture information stored on a tag attached to an object. RFID tags can be passive (without a battery) or active (with a battery).
5. Wireless Sensor Networks: Consist of spatially distributed autonomous sensors to monitor physical or environmental conditions, such as temperature, sound, vibration, pressure, motion or pollutants and to cooperatively pass their data through the network to a main location.
6. Participatory Sensing Technology: Sensor data collection system where individuals or organizations contribute sensory data via personal devices to create dynamic data maps and enable data sharing.

Embedded Platforms for IoT:

1. Embedded computing basics: Computing systems with a dedicated function within a larger mechanical or electrical system. They consist of microcontrollers and systems on chips which contain memory, processors and input/output peripherals.
2. Overview of IoT supported Hardware platforms:
- Arduino: Open-source electronic prototyping platform allowing to create interactive objects or environments.
- NetArduino: Internet-enabled Arduino compatible platform.
- Raspberry Pi: Credit-card sized computer which can be used to learn programming.
- BeagleBone: Community-supported development platform for developers and hobbyists.
- Intel Galileo boards: Development boards designed for Intel processors to support IoT and wearable devices.
- ARM cortex: Processor IP supplying low power processors for mobile and embedded computing devices.
