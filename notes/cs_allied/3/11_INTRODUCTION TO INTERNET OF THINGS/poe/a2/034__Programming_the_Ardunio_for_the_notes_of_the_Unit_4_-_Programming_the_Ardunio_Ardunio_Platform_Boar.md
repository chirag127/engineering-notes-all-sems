### Programming the Arduino for the notes of Unit 4 - Programming the Arduino:

1. Arduino Platform Boards Anatomy:
- Microcontroller
- Input and Output Pins
- Power Supply
- Clock
- Memory

2. Arduino IDE:
- Open source software
- Written in Java
- Used to write, compile and upload code to the Arduino board
- Includes a text editor, a message area, a compiler, and an uploader

3. Coding:
- Arduino programs are called sketches
- Written in C/C++
- Include functions like `setup()` which runs once and `loop()` which loops continuously
- Comments start with `//`

4. Using Emulator:
- Emulator simulates the Arduino board software and hardware
- Used for programming and testing before using actual hardware
- Allows prototyping without hardware

5. Using Libraries:
- Pre-written code for common tasks like LCD displays, Ethernet, etc.
- Reduces programming effort and avoids reinventing the wheel
- Need to be included using `#include` directive

6. Additions in Arduino:
- Arduino versions with more memory, processing power and connectivity options available now
- Examples: Arduino Mega, Arduino Micro, Arduino Due, Arduino Zero, etc.

7. Programming Arduino for IoT:
- Arduino can be connected to sensors and actuators to build IoT projects
- Requires additional shields or hardware modules for connectivity like WiFi, Bluetooth, GSM, etc.
- Programming for reading data from sensors, connectivity, cloud connectivity and controlling actuators
