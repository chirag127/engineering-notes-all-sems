### Architectural view for the notes of the Unit 1 - Internet of Things (IoT):

1. Vision: Interconnecting physical and virtual worlds through smart devices and Internet connectivity.
2. Definition: The interconnection via the Internet of computing devices embedded in everyday objects, enabling them to send and receive data.
3. Conceptual Framework: Sensor(s)/actuator(s), gateway, network, service/application layer.
4. Architectural view: Perception, network, application layers. Perception layer: sensors and actuators. Network layer: communication networks. Application layer: software applications and services.
5. Technology behind IoT: RFID, sensors, embedded systems, cloud computing, communication technologies (Wi-Fi, Bluetooth, etc.).
6. Sources of the IoT: Smart city, smart home, industrial Internet, connected cars, wearable devices, etc.
7. M2M Communication: Communication between machines/devices without human interaction.
8. IoT Examples: Smart cities, smart homes, smart grids, connected cars, wearable devices, etc.

Design Principles for Connected Devices:

1. IoT/M2M systems layers and design standardization:Perception, network, application layers and corresponding standards.
2. Communication technologies: Wired/wireless, short/long range as per application requirements.
3. Data enrichment and consolidation: Fuse data from multiple sources, extract useful information/knowledge, present consolidated information.
4. Ease of designing and affordability: Components and technologies should be modular, plug-and-play, and cost-effective for mass adoption.
