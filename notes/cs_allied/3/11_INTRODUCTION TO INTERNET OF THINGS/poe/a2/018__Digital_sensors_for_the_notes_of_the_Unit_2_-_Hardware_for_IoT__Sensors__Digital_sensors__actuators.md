### Digital sensors for the notes of the Unit 2 - Hardware for IoT:

1. Sensors: Detect physical quantities and convert them into signals which can be read by an electronic system. Examples: Temperature, Pressure, Motion, Light, Gas, etc. sensors.
2. Digital sensors: Sensors which convert the physical quantity into a digital signal (on/off electrical signal or a number) that can be directly read by a microcontroller or microprocessor. Examples: Digital temperature sensors (DS18B20), Light dependent resistors (LDR), etc.
3. Actuators: Devices which can convert an electrical signal into physical movement. Examples: Motors, relays, lights, heaters, etc.
4. Radio Frequency Identification (RFID) technology: Uses tags or chips to store data and a reader to retrieve the data wirelessly using radio waves. Used for identification, tracking and authentication.
5. Wireless Sensor Networks: A network of sensors which communicate wirelessly and pass on the data to a gateway. Enables collecting data from inaccessible locations.
6. Participatory Sensing Technology: Technique of collecting sensor data from mobile and handheld devices contributed by humans. Eliminates the need for dedicated sensing devices.

Embedded Platforms for IoT:

1. Embedded computing basics: Small and dedicated computing systems designed for specific tasks. Have software embedded into hardware.
2. Overview of IOT supported Hardware platforms:
- Arduino: Open-source hardware platform for prototyping interactive objects or environments. Supports sensors, actuators, network connectivity, etc.
- Netduino: Open source hardware platform for .NET microframework. Supports .NET programming languages.
- Raspberry pi: Credit card sized single board computer capable of connecting sensors, displays, motors, etc. Supports Linux operating system.
- Beagle Bone: Open source hardware platform with advanced I/O capabilities aimed at developers and hobbyists. Supports Linux operating system.
- Intel Galileo boards: Development boards designed for Intel Quark and Intel Atom processors. Supports Arduino shields and Windows/Linux operating systems.
- ARM cortex: Family of 32-bit RISC ARM processor cores designed for low power consumption. Used in many IOT hardware platforms.
