
### MAC Protocol Survey for the Notes of the Unit 3 - Network & Communication Aspects in IoT

* Wireless Medium Access Issues: Wireless medium access issues are related to the transmission of data in a wireless network. These issues include contention, hidden node, and exposed node problems. Contention occurs when two or more nodes attempt to transmit data at the same time. Hidden node and exposed node problems occur when nodes are unable to detect each other due to physical obstructions or distance.

* MAC Protocol Survey: MAC (Medium Access Control) protocols are used to control access to the shared wireless medium. These protocols are designed to reduce contention and improve throughput. Examples of MAC protocols include CSMA/CA, CSMA/CD, TDMA, FDMA, and ALOHA.

* Survey Routing Protocols: Survey routing protocols are used to survey the network topology in order to determine the best route for data transmission. These protocols include AODV, DSR, and DSDV.

* Sensor Deployment & Node Discovery: Sensor deployment and node discovery are important aspects of IoT networks. Sensor deployment involves deploying sensors in a variety of locations in order to collect data. Node discovery is the process of discovering nodes in the network in order to facilitate communication.

* Data Aggregation & Dissemination: Data aggregation and dissemination are important components of IoT networks. Data aggregation involves collecting data from multiple sources and combining it into a single dataset. Data dissemination involves distributing the data to the appropriate nodes in the network.
