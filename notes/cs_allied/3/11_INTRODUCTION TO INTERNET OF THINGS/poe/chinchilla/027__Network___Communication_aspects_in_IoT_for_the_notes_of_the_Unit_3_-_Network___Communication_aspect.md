### Network & Communication aspects in IoT

Internet of Things (IoT) is a network of interconnected devices that can communicate with each other and exchange data. This network requires a robust communication system to function effectively. Network and communication aspects in IoT include several factors such as wireless medium access issues, MAC protocol survey, survey routing protocols, sensor deployment and node discovery, and data aggregation and dissemination. Let's explore each of these aspects in detail:

#### Wireless Medium Access Issues

Wireless medium access issues refer to the problems that arise when multiple devices try to access a wireless channel simultaneously. In IoT, several devices operate in a shared medium, which leads to collisions and reduces the overall efficiency of the network. The following techniques are used to resolve wireless medium access issues:

- Time Division Multiple Access (TDMA): In this technique, the available time is divided into slots, and each device is allocated a specific slot to transmit its data.
- Carrier Sense Multiple Access (CSMA): In this technique, each device listens to the channel for ongoing transmissions before transmitting its data.
- Collision Avoidance Techniques: These techniques aim to avoid collisions by using various mechanisms such as random backoff and RTS/CTS (Request to Send/Clear to Send) protocols.

#### MAC Protocol Survey

Several MAC protocols are used in IoT networks, which include:

- IEEE 802.11: It is a widely used MAC protocol that uses CSMA/CA (Carrier Sense Multiple Access/Collision Avoidance) technique to avoid collisions.
- IEEE 802.15.4: It is a low-power MAC protocol that is used in wireless sensor networks (WSNs).
- ZigBee: It is a MAC protocol that is designed for low-cost and low-power IoT devices.

#### Survey Routing Protocols

Routing protocols are used to establish communication between devices in IoT networks. Some of the commonly used routing protocols are:

- Ad-hoc On-demand Distance Vector (AODV): It is a reactive routing protocol that establishes a route only when needed.
- Destination-Sequenced Distance Vector (DSDV): It is a proactive routing protocol that maintains a complete routing table to all the nodes in the network.
- Low-power and Lossy Network (LLN): It is a routing protocol that is used in low-power and lossy networks such as WSNs.

#### Sensor Deployment & Node Discovery

The deployment of sensors is a critical aspect of IoT networks. The following factors should be considered while deploying sensors:

- Sensor Placement: The sensors should be placed in such a way that they can capture the required data accurately.
- Power Management: The sensors should be designed to consume less power to ensure long battery life.
- Node Discovery: The process of discovering new nodes in the network is critical for expanding the network.

#### Data Aggregation & Dissemination

Data aggregation and dissemination refer to the process of collecting data from various nodes in the network and transmitting it to the destination. The following techniques are commonly used for data aggregation and dissemination:

- Tree-Based Techniques: In this technique, a tree structure is used to collect and transmit data to the destination.
- Cluster-Based Techniques: In this technique, the nodes in the network are grouped into clusters, and data is collected and transmitted within each cluster.

In conclusion, network and communication aspects play a crucial role in the effective functioning of IoT networks. By considering the factors mentioned above, we can design a robust and efficient IoT network that can cater to the needs of various applications.
