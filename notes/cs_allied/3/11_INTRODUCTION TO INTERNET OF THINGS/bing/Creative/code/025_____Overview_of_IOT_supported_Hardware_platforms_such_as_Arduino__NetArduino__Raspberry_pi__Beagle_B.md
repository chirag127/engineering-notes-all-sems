### Overview of IOT supported Hardware platforms such as Arduino, NetArduino, Raspberry pi, Beagle Bone, Intel Galileo boards and ARM cortex

- IOT supported hardware platforms are devices that can connect to the internet and interact with other devices, sensors, actuators, and applications.
- These platforms enable the development and deployment of various IOT applications, such as smart home, smart city, smart agriculture, smart health, etc.
- Some of the common features of these platforms are:
  - Low power consumption
  - Wireless communication capabilities
  - Programmable and configurable
  - Support for various sensors and actuators
  - Scalable and modular
- Some of the popular IOT supported hardware platforms are:

  - Arduino: Arduino is an open-source platform that consists of a microcontroller board and a software development environment. Arduino can be used to create interactive projects that involve sensors, actuators, LEDs, motors, etc. Arduino supports various communication protocols, such as Bluetooth, Wi-Fi, Ethernet, etc. Arduino has a large community of users and developers who share their projects and codes online.
  - Netduino: Netduino is a platform that is compatible with Arduino, but uses the .NET Micro Framework as the software development environment. Netduino can run C# code and supports various communication protocols, such as Wi-Fi, Ethernet, etc. Netduino also has a large community of users and developers who share their projects and codes online.
  - Raspberry Pi: Raspberry Pi is a small computer that can run various operating systems, such as Linux, Windows, etc. Raspberry Pi can be used to create various IOT applications that involve multimedia, web servers, databases, etc. Raspberry Pi supports various communication protocols, such as Wi-Fi, Ethernet, Bluetooth, etc. Raspberry Pi also has a large community of users and developers who share their projects and codes online.
  - Beagle Bone: Beagle Bone is a platform that consists of a single-board computer and a software development environment. Beagle Bone can run various operating systems, such as Linux, Android, etc. Beagle Bone can be used to create various IOT applications that involve sensors, actuators, web servers, etc. Beagle Bone supports various communication protocols, such as Wi-Fi, Ethernet, Bluetooth, etc. Beagle Bone also has a large community of users and developers who share their projects and codes online.
  - Intel Galileo: Intel Galileo is a platform that consists of a microcontroller board and a software development environment. Intel Galileo can run Linux and supports various communication protocols, such as Wi-Fi, Ethernet, Bluetooth, etc. Intel Galileo can be used to create various IOT applications that involve sensors, actuators, web servers, etc. Intel Galileo is compatible with Arduino and can use Arduino shields and libraries.
  - ARM Cortex: ARM Cortex is a family of microcontroller cores that are widely used in various IOT devices, such as smartphones, tablets, wearables, etc. ARM Cortex can run various operating systems, such as Linux, Android, etc. ARM Cortex supports various communication protocols, such as Wi-Fi, Ethernet, Bluetooth, etc. ARM Cortex can be used to create various IOT applications that involve sensors, actuators, web servers, etc. ARM Cortex has a large community of users and developers who share their projects and codes online.
