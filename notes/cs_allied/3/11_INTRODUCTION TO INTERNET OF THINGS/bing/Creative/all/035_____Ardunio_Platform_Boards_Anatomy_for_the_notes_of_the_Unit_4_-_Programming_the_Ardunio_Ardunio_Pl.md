# Ardunio Platform Boards Anatomy

- Arduino boards are the microcontroller development platform that will be at the heart of your projects .
- Arduino boards can sense the environment by receiving inputs from many sensors, and affect their surroundings by controlling lights, motors, and other actuators.
- Arduino boards can be programmed using the Arduino IDE, which is a cross-platform application that allows you to write code, compile it, and upload it to the board.
- Arduino boards can also be programmed using emulators, which are software applications that simulate the behavior of the hardware and allow you to test your code without a physical board.
- Arduino boards can use libraries, which are collections of code that provide specific functions or features, such as communication protocols, sensors, displays, etc.
- Arduino boards can be extended with additional hardware, such as shields, modules, sensors, actuators, etc., that can be plugged into the board or connected via wires.
- Arduino boards can be programmed for IoT applications, which are projects that involve connecting devices to the internet or to each other, and collecting, processing, and exchanging data.

## Arduino Uno Board Anatomy

- Arduino Uno is one of the most popular and widely used Arduino boards .
- Arduino Uno has the following main components  :

  - Microcontroller: Think of it as a tiny computer, designed to execute only a specific number of things. It is the brain of the board and runs the code that you upload to it. The Arduino Uno uses the ATmega328P microcontroller, which has 32 KB of flash memory, 2 KB of SRAM, and 1 KB of EEPROM.
  - USB port: Used to connect the board to the computer and upload the code. It also provides power to the board when connected to the computer or a USB charger.
  - USB to Serial chip: This is what makes it possible to program the Arduino board from your computer. It converts the USB signals to serial signals that the microcontroller can understand. The Arduino Uno uses the ATmega16U2 chip for this purpose.
  - Digital pins: Commonly used for switches and LEDs. They can be configured as inputs or outputs and can read or write digital values (HIGH or LOW). The Arduino Uno has 14 digital pins, numbered from 0 to 13. Some of them have special functions, such as PWM, serial communication, interrupts, etc.
  - Analog pins: Commonly used for sensors that produce a variable voltage, such as potentiometers, light sensors, temperature sensors, etc. They can only be configured as inputs and can read analog values from 0 to 1023. The Arduino Uno has 6 analog pins, numbered from A0 to A5.
  - Power pins: Used to provide power to the board or to other components. They include the following pins:

    - VIN: The input voltage to the Arduino board when using an external power source (6-20V).
    - 5V: The regulated power supply used to power the microcontroller and other components on the board (5V).
    - 3.3V: A 3.3V supply generated by the board for some components that require lower voltage (3.3V).
    - GND: Ground pins for common ground reference.
    - IOREF: The voltage at which the I/O pins of the board are operating (5V for Arduino Uno).
    - RESET: A pin that can be used to reset the microcontroller.

  - ICSP header: Used to program the microcontroller using an external programmer. It stands for In-Circuit Serial Programming and consists of 6 pins: MISO, MOSI, SCK, RESET, VCC, and GND.
  - Power LED: Indicates that the board is powered on.
  - TX and RX LEDs: Indicate the transmission and reception of data via the serial port.
  - L LED: Connected to digital pin 13 and can be used to test the board or as a status indicator.
  - Reset button: Used to reset the microcontroller and restart the code.
