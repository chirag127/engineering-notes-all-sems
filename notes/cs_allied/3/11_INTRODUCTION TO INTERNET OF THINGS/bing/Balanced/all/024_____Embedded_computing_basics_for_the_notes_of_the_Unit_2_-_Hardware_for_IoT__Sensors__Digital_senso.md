# Embedded Computing Basics

- An embedded system is a special-purpose computer system designed to perform a dedicated function.
- Unlike a general-purpose computer, such as a personal computer, an embedded system performs one or a few pre-defined tasks, usually with very specific requirements, and often includes task-specific hardware and mechanical parts not usually found in a general-purpose computer.
- Examples of embedded systems are an watch, washing machine, microwave oven, digital camera, etc.
- Embedded systems are usually classified into four types: standalone, networked, mobile, and real-time.
- Standalone embedded systems operate independently and do not require a host system or network connection.
- Networked embedded systems rely on a network connection to communicate with other systems or devices, such as sensors, actuators, or servers.
- Mobile embedded systems are portable and battery-powered, such as smartphones, tablets, or wearable devices.
- Real-time embedded systems have strict timing constraints and must respond to events or inputs within a specified deadline, such as airbags, pacemakers, or industrial controllers.
- Embedded systems are designed with various hardware and software components, such as microcontrollers, microprocessors, memory, input/output devices, operating systems, compilers, debuggers, etc.
- Embedded systems software and development environments are specialized tools and techniques to create, test, and deploy embedded applications.
- Embedded systems software can be written in different programming languages, such as C, C++, Java, Python, etc, depending on the requirements and constraints of the system.
- Embedded systems development environments can include hardware platforms, software tools, simulators, emulators, debuggers, etc.
- Some of the popular embedded hardware platforms for IoT are Arduino, Netduino, Raspberry Pi, BeagleBone, Intel Galileo, and ARM Cortex.
- Arduino is an open-source platform that consists of a microcontroller board and a software development environment that can be used to create interactive projects with sensors, actuators, LEDs, etc.
- Netduino is a similar platform to Arduino, but it uses the .NET Micro Framework and can be programmed in C# or Visual Basic.
- Raspberry Pi is a low-cost, credit-card sized computer that can run Linux or Windows operating systems and can be used for various applications, such as web servers, media centers, robotics, etc.
- BeagleBone is another small computer that can run Linux or Android operating systems and can interface with various peripherals, such as cameras, LCDs, keyboards, etc.
- Intel Galileo is a microcontroller board that is compatible with Arduino and can run Linux operating system and support various communication protocols, such as Ethernet, Wi-Fi, Bluetooth, etc.
- ARM Cortex is a family of microcontroller cores that can be used for various embedded applications, such as automotive, industrial, medical, etc.
