## Unit 4 - Programming the Arduino: Arduino Platform Boards Anatomy, Arduino IDE, coding, using emulator, using libraries, additions in Arduino, programming the Arduino for IoT.

- Arduino boards are the microcontroller development platform that will be at the heart of your projects. A microcontroller is a small computer that can run a single program repeatedly and can be used to control sensors, lights, motors, and other devices.
- Arduino boards have different features and capabilities depending on the model, but they all share some common components and functionalities. Here are some of the main parts of an Arduino board  :

  - **Power supply**: Arduino boards can be powered by a USB cable connected to a computer or a power adapter, or by a battery. The power supply provides the voltage and current needed for the board and the connected devices. The board has a voltage regulator that ensures a stable voltage of 5V or 3.3V, depending on the model.
  - **Microcontroller**: The microcontroller is the brain of the Arduino board. It is a chip that contains the processor, the memory, and the input/output pins. The microcontroller can be programmed using the Arduino IDE, which is a software that allows you to write and upload code to the board. The most common microcontroller used in Arduino boards is the ATmega328P, which has 32 KB of flash memory, 2 KB of RAM, and 20 input/output pins.
  - **Input/output pins**: The input/output pins are the connectors that allow the Arduino board to communicate with other devices, such as sensors, LEDs, motors, buttons, etc. The pins can be configured as digital or analog, depending on the type of signal they receive or send. Digital pins can only read or write values of 0 or 1, while analog pins can read or write values between 0 and 1023, corresponding to a range of voltages between 0 and 5V or 0 and 3.3V. Some pins have special functions, such as PWM (pulse-width modulation), which can be used to control the brightness of LEDs or the speed of motors, or serial communication, which can be used to send and receive data between the Arduino board and a computer or another device.
  - **LEDs**: Arduino boards have some built-in LEDs that indicate the status of the board or the communication. The most common LEDs are the power LED, which shows that the board is receiving power, the TX and RX LEDs, which blink when data is being transmitted or received through the serial port, and the pin 13 LED, which is connected to the digital pin 13 and can be controlled by the code.
  - **Reset button**: The reset button is used to restart the Arduino board and the code. Pressing the button will reset the microcontroller and run the code from the beginning. This can be useful for debugging or testing the code.

- Arduino IDE is the integrated development environment that allows you to write, compile, and upload code to the Arduino board. The IDE is a software that runs on your computer and provides a text editor, a compiler, a serial monitor, and other tools to help you program the Arduino board. The IDE can be downloaded from the official Arduino website.
- Coding for Arduino is done using a language that is based on C/C++, which are popular and widely used programming languages. The code for Arduino consists of two main parts: the setup and the loop. The setup is a function that runs once when the board is powered on or reset, and is used to initialize the variables, pins, and libraries. The loop is a function that runs repeatedly and is used to perform the main tasks of the program, such as reading sensors, controlling outputs, or communicating with other devices. The code for Arduino also uses some special keywords and functions that are specific to the Arduino platform, such as pinMode, digitalWrite, analogRead, Serial, etc.
- Using an emulator is a way to simulate the behavior of the Arduino board and the connected devices without having to use the actual hardware. An emulator is a software that mimics the functionality of the Arduino board and the input/output pins, and allows you to test and debug your code before uploading it to the real board. There are many emulators available online, such as Tinkercad Circuits, Arduino Simulator, Wokwi Arduino Simulator, etc.
- Using libraries is a way to extend the functionality of the Arduino board and the code by using pre-written code that can be reused and modified. Libraries are collections of code that provide specific features or functions
