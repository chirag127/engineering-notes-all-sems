### Architectural view for the notes of the Unit 1 - Internet of Things (IoT)

1. **Vision:** The vision of the Internet of Things (IoT) is to create a world where everyday objects are connected to the internet, allowing them to collect and share data, and interact with each other to improve our lives.

2. **Definition:** The Internet of Things (IoT) is a network of physical objects, or "things," that are embedded with sensors, software, and other technologies to connect and exchange data with other devices and systems over the internet.

3. **Conceptual Framework:** The conceptual framework of IoT includes the following components:
    - **Sensors/Devices:** These are the physical objects that collect data from the environment.
    - **Connectivity:** This refers to the communication technologies that allow the sensors/devices to transmit data to the cloud or other systems.
    - **Data Processing:** This involves the analysis and manipulation of the data collected by the sensors/devices.
    - **User Interface:** This is the means by which users can interact with the IoT system, such as through a mobile app or web interface.

4. **Architectural view:** The architectural view of IoT includes the following layers:
    - **Perception Layer:** This layer is responsible for collecting data from the environment through sensors and devices.
    - **Network Layer:** This layer is responsible for transmitting the data collected by the perception layer to the processing layer.
    - **Processing Layer:** This layer is responsible for processing and analyzing the data collected by the perception layer.
    - **Application Layer:** This layer is responsible for delivering the processed data to the user through a user interface.

5. **Technology behind IoT:** The technology behind IoT includes sensors, communication technologies, data processing and analysis tools, and user interface design.

6. **Sources of the IoT:** The sources of the IoT include sensors and devices that collect data from the environment, as well as data from other systems and sources.

7. **M2M Communication:** Machine-to-Machine (M2M) communication refers to the direct communication between devices, without the need for human intervention.

8. **IoT Examples:** Some examples of IoT applications include smart homes, wearable technology, and connected cars.

9. **Design Principles for Connected Devices:** The design principles for connected devices include IoT/M2M systems layers and design standardization, communication technologies, data enrichment and consolidation, ease of designing and affordability.
