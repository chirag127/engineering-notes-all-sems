## Unit 1 - Internet of Things (IoT)

### Vision
The vision of the Internet of Things (IoT) is to create a world where everyday objects are connected to the internet, allowing them to collect and share data, and interact with each other to improve our lives.

### Definition
IoT refers to the network of physical objects or "things" embedded with sensors, software, and other technologies for the purpose of connecting and exchanging data with other devices and systems over the internet.

### Conceptual Framework
The conceptual framework of IoT includes the following components:
- **Sensors/Devices**: These are the physical objects that collect data from the environment and send it to the network.
- **Connectivity**: This refers to the communication technologies that allow the sensors/devices to send data to the network.
- **Data Processing**: This refers to the process of analyzing and processing the data collected by the sensors/devices.
- **User Interface**: This refers to the interface through which users can interact with the IoT system.

### Architectural View
The architectural view of IoT includes the following layers:
- **Perception Layer**: This layer is responsible for collecting data from the environment using sensors/devices.
- **Network Layer**: This layer is responsible for transmitting the data collected by the sensors/devices to the data processing center.
- **Middleware Layer**: This layer is responsible for data processing, storage, and management.
- **Application Layer**: This layer is responsible for providing services to the users based on the processed data.

### Technology behind IoT
The technology behind IoT includes sensors, communication technologies, data processing technologies, and user interface technologies.

### Sources of the IoT
The sources of the IoT include sensors, devices, and systems that collect and transmit data.

### M2M Communication
M2M (Machine-to-Machine) communication refers to the communication between two or more machines without human intervention. This is an essential component of IoT, as it allows devices to exchange data and interact with each other.

### IoT Examples
Some examples of IoT include smart homes, where devices such as thermostats, lighting, and security systems are connected to the internet and can be controlled remotely; wearable devices, such as fitness trackers, that collect and transmit data about the user's health and activity; and smart cities, where sensors and devices are used to collect data and improve city services.

### Design Principles for Connected Devices
The design principles for connected devices in IoT/M2M systems include layers and design standardization, communication technologies, data enrichment and consolidation, ease of designing, and affordability.

#### IoT/M2M systems layers and design standardization
IoT/M2M systems should be designed using a layered approach, with each layer responsible for a specific function. The design of these systems should also be standardized to ensure interoperability between different devices and systems.

#### Communication technologies
Communication technologies are an essential component of IoT/M2M systems, as they allow devices to exchange data. These technologies should be chosen based on factors such as range, bandwidth, and power requirements.

#### Data enrichment and consolidation
Data collected by IoT/M2M systems should be enriched and consolidated to provide more meaningful and actionable insights.

#### Ease of designing and affordability
IoT/M2M systems should be easy to design and affordable to implement, to encourage widespread adoption.
