### Conceptual Framework for the notes of the Unit 1 - Internet of Things (IoT)

1. **Vision:** The vision of the Internet of Things (IoT) is to create a world where physical objects are seamlessly integrated into the information network, and where they can become active participants in business processes.
2. **Definition:** IoT refers to the interconnection of uniquely identifiable embedded computing devices within the existing Internet infrastructure.
3. **Conceptual Framework:** The conceptual framework of IoT includes the following components:
    - **Devices:** These are the physical objects that are connected to the network and can sense, actuate, and communicate.
    - **Network:** This is the infrastructure that enables communication between devices and the cloud.
    - **Cloud:** This is the central repository where data from devices is stored and processed.
    - **Applications:** These are the software programs that enable users to interact with the IoT system and derive value from the data.
4. **Architectural View:** The architectural view of IoT includes the following layers:
    - **Perception Layer:** This layer is responsible for collecting data from the physical world through sensors and other devices.
    - **Network Layer:** This layer is responsible for transmitting data from the perception layer to the processing layer.
    - **Processing Layer:** This layer is responsible for processing the data collected by the perception layer and making it available to the application layer.
    - **Application Layer:** This layer is responsible for providing services to the end user based on the processed data.
5. **Technology behind IoT:** The technology behind IoT includes sensors, actuators, communication protocols, cloud computing, and data analytics.
6. **Sources of the IoT:** The sources of the IoT include sensors, RFID tags, and other devices that can collect data from the physical world.
7. **M2M Communication:** Machine-to-Machine (M2M) communication refers to the direct communication between devices without the need for human intervention.
8. **IoT Examples:** Some examples of IoT applications include smart homes, smart cities, connected cars, and wearable devices.
9. **Design Principles for Connected Devices:** The design principles for connected devices include IoT/M2M systems layers and design standardization, communication technologies, data enrichment and consolidation, ease of designing and affordability.
