### Network & Communication aspects in IoT

Unit 3 of the subject "Introduction to Internet of Things" covers the Network & Communication aspects in IoT. The following points are discussed in this unit:

1. **Wireless Medium access issues:** This topic covers the challenges and issues related to accessing the wireless medium in IoT networks. It includes topics such as interference, congestion, and channel allocation.

2. **MAC protocol survey:** This topic provides an overview of the various Medium Access Control (MAC) protocols used in IoT networks. It covers protocols such as TDMA, CSMA/CA, and hybrid MAC protocols.

3. **Survey routing protocols:** This topic covers the various routing protocols used in IoT networks. It includes protocols such as AODV, DSR, and OLSR.

4. **Sensor deployment & Node discovery:** This topic covers the process of deploying sensors in an IoT network and discovering the nodes in the network. It includes topics such as node localization, node clustering, and node synchronization.

5. **Data aggregation & dissemination:** This topic covers the process of aggregating and disseminating data in an IoT network. It includes topics such as data fusion, data compression, and data routing.

These are the main topics covered in Unit 3 of the subject "Introduction to Internet of Things". It is important to have a good understanding of these topics to fully grasp the Network & Communication aspects in IoT.
