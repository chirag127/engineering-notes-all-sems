### Architectural view for the notes of the Unit 1 - Internet of Things (IoT)

1. **Vision:** The vision of the Internet of Things (IoT) is to create a world where everyday objects are connected to the internet, allowing them to collect and share data, and interact with each other to improve our lives.

2. **Definition:** The Internet of Things (IoT) is a network of physical objects, or "things," embedded with sensors, software, and other technologies to connect and exchange data with other devices and systems over the internet.

3. **Conceptual Framework:** The conceptual framework of IoT includes the following components: 
    - **Sensors/Actuators:** These are the devices that collect data from the environment or perform actions based on the data received.
    - **Connectivity:** This refers to the communication technologies used to connect the sensors/actuators to the internet.
    - **Data Processing:** This refers to the processing of the data collected by the sensors/actuators to extract useful information.
    - **User Interface:** This refers to the interface through which the user can interact with the IoT system.

4. **Architectural view:** The architectural view of IoT includes the following layers:
    - **Perception Layer:** This layer is responsible for collecting data from the environment using sensors/actuators.
    - **Network Layer:** This layer is responsible for transmitting the data collected by the sensors/actuators to the processing layer.
    - **Processing Layer:** This layer is responsible for processing the data collected by the sensors/actuators to extract useful information.
    - **Application Layer:** This layer is responsible for providing the user with the information extracted by the processing layer.

5. **Technology behind IoT:** The technologies behind IoT include sensors/actuators, communication technologies, data processing technologies, and user interface technologies.

6. **Sources of the IoT:** The sources of the IoT include sensors/actuators, RFID tags, smartphones, and other devices that can collect and transmit data.

7. **M2M Communication:** Machine-to-Machine (M2M) communication refers to the communication between two or more machines without human intervention.

8. **IoT Examples:** Some examples of IoT include smart homes, smart cities, smart grids, and wearable devices.

9. **Design Principles for Connected Devices:** The design principles for connected devices include IoT/M2M systems layers and design standardization, communication technologies, data enrichment and consolidation, ease of designing and affordability.

10. **IoT/M2M systems layers and design standardization:** The IoT/M2M systems layers include the perception layer, network layer, processing layer, and application layer. Design standardization refers to the use of standard protocols and interfaces to ensure interoperability between different IoT devices.

11. **Communication technologies:** The communication technologies used in IoT include cellular, Wi-Fi, Bluetooth, and other wireless technologies.

12. **Data enrichment and consolidation:** Data enrichment refers to the process of adding value to the data collected by the sensors/actuators by combining it with other data sources. Data consolidation refers to the process of combining data from multiple sources into a single, consistent view.

13. **Ease of designing and affordability:** Ease of designing refers to the ease with which IoT devices can be designed and developed. Affordability refers to the cost-effectiveness of IoT devices.
