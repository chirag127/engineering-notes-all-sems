# Unit 3 - Network & Communication aspects in IoT

## Wireless Medium access issues
- Wireless medium access control (MAC) is responsible for coordinating access to the shared wireless medium.
- In IoT networks, wireless medium access can be challenging due to the large number of devices, limited power, and the need for reliable communication.
- Common issues include interference, hidden terminal problems, and the need for efficient power management.

## MAC protocol survey
- There are several MAC protocols that have been proposed for use in IoT networks.
- These include contention-based protocols such as CSMA/CA, and TDMA-based protocols.
- The choice of MAC protocol depends on the specific requirements of the IoT network, such as the need for low power consumption or real-time communication.

## Survey routing protocols
- Routing protocols are responsible for determining the path that data takes through the network.
- In IoT networks, routing protocols must be able to handle the large number of devices and the dynamic nature of the network.
- Common routing protocols used in IoT networks include AODV, DSR, and OLSR.

## Sensor deployment & Node discovery
- Sensor deployment refers to the process of placing sensors in the environment to collect data.
- In IoT networks, sensors must be deployed in a way that ensures good coverage and connectivity.
- Node discovery is the process of identifying and locating the nodes in the network.
- This is important for establishing communication links and routing data through the network.

## Data aggregation & dissemination
- Data aggregation refers to the process of combining data from multiple sensors to reduce the amount of data that needs to be transmitted.
- This is important in IoT networks where bandwidth and power are limited.
- Data dissemination is the process of distributing data to the nodes in the network.
- This can be done using techniques such as flooding or gossiping.
