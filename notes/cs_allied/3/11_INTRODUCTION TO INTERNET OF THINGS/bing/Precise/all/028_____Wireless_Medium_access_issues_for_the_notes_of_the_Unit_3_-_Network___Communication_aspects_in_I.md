# Wireless Medium Access Issues

Wireless medium access issues arise when multiple devices attempt to communicate over a shared wireless channel. These issues can result in collisions, interference, and decreased network performance. To address these issues, various medium access control (MAC) protocols have been developed.

## MAC Protocol Survey

MAC protocols are responsible for coordinating access to the shared wireless channel. Some common MAC protocols include:

- **Carrier Sense Multiple Access with Collision Avoidance (CSMA/CA):** This protocol is used in Wi-Fi networks and involves devices sensing the channel before transmitting to avoid collisions.

- **Time Division Multiple Access (TDMA):** This protocol involves dividing the channel into time slots and assigning each device a specific time slot for transmission.

- **Frequency Division Multiple Access (FDMA):** This protocol involves dividing the channel into multiple frequency bands and assigning each device a specific frequency band for transmission.

## Survey Routing Protocols

Routing protocols are responsible for determining the best path for data to travel from the source to the destination. Some common routing protocols used in wireless networks include:

- **Ad-hoc On-Demand Distance Vector (AODV):** This protocol is used in ad-hoc networks and involves devices discovering routes to the destination on an as-needed basis.

- **Dynamic Source Routing (DSR):** This protocol is also used in ad-hoc networks and involves devices maintaining a cache of routes to the destination.

- **Optimized Link State Routing (OLSR):** This protocol is used in mesh networks and involves devices exchanging link state information to determine the best path to the destination.

## Sensor Deployment and Node Discovery

In wireless sensor networks, the deployment of sensors and the discovery of nodes are important issues. Sensors can be deployed randomly or in a planned manner, depending on the application. Node discovery involves the process of discovering and identifying the nodes in the network.

## Data Aggregation and Dissemination

Data aggregation involves the process of combining data from multiple sensors to reduce the amount of data that needs to be transmitted. Data dissemination involves the process of distributing data to the appropriate nodes in the network. These processes are important for reducing network congestion and improving network performance.
