# Network & Communication aspects in IoT

Unit 3 of the subject "Introduction to Internet of Things" covers the following topics:

1. **Wireless Medium access issues:** This topic covers the challenges and solutions for accessing the wireless medium in IoT networks. This includes issues such as interference, congestion, and power consumption.

2. **MAC protocol survey:** This topic provides an overview of the various Medium Access Control (MAC) protocols used in IoT networks. These protocols are responsible for controlling access to the wireless medium and ensuring efficient and reliable communication.

3. **Survey routing protocols:** This topic covers the various routing protocols used in IoT networks. These protocols are responsible for finding and maintaining routes between nodes in the network.

4. **Sensor deployment & Node discovery:** This topic covers the process of deploying sensors and discovering nodes in an IoT network. This includes issues such as node placement, network topology, and node discovery protocols.

5. **Data aggregation & dissemination:** This topic covers the process of aggregating and disseminating data in an IoT network. This includes issues such as data compression, data fusion, and data dissemination protocols.

These topics provide a comprehensive overview of the network and communication aspects of IoT and are essential for understanding the functioning of IoT networks.
