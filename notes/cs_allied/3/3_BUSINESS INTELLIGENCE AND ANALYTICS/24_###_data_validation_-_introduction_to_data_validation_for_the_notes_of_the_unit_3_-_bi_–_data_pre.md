### Data Validation - Introduction to Data Validation for the notes of the Unit 3 - BI – DATA PREPARTTION in the subject of BUSINESS INTELLIGENCE AND ANALYTICS KCS

Data Validation is the process of ensuring that data entered into a database or spreadsheet is accurate, consistent, and complete. It helps to prevent errors and ensure that data is entered in a consistent format. 

There are several methods for data validation, including:
- Range Validation: Restricts data to a specific range of values (e.g. only allow numbers between 1 and 100). 
- List Validation: Restricts data to specific list of items (e.g. only allow "yes" or "no" values). 
- Formula Validation: Uses a formula to validate data (e.g. check if a date is in the correct format). 
- Text Length Validation: Restricts the length of text entered into a field (e.g. only allow 10 characters). 
- Data Type Validation: Restricts data to a specific data type (e.g. only allow numbers). 

Data validation is important in Business Intelligence and Analytics because it helps to ensure the quality of data used for analysis. Poor quality data can lead to incorrect conclusions and decisions. By implementing data validation, organizations can increase the accuracy and reliability of their data.
