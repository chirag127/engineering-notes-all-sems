### Architecture of Data Mining and How Data mining works(Process) for the notes of the Unit 2 - BI – DATA MINING & WAREHOUSING in the subject of BUSINESS INTELLIGENCE AND ANALYTICS KCS

Data Mining is the process of discovering patterns and relationships in large datasets. It is a key component of Business Intelligence (BI) and is used to extract valuable insights from data to support decision-making.

The architecture of data mining typically consists of several stages, including data preparation, data exploration, pattern discovery, and pattern evaluation.

1. Data Preparation: This stage involves cleaning and transforming the data to make it suitable for analysis. This includes removing missing values, handling outliers, and converting data into a format that can be easily analyzed.

2. Data Exploration: This stage involves exploring the data to gain a better understanding of its structure and characteristics. This includes generating descriptive statistics, creating visualizations, and identifying correlations between variables.

3. Pattern Discovery: This stage involves applying algorithms to discover patterns and relationships within the data. This includes association rule mining, clustering, classification, and regression analysis.

4. Pattern Evaluation: This stage involves evaluating the discovered patterns to determine their significance and usefulness. This includes using statistical tests, such as hypothesis testing, to determine if the patterns are statistically significant.

The process of data mining works by using algorithms to analyze large datasets and identify patterns and relationships within the data. The algorithms used in data mining can be supervised or unsupervised. Supervised algorithms are used when the target variable is known, and the goal is to predict its value based on the values of other variables. Unsupervised algorithms are used when the target variable is not known, and the goal is to identify patterns and relationships within the data.

Once the patterns and relationships have been identified, they can be used to make predictions, classify data, and generate insights that can be used to support decision-making.

In summary, the architecture of data mining consists of several stages, including data preparation, data exploration, pattern discovery, and pattern evaluation. The process of data mining works by using algorithms to analyze large datasets and identify patterns and relationships within the data.
