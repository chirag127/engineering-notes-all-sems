## Unit 3 - BI – DATA PREPARTTION

Data preparation is the process of transforming raw data into a form that is suitable for analysis and reporting. Data preparation involves various steps, such as:

- Data collection: This is the process of acquiring data from different sources, such as databases, files, web services, sensors, etc. Data collection can be done manually or automatically, depending on the availability and accessibility of the data sources.
- Data integration: This is the process of combining data from different sources into a single, consistent, and coherent data set. Data integration can involve various techniques, such as data extraction, data transformation, data cleansing, data deduplication, data reconciliation, etc. Data integration can be done at different levels, such as schema level, instance level, or semantic level.
- Data quality: This is the process of ensuring that the data is accurate, complete, consistent, relevant, and timely. Data quality can involve various techniques, such as data validation, data verification, data correction, data enrichment, data standardization, data profiling, etc. Data quality can be measured by various metrics, such as accuracy, completeness, consistency, timeliness, etc.
- Data transformation: This is the process of modifying the data to fit the requirements of the analysis and reporting. Data transformation can involve various techniques, such as data aggregation, data filtering, data sorting, data grouping, data pivoting, data summarization, data calculation, data formatting, etc. Data transformation can be done at different levels, such as record level, field level, or table level.
- Data visualization: This is the process of presenting the data in a graphical or pictorial form that is easy to understand and interpret. Data visualization can involve various techniques, such as data charts, data graphs, data maps, data dashboards, data tables, data reports, etc. Data visualization can be done at different levels, such as descriptive, exploratory, explanatory, or predictive.
