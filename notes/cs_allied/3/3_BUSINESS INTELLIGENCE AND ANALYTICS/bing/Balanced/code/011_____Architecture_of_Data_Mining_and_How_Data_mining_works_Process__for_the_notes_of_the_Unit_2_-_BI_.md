# Architecture of Data Mining

- Data mining is the process of discovering meaningful new correlations, patterns, and trends by shifting through large amounts of data stored in repositories, using pattern recognition technologies as well as statistical and mathematical techniques.
- The data mining process involves several components, and these components constitute a data mining system architecture.
- The significant components of data mining systems are  :
  - A data source, which provides the raw data to be mined. The data source can be a database, a data warehouse, a flat file, or any other data storage system.
  - A data mining engine, which performs the core data mining tasks such as association, classification, clustering, prediction, and sequential pattern analysis. The data mining engine can use various algorithms and techniques to discover patterns and knowledge from the data.
  - A data warehouse server, which integrates the data from multiple heterogeneous data sources and provides a unified view of the data to the data mining engine. The data warehouse server can also perform data cleaning, transformation, integration, and pre-processing operations to prepare the data for mining.
  - A pattern evaluation module, which evaluates the patterns and knowledge discovered by the data mining engine and ranks them according to some interestingness measures. The pattern evaluation module can also filter out the irrelevant or redundant patterns and present only the most useful ones to the user.
  - A graphical user interface, which allows the user to interact with the data mining system and specify the data mining tasks and parameters. The graphical user interface can also display the results of data mining in a visual and intuitive way, such as graphs, charts, tables, or trees.
  - A knowledge base, which stores the domain knowledge and user preferences that can be used to guide the data mining process and improve the quality and efficiency of data mining. The knowledge base can also store the metadata and the results of previous data mining sessions for future reference.

# How Data Mining Works

- Data mining usually consists of four main steps: setting objectives, data gathering and preparation, applying data mining algorithms, and evaluating results.
- The first step is to set the business objectives, which define the problem to be solved and the goals to be achieved by data mining. This can be the hardest part of the data mining process, and many organizations spend too little time on this important step. The business objectives should be clear, measurable, and realistic, and they should align with the overall business strategy and vision.
- The second step is to gather and prepare the data, which involves selecting the relevant data sources, extracting the data, and transforming and cleaning the data to make it suitable for mining. This can be the most time-consuming and challenging part of the data mining process, as the data quality and completeness can affect the accuracy and validity of the data mining results. The data preparation step can also include data integration, data reduction, data discretization, and data normalization operations.
- The third step is to apply data mining algorithms, which perform the core data mining tasks on the prepared data and discover patterns and knowledge. The choice of data mining algorithms depends on the type and complexity of the data, the business objectives, and the available computational resources. Some of the common data mining tasks are:
  - Association, which finds the co-occurrence or correlation of items or events in a dataset. For example, finding the products that are frequently bought together by customers in a supermarket.
  - Classification, which assigns a label or category to an item or event based on its attributes or features. For example, predicting the credit risk of a loan applicant based on their income, age, and credit history.
  - Clustering, which groups items or events that are similar or related to each other based on some distance or similarity measure. For example, segmenting customers based on their demographics, preferences, and behavior.
  - Prediction, which forecasts the value or outcome of an item or event based on its historical or current data. For example, estimating the sales of a product in the next quarter based on the past sales and market trends.
  - Sequential pattern analysis, which finds the ordered or temporal relationships among items or events in a dataset. For example, finding the common sequences of web pages visited by users in a website.
