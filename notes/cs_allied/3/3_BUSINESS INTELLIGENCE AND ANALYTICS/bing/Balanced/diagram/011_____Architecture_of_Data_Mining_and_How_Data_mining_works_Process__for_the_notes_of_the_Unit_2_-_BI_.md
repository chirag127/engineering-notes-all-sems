### Architecture of Data Mining

- Data mining is the process of discovering meaningful new correlations, patterns, and trends by shifting through large amounts of data stored in repositories, using pattern recognition technologies as well as statistical and mathematical techniques.
- The data mining process involves several components, and these components constitute a data mining system architecture.
- The significant components of data mining systems are :
  - A data source, which provides the raw data to be mined. The data source can be a database, a data warehouse, a flat file, or any other data storage system.
  - A data mining engine, which performs the core data mining tasks such as association, classification, clustering, prediction, and sequential pattern analysis. The data mining engine can use various algorithms and techniques to discover patterns and knowledge from the data.
  - A data warehouse server, which integrates the data from multiple heterogeneous data sources and provides a unified view of the data to the data mining engine. The data warehouse server can also perform data cleaning, transformation, integration, and pre-processing operations to prepare the data for mining.
  - A pattern evaluation module, which evaluates the patterns and knowledge discovered by the data mining engine and ranks them according to some interestingness measures. The pattern evaluation module can also filter out the irrelevant or redundant patterns and present only the most useful ones to the user.
  - A graphical user interface, which allows the user to interact with the data mining system and specify the data mining tasks and parameters. The graphical user interface can also display the results of data mining in a visual and intuitive way, such as graphs, charts, tables, or trees.
  - A knowledge base, which stores the domain knowledge and the user preferences that can be used to guide the data mining process and improve the quality and efficiency of data mining. The knowledge base can also store the metadata and the data mining models generated by the data mining system.

### How Data Mining Works

- Data mining usually consists of four main steps:
  - Setting objectives, which involves defining the business problem and the goals of data mining. This can be the hardest part of the data mining process, and many organizations spend too little time on this important step.
  - Data gathering and preparation, which involves collecting the data from the data sources and performing data cleaning, transformation, integration, and pre-processing operations to make the data suitable for mining. This can be the most time-consuming and labor-intensive part of the data mining process, and many organizations spend too much time on this step.
  - Applying data mining algorithms, which involves selecting and applying the appropriate data mining techniques and methods to discover patterns and knowledge from the data. This can be the most technical and complex part of the data mining process, and many organizations rely on data mining experts or tools to perform this step.
  - Evaluating results, which involves assessing the quality and usefulness of the patterns and knowledge discovered by data mining and applying them to the business problem and the goals. This can be the most critical and challenging part of the data mining process, and many organizations struggle to measure the impact and value of data mining.
