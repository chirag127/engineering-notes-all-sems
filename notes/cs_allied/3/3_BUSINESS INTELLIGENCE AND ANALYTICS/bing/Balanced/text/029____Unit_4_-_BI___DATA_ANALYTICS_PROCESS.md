## Unit 4 - BI – DATA ANALYTICS PROCESS

Business intelligence (BI) is the process of transforming data into insights that help businesses make better decisions. BI involves the following steps:

- Data collection: This is the process of gathering data from various sources, such as internal systems, external databases, web pages, social media, sensors, etc. Data collection can be done manually or automatically, depending on the type and volume of data.
- Data preparation: This is the process of organizing and modeling the data for analysis. Data preparation can include cleaning, filtering, merging, transforming, aggregating, and validating the data. Data preparation can be done using tools such as Excel, SQL, Python, or specialized software.
- Data analysis: This is the process of applying queries, algorithms, statistics, and machine learning to the prepared data to uncover patterns, trends, correlations, and insights. Data analysis can be done using tools such as Power BI, Tableau, R, or SAS.
- Data visualization: This is the process of creating charts, graphs, dashboards, and reports to present the results of data analysis in a clear and engaging way. Data visualization can help users understand the data, identify key findings, and communicate them to others. Data visualization can be done using tools such as Power BI, Tableau, Excel, or Google Data Studio.
- Data-driven decision making: This is the process of using the information from data analysis and visualization to support and improve business decisions. Data-driven decision making can help businesses optimize their performance, identify opportunities, solve problems, and achieve their goals. Data-driven decision making can be done by business users, managers, or executives, depending on the level and scope of the decision.
