# Types of Analytical Techniques in BI – Descriptive

Descriptive analytics is one of the main types of analytical techniques used in Business Intelligence (BI). It is used to summarize and describe historical data to identify patterns, relationships, and trends. Descriptive analytics is the foundation of all other types of analytics and is commonly used in reporting and data visualization.

Some common techniques used in descriptive analytics include:

1. **Data Aggregation:** This technique involves combining data from multiple sources to create a summary view of the data. This can help identify trends and patterns in the data.

2. **Data Mining:** This technique involves using algorithms to identify patterns and relationships in large datasets. Data mining can help uncover hidden insights in the data.

3. **Data Visualization:** This technique involves using graphical representations of data to help users understand and explore the data. Common data visualization techniques include charts, graphs, and maps.

4. **Statistical Analysis:** This technique involves using statistical methods to analyze and summarize data. Common statistical methods include mean, median, mode, standard deviation, and correlation.

Descriptive analytics is an important part of the BI data analytics process and provides valuable insights into historical data. It is commonly used in business to support decision-making and improve performance.
