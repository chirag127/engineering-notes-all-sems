## Unit 3 - BI – DATA PREPARTTION

Data preparation is a critical step in the business intelligence (BI) process. It involves cleaning, transforming, and organizing data so that it can be analyzed and used to make informed decisions.

1. **Data Cleaning:** This involves identifying and correcting errors and inconsistencies in the data. This can include removing duplicate records, filling in missing values, and correcting data entry errors.

2. **Data Transformation:** This involves converting data from one format to another, or changing the way the data is represented. This can include normalizing data, aggregating data, and creating calculated fields.

3. **Data Integration:** This involves combining data from multiple sources into a single, unified view. This can include merging data from different databases, or combining data from different file formats.

4. **Data Reduction:** This involves reducing the amount of data that needs to be analyzed, while still maintaining the accuracy and usefulness of the data. This can include sampling data, or using dimensionality reduction techniques.

Overall, data preparation is an essential step in the BI process, as it ensures that the data being analyzed is accurate, consistent, and relevant. By properly preparing data, organizations can make better decisions and gain valuable insights from their data.
