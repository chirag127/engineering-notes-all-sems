### Functionalities & Classifications of Data Mining

Data mining is the process of discovering patterns and knowledge from large amounts of data. The data sources can include databases, data warehouses, the internet, and other sources.

The main functionalities of data mining are:

1. **Association rule learning:** This is a method for discovering interesting relations between variables in large databases. It is intended to identify strong rules discovered in databases using some measures of interestingness.

2. **Clustering:** This is the task of discovering groups and structures in the data that are in some way or another "similar", without using known structures in the data.

3. **Classification:** This is the task of generalizing known structure to apply to new data. For example, an email program might attempt to classify an email as "legitimate" or as "spam".

4. **Regression:** This is the task of mapping a data item to a real-valued prediction variable.

5. **Summarization:** This provides a more compact representation of the data set, including visualization and report generation.

Data mining can be classified into two categories: descriptive data mining and predictive data mining.

- **Descriptive data mining** is concerned with finding patterns describing the data and is commonly used for exploring the properties of the data at hand.

- **Predictive data mining** is concerned with finding a model for the data that can be used to predict future outcomes.
