## Unit 2 - BI – DATA MINING & WAREHOUSING

1. **Data Mining** is the process of discovering patterns and knowledge from large amounts of data. The data sources can include databases, data warehouses, the internet, and other sources.
2. The main goal of data mining is to extract information from data and transform it into an understandable structure for further use.
3. There are several key data mining techniques including association, classification, clustering, prediction, and sequential patterns.
4. **Data Warehousing** is the process of collecting, storing, and managing large amounts of data in a central repository.
5. The main goal of data warehousing is to provide a consistent and reliable source of data for analysis and reporting.
6. Data warehousing involves the integration of data from multiple sources, data cleaning and transformation, and the creation of a multidimensional data model.
7. Data mining and data warehousing are closely related, as data mining can be applied to the data stored in a data warehouse to extract useful information and patterns.
8. Both data mining and data warehousing are important components of Business Intelligence, which is the process of using data to make informed business decisions.
