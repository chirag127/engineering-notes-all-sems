## Unit 3 - BI – DATA PREPARTTION

Data preparation is the process of transforming raw data into a format that is suitable for analysis and reporting. Data preparation involves various steps, such as:

- Data collection: This is the process of acquiring data from different sources, such as databases, files, web services, sensors, etc. Data collection can be done manually or automatically, depending on the availability and accessibility of the data sources.
- Data integration: This is the process of combining data from different sources into a single, consistent, and coherent data set. Data integration can involve various techniques, such as data extraction, data transformation, data cleansing, data deduplication, data validation, data enrichment, etc.
- Data exploration: This is the process of examining and understanding the data set, such as its structure, content, quality, distribution, patterns, relationships, etc. Data exploration can involve various techniques, such as data profiling, data visualization, data summarization, data mining, etc.
- Data modeling: This is the process of defining and creating a logical representation of the data set, such as its schema, dimensions, measures, hierarchies, attributes, etc. Data modeling can involve various techniques, such as data normalization, data denormalization, data aggregation, data disaggregation, data partitioning, etc.
- Data transformation: This is the process of modifying and enhancing the data set, such as its format, values, types, units, etc. Data transformation can involve various techniques, such as data conversion, data standardization, data normalization, data scaling, data encoding, data interpolation, data imputation, data derivation, data augmentation, etc.
- Data quality: This is the process of ensuring and improving the accuracy, completeness, consistency, timeliness, validity, and reliability of the data set. Data quality can involve various techniques, such as data verification, data correction, data filtering, data matching, data auditing, data monitoring, data governance, etc.
- Data storage: This is the process of saving and organizing the data set in a persistent and accessible location, such as a database, a data warehouse, a data lake, a data mart, a data cube, etc. Data storage can involve various techniques, such as data compression, data encryption, data indexing, data partitioning, data replication, data backup, data security, data privacy, etc.

Data preparation is an essential and iterative step in any business intelligence (BI) project, as it affects the quality and usability of the data for analysis and reporting. Data preparation can be done using various tools, such as data preparation software, data integration software, data quality software, data visualization software, data modeling software, etc. Data preparation can also be done using various languages, such as SQL, Python, R, etc. Data preparation can be done by various roles, such as data engineers, data analysts, data scientists, etc. Data preparation can be done for various purposes, such as descriptive analytics, diagnostic analytics, predictive analytics, prescriptive analytics, etc. Data preparation can be done at various levels, such as individual, team, department, organization, etc. Data preparation can be done in various environments, such as on-premise, cloud, hybrid, etc. Data preparation can be done in various scenarios, such as batch, real-time, streaming, etc. Data preparation can be done in various domains, such as finance, marketing, sales, operations, human resources, etc. Data preparation can be done in various industries, such as retail, banking, healthcare, education, manufacturing, etc. Data preparation can be done in various contexts, such as business, social, environmental, etc.
