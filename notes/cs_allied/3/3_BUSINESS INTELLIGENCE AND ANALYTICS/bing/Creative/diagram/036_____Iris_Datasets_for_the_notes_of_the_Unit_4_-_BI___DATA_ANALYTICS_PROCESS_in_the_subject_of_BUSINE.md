### Iris Dataset

- The Iris dataset is a multivariate dataset that contains measurements on four different attributes (in centimeters) for 50 flowers from three different species of iris: setosa, versicolor, and virginica  .
- The four attributes are: sepal length, sepal width, petal length, and petal width  .
- The dataset was introduced by the British statistician and biologist Ronald Fisher in his 1936 paper "The use of multiple measurements in taxonomic problems" as an example of linear discriminant analysis .
- The dataset is widely used as a beginner's dataset for machine learning purposes, as it is easy to access, visualize, and analyze .
- The dataset is included in R base and Python in the machine learning library scikit-learn, so that users can access it without having to find a source for it .
- The dataset can be used to perform various tasks, such as classification, clustering, regression, dimensionality reduction, and visualization  .
- The dataset can be loaded in R using the command `data(iris)` and in Python using the command `from sklearn.datasets import load_iris; iris = load_iris()`.
- The dataset can be summarized in R using the command `summary(iris)` and in Python using the command `iris.DESCR`.
- The dataset can be visualized in R using the command `plot(iris)` and in Python using the command `import matplotlib.pyplot as plt; plt.scatter(iris.data[:,0], iris.data[:,1], c=iris.target); plt.xlabel('sepal length'); plt.ylabel('sepal width'); plt.show()`.
- The dataset can be split into training and testing sets in R using the command `set.seed(123); train_index = sample(1:nrow(iris), 0.8*nrow(iris)); train = iris[train_index,]; test = iris[-train_index,]` and in Python using the command `from sklearn.model_selection import train_test_split; X_train, X_test, y_train, y_test = train_test_split(iris.data, iris.target, test_size=0.2, random_state=123)`.
- The dataset can be used to train and evaluate a simple linear classifier in R using the command `library(e1071); model = svm(Species ~ ., data = train, kernel = 'linear'); pred = predict(model, test); table(pred, test$Species); accuracy = mean(pred == test$Species)` and in Python using the command `from sklearn.linear_model import LogisticRegression; model = LogisticRegression(); model.fit(X_train, y_train); pred = model.predict(X_test); from sklearn.metrics import confusion_matrix, accuracy_score; confusion_matrix(y_test, pred); accuracy_score(y_test, pred)`.
