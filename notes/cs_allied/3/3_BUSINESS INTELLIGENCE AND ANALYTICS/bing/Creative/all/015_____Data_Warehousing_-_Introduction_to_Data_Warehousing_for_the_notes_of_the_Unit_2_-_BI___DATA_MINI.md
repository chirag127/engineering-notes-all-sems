# Data Warehousing - Introduction to Data Warehousing

- A data warehouse is a database designed to enable and support business intelligence (BI) activities, especially analytics .
- A data warehouse aggregates data from different sources into a single, central, consistent data store to support data analysis, data mining, artificial intelligence (AI), and machine learning.
- A data warehouse is solely intended to perform queries and analysis and often contains large amounts of historical data.
- A data warehouse helps users understand and enhance their organization's performance by providing them with relevant, accurate, and timely information.
- A data warehouse differs from a traditional operational database in several ways, such as:
  - A data warehouse is subject-oriented, meaning it organizes data around the key entities or concepts of the business, such as customers, products, sales, etc.
  - A data warehouse is integrated, meaning it combines data from various sources and formats into a unified and consistent schema.
  - A data warehouse is non-volatile, meaning it preserves the data once it is loaded and does not allow modifications or deletions.
  - A data warehouse is time-variant, meaning it keeps track of the changes and trends in the data over time, using timestamps, snapshots, or versions.
- A data warehouse typically consists of several components, such as:
  - A data source, which is the original system or application that generates or collects the data.
  - A data extraction, transformation, and loading (ETL) process, which is the mechanism that extracts, cleans, transforms, and loads the data from the data source to the data warehouse.
  - A data storage, which is the physical location and structure of the data warehouse, such as a relational database, a multidimensional database, or a cloud-based service.
  - A data access, which is the interface or tool that allows users to query and analyze the data in the data warehouse, such as a reporting tool, a dashboard, a data mining tool, or a BI application.
