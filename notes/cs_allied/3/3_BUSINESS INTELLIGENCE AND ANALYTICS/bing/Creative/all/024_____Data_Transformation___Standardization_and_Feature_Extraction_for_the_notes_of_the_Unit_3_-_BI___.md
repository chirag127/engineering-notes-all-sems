# Data Transformation – Standardization and Feature Extraction

## Data Transformation
- Data transformation is the process of modifying the data to make it more suitable for analysis or modeling.
- Data transformation can involve various operations, such as cleaning, filtering, aggregating, scaling, encoding, imputing, etc.
- Data transformation can improve the quality, consistency, and usability of the data, as well as reduce the dimensionality and complexity of the data.

## Standardization
- Standardization is a type of data transformation that rescales the data to have a mean of zero and a standard deviation of one.
- Standardization can help to eliminate the effect of different units, scales, and ranges of the data, and make the data more comparable and compatible.
- Standardization can also help to reduce the influence of outliers and improve the performance of some algorithms that assume normality or equal variance of the data.
- Standardization can be applied to numerical variables, such as height, weight, income, etc.
- Standardization can be done by subtracting the mean and dividing by the standard deviation of each variable.

## Feature Extraction
- Feature extraction is a type of data transformation that creates new features from the existing data, or reduces the number of features by combining or selecting the most relevant ones.
- Feature extraction can help to capture the underlying patterns, structures, or relationships in the data, and enhance the information content and interpretability of the data.
- Feature extraction can also help to reduce the dimensionality and redundancy of the data, and improve the efficiency and accuracy of some algorithms that suffer from the curse of dimensionality or multicollinearity.
- Feature extraction can be applied to various types of data, such as text, image, audio, video, etc.
- Feature extraction can be done by using various techniques, such as principal component analysis, linear discriminant analysis, singular value decomposition, latent semantic analysis, etc.
