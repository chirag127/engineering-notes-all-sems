# Selection

- Selection is the process of choosing a subset of data from a larger data set based on some criteria.
- Selection can be done for different purposes, such as reducing the size of the data, focusing on the relevant data, removing the irrelevant or redundant data, or improving the quality of the data.
- Selection can be applied to different levels of the data, such as rows, columns, cells, or values.
- Selection can be done manually or automatically, depending on the complexity and volume of the data, and the availability of the criteria.
- Selection can be done using different methods, such as filtering, sampling, aggregation, or dimensionality reduction.

## Filtering

- Filtering is the method of selecting a subset of data that satisfies one or more conditions or rules.
- Filtering can be done on rows or columns of the data, depending on the type of the condition or rule.
- Filtering can be done using different operators, such as equal, not equal, greater than, less than, between, in, not in, etc.
- Filtering can be done using different types of conditions or rules, such as logical, arithmetic, string, date, or spatial.
- Filtering can be done using different tools, such as SQL, Excel, Python, R, or BI tools.

- Sampling can be done using different techniques, such as random, systematic, stratified, cluster, or convenience.
- Sampling can be done using different tools, such as SQL, Excel, Python, R, or BI tools.

## Aggregation

- Aggregation can be done using different functions, such as sum, count, average, minimum, maximum, median, mode, standard deviation, variance, etc.
- Aggregation can be done using different tools, such as SQL, Excel, Python, R, or BI tools.
