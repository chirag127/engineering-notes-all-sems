### Selection for the notes of the Unit 3 - BI – DATA PREPARTTION in the subject of BUSINESS INTELLIGENCE AND ANALYTICS KCS

When it comes to Business Intelligence and Analytics, data preparation plays a crucial role in ensuring that the data is ready for analysis. In this unit, you will learn about the different methods and techniques used for preparing data for analysis. Some of the key topics covered in this unit include:

- Data Cleansing: This involves removing any inconsistencies, errors, or inaccuracies from the data. This is important because inaccurate data can lead to incorrect analysis and decision making. Some of the techniques used for data cleansing include filtering, sorting, and removing duplicates.

- Data Integration: This involves combining data from different sources into a single dataset. This is important because it allows for a more comprehensive analysis of the data. Some of the techniques used for data integration include merging, joining, and appending.

- Data Transformation: This involves converting the data into a format that is suitable for analysis. This is important because different analysis techniques require different data formats. Some of the techniques used for data transformation include data normalization, data aggregation, and data pivoting.

- Data Reduction: This involves reducing the amount of data that needs to be analyzed. This is important because analyzing large datasets can be time-consuming and resource-intensive. Some of the techniques used for data reduction include data sampling, data summarization, and data clustering.

By the end of this unit, you will have a solid understanding of the different methods and techniques used for preparing data for analysis. This knowledge will be invaluable in your future career as a business intelligence and analytics professional.
