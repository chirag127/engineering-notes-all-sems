## Unit 3 - BI – DATA PREPARTTION

In this unit, we will cover the following topics related to BI and data preparation:

- Data sources: Understand the different data sources that can be used for BI and how to choose the right source for your needs. This includes internal and external data sources, structured and unstructured data, and real-time data sources.

- Data integration: Learn how to integrate data from multiple sources and transform it into a format that can be used for analysis. This includes data cleansing, data profiling, and data enrichment.

- Data modeling: Understand the basics of data modeling and how to design a data model that supports your BI needs. This includes understanding data warehousing concepts, designing a star schema, and creating data cubes.

- Data visualization: Learn how to present data in a way that is easy to understand and meaningful to your audience. This includes choosing the right visualization tool, creating effective charts and graphs, and designing dashboards.

- Data governance: Understand the importance of data governance and how to establish policies and procedures to ensure data quality, security, and compliance. This includes identifying data ownership, establishing data standards, and implementing data security measures.

By the end of this unit, you should have a solid understanding of the fundamentals of BI and data preparation. You should be able to identify the different types of data sources, integrate data from multiple sources, design a data model, create effective visualizations, and establish data governance policies and procedures. This knowledge will be essential for anyone who wants to work in the field of BI and data analytics.
