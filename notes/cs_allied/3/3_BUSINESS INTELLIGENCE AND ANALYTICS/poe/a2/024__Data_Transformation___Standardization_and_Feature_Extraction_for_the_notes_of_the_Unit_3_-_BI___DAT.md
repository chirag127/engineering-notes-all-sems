### Data Transformation – Standardization and Feature Extraction

1. Data Standardization
- Bringing the data to a common scale, typically between 0 and 1.
- Helps in handling the outliers and skewed data.
- Makes the learning algorithm work efficiently and gives better results.
- Min-Max Scaling: Subtracting the min value from each value and then dividing the result by the range (max – min).
- Z-score Normalization: Subtracting the mean and dividing by the standard deviation. Centers the data around 0 with unit variance.

2. Feature Extraction
- Creating new features from the existing raw features to make the learning process efficient.
- Some of the ways are:
-- Binning: Dividing the range of a feature into intervals to convert to categories.
-- Polynomial decomposition: Converting to polynomial features.
-- PCA: Using Principal Component Analysis to find the major axes of variations in the data.
