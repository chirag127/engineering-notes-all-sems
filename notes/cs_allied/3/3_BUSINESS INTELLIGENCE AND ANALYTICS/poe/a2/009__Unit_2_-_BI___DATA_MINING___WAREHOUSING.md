## Unit 2 - BI – DATA MINING & WAREHOUSING

1. Data Warehousing
- A data warehouse is a central repository of integrated data from one or more sources.
- Data warehouses store current and historical data and are used for creating analytical reports for users throughout the enterprise.
- Data warehouses contain corporate data that has been cleaned and formatted for analysis.
- A data warehouse provides a unified view and consolidated picture of the organization's data typically over a long time period.

2. Data Mining
- Data mining is the process of discovering patterns in large data sets in order to extract useful information and insights.
- Data mining uses machine learning, statistical analysis, AI techniques to detect and extract patterns in data without being explicitly programmed where to look.
- Data mining is used in applications ranging from marketing to fraud detection and scientific discovery.
- The key steps in data mining are:
1. Data Cleaning - Remove noise and inconsistent data
2. Data Integration - Combine multiple data sources
3. Data Selection - Select relevant data
4. Data Transformation - Transform data for mining
5. Data Mining - Apply mining algorithms
6. Pattern Evaluation - Evaluate mined patterns
7. Knowledge Presentation - Present knowledge to users

3. Difference between Data Warehousing and Data Mining
- Data warehousing focuses on data storage whereas data mining focuses on data analysis.
- Data warehousing retrieves and presents data whereas data mining extracts hidden patterns and relationships from data.
- Data warehousing is a prerequisite for data mining. The data mining process uses data from a data warehouse.
- Data warehousing organizes data whereas data mining discovers insights and relationships in the data.
