### Data Validation - Introduction to Data Validation

- Data validation is the process of checking data for accuracy, completeness, consistency, reasonableness, and validity.
- It is done to ensure high quality data which leads to accurate and reliable analysis and reports.
- Data validation checks for things like:
-- Missing values
-- Out of range values
-- Duplicate values
-- Invalid values (eg. alphabet in numeric field)
-- Inconsistencies across related data
-- Reasonable values (eg. salary cannot be negative)
- Some methods for data validation are:
-- Constraints and data types in database
-- Custom functions and scripts
-- Statistical techniques
-- Visualization and spot-checking
- Data validation is important as:
-- Garbage in, garbage out - inaccurate input will lead to inaccurate outputs and insights
-- It improves data reliability and trust in reports/analysis
-- It helps identifying data issues early and fixing them to maintain high quality data
- That's all for the introduction to data validation. In subsequent units, we will explore various data validation techniques in detail.
