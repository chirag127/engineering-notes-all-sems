### Types of Analytical Techniques in BI – Descriptive

Business Intelligence (BI) is a process of extracting useful insights from data to make informed decisions. Descriptive analytics is a type of analytical technique that deals with understanding past events and explaining why they occurred. Here are some common descriptive analytical techniques used in BI:

1. Reporting: Reporting is a technique used to present data in a summarized form. It involves creating dashboards, scorecards, and other visualizations to provide an overview of data. Reporting is useful for identifying trends, patterns, and anomalies in data.

2. Data Mining: Data mining is the process of discovering patterns in large datasets. It involves using statistical and machine learning algorithms to identify relationships between variables. Data mining can help businesses to identify customer behavior, market trends, and other insights.

3. Drill-Down: Drill-down is a technique used to explore data in detail. It involves starting with a high-level overview and then drilling down into specific data points to get more detailed insights. Drill-down is useful for identifying the root cause of a problem or for exploring specific trends in data.

4. OLAP (Online Analytical Processing): OLAP is a technique used to analyze large datasets. It involves aggregating data into cubes and then slicing and dicing the data to gain insights. OLAP is useful for analyzing multidimensional data and for identifying trends across different dimensions.

5. Data Warehousing: Data warehousing is the process of storing and managing data from multiple sources in a centralized location. It involves creating a data warehouse, which is a large database that can be used for analysis. Data warehousing is useful for integrating data from different sources and for providing a single source of truth for analysis.

6. Data Visualization: Data visualization is a technique used to present data in a visual format. It involves creating charts, graphs, and other visualizations to help users understand data. Data visualization is useful for identifying patterns and trends in data and for communicating insights to stakeholders.

In conclusion, descriptive analytical techniques play a vital role in BI. By using these techniques, businesses can gain valuable insights from data and make informed decisions. Understanding the various techniques available can help businesses to choose the best approach for their specific needs.
