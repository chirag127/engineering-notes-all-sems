## Unit 4 - BI – DATA ANALYTICS PROCESS

In this unit, we will learn about the BI - Data Analytics Process, which is a framework for analyzing data and deriving insights from it. The process involves several stages, which are as follows:

1. **Data Extraction**: The first step in the data analytics process is to extract data from various sources such as databases, spreadsheets, and other data repositories. This data could be structured or unstructured, and it could be in different formats such as CSV, Excel, or JSON.

2. **Data Cleaning**: Once the data is extracted, it needs to be cleaned and preprocessed to ensure its quality and consistency. This involves removing duplicates, correcting errors, and handling missing values.

3. **Data Transformation**: In this stage, the data is transformed into a format suitable for analysis. This could involve aggregating data, creating new variables, and encoding categorical variables.

4. **Data Analysis**: This is the core stage of the data analytics process, where various statistical techniques are used to analyze the data and derive insights from it. This could involve exploratory data analysis, hypothesis testing, and regression analysis.

5. **Data Visualization**: Once the analysis is done, the insights need to be communicated effectively to the stakeholders. Data visualization techniques such as charts, graphs, and dashboards are used to present the insights in an easy-to-understand manner.

6. **Decision Making**: The final stage of the data analytics process is to use the insights derived from the analysis to make informed decisions. This could involve making changes to the business strategy, optimizing operations, or improving customer experience.

In summary, the BI - Data Analytics Process is a framework for analyzing data and deriving insights from it. It involves several stages, including data extraction, data cleaning, data transformation, data analysis, data visualization, and decision making. By following this process, organizations can make data-driven decisions and improve their overall performance.
