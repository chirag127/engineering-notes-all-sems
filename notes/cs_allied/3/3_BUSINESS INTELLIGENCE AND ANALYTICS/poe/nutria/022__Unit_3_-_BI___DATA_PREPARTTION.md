
## Unit 3 - BI – DATA PREPARTTION

1. Data Preparation is the process of collecting, cleaning, and transforming data for analysis. It involves selecting relevant data, removing outliers, and transforming the data into a format that is suitable for analysis.

2. Data cleaning involves identifying and correcting errors, inconsistencies, and missing values in the data. Common techniques used in data cleaning include replacing missing values, removing outliers, and normalizing data.

3. Data transformation involves converting data from one format to another. Common techniques used in data transformation include aggregation, normalization, and encoding.

4. Data integration involves combining data from multiple sources. Common techniques used in data integration include data federation, data replication, and data warehousing.

5. Data visualization is the process of presenting data in a graphical format. Common techniques used in data visualization include bar charts, line graphs, and scatter plots.
