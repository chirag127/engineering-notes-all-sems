
### Architecture of Data Mining 

Data mining is the process of discovering patterns in large data sets involving methods at the intersection of machine learning, statistics, and database systems. It is an essential process where intelligent methods are applied to extract data patterns.

The architecture of data mining can be divided into three components:

1. Data Sources: This is the source of data used in data mining. It can be a database, a data warehouse, or a flat file.

2. Data Mining Engine: This is the component that performs the actual data mining operations. It consists of algorithms which are used to extract patterns from the data.

3. Knowledge Representation and Visualization: This is the component which is used to represent the patterns discovered by the data mining engine. It can be in the form of graphical representations or textual descriptions.

### How Data Mining Works (Process)

Data mining is a process which follows a certain number of steps to be able to extract useful information from a given dataset. The steps involved in the process are as follows:

1. Data Preparation: This is the first step in the process of data mining. It involves cleaning the raw data and preparing it for further analysis.

2. Data Selection: This is the step where the relevant data is selected from the given dataset. This step is important as it helps to reduce the amount of data that needs to be analyzed.

3. Data Transformation: This is the step where the selected data is transformed into a format which is suitable for data mining.

4. Data Mining: This is the actual data mining step. It involves the application of data mining algorithms to the transformed data to discover patterns and relationships.

5. Pattern Evaluation: This is the step where the discovered patterns are evaluated to determine their usefulness.

6. Knowledge Representation: This is the step where the discovered patterns are represented in a suitable format for further analysis.
