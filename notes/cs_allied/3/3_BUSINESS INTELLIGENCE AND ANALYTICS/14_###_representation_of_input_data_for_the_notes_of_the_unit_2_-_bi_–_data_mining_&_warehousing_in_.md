### Representation of Input Data for the notes of the Unit 2 - BI – DATA MINING & WAREHOUSING in the subject of BUSINESS INTELLIGENCE AND ANALYTICS KCS

Representation of input data refers to the process of converting raw data into a format that can be easily analyzed and processed by data mining and warehousing tools. This is an important step in the data analytics lifecycle, as it helps to ensure that the data is accurate, relevant, and useful for decision-making purposes.

There are several ways to represent input data, including:

1. Numeric representation: This involves converting data into numerical values, such as integers or real numbers. This is useful for data that can be easily quantified, such as sales figures or demographic data.

2. Categorical representation: This involves converting data into categorical values, such as gender or product type. This is useful for data that cannot be easily quantified, such as customer opinions or product reviews.

3. Binary representation: This involves converting data into binary values, such as 0 or 1. This is useful for data that can be easily divided into two categories, such as yes/no responses or male/female.

4. Ordinal representation: This involves converting data into ordinal values, such as ranks or grades. This is useful for data that can be easily ranked or ordered, such as movie ratings or customer satisfaction scores.

5. Time series representation: This involves converting data into time series data, such as daily, weekly, or monthly data. This is useful for data that is collected over time, such as stock prices or weather data.

It is important to choose the appropriate representation of input data based on the data type and the goals of the data analytics project. This will help to ensure that the data is accurate, relevant, and useful for decision-making purposes.
