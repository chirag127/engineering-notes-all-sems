### Markov Inequality

Markov's inequality is a statement about non-negative random variables. It provides an upper bound on the probability that a non-negative random variable is greater than or equal to a certain value.

Let X be a non-negative random variable and let a > 0 be a positive constant. Then, Markov's inequality states that:

P(X >= a) <= E(X) / a

where E(X) is the expected value of X.

This inequality can be useful in providing a rough estimate of the probability that a random variable takes on large values. It is often used as a first step in proving more refined bounds.

Here are some key points to remember about Markov's inequality:

- It only applies to non-negative random variables.
- The bound provided by the inequality may not be tight.
- It can be used as a first step in proving more refined bounds.
