# Linear Combination

- A linear combination of a set of vectors is a sum of scalar multiples of the vectors.
- For example, if u, v, and w are vectors, and a, b, and c are scalars, then au + bv + cw is a linear combination of u, v, and w.
- The scalars a, b, and c are called the coefficients of the linear combination.
- A set of vectors is said to span a vector space if every vector in the space can be written as a linear combination of the vectors in the set.
- For example, the standard basis vectors e1 = (1, 0, 0), e2 = (0, 1, 0), and e3 = (0, 0, 1) span R3, because any vector (x, y, z) in R3 can be written as x e1 + y e2 + z e3.
- A linear combination of a set of vectors is said to be trivial if all the coefficients are zero, and nontrivial otherwise.
- For example, 0 u + 0 v + 0 w is a trivial linear combination of u, v, and w, while 2 u - 3 v + 4 w is a nontrivial linear combination of u, v, and w.
