# Linear Transformations and Matrices for Linear Transformation

- A linear transformation is a function that maps vectors from one vector space to another vector space, preserving the operations of vector addition and scalar multiplication.
- A matrix is a rectangular array of numbers that can be used to represent linear transformations in a convenient and compact way.
- To find the matrix of a linear transformation, we need to choose a basis for the input and output vector spaces, and then compute the images of the basis vectors under the transformation.
- The matrix of a linear transformation can be multiplied by a vector to obtain the transformed vector, using the rule of matrix-vector multiplication.
- The matrix of a linear transformation depends on the choice of bases, and different bases may lead to different matrices for the same transformation.
- The matrix of a linear transformation can be used to study the properties of the transformation, such as its rank, nullity, kernel, image, eigenvalues, eigenvectors, etc.
