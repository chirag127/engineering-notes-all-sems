### Transformations for the notes of the Unit 3 - Pseudo-Random Numbers

- Pseudo-random numbers are numbers that are generated by a deterministic algorithm that mimics the properties of random numbers.
- Pseudo-random numbers are often used in simulations, cryptography, games, and other applications that require randomness.
- Pseudo-random numbers can be generated from different probability distributions, such as uniform, normal, exponential, etc.
- There are different methods for generating pseudo-random numbers from different distributions, such as:

  - Linear congruential generator: This is a simple and widely used method that generates pseudo-random numbers from a uniform distribution. The algorithm is defined by the recurrence relation: Xn+1 = (aXn + c) mod m, where X is the sequence of pseudo-random values, m is the modulus, a is the multiplier, c is the increment, and x0 is the seed or start value.
  - Probability integral transform: This is a general method that can generate pseudo-random numbers from any distribution, given its cumulative distribution function (CDF). The algorithm is based on the fact that if X is a random variable with CDF F, then F(X) is a uniform random variable. Therefore, to generate a random variable X with CDF F, we can generate a uniform random variable U and then apply the inverse of F to U, i.e., X = F^-1(U) .
  - Transformations: This is a method that exploits the relationships between different probability distributions through various transformations. For example, if X is a standard normal random variable, then Y = e^X is a log-normal random variable, and Z = |X| is a half-normal random variable. Therefore, to generate a random variable Y or Z, we can generate a random variable X and then apply the appropriate transformation.
  - Summation: This is a method that generates a random variable by summing several generated pseudo-random numbers with the appropriate distribution. For example, if X1, X2, ..., Xn are independent and identically distributed (i.i.d.) exponential random variables with mean 1, then Y = X1 + X2 + ... + Xn is a gamma random variable with shape parameter n and scale parameter 1. Therefore, to generate a random variable Y, we can generate n random variables X and then sum them.
