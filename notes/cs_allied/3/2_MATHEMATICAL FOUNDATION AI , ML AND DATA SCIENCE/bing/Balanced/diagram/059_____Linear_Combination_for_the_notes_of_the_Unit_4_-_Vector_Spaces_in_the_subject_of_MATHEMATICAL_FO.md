### Linear Combination

- A linear combination is a mathematical expression that is formed by adding or subtracting multiples of some terms .
- The terms can be variables, vectors, matrices, functions, or any other objects that can be multiplied by a constant and added together .
- The constants that multiply the terms are called coefficients or scalars.
- A linear combination can be written in the form:

  `c1v1 + c2v2 + ... + cnvn`

  where `c1, c2, ..., cn` are the coefficients and `v1, v2, ..., vn` are the terms.

- A linear combination can be used to represent various mathematical objects, such as:

  - A point or a vector in a coordinate system, by using the coefficients as the coordinates and the terms as the basis vectors.
  - A solution to a system of linear equations, by using the coefficients as the unknowns and the terms as the columns of the coefficient matrix.
  - A linear transformation, by using the coefficients as the entries of the transformation matrix and the terms as the basis vectors of the domain and the codomain.

- A linear combination can also be used to determine various properties of the terms, such as:

  - Linear dependence or independence, by checking if there exists a nontrivial linear combination that equals the zero vector.
  - Span, by finding all possible linear combinations of a given set of terms.
  - Linear combination, by finding the coefficients that make a given term equal to a linear combination of other terms.
