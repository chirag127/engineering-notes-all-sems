### Linear Independence

- A set of vectors is said to be **linearly independent** if none of the vectors can be written as a linear combination of the others.
- In other words, a set of vectors is linearly independent if the only solution to the equation `c1v1 + c2v2 + ... + cnvn = 0` is `c1 = c2 = ... = cn = 0`, where `c1, c2, ..., cn` are scalars and `v1, v2, ..., vn` are vectors.
- A set of vectors that is not linearly independent is called **linearly dependent**. This means that at least one of the vectors can be expressed as a linear combination of the others, or equivalently, that there is a non-trivial solution to the equation `c1v1 + c2v2 + ... + cnvn = 0`.
- Linear independence is a property that depends on the vector space in which the vectors are defined. For example, the vectors `(1, 0)` and `(0, 1)` are linearly independent in `R^2`, but linearly dependent in `R^3`, since `(1, 0, 0) = 1 * (1, 0) + 0 * (0, 1) + 0 * (0, 0)`.
- Some facts about linear independence are:
  - The empty set is linearly independent by convention.
  - A set containing a single non-zero vector is linearly independent.
  - A set containing a zero vector is linearly dependent.
  - A set containing more vectors than the dimension of the vector space is linearly dependent.
  - A set of vectors is linearly independent if and only if its span is equal to the subspace generated by the vectors.
  - A set of vectors is linearly independent if and only if the matrix formed by placing the vectors as columns (or rows) has a non-zero determinant.
