## Unit 4 - Vector Spaces

A vector space is a mathematical structure that allows us to add and scale vectors, which are objects that have both magnitude and direction. A vector space consists of a set of vectors and a set of scalars, which are usually real or complex numbers. The vector space must satisfy some properties, called axioms, that make the operations of addition and scalar multiplication well-defined and consistent.

Some examples of vector spaces are:

- The set of all n-tuples of real numbers, denoted by R^n, where n is any positive integer. For example, R^2 is the set of all ordered pairs of real numbers, which can be represented as points or arrows in a plane. R^3 is the set of all ordered triples of real numbers, which can be represented as points or arrows in a three-dimensional space.
- The set of all polynomials of degree at most n, denoted by P_n, where n is any non-negative integer. For example, P_2 is the set of all polynomials of the form a + bx + cx^2, where a, b, and c are real numbers. P_0 is the set of all constant polynomials, which are just real numbers.
- The set of all functions from a set X to a set Y, denoted by Y^X, where X and Y are any sets. For example, R^R is the set of all real-valued functions of a real variable, such as f(x) = sin(x) or g(x) = e^x. C^R is the set of all complex-valued functions of a real variable, such as h(x) = cos(x) + i sin(x).

The axioms of a vector space are:

- Closure under addition: For any two vectors u and v in the vector space, their sum u + v is also in the vector space.
- Commutativity of addition: For any two vectors u and v in the vector space, u + v = v + u.
- Associativity of addition: For any three vectors u, v, and w in the vector space, (u + v) + w = u + (v + w).
- Existence of additive identity: There exists a vector 0 in the vector space, such that for any vector u in the vector space, u + 0 = u.
- Existence of additive inverse: For any vector u in the vector space, there exists a vector -u in the vector space, such that u + (-u) = 0.
- Closure under scalar multiplication: For any scalar c and any vector u in the vector space, their product cu is also in the vector space.
- Distributivity of scalar multiplication over vector addition: For any scalar c and any two vectors u and v in the vector space, c(u + v) = cu + cv.
- Distributivity of vector addition over scalar multiplication: For any two scalars c and d and any vector u in the vector space, (c + d)u = cu + du.
- Associativity of scalar multiplication: For any two scalars c and d and any vector u in the vector space, (cd)u = c(du).
- Existence of multiplicative identity: There exists a scalar 1, such that for any vector u in the vector space, 1u = u.

Some properties that follow from the axioms of a vector space are:

- The additive identity 0 is unique: There is only one vector 0 in the vector space that satisfies the axiom of additive identity.
- The additive inverse -u is unique: For any vector u in the vector space, there is only one vector -u in the vector space that satisfies the axiom of additive inverse.
- The multiplicative identity 1 is unique: There is only one scalar 1 that satisfies the axiom of multiplicative identity.
- The zero vector 0 is the only vector that is annihilated by any scalar: For any scalar c and the vector 0 in the vector space, c0 = 0.
- The scalar 0 is the only scalar that annihilates any vector: For any scalar 0 and any vector u in the vector space, 0u = 0.
