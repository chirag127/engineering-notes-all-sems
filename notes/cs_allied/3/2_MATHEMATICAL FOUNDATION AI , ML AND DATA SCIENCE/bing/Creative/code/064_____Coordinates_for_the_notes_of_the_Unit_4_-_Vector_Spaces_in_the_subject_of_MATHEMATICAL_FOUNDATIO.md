### Coordinates

- A coordinate system is a way of assigning a unique set of numbers to each point in a vector space, such that the numbers can be used to identify the point and perform operations on it.
- A coordinate system consists of a basis and an origin. A basis is a set of linearly independent vectors that span the vector space, and an origin is a fixed point that serves as a reference for the coordinates.
- The coordinates of a point are the scalars that multiply the basis vectors in the linear combination that gives the point. For example, if $\mathbf{v} = a\mathbf{u}_1 + b\mathbf{u}_2 + c\mathbf{u}_3$ is a point in a vector space with basis $\{\mathbf{u}_1, \mathbf{u}_2, \mathbf{u}_3\}$, then the coordinates of $\mathbf{v}$ are $(a, b, c)$.
- The coordinates of a point depend on the choice of the basis and the origin. Different bases and origins may give different coordinates for the same point. For example, if $\mathbf{v} = 2\mathbf{e}_1 + 3\mathbf{e}_2$ is a point in a vector space with basis $\{\mathbf{e}_1, \mathbf{e}_2\}$ and origin $\mathbf{0}$, then the coordinates of $\mathbf{v}$ are $(2, 3)$. However, if we change the basis to $\{\mathbf{f}_1, \mathbf{f}_2\}$, where $\mathbf{f}_1 = \mathbf{e}_1 + \mathbf{e}_2$ and $\mathbf{f}_2 = \mathbf{e}_1 - \mathbf{e}_2$, then the coordinates of $\mathbf{v}$ are $(5, 1)$. Similarly, if we change the origin to $\mathbf{w} = \mathbf{e}_1 + \mathbf{e}_2$, then the coordinates of $\mathbf{v}$ are $(1, 2)$.
- To change the coordinates of a point from one basis to another, we can use a linear transformation that maps the old basis to the new basis. For example, if we want to change the coordinates of $\mathbf{v}$ from the basis $\{\mathbf{e}_1, \mathbf{e}_2\}$ to the basis $\{\mathbf{f}_1, \mathbf{f}_2\}$, we can use the matrix $A = \begin{bmatrix} 1 & 1 \\ 1 & -1 \end{bmatrix}$, which satisfies $A\mathbf{e}_1 = \mathbf{f}_1$ and $A\mathbf{e}_2 = \mathbf{f}_2$. Then, the coordinates of $\mathbf{v}$ in the new basis are given by $A^{-1}\mathbf{v} = \begin{bmatrix} 5 \\ 1 \end{bmatrix}$.

For example, if we want to change the coordinates of $\mathbf{v}$ from the origin $\mathbf{0}$ to the origin $\mathbf{w}$, we can use the vector $\mathbf{w} - \mathbf{0} = \mathbf{w}$, which satisfies $\mathbf{v} - \mathbf{w} = \mathbf{v} - (\mathbf{e}_1 + \mathbf{e}_2)$.
