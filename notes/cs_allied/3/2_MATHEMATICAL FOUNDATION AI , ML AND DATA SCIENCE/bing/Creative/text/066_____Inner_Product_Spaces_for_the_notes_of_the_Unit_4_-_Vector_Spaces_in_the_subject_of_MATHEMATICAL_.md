### Inner Product Spaces

- An inner product space is a vector space with an additional structure called an inner product. An inner product is a function that assigns a real number to every pair of vectors in the space, denoted by <u,v>.
- The inner product satisfies the following properties for any vectors u, v, w and any scalar c in the space:
  - <u,v> = <v,u> (symmetry)
  - <u+v,w> = <u,w> + <v,w> (additivity)
  - <cu,v> = c<u,v> (homogeneity)
  - <u,u> >= 0 and <u,u> = 0 if and only if u = 0 (positive definiteness)
- An example of an inner product space is the Euclidean space R^n with the standard inner product defined as <u,v> = u1v1 + u2v2 + ... + unvn, where ui and vi are the components of u and v respectively.
- Another example of an inner product space is the space of continuous functions on a closed interval [a,b] with the inner product defined as <f,g> = ∫ab f(x)g(x) dx, where f and g are any functions in the space.
- An inner product induces a norm on the vector space, which is a function that measures the length or magnitude of a vector. The norm of a vector u is defined as ||u|| = √<u,u>.
- The norm satisfies the following properties for any vectors u, v and any scalar c in the space:
  - ||u|| >= 0 and ||u|| = 0 if and only if u = 0 (positive definiteness)
  - ||cu|| = |c| ||u|| (absolute homogeneity)
  - ||u+v|| <= ||u|| + ||v|| (triangle inequality)
- The norm also induces a metric on the vector space, which is a function that measures the distance between two vectors. The metric of two vectors u and v is defined as d(u,v) = ||u-v||.
- The metric satisfies the following properties for any vectors u, v, w in the space:
  - d(u,v) >= 0 and d(u,v) = 0 if and only if u = v (positive definiteness)
  - d(u,v) = d(v,u) (symmetry)
  - d(u,w) <= d(u,v) + d(v,w) (triangle inequality)
- An inner product space is also a normed space and a metric space, since it has an inner product, a norm and a metric.
