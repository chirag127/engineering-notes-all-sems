### Orthogonal Vectors

- Two vectors **u** and **v** in a vector space are called **orthogonal** if their inner product is zero, i.e., **u** · **v** = 0.
- Orthogonal vectors are also called **perpendicular** vectors, since they form a right angle with each other.
- The zero vector is orthogonal to any vector, since **0** · **v** = 0 for any **v**.
- A set of vectors {**u**<sub>1</sub>, **u**<sub>2</sub>, ..., **u**<sub>n</sub>} is called an **orthogonal set** if every pair of vectors in the set is orthogonal, i.e., **u**<sub>i</sub> · **u**<sub>j</sub> = 0 for all i ≠ j.
- An orthogonal set of nonzero vectors is linearly independent, since the only way to satisfy the equation c<sub>1</sub>**u**<sub>1</sub> + c<sub>2</sub>**u**<sub>2</sub> + ... + c<sub>n</sub>**u**<sub>n</sub> = **0** is to have c<sub>1</sub> = c<sub>2</sub> = ... = c<sub>n</sub> = 0.
- An **orthogonal basis** for a vector space is a basis that is also an orthogonal set.
- An orthogonal basis has the advantage of simplifying the computation of coordinates, inner products, norms, and distances of vectors.
- To find an orthogonal basis for a vector space, one can use the **Gram-Schmidt process**, which takes a linearly independent set of vectors and produces an orthogonal set of vectors that spans the same space.
