### Probability

- Probability is a measure of how likely an event is to occur in a random experiment.
- An event is a subset of the sample space, which is the set of all possible outcomes of the experiment.
- The probability of an event A is denoted by P(A) and is a number between 0 and 1, where 0 means impossible and 1 means certain.
- There are different ways to assign probabilities to events, such as relative frequency, classical, subjective, or axiomatic approaches.
- Some basic properties of probability are:

  - P(A) >= 0 for any event A
  - P(S) = 1, where S is the sample space
  - If A and B are mutually exclusive events, then P(A or B) = P(A) + P(B)
  - P(A and B) = P(A) * P(B), if A and B are independent events
  - P(A) = 1 - P(A'), where A' is the complement of A
  - P(A or B) = P(A) + P(B) - P(A and B), for any events A and B

- Some common types of events are:

  - Simple event: an event that consists of a single outcome
  - Compound event: an event that consists of two or more outcomes
  - Exhaustive event: an event that covers all possible outcomes of the experiment
  - Equally likely event: an event that has the same probability as any other event of the same size
  - Conditional event: an event that depends on another event
  - Independent event: an event that does not affect or is not affected by another event
  - Dependent event: an event that affects or is affected by another event
  - Mutually exclusive event: an event that cannot occur at the same time as another event
  - Mutually inclusive event: an event that can occur at the same time as another event

- Some common rules of probability are:

  - Addition rule: P(A or B) = P(A) + P(B) - P(A and B), for any events A and B
  - Multiplication rule: P(A and B) = P(A) * P(B|A), for any events A and B, where P(B|A) is the conditional probability of B given A
  - Bayes' theorem: P(A|B) = P(B|A) * P(A) / P(B), for any events A and B, where P(A|B) is the conditional probability of A given B
  - Total probability theorem: P(B) = P(B|A) * P(A) + P(B|A') * P(A'), for any events A and B, where A' is the complement of A
  - Law of large numbers: As the number of trials of a random experiment increases, the relative frequency of an event approaches its true probability
  - Central limit theorem: As the sample size of a random variable increases, the sampling distribution of its mean approaches a normal distribution
