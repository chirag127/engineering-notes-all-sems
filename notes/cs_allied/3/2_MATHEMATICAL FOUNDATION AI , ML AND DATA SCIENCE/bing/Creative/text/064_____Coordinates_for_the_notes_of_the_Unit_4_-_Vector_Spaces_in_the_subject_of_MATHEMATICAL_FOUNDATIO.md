### Coordinates for the notes of the Unit 4 - Vector Spaces in the subject of MATHEMATICAL FOUNDATION AI , ML AND DATA SCIENCE

- A **vector space** is a set of objects called **vectors** that can be added and multiplied by **scalars** (numbers) according to certain rules.
- A **coordinate vector** is a representation of a vector in terms of a **basis**, which is an ordered set of linearly independent vectors that span the vector space.
- A **real coordinate space** is a vector space whose scalars and coordinates are real numbers. It can be denoted by R^n^, where n is the dimension of the space.
- A **complex coordinate space** is a vector space whose scalars and coordinates are complex numbers. It can be denoted by C^n^, where n is the dimension of the space.
- A **Euclidean space** is a real coordinate space that has a notion of **distance** and **angle** between vectors, defined by the **dot product**.
- A **Cartesian coordinate system** is a way of assigning n real numbers to each point in a Euclidean space, using n mutually perpendicular axes.
- A **standard basis** for a real or complex coordinate space is a basis consisting of n unit vectors, each having a 1 in one coordinate and 0 in the others. For example, the standard basis for R^2^ is {(1,0), (0,1)}.
- A **linear transformation** is a function between two vector spaces that preserves the operations of vector addition and scalar multiplication.
- A **matrix** is a rectangular array of numbers that can represent a linear transformation by multiplying coordinate vectors.
- A **system of linear equations** is a set of equations involving linear combinations of variables that can be solved by finding the values of the variables that satisfy all the equations.
