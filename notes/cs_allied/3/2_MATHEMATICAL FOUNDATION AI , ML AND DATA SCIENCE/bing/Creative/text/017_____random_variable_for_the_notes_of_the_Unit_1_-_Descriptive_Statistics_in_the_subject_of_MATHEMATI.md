### Random Variable

- A random variable is a variable that takes on different values depending on the outcome of a random experiment.
- A random variable can be either discrete or continuous, depending on whether it has a finite or infinite number of possible values.
- A discrete random variable can only take on a countable number of values, such as 0, 1, 2, ..., n. For example, the number of heads in a coin toss is a discrete random variable.
- A continuous random variable can take on any value in a given interval, such as [0, 1] or [a, b]. For example, the height of a person is a continuous random variable.
- A random variable can be denoted by a capital letter, such as X, Y, or Z. The possible values of a random variable can be denoted by a lowercase letter, such as x, y, or z.
- A probability distribution is a function that assigns probabilities to the possible values of a random variable. The probability distribution of a random variable X can be denoted by P(X) or f(X).
- A probability distribution must satisfy two conditions: (1) the probabilities must be non-negative, i.e., P(X = x) >= 0 for all x, and (2) the sum (or integral) of the probabilities must be equal to 1, i.e., sum(P(X = x)) = 1 for discrete X or integral(P(X = x)dx) = 1 for continuous X.
- A probability distribution can be represented by a table, a formula, a graph, or a histogram, depending on the type and nature of the random variable.
- A probability distribution can be used to calculate the probability of an event involving a random variable, such as P(X > 5) or P(X < 3 and Y > 2).
- A probability distribution can also be used to describe the characteristics of a random variable, such as its mean, variance, standard deviation, mode, median, skewness, kurtosis, etc.
