### Linear Independence

- Linear independence is a property of a set of vectors that means none of them can be written as a linear combination of the others.
- A linear combination of vectors is a sum of scalar multiples of the vectors. For example, if u, v and w are vectors, and a, b and c are scalars, then au + bv + cw is a linear combination of u, v and w.
- A set of vectors is linearly independent if the only way to write the zero vector as a linear combination of them is to use all zero scalars. For example, if u, v and w are linearly independent, then the equation au + bv + cw = 0 has only one solution: a = b = c = 0.
- A set of vectors is linearly dependent if it is not linearly independent. That means there is a non-trivial linear combination of the vectors that gives the zero vector. For example, if u, v and w are linearly dependent, then there exist scalars a, b and c, not all zero, such that au + bv + cw = 0.
- Linear independence is important because it determines the dimension and basis of a vector space. The dimension of a vector space is the maximum number of linearly independent vectors in it. A basis of a vector space is a set of linearly independent vectors that spans the whole space. That means any vector in the space can be written as a unique linear combination of the basis vectors.
- To check if a set of vectors is linearly independent, we can use the following methods:
  - Write the vectors as columns of a matrix and perform row operations to reduce it to row echelon form. The set is linearly independent if and only if there are no zero rows in the row echelon form.
  - Write the vectors as rows of a matrix and calculate its determinant. The set is linearly independent if and only if the determinant is not zero.
  - Write the vectors as terms of a homogeneous system of linear equations and solve it. The set is linearly independent if and only if the system has only the trivial solution.
