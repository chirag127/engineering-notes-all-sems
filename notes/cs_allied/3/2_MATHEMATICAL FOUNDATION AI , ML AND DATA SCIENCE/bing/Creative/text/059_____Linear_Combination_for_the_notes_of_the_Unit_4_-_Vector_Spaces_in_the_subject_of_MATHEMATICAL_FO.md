### Linear Combination

- A linear combination of a set of vectors $\{v_1, v_2, ..., v_n\}$ is an expression of the form $c_1v_1 + c_2v_2 + ... + c_nv_n$, where $c_1, c_2, ..., c_n$ are scalars.
- A linear combination can be seen as a weighted sum of the vectors, where the scalars are the weights.
- A linear combination can also be interpreted as a linear transformation of the vectors, where the scalars are the coefficients of the transformation matrix.
- The set of all possible linear combinations of a set of vectors is called the span of the set, and it forms a vector space.
- A set of vectors is linearly independent if none of the vectors can be written as a linear combination of the others. A set of vectors is linearly dependent if at least one of the vectors can be written as a linear combination of the others.
- A basis of a vector space is a set of linearly independent vectors that span the space. A basis is not unique, but any two bases of the same space have the same number of vectors, which is called the dimension of the space.
- A linear combination can be used to represent any vector in a vector space as a unique combination of the basis vectors. This is called the coordinate representation of the vector with respect to the basis.
- A linear combination can also be used to solve systems of linear equations, by finding the values of the scalars that make the linear combination equal to a given vector. This is called the linear equation representation of the vector with respect to the set of vectors.
