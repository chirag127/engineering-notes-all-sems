# Subspace

- A subspace is a subset of a vector space that is also a vector space itself.
- A subspace must satisfy three conditions:
  - It must contain the zero vector of the original vector space.
  - It must be closed under vector addition, meaning that if u and v are in the subspace, then u + v is also in the subspace.
  - It must be closed under scalar multiplication, meaning that if u is in the subspace and c is any scalar, then c * u is also in the subspace.
- Examples of subspaces are:
  - The set of all vectors with zero entries, which is called the trivial subspace.
  - The set of all vectors that are parallel to a given vector, which is called a line through the origin.
  - The set of all vectors that are orthogonal to a given vector, which is called a hyperplane through the origin.
  - The set of all linear combinations of a given set of vectors, which is called the span of the set.
- A subspace can be characterized by a basis, which is a linearly independent set of vectors that spans the subspace.
- The dimension of a subspace is the number of vectors in a basis for the subspace.
- A subspace can also be characterized by a system of linear equations, which is equivalent to finding the null space of the corresponding coefficient matrix.
