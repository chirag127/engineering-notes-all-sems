# Multiple Regression Analysis

- Multiple regression analysis is a statistical technique that allows us to study the relationship between a dependent variable (also called the response or outcome variable) and two or more independent variables (also called the predictors or explanatory variables).
- The goal of multiple regression analysis is to model how the dependent variable changes as a function of the independent variables, and to test hypotheses about the effects of the independent variables on the dependent variable.
- Multiple regression analysis can be used for various purposes, such as:
  - Exploring the causal relationships among variables
  - Estimating the effects of the independent variables on the dependent variable
  - Predicting the value of the dependent variable for new observations
  - Controlling for confounding variables that may affect the dependent variable
  - Evaluating the fit and adequacy of the regression model
- Multiple regression analysis can be performed using different methods, such as:
  - Linear regression: when the dependent variable is continuous and the relationship between the dependent and independent variables is linear
  - Logistic regression: when the dependent variable is binary (0 or 1) and the relationship between the dependent and independent variables is logistic
  - Poisson regression: when the dependent variable is a count (non-negative integer) and the relationship between the dependent and independent variables is Poisson
  - Cox regression: when the dependent variable is a time-to-event (survival) and the relationship between the dependent and independent variables is proportional hazards
- Multiple regression analysis involves several steps, such as:
  - Defining the research question and hypotheses
  - Selecting the appropriate regression method and model
  - Collecting and preparing the data
  - Fitting the regression model and estimating the parameters
  - Checking the assumptions and diagnostics of the regression model
  - Interpreting and reporting the results of the regression model
  - Evaluating the significance and practical relevance of the regression model
