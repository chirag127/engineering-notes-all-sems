# Multiple Correlation

- Multiple correlation is a statistical technique that predicts values of one variable on the basis of two or more other variables .
- Multiple correlation is a generalization of the concept of correlation, which measures the strength and direction of the relationship between two variables.
- Multiple correlation can be used to assess how well a set of predictor variables can explain the variation in a response variable, or to explore the associations among a set of variables.
- Multiple correlation can be calculated using the formula:

$$R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}$$

where:

  - $R^2$ is the multiple correlation coefficient, which ranges from 0 to 1.
  - $SSR$ is the sum of squares due to regression, which measures how much the predicted values differ from the mean of the response variable.
  - $SST$ is the total sum of squares, which measures how much the response variable varies around its mean.
  - $SSE$ is the sum of squares due to error, which measures how much the observed values differ from the predicted values.

- Multiple correlation can also be expressed as the square root of the coefficient of determination, which is the proportion of variance in the response variable that is explained by the predictor variables:

$$R = \sqrt{R^2}$$

- Multiple correlation can be computed using various methods, such as:

  - Multiple linear regression, which assumes a linear relationship between the response variable and the predictor variables.
  - Multiple logistic regression, which assumes a binary or categorical response variable and a linear relationship between the logit of the response variable and the predictor variables.
  - Multiple nonlinear regression, which allows for nonlinear relationships between the response variable and the predictor variables.
  - Multiple correlation analysis, which finds the maximum correlation between the response variable and linear combinations of the predictor variables.
  - Canonical correlation analysis, which finds the maximum correlation between two sets of variables.
