# Gibbs sampling

Gibbs sampling is a technique for generating samples from a multivariate probability distribution, especially when direct sampling is difficult or impossible. It is a type of Markov chain Monte Carlo (MCMC) method, which means that it produces a sequence of random samples that converge to the target distribution as the number of samples increases.

Gibbs sampling is based on the idea of sampling from the conditional distributions of each variable given the current values of the other variables. For example, suppose we have a joint distribution of two variables, X and Y, and we want to sample from it. We can do this by:

- Initializing X and Y to some arbitrary values, x0 and y0.
- Repeating the following steps until we have enough samples:
  - Sampling a new value of X from the conditional distribution of X given Y = y0, and updating x0 to this new value.
  - Sampling a new value of Y from the conditional distribution of Y given X = x0, and updating y0 to this new value.
  - Appending (x0, y0) to the list of samples.

The samples generated by this procedure will form a Markov chain, which means that each sample depends only on the previous one. The Markov chain will have the same stationary distribution as the joint distribution of X and Y, which means that as the number of samples increases, the empirical distribution of the samples will approach the true distribution.

Gibbs sampling can be generalized to more than two variables, by sampling from the conditional distribution of each variable given the current values of the rest of the variables, in some order. The order can be fixed, random, or cyclic. The main advantage of Gibbs sampling is that it simplifies the sampling problem by breaking it down into smaller and easier subproblems. The main disadvantage is that it can be slow to converge, especially if the variables are highly correlated or the conditional distributions are complex.

Gibbs sampling is widely used in Bayesian inference, where the goal is to estimate the posterior distribution of some unknown parameters given some observed data and a prior distribution. Gibbs sampling can be used to generate samples from the posterior distribution, which can then be used to compute summary statistics, such as the mean, the mode, the variance, or the credible intervals of the parameters. Gibbs sampling can also be used to estimate the marginal likelihood of the data, which can be useful for model comparison or selection.

Some examples of applications of Gibbs sampling are:

- Latent Dirichlet allocation (LDA), a topic model that assigns each document in a corpus to a mixture of topics, and each word in a document to a specific topic.
- Ising model, a statistical physics model that describes the behavior of magnetic spins on a lattice, where each spin can be either up or down, and depends on the neighboring spins.
- Bayesian network, a graphical model that represents the conditional dependencies among a set of random variables, where each variable can have a discrete or continuous distribution.
