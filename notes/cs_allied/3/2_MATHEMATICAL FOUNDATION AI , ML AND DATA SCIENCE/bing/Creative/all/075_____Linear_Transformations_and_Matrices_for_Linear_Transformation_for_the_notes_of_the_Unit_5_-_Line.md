# Linear Transformations and Matrices for Linear Transformation

## Linear Transformations

- A linear transformation is a function that maps vectors from one vector space to another vector space, preserving the operations of vector addition and scalar multiplication.
- A linear transformation can be represented by a matrix, which is a rectangular array of numbers that encodes the action of the transformation on the basis vectors of the domain and the range.
- A matrix transformation is a linear transformation that can be written as T(x) = Ax, where A is a matrix and x is a vector.
- The matrix of a linear transformation depends on the choice of bases for the domain and the range. Different bases may result in different matrices for the same transformation.
- The matrix of a linear transformation can be used to compute the image of any vector in the domain by multiplying the matrix and the vector.
- The matrix of a linear transformation also reveals some properties of the transformation, such as its rank, nullity, kernel, image, determinant, eigenvalues, and eigenvectors.

## Matrices as Transformations

- A matrix can be viewed as a transformation that maps vectors from one vector space to another vector space, according to the rule of matrix multiplication.
- A matrix can be interpreted as a collection of column vectors, each representing the image of a standard basis vector under the transformation.
- A matrix can also be interpreted as a collection of row vectors, each representing the coefficients of a linear equation that defines the transformation.
- A matrix can perform various types of transformations, such as scaling, rotation, reflection, projection, shear, and more.
- A matrix can be composed with another matrix to create a new transformation that is equivalent to applying the two matrices in sequence.
- A matrix can be inverted to find the inverse transformation, if it exists, that undoes the original transformation.
