### Linear Combination

- A linear combination of a set of vectors $\{v_1, v_2, ..., v_n\}$ is a sum of the form $c_1v_1 + c_2v_2 + ... + c_nv_n$, where $c_1, c_2, ..., c_n$ are scalars.
- A linear combination can be seen as a weighted sum of the vectors, where the scalars are the weights.
- A linear combination can also be interpreted as a linear transformation of the vectors, where the scalars are the coefficients of the transformation matrix.
- A linear combination can be used to express any vector in a vector space as a combination of the basis vectors of that space.
- A linear combination can be used to determine the span, linear independence, and dimension of a set of vectors.
- A linear combination can be used to solve systems of linear equations, by finding the values of the scalars that make the linear combination equal to a given vector.

Some examples of linear combinations are:

- $2(1, 0, -1) + 3(0, 1, 2) = (2, 3, 1)$
- $-4(2, 3) + 5(1, -1) = (-3, -17)$
- $0.5(1, 2, 3, 4) + 0.25(4, 3, 2, 1) + 0.75(0, 1, 0, 1) = (2.5, 3.5, 2.5, 3.5)$
