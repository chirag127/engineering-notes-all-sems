### Vector Space

- A vector space is a set of objects called vectors, which can be added together and multiplied by scalars (numbers), satisfying certain rules.
- The rules are called axioms and they ensure that the operations of vector addition and scalar multiplication are well-defined and have the properties we expect from linear algebra.
- A vector space can have any dimension, which is the number of independent vectors that can span the space. For example, the set of all real numbers is a one-dimensional vector space, and the set of all ordered pairs of real numbers is a two-dimensional vector space.
- A vector space can also have a basis, which is a set of linearly independent vectors that can generate the whole space by linear combinations. For example, the standard basis of the two-dimensional vector space is the set {(1,0), (0,1)}, where any vector (x,y) can be written as x(1,0) + y(0,1).
- A vector space can also have a subspace, which is a subset of vectors that is also a vector space. For example, the set of all vectors of the form (x,0) is a subspace of the two-dimensional vector space, and it is one-dimensional.
- A vector space can also have a linear transformation, which is a function that maps vectors from one vector space to another, preserving the operations of vector addition and scalar multiplication. For example, the function that rotates every vector by 90 degrees counterclockwise is a linear transformation from the two-dimensional vector space to itself.
