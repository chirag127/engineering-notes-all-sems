### Subspace

- A subspace is a subset of a vector space that is also a vector space itself.
- A subspace must satisfy three conditions:
  - It must contain the zero vector of the original vector space.
  - It must be closed under vector addition, meaning that if u and v are in the subspace, then u + v is also in the subspace.
  - It must be closed under scalar multiplication, meaning that if u is in the subspace and c is any scalar, then c * u is also in the subspace.
- Examples of subspaces are:
  - The set of all vectors with zero entries, which is called the trivial subspace.
  - The set of all vectors that are parallel to a given nonzero vector, which is called a line through the origin.
  - The set of all vectors that are orthogonal to a given nonzero vector, which is called a hyperplane through the origin.
  - The set of all solutions to a homogeneous system of linear equations, which is called the null space of the coefficient matrix.
  - The set of all linear combinations of a given set of vectors, which is called the span of the set of vectors.
- To check if a subset of a vector space is a subspace, we can use the following method:
  - Verify that the subset contains the zero vector of the original vector space.
  - Pick any two vectors in the subset and check if their sum is also in the subset.
  - Pick any vector in the subset and any scalar and check if their product is also in the subset.
  - If all three steps are true, then the subset is a subspace. Otherwise, it is not a subspace.
