### Random Variable

A random variable is a variable whose value is subject to variations due to chance. It is used to describe the outcomes of a random event or experiment. Random variables are often denoted by capital letters, such as X, Y, or Z.

#### Types of Random Variables

1. Discrete Random Variable: A random variable that can only take on a finite or countably infinite set of values. Examples include the number of heads in a coin toss or the number of cars passing by a particular point in a given time.

2. Continuous Random Variable: A random variable that can take on any value within a specified range. Examples include the height of a person or the temperature of a room.

#### Probability Distribution

The probability distribution of a random variable describes the likelihood of each possible outcome. It can be represented using a probability density function (PDF) for continuous random variables or a probability mass function (PMF) for discrete random variables.

#### Mean and Variance

The mean, also known as the expected value, of a random variable is the sum of the product of each possible value and its probability. The variance is a measure of how spread out the values of a random variable are from its mean.

#### Examples

1. A fair six-sided die is rolled. Let X represent the number that appears on the top face. X is a discrete random variable with a PMF of P(X = i) = 1/6 for i = 1, 2, 3, 4, 5, 6.

2. The height of a randomly selected person is a continuous random variable with a PDF that follows a normal distribution.

#### Applications

Random variables are used extensively in statistics, probability theory, and machine learning. They are used to model real-world phenomena and make predictions based on data. For example, in finance, random variables are used to model stock prices and predict future trends. In medical research, they are used to model the effectiveness of a drug treatment.
