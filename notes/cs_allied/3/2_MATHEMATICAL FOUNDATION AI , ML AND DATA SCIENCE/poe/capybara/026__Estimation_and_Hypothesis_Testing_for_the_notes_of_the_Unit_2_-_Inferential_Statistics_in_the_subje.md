### Estimation and Hypothesis Testing

Inferential statistics deals with making predictions and inferences about a population based on a sample of data. In this unit, we will learn about estimation and hypothesis testing, which are two important tools used in inferential statistics.

#### Estimation

Estimation is the process of using sample data to make predictions about the population. There are two main types of estimation: point estimation and interval estimation.

- Point estimation involves using a single value (the point estimate) to estimate an unknown population parameter. The most common point estimate is the sample mean, which is used to estimate the population mean.
- Interval estimation involves using a range of values (the confidence interval) to estimate an unknown population parameter. The most common confidence interval is the 95% confidence interval, which means that we are 95% confident that the true population parameter lies within the calculated interval.

#### Hypothesis Testing

Hypothesis testing is a statistical method used to determine whether a hypothesis about a population parameter is supported by the sample data. The hypothesis is usually stated in terms of two opposing statements: the null hypothesis and the alternative hypothesis.

- The null hypothesis (H0) is the statement that there is no significant difference between the sample data and the population parameter. It is assumed to be true until there is enough evidence to reject it.
- The alternative hypothesis (Ha) is the statement that there is a significant difference between the sample data and the population parameter. It is accepted if there is enough evidence to reject the null hypothesis.

The hypothesis testing process involves the following steps:

1. State the null and alternative hypotheses.
2. Choose a significance level (alpha) to determine the critical value or p-value.
3. Calculate the test statistic using the sample data.
4. Compare the test statistic with the critical value or p-value.
5. Make a decision to either reject or fail to reject the null hypothesis.

#### Conclusion

Estimation and hypothesis testing are important tools used in inferential statistics to make predictions and inferences about a population based on a sample of data. By learning about these tools, we can better understand how to analyze and interpret data in the field of AI, ML, and data science.
