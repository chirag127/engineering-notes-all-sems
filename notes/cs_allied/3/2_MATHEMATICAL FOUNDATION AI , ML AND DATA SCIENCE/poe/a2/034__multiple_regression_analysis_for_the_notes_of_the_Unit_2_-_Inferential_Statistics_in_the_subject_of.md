### Multiple Regression Analysis

- Multiple regression is an extension of linear regression that allows you to analyze data where the dependent variable y depends on multiple independent variables (x1, x2, ... , xk).
- The model is: y = β0 + β1x1 + β2x2 + ... + βkxK + ε
- The β coefficients are estimated using least squares - minimizing the sum of squared errors between the predicted and actual y values.
- Assumptions:
    - Linear relationship between dependent and independent variables
    - Multicollinearity: independent variables are not perfectly correlated
    - Homoscedasticity: equal variance of errors across values of independent variables
    - Normality of errors
- Uses:
    - Predict a quantitative outcome variable based on multiple predictors
    - Determine strength of relationship between independent and dependent variables while controlling for other variables
    - Identification of confounding variables
- Limitations:
    - Cannot prove causation, only correlation
    - May overfit model if too many independent variables relative to sample size
