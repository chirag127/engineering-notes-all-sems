### Linear Methods for Regression Analysis

- Linear regression is a statistical technique for modelling relationship between a dependent variable and one or more independent variables using a straight line.
- The equation for a straight line is y = mx + c where m is the slope and c is the y-intercept.
- In linear regression, the slope represents the effect of x on y and the y-intercept represents the value of y when x = 0.
- The goal is to minimize the residual sum of squares (RSS) which is the vertical distance between the points and the line. The line that minimizes RSS is the best fit line.
- To find the best fit line, we need to estimate m and c. This is done using the least squares method which minimizes the RSS.
- The assumptions of linear regression are:
    - Linear relationship between dependent and independent variables.
    - Little or no multicollinearity between independent variables.
    - Variance of errors is constant across all values of x.
    - Errors are uncorrelated and follow a normal distribution.
- Applications of linear regression include forecasting, predicting effects of changes, comparing groups, etc.
