### Linear Combination

* A linear combination of vectors v1, v2, ..., vn is a vector which can be written as a1v1 + a2v2 + ... + anvn where a1, a2, ..., an are scalars.
* The set of all possible linear combinations of a given set of vectors forms a vector space. This is known as the span of the vectors.
* The span of a set of vectors is the set of all possible linear combinations of those vectors. It is the smallest vector space that contains the given vectors.
* Two sets of vectors have the same span if and only if every vector in one set can be written as a linear combination of vectors in the other set, and vice-versa.
* If a set of vectors has a finite span, then there exists a minimum number of vectors such that every vector in the span can be written as a linear combination of these minimum number of vectors. Such a minimum set is called a basis for the span.
* The dimension of a vector space is the number of vectors in any basis for the space. All bases for a vector space have the same number of elements and this common number is the dimension of the space.
