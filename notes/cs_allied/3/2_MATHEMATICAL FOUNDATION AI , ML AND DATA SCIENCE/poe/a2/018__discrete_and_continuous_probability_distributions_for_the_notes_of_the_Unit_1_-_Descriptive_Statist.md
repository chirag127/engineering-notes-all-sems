### Discrete and Continuous Probability Distributions

Discrete Probability Distributions:

- Discrete random variables can only take on a countable number of possible values.
- The probability mass function (PMF) is used to describe the probability distribution of a discrete random variable. The PMF takes on non-negative values that sum to 1.
- Examples: Binomial distribution, Poisson distribution, geometric distribution.

Continuous Probability Distributions:

- Continuous random variables can take on any value in an interval.
- The probability density function (PDF) is used to describe the probability distribution of a continuous random variable. The PDF must be non-negative and integrate to 1 over the interval.
- Examples: Normal distribution, exponential distribution, uniform distribution.

Differences:

- Discrete random variables can only take on distinct, separate values (e.g. number of heads in 3 flips), while continuous random variables can take on any value in an interval (e.g. height of individuals).
- Probability mass function (PMF) is used for discrete random variables, probability density function (PDF) is used for continuous random variables.
- The PMF takes on non-negative values that sum to 1, while the PDF must be non-negative and integrate to 1 over the interval.
