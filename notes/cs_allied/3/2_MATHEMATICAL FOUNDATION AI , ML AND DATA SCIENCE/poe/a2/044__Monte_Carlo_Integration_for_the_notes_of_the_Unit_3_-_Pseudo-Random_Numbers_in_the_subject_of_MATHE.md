### Monte Carlo Integration

- Monte Carlo integration is a technique to estimate the integral of a function using random sampling.
- It involves calculating the integral of a function by generating random points within the function's domain and calculating the average of the function values at these points.
- As more random points are generated, the estimate becomes more accurate.
- Pseudo-random number generators are used to generate the random points.
- The key steps are:

1. Generate N random points in the interval [a, b]
2. Evaluate the function at each point
3. Calculate the average of the function values
4. Multiply the average by (b-a) to get the estimate of the integral

- The accuracy of the estimate improves as N increases but the rate of improvement decreases with increase in N.
- Monte Carlo integration is useful when analytical evaluation of the integral is difficult or impossible.
- It is a simple and versatile method but can be computationally expensive if high accuracy is required.
