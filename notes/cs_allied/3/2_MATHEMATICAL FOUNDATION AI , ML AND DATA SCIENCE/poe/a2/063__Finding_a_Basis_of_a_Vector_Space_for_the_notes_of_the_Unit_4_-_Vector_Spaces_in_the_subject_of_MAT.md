### Finding a Basis of a Vector Space

1. A basis for a vector space V is a set of vectors that spans V, i.e. every vector in V can be written as a linear combination of basis vectors.
2. A basis has minimum number of vectors. If a set of vectors spans V but has more vectors than a basis, then it is not a basis.
3. Given a set of vectors {v1, v2, ..., vn} in a vector space V, the following steps can be used to check if it is a basis:
    1. Check if the set spans V, i.e. every vector in V can be written as a linear combination of {v1, v2, ..., vn}
    2. Check if the vectors in the set are linearly independent. If they are linearly dependent, the set cannot be a basis.
    3. If the set satisfies steps 1 and 2, check if it has minimum number of vectors. If yes, then the set is a basis for V.
4. Examples:
    1. In R2, the standard basis is {**(1,0), (0,1)}. Any vector in R2 can be written as a linear combination of these two vectors and there are exactly two vectors in the basis.
    2. In R3, the standard basis is {**(1,0,0), (0,1,0), (0,0,1)}. This set spans R3, the vectors are linearly independent, and there are three vectors in the basis.
