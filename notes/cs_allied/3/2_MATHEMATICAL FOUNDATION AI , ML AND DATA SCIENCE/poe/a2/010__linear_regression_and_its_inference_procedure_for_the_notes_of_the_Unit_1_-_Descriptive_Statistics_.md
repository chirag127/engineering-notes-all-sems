### Linear Regression and its Inference Procedure

Linear regression is a statistical technique for modeling the relationship between a dependent variable and one or more independent variables using a straight line.

Inference procedure for linear regression:

1. Check the assumptions:
- Linear relationship between dependent and independent variables
- No multicollinearity between independent variables
- Residuals are normally distributed with zero mean and constant variance
- Independence of errors

2. Fit the linear regression model using least squares method
3. Evaluate the fit of the model using R-squared and p-values
- R-squared: Proportion of variance in dependent variable explained by the model
- p-values: Check significance of each regressor in the model

4. Diagnose the model and check for violations of assumptions
- Check residual plots for non-normality or heteroscedasticity
- Check variance inflation factor (VIF) for multicollinearity

5. Interpret the regression coefficients and make inferences
- Check significance of individual coefficients using t-test
- Interpret coefficients as change in predicted value of dependent variable due to one unit change in the regressor keeping others fixed

6. Evaluate performance and predict on new data
- Calculate mean absolute error (MAE) and mean squared error (MSE) on training data for evaluation
- Predict dependent variable for new data using the fitted regression equation
