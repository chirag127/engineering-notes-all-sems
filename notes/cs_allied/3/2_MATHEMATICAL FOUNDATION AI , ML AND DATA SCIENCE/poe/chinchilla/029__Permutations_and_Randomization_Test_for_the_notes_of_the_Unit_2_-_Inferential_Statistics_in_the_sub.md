### Permutations and Randomization Test for the notes of the Unit 2 - Inferential Statistics in the subject of MATHEMATICAL FOUNDATION AI, ML AND DATA SCIENCE

Inferential statistics is the branch of statistics that helps us draw conclusions about a population based on a sample. One way to do this is by using hypothesis testing. In this topic, we will discuss two methods of hypothesis testing - Permutations and Randomization Test.

#### Permutations Test

Permutations test is a non-parametric test that is used to test the null hypothesis that two groups of data are drawn from the same population. This test is useful when the assumptions of the parametric tests are not met.

The steps involved in conducting a permutations test are as follows:

1. Define the null hypothesis and alternative hypothesis.
2. Calculate the test statistic for the observed data.
3. Randomly permute the data and calculate the test statistic for each permutation.
4. Calculate the p-value as the proportion of permutations that give a test statistic at least as extreme as the observed data.
5. If the p-value is less than the significance level, reject the null hypothesis. Otherwise, fail to reject the null hypothesis.

#### Randomization Test

Randomization test is another non-parametric test that is used to test the null hypothesis that there is no difference between two groups of data. This test is useful when the assumptions of the parametric tests are not met.

The steps involved in conducting a randomization test are as follows:

1. Define the null hypothesis and alternative hypothesis.
2. Calculate the test statistic for the observed data.
3. Randomly assign the data to two groups and calculate the test statistic for each random assignment.
4. Calculate the p-value as the proportion of random assignments that give a test statistic at least as extreme as the observed data.
5. If the p-value is less than the significance level, reject the null hypothesis. Otherwise, fail to reject the null hypothesis.

In conclusion, Permutations and Randomization Test are non-parametric tests that are useful when the assumptions of the parametric tests are not met. These tests are used to test the null hypothesis that there is no difference between two groups of data. By using these tests, we can draw conclusions about a population based on a sample.
