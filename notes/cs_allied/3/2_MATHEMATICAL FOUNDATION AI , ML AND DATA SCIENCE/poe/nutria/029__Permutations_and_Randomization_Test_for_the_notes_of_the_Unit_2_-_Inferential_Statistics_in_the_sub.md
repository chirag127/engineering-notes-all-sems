
### Permutations and Randomization Test

* Permutations are arrangements of a set of items in a specific order. It is a way to rearrange the elements of a set in all possible ways. For example, if we have three items A, B, and C, then the permutations can be ABC, ACB, BAC, BCA, CAB, and CBA. 

* Randomization tests are statistical tests that use random samples to test a hypothesis. The idea is to generate a large number of random samples and compare the results to the expected outcome. This type of test is used to evaluate the validity of a hypothesis and to determine if the results are due to chance or if there is a significant difference between the observed and expected results.

* In the context of inferential statistics, the use of permutations and randomization tests can be used to determine the probability of a certain outcome. For example, if we have a set of data points, we can use randomization tests to determine the probability of a certain outcome. We can also use permutations to determine the probability of a certain outcome.

* Permutations and randomization tests are also used to determine the significance of a certain result. For example, if we have a set of data points, we can use randomization tests to determine if the observed results are significantly different from the expected results. We can also use permutations to determine if the observed results are significantly different from the expected results.
