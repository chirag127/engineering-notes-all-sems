## Unit 4 - Vector Spaces

Vector spaces are mathematical structures used to describe and analyze linear relationships between objects.

1. Definition: Vector spaces are mathematical structures used to describe and analyze linear relationships between objects. A vector space is a set of vectors that can be added and scaled, and is equipped with the operations of addition and scalar multiplication.

2. Properties: Vector spaces have several properties, including the existence of a zero vector, the existence of additive inverses, and the distributive property of scalar multiplication.

3. Basis: A basis is a set of vectors that can be used to represent any vector in the vector space. The dimension of a vector space is the number of vectors in a basis for the vector space.

4. Inner Product: An inner product is a scalar valued function that takes two vectors as input and returns a scalar. Inner products are used to define the length and angle between vectors in a vector space.

5. Norm: A norm is a scalar valued function that takes a vector as input and returns a scalar. Norms are used to define the length of a vector in a vector space.

6. Orthogonality: Orthogonality refers to the property of two vectors being perpendicular to each other. Orthogonality is an important concept in vector spaces as it is used to define orthogonal bases and orthogonal projections.

7. Applications: Vector spaces are used in a wide range of applications in mathematics, engineering, and computer science. Vector spaces are used in fields such as linear algebra, functional analysis, and machine learning.

Limitations: Despite their wide range of applications, vector spaces also have several limitations, including the difficulty of defining vector spaces for non-linear relationships, the difficulty of defining vector spaces for non-numeric objects, and the difficulty of defining vector spaces for infinite dimensional objects.
