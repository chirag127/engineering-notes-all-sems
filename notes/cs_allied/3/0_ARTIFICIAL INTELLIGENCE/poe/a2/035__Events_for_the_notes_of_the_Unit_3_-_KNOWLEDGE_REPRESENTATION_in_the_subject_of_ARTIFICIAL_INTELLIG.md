### Events for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Propositional Logic
- Atomic propositions: Simple statements that are either true or false.
- Connectives: AND, OR, NOT, IF-THEN, etc. are used to combine propositions.
- Well-formed formula: Propositional logic formula created using propositions and connectives that follows the syntax rules.
- Truth table: Shows the output truth value for all possible combinations of truth values of propositions in a well-formed formula.

2. First-Order Logic
- Terms: Refer to objects in the domain of discourse.
- Variables: Placeholders for terms whose values can change.
- Predicates: Express properties of or relations between terms.
- Quantifiers: ALL, EXISTS are used to specify the scope of variables.
- Sentences: Well-formed formulas that can be true or false.
- Proof: Step-by-step derivation of a conclusion from premises.

3. Rules of Inference
- Modus ponens: If P implies Q and P is true, then Q must be true.
- Modus tollens: If P implies Q and Q is false, then P must be false.
- Hypothetical syllogism: If P implies Q and Q implies R, then P implies R.
- Disjunctive syllogism: If P or Q is true, and P is false, then Q must be true.
