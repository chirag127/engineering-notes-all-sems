### Problem Solving Approach to Typical AI problems for the notes of the Unit 1 - INTRODUCTION in the subject of ARTIFICIAL INTELLIGENCE KCS:

1. Understanding the problem: First step is to understand the problem statement clearly. Some questions to ask are:
- What is the exact problem?
- What is the input? What is the output?
- Is the input clearly defined? Is the output clearly defined?
- Are there any constraints or limitations?
- Is the problem statement complete or do you need more information?

2. Representing the problem: Once the problem is understood, it needs to be represented in a form that can be used by the computer to solve. Some ways to represent the problem are:
- Logically as a set of statements.
- Mathematically as a function or set of equations.
- In a form of data like graphs, tables.

3. Choosing a strategy or algorithm: After representing the problem, choose a strategy or algorithm to solve the problem. Some options are:
- Searching through all possible solutions (brute-force)
- Applying problem-specific heuristics or rules of thumb
- Finding an optimal solution (using optimization techniques)
- Dividing the problem into smaller sub-problems and solving each sub-problem (divide and conquer)
- Pattern matching or learning based on examples (machine learning)

4. Implementing the solution: The chosen algorithm or strategy is implemented in a programming language to get the solution.

5. Evaluating and analysis: The solution is evaluated based on the defined objectives and constraints. The performance of the algorithm or technique is analyzed to find ways to improve the solution if required.
