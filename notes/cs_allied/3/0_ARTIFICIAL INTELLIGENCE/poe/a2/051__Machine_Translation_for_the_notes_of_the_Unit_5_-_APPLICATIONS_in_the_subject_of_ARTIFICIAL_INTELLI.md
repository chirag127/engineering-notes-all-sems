### Machine Translation for the notes of the Unit 5 - APPLICATIONS in the subject of ARTIFICIAL INTELLIGENCE KCS.

* Machine Translation is the task of automatically converting source language text into target language text.
* It makes use of computer software to translate text or speech from one natural language to another.
* The key goal is to enable communication between speakers of different languages.
* The quality of machine translation has improved in recent years with the use of neural networks, especially the Transformer architecture.
* However, machine translation still suffers from imperfections such as incorrect translations, nonsensical language, and biased or offensive language.
* Human evaluation and post-editing are often needed to ensure high-quality translation.
* Some examples of machine translation applications are Google Translate, Bing Translator, etc.
* The main steps involved in machine translation are:
* Analysis: Break input into linguistic components
* Transfer: Match components to appropriate target language equivalents
* Generation: Synthesize the target language components into fluent output
* The approaches used are rule-based, statistical and neural machine translation.
* Neural machine translation has achieved significant improvements in accuracy over statistical and rule-based approaches.
