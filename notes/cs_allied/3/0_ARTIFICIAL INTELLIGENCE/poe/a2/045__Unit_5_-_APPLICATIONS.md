## Unit 5 - APPLICATIONS

1. Application software is designed to perform a specific task other than one relating to the computer system itself.
- Examples include word processors, spreadsheets, database software, multimedia players, etc.

2. Word processing software is used to produce letters, documents, reports, etc.
- Features include fonts, font sizes, page layout, spell check, grammar check, etc.
- Popular examples are Microsoft Word, OpenOffice Writer, etc.

3. Spreadsheet software is used for numeric calculations and data analysis.
- Data is organized in rows and columns.
- Formulas can be used to manipulate and calculate numerical data.
- Examples are Microsoft Excel, OpenOffice Calc, Google Sheets, etc.

4. Presentation software is used to create slideshows for the purpose of presentations.
- Slides may contain text, images, graphics, animations, etc.
- Examples are Microsoft PowerPoint, OpenOffice Impress, Google Slides, etc.

5. Multimedia software is used to create and edit images, audio and video.
- Examples are photo editing software like Photoshop, video editing software like iMovie or Adobe Premiere Pro, audio editing software, etc.

6. Database software is used to create and manage databases.
- Data is organized in tables with rows and columns.
- Queries are used to retrieve specific data.
- Examples are Microsoft Access, MySQL, Oracle Database, etc.
