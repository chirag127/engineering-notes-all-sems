
### Backward Chaining for the Notes of the Unit 3 - Knowledge Representation in the Subject of Artificial Intelligence KCS

1. Backward Chaining is a form of reasoning used in Artificial Intelligence (AI) that is used to find a solution to a problem by working backwards from the goal. 
2. It is a type of goal-driven reasoning that starts with the goal and works backwards to find the solution.
3. Backward Chaining is often used in AI to solve problems that involve a lot of variables and conditions.
4. It is a type of logic-based approach that uses a set of rules to deduce the solution.
5. The rules are used to determine the order in which the variables should be explored in order to reach the goal.
6. In order to use Backward Chaining, the problem must be represented as a set of predicates.
7. The predicates are then used to form a set of rules that can be used to find the solution.
8. Backward Chaining is used in AI to solve problems such as game playing, natural language processing, and robotics.
