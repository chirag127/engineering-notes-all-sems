### Uninformed Search

Uninformed search, also known as blind search, is a type of search algorithm used in Artificial Intelligence for traversing and searching tree or graph data structures. It is called "uninformed" because it does not have any additional information about the states beyond what is provided in the problem definition. 

Some common types of uninformed search algorithms include:
1. Breadth-first search: This algorithm expands the shallowest node in the search tree first.
2. Depth-first search: This algorithm expands the deepest node in the search tree first.
3. Uniform-cost search: This algorithm expands the node with the lowest path cost first.
4. Iterative deepening depth-first search: This algorithm combines the benefits of depth-first search and breadth-first search by gradually increasing the depth limit of a depth-first search.

Uninformed search algorithms are generally not very efficient, as they may have to explore a large portion of the search space before finding a solution. However, they are guaranteed to find a solution if one exists. They are often used as a last resort when other, more informed search algorithms are not applicable.
