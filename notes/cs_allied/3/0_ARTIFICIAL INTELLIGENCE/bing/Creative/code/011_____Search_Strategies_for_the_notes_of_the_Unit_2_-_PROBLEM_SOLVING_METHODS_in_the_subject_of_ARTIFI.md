### Search Strategies

- A search strategy is a method for finding a solution to a problem by exploring the space of possible states and actions.
- A search strategy consists of two components: a search algorithm and a search data structure.
- A search algorithm is a procedure that determines which state to expand next and which actions to apply to reach a new state.
- A search data structure is a way of organizing the states that have been visited or are waiting to be visited by the search algorithm.
- There are different types of search strategies, depending on how they select the next state to expand, how they store the states, and whether they use additional information to guide the search.
- Some common types of search strategies are:

  - Uninformed search: These are search strategies that do not use any domain-specific knowledge or heuristics to guide the search. They only use the problem definition and the goal test to determine whether a state is a solution or not. Examples of uninformed search are breadth-first search, depth-first search, uniform-cost search, and iterative deepening search.
  - Informed search: These are search strategies that use some domain-specific knowledge or heuristics to guide the search. They estimate the cost or the likelihood of reaching a solution from a given state, and use this information to select the most promising state to expand next. Examples of informed search are greedy search, A* search, hill-climbing search, and beam search.
  - Local search: These are search strategies that do not keep track of the path or the history of the states that have been visited. They only maintain a current state and try to improve it by applying some local changes or moves. They are useful for finding approximate solutions to optimization problems, where the goal is to find the best state according to some objective function. Examples of local search are simulated annealing, genetic algorithms, and tabu search.
