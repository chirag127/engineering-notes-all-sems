### Problem solving Methods

- Problem solving methods are general strategies or techniques that can be applied to different types of problems in artificial intelligence.
- Problem solving methods can be classified into two categories: **search-based methods** and **knowledge-based methods**.
- Search-based methods involve exploring a large space of possible solutions or actions, and finding the optimal or satisfactory one based on some criteria or objective function.
- Knowledge-based methods involve using domain-specific knowledge or rules to guide the problem solving process, and reduce the search space or complexity of the problem.
- Some examples of search-based methods are:
  - **Blind search methods**: These methods do not use any information about the problem domain, and rely on brute-force or random exploration of the search space. Examples are breadth-first search, depth-first search, iterative deepening search, etc.
  - **Heuristic search methods**: These methods use some heuristic function or estimate of the cost or value of each state or action, and try to find the most promising or optimal solution. Examples are best-first search, hill climbing, simulated annealing, genetic algorithms, etc.
  - **Adversarial search methods**: These methods deal with problems that involve multiple agents or players, and try to find the best strategy or move for each agent, taking into account the possible actions and responses of the other agents. Examples are minimax, alpha-beta pruning, expectimax, etc.
- Some examples of knowledge-based methods are:
  - **Rule-based methods**: These methods use a set of rules or facts that describe the problem domain, and apply logical inference or deduction to derive new facts or conclusions. Examples are forward chaining, backward chaining, resolution, etc.
  - **Constraint satisfaction methods**: These methods use a set of variables, domains, and constraints that define the problem, and try to find an assignment of values to the variables that satisfies all the constraints. Examples are backtracking, arc consistency, local search, etc.
  - **Planning methods**: These methods use a representation of the initial state, the goal state, and the possible actions or operators that can change the state, and try to find a sequence of actions that leads from the initial state to the goal state. Examples are STRIPS, partial-order planning, hierarchical task network planning, etc.
