### Events

- Events are one of the types of knowledge representation that can be used to model dynamic aspects of the world, such as actions, processes, and changes of state.
- Events can be represented as structured objects that have attributes such as type, participants, time, location, preconditions, effects, and causal relations.
- Events can be organized into hierarchies or scripts that capture the typical sequences and scenarios of events that occur in a domain.
- Events can be learned from text corpora using natural language processing techniques, such as event extraction, event coreference, and event representation learning.
- Events can be enhanced with external commonsense knowledge, such as the intents and emotions of the event participants, the norms and expectations of the society, and the background knowledge of the domain.
- Events can be used for various artificial intelligence tasks, such as event prediction, event summarization, event causality analysis, and event-based reasoning.
