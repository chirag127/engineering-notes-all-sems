### Uninformed Search Methods in Artificial Intelligence

Uninformed search methods are also known as blind search methods. They are search algorithms that do not use any additional information about the problem domain, other than the problem definition itself. They only differentiate between goal and non-goal states, and explore the search space in a systematic, but blind, manner. They do not consider the cost of reaching the goal or the likelihood of finding a solution.

Some of the key features of uninformed search methods are:

- Systematic exploration: Uninformed search methods explore the search space systematically, either by expanding all children of a node (e.g. breadth-first search) or by exploring as deep as possible in a single path before backtracking (e.g. depth-first search).
- No heuristics: Uninformed search methods do not use any additional information, such as heuristics or cost functions, to guide the search process. They rely only on the problem definition and the search strategy.
- Completeness: Uninformed search methods are guaranteed to find a solution if one exists, as long as the search space is finite and the branching factor is bounded. However, this may take a long time or a lot of memory, depending on the size and complexity of the problem.
- Optimality: Uninformed search methods are not guaranteed to find the optimal solution, unless the search strategy is uniform-cost search, which expands the nodes with the lowest path cost first. Other uninformed search methods may find a suboptimal solution or a solution with a higher cost.

Some of the common uninformed search methods are:

- Breadth-first search: It is a search algorithm that expands the nodes in a level-by-level order, starting from the root node. It uses a queue data structure to store the nodes to be expanded. It is complete and optimal for problems with a constant step cost, but it may consume a lot of memory and time for problems with a large branching factor or a deep solution.
- Depth-first search: It is a search algorithm that explores the nodes in a depth-first order, starting from the root node. It uses a stack data structure to store the nodes to be expanded. It is not complete, as it may get stuck in an infinite loop or a dead end, and it is not optimal, as it may find a suboptimal solution or a solution with a higher cost. However, it is more memory-efficient than breadth-first search, as it only stores the nodes along the current path.
- Uniform-cost search: It is a search algorithm that expands the nodes with the lowest path cost first, using a priority queue data structure to store the nodes to be expanded. It is complete and optimal for any problem with a positive step cost, but it may consume a lot of memory and time for problems with a large branching factor or a high-cost solution.
- Depth-limited search: It is a search algorithm that limits the depth of the search tree to a predefined limit, using a depth-first search strategy. It is not complete, as it may miss a solution that is deeper than the limit, and it is not optimal, as it may find a suboptimal solution or a solution with a higher cost. However, it avoids the problem of infinite loops or dead ends that depth-first search may encounter, and it is more memory-efficient than breadth-first search.
- Iterative deepening search: It is a search algorithm that combines the advantages of breadth-first search and depth-first search, by performing a series of depth-limited searches with increasing depth limits, until a solution is found or the search space is exhausted. It is complete and optimal for problems with a constant step cost, and it is more memory-efficient than breadth-first search, as it only stores the nodes along the current path. However, it may repeat some work by expanding the same nodes multiple times.
