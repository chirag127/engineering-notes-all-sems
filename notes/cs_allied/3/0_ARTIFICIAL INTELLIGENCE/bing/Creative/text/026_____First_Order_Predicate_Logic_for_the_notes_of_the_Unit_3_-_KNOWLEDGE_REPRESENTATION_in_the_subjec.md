### First Order Predicate Logic

- First order predicate logic (FOPL) is a formal system of logic that allows the representation of complex sentences and relations using predicates, quantifiers, and variables.
- A predicate is a symbol that denotes a property or a relation of one or more objects. For example, `P(x)` means that object `x` has property `P`, and `R(x,y)` means that objects `x` and `y` are related by relation `R`.
- A quantifier is a symbol that expresses how many objects in a domain satisfy a predicate or a relation. There are two main types of quantifiers: universal (`∀`) and existential (`∃`). For example, `∀x P(x)` means that all objects in the domain have property `P`, and `∃x P(x)` means that there exists at least one object in the domain that has property `P`.
- A variable is a symbol that can take any value from a domain of objects. Variables are usually denoted by lowercase letters such as `x`, `y`, `z`, etc. For example, `P(x)` means that some object `x` has property `P`, but the value of `x` is not specified.
- A constant is a symbol that denotes a specific object in the domain. Constants are usually denoted by uppercase letters such as `A`, `B`, `C`, etc. For example, `P(A)` means that the object `A` has property `P`.
- A term is either a variable or a constant. Terms are used to refer to objects in the domain.
- An atomic formula is a predicate applied to one or more terms. For example, `P(x)`, `R(x,y)`, and `Q(A,B)` are atomic formulas.
- A formula is either an atomic formula or a complex formula. A complex formula is formed by applying logical connectives (such as `¬`, `∧`, `∨`, `→`, `↔`) and quantifiers to other formulas. For example, `¬P(x)`, `P(x) ∧ Q(x)`, `∀x (P(x) → Q(x))`, and `∃x ∃y (R(x,y) ∧ ¬R(y,x))` are formulas.
- A sentence is a formula that has no free variables. A free variable is a variable that is not bound by a quantifier. For example, `P(x)` is not a sentence because `x` is a free variable, but `∀x P(x)` is a sentence because `x` is bound by the universal quantifier.
- A model is a structure that assigns a domain of objects, a value to each constant, and an interpretation to each predicate. A model satisfies a sentence if the sentence is true under the model. For example, a model for the sentence `∀x (P(x) → Q(x))` could be a domain of natural numbers, a value of `2` for the constant `A`, and an interpretation of `P(x)` as "x is even" and `Q(x)` as "x is divisible by 4". This model satisfies the sentence because for every even number, it is also divisible by 4.
- A sentence is valid if it is satisfied by every model. A sentence is satisfiable if it is satisfied by some model. A sentence is unsatisfiable if it is satisfied by no model. For example, `∀x P(x) ∨ ¬P(x)` is valid, `∃x P(x)` is satisfiable, and `∀x P(x) ∧ ¬P(x)` is unsatisfiable.
- A sentence is a logical consequence of a set of sentences if every model that satisfies the set also satisfies the sentence. For example, `Q(A)` is a logical consequence of the set `{P(A), ∀x (P(x) → Q(x))}` because every model that makes `P(A)` and `∀x (P(x) → Q(x))` true also makes `Q(A)` true.
- A set of sentences is consistent if there is a model that satisfies all the sentences in the set. A set of sentences is inconsistent if there is no such model. For example, the set `{P(A), ¬P(A)}` is inconsistent because there is no model that can make both `P(A)` and `¬P(A)` true.
