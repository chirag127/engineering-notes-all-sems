### Reasoning with Default Information

- Reasoning with default information is a form of non-monotonic reasoning that allows for drawing plausible conclusions from incomplete or uncertain information, based on general rules that may have exceptions .
- Non-monotonic reasoning is a type of reasoning that does not follow the principle of monotonicity, which states that adding new information to a set of premises cannot reduce the set of conclusions that can be derived from them. In other words, non-monotonic reasoning allows for revising or retracting conclusions when new information contradicts or invalidates them .
- Reasoning with default information is useful in artificial intelligence because it can model common sense reasoning, where humans often make assumptions or inferences based on typical or normal situations, but are willing to change their minds when they encounter exceptions or anomalies .
- One of the most influential formalisms for reasoning with default information is default logic, proposed by Raymond Reiter in 1980 . Default logic consists of a set of facts (the background theory) and a set of default rules, each of which has the form:

  - :bird: → :flies:
  - :bird: :penguin: → ¬:flies:

  The first rule means that if something is a bird, then normally it flies. The second rule means that if something is a bird and a penguin, then normally it does not fly. The symbol → denotes the default implication, which is weaker than the classical implication (⇒). The symbol ¬ denotes the classical negation.

  A default rule can be applied to a set of facts if its prerequisite (the part before the arrow) is consistent with the facts, and its justification (the part after the arrow) is consistent with the facts and the normality assumption. The normality assumption states that nothing is known to be abnormal unless there is evidence to the contrary. For example, the first rule can be applied to the fact that Tweety is a bird, because :bird: is consistent with :bird: Tweety, and :flies: is consistent with :bird: Tweety and the normality assumption. The second rule cannot be applied to the fact that Tweety is a bird, because :bird: :penguin: is not consistent with :bird: Tweety.

  Applying a default rule to a set of facts extends the set of facts with the conclusion of the rule. For example, applying the first rule to the fact that Tweety is a bird extends the set of facts with the conclusion that Tweety flies. A set of facts that is closed under the application of default rules is called a default extension. A default extension represents a possible world that is consistent with the facts and the default rules. There may be more than one default extension for a given set of facts and default rules, depending on which rules are applied and in which order. For example, if we add the fact that Tweety is a penguin, then there are two default extensions: one where Tweety flies (by applying the first rule before the second rule) and one where Tweety does not fly (by applying the second rule before the first rule).

  A default extension is said to be skeptical if it contains only the conclusions that are common to all default extensions. A default extension is said to be credulous if it contains any conclusion that is possible in some default extension. For example, the skeptical default extension for the facts that Tweety is a bird and a penguin is empty, because there is no conclusion that is common to both default extensions. The credulous default extension for the same facts is the union of both default extensions, which contains both the conclusion that Tweety flies and the conclusion that Tweety does not fly.

  Reasoning with default logic can be done by finding the default extensions for a given set of facts and default rules, and then checking whether a query is entailed by a skeptical or a credulous default extension. For example, the query :flies: Tweety is entailed by a credulous default extension, but not by a skeptical default extension. The query ¬:flies: Tweety is also entailed by a credulous default extension, but not by a skeptical default extension. The query :bird: Tweety is entailed by both a skeptical and a credulous default extension.
