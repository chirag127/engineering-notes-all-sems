### Prolog Programming for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

- Prolog stands for **programming in logic** . It is a declarative language, which means that a program consists of data based on the facts and rules (logical relationships) rather than computing how to find a solution.
- Prolog has its roots in **first-order logic**, a formal logic, and unlike many other programming languages, Prolog is intended primarily as a **declarative programming language**: the program logic is expressed in terms of relations, represented as facts and rules. A computation is initiated by running a query over these relations.
- Prolog programming means programming in logic to be used in the **computational semantic**. The prolog programming is based on the fact and rules of the data-based language. A prolog programming is a logical relationship and data-related works for advanced computational technology.
- Prolog programming is based on three main concepts: **unification**, **backtracking**, and **recursion**.
  - Unification: The basic idea is, can the given terms be made to represent the same structure. Unification is the process of finding a substitution that makes two terms identical.
  - Backtracking: When a task fails, prolog traces backwards and tries to satisfy previous task. Backtracking is the mechanism that allows prolog to explore alternative solutions when the current one fails.
  - Recursion: Recursion is the basis for any search in program. Recursion is the technique of defining a predicate in terms of itself, using a base case and a recursive case.
- Prolog programming can be used for various applications, such as **artificial intelligence**, **natural language processing**, **expert systems**, **database management**, **game development**, and **web development**  . Prolog programming can also be used for **knowledge representation**, which is the process of encoding information about a domain in a form that can be manipulated by a computer system. Prolog programming can represent knowledge using facts, rules, variables, constants, and predicates.
