### Informed Search

Informed search is a type of problem-solving technique in artificial intelligence that uses additional information or heuristics to guide the search process towards the goal state. Informed search algorithms are also called heuristic search algorithms, as they use a heuristic function to estimate the cost or distance from the current state to the goal state. Heuristic functions are domain-specific and depend on the nature of the problem.

Some of the common informed search algorithms are:

- **Best-first search**: This is a general search strategy that expands the most promising node according to a given heuristic function. It uses a priority queue to store the nodes, where the priority is determined by the heuristic value. Best-first search can be seen as a combination of depth-first search and breadth-first search, as it explores both the depth and the breadth of the search space, but with a preference for nodes with lower heuristic values.
- **Greedy best-first search**: This is a special case of best-first search that always chooses the node with the lowest heuristic value, regardless of the cost or distance from the start node. Greedy best-first search is not optimal, as it may get stuck in local minima or dead ends, but it is fast and efficient in finding a solution if one exists.
- **A* search**: This is another special case of best-first search that combines the heuristic value with the actual cost or distance from the start node. A* search always chooses the node with the lowest value of f(n) = g(n) + h(n), where g(n) is the cost from the start node to node n, and h(n) is the heuristic value of node n. A* search is optimal and complete, meaning that it will find the best solution if one exists, and it will terminate if there is no solution. A* search is also admissible, meaning that it will never overestimate the cost of the optimal solution. However, A* search can be memory-intensive, as it may need to store a large number of nodes in the priority queue.
- **Iterative deepening A* (IDA*) search**: This is a variation of A* search that uses a depth-first search with a dynamically changing depth limit. The depth limit is initially set to the heuristic value of the start node, and it is increased whenever the search reaches a node with a higher f(n) value than the limit. IDA* search is also optimal, complete, and admissible, but it uses less memory than A* search, as it only stores the nodes along the current path. However, IDA* search may need to revisit the same nodes multiple times, as it expands them with different depth limits.
- **Recursive best-first search (RBFS)**: This is another variation of A* search that uses a recursive depth-first search with a dynamically changing f-limit. The f-limit is initially set to infinity, and it is updated whenever the search reaches a node with a higher f(n) value than the limit. RBFS also uses less memory than A* search, as it only stores the nodes along the current path and the best alternative node for each level of the search tree. However, RBFS may also need to revisit the same nodes multiple times, as it backtracks and re-expands them with different f-limits.
