### Problem Solving Methods

- Problem solving is the process of finding a solution to a given problem that satisfies some criteria of optimality, efficiency, and correctness.
- In artificial intelligence, problem solving often involves investigating potential solutions to problems through reasoning techniques, making use of polynomial and differential equations, and carrying them out and use modelling frameworks.
- A same problem may have multiple solutions, that are all accomplished using a unique algorithm.
- Problem solving methods in AI can be classified into two main categories: search algorithms and knowledge-based methods.

#### Search Algorithms
- Search algorithms are one of the common methods to solve problems in AI.
- The problem solving or rational agents with search algorithms are used to find the best optimal solution.
- This type of problem-solving technique is often called goal-based.
- Search algorithms in AI can be further divided into two types: uninformed search and informed search.
- Uninformed search algorithms do not use any domain-specific knowledge or heuristic function to guide the search. They only use the problem definition and the goal state to explore the search space. Examples of uninformed search algorithms are breadth-first search, depth-first search, uniform-cost search, and iterative deepening search.
- Informed search algorithms use some domain-specific knowledge or heuristic function to guide the search. They estimate the cost or distance of reaching the goal state from each node in the search space and select the most promising node to expand. Examples of informed search algorithms are greedy search, A* search, hill-climbing search, and beam search.

#### Knowledge-Based Methods
- Knowledge-based methods are another type of problem solving methods in AI.
- They use symbolic representations of the problem domain and the problem instance to reason about the possible solutions.
- They often rely on logic, rules, ontologies, and inference mechanisms to derive conclusions from the given facts and assumptions.
- Knowledge-based methods can be further divided into two types: declarative methods and procedural methods.
- Declarative methods use a declarative language to specify the problem domain and the problem instance. They do not specify how to solve the problem, but rather what the problem is and what the desired solution is. Examples of declarative methods are logic programming, constraint programming, and answer set programming.
- Procedural methods use a procedural language to specify the problem domain and the problem instance. They also specify how to solve the problem, by providing a sequence of steps or actions to reach the goal state. Examples of procedural methods are planning, scheduling, and game playing.
