### Typical Intelligent Agents

- An **intelligent agent** is an entity that makes a decision, that enables artificial intelligence to be put into action.
- It can also be described as a software entity that conducts operations in the place of users or programs after sensing the environment.
- It uses **sensors** to perceive the environment and **actuators** to initiate action in that environment.
- In addition, intelligent agents may **learn** from the environment to achieve their goals.
- Intelligent agents in artificial intelligence are closely related to agents in economics, and versions of the intelligent agent paradigm are studied in cognitive science, ethics, the philosophy of practical reason, as well as in many interdisciplinary socio-cognitive modeling and computer social simulations.
- Driverless cars and the Siri virtual assistant are examples of intelligent agents in AI.

#### Types of Intelligent Agents

- There are different types of intelligent agents based on their degree of rationality, autonomy, learning ability, and interaction with other agents.
- Some of the common types of intelligent agents are:

  - **Simple reflex agents**: These agents act based on the current state of the environment, without considering the consequences of their actions or the history of the environment. They use condition-action rules to select an action based on the perceived state. For example, a vacuum cleaner agent that cleans the dirt when it senses it.
  - **Model-based reflex agents**: These agents act based on the current state of the environment and an internal model of the environment that they maintain. They use condition-action rules to select an action based on the perceived state and the model. For example, a vacuum cleaner agent that cleans the dirt when it senses it and avoids obstacles based on its model of the room.
  - **Goal-based agents**: These agents act based on the current state of the environment, an internal model of the environment, and a goal or set of goals that they want to achieve. They use search and planning techniques to select an action that leads to the goal state. For example, a chess-playing agent that selects a move that maximizes the chances of winning.
  - **Utility-based agents**: These agents act based on the current state of the environment, an internal model of the environment, a goal or set of goals that they want to achieve, and a utility function that measures how desirable a state is. They use search and planning techniques to select an action that maximizes the expected utility. For example, a stock-trading agent that selects a portfolio that maximizes the expected profit.
  - **Learning agents**: These agents act based on the current state of the environment, an internal model of the environment, a goal or set of goals that they want to achieve, a utility function that measures how desirable a state is, and a learning component that improves the agent's performance over time. They use feedback from the environment and their own actions to update their model, goal, utility function, or action selection mechanism. For example, a self-driving car that learns from its own driving experience and adapts to different road conditions.
