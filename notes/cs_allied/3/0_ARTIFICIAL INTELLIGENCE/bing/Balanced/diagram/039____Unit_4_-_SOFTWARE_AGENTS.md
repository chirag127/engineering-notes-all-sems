## Unit 4 - SOFTWARE AGENTS

- A software agent is a computer program that acts for a user or another program in a relationship of agency.
- A software agent can perform various actions continuously and autonomously on behalf of an individual or an organization.
- A software agent can activate and run itself, not requiring input from or interaction with a human user.
- A software agent can learn from its experience in functioning in an environment over a long period of time.
- Examples of software agents are:
  - Web crawlers that index web pages for search engines.
  - Chatbots that converse with human users via natural language.
  - Personal assistants that manage tasks, schedules, and information for users.
  - Recommender systems that suggest products, services, or content to users based on their preferences and behavior.
  - Malware that infects, damages, or steals data from computers or networks.
