### Architecture for Intelligent Agents

- An **intelligent agent** is a system that perceives its environment via sensors and acts rationally upon that environment with its effectors.
- The **architecture** of an agent describes its modules and capabilities, and how these operate together.
- The architecture determines how the agent function, which maps percepts to actions, is implemented in the agent program, which runs on the agent hardware.
- There are different types of architectures for intelligent agents, depending on their level of complexity, rationality, and interaction.
- Some of the common architectures are:

  - **Reactive architectures**: These are the simplest architectures for agents. They consist of a mapping between stimulus and response, without any internal state or decision-making skills. The agent only reacts to the current percept, ignoring the history or the future. Examples of reactive agents are thermostats, vending machines, and obstacle-avoiding robots.
  - **Model-based reflex architectures**: These are more sophisticated architectures that incorporate an internal state or model of the environment, which is updated based on the percepts. The agent can use this model to choose the best action according to some rules or condition-action pairs. The agent is still reactive, but can handle partially observable environments better than reactive agents. Examples of model-based reflex agents are taxi drivers, chess players, and vacuum cleaners.
  - **Goal-based architectures**: These are architectures that extend the model-based reflex architectures by adding a set of goals or objectives that the agent wants to achieve. The agent can use its model of the environment and its goals to search for the best sequence of actions that leads to the desired outcome. The agent is more flexible and rational than model-based reflex agents, but also more complex and computationally demanding. Examples of goal-based agents are planning robots, route finders, and game players.
  - **Utility-based architectures**: These are architectures that further refine the goal-based architectures by assigning a utility or preference value to each state or outcome. The agent can use its model of the environment and its utility function to evaluate the expected utility of each action and choose the one that maximizes its utility. The agent is more realistic and adaptable than goal-based agents, but also more difficult to design and implement. Examples of utility-based agents are stock traders, medical diagnosis systems, and recommender systems.
  - **Learning architectures**: These are architectures that enable the agent to improve its performance over time by learning from its experience. The agent can use various learning techniques, such as reinforcement learning, supervised learning, or unsupervised learning, to update its model, rules, goals, or utility function based on the feedback or data it receives. The agent is more intelligent and autonomous than utility-based agents, but also more challenging and uncertain. Examples of learning agents are self-driving cars, natural language processors, and image classifiers.
  - **Logical architectures**: These are architectures that use logic as the main representation and reasoning tool for the agent. The agent can use various logic languages, such as propositional logic, first-order logic, or modal logic, to encode its knowledge, beliefs, desires, and intentions, and to infer the best action based on logical rules and proofs. The agent is more expressive and formal than learning agents, but also more limited and complex. Examples of logical agents are theorem provers, expert systems, and DALI agents.
  - **Interacting architectures**: These are architectures that allow the agent to communicate and cooperate with other agents or humans. The agent can use various interaction protocols, such as speech acts, negotiation, or coordination, to exchange information, requests, or commitments with other parties. The agent is more social and collaborative than logical agents, but also more dependent and diverse. Examples of interacting agents are chatbots, multi-agent systems, and social robots.
