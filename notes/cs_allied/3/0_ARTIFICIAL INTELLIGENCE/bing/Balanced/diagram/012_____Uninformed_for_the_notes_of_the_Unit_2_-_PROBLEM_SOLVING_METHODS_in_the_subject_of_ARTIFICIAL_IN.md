### Uninformed Search
- Uninformed search is a type of search strategy that does not use any domain-specific knowledge or heuristics to guide the search process.
- Uninformed search methods are also called blind search or brute-force search, as they explore the search space systematically without any direction or preference.
- Uninformed search methods are useful when there is no information available about the problem domain, or when the information is too complex or costly to use.
- Uninformed search methods can be classified into two categories: tree search and graph search.
  - Tree search is a search method that expands the nodes of a search tree, which is a data structure that represents the possible paths from the initial state to the goal state.
  - Graph search is a search method that expands the nodes of a search graph, which is a data structure that represents the states and actions of the problem domain, and avoids revisiting the same state more than once.
- Some of the common uninformed search methods are:
  - Breadth-first search (BFS): a search method that expands the shallowest node in the frontier, which is the set of nodes that are waiting to be explored.
  - Depth-first search (DFS): a search method that expands the deepest node in the frontier, which is the set of nodes that are waiting to be explored.
  - Uniform-cost search (UCS): a search method that expands the node with the lowest path cost from the initial state to the node, where the path cost is the sum of the costs of the actions along the path.
  - Depth-limited search (DLS): a search method that limits the depth of the search tree to a predefined value, and discards any node that exceeds the limit.
  - Iterative deepening search (IDS): a search method that performs a series of depth-limited searches with increasing depth limits, until a solution is found or the search space is exhausted.
