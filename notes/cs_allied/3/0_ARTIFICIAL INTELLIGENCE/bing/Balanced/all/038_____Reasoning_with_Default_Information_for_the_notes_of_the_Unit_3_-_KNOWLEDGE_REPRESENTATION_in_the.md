# Reasoning with Default Information

- Reasoning with default information is a form of non-monotonic reasoning that allows for drawing plausible conclusions from incomplete or uncertain information, based on general rules that may have exceptions .
- Non-monotonic reasoning is a type of reasoning that does not follow the principle of monotonicity, which states that adding new information to a set of premises cannot reduce the set of conclusions that can be derived from them.
- Reasoning with default information is useful in artificial intelligence, where the information available may be incomplete or uncertain, and where exceptions to general rules may exist .
- One of the main methods of reasoning with default information is default logic, which is based on the principle of assuming the truth of something unless there is evidence to the contrary.
- Default logic consists of a set of facts, a set of default rules, and a set of conclusions. A default rule has the form: p:q/r, which means that if p is true, then normally q is true, and therefore r can be concluded. However, this rule can be overridden if there is evidence that q is false .
- For example, a default rule could be: bird:flies/bird, which means that if something is a bird, then normally it flies, and therefore it can be concluded that it is a bird. However, this rule can be overridden if there is evidence that the thing does not fly, such as a penguin.
- A set of facts, default rules, and conclusions is called a default theory. A default theory is consistent if there is no contradiction between the facts and the conclusions. A default theory is complete if there is no default rule that can be applied to derive a new conclusion.
- A default theory may have more than one consistent and complete extension, which is a set of conclusions that can be derived from the facts and the default rules. An extension is called normal if it contains all the conclusions that can be derived by applying the default rules as much as possible.
- For example, a default theory could be: {bird(tweety), bird:flies/bird}, which means that tweety is a bird, and if something is a bird, then normally it flies, and therefore it can be concluded that it is a bird. This theory has two extensions: {bird(tweety), flies(tweety)}, which is normal, and {bird(tweety), ¬flies(tweety)}, which is not normal.
- Reasoning with default information can be applied to various domains and problems in artificial intelligence, such as default assignments to variables, the closed world assumption, the frame problem, exceptions as defaults, and negation in artificial intelligence programming languages.
