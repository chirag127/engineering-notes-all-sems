# Typical Intelligent Agents

- An **intelligent agent** is an entity that makes a decision, that enables artificial intelligence to be put into action.
- It can also be described as a software entity that conducts operations in the place of users or programs after sensing the environment.
- It uses **sensors** to perceive the environment and **actuators** to initiate action in that environment.
- An intelligent agent may also **learn** from the environment to achieve its goals.
- Examples of intelligent agents are driverless cars, virtual assistants, chatbots, robots, etc.

## Types of Intelligent Agents

- There are different types of intelligent agents based on their degree of rationality, autonomy, learning ability, and interaction.
- Some of the common types are:

  - **Simple reflex agents**: These agents act based on the current state of the environment, without considering the history or the future consequences of their actions. They use predefined rules or condition-action pairs to decide what to do. For example, a vacuum cleaner robot that moves away from an obstacle when it senses it.
  - **Model-based reflex agents**: These agents act based on the current state of the environment as well as an internal model of the environment that they maintain. They use the model to keep track of the changes in the environment and predict the outcomes of their actions. For example, a driverless car that uses a map and a GPS to navigate the road.
  - **Goal-based agents**: These agents act based on the current state of the environment, an internal model of the environment, and a goal or set of goals that they want to achieve. They use the model and the goal to search for the best action that leads to the desired state. For example, a chess-playing program that chooses the best move to win the game.
  - **Utility-based agents**: These agents act based on the current state of the environment, an internal model of the environment, a goal or set of goals, and a utility function that measures how good each state is. They use the model, the goal, and the utility function to evaluate the possible actions and choose the one that maximizes their expected utility. For example, a stock-trading program that buys and sells shares to maximize its profit.
  - **Learning agents**: These agents act based on the current state of the environment, an internal model of the environment, a goal or set of goals, a utility function, and a learning component that allows them to improve their performance over time. They use the learning component to update their model, goal, utility function, or action selection based on their experience and feedback. For example, a virtual assistant that learns from the user's preferences and behavior to provide better service.

## Functions of Intelligent Agents

- The main functions of intelligent agents are:

  - **Perception**: This is the process of acquiring information from the environment using sensors. The information can be in the form of images, sounds, text, etc. The agent uses the information to update its internal state and model of the environment.
  - **Action**: This is the process of performing an operation in the environment using actuators. The operation can be in the form of movement, speech, display, etc. The agent uses the operation to change the state of the environment or achieve its goals.
  - **Reasoning**: This is the process of applying logic and knowledge to make decisions and solve problems. The agent uses reasoning to infer the best action to take based on the current state of the environment, its model, its goals, and its utility function.
  - **Learning**: This is the process of improving the agent's performance and adaptability based on its experience and feedback. The agent uses learning to update its model, goals, utility function, or action selection based on the outcomes of its actions and the rewards or penalties it receives.
