4. Statistical Machine Translation: Statistical machine translation is a type of machine translation that uses statistical models to translate text from one language to another. Statistical machine translation is often used for large-scale translations and for languages with limited resources.

5. Neural Machine Translation: Neural machine translation is a type of machine translation that uses deep learning algorithms to translate text from one language to another. Neural machine translation is often used for high-quality translations and for languages with limited resources.
