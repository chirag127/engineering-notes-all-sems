
### Network Protocols - Data Dissemination for Unit 1 - Big Data Platforms for the Internet of Things in KOT 061 Big Data Analytics for IoT KCS

* Network protocols refer to the rules and conventions that govern how devices connected to a network communicate with each other. 
* The most common protocols used for data dissemination in the Internet of Things are TCP/IP, HTTP, and MQTT. 
* TCP/IP (Transmission Control Protocol/Internet Protocol) is the most widely used protocol for data transmission over the internet. It is responsible for breaking down data into packets and sending them from one device to another. 
* HTTP (Hypertext Transfer Protocol) is a protocol used for transferring web pages from a server to a browser. It is used in the Internet of Things to transfer data between devices. 
* MQTT (Message Queuing Telemetry Transport) is a lightweight protocol used for sending data between devices. It is used in the Internet of Things to send data from a sensor to a server. 
* Data dissemination in the Internet of Things is an important part of the overall system. It is responsible for transferring data between devices and ensuring that the data is received in a timely manner.
