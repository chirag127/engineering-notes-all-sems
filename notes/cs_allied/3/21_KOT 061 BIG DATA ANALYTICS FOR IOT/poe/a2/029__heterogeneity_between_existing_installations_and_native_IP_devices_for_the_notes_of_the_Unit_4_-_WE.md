### Heterogeneity between existing installations and native IP devices

- Existing buildings have legacy systems and devices which are not IP-enabled. These include HVAC systems, lighting systems, security systems, etc.
- New smart buildings are employing IP-enabled or IoT-enabled devices and systems which can connect to the network and generate data.
- This heterogeneity between legacy systems and modern IP-enabled devices and systems poses integration challenges.
- Data generated by the IP-enabled devices can provide insights into energy usage, occupant behavior, device performance, etc. However, these insights are limited due to the presence of legacy devices which do not generate data.
- Retrofitting legacy devices and systems with sensors and IP-connectivity is costly and often not feasible.
- Bridging the gap between legacy and IP-enabled systems and facilitating data exchange between them is critical to realizing the full potential of IoT-enabled smart buildings.
- Some ways to enable this include:
  - Using sensor arrays and modules which can be attached to legacy devices to generate data.
  - Using sub-metering and channel-level energy monitoring techniques to derive data from legacy systems.
  - Standardization of data formats and communication protocols to facilitate integration.
  - Edge computing and middleware to translate between legacy and IP-enabled systems.
