## Unit 3 - FOG COMPUTING

1. Fog Computing: Fog computing refers to a decentralized computing infrastructure in which data, compute, storage, and applications are distributed in the most logical, efficient place between the data source and the cloud.

2. Need for Fog Computing: As IoT devices are generating huge amounts of data, it is not feasible to send all the data to the cloud for processing due to bandwidth constraints and latency issues. Fog computing tackles these challenges by providing compute, storage, and networking services between end devices and traditional cloud computing data centers.

3. Fog Computing Architecture: The fog computing architecture consists of three layers:

- End Devices Layer: This layer consists of IoT devices and sensors that generate data.
- Fog Layer: This layer consists of fog nodes that are located at the edge of the network. Fog nodes provide computing, storage, and networking resources for IoT applications.
- Cloud Layer: This layer consists of cloud data centers that provide virtually unlimited computing and storage resources.

4. Benefits of Fog Computing:
- Reduced latency: Computing is done at the edge, closer to the data source, thereby reducing latency.
- Bandwidth optimization: Only the required data is sent to the cloud, optimizing bandwidth utilization.
- Mobility support: Fog computing supports mobility of IoT devices and data.
- Location awareness: Fog computing enables location-aware IoT applications by processing data close to its source.
- Scalability: Additional fog nodes can be added to scale the fog computing infrastructure.

5. Challenges in Fog Computing:
- Heterogeneity: The fog layer consists of heterogeneous devices and platforms, making it challenging to implement a common framework.
- Limited resources: Fog nodes have limited computing, storage, and networking resources compared to cloud data centers.
- Management: Efficient management of the fog computing infrastructure and allocation of resources is challenging due to the scale and distribution of fog nodes.
- Security: The distribution of resources in fog computing poses security challenges and makes the infrastructure vulnerable to attacks.
- Reliability: Ensuring reliability and high availability of services is difficult in fog computing due to the scale and distribution of fog nodes.
