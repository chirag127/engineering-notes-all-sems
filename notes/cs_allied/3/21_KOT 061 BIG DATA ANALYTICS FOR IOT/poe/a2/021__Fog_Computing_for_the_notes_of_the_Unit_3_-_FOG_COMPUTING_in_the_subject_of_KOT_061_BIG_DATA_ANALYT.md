### Fog Computing

- Fog computing refers to extending cloud computing to the edge of the network.
- It brings computation, networking, storage and applications closer to the data sources or users.
- The key characteristics of fog computing are:
-- Low latency: Fog computing reduces latency by bringing computing resources close to the end devices that generate or act on the data.
-- Wide geographic distribution: The fog nodes are dispersed in a wide geographic area.
-- Massive numbers: There can be a very large number of fog nodes to handle the scale of end devices and data in IoT environments.
-- Heterogeneity: The fog nodes can be very diverse in terms of compute, storage and network resources. They are often embedded systems, single-board computers or small servers.
- The benefits of fog computing include:
-- Reduced network bandwidth usage: By processing data locally, fog computing reduces the amount of data that needs to be sent to the cloud.
-- Improved performance for time-critical applications: The proximity of fog nodes allows for quicker response times and reduced latency for applications that are latency-sensitive.
-- Data security and privacy: Sensitive data can be processed locally within the fog, rather than sending all data to the cloud.
-- Scalability: The large number of fog nodes helps to scale the capacity as the number of connected devices grows.
- Fog computing complements cloud computing and is increasingly being deployed alongside cloud infrastructure. It enables a new class of applications and services that harness the power of cloud resources along with the low latency, location awareness and ubiquity of the edge.
