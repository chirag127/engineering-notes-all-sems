## Unit 1 - BIG DATA PLATFORMS FOR THE INTERNET OF THINGS

1. Introduction to IoT
- IoT refers to the interconnection of everyday physical objects and appliances via the internet
- These devices are equipped with sensors, software and network connectivity that allow them to send and receive data
- IoT enables everyday objects to be sensed and controlled remotely across existing network infrastructure
- This connectivity leads to generation of massive amounts of data which can be analyzed to gain business insights and enable automation

2. Challenges with IoT Data
- IoT devices generate large volumes of data at high velocity
- The data is heterogeneous, unstructured and intermittent
- Storing and processing this data is challenging due to scale, complexity and need for real-time analysis
- Traditional data processing solutions are not suited to handle the IoT data challenges
- IoT specific big data platforms are required to ingest, store, process and analyze IoT data to derive value

3. IoT Big Data Platforms
- IoT platforms like AWS IoT, Azure IoT Suite and GE Predix provide capabilities to connect, monitor and control IoT devices
- They offer capabilities to store and process IoT data at scale using cloud based big data services
- The IoT data can be analyzed in real-time or batch mode using services like AWS Lambda, Azure Stream Analytics and Hadoop/Spark
- The analyzed data can be used to gain operational insights or build machine learning models for automation
- An IoT platform along with big data services provide a full stack solution to solve the challenges of IoT data
