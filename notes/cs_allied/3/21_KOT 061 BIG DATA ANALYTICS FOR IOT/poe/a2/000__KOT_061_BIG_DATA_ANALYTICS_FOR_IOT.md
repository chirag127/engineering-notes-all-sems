# KOT 061 BIG DATA ANALYTICS FOR IOT

1. Introduction to IoT
- IoT refers to the interconnection of physical devices, vehicles, appliances, and other items that are now being equipped with sensors, processing capabilities, and networking interfaces.
- This allows these objects to collect and exchange data.
- The IoT allows objects to be sensed and controlled remotely across existing network infrastructure.
- This creates opportunities for more direct integration between the physical world and computer-based systems.

2. IoT Data Generation
- IoT devices generate a huge amount of data.
- For example, a single jet engine can generate 10+ terabytes of data per flight.
- Autonomous cars generate approximately 4 terabytes of data per day.
- This huge amount of data generated by the enormous number of connected IoT devices is known as big data.

3. IoT Data Analysis
- The big data generated by IoT devices holds a treasure trove of information.
- By analyzing the data, organizations can gain business insights and make better business decisions.
- Data analysis techniques like data mining and machine learning are used to analyze IoT data.
- By analyzing the data, you can discover patterns and trends and get information to optimize business processes.

4. Challenges in IoT Data Analysis
- Heterogeneity: IoT data comes in different formats from various sources. Integrating and analyzing the heterogeneous data is challenging.
- Velocity: IoT data is generated at a rapid pace. This high velocity of data poses difficulties in storing and analyzing the data in real-time.
- Volume: The enormous volume of IoT data leads to scalability issues with storage and analysis.
- Variety: IoT data has a variety of types like numeric, textual, audio, and video. Analyzing the diverse data types is challenging.
- Veracity: IoT data may be unreliable, inconsistent, and incomplete. Ensuring the veracity or truthfulness of data is difficult.
