## Unit 2 - RFID FALSE AUTHENTICATIONS

1. RFID spoofing: An adversary can spoof or imitate an RFID tag to trick an RFID reader into accepting the spoofed tag as authentic. This can be done using a "replay attack" where the adversary records the data from a legitimate RFID communication and replays it to masquerade as the legitimate tag.

2. Tag cloning: The data on an RFID tag can be copied to another tag, creating a clone. The clone can then be used to fool an RFID system. Cloning requires physical access to the tag to read and copy the data, but some tags have vulnerabilities that allow cloning without physical access.

3. Relay attacks: An adversary can intercept and relay an RFID communication between a reader and a tag to make it appear that the reader and tag are directly communicating when in fact the adversary is relaying the communication. This can be used to trick a system into accepting an illegitimate tag or reader as authentic.

4. Denial of service: An adversary can interfere with RFID communications to prevent legitimate RFID transactions from occurring. This can be done using jamming, noise, or other disruption techniques that degrade the ability of readers and tags to communicate. A denial of service attack can interfere with RFID systems that expect reliable tag access.
