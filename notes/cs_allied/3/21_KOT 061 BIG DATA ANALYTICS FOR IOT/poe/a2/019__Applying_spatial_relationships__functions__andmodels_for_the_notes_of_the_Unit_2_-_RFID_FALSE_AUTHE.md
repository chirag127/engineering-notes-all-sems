### Applying spatial relationships, functions, andmodels for the notes of the Unit 2 - RFID FALSE AUTHENTICATIONS in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

1. RFID tags can be cloned or spoofed easily as they do not have any security mechanisms. This can lead to RFID false authentications where an unauthorized RFID tag is used to gain access to secure systems or data.
2. Some of the commonly used techniques for RFID false authentications are:
- Tag cloning: Copying the data of a valid RFID tag onto another tag to create a clone that can be used for unauthorized access.
- Tag spoofing: Using a device that emulates an RFID tag by transmitting data that mimics a valid tag. This device does not contain any actual RFID chip but is used to spoof receivers.
3. To prevent RFID false authentications, the following methods can be employed:
- Use of encryption techniques and cryptographic protocols to secure the communication between the RFID tag and reader.
- Use of challenge-response authentication to verify the authenticity of RFID tags. The reader sends a random challenge to the tag which responds with a valid response. If the response is correct, the tag is authenticated.
- Use of RFID tags with unique identifiers and authentication capabilities to prevent cloning and spoofing. Such tags have security features like cryptography and passwords/keys to prevent unauthorized access.
