### Current State of Art for the Notes of Unit 1 - Big Data Platforms for the Internet of Things

- The Internet of Things (IoT) refers to the interconnection of physical devices through the internet. These devices generate massive amounts of data which needs to be stored and analyzed.
- Big Data platforms are required to handle the huge volume of data generated by IoT devices. Some of the popular Big Data platforms for IoT are:
- Hadoop ecosystem: Hadoop is a distributed processing system which can store and process big data in a distributed manner across clusters of computers. Tools like HDFS, MapReduce, Hive, Pig etc. can be used to store and analyze IoT data.
- Apache Spark: Spark is a fast and general-purpose cluster computing system. It can be used to perform streaming, graph processing and machine learning on IoT data.
- Apache Flink: Flink is a framework and distributed processing engine for stateful computations over unbounded and bounded data streams. It can be used for real-time streaming analytics on IoT data.
- MongoDB: MongoDB is a document-oriented NoSQL database used for storing IoT data. It is scalable and makes schema changes easy.
- Time-series databases: Time-series databases like InfluxDB are optimized for storing and serving time-series data which is common in IoT applications. They enable efficient storage and retrieval of time-series data.
- Cloud platforms: Cloud platforms like AWS, Azure and GCP provide services to ingest, store, process and analyze IoT data at scale. They handle the infrastructural requirements and provide managed services for IoT applications.
