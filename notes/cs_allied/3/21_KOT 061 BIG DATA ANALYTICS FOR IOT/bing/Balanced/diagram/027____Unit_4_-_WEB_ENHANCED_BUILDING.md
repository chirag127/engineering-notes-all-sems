## Unit 4 - WEB ENHANCED BUILDING

- A web enhanced building is a building that uses web technologies to improve its functionality, efficiency, and user experience.
- A web enhanced building can have different levels of web integration, from web-enhanced courses to web-enhanced building automation systems.
- Web-enhanced courses are courses that use web platforms such as Blackboard to provide online access to course materials, assignments, quizzes, and communication tools. Web-enhanced courses do not replace face-to-face instruction, but complement it with online resources that are available 24/7.
- Web-enhanced building automation systems are systems that use web protocols and standards to enable interoperability and communication between different devices and sensors in a building. Web-enhanced building automation systems can provide benefits such as energy efficiency, security, comfort, and remote control .
- Some of the web technologies that can be used to enhance buildings are:
  - Internet of Things (IoT): a network of physical objects that can communicate and exchange data over the internet.
  - Web services: software components that can be accessed and invoked over the web using standard protocols such as HTTP and SOAP.
  - Semantic web: a web of data that can be understood and processed by machines using common formats and vocabularies such as RDF and OWL.
  - Web of Things (WoT): a framework that applies web principles and technologies to IoT devices, making them easier to discover, access, and control over the web.
