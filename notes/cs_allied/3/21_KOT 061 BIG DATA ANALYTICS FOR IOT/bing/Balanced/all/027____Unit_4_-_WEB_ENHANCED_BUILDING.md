## Unit 4 - WEB ENHANCED BUILDING

- Web enhanced building is a concept that integrates web technologies and building automation systems to create smart, connected and sustainable buildings.
- Web enhanced building can provide benefits such as improved energy efficiency, occupant comfort, security, safety, productivity and environmental performance.
- Web enhanced building can be achieved by using web standards, protocols, services and applications to enable communication, data exchange, control and automation among building devices, systems and users.
- Web enhanced building can be classified into three levels: web accessible, web enabled and web based.

  - Web accessible building: A building that provides basic web access to its devices and systems, such as web browsers, web servers and web pages. The web access is mainly for monitoring and visualization purposes, and does not support advanced functions such as data analysis, control and automation.
  - Web enabled building: A building that uses web technologies to enhance the functionality and interoperability of its devices and systems, such as web services, web APIs and web applications. The web technologies enable data integration, processing, analysis and visualization, as well as control and automation functions across different devices and systems.
  - Web based building: A building that fully utilizes web technologies to create a distributed, intelligent and adaptive building system, such as web of things, web semantics and web agents. The web technologies enable the building to interact with other web resources, such as cloud services, social networks and external data sources, and to learn from and adapt to the changing environment and user preferences.
