# Advantages and Achievements of Web Enhanced Building in Big Data Analytics for IoT

- Web enhanced building is a concept that uses the Internet of Things (IoT) to collect, process, and analyze data from various sensors and devices installed in a building, such as temperature, humidity, lighting, occupancy, energy consumption, etc.
- Web enhanced building can provide many benefits for building owners, managers, occupants, and the environment, such as:
  - Improved energy efficiency and reduced carbon footprint by optimizing the use of resources and minimizing waste.
  - Enhanced comfort and productivity for occupants by adjusting the indoor environment according to their preferences and needs.
  - Increased security and safety by detecting and preventing potential threats and hazards, such as fire, intrusion, leakage, etc.
  - Reduced operational and maintenance costs by identifying and resolving issues before they escalate and cause damage or downtime.
  - Increased asset value and marketability by demonstrating the performance and sustainability of the building.
- Web enhanced building can also enable new opportunities and innovations for big data analytics and IoT, such as:
  - Reusing and sharing the data across multiple applications and stakeholders, such as marketing, customer service, research, etc.
  - Applying advanced techniques and tools, such as machine learning, artificial intelligence, cloud computing, etc., to extract insights and patterns from the data and support decision making.
  - Creating interactive and dynamic dashboards and visualizations to monitor and control the building systems and devices in real time.
  - Developing new services and solutions based on the data, such as personalized recommendations, alerts, notifications, etc.
- Some examples of achievements and applications of web enhanced building in big data analytics and IoT are:
  - Azure IoT, a cloud platform that provides various services and tools to connect, manage, and analyze IoT data from smart buildings and other domains. 
  - Amazon Kinesis Firehose and Amazon QuickSight, a data streaming and visualization service that can capture, transform, and load IoT data from smart buildings and other sources into AWS and create dashboards and reports. 
  - An IoT big data analytics framework for smart buildings systems and applications, a proposed architecture that integrates IoT sensors, data storage, and analytics tools to enable real-time monitoring and analysis of smart building data. 
  - IoT-enabled big data analytics architecture for multimedia data processing and computation, a proposed model that combines IoT application development and big data analytics to process and compute multimedia data generated from IoT devices in smart buildings and other domains.
