# Toward Web Enhanced Building Automation Systems

- Building automation systems (BAS) are systems that control and monitor the mechanical, electrical, and plumbing systems of a building, such as heating, ventilation, air conditioning, lighting, security, fire alarms, etc.
- BAS are typically composed of sensors, actuators, controllers, and communication networks that enable the exchange of data and commands between the components.
- BAS can improve the energy efficiency, comfort, safety, and security of buildings, as well as reduce the operational and maintenance costs.
- However, BAS face some challenges, such as the lack of interoperability, scalability, and flexibility, the complexity of installation and configuration, and the difficulty of accessing and analyzing the data generated by the systems.
- Web enhanced building automation systems (WEBAS) are a new paradigm that aims to overcome these challenges by leveraging the technologies and standards of the web, such as HTTP, REST, JSON, XML, RDF, etc.
- WEBAS can provide the following benefits:
  - Web-based interfaces that allow users to access and control the BAS from any device and location, using common web browsers and applications.
  - Web services that expose the BAS functionalities and data as resources that can be accessed, manipulated, and integrated by other web applications and systems, using standard web protocols and formats.
  - Web of Things (WoT) that enable the discovery, description, and interaction of the BAS devices and components as things that have unique identifiers, properties, actions, and events, using semantic web technologies and ontologies.
  - Web analytics that enable the collection, storage, processing, and visualization of the BAS data, using web-based platforms and tools, such as cloud computing, big data, machine learning, etc.
- WEBAS can enhance the performance, functionality, and usability of BAS, as well as enable new applications and services, such as smart grid integration, demand response, fault detection and diagnosis, predictive maintenance, etc.
