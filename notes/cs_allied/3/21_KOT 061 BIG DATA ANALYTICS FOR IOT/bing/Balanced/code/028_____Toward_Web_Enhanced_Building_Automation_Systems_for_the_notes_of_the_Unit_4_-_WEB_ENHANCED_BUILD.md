### Toward Web Enhanced Building Automation Systems

- Building automation systems (BAS) are systems that control and monitor the mechanical, electrical and plumbing systems in a building, such as heating, ventilation, air conditioning, lighting, security, fire alarms, etc.
- BAS can improve the energy efficiency, comfort, safety and security of buildings, as well as reduce the operational and maintenance costs.
- However, BAS are often isolated and proprietary systems that are difficult to integrate and interoperate with other systems and devices, especially those that are web-based or Internet-of-Things (IoT) enabled.
- Web enhanced building automation systems (WEBAS) are systems that leverage web technologies and standards to enable the integration and interoperability of BAS with other web-based or IoT systems and devices, such as sensors, actuators, smart meters, smart appliances, etc.
- WEBAS can provide more functionalities, such as machine-to-machine communication, data analysis, remote control, user feedback, etc., as well as more flexibility, scalability, reliability and security.
- Some of the web technologies and standards that can be used to enhance BAS are:

  - Web services: a software system that provides a standardized way of exchanging data and functionality over the web, using protocols such as HTTP, XML, SOAP, WSDL, etc.
  - RESTful web services: a style of web service that follows the principles of Representational State Transfer (REST), such as using uniform resource identifiers (URIs) to identify resources, using HTTP methods to manipulate resources, and using standard formats to represent resources, such as JSON, XML, etc.
  - Semantic web: a web of data that can be processed by machines, using technologies such as RDF, OWL, SPARQL, etc., to provide a common framework for representing and querying data and metadata.
  - Web of Things (WoT): a vision of applying web technologies and standards to IoT devices, such as using URIs to identify devices, using RESTful web services to access devices, and using semantic web to describe devices and their capabilities.
  - WebSockets: a protocol that enables bidirectional and full-duplex communication between a web browser and a web server, using a single TCP connection, which can improve the performance and efficiency of web applications that require real-time data exchange, such as BAS.
  - MQTT: a lightweight and publish-subscribe messaging protocol that can be used for machine-to-machine communication, especially for IoT devices that have limited bandwidth, power and memory, such as sensors and actuators.
  - CoAP: a web transfer protocol that is designed for constrained devices and networks, such as IoT devices, that can provide similar functionalities as HTTP, such as URIs, methods, headers, etc., but with lower overhead and complexity.

- Some of the benefits of WEBAS are:

  - They can enable the integration and interoperability of BAS with other web-based or IoT systems and devices, such as smart grids, smart cities, smart homes, etc., which can create new opportunities and applications for energy management, demand response, load balancing, etc.
  - They can provide more functionalities, such as machine-to-machine communication, data analysis, remote control, user feedback, etc., which can improve the performance, efficiency and usability of BAS, as well as provide more value-added services to the users and stakeholders.
  - They can provide more flexibility, scalability, reliability and security, as they can leverage the existing web infrastructure and protocols, such as cloud computing, web servers, web browsers, etc., which can reduce the dependency on proprietary and vendor-specific solutions, as well as enhance the availability, redundancy and resilience of BAS.
