## Unit 4 - WEB ENHANCED BUILDING

- Web enhanced building is a concept that integrates web technologies and building automation systems to create smart, connected and sustainable buildings.
- Web enhanced building can provide benefits such as:
  - Improved energy efficiency and environmental performance by monitoring and optimizing building operations and systems.
  - Enhanced occupant comfort and productivity by providing personalized and adaptive services and environments.
  - Increased security and safety by detecting and responding to threats and emergencies.
  - Reduced operational and maintenance costs by enabling remote management and diagnostics.
  - Increased asset value and marketability by offering innovative and attractive features and services.
- Web enhanced building can be implemented using various web technologies and standards, such as:
  - Web services and APIs that enable interoperability and data exchange between different building systems and devices.
  - Web browsers and applications that provide user interfaces and access to building information and services.
  - Web protocols and formats that facilitate communication and data representation, such as HTTP, XML, JSON, etc.
  - Web of Things (WoT) that extends the web to physical devices and sensors, enabling discovery, interaction and integration of building components.
  - Web semantics and ontologies that provide common vocabularies and meanings for building concepts and data.
  - Web security and privacy that ensure the protection and confidentiality of building data and services.
