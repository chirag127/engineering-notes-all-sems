### Loosely-Coupled Web Protocol Stack

- A loosely-coupled web protocol stack is a set of web protocols that allow interoperation between different devices and services in a smart building or an IoT system.
- A loosely-coupled web protocol stack enables flexibility, scalability, and interoperability of the system, as the components can communicate with each other dynamically at runtime, without requiring a static compile-time binding   .
- A loosely-coupled web protocol stack consists of four layers: application, service, transport, and network.
- The application layer defines the semantics and formats of the messages exchanged between the components, such as REST, SOAP, or CoAP .
- The service layer provides the mechanisms for service discovery, registration, and invocation, such as DNS-SD, mDNS, or UDDI .
- The transport layer handles the reliable and secure delivery of the messages, such as TCP, UDP, or DTLS .
- The network layer deals with the routing and addressing of the messages, such as IP, IPv6, or 6LoWPAN .
- An example of a loosely-coupled web protocol stack for smart buildings is BACnet, which is a standard for building automation and control networks .
- BACnet defines an application layer protocol that supports various services and objects for building automation, such as lighting, HVAC, fire, security, etc.
- BACnet also defines a service layer protocol that allows BACnet devices to discover and register with each other, using BACnet Broadcast Management Device (BBMD) and Foreign Device Registration (FDR).
- BACnet can use different transport and network layer protocols, such as BACnet/IP, BACnet/Ethernet, BACnet/IPv6, BACnet/MS/TP, etc.
- BACnet provides a loosely-coupled web protocol stack that enables interoperability and integration of different building automation devices and systems.
