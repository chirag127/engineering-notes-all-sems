### Toward Web Enhanced Building Automation Systems

- Building automation systems (BAS) are systems that control and monitor the mechanical, electrical and plumbing systems of a building, such as heating, ventilation, air conditioning, lighting, security, fire alarms, etc.
- BAS can improve the comfort, safety and energy efficiency of buildings, as well as reduce the operational and maintenance costs.
- However, traditional BAS are often proprietary, isolated and incompatible with other systems and devices, which limits their interoperability, scalability and flexibility.
- Web enhanced building automation systems (WebBAS) are systems that leverage the web technologies and standards to enable the integration, communication and collaboration of BAS with other systems and devices, such as sensors, actuators, smart meters, smart appliances, etc.
- WebBAS can provide the following benefits:
  - WebBAS can use the web as a common platform for data exchange and service discovery, which can facilitate the interoperability and compatibility of different systems and devices.
  - WebBAS can use the web as a universal interface for accessing and controlling the BAS from any device and location, which can enhance the usability and convenience of the BAS.
  - WebBAS can use the web as a source of information and intelligence, which can enable the BAS to perform advanced functions, such as data analysis, optimization, prediction, etc.
  - WebBAS can use the web as a medium for collaboration and social interaction, which can allow the BAS to involve the users and stakeholders in the decision making and feedback processes, as well as to share and learn from the best practices and experiences of other buildings and communities.
- WebBAS can be implemented using various web technologies and standards, such as:
  - Web services, which are software components that provide specific functionalities and can be accessed and invoked over the web using standard protocols, such as SOAP, REST, etc.
  - Web of Things, which is an extension of the Internet of Things (IoT) that applies the web technologies and standards to the physical objects and devices, such as sensors, actuators, etc., to make them discoverable, accessible and controllable over the web.
  - Semantic web, which is an extension of the web that adds meaning and structure to the web data and resources, using standard formats, such as RDF, OWL, etc., to enable the machine-understandability and reasoning of the web content.
  - Social web, which is an extension of the web that supports the social interaction and collaboration of the web users and communities, using standard platforms, such as blogs, wikis, social networks, etc., to enable the creation and sharing of the web content.
