### Unit 3 - FOG COMPUTING in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

- Fog computing is a paradigm that extends cloud computing to the edge of the network, where IoT devices are located.
- Fog computing aims to reduce network latency, bandwidth consumption, and data privacy issues by processing and analyzing IoT data closer to the source, rather than sending it to the cloud.
- Fog computing enables real-time and context-aware applications for IoT, such as smart cities, smart grids, smart health, and smart transportation.
- Fog computing consists of fog nodes, which are intermediary devices that can perform computation, storage, communication, and control functions for IoT devices.
- Fog nodes can be network gateways, routers, switches, servers, access points, or even end-user devices, such as smartphones or laptops.
- Fog nodes can form a hierarchical, distributed, and collaborative network that connects IoT devices to the cloud.
- Fog computing leverages the existing network infrastructure and protocols, such as IP, TCP, UDP, and HTTP, to provide seamless and secure communication between fog nodes and IoT devices.
- Fog computing also supports various programming models and frameworks, such as Apache Spark, Apache Storm, and OpenFog, to facilitate the development and deployment of fog applications.
- Fog computing faces several challenges, such as resource management, security, privacy, scalability, interoperability, and standardization, which require further research and development.
