## Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure in which data, compute, storage, and applications are located somewhere between the data source and the cloud.
- It is also known as edge computing or fogging.
- Fog computing is designed to improve efficiency and reduce the amount of data transported to the cloud for processing, analysis, and storage.
- This is achieved by leveraging edge devices and gateways to perform these tasks closer to the data source.
- Fog computing can be used in various applications such as Internet of Things (IoT), 5G, and artificial intelligence.
- It can also help to address issues such as latency, bandwidth, and security.
- Fog computing is complementary to cloud computing and can be used in conjunction with it to provide a more comprehensive and efficient computing solution.
