## Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure that uses edge devices to perform computation, storage, and communication locally and routed over the Internet backbone.
- Fog computing is also known as edge computing or fogging  .
- Fog computing is intended for distributed computing where numerous "peripheral" devices connect to a cloud.
- Fog computing brings the advantages and power of the cloud closer to where data is created and acted upon.
- Fog computing is more energy-efficient than cloud computing.
- Fog computing is a medium weight and intermediate level of computing power that often serves as a complement to cloud computing.
- Fog computing enables faster response time, lower latency, improved security, and reduced network congestion .
- Fog computing supports applications that require real-time processing, analytics, and decision making, such as smart cities, autonomous vehicles, and healthcare .
- Fog computing follows the standards proposed by OpenFog Consortium and adopted by IEEE.
