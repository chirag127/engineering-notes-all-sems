### Unit 3 - FOG COMPUTING

- Fog computing is a computing architecture in which a series of nodes receives data from IoT devices in real time. These nodes perform real-time processing of the data that they receive, with millisecond response time. The nodes periodically send analytical summary information to the cloud.
- Fog computing is also called edge computing, as it extends the cloud computing to the edge of the network, closer to the IoT devices .
- Fog computing is not a substitute, but a complement to cloud computing. Fog computing is more energy-efficient than cloud computing, as it reduces the amount of data that needs to be transmitted to the cloud.
- Fog computing has several advantages, such as:
  - Low latency: Fog computing enables faster response time for time-sensitive applications, such as autonomous vehicles, smart grids, and video analytics.
  - Bandwidth savings: Fog computing reduces the network congestion and the cost of data transmission by processing and filtering the data locally.
  - Security and privacy: Fog computing enables data encryption and access control at the edge, reducing the risk of data breaches and cyberattacks.
  - Reliability and availability: Fog computing provides backup and failover mechanisms for the IoT devices, ensuring uninterrupted service even in case of network failures or cloud outages.
- Fog computing also has some challenges, such as:
  - Resource management: Fog computing requires efficient allocation and coordination of the computing, storage, and networking resources across the fog nodes and the cloud.
  - Scalability: Fog computing needs to handle the increasing number and diversity of the IoT devices and applications, as well as the dynamic and heterogeneous nature of the fog environment.
  - Interoperability: Fog computing needs to ensure the compatibility and communication among the different fog nodes, IoT devices, and cloud platforms, as well as the compliance with the standards and regulations.
- Fog computing is supported by several standards and frameworks, such as:
  - IEEE 1934: A standard that defines the reference architecture and core functionalities of fog computing, based on the proposal by the OpenFog Consortium.
  - Cisco IOx: A platform that enables the development and deployment of fog applications on Cisco network devices, such as routers, switches, and gateways.
  - FogHorn: A software platform that provides edge intelligence and machine learning for industrial IoT applications, such as manufacturing, energy, and transportation.
