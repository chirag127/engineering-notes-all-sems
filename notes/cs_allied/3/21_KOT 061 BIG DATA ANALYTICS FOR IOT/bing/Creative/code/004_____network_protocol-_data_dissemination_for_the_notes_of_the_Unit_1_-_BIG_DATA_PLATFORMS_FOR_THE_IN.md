### Network protocol data dissemination for IoT big data

- Data dissemination is the process of delivering data that matches the interest or query of the nodes in a network.
- Data dissemination is important for IoT applications, as they generate massive amounts of data from various sensors and devices, and require fast processing, storage, and analysis .
- Data dissemination in IoT networks faces several challenges, such as:
  - Resource constraints of the nodes, such as limited energy, memory, and bandwidth.
  - Network dynamics, such as node mobility, topology changes, and link failures.
  - Network security, such as data confidentiality, integrity, and authenticity .
- Data dissemination protocols for IoT networks can be classified into two categories: push-based and pull-based.
  - Push-based protocols: The data source or the network initiates the data delivery to the interested nodes, without waiting for their requests. This can reduce the communication overhead and latency, but may also cause data redundancy and waste of resources.
  - Pull-based protocols: The interested nodes initiate the data delivery by sending queries or subscriptions to the data source or the network. This can reduce the data redundancy and resource waste, but may also increase the communication overhead and latency.
- Data dissemination protocols for IoT networks can also be classified into three types: flooding, gossiping, and routing.
  - Flooding: The data source or the network broadcasts the data to all the nodes in the network, without any filtering or aggregation. This can ensure high data reliability and coverage, but may also cause high network congestion and energy consumption.
  - Gossiping: The data source or the network randomly selects a subset of nodes to forward the data, and each node repeats the same process until the data reaches the interested nodes. This can reduce the network congestion and energy consumption, but may also reduce the data reliability and coverage.
  - Routing: The data source or the network selects a specific path or a set of paths to forward the data to the interested nodes, based on some criteria, such as shortest distance, highest energy, or lowest congestion. This can optimize the network performance and resource utilization, but may also increase the complexity and overhead of the protocol.
