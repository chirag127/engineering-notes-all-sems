### Toward Web Enhanced Building Automation Systems

- Building automation systems (BAS) are systems that control and monitor the mechanical, electrical and plumbing systems in a building, such as heating, ventilation, air conditioning, lighting, security, fire alarms, etc.
- BAS can improve the energy efficiency, comfort, safety and security of buildings, as well as reduce the operational and maintenance costs.
- However, traditional BAS are often proprietary, isolated and incompatible with each other, making it difficult to integrate, manage and access them from different locations and devices.
- Web enhanced building automation systems (WEBAS) are systems that leverage the web technologies and standards to enable the interoperability, accessibility and scalability of BAS.
- WEBAS can provide the following benefits:
  - Web-based user interfaces that can be accessed from any device and platform, such as PCs, tablets, smartphones, etc.
  - Web services and APIs that can expose the data and functionalities of BAS to other applications and systems, such as cloud computing, big data analytics, Internet of Things, etc.
  - Web protocols and formats that can facilitate the communication and data exchange between different BAS and devices, such as HTTP, REST, JSON, XML, etc.
  - Web ontologies and semantics that can provide a common vocabulary and understanding of the concepts and relationships in the building domain, such as W3C SSN, SAREF, Brick, etc.
- Some examples of WEBAS are:
  - WebCTRL® by Automated Logic, a web-based platform that provides facility managers with software tools to keep occupants comfortable, manage energy conservation measures, identify key operational problems, and analyze the results.
  - APOGEE by Siemens, a web-enabled system that integrates building automation, fire safety, security, lighting and energy management into a single platform.
  - BMS by Honeywell, a web-based system that offers a range of controllers, field devices and software to customize a system to fit the building and its future.
