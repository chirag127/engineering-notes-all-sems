### A Platform for Internet of Things and Analytics for the notes of the Unit 3 - FOG COMPUTING in the subject of KOT 061 BIG DATA ANALYTICS FOR IOT KCS

- Fog computing is a computing architecture in which a series of nodes receives data from IoT devices in real time. These nodes perform real-time processing of the data that they receive, with millisecond response time. The nodes periodically send analytical summary information to the cloud.
- Fog computing is a form of distributed computing that brings computation and data storage closer to the network edge, where many IoT devices are located. By doing this, fog computing reduces the reliance on the cloud for these resource-intensive tasks, improving performance and reducing latency.
- Fog networking supports the Internet of Things (IoT) concept, in which most of the devices used by humans on a daily basis will be connected to each other. Examples include phones, wearable health monitoring devices, connected vehicle and augmented reality using devices such as the Google Glass.
- Fog computing allows computing, decision-making and action-taking to happen via IoT devices and only pushes relevant data to the cloud. It aims to bring intelligence, processing, and storage closer to the network’s edge to provide quicker and more localized computing services for the connected smart devices that make up the IoT .
- Fog computing can be seen as a platform for IoT and analytics, as it enables the following benefits:
  - It reduces the bandwidth and latency requirements for data transmission between IoT devices and the cloud, which can improve the quality of service and user experience.
  - It enables real-time and context-aware data processing and decision making, which can enhance the functionality and efficiency of IoT applications.
  - It provides data security and privacy, as sensitive data can be processed and stored locally, without exposing it to the cloud or third parties.
  - It supports scalability and heterogeneity, as it can handle the increasing number and diversity of IoT devices and data sources.
  - It facilitates interoperability and collaboration, as it can integrate different IoT devices and systems, and enable data sharing and coordination among them.
