### Unit 3 - FOG COMPUTING

- Fog computing is a decentralized computing infrastructure that uses edge devices to perform computation, storage, and communication locally and over the Internet backbone  .
- Fog computing is also known as edge computing or fogging .
- Fog computing is intended for distributed computing where numerous peripheral devices connect to a cloud.
- Fog computing brings the advantages and power of the cloud closer to where data is created and acted upon .
- Fog computing is more energy-efficient than cloud computing.
- Fog computing is not a substitute, but a complement to cloud computing.
- Fog computing supports low-latency, real-time applications, such as smart cities, smart grids, smart health, and smart transportation  .
- Fog computing enables data analytics and decision making at the edge of the network  .
- Fog computing reduces the bandwidth and storage requirements of the cloud  .
- Fog computing improves the security and privacy of data by minimizing the exposure to external threats  .
- Fog computing faces some challenges, such as resource management, scalability, interoperability, and standardization .
- IEEE adopted the fog computing standards proposed by OpenFog Consortium.
