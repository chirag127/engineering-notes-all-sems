# Big Data Platforms for the Internet of Things

## Introduction

- The Internet of Things (IoT) is a network of physical objects or things that are embedded with sensors, actuators, and communication technologies to collect, process, and exchange data with other devices and systems over the internet.
- Big Data is a term that refers to the large volume, variety, velocity, and veracity of data that are generated by various sources, such as IoT devices, social media, web logs, etc.
- Big Data platforms are software systems that provide the capabilities to store, manage, analyze, and visualize Big Data in a scalable, reliable, and efficient manner.
- Big Data platforms for the IoT are specialized Big Data systems that are designed to handle the specific challenges and requirements of IoT data, such as high volume, high velocity, high variety, low quality, streaming, real-time, geo-distributed, etc.

## Types of Big Data Platforms for the IoT

- According to , Big Data platforms for the IoT can be classified into three types: cloud platforms, edge platforms, and hybrid platforms.

### Cloud Platforms

- Cloud platforms are Big Data systems that are hosted on remote servers and accessed over the internet. They offer the advantages of scalability, elasticity, availability, and cost-effectiveness.
- Cloud platforms provide various services and functionalities for the IoT, such as data storage, data processing, data analytics, data visualization, data security, data governance, etc.
- Some examples of cloud platforms for the IoT are:

  - **Amazon Web Services (AWS)**: AWS offers a suite of services and tools for the IoT, such as AWS IoT Core, AWS IoT Analytics, AWS IoT Greengrass, AWS IoT Device Management, AWS IoT Events, AWS IoT SiteWise, etc. 
  - **Microsoft Azure**: Azure provides a comprehensive platform for the IoT, such as Azure IoT Hub, Azure IoT Edge, Azure IoT Central, Azure IoT Solution Accelerators, Azure Stream Analytics, Azure Time Series Insights, etc. 
  - **Google Cloud Platform**: Google Cloud Platform offers a range of solutions and products for the IoT, such as Google Cloud IoT Core, Google Cloud IoT Edge, Google Cloud Pub/Sub, Google Cloud Dataflow, Google Cloud BigQuery, Google Cloud AI Platform, etc. 

### Edge Platforms

- Edge platforms are Big Data systems that are deployed on the edge of the network, near the IoT devices and sources of data. They offer the benefits of low latency, high bandwidth, data privacy, and data locality.
- Edge platforms enable the IoT devices to perform data processing, data analytics, data filtering, data aggregation, data caching, data compression, etc. at the edge, without sending the data to the cloud or a central server.
- Some examples of edge platforms for the IoT are:

  - **Artik from Samsung Electronics**: Artik is a platform that provides hardware, software, and cloud services for the IoT. It supports edge computing and edge analytics for the IoT devices, such as Artik modules, Artik chips, Artik cloud connectors, etc. 
  - **Cisco Cloud Connect**: Cisco Cloud Connect is a platform that connects the IoT devices to the cloud and enables edge computing and edge analytics for the IoT data. It consists of components such as Cisco IoT Data Connect, Cisco IoT Edge Connect, Cisco IoT Cloud Connect, etc. 
  - **OpenStack**: OpenStack is an open-source platform that provides cloud computing and edge computing services for the IoT. It supports edge computing and edge analytics for the IoT data using components such as OpenStack Nova, OpenStack Neutron, OpenStack Swift, OpenStack Sahara, etc. 

### Hybrid Platforms

- Hybrid platforms are Big Data systems that combine the features and functionalities of both cloud platforms and edge platforms. They offer the best of both worlds, such as scalability, elasticity, availability, cost-effectiveness, low latency, high bandwidth, data privacy, and data locality.
- Hybrid platforms enable the IoT devices to perform data processing, data analytics, data filtering, data aggregation, data caching, data compression, etc. at the edge, and also send the data to the cloud or a central server for further processing, analytics, visualization, etc.
- Some examples of hybrid platforms for the IoT are:

  - **Salesforce Cloud**: Salesforce Cloud is a platform that provides cloud services and edge services for the IoT. It supports hybrid computing and hybrid analytics for the IoT data using components such as Salesforce IoT Cloud, Salesforce IoT Explorer, Salesforce Edge Data Router, etc
