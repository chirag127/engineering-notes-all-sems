### Objectoriented database systems for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

Object-oriented database systems are databases that use object-oriented concepts, such as classes, objects, and inheritance, to model data. They are designed to provide a more natural and intuitive way to model and store data, compared to traditional relational databases.

The following are key aspects of object-oriented database systems:

1. Classes and Objects: Classes are used to define the structure of objects, and objects are used to represent instances of data. Classes can inherit characteristics from other classes, allowing for the creation of complex data models.

2. Encapsulation: Object-oriented databases use encapsulation to hide the internal details of objects from the rest of the system, providing a more secure and flexible way to model data.

3. Polymorphism: Polymorphism allows objects to be treated as instances of a common type, regardless of their specific class. This makes it easier to write generic code that can work with objects of different classes.

4. Object Identity: Object-oriented databases use object identity to uniquely identify objects, allowing for the creation of complex relationships between objects.

5. Object Query Languages: Object-oriented databases often use object query languages, such as Object Query Language (OQL), to query and manipulate data.

Unit 2 - Semantic Data Models covers the use of object-oriented and semantic data models in intelligent database systems, including the use of classes, objects, encapsulation, polymorphism, object identity, and object query languages.
