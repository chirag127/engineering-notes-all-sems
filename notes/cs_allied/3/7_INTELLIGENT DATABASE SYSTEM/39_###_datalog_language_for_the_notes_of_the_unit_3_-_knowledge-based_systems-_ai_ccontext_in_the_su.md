### DATALOG language for the notes of the Unit 3 - Knowledge-Based Systems- AI Ccontext in the subject of INTELLIGENT DATABASE SYSTEM

Datalog is a declarative language used in knowledge-based systems for querying and manipulating data. It is based on the logic programming paradigm and is used to represent and manipulate knowledge in a structured and formal way.

The key features of Datalog include:
1. Declarative: Datalog is a declarative language, meaning that the programmer specifies what they want to achieve, rather than how to achieve it.

2. Rule-based: Datalog is a rule-based language, meaning that it uses rules to represent knowledge and relationships between data.

3. Recursive: Datalog allows for recursive rules, allowing for the representation of complex relationships between data.

4. Efficient: Datalog is an efficient language for querying and manipulating data, as it is optimized for use in knowledge-based systems.

In summary, Datalog is a declarative, rule-based, recursive, and efficient language used in knowledge-based systems for querying and manipulating data. It is based on the logic programming paradigm and is used to represent and manipulate knowledge in a structured and formal way.
