### Basic concepts of a core object-oriented data model for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

The core concepts of an object-oriented data model are:
1. Object: An instance of a class with attributes and methods
2. Class: A blueprint for creating objects with common properties and behaviors
3. Inheritance: A mechanism for creating new classes based on existing classes
4. Polymorphism: The ability of objects to take on different forms based on their context
5. Encapsulation: The practice of hiding the implementation details of an object and exposing only its public interface.

In the context of semantic data models, these concepts are used to represent real-world entities and their relationships in a structured manner. This allows for more efficient and meaningful data storage, retrieval, and analysis. Additionally, semantic data models often use ontologies to define the relationships between classes and objects, providing a shared vocabulary and understanding of the data.
