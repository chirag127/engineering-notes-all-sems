### Active database systems for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

Active databases are databases that allow for the execution of procedures or rules in response to specific events or changes in the data. These events can be triggered by changes to the data, such as the insertion or deletion of a record, or by external events, such as the arrival of a message or the passage of time. 

Some examples of active database systems include: 
- Object-Oriented Database Management Systems (OODBMS) 
- Rule-Based Database Management Systems (RDBMS) 
- Event-Driven Database Management Systems (EDDBMS) 
- Trigger-Based Database Management Systems (TDBMS) 

In the context of semantic data models, active databases can play a crucial role in maintaining the integrity and consistency of the data by automatically enforcing constraints and rules defined in the data model. For example, a rule could be defined to ensure that a certain attribute in a record must always have a value within a specified range. If a user tries to insert a record with an attribute value outside of this range, the active database could automatically reject the insertion and notify the user of the violation. 

Overall, active databases provide a powerful tool for ensuring the quality and accuracy of data in intelligent database systems.
