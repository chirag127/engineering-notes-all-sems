### Basic indexing methods for the notes of the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM

Basic indexing methods are used to improve the performance of database queries by reducing the amount of data that needs to be searched. The following are some of the most common indexing methods:

1. Hash indexing: A method of indexing based on hash functions, which map data values to a fixed number of buckets.

2. B-tree indexing: A method of indexing based on a balanced tree structure, which allows for fast searching, insertion, and deletion of data.

3. Bitmap indexing: A method of indexing that uses a bitmap to represent the data, where each bit represents the presence or absence of a data value.

4. Clustered indexing: A method of indexing that physically orders the data in the database according to the index, allowing for faster access to the data.

5. Non-clustered indexing: A method of indexing that creates a separate index structure that points to the actual data in the database, rather than physically ordering the data.

The choice of indexing method depends on the specific requirements of the database and the types of queries being performed. For example, hash indexing may be suitable for databases with a small number of distinct values, while B-tree indexing may be more appropriate for databases with a large number of distinct values.

Overall, indexing is an important tool in the field of intelligent database systems, as it allows for faster and more efficient retrieval of data, and can play a crucial role in improving the performance of database queries.
