### Deductive database systems and logic programming systems—differences for the notes of the Unit 3 - Knowledge-Based Systems- AI Ccontext in the subject of INTELLIGENT DATABASE SYSTEM

Deductive database systems and logic programming systems are two different approaches to represent and manipulate knowledge in a formal, systematic way. Both approaches are used in knowledge-based systems and artificial intelligence, but there are several key differences between the two.

1. Representation of knowledge: Deductive database systems represent knowledge in the form of rules and facts, while logic programming systems represent knowledge in the form of logic programs.

2. Reasoning: Deductive database systems use deductive reasoning to derive new knowledge from existing knowledge, while logic programming systems use declarative programming to represent and manipulate knowledge.

3. Query processing: Deductive database systems use query processing techniques to answer questions and make decisions based on the knowledge in the system, while logic programming systems use logic programming techniques to manipulate and reason about the knowledge in the system.

4. Performance: Deductive database systems are optimized for query processing and are well-suited for large-scale, complex knowledge bases, while logic programming systems are optimized for declarative programming and are well-suited for complex, symbolic reasoning tasks.

In conclusion, Deductive database systems and logic programming systems are two different approaches to represent and manipulate knowledge in a formal, systematic way. Deductive database systems represent knowledge in the form of rules and facts, use deductive reasoning to derive new knowledge, and are optimized for query processing, while logic programming systems represent knowledge in the form of logic programs, use declarative programming to represent and manipulate knowledge, and are optimized for complex, symbolic reasoning tasks.
