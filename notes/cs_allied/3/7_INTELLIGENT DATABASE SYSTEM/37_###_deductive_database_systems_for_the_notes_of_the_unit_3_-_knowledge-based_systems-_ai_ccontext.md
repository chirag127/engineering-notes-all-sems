### Deductive database systems for the notes of the Unit 3 - Knowledge-Based Systems- AI Ccontext in the subject of INTELLIGENT DATABASE SYSTEM

Unit 3 - Knowledge-Based Systems- AI Context covers the topic of deductive database systems, which are a type of knowledge-based system that use logic and reasoning to process and manipulate data. 

The following are key aspects of deductive database systems:

1. Deductive Reasoning: Deductive reasoning is a form of logical reasoning that involves deducing conclusions from premises. Deductive reasoning is a critical component of deductive database systems, as it allows the system to process and manipulate data in a logical and systematic way.

2. Logic Programming: Logic programming is a programming paradigm that uses logic to represent and manipulate data. Logic programming is used in deductive database systems to represent and manipulate data in a logical and systematic way.

3. Rule-Based Systems: Rule-based systems are a type of deductive database system that use a set of rules to represent and manipulate data. Rule-based systems are used in expert systems and other knowledge-based systems.

4. Prolog: Prolog is a programming language that is used for logic programming. Prolog is widely used in deductive database systems, and is a critical component of these systems.

By understanding these concepts, organizations can effectively use deductive database systems to process and manipulate data in a logical and systematic way.
