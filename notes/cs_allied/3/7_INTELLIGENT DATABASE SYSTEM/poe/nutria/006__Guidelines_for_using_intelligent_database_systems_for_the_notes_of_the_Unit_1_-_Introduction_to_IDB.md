
### Guidelines for using intelligent database systems for the notes of the Unit 1 - Introduction to IDBS in the subject of INTELLIGENT DATABASE SYSTEM

1. Understand the basic concepts of Intelligent Database Systems (IDBS) such as data storage, retrieval, manipulation, and analysis.
2. Learn the different types of IDBS such as relational, object-oriented, and distributed databases.
3. Understand the architecture of an IDBS and its components such as the database management system (DBMS), the query language, and the user interface.
4. Learn how to design and implement an IDBS, including the data model, the data dictionary, and the physical design.
5. Understand the security and integrity issues related to IDBS and how to address them.
6. Learn how to use the query language to retrieve data from an IDBS and how to use the data for analysis.
7. Understand the performance issues related to IDBS and how to improve them.
8. Learn how to use the various tools available for managing and monitoring an IDBS.
