
### Conclusions for the Notes of the Unit 2 - Semantic Data Models in the Subject of INTELLIGENT DATABASE SYSTEM

1. Semantic data models are used to represent the meaning of data stored in a database.
2. Semantic data models are based on the concept of a semantic network, which is a graph-like structure composed of nodes and relationships.
3. Semantic data models can be used to represent complex relationships between data, such as those found in natural language.
4. Semantic data models can be used to represent the meaning of data stored in a database in a more human-readable form.
5. Semantic data models can be used to facilitate the integration of data from multiple sources, as well as to enable the sharing of data across multiple applications.
6. Semantic data models can also be used to improve the performance of query processing and data retrieval.
7. Intelligent database systems can use semantic data models to enable the automatic discovery of new knowledge from existing data.
