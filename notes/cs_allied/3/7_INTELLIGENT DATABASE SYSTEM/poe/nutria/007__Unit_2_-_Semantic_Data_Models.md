
## Unit 2 - Semantic Data Models

1. Semantic data models are used to represent the meaning of data and relationships between data. 
2. They are a type of data model that is used to represent the structure of a database.
3. Semantic data models are used to provide a more accurate representation of the data and its relationships.
4. These models are based on the concept of semantic networks, which are used to represent the meaning of data and relationships between data.
5. Semantic networks are composed of nodes and edges, which represent the data and the relationships between the data.
6. These models are used to provide a more accurate representation of the data, which can be used to improve the accuracy of data analysis and decision making.
7. Semantic data models are used in a variety of applications, such as knowledge management, natural language processing, data mining, and machine learning.
8. They are also used in the development of ontologies, which are used to represent the structure and meaning of data.
