
### Query Languages and Query Processing

* Query languages are used to define and manipulate data stored in a database. They are used to create, update, delete, and retrieve data from the database. 
* Query processing is the process of translating a user's query into a form that can be executed by the database system. It involves parsing, optimization, and execution.
* Semantic data models are used to represent the structure and meaning of data. These models provide a high-level view of the data, which can be used to improve query processing.
* The most common query languages used in database systems are Structured Query Language (SQL) and Object Query Language (OQL).
* SQL is a declarative language that allows users to specify what data they want, without specifying how to retrieve it. It is used to query relational databases.
* OQL is an object-oriented language that is used to query object-oriented databases. It allows users to specify the structure of the data they want, as well as the data itself.
* Query processing includes several steps, such as parsing, optimization, and execution. Parsing is the process of translating a user's query into a form that can be executed by the database system. Optimization is the process of selecting the most efficient way to execute a query. Execution is the process of actually executing the query.
