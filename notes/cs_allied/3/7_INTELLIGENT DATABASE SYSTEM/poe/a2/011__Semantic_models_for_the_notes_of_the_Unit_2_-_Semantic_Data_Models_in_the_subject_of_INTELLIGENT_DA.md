### Semantic models

1. RDF (Resource Description Framework):
- RDF is a standard model for data interchange on the Web.
- It represents data in the form of statements. A statement is made of a subject, a predicate, and an object which is also known as a triple.
- Subject denotes the resource, predicate denotes the property type, and the object denotes the value.
- RDF uses XML and URIs to represent and exchange data.
- RDF Schema (RDFS) provides basic elements to describe the structure and semantics of RDF resources.

2. OWL (Web Ontology Language):
- OWL is a semantic markup language for publishing and sharing ontologies on the World Wide Web.
- It provides additional vocabulary along with formal semantics to define the meaning of terms in vocabularies and the relationships between those terms.
- It facilitates greater machine interpretability of Web content than that supported by XML, RDF, and RDF Schema.
- It has three increasingly expressive sublanguages: OWL Lite, OWL DL, and OWL Full.

3. Topic Maps:
- Topic Maps is a standard for describing knowledge structures and associating information resources with those structures.
- It represents information using topics, associations, and occurrences.
- A topic can represent any concept, like people, places, events, documents, etc. Associations represent relationships between topics. Occurrences are information resources relevant to a particular topic.
- It provides a flexible, graph-based model that can represent the complex structures of real-world domains.
