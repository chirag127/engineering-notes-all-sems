### Comparison with other data models for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. Object-Oriented Data Model
- Data is represented as objects with attributes and methods
- Complex real-world entities can be directly represented
- Supports data abstraction and encapsulation
- Inheritance can be used to represent is-a relationships
- Queries are translated to navigating through pointers between objects
- Schema evolution is easy but can lead to data migration issues

2. Semantic Data Model
- Data is represented in the form of objects, concepts and relationships
- Supports representation of knowledge and semantics of data
- Powerful query languages to retrieve data based on semantic relationships
- Schema evolution is complex due to explicit semantics
- Additional layers required for storage and query processing leading to reduced performance

3. Graph Data Model
- Data is represented as nodes, edges and properties
- Simple and intuitive representation of data and relationships
- Powerful for representation of networks and relationships
- Query languages use graph traversal for retrieval which can be inefficient for large data
- Schema evolution is easy but may affect existing queries and applications
