### Nested and semantic data models

1. Object-oriented data models
- Represent data in terms of objects, attributes and methods
- Each object has an ID to uniquely identify it
- Attributes describe the object and methods operate on the object
- Complex objects can be constructed from simpler objects
- Offer possibilities for encapsulation and inheritance

2. Entity-relationship data models
- Focus on entities, relationships between entities and attributes of entities
- Entities: objects or concepts that are modeled
- Relationships: associations between entities
- Attributes: properties of entities
- Diagrams are used to represent ER models
- Provide a more semantic way to represent data and relationships

3. Graph data models
- Data is represented as nodes (entities) and edges (relationships)
- Nodes and edges can have attributes
- Queries involve traversing the graph
- Useful for representing highly connected data and relationships
- Flexible but can be complex to query
