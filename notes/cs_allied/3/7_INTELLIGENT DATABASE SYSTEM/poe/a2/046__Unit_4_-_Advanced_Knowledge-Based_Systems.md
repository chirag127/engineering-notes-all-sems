## Unit 4 - Advanced Knowledge-Based Systems

1. Expert Systems
- Rule-based systems that contain encoded knowledge of human experts to solve specific problems.
- IF-THEN rules are used to represent knowledge.
- Inference engine matches rules/facts to derive new conclusions.
- Used in medical diagnosis, technical troubleshooting, financial analysis, etc.

2. Fuzzy Systems
- Handle imprecise/uncertain information.
- Facts/rules have degrees of truth (0-1) rather than true/false.
- Use fuzzy logic/fuzzy sets to reason about vague/imprecise information.
- Examples: control systems, pattern recognition, decision support systems.

3. Natural Language Processing
- Allow humans to interact with systems in normal language.
- Parse input text to understand syntax & semantics.
- Process language to handle requests, questions, and tasks.
- Use machine learning, statistical techniques, and domain-specific knowledge.
- Examples: virtual assistants, question answering systems, summarization systems.

4. Machine Learning & Knowledge-Based Systems
- Knowledge-based systems use programmed rules/knowledge while machine learning systems learn from data.
- The two approaches can be combined:
- Use machine learning to learn/update knowledge bases.
- Use knowledge bases to provide constraints/supervision to machine learning.
- Examples: personalized health assistants, recommendation systems.
