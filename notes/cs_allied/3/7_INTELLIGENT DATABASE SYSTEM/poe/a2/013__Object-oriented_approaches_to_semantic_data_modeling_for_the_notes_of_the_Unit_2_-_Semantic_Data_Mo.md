### Object-oriented approaches to semantic data modeling for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Object-oriented modeling approaches treat the real world as objects with attributes and behaviors.
2. The key concepts in object-oriented modeling are:
- Class: Represents a group of similar objects. Defines the structure and behavior of its objects.
- Object: An instance of a class.
- Attribute: A property that describes the object.
- Method: An action that an object can perform.
3. Two major object-oriented data models are:
- Entity-Relationship Model: Focuses on entities, relationships, and attributes. Entities are represented as objects. Relationships are associations between entities.
- Object-Role Modeling: Focuses on objects, roles, and relationships. Roles are ways in which objects interact or relate to each other. Relationships are connections between roles.
4. Advantages of object-oriented approach:
- Close resemblance to the real world.
- Support for hierarchical and complex data.
- Encapsulation of data and procedures.
- Modularity and reuse.
