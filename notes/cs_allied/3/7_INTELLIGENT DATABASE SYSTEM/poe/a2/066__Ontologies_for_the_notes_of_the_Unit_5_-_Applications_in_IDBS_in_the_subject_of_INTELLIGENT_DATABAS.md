### Ontologies for the notes of the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM

1. Ontology is a formal representation of knowledge as a set of concepts within a domain and the relationships between those concepts.
2. It is used to reason about the properties of that domain, and may be used to describe the domain.
3. Ontologies are the structural frameworks for organizing knowledge. They are made up of classes, relations, functions, axioms and instances.
4. Classes - representation of a set of objects or concepts. Relations - ways in which classes are related. Functions - complex relations between classes. Axioms - statements about the ontology. Instances - individual members of a class.
5. The key benefits of ontologies are:
    - Shared and common vocabulary.
    - Reduced ambiguity.
    - Knowledge reuse.
    - Decision support.
    - Information integration.
6. Applications of ontologies in IDBS:
    - Query expansion - Expanding user queries using ontology to retrieve more relevant results.
    - Information extraction - Extracting semantic information from text using domain ontologies.
    - Recommender systems - Recommending products or information to users based on ontology-based user profiles and item descriptions.
