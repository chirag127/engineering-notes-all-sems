### Ontology theoretical foundations for the notes of the Unit 5 - Applications in IDBS in the subject of INTELLIGENT DATABASE SYSTEM.

1. Ontology is a formal representation of knowledge as a set of concepts within a domain and the relationships between those concepts.

2. It is used to reason about the entities in that domain and may be used to describe the domain.

3. Ontologies are the structural frameworks for organizing information and are used in artificial intelligence, the Semantic Web, software engineering, biomedical informatics and library science.

4. The nodes in ontologies are classes (or concepts), and the edges are properties. The properties can also be classes. Multiple inheritance is allowed.

5. There are three main benefits of ontologies:

- Share common vocabulary.
- Enable reuse of domain knowledge.
- Make domain assumptions explicit.

6. The key components of an ontology are:

- Classes: Represent concepts or types of objects.
- Relations: Represent relationships between classes.
- Instances: Represent individual objects.
- Axioms: Represent additional statements about the ontology for reasoning purposes.

7. The most common ontology languages are:

- OWL: Web Ontology Language.
- RDF: Resource Description Framework.
- RDFS: RDF Schema.
