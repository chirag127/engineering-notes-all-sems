### Active database systems for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. An active database system is a database system that includes event-driven programming capabilities.
2. Event-condition-action (ECA) rules are used to specify actions that are automatically triggered by events.
3. ECA rules allow users to specify actions to be executed when certain conditions are met.
4. Complex conditions and actions can be defined using a programming language.
5. Active rules are evaluated whenever data is modified. This allows the database to react to changes and propagate updates.
6. Active databases embed the ECA rules into the database system. This allows efficient implementation and optimization of active rules.
7. The main benefits of active databases are:
- Automation of tasks and processes
- Maintaining data consistency and integrity
- Monitoring and adapting to changes

The above points cover the key aspects of active database systems and their significance in maintaining data consistency and database automation.
