### Commercial relational approaches for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. Relational Database Management System (RDBMS):
- Data is stored in tables with rows and columns.
- Tables are related using keys.
- Queries are used to retrieve and manipulate data.
- Examples: MySQL, Oracle, MS SQL Server, etc.

2. Entity-Relationship (ER) Model:
- Represents conceptual data models.
- Data is modeled using entities, attributes and relationships.
- Can be mapped to relational model.
- Diagrams are used to represent data models.

3. Relational Algebra:
- Collection of operators to manipulate relations.
- Examples: select, project, union, difference, cartesian product, rename, etc.
- Used to construct relational queries.

4. Relational Calculus:
- Declarative method to specify queries.
- Tuple relational calculus and domain relational calculus are the two variants.
- Specify what to retrieve rather than how to retrieve.
