### The object-relational data model for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. The object-relational data model is an extension of the relational model. It incorporates concepts from object-oriented programming.
2. The key extensions are:
- Objects: Allow complex structures to be stored in a single row of a table.
- Methods: Allow operations to be defined on data.
- Inheritance: Allow objects to inherit characteristics from super-classes.
3. The main benefits are:
- Represent complex data more naturally.
- Provide more functionality to database users.
- Allow object-oriented programming languages to manipulate databases more easily.
4. However, there are also costs:
-Complexity: Object-relational systems are more complex to design and implement.
-Inefficiency: There is often inefficiency in storing objects in a relational system.
-Lack of standards: Different systems implement different subsets of object-relational features,leading to portability problems.
