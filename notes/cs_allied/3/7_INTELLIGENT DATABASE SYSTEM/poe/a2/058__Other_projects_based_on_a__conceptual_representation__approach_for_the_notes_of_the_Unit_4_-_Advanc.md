### Other projects based on a 'conceptual representation' approach for the notes of the Unit 4 - Advanced Knowledge-Based Systems in the subject of INTELLIGENT DATABASE SYSTEM:

1. ConceptBase: A deductive database system based on conceptual graphs. It uses conceptual graphs as a knowledge representation formalism and defines a graph query language to retrieve data.
2. KRYPTON: A knowledge base system that uses epistemological logic as a knowledge representation. It provides a Prolog-like assertion language to enter knowledge and a relational algebra-like query language to retrieve information.
3. LOOM: A knowledge-representation and reasoning system that is based on the description logic formalism. It provides an object-oriented Prolog-like language to represent knowledge bases and can classify concepts and detect inconsistencies.
4. BACK: Berkeley DB: A prototypical deductive database system developed at the University of California at Berkeley. It provides a language for expressing rules and the mechanisms for efficient processing of queries in presence of rules. 
5. LDL: A Description Logic-based system that consists of a knowledge base with an TBox, ABox, and RBox and provides sound and complete proof procedures. It acts as an inference engine for the description logic.
