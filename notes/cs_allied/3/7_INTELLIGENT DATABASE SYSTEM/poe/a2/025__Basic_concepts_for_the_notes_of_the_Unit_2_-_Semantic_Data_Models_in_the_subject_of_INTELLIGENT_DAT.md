### Basic concepts for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Semantic Data Model
- It is a conceptual data model that provides a human-oriented format.
- It uses object-oriented concepts to model real-world entities and relationships.
- It represents the meaning of data rather than its structure like in relational model.
- It implements semantics that defines and represents knowledge about the world.

2. Object-Oriented Data Model
- Data is represented as objects with attributes and behaviors.
- Objects are organized into classes which represents entities.
- Attributes are characteristics of an object and behaviors are actions performed by object.
- Supports data encapsulation, inheritance, polymorphism which makes the model more flexible.

3. Frame-Based Data Model
- Data is represented as frames which are objects described using a set of attributes.
- Attributes are characteristics of a frame and have values.
- Supports generalization hierarchy using ISA relationship.
- Flexible as attributes can be added or removed easily.
- Useful for domains where new information may be discovered and included frequently.
