## Unit 2 - Semantic Data Models

1. Resource Description Framework (RDF):
- RDF is a framework for representing information in the Web.
- It uses statements to represent information in the form of subject-predicate-object expressions.
- Subject denotes the resource, predicate denotes the properties or characteristics and object contains the value of the properties.
- RDFSchema provides vocabulary for describing properties and classes of RDF resources.

2. Web Ontology Language (OWL):
- OWL is a semantic markup language for publishing and sharing ontologies on the Web.
- It adds more vocabulary for describing properties and classes: equivalent classes, disjoint classes, intersection of classes, cardinality, equality, richer typing of properties, characteristics of properties, etc.
- It offers more expressiveness than RDFS for developing ontologies.

3. SPARQL:
- SPARQL is an RDF query language for fetching data from RDF graphs.
- It is used to retrieve and manipulate data stored in RDF format.
- It can be used to express queries across diverse data sources, whether the data is stored natively as RDF or viewed as RDF via middleware.

4. Triplestores:
- Triplestores are database systems optimized for storing and querying RDF data.
- They store data in triples (subject-predicate-object) format and provide interfaces to query the data using SPARQL.
- Examples: Apache Jena, Oracle Spatial and Graph, Mulgara, 4store, etc.
