 Here are the conclusions for the notes of Unit 2 - Semantic Data Models in the subject of Intelligent Database Systems:

1. Semantic data models provide a more meaningful way to represent data as compared to record-based models. They are focused on what the data means rather than how it is formatted.
2. The entity-relationship model is a popular high-level semantic data model that represents data in terms of entities, attributes, and relationships. It is useful for conceptual database design.
3. The resource description framework (RDF) is a directed, labeled graph data format for representing information in the Web. Statements are made in the form of subject-predicate-object expressions (triples) to represent semantic data.
4. Web Ontology Language (OWL) is a family of knowledge representation languages for authoring ontologies. It is built on top of RDF and provides additional vocabulary for describing properties and classes: for example, characteristics of properties (e.g., symmetry), class constructors (e.g., intersections), and restrictions (e.g., cardinality constraints).
5. SPARQL is a query language for RDF data. It is semantic web technology's equivalent of SQL for relational databases. SPARQL queries can retrieve and manipulate data from RDF graphs.

The above points summarize the key takeaways from studying semantic data models in Unit 2. The entity-relationship model is useful for conceptual design, while RDF, OWL, and SPARQL enable the semantic web and linked open data.
