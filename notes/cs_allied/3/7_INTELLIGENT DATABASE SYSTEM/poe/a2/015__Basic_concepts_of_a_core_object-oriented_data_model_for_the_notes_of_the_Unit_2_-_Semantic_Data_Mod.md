### Basic concepts of a core object-oriented data model for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Objects: Entities in the real world are represented as objects in the data model. For example, a person, a bank account, a product, etc. can be objects.
2. Classes: Objects are categorized into classes. For example, the objects person, student, employee can be categorized into the class person. The objects current account, saving account can be categorized into the class bank account.
3. Attributes: Objects have attributes which define their properties. For example, person objects can have attributes like name, age, address, etc. Bank account objects can have attributes like account number, balance, etc.
4. Relationships: Objects are interconnected through relationships. For example, a person object can be related to a bank account object if that person owns the bank account. Relationships allow us to navigate between connected objects.
5. Inheritance: Classes can be organized into a hierarchy through inheritance. The child class inherits the attributes and behaviors of the parent class. This allows us to define a class once and reuse it through inheritance.

The above points cover the basic concepts of an object-oriented data model which can be used to formally represent the entities and relationships in the real-world scenario related to the notes of Unit 2 - Semantic Data Models. The data model acts as a blueprint for designing the database.
