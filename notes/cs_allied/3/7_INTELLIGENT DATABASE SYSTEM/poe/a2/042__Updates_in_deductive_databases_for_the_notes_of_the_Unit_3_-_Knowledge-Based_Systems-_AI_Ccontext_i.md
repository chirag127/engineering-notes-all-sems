### Updates in deductive databases for the notes of the Unit 3 - Knowledge-Based Systems- AI Ccontext in the subject of INTELLIGENT DATABASE SYSTEM

1. Deductive databases allow rules to be stored along with data. These rules are used to infer new facts from the stored data.
2. Deductive databases provide a declarative approach to define logic-based rules for deriving implicit information from explicitly stored data.
3. The two main components of a deductive database are:
    - A deductive database stores data and rules in a declarative manner.
    - A deductive database system provides an efficient implementation for evaluating queries on the deductive database.
4. Some important properties of deductive databases are:
    - They provide a declarative semantics based on first-order logic.
    - They have a clear separation between the declarative semantics and implementation details.
    - They provide some form of integrity constraints and views.
    - They facilitate the modular specification of knowledge.
    - They have well-defined semantics for handling exceptions and undefined data.
5. The main research issues for deductive databases are:
    - Efficient evaluation of recursive queries
    - Handling of very large databases
    - Optimization of query processing
    - Update processing
    - Inference control
    - Inheritance algorithms
    - Parallel/distributed query processing
