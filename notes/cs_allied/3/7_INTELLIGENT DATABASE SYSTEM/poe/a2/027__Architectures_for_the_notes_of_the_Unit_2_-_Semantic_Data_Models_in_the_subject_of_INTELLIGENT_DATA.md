### Architectures for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM.

1. Object-Oriented Data Model
- Complex data types are used to represent objects and relationships
- Objects have attributes (data) and methods (behavior)
- Inheritance is used to share common characteristics among objects
- Example: OODM (Object-Oriented Data Model), ORION

2. Semantic Data Model
- Focuses on meanings of data rather than just structure
- Uses concepts and relationships to model real-world entities and relationships
- Includes explicit representation of semantics (meaning) of data
- Allows rich expressive power and integration of heterogeneous data
- Examples: Resource Description Framework (RDF), Topic Maps (TM)

3. Graph-Based Data Model
- Data is represented as nodes (entities) and relationships (edges)
- Flexible structure allows representation of complex data and relationships
- Powerful querying capabilities using graph traversals
- Examples: Property Graph, Hypergraph
