### Systems for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

Semantic data models are data models that provide a high-level, abstract representation of the meaning of data. They are used to represent knowledge in a structured and formal way, and are commonly used in intelligent database systems.

There are several types of semantic data models, including:
1. Conceptual data models: provide a high-level, abstract representation of the concepts and relationships in a domain. Examples include the Entity-Relationship (ER) model and the Unified Modeling Language (UML).
2. Logical data models: provide a detailed, logical representation of the data in a domain. Examples include the relational model and the object-oriented model.
3. Physical data models: provide a low-level, physical representation of the data in a database. Examples include the file system and the relational database management system (RDBMS).

In summary, semantic data models are data models that provide a high-level, abstract representation of the meaning of data, and are commonly used in intelligent database systems. There are several types of semantic data models, including conceptual data models, logical data models, and physical data models.
