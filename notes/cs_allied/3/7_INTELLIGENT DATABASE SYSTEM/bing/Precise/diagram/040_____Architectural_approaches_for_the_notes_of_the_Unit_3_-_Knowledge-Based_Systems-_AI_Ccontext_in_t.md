### Architectural approaches for the notes of the Unit 3 - Knowledge-Based Systems- AI Context in the subject of INTELLIGENT DATABASE SYSTEM

1. **Rule-based systems:** These systems use a set of rules to represent knowledge and make decisions. The rules are typically in the form of IF-THEN statements, where the IF part represents the conditions that must be met for the rule to be applied, and the THEN part represents the action to be taken when the rule is applied.

2. **Frame-based systems:** These systems use frames to represent knowledge. A frame is a data structure that represents a concept or object and its attributes and relationships. Frames can be organized into hierarchies, with more general frames at the top and more specific frames at the bottom.

3. **Semantic networks:** These systems use a network of nodes and links to represent knowledge. The nodes represent concepts or objects, and the links represent relationships between the concepts or objects. The links can be labeled to indicate the type of relationship.

4. **Neural networks:** These systems use a network of interconnected nodes, or artificial neurons, to represent knowledge and make decisions. The nodes are organized into layers, with input nodes at the bottom, output nodes at the top, and hidden nodes in between. The nodes are connected by weighted links, and the weights are adjusted during training to improve the performance of the network.

5. **Bayesian networks:** These systems use a graphical model to represent knowledge and make decisions. The model consists of nodes representing random variables and links representing probabilistic dependencies between the variables. The model can be used to compute the probability of a particular outcome given the evidence.

6. **Case-based reasoning:** These systems use a database of past cases to represent knowledge and make decisions. When a new problem is encountered, the system searches the database for similar cases and uses the solutions from those cases to solve the new problem.

7. **Genetic algorithms:** These systems use a population of potential solutions to represent knowledge and make decisions. The population is evolved over time using genetic operators such as selection, crossover, and mutation to improve the quality of the solutions.

8. **Fuzzy logic:** These systems use fuzzy sets and fuzzy rules to represent knowledge and make decisions. Fuzzy sets allow for the representation of uncertainty and vagueness, and fuzzy rules allow for the representation of imprecise and approximate reasoning.
