### Architectures for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. **Three-Schema Architecture**: This architecture separates the user applications and the physical database. It consists of three levels: the external level, the conceptual level, and the internal level.
2. **Two-Schema Architecture**: This architecture is similar to the three-schema architecture, but it combines the external and conceptual levels into one level.
3. **One-Schema Architecture**: This architecture has only one level, which is the internal level. The user applications and the physical database are not separated.
4. **Client-Server Architecture**: This architecture separates the database system into two parts: the client and the server. The client is responsible for the user interface and the application processing, while the server is responsible for the data storage and retrieval.
5. **Distributed Database Architecture**: This architecture distributes the data across multiple databases, which can be located in different physical locations. The data is accessed and updated by the distributed database management system.
