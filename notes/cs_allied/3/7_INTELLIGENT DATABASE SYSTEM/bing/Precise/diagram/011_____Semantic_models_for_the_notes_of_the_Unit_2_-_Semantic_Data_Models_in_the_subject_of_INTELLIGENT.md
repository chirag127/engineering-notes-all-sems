### Semantic Data Models

Semantic data models are a method of structuring data in order to represent it in a specific logical way. They are a conceptual data model that includes semantic information that adds a basic meaning to the data and the relationships that lie between them .

#### How it works
A Semantic data model works by creating relationships between data when the data is organized. This allows the data to have meaning without human intervention or additional processing. The data is organized into three essential parts—the first data element or object, the relationship, and then the second data element or object .

#### Advantages
The semantic data model provides users with significantly more useful abstractions than the SQL data model and queries. These abstractions are more composable and reusable than queries . The semantic model helps data management manage and oversee the company's overall data, thus increasing decision-making capabilities .

#### Goals
There are four primary goals of SDMs:
1. Data resource planning: The SDM can be used in the initial stages of project planning to provide the necessary data resources .
2. Capture more of the meaning of an application environment than is possible with contemporary database models .
3. Development Activities .
4. Ensuring It’s Good .

#### Development
The development of a semantic model involves several activities, including setting the stage, deciding what to build, building it, ensuring it’s good, making it useful, and making it last . This can involve the use of vocabularies, patterns, and exemplary models, such as upper ontologies, design patterns, standard and reference models, and public models and datasets . Semantic model mining can also be used to extract useful information from existing data .
