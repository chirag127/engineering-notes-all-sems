### Basic Concepts for the Notes of Unit 2 - Semantic Data Models in the Subject of Intelligent Database System

1. **Semantic Data Model**: A semantic data model is a high-level data model that represents the meaning of data within the context of its interrelationships with other data.
2. **Entity-Relationship Model**: The entity-relationship model is a type of semantic data model that represents data as entities and the relationships between them.
3. **Object-Oriented Model**: The object-oriented model is another type of semantic data model that represents data as objects and the relationships between them.
4. **Ontology**: An ontology is a formal representation of knowledge as a set of concepts within a domain and the relationships between those concepts.
5. **RDF**: The Resource Description Framework (RDF) is a standard for modeling and exchanging data on the web.
6. **OWL**: The Web Ontology Language (OWL) is a language for defining and instantiating web ontologies.
7. **SPARQL**: SPARQL is a query language for RDF data.
8. **Triplestore**: A triplestore is a type of database designed to store and retrieve RDF data.
9. **Inference**: Inference is the process of deriving new information from existing information using logical reasoning.
10. **Reasoning**: Reasoning is the process of drawing conclusions from facts or premises.
