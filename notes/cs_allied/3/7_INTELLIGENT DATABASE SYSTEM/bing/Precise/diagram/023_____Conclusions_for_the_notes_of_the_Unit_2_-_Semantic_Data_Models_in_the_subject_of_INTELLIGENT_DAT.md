### Conclusions for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. Semantic data models provide a higher level of abstraction for data modeling, which allows for a more intuitive representation of the real world.
2. These models use concepts such as entities, relationships, and attributes to represent data and their relationships.
3. Semantic data models are commonly used in the design of databases, as they provide a clear and concise way to represent the data and its relationships.
4. Some common types of semantic data models include the Entity-Relationship model, the Object-Oriented model, and the Functional Data Model.
5. These models can be used to design databases that are more flexible, easier to use, and more efficient in terms of data retrieval and manipulation.
6. Overall, semantic data models provide a powerful tool for representing and managing data in an intelligent database system.
