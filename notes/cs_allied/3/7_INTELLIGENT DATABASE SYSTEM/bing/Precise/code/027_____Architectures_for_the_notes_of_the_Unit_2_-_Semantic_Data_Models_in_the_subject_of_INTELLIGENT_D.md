### Architectures for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. **Three-Schema Architecture**: This architecture separates the user applications and the physical database. It consists of three levels: the external level, the conceptual level, and the internal level.
2. **Two-Schema Architecture**: This architecture is a simplification of the three-schema architecture. It consists of two levels: the external level and the internal level.
3. **Object-Oriented Architecture**: This architecture is based on the object-oriented programming paradigm. It represents data as objects and defines relationships between objects using methods and inheritance.
4. **Client-Server Architecture**: This architecture separates the database system into two parts: the client and the server. The client is responsible for the user interface and the server is responsible for data storage and retrieval.
5. **Distributed Architecture**: This architecture distributes the database over multiple locations. Data can be stored and accessed from multiple sites, improving performance and reliability.
