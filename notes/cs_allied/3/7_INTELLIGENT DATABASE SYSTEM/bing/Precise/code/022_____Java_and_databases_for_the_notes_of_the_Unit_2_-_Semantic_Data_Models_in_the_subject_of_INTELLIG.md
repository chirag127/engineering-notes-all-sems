### Unit 2 - Semantic Data Models: Java and Databases

1. Java is a popular programming language that can be used to interact with databases.
2. Java Database Connectivity (JDBC) is an API that allows Java programs to access and manipulate data stored in relational databases.
3. JDBC provides a standard interface for connecting to databases, executing SQL statements, and retrieving results.
4. To use JDBC, a developer must first obtain a JDBC driver for the specific database management system they wish to use.
5. Once the driver is installed, a connection to the database can be established using the DriverManager class.
6. SQL statements can be executed using the Statement or PreparedStatement classes, and results can be retrieved using the ResultSet class.
7. Java also supports Object-Relational Mapping (ORM) frameworks, such as Hibernate, which allow developers to interact with databases using object-oriented concepts.
8. ORM frameworks can simplify database interactions by automatically generating SQL statements and mapping database records to Java objects.
9. Java and databases can be used together to create powerful and scalable applications that can store, retrieve, and manipulate large amounts of data.
