### Basic concepts for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

1. **Semantic Data Models**: A semantic data model is a high-level data model that represents the meaning of data within the context of its interrelationships with other data. It is used to design and develop complex databases.

2. **Entity-Relationship Model**: The Entity-Relationship (ER) model is a type of semantic data model that represents data as entities and relationships between them. It is used to design and develop relational databases.

3. **Object-Oriented Model**: The Object-Oriented (OO) model is a type of semantic data model that represents data as objects and their relationships. It is used to design and develop object-oriented databases.

4. **Functional Data Model**: The Functional Data Model (FDM) is a type of semantic data model that represents data as functions and their relationships. It is used to design and develop functional databases.

5. **Ontology**: An ontology is a formal representation of knowledge as a set of concepts within a domain and the relationships between those concepts. It is used to design and develop knowledge-based systems.

6. **Semantic Web**: The Semantic Web is an extension of the World Wide Web that enables the sharing and reuse of data across applications, enterprises, and communities. It is based on the use of ontologies to represent data and its meaning.

7. **RDF**: The Resource Description Framework (RDF) is a standard for modeling and exchanging data on the Semantic Web. It is based on the use of triples to represent data and its relationships.

8. **SPARQL**: SPARQL is a query language for RDF data. It is used to retrieve and manipulate data stored in RDF format.

9. **OWL**: The Web Ontology Language (OWL) is a standard for representing ontologies on the Semantic Web. It is used to define and share ontologies.

10. **Linked Data**: Linked Data is a method of publishing structured data on the Web in a way that it can be interlinked and become more useful. It is based on the use of URIs to identify data and its relationships.
