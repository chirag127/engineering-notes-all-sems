### Temporal databases

- A temporal database is a database that has certain features that support time-sensitive status for entries.
- A temporal database can store data relating to past, present and future time instances.
- A temporal database can track the history of data changes, the validity of data in the real world, and the decision time of data operations.
- A temporal database can be classified into three types: uni-temporal, bi-temporal, and tri-temporal.
  - A uni-temporal database supports only one temporal aspect, such as valid time or transaction time.
  - A bi-temporal database supports both valid time and transaction time.
  - A tri-temporal database supports valid time, transaction time, and decision time.
- A temporal database can offer temporal data types, such as date, time, interval, and period.
- A temporal database can provide temporal query languages, such as SQL:2011, that allow users to specify temporal predicates and operators.
- A temporal database can enable temporal integrity constraints, such as temporal primary keys, temporal foreign keys, and temporal referential integrity.
- A temporal database can implement temporal indexing techniques, such as B+-trees, R-trees, and TSB-trees, to improve the performance of temporal queries.
- A temporal database can support temporal applications, such as data warehousing, data mining, auditing, version control, and temporal reasoning.
