### The 'tight coupling' approach

- The tight coupling approach is a way of integrating data mining systems with database or data warehouse systems using a common interface and data model .
- In this approach, the data mining system is treated as a functional component of the information system, and can access the data stored in the database or data warehouse directly.
- The tight coupling approach provides system scalability, high performance, and integrated information, as the data mining system can leverage the features and capabilities of the database or data warehouse system.
- The tight coupling approach also supports the text data type as a built-in data type, and can handle queries involving both structured and unstructured data efficiently.
- The tight coupling approach requires a novel structure of the IR index and query processing algorithms to support the DB-IR integration.
- The tight coupling approach can also be used to wrap a database system with a GraphQL layer, which can provide a flexible and declarative way of querying the data using GraphQL.
