### Structured, semi-structured and unstructured data

- Structured data is data with a high degree of organization, typically stored in a spreadsheet-like manner. It has a predefined schema, format and structure. It can be easily queried, analyzed and manipulated using relational database management systems (RDBMS) and SQL. Examples of structured data are customer records, product inventory, sales transactions, etc.    
- Semi-structured data is data with some degree of organization, but not as rigid as structured data. It has some elements of a schema, format and structure, but also allows for some variation and flexibility. It can be stored in a non-tabular form, such as JSON, CSV, XML, etc. It can be queried and analyzed using tools like NoSQL databases, Hadoop, Spark, etc. Examples of semi-structured data are web logs, social media posts, email messages, etc.     
- Unstructured data is data with no predefined organizational form and no specific format or structure. It is often complex and qualitative information that is difficult to reduce to or organize in a tabular form. It can be stored in its native formats, such as text, audio, video, image, etc. It can be analyzed using tools like natural language processing (NLP), text mining, computer vision, etc. Examples of unstructured data are books, articles, reviews, tweets, podcasts, videos, photos, etc.
