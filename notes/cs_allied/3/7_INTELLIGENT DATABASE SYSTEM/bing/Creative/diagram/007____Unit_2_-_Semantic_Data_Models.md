## Unit 2 - Semantic Data Models

- Semantic data models are conceptual data models that capture the meaning and relationships of data in a domain of interest.
- Semantic data models use high-level concepts, such as entities, attributes, and relationships, to represent data and their semantics.
- Semantic data models can be used to design databases, query data, and perform data analysis.
- Semantic data models can be classified into two main categories: entity-relationship models and ontological models.

### Entity-relationship models

- Entity-relationship models (ER models) are the most widely used semantic data models for database design.
- ER models use entities to represent real-world objects or concepts, attributes to represent properties or characteristics of entities, and relationships to represent associations or interactions between entities.
- ER models can be represented graphically using ER diagrams, which show the entities, attributes, and relationships in a domain, along with their cardinalities and constraints.
- ER models can be mapped to relational models, which are the basis of relational databases, using a set of rules and transformations.

### Ontological models

- Ontological models are semantic data models that use ontologies to represent the knowledge and reasoning about a domain of interest.
- Ontologies are formal specifications of the concepts, terms, and relationships in a domain, along with their definitions, axioms, and rules.
- Ontologies can be represented using logic-based languages, such as RDF, OWL, and SWRL, which enable machine-readable and interoperable representations of data and their semantics.
- Ontologies can be used to query data, perform data integration, and support data analysis and inference.
