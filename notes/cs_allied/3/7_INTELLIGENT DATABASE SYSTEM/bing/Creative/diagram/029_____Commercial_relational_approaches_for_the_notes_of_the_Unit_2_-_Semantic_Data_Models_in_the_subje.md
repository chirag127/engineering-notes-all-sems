### Commercial relational approaches for the notes of the Unit 2 - Semantic Data Models in the subject of INTELLIGENT DATABASE SYSTEM

- A relational data model is a data model that represents data as a collection of tables or relations, where each table consists of a set of rows and columns .
- A semantic data model is a data model that captures the meaning and relationships of the data in a more natural and intuitive way, using concepts such as objects, attributes, and associations .
- Some of the commercial relational approaches that support semantic data modeling are:

  - **Object-relational databases**: These are databases that extend the relational model with object-oriented features, such as user-defined types, inheritance, polymorphism, and methods. Examples of object-relational databases are Oracle, PostgreSQL, and IBM DB2.
  - **Semantic graph databases**: These are databases that use a graph-based data model, where data is represented as nodes (entities) and edges (relationships), and where each node and edge can have properties and labels. Examples of semantic graph databases are Neo4j, Stardog, and AllegroGraph.
  - **Semantic web databases**: These are databases that use the standards and technologies of the semantic web, such as RDF, OWL, and SPARQL, to store and query data that is annotated with ontologies and vocabularies. Examples of semantic web databases are Virtuoso, Jena, and Sesame.
