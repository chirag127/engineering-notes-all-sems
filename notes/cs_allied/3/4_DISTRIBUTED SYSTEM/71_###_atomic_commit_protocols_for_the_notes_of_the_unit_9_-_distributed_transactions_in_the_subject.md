### Atomic Commit protocols for the notes of the Unit 9 - Distributed Transactions in the subject of DISTRIBUTED SYSTEM

Unit 9 - Distributed Transactions covers the concept of atomic commit protocols, which are used to ensure that transactions are executed atomically in a distributed system. Atomic commit protocols are critical to ensuring that the system remains in a consistent state, even in the face of failures.

The following are key aspects of atomic commit protocols:

1. Two-Phase Commit (2PC): Two-Phase Commit (2PC) is a widely-used atomic commit protocol that ensures that all participants in a transaction agree to commit the transaction before it is executed.

2. Three-Phase Commit (3PC): Three-Phase Commit (3PC) is an extension of 2PC that provides additional reliability and fault tolerance. 3PC ensures that all participants in a transaction agree to commit the transaction before it is executed, and also provides a mechanism for handling failures.

3. Coordination: Atomic commit protocols require coordination between the participants in a transaction in order to ensure that the transaction is executed atomically.

4. Consistency: Atomic commit protocols ensure that the system remains in a consistent state, even in the face of failures, by ensuring that all participants in a transaction agree to commit the transaction before it is executed.

5. Fault Tolerance: Atomic commit protocols provide fault tolerance by ensuring that the system remains in a consistent state, even in the face of failures.

By understanding atomic commit protocols, organizations can effectively implement distributed transactions that are reliable and maintain consistency, even in the face of failures.
