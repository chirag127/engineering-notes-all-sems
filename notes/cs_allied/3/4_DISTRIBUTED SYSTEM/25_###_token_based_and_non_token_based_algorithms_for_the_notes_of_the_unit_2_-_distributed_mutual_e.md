### Token based and non token based algorithms for the notes of the Unit 2 - Distributed Mutual Exclusion in the subject of DISTRIBUTED SYSTEM

Token-based algorithms:
1. Ricart-Agrawala algorithm: a mutual exclusion algorithm that uses a token to grant access to a shared resource.
2. Maekawa's algorithm: a token-based algorithm for distributed mutual exclusion that uses a coordinator to manage access to the shared resource.

Non-token-based algorithms:
1. Chandy-Lamport algorithm: a distributed mutual exclusion algorithm that uses a distributed snapshot to determine the state of the system.
2. Lamport's bakery algorithm: a mutual exclusion algorithm that uses a queue to manage access to the shared resource.
