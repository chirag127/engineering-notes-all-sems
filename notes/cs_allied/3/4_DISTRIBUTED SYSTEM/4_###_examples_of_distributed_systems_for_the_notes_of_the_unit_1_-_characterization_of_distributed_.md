### Examples of distributed Systems for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

Distributed Systems are computer systems that consist of multiple autonomous computers communicating with each other through a network to achieve a common goal. Some examples of distributed systems are:

1. Client-Server Systems: A client-server system is a distributed system where clients request services or resources from servers. Examples include web servers, file servers, and database servers.

2. Peer-to-Peer Systems: A peer-to-peer system is a distributed system where each node acts as both a client and a server. Examples include BitTorrent, Gnutella, and Napster.

3. Grid Computing Systems: A grid computing system is a distributed system that utilizes the idle processing power of many computers to perform large-scale computations. Examples include SETI@home and the World Community Grid.

4. Cluster Computing Systems: A cluster computing system is a distributed system that consists of multiple interconnected nodes that work together to solve a problem. Examples include Hadoop and Apache Spark.

5. Cloud Computing Systems: A cloud computing system is a distributed system that provides on-demand access to shared resources, such as computing power, storage, and applications, over the internet. Examples include Amazon Web Services, Microsoft Azure, and Google Cloud Platform.
