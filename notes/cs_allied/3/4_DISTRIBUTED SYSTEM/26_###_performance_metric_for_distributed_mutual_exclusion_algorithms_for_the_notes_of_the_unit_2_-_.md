### performance metric for distributed mutual exclusion algorithms for the notes of the Unit 2 - Distributed Mutual Exclusion in the subject of DISTRIBUTED SYSTEM

Performance metrics for distributed mutual exclusion algorithms are used to evaluate the effectiveness and efficiency of these algorithms in a distributed system. The following are common performance metrics:

1. Latency: The time it takes for a process to acquire the lock and release it.

2. Throughput: The number of lock requests that can be handled per unit of time.

3. Deadlock: The situation where two or more processes are waiting for each other to release the lock, resulting in a permanent block.

4. Starvation: The situation where a process is repeatedly denied access to the lock, resulting in an unfair distribution of resources.

5. Scalability: The ability of the algorithm to handle increasing numbers of processes and nodes in the network.

6. Fault tolerance: The ability of the algorithm to continue functioning in the presence of failures or crashes.

7. Message complexity: The number of messages exchanged between processes during the lock acquisition and release process.

8. Time complexity: The amount of time required for lock acquisition and release.

9. Space complexity: The amount of memory required to implement the algorithm.

10. Simplicity: The ease of implementation and understanding of the algorithm.
