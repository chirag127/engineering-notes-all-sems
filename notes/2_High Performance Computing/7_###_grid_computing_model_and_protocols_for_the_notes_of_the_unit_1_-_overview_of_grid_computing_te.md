### Grid Computing Model and Protocols for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing
Grid Computing Model:
- Grid computing is a type of parallel and distributed system that enables sharing of resources among multiple computers.
- It involves pooling of resources like processing power, storage, and network bandwidth to solve complex problems.
- Grid computing is characterized by a virtual organization structure, where resources are shared across multiple administrative domains.

Protocols for Grid Computing:
- Grid protocols provide the underlying communication and coordination mechanisms for grid computing.
- Some common grid protocols are:
  - Global Grid Forum (GGF) protocols:
    - GridFTP: for data transfer in grid computing.
    - OGSA (Open Grid Services Architecture): for web services in grid computing.
  - Open Grid Forum (OGF) protocols:
    - Globus Toolkit: a software toolkit for grid computing.
    - Grid Security Infrastructure (GSI): for security in grid computing.

Note: The protocols mentioned above are just a few examples and there are many other protocols available for grid computing.
