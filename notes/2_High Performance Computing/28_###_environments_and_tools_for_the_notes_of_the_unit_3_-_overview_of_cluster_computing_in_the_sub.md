### Environments and Tools for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing
Environments and Tools for Cluster Computing:
- Cluster Management Software: software that automates the deployment, configuration, and management of a cluster. Examples: Rocks Cluster, OpenMPI, LSF, PBS.
- Cluster File Systems: file systems designed for use in a cluster environment. Examples: Lustre, GlusterFS, BeeGFS.
- Job Schedulers: software that manages and schedules jobs to run on the cluster. Examples: Slurm, Torque, Grid Engine.
- Virtualization: technology that allows multiple virtual machines to run on a single physical machine. Examples: VMware, KVM, Xen.
- Debugging Tools: tools that help diagnose and fix problems in cluster computing. Examples: TotalView, DDT, GDB.
- Performance Tools: tools that measure and analyze the performance of a cluster. Examples: Ganglia, Perfsuite, Scalasca.
