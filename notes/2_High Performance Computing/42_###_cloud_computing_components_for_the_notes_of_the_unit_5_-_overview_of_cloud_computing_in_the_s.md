### Cloud Computing Components for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing
Cloud Computing Components:
1. Front-end hardware: client devices accessing cloud services
2. Back-end hardware: server and storage systems that make up the cloud infrastructure
3. Network: communication between front-end and back-end components
4. Cloud software: management software for the cloud infrastructure
5. Cloud services: services provided to clients, such as virtual machines and storage
6. Data center: physical facilities where cloud infrastructure is housed
7. Management tools: tools used to manage and monitor cloud services and infrastructure.
