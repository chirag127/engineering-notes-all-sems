### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing
Storage for Unit 5 notes:
1. Cloud storage: using third-party providers to store data on remote servers that can be accessed through the internet.
2. Object storage: a type of cloud storage that uses a flat address space and can store unlimited amounts of unstructured data.
3. Block storage: a type of cloud storage that provides raw disk access to stored data and is commonly used for databases and file systems.
4. File storage: a type of cloud storage that provides a file-based interface for storing and accessing data.
5. Hybrid storage: a combination of different types of storage, including cloud and local storage, to meet specific needs.
6. Backup and disaster recovery: using cloud storage to backup data and ensure business continuity in case of a disaster.
