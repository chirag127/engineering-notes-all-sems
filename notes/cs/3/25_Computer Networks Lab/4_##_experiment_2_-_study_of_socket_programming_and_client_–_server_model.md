## Experiment 2 - Study of Socket Programming and Client – Server model

Experiment 2: Study of Socket Programming and Client-Server Model:
- This experiment covers the basics of socket programming and the client-server model.
- Topics may include:
  - Overview of socket programming and the client-server model.
  - Creating a socket, binding it to a port, and listening for incoming connections.
  - Implementing a client program that connects to a server using sockets.
  - Implementing a server program that accepts incoming connections and communicates with the client.
  - Transferring data between the client and server using sockets.
  - Implementing a simple application, such as a chat program, using the client-server model and socket programming.
  - Understanding the role of sockets in network programming and distributed systems.
  - Best practices for socket programming, including error handling, security, and performance.
