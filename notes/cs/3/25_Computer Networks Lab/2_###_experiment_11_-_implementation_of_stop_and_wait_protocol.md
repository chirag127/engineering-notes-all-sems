### Experiment 1.1 - Implementation of Stop and Wait Protocol

Experiment 1.1: Implementation of Stop and Wait Protocol:
- Stop and Wait Protocol is a simple protocol used for reliable data transmission in computer networks.
- In this experiment, the objective is to implement the Stop and Wait Protocol using a programming language such as C, Java, or Python.
- The implementation should include the following steps:
  - Creation of a sender and receiver process.
  - The sender process sends a data packet to the receiver process.
  - The receiver process sends an acknowledgment to the sender process after receiving the data packet.
  - The sender process waits for the acknowledgment before sending the next data packet.
  - The implementation should handle errors, such as lost or corrupted packets, and retransmit the data if necessary.
- The experiment should be tested for different scenarios, such as different data sizes, network conditions, and error rates, to evaluate the performance of the Stop and Wait Protocol.
