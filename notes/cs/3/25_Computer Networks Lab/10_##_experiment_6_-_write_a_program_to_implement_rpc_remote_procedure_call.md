## Experiment 6 - Write a program to implement RPC (Remote Procedure Call)

Experiment 6 - Write a program to implement RPC (Remote Procedure Call) covers the following topic:

1. RPC:
RPC (Remote Procedure Call) is a protocol that allows a computer program to make a request to a remote system and receive a response. It enables communication between separate processes running on different computers.

2. How it works:
RPC works by allowing a client program to make a request to a remote server, which then executes the requested procedure and returns the result to the client. The client program and the server program communicate using a common interface, which defines the procedures that can be called by the client.

3. Implementation:
Implementing RPC involves writing both the client program and the server program. The client program makes a request to the server program, which then executes the requested procedure and returns the result to the client.

4. Advantages:
RPC has several advantages, including:
1. Interprocess Communication: RPC enables communication between separate processes running on different computers, allowing for distributed computing.
2. Simplicity: RPC provides a simple and straightforward way to make requests and receive responses.
3. Scalability: RPC can be used to scale a system by adding more servers to handle the increased load.

In conclusion, RPC is a protocol that enables communication between separate processes running on different computers. Implementing RPC involves writing both the client program and the server program, and provides several advantages, including interprocess communication, simplicity, and scalability.
