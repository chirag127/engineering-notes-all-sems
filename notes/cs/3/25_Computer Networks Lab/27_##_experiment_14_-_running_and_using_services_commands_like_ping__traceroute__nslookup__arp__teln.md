## Experiment 14 - Running and using services/commands like ping, traceroute, nslookup, arp, telnet, ftp, etc

Experiment 14 - Running and Using Services/Commands:

In this experiment, you will learn how to run and use various services and commands, such as ping, traceroute, nslookup, arp, telnet, ftp, etc. These services and commands are used to perform various network-related tasks, such as testing network connectivity, resolving hostnames to IP addresses, and transferring files between devices.

Here is a brief description of each service/command:

1. Ping: The ping command is used to test network connectivity by sending an echo request to a device and measuring the time it takes to receive a response.

2. Traceroute: The traceroute command is used to determine the route that packets take from the source device to the destination device.

3. Nslookup: The nslookup command is used to resolve hostnames to IP addresses and vice versa.

4. Arp: The arp command is used to display and manipulate the ARP cache, which maps IP addresses to physical addresses.

5. Telnet: The telnet command is used to establish a remote connection to a device, allowing you to log in and run commands on the remote device.

6. FTP: The ftp command is used to transfer files between devices using the File Transfer Protocol (FTP).

To run these services and commands, you will typically use the command prompt or terminal on your computer. The syntax for each command will vary, so it is important to consult the documentation for each command to learn how to use it effectively.

In conclusion, this experiment provides an overview of various services and commands that are commonly used in computer networks, such as ping, traceroute, nslookup, arp, telnet, ftp, etc. By learning how to run and use these services and commands, you will gain a deeper understanding of how computer networks work, and how to troubleshoot network-related issues.
