## Experiment 13 - Configuration of router, hub, switch etc. (using real devices or simulators)

Experiment 13: Configuration of Router, Hub, Switch, etc.:
- This experiment covers the configuration of network devices such as routers, hubs, and switches.
- Topics may include:
- Overview of different types of network devices, including routers, hubs, switches, and firewalls.
- Configuration of network devices, including setting IP addresses, subnet masks, default gateways, and port configurations.
- Configuring VLANs, Virtual Local Area Networks, to segment networks into smaller sub-networks.
- Configuring routing protocols, such as OSPF and BGP, to exchange routing information between routers.
- Configuring security features, such as firewalls and access control lists, to protect the network from unauthorized access.
- Testing and troubleshooting network device configurations, including using network tools such as ping, traceroute, and netstat.
- Best practices for configuring network devices, including security, reliability, and performance considerations.
