### Experiment 11.1 - Link State routing

Experiment 11.1: Link State Routing:
- This experiment covers the study of link state routing in computer networks.
- Topics may include:
  - Overview of link state routing and its use in computer networks.
  - Study of the link state routing protocol (OSPF) and its operation.
  - Implementation of OSPF in a computer network, including the calculation of shortest paths and the exchange of link state information.
  - Comparison of link state routing with distance vector routing.
  - Analysis of the advantages and disadvantages of link state routing, including scalability, reliability, and security.
  - Best practices for designing and implementing link state routing in a computer network.
