## Experiment 4 - Write a code simulating PING and TRACEROUTE commands

Experiment 4: Writing a Code to Simulate PING and TRACEROUTE Commands:
- This experiment involves writing code to simulate the functionality of the PING and TRACEROUTE network diagnostic tools.
- PING is used to test the reachability of a network host and to measure the round-trip time for packets to travel from the source host to the target host and back.
- TRACEROUTE is used to determine the path taken by packets from the source host to the target host and to identify any intermediate routers along the way.
- The code can be written in a programming language such as Python or C and can use network sockets to send and receive packets.
- The code should be able to display the results of the PING and TRACEROUTE commands, including the round-trip time for PING and the path taken for TRACEROUTE.
- The experiment may also include a comparison of the results of the simulated PING and TRACEROUTE commands with the results of the actual PING and TRACEROUTE commands.
