### Experiment 11.3 - Distance vector

Experiment 11.3 - Distance Vector:

Distance Vector is a routing algorithm used in computer networks to determine the shortest path from one node to another. The basic idea behind Distance Vector is to maintain a table of the distances between each node in the network, and to update the table whenever a change occurs in the network.

The following are the steps involved in Experiment 11.3 - Distance Vector:

1. Network Configuration: The first step is to configure the network, by setting up nodes and connecting them with links.

2. Initialization: Each node initializes its distance table with its own distance to each of its neighbors, and the next hop to reach each neighbor.

3. Routing Updates: Each node periodically sends its distance table to its neighbors, and updates its own distance table based on the information received from its neighbors.

4. Convergence: The distance tables of all nodes in the network eventually converge to the same values, indicating that the shortest path from one node to another has been determined.

5. Path Selection: Once the distance tables have converged, each node selects the next hop to reach a destination based on the shortest distance in its distance table.

In conclusion, Experiment 11.3 - Distance Vector is a routing algorithm used in computer networks to determine the shortest path from one node to another. The basic steps in this experiment are network configuration, initialization, routing updates, convergence, and path selection. The goal of this experiment is to demonstrate the behavior of the Distance Vector algorithm, and to understand how it works in practice.
