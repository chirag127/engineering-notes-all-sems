## Unit 5 - Software Maintenance and Software Project Management

This unit will cover the following topics:

- Software Maintenance
- Types of software maintenance
- Software Project Management
- Project Management Processes
- Project Planning
- Project Monitoring and Control
- Project Closure

### Software Maintenance

Software maintenance is the process of modifying a software product after it has been delivered to the customer. The main goal of software maintenance is to preserve the value of software over time.

There are three types of software maintenance:

1. Corrective Maintenance: This type of maintenance is done to fix problems that are found in the software. The problems can be errors, bugs or defects.

2. Adaptive Maintenance: This type of maintenance is done to keep the software up-to-date with changes in the environment. The changes can be due to hardware, software or regulatory requirements.

3. Perfective Maintenance: This type of maintenance is done to improve the performance, maintainability or other attributes of the software.

### Software Project Management

Software Project Management is the process of managing software development projects. The main goal of software project management is to deliver a software product that meets the customer's requirements, on time and within budget.

The project management process consists of the following phases:

1. Project Planning: This phase involves defining the project scope, goals, objectives, and deliverables. The project manager should also identify the resources needed, estimate the time and cost, and create a project plan.

2. Project Monitoring and Control: This phase involves tracking the project progress, identifying and resolving problems, and maintaining project quality. The project manager should also manage the project budget, schedule, and scope.

3. Project Closure: This phase involves closing out the project and delivering the final product to the customer. The project manager should also conduct a post-project review and identify lessons learned for future projects.

In conclusion, software maintenance and software project management are important aspects of software development. Understanding these topics will help software developers and project managers deliver high-quality software products that meet the customer's requirements.
