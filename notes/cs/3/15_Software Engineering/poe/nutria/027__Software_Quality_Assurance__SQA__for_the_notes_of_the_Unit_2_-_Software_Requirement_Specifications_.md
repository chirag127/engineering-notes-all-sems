
### Software Quality Assurance (SQA) 

Software Quality Assurance (SQA) is a set of activities that ensure that software is developed and maintained to meet the requirements of the customer. SQA is a process that is used to ensure that the software meets the customer's expectations and is of high quality.

SQA activities include:

1. Establishing quality objectives 
2. Developing a test plan 
3. Executing the test plan 
4. Identifying and resolving software defects 
5. Documenting the results of the testing 

Software Requirement Specifications (SRS) 

Software Requirement Specifications (SRS) is a document that describes the functional and non-functional requirements of the software. It is used to define the scope of the software project and to ensure that all stakeholders understand what the software should do. 

The SRS should include:

1. Description of the intended purpose of the software 
2. Description of the functional requirements of the software 
3. Description of the non-functional requirements of the software 
4. Description of the user interface 
5. Description of the hardware and software environment 
6. Description of the security requirements 
7. Description of the data requirements 
8. Description of the performance requirements 
9. Description of the system constraints 
10. Description of the implementation requirements
