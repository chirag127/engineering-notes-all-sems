
### Data Flow Diagrams for the notes of the Unit 2 - Software Requirement Specifications (SRS) in the subject of Software Engineering

* Data Flow Diagrams (DFDs) are graphical representations of the flow of data between different processes within a system.
* They are used to show the relationships between different processes and the data that flows between them. 
* A DFD consists of four main components: 
  1. Processes: Represent the activities that transform input data into output data.
  2. Data Stores: Represent the persistent data that is stored in a system.
  3. Data Flows: Represent the movement of data between processes and data stores.
  4. External Entities: Represent the sources and destinations of data outside the system.
* DFDs are used to analyze and design information systems, as well as to document existing systems.
* DFDs are used to identify the requirements of a system and to design the system architecture.
* DFDs can also be used to identify potential problems in a system, such as data redundancy or lack of data integrity.
