
### Static Testing Strategies for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

1. **Static Analysis**: Static Analysis is a type of software testing technique used to identify errors and defects in the source code without executing the code. It is also known as White Box Testing and it is used to identify the errors in the software code.

2. **Code Reviews**: Code Reviews are a type of software testing technique used to detect errors and defects in the source code. A code review is conducted by one or more people who examine the source code and make suggestions for improvement.

3. **Walkthroughs**: Walkthroughs are a type of software testing technique used to identify errors and defects in the source code. A walkthrough is conducted by one or more people who examine the source code line by line and make suggestions for improvement.

4. **Static Code Analysis Tools**: Static Code Analysis Tools are a type of software testing technique used to detect errors and defects in the source code. These tools analyze the source code and generate a report on the errors and defects found in the code.

5. **Unit Testing**: Unit Testing is a type of software testing technique used to identify errors and defects in the source code at the unit level. It is used to test individual units of code to identify any errors or defects in the code.

6. **Code Coverage**: Code Coverage is a type of software testing technique used to measure the amount of code that has been tested. It is used to identify which parts of the code have been tested and which parts have not been tested.
