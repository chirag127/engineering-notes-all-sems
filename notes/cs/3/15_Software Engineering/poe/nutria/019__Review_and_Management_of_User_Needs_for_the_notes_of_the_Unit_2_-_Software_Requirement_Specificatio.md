
### Review and Management of User Needs for the Notes of the Unit 2 - Software Requirement Specifications (SRS) in the Subject of Software Engineering

1. User needs are the requirements that the software must meet in order to satisfy the needs of the user.
2. User needs should be identified, analyzed and documented during the software requirements specification (SRS) process.
3. User needs can be divided into functional and non-functional requirements.
4. Functional requirements describe what the software should do, while non-functional requirements describe how the software should behave.
5. The user needs should be reviewed and managed throughout the software development life cycle in order to ensure that the software meets the user’s needs.
6. User needs should be prioritized in order to ensure that the most important requirements are addressed first.
7. User needs should be validated to ensure that they are achievable and that they meet the user’s expectations.
8. User needs should be tracked and monitored throughout the software development life cycle to ensure that they are being met.
9. User feedback should be incorporated into the software development process in order to ensure that the software meets the user’s needs.
