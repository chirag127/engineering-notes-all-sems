
### Object Oriented Design

* Object-oriented design (OOD) is a software design methodology that focuses on creating objects that represent real-world entities and their interactions.
* OOD is based on the concept of abstraction, which is the process of removing unnecessary details from a problem in order to focus on the essential aspects.
* OOD involves creating classes, which are templates for objects, and objects, which are instances of classes.
* Classes contain attributes, which define the characteristics of the objects, and methods, which define the behavior of the objects.
* Classes can also be organized into hierarchies, which allow objects to inherit attributes and methods from parent classes.
* OOD also involves creating relationships between classes, such as associations, aggregations, and compositions.
* OOD is used to create software that is maintainable, extensible, and reusable.
