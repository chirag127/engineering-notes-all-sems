
### Information Modelling for the notes of the Unit 2 - Software Requirement Specifications (SRS) in the subject of Software Engineering

1. Information modelling is the process of creating a representation of a system or process. It is used to capture the requirements of a software system, and to create a visual representation of the system’s design.

2. Software Requirements Specifications (SRS) is a document that describes the requirements of a software system. It includes a description of the system’s functionality, its performance, the system’s external interfaces, and any other requirements that must be met in order for the system to be successful.

3. The SRS is used to define the scope of the software project, and to document the requirements of the system. It should be written in a clear and concise manner, and should include all of the necessary information for the development team to understand the requirements of the system.

4. The SRS should include a description of the system’s user interface, the system’s data model, the system’s security requirements, and any other requirements that must be met in order for the system to be successful.

5. The SRS should be reviewed and approved by all stakeholders before the development process begins. This will ensure that all requirements are understood and agreed upon before the development process begins.
