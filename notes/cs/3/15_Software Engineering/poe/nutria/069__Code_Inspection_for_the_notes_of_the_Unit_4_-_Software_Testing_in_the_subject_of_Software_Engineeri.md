
### Code Inspection

Code inspection is a static software testing technique used to identify defects in the source code of a program. It is also known as peer review, code review or software review.

* Code inspection involves a careful examination of the source code by a trained professional.
* The purpose of code inspection is to identify and eliminate defects in the source code.
* Code inspection is an effective way to detect syntax errors, logical errors, and design flaws.
* Code inspection is an efficient way to detect coding standards violations and coding conventions.
* Code inspection can be used to identify potential security vulnerabilities and design flaws.
* During code inspection, the code is read line-by-line and each statement is inspected for correctness, completeness, and adherence to coding standards.
* Code inspection is a time-consuming process, but it is an effective way to ensure that the code is of high quality.
