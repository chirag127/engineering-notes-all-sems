
### Unit Testing for the Notes of Unit 4 - Software Testing in the Subject of Software Engineering

1. Unit testing is a type of software testing that focuses on individual units or components of a software system. 
2. Unit tests are usually written by developers and are used to ensure that the code they have written is working correctly.
3. Unit testing is done at the component level before any integration testing is done.
4. Unit tests are used to validate that a unit of code works as expected.
5. Unit tests are typically written using a unit testing framework, such as JUnit, NUnit, or xUnit.
6. Unit tests are typically written using a test-driven development (TDD) approach, where the tests are written before the code.
7. Unit tests can be used to detect and prevent defects in the code.
8. Unit tests should be automated to ensure that they are run regularly and consistently.
9. Unit tests should be written to cover all possible paths through the code.
10. Unit tests should be written to test the boundary conditions of the code.
