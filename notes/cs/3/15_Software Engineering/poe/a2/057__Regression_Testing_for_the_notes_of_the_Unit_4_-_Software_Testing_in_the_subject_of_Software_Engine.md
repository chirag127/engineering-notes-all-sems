### Regression Testing for the notes of the Unit 4 - Software Testing in the subject of Software Engineering.

1. Regression Testing is performed to ensure that the changes made to the software do not affect the existing functionality. It is done after changes are made to the software to detect bugs early and ensure high quality software.
2. The test cases used for regression testing are derived from the previous test cases of the unchanged parts of the software. The previously used test cases are reused to test the unchanged parts after modifications to check for any faults.
3. Regression testing is often automated by using scripted test cases. This saves time and effort in regression testing as testers do not have to manually execute each test case. Automation of regression testing ensures consistent and comprehensive testing.
4. Challenges in regression testing include determination of the scope of regression testing, selection of test cases for regression testing and maintenance of automated regression test scripts as software changes.
5. Regression testing is an important type of software testing that is performed repeatedly during the software development lifecycle to detect bugs at an early stage and ensure that modifications made to the software have not adversely affected the existing functionality. It increases the reliability and quality of the software.
