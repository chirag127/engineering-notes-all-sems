### Software Quality Frameworks

1. ISO 9126 Quality Model
- Functionality: Suitability, Accuracy, Interoperability, Security
- Reliability: Maturity, Fault Tolerance
- Usability: Understandability, Learnability, Operability
- Efficiency: Time Behavior, Resource Utilization
- Maintainability: Analyzability, Changeability, Stability, Testability
- Portability: Adaptability, Installability, Replaceability

2. McCall's Quality Model
- Correctness: Meets specifications and fulfills purpose
- Reliability: Consistent intended performance
- Efficiency: Appropriate use of resources
- Integrity: Accurate and complete
- Usability: Easily and effectively used
- Maintainability: Easily modified
- Testability:can be validated

3. Boehm's Quality Model
- Maintainability: Ease of corrections and changes
- Verifiability: Testable and measurable
- Testability: Conformance to specifications
- Functionality: Services provided and inputs/outputs
- Reliability: Continued delivery of services
- Usability: Ease of learning and use
- Efficiency: Resource usage

4. Dromey's Quality Model
- Correctness: Meets specifications
- Reliability: Consistent performance
- Robustness: Graceful degradation
- Integrity: Complete and accurate data
- Security: Protection from unauthorized access/use
- Efficiency: Appropriate resource utilization
- Portability: Adaptability to new environments
