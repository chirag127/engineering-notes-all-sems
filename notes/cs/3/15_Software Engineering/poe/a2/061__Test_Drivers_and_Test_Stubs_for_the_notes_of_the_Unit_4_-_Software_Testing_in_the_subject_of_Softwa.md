### Test Drivers and Test Stubs for the notes of the Unit 4 - Software Testing in the subject of Software Engineering.

1. Test Drivers:
- A test driver is a program module that provides test inputs to the component being tested and analyzes its outputs.
- It is used to control and coordinate the testing of a module.
- It typically handles flow of control and data to drive the module through a sequence of test cases.
- It simulates the calling environment of the module.

2. Test Stubs:
- A test stub is a dummy called module that provides predetermined responses to calls made to it by the module being tested.
- It is used in a top-down approach to testing when lower level modules are not yet available.
- It simulates the modules that would normally interact with the module being tested.
- It provides test inputs to and checks outputs from the module being tested.

The above points cover the key concepts and definitions regarding Test Drivers and Test Stubs which are techniques used for unit testing software modules.
