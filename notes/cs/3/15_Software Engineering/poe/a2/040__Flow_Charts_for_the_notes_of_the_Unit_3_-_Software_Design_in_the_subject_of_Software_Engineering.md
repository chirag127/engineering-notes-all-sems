### Flow Charts for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Flow charts are diagrams that show the sequence of steps in a process.
2. They are used to visually represent algorithms and process flows.
3. The flow chart uses standard symbols to represent the different steps. Some of the common symbols are:
 - Oval or round shape: Start or End
 - Rectangle: Process or Action
 - Diamond: Decision
 - Arrow: Flow of sequence
4. The flow charts always start with a start symbol and end with an end symbol. The other symbols are connected using arrows to show the flow of sequence.
5. The flow charts can be broadly categorized into:
 - Sequential: Steps are followed in a sequential manner.
 - Decision: Based on a decision, the flow can take two or more paths.
 - Iterative: A step can be repeated multiple times until a condition is met.

The flow charts are a key technique used in software engineering to visually represent the design of the software or algorithm. They help identify any flaws in the logic and are easy to understand. The standardized symbols make the flow charts easily comprehensible to anyone reading them.
