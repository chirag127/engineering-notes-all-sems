### Design Structure Charts for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Design Structure Matrix (DSM):
- It is a simple matrix-based modeling technique for analyzing and managing dependencies between components or tasks.
- It represents components or tasks as a square matrix and dependency between them as marked cells.
- It helps in scheduling, risk analysis, and management of dependencies.

2. Dependency Structure Matrix (DSM):
- It is a variation of Design Structure Matrix (DSM) used in software engineering to analyze dependencies between software artifacts.
- It represents modules or components of a software system as a square matrix and dependency between them using marked cells.
- It helps in assessing modularity, parallelism, and manage coupling between software components.

3. Nassi-Shneiderman charts:
- It is a graphical design representation technique that presents the control flow of a program using rectangles and arrows.
- The flow of control is shown using arrows and different structures like sequence, selection, iteration, and concurrency are represented using different shapes of the boxes.
- It increases the understandability of the system and helps in step-wise refinement of the system.
