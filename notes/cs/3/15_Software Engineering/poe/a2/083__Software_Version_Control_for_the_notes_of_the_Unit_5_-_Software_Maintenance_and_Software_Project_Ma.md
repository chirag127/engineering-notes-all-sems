### Software Version Control for the notes of the Unit 5 - Software Maintenance and Software Project Management in the subject of Software Engineering.

1. Version Control System (VCS) - A version control system is a software tool that helps software teams manage changes to source code over time. It allows you to revert files back to a previous state, revert the entire project back to a previous state, compare changes over time, see who last modified something that might be causing a problem, who introduced an issue and when, and more.

2. Types of VCS - There are three common types of VCS:

- Local VCS - The database is kept on local machine. developers periodicially share their changes by sending patches to each other. Limitation is it lacks concurrency.
- Centralized VCS - There is a central server that contains all the versioned files and a team of developers check out files from this central repository. Allows concurrency but single point of failure. Eg. SVN.
- Distributed VCS - Every developer's working copy of the code is a full backup of the central repository. Allows easy branching and merging, higher tolerance to failures and optimal performance with large projects. Eg. Git, Mercurial.

3. Benefits of VCS -

- Maintains history of changes
- Facilitates Collaboration
- Allows rollback to previous versions
- Supports Parallel Development
- Aids in debugging
- Enforces Coding Standards through commits
- Supports Automated Deployments

4. Git - Git is a free and open source distributed version control system designed to handle everything from small to very large projects with speed and efficiency. Some key concepts in Git are:

- Repository - contains all files and stores metadata and object database for the project.
- Commit - snapshots of project at a particular point of time.
- Branch - Independent line of development.
- Merge - To integrate branches together.
- Clone - Copy of an existing Git repository.
- Push - Upload local repository content to a remote repository.
- Pull - Download content from a remote repository into local repo.
- Checkout - Used to switch between branches or restore working tree files.
