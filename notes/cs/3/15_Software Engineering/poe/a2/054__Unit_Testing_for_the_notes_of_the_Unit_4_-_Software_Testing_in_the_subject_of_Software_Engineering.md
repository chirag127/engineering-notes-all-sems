### Unit Testing for the notes of the Unit 4 - Software Testing in the subject of Software Engineering.

1. Unit Testing is a level of software testing where individual units or components of a software are tested. The purpose is to validate that each unit of the software performs as designed.
2. Unit Testing is done during the development (coding phase) of an application by the developers.
3. Unit Tests are created before writing the actual code. This is known as Test Driven Development (TDD).
4. The goal of Unit Testing is to isolate a section of code and verify its correctness. A unit may be an individual function, method, procedure, module, or object.
5. Important benefits of Unit Testing are:
- Identifies early defects and errors
- Improves and documents the code functionality
- Facilitates changes to the code
- Increases the quality of the code
- Reduces debugging time
6. Examples of Unit Testing:
- Testing a method to return correct result for given inputs
- Testing a method to handle incorrect inputs properly
- Testing getter and setter methods of a class
- Testing the logic of a decision making code, etc.
