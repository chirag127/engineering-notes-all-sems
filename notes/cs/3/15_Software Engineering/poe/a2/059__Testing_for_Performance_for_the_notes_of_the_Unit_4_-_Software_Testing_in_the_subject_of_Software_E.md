### Testing for Performance for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

1. Performance testing is done to determine the speed or responsiveness of a system. It is conducted to evaluate the system's performance against specified performance requirements.
2. It helps to identify and remove the performance bottlenecks.
3. It determines if the system meets the desired performance requirements under normal and peak loads.
4. It identifies the maximum load the system can handle without significant performance degradation.
5. Types of Performance Tests:
    - Load testing - testing the system with increasing load to identify the maximum load it can handle.
    - Stress testing - testing the system with load higher than the maximum capacity to identify the point of system failure.
    - Spike testing - sudden increase of load on the system to check performance.
    - Endurance testing - checking performance of the system with continuously high load for extended duration of time.
    - Scalability testing - testing with rapidly increasing load to determine how the system handles growth.
6. Performance testing metrics include:
    - Response time - time taken to respond to a request.
    - Throughput - number of transactions completed in a unit of time.
    - Utilization - percentage of components used.
    - Errors - number of errors occurred.
    - Resource usage - memory, CPU, etc. usage.

7. Performance testing tools include:
    - JMeter - open source tool to load test functional behavior and measure performance.
    - LoadRunner - commercial performance and load testing tool by HP.
    - WebLOAD - commercial tool for web performance and load testing.
    - Apache Bench (ab) - command line tool to benchmark HTTP server performance.
