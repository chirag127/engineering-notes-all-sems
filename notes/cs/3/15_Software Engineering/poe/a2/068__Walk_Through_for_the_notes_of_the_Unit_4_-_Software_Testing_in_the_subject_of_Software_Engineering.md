### Walk Through for the notes of the Unit 4 - Software Testing in the subject of Software Engineering.

1. Software Testing - Software testing is a process of executing a program or application with the intent of finding software bugs (errors or other defects). 
2. The purpose of software testing is to identify errors, gaps or missing requirements in contrary to the actual requirements.
3. Different Types of Software Testing - There are various types of software testing which can be performed. Some of the major types are:
 - Unit Testing - Testing individual software components.
 - Integration Testing - Testing combined parts of the software.
 - System Testing - Testing the complete software product.
 - Acceptance Testing - Testing by the customer under a real-world environment.
4. Manual vs Automated Testing - Manual testing is performed manually by a tester while automated testing makes use of automation tools to execute tests and compare results. Automated testing is more efficient and effective but requires initial effort and resources to set up the automation infrastructure.
5. Test Case - A test case is a set of conditions or variables under which a tester will determine whether a system under test satisfies requirements or works correctly. A test case should consist of input data, expected output and actual output.
6. Test Suite - A test suite is a collection of test cases which are intended to be used to test a software program to show that it has some specified set of behaviours.
