### Cyclomatic Complexity Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering:

1. Cyclomatic Complexity: It is a software metric used to measure the complexity of a program. It is computed as:
Cyclomatic Complexity = E - N + 2
Where E is the number of edges of the graph and N is the number of nodes of the graph.
A higher cyclomatic complexity indicates that the program is complex and more prone to errors.

2. Essential Complexity: It is the minimum cyclomatic complexity required to solve a given problem. It depends on the number of independent paths in the flow graph.
Essential Complexity = Number of independent paths

3. Accidental Complexity: It is the additional complexity in a program other than the essential complexity to solve the given problem. It can be reduced by using better programming practices and techniques.
Accidental Complexity = Cyclomatic Complexity - Essential Complexity

The above points cover the key metrics for measuring cyclomatic complexity in software and components of a program's complexity.
