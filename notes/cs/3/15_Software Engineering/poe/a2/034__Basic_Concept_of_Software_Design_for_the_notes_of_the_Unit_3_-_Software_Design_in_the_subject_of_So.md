### Basic Concept of Software Design

1. Modularization: Breaking down the system into modules (self-contained components) that perform specific functions. This increases understandability and maintainability.
2. Abstraction: Hiding the complexity of lower-level details and showing only essential features. This reduces complexity and increases portability.
3.Hierarchy: Arranging system components in a hierarchy showing the dependencies between components. This increases understandability and maintainability.
4. Separation of concerns: Separating a computer program into components/modules that each handle a separate concern. This increases cohesion, understandability and maintainability.
5. Loose coupling: Reducing the interdependencies between components. This increases the flexibility and reusability of components.
6. Information hiding: Hiding the internal details of a component/module from other components and revealing only the essential information. This reduces complexity and increases understandability, maintainability and reusability.

The concepts listed above make the software design more efficient, flexible, reusable, maintainable and understandable. Applying these concepts appropriately leads to a good software design.
