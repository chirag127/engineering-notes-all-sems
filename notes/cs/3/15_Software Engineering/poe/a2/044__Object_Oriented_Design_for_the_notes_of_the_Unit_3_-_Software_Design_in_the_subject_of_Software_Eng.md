### Object Oriented Design for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Object Oriented Design (OOD) is a design paradigm based on the concept of "objects", which are usually instances of classes. 
2. OOD focuses on representing problems as a set of interacting objects that have data and methods. 
3. The key principles of OOD are encapsulation, inheritance, polymorphism, and abstraction.
4. Encapsulation refers to hiding the internal details of an object and only exposing its interfaces to the outside. This helps to reduce coupling between objects.
5. Inheritance allows a class to inherit the properties and methods of another class, thereby promoting code reuse and establishing is-a relationships.
6. Polymorphism allows objects of different classes to respond to the same method calls. This allows the same interface to have different underlying implementations.
7. Abstraction focuses on essential characteristics and ignores the details. Abstract classes are used to define interfaces and partial implementations.
8. The steps in OOD are: identify objects and responsibilities, define interfaces, refine interfaces and add methods, evaluate design, and iterate.
9. OOD provides several benefits such as increased maintainability, reusability, extensibility, and reduced complexity. However, it may lead to over-engineering if taken to an extreme.
