### Perfective Maintenance for the notes of the Unit 5 - Software Maintenance and Software Project Management in the subject of Software Engineering

Perfective Maintenance is a type of software maintenance that involves making improvements or adding new functionality to a software system. The following are some of the key concepts related to perfective maintenance:

1. Requirements Gathering: Requirements gathering is the process of collecting and documenting the requirements for the improvements or new functionality to be added to the software system.

2. Change Management: Change management is the process of controlling and tracking changes to the software system, including the changes made during perfective maintenance.

3. Impact Analysis: Impact analysis is the process of evaluating the impact of changes to the software system, including the impact of changes made during perfective maintenance.

4. Testing: Testing is the process of evaluating the software system to ensure that it meets the requirements and that it is free of bugs and other defects. Testing is an important step in perfective maintenance to ensure that the changes made to the software system do not introduce new bugs or defects.

5. Deployment: Deployment is the process of delivering the software system to the end-users. Deployment is an important step in perfective maintenance to ensure that the changes made to the software system are available to the end-users.

6. Documentation: Documentation is the process of creating and maintaining documentation for the software system, including the documentation for the changes made during perfective maintenance.

In this unit, you will learn about perfective maintenance and the key concepts related to it, including requirements gathering, change management, impact analysis, testing, deployment, and documentation.

This unit will provide a foundation for understanding the principles and practices of software maintenance and software project management, and for exploring the various concepts and techniques used in the field of Software Engineering.
