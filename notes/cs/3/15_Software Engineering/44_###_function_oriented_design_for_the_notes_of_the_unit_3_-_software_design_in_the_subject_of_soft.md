### Function Oriented Design for the notes of the Unit 3 - Software Design in the subject of Software Engineering

Function Oriented Design is a software design approach that focuses on the functional requirements of a software system and the functions that the system must perform to meet those requirements. The following are some of the key concepts related to Function Oriented Design:

1. Function Decomposition: Function Decomposition is the process of breaking down the functional requirements of a software system into smaller, manageable functions.

2. Function Specification: Function Specification is the process of documenting the functions of a software system, including the inputs, outputs, and processing steps.

3. Data Flow Diagrams: Data Flow Diagrams are graphical representations of the functions of a software system, and they show the flow of data between functions.

4. Function Modules: Function Modules are the building blocks of a software system, and they represent the functions that the system must perform.

5. Function Allocation: Function Allocation is the process of assigning functions to specific components or modules of a software system.

6. Function Testing: Function Testing is the process of testing the functions of a software system to ensure that they meet the requirements and that they are free of bugs and other defects.

In this unit, you will learn about Function Oriented Design and how it is used in software engineering. You will also learn about the key concepts related to Function Oriented Design, including function decomposition, function specification, data flow diagrams, function modules, function allocation, and function testing.

This unit will provide a foundation for understanding the principles and practices of software design, and for exploring the various concepts and techniques used in the field of Software Engineering.
