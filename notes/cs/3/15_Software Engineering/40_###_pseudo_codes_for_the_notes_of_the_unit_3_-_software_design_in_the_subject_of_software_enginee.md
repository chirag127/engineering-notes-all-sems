### Pseudo Codes for the notes of the Unit 3 - Software Design in the subject of Software Engineering

Pseudo codes are a high-level representation of a software system's algorithms, used to describe the logic of a program before it is actually implemented. In the context of Unit 3 - Software Design in the subject of Software Engineering, students will learn about pseudo codes and how they are used in the software design process.

Pseudo codes are written in a language that is similar to a programming language, but is not a complete programming language. They are used to describe the logic of a program in a clear and concise manner, and to help designers and developers understand the program's behavior.

In the Unit 3 - Software Design in the subject of Software Engineering, students will learn how to create effective pseudo codes that describe the logic of a program. This may include working with examples of pseudo codes, analyzing the benefits and limitations of pseudo codes, and learning how to use pseudo codes to design and implement software systems.

In summary, in the Unit 3 - Software Design in the subject of Software Engineering, students will learn about pseudo codes, a high-level representation of a software system's algorithms used to describe the logic of a program before it is actually implemented. They will learn how to create effective pseudo codes and how to use pseudo codes in the software design process.
