### Design Strategies for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- Design strategies are the approaches that are taken to design a software system that meets the requirements and specifications.
- Design strategies involve making decisions about the architecture, components, modules, interfaces, and data for a software system.
- There are three major system design strategies in software engineering: structured design, function-oriented design, and object-oriented design.
  - Structured design is a design strategy that focuses on the decomposition of a system into modules that have well-defined inputs and outputs, and that can be tested and maintained independently.
  - Function-oriented design is a design strategy that focuses on the identification and grouping of functions that are performed by a system, and the data that is manipulated by those functions.
  - Object-oriented design is a design strategy that focuses on the identification and grouping of objects that are relevant to a system, and the behaviors and interactions of those objects.
- There are two common ways to apply design strategies in software engineering: top-down design and bottom-up design.
  - Top-down design is a design strategy that starts with a high-level view of the system and gradually breaks it down into smaller, more manageable components.
  - Bottom-up design is a design strategy that starts with the low-level components of the system and gradually integrates them into larger, more complex components.
- Design strategies can also be influenced by the software architecture patterns that are used to describe the structure and behavior of a software system.
  - Software architecture patterns are reusable schemes that address common software design challenges, such as performance, scalability, reliability, security, etc.
  - Some examples of software architecture patterns are: layered pattern, client-server pattern, microservices pattern, event-driven pattern, etc.
