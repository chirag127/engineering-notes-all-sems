### Flow Charts for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- A flow chart is a graphical representation of an algorithm or a process that uses basic shapes and symbols to show the flow of information and processing .
- Flow charts are useful for programmers to plan and design software solutions, as well as to communicate and document the logic and structure of the program .
- Flow charts consist of the following elements:
  - Start and end symbols: usually represented by circles or ovals, they mark the beginning and the end of the flow chart.
  - Process symbols: usually represented by rectangles, they show the steps or actions that are performed in the algorithm or process.
  - Decision symbols: usually represented by diamonds, they show the points where a condition is checked and a branch is taken based on the result.
  - Input/output symbols: usually represented by parallelograms, they show the points where data is entered or displayed by the program.
  - Flow lines: usually represented by arrows, they show the direction and sequence of the flow of information and processing.
- Flow charts follow some basic rules and conventions, such as:
  - The flow chart should have a clear start and end point.
  - The flow chart should flow from top to bottom or left to right, unless there is a loop or a jump.
  - The flow lines should not cross each other, unless there is no alternative.
  - The symbols should be labeled with concise and meaningful text.
  - The symbols should be connected by only one flow line, unless there is a decision or a merge.
  - The decision symbol should have only two outgoing flow lines, labeled with yes/no or true/false.
- Flow charts can be drawn using various tools, such as:
  - Lucidchart: a web-based diagramming tool that offers a Microsoft Visio alternative and compatibility, as well as a large library of templates and shapes.
  - Microsoft Visio: a desktop diagramming tool that is integrated with the Office suite and offers advanced features and customization options.
  - Textografo: a text-based diagramming tool that allows users to create flow charts by typing simple commands and keywords.
  - diagrams.net: a free and open source diagramming tool that can be used online or offline, and supports various formats and integrations.
  - SmartDraw: a desktop and online diagramming tool that offers the biggest collection of diagramming templates and examples, as well as automated features and collaboration tools.
  - EdrawMax: an online diagramming tool that supports various types of diagrams, including data flow diagrams, which are related to flow charts and show how data moves through a system .
