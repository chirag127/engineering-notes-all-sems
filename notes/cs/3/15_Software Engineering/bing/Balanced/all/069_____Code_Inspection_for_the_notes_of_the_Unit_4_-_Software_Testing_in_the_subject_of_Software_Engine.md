# Code Inspection for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

- Code inspection is a type of static testing which aims in reviewing the software code and examining for any errors in that .
- Code inspection checks for common programming errors, such as syntax errors, logic errors, memory leaks, security vulnerabilities, etc .
- Code inspection helps in reducing the ratio of defect multiplication and avoids later-stage error detection by simplifying all the initial error detection processes.
- Code inspection also improves the quality of the code, the readability of the code, the maintainability of the code, and the adherence to the coding standards and guidelines.
- Code inspection can be performed manually or with the help of automated tools.
- Code inspection involves the following steps:
  - Planning: The code inspection team is formed, the roles and responsibilities are assigned, the scope and objectives of the inspection are defined, and the schedule and resources are planned.
  - Preparation: The code inspection team reviews the code and the related documents, such as design specifications, test cases, etc. The team identifies the potential defects and prepares a checklist of items to be verified during the inspection.
  - Inspection: The code inspection team meets and discusses the code and the checklist. The team records the defects and the suggestions for improvement. The team also evaluates the effectiveness of the inspection process and the quality of the code.
  - Rework: The code inspection team reports the defects and the suggestions to the code author. The code author fixes the defects and implements the suggestions. The code author also verifies that the code is free of defects and meets the requirements.
  - Follow-up: The code inspection team reviews the reworked code and confirms that the defects are resolved and the suggestions are implemented. The team also updates the checklist and the documents. The team closes the inspection process and documents the results and the lessons learned.
