# Decision Tables

- A decision table is a tabular representation of the logical rules that govern the behavior of a system or a component based on different combinations of inputs and outputs.
- A decision table consists of four quadrants: condition stub, condition entry, action stub, and action entry.
- The condition stub lists the possible inputs or conditions that affect the system or component.
- The condition entry lists the values or states of each condition for each possible scenario or rule.
- The action stub lists the possible outputs or actions that the system or component can perform.
- The action entry lists the values or states of each action for each possible scenario or rule.
- A decision table can be used to specify the functional requirements of a system or component in a clear and concise way.
- A decision table can also be used to verify the completeness and consistency of the requirements by checking for missing, redundant, or conflicting rules.
- A decision table can be converted into a decision tree, which is a graphical representation of the logical rules using nodes and branches.
- A decision tree can be used to visualize the flow of logic and the dependencies among the conditions and actions.
- A decision tree can also be used to simplify the decision table by eliminating duplicate or irrelevant branches.
