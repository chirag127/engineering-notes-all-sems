## Unit 1 - Introduction to Software Engineering

- Software engineering is the discipline of designing, developing, testing, and maintaining software systems that meet the needs and expectations of users and stakeholders.
- Software engineering is not only about writing code, but also about applying engineering principles and methods to software development, such as analysis, design, modeling, verification, validation, quality assurance, project management, and documentation.
- Software engineering is motivated by the challenges and opportunities of developing software systems that are complex, large-scale, distributed, concurrent, adaptive, reliable, secure, and efficient.
- Software engineering is influenced by the characteristics and requirements of the application domains, such as web, mobile, embedded, scientific, enterprise, and gaming software.
- Software engineering is also affected by the rapid changes and evolution of technology, such as programming languages, frameworks, tools, platforms, and standards.
- Software engineering is a team-based and collaborative activity that involves multiple roles and responsibilities, such as software engineers, software architects, software testers, software managers, software customers, and software users.
- Software engineering is a dynamic and creative process that requires continuous learning and improvement, as well as ethical and professional conduct.
