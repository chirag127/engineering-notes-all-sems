### Architectural Design for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- Architectural design is the process of defining a collection of hardware and software components and their interfaces to establish the framework for the development of a computer system.
- Architectural design is about decomposing the system into interacting components that provide the required functionality, quality, and performance.
- Architectural design is expressed as a block diagram defining an overview of the system structure, features of the components, and how these components communicate with each other to share data.
- Architectural design is of crucial importance in software engineering as it deals with the essential requirements like reliability, cost, and performance of the system.
- Architectural design also helps in planning, managing, and controlling the development process, as well as facilitating communication and collaboration among the stakeholders.
- Architectural design can be influenced by various factors, such as the type of system, the domain, the user needs, the technology, the standards, the constraints, and the trade-offs.
- Architectural design can be performed using various methods, such as top-down, bottom-up, iterative, or incremental approaches.
- Architectural design can be represented using various models, such as structural, behavioral, or functional models.
- Architectural design can be evaluated using various criteria, such as consistency, completeness, correctness, modularity, cohesion, coupling, reusability, scalability, maintainability, testability, and usability.
- Architectural design can be implemented using various tools, such as architecture description languages, frameworks, patterns, or software architecture software .
- Architectural design can be documented using various formats, such as text, diagrams, tables, or matrices.
- Architectural design can be verified and validated using various techniques, such as reviews, inspections, testing, or analysis.
- Architectural design can be evolved and adapted to changing requirements, technologies, or environments using various strategies, such as refactoring, restructuring, or reengineering.
