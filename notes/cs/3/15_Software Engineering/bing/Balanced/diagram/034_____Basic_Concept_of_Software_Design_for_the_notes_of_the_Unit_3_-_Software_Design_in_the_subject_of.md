### Basic Concept of Software Design

- Software design is the process of envisioning and defining software solutions to one or more sets of problems.
- Software design is also the process by which an agent creates a specification of a software artifact intended to accomplish goals, using a set of primitive components and subject to constraints.
- Software design is a part of the software development process, which refers to a set of computer science activities dedicated to the process of creating, designing, deploying and supporting software.
- Software design is based on the software requirements analysis (SRA), which is a part of the software development process that lists specifications used in software engineering.
- Software design is a process to transform user requirements into some suitable form, which helps the programmer in software coding and implementation.
- Software design involves the following principles:
  - Abstraction: hiding irrelevant data and details to reduce complexity and increase efficiency.
  - Modularity: subdividing the system or project into smaller and independent parts to facilitate development, testing and maintenance.
  - Coupling: the degree of interdependence between software modules. Low coupling is desirable as it reduces the impact of changes and errors in one module on others.
  - Cohesion: the degree of relatedness and consistency among the elements of a software module. High cohesion is desirable as it increases the readability and reusability of the module.
  - Encapsulation: hiding the internal details and data of a software module from other modules. It supports abstraction, modularity and information hiding.
  - Inheritance: the mechanism of reusing the properties and behaviors of a parent class by a child class. It supports code reuse and polymorphism.
  - Polymorphism: the ability of an object to behave differently depending on the context. It supports dynamic binding and flexibility.
