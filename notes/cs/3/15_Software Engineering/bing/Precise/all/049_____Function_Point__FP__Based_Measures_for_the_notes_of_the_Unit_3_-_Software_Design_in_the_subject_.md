# Function Point (FP) Based Measures

Function Point (FP) is a unit of measurement used to express the amount of business functionality provided by a software system. It is a standardized method for measuring the size of a software application, based on the user's view of the system.

Here are some key points to note about Function Point (FP) Based Measures:

1. Function Point (FP) Based Measures are used to estimate the size of a software system based on the functionality it provides to the user.
2. FP measures are independent of the technology used to implement the system, making them useful for comparing systems developed using different technologies.
3. FP measures are based on the user's view of the system, rather than the developer's view. This means that they take into account the functionality that is visible to and usable by the user, rather than the underlying code and architecture of the system.
4. FP measures are calculated by counting the number of inputs, outputs, inquiries, internal logical files, and external interface files in the system, and applying a weighting factor to each based on its complexity.
5. FP measures can be used to estimate the effort required to develop a software system, as well as to track the progress of development and to measure productivity.
