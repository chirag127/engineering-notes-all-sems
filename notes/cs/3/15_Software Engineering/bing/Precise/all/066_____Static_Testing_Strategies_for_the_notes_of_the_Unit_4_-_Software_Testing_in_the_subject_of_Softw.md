# Static Testing Strategies

Static testing is a type of software testing method that checks for defects in software without actually executing the code of the software application. It is performed to analyze the code, requirement documents, and design documents to find errors. Static testing is about the prevention of defects, while dynamic testing is about finding and fixing the defects .

There are two main types of static testing techniques:

1. **Manual examinations**: This includes analysis of code done manually, also known as reviews .
2. **Automated analysis using tools**: This is basically static analysis which is done using tools .

A static test evaluates the quality of a system without actually running the system. The static test looks at portions or system elements to detect problems as early as possible. For example, developers review their code after writing and before testing .
