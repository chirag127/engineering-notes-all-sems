### Integration Testing

Integration testing is a level of software testing where individual units are combined and tested as a group. The purpose of this level of testing is to expose faults in the interaction between integrated units. Test drivers and test stubs are used to assist in Integration Testing.

#### Key points to remember:

- Integration testing is performed after unit testing and before system testing.
- The main objective of integration testing is to test the interface between the modules.
- Integration testing can be done in two ways: bottom-up integration testing and top-down integration testing.
- In bottom-up integration testing, the lower level modules are tested first and then the higher level modules are tested.
- In top-down integration testing, the higher level modules are tested first and then the lower level modules are tested.
- Integration testing can be done using big-bang approach, where all the modules are integrated and tested together, or using incremental approach, where the modules are integrated and tested incrementally.
- Integration testing is important to ensure that the integrated modules work together as expected.
