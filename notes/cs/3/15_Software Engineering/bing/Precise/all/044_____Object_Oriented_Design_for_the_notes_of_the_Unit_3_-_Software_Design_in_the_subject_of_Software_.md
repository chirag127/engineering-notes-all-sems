### Object Oriented Design

Object-oriented design is a software design methodology that models a system as a group of interacting objects. Each object represents an entity in the real world with its own responsibilities and behaviors. The main principles of object-oriented design are:

1. **Abstraction:** Abstraction is the process of identifying the essential features of an object while ignoring its irrelevant details. This allows us to represent complex systems in a simplified manner.

2. **Encapsulation:** Encapsulation is the practice of hiding the internal details of an object and providing a public interface for interacting with it. This helps to reduce the complexity of the system and makes it easier to maintain.

3. **Inheritance:** Inheritance is the mechanism by which one class can inherit the properties and behaviors of another class. This allows us to reuse existing code and create more specialized classes.

4. **Polymorphism:** Polymorphism is the ability of an object to take on many forms. This allows us to write more flexible and reusable code by defining a common interface for objects of different classes.

Object-oriented design is widely used in software development and is the foundation of many popular programming languages such as Java, C++, and Python. It is an important concept in the field of software engineering and is covered in Unit 3 - Software Design of the subject of Software Engineering.
