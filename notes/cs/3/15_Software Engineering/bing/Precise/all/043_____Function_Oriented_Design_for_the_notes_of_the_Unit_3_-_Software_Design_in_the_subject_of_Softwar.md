# Function Oriented Design

Function Oriented Design is a design methodology used in software engineering. It is used to design software systems by decomposing the system into smaller, manageable functions or modules. Each function or module is designed to perform a specific task or set of tasks.

Some key points to consider when using Function Oriented Design are:

1. The system is decomposed into a hierarchy of functions or modules.
2. Each function or module is designed to perform a specific task or set of tasks.
3. The functions or modules are designed to be reusable and modular.
4. The design focuses on the functionality of the system rather than the data or objects.
5. The design process involves identifying the functions or modules, defining their interfaces, and specifying their behavior.

Function Oriented Design is commonly used in procedural programming languages such as C and FORTRAN. It is also used in the design of operating systems and other large software systems.

In summary, Function Oriented Design is a design methodology used in software engineering to design software systems by decomposing the system into smaller, manageable functions or modules. Each function or module is designed to perform a specific task or set of tasks, and the design focuses on the functionality of the system rather than the data or objects. This methodology is commonly used in procedural programming languages and in the design of large software systems.
