# Design Strategies for Unit 3 - Software Design in Software Engineering

1. **Modularity**: Divide the software into smaller, manageable and independent modules. This makes it easier to understand, develop and maintain the software.
2. **Abstraction**: Hide the implementation details and only show the necessary information to the user. This reduces complexity and makes the software easier to use.
3. **Information Hiding**: Keep the internal details of a module hidden from other modules. This reduces the dependencies between modules and makes it easier to change the implementation of a module without affecting other modules.
4. **Coupling**: Minimize the dependencies between modules. This makes it easier to change one module without affecting other modules.
5. **Cohesion**: Maximize the relatedness of the elements within a module. This makes it easier to understand and maintain the module.
6. **Layering**: Organize the software into layers, where each layer provides services to the layer above it and uses services from the layer below it. This makes it easier to change one layer without affecting other layers.
7. **Separation of Concerns**: Separate the software into different parts, where each part addresses a specific concern. This makes it easier to understand, develop and maintain the software.

These are some of the design strategies that can be used when designing software. It is important to carefully consider these strategies and apply them appropriately to create high-quality software.
