### Various Size Oriented Measures

Size-oriented measures are used to estimate the size of a software product. These measures are based on the assumption that the size of the software product is directly related to the effort required to develop it. Some of the commonly used size-oriented measures are:

1. **Lines of Code (LOC):** This measure is based on the number of lines of code in the software product. It is a simple and widely used measure, but it has some limitations. For example, it does not take into account the complexity of the code or the programming language used.

2. **Function Points (FP):** This measure is based on the functionality provided by the software product. It takes into account the number of inputs, outputs, user interactions, and other factors that contribute to the functionality of the software. It is a more sophisticated measure than LOC, but it requires more effort to calculate.

3. **Feature Points (FeP):** This measure is similar to function points, but it takes into account the complexity of the features provided by the software product. It is a more accurate measure than function points, but it requires even more effort to calculate.

These are some of the commonly used size-oriented measures in software engineering. They can be used to estimate the size of a software product and to predict the effort required to develop it. However, it is important to note that these measures are not perfect and should be used in conjunction with other measures to obtain a more accurate estimate.
