### Object Oriented Design

Object-oriented design is a software design methodology that focuses on modeling real-world objects and their interactions. It is a key component of the software design process in Unit 3 of the Software Engineering subject. Here are some key points to consider when studying object-oriented design:

1. **Encapsulation**: This refers to the practice of hiding the internal details of an object and providing a public interface for interaction with the object. This helps to reduce complexity and increase maintainability.

2. **Inheritance**: This allows for the creation of new classes based on existing classes, inheriting their attributes and behaviors. This promotes code reuse and can reduce development time.

3. **Polymorphism**: This allows for objects of different classes to be treated as objects of a common superclass. This enables flexibility and can simplify code.

4. **Abstraction**: This refers to the process of identifying the essential features of an object while ignoring its irrelevant details. This helps to reduce complexity and improve understanding.

5. **Design Patterns**: These are reusable solutions to common problems in software design. They provide a common vocabulary and can help to improve the design process.

Overall, object-oriented design is a powerful tool for creating flexible, reusable, and maintainable software. It is an important topic to study for anyone interested in software design.
