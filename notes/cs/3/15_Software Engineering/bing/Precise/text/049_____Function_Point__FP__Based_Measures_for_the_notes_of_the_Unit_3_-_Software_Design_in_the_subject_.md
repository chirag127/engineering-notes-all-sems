### Function Point (FP) Based Measures

Function Point (FP) is a unit of measurement used to express the amount of business functionality provided by a software system. It is a standardized method for measuring software size, and is widely used in the software industry for estimating, planning, and managing software projects.

Some key points to note about Function Point (FP) based measures are:

1. FP is a measure of the functionality provided by a software system, as perceived by the user.
2. FP is independent of the technology used to implement the software.
3. FP is based on the user's view of the system, and not on the technical complexity of the system.
4. FP is used to estimate the size of a software project, and can be used to estimate the effort and cost required to develop the software.
5. FP is widely used in the software industry, and is recognized as a standard method for measuring software size.

In summary, Function Point (FP) based measures provide a standardized way to measure the size and functionality of a software system, and are widely used in the software industry for project estimation and management. They are based on the user's view of the system, and are independent of the technology used to implement the software.
