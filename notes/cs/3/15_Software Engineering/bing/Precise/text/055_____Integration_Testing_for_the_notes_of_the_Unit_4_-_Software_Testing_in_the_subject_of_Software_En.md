### Integration Testing

- Integration testing is a level of software testing where individual units are combined and tested as a group.
- The purpose of this level of testing is to expose faults in the interaction between integrated units.
- Test drivers and test stubs are used to assist in Integration Testing.
- Integration testing is performed after unit testing and before system testing.
- There are different approaches to performing integration testing, such as big bang, top-down, bottom-up, and sandwich/hybrid.
- Big bang integration testing involves integrating all the units at once and then testing them together.
- Top-down integration testing involves testing the top-level units first and gradually moving down the hierarchy.
- Bottom-up integration testing involves testing the lower-level units first and gradually moving up the hierarchy.
- Sandwich/hybrid integration testing is a combination of top-down and bottom-up approaches.
- Integration testing can be performed manually or using automated tools.
- Integration testing is important to ensure that the different units of the software work together correctly and efficiently.
