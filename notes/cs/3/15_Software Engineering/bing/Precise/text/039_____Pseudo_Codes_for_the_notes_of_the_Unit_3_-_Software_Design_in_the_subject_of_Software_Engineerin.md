### Pseudo Codes for the notes of the Unit 3 - Software Design in the subject of Software Engineering

1. Pseudo code is a way to describe an algorithm in a human-readable format.
2. It is not a programming language, but rather a way to express the logic of an algorithm in a structured manner.
3. Pseudo code is often used in the design phase of software development to help developers visualize the flow of the program.
4. Pseudo code can be written in any language, but it is usually written in a language that is similar to the programming language that will be used to implement the algorithm.
5. Pseudo code is not meant to be executed, but rather to be read and understood by humans.
6. Pseudo code can be used to communicate the design of an algorithm to other developers or to document the design for future reference.
7. Pseudo code can be converted into actual code by a programmer, but it is not a one-to-one translation.
8. Pseudo code can help developers identify potential problems or inefficiencies in the design of an algorithm before it is implemented.
9. Pseudo code can be used to test the logic of an algorithm before it is implemented.
10. Pseudo code is a valuable tool for software design and development.
