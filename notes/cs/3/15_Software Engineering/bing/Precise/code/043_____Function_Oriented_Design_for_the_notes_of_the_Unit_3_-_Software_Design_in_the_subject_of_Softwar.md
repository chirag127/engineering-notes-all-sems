### Function Oriented Design

Function Oriented Design is a design methodology used in software engineering. It is used to design software systems by decomposing the system into smaller, manageable functions or modules. The main focus of this design methodology is on the functions performed by the system and the data flow between these functions.

Here are some key points to remember about Function Oriented Design:

1. Function Oriented Design is based on the idea of decomposing a system into smaller, manageable functions or modules.
2. The main focus of this design methodology is on the functions performed by the system and the data flow between these functions.
3. Function Oriented Design is best suited for systems where the primary focus is on the processing of data.
4. This design methodology is commonly used in the development of traditional, procedural software systems.
5. Function Oriented Design is not well suited for systems where the primary focus is on the interactions between objects or the behavior of the system.
