### Function Point (FP) Based Measures

Function Point (FP) is a unit of measurement used to express the amount of business functionality provided by a software system. It is a standardized method for measuring the size of a software application or project, based on the user's view of the system.

Here are some key points to consider when using Function Point (FP) based measures in software design:

1. FP measures are based on the functionality provided by the software, as perceived by the user, rather than the technical complexity of the system.
2. FP measures take into account the number and complexity of inputs, outputs, user interactions, and data files, as well as the number of external interfaces.
3. FP measures are independent of the technology used to implement the system, making them useful for comparing systems developed using different technologies or programming languages.
4. FP measures can be used to estimate the effort required to develop, maintain, or enhance a software system, as well as to measure productivity and quality.
5. FP measures can be used to support project planning, management, and control, as well as to support software process improvement initiatives.

In summary, Function Point (FP) based measures provide a standardized and technology-independent way to measure the size and complexity of a software system, based on the user's view of the system. These measures can be used to support a wide range of software engineering activities, including project planning, management, and control, as well as process improvement initiatives.
