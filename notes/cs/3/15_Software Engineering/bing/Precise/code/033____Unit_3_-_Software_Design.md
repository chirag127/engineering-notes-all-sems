## Unit 3 - Software Design

Software design is the process of defining software methods, functions, objects, and the overall structure and interaction of the code so that the resulting functionality will satisfy the user's requirements.

1. **Design Principles:** There are several principles that guide the software design process, including modularity, abstraction, encapsulation, coupling, and cohesion.
2. **Design Patterns:** Design patterns are reusable solutions to common problems in software design. They provide a template for solving a problem that can be used in many different situations.
3. **Architecture:** Software architecture refers to the high-level structure of a software system, including its components, their relationships, and the principles and guidelines governing their design and evolution over time.
4. **Modeling:** Modeling is the process of creating a representation of a system or process to aid in understanding, communication, and decision making. In software design, modeling can be used to represent the structure, behavior, and interactions of a software system.
5. **Documentation:** Documentation is an important part of the software design process, as it provides a record of the design decisions and the rationale behind them. It also serves as a reference for developers and other stakeholders.
