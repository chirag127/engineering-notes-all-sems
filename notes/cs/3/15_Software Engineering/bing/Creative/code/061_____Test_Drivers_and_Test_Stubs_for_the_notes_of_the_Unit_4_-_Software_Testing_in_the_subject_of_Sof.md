# Test Drivers and Test Stubs

- Test drivers and test stubs are two types of test harnesses, which are collections of software and test data that are configured together in order to test a unit of a program by stimulating various conditions while constantly monitoring its outputs and behavior.
- Test drivers and test stubs are used in integration testing, which is a type of testing that aims to verify the functionality, performance, and reliability of different modules or components of a software system when they are combined together.
- Test drivers and test stubs are especially useful when some modules or components are not yet developed or available, or when they are too complex or costly to use in the testing environment.
- Test drivers and test stubs can simulate the features and functionalities of the missing or unavailable modules or components, and provide inputs and outputs to the modules or components under test.
- Test drivers and test stubs can reduce unnecessary delays in testing and make the testing process faster and more efficient.

## Test Drivers

- A test driver is a piece of code that emulates a calling function or a main function that invokes other modules or components to form a complete application .
- Test drivers are created in integration testing following a bottom-up approach, which is a type of integration testing that starts with testing the lowest-level or the most basic modules or components, and then gradually integrates and tests the higher-level or the more complex modules or components .
- Test drivers provide inputs and test cases to the modules or components under test, and receive and verify their outputs and behavior .
- Test drivers can also control the execution flow and the order of the modules or components under test, and handle any exceptions or errors that may occur during the testing process .
- Test drivers can be written in the same programming language as the modules or components under test, or in a different language that can communicate with them through interfaces or protocols .

## Test Stubs

- A test stub is a piece of code that emulates a called function or a module or component that is invoked by another module or component under test .
- Test stubs are created in integration testing following a top-down approach, which is a type of integration testing that starts with testing the highest-level or the most complex modules or components, and then gradually integrates and tests the lower-level or the more basic modules or components .
- Test stubs provide outputs and responses to the modules or components under test, and simulate their behavior and functionality .
- Test stubs can also validate the inputs and parameters received from the modules or components under test, and generate any exceptions or errors that may occur during the testing process .
- Test stubs can be written in the same programming language as the modules or components under test, or in a different language that can communicate with them through interfaces or protocols .
