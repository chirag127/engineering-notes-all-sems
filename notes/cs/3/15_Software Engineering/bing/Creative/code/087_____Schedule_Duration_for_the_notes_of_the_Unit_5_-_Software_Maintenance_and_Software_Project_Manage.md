### Schedule/Duration for the notes of the Unit 5 - Software Maintenance and Software Project Management in the subject of Software Engineering

- Software maintenance is the process of modifying and updating software after it has been delivered to the customer. Software maintenance includes correcting errors, improving performance, adapting to changing environments, and adding new features .
- Software project management is the discipline of planning, organizing, leading, and controlling software projects. Software project management involves defining the scope, schedule, budget, quality, and risks of the project, as well as managing the stakeholders, resources, communication, and deliverables .
- The notes of the unit 5 cover the following topics:

  - Software as an evolutionary entity: This topic explains how software evolves over time to meet the changing needs and expectations of the users and the market. It also discusses the challenges and benefits of software evolution, and the models and techniques for managing software evolution.
  - Software maintenance process: This topic describes the activities and tasks involved in software maintenance, such as identification, analysis, design, implementation, testing, and deployment. It also covers the types and categories of software maintenance, such as corrective, adaptive, perfective, and preventive maintenance.
  - Software maintenance models: This topic presents the different models and frameworks for software maintenance, such as the waterfall model, the iterative model, the spiral model, and the agile model. It also compares and contrasts the advantages and disadvantages of each model.
  - Software project management process: This topic outlines the phases and stages of software project management, such as initiation, planning, execution, monitoring and control, and closure. It also explains the tools and techniques for software project management, such as project charter, work breakdown structure, Gantt chart, network diagram, and earned value analysis .
  - Software project management knowledge areas: This topic covers the ten knowledge areas of software project management, as defined by the Project Management Institute (PMI). These are integration, scope, time, cost, quality, human resources, communication, risk, procurement, and stakeholder management. It also discusses the processes and best practices for each knowledge area .
  - Software project management challenges and issues: This topic identifies the common problems and difficulties that software project managers face, such as unrealistic expectations, scope creep, changing requirements, technical complexity, team conflicts, and resource constraints. It also suggests the possible solutions and mitigation strategies for each problem  .
