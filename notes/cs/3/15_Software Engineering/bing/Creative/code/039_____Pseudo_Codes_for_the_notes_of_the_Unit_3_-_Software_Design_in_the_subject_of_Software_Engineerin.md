### Pseudo Codes for the notes of the Unit 3 - Software Design in the subject of Software Engineering

- Pseudo code is a text outline of the program design   that uses natural language and common programming keywords to describe the main operations and structure of an algorithm.
- Pseudo code can be an ideal way to start any software development project that involves collaboration and joint effort in creating a design or structure that can serve as a framework for the entire project .
- Pseudo code can also be used to solve coding problems by breaking down the problem into smaller and simpler steps that can be translated into actual code later.
- Pseudo code is an informal method of program design, so there are no strict rules or syntax to follow. However, some general guidelines are:
  - Use indentation to show the hierarchy and nesting of statements and blocks.
  - Use keywords such as `BEGIN`, `END`, `IF`, `ELSE`, `WHILE`, `FOR`, `FUNCTION`, `RETURN`, etc. to indicate the structure and logic of the algorithm.
  - Use descriptive names for variables, constants, functions, and parameters.
  - Use comments to explain the purpose and functionality of the code.
  - Use pseudocode to describe the main steps of the algorithm, not the details of the implementation or the syntax of a specific programming language.
- An example of pseudocode for a function that calculates the factorial of a positive integer n is:

```
FUNCTION factorial(n)
  // This function returns the factorial of n
  IF n == 0 OR n == 1 THEN
    RETURN 1
  ELSE
    RETURN n * factorial(n - 1)
  END IF
END FUNCTION
```

- Pseudo code can be complemented by other tools such as flowcharts, data flow diagrams, state diagrams, and process flow charts to visually represent the flow and structure of the algorithm  . These tools can help to identify the inputs, outputs, processes, decisions, loops, and branches of the algorithm.
