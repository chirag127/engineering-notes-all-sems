### Review and Management of User Needs

- User needs are the expectations and requirements of the end-users of a software system.
- User needs can be expressed in various forms, such as user stories, use cases, scenarios, goals, tasks, etc.
- User needs are the basis for defining the software requirements, which are the specifications of what the software system should do and how it should behave.
- Reviewing and managing user needs is an important activity in software engineering, as it ensures that the software system meets the needs and expectations of the users, and that the user needs are consistent, complete, clear, and feasible.
- Reviewing and managing user needs involves the following steps:

  - Eliciting user needs: This is the process of gathering and understanding the user needs from various sources, such as interviews, surveys, observations, documents, etc.
  - Analyzing user needs: This is the process of identifying, organizing, prioritizing, and validating the user needs, and resolving any conflicts or ambiguities among them.
  - Documenting user needs: This is the process of recording and communicating the user needs in a structured and consistent format, such as user requirement documents, user stories, use cases, etc.
  - Reviewing user needs: This is the process of verifying and validating the user needs with the stakeholders, such as users, customers, developers, testers, etc., and ensuring that they are accurate, complete, and feasible.
  - Managing user needs: This is the process of controlling and tracking the changes and updates to the user needs throughout the software development lifecycle, and ensuring that they are aligned with the project scope, objectives, and constraints.
