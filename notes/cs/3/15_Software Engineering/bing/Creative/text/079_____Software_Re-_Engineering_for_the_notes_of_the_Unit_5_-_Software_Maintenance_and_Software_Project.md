### Software Re-Engineering

- Software Re-Engineering is the examination and alteration of a system to reconstitute it in a new form .
- Software Re-Engineering is a process of software development which is done to improve the maintainability, quality, performance, and customer service of a software system  .
- Software Re-Engineering encompasses a combination of sub-processes such as reverse engineering, forward engineering, reconstructing, etc.
- Reverse engineering is the process of analyzing the existing system to identify its components and their relationships, and to create representations of the system in another form or a higher level of abstraction.
- Forward engineering is the process of creating or modifying a system from the available representations or specifications.
- Reconstructing is the process of applying a series of analysis and design transformations to an existing system to improve its structure, readability, and maintainability.
- Software Re-Engineering can be applied to any software system, but it is especially useful for legacy systems that are difficult to maintain, modify, or understand .
- Software Re-Engineering can positively affect software cost, quality, customer service, and delivery speed .
- Software Re-Engineering can also help to migrate a system to a new platform, to a new language, or to a new architecture.
- Software Re-Engineering requires a clear understanding of the system's requirements, functionality, and design, as well as the tools and techniques to perform the re-engineering tasks .
- Software Re-Engineering is not a one-time activity, but a continuous process of improving and evolving a software system.
