### Structural Testing (White Box Testing) for the notes of the Unit 4 - Software Testing in the subject of Software Engineering

- Structural testing, also known as white box testing, is a method of software testing that tests the internal structure, logic, and code of the software system  .
- The tester has access to the source code and can create test cases based on the code paths, branches, conditions, loops, and statements  .
- The main objective of structural testing is to verify the quality, reliability, security, and performance of the software system by checking its code coverage, data flow, control flow, and error handling  .
- Structural testing can be performed at any level of testing, such as unit testing, integration testing, system testing, or acceptance testing  .
- Some of the common techniques and tools used for structural testing are   :
  - Statement coverage: It measures the percentage of executable statements that are covered by the test cases.
  - Branch coverage: It measures the percentage of branches or decision points that are covered by the test cases.
  - Path coverage: It measures the percentage of paths or sequences of statements and branches that are covered by the test cases.
  - Condition coverage: It measures the percentage of logical conditions or expressions that are evaluated to both true and false by the test cases.
  - Data flow testing: It analyzes the flow of data values and variables between the definitions and uses of the data in the code.
  - Control flow testing: It analyzes the flow of control or execution between the nodes and edges of the code graph.
  - Mutation testing: It generates and executes variants or mutants of the original code by introducing small changes and compares the outputs with the expected outputs.
  - Debugging tools: They help to identify and fix the errors or defects in the code by providing features such as breakpoints, watchpoints, step-by-step execution, and variable inspection.
