# Flow Charts

- A flow chart is a graphical representation of the sequence of steps or actions of a process, algorithm or workflow.
- A flow chart shows the inputs, outputs, decisions, branches, loops and terminations of a process.
- A flow chart can be used to design, document, analyze or communicate a process in a clear and concise way.
- A flow chart consists of a set of standard symbols and connectors that represent the different elements of a process.

## Guidelines for Drawing a Flow Chart

- The following are some of the general guidelines for drawing a flow chart:

- Start from the top and work downwards, or from the left and work rightwards.
- Use a single flowline whenever possible. Avoid crossing or overlapping flowlines.
- Use a connector symbol to indicate a jump from one point to another in the flow chart. Label the connector with a letter or a number and use the same label at the destination point.
- Use a decision symbol to indicate a branching point in the flow chart. Label the branches with the conditions or choices that lead to them.
- Use a subprocess symbol to indicate a subflow that is defined elsewhere. Label the subprocess with a name or a reference to another flow chart.
- Use clear and concise labels for the symbols. Use verbs for process symbols, nouns for input/output symbols, and questions for decision symbols.
- Use standard symbols and connectors as much as possible. Avoid using non-standard or ambiguous symbols.
- Test the flow chart for logic and completeness. Check if the flow chart covers all the possible scenarios and outcomes of the process.
