### Function Point (FP) Based Measures for the notes of the Unit 3 - Software Design in the subject of Software Engineering

Function Point (FP) Based Measures is a software measurement technique that is used to estimate the size and complexity of a software system. In the context of Unit 3 - Software Design in the subject of Software Engineering, students will learn about Function Point (FP) Based Measures and how they are used to estimate the size and complexity of a software system.

Function Point (FP) Based Measures are based on the concept of function points, which are a measure of the functionality provided by a software system. Function points are calculated based on a set of inputs, outputs, and user interactions, and they provide a measure of the complexity and size of a software system.

In the Unit 3 - Software Design in the subject of Software Engineering, students will learn how to use Function Point (FP) Based Measures to estimate the size and complexity of a software system. This may include working with examples of Function Point (FP) Based Measures, analyzing the benefits and limitations of Function Point (FP) Based Measures, and learning how to apply Function Point (FP) Based Measures to real-world software development projects.
