### Object Oriented Design for the notes of the Unit 3 - Software Design in the subject of Software Engineering

Object-Oriented Design (OOD) is a software design approach that focuses on creating software systems as a collection of objects that interact with each other. The following are some of the key concepts related to OOD:

1. Objects: An object is a representation of a real-world entity that encapsulates data and behavior. Objects interact with each other to achieve the desired functionality of the software system.

2. Classes: A class is a blueprint for creating objects. Classes define the data and behavior of objects, and they can be used to create multiple instances of the same type of object.

3. Inheritance: Inheritance is a mechanism that allows classes to inherit properties and behavior from parent classes. This allows for the creation of specialized classes that are derived from more general classes.

4. Polymorphism: Polymorphism is a mechanism that allows objects to behave differently based on their context. This allows for the creation of objects that can be used interchangeably, even though they may have different properties and behavior.

5. Abstraction: Abstraction is a mechanism that allows objects to hide the implementation details of their behavior, and to expose only the essential information needed for interaction with other objects.

6. Encapsulation: Encapsulation is a mechanism that protects the data and behavior of objects from unauthorized access, and it ensures that objects can only be modified in a controlled and predictable manner.

In this unit, you will learn about Object-Oriented Design and the key concepts related to it, including objects, classes, inheritance, polymorphism, abstraction, and encapsulation.

This unit will provide a foundation for understanding the principles and practices of software design, and for exploring the various concepts and techniques used in the field of Software Engineering.
