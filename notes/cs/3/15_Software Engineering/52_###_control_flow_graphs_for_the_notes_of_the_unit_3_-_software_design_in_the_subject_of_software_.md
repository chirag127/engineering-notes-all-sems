### Control Flow Graphs for the notes of the Unit 3 - Software Design in the subject of Software Engineering

A Control Flow Graph (CFG) is a graphical representation of the flow of control in a software system, used in software engineering to analyze and understand the behavior of the software system. The following are some of the key concepts related to CFGs:

1. Nodes: Nodes in a CFG represent the basic blocks of code in a software system, and they represent the flow of control from one block of code to another.

2. Edges: Edges in a CFG represent the flow of control from one node to another, and they indicate the order in which the blocks of code are executed.

3. Paths: Paths in a CFG represent sequences of nodes and edges that represent the possible flow of control in a software system.

4. Cyclomatic Complexity: Cyclomatic complexity is a measure of the complexity of a CFG, and it is used to determine the number of independent paths in a CFG.

5. Testing: CFGs are used to guide the testing of a software system, and they can be used to determine the number of test cases needed to achieve a desired level of coverage.

6. Debugging: CFGs can be used to help debug a software system, and they can be used to identify the source of errors and to trace the flow of control through the software system.

In this unit, you will learn about CFGs and the key concepts related to them, including nodes, edges, paths, cyclomatic complexity, testing, and debugging.

This unit will provide a foundation for understanding the principles and practices of software design, and for exploring the various concepts and techniques used in the field of Software Engineering.
