### Desktop input devices for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

Unit 3 of the Augmented & Virtual Reality course focuses on 3D User Interface Input Hardware and covers the aspect of Desktop Input Devices.

Desktop input devices are hardware devices used to control and interact with desktop computers and other electronic devices. They are used to input data, control applications, and navigate the user interface.

There are several types of desktop input devices, including keyboard, mouse, touchpad, joystick, and gamepad. The keyboard is used for typing text and entering commands, and typically includes alphanumeric keys, function keys, and control keys. The mouse is used for pointing, clicking, and dragging, and typically includes buttons and a scroll wheel. The touchpad is used for pointing and clicking, and typically includes a touch-sensitive surface and buttons. The joystick is used for controlling movement in games and simulations, and typically includes a stick and buttons. The gamepad is used for playing games, and typically includes buttons, triggers, and thumbsticks.

In the context of the Augmented & Virtual Reality course, students in Unit 3 will learn about desktop input devices as part of the discussion on 3D User Interface Input Hardware. This may include working with examples of desktop input devices, analyzing the benefits and limitations of different types of desktop input devices, and learning how to choose the appropriate input device for a given application.
