### Unit 4 - SOFTWARE TECHNOLOGIES

#### Scripts

1. Scripts are a type of computer program that automate tasks and processes.
2. Scripts are typically written in a scripting language, such as JavaScript, Python, or Ruby.
3. Scripts can be used to automate repetitive tasks, manipulate data, or interact with other software.
4. In the context of Augmented and Virtual Reality, scripts can be used to create interactive experiences, control animations, and manage user input.
5. Scripts can be embedded within other software, such as a game engine, to provide additional functionality.
6. Scripts can be written by developers or generated by software tools.
7. Scripts can be executed on the client-side, server-side, or both.
8. Scripts can be used to create dynamic and responsive user interfaces.
9. Scripts can be used to create custom behaviors and interactions within an Augmented or Virtual Reality experience.
10. Scripts can be used to integrate external data sources and services into an Augmented or Virtual Reality experience.
