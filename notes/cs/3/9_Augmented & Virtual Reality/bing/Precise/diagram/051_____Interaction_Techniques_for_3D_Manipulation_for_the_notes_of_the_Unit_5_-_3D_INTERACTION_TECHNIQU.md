### Interaction Techniques for 3D Manipulation

Interaction techniques for 3D manipulation are used to enable users to interact with 3D objects in virtual and augmented reality environments. These techniques can be categorized into several types, including:

1. **Grasping**: This technique involves the user physically grasping a virtual object to manipulate it.
2. **Pointing**: This technique involves the user pointing at a virtual object to select and manipulate it.
3. **Surface**: This technique involves the user interacting with the surface of a virtual object to manipulate it.
4. **Indirect**: This technique involves the user manipulating a virtual object indirectly, such as through the use of a controller or other input device.
5. **Bimanual**: This technique involves the user using both hands to manipulate a virtual object.
6. **Hybrid**: This technique involves the use of a combination of the above techniques to manipulate a virtual object.

In handheld mobile AR, the interaction technique can be categorized into:

1. **Touch-based interaction**: This technique involves the user interacting with the virtual object through touch inputs on the mobile device.
2. **Mid-air gestures-based interaction**: This technique involves the user interacting with the virtual object through mid-air gestures.
3. **Device-based interaction**: This technique involves the user manipulating the virtual object by rotating, tilting, skewing, and moving the mobile device itself.

Each type of interaction has its own limitations and strengths. It is important to choose the appropriate technique for the task at hand to ensure effective and efficient interaction with the virtual environment.
