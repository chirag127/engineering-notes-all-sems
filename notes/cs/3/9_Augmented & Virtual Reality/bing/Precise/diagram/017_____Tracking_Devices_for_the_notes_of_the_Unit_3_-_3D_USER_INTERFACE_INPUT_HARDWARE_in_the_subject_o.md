# Tracking Devices for 3D User Interface Input Hardware

Tracking devices are used to move objects dynamically in 3 dimensions and are useful in manipulating virtual objects. There are several types of tracking devices, including motion trackers, eye trackers, and data gloves.

## Motion Tracking
Motion tracking devices can use various technologies to track the movement of an object, including:
- Magnetic tracking
- Mechanical tracking
- Acoustic tracking
- Inertial tracking
- Optical tracking
- Hybrid tracking

## Eye Tracking
Eye tracking devices are purely passive input devices used to determine where the user is looking. They use corneal reflections detected by a camera or electro-oculography, which measures the skin’s electric potential differences using electrodes placed around the eye.

## Data Gloves
Data gloves can detect hand postures and determine if a user is touching 2 or more fingertips together. There are two types of data gloves:
- Bend sensing gloves
- Pinch Gloves

## 3D Mice
3D mice allow the user to physically move them in 3D space. They can be handheld or user-worn, making the device an extension of the user’s hand.

## Direct Human Input
Direct human input devices obtain data directly from signals generated by the human body.

These are some of the tracking devices used for 3D User Interface Input Hardware. They enable the system to track the user's position, orientation, and/or motion to enable 3D interaction     .
