### Objects - Geometry

1. In the context of Augmented and Virtual Reality, objects refer to the digital representations of real-world or imaginary items that can be placed and interacted with in a virtual environment.
2. Geometry refers to the mathematical study of the properties, measurements, and relationships of points, lines, angles, surfaces, and solids.
3. In the context of 3D modeling and computer graphics, geometry is used to define the shape and structure of objects.
4. Common geometric primitives used to create 3D objects include points, lines, polygons, and curves.
5. These primitives can be combined and manipulated to create complex shapes and structures.
6. The process of creating 3D objects using geometric primitives is known as modeling.
7. Modeling software, such as Blender or Maya, provides tools for creating and manipulating geometric primitives to create 3D objects.
8. Once an object has been modeled, it can be imported into an Augmented or Virtual Reality application and placed in a virtual environment for the user to interact with.
9. Understanding the principles of geometry is essential for creating realistic and accurate 3D objects for use in Augmented and Virtual Reality applications.
