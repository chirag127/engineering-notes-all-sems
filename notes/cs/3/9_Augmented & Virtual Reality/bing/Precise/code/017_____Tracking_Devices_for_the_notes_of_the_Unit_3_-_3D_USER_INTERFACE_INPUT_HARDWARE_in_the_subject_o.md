### Tracking Devices for 3D User Interface Input Hardware

- **Tracking devices** are used to move objects dynamically in 3 dimensions and are useful in manipulating virtual objects .
- There are several types of tracking devices, including **motion trackers**, **eye trackers**, and **data gloves** .
- **Motion tracking** can be achieved through various methods, including **magnetic tracking**, **mechanical tracking**, **acoustic tracking**, **inertial tracking**, **optical tracking**, and **hybrid tracking** .
- **Eye tracking** is a purely passive input device used to determine where the user is looking. It uses corneal reflections detected by a camera or electro-oculography, which measures the skin’s electric potential differences using electrodes placed around the eye .
- **Data gloves** can be used to detect hand postures or determine if a user is touching two or more fingertips together. There are two types of data gloves: **bend sensing gloves** and **pinch gloves** .
- **3D mice** allow the user to physically move them in 3D space. They can be **handheld** or **user worn**, making the device an extension of the user’s hand .
- **Direct human input** can also be used to obtain data directly from signals generated by the human body .
