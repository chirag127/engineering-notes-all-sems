### Interaction Techniques for 3D Manipulation

1. **Virtual Hand**: This technique allows the user to interact with virtual objects as if they were using their own hand. The user can grab, move, and manipulate objects in 3D space using a virtual hand controlled by a tracking device.

2. **Ray Casting**: This technique involves pointing a virtual ray from the user's hand or a handheld device, and selecting or manipulating objects that the ray intersects with.

3. **Haptic Feedback**: This technique provides the user with tactile feedback when interacting with virtual objects. This can enhance the realism of the interaction and provide the user with a better sense of the object's properties.

4. **Voice Commands**: This technique allows the user to issue verbal commands to manipulate objects in the virtual environment. This can be useful for hands-free interaction or for users with limited mobility.

5. **Gestures**: This technique involves using hand or body gestures to interact with the virtual environment. Gestures can be recognized by tracking devices and used to perform actions such as selecting, moving, or manipulating objects.

6. **Physical Props**: This technique involves using physical objects as props to interact with the virtual environment. The physical props can be tracked and their movements can be used to manipulate virtual objects.

These are some of the common interaction techniques used for 3D manipulation in virtual and augmented reality environments. Each technique has its own advantages and limitations, and the choice of technique may depend on the specific application and user needs.
