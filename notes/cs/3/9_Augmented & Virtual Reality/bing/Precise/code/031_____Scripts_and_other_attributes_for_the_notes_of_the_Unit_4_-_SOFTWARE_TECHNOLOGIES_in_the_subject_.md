### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. **Scripts** are a fundamental aspect of software technologies used in augmented and virtual reality. They are used to define the behavior of objects and interactions within the virtual environment.
2. **Programming languages** such as C++, C#, and JavaScript are commonly used to write scripts for augmented and virtual reality applications.
3. **Game engines** such as Unity and Unreal Engine provide built-in scripting support and a visual scripting system to make it easier for developers to create interactive content.
4. **Attributes** are used to define the properties of objects and characters within the virtual environment. These can include physical attributes such as size, shape, and color, as well as behavioral attributes such as movement speed and reaction to user input.
5. **Animation** is another important aspect of software technologies used in augmented and virtual reality. It is used to bring characters and objects to life, making them move and interact in a realistic manner.
6. **Physics engines** are used to simulate the behavior of objects within the virtual environment, taking into account factors such as gravity, collisions, and other physical interactions.
7. **Artificial intelligence** is used to create intelligent characters and objects that can react to the user and the environment in a realistic manner.
8. **Networking** is used to enable multiplayer experiences and to allow users to interact with each other within the virtual environment.
