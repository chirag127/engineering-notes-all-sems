### Multimodal System Control Techniques

Multimodal System Control Techniques refer to the use of multiple modes of interaction in a virtual or augmented reality environment. These modes can include 3D gesture, spoken language, and referential agents . The combination of more than one modality is called multimodal .

Some of the interaction techniques proposed by Augmented Reality (AR) include 3D interactions, natural interactions, tangible interactions, spatial awareness interactions, and multimodal interactions .

An example of a multimodal interaction technique in an AR environment is the use of static and stroke hand gestures along with speech to interact with the virtual reality system and perform functions .

Another example is the use of a Multimodal Interaction Algorithm based on AR, which takes as input a gesture depth map and sensor signal, and outputs vibration feedback and visual effects .

These techniques allow for a more immersive and natural interaction with the virtual or augmented reality environment.
