# Unit 4 - SOFTWARE TECHNOLOGIES

## Scripts

1. Scripts are a type of computer program that automate tasks and processes.
2. Scripts are typically written in a scripting language, such as JavaScript, Python, or Ruby.
3. Scripts can be used to automate repetitive tasks, manipulate data, and interact with other software applications.
4. In the context of Augmented and Virtual Reality, scripts can be used to create interactive experiences, control the behavior of virtual objects, and respond to user input.
5. Scripts can be embedded within a larger software application or run as standalone programs.
6. Scripting languages are typically easier to learn and use than traditional programming languages, making them a popular choice for creating simple programs and automating tasks.
7. Scripts can be edited and modified easily, allowing for rapid development and iteration.
8. Scripts can be used to create custom functionality and extend the capabilities of existing software applications.
