# Unit 8 - Augmented and Mixed Reality
### Wireless Displays in Educational Augmented Reality Applications

1. **Wireless technologies** can be used to transmit uncompressed stereoscopic video signals to wireless displays in real time.
2. Two output devices, a **stereoscopic head-mounted display (HMD)** and a **TFT display module**, have been adapted to act as wireless receivers in order to display wirelessly streamed AR content.
3. Wireless displays have **advantages** for educational AR applications. By way of example, two educational AR applications are presented which were used to demonstrate and test wireless displays.
4. A number of teaching scenarios are described where teachers and students greatly benefit from the use of wireless displays.
5. The use of wireless displays can solve usability problems such as the tangling of cables when multiple users collaborate in a virtual environment using personal displays.
6. Wireless displays can deliver user-specific views or context-sensitive information to each user privately.
