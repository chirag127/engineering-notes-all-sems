# Tools for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. **3D Modeling Software**: Tools such as Blender, Maya, and 3ds Max can be used to create 3D models for use in virtual and augmented reality environments.
2. **Game Engines**: Game engines such as Unity and Unreal Engine can be used to develop interactive 3D experiences for virtual and augmented reality.
3. **Input Devices**: Devices such as motion controllers, haptic gloves, and hand tracking sensors can be used to interact with virtual and augmented reality environments.
4. **Head-Mounted Displays**: Head-mounted displays such as the Oculus Rift, HTC Vive, and Microsoft HoloLens can be used to view and interact with virtual and augmented reality environments.
5. **Tracking Systems**: Tracking systems such as the Oculus Insight, Lighthouse, and Windows Mixed Reality can be used to track the position and movement of the user and input devices in virtual and augmented reality environments.
6. **Audio Tools**: Tools such as FMOD and Wwise can be used to create immersive audio experiences in virtual and augmented reality environments.
7. **Networking Tools**: Networking tools such as Photon and UNet can be used to create multiplayer experiences in virtual and augmented reality environments.
