# Classification for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. **Selection and Manipulation Techniques**: These techniques allow users to select and manipulate virtual objects in 3D space. Examples include ray-casting, virtual hand, and image plane techniques.
2. **Navigation Techniques**: These techniques allow users to move through virtual environments. Examples include real walking, walking-in-place, and flying.
3. **System Control Techniques**: These techniques allow users to control the virtual environment and its settings. Examples include menus, buttons, and voice commands.
4. **Symbolic Input Techniques**: These techniques allow users to input text or symbols into the virtual environment. Examples include virtual keyboards and handwriting recognition.
5. **Multi-Modal Techniques**: These techniques combine multiple interaction techniques to provide a more immersive and intuitive experience. Examples include using hand gestures and voice commands simultaneously.
