# 3D Manipulation Tasks

3D manipulation is a fundamental task for many different scientific datasets, such as particle data in physics and astronomy, fluid data in aerography, and structured data in medical science .

## Application-Specific Manipulation Tasks

Canonical tasks can fail to capture important task properties for real applications. For example, positioning a medical probe relative to virtual models of internal organs in a VR medical training application. Techniques must capture and replicate minute details of such manipulation tasks .

## Definition

3D Manipulation Tasks can be defined broadly as any act of physically handling objects with one or two hands. A narrower definition is spatial rigid object manipulation (shape preserving) .

## Canonical Manipulation Tasks

Canonical 3D manipulation tasks include select, position, and rotate. Variables that affect manipulation include distance to object, object size, required translation distance, amount of rotation, object density, and others. The design of manipulation techniques depends on interaction tasks and variables .
