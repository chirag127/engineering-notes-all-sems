# Interaction Techniques for 3D Manipulation

Interaction techniques for 3D manipulation are used to select and manipulate objects in a 3D environment. There are several techniques that can be used for this purpose, including:

1. **Grasping**: This technique involves physically grasping an object in the virtual environment to manipulate it.
2. **Pointing**: This technique involves pointing at an object to select it and then using gestures or other inputs to manipulate it.
3. **Surface**: This technique involves using a surface, such as a touchscreen, to manipulate objects in the virtual environment.
4. **Indirect**: This technique involves using an input device, such as a mouse or joystick, to manipulate objects in the virtual environment.
5. **Bimanual**: This technique involves using both hands to manipulate objects in the virtual environment.
6. **Hybrid**: This technique involves combining multiple techniques to achieve more complex manipulation of objects in the virtual environment.

In handheld mobile AR, the interaction technique can be categorized into 1) touch-based interaction, 2) mid-air gestures-based interaction and 3) device-based interaction. Each type of interaction has its own limitations and strengths.

These techniques can be used for common tasks such as selection, manipulation, navigation, and system control. They can be designed and developed using various strategies, including the use of 2D interaction, "magic" vs. "natural" interaction techniques, multimodal interaction, and two-handed interaction.
