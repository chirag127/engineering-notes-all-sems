# Graphical User Interface

A graphical user interface (GUI) is a type of user interface that allows users to interact with electronic devices through graphical icons and visual indicators, as opposed to text-based interfaces, typed command labels or text navigation.

- GUIs were introduced in response to the perceived steep learning curve of command-line interfaces (CLIs), which require commands to be typed on a computer keyboard.
- The actions in a GUI are usually performed through direct manipulation of the graphical elements.
- GUIs can be designed for the requirements of a vertical market as application-specific graphical user interfaces.
- The system's overall functionality and its application-specific graphical user interface are dependent on the type of software being used.

Some common components of a GUI include:
- Windows: A window is a graphical control element that displays the output of and allows input for one or more processes.
- Icons: An icon is a small picture or symbol that represents a program, command, or data file.
- Menus: A menu is a graphical control element that provides the user with a choice of commands or options.
- Pointers: A pointer is a graphical image on the screen that moves in response to the movement of the pointing device, typically a mouse.

GUIs are used in many types of software, including operating systems, web browsers, and various application software. They are an essential part of modern computer systems and have greatly improved the accessibility and usability of computers for the general population.
