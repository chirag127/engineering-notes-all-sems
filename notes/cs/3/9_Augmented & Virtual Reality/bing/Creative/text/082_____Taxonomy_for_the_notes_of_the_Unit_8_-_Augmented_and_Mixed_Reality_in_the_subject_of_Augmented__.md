### Taxonomy for the notes of the Unit 8 - Augmented and Mixed Reality

- Taxonomy is a system of classification that organizes and categorizes different types of phenomena based on their characteristics and relationships.
- Augmented reality (AR) and mixed reality (MR) are two types of immersive technologies that enhance the perception of reality by overlaying or blending virtual elements with the real environment.
- AR and MR can be classified according to different criteria, such as the type of device, the type of display, the type of interaction, the type of content, the type of application, and the type of purpose.
- One possible taxonomy of AR and MR is based on the following facets :

  - Device: the hardware and software that enable AR and MR experiences, such as wearable (e.g., head-mounted displays, smart glasses, contact lenses), portable (e.g., smartphones, tablets, laptops), or stationary (e.g., projectors, monitors, holograms) devices.
  - Display: the visual representation of the virtual elements in relation to the real environment, such as video-see-through (e.g., using a camera to capture and display the real scene with virtual elements), optical-see-through (e.g., using a transparent or semi-transparent screen to overlay virtual elements on the real scene), or spatial (e.g., using a volumetric or holographic display to create virtual elements in the real space) displays.
  - Interaction: the methods and techniques that enable the user to manipulate and communicate with the virtual elements and the real environment, such as gesture (e.g., using hand or body movements to control the virtual elements), voice (e.g., using speech or sound commands to interact with the virtual elements), touch (e.g., using haptic feedback or physical objects to feel the virtual elements), or gaze (e.g., using eye tracking or head orientation to select or activate the virtual elements) interaction.
  - Content: the type and quality of the virtual elements that are presented in AR and MR, such as realistic (e.g., using photorealistic or 3D models to create virtual elements that resemble the real objects), abstract (e.g., using symbols or icons to create virtual elements that represent information or concepts), or hybrid (e.g., using a combination of realistic and abstract elements to create virtual elements that have both visual and semantic features) content.
  - Application: the domain and context of use of AR and MR, such as education (e.g., using AR and MR to support learning and teaching), entertainment (e.g., using AR and MR to create games and stories), health (e.g., using AR and MR to assist diagnosis and treatment), industry (e.g., using AR and MR to enhance manufacturing and maintenance), or art (e.g., using AR and MR to create and exhibit artistic expressions) application.
  - Purpose: the goal and outcome of using AR and MR, such as cognitive (e.g., using AR and MR to improve memory and reasoning), affective (e.g., using AR and MR to influence emotion and motivation), behavioral (e.g., using AR and MR to change action and performance), or social (e.g., using AR and MR to facilitate communication and collaboration) purpose.

- The taxonomy can help to understand the diversity and complexity of AR and MR, and to design and evaluate AR and MR applications according to different criteria and dimensions.
