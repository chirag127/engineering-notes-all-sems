### Symbolic Input Tasks

- Symbolic input tasks are 3D interaction tasks in which users communicate symbolic information (text, numbers, and other symbols or marks) to the system .
- Symbolic input tasks are common in 2D user interfaces, but pose challenges in 3D user interfaces due to the lack of standard input devices, the complexity of 3D environments, and the difficulty of text entry and recognition.
- Symbolic input tasks can be classified into four main categories based on the input technique used  :
  - Keyboard-based techniques: These techniques use physical or virtual keyboards to enter text or symbols. Examples include miniature keyboards, chord keyboards, and soft keyboards.
  - Pen-based techniques: These techniques use a pen or stylus to write or draw symbols on a surface or in the air. Examples include handwriting recognition, sketch recognition, and graffiti.
  - Gesture-based techniques: These techniques use hand or body gestures to perform symbolic actions or commands. Examples include finger spelling, sign language, and gesture menus.
  - Speech-based techniques: These techniques use voice input to speak words or commands to the system. Examples include speech recognition, natural language processing, and voice commands.
