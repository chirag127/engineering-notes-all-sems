### Classification

- 3D interaction techniques are methods for manipulating, navigating, and selecting objects and information in 3D virtual environments.
- 3D interaction techniques can be classified according to different criteria, such as:
  - The type of task they support, e.g., manipulation, navigation, selection, system control, etc.
  - The type of input device they use, e.g., mouse, keyboard, joystick, tracker, glove, etc.
  - The type of feedback they provide, e.g., visual, auditory, haptic, etc.
  - The type of metaphor they employ, e.g., direct manipulation, ray-casting, virtual hand, etc.
- A common classification scheme for 3D interaction techniques is based on the taxonomy proposed by Bowman et al. (2004), which divides them into four main categories:
  - Travel techniques: allow the user to move through the virtual environment, changing their viewpoint and position.
  - Selection techniques: allow the user to select one or more objects in the virtual environment, indicating their focus of attention or intention to manipulate them.
  - Manipulation techniques: allow the user to change the position, orientation, size, shape, or other attributes of the selected objects in the virtual environment.
  - System control techniques: allow the user to access menus, dialogs, or other interface elements that control the state or behavior of the virtual environment or the application.
