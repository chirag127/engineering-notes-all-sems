# Multimodal System Control Techniques

- Multimodal system control techniques are methods of using multiple input channels (such as speech, gesture, eye gaze, etc.) to control the system or application settings, modes, or commands in a 3D user interface (3DUI).
- Researchers have identified several advantages of using multimodal system control techniques (mostly in the domain of 2D GUIs) that can also apply to 3D UIs:
  - Decoupling: Using an input channel that differs from the main input channel used for interaction with the environment can decrease user cognitive load. For example, using speech to switch between modes while using hand gestures to manipulate objects can avoid mode errors and reduce the need for mode switches.
  - Error reduction and correction: The use of multiple input channels can be very effective when the input is ambiguous or noisy, especially with recognition-based input like speech or gestures. For example, using speech and gesture together can increase the accuracy and robustness of the system, and allow the user to correct errors by repeating or modifying the input.
  - Expressiveness and efficiency: The use of multiple input channels can enable the user to express complex or abstract commands or queries more easily and naturally than using a single input channel. For example, using speech and gesture together can allow the user to specify spatial relations, attributes, or constraints more intuitively and concisely than using menus or buttons.
- Some examples of multimodal system control techniques for 3DUIs are:
  - Speech and gesture: This is a common and natural combination of input channels for 3DUIs, as speech can provide symbolic and semantic information, while gesture can provide spatial and deictic information. For example, the Naval Research Laboratory's Dragon 3D VR system used a multimodal system to create digital content in a 3D topographical scene, allowing users to create and position objects by speaking while gesturing in 3D space.
  - Eye gaze and gesture: This is another combination of input channels that can leverage the user's natural attention and pointing behaviors in 3DUIs. Eye gaze can provide fast and accurate selection of targets, while gesture can provide manipulation and confirmation of actions. For example, the Gaze-Gesture system used eye gaze and hand gesture to interact with virtual objects in a VR environment, allowing users to select objects by looking at them and perform actions by making gestures with their hands.
  - Haptic and gesture: This is a combination of input channels that can provide rich and realistic feedback and control for 3DUIs, as haptic can provide tactile and force information, while gesture can provide spatial and kinesthetic information. For example, the Haptic-Gesture system used a haptic device and hand gesture to interact with virtual objects in a VR environment, allowing users to feel the shape and weight of objects and manipulate them by making gestures with their hands.
