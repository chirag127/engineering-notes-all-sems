# Home-Brewed Input Devices for 3D User Interfaces

- Home-brewed input devices are custom-made or modified input devices that are designed to suit specific needs or preferences of the user or the application.
- Home-brewed input devices can be created by using off-the-shelf components, such as sensors, microcontrollers, wires, buttons, etc., or by hacking existing devices, such as keyboards, mice, game controllers, etc.
- Home-brewed input devices can offer advantages over commercial input devices, such as lower cost, higher flexibility, better performance, or novel functionality.
- Home-brewed input devices can also pose challenges, such as lack of standardization, compatibility, reliability, or usability.
- Home-brewed input devices can be classified into two categories: **passive** and **active**.
  - Passive input devices are those that do not require any power source or communication with the computer. They rely on the tracking system to detect their position and orientation in 3D space. Examples of passive input devices are props, markers, gloves, etc.
  - Active input devices are those that require a power source and communicate with the computer via wired or wireless connections. They can provide additional input modalities, such as buttons, switches, sliders, dials, etc. Examples of active input devices are 3D mice, joysticks, haptic devices, etc.
- Some examples of home-brewed input devices for 3D user interfaces are:
  - The **Pinch Gloves**, which are modified gloves with electrical contacts on the fingertips that allow the user to perform gestures and manipulate virtual objects by pinching the fingers together.
  - The **Wanda**, which is a 6-DOF input device made of two orthogonal rods with a tracker attached to the intersection point. The user can hold the device in different ways and use it as a virtual wand, a ray-casting device, or a steering device.
  - The **3D Sketch**, which is a pen-based input device that allows the user to draw 3D curves in the air by using a tracker and a button. The device can also be used as a pointing device or a selection device.
  - The **Tangible User Interface Objects**, which are physical objects that can be tracked and used to interact with virtual objects or environments. The objects can have different shapes, sizes, textures, or functionalities, and can provide haptic feedback to the user.
