# VR toolkits

VR toolkits are software libraries or frameworks that provide various features and functionalities for developing VR applications. VR toolkits can help developers to create immersive and interactive VR experiences, such as rendering 3D scenes, tracking head and hand movements, handling user input, and integrating with VR hardware.

Some of the popular VR toolkits are:

- **VRTK (VR Toolkit)**: A free and open-source collection of reusable solutions for common VR problems, such as locomotion, interaction, UI, and audio. VRTK supports multiple VR platforms, such as Oculus, SteamVR, and Windows Mixed Reality. VRTK can be downloaded from the Unity Asset Store or from GitHub .
- **VRToolkit**: A modular shader created for ReShade to enhance the clarity and sharpness of VR images, while keeping the performance impact minimal. VRToolkit can adjust the sharpening modes, contrast, brightness, and color of VR images, and only processes the pixels that are in the sweet spot of the VR headset. VRToolkit can be downloaded from its official website or from GitHub.
- **VR Performance Toolkit**: A tool for measuring and optimizing the performance of VR applications, using the Oculus SDK and NVAPI. VR Performance Toolkit can monitor the CPU and GPU usage, frame rate, latency, and other metrics of VR applications, and provide suggestions for improving the performance. VR Performance Toolkit can be downloaded from GitHub.
- **OVR Toolkit**: A utility application that allows users to view and interact with the desktop in VR, using SteamVR. OVR Toolkit can place desktop windows around the VR world, and enable mouse input, typing with a virtual keyboard, and quick switching between windows. OVR Toolkit can be purchased from Steam.
