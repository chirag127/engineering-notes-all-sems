# 2D Controls for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- 2D controls are user interface elements that are displayed on a two-dimensional plane, such as buttons, sliders, menus, etc.
- 2D controls can be used in augmented reality (AR) and virtual reality (VR) applications to provide interaction and feedback to the user.
- 2D controls can be rendered on different surfaces, such as the device screen, a virtual plane, or a real-world object.
- 2D controls can have different styles, such as realistic, abstract, or skeuomorphic, depending on the design goals and the context of the application.
- 2D controls can have different behaviors, such as static, dynamic, or adaptive, depending on the user input and the state of the application.
- 2D controls can have different challenges, such as occlusion, distortion, or latency, depending on the rendering method and the device performance.

Some examples of 2D controls in AR and VR are:

- A 2D menu that appears on the device screen when the user taps a button, allowing the user to select different options or settings for the AR or VR experience.
- A 2D slider that is attached to a virtual plane in the user's field of view, allowing the user to adjust the volume or brightness of the VR environment.
- A 2D button that is mapped to a real-world object, such as a book or a poster, allowing the user to trigger an AR effect, such as a 2D animation or a 3D model.
- A 2D label that is displayed on a virtual object, such as a building or a landmark, providing the user with information or guidance in the AR or VR scene.
- A 2D joystick that is rendered on the device screen, allowing the user to control the movement or orientation of the VR camera or the AR object.
