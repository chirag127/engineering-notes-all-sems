# Symbolic Input Tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- Symbolic input is the task in which users communicate symbolic information (text, numbers, and other symbols or marks) to the system .
- Symbolic input is a common and important task in many applications, such as text editing, data entry, programming, annotation, and communication.
- Symbolic input is challenging in 3D user interfaces (3DUIs) because of the lack of standard input devices, the complexity of 3D environments, and the diversity of user preferences and abilities.
- Symbolic input techniques for 3DUIs can be classified into four categories based on the input device or modality  :
  - Keyboard-based techniques: use physical or virtual keyboards to enter text or symbols, either directly or through a mapping scheme. Examples are miniature keyboards, chord keyboards, and soft keyboards.
  - Pen-based techniques: use a stylus or a finger to write or draw symbols on a surface or in the air. Examples are handwriting recognition, graffiti, and sketching.
  - Gesture-based techniques: use hand or body movements to perform predefined gestures that represent symbols. Examples are sign language, finger spelling, and gesture shortcuts.
  - Speech-based techniques: use voice input to speak or dictate symbols. Examples are speech recognition, natural language processing, and voice commands.
- Symbolic input techniques for 3DUIs can be evaluated based on several criteria, such as accuracy, speed, ease of use, learnability, fatigue, and user satisfaction .
- Symbolic input techniques for 3DUIs can be designed and implemented by considering the following guidelines:
  - Choose the appropriate input device or modality for the task and the user.
  - Provide feedback and error correction mechanisms.
  - Support multiple input modes and allow switching between them.
  - Adapt to the user's preferences and abilities.
  - Minimize the physical and mental workload of the user.
  - Maximize the compatibility and consistency with existing standards and conventions.
