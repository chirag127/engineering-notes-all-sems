# Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Scripts are sequences of commands or instructions that are executed by a software program or an interpreter. Scripts can be used to automate tasks, manipulate data, control the behavior of applications, or create interactive content.
- Some examples of scripting languages are Python, JavaScript, Lua, and C#.
- Scripts can be embedded in other software technologies, such as HTML, XML, JSON, or Unity, to enhance their functionality and interactivity.
- Other attributes are features or properties that define or describe a software technology, such as its purpose, functionality, performance, quality, compatibility, security, or usability.
- Some examples of other attributes are:
  - Purpose: the intended use or goal of a software technology, such as productivity, graphics, security, or entertainment.
  - Functionality: the set of actions or operations that a software technology can perform, such as creating, editing, formatting, or displaying data or content.
  - Performance: the measure of how well a software technology executes its functionality, such as speed, accuracy, efficiency, or reliability.
  - Quality: the degree of excellence or satisfaction that a software technology provides to its users or stakeholders, such as functionality, performance, usability, or aesthetics.
  - Compatibility: the ability of a software technology to work with other software technologies, such as platforms, devices, formats, or standards.
  - Security: the protection of a software technology and its data or content from unauthorized access, modification, or damage, such as encryption, authentication, or backup.
  - Usability: the ease of use or learnability of a software technology for its users, such as user interface, user experience, or user feedback.

- In the subject of augmented and virtual reality, software technologies are essential for creating, delivering, and experiencing immersive and interactive environments that blend the real and the virtual worlds.
- Some examples of software technologies for augmented and virtual reality are:
  - Unity: a cross-platform game engine and development environment that allows users to create 2D, 3D, and mixed reality applications and games, using C# as the scripting language.
  - Unreal Engine: a game engine and development environment that enables users to create realistic and high-quality 3D and mixed reality applications and games, using C++ or Blueprint as the scripting language.
  - WebXR: a web standard and API that enables web browsers to support augmented and virtual reality content and devices, using HTML, CSS, and JavaScript as the scripting languages.
  - ARCore: a software development kit (SDK) that provides a set of tools and libraries for creating augmented reality applications for Android devices, using Java, Kotlin, or C++ as the scripting languages.
  - ARKit: a software development kit (SDK) that provides a set of tools and libraries for creating augmented reality applications for iOS devices, using Swift or Objective-C as the scripting languages.
