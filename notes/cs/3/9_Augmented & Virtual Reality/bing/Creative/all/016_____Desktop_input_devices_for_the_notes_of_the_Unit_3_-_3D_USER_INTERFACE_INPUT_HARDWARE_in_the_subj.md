# Desktop input devices for 3D user interface

- Desktop input devices are devices that allow the user to interact with a 3D user interface on a desktop system, such as a computer monitor or a projection screen.
- Desktop input devices can be classified into two categories: traditional input devices and 6-DOF input devices .
- Traditional input devices are devices that are commonly used for 2D user interfaces, such as keyboards, mice, trackballs, pen- and touch-based tablets, and joysticks .
  - These devices have limited degrees of freedom (DOF), which means they can only sense or control a few parameters of the user's input, such as position, orientation, or pressure.
  - These devices can be used for 3D user interfaces by mapping their input to 3D actions, such as rotation, translation, scaling, or selection.
  - These devices are usually easy to use, cheap, and widely available, but they may not provide natural or intuitive interaction for 3D tasks, such as navigation, manipulation, or animation.
- 6-DOF input devices are devices that can sense or control six parameters of the user's input, such as position and orientation in 3D space .
  - These devices can provide direct and natural interaction for 3D user interfaces, as they allow the user to manipulate 3D objects or viewpoints with one-to-one correspondence.
  - These devices can be either isotonic or isometric .
    - Isotonic devices are devices that sense the user's movement or displacement, such as a 3D mouse or a 3D tracker .
    - Isometric devices are devices that sense the user's force or torque, such as a 3D joystick or a haptic device .
  - These devices are usually more expensive, complex, and less available than traditional input devices, but they may provide higher performance and satisfaction for 3D tasks, such as animation, modeling, or simulation.
- Some examples of desktop input devices for 3D user interface are:
  - Polhemus sensors: small, lightweight devices that use electromagnetic fields to sense the position and orientation of the user's hand or head.
  - Leap Motion: a device that uses infrared cameras to track the user's hand and finger gestures in 3D space.
  - Holo Lens: a device that uses a head-mounted display and a depth camera to project 3D holograms and sense the user's hand gestures and voice commands.
  - Magic Leap: a device that uses a head-mounted display and a handheld controller to create 3D mixed reality and sense the user's hand gestures and eye movements.
