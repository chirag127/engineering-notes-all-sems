# Interaction - Simple

- Interaction is the process of communicating and exchanging information between a user and a system, such as augmented reality (AR) or virtual reality (VR).
- Interaction can involve different modalities, such as visual, auditory, haptic, somatosensory and olfactory, depending on the system and the user's preferences.
- Interaction can also vary in the level of immersion, realism and feedback that the system provides to the user.
- Interaction can be classified into two types: direct and indirect.
  - Direct interaction is when the user manipulates the system or the virtual objects directly, such as using gestures, voice commands, touch screens, controllers or trackers.
  - Indirect interaction is when the user uses an intermediary device or interface to control the system or the virtual objects, such as using a mouse, keyboard, joystick, menu or button.
- Interaction can be evaluated based on different criteria, such as usability, user satisfaction, engagement, presence, performance and learnability.
- Interaction can be designed using different methods, such as user-centered design, participatory design, prototyping, testing and evaluation.
- Interaction can be improved by applying different principles, such as consistency, feedback, affordance, visibility, mapping and constraints.
