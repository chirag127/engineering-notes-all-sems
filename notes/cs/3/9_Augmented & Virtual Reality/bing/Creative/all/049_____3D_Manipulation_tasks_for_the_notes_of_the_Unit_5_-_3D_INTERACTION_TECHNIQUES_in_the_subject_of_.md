# 3D Manipulation Tasks

3D manipulation tasks are the tasks of physically handling objects in a 3D environment. They are essential for creating and modifying 3D scenes, as well as interacting with 3D applications. According to some categorizations, there are three basic 3D manipulation tasks: selection, positioning, and rotation . Some sources also include scaling as a basic manipulation task.

- Selection is the task of acquiring or identifying a particular object or subset of objects from the entire set of objects available. Selection can be done by pointing, clicking, touching, or using voice commands. Selection can also be based on attributes, such as color, shape, or name. Selection techniques can be classified into direct and indirect techniques. Direct techniques involve direct contact or proximity between the user and the object, such as ray-casting or virtual hand. Indirect techniques involve using an intermediate device or representation, such as a cursor or a menu  .

- Positioning is the task of changing the 3D position of an object. Positioning can be done by dragging, throwing, snapping, or using constraints. Positioning techniques can be classified into absolute and relative techniques. Absolute techniques involve specifying the exact coordinates or location of the object, such as using a 3D widget or a map. Relative techniques involve specifying the displacement or direction of the object, such as using a 3D mouse or a gesture  .

- Rotation is the task of changing the orientation of an object. Rotation can be done by twisting, turning, aligning, or using constraints. Rotation techniques can be classified into absolute and relative techniques. Absolute techniques involve specifying the exact angles or axes of the object, such as using a 3D widget or a dial. Relative techniques involve specifying the rotation amount or direction of the object, such as using a 3D mouse or a gesture  .

- Scaling is the task of changing the size of an object. Scaling can be done by stretching, shrinking, or using constraints. Scaling techniques can be classified into absolute and relative techniques. Absolute techniques involve specifying the exact dimensions or scale factor of the object, such as using a 3D widget or a slider. Relative techniques involve specifying the scaling amount or direction of the object, such as using a 3D mouse or a gesture.

3D manipulation tasks can be performed using various input devices, such as 3D mice, gloves, trackers, or controllers. The number and integration of control dimensions can affect the performance and usability of the manipulation techniques. Generally, multiple integrated degrees of freedom (DOFs) are preferred for 3D manipulation, as they allow more natural and intuitive interaction. However, some trade-offs may exist between accuracy, speed, and ease of use. Position control is usually preferred for manipulation, as it provides direct feedback and control. Force control can be more suitable for controlling rates, such as velocity or acceleration  .
