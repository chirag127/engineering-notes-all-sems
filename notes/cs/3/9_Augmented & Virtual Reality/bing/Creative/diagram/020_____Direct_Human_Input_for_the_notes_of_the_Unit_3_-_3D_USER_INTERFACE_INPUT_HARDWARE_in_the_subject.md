### Direct Human Input for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE

- Direct human input refers to the type of 3D user interface (UI) that involves direct interaction in a virtual 3D spatial context.
- The user provides input to the system by making movements in physical 3D space or manipulating tools, sensors, or devices in 3D space .
- The degrees of freedom (DOF) are one of the main features of these systems, as they determine how many parameters are needed to specify the position and orientation of the input device or the user's body part.
- Some examples of direct human input devices are :
  - 3D mice: These are devices that allow the user to control a cursor or a virtual object in 3D space by moving the device along three axes (x, y, z) and rotating it around three axes (pitch, yaw, roll). Some 3D mice also have buttons or wheels for additional functions.
  - Gloves: These are devices that track the position and orientation of the user's hand and fingers, and sometimes provide haptic feedback. Gloves can be used to perform gestures, manipulate virtual objects, or interact with menus and widgets.
  - Trackers: These are devices that attach to the user's body parts (such as head, torso, limbs, etc.) and measure their position and orientation in 3D space. Trackers can be used to create a virtual representation of the user's body, or to control the viewpoint or the navigation in the virtual environment.
  - Cameras: These are devices that capture the user's image or motion and use computer vision techniques to extract information about the user's pose, gestures, facial expressions, or eye gaze. Cameras can be used to create a natural and intuitive interface that does not require any physical device to be worn or held by the user.
