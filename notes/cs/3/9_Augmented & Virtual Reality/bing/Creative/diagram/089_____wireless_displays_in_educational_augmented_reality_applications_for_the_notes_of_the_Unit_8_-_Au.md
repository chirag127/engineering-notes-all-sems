# Wireless Displays in Educational Augmented Reality Applications

- Wireless displays are output devices that can receive and display wirelessly streamed content, such as stereoscopic video signals, in real time.
- Wireless displays can be used for educational augmented reality (AR) applications, which are applications that combine real and virtual elements to enhance learning and teaching.
- Wireless displays can offer several advantages for educational AR applications, such as:
  - Enabling personalization and privacy of content for each user.
  - Reducing the number of cables and wires that can hinder movement and interaction.
  - Increasing the scalability and flexibility of the system by allowing more users and displays to be connected.
  - Supporting collaborative and cooperative learning scenarios by allowing users to share and exchange views and information.
- Examples of wireless displays that can be used for educational AR applications are:
  - A stereoscopic head mounted display (HMD) that can display 3D content and track the user's head orientation.
  - A TFT display module that can display 2D content and be attached to different objects or surfaces.
- Examples of educational AR applications that have used wireless displays are:
  - Construct3D, a 3D geometry construction and visualization tool that allows users to create and manipulate 3D objects using a pen-based interface.
  - ARMath, a math learning tool that allows users to explore and solve arithmetic problems using physical objects and virtual feedback.
- Examples of teaching scenarios that can benefit from wireless displays are:
  - A teacher can use a wireless HMD to monitor and guide the students' work on Construct3D, while the students can use wireless TFT displays to view their own or their peers' constructions.
  - A teacher can use a wireless TFT display to demonstrate and explain the ARMath problems, while the students can use wireless HMDs to interact with the problems and receive personalized feedback.
