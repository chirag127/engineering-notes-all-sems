### Desktop input devices for 3D user interface

- Desktop input devices are devices that allow the user to interact with a 3D user interface on a desktop system, such as a computer monitor or a projection screen.
- Desktop input devices can be classified into two categories: 2D input devices and 3D input devices.
- 2D input devices are devices that capture the user's input in two dimensions, such as the x and y coordinates of a mouse cursor or a touch point. 2D input devices can be used to control a 3D user interface by mapping the 2D input to a 3D virtual location or a 3D manipulation technique, such as rotation, scaling, or translation.
- 3D input devices are devices that capture the user's input in three dimensions, such as the position and orientation of a hand or a stylus. 3D input devices can provide more natural and direct interaction with a 3D user interface by allowing the user to perform actions in 3D space, such as grabbing, pointing, or drawing.
- Some examples of 2D input devices are:
  - Keyboards: devices that allow the user to enter text or commands by pressing keys. Keyboards can be used to control a 3D user interface by assigning keys to specific functions, such as navigation, selection, or mode switching.
  - 2D mice and trackballs: devices that allow the user to move a cursor on a 2D surface by moving a physical device. 2D mice and trackballs can be used to control a 3D user interface by mapping the cursor movement to a 3D virtual location or a 3D manipulation technique, such as ray-casting, virtual sphere, or arcball.
  - Pen- and touch-based tablets: devices that allow the user to interact with a 2D surface by using a pen or a finger. Pen- and touch-based tablets can be used to control a 3D user interface by mapping the pen or touch input to a 3D virtual location or a 3D manipulation technique, such as sketching, gesturing, or multi-touch.
- Some examples of 3D input devices are:
  - Joysticks: devices that allow the user to control the direction and speed of a 3D movement by tilting a stick. Joysticks can be used to control a 3D user interface by mapping the stick movement to a 3D navigation technique, such as flying, walking, or orbiting.
  - Desktop 6-DOF input devices: devices that allow the user to control the position and orientation of a 3D object by moving a physical device. Desktop 6-DOF input devices can be used to control a 3D user interface by mapping the device movement to a 3D manipulation technique, such as grabbing, pointing, or drawing. Some examples of desktop 6-DOF input devices are Polhemus sensors, SpaceMouse, and Phantom.
  - Hand gesture and body tracking devices: devices that allow the user to interact with a 3D user interface by using hand or body gestures, such as waving, pointing, or grabbing. Hand gesture and body tracking devices can be used to control a 3D user interface by mapping the gestures to a 3D manipulation technique, such as grabbing, pointing, or drawing. Some examples of hand gesture and body tracking devices are Kinect, Leap Motion, HoloLens, and Magic Leap.
