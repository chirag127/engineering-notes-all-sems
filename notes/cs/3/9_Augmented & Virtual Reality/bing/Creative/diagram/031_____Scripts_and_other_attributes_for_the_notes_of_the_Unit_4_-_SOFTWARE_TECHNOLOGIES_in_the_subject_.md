### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Scripts are sequences of commands or instructions that are executed by a software program or an interpreter. Scripts can be used to automate tasks, manipulate data, control the behavior of applications, or create interactive content.
- Scripts can be written in various programming languages, such as Python, JavaScript, C#, Lua, etc. Some languages are more suitable for certain domains or platforms than others. For example, Python is widely used for data analysis and machine learning, JavaScript is the standard language for web development, C# is the main language for Unity, and Lua is often used for game scripting.
- Scripts can be embedded in other files, such as HTML, XML, JSON, etc. or stored in separate files with specific extensions, such as .py, .js, .cs, .lua, etc. Scripts can also be compiled or interpreted, depending on the language and the environment. Compiled scripts are translated into executable code before running, while interpreted scripts are executed line by line at runtime.
- Scripts can interact with other software components, such as libraries, frameworks, APIs, etc. Libraries are collections of pre-written code that provide common functionality, such as math, graphics, networking, etc. Frameworks are sets of libraries and tools that support the development of specific types of applications, such as web, mobile, desktop, etc. APIs are interfaces that define how different software components communicate and exchange data, such as web services, databases, sensors, etc.
- Scripts can also have various attributes, such as parameters, variables, constants, data types, operators, expressions, statements, functions, classes, objects, etc. Parameters are values that are passed to a script or a function when it is called. Variables are names that store data that can change during the execution of a script. Constants are names that store data that cannot change during the execution of a script. Data types are categories of data that define their properties and operations, such as numbers, strings, booleans, lists, dictionaries, etc. Operators are symbols that perform arithmetic, logical, or bitwise operations on data, such as +, -, *, /, %, &, |, ^, etc. Expressions are combinations of data and operators that produce a value, such as 2 + 3, x * y, a and b, etc. Statements are instructions that control the flow of a script, such as if, else, for, while, break, continue, return, etc. Functions are blocks of code that perform a specific task and can be reused. Classes are templates that define the attributes and behaviors of objects. Objects are instances of classes that have their own data and methods.
