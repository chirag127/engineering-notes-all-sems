### Classification

- 3D interaction techniques are methods for manipulating, navigating, and selecting objects and information in 3D virtual environments.
- 3D interaction techniques can be classified according to different criteria, such as:
  - The type of task they support, such as manipulation, navigation, or selection.
  - The type of input device they use, such as mouse, keyboard, joystick, or gesture.
  - The type of feedback they provide, such as visual, auditory, or haptic.
  - The type of mapping they employ, such as direct, indirect, or hybrid.
- A common classification scheme for 3D interaction techniques is based on the taxonomy proposed by Bowman et al. (2004), which divides them into four categories:
  - Travel techniques: These techniques allow the user to move through the virtual environment, changing their viewpoint and position.
  - Selection techniques: These techniques allow the user to select one or more objects in the virtual environment, indicating their interest or intention to manipulate them.
  - Manipulation techniques: These techniques allow the user to change the position, orientation, size, shape, or other attributes of the selected objects in the virtual environment.
  - System control techniques: These techniques allow the user to access and control the system functions, such as menus, dialogs, or tools, that are not part of the virtual environment.
