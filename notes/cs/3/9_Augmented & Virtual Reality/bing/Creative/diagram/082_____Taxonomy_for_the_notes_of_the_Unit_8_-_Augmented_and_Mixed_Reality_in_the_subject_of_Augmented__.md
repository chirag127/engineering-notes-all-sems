### Taxonomy for the notes of the Unit 8 - Augmented and Mixed Reality

- Taxonomy is a system of classification that organizes and categorizes different types of phenomena based on their characteristics and relationships.
- Augmented reality (AR) and mixed reality (MR) are two types of immersive technologies that enhance the perception of reality by overlaying virtual elements on the real environment or blending them together.
- A taxonomy of AR and MR applications can help to understand the different aspects and dimensions of these technologies, such as their purpose, design, implementation, and evaluation.
- Based on the web search results, a possible taxonomy of AR and MR applications can be constructed as follows:

| Facet | Categories | Description |
| ----- | ---------- | ----------- |
| Educational Purpose | Cognitive, Affective, Psychomotor | The educational objectives that the application aims to achieve, such as knowledge, skills, attitudes, or behaviors. |
| Application Domain | Science, Technology, Engineering, Mathematics, Arts, Humanities, Social Sciences, Health, etc. | The subject area or discipline that the application relates to or supports. |
| Output Technology | Head-mounted display, Handheld device, Projection-based, Spatial, Haptic, Audio, etc. | The type of device or system that displays the virtual elements to the user. |
| Visual Guidance | Annotation, Registration, Occlusion, Lighting, Shadows, Depth cues, etc. | The techniques or methods that enhance the visual perception and understanding of the virtual elements in relation to the real environment. |
| Interaction Technique | Gesture, Touch, Voice, Gaze, Body movement, etc. | The type of input or feedback that the user can provide or receive from the application. |
| Evaluation Method | User study, Experiment, Survey, Interview, Observation, etc. | The type of research or assessment that the application undergoes to measure its effectiveness, usability, or user satisfaction. |

- An example of an AR application that can be classified using this taxonomy is:

| Facet | Category |
| ----- | -------- |
| Educational Purpose | Cognitive (understanding the solar system) |
| Application Domain | Science (astronomy) |
| Output Technology | Handheld device (smartphone) |
| Visual Guidance | Annotation (labels and information) |
| Interaction Technique | Touch (swipe and tap) |
| Evaluation Method | User study (pre-test and post-test) |

- An example of an MR application that can be classified using this taxonomy is:

| Facet | Category |
| ----- | -------- |
| Educational Purpose | Psychomotor (learning to play piano) |
| Application Domain | Arts (music) |
| Output Technology | Projection-based (projector and camera) |
| Visual Guidance | Registration (alignment and calibration) |
| Interaction Technique | Gesture (hand and finger movement) |
| Evaluation Method | Experiment (control and experimental group) |
