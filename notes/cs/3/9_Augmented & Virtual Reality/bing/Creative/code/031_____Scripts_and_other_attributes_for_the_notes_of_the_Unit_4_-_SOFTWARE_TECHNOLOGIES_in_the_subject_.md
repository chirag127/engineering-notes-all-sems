### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Scripts are sequences of commands or instructions that are executed by a software program or an interpreter. Scripts can be used to automate tasks, manipulate data, control the behavior of applications, or create interactive content.
- Some examples of scripting languages are Python, JavaScript, Lua, and C#.
- Scripts can be embedded in other software technologies, such as HTML, XML, JSON, or Unity, to enhance their functionality and interactivity.
- Other attributes are properties or characteristics of software technologies that define their quality, performance, compatibility, security, or usability.
- Some examples of attributes are reliability, efficiency, portability, maintainability, scalability, and accessibility.
- Attributes can be measured, evaluated, or verified using various methods, such as testing, debugging, profiling, benchmarking, or auditing.
- Software technologies for augmented and virtual reality (AR/VR) require specific scripts and attributes to create immersive and realistic experiences for the users.
- Some examples of scripts for AR/VR are:
  - Tracking scripts: These scripts enable the software to detect and track the position, orientation, and movement of the user, the device, or the environment, using sensors, cameras, or markers.
  - Rendering scripts: These scripts enable the software to generate and display 3D graphics, animations, sounds, or effects, using frameworks, libraries, or engines, such as OpenGL, DirectX, or Unity.
  - Interaction scripts: These scripts enable the software to respond to the user's input, gestures, voice, or actions, using interfaces, controllers, or haptics.
- Some examples of attributes for AR/VR are:
  - Immersion: This attribute measures how well the software creates a sense of presence and realism for the user, using factors such as field of view, resolution, frame rate, latency, or feedback.
  - Compatibility: This attribute measures how well the software works with different devices, platforms, or standards, using factors such as hardware requirements, software dependencies, or interoperability.
  - Security: This attribute measures how well the software protects the user's privacy, data, or identity, using factors such as encryption, authentication, or authorization.
