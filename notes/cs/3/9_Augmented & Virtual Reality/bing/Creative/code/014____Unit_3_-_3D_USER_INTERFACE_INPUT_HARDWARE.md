# Unit 3 - 3D User Interface Input Hardware

- 3D user interface input hardware are devices that capture and interpret the actions performed by the user in a 3D environment .
- The degrees of freedom (DOF) are one of the main features of these devices, as they indicate the number and type of independent movements that a device can sense or produce .
- Input devices can be classified according to the input type or frequency of data they generate:
  - Discrete: single data value (e.g. Boolean value, key press, button click)
  - Continuous: multiple data values (e.g. pixel coordinates, orientation angles, force vectors)
- Input devices can also be classified according to the amount of physical interaction they require:
  - Isomorphic: the device has a similar shape and motion as the virtual object it controls (e.g. steering wheel, joystick, glove)
  - Non-isomorphic: the device has a different shape and motion than the virtual object it controls (e.g. mouse, keyboard, touch screen)
- Some examples of input devices commonly used in 3D UIs are  :
  - Keyboards: discrete input devices that allow text entry and command selection
  - 2D mice and trackballs: continuous input devices that map 2D motion to 3D motion or selection
  - Pen- and touch-based tablets: continuous input devices that allow direct manipulation of 2D or 3D objects with a stylus or finger
  - Joysticks: continuous input devices that sense angular or linear displacement in one or more DOF
  - Gloves: continuous input devices that sense the position and orientation of the hand and fingers
  - Trackers: continuous input devices that sense the position and orientation of the head, body, or other objects in 3D space
  - Haptic devices: continuous input devices that provide force feedback to the user
  - Gesture recognition systems: discrete or continuous input devices that interpret the user's body movements as commands or actions
  - Voice recognition systems: discrete or continuous input devices that interpret the user's speech as commands or actions
