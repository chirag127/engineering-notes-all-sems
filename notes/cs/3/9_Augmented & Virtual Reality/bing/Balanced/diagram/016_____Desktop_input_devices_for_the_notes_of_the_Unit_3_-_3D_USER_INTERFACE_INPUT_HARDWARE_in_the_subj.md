### Desktop input devices for 3D user interface

- Desktop input devices are devices that allow users to interact with 3D user interfaces on a desktop system, such as a computer monitor or a projection screen.
- Desktop input devices can be classified into two categories: 2D input devices and 3D input devices.
- 2D input devices are devices that capture two degrees of freedom (DOF) of user input, such as position or orientation in a plane. Examples of 2D input devices are keyboards, mice, trackballs, touchpads, and touchscreens.
- 3D input devices are devices that capture three or more degrees of freedom of user input, such as position and orientation in 3D space. Examples of 3D input devices are joysticks, 3D mice, 6-DOF trackers, gesture sensors, and motion controllers.
- Desktop input devices can be used for different purposes in 3D user interfaces, such as navigation, selection, manipulation, system control, and symbolic input.
- Desktop input devices have different advantages and disadvantages for 3D user interfaces, depending on their characteristics, such as accuracy, resolution, bandwidth, latency, feedback, ergonomics, and compatibility.
