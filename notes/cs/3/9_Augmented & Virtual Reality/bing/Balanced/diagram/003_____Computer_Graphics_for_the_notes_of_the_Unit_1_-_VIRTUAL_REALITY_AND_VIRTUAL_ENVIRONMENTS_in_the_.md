### Computer Graphics for the notes of the Unit 1 - VIRTUAL REALITY AND VIRTUAL ENVIRONMENTS

- Virtual reality (VR) is the use of computer graphics systems in combination with various display and interface devices to provide the effect of immersion in the interactive 3D computer-generated environment . We call such an environment a virtual environment (VE).
- A virtual environment can simulate a real or an imaginary world, and can be designed for various purposes, such as entertainment, education, training, or research .
- A virtual environment typically consists of the following components :
  - A computer system that generates the graphics, sound, and other sensory inputs for the virtual environment.
  - A display device that presents the virtual environment to the user, such as a head-mounted display (HMD), a projection screen, or a monitor.
  - An interface device that allows the user to interact with the virtual environment, such as a joystick, a glove, a mouse, or a keyboard.
  - A tracking device that measures the user's position and orientation in the virtual environment, such as a camera, a gyroscope, or a magnetic sensor.
  - A feedback device that provides the user with sensory feedback from the virtual environment, such as a speaker, a haptic device, or a vest.
- A virtual environment can be classified into different types based on the degree of realism, interactivity, and immersion :
  - Realism refers to how closely the virtual environment resembles the real world or the intended scenario, in terms of visual, auditory, haptic, and other sensory cues.
  - Interactivity refers to how responsive the virtual environment is to the user's actions and inputs, and how much control the user has over the virtual environment.
  - Immersion refers to how much the user feels present and engaged in the virtual environment, and how much the user's attention is focused on the virtual environment rather than the real world.
- A virtual environment can be categorized into the following types based on the realism, interactivity, and immersion :
  - Non-immersive VR: The user views the virtual environment on a monitor or a screen, and interacts with it using a mouse, a keyboard, or a joystick. The user is aware of the real world and can easily switch attention between the virtual and the real world. The realism and interactivity are low, and the immersion is minimal.
  - Semi-immersive VR: The user views the virtual environment on a large projection screen or a wall, and interacts with it using a more sophisticated interface device, such as a glove, a wand, or a steering wheel. The user is partially aware of the real world, but can also be immersed in the virtual world. The realism and interactivity are moderate, and the immersion is medium.
  - Fully immersive VR: The user views the virtual environment through a head-mounted display (HMD) that covers the user's field of vision, and interacts with it using a highly realistic interface device, such as a body suit, a treadmill, or a motion platform. The user is isolated from the real world and fully immersed in the virtual world. The realism and interactivity are high, and the immersion is maximal.
