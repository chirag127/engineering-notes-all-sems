# Direct Human Input for 3D User Interface Input Hardware

- Direct human input refers to the use of the human body or parts of it as input devices for 3D user interfaces (3D UIs).
- Direct human input can be achieved by tracking the position, orientation, and motion of the user's head, hands, fingers, eyes, or other body parts, and using them to control 3D objects, navigate 3D environments, or issue commands to the system.
- Direct human input can provide natural, intuitive, and expressive interaction for 3D UIs, as well as reduce the need for external hardware devices.
- Direct human input can be classified into two categories: gesture-based and vision-based.

## Gesture-based input
- Gesture-based input involves the use of hand or body gestures to interact with 3D UIs.
- Gesture-based input can be captured by various sensors, such as gloves, trackers, cameras, or inertial measurement units (IMUs).
- Gesture-based input can be used for 3D object selection, manipulation, navigation, or system control, depending on the type and meaning of the gesture.
- Gesture-based input can be either discrete or continuous, depending on whether the gesture has a clear start and end point, or is a continuous stream of data.
- Gesture-based input can be either symbolic or spatial, depending on whether the gesture represents a symbol or a command, or a spatial movement or transformation.
- Gesture-based input can be either unimanual or bimanual, depending on whether the gesture involves one or both hands.
- Gesture-based input can be either static or dynamic, depending on whether the gesture involves a single pose or a sequence of poses.

## Vision-based input
- Vision-based input involves the use of the user's gaze or eye movements to interact with 3D UIs.
- Vision-based input can be captured by eye trackers, which measure the direction and focus of the user's eyes, or by cameras, which detect the user's face and head orientation.
- Vision-based input can be used for 3D object selection, manipulation, navigation, or system control, depending on the type and meaning of the eye movement.
- Vision-based input can be either discrete or continuous, depending on whether the eye movement has a clear start and end point, or is a continuous stream of data.
- Vision-based input can be either direct or indirect, depending on whether the eye movement is mapped to the same or a different location in the 3D UI.
- Vision-based input can be either explicit or implicit, depending on whether the eye movement is intended or unintended by the user.
