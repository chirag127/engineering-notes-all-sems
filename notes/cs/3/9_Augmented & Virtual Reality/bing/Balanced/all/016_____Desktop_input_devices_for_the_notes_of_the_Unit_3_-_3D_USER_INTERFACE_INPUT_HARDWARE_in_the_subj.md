# Desktop input devices for 3D user interface

- Desktop input devices are devices that allow the user to interact with a 3D user interface on a desktop system, such as a computer monitor or a projection screen.
- Desktop input devices can be classified into two categories: 2D input devices and 3D input devices.
- 2D input devices are devices that capture the user's input in two dimensions, such as the x and y coordinates of a mouse or a touch screen. 2D input devices can be used to control a 3D user interface by mapping the 2D input to a 3D virtual location or orientation, such as using a mouse to rotate a 3D object or to navigate a 3D scene.
- 3D input devices are devices that capture the user's input in three dimensions, such as the position and orientation of a hand or a head. 3D input devices can be used to control a 3D user interface by directly mapping the 3D input to a 3D virtual location or orientation, such as using a hand gesture to manipulate a 3D object or to interact with a 3D menu.
- Some examples of desktop input devices for 3D user interface are:

  - Keyboards: Keyboards are 2D input devices that allow the user to enter text or commands by pressing keys. Keyboards can be used to control a 3D user interface by assigning keys to specific functions or actions, such as using the arrow keys to move a 3D camera or to select a 3D option.
  - Mice and trackballs: Mice and trackballs are 2D input devices that allow the user to move a cursor on a 2D screen by moving the device on a surface or by rotating a ball. Mice and trackballs can be used to control a 3D user interface by mapping the cursor movement to a 3D virtual location or orientation, such as using a mouse to point and click on a 3D object or to drag and drop a 3D object.
  - Pen- and touch-based tablets: Pen- and touch-based tablets are 2D input devices that allow the user to draw or write on a surface using a stylus or a finger. Pen- and touch-based tablets can be used to control a 3D user interface by mapping the pen or finger movement to a 3D virtual location or orientation, such as using a pen to sketch a 3D shape or to trace a 3D path.
  - Joysticks: Joysticks are 2D input devices that allow the user to control a 2D or 3D direction by tilting a stick. Joysticks can be used to control a 3D user interface by mapping the stick tilt to a 3D virtual location or orientation, such as using a joystick to fly a 3D airplane or to steer a 3D car.
  - Desktop 6-DOF input devices: Desktop 6-DOF input devices are 3D input devices that allow the user to control a 3D position and orientation by moving or rotating the device in 3D space. Desktop 6-DOF input devices can be used to control a 3D user interface by directly mapping the device movement or rotation to a 3D virtual location or orientation, such as using a 6-DOF mouse to grab and move a 3D object or to look around a 3D scene.
  - Hand or body gesture sensors: Hand or body gesture sensors are 3D input devices that allow the user to control a 3D user interface using hand or body gestures, such as waving, pointing, or grabbing. Hand or body gesture sensors can be used to control a 3D user interface by directly mapping the gesture to a 3D virtual location or orientation, such as using a hand gesture to select or manipulate a 3D object or to interact with a 3D menu.
