## Unit 8 - Augmented and Mixed Reality

- Augmented reality (AR) is a technology that overlays virtual objects on the real-world environment, such as images, text, or sound, using a device such as a smartphone, a tablet, or a headset. AR enhances the user's perception of reality by adding information or entertainment to the existing scene. Examples of AR applications include navigation, gaming, education, and marketing.
- Mixed reality (MR) is a technology that not only overlays but also anchors virtual objects to the real world, allowing real and virtual elements to interact in an environment. MR combines the features of both AR and VR, creating a hybrid reality that merges the physical and digital worlds. Examples of MR applications include holographic communication, simulation, training, and entertainment.
- The main difference between AR and MR is the degree of immersion and interaction. AR provides a partial immersion, where the user can still see and interact with the real world, but with some virtual elements added. MR provides a full immersion, where the user can see and interact with both the real and virtual worlds, and the virtual elements can respond to the real environment.
