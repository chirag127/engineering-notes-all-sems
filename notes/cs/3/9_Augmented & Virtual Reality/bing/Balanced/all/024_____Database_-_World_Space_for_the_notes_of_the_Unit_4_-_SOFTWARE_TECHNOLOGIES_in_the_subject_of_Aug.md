# Database - World Space

- Database is a collection of organized and structured data that can be accessed, manipulated, and updated by software applications.
- World space is the coordinate system that defines the position and orientation of objects in a three-dimensional environment, such as augmented reality (AR) or virtual reality (VR).
- Database - world space is the concept of using database to store and retrieve data that is relevant to the physical environment and the objects in it, and to display the data in an immersive and interactive way using AR or VR technology.
- Some examples of database - world space applications are:

  - Power BI Data in space: a feature that uses AR to create spatial anchors in the real world and attach Power BI data to them, so that data can be connected to the physical environment it is relevant to.
  - FME AR: a tool that allows users to view and interact with spatial data in AR, such as maps, models, and point clouds.
  - Google AR: a platform that enables developers to create AR experiences for various devices and scenarios, such as education, gaming, and shopping.
  - T2AR: a project that demonstrates how station crew members can inspect and maintain scientific and exercise equipment in space using AR without assistance from ground teams.

- Some benefits of database - world space are:

  - It enhances the user's perception and understanding of the data and its context by providing a more natural and intuitive way of visualizing and exploring it.
  - It enables the user to interact with the data and the environment in real time, and to manipulate and modify the data as needed.
  - It reduces the need for external devices or interfaces, such as screens, keyboards, or mice, and allows the user to use gestures, voice, or eye movements to control the data and the AR or VR device.
  - It increases the user's engagement and interest in the data and the environment, and creates a more immersive and memorable experience.
