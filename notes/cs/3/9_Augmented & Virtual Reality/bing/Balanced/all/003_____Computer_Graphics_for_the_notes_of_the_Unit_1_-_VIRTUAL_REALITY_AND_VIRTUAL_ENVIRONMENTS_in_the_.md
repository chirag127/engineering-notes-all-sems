# Computer Graphics for the notes of the Unit 1 - VIRTUAL REALITY AND VIRTUAL ENVIRONMENTS in the subject of Augmented & Virtual Reality

- Virtual reality (VR) is the use of computer graphics systems in combination with various display and interface devices to provide the effect of immersion in the interactive 3D computer-generated environment . We call such an environment a virtual environment (VE).
- A virtual environment can simulate reality or create a fictional world that does not exist in the real world. The imagery of virtual reality may be constructed from photographs or film of real places, or it can be entirely computer generated.
- VR applications immerse the user in a computer-generated environment that simulates reality through the use of interactive devices, which send and receive information from the computer system. These devices may include head-mounted displays (HMDs), gloves, controllers, trackers, haptic devices, etc.
- The main components of a VR system are:
  - The computer system that generates the virtual environment and processes the user input and feedback.
  - The display system that presents the virtual environment to the user's senses, such as vision, hearing, touch, etc.
  - The interface system that allows the user to interact with the virtual environment, such as navigation, manipulation, communication, etc.
- The main challenges of VR are:
  - Creating realistic and convincing virtual environments that can match the user's expectations and preferences.
  - Providing natural and intuitive interaction methods that can support the user's tasks and goals in the virtual environment.
  - Ensuring the user's comfort and safety while using the VR system, such as avoiding motion sickness, eye strain, fatigue, etc.
  - Evaluating the effectiveness and usability of the VR system for different applications and domains, such as education, entertainment, training, etc.
