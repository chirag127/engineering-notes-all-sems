# Tools for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- 3D interaction techniques are methods for interacting with 3D environments and objects using various input devices and modalities.
- 3D interaction techniques can be classified into four main categories: navigation, selection and manipulation, system control, and symbolic input.
- Navigation techniques allow the user to move around the 3D environment and change the viewpoint. Examples of navigation techniques are walking, flying, steering, and teleporting.
- Selection and manipulation techniques allow the user to select and manipulate 3D objects in the environment. Examples of selection and manipulation techniques are ray-casting, virtual hand, go-go, HOMER, and 3D widgets.
- System control techniques allow the user to access and control the system functions and settings, such as menus, dialogs, and toolbars. Examples of system control techniques are 3D menus, 3D buttons, voice commands, and gestures.
- Symbolic input techniques allow the user to enter text, numbers, or symbols in the 3D environment. Examples of symbolic input techniques are virtual keyboards, speech recognition, and handwriting recognition.
- 3D interaction techniques can be designed and developed using various strategies, such as using 2D interaction techniques in 3D, adapting natural interaction techniques, combining multiple modalities, and using two-handed interaction.
- 3D interaction techniques can be evaluated using various criteria, such as usability, performance, user satisfaction, presence, and immersion.
- 3D interaction techniques can be applied to various domains and applications, such as education, training, gaming, visualization, and design. For example, 3D interaction techniques can be used for musical expression, semantic-based interaction, and 3D user interfaces.
