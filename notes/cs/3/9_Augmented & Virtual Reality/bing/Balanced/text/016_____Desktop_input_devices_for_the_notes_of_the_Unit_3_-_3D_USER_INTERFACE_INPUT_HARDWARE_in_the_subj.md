### Desktop input devices for 3D user interface

- Desktop input devices are devices that allow the user to interact with a 3D user interface on a desktop system, such as a computer monitor or a projection screen.
- Desktop input devices can be classified into two categories: 2D input devices and 3D input devices.
- 2D input devices are devices that capture the user's input in two dimensions, such as the x and y coordinates of a mouse cursor or a touch screen. 2D input devices can be used to control a 3D user interface by mapping the 2D input to a 3D virtual location or orientation, such as using a mouse to rotate a 3D object or to navigate a 3D scene.
- 3D input devices are devices that capture the user's input in three dimensions, such as the position and orientation of a hand or a head. 3D input devices can be used to control a 3D user interface by directly manipulating the 3D objects or the 3D viewpoint, such as using a hand gesture to grab and move a 3D object or to change the perspective of a 3D scene.
- Some examples of desktop input devices for 3D user interface are:

  - Keyboards: Keyboards are 2D input devices that allow the user to enter text or commands by pressing keys. Keyboards can be used to control a 3D user interface by assigning keys to specific functions or actions, such as using the arrow keys to move a 3D avatar or to switch between different 3D views.
  - 2D mice and trackballs: 2D mice and trackballs are 2D input devices that allow the user to move a cursor on a 2D surface by moving a physical device. 2D mice and trackballs can be used to control a 3D user interface by mapping the cursor movement to a 3D virtual location or orientation, such as using a mouse to select and drag a 3D object or to pan and zoom a 3D scene.
  - Pen- and touch-based tablets: Pen- and touch-based tablets are 2D input devices that allow the user to draw or tap on a 2D surface by using a stylus or a finger. Pen- and touch-based tablets can be used to control a 3D user interface by mapping the drawing or tapping to a 3D virtual location or orientation, such as using a pen to sketch a 3D shape or to rotate a 3D object or using a finger to swipe and pinch a 3D scene.
  - Joysticks: Joysticks are 3D input devices that allow the user to control a 3D user interface by moving a stick in different directions. Joysticks can be used to control a 3D user interface by mapping the stick movement to a 3D virtual location or orientation, such as using a joystick to fly a 3D airplane or to look around a 3D environment.
  - Desktop 6-DOF input devices: Desktop 6-DOF input devices are 3D input devices that allow the user to control a 3D user interface by moving and rotating a physical device in six degrees of freedom (DOF), which are the three translational DOF (x, y, z) and the three rotational DOF (pitch, yaw, roll). Desktop 6-DOF input devices can be used to control a 3D user interface by directly manipulating the 3D objects or the 3D viewpoint, such as using a 6-DOF device to grab and move a 3D object or to change the perspective of a 3D scene. Some examples of desktop 6-DOF input devices are the SpaceMouse, the Polhemus sensors, and the 3Dconnexion devices.
