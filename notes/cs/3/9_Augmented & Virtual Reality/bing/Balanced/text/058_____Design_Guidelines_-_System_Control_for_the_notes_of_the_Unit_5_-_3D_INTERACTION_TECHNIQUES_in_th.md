### Design Guidelines - System Control

- System control refers to the ability of the user to manipulate the state and behavior of the virtual environment and the application.
- System control can include tasks such as changing the viewpoint, selecting and manipulating objects, accessing menus and options, and quitting the application.
- System control can be achieved by various means, such as gestures, voice commands, physical buttons, or virtual widgets.
- Some design guidelines for system control are:

  - Provide consistent and intuitive mappings between the input devices and the system actions.
  - Use natural and familiar metaphors for the system control, such as grabbing, pointing, or speaking.
  - Provide feedback for the system control, such as highlighting, sound effects, or text messages.
  - Avoid conflicts and ambiguities between the system control and the interaction with the virtual objects.
  - Provide multiple modalities for the system control, such as combining gestures and voice commands, to increase flexibility and robustness.
  - Provide clear and easy ways to access and exit the system control, such as using a dedicated button or gesture, or a virtual menu.
