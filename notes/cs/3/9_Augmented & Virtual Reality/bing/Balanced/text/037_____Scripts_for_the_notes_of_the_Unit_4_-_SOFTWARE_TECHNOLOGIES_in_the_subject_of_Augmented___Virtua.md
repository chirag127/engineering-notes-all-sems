### Scripts for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Augmented reality (AR) and virtual reality (VR) are two types of immersive technologies that create simulated or enhanced environments for users to interact with.
- AR overlays digital information or objects on the real world, while VR creates a fully artificial environment that surrounds the user.
- AR and VR applications can be used for various purposes, such as entertainment, education, training, health care, tourism, gaming, and social media.
- To develop AR and VR applications, software developers need to use appropriate programming languages, tools, frameworks, and platforms that support these technologies.
- Some of the most popular AR and VR programming languages are:
  - C# - A general-purpose, object-oriented language that is widely used for developing games and applications with Unity, a cross-platform game engine that supports AR and VR development.
  - C++ - A low-level, compiled language that offers high performance and control over hardware and memory. It is used for developing complex and realistic VR applications with Unreal Engine, a powerful game engine that supports VR development.
  - Java - A high-level, interpreted language that runs on multiple platforms and devices. It is used for developing AR and VR applications for Android devices with Google ARCore and Google VR SDK, which are frameworks that provide AR and VR features and functionalities.
  - JavaScript - A scripting language that runs on web browsers and can manipulate web pages and elements. It is used for developing web-based AR and VR applications with frameworks such as A-Frame, Three.js, and Babylon.js, which are libraries that enable 3D graphics and VR rendering on the web.
  - Swift - A modern, compiled language that is designed for developing applications for iOS and macOS devices. It is used for developing AR and VR applications for Apple devices with ARKit and RealityKit, which are frameworks that provide AR and VR features and functionalities.
  - Python - A high-level, interpreted language that is easy to learn and use. It is used for developing AR and VR applications with frameworks such as PyOpenGL, Pyglet, and PyVR, which are libraries that enable 3D graphics and VR rendering with Python.
- To develop AR and VR applications, software developers also need to use appropriate tools, frameworks, and platforms that support these technologies. Some of the most popular ones are:
  - Unity - A cross-platform game engine that supports AR and VR development. It provides a graphical user interface (GUI) for creating scenes, assets, scripts, and animations, as well as a scripting API for programming logic and interactivity. It also supports various AR and VR devices and platforms, such as Oculus, HTC Vive, Windows Mixed Reality, Google Cardboard, and Vuforia.
  - Unreal Engine - A powerful game engine that supports VR development. It provides a GUI for creating realistic and immersive VR environments, as well as a scripting API for programming logic and interactivity. It also supports various VR devices and platforms, such as Oculus, HTC Vive, Windows Mixed Reality, and SteamVR.
  - Google ARCore and Google VR SDK - Frameworks that provide AR and VR features and functionalities for Android devices. They enable developers to create AR and VR applications with Java or C#, using Android Studio or Unity. They also provide various tools and libraries for tracking, rendering, audio, and input.
  - ARKit and RealityKit - Frameworks that provide AR and VR features and functionalities for Apple devices. They enable developers to create AR and VR applications with Swift or Objective-C, using Xcode or Unity. They also provide various tools and libraries for tracking, rendering, audio, and input.
  - A-Frame, Three.js, and Babylon.js - Libraries that enable 3D graphics and VR rendering on the web. They enable developers to create web-based AR and VR applications with JavaScript, using HTML and CSS. They also provide various tools and libraries for tracking, rendering, audio, and input.
