### Symbolic Input Tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- Symbolic input is the task in which users communicate symbolic information (text, numbers, and other symbols or marks) to the system .
- Symbolic input is a common and important task in many 3D applications, such as annotation, labeling, text entry, command input, and data entry.
- Symbolic input is challenging in 3D environments because of the lack of standard input devices, the difficulty of mapping 2D symbols to 3D spaces, and the trade-off between accuracy and efficiency.
- Symbolic input techniques can be classified into four categories based on the input device or modality used  :
  - Keyboard-based techniques: use physical or virtual keyboards to enter symbols, either directly or through a mapping scheme. Examples are miniature keyboards, chord keyboards, and soft keyboards.
  - Pen-based techniques: use a stylus or a finger to write or draw symbols on a surface or in mid-air. Examples are handwriting recognition, graffiti, and sketching.
  - Gesture-based techniques: use hand or body movements to perform predefined gestures that represent symbols. Examples are finger spelling, sign language, and motion gestures.
  - Speech-based techniques: use voice input to speak symbols or commands. Examples are speech recognition, natural language processing, and voice commands.
- Symbolic input techniques can be evaluated based on several criteria, such as input speed, error rate, user preference, cognitive load, and fatigue .
- Symbolic input techniques can be combined with other 3D interaction techniques, such as selection, manipulation, and system control, to create more complex and expressive tasks.
