## Unit 4 - SOFTWARE TECHNOLOGIES

- Software technologies are the tools and methods used to create, maintain, and improve software systems.
- Software technologies can be classified into different categories, such as programming languages, software development methodologies, software engineering principles, software testing techniques, software quality assurance, software security, software maintenance, and software evolution.
- Programming languages are the formal languages used to specify the instructions and data for software systems. Programming languages can be divided into low-level languages, such as assembly and machine code, and high-level languages, such as C, Java, Python, and Ruby. Programming languages can also be classified by their paradigms, such as imperative, declarative, functional, object-oriented, and logic programming.
- Software development methodologies are the frameworks and processes used to organize and manage software projects. Software development methodologies can be based on different models, such as waterfall, spiral, incremental, iterative, agile, and lean. Software development methodologies can also involve different practices, such as requirements analysis, design, coding, testing, deployment, and documentation.
- Software engineering principles are the guidelines and best practices used to ensure the quality and reliability of software systems. Software engineering principles can cover different aspects, such as modularity, abstraction, encapsulation, cohesion, coupling, inheritance, polymorphism, and design patterns. Software engineering principles can also address different challenges, such as complexity, change, reuse, and concurrency.
- Software testing techniques are the methods used to verify and validate the functionality and performance of software systems. Software testing techniques can be classified into different levels, such as unit testing, integration testing, system testing, and acceptance testing. Software testing techniques can also be classified into different types, such as black-box testing, white-box testing, functional testing, non-functional testing, and regression testing.
- Software quality assurance is the process of ensuring that software systems meet the specified requirements and standards. Software quality assurance can involve different activities, such as quality planning, quality control, quality audit, quality improvement, and quality measurement. Software quality assurance can also use different metrics, such as defect density, code coverage, cyclomatic complexity, and maintainability index.
- Software security is the process of protecting software systems from unauthorized access, modification, or damage. Software security can involve different techniques, such as encryption, authentication, authorization, access control, firewalls, intrusion detection, and penetration testing. Software security can also address different threats, such as malware, viruses, worms, trojans, spyware, ransomware, and denial-of-service attacks.
- Software maintenance is the process of modifying and updating software systems after their deployment. Software maintenance can be classified into different types, such as corrective maintenance, adaptive maintenance, perfective maintenance, and preventive maintenance. Software maintenance can also involve different tasks, such as bug fixing, performance tuning, compatibility enhancement, and feature addition.
- Software evolution is the process of changing and improving software systems over time. Software evolution can be driven by different factors, such as user feedback, market demand, technology advancement, and regulation compliance. Software evolution can also follow different patterns, such as software aging, software growth, software decay, and software rejuvenation.
