### 2D Controls for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- 2D controls are graphical user interface elements that are used to interact with 2D content in augmented and virtual reality applications.
- 2D controls can be displayed on a flat surface, such as a screen, a tablet, a smartphone, or a virtual window, or they can be projected onto a 3D scene, such as a wall, a floor, or a hologram.
- 2D controls can be used for various purposes, such as navigation, selection, manipulation, input, feedback, and communication.
- 2D controls can be designed using different styles, such as realistic, abstract, or symbolic, depending on the context and the user's preferences.
- 2D controls can be implemented using different technologies, such as web-based, native, or hybrid, depending on the platform and the performance requirements.
- 2D controls can be evaluated using different criteria, such as usability, functionality, aesthetics, and accessibility, depending on the user's needs and expectations.

Some examples of 2D controls in augmented and virtual reality are:

- Buttons: Buttons are the most common 2D control, used to trigger an action or a command, such as opening a menu, playing a video, or confirming a selection. Buttons can be designed using different shapes, colors, icons, and labels, and they can provide visual and auditory feedback when pressed.
- Sliders: Sliders are 2D controls used to adjust a continuous value, such as volume, brightness, or speed. Sliders can be designed using different styles, such as linear, circular, or radial, and they can provide visual and auditory feedback when moved.
- Switches: Switches are 2D controls used to toggle a binary state, such as on/off, yes/no, or true/false. Switches can be designed using different styles, such as checkboxes, radio buttons, or toggles, and they can provide visual and auditory feedback when switched.
- Text fields: Text fields are 2D controls used to enter or display text, such as names, passwords, or messages. Text fields can be designed using different styles, such as single-line, multi-line, or password, and they can provide visual and auditory feedback when typed or edited.
- Menus: Menus are 2D controls used to display a list of options or commands, such as settings, tools, or actions. Menus can be designed using different styles, such as drop-down, pop-up, or radial, and they can provide visual and auditory feedback when opened, closed, or selected.
- Toolbars: Toolbars are 2D controls used to display a set of buttons or icons, usually related to a specific task or function, such as drawing, editing, or annotating. Toolbars can be designed using different styles, such as horizontal, vertical, or floating, and they can provide visual and auditory feedback when activated or deactivated.
