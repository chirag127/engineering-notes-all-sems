# Symbolic Input Techniques

Symbolic input is the task in which users communicate symbolic information (text, numbers, and other symbols or marks) to the system. Symbolic input is often needed for tasks such as entering commands, passwords, names, labels, annotations, or queries. Symbolic input is challenging in 3D interaction because of the lack of standard input devices and the difficulty of mapping 2D symbols to 3D space.

Some of the main techniques for symbolic input in 3D interaction are:

- **Virtual keyboards**: These are graphical representations of keyboards that can be displayed in 3D space and manipulated by the user. The user can select keys using a 3D cursor, a ray-casting technique, or a direct touch technique. Virtual keyboards can be customized for different languages, layouts, or symbols. Virtual keyboards are easy to use and familiar to most users, but they can be slow, occlusive, and cumbersome to manipulate in 3D space  .

- **Speech input**: This is a technique that uses voice recognition to convert spoken words into text or commands. Speech input can be natural, fast, and hands-free, but it can also be affected by noise, accents, errors, or ambiguity. Speech input can be combined with other modalities, such as gestures or gaze, to improve accuracy and efficiency  .

- **Handwriting recognition**: This is a technique that uses a stylus, a finger, or a hand gesture to draw symbols on a surface or in the air, and then recognizes them as text or commands. Handwriting recognition can be flexible, intuitive, and expressive, but it can also be slow, inaccurate, or tiring. Handwriting recognition can be enhanced by using feedback, correction, or prediction mechanisms  .

- **Gestural input**: This is a technique that uses predefined or user-defined hand or body gestures to communicate symbols or commands to the system. Gestural input can be fast, natural, and immersive, but it can also be ambiguous, hard to remember, or prone to false positives. Gestural input can be supported by using visual, auditory, or haptic feedback, or by using menus or guides to display the available gestures   .

- **Eye tracking**: This is a technique that uses the direction of the user's gaze to select symbols or commands from a menu or a grid. Eye tracking can be quick, accurate, and unobtrusive, but it can also be affected by calibration, fatigue, or the Midas touch problem (unintentional selection). Eye tracking can be combined with other modalities, such as speech or gestures, to confirm or refine the selection  .
