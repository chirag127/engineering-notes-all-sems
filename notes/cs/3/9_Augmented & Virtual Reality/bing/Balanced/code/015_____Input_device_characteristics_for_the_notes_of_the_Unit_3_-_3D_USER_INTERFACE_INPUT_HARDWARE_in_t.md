### Input device characteristics for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

- Input devices are hardware that allow the user to communicate with the system by providing input in 3D space  .
- Input devices can be classified according to the following characteristics :
  - Degrees of freedom (DOFs): the number and type of independent parameters that define the position and orientation of the device or the user in 3D space. For example, a 6-DOF device can report three translational and three rotational parameters. DOFs can be integral (combined in a single device) or separable (divided among multiple devices).
  - Type of electronics: digital (binary) or analog (continuous) devices that report discrete or continuous values, respectively. For example, a button is a digital device that reports on or off, while a joystick is an analog device that reports a range of values.
  - Range of reported values: discrete (fixed number of values), continuous (infinite number of values), or hybrid (combination of discrete and continuous values) devices that report different levels of granularity. For example, a mouse wheel is a discrete device that reports a fixed number of steps, while a mouse movement is a continuous device that reports a continuous range of values.
  - Sensing technology: active (emit signals) or passive (receive signals) devices that use different methods to track the position and orientation of the device or the user in 3D space. For example, a magnetic tracker is an active device that emits a magnetic field, while a camera is a passive device that receives light.
  - Input modality: the type of input that the device can capture, such as position, orientation, gesture, voice, eye gaze, etc. For example, a glove is a device that can capture hand gestures, while a microphone is a device that can capture voice commands.
  - Interaction technique: the way the device is used to perform actions or tasks in the system, such as selection, manipulation, navigation, etc. For example, a ray-casting technique is an interaction technique that uses a device to point and select objects in 3D space, while a virtual hand technique is an interaction technique that uses a device to grab and move objects in 3D space.
- Input devices can be traditional (used for 2D interfaces) or spatial (designed for 3D interfaces). Traditional input devices include keyboards, mice, touchscreens, etc. Spatial input devices include trackers, gloves, wands, haptic devices, etc  .
- Input devices can be used for complementary input, which means that they can provide additional information or feedback to the user, such as sound, vibration, force, etc. For example, a haptic device can provide force feedback to the user when manipulating objects in 3D space .
- Input devices can be special purpose, which means that they are designed for specific tasks or applications in 3D interfaces. For example, a steering wheel is a special purpose input device for driving simulations, while a VR headset is a special purpose input device for immersive VR experiences .
