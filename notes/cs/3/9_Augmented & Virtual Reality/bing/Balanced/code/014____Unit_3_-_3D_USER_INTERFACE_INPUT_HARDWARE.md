# Unit 3 - 3D User Interface Input Hardware

- 3D user interface input hardware are devices that capture and interpret the actions performed by the user in a 3D environment.
- The main characteristics of 3D user interface input hardware are:
  - Degrees of freedom (DOF): the number of independent ways that a body can move in space. For example, a 3D mouse can have six DOF: three for translation (x, y, z) and three for rotation (pitch, yaw, roll).
  - Input type/frequency of data: the kind and amount of data that the device generates. For example, discrete input devices produce single data values (e.g. Boolean values), while continuous input devices generate multiple data values (e.g. pixel coordinates).
  - Physical interaction: the amount and type of physical effort required by the user to operate the device. For example, some devices are passive (e.g. gloves), while others are active (e.g. joysticks).
- Some examples of 3D user interface input hardware are:
  - Keyboards: a set of keys that can be used to enter text, commands, or shortcuts. They are typically used in desktop 3D UIs, and can have different layouts and sizes.
  - 2D mice and trackballs: devices that can sense the movement of the user's hand on a surface or a ball. They are also used in desktop 3D UIs, and can have different buttons and scroll wheels.
  - Pen- and touch-based tablets: devices that can sense the position and pressure of the user's finger or stylus on a surface. They can be used for drawing, writing, or selecting objects in 3D UIs.
  - Joysticks: devices that can sense the direction and magnitude of the user's hand movement on a stick. They can be used for navigating, flying, or controlling objects in 3D UIs.
  - Gloves: devices that can sense the position and orientation of the user's hand and fingers. They can be used for gesturing, manipulating, or interacting with objects in 3D UIs.
  - Trackers: devices that can sense the position and orientation of the user's head, body, or limbs. They can be used for tracking the user's viewpoint, posture, or motion in 3D UIs.
