### Symbolic Input Tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

- Symbolic input is the task in which users communicate symbolic information (text, numbers, and other symbols or marks) to the system .
- Symbolic input is a common and important task in many applications, such as text editing, data entry, programming, annotation, and communication.
- Symbolic input is challenging in 3D user interfaces (3DUIs) because of the lack of standard input devices, the complexity of 3D environments, and the diversity of user preferences and abilities.
- Symbolic input techniques for 3DUIs can be classified into four categories based on the input device and modality  :
  - Keyboard-based techniques: use physical or virtual keyboards to enter text or symbols, either directly or through a mapping scheme. Examples are miniature keyboards, chord keyboards, and soft keyboards.
  - Pen-based techniques: use a stylus or a finger to write or draw symbols on a surface or in the air. Examples are handwriting recognition, graffiti, and sketch-based interfaces.
  - Gesture-based techniques: use hand or body motions to perform predefined gestures that represent symbols. Examples are finger spelling, sign language, and motion capture.
  - Speech-based techniques: use voice input to dictate or command symbols. Examples are speech recognition, natural language processing, and voice chat.
- Symbolic input techniques for 3DUIs should consider the following design issues :
  - Input accuracy: how well the technique can recognize the intended symbols and avoid errors or ambiguities.
  - Input speed: how fast the user can enter symbols using the technique and how much feedback or confirmation is needed.
  - Input comfort: how easy and natural the technique is for the user and how much fatigue or discomfort it causes.
  - Input flexibility: how adaptable the technique is to different contexts, tasks, environments, and user preferences.
  - Input expressiveness: how rich and diverse the set of symbols that the technique can support is and how well it can convey the user's intention and emotion.
