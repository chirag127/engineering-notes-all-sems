### Marker-less tracking for augmented reality
- Marker-less tracking is a technique that does not require any predefined markers or targets to display augmented reality (AR) content on the user's environment.
- Marker-less tracking can use different methods to detect and track the features of the real world, such as natural features, depth sensors, inertial sensors, or a combination of them.
- Marker-less tracking can provide more flexibility and realism for AR applications, as it can adapt to different scenes and scenarios without the need for artificial markers.
- Marker-less tracking can also pose some challenges, such as occlusions, illumination changes, dynamic scenes, and computational complexity.
- Some examples of marker-less tracking methods are:
  - Visual Simultaneous Localization and Mapping (SLAM): a method that uses a camera to map the environment and estimate the camera pose simultaneously.
  - Visual Servoing: a method that uses a camera to control the motion of a robot or a virtual object by minimizing the error between the current and desired image features.
  - Feature-based Classification: a method that uses feature detection and description algorithms to extract and match features from the real world and a database of images, and then uses a classifier to identify the best match.
- Some applications of marker-less tracking for AR are:
  - Indoor navigation: a method that uses SLAM to guide the user through an indoor environment by overlaying directions and information on the camera view.
  - Furniture placement: a method that uses depth sensors to detect the floor and walls, and then allows the user to place virtual furniture on the real scene.
  - Gaming: a method that uses inertial sensors to track the user's head and hand movements, and then displays virtual objects and characters on the user's view.
