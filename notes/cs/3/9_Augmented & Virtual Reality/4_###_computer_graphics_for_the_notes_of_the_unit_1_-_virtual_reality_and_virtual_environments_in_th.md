### Computer Graphics for the notes of the Unit 1 - VIRTUAL REALITY AND VIRTUAL ENVIRONMENTS in the subject of Augmented & Virtual Reality

Unit 1 of the Augmented & Virtual Reality course focuses on Virtual Reality and Virtual Environments and covers the aspect of Computer Graphics.

Computer Graphics refers to the creation and manipulation of images and animations using computer algorithms and software. It is a field that combines computer science, mathematics, and art to produce visual representations of objects, scenes, and animations.

In the context of virtual reality and virtual environments, computer graphics is used to create realistic and immersive virtual environments. This includes creating 3D models of objects, scenes, and characters, as well as rendering these models with lighting, shading, and texture to create a realistic and believable virtual environment.

There are several techniques and algorithms used in computer graphics, including modeling, shading, lighting, and texturing. Modeling involves creating 3D representations of objects and scenes, which can be done using techniques such as polygonal modeling, NURBS modeling, and sculpting. Shading involves adding depth and texture to the models, which can be done using techniques such as smooth shading, flat shading, and texture mapping. Lighting involves adding illumination to the models, which can be done using techniques such as ambient lighting, diffuse lighting, and specular lighting. Texturing involves adding surface detail to the models, which can be done using techniques such as image mapping, procedural textures, and bump mapping.

In the context of the Augmented & Virtual Reality course, students in Unit 1 will learn about computer graphics as part of the discussion on Virtual Reality and Virtual Environments. This may include working with examples of computer graphics techniques and algorithms, analyzing the benefits and limitations of different computer graphics techniques, and learning how to use computer graphics to create realistic and immersive virtual environments.

In summary, Unit 1 of the Augmented & Virtual Reality course focuses on Virtual Reality and Virtual Environments and covers the aspect of Computer Graphics. Computer Graphics refers to the creation and manipulation of images and animations using computer algorithms and software, and is used to create realistic and immersive virtual environments. Students will learn about computer graphics through interactive activities and hands-on experiences, and will learn how to use computer graphics to create realistic and immersive virtual environments.
