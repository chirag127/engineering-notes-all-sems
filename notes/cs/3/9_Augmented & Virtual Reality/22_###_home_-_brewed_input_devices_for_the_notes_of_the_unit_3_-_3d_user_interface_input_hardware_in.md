### Home - Brewed Input Devices for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

Unit 3 of the Augmented & Virtual Reality course focuses on 3D User Interface Input Hardware and covers the aspect of home-brewed input devices.

A home-brewed input device is a custom-made input device that is built by an individual or a small group of individuals, rather than being purchased from a commercial vendor. Home-brewed input devices are often used in virtual reality and augmented reality applications to provide a unique and customized input experience for the user.

Some examples of home-brewed input devices include custom-made controllers, gloves, and body-tracking devices. Custom-made controllers are devices that are designed to provide specific input for a particular application, such as a virtual reality game or a simulation. Gloves are devices that are worn on the hands of the user, and are used to provide hand tracking and gesture recognition. Body-tracking devices are devices that are worn on the body of the user, and are used to track the position and orientation of the user's body in 3D space.

In the context of the Augmented & Virtual Reality course, students in Unit 3 will learn about home-brewed input devices as part of the discussion on 3D User Interface Input Hardware. This may include working with examples of home-brewed input devices, analyzing the benefits and limitations of home-brewed input devices, and learning how to design and build home-brewed input devices.
