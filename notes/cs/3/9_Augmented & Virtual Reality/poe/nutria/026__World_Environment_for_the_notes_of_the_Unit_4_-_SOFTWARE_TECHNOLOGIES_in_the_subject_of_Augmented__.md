
### World Environment for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

- Augmented Reality (AR) is a technology that superimposes digital images and information onto the real world. It is used to enhance the user experience and provide additional context to physical objects.

- Virtual Reality (VR) is a simulated environment that can be experienced through the use of a headset or other devices. It is used to create an immersive experience with the user being able to interact with the virtual world.

- Mixed Reality (MR) is a combination of AR and VR. It combines the digital elements of AR with the immersive experience of VR.

- Augmented Virtuality (AV) is a technology that combines digital elements with physical objects. It is used to create a more immersive experience for the user, allowing them to interact with the physical world while still having access to the digital elements.

- Wearable Technology is a type of technology that is worn on the body. It can be used to monitor the user’s health, provide additional information about the environment, or provide additional context to physical objects.

- Gesture Recognition is a technology that uses sensors to detect the user’s gestures and movements. It is used to allow the user to interact with the virtual environment without the need for a controller.

- Natural User Interface (NUI) is a type of technology that uses natural language processing to understand the user’s intent. It is used to create a more intuitive and natural user experience.
