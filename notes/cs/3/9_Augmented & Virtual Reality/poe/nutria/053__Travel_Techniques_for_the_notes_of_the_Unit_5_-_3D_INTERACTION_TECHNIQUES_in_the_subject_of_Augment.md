
### Travel Techniques for the Notes of Unit 5 - 3D INTERACTION TECHNIQUES

1. Pointing: Pointing is a simple 3D interaction technique that involves the user pointing to a specific object or location in the virtual environment. This technique can be used to select an object or to indicate the direction of travel.

2. Direct Manipulation: Direct manipulation is a 3D interaction technique that allows the user to directly manipulate an object in the virtual environment. This technique can be used to move an object, rotate it, or scale it.

3. Gesture Recognition: Gesture recognition is a 3D interaction technique that uses hand or body movements to control the virtual environment. This technique can be used to select objects, move them, or control other aspects of the virtual environment.

4. Voice Recognition: Voice recognition is a 3D interaction technique that uses spoken commands to control the virtual environment. This technique can be used to select objects, move them, or control other aspects of the virtual environment.

5. Eye Tracking: Eye tracking is a 3D interaction technique that uses the user's gaze to control the virtual environment. This technique can be used to select objects, move them, or control other aspects of the virtual environment.
