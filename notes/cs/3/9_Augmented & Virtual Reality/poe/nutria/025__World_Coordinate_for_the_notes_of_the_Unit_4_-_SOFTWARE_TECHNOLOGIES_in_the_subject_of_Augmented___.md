
### World Coordinate for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Augmented Reality (AR) is a technology that overlays digital content onto the physical world. It is used to enhance the user experience by providing an immersive and interactive environment.

2. Virtual Reality (VR) is a technology that creates a simulated environment for the user. It is used to provide an immersive experience and can be used for gaming, training, and other applications.

3. Augmented and Virtual Reality technologies can be used together to create a mixed reality experience. This is done by combining the physical world with digital elements to create an interactive environment.

4. Software technologies are used to create and maintain Augmented and Virtual Reality applications. These technologies include game engines, 3D modeling software, and development tools.

5. The World Coordinate System (WCS) is used to define the position and orientation of objects in Augmented and Virtual Reality. The WCS is used to create a consistent and accurate representation of the virtual environment.
