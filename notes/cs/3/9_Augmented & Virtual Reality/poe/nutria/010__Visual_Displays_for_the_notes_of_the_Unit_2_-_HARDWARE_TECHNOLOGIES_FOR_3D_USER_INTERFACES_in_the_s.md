
### Visual Displays for the notes of the Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES in the subject of Augmented & Virtual Reality 

* Visual displays are the most important components of augmented and virtual reality systems. 
* They provide the user with a 3D view of the environment and allow them to interact with the environment in a natural way. 
* There are several types of displays used in augmented and virtual reality, including head-mounted displays (HMDs), projection systems, and immersive displays. 
* HMDs provide the user with a 3D view of the environment and allow them to interact with the environment in a natural way. 
* Projection systems use two or more projectors to project images onto a surface, creating an immersive environment for the user. 
* Immersive displays use multiple screens to create a 3D environment for the user. 
* Each type of display has its own advantages and disadvantages, and the type of display used will depend on the application.
