
### Input Device Characteristics for the Notes of Unit 3 - 3D User Interface Input Hardware 

1. Tracking Devices: These devices are used to detect the position and orientation of the user’s body and hands in 3D space. Common tracking devices include optical tracking systems, accelerometers, gyroscopes, and magnetometers. 

2. Input Devices: These devices are used to detect the user’s input. Common input devices include keyboards, mice, joysticks, touchscreens, and haptic devices. 

3. Output Devices: These devices are used to display the output of the system. Common output devices include stereoscopic displays, projection systems, and haptic devices.

4. Interaction Techniques: These techniques are used to enable the user to interact with the system. Common interaction techniques include direct manipulation, gesture recognition, and voice recognition.
