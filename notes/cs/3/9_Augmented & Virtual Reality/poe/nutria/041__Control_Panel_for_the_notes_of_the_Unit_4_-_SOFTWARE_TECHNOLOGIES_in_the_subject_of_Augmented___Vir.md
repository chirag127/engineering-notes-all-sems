
### Control Panel for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

* Augmented Reality (AR) is a technology that enhances the real world with virtual elements. It allows users to interact with virtual objects in the real world, and can be used to create immersive experiences.
* Virtual Reality (VR) is a technology that allows users to interact with a virtual environment. It uses computer-generated images and sound to create a realistic and immersive experience.
* Mixed Reality (MR) is a combination of AR and VR technologies. It combines virtual elements with the real world in order to create a more immersive experience.
* Software Technologies are used to create and manage AR, VR, and MR experiences. These technologies include game engines, 3D modeling software, and development frameworks. 
* 3D modeling software is used to create 3D models for use in AR and VR applications. It includes tools for creating, editing, and manipulating 3D objects.
* Game engines are used to create interactive 3D applications. They provide a framework for creating games, simulations, and other interactive experiences.
* Development frameworks are used to create applications for AR and VR devices. They provide tools for creating and managing applications, as well as for deploying them to various platforms.
