
### Design Guidelines for the Notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the Subject of Augmented & Virtual Reality

1. 3D interaction techniques are used to create an immersive experience in augmented and virtual reality environments.
2. Gesture-based interactions such as hand tracking, motion controllers, and eye tracking can be used to interact with virtual objects.
3. Voice commands can be used to control virtual objects and navigate the environment.
4. Haptic feedback can be used to provide tactile feedback when interacting with virtual objects.
5. Natural language processing can be used to interpret user commands and provide appropriate responses.
6. Computer vision and machine learning algorithms can be used to detect objects and interpret user intent.
7. 3D audio can be used to create a more immersive experience in virtual environments.
8. AI-based virtual assistants can be used to provide assistance and guidance to users.
