
### Desktop Input Devices for Unit 3 - 3D USER INTERFACE INPUT HARDWARE

1. Keyboard: A keyboard is an input device used to type characters and commands into a computer system. It is the most common input device used for desktop computers.

2. Mouse: A mouse is an input device used to move a pointer or cursor on a computer screen. It is the most common input device used for desktop computers.

3. Touchpad: A touchpad is an input device used to move a pointer or cursor on a computer screen. It is similar to a mouse, but is operated using one or more fingers on a flat, touch-sensitive surface.

4. Joystick: A joystick is an input device used to move a pointer or cursor on a computer screen. It is operated using a hand-held stick that has a button or trigger for controlling the movement of the pointer.

5. Trackball: A trackball is an input device used to move a pointer or cursor on a computer screen. It is operated using a hand-held ball that is moved around a flat surface to control the movement of the pointer.

6. Light Pen: A light pen is an input device used to draw on a computer screen. It is operated using a hand-held pen that is pointed at the screen to draw lines and shapes.

7. Touchscreen: A touchscreen is an input device used to interact with a computer system. It is operated by touching the screen with a finger or stylus to control the movement of the pointer.
