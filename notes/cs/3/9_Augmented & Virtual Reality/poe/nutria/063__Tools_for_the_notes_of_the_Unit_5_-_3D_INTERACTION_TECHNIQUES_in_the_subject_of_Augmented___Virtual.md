1. 3D Interaction Techniques: 3D interaction techniques allow users to interact with virtual objects and environments in a natural and intuitive way. 3D interaction techniques can be divided into two main categories: direct manipulation and indirect manipulation.

2. Direct Manipulation: Direct manipulation involves the user directly manipulating objects in a virtual environment. Examples of direct manipulation techniques include hand gestures, body movements, and voice commands.

3. Indirect Manipulation: Indirect manipulation involves the user indirectly manipulating objects in a virtual environment. Examples of indirect manipulation techniques include mouse and keyboard commands, touch screens, and eye tracking.
