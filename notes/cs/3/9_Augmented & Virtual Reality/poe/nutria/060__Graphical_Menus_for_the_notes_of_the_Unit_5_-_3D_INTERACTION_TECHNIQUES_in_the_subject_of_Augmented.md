
### Graphical Menus for the Notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the Subject of Augmented & Virtual Reality

1. Graphical User Interfaces (GUIs) are the most common way to interact with 3D applications. They provide a visual representation of the user’s options and allow them to make selections easily.

2. Menus are a type of GUI that allow users to navigate through a list of options. They can be placed on the screen or in the 3D world and can be used to access features and functions.

3. 3D menus are a type of menu that is used to provide access to options in a 3D environment. They can be used to access features, functions, and data in a 3D environment.

4. 3D menus can be created using a variety of techniques. These include using 3D objects, using a 3D cursor, using a raycasting technique, and using a combination of these techniques.

5. Raycasting is a technique used to create 3D menus. It involves projecting a ray from the user’s viewpoint and then detecting the intersection of the ray with an object in the 3D environment.

6. 3D menus can be used to provide access to a variety of functions and features in a 3D environment. These include navigation, selection, and manipulation of objects. They can also be used to provide access to data in a 3D environment.
