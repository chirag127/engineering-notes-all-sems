
### User Centered Wayfinding Support for the Notes of Unit 5 - 3D INTERACTION TECHNIQUES

1. User centered wayfinding support is an important concept in augmented and virtual reality (AR/VR) applications. It is the process of providing users with the tools and information they need to navigate the virtual environment.

2. 3D interaction techniques are used to facilitate user navigation in AR/VR applications. These techniques include gesture control, voice commands, and haptic feedback.

3. Gesture control is the use of hand and body movements to interact with the virtual environment. This technique is often used in gaming applications, where users can move their hands to control the character or object they are playing with.

4. Voice commands are used to control the virtual environment. This can be used to open menus, select items, or give instructions to the virtual environment.

5. Haptic feedback is the use of tactile feedback to provide users with a sense of physical presence in the virtual world. This can be used to simulate the feeling of touching a virtual object or to provide feedback when a user performs an action.

6. Wayfinding support should be designed with the user in mind. This includes providing clear and intuitive navigation cues, such as visual indicators, audio cues, and haptic feedback. It is also important to consider the user’s level of experience with the virtual environment, as this can affect their ability to navigate it.
