
## Unit 3 - 3D USER INTERFACE INPUT HARDWARE

1. 3D user interface (UI) input hardware refers to the physical devices used to interact with a 3D UI. 
2. Common examples of 3D UI input hardware include motion controllers, 3D cameras, haptic devices, and 3D displays. 
3. Motion controllers allow users to interact with 3D UI elements by making physical gestures, such as waving their hands in the air. 
4. 3D cameras can be used to capture 3D images and motion data, which can then be used to control a 3D UI. 
5. Haptic devices provide tactile feedback to users when interacting with a 3D UI, allowing for a more immersive experience. 
6. 3D displays allow users to view 3D UI elements in three dimensions, providing a more realistic experience. 
7. In order to use 3D UI input hardware, users must be familiar with the specific technology and hardware used to interact with the 3D UI.
