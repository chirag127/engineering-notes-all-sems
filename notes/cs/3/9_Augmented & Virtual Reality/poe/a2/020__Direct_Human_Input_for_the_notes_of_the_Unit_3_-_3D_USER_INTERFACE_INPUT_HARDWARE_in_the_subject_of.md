### Direct Human Input for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE

1. Motion Tracking Devices
- Captures the motion of the user and translates it into input for the system.
- Examples: Motion controllers, data gloves, tracking markers/sensors, inertial measurement units (IMUs), etc.

2. Gesture Recognition Devices
- Capture gestures and hand poses of the user to input commands or interact with the system.
- Examples: Data gloves, wrist bands, hand-worn motion trackers, etc.

3. Haptic Devices
- Provide touch feedback to the user through forces, vibrations, and motions.
- Examples: Force feedback joysticks/controllers, tactile surfaces, exoskeletons, etc.

4. Eye Tracking Devices
- Track the gaze direction/eye motion of the user to input commands or interact with the system.
- Examples: Head-mounted eye trackers, remote eye trackers, etc.

5. Brain-Computer Interfaces
- Directly measure electrical activity of the brain and translate it into input for the system.
- Examples: EEG, fMRI, etc.
