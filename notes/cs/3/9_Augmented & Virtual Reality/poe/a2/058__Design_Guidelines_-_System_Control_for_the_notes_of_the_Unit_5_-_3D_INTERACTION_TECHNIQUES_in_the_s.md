 Here are the design guidelines for system control in 3D interaction techniques:

1. Provide direct control: The interaction techniques should provide direct control over the system and the user's actions should have a visible effect on the system. This provides a sense of agency to the user.
2. Use intuitive mappings: The mappings between the user's inputs and the system's outputs should be intuitive and easy to understand. This makes the system easier to learn and use.
3. Offer multiple modalities: The system should accept inputs from multiple modalities such as gesture, voice, gaze, etc. This increases inclusiveness and provides alternatives if one modality is unavailable.
4. Consider fatigue: The interaction techniques should be designed to minimize fatigue. This could include using gross movements instead of fine controls or providing modes to complete tasks efficiently.
5. Offer customizability: The system should allow customization of interactions based on user preferences or specific use cases. This personalizes the experience and makes the system adaptable to different requirements.

The design guidelines aim to make the interaction with 3D systems efficient, intuitive, inclusive and comfortable for the users. Following these guidelines while designing 3D interaction techniques leads to better user experience and wider adoption of the systems.
