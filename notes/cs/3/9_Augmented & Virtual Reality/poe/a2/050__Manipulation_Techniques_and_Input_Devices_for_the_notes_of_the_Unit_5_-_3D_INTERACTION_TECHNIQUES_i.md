### Manipulation Techniques and Input Devices

-   Direct manipulation: Users interact directly with objects in the virtual environment. Eg. Grabbing and moving objects with hands.
-   Indirect manipulation: Users interact via an interface device. Eg. Using controllers to select and move objects.
-   Examples of input devices:
    -   Hands: Gesture recognition, haptic gloves.
    -   Controllers: Wands, data gloves, joysticks.
    -   Head-mounted displays: Track head movements.
    -   Speech recognition: Recognize voice commands.
    -   Eye trackers: Track gaze and eye movements.
-   Each input device has advantages and limitations in terms of naturalness, accuracy, cost, etc. The choice of device depends on the desired interaction and applications.
-   Bimanual interaction allows more complex interactions using two hands/controllers, enabling actions like grasping/manipulating objects with one hand and navigating the scene with the other.
-   Direct manipulation with hands is most natural but limited by tracking accuracy and fatigue. Indirect manipulation via controllers enables precise interaction but can feel unnatural. A combination of direct/indirect manipulation is often used.
