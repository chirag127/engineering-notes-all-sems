### Input device characteristics for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality:

1. Buttons and triggers: Used to provide discrete input with on/off binary states. Can be used for selection, menu navigation, etc.
2. Joysticks and trackballs: Used to provide continuous analog input for navigation, object manipulation, etc. Joysticks provide 2D/3D input while trackballs provide 2D input.
3. Data gloves: Fabric gloves with sensors to capture finger bend and movement. Provide input for hand gesture recognition and object manipulation.
4. Motion trackers: Used to track the position and orientation of physical devices or parts of the user's body. Can be mechanical, inertial, optical, acoustic, magnetic, etc. Necessary for tracking the user's movement and gestures.
5. Gesture recognition: Vision-based or sensor-based systems to recognize and interpret gestures and movements of the user. Enable touchless input which is desirable for hygiene.
6. Voice recognition: Identifies speech input and converts it to text or commands. Enables hands-free interaction but can face challenges with background noise, accents, etc.
7. Eye trackers: Track the gaze direction/point of regard of the user's eyes. Allow input through eye movement and selection through eye fixations. Useful for hands-free interaction but can have precision and tracking challenges.

The input devices provide various modalities for user input in 3D user interfaces and the choice of devices depends on the input requirements of the tasks, user preferences, cost, etc. Both direct input devices and sensor-based gesture/motion/voice recognition systems are used.
