### Mutimodal System Control Techniques

Notes for Unit 5 - 3D Interaction Techniques

- Direct manipulation: Objects in a virtual environment can be directly manipulated using techniques like grasping, pushing, pulling, etc. This makes interaction intuitive but requires accurate tracking of hands or input devices.
- Indirect manipulation: Interaction is mediated through on-screen controls or commands. This is easier to implement but can be less intuitive and immersive. Examples include using menus, buttons or other widgets to control objects.
- Speech: Users can speak commands or instructions. Speech recognition is used to understand user utterances. This is convenient but can be limited by recognition accuracy and the need to remember specific commands.
- Gestures: Users can perform gestures with their hands, arms or body that are interpreted as interaction commands. This is an expressive way to interact but gestures can be difficult to distinguish reliably.
- Thought control: Changes in users brain activity are monitored to enable interaction without physical actions or speech. This is currently experimental and limited in capability.
- Combining multiple modalities: Different modalities can be combined to provide versatility, multidimensionality and robustness. However this requires integration of heterogeneous input sensing and interpretation technologies.
