### Computer Graphics for the notes of the Unit 1 - VIRTUAL REALITY AND VIRTUAL ENVIRONMENTS

- Computer graphics is the field of computer science that studies methods for digitally synthesizing and manipulating visual content.
- Computer graphics studies algorithms and techniques for generating imagery from 3D models or 2D image data.
- The main hardware components for computer graphics are:
    - Graphics processing unit (GPU) - Handles all the computational tasks for rendering graphics.
    - Display - Outputs the final rendered graphics. Can be monitors, projectors etc.
    - Input devices - Capture user input e.g. keyboard, mouse, touchscreen, motion controllers etc.
- The main software components for computer graphics are:
    - Modeling software - Used to create 3D models of objects. E.g. Blender, Maya, 3ds Max.
    - Rendering software - Converts 3D models into 2D images. E.g. Blender Internal, Cycles, Arnold.
    - Graphics libraries - Provide programmers access to graphics hardware. E.g. OpenGL, Vulkan, Direct3D.
- Key concepts in computer graphics include:
    - 3D modeling - Representing 3D objects mathematically. Uses techniques like polygonal modeling, sculpting, curve modeling etc.
    - Animation - Creating the illusion of movement. Uses techniques like keyframing, motion capture, procedural animation etc.
    - Rendering - Computing 2D images from 3D models. Uses techniques like ray tracing, rasterization, global illumination etc.
    - Image processing - Manipulating, analyzing or enhancing 2D images. Uses techniques like convolution, Fourier transforms, edge detection etc.
