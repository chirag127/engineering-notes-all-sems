### Visual Displays for the notes of the Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES

1. Stereoscopic Displays:
- Present separate images to the left and right eyes to create an illusion of depth.
- Require users to wear head-mounted displays or shutter glasses.
- Examples: Oculus Rift, HTC Vive.

2. Volumetric Displays:
- Create 3D imagery via illumination of voxels (3D pixels) in a 3D space.
- Allow 3D content to be viewed without special glasses.
- Examples: HoloLens (uses light field technology).

3. Holographic Displays:
- Create 3D light field via laser light diffraction.
- Very high resolution and wide viewing angles.
- Examples: Still in research (expensive and complex to implement).

The displays discussed enable hardware technologies for 3D user interfaces with augmented and virtual reality experiences. Selecting appropriate display technology depends on use cases and requirements such as form factor, depth perception, viewing angles, cost, etc. More research and development is focused on improving resolutions, sizes, and costs to enable mainstream consumer adoption of XR technologies with compelling visual experiences.
