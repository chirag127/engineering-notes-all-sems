### Classification for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

1. Direct manipulation techniques
- Ray casting: Interacting with virtual objects by pointing and clicking using a ray from a pointer. The first object intersected by the ray is selected or manipulated.
- Virtual hand: The user controls a virtual hand using data gloves or motion trackers. The hand can grasp and manipulate virtual objects.
- Wand: The user controls a wand device to select and manipulate objects. The wand position and orientation is tracked to allow interaction with objects.

2. Indirect manipulation techniques
- Menus: The user interacts with menus to select objects or invoke commands. Drop down or pie menus are common versions for 3D interaction.
- Widgets: Two or three-dimensional widgets/gadgets are used to control objects, for example, rotation widgets to control rotation or sliders to control size.
- Speech input: The user can invoke commands via speech input which is recognized using speech recognition systems.
- Gesture recognition: The user's physical gestures are tracked and recognized using gesture recognition algorithms to control the system.

3. Hybrid techniques
- Combine direct and indirect techniques for interaction. For example, using a wand for selection and menus for specifying parameters or modes.
- Use multiple interaction techniques and modalities together such as speech and gesture recognition along with menus or widgets. The appropriateness of each technique depends on the task and user preferences.
