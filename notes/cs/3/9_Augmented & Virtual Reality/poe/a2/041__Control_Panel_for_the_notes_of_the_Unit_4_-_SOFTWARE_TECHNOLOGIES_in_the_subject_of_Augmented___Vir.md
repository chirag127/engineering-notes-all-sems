### Control Panel for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Introduction to Software Technologies
- Application Software: Software designed to perform specific tasks for users like word processors, spreadsheets, etc.
- System Software: Software that interacts with computer hardware to provide core functionality. Eg. operating systems, drivers, utilities, etc.
- Programming Languages: Languages used to create software. Eg. C/C++, Java, Python, etc.
- Software Development Lifecycle: The process of analyzing problems, designing, developing and testing software. Includes stages like requirements, design, implementation, testing, deployment and maintenance.

2. Operating Systems
- Manage computer resources and provide an interface to use the system.
- Examples: Windows, Linux, macOS, Android, iOS, etc.
- Key functions: Process management, memory management, file management, handling I/O devices, providing user interface, etc.
- Architectures: Monolithic, Layered, Microkernel, etc.

3. Programming Languages
- Low-level vs High-level languages: Machine-independent vs human-readable languages.
- Compilation vs Interpretation: Converting entire programs vs translating instructions one at a time.
- Object-Oriented Programming: Programming paradigm based on objects and classes which model real-world problems. Supports concepts like inheritance, encapsulation, polymorphism, etc.
- Examples of languages: C/C++, Java, Python, JavaScript, etc.
