### Graphical User Interface for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. GUI or Graphical User Interface is the interface through which a user interacts with an application or a software. It allows users to interact with electronic devices through graphical icons and visual indicators.
2. The basic components of a GUI are windows, icons, menus, pointer, scroll bars, etc. These components are manipulated through input devices like mouse, keyboards, touch screens, etc.
3. The advantages of GUI are:
- Easy to use: GUIs are easier to use than command-line interfaces as they involve buttons, icons and menus that are easy to understand.
- Visually appealing: GUIs are more visually appealing and engaging for users. The use of graphics and visual elements makes the interface more attractive and interesting.
- Learnability: GUIs are easier to learn as the components have a metaphorical resemblance to physical objects which makes their functioning easy to understand.
4. The disadvantages of GUI are:
- Require more system resources: GUIs require more memory and processing power as they involve management of graphical elements. This can slow down the system speed.
- Easy to make mistakes: The ease of use of GUIs can lead to users making more mistakes by accidentally clicking on wrong options.
- Platform dependence: GUIs are often platform dependent and a GUI designed for one system may not work properly on another system. Porting GUIs to different platforms can be difficult.
