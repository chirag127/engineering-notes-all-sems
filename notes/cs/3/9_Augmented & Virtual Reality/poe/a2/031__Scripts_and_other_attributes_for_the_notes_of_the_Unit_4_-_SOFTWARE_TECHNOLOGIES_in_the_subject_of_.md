### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Scripts: Scripts are the programming codes written using a programming language to develop and control the behavior and functions of an AR/VR application. Some of the popular scripting languages used are:
- Javascript: Used to develop interactive AR/VR web experiences. Supports cross-platform experiences.
- C#: Used to develop AR/VR applications for Microsoft platforms like Hololens.
- C/C++: Used to develop high performance AR/VR applications. Provides low-level access to devices and systems.
- Python: Used for quick prototyping of AR/VR applications. Has many libraries for computer vision, machine learning, etc.

2. Markup languages: Markup languages are used to define the structure and layout of the AR/VR content. Some examples are:
- HTML: Used to structure AR/VR web content and experiences.
- XML: Used to structure 3D models and scenes in AR/VR. Supports integration of 3D assets from various sources.
- JSON: Used to structure data and configure parameters in AR/VR. Often used to load 3D models and their properties.

3. 3D computer graphics APIs: APIs are used to render and display 3D graphics in AR/VR. Some options are:
- OpenGL: Cross-language, hardware-independent API to render 2D and 3D graphics.
- WebGL: JavaScript API based on OpenGL ES to render 2D and 3D graphics within a web browser.
- Vulkan: Cross-platform, low-level API to render 2D and 3D graphics with minimal CPU overhead.
- Direct3D: API by Microsoft to render 3D graphics in Windows-based apps and games. Integrated into the XBOX ecosystem.
