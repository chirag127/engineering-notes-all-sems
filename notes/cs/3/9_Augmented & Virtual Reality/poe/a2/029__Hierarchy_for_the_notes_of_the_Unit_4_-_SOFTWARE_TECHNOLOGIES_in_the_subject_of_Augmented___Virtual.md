### Hierarchy for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Introduction to Software Technologies
- What are software technologies? Programming languages, software frameworks, APIs, etc. used to develop AR/VR applications
- Types of software technologies: Programming languages (C/C++, C#, Java, Python, etc.), Software frameworks (Unity, Unreal Engine, ARKit, ARCore, etc.), APIs (AR APIs, VR APIs, spatial APIs, etc.)

2. Popular Programming Languages for AR/VR
- C/C++ - Low-level languages, gives more control over hardware, used to develop engines and platforms
- C# - Used in Unity engine, easy to learn, provides high-level functionality
- Java - Used in some VR platforms, object-oriented, provides portability
- Python - Easy to learn, rapid development, used for some AR applications and machine learning in AR/VR

3. Popular Software Frameworks for AR/VR
- Unity - Popular game engine, supports multiple platforms including AR/VR, uses C#, easy to get started
- Unreal Engine - Powerful game engine, uses C++, highly customizable
- ARKit / ARCore - AR software frameworks by Apple and Google respectively, uses Swift/Java, allows easy development of AR experiences

4. AR/VR APIs
- Different types: Spatial APIs, VR APIs, AR APIs, etc.
- Example VR APIs: OpenVR, SteamVR, Oculus SDK, etc.
- Example AR APIs: ARKit, ARCore, Vuforia, etc.
- functionalities provided by APIs: Tracking, sensing, spatial mapping, etc.

5. Comparision of technologies and concluding remarks
- Comparision of programming languages, software frameworks, and APIs in terms of use cases, functionality, ease of development, portability, etc.
- Concluding remarks on choosing suitable technologies based on requirements and use cases.
