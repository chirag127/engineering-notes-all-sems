### World Environment for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

1. Unity: Unity is a cross-platform game engine developed by Unity Technologies. It is primarily used to develop video games and simulations for mobile devices, consoles, PCs, and websites. Unity allows developers to create 2D and 3D games and experiences.

2. Unreal Engine: Unreal Engine is a game engine developed by Epic Games. It provides a powerful engine for creating realistic 3D games, architectural and product visualizations, and film and television content. It has a robust material system, asset pipeline, and many customization options.

3. Vuforia: Vuforia is an augmented reality software development kit (SDK) for mobile devices that enables the creation of augmented reality applications. It uses computer vision technology to recognize and track planar images (images that contain distinct features like markers or textured patterns), simple 3D objects, and user-specified target databases.

4. ARToolKit: ARToolKit is an open-source C/C++ library for building augmented reality (AR) applications. It uses computer vision techniques to calculate the real-time pose of physical markers in a video stream and provides an API for rendering virtual objects on top of the markers. It supports square markers and natural feature tracking.
