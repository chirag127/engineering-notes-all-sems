### 3D Manipulation tasks for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

In this unit, we will be discussing 3D manipulation tasks and techniques that are commonly used in Augmented and Virtual Reality applications. These techniques are used to manipulate and interact with 3D objects in virtual environments. Here are some of the important 3D manipulation tasks that you should know:

1. Translation: This technique is used to move an object in a specific direction. Translation can be done along the X, Y, or Z axis. In order to perform translation, you need to select the object and then use the appropriate translation tool.

2. Rotation: Rotation is used to change the orientation of an object in 3D space. You can rotate an object along any axis, including the X, Y, and Z axis. To perform rotation, you need to select the object and then use the rotation tool.

3. Scaling: Scaling is used to change the size of an object. You can scale an object uniformly or non-uniformly. To perform scaling, you need to select the object and then use the scaling tool.

4. Skewing: Skewing is used to distort an object along a specific axis. This technique is often used to create perspective effects. To perform skewing, you need to select the object and then use the skewing tool.

5. Shearing: Shearing is used to shift one part of an object relative to another part. This technique is often used to create slanted or tilted objects. To perform shearing, you need to select the object and then use the shearing tool.

6. Extrusion: Extrusion is used to create a 3D object by extending a 2D shape along a specific axis. This technique is often used to create complex shapes such as buildings or vehicles. To perform extrusion, you need to select the 2D shape and then use the extrusion tool.

7. Beveling: Beveling is used to add a sloping edge or chamfer to an object. This technique is often used to create rounded or angled edges on objects. To perform beveling, you need to select the object and then use the beveling tool.

8. Boolean operations: Boolean operations are used to combine or subtract 3D objects. This technique is often used to create complex shapes or to cut holes in objects. To perform Boolean operations, you need to select the objects and then use the appropriate Boolean tool.

In conclusion, understanding these 3D manipulation tasks and techniques is crucial for designing and developing Augmented and Virtual Reality applications. By mastering these techniques, you can create realistic and immersive virtual environments that provide an engaging user experience.
