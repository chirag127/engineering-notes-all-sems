- Introduction to software technologies for AR/VR
- Programming languages for AR/VR development
- Game engines for AR/VR development

#### Key concepts to remember:

- Software technologies are essential for developing AR/VR applications.
- Different programming languages can be used for AR/VR development, each with its advantages and disadvantages.
- Game engines are powerful tools that can simplify AR/VR development.
- AR/VR SDKs and frameworks provide pre-built components for AR/VR development.
- AR/VR development tools and environments can make the development process more efficient and productive.
- AR/VR deployment and distribution can be challenging, and developers need to consider various factors such as device compatibility and performance.

#### Important terms:

- SDK: Software Development Kit, a set of tools and APIs for developing software applications.
- Framework: A pre-built set of components that can be used to develop applications.
- Game engine: A software platform designed to create video games and other interactive applications.
- IDE: Integrated Development Environment, a software application that provides comprehensive facilities for software development.
- Deployment: The process of releasing an application to end-users.
- Distribution: The process of making an application available to users via different channels such as app stores or websites.
