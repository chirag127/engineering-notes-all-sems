### 2D Controls for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

In augmented and virtual reality, 2D controls refer to the user interface elements that allow a user to interact with the virtual environment. These controls are essential to create an intuitive and user-friendly experience. Here are some common 2D controls used in AR/VR applications:

- **Buttons**: Buttons are one of the most common 2D controls used in AR/VR applications. They are used to trigger events or actions when clicked. Buttons can be designed in various shapes and sizes, and they can have different colors and labels to indicate their purpose.

- **Sliders**: Sliders are used to adjust values such as volume, brightness, or size. They are usually represented as a bar with a slider knob that can be dragged to change the value.

- **Checkboxes**: Checkboxes are used to select or deselect an option. They are typically represented as a square box that can be checked or unchecked.

- **Radio buttons**: Radio buttons are used to select only one option from a group of options. They are usually represented as a circle with a dot inside.

- **Drop-down menus**: Drop-down menus are used to display a list of options that can be selected. They are typically represented as a button with a down-arrow that, when clicked, displays a list of options.

- **Text boxes**: Text boxes are used to enter text or numeric values. They are usually represented as a rectangular box where the user can type their input.

These 2D controls can be used in combination with each other to create more complex user interfaces. It is essential to design 2D controls that are easy to understand and use to enhance the user experience in AR/VR applications.
