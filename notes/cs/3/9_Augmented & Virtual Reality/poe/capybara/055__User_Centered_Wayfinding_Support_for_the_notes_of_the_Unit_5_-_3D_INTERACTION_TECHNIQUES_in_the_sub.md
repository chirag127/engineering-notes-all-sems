### User Centered Wayfinding Support

User centered wayfinding support is an essential aspect of 3D interaction techniques in the field of augmented and virtual reality. In this context, the following points are worth noting:

- Wayfinding support refers to the process of helping users navigate through a virtual or augmented environment. It involves providing users with information about their location, the direction they need to take, and the distance to their destination.

- User centered wayfinding support is based on the principle of designing the system with the user in mind. It means that the system should take into account the user's needs, preferences, and limitations.

- One way to provide user centered wayfinding support is through the use of landmarks. Landmarks are distinctive features in the environment that help users orient themselves and navigate through the space. They can be visual, auditory, or haptic cues.

- Another way to provide user centered wayfinding support is through the use of maps. Maps can provide users with an overview of the environment and help them plan their route. They can also be used to highlight the user's current location and the location of their destination.

- Augmented reality can provide users with wayfinding support by overlaying information on the real world. For example, an augmented reality app can display directions on the user's smartphone camera view.

- Virtual reality can provide users with wayfinding support by creating a virtual environment that is easy to navigate. For example, a virtual reality game can use visual cues to guide the user through the space.

In conclusion, user centered wayfinding support is an important aspect of 3D interaction techniques in augmented and virtual reality. By designing the system with the user in mind and providing them with landmarks, maps, and other cues, we can help users navigate through the environment with ease.
