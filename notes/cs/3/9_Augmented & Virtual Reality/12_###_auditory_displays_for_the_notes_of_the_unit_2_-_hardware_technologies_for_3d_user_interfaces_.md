### Auditory Displays for the notes of the Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES in the subject of Augmented & Virtual Reality

Unit 2 of the Augmented & Virtual Reality course focuses on Hardware Technologies for 3D User Interfaces and covers the aspect of Auditory Displays.

An auditory display is a type of non-visual display that uses sound to convey information. In the context of virtual and augmented reality, auditory displays are used to enhance the user's experience by providing additional information and feedback through sound.

There are several types of auditory displays, including spatial audio, 3D audio, and binaural audio. Spatial audio refers to the use of sound to convey information about the location of objects in a virtual environment. 3D audio refers to the use of sound to convey information about the depth and height of objects in a virtual environment. Binaural audio refers to the use of sound to convey information about the direction and distance of objects in a virtual environment.

Auditory displays are used for several purposes in virtual and augmented reality, including navigation, object identification, and feedback. For example, auditory displays can be used to provide audio cues to help the user navigate a virtual environment, to identify objects in a virtual environment, and to provide feedback on the user's actions in a virtual environment.

In the context of the Augmented & Virtual Reality course, students in Unit 2 will learn about auditory displays as part of the discussion on Hardware Technologies for 3D User Interfaces. This may include working with examples of auditory displays, analyzing the benefits and limitations of auditory displays, and learning how to design and implement auditory displays in virtual and augmented reality applications.
