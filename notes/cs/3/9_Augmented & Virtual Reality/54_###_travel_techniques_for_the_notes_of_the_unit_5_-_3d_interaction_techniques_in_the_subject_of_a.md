Travel techniques are used to provide a sense of immersion and presence in the virtual environment, and to allow the user to explore and interact with the virtual environment.

Teleportation is a technique that allows the user to instantly move from one location to another within the virtual environment. Free-viewpoint navigation is a technique that allows the user to move through the virtual environment by changing their viewpoint, as if they were walking or flying. Object-relative navigation is a technique that allows the user to move relative to an object in the virtual environment, such as a vehicle or a platform.
