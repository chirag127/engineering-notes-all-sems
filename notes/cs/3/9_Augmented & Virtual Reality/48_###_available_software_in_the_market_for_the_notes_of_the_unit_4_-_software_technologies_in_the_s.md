### Available software in the market for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

Unit 4 of the Augmented & Virtual Reality course focuses on Software Technologies and covers the aspect of available software in the market.

Software is a critical component of augmented and virtual reality systems, as it provides the underlying technology for creating and managing virtual environments. There are several types of software that are used in augmented and virtual reality, including game engines, 3D modeling software, and development tools.

Game engines are software platforms that are used to create video games and other interactive applications. Game engines provide a range of tools and features for creating 3D environments, including physics engines, scripting languages, and asset management tools. Some popular game engines for augmented and virtual reality include Unity, Unreal Engine, and CryEngine.

3D modeling software is used to create 3D models of objects, characters, and environments that can be used in virtual and augmented reality applications. 3D modeling software provides tools for creating and manipulating 3D geometry, as well as tools for texturing, lighting, and animation. Some popular 3D modeling software for augmented and virtual reality include Blender, 3DS Max, and Maya.

Development tools are software tools that are used to develop, test, and deploy augmented and virtual reality applications. Development tools provide a range of features for creating and debugging augmented and virtual reality applications, including programming languages, integrated development environments (IDEs), and debugging tools. Some popular development tools for augmented and virtual reality include Visual Studio, Xcode, and Android Studio.

This may include working with examples of software, analyzing the benefits and limitations of different types of software, and learning how to choose the appropriate software for a given application.
