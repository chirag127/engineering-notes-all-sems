### Visual Displays for the notes of the Unit 2 - HARDWARE TECHNOLOGIES FOR 3D USER INTERFACES in the subject of Augmented & Virtual Reality

Unit 2 of the Augmented & Virtual Reality course focuses on Hardware Technologies for 3D User Interfaces and covers the aspect of visual displays.

A visual display is a device that is used to display visual information to a user. In the context of virtual reality and augmented reality, visual displays are used to create immersive experiences for the user.

There are several types of visual displays that are used in virtual reality and augmented reality, including head-mounted displays (HMDs), projection systems, and handheld displays.

Head-mounted displays (HMDs) are wearable devices that are placed on the head of the user and display visual information directly in front of the user's eyes. HMDs are used to create fully immersive virtual reality experiences.

Projection systems are devices that project visual information onto a screen or a surface. Projection systems are used to create large-scale virtual environments, such as CAVEs (Cave Automatic Virtual Environment).

Handheld displays are devices that are held in the hand of the user and display visual information. Handheld displays are used to create augmented reality experiences, where virtual objects are superimposed on the real world.

In the context of the Augmented & Virtual Reality course, students in Unit 2 will learn about visual displays as part of the discussion on Hardware Technologies for 3D User Interfaces. This may include working with examples of visual displays, analyzing the benefits and limitations of different types of visual displays, and learning how to choose the appropriate visual display for a given application.
