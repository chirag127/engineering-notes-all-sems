### Scripts and other attributes for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

Scripts: 
- Scripts are code snippets in a programming language that are used to automate tasks in virtual and augmented reality applications.
- They can be used to control the behavior of objects, characters, and environments in the virtual world.
- Scripts can also be used to respond to user input and trigger events in the virtual environment.

Other Attributes:
- Transform: position, rotation, and scale of an object in the virtual world.
- Collider: determines if an object interacts with other objects in the virtual world.
- Rigidbody: determines the physical properties of an object, such as mass, gravity, and friction.
- Material: defines the appearance of an object, including color, texture, and shading.
- Light: adds illumination to the virtual environment and affects the appearance of objects.
