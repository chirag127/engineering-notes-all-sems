### Direct Human Input for the notes of the Unit 3 - 3D USER INTERFACE INPUT HARDWARE in the subject of Augmented & Virtual Reality

Unit 3 of the Augmented & Virtual Reality course focuses on 3D User Interface Input Hardware and covers the aspect of Direct Human Input.

Direct Human Input refers to the methods by which users can directly interact with virtual environments using physical devices, such as hand gestures, body movements, or physical objects. This type of input allows users to interact with virtual environments in a more natural and intuitive way, as it mimics the way people interact with the physical world.

There are several types of direct human input devices, including hand-held controllers, body-tracking systems, and haptic devices. Hand-held controllers, such as gamepads or motion controllers, allow users to control the virtual environment using buttons, joysticks, or other physical controls. Body-tracking systems, such as motion capture systems or depth cameras, allow users to control the virtual environment using body movements, such as gestures, head movements, or body position. Haptic devices, such as gloves or force feedback devices, allow users to experience physical sensations, such as touch or force, in the virtual environment.

In the context of the Augmented & Virtual Reality course, students in Unit 3 will learn about direct human input as part of the discussion on 3D User Interface Input Hardware. This may include working with examples of direct human input devices, analyzing the benefits and limitations of different direct human input devices, and learning how to design and implement direct human input systems.
