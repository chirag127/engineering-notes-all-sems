### Tessellated Data for the notes of the Unit 4 - SOFTWARE TECHNOLOGIES in the subject of Augmented & Virtual Reality

Tessellated data refers to the process of breaking down a 3D object into smaller, manageable parts called "tiles". This technique is commonly used in video games, virtual reality, and augmented reality applications to improve performance and reduce memory usage. The tessellated data is then stored and processed in a way that allows for easy manipulation and rendering of the object in real-time. This leads to a more efficient and smoother experience for the user. Additionally, tessellation can also be used to add detail to an object, such as adding more polyggonal faces to a 3D model to make it appear smoother or more complex. Overall, tessellation is a crucial component in the development of augmented and virtual reality applications, as it allows for the creation of more immersive and interactive experiences for the user.
