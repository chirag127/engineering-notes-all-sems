### User Centered Wayfinding Support for the notes of the Unit 5 - 3D INTERACTION TECHNIQUES in the subject of Augmented & Virtual Reality

User Centered Wayfinding Support is a design approach that focuses on the needs and preferences of users when designing navigation and wayfinding systems in virtual environments. The following are some of the key concepts related to User Centered Wayfinding Support:

1. User Experience: User Centered Wayfinding Support prioritizes the user experience, ensuring that navigation and wayfinding systems are intuitive, efficient, and effective.

2. Context Awareness: User Centered Wayfinding Support takes into account the context of the user, such as their location, goals, and preferences, to provide personalized and relevant navigation and wayfinding support.

3. Spatial Awareness: User Centered Wayfinding Support supports spatial awareness, allowing users to understand their location, orientation, and movement within the virtual environment.

4. Navigation Aids: User Centered Wayfinding Support provides navigation aids, such as maps, markers, and guidance, to help users navigate and find their way in the virtual environment.

5. User Feedback: User Centered Wayfinding Support provides user feedback, such as notifications, alerts, and prompts, to help users understand their progress and make informed decisions.

6. Accessibility: User Centered Wayfinding Support takes into account accessibility considerations, such as accommodating users with disabilities, to ensure that navigation and wayfinding systems are accessible to all users.

In this unit, you will learn about User Centered Wayfinding Support, and you will learn how to design and implement navigation and wayfinding systems in virtual environments that are user-centered, context-aware, and accessible. You will also learn about the key concepts and components of User Centered Wayfinding Support, including user experience, context awareness, spatial awareness, navigation aids, user feedback, and accessibility.

This unit will provide a foundation for understanding the principles and practices of User Centered Wayfinding Support, and for exploring the various concepts and techniques used in the field of Augmented and Virtual Reality.
