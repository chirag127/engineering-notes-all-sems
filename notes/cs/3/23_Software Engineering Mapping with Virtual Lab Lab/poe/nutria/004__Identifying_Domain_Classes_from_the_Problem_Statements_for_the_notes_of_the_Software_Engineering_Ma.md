
## Identifying Domain Classes from the Problem Statements

1. The first step in identifying domain classes from a problem statement is to identify the nouns in the statement. These nouns are likely to be the objects that are part of the problem domain. 
2. Once the nouns have been identified, look for any relationships between them. These relationships will help to identify the classes and the attributes of those classes. 
3. Once the classes have been identified, consider the verbs in the problem statement. These verbs will help to identify the operations that the classes can perform. 
4. Finally, consider any adjectives or adverbs in the problem statement. These can help to identify the attributes of the classes. 
5. Once the classes, attributes and operations have been identified, it is important to consider how they will interact with each other. This will help to create a model of the problem domain that can be used to develop the software.
