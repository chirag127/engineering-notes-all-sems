## Statechart and Activity Modeling

1. Statechart: A statechart is a behavioral modeling technique which shows different states of a system/component and the transitions between those states. It can model complex behaviors with states and transitions.
2. States: The circles/boxes in a statechart represent states. A state represents some specific behavior or a stable situation of the system.
3. Transitions: The arrows between states represent transitions. A transition is a change from one state to another which occurs due to some event or condition.
4. Activities: An activity diagram is a UML behavior diagram that shows flows/sequence of activities/actions. It visualizes an overall flow/process of a system with activities, decisions, and branching.
5. Activity nodes: The shapes in an activity diagram denote different types of activities/actions:
- Initial node: Represents the start of the workflow
- Action: Represents some executable behavior/workflow
- Decision: Represents a branching point with multiple possible paths
- Merge: Joins multiple alternate paths
- Final node: Represents the completion of the activity
