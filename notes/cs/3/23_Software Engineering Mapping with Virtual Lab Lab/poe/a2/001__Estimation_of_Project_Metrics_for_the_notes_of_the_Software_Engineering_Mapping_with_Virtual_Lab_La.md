## Estimation of Project Metrics for the notes of the Software Engineering Mapping with Virtual Lab Lab in the subject of Software Engineering.

1. Size Metrics
- Lines of Code (LOC): Total number of lines of code written for a software product.
- Function Points (FP): A measure of the functionality provided by the software based on inputs, outputs, logical files, interfaces and functions.

2. Effort Metrics
- Person-Months (PM): Effort required in terms of number of people and number of months.
- Person-Hours (PH): Effort required in terms of number of people and number of hours.

3. Cost Metrics
- Development Cost: Cost incurred in terms of effort, resources and other expenses during software development.
- Maintenance Cost: Cost incurred in terms of effort, resources and other expenses during software maintenance.

4. Quality Metrics
- Number of Bugs: Total number of defects/bugs found in the software.
- Reusability: Extent to which a software component can be used in other applications.
- Reliability: Ability of software product to perform its intended functions under specified conditions for a specified period of time.
- Efficiency: Amount of computing resources and code required to perform a function.
- Portability: Ease of transferring software product to a different hardware or software environment.
- Testability: Effort required to test the software product.

The above points cover the major metrics estimated for a software project to analyze the project's size, cost, effort and quality. The metrics help in planning, monitoring and controlling software projects.
