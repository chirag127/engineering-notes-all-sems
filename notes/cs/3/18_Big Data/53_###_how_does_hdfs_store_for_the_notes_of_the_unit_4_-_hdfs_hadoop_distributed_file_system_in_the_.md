Unit 4 - HDFS (Hadoop Distributed File System) in the subject of Big Data will cover the basics of how HDFS stores data in a distributed manner.

HDFS (Hadoop Distributed File System) is a distributed file system that is designed to store large amounts of data in a scalable and fault-tolerant manner. HDFS stores data in a distributed manner by breaking it into smaller blocks and distributing the blocks across multiple nodes in a cluster. Each block is stored on multiple nodes in the cluster, providing redundancy and ensuring that data is available even if a node fails.
