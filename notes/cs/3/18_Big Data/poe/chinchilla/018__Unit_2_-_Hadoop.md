## Unit 2 - Hadoop 

Hadoop is an open-source framework that provides distributed storage and processing of large-scale data sets across clusters of computers. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage. Here are the key points to keep in mind while learning about Hadoop:

- Hadoop consists of two main components: Hadoop Distributed File System (HDFS) and MapReduce. HDFS is a distributed file system that provides reliable and scalable storage for large data sets, while MapReduce is a programming model used for distributed processing of large data sets.
- Hadoop is designed for processing large-scale data sets that cannot be processed by traditional data processing systems. It is widely used in Big Data applications, such as web search, advertising, and social media analysis.
- Hadoop provides fault tolerance, which means that if one node fails, the data and processing can be automatically transferred to another node in the cluster. This makes Hadoop highly reliable and ensures that data is not lost in case of hardware failure.
- Hadoop also provides scalability, which means that it can handle large data sets by adding more nodes to the cluster. This makes it easy to scale up or down based on the size of the data set and the processing requirements.
- Hadoop has a rich ecosystem of tools and technologies that can be used to enhance its functionality. Some of the popular tools include Apache Pig, Apache Hive, Apache HBase, and Apache Spark.
- Hadoop is written in Java, but it supports several programming languages, such as Python and R. This makes it easy for developers to write MapReduce jobs using their preferred programming language.
- Hadoop is supported by several vendors, including Cloudera, Hortonworks, and MapR. These vendors provide commercial support and additional tools and services to enhance the functionality of Hadoop.

In summary, Hadoop is a powerful framework for processing large-scale data sets. It provides fault tolerance, scalability, and a rich ecosystem of tools and technologies. Learning Hadoop can be beneficial for developers and data scientists who work with Big Data applications.
