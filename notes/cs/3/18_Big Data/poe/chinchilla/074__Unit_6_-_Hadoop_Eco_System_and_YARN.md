## Unit 6 - Hadoop Eco System and YARN

Hadoop is a distributed computing framework designed to process large data sets. It consists of four main components: Hadoop Distributed File System (HDFS), MapReduce, YARN, and Hadoop Common. In this unit, we will focus on Hadoop Eco System and YARN.

### Hadoop Eco System

Hadoop Eco System is a collection of tools and frameworks that work with Hadoop to make it more efficient and effective. Some of the popular tools and frameworks in the Hadoop Eco System are:

1. Apache Pig - Pig is a high-level platform for creating MapReduce programs used to analyze large data sets.

2. Apache Hive - Hive is a data warehousing and SQL-like query language used to analyze and process data stored in Hadoop.

3. Apache Spark - Spark is an open-source, distributed computing system used for big data processing.

4. Apache HBase - HBase is a distributed, NoSQL database used to store and manage large data sets.

5. Apache Flume - Flume is a distributed, reliable, and available system used for efficiently collecting, aggregating, and moving large amounts of log data.

### YARN

YARN (Yet Another Resource Negotiator) is the resource management layer of Hadoop. It is responsible for managing resources and scheduling tasks in a Hadoop cluster. YARN allows different data processing engines such as MapReduce, Spark, and Tez to run simultaneously on the same Hadoop cluster.

Some of the key features of YARN are:

1. Cluster Resource Management - YARN provides a central platform to manage resources in a Hadoop cluster. It allocates resources to applications based on their requirements.

2. Application Management - YARN allows different applications to run on a Hadoop cluster without interference. It ensures that each application gets the resources it needs to run efficiently.

3. Scalability - YARN can handle large clusters with thousands of nodes, making it highly scalable.

4. Fault Tolerance - YARN provides fault tolerance capabilities to ensure that applications keep running even in the event of hardware or software failures.

5. Multi-Tenancy - YARN allows different users to share a Hadoop cluster, ensuring that resources are allocated fairly.

In conclusion, Hadoop Eco System and YARN are essential components of Hadoop that enable efficient and effective processing of large data sets. Understanding these components and their features is crucial for anyone working with Hadoop.
