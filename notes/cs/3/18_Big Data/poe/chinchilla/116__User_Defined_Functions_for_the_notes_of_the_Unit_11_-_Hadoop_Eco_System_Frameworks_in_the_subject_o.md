### User Defined Functions for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

In Hadoop ecosystem, User Defined Functions (UDFs) play a crucial role in transforming and processing data. UDFs are custom functions that allow users to define their own logic for data processing. They are used in various Hadoop components such as Pig, Hive, and MapReduce. 

Here are some important points to keep in mind about UDFs in Hadoop ecosystem:

- UDFs are used to extend the functionality of Hadoop components by allowing users to define their own logic for data processing.
- In Pig, UDFs can be written in various programming languages such as Java, Python, and Ruby. They can be used to perform complex data transformations and manipulations.
- In Hive, UDFs can be used to perform custom aggregations, data transformations, and data analysis. Hive UDFs can be written in Java, Python, and other programming languages supported by the JVM.
- In MapReduce, UDFs can be used to perform custom data processing tasks. They can be written in Java or any other programming language that can be compiled to bytecode.
- UDFs can be either scalar or aggregate. Scalar UDFs take one or more input values and return a single output value. Aggregate UDFs take multiple input values and return a single output value after performing some aggregation operation.
- UDFs can be categorized as either deterministic or non-deterministic. Deterministic UDFs always return the same output for a given input. Non-deterministic UDFs can return different output for the same input depending on the state of the system.
- UDFs can also be categorized as either simple or complex. Simple UDFs can be easily defined and implemented. Complex UDFs require more complex logic and may need to be implemented using a combination of other UDFs or functions.

In conclusion, UDFs are a powerful feature of Hadoop ecosystem that allow users to define their own logic for data processing. They can be used in various Hadoop components such as Pig, Hive, and MapReduce to perform custom data transformations and manipulations. Understanding UDFs is an important aspect of learning Hadoop ecosystem and Big Data processing.
