### Basic Types and Operators

Scala is a statically typed programming language that provides support for various basic types and operators. In this unit, we will learn about the basic types and operators in Scala that are important for Big Data processing.

#### Basic Types

Scala provides support for the following basic types:

- **Byte**: It is an 8-bit signed two's complement integer that can hold values from -128 to 127.
- **Short**: It is a 16-bit signed two's complement integer that can hold values from -32768 to 32767.
- **Int**: It is a 32-bit signed two's complement integer that can hold values from -2147483648 to 2147483647.
- **Long**: It is a 64-bit signed two's complement integer that can hold values from -9223372036854775808 to 9223372036854775807.
- **Float**: It is a single-precision 32-bit IEEE 754 floating-point number that can hold values from approximately 1.4 x 10^-45 to 3.4 x 10^38.
- **Double**: It is a double-precision 64-bit IEEE 754 floating-point number that can hold values from approximately 4.9 x 10^-324 to 1.8 x 10^308.
- **Char**: It is a 16-bit Unicode character that can hold any character from the Unicode standard.
- **Boolean**: It is a logical type that can hold either true or false.

#### Operators

Scala provides support for various operators that are used to perform operations on the basic types. Some of the important operators are:

- **Arithmetic Operators**: These operators are used to perform arithmetic operations such as addition (+), subtraction (-), multiplication (*), division (/), and modulus (%).
- **Relational Operators**: These operators are used to compare two values and return a Boolean value. The relational operators are less than (<), less than or equal to (<=), greater than (>), greater than or equal to (>=), equal to (==), and not equal to (!=).
- **Logical Operators**: These operators are used to perform logical operations such as logical AND (&&), logical OR (||), and logical NOT (!).
- **Bitwise Operators**: These operators are used to perform bitwise operations on the binary representation of the values. The bitwise operators are bitwise AND (&), bitwise OR (|), bitwise XOR (^), and bitwise complement (~).
- **Assignment Operators**: These operators are used to assign a value to a variable. The assignment operators are =, +=, -=, *=, /=, %=, &=, |=, ^=, <<=, and >>=.

In conclusion, basic types and operators are fundamental concepts in Scala programming that are essential for Big Data processing. Understanding these concepts is important for writing efficient and effective code for Big Data applications.
