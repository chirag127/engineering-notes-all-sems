
### Hadoop Configuration for Unit 5 - Hadoop Environment in Big Data

1. Hadoop is an open-source software framework used for distributed storage and processing of large datasets across clusters of computers.
2. Hadoop is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
3. Hadoop applications can run on a cluster of commodity hardware.
4. Hadoop is written in Java, and is an Apache project sponsored by the Apache Software Foundation.
5. Hadoop uses the MapReduce programming model for distributed computing.
6. Hadoop provides a distributed file system called HDFS, which stands for Hadoop Distributed File System.
7. HDFS is designed to store large datasets in a distributed fashion, and to provide high throughput access to these datasets.
8. HDFS is based on the Google File System (GFS) and provides a fault-tolerant storage layer for Hadoop.
9. Hadoop also provides a resource management system called YARN, which stands for Yet Another Resource Negotiator.
10. YARN is responsible for scheduling jobs on the cluster and managing resources between applications.
