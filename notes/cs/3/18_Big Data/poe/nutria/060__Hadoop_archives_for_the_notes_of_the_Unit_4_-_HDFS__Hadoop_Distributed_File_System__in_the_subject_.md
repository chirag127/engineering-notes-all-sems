
### Hadoop archives for the notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the subject of Big Data

1. Hadoop Distributed File System (HDFS) is a distributed file system designed to store very large files with streaming data access patterns, running on commodity hardware.
2. HDFS is designed to be highly fault-tolerant and is suitable for applications that require large data sets.
3. HDFS is designed to provide high throughput access to application data and is suitable for applications that have large data sets.
4. HDFS provides a way to store large files across multiple machines.
5. HDFS is designed to be resilient to hardware failures and can tolerate the loss of individual nodes.
6. HDFS also provides high-availability and scalability for applications that require large data sets.
7. HDFS is optimized for batch processing and is suitable for applications that require large data sets.
8. HDFS provides access to data through a client-server architecture.
9. HDFS has a master-slave architecture where the master node is responsible for managing the file system namespace and the slave nodes are responsible for storing the data.
10. HDFS provides file system access through the Hadoop Distributed File System (HDFS) API.
