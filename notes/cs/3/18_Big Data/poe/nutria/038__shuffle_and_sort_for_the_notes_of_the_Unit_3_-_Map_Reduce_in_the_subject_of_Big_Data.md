
### Shuffle and Sort for the Notes of the Unit 3 - Map Reduce in the Subject of Big Data

1. Map Reduce is a programming model used for processing and generating large data sets with a parallel and distributed algorithm on a cluster.
2. The Map Reduce algorithm consists of two main functions: the map function and the reduce function.
3. The map function takes a set of data and converts it into another set of data, where individual elements are broken down into tuples (key-value pairs).
4. The reduce function takes the output from the map function and combines those data tuples into a smaller set of tuples.
5. Shuffling and sorting are two important steps in the Map Reduce algorithm.
6. Shuffling is the process of re-distributing data across different nodes in the cluster.
7. Sorting is the process of ordering the data based on the key.
8. The output of the Map Reduce algorithm is a set of key-value pairs which can be used for further processing or analysis.
