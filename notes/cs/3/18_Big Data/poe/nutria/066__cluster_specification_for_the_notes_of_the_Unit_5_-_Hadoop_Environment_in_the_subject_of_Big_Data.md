
### Cluster Specification for Unit 5 - Hadoop Environment

1. Hadoop is an open-source software framework for distributed storage and distributed processing of large datasets on computer clusters.

2. Hadoop clusters are made up of two types of nodes: the master node and the worker nodes. The master node is responsible for managing the workload of the cluster and the worker nodes are responsible for performing the actual processing.

3. The master node is typically a single node, while the worker nodes can be multiple nodes.

4. Hadoop clusters are usually deployed in a distributed fashion, with each node having its own local storage and memory.

5. Hadoop clusters are designed to be highly fault-tolerant and can continue to operate even when some of the nodes fail.

6. Hadoop clusters can be used to process large datasets in parallel, which can speed up processing time and improve efficiency.

7. Hadoop clusters can be used for a variety of tasks, including data analysis, machine learning, and web indexing.
