
### User Defined Functions for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

* User Defined Functions (UDFs) are functions that are written by the user to extend the capabilities of the Hadoop Eco System Frameworks. 
* UDFs are written in Java and can be used to process data in MapReduce jobs. 
* UDFs can be used to perform custom operations on data such as filtering, sorting, or transforming data into a different format. 
* UDFs are an important part of the Hadoop Eco System and can be used to increase the efficiency of data processing. 
* UDFs can be used to perform complex operations on data such as calculating the average of a group of numbers or finding the mode of a set of values.
