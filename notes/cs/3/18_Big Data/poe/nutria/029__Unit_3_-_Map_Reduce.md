
## Unit 3 - Map Reduce

Map Reduce is a programming model used for processing and generating large datasets. It is most commonly used in distributed computing environments where data is stored in multiple nodes.

* Map Reduce consists of two main functions: Map and Reduce. The Map function takes a set of data and converts it into another set of data, where individual elements are broken down into tuples (key/value pairs). The Reduce function combines the output of the Map function and produces a single output.

* Map Reduce is a divide and conquer algorithm. It divides the input data into smaller chunks and processes them in parallel. This makes it more efficient than processing the data in a single thread.

* Map Reduce is used in a variety of applications such as web indexing, data mining, machine learning, and natural language processing. It is also used in Big Data analytics, where large datasets are analyzed to gain insights.

* Hadoop is an open-source software framework that is used to implement Map Reduce. It provides a distributed file system and a framework for running Map Reduce programs.
