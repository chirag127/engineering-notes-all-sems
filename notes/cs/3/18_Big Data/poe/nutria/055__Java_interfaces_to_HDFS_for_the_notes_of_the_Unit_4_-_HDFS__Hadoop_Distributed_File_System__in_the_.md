
### Java Interfaces to HDFS

HDFS (Hadoop Distributed File System) is a distributed, scalable, and portable file-system written in Java for the Hadoop framework. It provides high-throughput access to application data and is suitable for applications with large data sets.

The following are the Java interfaces to HDFS:

1. **Hadoop File System (HDFS) API**: This API provides a Java-based interface for applications to interact with HDFS. It allows applications to read and write files on HDFS, as well as to manage directories, access file system metadata, and perform other operations.

2. **Hadoop File System Shell**: This is a command-line interface to HDFS. It provides a set of commands for interacting with HDFS, such as creating and deleting directories, copying files, setting permissions, and more.

3. **Hadoop File System WebHDFS**: This is a web-based interface for HDFS. It provides a RESTful API for applications to access HDFS.

4. **Hadoop File System Java Native Interface (JNI)**: This is a Java-based interface that provides direct access to HDFS. It allows applications to bypass the HDFS API and directly access HDFS data.
