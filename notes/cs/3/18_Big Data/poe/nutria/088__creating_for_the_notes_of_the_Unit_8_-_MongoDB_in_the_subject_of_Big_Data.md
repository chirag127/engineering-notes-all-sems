
### Unit 8 - MongoDB
MongoDB is a document-oriented database program that is part of the NoSQL family of databases. It is designed to store and manage large amounts of data in a distributed, scalable, and reliable manner. MongoDB is an open-source database, meaning it is free to use and modify.

MongoDB is a powerful tool for managing large amounts of data. It provides a flexible data model, allowing users to store data in a variety of formats, including JSON, BSON, and XML. It also provides powerful query capabilities, allowing users to quickly and easily retrieve data from the database. Additionally, MongoDB provides scalability, allowing users to scale their databases as their data grows.

MongoDB is a popular choice for Big Data applications due to its scalability, flexibility, and performance. It is used by many large companies, including Google, Facebook, and Amazon. Additionally, MongoDB is used in many industries, including healthcare, finance, and retail.
