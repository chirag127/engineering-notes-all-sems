

### Task Execution for the Notes of Unit 3 - Map Reduce in Big Data

1. MapReduce is a programming model used to process large datasets in a distributed computing environment.
2. The MapReduce model consists of two main phases: the Map phase and the Reduce phase.
3. In the Map phase, data is divided into smaller pieces and each piece is then processed in parallel by multiple nodes.
4. In the Reduce phase, the results of the Map phase are aggregated and combined into a single result.
5. The MapReduce model is used in many big data applications such as search engine indexing, web analytics, and machine learning.
6. MapReduce is an example of a divide-and-conquer algorithm, which is a type of algorithm that splits a problem into smaller subproblems and then solves each subproblem independently.
7. MapReduce is a powerful tool for processing large datasets, but it is important to note that it is not suitable for all types of problems.
