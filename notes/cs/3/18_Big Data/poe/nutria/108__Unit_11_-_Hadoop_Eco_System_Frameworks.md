
## Unit 11 - Hadoop Eco System Frameworks

1. Hadoop is an open-source software framework designed to store and process large amounts of data. It is based on the MapReduce programming model and consists of two main components: the Hadoop Distributed File System (HDFS) and the Hadoop Common.

2. HDFS is a distributed file system that stores data across multiple machines and allows for data to be processed in parallel. It is fault-tolerant and can handle large amounts of data quickly.

3. Hadoop Common is a collection of libraries and utilities that are used to support the Hadoop system. It includes libraries for distributed computing, distributed file systems, and data processing.

4. Hadoop Eco System Frameworks are a set of tools and libraries that provide additional functionality to the Hadoop system. These include Apache Pig, Apache Hive, Apache HBase, Apache Mahout, Apache Spark, and Apache Flume.

5. Apache Pig is a data processing framework that enables data to be processed using a high-level language called Pig Latin. It is used to analyze large datasets and can be used in conjunction with HDFS and MapReduce.

6. Apache Hive is a data warehouse system that enables data to be queried using a SQL-like language called HiveQL. It is used to store and analyze large datasets and can be used in conjunction with HDFS and MapReduce.

7. Apache HBase is a NoSQL database that is used to store and process large amounts of data. It is used in conjunction with HDFS and MapReduce and is designed to be highly scalable and fault-tolerant.

8. Apache Mahout is a machine learning framework that is used to analyze large datasets and develop predictive models. It is used in conjunction with HDFS and MapReduce.

9. Apache Spark is a distributed computing framework that is used to process large datasets in parallel. It is used in conjunction with HDFS and MapReduce and is designed to be highly scalable and fault-tolerant.

10. Apache Flume is a distributed streaming data collection system that is used to collect, aggregate, and move large amounts of data from sources to sinks. It is used in conjunction with HDFS and MapReduce.
