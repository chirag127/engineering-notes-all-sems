
### Hive and HBase for the Notes of Unit 11 - Hadoop Eco System Frameworks in the Subject of Big Data

1. Apache Hive is an open source data warehouse system built on top of Hadoop. It provides a SQL-like language called HiveQL for querying and analyzing data stored in the Hadoop Distributed File System (HDFS). Hive also supports data manipulation and storage of structured and semi-structured data.

2. Apache HBase is an open-source, distributed, versioned, non-relational database modeled after Google's BigTable. It runs on top of the Hadoop Distributed File System (HDFS) and provides real-time read/write access to large datasets. HBase is designed to store billions of rows and millions of columns of data.

3. Hive and HBase are two of the most popular frameworks in the Hadoop ecosystem. Both are used for processing and querying large datasets stored in HDFS. Hive is used for batch processing of structured and semi-structured data, while HBase is used for real-time read/write access to large datasets.
