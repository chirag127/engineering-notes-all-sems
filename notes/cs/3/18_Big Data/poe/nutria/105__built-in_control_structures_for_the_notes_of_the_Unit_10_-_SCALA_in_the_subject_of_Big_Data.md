
### Built-In Control Structures for the Notes of the Unit 10 - SCALA in the Subject of Big Data

1. **For Loops**: Scala's `for` loop is a powerful tool for iterating over collections. It can be used to iterate over elements in an array, list, set, or other collection.

2. **Match Expressions**: Match expressions are a powerful tool for pattern matching in Scala. They are used to match a value to a set of patterns and execute code based on the pattern that matches.

3. **If-Else Statements**: If-else statements are used to control the flow of a program. They are used to execute different code based on a boolean condition.

4. **Try-Catch Blocks**: Try-catch blocks are used to handle errors in a program. They are used to catch exceptions that occur during the execution of a program and handle them gracefully.

5. **While Loops**: While loops are used to iterate over a collection or condition until the condition is false. They are used to execute code until a certain condition is met.
