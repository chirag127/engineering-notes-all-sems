
### Updating and Deleting Documents for the Notes of Unit 8 - MongoDB in the Subject of Big Data

- Updating documents in MongoDB is a simple process, and can be done with the `updateOne()` and `updateMany()` methods. 
- `updateOne()` can be used to update a single document, while `updateMany()` can be used to update multiple documents.
- When updating documents, you can use the `$set` operator to specify which fields you want to update. 
- You can also use the `$inc` operator to increment or decrement a field's value by a specified amount. 
- Deleting documents in MongoDB is done with the `deleteOne()` and `deleteMany()` methods. 
- `deleteOne()` can be used to delete a single document, while `deleteMany()` can be used to delete multiple documents. 
- When deleting documents, you can use the `justOne` option to specify if you want to delete only one document or all documents that match the query.
