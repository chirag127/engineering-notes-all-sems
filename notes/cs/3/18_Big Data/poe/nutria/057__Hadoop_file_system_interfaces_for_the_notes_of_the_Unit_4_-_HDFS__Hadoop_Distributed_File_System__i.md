
### Hadoop File System Interfaces

1. HDFS (Hadoop Distributed File System) is the primary distributed storage system used by Hadoop applications. It uses a master/slave architecture, with a single Namenode (master) and multiple Datanodes (slaves).
2. HDFS is designed to store large files across multiple machines. It is fault tolerant, meaning that it can detect and recover from hardware and software failures.
3. HDFS provides access to files through a variety of interfaces, including a Java API, a command-line interface, and a web-based user interface.
4. HDFS also provides access to files through the Hadoop File System (HDFS) shell. The shell provides a set of commands for managing files and directories.
5. HDFS also provides a Java API for accessing files. The API provides methods for reading and writing files, creating and deleting directories, and more.
6. HDFS also provides a command-line interface for managing files and directories. The command-line interface provides commands for listing files, copying files, and more.
