
### Security in Hadoop

1. Hadoop provides a framework for distributed processing of large datasets across clusters of computers.
2. Security in Hadoop is based on authentication, authorization, and data encryption.
3. Authentication is used to verify the identity of a user or a service. It is implemented using Kerberos, which is a network authentication protocol.
4. Authorization is used to control access to resources and data within the Hadoop cluster. It is implemented using Access Control Lists (ACLs) and pluggable authorization modules.
5. Data encryption is used to protect data stored in the Hadoop Distributed File System (HDFS). It is implemented using Secure Socket Layer (SSL) and Transport Layer Security (TLS).
6. Hadoop also provides other security features, such as secure RPC, secure data transfer, and secure inter-node communication.
