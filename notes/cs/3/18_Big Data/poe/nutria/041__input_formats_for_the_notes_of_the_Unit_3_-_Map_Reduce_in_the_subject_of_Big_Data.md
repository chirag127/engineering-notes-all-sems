
### Input Formats for Unit 3 - Map Reduce in Big Data

1. Text Input Format: This is the default input format. It is used to read data line by line from a given file.

2. Key-Value Input Format: This input format is used to read data in the form of key-value pairs.

3. Sequence File Input Format: This input format is used to read data from a sequence file. A sequence file stores data in binary format.

4. NLineInputFormat: This input format is used to read data from multiple lines of a file.

5. DBInputFormat: This input format is used to read data from a database.

6. XMLInputFormat: This input format is used to read data from an XML file.

7. MultiFileInputFormat: This input format is used to read data from multiple files.
