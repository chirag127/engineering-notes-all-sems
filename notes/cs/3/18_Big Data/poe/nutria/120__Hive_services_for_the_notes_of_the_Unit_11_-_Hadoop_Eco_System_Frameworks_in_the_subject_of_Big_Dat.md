
### Hive Services for Unit 11 - Hadoop Eco System Frameworks

* Hive is an open source data warehouse system for querying and analyzing large datasets stored in Hadoop's HDFS.
* Hive provides a SQL-like language called HiveQL for querying data.
* Hive also provides a mechanism to project structure onto this data and query the data using a more familiar SQL interface.
* Hive provides a way to query data stored in HDFS using SQL-like syntax.
* Hive supports data summarization, ad-hoc queries, and analysis of large datasets stored in Hadoop compatible file systems.
* Hive supports the extensibility of user-defined functions (UDFs) to manipulate data in custom ways.
* Hive can be used to perform data mining operations on large datasets.
* Hive is often used in conjunction with Hadoop MapReduce to process and analyze large datasets.
