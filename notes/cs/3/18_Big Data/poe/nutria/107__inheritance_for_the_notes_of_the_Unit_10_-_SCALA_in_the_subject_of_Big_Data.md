
### Inheritance in Scala

- Inheritance is a mechanism in which one class acquires the properties and behavior of another class. 
- In Scala, the class which inherits the properties of another class is known as a subclass, and the class whose properties are inherited is known as a superclass. 
- Scala supports both single and multiple inheritance. 
- In single inheritance, a subclass can inherit the properties of only one superclass. 
- In multiple inheritance, a subclass can inherit the properties of multiple superclasses. 
- Scala also supports hierarchical inheritance, in which one class can inherit the properties of multiple superclasses. 
- Scala supports abstract classes, which are classes that cannot be instantiated, but can be inherited by subclasses. 
- Scala also supports trait classes, which are classes that can be used to extend the functionality of a class without the need to inherit from the class. 
- Traits can also be used to provide additional functionality to an existing class.
