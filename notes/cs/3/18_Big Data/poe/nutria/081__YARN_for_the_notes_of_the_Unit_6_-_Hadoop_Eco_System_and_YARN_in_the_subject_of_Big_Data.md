
### YARN for the Notes of Unit 6 - Hadoop Eco System and YARN in the Subject of Big Data

1. YARN stands for Yet Another Resource Negotiator. It is a cluster management technology developed by the Apache Software Foundation for use in distributed computing applications.

2. YARN is a part of the Hadoop Eco System and is used to manage and allocate resources across multiple applications running on a cluster of computers.

3. YARN is responsible for scheduling jobs, managing resources, and providing fault tolerance. It also provides an API for applications to interact with the cluster.

4. YARN is designed to be scalable and fault tolerant. It can handle thousands of nodes and jobs at the same time.

5. YARN consists of two main components: the Resource Manager and the Node Manager. The Resource Manager is responsible for allocating resources to applications, while the Node Manager is responsible for managing the resources on each node.

6. YARN also provides security features such as authentication, authorization, and encryption. It also provides support for multiple programming languages such as Java, Python, and C++.
