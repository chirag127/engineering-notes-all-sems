
### Map Reduce Types

1. **MapReduce** is a programming model for processing large datasets in a distributed manner. It is based on the concept of dividing a large problem into smaller sub-problems, which can then be solved in parallel.

2. **MapReduce** consists of two phases: the **Map** phase and the **Reduce** phase. In the **Map** phase, the input data is divided into smaller chunks and each chunk is processed independently. The output of the **Map** phase is then passed to the **Reduce** phase, where the results of the **Map** phase are combined to produce the final result.

3. **MapReduce** is commonly used for processing large datasets in a distributed manner. It is well-suited for tasks such as data mining, web indexing, machine learning, and natural language processing.

4. The **Map** phase of a **MapReduce** job consists of a set of mappers that process the input data in parallel. Each mapper receives a portion of the input data and produces a set of intermediate key-value pairs.

5. The **Reduce** phase of a **MapReduce** job consists of a set of reducers that combine the intermediate key-value pairs to produce the final result. The reducers receive the intermediate key-value pairs from the mappers and combine them to produce the final result.
