
### How Map Reduce Works for the Notes of Unit 3 - Map Reduce in the Subject of Big Data

1. MapReduce is a programming model used to process large data sets in a distributed computing environment.
2. It is a two-step process that first maps data into key-value pairs, and then reduces the mapped data into a smaller set of data.
3. The map step takes a set of data and converts it into another set of data, where individual elements are broken down into tuples (key/value pairs).
4. The reduce step takes the output from the map step and combines the data tuples into a smaller set of tuples.
5. MapReduce is used in many applications, such as web indexing, data mining, log file analysis, machine learning, and financial modeling.
6. It is also used to analyze large amounts of data in a distributed computing environment, such as a cluster of distributed computers.
7. MapReduce was developed by Google in 2004 and is now used by many companies and organizations.
8. It is a powerful tool for data analysis and has been adopted by many industries.
