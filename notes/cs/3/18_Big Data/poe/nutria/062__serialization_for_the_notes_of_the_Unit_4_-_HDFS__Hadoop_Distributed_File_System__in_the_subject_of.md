
### Serialization for the Notes of the Unit 4 - HDFS (Hadoop Distributed File System) in the Subject of Big Data

1. Serialization is the process of converting an object into bytes that can be stored or transmitted over a network. 
2. Hadoop Distributed File System (HDFS) is a distributed, scalable, and portable file system written in Java for the Hadoop framework. 
3. HDFS is designed to store large files across multiple nodes in a Hadoop cluster. 
4. Serialization is used in HDFS to store and retrieve data from the file system. 
5. When a file is stored in HDFS, it is split into chunks and each chunk is stored as a separate block on the DataNodes. 
6. DataNodes communicate with the NameNode to store, retrieve, and replicate the blocks. 
7. Serialization is used to convert the objects into bytes before storing them in the HDFS. 
8. Serialization is also used to convert the bytes back into objects when retrieving them from the HDFS. 
9. Serialization is also used to transfer data between the different components of the Hadoop framework such as the MapReduce framework. 
10. Serialization is an important part of the HDFS and is used to store and retrieve data efficiently.
