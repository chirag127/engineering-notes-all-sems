
### Classes and Objects in Scala

* Scala is an object-oriented programming language. It supports classes and objects, which are the two main concepts of object-oriented programming. 
* Classes are templates for objects. They define the state and behavior that the objects of the class all share. 
* Objects are instances of classes. They contain their own state and behavior. 
* Classes and objects can contain fields and methods. Fields store data associated with the object, while methods define the behavior of the object. 
* Classes can also contain constructors, which are special methods that are used to create new objects. 
* Classes can be extended, which means that they can inherit the fields and methods of another class. 
* Classes can also be used as types, which means that they can be used to define the type of a variable or parameter. 
* Objects can also be used as types, which means that they can be used to define the type of a variable or parameter. 
* Scala supports both single inheritance and multiple inheritance. 
* Scala also supports traits, which allow classes to share behavior without having to extend another class.
