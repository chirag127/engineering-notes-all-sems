
### Grunt for the Notes of the Unit 11 - Hadoop Eco System Frameworks in the Subject of Big Data

1. Grunt is a scripting language used to interact with Hadoop. It is based on JavaScript and is used to write scripts that can be executed on the Hadoop Distributed File System (HDFS).
2. Grunt is used to perform tasks such as data analysis, data transformation and data movement.
3. Grunt is used to run MapReduce jobs, Pig Latin scripts and Hive queries.
4. Grunt is also used to access data stored in HDFS and other distributed storage systems.
5. Grunt can be used to create and manage Hadoop clusters, and to deploy and manage applications on the Hadoop cluster.
6. Grunt is a powerful tool for managing and manipulating data stored in HDFS and other distributed storage systems.
7. Grunt is an open source project and is available under the Apache License.
