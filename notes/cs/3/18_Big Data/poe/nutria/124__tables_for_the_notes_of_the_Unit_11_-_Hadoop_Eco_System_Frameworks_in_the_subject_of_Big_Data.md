
### Unit 11 - Hadoop Eco System Frameworks

1. Apache Hadoop: Apache Hadoop is an open-source software framework that allows for distributed storage and processing of large datasets across clusters of computers. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

2. Apache Hive: Apache Hive is a data warehouse software project built on top of Apache Hadoop for providing data summarization, query, and analysis. Hive queries are written in a SQL-like language called HiveQL.

3. Apache Pig: Apache Pig is a high-level platform for creating programs that run on Apache Hadoop. The language for this platform is called Pig Latin. It is designed to handle data flows in a more efficient manner than MapReduce.

4. Apache Spark: Apache Spark is an open-source distributed general-purpose cluster-computing framework. It provides an interface for programming entire clusters with implicit data parallelism and fault tolerance.

5. Apache Flink: Apache Flink is an open-source stream processing framework for distributed, high-performing, always-available, and accurate data streaming applications. It is designed to run both batch and streaming jobs.

6. Apache Storm: Apache Storm is a distributed, real-time computation system. It is designed to process unbounded streams of data. It is also capable of doing batch processing.
