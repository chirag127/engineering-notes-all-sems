
### Apache Hadoop for the Notes of the Unit 2 - Hadoop in the Subject of Big Data

1. Apache Hadoop is an open-source software framework for distributed storage and processing of large data sets on computer clusters.
2. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
3. Hadoop is designed to handle both structured and unstructured data, allowing for the analysis of large datasets that traditional databases cannot handle.
4. Hadoop is composed of four main components: the Hadoop Distributed File System (HDFS), MapReduce, YARN, and Common.
5. HDFS is the primary storage system used by Hadoop and is responsible for storing and managing large datasets.
6. MapReduce is a programming model used to process the data stored in HDFS.
7. YARN is the resource management layer of Hadoop and is responsible for allocating resources to applications running on the cluster.
8. Common is a collection of libraries and utilities that provide support for other Hadoop components.
9. Hadoop is used in many industries for data analysis, such as finance, healthcare, and retail.
10. Hadoop is also used for research and development, as it allows for the analysis of large datasets that traditional databases cannot handle.
