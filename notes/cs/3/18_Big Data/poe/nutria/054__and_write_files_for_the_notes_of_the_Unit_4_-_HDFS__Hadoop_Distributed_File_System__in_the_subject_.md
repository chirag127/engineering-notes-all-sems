
### Unit 4 - HDFS (Hadoop Distributed File System)

1. HDFS is a distributed file system that is designed to store and manage large volumes of data across a cluster of commodity hardware.

2. HDFS is designed to provide high-throughput access to data by using a cluster of machines working together.

3. HDFS stores data in blocks of a fixed size and replicates each block across multiple nodes in the cluster for reliability.

4. HDFS is optimized for streaming reads of large files rather than random access to small files.

5. HDFS provides fault tolerance through replication and is designed to be highly available.

6. HDFS is designed to be used with MapReduce for distributed computation.
