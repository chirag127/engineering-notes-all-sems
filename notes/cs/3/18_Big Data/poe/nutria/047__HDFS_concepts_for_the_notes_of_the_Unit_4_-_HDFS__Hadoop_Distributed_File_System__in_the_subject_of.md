
### HDFS Concepts

1. HDFS (Hadoop Distributed File System) is a distributed and fault-tolerant file system used to store large amounts of data on commodity hardware.
2. HDFS is designed to run on a cluster of computers, with each node in the cluster storing a portion of the data.
3. HDFS is designed to be highly available and fault-tolerant, meaning that if a node in the cluster fails, the data stored on that node can be recovered from other nodes in the cluster.
4. HDFS is optimized for streaming data access, meaning that it is designed to efficiently read and write large files in a single operation.
5. HDFS uses a master-slave architecture, where the master node (or NameNode) is responsible for managing the file system, and the slave nodes (or DataNodes) are responsible for storing the data.
6. HDFS is designed to store large files, and it is not suitable for applications that require low latency access to small files.
7. HDFS is designed to be highly scalable, meaning that it can easily expand to accommodate a large number of nodes and large amounts of data.
8. HDFS is designed to be secure, with security features such as authentication, authorization, and encryption.
