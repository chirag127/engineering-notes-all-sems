
### Fair and Capacity for the Notes of the Unit 6 - Hadoop Eco System and YARN in the Subject of Big Data

1. Hadoop is an open-source software framework for distributed storage and processing of large data sets on clusters of computers. 
2. Hadoop Eco System consists of various components such as HDFS, MapReduce, YARN, Pig, Hive, HBase, and Zookeeper, which are used for different purposes. 
3. YARN (Yet Another Resource Negotiator) is a resource-management platform responsible for managing computing resources in clusters and using them for scheduling of users' applications. 
4. YARN provides a central platform to manage distributed computing resources, enabling users to efficiently allocate resources to applications. 
5. YARN is responsible for allocating resources to applications, scheduling tasks, and monitoring the progress of applications. 
6. YARN provides a framework for scheduling jobs and executing tasks on a cluster of nodes. 
7. YARN also provides a mechanism for assigning priorities to jobs and tasks based on user-defined criteria. 
8. YARN enables applications to run in a distributed fashion, allowing them to scale up or down as needed. 
9. YARN also provides a mechanism for fault-tolerance, allowing applications to recover from failures. 
10. YARN is a key component of the Hadoop Eco System, which enables the efficient use of distributed computing resources for Big Data processing.
