### Administering Hadoop

1. Setting up Hadoop - Download and install Java, Hadoop, and configure required environment variables.
2. HDFS - Format the NameNode and manage the DataNodes. Start and stop HDFS and view cluster status.
3. YARN - Start and stop YARN and view the resource manager and node manager status.
4. MapReduce - Submit and monitor MapReduce jobs.
5. Security - Configure authentication (Kerberos), authorization, and manage service-level authorization.
6. Monitoring - Monitor cluster resources, utilization, and performance. Log aggregation and monitoring.
7. Troubleshooting - Analyze logs and take corrective actions for identified issues.
8. Upgrading - Perform rolling upgrades for major version upgrades and minor patch updates.
9. Scaling - Add and remove nodes from a cluster and increase or decrease capacity.
10. Backup and Disaster Recovery - Configure backups and design disaster recovery plans.
