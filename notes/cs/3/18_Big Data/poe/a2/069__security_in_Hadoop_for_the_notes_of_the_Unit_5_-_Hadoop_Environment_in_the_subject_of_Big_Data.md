### Security in Hadoop

1. Authentication
- Kerberos authentication to validate users
- Hadoop Authentication (simple authentication utility)

2. Authorization
- Access Control Lists (ACLs) to control access to files
- Apache Sentry provides role-based authorization to control access to data and metadata

3. Data security
- Data encrypted with encryption keys when writing to HDFS
- Apache Knox gateway provides perimeter security and access control

4. Configuration security
- Sensitive configurations should be secured and not exposed
- Manage secrets using credential providers

5. Network security
- Data transfer over secure channels using SSL/TLS
- Only authorized nodes can access the cluster
