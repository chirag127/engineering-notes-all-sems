## Unit 3 - Map Reduce

1. Map Reduce is a programming model for processing and generating large data sets.

2. It consists of two major tasks:

- Mapping: It is the first phase where the input data is divided into smaller chunks which are processed in parallel. The input data is converted into key-value pairs.

- Reducing: It is the second phase where the output of the mapping phase is combined to get the final output. The key-value pairs with the same key from the mapping phase are combined.

3. The key benefits of Map Reduce are:

- Scalability: It can process huge amounts of data by distributing the work across multiple nodes in a cluster.

- Fault Tolerance: It is fault tolerant as the work is divided into multiple tasks and if one fails, it can be re-executed on another node.

- Low Cost: It utilizes the power of commodity hardware and is cost effective.

4. The applications of Map Reduce include:

- Web indexing
- Log file analysis
- Data mining
- Machine learning

5. The major implementations of Map Reduce are Hadoop Map Reduce by Apache and Map Reduce in Cloud by AWS and Google Cloud.
