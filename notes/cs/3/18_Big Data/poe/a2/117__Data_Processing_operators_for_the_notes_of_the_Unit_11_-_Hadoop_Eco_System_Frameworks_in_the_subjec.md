### Data Processing operators for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data.

1. MapReduce: MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
- Map: Divides the input into smaller sub-problems and assigns them to worker nodes.
- Reduce: Combines the answers to the sub-problems and returns the final output.
2. Pig: Pig is a high-level language platform for analyzing large data sets that consists of a language, Pig Latin, and an execution environment. Pig Latin includes operators similar to SQL.
3. Hive: Hive is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis. It converts SQL-like queries into MapReduce jobs.
4. Jaql: Jaql is a declarative query language for JSON data inspired by SQL and XQuery. It can transform JSON data into new JSON output.
5. Cascading: Cascading is an application development platform for data processing on a Hadoop cluster. It provides an Java API and a processing language, Pipes, to define data processing workflows.
