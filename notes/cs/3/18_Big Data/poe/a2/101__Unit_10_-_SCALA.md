## Unit 10 - SCALA

1. Scala is a statically typed programming language that runs on the Java Virtual Machine (JVM) and also can be compiled to JavaScript source code.
2. It has a strong static type system. Variables and methods have types, and the compiler will check type correctness of all operations.
3. Scala source code is intended to be compiled to Java bytecode, so that the resulting executable code runs on a Java virtual machine.
4. Scala's syntax is a mix of object-oriented and functional programming concepts. It has traits as typesafe alternatives to inheritance hierarchies, case classes for pattern-matching, and more generally supports functional constructs.
5. The Scala library includes advanced features like parallel collections, actors, scala macros, complex number class, etc. to provide more out of the box functionality.
6. Scala compiles to JVM bytecode and can access Java frameworks easily. This makes Scala a capable alternative for Java with more developer productivity and conciseness without compromising performance.
7. The main application areas of Scala include web programming with Scala/Lift and Play Framework, financial modelling, data science, scientific computing and scalable distributed systems.
