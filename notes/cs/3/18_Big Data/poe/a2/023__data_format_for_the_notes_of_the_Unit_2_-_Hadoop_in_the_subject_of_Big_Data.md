### Data Formats for Hadoop Unit 2 Notes

1. Text input format:
- Generic format, rows separated by newlines
- Data is in text files
- Needs custom input format for parsing
- Example: CSV, TSV files

2. Sequence file input format:
- Binary data format with header
- Supports complex types like maps and arrays
- Compression can be applied
- Faster than text input format
- Typically used for MapReduce programs in Hadoop

3. RCFile (Record Columnar file) format:
- Stores data in a columnar fashion
- Similar to Parquet and ORC
- Supports complex data types
- Uses less disk space and is faster for queries
- Requires schema to interpret data

4. Avro input format:
- Uses JSON-based schema to interpret data
- Supports complex types
- Data is stored in binary encoded format
- Schemas allow for data processing across languages and systems
- Self-describing and platform independent format
