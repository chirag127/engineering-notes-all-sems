### Map Reduce framework and basics

1. Map Reduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
2. It consists of two major tasks - Map and Reduce.
3. The Map task divides the input into smaller sub-problems which are processed in parallel. It filters and sorts the data.
4. The Reduce task merges the outputs of the maps and combines them to produce the final output. It summarizes the data.
5. The framework takes care of scheduling the tasks, monitoring them and re-executes the failed tasks.
6. The key benefits of Map Reduce are:
- Scalability: It can handle huge amounts of data on a large cluster of machines.
- Fault Tolerance: It can handle machine failures and re-execute failed tasks.
- Low Cost: It can use inexpensive commodity hardware as it is a distributed system.
- Processing Speed: Tasks are processed in parallel, so it is faster than processing on a single machine.
