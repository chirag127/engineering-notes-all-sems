### Resilient Distributed Databases
- A distributed database spreads its data across multiple nodes/servers. This allows for scalability, fault tolerance and high availability.
- A resilient distributed database is able to withstand failures of some of its nodes/servers and continue to function. It does this through data replication across the nodes.
- Popular resilient distributed databases include:
-- Hadoop Distributed File System (HDFS) - The primary storage system used with Hadoop. It splits files into large blocks and replicates them across the cluster.
-- Cassandra - A wide column store database designed for scalability and high availability. Data is distributed among nodes and replicated for fault tolerance.
-- MongoDB - A document-oriented database which stores data in JSON-like documents. The data is replicated across shards (partitions) for scalability and fault tolerance.
-- Splice Machine - A distributed SQL database built on Hadoop and HBase. It offers resilience, scalability and ACID transactions.

The key points to note about resilient distributed databases are:
- They spread data across multiple servers/nodes.
- Data is replicated across the servers/nodes to provide fault tolerance.
- The databases are designed to continue functioning even with the failure of some servers/nodes.
- Scalability is achieved through partitioning/sharding the data across the servers/nodes.
- Examples include HDFS, Cassandra, MongoDB and Splice Machine.
