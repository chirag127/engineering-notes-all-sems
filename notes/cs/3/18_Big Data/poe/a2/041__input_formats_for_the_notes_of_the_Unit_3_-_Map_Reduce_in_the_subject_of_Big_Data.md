### Input formats for the notes of the Unit 3 - Map Reduce in the subject of Big Data:

1. Text Input Format: Used for plain text files. Key is the offset of the line and value is the line of text.
2. KeyValueInputFormat: Used for input data in the form of <key,value> pairs. Key and value can be of any type.
3. SequenceFileInputFormat: Used for input data in SequenceFile format. SequenceFiles contain key-value pairs that are serialized.
4. DBInputFormat: Used to read data from databases. It uses a SQL query to read data from a table and returns key-value pairs.
5. TableInputFormat: Used for reading data from HBase tables. Returns key-value pairs where key is HBase row key and value is the row.

The input formats describe the different structured and unstructured ways of ingesting data as input to the MapReduce framework. The appropriate input format is chosen based on the format and source of the input data. The input format parses the input into key-value pairs that are then processed by the map functions.
