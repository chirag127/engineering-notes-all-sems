### Comparison with traditional databases for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data:

1. Traditional databases are relational databases which follow ACID properties. Hadoop Eco System frameworks are distributed and follow CAP theorem.
2. Traditional databases store data in tables with rows and columns. Hadoop uses HDFS which splits files into blocks and distributes across nodes.
3. Traditional databases use SQL for queries. Hadoop Eco System frameworks use MapReduce programming model for processing data in a distributed fashion.
4. Traditional databases are vertically scalable. Hadoop is horizontally scalable as more nodes can be added easily.
5. Data in traditional databases needs to be structured. Hadoop can handle structured, semi-structured and unstructured data.

The above points summarize some key differences between traditional databases and Hadoop Eco System frameworks for Big Data processing. Hadoop is more suitable for handling large volumes of data that may not be structured. However, for complex transactions and operations, traditional databases are more efficient due to ACID properties. The choice between the two depends on the use case.
