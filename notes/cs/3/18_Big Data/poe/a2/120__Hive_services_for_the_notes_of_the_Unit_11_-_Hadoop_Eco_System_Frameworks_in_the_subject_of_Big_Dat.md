### Hive services for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data.

1. Hive is a data warehouse infrastructure built on top of Hadoop for providing data summarization, query, and analysis.
2. Hive provides a SQL-like interface called HiveQL to query data stored in various databases and file formats integrates with Hadoop.
3. Hive translates the queries into MapReduce jobs which are executed on Hadoop.
4. Hive has three main components:

- Metastore: Stores metadata or schema information about the data (table names, column names, data types, partition keys).
- Compiler: Converts HiveQL queries into logical, physical, and MapReduce execution plans.
- Driver: Provides a JDBC/ODBC server to accept HiveQL queries from clients.

5. Benefits of using Hive:

- Easy to learn for users familiar with SQL.
- Hides the complexities of MapReduce and HDFS.
- Schema can be easily evolved as the datasets grow.
- Integrates with Hadoop security and authentication.
- Supports partitions for organizing tables.
- Used for data summarization, querying, and analysis of large datasets on Hadoop.
