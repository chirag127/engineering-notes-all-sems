## Unit 8 - MongoDB

1. MongoDB is a document-oriented NoSQL database.
2. Data in MongoDB is stored in documents (instead of rows & columns in a table). A document is a data structure composed of field and value pairs.
3. MongoDB collections contain sets of documents. A collection is the equivalent of an RDBMS table.
4. MongoDB supports dynamic schemas. Documents in a MongoDB collection can have different fields.
5. MongoDB provides high performance, high availability, and automatic scaling.
6. MongoDB replica sets provide redundancy and high availability. Data is replicated across multiple servers.
7. MongoDB shards provide horizontal scaling by splitting data across multiple machines.
8. MongoDB supports ad-hoc queries, indexing, and real time aggregation.
9. MongoDB's native drivers provide connectivity from a wide variety of programming languages.
10. MongoDB Atlas is a fully managed cloud database service for MongoDB. It handles operational tasks like provisioning servers, setup, configuration, monitoring, backups, etc.
