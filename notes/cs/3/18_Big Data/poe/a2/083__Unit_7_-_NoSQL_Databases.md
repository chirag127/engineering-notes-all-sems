## Unit 7 - NoSQL Databases

1. NoSQL databases are non-relational databases that do not require a fixed schema. They have a dynamic schema for unstructured data.
2. The core components of NoSQL databases are:
- Documents - Data is stored in documents (instead of rows & columns in a table)
- Key-value pairs - Data is stored in an array of key-value pairs
- Graphs - Data is stored in graphs with nodes, edges and properties
- Wide-column stores - Data is stored in columns instead of rows
3. Some popular NoSQL databases are:
- MongoDB - Document database, stores data in JSON-like documents
- CouchDB - Document database with HTTP interface
- DynamoDB - Key-value and document database from AWS
- Cassandra - Wide-column store database, decentralised and distributed
- Neo4j - Graph database, stores data in nodes, relationships and properties
4. Advantages of NoSQL databases:
- Scalable and distributed
- Schema less
- Open source
- Performance with large volumes of data
- Cost effective

Disadvantages:
- Limited query capabilities (no JOINS)
- Eventual consistency
- Learning curve
