### Basic Types and Operators

1. Integers - Scala has integer types: Byte, Short, Int, Long. Default type is Int.
2. Floating Points - Scala has two floating point types: Float and Double. Default type is Double.
3. Booleans - Scala has a Boolean type with two values: true and false.
4. Characters - Scala has a Char type to represent a single character. Characters are surrounded by single quotes.
5. Strings - Scala has a String type to represent text. Strings are sequences of Characters surrounded by double quotes.
6. Literals - Literal is a notation to representing a fixed value in source code. Scala supports literals for all types like 42 (Int), 3.14 (Double), 'x' (Char), "Hello" (String).
7. Type Inference - Scala can infer the type of a value from its value. We do not have to explicitly define types for variables if they can be inferred. For example, val x = 42 infers Int type for x.
8. Operator Overloading - Scala allows operator overloading which means operators can be used on user-defined types. However, this should be used judiciously as it can make the code hard to read.
