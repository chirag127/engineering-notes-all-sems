### Task execution for the notes of the Unit 3 - Map Reduce in the subject of Big Data

1. Map Reduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.
2. The computation takes a set of input key/value pairs, and produces a set of output key/value pairs.
3. The compute job is divided into Map tasks and Reduce tasks.
4. The input is split into M splits which are processed by M map tasks in parallel.
5. The output of the map tasks are sorted and shuffled to be sent to R reduce tasks.
6. The reduce tasks process the map output and produce the final output.
7. Fault tolerance is achieved by speculative execution and re-executing failed tasks on other nodes.
8. Hadoop's MapReduce implementation scales to thousands of nodes and petabytes of data.
9. The key characteristics of MapReduce are scalability, fault tolerance, low cost, and decentralized processing.
