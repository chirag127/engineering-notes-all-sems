### Hadoop Echo System for the notes of the Unit 2 - Hadoop in the subject of Big Data

1. Hadoop Common: The common utilities that support the other Hadoop modules. It includes Java libraries and scripts needed by other modules.
2. Hadoop Distributed File System (HDFS): A distributed file system that provides high-throughput access to application data.
3. Hadoop YARN: A framework for job scheduling and cluster resource management.
4. Hadoop MapReduce: A YARN-based system for parallel processing of large data sets.

The key components of Hadoop are:

- HDFS: Storage layer to store huge data
- YARN: Resource management layer to manage and allocate resources
- MapReduce: Processing layer to process stored data

The benefits of Hadoop are:

- Distributed storage and processing of large data sets
- Fault tolerance via data replication and tasktracker rescheduling
- Scalability - can be scaled up from single server to thousands of machines
- Cost effectiveness - uses commodity hardware and open source software
- Flexibility - new modules and functions can be easily added
