### Grunt for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

1. Grunt is a task runner tool for automating tasks like minification, compilation, unit testing, etc. It uses a json configuration file (Gruntfile.js) to define and configure the tasks.
2. Some of the benefits of using Grunt are:
- Saves time by reducing repetition of manual tasks.
- Provides a wide plugin ecosystem to add functionality to Grunt.
- Has a simple and easy to learn configuration syntax.
3. Some common tasks that can be performed using Grunt are:
- Compile Sass/Less files to CSS.
- Linting (checks for errors) on JavaScript/CSS code.
- Image optimization.
- File concatenation and minification.
- Running tests.
4. To use Grunt, you first need to install it globally using npm install -g grunt-cli. Then locally install Grunt and the plugins you want to use in your project. Finally, configure the tasks in Gruntfile.js and run grunt to execute the tasks.
