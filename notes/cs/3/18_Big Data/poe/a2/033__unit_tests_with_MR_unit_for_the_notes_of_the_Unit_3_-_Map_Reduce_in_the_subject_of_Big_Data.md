### Unit tests with MR unit for the notes of the Unit 3 - Map Reduce

1. MR unit is a testing framework for testing MapReduce programs. It launches a single JVM to simulate the MapReduce system and executes the map and reduce logic.
2. This speeds up the testing process as compared to launching a complete MapReduce cluster for every test.
3. The framework provides methods to input data, run the map and reduce logic, and output the results.
4. The input, output and the execution can be controlled to thoroughly test all the scenarios and check for correctness of the logic.
5. This enables the developers to adapt Test Driven Development for MapReduce programs. Comprehensive tests can be written before implementing the actual logic.
6. Some of the features of MR unit are:
 - Simulate multiple input splits
 - Specify outputs and verify the actual output
 - Control the execution flow
 - Test intermediate data via collectors
 - Imitate faults by simulating task failures
7. MR unit makes MapReduce testing efficient, comprehensive and accurate, leading to higher quality and robust MapReduce programs.
