### Jobs for the notes of the Unit 9 - Spark in the subject of Big Data

1. Spark Driver: The driver program that contains the main function. It coordinates the execution of an application by responding to the cluster manager and dispatching tasks to executors.
2. Spark Executor: A process launched for an app on a worker node to run tasks and keep data in memory or disk storage across tasks.
3. Cluster Manager: The service that allocates resources across applications. It monitors application status and allows for adding or removing nodes. Common implementations are Standalone, Mesos, YARN.
4. Job: A parallel computation consisting of multiple tasks that gets spawned in response to an action on an RDD or DataFrame.
5. Task: A unit of work done as part of a Spark job.

The key points to remember are:
1) The driver program contains the main function and coordinates the application.
2) Executors are launched to run tasks and cache data.
3) A cluster manager allocates resources and monitors applications.
4) A job consists of tasks spanning a DataFrame or RDD action.
5) Tasks are the units of work in a Spark job.
