### Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

1. MongoDB is a document-oriented NoSQL database used for high volume data storage.
2. instead of using tables and rows as in SQL, MongoDB uses documents and collections.
3. A document is a data record in a collection and is analogous to a row in a table.
4. A collection is a grouping of MongoDB documents and is analogous to a table in a relational database.
5. MongoDB documents are stored in a binary JSON format called BSON.
6. MongoDB supports dynamic schemas. Documents in a collection can have different fields.
7. MongoDB scales horizontally using sharding. Data is distributed across multiple machines.
8. Replication provides redundancy and high availability.
9. MongoDB supports rich queries, indexing, and aggregation.
10. Use cases include content management systems, real-time analytics, mobile applications, etc.
