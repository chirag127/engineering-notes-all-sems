### Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

1. Pig is a high-level scripting language that is used with Apache Hadoop.
2. Pig translates the Pig Latin scripts into MapReduce jobs which are executed on a Hadoop cluster.
3. Pig has a simple and easy to learn syntax (called Pig Latin) and it handles complex data processing tasks with less coding.
4. Pig Latin abstracts away the complexity of MapReduce and allows the user to focus on the logic of the processing task rather than on system infrastructure and implementation details.
5. Pig excels at very large data processing tasks where high-level scripts can be translated into sequences of Map and Reduce jobs and automatically optimized.
6. Pig's scripting language Pig Latin can do a lot more than just SQL-like queries, you can do transformations, joins, filters, grouping, etc. very easily in a short amount of time.
7. Some key benefits of Pig are:

- Expressive power: Pig Latin provides various operators to transform and process data in a very easy way.
-Extensibility: User can create their own functions to extend the capabilities of Pig.
-Optimization: The Pig execution engine automatically optimizes the data flow and generates efficient MapReduce jobs to process data.
-Compatibility: Pig Latin scripts can be executed on major Hadoop distributions.
-Readability: Pig Latin is easier to read and learn than Java MapReduce programs.
