### Hive - Apache Hive architecture and installation for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

Apache Hive is an open-source data warehouse software that allows querying and analyzing large datasets stored in Hadoop file system. It was developed by Facebook, and later donated to the Apache Software Foundation. Hive provides SQL-like language called HiveQL to query data stored in Hadoop.

#### Architecture of Apache Hive

The architecture of Apache Hive consists of the following components:

- **Hive Clients:** Hive clients are the interface for users to interact with Hive. Users can submit queries to Hive using the command-line interface (CLI), Hive Web Interface or through JDBC/ODBC drivers.

- **Hive Services:** Hive Services are the core components of Hive that execute queries submitted by the users. The services include:

  - **Hive Driver:** Hive Driver receives queries submitted by the clients and converts them into a series of MapReduce jobs.

  - **Hive Metastore:** Hive Metastore stores the metadata of the Hive tables such as schema, partitioning, and location of data in HDFS.

  - **Hive Query Compiler:** Hive Query Compiler is responsible for compiling the HiveQL queries into a series of MapReduce jobs.

  - **Hive Execution Engine:** Hive Execution Engine executes the MapReduce jobs generated by the Query Compiler.

- **Hadoop Distributed File System (HDFS):** HDFS is the storage system used by Hive to store data.

#### Installation of Apache Hive

To install Apache Hive, follow these steps:

1. Download the latest version of Apache Hive from the official website.

2. Install Java Development Kit (JDK) if it is not installed already.

3. Extract the downloaded Hive files to a directory.

4. Set the environment variables HIVE_HOME and PATH to the Hive installation directory and its bin directory, respectively.

5. Start Hive by running the command "hive" in the terminal.

6. Verify the installation by running a sample query.

#### Conclusion

Apache Hive is a powerful tool for querying and analyzing large datasets stored in Hadoop. It provides a SQL-like interface for querying data stored in Hadoop. The architecture of Hive consists of Hive Clients, Hive Services, and Hadoop Distributed File System. To install Hive, download the latest version, extract the files, set the environment variables, and start Hive.
