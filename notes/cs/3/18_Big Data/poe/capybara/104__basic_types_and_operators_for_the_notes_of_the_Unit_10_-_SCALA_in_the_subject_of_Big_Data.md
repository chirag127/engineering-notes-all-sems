

### Basic Types and Operators

Scala is a statically typed programming language that supports both object-oriented and functional programming. It has a rich set of data types and operators that are used to perform various operations in Big Data. In this section, we will discuss the basic types and operators in Scala.

#### Basic Types

Scala provides various built-in data types, which are used to represent different kinds of values. The following are the basic data types in Scala:

- **Byte**: It is an 8-bit signed integer that ranges from -128 to 127.
- **Short**: It is a 16-bit signed integer that ranges from -32768 to 32767.
- **Int**: It is a 32-bit signed integer that ranges from -2147483648 to 2147483647.
- **Long**: It is a 64-bit signed integer that ranges from -9223372036854775808 to 9223372036854775807.
- **Float**: It is a 32-bit floating-point number that ranges from 1.401298e-45 to 3.4028235e+38.
- **Double**: It is a 64-bit floating-point number that ranges from 4.9406564584124654e-324 to 1.7976931348623157e+308.
- **Char**: It is a 16-bit Unicode character that ranges from '\u0000' to '\uffff'.
- **Boolean**: It represents a logical value that can be either true or false.

#### Operators

Scala provides a wide range of operators that are used to perform various operations on data types. The following are the commonly used operators in Scala:

- **Arithmetic Operators**: These operators perform mathematical operations on numbers. The basic arithmetic operators are + (addition), - (subtraction), * (multiplication), / (division), and % (modulus).
- **Relational Operators**: These operators are used to compare two values. The relational operators are == (equal to), != (not equal to), > (greater than), < (less than), >= (greater than or equal to), and <= (less than or equal to).
- **Logical Operators**: These operators perform logical operations on Boolean values. The logical operators are && (logical and), || (logical or), and ! (logical not).
- **Bitwise Operators**: These operators perform bitwise operations on binary numbers. The bitwise operators are & (and), | (or), ^ (exclusive or), ~ (complement), << (left shift), and >> (right shift).
- **Assignment Operators**: These operators are used to assign values to variables. The assignment operators are = (simple assignment), += (addition assignment), -= (subtraction assignment), *= (multiplication assignment), /= (division assignment), and %= (modulus assignment).

In conclusion, Scala provides a wide range of data types and operators that are used to perform various operations in Big Data. It is essential to understand these basic types and operators to work efficiently with Scala.
