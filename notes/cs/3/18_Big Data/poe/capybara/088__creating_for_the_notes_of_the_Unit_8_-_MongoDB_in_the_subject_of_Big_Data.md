### Creating Notes for Unit 8 - MongoDB in Big Data

In this unit, we will be exploring the world of MongoDB, a popular NoSQL database management system. Here are some key points to keep in mind while creating your study notes:

1. Understanding NoSQL: MongoDB is a NoSQL database, which means it does not use the traditional table-based relational database architecture. Instead, it uses collections and documents to organize data.

2. Document-Oriented: MongoDB is a document-oriented database, which means it stores data in JSON-like documents. Each document can have its own structure, which allows for more flexibility compared to traditional databases.

3. Schemaless: MongoDB is schemaless, which means you do not need to define a schema before you start adding data. This allows for more agile development and makes it easier to handle unstructured data.

4. Indexing: Like traditional databases, MongoDB also supports indexing to speed up queries. Indexes can be created on any field in a collection, and MongoDB uses a B-tree index to store data.

5. Sharding: MongoDB supports sharding, which allows you to scale horizontally by distributing data across multiple servers. This is particularly useful for large-scale applications where a single server cannot handle the load.

6. Aggregation: MongoDB provides powerful aggregation features that allow you to perform complex operations on data. Aggregation pipelines can be used to group, filter, and transform data, making it easier to extract insights from your data.

7. Drivers and APIs: MongoDB provides drivers and APIs for a variety of programming languages, making it easy to integrate with your existing application stack.

Remember to take notes on all these points and practice using MongoDB through hands-on exercises. With a good understanding of MongoDB, you will be better equipped to handle large-scale data in the real world.
