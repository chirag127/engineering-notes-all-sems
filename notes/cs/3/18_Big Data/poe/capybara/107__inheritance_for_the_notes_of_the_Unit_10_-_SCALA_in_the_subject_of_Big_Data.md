### Inheritance in SCALA

Inheritance is an important concept in object-oriented programming that allows a new class to be based on an existing class. In SCALA, inheritance can be achieved through the use of the "extends" keyword.

Here are some important points to keep in mind while studying inheritance in SCALA:

- The class that is being inherited from is called the "parent" class, while the class that inherits from it is called the "child" class.
- In SCALA, a child class can inherit from only one parent class, which is known as single inheritance.
- The child class can access all the members (variables and methods) of the parent class, except for the private members.
- SCALA also supports the concept of abstract classes, which cannot be instantiated but can be inherited from. Abstract classes can have both abstract and non-abstract (concrete) methods.
- A child class can override a method of the parent class by defining a method with the same name and signature. This is known as method overriding.
- SCALA also provides the "super" keyword to access the parent class's members from within the child class.
- Inheritance can also be used to create a hierarchy of classes, with each child class inheriting from its parent class and adding its own features and methods.

Overall, inheritance is a powerful tool in SCALA that allows for code reuse and the creation of complex class hierarchies. By understanding the concepts and syntax of inheritance, you can write efficient and flexible code in your Big Data projects.
