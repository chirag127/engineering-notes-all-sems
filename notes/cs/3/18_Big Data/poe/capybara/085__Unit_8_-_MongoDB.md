## Unit 8 - MongoDB

In this unit, we will be discussing MongoDB, a popular NoSQL database management system. Here are some important points to keep in mind:

- MongoDB is a document-oriented database, meaning that it stores data in JSON-like documents.
- The primary unit of data in MongoDB is a collection, which is a group of documents that have similar characteristics.
- MongoDB uses a flexible schema, which means that documents within the same collection can have different fields and data types.
- MongoDB supports a variety of data types, including strings, numbers, booleans, dates, arrays, and objects.
- MongoDB queries use a syntax that is similar to JSON, making them easy to read and write.
- MongoDB provides several features for scaling and replicating databases, including sharding and replica sets.
- MongoDB has built-in support for indexing, which can greatly improve the performance of queries.
- MongoDB provides a variety of tools for managing databases, including the mongo shell, MongoDB Compass, and the MongoDB Management Service (MMS).
- MongoDB can be used in a variety of applications, including web applications, mobile applications, and real-time analytics.
- MongoDB integrates well with other technologies in the modern software stack, including Node.js, Python, and cloud platforms like AWS and Azure.

Overall, MongoDB is a powerful and flexible database management system that is well-suited for a wide range of applications. By understanding its features and capabilities, developers can build robust and scalable applications that meet the needs of their users.
