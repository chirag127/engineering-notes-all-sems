

## Unit 11 - Hadoop Eco System Frameworks

In this unit, we will be discussing the Hadoop Eco System Frameworks. These frameworks are a set of tools and libraries that are built on top of the Hadoop Distributed File System (HDFS) and Hadoop MapReduce. They are used to make the Hadoop platform more efficient and easier to use.

### 1. Apache Hive
- Apache Hive is a data warehouse system that is built on top of Hadoop.
- It allows users to write SQL-like queries to analyze large datasets stored in HDFS.
- Hive supports various data formats such as CSV, JSON, and Parquet.
- It also supports partitioning of data for faster processing.
- Hive is suitable for ad hoc queries and data exploration.

### 2. Apache Pig
- Apache Pig is a high-level platform for creating MapReduce programs used with Hadoop.
- It allows users to write complex data transformation pipelines using a scripting language called Pig Latin.
- Pig Latin is a simple language that is easy to learn and understand.
- Pig supports various data formats such as CSV, JSON, and Avro.
- It is suitable for batch processing of large datasets.

### 3. Apache HBase
- Apache HBase is a distributed NoSQL database that is built on top of Hadoop.
- It provides real-time read/write access to large datasets stored in HDFS.
- HBase is suitable for applications that require low latency and high throughput.
- It supports random access to data using row keys.
- HBase is used in various applications such as social media analytics, fraud detection, and recommendation engines.

### 4. Apache Spark
- Apache Spark is a fast and general-purpose cluster computing system.
- It provides an interface for programming entire clusters with implicit data parallelism and fault tolerance.
- Spark supports various data sources such as HDFS, Cassandra, and HBase.
- It provides APIs for various programming languages such as Scala, Java, and Python.
- Spark is suitable for iterative algorithms and real-time processing.

### 5. Apache Sqoop
- Apache Sqoop is a tool used to transfer data between Hadoop and relational databases.
- It allows users to import data from databases to HDFS and export data from HDFS to databases.
- Sqoop supports various databases such as MySQL, Oracle, and SQL Server.
- It provides options for partitioning data and handling incremental updates.
- Sqoop is suitable for batch processing of large datasets.

These are some of the Hadoop Eco System Frameworks that are widely used in the industry. By using these frameworks, users can leverage the power of Hadoop and build scalable and efficient data processing systems.
