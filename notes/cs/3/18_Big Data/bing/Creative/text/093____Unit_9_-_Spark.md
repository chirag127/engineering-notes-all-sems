## Unit 9 - Spark

- Spark is an open source framework for distributed data processing that supports several big data scenarios, such as extract, transform, and load (ETL), machine learning, real-time analytics, and graph processing .
- Spark was introduced by Apache Software Foundation in 2014 to speed up the Hadoop computational process, which relies on the MapReduce paradigm that is slow for iterative and interactive applications.
- Spark is not a modified version of Hadoop and does not depend on Hadoop, because it has its own cluster management system and can run on various storage systems, such as HDFS, Amazon S3, Couchbase, Cassandra, and others .
- Spark provides a faster and more general data processing platform than Hadoop, because it performs in-memory computations and supports multiple programming languages (Scala, Python, Java, R, and SQL) and multiple APIs (RDD, DataFrame, Dataset, and SQL) for expressing data transformations .
- Spark consists of several components, such as Spark Core, Spark SQL, Spark Streaming, Spark MLlib, and GraphX, that provide different functionalities and abstractions for working with various types of data and algorithms .
- Spark can be deployed on various cluster managers, such as YARN, Mesos, Kubernetes, or standalone, and can also run locally on a single machine for testing and development purposes.
