### Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

- Pig is an open-source high-level data flow system that runs on top of Hadoop.
- Pig provides a simple scripting language called Pig Latin, which allows users to write data analysis programs that are compiled into MapReduce jobs .
- Pig Latin provides various operators for data manipulation, such as loading, filtering, grouping, joining, sorting, and aggregating .
- Pig also allows users to define their own functions using Java, Python, or other languages, and use them in Pig Latin scripts .
- Pig is generally used for data administration tasks, such as data cleansing, data preparation, data integration, and data summarization .
- Pig can handle structured, semi-structured, and unstructured data, and can process data from various sources, such as HDFS, local file system, or web services .
- Pig can also interact with other Hadoop components, such as Hive, HBase, and ZooKeeper .
- Pig is suitable for complex and ad-hoc data analysis, as it provides a high-level of abstraction and flexibility for users .
- Pig is not suitable for real-time or interactive data analysis, as it relies on batch processing and MapReduce framework.
- Pig is also not suitable for data transformation tasks that require complex logic or control flow, as Pig Latin is a declarative language that does not support loops or conditional statements.
