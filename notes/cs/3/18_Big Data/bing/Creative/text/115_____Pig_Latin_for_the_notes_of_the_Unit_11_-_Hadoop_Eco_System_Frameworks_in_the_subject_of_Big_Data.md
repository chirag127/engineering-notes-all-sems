### Pig Latin

- Pig Latin is a high-level scripting language that is used to write programs for Apache Pig, a platform for large-scale data analysis.
- Pig Latin abstracts the details of MapReduce programming and provides a simple way to express data transformations, such as filtering, grouping, joining, and aggregating.
- Pig Latin programs are compiled into MapReduce jobs and executed on a Hadoop cluster.
- Pig Latin has a rich set of built-in functions and operators, as well as the ability to define custom functions using Java, Python, or other languages.
- Pig Latin supports both structured and unstructured data, and can process data from various sources, such as HDFS, HBase, Hive, or local files.
- Pig Latin has a declarative syntax that resembles SQL, but also allows for nested and complex data types, such as bags, tuples, and maps.
- Pig Latin follows a dataflow paradigm, where each statement defines a relation (a named collection of tuples) and applies a transformation to it.
- Pig Latin statements can be chained together to form a directed acyclic graph (DAG) of relations, where the output of one statement becomes the input of another.
- Pig Latin supports both batch and interactive modes of execution, where the former runs the entire program as a single job, and the latter allows the user to execute statements one by one and inspect the results.
- Pig Latin can be extended with user-defined functions (UDFs), user-defined aggregates (UDAs), user-defined loads (UDLs), and user-defined stores (UDSs), which enable custom logic and data formats.
