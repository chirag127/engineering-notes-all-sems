### Security in Hadoop

- Security in Hadoop refers to the process of protecting the data and services in a Hadoop cluster from unauthorized access, modification, or disclosure.
- Security in Hadoop consists of four main aspects: authentication, authorization, auditing, and encryption   .
- Authentication is the process of verifying the identity of a user or a service before allowing access to the Hadoop cluster. Authentication can be done using Kerberos, a network protocol that uses tickets to establish secure communication between the client and the server   .
- Authorization is the process of granting or denying access to specific resources or operations in the Hadoop cluster based on the authenticated identity of the user or the service. Authorization can be done using HDFS file permissions, which control the read, write, and execute permissions for files and directories in the Hadoop Distributed File System (HDFS)   , or using Service Level Authorization, which controls the access to the Hadoop services such as MapReduce, YARN, Hive, HBase, etc. .
- Auditing is the process of recording and monitoring the activities and events that occur in the Hadoop cluster, such as who accessed what data, when, and how. Auditing can be done using audit logs, which store the information about the authentication and authorization events in the Hadoop cluster  .
- Encryption is the process of transforming the data in the Hadoop cluster into an unreadable form using a secret key, so that only authorized parties can decrypt and access the data. Encryption can be done using network encryption, which encrypts the data in transit between the client and the server using SSL/TLS protocols   , or using data encryption, which encrypts the data at rest in the HDFS using encryption zones and encryption keys  .
