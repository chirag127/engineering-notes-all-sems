## Unit 8 - MongoDB

MongoDB is an open-source document database and leading NoSQL database. MongoDB is written in C++. In this unit, you will learn the basics of MongoDB and how to use it for creating and deploying a highly scalable and performance-oriented database.

Some of the topics that you will learn in this unit are:

- What is MongoDB and why use it?
- How to install MongoDB and connect to it using different tools and drivers.
- How to create, read, update, and delete documents in MongoDB collections.
- How to use MongoDB operators, expressions, and indexes for querying and manipulating data.
- How to use MongoDB aggregation framework for performing complex data analysis and transformations.
- How to use MongoDB replication and sharding for ensuring high availability and scalability of your database.
- How to use MongoDB security features for enforcing authentication and authorization of your database users and roles.
- How to use MongoDB Atlas, the cloud offering by MongoDB, for creating and managing your database instances in the cloud.

By the end of this unit, you will be able to:

- Understand the key features and benefits of MongoDB as a NoSQL database.
- Perform basic CRUD operations on MongoDB documents and collections.
- Use MongoDB query language and tools for accessing and manipulating data.
- Apply MongoDB aggregation framework for data analysis and reporting.
- Implement MongoDB replication and sharding for high availability and scalability.
- Secure your MongoDB database with authentication and authorization mechanisms.
- Use MongoDB Atlas for cloud-based database management and deployment.
