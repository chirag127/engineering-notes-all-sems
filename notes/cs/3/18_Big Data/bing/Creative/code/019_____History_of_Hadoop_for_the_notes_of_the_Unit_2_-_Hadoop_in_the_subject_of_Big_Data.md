### History of Hadoop

- Hadoop is an open-source software framework for storing and processing big data in a distributed manner on large clusters of commodity hardware.
- Hadoop was started by Doug Cutting and Mike Cafarella in 2002, when they began working on the Apache Nutch project, which aimed to build a search engine system that could index 1 billion pages .
- The inspiration for Hadoop came from two papers published by Google in 2003 and 2004, describing the Google File System (GFS) and the MapReduce programming model, respectively .
- Cutting, who was working at Yahoo at the time, realized that the existing distributed computing solutions were inadequate for the scale and complexity of web data, and decided to implement the ideas from Google's papers in Nutch.
- In 2006, Cutting and Cafarella moved the distributed computing components of Nutch to a separate sub-project, which they named Hadoop after Cutting's son's toy elephant .
- In 2008, Hadoop became a top-level project of the Apache Software Foundation, and also achieved a significant milestone by sorting 1 terabyte of data in 209 seconds, beating the previous record held by a supercomputer.
- Since then, Hadoop has evolved into a large and diverse ecosystem of components and tools that support a variety of use cases and applications for big data analytics .
- Some of the major components of the Hadoop ecosystem are:
  - Hadoop Distributed File System (HDFS) – a distributed file system that provides high-throughput access to application data and can store data across thousands of nodes.
  - Hadoop MapReduce – an implementation of the MapReduce programming model for large-scale data processing on HDFS.
  - Hadoop YARN – a platform that manages computing resources in clusters and schedules user applications on top of MapReduce.
  - Hadoop Ozone – an object store for Hadoop that can handle billions of small files and supports multiple protocols.
  - Hadoop Common – a set of common utilities and libraries that support other Hadoop modules.
  - Other projects that run on or integrate with Hadoop, such as Apache Hive, Apache Pig, Apache Spark, Apache HBase, Apache Kafka, Apache Flume, Apache Sqoop, Apache ZooKeeper, etc..
