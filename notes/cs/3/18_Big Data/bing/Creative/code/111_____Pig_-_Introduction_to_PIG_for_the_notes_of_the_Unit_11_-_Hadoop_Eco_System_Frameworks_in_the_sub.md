### Pig - Introduction to PIG

- Pig is a high-level scripting language that allows users to write complex data analysis programs for large-scale data sets.
- Pig is part of the Hadoop ecosystem and runs on top of the Hadoop Distributed File System (HDFS).
- Pig programs are translated into a series of MapReduce jobs that are executed by the Hadoop framework.
- Pig provides a set of built-in operators and functions to perform common data operations such as filtering, grouping, joining, sorting, and aggregating.
- Pig also allows users to define their own custom functions using Java, Python, or other languages.
- Pig can handle both structured and unstructured data, and can process data from various sources such as HDFS, local files, or web services.
- Pig is designed to be expressive, extensible, and easy to use for data analysts and developers who are familiar with SQL or scripting languages.
- Pig was developed by Yahoo! in 2006 and became an Apache project in 2007. The current stable version of Pig is 0.17.0, released in 2017.
