## Unit 8 - MongoDB

MongoDB is an open-source document database and leading NoSQL database. MongoDB is written in C++. In this unit, you will learn the basics of MongoDB and how to use it for creating and deploying a highly scalable and performance-oriented database.

Some of the topics that will be covered in this unit are:

- What is MongoDB and why use it?
- How to install and run MongoDB on different platforms
- How to create, read, update and delete documents in MongoDB
- How to use MongoDB operators, indexes, aggregation and transactions
- How to use MongoDB with various programming languages and frameworks
- How to use MongoDB Atlas, the cloud offering by MongoDB
- How to use MongoDB tools and utilities for administration and monitoring
- How to use MongoDB security features and best practices
- How to use MongoDB sharding and replication for scalability and availability

By the end of this unit, you will be able to:

- Understand the concepts and features of MongoDB
- Perform basic and advanced CRUD operations on MongoDB documents
- Use MongoDB query language and operators to filter and manipulate data
- Use MongoDB indexes to improve query performance and support text search
- Use MongoDB aggregation framework to perform complex data analysis and transformation
- Use MongoDB transactions to ensure data consistency and integrity
- Use MongoDB with various programming languages and frameworks such as Python, Node.js, Java, etc.
- Use MongoDB Atlas to create and manage MongoDB clusters in the cloud
- Use MongoDB tools and utilities such as mongo shell, Compass, mongodump, mongorestore, etc.
- Use MongoDB security features such as authentication, authorization, encryption, auditing, etc.
- Use MongoDB sharding and replication to distribute data across multiple servers and regions
