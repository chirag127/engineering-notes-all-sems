# Security in Hadoop

- Security in Hadoop is the process of protecting the data and services of a Hadoop cluster from unauthorized access, modification, or disclosure.
- Security in Hadoop consists of four main aspects: authentication, authorization, auditing, and encryption   .
- Authentication is the process of verifying the identity of a user or a service before allowing access to the Hadoop cluster. Authentication can be done using Kerberos, a network protocol that uses tickets and keys to establish secure communication between the client and the server   .
- Authorization is the process of granting or denying access to the data and services of the Hadoop cluster based on the authenticated identity of the user or the service. Authorization can be done using HDFS file permissions, which control the read, write, and execute permissions of files and directories in the Hadoop Distributed File System (HDFS), or using Service Level Authorization, which controls the access to the Hadoop services such as MapReduce, YARN, Hive, HBase, etc   .
- Auditing is the process of recording and monitoring the activities and events that occur in the Hadoop cluster, such as who accessed what data, when, and how. Auditing can be done using audit logs, which store the information about the operations performed on the Hadoop cluster, or using third-party tools, such as Apache Ranger, Apache Sentry, or Cloudera Navigator, which provide more advanced features such as policy management, data lineage, and data governance  .
- Encryption is the process of transforming the data into an unreadable form using a secret key, so that only authorized parties can decrypt and access the data. Encryption can be done at different levels, such as network encryption, which secures the communication between the nodes of the Hadoop cluster using SSL/TLS protocols, or data encryption, which secures the data stored in HDFS or other storage systems using encryption algorithms, such as AES or RSA  .
