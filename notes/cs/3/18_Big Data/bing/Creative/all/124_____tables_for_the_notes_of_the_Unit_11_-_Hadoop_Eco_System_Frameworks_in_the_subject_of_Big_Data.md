# Tables for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

## Table 1: Definition and overview of Hadoop and its ecosystem

| Term | Definition | Reference |
|------|------------|-----------|
| Hadoop | An open-source software framework that allows for the distributed processing of large data sets across clusters of computers using simple programming models. |  |
| Hadoop Ecosystem | A platform or a suite that provides various services to solve the big data problems. It includes Apache projects and various commercial tools and solutions. |  |
| Hadoop Distributed File System (HDFS) | A distributed file system that has the capability to store a large stack of data sets. It provides high availability, fault tolerance, scalability, and reliability. |  |
| MapReduce | A programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster. |  |
| YARN | A framework for job scheduling and cluster resource management. It allows multiple data processing engines such as MapReduce, Spark, and Hive to run on the same cluster. |  |
| Hadoop Common | A set of common utilities that support the other Hadoop modules. It includes libraries and scripts for Hadoop installation and configuration. |  |

## Table 2: Examples of Hadoop ecosystem components and their functions

| Component | Function | Reference |
|-----------|----------|-----------|
| Hive | A data warehouse software that facilitates reading, writing, and managing large data sets residing in distributed storage using SQL. |  |
| Pig | A high-level platform for creating programs that run on Hadoop. It uses a language called Pig Latin that allows users to express data analysis tasks. |  |
| Spark | A fast and general engine for large-scale data processing. It supports batch, streaming, SQL, machine learning, and graph processing. |  |
| HBase | A distributed, scalable, big data store that provides random, real-time read/write access to hundreds of terabytes or petabytes of data. |  |
| Sqoop | A tool that transfers data between Hadoop and relational databases. It can import data from external sources into HDFS or Hive, and export data from HDFS or Hive to external sources. |  |
| Flume | A service that collects, aggregates, and moves large amounts of log data from various sources to a centralized data store. |  |
| Kafka | A distributed streaming platform that allows publishers and subscribers to exchange messages in real-time. It can handle high-volume data and integrate with various data sources and sinks. |  |
| Oozie | A workflow scheduler system that manages Hadoop jobs. It supports complex workflows that can include multiple types of Hadoop jobs such as MapReduce, Pig, Hive, and Sqoop. |  |
| ZooKeeper | A centralized service that maintains configuration information, naming, and synchronization for distributed systems. It helps coordinate the operation of Hadoop clusters. |  |
| Mahout | A library of scalable machine learning algorithms that run on top of Hadoop. It supports various types of learning such as classification, clustering, recommendation, and dimensionality reduction. |  |
