### Hadoop Configuration

Hadoop configuration is the process of setting the parameters and properties of the Hadoop system and its components, such as HDFS, YARN, and MapReduce. Hadoop configuration can be done at different levels, such as cluster, node, daemon, and job. Hadoop configuration can affect the performance, security, and functionality of the Hadoop system.

Some of the main points to know about Hadoop configuration are:

- Hadoop configuration is driven by two types of important configuration files: read-only default configuration files and site-specific configuration files. The default configuration files provide the default values for the Hadoop parameters and are located in the source code of Hadoop. The site-specific configuration files override the default values and are located in the `etc/hadoop` directory of the Hadoop installation. The site-specific configuration files are `core-site.xml`, `hdfs-site.xml`, `yarn-site.xml`, and `mapred-site.xml`  .
- To configure the Hadoop cluster, you will need to configure the environment in which the Hadoop daemons execute as well as the configuration parameters for the Hadoop daemons. The Hadoop daemons are NameNode, SecondaryNameNode, DataNode, ResourceManager, NodeManager, and WebAppProxy for Hadoop 3.x, and NameNode, DataNode, JobTracker, and TaskTracker for Hadoop 1.x . The environment configuration includes setting the Java version, the Hadoop home directory, the Hadoop log directory, the Hadoop PID directory, and the SSH settings. The daemon configuration includes setting the memory, heap size, port, replication factor, block size, and other parameters for each daemon .
- To configure the Hadoop node, you will need to edit the `etc/hadoop/hadoop-env.sh` file and set the environment variables for the node, such as `JAVA_HOME`, `HADOOP_HOME`, `HADOOP_LOG_DIR`, `HADOOP_PID_DIR`, and `HADOOP_CONF_DIR`. The `HADOOP_CONF_DIR` variable specifies the location of the site-specific configuration files .
- To configure the Hadoop job, you will need to specify the job-specific parameters in the `mapred-site.xml` file or in the command line when submitting the job. The job-specific parameters include the number of mappers, the number of reducers, the input format, the output format, the compression codec, the partitioner, the combiner, and the mapper and reducer classes .
- To check the current configuration of the Hadoop system, you can use the `hadoop conf` command or the web interface of the Hadoop daemons. The `hadoop conf` command displays the configuration information of the Hadoop system and its components. The web interface of the Hadoop daemons provides the status, metrics, logs, and configuration of each daemon .
