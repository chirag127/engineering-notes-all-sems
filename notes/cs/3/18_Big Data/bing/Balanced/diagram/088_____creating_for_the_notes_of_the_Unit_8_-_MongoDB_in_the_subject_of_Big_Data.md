### Unit 8 - MongoDB

MongoDB is a document-oriented database that stores data in JSON-like format. It is one of the most popular and widely used Big Data databases, as it can handle a variety of data types, support real-time analysis, and scale horizontally. Here are some key points to note about MongoDB:

- MongoDB is schema-less, meaning that the structure of the data can vary from document to document. This allows for flexibility and agility in data modeling and processing.
- MongoDB supports dynamic queries, which can filter, sort, aggregate, and transform data on the fly. MongoDB also provides a powerful aggregation framework, which can perform complex data analysis and manipulation.
- MongoDB is designed for high availability and scalability, using a distributed architecture that can automatically shard and replicate data across multiple nodes. MongoDB also supports transactions, which can ensure data consistency and integrity across multiple documents and collections.
- MongoDB can integrate with various Big Data frameworks and tools, such as Apache Spark, Hadoop, Kafka, and MongoDB Atlas Data Lake. MongoDB can also leverage its native drivers and connectors to interact with various programming languages and platforms, such as Python, Java, Node.js, and MongoDB Stitch.
