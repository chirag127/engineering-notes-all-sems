## Unit 8 - MongoDB

MongoDB is an open-source document database and leading NoSQL database. MongoDB is written in C++. MongoDB is designed to create and deploy a highly scalable and performance-oriented database. MongoDB stores data in flexible, JSON-like documents, meaning fields can vary from document to document and data structure can be changed over time. MongoDB supports various features such as indexing, regular expression, sharding data, aggregation framework, etc.

Some of the topics that will be covered in this unit are:

- MongoDB installation and configuration
- MongoDB data model and CRUD operations
- MongoDB indexing and query optimization
- MongoDB aggregation framework and pipeline
- MongoDB security and authentication
- MongoDB replication and sharding
- MongoDB backup and restore
- MongoDB tools and drivers

Each topic will have a theoretical explanation followed by practical examples and exercises. By the end of this unit, you will be able to:

- Understand the basics and advantages of MongoDB
- Create and manage MongoDB databases and collections
- Perform CRUD operations on MongoDB documents
- Use MongoDB indexes to improve query performance
- Use MongoDB aggregation framework to perform complex data analysis
- Secure and authenticate MongoDB access
- Set up MongoDB replication and sharding for high availability and scalability
- Backup and restore MongoDB data
- Use MongoDB tools and drivers to interact with MongoDB from different languages and platforms
