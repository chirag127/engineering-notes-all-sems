# Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

- MongoDB is a popular open-source document-oriented database system that stores data in JSON-like format.
- MongoDB is classified as a NoSQL database, which means it does not use the relational model or SQL language to store and query data.
- MongoDB is designed to handle large volumes of unstructured or semi-structured data, such as social media posts, web logs, sensor data, etc.
- MongoDB supports dynamic schema, which means the structure of the documents can vary within a collection and can be changed over time without affecting the existing data.
- MongoDB provides high availability, scalability, and performance by using features such as replication, sharding, indexing, aggregation, and caching.
- MongoDB can be integrated with various big data frameworks and tools, such as Hadoop, Spark, Kafka, etc., to perform complex analytics and processing on the data.
- MongoDB can be accessed through various drivers and APIs that support different programming languages, such as Java, Python, C#, Ruby, etc.
- MongoDB can be deployed on various platforms, such as Windows, Linux, MacOS, cloud services, etc.
