### Components of Hadoop

Hadoop is a framework for distributed storage and processing of large-scale data sets. It consists of the following core components :

- **Hadoop Distributed File System (HDFS)**: This is the storage layer of Hadoop that stores data in a distributed manner across multiple nodes in a cluster. HDFS can handle different types of data, such as structured, semi-structured, or unstructured, without prior organization. HDFS also provides fault tolerance, replication, and high availability features  .
- **Hadoop MapReduce**: This is the processing layer of Hadoop that allows parallel execution of user-defined functions on the data stored in HDFS. MapReduce consists of two phases: map and reduce. The map phase applies a function to each input key-value pair and produces intermediate key-value pairs. The reduce phase aggregates the intermediate key-value pairs by the same key and produces the final output  .
- **Hadoop YARN**: This is the resource management layer of Hadoop that allocates and schedules resources for different applications running on the cluster. YARN stands for Yet Another Resource Negotiator. YARN consists of two components: a Resource Manager that manages the cluster resources and a Node Manager that runs on each node and monitors the resource usage and health of the node  .

Apart from these core components, Hadoop also has several other components that provide additional functionality, such as data ingestion, data integration, data analysis, data visualization, and data security. Some of these components are:

- **Hadoop Common**: This is a set of shared libraries and utilities that support the other Hadoop components. It includes the Hadoop configuration files, the Hadoop command-line interface, and the Hadoop Java API.
- **Hadoop ZooKeeper**: This is a service that provides coordination and synchronization for distributed applications. It maintains a hierarchical namespace of configuration data, service discovery information, and distributed locks.
- **Hadoop Oozie**: This is a workflow scheduler that orchestrates and executes complex Hadoop jobs. It supports both MapReduce and YARN applications, as well as other Hadoop components, such as Pig, Hive, and Sqoop.
- **Hadoop Pig**: This is a scripting language that allows users to write high-level queries for data analysis on Hadoop. It translates the queries into MapReduce jobs and runs them on the cluster.
- **Hadoop Hive**: This is a data warehouse system that provides a SQL-like interface for querying and analyzing data stored in HDFS. It supports a variety of data formats, such as text, JSON, ORC, and Parquet. It also supports user-defined functions and custom data types.
- **Hadoop Sqoop**: This is a tool that transfers data between Hadoop and relational databases, such as MySQL, Oracle, and PostgreSQL. It supports both full and incremental data import and export.
- **Hadoop Flume**: This is a tool that collects and transports streaming data, such as log files, sensor data, and social media data, from various sources to HDFS or other Hadoop components. It supports multiple sources, sinks, and channels, and allows data transformation and enrichment.
- **Hadoop Spark**: This is a fast and general-purpose engine for large-scale data processing. It supports batch, streaming, interactive, and machine learning applications. It can run on Hadoop YARN or standalone mode. It also provides several libraries, such as Spark SQL, Spark Streaming, Spark MLlib, and Spark GraphX.
- **Hadoop HBase**: This is a distributed and scalable NoSQL database that provides random access and low-latency operations on large-scale data sets. It is based on the Google Bigtable model and stores data in column-oriented tables. It also supports transactions, replication, and integration with Hadoop MapReduce and Spark.
- **Hadoop Mahout**: This is a library that provides scalable and distributed machine learning algorithms for Hadoop. It supports various types of learning, such as classification, clustering, recommendation, and dimensionality reduction.
