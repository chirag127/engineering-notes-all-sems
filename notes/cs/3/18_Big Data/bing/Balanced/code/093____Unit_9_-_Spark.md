## Unit 9 - Spark

Spark is a distributed computing framework that allows processing large-scale data in parallel and in memory. Spark provides a unified API for batch, streaming, SQL, graph, and machine learning applications. Spark is written in Scala and runs on the Java Virtual Machine (JVM). Spark can be deployed on various cluster managers, such as Hadoop YARN, Apache Mesos, or Kubernetes.

Some of the main features of Spark are:

- Resilient Distributed Datasets (RDDs): RDDs are the core abstraction of Spark. They are immutable, partitioned, and fault-tolerant collections of data that can be operated on in parallel. RDDs can be created from various sources, such as files, databases, or other RDDs. RDDs support two types of operations: transformations and actions. Transformations create new RDDs from existing ones, such as map, filter, join, etc. Actions trigger the computation of RDDs and return results to the driver program, such as count, collect, save, etc.
- Spark SQL: Spark SQL is a module that provides structured and semi-structured data processing capabilities. Spark SQL allows users to query data using SQL or a DataFrame API, which is similar to Pandas or R data frames. Spark SQL can also read and write data from various sources, such as Hive, Parquet, JSON, CSV, etc. Spark SQL also supports a Catalyst optimizer that can perform various optimizations, such as predicate pushdown, column pruning, etc.
- Spark Streaming: Spark Streaming is a module that enables scalable and fault-tolerant stream processing of live data. Spark Streaming can ingest data from various sources, such as Kafka, Flume, Socket, etc. Spark Streaming can also integrate with Spark SQL and MLlib to perform complex analytics on streaming data. Spark Streaming uses a micro-batch model, where the incoming data is divided into small batches and processed by Spark as RDDs.
- Spark MLlib: Spark MLlib is a module that provides scalable and distributed machine learning algorithms and utilities. Spark MLlib supports both supervised and unsupervised learning, as well as feature extraction, selection, and transformation. Spark MLlib also provides a high-level API called ML Pipelines, which allows users to chain multiple transformers and estimators into a single workflow. Spark MLlib can also leverage Spark SQL and DataFrames for data manipulation and processing.
- Spark GraphX: Spark GraphX is a module that provides graph processing and analytics capabilities. Spark GraphX allows users to create and manipulate graphs using a Graph abstraction, which is composed of vertices and edges. Spark GraphX also provides various graph algorithms, such as PageRank, Connected Components, Triangle Counting, etc. Spark GraphX can also integrate with Spark SQL and DataFrames for data manipulation and processing.
