### Unit 8 - MongoDB

MongoDB is an open-source document database and leading NoSQL database. MongoDB is written in C++. MongoDB is designed to create and deploy a highly scalable and performance-oriented database. MongoDB uses JSON-like documents with optional schemas. MongoDB supports dynamic queries on documents using a powerful aggregation framework that can run on multiple servers. MongoDB also supports indexing, replication, sharding, text search, geospatial queries, graph traversal, and more.

Some of the topics that you should learn in this unit are:

- MongoDB installation and configuration
- MongoDB data model and CRUD operations
- MongoDB indexing and query optimization
- MongoDB aggregation framework and pipeline
- MongoDB replication and sharding
- MongoDB security and authentication
- MongoDB backup and restore
- MongoDB monitoring and administration
