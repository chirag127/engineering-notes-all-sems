### Map Reduce types for the notes of the Unit 3 - Map Reduce in the subject of Big Data

MapReduce is a programming model and a software framework for processing large-scale data sets in parallel using a cluster of computers or nodes. It consists of two phases: map and reduce. The map phase applies a user-defined function to each input record and produces a set of intermediate key-value pairs. The reduce phase aggregates the intermediate values associated with the same key and produces the final output.

There are different types of MapReduce based on the application domain, the data source, the programming language, and the execution environment. Some of the common types are:

- **Hadoop MapReduce**: This is the original and most widely used implementation of MapReduce, which runs on the Apache Hadoop platform. It is written in Java and supports various data sources, such as Hadoop Distributed File System (HDFS), Amazon S3, and local files. It also supports various programming languages, such as Java, Python, Ruby, and C++. Hadoop MapReduce is suitable for batch processing of large and structured data sets.
- **Spark MapReduce**: This is an alternative implementation of MapReduce, which runs on the Apache Spark platform. It is written in Scala and supports various data sources, such as HDFS, S3, Cassandra, and Kafka. It also supports various programming languages, such as Scala, Java, Python, and R. Spark MapReduce is suitable for stream processing of large and unstructured data sets, as well as interactive and iterative analysis.
- **MongoDB MapReduce**: This is a specialized implementation of MapReduce, which runs on the MongoDB database. It is written in JavaScript and supports MongoDB collections as the data source. It also supports various programming languages, such as JavaScript, Java, Python, and C#. MongoDB MapReduce is suitable for aggregation and transformation of large and semi-structured data sets, such as JSON documents.
- **Amazon Elastic MapReduce (EMR)**: This is a cloud-based implementation of MapReduce, which runs on the Amazon Web Services (AWS) platform. It supports various data sources, such as S3, DynamoDB, and Redshift. It also supports various programming frameworks, such as Hadoop, Spark, Hive, and Pig. Amazon EMR is suitable for scalable and cost-effective processing of large and diverse data sets in the cloud.
