### Types of digital data

Digital data is any information that can be stored, processed, or transmitted in a digital form, such as binary digits (bits) or characters. Digital data can be contrasted with analog data, which is represented by a value from a continuous range of real numbers.

There are three main types of digital data, depending on the level of structure and format they have:

- **Unstructured data**: This is data that has no predefined format or schema, and is usually in the form of text, images, audio, video, or other multimedia. Unstructured data accounts for the majority of the digital data that makes up big data, and extracting information from it can be difficult and time-consuming. Examples of unstructured data include email, text messages, invoices, social media posts, web pages, etc .

- **Semi-structured data**: This is data that has some level of organization or structure, but not in a fixed or rigid format. Semi-structured data often contains tags, labels, or metadata that help identify and describe the data, but not in a consistent or standardized way. Examples of semi-structured data include XML, JSON, HTML, CSV, log files, etc.

- **Structured data**: This is data that has a well-defined format and schema, and can be easily stored, queried, and analyzed in a relational database or a spreadsheet. Structured data follows a set of rules and conventions that make it easy to manipulate and process. Examples of structured data include tables, records, fields, columns, rows, etc.

Some of the factors that affect the choice of data type and format are:

- The purpose and use of the data
- The size and complexity of the data
- The availability and compatibility of software and hardware tools
- The quality and reliability of the data
- The security and privacy of the data
- The cost and efficiency of the data storage and processing

Some of the recommended digital data formats for different types of data are:

- Text, Documentation, Scripts: XML, PDF/A, HTML, Plain Text
- Still Image: TIFF, JPEG 2000, PNG, JPEG/JFIF, DNG (digital negative), BMP, GIF
- Geospatial: Shapefile (SHP, DBF, SHX), GeoTIFF, NetCDF
- Graphic Image: raster formats: TIFF, JPEG2000, PNG, JPEG/JFIF, DNG, BMP, GIF; vector formats: SVG, EPS, PDF
- Audio: WAV, AIFF, FLAC, MP3, AAC
- Video: MOV, MPEG-4, AVI, MKV
- Tabular Data: CSV, TSV, XML, JSON
- Database: SQL, SQLite, XML, JSON
