### Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

- MongoDB is a popular open-source document-oriented database that stores data in JSON-like format.
- MongoDB is a NoSQL database, which means it does not use the relational model of tables, rows, and columns, but rather organizes data into collections of documents that can have varying fields and structures.
- MongoDB is designed to handle large volumes of data with high performance, scalability, and availability. It supports features such as replication, sharding, indexing, aggregation, transactions, and schema validation.
- MongoDB is widely used for applications that require real-time analytics, social media, e-commerce, IoT, and cloud computing.
- MongoDB can be installed on various operating systems, such as Windows, Linux, macOS, and cloud platforms. It can be accessed through various drivers and tools that support different programming languages and frameworks.
- MongoDB follows the CRUD (Create, Read, Update, Delete) operations to manipulate data in the database. It also provides a powerful query language that allows users to filter, sort, project, and aggregate data.
- MongoDB has a flexible schema, which means that documents in the same collection can have different fields and types. This allows users to store complex and heterogeneous data without having to define a rigid structure beforehand.
- MongoDB uses BSON (Binary JSON) as its internal data format, which is a binary-encoded version of JSON that supports additional data types, such as date, binary, and ObjectId. BSON is more compact and efficient than JSON for data storage and transmission.
