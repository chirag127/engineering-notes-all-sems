### Schedulers for the notes of the Unit 6 - Hadoop Eco System and YARN in the subject of Big Data

- Schedulers are algorithms that allocate resources to applications running on a Hadoop cluster based on some criteria, such as fairness, capacity, priority, etc.   
- Schedulers are pluggable components that can be configured in the YARN configuration file. YARN is the resource management framework of Hadoop that consists of a Resource Manager, a Node Manager, and an Application Master.  
- There are three main types of schedulers in Hadoop: FIFO (First In First Out) Scheduler, Capacity Scheduler, and Fair Scheduler. 
- FIFO Scheduler: This is the simplest and default scheduler that assigns resources to applications in the order of their submission. It does not consider the resource requirements or the priority of the applications. It is suitable for small clusters with few applications. 
- Capacity Scheduler: This is a hierarchical scheduler that divides the cluster resources into multiple queues, each with a configurable capacity and priority. Each queue can have sub-queues and can run multiple applications. The scheduler ensures that each queue gets its fair share of resources, and also allows for resource sharing and preemption among queues and applications. It is suitable for large clusters with multiple tenants and diverse workloads.  
- Fair Scheduler: This is a flexible scheduler that assigns resources to applications such that all applications get an equal share of resources over time, regardless of the order of submission. It also supports hierarchical queues, resource sharing, preemption, and configurable policies to adjust the fair share based on weights, min/max shares, etc. It is suitable for clusters with a mix of short and long running applications, and for achieving high utilization and throughput.
