### Cluster Specification for the Notes of the Unit 5 - Hadoop Environment in the Subject of Big Data

- A Hadoop cluster is a collection of computers, known as nodes, that are networked together to perform parallel computations on big data sets .
- A Hadoop cluster is designed to store and analyze large amounts of structured, semi-structured, and unstructured data in a distributed environment. It is often referred to as a shared-nothing system because the only thing that is shared between the nodes is the network itself.
- A Hadoop cluster consists of two types of nodes: master nodes and worker nodes. Master nodes are responsible for coordinating and managing the tasks of the worker nodes. Worker nodes are responsible for storing and processing the data blocks assigned to them.
- A Hadoop cluster can be divided into four distinctive layers: distributed storage layer, distributed processing layer, resource management layer, and application layer.
  - Distributed storage layer: Each node in a Hadoop cluster has its own disk space, memory, bandwidth, and processing. The incoming data is split into individual data blocks, which are then stored within the HDFS distributed storage layer. HDFS is a fault-tolerant file system that replicates the data blocks across multiple nodes to ensure data availability and reliability.
  - Distributed processing layer: The distributed processing layer is responsible for executing the user-defined tasks on the data blocks stored in the HDFS. The tasks are written in a programming model called MapReduce, which consists of two phases: map and reduce. The map phase applies a user-defined function to each data block and produces intermediate key-value pairs. The reduce phase aggregates the intermediate key-value pairs based on the keys and produces the final output.
  - Resource management layer: The resource management layer is responsible for allocating and scheduling the resources (such as CPU, memory, disk, and network) for the tasks submitted by the users. The resource management layer consists of two components: YARN and ZooKeeper. YARN is a framework that manages the resources and the execution of the tasks across the cluster. ZooKeeper is a service that maintains the configuration and coordination of the cluster nodes.
  - Application layer: The application layer is responsible for providing the user interface and the tools for interacting with the Hadoop cluster. The application layer consists of various components, such as Hive, Pig, Spark, HBase, and Sqoop. These components provide different functionalities, such as data querying, data processing, data analysis, data storage, and data integration.
