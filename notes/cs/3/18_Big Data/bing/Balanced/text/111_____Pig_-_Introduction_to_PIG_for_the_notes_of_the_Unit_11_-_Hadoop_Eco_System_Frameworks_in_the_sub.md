### Pig - Introduction to PIG for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

- Pig is a tool or platform for processing and analyzing large data sets, also known as big data, as data flows  .
- Pig provides a high-level of abstraction for processing over the MapReduce framework, which is a core component of Hadoop  .
- Pig offers a scripting language called Pig Latin, which is used to develop data analysis programs that can run on Hadoop clusters  .
- Pig Latin is a declarative language that allows users to specify the logic of data transformations without worrying about the low-level details of MapReduce programming  .
- Pig Latin supports various data types, such as tuples, bags, maps, and atomic types, and provides many built-in operators and functions for data manipulation, such as filtering, grouping, joining, sorting, and aggregating  .
- Pig can also interact with other languages, such as Python, Java, and Ruby, through user-defined functions (UDFs), which can extend the functionality of Pig Latin  .
- Pig can run in two modes: local mode and MapReduce mode. In local mode, Pig runs on a single machine without Hadoop, and is useful for testing and debugging. In MapReduce mode, Pig runs on a Hadoop cluster and converts Pig Latin scripts into MapReduce jobs  .
- Pig is useful for data analysts and developers who want to perform complex data analysis tasks on large data sets without writing complex MapReduce code. Pig can handle structured, semi-structured, and unstructured data, and can integrate with other Hadoop components, such as Hive, HBase, and Spark  .
