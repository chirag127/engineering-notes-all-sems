### Security in Hadoop

- Security in Hadoop refers to the process of protecting the data and services of a Hadoop cluster from unauthorized access, modification, or disclosure.
- Security in Hadoop consists of four main aspects: authentication, authorization, encryption, and auditing.
- Authentication is the process of verifying the identity of a user or a service before allowing access to the Hadoop cluster. Hadoop supports Kerberos as the primary mechanism for authentication, which is a network protocol that uses tickets to establish secure communication between the client and the server. Hadoop also supports other authentication methods, such as LDAP, SAML, OAuth, and certificates.
- Authorization is the process of granting or denying access to the data and services of the Hadoop cluster based on the authenticated identity of the user or the service. Hadoop supports different authorization mechanisms for different components, such as HDFS file permissions, MapReduce ACLs, Hive policies, HBase ACLs, and Sentry roles. Hadoop also supports service-level authorization, which is a feature that allows the administrator to specify which users or groups can access which Hadoop services.
- Encryption is the process of transforming the data into an unreadable form to prevent unauthorized access or disclosure. Hadoop supports encryption at different levels, such as network encryption, which secures the communication between the nodes of the cluster using SSL/TLS, and data encryption, which secures the data stored in HDFS or HBase using encryption zones or transparent encryption.
- Auditing is the process of recording and monitoring the activities and events that occur in the Hadoop cluster, such as who accessed what data, when, and how. Hadoop supports auditing through different mechanisms, such as audit logs, which capture the security-related events of the Hadoop services, and Ranger, which is a framework that provides centralized security administration and auditing for the Hadoop ecosystem.
