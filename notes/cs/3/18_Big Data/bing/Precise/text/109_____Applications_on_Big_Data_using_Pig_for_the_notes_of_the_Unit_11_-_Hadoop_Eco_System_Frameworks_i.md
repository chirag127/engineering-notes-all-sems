### Applications on Big Data using Pig

- Pig is a high-level platform or tool which is used to process large datasets. It provides a high level of abstraction for processing over MapReduce.
- Pig provides a high-level scripting language, known as Pig Latin which is used to develop the data analysis codes.
- Pig is used for exploring large datasets .
- Pig provides supports across large data sets for Ad-hoc queries .
- Pig is utilized by telecom organizations to de-identify the customer call data information.
- Pig in big data gives the ability to make User-defined Functions (UDFs) in other programming languages like Java and embed or invoke them in Pig Scripts.
- Apache Pig examines a wide range of data, both unstructured as well as structured.
- Pig is used in the prototyping of large data-sets processing algorithms.
- Pig is required to process the time sensitive data loads.
- Pig is used for collecting large amounts of datasets.
