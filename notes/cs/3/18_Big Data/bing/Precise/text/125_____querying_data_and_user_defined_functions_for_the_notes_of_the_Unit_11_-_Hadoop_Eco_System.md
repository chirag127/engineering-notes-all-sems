### Querying Data and User Defined Functions for the Notes of the Unit 11 - Hadoop Eco System

1. Querying data in Hadoop involves using tools such as Hive and Pig to extract and analyze data stored in the Hadoop Distributed File System (HDFS).
2. Hive is a data warehousing and SQL-like query language that allows users to write queries to extract data from HDFS. It translates these queries into MapReduce jobs that are executed on the Hadoop cluster.
3. Pig is a high-level platform for creating MapReduce programs used with Hadoop. It includes a language called Pig Latin for expressing data analysis programs and an infrastructure for evaluating these programs.
4. User Defined Functions (UDFs) are custom functions written by users to perform specific operations on data. They can be used in both Hive and Pig to extend their functionality and allow for more complex data analysis.
5. UDFs can be written in various programming languages such as Java, Python, and Ruby, and can be used to perform operations such as data cleansing, data transformation, and data enrichment.
6. UDFs can be registered with Hive or Pig and then used in queries or scripts just like built-in functions.
7. Using UDFs can improve the performance of data analysis tasks by allowing users to write custom code that is optimized for their specific use case.
8. UDFs can also be shared and reused by other users, making it easier to perform common data analysis tasks.
