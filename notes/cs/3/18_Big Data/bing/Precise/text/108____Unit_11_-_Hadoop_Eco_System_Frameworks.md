## Unit 11 - Hadoop Eco System Frameworks

The Hadoop ecosystem is a collection of open-source software utilities that facilitate using a network of many computers to solve problems involving massive amounts of data and computation. The core of Apache Hadoop consists of a storage part, known as Hadoop Distributed File System (HDFS), and a processing part which is a MapReduce programming model.

Some of the popular frameworks in the Hadoop ecosystem include:

1. **Hive**: A data warehousing and SQL-like query language for Hadoop.
2. **Pig**: A high-level platform for creating MapReduce programs used with Hadoop.
3. **HBase**: A non-relational, distributed database that runs on top of Hadoop.
4. **Spark**: A fast and general-purpose cluster computing system.
5. **ZooKeeper**: A high-performance coordination service for distributed applications.
6. **Oozie**: A workflow scheduler system to manage Apache Hadoop jobs.
7. **Flume**: A distributed, reliable, and available service for efficiently collecting, aggregating, and moving large amounts of log data.
8. **Sqoop**: A tool designed for efficiently transferring bulk data between Apache Hadoop and structured datastores such as relational databases.

These frameworks provide a wide range of functionality and can be used to solve a variety of data processing and analysis tasks. They are designed to work together, allowing users to easily move data between different systems and perform complex analysis on large datasets.
