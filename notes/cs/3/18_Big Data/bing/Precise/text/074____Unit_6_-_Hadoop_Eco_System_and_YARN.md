## Unit 6 - Hadoop Eco System and YARN

1. **Hadoop Eco System:** The Hadoop ecosystem is a framework and set of tools for processing large amounts of data. It includes the Hadoop Distributed File System (HDFS) for storing data, and MapReduce for processing data. Other tools in the ecosystem include Pig, Hive, and HBase.

2. **YARN:** YARN (Yet Another Resource Negotiator) is a resource management layer in Hadoop. It is responsible for allocating resources to applications and managing their execution. YARN allows multiple data processing engines to run on the same Hadoop cluster, improving resource utilization and scalability.

3. **HDFS:** The Hadoop Distributed File System (HDFS) is a distributed file system designed to run on commodity hardware. It provides high-throughput access to application data and is suitable for applications with large data sets.

4. **MapReduce:** MapReduce is a programming model for processing large data sets. It is based on the idea of splitting the data into chunks and processing each chunk in parallel. The results are then combined to produce the final output.

5. **Pig:** Pig is a platform for analyzing large data sets. It provides a high-level language for expressing data analysis programs, and an execution environment for running those programs.

6. **Hive:** Hive is a data warehousing and SQL-like query language for Hadoop. It allows users to query and analyze data stored in HDFS using a familiar SQL syntax.

7. **HBase:** HBase is a distributed, column-oriented database built on top of HDFS. It is designed to provide real-time read/write access to large data sets.
