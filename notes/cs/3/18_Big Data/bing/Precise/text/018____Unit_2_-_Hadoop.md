## Unit 2 - Hadoop

1. **Introduction:** Hadoop is an open-source software framework for storing and processing large datasets using distributed computing. It was developed by the Apache Software Foundation.

2. **Hadoop Distributed File System (HDFS):** HDFS is the primary storage system used by Hadoop. It is designed to store and manage large files across multiple machines.

3. **MapReduce:** MapReduce is a programming model for processing large datasets in parallel. It is used to perform distributed computations on data stored in HDFS.

4. **YARN:** YARN (Yet Another Resource Negotiator) is a resource management layer in Hadoop. It is responsible for allocating resources to applications and managing their execution.

5. **Hadoop Ecosystem:** The Hadoop ecosystem consists of a number of tools and frameworks that can be used with Hadoop, including Apache Pig, Apache Hive, Apache HBase, Apache Spark, and Apache Storm.

6. **Applications:** Hadoop is used in a variety of applications, including data warehousing, log analysis, recommendation systems, and fraud detection.

7. **Conclusion:** Hadoop is a powerful tool for managing and processing large datasets. Its distributed architecture and ecosystem of tools make it a popular choice for big data applications.
