## Unit 8 - MongoDB

MongoDB is a cross-platform document-oriented database program. It is classified as a NoSQL database program, which means it uses a non-tabular data model for storing data. Some of the key features of MongoDB are:

1. **Document-based**: Data is stored in flexible, JSON-like documents, meaning fields can vary from document to document and data structure can be changed over time.

2. **Scalable**: MongoDB is horizontally scalable, meaning it can handle large amounts of data by distributing it across multiple servers.

3. **Flexible**: MongoDB allows for flexible querying and indexing, making it easy to search for and access data.

4. **High performance**: MongoDB is designed for high performance, with features such as in-memory storage and native aggregation.

5. **High availability**: MongoDB provides high availability through built-in replication and automatic failover.

MongoDB is used by many organizations for a variety of use cases, including content management, mobile and web applications, real-time analytics, and more. It is a popular choice for developers due to its ease of use and flexibility.
