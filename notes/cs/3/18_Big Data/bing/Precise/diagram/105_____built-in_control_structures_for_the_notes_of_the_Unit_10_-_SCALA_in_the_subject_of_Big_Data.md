### Unit 10 - SCALA: Built-in Control Structures

Scala has several built-in control structures that allow for the manipulation of the flow of a program. These include:

1. **If/else statements:** These statements allow for conditional execution of code. The `if` statement evaluates a condition and, if it is true, executes the code within its block. If the condition is false, the code within the `else` block is executed.

2. **While loops:** A `while` loop repeatedly executes a block of code while a condition is true. Once the condition becomes false, the loop terminates.

3. **For loops:** A `for` loop iterates over a collection of elements, executing a block of code for each element in the collection.

4. **Match expressions:** A `match` expression is similar to a `switch` statement in other languages. It allows for the evaluation of multiple conditions and the execution of code based on the result of the evaluation.

5. **Exception handling:** Scala provides the ability to handle exceptions through the use of `try`, `catch`, and `finally` blocks. These blocks allow for the execution of code in the event of an exception being thrown, the handling of the exception, and the execution of code regardless of whether an exception was thrown or not.

These built-in control structures provide a powerful and flexible way to control the flow of a program in Scala. They are an essential part of any Scala programmer's toolkit.
