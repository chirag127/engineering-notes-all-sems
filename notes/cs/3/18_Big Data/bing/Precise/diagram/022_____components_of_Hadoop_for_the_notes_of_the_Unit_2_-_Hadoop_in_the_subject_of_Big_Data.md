### Components of Hadoop

Hadoop is an open-source software framework for storing and processing big data in a distributed fashion on large clusters of commodity hardware. The core components of Hadoop include:

1. **MapReduce** – A software programming model for processing large sets of data in parallel.
2. **Hadoop Distributed File System (HDFS)** – The Java-based distributed file system that can store all kinds of data without prior organization.
3. **YARN** – A resource management framework for scheduling and handling resource requests from distributed applications.

These components work together to provide a reliable and scalable platform for big data processing. MapReduce is used for processing the data, HDFS is used for storing the data, and YARN is used for managing the resources of the cluster.
