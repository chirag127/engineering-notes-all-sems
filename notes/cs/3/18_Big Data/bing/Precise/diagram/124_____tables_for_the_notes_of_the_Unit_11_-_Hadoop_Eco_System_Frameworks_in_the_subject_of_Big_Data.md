### Unit 11 - Hadoop Eco System Frameworks

1. **Hadoop**: An open-source software framework for storing and processing large datasets using distributed computing.
2. **HDFS**: Hadoop Distributed File System, a distributed file system designed to store large files across multiple machines.
3. **MapReduce**: A programming model for processing large datasets in parallel across a Hadoop cluster.
4. **YARN**: Yet Another Resource Negotiator, a resource management layer for Hadoop.
5. **Hive**: A data warehousing and SQL-like query language for Hadoop.
6. **Pig**: A high-level platform for creating MapReduce programs used with Hadoop.
7. **HBase**: A non-relational distributed database that runs on top of HDFS.
8. **ZooKeeper**: A centralized service for maintaining configuration information, naming, and providing distributed synchronization.
9. **Oozie**: A workflow scheduler system to manage Hadoop jobs.
10. **Sqoop**: A tool for transferring data between Hadoop and relational databases.
11. **Flume**: A service for collecting, aggregating, and moving large amounts of log data.
12. **Spark**: An open-source cluster computing system for fast and flexible data processing.
