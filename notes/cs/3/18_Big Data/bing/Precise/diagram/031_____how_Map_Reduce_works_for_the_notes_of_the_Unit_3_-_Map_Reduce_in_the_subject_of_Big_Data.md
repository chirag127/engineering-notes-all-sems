### Unit 3 - Map Reduce

MapReduce is a programming model for processing large datasets in parallel across a large number of nodes. It is commonly used in the field of Big Data.

#### How MapReduce Works

1. **Input Data**: MapReduce can perform distributed and parallel computations using large datasets across a large number of nodes. A MapReduce job usually splits the input datasets and then process each of them independently by the Map tasks in a completely parallel manner.

2. **Map Task**: The Map task takes a set of data and converts it into another set of data, where individual elements are broken down into tuples (key-value pairs). The output is then sorted and input to reduce tasks.

3. **Reduce Task**: After all the mappers complete processing, the framework shuffles and sorts the results before passing them on to the reduce tasks.

4. **Output Data**: The final output is generated by the reduce tasks.

MapReduce is a powerful tool for processing large datasets in a distributed and parallel manner. It is widely used in the field of Big Data for its ability to handle large volumes of data efficiently.
