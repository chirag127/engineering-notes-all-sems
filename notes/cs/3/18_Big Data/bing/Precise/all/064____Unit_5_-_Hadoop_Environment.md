## Unit 5 - Hadoop Environment

1. **Introduction to Hadoop Environment:** Hadoop is an open-source software framework for storing and processing large datasets using distributed computing. It is designed to scale up from a single server to thousands of machines, each offering local computation and storage.

2. **Hadoop Distributed File System (HDFS):** HDFS is the primary storage system used by Hadoop applications. It is a distributed file system that provides high-throughput access to application data and is designed to be fault-tolerant.

3. **MapReduce:** MapReduce is a programming model and software framework for writing applications that process large amounts of data in parallel on large clusters of commodity hardware.

4. **YARN:** Yet Another Resource Negotiator (YARN) is a resource management layer in Hadoop that is responsible for managing and allocating resources to applications.

5. **Hadoop Ecosystem:** The Hadoop ecosystem includes a number of tools and technologies that can be used with Hadoop to enhance its capabilities, including Apache Pig, Apache Hive, Apache HBase, Apache Spark, and Apache ZooKeeper.

6. **Hadoop Cluster:** A Hadoop cluster is a collection of computers, known as nodes, that work together to store and process data. A typical Hadoop cluster consists of a master node and multiple worker nodes.

7. **Hadoop Configuration:** Hadoop can be configured to meet the specific needs of an organization. Configuration options include setting the number of replicas for data blocks, the size of data blocks, and the amount of memory allocated to MapReduce tasks.

8. **Hadoop Security:** Hadoop provides several security features, including Kerberos authentication, access control lists, and data encryption.

9. **Hadoop Operations:** Hadoop operations include tasks such as starting and stopping the Hadoop services, monitoring the health of the cluster, and managing data stored in HDFS.

10. **Hadoop Administration:** Hadoop administration involves tasks such as installing and configuring Hadoop, managing the Hadoop cluster, and performing backups and disaster recovery.
