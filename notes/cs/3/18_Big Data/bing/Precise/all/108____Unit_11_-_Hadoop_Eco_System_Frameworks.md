## Unit 11 - Hadoop Eco System Frameworks

Hadoop is an open-source software framework for storing and processing large datasets. The Hadoop ecosystem consists of several frameworks that work together to provide a complete solution for big data processing.

1. **Hadoop Distributed File System (HDFS)**: A distributed file system that provides high-throughput access to application data.
2. **MapReduce**: A programming model for processing large datasets in parallel.
3. **YARN**: A resource management platform responsible for managing compute resources in clusters and using them for scheduling of users' applications.
4. **HBase**: A column-oriented NoSQL database that runs on top of HDFS.
5. **Hive**: A data warehousing and SQL-like query language for Hadoop.
6. **Pig**: A high-level platform for creating MapReduce programs used with Hadoop.
7. **Sqoop**: A tool for transferring data between Hadoop and relational databases.
8. **Flume**: A service for collecting, aggregating, and moving large amounts of log data.
9. **Oozie**: A workflow scheduler system to manage Hadoop jobs.

These frameworks provide a powerful and flexible platform for processing large datasets and are widely used in industry and academia. They are constantly evolving and new frameworks are being added to the ecosystem to address new challenges and requirements.
