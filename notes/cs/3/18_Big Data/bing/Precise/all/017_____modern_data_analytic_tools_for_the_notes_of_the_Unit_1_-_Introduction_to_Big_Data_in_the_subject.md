# Unit 1 - Introduction to Big Data

### Modern Data Analytic Tools

1. **Python** - A popular programming language for data analysis and visualization.
2. **R** - A programming language and software environment for statistical computing and graphics.
3. **SAS** - A software suite for advanced analytics, multivariate analysis, business intelligence, data management, and predictive analytics.
4. **Excel** - A spreadsheet program that can be used for data analysis and visualization.
5. **Power BI** - A business analytics service by Microsoft that provides interactive visualizations and business intelligence capabilities.
6. **Tableau** - A data visualization software that helps people see and understand data.
7. **Apache Spark** - An open-source distributed general-purpose cluster-computing framework for large-scale data processing.
8. **Apache Hadoop** - A Java-based free software framework that helps in the effective storage of a huge amount of data in a storage place known as a cluster.

These are some of the modern data analytic tools that are widely used in the field of Big Data. They provide powerful capabilities for data analysis, visualization, and management. It is important to have a good understanding of these tools to effectively work with Big Data.
