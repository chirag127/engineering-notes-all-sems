# Unit 3 - Map Reduce

### Map Reduce Types

MapReduce is a programming model for processing large data sets with a parallel, distributed algorithm on a cluster. There are several types of MapReduce, including:

1. **Classic MapReduce**: This is the original MapReduce model introduced by Google. It consists of two main functions: Map and Reduce. The Map function takes an input and produces a set of intermediate key-value pairs. The Reduce function takes the intermediate key-value pairs and combines them to produce the final output.

2. **Map-Only**: In this type of MapReduce, there is no Reduce function. The Map function produces the final output directly. This is useful for tasks such as filtering and sorting.

3. **Reduce-Only**: In this type of MapReduce, there is no Map function. The input data is directly fed into the Reduce function, which produces the final output. This is useful for tasks such as aggregation and summarization.

4. **Combiner**: A Combiner is an optional function that can be used in a MapReduce job to perform local aggregation of the intermediate data generated by the Map function. This can help reduce the amount of data that needs to be transferred between the Map and Reduce functions, improving the performance of the job.

5. **Partitioner**: A Partitioner is responsible for dividing the intermediate data generated by the Map function into partitions, which are then assigned to different Reduce tasks. This allows the data to be processed in parallel by multiple Reduce tasks. The Partitioner can be customized to control the distribution of the data among the Reduce tasks.

These are the main types of MapReduce. Each type has its own advantages and can be used for different types of tasks. It is important to choose the right type of MapReduce for the task at hand to achieve the best performance.
