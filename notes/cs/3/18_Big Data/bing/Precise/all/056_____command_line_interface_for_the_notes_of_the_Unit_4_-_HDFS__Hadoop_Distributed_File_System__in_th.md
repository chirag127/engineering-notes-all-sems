# Command Line Interface for HDFS (Hadoop Distributed File System)

HDFS (Hadoop Distributed File System) is a distributed file system designed to store large data sets across multiple machines. It is a part of the Apache Hadoop project and is used to store and process big data.

Here are some key points to remember when using the command line interface for HDFS:

1. The `hadoop fs` command is used to interact with HDFS from the command line.
2. The `hadoop fs -ls` command is used to list the contents of a directory in HDFS.
3. The `hadoop fs -put` command is used to copy a file from the local file system to HDFS.
4. The `hadoop fs -get` command is used to copy a file from HDFS to the local file system.
5. The `hadoop fs -rm` command is used to delete a file from HDFS.
6. The `hadoop fs -mkdir` command is used to create a directory in HDFS.
7. The `hadoop fs -cat` command is used to display the contents of a file in HDFS.
8. The `hadoop fs -tail` command is used to display the last few lines of a file in HDFS.

These are some of the basic commands that can be used to interact with HDFS from the command line. It is important to familiarize oneself with these commands in order to effectively manage and process big data using HDFS.
