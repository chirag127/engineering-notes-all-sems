# Hadoop Streaming

- Hadoop streaming is a utility that comes with the Hadoop distribution .
- The utility allows you to create and run Map/Reduce jobs with any executable or script as the mapper and/or the reducer .
- For example, you can supply a Java class as the mapper and/or the reducer .
- Hadoop streaming is a powerful feature that enables anyone to write code in any language of their own choice .
- Hadoop streaming works by utilizing the external mapper and reducers .
