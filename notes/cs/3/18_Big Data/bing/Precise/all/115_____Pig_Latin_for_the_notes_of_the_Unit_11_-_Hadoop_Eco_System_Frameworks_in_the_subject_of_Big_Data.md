# Unit 11 - Hadoop Eco System Frameworks: Pig Latin

- Pig Latin is a high-level platform for creating MapReduce programs used with Hadoop.
- It is a data flow language that abstracts the programming from the Java MapReduce idiom into a notation which makes MapReduce programming high level, similar to that of SQL for RDBMS systems.
- Pig Latin is a procedural language and it fits in a pipeline paradigm.
- Pig Latin scripts are automatically optimized by the runtime system, so the programmer does not have to worry about optimization.
- Pig Latin is designed to handle any kind of data, structured or unstructured. It can handle data stored in HDFS, HBase, or any other storage system that Hadoop can access.
- Pig Latin is extensible, so users can develop their own functions for reading, processing, and writing data.
- Pig Latin is an open-source project and is part of the Apache Hadoop project.
