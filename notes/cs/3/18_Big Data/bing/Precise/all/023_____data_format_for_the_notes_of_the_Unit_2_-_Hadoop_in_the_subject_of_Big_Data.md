### Data Format for the Notes of the Unit 2 - Hadoop in the Subject of Big Data

1. Hadoop is an open-source software framework for storing and processing large datasets.
2. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.
3. Hadoop uses a distributed file system called HDFS (Hadoop Distributed File System) to store data.
4. Data is stored in blocks and distributed across multiple nodes in the cluster.
5. Hadoop uses a programming model called MapReduce to process data.
6. MapReduce divides the data into smaller chunks and processes them in parallel on multiple nodes.
7. The results of the processing are then combined and returned to the user.
8. Hadoop also includes other components such as YARN (Yet Another Resource Negotiator) for resource management and job scheduling, and HBase for storing structured data in a column-oriented format.
9. Hadoop is widely used in big data applications for its ability to handle large volumes of data and its scalability.
