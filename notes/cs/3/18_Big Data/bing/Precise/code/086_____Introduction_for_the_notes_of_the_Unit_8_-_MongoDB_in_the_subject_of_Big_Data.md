### Introduction for the notes of the Unit 8 - MongoDB in the subject of Big Data

1. MongoDB is a document-based database management system.
2. It is a NoSQL database, meaning it does not use the traditional relational database structure.
3. MongoDB stores data in flexible, JSON-like documents.
4. It is designed to handle large amounts of data and is often used in big data applications.
5. MongoDB is an open-source software, meaning it is freely available for anyone to use and modify.
6. It is a popular choice for web and mobile applications due to its scalability and flexibility.
7. MongoDB supports dynamic schema design, allowing the structure of the data to change over time.
8. It also supports indexing, aggregation, and ad-hoc queries for fast data retrieval.
9. MongoDB can be used in a variety of applications, including content management, real-time analytics, and data storage for the Internet of Things (IoT).
10. It is part of the MEAN stack, a popular technology stack for building web applications.
