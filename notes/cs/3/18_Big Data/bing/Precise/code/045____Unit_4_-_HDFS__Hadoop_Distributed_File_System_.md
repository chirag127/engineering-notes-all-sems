## Unit 4 - HDFS (Hadoop Distributed File System)

HDFS is a distributed file system that is designed to run on commodity hardware. It is highly fault-tolerant and is designed to be deployed on low-cost hardware. HDFS provides high throughput access to application data and is suitable for applications that have large data sets.

Some key features of HDFS include:

1. Scalability: HDFS can easily scale to handle petabytes of data by simply adding more nodes to the cluster.
2. Data Reliability: HDFS replicates data across multiple nodes to ensure data reliability and availability.
3. High Availability: HDFS is designed to be highly available, with features such as automatic failover and data replication.
4. Cost-Effective: HDFS is designed to run on commodity hardware, making it a cost-effective solution for storing large amounts of data.
5. Easy to Use: HDFS is easy to use and provides a simple interface for storing and retrieving data.

HDFS is an important component of the Hadoop ecosystem and is used by many big data applications to store and process large amounts of data. It is a key technology for enabling big data analytics and is widely used in industries such as finance, healthcare, and retail.
