### data format for the notes of the Unit 2 - Hadoop in the subject of Big Data

Data format refers to the structure and organization of data, and is a critical aspect of big data systems. The following are some of the key concepts related to data format in big data systems:

1. Structured Data: Structured data is data that is organized into a well-defined format, such as a relational database or a spreadsheet.

2. Semi-Structured Data: Semi-structured data is data that has some structure, but also contains unstructured elements, such as text or images.

3. Unstructured Data: Unstructured data is data that does not have a well-defined format, such as audio, video, or text.

4. Columnar Data: Columnar data is data that is organized into columns, rather than rows, and is optimized for fast data processing and analysis.

5. Parquet Format: Parquet is a columnar data format that is optimized for big data processing and analysis, and is widely used in big data systems.

6. Avro Format: Avro is a data serialization format that is optimized for big data processing and analysis, and is widely used in big data systems.

In this unit, you will learn about data format in big data systems, including structured data, semi-structured data, unstructured data, columnar data, Parquet format, and Avro format.

This unit will provide a foundation for understanding the principles and practices of data format in big data systems, and for exploring the various concepts and techniques used in the field of big data.
