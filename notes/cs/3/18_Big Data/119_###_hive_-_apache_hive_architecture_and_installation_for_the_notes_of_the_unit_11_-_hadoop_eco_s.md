### Hive - Apache Hive architecture and installation for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

The Hive - Apache Hive Architecture and Installation section of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data should cover the following topics:

1. Definition of Apache Hive (a data warehousing and SQL-like query language for Hadoop)
2. Overview of Apache Hive (what it is, when it is used, advantages and disadvantages)
3. Hive Architecture (e.g. the components and structure of Apache Hive)
4. Overview of Hive Architecture (what it is, when it is used, advantages and disadvantages)
5. Hive Metastore (e.g. the central repository for metadata in Apache Hive)
6. Overview of Hive Metastore (what it is, when it is used, advantages and disadvantages)
7. Hive Query Processor (e.g. the component in Apache Hive that processes queries)
8. Overview of Hive Query Processor (what it is, when it is used, advantages and disadvantages)
9. Hive Execution Engine (e.g. the component in Apache Hive that executes queries)
10. Overview of Hive Execution Engine (what it is, when it is used, advantages and disadvantages)
11. Hive Installation (e.g. how to install Apache Hive on a Hadoop cluster)
12. Overview of Hive Installation (what it is, when it is used, advantages and disadvantages)
13. Hive Configuration (e.g. how to configure Apache Hive after installation)
14. Overview of Hive Configuration (what it is, when it is used, advantages and disadvantages)
15. Hive in industry applications (how Apache Hive is used in various industries)
16. Further reading and resources (books, articles, online resources)

Apache Hive is an important component of the subject of Big Data, especially in the context of Hadoop Eco System Frameworks. Understanding the architecture and installation of Apache Hive helps students to develop the skills required to design and implement data warehousing solutions using Apache Hive. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
