### Map Reduce framework and basics for the notes of the Unit 3 - Map Reduce in the subject of Big Data

Unit 3 - Map Reduce in the subject of Big Data will cover the basics of the MapReduce framework, a programming model used for processing large amounts of data in parallel.

MapReduce is a programming model used for processing large amounts of data in parallel. It is based on the map and reduce functions, which are used to process data in parallel across multiple nodes in a cluster. The map function takes a set of data and converts it into a set of intermediate key-value pairs, while the reduce function takes the intermediate key-value pairs and aggregates the values for each key.
