### Hive services for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

Hive is a data warehousing and SQL-like query language for Hadoop. The following are some of the key services associated with Hive:

1. Hive Metastore: A centralized repository that stores metadata about the tables, columns, and partitions in a Hive database.

2. HiveServer2: A service that provides a Thrift API for accessing Hive data and metadata, and supports multiple client connections.

3. Hive CLI: A command-line interface for interacting with the Hive metastore and executing Hive queries.

4. Hive Web Interface: A web-based interface for interacting with the Hive metastore and executing Hive queries.

5. Hive ODBC Driver: An ODBC driver that allows Hive data to be accessed from other applications using the ODBC API.

6. Hive JDBC Driver: A JDBC driver that allows Hive data to be accessed from other applications using the JDBC API.

In this unit, you will learn about Hive services, including Hive Metastore, HiveServer2, Hive CLI, Hive Web Interface, Hive ODBC Driver, and Hive JDBC Driver.

This unit will provide a foundation for understanding the principles and practices of Hive services, and for exploring the various concepts and techniques used in the field of big data processing and management.
