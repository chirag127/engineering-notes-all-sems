### Map Reduce features for the notes of the Unit 3 - Map Reduce in the subject of Big Data

Unit 3 - Map Reduce in the subject of Big Data will cover the features of MapReduce, a programming model for processing large amounts of data in parallel.

MapReduce has several key features that make it an effective solution for processing large amounts of data in parallel. Some of these features include:

1. Scalability: MapReduce is designed to scale from single servers to thousands of machines, each offering local computation and storage.

2. Parallel Processing: MapReduce allows for the processing of large amounts of data in parallel across multiple nodes in a cluster.

3. Fault Tolerance: MapReduce provides automatic fault tolerance, allowing for the processing of data even if one or more nodes in the cluster fail.

4. Data Locality: MapReduce takes advantage of data locality, processing data on the same node where it is stored whenever possible.

5. High-level Abstraction: MapReduce provides a high-level abstraction for processing data, making it easier for developers to write programs that process large amounts of data in parallel.
