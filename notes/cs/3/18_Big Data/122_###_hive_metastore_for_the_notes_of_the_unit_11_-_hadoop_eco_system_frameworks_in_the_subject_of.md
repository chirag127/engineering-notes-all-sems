### Hive metastore for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

The Hive Metastore section of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data should cover the following topics:

1. Definition of Hive Metastore (a data store that contains metadata about the structure and contents of data stored in a Hive data warehouse)
2. Overview of Hive Metastore (what it is, when it is used, advantages and disadvantages)
3. Hive Metastore Architecture (e.g. how Hive Metastore works and its components)
4. Overview of Hive Metastore Architecture (what it is, when it is used, advantages and disadvantages)
5. Hive Metastore Types (e.g. the different types of Hive Metastores such as embedded and remote)
6. Overview of Hive Metastore Types (what they are, when they are used, advantages and disadvantages)
7. Hive Metastore Tables (e.g. the tables stored in the Hive Metastore)
8. Overview of Hive Metastore Tables (what they are, when they are used, advantages and disadvantages)
9. Hive Metastore API (e.g. the API used to interact with the Hive Metastore)
10. Overview of Hive Metastore API (what it is, when it is used, advantages and disadvantages)
11. Hive Metastore in industry applications (how Hive Metastore is used in various industries)
12. Further reading and resources (books, articles, online resources)

Hive Metastore is an important component of the subject of Big Data, especially in the context of Hadoop Eco System Frameworks. Understanding the principles and techniques of Hive Metastore helps students to develop the skills required to design and implement effective big data solutions using Hive. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
