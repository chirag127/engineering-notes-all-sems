### MRv2 for the notes of the Unit 6 - Hadoop Eco System and YARN in the subject of Big Data

MRv2 (MapReduce version 2) is the next generation of the MapReduce data processing framework in Hadoop. The following are some of the key concepts related to MRv2:

1. YARN: YARN (Yet Another Resource Negotiator) is the resource management system used by MRv2 to allocate resources and manage jobs in the Hadoop cluster. 

2. Scalability: MRv2 provides improved scalability compared to the original MapReduce by allowing multiple data processing frameworks to run on the same cluster.

3. Flexibility: MRv2 provides greater flexibility compared to the original MapReduce by allowing multiple data processing frameworks to run on the same cluster and by supporting a wider range of data processing workloads.

4. Resource Management: MRv2 provides improved resource management compared to the original MapReduce by using YARN to allocate resources and manage jobs in the Hadoop cluster.

5. Performance: MRv2 provides improved performance compared to the original MapReduce by optimizing resource utilization and reducing the overhead associated with managing jobs in the Hadoop cluster.

6. Compatibility: MRv2 is compatible with the original MapReduce, and existing MapReduce applications can be easily migrated to MRv2.

In this unit, you will learn about MRv2, including YARN, scalability, flexibility, resource management, performance, and compatibility.

This unit will provide a foundation for understanding the principles and practices of MRv2, and for exploring the various concepts and techniques used in the field of big data processing and management.
