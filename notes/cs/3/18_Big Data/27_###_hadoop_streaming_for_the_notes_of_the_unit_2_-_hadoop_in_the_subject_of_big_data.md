### Hadoop streaming for the notes of the Unit 2 - Hadoop in the subject of Big Data

Hadoop Streaming is a feature of Apache Hadoop that allows developers to write MapReduce programs in any language, as long as the programs can read input from standard input (stdin) and write output to standard output (stdout). The following are some of the key concepts related to Hadoop Streaming:

1. MapReduce: MapReduce is a programming model for processing large and complex data sets, and is the foundation of Hadoop.

2. Standard Input and Output: Standard input (stdin) and standard output (stdout) are the standard data streams used by programs in Hadoop Streaming.

3. Mapper and Reducer: Mapper and Reducer are the two main components of a MapReduce program, and are responsible for processing data in Hadoop Streaming.

4. Input and Output Formats: Input and output formats are the formats used by Hadoop Streaming to read and write data, and include formats such as TextInputFormat and TextOutputFormat.

5. Partitioning and Shuffling: Partitioning and shuffling are the processes used by Hadoop Streaming to divide data into smaller chunks and redistribute the data to different nodes in the cluster, respectively.

6. Performance: Performance is a key consideration in Hadoop Streaming, and depends on factors such as the size of the data set, the number of nodes in the cluster, and the complexity of the MapReduce program.

In this unit, you will learn about Hadoop Streaming in Apache Hadoop, including MapReduce, standard input and output, mapper and reducer, input and output formats, partitioning and shuffling, and performance.

This unit will provide a foundation for understanding the principles and practices of Hadoop Streaming and for exploring the various concepts and techniques used in the field of Big Data.
