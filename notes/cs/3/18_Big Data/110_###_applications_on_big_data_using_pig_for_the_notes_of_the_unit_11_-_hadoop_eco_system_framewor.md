### Applications on Big Data using Pig for the notes of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data

The Applications on Big Data using Pig section of the Unit 11 - Hadoop Eco System Frameworks in the subject of Big Data should cover the following topics:

1. Definition of Pig (a high-level platform for creating MapReduce programs used for big data processing)
2. Overview of Pig (what it is, when it is used, advantages and disadvantages)
3. Pig Latin (e.g. the language used to write Pig scripts)
4. Overview of Pig Latin (what it is, when it is used, advantages and disadvantages)
5. Pig for Data Processing (e.g. using Pig for data processing tasks such as filtering, transforming, and aggregating data)
6. Overview of Pig for Data Processing (what it is, when it is used, advantages and disadvantages)
7. Pig for Machine Learning (e.g. using Pig for machine learning tasks such as classification, regression, and clustering)
8. Overview of Pig for Machine Learning (what it is, when it is used, advantages and disadvantages)
9. Pig for Graph Processing (e.g. using Pig for graph processing tasks such as graph traversal and PageRank calculation)
10. Overview of Pig for Graph Processing (what it is, when it is used, advantages and disadvantages)
11. Pig for Streaming (e.g. using Pig for real-time data processing tasks such as data ingestion, processing, and analysis)
12. Overview of Pig for Streaming (what it is, when it is used, advantages and disadvantages)
13. Applications on Big Data using Pig in industry applications (how applications on big data using Pig are used in various industries)
14. Further reading and resources (books, articles, online resources)

Applications on Big Data using Pig is an important component of the subject of Big Data, especially in the context of Hadoop Eco System Frameworks. Understanding the principles and techniques of Applications on Big Data using Pig helps students to develop the skills required to design and implement effective big data processing solutions using Pig.
