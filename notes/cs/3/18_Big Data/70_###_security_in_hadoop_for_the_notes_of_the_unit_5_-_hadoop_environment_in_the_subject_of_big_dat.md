### security in Hadoop for the notes of the Unit 5 - Hadoop Environment in the subject of Big Data

Security in Hadoop refers to the measures and techniques used to protect the data and resources in a Hadoop environment from unauthorized access and malicious attacks. The following are some of the key concepts related to security in Hadoop:

1. Authentication: Authentication is the process of verifying the identity of a user or system, and is used to control access to Hadoop resources.

2. Authorization: Authorization is the process of granting or denying access to Hadoop resources based on the identity of the user or system, and is used to enforce security policies.

3. Encryption: Encryption is the process of converting data into a secret code to protect it from unauthorized access, and is used to secure data in transit and at rest in Hadoop.

4. Kerberos: Kerberos is an authentication protocol that provides secure authentication for Hadoop, and is used to control access to Hadoop resources.

5. Secure Shell (SSH): Secure Shell (SSH) is a secure communication protocol that provides encryption for network services, and is used to secure communication between Hadoop nodes.

6. Hadoop Security Model: The Hadoop security model is the set of security policies and procedures used to secure a Hadoop environment, and includes measures such as authentication, authorization, encryption, and secure communication.

In this unit, you will learn about security in Hadoop, including authentication, authorization, encryption, Kerberos, Secure Shell (SSH), and the Hadoop security model.

This unit will provide a foundation for understanding the principles and practices of security in Hadoop, and for exploring the various concepts and techniques used in the field of big data security.
