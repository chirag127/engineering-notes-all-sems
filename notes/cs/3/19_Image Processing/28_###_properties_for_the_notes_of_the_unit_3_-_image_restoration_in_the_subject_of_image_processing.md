### Properties for the notes of the Unit 3 - IMAGE RESTORATION in the subject of Image Processing

Image restoration is the process of removing degradation from an image and restoring it to its original form. The following are some of the key properties associated with image restoration:

1. Degradation Model: Image restoration requires a model of the degradation that has affected the image, such as blur, noise, and others. The choice of degradation model depends on the specific requirements of the image restoration task, including the type of image data, the processing requirements, and the desired results.

2. Inverse Filtering: Image restoration can be performed using inverse filtering, which involves applying an inverse filter to the degraded image to remove the degradation. Inverse filtering is useful for removing simple degradation models, such as blur, but is limited by the presence of noise in the image.

3. Regularization: Image restoration can be performed using regularization, which involves adding a constraint to the inverse filtering process to control the solution. Regularization is useful for removing complex degradation models, such as noise, and for controlling the solution of the inverse filtering process.

4. Constrained Optimization: Image restoration can be performed using constrained optimization, which involves solving an optimization problem subject to constraints. Constrained optimization is useful for removing complex degradation models, such as noise, and for controlling the solution of the inverse filtering process.

5. Iterative Algorithms: Image restoration can be performed using iterative algorithms, which involve repeating a set of operations until a desired result is obtained. Iterative algorithms are useful for removing complex degradation models, such as noise, and for controlling the solution of the inverse filtering process.

In this unit, you will learn about the properties of image restoration, including degradation model, inverse filtering, regularization, constrained optimization, and iterative algorithms.

This unit will provide a foundation for understanding the principles and practices of image restoration, and for exploring the various concepts and techniques used in the field of image processing.
