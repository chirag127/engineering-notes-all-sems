### Edge linking via Hough transform

- Edge linking is the process of connecting edge pixels in an image to form continuous contours or boundaries of objects.
- Edge linking can be done by local or global methods. Local methods analyze the neighborhood of each edge pixel and link it to another edge pixel based on some criteria, such as gradient direction, intensity difference, or distance. Global methods use a parametric representation of the edge shape and find the best fit for the edge pixels in the image.
- Hough transform is a global method for edge linking that can detect lines, circles, ellipses, or other curves in an image. The basic idea of Hough transform is to map each edge pixel in the image space to a set of parameters in the parameter space, and then find the peaks or maxima in the parameter space that correspond to the most likely edge shapes in the image space.
- For example, to detect lines in an image, the Hough transform uses the polar representation of a line: rho = x * cos(theta) + y * sin(theta), where rho is the distance from the origin to the line, and theta is the angle of the normal vector of the line. Each edge pixel (x, y) in the image space can be mapped to a sinusoidal curve in the (rho, theta) parameter space, and each point on the curve represents a possible line that passes through (x, y). The intersection of multiple curves in the parameter space indicates a common line that passes through multiple edge pixels in the image space. The more curves intersect at a point, the higher the value of the Hough accumulator at that point, and the more likely that point represents a true line in the image. The peaks or maxima in the Hough accumulator can be found by applying a threshold or a local non-maximum suppression algorithm.
- The advantages of Hough transform are that it can handle noisy or incomplete edge pixels, and it can detect multiple edge shapes simultaneously. The disadvantages are that it requires a large parameter space and a lot of computation, and it may produce false positives or miss some edge shapes that do not fit the parametric model.
