## Unit 4 - IMAGE SEGMENTATION

- Image segmentation is the process of partitioning an image into multiple segments, each of which consists of a group of pixels that share certain characteristics .
- Image segmentation is typically used to locate objects and boundaries in images, such as faces, organs, roads, buildings, etc .
- Image segmentation can reduce the complexity of the image and enable further processing or analysis of each image segment .
- Image segmentation can be classified into two main types: supervised and unsupervised.
  - Supervised image segmentation uses a set of labeled images as training data to learn the features and boundaries of the segments.
  - Unsupervised image segmentation does not use any prior information and relies on clustering or similarity measures to group the pixels.
- Some of the common techniques for image segmentation are :
  - Thresholding: This technique divides the image into two or more segments based on a predefined threshold value of the pixel intensity.
  - Region-based: This technique grows or merges regions based on some homogeneity criteria, such as color, texture, or shape.
  - Edge-based: This technique detects the edges or boundaries of the segments using filters, gradients, or edge detectors.
  - Clustering: This technique groups the pixels into clusters based on their similarity or distance in the feature space.
  - Deep learning: This technique uses neural networks to learn the features and boundaries of the segments from large amounts of data.
