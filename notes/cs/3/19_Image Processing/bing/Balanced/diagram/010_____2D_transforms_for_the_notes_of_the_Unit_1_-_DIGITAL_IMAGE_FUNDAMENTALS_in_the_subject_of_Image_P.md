### 2D transforms

- A 2D transform is a mathematical operation that changes the position, size, shape, or orientation of a 2D object, such as an image, on a plane.
- A 2D transform can be represented by a 2x2 matrix that operates on a 2D vector, or by a 3x3 matrix that operates on a 3D vector in homogeneous coordinates.
- Homogeneous coordinates are a way of representing 2D points with an extra dimension, which allows for translation (shifting) as well as other transformations.
- Some common types of 2D transforms are:

  - Translation: moving an object by a certain distance along the x and y axes.
  - Scaling: changing the size of an object by a certain factor along the x and y axes.
  - Rotation: rotating an object by a certain angle around the origin or a pivot point.
  - Shearing: skewing an object by a certain angle along the x or y axis.
  - Reflection: flipping an object over a line, such as the x-axis, the y-axis, or the line y = x.

- 2D transforms can be combined by multiplying their matrices, which results in a composite transform that performs all the individual transforms in sequence.
- 2D transforms can be applied to images to manipulate their appearance, such as cropping, resizing, rotating, warping, etc.
- 2D transforms can also be used to analyze the frequency content of images, such as the Fourier transform, which decomposes an image into a sum of sinusoids of different frequencies, amplitudes, and phases.
- Another example of a 2D transform is the wavelet transform, which decomposes an image into a sum of wavelets of different scales, orientations, and positions, which can capture both the global and local features of an image.
