## Unit 4 - IMAGE SEGMENTATION

- Image segmentation is the process of partitioning an image into multiple segments, each of which has a label or a class associated with it .
- Image segmentation is typically used to locate objects and boundaries in images, such as people, animals, buildings, roads, etc  .
- Image segmentation can reduce the complexity of the image and enable further processing or analysis of each image segment.
- Image segmentation can be based on various heuristics or high-level image features, such as color, intensity, texture, shape, edge, region, etc.
- Image segmentation can be classified into two main types: supervised and unsupervised.
  - Supervised image segmentation uses a set of labeled images as training data to learn a model that can segment new images.
  - Unsupervised image segmentation does not use any labeled images, but relies on clustering or grouping algorithms to find the natural segments in the image.
- Some of the common techniques for image segmentation are :
  - Thresholding: This technique divides the image into two or more segments based on a predefined threshold value for the pixel intensity or color. For example, a binary thresholding can separate the foreground from the background by setting a threshold value that distinguishes the two.
  - Edge detection: This technique identifies the boundaries or edges of the objects in the image by finding the pixels where the intensity or color changes abruptly. For example, the Canny edge detector is a popular algorithm that uses gradient and non-maximum suppression to find the edges in the image.
  - Region growing: This technique starts from a seed pixel or a region and expands it by adding neighboring pixels that have similar characteristics, such as intensity or color. For example, the connected components algorithm is a simple region growing technique that labels the pixels that are connected to each other by a path of similar pixels.
  - Region splitting and merging: This technique recursively divides the image into smaller regions until each region is homogeneous or meets a certain criterion, and then merges the adjacent regions that are similar or compatible. For example, the quadtree algorithm is a region splitting and merging technique that divides the image into four quadrants and then merges them if they have the same label or color.
  - Watershed: This technique treats the image as a topographic surface, where the pixel intensity or color represents the height, and finds the catchment basins or the regions that are separated by the watershed lines or the ridges. For example, the marker-based watershed algorithm is a watershed technique that uses user-defined markers or seeds to guide the segmentation process.
  - K-means clustering: This technique partitions the image into K clusters or segments, where each pixel belongs to the cluster with the nearest mean or centroid, which is the average of the pixel values in the cluster. For example, the K-means algorithm is a clustering technique that iteratively assigns each pixel to the nearest cluster and updates the cluster centroids until convergence.
  - Mean shift: This technique finds the modes or the peaks of the probability density function of the image, and assigns each pixel to the nearest mode. For example, the mean shift algorithm is a clustering technique that iteratively shifts each pixel to the direction of the highest density until convergence.
  - Graph cut: This technique models the image as a graph, where the nodes represent the pixels and the edges represent the similarity or dissimilarity between the pixels, and finds the optimal cut or the partition of the graph that minimizes the cost function. For example, the min-cut algorithm is a graph cut technique that finds the cut that separates the source node from the sink node with the minimum edge weight.
  - Neural networks: This technique uses a neural network model, such as a convolutional neural network (CNN) or a fully convolutional network (FCN), to learn the mapping from the input image to the output segmentation mask. For example, the U-Net algorithm is a neural network technique that uses an encoder-decoder architecture with skip connections to segment biomedical images.
