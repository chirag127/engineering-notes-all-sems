## Unit 1 - DIGITAL IMAGE FUNDAMENTALS

- A digital image is a representation of a two-dimensional image as a finite set of digital values, called pixels or picture elements.
- Each pixel has a numeric value that corresponds to its brightness, color, or intensity.
- A digital image can be stored, processed, and displayed by a computer system.
- A digital image can be created from various sources, such as a scanner, a camera, a screen capture, or a synthetic image generator.

### Elements of digital image processing systems

- A digital image processing system consists of the following elements:
  - Image acquisition: The process of capturing an image from a physical scene using a sensor, such as a camera or a scanner.
  - Image enhancement: The process of improving the appearance or quality of an image by modifying its pixel values, such as contrast, brightness, sharpness, or noise reduction.
  - Image restoration: The process of recovering an image that has been degraded by some factors, such as blurring, distortion, or noise, using a mathematical model of the degradation.
  - Image compression: The process of reducing the amount of data required to represent an image by exploiting its redundancy, such as spatial, temporal, or perceptual.
  - Image segmentation: The process of dividing an image into meaningful regions or objects based on some criteria, such as color, texture, shape, or edge.
  - Image representation and description: The process of encoding the features or characteristics of an image or its regions using a compact and efficient format, such as boundary, contour, skeleton, or histogram.
  - Image recognition and interpretation: The process of identifying and understanding the content or meaning of an image or its regions using prior knowledge, such as templates, models, or rules.

### Basic concepts of digital image processing

- Some basic concepts of digital image processing are:
  - Pixel: The smallest unit of a digital image that has a specific location and value.
  - Resolution: The number of pixels in an image, usually expressed as width x height, such as 640 x 480.
  - Bit depth: The number of bits used to represent the value of each pixel, such as 8 bits, 16 bits, or 24 bits.
  - Color model: A mathematical representation of color as a combination of primary components, such as RGB (red, green, blue), CMYK (cyan, magenta, yellow, black), or HSV (hue, saturation, value).
  - Histogram: A graphical representation of the frequency distribution of pixel values in an image, such as the number of pixels with a certain brightness or color.
  - Spatial domain: The domain of an image where each pixel is represented by its location and value, such as a matrix or an array.
  - Frequency domain: The domain of an image where each pixel is represented by its frequency and phase, such as a Fourier transform or a wavelet transform.
  - Filter: A mathematical operation that modifies the pixel values of an image based on some criteria, such as smoothing, sharpening, or edge detection.
  - Kernel: A small matrix or mask that defines the coefficients or weights of a filter, such as a 3 x 3 or a 5 x 5 kernel.
  - Convolution: A process of applying a filter to an image by multiplying the kernel with the pixel values in a sliding window, such as a 3 x 3 or a 5 x 5 window.
  - Thresholding: A process of converting a grayscale image into a binary image by assigning a pixel value of 0 or 1 based on a threshold value, such as 128 or 200.
  - Morphology: A process of modifying the shape or structure of an image or its regions using basic operations, such as erosion, dilation, opening, or closing.
