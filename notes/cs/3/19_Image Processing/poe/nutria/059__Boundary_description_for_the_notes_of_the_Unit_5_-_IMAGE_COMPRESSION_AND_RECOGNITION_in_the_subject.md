
### Boundary Description for the Notes of the Unit 5 - IMAGE COMPRESSION AND RECOGNITION in the Subject of Image Processing

* Boundary description is a process of finding the boundaries of objects in an image. 
* It is used for various applications such as object recognition, image segmentation, and image compression.
* Boundary description can be divided into two categories: edge detection and region-based methods. 
* Edge detection methods are used to detect the edges of the objects in an image. These methods use the gradient of the image to detect the edges. 
* Region-based methods are used to detect the boundaries of the objects in an image. These methods use the properties of the regions to detect the boundaries. 
* Image compression is the process of reducing the size of an image to save storage space. It is used to reduce the size of an image while maintaining the quality of the image. 
* Image recognition is the process of recognizing objects in an image. It is used to identify objects in an image and classify them.
