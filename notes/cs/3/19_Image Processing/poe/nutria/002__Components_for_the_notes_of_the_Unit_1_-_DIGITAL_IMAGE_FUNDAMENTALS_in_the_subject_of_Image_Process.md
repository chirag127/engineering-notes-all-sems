
### Components for the Notes of the Unit 1 - Digital Image Fundamentals in the Subject of Image Processing

* Digital images are composed of pixels, which are the smallest elements of an image. 
* Pixels are usually arranged in a rectangular grid, and each pixel has a specific value or color.
* Digital images can be stored in different file formats, such as JPEG, PNG, GIF, TIFF, and BMP.
* Digital images can be manipulated using various techniques, such as cropping, rotating, resizing, and color correction.
* Image editing software can be used to enhance digital images, such as by adding text, shapes, and special effects.
* Digital images can be compressed to reduce their file size and improve their loading time.
* Digital images can be used for various purposes, such as printing, web design, and video production.
