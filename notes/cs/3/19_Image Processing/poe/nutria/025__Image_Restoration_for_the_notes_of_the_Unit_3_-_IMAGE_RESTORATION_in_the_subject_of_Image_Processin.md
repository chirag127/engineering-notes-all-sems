
### Image Restoration

Image restoration is the process of removing noise and other distortions from a digital image. It is a common technique used in digital image processing and computer vision.

* Noise: Noise is an unwanted signal that can be caused by a variety of sources, such as electronic components, natural phenomena, or even human errors. Noise can have a significant impact on the quality of an image, making it difficult to recognize or interpret.

* Filtering: Filtering is a process used to reduce the amount of noise in an image. It is typically done by applying a linear filter to the image, which is a mathematical operation that modifies the values of the pixels in an image in order to reduce noise.

* Image Enhancement: Image enhancement is a process used to improve the visibility of an image. It is typically done by adjusting the contrast, brightness, and sharpness of the image.

* Image Inpainting: Image inpainting is a process used to fill in missing or damaged parts of an image. It is typically done by using an algorithm to fill in the missing parts of the image with values that are consistent with the surrounding pixels.

* Image Restoration Algorithms: Image restoration algorithms are used to improve the quality of an image by removing noise and other distortions. Common algorithms used for image restoration include Wiener filtering, Total Variation, and Non-Local Means.
