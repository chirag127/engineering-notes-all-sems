
## Unit 3 - IMAGE RESTORATION

1. Image restoration is the process of restoring a damaged or degraded image back to its original state. This can be done through a variety of methods, such as filtering, interpolation, and image fusion. 
2. Filtering is a process in which an image is processed using a filter to reduce noise or enhance features. Common filters used for image restoration include median filtering, low-pass filtering, and high-pass filtering. 
3. Interpolation is a process of reconstructing an image from incomplete data. This can be done by using techniques such as nearest neighbor interpolation, bilinear interpolation, and bicubic interpolation. 
4. Image fusion is the process of combining two or more images to create a single image. This is accomplished by combining the information from each image to create a more detailed and accurate image. 
5. Image restoration can be used to improve the quality of a digital image, reduce noise, and enhance features. It can also be used to correct errors caused by compression, transmission, and storage.
