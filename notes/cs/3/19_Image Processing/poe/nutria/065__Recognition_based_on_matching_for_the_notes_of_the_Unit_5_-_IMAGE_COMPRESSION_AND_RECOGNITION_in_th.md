
### Recognition based on Matching

* Recognition based on matching is a process of identifying an object from an image or video based on a model or template. 
* It is a form of image recognition where the goal is to identify an object or pattern within an image.
* The process involves comparing a template of the object or pattern to be identified with the image or video.
* The model or template can be a pre-defined set of features, such as color, shape, size, or texture, or it can be a learned model.
* In the case of a learned model, the template is learned from a set of training images.
* The process of recognition based on matching is commonly used in applications such as facial recognition, object recognition, and pattern recognition.
* It is also used in image compression and recognition, where the goal is to reduce the size of an image while still preserving its features.
* This is done by using a set of algorithms that identify the important features in an image and then compress them so that the image can be stored in a smaller format.
