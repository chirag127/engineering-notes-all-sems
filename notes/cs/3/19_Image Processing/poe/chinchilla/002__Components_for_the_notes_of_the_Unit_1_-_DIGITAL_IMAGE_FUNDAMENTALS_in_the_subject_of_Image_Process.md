### Components for the notes of the Unit 1 - DIGITAL IMAGE FUNDAMENTALS in the subject of Image Processing

In this unit, we will be discussing the fundamentals of digital images, which are the building blocks of image processing. Here are the key components to keep in mind while taking notes:

- **Pixels:** Images are made up of small dots called pixels. Each pixel represents a single color or shade of gray. The number of pixels in an image determines its resolution, which affects the image's clarity and detail.
- **Resolution:** Resolution refers to the number of pixels in an image. Higher resolution images have more pixels and therefore more detail. Resolution is typically measured in pixels per inch (PPI) or dots per inch (DPI).
- **Color models:** Images can be represented using different color models such as RGB, CMYK, and Grayscale. RGB is the most commonly used color model for digital images and is made up of three primary colors: red, green, and blue. CMYK is used for print media and stands for cyan, magenta, yellow, and black. Grayscale uses shades of gray to represent the color values in an image.
- **Image file formats:** Images can be saved in a variety of file formats such as JPEG, PNG, TIFF, and BMP. Each file format has its own advantages and disadvantages depending on the intended use of the image.
- **Image enhancement techniques:** Image enhancement techniques are used to improve the quality of an image. These techniques include contrast adjustment, brightness adjustment, noise reduction, and sharpening.
- **Image segmentation:** Image segmentation is the process of dividing an image into multiple segments or regions based on similar characteristics such as color or texture. This technique is used in image processing for object recognition and tracking.
- **Image compression:** Image compression is the process of reducing the size of an image file without significantly degrading its quality. Lossy compression techniques sacrifice some image quality to achieve higher compression ratios, while lossless compression techniques preserve the image quality but may not achieve as high of compression ratios.

By understanding these key components, you will have a solid foundation for learning and understanding the more advanced concepts and techniques in image processing.
