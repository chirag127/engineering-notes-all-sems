Unit 4 - Database Design & Normalization in the subject of Basics of Database Management System covers the concept of normalization, which is a process used to optimize the design of a database. Normalization is used to eliminate redundancy and improve the efficiency of a database.

One of the main tools used in normalization is functional dependency (FD), which is a relationship between attributes in a database. A functional dependency occurs when one attribute determines another attribute. For example, if a customer's name is known, then their address can be determined.

Functional dependencies are used in normalization to identify relationships between attributes in a database, and to eliminate redundancy. Normalization is a process that involves breaking down a database into smaller, more manageable tables, and establishing relationships between the tables.

The goal of normalization is to create a database that is:

1. Accurate: The data in a normalized database is accurate and consistent.

2. Efficient: The data in a normalized database is stored in an efficient manner, reducing the risk of data corruption and improving performance.

3. Scalable: The data in a normalized database is scalable, allowing it to grow and adapt to changing requirements.
