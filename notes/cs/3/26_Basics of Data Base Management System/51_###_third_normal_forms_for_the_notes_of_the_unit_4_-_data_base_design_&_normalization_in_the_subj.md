### third normal forms for the notes of the Unit 4 - Data Base Design & Normalization in the subject of Basics of Data Base Management System

Third Normal Form (3NF) is a normalization process in database design that aims to minimize redundancy and improve data integrity. 

1. Remove Transitive Dependencies: 3NF requires the removal of transitive dependencies, which occur when an attribute depends on another attribute, which in turn depends on a primary key. 

2. No Duplicate Data: 3NF ensures that there is no duplicate data in the database, which can lead to inconsistencies and errors. 

3. No Redundant Data: 3NF also ensures that there is no redundant data in the database, which can lead to inefficiencies and slow performance. 

4. Improved Data Integrity: By removing transitive dependencies, duplicates, and redundant data, 3NF improves data integrity and reduces the risk of data corruption. 

5. Better Data Organization: 3NF also leads to better data organization, making it easier to manage and maintain the database. 

6. Improved Query Performance: By removing redundant data, 3NF can also improve query performance, as the database will be smaller and more efficient. 

7. Better Data Security: By reducing the risk of data corruption and improving data integrity, 3NF can also improve data security and reduce the risk of unauthorized access or manipulation. 

8. Complexity: 3NF can be complex to implement and may require significant changes to the database design. 

9. Limitations: 3NF has limitations and may not be suitable for all databases, particularly those with complex relationships between entities.
