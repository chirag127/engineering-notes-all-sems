Unit 5 - Structured Query Language (SQL) in the subject of Basics of Database Management System covers the following topic:

1. Aggregate Functions:
Aggregate functions are functions in SQL that perform calculations on a set of values and return a single result. Some common aggregate functions include SUM, AVG, MIN, MAX, and COUNT.

2. Purpose of Aggregate Functions:
The purpose of aggregate functions is to perform calculations on a set of values and return a single result. Aggregate functions are used to summarize data in a database, such as finding the average of a set of values or counting the number of records in a table.

3. How to Use Aggregate Functions:
Aggregate functions are used in SQL statements to perform calculations on a set of values. The syntax for using aggregate functions in SQL depends on the specific function being used. For example, the syntax for using the SUM function is:

SELECT SUM(column_name) FROM table_name;

4. Advantages of Aggregate Functions:
The use of aggregate functions in SQL has several advantages, including:
1. Improved Data Analysis: Aggregate functions provide a powerful and efficient way of summarizing and analyzing data stored in a database.
2. Improved Data Management: Aggregate functions make it easier to manage the data in a database, by providing a way to summarize and analyze data.
3. Improved Data Retrieval: Aggregate functions provide a more efficient way of retrieving specific data from a database, by summarizing and analyzing data.
