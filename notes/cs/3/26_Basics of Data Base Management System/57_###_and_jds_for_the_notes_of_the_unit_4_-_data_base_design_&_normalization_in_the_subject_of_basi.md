Unit 4 - Data Base Design & Normalization in the subject of Basics of Database Management System covers the following topics:

1. Database Design:
Database design is the process of creating a database that is optimized for a specific set of requirements. It involves defining the structure of the database, including the tables, columns, and relationships between tables, as well as the data that will be stored in the database.

2. Normalization:
Normalization is the process of organizing a database to minimize data redundancy and improve data integrity. Normalization involves dividing a database into smaller tables, each of which represents a different aspect of the data, and establishing relationships between tables using primary and foreign keys.

3. Normal Forms:
Normal forms are the levels of normalization that a database can achieve. There are several normal forms, including First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), and so on.

4. Job Descriptions (JDs):
A job description (JD) is a document that outlines the responsibilities, duties, and requirements of a specific job. JDs are used in database design to define the data that will be stored in the database, as well as the relationships between data elements.

In conclusion, Unit 4 - Data Base Design & Normalization in the subject of Basics of Database Management System covers the topics of database design, normalization, normal forms, and job descriptions (JDs). Understanding these concepts is essential for creating effective and efficient databases that meet the specific requirements of a given application.
