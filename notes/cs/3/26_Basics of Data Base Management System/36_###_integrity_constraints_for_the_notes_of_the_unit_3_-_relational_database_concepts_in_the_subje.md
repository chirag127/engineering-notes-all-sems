### integrity constraints for the notes of the Unit 3 - Relational Database Concepts in the subject of Basics of Data Base Management System

Unit 3 - Relational Database Concepts in the subject of Basics of Database Management System covers the following topic:

1. Integrity Constraints:
Integrity constraints are rules that are used to ensure the accuracy and consistency of data stored in a database. They are used to enforce business rules and to prevent data anomalies.

2. Types of Integrity Constraints:
There are several types of integrity constraints, including:
1. Primary Key Constraints: This constraint ensures that each record in a table has a unique identifier, known as a primary key.
2. Foreign Key Constraints: This constraint ensures that a foreign key in one table refers to a valid primary key in another table.
3. Not Null Constraints: This constraint ensures that a column in a table cannot contain a null value.
4. Unique Constraints: This constraint ensures that the values in a column are unique.
5. Check Constraints: This constraint ensures that the values in a column meet a specified condition.

3. How it works:
To enforce integrity constraints in a database, the following steps are taken:
1. Defining the integrity constraints in the database schema.
2. Enforcing the integrity constraints during data entry and modification.
3. Monitoring the integrity constraints to ensure that they are being enforced correctly.

4. Advantages:
The use of integrity constraints in a database has several advantages, including:
1. Improved data accuracy: Integrity constraints help to ensure that the data stored in the database is accurate and consistent.
2. Improved data security: Integrity constraints help to prevent unauthorized access to the data stored in the database.
3. Improved data consistency: Integrity constraints help to ensure that the data stored in the database is consistent, even when multiple users are accessing and modifying the data.

In conclusion, integrity constraints are an important aspect of relational database concepts in the subject of Basics of Database Management System. They help to ensure the accuracy, security, and consistency of data stored in a database.
