Unit 4 - Data Base Design & Normalization in the subject of Basics of Database Management System covers the following topic:

1. MVD (Multi-Valued Dependency):
A multi-valued dependency (MVD) is a type of constraint that exists between two or more attributes in a relational database. It states that the value of one attribute determines the values of another attribute, but not vice versa.

2. Importance of MVD:
MVD is important in database design and normalization because it helps to ensure that the data stored in a database is accurate and consistent. By identifying MVDs in a database, it is possible to determine which attributes should be separated into different tables to minimize data redundancy and improve data integrity.

3. How to Identify MVD:
To identify MVD in a database, the following steps can be taken:
1. Identify the attributes in the database that have a relationship with each other.
2. Determine the nature of the relationship between the attributes.
3. Determine whether the relationship is a function or a multi-valued dependency.

4. Normalization:
Normalization is the process of organizing data in a relational database to minimize data redundancy and improve data integrity. Normalization involves dividing data into different tables and establishing relationships between tables using primary and foreign keys.
