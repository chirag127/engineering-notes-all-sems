### entity integrity for the notes of the Unit 3 - Relational Database Concepts in the subject of Basics of Data Base Management System

Unit 3 - Relational Database Concepts in the subject of Basics of Database Management System covers the following topic:

1. Entity Integrity:
Entity integrity is a database constraint that ensures that each record in a database table has a unique identifier. This unique identifier, also known as a primary key, is used to identify each record in the table.

2. Purpose of Entity Integrity:
The purpose of entity integrity is to ensure that each record in a database table can be uniquely identified. This is important for several reasons, including:
1. Data retrieval: Unique identifiers are used to retrieve specific records from a database table.
2. Data relationships: Unique identifiers are used to establish relationships between records in different database tables.
3. Data consistency: Unique identifiers ensure that records in a database table are not duplicated, which helps to maintain the consistency of the data.

3. Implementing Entity Integrity:
Entity integrity can be implemented in a database by defining a primary key for each table. The primary key is a unique identifier for each record in the table and is used to enforce entity integrity.

4. Primary Key Constraints:
Primary key constraints are database constraints that enforce entity integrity by ensuring that each record in a database table has a unique primary key. Primary key constraints can be implemented using database management software or by using database programming languages.

In conclusion, entity integrity is an important concept in the subject of Basics of Database Management System. It ensures that each record in a database table can be uniquely identified, which is important for data retrieval, data relationships, and data consistency. Entity integrity is implemented by defining a primary key for each table and enforcing it using primary key constraints. Understanding entity integrity is essential for creating effective and efficient relational databases.
