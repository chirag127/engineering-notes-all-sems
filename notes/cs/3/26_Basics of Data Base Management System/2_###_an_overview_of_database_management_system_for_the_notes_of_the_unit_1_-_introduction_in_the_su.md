### An overview of database management system for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

Unit 1 - Introduction in the subject of Basics of Database Management System (DBMS) covers the following topic:

1. Database Management System (DBMS):
DBMS is a software system that provides an interface for managing and organizing data stored in a database. It enables users to create, modify, and query data in a database, as well as control access to the data.

2. Types of DBMS:
There are several types of DBMS, including:
1. Relational DBMS: A relational DBMS stores data in tables, with each table representing a different type of data.
2. Hierarchical DBMS: A hierarchical DBMS stores data in a tree-like structure, with each node representing a different type of data.
3. Network DBMS: A network DBMS stores data in a network structure, with each node representing a different type of data.
4. Object-Oriented DBMS: An object-oriented DBMS stores data in objects, with each object representing a different type of data.

3. Advantages of DBMS:
DBMS has several advantages, including:
1. Data Integrity: DBMS ensures the accuracy and consistency of data stored in a database.
2. Data Security: DBMS provides mechanisms for controlling access to data stored in a database, ensuring that sensitive data is protected.
3. Data Sharing: DBMS enables multiple users to access and modify data stored in a database, making it easier to share data between different departments and organizations.
4. Data Backup and Recovery: DBMS provides mechanisms for backing up and recovering data stored in a database, ensuring that data is not lost in the event of a disaster.

In conclusion, Unit 1 - Introduction in the subject of Basics of Database Management System covers the basics of DBMS and its various types. The unit provides an overview of the advantages of DBMS, including data integrity, data security, data sharing, and data backup and recovery.
