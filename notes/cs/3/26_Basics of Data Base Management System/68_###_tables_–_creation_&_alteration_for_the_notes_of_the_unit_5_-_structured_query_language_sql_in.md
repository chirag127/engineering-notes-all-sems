### tables – creation & alteration for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System

Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System covers the following topics:

1. Tables:
Tables are the basic building blocks of a relational database. They are used to store data in a structured format, with each row representing a single record and each column representing an attribute of the record.

2. Table Creation:
Table creation is the process of creating a new table in a relational database. This involves defining the columns of the table, including the data type and constraints for each column.

3. Table Alteration:
Table alteration is the process of modifying an existing table in a relational database. This can involve adding new columns, modifying existing columns, or deleting columns.

4. SQL:
SQL (Structured Query Language) is a standard programming language used to manage relational databases. SQL provides a set of commands for creating, altering, and querying tables in a relational database.

5. CREATE TABLE Statement:
The CREATE TABLE statement is used to create a new table in a relational database. It is used to specify the columns of the table, including the data type and constraints for each column.

6. ALTER TABLE Statement:
The ALTER TABLE statement is used to modify an existing table in a relational database. It is used to add, modify, or delete columns in an existing table.

In conclusion, Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System covers the topics of tables, table creation, and table alteration in a relational database. The unit covers the use of SQL commands, including the CREATE TABLE and ALTER TABLE statements, for creating and modifying tables in a relational database. Understanding these concepts is essential for managing and querying data in a relational database.
