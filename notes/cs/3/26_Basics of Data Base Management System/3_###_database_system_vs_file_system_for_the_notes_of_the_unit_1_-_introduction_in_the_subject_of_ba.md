### database system vs file system for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

Unit 1 - Introduction to Basics of Database Management System:

In this unit, we will compare and contrast database systems and file systems. Both database systems and file systems are used to store and manage data, but they have different approaches and capabilities.

A file system is a method of organizing and storing data on a computer. In a file system, data is stored in individual files, which are organized into directories or folders. Each file contains a specific type of data, such as a text document, image, or audio file.

A database system, on the other hand, is a more sophisticated method of storing and managing data. In a database system, data is organized into tables, with each table containing related data. For example, a table might contain information about customers, with each row in the table representing a different customer and each column representing a different piece of information about the customer, such as name, address, and phone number.

One of the main advantages of a database system over a file system is that a database system provides more structured and organized data management. With a database system, it is easier to search, sort, and retrieve data, and to enforce data integrity and consistency.

Another advantage of a database system is that it provides better security and privacy. In a file system, data is stored in individual files, which can be easily accessed by unauthorized users. In a database system, however, access to data is controlled through user accounts and permissions, making it more difficult for unauthorized users to access sensitive data.

In conclusion, database systems and file systems are both methods of storing and managing data, but they have different approaches and capabilities. A file system is a simple method of organizing and storing data, while a database system provides more structured and organized data management, as well as better security and privacy. When deciding which method to use, it is important to consider the specific requirements of the data being stored and the goals of the data management system.
