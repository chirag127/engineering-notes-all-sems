1. B-Tree Index: A B-Tree index is a type of index that is used to store data in a balanced tree structure. B-Tree indices are used to improve the performance of SELECT, INSERT, and UPDATE operations.

2. Hash Index: A Hash index is a type of index that is used to store data in a hash table. Hash indices are used to improve the performance of SELECT operations.

3. Bitmap Index: A Bitmap index is a type of index that is used to store data in a bitmap format. Bitmap indices are used to improve the performance of SELECT operations.
