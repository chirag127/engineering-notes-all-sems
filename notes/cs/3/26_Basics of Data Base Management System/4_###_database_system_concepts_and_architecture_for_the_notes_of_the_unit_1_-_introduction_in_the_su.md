### database system concepts and architecture for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

Unit 1 - Introduction to Basics of Database Management Systems covers the following topics:

1. Database System Concepts:
A database system is a collection of data that is organized in a specific manner for efficient retrieval and manipulation. The concepts of a database system include data structures, data models, data manipulation languages, and database management systems.

2. Data Structures:
Data structures are the ways in which data is organized in a database. Some common data structures used in database systems include tables, records, and fields.

3. Data Models:
Data models are the ways in which data is represented in a database. Some common data models used in database systems include the relational model and the object-oriented model.

4. Data Manipulation Languages:
Data manipulation languages are the languages used to manipulate data in a database. Some common data manipulation languages used in database systems include SQL (Structured Query Language) and NoSQL (Not Only SQL).

5. Database Management Systems:
Database management systems (DBMS) are software systems that are used to manage and manipulate data in a database. Some common database management systems include Oracle, MySQL, and Microsoft SQL Server.

6. Database Architecture:
Database architecture is the design and structure of a database system. It includes the physical components of the system, such as storage devices and servers, as well as the logical components, such as tables and fields.

In conclusion, Unit 1 - Introduction to Basics of Database Management Systems provides an overview of the concepts and architecture of database systems. The unit covers topics such as data structures, data models, data manipulation languages, database management systems, and database architecture. Understanding these concepts is essential for working with database systems and managing data effectively.
