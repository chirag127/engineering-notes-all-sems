Unit 3 - Relational Database Concepts in the subject of Basics of Database Management System:

The relational database is a type of database management system that is based on the relational model. In a relational database, data is organized into tables, with each table representing a different type of data. The tables in a relational database are related to each other through relationships, which define the links between the tables.

The relational model was first introduced by Dr. E.F. Codd in 1970, and has since become the most widely used type of database management system. The relational model is based on the idea of representing data as a set of relations, which are similar to tables in a spreadsheet. Each relation contains a set of rows and columns, with each row representing a different record and each column representing a different field.

The relational model provides several advantages over other types of database management systems, including:

1. Structured data: The relational model provides a structured way of organizing data, which makes it easier to search, sort, and retrieve data.

2. Data integrity: The relational model provides several mechanisms for enforcing data integrity, such as constraints and triggers, which help to ensure that the data in the database is accurate and consistent.

3. Scalability: The relational model is highly scalable, which means that it can be used to manage large amounts of data.

4. Flexibility: The relational model is flexible, which means that it can be used to store and manage a wide variety of data types, including text, numbers, and images.

In conclusion, the relational database is a type of database management system that is based on the relational model. The relational model provides several advantages over other types of database management systems, including structured data, data integrity, scalability, and flexibility.
