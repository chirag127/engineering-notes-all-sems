2. Variables and Constants: PL/SQL supports variables and constants, which can be used to store and manipulate data in your code. Variables can be used to store values that change, while constants are used to store values that do not change.

3. Control Structures: PL/SQL supports a variety of control structures, including conditional statements, loops, and exception handling. These control structures allow you to control the flow of your code, and to handle errors and exceptions in a controlled manner.

4. Stored Procedures and Functions: PL/SQL supports stored procedures and functions, which are reusable blocks of code that can be executed from within your code. Stored procedures and functions can be used to perform complex operations, and to encapsulate business logic in a database.

5. Triggers: PL/SQL supports triggers, which are special procedures that are executed automatically in response to specific events, such as an INSERT, UPDATE, or DELETE statement. Triggers can be used to enforce business rules, and to maintain the integrity of your data.
