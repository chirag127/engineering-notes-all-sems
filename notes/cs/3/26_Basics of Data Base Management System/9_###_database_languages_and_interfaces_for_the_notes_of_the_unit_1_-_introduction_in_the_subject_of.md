### database languages and interfaces for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

Unit 1 - Introduction to Basics of Database Management System covers the following topic:

1. Database Languages:
Database languages are used to interact with a database management system. There are several types of database languages, including:
1. Data Definition Language (DDL): used to define the structure of a database, including tables, fields, and relationships between tables.
2. Data Manipulation Language (DML): used to manipulate data within a database, including adding, updating, and deleting records.
3. Data Control Language (DCL): used to control access to a database, including granting and revoking permissions.

2. Database Interfaces:
Database interfaces are the means by which a user interacts with a database management system. There are several types of database interfaces, including:
1. Command Line Interface (CLI): a text-based interface that allows a user to interact with a database by entering commands.
2. Graphical User Interface (GUI): a graphical interface that allows a user to interact with a database using visual elements, such as buttons and menus.
3. Application Programming Interface (API): a set of programming interfaces that allow a developer to interact with a database programmatically.

3. Advantages:
Using database languages and interfaces has several advantages, including:
1. Ease of use: Database interfaces make it easy for a user to interact with a database, regardless of their technical expertise.
2. Flexibility: Different database interfaces can be used to meet the specific needs of a user or application.
3. Integration: Database interfaces can be integrated with other software systems, allowing for seamless integration with other applications.

In conclusion, database languages and interfaces are important components of a database management system. They provide the means by which a user or developer can interact with a database, and offer several advantages, including ease of use, flexibility, and integration with other software systems.
