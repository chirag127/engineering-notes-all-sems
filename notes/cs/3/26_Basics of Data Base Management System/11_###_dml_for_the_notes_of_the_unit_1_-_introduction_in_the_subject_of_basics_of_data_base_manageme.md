### DML for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

Unit 1 - Introduction to Basics of Database Management System:

Data Manipulation Language (DML) is a subset of SQL (Structured Query Language) that is used to manage data stored in a database. DML includes commands for inserting, updating, and deleting data in a database.

Here is a brief overview of the main DML commands:

1. SELECT: The SELECT command is used to retrieve data from a database. You can specify the columns you want to retrieve and apply various filters to limit the data that is returned.

2. INSERT: The INSERT command is used to add new records to a database. You can specify the values for each column in the record.

3. UPDATE: The UPDATE command is used to modify existing records in a database. You can specify the values for one or more columns in a record and apply filters to limit the records that are updated.

4. DELETE: The DELETE command is used to remove records from a database. You can apply filters to limit the records that are deleted.

When using DML commands, it is important to understand the basic syntax of SQL and to be familiar with the structure of the database you are working with. You should also be aware of the potential consequences of making changes to a database, such as data loss or corruption.

In conclusion, DML is an important aspect of database management, and includes commands for inserting, updating, and deleting data in a database. To effectively use DML, it is important to understand the basic syntax of SQL and to be familiar with the structure of the database you are working with.
