## Unit 9 - Database Security

Database security is the protection of data stored in a database from unauthorized access, modification, or deletion. Database security involves the following aspects:

- **Data confidentiality**: ensuring that only authorized users can access the data in the database.
- **Data integrity**: ensuring that the data in the database is accurate, consistent, and reliable.
- **Data availability**: ensuring that the data in the database is accessible to authorized users whenever they need it.
- **Data authentication**: ensuring that the identity of the users and the sources of the data are verified.
- **Data authorization**: ensuring that the users and the sources of the data have the appropriate permissions to access, modify, or delete the data in the database.

Some of the common threats to database security are:

- **SQL injection**: a type of attack that exploits a vulnerability in the database application by inserting malicious SQL statements into the user input, which are then executed by the database server.
- **Data theft**: a type of attack that involves stealing sensitive or confidential data from the database, either by accessing the database directly or by intercepting the data in transit.
- **Data tampering**: a type of attack that involves modifying or deleting data in the database, either by accessing the database directly or by intercepting the data in transit.
- **Denial of service**: a type of attack that involves overwhelming the database server with requests or traffic, preventing legitimate users from accessing the database.
- **Malware**: a type of attack that involves installing malicious software on the database server or the database application, which can compromise the data or the functionality of the database.

Some of the common techniques to enhance database security are:

- **Encryption**: a technique that involves transforming the data into an unreadable form, using a secret key, so that only authorized users with the key can decrypt and access the data.
- **Auditing**: a technique that involves recording and monitoring the activities and events that occur in the database, such as who accessed the data, when, and what changes were made.
- **Backup and recovery**: a technique that involves creating and storing copies of the data in the database, in case of data loss or corruption, and restoring the data from the copies when needed.
- **Access control**: a technique that involves defining and enforcing rules and policies that specify who can access the data in the database, and what operations they can perform on the data.
- **Firewall**: a technique that involves using a software or hardware device that filters and blocks the incoming and outgoing network traffic to and from the database server, based on predefined rules and criteria.
