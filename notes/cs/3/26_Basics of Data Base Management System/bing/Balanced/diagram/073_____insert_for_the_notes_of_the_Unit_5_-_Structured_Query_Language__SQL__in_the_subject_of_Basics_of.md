### Unit 5 - Structured Query Language (SQL)

- SQL is a standard language for creating, manipulating, and querying data in relational databases.
- SQL has three main components: Data Definition Language (DDL), Data Manipulation Language (DML), and Data Query Language (DQL).
- DDL is used to define the structure and schema of the database, such as creating, altering, and dropping tables, views, indexes, and constraints.
- DML is used to insert, update, delete, and merge data in the database tables.
- DQL is used to retrieve and manipulate data from the database tables, such as selecting, joining, grouping, filtering, sorting, and aggregating data.
- SQL also supports various functions, operators, expressions, clauses, and keywords to perform various operations and calculations on the data.
- SQL is a declarative language, which means that it specifies what data to retrieve or manipulate, not how to do it.
- SQL is a set-based language, which means that it operates on sets or collections of data, not on individual records or values.
- SQL is a case-insensitive language, which means that it does not distinguish between uppercase and lowercase letters in keywords, identifiers, or literals.
- SQL follows a standard syntax and grammar, which consists of statements, commands, clauses, and terms, separated by semicolons, commas, parentheses, and spaces.
- SQL statements are executed by a database management system (DBMS), which interprets and executes the SQL commands and returns the results to the user or application.
