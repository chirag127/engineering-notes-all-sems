### Views of Data – Levels of Abstraction

- Views of data are the ways of representing the data in a database system at different levels of abstraction.
- Abstraction is the process of hiding the unnecessary details and showing only the essential features to the users.
- There are three levels of data abstraction in a database system: physical, logical, and view level.
- Physical level: This is the lowest level of data abstraction. It describes how the data is actually stored in the storage devices and the access methods used to retrieve it. It also reveals the data structures, file organizations, and indexes used to optimize the performance of the system. The physical level is also called the internal level or the implementation level.
- Logical level: This is the middle level of data abstraction. It describes what data is stored in the database and the relationships among the data. It also defines the constraints, keys, and integrity rules that apply to the data. The logical level is also called the conceptual level or the schema level. It is independent of the physical level and can be changed without affecting the physical level.
- View level: This is the highest level of data abstraction. It describes how the data is seen by different users and applications. It also hides some details of the data from the users to provide security and simplicity. The view level is also called the external level or the user level. It is dependent on the logical level and can be changed without affecting the logical level.
