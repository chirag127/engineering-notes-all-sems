### Storage Management

Storage management is the method by which organizations ensure data integrity, access, policy/regulation compliance, and effective storage resource use. It involves developing a plan to provision, configure, back up, and monitor data storage infrastructure to prevent data loss, performance slowdowns, and access problems.

Some of the topics covered in storage management for the notes of Unit 1 - Introduction in the subject of Basics of Data Base Management System are:

- Data storage in database: This refers to the capacity secured by the database management system in the memory of the server allocated for the database and the related operations. Data storage in database can be classified into three types: primary, secondary, and tertiary. Primary storage devices are the fastest and most expensive, such as the CPU's main memory, registers, and cache memory. Secondary storage devices are slower and cheaper, such as hard disks, optical disks, and magnetic tapes. Tertiary storage devices are the slowest and cheapest, such as CDs, DVDs, and flash drives.
- Storage hierarchy: This refers to the arrangement of storage devices in a database system according to their speed, cost, and capacity. The storage hierarchy typically follows the principle of locality, which states that data that is accessed frequently should be stored in faster and more expensive devices, while data that is accessed infrequently should be stored in slower and cheaper devices. The storage hierarchy can be represented as a pyramid, with the primary storage devices at the top, the secondary storage devices in the middle, and the tertiary storage devices at the bottom.
- Storage allocation and access methods: This refers to the techniques used by the database management system to allocate space for data in the storage devices and to access data from the storage devices. Storage allocation can be done in two ways: contiguous and non-contiguous. Contiguous allocation means that data is stored in consecutive blocks of storage, which makes access faster but may cause fragmentation and waste of space. Non-contiguous allocation means that data is stored in scattered blocks of storage, which makes access slower but may reduce fragmentation and waste of space. Access methods can be classified into three types: sequential, direct, and indexed. Sequential access means that data is accessed in a fixed order, which is suitable for sequential devices such as magnetic tapes. Direct access means that data is accessed by specifying its address, which is suitable for random-access devices such as hard disks. Indexed access means that data is accessed by using an index that maps data values to their addresses, which is suitable for devices that support both sequential and direct access, such as optical disks.
- Storage resource management: This refers to the software tools and services that help organizations optimize the performance, availability, and utilization of their data storage infrastructure. Storage resource management can offer numerous benefits, such as reducing costs, improving efficiency, enhancing security, and enabling data analytics. Some of the general methods and services for storage resource management are: storage resource management software, consolidation of systems, multiprotocol storage arrays, storage tiers, strategic SSD deployment, hybrid cloud, scale-out systems, archive storage of infrequently accessed data, and elimination of duplicate data.
