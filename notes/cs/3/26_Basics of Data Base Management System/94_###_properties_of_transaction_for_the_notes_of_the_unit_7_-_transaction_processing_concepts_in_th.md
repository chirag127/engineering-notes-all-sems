### properties of transaction for the notes of the Unit 7 - Transaction Processing Concepts in the subject of Basics of Data Base Management System

Unit 7 - Transaction Processing Concepts in the subject of Basics of Database Management System covers the following topic:

1. Transactions:
A transaction is a unit of work that is performed in a relational database. Transactions are used to ensure that the data stored in a database is consistent and accurate.

2. Properties of Transactions:
Transactions have several important properties, including:
1. Atomicity: A transaction is atomic, meaning that it is either completed in its entirety or not at all. If a transaction is not completed, any changes made to the database are rolled back to their original state.
2. Consistency: A transaction must leave the database in a consistent state, meaning that the data stored in the database must meet all of the constraints and rules defined for the database.
3. Isolation: A transaction must be isolated from other transactions, meaning that the changes made by one transaction must not affect the outcome of another transaction.
4. Durability: The changes made by a transaction must be durable, meaning that they must persist even in the event of a system failure.

3. ACID Properties:
The properties of transactions are often referred to as the ACID properties, where ACID stands for Atomicity, Consistency, Isolation, and Durability. Understanding the ACID properties is essential for designing and managing transactions in a relational database.

In conclusion, Unit 7 - Transaction Processing Concepts in the subject of Basics of Database Management System covers the topic of transactions and their properties. Transactions are units of work that are performed in a relational database and are used to ensure that the data stored in a database is consistent and accurate. The properties of transactions include atomicity, consistency, isolation, and durability, which are often referred to as the ACID properties. Understanding the properties of transactions is essential for designing and managing transactions in a relational database.
