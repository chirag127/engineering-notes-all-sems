### attributes for the notes of the Unit 3 - Relational Database Concepts in the subject of Basics of Data Base Management System

Unit 3 - Relational Database Concepts in the subject of Basics of Data Base Management System covers the following topic:

1. Attributes:
Attributes are the characteristics of an entity in a relational database. They are used to describe the properties of an entity, such as its name, address, and phone number.

2. Types of Attributes:
There are several types of attributes, including:
1. Simple Attributes: Simple attributes represent a single value for an entity, such as a name or an address.
2. Composite Attributes: Composite attributes represent multiple values for an entity, such as a full name or a postal address.
3. Derived Attributes: Derived attributes are attributes that are calculated based on other attributes, such as the age of a person based on their date of birth.

3. Attribute Domains:
Attribute domains are the set of possible values that an attribute can take. For example, the domain of a phone number attribute may be a set of 10-digit numbers.

4. Attribute Constraints:
Attribute constraints are the restrictions placed on the values that an attribute can take. For example, a constraint on a phone number attribute may require that it be a 10-digit number.

5. Attribute Normalization:
Attribute normalization is the process of organizing the attributes of an entity in a relational database to minimize redundancy and improve the accuracy and consistency of the data.

In conclusion, Unit 3 - Relational Database Concepts in the subject of Basics of Data Base Management System covers the topic of attributes in a relational database. The unit covers the different types of attributes, including simple, composite, and derived attributes, as well as attribute domains and constraints. The unit also covers the concept of attribute normalization and the importance of organizing attributes to minimize redundancy and improve the accuracy and consistency of the data.
