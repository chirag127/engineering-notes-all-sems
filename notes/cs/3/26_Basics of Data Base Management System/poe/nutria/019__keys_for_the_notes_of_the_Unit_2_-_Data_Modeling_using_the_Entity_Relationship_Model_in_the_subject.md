
### Keys for the Notes of the Unit 2 - Data Modeling using the Entity Relationship Model in the Subject of Basics of Data Base Management System

1. An **entity** is an object or concept about which data is stored.
2. An **entity type** is a collection of entities that have the same attributes.
3. An **attribute** is a property or characteristic of an entity type.
4. A **relationship** is an association between two or more entities.
5. The **Entity Relationship Model** (ERM) is a graphical representation of entities and their relationships.
6. The **primary key** is a unique identifier for each entity in a given entity type.
7. The **foreign key** is a reference to the primary key of another entity type.
8. A **relationship type** is a collection of relationships between two or more entity types.
9. The **cardinality** of a relationship type is the number of entities associated with a given entity type.
10. The **degree** of a relationship type is the number of entity types associated with a given relationship type.
