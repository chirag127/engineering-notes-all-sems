
### Validation-Based Protocol for the Notes of Unit 8 - Concurrency Control Techniques in Basics of Database Management System

1. Validation-based protocols are used to ensure that the updates to the database are consistent with the initial state of the database. 
2. These protocols are based on the concept of “validation”, which is the process of verifying that the updates to the database are valid and consistent with the initial state of the database. 
3. Validation-based protocols are designed to prevent concurrent transactions from making conflicting updates to the same data item. 
4. The basic idea behind these protocols is to validate the updates to the database before allowing them to be committed. 
5. The validation process typically involves comparing the values of the data items before and after the transaction has been executed. 
6. If the values are different, then the transaction is rejected and the database is rolled back to its initial state. 
7. Validation-based protocols are used to ensure that transactions are not allowed to commit conflicting updates to the same data item. 
8. These protocols are also used to ensure that transactions are not allowed to commit updates that violate the integrity constraints of the database. 
9. Validation-based protocols are used in many database management systems, including Oracle, SQL Server, and MySQL.
