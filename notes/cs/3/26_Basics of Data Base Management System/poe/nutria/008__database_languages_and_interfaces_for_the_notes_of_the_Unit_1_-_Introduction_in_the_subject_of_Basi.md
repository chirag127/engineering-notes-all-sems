
### Database Languages and Interfaces

1. Structured Query Language (SQL): SQL is the standard language for interacting with relational databases. It is used to create, update, and delete data, as well as to query and manipulate data stored in relational databases.
2. Data Definition Language (DDL): DDL is a language used to define the structure of a database, including the tables, columns, and relationships between them.
3. Data Manipulation Language (DML): DML is a language used to manipulate the data stored in a relational database, such as inserting, updating, and deleting records.
4. Database Interfaces: Database interfaces are software programs that allow users to interact with a database. Examples of database interfaces include graphical user interfaces (GUI), web-based interfaces, and command-line interfaces.
