
### Keys Constraints for the Notes of the Unit 3 - Relational Database Concepts 

1. Primary Key: A primary key is a field in a table which uniquely identifies each row/record in a database table. A primary key is a combination of fields which uniquely identify a record in a database table.

2. Foreign Key: A foreign key is a field in a table that is used to establish a link between two tables. A foreign key is a field in one table that is linked to the primary key of another table.

3. Unique Key: A unique key is a field in a table which uniquely identifies each row/record in a database table. A unique key is a combination of fields which uniquely identify a record in a database table.

4. Composite Key: A composite key is a combination of two or more fields in a table which uniquely identifies each row/record in a database table.

5. Candidate Key: A candidate key is a field in a table which uniquely identifies each row/record in a database table. A candidate key is a combination of fields which uniquely identify a record in a database table.

6. Super Key: A super key is a combination of two or more fields in a table which uniquely identifies each row/record in a database table.

7. Alternate Key: An alternate key is a field in a table which uniquely identifies each row/record in a database table. An alternate key is a combination of fields which uniquely identify a record in a database table.
