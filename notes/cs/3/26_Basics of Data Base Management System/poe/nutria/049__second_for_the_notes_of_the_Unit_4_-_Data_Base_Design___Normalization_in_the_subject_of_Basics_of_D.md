
### Unit 4 - Database Design & Normalization

* Database design is the process of creating a logical data structure for a database. It involves the planning, modeling, and optimization of data in order to ensure that the data is stored in a way that is efficient and effective.
* Normalization is the process of organizing data in a database to minimize duplication and redundancy. The goal of normalization is to create a structure that is easy to maintain and update, while also ensuring data integrity.
* In order to design a database effectively, it is important to understand the relationships between the different entities in the database. This is done by creating an Entity Relationship Diagram (ERD).
* The first step in normalizing a database is to identify the entities and their relationships. Once this is done, the database can be broken down into smaller, more manageable parts.
* The next step is to identify the attributes that are associated with each entity. These attributes can then be used to create tables and columns in the database.
* The final step is to create the relationships between the tables. This is done by creating foreign keys, which are columns that reference other tables.
* Normalization is an important part of database design and is essential for ensuring data integrity and efficiency. It is also important to note that normalization is not a one-time process, and should be revisited regularly to ensure that the database remains normalized.
