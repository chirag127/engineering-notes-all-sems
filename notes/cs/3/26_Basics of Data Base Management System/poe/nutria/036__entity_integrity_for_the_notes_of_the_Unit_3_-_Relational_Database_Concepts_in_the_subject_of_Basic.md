
### Entity Integrity 

1. Entity integrity is a property of relational databases in which each row of a table must have a unique identifier. This means that each row must have a primary key that is different from any other row in the same table. 

2. Entity integrity ensures that each row in a table is uniquely identified and that no two rows can have the same primary key value.

3. Entity integrity is important for maintaining the accuracy and integrity of data in a relational database. Without it, data could be duplicated or lost, leading to incorrect or incomplete results. 

4. Entity integrity is also important for ensuring data consistency across different tables. By ensuring that each row in a table has a unique primary key, it is easier to join tables together and ensure that the data is consistent between them.
