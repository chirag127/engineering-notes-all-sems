

### Aggregate Functions for Unit 5 - Structured Query Language (SQL)

1. **AVG()**: This aggregate function is used to calculate the average value of a given set of values.

2. **COUNT()**: This aggregate function is used to count the number of rows in a table.

3. **MAX()**: This aggregate function is used to find the maximum value of a given set of values.

4. **MIN()**: This aggregate function is used to find the minimum value of a given set of values.

5. **SUM()**: This aggregate function is used to calculate the sum of a given set of values.
