
### DML for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System

* Data Manipulation Language (DML) is a language used to query and manipulate data in a database.
* Structured Query Language (SQL) is a popular language used to access and manipulate databases.
* SQL statements can be used to retrieve, add, delete, and update data in a database.
* SQL statements can also be used to create and modify database objects such as tables, views, and stored procedures.
* SQL statements can be used to join multiple tables together to create complex queries.
* SQL statements can also be used to control user access to the database.
