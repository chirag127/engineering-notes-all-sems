
### SQL Operators and Their Procedure

1. **SELECT** - Used to select data from a database. It allows users to specify columns, tables, and conditions for the data to be retrieved.

2. **INSERT** - Used to add new records to a table.

3. **UPDATE** - Used to modify existing records in a table.

4. **DELETE** - Used to delete existing records from a table.

5. **JOIN** - Used to combine data from two or more tables.

6. **CREATE** - Used to create objects such as tables, views, and stored procedures in a database.

7. **ALTER** - Used to modify the structure of a database object.

8. **DROP** - Used to delete objects such as tables, views, and stored procedures from a database.
