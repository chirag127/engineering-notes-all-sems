
### Relations & Relational Database Schema

1. A **relation** is a mathematical concept which represents a table of values. It is composed of columns (attributes) and rows (tuples).

2. A **relational database schema** is a logical structure which describes the structure of a database and the relationships between different tables and fields.

3. In a relational database, data is organized into tables. Each table consists of columns (attributes) and rows (tuples).

4. Each table has a unique name and consists of a set of columns with specific data types.

5. The relationships between different tables in a database is described by the **database schema**.

6. The database schema describes the structure of the database, the relationships between different tables and fields, and the constraints that must be followed.

7. A **primary key** is a field in a table which uniquely identifies a row in the table.

8. A **foreign key** is a field in a table which references a primary key in another table.

9. A **referential integrity constraint** is a constraint which ensures that foreign keys reference valid primary keys.

10. A **normalization** is the process of organizing a database into smaller, more efficient tables.
