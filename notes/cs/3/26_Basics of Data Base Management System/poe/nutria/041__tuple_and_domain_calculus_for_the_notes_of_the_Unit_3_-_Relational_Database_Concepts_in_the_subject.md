
### Tuple and Domain Calculus for Relational Database Concepts

1. A **tuple** is a single record in a database table. It is a set of attributes that describe an entity, and each attribute has a value.

2. **Domain calculus** is a set of operations that can be used to manipulate tuples. The operations include selection, projection, union, and difference.

3. **Selection** is used to select a subset of tuples from a table that meet a certain condition.

4. **Projection** is used to select specific attributes from a set of tuples.

5. **Union** is used to combine two sets of tuples into a single set.

6. **Difference** is used to subtract one set of tuples from another set.
