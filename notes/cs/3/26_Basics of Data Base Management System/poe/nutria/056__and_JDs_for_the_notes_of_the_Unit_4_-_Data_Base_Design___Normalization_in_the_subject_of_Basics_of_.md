
### Unit 4 - Database Design & Normalization 

1. Database Design: Database design is the process of designing a database structure to store and manage data efficiently. It involves a number of activities such as creating a logical data model, developing a physical data model, and normalizing the data.

2. Normalization: Normalization is a process of organizing data into related tables. It helps to reduce data redundancy, improve data integrity, and simplify queries. Normalization involves the use of normal forms which are the rules for organizing data into tables.

3. Normal Forms: Normal forms are the rules for organizing data into tables. There are several types of normal forms such as First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), and Boyce-Codd Normal Form (BCNF).

4. Database Refactoring: Database refactoring is the process of making changes to an existing database structure without changing the functionality. It involves restructuring tables and columns, splitting tables, and adding indexes.
