
### Stored Procedures for Unit 6 - PL/SQL in Basics of Database Management System

1. Stored procedures are a type of subprogram that can be stored in a database and called from other programs.
2. Stored procedures are used to encapsulate business logic in the database and provide access to data without exposing the underlying database structure.
3. Stored procedures can be written in the database's native language (e.g. PL/SQL in Oracle) or in an external language (e.g. Java in Oracle).
4. Stored procedures can accept input parameters and return multiple result sets.
5. Stored procedures can be used to improve performance by reducing the amount of data that needs to be sent over the network.
6. Stored procedures can be used to ensure data integrity by enforcing business rules at the database level.
7. Stored procedures can be used to improve security by restricting access to data and operations.
8. Stored procedures can be used to simplify complex queries by encapsulating the query logic in a single stored procedure.
