
### Normalization Using FD

* Normalization is the process of organizing data in a database in order to reduce data redundancy and improve data integrity.
* Normalization involves decomposing a table into smaller tables and defining relationships between them.
* A functional dependency (FD) is a relationship between two attributes, A and B, such that the value of A determines the value of B.
* In database design, functional dependencies are used to normalize the database.
* Normalization using FD involves breaking up a table into smaller tables, each with a set of attributes that are functionally dependent on one another.
* The normal forms (1NF, 2NF, 3NF, BCNF) are used to describe how normalized a database is.
* The 1NF (First Normal Form) is the simplest form of normalization and requires that each row in a table is unique and that all the columns are atomic.
* The 2NF (Second Normal Form) requires that all the attributes in a table are functionally dependent on the primary key.
* The 3NF (Third Normal Form) requires that all the attributes in a table are dependent on the primary key and nothing else.
* The BCNF (Boyce-Codd Normal Form) is the highest level of normalization and requires that all the attributes in a table are dependent on the primary key and nothing else.
* Normalization using FD is an important process in database design and can help to improve data integrity and reduce data redundancy.
