
### Relational Model Terminology – Domains

* Domain: A domain is a set of values from which one or more attributes of a relation can take their values.
* Attribute: An attribute is a property or characteristic of an entity that is represented by one or more columns in a relation.
* Entity: An entity is a real-world object or concept about which data is stored in a database.
* Relation: A relation is a set of attributes that describe a particular entity.
* Tuple: A tuple is a single record in a relation. It is composed of a set of values, one for each attribute of the relation.
* Cardinality: The cardinality of a relation is the number of tuples in the relation.
* Degree: The degree of a relation is the number of attributes in the relation.
