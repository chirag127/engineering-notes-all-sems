
### Intersection for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System

* Structured Query Language (SQL) is a programming language used to manage and manipulate data in relational databases.
* SQL is a language that is used to create, update, delete, and query data in a relational database.
* SQL is used to create and modify tables, views, indexes, and other database objects.
* SQL statements are used to retrieve data from the database, insert data into the database, update existing data in the database, and delete data from the database.
* SQL statements are structured in a specific syntax, which is the same regardless of the database system being used.
* SQL statements can be used to join tables together to create complex queries.
* SQL statements can be used to create views, which are virtual tables that can be used to query data from multiple tables.
* SQL statements can be used to create stored procedures, which are blocks of code that can be used to perform complex tasks.
* SQL statements can be used to create triggers, which are code that will be executed when certain conditions are met.
* SQL statements can be used to control user access and permissions to the database.
