
### Primary Key for the Notes of the Unit 2 - Data Modeling using the Entity Relationship Model in the Subject of Basics of Data Base Management System

1. A primary key is a field or set of fields in a table that uniquely identifies each record. 
2. It is the most important field in a table because it uniquely identifies each row in the table and helps to establish relationships between different tables. 
3. In the Entity Relationship Model, the primary key of a table is represented by a diamond shape. 
4. A primary key can consist of one or more fields. When more than one field is used, it is called a composite key. 
5. A primary key should not contain null values and should not be changed once it is set. 
6. It is important to choose a primary key that is not likely to change. Examples of good primary keys include an employee ID, a customer ID, or a product ID. 
7. Foreign keys are used to create relationships between different tables. A foreign key is a field in one table that is linked to the primary key of another table. 
8. The primary key of a table can be used as a foreign key in another table to create a relationship between the two tables.
