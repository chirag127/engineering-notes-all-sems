
### Basics of SQL for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System 

1. SQL stands for Structured Query Language and is a programming language used to manage and query relational databases. 
2. SQL commands are used to create, delete, update, and retrieve data from a database.
3. SQL statements are divided into two categories: data definition language (DDL) and data manipulation language (DML).
4. Data definition language (DDL) statements are used to create, modify, and delete database objects such as tables, views, and indexes.
5. Data manipulation language (DML) statements are used to insert, update, and delete data from a database.
6. SQL can also be used to create stored procedures, functions, and triggers.
7. SQL is a cross-platform language, meaning it can be used on multiple operating systems and databases.
8. SQL is a standard language for relational databases and is widely used in data warehousing, business intelligence, and analytics applications.
