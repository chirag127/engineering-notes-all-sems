
## Unit 9 - Database Security 

1. Database security is the process of protecting data stored in a database from unauthorized access, modification, or destruction. 
2. It involves the use of authentication and authorization techniques, as well as encryption, to ensure that only authorized users can access the data. 
3. Authentication is the process of verifying the identity of a user or a system. It typically involves the use of a username and password. 
4. Authorization is the process of determining what a user or system is allowed to do. It typically involves the use of access control lists or roles. 
5. Encryption is the process of encoding data so that it cannot be read or understood by unauthorized users. 
6. Database security also involves the use of firewalls, intrusion detection systems, and audit trails to monitor and control access to the database. 
7. Database security is an important part of overall system security and should be taken into consideration when designing and implementing any system.
