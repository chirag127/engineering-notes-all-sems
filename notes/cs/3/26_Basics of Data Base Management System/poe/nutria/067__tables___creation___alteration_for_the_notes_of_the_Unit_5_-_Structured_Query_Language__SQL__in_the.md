
### Tables – Creation & Alteration for the Notes of the Unit 5 - Structured Query Language (SQL) in the Basics of Data Base Management System

1. Tables are the foundation of a database, and are used to store information.
2. Tables are created using the `CREATE TABLE` statement in SQL.
3. When creating a table, the columns and their data types must be specified.
4. Tables can be altered using the `ALTER TABLE` statement in SQL.
5. The `ALTER TABLE` statement can be used to add, modify, or delete columns from a table.
6. It can also be used to add, modify, or delete constraints from a table.
7. When using the `ALTER TABLE` statement, the table must be specified before any changes can be made.
8. After making changes to a table, the `COMMIT` statement must be used to save the changes.
