
### Types of SQL Commands
1. **Data Definition Language (DDL)**: This type of SQL command is used to define the structure of a database. It is used to create, modify, and delete database objects such as tables, indexes, and views. Examples of DDL commands include `CREATE`, `ALTER`, and `DROP`.
2. **Data Manipulation Language (DML)**: This type of SQL command is used to manipulate the data stored in the database. It is used to insert, update, and delete data from the database. Examples of DML commands include `SELECT`, `INSERT`, and `DELETE`.
3. **Data Control Language (DCL)**: This type of SQL command is used to control access to the data stored in the database. It is used to grant and revoke permissions from users. Examples of DCL commands include `GRANT` and `REVOKE`.
