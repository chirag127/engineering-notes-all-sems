
### SQL Data Types and Literals

SQL supports a variety of data types, including:

* Numeric data types: `INT`, `FLOAT`, `DECIMAL`, `BIT`, `NUMERIC`, `SMALLINT`, `BIGINT`
* Date and time data types: `DATE`, `TIME`, `TIMESTAMP`
* Character data types: `CHAR`, `VARCHAR`, `LONGVARCHAR`, `TEXT`
* Binary data types: `BINARY`, `VARBINARY`, `LONGBINARY`, `IMAGE`

In addition to data types, SQL also supports literals. Literals are values that are not stored in the database, but are used in expressions. Literals include:

* Numeric literals: `123`, `3.14`, `1.0e-3`
* String literals: `'Hello World'`, `'John Doe'`
* Date literals: `'2021-03-30'`, `'03-30-2021'`
* Boolean literals: `TRUE`, `FALSE`
