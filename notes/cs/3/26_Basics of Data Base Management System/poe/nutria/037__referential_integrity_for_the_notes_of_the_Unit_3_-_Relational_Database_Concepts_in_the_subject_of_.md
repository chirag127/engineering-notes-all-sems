
### Referential Integrity for Unit 3 - Relational Database Concepts

1. Referential integrity is a concept used in relational database management systems to ensure data accuracy and consistency.
2. It ensures that any foreign key references in a table point to valid records in another table.
3. This means that any foreign key value must exist in the referenced table, or it must be set to NULL.
4. Referential integrity also ensures that any record in the referenced table cannot be deleted until all foreign key references to it have been removed.
5. Referential integrity is an important concept to ensure data accuracy and consistency in a relational database.
