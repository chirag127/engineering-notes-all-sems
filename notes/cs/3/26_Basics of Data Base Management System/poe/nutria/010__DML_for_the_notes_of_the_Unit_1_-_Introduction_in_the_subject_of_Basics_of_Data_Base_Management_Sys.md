
### DML for the notes of the Unit 1 - Introduction in the subject of Basics of Data Base Management System

1. Data Manipulation Language (DML) is a type of computer language used to manipulate data within a database.

2. It includes commands such as SELECT, INSERT, UPDATE, and DELETE, which are used to retrieve, add, modify, and delete data from a database.

3. DML is used to modify the data in a database, but it cannot be used to create or delete the structure of the database.

4. DML commands are used to perform operations such as creating views, inserting records, updating records, and deleting records.

5. DML is an important part of database management and is used to ensure the accuracy and integrity of the data stored in a database.
