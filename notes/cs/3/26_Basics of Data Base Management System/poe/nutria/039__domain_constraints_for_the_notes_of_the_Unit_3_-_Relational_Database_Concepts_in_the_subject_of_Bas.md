

### Domain Constraints

* A domain is a set of values from which one or more attributes of an entity can take their values.
* Domain constraints are the restrictions placed on the values that can be assigned to an attribute.
* Domain constraints are used to ensure data integrity.
* The most common domain constraints are:
    * **Not Null:** This constraint ensures that a value must be entered for the attribute.
    * **Unique:** This constraint ensures that no two entities can have the same value for an attribute.
    * **Check:** This constraint allows the user to define a condition that must be met for the value to be accepted.
    * **Foreign Key:** This constraint ensures that the value of an attribute is taken from the primary key of another entity.
* Domain constraints are enforced by the database management system.
