In this unit, we will cover the following topics related to Relational Database Concepts:

1. Introduction to Relational Database
  - Definition of Relational Database
  - Features of Relational Database
  - Advantages of Relational Database

2. Entity-Relationship Model
  - Definition of Entity-Relationship Model
  - Components of Entity-Relationship Model

3. Relational Data Model

  - Relational Data Model Terminologies

6. Database Design
  - Definition of Database Design

7. Database Management Systems (DBMS)
  - Definition of DBMS
  - Types of DBMS (Relational, Object-Oriented, Hierarchical, Network)

By the end of this unit, you should be able to understand the basic concepts of Relational Database, Entity-Relationship Model, Relational Data Model, Normalization, Structured Query Language (SQL), Database Design, and Database Management Systems (DBMS). These concepts are essential for designing and managing a Relational Database System.
