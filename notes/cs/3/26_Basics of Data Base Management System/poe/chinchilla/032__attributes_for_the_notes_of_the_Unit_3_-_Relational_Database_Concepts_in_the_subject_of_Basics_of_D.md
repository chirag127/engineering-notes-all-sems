### Attributes for the notes of the Unit 3 - Relational Database Concepts in the subject of Basics of Data Base Management System

In this unit, you will learn about the following concepts related to relational databases:

1. Introduction to Relational Databases:
   - Definition of a relational database
   - Advantages of using relational databases
   - Components of a relational database management system (RDBMS)
   - Examples of popular RDBMSs

2. Data Modeling:
   - Definition of data modeling
   - Types of data models (conceptual, logical, physical)
   - Entity-relationship (ER) modeling
   - Cardinality and relationships between entities

3. Relational Model:
   - Definition of the relational model
   - Components of the relational model (tables, attributes, keys)
   - Primary keys and foreign keys
   - Normalization and denormalization

4. Structured Query Language (SQL):
   - Definition of SQL
   - Basic SQL commands (SELECT, INSERT, UPDATE, DELETE)
   - Joins (inner, outer, self)
   - Subqueries and nested queries

5. Database Design:
   - Definition of database design
   - Steps in the database design process
   - Designing tables and relationships
   - Normalization and denormalization in database design

6. Database Administration:
   - Definition of database administration
   - Roles and responsibilities of a database administrator
   - Backup and recovery procedures
   - Security and access control

7. Database Applications:
   - Definition of database applications
   - Types of database applications (transaction processing systems, decision support systems, data warehousing)
   - Design considerations for database applications
   - Integration with other systems and technologies

By understanding these concepts, you will have a good foundation for working with relational databases and be able to design, implement, and manage them effectively.
