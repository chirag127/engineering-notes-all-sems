## Unit 5 - Structured Query Language (SQL)

Structured Query Language (SQL) is a standard language used for managing relational databases. It is a powerful tool for retrieving, manipulating and updating data stored in a database. In this unit, we will cover the following topics related to SQL:

1. Introduction to SQL
    - What is SQL?
    - Why is SQL important?
    - History of SQL

2. Basic SQL Commands
    - SELECT statement
    - FROM clause
    - WHERE clause
    - ORDER BY clause
    - LIMIT clause

3. Filtering and Sorting Data
    - Comparison operators
    - Logical operators
    - LIKE operator
    - DISTINCT keyword
    - GROUP BY clause
    - HAVING clause

4. Joins and Subqueries
    - INNER JOIN
    - OUTER JOIN
    - Subqueries

5. Database Administration with SQL
    - Creating tables
    - Inserting data
    - Updating data
    - Deleting data
    - Indexes and constraints

6. Advanced SQL Topics
    - Views
    - Stored procedures
    - Triggers
    - Transactions
    - Cursors

SQL is an essential skill for anyone interested in working with databases. It is widely used in the industry and provides a powerful set of tools for managing data. By mastering the concepts and techniques covered in this unit, you will be well equipped to work with databases and use SQL to perform complex data manipulations.
