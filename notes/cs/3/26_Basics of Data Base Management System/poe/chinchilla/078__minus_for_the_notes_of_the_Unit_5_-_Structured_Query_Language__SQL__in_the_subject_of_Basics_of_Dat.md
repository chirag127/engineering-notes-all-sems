### Unit 5 - Structured Query Language (SQL)

Structured Query Language (SQL) is a standard language used to manage and manipulate relational databases. It is a powerful tool used to retrieve, insert, update, and delete data from a database.

#### SQL Syntax

SQL syntax is simple and easy to understand. It consists of a set of commands that allow you to interact with the database. The basic syntax of SQL includes:

- SELECT: Used to retrieve data from a database
- INSERT: Used to insert data into a database
- UPDATE: Used to update data in a database
- DELETE: Used to delete data from a database

#### SQL Statements

SQL statements are used to perform specific tasks on a database. Some of the SQL statements include:

- CREATE: Used to create a database, table, or view
- ALTER: Used to modify the structure of a database, table, or view
- DROP: Used to delete a database, table, or view
- TRUNCATE: Used to remove all the data from a table
- COMMIT: Used to save the changes made to a database
- ROLLBACK: Used to undo the changes made to a database
- GRANT: Used to give privileges to a user
- REVOKE: Used to remove privileges from a user

#### SQL Clauses

SQL clauses are used to filter and sort data retrieved from a database. Some of the SQL clauses include:

- WHERE: Used to filter data based on a specific condition
- GROUP BY: Used to group data based on a specific column
- HAVING: Used to filter data based on a condition after grouping
- ORDER BY: Used to sort data in ascending or descending order
- LIMIT: Used to limit the number of rows returned from a query

#### SQL Functions

SQL functions are used to perform calculations on data retrieved from a database. Some of the SQL functions include:

- COUNT: Used to count the number of rows returned from a query
- SUM: Used to calculate the sum of a column
- AVG: Used to calculate the average of a column
- MAX: Used to find the maximum value in a column
- MIN: Used to find the minimum value in a column

#### Conclusion

SQL is a powerful language used to manage and manipulate relational databases. It is essential for anyone working with data to have a basic understanding of SQL. By mastering SQL, you can easily retrieve, insert, update, and delete data from a database.
