### SQL within PL/SQL

PL/SQL is a procedural language used to extend the capabilities of SQL. SQL can be used within PL/SQL to perform database operations. Here are some important points to remember about SQL within PL/SQL:

- SQL statements can be executed in PL/SQL using the EXECUTE IMMEDIATE statement.
- Variables can be used in SQL statements within PL/SQL by prefixing the variable name with a colon (:).
- Cursors can be used in PL/SQL to fetch data from SQL queries.
- SQL exceptions can be handled using the EXCEPTION block in PL/SQL.
- PL/SQL also provides a number of built-in SQL functions that can be used in SQL statements within PL/SQL.
- Dynamic SQL can be used within PL/SQL to dynamically construct SQL statements at runtime.
- PL/SQL also provides the ability to create and execute SQL scripts using the DBMS_SQL package.
- The SELECT INTO statement can be used in PL/SQL to assign the result of a SQL query to a variable.
- The FOR LOOP statement in PL/SQL can be used to loop through the result set of a SQL query.
- The INSERT, UPDATE, and DELETE statements can be used within PL/SQL to modify data in the database.
- Transactions can be managed in PL/SQL using the COMMIT and ROLLBACK statements.

By using SQL within PL/SQL, developers can take advantage of the powerful database manipulation capabilities of SQL while also having the ability to extend its functionality through procedural logic.
