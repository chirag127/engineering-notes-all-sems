### multiple granularity for the notes of the Unit 8 - Concurrency Control Techniques in the subject of Basics of Data Base Management System

Unit 8 - Concurrency Control Techniques in the subject of Basics of Database Management System covers the following topic:

1. Concurrency Control:
Concurrency control is the process of managing access to shared resources in a database system, such as tables and rows, so that multiple transactions can execute simultaneously without interfering with each other.

2. Multiple Granularity:
Multiple granularity refers to the level of detail at which concurrency control is applied in a database system. There are two main levels of granularity:
1. Fine-grained: Fine-grained concurrency control applies concurrency control at a very detailed level, such as at the level of individual rows or cells in a table.
2. Coarse-grained: Coarse-grained concurrency control applies concurrency control at a higher level, such as at the level of entire tables or sets of tables.

3. Advantages and Disadvantages:
Each level of granularity has its own advantages and disadvantages. Fine-grained concurrency control provides greater control over access to data, but can result in increased overhead and decreased performance. Coarse-grained concurrency control provides greater performance, but less control over access to data.

Multiple granularity refers to the level of detail at which concurrency control is applied in a database system, with two main levels of granularity being fine-grained and coarse-grained. Understanding multiple granularity is essential for managing access to shared resources in a database system and ensuring that multiple transactions can execute simultaneously without interfering with each other.
