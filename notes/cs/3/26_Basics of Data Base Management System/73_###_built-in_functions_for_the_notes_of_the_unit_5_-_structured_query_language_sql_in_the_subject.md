### built-in functions for the notes of the Unit 5 - Structured Query Language (SQL) in the subject of Basics of Data Base Management System

Unit 5 - Structured Query Language (SQL) in the subject of Basics of Database Management System covers the following topic:

1. SQL:
SQL (Structured Query Language) is a standard programming language used to manage relational databases. It is used to create, modify, and query databases, as well as to manage the data stored in databases.

2. Built-in Functions:
SQL provides a set of built-in functions that can be used to perform various operations on data stored in a database. Some of the most commonly used built-in functions include:
1. Aggregate Functions: Functions such as SUM, AVG, MIN, and MAX that are used to perform calculations on a set of values.
2. Date and Time Functions: Functions such as NOW, DATE, and TIME that are used to manipulate date and time values.
3. String Functions: Functions such as LENGTH, CONCAT, and SUBSTRING that are used to manipulate string values.
4. Numeric Functions: Functions such as ROUND and ABS that are used to perform mathematical operations on numeric values.

3. Advantages of Built-in Functions:
The use of built-in functions in SQL has several advantages, including:
1. Improved Data Analysis: Built-in functions make it easier to perform complex calculations and data analysis on data stored in a database.
2. Improved Data Management: Built-in functions make it easier to manage data stored in a database, by providing a set of tools for manipulating and analyzing data.
3. Improved Data Security: Built-in functions help to ensure that sensitive data is protected, by providing a set of tools for managing and analyzing data.

Built-in functions provide a set of tools for performing various operations on data stored in a database, including aggregate functions, date and time functions, string functions, and numeric functions.
