## Unit 3 - Relational Database Concepts

Unit 3 - Relational Database Concepts covers the following topics:

1. Relational Model:
The relational model is a data model used to represent data in a database. It is based on the idea of organizing data into tables, with each table representing a different type of data.

2. Tables:
Tables are the basic structure in a relational database. Each table consists of rows and columns, with each row representing a record and each column representing a field.

3. Primary Key:
A primary key is a unique identifier for each record in a table. It is used to ensure that each record can be uniquely identified and to enforce referential integrity between tables.

4. Foreign Key:
A foreign key is a column in one table that refers to the primary key of another table. It is used to enforce referential integrity between tables and to ensure that data is consistent across multiple tables.

5. Normalization:
Normalization is the process of organizing data in a relational database to minimize data redundancy and improve data integrity. Normalization involves dividing data into different tables and establishing relationships between tables using primary and foreign keys.

6. SQL:
SQL (Structured Query Language) is the language used to interact with a relational database. It is used to create tables, insert data into tables, update data in tables, and retrieve data from tables.

In conclusion, Unit 3 - Relational Database Concepts covers the basics of the relational model, including tables, primary keys, foreign keys, normalization, and SQL. Understanding these concepts is essential for working with relational databases and ensuring that data is stored and retrieved efficiently and accurately.
