### SQL within Pl/SL for the notes of the Unit 6 - PL/SQL in the subject of Basics of Data Base Management System

PL/SQL is a procedural language designed specifically for the Oracle Database Management System. It is used to create stored procedures, functions, triggers, and packages to manage and manipulate data within the database.

SQL statements can be included within PL/SQL code to interact with the database. The following are some of the common SQL statements used in PL/SQL:

1. SELECT: retrieves data from one or more tables in the database.

2. INSERT: adds new data to a table in the database.

3. UPDATE: modifies existing data in a table in the database.

4. DELETE: removes data from a table in the database.

5. COMMIT: saves changes to the database.

6. ROLLBACK: undoes changes to the database.

7. SAVEPOINT: creates a temporary checkpoint in a transaction, allowing you to undo changes made after the savepoint.

8. SET TRANSACTION: sets the properties of a transaction, such as the isolation level.

In PL/SQL, SQL statements can be executed dynamically using the EXECUTE IMMEDIATE statement or can be stored in a cursor for later execution. Cursors allow you to retrieve and manipulate data in a row-by-row fashion, which can be useful for processing large amounts of data.

PL/SQL also provides a number of built-in functions for working with data, such as converting data types, manipulating strings, and performing mathematical operations.

Overall, PL/SQL provides a powerful and flexible way to interact with the database using SQL within a procedural language, allowing you to manage and manipulate data effectively and efficiently.
