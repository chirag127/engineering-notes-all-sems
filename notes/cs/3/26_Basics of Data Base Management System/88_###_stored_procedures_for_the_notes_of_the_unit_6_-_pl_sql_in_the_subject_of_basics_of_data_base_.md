### stored procedures for the notes of the Unit 6 - PL/SQL in the subject of Basics of Data Base Management System

Unit 6 - PL/SQL in the subject of Basics of Data Base Management System covers the following topic:

1. Stored Procedures:
A stored procedure is a pre-compiled program that is stored in a relational database. Stored procedures are used to perform complex operations on data stored in a relational database, such as data validation, data processing, and data retrieval.

2. Advantages of Stored Procedures:
The use of stored procedures has several advantages, including:
1. Improved Data Security: Stored procedures can be used to enforce security policies by controlling access to data stored in a relational database.
2. Improved Data Integrity: Stored procedures can be used to enforce data integrity by validating data before it is stored in a relational database.
3. Improved Performance: Stored procedures can improve performance by reducing the amount of data that needs to be transferred between the database and the application.

3. PL/SQL:
PL/SQL is a procedural language used to manage relational databases. It is used to create and execute stored procedures in a relational database.

4. CREATE PROCEDURE Statement:
The CREATE PROCEDURE statement is used to create a new stored procedure in a relational database. It is used to specify the code that will be executed when the stored procedure is called.

5. EXECUTE Statement:
The EXECUTE statement is used to execute a stored procedure in a relational database. It is used to call the stored procedure and execute the code that is specified in the CREATE PROCEDURE statement.

In conclusion, Unit 6 - PL/SQL in the subject of Basics of Data Base Management System covers the topic of stored procedures in a relational database. Stored procedures are pre-compiled programs that are stored in a relational database and are used to perform complex operations on data stored in a relational database. The use of stored procedures provides several advantages, including improved data security, improved data integrity, and improved performance. Understanding stored procedures and PL/SQL is essential for managing data in a relational database.
