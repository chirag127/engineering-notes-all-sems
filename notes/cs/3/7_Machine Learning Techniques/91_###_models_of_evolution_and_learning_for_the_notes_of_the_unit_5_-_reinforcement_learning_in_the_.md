### Models of Evolution and Learning for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

Models of evolution and learning in reinforcement learning refer to the methods used to update the policy or value function of an agent in response to its interactions with the environment. 

1. Evolutionary algorithms: These algorithms use principles of natural selection and evolution to update the policy of an agent. The policies are represented as a population of candidate solutions, which are evaluated based on their performance in the environment. 

2. Temporal Difference (TD) learning: This is a model-free reinforcement learning algorithm that updates the value function of an agent based on the difference between the estimated value of the current state and the observed reward. 

3. Q-Learning: This is a model-free reinforcement learning algorithm that updates the action-value function of an agent based on the observed reward and the estimated value of the next state. 

4. SARSA: This is a model-based reinforcement learning algorithm that updates the action-value function of an agent based on the observed reward, the estimated value of the next state, and the action taken in the next state. 

5. Actor-Critic: This is a model-based reinforcement learning algorithm that uses two separate models, an actor and a critic, to update the policy and value function of an agent. 

These models are used to solve problems in reinforcement learning, such as finding the optimal policy for an agent to maximize its reward in an environment.
