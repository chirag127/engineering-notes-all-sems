### k-Nearest Neighbour Learning for the notes of the Unit 3 - DECISION TREE LEARNING in the subject of Machine Learning Techniques

k-Nearest Neighbour (k-NN) Learning is a type of instance-based learning algorithm that is used for both classification and regression tasks. It is based on the idea that the class or value of a given sample is determined by the class or value of its k nearest neighbors.

The following are some of the key concepts related to k-NN Learning:

1. Distance Metric: The distance metric is a measure of the similarity between two samples, and it is used to determine the k nearest neighbors.

2. k: k is the number of nearest neighbors used to determine the class or value of a given sample, and it is a hyperparameter that must be set before the algorithm is run.

3. Instance-Based Learning: Instance-Based Learning is a type of machine learning algorithm that is based on the idea that the class or value of a given sample is determined by the class or value of its nearest neighbors.

4. Lazy Learning: Lazy Learning is a type of machine learning algorithm that does not build a model until a prediction is needed, and it is used to reduce the computational cost of the algorithm.

5. Curse of Dimensionality: The curse of dimensionality is a phenomenon that occurs in high-dimensional spaces, and it is used to describe the difficulty of finding nearest neighbors in high-dimensional spaces.
