
### Locally Weighted Regression 

Locally Weighted Regression (LWR) is a non-parametric regression technique used in machine learning. It is a method for fitting a regression model to a set of data points by locally weighting the data points in the vicinity of the point of interest. This technique is used to predict the value of a given point based on the values of the surrounding points. 

The goal of LWR is to find a function that best fits the data points in the vicinity of the point of interest. This is done by assigning weights to each data point based on its distance from the point of interest. The weights are then used to compute the function that best fits the data points. 

The advantages of using LWR over other regression techniques include its ability to capture non-linear trends in the data, its ability to capture local trends, and its ability to handle large datasets. The disadvantages of using LWR include its high computational cost and its sensitivity to noise. 

In the context of decision tree learning, LWR can be used to determine the best split point for a given decision tree. It can also be used to determine the best attribute to split on. This is done by computing the weights for each attribute and then using the weights to determine the best split point. 

Overall, LWR is a useful non-parametric regression technique that can be used in machine learning to capture local trends in the data and to determine the best split point for a given decision tree.
