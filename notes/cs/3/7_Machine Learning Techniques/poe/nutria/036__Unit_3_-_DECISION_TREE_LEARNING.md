
## Unit 3 - DECISION TREE LEARNING

Decision Tree Learning is a type of supervised machine learning algorithm used for classification and regression tasks. It is a decision support tool that uses a tree-like model of decisions and their possible consequences, including chance event outcomes, resource costs, and utility. It is one of the most widely used and practical methods for supervised learning.

1. **Definition**: Decision Tree Learning is a supervised machine learning algorithm that uses a tree-like model of decisions and their possible consequences. It is used to solve classification and regression problems.

2. **Applications**: Decision Tree Learning is used in a variety of applications, such as medical diagnosis, credit scoring, fraud detection, and customer segmentation.

3. **Advantages**: Decision Tree Learning has several advantages, such as its ability to handle both numerical and categorical data, its scalability, and its interpretability.

4. **Disadvantages**: Decision Tree Learning has some disadvantages, such as its instability (small changes in the data can lead to large changes in the tree structure) and its potential to overfit the data.

5. **Algorithm**: The Decision Tree Learning algorithm involves constructing a decision tree from a given dataset. The algorithm starts with the root node, which contains the best attribute to split the dataset. Each branch of the tree corresponds to a value of the attribute, and each leaf node corresponds to a class label. The algorithm then recursively splits the dataset based on the best attribute until all the data points are classified.
