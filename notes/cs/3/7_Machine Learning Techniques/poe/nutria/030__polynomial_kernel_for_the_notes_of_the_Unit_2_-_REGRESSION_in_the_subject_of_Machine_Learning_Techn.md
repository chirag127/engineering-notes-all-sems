
### Polynomial Kernel for the Notes of the Unit 2 - Regression in the Subject of Machine Learning Techniques

* Polynomial kernels are used in Support Vector Machines (SVMs) for regression and classification tasks. 
* A polynomial kernel is a type of kernel function which takes two inputs, x and y, and computes a polynomial of degree n in x and y. 
* The polynomial kernel is a non-linear kernel and can be used to model complex relationships between the inputs. 
* The polynomial kernel can be used to model non-linear relationships between the input variables. 
* The polynomial kernel is a popular choice for regression tasks due to its ability to model complex relationships. 
* The polynomial kernel is defined as K(x,y) = (x.y + c)^n, where c is the offset and n is the degree of the polynomial. 
* The degree of the polynomial determines the complexity of the model and the number of parameters that need to be tuned. 
* The polynomial kernel is sensitive to outliers and can overfit the data if the degree is too high. 
* The polynomial kernel is a good choice for regression problems when the data is not linearly separable.
