

### Issues in SVM for the Notes of the Unit 2 - REGRESSION in the Subject of Machine Learning Techniques

1. SVM is prone to overfitting and can be difficult to train due to the large number of parameters.
2. SVM can be computationally expensive and time-consuming, especially when dealing with large datasets.
3. SVM is not suitable for non-linear data, as it relies on linear boundaries to separate data points.
4. SVM can be sensitive to outliers, as a single outlier can have a significant effect on the decision boundary.
5. SVM can struggle to handle noisy data, as it is more likely to be misclassified.
