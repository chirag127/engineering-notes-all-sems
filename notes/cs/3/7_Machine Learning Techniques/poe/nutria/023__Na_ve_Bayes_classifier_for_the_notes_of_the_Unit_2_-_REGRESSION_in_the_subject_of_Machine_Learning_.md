
### Naïve Bayes classifier for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

1. Naïve Bayes classifier is a supervised learning algorithm used in machine learning for classification problems. 
2. It is based on the Bayes theorem, which states that the probability of an event occurring is equal to the probability of the event given some evidence multiplied by the prior probability of the event. 
3. Naïve Bayes classifier uses a probabilistic approach to classify data points into different classes. 
4. It assumes that the features in the data are independent of each other and uses the probability of each feature to predict the class of the data point. 
5. Naïve Bayes classifier is used for both binary and multi-class classification problems. 
6. It is easy to implement and can be used for large datasets. 
7. However, it is prone to over-fitting and has a high bias. 
8. It is also sensitive to irrelevant features and can suffer from the curse of dimensionality.
