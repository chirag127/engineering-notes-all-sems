
### Well defined learning problems for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

1. Classification: This type of problem involves predicting a categorical label (e.g. spam/not spam, cancer/no cancer, etc.) based on a set of features.

2. Regression: This type of problem involves predicting a continuous value (e.g. stock price, temperature, etc.) based on a set of features.

3. Clustering: This type of problem involves grouping data into clusters (e.g. customer segmentation, image segmentation, etc.) based on a set of features.

4. Anomaly Detection: This type of problem involves detecting outliers (e.g. fraudulent transactions, malicious activities, etc.) based on a set of features.

5. Association Rule Learning: This type of problem involves finding associations between different items (e.g. market basket analysis, recommender systems, etc.) based on a set of features.
