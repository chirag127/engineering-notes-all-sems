
### Hyperplane for the Notes of the Unit 2 - REGRESSION in the Subject of Machine Learning Techniques

1. Regression is a type of supervised learning algorithm used to predict a continuous outcome.
2. A hyperplane is a decision boundary used to separate two or more classes in a classification problem.
3. In linear regression, the hyperplane is a straight line that best fits the data points.
4. In logistic regression, the hyperplane is a curved line that best separates the classes.
5. In other types of regression, the hyperplane is a higher-dimensional surface that best separates the classes.
6. The goal of the regression algorithm is to find the best hyperplane that minimizes the error between the predicted and actual values.
7. The process of finding the best hyperplane is called optimization and is often done using gradient descent.
8. The hyperplane can be used to make predictions on new data points by measuring the distance from the hyperplane to the data point.
