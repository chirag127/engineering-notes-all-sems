
### Information Gain for the Notes of the Unit 3 - DECISION TREE LEARNING in the Subject of Machine Learning Techniques

1. Information gain is a measure of the decrease in uncertainty brought about by observing a given attribute. 
2. It is used in decision tree learning to determine which attribute should be chosen as the root node in the tree. 
3. The attribute with the highest information gain is chosen as the root node. 
4. Information gain is calculated by comparing the entropy of the system before and after the attribute is observed. 
5. Entropy is a measure of the randomness or disorder of a system. 
6. The entropy of a system is calculated by summing the probabilities of each outcome multiplied by the logarithm of the probability. 
7. The entropy of a system decreases when the uncertainty of the system is reduced. 
8. Decision tree learning works by recursively partitioning the data into smaller and smaller subsets using the attribute with the highest information gain as the root node. 
9. This process is repeated until the subsets are pure or until a specified stopping criterion is met. 
10. The resulting decision tree can then be used to classify new data points.
