
### K-Nearest Neighbour Learning

K-Nearest Neighbour (KNN) Learning is a supervised machine learning technique used to classify data points based on their proximity to other data points in the same category. It is a non-parametric method, meaning that it does not make any assumptions about the underlying data distribution.

KNN works by assigning each data point a label based on the labels of its closest neighbours. The number of neighbours to consider is determined by the user, and is usually denoted by the letter 'K'. KNN is an instance-based learning algorithm, meaning that it does not build a model to make predictions, but instead relies on the data points themselves.

KNN is useful for classification tasks, such as determining whether a given image is a cat or a dog. It can also be used for regression tasks, such as predicting the price of a house based on its location.

KNN is a powerful tool for machine learning, but it does have some drawbacks. It is computationally expensive, as it requires computing the distance between each data point and its neighbours. Additionally, it is sensitive to outliers, meaning that a single outlier can have a large effect on the results.
