
### Unsupervised Learning for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. Unsupervised learning is a type of machine learning algorithm that uses data that is not labeled, classified or categorized. 
2. It aims to find patterns or relationships in data sets without the help of a human supervisor.
3. It is used to detect anomalies, to identify clusters of data points with similar properties, or to find data associations.
4. Artificial Neural Networks (ANNs) are a type of unsupervised learning algorithm. 
5. ANNs are composed of interconnected neurons that are used to process data and make decisions.
6. ANNs learn by adjusting weights and biases to minimize the error between the actual output and the desired output.
7. ANNs can be used for a variety of tasks, such as image recognition, object detection, and natural language processing.
8. ANNs are typically used in supervised learning tasks, where labeled data is used to train the network.
9. ANNs can also be used in unsupervised learning tasks, where unlabeled data is used to identify patterns and relationships in the data.
10. Unsupervised learning with ANNs is useful for clustering data points, discovering new patterns in data, and detecting anomalies.
