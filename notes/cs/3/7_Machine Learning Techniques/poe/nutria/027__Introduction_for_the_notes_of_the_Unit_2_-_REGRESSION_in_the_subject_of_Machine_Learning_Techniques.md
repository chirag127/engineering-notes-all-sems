
### Introduction to Unit 2 - Regression in Machine Learning Techniques

* Regression is a supervised machine learning technique used to predict a continuous variable from a set of independent variables.
* It is used to identify the relationships between the independent and dependent variables, and to make predictions about the future.
* Regression models can be used for a variety of tasks, such as predicting sales, forecasting stock prices, and predicting customer behaviour.
* Linear regression is the most common type of regression, and is used when the dependent variable is continuous.
* Logistic regression is used when the dependent variable is categorical.
* Polynomial regression is used when the dependent variable is non-linear.
* Regularization techniques are used to address overfitting, which is when a model is overly complex and does not generalize well.
* Regularization techniques include L1 regularization, L2 regularization, and elastic net regularization.
