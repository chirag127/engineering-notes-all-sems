
## Unit 5 - REINFORCEMENT LEARNING

1. Reinforcement Learning (RL) is a type of machine learning algorithm that allows an agent to learn how to behave in an environment by performing actions and learning from the rewards or punishments it receives. 
2. The goal of reinforcement learning is to maximize the reward the agent receives over time, while also exploring the environment and learning from it. 
3. RL algorithms are based on the idea of trial and error, where the agent tries different actions in order to achieve a goal. 
4. The agent receives a reward for taking an action, and this reward is used to update the agent's policy, which is the set of rules that determine what action the agent should take in a given situation. 
5. RL algorithms are used in a variety of applications, such as robotics, autonomous driving, and game playing. 
6. RL algorithms can be divided into two main categories: model-free and model-based. 
7. Model-free algorithms do not require the agent to have a model of the environment and learn by trial and error. 
8. Model-based algorithms require the agent to have a model of the environment and use it to plan ahead and select the best action. 
9. RL algorithms can also be divided into three main types: value-based, policy-based, and actor-critic. 
10. Value-based algorithms learn a value function that estimates the expected reward for taking a given action. 
11. Policy-based algorithms learn a policy, which is a mapping from states to actions. 
12. Actor-critic algorithms combine the ideas of value-based and policy-based algorithms. 
13. RL algorithms are used in many real-world applications, such as robotics, autonomous driving, and game playing.
