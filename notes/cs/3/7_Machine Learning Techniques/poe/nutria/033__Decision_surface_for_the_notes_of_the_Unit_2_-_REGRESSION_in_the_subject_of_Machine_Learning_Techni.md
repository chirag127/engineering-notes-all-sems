
### Decision Surface for the Notes of Unit 2 - REGRESSION in the Subject of Machine Learning Techniques

1. Regression is a supervised learning technique used to predict a continuous target variable from a set of input features.
2. The goal of regression is to find the best fitting model that describes the relationship between the input features and the target variable.
3. Linear regression is the most basic form of regression and is used to model the relationship between a single input feature and the target variable.
4. Multiple linear regression is used to model the relationship between multiple input features and the target variable.
5. Logistic regression is used to model the relationship between a single input feature and a binary target variable.
6. Polynomial regression is used to model the relationship between a single input feature and the target variable when the relationship is non-linear.
7. Support vector regression (SVR) is used to model the relationship between multiple input features and the target variable when the relationship is non-linear.
8. Decision trees are used to model the relationship between multiple input features and the target variable when the relationship is non-linear.
9. Neural networks are used to model the relationship between multiple input features and the target variable when the relationship is non-linear.
10. Regularization techniques are used to reduce the complexity of the model and to prevent overfitting.
