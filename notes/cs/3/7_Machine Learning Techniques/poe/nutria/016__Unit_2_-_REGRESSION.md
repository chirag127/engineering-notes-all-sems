
## Unit 2 - REGRESSION

Regression is a statistical technique used for predicting future values of a dependent variable based on past values of an independent variable. It is used to analyze the relationship between variables and identify patterns in data.

* Regression analysis is used to identify the relationship between one or more independent variables and a dependent variable. 
* It can be used to identify trends in data, predict future values, and make decisions based on the data. 
* Regression analysis is used in many different fields such as finance, economics, and marketing. 
* It is used to identify relationships between variables and to predict future values of a dependent variable. 
* Regression models are used to make predictions about future values based on past values. 
* Regression models can be used to identify patterns in data, to make decisions, and to predict future values. 
* Regression models can be used to identify relationships between variables and to make decisions based on the data.
