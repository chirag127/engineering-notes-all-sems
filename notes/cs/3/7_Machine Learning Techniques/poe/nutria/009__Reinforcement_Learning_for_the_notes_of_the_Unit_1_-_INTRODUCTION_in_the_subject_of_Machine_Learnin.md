
### Reinforcement Learning for the Notes of Unit 1 - INTRODUCTION in the Subject of Machine Learning Techniques

1. Reinforcement Learning (RL) is a type of Machine Learning technique that focuses on taking suitable action to maximize reward in a particular situation.

2. It is based on the idea of trial and error. An agent (or AI) learns from its environment by taking actions and receiving rewards or punishments for each action.

3. RL algorithms use a combination of exploration and exploitation to find the optimal solution. Exploration is the process of trying out different actions to find the best solution while exploitation is the process of taking the best action based on the knowledge acquired so far.

4. RL can be used in a variety of applications such as robotics, control systems, game playing, natural language processing and more.

5. RL algorithms use two main components: a policy and a value function. The policy determines the action that the agent should take in a given state, while the value function determines the expected reward for a given state or action.

6. RL algorithms are divided into two main categories: model-based and model-free. Model-based algorithms use a model of the environment to make decisions, while model-free algorithms use trial and error to learn the optimal policy.

7. RL algorithms can be further divided into on-policy and off-policy algorithms. On-policy algorithms learn the optimal policy by taking actions in the environment, while off-policy algorithms learn the optimal policy by observing the actions of other agents.
