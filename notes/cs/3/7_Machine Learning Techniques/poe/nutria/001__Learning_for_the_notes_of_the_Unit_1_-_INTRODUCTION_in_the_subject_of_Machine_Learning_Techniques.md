
### Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

1. Machine Learning (ML) is a type of Artificial Intelligence (AI) that enables computers to learn from data and experience without being explicitly programmed.
2. ML algorithms use data to identify patterns and make predictions.
3. ML techniques can be used for a variety of tasks, such as predicting customer behavior, fraud detection, and medical diagnosis.
4. ML techniques can be divided into three main categories: supervised learning, unsupervised learning, and reinforcement learning.
5. Supervised learning algorithms use labeled data to learn from past examples and make predictions about future data.
6. Unsupervised learning algorithms use unlabeled data to uncover patterns and relationships between data points.
7. Reinforcement learning algorithms use rewards and punishments to learn how to complete tasks.
8. ML algorithms can be applied to a variety of data types, such as images, text, and time-series data.
9. ML algorithms can also be used to optimize decision making processes, such as route optimization, portfolio optimization, and resource allocation.
