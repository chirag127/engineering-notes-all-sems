### Introduction for the notes of the Unit 5 - REINFORCEMENT LEARNING

1. Reinforcement Learning is a type of Machine Learning where an agent learns how to behave in an environment by performing actions and seeing the results. The key aspect is that the agent receives evaluative feedback in the form of rewards in the environment.
2. The goal of Reinforcement Learning is to determine an optimal way of behaving (policy) that maximizes the cumulative reward. The agent has to choose actions that lead to high reward.
3. In Reinforcement Learning, there is no supervisor to provide labels for good/bad actions. The agent has to discover them for itself by interacting with the environment. This trial-and-error process is what enables the agent to determine the optimal way of behaving.
4. Key components of Reinforcement Learning:

- Environment: The system that the agent interacts with. The environment provides feedback to the agent in the form of rewards.
- Agent: The entity that performs actions in the environment and learns from experience. The agent's goal is to maximize reward.
- Actions: The set of possible moves that the agent can take in the environment.
- Rewards: Feedback from the environment in response to the agent's actions. The agent's goal is to maximize cumulative reward.
- Policy: The agent's strategy for choosing actions. A good policy leads to higher rewards. The agent has to learn an optimal policy.
- Value Function: A function that estimates the long-term reward for a given state or state-action pair. The agent can use the value function to determine good policies.
