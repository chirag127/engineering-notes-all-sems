### Well defined learning problems for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques.

1. Predict the price of a house based on its characteristics like size, location, rooms, etc. This is a regression problem.

4. Cluster customers into distinct groups based on their shopping patterns. This is a clustering problem where we group similar data points together.
5. Anomaly detection: Identify unusual patterns in the data such as fraudulent credit card transactions. This is an anomaly detection problem.
