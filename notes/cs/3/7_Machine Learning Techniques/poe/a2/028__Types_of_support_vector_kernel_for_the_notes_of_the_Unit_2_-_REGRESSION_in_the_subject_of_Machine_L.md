### Types of support vector kernel for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques:

1. Linear kernel: It is the simplest kernel. It performs a linear mapping of the input space into a higher dimension feature space. It works well with data that can be separated by a linear hyperplane.

2. Polynomial kernel: It is a homogeneous polynomial kernel. It takes the form (x.y + r)^d, where d is the degree of the polynomial. It is more flexible than the linear kernel and can model complex nonlinear relationships. The degree of the polynomial and the constant term play an important role in controlling the flexibility of the kernel.

3. Radial basis function (RBF) kernel: It has a single parameter gamma that controls the width of the RBF. An RBF kernel leads to good results in general and is recommended as a default kernel. It is a good choice when we have no prior knowledge about the complexity of the data.

4. Sigmoid kernel: It is a kernel based on a sigmoid function. It has parameters to control the slope and offset of the sigmoid. It can model complex nonlinear relationships and works well with probability distributions. However, it may lead to overfitting if not properly regularized.
