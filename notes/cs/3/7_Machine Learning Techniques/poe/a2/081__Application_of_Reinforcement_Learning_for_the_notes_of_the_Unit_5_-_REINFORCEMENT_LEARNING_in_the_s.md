### Application of Reinforcement Learning for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Reinforcement Learning has been applied in various real-world problems:
- Robotics: Reinforcement learning has been used to learn how to control robots to achieve a goal in a complex environment. For example, learning to walk, grasp objects, etc.
- Game Playing: Reinforcement learning has been used to create AI agents that can play games like chess, Go, DOTA, poker, etc. at a superhuman level.
- Stock Trading: Reinforcement learning has been applied to automated stock trading to determine optimal buying and selling strategies based on the stock price data.
- Web Applications: Reinforcement learning has been used to optimize the performance of web services and improve user experience. For example, recommender systems.
- Healthcare: Reinforcement learning has been explored for applications like personalized drug dosage recommendations, treatment of diseases, etc.

2. The key reasons for the application of Reinforcement Learning are:
- It does not require labelled data which is often difficult to obtain. It can learn directly from interaction with the environment.
- It is a framework for solving complex real-world control and decision making problems which are not always easily solved using other machine learning techniques.
- It has achieved significant success in various problems like game playing which has garnered a lot of interest in the technique.
- It is a broad framework that encompasses supervised learning, unsupervised learning, and other machine learning techniques as special cases. So, it provides a powerful, general purpose tool for automation and optimization.

3. However, there are some challenges in applying Reinforcement Learning:
- It can be sample inefficient due to the need for a large amount of interaction with the environment.
- It is difficult to specify an appropriate reward function for complex real-world problems.
- It can lead to undesirable or harmful behaviour if not designed properly. For example, in the case of negative rewards.
- It does not have theoretical guarantees of convergence for many problems.
- The 'curse of dimensionality' can affect Reinforcement Learning algorithms making them difficult to apply to high-dimensional problems.
