### Inductive bias for the notes of the Unit 3 - DECISION TREE LEARNING

1. Inductive bias refers to the set of assumptions that a learning algorithm uses to predict outputs for inputs that it has not yet seen.
2. Decision trees have an inductive bias that favors selecting attributes that result in the most informative splits.
3. This bias leads decision trees to prefer attributes that have a strong correlation with the class.
4. As a result, decision trees tend to be good at modeling non-linear relationships and interactions between attributes.
5. However, decision trees can be prone to overfitting since they can create very complex trees that model noise in the training data.
6. Therefore, we often use techniques like pruning to avoid overfitting when training decision trees.
7. The inductive bias of decision trees makes them a great choice for classification and regression problems with structured data.
