### 1D and 2D for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS

1. One Dimensional Array (1D Array):
- It is a linear array of elements of same type placed in contiguous memory locations that can be accessed by indexing.
- Index starts from 0.
- Size is specified while declaration.
- Elements can be accessed using index.

2. Two Dimensional Array (2D Array):
- It is an array of arrays (a matrix).
- Made up of rows and columns.
- Rows are accessed using first index and columns using second index.
- Size is specified as row size and column size.
- Useful for image processing, graphics, machine learning, etc.

3. Multidimensional Array:
- Array with more than two dimensions.
- Can be 3D, 4D, and so on.
- Elements are accessed using multiple indices.
- Useful for applications involving multiple features.

### Uses of Arrays in Artificial Neural Networks:
1. To store input data.
2. To store weights connecting inputs to outputs.
3. To store output values.
4. Arrays allow efficient storage and access of data required during training and testing of neural networks.
5. Various array operations can be applied to process data and update weights, making implementation of neural networks simpler.
