## Unit 4 - ARTIFICIAL NEURAL NETWORKS

1. Artificial Neural Networks (ANNs) are a type of machine learning algorithm that is inspired by the structure and functioning of the human brain.
2. They are made up of interconnected nodes that must be trained on large amounts of data to learn how to perform a task.
3. The network is organized into layers:
 - Input layer: The data is fed into the network through this layer.
 - Hidden layer(s): The layers between the input and output layers that transform the input and recognize patterns. The number of hidden layers and nodes in each layer vary based on the complexity of the task.
 - Output layer: The results are produced in this layer. The number of nodes in the output layer depends on the number of categories or values being predicted.
4. As the network is exposed to large amounts of data, it learns by adjusting the strengths of the connections (weights) between nodes. This is called training the network.
5. Some types of ANNs are:
 - Feedforward neural network: Data moves in only one direction from input to output.
 - Recurrent neural network: Data can loop back to previous nodes, allowing the network to remember previous inputs. This is useful for tasks like speech and handwriting recognition.
 - Convolutional neural network: Contains convolution layers that are useful for processing image data.
