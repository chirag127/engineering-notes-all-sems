### Mutation for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

1. Reinforcement Learning: Learning by interacting with the environment. The agent learns the optimal way of achieving the highest reward by trial-and-error using feedback from the environment.
2. Markov Decision Process (MDP): A framework for RL comprising of states, actions, transition probabilities, and rewards. The agent transitions between states by taking actions and receives rewards. The goal is to maximize the expected cumulative reward.
3. Value Functions: Functions that predict the expected cumulative reward for a state or state-action pair. They are used to determine the optimal strategy.
 - State-value function: Predicted reward for being in a state.
 - Action-value function (Q-function): Predicted reward for taking an action in a state.
4. Policy: The strategy that the agent follows to determine which action to take in a given state. The goal is to determine the optimal policy that maximizes the reward.
 - Greedy policy: Selects the action that has the highest reward prediction.
 - Epsilon-greedy policy: Selects a random action with probability epsilon and the greedy action with 1 - epsilon probability. Helps in exploration.
5. Temporal-difference learning: A method to learn value functions by bootstrapping using predicted future rewards. It updates predictions based on new experiences to reduce the error.
 - Monte Carlo methods: Estimate values based on actual rewards
 - TD methods: Estimate values based on predicted future rewards
