### Bayesian networks for the notes of the Unit 1 - INTRODUCTION

1. Bayesian networks are probabilistic graphical models that use Bayesian conditional probabilities and Bayes' theorem to encode independence relationships between variables.

2. They are widely used in machine learning and artificial intelligence for various applications such as:

- Diagnosis of diseases.
- Speech and handwriting recognition.
- Image segmentation.
- Robotics planning.
- Inference in graphical models.

3. A Bayesian network consists of:

- A set of variables (nodes).
- A set of directed edges (arrows) between variables.
- A set of conditional probability distributions (CPDs).

4. The network structure encodes the independence assumptions via d-separation. The CPDs encode the strengths of the direct dependencies.

5. Learning Bayesian networks involves both structure learning and parameter learning:

- Structure learning: Learning the graph topology from data.
- Parameter learning: Estimating the CPDs from data.
