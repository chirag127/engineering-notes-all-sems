### Multilayer networks for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. A single neuron can only compute linear separable functions. To compute complex non-linear functions, we need to use multiple layers of neurons.
2. A multilayer neural network has an input layer, one or more hidden layers, and an output layer. Each layer contains one or more neurons.
3. The input is fed into the input layer. The output of the input layer is passed as input to the first hidden layer. The output of the first hidden layer is passed as input to the second hidden layer and so on. The final output is produced by the output layer.
4. As the data passes through the network from the input layer to the output layer, it gets transformed at each layer. This allows the network to detect complex patterns in the data.
5. The power of a neural network lies in its ability to approximate any function. As we increase the number of layers and neurons in each layer, the neural network is capable of modeling more and more complex patterns. However, this increase in complexity comes at the cost of increased training time and risk of overfitting.
6. The selection of the number of layers and number of neurons in each layer depends on the complexity of the problem and the amount of data available for training the network. This is determined using a trial-and-error method.
