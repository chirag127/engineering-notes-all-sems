### Reinforcement Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

1. Reinforcement Learning: Reinforcement Learning is a type of Machine Learning that learns by interacting with a dynamic environment. The agent learns the behavior that maximizes the reward by trial-and-error using feedback from the environment.

2. Components: The main components of a Reinforcement Learning problem are:

- Agent: The learner or decision-maker.
- Environment: The dynamic system that the agent interacts with.
- Actions: The set of possible actions the agent can take.
- Rewards: Feedback from the environment to the agent for taking an action.
- Policy: The agent's behavior or strategy.
- Value function: The expected reward the agent can get by following a policy.

3. Types: The three major types of Reinforcement Learning are:

- Value-based: Learning value functions to evaluate states or state-action pairs. e.g. SARSA, Q-Learning.
- Policy search: Learning a policy directly by searching the policy space. e.g. REINFORCE, PG.
- Model-based: Learning a model of the environment and planing with the model. e.g. Dyna.

4. Applications: Reinforcement Learning is applied to problems such as:

- Game playing: e.g. AlphaZero, AlphaGo.
- Robot control.
- Network routing.
- Recommendation systems.
- Finance.
- Healthcare.
