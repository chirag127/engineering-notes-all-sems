### Properties of SVM for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

SVM or Support Vector Machine is a popular machine learning algorithm that is widely used for regression and classification problems. It is a powerful technique that is known for its ability to handle complex data and provide accurate predictions. Here are some of the important properties of SVM that you should know for the Unit 2 - REGRESSION in the subject of Machine Learning Techniques:

- **Kernel Function**: SVM uses a kernel function to transform the input data into a higher dimensional space. This helps in separating the data points that are not linearly separable in the original space. Some of the commonly used kernel functions are linear, polynomial, radial basis function (RBF), and sigmoid.

- **Margin Optimization**: SVM tries to maximize the margin between the decision boundary and the closest data points. The decision boundary is the line that separates the data points into different classes. The closest data points to the decision boundary are called support vectors. By maximizing the margin, SVM reduces the chance of overfitting and improves the generalization performance.

- **Regularization**: SVM uses regularization to prevent overfitting. The regularization parameter controls the trade-off between the margin and the classification error. A smaller value of the regularization parameter results in a larger margin and a higher classification error, while a larger value of the regularization parameter results in a smaller margin and a lower classification error.

- **Non-Probabilistic**: Unlike some other machine learning algorithms such as logistic regression and Naive Bayes, SVM is a non-probabilistic algorithm. This means that it does not provide a probability estimate for the prediction. Instead, it only provides the predicted class label.

- **Sensitive to Outliers**: SVM is sensitive to outliers in the data. Outliers are data points that are significantly different from the rest of the data. They can have a large impact on the decision boundary and the margin. Therefore, it is important to preprocess the data and remove the outliers before applying SVM.

- **Computational Complexity**: SVM can be computationally expensive for large datasets. The training time and memory requirements increase with the size of the dataset and the number of features. Therefore, it is important to choose the appropriate kernel function and regularization parameter to balance the computational complexity and the performance.

These are some of the important properties of SVM that you should know for the Unit 2 - REGRESSION in the subject of Machine Learning Techniques. Understanding these properties will help you to apply SVM effectively for regression problems and improve the accuracy of your predictions.
