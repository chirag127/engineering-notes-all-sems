### Types of Learning for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

Unit 1 of the Machine Learning Techniques course focuses on the Introduction and covers the aspect of Types of Learning.

There are three main types of learning in the field of machine learning: supervised learning, unsupervised learning, and reinforcement learning.

Supervised learning involves training a model on labeled data, where the correct output is known for each input. The goal of supervised learning is to learn a mapping from inputs to outputs, and to use this mapping to make predictions on new, unseen data.

Unsupervised learning involves training a model on unlabeled data, where the correct output is not known for each input. The goal of unsupervised learning is to find patterns or relationships in the data, and to use these patterns to make predictions or to cluster the data into groups.

Reinforcement learning involves training an agent to make decisions in an environment, where the agent receives rewards or penalties based on its actions. The goal of reinforcement learning is to learn a policy that maximizes the total reward received by the agent.

In the context of the Machine Learning Techniques course, students in Unit 1 will learn about the different types of learning as part of the introduction to the course. This may include working with examples of each type of learning, analyzing the benefits and limitations of each type of learning, and learning how to choose the appropriate type of learning for a given problem.

There are three main types of learning in the field of machine learning: supervised learning, unsupervised learning, and reinforcement learning.
