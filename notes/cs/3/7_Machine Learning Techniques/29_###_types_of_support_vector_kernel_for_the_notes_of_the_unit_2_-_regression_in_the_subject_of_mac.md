### Types of support vector kernel for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

Unit 2 of the Machine Learning Techniques course focuses on Regression and covers the aspect of Types of Support Vector Kernels.

Support Vector Machines (SVMs) are a type of supervised learning algorithm used for classification and regression. In the context of regression, SVMs use a kernel function to transform the input data into a higher dimensional space, where a linear boundary can be found to separate the data.

There are several types of kernels that can be used in SVMs, including linear, polynomial, radial basis function (RBF), and sigmoid kernels. The choice of kernel depends on the specific requirements of the problem and the type of data being analyzed.

Linear kernels are used when the data is linearly separable in the original space. Polynomial kernels are used when the data is not linearly separable in the original space, but can be separated by a polynomial boundary. RBF kernels are used when the data is not linearly separable in the original space, and a non-linear boundary is needed. Sigmoid kernels are used when the data is not linearly separable in the original space, and a non-linear boundary is needed, but the boundary should have a sigmoidal shape.

In the context of the Machine Learning Techniques course, students in Unit 2 will learn about the different types of support vector kernels as part of the discussion on regression. This may include working with examples of each type of kernel, analyzing the benefits and limitations of each type of kernel, and learning how to choose the appropriate type of kernel for a given problem.
