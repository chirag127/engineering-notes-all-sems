### SUPPORT VECTOR MACHINE for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

Support Vector Machine (SVM) is a supervised learning algorithm that is used for classification and regression tasks. SVM is a powerful machine learning technique that uses a boundary, called a hyperplane, to separate the data into different classes.

The following are some of the key concepts related to Support Vector Machine:

1. Hyperplane: The hyperplane is a boundary used to separate the data into different classes, and it is defined by the support vectors.

2. Support Vectors: Support vectors are the data points closest to the hyperplane, and they define the hyperplane.

3. Margin: The margin is the distance between the hyperplane and the closest data points, and it is used to measure the separation between the classes.

4. Hard Margin SVM: Hard Margin SVM is a SVM that uses a hard boundary to separate the data into different classes, and it is used when the data is linearly separable.

5. Soft Margin SVM: Soft Margin SVM is a SVM that uses a soft boundary to separate the data into different classes, and it is used when the data is not linearly separable.

6. Kernel Trick: The kernel trick is a technique used in SVM to transform the data into a higher-dimensional space, and it is used to make the data linearly separable.

In this unit, you will learn about Support Vector Machine, and you will learn how to use SVM for classification and regression tasks. You will also learn about the hyperplane, support vectors, margin, hard margin SVM, soft margin SVM, and the kernel trick.

This unit will provide a foundation for understanding the principles and practices of Support Vector Machine, and for exploring the various concepts and techniques used in the field of machine learning.
