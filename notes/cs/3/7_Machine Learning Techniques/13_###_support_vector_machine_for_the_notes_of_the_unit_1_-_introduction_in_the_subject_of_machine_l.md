### Support Vector Machine for the notes of the Unit 1 - INTRODUCTION in the subject of Machine Learning Techniques

Unit 1 of the Machine Learning Techniques course focuses on Introduction and covers the aspect of Support Vector Machines (SVMs).

Support Vector Machines (SVMs) are a type of supervised learning algorithm used for classification and regression. The goal of an SVM is to find the boundary, or hyperplane, that best separates the data into distinct classes. SVMs are particularly useful when the data is not linearly separable, as they can find non-linear boundaries by transforming the data into a higher dimensional space.

SVMs are based on the concept of finding the maximum margin hyperplane, which is the hyperplane that has the maximum distance from the closest data points of each class. This maximum margin hyperplane is called the support vector and the data points closest to the hyperplane are called support vectors.

In the context of the Machine Learning Techniques course, students in Unit 1 will learn about Support Vector Machines (SVMs) as a type of supervised learning algorithm. This may include working with examples of SVMs, analyzing the benefits and limitations of SVMs, and learning how to use SVMs to perform classification and regression tasks.
