### Types of layers for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

Types of Layers:
1. Input layer: Accepts input data for the network
2. Hidden layer: Performs computation and transformations on input data
3. Output layer: Produces the final output of the network
4. Convolutional layer: Used in image processing, applies filters to input data
5. Recurrent layer: Used in processing sequential data, retains memory of past inputs
6. Pooling layer: Downsamples input data to reduce computation complexity
7. Dropout layer: Prevents overfitting by randomly dropping out neurons during training
8. Batch Normalization layer: Normalizes the inputs to a layer to improve training stability.
