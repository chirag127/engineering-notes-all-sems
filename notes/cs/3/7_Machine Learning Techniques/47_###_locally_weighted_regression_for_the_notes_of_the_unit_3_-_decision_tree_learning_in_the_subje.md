### Locally Weighted Regression for the notes of the Unit 3 - DECISION TREE LEARNING in the subject of Machine Learning Techniques

Locally Weighted Regression (LWR) is a type of regression algorithm that is used to make predictions about a target variable based on a set of features. It is a non-parametric method that assigns higher weights to the data points that are closest to the target point, and it is used to model non-linear relationships between the features and the target variable.

The following are some of the key concepts related to Locally Weighted Regression:

1. Non-Parametric Method: A non-parametric method is a method that does not make any assumptions about the underlying distribution of the data, and it is used to model non-linear relationships between the features and the target variable.

2. Weights: Weights are used to assign higher importance to the data points that are closest to the target point, and they are used to make predictions about the target variable.

3. Kernel Function: A kernel function is a function that is used to compute the weights for each data point, and it is used to determine the importance of each data point in the prediction.

4. Bandwidth: The bandwidth is a parameter that determines the size of the region around the target point that is used to make predictions, and it is used to control the smoothness of the predictions.

5. Overfitting: Overfitting is a phenomenon in which the model fits the training data too closely, and it is used to make predictions about the outcome of a particular event.

You will also learn about non-parametric methods, weights, kernel functions, bandwidth, and overfitting, and you will learn how these concepts are used in LWR.

This unit will provide a foundation for understanding the principles and practices of Locally Weighted Regression, and for exploring the various concepts and techniques used in the field of machine learning.
