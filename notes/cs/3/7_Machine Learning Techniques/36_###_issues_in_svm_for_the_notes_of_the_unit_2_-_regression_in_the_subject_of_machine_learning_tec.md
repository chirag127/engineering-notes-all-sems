### Issues in SVM for the notes of the Unit 2 - REGRESSION in the subject of Machine Learning Techniques

Unit 2 of the Machine Learning Techniques course focuses on Regression and covers the aspect of issues in Support Vector Machines (SVMs).

Support Vector Machines (SVMs) are a popular type of machine learning algorithm used for classification and regression. However, there are several issues that can arise when using SVMs, including:

1. Overfitting: SVMs can be prone to overfitting, especially when the data is noisy or when the model is too complex. Overfitting occurs when the model fits the training data too well, and does not generalize well to new, unseen data.

2. Choice of kernel: The choice of kernel is an important decision when using SVMs, as it determines the type of boundary that the SVM will find. The choice of kernel can have a significant impact on the performance of the SVM, and choosing the wrong kernel can result in poor performance.

3. Computational complexity: SVMs can be computationally expensive, especially for large datasets. The training time for an SVM can be very long, and the prediction time can also be slow.

4. Sensitivity to scaling: SVMs are sensitive to the scaling of the data, and it is important to scale the data appropriately before training an SVM. If the data is not scaled appropriately, the SVM may find a boundary that is not representative of the true relationships in the data.

In the context of the Machine Learning Techniques course, students in Unit 2 will learn about the issues that can arise when using Support Vector Machines (SVMs) as part of the discussion on regression. This may include working with examples of SVMs, analyzing the benefits and limitations of SVMs, and learning how to address the issues that can arise when using SVMs.

In summary, Unit 2 of the Machine Learning Techniques course focuses on Regression and covers the aspect of issues in Support Vector Machines (SVMs). There are several issues that can arise when using SVMs, including overfitting, choice of kernel, computational complexity, and sensitivity to scaling. Students will learn about these issues through interactive activities and hands-on experiences, and will learn how to address the issues that can arise when using SVMs.
