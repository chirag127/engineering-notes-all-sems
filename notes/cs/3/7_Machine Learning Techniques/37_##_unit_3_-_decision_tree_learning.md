## Unit 3 - DECISION TREE LEARNING

Decision Tree Learning is a type of machine learning algorithm that is used for both classification and regression tasks. It is a tree-based model that represents a series of decisions and their possible consequences.

The following are some of the key concepts related to Decision Tree Learning:

1. Root Node: The root node is the first node in a decision tree, and it represents the entire dataset.

2. Internal Nodes: Internal nodes are the nodes in a decision tree that represent a decision, and they are used to split the data into smaller subsets.

3. Leaf Nodes: Leaf nodes are the nodes in a decision tree that represent a prediction, and they are used to make a prediction for a given sample.

4. Entropy: Entropy is a measure of the impurity of a set of data, and it is used to determine the best feature to split the data at each internal node.

5. Information Gain: Information gain is a measure of the reduction in entropy achieved by splitting the data at a given feature, and it is used to determine the best feature to split the data at each internal node.

6. Pruning: Pruning is a technique used to reduce the size of a decision tree, and it is used to prevent overfitting.

In this unit, you will learn about Decision Tree Learning, and you will learn how to use decision trees for both classification and regression tasks. You will also learn about the root node, internal nodes, leaf nodes, entropy, information gain, and pruning.

This unit will provide a foundation for understanding the principles and practices of Decision Tree Learning, and for exploring the various concepts and techniques used in the field of machine learning.
