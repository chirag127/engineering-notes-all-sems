# Unit 5 - Reinforcement Learning

Reinforcement Learning is a type of Machine Learning technique that enables an agent to learn in an interactive environment by trial and error using feedback from its own actions and experiences.

Here are some key points to remember about Reinforcement Learning:

1. Reinforcement Learning is a type of learning that is based on the concept of reward-based learning, where an agent learns by interacting with its environment and receiving feedback in the form of rewards or punishments.

2. The goal of Reinforcement Learning is to learn a policy that maps states to actions in such a way that the agent can maximize its cumulative reward over time.

3. Reinforcement Learning algorithms can be classified into two main categories: model-based and model-free. Model-based algorithms use a model of the environment to make predictions about future states and rewards, while model-free algorithms do not rely on a model and instead learn directly from experience.

4. Some common Reinforcement Learning algorithms include Q-learning, SARSA, and Deep Q-Networks (DQN).

5. Reinforcement Learning has many applications, including game playing, robotics, and autonomous driving.
