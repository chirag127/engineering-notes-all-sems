### Bayesian Networks

Bayesian networks are graphical models that represent the probabilistic relationships between variables in a system. They are used in a variety of applications, including machine learning, to model complex systems and make predictions.

Here are some key points to remember about Bayesian networks:

1. A Bayesian network is a directed acyclic graph (DAG) where each node represents a random variable and the edges represent the conditional dependencies between the variables.
2. The structure of the graph encodes the conditional independence assumptions of the model.
3. Each node is associated with a conditional probability distribution (CPD) that specifies the probability of the variable given its parents in the graph.
4. Bayesian networks can be used for both inference and learning. Inference involves computing the posterior probabilities of the variables given evidence, while learning involves estimating the parameters of the model from data.
5. There are several algorithms for learning the structure and parameters of a Bayesian network, including constraint-based, score-based, and hybrid methods.
6. Bayesian networks can handle missing data and can be used for both classification and regression tasks.

These are some of the key points to remember about Bayesian networks. They provide a powerful framework for modeling complex systems and making predictions based on probabilistic reasoning.
