### Perceptron’s for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

- A perceptron is a type of artificial neural network invented in 1957 by Frank Rosenblatt.
- It is a binary classifier that maps its input x (a real-valued vector) to an output value f(x) (a single binary value).
- The perceptron algorithm is used to determine the weights of the inputs to the perceptron, which can then be used to make predictions on new data.
- The perceptron algorithm is an iterative method for finding the weights that correctly classify the training data.
- The perceptron algorithm is guaranteed to converge to a solution if the training data is linearly separable.
- If the training data is not linearly separable, the perceptron algorithm may not converge to a solution.
- The perceptron algorithm can be extended to multi-class classification by training multiple perceptrons, one for each class.
- The perceptron can also be used for regression by replacing the step function with a linear function.
- The perceptron is a simple and powerful algorithm, but it has limitations, such as its inability to solve problems that are not linearly separable.
- More advanced neural network architectures, such as multi-layer perceptrons, can overcome some of these limitations.
