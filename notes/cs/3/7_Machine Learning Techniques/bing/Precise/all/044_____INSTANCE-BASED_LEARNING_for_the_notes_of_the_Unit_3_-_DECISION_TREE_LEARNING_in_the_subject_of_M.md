# Instance-Based Learning

Instance-based learning is a type of learning in which the training data is stored, and new instances are classified based on their similarity to the stored instances. This is in contrast to other learning methods, such as decision trees, where a model is built from the training data and used to classify new instances.

Some key points to remember about instance-based learning are:

- Instance-based learning is also known as memory-based learning or lazy learning.
- The training data is stored, and new instances are classified based on their similarity to the stored instances.
- The k-nearest neighbor algorithm is a commonly used instance-based learning algorithm.
- Instance-based learning can be used for both classification and regression problems.
- The choice of similarity measure is important in instance-based learning, as it determines how similar two instances are.
- Instance-based learning can be sensitive to the scale of the input features, so feature scaling may be necessary.
- Instance-based learning can be computationally expensive, as it requires comparing a new instance to all stored instances.
