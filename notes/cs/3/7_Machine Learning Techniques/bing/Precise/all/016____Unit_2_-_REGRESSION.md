## Unit 2 - REGRESSION

Regression is a statistical method used to study the relationship between two or more variables. It is used to predict the value of one variable based on the values of the other variables.

There are two main types of regression: simple linear regression and multiple linear regression.

1. **Simple Linear Regression** is used to study the relationship between two variables. It is used to predict the value of one variable based on the value of the other variable.

2. **Multiple Linear Regression** is used to study the relationship between more than two variables. It is used to predict the value of one variable based on the values of the other variables.

In both types of regression, the goal is to find the line of best fit that can be used to make predictions. The line of best fit is the line that minimizes the sum of the squared errors between the observed values and the predicted values.

Regression analysis is widely used in many fields, including economics, finance, biology, engineering, and social sciences. It is a powerful tool for understanding the relationships between variables and making predictions. However, it is important to use regression analysis correctly and to interpret the results carefully. Incorrect use of regression analysis can lead to misleading conclusions.
