### Unit 1 - INTRODUCTION
#### Types of Learning in Machine Learning Techniques

1. **Supervised Learning**: In supervised learning, the algorithm is trained on a labeled dataset, where the outcome variable is known. The algorithm then makes predictions based on the input data and the known outcome variable. The goal of supervised learning is to learn a function that maps inputs to outputs.

2. **Unsupervised Learning**: In unsupervised learning, the algorithm is trained on an unlabeled dataset, where the outcome variable is unknown. The algorithm then tries to find patterns or relationships in the data. The goal of unsupervised learning is to find the underlying structure of the data.

3. **Semi-Supervised Learning**: Semi-supervised learning is a combination of supervised and unsupervised learning. The algorithm is trained on a partially labeled dataset, where some of the data points have known outcome variables and some do not. The goal of semi-supervised learning is to improve the performance of the algorithm by using both labeled and unlabeled data.

4. **Reinforcement Learning**: In reinforcement learning, the algorithm learns by interacting with its environment. The algorithm receives feedback in the form of rewards or punishments based on its actions, and it uses this feedback to improve its performance. The goal of reinforcement learning is to learn a policy that maximizes the cumulative reward over time.

5. **Deep Learning**: Deep learning is a subset of machine learning that uses neural networks with multiple layers. These layers are capable of learning features from the data in a hierarchical manner. Deep learning algorithms can be used for supervised, unsupervised, and reinforcement learning.

6. **Transfer Learning**: Transfer learning is a technique where a pre-trained model is used as a starting point for a new task. The pre-trained model has already learned features from a large dataset, and these features can be useful for the new task. The goal of transfer learning is to improve the performance of the algorithm by leveraging the knowledge gained from a related task.
