### Locally Weighted Regression

Locally Weighted Regression (LWR) is a non-parametric method for fitting data points. It is used in the field of machine learning and is a part of the Decision Tree Learning unit in the subject of Machine Learning Techniques.

Here are some key points about LWR:

1. LWR is a type of regression analysis that fits data points using a weighted least squares method.
2. The weights are determined by the distance between the data point and the point being predicted.
3. The closer the data point is to the point being predicted, the higher the weight assigned to it.
4. This results in a model that is more flexible and can better fit the data points.
5. LWR is particularly useful when the data has a non-linear relationship.
6. It is also useful when the data has a high degree of noise or outliers.
7. LWR can be computationally expensive, as it requires the calculation of weights for each data point.
