### Perceptron’s for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. A perceptron is a type of artificial neural network invented in 1957 by Frank Rosenblatt.
2. It is a binary classifier that maps its input x (a real-valued vector) to an output value f(x) (a single binary value).
3. The perceptron algorithm is used to determine the weights for the input features in order to correctly classify the data.
4. The algorithm iteratively adjusts the weights based on the training data, until the data is correctly classified or a maximum number of iterations is reached.
5. The perceptron can only classify linearly separable data, meaning that the data can be separated by a hyperplane.
6. The perceptron algorithm is guaranteed to converge to a solution if the data is linearly separable.
7. If the data is not linearly separable, the perceptron algorithm will not converge and will continue to make mistakes.
8. The perceptron can be extended to multi-class classification by using multiple perceptrons, one for each class.
9. The perceptron can also be extended to non-linearly separable data by using kernel methods or by adding additional layers to create a multi-layer perceptron.
10. The perceptron is a simple and powerful algorithm, but it has limitations and is not suitable for all classification problems.
