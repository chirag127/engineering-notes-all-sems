### Unit 5 - REINFORCEMENT LEARNING

Reinforcement Learning is a type of Machine Learning technique that enables an agent to learn in an interactive environment by trial and error using feedback from its own actions and experiences.

Here are some key points to remember about Reinforcement Learning:

1. Reinforcement Learning is a type of learning that is based on the concept of reward-based learning.
2. The goal of Reinforcement Learning is to learn a policy that maximizes the cumulative reward over time.
3. The agent learns by interacting with the environment and receiving feedback in the form of rewards or penalties.
4. The agent's actions are determined by a policy, which is a mapping from states to actions.
5. The value function estimates the expected cumulative reward of following a particular policy from a given state.
6. The Q-function estimates the expected cumulative reward of taking a particular action in a given state and following a particular policy thereafter.
7. The Bellman equation is used to update the value function and the Q-function.
8. Common algorithms used in Reinforcement Learning include Q-learning, SARSA, and Monte Carlo methods.
9. Reinforcement Learning has been successfully applied to various domains, including game playing, robotics, and resource management.
