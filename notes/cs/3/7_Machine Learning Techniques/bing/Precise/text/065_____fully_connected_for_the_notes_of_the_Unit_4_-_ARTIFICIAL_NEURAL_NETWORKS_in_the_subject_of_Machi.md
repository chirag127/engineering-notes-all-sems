### Fully Connected

- A fully connected layer is a type of neural network layer where each neuron is connected to every neuron in the previous layer.
- This type of layer is also known as a dense layer or a fully connected neural network (FCNN).
- The purpose of a fully connected layer is to combine the features learned by the previous layers to make predictions.
- The number of neurons in a fully connected layer is typically chosen based on the number of classes in the classification problem.
- The weights of the connections between neurons are learned during training using backpropagation.
- Fully connected layers are commonly used as the final layer in a neural network, but can also be used in the middle of the network.
- They are often used in combination with other types of layers, such as convolutional and recurrent layers, to build deep neural networks.
- Fully connected layers can be computationally expensive, especially for large datasets, due to the large number of connections between neurons.
- Techniques such as dropout and batch normalization can be used to improve the performance of fully connected layers.
