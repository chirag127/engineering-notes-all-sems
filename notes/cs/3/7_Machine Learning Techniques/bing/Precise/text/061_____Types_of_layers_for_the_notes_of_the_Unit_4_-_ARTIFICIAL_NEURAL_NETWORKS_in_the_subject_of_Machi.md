### Types of layers for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

1. **Input Layer:** The input layer is the first layer of an artificial neural network. It receives the input data and passes it on to the next layer. The number of neurons in the input layer is equal to the number of input features.

2. **Hidden Layer:** The hidden layer is the layer between the input and output layers. It performs computations on the data received from the input layer and passes the results to the output layer. The number of neurons in the hidden layer can vary and is determined by the complexity of the problem.

3. **Output Layer:** The output layer is the last layer of an artificial neural network. It receives the data from the hidden layer and produces the final output. The number of neurons in the output layer is equal to the number of classes in a classification problem or one in a regression problem.

4. **Convolutional Layer:** The convolutional layer is used in convolutional neural networks, which are commonly used for image recognition tasks. It applies a set of filters to the input data to extract features.

5. **Pooling Layer:** The pooling layer is used in convolutional neural networks to reduce the dimensionality of the data. It performs a downsampling operation on the data, reducing its size while retaining important information.

6. **Recurrent Layer:** The recurrent layer is used in recurrent neural networks, which are commonly used for sequence data such as text or time series. It has a memory that allows it to remember previous inputs and use them to make predictions.

7. **Fully Connected Layer:** The fully connected layer is a layer in which every neuron is connected to every neuron in the previous layer. It is commonly used as the final layer in a neural network to produce the final output.

8. **Dropout Layer:** The dropout layer is used to prevent overfitting in a neural network. It randomly drops out some of the neurons during training, forcing the network to learn more robust features.

9. **Batch Normalization Layer:** The batch normalization layer is used to normalize the data within a batch during training. It helps to speed up training and improve the performance of the network.

10. **Embedding Layer:** The embedding layer is used to represent categorical data as dense vectors. It is commonly used in natural language processing tasks to represent words as vectors.
