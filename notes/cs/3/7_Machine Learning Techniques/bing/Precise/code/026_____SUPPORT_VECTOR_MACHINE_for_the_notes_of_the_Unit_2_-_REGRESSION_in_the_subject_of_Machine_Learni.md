### SUPPORT VECTOR MACHINE

Support Vector Machine (SVM) is a supervised machine learning algorithm that can be used for classification or regression tasks. It is mostly used for classification problems. Here are some key points to note about SVM:

1. SVM works by finding the hyperplane that best separates the data into different classes.
2. The hyperplane is chosen in such a way that the margin between the closest points to the hyperplane (called support vectors) is maximized.
3. SVM can handle both linearly and non-linearly separable data by using kernel functions to map the data into a higher dimensional space.
4. SVM is effective in high dimensional spaces and is relatively memory efficient.
5. The main disadvantage of SVM is that it can be sensitive to the choice of kernel function and the values of its parameters.

In the context of regression, SVM can be used to find the hyperplane that best fits the data, with a certain tolerance for errors. This is known as Support Vector Regression (SVR).
