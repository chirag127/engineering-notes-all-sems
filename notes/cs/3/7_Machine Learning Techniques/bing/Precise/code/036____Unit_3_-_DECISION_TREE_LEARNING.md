## Unit 3 - DECISION TREE LEARNING

Decision tree learning is a type of supervised learning algorithm used for classification and regression tasks. It works by recursively partitioning the data into subsets based on the values of the input features, and then assigning a class label or a numerical value to each leaf node of the tree.

Some key points to remember about decision tree learning are:

1. Decision trees can handle both categorical and numerical data.
2. The tree is constructed by selecting the best feature to split the data at each node, based on a measure of impurity such as entropy or Gini index.
3. The tree is grown until all the data at a node belongs to the same class, or until a stopping criterion is reached, such as a maximum depth or a minimum number of samples at a node.
4. Decision trees are prone to overfitting, especially when the tree is grown too deep. Techniques such as pruning can be used to reduce overfitting.
5. Decision trees can be visualized and are easy to interpret, making them a popular choice for many applications.
