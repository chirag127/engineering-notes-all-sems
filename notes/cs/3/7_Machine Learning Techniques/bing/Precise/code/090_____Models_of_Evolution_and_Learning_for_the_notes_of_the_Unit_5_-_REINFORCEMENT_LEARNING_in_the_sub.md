### Models of Evolution and Learning

Reinforcement Learning is a type of feedback-based Machine learning technique in which we train an agent that learns to behave in an environment by performing the actions and observing the results of actions. It is the closest machine learning type to how humans learn. The algorithm or agent used learns by interacting with its environment and getting a positive or negative reward. Common algorithms include temporal difference, deep adversarial networks, and Q-learning.

One of the models of evolution and learning in reinforcement learning is Evolutionary-Driven Reinforcement Learning (evo-RL). This algorithm embeds the reinforcement learning algorithm in an evolutionary cycle, where we distinctly differentiate between purely evolvable (instinctive) behavior versus purely learnable behavior.

Another model is deep evolutionary reinforcement learning, which evolves agents with diverse morphologies to learn hard locomotion and manipulation tasks in complex environments.

There are many different types of models such as GANs, LSTMs & RNNs, CNNs, Autoencoders, and Deep Reinforcement Learning models. Deep neural networks are used for object detection, speech recognition and synthesis, image processing, style transfer, and machine translation, and can replace most classical machine learning algorithms.
