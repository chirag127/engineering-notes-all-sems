### Perceptron’s for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

- A perceptron is a type of artificial neural network invented in 1957 by Frank Rosenblatt.
- It is a binary classifier that maps its input x (a real-valued vector) to an output value f(x) (a single binary value).
- The perceptron algorithm is used to determine the weights for the inputs in order to correctly classify the input data.
- The perceptron algorithm is an iterative process that updates the weights based on the errors made in the classification of the training data.
- The perceptron algorithm is guaranteed to converge to a solution if the data is linearly separable.
- If the data is not linearly separable, the perceptron algorithm will not converge and will continue to update the weights indefinitely.
- The perceptron can be used for supervised learning tasks such as classification and regression.
- The perceptron can also be used as a building block for more complex neural network architectures such as multi-layer perceptrons.
- The perceptron algorithm is simple and easy to implement, making it a popular choice for introductory machine learning courses.
