### Genetic Programming for the notes of the Unit 5 - REINFORCEMENT LEARNING in the subject of Machine Learning Techniques

- Genetic Programming (GP) is a type of Evolutionary Algorithm (EA), a subset of machine learning. EAs are used to discover solutions to problems humans do not know how to solve, directly.
- In Reinforcement Learning (RL), the choice of values for learning algorithm parameters can significantly impact the overall learning process.
- A genetic algorithm (GA) can be used to find the values of parameters used in Deep Deterministic Policy Gradient (DDPG) combined with Hindsight Experience Replay (HER), to help speed up the learning agent.
- A genetic programming based approach for feature discovery in reinforcement learning can be used. A population of individuals, each representing a set of features, is evolved, and individuals are evaluated by their average performance on short reinforcement learning trials.
- With continuous-valued state and input variables, RL algorithms must rely on function approximators to represent the value function and policy mappings.
