### INSTANCE-BASED LEARNING

Instance-based learning is a type of learning in which the training data is stored, and new instances are classified based on their similarity to the stored instances. This is also known as memory-based learning or lazy learning.

Some key points to remember about instance-based learning are:
- The training data is stored, rather than discarded after the model is built.
- New instances are classified based on their similarity to the stored instances.
- The similarity measure used is critical to the performance of the algorithm.
- The k-nearest neighbors algorithm is a commonly used instance-based learning algorithm.
- Instance-based learning can be used for both classification and regression problems.

This type of learning is useful when the data is complex and difficult to represent using a parametric model. It is also useful when the data is changing rapidly, as new instances can be easily added to the stored data.

However, instance-based learning can be computationally expensive, as the entire training dataset must be searched to find the nearest neighbors. It can also be sensitive to irrelevant features, as all features are used to calculate the similarity measure.

In summary, instance-based learning is a type of learning in which the training data is stored and new instances are classified based on their similarity to the stored instances. It is useful for complex and rapidly changing data, but can be computationally expensive and sensitive to irrelevant features.
