### Radial basis function networks

Radial basis function networks (RBF networks) are a type of artificial neural network used for function approximation and classification. They are commonly used in machine learning techniques, particularly in the context of decision tree learning.

Some key points to note about RBF networks include:

1. RBF networks are composed of three layers: an input layer, a hidden layer, and an output layer.
2. The hidden layer contains radial basis function neurons, which compute the distance between the input vector and a center vector.
3. The output of the RBF neuron is a non-linear function of the distance, typically a Gaussian function.
4. The output layer computes a weighted sum of the outputs of the RBF neurons in the hidden layer.
5. RBF networks can be trained using supervised learning algorithms, such as backpropagation or least squares.
6. RBF networks are particularly well-suited for problems where the input data is non-linearly separable.
7. RBF networks can be used for both regression and classification tasks.
