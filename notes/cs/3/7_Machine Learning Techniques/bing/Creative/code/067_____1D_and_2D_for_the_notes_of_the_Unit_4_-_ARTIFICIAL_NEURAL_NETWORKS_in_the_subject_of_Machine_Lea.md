# 1D and 2D

## 1D

- 1D stands for one-dimensional, which means that the data has only one dimension or axis.
- 1D data can be represented as a sequence of values, such as a time series, a sound wave, or a text.
- 1D data can be processed by using linear models, such as linear regression, logistic regression, or support vector machines, or by using recurrent neural networks (RNNs), such as long short-term memory (LSTM) or gated recurrent units (GRU).
- 1D data can be visualized by using line plots, histograms, or box plots.

## 2D

- 2D stands for two-dimensional, which means that the data has two dimensions or axes.
- 2D data can be represented as a matrix of values, such as an image, a heatmap, or a spreadsheet.
- 2D data can be processed by using matrix operations, such as matrix multiplication, inverse, or transpose, or by using convolutional neural networks (CNNs), such as LeNet, AlexNet, or ResNet.
- 2D data can be visualized by using image plots, contour plots, or scatter plots.
