## Unit 2 - REGRESSION

- Regression is a statistical method that aims to model the relationship between a dependent variable (also called the response or outcome variable) and one or more independent variables (also called the predictors or explanatory variables).
- Regression can be used for various purposes, such as describing how the dependent variable changes with the independent variables, testing hypotheses about the effects of the independent variables, predicting the value of the dependent variable for new observations, or evaluating the goodness of fit of a model.
- There are different types of regression models, depending on the nature of the dependent variable and the assumptions made about the relationship. Some common types are:
  - Linear regression: The dependent variable is continuous and the relationship is linear, meaning that it can be expressed as a straight line. The model has the form: `y = b0 + b1x1 + b2x2 + ... + bnxn + e`, where `y` is the dependent variable, `x1, x2, ..., xn` are the independent variables, `b0, b1, b2, ..., bn` are the coefficients or parameters to be estimated, and `e` is the error term or residual.
  - Logistic regression: The dependent variable is binary, meaning that it can take only two values (usually 0 or 1). The relationship is nonlinear, meaning that it cannot be expressed as a straight line. The model has the form: `logit(p) = b0 + b1x1 + b2x2 + ... + bnxn`, where `p` is the probability of the dependent variable being 1, `logit(p) = ln(p/(1-p))` is the logit function, and the other terms are as in linear regression.
  - Poisson regression: The dependent variable is a count, meaning that it can take only non-negative integer values. The relationship is nonlinear, meaning that it cannot be expressed as a straight line. The model has the form: `log(y) = b0 + b1x1 + b2x2 + ... + bnxn`, where `y` is the dependent variable, `log(y)` is the natural logarithm, and the other terms are as in linear regression.
- To fit a regression model to a given data set, various methods can be used, such as the method of least squares, the method of maximum likelihood, or the method of moments. These methods aim to find the values of the coefficients or parameters that minimize the discrepancy between the observed and predicted values of the dependent variable, measured by some criterion such as the sum of squared errors, the likelihood function, or the moment conditions.
- To evaluate the quality of a regression model, various measures can be used, such as the coefficient of determination (R-squared), the adjusted R-squared, the root mean squared error (RMSE), the Akaike information criterion (AIC), or the Bayesian information criterion (BIC). These measures aim to assess how well the model fits the data, how parsimonious the model is, or how well the model predicts new observations.
