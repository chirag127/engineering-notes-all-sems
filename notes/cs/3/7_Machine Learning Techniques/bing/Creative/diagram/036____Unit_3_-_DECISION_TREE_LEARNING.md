## Unit 3 - DECISION TREE LEARNING

- Decision tree learning is a method of supervised learning that uses a tree-like structure to represent a set of rules for classifying or predicting the outcome of a given input.
- A decision tree consists of nodes, branches, and leaves. Nodes represent tests or decisions on the input features, branches represent the possible outcomes of the tests, and leaves represent the final classes or predictions.
- A decision tree can be learned from a set of labeled training examples using a recursive algorithm that splits the data into subsets based on the values of a chosen feature, and then repeats the process on each subset until a stopping criterion is met.
- The stopping criterion can be based on the purity of the subsets, the depth of the tree, the number of examples in each subset, or a combination of these factors.
- The choice of the feature to split on can be based on different criteria, such as information gain, gain ratio, gini index, or chi-square test. These criteria measure how well a feature can separate the examples into different classes, and aim to maximize the information or reduce the impurity of the subsets.
- A decision tree can be used for classification or regression tasks, depending on the type of the output variable. For classification, the output variable is categorical, and the leaves of the tree represent the most frequent or majority class in each subset. For regression, the output variable is numerical, and the leaves of the tree represent the average or median value of the output in each subset.
- A decision tree can be visualized as a flowchart or a diagram, where each node is labeled with a feature name and a condition, each branch is labeled with a possible value of the feature, and each leaf is labeled with a class or a prediction.
- A decision tree can be evaluated using different metrics, such as accuracy, precision, recall, f1-score, or mean squared error, depending on the task and the goal. These metrics measure how well the decision tree can generalize to new or unseen examples, and can be computed using a test set or a cross-validation technique.
- A decision tree can suffer from overfitting or underfitting, depending on the complexity of the tree and the amount of data. Overfitting occurs when the tree is too specific or too deep, and captures the noise or the outliers in the data, resulting in poor generalization. Underfitting occurs when the tree is too simple or too shallow, and misses the important patterns or relationships in the data, resulting in poor accuracy.
- A decision tree can be improved or modified using different techniques, such as pruning, ensemble methods, or feature selection. Pruning is a process of reducing the size or the depth of the tree by removing or merging some nodes or branches, based on a validation set or a complexity measure. Ensemble methods are methods of combining multiple decision trees to form a more robust or accurate model, such as bagging, boosting, or random forests. Feature selection is a process of selecting a subset of relevant or informative features to use for building the tree, based on some criteria or methods, such as filter, wrapper, or embedded methods.
