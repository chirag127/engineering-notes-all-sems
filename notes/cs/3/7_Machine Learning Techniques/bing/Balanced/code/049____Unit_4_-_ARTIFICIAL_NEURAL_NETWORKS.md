## Unit 4 - ARTIFICIAL NEURAL NETWORKS

- Artificial neural networks (ANNs) are computational models inspired by the biological neural networks that constitute animal brains.
- ANNs are composed of layers of artificial neurons, which are units that can receive, process, and transmit information. Each neuron has a set of weights and a threshold that determine its output based on its input.
- ANNs can learn from data and approximate complex functions that are generally unknown or difficult to express mathematically.
- ANNs are a subset of machine learning and are at the heart of deep learning algorithms, which are applications of ANNs that can handle large and high-dimensional data.
- ANNs have many types and architectures, depending on the number of layers, the connections between neurons, the activation functions, the learning algorithms, and the tasks they perform.
- Some of the common types of ANNs are:
  - Feedforward neural networks, which have no feedback loops and pass information from the input layer to the output layer through one or more hidden layers.
  - Recurrent neural networks, which have feedback loops and can store information in their internal state, allowing them to process sequential data such as text and speech.
  - Convolutional neural networks, which have specialized layers that can extract features from spatial data such as images and videos.
  - Generative adversarial networks, which have two competing networks that can generate realistic data such as images and text.
- ANNs have many applications in various domains, such as image and voice recognition, natural language processing, computer vision, robotics, data mining, and bioinformatics.
