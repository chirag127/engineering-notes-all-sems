### Perceptron's for the notes of the Unit 4 - ARTIFICIAL NEURAL NETWORKS in the subject of Machine Learning Techniques

- A perceptron is an algorithm for supervised learning of binary classifiers .
- A binary classifier is a function that can decide whether an input, represented by a vector of numbers, belongs to some specific class.
- A perceptron is also a single-layer neural network, which is the simplest possible neural network.
- A perceptron consists of an input layer, a set of weights, a bias, an activation function, and an output layer .
- The input layer receives the input vector and passes it to the next layer with the weights and the bias .
- The weights and the bias are parameters that are learned by the perceptron during the training process .
- The activation function is a nonlinear function that maps the weighted sum of the inputs and the bias to the output layer .
- The output layer produces a single value, which is the prediction of the perceptron for the input vector .
- The perceptron can be trained using an iterative algorithm that updates the weights and the bias based on the error between the prediction and the actual class of the input vector .
- The perceptron can learn linearly separable patterns, which means that the input vectors can be separated by a hyperplane into two classes .
- The perceptron cannot learn nonlinearly separable patterns, which means that the input vectors cannot be separated by a hyperplane into two classes .
- The perceptron was invented by Frank Rosenblatt in 1957, and was inspired by the biological neurons in the brain .
