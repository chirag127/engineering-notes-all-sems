### SUPPORT VECTOR MACHINE

- Support vector machine (SVM) is a supervised machine learning algorithm that can be used for both classification and regression tasks.
- SVM tries to find a hyperplane that separates the data into different classes or predicts the output value based on the input features .
- SVM is considered a nonparametric technique because it relies on kernel functions to map the data into a higher-dimensional space where the separation is possible .
- SVM has two main parameters: the regularization parameter C and the kernel parameter gamma .
- The regularization parameter C controls the trade-off between the complexity of the model and the error on the training data. A larger C means a more complex model that fits the data better, but may overfit .
- The kernel parameter gamma determines how much influence a single training example has on the decision boundary. A larger gamma means a more localized decision boundary, but may overfit .
- SVM can use different types of kernels, such as linear, polynomial, radial basis function (RBF), or sigmoid, depending on the nature of the data  .
- SVM has some advantages, such as being effective in high-dimensional spaces, being robust to outliers, and having a unique solution.
- SVM also has some disadvantages, such as being sensitive to the choice of parameters, being computationally expensive, and requiring scaling of the input data.
