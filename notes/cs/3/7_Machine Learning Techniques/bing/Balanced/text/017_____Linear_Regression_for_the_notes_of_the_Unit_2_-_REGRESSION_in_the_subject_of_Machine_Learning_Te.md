### Linear Regression

- Linear regression is a supervised machine learning technique that models the relationship between one or more independent variables (features) and a dependent variable (target).
- The goal of linear regression is to find the best-fitting line or hyperplane that minimizes the sum of squared errors (SSE) between the predicted and actual values of the target variable.
- Linear regression can be divided into two types: simple linear regression and multiple linear regression.
- Simple linear regression involves only one independent variable and one dependent variable. The equation of the best-fitting line is given by:

    y = b0 + b1x

    where y is the dependent variable, x is the independent variable, b0 is the intercept, and b1 is the slope of the line.

- Multiple linear regression involves more than one independent variable and one dependent variable. The equation of the best-fitting hyperplane is given by:

    y = b0 + b1x1 + b2x2 + ... + bnxn

    where y is the dependent variable, x1, x2, ..., xn are the independent variables, b0 is the intercept, and b1, b2, ..., bn are the coefficients of the hyperplane.

- Linear regression can be used for various purposes, such as prediction, inference, hypothesis testing, and model evaluation.
- Linear regression can be performed using various methods, such as ordinary least squares (OLS), gradient descent, normal equation, ridge regression, lasso regression, and elastic net regression.
- Linear regression has some assumptions, such as linearity, homoscedasticity, independence, normality, and multicollinearity, that need to be checked before applying the technique.
- Linear regression has some advantages, such as simplicity, interpretability, and applicability to various types of data.
- Linear regression has some limitations, such as sensitivity to outliers, overfitting, underfitting, and inability to capture nonlinear relationships.
