
### Create a Table for Unit 5 - Design Server Site Applications Using JDDC, ODBC and Section Tracking API
When designing server site applications using JDDC, ODBC and section tracking API, it is important to create a table that contains the following fields:

* Name
* Password
* Email-ID
* Phone number

These fields are necessary for tracking the progress of the server site applications. The name field is used to identify the user, the password field is used to authenticate the user, the email-ID field is used to contact the user and the phone number field is used to verify the user's identity.
