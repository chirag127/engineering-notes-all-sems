
## Unit 3 - Design dynamic web pages using Javascript and XML

* Dynamic web pages are web pages that are generated as a result of a user's interaction with the page. 
* JavaScript is a scripting language used to create interactive web pages. It is used to create dynamic web pages that respond to user input and can also be used to create games and other interactive applications.
* XML (Extensible Markup Language) is a markup language used to store and transport data. It is used to store data in a structured way, making it easier to exchange information between different systems.
* JavaScript and XML can be used together to create dynamic web pages. JavaScript is used to provide the user interface and interactivity, while XML is used to store and transport data.
* JavaScript can be used to make requests to a server and receive data in XML format. This data can then be used to update the page dynamically.
* JavaScript can also be used to manipulate the XML data and display it in a user-friendly way.
* In addition, XML can be used to store the data that is generated by the user's interaction with the page, so that it can be accessed later.
