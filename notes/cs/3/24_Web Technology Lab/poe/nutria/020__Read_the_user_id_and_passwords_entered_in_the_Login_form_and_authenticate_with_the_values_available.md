
### Read the user id and passwords entered in the Login form and authenticate with the values available in the cookies

1. The user id and password must be entered into the login form.
2. The authentication process is done by comparing the values entered with the values stored in the cookies.
3. The cookies contain information about the user, such as their username and password.
4. The cookies must be checked to ensure that the user is authorized to access the notes for Unit 5 - Design server site applications using JDDC, ODBC and section tracking API in the subject of Web Technology Lab.
5. Once the authentication process is successful, the user can access the notes.
