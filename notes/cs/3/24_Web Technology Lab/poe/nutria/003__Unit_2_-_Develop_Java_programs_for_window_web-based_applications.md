
## Unit 2 - Develop Java programs for window/web-based applications

1. Java is an object-oriented programming language that can be used to create applications for Windows and the web. 
2. Java programs are platform independent, meaning they can run on any system with a Java Virtual Machine (JVM). 
3. Java programs are composed of classes, which contain methods and variables. 
4. Java has a wide range of built-in data types and objects. 
5. Java programs can be compiled into bytecode, which can then be executed by the JVM. 
6. Java programs can be written in an integrated development environment (IDE) such as Eclipse or NetBeans. 
7. Java programs can be debugged using breakpoints, watches, and the Java debugger. 
8. Java programs can be tested using unit tests and integration tests. 
9. Java programs can be deployed to web servers using servlets and web services. 
10. Java programs can be deployed to mobile devices using Android Studio.
