
### Writing HTML/JavaScript to Display Your CV

1. To display your CV in a browser, you need to write HTML/JavaScript code.
2. HTML is a markup language used to create webpages. It consists of tags and attributes that define the structure of a page.
3. JavaScript is a scripting language used to create dynamic websites. It can be used to add interactivity to webpages.
4. To create a CV, you need to write HTML code to define the structure of your CV. This includes the headings, paragraphs, and other elements that make up the page.
5. You can also add styling to your CV using CSS. CSS is a language used to define the look and feel of a webpage.
6. You can also add interactivity to your CV using JavaScript. This includes creating buttons, forms, and other interactive elements.
7. Once you have written the HTML/JavaScript code, you can upload it to your Institute website, Department website, and Tutorial website for Unit 1 - Develop static webpages using HTML in the subject of Web Technology Lab.
