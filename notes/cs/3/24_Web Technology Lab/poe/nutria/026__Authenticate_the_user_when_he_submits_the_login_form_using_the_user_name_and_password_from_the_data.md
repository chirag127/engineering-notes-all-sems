
### Authenticate the user when he submits the login form 

1. To authenticate the user when he submits the login form, the user name and password from the database must be retrieved. 
2. JDDC, ODBC and section tracking API can be used to access the database. 
3. The user name and password must be verified against the database to authenticate the user. 
4. Once the user is authenticated, the notes of Unit 5 - Design server site applications can be accessed.
