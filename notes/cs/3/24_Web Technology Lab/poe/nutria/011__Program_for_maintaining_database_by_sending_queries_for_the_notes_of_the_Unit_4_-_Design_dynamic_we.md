
### Program for Maintaining Database by Sending Queries for the Notes of the Unit 4 - Design Dynamic Web Page Using Server Site Programming Ex. ASP/JSP/PHP in the Subject of Web Technology Lab

1. A database is a collection of data, stored and organized in a manner that allows for easy retrieval and manipulation. 
2. In order to maintain a database, it is necessary to send queries to the database to retrieve data, or to update and delete data. 
3. Queries are written using a language called Structured Query Language (SQL). 
4. SQL is used to create, update, delete, and retrieve data from a database. 
5. Unit 4 of the Web Technology Lab focuses on the design of dynamic web pages using server-side programming languages such as ASP, JSP, and PHP. 
6. These languages allow the user to create web pages that can interact with a database, by sending SQL queries to the database. 
7. The user can use these languages to create dynamic web pages that can display data from the database, update the database with new data, or delete data from the database. 
8. In order to create a dynamic web page, the user must be familiar with the syntax of the language they are using, as well as the syntax of SQL.
