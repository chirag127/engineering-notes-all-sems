### Write a Java applet to display the Application Program screen i.e. calculator and other for the notes of the Unit 2 - Develop Java programs for window/web-based applications in the subject of Web Technology Lab.

1. Import necessary packages like java.awt, java.applet
2. Extend Applet class and override init(), start(), stop() and paint() methods
3. In init() method, set the size of applet window and background color
4. In start() method, create AWT components like buttons, textfields and labels required for calculator
5. In actionperformed() method of buttons, write logic to perform arithmetic operations like addition, subtraction, multiplication and division
6. In paint() method, draw strings/labels to display the output
7. Use <applet> tag to embed the applet in HTML file
8. Compile the .java file and run the .html file to view the output
