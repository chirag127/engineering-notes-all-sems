## Unit 3 - Design dynamic web pages using Javascript and XML.

1. JavaScript - JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It allows web pages to be interactive and more dynamic. Some of the uses of JavaScript are:
    - Validating web form data
    - Creating cookies
    - Redirecting web page navigation
    - Animating images or other elements
    - Receiving and sending data using AJAX which stands for Asynchronous JavaScript and XML
2. DOM - The Document Object Model (DOM) is a programming interface for HTML and XML documents. It represents the page so that programs can change the document structure, style, and content. The DOM defines the logical structure of documents and the way a document is accessed and manipulated.
3. XML - XML stands for Extensible Markup Language. It is a markup language much like HTML. It was designed to store and transport data. Some of the key features of XML are:
    - It is self-descriptive
    - It is platform independent and programming language independent
    - It supports namespaces to avoid element name conflicts
    - It has a hierarchical or tree-like structure
    - It supports validation using XML schemas
4. JavaScript can be used to manipulate both HTML DOM and XML DOM to create dynamic web pages. Some of the common tasks using JavaScript and XML are:
    - Loading external XML data into a web page
    - Transforming XML data into HTML for display
    - Animating parts of an XML document
    - Highlighting items in an XML document based on user input
    - Performing calculations or other functions on XML data values
