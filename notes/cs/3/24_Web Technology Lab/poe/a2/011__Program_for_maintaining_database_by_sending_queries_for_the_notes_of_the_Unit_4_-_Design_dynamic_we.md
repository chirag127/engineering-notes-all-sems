### Program for maintaining database by sending queries for the notes of the Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP in the subject of Web Technology Lab

1. Connect to the database - Establish a connection between the program and the database by providing hostname, username, password and database name.
2. Create a table - Send a query to create a table with required number of columns and specify the data type and constraints for each column.
3. Insert data - Send an insert query with values in the correct order to insert data into the table.
4. Read data - Send a select query to read the data from the table and display it.
5. Update data - Send an update query with a where clause to update existing data.
6. Delete data - Send a delete query with a where clause to delete data from the table.
7. Close the connection - Close the connection to the database after performing all the operations.
