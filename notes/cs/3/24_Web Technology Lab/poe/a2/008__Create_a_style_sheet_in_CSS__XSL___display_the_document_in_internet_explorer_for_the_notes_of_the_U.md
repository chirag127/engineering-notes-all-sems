### Create a style sheet in CSS/ XSL & display the document in internet explorer for the notes of the Unit 3 - Design dynamic web pages using Javascript and XML in the subject of Web Technology Lab:

1. Create an HTML file with basic structure and add some content. For example:

```html
<!DOCTYPE html>
<html>
<head>
</head>
<body>
<h1>Welcome</h1>
<p>This is a sample page</p>
</body>
</html>
```

2. Create a CSS file and add styles to the HTML elements. For example:

```css
h1 {
  color: blue;
}

p {
  font-size: 20px;
}
```

3. Link the CSS file to the HTML file using `<link>` element in the `<head>`

```html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
```

4. Load the HTML file in Internet Explorer and see the styling applied.

5. Alternatively, create an XSL file to transform the HTML and apply styles. An XSL file requires adding processing instructions to the HTML file to associate the XSL file. The output can be viewed in the browser.
