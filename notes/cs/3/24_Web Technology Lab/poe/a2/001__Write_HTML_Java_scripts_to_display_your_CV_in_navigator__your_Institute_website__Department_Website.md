### Write HTML/Java scripts to display your CV in navigator, your Institute website, Department Website and Tutorial website for specific subject for the notes of the Unit 1 - Develop static web pages using HTML in the subject of Web Technology Lab:

- Create an HTML file with .html extension.
- Use HTML tags to structure the content. For example:
<html>
    <head>
        <title>CV</title>
    </head>
    <body>
        <h1>Your Name</h1>
        <p>Your bio, qualifications, skills, etc.</p>
    </body>
</html>
- Use appropriate tags for headings, paragraphs, lists, etc.
- Include images using <img> tag. For example: <img src="image.jpg" alt="Your Image">
- Add links to your social media profiles or other web pages using <a>anchor tag. For example: <a href="www.facebook.com">Facebook</a>
- Use CSS styles to customize the appearance. You can include CSS in HTML document using <style> tag or link an external .css file.
- To display the HTML file in a web browser, simply double click the file or drag and drop the file into a browser window.
- To display on a website, upload the HTML file to the website and access it using the file's URL.
- For department or tutorial website, get access to upload content to the site and then upload your HTML file. The file will be displayed on the website and can be accessed by anyone visiting the site.
