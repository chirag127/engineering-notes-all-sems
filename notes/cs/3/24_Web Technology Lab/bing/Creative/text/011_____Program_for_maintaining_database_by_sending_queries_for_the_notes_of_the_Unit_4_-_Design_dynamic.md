### Program for maintaining database by sending queries for the notes of the Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP in the subject of Web Technology Lab

- Server-side programming is the process of creating web pages that are dynamically generated by the server based on user input or other data sources.
- Server-side programming languages are used to interact with databases, files, other servers, web applications, and user input.
- ASP, JSP, and PHP are examples of popular server-side programming languages that can create dynamic web pages    .
- ASP stands for Active Server Pages, a server-side scripting language that uses VBScript or JScript to embed code in HTML pages.
- JSP stands for Java Server Pages, a server-side scripting language that uses Java to embed code in HTML or XML pages .
- PHP stands for Hypertext Preprocessor, a server-side scripting language that uses PHP to embed code in HTML pages .
- To maintain a database by sending queries using server-side programming, the following steps are required:
  - Connect to the database using the appropriate functions or classes of the server-side language.
  - Write SQL queries to perform operations on the database, such as creating, reading, updating, or deleting data.
  - Execute the queries using the appropriate functions or classes of the server-side language.
  - Fetch the results of the queries and display them on the web page using the appropriate functions or classes of the server-side language.
  - Close the connection to the database using the appropriate functions or classes of the server-side language.
- The following are some examples of code snippets for maintaining a database by sending queries using ASP, JSP, and PHP:

```asp
<% 'ASP code to connect to a database and execute a query
'Create a connection object
Set conn = Server.CreateObject("ADODB.Connection")
'Open the connection using a connection string
conn.Open "Provider=SQLOLEDB;Data Source=server_name;Initial Catalog=database_name;User Id=user_name;Password=password;"
'Create a recordset object
Set rs = Server.CreateObject("ADODB.Recordset")
'Write a SQL query
sql = "SELECT * FROM table_name"
'Execute the query and store the results in the recordset object
rs.Open sql, conn
'Display the results on the web page
Do While Not rs.EOF
  Response.Write(rs("column_name") & "<br>")
  rs.MoveNext
Loop
'Close the recordset and the connection objects
rs.Close
conn.Close
%>
```

```jsp
<% //JSP code to connect to a database and execute a query
//Import the required classes
import java.sql.*;
//Create a connection object
Connection conn = null;
//Create a statement object
Statement stmt = null;
//Create a resultset object
ResultSet rs = null;
//Write a SQL query
String sql = "SELECT * FROM table_name";
try {
  //Load the driver class
  Class.forName("com.mysql.jdbc.Driver");
  //Open the connection using a connection string
  conn = DriverManager.getConnection("jdbc:mysql://server_name:port/database_name", "user_name", "password");
  //Create a statement object from the connection object
  stmt = conn.createStatement();
  //Execute the query and store the results in the resultset object
  rs = stmt.executeQuery(sql);
  //Display the results on the web page
  while (rs.next()) {
    out.println(rs.getString("column_name") + "<br>");
  }
} catch (Exception e) {
  //Handle any exceptions
  e.printStackTrace();
} finally {
  //Close the resultset, the statement, and the connection objects
  if (rs != null) rs.close();
  if (stmt != null) stmt.close();
  if (conn != null) conn.close();
}
%>
```
