## Unit 1 - Develop static web pages using HTML

Unit 1 of the Software Engineering Mapping with Virtual Lab Lab in the subject of Software Engineering focuses on developing static web pages using HTML. The following are the key concepts and techniques covered in this unit:

1. HTML: HTML (Hypertext Markup Language) is the standard markup language for creating web pages. HTML provides the structure and content of web pages, and is used to define the text, images, links, and other elements that make up a web page.

2. HTML Elements: HTML elements are the basic building blocks of HTML, and are used to define the content and structure of web pages. HTML elements include headings, paragraphs, lists, links, images, and more.

3. HTML Attributes: HTML attributes are used to provide additional information about HTML elements, such as the size, color, and style of text, images, and other elements.

4. HTML Forms: HTML forms are used to collect information from users, and are an important part of many web applications. HTML forms can be used to create input fields, buttons, checkboxes, and other elements that allow users to enter and submit data.

5. HTML Tables: HTML tables are used to display data in a tabular format, and are an important part of many web applications. HTML tables can be used to create headers, rows, and columns, and can be used to display data in a variety of formats.

In this unit, you will learn how to develop static web pages using HTML, including the key concepts and techniques involved in creating web pages using HTML. This unit will provide hands-on experience with the concepts and techniques used in web development, and will help you to develop the skills needed to create effective and efficient web pages.
