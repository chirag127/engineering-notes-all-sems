### Create MS Access Database, Create on ODBC link, Compile & execute JAVA JDVC Socket for the notes of the Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP in the subject of Web Technology Lab

Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP in the subject of Web Technology Lab covers the following topics:

1. Create MS Access Database:
Creating an MS Access database involves defining the structure of the database, including the tables, fields, and relationships between the tables. This can be done using the MS Access graphical user interface or by writing SQL code.

2. Create an ODBC Link:
An ODBC (Open Database Connectivity) link is used to connect an MS Access database to a web application, such as an ASP or JSP page. This allows the web application to query and manipulate the data in the database.

3. Compile & Execute Java JDBC Socket:
Java JDBC (Java Database Connectivity) sockets are used to connect Java applications to databases. To use a JDBC socket, the Java code must be compiled and executed, and the JDBC driver must be installed on the computer.

In conclusion, these topics are important for designing dynamic web pages using server-side programming. By creating an MS Access database and an ODBC link, data can be stored and retrieved from a database, while Java JDBC sockets provide a means for connecting Java applications to databases and accessing the data stored in the database.
