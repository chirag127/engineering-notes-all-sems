## Unit 4 - Design dynamic web page using server site programming Ex. ASP/JSP/PHP

Designing Dynamic Web Pages using Server-side Programming:

Dynamic web pages are web pages that change content based on user input, or based on data from a database. To create dynamic web pages, server-side programming languages such as ASP, JSP, and PHP are used. These languages are executed on the server, and generate HTML content that is sent to the client's browser.

ASP (Active Server Pages) is a server-side scripting language developed by Microsoft. ASP is used to create dynamic web pages by embedding scripting code within HTML pages. The server-side code is executed on the server, and the resulting HTML content is sent to the client's browser.

JSP (JavaServer Pages) is a server-side scripting language based on Java. JSP is used to create dynamic web pages by embedding Java code within HTML pages. The server-side code is executed on the server, and the resulting HTML content is sent to the client's browser.

PHP (Hypertext Preprocessor) is a server-side scripting language used for creating dynamic web pages. PHP code is embedded within HTML pages, and is executed on the server. The resulting HTML content is sent to the client's browser.

In conclusion, dynamic web pages are web pages that change content based on user input, or based on data from a database. To create dynamic web pages, server-side programming languages such as ASP, JSP, and PHP are used. These languages are executed on the server, and generate HTML content that is sent to the client's browser. ASP, JSP, and PHP are widely used server-side scripting languages, each with its own strengths and weaknesses, and each well-suited for different types of web applications.
