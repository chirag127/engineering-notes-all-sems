# Modern Data Analytic Tools

Data analytics is the process of collecting, organizing, analyzing, and presenting data to gain insights and make informed decisions. Data analytics can be applied to various domains, such as business, science, engineering, education, health, and social sciences.

Modern data analytic tools are software applications or platforms that enable data analysts to perform data analytics tasks more efficiently and effectively. Modern data analytic tools can offer features such as data ingestion, data transformation, data storage, data analysis, data visualization, data reporting, and data collaboration.

Some of the modern data analytic tools that are widely used in 2023 are:

- **Python**: Python is a general-purpose programming language that supports multiple paradigms, such as object-oriented, functional, procedural, and imperative. Python has a rich set of libraries and frameworks for data analytics, such as NumPy, pandas, SciPy, scikit-learn, TensorFlow, PyTorch, and matplotlib. Python is easy to learn, write, and read, and has a large and active community of developers and users .
- **R**: R is a programming language and environment for statistical computing and graphics. R has a comprehensive collection of packages and functions for data manipulation, analysis, modeling, and visualization, such as dplyr, tidyr, ggplot2, shiny, and rmarkdown. R is widely used by statisticians, data scientists, and researchers for exploratory data analysis, data mining, machine learning, and reporting .
- **SAS**: SAS is a software suite for advanced analytics, business intelligence, data management, and predictive analytics. SAS has a proprietary programming language and a graphical user interface for data processing, analysis, and visualization. SAS is widely used by enterprises and organizations for data integration, data quality, data warehousing, data mining, statistical analysis, and reporting .
- **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel can perform basic and advanced calculations, data manipulation, data analysis, and data visualization using formulas, functions, charts, pivot tables, and macros. Excel is widely used by business professionals, managers, and analysts for data entry, data management, data analysis, and reporting .
- **Power BI**: Power BI is a business analytics service that is part of the Microsoft Power Platform. Power BI can connect to various data sources, such as databases, files, web services, and cloud platforms. Power BI can transform, model, analyze, and visualize data using queries, dataflows, datasets, reports, dashboards, and apps. Power BI can also leverage artificial intelligence and machine learning capabilities to generate insights and recommendations  .
- **Tableau**: Tableau is a business intelligence and data visualization platform that can connect to various data sources, such as databases, files, web services, and cloud platforms. Tableau can transform, analyze, and visualize data using worksheets, dashboards, stories, and maps. Tableau can also leverage artificial intelligence and machine learning capabilities to generate insights and recommendations .
- **Apache Spark**: Apache Spark is an open-source distributed computing framework that can process large-scale data in parallel and in memory. Apache Spark can perform batch processing, stream processing, machine learning, graph processing, and SQL queries using various libraries and APIs, such as Spark Core, Spark SQL, Spark Streaming, MLlib, GraphX, and SparkR. Apache Spark can run on various cluster managers, such as Hadoop YARN, Apache Mesos, and Kubernetes  .
