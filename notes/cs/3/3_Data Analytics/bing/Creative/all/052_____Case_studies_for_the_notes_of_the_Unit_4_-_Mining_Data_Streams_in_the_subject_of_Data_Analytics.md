# Case studies for the notes of the Unit 4 - Mining Data Streams in the subject of Data Analytics

Mining data streams is the process of extracting knowledge structures represented in models and patterns from continuous and unbounded streams of information. Data stream mining has many applications and challenges in various domains, such as network monitoring, sensor networks, web mining, social media analysis, etc. In this unit, we will review some case studies for mining data streams using different techniques and methods.

## Case study 1: Stream Data Mining Classification

This case study presents a stream data mining classification task using the MOA (Massive Online Analysis) framework. The goal is to classify the network intrusion data stream, which contains normal and malicious network connections. The data stream is generated by the KDD Cup 1999 dataset, which has 41 attributes and 4 classes (normal, probe, dos, u2r, r2l). The case study compares four stream classification algorithms: Naive Bayes, Hoeffding Tree, Hoeffding Option Tree, and Adaptive Random Forest. The evaluation metrics are accuracy, kappa, and memory usage. The results show that Adaptive Random Forest has the best performance in terms of accuracy and kappa, while Hoeffding Tree has the lowest memory usage.

## Case study 2: Data Stream Clustering

This case study presents a data stream clustering task using the CluStream algorithm. The goal is to cluster the electricity price data stream, which contains the hourly prices of electricity in New England from 1998 to 2003. The data stream has two attributes: time and price. The case study applies the CluStream algorithm to the data stream, which maintains a summary of the data stream using micro-clusters and macro-clusters. The micro-clusters are updated online with the incoming data, while the macro-clusters are generated offline using a user-defined time horizon. The case study shows how the CluStream algorithm can capture the evolving patterns and trends of the data stream over time, such as seasonal variations, daily cycles, and outliers.

## Case study 3: Data Stream Mining for Big Data

This case study presents a data stream mining approach for big data using the MOA framework. The goal is to predict the customer churn rate for a telecommunication company, which is the percentage of customers who stop using the service within a given period. The data stream is generated by a real-world dataset, which has 21 attributes and 2 classes (churn or not churn). The case study proposes an improvised method for tackling big data stream mining challenges, which consists of four steps: feature selection, data preprocessing, ensemble learning, and concept drift detection. The case study compares the proposed method with the baseline method, which uses all the features and a single classifier. The evaluation metrics are accuracy, kappa, and F-measure. The results show that the proposed method outperforms the baseline method in terms of all the metrics, and can handle the high dimensionality, noise, imbalance, and concept drift of the data stream.
