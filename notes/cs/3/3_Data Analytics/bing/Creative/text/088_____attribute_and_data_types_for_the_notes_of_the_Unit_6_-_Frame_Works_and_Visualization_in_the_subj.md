### Attribute and Data Types

- An attribute is a characteristic or property of an entity, such as a person, product, or event.
- A data type is a classification of data that specifies how the data can be stored, manipulated, and displayed.
- There are different types of attributes and data types, depending on the context and purpose of the data analysis.
- Some common types of attributes and data types are:

  - **Nominal**: A nominal attribute is a categorical attribute that has no inherent order or ranking. For example, the names of countries, colors, or genres are nominal attributes. A nominal data type is a data type that can store nominal attributes, such as strings or integers.
  - **Ordinal**: An ordinal attribute is a categorical attribute that has a meaningful order or ranking, but no fixed interval or ratio between the values. For example, the ratings of movies, the levels of education, or the sizes of clothes are ordinal attributes. An ordinal data type is a data type that can store ordinal attributes, such as integers or enums.
  - **Interval**: An interval attribute is a numerical attribute that has a fixed interval or difference between the values, but no absolute zero point. For example, the temperatures in Celsius or Fahrenheit, the dates in a calendar, or the scores in a test are interval attributes. An interval data type is a data type that can store interval attributes, such as floats or dates.
  - **Ratio**: A ratio attribute is a numerical attribute that has a fixed interval or difference between the values, and an absolute zero point. For example, the heights or weights of people, the distances or speeds of objects, or the prices or quantities of products are ratio attributes. A ratio data type is a data type that can store ratio attributes, such as floats or decimals.
  - **Binary**: A binary attribute is a special type of nominal attribute that has only two possible values, such as true or false, yes or no, or 0 or 1. A binary data type is a data type that can store binary attributes, such as booleans or bits.
