### Introduction to streams concepts

- A data stream is an existing, continuous, ordered (implicitly by entrance time or explicitly by timestamp) chain of items.
- Data streams can be generated by various sources, such as equipment sensors, clickstreams, social media feeds, stock market quotes, app activity, and more.
- Data stream processing is the continuous processing and analysis of big data in motion .
- Data stream processing can enable real-time analytics, which is any method of data processing that results in a latency period defined as “real-time”.
- Real-time analytics can be classified into hard and soft real-time, depending on the strictness of the latency requirements.
- Data stream processing can involve various operations, such as filtering, transforming, enhancing, aggregating, joining, or windowing the data.
- Data stream processing can also involve storing only the summary of the data seen so far, such as statistics, sketches, samples, or models.
- Data stream processing can be implemented using various tools and frameworks, such as Apache Kafka, Apache Spark, Apache Flink, Apache Storm, StreamSets, and more .
- Data stream processing can enable various use cases and applications, such as fraud detection, anomaly detection, sentiment analysis, recommendation systems, dashboarding, and more .
