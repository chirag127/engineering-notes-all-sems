### Introduction to streams concepts

- A data stream is an existing, continuous, ordered (implicitly by entrance time or explicitly by timestamp) chain of items.
- Data streams capture the data processing needs of today, where random access is expensive and a single scan algorithm is preferred.
- Data streams can come from various sources, such as equipment sensors, clickstreams, social media feeds, stock market quotes, app activity, and more.
- Stream processing is a data management technique that involves ingesting a continuous data stream to quickly analyze, filter, transform or enhance the data in real time.
- Stream processing can enable applications such as real-time analytics, fraud detection, event processing, and data integration.
- Streaming data analytics is the process of extracting insights from data streams in real time or near real time using various methods and tools.
- Streaming data analytics can provide benefits such as faster decision making, improved customer experience, reduced operational costs, and increased competitive advantage.
- Streaming data analytics requires a streaming data architecture that consists of key components such as data sources, data ingestion, stream processing, data storage, and data consumption.
- Streaming data architecture can vary depending on the use case, the data volume, the data velocity, the data variety, and the data quality.
- Streaming data architecture can leverage various technologies and frameworks, such as Apache Kafka, Apache Spark, Apache Flink, Apache Beam, and StreamSets.
