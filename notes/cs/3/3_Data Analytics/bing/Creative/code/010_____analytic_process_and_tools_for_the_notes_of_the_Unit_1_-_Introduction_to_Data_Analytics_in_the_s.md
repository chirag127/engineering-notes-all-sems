### Analytic Process and Tools

- A process is a group of resources and activities that transforms inputs into outputs by adding value and executing repeatable tasks in a specific order.
- Process analysis is the systematic examination of a process to identify its purpose, objectives, inputs, outputs, activities, resources, performance indicators, and potential areas for improvement.
- Process analysis tools are techniques or software that help in process modeling, documentation, measurement, evaluation, and improvement.
- Some of the common process analysis tools are:
  - Flowchart: A graphical representation of the steps of a process in sequential order, showing the inputs, outputs, decisions, and people involved.
  - Process map: A detailed diagram of the process, showing the inputs, outputs, activities, resources, roles, responsibilities, and interrelationships of each step.
  - Procedure: A written document that describes the process in a clear, concise, and consistent manner, specifying the purpose, scope, steps, roles, and expected outcomes.
  - Work instruction: A detailed document that provides step-by-step instructions on how to perform a specific task or activity within a process.
  - Cause and effect diagram: A graphical tool that helps identify the possible causes of a problem or an effect by organizing them into categories and subcategories.
  - Pareto chart: A graphical tool that helps prioritize the most significant causes or effects of a problem by ranking them according to their frequency or impact.
  - Histogram: A graphical tool that shows the distribution of data values in a process, indicating the variation, central tendency, and outliers.
  - Control chart: A graphical tool that monitors the stability and performance of a process over time, showing the average, upper and lower control limits, and any special causes of variation.
- Data analytics is the process of collecting, organizing, analyzing, and interpreting data to generate insights, support decision making, and solve problems.
- Data analytics tools are software or applications that help in data acquisition, preparation, analysis, visualization, and reporting.
- Some of the popular data analytics tools are:
  - Microsoft Power BI: A data analytics tool that provides interactive data visualization, business intelligence, and reporting capabilities, integrating with various data sources and platforms.
  - Tableau: A data analytics tool that offers powerful data analysis, visualization, and dashboard creation features, enabling users to explore, understand, and share data insights.
  - Qlik Sense: A data analytics tool that leverages machine learning and artificial intelligence to provide self-service data analysis, visualization, and discovery, allowing users to ask natural language questions and get answers.
  - Looker: A data analytics tool that connects to various data sources and platforms, providing a unified data model, a flexible query language, and customizable data visualization and reporting options.
  - R: A programming language and environment that supports data analysis, manipulation, visualization, and statistical computing, offering a wide range of packages and libraries.
  - Python: A programming language and environment that supports data analysis, manipulation, visualization, and machine learning, offering a rich set of modules and frameworks.
