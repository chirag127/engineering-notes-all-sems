# Unit 6 - Frameworks and Visualization

- Frameworks are sets of principles, concepts, and methods that guide the design and implementation of visual representations of information.
- Visualization is the process of creating and using visual representations of information to communicate, explore, analyze, or understand data or concepts.
- Frameworks and visualization are closely related, as frameworks provide the theoretical and practical foundations for creating effective and appropriate visualizations for different purposes and audiences.
- Some examples of frameworks and visualization are:

  - A framework for analyzing and designing diagrams and graphics, which provides a vocabulary and a method for thoroughly analyzing the full spectrum of visual representations of information, and a mechanism for exploring previously unexploited combinations of visual encoding principles for representing information.
  - A 7-step data visualization framework for stronger storytelling, which helps to empower audiences with actionable information by breaking down data into an easily digestible visual format, following the steps of: define, collect, clean, analyze, visualize, refine, and share.
  - A list of 11 JavaScript frameworks for creating graphics, which showcases some libraries that will help you create stunning graphics using the browser's high-powered drawing APIs and surfaces, such as canvas and SVG.
  - A data visualization literacy framework, which defines data visualization literacy as the ability to read, make, and explain data visualizations, and proposes a set of core competencies and assessment methods for teaching and evaluating data visualization literacy.
  - A cognitive framework for decision making with visualizations, which examines how visualizations support different types of decision making across domains and contexts, and identifies the cognitive processes and factors that influence the use and effectiveness of visualizations for decision making.
