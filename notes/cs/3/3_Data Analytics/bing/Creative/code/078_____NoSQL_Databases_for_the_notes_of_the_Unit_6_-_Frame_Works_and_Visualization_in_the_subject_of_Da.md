### NoSQL Databases

- NoSQL databases are databases that store and retrieve data in formats other than relational tables .
- NoSQL databases are also known as "not only SQL", "non-SQL", or "non-relational" databases  .
- NoSQL databases can store data that is structured, semi-structured, or unstructured.
- NoSQL databases can handle large volumes of data and high concurrency with high performance and scalability .
- NoSQL databases can be classified into four main types based on their data model:
  - Document databases: store data as documents, usually in JSON or XML format. Each document can have a different structure and contain various fields and values. Examples: MongoDB, CouchDB, Firebase.
  - Key-value databases: store data as pairs of keys and values. Each key is unique and can be used to retrieve the corresponding value. Values can be simple data types or complex objects. Examples: Redis, DynamoDB, Memcached.
  - Wide-column databases: store data as rows and columns, similar to relational tables, but with more flexibility. Each row can have a different number of columns, and columns can have different data types. Columns are grouped into column families, which are stored together for fast access. Examples: Cassandra, HBase, Bigtable.
  - Graph databases: store data as nodes and edges, representing entities and relationships. Nodes can have properties and labels, and edges can have types and directions. Graph databases are suitable for modeling complex networks and queries that involve traversing multiple connections. Examples: Neo4j, OrientDB, ArangoDB.
