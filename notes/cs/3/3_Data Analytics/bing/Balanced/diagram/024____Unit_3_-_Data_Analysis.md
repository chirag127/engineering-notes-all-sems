## Unit 3 - Data Analysis

Data analysis is the process of collecting, organizing, summarizing, and interpreting data to answer questions or test hypotheses. Data analysis can be done using various methods and tools, depending on the type and purpose of the data.

Some of the topics covered in this unit are:

- **Descriptive statistics**: These are numerical or graphical methods to summarize and display the features of a data set, such as mean, median, mode, range, standard deviation, frequency, histogram, boxplot, etc.
- **Inferential statistics**: These are methods to draw conclusions or make predictions about a population based on a sample of data, such as confidence intervals, hypothesis testing, correlation, regression, etc.
- **Data visualization**: This is the art and science of presenting data in an effective and appealing way, using charts, graphs, maps, dashboards, etc. Data visualization can help to explore, communicate, and persuade with data.
- **Data cleaning**: This is the process of identifying and correcting errors, inconsistencies, outliers, missing values, and duplicates in a data set, using techniques such as filtering, sorting, grouping, merging, etc. Data cleaning can improve the quality and reliability of the data analysis.
- **Data transformation**: This is the process of changing the format, structure, or values of a data set, using techniques such as scaling, standardizing, normalizing, encoding, etc. Data transformation can make the data more suitable for analysis or modeling.
- **Data modeling**: This is the process of creating a mathematical or statistical representation of a data set, using techniques such as linear models, logistic models, decision trees, neural networks, etc. Data modeling can help to understand the relationships, patterns, and trends in the data.
