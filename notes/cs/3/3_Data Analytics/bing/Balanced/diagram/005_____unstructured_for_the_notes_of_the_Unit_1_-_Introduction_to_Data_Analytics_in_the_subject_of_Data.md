### Unstructured Data

- Unstructured data is information that does not have a pre-defined data model or is not organized in a pre-defined manner.
- Unstructured data is typically text-heavy, but may contain other types of data such as dates, numbers, images, audio, video, etc.
- Unstructured data cannot be processed and analyzed via conventional data tools and methods.
- Unstructured data is best managed in non-relational (NoSQL) databases, which do not require a fixed schema or structure.
- Unstructured data accounts for the vast majority of new data being generated today, such as social media posts, emails, blogs, web pages, etc.
- Unstructured data poses many challenges for data analytics, such as data quality, data integration, data storage, data retrieval, data mining, data visualization, etc.
- Unstructured data also offers many opportunities for data analytics, such as sentiment analysis, natural language processing, image recognition, speech recognition, text summarization, etc.
