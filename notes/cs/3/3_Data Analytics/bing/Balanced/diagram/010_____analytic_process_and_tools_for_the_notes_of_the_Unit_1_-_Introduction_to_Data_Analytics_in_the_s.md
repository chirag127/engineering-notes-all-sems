### Analytic Process and Tools

- A process is a group of resources and activities that transforms inputs into outputs by adding value and executing repeatable tasks in a specific order.
- Process analysis is the method of studying, documenting, and improving a process by identifying its inputs, outputs, activities, resources, and performance indicators.
- Process analysis tools are techniques or software that help in process modeling, documentation, improvement, and evaluation.
- Some of the common process analysis tools are :
  - Flowchart: A graphical representation of the steps of a process in sequential order, showing the inputs, outputs, decisions, and people involved.
  - Process map: A detailed diagram of the process, showing the inputs, outputs, activities, resources, and performance indicators of each step, as well as the relationships and dependencies among them.
  - Written procedure: A textual description of the process, explaining the purpose, scope, roles, responsibilities, and steps of the process, as well as the standards and guidelines to follow.
  - Work instruction: A specific set of instructions for performing a task or activity within the process, providing the details, examples, and tips for completing the task effectively and efficiently.
  - Cause and effect diagram: A tool for identifying and analyzing the potential causes of a problem or an effect, using a fishbone-like structure to organize the causes into categories and subcategories.
  - Pareto chart: A tool for prioritizing the causes of a problem or an effect, using a bar graph and a line graph to show the frequency and cumulative percentage of each cause.
  - Histogram: A tool for displaying the distribution of a set of data, using a bar graph to show the frequency of each value or range of values.
  - Control chart: A tool for monitoring the variation and stability of a process, using a line graph to plot the data points and the upper and lower control limits.
  - Scatter diagram: A tool for exploring the relationship between two variables, using a scatter plot to show the correlation and the trend of the data points.
  - Data analytics is the process of collecting, organizing, analyzing, and interpreting data to generate insights and support decision making.
  - Data analytics tools are software that help in data acquisition, preparation, exploration, visualization, and communication.
  - Some of the popular data analytics tools are:
    - Microsoft Power BI: A tool for data visualization and business intelligence, allowing users to create interactive dashboards and reports from various data sources and share them with others.
    - Tableau: A tool for business intelligence and data visualization, enabling users to connect to various data sources, analyze and explore data, and create and publish dashboards and stories.
    - Qlik Sense: A tool for machine learning and data analytics, empowering users to access, combine, and analyze data from multiple sources, and create and share visualizations and apps.
    - Looker: A tool for data analysis and visualization, providing users with a data platform that connects to various data sources, and a web-based interface that allows users to query, explore, and visualize data.
    - SAS: A tool for data analysis and statistics, offering users a comprehensive suite of software products and solutions for data management, advanced analytics, machine learning, and business intelligence.
