# Unit 1 - Introduction to Data Analytics

## Unstructured Data

- Unstructured data is the data which does not conform to a data model and has no easily identifiable structure such that it can not be used by a computer program easily.
- Unstructured data, typically categorized as qualitative data, cannot be processed and analyzed via conventional data tools and methods.
- Unstructured data does not have a predefined data model, it is best managed in non-relational (NoSQL) databases.
- Unstructured data is typically text-heavy, but may contain data such as dates, numbers, and facts as well.
- Some examples of unstructured data are:
  - Scientific data: This includes oil and gas surveys, space exploration, seismic imagery, and atmospheric data.
  - Digital surveillance: This category features data like reconnaissance photos and videos.
  - Satellite imagery: This data includes weather data, land surveys, and traffic patterns.
  - Social media data: This includes posts, tweets, comments, likes, shares, and reviews from various platforms.
  - Audio and video files: This includes podcasts, music, movies, TV shows, and webinars.
- Unstructured data poses many challenges for data analytics, such as:
  - Storage: Unstructured data requires more space and resources to store than structured data.
  - Processing: Unstructured data is difficult to process and analyze using traditional methods and tools, such as SQL queries and relational databases.
  - Quality: Unstructured data is often incomplete, inconsistent, inaccurate, or irrelevant, which affects the reliability and validity of the analysis.
  - Security: Unstructured data may contain sensitive or personal information that needs to be protected and encrypted.
- Unstructured data also offers many opportunities for data analytics, such as:
  - Insights: Unstructured data can reveal hidden patterns, trends, and insights that structured data may not capture.
  - Innovation: Unstructured data can enable new ways of thinking, problem-solving, and decision-making using advanced techniques and tools, such as natural language processing, machine learning, and artificial intelligence.
  - Value: Unstructured data can create value for businesses and organizations by improving customer satisfaction, operational efficiency, and competitive advantage.
