# Modern Data Analytic Tools

- Data analytics is the process of collecting, organizing, analyzing, and presenting data to gain insights and make informed decisions.
- Modern data analytic tools are software applications or platforms that enable data analysts to perform various tasks related to data analytics, such as data extraction, transformation, loading, modeling, visualization, reporting, and machine learning.
- Some of the modern data analytic tools that are widely used in 2023 are:

  - **Python**: Python is a general-purpose programming language that supports multiple paradigms, such as object-oriented, functional, and procedural. Python has a rich set of libraries and frameworks for data analysis, such as NumPy, pandas, SciPy, scikit-learn, TensorFlow, PyTorch, and Keras. Python also has a large and active community of developers and users who contribute to its development and documentation .
  - **R**: R is a programming language and environment for statistical computing and graphics. R provides a comprehensive collection of packages and functions for data manipulation, visualization, modeling, and machine learning. R also has a vibrant and diverse community of users and developers who share their code and expertise through online platforms, such as CRAN, Bioconductor, and GitHub .
  - **SAS**: SAS is a software suite for advanced analytics, business intelligence, data management, and predictive analytics. SAS offers a variety of tools and solutions for data integration, quality, governance, exploration, visualization, reporting, and machine learning. SAS also provides industry-specific applications and services for various domains, such as healthcare, banking, retail, and manufacturing .
  - **Excel**: Excel is a spreadsheet application that is part of the Microsoft Office suite. Excel allows users to perform basic and advanced calculations, data analysis, and visualization using formulas, functions, charts, pivot tables, and macros. Excel also supports data connection and integration with other sources, such as databases, web services, and Power BI .
  - **Power BI**: Power BI is a cloud-based business intelligence and analytics service that is part of the Microsoft Power Platform. Power BI enables users to connect to various data sources, transform and model data, create interactive dashboards and reports, and share and collaborate with others. Power BI also supports advanced analytics and machine learning capabilities, such as natural language processing, cognitive services, and automated insights .
  - **Tableau**: Tableau is a software company that specializes in data visualization and analytics. Tableau offers a range of products and solutions for data preparation, analysis, and presentation, such as Tableau Desktop, Tableau Server, Tableau Online, and Tableau Public. Tableau also supports integration with various data sources, such as databases, files, web services, and APIs. Tableau also provides features for data storytelling, collaboration, and governance .
  - **Apache Spark**: Apache Spark is an open-source distributed computing framework that provides a unified platform for large-scale data processing, analysis, and machine learning. Spark supports multiple programming languages, such as Scala, Python, Java, and R. Spark also provides a rich set of libraries and APIs for data manipulation, streaming, graph, and machine learning, such as Spark SQL, Spark Streaming, GraphX, and MLlib .
