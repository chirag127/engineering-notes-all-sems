# HBase

HBase is a column-oriented non-relational database management system that runs on top of Hadoop Distributed File System (HDFS). It is an open-source project and is horizontally scalable. HBase is a data model that is similar to Google’s big table designed to provide quick random access to huge amounts of structured data .

Some of the features of HBase are:

- It supports sparse data sets, which are common in many big data use cases.
- It provides a fault-tolerant way of storing and processing data.
- It is well suited for real-time data processing or random read/write access to large volumes of data.
- It is designed to scale linearly by adding more nodes to the cluster.
- It comprises a set of standard tables with rows and columns, much like a traditional database.
- It has a primary key for each table, which is used for accessing the data.
- It supports versioning, which means it can store multiple versions of the same data in the same cell.
- It supports compression, which reduces the storage space and improves the performance.
- It supports replication, which enhances the availability and durability of the data.
- It supports filters, which allow the users to specify the criteria for selecting the data.
- It supports coprocessors, which are user-defined code that can run on the server side and perform custom operations on the data.
