# Mining Frequent Itemsets

- Frequent itemset mining (pattern mining) is a technique used to derive relationships such as regularities in customers’ shopping behavior in physical and online stores to discover association rules out of the relationships.
- Association rules are statements that describe how often items or features co-occur in a given dataset. For example, "80% of customers who buy bread also buy milk" is an association rule that implies a strong relationship between bread and milk in the dataset.
- Frequent itemsets are sets of items or features that appear together in the dataset above a certain frequency threshold. For example, {bread, milk} is a frequent itemset if it occurs in more than 10% of the transactions in the dataset.
- Mining frequent itemsets is the first step of association rule mining, which aims to find interesting and useful patterns in the data that can be used for various purposes, such as recommendation systems, market basket analysis, fraud detection, etc.
- There are several algorithms for mining frequent itemsets, such as Apriori, Eclat, and FP-growth. These algorithms differ in how they search the space of possible itemsets and how they prune the candidates that are unlikely to be frequent.
- Apriori is the most commonly used algorithm for mining frequent itemsets. It works by generating candidate itemsets of increasing size (from 1 to n) and counting their support (frequency) in the dataset. It uses the property that any subset of a frequent itemset must also be frequent (called the Apriori property) to reduce the number of candidates .
- Eclat is a variation of Apriori that uses a depth-first search strategy and a vertical data format (where each item is associated with a set of transactions that contain it) to efficiently mine frequent itemsets. It avoids generating and counting candidates by intersecting the transaction sets of the items and using the set size as the support.
- FP-growth is another algorithm for mining frequent itemsets that uses a compressed data structure called an FP-tree (frequent pattern tree) to store the dataset in a compact and searchable form. It avoids generating candidates by recursively dividing the FP-tree into smaller sub-trees and extracting frequent itemsets from each sub-tree.
