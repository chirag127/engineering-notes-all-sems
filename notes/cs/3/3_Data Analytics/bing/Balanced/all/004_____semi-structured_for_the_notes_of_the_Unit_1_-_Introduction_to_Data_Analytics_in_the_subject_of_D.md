# Semi-structured data
- Semi-structured data is a type of data that has some form of structure, but not as rigid or consistent as structured data.
- Semi-structured data often contains tags, labels, or keywords that provide some information about the data, but not enough to fit into a predefined schema or table.
- Examples of semi-structured data include XML, JSON, HTML, CSV, and log files.
- Semi-structured data is useful for storing and processing complex, heterogeneous, or dynamic data that cannot be easily modeled by structured data.
- Semi-structured data can be queried and analyzed using tools such as XPath, XQuery, JSONPath, or NoSQL databases.
- Semi-structured data can also be converted to structured data using techniques such as data extraction, data transformation, or data integration.
