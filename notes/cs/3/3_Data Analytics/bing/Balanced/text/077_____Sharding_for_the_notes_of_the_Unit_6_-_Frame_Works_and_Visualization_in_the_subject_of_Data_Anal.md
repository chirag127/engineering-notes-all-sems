### Sharding

- Sharding is a database partitioning technique that splits a large database into smaller, faster, and more manageable parts called shards  .
- Sharding is used by blockchain companies and other applications that need to scale up and process more transactions per second.
- Sharding can improve the performance, availability, and reliability of a database by distributing the data and the workload across multiple nodes.
- Sharding can also reduce the cost of storage and maintenance by using cheaper and less powerful hardware.
- Sharding can be done horizontally or vertically. Horizontal sharding divides the data by rows, while vertical sharding divides the data by columns.
- Sharding can be based on different criteria, such as key, range, hash, or list. Key sharding assigns a shard to each data item based on a unique identifier. Range sharding assigns a shard to each data item based on a predefined range of values. Hash sharding assigns a shard to each data item based on a hash function. List sharding assigns a shard to each data item based on a predefined list of values.
- Sharding has some challenges and limitations, such as data consistency, complexity, and security. Data consistency refers to the difficulty of ensuring that all the shards have the same and updated version of the data. Complexity refers to the increased overhead and difficulty of managing and querying multiple shards. Security refers to the increased risk of data breaches and attacks due to the exposure of more nodes .
