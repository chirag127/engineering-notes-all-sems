## Unit 6 - Frame Works and Visualization

- In this unit, you will learn about the concepts and techniques of data visualization, which is the process of creating graphical representations of data and information.
- You will also learn about some of the popular frameworks and tools for data visualization, such as Matplotlib, Seaborn, Plotly, and Bokeh, which are Python libraries that provide various functionalities and features for creating interactive and static plots.
- The objectives of this unit are:

  - To understand the principles and elements of data visualization, such as data types, variables, aesthetics, scales, and coordinate systems.
  - To explore the different types of plots and charts that can be used to visualize data, such as histograms, bar charts, pie charts, scatter plots, line plots, box plots, and heat maps.
  - To apply the best practices and guidelines for effective data visualization, such as choosing appropriate colors, fonts, labels, legends, titles, and annotations.
  - To compare and contrast the advantages and disadvantages of different frameworks and tools for data visualization, such as Matplotlib, Seaborn, Plotly, and Bokeh.
  - To create and customize various plots and charts using the frameworks and tools for data visualization, such as Matplotlib, Seaborn, Plotly, and Bokeh.
  - To export and share the plots and charts created using the frameworks and tools for data visualization, such as Matplotlib, Seaborn, Plotly, and Bokeh.
