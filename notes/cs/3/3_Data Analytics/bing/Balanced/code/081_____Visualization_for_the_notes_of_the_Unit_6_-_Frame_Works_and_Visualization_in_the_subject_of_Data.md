### Visualization for the notes of the unit 6 - frameworks and visualization in the subject of data analytics

- Data visualization is the process of transforming data into graphical or pictorial representations that can reveal patterns, trends, and insights hidden in the data.
- Data visualization can help users to perform data analysis, communicate findings, and support decision-making in various domains and contexts.
- Data visualization can be classified into different types based on the purpose, data structure, and visual encoding. Some common types are charts, graphs, diagrams, maps, dashboards, and reports.
- Data visualization requires a systematic and iterative process that involves the following steps:
  - Define the problem and the audience: Identify the question or goal that the visualization aims to address, and the target audience that will consume the visualization.
  - Acquire and prepare the data: Collect the relevant data from various sources, and clean, transform, and filter the data to make it suitable for analysis and visualization.
  - Explore and analyze the data: Use descriptive and inferential statistics, as well as exploratory visualization techniques, to understand the characteristics, distribution, and relationships of the data variables.
  - Choose the appropriate visualization technique: Select the most effective and efficient way to represent the data based on the data type, analysis objective, and audience preference.
  - Design and create the visualization: Apply the principles of visual perception, cognition, and aesthetics to encode the data using visual elements such as color, shape, size, position, and texture, and to arrange the elements in a coherent and meaningful layout.
  - Refine and evaluate the visualization: Test and improve the visualization by soliciting feedback from the audience, and by applying best practices and guidelines to enhance the clarity, accuracy, and appeal of the visualization.
  - Present and disseminate the visualization: Communicate the message and the story behind the visualization to the audience, and use appropriate channels and formats to distribute the visualization to the intended users.
- Data visualization can be implemented using various tools and frameworks that offer different features and functionalities. Some of the popular tools and frameworks are :
  - Apache Kafka: A distributed streaming platform that enables high throughput, scalability, reliability, and fault-tolerance for real-time data processing and analysis.
  - Apache Spark: A unified analytics engine for batch, streaming, SQL, machine learning, and graph processing, that can run on various platforms such as Hadoop, Kubernetes, or in the cloud.
  - Apache Flink: A stream processing framework for unbounded and bounded data streams, that supports event-time semantics, stateful computations, and high availability.
  - Tableau: A data visualization tool with drag-and-drop functionality, that allows users to connect to various data sources and create interactive dashboards and reports.
  - Power BI: A business intelligence tool for connecting to data sources and creating interactive reports, that can be embedded in applications or shared online.
