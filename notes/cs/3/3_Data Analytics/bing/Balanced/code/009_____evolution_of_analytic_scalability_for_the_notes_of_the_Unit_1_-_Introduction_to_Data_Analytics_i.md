### Evolution of analytic scalability

- Analytic scalability refers to the ability to handle large and complex data sets for analysis purposes.
- It involves pulling the data together in a separate analytics environment and then performing analysis using various techniques and tools.
- It also involves merging data sets from different sources and formats, which may contain millions or billions of rows.
- The evolution of analytic scalability can be traced from the traditional data warehouse approach to the modern big data paradigm.
- The traditional data warehouse approach involved storing and processing data in a centralized relational database management system (RDBMS) using structured query language (SQL).
- This approach had some limitations, such as high cost, limited scalability, rigid schema, and poor performance for complex analytics.
- The modern big data paradigm involves storing and processing data in a distributed and parallel manner using various technologies, such as massively parallel processing (MPP) architectures, the cloud, grid computing, and MapReduce.
- These technologies enable greater scalability, flexibility, efficiency, and performance for handling large and complex data sets  .
- The evolution of analytic scalability also involves the convergence of the analytic and data environments, which means that the data and the analytics are co-located and co-processed in the same environment .
- This enables faster and more accurate insights, as well as more opportunities for innovation and experimentation.
