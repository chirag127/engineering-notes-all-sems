### NoSQL Databases

- NoSQL databases are databases that store and query data in formats other than relational tables  .
- NoSQL databases are also known as "not only SQL", "non-SQL", or "non-relational" databases .
- NoSQL databases can store data that is structured, semi-structured, or unstructured.
- NoSQL databases can handle large volumes of data and high user loads with high performance and scalability.
- NoSQL databases can be classified into four main types based on their data model:
  - Document databases: store data as documents, which are collections of key-value pairs. Each document can have a different structure and schema. Examples: MongoDB, CouchDB, Firebase.
  - Key-value databases: store data as simple key-value pairs, where the key is a unique identifier and the value can be any type of data. Examples: Redis, Memcached, DynamoDB.
  - Wide-column databases: store data as rows and columns, but unlike relational tables, each row can have a different number and type of columns. Examples: Cassandra, HBase, Bigtable.
  - Graph databases: store data as nodes and edges, where nodes represent entities and edges represent relationships. Examples: Neo4j, OrientDB, Amazon Neptune.
