### Unit 4 - Mining Data Streams: Stream Computing

- Stream computing is a method of pulling in streams of data, processing the data, and streaming it back out as a single flow.
- It uses software algorithms that analyze data in real-time as it streams in to increase speed and accuracy when dealing with data handling and analysis.
- Stream computing enables organizations to process data streams that are always on and never ceasing.
- It helps organizations spot opportunities and risks across all data.
- IBM Stream Computing, for example, continuously analyzes data and connects to all data sources.
- The stream processing computational paradigm consists of assimilating data readings from collections of software or hardware sensors in stream form, analyzing the data, and producing actionable results, possibly in stream format as well.
- In computer science, stream processing is also known as event stream processing, data stream processing, or distributed stream processing.
- It is a programming paradigm that views data streams, or sequences of events in time, as the central input and output objects of computation.
