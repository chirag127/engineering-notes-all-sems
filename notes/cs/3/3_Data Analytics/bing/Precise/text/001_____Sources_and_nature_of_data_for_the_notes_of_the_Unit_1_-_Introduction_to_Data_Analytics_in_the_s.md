### Sources and nature of data for the notes of the Unit 1 - Introduction to Data Analytics in the subject of Data Analytics

1. **Data sources**: Data can be collected from various sources such as surveys, experiments, and observations. It can also be obtained from existing sources such as databases, data warehouses, and the internet.

2. **Nature of data**: Data can be classified into different types based on its nature. Some common types of data include numerical, categorical, and ordinal data.

3. **Numerical data**: Numerical data is data that is represented by numbers. It can be further classified into discrete and continuous data. Discrete data is data that can only take on certain values, while continuous data can take on any value within a certain range.

4. **Categorical data**: Categorical data is data that is represented by categories or labels. It can be further classified into nominal and ordinal data. Nominal data is data that has no inherent order, while ordinal data has an inherent order.

5. **Data quality**: The quality of data is important in data analytics. Data quality can be affected by factors such as accuracy, completeness, consistency, and timeliness.

6. **Data preprocessing**: Data preprocessing is the process of cleaning, transforming, and organizing data to improve its quality and make it suitable for analysis. Common data preprocessing techniques include data cleaning, data transformation, and data reduction.

7. **Data analysis**: Data analysis is the process of examining, modeling, and interpreting data to extract useful information and insights. Common data analysis techniques include descriptive statistics, data visualization, and predictive modeling.

8. **Data visualization**: Data visualization is the process of representing data in a visual format to help communicate information and insights. Common data visualization techniques include charts, graphs, and maps.

9. **Predictive modeling**: Predictive modeling is the process of using data to make predictions about future events or outcomes. Common predictive modeling techniques include regression analysis, decision trees, and neural networks.

10. **Data-driven decision making**: Data-driven decision making is the process of using data to inform and guide decision making. It involves using data analysis and visualization techniques to extract insights and make informed decisions.
