# Unit 5 - Frequent Itemsets and Clustering
## Clustering in Non-Euclidean Space

1. Clustering is the process of grouping similar data points together based on a measure of similarity or distance.
2. In Euclidean space, the distance between two points is calculated using the Euclidean distance formula.
3. However, in non-Euclidean spaces, the concept of distance is not as straightforward and can vary depending on the specific space.
4. Some common non-Euclidean spaces include hyperbolic space, spherical space, and graph space.
5. In these spaces, the distance between two points is not calculated using the Euclidean distance formula, but rather using a different distance metric specific to the space.
6. For example, in hyperbolic space, the distance between two points is calculated using the hyperbolic distance formula, while in spherical space, the distance is calculated using the great-circle distance formula.
7. Clustering algorithms can be adapted to work in non-Euclidean spaces by using the appropriate distance metric for the specific space.
8. Some common clustering algorithms that can be used in non-Euclidean spaces include k-means, hierarchical clustering, and DBSCAN.
9. These algorithms can be used to cluster data in non-Euclidean spaces, allowing for the discovery of patterns and relationships in the data that may not be apparent in Euclidean space.
