### Unit 6 - Frame Works and Visualization in Data Analytics

#### Systems and Applications

1. **Tableau**: A data visualization software that allows users to connect, visualize, and share data in a way that makes it easier to understand and analyze.
2. **QlikView**: A business intelligence platform that provides data visualization and discovery capabilities.
3. **D3.js**: A JavaScript library for producing dynamic, interactive data visualizations in web browsers.
4. **R**: A programming language and software environment for statistical computing and graphics.
5. **Python**: A high-level programming language that is widely used for data analysis and visualization.
6. **Excel**: A spreadsheet program that can be used for data analysis and visualization.
7. **Power BI**: A business analytics service by Microsoft that provides interactive visualizations and business intelligence capabilities.
8. **SAS**: A software suite for advanced analytics, multivariate analyses, business intelligence, data management, and predictive analytics.
9. **SPSS**: A software package used for statistical analysis in social science.
10. **Matplotlib**: A plotting library for the Python programming language and its numerical mathematics extension NumPy.

These are some of the commonly used systems and applications for data visualization and analysis in the field of Data Analytics. Each has its own strengths and capabilities, and the choice of tool depends on the specific needs and requirements of the user.
