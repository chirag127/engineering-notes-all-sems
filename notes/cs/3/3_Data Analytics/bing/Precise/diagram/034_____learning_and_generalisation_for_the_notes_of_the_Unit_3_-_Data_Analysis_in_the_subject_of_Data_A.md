### Learning and Generalisation

Unit 3 - Data Analysis in the subject of Data Analytics

1. **Learning** is the process of acquiring knowledge or skills through experience, study, or instruction.
2. In the context of data analysis, learning refers to the process of using data to train a model to make predictions or decisions.
3. **Generalisation** refers to the ability of a model to perform well on new, unseen data.
4. A model that generalises well is able to accurately make predictions or decisions on new data, even if it was not part of the training data.
5. The goal of data analysis is to create a model that can learn from the data and generalise well to new data.
6. Overfitting occurs when a model is too complex and fits the training data too closely, resulting in poor generalisation to new data.
7. Regularisation techniques can be used to prevent overfitting and improve generalisation.
8. Cross-validation is a technique used to assess the generalisation ability of a model by splitting the data into training and validation sets.
9. The performance of the model on the validation set provides an estimate of its generalisation ability.
