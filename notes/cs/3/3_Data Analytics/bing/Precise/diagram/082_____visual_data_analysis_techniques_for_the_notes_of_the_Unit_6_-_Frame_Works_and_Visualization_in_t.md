# Unit 6 - Frame Works and Visualization in Data Analytics

## Visual Data Analysis Techniques

Visual data analysis techniques are used to explore, analyze, and present data in a visual format. These techniques can help to identify patterns, trends, and relationships in data that may not be immediately apparent through traditional data analysis methods. Some of the most common visual data analysis techniques include:

1. **Charts and Graphs**: Charts and graphs are used to represent data in a visual format. Common types of charts and graphs include bar charts, pie charts, line graphs, and scatter plots.

2. **Heat Maps**: Heat maps use color to represent data values in a two-dimensional matrix. They are often used to show the distribution of data across a geographic region or to represent the correlation between two variables.

3. **Tree Maps**: Tree maps use nested rectangles to represent hierarchical data. The size of each rectangle represents the relative size of the data value, while the color can be used to represent additional information.

4. **Network Diagrams**: Network diagrams are used to represent relationships between data points. They are often used to visualize social networks, organizational structures, or the flow of information.

5. **Geospatial Visualization**: Geospatial visualization techniques are used to represent data on a map. These techniques can be used to show the distribution of data across a geographic region or to represent the movement of data over time.

These are just a few of the many visual data analysis techniques that can be used to explore, analyze, and present data. By using these techniques, data analysts can gain new insights into their data and communicate their findings in a clear and effective manner.
