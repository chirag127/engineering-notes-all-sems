### Unit 1 - Introduction to Data Analytics

#### Semi-Structured Data

- Semi-structured data refers to data that does not conform to a strict data model, but still has some structure.
- This type of data is often stored in formats such as XML or JSON, which allow for the representation of hierarchical relationships between data elements.
- Semi-structured data is often used in situations where the data model is not well-defined or is subject to change.
- This type of data is commonly found in web applications, where the data model may evolve over time as new features are added.
- Semi-structured data can be more flexible than structured data, but it can also be more difficult to work with, as the lack of a strict data model can make it harder to query and analyze.
- Tools such as NoSQL databases and data processing frameworks like Hadoop and Spark are often used to work with semi-structured data.
