# Unit 1 - Introduction to Data Analytics

### Analytic Process and Tools

1. **Data Collection:** The first step in the analytic process is to collect data from various sources such as databases, spreadsheets, and text files.

2. **Data Preprocessing:** Once the data is collected, it needs to be preprocessed to remove any inconsistencies, errors, or missing values. This step also involves transforming the data into a suitable format for analysis.

3. **Data Analysis:** After preprocessing, the data is analyzed using various statistical and machine learning techniques to identify patterns, relationships, and trends.

4. **Data Visualization:** The results of the analysis are then visualized using charts, graphs, and other visual aids to help communicate the findings to stakeholders.

5. **Data Interpretation:** The final step in the analytic process is to interpret the results and draw conclusions based on the analysis.

Some of the popular tools used in the analytic process include:

- **Excel:** A spreadsheet program that can be used for data collection, preprocessing, and analysis.

- **R:** A programming language and software environment for statistical computing and graphics.

- **Python:** A high-level programming language that can be used for data analysis and visualization.

- **Tableau:** A data visualization software that allows users to create interactive dashboards and reports.

- **SAS:** A software suite for advanced analytics, multivariate analysis, business intelligence, data management, and predictive analytics.

- **SPSS:** A software package used for statistical analysis in social science research.
