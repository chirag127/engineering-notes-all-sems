# Limited Pass Algorithm

The limited pass algorithm is a method used in data analytics for finding frequent itemsets and clustering. It is part of the study material for Unit 5 - Frequent Itemsets and Clustering in the subject of Data Analytics.

- The algorithm works by making multiple passes over the data.
- In each pass, the algorithm counts the occurrences of itemsets and determines which itemsets are frequent.
- The algorithm then uses this information to prune the search space and reduce the number of itemsets that need to be considered in the next pass.
- This process is repeated until all frequent itemsets have been found.
- The limited pass algorithm is an efficient method for finding frequent itemsets in large datasets.
