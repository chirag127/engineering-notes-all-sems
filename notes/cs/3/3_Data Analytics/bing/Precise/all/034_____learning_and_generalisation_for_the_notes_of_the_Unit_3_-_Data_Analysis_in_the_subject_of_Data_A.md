### Learning and Generalisation

Unit 3 - Data Analysis in the subject of Data Analytics

- Learning is the process of acquiring new knowledge, skills, or behaviors through experience, study, or instruction.
- Generalisation refers to the ability to apply learned knowledge or skills to new situations or contexts.
- In the context of data analysis, learning involves using data to build models that can make predictions or identify patterns.
- Generalisation is important in data analysis because it allows models to make accurate predictions on new data that was not used in the training process.
- Overfitting is a common problem in data analysis that occurs when a model is too complex and fits the training data too closely, resulting in poor generalisation to new data.
- Techniques such as cross-validation and regularisation can be used to improve the generalisation of models in data analysis.
- In summary, learning and generalisation are important concepts in data analysis that involve using data to build models that can make accurate predictions on new data. Techniques such as cross-validation and regularisation can be used to improve the generalisation of models.
