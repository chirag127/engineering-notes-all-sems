### Learning and Generalisation

Learning and generalisation are two important concepts in the field of data analysis. Here are some key points to remember:

1. **Learning** refers to the process of acquiring knowledge or skills through experience, study, or instruction. In the context of data analysis, learning often involves using data to build models that can make predictions or identify patterns.

2. **Generalisation** refers to the ability of a model to perform well on new, unseen data. A model that generalises well is able to make accurate predictions or identify patterns in data that it has not been trained on.

3. The goal of data analysis is often to build models that can generalise well. This means that the model should be able to make accurate predictions or identify patterns in new data, even if it has not seen that data before.

4. One way to improve the generalisation of a model is to use a large and diverse training dataset. This can help the model learn to identify patterns that are common across different data points, rather than overfitting to the specific characteristics of the training data.

5. Another way to improve generalisation is to use techniques such as cross-validation or regularisation. These techniques can help prevent overfitting and ensure that the model is able to generalise well to new data.

6. It is important to evaluate the generalisation of a model using a separate test dataset. This can help ensure that the model is able to perform well on new data, and not just on the data it was trained on.
