## Unit 6 - Frameworks and Visualization

1. Frameworks are software libraries that provide a structure for building applications.
2. They can help developers save time and effort by providing pre-built components and functionality.
3. Some popular frameworks include React, Angular, and Vue for front-end development, and Django, Ruby on Rails, and Express for back-end development.
4. Visualization refers to the graphical representation of data and information.
5. It can help users understand complex data by presenting it in a visual and interactive format.
6. Some popular visualization tools include Tableau, D3.js, and Power BI.
7. Frameworks and visualization tools can be used together to create powerful and user-friendly applications.
