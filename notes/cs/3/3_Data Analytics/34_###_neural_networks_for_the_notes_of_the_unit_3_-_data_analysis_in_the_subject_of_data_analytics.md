### neural networks for the notes of the Unit 3 - Data Analysis in the subject of Data Analytics

Neural Networks:
- A type of machine learning model inspired by the structure and function of the human brain
- Consist of interconnected nodes (neurons) that process and transmit information
- Used for various tasks such as image recognition, language translation, and prediction 
- Work by adjusting weights on connections between neurons based on input data and desired output 
- Can handle complex non-linear relationships between inputs and outputs 
- Popular types: feedforward, recurrent, and convolutional neural networks.
