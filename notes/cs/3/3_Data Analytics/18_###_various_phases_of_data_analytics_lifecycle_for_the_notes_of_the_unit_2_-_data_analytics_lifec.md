### various phases of data analytics lifecycle for the notes of the Unit 2 - Data Analytics Lifecycle in the subject of Data Analytics

1. Data Discovery: Identifying relevant data sources, exploring and understanding the data.
2. Data Preparation: Cleaning, transforming, and organizing data for analysis.
3. Data Analysis: Using statistical and machine learning techniques to uncover insights and relationships in the data.
4. Data Visualization: Presenting the results of the analysis in graphical and interactive forms.
5. Data Deployment: Deploying the results of the analysis into production systems and making them available to end-users.
6. Data Monitoring: Continuously monitoring the deployed results to ensure they remain accurate and relevant.
