

### Learning and Generalisation for the Notes of Unit 3 - Data Analysis in the Subject of Data Analytics

1. Learning is the process of acquiring knowledge and skills through experience, practice, and instruction.

2. Generalisation is the process of taking what has been learned in one situation and applying it to other situations.

3. Data analysis is the process of collecting, organizing, and interpreting data to identify patterns and trends.

4. Data analytics is the process of using data to gain insights and make decisions.

5. Machine learning is a branch of artificial intelligence that uses algorithms to analyze data and make predictions.

6. Supervised learning is a type of machine learning that uses labeled data to train a model.

7. Unsupervised learning is a type of machine learning that uses unlabeled data to identify patterns and structure in data.

8. Reinforcement learning is a type of machine learning that uses rewards and punishments to teach a model how to act in certain situations.
