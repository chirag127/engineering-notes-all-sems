
### Data Import and Export for the Notes of the Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

1. Data import is the process of bringing data into a program or application from an external source in order to be used, manipulated, or analyzed. 
2. Data export is the process of transferring data from a program or application to an external destination.
3. Common data import formats include CSV, XML, and JSON.
4. Common data export formats include HTML, PDF, and XLSX.
5. Data visualization frameworks are used to create interactive visualizations from data sets.
6. Common data visualization frameworks include D3.js, Chart.js, and Plotly.
7. Visualization techniques include scatter plots, bar charts, histograms, and pie charts.
8. Data analytics is the process of analyzing data in order to draw insights and make decisions.
9. Common data analytics techniques include descriptive, predictive, and prescriptive analytics.
10. Data analytics can be used to gain insights into customer behavior, market trends, and operational efficiency.
