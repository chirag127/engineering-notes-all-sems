
### Sharding for the Notes of the Unit 6 - Frameworks and Visualization in the Subject of Data Analytics
1. Sharding is a method of distributing data across multiple servers, or “shards”, to improve the performance of a database.
2. By using sharding, data can be stored on multiple servers which can be located in different physical locations. This allows for faster access to data, as well as improved scalability and redundancy.
3. Frameworks are a set of tools and libraries that provide a structure for developing software applications. Frameworks can provide a variety of features such as data access, security, logging, and configuration management.
4. Visualization is the process of creating and displaying data in a graphical form. Visualization can help to better understand data, and can be used to present data in a more engaging way.
5. Data analytics is the process of examining data to gain insights and generate actionable results. Data analytics can be used to identify trends, uncover patterns, and make predictions.
