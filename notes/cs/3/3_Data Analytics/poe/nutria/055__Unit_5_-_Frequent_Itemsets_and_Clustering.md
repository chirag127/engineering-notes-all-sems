
## Unit 5 - Frequent Itemsets and Clustering

* Frequent itemsets are sets of items that appear frequently together in a given dataset. 
* Clustering is the task of grouping a set of objects in such a way that objects in the same group (called a cluster) are more similar to each other than to those in other groups.
* Frequent itemsets can be used to find clusters in a dataset, as the items that appear together frequently are likely to be related.
* Apriori algorithm is a popular algorithm for finding frequent itemsets. It works by finding all subsets of items that appear frequently together in the dataset.
* K-means clustering is a popular algorithm for clustering data. It works by assigning each data point to the cluster whose mean is closest to the data point.
* Hierarchical clustering is another popular algorithm for clustering data. It works by creating a hierarchical tree of clusters, where each node in the tree is a cluster.
