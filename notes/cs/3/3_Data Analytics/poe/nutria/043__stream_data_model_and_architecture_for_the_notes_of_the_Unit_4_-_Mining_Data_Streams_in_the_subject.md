
### Stream Data Model and Architecture for the Notes of the Unit 4 - Mining Data Streams in the Subject of Data Analytics

1. Stream data models are used to represent and store data that is collected in real-time. This data can come from a variety of sources, including sensors, systems, and applications.
2. Stream data architecture is a set of components and techniques used to process and store data in real-time. These components include a data source, a stream processing engine, a stream storage engine, and a stream analytics engine.
3. Stream processing engines are used to process data in real-time. These engines can perform basic operations such as filtering, aggregation, and transformation.
4. Stream storage engines are used to store data in real-time. These engines can be used to store data in a variety of formats, including relational databases, NoSQL databases, and object stores.
5. Stream analytics engines are used to analyze data in real-time. These engines can perform complex operations such as machine learning, pattern recognition, and anomaly detection.
6. Stream data architectures can be used to build real-time applications that can process and analyze data in real-time. These applications can be used for a variety of tasks, including fraud detection, customer segmentation, and predictive maintenance.
