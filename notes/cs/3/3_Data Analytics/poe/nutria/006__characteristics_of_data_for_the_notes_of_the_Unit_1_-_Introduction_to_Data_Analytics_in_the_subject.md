

### Characteristics of Data for Unit 1 - Introduction to Data Analytics

1. Data can be qualitative or quantitative. Qualitative data is descriptive and non-numerical, while quantitative data is numerical and can be used to measure and compare. 
2. Data can be structured or unstructured. Structured data is organized in a specific format (e.g. database tables), while unstructured data is more free-form and can include text, images, and audio/video. 
3. Data can be static or dynamic. Static data is unchanging and does not change over time, while dynamic data is constantly changing and updating. 
4. Data can be discrete or continuous. Discrete data is distinct and separate, while continuous data is continuous and can take on any value within a range. 
5. Data can be homogeneous or heterogeneous. Homogeneous data is the same type of data, while heterogeneous data is composed of different types of data. 
6. Data can be temporal or spatial. Temporal data is related to time, while spatial data is related to location. 
7. Data can be primary or secondary. Primary data is collected directly from the source, while secondary data is collected from existing sources.
