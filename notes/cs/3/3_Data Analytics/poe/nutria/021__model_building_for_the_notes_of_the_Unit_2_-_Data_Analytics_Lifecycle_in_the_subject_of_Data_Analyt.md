
### Model Building for Unit 2 - Data Analytics Lifecycle

1. Model building is an important part of the data analytics lifecycle. It involves constructing a mathematical model to analyze data and uncover patterns and insights that can be used to make decisions.

2. The process of model building typically involves gathering data, exploring and analyzing the data, selecting the appropriate type of model, and then building and validating the model.

3. Different types of models can be used for different purposes. For example, linear regression models are used to predict the relationship between two or more variables, while decision trees are used to make decisions based on multiple criteria.

4. Model building also involves tuning the parameters of the model to ensure that it is as accurate as possible. This process involves testing different parameters and evaluating the results to determine which parameters are most effective.

5. Once the model has been built and tuned, it can be used to make predictions or provide insights into the data. This can be used to make decisions or to generate new ideas and hypotheses.
