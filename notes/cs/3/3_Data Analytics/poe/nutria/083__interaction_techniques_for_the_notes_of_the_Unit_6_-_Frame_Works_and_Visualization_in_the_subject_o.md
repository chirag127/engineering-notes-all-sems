
### Interaction Techniques for the Notes of the Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

1. **Data Visualization:** Data visualization is a process of presenting data in a graphical format. It allows us to quickly identify patterns, trends, and relationships in data.

2. **Data Exploration:** Data exploration is the process of analyzing data sets to uncover patterns, trends, and relationships hidden within the data.

3. **Data Mining:** Data mining is the process of discovering meaningful patterns from large datasets. It involves the use of algorithms and statistical techniques to extract useful information from data.

4. **Data Manipulation:** Data manipulation is the process of transforming data from one format to another. It involves the use of scripting languages, such as Python and R, to manipulate data.

5. **Data Analysis:** Data analysis is the process of analyzing data sets to uncover patterns, trends, and relationships hidden within the data. It involves the use of mathematical and statistical methods, such as linear regression and clustering, to analyze data.

6. **Data Visualization Tools:** Data visualization tools are software applications used to create graphical representations of data. Popular data visualization tools include Tableau, Power BI, and Qlikview.
