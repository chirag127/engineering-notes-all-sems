
### Hadoop Distributed File Systems

Hadoop Distributed File Systems (HDFS) is a distributed, scalable, and fault-tolerant file system designed to run on commodity hardware. It is the primary storage system used by Hadoop applications. HDFS provides high throughput access to application data and is suitable for applications that have large data sets.

HDFS provides the following features:

- **Fault tolerant**: HDFS is designed to be fault tolerant and highly available. It can detect and handle failures at the application layer.

- **High throughput**: HDFS provides high throughput access to application data, making it suitable for applications that have large data sets.

- **Scalability**: HDFS is designed to scale to large clusters of nodes and large data sets.

- **Data locality**: HDFS provides data locality by placing replicas of data blocks near the compute nodes that need to access them. This helps reduce network traffic and improve performance.

- **Data integrity**: HDFS provides data integrity by ensuring that data is not corrupted or lost due to hardware or software failures.

- **Data security**: HDFS provides data security by encrypting data at rest and in transit.
