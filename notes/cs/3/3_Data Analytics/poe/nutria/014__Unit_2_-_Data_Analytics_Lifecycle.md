
## Unit 2 - Data Analytics Lifecycle

1. The data analytics lifecycle is an iterative process used to analyze data and generate insights from it. It involves a series of steps, including data collection, data preparation, data exploration, data modeling, and data visualization.

2. Data Collection is the first step in the data analytics lifecycle. It involves gathering data from various sources, such as databases, files, and web services. The data should be collected in a format that is suitable for further analysis.

3. Data Preparation is the second step in the data analytics lifecycle. It involves cleaning and transforming the data to make it suitable for further analysis. This includes removing outliers, normalizing data, and transforming data into a format that is suitable for further analysis.

4. Data Exploration is the third step in the data analytics lifecycle. It involves analyzing the data to identify patterns and correlations. This includes using statistical methods and machine learning algorithms to identify patterns and trends in the data.

5. Data Modeling is the fourth step in the data analytics lifecycle. It involves creating a model that can be used to generate insights from the data. This includes using machine learning algorithms to create predictive models and using statistical methods to create descriptive models.

6. Data Visualization is the fifth step in the data analytics lifecycle. It involves creating visualizations of the data to make it easier to understand and interpret. This includes creating graphs, charts, and other visual representations of the data.
