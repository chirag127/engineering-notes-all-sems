
### Analytic Process and Tools for the Notes of the Unit 1 - Introduction to Data Analytics in the Subject of Data Analytics

1. Data Analytics is a field that involves the use of tools and techniques to analyze large datasets. It is used to gain insights, uncover patterns, and make predictions.

2. The analytic process typically involves the following steps:
    * Collecting and organizing data
    * Exploring and understanding the data
    * Building models and making predictions
    * Evaluating the results

3. Common tools used in data analytics include:
    * Spreadsheets
    * Statistical software
    * Data visualization tools
    * Machine learning algorithms
    * Natural language processing algorithms

4. Understanding the analytic process and the tools available can help data analysts make more informed decisions and create better models.
