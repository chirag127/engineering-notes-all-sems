

### Attribute and Data Types for the Notes of Unit 6 - Frameworks and Visualization in Data Analytics

1. Attributes are properties of a dataset that can be used to describe its contents. Attributes can be of various data types, such as numerical, categorical, and textual.
2. Numerical data types include integers, floats, and dates. These data types can be used to represent quantitative information such as age, height, weight, and other measurements.
3. Categorical data types are used to represent qualitative information such as gender, ethnicity, and other categorical variables.
4. Textual data types include strings, text documents, and other textual data. These data types can be used to represent textual information such as descriptions, comments, and other textual data.
5. Frameworks are collections of tools, libraries, and other resources that can be used to create applications and other software. Common frameworks used in data analytics include Apache Spark, Hadoop, and TensorFlow.
6. Visualization is the process of transforming data into graphical representations, such as charts, graphs, and maps. Visualization tools can be used to explore and analyze data, and to communicate insights to others. Common visualization tools used in data analytics include Tableau, Power BI, and Matplotlib.
