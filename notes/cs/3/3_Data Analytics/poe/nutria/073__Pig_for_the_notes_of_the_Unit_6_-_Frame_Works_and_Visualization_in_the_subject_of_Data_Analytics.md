
### Pig for the Notes of the Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

1. Apache Pig is a high-level platform for creating programs that run on Apache Hadoop. It is designed to handle large-scale data analysis.
2. Pig Latin is the language used to write Pig programs. It is a data flow language that allows users to write complex data transformations in a simple and concise manner.
3. Pig programs are composed of a series of operations, or transformations, that are applied to the input data to produce the desired output.
4. Pig provides a set of operators for common data transformations, such as filtering, sorting, joining, and aggregation.
5. Pig also provides a set of built-in functions for manipulating data, such as string manipulation, mathematical functions, and date/time functions.
6. Pig can be used to create data pipelines for ETL (Extract, Transform, Load) operations, such as loading data from a source system into a data warehouse.
7. Pig can also be used for data analysis, such as creating reports and performing ad-hoc queries.
8. Pig provides a set of visualization tools for exploring and understanding data. These tools can be used to quickly identify patterns and outliers in the data.
9. Pig programs can be executed in a local or distributed mode. In a distributed mode, the Pig program is executed on a cluster of machines, allowing it to process large amounts of data in parallel.
