
### Sampling Data in a Stream

* Sampling is a process of selecting a subset of data from a larger dataset. This is done to reduce the amount of data to be processed. 
* In data streams, sampling is used to make decisions about the data in real-time.
* Sampling can be done in a variety of ways, including random sampling, systematic sampling, and stratified sampling.
* Random sampling is the simplest form of sampling and involves randomly selecting a subset of the data.
* Systematic sampling involves selecting a subset of the data based on a predetermined pattern.
* Stratified sampling is a sampling technique where the data is divided into different strata and a sample is taken from each stratum.
* Sampling can also be used to identify outliers in a data stream.
* Sampling can be used to reduce the data rate in a stream, allowing for more efficient processing.
