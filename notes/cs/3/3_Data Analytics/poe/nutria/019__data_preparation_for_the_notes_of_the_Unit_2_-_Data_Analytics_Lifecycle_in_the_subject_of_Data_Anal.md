
### Data Preparation for the Notes of the Unit 2 - Data Analytics Lifecycle in the Subject of Data Analytics

1. Data preparation is the process of gathering and organizing data in a way that makes it ready for analysis. 
2. It involves cleaning and transforming raw data into a format that can be used for further analysis.
3. Data preparation can include activities such as data cleaning, data wrangling, data integration, data manipulation, data formatting, and data augmentation.
4. Data cleaning involves identifying and removing errors, inconsistencies, and missing values in the data.
5. Data wrangling is the process of combining, reshaping, and restructuring data to make it easier to analyze.
6. Data integration involves combining data from multiple sources into a single dataset.
7. Data manipulation involves changing the data to make it easier to interpret and analyze.
8. Data formatting involves changing the structure of the data to make it easier to interpret and analyze.
9. Data augmentation involves adding additional information to the data to make it more useful for analysis.
