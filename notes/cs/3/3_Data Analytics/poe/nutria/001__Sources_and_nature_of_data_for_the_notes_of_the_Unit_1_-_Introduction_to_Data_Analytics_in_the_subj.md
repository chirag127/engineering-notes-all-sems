
### Sources and Nature of Data

1. Data can be collected from a variety of sources, including:
    * Primary sources: data that is collected directly from the source, such as surveys, interviews, and observations.
    * Secondary sources: data that has been collected and compiled by an organization or individual, such as census data, published reports, and public records.
    * Tertiary sources: data that has been aggregated from multiple sources, such as data warehouses and data lakes.
2. Data can come in a variety of formats, including:
    * Structured data: data that is organized into a fixed set of fields or columns, such as a spreadsheet or database.
    * Unstructured data: data that is not organized into a fixed set of fields, such as text, images, and audio.
3. Data can be qualitative or quantitative:
    * Qualitative data: data that is descriptive in nature, such as opinions, beliefs, and attitudes.
    * Quantitative data: data that is numerical in nature, such as counts and measurements.
4. Data can be static or dynamic:
    * Static data: data that does not change over time, such as census data.
    * Dynamic data: data that changes over time, such as stock prices.
