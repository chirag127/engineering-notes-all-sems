### Attribute and Data Types

- An attribute refers to a property or characteristic of a data entity. For example, attributes of a student can be name, age, grade, etc.
- Data types refer to the type of data an attribute can hold such as numeric, character, date, boolean, etc. For example, age can be an integer, name can be a string, enrollment date can be a date, etc.
- Choosing the appropriate data type for an attribute is important to ensure efficient storage and processing of data. For example, storing a boolean value in a numeric data type would be inefficient.
- Some common data types are:
    - Numeric - int, float, double
    - Character - char, varchar
    - Date - date, datetime
    - Boolean - true/false
- Data type conversion may be required in certain cases. For example, converting a numeric value to a character data type to display it. This is known as type casting.
- Inappropriate data type conversion can lead to loss of data precision or errors. Hence, data type conversion should be done carefully.
