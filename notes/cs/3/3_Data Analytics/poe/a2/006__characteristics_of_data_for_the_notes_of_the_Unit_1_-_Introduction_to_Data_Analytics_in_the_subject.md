### Characteristics of Data for the notes of the Unit 1 - Introduction to Data Analytics

1. Volume: The amount of data available for analysis is massive and keeps increasing rapidly. Data volume refers to the size of the data which can range from a few megabytes to petabytes and zettabytes.
2. Velocity: The speed at which data is generated and processed has increased exponentially. Data velocity refers to the rate at which data is generated and processed. Real-time data needs to be processed at a high velocity.
3. Variety: Data today comes in all forms like numbers, text, audio, video, etc. The types and formats of data are wide-ranging. Data variety refers to the different types and formats of data which can be structured, semi-structured or unstructured.
4. Veracity: The quality and accuracy of data need to be reliable for analysis. Data veracity refers to the accuracy, reliability and trustworthiness of the data. Data may contain errors, noise or biases which need to be identified and handled.
5. Value: The ultimate purpose of data analysis is to extract useful information and gain insights to drive decisions and actions. Data value refers to the potential of the data to generate opportunities, decisions, and insights. The value of data increases when it can be linked, analyzed and interpreted.
