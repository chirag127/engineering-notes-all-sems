### Data Import and Export

1. Import - Bringing data into Python from an external source for use in Python.
2. Export - Taking data from Python and saving/outputting it to an external source.

**Import**
- CSV - Comma Separated Values, a simple file format where data is separated by commas. Can be imported using the `pandas` library.
- JSON - Javascript Object Notation, a format that stores data in a hierarchy of objects, arrays, and values. Can be imported using the `json` library.
- Excel - Data can be imported from .xlsx or .xls files using the `pandas` library.
- Databases - Data can be imported from databases such as SQL, MongoDB, etc. using database connector libraries.

**Export**
- CSV - Data can be exported from Python to CSV files for use in other applications using `pandas`.
- JSON - Data can be exported to JSON format using the `json` library.
- Excel - Data can be exported to .xlsx or .xls Excel files using `pandas`.
- Databases - Data can be exported to databases for persistent storage using database connector libraries.
