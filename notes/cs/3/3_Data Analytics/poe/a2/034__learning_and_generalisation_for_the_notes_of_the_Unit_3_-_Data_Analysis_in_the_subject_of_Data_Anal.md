### Learning and Generalisation for Unit 3 - Data Analysis Notes

1. Data Analysis is the process of inspecting, cleaning, transforming and modeling data with the goal of discovering useful information, informing conclusions and supporting decision making.
2. The main steps in data analysis are:
- Understanding the problem and determining the goals: This step involves understanding the problem statement clearly, identifying the key metrics that need to be analyzed and determining the goals and objectives of the analysis.
- Collecting and organizing the data: This step includes collecting the relevant data, cleaning and organizing the data so that it is suitable for analysis.
- Exploring and visualizing the data: This step includes exploring the data to identify patterns and trends, detect anomalies and outliers and visualize the data to gain insights and understand the data better.
- Modeling and evaluating: This step includes applying appropriate statistical/machine learning models to the data and evaluating the performance of the models to identify the best model for the problem.
- Interpreting and communicating results: This step includes interpreting the results, drawing insights and conclusions and communicating the results and insights to stakeholders.
3. Some important techniques used in data analysis are data visualizations, statistics, data mining, machine learning, etc.
4. Some important skills required for data analysis are knowledge of statistics and data visualization tools, problem-solving skills, critical thinking skills, and communication skills.
5. Generalization refers to identifying patterns in the data and deducing general statements/rules that extend beyond the sample data. This helps in making inferences about the entire population from a sample. Generalization requires caution to avoid overfitting or unrealistic conclusions. Cross-validation and testing the model on new data are techniques used to evaluate the reliability of generalizations.
