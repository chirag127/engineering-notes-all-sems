## Unit 4 - Mining Data Streams

1. Introduction to Data Streams
- Data streams are sequences of tuples arriving continuously at high speed with no specific end.
- Traditional data mining algorithms assume that the data fits in the memory and can be scanned multiple times, which is not feasible for data streams.
- New algorithms are required that can react to concept drift and change their model on the fly.

2. Challenges in Mining Data Streams
- Huge volume: Too much data to store or scan multiple times.
- High velocity: Data comes at a high rate and algorithms have to be efficient and incremental.
- Concept drift: The underlying distribution can change over time and the model has to adapt to reflect these changes.

3. Types of Algorithms for Data Streams
- Single-pass algorithms: Go through the data only once to find patterns.
- Sliding-window algorithms: Use a window of recent data and discard old data.
- Drift-detection algorithms: Detect changes in incoming data and adapt the model.
