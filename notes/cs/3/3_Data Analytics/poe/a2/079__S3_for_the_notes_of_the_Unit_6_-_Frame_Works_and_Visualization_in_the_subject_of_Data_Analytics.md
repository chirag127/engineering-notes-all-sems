### S3 for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics

1. S3 stands for Simple Storage Service. It is a storage service provided by Amazon Web Services (AWS).
2. It is a highly scalable object storage service that is fast, inexpensive, and fully managed.
3. Data in S3 is stored in "buckets" which are similar to folders. Buckets are used to organize data.
4. Objects are the fundamental entities stored in S3. Objects contain data (e.g. files) along with metadata that describes them.
5. S3 provides security and access control mechanisms to keep data secure. It supports encryption of data at rest and encryption of data in transit.
6. S3 pricing is based on storage used, number of requests, additional features, and data transfer. The first 50TB / month of storage and 2 million requests are free.
7. Some use cases of S3 are:
- Website hosting
- Database backups
- Storage for big data analytics
- Mobile and web application data storage
- Media sharing and content distribution
- Software delivery
