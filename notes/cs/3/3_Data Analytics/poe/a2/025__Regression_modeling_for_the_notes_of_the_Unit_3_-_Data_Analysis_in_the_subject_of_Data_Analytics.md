### Regression modeling for the notes of the Unit 3 - Data Analysis in the subject of Data Analytics.

1. Regression is a statistical technique to analyze the relationship between a dependent variable and one or more independent variables. It helps in modeling the relationship between variables and forecasting the value of a dependent variable based on the value of an independent variable.

2. The basic steps involved in regression are:

- Identifying the dependent and independent variables. The variable whose variation is to be studied is the dependent variable and the variable that is used to study the variation is the independent variable.
- Collecting the data and plotting the variables to check linearity. The data should have a linear relationship to apply regression.
- Computing the regression line/curve and regression coefficients. The regression line is the line that best fits the data points and regression coefficients help quantify the relationship.
- Evaluating the regression model. This is done by calculating the R2 value and p-value to check the goodness of fit and significance of the model.

3. The types of regression are:

- Simple Linear Regression: Used for studying the relationship between a dependent and a single independent variable.
- Multiple Linear Regression: Used for studying the relationship between a dependent and two or more independent variables.
- Non-Linear Regression: Used for modeling non-linear relationships between the variables. Examples are exponential, logarithmic, etc.

4. Regression is useful in data analysis for understanding data patterns, forecasting future values, and gaining useful insights from the data. It has applications in fields like finance, marketing, and economics.
