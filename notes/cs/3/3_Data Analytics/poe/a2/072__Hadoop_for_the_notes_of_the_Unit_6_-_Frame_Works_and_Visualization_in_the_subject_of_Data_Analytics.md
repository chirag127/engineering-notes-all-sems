### Hadoop for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics

1. Hadoop is an open-source software framework for distributed storage and processing of big data sets using the MapReduce programming model.
2. The Hadoop framework allows for the distributed processing of large data sets across clusters of computers using simple programming models.
3. The Hadoop framework consists of the following modules:
- Hadoop Common: The common utilities that support other Hadoop modules.
- Hadoop Distributed File System (HDFS): A distributed file system that provides high-throughput access to application data.
- Hadoop YARN: A framework for job scheduling and cluster resource management.
- Hadoop MapReduce: A software framework for distributed processing of large data sets.
4. The key benefits of Hadoop are:
- Scalability: Hadoop can scale up from single servers to thousands of machines, with a capacity of petabytes of data.
- Fault tolerance: Hadoop is fault tolerant and can handle machine failures without affecting the jobs done. Data is replicated across the cluster.
- Low cost: Hadoop uses commodity hardware and an open source framework thus reducing costs.
- Flexibility: Hadoop is highly flexible to store and process unstructured, semi-structured and structured data.
