### Multivariate Analysis for Unit 3 - Data Analysis

1. Multivariate Analysis - Analysis of data that involves multiple variables. It is used to analyze the relationship between two or more variables simultaneously. Some of the techniques used are:

- Multiple Regression - Used to understand the relationship between a dependent variable and two or more independent variables. It helps in finding the best fitting line/plane to the data.
- Factor Analysis - Used to identify hidden patterns in the data and group variables into factors. It helps in dimensionality reduction and finding correlating variables.
- Cluster Analysis - Used to group similar data points into clusters. It is a unsupervised learning technique used to find hidden patterns in the data.
- Discriminant Analysis - Used to classify data points into predetermined categories. It computes a discriminant function to classify data points.
- Principal Component Analysis - Used to extract important variables (principal components) from a large set of variables. It helps in dimensionality reduction and finding patterns in the data.

2. Assumptions - The multivariate techniques come with certain assumptions that must be satisfied for the analysis to be accurate:

- Linear relationship between the variables
- Multivariate normality - Data follows a multivariate normal distribution
- Independence of observations
- Multicollinearity - Low correlations between the independent variables
- Outliers - No extreme outliers in the data

3. Use Cases - Multivariate analysis is used in various fields:

- Market Research - Understanding customer segments and product correlations.
- Medical Diagnosis - Classifying diseases and predicting outcomes.
- Social Science - Analyzing trends and relationships between indicators.
- Pattern Recognition - Identifying patterns and clusters in data.
