### HBase for the notes of the Unit 6 - Frame Works and Visualization in the subject of Data Analytics

1. HBase is a column-oriented database management system that runs on top of Hadoop Distributed File System (HDFS).
2. It is a scalable, distributed, versioned, non-relational database.
3. HBase provides real-time read/write access to Big Data.
4. HBase uses Hadoop's distributed HDFS for its underlying storage.
5. Data in HBase is stored in tables that contain rows and columns.
6. Each table contains billions of rows and millions of columns.
7. HBase is suitable for sparse data sets, i.e. if most of the table cells are empty.
8. HBase does not require a fixed schema and is a schemaless database. Columns can be added on the fly.
9. HBase provides high throughput access to data using push-down predicate, server-side filters and bloom filters.
10. HBase runs on top of HDFS and can leverage Hadoop's automatic failover and high availability.
