### Stream Computing

1. Stream computing refers to processing data in real-time as it is being generated, rather than storing it and processing it later. This is important for time-sensitive applications.
2. Some characteristics of data streams are:
- Arrive continuously at high velocity.
- Limited size, so can't store and process later.
- May be unbounded.
- Often unpredictable.
3. Challenges with stream computing:
- Limited time to process each data item.
- Limited resources (memory, CPU).
- Must process data quickly and return results, can't re-visit data.
4. Types of stream processing:
- Tuple-based: Data represented as tuples, processed one at a time. Good for simple logic and filtering.
- Window-based: Use sliding windows to group related data and detect patterns. Windows can be based on time, tuples, or other metrics.
- Complex event processing: Detect complex patterns in event streams and infer higher-level events. Uses techniques like sequencing, causality, timing, and resource contention.
