### Modern Data Analytic Tools

- R Programming: R is a programming language and software environment for statistical computing and graphics. It is widely used among statisticians and data miners for developing statistical software and data analysis.
- Python: Python is a popular programming language used for both scripting and application development. It has multiple libraries for data science and machine learning like NumPy, SciPy, Pandas, Matplotlib, etc.
- SQL: SQL is a domain-specific language used in programming and designed for managing data held in a relational database management system. It is used to query, manipulate and transform data from a relational database.
- SAS: SAS is a software suite developed by SAS Institute for advanced analytics, multivariate analyses, business intelligence, data management, and predictive analytics.
- Tableau: Tableau is a data visualization tool used to visualize and analyze data with an easy to use interface. It allows anyone to easily connect to data, drag and drop to create interactive dashboards and visually explore data.
- Power BI: Power BI is a business analytics service by Microsoft for analyzing data and sharing insights. It provides interactive visualizations, business intelligence capabilities and an easy to use drag and drop interface.

The above points cover some of the popular modern data analytic tools used by data analysts and data scientists to query, manipulate, visualize and analyze data. These tools help in efficiently performing various data analytics tasks and gaining insights from the data.
