### Decaying Window

- In data streams, the data can be infinite and it is not possible to store all the data and process it.
- Hence, we use sliding window techniques where we consider only the recent data for processing and ignore the old data.
- A decaying window is a type of sliding window where the weightage given to the data points decrease exponentially as they get older.
- The recent data points have higher weightage while the older data points have lesser weightage. This gives more importance to latest trends in the data.
- The decay factor determines how fast the weightage decreases. A higher decay factor leads to faster decrease in weightage of older data points.
- Decaying windows are useful in scenarios like detecting recent trends and patterns in data streams where old data is not relevant.
- They provide a feasible way to handle infinite data streams by focusing on latest data.
