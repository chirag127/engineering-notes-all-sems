### Data Preparation for Unit 2 - Data Analytics Lifecycle

1. Gathering Data
- Identify data sources that are relevant to the problem. This could be internal data (such as sales data) or external data (such as industry reports or economic indicators).
- Obtain permissions to access the data if necessary. Data privacy regulations may apply, especially for customer or employee data.
- Download or access the data in a format that can be used for analysis. Often data will need to be extracted from databases or APIs.

2. Assessing Data
- Check for data quality issues like inaccurate, missing, or duplicate data. Low quality data will produce misleading analysis results.
- Determine if the data is sufficient and appropriate for the problem. Additional data may be needed.
- Document the data including structure, attributes, sources, collection methods, limitations, etc.
- Preprocess the data by handling missing values, variable types, scaling, etc. to get it into a suitable format for the analysis tools.

3. Exploring and Visualizing Data
- Explore the data through summaries, distributions, correlations, etc. to find patterns and insights.
- Create visualizations to make trends and patterns more detectable. Different types of visualizations are suited for different types of data and analysis goals.
- Iteratively explore and visualize the data to gain an understanding and check for anomalies before proceeding to the modeling stage.
