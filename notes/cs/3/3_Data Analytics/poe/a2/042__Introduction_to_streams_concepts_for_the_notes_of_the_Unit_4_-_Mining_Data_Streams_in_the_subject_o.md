### Introduction to streams concepts for the notes of the Unit 4 - Mining Data Streams in the subject of Data Analytics

1. Data streams - Data streams refer to ordered sequences of data records continuously generated at rapid rates. These data streams need to be processed in real-time as opposed to stored data which can be processed in batches.
2. Characteristics of data streams -
a) Huge volume - Data streams can consist of huge volumes of data generated continuously at a rapid pace.
b) Arrival rate - The data records arrive at a very high rate in data streams. The arrival rate can be fluctuating and unpredictable.
c) Limited storage - It is not feasible to store all the data in data streams due to the high arrival rate and huge volume. The data needs to be processed on-the-go using limited storage and computing resources.
d) Optional relevance - The data records in streams may or may not be relevant for the task at hand. The relevant records need to be identified and processed with limited resources.
3. Types of data streams - The data streams can be of different types like financial data streams, sensor data streams, network traffic data streams, etc. The techniques to process these different types of data streams may differ based on the characteristics and use cases.
4. Stream processing - Stream processing refers to techniques to process the data records in streams at the rapid rate they are generated using limited resources. This involves tasks like filtering, aggregation, pattern detection, etc. to extract insights and patterns from data streams. Various models and algorithms have been developed for stream processing to deal with the characteristics of data streams.
