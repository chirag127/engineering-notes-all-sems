### Support Vector and Kernel Methods

1. Support Vector Machines (SVMs): SVMs are a type of supervised learning classification algorithm. They can be used for both linear and non-linear classification.
- In linear SVMs, the data is separated into classes by a hyperplane that maximizes the margin between the classes. The points that are closest to the hyperplane are called support vectors.
- In non-linear SVMs, the data is mapped into a higher dimensional space using a kernel trick and then a hyperplane is constructed to separate the classes. Some common kernels used are linear, polynomial, radial basis function (RBF), etc.

2. Kernel Trick: The kernel trick is a technique used to map the data into a higher dimensional space without having to compute the coordinates of the data in that space. It makes the computation more efficient. A kernel function is used to calculate the dot product in the higher dimensional space directly from the input data. This trick is used in non-linear SVMs, kernel ridge regression, etc.

3. Model Selection: There are various parameters to tune in SVMs like the C parameter, kernel type and kernel parameters. This can be done using methods like cross-validation, grid search, etc. to select the model with the best performance. SVMs also have the advantage of effective scaling to large datasets using kernels.

4. Applications: SVMs have applications in both classification and regression problems. Some applications include:
- Image classification
- Text classification
- Handwritten digit recognition
- Bioinformatics
- Regression for forecasting, etc.
