### Stream Data Model and Architecture

1. Stream: A continuous flow of data records. Data streams are potentially unbounded and fast-moving.
2. Stream processing: Analyzing and processing data records in a streaming fashion. The key challenge is to process data fast enough before it expires.
3. Types of Stream Processing:
 - Record-at-a-time: Process one record at a time.
 - Micro-batch: Process small batches of records at a time.
 - Complex event processing: Process event patterns and complex events.
4. Stream processing architecture:
 - Ingestion: Receiving raw input data streams.
 - Storage: Temporarily storing data streams.
 - Processing: Performing computations and analysis on data streams.
 - Output: Producing output streams or storing results.
 - Feedback: Feeding back results to stream processing.
5. Challenges: Out-of-order data, late-arriving data, high throughput, low latency, fault tolerance.
