## Unit 1 - Introduction to Data Analytics

1. Data Analytics - Data analytics is the process of examining data and identifying patterns and insights to make better decisions. It involves applying an analytical process to data and using statistical techniques and tools to find trends and insights.
2. Types of Data - There are two types of data - Structured data which is organized and follows a pattern like numeric data, dates, etc. and Unstructured data like text, audio, images, etc. which does not have a defined pattern. Both structured and unstructured data is analyzed in data analytics.
3. Data Analytics Process - The key steps in the data analytics process are:

a. Gathering data
b. Organizing and preparing the data
c. Applying statistical and data modeling techniques
d. Analyzing and interpreting the data
e. Gaining insights and making decisions

4. Tools - Some of the tools used for data analytics are Excel, SQL, Python, R, SAS, etc. The tools are chosen based on the type and volume of data, complexity of analysis, and organizational requirements.
5. Applications - Data analytics has a wide range of applications in various industries like business, healthcare, education, and more. It is used to gain business insights, personalize experiences, predict trends, and make optimized decisions.
