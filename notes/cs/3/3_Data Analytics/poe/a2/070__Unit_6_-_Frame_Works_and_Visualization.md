## Unit 6 - Frame Works and Visualization

1. Frameworks provide structure to a software application and enable modular programming. Some key benefits of using frameworks are:
- Increased productivity due to reuse of common code
- Better maintainability as the code is organized in a structured manner
- Faster development as many common tasks are already implemented
- Consistency in coding style and structure

2. Some popular web development frameworks are:
- React - Used for building user interfaces. It is maintained by Facebook and uses a component-based architecture.
- Angular - Built by Google and is a TypeScript-based open-source front-end web application framework.
- Vue.js - Progressive framework with a focus on declarative rendering and component composition.

3. Data visualization refers to the presentation of data in a graphical format. Some key benefits of data visualization are:
- Complex data can be more easily interpreted
- Trends and patterns can be spotted more easily
- The information can be understood faster than reading the raw data
- The data can be more memorable and impactful

4. Libraries used for data visualization in Python are:
- Matplotlib - Comprehensive library for creating static, animated, and interactive visualizations
- Seaborn - Built on top of Matplotlib and provides a high-level interface for drawing attractive statistical graphics
- Bokeh - Enables interactive and web-based visualizations
- Pygal - Creates SVG charts and diagrams in a simple way
