### Visual Data Analysis Techniques

1. Scatter Plot: A scatter plot is a graph with points plotted to show the relationship between two quantitative variables measured on the same individual. It is often used to find out if there is a correlation between variables and the nature of correlation (positive, negative, or none).

2. Line Chart: A line chart is used to display information that changes continuously over time. It is used to show trends in data over a period of time. The data is displayed as a series of data points connected by straight line segments. It is ideal for showing fluctuations and comparative changes in the data.

3. Bar Chart: A bar chart is a graph with rectangular bars with lengths proportional to the values that they represent. It is used to compare different entities to each other. The categories appear on the x-axis and the quantity on the y-axis. It is suitable for representing categorical data.

4. Pie Chart: A pie chart shows the relationship of parts to a whole. It is a circular graph divided into sectors to represent proportions of a whole. The size of each sector shows the proportional value of each category relative to the whole. It is good for showing categorical data as parts of a whole.

5. Histogram: A histogram is used to display the distribution of data. It groups the data into "bins", and shows the number of data points that fall into each bin. It is useful in identifying patterns in the distribution of the data and noticing deviations from these patterns. It is a good way to get an initial sense of the shape of a distribution.
