### Sources and nature of data for the notes of the Unit 1 - Introduction to Data Analytics in the subject of Data Analytics

Data analytics is the process of examining large and varied data sets to derive meaningful insights and draw conclusions. In order to conduct effective data analytics, it is important to have access to relevant and reliable data. In this section, we will discuss the sources and nature of data that are commonly used in data analytics.

- **Internal Data**: This refers to the data that is generated within an organization. This can include sales data, financial data, customer data, and employee data. Internal data is often stored in databases or data warehouses and can be accessed by analysts using various tools and software.

- **External Data**: This refers to the data that is generated outside of an organization. This can include market data, social media data, and government data. External data can be obtained from various sources such as public data sets or through data providers.

- **Structured Data**: This refers to data that is organized in a specific format such as tables or spreadsheets. Structured data is often easy to analyze and can be processed using various data tools.

- **Unstructured Data**: This refers to data that is not organized in a specific format. This can include text data, images, and videos. Unstructured data can be more difficult to analyze and requires specialized software and tools.

- **Big Data**: This refers to data sets that are too large and complex to be processed using traditional data processing tools. Big data requires specialized software and tools such as Hadoop and Spark to process and analyze the data.

- **Real-time Data**: This refers to data that is generated and processed in real-time. This can include data from sensors, social media, and other sources. Real-time data requires specialized tools and software to process and analyze the data in real-time.

In conclusion, data analytics requires access to relevant and reliable data. Internal and external data, structured and unstructured data, big data, and real-time data are all commonly used in data analytics. Understanding the nature and sources of data is essential for effective data analytics.
