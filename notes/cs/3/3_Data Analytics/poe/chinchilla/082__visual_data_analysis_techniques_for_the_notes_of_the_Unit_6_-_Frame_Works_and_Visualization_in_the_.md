### Visual Data Analysis Techniques for the Notes of the Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

Visual data analysis is an important aspect of data analytics that helps in understanding complex data sets easily. In this unit, we will explore various frameworks and visualization techniques used for visual data analysis. Following are the important visual data analysis techniques that you should know:

1. Scatterplots - Scatterplots are used to display the relationship between two variables. It helps in identifying patterns and trends in data.

2. Bar Charts - Bar charts are used to display the distribution of categorical data. It helps in comparing the frequency of data categories easily.

3. Line Charts - Line charts are used to display trends in data over time. It helps in identifying patterns and trends in data over a period of time.

4. Histograms - Histograms are used to display the distribution of continuous data. It helps in identifying the frequency of data values in a given range.

5. Box Plots - Box plots are used to display the distribution of data and identify outliers. It helps in identifying the range of data values, median, quartiles, and outliers.

6. Heat Maps - Heat maps are used to display the distribution of data values as colors on a grid. It helps in identifying patterns and trends in data quickly.

7. Tree Maps - Tree maps are used to display hierarchical data as a set of nested rectangles. It helps in identifying the size and proportion of data values in each category.

8. Network Graphs - Network graphs are used to display relationships between entities as nodes and edges. It helps in identifying the connections and relationships between data entities.

These visual data analysis techniques can be used with various frameworks such as matplotlib, seaborn, ggplot, and bokeh. These frameworks provide a range of functions and tools for visualizing data and creating interactive visualizations. By using these frameworks and techniques, you can create effective visualizations that help in understanding complex data easily.
