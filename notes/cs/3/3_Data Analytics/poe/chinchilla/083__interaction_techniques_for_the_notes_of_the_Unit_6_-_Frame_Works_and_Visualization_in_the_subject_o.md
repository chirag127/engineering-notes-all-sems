### Interaction Techniques for the Notes of the Unit 6 - Frameworks and Visualization in the Subject of Data Analytics

Data visualization is a crucial aspect of data analytics, and it is essential to use the right techniques to interpret and analyze data. With the help of visualization frameworks, data analysts can create interactive and dynamic data visualizations that enable users to explore data and gain insights that were not apparent before. In this unit, we will discuss the interaction techniques that are commonly used to enhance the usability and effectiveness of data visualization frameworks.

Here are some of the interaction techniques that you must know for the notes of Unit 6:

1. **Selection and Filtering** - Selection and filtering techniques are used to highlight specific data points or to exclude data points from visualization. By selecting specific data points, you can focus on the critical aspects of the data and obtain more insights. Filtering techniques enable users to exclude data points that are not relevant to the analysis.

2. **Zooming and Panning** - Zooming and panning techniques allow users to explore data in detail by zooming in or out of the data visualization. Panning enables users to move the visualization to view specific parts of the data. These techniques are particularly useful for analyzing large datasets.

3. **Brushing and Linking** - Brushing and linking techniques enable users to select data points in one visualization and link them to another visualization. This technique is useful for exploring relationships between different aspects of the data and identifying patterns and trends.

4. **Drag and Drop** - Drag and drop techniques enable users to move data points from one visualization to another. This technique is useful for creating new visualizations and comparing different aspects of the data.

5. **Hovering and Tooltips** - Hovering and tooltips techniques enable users to view additional information about specific data points by hovering over them. This technique is useful for providing context and insight into the data.

By using these interaction techniques, data analysts can create powerful and effective data visualizations that enable users to explore data in new ways and gain insights that were not apparent before. It is essential to use the right interaction techniques to enhance the usability and effectiveness of data visualization frameworks.
