### data preparation for the notes of the Unit 2 - Data Analytics Lifecycle in the subject of Data Analytics

Data preparation is a crucial step in the Data Analytics Lifecycle, as it involves cleaning and transforming raw data into a format suitable for analysis. The following steps are involved in data preparation:

1. Data Collection: Collecting data from various sources, including databases, spreadsheets, and APIs.

2. Data Cleaning: Removing missing or incorrect values, dealing with duplicates, and transforming data into a consistent format.

3. Data Transformation: Converting data into a format that can be easily analyzed, such as converting categorical variables into numerical ones.

4. Data Normalization: Scaling data to a common range, so that variables with different units can be compared.

5. Data Integration: Combining data from multiple sources into a single dataset for analysis.

6. Data Reduction: Selecting a subset of relevant data for analysis, reducing the size of the dataset for faster processing.

7. Data Validation: Checking data for accuracy and consistency, and fixing any errors found.

Data preparation is an iterative process, and it may be necessary to repeat some of these steps several times to obtain a clean and usable dataset.
