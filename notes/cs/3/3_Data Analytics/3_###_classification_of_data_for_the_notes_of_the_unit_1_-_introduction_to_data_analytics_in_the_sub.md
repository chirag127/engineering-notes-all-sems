### classification of data for the notes of the Unit 1 - Introduction to Data Analytics in the subject of Data Analytics

Classification of data refers to the process of organizing data into categories based on common characteristics. This is useful for analyzing and understanding patterns in the data. There are several methods for classifying data, including:

1. Nominal: data is placed into categories without any order or ranking.
2. Ordinal: data is placed into categories with a specific order or ranking.
3. Interval: data is placed into categories with equal intervals between values.
4. Ratio: data is placed into categories with a true zero point, allowing for meaningful comparisons of values.

Examples of classification of data in Data Analytics include:

1. Categorizing customer data based on demographics (nominal)
2. Sorting sales data by revenue (ordinal)
3. Grouping temperature data by decade (interval)
4. Measuring website traffic by unique visitors (ratio)
