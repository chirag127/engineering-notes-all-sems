### stream data model and architecture for the notes of the Unit 4 - Mining Data Streams in the subject of Data Analytics

Stream data model:
- Data is processed in real-time and in a continuous manner
- Data is unbounded and arrives in a high velocity
- Data is often processed in a distributed manner

Stream data architecture:
- Typically includes a data source, a data stream processing engine, and a data sink
- The data source generates the data stream and sends it to the processing engine
- The processing engine performs operations on the data stream such as filtering, aggregating, and transforming
- The data sink stores the processed data

Note: 
- In a stream data architecture, data is processed as it arrives and there is no need to store all the data. 
- The architecture must be scalable and able to handle large amounts of data.
