## Program for Selection Sort for the notes of the Design and Analysis of Algorithm Lab in the subject of Real Time System

Selection Sort is a simple sorting algorithm that sorts an array by repeatedly finding the minimum element from the unsorted part of the array and swapping it with the first unsorted element. The following are some of the key concepts related to the Selection Sort algorithm:

1. Array: The input to the Selection Sort algorithm is an array of elements that need to be sorted.

2. Sorted and Unsorted Part: The array is divided into a sorted part, which contains the elements that have been sorted, and an unsorted part, which contains the elements that still need to be sorted.

3. Finding the Minimum Element: The algorithm repeatedly finds the minimum element from the unsorted part of the array and swaps it with the first unsorted element.

4. Swapping Elements: The algorithm swaps the minimum element found with the first unsorted element, effectively moving the minimum element to the sorted part of the array.

5. Repeat: The algorithm repeats the process of finding the minimum element and swapping it with the first unsorted element until all elements have been sorted.

6. Time Complexity: The time complexity of the Selection Sort algorithm is O(n^2), where n is the number of elements in the array.
