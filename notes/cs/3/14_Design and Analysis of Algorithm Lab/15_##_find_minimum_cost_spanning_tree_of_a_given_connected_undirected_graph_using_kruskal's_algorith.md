## Find Minimum Cost Spanning Tree of a given connected undirected graph using Kruskal's algorithm. Use Union-Find algorithms in your program. for the notes of the Design and Analysis of Algorithm Lab in the subject of Real Time System

Kruskal's algorithm is a greedy algorithm that is used to find the minimum cost spanning tree of a given connected undirected graph. The following are some of the key concepts related to Kruskal's algorithm and union-find algorithms:

1. Spanning Tree: A spanning tree is a tree that spans all the vertices of a graph, and a minimum cost spanning tree is a spanning tree with the minimum possible total edge weight.

2. Kruskal's Algorithm: Kruskal's algorithm is a greedy algorithm that sorts the edges of the graph by weight and adds edges to the spanning tree in increasing order of weight, as long as adding the edge does not create a cycle.

3. Union-Find Algorithms: Union-find algorithms are used to keep track of the connected components in the graph, and they are used to determine if adding an edge creates a cycle.

4. Disjoint Sets: Disjoint sets are sets of vertices that do not have any common vertices, and union-find algorithms are used to maintain disjoint sets.

5. Union and Find Operations: The union operation combines two disjoint sets into a single set, and the find operation returns the representative of a set.

6. Time Complexity: The time complexity of Kruskal's algorithm with union-find algorithms is O(m log n), where m is the number of edges and n is the number of vertices in the graph.
