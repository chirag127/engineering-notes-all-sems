## Program for Heap Sort for the notes of the Design and Analysis of Algorithm Lab in the subject of Real Time System

Heap Sort is a sorting algorithm that uses a binary heap data structure to sort an array of elements. The following are some of the key concepts related to Heap Sort:

1. Binary Heap: A binary heap is a complete binary tree data structure that is used to implement Heap Sort. It has two types: max-heap and min-heap.

2. Max-Heap: In a max-heap, the parent node is always greater than or equal to its children.

3. Min-Heap: In a min-heap, the parent node is always less than or equal to its children.

4. Heapify: Heapify is the process of converting a binary tree into a heap.

5. Build Heap: Build Heap is the process of constructing a heap from an array of elements.

6. Sorting: Heap Sort sorts an array of elements by repeatedly removing the maximum or minimum element from the heap and inserting it into the sorted portion of the array.

In this unit, you will learn about Heap Sort, and you will learn how to implement it using a binary heap data structure. You will also learn about the key concepts related to Heap Sort, including binary heap, max-heap, min-heap, heapify, build heap, and sorting.

This unit will provide a foundation for understanding the principles and practices of Heap Sort, and for exploring the various concepts and techniques used in the field of Real Time System and Design and Analysis of Algorithm Lab.
