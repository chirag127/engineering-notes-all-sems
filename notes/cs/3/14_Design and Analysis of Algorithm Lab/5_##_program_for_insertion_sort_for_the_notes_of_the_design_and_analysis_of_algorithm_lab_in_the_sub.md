## Program for Insertion Sort for the notes of the Design and Analysis of Algorithm Lab in the subject of Real Time System

Insertion Sort is a simple sorting algorithm that sorts an array by comparing each element to the elements that come before it and swapping elements if necessary. The following are some of the key concepts related to Insertion Sort:

1. Algorithm Steps: Insertion Sort works by iterating through the array, comparing each element to the elements that come before it, and swapping elements if necessary.

2. Time Complexity: The time complexity of Insertion Sort is O(n^2), which means that the algorithm takes longer to sort larger arrays.

3. Space Complexity: The space complexity of Insertion Sort is O(1), which means that the algorithm only requires a constant amount of memory regardless of the size of the array.

4. Stable Sorting: Insertion Sort is a stable sorting algorithm, which means that it maintains the relative order of elements with the same value.

5. Adaptive Sorting: Insertion Sort is an adaptive sorting algorithm, which means that it performs better when the array is partially sorted.

6. Use Cases: Insertion Sort is best suited for small arrays or arrays that are already partially sorted, and it is not recommended for large arrays.
