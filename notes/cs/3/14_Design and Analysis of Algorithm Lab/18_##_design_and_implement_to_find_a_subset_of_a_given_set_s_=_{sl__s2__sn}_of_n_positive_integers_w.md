3. Base Case: The base case in the Subset Sum problem is when the sum of the current subset is equal to d, in which case the current subset is a solution.

4. Backtracking: The Subset Sum problem involves trying different subsets and undoing them if they fail, which is a form of backtracking.

5. Pruning: Pruning can be used to improve the performance of the Subset Sum problem by discarding subsets that are unlikely to lead to a solution.
