### CIDR for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

Unit 5 - Network Layer in the subject of Computer Networks will cover the concept of CIDR (Classless Inter-Domain Routing), a method for allocating IP addresses and routing IP packets.

CIDR is a method for allocating IP addresses and routing IP packets that was introduced to address the shortage of IP addresses in the early days of the Internet. CIDR replaces the traditional classful IP addressing system with a more flexible and scalable system that allows for more efficient use of IP addresses.

In the context of Unit 5 - Network Layer in the subject of Computer Networks, students will learn about the basics of CIDR, including how to use CIDR to allocate IP addresses and route IP packets. This may include working with examples of CIDR, analyzing the syntax and structure of CIDR, and learning how to use CIDR to manage IP addresses and routing in a computer network.

In Unit 5 - Network Layer in the subject of Computer Networks, students will also learn about the benefits and limitations of using CIDR, and will learn about alternative methods for allocating IP addresses and routing IP packets, such as subnetting.
