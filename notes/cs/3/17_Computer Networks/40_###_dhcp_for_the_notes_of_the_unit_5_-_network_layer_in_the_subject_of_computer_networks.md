### DHCP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

DHCP (Dynamic Host Configuration Protocol) is a protocol used in computer networks to dynamically assign IP addresses to devices. The following are some of the key concepts related to DHCP:

1. IP Addresses: IP addresses are unique identifiers assigned to devices in a network, and are used to route data between devices.

2. Dynamic IP Addresses: Dynamic IP addresses are IP addresses that are assigned to devices dynamically, rather than being statically assigned.

3. DHCP Server: A DHCP server is a device that is responsible for assigning IP addresses to devices in a network.

4. DHCP Client: A DHCP client is a device that requests an IP address from a DHCP server.

5. DHCP Lease: A DHCP lease is the amount of time for which an IP address is assigned to a device.

6. DHCP Renewal: DHCP renewal is the process of renewing a DHCP lease before it expires, to ensure that the device continues to have a valid IP address.

In this unit, you will learn about DHCP, including IP addresses, dynamic IP addresses, DHCP server, DHCP client, DHCP lease, and DHCP renewal.

This unit will provide a foundation for understanding the principles and practices of the network layer in computer networking, and for exploring the various concepts and techniques used in the field of computer networks.
