### Cryptography – basic concepts for the notes of the Unit 7 - Application Layer in the subject of Computer Networks

Unit 7 - Application Layer in the subject of Computer Networks will cover the basic concepts of Cryptography, a technique used to secure data transmission in computer networks.

Cryptography is the practice of using mathematical algorithms to secure data transmission in computer networks. It involves transforming data into a secret code to protect it from unauthorized access or modification. Cryptography is used to secure data transmission in computer networks, to ensure that sensitive information is protected from unauthorized access or modification.
