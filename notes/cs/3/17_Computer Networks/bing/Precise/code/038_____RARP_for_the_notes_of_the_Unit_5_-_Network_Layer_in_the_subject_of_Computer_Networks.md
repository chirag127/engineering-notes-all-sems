### RARP

RARP stands for Reverse Address Resolution Protocol. It is a protocol used to map a MAC address to an IP address. It is used in situations where a device does not know its own IP address, but knows its MAC address. Here are some key points to remember about RARP:

1. RARP is defined in RFC 903.
2. RARP operates at the Data Link Layer of the OSI model.
3. RARP uses the same message format as ARP, but with different operation codes.
4. RARP is used by diskless workstations to obtain an IP address from a RARP server.
5. RARP is not widely used today, as it has been largely replaced by other protocols such as BOOTP and DHCP.
