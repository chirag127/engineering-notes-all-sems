### Link Layer Switches & Bridges

Link layer switches and bridges are devices used in computer networks to connect multiple devices and facilitate communication between them. These devices operate at the link layer (layer 2) of the OSI model and are responsible for forwarding data frames between devices on the same network or between different networks.

Some key points to note about link layer switches and bridges are:

1. Link layer switches and bridges are used to segment a network into smaller collision domains, reducing the number of collisions and improving network performance.
2. These devices use MAC addresses to forward data frames to their destination.
3. Switches and bridges can learn the MAC addresses of devices connected to them by examining the source MAC address of incoming data frames.
4. Switches and bridges can use this information to build a forwarding table, which is used to determine the appropriate port to forward a data frame to.
5. Switches and bridges can also use filtering and forwarding rules to control the flow of data on the network.
6. Bridges can be used to connect different types of networks, such as Ethernet and Token Ring, while switches are typically used to connect devices on the same type of network.
7. Switches are generally faster and more efficient than bridges, as they can handle multiple data frames simultaneously.

This is a brief overview of link layer switches and bridges. These devices play a crucial role in the operation of computer networks, allowing multiple devices to communicate and share data efficiently. They are an important topic to understand for anyone studying computer networks and medium access control.
