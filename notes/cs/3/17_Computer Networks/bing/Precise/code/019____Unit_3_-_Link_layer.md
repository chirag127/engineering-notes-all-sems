## Unit 3 - Link layer

The link layer is the lowest layer in the OSI model of computer networking. It is responsible for the transmission of data between two directly connected nodes. Some of the key functions of the link layer include:

1. **Framing**: The link layer takes packets from the network layer and encapsulates them into frames. This involves adding a header and a trailer to the packet, which contains information such as the source and destination addresses.

2. **Error detection and correction**: The link layer is responsible for detecting and correcting errors that may occur during transmission. This is achieved through the use of error-detecting codes such as checksums and cyclic redundancy checks.

3. **Flow control**: The link layer ensures that the sender does not overwhelm the receiver by sending too much data too quickly. This is achieved through the use of flow control mechanisms such as sliding window protocols.

4. **Media access control**: In a shared medium such as a local area network, the link layer is responsible for controlling access to the transmission medium. This is achieved through the use of media access control protocols such as CSMA/CD.

5. **Physical addressing**: The link layer is responsible for mapping network addresses to physical addresses. This is achieved through the use of protocols such as the Address Resolution Protocol (ARP).

The link layer is an essential component of any computer network, providing the foundation for the higher layers to build upon. It is responsible for ensuring that data is transmitted reliably and efficiently between directly connected nodes.
