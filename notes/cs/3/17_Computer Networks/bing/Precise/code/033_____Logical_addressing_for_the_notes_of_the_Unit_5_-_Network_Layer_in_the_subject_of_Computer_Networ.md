### Logical Addressing

- Logical addressing is used to provide a universal addressing scheme for identifying hosts on a network.
- It is used at the network layer of the OSI model.
- Logical addresses are assigned by the network layer protocol, such as the Internet Protocol (IP).
- Logical addresses are used to route data between networks.
- The most common logical addressing scheme is the IP addressing scheme, which uses 32-bit (IPv4) or 128-bit (IPv6) addresses.
- Logical addresses are hierarchical, meaning that they are divided into network and host portions.
- The network portion of the address identifies the network to which the host is connected, while the host portion identifies the specific host on that network.
- Logical addresses are independent of the physical addresses used by the data link layer, allowing for flexibility in network design and management.
- Logical addressing is essential for routing data across the internet, as it allows routers to determine the best path for forwarding data based on the destination address.
