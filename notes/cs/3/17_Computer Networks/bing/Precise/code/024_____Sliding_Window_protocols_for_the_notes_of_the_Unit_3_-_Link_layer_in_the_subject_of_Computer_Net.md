### Sliding Window protocols for the notes of the Unit 3 - Link layer in the subject of Computer Networks

Sliding Window protocols are a type of flow control protocol used in computer networks to manage the transmission of data between two devices. These protocols are used at the link layer of the OSI model to ensure that data is transmitted reliably and efficiently.

Some key points to remember about Sliding Window protocols are:

1. Sliding Window protocols use a window of data frames to manage the transmission of data between two devices.
2. The window size determines the number of data frames that can be transmitted at any given time.
3. The sender transmits data frames within the window and waits for an acknowledgment from the receiver before transmitting more data.
4. If an acknowledgment is not received within a certain time period, the sender will retransmit the data frames.
5. The receiver uses the window to manage the reception of data frames and to ensure that data is received in the correct order.
6. The receiver sends an acknowledgment to the sender for each data frame received within the window.
7. The window is moved along the data stream as data is transmitted and acknowledged, allowing for the continuous transmission of data.

Sliding Window protocols are an important part of the link layer in computer networks and are essential for ensuring the reliable and efficient transmission of data. They are used in many different types of networks, including local area networks (LANs) and wide area networks (WANs).
