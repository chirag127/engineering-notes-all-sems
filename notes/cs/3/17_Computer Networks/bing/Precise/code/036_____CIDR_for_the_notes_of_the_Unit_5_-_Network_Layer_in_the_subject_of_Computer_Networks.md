### CIDR for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

CIDR stands for Classless Inter-Domain Routing. It is a method for allocating IP addresses and routing Internet Protocol packets. Here are some key points to remember about CIDR:

1. CIDR notation is used to represent IP addresses and their associated routing prefix. It is written as the IP address, followed by a slash, and then the prefix length. For example, `192.168.1.0/24` represents the IPv4 address `192.168.1.0` with a 24-bit routing prefix.
2. CIDR allows for more efficient use of IP address space and routing table memory. It does this by allowing for variable-length subnet masks, which can be used to allocate IP addresses more precisely.
3. CIDR is used by Internet Service Providers (ISPs) to allocate IP addresses to their customers. It is also used by network administrators to divide their networks into smaller subnets.
4. CIDR has replaced the older system of classful IP addressing, which divided the IP address space into fixed-size classes.
5. CIDR is an important concept to understand when studying computer networks, as it is widely used in the routing of IP packets on the Internet.
