### Static and dynamic routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

1. **Static routing** is a type of routing in which the network administrator manually configures the routing table on a router. The routing table contains information about the network topology and the best path to reach a destination network.
2. Static routing is simple to implement and requires less processing power and memory than dynamic routing. However, it is not scalable and can be difficult to manage in large networks.
3. **Dynamic routing** is a type of routing in which the router automatically learns the best path to reach a destination network. This is done through the use of routing protocols, which exchange information about the network topology between routers.
4. Dynamic routing is more scalable and easier to manage than static routing, but it requires more processing power and memory. It is also more complex to implement and can be less predictable than static routing.
5. Some common dynamic routing protocols include OSPF, EIGRP, and BGP.
6. The choice between static and dynamic routing depends on the size and complexity of the network, as well as the level of control and predictability required by the network administrator.
