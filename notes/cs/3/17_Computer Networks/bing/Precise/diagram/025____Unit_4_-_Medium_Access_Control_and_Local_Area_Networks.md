## Unit 4 - Medium Access Control and Local Area Networks

1. **Medium Access Control (MAC)** is a sublayer of the Data Link Layer in the OSI model. It is responsible for controlling how devices in a network gain access to a shared medium and transmit data.

2. MAC protocols can be divided into two categories: **contention-based** and **contention-free**. Contention-based protocols, such as Carrier Sense Multiple Access with Collision Detection (CSMA/CD), allow multiple devices to compete for access to the shared medium. Contention-free protocols, such as Time Division Multiple Access (TDMA), allocate time slots to each device to transmit data without contention.

3. **Local Area Networks (LANs)** are computer networks that span a relatively small area, such as a single building or a group of buildings. LANs are typically used to connect devices within a single organization and enable them to share resources, such as printers and file servers.

4. The most common type of LAN is an **Ethernet LAN**, which uses the CSMA/CD protocol for medium access control. Ethernet LANs can operate at speeds ranging from 10 Mbps to 100 Gbps.

5. Another type of LAN is a **Wireless LAN (WLAN)**, which uses radio waves to transmit data between devices. The most common WLAN technology is Wi-Fi, which operates in the 2.4 GHz and 5 GHz frequency bands and can support data rates up to several Gbps.

6. LANs can be interconnected using devices such as **bridges**, **switches**, and **routers**. Bridges and switches operate at the Data Link Layer and are used to connect LAN segments, while routers operate at the Network Layer and are used to connect multiple LANs to form a larger network.

7. **Virtual LANs (VLANs)** are a way to logically segment a LAN into multiple broadcast domains. VLANs can be used to improve network performance, security, and manageability by grouping devices with similar requirements into the same broadcast domain.

8. **Spanning Tree Protocol (STP)** is a protocol used to prevent loops in a network with redundant links. STP ensures that only one path is active between any two network devices, preventing loops and enabling the network to recover from link failures.

9. **Power over Ethernet (PoE)** is a technology that allows network devices to receive power over the same cable that carries data. PoE can be used to power devices such as IP phones, wireless access points, and security cameras, eliminating the need for separate power cables.

10. **Quality of Service (QoS)** is a mechanism used to prioritize different types of traffic in a network. QoS can be used to ensure that critical applications, such as voice and video, receive the necessary bandwidth and delay guarantees to function properly.
