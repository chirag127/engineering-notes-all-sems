### Link Layer Switches & Bridges

Link layer switches and bridges are devices used in computer networks to connect multiple devices and facilitate communication between them. These devices operate at the link layer (layer 2) of the OSI model and are responsible for forwarding data frames between devices on the same network or between different networks.

Some key points to note about link layer switches and bridges are:

1. Link layer switches and bridges are used to segment a network into smaller, more manageable sections, reducing the amount of traffic on each segment and improving overall network performance.
2. These devices use MAC addresses to forward data frames to their destination. They maintain a table of MAC addresses and their associated ports, allowing them to quickly forward frames to the correct destination.
3. Link layer switches and bridges can also be used to connect different types of networks, such as Ethernet and Token Ring, by converting the data frames between the different formats.
4. Bridges operate at the link layer, while switches can operate at both the link and network layers. This allows switches to perform more advanced functions, such as routing and filtering, in addition to basic frame forwarding.
5. Link layer switches and bridges can be used to create virtual LANs (VLANs), which allow devices on the same physical network to be logically separated into different broadcast domains.

These are some of the key points to remember about link layer switches and bridges in the context of medium access control and local area networks. They play an important role in improving network performance and facilitating communication between devices.
