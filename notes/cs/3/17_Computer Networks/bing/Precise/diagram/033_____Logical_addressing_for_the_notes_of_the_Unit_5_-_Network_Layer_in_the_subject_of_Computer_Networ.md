### Logical Addressing

Logical addressing is a method used in computer networks to identify devices on the network. It is used in the network layer of the OSI model. Logical addresses are also known as network addresses or IP addresses.

Here are some key points to remember about logical addressing:

1. Logical addresses are assigned by the network administrator or automatically by the network's Dynamic Host Configuration Protocol (DHCP) server.
2. Logical addresses are used to route data between devices on a network.
3. Logical addresses are hierarchical, meaning that they are divided into different levels, such as network and host addresses.
4. Logical addresses are independent of the physical addresses used by the data link layer.
5. Logical addresses are used by routers to determine the best path for data to travel between devices on a network.
6. The most common logical addressing scheme used on the Internet is the Internet Protocol (IP) addressing scheme.
