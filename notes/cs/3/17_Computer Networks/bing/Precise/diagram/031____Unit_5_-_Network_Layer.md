## Unit 5 - Network Layer

The network layer is responsible for routing data packets from the source to the destination. It is the third layer in the OSI model and is responsible for the following functions:

1. **Logical Addressing:** The network layer assigns a logical address to each device on the network. This address is used to identify the device and route data to it.

2. **Routing:** The network layer is responsible for finding the best path for data to travel from the source to the destination. This is done using routing algorithms.

3. **Fragmentation and Reassembly:** If a data packet is too large to be transmitted over a particular link, the network layer can fragment the packet into smaller packets. These smaller packets are then reassembled at the destination.

4. **Error Handling and Diagnostics:** The network layer is responsible for detecting and correcting errors that may occur during transmission. It can also provide diagnostic information to help troubleshoot network problems.

5. **Congestion Control:** The network layer can implement congestion control mechanisms to prevent network congestion and ensure that data is transmitted efficiently.

The network layer is a crucial component of any network, as it enables communication between devices on different networks. It is responsible for ensuring that data is transmitted reliably and efficiently, and plays a key role in the overall performance of the network.
