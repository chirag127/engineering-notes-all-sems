## Unit 3 - Link layer

The link layer is the lowest layer in the OSI model of computer networking. It is responsible for the transmission of data between two directly connected nodes. The link layer is responsible for the following tasks:

1. **Framing**: The link layer takes the packets from the network layer and encapsulates them into frames. This involves adding a header and a trailer to the packet to create a frame.

2. **Error detection and correction**: The link layer is responsible for detecting and correcting errors that may occur during transmission. This is done using techniques such as checksums and cyclic redundancy checks (CRC).

3. **Flow control**: The link layer is responsible for regulating the flow of data between two nodes to prevent the receiver from being overwhelmed by the sender.

4. **Media access control**: In a shared medium, such as a local area network (LAN), the link layer is responsible for controlling access to the medium to prevent collisions.

5. **Physical addressing**: The link layer is responsible for assigning physical addresses, such as MAC addresses, to nodes on the network.

The link layer is an essential component of any network, as it provides the foundation for the transmission of data between nodes. It is responsible for ensuring that data is transmitted reliably and efficiently, and for managing access to shared resources.
