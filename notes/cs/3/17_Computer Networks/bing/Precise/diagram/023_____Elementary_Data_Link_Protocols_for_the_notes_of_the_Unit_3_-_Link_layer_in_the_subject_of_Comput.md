### Elementary Data Link Protocols

The data link layer is responsible for providing reliable data transfer between two adjacent nodes in a network. This is achieved through the use of various data link protocols. Some of the elementary data link protocols are:

1. **Simplex Protocol**: This protocol is used when the communication is unidirectional, i.e., data is transmitted in one direction only. It is a simple protocol where the sender sends the data and the receiver receives it without any acknowledgment.

2. **Stop-and-Wait Protocol**: This protocol is used when the communication is bidirectional, i.e., data is transmitted in both directions. In this protocol, the sender sends a frame and waits for an acknowledgment from the receiver before sending the next frame.

3. **Sliding Window Protocol**: This protocol is an improvement over the stop-and-wait protocol. In this protocol, the sender can send multiple frames before waiting for an acknowledgment from the receiver. The number of frames that can be sent is determined by the window size.

These are some of the elementary data link protocols used in computer networks. They provide reliable data transfer between two adjacent nodes in a network.
