### DHCP
DHCP (Dynamic Host Configuration Protocol) is a network management protocol used to dynamically assign an IP address to devices on a network. It is used to enable devices to communicate with each other on an IP network.

Here are some key points to remember about DHCP:

1. DHCP is used to automatically assign IP addresses to devices on a network.
2. DHCP can also provide other network configuration information, such as the subnet mask, default gateway, and DNS server addresses.
3. DHCP operates on the application layer of the OSI model.
4. DHCP uses a client-server model, where the DHCP server manages a pool of IP addresses and assigns them to clients as needed.
5. When a device connects to a network, it sends a broadcast message requesting an IP address. The DHCP server responds with an offer of an IP address, and the device can accept or decline the offer.
6. DHCP can be used to assign both static and dynamic IP addresses.
7. DHCP can help reduce the administrative burden of managing IP addresses on a large network.
