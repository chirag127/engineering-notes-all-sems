## Unit 3 - Link layer

The link layer is the lowest layer in the OSI model of computer networking. It is responsible for the transmission of data between two directly connected nodes. Some of the key functions of the link layer include:

1. **Framing:** The link layer is responsible for dividing the data into frames, which are units of data that can be transmitted over the network.

2. **Error detection and correction:** The link layer is responsible for detecting and correcting errors that may occur during transmission.

3. **Flow control:** The link layer is responsible for regulating the flow of data between two nodes to prevent the receiver from being overwhelmed by the sender.

4. **Media access control:** The link layer is responsible for controlling access to the shared transmission medium, such as a cable or wireless channel.

5. **Addressing:** The link layer is responsible for assigning addresses to nodes on the network, which are used to identify the source and destination of data.

The link layer is an essential component of any computer network, as it provides the foundation for the transmission of data between nodes. It is responsible for ensuring that data is transmitted reliably and efficiently, and plays a key role in the overall performance of the network.
