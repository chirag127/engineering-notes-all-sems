# Unit 3 - Link Layer: Framing

1. Framing is the process of encapsulating data into a frame or packet for transmission over a network.
2. The link layer is responsible for framing, which includes adding a header and trailer to the data.
3. The header contains information such as the source and destination addresses, while the trailer contains error-detection information.
4. Different link layer protocols use different framing methods, such as character stuffing or bit stuffing.
5. The framing method used depends on the characteristics of the transmission medium, such as whether it is a synchronous or asynchronous transmission.
6. The purpose of framing is to provide a way for the receiver to identify the start and end of a frame, and to ensure that the data is transmitted correctly.
7. Error-detection methods, such as checksums or cyclic redundancy checks (CRC), are used to detect errors in the transmitted data.
8. If an error is detected, the receiver can request that the frame be retransmitted.
9. Framing is an essential part of the link layer, as it provides the necessary structure for data transmission over a network.
