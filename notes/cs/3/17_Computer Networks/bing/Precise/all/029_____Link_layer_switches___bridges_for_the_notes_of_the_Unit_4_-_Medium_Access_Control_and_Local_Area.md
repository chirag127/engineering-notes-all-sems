### Link Layer Switches & Bridges

Link layer switches and bridges are devices that operate at the link layer (layer 2) of the OSI model and are used to connect multiple network segments and create a larger network.

1. **Link Layer Switches:** Link layer switches are used to connect multiple devices on a local area network (LAN) and forward data packets between them. They use the MAC addresses of the devices to determine the destination of the data packets and forward them accordingly. Link layer switches can also be used to create virtual LANs (VLANs) to logically separate devices on the same physical network.

2. **Bridges:** Bridges are similar to link layer switches in that they are used to connect multiple network segments and forward data packets between them. However, bridges operate at a lower level than switches and are typically used to connect two LANs that use the same link layer protocol. Bridges use the MAC addresses of the devices to determine the destination of the data packets and forward them accordingly.

In summary, link layer switches and bridges are used to connect multiple network segments and create a larger network. They operate at the link layer of the OSI model and use the MAC addresses of the devices to forward data packets between them. Link layer switches can also be used to create VLANs to logically separate devices on the same physical network.
