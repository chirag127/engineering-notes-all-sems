### File Transfer Protocol (FTP)

FTP is a standard network protocol used to transfer files from one host to another over a TCP-based network, such as the Internet. FTP is built on a client-server architecture and uses separate control and data connections between the client and the server.

Here are some key points to remember about FTP:

1. FTP is a standard protocol for transferring files over the Internet.
2. FTP uses a client-server architecture.
3. FTP uses separate control and data connections between the client and the server.
4. FTP can be used to transfer files of any size and type.
5. FTP can be used to transfer files between different operating systems.
6. FTP can be used to transfer files between different file systems.
7. FTP can be used to transfer files between different network architectures.
8. FTP can be used to transfer files between different security domains.
