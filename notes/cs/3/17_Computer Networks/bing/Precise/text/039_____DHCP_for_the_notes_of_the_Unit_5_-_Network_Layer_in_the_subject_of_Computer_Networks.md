### DHCP (Dynamic Host Configuration Protocol)
- DHCP is a network management protocol used on Internet Protocol (IP) networks.
- It is used for automatically assigning IP addresses and other network configuration parameters to devices on a network.
- DHCP operates on a client-server model, where a DHCP server dynamically assigns an IP address and other network configuration parameters to each device on a network.
- The DHCP server maintains a pool of IP addresses and leases an address to any DHCP-enabled client when it starts up on the network.
- The lease time for an IP address is configurable, and after the lease time has expired, the client must request a new IP address.
- DHCP can also provide other network configuration parameters, such as the subnet mask, default gateway, and Domain Name System (DNS) server addresses.
- DHCP is an essential part of modern networks and is used in homes, businesses, and other organizations to simplify network management and reduce the need for manual configuration.
