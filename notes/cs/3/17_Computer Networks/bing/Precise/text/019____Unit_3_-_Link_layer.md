## Unit 3 - Link layer

The link layer is the lowest layer in the OSI model of computer networking. It is responsible for the transmission of data between two directly connected nodes. The link layer is responsible for the following tasks:

1. Framing: The link layer takes the packets from the network layer and encapsulates them into frames. This process adds a header and a trailer to the packet, which contains information such as the source and destination addresses, error detection codes, and other control information.

2. Error detection and correction: The link layer is responsible for detecting and correcting errors that may occur during transmission. This is done using techniques such as parity checking and cyclic redundancy checks.

3. Flow control: The link layer is responsible for regulating the flow of data between the two nodes. This is done to prevent the receiver from being overwhelmed by the sender.

4. Media access control: The link layer is responsible for controlling access to the shared communication medium. This is done using techniques such as carrier sense multiple access with collision detection (CSMA/CD) and token passing.

5. Physical addressing: The link layer is responsible for assigning physical addresses to the nodes in the network. These addresses are used to identify the source and destination of the frames.

The link layer is an essential component of any computer network, as it provides the foundation for the transmission of data between nodes. It is responsible for ensuring that the data is transmitted reliably and efficiently, and for managing access to the shared communication medium.
