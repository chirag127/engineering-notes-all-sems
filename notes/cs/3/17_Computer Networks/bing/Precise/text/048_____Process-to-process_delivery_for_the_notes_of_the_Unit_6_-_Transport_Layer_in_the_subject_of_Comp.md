### Process-to-process delivery

Process-to-process delivery is a key function of the transport layer in computer networks. It involves the delivery of data from one application process on one device to another application process on another device. Here are some key points to remember about process-to-process delivery:

1. The transport layer is responsible for providing logical communication between application processes running on different hosts.
2. To achieve this, the transport layer uses port numbers to identify different application processes and to distinguish between them.
3. The transport layer also provides mechanisms for error control, flow control, and congestion control to ensure reliable and efficient data transfer between application processes.
4. Two common transport layer protocols that provide process-to-process delivery are the Transmission Control Protocol (TCP) and the User Datagram Protocol (UDP).
5. TCP provides reliable, connection-oriented service, while UDP provides an unreliable, connectionless service.
6. The choice of transport layer protocol depends on the requirements of the application, with some applications requiring the reliability of TCP, while others can tolerate the unreliability of UDP in exchange for lower overhead and faster transmission.
