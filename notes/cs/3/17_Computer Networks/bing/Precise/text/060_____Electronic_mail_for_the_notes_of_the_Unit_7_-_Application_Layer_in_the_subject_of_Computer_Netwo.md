### Electronic Mail

Electronic mail, commonly known as email, is a method of exchanging digital messages between people using electronic devices. It is one of the most widely used services on the internet and is an essential component of the Application Layer in the subject of Computer Networks.

1. **Components of Email System:** An email system consists of several components, including user agents, mail servers, and the Simple Mail Transfer Protocol (SMTP).
2. **User Agents:** A user agent, also known as an email client, is a software application that allows users to compose, send, receive, and manage email messages. Examples of user agents include Microsoft Outlook, Apple Mail, and Gmail.
3. **Mail Servers:** A mail server is a computer system that stores and manages email messages. It receives incoming messages from other mail servers or user agents and stores them in the appropriate mailbox. It also forwards outgoing messages to their destination.
4. **Simple Mail Transfer Protocol (SMTP):** SMTP is the standard protocol used for sending email messages between mail servers. It is used to transfer messages from the sender's mail server to the recipient's mail server.
5. **Email Message Format:** An email message consists of two main parts: the header and the body. The header contains information about the sender, recipient, subject, and other metadata. The body contains the actual content of the message.
6. **Email Security:** Email security is an important concern as email messages can contain sensitive information. Common security measures include encryption, digital signatures, and spam filtering.
