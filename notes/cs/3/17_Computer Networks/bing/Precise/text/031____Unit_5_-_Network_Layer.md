## Unit 5 - Network Layer

The network layer is responsible for routing data packets from the source to the destination. It is the third layer of the OSI model, sitting above the data link layer and below the transport layer.

Some of the key functions of the network layer include:
1. Logical addressing: The network layer assigns logical addresses, such as IP addresses, to devices on the network. These addresses are used to identify devices and route data between them.
2. Routing: The network layer is responsible for determining the best path for data to travel from the source to the destination. This is done using routing algorithms and protocols.
3. Packet forwarding: Once the best path has been determined, the network layer is responsible for forwarding data packets along that path.
4. Fragmentation and reassembly: If a data packet is too large to be transmitted over a particular link, the network layer may fragment the packet into smaller pieces. These pieces are then reassembled at the destination.
5. Error handling and diagnostics: The network layer is responsible for detecting and handling errors that may occur during transmission. This includes lost or corrupted packets, as well as network congestion.

Some common protocols used at the network layer include IP (Internet Protocol), ICMP (Internet Control Message Protocol), and IGMP (Internet Group Management Protocol). These protocols provide the necessary functionality for routing and managing data on a network.
