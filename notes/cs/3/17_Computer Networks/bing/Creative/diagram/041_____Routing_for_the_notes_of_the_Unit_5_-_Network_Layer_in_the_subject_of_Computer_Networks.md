### Routing
- Routing is the process of delivering packets from a source host to a destination host across one or more networks  .
- Routing takes place at the network layer (layer 3) of the Open Systems Interconnection (OSI) reference model .
- Routing involves two main functions: determining the optimal path for each packet and forwarding the packet along that path.
- Routing is performed by a special device known as a router  .
- A router is a network device that operates at the network layer and connects two or more networks or subnetworks .
- A router forwards packets based on the information available in the packet header and the forwarding table .
- The packet header contains the source and destination IP addresses of the packet.
- The forwarding table contains the mapping of IP addresses to the next-hop router or interface.
- There are different types of routing algorithms that can be used to determine the optimal path for each packet.
- Some of the common types of routing algorithms are:
  - Static routing: the routes are manually configured by the network administrator.
  - Dynamic routing: the routes are automatically updated by the routers using routing protocols.
  - Distance vector routing: the routers exchange information about the distance and direction to each destination.
  - Link state routing: the routers exchange information about the state and cost of each link in the network.
  - Hierarchical routing: the network is divided into regions or domains and routing is done at different levels.
