### Multiple access protocols

Multiple access protocols are a set of protocols operating in the Medium Access Control sublayer (MAC sublayer) of the Open Systems Interconnection (OSI) model. These protocols allow a number of nodes or users to access a shared network channel. The main objectives of multiple access protocols are to avoid collisions, minimize delay, maximize throughput, and ensure fairness.

#### Categories of multiple access protocols

Multiple access protocols can be broadly classified into three categories :

- **Random access protocols**: Random access protocols assign uniform priority to all connected nodes. Any node can send data whenever it wants, without waiting for a permission or a turn. However, if two or more nodes transmit data at the same time, a collision occurs and the data is corrupted. The nodes have to detect and resolve the collisions using some algorithms. Examples of random access protocols are ALOHA, CSMA, CSMA/CD, and CSMA/CA.
- **Controlled access protocols**: Controlled access protocols assign different priority levels to different nodes. A node has to request and obtain permission from a central authority or a distributed algorithm before sending data. This way, collisions are avoided and the channel utilization is improved. Examples of controlled access protocols are Reservation, Polling, and Token passing.
- **Channelization protocols**: Channelization protocols divide the channel into smaller sub-channels and assign them to different nodes. Each node can send data only on its assigned sub-channel, without interfering with other nodes. The sub-channels can be based on time, frequency, or code. Examples of channelization protocols are TDMA, FDMA, and CDMA.

#### Random access protocols

Random access protocols are based on the principle of contention, where nodes compete for the channel access. The main advantage of random access protocols is that they are simple and do not require coordination among nodes. The main disadvantage is that they are prone to collisions and wastage of bandwidth. Some of the common random access protocols are :

- **ALOHA**: ALOHA is the simplest random access protocol, where nodes send data whenever they have it, without checking the channel state. If a node receives an acknowledgment from the receiver within a specified time, the transmission is successful. Otherwise, the node assumes a collision and retransmits the data after a random delay. ALOHA has two variants: pure ALOHA and slotted ALOHA. Pure ALOHA does not have any synchronization among nodes, while slotted ALOHA divides the time into equal slots and nodes can send data only at the beginning of a slot. Slotted ALOHA has better performance than pure ALOHA, as it reduces the collision probability.
- **CSMA (Carrier Sense Multiple Access)**: CSMA is an improvement over ALOHA, where nodes sense the channel state before sending data. If the channel is idle, the node transmits the data. If the channel is busy, the node defers the transmission until the channel becomes idle. However, CSMA cannot prevent collisions completely, as two or more nodes may sense the channel as idle at the same time and start transmitting simultaneously. CSMA has three variants: 1-persistent CSMA, non-persistent CSMA, and p-persistent CSMA. 1-persistent CSMA transmits data as soon as the channel is idle, non-persistent CSMA waits for a random time before sensing the channel again, and p-persistent CSMA transmits data with a probability p when the channel is idle.
- **CSMA/CD (Carrier Sense Multiple Access with Collision Detection)**: CSMA/CD is an extension of CSMA, where nodes detect the collisions while transmitting data. If a node detects a collision, it aborts the transmission and sends a jamming signal to inform other nodes about the collision. Then, the node waits for a random time before retransmitting the data. CSMA/CD is used in wired networks, such as Ethernet, where collision detection is feasible.
