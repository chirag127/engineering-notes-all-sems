### World Wide Web and Hyper Text Transfer Protocol

- The World Wide Web (WWW) is a system of interlinked hypertext documents that can be accessed via the Internet using a web browser.
- A hypertext document is a text file that contains links to other documents or resources, such as images, videos, or audio files.
- The links in a hypertext document are called hyperlinks, and they allow users to navigate from one document to another by clicking on them.
- The WWW was invented by Tim Berners-Lee and his team at CERN in 1989-1991, as a way to share information among researchers across the world.
- The WWW is based on three main technologies: Uniform Resource Locators (URLs), HyperText Markup Language (HTML), and HyperText Transfer Protocol (HTTP).
- A URL is a string of characters that identifies the location and name of a resource on the Internet, such as a webpage, an image, or a video.
- An example of a URL is https://www.khanacademy.org/computing/computers-and-internet/xcae6f4a7ff015e7d:the-internet/xcae6f4a7ff015e7d:web-protocols/a/the-world-wide-web, which is the URL of a webpage about the WWW on Khan Academy.
- HTML is a markup language that defines the structure and content of a webpage, using tags and attributes to specify elements such as headings, paragraphs, lists, tables, images, links, etc.
- An example of HTML code is `<p>This is a paragraph.</p>`, which creates a paragraph element with the text "This is a paragraph." on a webpage.
- HTTP is an application layer protocol that defines how web browsers and web servers communicate and exchange data over the Internet.
- HTTP uses a request-response model, where a web browser sends an HTTP request to a web server, and the web server responds with an HTTP response that contains the requested resource or an error message.
- An example of an HTTP request is `GET /computing/computers-and-internet/xcae6f4a7ff015e7d:the-internet/xcae6f4a7ff015e7d:web-protocols/a/the-world-wide-web HTTP/1.1`, which asks the web server to send the webpage with the URL https://www.khanacademy.org/computing/computers-and-internet/xcae6f4a7ff015e7d:the-internet/xcae6f4a7ff015e7d:web-protocols/a/the-world-wide-web.
- An example of an HTTP response is `HTTP/1.1 200 OK`, which indicates that the web server has successfully found and sent the requested webpage.
- HTTP is the foundation of the WWW, and is used to load webpages using hypertext links  .
- HTTP runs on top of other layers of the network protocol stack, such as the Transport Layer Security (TLS) protocol, which provides encryption and authentication for secure web communication  .
