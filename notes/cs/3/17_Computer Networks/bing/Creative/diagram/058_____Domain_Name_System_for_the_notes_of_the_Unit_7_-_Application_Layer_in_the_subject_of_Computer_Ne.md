### Domain Name System

- The Domain Name System (DNS) is a **hierarchical and decentralized naming system** for computers, servers, services, resources, network devices and components that are present on large networks such as the public Internet .
- DNS maps **alphabetic names** (also called domain names) to **numeric IP addresses** on the Internet, similar to how a phone book maps a person's name to a phone number .
- DNS allows humans to access information online through **easy-to-remember domain names**, like nytimes.com or espn.com, instead of typing long and complex IP addresses, like 151.101.65.164 or 151.101.193.86.
- DNS also enables web browsers to **interact with web servers** through Internet Protocol (IP) addresses. DNS translates domain names to IP addresses so browsers can load Internet resources.
- DNS is composed of several **components and processes**, such as domain name space, domain name syntax, name servers, address resolution mechanism, DNS resolvers, circular dependencies, glue records, record caching, reverse lookup and client lookup.
- DNS is an **essential component** of the functionality and performance of the Internet, as it provides a worldwide, distributed directory service.
