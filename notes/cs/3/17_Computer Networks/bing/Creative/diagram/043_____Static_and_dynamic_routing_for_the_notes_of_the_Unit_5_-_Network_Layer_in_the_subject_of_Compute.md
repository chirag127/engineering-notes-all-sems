### Static and dynamic routing

- Static routing and dynamic routing are two methods used to determine how to send a packet toward its destination.
- Static routes are configured in advance of any network communication.
- Dynamic routing requires routers to exchange information with other routers to learn about paths through the network.

#### Static routing

- Static routing used for small networks like having one or two routes.
- Static routing is often more efficient because a link is not being wasted by exchanging dynamic routing information.
- Static routing provides high or more security.
- Static routing is manual.
- Static routing requires less compute power and bandwidth, as it only has one preconfigured route.
- Static routing is often used as a complement to dynamic routing to provide a backup if a dynamic route is unavailable.

#### Dynamic routing

- Dynamic routing uses complex routing algorithms.
- Dynamic routing uses distance vector protocols, such as RIP and IGRP, and link state protocols, such as OSPF and IS-IS, to adjust routes.
- Dynamic routing provides less security.
- Dynamic routing is automated.
- Dynamic routing is implemented in large networks.
- Dynamic routing requires more compute power and bandwidth, as it has to exchange routing information with other routers.
- Dynamic routing is known as a technique of finding the best path for the data to travel over a network in this process a router can transmit data through various different routes and reach its destination on the basis of conditions at that time of communication circuits.
