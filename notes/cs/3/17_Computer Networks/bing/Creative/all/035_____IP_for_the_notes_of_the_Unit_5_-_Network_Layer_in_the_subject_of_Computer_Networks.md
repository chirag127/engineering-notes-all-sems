# IP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- The network layer is responsible for the delivery of packets across different networks using routers and switches.
- The network layer uses the Internet Protocol (IP) to assign unique addresses to each device on the network and to route packets based on these addresses.
- IP is a connectionless and unreliable protocol, meaning that it does not guarantee the delivery, order, or integrity of the packets. It relies on the transport layer protocols, such as TCP or UDP, to provide these services.
- IP has two versions: IPv4 and IPv6. IPv4 uses 32-bit addresses, which can support up to 4.3 billion devices. IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 devices.
- IP addresses are divided into network and host parts. The network part identifies the network to which the device belongs, and the host part identifies the device within the network. The network part can have different lengths depending on the class or the subnet of the address.
- IP addresses can be either static or dynamic. Static addresses are manually assigned and do not change. Dynamic addresses are automatically assigned by a server, such as DHCP, and can change over time.
- IP addresses can be either public or private. Public addresses are globally unique and can be accessed from the Internet. Private addresses are locally unique and can only be accessed within a network. Private addresses are reserved by the Internet Assigned Numbers Authority (IANA) and are not routable on the Internet.
- IP packets consist of a header and a payload. The header contains information such as the source and destination addresses, the protocol version, the length, the time to live (TTL), and the checksum. The payload contains the data to be transmitted.
- IP packets can be fragmented if they are larger than the maximum transmission unit (MTU) of the network. Fragmentation is the process of dividing a packet into smaller pieces, each with its own header. Fragmentation can occur at the source or at any intermediate router. Reassembly is the process of putting the pieces back together at the destination.
- IP packets can be routed using different algorithms, such as shortest path, flooding, distance vector, or link state. Routing algorithms determine the best path for a packet to reach its destination based on various criteria, such as distance, cost, or congestion. Routing algorithms can be either static or dynamic. Static algorithms use fixed tables that do not change. Dynamic algorithms use tables that are updated periodically or in response to network changes.
- IP packets can be forwarded using different techniques, such as store-and-forward, cut-through, or wormhole. Forwarding techniques determine how a router handles a packet when it arrives at its input port. Store-and-forward technique buffers the entire packet before sending it to the output port. Cut-through technique sends the packet to the output port as soon as the destination address is read. Wormhole technique sends the packet in small pieces without buffering.
