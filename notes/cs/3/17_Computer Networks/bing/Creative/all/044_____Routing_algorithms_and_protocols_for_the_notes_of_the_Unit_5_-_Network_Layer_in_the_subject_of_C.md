# Routing algorithms and protocols for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- Routing is the process of finding and selecting the best path for data transmission from source to destination in a computer network.
- Routing algorithms are the software programs that implement the logic of routing, i.e., deciding the optimal path for each packet.
- Routing protocols are the set of rules and procedures that govern the exchange of routing information and the operation of routing algorithms among routers.
- Routing algorithms and protocols can be classified into two main categories: static and dynamic.
  - Static routing algorithms and protocols use fixed and predefined routes that do not change unless manually configured by the network administrator. They are simple, fast, and secure, but they cannot adapt to network changes or failures, and they require manual intervention for updates.
  - Dynamic routing algorithms and protocols use various metrics and criteria to calculate and update the routes based on the current network conditions and topology. They are more complex, slower, and less secure, but they can adapt to network changes or failures, and they require less manual intervention for updates.
- Routing algorithms and protocols can also be classified based on the scope and scale of the network: intra-domain and inter-domain.
  - Intra-domain routing algorithms and protocols operate within a single autonomous system (AS), which is a group of routers under the same administrative control and policy. They are also called interior gateway protocols (IGPs). They aim to find the shortest or least-cost path within the AS.
  - Inter-domain routing algorithms and protocols operate between different autonomous systems, which are groups of routers under different administrative control and policy. They are also called exterior gateway protocols (EGPs). They aim to find the best path between the ASes based on various factors such as policy, performance, and reliability.
- Some of the common routing algorithms and protocols are :
  - Distance vector routing algorithm and protocol: It is a dynamic and intra-domain routing algorithm and protocol that uses the hop count (number of routers) as the metric to find the shortest path. It is based on the Bellman-Ford algorithm. It uses periodic updates of routing tables among neighboring routers. It is simple and easy to implement, but it suffers from slow convergence, routing loops, and count-to-infinity problems. An example of a distance vector routing protocol is the Routing Information Protocol (RIP).
  - Link state routing algorithm and protocol: It is a dynamic and intra-domain routing algorithm and protocol that uses the cost (a function of bandwidth, delay, reliability, etc.) as the metric to find the least-cost path. It is based on the Dijkstra's algorithm. It uses periodic or triggered updates of link state packets among all routers in the network. It is more complex and resource-intensive, but it has faster convergence, no routing loops, and no count-to-infinity problems. An example of a link state routing protocol is the Open Shortest Path First (OSPF) protocol.
  - Path vector routing algorithm and protocol: It is a dynamic and inter-domain routing algorithm and protocol that uses the AS path (a list of ASes traversed) as the metric to find the best path. It is based on the Bellman-Ford algorithm with path information. It uses periodic or triggered updates of path vector messages among neighboring routers. It is more scalable and flexible, but it requires more memory and processing power. An example of a path vector routing protocol is the Border Gateway Protocol (BGP).
