# Multiple Access Protocols in Computer Networks

Multiple access protocols are a set of protocols operating in the Medium Access Control sublayer (MAC sublayer) of the Open Systems Interconnection (OSI) model. These protocols allow a number of nodes or users to access a shared network channel. The main objectives of multiple access protocols are to avoid collisions, minimize delays, and maximize throughput.

There are three main categories of multiple access protocols:

- **Channel partitioning protocols**: These protocols divide the channel into smaller pieces, such as time slots, frequency bands, or codes, and assign each piece to a different node or user. Examples of channel partitioning protocols are Time Division Multiple Access (TDMA), Frequency Division Multiple Access (FDMA), and Code Division Multiple Access (CDMA).
- **Random access protocols**: These protocols allow nodes or users to transmit data whenever they have data to send, without any reservation or coordination. However, there is a possibility of collisions, which occur when two or more nodes or users transmit data at the same time on the same channel. Examples of random access protocols are ALOHA, Carrier Sense Multiple Access (CSMA), CSMA with Collision Detection (CSMA/CD), and CSMA with Collision Avoidance (CSMA/CA).
- **Taking-turns protocols**: These protocols allow nodes or users to take turns in accessing the channel, either by using a central controller or by passing a token among themselves. Examples of taking-turns protocols are Polling, Token Ring, and Token Bus.

Some of the important features and characteristics of these protocols are:

- **ALOHA**: ALOHA is a simple random access protocol that does not require any carrier sensing or collision detection. A node or user transmits data whenever it has data to send, and waits for an acknowledgment from the receiver. If no acknowledgment is received within a certain time, the node or user assumes that a collision has occurred and retransmits the data after a random delay. ALOHA has two variants: pure ALOHA and slotted ALOHA. Pure ALOHA does not have any synchronization among the nodes or users, while slotted ALOHA divides the time into equal slots and requires the nodes or users to transmit data only at the beginning of each slot. Slotted ALOHA has a higher throughput than pure ALOHA, but both have low efficiency and high delay.
- **CSMA**: CSMA is a random access protocol that requires the nodes or users to sense the channel before transmitting data. If the channel is idle, the node or user can transmit data. If the channel is busy, the node or user can either wait until the channel becomes idle (persistent CSMA) or defer the transmission for a random time (non-persistent CSMA). CSMA reduces the probability of collisions, but does not eliminate them completely. CSMA also has a problem of hidden terminals, which occur when two nodes or users are hidden from each other by an intermediate node or user, and cannot sense each other's transmissions.
- **CSMA/CD**: CSMA/CD is a random access protocol that requires the nodes or users to sense the channel before transmitting data, and also to detect collisions during the transmission. If a collision is detected, the node or user aborts the transmission and sends a jamming signal to inform the other nodes or users of the collision. The node or user then waits for a random time before retransmitting the data. CSMA/CD is used in Ethernet networks, and can achieve a high throughput and low delay in low-load conditions. However, CSMA/CD has a problem of exposed terminals, which occur when a node or user can sense the transmission of another node or user, but is not involved in the collision, and thus wastes its transmission opportunity.
