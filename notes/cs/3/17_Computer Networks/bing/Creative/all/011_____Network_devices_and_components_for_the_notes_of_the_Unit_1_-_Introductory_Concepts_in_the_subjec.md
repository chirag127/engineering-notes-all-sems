# Network devices and components

Network devices and components are the hardware and software elements that enable communication and data exchange between different devices on a network. They can be classified into different types and functions depending on their role and location in the network.

Some of the basic network devices and components are:

- **Sender and receiver**: These are the end points of a network communication, such as computers, printers, scanners, etc. They send and receive data packets using network interface cards (NICs) and network media.
- **Network interface card (NIC)**: This is a device that connects a sender or receiver to the network media, such as a cable or a wireless signal. It provides a unique address (MAC address) for each device and converts data into electrical signals or radio waves.
- **Network media**: This is the physical or wireless medium that carries the data signals between devices. Examples of network media are twisted pair cables, coaxial cables, fiber optic cables, radio waves, infrared waves, etc.
- **Connectors**: These are the devices that attach the network media to the NICs or other network devices. They ensure a secure and reliable connection and prevent signal loss or interference. Examples of connectors are RJ45, BNC, ST, SC, etc.
- **Switch**: This is a device that connects multiple devices on a network and forwards data packets to the intended destination based on the MAC address. It creates a separate collision domain for each port and reduces network congestion and collisions.
- **Router**: This is a device that connects multiple networks and forwards data packets to the best route based on the IP address. It creates a separate broadcast domain for each interface and filters network traffic based on routing protocols and policies.
- **Hub**: This is a device that connects multiple devices on a network and broadcasts data packets to all connected devices. It does not filter or forward data packets based on the address and creates a single collision and broadcast domain for the entire network.
- **Repeater**: This is a device that amplifies and regenerates the data signals on a network media. It extends the range and reach of a network and prevents signal attenuation and degradation.
- **Gateway**: This is a device that connects networks that use different protocols or architectures. It translates and converts data packets between different formats and enables communication between incompatible networks.
- **Bridge**: This is a device that connects two or more segments of a network and filters data packets based on the MAC address. It divides a network into smaller segments and reduces network congestion and collisions.
- **Brouter**: This is a device that combines the functions of a bridge and a router. It can filter and forward data packets based on the MAC address or the IP address depending on the network layer.
