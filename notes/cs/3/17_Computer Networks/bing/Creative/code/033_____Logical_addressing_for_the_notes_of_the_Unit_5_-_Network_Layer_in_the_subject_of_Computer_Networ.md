### Logical addressing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- Logical addressing is the scheme of assigning addresses to the devices in a network that are used by the network layer protocols, such as IP.
- Logical addresses are also called global addresses or network addresses, as they are unique and universal across the internet.
- Logical addresses are software-based and can be changed or modified by the network administrator or the operating system.
- Logical addresses are independent of the physical addresses, which are hardware-based and fixed by the manufacturer of the network interface card (NIC).
- Logical addresses are used to identify the source and destination of the packets in a network, and to route them through intermediate devices, such as routers.
- Logical addresses are usually represented in a human-readable format, such as dotted decimal notation for IPv4 or hexadecimal notation for IPv6.
- Logical addresses consist of two parts: network ID and host ID. The network ID identifies the network to which the device belongs, and the host ID identifies the device within the network.
- Logical addresses are hierarchical, meaning that they can be divided into subnets and sub-subnets to create a logical structure of the network.
- Logical addresses are assigned by the Internet Assigned Numbers Authority (IANA) and its regional registries, such as ARIN, RIPE, APNIC, etc.
- Logical addresses are subject to network address translation (NAT), which is a technique of mapping one set of logical addresses to another set of logical addresses, usually to conserve the public IP address space or to provide security.
