## Unit 1 - Introductory Concepts

- This unit covers some basic concepts and terms related to computer science and programming.
- Some of the topics included in this unit are:
  - What is a computer and how does it work?
  - What is an algorithm and how to design one?
  - What is a programming language and how to choose one?
  - What are the steps of software development and how to apply them?
  - What are some common tools and techniques for debugging and testing programs?
- The learning objectives of this unit are:
  - To understand the basic components and functions of a computer system.
  - To define and identify algorithms and their properties.
  - To compare and contrast different types of programming languages and paradigms.
  - To describe and follow the software development life cycle and its phases.
  - To use appropriate tools and methods for debugging and testing programs.
- The assessment criteria of this unit are:
  - To demonstrate the ability to explain the concepts and terms related to computer science and programming using examples and diagrams.
  - To demonstrate the ability to design and implement simple algorithms using pseudocode or flowcharts.
  - To demonstrate the ability to select and use suitable programming languages and paradigms for different tasks and problems.
  - To demonstrate the ability to apply the software development life cycle and its phases to a given project or scenario.
  - To demonstrate the ability to debug and test programs using various tools and techniques.
