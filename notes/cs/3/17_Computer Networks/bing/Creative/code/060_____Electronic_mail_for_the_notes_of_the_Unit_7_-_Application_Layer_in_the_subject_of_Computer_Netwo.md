# Electronic Mail

Electronic mail (e-mail) is a computer-based application for the exchange of messages between users. A worldwide e-mail network allows people to exchange e-mail messages very quickly. E-mail is the electronic equivalent of a letter, but with advantages in timeliness and flexibility.

Some basic concepts of e-mail are:

- An e-mail address: This is a unique identifier for each user, typically in the format of name@domain.com. The name part is the user name and the domain part is the name of the organization or service provider that hosts the user's mailbox. For example, alice@gmail.com is an e-mail address of a user named Alice who uses Gmail as her e-mail service provider.
- An e-mail message: This is the content of the communication between the sender and the receiver. It consists of two parts: a header and a body. The header contains information such as the sender's and receiver's e-mail addresses, the subject, the date and time, and other optional fields. The body contains the actual text or data of the message, which can be plain text, formatted text, images, attachments, or other types of media.
- An e-mail client: This is a software application that allows the user to compose, send, receive, and manage e-mail messages. It can be a web-based application (such as Gmail or Yahoo Mail) that runs on a browser, or a desktop application (such as Outlook or Thunderbird) that runs on a local computer. An e-mail client communicates with an e-mail server to send and receive e-mail messages.
- An e-mail server: This is a computer system that stores and delivers e-mail messages for the users. It can be a single server or a cluster of servers that provide e-mail services for a domain or a network. An e-mail server runs one or more protocols to handle the e-mail transactions, such as SMTP, POP3, IMAP, or HTTP.

The process of sending and receiving an e-mail message involves the following steps:

- The sender composes an e-mail message using an e-mail client and specifies the receiver's e-mail address.
- The e-mail client sends the message to the sender's e-mail server using the SMTP protocol.
- The sender's e-mail server looks up the domain name of the receiver's e-mail address and finds the IP address of the receiver's e-mail server using the DNS service.
- The sender's e-mail server connects to the receiver's e-mail server using the SMTP protocol and transfers the message.
- The receiver's e-mail server stores the message in the receiver's mailbox.
- The receiver checks the mailbox using an e-mail client and downloads the message using the POP3 or IMAP protocol, or views the message using the HTTP protocol.
- The receiver reads the message and optionally replies to the sender using the same steps.
