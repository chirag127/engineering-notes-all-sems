### IP

- IP stands for Internet Protocol. It is the network layer protocol in the Internet protocol suite for relaying datagrams across network boundaries.
- IP is responsible for routing packets of data from one device to another across a network. It uses logical addresses, called IP addresses, to identify and locate devices on the network.
- IP is an encapsulating protocol, which means it adds a header to the data before sending it. The header contains information such as the source and destination IP addresses, the length of the data, and a checksum to verify the integrity of the data.
- IP is a connectionless and unreliable protocol, which means it does not establish a connection or guarantee the delivery of the data. It relies on other protocols, such as TCP, to provide reliability and error control.
- IP supports two versions: IPv4 and IPv6. IPv4 uses 32-bit addresses, which can support up to 4.3 billion devices on the network. IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 devices on the network. IPv6 also has some other features, such as improved security, simplified header format, and enhanced multicast and mobility support.
