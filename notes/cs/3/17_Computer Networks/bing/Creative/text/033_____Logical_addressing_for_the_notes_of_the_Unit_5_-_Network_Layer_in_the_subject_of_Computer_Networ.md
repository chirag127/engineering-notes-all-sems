### Logical addressing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- Logical addressing is the scheme of assigning addresses to the devices or hosts in a network that communicate using the internet protocol (IP) .
- Logical addresses are also known as IP addresses, which are software-based and can be changed or modified by the network administrator .
- Logical addresses are different from physical addresses, which are hardware-based and unique to each device or host .
- Logical addresses are used to identify the source and destination of the packets in the network layer, while physical addresses are used to identify the source and destination of the frames in the data link layer .
- Logical addresses are composed of two parts: network ID and host ID. The network ID identifies the network to which the host belongs, and the host ID identifies the host within the network .
- Logical addresses can be classified into two types: IPv4 and IPv6. IPv4 addresses are 32 bits long and use dotted decimal notation, while IPv6 addresses are 128 bits long and use hexadecimal notation .
- Logical addresses can be further divided into classes, subnets, and supernet based on the number of bits allocated for the network ID and the host ID .
- Logical addressing enables the communication between different networks and hosts across the internet, and also supports the routing of packets based on the network ID .
