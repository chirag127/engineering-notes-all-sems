### Services for the notes of the Unit 1 - Introductory Concepts in the subject of Computer Networks

- A service is a set of functions or capabilities that a network provides to the applications or users that use it.
- A service can be classified as either connection-oriented or connectionless, depending on whether it requires a connection establishment phase before data transmission or not.
- A service can also be classified as either reliable or unreliable, depending on whether it guarantees the delivery of data packets or not.
- Some examples of services are:
  - File Transfer Protocol (FTP): a connection-oriented and reliable service that allows users to transfer files between hosts over a network.
  - Hypertext Transfer Protocol (HTTP): a connectionless and unreliable service that allows users to access web pages and other resources over a network.
  - Domain Name System (DNS): a connectionless and unreliable service that allows users to map host names to IP addresses over a network.
  - Simple Mail Transfer Protocol (SMTP): a connection-oriented and reliable service that allows users to send and receive emails over a network.
- Services are provided by the network layer and the transport layer of the network architecture.
- The network layer is responsible for routing packets from the source host to the destination host across multiple networks.
- The transport layer is responsible for providing end-to-end communication between the source and destination applications.
- The network layer and the transport layer use protocols to implement the services they provide.
- A protocol is a set of rules and formats that govern the communication between entities in a network.
- Some examples of protocols are:
  - Internet Protocol (IP): a network layer protocol that provides connectionless and unreliable service for packet delivery across networks.
  - Transmission Control Protocol (TCP): a transport layer protocol that provides connection-oriented and reliable service for data transmission between applications.
  - User Datagram Protocol (UDP): a transport layer protocol that provides connectionless and unreliable service for data transmission between applications.
- Protocols are organized into layers according to the network architecture.
- The network architecture is a conceptual model that defines the structure, functions, and interfaces of the network components.
- The most common network architecture is the TCP/IP model, which consists of four layers: application, transport, network, and link.
- The application layer contains the protocols and services that support the user applications, such as FTP, HTTP, DNS, and SMTP.
- The transport layer contains the protocols and services that provide end-to-end communication, such as TCP and UDP.
- The network layer contains the protocols and services that provide packet delivery across networks, such as IP.
- The link layer contains the protocols and services that provide data transmission over a single link, such as Ethernet and Wi-Fi.
