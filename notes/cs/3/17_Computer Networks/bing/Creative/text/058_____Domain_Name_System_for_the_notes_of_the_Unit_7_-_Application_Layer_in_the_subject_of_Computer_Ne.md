### Domain Name System

- The Domain Name System (DNS) is a method for mapping alphabetic names to numeric IP addresses on the Internet, similar to how a phone book maps a person's name to a phone number.
- DNS is a hierarchical and decentralized naming system that allows computers, servers, services, resources, network devices and components to be identified and located on large networks such as the public Internet.
- A network domain is an administrative grouping of multiple private computer networks or local hosts within the same infrastructure. Domains can be identified using a domain name; domains which need to be accessible from the public Internet can be assigned a globally unique name within the Domain Name System (DNS).
- A DNS query is made when a web address (URL) is typed into a browser to obtain the IP address of a web server associated with that name.
- DNS consists of four main components: domain name space, name servers, resolvers and records.
- Domain name space is the structure of the DNS, which is divided into zones. Each zone corresponds to a domain or a subdomain. The root zone is the top-level zone that contains all other zones. The root zone is managed by the Internet Corporation for Assigned Names and Numbers (ICANN).
- Domain name syntax is the set of rules that define how domain names are formed and written. Domain names consist of labels separated by dots. Each label can have up to 63 characters. The rightmost label is the top-level domain (TLD), such as .com, .org, .net, etc. The second-level domain (SLD) is the name of the organization or entity that owns the domain, such as google, amazon, wikipedia, etc. The third-level domain (TLD) and lower-level domains are optional and can be used for subdomains, such as mail.google.com, aws.amazon.com, en.wikipedia.org, etc.
- Domain name internationalization is the process of allowing domain names to use characters from different languages and scripts, such as Chinese, Arabic, Cyrillic, etc. This is achieved by using the Internationalized Domain Name (IDN) system, which encodes non-ASCII characters into ASCII-compatible strings using the Punycode algorithm.
- Name servers are the servers that store and provide information about the domain name space. They are responsible for answering DNS queries and resolving domain names to IP addresses. There are two types of name servers: authoritative and recursive.
- Authoritative name server is the name server that has the definitive and up-to-date information about a domain or a zone. It is the ultimate source of truth for the domain name space. There are two types of authoritative name servers: primary and secondary. Primary name server is the name server that has the original copy of the zone data, which is usually stored in a zone file. Secondary name server is the name server that obtains the zone data from the primary name server through a process called zone transfer.
- Recursive and caching name server is the name server that acts as an intermediary between the client and the authoritative name server. It receives DNS queries from the client and tries to resolve them by contacting the authoritative name server or using its own cache. If the query is resolved, it returns the answer to the client and stores it in its cache for future use. If the query is not resolved, it returns an error or a referral to the client.
- DNS resolvers are the clients that initiate DNS queries and communicate with the name servers. They are usually implemented as software libraries or applications that run on the end-user devices, such as web browsers, email clients, etc. They are responsible for converting domain names to IP addresses and vice versa.
- Circular dependencies and glue records are the situations where the name server for a domain or a zone depends on the name server for another domain or a zone, creating a loop. For example, if the name server for example.com is ns1.example.net, and the name server for example.net is ns2.example.com, then there is a circular dependency between the two domains. To resolve this, glue records are used, which are special records that provide the IP address of the name server along with its domain name, breaking the loop.
- Record caching is the process of storing the results of DNS queries in the memory of the name servers or the resolvers for a certain period of time, called the time to live (TTL). This reduces the number of DNS queries and improves the performance and efficiency of the DNS system
