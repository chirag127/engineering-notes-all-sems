### Data compression

Data compression is the process of reducing the amount of data needed for the storage or transmission of a given piece of information, typically by the use of encoding techniques. Data compression can improve the performance and efficiency of computer networks by reducing the bandwidth, latency, and cost of data transmission and storage.

There are two main types of data compression techniques: lossless and lossy. Lossless compression techniques preserve the exact information of the original data, while lossy compression techniques discard some information of the original data, usually in a way that is imperceptible or acceptable to the human perception.

Some of the common data compression techniques are:

- **Run length encoding (RLE)**: This technique replaces consecutive identical symbols or bytes with a single symbol or byte followed by the number of repetitions. For example, the string "AAAAABBBBCCCC" can be compressed as "A5B4C4". This technique is useful for data sets containing large amounts of redundant information, such as graphics and video data.
- **Differential pulse code modulation (DPCM)**: This technique encodes the difference between successive samples of a signal, rather than the absolute value of each sample. This reduces the number of bits needed to represent each sample, as the difference is usually smaller than the original value. For example, the sequence "10, 12, 15, 18, 20" can be compressed as "10, 2, 3, 3, 2". This technique is useful for data sets that have a high correlation between adjacent samples, such as audio and image data.
- **Dictionary based encoding**: This technique uses a predefined dictionary of symbols or strings to encode the data. The dictionary can be fixed or adaptive, depending on whether it is predefined or updated during the compression process. For example, the string "the cat sat on the mat" can be compressed using a fixed dictionary as "1 2 3 4 1 5", where the numbers represent the corresponding words in the dictionary. This technique is useful for data sets that have a high frequency of recurring symbols or strings, such as text and DNA data.
- **Huffman coding**: This technique assigns variable-length codes to the symbols or bytes of the data, based on their frequency of occurrence. The most frequent symbols or bytes are assigned the shortest codes, while the least frequent ones are assigned the longest codes. For example, the string "ABRACADABRA" can be compressed using Huffman coding as "01101110100010101101110", where A is encoded as 0, B as 10, R as 110, C as 1110, and D as 1111. This technique is useful for data sets that have a skewed distribution of symbols or bytes, such as text and image data.
- **Lempel-Ziv (LZ) coding**: This technique builds a dynamic dictionary of symbols or strings during the compression process, based on the previous data that has been encoded. The dictionary is then used to encode the subsequent data by replacing the symbols or strings with their corresponding dictionary entries. For example, the string "ABABABABABAB" can be compressed using LZ coding as "AB(1)(1)(1)(1)(1)", where 1 represents the previous two symbols. This technique is useful for data sets that have a high degree of repetition or regularity, such as text and image data.
