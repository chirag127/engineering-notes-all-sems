## Unit 6 - Transport Layer

The transport layer is the fourth layer of the OSI model. It is responsible for providing end-to-end communication services between applications running on different hosts. Some of the main functions of the transport layer are:

- **Segmentation and reassembly**: The transport layer divides the data received from the application layer into smaller units called segments, and adds a header to each segment. The header contains information such as source and destination port numbers, sequence and acknowledgment numbers, and checksum. The segments are then sent to the network layer for transmission. At the destination, the transport layer reassembles the segments into the original data and delivers it to the application layer.
- **Connection-oriented and connectionless communication**: The transport layer can provide either connection-oriented or connectionless communication services to the application layer. Connection-oriented communication involves establishing, maintaining, and terminating a logical connection between the source and destination hosts. Connectionless communication does not require a connection setup or teardown, and each segment is treated independently. TCP (Transmission Control Protocol) is an example of a connection-oriented transport protocol, while UDP (User Datagram Protocol) is an example of a connectionless transport protocol.
- **Reliable and unreliable delivery**: The transport layer can provide either reliable or unreliable delivery of data to the application layer. Reliable delivery means that the transport layer ensures that all the segments sent by the source are received by the destination in the correct order and without any errors or losses. Unreliable delivery means that the transport layer does not guarantee the delivery of segments, and some segments may be lost, duplicated, corrupted, or delivered out of order. TCP provides reliable delivery, while UDP provides unreliable delivery.
- **Flow control**: The transport layer can provide flow control to prevent the sender from overwhelming the receiver with too many segments. Flow control regulates the rate of data transmission based on the feedback from the receiver. TCP uses a sliding window mechanism to implement flow control, while UDP does not provide any flow control.
- **Congestion control**: The transport layer can provide congestion control to avoid or reduce network congestion. Network congestion occurs when the demand for network resources exceeds the available capacity. Congestion control aims to adjust the rate of data transmission based on the network conditions and the feedback from the routers. TCP uses various algorithms to implement congestion control, such as slow start, congestion avoidance, fast retransmit, and fast recovery. UDP does not provide any congestion control.
- **Error detection and correction**: The transport layer can provide error detection and correction to ensure the integrity of the data. Error detection involves checking the segments for any errors or corruption using the checksum field in the header. Error correction involves retransmitting the segments that are detected as erroneous or lost using the sequence and acknowledgment numbers in the header. TCP provides error detection and correction, while UDP does not provide any error correction.
