### Basic internetworking for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- The network layer is the part of the Internet communications process where packets of data are sent back and forth between different networks.
- The network layer is also called the Internet layer in the TCP/IP model, which is the most widely used model for Internet protocols.
- The network layer is responsible for routing, addressing, fragmentation, and reassembly of packets across multiple networks.
- An internetwork is an interconnected collection of physical networks that form a logical network.
- An internetwork can be composed of different types of networks, such as LANs, WANs, MANs, etc.
- An internetwork requires devices that can connect different networks, such as routers, gateways, bridges, etc.
- An internetwork also requires protocols that can handle the communication between different networks, such as IP, ICMP, ARP, etc.
- An internetwork can have different variants, depending on who administers and who participates in them, such as intranet, extranet, and Internet.
- The Internet is the most notable example of an internetwork, which connects millions of networks and devices worldwide.
- The network layer uses different types of addresses to identify the source and destination of packets, such as data-link layer addresses, MAC addresses, and network-layer addresses.
- Data-link layer addresses are used to identify each physical network connection of a network device, such as Ethernet addresses.
- MAC addresses are a type of data-link layer addresses that are assigned by the manufacturer of the network device and are usually fixed.
- Network-layer addresses are used to identify each logical network connection of a network device, such as IP addresses.
- Network-layer addresses are assigned by the network administrator or the network service provider and can be changed.
- The network layer uses a process called address resolution to map network-layer addresses to data-link layer addresses, such as ARP.
- The network layer also uses a process called address translation to map network-layer addresses to different network-layer addresses, such as NAT.
