### IP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- IP stands for Internet Protocol, which is the network layer communications protocol in the Internet protocol suite for relaying datagrams across network boundaries.
- IP is responsible for routing, addressing, fragmentation, and reassembly of packets in the network.
- IP operates on the logical address of the hosts, which is called the IP address. An IP address is a 32-bit or 128-bit binary number that uniquely identifies a host in the network .
- IP addresses are divided into two parts: network prefix and host suffix. The network prefix identifies the network to which the host belongs, and the host suffix identifies the host within the network.
- IP addresses are classified into five classes: A, B, C, D, and E, based on the length and value of the network prefix. Class A, B, and C are used for unicast communication, Class D is used for multicast communication, and Class E is reserved for future use.
- IP also supports special addresses, such as loopback address, broadcast address, anycast address, and multicast address, for different purposes.
- IP uses a hierarchical routing scheme, where routers forward packets based on the network prefix of the destination IP address. Routers maintain routing tables that store the next hop information for each network prefix.
- IP allows packets to be fragmented and reassembled when they encounter a network with a smaller maximum transmission unit (MTU) than the original packet size. IP assigns a unique identification number, a fragment offset, and a flag to each fragment to facilitate the reassembly process at the destination.
- IP provides a best-effort delivery service, which means that it does not guarantee the reliability, order, or integrity of the packets. IP relies on the higher layer protocols, such as TCP, to provide these features.
- IP is the foundation of the Internet, and it enables internetworking, which is the interconnection of different types of networks using a common protocol.
