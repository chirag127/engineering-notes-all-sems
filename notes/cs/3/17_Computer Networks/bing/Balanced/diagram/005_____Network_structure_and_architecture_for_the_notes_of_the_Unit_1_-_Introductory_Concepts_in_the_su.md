### Network structure and architecture

- Network structure and architecture refers to the way network devices and services are structured to serve the connectivity needs of client devices .
- Network devices typically include switches, routers, hubs, bridges, gateways, firewalls, etc.
- Network services typically include DHCP, DNS, FTP, HTTP, SMTP, etc.
- Network structure and architecture also describes how the network devices are connected and the rules that govern data transfer between them .
- The medium of data transmission, such as wired or wireless, also constitutes the network architecture.
- There are many ways to approach network architecture design, which depend on the purpose and size of the network.
- The main types of network architecture are peer-to-peer (P2P) and client/server.
- In a peer-to-peer network, each device can act as both a client and a server, and there is no central authority or server.
- In a client/server network, there is a dedicated server that provides services to multiple clients, and the clients rely on the server for resources and data.
- A network can also be classified based on its geographic scope, such as local area network (LAN), metropolitan area network (MAN), wide area network (WAN), or personal area network (PAN).
- A network can also be classified based on its topology, which is the physical or logical arrangement of the network devices and links, such as bus, ring, star, mesh, tree, or hybrid.
- A network can also be classified based on its communication protocol, which is the set of rules and standards that define how the network devices communicate and exchange data, such as TCP/IP, Ethernet, Wi-Fi, Bluetooth, etc..
