### Routing
- Routing is the process of delivering packets from one network to another by choosing an optimal path  .
- Routing takes place at the network layer (layer 3) of the Open Systems Interconnection (OSI) reference model .
- Routing is performed by a special device known as a router  .
- A router is a networking device that forwards packets based on the information available in the packet header and forwarding table .
- A router connects to two or more IP networks or subnetworks and passes data packets between them as needed.
- Routing is essential for establishing communication between different networks and ensuring reliable and efficient data transmission .

### Types of Routing
- There are three main types of routing: static routing, dynamic routing, and default routing.
- Static routing: Static routing is a process in which we have to manually add routes to the routing table. Static routing is simple, secure, and resource-efficient, but it is not scalable, adaptable, or fault-tolerant.
- Dynamic routing: Dynamic routing is a process in which routers exchange information about the network topology and update their routing tables automatically. Dynamic routing is scalable, adaptable, and fault-tolerant, but it is complex, insecure, and resource-intensive.
- Default routing: Default routing is a process in which a router forwards all packets that do not match any specific route to a default gateway. Default routing is useful for connecting to the internet or other networks, but it is not optimal for internal routing.
