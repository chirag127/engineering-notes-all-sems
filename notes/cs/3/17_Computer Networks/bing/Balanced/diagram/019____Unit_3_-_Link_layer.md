## Unit 3 - Link layer

The link layer is the lowest layer of the TCP/IP model. It is responsible for sending and receiving data frames between nodes on the same network segment. The link layer also provides error detection, flow control, and medium access control.

Some of the main topics covered in this unit are:

- **Data link layer protocols**: These are the rules and formats that define how data frames are structured, addressed, and transmitted on a network segment. Some examples of data link layer protocols are Ethernet, Wi-Fi, PPP, and HDLC.
- **Error detection and correction**: These are the techniques that allow the link layer to detect and correct errors that may occur during data transmission. Some examples of error detection and correction methods are parity bits, checksums, cyclic redundancy checks (CRCs), and forward error correction (FEC).
- **Flow control**: This is the mechanism that regulates the rate of data transmission between two nodes to avoid congestion and data loss. Some examples of flow control methods are stop-and-wait, sliding window, and backpressure.
- **Medium access control (MAC)**: This is the sublayer of the link layer that coordinates the access of multiple nodes to a shared medium, such as a cable or a wireless channel. Some examples of medium access control protocols are CSMA/CD, CSMA/CA, token ring, and TDMA.
- **Switching and bridging**: These are the devices and techniques that connect multiple network segments and forward data frames based on their MAC addresses. Some examples of switching and bridging devices are hubs, switches, bridges, and repeaters.
