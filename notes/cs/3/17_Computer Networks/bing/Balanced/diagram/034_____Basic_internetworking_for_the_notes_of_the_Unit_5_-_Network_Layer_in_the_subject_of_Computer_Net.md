### Basic internetworking for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- The network layer is the part of the Internet communications process where these connections occur, by sending packets of data back and forth between different networks.
- The network layer roughly corresponds to the Internet layer in the TCP/IP model, which is the most widely used model for Internet protocols.
- The network layer is responsible for routing, addressing, fragmentation, reassembly, congestion control, and error detection and correction.
- An internetwork is an interconnected collection of physical networks, which can be of different types and technologies.
- An internet is a logical network built out of an internetwork, using a common set of protocols and addressing schemes.
- The most notable example of an internetwork and an internet is the Internet (capitalized), which connects millions of networks and devices worldwide.
- Internetworking requires devices that can interconnect different networks, such as routers, switches, gateways, and bridges.
- Internetworking also requires protocols that can operate across different networks, such as IP, ICMP, ARP, and RARP.
- Internetworking addresses are used to uniquely identify each network device and each network connection in an internetwork.
- There are three kinds of internetwork addresses that are commonly used: data-link layer addresses, media access control (MAC) addresses, and network-layer addresses.
- Data-link layer addresses are assigned by the network interface card (NIC) manufacturer and are usually fixed.
- MAC addresses are a type of data-link layer addresses that are used in Ethernet and other IEEE 802 networks.
- Network-layer addresses are assigned by the network administrator or the Internet service provider (ISP) and are usually configurable.
- IP addresses are a type of network-layer addresses that are used in the Internet and other IP-based networks.
- Internetworking addresses are mapped to each other using various protocols, such as ARP, which maps IP addresses to MAC addresses, and DNS, which maps domain names to IP addresses.
