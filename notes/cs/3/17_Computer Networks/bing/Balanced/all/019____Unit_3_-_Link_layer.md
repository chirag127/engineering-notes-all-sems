## Unit 3 - Link layer

The link layer is the lowest layer in the TCP/IP model. It is responsible for sending and receiving frames between nodes on the same physical medium, such as a cable or a wireless network. The link layer also provides error detection and correction, flow control, and medium access control.

Some of the main topics covered in this unit are:

- **Framing**: The process of dividing a stream of bits into frames, which are units of data that can be transmitted and received by the link layer. Framing involves adding headers and trailers to the data, which contain information such as source and destination addresses, frame type, and error detection codes.
- **Error detection and correction**: The techniques used by the link layer to detect and correct errors that may occur during transmission, such as bit flips, burst errors, or lost frames. Error detection involves adding redundant bits to the frames, such as parity bits, checksums, or cyclic redundancy checks (CRCs), which can be used to verify the integrity of the data. Error correction involves adding extra bits to the frames, such as forward error correction (FEC) codes, which can be used to recover the original data from the corrupted frames.
- **Flow control**: The mechanism used by the link layer to regulate the rate of data transmission between the sender and the receiver, to avoid congestion and buffer overflow. Flow control can be implemented using feedback-based or rate-based schemes. Feedback-based schemes involve sending acknowledgments or requests from the receiver to the sender, such as stop-and-wait, go-back-N, or selective repeat. Rate-based schemes involve sending signals from the sender to the receiver, such as sliding window or leaky bucket.
- **Medium access control (MAC)**: The protocol used by the link layer to coordinate the access of multiple nodes to a shared medium, such as a bus, a ring, or a wireless channel. MAC protocols can be classified into two categories: contention-based or reservation-based. Contention-based protocols involve competing for the medium, such as ALOHA, CSMA, or CSMA/CD. Reservation-based protocols involve reserving the medium, such as TDMA, FDMA, or CDMA.
