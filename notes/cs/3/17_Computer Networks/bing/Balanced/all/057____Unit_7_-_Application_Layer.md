# Unit 7 - Application Layer

The application layer is the topmost layer of the TCP/IP and OSI models that provides the interface and protocols for communication between applications over a network. The application layer contains several protocols that enable different types of services and functionalities, such as file transfer, email, web browsing, remote access, and network management. Some of the common application layer protocols are:

- **TELNET**: Telnet stands for the TELetype NETwork. It helps in terminal emulation. It allows Telnet clients to access and execute commands on remote Telnet servers using a virtual terminal interface. Telnet uses port 23 and operates on a client-server model. Telnet is not secure as it sends data in plain text.   
- **FTP**: FTP stands for file transfer protocol. It is the protocol that actually lets us transfer files. It can transfer files between two computers on a network. FTP uses port 21 for control connection and port 20 for data connection. FTP operates on a client-server model and uses TCP for reliable data transfer. FTP supports authentication, directory listing, and file manipulation.    
- **TFTP**: The Trivial File Transfer Protocol is abbreviated as TFTP. It is a simplified version of FTP that does not require authentication or directory listing. It is used for transferring small files such as boot images or configuration files. TFTP uses port 69 and operates on a client-server model. TFTP uses UDP for data transfer and implements its own reliability mechanism.   
- **HTTP**: HTTP stands for hypertext transfer protocol. It is the protocol that enables the communication between web browsers and web servers. HTTP uses port 80 and operates on a client-server model. HTTP uses TCP for reliable data transfer. HTTP supports various methods such as GET, POST, PUT, DELETE, etc. to request and send data. HTTP is stateless, meaning it does not keep track of the previous requests or responses.    
- **HTTPS**: HTTPS stands for hypertext transfer protocol secure. It is the secure version of HTTP that encrypts the data using SSL or TLS protocols. HTTPS uses port 443 and operates on a client-server model. HTTPS uses TCP for reliable data transfer. HTTPS provides confidentiality, integrity, and authentication for the communication between web browsers and web servers.    
- **DNS**: DNS stands for domain name system. It is the protocol that maps the human-readable domain names to the numerical IP addresses. DNS uses port 53 and operates on a distributed database model. DNS uses both TCP and UDP for data transfer. TCP is used for zone transfers and UDP is used for queries. DNS supports various types of records such as A, AAAA, CNAME, MX, NS, PTR, etc. to store different types of information.    
- **SMTP**: SMTP stands for simple mail transfer protocol. It is the protocol that enables the sending and receiving of email messages. SMTP uses port 25 and operates on a client-server model. SMTP uses TCP for reliable data transfer. SMTP supports various commands such as HELO, MAIL, RCPT, DATA, QUIT, etc. to establish and terminate a mail session. SMTP is used to send mail from the sender to the recipient's mail server.    
- **POP3**: POP3 stands for post office protocol version 3. It is the protocol that enables the downloading of email messages from the mail server to the mail client. POP3 uses port 110 and operates on a client-server model. POP3 uses TCP for reliable data transfer. POP3 supports various commands such as USER, PASS, LIST, RETR, DELE, QUIT, etc. to authenticate and manipulate the mail messages. POP3 is used to retrieve mail from the mail server to the mail client.    
- **IMAP**: IMAP stands for internet message access protocol. It is the protocol that enables the accessing and managing of email messages on the mail server. IMAP uses port 143 and operates on a client-server model.
