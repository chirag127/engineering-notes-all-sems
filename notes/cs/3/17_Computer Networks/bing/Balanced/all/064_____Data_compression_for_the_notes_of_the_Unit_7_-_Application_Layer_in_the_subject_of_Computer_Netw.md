# Data compression

Data compression is the process of reducing the amount of data needed for the storage or transmission of a given piece of information, typically by the use of encoding techniques. Data compression can improve the performance and efficiency of computer networks by reducing the time, cost and bandwidth required for data transfer.

There are two main types of data compression techniques: lossless and lossy. Lossless compression techniques preserve the exact original data, while lossy compression techniques discard some data to achieve higher compression ratios, but at the cost of data quality.

Some of the common data compression techniques are:

- **Run length encoding (RLE)**: This technique replaces consecutive identical symbols or bytes with a single symbol or byte followed by the number of repetitions. For example, the string "AAAAABBBBCCCC" can be compressed as "A5B4C4". This technique is useful for data sets containing large amounts of redundant information, such as graphics and video data.
- **Differential pulse code modulation (DPCM)**: This technique encodes the difference between successive samples of a signal, rather than the absolute values. For example, if the original signal is "1, 3, 5, 7, 9", the encoded signal can be "1, 2, 2, 2, 2". This technique reduces the number of bits required to represent a signal, especially if the signal has low variability.
- **Dictionary based encoding**: This technique uses a predefined dictionary of symbols or strings and their corresponding codes. For example, the string "the cat sat on the mat" can be compressed as "1 2 3 4 1 5" if the dictionary is {"the": 1, "cat": 2, "sat": 3, "on": 4, "mat": 5}. This technique is effective for data sets that have high frequency of certain symbols or strings, such as text data.
- **Huffman coding**: This technique assigns variable-length codes to symbols or strings based on their frequency of occurrence. The most frequent symbols or strings are assigned the shortest codes, while the least frequent ones are assigned the longest codes. For example, if the frequency of symbols A, B, C, D, E are 40%, 30%, 15%, 10%, 5%, respectively, the Huffman codes can be "0", "10", "110", "1110", "1111". This technique minimizes the average code length and maximizes the compression ratio.
- **Lempel-Ziv (LZ) coding**: This technique builds a dynamic dictionary of symbols or strings and their corresponding codes during the compression process. The dictionary is updated with new symbols or strings as they are encountered in the data. For example, the string "abababababababab" can be compressed as "a, b, ab, 3, 5" if the dictionary is {"a": 1, "b": 2, "ab": 3, "bab": 4, "abab": 5}. This technique adapts to the characteristics of the data and can achieve high compression ratios.
