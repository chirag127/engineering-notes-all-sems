# Static and Dynamic Routing

Static and dynamic routing are two methods used to determine how to send a packet toward its destination in a computer network. They differ in the following aspects:

- **Configuration**: Static routes are configured in advance of any network communication. Static routing used for small networks like having one or two routes. Static routing is often used as a complement to dynamic routing to provide a backup if a dynamic route is unavailable . Dynamic routing, on the other hand, requires routers to exchange information with other routers to learn about paths through the network. Dynamic routing is implemented in large networks and uses complex routing algorithms .
- **Security**: Static routing provides high or more security, as it only has one preconfigured route. Static routing is manual and does not reveal any information about the network topology or the routes to other routers. Dynamic routing provides less security, as it involves exchanging routing information with other routers. Dynamic routing is automated and may expose some information about the network topology or the routes to other routers.
- **Computation and bandwidth requirements**: Static routing requires less compute power and bandwidth, as it does not involve any routing updates or calculations. Static routing is simple and stable, but it may not be able to adapt to network changes or failures . Dynamic routing requires more compute power and bandwidth, as it involves routing updates and calculations. Dynamic routing uses distance vector protocols, such as RIP and IGRP, and link state protocols, such as OSPF and IS-IS, to adjust routes. Dynamic routing is complex and adaptive, but it may cause routing loops or instability .
- **Scalability and flexibility**: Static routing is not scalable or flexible, as it requires manual configuration and maintenance of each route. Static routing is suitable for small and stable networks, but it may not be able to handle network growth or changes . Dynamic routing is scalable and flexible, as it can automatically adjust to network growth or changes. Dynamic routing is suitable for large and dynamic networks, but it may require more resources and management .
