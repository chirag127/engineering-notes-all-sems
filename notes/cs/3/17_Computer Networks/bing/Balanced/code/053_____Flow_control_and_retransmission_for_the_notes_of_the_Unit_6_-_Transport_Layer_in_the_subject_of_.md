### Flow control and retransmission for the notes of the Unit 6 - Transport Layer in the subject of Computer Networks

- The transport layer is the fourth layer of the OSI model that provides reliable and efficient communication between end systems.
- The transport layer performs the following functions     :
  - **Segmentation and reassembly**: The transport layer divides the application data into smaller segments and adds a header to each segment with a sequence number and other information. The header also contains the source and destination port numbers that identify the application processes. The transport layer at the destination reassembles the segments into the original data.
  - **Connection-oriented and connectionless services**: The transport layer can provide either connection-oriented or connectionless services to the application layer. Connection-oriented services require the establishment, maintenance and termination of a logical connection between the source and destination. Connectionless services do not require any connection setup or teardown and send data as independent datagrams. TCP is an example of a connection-oriented protocol and UDP is an example of a connectionless protocol.
  - **Reliable and unreliable delivery**: The transport layer can provide either reliable or unreliable delivery of data to the application layer. Reliable delivery means that the transport layer ensures that all the data segments are received correctly and in order by the destination. Unreliable delivery means that the transport layer does not guarantee the delivery of data segments and may lose or reorder them. TCP provides reliable delivery and UDP provides unreliable delivery.
  - **Flow control**: The transport layer also controls the rate of data transmission between the source and destination to prevent data loss or buffer overflow. Flow control can be implemented by using feedback mechanisms such as acknowledgments, windowing and sliding window protocols. Flow control can also be used to improve the efficiency of data transmission by avoiding buffer underrun. Flow control is performed end-to-end between the transport layer entities and not across a single link.
  - **Error control**: The transport layer also detects and corrects errors that may occur during data transmission. Error control can be implemented by using checksums, sequence numbers, acknowledgments, timers and retransmissions. Error control can also be used to improve the reliability and quality of service of data transmission. Error control is performed end-to-end between the transport layer entities and not across a single link.
  - **Multiplexing and demultiplexing**: The transport layer also enables multiple application processes to share the same network connection by using port numbers. Multiplexing is the process of combining data from different application processes into a single transport layer segment. Demultiplexing is the process of separating data from a single transport layer segment into different application processes. Multiplexing and demultiplexing are performed at the source and destination transport layer entities respectively.
