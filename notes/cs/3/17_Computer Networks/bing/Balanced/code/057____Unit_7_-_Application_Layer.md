## Unit 7 - Application Layer

The application layer is the topmost layer of the network model that provides the interface and protocols for communication between applications over the network. The application layer contains several protocols that enable users to access, share, and exchange information over the internet. Some of the common application layer protocols are:

- **HTTP (Hypertext Transfer Protocol):** This protocol is used to transfer web pages and other resources over the internet. HTTP defines the format and methods for requesting and responding to web resources. HTTP uses TCP as the underlying transport protocol and runs on port 80 by default. HTTP is a stateless protocol, which means it does not keep track of the previous requests or responses. HTTP supports various methods, such as GET, POST, PUT, DELETE, etc., to perform different operations on web resources. HTTP also supports encryption and compression of data using HTTPS and HTTP/2 respectively.

- **DNS (Domain Name System):** This protocol is used to resolve domain names into IP addresses and vice versa. DNS is a hierarchical and distributed database that maps domain names to IP addresses and provides other information, such as mail servers, name servers, etc. DNS uses UDP as the underlying transport protocol and runs on port 53 by default. DNS uses a recursive query mechanism, which means it can forward the query to other DNS servers if it does not have the answer. DNS also supports caching and updating of records to improve performance and reliability.

- **SMTP (Simple Mail Transfer Protocol):** This protocol is used to send and receive email messages over the internet. SMTP defines the format and methods for transferring email messages between mail servers and mail clients. SMTP uses TCP as the underlying transport protocol and runs on port 25 by default. SMTP is a simple and reliable protocol, which means it does not support encryption, authentication, or compression of data. SMTP also supports various commands, such as HELO, MAIL, RCPT, DATA, QUIT, etc., to perform different operations on email messages.

- **FTP (File Transfer Protocol):** This protocol is used to transfer files and directories between hosts over the internet. FTP defines the format and methods for establishing a connection, authenticating users, and transferring data. FTP uses TCP as the underlying transport protocol and runs on port 21 by default. FTP is a stateful protocol, which means it maintains a control connection and a data connection for each session. FTP also supports various commands, such as USER, PASS, LIST, RETR, STOR, etc., to perform different operations on files and directories.

- **TELNET (TELetype NETwork):** This protocol is used to provide remote access and terminal emulation over the internet. TELNET enables users to log in and execute commands on remote hosts using a virtual terminal. TELNET uses TCP as the underlying transport protocol and runs on port 23 by default. TELNET is a simple and insecure protocol, which means it does not support encryption, authentication, or compression of data. TELNET also supports various options, such as ECHO, BINARY, TERMINAL-TYPE, etc., to negotiate the parameters of the session.

- **SNMP (Simple Network Management Protocol):** This protocol is used to monitor and manage network devices and resources over the internet. SNMP defines the format and methods for exchanging information between network managers and network agents. SNMP uses UDP as the underlying transport protocol and runs on port 161 by default. SNMP is a simple and flexible protocol, which means it supports various data types, operations, and security levels. SNMP also supports various components, such as MIB (Management Information Base), PDU (Protocol Data Unit), and SMI (Structure of Management Information), to define the structure and semantics of the information.

- **DHCP (Dynamic Host Configuration Protocol):** This protocol is used to assign dynamic IP addresses and other configuration parameters to hosts over the internet. DHCP defines the format and methods for requesting and offering IP addresses and other information. DHCP uses UDP as the underlying transport protocol and runs on port 67 and 68 by default. DHCP is a stateful protocol, which means it keeps track of the leases and renewals of IP addresses. DHCP also supports various messages, such as DISCOVER, OFFER, REQUEST, ACK, etc., to perform different operations on IP addresses.
