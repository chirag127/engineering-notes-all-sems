# Network management for the notes of the Unit 7 - Application Layer in the subject of Computer Networks

- The application layer is the topmost and seventh layer in the OSI model, where users interact with the network, download information and send data.
- The application layer is an abstraction layer that specifies the shared protocols and interface methods used by hosts in a communication network .
- The application layer helps us to identify communication partners, synchronize communication, and determine the availability of resources.
- The application layer protocols define the messages exchanged by applications and the actions taken by them.
- Some examples of application layer protocols are HTTP, DNS, FTP, SMTP, SNMP, etc.
- Network management refers to the process of configuring, monitoring, and managing the performance of a network, as well as the platform that IT and NetOps teams use to complete these tasks.
- Network management involves various functions, such as fault management, configuration management, performance management, security management, and accounting management.
- Network management also requires the use of application layer protocols, such as SNMP, to communicate with network devices and collect information about their status, configuration, performance, etc.
- Network management is essential for ensuring the reliability, availability, and security of the network, as well as optimizing its performance and efficiency.
