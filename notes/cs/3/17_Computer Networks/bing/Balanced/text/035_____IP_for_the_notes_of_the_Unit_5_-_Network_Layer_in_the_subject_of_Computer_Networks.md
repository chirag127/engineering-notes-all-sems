### IP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

- The network layer is responsible for the delivery of packets across different networks using routers and switches.
- The network layer uses the Internet Protocol (IP) to assign unique addresses to each device on the network and to route packets based on these addresses.
- IP is a connectionless and unreliable protocol, meaning that it does not guarantee the delivery, order, or integrity of the packets. It relies on the transport layer protocols, such as TCP or UDP, to provide these services.
- IP has two versions: IPv4 and IPv6. IPv4 uses 32-bit addresses, which can support up to 4.3 billion devices. IPv6 uses 128-bit addresses, which can support up to 3.4 x 10^38 devices.
- IP addresses are divided into network and host portions. The network portion identifies the network to which the device belongs, and the host portion identifies the device within the network. The network portion can vary in length depending on the subnet mask, which is a binary pattern that indicates which bits belong to the network and which bits belong to the host.
- IP addresses can be classified into five classes: A, B, C, D, and E. Class A addresses have the first bit as 0, and can support up to 126 networks with 16 million hosts each. Class B addresses have the first two bits as 10, and can support up to 16,384 networks with 65,536 hosts each. Class C addresses have the first three bits as 110, and can support up to 2 million networks with 256 hosts each. Class D addresses have the first four bits as 1110, and are used for multicast communication. Class E addresses have the first four bits as 1111, and are reserved for experimental purposes.
- IP addresses can also be divided into public and private addresses. Public addresses are globally unique and can be used to communicate over the Internet. Private addresses are locally unique and can be used to communicate within a network. Private addresses are not routable over the Internet and need to be translated to public addresses using Network Address Translation (NAT).
- IP packets consist of a header and a payload. The header contains information such as the source and destination addresses, the protocol version, the header length, the time to live (TTL), the type of service (TOS), the identification, the flags, the fragment offset, the header checksum, and the options. The payload contains the data from the upper layers.
- IP packets can be fragmented if they are larger than the maximum transmission unit (MTU) of the network. Fragmentation is the process of dividing a large packet into smaller packets that can fit the MTU. Each fragment has the same identification number as the original packet, but has different flags and fragment offset values. Fragmentation can occur at the source or at any intermediate router. Reassembly is the process of combining the fragments into the original packet at the destination.
- IP packets can be routed using different algorithms, such as shortest path, flooding, distance vector, link state, or hierarchical routing. Routing algorithms aim to find the best path for each packet based on different criteria, such as distance, cost, bandwidth, or congestion. Routing algorithms can be static or dynamic. Static routing algorithms use fixed routing tables that do not change unless manually updated. Dynamic routing algorithms use routing protocols, such as RIP, OSPF, or BGP, to exchange routing information and update routing tables automatically.
