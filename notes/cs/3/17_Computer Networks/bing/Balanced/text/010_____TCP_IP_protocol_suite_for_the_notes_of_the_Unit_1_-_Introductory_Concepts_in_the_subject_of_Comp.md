### TCP/IP protocol suite

- TCP/IP stands for **Transmission Control Protocol/Internet Protocol** and is a suite of communication protocols used to interconnect network devices on the internet .
- TCP/IP is also used as a communications protocol in a private computer network (an intranet or extranet).
- TCP/IP is commonly known as the **Internet protocol suite**, which is a framework for organizing the set of communication protocols used in the Internet and similar computer networks according to functional criteria.
- TCP/IP consists of four layers: the **application layer**, the **transport layer**, the **internet layer**, and the **network access layer** .
- The application layer provides the interface for the user applications to communicate with the network, such as web browsers, email clients, FTP clients, etc. Some of the protocols in this layer are HTTP, SMTP, FTP, DNS, etc .
- The transport layer provides the end-to-end data transmission services between the source and destination hosts, such as reliability, flow control, congestion control, error detection, etc. Some of the protocols in this layer are TCP, UDP, SCTP, etc .
- The internet layer provides the routing and addressing functions for the data packets across different networks, such as IP addresses, subnet masks, gateways, etc. Some of the protocols in this layer are IP, ICMP, ARP, RARP, etc .
- The network access layer provides the physical and data link functions for the data transmission over the specific network media, such as Ethernet, Wi-Fi, Bluetooth, etc. Some of the protocols in this layer are Ethernet, PPP, SLIP, etc .
