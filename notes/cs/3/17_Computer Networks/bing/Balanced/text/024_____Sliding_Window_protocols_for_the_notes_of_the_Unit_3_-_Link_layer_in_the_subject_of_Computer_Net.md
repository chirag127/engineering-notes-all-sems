### Sliding Window Protocols

- Sliding window protocols are data link layer protocols for reliable and sequential delivery of data frames.
- The sliding window is a technique that allows the sender to send multiple frames at a time before receiving any acknowledgment from the receiver.
- The sliding window is also used in the Transmission Control Protocol (TCP) at the transport layer.
- The sliding window is a variable-sized buffer that slides along the data stream, indicating the range of frames that can be sent or received at any time.
- The sliding window has two types: sender window and receiver window. The sender window shows the range of frames that can be sent without waiting for an acknowledgment. The receiver window shows the range of frames that can be received and acknowledged.
- The size of the sliding window is determined by the bandwidth-delay product, which is the product of the link bandwidth and the round-trip time (RTT) of the packets. The larger the bandwidth-delay product, the larger the sliding window size.
- The sliding window protocols can be classified into three types: stop-and-wait, go-back-N, and selective repeat.
- Stop-and-wait protocol is the simplest sliding window protocol, where the sender sends one frame at a time and waits for an acknowledgment before sending the next frame. The sender window and the receiver window size are both one. This protocol is inefficient and has low utilization of the link.
- Go-back-N protocol is a sliding window protocol where the sender can send multiple frames at a time, up to the size of the sender window, without waiting for an acknowledgment. The receiver window size is one, and the receiver only accepts the frames in order and discards the out-of-order frames. The receiver sends a cumulative acknowledgment for the last in-order frame received. If the sender does not receive an acknowledgment within a timeout period, it retransmits all the frames from the last acknowledged frame. This protocol is more efficient than stop-and-wait, but it has high overhead and wastage of bandwidth due to retransmissions.
- Selective repeat protocol is a sliding window protocol where the sender can send multiple frames at a time, up to the size of the sender window, without waiting for an acknowledgment. The receiver window size is equal to the sender window size, and the receiver can accept the frames out of order and buffer them. The receiver sends a selective acknowledgment for each frame received. If the sender does not receive an acknowledgment for a specific frame within a timeout period, it retransmits only that frame. This protocol is the most efficient and reliable sliding window protocol, but it has high complexity and memory requirements.
