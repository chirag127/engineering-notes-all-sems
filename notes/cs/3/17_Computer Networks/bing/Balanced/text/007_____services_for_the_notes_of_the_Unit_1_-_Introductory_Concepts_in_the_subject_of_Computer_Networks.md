### Services for the notes of the Unit 1 - Introductory Concepts in the subject of Computer Networks

- A service is a set of functions or capabilities that a layer provides to the layer above it in the network architecture.
- A service can be either connection-oriented or connectionless.
- A connection-oriented service establishes a logical connection between the sender and the receiver before transferring data.
- A connectionless service does not require a connection establishment and sends data as independent packets.
- Some examples of services are:
  - Reliable data transfer: ensures that the data is delivered without errors and in the correct order.
  - Congestion control: regulates the amount of data sent by the sender to avoid overwhelming the network resources.
  - Routing: determines the best path for the data packets to reach the destination.
  - Addressing: assigns unique identifiers to the network devices and enables the data packets to be delivered to the correct destination.
  - Security: protects the data from unauthorized access, modification, or disclosure.
- Services are provided by protocols, which are rules or standards that define how the communication between the network layers is performed.
- Protocols specify the format, syntax, and semantics of the data packets, as well as the procedures for error detection, correction, and recovery.
- Protocols are implemented by software or hardware components in the network devices.
- Some examples of protocols are:
  - Transmission Control Protocol (TCP): provides reliable, connection-oriented, and byte-stream service to the application layer.
  - User Datagram Protocol (UDP): provides unreliable, connectionless, and message-oriented service to the application layer.
  - Internet Protocol (IP): provides connectionless and best-effort service to the transport layer and is responsible for routing and addressing.
  - Ethernet: provides connectionless and best-effort service to the network layer and is responsible for data link and physical layer functions.
  - Hypertext Transfer Protocol (HTTP): provides request-response service to the web applications and is responsible for transferring web documents.
