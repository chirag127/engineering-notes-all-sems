### layering principles for the notes of the Unit 1 - Introductory Concepts in the subject of Computer Networks

Layering is a design principle in computer networking where communication between systems is divided into separate functional layers, each responsible for a specific aspect of communication. The following are some of the key concepts related to layering:

1. Abstraction: Layering provides abstraction, which means that each layer only needs to understand the services provided by the layer below it, and does not need to know the details of how those services are implemented.

2. Modularity: Layering provides modularity, which means that the different layers can be developed and tested independently, and changes to one layer do not affect the other layers.

3. Scalability: Layering provides scalability, which means that new features and services can be added to a specific layer without affecting the other layers.

4. OSI Model: The Open Systems Interconnection (OSI) model is a widely used layering model in computer networking, and defines seven layers, from the physical layer to the application layer.

5. TCP/IP Model: The Transmission Control Protocol/Internet Protocol (TCP/IP) model is another widely used layering model in computer networking, and defines four layers, from the link layer to the application layer.

6. Encapsulation: Encapsulation is the process of wrapping data in a layer with header information, which is used to provide the services of that layer.

In this unit, you will learn about layering principles and the key concepts related to them, including abstraction, modularity, scalability, the OSI model, the TCP/IP model, and encapsulation.

This unit will provide a foundation for understanding the principles and practices of layering in computer networking and for exploring the various concepts and techniques used in the field of computer networks.
