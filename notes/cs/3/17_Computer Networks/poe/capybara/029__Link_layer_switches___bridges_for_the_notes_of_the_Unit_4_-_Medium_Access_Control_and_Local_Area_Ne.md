### Link layer switches & bridges

Link layer switches and bridges are network devices that operate at the data link layer of the OSI model. These devices connect network segments and forward data packets between them, improving network performance and reducing network congestion. Here are some key points to understand about link layer switches and bridges:

- A link layer switch is a network device that connects multiple devices on a local area network (LAN) and forwards data packets between them. It uses the MAC addresses of the devices to determine where to forward the data packets.
- A bridge is a simpler version of a switch that connects two network segments together. It also uses MAC addresses to forward data packets between the segments.
- Link layer switches and bridges operate at the data link layer, which is the second layer of the OSI model. This layer is responsible for providing reliable data transfer across a physical link.
- Link layer switches and bridges are transparent to higher-layer protocols such as IP. They only look at the MAC addresses in the data packets they forward.
- Link layer switches and bridges improve network performance by reducing network congestion. They do this by creating separate collision domains for each port on the switch or bridge. This means that data packets can be transmitted simultaneously on different ports without colliding with each other.
- Link layer switches and bridges also improve network security by isolating traffic between different network segments. This prevents unauthorized access to sensitive data.
- Link layer switches and bridges can be configured to support different network speeds and protocols. For example, some switches support Gigabit Ethernet while others support Fast Ethernet. Some switches also support VLANs (virtual LANs), which allow multiple virtual LANs to share the same physical network infrastructure.

In summary, link layer switches and bridges are important network devices that improve network performance and security. They operate at the data link layer of the OSI model and use MAC addresses to forward data packets between network segments. By creating separate collision domains and isolating traffic between segments, they reduce network congestion and prevent unauthorized access to sensitive data.
