## Unit 5 - Network Layer

The network layer is the third layer of the OSI model, responsible for the transmission of data across different networks. It provides logical addressing and routing of data packets between different hosts in a network. In this unit, we will cover the following topics:

1. Network Layer Functions:
   - Logical addressing: The network layer provides logical addressing to identify hosts in a network. IP addresses are used for this purpose.
   - Routing: The network layer determines the best path for data packets to reach their destination, using routing algorithms and protocols.
   - Fragmentation and reassembly: The network layer divides large data packets into smaller fragments for transmission and reassembles them at the receiving end.

2. IPv4 Addressing:
   - IPv4 address structure: IPv4 addresses are 32-bit binary numbers, divided into four octets. Each octet is represented in decimal form, separated by dots.
   - Classes of IPv4 addresses: IPv4 addresses are divided into five classes, A, B, C, D, and E. Each class has a different range of addresses for different network sizes.
   - Subnetting: Subnetting is a technique used to divide a large network into smaller sub-networks, to improve network performance and manageability.

3. IPv6 Addressing:
   - IPv6 address structure: IPv6 addresses are 128-bit binary numbers, represented in hexadecimal form, separated by colons.
   - Advantages of IPv6: IPv6 provides a much larger address space than IPv4, improved security features, and better support for mobile networks.

4. Routing:
   - Routing algorithms: Different routing algorithms are used to determine the best path for data packets, such as distance vector, link state, and path vector algorithms.
   - Routing protocols: Different routing protocols are used to exchange routing information between routers, such as RIP, OSPF, BGP, and IS-IS.

5. Network Address Translation (NAT):
   - NAT basics: NAT is a technique used to map private IP addresses to public IP addresses, to allow hosts in a private network to access the Internet.
   - Types of NAT: Different types of NAT are used for different purposes, such as static NAT, dynamic NAT, and port address translation (PAT).

In summary, the network layer provides logical addressing and routing of data packets between different hosts in a network. It uses IP addresses for logical addressing and routing algorithms and protocols for determining the best path for data packets. IPv4 and IPv6 are the two versions of IP addresses used in networks, and routing protocols and algorithms are used for exchanging routing information and determining the best path for data packets. NAT is a technique used to map private IP addresses to public IP addresses, to allow hosts in a private network to access the Internet.
