### Process-to-process delivery for the notes of the Unit 6 - Transport Layer in the subject of Computer Networks

In computer networks, the transport layer is responsible for ensuring reliable process-to-process delivery of data between applications running on different hosts. Here are some important points to understand about process-to-process delivery:

- The transport layer provides end-to-end communication between applications running on different hosts. This means that the data is delivered from the source application to the destination application, regardless of the number of intermediate hosts between them.
- The transport layer uses port numbers to identify the applications running on different hosts. A port number is a 16-bit number that uniquely identifies an application running on a host. The source and destination port numbers are used by the transport layer to route the data to the correct application.
- The transport layer provides reliable delivery of data by using various techniques such as error detection, retransmission of lost packets, flow control, and congestion control. These techniques ensure that the data is delivered to the destination application without any errors and in a timely manner.
- The transport layer provides connection-oriented and connectionless services to applications. In connection-oriented service, a virtual circuit is established between the source and destination applications before data transfer begins. This ensures that the data is delivered in the correct order and without any loss. In connectionless service, the data is sent without establishing a virtual circuit. This service is faster but less reliable than the connection-oriented service.
- The transport layer provides multiplexing and demultiplexing of data. Multiplexing allows multiple applications to share the same network connection, while demultiplexing ensures that the data is delivered to the correct application.
- The transport layer protocols include TCP (Transmission Control Protocol) and UDP (User Datagram Protocol). TCP provides reliable, connection-oriented service, while UDP provides unreliable, connectionless service. TCP is used for applications that require reliable data delivery, such as email and file transfer, while UDP is used for applications that require low latency and fast data delivery, such as video streaming and online gaming.

Understanding process-to-process delivery is important for designing and implementing reliable and efficient applications that use computer networks for data communication.
