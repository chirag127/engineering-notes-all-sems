
### Channel Allocation for the Notes of the Unit 4 - Medium Access Control and Local Area Networks in the subject of Computer Networks

* Channel allocation is the process of assigning a particular frequency or set of frequencies to a user or group of users. 
* In computer networks, channel allocation is used to ensure that multiple users can use the same medium without interference. 
* The two main types of channel allocation algorithms are static and dynamic. 
* Static channel allocation algorithms are used when the number of users is known in advance and the number of channels is fixed. 
* Dynamic channel allocation algorithms are used when the number of users is unknown and the number of channels is variable. 
* In local area networks, the main channel allocation algorithms used are the Carrier Sense Multiple Access (CSMA) and the Carrier Sense Multiple Access with Collision Detection (CSMA/CD). 
* CSMA is a protocol in which multiple devices share the same medium and each device must listen before transmitting. 
* CSMA/CD is a protocol in which multiple devices share the same medium and each device must listen before transmitting. If two devices transmit at the same time, a collision occurs and the devices must wait for a random amount of time before retransmitting. 
* In addition to CSMA/CD, other channel allocation algorithms used in local area networks include Demand Priority, Token Passing, and Reservation.
