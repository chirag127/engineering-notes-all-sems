
### Remote Login for Unit 7 - Application Layer in Computer Networks

* Remote login is a form of network access that enables a user to access a remote computer or network from a different location.
* It is commonly used in the workplace to allow employees to access their work files from home, or from any other remote location.
* Remote login can be established using a variety of protocols, such as Telnet, SSH, and RDP.
* Telnet is a text-based protocol that allows users to log in to a remote computer and access its command line interface.
* SSH (Secure Shell) is a secure protocol that encrypts all data sent over the network, making it more secure than Telnet.
* RDP (Remote Desktop Protocol) is a Microsoft protocol that allows users to remotely access their Windows computer from any other Windows computer.
* Remote login can also be used to access web-based applications and services, such as email, online banking, and online file storage.
