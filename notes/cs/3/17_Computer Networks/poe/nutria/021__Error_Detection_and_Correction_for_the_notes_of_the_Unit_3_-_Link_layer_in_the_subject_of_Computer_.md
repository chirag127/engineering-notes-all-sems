
### Error Detection and Correction for the notes of the Unit 3 - Link layer in the subject of Computer Networks

- Error detection and correction is an important aspect of communication in computer networks. 
- Error detection is the process of detecting errors in transmitted data. It can be done in two ways: by the use of a checksum or by the use of a parity bit. 
- Checksums are created by adding up all the bits in a data packet and comparing it to a predetermined value. If the checksum matches the predetermined value, the data is assumed to be error-free. 
- Parity bits are used to detect errors in data packets. A parity bit is added to the end of a data packet and is set to either 0 or 1. If the parity bit is set to 0, the number of 1s in the data packet must be even; if it is set to 1, the number of 1s must be odd. If the number of 1s does not match the parity bit, an error has been detected. 
- Error correction is the process of correcting errors in transmitted data. It is done by using forward error correction, in which redundant data is sent along with the original data. If an error is detected, the redundant data can be used to reconstruct the original data. 
- Error detection and correction are essential for reliable communication in computer networks. By using checksums and parity bits, errors can be detected, and with forward error correction, errors can be corrected.
