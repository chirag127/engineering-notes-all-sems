
### Framing for the notes of the Unit 3 - Link layer in the subject of Computer Networks

* Framing is the process of adding a frame header to the data packet so that it can be transmitted through the physical layer. 
* The frame header contains information such as source and destination address, packet size, error detection, and sequencing information. 
* The frame header also contains a delimiter which is used to mark the start and end of the frame. 
* The frame header is followed by the data payload which contains the actual data to be transmitted. 
* The frame trailer is then added at the end of the frame which contains an error detection code, such as a Cyclic Redundancy Check (CRC) or a checksum. 
* The frame trailer is used to ensure that the data was transmitted correctly and without any errors. 
* After the frame is transmitted, the receiver performs the same error detection process to ensure that the data was received correctly. 
* If any errors are detected, the receiver can request a retransmission of the frame.
