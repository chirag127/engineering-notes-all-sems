
### File Transfer Protocol

- File Transfer Protocol (FTP) is a protocol used to transfer files between two computers over a network. 
- It is based on the client-server model, where a client initiates a request to a server and the server responds to the request.
- FTP uses two channels for communication, a control channel and a data channel. 
- The control channel is used to authenticate the user and to send commands to the server, while the data channel is used to transfer the requested files.
- FTP supports both active and passive modes of communication. In active mode, the client initiates the connection and the server responds to the request. In passive mode, the server initiates the connection and the client responds to the request.
- FTP is widely used for transferring large files, such as software, multimedia files, and documents.
