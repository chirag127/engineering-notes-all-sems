
### Network Topology Design

* Network topology is the physical and logical layout of the nodes and connections in a network.
* Common network topologies include bus, star, ring, mesh, and tree.
* Bus networks connect all nodes to a single cable or bus, which is a shared medium.
* Star networks connect all nodes to a central hub or switch, which is the control point for the network.
* Ring networks connect all nodes in a continuous loop, with each node connected to two other nodes.
* Mesh networks connect all nodes in a full-mesh, where each node is connected to every other node in the network.
* Tree networks connect all nodes in a hierarchical structure, with each node connected to a central node.
