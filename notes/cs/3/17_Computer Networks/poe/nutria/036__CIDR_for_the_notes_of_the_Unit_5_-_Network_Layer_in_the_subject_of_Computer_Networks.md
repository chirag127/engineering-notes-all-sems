
### CIDR for the Notes of the Unit 5 - Network Layer in the Subject of Computer Networks

1. CIDR stands for Classless Inter-Domain Routing. It is a method of allocating IP addresses and routing Internet Protocol packets.

2. CIDR was introduced to replace the traditional system of IP address allocation, which used Class A, B, and C networks.

3. CIDR allows for more efficient use of IP address space by allowing for variable-length subnet masks.

4. CIDR notation is a compact representation of an IP address and its associated routing prefix. It is written as a string of numbers, separated by a slash, that specifies the number of bits of the address that are used for the network prefix.

5. CIDR allows for more efficient routing of traffic on the Internet, as it reduces the size of routing tables and reduces the amount of traffic that needs to be routed.

6. CIDR also allows for more efficient use of IP address space, as it allows for the allocation of IP addresses in smaller subnets. This allows for more efficient use of IP address space, as it reduces the amount of wasted IP address space.
