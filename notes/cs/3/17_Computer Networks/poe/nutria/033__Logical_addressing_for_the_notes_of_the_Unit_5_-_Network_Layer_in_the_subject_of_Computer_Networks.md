
### Logical Addressing for the Notes of the Unit 5 - Network Layer in the Subject of Computer Networks

1. Logical addressing is a networking technique used to identify devices on a network. It is used to differentiate between devices on a network and allow them to communicate with each other. 
2. Logical addressing is based on the IP address of a device, which is a unique identifier assigned to each device on a network.
3. IP addresses are composed of four octets, each of which is a number between 0 and 255. The first octet is the network address, while the remaining three octets are the host address.
4. IP addresses are assigned to devices in two ways: static and dynamic. Static IP addresses are manually assigned to devices and remain the same, while dynamic IP addresses are assigned by a DHCP server and can change.
5. Subnet masks are used to divide a network into subnets. They are composed of four octets, with the first octet being the network address and the remaining three octets being the subnet mask.
6. Network layer protocols, such as IP and ICMP, are responsible for routing data across networks. They are used to determine the best path for data to travel from one device to another.
7. Network layer protocols are responsible for providing error detection and correction, as well as flow control. 
8. Network layer protocols are also responsible for providing Quality of Service (QoS) to ensure that data is delivered in a timely manner.
9. Network layer protocols are used to establish secure connections between devices on a network. They use encryption and authentication techniques to ensure that data is secure.
10. Network layer protocols are responsible for providing network address translation (NAT) to allow devices to communicate with each other without having to use public IP addresses.
