
### Sliding Window Protocols

* Sliding window protocols are used in computer networks to ensure reliable transmission of data over a link layer. 
* These protocols are based on the concept of a sender window and a receiver window, which are used to keep track of the packets that have been sent and received. 
* The size of the window determines the amount of data that can be sent without acknowledgement from the receiver. 
* The sender window keeps track of the packets that have been sent and the receiver window keeps track of the packets that have been received. 
* The sliding window protocol ensures that only packets that have been acknowledged by the receiver are sent, thus preventing the sender from sending too many packets at once. 
* In addition, the sliding window protocol also allows the sender to adjust the rate of transmission according to the available bandwidth, thus ensuring efficient use of the network resources. 
* The sliding window protocol also allows for error correction, as the sender can retransmit any packets that may have been lost or corrupted during transmission. 
* Finally, the sliding window protocol also allows for flow control, where the sender can limit the rate of transmission if the receiver is unable to process the data quickly enough.
