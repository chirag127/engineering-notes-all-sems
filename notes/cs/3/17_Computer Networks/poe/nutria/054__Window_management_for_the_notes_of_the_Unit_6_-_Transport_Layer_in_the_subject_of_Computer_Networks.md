
### Window Management for the Notes of the Unit 6 - Transport Layer in the Subject of Computer Networks

* The Transport layer is responsible for providing end-to-end communication services for applications. 
* Window management is an important technique used by the Transport layer to ensure reliable data transfer. 
* Window management involves the use of sliding windows, which are used to determine the amount of data that can be sent without receiving an acknowledgement from the receiver. 
* The sender maintains a window of unacknowledged packets, which is used to ensure that the receiver is not overwhelmed with data. 
* The sender can only send as much data as the receiver can handle, and the size of the window determines the amount of data that can be sent. 
* The size of the window is adjusted dynamically based on the current network conditions. 
* The window size can be increased if the network conditions are favorable, and decreased if the network conditions are not favorable. 
* The window size is also adjusted based on the type of data being transmitted. For example, if the data is large, the window size may be increased to ensure that all of the data is transmitted successfully. 
* The window size can also be adjusted based on the amount of data that has been successfully transmitted. 
* If the amount of data that has been successfully transmitted is large, the window size may be reduced to prevent the receiver from being overwhelmed with data.
