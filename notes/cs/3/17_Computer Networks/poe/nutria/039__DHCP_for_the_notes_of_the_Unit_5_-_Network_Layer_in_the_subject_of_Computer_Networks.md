
### DHCP for the Notes of the Unit 5 - Network Layer in the Subject of Computer Networks

* Dynamic Host Configuration Protocol (DHCP) is a network protocol used to automatically assign IP addresses to computers and other network devices. 
* DHCP works by sending out a broadcast request on the local network, which is then answered by a DHCP server. 
* The DHCP server maintains a pool of available IP addresses and assigns an IP address to the requesting device. 
* DHCP also sends other configuration information to the requesting device, such as the IP address of the default gateway, the IP address of the DNS server, and other network configuration options.
* DHCP can also be used to configure network devices such as routers, switches, and access points. 
* DHCP is an important part of network management, as it helps to reduce the need for manual configuration of IP addresses.
