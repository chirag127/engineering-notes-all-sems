
### Types of connections for the notes of the Unit 2 - Physical Layer in the subject of Computer Networks

1. Point-to-Point Connection: Point-to-point connection is a type of physical connection between two devices, such as a computer and a printer. It is a dedicated line that allows data to be transferred between the two devices without interference from any other device.

2. Multipoint Connection: A multipoint connection is a type of physical connection between three or more devices or nodes. It is a shared line that allows data to be transferred between the devices without interference from any other device.

3. Broadcast Connection: A broadcast connection is a type of physical connection in which data is transmitted from one device to all the other devices in the network. This type of connection is used to send out messages to all the devices in the network simultaneously.

4. Mesh Connection: A mesh connection is a type of physical connection in which each device is connected to every other device in the network. This type of connection is used in networks where each device needs to be able to communicate with every other device.
