
### Network Devices and Components

1. **Routers**: Routers are networking devices that forward data packets between computer networks. They are used to connect multiple networks, such as LANs, WANs, and MANs. Routers use routing tables to determine the best path for data packets to take.

2. **Switches**: Switches are networking devices that connect computers and other devices together in a network. They create a network by connecting multiple devices together and allow data to be transferred between them.

3. **Network Interface Cards (NICs)**: Network Interface Cards are hardware components that allow computers to connect to a network. They are installed inside a computer and provide a physical connection between the computer and the network.

4. **Network Cables**: Network cables are used to connect computers and other devices together in a network. They can be made of copper, fiber optic, or wireless.

5. **Wireless Access Points (WAPs)**: Wireless Access Points are networking devices that allow computers to connect to a wireless network. They are used to create a wireless network, and can be used to extend the range of a wireless network.
