## Unit 6 - Transport Layer

1. The transport layer is responsible for providing data transfer between applications on different hosts. It provides transparency and reliability to the upper layers.

2. The two most commonly used transport protocols are:

- Transmission Control Protocol (TCP): Provides reliable, ordered, and error-checked delivery of transmitted data. Typically used for web browsing, email, and file transfer.
- User Datagram Protocol (UDP): Provides fast but unreliable datagram service. Typically used for real-time applications such as video streaming or online gaming.

3. TCP provides reliable data transmission with the use of the following mechanisms:

- Sequencing: Numbers each byte of data to ensure proper ordering
- Acknowledgment: Receiver sends acknowledgement for the received bytes
- Timeout and retransmission: Sender retransmits unacknowledged bytes after a timeout
- Error checking: Checksums ensure data is not corrupted
- Flow control: Sender will not overwhelm receiver with data
- Congestion control: Sender will not overwhelm the network with data

4. UDP provides an unreliable datagram service. It offers minimal transmission services without guarantees on ordering, delivery, or error checking. This makes it faster than TCP at the expense of reliability. UDP is typically used for real-time applications where some data loss is preferable to delay.
