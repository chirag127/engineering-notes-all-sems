## Unit 7 - Application Layer

1. Application Layer Protocols: The application layer supports application and end-user processes. Application layer protocols are used for access to network services and data. Examples of application layer protocols include:
- HTTP: Used for web access
- SMTP: Used for email
- FTP: Used for file transfer
- DNS: Used for mapping hostnames to IP addresses
- SNMP: Used for network management

2. HTTP: HTTP (Hypertext Transfer Protocol) is the foundation of data communication for the World Wide Web. HTTP defines how messages should be formatted and transmitted, and what actions web servers and browsers should take in response to various commands. For example, when a web browser requests a web page from a web server, this happens via an HTTP command.

3. FTP: FTP (File Transfer Protocol) is a standard network protocol used to transfer files from one host to another host over a TCP-based network, such as the Internet. A FTP client establishes a connection to a FTP server and can then request to upload or download files. FTP is commonly used to transfer web page files (using HTTP) and to publish software updates.
