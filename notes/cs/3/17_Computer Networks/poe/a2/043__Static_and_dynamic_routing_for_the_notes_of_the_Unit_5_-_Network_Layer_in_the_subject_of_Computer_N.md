### Static and dynamic routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks.

1. Static routing:
  - Routes are manually configured and remain fixed.
  - Route selection is made once based on the network topology.
  - Little overhead on the router CPU (no periodic route updates).
  - Not suitable for large and complex networks where topology changes frequently.

2. Dynamic routing:
  - Routes are learned automatically and adapt to changes in topology.
  - Route selection is made based on the latest routing information.
  - Requires additional overhead on the router CPU to maintain routing tables.
  - Suitable for large and complex networks with frequent topology changes.
  - Examples: RIP, OSPF, BGP, etc.

3. Hybrid routing:
  - Combines both static and dynamic routing.
  - Less frequently changing routes can use static routing.
  - More dynamic routes can use dynamic routing to handle topology changes.
  - Examples: Static routes with a default route using dynamic routing.
