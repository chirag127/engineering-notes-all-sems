### CIDR for the notes of the Unit 5 - Network Layer in the subject of Computer Networks.

1. CIDR stands for Classless Inter-Domain Routing. It is a method for allocating IP addresses and routing Internet Protocol packets.
2. In CIDR, the IP address is specified with a prefix indicating the number of significant bits in the address. For example, 192.168.1.0/24 indicates that the first 24 bits of the address are the network address.
3. CIDR eliminates the need for the original system based on classes A, B, and C networks and allows for a more efficient and aggregated allocation and routing of addresses.
4. The CIDR notation is a compact way to represent and specify networks and routes. The IP address is followed by a slash and the number of significant bits. For example, 172.16.0.0/12 represents the 172.16.0.0 through 172.31.255.255 networks.
5. An IP address prefix length indicates how many of the leftmost contiguous bits of the address are used for the network prefix. The remaining bits are used for the host identifier. A larger prefix length results in a smaller number of available subnets and hosts.
6. CIDR has been adopted to mitigate the problem of IPv4 address exhaustion and contain the growth of the Internet routing tables. It allows for a more efficient allocation of the limited IPv4 address space.
