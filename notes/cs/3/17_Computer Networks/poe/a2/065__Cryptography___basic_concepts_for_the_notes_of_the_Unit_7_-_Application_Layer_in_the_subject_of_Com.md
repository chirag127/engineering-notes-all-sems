### Cryptography – basic concepts for the notes of the Unit 7 - Application Layer in the subject of Computer Networks:

1. Cryptography is the process of converting the plain text into ciphertext using encryption algorithms and converting the ciphertext back to plain text using decryption algorithms.
2. The two main types of cryptography are:
- Symmetric key cryptography: Uses a single key for both encryption and decryption. The sender and receiver have the same key. Eg: AES, DES, Blowfish.
- Asymmetric key cryptography: Uses a public key for encryption and a private key for decryption. The public key can be shared with everyone while the private key is only known to the recipient. Eg: RSA, ECC.
3. Cryptanalysis is the art of cracking cryptography and involves analyzing the cryptography algorithm and attacking the weaknesses to recover the original message without knowing the key. Common attacks are brute-force attacks, dictionary attacks, cipher text only attacks, etc.
4. Cryptographic algorithms and keys should be very strong and not vulnerable to attacks. The key size should be large enough and the algorithms should not have any redundancies or patterns that can be exploited.
5. Cryptography is used in various applications like data security, authentication, digital signatures, etc to provide confidentiality, integrity, authentication and non-repudiation.
