### File Transfer Protocol for the notes of the Unit 7 - Application Layer in the subject of Computer Networks.

1. FTP or File Transfer Protocol is a application layer protocol used to transfer files between two hosts over a TCP-based network, such as the Internet.
2. It uses separate control and data connections between the client and the server.
3. The control connection is used to send FTP commands from the client to the server and send replies from the server to the client. The data connection is used to transfer the actual file data.
4. The two most commonly used FTP modes are active mode and passive mode. In active mode, the client specifies the data port number but in passive mode, the server specifies the data port number.
5. FTP commands are used for authentication, to navigate the server's file system, and to send and receive files.
6. There are two types of FTP - FTP and Secure FTP or SFTP. FTP sends authentication information and file data in clear text, making it insecure whereas SFTP uses SSH security mechanisms to encrypt the data being sent.
7. FTP is commonly used to upload/download website files, software patches, and other bulk data transfers on the Internet.
