### Logical addressing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks.

1. Logical addresses - IP addresses
- IP addresses are 32 bit (IPv4) or 128 bit (IPv6) logical addresses assigned to devices.
- They allow devices to be addressed and located on a network.
- The IP address space is divided into smaller networks (using subnet masks) which can be used by organizations or Internet Service Providers.

2. IP address structure
- IP addresses are written as 4 decimal numbers separated by periods (IPv4) or 8 groups of 4 hexadecimal numbers separated by colons (IPv6).
- The address is split into a network portion (determined by the subnet mask) and a host portion (identifying a specific device on the network).
- The subnet mask is also written in the same format as an IP address and is used to extract the network address portion.

3. Subnetting
- Dividing a larger network into smaller subnetworks allows efficient use of the IP address space.
- Subnetting is done by extending the subnet mask to allocate more bits to identify the subnetwork. For example, using a subnet mask of 255.255.255.0 would create 256 subnetworks with 254 hosts each.
- Subnetting allows networks to be structured hierarchically and scoped to the size needed for an organization or group.
