### ICMP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

1. ICMP stands for Internet Control Message Protocol.
2. It is used for diagnosing network problems and sending error messages.
3. ICMP messages are encapsulated within IP datagrams.
4. Types of ICMP messages:
 - Echo Request and Echo Reply: Used by ping to check reachability of a host.
 - Destination Unreachable: Sent when a router cannot forward a packet due to reasons like network unreachability, host unreachability, protocol unreachability, etc.
 - Time Exceeded: Sent when a router discards a packet because it exceeded the time-to-live field.
 - Parameter Problem: Sent when a router detects a problem with the IP header of a packet.
5. Traceroute uses ICMP Echo messages with varying TTL values to discover the route taken by packets across a network.
6. ICMP is a connectionless and unreliable protocol. ICMP messages are not guaranteed to be delivered or delivered in order.
