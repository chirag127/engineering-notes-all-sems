### Network structure and architecture for the notes of the Unit 1 - Introductory Concepts in the subject of Computer Networks:

1. Network: A network is a group of two or more computer systems linked together. Networks allow computers to communicate and share resources.

2. Node: A node refers to a connection point, either a redistribution point or an endpoint for data transmissions. Devices such as computers, printers, and routers are examples of nodes.

3. Link: A link refers to the physical or logical connection between two nodes. It is a communication pathway connecting two or more nodes.

4. Network devices: Networks typically consist of multiple devices such as switches, routers, servers, clients, and storage devices.
- Switches: Switches connect network devices and route data to the correct destination.
- Routers: Routers connect multiple networks and direct traffic between them.
- Servers: Servers provide resources, services, and applications to other computers.
- Clients: Clients are devices that access the resources, services, and applications provided by servers.
- Storage devices: Storage devices provide permanent storage of data in a network.

5. Network architecture: The network architecture refers to the basic design of a computer network. It defines how the systems and resources in a network are connected and how they communicate with each other. The most common network architectures are:
- Client-server: In this architecture, dedicated server computers provide resources and services to client computers.
- Peer-to-peer: In this architecture, each computer can act as both a client and a server, and all devices share resources and responsibilities.
- Hybrid: This architecture combines features from client-server and peer-to-peer architectures.
