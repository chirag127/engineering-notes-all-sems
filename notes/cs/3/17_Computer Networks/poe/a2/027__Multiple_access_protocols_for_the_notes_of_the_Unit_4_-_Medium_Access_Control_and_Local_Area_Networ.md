### Multiple access protocols for the notes of the Unit 4 - Medium Access Control and Local Area Networks in the subject of Computer Networks.

1. ALOHA:
- Pure ALOHA: Nodes transmit whenever they have data to send. Collisions can occur.
- Slotted ALOHA: Time is divided into slots and nodes can only transmit at slot boundaries. Collisions can still occur.

2. CSMA (Carrier Sense Multiple Access):
- Nodes sense the channel before transmitting. If the channel is idle, the nodes transmits. If the channel is busy, the node waits for a random period before sensing again.
- Examples: CSMA/CD (Collision Detection) used in Ethernet, CSMA/CA (Collision Avoidance) used in WiFi.

3. Token Passing:
- A token is passed around the nodes in the network. Only the node having the token can transmit. After transmission is complete, the node passes the token to the next node.
- Examples: Token Ring, FDDI.
