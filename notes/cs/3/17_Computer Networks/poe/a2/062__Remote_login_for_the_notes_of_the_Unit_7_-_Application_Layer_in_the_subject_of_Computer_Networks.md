### Remote login for the notes of the Unit 7 - Application Layer in the subject of Computer Networks.

1. Remote login is a service that allows a user to login to a remote computer (server) from a local computer (client) over a network and access its resources.
2. The user has to authenticate himself/herself to the remote computer with a valid username and password. After authentication, the user gets the access to the resources and services available on the remote computer.
3. The remote login service uses an application layer protocol called SSH (Secure Shell) or Telnet. SSH provides strong security and encryption for data transfer between the local and remote computer while Telnet sends the data in plain text without any encryption making it insecure.
4. The local computer runs a remote login client application that connects to the remote login service running on the remote computer. The client and server authenticate each other using digital certificates or passwords and then establish a connection allowing the user to access the remote resources.
5. Remote login is commonly used to manage servers, access accounts and resources on other computers, work from home or remote locations, etc. However, it poses security risks if the data is sent in plain text or if the credentials are weak. SSH should be used with strong passwords or keys to mitigate the risks.
