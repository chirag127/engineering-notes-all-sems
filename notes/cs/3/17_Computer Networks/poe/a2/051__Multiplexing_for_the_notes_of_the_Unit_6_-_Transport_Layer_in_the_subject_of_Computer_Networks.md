### Multiplexing for the notes of the Unit 6 - Transport Layer in the subject of Computer Networks

1. Multiplexing is a technique where multiple signals or information streams are combined into one signal over a shared medium.
2. Transport layer multiplexing allows multiple applications running on the same computer to share the network access, thereby reducing the number of ports required. For example, if four applications need network access, only one port is required if multiplexing is used, rather than four ports without multiplexing.
3. The two types of multiplexing used in the transport layer are:
 - Port numbering: Each application is assigned a port number, allowing the destination device to demultiplex the incoming traffic and direct it to the appropriate application.
 - Address multiplexing: The source and destination address along with the port numbers are used to distinguish between the traffic of different applications.
4. Demultiplexing is the reverse process of extracting the original streams from the combined signal. The transport layer at the destination uses demultiplexing to pass the incoming segments to the appropriate applications.
5. Multiplexing reduces network congestion, making more efficient use of available bandwidth. It also makes additional applications and services possible without the need for a unique port for each application.
