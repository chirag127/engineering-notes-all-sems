## Unit 1 - Introductory Concepts

1. Introduction to Programming
- Programming is the process of creating instructions for a computer to follow
- Programming languages act as interpreters between humans and machines
- The two broad types of programming languages are low-level languages and high-level languages
- Low-level languages directly interface with the computer's CPU while high-level languages use abstraction to be more human-readable

2. Algorithms and Flowcharts
- Algorithms are series of steps to solve a problem or achieve some goal
- Flowcharts are diagrams that represent the flow of data and logic in a program using symbols for different programming constructs
- Flowcharts help visualize the logic of a program and aid in debugging by making the process of finding and fixing errors easier

3. Software and Programming Tools
- Software refers to the programs that run on a computer and enable functionality
- There are many programming tools available like code editors, debuggers, compilers, interpreters, etc. to help in the programming process
- Choosing the right programming tools depends on individual preferences, programming language, and project requirements
