### Static and dynamic routing for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

Routing is the process of forwarding data between networks, and is a key function of the network layer in computer networks. The following are some of the key concepts related to static and dynamic routing:

1. Routing Tables: Routing tables are used by routers to store information about the routes to different networks.

2. Static Routing: Static routing is a type of routing where the routes are manually configured by an administrator.

3. Dynamic Routing: Dynamic routing is a type of routing where the routes are automatically discovered and updated by the routers.

4. Routing Protocols: Routing protocols are used by routers to exchange information about the network topology, and to dynamically update the routing tables.

5. Distance-Vector Routing Protocols: Distance-vector routing protocols, such as Routing Information Protocol (RIP), calculate the best route based on the distance to the destination network.

6. Link-State Routing Protocols: Link-state routing protocols, such as Open Shortest Path First (OSPF), maintain a complete map of the network topology and calculate the best route based on the state of the links in the network.

In this unit, you will learn about static and dynamic routing in computer networking, including routing tables, static routing, dynamic routing, routing protocols, distance-vector routing protocols, and link-state routing protocols.

This unit will provide a foundation for understanding the principles and practices of routing in computer networking and for exploring the various concepts and techniques used in the field of computer networks.
