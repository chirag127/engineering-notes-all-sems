## Unit 3 - Link layer

The link layer is the second layer of the TCP/IP model in computer networking, and is responsible for transmitting data between devices on the same network segment. The following are some of the key concepts related to the link layer:

1. Network Interfaces: Network interfaces are the physical or logical connections between devices on a network, and are used by the link layer to transmit data.

2. MAC Addresses: MAC (Media Access Control) addresses are unique identifiers assigned to network interfaces, and are used by the link layer to identify devices on a network.

3. Data Link Protocols: Data link protocols are the protocols used by the link layer to transmit data between devices, such as Ethernet, Wi-Fi, and Bluetooth.

4. Error Detection and Correction: The link layer is responsible for detecting and correcting errors that occur during the transmission of data, such as bit errors and lost packets.

5. Flow Control: Flow control is the process of regulating the flow of data between devices to prevent overloading of the network.

6. Access Control: Access control is the process of regulating the access of devices to the network, such as through the use of media access control (MAC) protocols.

In this unit, you will learn about the link layer in computer networking, including network interfaces, MAC addresses, data link protocols, error detection and correction, flow control, and access control.

This unit will provide a foundation for understanding the principles and practices of the link layer in computer networking and for exploring the various concepts and techniques used in the field of computer networks.
