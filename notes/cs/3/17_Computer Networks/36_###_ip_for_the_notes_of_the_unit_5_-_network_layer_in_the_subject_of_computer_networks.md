### IP for the notes of the Unit 5 - Network Layer in the subject of Computer Networks

IP (Internet Protocol) is a network layer protocol in the TCP/IP model that is responsible for routing data between networks. The following are some of the key concepts related to IP:

1. IP Addresses: IP addresses are unique identifiers assigned to devices in a network, and are used by the network layer to route data between networks.

2. IP Packets: IP packets are the units of data that are transmitted between networks, and contain the source and destination IP addresses, along with other information.

3. Routing: Routing is the process of forwarding IP packets from one network to another, and is performed by routers in the network layer.

4. Subnetting: Subnetting is the process of dividing a network into smaller sub-networks, and is used to improve network performance and security.

5. Classful IP Addresses: Classful IP addresses are IP addresses that are divided into classes based on their size, and are used in the early days of the Internet.

6. Classless IP Addresses: Classless IP addresses are IP addresses that are not divided into classes, and are used in modern networks.

In this unit, you will learn about IP, including IP addresses, IP packets, routing, subnetting, classful IP addresses, and classless IP addresses.

This unit will provide a foundation for understanding the principles and practices of IP and for exploring the various concepts and techniques used in the field of computer networking.
