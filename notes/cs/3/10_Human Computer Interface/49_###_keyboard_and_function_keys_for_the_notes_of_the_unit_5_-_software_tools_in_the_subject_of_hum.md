### Keyboard and function keys for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

Unit 5 - Software Tools:
- Keyboard and Function Keys:
  1. Keyboard: A physical device used to input text and commands into a computer.
  2. Function Keys: Special keys located on the keyboard that perform specific functions, typically indicated by an F followed by a number.
  3. Common Function Keys: F1 (Help), F2 (Rename), F3 (Search), F4 (Close), etc.
  4. Keyboard Shortcuts: Combinations of keys used to perform specific functions, such as Control + C (Copy) or Control + V (Paste).

Note: Keyboard and function keys are important tools for inputting data and commands into a computer. This unit covers the basic concepts of keyboards and function keys, including common function keys and keyboard shortcuts.
