### Building Tools for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

Unit 5 - Software Tools:
- Building Tools:
  1. Integrated Development Environments (IDEs): Tools for developing, testing, and debugging software.
  2. Graphical User Interface (GUI) Builders: Tools for designing and building user interfaces.
  3. Code Libraries and Frameworks: Pre-written code that can be used to build interfaces more quickly and efficiently.
  4. Prototyping Tools: Tools for creating interactive prototypes of interfaces.

Note: Building tools are critical for the development of effective and user-friendly Human-Computer Interfaces (HCI). This unit covers the key types of building tools, including Integrated Development Environments (IDEs), Graphical User Interface (GUI) Builders, Code Libraries and Frameworks, and Prototyping Tools.
