### information retrieval on web for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

Unit 3 - Screen Designing:
- Information Retrieval on the Web:
  1. Search Engines: Tools that help users find information on the web.
  2. Search Engine Optimization (SEO): Techniques used to improve the visibility of a website in search engine results.
  3. Design Considerations: Information retrieval on the web should be efficient and effective, with clear and concise information and easy-to-use search tools.

Note: Information retrieval on the web is a critical component of user interface design, as it determines how users find and access information. This unit covers the key concepts of search engines, search engine optimization (SEO), and provides guidelines for designing effective information retrieval on the web.
