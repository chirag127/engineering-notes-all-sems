### Interaction Devices for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

Unit 5 - Software Tools:
- Interaction Devices:
  1. Mouse: A pointing device used to select and manipulate objects on a computer screen.
  2. Keyboard: An input device used to enter text and commands into a computer.
  3. Touchscreen: An input device that allows users to interact with a computer by touching the screen.
  4. Stylus: A pointing device used to select and manipulate objects on a touchscreen.
  5. Joystick: An input device used to control games and other applications.

Note: Interaction devices are an important component of human-computer interaction, as they determine how users interact with and control digital devices and systems. This unit covers the key interaction devices, including the mouse, keyboard, touchscreen, stylus, and joystick.
