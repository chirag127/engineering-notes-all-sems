### Building Tools for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

1. **Text editors** - These tools allow users to create and edit text documents. Examples include Notepad, Sublime Text, and Atom.
2. **Integrated Development Environments (IDEs)** - These tools provide a comprehensive environment for software development, including features such as code editing, debugging, and testing. Examples include Visual Studio, Eclipse, and PyCharm.
3. **Version control systems** - These tools help manage changes to source code over time, allowing multiple developers to collaborate on a project. Examples include Git, Mercurial, and Subversion.
4. **Debuggers** - These tools help developers find and fix errors in their code. Examples include GDB, WinDbg, and LLDB.
5. **Compilers** - These tools translate source code into machine-readable instructions that can be executed by a computer. Examples include GCC, Clang, and the Java Compiler.
6. **Build automation tools** - These tools automate the process of building software, including tasks such as compiling source code and packaging the resulting binaries. Examples include Make, Ant, and Gradle.
7. **Testing frameworks** - These tools provide a framework for writing and running automated tests to ensure that software is functioning correctly. Examples include JUnit, NUnit, and Mocha.
