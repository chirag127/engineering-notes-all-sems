### Unit 4 - Windows in Human Computer Interface

#### Uses:
- Windows provide a graphical user interface (GUI) for users to interact with the computer.
- Windows allow multiple applications to be open and visible at the same time, enabling multitasking.
- Windows provide a consistent and familiar interface for users to interact with different applications.
- Windows allow users to customize their desktop and personalize their computing experience.

#### Problems:
- Overlapping windows can cause confusion and make it difficult to find the desired application.
- Too many open windows can slow down the computer and affect performance.
- Inconsistent design and behavior of windows across different applications can cause confusion and frustration for users.
- Windows can be vulnerable to security threats such as viruses and malware.
