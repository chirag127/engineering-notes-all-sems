# Unit 1 - Introduction: Characteristics of Human Computer Interface

1. **Usability**: The interface should be easy to use and learn for the user.
2. **Efficiency**: The interface should allow the user to perform tasks quickly and accurately.
3. **Flexibility**: The interface should be able to adapt to the user's needs and preferences.
4. **Learnability**: The interface should be easy for the user to learn and remember how to use.
5. **Error Tolerance**: The interface should be designed to prevent errors and help the user recover from them if they do occur.
6. **Aesthetics**: The interface should be visually appealing and engaging to the user.
7. **Accessibility**: The interface should be accessible to users with disabilities or special needs.
8. **Consistency**: The interface should be consistent in its design and behavior across different tasks and contexts.
9. **Feedback**: The interface should provide clear and timely feedback to the user about their actions and the system's status.
10. **Affordance**: The interface should provide clear visual cues about how the user can interact with it.
