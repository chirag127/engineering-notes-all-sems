# Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. **Window Frame**: The frame is the outermost part of the window that holds the panes of glass in place and provides structure to the window.
2. **Title Bar**: The title bar is the horizontal bar at the top of a window that displays the name of the window and typically contains buttons for minimizing, maximizing, and closing the window.
3. **Menu Bar**: The menu bar is the horizontal bar below the title bar that contains drop-down menus for accessing the various functions of the application.
4. **Toolbar**: The toolbar is a row of icons below the menu bar that provides quick access to commonly used functions.
5. **Status Bar**: The status bar is the horizontal bar at the bottom of the window that displays information about the current state of the application or document.
6. **Scroll Bar**: The scroll bar is the vertical or horizontal bar on the right or bottom of the window that allows the user to scroll the contents of the window.
7. **Minimize, Maximize, and Close Buttons**: These buttons are typically located in the top right corner of the window and allow the user to minimize, maximize, or close the window.
8. **Resize Handle**: The resize handle is the small triangle in the bottom right corner of the window that allows the user to resize the window by clicking and dragging.
9. **Client Area**: The client area is the main area of the window where the content is displayed.
