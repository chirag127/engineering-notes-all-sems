### Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. **Window**: A window is a graphical user interface element that displays the contents of an application or a document. It is a rectangular area on the screen that can be moved, resized, and closed by the user.
2. **Title bar**: The title bar is the horizontal bar at the top of a window that displays the name of the window. It also contains buttons for minimizing, maximizing, and closing the window.
3. **Menu bar**: The menu bar is a horizontal bar that contains drop-down menus for accessing the commands and functions of an application.
4. **Toolbar**: A toolbar is a graphical control element that contains buttons or icons that provide quick access to commonly used commands or functions.
5. **Status bar**: The status bar is a horizontal bar at the bottom of a window that displays information about the current state of the application or document.
6. **Scroll bar**: A scroll bar is a graphical control element that allows the user to scroll the contents of a window or a document.
7. **Resize handle**: The resize handle is a small graphical control element located at the bottom right corner of a window that allows the user to resize the window.
8. **Client area**: The client area is the main area of a window where the contents of the application or document are displayed.
