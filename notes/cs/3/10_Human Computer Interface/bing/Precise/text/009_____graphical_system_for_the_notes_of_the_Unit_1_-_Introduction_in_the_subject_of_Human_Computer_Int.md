### Graphical System for the Notes of Unit 1 - Introduction in the Subject of Human Computer Interface

1. A graphical system is a computer program that enables users to interact with a computer through a graphical user interface (GUI).
2. GUIs provide a visual way for users to interact with the computer, using windows, icons, menus, and other graphical elements.
3. GUIs are designed to be intuitive and easy to use, allowing users to perform tasks without having to memorize complex commands or navigate through multiple menus.
4. GUIs are commonly used in operating systems, applications, and websites, and have become the standard way for users to interact with computers.
5. In the context of Human Computer Interface, a graphical system is an important tool for designing and implementing user-friendly interfaces that improve the user experience.
6. Unit 1 - Introduction in the subject of Human Computer Interface covers the basics of graphical systems and their role in improving the interaction between humans and computers.
7. Key concepts covered in this unit include the history and evolution of graphical systems, the principles of good interface design, and the use of graphical systems in various applications and contexts.
8. By studying this unit, students will gain a solid understanding of the importance of graphical systems in the field of Human Computer Interface and be able to apply this knowledge in the design and evaluation of user interfaces.
