### New and Navigation schemes selection of window for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

- A window is a rectangular area on the screen that displays information and allows interaction with an application or a document.
- Windows can have different types, sizes, shapes, and styles depending on the purpose and functionality of the application or the document.
- Windows can also have different components, such as title bar, menu bar, toolbar, status bar, scroll bar, etc. that provide additional information and control options for the user.
- New and navigation schemes are the ways of creating, opening, closing, and switching between windows in an application or a document.
- New and navigation schemes can affect the usability, efficiency, and satisfaction of the user, as well as the consistency and coherence of the application or the document.
- Some of the common new and navigation schemes are:

  - Single document interface (SDI): Each document or task is displayed in a separate window that can be moved, resized, and closed independently. The user can switch between windows using the taskbar or the keyboard shortcuts. Examples: Notepad, Paint, Calculator, etc.
  - Multiple document interface (MDI): Multiple documents or tasks are displayed within a single parent window that contains a menu bar and a toolbar for the application. The user can arrange the child windows using the window menu or the buttons on the right corner of the parent window. Examples: Microsoft Word, Excel, PowerPoint, etc.
  - Tabbed document interface (TDI): Multiple documents or tasks are displayed within a single window that contains a tab bar at the top or the bottom. The user can switch between tabs by clicking on them or using the keyboard shortcuts. Examples: Web browsers, text editors, etc.
  - Cascading windows: Windows are overlapped in a diagonal or a horizontal manner, such that the title bars of all windows are visible. The user can bring a window to the front by clicking on its title bar or using the keyboard shortcuts. Examples: File Explorer, Control Panel, etc.
  - Tiled windows: Windows are arranged in a grid-like manner, such that no window overlaps another. The user can resize and rearrange the windows by dragging their borders or using the keyboard shortcuts. Examples: Windows 10 Snap feature, etc.
  - Stacked windows: Windows are stacked vertically or horizontally, such that only one window is fully visible at a time. The user can switch between windows by clicking on the tabs or the buttons on the side of the stack. Examples: Windows 10 Task View feature, etc.
