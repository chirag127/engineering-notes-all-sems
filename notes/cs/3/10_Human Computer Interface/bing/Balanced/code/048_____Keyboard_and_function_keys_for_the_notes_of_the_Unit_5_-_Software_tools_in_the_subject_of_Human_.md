### Keyboard and function keys

- A keyboard is a device input device for data entry that uses an organization of keys/buttons that serves as a mechanical device for a computer .
- Each key in a keyboard corresponds to a single written symbol or character.
- The main types of keyboard keys are functional, alphanumeric, formatting, special, and numeric among many others.
- Functional keyboard keys: they range from F1 to F12 and they are found at the top of the keyboard. They are used for specific functions which are mostly programmed for them .
  - For example, F1 is used for Help in the Window Operating system, F5 is used for refresh, F11 is used for full screen mode, etc.
  - The functionality of these keys differs from program to program.
- Alphanumeric keyboard keys: they include the letters from A to Z and the numbers from 0 to 9. They are used for typing text and numbers.
- Formatting keyboard keys: they include the Shift, Ctrl, Alt, Tab, Caps Lock, Enter, and Backspace keys. They are used for modifying the appearance or layout of the text or data .
  - For example, Shift is used for capitalizing letters or accessing symbols, Ctrl is used for keyboard shortcuts, Alt is used for accessing menus, Tab is used for moving between fields or indents, etc .
- Special keyboard keys: they include the Esc, Print Screen, Scroll Lock, Pause, Insert, Home, End, Page Up, Page Down, Delete, and the Windows logo key. They are used for performing specific tasks or commands .
  - For example, Esc is used for canceling or closing a window, Print Screen is used for capturing the screen image, Scroll Lock is used for locking the scrolling of the screen, Pause is used for pausing a program, etc .
- Numeric keyboard keys: they include the numbers from 0 to 9 and the symbols +, -, *, /, ., and Enter. They are found on the right side of the keyboard and they are used for entering numbers or performing calculations.
  - Some keyboards have a Fn key that can be pressed and held while pressing keyboard letters M, J, K, L, U, I, O, P, /, ;, and 0 to match the physical layout of a numeric keypad.
- Some keyboards have an F Lock key that can be pressed to toggle between the standard commands and alternate commands of the function keys.
