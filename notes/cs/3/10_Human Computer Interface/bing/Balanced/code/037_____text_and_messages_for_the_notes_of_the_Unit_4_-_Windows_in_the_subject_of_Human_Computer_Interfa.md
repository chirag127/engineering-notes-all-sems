# Text and Messages for the Notes of the Unit 4 - Windows in the Subject of Human Computer Interface

- Text and messages are two types of user interface elements that are used to display or communicate information to the user in a window-based system.
- Text can be static or dynamic, depending on whether it changes or not during the interaction. Static text is usually used to label controls, provide instructions, or display constant information. Dynamic text is usually used to show variable information, such as the status of a process, the result of a calculation, or the input from the user.
- Messages are notifications or alerts that are displayed to the user in response to some events, such as errors, warnings, confirmations, or requests. Messages can be modal or modeless, depending on whether they block the user from interacting with other windows or not. Modal messages require the user to acknowledge them before continuing, while modeless messages allow the user to ignore them or dismiss them later.
- Text and messages should follow some general guidelines to ensure usability and clarity, such as:
  - Use simple and concise language that is appropriate for the target audience and the context of the interaction.
  - Use consistent terminology and formatting throughout the interface.
  - Use positive and polite tone and avoid blaming or criticizing the user.
  - Use appropriate font size, style, color, and alignment to enhance readability and contrast.
  - Use appropriate icons, symbols, or graphics to supplement or replace text when possible.
  - Use appropriate punctuation, capitalization, and grammar to avoid ambiguity and confusion.
  - Provide feedback and confirmation to the user when an action is performed or a message is received.
  - Provide clear and actionable instructions or options to the user when a message is displayed.
  - Avoid displaying unnecessary or redundant text or messages that may distract or annoy the user.
