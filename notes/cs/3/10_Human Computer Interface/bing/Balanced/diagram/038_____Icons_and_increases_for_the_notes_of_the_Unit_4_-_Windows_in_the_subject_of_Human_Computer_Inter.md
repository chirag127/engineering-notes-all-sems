### Icons and Interfaces for Windows

- Icons are visual images and symbols that help users understand and move through an app.
- Icons are used as metaphors that represent a concept, action, or status.
- Windows 11 uses three types of icons: application, system, and file type.
- Application icons identify an app and communicate its brand and personality.
- System icons are used in common controls, menus, dialogs, and notifications .
- File type icons indicate the format and content of a file.
- Icons should be clear, consistent, familiar, and scalable .
- Icons should follow the Fluent Design System guidelines for color, shape, size, and style.
- Icons can be customized by the user using the Settings app or third-party programs.
- There are many icon packs available online that offer different themes and aesthetics for Windows 11.
