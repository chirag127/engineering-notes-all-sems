# Specification methods for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

- Specification methods are techniques that can be used to describe human-computer interfaces in a precise and unambiguous way.
- Specification methods can help to design, implement, test, and evaluate interfaces, as well as to communicate and document them.
- Specification methods can be classified into two categories, according to their underlying formal models: state transition diagrams and BNF.

## State transition diagrams
- State transition diagrams are graphical representations of the states and events of an interface, and the transitions between them.
- States are the possible configurations of the interface, such as the display of a menu, a dialog box, or a message.
- Events are the user actions or system responses that trigger a change of state, such as clicking a button, entering a command, or receiving an error message.
- Transitions are the links between states, indicating the conditions and actions that occur when an event happens.
- State transition diagrams can show the dynamic behavior and logic of an interface, as well as the possible user paths and system feedback.
- State transition diagrams can be used to specify the functionality, usability, and reliability of an interface, as well as to test and debug it.

## BNF
- BNF stands for Backus-Naur form, a notation for defining the syntax of a language or a grammar.
- BNF uses symbols and rules to describe the structure and elements of a language, such as the keywords, operators, variables, and expressions.
- BNF can be used to specify the syntax of an interface, such as the commands, parameters, and options that the user can enter, or the menus, icons, and widgets that the user can select.
- BNF can show the static structure and components of an interface, as well as the possible user inputs and system outputs.
- BNF can be used to specify the consistency, clarity, and efficiency of an interface, as well as to parse and validate it.
