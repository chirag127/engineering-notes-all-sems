## Unit 4 - Windows

- A window is a graphical user interface (GUI) element that displays the content of an application or a file.
- A window can have various components, such as a title bar, a menu bar, a toolbar, a status bar, a scroll bar, a minimize button, a maximize button, a close button, and a resize handle.
- A window can be moved, resized, minimized, maximized, restored, closed, or hidden by the user or the application.
- A window can have different states, such as active, inactive, foreground, background, modal, or modeless.
- A window can have different styles, such as borderless, resizable, fixed, or transparent.
- A window can have different types, such as main, child, dialog, pop-up, or message box.
- A window can have different behaviors, such as always on top, always on bottom, or stay on desktop.
- A window can have different events, such as create, destroy, show, hide, move, resize, activate, deactivate, minimize, maximize, restore, close, or paint.
- A window can have different messages, such as WM_CREATE, WM_DESTROY, WM_SHOWWINDOW, WM_HIDEWINDOW, WM_MOVE, WM_SIZE, WM_ACTIVATE, WM_DEACTIVATE, WM_MINIMIZE, WM_MAXIMIZE, WM_RESTORE, WM_CLOSE, or WM_PAINT.
- A window can have different properties, such as handle, title, text, icon, cursor, font, color, or style.
- A window can have different methods, such as show, hide, move, resize, minimize, maximize, restore, close, or repaint.
- A window can have different functions, such as GetWindowHandle, GetWindowTitle, GetWindowText, SetWindowTitle, SetWindowText, GetWindowIcon, SetWindowIcon, GetWindowCursor, SetWindowCursor, GetWindowFont, SetWindowFont, GetWindowColor, SetWindowColor, GetWindowStyle, SetWindowStyle, ShowWindow, HideWindow, MoveWindow, ResizeWindow, MinimizeWindow, MaximizeWindow, RestoreWindow, CloseWindow, or RepaintWindow.
