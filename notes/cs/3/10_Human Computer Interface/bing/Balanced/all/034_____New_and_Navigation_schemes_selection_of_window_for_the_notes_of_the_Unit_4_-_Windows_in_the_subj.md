# New and Navigation schemes selection of window for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

- A window is a rectangular area on the screen that displays information and allows interaction with an application or a document.
- Windows can have different sizes, shapes, styles, and functions depending on the context and the user's needs.
- Windows can be classified into three main types: primary, secondary, and modal.
- Primary windows are the main windows that provide access to the core functionality of an application or a document. They usually have a title bar, a menu bar, a toolbar, a status bar, and a scroll bar.
- Secondary windows are the windows that provide additional information or functionality that is related to the primary window. They can be opened and closed independently of the primary window. They usually have a title bar, a close button, and sometimes a menu bar or a toolbar.
- Modal windows are the windows that require the user's attention and block the interaction with the primary window until they are closed. They are used to display important messages, warnings, errors, or requests for input. They usually have a title bar, a close button, and sometimes an icon or a text label.
- Navigation schemes are the ways that users can move between windows and access different information or functionality within an application or a document.
- Navigation schemes can be classified into four main types: menu-based, toolbar-based, tab-based, and hyperlink-based.
- Menu-based navigation schemes use menus to display a list of commands or options that the user can select from. Menus can be either pull-down, pop-up, or cascading. Pull-down menus are attached to the menu bar and are displayed when the user clicks on a menu item. Pop-up menus are displayed when the user right-clicks on an object or an area on the screen. Cascading menus are submenus that are displayed when the user selects a menu item that has a right-pointing arrow.
- Toolbar-based navigation schemes use toolbars to display a row or a column of icons or buttons that represent commands or options that the user can click on. Toolbars can be either fixed or customizable. Fixed toolbars are always visible and cannot be moved or modified by the user. Customizable toolbars can be hidden, shown, moved, or modified by the user according to their preferences.
- Tab-based navigation schemes use tabs to display a set of pages or panels that contain different information or functionality that the user can switch between. Tabs can be either horizontal or vertical. Horizontal tabs are arranged along the top or the bottom of the window and are labeled with text or icons. Vertical tabs are arranged along the left or the right side of the window and are labeled with text or icons.
- Hyperlink-based navigation schemes use hyperlinks to display a word, a phrase, an image, or an icon that the user can click on to access another window, document, or web page. Hyperlinks can be either embedded or external. Embedded hyperlinks are contained within the same window or document and are usually highlighted or underlined. External hyperlinks are contained in a different window, document, or web page and are usually indicated by a different color or an icon.
