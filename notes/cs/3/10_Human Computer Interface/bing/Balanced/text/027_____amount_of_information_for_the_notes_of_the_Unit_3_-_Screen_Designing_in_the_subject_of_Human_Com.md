### Amount of information for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

- Screen designing is the process of creating the layout, appearance, and functionality of the user interface (UI) for a software application or a website.
- Screen designing involves the following steps:
  - Define the goals and requirements of the UI, such as the target audience, the tasks to be performed, the information to be displayed, and the constraints to be considered.
  - Sketch the ideas and concepts for the UI, using low-fidelity prototypes such as paper sketches, wireframes, or mockups.
  - Evaluate the usability and effectiveness of the UI, using methods such as heuristic evaluation, user testing, or feedback surveys.
  - Refine and improve the UI, using high-fidelity prototypes such as interactive or graphical models, and applying design principles and guidelines.
  - Implement and test the UI, using appropriate tools and technologies, and ensuring the compatibility and accessibility of the UI across different devices and platforms.
- Screen designing requires the knowledge and skills of various disciplines, such as graphic design, human-computer interaction, psychology, and computer science.
- Screen designing is influenced by various factors, such as the context of use, the user characteristics, the content and functionality, and the design trends and standards.
- Screen designing aims to achieve the following objectives:
  - Enhance the user experience (UX) by making the UI easy to use, learn, and remember, and by satisfying the user needs and expectations.
  - Increase the user engagement by making the UI attractive, appealing, and enjoyable, and by providing feedback and rewards.
  - Support the user goals by making the UI efficient, effective, and error-free, and by providing guidance and assistance.
  - Communicate the message and meaning by making the UI clear, consistent, and coherent, and by using appropriate visual elements and language.
  - Reflect the identity and brand by making the UI distinctive, recognizable, and trustworthy, and by using consistent style and tone.
