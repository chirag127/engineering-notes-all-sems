## Unit 3 - Screen Designing

- Screen designing is the process of creating the visual layout and appearance of a user interface for an application or a website.
- Screen designing involves the following steps:
  - Define the purpose and goals of the application or website.
  - Identify the target audience and their needs, preferences, and expectations.
  - Sketch the basic structure and navigation of the application or website using wireframes or mockups.
  - Choose the appropriate colors, fonts, images, icons, and other visual elements that suit the theme and mood of the application or website.
  - Apply the principles of visual design, such as contrast, alignment, balance, hierarchy, consistency, and simplicity, to enhance the usability and aesthetics of the application or website.
  - Test the screen design with users and stakeholders and collect feedback to improve the design.
- Screen designing requires the use of various tools and techniques, such as:
  - Graphic design software, such as Adobe Photoshop, Illustrator, or Sketch, to create and edit the visual elements of the screen design.
  - Prototyping software, such as Adobe XD, Figma, or InVision, to create interactive and realistic simulations of the screen design.
  - User interface design patterns, such as menus, tabs, buttons, forms, dialogs, etc., to provide common and familiar solutions for common user interface problems.
  - User interface design guidelines, such as Material Design, iOS Human Interface Guidelines, or Windows Design Principles, to follow the best practices and standards for designing user interfaces for specific platforms and devices.
  - User interface design principles, such as clarity, feedback, efficiency, learnability, etc., to ensure that the screen design meets the user's needs and expectations.
