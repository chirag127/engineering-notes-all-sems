## Unit 4 - Windows

### Introduction

Windows is an operating system developed by Microsoft that runs on personal computers, laptops, tablets, and other devices. Windows provides a graphical user interface (GUI) that allows users to interact with the system and applications using a mouse, keyboard, touch screen, or voice commands. Windows also supports various features and functions, such as file management, networking, security, multimedia, web browsing, gaming, and more.

### History

- The first version of Windows, Windows 1.0, was released in 1985 as an extension of the MS-DOS operating system. It offered a graphical environment with windows, icons, menus, and a mouse support.
- Windows 2.0, released in 1987, introduced overlapping windows, keyboard shortcuts, and the Control Panel.
- Windows 3.0, released in 1990, improved the performance and memory management of Windows and added features such as Program Manager, File Manager, and Print Manager.
- Windows 3.1, released in 1992, added support for TrueType fonts, multimedia, and networking.
- Windows 95, released in 1995, was the first version of Windows to have a Start menu, a taskbar, and a built-in web browser. It also supported long file names, plug and play devices, and 32-bit applications.
- Windows 98, released in 1998, enhanced the user interface and the web integration of Windows 95 and added features such as Active Desktop, Internet Explorer 4, and Windows Update.
- Windows ME, released in 2000, was the last version of Windows based on the MS-DOS kernel. It focused on multimedia and home users and introduced features such as System Restore, Windows Movie Maker, and Windows Media Player.
- Windows 2000, released in 2000, was the first version of Windows based on the NT kernel. It was designed for business and professional users and offered improved stability, security, and performance. It also supported features such as Active Directory, Encrypting File System, and Remote Desktop.
- Windows XP, released in 2001, was the most popular and widely used version of Windows. It combined the features and user interface of Windows 2000 and Windows ME and added features such as Fast User Switching, Windows Firewall, and Windows Media Center.
- Windows Vista, released in 2007, introduced a new user interface called Aero, which had transparent and animated effects. It also added features such as User Account Control, Windows Defender, Windows Sidebar, and Windows Search.
- Windows 7, released in 2009, improved the performance and usability of Windows Vista and added features such as Jump Lists, Snap, Shake, Peek, and Libraries.
- Windows 8, released in 2012, introduced a new user interface called Metro, which was optimized for touch screen devices. It also added features such as Start Screen, Live Tiles, Charms Bar, and Windows Store.
- Windows 8.1, released in 2013, addressed some of the criticisms and issues of Windows 8 and added features such as Start Button, Boot to Desktop, and Bing Smart Search.
- Windows 10, released in 2015, is the latest and current version of Windows. It combines the features and user interface of Windows 7 and Windows 8 and added features such as Cortana, Microsoft Edge, Continuum, and Windows Hello. It also introduced a new update model called Windows as a Service, which delivers regular and incremental updates to Windows 10.

### Components

Windows consists of several components that work together to provide the functionality and user experience of the operating system. Some of the main components are:

- Kernel: The core of the operating system that manages the system resources, such as memory, CPU, disk, and devices. It also provides services and interfaces for other components and applications to access the system resources.
- Shell: The component that provides the graphical user interface and the user interaction with the system and applications. It includes the Start menu, the taskbar, the desktop, the explorer, and the command prompt.
- Registry: The component that stores the configuration and settings of the system and applications. It is organized as a hierarchical database of keys and values that can be accessed and modified by the system and applications.
- Services: The component that provides background processes and functions that run independently of the user session and can be started and stopped by the system or the user. They include services such as Windows Update, Windows Firewall, and Windows Search.
