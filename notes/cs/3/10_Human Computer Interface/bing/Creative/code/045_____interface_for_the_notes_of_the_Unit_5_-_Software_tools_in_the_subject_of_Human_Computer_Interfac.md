# Unit 5 - Software tools

## Introduction

- Software tools are applications or programs that help users to create, design, evaluate, or implement human-computer interfaces (HCI).
- Software tools can be classified into different categories based on their functions, such as prototyping tools, evaluation tools, implementation tools, or integrated tools.
- Software tools can also be classified based on their level of abstraction, such as low-fidelity tools, medium-fidelity tools, or high-fidelity tools.
- Software tools can have various benefits for HCI, such as reducing development time and cost, improving usability and user satisfaction, supporting collaboration and communication, or facilitating creativity and innovation.

## Prototyping tools

- Prototyping tools are software tools that help users to create mock-ups or sketches of the interface design, without requiring coding or programming skills.
- Prototyping tools can be used to explore different design alternatives, communicate design ideas, test design concepts, or collect feedback from users or stakeholders.
- Prototyping tools can range from low-fidelity tools, such as paper and pencil, to high-fidelity tools, such as interactive simulations or animations.
- Some examples of prototyping tools are Balsamiq, Adobe XD, Figma, Sketch, or InVision.

## Evaluation tools

- Evaluation tools are software tools that help users to assess the usability, accessibility, or effectiveness of the interface design, using various methods or techniques.
- Evaluation tools can be used to identify and fix design problems, measure user performance and satisfaction, or compare different design alternatives.
- Evaluation tools can be classified into two types: formative tools and summative tools.
- Formative tools are used during the design process to provide feedback and guidance for improvement, such as heuristic evaluation, usability testing, or cognitive walkthrough.
- Summative tools are used at the end of the design process to measure the final outcome and quality of the design, such as usability metrics, user surveys, or user reviews.
- Some examples of evaluation tools are UsabilityHub, UserTesting, Hotjar, Google Analytics, or Qualtrics.

## Implementation tools

- Implementation tools are software tools that help users to translate the interface design into a functional and interactive system, using coding or programming languages.
- Implementation tools can be used to create the interface layout, style, behavior, or functionality, using various frameworks, libraries, or platforms.
- Implementation tools can be classified into two types: front-end tools and back-end tools.
- Front-end tools are used to create the user-facing part of the interface, such as HTML, CSS, JavaScript, or React.
- Back-end tools are used to create the server-side part of the interface, such as PHP, Python, Ruby, or Node.js.
- Some examples of implementation tools are Visual Studio Code, Sublime Text, Bootstrap, jQuery, or Firebase.

## Integrated tools

- Integrated tools are software tools that combine the functions of prototyping, evaluation, and implementation tools, into a single platform or environment.
- Integrated tools can be used to create, design, test, and deploy the interface, using a unified and consistent workflow.
- Integrated tools can have various advantages, such as simplifying the development process, reducing the need for switching between different tools, or enabling seamless collaboration and integration.
- Some examples of integrated tools are Microsoft Visual Studio, Adobe Dreamweaver, Webflow, or Bubble.
