### Image and Video Displays for the Notes of the Unit 5 - Software Tools in the Subject of Human Computer Interface

- Image and video displays are types of screenless displays that use different technologies to project images or videos onto various surfaces or into the air without using a physical screen.
- Image and video displays can be used for various purposes in human-computer interaction (HCI), such as enhancing the user experience, providing feedback, creating immersive environments, or facilitating communication.
- Image and video displays can be classified into three categories based on the type of projection: visual image, retinal, and synaptic.
  - Visual image displays use lasers, holograms, or mirrors to create images or videos that can be seen by the human eye without any special device. Examples of visual image displays are holographic displays, virtual reality goggles, heads up displays, etc .
  - Retinal displays use low-power lasers or LEDs to scan images or videos directly onto the retina of the eye. Examples of retinal displays are Google Glass, EyeTap, etc.
  - Synaptic displays use electrical or magnetic stimulation to create images or videos in the brain. Examples of synaptic displays are brain-computer interfaces, neural implants, etc.
- Image and video displays can also be classified into two categories based on the distance from the user: close view and distant view.
  - Close view displays are used for applications that require the user to interact with the computer in a close range, such as desktop computer applications or mobile phone interfaces. Examples of close view displays are webcams, touchscreens, gesture recognition, etc.
  - Distant view displays are used for applications that require the user to interact with the computer in a large space, such as smart rooms, augmented reality games, or public displays. Examples of distant view displays are cameras, projectors, motion sensors, etc.
- Image and video displays can be evaluated based on various criteria, such as resolution, brightness, contrast, color, refresh rate, latency, power consumption, portability, cost, etc.
- Image and video displays can be designed based on various principles of HCI, such as usability, user satisfaction, user engagement, user needs, user preferences, user feedback, user context, etc.
