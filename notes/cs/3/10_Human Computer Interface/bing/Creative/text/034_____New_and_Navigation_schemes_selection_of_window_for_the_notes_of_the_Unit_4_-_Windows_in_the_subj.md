### New and Navigation schemes selection of window

- Windows are graphical user interface elements that allow users to view and interact with multiple applications or documents on a single screen.
- Windows can have different characteristics, such as size, shape, position, title, border, scroll bars, menus, icons, etc.
- Windows can also have different presentation styles, such as tiled, cascaded, overlapping, modal, modeless, etc.
- Windows can also have different types, such as primary, secondary, dialog, pop-up, palette, etc.
- Windows can be managed by the user or the system, depending on the window operations, such as opening, closing, moving, resizing, minimizing, maximizing, etc.
- Windows can also be organized by the user or the system, depending on the window functions, such as switching, arranging, grouping, etc.
- Navigation schemes are the methods or techniques that allow users to move from one window to another, or within a window, using various input devices or screen-based controls.
- Navigation schemes can be classified into two categories: window-based and content-based.
- Window-based navigation schemes are those that use the window itself or its components as the means of navigation, such as title bars, menus, scroll bars, etc.
- Content-based navigation schemes are those that use the content of the window or its elements as the means of navigation, such as hyperlinks, buttons, tabs, etc.
- The selection of window and navigation schemes depends on several factors, such as the user's goals, tasks, preferences, skills, etc., the application's functionality, complexity, structure, etc., and the system's capabilities, constraints, standards, etc.
- The selection of window and navigation schemes should follow some general principles, such as consistency, simplicity, efficiency, feedback, flexibility, etc.
