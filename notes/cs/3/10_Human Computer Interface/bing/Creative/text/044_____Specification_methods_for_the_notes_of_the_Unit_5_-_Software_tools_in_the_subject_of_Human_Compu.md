### Specification methods for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

- Specification methods are techniques for describing the requirements and design of a software system in a precise and unambiguous way.
- Specification methods can be classified into two main categories: formal and informal.
- Formal methods use mathematical notation and logic to specify the syntax and semantics of a software system. Formal methods can be used to verify the correctness and consistency of a specification, and to derive implementations from specifications. Formal methods can also support automated analysis, testing, and verification of software systems.
- Informal methods use natural language, diagrams, and other graphical notations to specify the software system. Informal methods are more intuitive and easier to understand by humans, but they can also be ambiguous, incomplete, and inconsistent. Informal methods can be used to communicate the requirements and design of a software system to stakeholders, and to elicit feedback and validation from them.
- Some examples of formal methods are: Z, VDM, B, Alloy, and UML/OCL.
- Some examples of informal methods are: user stories, use cases, scenarios, flowcharts, and wireframes.
- Software tools are applications that support the development, maintenance, and evaluation of software systems. Software tools can be used to create, edit, analyze, test, and verify specifications, as well as to generate code, documentation, and user interfaces from specifications.
- Software tools can be classified into two main categories: generic and domain-specific.
- Generic tools are tools that can be used for any kind of software system, regardless of the application domain, programming language, or specification method. Generic tools can provide general functionality such as text editing, syntax highlighting, debugging, version control, and project management.
- Domain-specific tools are tools that are tailored for a specific application domain, programming language, or specification method. Domain-specific tools can provide specialized functionality such as syntax checking, semantic analysis, code generation, simulation, and verification.
- Some examples of generic tools are: Notepad++, Eclipse, Visual Studio, Git, and Jira.
- Some examples of domain-specific tools are: Z/EVES, VDMTools, ProB, Alloy Analyzer, and Papyrus.
