### Screen navigation and flow for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

- Screen navigation and flow refer to the way users move through the screens of an application or a website, and how the screens are connected and organized.
- Screen navigation and flow are important aspects of screen design, as they affect the usability, efficiency, and user satisfaction of the application or website.
- Screen navigation and flow can be designed using various methods and techniques, such as:
  - Hierarchical navigation: The screens are arranged in a tree-like structure, where each screen has a parent screen and may have one or more child screens. The user can navigate from the parent screen to the child screens, or from the child screens to the parent screen. This method is suitable for applications or websites that have a clear and logical hierarchy of information or tasks, such as e-commerce, education, or news websites.
  - Sequential navigation: The screens are arranged in a linear sequence, where the user can navigate from one screen to the next screen, or from the previous screen to the current screen. This method is suitable for applications or websites that have a fixed or predefined order of steps or stages, such as online forms, surveys, or tutorials.
  - Parallel navigation: The screens are arranged in a parallel or horizontal layout, where the user can navigate from one screen to another screen at the same level, without going back to the parent screen. This method is suitable for applications or websites that have multiple options or alternatives for the user to choose from, such as social media, entertainment, or gaming websites.
  - Global navigation: The screens are connected by a common or consistent element, such as a menu bar, a toolbar, a footer, or a logo, that allows the user to access any screen from any screen. This method is suitable for applications or websites that have a large number of screens or features, or that require frequent switching between screens, such as web browsers, email clients, or productivity tools.
- Screen navigation and flow should be designed according to the following principles and guidelines:
  - Simplicity: The screen navigation and flow should be easy to understand and use, and avoid unnecessary complexity or confusion. The number of screens, navigation options, and navigation levels should be minimized and optimized, and the navigation labels and icons should be clear and descriptive.
  - Consistency: The screen navigation and flow should be consistent and coherent across the application or website, and follow the established conventions and standards of the platform, domain, and genre. The navigation elements, such as menus, buttons, links, and gestures, should be uniform and predictable, and the navigation feedback, such as highlights, transitions, and sounds, should be appropriate and informative.
  - Visibility: The screen navigation and flow should be visible and accessible to the user, and avoid hidden or obscure navigation elements. The navigation elements should be placed in prominent and intuitive locations, and the navigation paths and states should be indicated and highlighted.
  - Flexibility: The screen navigation and flow should be flexible and adaptable to the user's needs, preferences, and situations, and allow the user to control and customize the navigation. The navigation elements should be responsive and adjustable to different screen sizes, orientations, and resolutions, and the navigation paths and states should be reversible and recoverable.
