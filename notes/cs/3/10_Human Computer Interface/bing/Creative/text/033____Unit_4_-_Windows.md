## Unit 4 - Windows

- Windows is an operating system developed by Microsoft that runs on personal computers, laptops, tablets, and other devices.
- Windows provides a graphical user interface (GUI) that allows users to interact with the system and applications using windows, icons, menus, and pointers.
- Windows also provides various services and features, such as file management, security, networking, multimedia, device drivers, and system utilities.
- Windows is the most widely used operating system in the world, with different versions and editions for different markets and needs.
- Some of the popular versions of Windows are Windows 10, Windows 8.1, Windows 7, Windows Vista, Windows XP, and Windows Server.
- Windows 10 is the latest version of Windows, released in 2015, that offers a unified platform for various devices, such as PCs, tablets, smartphones, and Xbox.
- Windows 10 introduces new features, such as Cortana, a personal assistant that can perform tasks and answer questions using voice or text input, Microsoft Edge, a web browser that replaces Internet Explorer, and Windows Hello, a biometric authentication system that uses facial recognition or fingerprint scanning to log in to the system or apps.
- Windows 10 also supports multiple desktops, a feature that allows users to create and switch between different workspaces, and Continuum, a feature that adapts the user interface depending on the device mode, such as tablet mode or desktop mode.
- Windows 10 is divided into several editions, such as Windows 10 Home, Windows 10 Pro, Windows 10 Enterprise, Windows 10 Education, and Windows 10 Mobile, each with different features and functionalities.
- Windows 10 can be installed or upgraded from previous versions of Windows using a DVD, a USB flash drive, or an online download. Windows 10 can also be activated using a product key, a digital license, or a Microsoft account.
