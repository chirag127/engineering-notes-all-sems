### Amount of information for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

- Screen designing is the process of creating the visual layout and appearance of a user interface for a software application or a website.
- Screen designing involves the following steps:
  - Define the goals and requirements of the user interface, such as the target audience, the tasks to be performed, the information to be displayed, and the constraints and limitations of the system.
  - Sketch the basic structure and layout of the user interface, such as the navigation, the menus, the buttons, the input fields, and the feedback mechanisms.
  - Choose the appropriate visual elements and styles for the user interface, such as the colors, the fonts, the icons, the images, and the animations.
  - Implement and test the user interface using prototyping tools or programming languages, and evaluate its usability, functionality, and aesthetics.
- Screen designing is influenced by the following factors:
  - The principles and guidelines of human-computer interaction, such as consistency, feedback, visibility, affordance, and user control.
  - The standards and conventions of the platform, the domain, and the culture, such as the common widgets, the terminology, the symbols, and the formats.
  - The user characteristics and preferences, such as the age, the gender, the education, the experience, and the expectations.
  - The context and environment of use, such as the device, the screen size, the resolution, the brightness, and the noise level.
- Screen designing is evaluated by the following criteria:
  - The usability of the user interface, which refers to how easy, efficient, and satisfying it is for the users to achieve their goals and complete their tasks.
  - The functionality of the user interface, which refers to how well it performs the intended functions and meets the requirements and specifications of the system.
  - The aesthetics of the user interface, which refers to how pleasing, attractive, and appealing it is for the users and the stakeholders.
