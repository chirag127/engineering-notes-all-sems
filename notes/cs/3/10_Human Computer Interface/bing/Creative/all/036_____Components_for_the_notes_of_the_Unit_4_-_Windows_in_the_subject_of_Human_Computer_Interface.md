# Components of Windows in Human Computer Interface

Windows are graphical user interface elements that allow users to interact with programs and data on a computer screen. Windows are managed by a window manager as part of a windowing system. Windows can have various components that enable user input, output, and manipulation. Some of the common components of windows in human computer interface are:

- **Pointer**: A symbol that appears on the screen and that you move to select objects and commands. The pointer can be controlled by a mouse, a touchpad, a trackball, a stylus, or other pointing devices.
- **Icon**: A small graphical representation of a program, a file, a folder, or other objects. Icons can be clicked or dragged to launch or manipulate the corresponding objects.
- **Menu**: A set of options presented to the user, to help with the execution of the program. Menus can be displayed as a horizontal or vertical bar, a drop-down list, a pop-up window, or a context-sensitive menu.
- **Scroll bar**: A graphical element that allows the user to scroll the content of a window by using a slider, arrows, or a wheel. Scroll bars can be horizontal or vertical, depending on the orientation of the content.
- **Title bar**: A horizontal bar at the top of a window that displays the name of the window and usually contains buttons for minimizing, maximizing, restoring, or closing the window.
- **Status bar**: A horizontal bar at the bottom of a window that displays information about the current state of the window, such as the number of items, the progress of a task, or the status of a connection.
- **Toolbar**: A horizontal or vertical bar that contains buttons, icons, or other tools for performing common tasks or accessing frequently used functions of a program.
- **Dialog box**: A small window that appears on top of another window and requests user input or provides information. Dialog boxes can have buttons, text boxes, check boxes, radio buttons, or other widgets for user interaction.
- **Tab**: A graphical element that divides a window into multiple sections, each containing different content or functions. Tabs can be clicked to switch between the sections.
- **Splitter**: A graphical element that allows the user to resize or reposition the sections of a window by dragging a divider.
