# Building Tools for Human Computer Interface

Human computer interface (HCI) is a design field that focuses on the interfaces between people and computers. HCI incorporates multiple disciplines, such as computer science, psychology, human factors, and ergonomics, into one field. HCI aims to create intuitive and usable interfaces that meet the needs and preferences of the users.

Building tools are software tools that help in designing, developing, and testing HCI applications. Building tools can be classified into three categories :

- **Interface building tools** are design methods that help in designing command languages, data-entry structures, and widgets. They provide graphical or textual representations of the interface elements and their properties. They also allow the designer to specify the behavior and functionality of the interface elements. Examples of interface building tools are Adobe XD, Figma, Sketch, etc.
- **Interface mockup tools** are tools to develop a quick sketch of the graphical user interface (GUI). They allow the designer to create low-fidelity prototypes of the interface layout, appearance, and navigation. They also enable the designer to get feedback from the users and stakeholders. Examples of interface mockup tools are Microsoft Visio, Visual Studio.Net, Balsamiq, etc.
- **Software engineering tools** are extensive programming tools that provide user interface management system (UIMS). They support the implementation, testing, and maintenance of the interface. They also provide features such as code generation, debugging, version control, etc. Examples of software engineering tools are Eclipse, Visual Studio, Xcode, etc.

Building tools are essential for HCI because they:

- Reduce the development time and cost of the interface.
- Increase the quality and usability of the interface.
- Facilitate the communication and collaboration among the designers, developers, and users.
- Support the evaluation and iteration of the interface design.
