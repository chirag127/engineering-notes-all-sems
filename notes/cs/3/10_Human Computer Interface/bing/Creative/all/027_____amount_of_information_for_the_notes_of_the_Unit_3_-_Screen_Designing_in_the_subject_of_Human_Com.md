# Unit 3 - Screen Designing

## Introduction

Screen designing is the process of creating the visual layout and appearance of a user interface for a software application or a website. Screen designing involves the use of various elements such as colors, fonts, icons, images, animations, and interactions to convey information and functionality to the users.

## Objectives

The objectives of screen designing are:

- To create a clear and consistent visual hierarchy of the information and controls on the screen
- To enhance the usability and accessibility of the interface for different types of users and devices
- To communicate the brand identity and personality of the application or website
- To elicit positive emotions and engagement from the users
- To support the user goals and tasks and provide feedback and guidance

## Principles

The principles of screen designing are:

- Alignment: The elements on the screen should be aligned to create a sense of order and balance
- Contrast: The elements on the screen should have enough contrast to create emphasis and distinction
- Repetition: The elements on the screen should be repeated to create consistency and familiarity
- Proximity: The elements on the screen that are related should be placed close to each other to create a logical grouping
- Simplicity: The elements on the screen should be simple and minimal to avoid clutter and confusion
- Affordance: The elements on the screen that are interactive should indicate their functionality and state to the users
- Consistency: The elements on the screen should follow the same style and conventions across the application or website
- Feedback: The elements on the screen should provide feedback to the users about their actions and the system status
- Visibility: The elements on the screen that are important should be visible and easy to find
- Aesthetics: The elements on the screen should be appealing and attractive to the users

## Process

The process of screen designing involves the following steps:

- Define the user requirements and goals
- Sketch the screen layout and structure
- Choose the color scheme and typography
- Design the icons and images
- Add the animations and interactions
- Test and evaluate the screen design

## Tools

The tools for screen designing are:

- Wireframing tools: These are tools that allow the creation of low-fidelity sketches of the screen layout and structure, such as Balsamiq, Figma, or Sketch
- Prototyping tools: These are tools that allow the creation of high-fidelity mockups of the screen design with colors, fonts, icons, images, animations, and interactions, such as Adobe XD, Figma, or Sketch
- Testing tools: These are tools that allow the evaluation of the screen design with users and stakeholders, such as UserTesting, UsabilityHub, or InVision
