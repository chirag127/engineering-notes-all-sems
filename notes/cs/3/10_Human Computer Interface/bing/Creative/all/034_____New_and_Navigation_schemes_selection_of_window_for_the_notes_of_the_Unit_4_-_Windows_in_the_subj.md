# New and Navigation schemes selection of window

- Windows are graphical user interface elements that allow users to view and interact with multiple applications or documents on a single screen .
- Windows can have different characteristics, components, presentation styles and types depending on the purpose and functionality of the application or document.
- Navigation schemes are methods or techniques that enable users to move from one window to another or within a window .
- Navigation schemes can be classified into two categories: device-based and screen-based .
- Device-based navigation schemes use input devices such as mouse, keyboard, touch screen, joystick, etc. to select and activate windows or window components .
- Screen-based navigation schemes use graphical elements such as menus, icons, buttons, tabs, etc. to select and activate windows or window components .
- The selection of windows and navigation schemes depends on several factors such as the user's goals, tasks, preferences, skills, experience, etc. as well as the system's functionality, usability, efficiency, etc. .
- Some general guidelines for selecting windows and navigation schemes are :
  - Use consistent and familiar windows and navigation schemes throughout the system.
  - Provide clear and concise labels and feedback for windows and navigation schemes.
  - Minimize the number of windows and navigation schemes required to complete a task.
  - Avoid overlapping, cluttering or obscuring windows and navigation schemes.
  - Support user control and flexibility in windows and navigation schemes.
  - Match the windows and navigation schemes to the user's mental model and expectations.
