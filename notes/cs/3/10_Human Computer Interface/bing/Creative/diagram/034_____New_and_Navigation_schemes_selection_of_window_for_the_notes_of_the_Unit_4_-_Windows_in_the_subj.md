### Window Selection and Navigation Schemes in Human Computer Interface

- Windows are graphical user interface elements that allow users to view and interact with multiple applications or documents on a single screen.
- Windows can have different characteristics, such as size, shape, position, title, border, scroll bars, menus, icons, etc.
- Windows can also have different presentation styles, such as tiled, cascaded, overlapping, modal, modeless, etc.
- Windows can also have different types, such as primary, secondary, dialog, pop-up, palette, etc.
- Window selection and navigation schemes are methods that enable users to switch between different windows or access different functions within a window.
- Some common window selection and navigation schemes are:

  - Menus: Menus are lists of commands or options that are displayed on a window or a menu bar. Menus can be structured hierarchically, linearly, or contextually. Menus can be navigated by using a pointing device, such as a mouse, or by using keyboard shortcuts or mnemonics.
  - Icons: Icons are graphical symbols that represent applications, documents, commands, or functions. Icons can be displayed on a window, a desktop, a toolbar, or a dock. Icons can be activated by clicking, double-clicking, dragging, or dropping them.
  - Buttons: Buttons are graphical elements that trigger an action or a command when clicked. Buttons can be displayed on a window, a toolbar, a dialog box, or a pop-up window. Buttons can have different shapes, sizes, colors, labels, or images.
  - Tabs: Tabs are graphical elements that divide a window into multiple sections or pages. Tabs can be displayed horizontally or vertically on a window. Tabs can be selected by clicking or using keyboard shortcuts.
  - Scroll bars: Scroll bars are graphical elements that allow users to move the visible portion of a window or a document. Scroll bars can be displayed horizontally or vertically on a window. Scroll bars can be manipulated by using a pointing device, such as a mouse, or by using keyboard shortcuts or arrow keys.
  - Tooltips: Tooltips are small pop-up windows that provide additional information or feedback about an element on a window, such as a menu item, an icon, a button, or a tab. Tooltips can be displayed when the user hovers the cursor over the element or when the user presses a modifier key, such as Ctrl or Alt.
