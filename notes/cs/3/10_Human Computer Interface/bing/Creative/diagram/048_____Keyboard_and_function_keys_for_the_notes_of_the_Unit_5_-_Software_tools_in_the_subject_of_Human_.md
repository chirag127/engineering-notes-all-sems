### Keyboard and function keys

A keyboard is a device that allows you to input text, numbers, symbols, and commands to a computer. A keyboard consists of several groups of keys, such as:

- Typing keys: These are the letters, numbers, punctuation, and other symbols that you can type on the screen. They are arranged in a layout called QWERTY, which is based on the most common letters in the English language.
- Modifier keys: These are the keys that modify the function of other keys when pressed together, such as Shift, Ctrl, Alt, and Windows. For example, pressing Shift and A together will type a capital A, while pressing Ctrl and C together will copy the selected text to the clipboard.
- Navigation keys: These are the keys that help you move the cursor or the screen, such as the arrow keys, Home, End, Page Up, Page Down, and Delete. For example, pressing the left arrow key will move the cursor one character to the left, while pressing Page Down will scroll down the screen by one page.
- Function keys: These are the keys labeled F1 to F12 on the top of the keyboard. They have different functions depending on the operating system or the running program. For example, pressing F1 will usually open the help menu, while pressing F5 will refresh the web page.

The function keys are a set of keys that can perform various tasks depending on the context. They can be used to access system settings, launch applications, control media playback, switch between windows, and more. However, some keyboards have a special key called Fn or Function, which acts as a toggle for the function keys. When the Fn key is pressed, the function keys will perform their secondary functions, which are usually indicated by icons or symbols on the keys. For example, pressing Fn and F1 together will mute the sound, while pressing Fn and F2 together will adjust the brightness.

To change the default behavior of the function keys, you can use the following methods:

- Use the Fn lock key: Some keyboards have a key that locks the Fn key, so that you don't have to press it every time you want to use the secondary functions. The Fn lock key may be labeled as Fn Lock, Esc, or F Lock. To use it, press and hold the Fn key, then press the Fn lock key. A light will indicate that the Fn key is locked. To unlock it, press and hold the Fn key, then press the Fn lock key again.
- Use the BIOS settings: You can also change the default behavior of the function keys in the BIOS settings, which are the basic input/output system of the computer. To access the BIOS settings, restart the computer and press the designated key, such as F2, F10, or Delete, before the Windows logo appears. Then, look for an option called Function Key Behavior, Action Keys Mode, or Hotkey Mode, and change it to your preference. Save the changes and exit the BIOS settings.
- Use the keyboard software: Some keyboards come with a software that allows you to customize the function keys and other settings. To use it, install the software from the manufacturer's website or the CD that came with the keyboard. Then, open the software and look for an option to change the function key behavior.
