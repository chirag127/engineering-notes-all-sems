## Unit 5 - Software tools

Unit 5 - Software Tools:
- Overview of software tools used in HCI design
- Types of software tools:
  1. Design and prototyping tools: Used for creating and testing user interface designs.
  2. User testing tools: Used for evaluating user interfaces with real users.
  3. Development tools: Used for coding and implementing user interfaces.

Note: Software tools play a critical role in the design and development of Human-Computer Interfaces (HCI). This unit covers the various types of software tools used in HCI design, including design and prototyping tools, user testing tools, and development tools. The selection of appropriate software tools will depend on the specific needs and goals of the HCI project.
