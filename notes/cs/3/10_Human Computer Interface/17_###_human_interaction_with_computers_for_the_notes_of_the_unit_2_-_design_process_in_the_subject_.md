### Human interaction with computers for the notes of the Unit 2 - Design process in the subject of Human Computer Interface

Unit 2 - Design Process:
- Human Interaction with Computers:
  1. Input Devices: Keyboard, Mouse, Touchscreens, Voice and Gesture recognition, etc.
  2. Output Devices: Monitors, Printers, Projectors, Speakers, etc.
  3. Interaction Styles: Command Line Interface, Menu-based Interface, Graphical User Interface (GUI), Natural User Interface (NUI), etc.
  4. Interaction Models: WIMP (Windows, Icons, Menus, Pointers), Direct Manipulation, etc.

Note: Human interaction with computers involves the use of input and output devices, and the selection of appropriate interaction styles and models. This unit covers the various input and output devices used in human-computer interaction, as well as the different interaction styles and models used to design effective and user-friendly interfaces.
