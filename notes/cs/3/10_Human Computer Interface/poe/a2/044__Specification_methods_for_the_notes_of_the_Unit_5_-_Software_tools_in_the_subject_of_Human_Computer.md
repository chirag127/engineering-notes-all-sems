### Specification methods for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface.

1. Sketching and prototyping
- Rough sketching: Quick drawings to visualize and communicate ideas.
- Throwaway prototyping: Simple prototypes to understand user needs and explore solutions.
- Evolutionary prototyping: Refined prototypes that evolve over time based on user feedback.

2. Storyboarding
- Visualize the flow of user interactions with a system.
- Show screens/interfaces and user actions.
- Help discuss and refine the user experience.

3. Use case diagrams
- Model system functionality and interactions with users (actors).
- Capture key tasks/goals and requirements.
- Supply a concise overview before detailed specification.

4. Scenarios
- Describe sequences of user actions and system responses.
- Focus on a particular user goal or task.
- Bring specifications to life and support evaluation and design.

5. Formal specification methods
- Z notation: Mathematical approach to formally specify and reason about software.
- VDM: Mathematic approach with syntax grounded on programming language.
- Petri nets: Graphical approach to model system states, events, and transitions.
