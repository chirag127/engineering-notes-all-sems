### Statistical Graphics for Unit 3 - Screen Designing notes

1. Graphs: Graphs are visual representations of quantitative data. They make data more understandable and meaningful. Some commonly used graphs are:
- Bar graph: Used to compare different categories of data. Rectangular bars are used with lengths proportional to the values they represent.
- Line graph: Used to show trends in data over a period of time. Data is represented by line segments connecting data points.
- Pie chart: Used to show proportions of a whole. A circle is divided into sectors that are proportional to the percentages they represent.
- Scatter plot: Used to show correlation between two quantitative variables plotted on x and y axes. Each data point is represented by a dot. Pattern of dots shows correlation.

2. Choosing appropriate graphs: The type of graph chosen depends on the type of data (categorical, quantitative, comparative, temporal, etc.) and the purpose of visualization (comparison, correlation, trend, etc.). inappropriate choice of graphs can mislead the audience. Hence, it is important to choose a graph type that accurately represents the data and highlights the required information.

3. Design principles: Some key design principles for effective statistical graphics are:
- Simplicity: The graphic should be as simple as possible highlighting only essential information. Too much complexity leads to confusion.
- Clarity: The graphic should be clear and unambiguous with properly labeled axes and headings.
- Accessibility: It should be accessible to the intended audience with appropriate typography, sufficient contrast, and accommodation for color blindness if required.
- Honesty: The graphic should not distort or manipulate data or use visual tricks to exaggerate trends. The representation should be fair and accurate.

4. Software tools: Some useful software tools to create statistical graphics are:
- Excel: Inbuilt charts and graphs with customized styling options.
- Python libraries - Matplotlib, Seaborn, Plotly: For greater control and variety in data visualization.
- Tableau: A data visualization tool with a user-friendly interface to create interactive graphics.
- D3.js: A javascript library to create custom interactive data visualizations.
