### New and Navigation schemes selection of window for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. Single Document Interface (SDI): Only one window is shown at a time. Each window is a separate application. Switching between windows is similar to switching between applications.
2. Multiple Document Interface (MDI): Multiple windows are contained within a single parent application window. The child windows can be tiled or overlapped. The parent window provides a common menu bar and toolbar.
3. Tabbed Document Interface (TDI): Multiple documents are contained within a single window, with each document displayed as a tab. Only one document is visible at a time, and the user selects which one to display by selecting its tab.
4. Split Window: The window is split into two or more areas that can contain different documents or views of the same document. A split can be horizontal or vertical. The division between areas can typically be adjusted by the user. The split window scheme combines aspects of MDI and TDI.

While selecting a scheme, factors to consider are:
- The task and the number of windows/documents required
- Available screen space
- User preferences
- Consistency with other applications

The schemes have their pros and cons and the selection depends on the requirements and preferences. An interface may even combine multiple schemes. The ultimate goal is to provide an easy and efficient mechanism to work with multiple documents and views.
