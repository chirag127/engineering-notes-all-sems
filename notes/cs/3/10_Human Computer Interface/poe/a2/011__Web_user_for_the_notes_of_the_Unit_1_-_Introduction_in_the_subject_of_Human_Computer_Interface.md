### Web user for the notes of the Unit 1 - Introduction in the subject of Human Computer Interface.

1. The World Wide Web (WWW) is an information space where documents and other web resources are identified by URLs, interlinked by hypertext links, and can be accessed via the Internet.

2. A web browser is a software application for accessing and displaying web pages. The browser retrieves web pages from web servers and displays their content on the user's device.

3. HTML (Hypertext Markup Language) is the main markup language for creating web pages and web applications. It uses tags like <html>, <head>, and <body> to structure a web page.

4. CSS (Cascading Style Sheets) is used to style the appearance of web pages written in HTML and XML. It separates the presentation of a document from the content of a document.

5. The HTTP (Hypertext Transfer Protocol) is the foundation of data communication for the World Wide Web. It defines how messages should be formatted and transmitted, and what actions web servers and browsers should take in response to various commands.
