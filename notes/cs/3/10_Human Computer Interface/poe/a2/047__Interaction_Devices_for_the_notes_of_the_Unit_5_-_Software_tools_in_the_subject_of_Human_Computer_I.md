### Interaction Devices for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

1. Keyboard: Keyboard is the most common input device which is used to input data and control the computer. It allows the user to enter alphanumeric data and instructions into the computer.

2. Mouse: Mouse is a pointing device which allows the user to control the cursor position on the screen. It is used to select options, draw, play games, etc. The most common types are mechanical mouse and optical mouse.

3. Trackball: Trackball is a pointing device consisting of a ball held in a socket containing sensors to detect rotation of the ball about two axes. It serves the same purpose as a mouse but with the advantage of not needing external space.

4. Light Pen: Light pen is a pointing device that allows the user to select on-screen options or draw on the display by detecting the light from the screen. It is typically used for tasks requiring precise selections or drawing.

5. Touch Screen: Touch screen is an input device that allows the user to interact with the system by touching the display screen. It allows direct manipulation of on-screen objects and is useful for public systems as it is easy to use.

6. Joystick: Joystick is an input device used to control motion and provide input for interaction in applications like games. It allows the user to control the position and orientation of objects. It can sense motion in one or more degrees of freedom.

7. Microphone: Microphone is an input device that converts speech and other audio signals into electrical signals which are then processed by the computer. It is used for applications like speech recognition, voice calls, recording audio, etc.
