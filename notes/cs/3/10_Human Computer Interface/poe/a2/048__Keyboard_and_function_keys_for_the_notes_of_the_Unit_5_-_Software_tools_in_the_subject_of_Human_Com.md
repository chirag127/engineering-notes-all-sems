### Keyboard and function keys for the notes of the Unit 5 - Software tools in the subject of Human Computer Interface

1. Escape (Esc) key - Used to exit or cancel an ongoing process or to move from the menu.
2. F1 to F12 - Function keys with specific purposes like to show help, save a file, print, etc. The purposes can vary based on the application.
3. Tab key - Used to move between the fields or controls in a window or to indent text.
4. Shift key - Used along with other keys to type capital letters or other special characters.
5. Ctrl key - Used along with other keys for keyboard shortcuts to perform certain actions.
6. Alt key - Used along with other keys to access menu options or perform certain actions.
7. Caps Lock key - Used to lock the keyboard in capital letter mode. The key has to be pressed again to return to small letter mode.
8. Insert key - In word processors, used to switch between insert and overtype modes while typing.
9. Home, End, Page Up and Page Down keys - Used to navigate to the start or end of a line or page or move up or down a page.
10. Arrow keys - Used to navigate up, down, left and right or to select options in a menu.
11. Numeric keypad - Used to enter numerical data or navigate like the arrow keys.
12. Special keys - Keys like Print Screen, Scroll Lock, Pause/Break, etc. have specific purposes.

The keyboard and function keys help to provide inputs and control the computer. They form an important part of human-computer interaction.
