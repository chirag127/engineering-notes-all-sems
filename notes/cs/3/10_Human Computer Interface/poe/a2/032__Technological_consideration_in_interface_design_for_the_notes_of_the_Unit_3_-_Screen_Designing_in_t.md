### Technological consideration in interface design for the notes of the Unit 3 - Screen Designing in the subject of Human Computer Interface

1. Screen Resolution: The screen resolution refers to the number of pixels in a display. Higher resolution leads to sharper and crisper display of elements. But higher resolution also means more data to be processed leading to performance issues. So, an ideal resolution should be chosen based on the usage.

2. Screen Size: The screen size impacts the amount of information that can be displayed at a time. Larger screens are good for viewing more data simultaneously but can't be used in constrained spaces. Smaller screens are portable but can only show limited information. The screen size should be decided based on the primary purpose of use.

3. Colour Depth: Colour depth refers to the number of colours that can be displayed on the screen. Higher colour depth leads to richer and more vibrant colours but also requires more processing power. Colour depth should be chosen based on the type of visual elements and graphics required in the interface.

4. Response Time: Response time refers to the time taken by the screen to respond to a command. Lower response time leads to a more responsive interface with minimal lag. But lower response time panels are more expensive. The response time should be decided based on the nature of the interface and tasks. Faster response time is needed for gaming or video editing software while normal response time would work for productivity applications.

5. Viewing Angle: The viewing angle refers to the angle at which the screen is visible. Wider viewing angles are better for collaboration or presentations while narrow viewing angles are fine for individual use. The viewing angle depends on the application and level of privacy required.
