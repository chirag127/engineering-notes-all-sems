### Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

1. Title Bar: The top horizontal bar in a window. It contains the window title and control buttons.
2. Menu Bar: The bar below the title bar that contains the menu items.
3. Toolbar: A bar that contains buttons for commonly used commands.
4. Status Bar: The bottom horizontal bar in a window that displays status information about the current task.
5. Taskbar: The bar at the bottom of the desktop that contains buttons for running applications and the notification area.
6. Notification Area: The part of the taskbar typically at the right end that contains status icons for running services and applications.
7. Scroll Bars: Controls for scrolling through a document or webpage that is larger than the visible area.
8. Resize Handles: Controls at the edges and corners of a window that allow the user to change the size and shape of the window.
