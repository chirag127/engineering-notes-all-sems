### Text and messages for the notes of the Unit 4 - Windows

1. Windows: Windows are the graphical user interfaces provided by the operating system to interact with the computer. They allow the user to access programs and data on the computer through icons, menus, and other graphical components.
2. Parts of a window:
- Title bar: Displays the title of the window and contains controls to minimize, maximize, restore, or close the window.
- Menu bar: Contains drop-down menus to access the commands and functions of the application.
- Toolbar: Contains buttons or icons that provide quick access to commonly used commands or functions.
- Task panes: Panes within the window that provides additional information or options.
- Content/Work area: The main area of the window where the user can enter and view data or interact with the application.
3. Window manipulation: Windows can be manipulated in various ways such as:
- Moving: Dragging the title bar to move the window to a different location on the screen.
- Resizing: Dragging the edges or corners of the window to adjust the size.
- Minimizing: Clicking the minimize button on the title bar to hide the window and display only the icon on the taskbar.
- Maximizing: Clicking the maximize button on the title bar to expand the window to the full size of the screen.
- Restoring: Clicking the restore button on the title bar to return the window to its original size after maximizing.
- Closing: Clicking the close button on the title bar to exit the application or close the window.
