### Information Retrieval on Web for Unit 3 - Screen Designing Notes

1.  Indexing - The process of indexing involves examining documents and creating index terms for them. These index terms are then stored in an index. This allows users to later search the index to find relevant documents based on keywords.
2.  Crawling - Crawling is the process by which a search engine explores the Web and indexes Web documents. Crawling robots, called spiders or bots, traverse the Web by following hyperlinks. As they crawl over pages, they analyze page content and add pages and information to the search engine's index.
3.  Ranking - After crawling and indexing, search engines rank results in order of relevance to the search query. The most relevant results are shown first. Ranking is based on measures of relevance that take into account factors such as keyword matches, hyperlink analysis, site authority, and incoming links.
4.  Query Processing - Query processing is the task of taking a user's search query, looking up relevant index terms, and returning matching documents ranked by relevance. The results are then displayed to the user. Query processing allows search engines to provide fast search results using their indexes and ranking algorithms.

The above points cover the major steps involved in information retrieval on the Web. The process allows users to search the vast content on the Web and retrieve relevant results based on their search queries.
