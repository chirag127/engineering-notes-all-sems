
### Keyboard and Function Keys

* Keyboards are the primary input device used to interact with a computer.
* There are two types of keyboard keys: alphanumeric keys (letters and numbers) and function keys.
* Function keys are labeled F1 through F12 and are used to perform specific tasks within a program.
* The most commonly used function keys are F1 (help), F5 (refresh), and F10 (menu).
* Other common function keys include F2 (rename), F3 (find), F4 (open), F6 (undo), F7 (spell check), F8 (cut), F9 (paste), and F12 (save).
* Function keys can also be used in combination with other keys such as Alt, Ctrl, and Shift to perform more complex tasks.
