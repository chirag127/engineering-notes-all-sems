
## Unit 4 - Windows

1. Windows is an operating system designed by Microsoft that is used on personal computers, laptops, tablets and smartphones.
2. It is available in several versions, including Windows 10, Windows 8, Windows 7, Windows Vista and Windows XP.
3. It is a graphical user interface (GUI) based operating system, which means that it uses graphical elements such as icons, windows and menus to interact with the user.
4. Windows includes many built-in features, such as a web browser, media player, email client, antivirus software and more.
5. It also has a wide range of third-party applications available for download, such as games, productivity tools and other software.
6. Windows is designed to be user-friendly and easy to use, with a range of customization options to suit different users.
7. It supports a wide range of hardware, including printers, scanners, cameras, external storage devices and more.
8. It also supports a variety of file formats, including documents, audio files, videos and images.
9. Windows is regularly updated with security patches and new features.
