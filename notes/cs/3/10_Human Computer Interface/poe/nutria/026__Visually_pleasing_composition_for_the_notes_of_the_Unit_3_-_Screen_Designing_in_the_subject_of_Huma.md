
### Visually Pleasing Composition for Screen Designing

1. Color: Color is a powerful tool for creating visually pleasing compositions. Colors can be used to create contrast, draw attention, and create a sense of harmony. Color can also be used to convey emotion, mood, and meaning.

2. Balance: Balance is the arrangement of elements in a composition to create a sense of equilibrium. Balance can be achieved through the use of size, shape, texture, and color.

3. Proportion: Proportion is the relationship between the size of elements in a composition. Proportion can be used to create visual interest and to draw attention to certain elements.

4. Unity: Unity is the sense of cohesion in a composition. Unity can be achieved through the use of repetition, rhythm, and pattern.

5. Space: Space is the area between and around elements in a composition. Space can be used to create a sense of depth and to draw attention to certain elements.

6. Typography: Typography is the use of typefaces to create visually pleasing compositions. Typography can be used to convey a message, create a mood, and draw attention to certain elements.
