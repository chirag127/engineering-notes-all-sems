### Statistical Graphics for the Notes of the Unit 3 - Screen Designing in the Subject of Human Computer Interface

Statistical graphics are used to represent data visually. They are used to understand complex data and relationships between variables. In screen designing, statistical graphics are used to represent data on the screen in a way that is easy to understand and interpret. Here are some important points to keep in mind when using statistical graphics:

- **Choose the right type of graph:** Different types of graphs are used to represent different types of data. For example, a bar graph is used to represent categorical data, while a line graph is used to represent continuous data. It is important to choose the right type of graph to represent your data accurately.

- **Use clear titles and labels:** The graph should have a clear and concise title that summarizes the data being presented. Labels should be used to identify the variables being represented and the units of measurement. This will help the user understand the data and its relevance.

- **Avoid clutter:** Too many data points or lines can make the graph cluttered and difficult to read. Simplify the graph by removing unnecessary data points or lines.

- **Use appropriate axis scales:** The axis scales should be chosen carefully to accurately represent the data. The scales should be evenly spaced and include enough tick marks to make the data clear. Avoid using non-linear scales.

- **Use appropriate colors and fonts:** The colors and fonts used in the graph should be chosen carefully to improve readability. Avoid using too many colors or fonts, as this can make the graph confusing.

- **Provide context:** It is important to provide context to help the user understand the data being presented. This can be done by including a brief description of the data, the source of the data, and any relevant information about the data.

In conclusion, statistical graphics are an important tool for representing data in screen designing. By choosing the right type of graph, using clear titles and labels, avoiding clutter, using appropriate axis scales, colors and fonts, and providing context, we can create effective and informative graphs that help the user understand the data.
