### Components for the notes of the Unit 4 - Windows in the subject of Human Computer Interface

Unit 4 - Windows:
- Components of a Window:
  1. Title bar: Displays the name of the window and provides controls for minimizing, maximizing, and closing the window.
  2. Menu bar: Contains menus and commands for accessing different functions and features of the application.
  3. Toolbar: Contains buttons and icons for accessing frequently used functions and features of the application.
  4. Status bar: Displays information about the status of the application, such as the current mode or the progress of a task.
  5. Workspace: The main area of the window where the user interacts with the application, such as viewing or editing documents.

Note: Windows are an important component of graphical user interfaces, as they provide a way for users to interact with applications and access different functions and features. This unit covers the components of a window, including the title bar, menu bar, toolbar, status bar, and workspace.
