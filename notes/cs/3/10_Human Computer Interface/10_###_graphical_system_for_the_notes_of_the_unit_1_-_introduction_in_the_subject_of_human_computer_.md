### graphical system for the notes of the Unit 1 - Introduction in the subject of Human Computer Interface

Unit 1 - Introduction:
- Graphical System: A graphical system is a computer system that uses graphics and visual representations to interact with users.
- Graphical User Interface (GUI): A GUI is a type of graphical system that uses graphics and visual representations to interact with users.
- GUI components: Windows, icons, menus, pointers (e.g. mouse pointer)
- GUI benefits: User-friendly, intuitive, visually appealing

Note: A graphical system is a computer system that uses graphics and visual representations to interact with users. A GUI, or graphical user interface, is a type of graphical system that uses windows, icons, menus, and pointers to interact with users. The benefits of a GUI include being user-friendly, intuitive, and visually appealing.
