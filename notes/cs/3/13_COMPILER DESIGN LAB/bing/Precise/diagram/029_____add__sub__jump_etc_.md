### Add, Sub, Jump etc.

- **Add** is an arithmetic operation that represents the combining of two or more numbers to get a total or sum. For example, 2 + 3 = 5.
- **Sub** is short for subtraction, which is another arithmetic operation. It represents the removal of one number from another. For example, 5 - 3 = 2.
- **Jump** is not an arithmetic operation, but it can refer to a command in computer programming. It is used to transfer program execution to a different location in the code. For example, a jump instruction might be used to skip over a section of code if a certain condition is met.
