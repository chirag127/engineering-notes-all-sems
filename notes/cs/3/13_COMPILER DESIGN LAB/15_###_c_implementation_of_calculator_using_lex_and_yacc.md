### c) Implementation of Calculator using LEX and YACC

c) Implementation of Calculator using LEX and YACC is a process of building a calculator program using LEX and YACC tools. LEX is a lexical analyzer generator that is used to generate a program that performs pattern matching on input strings. YACC is a parser generator that is used to generate a program that performs syntax analysis on the input string. Together, LEX and YACC are used to build a calculator program that takes as input mathematical expressions and produces the correct result. The implementation process involves writing LEX and YACC specifications to define the grammar of the calculator language, generating the LEX and YACC programs, and integrating the generated programs into a complete calculator program. The resulting calculator program can then be used to perform mathematical calculations.
