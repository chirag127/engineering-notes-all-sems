### DTD for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Document Type Definition (DTD)
- DTD defines the structure and the legal elements and attributes of an XML document.
- It defines the document structure with a list of legal elements and attributes.
- It is a set of markup declarations that specify a document type for an SGML-family markup language (SGML, XML, HTML).

2. Why use DTD?
- It acts as a contract between an XML document and its application.
- It ensures that the document is structurally correct and valid.
- It allows validation of XML documents against the DTD.
- It serves as documentation defining the structure and elements allowed in a XML document.

3. Structure of a DTD
- <!DOCTYPE> declaration
- Element declarations
- Attribute declarations
- General entities
- Notation declarations

4. XML validating processor
- Parses the XML document and checks if it conforms to the DTD.
- If valid, it processes the document. If invalid, it generates an error.
- This ensures correct structure and avoids malformed XML documents.
