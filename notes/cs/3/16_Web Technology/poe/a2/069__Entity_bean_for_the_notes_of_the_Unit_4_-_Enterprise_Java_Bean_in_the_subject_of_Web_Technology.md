### Entity bean for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. Entity beans represent persistent data stored in a database. They are Java classes that map to tables in a relational database.
2. Entity beans have declarative transaction management. This means that you specify transactional behavior in the deployment descriptor rather than in the bean's code.
3. Entity beans have container-managed persistence. This means that the container generates the SQL statements to load and store the bean's state in the database.
4. An entity bean instance has a unique identity that is defined by the container and the data stored in the database. The container manages the entity beans identity across transactions.
5. The state of an entity bean can be changed only by invoking its business methods. This ensures data integrity, security, and transactional consistency of the entity.
6. Entity beans support distributed transactions and have declarative security.
7. Entity beans can be read-only or can be read-write. The latter supports create, read, update, and delete (CRUD) operations on the entity bean persistence state.
8. Entity beans can have relationships with other entity beans. These relationships can either be unidirectional or bidirectional.
