### Objects for Unit 3 - Scripting Notes

1. Objects: Objects are instances of classes that contain data in fields (variables) and code in procedures (methods).
2. Classes: Classes are templates that define the structure and behaviors of objects. They specify the data and procedures that objects of the class have.
3. Encapsulation: Encapsulation is the bundling of data and methods that work on that data within one unit. In encapsulation, the variables of an object cannot be accessed directly from outside the object, but they can be accessed using the methods of the object.
4. Inheritance: Inheritance is the process by which one object can acquire the properties and behaviors of another object. It helps in code reusability. The object that inherits the properties of another object is called a child object, and the object whose properties are inherited is called a parent object.
5. Polymorphism: Polymorphism allows objects of different classes to respond to the same method calls by providing different implementations. It allows the same interface to have different underlying forms.

The above points cover the key concepts regarding objects, classes, encapsulation, inheritance and polymorphism which form the building blocks for scripting in web technologies. The notes can be referred to understand the concepts and apply them to scripting problems.
