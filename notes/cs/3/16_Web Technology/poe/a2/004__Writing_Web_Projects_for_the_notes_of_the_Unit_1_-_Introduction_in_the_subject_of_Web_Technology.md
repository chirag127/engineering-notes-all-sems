### Writing Web Projects for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Understand the Client-Server Model
- The client-server model forms the basis of the World Wide Web. The web browser acts as the client and requests for web pages from the server.
- The server processes the request and sends the required web page to the client.
- The client renders and displays the web page.

2. Learn HTML, CSS and JavaScript
- HTML or Hypertext Markup Language is used to structure the web pages and provide content.
- CSS or Cascading Style Sheets is used to style the web pages and control the layout and design.
- JavaScript is used to provide interactivity and dynamic functionality to the web pages.

3. Choose a Text Editor
- A text editor is required to write the HTML, CSS and JavaScript code.
- Popular options for text editors include Notepad++, Sublime Text, Visual Studio Code, etc.
- The text editor should have features like syntax highlighting, code completion, etc. to assist in coding.

4. Learn about Version Control using Git
- Git is a version control system that can be used to track changes and maintain versions of the code.
- Using Git, you can manage modifications to the code, revert to previous versions if needed and collaborate with others.
- Git repositories can be hosted locally or on platforms like GitHub to share your projects.

5. Deploy your web project
- Once the web project is ready, it needs to be deployed to a web server to make it accessible over the Internet.
- There are multiple options to deploy projects like hosting on GitHub Pages, deploying to a local web server, using a cloud platform like Heroku, etc.
- The deployed website can then be accessed by anyone over the Internet.
