### Using XML Processors for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML Parser: It is a software module that reads an XML document and converts it into an XML DOM object that can be navigated. It checks for the well-formedness of an XML document.
- DOM Parser: It loads the entire XML document into a DOM and converts it into a DOM object which can be navigated. It is easy to understand and use but occupies more memory.
- SAX Parser: It reads the XML document sequentially and calls handler functions upon recognizing structures. It does not load the entire document into memory and is suitable for large documents.

2. Processing an XML document:
- Parse the XML document to check if it is well-formed
- Build an XML DOM or trigger SAX events
- Navigate the DOM to extract information or register SAX event handlers
- Process the extracted information as per the application logic

3. Applications of XML Processors:
- To validate an XML document against an XML Schema
- To transform an XML document into another format like HTML/PDF using XSLT
- To extract and manipulate data from an XML document
- To search for specific elements or attributes in an XML document

The above points cover the key points about XML Processors, parsing an XML document and their applications. The notes can be referred to understand XML Processing for designing web pages using XML and learn the concepts of XML Parsers and Processing XML documents.
