### Introduction to AWT

1. AWT stands for Abstract Windowing Toolkit. It is a Java API that provides an interface to a native platform's graphical user interface. AWT allows Java programs to have windows, buttons, text fields, etc. that are rendered using the platform's native components.
2. AWT components are platform independent as the look and feel of the components is defined by the platform itself, and Java applications just provide the functionality. This gives a native look and feel to Java applications.
3. However, as AWT components depend on the underlying native system, the performance is not very good and the components are limited in capabilities as they have to map to the native system components.
4. AWT components include:
- Windows: Frame, Dialog
- Buttons: Button, Checkbox, RadioButton
- Text components: Label, TextField, TextArea
- Choice components: List, Choice
- Container components: Panel, Canvas
5. The AWT event model is also platform independent and maintains the same event types across platforms. This allows for consistent event-driven programming models in Java.
