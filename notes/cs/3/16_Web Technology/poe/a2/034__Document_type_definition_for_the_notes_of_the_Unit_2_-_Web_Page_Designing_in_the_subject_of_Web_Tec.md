### Document type definition for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. DOCTYPE declaration: It is the first line of an HTML document which informs the browser about the version of HTML used to create the page. It is not an HTML tag. For example, <!DOCTYPE html> is used for HTML5 pages.

2. HTML Tags: These are the main building blocks of an HTML document. A tag always comes in a pair - opening tag and closing tag. The closing tag has a forward slash (/) before the tag name. For example, <html></html>.

3. Attributes: These provide additional information about HTML elements. They are always specified in the opening tag. For example, <a href="www.example.com">Link</a>. Here, href is the attribute which specifies the URL or link destination.

4. Elements: An HTML element refers to the combination of an opening tag, its attributes, content, and closing tag. For example, <p>This is a paragraph</p>. Here, the <p> and </p> are the tags and "This is a paragraph" is the element content.

5. HTML versions: The major versions of HTML are HTML 4, HTML5 and XHTML. HTML5 is the latest version with new features like video and audio playback without plugins, canvas element for dynamic graphics, offline web apps etc.
