### DOM and SAX for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. DOM: DOM stands for Document Object Model. It is a programming interface for HTML and XML documents. It represents the page so that programs can change the document structure, style and content. The DOM views the XML/HTML document as a tree of nodes.

2. Advantages of DOM:
- Language independent: DOM can be accessed from any programming language like JavaScript, VBScript, Python etc.
- Platform independent: DOM can be used on any platform or OS.
- Easy to understand: DOM has a straightforward structure like a tree which is easy to understand.

3. SAX: SAX stands for Simple API for XML. It is an event-driven online algorithm for parsing XML documents. It does not build a tree structure like DOM and thus requires less memory. But it is slower and more complex than DOM.

4. Advantages of SAX over DOM:
- Uses less memory: No object structure is created in SAX thus requires less memory.
- Faster: SAX is faster than DOM as it does not require to build an entire object model of the document.
- Streaming: SAX enables streaming of XML documents i.e. parts of the document can be processed even before the entire document is read.

5. Disadvantages of SAX:
- Complex programming: Event driven model and piecemeal processing makes SAX API complex to program.
- Limited functionality: No random access to XML document parts is possible in SAX which limits its functionality.
