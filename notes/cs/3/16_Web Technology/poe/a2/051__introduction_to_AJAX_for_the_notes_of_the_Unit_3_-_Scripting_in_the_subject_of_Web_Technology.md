### Introduction to AJAX for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. AJAX stands for Asynchronous JavaScript and XML.
2. It is the use of the XMLHttpRequest object to communicate with server/api and load data in the background without refreshing the page.
3. The data from the server can be XML, JSON or plain text format. XML is used less nowadays and JSON is more popular.
4. The XMLHttpRequest object is used to exchange data with a web server behind the scenes. This means that it is possible to update parts of a web page, without reloading the whole page.
5. The main steps in AJAX are:

- Create XMLHttpRequest object
- Create a callback function to handle the server response
- Open a connection to the server
- Send request to the server
- Listen for the response from server
- Process the response

6. The advantages of using AJAX are:

- Faster load time: Only part of the page needs to be updated without refreshing the whole page.
- Interactivity: The user gets a more responsive feel as the data can be exchanged in the background.
- Reduced bandwidth: Only the required data is transferred instead of loading the whole page each time.

7. The disadvantages of using AJAX are:

- Low browser support for older browsers
- Increased complexity: AJAX introduces more complexity in web pages
- SEO challenges: The content loaded using AJAX may not be indexed by search engines properly
- Security issues: There is a risk of XSS (Cross-site-scripting) attacks if proper security precautions are not taken.
