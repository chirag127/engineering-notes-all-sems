### Internet Addressing for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. IP Address: An IP address is a numerical label assigned to each device (e.g., computer, printer) participating in a computer network that uses the Internet Protocol for communication.

2. Domain Name: A domain name is an identification string that defines a realm of administrative autonomy, authority, or control within the Internet. Domain names are used in various networking contexts and applications for the purpose of identifying and locating computers and resources on the Internet.

3. DNS: The Domain Name System (DNS) is a hierarchical and decentralized naming system for computers, services, or other resources connected to the Internet or a private network. It translates domain names meaningful to humans into the numerical IP addresses required for locating and identifying systems and resources on a network.

4. HTTP: Hypertext Transfer Protocol (HTTP) is an application layer protocol for distributed, collaborative, hypermedia information systems. HTTP is the foundation of data communication for the World Wide Web.

5. URL: A Uniform Resource Locator (URL), colloquially termed a web address, is a reference to a web resource that specifies its location on a computer network and a mechanism for retrieving it.
