### Instance Methods for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Methods are functions that are properties of objects. They are used to perform operations on the data (properties) of the object.
2. Instance methods are methods that are called on a specific instance of an object. They have access to the object instance via the this keyword.
3. The this keyword refers to the object that is calling the method. Within the method, this can be used to access the object's properties and other methods.
4. Examples of instance methods are:

- getFullName() - Returns the first and last name of a person object
- getArea() - Returns the area of a rectangle object
- increaseAge() - Increments the age property of a person object

5. Instance methods allow us to bundle related functionality that operates on an object's data into one place. This makes the code more organized, readable and maintainable.
