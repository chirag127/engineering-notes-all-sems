### Introduction

1. Web Technology refers to the various technologies that are used to create web pages and web applications. Some of the core web technologies are:
- HTML: Hypertext Markup Language is the main markup language used to create web pages. It is used to structure the web page and add content.
- CSS: Cascading Style Sheets is used to style the HTML elements and define the layout of the web page. It is used to specify styles for the web page.
- JavaScript: JavaScript is a scripting language used to create interactive effects within web pages and web applications. It is used for both frontend and backend development.
- PHP: PHP is a server-side scripting language used to create web pages with dynamic content. It can be embedded into HTML.

2. The World Wide Web (WWW) refers to the collection of interlinked web pages that can be accessed through the Internet. The web pages are hosted on web servers and can be accessed using a web browser. A web browser is a software application used to locate, retrieve and display web pages or other resources from the web. Some popular web browsers are Google Chrome, Mozilla Firefox, Microsoft Edge, etc.

3. The Internet refers to the global network of networks that connects computers and other digital devices from all over the world using a common protocol known as the Internet Protocol (IP) to serve, receive and exchange data, messages and other resources. The key components of the Internet are Internet service providers, Internet backbone, Internet protocols and applications that run on the Internet like the World Wide Web, email, etc.
