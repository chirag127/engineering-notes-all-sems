### Java Server Pages (JSP)

1. JSP is a technology that allows Java code and certain pre-defined actions to be embedded into a web page.
2. The JSP page is compiled into a Java servlet and executed on the server.
3. The output is sent to the client as a HTML page.
4. JSP provides a mechanism to separate the static content (HTML/XML) from the dynamic content (Java code).
5. A JSP page uses a combination of JSP elements, scriptlets, expressions and directives.
6. JSP elements are XML-style tags that control the structure of the page. Examples: <jsp:include>, <jsp:forward>, <jsp:param>.
7. Scriptlets are Java code blocks between <% %> tags. They are used to insert dynamic content into the JSP page.
8. Expressions are Java expressions between <%= %> tags. Their purpose is to insert values into the output.
9. Directives are messages to the JSP engine that control the structure and behavior of the JSP page. They start with <%@ %>. Examples: <%@ page %>, <%@ include %>.
10. The JSP container manages the life cycle of JSP pages and the associated servlets. When a JSP page is first loaded, it is translated into a servlet class and the servlet is loaded and instantiated.
