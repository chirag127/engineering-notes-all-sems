### JavaBeans Properties for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. JavaBeans are reusable software components for Java.
2. They have properties which can be set/get via setter/getter methods.
3. The properties are customizable and accessible externally.
4. The properties can be modified at runtime without recompiling the bean.
5. The properties can be simple types like int, float, double or complex types like arrays or other JavaBeans.
6. The properties can have restrictions on valid/invalid values via validation.
7. The properties can have notification mechanisms associated with them so that other beans can be notified of any changes.
8. The properties allow easy integration of beans into an application as the application can access and modify the bean properties as required.
9. The properties provide encapsulation as the internal state of the bean is hidden and only accessed via the properties.
10. The properties enable easy wiring of beans together as the application only needs to know the properties of beans and not their internal implementation.
