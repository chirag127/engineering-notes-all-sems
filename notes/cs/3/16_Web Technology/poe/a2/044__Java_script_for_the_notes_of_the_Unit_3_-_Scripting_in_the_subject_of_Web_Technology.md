### JavaScript for the notes of Unit 3 - Scripting in Web Technology

1. JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages.
2. It allows web pages to be interactive and more dynamic.
3. JavaScript code can react to user events such as clicking, tapping, or hovering over elements, store and retrieve data, animate graphics, etc.
4. JavaScript runs on a browser and is interpreted by the browser, not compiled to machine code like Java.
5. JavaScript borrows some syntax from Java but is otherwise unrelated. JavaScript is dynamically typed and supports prototypes rather than classes.
6. JavaScript can be embedded directly into HTML pages or referenced from an external .js file.
7. To use JavaScript, you need to have a browser that supports a JavaScript engine such as SpiderMonkey (Firefox), V8 (Chrome), Chakra (Microsoft Edge), or JavaScriptCore (Safari).
8. JavaScript is lightweight and interpreted, so it may be slower than compiled languages. However, modern browsers optimize performance with just-in-time compilation and other techniques.
9. The widespread adoption of JavaScript on the client side has led to the development of Node.js, a server-side JavaScript environment based on Chrome's V8 engine. This allows JavaScript to be used for full-stack web development.
