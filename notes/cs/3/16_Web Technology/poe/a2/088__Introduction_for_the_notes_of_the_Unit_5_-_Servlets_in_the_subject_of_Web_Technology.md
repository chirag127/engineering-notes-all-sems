### Introduction for the notes of the Unit 5 - Servlets

1. Servlets are server-side components that provide a powerful mechanism for dynamically interacting with users.
2. They are objects that receive requests and generate responses based on those requests.
3. Servlets run on the server, unlike applets which run inside a browser.
4. Servlets provide a component-based and platform-independent architecture.
5. Servlets take advantage of the Java advantage of "write once, run anywhere". Once a servlet is written, it can run on any Java-enabled web server.
6. Servlets are managed by a container, which is part of a web server or application server. The container is responsible for providing the servlet's lifecycle methods and mapping requests to servlet instances.
7. Servlets have access to all the resources of the Java platform, including the extensive class libraries and the RMI system. This makes servlets a powerful technology for creating dynamic web content.
8. Servlets differ from CGI scripts in that servlets are not new processes created each time a request comes in. Servlets are persistent objects that can handle multiple requests in a single thread, making them much more efficient than creating new processes for each request.
