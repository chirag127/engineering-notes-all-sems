### Forms for Unit 2 - Web Page Designing notes

1. Forms: Forms are required to take input from the user. The input is sent to the server for processing. Forms contain form elements like input boxes, radio buttons, checkboxes, submit buttons, etc.
2. Form Elements: The different form elements are:
- Input boxes: To enter text, numbers, dates, passwords, etc.
- Radio buttons: To select one option from multiple options.
- Checkboxes: To select multiple options from multiple options.
- Submit button: To submit the form.
- Reset button: To reset the form.
3. Form Attributes: The different attributes of a form are:
- Action: The URL to send the input to.
- Method: The HTTP method to send the data. GET or POST.
- Enctype: The encoding type for sending the data.
4. Form Processing: The input received from the form is processed at the server. The server-side scripts are used to process the input and generate appropriate outputs. The outputs are sent back to the web page to display the result to the user.
