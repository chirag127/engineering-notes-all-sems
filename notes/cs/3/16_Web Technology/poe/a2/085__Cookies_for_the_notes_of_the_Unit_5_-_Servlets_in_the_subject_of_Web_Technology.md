### Cookies for the notes of the Unit 5 - Servlets in the subject of Web Technology

1. Cookies are small pieces of data sent from a website and stored in the user's web browser while the user is browsing that website.
2. Cookies were designed to be a reliable mechanism for websites to remember stateful information (such as items added in the shopping cart in an online store) or to record the user's browsing activity (including clicking particular buttons, logging in, or recording which pages were visited in the past).
3. Cookies can store user preferences, web browser data, or identification credentials and can therefore be used to enhance the user experience. However, cookies can also pose privacy issues if they are used for tracking or other user profiling purposes.
4. The cookie is saved as a plain text file containing the website domain, the cookie name and the cookie value.
5. There are two types of cookies:
    1. Session cookies - These cookies get deleted when the user closes the browser window. They are used to store session identifiers and preferences.
    2. Persistent cookies - These cookies have expiration dates and are stored on the user's computer even after the user has left the website or closed the browser. They are used for storing user preferences and other website customizations.
6. Some key points about cookies:
    - Cookies are set via an HTTP response header.
    - Each website can set multiple cookies.
    - Each cookie has a name, value, domain and path.
    - The browser has the ability to accept or reject cookies.
    - Cookies can be accessed via JavaScript on the client side.
