### Statements for Unit 3 - Scripting Notes

1. Scripting is a way to implement dynamic features and logic on web pages. It allows web pages to be more interactive and customized to user needs.
2. The scripting language used for web pages is JavaScript. It is embedded into HTML pages and interpreted by the browser to provide dynamic functionality.
3. JavaScript can be used to validate forms, detect browsers, create cookies, redirect pages, detect mouse events like rollovers, create dynamic menus, create animations and much more.
4. JavaScript code is embedded into HTML pages within `<script>` tags or stored in external .js files and linked to HTML pages using `<script src="filename.js"></script>`.
5. JavaScript is an easy to learn scripting language with syntax similar to Java and C++, but it is interpreted and lightweight and integrated with HTML.
6. Key concepts in JavaScript include variables and data types, operators, control flows, functions, objects, built-in objects like Array and Date, DOM manipulation, and JavaScript events.
7. JavaScript can be used to create dynamic web pages by manipulating the DOM to change styles, content, add/remove elements, react to events, and more without reloading the page.
8. JavaScript code can be placed in the `<head>` or `<body>` of HTML pages or in external .js files. External files are better for organization and caching.
9. JavaScript running in the browser can access the DOM of the HTML page and store data in the form of variables and objects to create dynamic web pages.
