## Unit 2 - Web Page Designing

1. Introduction to HTML
- HTML stands for Hypertext Markup Language
- It is the main markup language used to create web pages
- HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page
- Each HTML tag consists of a start tag and an end tag with content in between
- HTML tags are not displayed on the web page and are used to define the structure and semantics of the web page

2. HTML Elements
- An HTML element refers to the start tag, end tag, and the content between them
- Examples of HTML elements: <p>Paragraph</p>, <h1>Heading</h1>, <img src="image.jpg">
- HTML elements can have attributes which provide additional information about the element
- HTML elements can be nested within each other
- Proper nesting of HTML elements is important to create a valid HTML document

3. HTML Comments
- HTML comments are not displayed on the web page and can be used to:
- Explain sections of HTML code
- Hide parts of HTML code
- Leave notes for other web developers
- HTML comments are written as <!-- This is a comment -->
