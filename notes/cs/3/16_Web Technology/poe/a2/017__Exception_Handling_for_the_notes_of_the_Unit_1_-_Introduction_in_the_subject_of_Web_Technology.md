### Exception Handling for the notes of the Unit 1 - Introduction in the subject of Web Technology.

1. Exceptions: Exceptions are errors that occur during the execution of a program. They disrupt the normal flow of the program.
2. Types of Exceptions: There are mainly two types of exceptions:
    1. Compile time exceptions: These occur during compilation of the program. For example, syntax errors.
    2. Run time exceptions: These occur during the execution of the program. For example, divide by zero error.
3. Handling exceptions: We can handle exceptions in our program using try, catch and finally blocks.
    1. Try block: The code that can cause an exception is written inside the try block.
    2. Catch block: The catch block contains the code that will execute if an exception occurs in the try block. It catches the exception.
    3. Finally block: The finally block contains code that will always execute whether or not an exception occurs. It is used to cleanup resources.
4. Throwing exceptions: We can also throw exceptions in our program if a condition occurs that is not ideal. We use the throw keyword to throw an exception.
5. Custom exceptions: We can also define our own exceptions by creating custom exception classes that extend the Exception class.
