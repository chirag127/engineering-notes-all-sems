### CSS for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style a web page and define the look and formatting of a web page.
3. CSS is used to separate the presentation of the HTML document from the content of the HTML document.
4. CSS makes it easy to change the look and feel of multiple web pages at once by changing only one CSS file.
5. The advantages of using CSS are:
- Easy maintenance: By using CSS, we can change the look of the entire web site by changing just one single CSS file.
- Browser compatibility: Different browsers interpret web pages in their own ways. By using CSS, we can have a consistent look across multiple browsers.
- Faster loading web pages: CSS files are cached by the browser, and hence the subsequent pages loads faster.
- Multiple formats: CSS supports multiple formats for images such as PNG, JPG, GIF etc.
