### Operator for the notes of the Unit 1 - Introduction in the subject of Web Technology.

1. HTML: HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page and its content.

2. CSS: CSS stands for Cascading Style Sheets. It is used to style the HTML elements and define how the content should look. Using CSS, we can control the fonts, colors, spacing, and other styles of a webpage.

3. JavaScript: JavaScript is a lightweight, interpreted programming or scripting language that is typically embedded into web pages. It allows web pages to be interactive and dynamic. Using JavaScript, we can perform various tasks like input validation, displaying pop up messages, redirecting pages, etc.

4. Web Browser: A web browser is an application software that is used to access and display web pages. Popular web browsers include Chrome, Firefox, Edge, Safari, Opera, etc. The web browser retrieves the HTML document from a web server and renders the content on the screen.

5. Web Server: A web server is a computer program that delivers web pages. It stores, processes and delivers web pages to users on the internet. The web server uses HTTP and communicates with the web browser to serve web pages. Some popular web servers are Apache HTTP server, Nginx, Microsoft IIS, etc.
