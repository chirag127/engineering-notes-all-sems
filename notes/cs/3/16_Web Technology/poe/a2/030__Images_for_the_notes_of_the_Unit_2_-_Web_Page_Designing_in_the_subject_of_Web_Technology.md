### Images for the notes of the Unit 2 - Web Page Designing

1. Images add visual appeal and interest to a web page. They bring information and page content to life and improve the user experience.
2. Some important points to keep in mind when using images on web pages:
- Choose images that are relevant to the page content and that enhance the user experience. Do not include images just for decoration.
- Optimize images for web use. This means choosing the appropriate file format and size. Larger file sizes lead to slower page loading.
- Include alternative text (alt text) for all images. This provides a description of the image for users who cannot see the image. Alt text is required for accessibility and SEO.
- Ensure there is proper contrast between image and background colors for accessibility.
3. Popular image file formats for web pages include:
- JPEG/JPG - best for photos with lots of colors and gradients
- PNG - best for logos and graphics with text/lines/shapes
- GIF - best for simple graphics and animated images
- SVG - an XML-based format ideal for logos and icons as it is scalable
4. To insert images into a web page, use the <img> element and specify the source of the image using the src attribute. You can also include alt text within the <img> element. Example:
<img src="images/logo.png" alt="Company logo">

5. Images can be aligned to the left, right, and center of a page and adjusted to fit the width or height of the browser window using CSS styling properties. This helps create a more visually appealing layout.
