### HTML for the notes of the Unit 2 - Web Page Designing

1. HTML stands for Hypertext Markup Language. It is the main markup language used to create web pages.
2. HTML uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page.
3. The <html> tag is the root element that tells the browser the page is written using HTML.
4. The <head> tag contains metadata about the page. The <title> tag inside <head> specifies the title of the web page that is displayed on the browser tab and as a heading in search engines.
5. The <body> tag contains the main content that is displayed on the web page. Headings, paragraphs, images, links, and other elements lie inside the <body> tag.
6. Headings are defined using <h1> to <h6> tags. <h1> specifies the most important heading and <h6> specifies the least important heading.
7. Paragraphs are defined using the <p> tag. The </p> tag marks the end of a paragraph.
8. Images are included in HTML using the <img> tag. The src attribute specifies the URL or path of the image.
9. Links are created using the <a> (anchor) tag. The href attribute specifies the URL of the linked resource.
10. HTML documents are saved with a .html or .htm extension. The basic structure of an HTML document is as given above with the <html>, <head>, and <body> tags and elements inside the body tag to add content.
