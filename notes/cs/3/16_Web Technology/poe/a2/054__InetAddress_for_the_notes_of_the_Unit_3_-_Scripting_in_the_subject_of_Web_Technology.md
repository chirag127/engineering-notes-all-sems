### InetAddress

- InetAddress is a class in Java that represents an Internet Protocol (IP) address.
- It is used to get information about the local host, perform domain name resolution, etc.
- Some important methods of InetAddress class are:

-- getLocalHost(): Returns the local host.
-- getHostName(): Returns the hostname.
-- getHostAddress(): Returns the IP address in text representation.
-- isReachable(int timeout): Checks if the IP Address is reachable within the provided timeout in milliseconds. Returns boolean.
-- getAllByName(String host): Returns an array of all the IP addresses for the given hostname.
-- reverseLookup(): Performs reverse host name resolution.

- The InetAddress class supports both IPv4 and IPv6 address formats.
- We can create an InetAddress object by passing the IP address or hostname to its constructor.
- The InetAddress class is very useful to get information about the network the application is running on. It helps in tasks like domain name resolution, checking the reachability of a host, etc.
