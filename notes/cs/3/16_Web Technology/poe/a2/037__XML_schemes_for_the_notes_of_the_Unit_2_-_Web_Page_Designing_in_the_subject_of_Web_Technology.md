### XML schemes for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML stands for Extensible Markup Language. It is a markup language used to define data.
2. XML uses tags similar to HTML but the tags are user-defined. We can define our own set of tags and attributes to suit our needs.
3. The XML document has a tree structure with a root element. All other elements are children of the root element.
4. Every XML element has an opening tag and a closing tag with the content in between them.
5. XML elements must be properly nested within each other.
6. XML documents are case-sensitive. The opening and closing tags must have the same case.
7. XML documents can be validated against a document type definition (DTD) or XML Schema to check for proper structure.
8. XML is a platform and language independent format designed to store and transport data.
9. The XML format makes it easy for machines to parse and generate data. This makes it suitable for data interchange on the web.
