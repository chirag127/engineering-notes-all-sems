### Introduction for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Scripting languages: Scripting languages are programming languages that are interpreted at runtime instead of being compiled in advance. Some of the popular scripting languages for web are:
- JavaScript: It is the dominant scripting language of the web. It can be embedded into HTML pages and can react to user events, display pop-up messages, redirect web pages, detect web browsers, and much more.
- PHP: It is a server-side scripting language. PHP code is executed on the server and its output is sent to the browser. It is often used to create database-driven web pages.
- Python: It is an easy to learn and powerful scripting language. It can be used on both the client-side and server-side. The Django framework allows Python to be used for both web development and server-side web applications.

2. Uses of scripting languages in web technology: Scripting languages are used in web technology for the following purposes:
- To make web pages more interactive, interesting, and dynamic
- To validate web forms and user input
- To access databases and other web services
- To customize web pages based on user preferences or profiles
- To create dynamic and data-driven web applications

3. Importance of learning scripting languages: It is important to learn scripting languages for web technology because:
- They enable us to create interactive and dynamic web pages
- They reduce the amount of HTML coding required and make web pages more efficient
- They provide more functionality and power to web pages
- They are essential to develop web applications and access databases
- Knowledge of scripting languages enhances the skills of web developers and designers
