### Networking for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Network: Interconnection of multiple devices configured in a pattern enabling them to communicate and exchange data.
2. Types of Networks:
- LAN: Local Area Network connecting devices in a small physical location like home, office, etc. Uses network devices like routers, switches, etc.
- WAN: Wide Area Network connecting geographically separated areas. Uses leased lines or VPN connections routed through ISP's networks.
3. Network Devices:
- Repeater: Amplifies signals and regenerates them. Used for extending network range.
- Hub: Connects multiple Ethernet devices and replicates data to all ports. Single collision domain.
- Switch: Connects multiple devices and sends data only to the destination device.Separate collision domains for each port.
- Router: Connects multiple networks and routes data to the destination network based on IP addresses.
4. Network Protocols:
- ICMP: Internet Control Message Protocol for network diagnostics and troubleshooting.
- TCP: Transmission Control Protocol for reliable data transmission with checks and acknowledgements.
- UDP: User Datagram Protocol for fast data transmission without checks and acknowledgements.
- IP: Internet Protocol for logical addressing and routing of data packets.
- HTTP: Hypertext Transfer Protocol for communication between web servers and browsers.
