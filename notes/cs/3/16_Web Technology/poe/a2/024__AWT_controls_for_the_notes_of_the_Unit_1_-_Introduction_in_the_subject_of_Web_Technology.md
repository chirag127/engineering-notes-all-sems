### AWT controls for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Java AWT (Abstract Windowing Toolkit) is a library that provides GUI components to develop desktop applications.
2. Some of the commonly used AWT components are:
- Label: Used to display text/image on the interface.
- Button: Used to display buttons to get user input.
- TextField: Used to get single line text input from user.
- TextArea: Used to get multi-line text input from user.
- Checkbox: Used to get a binary input (yes/no, true/false) from user.
- Choice: Used to get a user choice from a list of options.
- List: Used to get multiple user choices from a list of options.
3. All AWT components are encapsulated in a container called Frame which has title bar, border, etc. Similar to windows in operating systems.
4. Java AWT components have counterparts in Swing library which provide more enhanced GUI features. However, AWT components are lightweight and suitable for simple GUI based applications.
