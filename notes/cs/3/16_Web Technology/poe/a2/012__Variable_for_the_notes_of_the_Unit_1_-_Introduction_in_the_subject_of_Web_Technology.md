### Variable for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Variable: A variable is a container which holds the value that can be changed. In programming, variables are used to store data values and to refer to them by a readable name.
2. Data type: Every variable has a data type which determines the type of value that can be stored in it. For example, a variable can store integer values, decimal values, character values, etc. based on its data type.
3. Declaration: Before using a variable, it must be declared. Variable declaration means specifying the data type and name of the variable. For example, int age; //declares an integer type variable "age".
4. Initialization: Initialization refers to assigning an initial value to a variable. A variable must be initialized before its value can be used. For example, age = 30; //initializes the variable age with value 30.
5. Scope: The scope of a variable refers to the area of the program where the variable can be accessed. The scope can be global or local. A global variable can be accessed anywhere in the program, whereas a local variable can only be accessed within the block in which it is defined.
