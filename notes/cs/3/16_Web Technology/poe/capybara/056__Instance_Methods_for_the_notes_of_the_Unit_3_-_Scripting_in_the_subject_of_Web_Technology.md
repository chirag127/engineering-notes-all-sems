### Instance Methods for the notes of the Unit 3 - Scripting in the subject of Web Technology

In the context of scripting for web technology, instance methods are a powerful tool that allow for dynamic and interactive web applications. Here are some important instance methods to keep in mind:

- `getElementById()`: This method allows you to access an HTML element by its unique ID. This can be useful for dynamically updating content on a web page, such as changing the text of a headline or updating an image.

- `addEventListener()`: This method lets you define a function to be called whenever a specific event occurs on a HTML element, such as a button click or a mouse hover.

- `setAttribute()`: With this method, you can set or update the value of an attribute on an HTML element, such as the `src` attribute of an image or the `href` attribute of a link.

- `appendChild()`: This method allows you to add a new child element to an existing HTML element. This is often used for dynamically generating lists or tables on a web page.

- `removeChild()`: The opposite of `appendChild()`, this method lets you remove a child element from an existing HTML element.

- `createElement()`: This method creates a new HTML element with the specified tag name. This can be useful for dynamically generating content on a web page, such as adding a new paragraph or image.

- `innerHTML()`: This method allows you to set or update the HTML content of an element. This can be useful for dynamically updating the text or structure of a web page.

By mastering these instance methods, you can take your web scripting skills to the next level and create dynamic and interactive web applications.
