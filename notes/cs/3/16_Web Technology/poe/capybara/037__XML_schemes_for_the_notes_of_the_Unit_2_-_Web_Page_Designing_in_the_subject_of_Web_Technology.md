### XML Schemes for the Notes of Unit 2 - Web Page Designing in the Subject of Web Technology

XML or eXtensible Markup Language is a widely-used language for storing and transporting data. In the field of web technology, XML is used to describe and structure data in a way that can be easily processed by computers. The following are the essential XML schemes that every web designer should know:

1. **Document Type Definition (DTD):** DTD is a set of rules that define the structure and content of an XML document. It specifies the elements and attributes that can be used in an XML document and their relationships. DTD is used to validate the structure of an XML document.

2. **XML Schema Definition (XSD):** XSD is an XML-based language used to define the structure and content of an XML document. It provides a more powerful and flexible way to define the structure of an XML document than DTD. XSD supports data types, namespaces, and inheritance.

3. **XPath:** XPath is a language used to navigate an XML document and select elements and attributes based on their properties. It is used to extract data from an XML document and is often used in conjunction with XSLT.

4. **XSL Transformations (XSLT):** XSLT is a language used to transform an XML document into another document or format. It is often used to transform XML data into HTML or PDF format. XSLT uses XPath to select and manipulate elements in an XML document.

5. **XML Namespaces:** XML namespaces are used to avoid naming conflicts in an XML document. They provide a way to distinguish between elements and attributes that have the same name but different meanings. XML namespaces are defined using a Uniform Resource Identifier (URI).

In conclusion, understanding the above XML schemes is essential for web designers to create and manipulate XML documents effectively. These schemes provide a way to define the structure and content of an XML document, navigate and select elements, and transform XML data into other formats.
