### Manipulating for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

Enterprise Java Beans (EJB) is a framework used for developing robust, scalable and secure enterprise applications. This framework provides a set of APIs for building distributed, transactional and multi-tiered applications. In this unit, we will learn how to manipulate EJBs for developing enterprise applications. 

Here are some key concepts to take note of:

- EJBs are server-side components that are used to build enterprise applications. They are used to manage business logic, data persistence, and security of the application.
- EJBs can be of three types: Session Beans, Message-Driven Beans, and Entity Beans. 
- Session Beans are used to represent the business logic of the application. They can be of two types: Stateful and Stateless.
- Message-Driven Beans are used to receive and process messages asynchronously.
- Entity Beans are used to represent the data persistence layer of the application. They can be of two types: Container-Managed Persistence (CMP) and Bean-Managed Persistence (BMP).
- EJBs can be accessed remotely through Remote Method Invocation (RMI) or locally through the Local Interface.
- EJBs can be configured using annotations or XML deployment descriptors.

To manipulate EJBs effectively, it is important to have a good understanding of the following concepts:

- EJB Lifecycle: The lifecycle of an EJB is managed by the container. It includes four stages: Creation, Initialization, Invocation, and Destruction.
- EJB Container: The EJB container provides the runtime environment for the EJBs. It is responsible for managing the lifecycle of EJBs, providing security, and transaction management.
- EJB Transactions: EJBs support distributed transactions using the Java Transaction API (JTA). Transactions ensure data consistency and integrity.
- EJB Security: EJBs can be secured using declarative or programmatic security. Declarative security is done using annotations or XML deployment descriptors. Programmatic security is done using the Security API.

In conclusion, EJBs are an essential framework for building enterprise applications. Understanding the concepts of EJBs and their manipulation is crucial for developing robust, scalable, and secure enterprise applications.
