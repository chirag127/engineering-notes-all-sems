### A First Java Server Page Example

Java Server Pages (JSP) is a technology that allows developers to create dynamic web pages. In this tutorial, we will demonstrate how to create a simple JSP that displays a message.

#### Prerequisites

- Knowledge of HTML and Java programming language.
- A web server such as Apache Tomcat.

#### Creating the JSP File

1. Open your text editor and create a new file.
2. Save the file with a .jsp extension (e.g., `hello.jsp`).
3. Add the following code to the file:

```jsp
<html>
  <head>
    <title>Hello World!</title>
  </head>
  <body>
    <h1>Hello World!</h1>
  </body>
</html>
```

4. Save the file.

#### Deploying the JSP File

1. Copy the `hello.jsp` file to the appropriate directory on your web server (e.g., `webapps/ROOT` for Tomcat).
2. Start your web server.
3. Open your web browser and navigate to `http://localhost:8080/hello.jsp`.
4. You should see the message "Hello World!" displayed in your browser.

#### Conclusion

Congratulations! You have successfully created your first JSP. This is just a simple example, but JSPs can be used to create much more complex web applications. With this basic knowledge, you can start building your own dynamic web pages using JSPs.
