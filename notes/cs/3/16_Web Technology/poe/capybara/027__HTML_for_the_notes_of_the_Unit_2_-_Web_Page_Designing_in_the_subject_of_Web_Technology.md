### HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

HTML, or HyperText Markup Language, is the standard markup language used to create web pages. It is a markup language that defines the structure and content of a web page.

Some important points to remember about HTML are:

- HTML is the foundation of any web page. It provides the structure and content for the page.
- HTML is a markup language, which means that it uses tags to define the structure and content of the page. Tags are enclosed in angle brackets, like this: `<tag>`.
- HTML documents are made up of elements, which are composed of tags and content. The content is the text or other media that appears on the page.
- HTML documents are hierarchical. Elements can contain other elements, creating a nested structure. This structure is important for creating a well-organized and easy-to-read page.
- HTML documents are typically saved with the file extension .html or .htm.
- HTML documents can be created using a simple text editor like Notepad, or using more advanced tools like Adobe Dreamweaver.

Some commonly used HTML tags include:

- `<html>`: This tag indicates the beginning of an HTML document.
- `<head>`: This tag contains information about the document, like the title and meta data.
- `<body>`: This tag contains the content of the document.
- `<h1>`, `<h2>`, `<h3>`, etc.: These tags are used to create headings of different sizes.
- `<p>`: This tag is used to create paragraphs of text.
- `<a>`: This tag is used to create hyperlinks to other web pages or resources.
- `<img>`: This tag is used to insert images into the document.
- `<ul>` and `<li>`: These tags are used to create unordered lists of items.
- `<ol>` and `<li>`: These tags are used to create ordered lists of items.

Overall, HTML is an essential tool for anyone interested in web page designing. It provides the foundation for creating well-structured and organized pages that are easy to read and navigate.
