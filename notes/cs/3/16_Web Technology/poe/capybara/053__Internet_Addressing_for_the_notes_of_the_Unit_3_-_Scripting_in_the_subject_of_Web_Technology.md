### Internet Addressing

Internet Addressing is one of the key components of the Internet. It is the process of assigning unique identifiers to devices connected to the Internet. These unique identifiers are called IP addresses.

Following are the key aspects of Internet Addressing:

- **IP Address:** An IP address is a unique identifier assigned to devices connected to the Internet. It consists of a series of four numbers separated by dots, for example, `192.168.1.1`. There are two types of IP addresses - IPv4 and IPv6. IPv4 addresses are 32-bit long and IPv6 addresses are 128-bit long.
- **Domain Name System (DNS):** DNS is a system that maps domain names to IP addresses. It is a hierarchical naming system. The top-level domain (TLD) is at the highest level of the hierarchy, followed by second-level domains, and so on. For example, `www.example.com` is a domain name, where `.com` is the TLD and `example` is the second-level domain.
- **Uniform Resource Locator (URL):** A URL is a string of characters that identifies a web page. It consists of a protocol, domain name, and path. For example, `https://www.example.com/index.html` is a URL. The protocol is `https`, the domain name is `www.example.com`, and the path is `/index.html`.
- **Ports:** A port is a logical construct that identifies a specific process or service running on a device. Ports are identified by numbers ranging from 0 to 65535. Some well-known ports are 80 (HTTP), 443 (HTTPS), and 21 (FTP).

In conclusion, Internet Addressing plays a crucial role in the functioning of the Internet. It enables devices to communicate with each other and access web pages. Understanding Internet Addressing is essential for anyone working with web technologies.
