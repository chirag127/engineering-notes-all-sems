### Joining for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

Here are some important points to keep in mind while studying Enterprise Java Bean:

- Enterprise Java Bean (EJB) is a server-side software component that encapsulates the business logic of an application. It is used to develop scalable, distributed, and transactional applications.
- There are three types of EJBs - Session Beans, Message-Driven Beans, and Entity Beans. Each type serves a specific purpose and has its own set of characteristics.
- Session Beans are used to represent a single client's conversation with an EJB container. They are of two types - Stateful Session Beans and Stateless Session Beans.
- Message-Driven Beans are used to receive and process messages asynchronously. They are designed to handle high-volume, message-based applications.
- Entity Beans represent persistent data in a database. They are of two types - Container-Managed Entity Beans and Bean-Managed Entity Beans.
- EJBs are managed by an EJB container that provides services such as lifecycle management, security, and transaction management.
- EJBs can be accessed by clients using Remote Method Invocation (RMI), Java Naming and Directory Interface (JNDI), or web services.
- EJBs are developed using the Java Enterprise Edition (Java EE) platform and can be deployed on any Java EE-compliant application server.
- EJBs provide several benefits such as scalability, transaction management, security, and resource pooling.
