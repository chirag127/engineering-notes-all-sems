### AWT Controls

The Abstract Window Toolkit (AWT) is a set of classes for creating graphical user interfaces (GUI) in Java. The AWT provides various controls that can be used to create different types of user interface components. Here are some of the commonly used AWT controls:

1. Label
- A Label is used to display text or an image on a GUI.
- It cannot be edited by the user.
- Syntax: `Label l = new Label("Hello World");`

2. Button
- A Button is used to trigger an action when clicked by the user.
- Syntax: `Button b = new Button("Click me");`

3. TextField
- A TextField is used to accept input from the user.
- Syntax: `TextField tf = new TextField();`

4. TextArea
- A TextArea is used to display and accept multiple lines of text from the user.
- Syntax: `TextArea ta = new TextArea();`

5. Checkbox
- A Checkbox is used to allow the user to select one or more options.
- Syntax: `Checkbox cb = new Checkbox("Option 1");`

6. Choice
- A Choice is used to allow the user to select one option from a dropdown list.
- Syntax: `Choice c = new Choice();`

7. List
- A List is used to allow the user to select one or more options from a list of items.
- Syntax: `List list = new List();`

8. Scrollbar
- A Scrollbar is used to allow the user to scroll through a large amount of content.
- Syntax: `Scrollbar sb = new Scrollbar();`

9. Panel
- A Panel is a container for other GUI components.
- It is used to organize and layout the components on the GUI.
- Syntax: `Panel p = new Panel();`

10. Frame
- A Frame is a top-level container for a GUI.
- It is used to create a window for the GUI.
- Syntax: `Frame f = new Frame("My Frame");`

These are some of the commonly used AWT controls. Understanding these controls is important for creating effective and user-friendly GUIs in Java.
