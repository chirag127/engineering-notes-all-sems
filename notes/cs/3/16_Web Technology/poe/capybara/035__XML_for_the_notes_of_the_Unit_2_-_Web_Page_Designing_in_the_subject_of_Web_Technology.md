### XML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

XML or Extensible Markup Language is a markup language used for storing and transporting data. It is widely used in web page designing and web development. Here are some important points to note about XML:

- XML uses a set of rules for encoding documents in a format that is both human-readable and machine-readable.
- XML can be used to create custom tags and attributes, making it a flexible and versatile markup language.
- XML is often used to store data that needs to be exchanged between different systems and applications.
- XML documents are hierarchical in nature, with a root element that contains all other elements within the document.
- XML documents can be validated using a Document Type Definition (DTD) or an XML Schema, which ensures that the document conforms to a specific set of rules.
- XML is not a programming language, but it can be used in conjunction with programming languages such as Java, PHP, and .NET.
- XML documents can be transformed using XSLT (Extensible Stylesheet Language Transformations) to create different output formats such as HTML, PDF, or CSV.

In web page designing, XML is often used to create structured data that can be easily accessed and manipulated by other systems and applications. XML is also used to exchange data between web services using SOAP (Simple Object Access Protocol) and REST (Representational State Transfer) APIs.

Overall, XML is an important technology for web page designing and web development, and it is essential for web developers to have a good understanding of its capabilities and limitations.
