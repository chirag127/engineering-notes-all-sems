### List for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Here are some important points to take note of when studying web page designing in Web Technology:

- **HTML (Hypertext Markup Language)**: This is the foundation of web page designing. HTML is responsible for the structure of a web page. It uses tags to mark up content such as headings, paragraphs, images, links, and more.
- **CSS (Cascading Style Sheets)**: CSS is used to style and layout the HTML content of a web page. It allows designers to control the appearance of elements such as text, colors, images, and layout. CSS can be applied to a single web page or to an entire website.
- **Responsive Design**: With the increasing use of mobile devices, it is important for websites to adapt to different screen sizes. Responsive design ensures that a website is easy to use and navigate on any device, from a desktop computer to a smartphone.
- **Web Design Principles**: Designing a web page requires more than just knowledge of HTML and CSS. It also involves understanding web design principles such as balance, contrast, alignment, and hierarchy. These principles help to create a visually appealing and easy to use website.
- **User Experience (UX)**: UX is the overall experience a user has while interacting with a website. It involves designing a website that is easy to navigate, intuitive to use, and visually appealing. Good UX design can help increase user engagement and retention.
- **Web Accessibility**: Web accessibility is the practice of designing and developing websites that can be used by people with disabilities. It involves making sure that websites are perceivable, operable, understandable, and robust for all users, including those with visual, auditory, motor, and cognitive disabilities.
- **Web Hosting**: Once a web page is designed, it needs to be hosted on a web server so that it can be accessed by users. Web hosting involves choosing a hosting provider, uploading the web page files, and configuring the server settings.

These are just a few important points to keep in mind when studying web page designing in Web Technology. It is important to have a strong foundation in HTML and CSS, as well as an understanding of design principles, UX, web accessibility, and web hosting. With these skills, you can design and develop effective and user-friendly websites.
