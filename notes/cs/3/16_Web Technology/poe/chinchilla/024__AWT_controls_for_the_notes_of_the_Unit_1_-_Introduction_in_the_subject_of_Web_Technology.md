### AWT controls for the notes of the Unit 1 - Introduction in the subject of Web Technology

In the world of web technology, AWT (Abstract Window Toolkit) controls are essential components for creating graphical user interfaces (GUIs). AWT provides a set of UI components that can be used to create various types of user interfaces such as windows, buttons, labels, text fields, and more.

Here are some of the key AWT controls that you should be familiar with:

1. **Frame:** A Frame is a top-level window that can be used to display other components. It can have a title, borders, and menu bar. You can create a frame using the `Frame` class.

2. **Button:** A Button is a simple clickable UI component that can be used to trigger an action. You can create a button using the `Button` class.

3. **Label:** A Label is a non-editable UI component that can display text or an image. You can create a label using the `Label` class.

4. **TextField:** A TextField is an editable UI component that can be used to input text. You can create a text field using the `TextField` class.

5. **TextArea:** A TextArea is an editable UI component that can be used to input multi-line text. You can create a text area using the `TextArea` class.

6. **Checkbox:** A Checkbox is a UI component that can be used to select one or more options from a list of options. You can create a checkbox using the `Checkbox` class.

7. **Choice:** A Choice is a UI component that can be used to select one option from a list of options. You can create a choice using the `Choice` class.

8. **List:** A List is a UI component that can be used to display a list of items. You can create a list using the `List` class.

9. **Scrollbar:** A Scrollbar is a UI component that can be used to scroll through a large amount of data. You can create a scrollbar using the `Scrollbar` class.

10. **Panel:** A Panel is a container UI component that can be used to group other UI components. You can create a panel using the `Panel` class.

By mastering these AWT controls, you can create interactive and user-friendly GUIs for your web applications.
