### Table for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

In this unit, we will learn about the various aspects of web page designing. The following table summarizes the important points to keep in mind while designing a web page:

| Point | Description |
| --- | --- |
| **Layout** | The layout of a web page refers to the arrangement of its elements such as text, images, and videos. A good layout should be visually appealing, user-friendly, and should allow easy navigation. |
| **Color Scheme** | The color scheme of a web page should be consistent and should complement the content of the page. It should also be easy on the eyes and should not strain the user's vision. |
| **Typography** | The typography of a web page refers to the font, size, and spacing of the text. It should be easy to read and should complement the overall design of the page. |
| **Visual Hierarchy** | The visual hierarchy of a web page refers to the arrangement of its elements in order of importance. It helps users to easily navigate the page and find the information they are looking for. |
| **Images and Videos** | Images and videos can add visual interest to a web page. They should be relevant to the content and should be of high quality. |
| **Navigation** | Navigation refers to the way users move around a web page. It should be easy to understand and should allow users to quickly find what they are looking for. |
| **Responsive Design** | A web page should be designed to be responsive, i.e., it should be able to adjust to different screen sizes and devices. This makes it easier for users to access the page from any device. |
| **Accessibility** | A web page should be designed to be accessible to all users, including those with disabilities. This includes making sure that the page is easy to navigate, has descriptive alt text for images, and can be used with assistive technologies. |

By keeping these points in mind, you can design a web page that is visually appealing, user-friendly, and accessible to all users.
