### XML Schemes for the Notes of Unit 2 - Web Page Designing in the Subject of Web Technology

XML (Extensible Markup Language) is a markup language that is used to store and transport data. It is a standard format for exchanging data between different systems and platforms. In the context of web page designing, XML is used to define the structure and content of a web page. Here are some of the XML schemes that are commonly used in web page designing:

1. XHTML (Extensible Hypertext Markup Language):
   - A stricter version of HTML (Hypertext Markup Language).
   - Follows the XML syntax rules.
   - Defines the structure and content of a web page using tags.
   - Supports all the features of HTML, plus some additional features.
   - Used for creating web pages that are compatible with different systems and platforms.

2. RSS (Really Simple Syndication):
   - A format for distributing and sharing content on the web.
   - Uses XML to define the structure of the content.
   - Allows users to subscribe to a website and receive updates automatically.
   - Used for syndicating news, blogs, podcasts, and other types of content.

3. Atom:
   - A standard format for publishing and sharing web content.
   - Uses XML to define the structure of the content.
   - Similar to RSS, but more flexible and extensible.
   - Used for syndicating blogs, news, podcasts, and other types of content.

4. SVG (Scalable Vector Graphics):
   - A format for creating vector graphics on the web.
   - Uses XML to define the graphics elements.
   - Allows for high-quality graphics that can be scaled without loss of quality.
   - Used for creating logos, icons, diagrams, and other types of graphics.

5. MathML (Mathematical Markup Language):
   - A format for displaying mathematical equations on the web.
   - Uses XML to define the structure of the equations.
   - Allows for high-quality display of mathematical symbols and expressions.
   - Used for displaying mathematical content on web pages.

In conclusion, XML schemes are an important aspect of web page designing. By using XML, web designers can define the structure and content of a web page in a standard format that can be easily exchanged between different systems and platforms. The above-mentioned schemes are commonly used in web design and can help designers create high-quality, compatible web pages.
