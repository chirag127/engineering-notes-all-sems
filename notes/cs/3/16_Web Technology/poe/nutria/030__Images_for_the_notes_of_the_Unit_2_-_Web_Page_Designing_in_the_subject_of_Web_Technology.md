
### Images for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. Images are one of the most important elements of web page design. They can be used to enhance the look and feel of a website and to convey a message or emotion.

2. Images can be used to create a visual hierarchy on a page, allowing the user to quickly and easily understand the main points of the page.

3. Images can also be used to create a sense of depth and perspective, making the page more engaging and visually appealing.

4. Images should be optimized for the web, meaning they should be compressed to reduce file size and loading time.

5. Images should also be optimized for different devices, such as mobile devices, to ensure they look good on all screen sizes.

6. Images should be used sparingly to ensure the page does not become cluttered and overwhelming.

7. When using images, be sure to include alternative text (alt text) to ensure that the images are accessible to all users.
