

### Introduction to AWT

1. AWT stands for Abstract Window Toolkit and is a set of GUI components that allow developers to create graphical user interfaces (GUIs) for Java programs. 
2. It is a platform-independent API that allows developers to create GUIs that can run on any Java-supported platform. 
3. AWT components are built using native GUI components of the operating system, which means that the look and feel of AWT components are platform-dependent. 
4. AWT components are heavyweight, meaning that they are rendered directly by the operating system, making them slow and resource-intensive.
5. AWT components are event-driven, meaning that they respond to user input (such as mouse clicks and key presses) by generating events that can be handled by the program. 
6. AWT also contains a set of classes for creating and manipulating graphical objects such as lines, rectangles, and circles. 
7. AWT also contains a set of classes for working with fonts and colors.
