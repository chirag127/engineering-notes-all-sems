
### Joining for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

1. Enterprise Java Beans (EJB) are a type of server-side component designed to provide a secure and distributed computing environment for Java-based applications.

2. EJB components are typically deployed on a Java EE application server and can be used to create distributed applications that span multiple machines.

3. EJB components are composed of Enterprise Java Beans (EJBs) and Enterprise Java Bean Containers (EJBCs).

4. EJBs are Java classes that implement the business logic of an application, while EJBCs are responsible for managing the lifecycle of EJBs and providing access to them.

5. EJBs can be used to create a variety of applications, including web services, web applications, and enterprise applications.

6. To create an EJB application, the developer must define an EJB deployment descriptor, which is an XML document that describes the EJB components and their relationships.

7. The deployment descriptor defines the EJB components, the resources they require, and the security settings that will be applied to them.

8. Once the deployment descriptor is created, the EJB components can be deployed to the application server.

9. The application server then manages the lifecycle of the EJB components, providing them with the resources they need to run.

10. EJB applications can be deployed to multiple application servers, allowing them to be used in a distributed environment.
