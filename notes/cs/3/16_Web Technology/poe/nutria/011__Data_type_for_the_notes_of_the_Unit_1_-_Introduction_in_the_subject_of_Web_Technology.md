
### Data Type for the Notes of the Unit 1 - Introduction in the Subject of Web Technology

1. Primitive Data Types: Primitive data types are the most basic data types that are used to store information. They include integer, float, boolean, character, and string.

2. Reference Data Types: Reference data types are used to store a reference to an object. Examples include arrays, classes, and objects.

3. Structured Data Types: Structured data types are used to store data in a structured form. Examples include lists, dictionaries, and sets.

4. Unstructured Data Types: Unstructured data types are used to store data in an unstructured form. Examples include images, videos, and audio.
