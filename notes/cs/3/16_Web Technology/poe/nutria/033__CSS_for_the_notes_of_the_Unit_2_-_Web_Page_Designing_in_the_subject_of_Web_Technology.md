
### CSS for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. CSS stands for Cascading Style Sheets. It is a language used to define the look and feel of a web page.
2. CSS is used to control the layout of multiple web pages at once.
3. CSS is used to define the font, size, color, and other aspects of text on a web page.
4. CSS is used to define the background color, background images, borders, and other aspects of a web page.
5. CSS is used to define the positioning of elements on a web page.
6. CSS is used to define the spacing between elements on a web page.
7. CSS is used to define the size and shape of elements on a web page.
8. CSS is used to define the visibility of elements on a web page.
9. CSS is used to define the behavior of elements on a web page.
10. CSS is used to define the interactions between elements on a web page.
