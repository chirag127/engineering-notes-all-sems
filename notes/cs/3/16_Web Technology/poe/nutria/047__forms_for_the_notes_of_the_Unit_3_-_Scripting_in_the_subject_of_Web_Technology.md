
### Forms for the Notes of the Unit 3 - Scripting in the Subject of Web Technology

1. Forms are an essential element of web technology, as they allow users to interact with a website and provide data to the server. 
2. Forms can be created using HTML, which is a markup language used to structure and present content on the web. 
3. Forms are composed of different HTML elements such as text fields, checkboxes, radio buttons, and submit buttons. 
4. Each form element has an associated label, which allows users to identify the purpose of the element. 
5. Forms can also be used to validate user input, by using the HTML5 validation API. 
6. Client-side scripting languages such as JavaScript can be used to add additional functionality to forms, such as dynamic form elements and custom validation. 
7. Server-side scripting languages such as PHP and ASP can be used to process form data, such as storing it in a database or sending it via email.
