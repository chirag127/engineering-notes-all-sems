
### Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

1. Java is an object-oriented, class-based, general-purpose programming language developed by Sun Microsystems in 1995. It is designed to have as few implementation dependencies as possible.
2. Java is a strongly typed language, which means that all variables must first be declared before they can be used.
3. Java is platform independent, meaning that programs written in the language can run on any platform that supports the Java Virtual Machine (JVM).
4. Java is a secure language, as the JVM isolates code from the underlying system, helping to prevent malicious code from running on the system.
5. Java is an interpreted language, meaning that code is compiled into bytecode and then interpreted by the JVM.
6. Java is an object-oriented language, meaning that it is based on the concept of objects that contain both data and methods which act on the data.
7. Java is a multi-threaded language, meaning that multiple threads can be run simultaneously and can share the same memory space.
8. Java is an event-driven language, meaning that code can be written to respond to events such as user input or system events.
9. Java is a garbage-collected language, meaning that memory is managed automatically by the JVM and the programmer does not need to explicitly free up memory.
