
### Dynamic HTML 

Dynamic HTML (DHTML) is a collection of technologies used together to create interactive and animated web pages. DHTML is used for creating menus, forms, and other interactive elements on a web page. It is also used to create animations, transitions, and other visual effects.

* DHTML is based on HTML, CSS, and JavaScript. 
* HTML is used to structure and display content while CSS is used to style it. 
* JavaScript is used to make the web page dynamic and interactive. 
* DHTML is used to create menus, forms, and other interactive elements on a web page. 
* It is also used to create animations, transitions, and other visual effects. 
* DHTML can be used to create dynamic content that changes based on user input or other events. 
* DHTML can also be used to create games, interactive maps, and other interactive web applications. 
* DHTML is supported by all modern web browsers.
