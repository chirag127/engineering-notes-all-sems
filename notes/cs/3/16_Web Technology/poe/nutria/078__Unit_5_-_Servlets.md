
## Unit 5 - Servlets

1. Servlets are Java programs that run on a web server and act as a middle layer between a request coming from a web client and databases or applications on the HTTP server.

2. Servlets are used to process client requests and generate dynamic web content. They can also be used to manage sessions and store information about users.

3. Servlets are written in the Java programming language and are compiled into Java bytecode. They are then deployed to a server and run as part of a web application.

4. A servlet can be used to handle requests from web clients and generate responses based on the request. It can also be used to store data about a session, such as user preferences or shopping cart contents.

5. Servlets are managed by a servlet container, which is responsible for loading and unloading servlets, as well as providing services such as security, request handling, and session management.

6. Servlets are widely used in web applications, and are the foundation of many popular web frameworks such as JavaServer Faces (JSF), Struts, and Spring MVC.
