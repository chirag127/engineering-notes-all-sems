
### Exception Handling for Unit 1 - Introduction in Web Technology

* Exception handling is the process of responding to the occurrence of exceptions, special conditions that change the normal flow of program execution. 
* Exceptions can be handled using the try-catch-finally construct in many programming languages. 
* In Java, exception handling is done using five keywords: try, catch, throw, throws, and finally. 
* The try block contains the code that may throw an exception. 
* The catch block contains the code that handles the exception. 
* The finally block contains the code that is always executed, regardless of whether an exception was thrown or not. 
* The throw keyword is used to throw an exception. 
* The throws keyword is used to declare an exception. 
* Exceptions can be user-defined or predefined. 
* Commonly used predefined exceptions include ArithmeticException, NullPointerException, ArrayIndexOutOfBoundsException, and FileNotFoundException.
