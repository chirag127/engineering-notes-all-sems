
### Scripting for the Notes of the Unit 5 - Servlets in the Subject of Web Technology

1. Servlets are Java programs that are used to extend the capabilities of web servers. They are used to create dynamic web pages and provide a way to process user requests.

2. A servlet is a Java class designed to be executed within a web server. It is used to process requests from clients, such as web browsers, and generate a response.

3. The servlet is invoked by the web server when a request is received. The servlet can then process the request and generate a response.

4. The servlet API provides a set of classes and interfaces that define the servlet's behavior. The servlet API also contains classes that provide access to the web server's environment and its resources.

5. The servlet API is part of the Java Platform, Enterprise Edition (Java EE), which is a collection of technologies and APIs for developing web applications.

6. Servlets can be used to access databases, perform authentication and authorization, and generate dynamic web pages. They can also be used to process forms, store session data, and access web services.
