
### Cookies for the Notes of Unit 5 - Servlets in Web Technology 

1. A cookie is a small piece of data that is stored in a user's web browser. It is used to store information such as preferences and login details.
2. Cookies are sent from the web server to the user's browser, and the browser sends the cookie back to the server with each request.
3. Cookies are mainly used for authentication, storing site preferences, shopping cart contents, and tracking user behavior.
4. Servlets are server-side programs that run on a web server and generate dynamic web pages.
5. Servlets can be used to store and retrieve cookies from the browser.
6. Cookies can be set and retrieved using the `getCookies()` and `setCookies()` methods of the `HttpServletRequest` and `HttpServletResponse` objects.
7. Cookies can be used to store session data, such as the user's login information, in the browser.
8. Cookies are stored in the browser and sent to the server with each request, so they can be used to track user behavior.
9. Cookies should be used with caution, as they can be used to track users and collect personal information.
