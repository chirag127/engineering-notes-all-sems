
### A First Java Server Page Example for the notes of the Unit 5 - Servlets in the subject of Web Technology

1. JavaServer Pages (JSP) are a technology based on the Java programming language used to create dynamic webpages. 
2. JSPs are written in HTML with embedded Java code that is executed on the server. 
3. JSPs are compiled into Java servlets before they are executed. 
4. The servlets are then used to generate HTML output that is sent to the client. 
5. JSPs are often used to create web applications that interact with databases. 
6. JSPs can also be used to create custom tags that can be used in other JSPs. 
7. JSPs are a popular choice for creating dynamic webpages as they are easy to use and can be used to create powerful web applications.
