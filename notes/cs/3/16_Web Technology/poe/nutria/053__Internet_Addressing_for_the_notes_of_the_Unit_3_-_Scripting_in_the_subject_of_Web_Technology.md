
### Internet Addressing for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Internet addressing refers to the way in which computers on the internet communicate with each other. It is based on a set of rules known as the Internet Protocol (IP).

2. IP addresses are unique numerical labels that are assigned to each device connected to a computer network. They are used to identify and locate computers in the network.

3. In order to access the internet, a computer must have an IP address. This is usually assigned by an Internet Service Provider (ISP).

4. Domain names are used to make it easier to remember and type in a website address. They are converted into an IP address by a Domain Name System (DNS).

5. URLs (Uniform Resource Locators) are used to identify the location of a web page or file on the internet. They are composed of a domain name, a path, and a filename.

6. Scripting is a type of programming language used to automate tasks in web development. It is used to create dynamic web pages and can be used to create interactive web applications.

7. Scripting languages such as JavaScript, PHP, and Python are commonly used to create web applications. They can be used to add functionality to web pages, create user interfaces, and handle user input.
