

### AWT Controls for the Notes of Unit 1 - Introduction in Web Technology

1. Abstract Window Toolkit (AWT) is a set of Java classes and related components that allow developers to create graphical user interfaces (GUIs).

2. AWT components are the basic building blocks of a graphical user interface (GUI). These components include buttons, labels, text fields, check boxes, and other user interface elements.

3. AWT components are organized into a hierarchy of containers. At the top of the hierarchy is the Frame object, which contains all other components.

4. AWT components are event-driven, meaning they respond to user input (such as mouse clicks or keyboard presses).

5. AWT components can be used to create sophisticated user interfaces, including menus, dialog boxes, and other components.

6. AWT also provides support for layout managers, which allow developers to control the size and position of components within a container.
