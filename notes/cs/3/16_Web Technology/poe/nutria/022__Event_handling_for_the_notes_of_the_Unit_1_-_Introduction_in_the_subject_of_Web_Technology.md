
### Event Handling for Unit 1 - Introduction in Web Technology

1. Events are actions taken by a user or a script that triggers a response from the web page. Examples of events include clicking on a button, hovering over an image, or entering text into a form field.

2. Event handlers are used to respond to events and execute code when an event is triggered. Event handlers can be attached to elements in the HTML document, and can be written in JavaScript, HTML, or a combination of both.

3. Event bubbling is a process in which an event is triggered on an element, and then propagates up the DOM tree to the parent elements. Event bubbling allows a single event handler to be attached to a parent element, and respond to events triggered on any of its child elements.

4. Event capturing is the opposite of event bubbling, and allows an event handler to be attached to a parent element and respond to events triggered on any of its child elements.

5. Event delegation is a process in which an event handler is attached to a parent element and responds to events triggered on any of its child elements. Event delegation allows for more efficient event handling, as the event handler is only attached to the parent element, and does not need to be attached to each individual child element.
