
### HTML for the Notes of Unit 2 - Web Page Designing in Web Technology

1. HTML stands for Hypertext Markup Language and is the language used to structure and present content on the World Wide Web.
2. HTML documents are composed of elements, which are indicated by tags. Tags are enclosed in angle brackets (`< >`), and usually come in pairs.
3. HTML elements can have attributes, which provide additional information about an element. Attributes are defined within the start tag and usually come in name/value pairs.
4. HTML documents are rendered by web browsers, which interpret the HTML code and display the content accordingly.
5. HTML documents can be styled using Cascading Style Sheets (CSS). CSS is a language used to control the presentation and styling of HTML documents.
6. HTML documents can also contain scripts, which are used to add interactive features to web pages.
