
### Java Server Pages Overview for the Notes of Unit 5 - Servlets in Web Technology

1. Java Server Pages (JSP) is a server-side technology used to create dynamic web pages. It is an extension of the Java servlet technology and is based on the Java programming language.

2. JSP pages are written in HTML and can contain Java code that is executed on the server. This code can be used to generate dynamic content such as HTML pages, XML documents, and images.

3. The Java code in a JSP page is enclosed in special tags that indicate to the server that the code should be executed. These tags are known as JSP directives, actions, and scriptlets.

4. JSP pages are compiled into Java servlets by the web server. The servlet is then executed to generate the dynamic content.

5. JSP pages are used to create interactive web applications and can be used to connect to databases and other web services.

6. JSPs are often used to create web applications that are more complex than what can be created using HTML alone.
