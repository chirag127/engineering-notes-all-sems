
### Databases with JDBC for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

- Java Database Connectivity (JDBC) is an API for connecting to a database from a Java application. It provides a platform-independent and database-independent way of connecting to a database.
- JDBC allows Java applications to access any data stored in a database. It enables the transfer of data between a Java application and a database.
- JDBC provides a set of interfaces and classes that enable Java applications to connect to a database and perform database operations, such as querying and updating data.
- JDBC drivers provide a way for Java applications to access a database. They provide a bridge between the Java application and the database.
- Enterprise JavaBeans (EJB) is a server-side component model for Java applications. It provides a platform for developing and deploying distributed, transactional, secure and portable applications.
- EJB enables developers to create business components that can be deployed in any EJB-compliant application server.
- EJB components can be used to access and manipulate data stored in a database. They provide a way for applications to access data from a database using JDBC.
- EJB components can also be used to access other data sources, such as web services and message queues.
