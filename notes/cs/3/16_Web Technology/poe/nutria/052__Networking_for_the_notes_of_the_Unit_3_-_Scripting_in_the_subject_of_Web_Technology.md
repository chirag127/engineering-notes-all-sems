
### Networking for the notes of the Unit 3 - Scripting in the subject of Web Technology

1. Networking is the process of connecting two or more computers to each other using a network. It allows computers to share resources and communicate with one another.

2. Networking is used to share resources such as data, software, and hardware. It is also used to transfer files and to access the internet.

3. Networking technologies include Ethernet, Wi-Fi, and Bluetooth. Ethernet is a wired connection that is used to connect two or more computers together. Wi-Fi is a wireless connection that allows computers to access the internet. Bluetooth is a short-range wireless connection used to connect two or more devices.

4. Networking can be used to create a local area network (LAN) or a wide area network (WAN). A LAN is a private network that is used to connect computers within a local area. A WAN is a public network that is used to connect computers over a wide area.

5. Networking protocols are used to establish communication between two or more computers. Common protocols include TCP/IP, HTTP, and FTP.

6. Network security is used to protect networks from unauthorized access, malicious attacks, and data theft. Common security measures include firewalls, encryption, and authentication.
