

### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

* Frames are used to divide a web page into multiple sections, each of which can contain different content.
* Frames can be used to create a multi-column layout, with each column containing different content.
* Frames are created using the `<frameset>` tag and the `<frame>` tag.
* The `<frameset>` tag defines the rows and columns of the frameset, while the `<frame>` tag defines the content of each frame.
* Frames can also be nested to create a more complex layout.
* Frames can be used to create a navigation bar, with each frame containing a link to a different page.
* Frames can also be used to display multiple pages at once, such as a header, a sidebar, and the main content.
* Frames can be used to display multiple pages in different languages.
* Frames can be used to display different content for different screen sizes.
* Frames can be used to display different content for different browsers.
* Frames can be used to display different content for different devices.
* Frames can be used to display different content for different user roles.
