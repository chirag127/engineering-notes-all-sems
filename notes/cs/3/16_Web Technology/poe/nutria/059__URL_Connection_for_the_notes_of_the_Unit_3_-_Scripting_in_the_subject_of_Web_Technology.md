
### URL Connection for the Notes of Unit 3 - Scripting in Web Technology

1. A URL (Uniform Resource Locator) is a web address that is used to locate a particular web page or file on the Internet.
2. URLs are composed of several components, including the protocol, domain name, and path.
3. The protocol is the type of web address, such as HTTP or HTTPS.
4. The domain name is the unique web address of the website, such as example.com.
5. The path is the specific location of the page or file, such as /contact.html.
6. URLs are used to connect web pages and files to each other.
7. When a user clicks on a link, the browser sends a request to the server to retrieve the page or file specified in the URL.
8. URLs can also be used to pass data to a web page or file.
9. This data is usually passed via query strings, which are appended to the URL in the form of key-value pairs.
10. For example, a URL with the query string ?name=John would pass the value “John” to the web page or file.
