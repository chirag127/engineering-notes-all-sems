
### Objects for the Notes of the Unit 3 - Scripting in the Subject of Web Technology

1. Objects are data structures used to store data and methods that can be used to manipulate that data.
2. Objects are used in scripting languages to create dynamic web pages by providing methods for manipulating the data stored in the objects.
3. Objects can be created from a variety of sources, including built-in objects, user-defined objects, and third-party libraries.
4. Objects can be used to store data in a structured way, such as an array, a set, or a hash table.
5. Objects can also be used to store functions or methods, which can be used to manipulate the data stored in the object.
6. Objects can be used to create classes, which can be used to create instances of objects with the same properties and methods.
7. Objects can be used to create modules, which can be used to organize code into logical units.
8. Objects can be used to create libraries, which can be used to share code between different applications.
