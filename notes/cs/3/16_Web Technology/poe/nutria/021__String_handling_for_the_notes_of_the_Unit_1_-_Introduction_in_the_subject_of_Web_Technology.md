
### String Handling

* Strings are sequences of characters, such as letters, numbers, and symbols, that are used to represent text. 
* Strings are commonly used in web technologies to store and manipulate text data. 
* Strings can be created using single or double quotes, such as `'Hello World'` or `"Hello World"`. 
* Strings can be concatenated, or joined together, using the `+` operator. For example, `"Hello " + "World"` would result in `"Hello World"`.
* Strings can be indexed, or accessed, using square brackets. For example, `"Hello World"[0]` would result in `"H"`.
* Strings can be sliced, or portions of them can be accessed, using the `[ ]` operator. For example, `"Hello World"[0:5]` would result in `"Hello"`.
* Strings can be compared using the `==` operator. For example, `"Hello" == "Hello"` would result in `True`.
* Strings can be tested for membership using the `in` operator. For example, `"o" in "Hello"` would result in `True`.
* Strings can be converted to uppercase or lowercase using the `upper()` and `lower()` methods. For example, `"Hello".upper()` would result in `"HELLO"`.
* Strings can be searched using the `find()` method. For example, `"Hello".find("o")` would result in `4`.
