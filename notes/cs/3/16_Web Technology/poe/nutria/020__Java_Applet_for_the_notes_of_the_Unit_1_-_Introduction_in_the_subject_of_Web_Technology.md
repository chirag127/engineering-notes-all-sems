
### Java Applet for the Notes of the Unit 1 - Introduction in the Subject of Web Technology

1. Java applets are small programs written in the Java programming language and designed to be embedded within web pages.

2. Applet programs are usually executed within a web browser, such as Internet Explorer or Firefox.

3. Applet programs are typically restricted in terms of what they can do, as they are limited by the security restrictions of the web browser they are running in.

4. Java applets can be used to create interactive web pages, such as games, calculators, and other types of web-based applications.

5. Java applets can be used to create graphical user interfaces (GUIs) for web applications.

6. Java applets can be used to display dynamic content, such as animations and other types of graphics.

7. Java applets can also be used to process user input, such as form submissions and mouse clicks.

8. Java applets can be used to communicate with web servers and databases, allowing for more dynamic web pages and applications.
