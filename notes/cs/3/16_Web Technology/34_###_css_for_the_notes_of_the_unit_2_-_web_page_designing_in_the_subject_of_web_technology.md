### CSS for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

CSS in Web Page Designing:

CSS, or Cascading Style Sheets, is a style sheet language used for describing the look and formatting of a web page. CSS is used to separate the presentation of a web page from its content, allowing designers to change the look and feel of a web page without affecting the underlying HTML code.

CSS provides a wide range of styling options, including:

1. Fonts and typography: CSS provides a range of options for specifying font styles, sizes, and colors, as well as text alignment, spacing, and other typographical elements.

2. Colors and backgrounds: CSS provides a range of options for specifying colors, including color names, RGB values, and hexadecimal values. CSS also provides options for specifying background images and colors.

3. Layout and positioning: CSS provides a range of options for specifying the layout and positioning of elements on a web page, including options for specifying the width, height, and position of elements, as well as options for specifying the flow of text and other content.

4. Box model: CSS provides a box model for specifying the size and spacing of elements on a web page, including options for specifying margins, borders, and padding.

5. Transitions and animations: CSS provides options for specifying transitions and animations, allowing designers to create dynamic and interactive effects on a web page.

In conclusion, CSS is an essential tool for web page design, providing a wide range of options for specifying the look and formatting of a web page. CSS allows designers to separate the presentation of a web page from its content, making it possible to change the look and feel of a web page without affecting the underlying HTML code.
