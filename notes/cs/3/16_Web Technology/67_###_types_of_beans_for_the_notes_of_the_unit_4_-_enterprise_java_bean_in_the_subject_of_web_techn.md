### Types of beans for the notes of the Unit 4 - Enterprise Java Bean in the subject of Web Technology

Enterprise Java Beans (EJBs) are server-side components used to build scalable and secure Java EE applications. There are three types of EJBs:

1. Session Beans: Session beans are used to represent a single client-server session. They can be either stateful or stateless.

2. Stateful Session Beans: Stateful session beans maintain a conversational state with a client, meaning that the bean can remember information from one method call to another.

3. Stateless Session Beans: Stateless session beans do not maintain a conversational state with a client, meaning that the bean does not remember information from one method call to another.

4. Message-Driven Beans: Message-driven beans are used to process messages asynchronously. They are typically used for event-driven processing, such as processing messages from a JMS (Java Message Service) queue.

5. Entity Beans: Entity beans are used to represent persistent data, such as data stored in a database. Entity beans can be either bean-managed or container-managed.

In this unit, you will learn about the different types of Enterprise Java Beans (EJBs) and the key concepts related to them, including session beans, stateful session beans, stateless session beans, message-driven beans, and entity beans.

This unit will provide a foundation for understanding the principles and practices of Enterprise Java Beans (EJBs) and for exploring the various concepts and techniques used in the field of Web Technology.
