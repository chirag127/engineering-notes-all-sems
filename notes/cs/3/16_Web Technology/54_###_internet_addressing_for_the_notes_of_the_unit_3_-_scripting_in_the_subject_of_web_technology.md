### Internet Addressing for the notes of the Unit 3 - Scripting in the subject of Web Technology

Internet addressing is the system used to identify and locate resources on the Internet. The following are some of the key concepts related to Internet addressing:

1. IP Address: An IP address is a unique numerical identifier assigned to every device connected to the Internet. IP addresses are used to locate and communicate with devices on the Internet.

2. Domain Name System (DNS): The Domain Name System (DNS) is a hierarchical naming system used to translate domain names into IP addresses.

3. Domain Name: A domain name is a human-readable identifier for a resource on the Internet. Domain names are translated into IP addresses using the DNS.

4. URL: A URL (Uniform Resource Locator) is a string of characters that specifies the location of a resource on the Internet. URLs typically include the protocol, the domain name, and the path to the resource.

5. Protocol: A protocol is a set of rules and standards used for communication between devices on the Internet. Common protocols include HTTP (Hypertext Transfer Protocol) and FTP (File Transfer Protocol).

6. Port: A port is a logical communication endpoint used by applications to exchange data over the Internet. Different applications use different ports to communicate with each other.

In this unit, you will learn about Internet addressing and the key concepts related to it, including IP address, Domain Name System (DNS), domain name, URL, protocol, and port.

This unit will provide a foundation for understanding the principles and practices of Internet addressing and for exploring the various concepts and techniques used in the field of Web Technology.
