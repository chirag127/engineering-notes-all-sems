### Introduction to client-server computing for the notes of the Unit 1 - Introduction in the subject of Web Technology

Client-Server computing is a computing model that involves two components: the client and the server. The following are some of the key concepts related to client-server computing:

1. Client: A client is a computer or device that requests services or resources from a server.

2. Server: A server is a computer or device that provides services or resources to clients.

3. Request-Response: The client sends a request to the server, and the server sends a response back to the client. This is the basic communication pattern in client-server computing.

4. Network: A network is a collection of connected devices that can communicate with each other. Client-server computing typically involves a network, such as the Internet, to facilitate communication between the client and the server.

5. Protocol: A protocol is a set of rules that govern communication between the client and the server. The most common protocol used in client-server computing is the Transmission Control Protocol/Internet Protocol (TCP/IP).

6. Scalability: Scalability is the ability of a client-server system to handle an increasing number of clients and requests. Scalability is an important consideration in client-server computing, as it ensures that the system can handle increasing demand.

In this unit, you will learn about client-server computing and the key concepts related to it, including the client, the server, request-response, network, protocol, and scalability.

This unit will provide a foundation for understanding the principles and practices of client-server computing and for exploring the various concepts and techniques used in the field of Web Technology.
