### Datagram for the notes of the Unit 3 - Scripting in the subject of Web Technology

Datagram is a type of network data transmission that uses a simple, connectionless protocol to send and receive data packets over a network. The following are some of the key concepts related to datagrams:

1. Packets: Datagrams are sent and received as individual packets, each of which contains a small amount of data.

2. Connectionless: Datagrams are connectionless, meaning that there is no persistent connection between the sender and receiver of the data.

3. Best Effort Delivery: Datagrams are typically delivered on a best-effort basis, meaning that there is no guarantee that a datagram will be delivered to its intended recipient.

4. Ordering: Datagrams may arrive out of order, as there is no guarantee of the order in which they will be delivered.

5. Error Detection: Datagrams typically include error detection information, such as a checksum, to detect errors in the data.

6. Network Protocols: Datagrams can be used with a variety of network protocols, including the User Datagram Protocol (UDP) and the Datagram Congestion Control Protocol (DCCP).

In this unit, you will learn about datagrams and the key concepts related to them, including packets, connectionless, best-effort delivery, ordering, error detection, and network protocols.

This unit will provide a foundation for understanding the principles and practices of network data transmission and for exploring the various concepts and techniques used in the field of web technology.
