### Dynamic HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Unit 2 - Web Page Designing in the subject of Web Technology will cover Dynamic HTML (DHTML), a technology used to create dynamic and interactive web pages.

Dynamic HTML is a combination of HTML, CSS, and JavaScript that allows web developers to create web pages that respond to user actions and update dynamically without having to reload the page. This enables web developers to create more interactive and engaging web pages that provide a better user experience.

In the context of Unit 2 - Web Page Designing in the subject of Web Technology, students will learn about Dynamic HTML, including how to use HTML, CSS, and JavaScript to create dynamic and interactive web pages. This may include working with examples of DHTML, analyzing the syntax and structure of DHTML code, and learning how to use DHTML to create dynamic and interactive effects, such as drop-down menus, image rollovers, and dynamic content updates.

In Unit 2 - Web Page Designing in the subject of Web Technology, students will also learn about the benefits and limitations of using Dynamic HTML, and will learn about alternative approaches to creating dynamic and interactive web pages, such as using AJAX and other web technologies.

In summary, in Unit 2 - Web Page Designing in the subject of Web Technology, students will learn about Dynamic HTML, a technology used to create dynamic and interactive web pages. They will learn how to use HTML, CSS, and JavaScript to create dynamic and interactive web pages, and will learn about the benefits and limitations of using Dynamic HTML and alternative approaches to creating dynamic and interactive web pages.
