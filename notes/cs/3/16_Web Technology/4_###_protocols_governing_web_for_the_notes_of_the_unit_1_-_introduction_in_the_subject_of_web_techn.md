### Protocols Governing Web for the notes of the Unit 1 - Introduction in the subject of Web Technology

Protocols Governing Web refers to the set of rules and standards that govern the exchange of information over the World Wide Web (WWW). The following are some of the key concepts related to protocols governing web:

1. HTTP: HTTP (Hypertext Transfer Protocol) is the protocol used to transfer web pages and other information over the WWW. HTTP is a client-server protocol, which means that a client (such as a web browser) sends a request to a server, and the server sends a response back to the client.

2. HTTPS: HTTPS (Hypertext Transfer Protocol Secure) is a secure version of HTTP that uses encryption to protect the privacy and security of the information being transmitted over the WWW.

3. FTP: FTP (File Transfer Protocol) is a protocol used to transfer files over the Internet. FTP is often used to upload and download files, such as website files, from a server.

4. SMTP: SMTP (Simple Mail Transfer Protocol) is a protocol used to transfer email over the Internet. SMTP is used by email servers to send and receive email messages.

5. DNS: DNS (Domain Name System) is a system that maps domain names (such as www.example.com) to IP addresses (such as 192.168.0.1). DNS is used to translate domain names into IP addresses, so that web browsers can connect to web servers.

In this unit, you will learn about protocols governing web and the key concepts related to them, including HTTP, HTTPS, FTP, SMTP, and DNS.

This unit will provide a foundation for understanding the principles and practices of web technology, and for exploring the various concepts and techniques used in the field of web development.
