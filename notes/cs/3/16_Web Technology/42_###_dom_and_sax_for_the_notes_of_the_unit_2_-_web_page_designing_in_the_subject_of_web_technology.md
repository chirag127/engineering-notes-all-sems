### DOM and SAX for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

DOM (Document Object Model) and SAX (Simple API for XML) are two APIs used for processing XML data in web development. The following are some of the key concepts related to DOM and SAX:

1. DOM: DOM is a tree-like representation of an XML document, where each node in the tree represents an element, attribute, or text in the XML document. DOM provides a way to access, manipulate, and update the elements, attributes, and text in an XML document.

2. SAX: SAX is an event-driven API for processing XML data, where a SAX parser reads an XML document and generates events for each element, attribute, and text in the XML document. SAX provides a way to process XML data in a sequential and efficient manner, without the need to build a tree-like representation of the XML document.

3. Tree Structure: DOM represents an XML document as a tree structure, where each node in the tree represents an element, attribute, or text in the XML document.

4. Event-Driven Processing: SAX uses event-driven processing, where a SAX parser reads an XML document and generates events for each element, attribute, and text in the XML document.

5. Memory Usage: DOM uses more memory than SAX, as it builds a tree-like representation of the XML document, while SAX processes the XML document in a sequential and efficient manner without building a tree-like representation.

6. Random Access: DOM provides random access to the elements, attributes, and text in an XML document, while SAX provides sequential access to the elements, attributes, and text in an XML document.

In this unit, you will learn about DOM and SAX and the key concepts related to them, including tree structure, event-driven processing, memory usage, and random access.

This unit will provide a foundation for understanding the principles and practices of web page designing, and for exploring the various concepts and techniques used in the field of web technology.
