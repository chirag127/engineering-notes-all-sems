### URL for the notes of the Unit 3 - Scripting in the subject of Web Technology

URL (Uniform Resource Locator) is a string of characters that defines the location of a resource on the World Wide Web. The following are some of the key concepts related to URL:

1. Protocol: The protocol specifies the method used to access the resource, such as HTTP (Hypertext Transfer Protocol) or FTP (File Transfer Protocol).

2. Domain Name: The domain name specifies the location of the server that contains the resource, such as www.example.com.

3. Path: The path specifies the location of the resource on the server, such as /index.html.

4. Query String: The query string is an optional part of a URL that is used to pass parameters to the resource, such as ?name=value.

5. Fragment Identifier: The fragment identifier is an optional part of a URL that is used to specify a specific section of a resource, such as #section1.

6. Encoding: URL encoding is used to encode special characters in a URL, such as spaces, to ensure that the URL is properly formatted and can be used to access the resource.

In this unit, you will learn about URL and the key concepts related to it, including protocol, domain name, path, query string, fragment identifier, and encoding.

This unit will provide a foundation for understanding the principles and practices of web scripting, and for exploring the various concepts and techniques used in the field of web technology.
