## Unit 2 - Web Page Designing

Web page designing refers to the process of creating and developing the visual and interactive elements of a web page. The following are some of the key concepts related to web page designing:

1. User Experience (UX): User Experience (UX) is the overall experience of a user when interacting with a web page, including the design, layout, and functionality of the web page.

2. User Interface (UI): User Interface (UI) is the part of a web page that a user interacts with, including the buttons, text, images, and other elements of the web page.

3. Layout: Layout refers to the arrangement of elements on a web page, including the placement of text, images, and other elements.

4. Typography: Typography is the art and technique of arranging type to make written language legible, readable, and appealing when displayed.

5. Color: Color is an important aspect of web page design, as it can impact the overall look and feel of a web page, as well as convey meaning and emotions.

6. Responsive Design: Responsive design is a design approach that creates web pages that are optimized for different screen sizes and devices, such as desktops, laptops, tablets, and smartphones.

7. Web Design Tools: Web design tools are software applications used to create and develop web pages, including graphic design software, HTML editors, and CSS editors.

In this unit, you will learn about web page designing and the key concepts related to it, including User Experience (UX), User Interface (UI), layout, typography, color, responsive design, and web design tools.

This unit will provide a foundation for understanding the principles and practices of web page design, and for exploring the various concepts and techniques used in the field of Web Technology.
