### TCP/IP Server Sockets for the notes of the Unit 3 - Scripting in the subject of Web Technology

Unit 3 - Scripting covers the following topic:

1. TCP/IP Server Sockets:
TCP/IP Server Sockets are a type of network socket that allow a server to listen for incoming connections from clients and provide a means for communication between the server and the clients.

2. How it works:
A TCP/IP Server Socket is created on the server side and listens on a specific port for incoming connections from clients. When a client connects to the server, the server creates a new socket for the client and uses it to communicate with the client.

The communication between the server and the client is done using the Transmission Control Protocol (TCP), which provides reliable, ordered, and error-checked delivery of data. The IP part of the name refers to the Internet Protocol, which is used to route the data between the server and the client.

3. Advantages:
TCP/IP Server Sockets have several advantages, including:
1. Reliability: The use of TCP ensures reliable and error-checked delivery of data between the server and the client.
2. Scalability: TCP/IP Server Sockets can handle multiple clients, allowing for scalability and the ability to support large numbers of clients.
3. Portability: TCP/IP Server Sockets can be implemented on a variety of operating systems and platforms, making them portable and widely used.

In conclusion, TCP/IP Server Sockets are a critical component of Web Technology and provide a reliable and scalable means for communication between servers and clients. They are widely used and provide a flexible and portable solution for network communication.
