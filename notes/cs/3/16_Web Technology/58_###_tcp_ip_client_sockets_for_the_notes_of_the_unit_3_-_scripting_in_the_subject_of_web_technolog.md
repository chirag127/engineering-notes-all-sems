### TCP/IP Client Sockets for the notes of the Unit 3 - Scripting in the subject of Web Technology

TCP/IP Client Sockets in Web Technology:

In Web Technology, TCP/IP client sockets are used to establish a connection between a client and a server over the Internet. Sockets provide a way for the client and server to communicate and exchange data.

A client socket is created by the client and is used to initiate a connection to the server. The client socket sends a request to the server and waits for a response. The server listens for incoming connections and, when a connection is received, creates a new socket to handle the connection.

TCP/IP is the most common protocol used for client-server communication over the Internet. TCP (Transmission Control Protocol) provides reliable, ordered delivery of data, while IP (Internet Protocol) provides the underlying network communication.

When using TCP/IP client sockets, the client and server must agree on a port number, which is used to identify the service that the server provides. The client must also know the IP address of the server.

In conclusion, TCP/IP client sockets are an important aspect of Web Technology and are used to establish a connection between a client and a server over the Internet. Sockets provide a way for the client and server to communicate and exchange data, and TCP/IP is the most common protocol used for this communication. The client and server must agree on a port number and the client must know the IP address of the server in order to establish a connection.
