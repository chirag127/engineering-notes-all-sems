### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Unit 2 - Web Page Designing in the subject of Web Technology will cover the use of images in web design.

Images are a key element of web design, and they play an important role in adding visual interest and enhancing the user experience on a website. In web design, images can be used to convey information, create a mood, or simply add visual interest to a web page.

In the context of Unit 2 - Web Page Designing in the subject of Web Technology, students will learn about the use of images in web design. This may include working with examples of images used in web design, analyzing the benefits and limitations of different image formats, and learning how to choose the most appropriate image format for a given web design project.

Some common image formats used in web design include:

1. JPEG: A lossy image format that is commonly used for photographs and images with many colors.

2. PNG: A lossless image format that is commonly used for graphics and images with transparent backgrounds.

3. GIF: A lossless image format that is commonly used for simple graphics and animations.

In Unit 2 - Web Page Designing in the subject of Web Technology, students will learn about these and other image formats, and will learn how to choose the most appropriate format for a given web design project. They will also learn about the challenges involved in using images in web design, such as ensuring that images are optimized for the web and accessible to all users, and will learn how to overcome these challenges.

In summary, in Unit 2 - Web Page Designing in the subject of Web Technology, students will learn about the use of images in web design. They will learn about common image formats, such as JPEG, PNG, and GIF, and will learn how to choose the most appropriate format for a given web design project. They will also learn about the challenges involved in using images in web design and how to overcome these challenges.
