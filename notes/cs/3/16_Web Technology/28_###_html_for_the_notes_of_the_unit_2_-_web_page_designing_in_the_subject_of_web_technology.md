### HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

HTML (HyperText Markup Language) is a markup language used to create and structure web pages. The following are some of the key concepts related to HTML:

1. Elements: Elements are the building blocks of HTML, and are used to define the structure and content of a web page. Examples of elements include headings, paragraphs, lists, images, and links.

2. Attributes: Attributes are additional information that can be added to elements to modify their behavior or appearance.

3. Head: The head is a section of an HTML document that contains information about the document, such as the title, meta data, and links to external resources.

4. Body: The body is a section of an HTML document that contains the main content of the document, such as text, images, and links.

5. Semantic Elements: Semantic elements are elements that describe the meaning of the content they contain, such as headings, paragraphs, and lists.

6. Block-level Elements: Block-level elements are elements that create a new block formatting context, such as headings, paragraphs, and lists.

7. Inline Elements: Inline elements are elements that are placed inline with the text, such as images and links.

In this unit, you will learn about HTML and the key concepts related to it, including elements, attributes, head, body, semantic elements, block-level elements, and inline elements.

This unit will provide a foundation for understanding the principles and practices of web page design, and for exploring the various concepts and techniques used in the field of Web Technology.
