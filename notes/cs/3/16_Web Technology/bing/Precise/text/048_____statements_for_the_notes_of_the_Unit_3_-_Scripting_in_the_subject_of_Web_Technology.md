### Unit 3 - Scripting in Web Technology

1. Scripting is a programming method that allows developers to add interactivity and dynamic content to websites.
2. Scripts are written in scripting languages such as JavaScript, VBScript, and PHP.
3. Scripts can be embedded within HTML documents or linked to external files.
4. Scripts can be used to manipulate the Document Object Model (DOM) of a web page, allowing developers to dynamically change the content and layout of a page.
5. Scripts can also be used to handle user input, validate forms, and communicate with servers.
6. Scripting languages are interpreted, meaning that the code is executed by the browser or server as it is read, rather than being compiled into machine code.
7. Scripting languages are often easier to learn and use than traditional programming languages, making them a popular choice for web development.
8. Scripting can also be used on the server-side to generate dynamic web pages and interact with databases.
9. Common server-side scripting languages include PHP, ASP, and JSP.
10. Scripting can greatly enhance the user experience of a website, but it is important to use it responsibly and ensure that it does not negatively impact performance or accessibility.
