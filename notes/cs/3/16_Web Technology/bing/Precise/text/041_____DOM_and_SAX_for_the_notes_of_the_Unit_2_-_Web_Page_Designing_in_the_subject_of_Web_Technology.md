### DOM and SAX for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- **DOM (Document Object Model)** is a platform and language-neutral interface that allows programs and scripts to dynamically access and update the content, structure, and style of a document.
- The DOM specifies a standard way to represent HTML and XML documents in memory, as a tree structure with nodes representing different parts of the document.
- The DOM provides a set of standard APIs (Application Programming Interfaces) for accessing and manipulating the elements of a document.
- **SAX (Simple API for XML)** is an event-driven, serial-access mechanism for accessing XML documents.
- SAX provides a mechanism for reading data from an XML document as it is being parsed.
- SAX is a low-level API, meaning that it provides a basic set of methods for accessing the data in an XML document, but does not provide any additional functionality for manipulating the data.
- SAX is often used in situations where memory is limited, or where the entire document does not need to be loaded into memory at once.
- Both DOM and SAX have their own advantages and disadvantages, and the choice between the two often depends on the specific needs of the application.
