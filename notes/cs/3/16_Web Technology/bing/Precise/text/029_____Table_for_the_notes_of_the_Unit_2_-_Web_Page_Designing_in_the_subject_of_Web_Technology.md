### Table for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. **Introduction to Web Page Designing:** Web page designing involves the creation and arrangement of web pages that make up a website. It includes aspects such as layout, color scheme, graphics, and content.

2. **HTML:** HTML (Hypertext Markup Language) is the standard markup language used to create web pages. It provides the structure and content of a web page.

3. **CSS:** CSS (Cascading Style Sheets) is a style sheet language used to describe the look and formatting of a web page. It allows for the separation of presentation and content.

4. **JavaScript:** JavaScript is a programming language commonly used in web development to add interactivity and dynamic content to web pages.

5. **Responsive Web Design:** Responsive web design is an approach to web design that aims to provide an optimal viewing experience across a wide range of devices, from desktop computers to mobile phones.

6. **Web Accessibility:** Web accessibility refers to the practice of making websites usable by people with disabilities. It involves designing web pages in a way that allows for easy navigation and interaction for all users.

7. **Search Engine Optimization:** Search engine optimization (SEO) is the process of improving the visibility of a website or a web page in a search engine's unpaid results. It involves optimizing the content and structure of a web page to make it more easily discoverable by search engines.

8. **Web Analytics:** Web analytics is the measurement, collection, analysis, and reporting of web data for the purpose of understanding and optimizing web usage. It can provide valuable insights into user behavior and website performance.

9. **Web Design Tools:** There are many tools available for web design, including text editors, graphic design software, and content management systems. These tools can help streamline the web design process and improve the final result.

10. **Web Design Best Practices:** There are many best practices to follow when designing a web page, including using clear and concise language, organizing content in a logical manner, and ensuring that the page is easy to navigate. Following these best practices can improve the user experience and the overall effectiveness of a web page.
