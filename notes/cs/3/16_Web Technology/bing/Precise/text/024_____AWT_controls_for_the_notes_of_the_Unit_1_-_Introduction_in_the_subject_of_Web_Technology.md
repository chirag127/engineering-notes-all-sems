### AWT Controls

AWT (Abstract Window Toolkit) is a set of Java classes used to create graphical user interfaces (GUIs). AWT controls are the basic building blocks for creating user interfaces in Java. Some of the commonly used AWT controls are:

1. **Button:** A button is a component that triggers an action when clicked. It can display text or an image.
2. **Label:** A label is a component that displays text. It is used to provide information to the user.
3. **TextField:** A text field is a component that allows the user to enter a single line of text.
4. **TextArea:** A text area is a component that allows the user to enter multiple lines of text.
5. **Checkbox:** A checkbox is a component that allows the user to select or deselect an option.
6. **RadioButton:** A radio button is a component that allows the user to select one option from a group of options.
7. **List:** A list is a component that displays a list of items and allows the user to select one or more items.
8. **Choice:** A choice is a component that displays a drop-down list of items and allows the user to select one item.
9. **Scrollbar:** A scrollbar is a component that allows the user to scroll through a large amount of content.

These are some of the basic AWT controls used in creating user interfaces in Java. They can be combined and customized to create more complex interfaces.
