### Standard Actions for the notes of the Unit 5 - Servlets in the subject of Web Technology

1. Servlets are Java programs that run on a web server and handle HTTP requests and responses.
2. Servlets can be used to generate dynamic content, handle form data, and manage sessions.
3. The servlet lifecycle includes initialization, service, and destruction.
4. The `init()` method is called when the servlet is first loaded and is used to perform any necessary initialization.
5. The `service()` method is called for each HTTP request and is responsible for generating the response.
6. The `destroy()` method is called when the servlet is unloaded and is used to perform any necessary cleanup.
7. Servlets can be configured using the `web.xml` file or using annotations.
8. The `HttpServletRequest` and `HttpServletResponse` objects provide access to request and response data.
9. Servlets can forward requests to other resources or include other resources in the response.
10. Servlets can use cookies or session tracking to maintain state between requests.
