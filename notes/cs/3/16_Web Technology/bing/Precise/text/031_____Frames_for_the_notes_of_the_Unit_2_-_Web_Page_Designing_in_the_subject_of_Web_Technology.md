### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. **Introduction to Frames**: Frames allow for multiple `.html` documents to be displayed inside of one browser window at a time.
2. **Creating Frames**: Frames are created using the `<frameset>` tag in place of the `<body>` tag in an HTML document.
3. **Frame Attributes**: The `<frameset>` tag has several attributes, including `rows` and `cols`, which define the size and number of rows and columns in the frameset.
4. **Nested Framesets**: Framesets can be nested inside one another to create more complex layouts.
5. **Targeting Frames**: Links can be targeted to specific frames using the `target` attribute of the `<a>` tag.
6. **NoFrames**: The `<noframes>` tag can be used to provide alternative content for browsers that do not support frames.
7. **Advantages and Disadvantages**: Frames have both advantages and disadvantages, including ease of navigation and potential difficulty with printing and bookmarking.
