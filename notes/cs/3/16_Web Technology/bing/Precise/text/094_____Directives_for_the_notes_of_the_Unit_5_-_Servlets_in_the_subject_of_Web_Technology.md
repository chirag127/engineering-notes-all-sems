### Directives for the notes of the Unit 5 - Servlets in the subject of Web Technology

1. Servlets are Java programs that run on the server-side and handle HTTP requests and responses.
2. Servlets are managed by a servlet container, which is a component of a web server.
3. The servlet container is responsible for managing the lifecycle of servlets, mapping requests to servlets, and ensuring that servlets have access to the resources they need.
4. Servlets can be used to generate dynamic content, handle form data, manage sessions, and perform other server-side tasks.
5. The servlet API provides a standard interface for servlets to interact with the servlet container and the web server.
6. Servlets can be configured using annotations or through a deployment descriptor, which is an XML file that specifies the servlets and their mappings.
7. Servlets can be used in conjunction with other technologies, such as JSP, to build web applications.
