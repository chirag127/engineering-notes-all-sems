### XML Schemes for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. **XML (eXtensible Markup Language)** is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
2. **XML Schemas** define the structure, content, and semantics of XML documents. They provide a means for defining the structure, content, and constraints of XML documents.
3. **XML Schema Definition (XSD)** is a recommendation of the World Wide Web Consortium (W3C) that specifies how to formally describe the elements in an XML document. It provides a way to validate the structure and content of an XML document against a schema.
4. **Document Type Definition (DTD)** is an older schema language for XML that is still in use. It defines the structure and content of an XML document using a set of declarations.
5. **Relax NG** is another schema language for XML that is simpler and easier to learn than XSD. It is based on a compact syntax and is designed to be both easy to read and easy to write.
6. **Schematron** is a schema language for XML that is based on the use of XPath expressions. It is used to validate the content of XML documents and can be used in conjunction with other schema languages.

These are some of the XML schemes that are used in web page designing. They provide a means for defining and validating the structure and content of XML documents, which is an important aspect of web page designing. It is important to have a good understanding of these schemes in order to effectively design and develop web pages using XML.
