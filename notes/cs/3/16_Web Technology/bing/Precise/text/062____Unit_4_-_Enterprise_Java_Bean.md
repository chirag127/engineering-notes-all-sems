## Unit 4 - Enterprise Java Bean

1. Enterprise Java Beans (EJB) is a server-side component architecture for the Java Platform, Enterprise Edition (Java EE).
2. EJB is used to simplify the development of large, distributed applications by providing a container-managed environment for components.
3. EJB components, known as beans, can be used to implement business logic, manage transactions, and handle security.
4. There are three types of EJBs: session beans, entity beans, and message-driven beans.
5. Session beans are used to manage interactions between a client and the server, and can be either stateful or stateless.
6. Entity beans are used to represent persistent data and can be accessed using the Java Persistence API.
7. Message-driven beans are used to handle asynchronous messages, such as those sent using the Java Message Service.
8. EJBs are deployed in an EJB container, which provides services such as transaction management, security, and concurrency control.
9. EJBs can be accessed by local or remote clients using a variety of protocols, including RMI, CORBA, and web services.
10. EJBs can be developed using a variety of tools, including the Eclipse IDE and the NetBeans IDE.
