### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Images are an important part of web page designing as they can convey information and add visual appeal to a web page.
2. There are several types of image formats that can be used on the web, including JPEG, GIF, and PNG.
3. When choosing an image format, it is important to consider factors such as file size, image quality, and the ability to support transparency or animation.
4. Images can be added to a web page using the `<img>` tag, which has several attributes such as `src`, `alt`, and `width` and `height`.
5. It is important to optimize images for the web by reducing their file size while maintaining image quality. This can be done using image editing software or online tools.
6. Images should also be properly sized and positioned on a web page to improve the user experience and page load time.
7. Alternative text should be provided for images to improve accessibility for users with visual impairments or those using screen readers.
8. Images can also be used as backgrounds, links, or buttons on a web page, providing additional functionality and interactivity.
