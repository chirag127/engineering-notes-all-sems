### Unit 3 - Scripting in Web Technology

1. **Introduction to Scripting:** Scripting is a type of programming that is used to automate tasks and add interactivity to web pages. Scripts are written in a scripting language and are interpreted by the web browser or server.

2. **Client-side Scripting:** Client-side scripting refers to scripts that are executed by the web browser on the user's device. These scripts are used to add interactivity to web pages, such as form validation, animations, and user interface enhancements.

3. **Server-side Scripting:** Server-side scripting refers to scripts that are executed on the web server. These scripts are used to generate dynamic web pages, access databases, and perform other server-side tasks.

4. **JavaScript:** JavaScript is a popular client-side scripting language that is used to add interactivity to web pages. It is supported by all modern web browsers and can be used to create a wide range of interactive features.

5. **Document Object Model (DOM):** The Document Object Model (DOM) is a programming interface for web documents. It represents the structure of a document as a tree of objects, and allows scripts to manipulate the content and structure of the document.

6. **Event Handling:** Event handling refers to the process of responding to user actions, such as clicks, key presses, and mouse movements. Scripts can use event listeners to detect these actions and respond accordingly.

7. **AJAX:** AJAX (Asynchronous JavaScript and XML) is a technique for creating fast and dynamic web pages. It allows scripts to send and receive data from the server asynchronously, without reloading the entire page.

8. **jQuery:** jQuery is a popular JavaScript library that simplifies the process of writing client-side scripts. It provides a wide range of features, including DOM manipulation, event handling, and AJAX support.

9. **JSON:** JSON (JavaScript Object Notation) is a lightweight data interchange format that is easy for humans to read and write, and easy for machines to parse and generate. It is commonly used for transmitting data between a server and a web application.

10. **Web APIs:** Web APIs (Application Programming Interfaces) are interfaces that allow scripts to interact with web services and access their data and functionality. Many popular web services, such as Google Maps and Twitter, provide APIs that developers can use to integrate their services into web applications.
