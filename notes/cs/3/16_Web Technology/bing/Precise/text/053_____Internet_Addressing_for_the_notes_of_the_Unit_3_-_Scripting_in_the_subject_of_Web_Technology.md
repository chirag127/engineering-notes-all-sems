### Internet Addressing

- Internet addressing refers to the process of assigning unique identifiers to devices connected to the internet.
- These unique identifiers are known as IP (Internet Protocol) addresses.
- IP addresses are used to route data between devices on the internet.
- There are two versions of IP addresses in use: IPv4 and IPv6.
- IPv4 addresses are 32-bit numbers, while IPv6 addresses are 128-bit numbers.
- Due to the limited number of IPv4 addresses, IPv6 was introduced to provide a larger address space.
- IP addresses can be assigned statically or dynamically.
- Static IP addresses are manually assigned to a device and do not change.
- Dynamic IP addresses are assigned by a DHCP (Dynamic Host Configuration Protocol) server and can change over time.
- Domain names are used to provide a human-readable representation of IP addresses.
- DNS (Domain Name System) is used to translate domain names into IP addresses.
- URLs (Uniform Resource Locators) are used to specify the location of resources on the internet.
- A URL consists of a protocol, domain name, and optional path and query string.
- The protocol specifies how the resource should be accessed (e.g. http, https, ftp).
- The domain name specifies the location of the resource.
- The path and query string provide additional information about the resource.
