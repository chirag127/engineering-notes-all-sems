### Using XML Processors for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. XML processors are software programs that read and manipulate XML documents.
2. They are used to validate, parse, and transform XML data.
3. There are two types of XML processors: validating and non-validating.
4. Validating processors check the XML document against a schema or DTD to ensure that it is well-formed and valid.
5. Non-validating processors only check that the XML document is well-formed.
6. XML processors can be used to transform XML data into other formats, such as HTML or PDF, using XSLT (Extensible Stylesheet Language Transformations).
7. They can also be used to extract data from XML documents using technologies such as XPath or XQuery.
8. XML processors are commonly used in web page designing to manipulate and display XML data on web pages.
9. They can be integrated into web development tools and frameworks to provide easy access to XML data.
10. Using XML processors in web page designing allows for the separation of data and presentation, making it easier to maintain and update web pages.
