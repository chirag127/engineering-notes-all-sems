### Unit 3 - Scripting in Web Technology

1. Scripting is a programming method that allows developers to add interactivity and dynamic content to websites.
2. Scripts are small programs that are embedded in web pages and executed by the web browser.
3. The most commonly used scripting language for the web is JavaScript.
4. JavaScript can be used to create interactive elements such as drop-down menus, pop-up windows, and form validation.
5. Scripts can also be used to manipulate the Document Object Model (DOM) of a web page, allowing developers to dynamically change the content and layout of a page.
6. Other scripting languages used in web development include PHP, Python, and Ruby.
7. Server-side scripting is used to generate dynamic web pages, where the content is generated on the server and sent to the client's web browser.
8. Client-side scripting is used to create interactive elements on the client's web browser, without the need for communication with the server.
9. Scripting can also be used to create web applications, which are programs that run in the web browser and provide functionality similar to desktop applications.
10. Scripting is an essential part of modern web development and is used to create rich, interactive, and dynamic web experiences.
