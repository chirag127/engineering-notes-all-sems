### Internet Addressing

1. Internet addressing refers to the process of assigning unique identifiers to devices connected to the internet.
2. The most common form of internet addressing is the Internet Protocol (IP) address.
3. An IP address is a numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.
4. There are two versions of IP addresses in use: IPv4 and IPv6.
5. IPv4 addresses are 32-bit numbers, while IPv6 addresses are 128-bit numbers.
6. Each IP address is divided into two parts: the network identifier and the host identifier.
7. The network identifier specifies the network to which the device is connected, while the host identifier specifies the specific device on that network.
8. Domain Name System (DNS) is used to translate human-readable domain names into IP addresses.
9. DNS servers maintain a directory of domain names and their corresponding IP addresses.
10. When a user enters a domain name into their web browser, the browser sends a request to a DNS server to resolve the domain name into an IP address.
11. Once the IP address is obtained, the browser can then communicate with the server at that address to retrieve the desired web page.
