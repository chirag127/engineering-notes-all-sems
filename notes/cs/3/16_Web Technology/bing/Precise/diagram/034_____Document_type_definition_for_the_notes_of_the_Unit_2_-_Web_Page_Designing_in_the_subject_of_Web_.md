### Document Type Definition (DTD) - Unit 2: Web Page Designing

1. A Document Type Definition (DTD) is a set of markup declarations that define a document type for SGML-family markup languages (SGML, XML, HTML).
2. A DTD defines the valid building blocks of an XML document. It sets the rules for the markup language, so that the structure of the document can be verified.
3. A DTD can be declared inline inside an XML document, or as an external reference.
4. The purpose of a DTD is to define the structure, elements, and attributes that are allowed in a valid XML document.
5. DTDs use a formal grammar to define the allowed structure and content of an XML document.
6. DTDs are one of several mechanisms available for defining the structure and content of XML documents, with others including XML Schema and RELAX NG.
7. DTDs have been widely used in the past, but are being gradually replaced by other schema languages, such as XML Schema.
