### Unit 2 - Web Page Designing: Forms

1. Forms are used to collect user input on a web page.
2. The `<form>` tag is used to create an HTML form.
3. The `<input>` tag is used to create form controls such as text fields, checkboxes, and radio buttons.
4. The `type` attribute of the `<input>` tag specifies the type of form control to create.
5. The `name` attribute of the `<input>` tag specifies the name of the form control.
6. The `value` attribute of the `<input>` tag specifies the initial value of the form control.
7. The `<label>` tag is used to associate a text description with a form control.
8. The `<select>` tag is used to create a drop-down list.
9. The `<option>` tag is used to define the options in a drop-down list.
10. The `<textarea>` tag is used to create a multi-line text input field.
11. The `<button>` tag is used to create a clickable button.
12. The `action` attribute of the `<form>` tag specifies the URL of the page that will process the form data.
13. The `method` attribute of the `<form>` tag specifies the HTTP method to use when submitting the form data.
14. The `GET` method appends the form data to the URL in the form of query parameters.
15. The `POST` method sends the form data in the body of the HTTP request.
