### Protocols Governing Web

1. **TCP/IP (Transmission Control Protocol/Internet Protocol)**: This is the set of protocols used to communicate across the internet. It is also widely used on many organizational networks due to its flexibility and wide array of functionality provided.
2. **SMTP (Simple Mail Transfer Protocol)**: These protocols are important for sending and distributing outgoing emails.
3. **HTTP (HyperText Transfer Protocol)**: This protocol is used to request the webpage contents from an IP address.
4. **FTP (File Transfer Protocol)**: This protocol is used for transferring files over the internet.
5. **DNS (Domain Name System)**: This protocol is used to convert a domain name into an IP address.
