### Inheritance for the notes of the Unit 1 - Introduction in the subject of Web Technology

Inheritance is a mechanism in object-oriented programming that allows a new class to be created based on an existing class. The new class, called the subclass, inherits the properties and methods of the existing class, called the superclass. This allows for code reuse and can make the design of a program more modular and easier to maintain.

Some key points to remember about inheritance are:

1. Inheritance allows for code reuse by allowing a subclass to inherit the properties and methods of a superclass.
2. The subclass can add new properties and methods, as well as override existing methods.
3. Inheritance can make the design of a program more modular and easier to maintain.
4. Inheritance is one of the fundamental concepts of object-oriented programming.
