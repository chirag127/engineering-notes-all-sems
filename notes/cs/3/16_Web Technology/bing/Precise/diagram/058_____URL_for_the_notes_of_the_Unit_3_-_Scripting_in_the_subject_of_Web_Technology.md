### Unit 3 - Scripting in Web Technology

Scripting is a programming technique that allows developers to add interactivity and dynamic content to web pages. It is commonly used to create dynamic user interfaces, validate user input, and manipulate the Document Object Model (DOM) of a web page.

Some key points to remember about scripting in web technology are:

1. Scripting languages are interpreted, not compiled. This means that the code is executed by the browser at runtime, rather than being translated into machine code beforehand.

2. Common scripting languages used in web development include JavaScript, VBScript, and PHP.

3. Scripts can be embedded directly into an HTML file, or they can be included as external files and linked to the HTML file.

4. Scripting can be used to manipulate the DOM, which is the hierarchical representation of a web page's content and structure.

5. Scripts can also be used to handle events, such as user input, and to perform asynchronous operations, such as sending and receiving data from a server.

6. Scripting can introduce security risks, so it is important to follow best practices and keep scripts up to date.
