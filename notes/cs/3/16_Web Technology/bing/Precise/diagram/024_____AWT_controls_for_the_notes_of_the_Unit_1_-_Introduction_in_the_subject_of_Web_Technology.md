### AWT Controls

AWT (Abstract Window Toolkit) is a set of Java classes used to create graphical user interfaces (GUIs). AWT controls are components that allow the user to interact with the application. Some common AWT controls include:

1. **Button:** A button is a component that can be clicked to perform an action.
2. **Label:** A label is a component that displays text.
3. **TextField:** A text field is a component that allows the user to enter text.
4. **TextArea:** A text area is a component that allows the user to enter multiple lines of text.
5. **Checkbox:** A checkbox is a component that allows the user to select or deselect an option.
6. **RadioButton:** A radio button is a component that allows the user to select one option from a group of options.
7. **List:** A list is a component that displays a list of items from which the user can select one or more.
8. **Choice:** A choice is a component that displays a drop-down list of items from which the user can select one.
9. **Scrollbar:** A scrollbar is a component that allows the user to scroll through a large amount of content.
10. **Menu:** A menu is a component that displays a list of commands or options.

These are some of the common AWT controls used in creating GUIs in Java. They provide a way for the user to interact with the application and perform various actions. AWT controls are an important part of the Java AWT package and are used extensively in creating user interfaces for Java applications.
