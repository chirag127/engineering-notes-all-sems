### DOM and SAX for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- **DOM (Document Object Model)** is a platform and language-neutral interface that allows programs and scripts to dynamically access and update the content, structure, and style of a document.
- DOM represents a document as a tree structure, where each node in the tree represents a part of the document, such as an element, attribute, or text.
- DOM provides a standard set of methods for accessing and manipulating the nodes in the tree, allowing developers to create, delete, and modify elements and attributes, as well as navigate the tree and access the content of the nodes.
- **SAX (Simple API for XML)** is an event-driven, serial-access mechanism for accessing XML documents.
- SAX provides a standard interface for parsing XML documents, allowing developers to write custom handlers for processing the elements, attributes, and content of an XML document as it is being parsed.
- Unlike DOM, SAX does not build a tree representation of the document, but instead processes the document sequentially, generating events as it encounters elements, attributes, and content.
- SAX is often used for processing large XML documents, as it does not require the entire document to be loaded into memory, and can be more efficient than DOM for certain tasks.
