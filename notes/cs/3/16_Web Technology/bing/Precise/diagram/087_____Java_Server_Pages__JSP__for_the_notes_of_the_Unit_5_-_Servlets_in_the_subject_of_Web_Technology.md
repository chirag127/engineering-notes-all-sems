### Java Server Pages (JSP)

Java Server Pages (JSP) is a technology used for building dynamic web pages. It is part of the Java EE (Enterprise Edition) platform and is an extension of the Servlet technology. Here are some key points to note about JSP:

1. JSP allows developers to embed Java code within HTML pages.
2. JSP pages are compiled into servlets by the web container, which means that they have all the capabilities of servlets.
3. JSP pages can make use of JavaBeans components to separate the presentation logic from the business logic.
4. JSP supports custom tag libraries, which allows developers to create reusable components that can be used across multiple pages.
5. JSP pages can be used in conjunction with other Java EE technologies such as Enterprise JavaBeans (EJB) and JavaServer Faces (JSF) to build complex web applications.
