### CSS for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. CSS is used to define how HTML elements should be displayed.

Some key points to remember about CSS are:

1. CSS is used to separate the presentation of a document from its content.
2. CSS allows for greater control over the layout and design of a web page.
3. CSS can be used to create consistent styling across multiple pages of a website.
4. CSS can be used to create responsive designs that adapt to different screen sizes.
5. CSS can be applied to a document in three ways: inline, internal, and external.
6. CSS selectors are used to target specific HTML elements and apply styles to them.
7. CSS properties are used to define the appearance of an element, such as its color, font, and size.
8. CSS can be used to create animations and transitions.
9. CSS has a specific syntax and set of rules that must be followed when writing styles.
10. CSS is constantly evolving, with new features and capabilities being added regularly.
