## Unit 3 - Scripting

Scripting is a type of programming that is used to automate tasks and manipulate data. It is often used for tasks such as data processing, file management, and system administration.

1. **Scripting languages** are high-level programming languages that are interpreted rather than compiled. Some popular scripting languages include Python, Perl, and Ruby.
2. **Scripts** are programs written in a scripting language. They are often used to automate repetitive tasks, such as batch processing of data or file management.
3. **Scripting environments** provide a platform for running scripts. Some common scripting environments include the command line, web browsers, and application-specific environments such as Microsoft Excel.
4. **Scripting can be used for a wide range of tasks**, including data processing, system administration, and web development. It is a powerful tool for automating repetitive tasks and manipulating data.
