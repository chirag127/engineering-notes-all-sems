### Instance Methods

Instance methods are methods that are associated with an instance of a class. They are used to manipulate the state of an object. Here are some key points to remember about instance methods:

1. Instance methods are defined within a class and are called on an instance of that class.
2. They have access to the instance variables and other instance methods of the object on which they are called.
3. The first parameter of an instance method is always a reference to the object on which the method is being called. This parameter is usually called `self` in Python and `this` in JavaScript.
4. Instance methods can be overridden in subclasses to provide specialized behavior.
5. They can be called using the dot notation, for example: `myObject.myMethod()`.
6. Instance methods can be used to modify the state of an object, or to retrieve information about the object's state.
