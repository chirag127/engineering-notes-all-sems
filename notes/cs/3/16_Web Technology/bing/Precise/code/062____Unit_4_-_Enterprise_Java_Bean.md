## Unit 4 - Enterprise Java Bean

Enterprise Java Beans (EJB) is a server-side component architecture for the Java Platform, Enterprise Edition (Java EE). EJB is used to simplify the development of large-scale, distributed applications by providing a component-based approach to building business logic.

1. EJB components are server-side components that encapsulate the business logic of an application.
2. EJB components are written in the Java programming language and are deployed on an EJB container, which is a part of a Java EE application server.
3. EJB components can be accessed by local or remote clients, and can interact with other EJB components, as well as access resources such as databases and messaging systems.
4. EJB provides a number of services to simplify the development of enterprise applications, including transaction management, security, and concurrency control.
5. There are three types of EJB components: session beans, entity beans, and message-driven beans.
6. Session beans are used to represent a single client's interaction with the server, and can be either stateful or stateless.
7. Entity beans are used to represent persistent data and provide an object-oriented view of the data.
8. Message-driven beans are used to process messages asynchronously, and are typically used in conjunction with a messaging system such as Java Message Service (JMS).

EJB is a powerful technology for building enterprise applications, and provides a number of benefits, including simplified development, improved scalability, and increased reliability. However, it is important to carefully design and implement EJB components to ensure that they are efficient and effective.
