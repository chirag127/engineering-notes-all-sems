### AWT Controls

AWT (Abstract Window Toolkit) is a set of Java classes used to create graphical user interfaces (GUIs). AWT controls are components that allow the user to interact with the GUI. Some of the commonly used AWT controls are:

1. **Button:** A button is a component that triggers an action when clicked. It is typically used to submit data or perform a specific task.
2. **Label:** A label is a component used to display text. It is typically used to provide information to the user.
3. **TextField:** A text field is a component that allows the user to enter text. It is typically used to collect data from the user.
4. **TextArea:** A text area is a component that allows the user to enter multiple lines of text. It is typically used to collect large amounts of data from the user.
5. **Checkbox:** A checkbox is a component that allows the user to select one or more options. It is typically used to collect multiple choices from the user.
6. **RadioButton:** A radio button is a component that allows the user to select one option from a group of options. It is typically used to collect a single choice from the user.
7. **List:** A list is a component that displays a list of items. It allows the user to select one or more items from the list.
8. **Choice:** A choice is a component that displays a drop-down list of items. It allows the user to select one item from the list.
9. **ScrollBar:** A scroll bar is a component that allows the user to scroll through a large amount of content. It is typically used to navigate through long documents or lists.
10. **Canvas:** A canvas is a component that provides a blank area for drawing. It is typically used to create custom graphics.

These are some of the commonly used AWT controls in Java. They provide a way for the user to interact with the GUI and perform various tasks.
