### XML Schemes for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. **XML (eXtensible Markup Language)** is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
2. **XML Schemas** define the structure, content, and semantics of XML documents. They provide a means for defining the structure, content, and constraints on the set of valid documents.
3. **XML Schema Definition (XSD)** is a recommendation of the World Wide Web Consortium (W3C) that specifies how to formally describe the elements in an XML document. It provides a way to validate the structure and content of an XML document against a schema.
4. **Document Type Definition (DTD)** is another way to define the structure and content of an XML document. It is a set of declarations that define the legal building blocks of an XML document.
5. **XML Namespaces** provide a way to avoid element name conflicts by associating element names with a unique identifier, typically a URI.
6. **XPath** is a language for addressing parts of an XML document. It is used to navigate through elements and attributes in an XML document.
7. **XSLT (eXtensible Stylesheet Language Transformations)** is a language for transforming XML documents into other formats, such as HTML or plain text.
8. **XQuery** is a language for querying XML data. It is used to extract data from XML documents and manipulate it to produce new XML documents or other formats.

These are some of the key concepts related to XML schemes in the context of web page designing in the subject of web technology. It is important to have a good understanding of these concepts in order to effectively design and develop web pages using XML.
