### Unit 4 - Enterprise Java Bean

Enterprise Java Beans (EJB) is a server-side component architecture for the Java Platform, Enterprise Edition (Java EE). EJB is used to simplify the development of large, distributed applications by providing a container that handles many low-level details of application behavior automatically.

Here are some key points to remember about EJB:

1. EJB is a server-side component architecture for building distributed, scalable, and transactional enterprise applications.
2. EJB components are deployed in an EJB container, which provides services such as transaction management, security, and concurrency control.
3. There are three types of EJBs: session beans, entity beans, and message-driven beans.
4. Session beans are used to represent the business logic of an application and can be either stateful or stateless.
5. Entity beans are used to represent persistent data and can be either container-managed or bean-managed.
6. Message-driven beans are used to process messages asynchronously.
7. EJBs can be accessed remotely using the Java Naming and Directory Interface (JNDI).
8. EJBs can be used in combination with other Java EE technologies such as servlets, JavaServer Pages (JSP), and Java Message Service (JMS).
