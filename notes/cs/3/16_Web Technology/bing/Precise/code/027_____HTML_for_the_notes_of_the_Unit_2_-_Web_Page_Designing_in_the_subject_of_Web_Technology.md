### HTML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. HTML stands for HyperText Markup Language.
2. It is the standard markup language for creating web pages and other information that can be displayed in a web browser.
3. HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear a certain way or act a certain way.
4. The enclosing tags can make a word or image hyperlink to somewhere else, can italicize words, can make the font bigger or smaller, and so on.
5. HTML is not a programming language, it is a markup language. A markup language is a set of markup tags, and HTML uses markup tags to describe web pages.
6. HTML can embed programs written in a scripting language such as JavaScript, which affects the behavior and content of web pages.
7. HTML can also be used to include Cascading Style Sheets (CSS) to define the look and layout of text and other material.
8. The latest version of HTML is HTML5, which introduced new elements and attributes to provide more semantic meaning to the content and to improve the user experience on the web.
