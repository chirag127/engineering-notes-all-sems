## Unit 3 - Scripting

Scripting is a type of programming that is used to automate tasks and manipulate data. It is often used for tasks such as data processing, file management, and system administration.

Some common scripting languages include:

1. Python
2. Perl
3. Ruby
4. JavaScript
5. Bash

Scripting languages are often interpreted, meaning that the code is executed line by line, rather than being compiled into machine code and executed as a whole. This makes scripting languages more flexible and easier to use for quick tasks, but can also make them slower than compiled languages.

Scripts can be used for a wide variety of tasks, including:

- Automating repetitive tasks
- Processing and manipulating data
- Generating reports
- Interacting with web APIs
- System administration

Scripting can be a powerful tool for increasing productivity and efficiency, and is an important skill for anyone working with data or managing systems. It is also a useful skill for anyone looking to automate tasks or manipulate data in their personal or professional life.
