### DOM and SAX for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- **DOM (Document Object Model)** is a platform and language-neutral interface that allows programs and scripts to dynamically access and update the content, structure, and style of a document.
- DOM represents a document as a tree structure, where each node in the tree represents a part of the document, such as an element or an attribute.
- DOM provides a standard set of methods for accessing and manipulating the nodes in the tree, allowing developers to create, delete, and modify elements and attributes in the document.
- **SAX (Simple API for XML)** is an event-driven, serial-access mechanism for accessing XML documents.
- SAX provides a standard interface for XML parsers, allowing developers to write code that can read and process XML data from any SAX-compliant parser.
- Unlike DOM, SAX does not build a tree representation of the document. Instead, it generates events as it reads the document, allowing the application to process the data as it is read.
- SAX is generally faster and uses less memory than DOM, but it is not as easy to use and does not provide random access to the document.
