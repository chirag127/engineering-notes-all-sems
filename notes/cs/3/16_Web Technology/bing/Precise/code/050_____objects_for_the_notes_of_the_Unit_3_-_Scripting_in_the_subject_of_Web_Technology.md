### Objects

- In the context of scripting for web technology, an object is a collection of properties and methods that represent a real-world entity or concept.
- Properties are variables that store information about the object, while methods are functions that perform actions on the object.
- Objects are created using object literals, constructors, or the `Object.create()` method.
- Object literals are a simple way to create objects and define their properties and methods. The syntax for an object literal is `{propertyName: propertyValue, methodName: function(){...}}`.
- Constructors are functions that create and initialize objects. The `new` keyword is used to create an object from a constructor function.
- The `Object.create()` method creates a new object with the specified prototype object and properties.
- Objects can be manipulated by accessing and modifying their properties and methods using dot notation or bracket notation.
- Objects can also be used to organize code and create reusable components by defining custom objects and methods.
- Inheritance is a mechanism that allows objects to inherit properties and methods from other objects. This can be achieved using the prototype chain or by using the `Object.create()` method to create an object with a specified prototype.
