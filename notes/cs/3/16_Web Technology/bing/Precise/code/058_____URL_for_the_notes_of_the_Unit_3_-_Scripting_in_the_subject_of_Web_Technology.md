### Unit 3 - Scripting in Web Technology

1. Scripting is a programming technique that allows developers to add interactivity and dynamic content to websites.
2. Scripts are small programs that are embedded in web pages and executed by the web browser.
3. The most commonly used scripting language for the web is JavaScript.
4. JavaScript can be used to manipulate the Document Object Model (DOM) of a web page, allowing developers to change the content and behavior of a page in response to user actions.
5. Other popular scripting languages for the web include PHP, Python, and Ruby.
6. Scripting languages are often used in conjunction with HTML and CSS to create dynamic, interactive web pages.
7. Server-side scripting, such as PHP or Python, is used to generate dynamic content on the server before it is sent to the user's web browser.
8. Client-side scripting, such as JavaScript, is executed by the user's web browser and can be used to create interactive user interfaces and respond to user actions in real-time.
9. Scripting can also be used to create web applications, such as online games or social networking sites.
10. It is important to follow best practices for security when using scripting languages, as vulnerabilities can be exploited by attackers to compromise the security of a website or web application.
