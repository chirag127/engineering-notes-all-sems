### Images for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. Images are an essential part of web page designing. They can be used to enhance the visual appeal of a web page and convey information in a more engaging manner.
2. There are several types of images that can be used in web page designing, including raster images, vector images, and animated images.
3. Raster images are made up of pixels and are commonly used for photographs and other detailed images. They can be edited using image editing software such as Adobe Photoshop.
4. Vector images are made up of mathematical equations and are commonly used for logos and other graphics that need to be scaled without losing quality. They can be edited using vector graphics software such as Adobe Illustrator.
5. Animated images, such as GIFs, can be used to add movement and interactivity to a web page.
6. When using images in web page designing, it is important to consider factors such as file size, image resolution, and image optimization to ensure that the images load quickly and display properly on different devices.
7. It is also important to use appropriate alt text for images to ensure that the content is accessible to users with visual impairments.
8. In summary, images are a powerful tool in web page designing and can be used to enhance the user experience when used effectively.
