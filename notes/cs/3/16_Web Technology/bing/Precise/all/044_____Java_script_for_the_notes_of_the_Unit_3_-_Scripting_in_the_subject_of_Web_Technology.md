# Unit 3 - Scripting: JavaScript

JavaScript is a high-level, interpreted programming language that is commonly used to add interactivity and dynamic behavior to web pages. It is one of the core technologies of the World Wide Web, along with HTML and CSS.

Here are some key points to remember about JavaScript:

1. JavaScript is a client-side scripting language, which means that the code is executed on the user's computer, rather than on the server.
2. JavaScript is an object-oriented language, which means that it is based on the concept of objects that have properties and methods.
3. JavaScript is a loosely-typed language, which means that variables do not have to be declared with a specific data type.
4. JavaScript is case-sensitive, which means that variable and function names are case-sensitive.
5. JavaScript is an interpreted language, which means that the code is executed line by line, rather than being compiled into machine code and executed.

JavaScript can be used for a variety of tasks, including:

- Manipulating the content and style of a web page
- Validating user input
- Creating animations and visual effects
- Handling user events, such as clicks and mouse movements
- Sending and receiving data from a server

To use JavaScript in a web page, the code can be placed within a `<script>` tag, or it can be included in an external file and linked to the page using the `src` attribute of the `<script>` tag.

JavaScript has a rich set of built-in functions and objects, as well as a large ecosystem of libraries and frameworks that can be used to extend its capabilities. Some popular JavaScript libraries and frameworks include jQuery, React, and AngularJS.

In summary, JavaScript is a powerful and versatile language that is widely used for adding interactivity and dynamic behavior to web pages. It is an essential tool for any web developer to learn and master.
