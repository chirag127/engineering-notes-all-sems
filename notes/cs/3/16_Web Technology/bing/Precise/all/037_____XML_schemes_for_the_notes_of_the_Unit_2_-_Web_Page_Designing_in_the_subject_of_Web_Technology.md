# XML Schemes for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. XML (eXtensible Markup Language) is a markup language used to store and transport data.
2. XML Schemes define the structure, content, and semantics of XML documents.
3. XML Schemes provide a way to define the elements, attributes, and data types that can appear in an XML document.
4. XML Schemes are written in XML and are used to validate the structure and content of XML documents.
5. There are several XML schema languages, including DTD (Document Type Definition), XML Schema (XSD), and RELAX NG.
6. DTD is the oldest XML schema language and is used to define the structure and content of an XML document.
7. XML Schema (XSD) is a more powerful and flexible schema language that is used to define the structure, content, and data types of an XML document.
8. RELAX NG is a schema language that is used to define the structure and content of XML documents and is considered to be simpler and easier to use than XML Schema.
9. XML Schemes are important for ensuring the validity and interoperability of XML documents.
10. XML Schemes are used in many applications, including web services, data exchange, and content management systems.
