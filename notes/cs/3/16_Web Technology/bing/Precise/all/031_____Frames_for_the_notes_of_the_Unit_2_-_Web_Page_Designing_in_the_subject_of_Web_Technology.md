### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

1. **Introduction to Frames**: Frames allow a web page to be divided into multiple sections, each of which can display different content independently.
2. **Creating Frames**: Frames are created using the `<frameset>` tag, which replaces the `<body>` tag in a standard HTML document. The `<frameset>` tag specifies the number and size of the frames on the page.
3. **Frame Attributes**: The `<frame>` tag is used to define each frame within a `<frameset>`. Attributes such as `src`, `name`, `scrolling`, and `noresize` can be used to control the behavior of each frame.
4. **Targeting Frames**: Links and forms can be targeted to specific frames using the `target` attribute. This allows the content of one frame to be updated without refreshing the entire page.
5. **Nested Framesets**: Framesets can be nested within other framesets, allowing for more complex page layouts.
6. **Advantages and Disadvantages of Frames**: While frames can provide a convenient way to display multiple pieces of content on a single page, they also have some disadvantages, such as difficulty with bookmarking and printing, and potential accessibility issues.
