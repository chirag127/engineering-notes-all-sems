### Unit 3 - Scripting: Introduction to AJAX

AJAX stands for Asynchronous JavaScript and XML. It is a technique for creating fast and dynamic web pages without reloading the entire page. Here are some key points to remember about AJAX:

1. AJAX allows web pages to update asynchronously by exchanging data with a server behind the scenes. This means that it is possible to update parts of a web page without reloading the entire page.
2. AJAX uses a combination of technologies, including JavaScript, XML, HTML, and CSS.
3. AJAX is not a programming language, but a technique for using existing standards.
4. AJAX is based on the XMLHttpRequest object, which is used to exchange data with a server.
5. AJAX can be used with a variety of data formats, including XML, JSON, and plain text.
6. AJAX can improve the user experience by making web pages more responsive and reducing the need for page reloads.
