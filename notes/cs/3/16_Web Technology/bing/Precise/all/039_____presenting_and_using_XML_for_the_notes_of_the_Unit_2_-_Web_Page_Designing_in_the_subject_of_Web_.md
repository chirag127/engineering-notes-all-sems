### Presenting and Using XML for the Notes of the Unit 2 - Web Page Designing in the Subject of Web Technology

1. XML stands for eXtensible Markup Language.
2. It is a markup language that defines a set of rules for encoding documents in a format that is both human-readable and machine-readable.
3. XML is used to store and transport data.
4. It is a self-describing language, meaning that the tags used to markup the data describe the data itself.
5. XML is platform-independent and can be used on any operating system or programming language.
6. XML data can be presented using CSS or XSLT.
7. CSS is used to style the XML data, while XSLT is used to transform the XML data into another format, such as HTML.
8. XML data can also be manipulated using programming languages such as JavaScript or PHP.
9. XML is commonly used in web development, particularly in the creation of web services and APIs.
10. XML is also used in the creation of RSS feeds, which allow users to subscribe to updates from websites.
