# Unit 2 - Web Page Designing

Here are the notes for Unit 2 - Web Page Designing in the subject of Web Technology:

1. Introduction to Web Page Designing: Web page designing involves the creation and arrangement of web pages that make up a website. It includes aspects such as layout, color scheme, graphics, and content.

2. HTML: HTML (Hypertext Markup Language) is the standard markup language used to create web pages. It is used to structure content and define the layout of a web page.

3. CSS: CSS (Cascading Style Sheets) is a style sheet language used to describe the look and formatting of a document written in a markup language. It is used to separate the presentation of a web page from its content.

4. JavaScript: JavaScript is a programming language used to create interactive effects within web browsers. It is used to add dynamic behavior to web pages.

5. Web Design Principles: Some important web design principles include consistency, simplicity, usability, and accessibility.

6. Responsive Web Design: Responsive web design is an approach to web design that aims to provide an optimal viewing experience across a wide range of devices, from desktop computers to mobile phones.

7. Web Design Tools: There are many tools available for web designing, including text editors, graphic design software, and web design software.

8. Web Design Process: The web design process typically involves several stages, including planning, design, development, testing, and launch.
