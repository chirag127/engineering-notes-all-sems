# Unit 3 - Scripting in Web Technology: Forms

- Forms are used to collect user input and submit it to a server for processing.
- Forms are created using the `<form>` element, which contains one or more form controls such as text fields, checkboxes, radio buttons, and submit buttons.
- The `action` attribute of the `<form>` element specifies the URL to which the form data is sent when the form is submitted.
- The `method` attribute of the `<form>` element specifies the HTTP method used to send the form data. The two most common methods are `GET` and `POST`.
- Form controls are created using various input elements such as `<input>`, `<textarea>`, and `<select>`.
- The `name` attribute of form controls is used to identify the data when it is submitted to the server.
- The `value` attribute of form controls specifies the initial value of the control.
- Form validation can be performed on the client-side using JavaScript or on the server-side using a server-side scripting language such as PHP or ASP.
- Form data can be submitted using the submit button or by pressing the Enter key while a form control has focus.
- Form data can be processed on the server using a server-side scripting language to perform tasks such as storing the data in a database or sending an email.
