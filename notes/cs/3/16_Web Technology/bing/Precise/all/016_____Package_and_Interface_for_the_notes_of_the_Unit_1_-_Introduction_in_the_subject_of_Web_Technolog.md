### Package and Interface

#### Package
- A package is a collection of related classes and interfaces that are grouped together.
- Packages help to organize code and avoid naming conflicts.
- In Java, packages are created by using the `package` keyword followed by the package name at the top of the source file.
- To use a class or interface from a package, it must be imported using the `import` keyword followed by the package name and class or interface name.

#### Interface
- An interface is a collection of abstract methods (methods without a body) and constants.
- Interfaces are used to define a contract between classes, specifying what methods a class must implement.
- In Java, interfaces are created using the `interface` keyword.
- A class can implement an interface by using the `implements` keyword followed by the interface name.
- A class that implements an interface must provide an implementation for all of its methods.
