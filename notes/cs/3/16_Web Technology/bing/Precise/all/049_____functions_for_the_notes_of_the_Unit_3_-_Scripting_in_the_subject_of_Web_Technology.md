# Unit 3 - Scripting: Functions

Functions are a fundamental building block of scripting languages, including those used in web technology. Here are some key points to remember about functions:

1. A function is a block of code that performs a specific task and can be reused throughout a script.
2. Functions can take input in the form of arguments or parameters, and can return a value as output.
3. Functions can be defined using the `function` keyword, followed by the function name, a list of parameters in parentheses, and the function body enclosed in curly braces.
4. Functions can be called or invoked by using their name followed by parentheses, with any arguments passed inside the parentheses.
5. Functions can be assigned to variables, passed as arguments to other functions, and returned as values from other functions.
6. Functions can be used to organize code into reusable, modular units, making it easier to read, write, and maintain.

Here is an example of a simple function in JavaScript:

```javascript
function add(a, b) {
  return a + b;
}

let result = add(1, 2);
console.log(result); // 3
```

In this example, the `add` function takes two arguments, `a` and `b`, and returns their sum. The function is then called with the arguments `1` and `2`, and the result is assigned to the `result` variable and logged to the console.

Functions are a powerful tool for organizing and reusing code in scripting languages, and are essential for building complex web applications. It is important to understand how to define, call, and use functions when working with web technology.
