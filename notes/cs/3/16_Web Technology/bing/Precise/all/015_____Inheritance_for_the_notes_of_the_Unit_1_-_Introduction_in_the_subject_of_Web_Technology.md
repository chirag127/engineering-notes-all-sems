### Inheritance for the notes of the Unit 1 - Introduction in the subject of Web Technology

Inheritance is a mechanism in object-oriented programming that allows a new class to be created based on an existing class. The new class, called the derived class, inherits the properties and methods of the existing class, called the base class. This allows for code reuse and can make the code more organized and easier to maintain.

Some key points to remember about inheritance are:

1. Inheritance allows for code reuse by allowing a new class to inherit the properties and methods of an existing class.
2. The new class, called the derived class, can add new properties and methods or override the inherited ones.
3. Inheritance can make the code more organized and easier to maintain by reducing code duplication.
4. Inheritance is one of the fundamental concepts of object-oriented programming.
