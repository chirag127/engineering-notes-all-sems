### Manipulating Enterprise Java Bean (Unit 4 - Web Technology)

Enterprise Java Beans (EJB) is a server-side component architecture for building modular, scalable, and secure enterprise applications. EJBs are used to encapsulate business logic and provide a way to manipulate data in a distributed environment.

Here are some key points to remember when manipulating EJBs:

1. EJBs can be accessed and manipulated using the Java Naming and Directory Interface (JNDI), which provides a way to look up and reference EJBs.
2. EJBs can be manipulated using the methods defined in their remote or local interfaces. These interfaces define the business methods that can be invoked on the EJB.
3. EJBs can be manipulated using the EJB Query Language (EJB QL), which is a SQL-like language used to query and manipulate data stored in EJBs.
4. EJBs can be manipulated using the Java Persistence API (JPA), which provides a way to map Java objects to relational database tables and perform CRUD (Create, Read, Update, Delete) operations on the data.
5. EJBs can be manipulated using the Java Transaction API (JTA), which provides a way to manage transactions when manipulating data in EJBs.

These are some of the ways in which EJBs can be manipulated in a Web Technology context. It is important to understand these concepts when working with EJBs in enterprise applications.
