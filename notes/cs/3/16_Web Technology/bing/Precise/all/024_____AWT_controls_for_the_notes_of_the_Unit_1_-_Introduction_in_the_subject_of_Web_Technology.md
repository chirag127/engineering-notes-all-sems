### AWT Controls

AWT (Abstract Window Toolkit) is a set of Java classes used to create graphical user interfaces (GUIs). AWT controls are the basic building blocks of a GUI application. These controls are also known as components or widgets. Some of the commonly used AWT controls are:

1. **Label:** A label is a component that displays a single line of read-only text. It is used to provide information to the user.
2. **Button:** A button is a component that triggers an action when clicked by the user. It is used to initiate an action or submit data.
3. **TextField:** A text field is a component that allows the user to enter a single line of text. It is used to get input from the user.
4. **TextArea:** A text area is a component that allows the user to enter multiple lines of text. It is used to get input from the user.
5. **Checkbox:** A checkbox is a component that allows the user to select or deselect an option. It is used to get a boolean input from the user.
6. **Choice:** A choice is a component that allows the user to select one option from a list of options. It is used to get a single selection from the user.
7. **List:** A list is a component that allows the user to select one or more options from a list of options. It is used to get multiple selections from the user.

These are some of the basic AWT controls used in creating GUI applications. Each control has its own set of properties and methods that can be used to customize its appearance and behavior. AWT also provides layout managers to arrange these controls in a container. A container is a component that can hold other components. The most commonly used container is the Frame, which represents a window in a GUI application. AWT also provides event handling mechanisms to handle user interactions with the controls.
