### I/O for the notes of the Unit 1 - Introduction in the subject of Web Technology

- I/O stands for Input/Output.
- In the context of web technology, I/O refers to the exchange of data between a web application and its environment.
- Input refers to the data that is received by the web application from the user or another source.
- Output refers to the data that is sent from the web application to the user or another destination.
- Common input methods for web applications include forms, text fields, and file uploads.
- Common output methods for web applications include displaying data on a web page, downloading a file, or sending an email.
- I/O is an essential part of web technology as it enables the web application to interact with its users and other systems.
