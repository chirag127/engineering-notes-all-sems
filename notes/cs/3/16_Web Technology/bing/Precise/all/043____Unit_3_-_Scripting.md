# Unit 3 - Scripting

Scripting is the process of writing code in a scripting language to automate tasks or add functionality to a program. Some common scripting languages include Python, JavaScript, and Ruby.

1. **Scripting languages** are high-level programming languages that are interpreted rather than compiled. This means that the code is executed line by line, rather than being translated into machine code and executed all at once.

2. **Scripting languages** are often used for tasks such as automating repetitive tasks, manipulating data, and adding interactivity to web pages.

3. **Scripting languages** are often easier to learn and use than lower-level programming languages, making them a popular choice for beginners and non-programmers.

4. **Scripting languages** can be used for a wide range of tasks, from simple one-liners to complex programs.

5. **Scripting languages** are often used in conjunction with other languages and technologies, such as HTML, CSS, and databases.

6. **Scripting languages** can be used to create standalone programs, but are more commonly used to add functionality to existing programs or systems.

7. **Scripting languages** can be used on a variety of platforms, including desktop computers, servers, and mobile devices.

8. **Scripting languages** can be used to interact with APIs, allowing programs to access data and functionality from other programs and services.

9. **Scripting languages** can be used to create graphical user interfaces (GUIs), allowing users to interact with programs in a more intuitive and user-friendly way.

10. **Scripting languages** can be used to create and manipulate data in various formats, such as CSV, JSON, and XML.
