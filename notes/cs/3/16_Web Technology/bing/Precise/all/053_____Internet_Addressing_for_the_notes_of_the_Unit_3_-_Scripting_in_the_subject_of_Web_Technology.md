### Internet Addressing

1. Internet addressing refers to the process of assigning unique identifiers to devices connected to the internet.
2. These unique identifiers are known as IP (Internet Protocol) addresses.
3. IP addresses are used to route data between devices on the internet.
4. There are two versions of IP addresses in use: IPv4 and IPv6.
5. IPv4 addresses are 32-bit numbers, while IPv6 addresses are 128-bit numbers.
6. Due to the limited number of IPv4 addresses, IPv6 was developed to provide a larger address space.
7. IP addresses can be assigned statically or dynamically.
8. Static IP addresses are manually assigned to a device and do not change.
9. Dynamic IP addresses are assigned by a DHCP (Dynamic Host Configuration Protocol) server and can change over time.
10. Domain names are used to provide a human-readable representation of an IP address.
11. DNS (Domain Name System) is used to translate domain names into IP addresses.
12. URLs (Uniform Resource Locators) are used to specify the location of a resource on the internet.
13. A URL consists of a protocol, domain name, and optional path and query string.
14. The protocol specifies the method used to access the resource, such as HTTP or FTP.
15. The domain name specifies the location of the resource, while the path and query string provide additional information about the resource.
