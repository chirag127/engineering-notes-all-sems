### Protocols Governing Web

Protocols are a set of rules or standards that enable communication between different devices or applications. Protocols govern the web by defining how data is transmitted, formatted, addressed, secured, and processed over the internet. Some of the common protocols that are used on the web are:

- **TCP/IP (Transmission Control Protocol/Internet Protocol)**: This is the fundamental protocol suite that provides the basic functionality of the internet. TCP/IP consists of four layers: application, transport, internet, and network interface. TCP/IP enables reliable and ordered delivery of data packets between hosts on different networks. TCP/IP also provides addressing and routing mechanisms that allow data to reach its destination.  
- **HTTP (HyperText Transfer Protocol)**: This is the protocol that defines how web browsers and web servers communicate. HTTP is an application layer protocol that uses TCP/IP as the underlying transport protocol. HTTP allows web browsers to request web pages and other resources from web servers, and web servers to respond with the requested content. HTTP also supports methods such as GET, POST, PUT, and DELETE that allow web browsers to perform different actions on web servers. 
- **DNS (Domain Name System)**: This is the protocol that maps domain names to IP addresses. DNS is a distributed database that stores the records of domain names and their corresponding IP addresses. DNS allows web browsers to use human-readable names such as www.google.com instead of numerical IP addresses such as 172.217.14.206 to access web servers. DNS also provides other services such as load balancing, caching, and security. 
- **SMTP (Simple Mail Transfer Protocol)**: This is the protocol that enables sending and receiving emails over the internet. SMTP is an application layer protocol that uses TCP/IP as the underlying transport protocol. SMTP allows email clients to send messages to email servers, and email servers to relay messages to other email servers or deliver them to email recipients. SMTP also supports commands such as HELO, MAIL, RCPT, DATA, and QUIT that allow email clients and servers to exchange information and control the email transmission. 
- **FTP (File Transfer Protocol)**: This is the protocol that enables transferring files between hosts on the internet. FTP is an application layer protocol that uses TCP/IP as the underlying transport protocol. FTP allows users to upload and download files from remote servers, as well as create, delete, rename, and move files and directories on the servers. FTP also supports modes such as ASCII, binary, and passive that allow users to specify how the data is transferred and handled.
