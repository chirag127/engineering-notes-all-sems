### Networking for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Networking is the process of connecting multiple devices or systems over a network, such as the Internet, to exchange information and data.
- Networking can be done using various protocols, such as TCP/IP, HTTP, FTP, SMTP, etc.
- Networking can also involve programming, which is the process of creating and executing code to perform specific tasks or functions on a network.
- Networking programming can be done using various languages, such as Python, C#, JavaScript, etc.
- Networking programming can be divided into two categories: client-side and server-side.

#### Client-side scripting
- Client-side scripting is a web development method used to create dynamic and interactive web pages that run on the user's browser.
- Client-side scripting can be done using languages such as HTML, CSS, and JavaScript, which are interpreted by the browser and do not require a web server.
- Client-side scripting can be used to enhance the user interface, validate user input, manipulate the document object model (DOM), and communicate with the web server using AJAX.
- Client-side scripting has some limitations, such as browser compatibility, security, and performance issues.

#### Server-side scripting
- Server-side scripting is a web development method used to create customized and dynamic web pages that run on the web server.
- Server-side scripting can be done using languages such as PHP, Python, Ruby, C#, and JavaScript (NodeJS), which are interpreted or compiled by the web server and require a web server.
- Server-side scripting can be used to access databases, process user input, generate dynamic content, and perform complex calculations.
- Server-side scripting has some advantages, such as better security, faster performance, and more functionality.
