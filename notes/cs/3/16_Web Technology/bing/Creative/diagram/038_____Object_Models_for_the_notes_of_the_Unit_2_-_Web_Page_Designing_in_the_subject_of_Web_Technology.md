### Object Models for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- An object model is a visual representation of a system's objects, actions, and associated attributes.
- An object model can help to create a consistent and intuitive user interface for web pages.
- One of the most popular object models in web page designing is the Page Object Model (POM)  .
- POM is a design pattern that creates an object repository for web UI elements.
- POM reduces code duplication and improves test maintenance by separating the test logic from the web elements.
- POM follows the principle of abstraction and encapsulation by hiding the implementation details of the web elements and exposing only the relevant methods.
- POM consists of two components: Page Classes and Page Methods.
- Page Classes are the classes that represent each web page in the application and contain the web elements and their locators.
- Page Methods are the methods that perform the actions on the web elements, such as clicking, typing, selecting, etc.
- POM can be implemented using various tools and languages, such as Selenium, JavaScript, Java, Python, etc  .
- POM can be enhanced by using Page Factory, which is a way of initializing the web elements using annotations.
- POM can also be combined with other design patterns, such as ScreenPlay Model, which is a way of modeling the user interactions as tasks and questions.
- POM can help to create robust, reusable, and maintainable web page designs that can handle dynamic and complex web applications  .
