### Introduction to AJAX

- AJAX stands for **Asynchronous JavaScript and XML** .
- AJAX is a technique for creating **better, faster, and more interactive web applications** with the help of XML, HTML, CSS, and JavaScript .
- AJAX allows web pages to be **updated asynchronously** by exchanging data with a web server **behind the scenes**. This means that the web page can update parts of its content without reloading the whole page.
- AJAX uses the **XMLHttpRequest** object (built-in in most browsers) to **request data** from a web server. The data can be in various formats, such as XML, JSON, or plain text.
- AJAX uses **JavaScript and HTML DOM** to **display or use** the data on the web page.
- AJAX is not a programming language, but a **set of web development techniques** that uses various web technologies on the client-side .
- AJAX is a **misleading name**, as it does not require XML or JavaScript to work. However, it is a widely used term to describe this kind of web development.
