### Introduction to AJAX

- AJAX stands for **Asynchronous JavaScript and XML**  .
- AJAX is not a programming language, but a technique for creating **dynamic and interactive web pages** .
- AJAX allows web pages to **send and receive data from a web server** without reloading the whole page  .
- AJAX uses a combination of:
  - A browser built-in **XMLHttpRequest object** (to request data from a web server)  
  - **JavaScript** and **HTML DOM** (to display or use the data)  
- AJAX can work with data in different formats, such as **XML, JSON, HTML, or plain text** .
- AJAX is commonly used in popular web applications like **Google Maps, Gmail, Facebook, and Twitter** .
- An example of AJAX is the **Google Autocomplete feature**, which offers keyword suggestions as the user types into the search bar .
- AJAX can improve the **user experience, performance, and efficiency** of web applications by reducing the need for page refreshes and server requests .
