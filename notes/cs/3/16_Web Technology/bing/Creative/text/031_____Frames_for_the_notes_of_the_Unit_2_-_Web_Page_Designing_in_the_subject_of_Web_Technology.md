### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- Frames are a way of dividing a web page into multiple sections, each of which can display a different HTML document.
- Frames are created using the `<frameset>` tag, which replaces the `<body>` tag in a web page. The `<frameset>` tag can have one or more `<frame>` tags as its children, each of which specifies the source, name, size, and scrolling options of a frame.
- Frames can be nested inside other frames using another `<frameset>` tag as the source of a `<frame>` tag. This allows for complex layouts and navigation schemes.
- Frames have some advantages and disadvantages for web page designing. Some of the advantages are:
  - Frames can reduce the bandwidth and loading time of a web page, as only the content of the changed frame needs to be refreshed.
  - Frames can provide a consistent look and feel for a web site, as the header, footer, and navigation elements can be displayed in separate frames and remain unchanged across different pages.
  - Frames can allow for dynamic content and interactivity, as different frames can communicate with each other using JavaScript or other scripting languages.
- Some of the disadvantages of frames are:
  - Frames can cause accessibility and usability issues, as some browsers, screen readers, and search engines may not support or recognize frames properly.
  - Frames can make bookmarking and linking difficult, as the URL of a web page with frames may not reflect the content of a specific frame.
  - Frames can create navigation and scrolling problems, as the user may have to scroll or resize multiple frames to view the desired content.
  - Frames can break the back and forward buttons of the browser, as the browser history may not record the changes in the frames.
