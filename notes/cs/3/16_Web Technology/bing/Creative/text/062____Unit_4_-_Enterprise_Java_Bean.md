## Unit 4 - Enterprise Java Bean

- An enterprise bean is a Java component that can be combined with other resources to create Java applications  .
- An enterprise bean encapsulates the business logic of an application, which is the code that fulfills the purpose of the application .
- Enterprise beans run on the server side and are managed by the enterprise bean container, which provides services such as security, transaction management, concurrency control, and dependency injection   .
- Enterprise beans can be accessed by local or remote clients, such as web components, other enterprise beans, or standalone Java applications .
- There are three types of enterprise beans: session beans, entity beans, and message-driven beans   .
  - Session beans are non-persistent objects that represent a single client-server interaction or a conversational state  .
  - Entity beans are persistent objects that represent the data stored in a database or another persistent storage   .
  - Message-driven beans are objects that act as message consumers and process messages asynchronously from a message queue or topic  .
- Enterprise beans are based on the Enterprise JavaBeans (EJB) technology, which is the server-side component architecture for Java Platform, Enterprise Edition (Java EE)  .
- Enterprise beans are developed using the Jakarta Enterprise Beans (EJB) specification, which defines the APIs and contracts for creating and using enterprise beans.
- Enterprise beans can be annotated with metadata to simplify the development and deployment of enterprise applications   .
- Enterprise beans can use other Java EE technologies, such as Java Persistence API (JPA), Java Message Service (JMS), Java Transaction API (JTA), and Java Naming and Directory Interface (JNDI), to access and manipulate data, communicate with other components, manage transactions, and perform naming and directory services    .
