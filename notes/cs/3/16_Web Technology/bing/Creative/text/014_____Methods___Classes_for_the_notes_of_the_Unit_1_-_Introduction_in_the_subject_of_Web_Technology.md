### Methods & Classes

- A method is a set of instructions that performs a specific task or operation on some data or objects.
- A class is a blueprint or template that defines the attributes and behaviors of a type of object.
- In web technology, methods and classes are used to create dynamic and interactive web pages and applications.
- Some examples of methods and classes in web technology are:

  - The `document` object represents the HTML document loaded in the browser. It has methods such as `getElementById`, `createElement`, `write`, etc. that can manipulate the document elements and content.
  - The `window` object represents the browser window or tab. It has methods such as `alert`, `open`, `close`, `setTimeout`, etc. that can display messages, open or close windows, and execute functions after a delay.
  - The `XMLHttpRequest` class is used to send and receive data from a server asynchronously. It has methods such as `open`, `send`, `abort`, etc. that can initiate, cancel, or monitor the request status and response.
  - The `Date` class is used to create and manipulate date and time objects. It has methods such as `getFullYear`, `getMonth`, `getDay`, etc. that can return or set the date and time components.
  - The `Math` class is used to perform mathematical operations and calculations. It has methods such as `abs`, `sqrt`, `sin`, `cos`, etc. that can return the absolute value, square root, sine, cosine, etc. of a number.
