### Event handling

- An event is an action or occurrence that happens in the browser, such as a mouse click, a key press, a page load, or a form submission.
- Event handling is the process of responding to events by executing some code or function.
- Event handling involves three steps:
  - Selecting an element that will trigger the event, such as a button, a link, or an input field.
  - Specifying the type of event to listen for, such as `click`, `keydown`, `load`, or `submit`.
  - Providing a callback function that will run when the event occurs, such as changing the color of the element, displaying a message, or validating the input.
- There are different ways to implement event handling in web technology, such as:
  - Using HTML attributes, such as `onclick`, `onload`, or `onsubmit`, to embed the event handler code directly in the HTML element.
  - Using the DOM (Document Object Model) methods, such as `addEventListener()`, `removeEventListener()`, or `dispatchEvent()`, to attach, detach, or trigger event handlers dynamically in JavaScript.
  - Using the jQuery library, which provides a simplified and cross-browser compatible way of handling events, such as `on()`, `off()`, or `trigger()` methods.
