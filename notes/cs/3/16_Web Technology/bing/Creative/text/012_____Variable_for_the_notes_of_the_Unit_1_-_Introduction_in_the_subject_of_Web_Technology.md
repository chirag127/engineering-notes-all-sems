### Variable

- A variable is a named storage location that can hold a value of a specific type.
- A variable can be declared using a keyword followed by an identifier, such as `var x;` or `let y;` in JavaScript.
- A variable can be assigned a value using the assignment operator `=`, such as `x = 10;` or `y = "Hello";`.
- A variable can be used in expressions, statements, and functions to perform operations and computations, such as `console.log(x + y);` or `function add(a, b) { return a + b; }`.
- A variable has a scope, which defines where it can be accessed and modified. There are two types of scopes: global and local.
  - A global variable is declared outside any function and can be accessed and modified anywhere in the code.
  - A local variable is declared inside a function and can only be accessed and modified within that function.
- A variable has a lifetime, which defines how long it exists in the memory. There are two types of lifetimes: static and dynamic.
  - A static variable is allocated at compile time and exists throughout the execution of the program.
  - A dynamic variable is allocated at run time and exists until it is no longer needed or explicitly deleted.
