| Introduction to Web Page Designing | Definition and purpose of web pages | - A web page is a document that can be accessed through a web browser over the internet or a local network. <br> - The purpose of web pages is to present information, provide interactivity, or perform tasks for the users. |
|  | Types and components of web pages | - There are two main types of web pages: static and dynamic. <br> - Static web pages are pre-written and do not change in response to user input or server-side events. They are usually written in HTML, CSS, and JavaScript. <br> - Dynamic web pages are generated on the fly by the web server or the browser, based on user input, database queries, or other factors. They can use scripting languages such as PHP, ASP, JSP, or Ruby on Rails. <br> - The components of web pages are the elements that make up the structure, layout, and content of the page. They include: <br>   - Head: contains metadata and links to external resources such as stylesheets, scripts, or fonts. <br>   - Body: contains the visible content of the page, such as text, images, links, forms, tables, lists, etc. <br>   - Tags: mark the start and end of each element and define its attributes and properties. <br>   - Attributes: specify additional information about an element, such as its id, class, style, or event handlers. <br>   - Properties: define the appearance and behavior of an element, such as its color, size, position, or animation. |
| Web Page Design Principles | Layout and alignment | - The layout of a web page is the arrangement of its elements in a logical and aesthetic way. <br> - The alignment of a web page is the positioning of its elements in relation to each other and to the edges of the page. <br> - The layout and alignment of a web page should follow some basic principles, such as: <br>   - Consistency: use the same fonts, colors, styles, and spacing throughout the page. <br>   - Balance: distribute the visual weight of the elements evenly across the page. <br>   - Contrast: create a clear distinction between different types of elements, such as text and images, or headings and paragraphs. <br>   - Hierarchy: organize the elements according to their importance and relevance, using size, color, or position to emphasize the main points. <br>   - Proximity: group related elements together and separate unrelated elements apart. <br>   - Alignment: align the elements along a common edge or axis, such as left, right, center, or justify. <br>   - White space: leave some empty space around the elements to create a sense of clarity and breathing room. |
|  | Color and typography | - The color of a web page is the hue, saturation, and brightness of the elements on the page. <br> - The typography of a web page is the style, size, and arrangement of the text on the page. <br> - The color and typography of a web page should follow some basic principles, such as: <br>   - Harmony: use colors that complement each other and create a pleasing mood. <br>   - Contrast: use colors that stand out from each other and from the background. <br>   - Accessibility: use colors that are easy to read and distinguish for people with color vision deficiencies or low vision. <br>   - Legibility: use fonts that are clear and readable, and avoid using too many different fonts or sizes. <br>   - Readability: use fonts that are appropriate for the tone and purpose of the text, and avoid using fonts that are too fancy or informal. <br>   - Emphasis: use fonts that highlight the key words or phrases, and avoid using fonts that are too bold or italic. |
