### Introduction to AWT

- AWT stands for **Abstract Window Toolkit**, which is an API for creating **Graphical User Interface (GUI)** or windows-based applications in Java  .
- AWT components are **platform-dependent**, which means they are displayed according to the view of the underlying operating system . AWT is also **heavyweight**, which means its components use the resources of the operating system.
- AWT is part of the **Java Foundation Classes (JFC)**, which is the standard API for providing a GUI for a Java program. AWT is also the GUI toolkit for some **Java ME** profiles.
- AWT provides various classes and interfaces for creating and managing GUI components, such as **windows, buttons, labels, text fields, menus, dialogs, etc** .
- AWT also provides classes and interfaces for handling **events**, such as **mouse clicks, keyboard inputs, window closing, etc** .
- AWT uses a **container-component** hierarchy, where a container is a component that can contain other components, such as a window or a panel .
- AWT uses a **layout manager** to arrange the components in a container, such as **FlowLayout, BorderLayout, GridLayout, etc** .
- AWT uses a **graphics** class to draw shapes, images, and text on a component, such as a canvas or a panel .
- AWT uses a **color** class to represent colors, and a **font** class to represent fonts .
- AWT uses a **toolkit** class to provide system-specific information and functionality, such as screen size, beep sound, etc .
