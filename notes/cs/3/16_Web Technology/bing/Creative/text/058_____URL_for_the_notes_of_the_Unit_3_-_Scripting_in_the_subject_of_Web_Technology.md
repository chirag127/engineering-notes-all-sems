### Unit 3 - Scripting

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server at run-time, rather than compiled beforehand.
- Scripting languages can be embedded in HTML documents or stored in external files that are linked to HTML documents.
- Scripting languages can manipulate the content, structure, and style of web pages, as well as interact with users, servers, databases, and other web resources.
- Some examples of scripting languages are JavaScript, PHP, Python, Ruby, and Perl.

#### JavaScript

- JavaScript is a scripting language that runs on the client-side, meaning it is executed by the browser on the user's device.
- JavaScript can access and modify the HTML elements and CSS styles of a web page, as well as respond to user events, such as clicks, mouse movements, keyboard inputs, etc.
- JavaScript can also communicate with the server using AJAX (Asynchronous JavaScript and XML), which allows the exchange of data without reloading the web page.
- JavaScript can also use APIs (Application Programming Interfaces) to access various web services and functionalities, such as geolocation, web storage, web sockets, etc.
- JavaScript follows the ECMAScript standard, which defines the syntax, data types, operators, statements, and built-in objects of the language.
- JavaScript can be embedded in HTML documents using the `<script>` tag, or stored in external files with the `.js` extension and linked to HTML documents using the `src` attribute of the `<script>` tag.

#### PHP

- PHP is a scripting language that runs on the server-side, meaning it is executed by the web server before sending the web page to the browser.
- PHP can generate dynamic and customized web pages based on various factors, such as user input, server data, database queries, etc.
- PHP can also perform various tasks on the server, such as file handling, session management, email sending, etc.
- PHP can also communicate with various databases, such as MySQL, PostgreSQL, Oracle, etc., using various extensions and APIs.
- PHP follows the Zend Engine, which is the core of the language that interprets and executes the PHP code.
