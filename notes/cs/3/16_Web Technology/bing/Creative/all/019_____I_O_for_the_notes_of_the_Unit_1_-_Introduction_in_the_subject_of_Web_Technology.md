# I/O for the notes of the Unit 1 - Introduction

- I/O stands for input/output, which refers to the communication between a computer system and the external world.
- Input is the data or information that is given to a computer system by a user, a device, or another system.
- Output is the data or information that is produced by a computer system for a user, a device, or another system.
- I/O devices are the hardware components that enable input and output operations, such as keyboards, mice, monitors, printers, scanners, speakers, etc.
- I/O interfaces are the software components that manage the communication between the I/O devices and the computer system, such as drivers, protocols, ports, etc.
- I/O operations are the processes that involve transferring data or information between the I/O devices and the computer system, such as reading, writing, displaying, printing, scanning, etc.
- I/O is an essential aspect of web technology, as it enables the interaction between web users and web servers, web browsers and web pages, web applications and web services, etc.
- I/O can be classified into different types based on various criteria, such as:

  - Synchronous vs. asynchronous: Synchronous I/O means that the computer system waits for the input or output operation to complete before proceeding to the next task. Asynchronous I/O means that the computer system does not wait for the input or output operation to complete and can perform other tasks in the meantime.
  - Blocking vs. non-blocking: Blocking I/O means that the I/O operation blocks the execution of the program until it is finished. Non-blocking I/O means that the I/O operation does not block the execution of the program and can be interrupted or resumed at any time.
  - Buffered vs. unbuffered: Buffered I/O means that the data or information is temporarily stored in a memory area called a buffer before or after the I/O operation. Unbuffered I/O means that the data or information is directly transferred between the I/O devices and the computer system without using a buffer.
  - Sequential vs. random: Sequential I/O means that the data or information is accessed or stored in a sequential order, such as from the beginning to the end of a file. Random I/O means that the data or information can be accessed or stored in any order, such as by using a pointer or an index.
  - Character vs. binary: Character I/O means that the data or information is represented as characters, such as letters, digits, symbols, etc. Binary I/O means that the data or information is represented as binary digits, such as 0s and 1s.
