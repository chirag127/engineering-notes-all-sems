# Package and Interface

## Package
- A package is an organized set of related classes and interfaces in a programming language like Java .
- A package helps to group similar types of classes and interfaces and avoid name conflicts .
- A package can be accessed using an import statement .
- A package can have subpackages and can be nested .
- A package can have different levels of access modifiers such as public, protected, default, and private .

## Interface
- An interface is a set of fields and abstract methods that mainly allows implementing abstraction in a programming language like Java .
- An interface defines the behavior or contract that a class or another interface must follow .
- An interface can be extended by another interface or implemented by a class .
- An interface can have only public, static, and final fields and public and abstract methods .
- An interface can have default and static methods that have a body .

## Difference Between Package and Interface
- The main difference between package and interface is that a package is a collection of related classes and interfaces while an interface is a collection of fields and abstract methods .
- A package is used to organize the classes and interfaces in a logical manner while an interface is used to define the behavior or contract that a class or another interface must follow .
- A package can be accessed using an import statement while an interface can be extended by another interface or implemented by a class .
- A package can have different levels of access modifiers while an interface can have only public, static, and final fields and public and abstract methods .
