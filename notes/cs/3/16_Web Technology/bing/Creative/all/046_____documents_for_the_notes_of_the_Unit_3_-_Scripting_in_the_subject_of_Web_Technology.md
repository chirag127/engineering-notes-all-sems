# Documents for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are high-level languages that are interpreted by a browser or a server at run-time, rather than compiled beforehand.
- Scripting languages can be classified into two types: client-side and server-side.
- Client-side scripting languages are executed by the browser on the user's device, and can manipulate the HTML document, the browser window, and the user interface. Examples of client-side scripting languages are JavaScript, VBScript, and JScript.
- Server-side scripting languages are executed by the web server, and can access databases, files, and other server resources. Examples of server-side scripting languages are PHP, ASP, Perl, and Python.
- Scripting languages have some advantages and disadvantages over traditional programming languages, such as:
  - Advantages:
    - They are easy to learn and use, as they have simple syntax and built-in libraries.
    - They are portable and platform-independent, as they can run on any browser or server that supports them.
    - They are flexible and dynamic, as they can be embedded in HTML or other languages, and can change the web page content and appearance according to user input or other conditions.
  - Disadvantages:
    - They are less efficient and secure, as they are interpreted rather than compiled, and can be vulnerable to malicious code injection or unauthorized access.
    - They are less powerful and robust, as they have limited access to system resources and hardware, and can have compatibility issues with different browsers or servers.
    - They are less structured and standardized, as they have different syntax and features depending on the language and the implementation.
