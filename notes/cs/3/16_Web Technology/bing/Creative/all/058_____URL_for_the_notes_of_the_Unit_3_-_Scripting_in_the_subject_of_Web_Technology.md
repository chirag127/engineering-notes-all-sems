# Unit 3 - Scripting

Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages. Scripting languages are interpreted, high-level languages that can be embedded in HTML documents or run on web servers.

## Types of Scripting

There are two main types of scripting: client-side and server-side.

- Client-side scripting is the execution of scripts on the web browser of the user. It can manipulate the Document Object Model (DOM) of the web page, respond to user events, validate user input, and communicate with web servers. Client-side scripting languages include JavaScript, VBScript, and TypeScript.
- Server-side scripting is the execution of scripts on the web server that hosts the web page. It can generate dynamic HTML content, access databases, perform authentication, and handle requests from clients. Server-side scripting languages include PHP, Python, Ruby, and Node.js.

## Advantages and Disadvantages of Scripting

Some of the advantages of scripting are:

- Scripting languages are easy to learn and use, as they have simple syntax and do not require compilation.
- Scripting languages are flexible and expressive, as they support multiple paradigms and data types.
- Scripting languages are portable and cross-platform, as they can run on different browsers and operating systems.
- Scripting languages can enhance the functionality and interactivity of web pages, as they can create dynamic and responsive user interfaces.

Some of the disadvantages of scripting are:

- Scripting languages are slower and less efficient than compiled languages, as they require interpretation at runtime.
- Scripting languages are less secure and reliable than compiled languages, as they are more prone to errors and vulnerabilities.
- Scripting languages are less standardized and consistent than compiled languages, as they have different implementations and versions across browsers and servers.
