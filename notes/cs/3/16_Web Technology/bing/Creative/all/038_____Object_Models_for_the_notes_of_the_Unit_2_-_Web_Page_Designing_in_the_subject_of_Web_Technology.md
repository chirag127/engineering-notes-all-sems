# Object Models for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- An object model is a visual representation of a system's objects, actions, and associated attributes.
- An object model can be used, in conjunction with a design system, to create a consistent and intuitive user interface for web pages.
- One of the most popular object models in web page designing is the Page Object Model (POM), which is a design pattern used in test automation that creates an object repository for web UI elements  .
- In POM, each web page in the application is represented by a corresponding page class, which contains the web elements and the methods or functions to interact with them.
- The advantage of POM is that it reduces code duplication and improves test maintenance, as any change in the web page can be easily reflected in the page class without affecting the test scripts.
- POM also enhances the readability and reusability of the test code, as the test scripts can use the page class methods to perform actions on the web page, rather than directly accessing the web elements.
- POM can be implemented using various tools and frameworks, such as Selenium, JavaScript, Page Factory, ScreenPlay, etc.
- POM follows the principle of separation of concerns, which means that the test logic and the web page structure are kept separate, making the test code more modular and maintainable.
- POM can be combined with other design patterns, such as Data-Driven Testing, Keyword-Driven Testing, etc., to achieve more robust and scalable test automation solutions.
