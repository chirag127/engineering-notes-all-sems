# Variable

- A variable is a named storage location that can hold a value of a specific type.
- A variable can be declared using a keyword followed by an identifier, such as `var x;` or `let y;`.
- A variable can be assigned a value using the assignment operator `=`, such as `x = 10;` or `y = "Hello";`.
- A variable can be accessed by using its identifier, such as `console.log(x);` or `alert(y);`.
- A variable can be changed by assigning a new value to it, such as `x = 20;` or `y = y + "!";`.
- A variable can have different scopes depending on where it is declared and how it is used.
  - A global variable is a variable that is declared outside any function or block and can be accessed from anywhere in the code.
  - A local variable is a variable that is declared inside a function or block and can be accessed only from within that function or block.
  - A block-scoped variable is a variable that is declared using `let` or `const` inside a block (such as an `if` statement or a `for` loop) and can be accessed only from within that block.
- A variable can have different types depending on the value it holds.
  - A primitive type is a type that represents a single value, such as a number, a string, a boolean, a null, or an undefined.
  - An object type is a type that represents a collection of properties and methods, such as an array, a function, a date, or a regular expression.
  - A symbol type is a type that represents a unique and immutable identifier, such as `Symbol("foo");`.
- A variable can be converted from one type to another using various methods, such as `Number(x);`, `String(y);`, or `Boolean(z);`.
- A variable can be compared with another variable using various operators, such as `==`, `===`, `<`, `>`, `<=`, `>=`, or `!=`.
- A variable can be manipulated using various operators, such as `+`, `-`, `*`, `/`, `%`, `++`, `--`, `+=`, `-=`, `*=`, `/=`, or `%=`.
