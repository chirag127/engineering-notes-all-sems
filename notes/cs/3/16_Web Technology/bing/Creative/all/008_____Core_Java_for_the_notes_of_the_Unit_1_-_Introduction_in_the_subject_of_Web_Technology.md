# Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

- Core Java is the basic and fundamental part of the Java programming language that is used for developing general-purpose applications.
- Core Java covers the essential concepts and features of the Java language, such as data types, operators, control statements, classes, objects, inheritance, polymorphism, exception handling, I/O, collections, etc.
- Core Java is also the foundation for developing advanced Java technologies, such as Java Enterprise Edition (JEE) and Java Platform, Micro Edition (Java ME).
- Web Technology is the use of various tools and techniques to create and deliver web-based applications and services over the internet.
- Web Technology involves the use of web servers, web browsers, web protocols, web languages, web frameworks, web APIs, web databases, etc.
- Web Technology enables the communication and interaction between web clients and web servers, as well as the creation of dynamic and interactive web pages and web applications.
- Core Java is one of the essential web technologies that is used for creating web applications and services in Java.
- Core Java provides the Servlet API, which is a set of interfaces and classes that enable the creation and management of web components, such as servlets, filters, listeners, etc.
- Servlets are Java classes that handle requests and responses from web clients, such as browsers, and can generate dynamic web content, such as HTML, XML, JSON, etc.
- Core Java also provides the Java Server Pages (JSP) technology, which is a way of creating web pages that contain both static and dynamic content, using HTML, XML, and Java code.
- JSP pages are compiled into servlets by the web server, and can use various tags and expressions to simplify the web development process.
- Core Java also provides the Java Database Connectivity (JDBC) API, which is a way of connecting and interacting with various types of databases, such as MySQL, Oracle, SQL Server, etc.
- JDBC enables the execution of SQL statements and queries, and the retrieval and manipulation of data from databases, using Java code.
- Core Java also provides the Java Class Library, which is a collection of classes and interfaces that provide various functionalities and features, such as networking, security, concurrency, XML processing, etc.
- Core Java also provides the Java Virtual Machine (JVM), which is a software component that executes Java bytecode, which is the intermediate representation of Java source code, and enables the platform-independent and cross-platform nature of Java.
- Core Java also provides the Java Development Kit (JDK), which is a software package that contains the tools and utilities for developing, compiling, debugging, and running Java applications and applets.
