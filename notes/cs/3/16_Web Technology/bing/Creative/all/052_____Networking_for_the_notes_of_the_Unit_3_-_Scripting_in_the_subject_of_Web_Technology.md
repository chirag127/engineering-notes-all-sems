# Networking for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Networking is the process of connecting multiple devices or systems over a network, such as the Internet, to exchange information and data.
- Networking can be done using various protocols, such as TCP/IP, HTTP, FTP, SMTP, etc.
- Networking can also involve programming, which is the process of creating and executing code to perform specific tasks or functions on a network.
- Networking programming can be done using various languages, such as Python, Java, C#, JavaScript, etc.
- Networking programming can be divided into two categories: client-side and server-side.

## Client-side programming
- Client-side programming is the process of creating and executing code that runs on the user's browser or device, such as a web page or a mobile app.
- Client-side programming can be used to create dynamic and interactive web pages or apps that respond to user input and events.
- Client-side programming can be done using various languages, such as HTML, CSS, JavaScript, etc.
- Client-side programming can also use web scripting, which is the process of embedding scripts in a web page that are interpreted and executed by the browser.
- Web scripting can be done using various languages, such as JavaScript, VBScript, PHP, etc.
- Web scripting can be used to enhance the functionality and appearance of a web page, such as validating user input, manipulating the document object model (DOM), creating animations, etc.

## Server-side programming
- Server-side programming is the process of creating and executing code that runs on the web server or the network device, such as a database or a router.
- Server-side programming can be used to create customized and dynamic responses for each user or request, such as generating web pages, processing data, sending emails, etc.
- Server-side programming can be done using various languages, such as PHP, Python, Ruby, C#, JavaScript, etc.
- Server-side programming can also use server-side scripting, which is the process of employing scripts on a web server that produce a customized response for each user.
- Server-side scripting can be done using various languages, such as PHP, Python, Ruby, C#, JavaScript, etc.
- Server-side scripting can be used to access and manipulate various resources on the server, such as databases, files, sessions, cookies, etc.

## Networking programmability
- Networking programmability is the process of using code, concepts based on the software development lifecycle, and other tools to make networks perform actions.
- Networking programmability can be used to automate, optimize, and troubleshoot network devices and operations, such as configuration, deployment, monitoring, testing, etc.
- Networking programmability can be done using various tools and frameworks, such as Ansible, Puppet, Chef, Cisco DNA Center, etc.
- Networking programmability can also involve DevOps, which is the practice of combining software development and IT operations to deliver software products faster and more reliably.
- DevOps can be done using various tools and practices, such as Git, Jenkins, Docker, Kubernetes, agile, continuous integration, continuous delivery, etc.
