### Presenting and using XML for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- XML stands for **eXtensible Markup Language**   .
- XML is a markup language similar to HTML, but without predefined tags to use.
- Instead, you define your own tags designed specifically for your needs.
- This is a powerful way to store data in a plain text format that can be stored, searched, and shared .
- XML also makes it easier to expand or upgrade to new operating systems, new applications, or new browsers, without losing data.
- XML was designed to store and transport data, and to be both human- and machine-readable .
- For an XML document to be correct, the following conditions must be fulfilled:
  - Document must be well-formed, meaning it must conform to all XML syntax rules.
  - Document must conform to semantic rules, which are usually set in an XML schema or a DTD (Document Type Definition).
- An example of a well-formed XML document is :

```xml
<?xml version="1.0" encoding="UTF-8"?>
<note>
  <to>Tove</to>
  <from>Jani</from>
  <heading>Reminder</heading>
  <body>Don't forget me this weekend!</body>
</note>
```

- XML can be used for various purposes, such as:
  - Creating custom data formats for exchanging information between applications.
  - Storing and retrieving data from databases.
  - Configuring and controlling applications.
  - Generating dynamic web pages.
  - Representing complex data structures, such as graphs, trees, or matrices.
  - Defining vocabularies for specific domains, such as mathematics, music, or chemistry.
  - Annotating and enriching text documents, such as books, articles, or reports.
  - Validating and transforming data using XML tools, such as XSLT, XPath, or XQuery.
