## Unit 3 - Scripting

- Scripting is the process of writing and executing a series of commands or instructions that can automate a task or perform a specific function.
- Scripting languages are high-level programming languages that are interpreted rather than compiled, meaning they are executed line by line at run time.
- Scripting languages are often used for tasks such as web development, data analysis, system administration, text processing, and automation.
- Some examples of popular scripting languages are Python, JavaScript, Ruby, Perl, and Bash.
- Scripting languages have some advantages and disadvantages compared to compiled languages, such as:
  - Advantages:
    - They are easy to learn and use, as they have simple syntax and high-level features.
    - They are portable, as they can run on different platforms and environments without requiring recompilation.
    - They are flexible and dynamic, as they can handle different types of data and support multiple paradigms.
    - They are interactive, as they can provide immediate feedback and allow users to modify and test code on the fly.
  - Disadvantages:
    - They are slower, as they require an interpreter to execute the code at run time.
    - They are less secure, as they expose the source code and may have vulnerabilities or bugs.
    - They are less efficient, as they consume more memory and resources than compiled code.
    - They are less reliable, as they may have unexpected behavior or errors due to their dynamic nature.
