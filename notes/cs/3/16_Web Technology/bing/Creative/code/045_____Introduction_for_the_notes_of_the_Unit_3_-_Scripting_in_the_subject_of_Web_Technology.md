### Introduction for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a technique of writing programs that are executed by an interpreter at run time, rather than being compiled into machine code.
- Scripting languages are often used for web development, as they can be embedded into HTML documents or run on the server side to generate dynamic web pages.
- Some examples of scripting languages are JavaScript, PHP, Python, Ruby, Perl, etc.
- Scripting languages have some advantages and disadvantages over compiled languages, such as:
  - Advantages:
    - They are easy to learn and use, as they have simple syntax and high-level features.
    - They are portable, as they can run on different platforms and browsers without recompilation.
    - They are flexible, as they can be modified and tested quickly without recompilation.
    - They are extensible, as they can interact with other languages and libraries through APIs and frameworks.
  - Disadvantages:
    - They are slower, as they have to be interpreted at run time, which adds overhead and reduces performance.
    - They are less secure, as they can be easily accessed and modified by malicious users or hackers.
    - They are less reliable, as they have less error checking and debugging tools than compiled languages.
    - They are less efficient, as they consume more memory and CPU resources than compiled languages.
