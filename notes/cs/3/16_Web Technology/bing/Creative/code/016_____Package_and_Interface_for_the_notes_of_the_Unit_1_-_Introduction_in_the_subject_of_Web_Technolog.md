### Package and Interface

- A package is an organized set of related classes and interfaces that belong to a specific domain or functionality .
- An interface is a set of fields and abstract methods that mainly allows implementing abstraction .
- A package can contain multiple classes and interfaces, while an interface can only contain fields and methods.
- A package can be accessed using an import statement, while an interface can be extended using another interface or implemented using a class.
- A package is defined using the keyword `package`, while an interface is defined using the keyword `interface`.
- A package helps to avoid name conflicts and organize the code in a modular way, while an interface helps to achieve multiple inheritance and polymorphism .
- An example of a package in web technology is the `javax.servlet` package, which contains classes and interfaces for creating servlets.
- An example of an interface in web technology is the `javax.servlet.Servlet` interface, which defines the methods that a servlet must implement.
