### JavaScript for the notes of the Unit 3 - Scripting in the subject of Web Technology

JavaScript is a scripting language that can be used to create dynamic and interactive web pages. It can run on both the client-side and the server-side. It is a prototype-based, multi-paradigm, single-threaded, and dynamic language that supports object-oriented, imperative, and declarative programming styles.

Some of the basic concepts of JavaScript are:

- **Variables**: Variables are containers that store values. They can be declared with the keywords `var`, `let`, or `const`, depending on the scope and mutability of the variable. For example, `var x = 10;` declares a variable named `x` and assigns it the value `10`.
- **Operators**: Operators are symbols that perform operations on values or variables. They can be classified into arithmetic, assignment, comparison, logical, bitwise, and other types. For example, `x + y` is an arithmetic operator that adds the values of `x` and `y`.
- **Conditionals**: Conditionals are statements that execute different blocks of code depending on a condition. The most common conditional statements are `if`, `else if`, and `else`. For example, `if (x > y) {console.log("x is greater than y");}` executes the code inside the curly braces if the condition `x > y` is true.
- **Loops**: Loops are statements that repeat a block of code until a condition is met. The most common loop statements are `for`, `while`, and `do...while`. For example, `for (var i = 0; i < 10; i++) {console.log(i);}` executes the code inside the curly braces 10 times, incrementing the variable `i` by 1 each time.
- **Functions**: Functions are blocks of code that can be defined and called by name. They can take parameters and return values. They can also be assigned to variables or passed as arguments to other functions. For example, `function add(x, y) {return x + y;}` defines a function named `add` that takes two parameters `x` and `y` and returns their sum.
- **Objects**: Objects are collections of properties and methods that can be created and manipulated. Properties are key-value pairs that store data, and methods are functions that perform actions on the object. Objects can be created using object literals, constructors, or the `Object` class. For example, `var person = {name: "Alice", age: 25, greet: function() {console.log("Hello, " + this.name);}};` creates an object named `person` with three properties and one method.
- **Arrays**: Arrays are objects that store multiple values in a single variable. They can be created using array literals or the `Array` class. They have a property called `length` that returns the number of elements in the array, and methods such as `push`, `pop`, `slice`, `sort`, and `forEach` that manipulate the array. For example, `var fruits = ["apple", "banana", "orange"];` creates an array named `fruits` with three elements.
- **Strings**: Strings are objects that store sequences of characters. They can be created using string literals or the `String` class. They have properties such as `length` and `indexOf`, and methods such as `charAt`, `concat`, `replace`, `split`, and `toUpperCase` that manipulate the string. For example, `var name = "Bob";` creates a string named `name` with the value `"Bob"`.
- **Numbers**: Numbers are objects that store numeric values. They can be created using number literals or the `Number` class. They have properties such as `MAX_VALUE` and `MIN_VALUE`, and methods such as `toFixed`, `toExponential`, `toString`, and `valueOf` that manipulate the number. For example, `var pi = 3.14;` creates a number named `pi` with the value `3.14`.
