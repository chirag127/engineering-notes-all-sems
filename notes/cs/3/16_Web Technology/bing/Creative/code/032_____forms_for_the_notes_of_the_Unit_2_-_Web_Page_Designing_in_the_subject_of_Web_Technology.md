### Forms
- Forms are used to collect user input on a web page.
- Forms consist of one or more elements, such as text fields, checkboxes, radio buttons, drop-down lists, buttons, etc.
- Forms are enclosed by the `<form>` tag, which has attributes such as `action`, `method`, `name`, `id`, etc.
- The `action` attribute specifies the URL of the server-side script that will process the form data.
- The `method` attribute specifies the HTTP method to use when sending the form data, either `GET` or `POST`.
- The `name` attribute assigns a name to the form, which can be used to identify it in JavaScript or CSS.
- The `id` attribute assigns a unique identifier to the form, which can be used to access it in JavaScript or CSS.
- The form elements are enclosed by the `<input>` tag, which has attributes such as `type`, `name`, `value`, `placeholder`, `required`, `checked`, `disabled`, etc.
- The `type` attribute specifies the type of the input element, such as `text`, `password`, `email`, `number`, `date`, `checkbox`, `radio`, `submit`, etc.
- The `name` attribute assigns a name to the input element, which can be used to access its value on the server-side or in JavaScript.
- The `value` attribute specifies the initial or default value of the input element.
- The `placeholder` attribute specifies a hint or a sample value for the input element, which is displayed when the element is empty.
- The `required` attribute specifies that the input element must be filled out before submitting the form.
- The `checked` attribute specifies that the input element is selected by default, such as a checkbox or a radio button.
- The `disabled` attribute specifies that the input element is disabled and cannot be edited or submitted.
- Some input elements have special tags, such as `<textarea>` for multi-line text input, `<select>` for drop-down lists, `<option>` for options in a drop-down list, `<button>` for buttons, etc.
- The `<label>` tag is used to associate a text label with an input element, which can improve the accessibility and usability of the form.
- The `<fieldset>` tag is used to group related input elements in a form, which can improve the layout and readability of the form.
- The `<legend>` tag is used to provide a caption or a title for a fieldset, which can improve the clarity and organization of the form.
