### Variable

- A variable is a named storage location that can hold a value of a specific type.
- A variable has three main characteristics: name, type, and value.
- The name of a variable is an identifier that follows the naming rules of the programming language.
- The type of a variable determines what kind of values it can store and what operations can be performed on it.
- The value of a variable is the data that is stored in the variable at any given time.
- A variable can be declared, assigned, and used in a program.
- A variable declaration specifies the name and type of the variable, and optionally an initial value.
- A variable assignment changes the value of the variable to a new one.
- A variable can be used in expressions, statements, and other parts of the program where its value is needed.
- A variable can have different scopes, which define the visibility and lifetime of the variable in the program.
- A variable can have different storage classes, which determine how the variable is allocated and deallocated in memory.
