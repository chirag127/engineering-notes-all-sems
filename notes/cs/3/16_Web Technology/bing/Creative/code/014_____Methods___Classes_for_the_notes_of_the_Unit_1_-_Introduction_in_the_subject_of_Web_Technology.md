### Methods & Classes

- A method is a block of code that performs a specific task. It can be invoked by other parts of the program or by the user.
- A class is a blueprint for creating objects. It defines the attributes and behaviors of the objects of that class.
- A class can have one or more methods that define the actions that the objects of that class can perform.
- A method can have parameters that allow it to receive input from the caller. It can also have a return value that allows it to send output to the caller.
- A method can be public, private, or protected. A public method can be accessed by any other class. A private method can only be accessed by the same class. A protected method can be accessed by the same class or its subclasses.
- A class can have constructors that are special methods that are invoked when an object of that class is created. They are used to initialize the attributes of the object.
- A class can have static methods that are shared by all the objects of that class. They can be invoked without creating an object of that class.
- A class can have abstract methods that are declared but not implemented. They must be overridden by the subclasses that inherit from that class.
- A class can have final methods that cannot be overridden by the subclasses that inherit from that class.
- A class can implement an interface that is a collection of abstract methods that define a common behavior for a group of classes. A class that implements an interface must provide the implementation for all the abstract methods in the interface.
- A class can extend another class that is called the superclass or the parent class. The class that extends the superclass is called the subclass or the child class. The subclass inherits all the attributes and methods from the superclass, and can also add its own attributes and methods.
