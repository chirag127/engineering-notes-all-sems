| Introduction to Web Page Designing | Definition and purpose of web pages | - A web page is a document that can be accessed through a web browser over the internet or intranet. <br> - The purpose of web pages is to present information, provide interactivity, and enable communication. |
|  | Types of web pages | - Static web pages: These are web pages that do not change in response to user input or server-side events. They are created using HTML and CSS and stored as files on the web server. <br> - Dynamic web pages: These are web pages that change in response to user input or server-side events. They are created using scripting languages such as PHP, ASP, or JavaScript and interact with databases or other web services. |
|  | Web page layout and design principles | - Web page layout is the arrangement of visual elements on a web page, such as text, images, links, navigation, etc. <br> - Web page design principles are the guidelines that help to create effective and attractive web pages, such as consistency, contrast, alignment, balance, hierarchy, etc. |
| HTML | Introduction to HTML | - HTML stands for HyperText Markup Language. It is the standard language for creating web pages and web applications. <br> - HTML uses tags to define the structure and content of a web page. Tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p>. <br> - HTML elements are the building blocks of a web page. They consist of a start tag, an end tag, and the content between them. Some elements are self-closing, such as <img> and <br>. |
|  | HTML syntax and rules | - HTML syntax is the set of rules that define how to write HTML code. Some of the rules are: <br> - HTML tags are case-insensitive, but it is a good practice to use lowercase. <br> - HTML attributes are used to provide additional information about an element. They are written inside the start tag, after the element name, and have the format name="value". <br> - HTML comments are used to add notes or explanations to the code. They are written inside <!-- and --> and are ignored by the browser. |
|  | HTML document structure | - An HTML document consists of two main parts: the head and the body. <br> - The head contains information about the document, such as the title, the character encoding, the style sheets, the scripts, etc. It is written inside <head> and </head> tags. <br> - The body contains the visible content of the document, such as the text, the images, the links, the forms, etc. It is written inside <body> and </body> tags. <br> - The HTML document starts with a declaration that specifies the version and type of HTML. It is written as <!DOCTYPE html>. |
|  | HTML basic elements | - Some of the basic HTML elements are: <br> - <html>: This element defines the root of an HTML document. It contains the head and the body elements. <br> - <title>: This element defines the title of the document, which is displayed in the browser's tab or window. It is written inside the head element. <br> - <h1> to <h6>: These elements define the headings of the document, from the most important (h1) to the least important (h6). They are written inside the body element. <br> - <p>: This element defines a paragraph of text. It is written inside the body element. <br> - <a>: This element defines a hyperlink, which is a clickable text or image that leads to another web page or resource. It has an attribute called href, which specifies the URL of the destination. It is written inside the body element. <br> - <img>: This element defines an image, which is a visual representation of data or information. It has an attribute called src, which specifies the URL of the image file. It is a self-closing element and is written inside the body element. |
