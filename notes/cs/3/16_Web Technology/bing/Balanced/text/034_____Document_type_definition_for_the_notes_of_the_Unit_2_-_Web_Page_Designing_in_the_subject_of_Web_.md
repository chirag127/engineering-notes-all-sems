### Document type definition for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

- A document type definition (DTD) is a set of rules that defines the structure and content of an XML or HTML document.
- A DTD specifies the elements, attributes, entities, notations, and comments that are allowed or required in a document.
- A DTD can be declared either internally or externally to the document. An internal DTD is written inside the document, while an external DTD is written in a separate file and referenced by the document.
- A DTD helps to ensure the validity and interoperability of web documents by providing a common standard for different applications and users.
- A DTD consists of the following components:
  - Element declarations: define the names and types of elements that can appear in the document, as well as their possible attributes and child elements.
  - Attribute declarations: define the names, types, and default values of attributes that can be associated with elements.
  - Entity declarations: define the names and values of entities that can be used to replace text or markup in the document.
  - Notation declarations: define the names and formats of external data that can be embedded or referenced in the document, such as images or audio files.
  - Comments: provide additional information or explanation about the DTD or the document.
- A DTD can be written using either a formal syntax or an informal syntax. A formal syntax follows the rules of the SGML or XML specification, while an informal syntax uses a simpler and more readable notation.
- A DTD can be validated using a DTD validator, which is a tool that checks if a document conforms to the rules of the DTD. A DTD validator can report any errors or warnings that occur during the validation process.
