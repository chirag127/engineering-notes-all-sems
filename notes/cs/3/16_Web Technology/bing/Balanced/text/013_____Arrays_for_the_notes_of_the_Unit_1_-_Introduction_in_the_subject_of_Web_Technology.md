### Arrays

- An array is a data structure that can store a collection of values of the same type.
- An array has a fixed size and can be accessed by using an index, which is a non-negative integer that represents the position of an element in the array.
- An array can be declared by using the syntax `type[] arrayName = new type[size];`, where `type` is the data type of the elements, `arrayName` is the name of the array, and `size` is the number of elements in the array.
- An array can also be initialized by using the syntax `type[] arrayName = {value1, value2, ..., valueN};`, where `value1, value2, ..., valueN` are the values of the elements in the array.
- An array can be accessed by using the syntax `arrayName[index]`, where `index` is a valid index in the range of `0` to `size - 1`.
- An array can be modified by using the syntax `arrayName[index] = newValue;`, where `index` is a valid index in the range of `0` to `size - 1` and `newValue` is the new value to be assigned to the element at that index.
- An array can be iterated by using a for loop or a for-each loop, which can access each element of the array in a sequential order.
- An array can be passed as a parameter to a method by using the syntax `methodName(arrayName);`, where `methodName` is the name of the method and `arrayName` is the name of the array.
- An array can be returned from a method by using the syntax `return arrayName;`, where `arrayName` is the name of the array.
