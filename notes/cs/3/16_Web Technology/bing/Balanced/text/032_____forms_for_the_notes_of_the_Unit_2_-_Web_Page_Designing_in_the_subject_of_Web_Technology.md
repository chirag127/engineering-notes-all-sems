### Forms
- Forms are used to collect user input on web pages.
- Forms consist of one or more input elements, such as text fields, checkboxes, radio buttons, drop-down lists, etc.
- Forms are enclosed by the `<form>` tag, which has attributes such as `action`, `method`, `name`, and `enctype`.
- The `action` attribute specifies the URL of the server-side script that will process the form data.
- The `method` attribute specifies the HTTP method to use when sending the form data, either `GET` or `POST`.
- The `name` attribute assigns a name to the form, which can be used to identify it in JavaScript or PHP.
- The `enctype` attribute specifies the encoding type of the form data, either `application/x-www-form-urlencoded` (the default) or `multipart/form-data` (for uploading files).
- Each input element has a `type` attribute that defines its functionality, such as `text`, `password`, `email`, `number`, `date`, `checkbox`, `radio`, `submit`, etc.
- Each input element also has a `name` attribute that assigns a name to the input, which can be used to access its value in the server-side script.
- Some input elements also have a `value` attribute that defines the initial or default value of the input.
- Some input elements also have a `checked` attribute that indicates whether the input is selected or not, such as for checkboxes and radio buttons.
- Some input elements also have a `required` attribute that indicates whether the input is mandatory or not, which can be validated by the browser before submitting the form.
- Some input elements also have a `placeholder` attribute that defines a hint or example for the input, which is displayed when the input is empty.
- Some input elements also have a `pattern` attribute that defines a regular expression for the input, which can be validated by the browser before submitting the form.
- Some input elements also have a `min`, `max`, and `step` attributes that define the minimum, maximum, and increment values for the input, such as for number and date inputs.
- To group related inputs together, the `<fieldset>` and `<legend>` tags can be used, which create a border and a caption around the inputs.
- To add labels to the inputs, the `<label>` tag can be used, which has a `for` attribute that links it to the input by its `id` attribute.
- To add options to a drop-down list, the `<select>` and `<option>` tags can be used, which have `value` and `selected` attributes to define the option values and selections.
- To add a text area for multi-line input, the `<textarea>` tag can be used, which has `rows` and `cols` attributes to define its size.
- To add a button for custom functionality, the `<button>` tag can be used, which has `type`, `name`, and `value` attributes to define its functionality and data.
- To add a file upload input, the `<input>` tag with `type="file"` can be used, which has `name`, `accept`, and `multiple` attributes to define its data and behavior.
- To add a hidden input that is not visible to the user but can be sent to the server, the `<input>` tag with `type="hidden"` can be used, which has `name` and `value` attributes to define its data.
