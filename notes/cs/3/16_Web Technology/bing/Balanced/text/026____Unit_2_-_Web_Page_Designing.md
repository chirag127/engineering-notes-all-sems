## Unit 2 - Web Page Designing

- Web page designing is the process of creating and arranging the content of a web page, such as text, images, links, videos, etc.
- Web page designing involves two aspects: web design and web development.
- Web design is the visual and aesthetic aspect of a web page, such as layout, color scheme, typography, etc. Web design is usually done using tools like HTML, CSS, and JavaScript.
- Web development is the functional and interactive aspect of a web page, such as navigation, user input, data processing, etc. Web development is usually done using tools like PHP, Python, Ruby, etc.
- Web page designing follows some basic principles, such as:
  - Consistency: The web page should have a consistent look and feel throughout, such as using the same fonts, colors, and styles.
  - Clarity: The web page should have a clear and logical structure, such as using headings, subheadings, lists, etc.
  - Simplicity: The web page should avoid unnecessary or distracting elements, such as excessive graphics, animations, or pop-ups.
  - Accessibility: The web page should be accessible to all users, regardless of their devices, browsers, or abilities, such as using responsive design, alt text, captions, etc.
  - Usability: The web page should be easy to use and navigate, such as providing clear and intuitive links, buttons, menus, etc.
- Web page designing requires some skills and knowledge, such as:
  - HTML: HyperText Markup Language, the standard language for creating web pages, which defines the structure and content of a web page using tags and attributes.
  - CSS: Cascading Style Sheets, the language for styling web pages, which defines the appearance and layout of a web page using selectors and properties.
  - JavaScript: The scripting language for adding interactivity and functionality to web pages, which can manipulate the HTML and CSS elements of a web page using events and functions.
  - PHP: Hypertext Preprocessor, a server-side scripting language for creating dynamic web pages, which can process user input, connect to databases, and generate HTML output.
  - Python: A high-level, general-purpose programming language for creating web applications, which can perform various tasks, such as data analysis, web scraping, machine learning, etc.
  - Ruby: A dynamic, expressive, and elegant programming language for creating web applications, which can simplify web development using frameworks, such as Ruby on Rails.
