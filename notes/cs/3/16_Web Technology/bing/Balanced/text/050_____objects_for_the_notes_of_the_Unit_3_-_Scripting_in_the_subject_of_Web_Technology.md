### Objects

- An object is a collection of properties that store data and functions that perform actions.
- Objects can be created using object literals, constructors, or the Object.create() method.
- Objects can be accessed and modified using dot notation or bracket notation.
- Objects can inherit properties and methods from other objects using prototypal inheritance.
- Objects can have getters and setters that define how to get and set the value of a property.
- Objects can have enumerable and non-enumerable properties that determine whether they can be iterated over or not.
- Objects can have own and inherited properties that indicate whether they belong to the object itself or its prototype chain.
- Objects can have configurable and non-configurable properties that determine whether they can be deleted or modified.
- Objects can have writable and non-writable properties that determine whether they can be assigned a new value or not.
- Objects can be compared for equality using the == or === operators, or the Object.is() method.
- Objects can be copied using the Object.assign() method or the spread operator (...).
- Objects can be converted to primitive values using the toString() or valueOf() methods, or the Symbol.toPrimitive() method.
- Objects can be iterated over using the for...in or for...of loops, or the Object.keys(), Object.values(), or Object.entries() methods.
- Objects can be checked for the presence of a property using the in operator or the hasOwnProperty() method.
- Objects can be checked for the type of a property using the typeof operator or the instanceof operator.
