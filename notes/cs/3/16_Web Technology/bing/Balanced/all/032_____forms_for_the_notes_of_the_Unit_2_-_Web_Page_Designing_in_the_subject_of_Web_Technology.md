# Forms

- Forms are used to collect user input on a web page.
- Forms consist of one or more input elements, such as text fields, checkboxes, radio buttons, drop-down lists, etc.
- Forms are enclosed by the `<form>` tag, which has attributes such as `action`, `method`, `name`, `id`, etc.
- The `action` attribute specifies the URL of the server-side script that will process the form data.
- The `method` attribute specifies the HTTP method to use when sending the form data, either `GET` or `POST`.
- The `name` attribute assigns a name to the form, which can be used to identify it in JavaScript or CSS.
- The `id` attribute assigns a unique identifier to the form, which can be used to access it in JavaScript or CSS.
- Each input element has a `type` attribute that defines the type of input, such as `text`, `password`, `email`, `number`, `date`, `checkbox`, `radio`, `submit`, etc.
- Each input element also has a `name` attribute that assigns a name to the input, which is used to identify the input value in the form data.
- Some input elements also have a `value` attribute that specifies the initial or default value of the input.
- Some input elements also have a `placeholder` attribute that specifies a hint or example of the expected input value.
- Some input elements also have a `required` attribute that indicates that the input is mandatory and cannot be left blank.
- Some input elements also have a `disabled` attribute that indicates that the input is not editable and cannot be submitted.
- Some input elements also have a `readonly` attribute that indicates that the input is editable but cannot be modified by the user.
- Some input elements also have a `checked` attribute that indicates that the input is selected by default, such as checkboxes or radio buttons.
- Some input elements also have a `min`, `max`, `step`, `pattern`, `maxlength`, `minlength`, `size`, etc. attributes that specify the constraints or validation rules for the input value.
- The `<label>` tag is used to associate a text label with an input element, which improves the usability and accessibility of the form.
- The `<label>` tag has a `for` attribute that specifies the `id` of the input element that it is linked to.
- The `<fieldset>` tag is used to group related input elements in a form, which improves the structure and readability of the form.
- The `<fieldset>` tag has a `disabled` attribute that indicates that all the input elements inside it are disabled.
- The `<legend>` tag is used to provide a caption or title for the `<fieldset>` tag, which improves the clarity and meaning of the form.
- The `<button>` tag is used to create a clickable button on a form, which can perform various actions such as submitting the form, resetting the form, or executing a JavaScript function.
- The `<button>` tag has a `type` attribute that specifies the type of button, either `button`, `submit`, or `reset`.
- The `<button>` tag also has a `value` attribute that specifies the value of the button, which is sent along with the form data.
- The `<button>` tag also has a `name` attribute that assigns a name to the button, which is used to identify the button value in the form data.
- The `<button>` tag also has a `disabled` attribute that indicates that the button is not clickable and cannot be submitted.
- The `<select>` tag is used to create a drop-down list on a form, which allows the user to choose one or more options from a list of predefined values.
- The `<select>` tag has a `name` attribute that assigns a name to the list, which is used to identify the list value in the form data.
- The `<select>` tag also has a `multiple` attribute that indicates that the user can select more than one option from the list.
- The `<select>` tag also has a `size` attribute that specifies the number of visible options in the list.
- The `<select>` tag also has a `disabled` attribute that indicates that the list is not editable and cannot be submitted.
- The `<select>` tag contains one or more `<option>` tags, which define the available options in the list.
- The `<option>` tag has a `value` attribute that specifies the value of the option, which is sent along with the form data.
