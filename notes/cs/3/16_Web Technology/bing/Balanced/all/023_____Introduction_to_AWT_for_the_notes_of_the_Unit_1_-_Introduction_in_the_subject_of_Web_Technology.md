# Introduction to AWT

- AWT stands for **Abstract Window Toolkit**.
- It is a platform-dependent API to develop **Graphical User Interface (GUI)** or window-based applications in Java .
- It was developed by **Sun Microsystem** in 1995.
- The user interface elements provided by the AWT are implemented using each platform's native GUI toolkit, thereby preserving the **look and feel** of each platform.
- The AWT provides a common set of tools for graphical user interface design that work on a variety of platforms.
- The AWT provides various **components** like button, label, checkbox, etc. used as objects inside a Java program.
- The AWT also provides **layout managers** to arrange the components in a container.
- The AWT is **heavy weight** i.e. its components are using the resources of underlying operating system (OS).
- The AWT handles the details of **tracking the mouse** or reading the **keyboard**, and **writing to the screen**.
- The AWT is the foundation of **Swing**, a more advanced and flexible GUI toolkit.
