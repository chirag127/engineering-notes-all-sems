## Unit 3 - Scripting

- Scripting is the process of writing and executing a series of commands or instructions that can automate a task or perform a specific function.
- Scripting languages are high-level programming languages that are interpreted rather than compiled, meaning they are executed line by line by a program called an interpreter.
- Scripting languages are often designed for specific domains or purposes, such as web development, data analysis, system administration, or text processing.
- Some examples of popular scripting languages are Python, JavaScript, Ruby, Perl, and Bash.
- Scripting languages have some advantages and disadvantages compared to compiled languages, such as:
  - Advantages:
    - They are easy to learn and use, as they have simple syntax and features.
    - They are portable and platform-independent, as they can run on any system that has the interpreter installed.
    - They are flexible and dynamic, as they can handle different types of data and modify the code at runtime.
    - They are suitable for rapid prototyping and testing, as they do not require a compilation step and can be modified quickly.
  - Disadvantages:
    - They are slower and less efficient, as they have to be interpreted every time they run and have more overhead.
    - They are less secure and reliable, as they are more prone to errors and vulnerabilities due to their dynamic nature and lack of type checking.
    - They are less powerful and expressive, as they have fewer features and libraries than compiled languages and may not support low-level operations or complex algorithms.
- Scripting languages can be used in various ways, such as:
  - Embedding: Scripting languages can be embedded within other programs or applications to extend their functionality or customize their behavior. For example, JavaScript can be embedded in web pages to add interactivity and dynamic features, or Python can be embedded in Blender to create 3D models and animations.
  - Glueing: Scripting languages can be used to glue or integrate different components or systems that are written in different languages or run on different platforms. For example, Perl can be used to process text files and data from various sources, or Ruby can be used to create web applications that interact with databases and web servers.
  - Standalone: Scripting languages can also be used to create standalone programs or applications that do not depend on other programs or languages. For example, Python can be used to create graphical user interfaces (GUIs) or games, or Bash can be used to create shell scripts that automate system tasks.
