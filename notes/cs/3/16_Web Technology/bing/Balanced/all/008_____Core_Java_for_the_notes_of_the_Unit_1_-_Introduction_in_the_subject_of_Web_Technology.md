# Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

- Core Java is the basic and fundamental part of the Java programming language that is used for developing general-purpose applications.
- Core Java covers the essential concepts and features of the Java language, such as data types, operators, control statements, classes, objects, inheritance, polymorphism, exception handling, I/O, collections, etc.
- Core Java is also the foundation for developing advanced Java technologies, such as Java Enterprise Edition (JEE) and Java Platform, Micro Edition (Java ME).
- Web Technology is the use of various tools and techniques to create and deliver web-based applications and services over the internet.
- Web Technology involves the use of web servers, web browsers, web protocols, web languages, web frameworks, web APIs, web databases, etc.
- Web Technology enables the communication and interaction between web clients and web servers, as well as the creation of dynamic and interactive web pages and web applications.
- Core Java is one of the most widely used web technologies for developing web applications, as it provides a platform-independent, secure, robust, and high-performance environment for web development.
- Core Java can be used to create web applications using various web technologies, such as Servlets, JavaServer Pages (JSP), JavaServer Faces (JSF), Java Database Connectivity (JDBC), Java Persistence API (JPA), Java Message Service (JMS), JavaMail, etc.
- Core Java can also be used to create web services using various web technologies, such as Java API for XML Web Services (JAX-WS), Java API for RESTful Web Services (JAX-RS), Java API for XML Processing (JAXP), Java API for JSON Processing (JSON-P), etc.
- Core Java can also be used to create web clients using various web technologies, such as Java Applets, Java Web Start, JavaFX, Swing, etc.
