# Objects

- An object is a collection of properties that store data and functions that perform actions on the data.
- An object can be created using an object literal, which is a comma-separated list of property names and values enclosed in curly braces.
- An object can also be created using an object constructor, which is a function that defines the properties and methods of the object.
- An object can be accessed and modified using dot notation or bracket notation, which specify the property name or the expression that evaluates to the property name.
- An object can inherit properties and methods from another object using prototypal inheritance, which is based on the prototype property of the object.
- An object can implement encapsulation, which is the principle of hiding the internal details of the object from the outside world, by using private variables and methods that are only accessible within the object.
- An object can implement abstraction, which is the principle of exposing only the essential features of the object to the outside world, by using public variables and methods that are accessible from outside the object.
- An object can implement polymorphism, which is the principle of having different behaviors for the same operation depending on the type of the object, by using the instanceof operator or the typeof operator to check the object type.
- An object can implement inheritance, which is the principle of reusing the properties and methods of an existing object in a new object, by using the extends keyword or the Object.create() method to create a subclass of the object.
