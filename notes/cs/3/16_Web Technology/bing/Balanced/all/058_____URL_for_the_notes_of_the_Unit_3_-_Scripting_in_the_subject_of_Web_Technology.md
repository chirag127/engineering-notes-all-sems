# URL for the notes of the Unit 3 - Scripting in the subject of Web Technology

- Scripting is a programming technique that allows the creation and execution of dynamic and interactive web pages.
- Scripting languages are interpreted, not compiled, and run on the client-side or the server-side of the web application.
- Client-side scripting languages run on the web browser and manipulate the HTML document object model (DOM) and the browser events. Examples of client-side scripting languages are JavaScript, VBScript, and TypeScript.
- Server-side scripting languages run on the web server and generate dynamic HTML pages based on the user input and the database queries. Examples of server-side scripting languages are PHP, Python, Ruby, and ASP.NET.
- Scripting languages have some common features, such as variables, data types, operators, expressions, control structures, functions, arrays, objects, and events.
- Scripting languages also have some specific features, such as document object model (DOM) manipulation, browser object model (BOM) access, form validation, cookies, sessions, and Ajax.
