# Standard Actions

- Standard actions are predefined tags that perform some common tasks in servlets.
- Standard actions start with the prefix `jsp:` and have the syntax `<jsp:action_name attribute="value" />`.
- Some of the standard actions are:

  - `<jsp:include>`: This action includes the content of another resource (such as a servlet, JSP page, or HTML file) at the request time. It has two attributes: `page` and `flush`. The `page` attribute specifies the relative URL of the resource to be included. The `flush` attribute is a boolean value that indicates whether the output buffer should be flushed before including the resource. The default value is `false`.
  - `<jsp:forward>`: This action forwards the request to another resource (such as a servlet, JSP page, or HTML file) at the request time. It has one attribute: `page`. The `page` attribute specifies the relative URL of the resource to be forwarded to. The `<jsp:forward>` action terminates the current page execution and discards any output generated by the current page.
  - `<jsp:param>`: This action adds a parameter to the query string of the request. It can be used as a nested action within `<jsp:include>` or `<jsp:forward>` actions. It has two attributes: `name` and `value`. The `name` attribute specifies the name of the parameter. The `value` attribute specifies the value of the parameter.
  - `<jsp:plugin>`: This action generates the necessary HTML code to include a Java applet or a JavaBean component in the web page. It has two attributes: `type` and `code`. The `type` attribute specifies the type of the plugin, either `applet` or `bean`. The `code` attribute specifies the name of the class file that implements the plugin. The `<jsp:plugin>` action can also have nested `<jsp:params>` actions to pass parameters to the plugin.
  - `<jsp:useBean>`: This action creates or locates a JavaBean component and associates it with a scripting variable. It has three attributes: `id`, `class`, and `scope`. The `id` attribute specifies the name of the scripting variable. The `class` attribute specifies the fully qualified name of the JavaBean class. The `scope` attribute specifies the scope of the bean, either `page`, `request`, `session`, or `application`. The default value is `page`. The `<jsp:useBean>` action can also have nested `<jsp:setProperty>` and `<jsp:getProperty>` actions to set and get the properties of the bean.
  - `<jsp:setProperty>`: This action sets the value of a property of a JavaBean component. It can be used as a nested action within `<jsp:useBean>` action. It has three attributes: `name`, `property`, and `value`. The `name` attribute specifies the name of the scripting variable that refers to the bean. The `property` attribute specifies the name of the property to be set. The `value` attribute specifies the value of the property to be set.
  - `<jsp:getProperty>`: This action gets the value of a property of a JavaBean component. It can be used as a nested action within `<jsp:useBean>` action. It has two attributes: `name` and `property`. The `name` attribute specifies the name of the scripting variable that refers to the bean. The `property` attribute specifies the name of the property to be retrieved. The value of the property is inserted into the output stream of the JSP page.
