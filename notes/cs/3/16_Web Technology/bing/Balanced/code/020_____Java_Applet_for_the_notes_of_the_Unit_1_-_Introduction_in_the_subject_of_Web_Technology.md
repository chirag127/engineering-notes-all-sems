### Java Applet

- A Java applet is a small application written in the Java programming language, or another programming language that compiles to Java bytecode, and delivered to users in the form of Java bytecode .
- A Java applet can be transferred via the Internet and run by a Java-compatible web browser.
- The main difference between Java-based applications and applets is that applets are typically executed in an AppletViewer or Java-compatible web browser, while applications are executed by the Java Virtual Machine (JVM) directly.
- The user can launch the Java applet from a web page, and the applet is then executed within a JVM in a process separate from the web browser.
- The `<applet>` tag was used to embed the Java applet in the HTML document. It provided web applications with interactive and dynamic features that HTML couldn’t offer.
- An applet can perform a specific task, such as displaying graphics, animations, games, calculators, etc., and has limited functionality. This allows applets to run quickly and reliably without demanding a lot of system resources.
- An applet can also communicate with other applets running on the same machine or different machines on a network. It can also access the host that served the applet, as well as other servers and web services.
- An applet has some restrictions on its security and access to the user's system, such as it cannot read or write data to the user's hard drive, create or delete files, or run any programs on the user's computer. These restrictions are imposed to prevent malicious applets from harming the user's system or data.
- An applet can be signed with a digital certificate to grant it more privileges, such as accessing the user's clipboard, printing, or making network connections to any host. The user can choose to accept or reject the applet's request for additional permissions.
- An applet can be written using the Applet class or the JApplet class, which are subclasses of the java.awt.Container class. The Applet class supports the Abstract Window Toolkit (AWT) for creating user interfaces, while the JApplet class supports the Swing toolkit for creating more advanced user interfaces.
- An applet has four basic methods that control its life cycle: init(), start(), stop(), and destroy(). The init() method is called when the applet is first loaded, the start() method is called when the applet is ready to run, the stop() method is called when the applet is stopped by the user or the browser, and the destroy() method is called when the applet is removed from the browser's memory.
- An applet can also override the paint() method to draw graphics on the applet's display area. The paint() method is called whenever the applet needs to be redrawn, such as when it is resized, moved, or hidden.
- An applet can also implement event listeners to handle user input, such as mouse clicks, keyboard presses, or menu selections. The event listeners are registered with the applet's components, such as buttons, text fields, or menus, and are invoked when the corresponding events occur.
- An applet can also use threads to perform multiple tasks concurrently, such as animation, sound, or network communication. A thread is a separate path of execution within a program that can run independently of other threads. An applet can create and manage threads using the Thread class or the Runnable interface.
- An applet can also use the AppletContext and AppletStub interfaces to interact with the browser and the web page that contains the applet. The AppletContext interface provides methods to access information about the browser, such as its name, version, and document base. The AppletStub interface provides methods to access information about the applet, such as its parameters, size, and visibility.
