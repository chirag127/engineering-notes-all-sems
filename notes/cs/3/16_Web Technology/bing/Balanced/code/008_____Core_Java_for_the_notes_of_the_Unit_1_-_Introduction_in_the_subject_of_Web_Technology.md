### Core Java for the notes of the Unit 1 - Introduction in the subject of Web Technology

- Core Java is the basic and fundamental part of the Java programming language that is used for developing general-purpose applications.
- Core Java covers the essential features and concepts of the Java language, such as data types, operators, control statements, arrays, strings, classes, objects, inheritance, polymorphism, exception handling, input/output, collections, generics, concurrency, and networking.
- Core Java is also known as Java Standard Edition (Java SE) or Java Platform Standard Edition (Java SE).
- Core Java is the foundation for developing other Java technologies, such as Java Enterprise Edition (Java EE) or Java Platform Enterprise Edition (Java EE), which is used for developing web-based and distributed applications, and Java Micro Edition (Java ME) or Java Platform Micro Edition (Java ME), which is used for developing applications for mobile devices and embedded systems.
- Core Java follows the principle of "write once, run anywhere" (WORA), which means that the Java code can run on any platform that supports the Java Virtual Machine (JVM), which is an interpreter that executes the Java bytecode.
- Core Java is an object-oriented, class-based, concurrent, and secure programming language that supports multiple paradigms, such as imperative, declarative, functional, and generic programming.
- Core Java is designed to be simple, robust, portable, high-performance, dynamic, and adaptable.
