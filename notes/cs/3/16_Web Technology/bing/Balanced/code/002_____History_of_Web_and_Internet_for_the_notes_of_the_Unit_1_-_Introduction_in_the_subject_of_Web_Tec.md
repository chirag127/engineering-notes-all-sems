### History of Web and Internet

- The **Internet** is a global network of interconnected computers that communicate using standardized protocols.
- The **Web** is a system of information resources that can be accessed through the Internet using a web browser.
- The Internet originated in the **1960s** as a project of the U.S. Department of Defense, called **ARPANET**, to create a resilient and decentralized network for military and academic purposes.
- The Web was invented in **1989** by **Tim Berners-Lee**, a British scientist working at **CERN**, a European research organization based in Geneva, Switzerland .
- Berners-Lee created the **HTTP** protocol, which defines how web servers and web browsers communicate, and the **HTML** language, which defines how web pages are formatted and linked.
- Berners-Lee also developed the first web browser, web server, and web page, and made his software available for free to the public in **1991**.
- The Web rapidly grew in popularity and usage, as more people and organizations created and accessed web pages, and new technologies and standards emerged, such as **URLs**, **CSS**, **JavaScript**, **XML**, **PHP**, **AJAX**, **Web 2.0**, **Web 3.0**, etc.
- The Web has transformed various aspects of human society, such as communication, education, entertainment, commerce, politics, culture, and science.
