# Variable

- A variable is a named storage location that can hold a value of a specific data type.
- A variable can be declared by specifying a name and a data type, optionally with an initial value.
- A variable can be used to store, manipulate, and retrieve data in a program.
- A variable has a scope, which defines where and how long it can be accessed in a program.
- A variable can be classified into different types based on its scope, such as global, local, static, and dynamic variables.
- A variable can also be classified into different types based on its data type, such as primitive, reference, and composite variables.
