### JavaScript for the notes of the Unit 3 - Scripting in the subject of Web Technology

JavaScript is a scripting language that can be used to create dynamic and interactive web pages. It can run on both the browser and the server. It is one of the most popular and widely used languages for web development.

Some of the basic concepts of JavaScript are:

- **Variables**: Variables are containers that store values. They can be declared with the keywords `var`, `let`, or `const`. The difference between them is the scope and the reassignment of the variables. `var` has a function scope and can be redeclared and reassigned. `let` and `const` have a block scope and cannot be redeclared. `let` can be reassigned, but `const` cannot.
- **Operators**: Operators are symbols that perform operations on values or variables. There are different types of operators, such as arithmetic, assignment, comparison, logical, bitwise, and ternary operators. For example, `+` is an arithmetic operator that adds two values, `=` is an assignment operator that assigns a value to a variable, `==` is a comparison operator that checks if two values are equal, `&&` is a logical operator that returns true if both operands are true, `&` is a bitwise operator that performs a bitwise AND operation on two values, and `? :` is a ternary operator that returns one of two values based on a condition.
- **Conditionals**: Conditionals are statements that execute different blocks of code based on certain conditions. The most common conditional statements are `if`, `else if`, and `else`. They can be nested or combined with logical operators. For example, `if (x > 10) {console.log("x is greater than 10");} else if (x < 0) {console.log("x is negative");} else {console.log("x is between 0 and 10");}`. There are also other conditional statements, such as `switch`, which executes different cases based on a value, and `try`, `catch`, and `finally`, which handle errors and exceptions.
- **Loops**: Loops are statements that repeat a block of code until a certain condition is met. The most common loops are `for`, `while`, and `do...while`. They can be used to iterate over arrays, objects, strings, or numbers. For example, `for (let i = 0; i < 10; i++) {console.log(i);}`. There are also other loops, such as `for...in`, which iterates over the properties of an object, and `for...of`, which iterates over the values of an iterable object.
- **Functions**: Functions are blocks of code that can be defined and invoked to perform a specific task. They can have parameters and return values. They can also be assigned to variables, passed as arguments, or returned from other functions. For example, `function add(x, y) {return x + y;}`. There are also other ways to define functions, such as function expressions, arrow functions, and generator functions.
- **Arrays**: Arrays are objects that store multiple values in a single variable. They can have different types of values, such as numbers, strings, booleans, or other objects. They can be accessed by their index, which starts from 0. They can also be modified by using methods, such as `push`, `pop`, `shift`, `unshift`, `splice`, `slice`, `sort`, `reverse`, `map`, `filter`, `reduce`, and more. For example, `let arr = [1, 2, 3, 4, 5]; arr.push(6); console.log(arr); // [1, 2, 3, 4, 5, 6]`.
- **Objects**: Objects are collections of properties and methods that represent a real-world entity or concept. They can have different types of values, such as numbers, strings, booleans, arrays, functions, or other objects. They can be accessed by their property name, which can be a string or a symbol.
