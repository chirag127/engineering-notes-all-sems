### Frames for the notes of the Unit 2 - Web Page Designing in the subject of Web Technology

Frames are a feature of HTML that allow multiple pages to be displayed within a single web page. The following are some of the key concepts related to frames:

1. Frame Set: A frame set is a container for multiple frames, each of which can display a separate web page.

2. Frame: A frame is a section of a frame set that displays a separate web page.

3. Target: A target is an attribute that specifies the frame in which a link should be displayed.

4. Nested Frames: Nested frames are frames within frames, allowing for complex and hierarchical page designs.

5. Frame Borders: Frame borders are the borders that surround the individual frames in a frame set.

6. Scrollbars: Scrollbars are used to scroll the contents of a frame if the contents of the frame are larger than the size of the frame.

7. Limitations: Frames have some limitations, such as difficulties with printing, bookmarking, and search engine optimization. 

In this unit, you will learn about frames and the key concepts related to them, including frame sets, frames, targets, nested frames, frame borders, scrollbars, and limitations.

This unit will provide a foundation for understanding the principles and practices of web page designing, and for exploring the various concepts and techniques used in the field of web technology.
