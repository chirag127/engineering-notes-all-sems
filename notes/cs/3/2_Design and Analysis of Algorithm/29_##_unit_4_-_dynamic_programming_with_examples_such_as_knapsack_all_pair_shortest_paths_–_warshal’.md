The main objectives of Unit 4 are to:

1. Introduce dynamic programming: This includes explaining the concept of dynamic programming and its use in solving optimization problems.

2. Discuss the knapsack problem: This includes explaining the knapsack problem, a classic example of dynamic programming, and how it can be solved using dynamic programming.

3. Explain all-pair shortest paths algorithms: This includes outlining Warshal's and Floyd's algorithms for finding the shortest path between all pairs of vertices in a graph.

4. Discuss the resource allocation problem: This includes explaining the resource allocation problem, a type of optimization problem, and how it can be solved using dynamic programming.

5. Introduce backtracking: This includes explaining the concept of backtracking and its use in solving optimization problems.

6. Discuss branch and bound: This includes explaining the concept of branch and bound and its use in solving optimization problems.

7. Discuss examples of optimization problems: This includes explaining the travelling salesman problem, graph coloring, n-queen problem, Hamiltonian cycles, and sum of subsets, and how they can be solved using dynamic programming and/or backtracking and branch and bound.

By the end of Unit 4, students will have a comprehensive understanding of dynamic programming, backtracking, and branch and bound, and will be able to apply these techniques to solve a variety of optimization problems.
