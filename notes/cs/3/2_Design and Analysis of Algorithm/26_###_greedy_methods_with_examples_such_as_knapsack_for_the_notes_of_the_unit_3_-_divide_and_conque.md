Greedy Methods:

1. Definition: Greedy methods are a class of algorithms that make the best choice at each step in the hope of finding an optimal solution. 

2. Knapsack Problem: The knapsack problem is a classic example of a problem that can be solved using a greedy method. Given a set of items with weights and values, the goal is to find the subset of items that maximizes the total value while staying under a given weight limit. 

3. Optimal Reliability Allocation: Another example of a problem that can be solved using a greedy method is the optimal reliability allocation problem. Given a set of components with different reliabilities, the goal is to allocate the components to minimize the overall system failure rate.

4. Minimum Spanning Trees: The minimum spanning tree problem can also be solved using greedy methods. Given a connected, undirected graph, the goal is to find a tree that spans all the vertices and has the minimum total edge weight. Prim's and Kruskal's algorithms are two popular greedy algorithms for solving this problem.

5. Shortest Paths: The single source shortest path problem can also be solved using greedy methods. Dijkstra's and Bellman-Ford algorithms are two popular greedy algorithms for solving this problem.

Note: Greedy methods are simple and efficient, but they do not always produce an optimal solution. It is important to carefully analyze the problem and determine if a greedy method is appropriate before using it.
