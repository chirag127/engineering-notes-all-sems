
### Analyzing Algorithms

Unit 1 - Introduction: 
- Algorithms: A sequence of instructions that can be followed to achieve a desired outcome.
- Analyzing Algorithms: The process of understanding the behavior and performance of an algorithm.
- Complexity of Algorithms: The amount of resources (time, space, etc.) needed for an algorithm to complete.
- Growth of Functions: The rate at which a function grows as its input increases.
- Performance Measurements: The time and space complexity of an algorithm.
- Sorting and Order Statistics: The process of arranging elements in a particular order.
- Shell Sort: An algorithm for sorting that compares elements that are a certain distance apart.
- Quick Sort: An algorithm for sorting that uses a pivot element to partition the array.
- Merge Sort: An algorithm for sorting that recursively divides the array into halves and merges them.
- Heap Sort: An algorithm for sorting that uses a heap data structure.
- Comparison of Sorting Algorithms: Comparing the performance of different sorting algorithms.
- Sorting in Linear Time: An algorithm for sorting that runs in linear time.
