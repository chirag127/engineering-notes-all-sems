
### Dynamic Programming with Examples Such as All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms 

Dynamic Programming is an algorithmic technique used for solving optimization problems by breaking them down into smaller subproblems. It is used for solving problems with overlapping subproblems such as the knapsack problem, all-pairs shortest paths, resource allocation problem, and many others. 

The most common algorithms used in dynamic programming are Warshal’s and Floyd’s algorithms. Warshal’s algorithm is used to find the shortest paths between all pairs of vertices in a weighted graph. Floyd’s algorithm is used to find the shortest paths between all pairs of vertices in a weighted graph with negative edge weights. 

Other algorithmic techniques used in dynamic programming include backtracking, branch and bound, and sum of subsets. Backtracking is used to find solutions to problems such as the travelling salesman problem, graph coloring, n-queen problem, and Hamiltonian cycles. Branch and bound is used to find optimal solutions to problems such as the travelling salesman problem, graph coloring, and sum of subsets. Sum of subsets is used to find solutions to problems such as the knapsack problem and resource allocation problem.
