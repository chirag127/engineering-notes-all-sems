

## Unit 1 - Introduction: Algorithms, Analyzing Algorithms, Complexity of Algorithms, Growth of Functions, Performance Measurements, Sorting and Order Statistics

* An algorithm is a set of instructions that can be used to solve a problem. It is a step-by-step procedure for achieving a desired result.
* Analyzing algorithms is the process of understanding how an algorithm works and determining its performance characteristics.
* Complexity of algorithms is the amount of time and/or space required to execute an algorithm.
* Growth of functions is the rate at which a function's output increases as its input increases.
* Performance measurements is the process of measuring the performance of an algorithm.
* Sorting and order statistics are algorithms that can be used to rearrange a set of data into a specific order.

### Shell Sort

Shell sort is an in-place comparison sort algorithm. It works by comparing elements that are a certain distance apart and then swapping them if they are out of order.

### Quick Sort

Quick sort is an in-place comparison sort algorithm. It works by selecting a pivot element and then partitioning the array around the pivot.

### Merge Sort

Merge sort is an out-of-place comparison sort algorithm. It works by dividing the array into two halves, sorting each half, and then merging the sorted halves together.

### Heap Sort

Heap sort is an in-place comparison sort algorithm. It works by building a heap data structure and then sorting the elements of the heap.

### Comparison of Sorting Algorithms

The performance of sorting algorithms can be compared by looking at the time complexity, space complexity, and stability of the algorithm.

### Sorting in Linear Time

Sorting algorithms can be designed to run in linear time if the data is already partially sorted or if the data is known to have certain characteristics.
