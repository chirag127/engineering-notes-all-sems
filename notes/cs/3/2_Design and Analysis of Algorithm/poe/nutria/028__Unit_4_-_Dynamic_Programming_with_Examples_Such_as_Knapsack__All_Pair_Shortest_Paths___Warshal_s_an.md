
## Unit 4 - Dynamic Programming

Dynamic programming is an algorithmic technique for solving optimization problems. It is a powerful tool for solving complex problems by breaking them down into smaller, simpler subproblems.

### Knapsack Problem
The knapsack problem is a classic example of a dynamic programming problem. The goal is to fill a knapsack with items of maximum value without exceeding the knapsack's capacity.

### All Pair Shortest Paths – Warshal’s and Floyd’s Algorithms
Warshal's and Floyd's algorithms are two dynamic programming algorithms for finding the shortest paths between all pairs of vertices in a graph.

### Resource Allocation Problem
The resource allocation problem is a type of dynamic programming problem in which the goal is to allocate resources to different tasks in an optimal way.

### Backtracking
Backtracking is a general algorithmic technique for solving problems. It is a form of recursion in which the solution is built one step at a time by making choices and backtracking if the choice leads to a dead end.

### Branch and Bound
Branch and bound is a technique used to solve optimization problems. It involves breaking a problem down into smaller subproblems and then finding the best solution to each subproblem.

### Examples

#### Travelling Salesman Problem
The travelling salesman problem is an optimization problem in which the goal is to find the shortest route that visits all cities in a given graph.

#### Graph Coloring
Graph coloring is a type of optimization problem in which the goal is to color the vertices of a graph such that no two adjacent vertices have the same color.

#### n-Queen Problem
The n-queen problem is a classic example of a constraint satisfaction problem. The goal is to place n queens on an n x n chessboard such that no two queens attack each other.

#### Hamiltonian Cycles
A Hamiltonian cycle is a path in a graph that visits each vertex exactly once and returns to the starting vertex.

#### Sum of Subsets
The sum of subsets problem is an optimization problem in which the goal is to find a subset of a given set of numbers whose sum is equal to a given target.
