
### Algorithms for the notes of the Unit 1 - Introduction: Algorithms, Analyzing Algorithms, Complexity of Algorithms, Growth of Functions, Performance Measurements, Sorting and Order Statistics

* Algorithms: A set of instructions to solve a problem or perform a task.
* Analyzing Algorithms: Analysing the efficiency of an algorithm by looking at the amount of resources it uses.
* Complexity of Algorithms: Measuring the amount of resources an algorithm uses to solve a problem.
* Growth of Functions: Examining how the running time of an algorithm changes with the size of the input.
* Performance Measurements: Examining the time and space complexity of an algorithm.
* Sorting and Order Statistics: Algorithms that sort a list of elements and find the order statistics of the list.
* Shell Sort: An algorithm to sort a list of elements using insertion sort and exchange sort.
* Quick Sort: An algorithm to sort a list of elements using a divide-and-conquer approach.
* Merge Sort: An algorithm to sort a list of elements using a divide-and-conquer approach.
* Heap Sort: An algorithm to sort a list of elements using a heap data structure.
* Comparison of Sorting Algorithms: Examining the performance of different sorting algorithms.
* Sorting in Linear Time: Algorithms that can sort a list of elements in linear time.
