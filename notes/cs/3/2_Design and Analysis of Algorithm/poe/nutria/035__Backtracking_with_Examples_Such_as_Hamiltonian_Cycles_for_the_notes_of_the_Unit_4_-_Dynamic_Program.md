
### Backtracking with Examples Such as Hamiltonian Cycles 

Backtracking is a general algorithm for finding all (or some) solutions to some computational problem, that incrementally builds candidates to the solutions, and abandons each partial candidate c ("backtracks") as soon as it determines that c cannot possibly be completed to a valid solution.

Examples of backtracking include: 

* Hamiltonian cycles: A Hamiltonian cycle (or Hamiltonian circuit) is a graph cycle that visits each vertex exactly once. Hamiltonian cycles are often used to solve the travelling salesman problem. 

* n-Queen Problem: The n-queens problem is the problem of placing n queens on an n×n chessboard such that no two queens attack each other. 

* Graph Coloring: Graph coloring is a process of assigning colors to the vertices of a graph such that no two adjacent vertices have the same color. 

* Sum of Subsets: The sum of subsets problem is a problem of finding all subsets of a set of integers that sum up to a given number. 

* Travelling Salesman Problem: The travelling salesman problem is a problem of finding the shortest possible route that visits each city exactly once and returns to the origin city. 

* Resource Allocation Problem: The resource allocation problem is a problem of assigning resources to tasks in a way that maximizes the total benefit. 

* Knapsack Problem: The knapsack problem is a problem of maximizing the total value of items in a knapsack without exceeding its capacity. 

* All Pair Shortest Paths: All pair shortest paths (APSP) is an algorithm for finding the shortest path between every pair of nodes in a graph. Warshal's and Floyd's algorithms are commonly used to solve this problem.
