### GanttProject for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab.

1. GanttProject is free, open-source project management software.
2. It allows you to create Gantt charts to schedule and monitor tasks and projects.
3. A Gantt chart is a type of bar chart that illustrates a project schedule. Gantt charts illustrate the start and finish dates of the terminal elements and summary elements of a project.
4. GanttProject allows you to:
- Create tasks and milestones
- Define dependencies between tasks
- Assign resources (workers) to tasks
- View the critical path
- Track progress and monitor budget
- Export to PNG, PDF, HTML, Microsoft Project and other formats
5. GanttProject is suitable for:
- Project managers
- Software developers
- Students
- Home users
