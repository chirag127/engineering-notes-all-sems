### Junit for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab.

1. JUnit is a unit testing framework for Java programming language.
2. It is used to test individual units/components of a software application.
3. JUnit facilitates writing repeatable tests, testing core functionality and regression testing.
4. JUnit tests can be run automatically and they check for exceptions and failures.
5. The key components of JUnit are:
- Test case: Represents a single test.
- Test suite: A collection of test cases.
- Assertion: Used to check expected results.
- Fixtures: Used to set up preconditions for a test.
6. The benefits of JUnit are:
- Increases productivity.
- Facilitates refactoring.
- Serves as documentation.
- Increases quality and reliability.
- Reduces time required for testing.
