### It is also suggested that open source tools should be preferred to conduct the lab for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab.

- Open source tools are freely available and anyone can access, modify and distribute the source code.
- They are cost effective as they do not require any licensing fees.
- Wide community support is available for open source tools as many developers contribute to fix bugs and enhance the tools.
- Customizations and extensions are easily possible with the availability of source code.
- Students can understand the internal working of tools and learn while using open source tools.
- However, open source tools may lack technical support and guaranteed upgrades or fixes at times.
- Some key open source tools for software engineering lab include GitHub, Eclipse, NetBeans, Python, SQLite, MySQL, etc.
- Using these tools, students can get hands-on experience of various software engineering concepts and practices in a lab session.
