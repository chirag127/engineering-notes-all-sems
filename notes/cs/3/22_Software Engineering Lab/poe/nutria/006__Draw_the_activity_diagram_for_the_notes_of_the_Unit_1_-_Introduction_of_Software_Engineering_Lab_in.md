
### Draw the Activity Diagram for the Notes of the Unit 1 - Introduction of Software Engineering Lab in the Subject of Software Engineering Lab

1. Start: This is the starting point of the diagram.
2. Requirements Gathering: This is the process of gathering the requirements from the stakeholders.
3. Analysis: This is the process of analyzing the requirements to understand the user needs and the system requirements.
4. Design: This is the process of designing the system architecture, data model and user interface.
5. Coding: This is the process of coding the system according to the design.
6. Testing: This is the process of testing the system to ensure that it meets the requirements.
7. Deployment: This is the process of deploying the system to the production environment.
8. Maintenance: This is the process of maintaining the system and keeping it up-to-date.
9. End: This is the end point of the diagram.
