
### Prepare a SRS document in line with the IEEE recommended standards for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

1. Software Requirements Specification (SRS) is a document that describes the requirements of a software system.
2. The SRS should be written in accordance with the IEEE standards for software engineering.
3. The SRS should include the following elements: 
    - A description of the system to be developed 
    - The functional and non-functional requirements of the system 
    - The constraints and assumptions of the system 
    - The system's external interfaces 
4. The SRS should be written in a clear and concise manner and should be easily understandable by all stakeholders.
5. The SRS should be reviewed and approved by all stakeholders before the development of the system begins.
