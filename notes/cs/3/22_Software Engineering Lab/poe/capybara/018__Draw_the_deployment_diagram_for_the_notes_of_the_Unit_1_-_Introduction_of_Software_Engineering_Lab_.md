3. Draw the nodes: Draw the nodes, and label them appropriately. In this case, we will draw three nodes - the user's computer, the server, and the internet.

4. Add the components: Add the components of the system to the nodes. In this case, the notes will be hosted on the server. Therefore, we will add the notes component to the server node.

7. Add any other necessary details: Add any other necessary details to the diagram, such as firewalls or load balancers.
