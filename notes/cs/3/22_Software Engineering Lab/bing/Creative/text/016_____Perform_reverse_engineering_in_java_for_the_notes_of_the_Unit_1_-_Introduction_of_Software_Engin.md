### Perform reverse engineering in java for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

- Reverse engineering in java is the process of recovering the source code from a compiled class file .
- The source code that is obtained by reverse engineering is not the exact original code, but an equivalent code that can be compiled to produce the same class file.
- Reverse engineering can be useful for code understanding, debugging, testing, documentation, and modification .
- To perform reverse engineering in java, one needs a tool that can decompile the class file into a readable source code. There are many tools available for this purpose, such as JD-GUI, Procyon, CFR, Fernflower, etc.
- Some tools can also integrate with IDEs such as Eclipse or IntelliJ IDEA, and provide features such as syntax highlighting, code navigation, refactoring, etc .
- The steps to perform reverse engineering in java using a tool are as follows:
  - Select the class file or the jar file that contains the class file to be reverse engineered.
  - Open the file with the tool or the IDE plugin that supports reverse engineering.
  - View the source code that is generated by the tool or the plugin.
  - Save the source code as a java file or copy it to the clipboard.
  - Optionally, edit the source code to make it more readable, consistent, or compliant with the coding standards.
  - Optionally, compile the source code to verify its functionality and correctness.
