# Unit 1 - Introduction of Software Engineering Lab

## Precondition
- The precondition for the notes of this unit is that the student has basic knowledge of software development, programming languages, and software tools.

## Content
- Software engineering is the discipline of applying engineering principles and practices to the creation, operation, and maintenance of software systems.
- Software engineering lab is a practical course that aims to provide hands-on experience in software engineering concepts, methods, and tools.
- The objectives of software engineering lab are to:
  - Understand the software development life cycle and its phases.
  - Apply software engineering principles and standards to software projects.
  - Use software engineering tools and techniques for software analysis, design, implementation, testing, and documentation.
  - Develop software products that meet the functional and non-functional requirements of the stakeholders.
  - Work effectively in a team and communicate clearly with the clients and peers.
- The topics covered in software engineering lab are:
  - Software engineering process models and methodologies, such as waterfall, agile, and iterative models.
  - Software requirements engineering, such as elicitation, analysis, specification, validation, and management of software requirements.
  - Software design, such as architectural, structural, behavioral, and user interface design of software systems.
  - Software implementation, such as coding, debugging, and integration of software components.
  - Software testing, such as unit, integration, system, and acceptance testing of software products.
  - Software quality assurance, such as verification, validation, inspection, review, and audit of software artifacts.
  - Software maintenance, such as corrective, adaptive, perfective, and preventive maintenance of software systems.
  - Software configuration management, such as version control, change management, and release management of software artifacts.
  - Software project management, such as planning, estimation, scheduling, monitoring, and control of software projects.
  - Software engineering tools, such as editors, compilers, debuggers, testing tools, documentation tools, and CASE tools.
