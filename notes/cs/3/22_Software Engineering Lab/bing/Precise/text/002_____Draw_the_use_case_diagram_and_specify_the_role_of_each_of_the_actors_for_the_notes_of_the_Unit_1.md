### Use Case Diagram and Actors in Software Engineering Lab

A use case diagram is a visual representation of the interactions between the users (actors) and the system in a specific scenario. It helps to identify the requirements of the system and the roles of the actors involved.

In the context of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab, the use case diagram may include the following actors and their roles:

1. **Student**: A student is an actor who interacts with the system to learn and practice the concepts of software engineering. The student may perform actions such as accessing study materials, submitting assignments, and taking quizzes.

2. **Instructor**: An instructor is an actor who interacts with the system to teach and assess the students. The instructor may perform actions such as uploading study materials, creating assignments, and grading quizzes.

3. **System Administrator**: A system administrator is an actor who interacts with the system to manage and maintain it. The system administrator may perform actions such as creating and managing user accounts, and ensuring the smooth operation of the system.

```
+----------------+
| System         |
| Administrator  |
+----------------+
       |
       |
+----------------+
| Instructor     |
+----------------+
       |
       |
+----------------+
| Student        |
+----------------+
```

In this diagram, the actors are represented by stick figures and the use cases are represented by ovals. The lines between the actors and the use cases indicate the interactions between them. The system is represented by a rectangle that encloses the use cases.
