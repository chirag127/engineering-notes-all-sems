### Identify the classes for the notes of the Unit 1 - Introduction of Software Engineering Lab in the subject of Software Engineering Lab

1. **Introduction to Software Engineering:** This class covers the basic concepts and principles of software engineering, including the software development life cycle, software development methodologies, and software quality assurance.

2. **Software Development Process Models:** This class covers the various software development process models, including the Waterfall model, the Spiral model, the Incremental model, and the Agile model.

3. **Requirements Engineering:** This class covers the process of gathering, analyzing, and documenting software requirements, including functional and non-functional requirements.

4. **Software Design:** This class covers the process of designing software, including architectural design, modular design, and object-oriented design.

5. **Software Testing:** This class covers the process of testing software, including unit testing, integration testing, system testing, and acceptance testing.

6. **Software Maintenance:** This class covers the process of maintaining software, including corrective maintenance, adaptive maintenance, perfective maintenance, and preventive maintenance.

7. **Software Project Management:** This class covers the process of managing a software project, including project planning, project scheduling, risk management, and project monitoring and control.

8. **Software Configuration Management:** This class covers the process of managing the configuration of software, including version control, change management, and release management.

9. **Software Quality Assurance:** This class covers the process of ensuring the quality of software, including quality planning, quality control, and quality improvement.

10. **Software Metrics:** This class covers the use of software metrics to measure the quality of software, including size metrics, complexity metrics, and reliability metrics.
