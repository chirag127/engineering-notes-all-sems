### Function of Each Use Case for the Notes of the Unit 1 - Introduction of Software Engineering Lab in the Subject of Software Engineering Lab

A use case is a description of how a system interacts with one or more external entities called actors. Each use case describes the steps that the system and the actors take to achieve a specific goal. The main functions of use cases in software engineering are:

1. **Requirements elicitation**: Use cases help to identify and document the functional requirements of a system by describing the interactions between the system and its actors.

2. **System modeling**: Use cases provide a way to model the behavior of a system and its interactions with the actors. This helps to visualize and understand the system's functionality.

3. **Validation and verification**: Use cases can be used to validate and verify that the system meets the functional requirements. This is done by executing the use cases and checking if the system behaves as expected.

4. **Communication**: Use cases provide a common language for the development team, stakeholders, and users to communicate about the system's functionality. This helps to ensure that everyone has a shared understanding of the system's behavior.

5. **Documentation**: Use cases provide a way to document the system's behavior and its interactions with the actors. This documentation can be used as a reference for the development team, stakeholders, and users.

Overall, use cases are an important tool in software engineering for eliciting, modeling, validating, verifying, communicating, and documenting the functional requirements of a system. They help to ensure that the system meets the needs of its users and stakeholders.
