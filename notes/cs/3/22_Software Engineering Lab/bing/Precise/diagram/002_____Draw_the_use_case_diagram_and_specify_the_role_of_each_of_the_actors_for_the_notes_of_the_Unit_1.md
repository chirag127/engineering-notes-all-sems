### Use Case Diagram for Software Engineering Lab - Unit 1: Introduction

A use case diagram is a visual representation of the interactions between the users (actors) and the system. It shows the relationships between the actors and the use cases in which they are involved.

In the context of Unit 1 - Introduction of Software Engineering Lab, the use case diagram could include the following actors and their roles:

1. **Student**: The primary actor who interacts with the system to learn about the concepts of software engineering. The student can view the course material, take quizzes, and submit assignments.

2. **Instructor**: The secondary actor who is responsible for creating and managing the course content. The instructor can create and update the course material, create quizzes, and grade assignments.

3. **System Administrator**: The supporting actor who is responsible for maintaining the system. The system administrator can manage user accounts, backup and restore data, and monitor system performance.

The use case diagram for Unit 1 - Introduction of Software Engineering Lab could look like this:

```
+----------------+
|                |
|   Student      |
|                |
+-------+--------+
        |
        |
        |
+-------+--------+
|                |
|   Instructor   |
|                |
+----------------+
        |
        |
        |
+-------+--------+
|                |
|System Admin    |
|                |
+----------------+
```

Each of the actors has a specific role in the system, and the use case diagram shows the interactions between the actors and the system. The student can view the course material, take quizzes, and submit assignments. The instructor can create and update the course material, create quizzes, and grade assignments. The system administrator can manage user accounts, backup and restore data, and monitor system performance. These interactions are represented by the lines connecting the actors to the system.
