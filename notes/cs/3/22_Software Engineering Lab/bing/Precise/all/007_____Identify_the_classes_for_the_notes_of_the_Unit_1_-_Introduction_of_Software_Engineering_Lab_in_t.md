# Unit 1 - Introduction of Software Engineering Lab

In the subject of Software Engineering Lab, the classes for the notes of Unit 1 - Introduction of Software Engineering Lab are as follows:

1. **Overview of Software Engineering**: This class provides an introduction to the field of software engineering, including its history, principles, and practices.

2. **Software Development Life Cycle (SDLC)**: This class covers the various stages of the software development life cycle, including requirements analysis, design, implementation, testing, and maintenance.

3. **Software Development Models**: This class introduces various software development models, such as the waterfall model, the spiral model, and the agile model.

4. **Software Requirements**: This class covers the process of gathering, analyzing, and documenting software requirements.

5. **Software Design**: This class covers the principles and practices of software design, including architectural design, modular design, and object-oriented design.

6. **Software Testing**: This class covers the various types of software testing, including unit testing, integration testing, system testing, and acceptance testing.

7. **Software Maintenance**: This class covers the process of maintaining and enhancing software systems after they have been deployed.

8. **Software Project Management**: This class covers the principles and practices of managing software projects, including planning, scheduling, and tracking progress.
