## Use Case Diagram

A use case diagram is a visual representation of the interactions between the users (actors) and the system. It shows the relationships between the actors and the use cases in which they are involved.

In the context of the Software Engineering Lab, the use case diagram can be used to represent the different actors and their roles in the lab. Here is an example of a use case diagram for the Software Engineering Lab:

```
+----------------+
|                |
|   Instructor   |
|                |
+-------+--------+
        |
        |
+-------+--------+
|                |
|   Student      |
|                |
+----------------+
```

In this diagram, there are two actors: the Instructor and the Student. The Instructor is responsible for creating and managing the lab assignments, while the Student is responsible for completing the assignments.

## Roles of Actors

- **Instructor:** The Instructor is responsible for creating and managing the lab assignments. This includes defining the requirements, providing the necessary resources, and grading the assignments.

- **Student:** The Student is responsible for completing the lab assignments. This includes understanding the requirements, using the provided resources, and submitting the completed assignments for grading.

These are the basic roles of the actors in the Software Engineering Lab. However, the specific roles and responsibilities may vary depending on the specific lab and the requirements of the course. It is important to clearly define the roles of each actor to ensure that the lab runs smoothly and effectively.
