# dotProject

dotProject is a web-based, multi-user, multi-language project management application. It is free and open-source software, maintained by an open community of volunteer programmers. The software is free to anyone who would like to download it .

- **History:** dotProject was originally developed by Will Ezell at dotmarketing, Inc. as an open-source replacement for Microsoft Project, using a very similar user interface but including project management functionality. Begun in 2000, the project was moved to SourceForge in October 2001, and, from version 2.1.8 onwards, is hosted on GitHub .

- **Features:** dotProject is a volunteer-supported Project Management application. There is no "company" behind this project, it is managed, maintained, developed, and supported by a volunteer group and by the users themselves .

- **Community:** dotProject is completely developed and managed by its community. Support is given by the community, and it is constantly updated .
