A use case diagram is a visual representation of the interactions between actors and the system being developed in a software engineering project. Actors are entities that interact with the system, such as users, systems, or other external entities. In a use case diagram, actors are represented as stick figures and are connected to use cases, which are sequences of interactions between actors and the system.
