### Dynamic Versus Static Systems for the notes of the Unit 2 - Real Time Scheduling in the subject of Real Time System

Dynamic versus static systems are two types of real-time systems, which are systems that require predictable and timely processing of data. The following are some of the key concepts related to dynamic versus static systems:

1. Dynamic Systems: Dynamic systems are real-time systems where the processing requirements change over time, and the system must adapt to these changes. Dynamic systems require flexible scheduling algorithms that can handle changes in processing requirements.

2. Static Systems: Static systems are real-time systems where the processing requirements are known in advance and do not change over time. Static systems can use simpler scheduling algorithms, as the processing requirements are known and do not need to be adapted.

3. Scheduling Algorithms: The type of scheduling algorithm used in a real-time system depends on whether the system is dynamic or static. Dynamic systems require flexible scheduling algorithms that can handle changes in processing requirements, while static systems can use simpler scheduling algorithms.

4. Performance: The performance of a real-time system depends on the type of system and the scheduling algorithm used. Dynamic systems may have lower performance due to the need for flexible scheduling algorithms, while static systems may have higher performance due to the use of simpler scheduling algorithms.

5. Applications: Dynamic and static systems are used in different types of real-time applications, such as control systems, multimedia systems, and more. The type of system used depends on the requirements of the application and the processing requirements of the data.

In this unit, you will learn about dynamic versus static systems in real-time systems, including dynamic systems, static systems, scheduling algorithms, performance, and applications.

This unit will provide a foundation for understanding the principles and practices of dynamic versus static systems in real-time systems, and for exploring the various concepts and techniques used in the field of real-time systems.
