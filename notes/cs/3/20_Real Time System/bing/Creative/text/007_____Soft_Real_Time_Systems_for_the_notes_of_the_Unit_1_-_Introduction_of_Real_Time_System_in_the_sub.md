### Soft Real Time Systems

- A soft real-time system is a system that can tolerate some degree of latency or jitter in meeting its deadlines  .
- A deadline is the time limit within which a task or an event must be completed or responded to  .
- Latency is the delay between the occurrence of an event and the response to it  .
- Jitter is the variation in latency over time  .
- In a soft real-time system, missing a deadline occasionally or by a small margin does not cause a catastrophic failure or a significant degradation of the system performance   .
- A soft real-time system can still provide useful results or services even if some deadlines are missed   .
- A soft real-time system can run on multiple cores and impose fewer restrictions on applications than a hard real-time system .
- A soft real-time system is typically used to solve issues of concurrent access and the need to keep a number of connected systems up-to-date through changing situations.
- Some examples of soft real-time systems are: software that maintains and updates the flight plans for commercial airliners, streaming audio-video, online gaming, and multimedia applications.
