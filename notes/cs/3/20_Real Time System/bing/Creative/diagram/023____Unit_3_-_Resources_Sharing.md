## Unit 3 - Resource Sharing

Resource sharing is the process of making the resources of one computer system available to other computer systems on a network. Resource sharing can improve the efficiency, performance, and reliability of distributed systems by allowing multiple users and applications to access and utilize the same resources.

Some examples of resources that can be shared are:

- Files and directories: Users can store, retrieve, and modify data on remote file systems as if they were local.
- Printers and scanners: Users can send documents to print or scan on remote devices without having to physically connect them to their own computers.
- CPU and memory: Users can run programs or processes on remote computers that have more processing power or memory than their own computers.
- Software and applications: Users can access and use software and applications that are installed on remote computers without having to install them on their own computers.
- Databases and web servers: Users can query and update data on remote databases or access web pages and services hosted on remote web servers.

Resource sharing can be implemented in different ways depending on the network architecture, the type of resources, and the level of abstraction. Some common methods of resource sharing are:

- File transfer: Users can copy files from one computer to another using protocols such as FTP, HTTP, or SCP.
- Remote login: Users can log in to a remote computer and execute commands or run programs using protocols such as Telnet, SSH, or RDP.
- Remote procedure call: Users can invoke procedures or functions on a remote computer and receive the results using protocols such as RPC, SOAP, or REST.
- Distributed file system: Users can access and manipulate files and directories on a remote computer as if they were part of their own file system using protocols such as NFS, SMB, or HDFS.
- Distributed object system: Users can access and manipulate objects on a remote computer as if they were part of their own object system using protocols such as CORBA, RMI, or DCOM.
- Distributed computing: Users can utilize the CPU and memory of a remote computer to perform parallel or distributed computations using frameworks such as MPI, MapReduce, or Spark.

Resource sharing can also be classified into two categories based on the degree of transparency:

- Explicit resource sharing: Users have to explicitly specify the location and name of the resources they want to access or use. For example, users have to provide the IP address and port number of a web server or the path and filename of a file on a remote file system.
- Implicit resource sharing: Users do not have to explicitly specify the location and name of the resources they want to access or use. The system automatically locates and allocates the resources based on some criteria. For example, users can print a document on any available printer on the network or run a program on any idle computer on the network.

Resource sharing can provide many benefits to distributed systems, such as:

- Increased resource utilization: Resource sharing can reduce the idle time and waste of resources by allowing multiple users and applications to share the same resources.
- Reduced cost and complexity: Resource sharing can reduce the need to purchase, install, and maintain multiple copies of the same resources on different computers.
- Enhanced scalability and reliability: Resource sharing can increase the capacity and availability of resources by allowing the system to dynamically add or remove resources as needed.
- Improved performance and quality of service: Resource sharing can improve the response time and throughput of applications by allowing them to use the most suitable and efficient resources.
