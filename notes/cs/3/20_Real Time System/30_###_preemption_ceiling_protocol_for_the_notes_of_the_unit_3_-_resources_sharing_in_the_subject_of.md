### Preemption Ceiling Protocol for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

Preemption Ceiling Protocol (PCP) is a protocol used in real-time systems for resolving priority inversion, which is a situation where a lower priority task is holding a resource needed by a higher priority task. The following are some of the key concepts related to PCP:

1. Priority Inversion: PCP is used to resolve priority inversion, which is a situation where a lower priority task is holding a resource needed by a higher priority task. This can lead to unpredictable behavior in real-time systems, as higher priority tasks may be blocked from executing.

2. Ceiling Priority: PCP assigns a ceiling priority to each resource, which is the highest priority that can be assigned to a task holding the resource. When a task holds a resource, its priority is raised to the ceiling priority of the resource, allowing higher priority tasks to execute.

3. Resource Management: PCP is used for resource management in real-time systems, which is the process of managing the resources of the system, such as processing power, memory, and more, to ensure that the timing constraints for processing tasks are met.

4. Performance Evaluation: PCP can be evaluated for performance, which is the process of evaluating the effectiveness of the protocol in resolving priority inversion and managing resources in real-time systems. Performance evaluation can be performed using metrics such as response time, completion time, and more.

5. Comparison with Priority Inheritance Protocol (PIP): PCP is similar to Priority Inheritance Protocol (PIP), which is another protocol used for resolving priority inversion. The main difference between PCP and PIP is that PCP assigns a ceiling priority to each resource, while PIP temporarily raises the priority of the lower priority task to the priority of the higher priority task.
