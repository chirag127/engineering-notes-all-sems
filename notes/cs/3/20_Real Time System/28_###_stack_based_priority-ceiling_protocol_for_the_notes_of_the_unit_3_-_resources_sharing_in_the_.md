### Stack Based Priority-Ceiling Protocol for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

Stack-Based Priority-Ceiling Protocol (SB-PCP) is a resource sharing protocol used in real-time systems to manage access to shared resources. The following are some of the key concepts related to SB-PCP:

1. Resource Sharing: Resource sharing is the process of allowing multiple tasks to access a shared resource, such as a processor, memory, or other resource, in a real-time system. SB-PCP is a protocol for managing resource sharing in real-time systems.

2. Priority Ceiling: Priority ceiling is a method of assigning priorities to tasks based on their access to shared resources. Tasks with higher priority ceilings have higher priorities and are allowed to access shared resources before tasks with lower priority ceilings.

3. Stack-Based: SB-PCP is a stack-based protocol, which means that it uses a stack data structure to manage access to shared resources. The stack contains a list of tasks that are waiting to access a shared resource, and the task at the top of the stack has the highest priority for accessing the resource.

4. Resource Locking: Resource locking is the process of locking a shared resource to prevent other tasks from accessing it. SB-PCP uses resource locking to ensure that only one task at a time can access a shared resource.

5. Priority Inheritance: Priority inheritance is a method of assigning higher priorities to tasks that are blocked from accessing a shared resource. SB-PCP uses priority inheritance to ensure that tasks with higher priority ceilings have higher priorities for accessing shared resources.

6. Performance Evaluation: Performance evaluation is the process of measuring the effectiveness of a resource sharing protocol, and can be performed using metrics such as response time, completion time, and more. Performance evaluation is important for comparing different resource sharing protocols and for selecting the best protocol for a given real-time system.
