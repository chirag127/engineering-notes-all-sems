
## Unit 1 - Introduction of Real Time System

1. Real-time systems are computer systems that respond to external events within a specified period of time.

2. Real-time systems are used in applications such as process control, robotics, and embedded systems.

3. Real-time systems can be classified into two types: hard real-time systems and soft real-time systems.

4. Hard real-time systems must complete their tasks within a specified period of time, otherwise the system could fail and cause serious consequences.

5. Soft real-time systems are more tolerant of delays and can handle deadlines that are slightly exceeded.

6. Real-time systems must be designed for reliability, robustness, and predictability.

7. Real-time systems must also be designed for scalability and flexibility to be able to handle changes in the environment.

8. Real-time systems must also be designed with safety and security in mind.
