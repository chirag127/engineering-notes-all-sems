
### Effect of Resource Contention and Resource Access Control (RAC)

1. Resource contention occurs when multiple processes attempt to access the same resource at the same time, leading to a conflict.

2. Resource access control (RAC) is a mechanism which is used to manage access to resources by processes. It is used to ensure that only authorized processes can access the resources.

3. RAC can be implemented using various techniques such as priority-based scheduling, locks, semaphores, message passing, and deadlock detection and avoidance.

4. Priority-based scheduling is a technique used to prioritize processes based on their priority levels. This ensures that processes with higher priority get access to the resource first.

5. Locks are used to ensure that only one process can access a resource at a time. This prevents processes from accessing the same resource simultaneously.

6. Semaphores are used to control the number of processes that can access a resource at any given time.

7. Message passing is a technique used to exchange messages between processes. This ensures that processes can communicate with each other and coordinate their access to resources.

8. Deadlock detection and avoidance is a technique used to detect and prevent deadlocks from occurring. Deadlocks occur when two or more processes are waiting for each other to release a resource.
