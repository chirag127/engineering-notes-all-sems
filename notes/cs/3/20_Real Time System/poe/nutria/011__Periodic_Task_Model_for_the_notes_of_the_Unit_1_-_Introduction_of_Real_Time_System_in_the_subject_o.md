
### Periodic Task Model

1. The periodic task model is a scheduling algorithm used in real-time systems that defines the execution of tasks at regular intervals. 
2. It is used when tasks must be completed in a specific order, and when the deadlines for each task are known in advance.
3. The periodic task model is based on the concept of a periodic task, which is a task that is repeated at regular intervals. 
4. Each task has a period, which is the time between successive executions of the task. 
5. The period must be greater than the execution time of the task, otherwise the task will not be able to complete on time. 
6. The periodic task model also allows for the possibility of pre-emptive scheduling, where a higher-priority task can interrupt the execution of a lower-priority task. 
7. The periodic task model is useful for applications such as industrial control systems, where tasks must be executed in a specific order and on a regular basis.
