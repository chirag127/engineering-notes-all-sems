
## Unit 5 - Real Time Operating Systems and Databases

1. Real-time operating systems (RTOS) are designed to provide deterministic performance and are used in embedded systems. They are designed to respond to external events in a timely manner and to process data within a given period.

2. RTOSs are typically designed to be small in size and to use minimal resources. This allows them to be used in embedded systems with limited memory and processing power.

3. RTOSs are designed to be fault-tolerant and to be able to recover from errors quickly. They also provide scheduling and synchronization mechanisms to ensure that tasks are executed in the correct order.

4. Databases are used to store, organize, and retrieve data. They are used in a variety of applications such as web applications, enterprise applications, and scientific applications.

5. Relational databases are the most common type of database and are used to store data in tables. Each table contains rows and columns, and the data is organized into relationships between the tables.

6. NoSQL databases are used to store data that does not fit into the relational model. They are designed to scale horizontally and to be able to store data of different types.

7. Object-oriented databases are used to store objects and their associated data. They are designed to be more flexible than relational databases and to support the object-oriented programming paradigm.
