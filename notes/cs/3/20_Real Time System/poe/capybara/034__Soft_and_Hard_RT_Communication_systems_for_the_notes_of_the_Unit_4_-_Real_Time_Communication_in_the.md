### Soft and Hard RT Communication systems

Real-time systems require communication between different components to function effectively. Depending on the application, there are two types of communication systems - Soft and Hard RT communication systems. 

#### Soft RT Communication System

1. Soft RT communication system is used in applications where timing constraints are not very strict. 
2. In this system, the communication delay between components is not critical, and a small delay can be tolerated. 
3. This system is typically used in applications where the response time can vary and is not critical. 
4. Soft RT communication systems are commonly used in multimedia applications such as video streaming, where small delays can be tolerated. 

#### Hard RT Communication System

1. Hard RT communication system is used in applications where timing constraints are critical. 
2. In this system, communication delay between components must be strictly controlled and should be as low as possible. 
3. This system is typically used in applications such as flight control systems or industrial automation, where a delay in communication can result in catastrophic consequences. 
4. Hard RT communication systems use specialized communication protocols that guarantee the delivery of messages within a specific time frame. 

In conclusion, Soft and Hard RT communication systems serve different purposes and are used in different applications. Soft RT communication system is used in applications that can tolerate small delays, while Hard RT communication system is used in applications where timing constraints are critical. Understanding the differences between these two systems is important for developing real-time systems that meet the required performance criteria.
