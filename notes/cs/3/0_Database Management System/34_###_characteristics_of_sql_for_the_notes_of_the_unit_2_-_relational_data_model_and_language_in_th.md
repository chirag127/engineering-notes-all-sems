### Characteristics of SQL for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

SQL (Structured Query Language) is a standard language for managing relational databases. In the Unit 2 - Relational data Model and Language in the subject of Database Management System, students learn about the relational data model and SQL, the standard language for managing relational databases. The notes for this unit should include the following topics:

1. Definition of SQL (Structured Query Language)
2. Characteristics of SQL (declarative, non-procedural, high-level)
3. Overview of the relational data model (tables, rows, columns, relationships)
4. SQL syntax (data definition, data manipulation, data retrieval, transactions)
5. Techniques for creating and manipulating tables (CREATE, ALTER, DROP, INSERT, UPDATE, DELETE)
6. Techniques for retrieving data from tables (SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY)
7. Overview of transactions (ACID properties, COMMIT, ROLLBACK)
8. Overview of database normalization (1NF, 2NF, 3NF, BCNF)
9. Hands-on practice with programming exercises (creating tables, manipulating data, retrieving data, transactions)
10. Further reading and resources (books, online tutorials, forums)

SQL is a critical component of database management and is used to manage relational databases effectively and efficiently. Understanding the characteristics of SQL and the relational data model helps students to develop the skills required to manage relational databases in a variety of contexts. The hands-on practice and further reading resources will help students to develop their database management skills and deepen their understanding of the material.
