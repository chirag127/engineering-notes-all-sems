### Referential Integrity for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Referential integrity is a property of a database that ensures that relationships between tables are maintained consistently. It is a set of rules that govern the relationships between tables in a database, and it is used to enforce the consistency of data in a database.

Referential integrity is enforced using foreign keys, which are columns in one table that reference the primary key of another table. When referential integrity is enforced, the database management system (DBMS) ensures that the values in the foreign key column match the values in the referenced primary key column.

There are several types of referential integrity constraints, including:

1. Primary Key Constraints: A primary key constraint ensures that the values in a primary key column are unique and not null.

2. Foreign Key Constraints: A foreign key constraint ensures that the values in a foreign key column match the values in the referenced primary key column.

3. Not Null Constraints: A not null constraint ensures that the values in a column are not null.

4. Unique Constraints: A unique constraint ensures that the values in a column are unique.

You will also learn how to enforce referential integrity in a database, and how to use referential integrity to maintain the consistency of data in a database.
