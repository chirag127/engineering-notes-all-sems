### Data Definitions Language for the notes of the Unit 1 - Introduction in the subject of Database Management System

Data Definition Language (DDL) is a subset of SQL (Structured Query Language) used to define the database schema. It is used to create, modify, and delete database objects such as tables, indexes, and views.

In the context of the Unit 1 - Introduction in the subject of Database Management System, the following topics related to DDL may be covered:

1. CREATE: The CREATE statement is used to create a new database object, such as a table, index, or view. Students will learn how to specify the columns, data types, and constraints for a table, and how to create an index or view.

2. ALTER: The ALTER statement is used to modify an existing database object. Students will learn how to add, modify, or delete columns from a table, and how to modify the constraints and indexes associated with a table.

3. DROP: The DROP statement is used to delete a database object. Students will learn how to remove a table, index, or view from the database.

4. TRUNCATE: The TRUNCATE statement is used to delete all data from a table, but leave the table structure intact. Students will learn how to use this statement to quickly remove all data from a table.

5. RENAME: The RENAME statement is used to change the name of a database object. Students will learn how to use this statement to change the name of a table, index, or view.

6. Constraints: Students will learn about the different types of constraints, including primary key, foreign key, and unique constraints, and how to use these constraints to enforce data integrity in the database.

By the end of the Unit 1 - Introduction in the subject of Database Management System, students will have a solid understanding of the DDL commands and how to use them to define and modify database objects.
