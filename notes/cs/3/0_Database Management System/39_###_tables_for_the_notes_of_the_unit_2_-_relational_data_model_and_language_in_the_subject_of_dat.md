### Tables for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Unit 2 of the Database Management System course focuses on the Relational Data Model and Language, including the aspect of tables.

In a relational database, data is organized into tables, which are similar to spreadsheets. Each table consists of rows and columns, where each row represents a single record and each column represents a field or attribute of the record.

Tables in a relational database are related to each other through relationships, which are defined using keys. A key is a field or combination of fields that uniquely identifies a record in a table. There are two main types of keys in a relational database: primary keys and foreign keys. A primary key is a unique identifier for a record in a table, and a foreign key is a reference to the primary key of another table.

In the context of the Database Management System course, students in Unit 2 will learn about tables in the context of the relational data model. They will learn about the structure and organization of tables, including the use of keys to define relationships between tables. They will also have hands-on experiences working with tables in a relational database, including creating and modifying tables, and querying data from tables.

In summary, Unit 2 of the Database Management System course focuses on the Relational Data Model and Language, and includes a discussion of tables. In a relational database, data is organized into tables, which consist of rows and columns, and are related to each other through relationships defined using keys. Students will learn about tables, including their structure and organization, and will have hands-on experiences working with tables in a relational database.
