### SQL Operators and Their Procedure for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

The unit 2 of the Database Management System subject focuses on the Relational Data Model and Language, including SQL Operators and their procedures.

SQL Operators:
1. Arithmetic Operators: These operators perform arithmetic operations such as addition, subtraction, multiplication, and division. (+, -, *, /)

2. Comparison Operators: These operators compare values and return a Boolean result indicating whether the comparison is true or false. (> , <, >=, <=, =, <>)

3. Logical Operators: These operators evaluate logical expressions and return a Boolean result indicating whether the expression is true or false. (AND, OR, NOT)

4. Set Operators: These operators combine the results of two or more SELECT statements into a single result set. (UNION, UNION ALL, INTERSECT, MINUS)

Procedure:
1. Write a SELECT statement to retrieve the data you want to work with.

2. Use the appropriate operator to modify the data in the SELECT statement.

3. Execute the SELECT statement to display the results.

Examples:
1. Using Arithmetic Operators: SELECT column1 + column2 FROM table_name;

2. Using Comparison Operators: SELECT column1, column2 FROM table_name WHERE column1 > column2;

3. Using Logical Operators: SELECT column1, column2 FROM table_name WHERE column1 > column2 AND column1 < 100;

4. Using Set Operators: SELECT column1, column2 FROM table1 UNION SELECT column1, column2 FROM table2;

By the end of the unit, students should have a good understanding of the different SQL operators and how to use them in a SELECT statement to modify and retrieve data from a relational database.
