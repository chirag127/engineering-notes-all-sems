### Types of SQL Commands for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

SQL (Structured Query Language) is a language used to interact with relational databases. There are several types of SQL commands, each with a specific purpose. Here are some of the most common types of SQL commands:

1. Data Definition Language (DDL) commands: These commands are used to define the structure of a database, including creating, altering, and dropping tables and other database objects. Examples of DDL commands include CREATE TABLE, ALTER TABLE, and DROP TABLE.

2. Data Manipulation Language (DML) commands: These commands are used to manipulate data within a database, including inserting, updating, and deleting data. Examples of DML commands include INSERT INTO, UPDATE, and DELETE.

3. Data Control Language (DCL) commands: These commands are used to control access to a database, including granting and revoking permissions to users. Examples of DCL commands include GRANT and REVOKE.

4. Data Query Language (DQL) commands: These commands are used to retrieve data from a database, including selecting data from one or more tables. Examples of DQL commands include SELECT and JOIN.

5. Data Transaction Management commands: These commands are used to manage transactions, including committing and rolling back changes to the database. Examples of transaction management commands include COMMIT and ROLLBACK.

By understanding these different types of SQL commands, students will be able to effectively interact with relational databases and manipulate data within them. This knowledge is essential for anyone studying database management systems.
