### Minus for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Minus is an operation in relational databases that is used to subtract one relation from another relation. The result of the minus operation is a new relation that contains only the tuples that are in the first relation but not in the second relation.

The minus operation is used to perform set-difference operations on relational databases. It is used to remove tuples from one relation that are present in another relation. The syntax of the minus operation in SQL is `MINUS`.

In this unit, you will learn about the minus operation and its use in relational databases. You will also learn about the various relational operations, including union, intersection, and difference, and explore the use of these operations in database management. This will provide a foundation for understanding the principles and practices of relational databases, and for exploring the various concepts and techniques used in database management systems.
