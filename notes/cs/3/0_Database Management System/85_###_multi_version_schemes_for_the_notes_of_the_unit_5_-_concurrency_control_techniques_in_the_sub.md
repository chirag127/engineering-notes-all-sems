### Multi Version Schemes for the notes of the Unit 5 - Concurrency Control Techniques in the subject of Database Management System

Unit 5 of the Database Management System course focuses on Concurrency Control Techniques, including the aspect of Multi-Version Schemes.

Multi-Version Schemes are a type of concurrency control technique that are used to manage concurrent access to data in a database. In a multi-version scheme, multiple versions of a database record are maintained, each version representing a different state of the record at a different point in time.

Multi-Version Schemes are used to ensure that concurrent access to data in a database is managed efficiently, and to avoid conflicts between transactions that are accessing the same data. By maintaining multiple versions of a database record, multi-version schemes allow transactions to access and modify data without blocking other transactions, and without the need for locks or other synchronization mechanisms.

In the context of the Database Management System course, students in Unit 5 will learn about multi-version schemes as part of the discussion on Concurrency Control Techniques. This may include working with examples of multi-version schemes, analyzing the benefits and limitations of multi-version schemes, and learning how to design and implement multi-version schemes in a database.
