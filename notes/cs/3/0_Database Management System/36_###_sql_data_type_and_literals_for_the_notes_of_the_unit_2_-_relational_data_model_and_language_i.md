### SQl Data Type and Literals for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

SQL data types and literals are important concepts in the relational data model and language. They are used to specify the type of data that can be stored in a database, and to represent data values in SQL statements.

1. SQL Data Types: SQL provides several built-in data types for specifying the type of data that can be stored in a database. Some of the most common data types in SQL include:
  - INTEGER: Used to store integer values
  - CHAR: Used to store character strings of a fixed length
  - VARCHAR: Used to store character strings of a variable length
  - DATE: Used to store date and time values
  - NUMERIC: Used to store numeric values with a specified precision and scale

2. SQL Literals: SQL literals are used to represent data values in SQL statements. There are several types of literals in SQL, including:
  - Numeric literals: Used to represent numeric values, such as integers and decimals
  - String literals: Used to represent character strings, such as names and addresses
  - Date and time literals: Used to represent date and time values, such as birthdates and appointment times

In this unit, you will learn about SQL data types and literals, including the syntax, usage, and examples. You will also learn how to use SQL data types and literals to create and manipulate data in a relational database. This will provide a foundation for understanding the principles and practices of database management systems, and for exploring the various concepts and techniques used in database management.
