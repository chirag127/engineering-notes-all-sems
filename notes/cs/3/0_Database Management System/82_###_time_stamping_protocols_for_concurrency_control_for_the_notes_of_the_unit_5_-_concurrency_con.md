### Time Stamping Protocols for Concurrency Control for the notes of the Unit 5 - Concurrency Control Techniques in the subject of Database Management System

Time stamping protocols are a type of concurrency control technique used in database management systems to ensure that transactions are executed in a consistent and conflict-free manner.

Time stamping protocols assign a unique time stamp to each transaction, and transactions are executed in the order of their time stamps. This ensures that transactions are executed in a consistent and conflict-free manner, and it eliminates the need for locks, which can cause performance problems in a database system.

There are several types of time stamping protocols, including:

1. Thomas' Write Rule: This protocol assigns a time stamp to each transaction when it begins, and transactions are executed in the order of their time stamps.

2. Timestamp Ordering Protocol (TOP): This protocol assigns a unique time stamp to each transaction, and transactions are executed in the order of their time stamps.

3. Serializability with Timestamps (SWT): This protocol assigns a unique time stamp to each transaction, and transactions are executed in the order of their time stamps.
