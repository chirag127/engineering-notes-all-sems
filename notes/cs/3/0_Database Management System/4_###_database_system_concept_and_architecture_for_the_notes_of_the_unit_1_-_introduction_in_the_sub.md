### Database System Concept and Architecture for the notes of the Unit 1 - Introduction in the subject of Database Management System

Database System Concepts and Architecture is the first unit of the subject of Database Management System. It provides an overview of the fundamental concepts and architecture of database systems. 

In this unit, students will learn about: 

1. Database Systems: Definition, purpose, and types of database systems, including relational, object-oriented, and NoSQL databases.

2. Data Models: Overview of the different types of data models, including entity-relationship, relational, and object-oriented data models.

3. Data Abstraction: Explanation of data abstraction and its importance in database systems.

4. Data Independence: Explanation of data independence and its benefits in database systems.

5. Database Architecture: Overview of the three-tier architecture of database systems, including the presentation layer, application layer, and database layer.

6. Database Management System (DBMS): Definition and functions of a DBMS, including data definition, data manipulation, and data control.

7. Database Languages: Overview of the different database languages, including SQL, DDL, DML, and DCL.

By the end of this unit, students will have a foundational understanding of the concepts and architecture of database systems, and will be able to apply this knowledge in future units of the subject.
