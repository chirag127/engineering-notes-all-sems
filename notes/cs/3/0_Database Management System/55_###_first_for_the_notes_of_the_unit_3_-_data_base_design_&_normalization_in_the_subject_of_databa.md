### first for the notes of the Unit 3 - Data Base Design & Normalization in the subject of Database Management System

First normal form (1NF) is a property of a relational database table that ensures that each column contains only atomic values, and that there is no repeating group of data in a single column. Atomic values are indivisible and cannot be further decomposed.

1NF is achieved by creating a separate table for each repeating group of data, and by ensuring that each column in a table contains only atomic values. This results in a table with a simple and well-defined structure, and eliminates data redundancy, which is a major source of data inconsistencies and errors.

In this unit, you will learn about first normal form and its importance in database design and normalization. You will also learn about the process of normalizing a database, including the steps involved in transforming a table into first normal form. This will provide a foundation for understanding the principles and practices of database design and normalization, and for exploring the various concepts and techniques used in database management systems.
