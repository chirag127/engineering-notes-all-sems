### Keys for the notes of the Unit 1 - Introduction

- A database is a collection of related data that is organized and stored in a structured way.
- A database management system (DBMS) is a software system that allows users to create, manipulate, and access databases.
- A DBMS consists of three components: data, data dictionary, and database engine.
- Data is the actual information stored in the database, such as tables, records, and fields.
- Data dictionary is a set of metadata that describes the structure, format, and constraints of the data in the database.
- Database engine is the core component that performs the operations on the data, such as query processing, transaction management, concurrency control, and recovery.
- A DBMS can be classified into different types based on the data model, the level of abstraction, and the distribution of data.
- A data model is a set of concepts and rules that define how the data is structured and manipulated in a database.
- The most common data models are hierarchical, network, relational, object-oriented, and NoSQL.
- A level of abstraction is a view of the data that hides some details and shows only the relevant information for a specific purpose.
- The three levels of abstraction are physical, logical, and external.
- The physical level describes how the data is physically stored and accessed in the database.
- The logical level describes what data is stored in the database and the relationships among the data.
- The external level describes how the data is viewed by different users and applications.
- A distribution of data is the way the data is distributed and replicated across multiple sites or nodes in a network.
- A distributed database is a database that consists of two or more logically interrelated databases that are physically distributed over a network.
- A distributed DBMS is a DBMS that manages a distributed database and provides transparent access and coordination of the data.
- The advantages of a distributed database are improved performance, availability, reliability, scalability, and autonomy.
- The challenges of a distributed database are data fragmentation, data replication, data allocation, query processing, transaction management, concurrency control, and recovery.
