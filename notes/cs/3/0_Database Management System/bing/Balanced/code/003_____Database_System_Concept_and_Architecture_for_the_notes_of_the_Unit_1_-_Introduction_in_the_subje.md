### Database System Concept and Architecture

- A database is a collection of related data that represents some aspect of the real world.
- A database system is a software system that enables users to define, create, maintain, and manipulate databases.
- A database system consists of four main components: data, hardware, software, and users.
- Data is the raw material of the database system. It is stored in a structured format that conforms to a data model.
- Hardware is the physical device that hosts the database system and provides the resources for data storage, processing, and communication.
- Software is the set of programs that manage the database and provide the interface between the users and the data.
- Users are the people who interact with the database system for various purposes, such as querying, updating, analyzing, or designing data.
- A database system can be classified into different types based on the data model, the level of abstraction, the distribution, and the usage.
- The data model is the logical structure and organization of the data in the database. It defines the data types, the relationships, the constraints, and the operations on the data.
- The most common data models are the relational model, the hierarchical model, the network model, the object-oriented model, and the semi-structured model.
- The level of abstraction is the degree of detail and complexity that is hidden from the users of the database system. It defines the view of the data that is presented to the users.
- The three levels of abstraction are the physical level, the logical level, and the view level.
- The physical level is the lowest level of abstraction that describes how the data is physically stored and accessed in the hardware.
- The logical level is the middle level of abstraction that describes what data is stored in the database and what relationships exist among the data.
- The view level is the highest level of abstraction that describes how the data is seen by different users or applications.
- The distribution is the degree of physical separation and logical interconnection of the data and the database system components.
- A database system can be centralized, distributed, or parallel.
- A centralized database system is a single system that stores and manages the entire database at one location.
- A distributed database system is a system that consists of multiple database systems that are connected by a network and share data and resources.
- A parallel database system is a system that uses multiple processors and disks to perform database operations in parallel.
- The usage is the purpose and function of the database system for the users and the applications.
- A database system can be operational, analytical, or hybrid.
- An operational database system is a system that supports the day-to-day transactions and operations of an organization, such as sales, inventory, or payroll.
- An analytical database system is a system that supports the decision making and analysis of an organization, such as business intelligence, data mining, or data warehousing.
- A hybrid database system is a system that combines the features and functions of both operational and analytical database systems.
