### SQL Data Type and Literals

- SQL data types are the attributes that define the kind of data that can be stored in a column of a table or a variable in a program.
- SQL data types can be categorized into four groups: numeric, character, date and time, and boolean.
- SQL literals are the constant values that can be assigned to a column of a table or a variable in a program.
- SQL literals can be of different types, such as numeric, character, date and time, boolean, and null.

#### Numeric Data Types and Literals

- Numeric data types are used to store numbers, such as integers, decimals, and fractions.
- Numeric data types can be further classified into exact and approximate numeric data types.
- Exact numeric data types are used to store numbers with a fixed precision and scale, such as integers and decimals. Examples of exact numeric data types are INT, SMALLINT, BIGINT, DECIMAL, and NUMERIC.
- Approximate numeric data types are used to store numbers with a floating-point precision and scale, such as fractions and scientific notation. Examples of approximate numeric data types are FLOAT, REAL, and DOUBLE PRECISION.
- Numeric literals are the constant values that can be assigned to a numeric data type. Numeric literals can be written in decimal, hexadecimal, or scientific notation. Examples of numeric literals are 42, 3.14, 0x2A, and 1.23E4.

#### Character Data Types and Literals

- Character data types are used to store text, such as letters, symbols, and spaces.
- Character data types can be further classified into fixed-length and variable-length character data types.
- Fixed-length character data types are used to store text with a fixed number of characters, such as codes and abbreviations. Examples of fixed-length character data types are CHAR and NCHAR.
- Variable-length character data types are used to store text with a variable number of characters, such as names and descriptions. Examples of variable-length character data types are VARCHAR, NVARCHAR, TEXT, and CLOB.
- Character literals are the constant values that can be assigned to a character data type. Character literals are enclosed in single quotes or double quotes. Examples of character literals are 'Hello', "World", and 'SQL'.

#### Date and Time Data Types and Literals

- Date and time data types are used to store dates and times, such as years, months, days, hours, minutes, and seconds.
- Date and time data types can be further classified into date-only, time-only, and date-time data types.
- Date-only data types are used to store dates without time, such as birthdays and anniversaries. Examples of date-only data types are DATE and YEAR.
- Time-only data types are used to store times without date, such as durations and intervals. Examples of time-only data types are TIME and SECOND.
- Date-time data types are used to store dates and times together, such as events and appointments. Examples of date-time data types are DATETIME, TIMESTAMP, and INTERVAL.
- Date and time literals are the constant values that can be assigned to a date and time data type. Date and time literals are written in a standard format, such as YYYY-MM-DD for date and HH:MM:SS for time. Examples of date and time literals are '2023-03-15' for date and '20:08:10' for time.

#### Boolean Data Types and Literals

- Boolean data types are used to store logical values, such as true and false.
- Boolean data types can be further classified into bit and boolean data types.
- Bit data types are used to store binary values, such as 0 and 1. Examples of bit data types are BIT and BIT VARYING.
- Boolean data types are used to store boolean values, such as TRUE and FALSE. Examples of boolean data types are BOOLEAN and BOOL.
- Boolean literals are the constant values that can be assigned to a boolean data type. Boolean literals are written as TRUE, FALSE, or NULL. Examples of boolean literals are TRUE, FALSE, and NULL.

#### Null Data Types and Literals

- Null data types are used to store unknown or missing values, such as no answer or not applicable.
- Null data types can be assigned to any other data type, such as numeric, character, date and time, or boolean.
- Null literals are the constant values that can be assigned to a null data type. Null literals are written as NULL
