### Advantage of SQL for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

- SQL is a standard language for accessing and manipulating data in relational databases.
- SQL is widely supported by various database management systems, such as Oracle, MySQL, PostgreSQL, SQL Server, etc.
- SQL is easy to learn and use, as it has a simple and intuitive syntax and a rich set of commands and functions.
- SQL is flexible and expressive, as it can perform various operations on data, such as querying, inserting, updating, deleting, creating, altering, etc.
- SQL is powerful and efficient, as it can handle large and complex data sets, perform calculations and aggregations, join and combine data from multiple tables, etc.
- SQL is secure and reliable, as it supports various features to protect data integrity and consistency, such as transactions, constraints, triggers, views, etc.
