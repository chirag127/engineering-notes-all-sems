### Overview for the notes of the Unit 1 - Introduction in the subject of Database Management System

- A database is a collection of related data that can be stored, manipulated, and retrieved by a computer system.
- A database management system (DBMS) is a software system that provides the functionality to create, maintain, and access databases.
- A DBMS consists of three components: data, data dictionary, and database engine.
- Data is the actual information stored in the database, such as names, addresses, phone numbers, etc.
- Data dictionary is a set of metadata that describes the structure, format, and constraints of the data in the database.
- Database engine is the core component that performs the operations on the data, such as insertion, deletion, modification, retrieval, and query processing.
- A DBMS can be classified into different types based on various criteria, such as data model, user interface, and architecture.
- Data model is a logical representation of the data and the relationships among them. Some common data models are hierarchical, network, relational, object-oriented, and NoSQL.
- User interface is the mode of interaction between the user and the DBMS. Some common user interfaces are menu-driven, form-based, graphical, and natural language.
- Architecture is the way the DBMS components are organized and distributed. Some common architectures are centralized, client-server, and cloud-based.
- A DBMS can provide various benefits, such as data independence, data integrity, data security, data consistency, data sharing, and data abstraction.
- Data independence is the ability to change the physical or logical structure of the data without affecting the applications that use the data.
- Data integrity is the property that ensures the accuracy and validity of the data in the database.
- Data security is the property that protects the data from unauthorized access, modification, or deletion.
- Data consistency is the property that ensures that the data in the database is coherent and does not contain any contradictions or anomalies.
- Data sharing is the property that allows multiple users and applications to access and manipulate the data in the database concurrently.
- Data abstraction is the property that hides the details of the data storage and manipulation from the user and provides a conceptual view of the data.
