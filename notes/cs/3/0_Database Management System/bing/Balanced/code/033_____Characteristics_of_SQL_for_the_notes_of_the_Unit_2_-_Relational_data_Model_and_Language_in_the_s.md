### Characteristics of SQL

- SQL stands for Structured Query Language. It is a standard language for defining, manipulating, and querying data in relational databases.
- SQL is declarative, meaning that it specifies what data to retrieve or modify, not how to do it. The database management system (DBMS) is responsible for translating SQL statements into low-level operations.
- SQL is based on relational algebra and calculus, which are formal mathematical models for manipulating relations (tables) and tuples (rows) of data.
- SQL is a high-level language, meaning that it abstracts away the details of data storage and retrieval, such as file structures, indexes, and physical devices. The DBMS handles these details internally.
- SQL is a set-oriented language, meaning that it operates on sets (collections) of data, rather than individual records. SQL statements can apply functions, filters, joins, and aggregations to entire sets of data at once.
- SQL is a comprehensive language, meaning that it supports a wide range of data manipulation and query operations, such as creating, updating, deleting, and querying data, as well as defining data structures, constraints, views, and indexes.
- SQL is a standardized language, meaning that it follows a set of rules and syntax defined by international standards organizations, such as ANSI and ISO. However, different DBMSs may implement different versions or extensions of SQL, which may not be compatible with each other.
