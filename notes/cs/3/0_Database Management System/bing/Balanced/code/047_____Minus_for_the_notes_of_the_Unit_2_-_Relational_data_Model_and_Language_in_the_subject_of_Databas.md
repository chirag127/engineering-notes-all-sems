### Relational data Model and Language

- A relational data model is a way of representing data using tables, where each table consists of rows and columns.
- Each row in a table is called a tuple, and each column is called an attribute. A tuple represents an entity or a relationship, and an attribute represents a property or a role of an entity or a relationship.
- A table is also called a relation, and it has a name and a schema. A schema defines the name and the data type of each attribute in the table.
- A relational database is a collection of tables that are related to each other by some constraints, such as primary keys, foreign keys, and referential integrity.
- A primary key is a set of one or more attributes that uniquely identifies each tuple in a table. A primary key cannot have null values or duplicate values.
- A foreign key is a set of one or more attributes in a table that references the primary key of another table. A foreign key establishes a relationship between two tables, and it enforces referential integrity, which means that every value in the foreign key must match an existing value in the referenced primary key.
- A relational data language is a way of manipulating and querying data in a relational database. There are two types of relational data languages: relational algebra and relational calculus.
- Relational algebra is a procedural language that uses operators to perform operations on tables, such as selection, projection, join, union, intersection, difference, and division. Relational algebra operators can be combined to form complex expressions that specify the desired result of a query.
- Relational calculus is a declarative language that uses variables and predicates to specify the conditions that the desired result of a query must satisfy. Relational calculus does not specify how to obtain the result, but only what the result should be. There are two forms of relational calculus: tuple relational calculus and domain relational calculus.
