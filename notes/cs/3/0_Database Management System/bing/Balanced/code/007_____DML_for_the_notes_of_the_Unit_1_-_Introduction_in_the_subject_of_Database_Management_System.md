### DML

DML stands for Data Manipulation Language. It is a family of computer languages that are used to manipulate data in a database. DML includes commands that allow users to:

- Insert data into database tables
- Retrieve data from database tables
- Delete data from database tables
- Update data in database tables

Some of the most common DML statements are:

- SELECT: This statement is used to query data from one or more tables or views. It can also be used to perform calculations, join tables, filter data, group data, and sort data.
- INSERT: This statement is used to add new rows of data to a table. It can also be used to copy data from another table or query.
- DELETE: This statement is used to remove rows of data from a table. It can also be used with a WHERE clause to specify which rows to delete.
- UPDATE: This statement is used to modify existing rows of data in a table. It can also be used with a WHERE clause to specify which rows to update.

DML is a subset of SQL, which is the most widely used language for relational databases. DML mainly focuses on the data itself, rather than the structure or schema of the database. DML can also be used to trigger actions or events when data is manipulated, such as logging, auditing, or enforcing business rules. DML triggers are a special type of stored procedure that automatically execute when a DML statement affects a table or view.
