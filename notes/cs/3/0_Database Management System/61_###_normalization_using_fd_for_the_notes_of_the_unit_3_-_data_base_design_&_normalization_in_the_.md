### normalization using FD for the notes of the Unit 3 - Data Base Design & Normalization in the subject of Database Management System

Normalization using functional dependencies (FDs) is a process used to eliminate redundancy and improve the efficiency of a relational database. FDs are relationships between attributes in a table that describe the dependencies between them.

The normalization process using FDs involves identifying the FDs in a table, and using them to determine the appropriate structure of the table. This involves breaking down a table into smaller, simpler tables that are in higher normal forms, such as second normal form (2NF) and third normal form (3NF).

The goal of normalization using FDs is to eliminate data redundancy and improve the efficiency of a relational database. This is accomplished by removing data that is redundant or unnecessary, and by ensuring that the data in a database is stored in a simple, well-structured format.

In this unit, you will learn about normalization using FDs, including the process of identifying FDs and using them to normalize a database. You will also learn about the various normal forms, including first normal form (1NF), second normal form (2NF), and third normal form (3NF), and explore the use of normalization in database design and implementation. This will provide a foundation for understanding the principles and practices of database design and normalization, and for exploring the various concepts and techniques used in database management systems.
