
### DML for the notes of the Unit 1 - Introduction in the subject of Database Management System

1. Data Manipulation Language (DML) is a set of commands used to manipulate data in a database.

2. DML commands are used to perform operations such as inserting, deleting, and updating data.

3. DML commands are divided into two types: procedural and non-procedural.

4. Procedural DML requires the user to specify the exact steps for manipulating data. Examples include SQL (Structured Query Language) and PL/SQL (Procedural Language/Structured Query Language).

5. Non-procedural DML does not require the user to specify the exact steps for manipulating data. Examples include QBE (Query By Example) and OQL (Object Query Language).

6. Data manipulation operations can be divided into four categories: selection, projection, join, and aggregation.

7. Selection is the process of retrieving data from a database based on certain criteria.

8. Projection is the process of retrieving only certain columns from a database table.

9. Join is the process of combining two or more tables based on a common column.

10. Aggregation is the process of grouping data and performing calculations on the grouped data. Examples include SUM, AVG, and COUNT.
