
### Data Independence and Database Language and Interfaces

* Data Independence is the ability of a database system to make changes to the structure of the database without affecting the data stored in the database.
* Database languages are used to interact with a database, such as Structured Query Language (SQL).
* Database interfaces are used to access and manipulate data stored in the database, such as web-based graphical user interfaces.
* Database Management Systems (DBMS) provide a way to store and manage data. They have features such as data security, data integrity, and data recovery.
* DBMSs provide a way to query the data stored in the database, as well as to create and modify data in the database.
