
### Distributed Database for the notes of the Unit 4 - Transaction Processing Concept in the subject of Database Management System

- A distributed database is a type of database that is spread across multiple nodes, or locations, and is managed by a distributed database management system (DDBMS). 
- The nodes in a distributed database are connected by a network, allowing for the sharing of data and resources. 
- The DDBMS is responsible for managing the data stored in the distributed database, as well as providing access to the data for applications and users. 
- In a distributed database, data is stored across multiple nodes, which may be located in different locations. 
- Each node in the distributed database is responsible for managing its own data, and the data is replicated across multiple nodes for redundancy and fault tolerance. 
- The nodes in the distributed database are connected by a network, allowing for the sharing of data and resources. 
- Transaction processing is a type of database processing in which a series of related database operations are performed as a single unit. 
- Transaction processing ensures that the data in the database remains consistent, even in the event of system failure or power loss. 
- The transaction processing system is responsible for ensuring that all operations in a transaction are completed successfully, or that all changes made to the database are rolled back in the event of a failure. 
- In a distributed database, transaction processing is managed by the DDBMS, which ensures that all operations in a transaction are executed on all nodes simultaneously.
