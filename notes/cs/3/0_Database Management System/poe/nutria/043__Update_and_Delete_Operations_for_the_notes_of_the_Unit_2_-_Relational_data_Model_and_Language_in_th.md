
### Update and Delete Operations for the Notes of the Unit 2 - Relational Data Model and Language in the Subject of Database Management System

* Update Operations: Update operations allow users to modify existing data in a database. This can be done by using the SQL command UPDATE. When using this command, users must specify which table they wish to update, which columns they wish to modify, and what the new values should be.

* Delete Operations: Delete operations allow users to remove existing data from a database. This can be done by using the SQL command DELETE. When using this command, users must specify which table they wish to delete from, and which rows they wish to delete.
