
### SQL Operators and Their Procedure

1. **SELECT**: This operator is used to select data from a database. It is used to retrieve specific columns from one or more tables.

2. **INSERT**: This operator is used to insert new records into a database.

3. **UPDATE**: This operator is used to modify existing records in a database.

4. **DELETE**: This operator is used to delete existing records from a database.

5. **JOIN**: This operator is used to combine records from two or more tables.

6. **UNION**: This operator is used to combine the result set of two or more SELECT statements.

7. **INTERSECT**: This operator is used to return the records that are common to two or more SELECT statements.

8. **EXCEPT**: This operator is used to return the records that are not common to two or more SELECT statements.

9. **RENAME**: This operator is used to rename a table or a column in a table.

10. **CREATE**: This operator is used to create a new table in a database.

11. **ALTER**: This operator is used to modify an existing table in a database.

12. **DROP**: This operator is used to delete an existing table in a database.
