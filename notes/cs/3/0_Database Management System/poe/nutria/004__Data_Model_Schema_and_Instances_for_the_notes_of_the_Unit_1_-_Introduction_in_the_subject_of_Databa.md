
### Data Model Schema and Instances 

1. A data model is a set of concepts used to describe and represent data in a database.
2. A schema is the structure of a database, which describes how data is organized and how it relates to one another.
3. Instances are individual occurrences of data in a database.
4. A relational database is a type of database that stores data in tables and uses relationships between the data for storage and retrieval.
5. A table is a collection of related data, organized into rows and columns.
6. A primary key is a unique identifier for each row in a table.
7. A foreign key is a field in a table that is used to create a relationship between two tables.
8. Normalization is the process of organizing data into tables in a way that minimizes data redundancy and improves data integrity.
9. SQL (Structured Query Language) is a language used to interact with relational databases.
10. A query is a statement used to retrieve data from a database.
