
### Tables for the Notes of the Unit 2 - Relational Data Model and Language in the Subject of Database Management System

1. A relational data model is a way of organizing data in a database, where the data is stored in a collection of tables.
2. A relational database language is a language that is used to interact with a relational database. Examples of relational database languages include Structured Query Language (SQL), MySQL, and Oracle.
3. Tables are the basic structure of a relational database. A table is composed of columns and rows. Each row represents a single record and each column represents a data element.
4. Tables can be related to each other through the use of foreign keys. Foreign keys are used to link two tables together, allowing data from one table to be retrieved from another.
5. Joins are used to combine data from two or more tables. Joins can be used to create new tables or to retrieve data from existing tables.
6. Indexes are used to speed up data retrieval. Indexes are created on columns to make it easier to search for data.
7. Views are used to create virtual tables from existing tables. Views can be used to restrict access to data or to simplify complex queries.
8. Transactions are used to ensure data integrity. Transactions are used to ensure that data is not changed or corrupted during a database operation.
