
### Advantages of SQL for the Notes of the Unit 2 - Relational Data Model and Language in the subject of Database Management System

1. SQL is a powerful, yet simple language that can be used to access and manipulate data in relational databases. 
2. SQL is a standard language that is used by many database systems, making it easier to learn and use.
3. SQL is a declarative language that allows users to express their queries in a concise and consistent way.
4. SQL is a powerful language that can be used to perform complex queries and operations on large datasets.
5. SQL is a safe language that can be used to prevent unauthorized access to data.
6. SQL is a flexible language that can be used to create and modify database objects.
7. SQL is an efficient language that can be used to optimize database performance.
8. SQL is a portable language that can be used to access data from different platforms and databases.
