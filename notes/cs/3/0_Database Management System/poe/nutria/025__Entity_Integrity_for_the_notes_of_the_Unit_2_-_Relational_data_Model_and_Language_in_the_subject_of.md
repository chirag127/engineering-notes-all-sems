
### Entity Integrity 

Entity integrity is a property of relational databases that ensures that each row in a table is unique. This is achieved by assigning a unique identifier (primary key) to each row in the table. Entity integrity requires that the primary key of each row must not be null and that each row must have a unique value for the primary key. 

Entity integrity is an important concept in database management systems as it helps to ensure the accuracy and consistency of data. It also helps to prevent data duplication and accidental data loss.

Entity integrity is closely related to the concept of referential integrity, which ensures that foreign key values in a table are valid. Referential integrity ensures that all foreign key values in a table must either be null or must match a valid primary key value in the referenced table. 

Entity integrity is also related to the concept of data integrity, which ensures that data is accurate and consistent. Data integrity is achieved by using constraints, such as unique constraints, to enforce entity integrity.
