
### Relational Calculus

* Relational calculus is a query language used to query relational databases. 
* It is non-procedural and allows the user to describe what they want, rather than how to get it.
* It is based on predicate logic and allows the user to describe the desired result in terms of variables and predicates.
* Relational calculus is divided into two types: tuple relational calculus and domain relational calculus. 
* Tuple relational calculus uses variables to represent individual tuples in a relation, while domain relational calculus uses variables to represent attributes in a relation.
* Relational calculus is used to express queries in a more intuitive way, allowing the user to focus on the data they want to retrieve, rather than the details of how to retrieve it.
* It is useful for expressing queries that are too complex to be expressed in SQL.
