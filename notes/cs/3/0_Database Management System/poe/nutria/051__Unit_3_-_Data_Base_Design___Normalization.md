
## Unit 3 - Data Base Design & Normalization

* Database design and normalization is the process of creating a structured way of organizing and storing data in a database. 
* Database normalization is the process of organizing data into tables in such a way that the results of using the database are always unambiguous and as intended. 
* Normalization involves decomposing a single table into multiple smaller tables to reduce redundancy and improve data integrity. 
* The goal of normalization is to ensure that the data is organized in a way that minimizes redundancy and facilitates data retrieval. 
* Normalization typically involves dividing large tables into smaller ones and defining relationships between them. 
* The process of normalization typically involves the following steps: 
    1. Identifying the data that needs to be stored in the database. 
    2. Identifying the relationships between the data. 
    3. Determining the best way to organize the data into tables. 
    4. Creating the tables and assigning the data to the appropriate columns. 
    5. Establishing the relationships between the tables. 
    6. Ensuring that the data is consistent and accurate.
