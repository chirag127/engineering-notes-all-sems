
### Tuple and Domain Calculus for the Notes of the Unit 2 - Relational Data Model and Language in the Subject of Database Management System

1. **Tuple Calculus** is a formal language used to query relational databases. It was developed in the 1970s by Edgar F. Codd, the inventor of the relational model. It is a type of non-procedural query language that uses declarative statements to describe the desired result.

2. **Domain Calculus** is a formal language used to describe the structure of a relational database. It was developed in the 1970s by Edgar F. Codd, the inventor of the relational model. It is a type of procedural query language that uses operations to describe the desired result.

3. A **relation** is a two-dimensional table of values in which each row represents a single entity and each column represents an attribute of that entity. A relation is also known as a table or a relation schema.

4. A **tuple** is a single row in a relation. It is a collection of values that represent an entity. Each value in the tuple represents an attribute of the entity.

5. **Relational algebra** is a set of operations used to query a relational database. It is a type of procedural query language that uses operations to describe the desired result.

6. **Relational calculus** is a formal language used to query relational databases. It is a type of non-procedural query language that uses declarative statements to describe the desired result.
