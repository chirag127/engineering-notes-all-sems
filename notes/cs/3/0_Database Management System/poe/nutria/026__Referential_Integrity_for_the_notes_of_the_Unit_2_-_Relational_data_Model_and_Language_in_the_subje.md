
### Referential Integrity 

Referential integrity is an important concept in database management systems. It is a set of rules that ensure the accuracy and consistency of data in a relational database. It is based on the idea that every value in a foreign key column must match a value in the primary key column of another table. In this way, referential integrity helps to prevent orphan records and ensure data accuracy.

- Referential integrity ensures that the data in a relational database is accurate and consistent.
- It is based on the idea that every value in a foreign key column must match a value in the primary key column of another table.
- Referential integrity helps to prevent orphan records and ensures data accuracy.
- It is important to maintain referential integrity when making changes to the structure of a database.
- Referential integrity is enforced by using constraints such as foreign keys and primary keys.
