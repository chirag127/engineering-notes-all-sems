
### Keys Constraints for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

1. Primary Key: A primary key is a field or combination of fields which uniquely identifies a record in a table. It cannot contain null values and must be unique.

2. Foreign Key: A foreign key is a field or combination of fields which references a primary key in another table. It is used to establish a relationship between two tables.

3. Composite Key: A composite key is a combination of two or more fields which together form a primary key. It is used to uniquely identify a record in a table.

4. Unique Key: A unique key is a field or combination of fields which can contain null values but must be unique. It is used to ensure that there are no duplicate records in a table.

5. Referential Integrity: Referential integrity ensures that a foreign key value always references a valid primary key value in another table. It is used to maintain the consistency of data in a database.

6. Cascade Update: Cascade update is a feature of a database management system which propagates changes to a foreign key value to the related records in other tables.

7. Cascade Delete: Cascade delete is a feature of a database management system which deletes related records in other tables when a record in the primary table is deleted.
