
### Views and Indexes

* A **view** is a virtual table that is created from one or more tables in a database. It is a subset of the data contained in the underlying tables and can be used to simplify complex queries. 

* An **index** is a data structure that is used to speed up the retrieval of data from a database. It is a collection of pointers to the data and is used to reduce the time taken to search for a particular record. 

* Views can be used to restrict access to certain data in a database. They can be used to hide the complexity of the underlying tables and simplify the data retrieval process.

* Indexes can be used to improve the performance of queries by reducing the amount of data that needs to be searched. They can also be used to enforce uniqueness constraints on data.

* Views and indexes can be used together to improve the performance of queries. Views can be used to restrict access to certain data and indexes can be used to speed up the retrieval of data.
