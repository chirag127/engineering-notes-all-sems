
### Generalization for the notes of the Unit 1 - Introduction in the subject of Database Management System

* Database Management System (DBMS) is a software application that is used to create, maintain and manage a database.
* A database is a collection of data that is stored in a structured form.
* A database can be used to store any type of data such as text, images, documents, audio, and video.
* The DBMS provides a user-friendly interface to interact with the database.
* It also provides tools to perform various operations on the data such as searching, sorting, and filtering.
* The DBMS also provides security features to protect the data from unauthorized access.
* It also provides features to backup the data in case of a system crash or power failure.
