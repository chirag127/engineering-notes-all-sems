
### Triggers for the Notes of the Unit 2 - Relational Data Model and Language in the Database Management System

1. Triggers are stored programs that are executed automatically when a specific event occurs. 
2. They are used to maintain the integrity of the database by performing tasks such as updating related data items and enforcing business rules. 
3. Triggers can be used to check the data before it is inserted, updated or deleted from the database. 
4. A trigger can be either a stored procedure or an SQL statement. 
5. Triggers are associated with a table and are executed when a specific event occurs on that table. 
6. Triggers can be used to enforce business rules, such as ensuring that only valid data is entered into the database. 
7. Triggers can also be used to perform data auditing, such as logging changes to the data. 
8. Triggers can also be used to perform complex calculations, such as calculating the total cost of an order. 
9. Triggers can also be used to ensure data integrity, such as ensuring that the data in related tables is consistent. 
10. Triggers can also be used to perform automated tasks, such as sending an email when a certain event occurs.
