
### Queries and Sub Queries for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

1. A query is a request for data or information from a database table or combination of tables.
2. A query can specify criteria to select particular records, calculations to be performed, or other operations to be performed on the data before the results are returned.
3. A query language is a computer language used to make queries into databases or data repositories.
4. SQL (Structured Query Language) is the standard language for relational database management systems.
5. Subqueries are queries within other queries.
6. Subqueries can be used to select data from multiple tables in a single query.
7. Subqueries can also be used to compare values from two different tables.
8. Subqueries can also be used to modify data in a table based on the results of another query.
