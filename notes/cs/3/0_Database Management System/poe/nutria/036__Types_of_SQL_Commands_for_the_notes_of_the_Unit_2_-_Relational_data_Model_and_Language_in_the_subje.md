
### Types of SQL Commands 
1. **SELECT**: Used to select data from a database.
2. **UPDATE**: Used to update existing data in a database.
3. **DELETE**: Used to delete records from a database.
4. **INSERT**: Used to insert new records into a database.
5. **CREATE**: Used to create new tables and databases.
6. **ALTER**: Used to modify existing tables and databases.
7. **DROP**: Used to delete tables and databases.
8. **TRUNCATE**: Used to remove all records from a table.
9. **COMMIT**: Used to save changes to the database.
10. **ROLLBACK**: Used to undo changes to the database.
