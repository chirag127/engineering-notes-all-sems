
## Unit 2 - Relational Data Model and Language

1. A relational data model is a way of organizing data and representing relationships between different elements of the data. It is based on the concept of a relational database, which is a collection of related tables that store data in a structured format.

2. A relational language is a language used to manipulate and query data in a relational database. The most common relational language is Structured Query Language (SQL).

3. The relational data model is based on the mathematical concept of a relation, which is a set of tuples (rows) that have a specific set of attributes (columns). Each tuple represents a single entity, such as a customer or an order.

4. The relational data model is used to represent relationships between different entities in the data. This is done by creating tables that contain columns for each entity and rows that represent the relationships between them.

5. SQL is the most commonly used language for manipulating and querying data in a relational database. It is a powerful language that allows users to create, update, delete, and query data in a database.

6. SQL commands are used to create and modify tables, insert and delete data, query data, and perform other operations on a database. SQL is a powerful language that is used to create complex queries and perform advanced operations on data.
