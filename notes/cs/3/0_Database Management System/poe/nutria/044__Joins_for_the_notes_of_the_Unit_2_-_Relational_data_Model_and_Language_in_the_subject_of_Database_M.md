
### Joins for the Notes of Unit 2 - Relational Data Model and Language in Database Management System

1. A join is a query that combines rows from two or more tables, views, or materialized views.
2. Joins are typically used to retrieve data from multiple tables in a single query, which can improve the performance of the query.
3. The type of join used will depend on the data being retrieved and the desired result. 
4. The most common types of joins are inner joins, outer joins, left joins, and right joins.
5. Inner joins are used to combine rows from two tables where there is a match in the specified columns.
6. Outer joins are used to combine rows from two tables even if there is no match in the specified columns.
7. Left joins are used to combine all rows from the left table with the matching rows from the right table.
8. Right joins are used to combine all rows from the right table with the matching rows from the left table.
9. Joins can also be used to combine data from multiple tables into a single result set.
10. The SQL language provides a number of clauses and operators that can be used to construct joins.
