

### Procedures in SQL/PL SQL

1. Procedures are stored programs that are used to perform specific tasks. 
2. Procedures can be written in either SQL or PL/SQL. 
3. SQL procedures are written using the CREATE PROCEDURE statement. 
4. PL/SQL procedures are written using the BEGIN and END keywords. 
5. Procedures can accept parameters and return values. 
6. Procedures can be used to encapsulate business logic and reduce the complexity of SQL statements. 
7. Procedures can be used to perform calculations, such as summing or averaging a set of values. 
8. Procedures can be used to perform complex data manipulation tasks, such as sorting or filtering data. 
9. Procedures can be used to control the flow of data in an application. 
10. Procedures can be used to enforce security and data integrity rules.
