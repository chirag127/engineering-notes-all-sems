
### Overall Database Structure for the Unit 1 - Introduction in Database Management System

1. A database is an organized collection of data that is stored in a computer system. It is typically used to store information that can be accessed, managed and updated by multiple users. 
2. Database management systems (DBMSs) are software programs that allow users to create and manage databases. They provide an interface for users to interact with the data in the database.
3. A relational database is a type of database that stores data in tables that are related to one another. Each table contains a set of columns and rows, with each column representing a field and each row representing a record. 
4. Structured Query Language (SQL) is a programming language used to interact with relational databases. It is used to create, update and delete data in the database.
5. Data normalization is a process used to reduce redundancy and improve the integrity of the data in a database. It involves organizing the data into separate tables and ensuring that each table contains only related data. 
6. A database schema is a visual representation of the structure of a database. It is typically used to document the design of a database and to provide a blueprint for creating the database. 
7. Database security is the process of protecting a database from unauthorized access and use. It involves implementing measures such as authentication, encryption and access control to protect the data in the database.
