
### Aggregate Functions for the Notes of the Unit 2 - Relational Data Model and Language in the Database Management System

1. An aggregate function is a function that operates on a set of values and returns a single value.
2. Common aggregate functions include: 
    * `AVG()` - calculates the average value of a column.
    * `COUNT()` - counts the number of rows in a table.
    * `MAX()` - returns the highest value in a column.
    * `MIN()` - returns the lowest value in a column.
    * `SUM()` - calculates the sum of all values in a column.
3. Aggregate functions can be used in combination with the `GROUP BY` clause to group the results of a query by one or more columns.
4. Aggregate functions can also be used with the `HAVING` clause to filter the results of a query based on aggregate values.
5. Aggregate functions are commonly used to analyze data in a relational database.
