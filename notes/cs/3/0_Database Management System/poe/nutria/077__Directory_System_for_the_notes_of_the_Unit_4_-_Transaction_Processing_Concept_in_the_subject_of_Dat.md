
### Directory System for the Notes of the Unit 4 - Transaction Processing Concept in the Subject of Database Management System

1. Transaction processing concept (TPC) is a method of data processing that enables organizations to manage and execute transactions efficiently and securely.
2. TPC consists of a set of processes and techniques used to manage and execute transactions.
3. A transaction is a unit of work that is performed against a database. It is a sequence of operations that must be completed in order for the database to remain consistent and up-to-date.
4. Transactions can be divided into two categories: online and offline. Online transactions are those that are processed immediately, while offline transactions are those that are processed at a later time.
5. A directory system is used to manage the data associated with transactions. It is a hierarchical structure of directories and files that stores the data associated with a transaction.
6. The directory system consists of a root directory, which is the top-level directory, and a number of subdirectories that contain the data associated with the transaction.
7. The data stored in the directory system is organized in a hierarchical structure. Each file or directory is assigned a unique identifier, which is used to locate the file or directory in the directory system.
8. The directory system is used to store data associated with transactions such as customer information, product information, and payment information.
9. The directory system is also used to store information about the transaction itself, such as the transaction type, the transaction status, and the transaction date.
10. The directory system is used to ensure the integrity of the data associated with the transaction. It is also used to provide security to the data, as the data is stored in a secure environment.
