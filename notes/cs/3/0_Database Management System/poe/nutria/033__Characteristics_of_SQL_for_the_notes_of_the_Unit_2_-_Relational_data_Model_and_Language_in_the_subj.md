
### Characteristics of SQL
1. SQL is a declarative language, meaning that it allows users to describe the desired results of their queries without having to specify the exact sequence of steps needed to achieve them.
2. SQL is a domain-specific language, meaning that it is designed to work with relational databases.
3. SQL is a non-procedural language, meaning that it does not require users to specify the exact steps needed to manipulate the data.
4. SQL is a data definition language, meaning that it is used to define the structure of the database and the relationships between the various tables and fields.
5. SQL is a data manipulation language, meaning that it is used to manipulate the data stored in the database.
6. SQL is a set-oriented language, meaning that it is designed to work with sets of data rather than individual records.
7. SQL is a query language, meaning that it is used to retrieve data from the database.
8. SQL is a transaction-oriented language, meaning that it is designed to handle multiple transactions at once.
9. SQL is an interactive language, meaning that it allows users to interact with the database in real time.
