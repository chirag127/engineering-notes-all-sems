### Keys for the notes of the Unit 1 - Introduction in the subject of Database Management System

Database Management System (DBMS) is a software system that allows users to store, modify, and retrieve data from a database. It is an essential tool for managing large amounts of data efficiently. In this unit, we will discuss the basics of DBMS and its importance. Here are some key points to keep in mind while studying this unit:

- **Introduction to DBMS**: DBMS is a software system that manages databases. It allows users to store, modify, and retrieve data from a database. DBMS is used in many applications, including banking, finance, healthcare, and education.

- **Types of DBMS**: There are various types of DBMS, including relational, hierarchical, network, and object-oriented. Each has its own advantages and disadvantages. In this unit, we will focus on relational DBMS, which is the most widely used type.

- **Data Models**: A data model is a way of representing data in a DBMS. There are three types of data models: hierarchical, network, and relational. In this unit, we will focus on the relational data model, which represents data as tables.

- **Keys**: Keys are used to identify unique records in a table. There are several types of keys, including primary keys, foreign keys, and candidate keys. In this unit, we will focus on primary keys, which are used to uniquely identify each record in a table.

- **Normalization**: Normalization is the process of organizing data in a database to reduce redundancy and improve data integrity. There are several normal forms, including first normal form (1NF), second normal form (2NF), and third normal form (3NF). In this unit, we will focus on the first three normal forms.

- **SQL**: SQL (Structured Query Language) is a programming language used to manage databases. It is used to create, modify, and retrieve data from a database. In this unit, we will focus on basic SQL commands, including SELECT, INSERT, UPDATE, and DELETE.

In conclusion, understanding the basics of DBMS is essential for managing large amounts of data efficiently. This unit will provide you with the necessary knowledge and skills to work with databases effectively. Keep these key points in mind while studying this unit, and you will be well on your way to mastering DBMS.
