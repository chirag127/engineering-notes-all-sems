### DML for the notes of the Unit 1 - Introduction in the subject of Database Management System

DML stands for Data Manipulation Language, which is used to manage data in a database. In this unit, we will discuss the basics of DML and its importance in database management. Below are some important points to keep in mind:

- DML is used to insert, update, delete, and retrieve data from a database.
- The most commonly used commands in DML are INSERT, UPDATE, DELETE, and SELECT.
- INSERT command is used to add new data to a table.
- UPDATE command is used to modify existing data in a table.
- DELETE command is used to remove data from a table.
- SELECT command is used to retrieve data from a table.
- DML commands are executed using SQL (Structured Query Language).
- DML is an important component of database management and is used extensively in applications that require data management.
- DML commands should be used with caution as they can have a significant impact on the data stored in a database.
- It is important to have a good understanding of DML and its commands to effectively manage data in a database.

In conclusion, DML is an essential part of database management and is used to manipulate data in a database. It is important to have a good understanding of DML commands and their usage to effectively manage data in a database.
