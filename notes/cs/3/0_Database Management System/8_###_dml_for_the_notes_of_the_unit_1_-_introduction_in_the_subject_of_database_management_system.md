### DML for the notes of the Unit 1 - Introduction in the subject of Database Management System

Unit 1 of the Database Management System course focuses on Introduction, including the aspect of Data Manipulation Language (DML).

DML is a subset of SQL that is used to manipulate data stored in a database. DML includes commands such as SELECT, INSERT, UPDATE, and DELETE, which are used to retrieve, add, modify, and delete data in a database, respectively.

In the context of the Database Management System course, students in Unit 1 may learn about DML as part of the introduction to database management. This may include working with examples of DML commands, analyzing the use of DML in database management, and learning how to use DML commands to manipulate data in a database.

In summary, Unit 1 of the Database Management System course focuses on Introduction, and may include a discussion of Data Manipulation Language (DML).
