### Mapping Constraints for the notes of the Unit 1 - Introduction in the subject of Database Management System

Mapping constraints are a set of rules used to enforce data integrity in a database management system. In the context of Unit 1 - Introduction in the subject of Database Management System, mapping constraints are used to ensure that the data entered into the database is accurate, consistent, and meets certain criteria.

The following are some common mapping constraints that may be covered in Unit 1:

1. Primary Key Constraint: A primary key constraint is used to ensure that each record in a table has a unique identifier. This identifier is used to identify each record and to enforce relationships between tables.

2. Foreign Key Constraint: A foreign key constraint is used to enforce relationships between tables. It requires that a value in one table matches a value in another table.

3. Not Null Constraint: A not null constraint is used to ensure that a value is entered for a specific field in a table. This constraint prevents null values from being entered into the database.

4. Unique Constraint: A unique constraint is used to ensure that a value entered into a field is unique across all records in a table. This constraint prevents duplicate values from being entered into the database.

5. Check Constraint: A check constraint is used to enforce data integrity by checking the values entered into a field against a specified condition. This constraint can be used to ensure that values entered into a field are within a certain range, or that they meet a specific format.

6. Default Constraint: A default constraint is used to provide a default value for a field in a table. This constraint is used when a value is not entered for a specific field, and the default value is used instead.

By the end of Unit 1, students should have a good understanding of mapping constraints and how they are used to enforce data integrity in a database management system.
