### Introduction on SQL for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Unit 2 of the Database Management System course focuses on the Relational Data Model and Language, including an introduction to SQL (Structured Query Language).

SQL is a standard language used for managing and manipulating relational databases. It is used to create, modify, and query databases, and is widely used in industry for data management and analysis.

In the context of the Database Management System course, students in Unit 2 will learn about the relational data model, which is a way of organizing data into tables with relationships between them. They will also learn about SQL, including the syntax and structure of SQL statements, and will have hands-on experiences working with SQL to create, modify, and query databases.
