### Triggers for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Triggers are special type of stored procedures that are automatically executed in response to specific events in a database. In the context of Unit 2 - Relational data Model and Language in the subject of Database Management System, triggers are used to enforce business rules and maintain data integrity in a database.

1. Definition: A trigger is a set of instructions that are automatically executed in response to a specific event, such as the insertion, update, or deletion of data in a table.

2. Types of Triggers: There are two types of triggers: before triggers and after triggers. Before triggers are executed before the triggering event, while after triggers are executed after the event.

3. Use Cases: Triggers are commonly used to enforce business rules, such as ensuring that data entered into a database is valid and consistent. They can also be used to maintain data integrity, such as updating a related table when data in a primary table is modified.

4. Syntax: The syntax for creating a trigger in SQL varies depending on the database management system, but typically involves the CREATE TRIGGER statement, followed by the instructions for the trigger.

5. Trigger Limitations: There are limitations to the use of triggers, such as performance issues and the potential for circular references. Careful consideration should be given to the use of triggers, and they should be used only when necessary.

Triggers are a powerful tool in database management systems, and can be used to automate complex tasks and enforce business rules. However, they should be used with caution, as they can have a significant impact on performance and data integrity if not used properly.
