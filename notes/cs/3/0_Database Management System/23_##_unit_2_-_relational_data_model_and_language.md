## Unit 2 - Relational data Model and Language

The Unit 2 of the course focuses on relational data model and language. The objectives of this unit are to:

1. Introduction to Relational Data Model: Students will learn about the relational data model, which is the most widely used data model for storing and manipulating data in a database. They will learn about the concept of tables and relationships between tables, and how to design a relational database to meet specific requirements.

2. SQL: Students will learn about SQL (Structured Query Language), which is the standard language used to manage and manipulate data in a relational database. They will learn how to write SQL statements to create tables, insert data, update data, and retrieve data from a database.

3. Data Integrity and Constraints: Students will learn about the importance of data integrity and how to enforce constraints in a relational database. This will include learning about primary keys, foreign keys, and unique constraints, and how to use these constraints to ensure data consistency and accuracy.

4. Advanced SQL: Students will learn about advanced SQL concepts, including subqueries, joins, and aggregate functions. They will also learn about the use of views, stored procedures, and triggers in a relational database.

5. Database Normalization: Students will learn about database normalization, which is the process of organizing data in a relational database to minimize redundancy and improve data consistency. They will learn about the different normalization levels and how to apply normalization to a database design.

By the end of the unit, students will have a deep understanding of relational data models and SQL, and will be able to design, implement, and manage a relational database effectively.
