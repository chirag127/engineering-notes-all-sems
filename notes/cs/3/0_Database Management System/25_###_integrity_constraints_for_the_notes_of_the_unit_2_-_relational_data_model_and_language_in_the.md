### Integrity Constraints for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

The integrity constraints for the Unit 2 - Relational Data Model and Language in the subject of Database Management System are rules that ensure the accuracy and consistency of the data stored in a relational database. These constraints are used to prevent data anomalies and to enforce business rules. The following are some common types of integrity constraints:

1. Primary Key Constraint: A primary key is a unique identifier for each record in a table. The primary key constraint ensures that no two records in a table have the same primary key value.

2. Foreign Key Constraint: A foreign key is a field in one table that refers to the primary key of another table. The foreign key constraint ensures that the values in the foreign key field are valid and correspond to a record in the referenced table.

3. Not Null Constraint: The not null constraint ensures that a field in a table cannot be left empty or null.

4. Unique Constraint: The unique constraint ensures that no two records in a table have the same value in a specific field.

5. Check Constraint: The check constraint is a custom rule that can be defined to enforce specific business rules. For example, a check constraint can be used to ensure that a field contains a value within a certain range.

6. Default Constraint: The default constraint sets a default value for a field in a table. If no value is provided for the field, the default value will be used.

7. Referential Integrity Constraint: Referential integrity is a set of rules that ensure that changes to the primary key values of a table are reflected in the foreign key values of related tables.

These integrity constraints are an important part of the relational data model and language, and they help to ensure the accuracy and consistency of the data stored in a database. By enforcing these constraints, the database management system can help prevent data anomalies and ensure that the data is always in a consistent state.
