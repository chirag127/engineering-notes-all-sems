Unit 3 of the Database Management System course focuses on Database Design and Normalization, including the Third Normal Form (3NF).

Normalization is the process of organizing data in a database to minimize redundancy and improve data integrity. The Third Normal Form is a step in the normalization process that ensures that data in a table is not redundant and that all data in the table is dependent on the primary key.

In the Third Normal Form, all non-key attributes in a table must be dependent on the primary key, and there should not be any transitive dependencies between non-key attributes. This means that data in the table should not be redundant, and that all data in the table should be directly related to the primary key.
