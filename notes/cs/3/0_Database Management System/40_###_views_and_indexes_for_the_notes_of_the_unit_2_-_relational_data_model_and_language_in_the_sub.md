### Views and Indexes for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

The Unit 2 - Relational Data Model and Language in the subject of Database Management System focuses on the relational data model and the language used to manipulate relational databases.

1. Relational Data Model: The relational data model is a way of organizing data into tables, with each table representing a different type of entity. The relationships between entities are represented by relationships between tables. Students will learn about the key concepts of the relational data model, including entities, attributes, and relationships.

2. SQL: SQL (Structured Query Language) is the language used to manipulate relational databases. Students will learn the basics of SQL syntax, including how to create tables, insert data, update data, and retrieve data. They will also learn about advanced SQL concepts, such as subqueries, joins, and aggregate functions.

3. Views: Views are virtual tables that are derived from existing tables in the database. Students will learn how to create views and how to use them to simplify the process of retrieving data from a database. They will also learn about the benefits of using views, such as increased security and improved data integrity.

4. Indexes: Indexes are data structures that are used to improve the performance of database queries. Students will learn about the different types of indexes, including clustered and non-clustered indexes, and how to create and manage indexes in a database. They will also learn about the benefits of using indexes, such as improved query performance and reduced disk I/O.

By the end of the unit, students will have a comprehensive understanding of the relational data model and the language used to manipulate relational databases. They will be able to use SQL to create and manipulate relational databases, create views to simplify the process of retrieving data, and use indexes to improve the performance of database queries.
