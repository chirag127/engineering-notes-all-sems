### Keys Constraints for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

The keys and constraints for the notes of Unit 2 - Relational Data Model and Language in the subject of Database Management System are critical components of the relational database management system.

1. Keys: 
  a. Primary Key: A primary key is a unique identifier for each record in a table. It is used to enforce referential integrity in the database.
  b. Foreign Key: A foreign key is a field in one table that refers to the primary key of another table. It is used to enforce referential integrity and to create relationships between tables.

2. Constraints: 
  a. NOT NULL: This constraint ensures that a field cannot be left blank.
  b. UNIQUE: This constraint ensures that a field must contain a unique value for each record in a table.
  c. CHECK: This constraint restricts the values that can be entered into a field to a specified set of values.
  d. DEFAULT: This constraint sets a default value for a field if no value is provided.
  e. INDEX: This constraint optimizes database performance by creating an index for a field, allowing for faster searching and sorting.

By understanding these keys and constraints, students will be able to effectively design and manage relational databases, ensuring data integrity, consistency, and efficiency.
