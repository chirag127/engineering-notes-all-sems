### Procedures in SQL/PL SQL for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Procedures are pre-defined blocks of code that can be executed in a database management system. They are used to encapsulate logic and reduce code duplication, and they can be used to perform a variety of tasks, such as data validation, data manipulation, and data retrieval.

SQL/PL SQL provides support for procedures, and they can be used to perform a variety of tasks in a database management system. Procedures in SQL/PL SQL are defined using the `CREATE PROCEDURE` statement, and they can be executed using the `EXEC` statement.

The general syntax of a procedure in SQL/PL SQL is:

```
CREATE PROCEDURE procedure_name (arguments)
AS
BEGIN
    -- code to be executed
END;
```

You will also learn about the various types of procedures that can be used in a database management system, and how to use procedures to perform a variety of tasks, such as data validation, data manipulation, and data retrieval. This will provide a foundation for understanding the principles and practices of database management, and for exploring the various concepts and techniques used in database management systems.
