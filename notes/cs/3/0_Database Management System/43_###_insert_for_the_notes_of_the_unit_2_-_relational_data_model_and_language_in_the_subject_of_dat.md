### Insert for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Insert is a SQL statement used to insert data into a relational database. The basic syntax of the insert statement is:

```
INSERT INTO table_name (column1, column2, ...)
VALUES (value1, value2, ...);
```

The `table_name` is the name of the table into which the data is being inserted. The `column1, column2, ...` are the names of the columns in the table, and the `value1, value2, ...` are the values being inserted into the columns.

The insert statement can be used to insert a single row of data into a table, or multiple rows of data into a table. The values being inserted can be constants, variables, or expressions.

In this unit, you will learn about the insert statement and its role in the relational data model and language. You will also learn about the various forms of the insert statement, including the insert statement with a subquery, and the insert statement with a default value. This will provide a foundation for understanding the principles and practices of relational databases, and for exploring the various concepts and techniques used in database management systems.
