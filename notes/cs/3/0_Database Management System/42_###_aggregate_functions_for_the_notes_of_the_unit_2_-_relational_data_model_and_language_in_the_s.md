### Aggregate Functions for the notes of the Unit 2 - Relational data Model and Language in the subject of Database Management System

Aggregate functions are used to summarize data in a database. They are commonly used in database management systems to perform operations such as counting the number of rows in a table, finding the average value of a column, or calculating the sum of a column. 

1. COUNT: This function returns the number of rows in a table or the number of non-null values in a column.

2. SUM: This function returns the sum of all values in a column.

3. AVG: This function returns the average value of a column.

4. MIN: This function returns the minimum value in a column.

5. MAX: This function returns the maximum value in a column.

6. GROUP BY: This clause is used in conjunction with aggregate functions to group rows in a table based on the values in one or more columns.

7. HAVING: This clause is used to filter the results of a query based on aggregate values.

Aggregate functions are essential for analyzing and summarizing data in a database. They allow you to quickly and easily summarize large amounts of data, making it easier to understand and analyze the information in your database. These functions are supported by most relational database management systems and are a key component of the SQL language used to interact with databases.
