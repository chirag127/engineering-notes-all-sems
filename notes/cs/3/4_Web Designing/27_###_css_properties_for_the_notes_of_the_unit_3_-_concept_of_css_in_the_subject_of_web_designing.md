### CSS Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

The CSS Properties section of the Unit 3 - Concept of CSS in the subject of Web Designing should cover the following topics:

1. Definition of CSS (Cascading Style Sheets, a stylesheet language used for describing the look and formatting of web pages)
2. Overview of CSS (what it is, when it is used, advantages and disadvantages)
3. CSS properties (color, background, font, text, border, margin, padding, etc.)
4. Overview of color (the property used to specify the color of text and other elements)
5. Overview of background (the property used to specify the background color or image of an element)
6. Overview of font (the property used to specify the font family, size, weight, and style of text)
7. Overview of text (the property used to specify the alignment, decoration, and spacing of text)
8. Overview of border (the property used to specify the border style, color, and width of an element)
9. Overview of margin (the property used to specify the space outside of an element)
10. Overview of padding (the property used to specify the space inside of an element)
11. CSS units (px, em, rem, %, etc.)
12. Overview of px (pixels, a fixed unit of measurement)
13. Overview of em (a relative unit of measurement based on the font size of the parent element)
14. Overview of rem (a relative unit of measurement based on the font size of the root element)
15. Overview of % (percentage, a unit of measurement based on the size of the parent element)
16. CSS selectors (class, id, element, attribute, pseudo-class, etc.)
17. Overview of class (a selector used to select elements based on their class attribute)
18. Overview of id (a selector used to select a unique element based on its id attribute)
19. Overview of element (a selector used to select elements based on their type, such as <p> or <h1>)
20. Overview of attribute (a selector used to select elements based on their attributes, such as href or src)
21. Overview of pseudo-class (a selector used to select elements based on their state, such as :hover or :active)
22. The role of CSS in web design (styling and formatting web pages, improving accessibility and readability)
23. Limitations of CSS (browser compatibility, performance, accessibility)
24. Techniques for overcoming limitations (cross-browser compatibility, optimization, accessibility standards)
25. Further reading and resources (books, tutorials, online resources)

CSS is an important component of the subject of Web Designing. Understanding the principles and techniques of CSS helps students to develop the skills required to style and format web pages. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
