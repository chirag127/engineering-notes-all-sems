### Dimension for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

The Dimension section of the Unit 3 - Concept of CSS in the subject of Web Designing should cover the following topics:

1. Definition of dimension (the size and shape of an HTML element)
2. Overview of dimension (what it is, when it is used, advantages and disadvantages)
3. CSS properties for dimension (width, height, max-width, max-height, min-width, min-height)
4. Overview of width (the property used to specify the width of an element)
5. Overview of height (the property used to specify the height of an element)
6. Overview of max-width (the property used to specify the maximum width of an element)
7. Overview of max-height (the property used to specify the maximum height of an element)
8. Overview of min-width (the property used to specify the minimum width of an element)
9. Overview of min-height (the property used to specify the minimum height of an element)
10. CSS units for dimension (px, em, rem, %)
11. Overview of px (pixels, a fixed unit of measurement)
12. Overview of em (a relative unit of measurement based on the font size of the parent element)
13. Overview of rem (a relative unit of measurement based on the font size of the root element)
14. Overview of % (percentage, a unit of measurement based on the size of the parent element)
15. The role of dimension in web design (controlling the size and shape of elements, creating responsive and dynamic web pages)
16. Limitations of dimension (browser compatibility, performance, accessibility)
17. Techniques for overcoming limitations (cross-browser compatibility, optimization, accessibility standards)
18. Further reading and resources (books, tutorials, online resources)

Dimension is an important component of the subject of Web Designing. Understanding the principles and techniques of dimension helps students to develop the skills required to control the size and shape of HTML elements. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
