### CSS Color for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS Color is an important aspect of web design, as it allows you to control the color of text, backgrounds, and other elements on a web page. CSS provides several ways to specify color, including:

1. Color keywords: CSS provides a set of predefined color keywords, such as red, blue, green, and yellow, among others.

2. RGB values: CSS provides a way to specify color using RGB (red, green, blue) values, which are used to define the intensity of each color component.

3. HEX values: CSS provides a way to specify color using HEX (hexadecimal) values, which are used to define the intensity of each color component.

4. HSL values: CSS provides a way to specify color using HSL (hue, saturation, lightness) values, which are used to define the hue, saturation, and lightness of a color.

In this unit, you will learn about the different ways to specify color in CSS, and you will learn how to use CSS to control the color of text, backgrounds, and other elements on a web page. You will also learn about color theory, and you will learn how to use color to create a harmonious and visually appealing design.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
