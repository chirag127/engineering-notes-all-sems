### Navigation Bar for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

A navigation bar is a key element of web design, as it provides a way to navigate a website. Navigation bars can be created using HTML and CSS, and they typically include a list of links to the different pages on a website.

In this unit, you will learn about the basics of creating a navigation bar, including the HTML and CSS used to create and style the bar. You will also learn about the different types of navigation bars, including horizontal and vertical navigation bars, and you will learn how to create custom styles for navigation bars using CSS.

CSS provides a way to control the font, color, background, and layout of a navigation bar, and it provides a way to separate the content of a web page from its presentation. You will learn about the different CSS selectors and properties used to control the appearance of a navigation bar, and you will learn how to use CSS to create custom styles for navigation bars.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
