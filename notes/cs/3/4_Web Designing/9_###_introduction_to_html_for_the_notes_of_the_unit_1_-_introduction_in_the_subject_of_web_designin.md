### Introduction to HTML for the notes of the Unit 1 - Introduction in the subject of Web Designing

HTML (Hypertext Markup Language) is the standard language used to create web pages. It provides the structure and content of a web page, and it is used to define the text, images, videos, and other elements that make up a web page.

HTML consists of a series of tags, which are used to define the structure and content of a web page. For example, the <h1> tag is used to define a heading, the <p> tag is used to define a paragraph, and the <img> tag is used to define an image.

HTML also provides a way to add links to a web page, which allows users to navigate from one page to another. Links are created using the <a> tag, and they are defined using the href attribute.

In this unit, you will learn about the basics of HTML, including the structure of an HTML document, the different HTML tags and their uses, and how to create links and images in HTML. You will also learn about the basics of CSS (Cascading Style Sheets), which is used to control the appearance of a web page.

This unit will provide a foundation for understanding the principles and practices of web design, and for exploring the various concepts and techniques used in the field of web design.
