### Javascript Types for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

JavaScript is a high-level, dynamic, and interpreted programming language used for client-side scripting in web development. It is used to create interactive and dynamic effects on a web page, and it provides a way to manipulate the Document Object Model (DOM) of a web page.

There are several data types in JavaScript, including:

1. Number: Represents numeric values, including integers and floating-point numbers.

2. String: Represents a sequence of characters, such as "Hello, World!".

3. Boolean: Represents a logical value, either true or false.

4. Object: Represents a collection of properties and methods, and can be used to store data and manipulate the DOM.

5. Array: Represents an ordered list of values, and can be used to store and manipulate data.

6. Function: Represents a block of code that can be executed when called.

In this unit, you will learn about the different data types in JavaScript, and you will learn how to use them to create and manipulate data. You will also learn about the basics of JavaScript, including variables, operators, control structures, and functions.

This unit will provide a foundation for understanding the principles and practices of JavaScript and client-side scripting, and for exploring the various concepts and techniques used in the field of web design.
