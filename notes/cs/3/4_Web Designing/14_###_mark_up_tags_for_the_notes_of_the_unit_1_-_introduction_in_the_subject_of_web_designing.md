### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

The Markup Tags section of the Unit 1 - Introduction in the subject of Web Designing should cover the following topics:

1. Definition of Markup Tags (tags used to structure and format web content)
2. Overview of Markup Tags (what they are, when they are used, advantages and disadvantages)
3. Types of Markup Tags (HTML, XML, SGML)
4. Overview of HTML (Hypertext Markup Language, the standard markup language for web pages)
5. Overview of XML (eXtensible Markup Language, a markup language for data)
6. Overview of SGML (Standard Generalized Markup Language, a markup language for documents)
7. HTML tags (headings, paragraphs, links, images, lists, tables, forms, etc.)
8. Overview of headings (tags used to create headings, <h1> to <h6>)
9. Overview of paragraphs (tags used to create paragraphs, <p>)
10. Overview of links (tags used to create links, <a>)
11. Overview of images (tags used to create images, <img>)
12. Overview of lists (tags used to create ordered and unordered lists, <ol>, <ul>)
13. Overview of tables (tags used to create tables, <table>)
14. Overview of forms (tags used to create forms, <form>)
15. The role of Markup Tags in web designing (structuring and formatting web content, creating interactive web pages)
16. Applications of Markup Tags in web designing (web pages, e-commerce sites, blogs, etc.)
17. Limitations of Markup Tags (complexity, compatibility, accessibility)
18. Techniques for overcoming limitations (CSS, JavaScript, accessibility standards)
19. Further reading and resources (books, online tutorials, online resources)

Markup Tags are an important component of the subject of Web Designing. Understanding the principles and techniques of Markup Tags helps students to develop the skills required to structure and format web content. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
