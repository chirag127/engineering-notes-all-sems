### Creating page Layout and Site Designs for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Creating page layout and site designs is an important aspect of web design, as it determines the overall look and feel of a web page. CSS provides several properties and techniques for controlling the layout and design of a web page, including:

1. Box Model: CSS provides a way to control the size, padding, border, and margin of elements on a web page.

2. Layout: CSS provides a way to control the positioning and flow of elements on a web page, including floating elements, absolute positioning, and relative positioning.

3. Backgrounds: CSS provides a way to control the background color and image of a web page.

4. Design: CSS provides a way to control the font, color, and other design elements of a web page.

In this unit, you will learn about the different properties and techniques used in CSS to create page layouts and site designs, including the box model, layout, backgrounds, and design. You will learn how to use CSS to create complex and dynamic page layouts and site designs, and you will learn how to use CSS to control the appearance and layout of a web page.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
