### JS Objects for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

Unit 4 of the Web Designing course focuses on Introduction to Client Side Scripting, including the aspect of JS Objects.

JS (JavaScript) is a high-level, dynamic, and interpreted programming language that is widely used for client-side scripting in web development. JS is used to add interactivity and dynamic behavior to web pages, such as responding to user input, updating content, and creating animations.

JS Objects are data structures that contain properties and methods, and are used to represent real-world objects in a programmatic way. Objects can be created using object literals, or by using object constructors.

For example, the following code creates a person object using an object literal:

```
var person = {
  name: "John Doe",
  age: 30,
  sayHello: function() {
    console.log("Hello, my name is " + this.name);
  }
};
```

And the following code creates a person object using an object constructor:

```
function Person(name, age) {
  this.name = name;
  this.age = age;
  this.sayHello = function() {
    console.log("Hello, my name is " + this.name);
  };
}
var person = new Person("John Doe", 30);
```

In the context of the Web Designing course, students in Unit 4 will learn about JS Objects as part of the discussion on Introduction to Client Side Scripting. This may include working with examples of JS Objects, analyzing the benefits and limitations of using JS Objects, and learning how to create and use JS Objects in web development projects.

In summary, Unit 4 of the Web Designing course focuses on Introduction to Client Side Scripting, and includes the aspect of JS Objects. JS Objects are data structures that contain properties and methods, and are used to represent real-world objects in a programmatic way. Students will learn about JS Objects through interactive activities and hands-on experiences, and will learn how to create and use JS Objects in web development projects.
