### Working with Lists and Tables for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Working with lists and tables is an important aspect of web design, as they are used to organize and display information in a structured manner. HTML provides several tags and attributes for working with lists and tables, including:

1. Lists: The <ul>, <ol>, and <li> tags are used to define unordered and ordered lists, respectively. Lists are used to organize information into a structured format.

2. Tables: The <table>, <tr>, <th>, and <td> tags are used to define tables on a web page. Tables are used to organize information into rows and columns.

In this unit, you will learn about the different tags and attributes used for working with lists and tables in HTML, and you will learn how to create lists and tables. You will also learn about the basics of CSS, which is used to control the appearance of lists and tables on a web page.

CSS allows you to control the font, color, background, and layout of lists and tables, and it provides a way to separate the content of a web page from its presentation. You will learn about the different CSS selectors and properties used to control the appearance of lists and tables, and you will learn how to use CSS to create custom styles for lists and tables.

This unit will provide a foundation for understanding the basics of lists and tables in HTML, and for exploring the various concepts and techniques used in the field of web design. It will also provide a foundation for understanding the principles and practices of CSS and web design.
