### Working with Lists for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

Unit 2 of the Web Designing course focuses on Elements of HTML, including the aspect of working with lists.

Lists are a common element in HTML, and are used to present information in a structured and organized manner. There are two types of lists in HTML: ordered lists and unordered lists.

Ordered lists are lists that are numbered, and are created using the <ol> tag. The items in an ordered list are defined using the <li> tag.

Unordered lists are lists that are not numbered, and are created using the <ul> tag. The items in an unordered list are defined using the <li> tag.

In the context of the Web Designing course, students in Unit 2 will learn about working with lists as part of the discussion on Elements of HTML. This may include working with examples of ordered and unordered lists, analyzing the benefits and limitations of each type of list, and learning how to create and style lists in HTML.
