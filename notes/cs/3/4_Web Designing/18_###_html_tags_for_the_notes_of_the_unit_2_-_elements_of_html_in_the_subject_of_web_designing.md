### HTML Tags for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

Unit 2 of the Web Designing course focuses on Elements of HTML, including the aspect of HTML tags.

HTML tags are the building blocks of HTML, and are used to define the structure and content of a web page. HTML tags are surrounded by angle brackets (< >), and typically come in pairs, with an opening tag and a closing tag.

There are several types of HTML tags, including:
- Headings, which are used to define headings and subheadings on a web page.
- Paragraphs, which are used to define paragraphs of text on a web page.
- Links, which are used to create links to other web pages or resources.
- Images, which are used to embed images on a web page.
- Lists, which are used to create ordered or unordered lists on a web page.
- Tables, which are used to create tables on a web page.

In the context of the Web Designing course, students in Unit 2 will learn about HTML tags as part of the discussion on Elements of HTML. This may include working with examples of HTML tags, analyzing the benefits and limitations of each type of tag, and learning how to use HTML tags to create web pages.

In summary, Unit 2 of the Web Designing course focuses on Elements of HTML, and includes the aspect of HTML tags. HTML tags are the building blocks of HTML, and are used to define the structure and content of a web page. There are several types of HTML tags, including headings, paragraphs, links, images, lists, and tables. Students will learn about HTML tags through interactive activities and hands-on experiences, and will learn how to use HTML tags to create web pages.
