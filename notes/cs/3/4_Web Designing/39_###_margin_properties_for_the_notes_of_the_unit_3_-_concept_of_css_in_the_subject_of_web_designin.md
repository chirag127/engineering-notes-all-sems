### Margin properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Margins are the spaces between an HTML element and its surrounding elements. In CSS, margin properties are used to control the size of the margins around an element. The following are the main margin properties in CSS:

1. margin-top: Specifies the size of the margin above an element.

2. margin-right: Specifies the size of the margin to the right of an element.

3. margin-bottom: Specifies the size of the margin below an element.

4. margin-left: Specifies the size of the margin to the left of an element.

5. margin: Specifies the size of the margins for all four sides of an element.

In this unit, you will learn about the different margin properties in CSS, and you will learn how to use them to control the size of the margins around an element. You will also learn about the different units of measurement used in CSS, including pixels, ems, and percentages, among others.

This unit will provide a foundation for understanding the principles and practices of CSS, and for exploring the various concepts and techniques used in the field of web design.
