### Dimension for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- In CSS, the dimension property is used to define the height and width of an element.
- The height and width properties can be set using length values, percentages, or the keywords `auto`, `max-content`, `min-content`, `fit-content`, and `fill-available`.
- Length values can be specified using absolute units such as `px`, `cm`, `mm`, `in`, `pt`, and `pc`, or relative units such as `em`, `ex`, `ch`, `rem`, `vw`, `vh`, `vmin`, and `vmax`.
- Percentages are calculated with respect to the containing block.
- The `auto` keyword tells the browser to calculate the height or width based on the content and the available space.
- The `max-content` keyword specifies that the element should be as wide or tall as the content requires.
- The `min-content` keyword specifies that the element should be as small as possible while still fitting its content.
- The `fit-content` keyword specifies that the element should be as wide or tall as the content requires, but not wider than the available space.
- The `fill-available` keyword specifies that the element should take up all available space in the containing block.
- The `box-sizing` property can be used to include or exclude the padding and border of an element in the calculation of its width and height.
- The `box-sizing` property can take the values `content-box` (default) or `border-box`.
- When `box-sizing` is set to `content-box`, the width and height properties specify the dimensions of the content area of the element, excluding the padding and border.
- When `box-sizing` is set to `border-box`, the width and height properties specify the dimensions of the element including the padding and border.
