### Align for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is a stylesheet language used to describe the look and formatting of a document written in a markup language.
2. CSS is used to separate the presentation of a document from its content, allowing for greater flexibility and control in the design of web pages.
3. CSS allows for the creation of rules that specify how the elements of a document should be displayed. These rules can be applied to multiple documents, making it easy to maintain a consistent look and feel across a website.
4. CSS provides a wide range of styling options, including the ability to control the layout, color, font, and other visual aspects of a web page.
5. CSS can be used to create responsive designs, allowing web pages to adapt to different screen sizes and devices.
6. CSS can be applied to a document in several ways, including inline, internal, and external stylesheets.
7. CSS has a powerful cascading mechanism, allowing for the inheritance of styles and the ability to override styles based on their specificity.
8. CSS has a well-defined syntax and a rich set of selectors, allowing for the precise targeting of elements within a document.
9. CSS is constantly evolving, with new features and capabilities being added to the language on a regular basis.
