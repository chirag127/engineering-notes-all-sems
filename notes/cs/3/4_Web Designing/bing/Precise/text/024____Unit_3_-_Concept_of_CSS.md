## Unit 3 - Concept of CSS

- CSS stands for Cascading Style Sheets.
- CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
- CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
- CSS allows developers to separate the presentation of a web page from its content, making it easier to maintain and update.
- CSS can be applied to a web page in three ways: inline, internal, and external.
- Inline styles are applied directly to an HTML element using the `style` attribute.
- Internal styles are defined within the `style` element in the `head` section of an HTML document.
- External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
- CSS uses a set of rules to apply styles to elements on a web page. These rules are made up of selectors and declarations.
- Selectors are used to specify which elements on a web page the styles should be applied to.
- Declarations are used to define the styles that should be applied to the selected elements.
- CSS has a wide range of properties that can be used to style elements, including `color`, `font-size`, `background-color`, `margin`, and `padding`.
- CSS also has a powerful system of selectors, including class, ID, and attribute selectors, that allow developers to target specific elements on a web page.
- CSS has a cascading order that determines which styles are applied to an element when there are conflicting styles. The order is: inline styles, internal styles, external styles, and browser default styles.
- CSS also has a system of inheritance, where some styles are inherited by child elements from their parent elements.
- CSS has evolved over time, with new versions adding new features and capabilities. The current version of CSS is CSS3.
