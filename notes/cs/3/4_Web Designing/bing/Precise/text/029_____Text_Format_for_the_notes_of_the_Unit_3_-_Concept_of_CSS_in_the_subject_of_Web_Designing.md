### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used for describing the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the presentation of a web page from its content, making it easier to maintain and update.
5. CSS can be applied to a web page in three ways: inline, internal, and external.
6. Inline styles are applied directly to an HTML element using the `style` attribute.
7. Internal styles are defined within the `style` element in the `head` section of an HTML document.
8. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
9. CSS uses a set of rules to apply styles to elements on a web page. These rules are made up of selectors and declarations.
10. Selectors are used to specify which elements on a web page the styles should be applied to.
11. Declarations are used to define the styles that should be applied to the selected elements. They are made up of a property and a value, separated by a colon.
12. CSS has a wide range of properties that can be used to style elements on a web page, including `color`, `font-size`, `background-color`, `margin`, and `padding`.
13. CSS also has a powerful system of selectors, including class, ID, and attribute selectors, that can be used to target specific elements on a web page.
14. CSS has a cascading order that determines which styles are applied to an element when multiple styles are defined for the same element.
15. CSS also has a system of inheritance, where styles applied to a parent element are inherited by its child elements.
16. CSS has a wide range of tools and techniques for creating complex layouts, including the `display`, `position`, and `float` properties, as well as the Flexbox and Grid layout systems.
17. CSS is constantly evolving, with new features and capabilities being added to the language on a regular basis.
