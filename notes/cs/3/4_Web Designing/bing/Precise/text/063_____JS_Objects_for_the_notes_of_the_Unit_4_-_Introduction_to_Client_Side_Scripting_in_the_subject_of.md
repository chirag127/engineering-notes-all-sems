### JS Objects

- JavaScript objects are collections of properties.
- Properties are pairs of keys and values.
- Keys are always strings, while values can be any data type.
- Objects can be created using object literals or the `Object` constructor.
- Properties can be accessed using dot notation or bracket notation.
- Methods are functions that are stored as object properties.
- The `this` keyword refers to the object that the method is being called on.
- Objects can be used to model real-world concepts and organize data.
- Objects can be nested within other objects to create complex data structures.
- Objects can be passed as arguments to functions and returned from functions.
