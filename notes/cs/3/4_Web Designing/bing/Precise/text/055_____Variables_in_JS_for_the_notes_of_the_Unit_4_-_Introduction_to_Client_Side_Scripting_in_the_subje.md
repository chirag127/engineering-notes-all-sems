### Variables in JS

Variables are used to store data values in JavaScript. They are declared using the `var`, `let`, or `const` keywords.

- `var`: used to declare a variable with a function scope. This means that the variable is accessible within the function it is declared in, as well as any nested functions.

- `let`: used to declare a variable with a block scope. This means that the variable is accessible within the block it is declared in, as well as any nested blocks.

- `const`: used to declare a variable with a block scope that cannot be reassigned. This means that the value of the variable cannot be changed once it is declared.

Variables can store different types of data, including numbers, strings, and objects. They can be assigned a value when they are declared, or their value can be changed later in the code.

Here is an example of declaring and assigning a value to a variable in JavaScript:

```javascript
let myVariable = 'Hello, World!';
```

In this example, a variable called `myVariable` is declared using the `let` keyword and assigned the value `'Hello, World!'`. The value of the variable can be accessed and used in the code by referencing its name.

Variables are an essential part of JavaScript and are used to store and manipulate data in a program. Understanding how to declare and use variables is a fundamental concept in JavaScript programming.
