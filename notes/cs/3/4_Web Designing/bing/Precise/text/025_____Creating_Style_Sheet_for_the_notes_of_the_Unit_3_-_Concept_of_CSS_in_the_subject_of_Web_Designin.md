### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows you to create rules that specify how the content of elements within an HTML page should be displayed.
5. CSS is used to separate the presentation of a web page from its content, making it easier to maintain and update.
6. CSS can be applied to a web page in three ways: inline, internal, and external.
7. An inline style is applied directly to an individual element on a page using the `style` attribute.
8. An internal style sheet is defined within the `head` section of an HTML page using the `style` element.
9. An external style sheet is a separate file linked to an HTML page using the `link` element.
10. CSS has a simple syntax and uses a number of English keywords to specify the names of various style properties.
11. A style sheet consists of a list of rules, with each rule consisting of one or more selectors and a declaration block.
12. Selectors are used to specify the elements to which a set of CSS rules apply.
13. A declaration block consists of a list of declarations, with each declaration consisting of a property and a value, separated by a colon.
14. CSS rules can be combined and overridden to achieve the desired appearance of a web page.
15. CSS has a rich set of properties that can be used to control the layout and presentation of web pages.
