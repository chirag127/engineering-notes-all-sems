## Unit 4 - Introduction to Client Side Scripting

1. **Client-side scripting** refers to the use of scripts that are executed on the user's web browser, rather than on the web server.
2. These scripts are used to enhance the functionality and interactivity of web pages, and can be written in languages such as JavaScript, VBScript, and JScript.
3. Client-side scripts are embedded within the HTML of a web page and are downloaded along with the page when it is requested by the user's browser.
4. Once downloaded, the scripts are executed by the browser, allowing them to manipulate the page's content and respond to user interactions in real-time.
5. Some common uses of client-side scripting include form validation, user interface enhancements, and dynamic content updates.
6. Client-side scripting can also be used to store data on the user's device, using technologies such as cookies and local storage.
7. While client-side scripting can greatly enhance the user experience, it is important to ensure that it is used responsibly and does not compromise the security or privacy of the user.
