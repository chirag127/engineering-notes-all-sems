### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is one of the core technologies used in web design and development.
4. CSS allows developers to separate the presentation of a web page from its content, making it easier to maintain and update.
5. CSS provides a wide range of styling options, including the ability to control the layout, colors, fonts, and other visual aspects of a web page.
6. CSS was first proposed by Håkon Wium Lie in 1994 and has since gone through several revisions, with the latest version being CSS3.
7. CSS is widely supported by all modern web browsers and is an essential skill for any web designer or developer.
