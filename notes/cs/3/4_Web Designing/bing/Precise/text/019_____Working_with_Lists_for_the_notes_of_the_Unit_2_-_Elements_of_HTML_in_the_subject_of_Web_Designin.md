### Working with Lists

- Lists are used to group related items together on a web page.
- There are two main types of lists in HTML: ordered and unordered.
- Ordered lists use numbers to indicate the order of the items, while unordered lists use bullet points.
- To create an ordered list, use the `<ol>` tag. Each item in the list is placed within a `<li>` tag.
- To create an unordered list, use the `<ul>` tag. Each item in the list is also placed within a `<li>` tag.
- Lists can be nested within one another to create sub-lists.
- The `<dl>` tag can be used to create a definition list, where each item consists of a term and its definition.
- The `<dt>` tag is used to specify the term, while the `<dd>` tag is used to specify the definition.
- Lists can be styled using CSS to change their appearance.
