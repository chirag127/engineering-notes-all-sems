### Working with Lists and Tables

Unit 3 - Concept of CSS in the subject of Web Designing

1. Lists and tables are common elements in web design and can be styled using CSS.
2. Lists can be either ordered or unordered. Ordered lists use numbers to indicate the order of the items, while unordered lists use bullet points.
3. CSS can be used to change the appearance of the list markers, as well as the spacing and indentation of the list items.
4. Tables are used to display data in a tabular format, with rows and columns.
5. CSS can be used to style the table, including changing the border, background color, and text alignment of the cells.
6. It is also possible to use CSS to create alternating row colors, which can improve the readability of the table.
7. When working with tables, it is important to use proper HTML markup, including the use of the `thead`, `tbody`, and `tfoot` elements, to ensure that the table is accessible and easy to navigate.
8. CSS can also be used to control the layout of the table, including the width of the columns and the height of the rows.
9. With the use of CSS, it is possible to create responsive tables that adjust to the size of the screen, making them easier to view on mobile devices.
10. Overall, CSS provides a powerful tool for styling lists and tables, allowing web designers to create visually appealing and easy-to-use web pages.
