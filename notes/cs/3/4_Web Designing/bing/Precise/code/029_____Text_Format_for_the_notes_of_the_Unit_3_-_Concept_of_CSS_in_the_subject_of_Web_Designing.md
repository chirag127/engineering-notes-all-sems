### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used for describing the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be applied to a web page in three ways: inline, internal, and external.
6. Inline styles are applied directly to an HTML element using the `style` attribute.
7. Internal styles are defined within the `head` section of an HTML document using the `style` element.
8. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
9. CSS selectors are used to target specific HTML elements and apply styles to them.
10. CSS properties are used to define the appearance of an element, such as its color, font, or layout.
11. CSS has a powerful cascading mechanism that allows styles to be inherited from parent elements to child elements.
12. CSS also has a specificity hierarchy that determines which styles are applied to an element when multiple styles are defined for it.
13. CSS has evolved over time, with new versions adding new features and capabilities.
14. CSS3 is the latest version of the language and includes features such as animations, transitions, and transformations.
15. CSS is an essential part of web design and development, allowing developers to create visually appealing and user-friendly websites.
