### CSS Color

CSS (Cascading Style Sheets) is used to style and layout web pages. One of the ways to style a web page is by adding color to various elements. Here are some key points to remember when working with color in CSS:

1. **Color values**: There are several ways to specify color values in CSS, including using color names, hexadecimal values, RGB values, and HSL values.
2. **Color names**: CSS has 140 predefined color names, such as `red`, `green`, and `blue`, that can be used to specify color values.
3. **Hexadecimal values**: Hexadecimal values are specified using a `#` symbol followed by six characters, where each pair of characters represents the red, green, and blue components of the color.
4. **RGB values**: RGB values are specified using the `rgb()` function, where the red, green, and blue components are specified as integers between 0 and 255 or as percentages.
5. **HSL values**: HSL values are specified using the `hsl()` function, where the hue is specified as an angle between 0 and 360 degrees, and the saturation and lightness are specified as percentages.
6. **Opacity**: The opacity of a color can be specified using the `rgba()` or `hsla()` functions, where the fourth value specifies the opacity as a number between 0 and 1.
7. **Color properties**: There are several CSS properties that can be used to set the color of various elements, including `color`, `background-color`, `border-color`, and `outline-color`.

These are some of the key points to remember when working with color in CSS. By using these techniques, you can add color to your web pages and create visually appealing designs.
