### Unit 3 - Concept of CSS in Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be used to create consistent styling across multiple pages of a website.
6. CSS can be applied to a web page in three ways: inline, internal, and external.
7. Inline CSS is applied directly to an HTML element using the `style` attribute.
8. Internal CSS is defined within the `style` element in the `head` section of an HTML document.
9. External CSS is defined in a separate file with a `.css` extension and linked to an HTML document using the `link` element.
10. CSS uses a set of rules to apply styles to elements on a web page. These rules are made up of selectors and declarations.
11. Selectors are used to specify which elements on a web page the styles should be applied to.
12. Declarations are used to define the styles that should be applied to the selected elements. They are made up of a property and a value, separated by a colon.
13. CSS has a wide range of properties that can be used to style elements, including `color`, `font-size`, `background-color`, `margin`, and `padding`.
14. CSS also has a powerful system of selectors, including class, ID, and attribute selectors, that allow developers to target specific elements on a web page.
15. CSS has a cascading order that determines which styles are applied to an element when there are conflicting styles. The order is based on the specificity of the selector and the order in which the styles are defined.
