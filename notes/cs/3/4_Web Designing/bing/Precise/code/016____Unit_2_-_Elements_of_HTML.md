## Unit 2 - Elements of HTML

HTML (Hypertext Markup Language) is the standard markup language for creating web pages and other information that can be displayed in a web browser. HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear a certain way or act a certain way.

Some common HTML elements include:

1. `<html>`: This element represents the root of an HTML document. All other elements must be descendants of this element.
2. `<head>`: This element represents a container for metadata (data about data) and is placed between the `<html>` and `<body>` elements.
3. `<body>`: This element represents the content of an HTML document. There can be only one `<body>` element in a document.
4. `<h1>` to `<h6>`: These elements represent six levels of section headings. `<h1>` is the highest section level and `<h6>` is the lowest.
5. `<p>`: This element represents a paragraph.
6. `<a>`: This element represents a hyperlink, which is used to link from one page to another.
7. `<img>`: This element represents an image.
8. `<ul>` and `<ol>`: These elements represent unordered and ordered lists, respectively.
9. `<li>`: This element represents a list item and must be contained within a `<ul>` or `<ol>` element.
10. `<div>`: This element is a generic container for flow content and does not inherently represent anything. It can be used to group elements for styling purposes.

These are just a few of the many HTML elements available. Each element has its own specific purpose and attributes that can be used to modify its behavior and appearance. By using these elements and their attributes, web developers can create structured and visually appealing web pages.
