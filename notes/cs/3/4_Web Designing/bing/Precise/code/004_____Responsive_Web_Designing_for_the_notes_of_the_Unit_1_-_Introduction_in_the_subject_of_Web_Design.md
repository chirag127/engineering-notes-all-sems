### Responsive Web Designing
#### Unit 1 - Introduction

Responsive web design is an approach to web design that makes web pages render well on a variety of devices and window or screen sizes. It aims to provide an optimal viewing and interaction experience, easy reading and navigation with a minimum of resizing, panning, and scrolling, across a wide range of devices.

Some key points to consider when designing a responsive website are:

1. **Flexible Layouts:** Using a flexible grid to create the website layout that will dynamically resize to any width.

2. **Media Queries:** An extension to media types when targeting and including styles. Media queries allow designers to specify different styles for specific browser and device circumstances.

3. **Flexible Media:** Makes media (images, video and other formats) scalable, by changing the size of the media as the size of the viewport changes.

4. **Mobile First:** Designing for mobile devices first and then progressively enhancing the design for larger screens.

By following these principles, a website can provide a seamless user experience across different devices and screen sizes. It is important to note that responsive web design is not a single technology, but rather a collection of techniques and ideas working together to create a better web experience for users.
