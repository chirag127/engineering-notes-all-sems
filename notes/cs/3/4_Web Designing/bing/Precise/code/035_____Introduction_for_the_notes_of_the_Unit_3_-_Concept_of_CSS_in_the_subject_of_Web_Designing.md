### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is one of the core technologies used in web development, along with HTML and JavaScript.
4. CSS allows developers to separate the presentation of a web page from its content, making it easier to maintain and update.
5. CSS provides a wide range of styling options, including the ability to control the layout, colors, fonts, and other visual aspects of a web page.
6. CSS can be applied to a web page in several ways, including inline styles, internal stylesheets, and external stylesheets.
7. CSS has gone through several versions, with the most recent being CSS3, which introduced new features such as animations, transitions, and transformations.
8. CSS is constantly evolving, with new features and improvements being added regularly to enhance the capabilities of web developers.
