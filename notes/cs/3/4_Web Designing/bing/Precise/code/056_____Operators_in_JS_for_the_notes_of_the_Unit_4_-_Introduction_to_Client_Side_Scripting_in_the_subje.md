### Unit 4 - Introduction to Client Side Scripting: Operators in JS

JavaScript has several types of operators that allow you to manipulate values. Here are some of the most commonly used operators in JavaScript:

1. **Arithmetic Operators**: These operators perform basic arithmetic operations such as addition, subtraction, multiplication, and division. For example, `x + y` adds the values of `x` and `y`.

2. **Assignment Operators**: These operators assign values to variables. For example, `x = y` assigns the value of `y` to `x`.

3. **Comparison Operators**: These operators compare two values and return a boolean value (`true` or `false`) depending on the result of the comparison. For example, `x == y` returns `true` if `x` and `y` are equal, and `false` otherwise.

4. **Logical Operators**: These operators perform logical operations such as `AND`, `OR`, and `NOT`. For example, `x && y` returns `true` if both `x` and `y` are `true`, and `false` otherwise.

5. **String Operators**: These operators are used to manipulate strings. For example, the `+` operator can be used to concatenate two strings: `"Hello" + "World"` returns `"HelloWorld"`.

6. **Ternary Operator**: This operator is a shorthand way of writing an `if...else` statement. It takes three operands: a condition, a value to return if the condition is `true`, and a value to return if the condition is `false`. For example, `x > y ? x : y` returns `x` if `x` is greater than `y`, and `y` otherwise.

These are just a few of the many operators available in JavaScript. Understanding how to use these operators is essential for writing effective and efficient JavaScript code.
