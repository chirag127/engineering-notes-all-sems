### CSS Color

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML. One of the important aspects of presentation is color. CSS provides several ways to specify colors in stylesheets.

1. **Color Names**: CSS defines a set of named colors that can be used in stylesheets. For example, the color name `red` can be used to specify the color red. There are 140 standard color names defined in CSS.

2. **Hexadecimal Notation**: Colors can also be specified using hexadecimal notation. A hexadecimal color value is written as `#RRGGBB`, where `RR`, `GG`, and `BB` are two-digit hexadecimal values representing the red, green, and blue components of the color. For example, the color red can be specified as `#FF0000`.

3. **RGB and RGBA Notation**: Colors can also be specified using the `rgb()` and `rgba()` functions. The `rgb()` function takes three arguments representing the red, green, and blue components of the color. The `rgba()` function takes four arguments, with the fourth argument representing the alpha (transparency) component of the color. For example, the color red can be specified as `rgb(255, 0, 0)`.

4. **HSL and HSLA Notation**: Colors can also be specified using the `hsl()` and `hsla()` functions. The `hsl()` function takes three arguments representing the hue, saturation, and lightness components of the color. The `hsla()` function takes four arguments, with the fourth argument representing the alpha (transparency) component of the color. For example, the color red can be specified as `hsl(0, 100%, 50%)`.

These are some of the ways to specify colors in CSS. It is important to choose the right color scheme for a website to make it visually appealing and easy to use.
