### Working with block elements and objects

Unit 3 - Concept of CSS in the subject of Web Designing

1. Block elements are HTML elements that create a new line on the page and take up the full width available. Examples of block elements include `<div>`, `<p>`, and `<h1>` to `<h6>`.

2. Block elements can be styled using CSS (Cascading Style Sheets) to change their appearance and layout on the page.

3. CSS properties that can be used to style block elements include `width`, `height`, `margin`, `padding`, `border`, `background-color`, and `display`.

4. The `display` property can be used to change the default behavior of block elements. For example, setting `display: inline-block` will cause the element to behave like an inline element, taking up only the space it needs and not creating a new line.

5. Objects in CSS refer to the use of images, videos, and other media within a web page.

6. Objects can be styled using CSS properties such as `object-fit` and `object-position` to control how the media is displayed within its container.

7. The `object-fit` property can be used to specify how the media should be resized to fit its container, with options such as `contain`, `cover`, and `fill`.

8. The `object-position` property can be used to specify the alignment of the media within its container, using values such as `top`, `bottom`, `left`, and `right`.

9. Combining the use of block elements and objects allows for the creation of complex and visually appealing layouts in web design.
