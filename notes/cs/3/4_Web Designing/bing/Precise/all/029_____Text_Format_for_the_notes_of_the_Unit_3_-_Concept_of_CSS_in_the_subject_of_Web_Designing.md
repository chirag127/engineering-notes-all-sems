### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be used to create consistent styling across multiple pages of a website.
6. CSS can be applied to a web page in three ways: inline, internal, and external.
7. Inline styles are applied directly to an HTML element using the `style` attribute.
8. Internal styles are defined within the `style` element in the `head` section of an HTML document.
9. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
10. CSS has a powerful cascading mechanism that allows styles to be inherited from parent elements to child elements.
11. CSS has a rich set of selectors that can be used to target specific elements on a web page.
12. CSS has a wide range of properties that can be used to control the appearance of elements on a web page.
13. CSS3 is the latest version of the CSS specification and introduces many new features, including advanced selectors, animations, and transitions.
