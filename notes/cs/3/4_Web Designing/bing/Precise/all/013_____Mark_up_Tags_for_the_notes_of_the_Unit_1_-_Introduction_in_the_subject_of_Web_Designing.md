### Unit 1 - Introduction: Mark up Tags

- Markup tags are used to define the structure and layout of a web page.
- These tags are enclosed in angle brackets, for example `<tagname>`.
- The most common markup language is HTML (Hypertext Markup Language).
- HTML tags are used to define the different elements of a web page, such as headings, paragraphs, links, images, and lists.
- Some common HTML tags include:
  - `<h1>` to `<h6>`: Used to define headings, with `<h1>` being the largest and `<h6>` being the smallest.
  - `<p>`: Used to define a paragraph.
  - `<a>`: Used to define a hyperlink.
  - `<img>`: Used to embed an image.
  - `<ul>` and `<ol>`: Used to define unordered and ordered lists, respectively.
  - `<li>`: Used to define a list item.
- HTML tags are usually used in pairs, with an opening tag and a closing tag. The closing tag is the same as the opening tag, but with a forward slash before the tag name, for example `</tagname>`.
- Some HTML tags, such as `<img>` and `<br>`, are self-closing and do not require a closing tag.
- HTML tags can also have attributes, which provide additional information about the element. Attributes are defined within the opening tag, for example `<tagname attribute="value">`.
- Some common attributes include `href` for links, `src` for images, and `style` for inline CSS.
- It is important to use proper syntax and nesting when using markup tags, as errors can cause the web page to display incorrectly.
