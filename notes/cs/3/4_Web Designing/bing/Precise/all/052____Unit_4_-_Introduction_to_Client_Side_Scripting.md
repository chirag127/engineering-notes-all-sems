## Unit 4 - Introduction to Client Side Scripting

1. **Client-side scripting** refers to the use of scripts that are executed on the user's web browser, rather than on the web server.
2. These scripts are typically written in a scripting language such as JavaScript, and are used to create dynamic and interactive web pages.
3. Some common uses of client-side scripting include form validation, user interface enhancements, and the creation of dynamic content.
4. Client-side scripts are downloaded and executed by the user's web browser, and can interact with the Document Object Model (DOM) of the web page to manipulate its content.
5. One of the advantages of client-side scripting is that it can reduce the load on the web server, as many tasks can be performed on the client side.
6. However, it is important to note that client-side scripts can be disabled by the user, and may not work on all web browsers. As such, it is important to provide fallback functionality for users who do not have JavaScript enabled.
7. In summary, client-side scripting is a powerful tool for creating dynamic and interactive web pages, but it is important to use it responsibly and provide fallback functionality for users who do not have JavaScript enabled.
