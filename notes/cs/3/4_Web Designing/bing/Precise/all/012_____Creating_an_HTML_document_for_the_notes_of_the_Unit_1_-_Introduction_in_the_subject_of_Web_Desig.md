# Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. **HTML** stands for **HyperText Markup Language** and is used to create the structure and content of web pages.
2. An HTML document is a text file that contains **markup tags** that define the structure and content of the web page.
3. To create an HTML document, you can use a text editor such as **Notepad** or **TextEdit** and save the file with the **.html** extension.
4. The basic structure of an HTML document includes the **DOCTYPE** declaration, the **html** element, the **head** element, and the **body** element.
5. The **DOCTYPE** declaration specifies the version of HTML used in the document and should be the first line of the document.
6. The **html** element is the root element of the HTML page and contains all other elements.
7. The **head** element contains information about the document such as the **title** and **meta** tags.
8. The **body** element contains the main content of the web page and can include text, images, links, and other elements.
9. HTML tags are enclosed in **angle brackets** and usually come in pairs with an opening and closing tag.
10. The content of the web page is placed between the opening and closing tags of the relevant element.
