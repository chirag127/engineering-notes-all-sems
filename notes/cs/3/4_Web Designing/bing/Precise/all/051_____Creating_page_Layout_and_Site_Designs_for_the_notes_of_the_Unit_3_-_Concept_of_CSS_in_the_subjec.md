### Creating Page Layout and Site Designs

Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
2. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
3. CSS allows developers to separate the content of a page from its presentation, making it easier to maintain and update the design of a site.
4. CSS can be used to create a variety of page layouts, including fixed, fluid, and responsive designs.
5. Fixed layouts have a set width and do not change based on the size of the user's screen.
6. Fluid layouts use percentages to define the width of page elements, allowing the layout to adjust to the size of the user's screen.
7. Responsive design uses CSS media queries to apply different styles based on the size of the user's screen, allowing the layout to adapt to different devices.
8. CSS can also be used to create grid and flexbox layouts, which provide more advanced options for positioning and aligning page elements.
9. Site designs can be created using CSS by defining styles for common page elements, such as headers, footers, and navigation menus.
10. CSS frameworks, such as Bootstrap and Foundation, provide pre-designed styles and components that can be used to quickly create a consistent and professional-looking site design.
