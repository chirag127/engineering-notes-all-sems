### Controlling Fonts

1. CSS allows you to control the font family, size, style, and weight of text.
2. The `font-family` property specifies the font for an element. You can specify a list of fonts separated by commas, and the browser will use the first font in the list that is installed on the user's computer.
3. The `font-size` property specifies the size of the font. You can use absolute or relative units to specify the size.
4. The `font-style` property specifies the style of the font, such as italic or oblique.
5. The `font-weight` property specifies the weight of the font, such as normal or bold.
6. You can also use the `font` shorthand property to specify multiple font properties in one declaration.
