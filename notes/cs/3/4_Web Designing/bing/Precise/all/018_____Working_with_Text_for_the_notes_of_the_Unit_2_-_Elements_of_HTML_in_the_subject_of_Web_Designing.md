### Working with Text

#### Unit 2 - Elements of HTML

1. HTML stands for HyperText Markup Language and is used to structure content on the web.
2. HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear or act in a certain way.
3. The enclosing tags can make a word or image hyperlink to somewhere else, can italicize words, can make the font bigger or smaller, and so on.
4. Some of the most common text elements in HTML include headings, paragraphs, lists, links, and text formatting elements such as bold and italic.
5. Headings are defined with the `<h1>` to `<h6>` tags, with `<h1>` being the largest and `<h6>` being the smallest.
6. Paragraphs are defined with the `<p>` tag.
7. Lists can be either ordered or unordered. Ordered lists are defined with the `<ol>` tag and unordered lists with the `<ul>` tag. List items are defined with the `<li>` tag.
8. Links are defined with the `<a>` tag and the `href` attribute is used to specify the URL of the page the link goes to.
9. Text formatting elements include `<b>` for bold, `<i>` for italic, `<u>` for underline, and `<strike>` for strikethrough.
10. It is important to use these elements correctly and appropriately to ensure that the content is structured and accessible to all users.
