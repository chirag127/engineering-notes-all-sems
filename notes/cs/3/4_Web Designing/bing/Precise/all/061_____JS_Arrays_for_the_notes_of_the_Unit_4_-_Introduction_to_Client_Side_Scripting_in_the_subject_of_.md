### JS Arrays

#### Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

1. An array is a data structure that can store a collection of values.
2. In JavaScript, an array is an object that can store multiple values of different data types.
3. The values in an array are called elements and are stored in a contiguous block of memory.
4. The elements in an array are accessed using an index, which starts from 0.
5. The length property of an array returns the number of elements in the array.
6. The push() method can be used to add an element to the end of an array.
7. The pop() method can be used to remove the last element from an array.
8. The shift() method can be used to remove the first element from an array.
9. The unshift() method can be used to add an element to the beginning of an array.
10. The splice() method can be used to add or remove elements from an array at a specific index.
11. The slice() method can be used to create a new array by copying a portion of an existing array.
12. The concat() method can be used to merge two or more arrays into a new array.
13. The join() method can be used to convert an array into a string by concatenating its elements.
14. The forEach() method can be used to iterate over the elements of an array.
15. The map() method can be used to create a new array by applying a function to each element of an existing array.
16. The filter() method can be used to create a new array containing only the elements of an existing array that satisfy a specified condition.
17. The reduce() method can be used to apply a function to each element of an array and reduce it to a single value.
18. The every() method can be used to check if all elements in an array satisfy a specified condition.
19. The some() method can be used to check if at least one element in an array satisfies a specified condition.
20. The find() method can be used to find the first element in an array that satisfies a specified condition.
21. The findIndex() method can be used to find the index of the first element in an array that satisfies a specified condition.
22. The includes() method can be used to check if an array contains a specified value.
23. The indexOf() method can be used to find the index of the first occurrence of a specified value in an array.
24. The lastIndexOf() method can be used to find the index of the last occurrence of a specified value in an array.
25. The sort() method can be used to sort the elements of an array in ascending or descending order.
26. The reverse() method can be used to reverse the order of the elements in an array.
27. The fill() method can be used to fill all the elements of an array with a specified value.
28. The copyWithin() method can be used to copy a sequence of elements within an array to a new position.
29. The from() method can be used to create a new array from an array-like or iterable object.
30. The of() method can be used to create a new array from a variable number of arguments.
31. The isArray() method can be used to check if a value is an array.
32. The Array constructor can be used to create a new array.
33. The spread operator (...) can be used to spread the elements of an array into a new array or function arguments.
34. The destructuring assignment syntax can be used to extract values from an array and assign them to variables.
35. The for...of loop can be used to iterate over the values of an array.
36. The for...in loop can be used to iterate over the indices of an array.
37. The entries() method can be used to create an iterator object that contains the key/value pairs for each element in an array.
38. The keys() method can be used to create an iterator object that contains the keys for each element in an array.
39. The values() method can be used to create an iterator object that contains the values for each element in an array.
40. The flat() method can be used to create a new array with all sub-array elements concatenated into it recursively up to a specified depth.
41. The flatMap() method can be used to first map each element using a mapping function, then flatten the result into a new array.
