# Unit 5 - Web Hosting

### Web Hosting Basics

1. **Web hosting** is a service that allows individuals and organizations to make their website accessible on the internet.
2. A **web host** is a company that provides the technology and services necessary for a website to be viewed on the internet.
3. Websites are stored on **servers**, which are powerful computers that are connected to the internet.
4. When someone wants to view a website, their computer sends a request to the server where the website is stored, and the server sends the website's files back to the user's computer.
5. There are several types of web hosting, including **shared hosting**, **dedicated hosting**, **virtual private server (VPS) hosting**, and **cloud hosting**.
6. The type of hosting that is best for a website depends on factors such as the website's traffic, the resources required to run the website, and the website owner's budget.
7. It is important to choose a reliable web host that can provide good uptime, fast loading speeds, and adequate security measures.
8. Some web hosts also offer additional services such as email hosting, domain registration, and website building tools.
9. When choosing a web host, it is important to consider the host's reputation, customer support, and the features and services that they offer.
10. It is also a good idea to read reviews and compare the prices and features of different web hosts before making a decision.
