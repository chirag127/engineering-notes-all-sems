# Variables in JavaScript

Variables are used to store data values in JavaScript. They are declared using the `var`, `let`, or `const` keyword.

- `var`: used to declare a variable with a function scope or global scope.
- `let`: used to declare a variable with a block scope.
- `const`: used to declare a variable with a block scope, whose value cannot be reassigned.

Here are some key points to remember about variables in JavaScript:

1. Variable names are case-sensitive and must begin with a letter, underscore, or dollar sign.
2. Variables can store different data types, including numbers, strings, and objects.
3. The value of a variable can be changed by assigning a new value to it.
4. Variables declared with `var` are hoisted to the top of their scope.
5. Variables declared with `let` and `const` are not hoisted.
6. It is a good practice to use `let` and `const` instead of `var` to avoid issues with hoisting and to make the code more readable.
