# Unit 1 - Introduction to Responsive Web Designing

Responsive web design is an approach to web design that makes web pages render well on a variety of devices and window or screen sizes. This is achieved through the use of fluid grids, flexible images, and media queries.

1. **Fluid Grids:** A fluid grid is a layout system that uses percentages instead of fixed pixel values to define the size of page elements. This allows the layout to adapt to different screen sizes.

2. **Flexible Images:** Flexible images are images that can scale and change their aspect ratio depending on the size of the screen. This is achieved by setting the max-width property of the image to 100%.

3. **Media Queries:** Media queries are a CSS technique that allows you to apply different styles to a page depending on the characteristics of the device it is being viewed on. This can include the screen size, orientation, and resolution.

Responsive web design is important because it allows users to access your website on a variety of devices, from desktop computers to smartphones, without sacrificing the user experience. This can improve the accessibility of your website and increase user engagement.
