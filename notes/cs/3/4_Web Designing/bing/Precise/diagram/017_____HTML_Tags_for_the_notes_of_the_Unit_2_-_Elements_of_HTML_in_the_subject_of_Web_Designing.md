# Unit 2 - Elements of HTML

## HTML Tags

- HTML (Hypertext Markup Language) is the standard markup language for creating web pages and other information that can be displayed in a web browser.
- HTML consists of a series of elements or tags that are used to structure and format the content of a web page.
- The most common HTML tags include:
  - `<html>`: This tag is used to define the root of an HTML document and is the container for all other HTML elements.
  - `<head>`: This tag is used to define the head section of an HTML document and contains information about the page such as the title, meta information, and links to stylesheets and scripts.
  - `<body>`: This tag is used to define the body section of an HTML document and contains the main content of the page.
  - `<h1>` to `<h6>`: These tags are used to define headings, with `<h1>` being the highest level heading and `<h6>` being the lowest level heading.
  - `<p>`: This tag is used to define a paragraph of text.
  - `<a>`: This tag is used to define a hyperlink, which is used to link to another page or resource.
  - `<img>`: This tag is used to embed an image into an HTML page.
  - `<ul>` and `<ol>`: These tags are used to define unordered and ordered lists, respectively.
  - `<li>`: This tag is used to define a list item within an unordered or ordered list.
  - `<table>`: This tag is used to define a table.
  - `<tr>`: This tag is used to define a row within a table.
  - `<th>`: This tag is used to define a header cell within a table row.
  - `<td>`: This tag is used to define a data cell within a table row.
  - `<form>`: This tag is used to define a form that allows users to input data and submit it to a server for processing.
  - `<input>`: This tag is used to define an input field where users can enter data.
  - `<label>`: This tag is used to define a label for an input element.
  - `<select>`: This tag is used to define a drop-down list.
  - `<option>`: This tag is used to define an option within a drop-down list.
  - `<textarea>`: This tag is used to define a multi-line input field.
  - `<button>`: This tag is used to define a clickable button.
- These are just some of the most common HTML tags. There are many more tags available to structure and format the content of a web page.
