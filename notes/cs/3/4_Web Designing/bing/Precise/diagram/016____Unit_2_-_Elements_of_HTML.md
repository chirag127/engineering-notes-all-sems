## Unit 2 - Elements of HTML

HTML (Hypertext Markup Language) is the standard markup language for creating web pages and other information that can be displayed in a web browser. HTML consists of a series of elements, which are used to enclose, or wrap, different parts of the content to make it appear a certain way or act a certain way.

Some common HTML elements include:

1. `<p>`: The paragraph element, used to define a block of text.
2. `<a>`: The anchor element, used to create a hyperlink to another web page or resource.
3. `<img>`: The image element, used to embed an image in the web page.
4. `<ul>` and `<li>`: The unordered list and list item elements, used to create a bulleted list.
5. `<ol>` and `<li>`: The ordered list and list item elements, used to create a numbered list.
6. `<table>`, `<tr>`, `<th>`, and `<td>`: The table, table row, table header, and table data elements, used to create a table.

These are just a few examples of the many HTML elements available. Each element has its own specific purpose and attributes that can be used to further customize its behavior and appearance. By combining different elements and attributes, web developers can create complex and dynamic web pages.
