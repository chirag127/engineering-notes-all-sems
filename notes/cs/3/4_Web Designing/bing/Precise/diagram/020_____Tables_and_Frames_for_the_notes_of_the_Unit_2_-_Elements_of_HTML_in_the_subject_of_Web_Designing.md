### Unit 2 - Elements of HTML: Tables and Frames

#### Tables
- Tables are used to organize and present data in a structured manner.
- The `<table>` tag is used to create a table.
- The `<tr>` tag is used to define a table row.
- The `<td>` tag is used to define a table cell.
- The `<th>` tag is used to define a table header cell.
- The `colspan` and `rowspan` attributes can be used to merge cells horizontally and vertically, respectively.

#### Frames
- Frames are used to divide a web page into multiple sections, each of which can display a different HTML document.
- The `<frameset>` tag is used to define a frameset.
- The `<frame>` tag is used to define a frame within a frameset.
- The `src` attribute is used to specify the URL of the document to be displayed in the frame.
- The `name` attribute is used to specify a name for the frame, which can be used as the target for links.
- The `noresize` attribute can be used to prevent the user from resizing the frame.
