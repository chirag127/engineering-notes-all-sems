### Unit 4 - Introduction to Client Side Scripting: JavaScript Loops

JavaScript loops are used to repeatedly run a block of code until a certain condition is met. There are several types of loops in JavaScript, including:

1. **For loop:** A for loop repeats until a specified condition evaluates to false. The syntax for a for loop is:
```
for ([initialization]; [condition]; [final-expression]) {
   // code block to be executed
}
```
2. **While loop:** A while loop repeats while a specified condition is true. The syntax for a while loop is:
```
while (condition) {
  // code block to be executed
}
```
3. **Do...while loop:** A do...while loop is similar to a while loop, except that it is guaranteed to execute at least once. The syntax for a do...while loop is:
```
do {
  // code block to be executed
} while (condition);
```
4. **For...in loop:** A for...in loop iterates over the enumerable properties of an object. The syntax for a for...in loop is:
```
for (variable in object) {
  // code block to be executed
}
```
5. **For...of loop:** A for...of loop iterates over the values of an iterable object. The syntax for a for...of loop is:
```
for (variable of object) {
  // code block to be executed
}
```
These loops provide a powerful and flexible way to iterate over data and perform repetitive tasks in JavaScript. It is important to use the appropriate type of loop for the task at hand to ensure efficient and effective code.
