### Working with Lists and Tables

Unit 3 - Concept of CSS in the subject of Web Designing

1. Lists and tables are common elements in web design and can be styled using CSS.
2. Lists can be either ordered or unordered. Ordered lists use numbers to indicate the order of the items, while unordered lists use bullet points.
3. CSS can be used to change the appearance of the list markers, as well as the spacing and indentation of the list items.
4. Tables are used to display data in a structured format. They consist of rows and columns, with each cell containing a piece of data.
5. CSS can be used to style various aspects of a table, including the borders, background colors, and text alignment.
6. It is important to use semantic HTML when creating lists and tables, as this helps to ensure that the content is accessible to all users, including those using assistive technologies.
7. CSS can also be used to create responsive tables, which adjust their layout based on the size of the screen. This can help to ensure that the table remains readable on smaller devices.
