### Defining Name Servers

- A name server is a computer application that implements a network service for providing responses to queries against a directory service.
- It translates an often humanly-meaningful, text-based identifier to a system-internal, often numeric identification or addressing component.
- This service is performed by the server in response to a service protocol request.
- An example of a name server is the server component of the Domain Name System (DNS), one of the two principal name spaces of the Internet.
- The most important function of DNS servers is the translation of human-readable domain names and hostnames into the corresponding numeric Internet Protocol (IP) addresses.
- Name servers are a fundamental part of the Domain Name System.
- They allow users to access websites using domain names instead of IP addresses.
- Name servers are typically provided by web hosting companies or Internet service providers (ISPs).
- When a user enters a domain name into their web browser, the browser sends a request to the name server to resolve the domain name into an IP address.
- The name server then returns the IP address to the browser, which uses it to connect to the web server hosting the website associated with the domain name.
- In summary, name servers play a crucial role in enabling users to access websites using human-readable domain names instead of numerical IP addresses. They are an essential component of the Domain Name System and are typically provided by web hosting companies or ISPs.
