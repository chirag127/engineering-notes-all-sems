### Controlling Fonts

1. CSS allows you to control the font family, size, weight, style, and color of text.
2. The `font-family` property specifies the font for an element. You can specify a list of fonts separated by commas, and the browser will use the first font in the list that is installed on the user's computer.
3. The `font-size` property specifies the size of the font. You can specify the size in pixels, points, ems, or percentages.
4. The `font-weight` property specifies the weight of the font. Common values are normal and bold.
5. The `font-style` property specifies the style of the font. Common values are normal, italic, and oblique.
6. The `color` property specifies the color of the text. You can specify the color using a color name, a hexadecimal value, or an RGB value.
