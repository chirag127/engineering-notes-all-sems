### Pseudo class

- A pseudo-class is a keyword added to a selector that specifies a special state of the selected element(s).
- Pseudo-classes are used to define the style for elements in a specific state, such as when an element is being hovered over by the mouse pointer.
- Pseudo-classes are added to selectors by using a colon (`:`) followed by the pseudo-class name.
- Some common pseudo-classes include `:hover`, `:active`, `:visited`, and `:first-child`.
- Pseudo-classes can be combined with other selectors to create more specific styles. For example, `a:hover` would apply a style to all `a` elements when they are being hovered over by the mouse pointer.
- Pseudo-classes can also be used with pseudo-elements to create even more specific styles. For example, `p::first-letter` would apply a style to the first letter of all `p` elements.
- Pseudo-classes are an important concept in CSS and can be used to create dynamic and interactive styles for web pages.
