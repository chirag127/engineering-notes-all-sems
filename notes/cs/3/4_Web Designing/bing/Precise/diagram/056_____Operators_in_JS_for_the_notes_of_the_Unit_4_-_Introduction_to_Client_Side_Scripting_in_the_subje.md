### Unit 4 - Introduction to Client Side Scripting: Operators in JavaScript

JavaScript has several types of operators that allow you to manipulate values. Here are some of the most commonly used operators:

1. **Arithmetic Operators**: These operators perform basic arithmetic operations such as addition, subtraction, multiplication, and division. Examples include `+`, `-`, `*`, and `/`.

2. **Assignment Operators**: These operators assign values to variables. The most basic assignment operator is `=`, which assigns the value of the right operand to the variable on the left. There are also compound assignment operators that perform an operation and assignment in one step, such as `+=` and `-=`.

3. **Comparison Operators**: These operators compare two values and return a Boolean value indicating whether the comparison is true or false. Examples include `==`, `!=`, `>`, `<`, `>=`, and `<=`.

4. **Logical Operators**: These operators perform logical operations and return a Boolean value. The most commonly used logical operators are `&&` (logical AND), `||` (logical OR), and `!` (logical NOT).

5. **String Operators**: JavaScript has one string operator, the `+` operator, which can be used to concatenate two strings.

6. **Ternary Operator**: The ternary operator is a shorthand way of writing an `if...else` statement. It takes three operands and returns a value based on a condition. The syntax is `condition ? valueIfTrue : valueIfFalse`.

7. **Type Operators**: These operators return information about the data type of a value. The `typeof` operator returns a string indicating the type of a value, while the `instanceof` operator returns a Boolean value indicating whether an object is an instance of a particular constructor.

These are some of the most commonly used operators in JavaScript. Understanding how to use them is essential for writing effective and efficient code.
