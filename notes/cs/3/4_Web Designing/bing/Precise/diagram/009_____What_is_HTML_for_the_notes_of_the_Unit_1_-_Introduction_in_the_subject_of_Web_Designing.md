### Unit 1 - Introduction: What is HTML

- HTML stands for HyperText Markup Language.
- It is the standard markup language for creating web pages and other information that can be displayed in a web browser.
- HTML is used to structure content and give meaning to the data on a web page by defining that content as, for example, headings, paragraphs, or images.
- HTML code is saved in a file with the .html or .htm extension and is interpreted by a web browser to display the content in a formatted manner.
- HTML is not a programming language, but rather a markup language that uses tags to describe the structure and presentation of the content.
- HTML is constantly evolving, with new versions being released to add new features and improve the language. The current version of HTML is HTML5.
