### Domains and Hosting

#### Unit 1 - Introduction

- A domain name is the address of a website that people type in the browser URL bar to visit the website.
- Domain names are used to identify one or more IP addresses.
- Domain names are used in URLs to identify particular Web pages.
- Every domain name has a suffix that indicates which top-level domain (TLD) it belongs to.
- There are only a limited number of such domains, including .com, .org, .net, .edu, and .gov.
- A domain name must be registered before it can be used.
- Domain registration is the process of acquiring a domain name from a domain name registrar.
- Web hosting is the service of providing storage space and access for websites.
- Web hosting makes it possible for visitors to view a website's content when they type in the domain name.
- Web hosts are companies that provide space on a server owned or leased for use by clients, as well as providing Internet connectivity, typically in a data center.
- Web hosting can be obtained through a hosting provider or by self-hosting.
- There are various types of web hosting services available, including shared hosting, dedicated hosting, and virtual private server (VPS) hosting.
