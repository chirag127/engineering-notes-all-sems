## Unit 4 - Introduction to Client Side Scripting

1. **Client-side scripting** refers to the use of scripts that are executed on the user's web browser, rather than on the web server.
2. These scripts are typically written in languages such as **JavaScript**, and are used to create dynamic and interactive web pages.
3. Some common uses of client-side scripting include form validation, user interface enhancements, and the creation of dynamic content.
4. Client-side scripts are executed by the user's web browser, and can be used to manipulate the **Document Object Model (DOM)** of the web page.
5. This allows developers to create web pages that can change in response to user input, without the need for a round trip to the server.
6. Client-side scripting can also be used to improve the performance of web pages, by reducing the number of requests sent to the server.
7. However, it is important to note that client-side scripts can be disabled by the user, and may not be supported by all web browsers.
8. As such, it is important to ensure that web pages are still functional without the use of client-side scripts.
