### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be applied to a web page in three ways: inline, internal, and external.
6. Inline styles are applied directly to an HTML element using the `style` attribute.
7. Internal styles are defined within the `style` element in the `head` section of an HTML document.
8. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
9. CSS uses a set of rules to apply styles to HTML elements. These rules are made up of selectors and declarations.
10. Selectors are used to specify which HTML elements a set of CSS rules should apply to.
11. Declarations are used to define the styles that should be applied to the selected elements. They are made up of a property and a value, separated by a colon.
12. CSS has a wide range of properties that can be used to control the appearance of HTML elements, including `color`, `font-size`, `background-color`, `margin`, and `padding`.
13. CSS also provides a number of advanced features, such as the ability to create animations and transitions, and to apply styles based on the size of the user's screen.
