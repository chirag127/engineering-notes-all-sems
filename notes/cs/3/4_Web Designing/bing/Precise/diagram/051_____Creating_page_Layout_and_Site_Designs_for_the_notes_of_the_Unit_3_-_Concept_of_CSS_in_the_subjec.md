### Creating Page Layout and Site Designs

Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
2. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
3. CSS allows you to create rules that specify how the content of elements within an HTML page should be displayed.
4. CSS can be used to create a consistent look and feel across multiple pages of a website.
5. CSS can be used to create responsive designs that adapt to different screen sizes and devices.
6. CSS can be used to create grid-based layouts, which provide a flexible way to arrange content on a page.
7. CSS can be used to create multi-column layouts, which can be used to create magazine-style layouts.
8. CSS can be used to create flexible box layouts, which provide a way to distribute space and align content within a container.
9. CSS can be used to create positioning layouts, which allow you to precisely control the position of elements on a page.
10. CSS can be used to create animations and transitions, which can add visual interest to a page.
