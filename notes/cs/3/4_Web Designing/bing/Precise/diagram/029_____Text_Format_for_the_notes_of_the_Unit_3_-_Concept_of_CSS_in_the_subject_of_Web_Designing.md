### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is a stylesheet language used to describe the presentation of a document written in a markup language like HTML.
3. CSS is used to define the visual appearance of web pages, including colors, layout, and fonts.
4. CSS allows developers to separate the content of a web page from its presentation, making it easier to maintain and update.
5. CSS can be applied to a web page in three ways: inline, internal, and external.
6. Inline styles are applied directly to an HTML element using the `style` attribute.
7. Internal styles are defined within the `style` element in the `head` section of an HTML document.
8. External styles are defined in a separate CSS file and linked to an HTML document using the `link` element.
9. CSS uses a set of rules to apply styles to elements on a web page.
10. CSS rules consist of a selector and a declaration block.
11. The selector specifies which elements the rule applies to, and the declaration block contains one or more declarations that define the styles to be applied.
12. CSS declarations consist of a property and a value, separated by a colon.
13. CSS properties are used to define the visual appearance of an element, such as its color, font, or layout.
14. CSS values specify the value to be applied to the property, such as a color name, a length, or a percentage.
15. CSS also provides a set of pseudo-classes and pseudo-elements that allow developers to apply styles to specific states or parts of an element.
16. CSS has a powerful inheritance mechanism that allows styles to be inherited from parent elements to their children.
17. CSS also provides a set of cascading rules that determine how conflicting styles are resolved.
18. CSS has evolved over time, with new versions adding new features and capabilities.
19. The latest version of CSS is CSS3, which adds new features such as animations, transitions, and transformations.
20. CSS is an essential part of web design and development, and is widely used by developers to create visually appealing and functional web pages.
