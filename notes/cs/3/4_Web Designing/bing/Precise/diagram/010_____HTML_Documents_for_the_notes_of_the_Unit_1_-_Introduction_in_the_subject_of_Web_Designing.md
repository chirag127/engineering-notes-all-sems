### HTML Documents

HTML (Hypertext Markup Language) is the standard markup language for creating web pages and other information that can be displayed in a web browser. HTML documents are text files that contain a combination of content and markup tags that describe the structure and formatting of the content.

Here are some key points to remember when working with HTML documents:

1. HTML documents are saved with the `.html` or `.htm` file extension.
2. The basic structure of an HTML document includes the `<!DOCTYPE html>` declaration, the `<html>` element, the `<head>` element, and the `<body>` element.
3. The `<!DOCTYPE html>` declaration specifies that the document is an HTML5 document.
4. The `<html>` element is the root element of an HTML page and contains all other elements.
5. The `<head>` element contains metadata about the document, such as the title and links to stylesheets.
6. The `<body>` element contains the main content of the document, such as text, images, and links.
7. HTML tags are used to mark up the content and provide information about its structure and formatting.
8. HTML tags are enclosed in angle brackets (`<` and `>`) and are case-insensitive.
9. Most HTML tags have an opening tag and a closing tag, with the content in between. For example, `<p>This is a paragraph.</p>`.
10. Some HTML tags are self-closing and do not require a closing tag. For example, `<img src="image.jpg" alt="An image">`.
