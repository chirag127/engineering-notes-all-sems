### Image Sprites

- An image sprite is a collection of images put into a single image.
- Using image sprites reduces the number of server requests and saves bandwidth.
- Image sprites are used in web design to combine multiple small images into one larger image.
- This technique is commonly used for icons, buttons, and other user interface elements.
- To display a specific image from the sprite, the CSS `background-image` and `background-position` properties are used.
- The `background-image` property specifies the sprite image, while the `background-position` property specifies the position of the image within the sprite.
- By changing the `background-position` property, different images from the sprite can be displayed.
- This technique can improve the performance of a website by reducing the number of HTTP requests needed to load the page.
