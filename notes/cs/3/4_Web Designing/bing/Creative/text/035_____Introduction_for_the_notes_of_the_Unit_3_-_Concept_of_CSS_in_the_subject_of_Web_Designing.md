### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets. It is a language that defines how HTML elements are displayed on a web page.
- CSS can be used to control the layout, colors, fonts, backgrounds, borders, margins, padding, and other aspects of the presentation of a web page.
- CSS can be applied to HTML elements in three ways: inline, internal, and external.
  - Inline CSS is written inside the style attribute of an HTML element. It affects only that element and has the highest priority.
  - Internal CSS is written inside the style element in the head section of an HTML document. It affects all the elements in that document and has the second highest priority.
  - External CSS is written in a separate file with the .css extension and linked to an HTML document using the link element in the head section. It affects all the elements in the linked document and has the lowest priority.
- CSS can also be imported from another file using the @import rule in an internal or external style sheet.
- CSS follows a set of rules and syntax to specify the selectors, properties, and values that define the style of an element.
  - A selector is a pattern that matches one or more elements in an HTML document. It can be an element name, a class name, an id name, an attribute, a pseudo-class, a pseudo-element, or a combination of these.
  - A property is a name that specifies an aspect of the presentation of an element, such as color, font-size, or border-width.
  - A value is a data type that defines the value of a property, such as red, 16px, or solid.
  - A declaration is a pair of a property and a value, separated by a colon and ending with a semicolon, such as color: red;.
  - A declaration block is a group of one or more declarations, enclosed by curly braces, such as {color: red; font-size: 16px;}.
  - A rule set is a combination of a selector and a declaration block, such as p {color: red; font-size: 16px;}.
- CSS can be used to create various effects and animations on a web page, such as transitions, transforms, filters, and keyframes.
- CSS can also be used to create responsive web design, which adapts to different screen sizes and devices, using media queries, flexbox, grid, and other techniques.
