### CSS Color

- CSS color is a property that sets the color of an element's text, background, border, or other parts.
- CSS color can be specified by using a predefined color name, a hexadecimal value, an RGB value, an HSL value, or a color keyword.
- Predefined color names are the simplest way to specify a color in CSS. There are 140 color names defined in the CSS specification, such as `red`, `green`, `blue`, `black`, `white`, etc. For example, `color: red;` sets the text color to red.
- Hexadecimal values are six-digit codes that represent the amount of red, green, and blue in a color. They start with a `#` sign, followed by three pairs of hexadecimal digits from 00 to FF. For example, `#FF0000` is pure red, `#00FF00` is pure green, and `#0000FF` is pure blue. Hexadecimal values can also be shortened to three digits if each pair is the same, such as `#F00` for red, `#0F0` for green, and `#00F` for blue.
- RGB values are numerical values that specify the amount of red, green, and blue in a color. They are written as `rgb(red, green, blue)`, where each value can range from 0 to 255. For example, `rgb(255, 0, 0)` is pure red, `rgb(0, 255, 0)` is pure green, and `rgb(0, 0, 255)` is pure blue. RGB values can also be written as percentages, such as `rgb(100%, 0%, 0%)` for red, `rgb(0%, 100%, 0%)` for green, and `rgb(0%, 0%, 100%)` for blue.
- HSL values are numerical values that specify the hue, saturation, and lightness of a color. They are written as `hsl(hue, saturation, lightness)`, where hue is an angle from 0 to 360 degrees, saturation is a percentage from 0% to 100%, and lightness is a percentage from 0% to 100%. For example, `hsl(0, 100%, 50%)` is pure red, `hsl(120, 100%, 50%)` is pure green, and `hsl(240, 100%, 50%)` is pure blue. HSL values can also be written with an alpha channel, which specifies the opacity of the color, such as `hsla(0, 100%, 50%, 0.5)` for semi-transparent red.
- Color keywords are predefined words that represent a specific color. They are not case-sensitive and can be used as an alternative to color names or values. There are 17 color keywords defined in the CSS specification, such as `aqua`, `fuchsia`, `lime`, `maroon`, `navy`, etc. For example, `color: lime;` sets the text color to lime green. Color keywords can also be written with an alpha channel, such as `limea(0.5)` for semi-transparent lime green.
