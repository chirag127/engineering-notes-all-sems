## Unit 3 - Concept of CSS

- CSS stands for **Cascading Style Sheets** .
- CSS describes how HTML elements are to be displayed on screen, paper, or in other media .
- CSS saves a lot of work by controlling the layout of multiple web pages all at once.
- CSS is a rule-based language that specifies groups of styles that should be applied to particular elements or groups of elements on your web page.
- CSS has a syntax and forms of the language that define the selectors, properties, values, and functional notations.
- CSS has key concepts such as specificity, inheritance, and the cascade that determine how the styles are applied and resolved.
- CSS has units and values that can be used to specify lengths, colors, angles, functions, and more.
- CSS has a box model that defines how the content, padding, border, and margin of each element are calculated and rendered.
- CSS has a containing block that establishes the coordinate system and constraints for the layout of each element.
- CSS has stacking and block-formatting contexts that affect the positioning and overlapping of elements.
- CSS has initial, computed, used, and actual values that represent the different stages of style computation and application.
- CSS has shorthand properties that allow you to set multiple related properties with one declaration.
- CSS has layout modules such as flexbox and grid that enable you to create complex and responsive layouts with ease.
