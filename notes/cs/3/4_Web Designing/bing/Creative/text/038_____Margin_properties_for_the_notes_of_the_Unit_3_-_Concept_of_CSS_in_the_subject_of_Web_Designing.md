### Margin properties

- The CSS margin properties are used to create space around elements, outside of any defined borders.
- With CSS, you have full control over the margins. There are properties for setting the margin for each side of an element (top, right, bottom, and left).
- The margin property is a shorthand for four subproperties: margin-top, margin-right, margin-bottom, and margin-left.
- The margin property can have one, two, three, or four values:
  - One value: applies to all four sides.
  - Two values: the first value applies to the top and bottom margins, the second value applies to the left and right margins.
  - Three values: the first value applies to the top margin, the second value applies to the left and right margins, the third value applies to the bottom margin.
  - Four values: the values apply to the top, right, bottom, and left margins in that order.
- The margin property can have the following values :
  - auto: the browser calculates the margin.
  - length: specifies a margin in px, pt, cm, etc.
  - percentage: specifies a margin in percentage of the width of the containing element.
  - initial: sets the margin to its default value.
  - inherit: inherits the margin from its parent element.
- The margin property can also be used to center an element horizontally by setting the left and right margins to auto.
- The top and bottom margins of elements are sometimes collapsed into a single margin that is equal to the largest of the two margins. This does not happen on horizontal (left and right) margins. Only vertical (top and bottom) margins.
- The margin property can create negative space by using negative values. This can be useful for overlapping elements or creating gaps between elements.
