### Working with Text

- Text is the most common element of HTML documents. It can be formatted using various HTML tags and attributes.
- HTML tags are keywords enclosed in angle brackets (< and >) that define the structure and meaning of the text. For example, `<p>` defines a paragraph, `<h1>` defines a heading level 1, and `<em>` defines emphasized text.
- HTML attributes are additional information that modify the behavior or appearance of the tags. They are written inside the opening tag, after the tag name, in the form of name="value" pairs. For example, `<p align="center">` aligns the paragraph text to the center, and `<img src="logo.png" alt="Logo">` specifies the source and alternative text for an image.
- HTML tags can be nested, meaning that one tag can contain another tag inside it. For example, `<p>This is a <strong>bold</strong> text.</p>` makes the word "bold" appear in bold font. The inner tag is called the child tag, and the outer tag is called the parent tag. The child tag inherits the properties of the parent tag, unless specified otherwise.
- HTML tags can be either block-level or inline-level. Block-level tags create a new line and occupy the entire width of the container. For example, `<p>`, `<h1>`, and `<div>` are block-level tags. Inline-level tags do not create a new line and only occupy the space needed by the content. For example, `<span>`, `<em>`, and `<img>` are inline-level tags.
- HTML text can be formatted using various tags and attributes, such as:

  - `<b>` and `<strong>` for bold text
  - `<i>` and `<em>` for italic text
  - `<u>` and `<ins>` for underlined text
  - `<s>` and `<del>` for strikethrough text
  - `<sub>` and `<sup>` for subscript and superscript text
  - `<small>` and `<big>` for smaller and bigger text
  - `<pre>` and `<code>` for preformatted and code text
  - `<q>` and `<blockquote>` for quoted text
  - `<cite>` and `<abbr>` for citation and abbreviation text
  - `<mark>` and `<span>` for highlighted and styled text
  - `<br>` and `<wbr>` for line breaks and word breaks
  - `<hr>` for horizontal rules
  - `<font>` and `<style>` for font and style attributes (deprecated in HTML5)
