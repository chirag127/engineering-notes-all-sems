### Box Model

- The box model is a concept that describes how the size and spacing of HTML elements are calculated by the browser.
- Every HTML element is treated as a rectangular box, with four properties: width, height, padding and border.
- The width and height properties specify the content area of the box, which is the area where the text and images are displayed.
- The padding property specifies the space between the content area and the border of the box, which can be used to create some breathing room for the content.
- The border property specifies the thickness and style of the line that surrounds the box, which can be used to create visual boundaries or effects.
- There is another property called margin, which specifies the space outside the border of the box, which can be used to create gaps between adjacent boxes or to align the boxes within a container.
- The total size of a box is determined by adding up the width, height, padding, border and margin properties. This is called the box-sizing model.
- By default, the box-sizing model is content-box, which means that the width and height properties only apply to the content area of the box, and the padding and border are added on top of that.
- Alternatively, the box-sizing model can be set to border-box, which means that the width and height properties include the padding and border of the box, and the content area is reduced accordingly.
- The box-sizing model can be changed by using the CSS property box-sizing, which can take the values content-box or border-box.
- The box model can be visualized by using the browser's developer tools, which can show the dimensions and spacing of each box on the web page.
