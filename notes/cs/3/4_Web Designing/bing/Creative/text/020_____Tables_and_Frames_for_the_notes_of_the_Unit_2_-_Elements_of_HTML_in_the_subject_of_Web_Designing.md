### Tables and Frames for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

- Tables are used to display data in rows and columns in HTML documents.
- Tables are created using the `<table>` tag, which contains one or more `<tr>` tags for table rows, and one or more `<td>` tags for table cells.
- Tables can also have table headers, which are created using the `<th>` tag, and table captions, which are created using the `<caption>` tag.
- Tables can be styled using various attributes, such as `border`, `cellpadding`, `cellspacing`, `align`, `valign`, `bgcolor`, `colspan`, and `rowspan`.
- Frames are used to divide a web page into multiple sections, each of which can display a different HTML document.
- Frames are created using the `<frameset>` tag, which contains one or more `<frame>` tags for each section.
- Frames can also have a title, which is created using the `<title>` tag, and a noframes section, which is created using the `<noframes>` tag, to provide alternative content for browsers that do not support frames.
- Frames can be styled using various attributes, such as `rows`, `cols`, `frameborder`, `scrolling`, `marginwidth`, `marginheight`, `name`, and `src`.
- Tables and frames are useful for organizing and presenting information in a web page, but they also have some limitations and drawbacks, such as:
  - Tables can be difficult to maintain and update, especially if they contain a large amount of data or complex layouts.
  - Tables can affect the loading speed and performance of a web page, as they require more HTML code and rendering time than other elements.
  - Tables can be inaccessible to some users, such as those who use screen readers or text-only browsers, if they are not properly marked up with semantic tags and attributes.
  - Frames can cause navigation and bookmarking problems, as they do not have a unique URL for each section, and they can break the back and forward buttons of the browser.
  - Frames can affect the usability and compatibility of a web page, as they can create scrollbars within scrollbars, and they can be incompatible with some browsers or devices.
