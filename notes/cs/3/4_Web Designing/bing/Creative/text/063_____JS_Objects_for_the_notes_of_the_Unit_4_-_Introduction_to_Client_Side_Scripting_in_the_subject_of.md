### JS Objects

- An object is a collection of properties that store data and functions that perform actions.
- An object can be created using the object literal syntax, which consists of a pair of curly braces `{}` and a comma-separated list of property names and values.
- A property name can be any valid identifier or a string literal, and a property value can be any valid expression, including another object.
- A property can be accessed using the dot notation `object.property` or the bracket notation `object["property"]`.
- A property can be added, modified, or deleted using the assignment operator `=` or the `delete` operator.
- A function that is stored as a property of an object is called a method. A method can be invoked using the dot notation `object.method()` or the bracket notation `object["method"]()`.
- A method can access the object that it belongs to using the `this` keyword, which refers to the current object in the context of the method call.
- An object can be used to model real-world entities, such as a person, a car, a book, etc. by defining properties and methods that describe their attributes and behaviors.
- An object can also be used to group related data and functions into a single unit, such as a math object that contains constants and methods for mathematical operations, or a date object that represents a point in time and provides methods for manipulating dates.
- An object can be passed as an argument to a function, returned from a function, or stored in a variable or another object, just like any other value in JavaScript.
