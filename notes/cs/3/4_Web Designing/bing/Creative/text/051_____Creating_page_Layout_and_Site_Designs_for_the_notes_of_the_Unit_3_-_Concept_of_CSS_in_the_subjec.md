### Creating page Layout and Site Designs

- Page layout is the arrangement of visual elements on a web page. It involves using HTML and CSS to define the structure, appearance, and positioning of the content.
- Site design is the overall look and feel of a website, including its navigation, color scheme, typography, graphics, and interactivity. It involves using HTML, CSS, and other web technologies to create a consistent and user-friendly interface.
- CSS stands for Cascading Style Sheets. It is a language that allows web developers to style and format the HTML elements on a web page.
- CSS can be used to create page layout and site design by applying various properties and values to the HTML elements. Some of the common CSS properties and values are:

  - `display`: defines how an element is displayed on the page, such as block, inline, flex, grid, etc.
  - `position`: defines how an element is positioned on the page, such as static, relative, absolute, fixed, sticky, etc.
  - `margin`: defines the space outside the border of an element, such as auto, px, em, %, etc.
  - `padding`: defines the space inside the border of an element, such as auto, px, em, %, etc.
  - `border`: defines the style, width, and color of the border of an element, such as solid, dashed, dotted, none, etc.
  - `width`: defines the width of an element, such as auto, px, em, %, etc.
  - `height`: defines the height of an element, such as auto, px, em, %, etc.
  - `color`: defines the color of the text of an element, such as red, green, blue, hex, rgb, etc.
  - `background`: defines the background color, image, position, size, and repeat of an element, such as white, url, center, cover, no-repeat, etc.
  - `font`: defines the font family, size, weight, style, and variant of the text of an element, such as Arial, 16px, bold, italic, small-caps, etc.
  - `text-align`: defines the horizontal alignment of the text of an element, such as left, right, center, justify, etc.
  - `vertical-align`: defines the vertical alignment of the inline or table-cell elements, such as top, middle, bottom, baseline, etc.
  - `line-height`: defines the height of a line of text, such as normal, px, em, %, etc.
  - `letter-spacing`: defines the space between the letters of the text of an element, such as normal, px, em, %, etc.
  - `word-spacing`: defines the space between the words of the text of an element, such as normal, px, em, %, etc.
  - `text-decoration`: defines the decoration of the text of an element, such as none, underline, overline, line-through, etc.
  - `text-transform`: defines the transformation of the text of an element, such as none, uppercase, lowercase, capitalize, etc.
  - `box-sizing`: defines how the width and height of an element are calculated, such as content-box, border-box, etc.
  - `box-shadow`: defines the shadow effect of an element, such as none, inset, offset-x, offset-y, blur-radius, spread-radius, color, etc.
  - `border-radius`: defines the rounded corners of an element, such as px, em, %, etc.
  - `transform`: defines the transformation of an element, such as none, translate, rotate, scale, skew, etc.
  - `transition`: defines the transition effect of an element, such as none, property, duration, timing-function, delay, etc.
  - `animation`: defines the animation effect of an element, such as none, name, duration, timing-function, delay, iteration-count, direction, fill-mode, etc.
  - `media`: defines the media types and features for applying different CSS rules, such as screen, print, max-width, min-height, etc.
  - `selector`: defines the element or group of elements to which the CSS rules apply, such as element, class, id, attribute, pseudo-class, pseudo-element, etc.
  - `declaration`: defines the CSS property and value pair that specifies the style of an element, such as color: red; font-size: 16px; etc.
  - `rule`: defines the selector and declaration block that forms a CSS statement, such as p {color: red; font-size: 16px;} etc.
