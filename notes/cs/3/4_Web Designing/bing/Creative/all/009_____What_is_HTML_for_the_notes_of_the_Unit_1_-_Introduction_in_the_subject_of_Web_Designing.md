# What is HTML

- HTML stands for **HyperText Markup Language**   .
- HTML is the **standard markup language** for creating web pages .
- HTML defines the **meaning and structure** of web content using HTML elements .
- HTML elements are the **building blocks** of a web page  .
- HTML elements consist of **tags** and **attributes** that **enclose** or **wrap** different parts of the content .
- HTML elements tell the browser **how to display** the content and **how to act** on it .
- HTML elements can be **nested** inside other elements to create complex structures.
- HTML elements can also **link** to other web pages or resources using **hyperlinks** .
- HTML can be **styled** using **CSS** (Cascading Style Sheets) to change the appearance or presentation of the web page.
- HTML can be **enhanced** using **JavaScript** to add functionality or behavior to the web page.
