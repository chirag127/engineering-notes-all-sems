## Unit 5 - Web Hosting

- Web hosting is the service of providing storage space and access for websites on the internet.
- Web hosting providers are companies that offer web hosting plans, which include different features and resources, such as disk space, bandwidth, domains, email accounts, databases, etc.
- Web hosting plans can be categorized into different types, such as shared hosting, dedicated hosting, VPS hosting, cloud hosting, etc., depending on the level of control, performance, and scalability that the user needs.
- Web hosting plans can also vary in terms of pricing, reliability, security, and customer support.
- To choose a web hosting plan, the user should consider the following factors:
  - The purpose and goals of the website, such as personal, business, e-commerce, blog, etc.
  - The expected traffic and resource consumption of the website, such as visitors, page views, files, etc.
  - The technical requirements and features of the website, such as programming languages, frameworks, CMS, etc.
  - The budget and preferences of the user, such as monthly or annual payments, money-back guarantees, etc.
- To set up a web hosting account, the user should follow these steps:
  - Register a domain name, which is the unique address of the website on the internet, such as www.example.com.
  - Choose a web hosting provider and plan, and sign up for an account.
  - Connect the domain name to the web hosting account, by changing the DNS settings of the domain name to point to the web hosting server's IP address.
  - Upload the website files to the web hosting server, using FTP or a web-based file manager.
  - Test and launch the website, by accessing the domain name in a web browser.
