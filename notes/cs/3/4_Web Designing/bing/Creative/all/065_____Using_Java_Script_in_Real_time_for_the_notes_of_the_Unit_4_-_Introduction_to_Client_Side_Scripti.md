# Using JavaScript in Real Time for the Notes of the Unit 4 - Introduction to Client Side Scripting in the Subject of Web Designing

JavaScript is a scripting language that runs in the browser and can manipulate the HTML and CSS elements of a web page. JavaScript can also be used to create real-time applications that can communicate with the server and other clients without reloading the page. Real-time applications are useful for scenarios such as chat, gaming, collaboration, data visualization, and IoT.

Some of the ways to build real-time applications with JavaScript are:

- **Long-Polling**: This is when the application requests updates from the server on a schedule. The app is “polling” the server for new data. This method is simple but inefficient, as it creates a lot of unnecessary requests and consumes bandwidth. 
- **Server-Sent Events**: Server-Sent Events (SSE) is similar to long-polling in so much as the client asks the server for information. However, instead of sending a response and closing the connection, the server keeps the connection open and sends data whenever it is available. This reduces the overhead of creating and closing connections. SSE is supported by most modern browsers, except Internet Explorer. 
- **Web Sockets**: Web Sockets is a technology that facilitates a true two-way communication channel between a client and a server. Unlike HTTP, which is based on request-response, Web Sockets allows the server to push data to the client without waiting for a request. Web Sockets also supports binary data, which is useful for transmitting images, audio, video, and other complex data types. Web Sockets is widely supported by modern browsers and has many libraries and frameworks to simplify its implementation. 
- **SignalR**: SignalR is a library for ASP.NET that enables real-time web functionality. It abstracts the underlying transport mechanism and automatically chooses the best option based on the client and server capabilities. SignalR supports Web Sockets, Server-Sent Events, long-polling, and other techniques. SignalR also provides features such as groups, authentication, authorization, and scalability. 
- **Azure SignalR**: Azure SignalR is a cloud service that provides SignalR functionality as a managed service. It handles the connection management, scaling, load balancing, and security of the real-time applications. Azure SignalR also integrates with other Azure services such as Functions, App Service, and Logic Apps. Azure SignalR can be used with any language and platform that supports SignalR, such as JavaScript, C#, Java, Python, and more. 

Some of the examples of real-time applications that can be built with JavaScript are:

- **Chatroom**: A chatroom is an application that allows users to send and receive messages in real time. A chatroom can be built with Node.js, which is a JavaScript runtime environment that can run on the server side. Node.js can use Web Sockets or Socket.IO (a library that simplifies Web Sockets) to enable bi-directional communication between the server and the clients. A chatroom can also use React Native, which is a framework that allows JavaScript to build native mobile apps for Android and iOS.  
- **Gaming**: A gaming application is an application that allows users to play games with other users in real time. A gaming application can be built with Phaser, which is a framework that provides tools and features for creating 2D and 3D games with JavaScript. Phaser can use Web Sockets or Socket.IO to enable real-time multiplayer functionality. A gaming application can also use Babylon.js, which is a framework that allows JavaScript to create 3D games and animations with WebGL. 
- **Collaboration**: A collaboration application is an application that allows users to work together on a project or a document in real time. A collaboration application can be built with ShareDB, which is a library that enables real-time collaborative editing of JSON documents. ShareDB can use Web Sockets or Socket.IO to synchronize the changes between the server and the clients. A collaboration application can also use Quill, which is a library that provides a rich text editor with real-time collaboration features.
