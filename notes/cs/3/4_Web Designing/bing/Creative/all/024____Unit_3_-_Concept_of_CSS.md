## Unit 3 - Concept of CSS

CSS stands for Cascading Style Sheets. It is a language that is used to describe the presentation of HTML elements, such as their colors, fonts, layouts, and animations. CSS allows web developers to separate the content of a web page from its appearance, making it easier to maintain and update.

Some of the main concepts of CSS are:

- CSS rules: A CSS rule consists of a selector and a declaration block. The selector specifies which HTML elements the rule applies to, and the declaration block contains one or more declarations that define the style properties and values for those elements. For example, `p {color: blue;}` is a CSS rule that sets the text color of all paragraphs to blue.
- CSS selectors: There are different types of selectors that can be used to target HTML elements based on their attributes, classes, ids, positions, relationships, or states. For example, `#intro` is an id selector that matches the element with the id attribute of "intro", and `div > p` is a child selector that matches all paragraphs that are direct children of a div element.
- CSS specificity: Specificity is a measure of how specific a selector is, and determines which rule takes precedence when there are conflicting rules for the same element. Specificity is calculated based on the number and type of selectors in a rule, with higher specificity overriding lower specificity. For example, `p.intro` has higher specificity than `p` because it has a class selector in addition to a type selector.
- CSS inheritance: Inheritance is a mechanism that allows some style properties to be passed from parent elements to their children, unless the children have their own style declarations for those properties. For example, if a div element has a font-family property set to Arial, then all its children will inherit that property, unless they have a different font-family property specified.
- CSS cascade: Cascade is a process that resolves conflicts between multiple style sources, such as external style sheets, internal style sheets, inline styles, and browser default styles. The cascade follows a set of rules that determine the order of precedence for each style source, based on factors such as specificity, importance, and origin. For example, an inline style has higher precedence than an external style sheet, and a user-defined style has higher precedence than a browser default style.
