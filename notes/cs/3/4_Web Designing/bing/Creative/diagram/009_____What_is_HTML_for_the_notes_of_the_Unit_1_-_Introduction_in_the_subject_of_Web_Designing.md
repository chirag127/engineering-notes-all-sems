### What is HTML

- HTML stands for **HyperText Markup Language**  .
- HTML is the **code** that is used to **structure** a web page and its **content** .
- HTML consists of a series of **elements**, which are used to **enclose** or **wrap** different parts of the content to make it appear or act a certain way.
- HTML elements are the **building blocks** of a web page. They are written using **tags** and **attributes**  .
- HTML tags are **keywords** that are surrounded by **angle brackets** (< and >). They usually come in **pairs**, with a **start tag** and an **end tag** .
- HTML attributes are **additional information** that can be added to a tag to modify its **behavior** or **appearance** . They are written inside the start tag, after the tag name, and consist of an **attribute name** and an **attribute value**.
- HTML elements can be **nested** inside other elements to create more complex structures . The nested elements must be **closed** in the same order as they are **opened**.
- HTML elements can also contain **plain text** or other types of **content** such as **images**, **links**, **lists**, **tables**, **forms**, etc .
- HTML is the **foundation** of web design, and it works together with other technologies such as **CSS** (Cascading Style Sheets) and **JavaScript** to create **dynamic** and **interactive** web pages  .
