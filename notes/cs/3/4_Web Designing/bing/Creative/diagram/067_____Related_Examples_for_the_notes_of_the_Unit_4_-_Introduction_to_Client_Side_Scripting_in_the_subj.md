### Related Examples for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- Client-side scripting is the use of scripts that run on the user's browser and perform tasks such as data validation, user interface manipulation, and communication with the server.
- Client-side scripts can enhance the user experience, reduce the server load, and provide faster feedback to the user.
- Some of the common client-side scripting languages are JavaScript, TypeScript, jQuery, Angular, React, Vue, and Blazor WebAssembly.
- Some of the examples of client-side scripting are:

  - Placing the cursor in a form field on form load
  - Generating alerts, confirmations, and messages
  - Opening a web page or a network drive automatically after the user connects
  - Displaying a message on the computer screen indicating a successful connection
  - Validating user input before submitting a form
  - Applying custom business logic for displaying data on a form
  - Building interactive single-page applications with .NET

- Client-side scripting can also have some disadvantages, such as:

  - Browser compatibility issues
  - Security risks
  - Increased bandwidth consumption
  - Reduced accessibility
  - Difficulty in debugging and testing
