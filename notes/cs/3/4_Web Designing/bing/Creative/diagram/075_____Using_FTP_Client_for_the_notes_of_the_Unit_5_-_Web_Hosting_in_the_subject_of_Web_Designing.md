### Using FTP Client

- FTP stands for File Transfer Protocol, which is a standard network protocol for transferring files between a client and a server over the Internet.
- FTP client is a software application that allows the user to upload, download, delete, rename, or move files and directories on a remote server using FTP commands.
- FTP client can be used for web hosting purposes, such as uploading web pages, images, scripts, or other files to a web server, or downloading them from the server to the local computer for backup or editing.
- Some examples of FTP clients are FileZilla, WinSCP, Cyberduck, and CuteFTP.
- To use FTP client, the user needs to have the following information:
  - The hostname or IP address of the web server
  - The username and password for accessing the server
  - The port number for FTP connection (usually 21)
  - The mode of transfer (binary or ASCII)
- The steps for using FTP client are as follows:
  - Launch the FTP client and enter the connection details in the appropriate fields.
  - Click on the connect button to establish a connection with the server.
  - Navigate to the local directory where the files to be uploaded are stored, and select the files or folders to be transferred.
  - Drag and drop the selected files or folders to the remote directory where they should be uploaded, or use the upload button or menu option.
  - Wait for the transfer to complete and check the status or log messages for any errors or warnings.
  - To download files from the server, follow the same steps but in reverse order, i.e., select the files or folders from the remote directory and drag and drop them to the local directory, or use the download button or menu option.
  - To delete, rename, or move files or folders on the server, right-click on the file or folder and choose the desired option from the context menu, or use the corresponding button or menu option.
  - To disconnect from the server, click on the disconnect button or menu option, or close the FTP client.
