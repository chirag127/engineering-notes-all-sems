### HTML Tags
- HTML tags are keywords that define the structure and content of an HTML document.
- HTML tags are enclosed in angle brackets (< and >) and usually come in pairs, such as `<p>` and `</p>`.
- The opening tag (`<p>`) marks the beginning of an element, and the closing tag (`</p>`) marks the end of an element.
- Some HTML tags are self-closing, meaning they do not need a closing tag. For example, `<img>` is a self-closing tag that inserts an image in the document.
- HTML tags can have attributes, which are additional information that modify the behavior or appearance of an element. Attributes are written inside the opening tag, after the tag name, and consist of a name and a value, separated by an equal sign. For example, `<img src="logo.png" alt="Logo">` is an image tag with two attributes: src and alt.
- HTML tags are case-insensitive, meaning they can be written in uppercase or lowercase letters. However, it is a good practice to use lowercase letters for consistency and readability.
- HTML tags are hierarchical, meaning they can be nested inside each other to create complex structures. For example, `<p>` tags can be nested inside `<div>` tags to create paragraphs inside a division. The nested tags must follow the proper order of opening and closing, otherwise the document will not be valid. For example, `<div><p>...</div></p>` is not valid, but `<div><p>...</p></div>` is valid.
