### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for **Cascading Style Sheets** and it is a **stylesheet language** that is used to **style and layout web pages** .
- CSS can be used to **alter the font, color, size, and spacing** of the content, **split it into multiple columns**, or **add animations and other decorative features** to the web pages.
- CSS can also be used to **adapt the presentation** of the web pages to different types of devices, such as **screen, paper, speech, or other media**.
- CSS works by applying **rules** to the elements or groups of elements on the web page. Each rule consists of a **selector** and a **declaration block**.
- The selector specifies **which element or elements** the rule applies to, and the declaration block contains one or more **declarations** that define **how the element or elements should be styled**.
- A declaration consists of a **property** and a **value**, separated by a colon. The property specifies **what aspect** of the element should be styled, and the value specifies **how it should be styled**.
- For example, the following rule applies to all the `<h1>` elements on the web page and sets their font size to 36 pixels and their color to red:

```css
h1 {
  font-size: 36px;
  color: red;
}
```

- CSS can be **embedded** in the HTML document, **linked** from an external file, or **imported** from another stylesheet.
- CSS has a **cascading** mechanism that determines **which rule has more specificity** and **which rule overrides** another rule in case of a conflict.
- CSS also has a **box model** that defines **how the layout** of the elements on the web page is calculated. The box model consists of four components: **content, padding, border, and margin**.
- CSS has a **standard syntax** and a set of **keywords** that are defined by the **World Wide Web Consortium (W3C)**, which is the main international standards organization for the web.
- CSS is constantly **evolving** and **adding new features** to meet the needs of the web developers and designers. The latest version of CSS is **CSS3**, which is divided into **modules** that cover different aspects of styling and layout.
