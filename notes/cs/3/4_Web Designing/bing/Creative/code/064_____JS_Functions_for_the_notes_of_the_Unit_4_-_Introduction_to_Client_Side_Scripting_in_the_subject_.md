### JS Functions

- A function is a block of code that performs a specific task and can be reused multiple times.
- A function can take zero or more parameters as input and return a single value as output.
- A function can be defined using the `function` keyword followed by the function name and a list of parameters in parentheses.
- A function can be called by using the function name followed by a list of arguments in parentheses.
- A function can be declared before or after the code that calls it, as JavaScript has a feature called hoisting that moves the function declarations to the top of the script.
- A function can also be assigned to a variable or passed as an argument to another function. This is called a function expression.
- A function can be defined as an arrow function using the `=>` syntax. This is a shorter way of writing a function expression that does not have its own `this` value.
- A function can be nested inside another function. This is called a closure. A closure can access the variables and parameters of the outer function, even after the outer function has returned.
- A function can have a special object called `arguments` that contains all the arguments passed to the function. This can be useful when the number of arguments is unknown or variable.
- A function can have a special keyword called `return` that stops the execution of the function and returns a value to the caller. If no value is specified, the function returns `undefined`.
