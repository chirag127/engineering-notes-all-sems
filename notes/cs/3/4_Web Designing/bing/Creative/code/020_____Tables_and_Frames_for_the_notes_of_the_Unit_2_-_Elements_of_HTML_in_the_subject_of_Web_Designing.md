### Tables and Frames

- Tables are used to display data in rows and columns in HTML documents.
- Tables are created using the `<table>` tag, which contains one or more `<tr>` tags for table rows, and one or more `<td>` tags for table cells.
- Tables can also have table headers, which are created using the `<th>` tag, and table captions, which are created using the `<caption>` tag.
- Tables can be styled using various attributes, such as `border`, `cellpadding`, `cellspacing`, `align`, `valign`, `colspan`, `rowspan`, etc.
- Frames are used to divide the browser window into multiple sections, each displaying a different HTML document.
- Frames are created using the `<frameset>` tag, which contains one or more `<frame>` tags for each section.
- Frames can also have a title, which is created using the `<title>` tag, and a noframes section, which is displayed when the browser does not support frames.
- Frames can be styled using various attributes, such as `rows`, `cols`, `src`, `name`, `scrolling`, `marginwidth`, `marginheight`, etc.
