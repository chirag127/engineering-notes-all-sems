### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for **Cascading Style Sheets** and it is a **stylesheet language** that is used to **style and layout web pages** .
- CSS can be used to **alter the font, color, size, and spacing of your content, split it into multiple columns, or add animations and other decorative features**.
- CSS is a **rule-based language** that allows you to define the rules by specifying groups of styles that should be applied to particular elements or groups of elements on your web page.
- CSS can be applied to HTML or XML documents, including XML dialects such as SVG, MathML or XHTML.
- CSS can be written in three ways: **inline**, **internal**, or **external**.
  - Inline CSS is written inside the HTML element using the `style` attribute. It applies only to that element and has the highest priority.
  - Internal CSS is written inside the `<style>` tag in the `<head>` section of the HTML document. It applies to the whole document and has the second highest priority.
  - External CSS is written in a separate file with the `.css` extension and linked to the HTML document using the `<link>` tag in the `<head>` section. It applies to the whole document and has the lowest priority.
- CSS follows the **cascading** principle, which means that if there are conflicting styles for the same element, the one that is closer to the element or has more specificity will win .
- CSS can be divided into three levels: **CSS1**, **CSS2**, and **CSS3**.
  - CSS1 is the first version of CSS that was released in 1996. It covers basic styling and formatting features such as fonts, colors, margins, and borders.
  - CSS2 is the second version of CSS that was released in 1998. It adds more features such as positioning, media types, pseudo-elements, and pseudo-classes.
  - CSS3 is the latest version of CSS that is still under development. It introduces new features such as modules, selectors, transitions, animations, transforms, and grids.
