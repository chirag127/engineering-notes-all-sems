# Navigation Bar

A navigation bar is a user interface element that allows users to navigate through a website or an application. A navigation bar typically consists of a series of links, buttons, menus, or other interactive components that direct users to different sections or pages of the website or application.

## Types of Navigation Bar

There are different types of navigation bar that can be used for different purposes and layouts. Some of the common types of navigation bar are:

- **Horizontal navigation bar**: A horizontal navigation bar is placed at the top or bottom of the website or application, and displays the links or buttons horizontally. This type of navigation bar is suitable for websites or applications that have a few main sections or pages, and can fit the links or buttons in one row. For example, a horizontal navigation bar can be used for a portfolio website that has sections like Home, About, Services, Portfolio, and Contact.

- **Vertical navigation bar**: A vertical navigation bar is placed at the left or right side of the website or application, and displays the links or buttons vertically. This type of navigation bar is suitable for websites or applications that have many sections or pages, or that need to display submenus or nested links. For example, a vertical navigation bar can be used for an e-commerce website that has categories like Electronics, Clothing, Books, etc., and subcategories like Mobiles, Laptops, Cameras, etc.

- **Sticky navigation bar**: A sticky navigation bar is a type of navigation bar that stays fixed at the top or bottom of the website or application, even when the user scrolls up or down. This type of navigation bar is useful for websites or applications that have long pages or content, and that need to provide easy access to the navigation links or buttons at all times. For example, a sticky navigation bar can be used for a blog website that has posts with long texts and images, and that needs to provide links to other posts or categories.

- **Hamburger navigation bar**: A hamburger navigation bar is a type of navigation bar that hides the links or buttons behind a hamburger icon (three horizontal lines) that can be clicked or tapped to reveal the navigation menu. This type of navigation bar is useful for websites or applications that have limited space or that need to adapt to different screen sizes or devices. For example, a hamburger navigation bar can be used for a responsive website that needs to display the navigation links or buttons differently on desktop, tablet, and mobile devices.
