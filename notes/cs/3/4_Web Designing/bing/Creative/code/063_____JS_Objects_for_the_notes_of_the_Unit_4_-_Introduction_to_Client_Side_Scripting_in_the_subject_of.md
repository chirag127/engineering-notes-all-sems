### JS Objects

- An object is a collection of properties that store values and functions that perform actions.
- An object can be created using the object literal syntax, which uses curly braces `{}` to enclose the properties and functions.
- An object property is a key-value pair, where the key is a string or a symbol, and the value can be any data type, including another object or a function.
- An object function, also called a method, is a property that has a function as its value. A method can access the object's properties using the `this` keyword.
- An object can be accessed and modified using the dot notation `object.property` or the bracket notation `object['property']`.
- An object can be iterated over using a `for...in` loop, which loops through the keys of the object, or a `for...of` loop, which loops through the values of the object.
- An object can be copied using the `Object.assign()` method, which takes a target object and one or more source objects as arguments, and copies the properties and methods from the source objects to the target object.
- An object can be compared using the `===` operator, which checks if two objects refer to the same memory location, or the `Object.is()` method, which checks if two objects have the same value and type.
- An object can be converted to a string using the `toString()` method, which returns a string representation of the object, or the `JSON.stringify()` method, which returns a JSON-formatted string of the object.
- An object can be converted to an array using the `Object.keys()` method, which returns an array of the object's keys, the `Object.values()` method, which returns an array of the object's values, or the `Object.entries()` method, which returns an array of the object's key-value pairs.
