### Working with Lists and Tables

- Lists and tables are common elements in web pages that can be styled with CSS.
- Lists are used to display a series of items in a vertical or horizontal order. There are three types of lists in HTML: ordered lists, unordered lists, and definition lists.
- Ordered lists use numbers, letters, or roman numerals to indicate the order of the items. They are created with the `<ol>` element and each item is enclosed in a `<li>` element.
- Unordered lists use bullets, squares, circles, or other symbols to mark the items. They are created with the `<ul>` element and each item is enclosed in a `<li>` element.
- Definition lists are used to display terms and their definitions. They are created with the `<dl>` element and each term is enclosed in a `<dt>` element and each definition is enclosed in a `<dd>` element.
- CSS can be used to change the appearance of lists, such as the list-style-type, list-style-image, list-style-position, and list-style properties. These properties can be applied to the `<ol>`, `<ul>`, or `<dl>` elements or to the `<li>` elements individually.
- Tables are used to display data in rows and columns. They are created with the `<table>` element and each row is enclosed in a `<tr>` element and each cell is enclosed in a `<td>` element. A table can also have a header row with `<th>` elements and a caption with the `<caption>` element.
- CSS can be used to change the appearance of tables, such as the border, padding, margin, background, and alignment properties. These properties can be applied to the `<table>` element or to the `<tr>`, `<td>`, or `<th>` elements individually or in groups using selectors.
- CSS can also be used to create responsive tables that can adapt to different screen sizes and devices. One way to do this is to use the `display` property to change the table elements into block-level elements that can stack vertically or horizontally. Another way is to use the `overflow` property to enable scrolling for the table when the screen is too small to fit all the columns.
