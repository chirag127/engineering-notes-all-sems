# Javascript Types

- Javascript is a dynamic, prototype-based, multi-paradigm language that supports object-oriented, imperative, and declarative styles.
- Javascript has 8 basic data types: undefined, null, boolean, number, bigint, string, symbol, and object  .
- Undefined: The type undefined has one value, undefined, which indicates that a variable has not been assigned a value.
- Null: The type null has one value, null, which represents the absence of any object value.
- Boolean: The type boolean has two values, true and false, which are used for logical operations.
- Number: The type number represents both integer and floating-point numbers. There are many operations for numbers, such as arithmetic, bitwise, comparison, etc. Numbers are limited by ±(2^53 - 1).
- Bigint: The type bigint represents integer numbers of arbitrary length. They are created by appending n to the end of an integer literal or by calling the BigInt function.
- String: The type string represents a sequence of characters. A string may have zero or more characters, and there is no separate single-character type. Strings are enclosed in single or double quotes, or backticks.
- Symbol: The type symbol represents a unique identifier that can be used as a property key in objects. Symbols are created by calling the Symbol function.
- Object: The type object is a complex data type that can store collections of data or functions. Objects can be created with literal syntax, with the Object constructor, or with the new keyword. The object data type can contain:
  - An object: A collection of key-value pairs, where the keys are strings or symbols, and the values are any type.
  - An array: An ordered list of values, where each value can be accessed by a numeric index.
  - A date: An object that represents a specific point in time.
