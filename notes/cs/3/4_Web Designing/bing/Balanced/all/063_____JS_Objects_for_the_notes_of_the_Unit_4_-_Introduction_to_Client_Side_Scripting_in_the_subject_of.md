# JS Objects

- An object is a collection of properties that store data and functions that perform actions.
- An object can be created using the object literal syntax, which uses curly braces `{}` to enclose the properties and values.
- A property is a key-value pair, where the key is a name or identifier and the value can be any data type, such as a string, number, boolean, array, or another object.
- A function that belongs to an object is called a method. A method can access and modify the properties of the object using the `this` keyword.
- An object can be accessed and manipulated using the dot notation `object.property` or the bracket notation `object["property"]`.
- An object can be nested inside another object, creating a hierarchy of objects.
- An object can inherit properties and methods from another object using the prototype chain. The prototype of an object is the object that it is based on, and can be accessed using the `__proto__` property.
- An object can be created using a constructor function, which is a special function that defines the properties and methods of the object. A constructor function can be invoked using the `new` keyword, which creates a new instance of the object.
- An object can be created using the `Object.create()` method, which takes an existing object as an argument and returns a new object that inherits from it.
- An object can be converted to a string using the `JSON.stringify()` method, which returns a JSON representation of the object.
- An object can be parsed from a string using the `JSON.parse()` method, which takes a JSON string as an argument and returns an object.
