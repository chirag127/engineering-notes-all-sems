# Positioning for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- Positioning is a CSS property that allows you to control how elements are placed on a web page.
- Positioning can be used to create different layouts, such as fixed, fluid, responsive, grid, or flexbox.
- Positioning can also be used to create various effects, such as overlapping, floating, or sticky elements.
- Positioning has four possible values: static, relative, absolute, and fixed.
- Static positioning is the default value for all elements. It means that the element is placed in the normal flow of the document, without any offset or alignment.
- Relative positioning means that the element is placed in the normal flow of the document, but it can be offset from its original position using the top, right, bottom, and left properties.
- Absolute positioning means that the element is removed from the normal flow of the document, and it is positioned relative to its closest positioned ancestor (or the document body if none exists). The element can be placed anywhere on the page using the top, right, bottom, and left properties.
- Fixed positioning means that the element is removed from the normal flow of the document, and it is positioned relative to the viewport (the visible area of the browser window). The element stays in the same place even when the page is scrolled, and it can be placed anywhere on the page using the top, right, bottom, and left properties.
- Positioning can be combined with other CSS properties, such as display, width, height, margin, padding, border, and background, to create various layouts and effects.
- Positioning can be applied to any HTML element, such as div, span, p, h1, img, etc.
