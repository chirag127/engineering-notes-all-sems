# Unit 3 - Concept of CSS in Web Designing

- CSS stands for **Cascading Style Sheets** and is used to **style and layout web pages** .
- CSS is a **rule-based language** that allows you to define how different elements or groups of elements on your web page should be rendered on screen, on paper, in speech, or on other media.
- CSS rules consist of **selectors** and **declarations**. Selectors are used to specify which elements or groups of elements the rules apply to. Declarations are used to specify the styles that should be applied to the selected elements. Declarations are made up of **properties** and **values**. Properties are the aspects of the elements that can be styled, such as color, font, width, etc. Values are the specific choices for the properties, such as red, Arial, 50%, etc.
- CSS rules can be written in different places: **inline**, **internal**, or **external**. Inline styles are written directly in the HTML elements using the `style` attribute. Internal styles are written in the `<style>` element inside the `<head>` section of the HTML document. External styles are written in a separate file with the `.css` extension and linked to the HTML document using the `<link>` element.
- CSS has a **cascading** mechanism that determines how conflicting rules are resolved. The cascade follows a set of **precedence rules** that take into account the source, specificity, and order of the rules. In general, the more specific and the later the rule, the higher the precedence. Inline styles have the highest precedence, followed by internal styles, followed by external styles, followed by browser default styles.
- CSS also supports **inheritance**, which means that some properties are automatically passed from parent elements to child elements. For example, if you set the color of the `<body>` element to blue, all the text inside the `<body>` will inherit that color, unless you override it with a more specific rule.
- CSS allows you to create **responsive** web pages that can adapt to different screen sizes, devices, and orientations. You can use **media queries** to apply different sets of rules based on certain conditions, such as the width, height, resolution, or orientation of the device. You can also use **flexbox** and **grid** layouts to create flexible and grid-based layouts that can adjust to the available space.
- CSS also enables you to add **animations** and **transitions** to your web pages, which can create dynamic and interactive effects. Animations are used to change the styles of an element over time, using the `@keyframes` rule and the `animation` property. Transitions are used to create smooth changes between the styles of an element when a certain event occurs, such as hovering, clicking, or focusing, using the `transition` property.
