# Working with Hyperlinks

- Hyperlinks are one of the most important features of HTML, as they allow users to navigate from one web page to another, or to other resources on the web, such as images, videos, or documents.
- Hyperlinks are created using the `<a>` element, which stands for anchor. The `<a>` element has an attribute called `href`, which specifies the URL (Uniform Resource Locator) of the destination resource. The URL can be absolute or relative, depending on whether it includes the full address of the resource or only a part of it.
- The content of the `<a>` element is the text or image that the user can click on to follow the link. The content can be styled using CSS (Cascading Style Sheets) to change its appearance, such as color, font, or decoration.
- Hyperlinks can have different types, depending on their purpose or function. Some common types of hyperlinks are:

  - Internal links: These are links that point to another part of the same web page, such as a section header, a footnote, or a table of contents. Internal links are useful for creating a navigation system within a web page, or for allowing the user to jump to a specific point of interest. Internal links use the `id` attribute of the destination element to identify it, and the `href` attribute of the `<a>` element to reference it. For example, `<a href="#section1">Go to Section 1</a>` is an internal link that points to an element with the `id` attribute of `section1`.
  - External links: These are links that point to another web page or resource on a different website or domain. External links are useful for providing additional information, references, or sources for the content of the web page, or for linking to related or complementary resources. External links use the full URL of the destination resource in the `href` attribute of the `<a>` element. For example, `<a href="https://www.w3schools.com/html/">Learn more about HTML</a>` is an external link that points to the W3Schools website.
  - Mailto links: These are links that open the user's default email client and create a new email message with the specified recipient, subject, or body. Mailto links are useful for allowing the user to contact the author or owner of the web page, or to provide feedback, suggestions, or inquiries. Mailto links use the `mailto:` protocol in the `href` attribute of the `<a>` element, followed by the email address of the recipient, and optionally, other parameters such as `subject` or `body`. For example, `<a href="mailto:example@example.com?subject=Hello&body=I like your website">Send me an email</a>` is a mailto link that creates a new email message with the recipient of `example@example.com`, the subject of `Hello`, and the body of `I like your website`.
  - Tel links: These are links that open the user's default phone app and dial the specified phone number. Tel links are useful for allowing the user to call the author or owner of the web page, or to provide a customer service or support line. Tel links use the `tel:` protocol in the `href` attribute of the `<a>` element, followed by the phone number of the recipient. For example, `<a href="tel:+1234567890">Call me</a>` is a tel link that dials the phone number of `+1234567890`.
  - Download links: These are links that prompt the user to download the linked resource, such as a document, an image, or a video, instead of opening it in the browser. Download links are useful for providing the user with a copy of the resource that they can save, view, or edit offline. Download links use the `download` attribute of the `<a>` element, which can optionally specify the name of the file to be downloaded. For example, `<a href="resume.pdf" download="John_Doe_Resume.pdf">Download my resume</a>` is a download link that prompts the user to download the `resume.pdf` file with the name of `John_Doe_Resume.pdf`.
