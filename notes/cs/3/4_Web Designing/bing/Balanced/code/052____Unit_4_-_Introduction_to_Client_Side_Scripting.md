## Unit 4 - Introduction to Client Side Scripting

- Client side scripting is a process in which the code along with HTML web page is sent to the client by the server.
- The client is the computer system (including tablets and mobile devices) which is running the web browser.
- Client side scripting can be used to make web pages change after they arrive at the browser, such as validating user input, creating dynamic content, animating elements, etc.
- The most common client side scripting language is JavaScript, which is universally supported by all browsers.
- Other scripting languages, such as VBScript, can only be used if the user's browser supports them.
- Client side scripts are embedded in the HTML web page, either inline or as external files.
- Client side scripts are executed by the browser, without connecting to the server.
- Client side scripting has some advantages, such as faster response time, reduced server load, and more interactivity.
- Client side scripting also has some disadvantages, such as security risks, compatibility issues, and accessibility problems.
