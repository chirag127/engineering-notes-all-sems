### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page.
- CSS allows web developers to separate the presentation of a web page from its content and structure. This makes it easier to maintain, update and reuse the web design.
- CSS can control various aspects of the web page appearance, such as fonts, colors, backgrounds, borders, margins, padding, alignment, layout, etc.
- CSS can also create dynamic effects, such as transitions, animations, transformations, filters, etc. that enhance the user experience and interactivity of the web page.
- CSS can be applied to HTML elements in three ways: inline, internal and external. Inline CSS is written inside the HTML element using the style attribute. Internal CSS is written inside the head section of the HTML document using the style tag. External CSS is written in a separate file with the .css extension and linked to the HTML document using the link tag.
- CSS follows a set of rules or syntax that defines how to select and style HTML elements. A CSS rule consists of a selector and a declaration block. A selector specifies which HTML element or elements to apply the style to. A declaration block contains one or more declarations that define the style properties and values for the selected element. A declaration consists of a property and a value, separated by a colon and ending with a semicolon.
- CSS follows a cascading order that determines which style rule has the highest priority and overrides the others. The cascading order is based on the following factors: specificity, importance and source order. Specificity is a measure of how specific a selector is. Importance is a way of giving more weight to some style rules using the !important keyword. Source order is the order in which the style rules are defined in the document or file.
- CSS can be enhanced and extended using various tools and technologies, such as preprocessors, frameworks, libraries, etc. Preprocessors are programs that allow writing CSS in a more convenient and powerful way, using variables, functions, mixins, nesting, etc. and then compile it into standard CSS. Examples of preprocessors are Sass, Less, Stylus, etc. Frameworks are collections of predefined CSS rules and components that provide a consistent and responsive web design. Examples of frameworks are Bootstrap, Foundation, Materialize, etc. Libraries are sets of reusable CSS classes and functions that provide specific features or effects. Examples of libraries are Animate.css, Font Awesome, etc.
