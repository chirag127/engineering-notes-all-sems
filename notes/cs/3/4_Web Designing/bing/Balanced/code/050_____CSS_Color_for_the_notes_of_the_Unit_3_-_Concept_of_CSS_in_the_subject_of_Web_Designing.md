### CSS Color

- CSS color is a property that sets the color of an element's text, background, border, or other parts.
- CSS color can be specified by using a predefined color name, a hexadecimal value, an RGB value, an HSL value, or a color keyword.
- Predefined color names are the simplest way to specify a color, but they are limited to 140 colors that are widely supported by browsers. For example, `color: blue;` sets the text color to blue.
- Hexadecimal values are six-digit codes that represent the amount of red, green, and blue in a color. They start with a hash sign (#) and use the digits 0-9 and the letters A-F. For example, `color: #FF0000;` sets the text color to red.
- RGB values are numerical values that specify the amount of red, green, and blue in a color. They use the `rgb()` function and take three parameters, each ranging from 0 to 255. For example, `color: rgb(255, 0, 0);` sets the text color to red.
- HSL values are numerical values that specify the hue, saturation, and lightness of a color. They use the `hsl()` function and take three parameters: the hue (0 to 360 degrees), the saturation (0% to 100%), and the lightness (0% to 100%). For example, `color: hsl(0, 100%, 50%);` sets the text color to red.
- Color keywords are predefined words that represent a specific color. They are similar to color names, but they are more descriptive and flexible. For example, `color: tomato;` sets the text color to a reddish-orange color. There are 147 color keywords defined by CSS.
