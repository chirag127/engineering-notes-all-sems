# Mark up Tags

- Mark up tags are the elements that define the structure and content of a web document.
- Mark up tags are enclosed in angle brackets (< and >) and usually come in pairs, such as <p> and </p>.
- The first tag in a pair is called the start tag or opening tag, and the second tag is called the end tag or closing tag.
- The content between the start and end tags is called the element content, and it can be text, images, links, or other elements.
- Some mark up tags are self-closing, which means they do not need an end tag. For example, <img> is a self-closing tag that inserts an image in a web document.
- Mark up tags can have attributes, which are additional information that modify the behavior or appearance of an element. Attributes are written inside the start tag, after the tag name, and consist of a name and a value, separated by an equal sign (=). For example, <img src="logo.png" alt="Logo"> is an image tag with two attributes: src and alt.
- The src attribute specifies the source or location of the image file, and the alt attribute provides an alternative text for the image, in case it cannot be displayed or accessed by the user.
- Mark up tags can be nested, which means they can contain other elements inside their content. For example, <p><strong>Hello</strong> world!</p> is a paragraph element that contains a strong element, which makes the text bold.
- Mark up tags can be categorized into two types: structural and semantic.
- Structural mark up tags define the layout and presentation of a web document, such as headings, paragraphs, lists, tables, etc. For example, <h1> is a structural tag that creates a level one heading.
- Semantic mark up tags describe the meaning and purpose of the content, such as headings, paragraphs, lists, tables, etc. For example, <em> is a semantic tag that emphasizes the text.
- Semantic mark up tags are preferred over structural mark up tags, because they make the web document more accessible, understandable, and compatible with different devices and browsers.
