### Variables in JS

- Variables are containers that store data values in JavaScript.
- Variables are declared using the keywords `var`, `let`, or `const`.
- Variables can have different data types, such as numbers, strings, booleans, arrays, objects, etc.
- Variables can be assigned values using the assignment operator `=`.
- Variables can be re-assigned new values, unless they are declared with `const`.
- Variables have a scope, which determines where they can be accessed and modified in the code.
- Variables declared with `var` have a function scope, meaning they are visible within the function where they are declared, or globally if declared outside any function.
- Variables declared with `let` or `const` have a block scope, meaning they are visible within the block where they are declared, such as an `if` statement, a `for` loop, or a `switch` case.
- Variables declared without any keyword are automatically global, but this is not recommended as it can cause errors and conflicts.
- Variables can be accessed and manipulated using various operators, such as arithmetic, comparison, logical, and string operators.
- Variables can also be used as arguments for functions, or as properties and methods of objects.
