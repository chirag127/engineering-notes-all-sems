### HTML Documents
- HTML stands for HyperText Markup Language. It is the standard language for creating web pages and web applications.
- HTML documents are text files that contain HTML elements, which are the building blocks of web pages.
- HTML elements are written with a start tag, an end tag, and some content in between. For example, `<p>This is a paragraph.</p>` is an HTML element that defines a paragraph.
- HTML elements can have attributes, which are additional information that modify the behavior or appearance of the element. Attributes are written inside the start tag, after the element name, and are separated by spaces. For example, `<a href="https://www.example.com">This is a link.</a>` is an HTML element that defines a link, with an attribute named `href` that specifies the destination of the link.
- HTML documents have a basic structure that consists of the following elements:
  - `<!DOCTYPE html>`: This is the document type declaration that tells the browser that the document is an HTML document.
  - `<html>`: This is the root element that contains the whole document.
  - `<head>`: This is the element that contains the metadata of the document, such as the title, the character encoding, the style sheets, and the scripts.
  - `<title>`: This is the element that defines the title of the document, which is displayed in the browser's tab or window.
  - `<body>`: This is the element that contains the visible content of the document, such as the headings, the paragraphs, the images, the links, and the forms.
- HTML documents can be created and edited with any text editor, such as Notepad, Sublime Text, or Visual Studio Code. They can also be created and edited with web authoring tools, such as Adobe Dreamweaver, Microsoft FrontPage, or WordPress.
- HTML documents can be viewed in any web browser, such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari. They can also be validated with online tools, such as the W3C Markup Validation Service, to check for errors and compliance with the HTML standards.
