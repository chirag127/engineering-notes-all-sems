### Tables and Frames

- Tables are used to display data in rows and columns in HTML documents.
- Tables are created using the `<table>` tag, which contains one or more `<tr>` tags for table rows, and one or more `<td>` tags for table cells.
- Tables can also have a table header, which is created using the `<th>` tag, and a table caption, which is created using the `<caption>` tag.
- Tables can have various attributes, such as `border`, `cellpadding`, `cellspacing`, `align`, `width`, `height`, etc. to control the appearance and layout of the table.
- Tables can also have nested tables, which are tables inside other tables, to create complex layouts.
- Frames are used to divide the browser window into multiple sections, each displaying a different HTML document.
- Frames are created using the `<frameset>` tag, which contains one or more `<frame>` tags for each section.
- Frames can have various attributes, such as `rows`, `cols`, `src`, `name`, `scrolling`, `noresize`, etc. to control the size, source, name, and behavior of each frame.
- Frames can also have nested framesets, which are framesets inside other framesets, to create complex layouts.
- Frames can also have a default document, which is displayed when the browser does not support frames, or when the user disables frames. This is created using the `<noframes>` tag.
