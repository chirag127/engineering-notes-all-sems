### Line Breaks

- Line breaks are used to create a new line of text in HTML documents.
- The `<br>` tag is an empty tag that inserts a single line break.
- The `<br>` tag does not need a closing tag and can be written as `<br>` or `<br />`.
- The `<br>` tag is useful for creating paragraphs, addresses, poems, or any text that needs to be formatted with line breaks.
- The `<br>` tag should not be used to create margins or spaces between elements. Use CSS properties such as `margin` or `padding` for that purpose.
- Example of using the `<br>` tag:

```html
<p>This is a paragraph with<br>a line break.</p>
```

- Output:

<p>This is a paragraph with<br>a line break.</p>
