### Working with Text

- Text is the most common element of HTML documents. It can be formatted using various HTML tags and attributes.
- HTML tags are keywords enclosed in angle brackets (< and >) that define the structure and meaning of the text. For example, `<p>` is a tag that indicates a paragraph, and `</p>` is a tag that indicates the end of a paragraph.
- HTML attributes are additional information that modify the behavior or appearance of a tag. They are written inside the opening tag, after the tag name, and consist of a name and a value separated by an equal sign. For example, `<p align="center">` is a tag with an attribute named `align` and a value of `center`, which means that the paragraph will be centered on the page.
- Some HTML tags are **container tags**, which means that they have a matching closing tag and can contain other tags or text inside them. For example, `<p>` and `</p>` are container tags that can enclose other tags or text to form a paragraph. Other HTML tags are **empty tags**, which means that they do not have a closing tag and cannot contain anything inside them. For example, `<br>` is an empty tag that creates a line break on the page.
- Some common HTML tags for working with text are:

  - `<h1>` to `<h6>`: These tags create headings of different sizes, from the largest (`<h1>`) to the smallest (`<h6>`). Headings are used to organize the content of a document and make it easier to read and navigate.
  - `<p>`: This tag creates a paragraph, which is a block of text that is separated from other blocks by a blank line or a margin. Paragraphs are used to group related sentences or ideas together.
  - `<b>`: This tag makes the text inside it bold. Bold text is used to emphasize important words or phrases.
  - `<i>`: This tag makes the text inside it italic. Italic text is used to indicate titles of books, movies, or other works, or to add a different tone or style to the text.
  - `<u>`: This tag underlines the text inside it. Underlined text is used to indicate links, or to draw attention to specific words or phrases.
  - `<sub>`: This tag makes the text inside it subscript, which means that it is lowered and reduced in size. Subscript text is used to indicate chemical formulas, mathematical expressions, or footnotes.
  - `<sup>`: This tag makes the text inside it superscript, which means that it is raised and reduced in size. Superscript text is used to indicate exponents, powers, or references.
  - `<br>`: This tag creates a line break, which means that it ends the current line of text and starts a new one. Line breaks are used to create spaces between lines or to force a line break where it is not automatically done by the browser.
  - `<hr>`: This tag creates a horizontal rule, which is a line that spans across the page. Horizontal rules are used to separate sections of a document or to create a visual effect.
  - `<pre>`: This tag preserves the formatting of the text inside it, which means that it displays the text exactly as it is written in the HTML code, with all the spaces, tabs, and line breaks. This tag is used to display code, poetry, or other text that requires a fixed layout.
  - `<blockquote>`: This tag creates a block quotation, which is a section of text that is indented and set apart from the main text. Block quotations are used to quote a long passage from another source, such as a book, a speech, or a website.
  - `<q>`: This tag creates an inline quotation, which is a short quote that is integrated within the main text. Inline quotations are used to quote a brief phrase or sentence from another source, and are usually enclosed in quotation marks.
  - `<cite>`: This tag indicates the citation of a source, which is the name or title of the work that is quoted or referenced. Citations are usually italicized and placed after the quotation or reference.
  - `<code>`: This tag indicates a piece of code, which is a set of instructions or commands that can be executed by a computer or a program. Code is usually displayed in a monospaced font and can be highlighted or colored to indicate different elements or syntax.
