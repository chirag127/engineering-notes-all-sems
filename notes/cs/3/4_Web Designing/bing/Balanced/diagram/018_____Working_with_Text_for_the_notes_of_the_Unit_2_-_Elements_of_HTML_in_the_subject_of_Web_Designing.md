### Working with Text

- Text is the most common element of HTML documents. It can be formatted using various HTML tags and attributes.
- HTML tags are keywords enclosed in angle brackets (< and >) that define the structure and meaning of the text. For example, `<p>` is the tag for a paragraph, `<h1>` is the tag for a heading level 1, and `<em>` is the tag for emphasis.
- HTML attributes are additional information that modify the behavior or appearance of the tags. They are written inside the opening tag, after the tag name, in the form of name="value" pairs. For example, `<p align="center">` is a paragraph tag with an attribute that aligns the text to the center.
- Some HTML tags are paired, meaning they have an opening tag and a closing tag, with the text content in between. For example, `<p>This is a paragraph.</p>` The closing tag has a slash (/) before the tag name. Some HTML tags are unpaired, meaning they do not have a closing tag. For example, `<br>` is a tag that inserts a line break in the text.
- HTML tags can be nested, meaning they can contain other tags inside them. For example, `<p>This is a <em>paragraph</em> with <strong>emphasis</strong> and <u>underline</u>.</p>` The inner tags are called child tags, and the outer tags are called parent tags. The child tags inherit some properties from the parent tags, such as font size and color. The child tags can also override some properties of the parent tags, such as font style and weight.
- HTML tags can be classified into two categories: block-level and inline-level. Block-level tags create a new block of content that occupies the entire width of the parent element and starts on a new line. For example, `<p>`, `<h1>`, `<div>`, and `<ul>` are block-level tags. Inline-level tags create a new segment of content that occupies only the space needed by the text and does not start on a new line. For example, `<em>`, `<strong>`, `<a>`, and `<img>` are inline-level tags. Block-level tags can contain both block-level and inline-level tags, but inline-level tags can only contain other inline-level tags.
