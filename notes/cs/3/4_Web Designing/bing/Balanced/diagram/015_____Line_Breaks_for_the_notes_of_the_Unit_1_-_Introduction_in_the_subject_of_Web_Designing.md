### Line Breaks

- Line breaks are used to create a new line of text in HTML documents.
- Line breaks are created by using the `<br>` tag, which is an empty element that does not need a closing tag.
- The `<br>` tag can be used anywhere within the body of an HTML document, such as within paragraphs, headings, lists, tables, etc.
- The `<br>` tag is useful for creating line breaks in poems, addresses, quotations, or any other text that needs to be formatted in a specific way.
- The `<br>` tag should not be used to create extra space between elements, as this can be done with CSS properties such as margin or padding.
- The `<br>` tag should also not be used to create paragraphs, as this can be done with the `<p>` tag, which has semantic meaning and provides better accessibility and readability.
- Example of using the `<br>` tag:

```html
<p>This is a paragraph<br>
with a line break.</p>
```

- Output:

This is a paragraph
with a line break.
