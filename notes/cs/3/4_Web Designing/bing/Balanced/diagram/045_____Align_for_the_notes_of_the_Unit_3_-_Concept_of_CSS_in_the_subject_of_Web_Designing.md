### Align for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for **Cascading Style Sheets** and is used to **style and layout web pages** .
- CSS is a **rule-based language** that allows you to define the **presentation** of a document written in HTML or XML.
- CSS rules consist of **selectors** and **declarations**. Selectors are used to **target** the elements or groups of elements that you want to style. Declarations are used to **specify** the properties and values that you want to apply to the selected elements.
- CSS rules can be written in three ways: **inline**, **internal**, or **external**. Inline styles are written directly in the HTML element using the `style` attribute. Internal styles are written in the `<style>` tag within the `<head>` section of the HTML document. External styles are written in a separate file with the `.css` extension and linked to the HTML document using the `<link>` tag.
- CSS has many advantages over HTML for web designing, such as:
  - It allows you to **separate** the content from the presentation, making the code more **maintainable**, **reusable**, and **accessible** .
  - It allows you to **control** the appearance of multiple web pages from a single style sheet, making the design more **consistent** and **efficient** .
  - It allows you to **customize** the presentation of web pages for different devices, media, and user preferences, making the design more **responsive** and **adaptive** .
  - It allows you to **enhance** the visual effects of web pages with features such as colors, fonts, backgrounds, borders, margins, padding, alignment, positioning, transformations, transitions, animations, and more .
