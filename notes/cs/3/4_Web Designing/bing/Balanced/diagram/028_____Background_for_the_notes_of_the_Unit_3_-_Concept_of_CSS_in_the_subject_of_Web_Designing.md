### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

- CSS stands for Cascading Style Sheets. It is a language that describes how HTML elements are displayed on a web page.
- CSS was created by Håkon Wium Lie and Bert Bos in 1996. It was first proposed as a web standard by the World Wide Web Consortium (W3C) in 1998.
- CSS allows web developers to separate the presentation of a web page from its content and structure. This makes it easier to maintain, update, and reuse the code.
- CSS can also enhance the appearance and functionality of a web page by adding colors, fonts, layouts, animations, transitions, and other effects.
- CSS has three levels of specification: CSS1, CSS2, and CSS3. Each level adds new features and capabilities to the previous one. CSS3 is the latest and most advanced version of CSS.
- CSS can be applied to a web page in three ways: inline, internal, and external. Inline CSS is written inside the HTML element using the style attribute. Internal CSS is written inside the head section of the HTML document using the style tag. External CSS is written in a separate file with the .css extension and linked to the HTML document using the link tag.
- CSS follows a set of rules or syntax to define the style of an HTML element. A CSS rule consists of a selector and a declaration block. A selector is the name of the HTML element that the rule applies to. A declaration block is a set of one or more declarations enclosed by curly braces. A declaration is a pair of a property and a value, separated by a colon and followed by a semicolon. A property is the aspect of the element that is being styled, such as color, font-size, or margin. A value is the specific setting for the property, such as red, 16px, or 10px.
- CSS follows a cascading order to determine which rule has the highest priority and overrides the others. The order is based on the specificity and the source of the rule. Specificity is a measure of how precise or specific a selector is. The more specific a selector is, the higher its priority. The source of the rule is the location where the rule is defined. The order of priority from highest to lowest is: inline CSS, internal CSS, external CSS, and browser default CSS. If two rules have the same specificity and source, the rule that comes later in the code has higher priority.
