# Unit 1 - Introduction

## Mark up Tags

- Mark up tags are the elements that define the structure and content of a web document.
- Mark up tags are enclosed in angle brackets (< and >) and usually come in pairs, such as `<p>` and `</p>`.
- The opening tag (`<p>`) marks the beginning of an element, and the closing tag (`</p>`) marks the end of an element.
- Some mark up tags are self-closing, meaning they do not need a closing tag, such as `<img>` or `<br>`.
- Mark up tags can have attributes, which provide additional information about the element, such as `<img src="image.jpg" alt="A picture">`.
- Attributes are written inside the opening tag, after the tag name, and consist of a name and a value, separated by an equal sign (=).
- The value of an attribute is usually enclosed in quotation marks (" or ').
- Mark up tags can be nested, meaning one element can contain another element, such as `<p><strong>This is a paragraph with bold text.</strong></p>`.
- The order of the nested elements is important, and the closing tags must match the opening tags, such as `<p><em>This is a paragraph with <strong>italic and bold</strong> text.</em></p>`.
- Mark up tags can be categorized into two types: structural and semantic.
- Structural mark up tags define the layout and appearance of a web document, such as `<html>`, `<head>`, `<body>`, `<div>`, `<span>`, etc.
- Semantic mark up tags define the meaning and purpose of the content, such as `<h1>`, `<p>`, `<a>`, `<img>`, `<table>`, etc.
- Semantic mark up tags help to improve the accessibility, readability, and searchability of a web document.
