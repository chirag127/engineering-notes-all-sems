## Unit 2 - Elements of HTML

- HTML stands for HyperText Markup Language. It is the standard language for creating web pages and web applications.
- HTML consists of a series of elements, which are the building blocks of a web page. Elements are enclosed by tags, which are written in angle brackets. For example, `<p>` is the tag for a paragraph element.
- Elements can have attributes, which are additional information that modify or describe the element. Attributes are written inside the opening tag, after the element name, and consist of a name and a value. For example, `<p class="intro">` is a paragraph element with an attribute named class and a value of intro.
- Elements can contain text, other elements, or both. For example, `<p>This is a paragraph with <strong>bold</strong> text.</p>` is a paragraph element that contains text and another element, `<strong>`, which makes the text bold.
- Some elements are self-closing, which means they do not have a closing tag. For example, `<img src="image.jpg" alt="An image">` is an image element that has two attributes, src and alt, and does not need a closing tag.
- HTML elements are organized in a hierarchical structure, called the Document Object Model (DOM). The DOM represents the web page as a tree of elements, with the `<html>` element as the root, and the `<head>` and `<body>` elements as its children. The `<head>` element contains information about the web page, such as its title and links to external resources. The `<body>` element contains the visible content of the web page, such as text, images, and links.
- HTML elements can be classified into different categories, based on their function and appearance. Some of the common categories are:

  - Metadata elements: These elements provide information about the web page, such as its title, language, and character encoding. They are usually placed inside the `<head>` element. Examples of metadata elements are `<title>`, `<meta>`, and `<link>`.
  - Sectioning elements: These elements define the structure and outline of the web page, such as its sections, headings, and footers. They are usually placed inside the `<body>` element. Examples of sectioning elements are `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>`, `<h1>` to `<h6>`, and `<footer>`.
  - Grouping elements: These elements group related content together, such as paragraphs, lists, and tables. They are usually placed inside the `<body>` element. Examples of grouping elements are `<p>`, `<div>`, `<span>`, `<ul>`, `<ol>`, `<li>`, `<dl>`, `<dt>`, `<dd>`, `<table>`, `<tr>`, `<th>`, `<td>`, and `<caption>`.
  - Text-level elements: These elements modify or enhance the text content, such as making it bold, italic, or linked. They are usually placed inside other elements that contain text, such as `<p>` or `<li>`. Examples of text-level elements are `<strong>`, `<em>`, `<a>`, `<abbr>`, `<code>`, `<mark>`, and `<q>`.
  - Embedded elements: These elements embed external content into the web page, such as images, videos, or audio. They are usually placed inside the `<body>` element. Examples of embedded elements are `<img>`, `<video>`, `<audio>`, `<iframe>`, and `<object>`.
  - Form elements: These elements create interactive forms that allow the user to input data and submit it to a server. They are usually placed inside the `<body>` element. Examples of form elements are `<form>`, `<input>`, `<label>`, `<button>`, `<select>`, `<option>`, `<textarea>`, and `<fieldset>`.
  - Scripting elements: These elements enable dynamic behavior and interactivity on the web page, such as changing the content, validating the input, or responding to user events. They are usually placed inside the `<head>` or the `<body>` element. Examples of scripting elements are `<script>` and `<noscript>`.
