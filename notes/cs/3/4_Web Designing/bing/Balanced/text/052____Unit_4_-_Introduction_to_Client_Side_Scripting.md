## Unit 4 - Introduction to Client Side Scripting

- Client side scripting is a technique of writing code that runs on the user's browser, rather than on the web server.
- Client side scripting can enhance the interactivity, functionality, and usability of web pages by allowing the code to respond to user events, manipulate the document object model (DOM), and communicate with the web server without reloading the page.
- Client side scripting languages are usually interpreted, meaning they do not need to be compiled before execution. Some examples of client side scripting languages are JavaScript, VBScript, JScript, and ActionScript.
- Client side scripting can also be used to create dynamic web applications that use frameworks such as Angular, React, Vue, and jQuery. These frameworks provide libraries and tools that simplify the development of complex web applications that use client side scripting.
- Client side scripting has some advantages and disadvantages compared to server side scripting. Some of the advantages are:
  - Faster response time, as the code does not need to travel to the server and back.
  - Reduced server load, as the code runs on the user's browser and does not consume server resources.
  - More control over the user interface, as the code can access and modify the DOM elements directly.
  - More compatibility, as the code can adapt to different browsers and devices.
- Some of the disadvantages are:
  - Security risks, as the code can be viewed and modified by the user or by malicious third parties.
  - Dependency on the user's browser, as the code may not run or run differently on different browsers or devices.
  - Difficulty in debugging, as the code may not produce any error messages or may produce different errors on different browsers or devices.
