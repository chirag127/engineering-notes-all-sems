### Working with Text

- Text is the most common element of HTML documents. It can be formatted using various HTML tags and attributes.
- Some of the common HTML tags for text are:

  - `<p>`: Defines a paragraph of text. It creates a line break before and after the text.
  - `<h1>` to `<h6>`: Defines headings of different levels. The `<h1>` tag is the most important and largest heading, while the `<h6>` tag is the least important and smallest heading.
  - `<b>`: Makes the text bold.
  - `<i>`: Makes the text italic.
  - `<u>`: Underlines the text.
  - `<sub>`: Makes the text subscript (lower than the normal line).
  - `<sup>`: Makes the text superscript (higher than the normal line).
  - `<br>`: Inserts a line break in the text. It is an empty tag, meaning it does not need a closing tag.
  - `<hr>`: Inserts a horizontal rule in the document. It is also an empty tag.
  - `<pre>`: Preserves the formatting of the text as it is written in the HTML code. It displays the text in a fixed-width font and preserves the spaces and line breaks.
  - `<blockquote>`: Defines a block of text that is quoted from another source. It usually indents the text from both sides.
  - `<q>`: Defines a short quotation within a paragraph. It usually displays the text in quotation marks.
  - `<cite>`: Defines the title of a work that is cited or referenced. It usually displays the text in italic.
  - `<code>`: Defines a piece of code within the text. It usually displays the text in a fixed-width font.
  - `<kbd>`: Defines user input, such as keyboard keys or mouse clicks. It usually displays the text in a fixed-width font.
  - `<samp>`: Defines sample output from a program or a script. It usually displays the text in a fixed-width font.
  - `<var>`: Defines a variable name in a mathematical expression or a programming context. It usually displays the text in italic.
  - `<abbr>`: Defines an abbreviation or an acronym. It can use the `title` attribute to provide the full form of the abbreviation or acronym.
  - `<dfn>`: Defines a term that is being defined or explained. It can use the `title` attribute to provide the definition of the term.
  - `<mark>`: Highlights a part of the text that is important or relevant. It usually displays the text with a yellow background.
  - `<del>`: Defines a part of the text that has been deleted or removed. It usually displays the text with a line through it.
  - `<ins>`: Defines a part of the text that has been inserted or added. It usually displays the text with an underline.
  - `<s>`: Defines a part of the text that is no longer accurate or relevant. It usually displays the text with a line through it.
  - `<small>`: Makes the text smaller than the normal size.
  - `<strong>`: Emphasizes the text as important or significant. It usually displays the text in bold.
  - `<em>`: Emphasizes the text as stressed or emphasized. It usually displays the text in italic.
  - `<bdo>`: Changes the direction of the text. It can use the `dir` attribute to specify the direction as `ltr` (left to right) or `rtl` (right to left).

- Some of the common HTML attributes for text are:

  - `align`: Specifies the horizontal alignment of the text. It can have the values `left`, `right`, `center` or `justify`.
  - `dir`: Specifies the direction of the text. It can have the values `ltr` (left to right) or `rtl` (right to left).
  - `lang`: Specifies the language of the text. It can have the values of the ISO 639-1 language codes, such as `en` for English, `fr` for French, `zh` for Chinese, etc.
  - `style`: Specifies the inline CSS style of the text. It can have various properties and values, such as `color`, `font-family`, `font-size`, `text-decoration`, etc.
  - `title`: Specifies the additional information or description of the text. It usually displays as a tooltip when the user hovers over the text.
