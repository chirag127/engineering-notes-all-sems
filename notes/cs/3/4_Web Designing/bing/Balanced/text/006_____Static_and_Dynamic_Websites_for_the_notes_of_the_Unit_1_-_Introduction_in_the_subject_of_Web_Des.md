### Static and Dynamic Websites

- Static websites are ones that are fixed and display the same content for every user, usually written exclusively in HTML   .
- Dynamic websites are ones that can display different content and provide user interaction, by making use of advanced programming and databases in addition to HTML   .
- Some of the differences between static and dynamic websites are:

| Static Websites | Dynamic Websites |
| --------------- | ---------------- |
| Easier and cheaper to create and host  | More complex and expensive to create and host  |
| Faster to load and more secure  | Slower to load and more vulnerable to attacks  |
| Suitable for simple and small websites  | Suitable for large and interactive websites  |
| Require manual updating of each page  | Allow automatic updating of content from a database  |
| Examples: blogs, portfolios, landing pages  | Examples: e-commerce, social media, forums  |

- Some of the technologies used to create static and dynamic websites are:

| Static Websites | Dynamic Websites |
| --------------- | ---------------- |
| HTML, CSS, JavaScript   | PHP, ASP.NET, Ruby on Rails, Python, MySQL, MongoDB   |
| Static site generators like Jekyll, Hugo, Gatsby  | Content management systems like WordPress, Drupal, Joomla  |
