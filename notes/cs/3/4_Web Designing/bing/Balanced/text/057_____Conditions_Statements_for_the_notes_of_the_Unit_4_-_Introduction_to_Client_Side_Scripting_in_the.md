### Condition Statements for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- Condition statements are used to control the flow of execution of a program based on some conditions.
- Condition statements can be written in different languages, such as JavaScript, which is a popular client-side scripting language for web designing.
- Condition statements can be of different types, such as if, if-else, if-else-if, switch, and ternary operators.
- If statements are used to execute a block of code only if a condition is true.
- If-else statements are used to execute a block of code if a condition is true, or another block of code if the condition is false.
- If-else-if statements are used to execute one of several blocks of code based on multiple conditions.
- Switch statements are used to execute one of many blocks of code based on the value of an expression.
- Ternary operators are used to assign a value to a variable based on a condition, using the syntax `variable = condition ? value1 : value2`.
- Condition statements can be nested, meaning that one condition statement can be inside another condition statement, to create more complex logic.
- Condition statements can be combined with logical operators, such as `&&` (and), `||` (or), and `!` (not), to create more complex conditions.
- Condition statements can be used to validate user input, display different content, perform calculations, and more.
