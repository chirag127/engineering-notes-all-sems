## Unit 5 - Web Hosting

- Web hosting is the service of providing storage space and access for websites on the internet.
- Web hosting providers are companies that rent out their servers, network infrastructure, and software to host websites for clients.
- Web hosting can be classified into different types based on the level of control, performance, and resources available to the website owner. Some common types are:
  - Shared hosting: The website shares a server and its resources with other websites. This is the cheapest and most popular option for small to medium-sized websites.
  - Dedicated hosting: The website has a server and its resources exclusively for itself. This is the most expensive and secure option for large and complex websites that require high performance and customization.
  - VPS hosting: The website has a virtual server and its resources that are isolated from other websites on the same physical server. This is a more flexible and scalable option than shared hosting, but less costly than dedicated hosting.
  - Cloud hosting: The website is hosted on a network of servers that are distributed across different locations and can dynamically adjust to the website's needs. This is a more reliable and scalable option than traditional hosting, but may have higher costs and security risks.
- Web hosting also involves other aspects such as domain name registration, SSL certificates, email hosting, backup services, and technical support.
