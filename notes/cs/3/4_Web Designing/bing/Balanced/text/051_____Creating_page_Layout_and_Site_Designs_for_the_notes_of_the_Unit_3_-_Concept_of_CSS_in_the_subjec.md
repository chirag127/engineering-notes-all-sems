### Creating page layout and site design with CSS

- Page layout is the way elements are arranged on a web page, such as text, images, navigation, header, footer, etc.
- Site design is the overall look and feel of a website, such as color scheme, typography, layout, graphics, etc.
- CSS (Cascading Style Sheets) is a language that allows us to style HTML elements and control their layout and appearance.
- CSS can be used to create different types of page layouts and site designs, such as fixed, fluid, responsive, grid, flexbox, etc.
- Some of the main concepts and techniques for creating page layout and site design with CSS are:

  - The display property: This property allows us to change the default way elements are displayed, such as block, inline, inline-block, none, etc. It also enables us to use other layout methods, such as grid, flexbox, table, etc.
  - The box model: This is the way CSS calculates the width and height of an element, taking into account its content, padding, border, and margin. It also affects how elements are positioned and aligned with each other.
  - The position property: This property allows us to take elements out of the normal flow and place them in a specific location on the page, such as relative, absolute, fixed, or sticky.
  - The float and clear properties: These properties allow us to make elements float to the left or right of their containing block, and to prevent elements from wrapping around floated elements.
  - The flexbox layout: This is a one-dimensional layout system that allows us to create flexible and responsive layouts by aligning and distributing items along a main axis and a cross axis.
  - The grid layout: This is a two-dimensional layout system that allows us to create complex and responsive layouts by dividing the page into rows and columns, and placing items into grid cells.
  - The media queries: These are rules that allow us to apply different styles depending on the screen size, resolution, orientation, or other device features. They are useful for creating responsive and adaptive designs that adjust to different devices and situations.
  - The responsive design: This is an approach to web design that aims to create websites that work well on different devices and screen sizes, by using fluid layouts, flexible images, media queries, and other techniques.
