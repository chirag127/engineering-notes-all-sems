### CSS Color

- The color property in CSS is used to set the foreground color value of an element's text and text decorations  .
- The color property also sets the currentcolor value, which can be used as an indirect value on other properties, such as border-color or background-color.
- The color property accepts various types of color values, such as keywords, hexadecimal values, RGB values, HSL values, and more .
- The color property is inherited by default, which means that the color of a parent element will be applied to its child elements, unless the child elements have their own color property specified .
- The color property can be used with the :visited and :link pseudo-classes to style the color of visited and unvisited links .
- The color property can be used with the opacity property to create transparent or semi-transparent colors .
- The color property can be used with the color-adjust property to control how colors are adjusted when printed or displayed in different modes.
