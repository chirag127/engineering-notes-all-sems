### Basic structure of an HTML document

- HTML stands for HyperText Markup Language, which is the standard language for creating web pages and web applications.
- An HTML document is a text file that contains HTML elements, which are the building blocks of a web page.
- An HTML element consists of a start tag, an end tag, and the content between them. For example, `<p>Hello, world!</p>` is an HTML element that defines a paragraph of text.
- Some HTML elements are self-closing, which means they do not have an end tag. For example, `<img src="logo.png" alt="Logo">` is an HTML element that inserts an image on the web page.
- An HTML document has a basic structure that consists of the following elements:

  - `<!DOCTYPE html>`: This is the declaration that tells the browser that the document is an HTML document. It must be the first line of the document.
  - `<html>`: This is the root element that contains all the other elements of the document. It has an attribute called `lang` that specifies the language of the document. For example, `<html lang="en">` means the document is in English.
  - `<head>`: This is the element that contains the metadata of the document, such as the title, the character encoding, the style sheets, and the scripts. Metadata is the information that is not displayed on the web page, but is used by the browser or other applications to process the document.
  - `<title>`: This is the element that defines the title of the document, which is displayed on the browser's tab or window. It must be inside the `<head>` element.
  - `<meta>`: This is the element that defines various types of metadata, such as the character encoding, the author, the keywords, and the description of the document. It must be inside the `<head>` element. It has different attributes depending on the type of metadata. For example, `<meta charset="UTF-8">` specifies the character encoding of the document, and `<meta name="description" content="This is a web page about HTML">` specifies the description of the document.
  - `<link>`: This is the element that links the document to an external resource, such as a style sheet, an icon, or a font. It must be inside the `<head>` element. It has different attributes depending on the type of resource. For example, `<link rel="stylesheet" href="style.css">` links the document to a style sheet, and `<link rel="icon" href="favicon.ico">` links the document to an icon.
  - `<script>`: This is the element that embeds or references a script, such as JavaScript, that can add interactivity or functionality to the web page. It can be inside the `<head>` element or the `<body>` element. It has different attributes depending on the type of script. For example, `<script src="script.js"></script>` references an external script, and `<script>alert("Hello, world!");</script>` embeds an inline script.
  - `<body>`: This is the element that contains the content of the document, such as the text, the images, the links, the forms, and the tables. It is the visible part of the web page. It must be inside the `<html>` element and after the `<head>` element.
  - `<h1>` to `<h6>`: These are the elements that define the headings of the document, from the most important (`<h1>`) to the least important (`<h6>`). They are used to organize the content and make it easier to read and navigate. They must be inside the `<body>` element.
  - `<p>`: This is the element that defines a paragraph of text. It must be inside the `<body>` element.
  - `<a>`: This is the element that defines a hyperlink, which is a clickable text or image that leads to another web page or a section of the same web page. It must be inside the `<body>` element. It has an attribute called `href` that specifies the URL of the destination. For example, `<a href="https://www.google.com">Google</a>` creates a hyperlink to Google's web page.
  - `<img>`: This is the element that inserts an image on the web page. It must be inside the `<body>` element. It has two mandatory attributes: `src` that specifies the URL of the image, and `alt` that specifies the alternative text that is displayed if the image cannot be loaded.
