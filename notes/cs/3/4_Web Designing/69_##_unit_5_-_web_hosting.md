## Unit 5 - Web Hosting

Web Hosting is the process of storing and serving website files on a server that is connected to the internet. When a user visits a website, their browser requests the website files from the server, which then sends the files to the browser to be displayed.

There are several types of web hosting, including:

1. Shared Hosting: Shared hosting is the most basic and affordable type of web hosting, where a single server is shared by multiple websites.

2. VPS Hosting: VPS (Virtual Private Server) hosting is a type of web hosting where a single server is divided into multiple virtual servers, each with its own resources and operating system.

3. Dedicated Hosting: Dedicated hosting is a type of web hosting where a single server is dedicated to a single website.

4. Cloud Hosting: Cloud hosting is a type of web hosting where a website is hosted on a network of servers, rather than on a single server.

In this unit, you will learn about the different types of web hosting, and you will learn about the key features and considerations when choosing a web hosting provider. You will also learn about the basics of web hosting, including server configurations, domain names, and managing a website on a server.

This unit will provide a foundation for understanding the principles and practices of web hosting, and for exploring the various concepts and techniques used in the field of web design.
