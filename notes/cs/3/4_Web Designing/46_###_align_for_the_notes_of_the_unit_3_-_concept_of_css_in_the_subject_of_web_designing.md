### Align for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Alignment is an important aspect of web design, as it determines the position of an element on a web page. CSS provides several properties for controlling the alignment of elements, including:

1. text-align: The text-align property is used to control the alignment of text within an element.

2. vertical-align: The vertical-align property is used to control the vertical alignment of an element.

3. float: The float property is used to control the position of an element, allowing it to float to the left or right of its parent element.

4. display: The display property is used to control the display behavior of an element, including block, inline, and inline-block.

In this unit, you will learn about the different properties and values used to control the alignment of elements in CSS, and you will learn how to use CSS to control the alignment of text, the position of elements, and the display behavior of elements on a web page.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
