### Working with block elements and objects for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Working with block elements and objects is an important aspect of web design, as it allows you to control the layout and appearance of a web page. Block elements are used to define the structure of a web page, while objects are used to define the content of a web page.

In this unit, you will learn about the different types of block elements and objects available in HTML and CSS, including divs, spans, images, and videos, among others. You will learn how to use CSS to control the appearance of block elements and objects, including their size, position, background, and borders, among other things.

You will also learn about the basics of CSS layout, including the box model, floating elements, and positioning, among other things. You will learn how to use CSS to create complex layouts, including multi-column layouts and responsive designs.

This unit will provide a foundation for understanding the basics of block elements and objects in HTML and CSS, and for exploring the various concepts and techniques used in the field of web design. It will also provide a foundation for understanding the basics of CSS layout and its role in web design.
