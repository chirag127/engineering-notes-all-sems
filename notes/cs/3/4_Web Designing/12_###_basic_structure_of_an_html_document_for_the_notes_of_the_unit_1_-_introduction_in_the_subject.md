### Basic structure of an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing

Unit 1 of the Web Designing course focuses on Introduction, including the aspect of the basic structure of an HTML document.

HTML (Hypertext Markup Language) is a markup language used to structure and present content on the web. The basic structure of an HTML document consists of several key elements, including:

- DOCTYPE declaration, which specifies the version of HTML used in the document.
- HTML tag, which serves as the root element of the document and contains all other elements.
- Head tag, which contains information about the document, such as the title and meta data.
- Body tag, which contains the main content of the document, such as text, images, and links.

In the context of the Web Designing course, students in Unit 1 will learn about the basic structure of an HTML document as part of the discussion on Introduction. This may include working with examples of HTML documents, analyzing the role of each element in the structure of an HTML document, and learning how to create an HTML document from scratch.

In summary, Unit 1 of the Web Designing course focuses on Introduction, and includes the aspect of the basic structure of an HTML document. The basic structure of an HTML document consists of the DOCTYPE declaration, HTML tag, Head tag, and Body tag. Students will learn about the basic structure of an HTML document through interactive activities and hands-on experiences, and will learn how to create an HTML document from scratch.
