### Pseudo class for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Pseudo-classes are a CSS feature that allow you to apply styles to an element based on a specific state or condition. For example, you can use pseudo-classes to apply styles to an element when it is hovered over with a mouse, or when it is selected.

The following are some of the most commonly used pseudo-classes in CSS:

1. :hover: Applies styles to an element when it is hovered over with a mouse.

2. :active: Applies styles to an element when it is being actively clicked on.

3. :focus: Applies styles to an element when it has focus, such as when it is selected.

4. :visited: Applies styles to a link element that has been visited.

5. :first-child: Applies styles to the first child element of a parent element.

In this unit, you will learn about the different pseudo-classes in CSS, and you will learn how to use them to apply styles to elements based on specific states or conditions. You will also learn about the different selectors and properties used in CSS, and you will learn how to use CSS to create custom styles for a web page.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
