### HTML Documents for the notes of the Unit 1 - Introduction in the subject of Web Designing

The HTML Documents section of the Unit 1 - Introduction in the subject of Web Designing should cover the following topics:

1. Definition of HTML (Hypertext Markup Language, a standard markup language for creating web pages)
2. Overview of HTML (what it is, when it is used, advantages and disadvantages)
3. Basic structure of an HTML document (doctype, head, body)
4. Overview of doctype (declares the type of HTML document being used)
5. Overview of head (contains metadata about the document, such as the title and links to CSS and JavaScript files)
6. Overview of body (contains the main content of the document, including text, images, and other elements)
7. HTML elements (tags, attributes, values)
8. Overview of tags (markup elements that define the structure and content of an HTML document)
9. Overview of attributes (additional information about an HTML element, such as id, class, and style)
10. Overview of values (the data associated with an attribute, such as a specific color or font size)
11. Common HTML elements (headings, paragraphs, lists, links, images)
12. Overview of headings (elements used to create headings and subheadings in an HTML document)
13. Overview of paragraphs (elements used to create paragraphs of text in an HTML document)
14. Overview of lists (elements used to create ordered or unordered lists in an HTML document)
15. Overview of links (elements used to create links to other pages or resources)
16. Overview of images (elements used to include images in an HTML document)
17. HTML tables (elements used to create tables in an HTML document)
18. HTML forms (elements used to create forms for collecting user input)
19. The role of HTML in web design (creating the structure and content of web pages)
20. Limitations of HTML (static content, limited interactivity)
21. Further reading and resources (books, tutorials, online resources)

HTML is a fundamental component of the subject of Web Designing. Understanding the principles and techniques of HTML helps students to develop the skills required to create the structure and content of web pages. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
