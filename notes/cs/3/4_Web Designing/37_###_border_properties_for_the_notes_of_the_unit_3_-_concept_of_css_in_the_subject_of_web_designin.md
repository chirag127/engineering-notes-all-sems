### Border properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Borders are an important aspect of web design, as they provide a visual boundary between elements on a web page. CSS provides several properties for controlling the appearance of borders, including:

1. Border-width: The border-width property is used to control the width of the border.

2. Border-style: The border-style property is used to control the style of the border, including solid, dotted, dashed, double, groove, ridge, inset, and outset.

3. Border-color: The border-color property is used to control the color of the border.

4. Border-radius: The border-radius property is used to control the rounded corners of the border.

CSS also provides a shorthand property, border, which allows you to specify the border-width, border-style, and border-color in a single line of code.

In this unit, you will learn about the different properties and values used to control the appearance of borders in CSS, and you will learn how to use CSS to control the width, style, color, and radius of borders on a web page.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
