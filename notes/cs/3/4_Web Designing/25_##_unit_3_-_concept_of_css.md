## Unit 3 - Concept of CSS

Unit 3 of the Web Designing course focuses on the Concept of CSS (Cascading Style Sheets). CSS is a stylesheet language used to control the layout and presentation of web content. It is used to separate the presentation of a web page from its content, making it easier to maintain and update the look and feel of a website.

In Unit 3, students will learn about the following topics:
- Definition and history of CSS.
- Key concepts in CSS, such as selectors, properties, and values.
- Types of CSS styles, including inline, internal, and external styles.
- CSS Box Model, which defines the structure and layout of HTML elements on a web page.
- CSS positioning, which defines the position of HTML elements on a web page.
- CSS floats, which allow elements to float to the left or right of other elements on a web page.

Unit 3 is designed to provide students with a comprehensive understanding of CSS and its key concepts. Through interactive activities, lectures, and hands-on experiences, students will gain a deep understanding of CSS and learn how to use CSS to control the layout and presentation of web content.

In summary, Unit 3 of the Web Designing course focuses on the Concept of CSS. CSS is a stylesheet language used to control the layout and presentation of web content, and is used to separate the presentation of a web page from its content. Students will learn about the definition and history of CSS, key concepts, types of CSS styles, CSS Box Model, CSS positioning, and CSS floats. Unit 3 provides students with a comprehensive understanding of CSS and its key concepts, and students will learn how to use CSS to control the layout and presentation of web content.
