## Unit 2 - Elements of HTML

Unit 2 of the subject of Web Designing focuses on the elements of HTML, which are the building blocks of a web page. HTML elements are defined using tags, and they include text, images, links, lists, tables, and forms, among others.

In this unit, you will learn about the various HTML elements and how to use them to create a web page. You will learn about headings, paragraphs, lists, links, images, tables, and forms, and you will learn how to use HTML attributes to control the appearance and behavior of the elements.

You will also learn about the basics of CSS (Cascading Style Sheets), which is used to control the appearance of a web page. CSS allows you to control the font, color, background, and layout of a web page, and it provides a way to separate the content of a web page from its presentation.

This unit will provide a foundation for understanding the elements of HTML, and for exploring the various concepts and techniques used in the field of web design. It will also provide a foundation for understanding the principles and practices of CSS and web design.
