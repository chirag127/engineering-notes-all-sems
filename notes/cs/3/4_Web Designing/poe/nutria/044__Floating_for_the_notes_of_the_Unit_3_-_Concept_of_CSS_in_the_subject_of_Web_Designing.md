
### Floating for the Notes of the Unit 3 - Concept of CSS in the Subject of Web Designing

1. Floating is a positioning technique that allows an element to be shifted to the left or right of its normal position on the page. 
2. Float elements are often used to create page layouts, where elements are placed side-by-side in a specific order.
3. Floating an element requires the use of the CSS `float` property, which can be set to `left`, `right`, or `none`.
4. When an element is floated, it will remain in its floated position until it is cleared.
5. To clear an element, the `clear` property can be used, which can be set to `left`, `right`, or `both`.
6. When a floated element is cleared, it is shifted back to its original position on the page.
7. Floated elements can also be used to create columns of text, where multiple columns of text can be placed side-by-side.
8. To create columns of text, the `column-count` property can be used.
9. Floated elements can also be used to create responsive web designs, where elements are rearranged based on the size of the viewport.
10. To create responsive designs, the `@media` rule can be used.
