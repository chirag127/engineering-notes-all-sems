
### CSS Advanced for the Notes of Unit 3 - Concept of CSS in the Subject of Web Designing

1. CSS (Cascading Style Sheets) is a language used to describe the presentation of a document written in a markup language.
2. CSS is used to define styles for web pages, including the layout, colors, and fonts.
3. CSS is a powerful tool for creating visually appealing webpages and can be used to create complex designs.
4. CSS can be used to create responsive designs that adapt to different screen sizes and devices.
5. CSS can be used to create animations, transitions, and other interactive effects.
6. CSS can be used to create a consistent look and feel across different webpages.
7. CSS can be used to create cross-browser compatibility.
8. CSS can be used to create print-friendly webpages.
9. CSS can be used to optimize webpages for search engine optimization (SEO).
10. CSS is a powerful tool for creating visually appealing and accessible webpages.
