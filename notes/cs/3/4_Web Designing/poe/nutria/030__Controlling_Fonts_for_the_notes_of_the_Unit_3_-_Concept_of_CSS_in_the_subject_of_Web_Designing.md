
### Controlling Fonts for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* CSS allows developers to control the font size, color, font family, font style, font weight, and other font properties of text on a web page. 
* Font size can be controlled using the `font-size` property. It can be specified in various units, including pixels, points, ems, rems, and percentages. 
* Font color can be controlled using the `color` property. It can be specified in various formats, including hexadecimal, RGB, and HSL. 
* Font family can be controlled using the `font-family` property. It can be specified by providing a comma-separated list of font names. 
* Font style can be controlled using the `font-style` property. It can be set to `normal`, `italic`, or `oblique`. 
* Font weight can be controlled using the `font-weight` property. It can be set to a numerical value between 100 and 900, or to a keyword such as `normal` or `bold`. 
* Other font properties, such as text decoration, letter spacing, and line height, can also be controlled using CSS.
