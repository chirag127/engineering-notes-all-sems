
### Using Control Panel for the notes of the Unit 5 - Web Hosting in the subject of Web Designing

1. Control Panel is a web-based interface that allows users to manage their hosting accounts and configure the server settings.
2. It provides access to features such as creating and managing databases, setting up email accounts, and installing web applications.
3. It can also be used to manage domains, subdomains, and FTP accounts.
4. The most widely used control panels are cPanel and Plesk.
5. cPanel is a Linux-based control panel that provides an easy-to-use graphical interface for managing hosting accounts.
6. Plesk is a Windows-based control panel that provides an easy-to-use graphical interface for managing hosting accounts.
7. Both cPanel and Plesk provide access to a variety of features and tools for managing hosting accounts.
8. In addition to the control panel, users can also access the server via SSH or FTP.
9. It is important to note that the control panel is not the only way to manage a hosting account.
10. Users can also access the server directly via SSH or FTP.
