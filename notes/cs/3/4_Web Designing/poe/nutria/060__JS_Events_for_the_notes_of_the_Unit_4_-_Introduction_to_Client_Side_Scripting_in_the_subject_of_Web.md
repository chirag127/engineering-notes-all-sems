
### JS Events for the Notes of the Unit 4 - Introduction to Client Side Scripting in the Subject of Web Designing

* Event handlers allow user interaction with webpages. They are attached to HTML elements and are triggered when the user interacts with the element.
* Event bubbling is a method of event propagation that occurs when an event is triggered from a nested element. The event will propagate up through the DOM tree until it reaches the top element.
* Event delegation is a method of event propagation that allows for events to be handled by a single parent element instead of each element in the DOM tree.
* Event capturing is a method of event propagation that occurs when an event is triggered from the top element. The event will propagate down through the DOM tree until it reaches the nested element.
* The addEventListener() method allows for multiple event handlers to be attached to a single element.
* The removeEventListener() method allows for specific event handlers to be removed from an element.
* The preventDefault() method allows for the default action of an event to be prevented from occurring.
* The stopPropagation() method allows for the event to be stopped from propagating further up or down the DOM tree.
