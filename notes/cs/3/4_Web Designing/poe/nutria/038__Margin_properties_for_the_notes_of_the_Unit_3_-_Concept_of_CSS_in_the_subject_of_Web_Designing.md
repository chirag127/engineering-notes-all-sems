
### Margin Properties for the Notes of the Unit 3 - Concept of CSS in the Subject of Web Designing

1. Margin properties are used to create a space between elements on a web page.
2. The margin property is used to define the amount of space around an element.
3. The margin property can be used to set the size of the margin for all four sides of an element.
4. The margin property can also be used to set the size of the margin for each side of an element individually.
5. The margin property can be used to set the margin to a specific size or to set it to auto.
6. The auto value will set the margin size to the size of the element's content.
7. The margin property can be used to set the margin to a percentage of the parent element's width.
8. The margin property can be used to set the margin to a negative value.
9. Negative margins can be used to overlap elements on a web page.
10. The margin property can be used to set the margin to inherit the margin size of the parent element.
