
### HTML Tags for the Notes of Unit 2 - Elements of HTML in the Subject of Web Designing

* HTML tags are the basic building blocks of HTML documents.
* HTML tags are used to structure and format the content in an HTML document.
* HTML tags are written in angle brackets (< >).
* HTML tags typically come in pairs, with an opening tag and a closing tag.
* The opening tag contains the tag name and any attributes, while the closing tag contains the tag name preceded by a forward slash (/).
* HTML tags can be nested, meaning that one tag can contain other tags.
* Some HTML tags are self-closing, meaning they don't require a closing tag.
* HTML tags are used to add structure and meaning to the content of a web page.
* Some of the most commonly used HTML tags include the `<html>`, `<head>`, `<title>`, `<body>`, `<p>`, `<h1>`, `<div>`, `<span>`, and `<img>` tags.
