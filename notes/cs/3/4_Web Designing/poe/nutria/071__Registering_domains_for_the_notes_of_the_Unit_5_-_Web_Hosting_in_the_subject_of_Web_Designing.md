

### Registering Domains for the Notes of the Unit 5 - Web Hosting in the Subject of Web Designing

1. A domain name is a unique address that identifies a website on the internet. It is composed of two parts: a top-level domain (TLD) and a second-level domain (SLD). Examples of TLDs include .com, .org, and .net. Examples of SLDs include google, amazon, and facebook.

2. To register a domain name, you must first determine the availability of the domain name by using an online domain name search tool. Once you have found an available domain name, you must then purchase the domain name from a domain name registrar.

3. After purchasing the domain name, you must then configure the domain name with a web hosting provider. This requires providing the domain name registrar with the IP address of the web hosting provider.

4. Once the domain name has been configured with the web hosting provider, the domain name can then be used to host a website. This requires creating the website using HTML, CSS, and other web development technologies.

5. Finally, the domain name must be renewed periodically to ensure that it remains active. Domain name renewals are typically done on an annual basis.
