
### Border Properties for the Notes of the Unit 3 - Concept of CSS in the Subject of Web Designing

* Borders are the lines that surround an element and are used to separate and differentiate elements from each other.
* Borders can be styled using the `border` property in CSS.
* The `border` property allows you to specify the width, style, and color of the border.
* The `border-width` property specifies the width of the border, and it can be set to a specific length, percentage, or keyword.
* The `border-style` property specifies the style of the border, and it can be set to one of the following values: `solid`, `dotted`, `dashed`, `double`, `groove`, `ridge`, `inset`, or `outset`.
* The `border-color` property specifies the color of the border, and it can be set to any valid color value.
* The `border-radius` property specifies the roundness of the corners of the border, and it can be set to a specific length, percentage, or keyword.
* The `border-collapse` property specifies how adjacent cells in a table should be rendered, and it can be set to either `collapse` or `separate`.
* The `border-spacing` property specifies the spacing between adjacent cells in a table, and it can be set to a specific length, percentage, or keyword.
