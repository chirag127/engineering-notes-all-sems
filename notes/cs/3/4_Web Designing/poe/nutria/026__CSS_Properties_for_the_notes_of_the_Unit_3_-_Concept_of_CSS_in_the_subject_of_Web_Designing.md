
### CSS Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. **CSS Syntax**: CSS uses a set of rules to define how HTML elements should be styled. It consists of a selector, followed by a declaration block. The selector points to the HTML element you want to style, and the declaration block contains one or more declarations separated by semicolons. Each declaration includes a property name and a value, separated by a colon.

2. **CSS Selectors**: CSS selectors are used to select the HTML elements that should be styled. CSS selectors can be based on HTML element names, classes, IDs, or attributes.

3. **CSS Properties**: CSS properties are used to define the styles of HTML elements. Examples of CSS properties include font-family, font-size, color, background-color, border, margin, padding, and more.

4. **CSS Values**: CSS values are used to define the values of CSS properties. Examples of CSS values include length, percentage, color codes, and keywords.

5. **CSS Specificity**: CSS specificity is used to determine which CSS rules will be applied to an HTML element. It is based on the number of selectors that match the element, and the number of declarations that are applied.

6. **CSS Inheritance**: CSS inheritance is used to determine which CSS properties will be inherited by an HTML element. Certain properties, such as font-family and font-size, will be inherited from their parent element. Other properties, such as color and background-color, will not be inherited.
