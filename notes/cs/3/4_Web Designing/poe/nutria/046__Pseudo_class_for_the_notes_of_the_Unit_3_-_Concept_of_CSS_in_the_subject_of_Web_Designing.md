
### Pseudo class for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

* Pseudo classes are used to select elements based on their state or position in a document tree. 
* They are used to style elements based on their current state, such as when a user hovers over a link or when an element is active or disabled. 
* Pseudo classes are also used to select elements based on their position in the document tree, such as the first or last child of a parent element. 
* CSS pseudo classes are denoted with a colon (:) followed by the class name, such as :hover, :active, and :visited. 
* Pseudo classes can be combined with other selectors, such as class or id selectors, to style elements in specific states. 
* CSS pseudo elements are used to style specific parts of an element, such as the first letter or line of a paragraph. 
* Pseudo elements are denoted with two colons (::) followed by the element name, such as ::first-letter and ::first-line. 
* Pseudo elements can be used to style parts of an element that do not have a corresponding HTML element, such as the first letter or line of a paragraph.
