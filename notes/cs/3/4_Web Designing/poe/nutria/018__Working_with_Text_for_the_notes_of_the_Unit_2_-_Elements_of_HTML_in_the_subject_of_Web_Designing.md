
### Working with Text for the notes of Unit 2 - Elements of HTML in the subject of Web Designing

1. HTML offers a wide range of text-related tags, such as `<p>`, `<h1>`, `<h2>`, `<h3>`, `<h4>`, `<h5>`, and `<h6>`.
2. The `<p>` tag is used to create a paragraph of text.
3. The `<h1>` tag is used to create a heading, with `<h2>` through `<h6>` used for subheadings.
4. The `<b>` tag is used to make text bold, while the `<i>` tag is used to make text italic.
5. The `<u>` tag is used to underline text, while the `<s>` tag is used to strike through text.
6. The `<sup>` tag is used to make text superscript, while the `<sub>` tag is used to make text subscript.
7. The `<br>` tag is used to create line breaks, while the `<hr>` tag is used to create a horizontal line.
8. The `<pre>` tag is used to preserve whitespace, while the `<blockquote>` tag is used to create a blockquote.
9. The `<em>` tag is used to emphasize text, while the `<strong>` tag is used to make text bold.
10. The `<span>` tag is used to apply styles to a portion of text, while the `<div>` tag is used to group elements together.
