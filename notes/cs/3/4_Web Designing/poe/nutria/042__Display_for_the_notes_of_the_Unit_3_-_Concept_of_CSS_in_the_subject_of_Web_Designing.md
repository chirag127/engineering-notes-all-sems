
### Display for the Notes of the Unit 3 - Concept of CSS in the Subject of Web Designing

1. CSS stands for Cascading Style Sheets and is a language used to style HTML documents.
2. CSS allows you to control the look and feel of a web page, including font size, color, background images, and more.
3. CSS can be used to create responsive designs that adjust to different screen sizes.
4. CSS is composed of selectors, properties, and values.
5. Selectors identify the elements to be styled and properties define the styles that will be applied.
6. Values are the specific values for each property and can be numeric or text.
7. CSS can be written in a separate file or embedded in the HTML document.
8. CSS has several different types of selectors including element, class, id, and pseudo-class.
9. CSS also has several different types of properties including color, font, margin, padding, and border.
10. CSS can be used to create animations and transitions to make a website more interactive.
