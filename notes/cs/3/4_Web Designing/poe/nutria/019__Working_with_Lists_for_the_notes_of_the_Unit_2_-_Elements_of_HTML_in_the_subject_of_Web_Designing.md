
### Working with Lists for the notes of the Unit 2 - Elements of HTML in the Web Designing

* HTML lists are used to group related items in an organized and easy to understand way. 
* The two main types of HTML lists are ordered lists and unordered lists. 
* An ordered list is a list of items that are numbered in a specific order, such as a list of steps to follow. 
* An unordered list is a list of items that are not numbered, such as a list of ingredients for a recipe. 
* HTML lists can be nested, meaning that a list can contain another list inside of it. 
* Lists can be used to create menus, navigation bars, and other interactive elements on a website. 
* The `<ol>` and `<ul>` tags are used to create ordered and unordered lists, respectively. 
* The `<li>` tag is used to create list items. 
* The `<dl>` tag is used to create a definition list, which is a list of terms and their definitions. 
* The `<dt>` and `<dd>` tags are used to create definition list items.
