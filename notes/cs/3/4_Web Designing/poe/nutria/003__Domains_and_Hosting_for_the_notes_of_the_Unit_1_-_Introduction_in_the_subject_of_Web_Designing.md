
### Domains and Hosting for the notes of the Unit 1 - Introduction in the subject of Web Designing

1. Domain names are unique identifiers used to identify and locate a website on the Internet. They are typically made up of two parts: a top-level domain (TLD) and a second-level domain (SLD). Examples of TLDs include .com, .org, and .net. Examples of SLDs include google, yahoo, and bbc.

2. Hosting is the process of storing a website's data and files on a server, so that it can be accessed over the internet. A hosting provider is a company that provides the services and technologies required for a website to be viewed on the internet.

3. Domain registration is the process of registering a domain name with a domain registrar. Domain registrars are companies that are accredited by ICANN (the Internet Corporation for Assigned Names and Numbers) to provide domain name registration services.

4. DNS (Domain Name System) is a system that translates domain names into IP addresses. When a domain name is entered into a web browser, the DNS looks up the corresponding IP address and directs the user to the correct website.

5. SSL (Secure Sockets Layer) is a security protocol that encrypts data sent between a web server and a web browser. It is used to protect sensitive information such as credit card numbers and passwords. SSL certificates are issued by Certificate Authorities (CAs) and must be installed on the web server in order to enable secure connections.
