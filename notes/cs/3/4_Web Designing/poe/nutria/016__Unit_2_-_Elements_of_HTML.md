
## Unit 2 - Elements of HTML

1. HTML stands for HyperText Markup Language. It is a markup language used to create webpages.
2. HTML elements are the building blocks of HTML documents. They are composed of tags, attributes, and content.
3. Tags are used to mark up the start and end of HTML elements.
4. Attributes are used to provide additional information about an element.
5. Content is the information contained within an element.
6. HTML documents are composed of a head and a body.
7. The head contains information about the document, such as the title, meta tags, and other scripts.
8. The body contains the main content of the document, such as text, images, and other elements.
9. HTML elements can be nested, meaning they can be placed within other elements.
10. HTML documents can be styled with CSS to make them look more attractive.
