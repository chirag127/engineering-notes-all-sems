
### Conditions Statements for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

1. A **condition statement** is a type of statement used in programming to check if a certain condition is true. 
2. If the condition is true, the program will execute a certain set of instructions. 
3. If the condition is false, the program will execute a different set of instructions.
4. Conditions statements are typically used in loops, functions and if-else statements.
5. In client-side scripting, conditions statements are used to determine the behavior of webpages based on user input.
6. Common types of condition statements include comparison operators (e.g. greater than, less than), logical operators (e.g. and, or, not) and equality operators (e.g. equal to, not equal to).
7. Conditions statements can be combined to create more complex conditions.
8. It is important to ensure that conditions statements are properly formatted, as incorrect formatting can lead to errors in the program.
