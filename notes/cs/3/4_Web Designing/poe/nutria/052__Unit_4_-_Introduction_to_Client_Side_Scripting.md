
## Unit 4 - Introduction to Client Side Scripting

1. Client Side Scripting is a type of programming that is used to create interactive web applications.

2. It is written in languages such as JavaScript, HTML, and CSS.

3. Client Side Scripting enables webpages to respond to user input and create dynamic content in the browser.

4. Client Side Scripting is used to create interactive elements such as menus, forms, and animations.

5. Client Side Scripting is also used to validate user input, such as checking if a form is filled out correctly.

6. Client Side Scripting can also be used to store user data in the browser, such as preferences or login information.

7. Client Side Scripting is an important part of modern web development, and is used to create interactive and engaging web experiences.
