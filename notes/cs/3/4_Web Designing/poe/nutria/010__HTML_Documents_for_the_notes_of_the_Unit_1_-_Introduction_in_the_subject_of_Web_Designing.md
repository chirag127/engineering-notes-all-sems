
### HTML Documents 

* HTML stands for Hypertext Markup Language, and is the language used to create webpages. 
* HTML documents are written in plain text, and contain a series of tags that are used to define the structure of the document. 
* HTML documents are composed of elements, which are the building blocks of webpages. Elements can include text, images, and other media. 
* HTML documents are rendered by web browsers, which interpret the HTML code and display the document in a graphical format. 
* HTML documents can also contain scripts, which are used to add interactivity to the webpage. 
* HTML documents can be styled using Cascading Style Sheets (CSS). CSS is a language used to define the appearance of HTML elements. 
* HTML documents can be validated using the W3C Markup Validation Service. This service checks the HTML code of the document to ensure that it is valid and conforms to the standards set by the World Wide Web Consortium (W3C).
