

### JS Functions for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

- A JavaScript function is a block of code designed to perform a particular task.
- Functions are defined with the keyword `function` followed by a name and parentheses `()`.
- Inside the parentheses, you can specify parameters that the function will receive when it is called.
- Functions can also return a value by using the keyword `return`.
- Functions can be called or invoked by using the function name followed by parentheses `()` containing any necessary parameters.
- JavaScript functions can be declared either globally, or within a code block.
- JavaScript functions can also be used as objects, which can be passed as parameters to other functions.
- JavaScript functions can also be used as methods of an object.
- JavaScript functions can also be nested, which means that one function can be defined inside another function.
- JavaScript functions can also be anonymous, which means that they don't have a name.
