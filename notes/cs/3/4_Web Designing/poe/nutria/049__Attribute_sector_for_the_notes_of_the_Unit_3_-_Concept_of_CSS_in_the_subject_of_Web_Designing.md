
### Attribute Sector for the Notes of the Unit 3 - Concept of CSS in the Web Designing

1. CSS stands for Cascading Style Sheets. It is a language used for describing the look and formatting of a document written in a markup language, such as HTML.

2. CSS is used to define the layout, fonts, colors, and other design elements of a web page.

3. CSS can be used to control the layout of multiple web pages at once, by using an external stylesheet.

4. CSS can also be used to create responsive websites that are optimized for different screen sizes, such as mobile, tablet and desktop.

5. CSS can be written in three different ways: inline, embedded, and external.

6. Inline CSS is written directly in the HTML document.

7. Embedded CSS is written in a <style> tag in the HTML document.

8. External CSS is written in an external file and linked to the HTML document.

9. CSS selectors are used to target elements on a web page and apply styles to them.

10. CSS properties are used to define the styles of elements on a web page.
