
### Basic structure of an HTML document

1. An HTML document is made up of elements, which are the basic building blocks of a webpage.

2. An HTML document is composed of tags, which are the instructions that tell the web browser how to display the content.

3. A web page is made up of two parts: the head and the body. The head contains information about the page, such as the title, description, and keywords. The body contains the content of the page.

4. An HTML document must have a doctype declaration at the top of the page. This tells the web browser which version of HTML is being used.

5. The HTML document must have an opening and closing <html> tag.

6. The head of the document is contained within the opening and closing <head> tags.

7. The title of the page is contained within <title> tags.

8. The body of the document is contained within the opening and closing <body> tags.

9. Elements are contained within opening and closing tags. The opening tag includes the element name and any attributes.

10. Attributes are used to provide additional information about an element.

11. Comments are used to provide additional information about the code, and are not displayed in the web browser.
