
### JS Objects for the Notes of the Unit 4 - Introduction to Client Side Scripting in the Subject of Web Designing

1. JavaScript objects are collections of related data and functions that can be used to store, manipulate, and access information.
2. Objects are composed of properties, which are essentially variables associated with an object, and methods, which are functions that can be used to manipulate the object's properties.
3. Objects can be created in a number of ways, including by using object literals, constructors, and object factories.
4. Objects can also be used to create custom data types, which can be used to store and manipulate data in a more organized and efficient manner.
5. JavaScript also allows for inheritance, which allows objects to inherit properties and methods from other objects.
6. JavaScript also provides access to the Document Object Model (DOM), which allows for the manipulation of web pages and other documents.
