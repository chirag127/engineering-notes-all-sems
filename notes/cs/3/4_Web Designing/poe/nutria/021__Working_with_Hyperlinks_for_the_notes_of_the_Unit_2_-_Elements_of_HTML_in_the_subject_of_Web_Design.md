
### Working with Hyperlinks for the Notes of the Unit 2 - Elements of HTML in the Subject of Web Designing

1. Hyperlinks are a way to link two webpages together in HTML.
2. Hyperlinks are created using the `<a>` tag and an `href` attribute.
3. The `href` attribute is used to specify the URL of the page you are linking to.
4. The `<a>` tag can also include a `target` attribute, which specifies where the link should open.
5. The `target` attribute can be set to `_blank` to open the link in a new window or tab.
6. Hyperlinks can also be used to link to sections of the same page by using the `id` attribute.
7. To link to a section, the `href` attribute should be set to `#` followed by the `id` of the section.
8. Hyperlinks can also be used to link to downloadable files such as PDFs or images.
9. To link to a downloadable file, the `href` attribute should be set to the URL of the file.
