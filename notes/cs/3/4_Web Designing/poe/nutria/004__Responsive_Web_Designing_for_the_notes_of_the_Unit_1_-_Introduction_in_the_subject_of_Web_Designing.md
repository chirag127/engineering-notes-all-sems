

### Responsive Web Designing

1. Responsive web design is a method of web design that allows web pages to adapt to various screen sizes, resolutions, and orientations.

2. Responsive web design is based on the concept of fluid grids, where the size of elements on a page is defined as a percentage of the page's width, rather than a fixed size.

3. Responsive web design also uses media queries to determine the size of the device being used to view the page, and then serve the appropriate content and style.

4. Responsive web design can also be used to create adaptive layouts, where the page layout changes depending on the device being used.

5. Responsive web design is an important part of creating a user-friendly website, as it allows users to access the same content on any device.
