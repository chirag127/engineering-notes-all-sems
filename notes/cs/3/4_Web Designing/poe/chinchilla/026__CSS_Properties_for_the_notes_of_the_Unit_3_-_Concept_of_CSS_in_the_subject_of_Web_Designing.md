### CSS Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS (Cascading Style Sheets) is a styling language used to add style and layout to web pages. CSS allows web designers to separate the presentation of a web page from its content, making it easier to manage and update the design of a website. Here are some CSS properties that you should know:

1. Color: The color property allows you to change the color of text and backgrounds. You can use a color name, a hexadecimal code, an RGB value, or an HSL value to set the color.

2. Font: The font property allows you to change the font family, size, weight, and style of text. You can use a font name or a generic font family to set the font family. You can use a pixel or em value to set the font size.

3. Margin: The margin property allows you to add space around an element. You can set the margin for each side of an element separately or set a shorthand value for all sides.

4. Padding: The padding property allows you to add space within an element. You can set the padding for each side of an element separately or set a shorthand value for all sides.

5. Border: The border property allows you to add a border around an element. You can set the border width, style, and color separately or set a shorthand value for all three.

6. Background: The background property allows you to add a background color or image to an element. You can set the background color, image, position, and repeat.

7. Height and Width: The height and width properties allow you to set the height and width of an element. You can use a pixel or percentage value to set the height and width.

8. Display: The display property allows you to control how an element is displayed. You can set the display to block, inline, inline-block, none, and other values.

9. Position: The position property allows you to position an element relative to its parent element or to the browser window. You can set the position to static, relative, absolute, fixed, or sticky.

10. Text: The text property allows you to control the text decoration, alignment, and transformation of text. You can set the text-decoration, text-align, and text-transform properties to change the appearance of text.

These are just a few of the many CSS properties available for styling web pages. By mastering these properties, you will be able to create beautiful and functional websites.
