## Unit 2 - Elements of HTML

HTML, which stands for HyperText Markup Language, is the standard language used to create web pages. HTML is a markup language that uses various elements to define the structure and content of a web page. In this unit, we will be discussing the various elements of HTML that are used to create web pages.

### HTML Elements

HTML elements are the building blocks of web pages. They are used to define the structure and content of a web page. HTML elements are defined by a start tag, content, and an end tag. The start tag is written inside angle brackets (<>) and the end tag is written inside angle brackets with a forward slash (/) before the tag name.

Here are some commonly used HTML elements:

- `<html>` - This element is used to define the root of an HTML document.
- `<head>` - This element is used to define the head section of an HTML document.
- `<title>` - This element is used to define the title of an HTML document.
- `<body>` - This element is used to define the body section of an HTML document.
- `<h1>` to `<h6>` - These elements are used to define headings of different sizes.
- `<p>` - This element is used to define paragraphs.
- `<a>` - This element is used to create hyperlinks.
- `<img>` - This element is used to display images.
- `<ul>` - This element is used to create an unordered list.
- `<ol>` - This element is used to create an ordered list.
- `<li>` - This element is used to define list items.
- `<table>` - This element is used to create a table.
- `<tr>` - This element is used to define a table row.
- `<td>` - This element is used to define a table cell.

### Attributes

HTML elements can also have attributes, which provide additional information about the element. Attributes are written inside the start tag and are separated from the element name by a space. Attribute values are written inside double quotes ("").

Here are some commonly used HTML attributes:

- `id` - This attribute is used to give an element a unique identifier.
- `class` - This attribute is used to give an element a class name.
- `src` - This attribute is used to specify the source of an image or other media.
- `href` - This attribute is used to specify the URL of a hyperlink.
- `style` - This attribute is used to define inline styles for an element.

### HTML Comments

HTML comments are used to add notes to the HTML code that are not displayed in the web page. Comments are written inside `<!--` and `-->` and can be used to provide information about the code or to temporarily disable code.

### Conclusion

HTML elements are the building blocks of web pages. They are used to define the structure and content of a web page. In this unit, we have covered the various elements of HTML that are used to create web pages. By understanding these elements and how they are used, you will be able to create your own web pages using HTML.
