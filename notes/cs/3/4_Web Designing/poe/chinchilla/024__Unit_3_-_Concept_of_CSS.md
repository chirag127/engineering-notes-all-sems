## Unit 3 - Concept of CSS

Cascading Style Sheets (CSS) is a language used to style and format web pages. CSS provides the ability to control the appearance of HTML elements, including layout, colors, fonts, and more. In this unit, we will cover the following concepts related to CSS:

1. CSS Syntax:
   - CSS syntax consists of a selector and a declaration block.
   - The selector specifies which HTML element to apply the styles to.
   - The declaration block contains one or more property-value pairs separated by a semicolon.

2. CSS Selectors:
   - CSS selectors are used to select and style specific HTML elements.
   - There are several types of selectors, including element selectors, class selectors, ID selectors, and attribute selectors.
   - Specificity is used to determine which CSS rule to apply when multiple rules target the same element.

3. CSS Properties:
   - CSS properties determine the appearance of HTML elements.
   - There are many CSS properties available, including font-size, color, background-color, border, margin, padding, and more.
   - CSS properties can be set using a variety of units, including pixels, ems, and percentages.

4. CSS Box Model:
   - The CSS box model is used to define the layout of HTML elements.
   - Each HTML element is made up of a content area, padding, border, and margin.
   - The box model can be modified using CSS properties such as width, height, padding, and border.

5. CSS Layout:
   - CSS provides several layout techniques, including float, position, and display.
   - Float is used to place an element to the left or right of its container.
   - Position is used to position an element relative to its container or the browser window.
   - Display is used to change the display behavior of an element, such as making it a block element or an inline element.

6. CSS Units:
   - CSS units are used to define the size of HTML elements.
   - There are several types of units, including pixels, ems, percentages, and more.
   - Each unit has its own advantages and disadvantages, and the choice of unit depends on the specific use case.

7. CSS Responsive Design:
   - Responsive design is an approach to web design that aims to create a website that looks good on all devices, from desktops to smartphones.
   - CSS provides several techniques for creating responsive designs, including media queries and flexible layouts.
   - Media queries allow different styles to be applied based on the size of the screen or device.
   - Flexible layouts use relative units such as ems or percentages to create designs that adapt to different screen sizes.

In conclusion, CSS is a powerful tool for styling and formatting web pages. By understanding the concepts covered in this unit, you will be able to create visually appealing and responsive websites.
