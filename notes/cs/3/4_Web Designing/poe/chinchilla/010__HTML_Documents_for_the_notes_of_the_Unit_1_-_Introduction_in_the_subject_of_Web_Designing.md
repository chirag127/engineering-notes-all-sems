### HTML Documents

HTML documents or web pages are the backbone of the World Wide Web. HTML stands for HyperText Markup Language, which is used to create web pages. In this unit, we will learn about HTML documents and their structure.

HTML documents are built using tags which are used to describe the structure and content of a web page. The basic structure of an HTML document is as follows:

1. **<!DOCTYPE html>**: This is the first line of an HTML document and it declares the document type. It specifies that this is an HTML5 document.

2. **<html>**: This tag defines the root element of an HTML document. It contains all the other elements of the document.

3. **<head>**: This tag contains the metadata of the document, such as the title, author, and keywords.

4. **<title>**: This tag specifies the title of the document, which is displayed in the browser's title bar.

5. **<body>**: This tag contains the content of the web page, such as text, images, videos, and other multimedia elements.

6. **<h1> to <h6>**: These tags are used to define headings in the web page. The <h1> tag is used for the main heading, while the <h2> to <h6> tags are used for subheadings.

7. **<p>**: This tag is used to define paragraphs in the web page.

8. **<img>**: This tag is used to insert images in the web page.

9. **<a>**: This tag is used to create hyperlinks in the web page.

10. **<ul>**: This tag is used to create an unordered list.

11. **<ol>**: This tag is used to create an ordered list.

12. **<li>**: This tag is used to define list items.

13. **<table>**: This tag is used to create a table in the web page.

14. **<tr>**: This tag is used to define a table row.

15. **<td>**: This tag is used to define a table cell.

16. **<form>**: This tag is used to create a form in the web page.

17. **<input>**: This tag is used to create input fields in the form.

18. **<textarea>**: This tag is used to create a text area in the form.

19. **<button>**: This tag is used to create a button in the form.

20. **<select>**: This tag is used to create a dropdown list in the form.

By using these tags, we can create a well-structured and organized web page. It is important to follow the standards and guidelines of HTML while creating web pages to ensure compatibility with different browsers and devices.

In conclusion, HTML documents are the basic building blocks of a web page. They are created using tags which define the structure and content of the page. By following the standards and guidelines of HTML, we can create well-structured and organized web pages that are compatible with different browsers and devices.
