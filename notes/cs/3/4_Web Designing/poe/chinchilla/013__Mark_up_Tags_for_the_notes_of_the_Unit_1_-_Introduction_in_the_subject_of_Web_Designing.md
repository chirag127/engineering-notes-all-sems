### Mark up Tags for the notes of the Unit 1 - Introduction in the subject of Web Designing

Web designing is a vast field that involves creating and designing websites. It includes various techniques and tools that help in designing and developing a website. One of the essential tools in web designing is mark up tags. Mark up tags are used to define the structure and content of a web page. They are the building blocks of a website and help in creating a well-designed and structured web page.

The following are the various mark up tags used in web designing:

- <!DOCTYPE html>: This tag is used to define the document type and version of HTML being used in the web page. It is usually the first line of the code and is required for all HTML documents.
- <html>: This tag is used to define the start and end of the HTML document. It contains all the other tags used in the web page.
- <head>: This tag is used to define the start and end of the head section of the web page. The head section contains the title of the web page, metadata, and other information that is not displayed on the web page.
- <title>: This tag is used to define the title of the web page. It is displayed on the browser's title bar and is essential for SEO.
- <body>: This tag is used to define the start and end of the body section of the web page. The body section contains all the visible content of the web page.
- <h1> to <h6>: These tags are used to define the headings of the web page. The <h1> tag is the largest heading, and <h6> is the smallest heading.
- <p>: This tag is used to define the paragraphs of the web page. It is used to separate the content into meaningful sections.
- <a>: This tag is used to define hyperlinks in the web page. It is used to link to other web pages or resources.
- <img>: This tag is used to define images in the web page. It is used to display images on the web page.
- <ul> and <li>: These tags are used to define unordered lists on the web page. The <ul> tag is used to define the start and end of the list, and the <li> tag is used to define each item in the list.
- <ol> and <li>: These tags are used to define ordered lists on the web page. The <ol> tag is used to define the start and end of the list, and the <li> tag is used to define each item in the list.
- <div>: This tag is used to define a container for content on the web page. It is used to group related content together.
- <span>: This tag is used to define a small section of content on the web page. It is used to apply styles or formatting to specific parts of the content.

In conclusion, mark up tags are essential in web designing as they help in defining the structure and content of a web page. The above-listed tags are the building blocks of a well-designed and structured web page. It is essential to use these tags correctly and appropriately to create an effective and functional website.
