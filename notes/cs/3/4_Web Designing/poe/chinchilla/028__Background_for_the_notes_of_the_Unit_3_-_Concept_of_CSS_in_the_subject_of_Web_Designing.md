### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS or Cascading Style Sheets is a critical component of web designing. It's used to control the layout and appearance of web pages, and it's essential to have a good understanding of CSS if you want to create visually appealing websites. In this unit, we will cover the fundamental concepts of CSS, including selectors, properties, and values, and how they can be used to create stunning web designs.

Here are some key points to keep in mind as you study the concept of CSS:

- CSS stands for Cascading Style Sheets, and it's a style sheet language used for describing the presentation of a document written in HTML or XML.
- CSS separates the presentation of a document from its content. With CSS, you can define the layout, colors, and fonts of a web page, among other things. This separation of presentation and content makes it easier to maintain and update a website.
- CSS uses selectors to target specific elements on a web page. Selectors can be based on the element type, class, ID, or other attributes.
- Properties define the visual style of an element, such as its color, size, and position. CSS properties have a name and a value, separated by a colon.
- Values determine the specific style of a property. For example, the value of the color property can be a named color or a hexadecimal value.
- CSS rules consist of one or more selectors and a set of properties and values. When a rule is applied to an element on a web page, it changes the visual appearance of that element.
- CSS can be applied to a web page in several ways, including inline styles, internal styles, and external stylesheets. The best practice is to use external stylesheets, as they allow for easy maintenance and consistency across multiple pages.
- CSS has evolved over the years, and the latest version is CSS3. CSS3 introduces new features such as transitions, animations, and media queries, which allow for more advanced and dynamic web designs.

In conclusion, CSS is an essential aspect of web designing, and understanding its concepts is crucial for creating visually appealing and user-friendly websites. This unit will provide you with a solid foundation of CSS concepts and techniques, which you can build upon as you continue to learn and explore the world of web design.
