### Display for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS or Cascading Style Sheets is an essential component of web designing. It allows web developers to control the layout and presentation of web pages. Here are some important concepts related to CSS:

1. **CSS Selectors:** Selectors are used to target specific HTML elements on a web page. CSS selectors can be based on element type, class, ID, attributes, and more. By using selectors, developers can apply styles to specific parts of a web page.

2. **CSS Properties:** CSS properties are used to define how HTML elements should be displayed on a web page. CSS properties can control attributes such as font size, color, background color, margins, padding, borders, and more.

3. **CSS Units:** CSS units are used to specify the size and position of HTML elements on a web page. CSS units can be relative or absolute. Relative units such as percentages and ems are based on the size of the parent element, while absolute units such as pixels are fixed.

4. **CSS Box Model:** The box model is used to describe how CSS properties such as margins, padding, and borders affect the size and position of HTML elements. The box model consists of four parts: content, padding, border, and margin.

5. **CSS Layouts:** CSS layouts are used to control the position and arrangement of HTML elements on a web page. CSS layouts can be based on floats, positioning, flexbox, or grid.

6. **CSS Media Queries:** Media queries are used to apply different styles to a web page based on the size and orientation of the device used to view it. Media queries can be used to create responsive designs that adapt to different screen sizes.

7. **CSS Frameworks:** CSS frameworks are pre-designed sets of CSS styles and layouts that can be used to quickly create a web page. Examples of CSS frameworks include Bootstrap, Foundation, and Materialize.

In summary, CSS is a powerful tool for controlling the layout and presentation of web pages. By using CSS selectors, properties, units, box model, layouts, media queries, and frameworks, web developers can create elegant and responsive designs that work on a range of devices.
