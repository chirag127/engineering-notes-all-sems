### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS or Cascading Style Sheets is a powerful tool used for designing and styling web pages. It allows web designers to separate the presentation of a website's content from its structure and functionality. In this unit, we will learn about the basic concepts of CSS and how to apply them to create visually appealing web pages. Here are some important points to help you understand the text format for the notes of this unit:

- CSS stands for Cascading Style Sheets.
- It is used to define the layout, colors, fonts, and other visual aspects of a web page.
- CSS can be used to style individual HTML elements, or it can be applied to an entire web page.
- CSS uses selectors to target specific HTML elements and apply styles to them.
- There are three types of CSS selectors: element selectors, class selectors, and ID selectors.
- Element selectors target all instances of a specific HTML element on a web page.
- Class selectors target specific HTML elements that have a particular class attribute.
- ID selectors target a single HTML element that has a unique ID attribute.
- CSS styles can be applied inline within HTML tags, in an external CSS file, or in a style block within the head section of an HTML document.
- CSS properties define the style of an HTML element, such as its font size, color, background color, and border.
- CSS values are the settings for the CSS properties, such as "red" for color or "20px" for font size.
- CSS can also be used to create animations and transitions on a web page.
- CSS frameworks like Bootstrap and Foundation provide pre-designed CSS styles and layouts to help speed up the web design process.
- It is important to use CSS efficiently to create fast-loading, mobile-friendly, and accessible web pages.

By understanding these basic concepts of CSS and practicing their application, you can create visually appealing and user-friendly web pages that will engage and delight your audience.
