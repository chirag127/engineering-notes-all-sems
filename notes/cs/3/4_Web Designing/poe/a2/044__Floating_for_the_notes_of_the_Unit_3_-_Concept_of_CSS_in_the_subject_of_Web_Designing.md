### Floating for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Floating is a CSS property that moves an element as far to the left or right of its container as possible, and allows the following content to wrap around the floated element.
2. The floated element is removed from the normal flow of the document and is positioned to the left or right of its container, depending on which value is specified.
3. Floating is commonly used to create entire web layouts, or to embed content side by side. For example, a logo/avatar image floated left with body text wrapping around it.
4. Possible values for the float property are:

- left - The element floats to the left side of its container
- right - The element floats to the right side of its container
- none - The element will not float and will remain in the normal flow of the document
- inherit - The element inherits the float value of its parent

5. Clearing the float is required when using floats, to ensure no unintended effects occur. This can be done by adding an extra CSS rule "clear: both;" after floating elements.
6. Some benefits of using floats are:
- Creating flexible and responsive layouts
- Placing elements side by side
- Creating entire web layouts
