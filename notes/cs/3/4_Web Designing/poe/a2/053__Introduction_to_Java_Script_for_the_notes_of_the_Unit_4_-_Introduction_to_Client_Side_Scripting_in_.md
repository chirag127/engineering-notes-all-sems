### Introduction to Java Script

1. Java Script is a lightweight, interpreted programming or scripting language that is typically embedded into web pages.
2. It allows web pages to be interactive and more dynamic.
3. Java Script is not Java:
- Java is a compiled programming language developed by Sun Microsystems (now owned by Oracle).
- Java Script is an interpreted scripting language developed by Netscape Communications.
- Java runs on the Java Virtual Machine (JVM), while Java Script runs in a web browser.
4. Java Script can:
- React to events like clicks, form input, etc.
- Manipulate HTML elements and styles.
- Access and manipulate cookies and other data.
- Get data from forms and URLs.
- Create cookies.
- Detect browser properties.
- Control animations and multimedia.
- Work with Ajax to load data from the server.
5. Java Script runs client-side in the web browser and communicates with the server using HTTP requests. This makes Java Script apps more responsive than apps that rely solely on server-side processing.
