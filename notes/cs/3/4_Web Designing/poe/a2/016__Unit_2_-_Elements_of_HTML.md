## Unit 2 - Elements of HTML

1. HTML Elements
- HTML elements consist of tags and the content between them.
- Tags are keywords (enclosed in angle brackets) that tell the browser what type of content to display.
- The opening tag contains the element name surrounded by angle brackets. The closing tag is the same but with a forward slash before the element name.
- Content is the text or other elements that lie between the opening and closing tags.

2. Elements have attributes
- Elements can have attributes that provide additional information about the element.
- Attributes are always specified in the opening tag.
- They are made up of a name and a value, separated by an equals sign. Attribute values are always enclosed in double or single quotation marks.

3. Nesting elements
- Elements can be nested (placed inside other elements).
- This is necessary to indicate the structure of the page and the relationships between the elements.
- The nested element is said to be the child of the enclosing (or parent) element.
