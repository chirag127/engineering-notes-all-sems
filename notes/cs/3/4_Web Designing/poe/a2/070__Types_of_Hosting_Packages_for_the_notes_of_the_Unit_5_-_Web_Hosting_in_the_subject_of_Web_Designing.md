### Types of Hosting Packages for the notes of the Unit 5 - Web Hosting in the subject of Web Designing

1. Shared Hosting:
- Low cost hosting where resources like disk space & bandwidth are shared between multiple websites
- Limited resources and low performance due to resource sharing
- Ideal for personal blogs or small business websites with low traffic

2. VPS Hosting:
- Virtual Private Server with dedicated resources but shared physical server
- More resources than shared hosting resulting in better performance
- Ability to install custom software and have more control
- Suitable for medium-sized businesses or websites with medium traffic

3. Dedicated Hosting:
- Entire physical server dedicated to hosting a single website
- No sharing of resources resulting in maximum performance
- Full control over the server for customization
- Most expensive but most powerful hosting suited for high-traffic websites or applications

4. Cloud Hosting:
- Resources distributed across multiple servers for scalability
- Pay-as-you-go model - pay only for resources used
- High performance and reliability due to resource distribution
- Automated scaling possible based on load
- Best for variable traffic websites or applications

The above points cover the major types of web hosting packages and their key characteristics to aid in understanding the options and making an informed choice for hosting a website.
