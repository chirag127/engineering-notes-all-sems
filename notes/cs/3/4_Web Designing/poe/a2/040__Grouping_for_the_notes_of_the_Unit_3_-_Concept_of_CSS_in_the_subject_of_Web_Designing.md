### Grouping for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets. It is used to style the HTML elements and give a proper layout to the web pages.
2. The CSS rules are made up of selectors and declarations. The selectors point to the HTML elements which need to be styled. The declarations are made of properties and values and define the styles.
3. There are three ways to add CSS to HTML: Inline style, Internal style sheet and External style sheet.
4. In inline style, the style is added to the HTML element using the style attribute.
5. In internal style sheet, the CSS is written within the <head> element inside a <style> element.
6. In external style sheet, the CSS is written in a separate .css file and linked to the HTML page using <link> element.
7. The internal and external style sheets have preference over inline styles as they follow the cascade in CSS. Hence, the cascading part of the name.
8. There are numerous properties available in CSS to style elements like color, background, margin, padding, border, font, width, height etc. The values of the properties can be keywords, units or percentages.
9. CSS selectors have certain precedence or specificity which is used to determine which styles get applied if there are multiple conflicting styles for an element. The more specific selector wins.
10. CSS styling can also be done using CSS classes and IDs which enable us to use the same styles across multiple HTML elements and pages.
