### Planning process for the notes of the Unit 1 - Introduction in the subject of Web Designing.

1. Introduction to Web Designing
- What is web designing? The process of creating websites.
- Goal of web designing: To create websites that are easy to navigate, fast to load, fit the purpose and are visually appealing.
- Types of web designers: Freelancers, Agency designers, In-house designers.

2. History of web and web designing
- Inception of the world wide web in 1989 by Tim Berners-Lee.
- Web 1.0: Static web pages with limited interactivity. HTML, CSS and JavaScript launched in this phase.
- Web 2.0: More dynamic websites with increased user interactivity and collaboration. Introduction of social networks, blogs and wikis.
- Modern web (Web 3.0/4.0): focus on mobile-friendliness, AI, AR/VR technologies. Trends like one-page websites and card-based designs.

3. Skills required for web designing
- Coding skills: HTML, CSS, JavaScript
- Design software skills: Photoshop, Illustrator, Sketch
- Version control: Git
- Additional skills: UX design, Responsive design, Cross-browser testing, SEO

4. Popular trends in web designing
- Increased use of animation and interactivity
- Parallax scrolling
- Mobile-first approach and responsive design
- Use of HTML 5 and CSS3
- Image-focused layouts
- Card-based layouts and grid-based layouts
- Voice-based interfaces
- Use of bold colors and textures...
