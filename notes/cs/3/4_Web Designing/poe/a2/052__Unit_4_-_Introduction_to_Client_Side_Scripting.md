## Unit 4 - Introduction to Client Side Scripting

1. Client side scripting refers to scripts that are executed by the browser to enhance the user experience on a web page.
2. It can be used to validate forms, detect browsers, create dynamic pages etc.
3. The scripts are embedded into the HTML pages and are interpreted by the browser to display the web page as intended.
4. The most common languages used for client side scripting are:
- JavaScript: Most widely used scripting language. Can be used to create interactive effects, validate forms etc.
- VBScript: Created by Microsoft. Used in Microsoft servers to create dynamic web pages.
- JScript: Microsoft's implementation of JavaScript.
5. Advantages:
- Enhances user experience and interactivity
- Reduces server load as scripts are executed on the client side
- Detected errors are reported immediately without the need to send information to the server
6. Disadvantages:
- Each browser may interpret the scripts differently leading to compatibility issues
- The source code is visible to the end user which can be a security concern
- The end user can disable scripts leading to loss of functionality
