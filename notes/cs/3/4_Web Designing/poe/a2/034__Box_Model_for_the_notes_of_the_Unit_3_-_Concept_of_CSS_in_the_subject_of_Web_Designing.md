### Box Model for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Every HTML element can be considered as a box. This box has certain properties which can be adjusted using CSS. This concept is known as Box Model in CSS.
2. The box model consists of:
- Content - The actual content of the element like text, image, etc.
- Padding - Transparent area around the content.
- Border - Border around the padding.
- Margin - Transparent area outside the border.
3. The width and height of a box can be adjusted using:
- content width and height - width and height properties
- total width and height - includes content, padding and border
4. Different box sizes can be calculated as:
Total width = Content width + Left padding + Right padding + Left border + Right border
Total height = Content height + Top padding + Bottom padding + Top border + Bottom border
5. Different elements display as different types of boxes:
- Block elements - Display as boxes stacked on top of each other. Takes full width available.
- Inline elements - Display side by side in a line. Takes only required space.
- Inline-block - Display as inline elements but can have width and height set.
