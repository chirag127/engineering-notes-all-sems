### JS Popup Boxes

1. Popup boxes are used to display messages or take input from the user.
2. They are created using JavaScript alerts, prompts and confirm boxes.
3. Alert box is used to display a message to the user. It has only one button to close the box.
Syntax: alert("Message");
4. Prompt box is used to take input from the user. It has two buttons - OK and Cancel.
Syntax: prompt("Message", "Default input");
5. Confirm box is used to take confirmation from the user. It has two buttons - OK and Cancel.
Syntax: confirm("Message");
6. The input taken from prompt box is always a string. It needs to be converted to other data types if required.
7. The confirm box returns a boolean value - true if OK is clicked and false if Cancel is clicked.
8. Popup boxes are less preferred now as they interrupt the user experience. More user friendly options like forms should be used instead to take input.

The notes cover the key points about JavaScript popup boxes - alerts, prompts and confirms. The syntax and usage of each type of popup box is explained with examples. The limitations and modern alternatives of using popup boxes are also highlighted.
