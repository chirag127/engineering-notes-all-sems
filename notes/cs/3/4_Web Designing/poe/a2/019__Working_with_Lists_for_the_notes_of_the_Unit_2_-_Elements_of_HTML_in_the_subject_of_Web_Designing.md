### Working with Lists for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing.

1. Ordered Lists: Lists where each item in the list is numbered. It is created using `<ol>` (ordered list) element.

Example:
<ol>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ol>

2. Unordered Lists: Lists that begin with a bullet point. It is created using `<ul>` (unordered list) element.

Example:
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

3. Definition Lists: Made up of a set of terms along with the definitions for each of those terms. It is created using `<dl>`, `<dt>`, and `<dd>` elements.

Example:
<dl>
  <dt>HTML</dt>
  <dd>Hypertext Markup Language</dd>
  <dt>CSS</dt>
  <dd>Cascading Style Sheets</dd>
  <dt>JavaScript</dt>
  <dd>Lightweight, interpreted programming or scripting language</dd>
</dl>

4. Nested Lists: Lists that are inserted into another list item. It is done by placing an ordered/unordered list within another list item.

Example:
<ul>
  <li>
    HTML
    <ul>
      <li>HTML Elements</li>
      <li>HTML Attributes</li>
      <li>HTML Headings</li>
    </ul>
  </li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
