## Unit 3 - Concept of CSS

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style a web page and control the layout of multiple web pages.
3. With CSS, you can define styles for a web page hierarchy, which means you can style the whole web page, or individual sections of a web page.
4. CSS saves a lot of work. It can control the style of multiple elements at once.
5. CSS is easy to learn and understand but has a lot of features.
6. Some important CSS concepts are:

- Selectors: Selectors are patterns used to select the elements you want to style.
- Declarations: Declarations are properties and values that specify how the elements should look.
- Properties: Properties are aspects of an element you want to change, e.g. color, font, width, height etc.
- Values: Values are the settings you want to use for a specific property, e.g. red, bold, 10px, auto etc.
- Rules: Rules consist of selectors and declarations which are also known as styles.

7. There are 3 ways to add CSS to HTML:

- Inline styles: Using the style attribute in HTML elements
- <h1 style="color:blue;">Heading</h1>

- Internal stylesheet: Using <style> element in the head section.
- <style>
  h1 {
    color: blue;
  }
</style>

- External stylesheet: Using a separate .css file.
- <link rel="stylesheet" href="styles.css">
