### Working with block elements and objects for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing.

1. Block elements: Block elements occupy the full width available to them and therefore start on a new line. Some common block elements are:

- <div>
- <p>
- <h1> to <h6>
- <form>
- <table>
- <ul> and <ol>

2. Inline elements: Inline elements do not start on a new line and only occupy the width they need. Some common inline elements are:

- <a>
- <span>
- <img>
- <input>

3. Positioning objects: In CSS, the position property is used to determine the type of positioning method used for an element. It can take following values:

- static: Default value. The element is positioned according to the normal flow of the page.
- relative: The element is positioned relative to its normal position.
- absolute: The element is positioned relative to its first parent element that has a position other than static.
- fixed: The element is positioned relative to the viewport, which means it always stays in the same place even if the page is scrolled.
- sticky: The element is positioned based on the user's scroll position.

4. Display property: The display property specifies the type of rendering box used for an element. For example:

- block: Displays an element as a block element.
- inline: Displays an element as an inline element.
- inline-block: Displays an element as an inline-block.
- none: Hides an element.
