### Defining Name Servers for the notes of the Unit 5 - Web Hosting in the subject of Web Designing.

1. Name servers are servers that translate a domain name into an IP address. They are an integral part of the domain name system (DNS).
2. When a user enters a domain name into their web browser, the request is sent to a name server to find the corresponding IP address. The name server then returns the IP address to the user's computer, which connects to the website.
3. There are two types of name servers:
- Primary name servers: Maintain the master list of domain names and IP addresses.
- Secondary name servers: Retrieve information from the primary name servers and store copies of the domain name database. They provide faster responses and redundancy.
4. A domain name can have multiple name servers for redundancy and performance. The name servers for a domain are specified in the domain's DNS configuration.
