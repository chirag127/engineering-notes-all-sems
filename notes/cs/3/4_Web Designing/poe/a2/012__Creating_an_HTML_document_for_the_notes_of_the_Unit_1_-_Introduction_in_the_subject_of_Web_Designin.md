### Creating an HTML document for the notes of the Unit 1 - Introduction in the subject of Web Designing.

1. Declare the doctype - <!DOCTYPE html>
2. Add the HTML tag - <html>
3. Add the head section - <head>
- Add the title - <title>Page Title</title>
- Add the meta tags for charset and viewport
- Add the stylesheets link (if any)
- Add the scripts link (if any)
</head>
4. Add the body section - <body>
- This will contain the actual content of the web page
- You can add headings, paragraphs, images, lists, links, tables, forms, etc.
</body>
5. Close the HTML tag - </html>

The above structure creates a basic HTML document which can be used to build a web page. The head section contains the metadata about the page and the body section contains the visible page content.
