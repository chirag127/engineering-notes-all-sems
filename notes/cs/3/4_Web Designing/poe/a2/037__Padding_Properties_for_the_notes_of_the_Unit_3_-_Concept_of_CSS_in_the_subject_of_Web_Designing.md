### Padding Properties for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Padding refers to the space between the content and its border. It increases the clickable or tappable area of an element and separates the content from its border.
2. Padding can be specified using the padding property shorthand or using individual properties:
- padding-top
- padding-right
- padding-bottom
- padding-left
3. Padding values can be specified in the following ways:
- Length values: px, em, cm, etc.
- Percentage values: % of the width of the containing block
- inherit: Inherits the padding value of the parent element
4. The padding area is transparent. This means that the background color or image of the parent element will show through.
5. Negative values are not allowed. If a negative value is specified, it will be converted to 0.
6. The total padding area cannot exceed the width/height of the element. If it does, the values will be clipped at the element edge.
