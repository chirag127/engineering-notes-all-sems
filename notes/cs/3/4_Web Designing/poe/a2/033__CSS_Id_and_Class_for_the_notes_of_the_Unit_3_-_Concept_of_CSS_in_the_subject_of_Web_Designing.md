### CSS Id and Class for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. ID: Used to identify a unique element in a HTML document. Only one element can have a particular ID.
Syntax: <element id="id_name">
Example: <div id="main_div">

2. Class: Used to identify a group of elements in a HTML document. Multiple elements can have the same class.
Syntax: <element class="class_name">
Example: <div class="box">
<p class="box">Paragraph</p>

3. Advantages:
- IDs and Classes help in easy styling of elements using CSS.
- They provide a way to uniquely identify elements and apply styles.
- The same style can be applied to multiple elements having the same class.

4. Differences:
- An ID can be used to identify only one element whereas a class can be used to identify multiple elements.
- The syntax to define ID starts with # whereas for class it starts with .
- ID has higher specificity than class in CSS.
