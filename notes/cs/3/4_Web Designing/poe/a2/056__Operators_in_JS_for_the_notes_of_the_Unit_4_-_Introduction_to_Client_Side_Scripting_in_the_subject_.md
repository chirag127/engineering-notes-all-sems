### Operators in JS for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

1. Arithmetic operators: Used to perform arithmetic operations like addition, subtraction, multiplication, division, remainder.
Eg: +, -, *, /, %

2. Assignment operators: Used to assign values to variables.
Eg: =, +=, -=, *=, /=, %=, ...

3. Comparison operators: Used to compare values and return a boolean value.
Eg: ==, ===, !=, !==, >, <, >=, <=

4. Logical operators: Used to combine conditional statements.
Eg: && (and), || (or), ! (not)

5. String operators: Used to concatenate strings and return a new string.
Eg: +

The operators can be used to construct expressions and control the flow of a program based on certain conditions using conditional logic.
