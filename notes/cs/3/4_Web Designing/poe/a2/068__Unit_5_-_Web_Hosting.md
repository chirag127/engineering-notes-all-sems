## Unit 5 - Web Hosting

1. Web hosting is a service that allows organizations and individuals to post a website or web page onto the Internet. A web hosting service is a type of Internet hosting service that allows individuals and organizations to make their website accessible via the World Wide Web.

2. Web hosts typically offer space on a server they own or lease for use by their clients as well as providing Internet connectivity, typically in a data center.

3. There are various types of web hosting options available:

- Shared web hosting: Multiple websites are hosted on the same server sharing its resources like memory, CPU, storage, etc. It is most economical but has performance issues due to resource sharing.
- VPS (Virtual Private Server) hosting: A virtual machine is allocated as a dedicated server for hosting a website. Resources can be scaled up or down easily and performance is better than shared hosting. Cost is in between shared and dedicated hosting.
- Dedicated server hosting: Client has the entire server for hosting the website. Resources can be scaled and performance is very good. Cost is the highest among all options.
- Cloud hosting: Resources are scaled on demand and the client is charged based on usage. Performance is very good and cost is less than dedicated server hosting. Resources can scale up and down easily based on traffic.

4. Key things to consider when choosing a web hosting service are:

- Type of hosting (shared, VPS, dedicated, cloud) based on requirements and budget
- Reliability and uptime of the hosting service
- Technical support availability
- Scalability to handle growth in website traffic
- Security measures and backups provided
- Cost and pricing structure (monthly vs yearly plans, resource limits, etc.)
