### Mark up Tags

1. HTML: Hypertext Markup Language is the main markup language used to create web pages. It uses tags like <html>, <head>, <title>, <body>, <h1>, <p>, etc. to structure a web page and add content.
2. XHTML: Extensible Hypertext Markup Language is a reformulation of HTML 4 as an XML application. It has stricter rules for correctly nesting tags and using attributes.
3. CSS: Cascading Style Sheets is used to style the HTML elements and control the layout of a web page. It uses selectors to target HTML elements and properties to change the look and feel.
4. Elements: The basic building blocks of an HTML document are elements. They are denoted using tags. For example, <h1> is an element used for the most important heading on a page.
5. Tags: Tags are keywords (enclosed in angle brackets) that tell the browser what type of content they surround. For example, the <h1> tag indicates that the text it surrounds is a top-level heading.
6. Attributes: Additional information about an element can be specified using attributes. They are always specified in the start tag. For example, <a href="https://www.example.com"> is the link element with the href attribute specifying the linked URL.
