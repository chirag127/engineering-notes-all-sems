### Tables and Frames for the notes of the Unit 2 - Elements of HTML

*Tables*
- Used to display data in rows and columns
- Defined using `<table>` element
- Each row defined using `<tr>` (table row)
- Each column defined using `<td>` (table data)
- `<th>` used for headers
- `cellspacing`, `cellpadding`, `border`, `width`, `height`, etc. can be used to style
- Example:
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Alice</td>
    <td>24</td>
  </tr>
</table>

*Frames*
- Used to divide webpages into sections
- Defined using `<frameset>` and `<frame>` elements
- `<frameset>` specifies number of columns and rows
- `<frame>` specifies which HTML document to load in each section
- Falling out of use due to accessibility and usability issues
- Example:
<frameset cols="50%,50%">
  <frame src="frame_1.html" />
  <frame src="frame_2.html" />
</frameset>
