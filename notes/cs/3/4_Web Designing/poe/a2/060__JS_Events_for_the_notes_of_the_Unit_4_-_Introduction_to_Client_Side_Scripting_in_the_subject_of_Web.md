### JS Events for the notes of the Unit 4 - Introduction to Client Side Scripting

1. Events: Actions or occurrences that happen in the system you are programming, which the system tells you about so you can respond to them in some way if desired.
2. Examples of events:
    - Web page finishing loading
    - Form being submitted
    - Button being clicked
    - Mouse moving over an element
    - Key being pressed
3. Types of events:
    - User interaction events: click, dblclick, mousedown, mouseup, mouseover, mouseout, keypress, keydown, keyup, submit, focus, blur, change, input
    - Browser events: load, unload, abort, error, resize, scroll
4. Use of events:
    - Respond to user actions like clicking a button, filling out a form, etc.
    - React to browser events to adjust the page or interface accordingly
5. Attaching event handlers:
    - HTML event attributes: <button onclick="doSomething()">Click Me</button>
    - DOM methods: element.onclick = function() { /* do something */ }
    - addEventListener method: element.addEventListener("click", function() { /* do something */ })
