### Controlling Fonts for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Font-family: This property is used to specify the font face to be used for the text. Some commonly used font families are:
- Sans-serif: Fonts like Arial, Calibri, Helvetica, etc.
- Serif: Fonts like Times New Roman, Georgia, etc.
- Monospace: Fonts like Courier New, Lucida Console, etc.

2. Font-size: This property is used to specify the size of the font. It can be defined in pixels(px), rems, ems, percentages, etc. Some examples are:
- 16px
- 1.2em
- 125%

3. Font-style: This property is used to specify the font style and can have values like:
- normal: Sets the text to normal style
- italic: Sets the text to italic style
- oblique: Sets the text to oblique style

4. Font-weight: This property is used to specify the thickness or boldness of the font and can have values like:
- normal: Text is displayed using a normal weight font
- bold: Text is displayed using a bold font weight
- 100, 200, 300, 400, 500, 600, 700, 800, 900: Specifies font weight numerically

5. Text-transform: This property is used to specify the capitalization of the text and can have values like:
- none: No effect on the text
- uppercase: Converts the text to uppercase
- lowercase: Converts the text to lowercase
- capitalize: Capitalizes the first letter of each word
