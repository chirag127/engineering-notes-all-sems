### Display

1. Display property specifies how/if an element is displayed.
2. Values:
- none: Hides the element.
- block: Displays the element as a block element (like <p>).
- inline: Displays the element as an inline element (like <span>).
- inline-block: Displays the element as an inline-block element.
- flex: Displays the element as a block-level flex container.
- grid: Displays the element as a block-level grid container.
3. Example:
    div {
      display: inline;
    }

4. Default display values:
- Block-level elements: display: block
- Inline elements: display: inline
- Others: display: inline-block

5. Changing the display of an element can alter its behavior and appearance. This is often used to create responsive web designs and grid layouts.
