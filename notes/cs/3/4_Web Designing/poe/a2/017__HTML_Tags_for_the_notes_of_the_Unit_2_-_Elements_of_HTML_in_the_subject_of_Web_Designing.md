### HTML Tags for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing:

1. HTML Tags: HTML tags are keywords (enclosed in angle brackets) that tell the browser what type of information they surround.

2. Opening Tag: The opening tag indicates where a particular element begins. For example, <html> indicates the beginning of the HTML document, <head> indicates the beginning of the head section, and <title> indicates the beginning of the title element.

3. Closing Tag: The closing tag indicates where an element ends. Most HTML elements have both an opening tag and a closing tag. Closing tags begin with </ followed by the element name. For example, </html> indicates the end of the HTML document, </head> indicates the end of the head section, and </title> indicates the end of the title element.

4. Content: The content of an element appears between its opening and closing tags. For example, the title element contains the title of the document between its opening <title> and closing </title> tags.

5. Attributes: HTML elements can have attributes that provide additional information about the element. For example, the href attribute specifies the Uniform Resource Locator (URL) of a linked resource (the address of a web page). Attributes are always specified in the opening tag.
