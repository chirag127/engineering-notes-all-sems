### Related Examples for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing.

1. Displaying alert message: We can display an alert message on web page using JavaScript's alert() function. For example, alert('Hello World'); will display a message box with 'Hello World' message.

2. Displaying prompt dialog box: We can get input from the user using prompt() function. For example, prompt('Enter your name:'); will display a prompt dialog box asking user to enter name. The input entered by the user is returned by the prompt() function.

3. Displaying confirmed dialog box: We can get confirmation from the user using confirm() function. For example, confirm('Are you sure?'); will display a confirm dialog box with 'Are you sure?' message and returns true if user clicks OK and false if user clicks Cancel.

4. Changing web page content: We can change the content of a web page dynamically using JavaScript. For example, document.write('Hello World'); will write 'Hello World' to the web page. We can also get elements by ID or tag name and modify their content using properties like innerHTML.

5. Adding interactivity: We can add interactivity to web pages using JavaScript. For example, we can display an alert when a button is clicked or we can validate a form before submitting using JavaScript functions. We can attach JavaScript functions to events like onclick, onblur, onsubmit etc. to add interactivity.
