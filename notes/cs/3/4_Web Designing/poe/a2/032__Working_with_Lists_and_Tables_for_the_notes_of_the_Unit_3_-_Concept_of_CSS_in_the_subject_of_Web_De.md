### Working with Lists and Tables for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing:

1. Lists:
- Ordered Lists: Lists with sequence like 1, 2, 3, etc. Created using <ol> element.
- Unordered Lists: Lists with bulleted points. Created using <ul> element.
- Definition Lists: Lists of terms and their definitions. Created using <dl> element.

2. Tables:
- Used to display data in rows and columns.
- Created using <table> element.
- Table Header: Created using <th> element. Used for headings.
- Table Rows: Created using <tr> element. Holds the table cells.
- Table Cells: Created using <td> element. Hold the content of the table.
- Colspan: Used to make a cell span across multiple columns.
- Rowspan: Used to make a cell span across multiple rows.
- Table Borders: Added using CSS border property.
