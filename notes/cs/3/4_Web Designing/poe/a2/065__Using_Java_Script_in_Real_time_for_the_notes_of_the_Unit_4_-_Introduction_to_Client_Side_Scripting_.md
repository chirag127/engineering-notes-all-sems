### Using Java Script in Real time for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing.

1. Java Script is a lightweight, interpreted programming or scripting language that is typically embedded into web pages.
2. It allows web pages to be interactive and more dynamic.
3. Java Script code is executed by the browser and it can react to user events, dynamically modify web page content, communicate with servers, and more.
4. Some of the uses of Java Script are:
    - Displaying popup messages.
    - Validating web form data.
    - Creating cookies.
    - Redirecting web pages.
    - Animations and effects.
    - Communicating with servers using AJAX.
5. The Java Script code is embedded within the HTML page inside the <script> tags or it can be stored in an external .js file and linked to the HTML page.
6. Some of the core concepts in Java Script are:
    - Variables - To store data.
    - Data types - To specify the type of data a variable can store.
    - Operators - To perform operations on variables.
    - Control flows - To control the flow of execution of code.
    - Functions - To encapsulate code.
    - Objects - To model real world things.
7. The document object model (DOM) is a programming interface for HTML and XML documents. It represents the page so that it can be manipulated by Java Script.
8. The Java Script can be used to dynamically modify the content, structure, and style of a web document. It can create, modify, and delete elements and attributes.
