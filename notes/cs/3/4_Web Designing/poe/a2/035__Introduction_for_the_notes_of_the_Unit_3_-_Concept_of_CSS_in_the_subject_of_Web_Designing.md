### Introduction for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style the HTML elements and give a proper look and design to a web page.
3. Some of the uses of CSS are:

- Change the color of the text.
- Change the background color of the page or elements.
- Control the font family.
- Control the size of the font.
- Add padding, margins, and borders.
- Change the layout of the elements.
- Animate elements.
- Hide elements.
- Customize scrollbars.

4. There are three ways to implement CSS:

- Inline Styling: Using the style attribute in HTML elements.
- Internal Styling Sheet: Using <style> element in the head section.
- External Styling Sheet: Using a separate CSS file and linking it to the HTML file.

5. Some of the advantages of using CSS are:

- It makes web pages attractive and presents the content in a proper way.
- It saves a lot of work as you can control the styling of multiple HTML elements in one CSS rule.
- It makes web pages faster to load as the CSS file can be cached, and browsers can render pages faster.
- It makes web pages more accessible to users as they can control the styles using their browser settings.
- It makes maintenance easy as you only need to update the CSS file to change the look of the entire web page.
