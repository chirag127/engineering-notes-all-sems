### Domains and Hosting for the notes of the Unit 1 - Introduction in the subject of Web Designing.

1. Domain Name: The domain name is the unique name that identifies a website on the internet. It is the address that users type into the browser to access a website. For example, 'google.com' is the domain name for Google's website. One can purchase a domain name from a domain name registrar.

2. Web Hosting: Web hosting refers to the service that hosts the website files and serves the website to users over the internet. The web hosting service provides space on its servers for hosting the website files and delivers the website as requested by users. One needs to purchase web hosting from a web hosting service provider to publish a website live on the internet. The website files are uploaded to the web hosting which is then accessible via the domain name.

3. Types of Web Hosting: The major types of web hosting are:
- Shared Hosting: In shared hosting, multiple websites are hosted on the same server sharing its resources. It is affordable but can face performance issues due to resource sharing.
- VPS Hosting: In VPS (Virtual Private Server) hosting, a portion of the server is allocated to the website. It offers more resources than shared hosting but is costlier.
- Dedicated Hosting: In dedicated hosting, the entire server is leased to host a single website. It offers maximum performance and resources but is the most expensive type of hosting.

4. Factors to consider while choosing Hosting: The main factors to consider while choosing a web hosting service are:
- Cost of hosting
- Bandwidth and storage capacity
- Server uptime and reliability
- Customer support
- Ease of website management
- Technical requirements compatibility

The above points cover the key concepts regarding domains and hosting which are fundamental to publishing a website on the internet.
