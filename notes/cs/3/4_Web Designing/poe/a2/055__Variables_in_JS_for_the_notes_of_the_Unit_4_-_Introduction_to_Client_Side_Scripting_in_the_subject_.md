### Variables in JS

1. Variables are containers for storing data values.
2. Variables in JS are declared using the var keyword followed by the variable name. For example: var x;
3. Variables can store different types of data such as strings, numbers, booleans, etc. The data type is identified automatically by JS when the value is assigned to the variable. For example:
    - var stringVar = "Hello"; // string
    - var numberVar = 10; // number
    - var booleanVar = true; // boolean
4. The value of a variable can be changed and reassigned. For example:
    var x = 5;
    x = 10; // value of x is now 10
5. Variables in JS are loosely typed which means we do not need to specify the data type of a variable while declaring it. The type is associated with the value.
6. Variables must be declared before use. Otherwise, a ReferenceError occurs.
7. Variable names in JS can contain letters, digits, underscores, and dollar signs but cannot contain spaces or start with a number. For example:
    - valid: age, salary, _name, $var
    - invalid: 1age, var age, var name with space
