### Creating page Layout and Site Designs for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. Introduction to CSS
- CSS stands for Cascading Style Sheets.
- It is used to style the web pages and applied using style attributes or <style> tag or external .css files.
- It separates the presentation of the content from the content itself.

2. Why use CSS?
- It makes web pages attractive and appealing to the viewers.
- It saves time by allowing the web designer to change the look and feel of the entire web page by editing just one single CSS file.
- It increases accessibility and flexibility.
- It improves the load time of web pages as the CSS files can be cached.

3. How to implement CSS?
- Inline styling: Using the style attribute in the HTML elements.
- <style> tag: Using the <style> tag in the head section of the HTML page.
- External CSS: Creating a .css file and linking it to the HTML page using <link> tag.
