### CSS Styling for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

1. CSS stands for Cascading Style Sheets.
2. CSS is used to style the web pages and provide an attractive look and feel to the web pages.
3. CSS separates the presentation of the HTML document from the HTML structure. This makes the web page more accessible and easy to maintain.
4. The CSS rules are specified in the CSS files with .css extension. The CSS files are then linked with the HTML files using <link> tag inside the <head> section.
5. CSS works on the basis of selectors and declarations. The selectors specify the HTML elements to be styled. The declarations contain the properties and their values which are to be set for the elements.
6. CSS has various properties like color, background-color, font-size, text-align, etc which can be used to style the elements in numerous ways.
7. CSS can be embedded in HTML document, put in a separate CSS file or can be written in the HTML <style> tag.
8. CSS focuses on presentation, is easy to maintain and makes the web pages more accessible. The separation of concerns helps to reduce the complexity of the web pages.
9. CSS positioning is used to determine the actual position of the elements on the screen. It has properties like float, clear, position, top, bottom, left, right, z-index, etc to position the elements as required.
