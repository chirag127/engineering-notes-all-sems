### Working with Forms and controls for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing.

1. Forms: Forms are required to take input from the user. They contain form elements like input fields, radio buttons, checkboxes, submit buttons, etc.
2. Input fields: Used to take input text from the user. Different types are text, password, email, number, range, etc.
3. Radio buttons: Used when only one option is required to be selected from multiple options.
4. Checkboxes: Used when multiple options are required to be selected from multiple options.
5. Submit buttons: Used to submit the form data to the server for processing.
6. Text area: Used for taking multiple line text input from the user.
7. Labels: Used to provide captions to the form elements.
8. Form attributes: Action, method and id are some important form attributes. Action specifies the URL to send the data to. Method specifies the HTTP method to send the data. Id is used to identify the form.

The above points cover the key elements and attributes used while working with forms in HTML. Forms are an important way to take user input and send data to the server. Proper structure and usage of form controls and elements is essential to create effective forms.
