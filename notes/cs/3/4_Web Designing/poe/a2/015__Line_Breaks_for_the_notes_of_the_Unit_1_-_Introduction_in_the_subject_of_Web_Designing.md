### Line Breaks

1. Line breaks are inserted using the <br> tag.
2. The <br> tag is an empty element tag which means it does not have a closing tag.
3. It is used to add a line break or move to the next line in a text.
4. For example:
This is line 1<br>
This is line 2

5. In the output, line 2 will appear on a new line after line 1 due to the <br> tag inserted between the lines.
6. Line breaks are useful in :
- Poems or addresses to format the content in lines.
- In headings or paragraphs to add spacing.
- In forms to move to the next field.

7. However, using line breaks excessively can make the content look messy or disjointed. Use them judiciously for proper formatting and layout.
