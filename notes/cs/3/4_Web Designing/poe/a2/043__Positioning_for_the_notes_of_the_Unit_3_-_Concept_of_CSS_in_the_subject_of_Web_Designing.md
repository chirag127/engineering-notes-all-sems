### Positioning for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing.

1. Static Positioning: This is the default positioning of an element where it appears in the normal flow of the page. No positioning properties are required.
2. Relative Positioning: The element is positioned relative to its normal position. This means "move the element X pixels horizontally" and "move the element Y pixels vertically". Other elements do not adjust their positions to fit the relatively positioned element.
3. Absolute Positioning: The element is positioned relative to its first non-statically positioned ancestor element. It is removed from the normal flow of the document and other elements behave as if it is not there.
4. Fixed Positioning: The element is positioned relative to the viewport, so it always stays in the same place on the screen. It is removed from the normal flow of the document and other elements behave as if it is not there.
5. Stacking Contexts: When multiple elements overlap, the element with the higher stacking context will appear on top of the others. The root element has the highest stacking context by default but the z-index property can be used to control the stacking order.
