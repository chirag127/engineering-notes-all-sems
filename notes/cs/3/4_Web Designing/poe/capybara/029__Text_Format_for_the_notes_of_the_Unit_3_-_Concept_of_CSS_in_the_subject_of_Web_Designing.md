### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS stands for Cascading Style Sheets. It is a style sheet language used for describing the presentation of a document written in HTML or XML. It is used to control the layout, fonts, colors, and other visual elements of a web page.

Text formatting is an essential aspect of CSS. Here are the different ways to format text using CSS:

1. Font Properties: CSS provides various font properties such as font-family, font-size, font-style, font-weight, and font-variant to format the text. These properties help in controlling the appearance of the text by changing the font, size, style, weight, and variant.

2. Text Color: CSS allows changing the color of the text using the color property. The color can be defined using different methods such as color name, hexadecimal value, RGB value, and HSL value.

3. Text Decoration: CSS provides text-decoration property to add or remove the underline, overline, line-through, and blink effects to the text.

4. Text Alignment: CSS provides text-align property to align the text horizontally. It can be aligned to the left, right, center, or justified.

5. Text Indentation: CSS provides text-indent property to indent the first line of the text. It can be used to create a paragraph or a blockquote.

6. Text Transform: CSS provides text-transform property to transform the text. It can be used to change the case of the text, such as uppercase, lowercase, or capitalize.

7. Letter Spacing: CSS provides letter-spacing property to adjust the spacing between the letters. It can be used to increase or decrease the space between the letters.

8. Line Height: CSS provides line-height property to adjust the height of the lines. It can be used to increase or decrease the space between the lines.

In conclusion, text formatting is an essential aspect of CSS. It helps in controlling the appearance of the text and making it more readable and attractive. It is essential to have a good understanding of text formatting to create visually appealing web pages.
