### Conditions Statements for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

Client-side scripting involves the use of scripts on the user's browser to create interactive web pages. One of the essential features of client-side scripting is the use of condition statements. In this section, we will look at the different types of condition statements that are used in client-side scripting.

#### 1. If statements

If statements are used to make decisions based on the evaluation of one or more conditions. The syntax for an if statement is as follows:

```
if (condition) {
    // code to be executed if the condition is true
}
```

#### 2. If-else statements

If-else statements are used to execute different code depending on whether a condition is true or false. The syntax for an if-else statement is as follows:

```
if (condition) {
    // code to be executed if the condition is true
} else {
    // code to be executed if the condition is false
}
```

#### 3. Nested if statements

Nested if statements are if statements that are placed inside other if statements. They are used to check for multiple conditions. The syntax for a nested if statement is as follows:

```
if (condition1) {
    if (condition2) {
        // code to be executed if both conditions are true
    }
}
```

#### 4. Switch statements

Switch statements are used to execute different code depending on the value of a variable. The syntax for a switch statement is as follows:

```
switch (variable) {
    case value1:
        // code to be executed if the variable is equal to value1
        break;
    case value2:
        // code to be executed if the variable is equal to value2
        break;
    default:
        // code to be executed if the variable is not equal to any of the values
}
```

In conclusion, condition statements are an essential part of client-side scripting. They allow us to make decisions and execute different code depending on the conditions that are met. Understanding the different types of condition statements and how to use them can help us create more interactive and dynamic web pages.
