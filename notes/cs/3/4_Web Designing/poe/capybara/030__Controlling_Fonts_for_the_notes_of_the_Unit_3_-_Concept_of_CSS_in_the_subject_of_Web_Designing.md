### Controlling Fonts for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Web Designing is an important aspect of creating a website. CSS plays a crucial role in designing the website. Fonts are one of the important elements of web designing. Controlling fonts using CSS is essential to enhance the website's look and feel. Here are some points to understand how to control fonts using CSS:

- CSS has the capability to control the font type, size, style, and color of the text displayed on the website. 
- The font-family property in CSS is used to define the font used in the website. 
- The font-size property is used to define the size of the font used on the website. 
- The font-style property is used to set the style of the font used on the website. It can be set to normal, italic, or oblique. 
- The font-weight property is used to set the weight of the font used on the website. It can be set to normal, bold, bolder, or lighter. 
- The color property is used to set the color of the font used on the website. 

By using the above mentioned CSS properties, one can easily control the fonts used in their website. It is important to choose the right font that complements the website's design and is easy to read. 

Remember, the font used in a website is a reflection of its brand value and identity. Hence, proper attention must be given while choosing and controlling fonts using CSS in web designing.
