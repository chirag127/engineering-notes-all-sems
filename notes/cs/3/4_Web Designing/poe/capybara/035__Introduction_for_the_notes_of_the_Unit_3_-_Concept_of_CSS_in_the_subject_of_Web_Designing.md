### Introduction

In this unit, we will be discussing the concept of CSS (Cascading Style Sheets) and how it is used in web designing. CSS is an important aspect of web development, as it allows us to control the visual appearance of our web pages.

Here are some key points to keep in mind as we explore the concept of CSS:

- CSS stands for Cascading Style Sheets and is a language used to describe the presentation of HTML documents.
- CSS can control the layout, colors, fonts, and other visual aspects of a webpage.
- The syntax of CSS includes selectors, properties, and values.
- CSS can be added to an HTML document in three ways: inline, internal, and external.
- Inline CSS is added directly to an HTML element using the "style" attribute.
- Internal CSS is added to an HTML document using the "style" element in the head section of the page.
- External CSS is stored in a separate file and linked to an HTML document using the "link" element in the head section of the page.
- CSS follows a cascading rule, where styles are applied in a specific order: inline styles, internal styles, external styles, and finally the browser's default styles.
- CSS also has the concept of specificity, which determines which styles take precedence over others.
- CSS can also be used with media queries to create responsive design, where the layout and style of a webpage changes based on the size of the screen it is being viewed on.

As we dive deeper into the concept of CSS, we will explore each of these points in more detail and learn how to use CSS to create visually appealing and responsive web pages.
