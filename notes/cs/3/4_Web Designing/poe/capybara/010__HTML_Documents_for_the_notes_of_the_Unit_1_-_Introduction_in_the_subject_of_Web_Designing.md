### HTML Documents

HTML documents are the building blocks of web pages. HTML stands for 'Hyper Text Markup Language' and is used to create web pages that are displayed on the internet. In this unit, you will learn about HTML documents and how they are used in web designing.

Here are some key points to remember about HTML documents:

- HTML documents are text documents that contain HTML markup tags.
- The file extension for an HTML document is '.html' or '.htm'.
- HTML documents are made up of various elements such as headings, paragraphs, images, and links.
- The basic structure of an HTML document consists of the HTML tag, head tag, and body tag.
- The HTML tag is used to identify the document as an HTML document.
- The head tag contains information about the document such as the title and meta data.
- The body tag contains the content of the web page.
- HTML documents are created using a text editor such as Notepad or Sublime Text.
- HTML documents can be viewed in a web browser such as Google Chrome, Mozilla Firefox, or Microsoft Edge.

In conclusion, understanding HTML documents is essential for web designing. HTML documents allow us to create web pages that are displayed on the internet. By mastering the basics of HTML documents, you can create beautiful and functional web pages that are accessible to everyone.
