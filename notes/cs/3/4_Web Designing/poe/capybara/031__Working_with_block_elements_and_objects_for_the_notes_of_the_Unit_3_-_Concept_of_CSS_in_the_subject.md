### Working with Block Elements and Objects

CSS is used to style and position HTML elements. In this unit, you will learn about working with block elements and objects to create visually appealing websites.

#### Block elements

Block elements are HTML elements that create a rectangular block on the web page. These elements are used to structure the content of the web page. Some of the commonly used block elements are:

- `<div>`: This element is used to group other HTML elements together and apply styles to them.
- `<p>`: This element is used to define a paragraph of text.
- `<h1>` to `<h6>`: These elements are used to define headings of different levels.

#### Objects

Objects are HTML elements that are not rectangular in shape. These elements are used to add visual interest to the web page. Some of the commonly used objects are:

- `<img>`: This element is used to add images to the web page.
- `<video>`: This element is used to add videos to the web page.
- `<audio>`: This element is used to add audio files to the web page.
- `<canvas>`: This element is used to create graphics on the web page.

#### Styling block elements and objects

CSS is used to style block elements and objects. You can use CSS to change the color, font, size, and position of these elements. Some of the commonly used CSS properties for styling block elements and objects are:

- `background-color`: This property is used to change the background color of an element.
- `font-family`: This property is used to change the font family of an element.
- `font-size`: This property is used to change the font size of an element.
- `position`: This property is used to change the position of an element.
- `margin` and `padding`: These properties are used to add spacing around an element.

In conclusion, understanding how to work with block elements and objects is an important part of creating visually appealing websites using CSS. It is important to use CSS to style these elements to ensure that the web page looks professional and is easy to navigate.
