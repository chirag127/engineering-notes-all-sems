### Align for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS or Cascading Style Sheets is a style sheet language used for describing the presentation of a document written in HTML or XML. CSS is widely used in web design to control the appearance of web pages. The following are some important points to keep in mind while studying the concept of CSS:

- CSS stands for Cascading Style Sheets and is used for styling web pages.
- CSS separates the presentation of web pages from their content, making it easier to maintain and update the website.
- CSS can be applied to HTML elements in three ways: inline, internal, and external.
- Inline CSS is applied directly to an HTML element using the "style" attribute.
- Internal CSS is defined in the "head" section of an HTML document using the "style" tag.
- External CSS is defined in a separate CSS file and linked to the HTML document using the "link" tag.
- CSS selectors are used to target specific HTML elements and apply styles to them.
- CSS properties are used to define the style of HTML elements, such as font size, color, background color, and more.
- CSS also allows for the creation of complex page layouts, such as grids and columns.
- CSS can be used to create responsive design, which allows a website to adapt to different screen sizes and devices.
- CSS frameworks, such as Bootstrap and Foundation, provide pre-designed CSS styles and components to make web design easier and faster.

By understanding the concept of CSS and its various applications, web designers can create visually appealing and functional websites that meet the needs of their clients.
