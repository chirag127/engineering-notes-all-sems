### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS or Cascading Style Sheets is a powerful tool used to control the presentation of a website. It allows developers to separate the content of a website from its presentation, making it easier to manage and update.

Here are some background points to help you understand the concept of CSS:

- CSS was first introduced in 1996 and has since become an essential part of web design.
- It was created by Håkon Wium Lie and Bert Bos, who were working for the W3C (World Wide Web Consortium) at the time.
- CSS allows developers to define styles for HTML elements, such as font size, color, and layout.
- It also allows for the creation of more advanced effects, such as animations and transitions.
- With CSS, developers can create responsive designs that adapt to different screen sizes and devices.
- CSS can be used in conjunction with other web technologies, such as JavaScript and HTML5, to create complex and dynamic web applications.
- There are different versions of CSS, with CSS3 being the latest and most advanced version.
- Learning CSS is an essential skill for anyone who wants to become a web designer or front-end developer.

In conclusion, CSS is a vital tool for web designers and developers. It allows for the creation of visually appealing and functional websites that can adapt to different devices and screen sizes. Understanding the background and basics of CSS is essential for anyone who wants to become proficient in web design.
