### Floating for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Unit 3 of the Web Designing course focuses on the Concept of CSS, including the aspect of Floating.

Floating is a CSS property used to control the position of HTML elements on a web page. By floating an element, you can cause it to float to the left or right of other elements on the page, allowing text or other elements to wrap around it.

In CSS, the float property is specified using the float property, and can be set to either left, right, or none. For example, the following CSS code will cause an element to float to the left of other elements on the page:

```
float: left;
```

Floating is useful for creating multi-column layouts, and for controlling the position of elements on a web page. However, it is important to use floating correctly, as incorrect usage can lead to unexpected results.

In the context of the Web Designing course, students in Unit 3 will learn about Floating as part of the discussion on the Concept of CSS. This may include working with examples of Floating, analyzing the benefits and limitations of Floating, and learning how to use Floating to control the position of elements on a web page.
