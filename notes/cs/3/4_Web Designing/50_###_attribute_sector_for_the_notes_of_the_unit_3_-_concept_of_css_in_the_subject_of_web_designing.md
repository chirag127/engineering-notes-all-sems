### Attribute sector for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

An attribute selector in CSS is a selector that selects elements based on the value of an attribute. Attribute selectors can be used to select elements based on the value of an attribute, or to select elements based on the presence of an attribute.

There are several types of attribute selectors, including:

1. [attribute]: Selects elements that have the specified attribute, regardless of its value.

2. [attribute=value]: Selects elements that have the specified attribute and value.

3. [attribute~=value]: Selects elements that have the specified attribute and a value that contains the specified word.

4. [attribute|=value]: Selects elements that have the specified attribute and a value that starts with the specified word, followed by a hyphen.

5. [attribute^=value]: Selects elements that have the specified attribute and a value that starts with the specified word.

6. [attribute$=value]: Selects elements that have the specified attribute and a value that ends with the specified word.
