### Text Format for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

Text format is an important aspect of web design, as it affects the readability and appearance of a web page. CSS (Cascading Style Sheets) provides a way to control the format of text on a web page, including:

1. Fonts: CSS provides a way to control the typeface, size, and style of text on a web page.

2. Colors: CSS provides a way to control the color of text on a web page.

3. Spacing: CSS provides a way to control the spacing between letters, words, and lines of text on a web page.

4. Alignment: CSS provides a way to control the alignment of text on a web page, including left, right, center, and justified alignment.

5. Decoration: CSS provides a way to control the decoration of text on a web page, including underlining, overlining, and striking through text.

In this unit, you will learn about the different properties and values used to control the format of text in CSS, and you will learn how to use CSS to control the typeface, size, color, spacing, alignment, and decoration of text on a web page.

This unit will provide a foundation for understanding the principles and practices of CSS, and for exploring the various concepts and techniques used in the field of web design.
