### Display for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

The Display section of the Unit 3 - Concept of CSS in the subject of Web Designing should cover the following topics:

1. Definition of display (the property used to specify how an HTML element should be displayed)
2. Overview of display (what it is, when it is used, advantages and disadvantages)
3. Display values (block, inline, inline-block, none, flex, grid, etc.)
4. Overview of block (an element that takes up the full width of its parent container and creates a new line after it)
5. Overview of inline (an element that only takes up as much space as its content and does not create a new line)
6. Overview of inline-block (an element that takes up only as much space as its content, but can be styled like a block element)
7. Overview of none (an element that is not displayed and takes up no space)
8. Overview of flex (a display value used for flexible and responsive layout)
9. Overview of grid (a display value used for grid-based layout)
10. The role of display in web design (controlling the layout and appearance of web pages)
11. Applications of display in web design (responsive design, grid-based layout, etc.)
12. Limitations of display (browser compatibility, performance, accessibility)
13. Techniques for overcoming limitations (cross-browser compatibility, optimization, accessibility standards)
14. Further reading and resources (books, tutorials, online resources)

Display is an important component of the subject of Web Designing. Understanding the principles and techniques of display helps students to develop the skills required to control the layout and appearance of web pages. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
