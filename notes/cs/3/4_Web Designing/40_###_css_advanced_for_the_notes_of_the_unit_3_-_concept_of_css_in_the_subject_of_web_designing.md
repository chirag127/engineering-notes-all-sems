### CSS Advanced for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS Advanced refers to the advanced concepts and techniques used in CSS to create complex and dynamic web designs. These include:

1. CSS Grid and Flexbox: CSS Grid and Flexbox provide a way to create complex and flexible grid-based layouts, allowing you to control the size, position, and flow of elements on a web page.

2. CSS Transforms: CSS Transforms provide a way to rotate, scale, and skew elements on a web page, allowing you to create dynamic and interactive effects.

3. CSS Animations: CSS Animations provide a way to create smooth transitions and animations between different styles, allowing you to add dynamic and interactive behavior to a web page.

4. CSS Media Queries: CSS Media Queries provide a way to create responsive designs, allowing you to control the appearance and layout of a web page based on the size of the screen and device.

In this unit, you will learn about the advanced concepts and techniques used in CSS, including CSS Grid and Flexbox, CSS Transforms, CSS Animations, and CSS Media Queries. You will learn how to use these advanced concepts and techniques to create complex and dynamic web designs.

This unit will provide a foundation for understanding the advanced concepts and techniques used in CSS, and for exploring the various concepts and techniques used in the field of web design.
