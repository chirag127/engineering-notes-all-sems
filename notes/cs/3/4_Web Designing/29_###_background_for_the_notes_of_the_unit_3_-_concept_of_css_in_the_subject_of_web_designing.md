### Background for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

The Background section of the Unit 3 - Concept of CSS in the subject of Web Designing should cover the following topics:

1. Definition of background (the visual area behind the content of an HTML element)
2. Overview of background (what it is, when it is used, advantages and disadvantages)
3. Background properties in CSS (background-color, background-image, background-repeat, background-attachment, background-position)
4. Overview of background-color (the color of the background of an HTML element)
5. Overview of background-image (an image used as the background of an HTML element)
6. Overview of background-repeat (how an image is repeated as the background of an HTML element)
7. Overview of background-attachment (whether an image scrolls with the content or stays in a fixed position)
8. Overview of background-position (the position of an image as the background of an HTML element)
9. Background shorthand property (a shorthand property for setting multiple background properties at once)
10. The role of background in web design (adding visual interest and depth to web pages)
11. Applications of background in web design (websites, landing pages, blogs, etc.)
12. Limitations of background (performance, compatibility, accessibility)
13. Techniques for overcoming limitations (optimizing images, using CSS instead of images, accessibility testing)
14. Further reading and resources (books, tutorials, online resources)

Background is an important component of the subject of Web Designing. Understanding the principles and techniques of background helps students to develop the skills required to add visual interest and depth to web pages. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
