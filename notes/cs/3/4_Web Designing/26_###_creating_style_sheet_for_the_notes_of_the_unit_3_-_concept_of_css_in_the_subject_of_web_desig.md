### Creating Style Sheet for the notes of the Unit 3 - Concept of CSS in the subject of Web Designing

CSS (Cascading Style Sheets) is a stylesheet language used to control the appearance of a web page. CSS allows you to control the font, color, background, and layout of a web page, and it provides a way to separate the content of a web page from its presentation.

Creating a style sheet involves defining a set of rules that determine the appearance of the elements on a web page. The rules are defined using selectors and declarations, and they are stored in a CSS file.

A selector is used to specify the element or elements that the rule applies to. For example, you can use a selector to specify that all <p> elements should have a font size of 16 pixels.

A declaration is used to specify the property and value of the rule. For example, you can use a declaration to specify that the font size of an element should be 16 pixels.

CSS can be added to a web page in several ways, including:

1. Inline: CSS can be added directly to an HTML element using the style attribute.

2. Internal: CSS can be added to the head of an HTML document using the <style> tag.

3. External: CSS can be added to an external file and linked to an HTML document using the <link> tag.

In this unit, you will learn about the basics of CSS, including selectors, declarations, and the different ways to add CSS to a web page. You will also learn about the various properties and values used in CSS, and you will explore the various concepts and techniques used in the field of web design.

This unit will provide a foundation for understanding the principles and practices of CSS and web design, and for exploring the various concepts and techniques used in the field of web design.
