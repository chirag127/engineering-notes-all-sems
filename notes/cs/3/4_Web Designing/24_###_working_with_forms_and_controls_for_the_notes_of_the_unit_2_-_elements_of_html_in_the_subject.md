### Working with Forms and controls for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

Forms and controls are important elements of HTML that allow users to interact with a web page. Forms are used to collect information from users, such as their name, address, and email. Controls are used to provide the user with a way to interact with the form, such as by entering text, selecting options, or uploading files.

In this unit, you will learn about the different types of forms and controls available in HTML, including text fields, password fields, radio buttons, checkboxes, select lists, and file upload controls, among others. You will learn how to create a form, how to add controls to a form, and how to use HTML attributes to control the appearance and behavior of the form and its controls.

You will also learn about the basics of JavaScript, which is used to add interactivity and dynamic behavior to a web page. JavaScript allows you to validate form data, provide feedback to the user, and create dynamic effects, among other things.

This unit will provide a foundation for understanding the basics of forms and controls in HTML, and for exploring the various concepts and techniques used in the field of web design. It will also provide a foundation for understanding the basics of JavaScript and its role in web design.
