### Static and Dynamic Websites for the notes of the Unit 1 - Introduction in the subject of Web Designing

Unit 1 of the Web Designing course focuses on Introduction, including the aspect of Static and Dynamic Websites.

Static websites are web pages that have a fixed content and layout, and do not change in response to user interactions. They are typically built using HTML, CSS, and JavaScript, and are suitable for small websites with simple content and limited functionality.

Dynamic websites, on the other hand, are web pages that can change in response to user interactions. They are typically built using server-side technologies, such as PHP, Ruby on Rails, or Node.js, and can provide a more interactive and personalized experience for users.

In the context of the Web Designing course, students in Unit 1 will learn about Static and Dynamic Websites as part of the discussion on Introduction. This may include working with examples of Static and Dynamic Websites, analyzing the benefits and limitations of each type of website, and learning how to choose the appropriate type of website for a specific project.

In summary, Unit 1 of the Web Designing course focuses on Introduction, and includes the aspect of Static and Dynamic Websites. Static websites are web pages with a fixed content and layout, while dynamic websites are web pages that can change in response to user interactions. Students will learn about Static and Dynamic Websites through interactive activities and hands-on experiences, and will learn how to choose the appropriate type of website for a specific project.
