### JS Events for the notes of the Unit 4 - Introduction to Client Side Scripting in the subject of Web Designing

JS Events are actions or occurrences that happen in the browser, such as a user clicking on a button, a page finishing loading, or an element being updated. JavaScript provides a way to respond to events, by executing a function or code when a specific event occurs.

The following are some of the most commonly used events in JavaScript:

1. click: Triggered when a user clicks on an element.

2. load: Triggered when a page finishes loading.

3. mouseover: Triggered when a user moves the mouse over an element.

4. submit: Triggered when a form is submitted.

5. keydown: Triggered when a user presses a key on the keyboard.

In this unit, you will learn about the different events in JavaScript, and you will learn how to respond to events by executing code or functions. You will also learn about the different ways to attach event handlers to elements, including using inline event handlers, using the addEventListener method, and using the onclick property.

This unit will provide a foundation for understanding the principles and practices of client-side scripting, and for exploring the various concepts and techniques used in the field of web design.
