### Tables and Frames for the notes of the Unit 2 - Elements of HTML in the subject of Web Designing

Unit 2 of the Web Designing course focuses on Elements of HTML, including the aspect of Tables and Frames.

Tables are HTML elements used to present data in a tabular format, with rows and columns. Tables can be used to present data in a variety of formats, including lists, calendars, and spreadsheets.

Frames are HTML elements used to divide a web page into multiple sections, each of which can be independently scrolled. Frames are used to create multi-paned interfaces, where each pane displays a different web page or content.

In the context of the Web Designing course, students in Unit 2 will learn about Tables and Frames as part of the discussion on Elements of HTML. This may include working with examples of Tables and Frames, analyzing the benefits and limitations of each element, and learning how to create and use Tables and Frames in a web page.

In summary, Unit 2 of the Web Designing course focuses on Elements of HTML, and includes the aspect of Tables and Frames. Tables are HTML elements used to present data in a tabular format, and Frames are HTML elements used to divide a web page into multiple sections.
