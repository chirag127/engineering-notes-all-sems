Unit 3 - Coding a sequence in the subject of Data Compression will cover the concept of Prediction with Partial match (ppm).

PPM (Prediction with Partial match) is a lossless data compression technique that uses statistical modeling to predict the next symbol in a sequence based on the context of the previous symbols. PPM uses a dynamic model that is updated as new data is processed, allowing it to adapt to the changing statistical properties of the data.
