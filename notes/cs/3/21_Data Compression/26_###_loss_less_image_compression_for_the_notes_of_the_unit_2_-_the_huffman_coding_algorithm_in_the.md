### Loss less image compression for the notes of the Unit 2 - The Huffman coding algorithm in the subject of Data Compression

Lossless image compression is a type of image compression that ensures that the original image can be recovered exactly from the compressed image. The following are some of the key concepts related to lossless image compression:

1. Image Compression: Image compression is the process of reducing the size of an image without losing any of the information contained in the image. Image compression is used in a wide range of applications, including digital imaging, web graphics, and more.

2. Lossless Image Compression: Lossless image compression is a type of image compression that ensures that the original image can be recovered exactly from the compressed image. Lossless image compression is used in applications where image integrity is critical, such as in medical imaging and scientific data.

3. Huffman Coding: Huffman coding is a lossless data compression algorithm that is widely used in image compression. Huffman coding is based on the principle of entropy coding, and uses a statistical model of the data to identify the most efficient coding for each symbol in the data.

4. Run Length Encoding: Run length encoding is a lossless image compression technique that is based on the observation that many images contain large areas of uniform color. Run length encoding represents these areas of uniform color as a series of runs, and is often used in combination with Huffman coding for improved compression.

5. Performance Evaluation: Performance evaluation is the process of measuring the effectiveness of image compression, and can be performed using metrics such as compression ratio, processing time, and more. Performance evaluation is important for comparing different image compression techniques and for selecting the best technique for a given application.
