1. Entropy Coding: Entropy coding is a type of coding used in data compression to reduce the size of the data. Entropy coding is based on the mathematical concept of entropy, which is a measure of the amount of information in a data set.

2. CALIC: CALIC is a type of entropy coding that is used to compress image data. CALIC is based on the idea of using context modeling to predict the probability of a symbol in the data, and then using entropy coding to code the data based on the predicted probability.

3. Context Modeling: Context modeling is a process of using statistical models to predict the probability of a symbol in the data. Context modeling is used in CALIC to predict the probability of a symbol in the data, and to improve the effectiveness of the entropy coding.

Performance Evaluation: Performance evaluation is the process of measuring the effectiveness of data compression, and can be performed using metrics such as compression ratio, processing time, and more.
