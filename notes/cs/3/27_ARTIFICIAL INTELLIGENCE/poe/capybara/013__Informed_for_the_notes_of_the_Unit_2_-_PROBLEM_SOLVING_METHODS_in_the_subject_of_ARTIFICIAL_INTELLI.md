In this unit, we will discuss the different problem-solving methods used in Artificial Intelligence. Informed search is one such method that is used to solve problems more efficiently. Let's understand what informed search is and how it works.

1. Informed search, also known as heuristic search, is a problem-solving method that uses domain-specific knowledge to guide the search process.

2. The main objective of informed search is to reduce the search space and find a solution more quickly than an uninformed search algorithm.

3. Informed search uses a heuristic function that estimates the cost of reaching the goal state from the current state.

4. One of the most commonly used informed search algorithms is A* search. A* search combines the cost of the path already taken with the estimated cost of reaching the goal state.

5. Another popular informed search algorithm is Greedy Best-First Search. It selects the node that appears to be closest to the goal state based on the heuristic function.

6. Informed search is particularly useful when the search space is large and the cost of exploring every node is high.

7. Informed search algorithms can be applied to a variety of problems such as pathfinding, puzzle solving, and game playing.

In conclusion, informed search is a powerful problem-solving method in Artificial Intelligence that can help us find solutions more efficiently. By using domain-specific knowledge, we can reduce the search space and find a solution more quickly. Understanding and implementing informed search algorithms is essential for any AI professional.
