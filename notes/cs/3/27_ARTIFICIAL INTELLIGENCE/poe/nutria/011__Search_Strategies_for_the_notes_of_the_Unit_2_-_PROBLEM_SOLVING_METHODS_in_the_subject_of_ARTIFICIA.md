
### Search Strategies for the Notes of the Unit 2 - PROBLEM SOLVING METHODS in the Subject of ARTIFICIAL INTELLIGENCE KCS

1. **Uninformed Search**: Uninformed search algorithms are those that do not use any additional information about the problem to guide the search. These algorithms are also known as blind search algorithms. Examples of uninformed search algorithms include Breadth-First Search and Depth-First Search.

2. **Informed Search**: In contrast to uninformed search algorithms, informed search algorithms make use of additional information about the problem to guide the search. Examples of informed search algorithms include Best-First Search and A* Search.

3. **Heuristic Search**: Heuristic search algorithms are informed search algorithms that use heuristics to guide the search. Heuristics are rules of thumb that are used to guide the search process. Examples of heuristic search algorithms include Greedy Search and Hill Climbing.

4. **Local Search**: Local search algorithms are heuristic search algorithms that are used to find local optima. These algorithms are often used to solve optimization problems. Examples of local search algorithms include Simulated Annealing and Tabu Search.
