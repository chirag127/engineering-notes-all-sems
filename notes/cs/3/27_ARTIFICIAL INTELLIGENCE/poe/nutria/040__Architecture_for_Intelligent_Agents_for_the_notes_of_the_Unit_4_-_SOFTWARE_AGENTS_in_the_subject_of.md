
### Architecture for Intelligent Agents

1. An intelligent agent (IA) is a system that perceives its environment and takes actions that maximize its chances of success.
2. Intelligent agents can be either reactive or deliberative. Reactive agents respond to their environment without any prior knowledge, while deliberative agents use knowledge and plans to decide how to act.
3. An agent architecture is a set of components that an agent uses to interact with its environment. Common components include sensors, actuators, and a knowledge base.
4. A variety of architectures exist for intelligent agents, including subsumption architectures, blackboard architectures, and hierarchical architectures.
5. In a subsumption architecture, the agent is composed of a series of layers, each of which is responsible for a different task.
6. In a blackboard architecture, the agent's components interact by sending messages to a central blackboard.
7. In a hierarchical architecture, the agent is composed of a series of levels, each of which is responsible for a different task.
8. Intelligent agents can be used in a variety of applications, including robotics, search engines, and computer games.
