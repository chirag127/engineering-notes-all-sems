
### Reasoning with Default Information

1. Default reasoning is a type of reasoning used in Artificial Intelligence (AI) to make decisions based on incomplete or uncertain information. 
2. It is based on the assumption that if certain information is not provided, then the default option is assumed. 
3. Default reasoning is used in Knowledge Representation to represent knowledge in a concise and efficient way. 
4. It is based on the assumption that certain facts are true unless explicitly stated otherwise. 
5. Default reasoning is used in AI applications such as natural language processing and robotics. 
6. It is also used to represent common sense knowledge, such as the fact that all cats have fur, or that all humans can walk. 
7. Default reasoning can be used to infer new information from existing knowledge, such as inferring that a particular cat has fur based on the fact that all cats have fur. 
8. Default reasoning has been used in AI applications such as intelligent tutoring systems and automated planning systems. 
9. Default reasoning can be used to make decisions in uncertain or incomplete situations, such as when making a medical diagnosis or deciding which course of action to take in a particular situation.
