### Architecture for Intelligent Agents

1. Agent Components - An agent has three basic components:
- Perceptual system: responsible for gathering information from the environment.
- Memory system: responsible for storing information about itself and the environment.
- Problem-solving system or reasoning system: responsible for processing the information received from the perceptual system and stored in memory, and for determining appropriate actions.

2. Agent Environment - An agent operates in an environment, which is the context in which it exists and acts. The environment provides:
- Inputs to the agent (perceptions)
- Outputs from the agent (actions)
- Performance measure used to evaluate the agent
- Constraints on what the agent can do

3. Agent Capabilities - An agent has certain capabilities that enable it to operate successfully in its environment:
- Reactivity: to respond in a timely fashion to changes in the environment.
- Proactiveness: to achieve goals by taking initiative rather than just reacting.
- Social ability: to interact with other agents or humans.
- Learning: to improve its capabilities based on experience.
