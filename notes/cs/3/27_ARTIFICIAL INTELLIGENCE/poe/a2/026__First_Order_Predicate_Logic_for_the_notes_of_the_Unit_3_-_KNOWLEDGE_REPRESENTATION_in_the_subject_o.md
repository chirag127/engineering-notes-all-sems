### First Order Predicate Logic

- First order predicate logic is a formal system used to express knowledge about the world.
- It allows us to represent objects, relationships between objects and variables.
- It consists of 4 components:
-- Constants: Objects in the domain of discourse (eg. John, Microsoft, etc.)
-- Variables: Placeholders for objects (eg. x, y, etc.)
-- Predicates: Express properties of objects/relationships between objects (eg. tall(x), father(x,y), etc.)
-- Quantifiers: Specify whether a predicate is true for all objects or some objects (eg. ∀, ∃)
- Sentences in FOPL are formed using the components above. They can be:
-- Atomic: Contain a single predicate applied to terms (eg. tall(John))
-- Molecular: Formed by combining atomic sentences using logical connectives (eg. (tall(John) ∧ ¬tall(Mary))
- FOPL is useful as it has a formal syntax and semantics, is computationally tractable and can represent many types of commonsense knowledge. However, it also has limitations in its inability to represent vagueness, inconsistency tolerance, etc.
