### Reasoning with Default Information for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS.

1. Default reasoning is used when there is absence of information. It involves inferring information based on defaults when the required data is missing.
2. It is a form of non-monotonic reasoning as conclusions can be withdrawn if more information becomes available.
3. Default logic is used to represent and reason with default information. It involves two types of statements - strict statements that are always true and default statements that are true unless there is evidence to the contrary.
4. Reiter's defaults are a popular way to specify default logic. It involves a default base stating defaults and an epistemic base with strict statements. The extensions are consistent sets of defaults and strict statements.
5. Autoepistemic logic is used to represent self-referential statements about an agent's knowledge and beliefs. It helps handle inconsistencies and make inferences in the absence of complete information.
6. Circumscription is another approach to deal with incomplete knowledge. It finds the most likely solution by minimizing the extension of predicates. It results in a canonical model that satisfies common-sense reasoning.
