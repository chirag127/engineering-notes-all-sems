### Searching with Partial Observations

- Searching with partial observations is a problem-solving method in artificial intelligence that deals with environments that are **partially observable**, meaning that the agent cannot access the complete state of the environment at any given time.
- Partial observability can arise due to **limited sensors**, **noise**, **uncertainty**, or **hidden variables** in the environment.
- A partial observation is a **subset** of the information that is available in a fully observable environment. For example, a vacuum agent may only see its current position and whether there is dirt in that square, but not the dirt status of other squares.
- To search with partial observations, an agent needs to maintain a **belief state**, which is a set of possible states that are consistent with the observations so far. A belief state can be represented as a **probability distribution** over the states, or as a **logical formula** that captures the constraints on the states.
- A search problem with partial observations can be formulated as a **belief-state search problem**, where the initial state is the initial belief state, the goal test is a function that checks if a belief state satisfies the goal condition, the actions are the same as in the fully observable problem, and the successor function returns the updated belief state after applying an action and receiving an observation.
- A search algorithm for partial observations needs to handle two main challenges: **branching** and **sensing**. Branching occurs when an action leads to multiple possible outcomes, depending on the hidden state of the environment. Sensing occurs when an observation reduces the uncertainty about the state, by eliminating some possibilities from the belief state.
- There are different types of search algorithms for partial observations, depending on how they handle branching and sensing. Some examples are:

  - **AND-OR search**: This is a tree-based search algorithm that uses two types of nodes: AND nodes and OR nodes. An AND node represents a belief state, and has one child for each possible action. An OR node represents an action, and has one child for each possible observation. The algorithm expands the tree until it finds a path from the root to a goal node, where each AND node is satisfied by at least one of its children, and each OR node is satisfied by all of its children.
  - **AO* algorithm**: This is a graph-based search algorithm that uses a heuristic function to guide the search. It starts with a single node representing the initial belief state, and expands it by adding one action and one observation at a time, until it reaches a goal node. It then updates the heuristic values of the nodes based on the cost of the path to the goal, and repeats the process until it finds an optimal solution.
  - **Expectimax search**: This is a tree-based search algorithm that assumes a stochastic environment, where the outcomes of the actions are probabilistic. It uses a utility function to evaluate the nodes, and alternates between two types of nodes: MAX nodes and CHANCE nodes. A MAX node represents a belief state, and has one child for each possible action. A CHANCE node represents an action, and has one child for each possible observation, weighted by the probability of that observation. The algorithm expands the tree until it reaches a predefined depth, and then returns the expected utility of the root node.
