# Events

- Events are the occurrence of things in the real world .
- Events are the actions which occur in our world.
- Events are an essential kind of knowledge in the world.
- Events trigger the spring up of event-centric knowledge representation form like Event KG (EKG).
- Events can be represented by using predicates, arguments, and temporal information.
- Events can be classified into different types, such as atomic, complex, generic, specific, etc.
- Events can be related to each other by using causal, temporal, or thematic relations.
- Events can be extracted from natural language texts by using natural language processing techniques.
- Events can be used to describe behavior which involves knowledge about how to do things.
- Events can be used to represent symbolic representations of objects and events which are not immediately present but exist only in imagination.
