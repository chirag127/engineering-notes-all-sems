### Characteristics of Intelligent Agents

An intelligent agent is a software entity that enables artificial intelligence to take action. Intelligent agent senses the environment and uses actuators to initiate action and conducts operations in the place of users. Or simply an Intelligent Agent (IA) is an entity that makes decisions.

Some examples of intelligent agents are:

- Driverless cars
- Siri virtual assistant
- Thermostat
- Chess-playing program

Intelligent agents have the following distinguishing characteristics :

- **Autonomy**: the ability of an agent to make decisions and control its actions without human intervention or guidance.
- **Reactivity**: the ability of an agent to perceive and react to environmental changes in order to achieve the goal or maintain the desired state.
- **Proactivity**: the ability of an agent to initiate actions based on its own goals, plans, and beliefs, rather than just responding to stimuli.
- **Learning**: the ability of an agent to improve its performance and adapt to new situations by acquiring new knowledge and skills from experience or feedback.
- **Sociality**: the ability of an agent to interact with other agents or humans in a cooperative or competitive manner, using communication, coordination, or negotiation.

Intelligent agents can be grouped into five classes based on their degree of perceived intelligence and capability:

- **Simple reflex agents**: these agents ignore the rest of the percept history and act only on the basis of the current percept. They have a fixed set of rules that map the current state to an action.
- **Model-based reflex agents**: these agents maintain an internal state that represents some aspects of the environment. They use this state to choose an action that is appropriate for the current situation.
- **Goal-based agents**: these agents have a set of goals that they want to achieve, and they choose actions that lead them to those goals. They use a search or planning algorithm to find the best sequence of actions to reach the desired state.
- **Utility-based agents**: these agents have a utility function that measures how desirable a state is. They choose actions that maximize their expected utility, taking into account the uncertainty and the trade-offs involved.
- **Learning agents**: these agents have the ability to learn from their own experience and improve their performance over time. They have a learning component that updates their knowledge or parameters, a performance component that selects actions, a critic component that evaluates the actions, and a problem generator component that explores new situations.
