### Backtracking Search

- Backtracking search is a general algorithm for finding solutions to some computational problems, notably constraint satisfaction problems (CSPs), that incrementally builds candidates to the solutions, and abandons a candidate (“backtracks”) as soon as it determines that the candidate cannot possibly be completed to a valid solution.
- A CSP is a problem where a set of variables must be assigned values from a given domain, subject to some constraints that restrict the possible combinations of values.
- Backtracking search searches a space of consistent partial assignments to variables, in the sense that all constraints among instantiated variables are satisfied, and looks for a complete consistent assignment to the variables, or in other words a solution.
- Backtracking search is a depth-first search (DFS) with single-variable assignments for a CSP. It starts with an empty assignment and tries to extend it by assigning a value to an unassigned variable. If the assignment is consistent, it recursively tries to extend it further. If the assignment is inconsistent, it backtracks and tries a different value for the previous variable. This process continues until a solution is found or all possibilities are exhausted.
- Backtracking search can be improved by using heuristics to determine which variable to assign next and which value to try first. For example, the minimum remaining values (MRV) heuristic chooses the variable with the fewest legal values, and the least constraining value (LCV) heuristic chooses the value that rules out the fewest values for the neighboring variables.
- Backtracking search can also be enhanced by using inference techniques to prune the search space. For example, forward checking keeps track of the remaining legal values for unassigned variables and terminates the search when any variable has no legal values. Arc consistency enforces the constraints between each pair of variables and removes values that are inconsistent with any other value.
- Backtracking search is used in various applications, including the N-queen problem, the knight tour problem, maze solving problems, and the search for all Hamilton paths in a graph.
