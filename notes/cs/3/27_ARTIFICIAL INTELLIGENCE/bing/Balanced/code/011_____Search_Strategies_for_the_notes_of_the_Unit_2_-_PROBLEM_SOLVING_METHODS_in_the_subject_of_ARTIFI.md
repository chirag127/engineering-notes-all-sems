### Search Strategies

- A search strategy is a method for finding a solution to a problem by exploring the space of possible states and actions.
- A search strategy consists of two components: a search algorithm and a search heuristic.
- A search algorithm is a systematic procedure that determines how to expand the nodes in the search tree and in what order.
- A search heuristic is a function that estimates the cost or distance from a node to the goal state, and guides the search algorithm towards the most promising nodes.
- There are different types of search strategies, such as:
  - Uninformed search: a search strategy that does not use any domain-specific knowledge or heuristic function, and relies only on the problem definition. Examples are breadth-first search, depth-first search, uniform-cost search, and iterative deepening search.
  - Informed search: a search strategy that uses a heuristic function to evaluate the nodes and select the best ones to expand. Examples are greedy search, A* search, hill-climbing search, and beam search.
  - Local search: a search strategy that operates on a single current state and moves to a neighboring state that is better than the current one, without keeping track of the path or the search tree. Examples are hill-climbing search, simulated annealing, genetic algorithms, and tabu search.
  - Adversarial search: a search strategy that considers the actions of other agents that may have conflicting goals, and tries to maximize its own utility while minimizing the utility of the opponents. Examples are minimax search, alpha-beta pruning, and expectimax search.
  - Constraint satisfaction search: a search strategy that solves problems that can be formulated as a set of variables, domains, and constraints, and tries to find an assignment of values to the variables that satisfies all the constraints. Examples are backtracking search, forward checking, arc consistency, and local search with min-conflicts heuristic.
