# Informed Search

- Informed search is a type of search strategy that uses additional information or heuristics to guide the search process towards the goal state.
- Heuristics are estimates of the cost, distance, or quality of a solution from a given state.
- Informed search algorithms are also called heuristic search algorithms, as they use heuristics to evaluate the nodes in the search space.
- Informed search algorithms can be more efficient and effective than uninformed search algorithms, as they can avoid exploring irrelevant or suboptimal paths.
- Some examples of informed search algorithms are:
  - Best-first search: a general search strategy that expands the node with the lowest heuristic value at each step.
  - Greedy search: a type of best-first search that uses the heuristic function h(n), which estimates the cost of reaching the goal from node n.
  - A* search: a type of best-first search that uses the heuristic function f(n) = g(n) + h(n), where g(n) is the cost of reaching node n from the start node, and h(n) is the estimated cost of reaching the goal from node n.
  - Hill-climbing search: a local search strategy that moves to the neighbor node with the highest heuristic value, until a local maximum is reached.
  - Simulated annealing: a local search strategy that moves to a random neighbor node with a probability that depends on the difference in heuristic values and a decreasing temperature parameter.
  - Genetic algorithms: a population-based search strategy that uses biological concepts such as reproduction, mutation, and selection to generate new solutions from a pool of candidates.
