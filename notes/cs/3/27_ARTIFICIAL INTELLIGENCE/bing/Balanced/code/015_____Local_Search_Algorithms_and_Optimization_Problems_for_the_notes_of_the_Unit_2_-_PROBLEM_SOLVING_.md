### Local Search Algorithms and Optimization Problems

- Local search algorithms are heuristic methods for solving computationally hard optimization problems.
- Optimization problems are problems that can be formulated as finding a solution that maximizes or minimizes a criterion among a number of candidate solutions.
- Local search algorithms examine and analyze many solutions (search space) by making local changes until an optimal solution is obtained or a number of iterations are performed.
- Local search algorithms do not keep a search tree, but only a single current state and move to a neighboring state according to some rule.
- Local search algorithms are widely used for very big problems and return good but not optimal solutions.
- Local search algorithms are usually very slow, but can yield good solutions if you wait.
- Local search algorithms are very sensitive to the initial solution and have a high probability of getting trapped in a local optima.
- Some examples of local search algorithms are hill climbing, simulated annealing, genetic algorithms, and tabu search .
- Local search algorithms are important in artificial intelligence because they enhance the solving of problems through logical search mechanisms such as problem definition, actions, and search space.
- Local search algorithms are used in artificial intelligence for applications such as scheduling, planning, routing, machine learning, and game playing .
