### Stochastic Games

Stochastic games are a type of dynamic game with probabilistic transitions played by one or more players. The game is played in a sequence of stages, and at the beginning of each stage, the game is in a certain state.

Stochastic games were first introduced by Shapley in 1953. They model dynamic interactions in which the environment changes in response to the behavior of the players.

Formally, a stochastic game is a tuple G = (N, S, (A_i, A_i, u_i)_ {i in N}, q) where N is a set of players.

Stochastic games have an element of chance: the state of the next round is determined probabilistically depending upon players' actions and the current state. Successful players need to balance the need for short-term payoffs while ensuring future opportunities remain high.
