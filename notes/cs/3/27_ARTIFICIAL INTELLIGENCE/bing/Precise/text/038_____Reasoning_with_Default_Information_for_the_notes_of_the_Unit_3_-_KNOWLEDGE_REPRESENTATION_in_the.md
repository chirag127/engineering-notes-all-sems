### Reasoning with Default Information

- Default reasoning is a type of non-monotonic reasoning that allows for the representation of incomplete information.
- It is based on the idea that, in the absence of evidence to the contrary, certain assumptions can be made.
- Default rules are used to represent these assumptions. They have the form: if P then usually Q.
- For example, a default rule for birds might be: if X is a bird, then usually X can fly.
- Default reasoning allows for exceptions to these rules. For example, penguins are birds but they cannot fly.
- Default reasoning is useful in artificial intelligence because it allows for the representation of common sense knowledge and the ability to draw conclusions based on incomplete information.
- There are several formalisms for default reasoning, including default logic, autoepistemic logic, and circumscription.
- Default reasoning can be used in a variety of applications, including natural language processing, expert systems, and diagnosis.
