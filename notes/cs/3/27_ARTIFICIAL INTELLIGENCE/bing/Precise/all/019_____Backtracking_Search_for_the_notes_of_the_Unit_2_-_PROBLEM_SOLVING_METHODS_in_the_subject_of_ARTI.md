# Backtracking Search

Backtracking search is a depth-first search algorithm that is used to solve problems with constraints. It is a form of brute force search, where all possible solutions are generated and tested to see if they satisfy the constraints of the problem. The algorithm works by incrementally building a solution, and if at any point the solution is found to be invalid, the algorithm backtracks to the previous step and tries a different path.

Here are some key points to remember about backtracking search:

1. Backtracking search is a depth-first search algorithm.
2. It is used to solve problems with constraints.
3. The algorithm works by incrementally building a solution.
4. If at any point the solution is found to be invalid, the algorithm backtracks to the previous step and tries a different path.
5. Backtracking search is a form of brute force search, where all possible solutions are generated and tested.
