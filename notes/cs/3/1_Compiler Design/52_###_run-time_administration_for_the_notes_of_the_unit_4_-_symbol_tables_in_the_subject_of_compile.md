### Run-Time Administration for the notes of the Unit 4 - Symbol Tables in the subject of Compiler Design

Run-time administration is a process in compiler design that involves managing the execution of a program at runtime. This includes managing the memory allocation, data structures, and other resources required by the program.

The process of run-time administration involves several steps, including:

1. Initialization: This step involves setting up the memory and data structures required by the program, such as the symbol table, the stack, and the heap.

2. Execution: This step involves executing the program, and managing the memory and data structures used by the program.

3. Cleanup: This step involves releasing any memory or other resources used by the program, and restoring the system to its original state.

Run-time administration is an important part of compiler design, because it allows the program to be executed efficiently and correctly. The process of run-time administration is closely tied to the process of code generation, because the generated code must be able to interact with the run-time environment in order to execute correctly.
