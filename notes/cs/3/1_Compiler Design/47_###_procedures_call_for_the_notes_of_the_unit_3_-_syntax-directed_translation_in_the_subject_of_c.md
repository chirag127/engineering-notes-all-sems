### procedures call for the notes of the Unit 3 - Syntax-directed Translation in the subject of Compiler Design

Procedure calls are a fundamental concept in compiler design, and they are used to invoke functions or subroutines in a program. A procedure call is a request to execute a specific procedure, and it is used to transfer control from the caller to the callee.

During the process of syntax-directed translation, procedure calls are typically represented as nodes in the parse tree or syntax tree. The parse tree or syntax tree is then used to generate the intermediate or target code, and the procedure calls are transformed into machine code that invokes the appropriate function or subroutine.

Procedure calls are an important aspect of compiler design, because they allow programs to be organized into smaller, reusable components. Procedure calls also allow programs to be more easily tested and debugged, because the behavior of individual procedures can be tested and debugged in isolation.
