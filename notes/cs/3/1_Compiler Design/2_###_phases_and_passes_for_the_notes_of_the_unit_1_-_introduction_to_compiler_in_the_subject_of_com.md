### Phases and passes for the notes of the Unit 1 - Introduction to Compiler in the subject of Compiler Design

A compiler is a software program that translates source code written in a high-level programming language into machine code that can be executed by a computer. The process of compiling source code into machine code is known as the compilation process, and it typically consists of several phases and passes.

The phases of a compiler are:

1. Lexical Analysis: This phase is responsible for breaking the source code into a sequence of tokens, which are the basic building blocks of the source code.

2. Syntax Analysis: This phase is responsible for checking the syntax of the source code, and for building a parse tree, which represents the structure of the source code.

3. Semantic Analysis: This phase is responsible for checking the semantics of the source code, and for ensuring that the source code is semantically correct.

4. Intermediate Code Generation: This phase is responsible for generating an intermediate representation of the source code, which can be used to generate machine code.

5. Code Optimization: This phase is responsible for optimizing the intermediate code, and for improving the performance of the generated machine code.

6. Code Generation: This phase is responsible for generating the machine code that can be executed by a computer.

The passes of a compiler are:

1. One-pass Compiler: A one-pass compiler processes the source code in a single pass, and generates the machine code in a single pass.

2. Two-pass Compiler: A two-pass compiler processes the source code in two passes, and generates the machine code in two passes.

In this unit, you will learn about the phases and passes of a compiler, including the purpose, process, and benefits of each phase and pass. You will also learn about the various components of a compiler, including the lexer, parser, and code generator. This will provide a foundation for understanding the principles and practices of compiler design, and for exploring the various concepts and techniques used in compiler design.
