# Derivation and Parse Trees

In the context of compiler design, a derivation is a sequence of grammar rule applications that transform the start symbol of a grammar into a string of terminal symbols. A parse tree is a graphical representation of a derivation, where the internal nodes represent non-terminal symbols and the leaves represent terminal symbols.

Here are some key points to remember about derivation and parse trees:

1. Derivations can be either leftmost or rightmost, depending on whether the leftmost or rightmost non-terminal symbol is expanded at each step.
2. A parse tree represents the hierarchical structure of a sentence according to a given grammar.
3. The root of the parse tree is the start symbol of the grammar, and the leaves of the tree are the terminal symbols derived from the start symbol.
4. The internal nodes of the parse tree represent non-terminal symbols, and the edges represent the application of production rules.
5. A parse tree is also known as a concrete syntax tree, as it represents the concrete syntax of a sentence according to a given grammar.
6. Parse trees are useful for understanding the structure of a sentence and for performing semantic analysis.
