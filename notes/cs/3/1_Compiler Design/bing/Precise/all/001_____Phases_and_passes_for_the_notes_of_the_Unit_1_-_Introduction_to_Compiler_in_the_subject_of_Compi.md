# Phases and Passes for the Notes of the Unit 1 - Introduction to Compiler in the Subject of Compiler Design

A compiler is a program that translates a source program written in a high-level programming language into a target program in machine code or assembly language. The process of compilation is divided into several phases, each of which performs a specific task. These phases are:

1. **Lexical Analysis:** This phase is responsible for scanning the source code and converting it into a sequence of tokens. Each token represents a meaningful unit of the source code, such as a keyword, an identifier, or a constant.

2. **Syntax Analysis:** This phase is responsible for checking the syntactic structure of the source code. It verifies that the sequence of tokens generated by the lexical analyzer conforms to the grammar of the programming language.

3. **Semantic Analysis:** This phase is responsible for checking the semantic correctness of the source code. It verifies that the source code is meaningful and that it follows the rules of the programming language.

4. **Intermediate Code Generation:** This phase is responsible for generating an intermediate representation of the source code. This intermediate representation is usually in the form of a tree or a graph.

5. **Code Optimization:** This phase is responsible for improving the intermediate representation of the source code. It applies various optimization techniques to reduce the execution time or the memory usage of the target program.

6. **Code Generation:** This phase is responsible for generating the target program in machine code or assembly language. It translates the intermediate representation of the source code into the target language.

A compiler may perform these phases in one or more passes. A pass is a complete traversal of the source code by the compiler. In a single-pass compiler, all phases are performed in a single pass. In a multi-pass compiler, some phases may be performed in multiple passes.
