### Addresses in the Target Code

1. **Absolute addresses**: These are fixed addresses in the target machine's memory. They are used for global data and code labels.
2. **PC-relative addresses**: These addresses are relative to the program counter (PC) register. They are used for branch instructions and for accessing data relative to the current instruction.
3. **Register-relative addresses**: These addresses are relative to the contents of a specific register. They are used for accessing data relative to a base address stored in a register.
4. **Frame-relative addresses**: These addresses are relative to the frame pointer (FP) register. They are used for accessing local variables and parameters of the current function.
5. **Stack-relative addresses**: These addresses are relative to the stack pointer (SP) register. They are used for accessing temporary data on the stack.
