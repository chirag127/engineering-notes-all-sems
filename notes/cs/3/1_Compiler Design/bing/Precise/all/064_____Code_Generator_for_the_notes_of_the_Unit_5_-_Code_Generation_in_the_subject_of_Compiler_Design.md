# Code Generator for the notes of the Unit 5 - Code Generation in the subject of Compiler Design

Code generation is the final phase of the compiler design process. The code generator takes as input an intermediate representation of the source program and maps it into the target machine language. The main tasks performed by the code generator are:

1. Instruction selection: The code generator selects the appropriate machine instructions to implement the intermediate code operations.

2. Register allocation: The code generator assigns registers to hold the values of the intermediate code operands.

3. Instruction scheduling: The code generator schedules the selected instructions to improve the performance of the generated code.

4. Code optimization: The code generator applies code optimization techniques to improve the quality of the generated code.

The code generator must generate correct and efficient code for the target machine. The quality of the generated code depends on the effectiveness of the instruction selection, register allocation, instruction scheduling, and code optimization algorithms used by the code generator.
