# Declarations and Case Statements

## Declarations
Declarations are used to specify the properties of variables, constants, and other objects in a program. They are used to define the type, storage class, and initial value of an object. Declarations can appear at the beginning of a block or at the file scope.

Here are some key points to remember about declarations:
- Declarations specify the type and other properties of an object.
- Declarations can appear at the beginning of a block or at the file scope.
- The type of an object determines the set of values it can have and the operations that can be performed on it.
- The storage class of an object determines its lifetime and visibility.
- The initial value of an object can be specified in its declaration.

## Case Statements
A case statement is a control structure that allows a program to choose between several alternative actions based on the value of an expression. The case statement is often used in conjunction with a switch statement, which evaluates an expression and transfers control to the appropriate case label.

Here are some key points to remember about case statements:
- A case statement is used to choose between several alternative actions.
- A case statement is often used in conjunction with a switch statement.
- The switch statement evaluates an expression and transfers control to the appropriate case label.
- Each case label specifies a constant value and is followed by a sequence of statements.
- The statements following a case label are executed if the value of the switch expression matches the value of the case label.
- A break statement can be used to exit a switch statement.
