### Lexical Phase Errors

Lexical phase errors occur during the lexical analysis phase of the compilation process. This phase is responsible for converting the source code into a sequence of tokens, which are then passed to the parser for further analysis. Lexical errors can occur when the lexical analyzer is unable to recognize a sequence of characters as a valid token. Some common examples of lexical errors include:

1. **Misspelled keywords:** If a keyword is misspelled, the lexical analyzer will not recognize it as a valid token. For example, if the keyword `int` is misspelled as `itn`, the lexical analyzer will not recognize it as a valid keyword.

2. **Invalid characters:** If the source code contains characters that are not valid in the programming language, the lexical analyzer will not be able to recognize them as valid tokens. For example, if the source code contains the character `@`, which is not a valid character in most programming languages, the lexical analyzer will not recognize it as a valid token.

3. **Unterminated strings or comments:** If a string or comment is not properly terminated, the lexical analyzer will not be able to recognize it as a valid token. For example, if a string is not properly terminated with a closing quotation mark, the lexical analyzer will not recognize it as a valid string.

These are some common examples of lexical phase errors that can occur during the lexical analysis phase of the compilation process. It is important to carefully check the source code for these types of errors to ensure that the compilation process can proceed smoothly.
