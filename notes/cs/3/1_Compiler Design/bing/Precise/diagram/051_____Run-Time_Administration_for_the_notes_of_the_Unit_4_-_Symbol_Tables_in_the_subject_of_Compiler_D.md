### Run-Time Administration

Run-time administration refers to the management of resources during the execution of a program. In the context of compiler design and the unit on symbol tables, this involves the management of memory allocation and deallocation for variables and data structures.

Some key points to consider when studying run-time administration in relation to symbol tables include:

1. The symbol table is used to store information about the variables and data structures used in a program, including their names, types, and memory locations.
2. During the execution of a program, the compiler or interpreter uses the symbol table to allocate memory for variables and data structures, and to keep track of their current values.
3. Memory allocation can be done statically, at compile-time, or dynamically, at run-time. Static allocation is used for variables with a fixed size, while dynamic allocation is used for variables whose size is not known until run-time.
4. Memory management techniques, such as garbage collection, can be used to automatically deallocate memory that is no longer needed by the program.
5. Efficient run-time administration is important for the performance of a program, as it can help to minimize the amount of memory used and reduce the time spent on memory allocation and deallocation.
