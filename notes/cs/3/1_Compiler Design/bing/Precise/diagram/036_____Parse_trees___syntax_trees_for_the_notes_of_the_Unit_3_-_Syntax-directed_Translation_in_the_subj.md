### Parse Trees & Syntax Trees

Parse trees and syntax trees are data structures used in the field of compiler design, specifically in the unit of Syntax-directed Translation.

1. **Parse Trees:** A parse tree is a tree representation of the syntactic structure of a sentence according to a given grammar. It shows the hierarchical relationship between the different components of the sentence, with the root representing the start symbol of the grammar and the leaves representing the terminal symbols.

2. **Syntax Trees:** A syntax tree, also known as an abstract syntax tree (AST), is a simplified version of a parse tree. It is obtained by removing unnecessary details from the parse tree, such as the nodes representing the non-terminal symbols that do not contribute to the meaning of the sentence. Syntax trees are used to represent the structure of the program in a way that is easier to manipulate and analyze.

In summary, parse trees and syntax trees are important data structures used in the process of syntax-directed translation in compiler design. While parse trees provide a detailed representation of the syntactic structure of a sentence, syntax trees provide a more abstract and simplified representation that is easier to manipulate and analyze.
