### capabilities of CFG for the notes of the Unit 1 - Introduction to Compiler in the subject of Compiler Design

Context-Free Grammars (CFGs) are a fundamental concept in the subject of Compiler Design, and are used to define the syntax of programming languages. In the context of Unit 1 - Introduction to Compiler, the following capabilities of CFGs will be covered:

1. Syntax Definition: CFGs are used to define the syntax of programming languages, including the rules for constructing valid sentences in the language.

2. Parsing: CFGs are used to parse input strings and determine if they are valid sentences in the language defined by the CFG. The process of parsing involves constructing a parse tree that represents the structure of the input string.

3. Ambiguity: CFGs can be used to detect ambiguity in the syntax of a language, which can cause problems during parsing. Ambiguity can be resolved by modifying the CFG to eliminate the ambiguity.

4. Top-Down Parsing: CFGs can be used to implement top-down parsing algorithms, such as recursive descent parsing, which generate a parse tree from the top down.

5. Bottom-Up Parsing: CFGs can also be used to implement bottom-up parsing algorithms, such as shift-reduce parsing, which generate a parse tree from the bottom up.

6. Automata Generation: CFGs can be used to generate finite automata, which can be used to recognize valid sentences in a language.

By the end of Unit 1 - Introduction to Compiler, students will have a comprehensive understanding of the capabilities of CFGs and how they are used in compiler design to define the syntax of programming languages and implement parsing algorithms.
