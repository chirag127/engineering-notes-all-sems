### representing scope information for the notes of the Unit 4 - Symbol Tables in the subject of Compiler Design

In compiler design, symbol tables are used to store information about the symbols used in a program, such as variables, functions, and types. Symbol tables are used to store information such as the name, type, and scope of each symbol.

Scope information is used to determine the visibility and accessibility of symbols in a program. A symbol's scope determines where in the program the symbol can be used, and it is used to resolve naming conflicts and to enforce access control.

There are several ways to represent scope information in a symbol table, including:

1. Stack-based representation: A stack-based representation uses a stack to store the symbols and their scope information, and it is used to track the current scope of the program.

2. Tree-based representation: A tree-based representation uses a tree to store the symbols and their scope information, and it is used to represent the hierarchical structure of the scopes in a program.

3. Hash table representation: A hash table representation uses a hash table to store the symbols and their scope information, and it is used to provide fast access to the symbols based on their names.
