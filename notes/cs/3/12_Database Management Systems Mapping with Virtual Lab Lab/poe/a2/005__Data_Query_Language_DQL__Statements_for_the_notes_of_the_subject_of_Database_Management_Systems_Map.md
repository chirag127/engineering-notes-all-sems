## Data Query Language(DQL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

1. SELECT - retrieves data from the database table which matches the criteria specified.
2. PROJECT - returns selected columns from tables.
3. RENAME - renames a column or a table.
4. SET OPERATORS - combine two or more SELECT statements. Includes UNION, INTERSECT, EXCEPT.
5. JOIN - combines rows from two or more tables. Includes INNER JOIN, OUTER JOIN (LEFT, RIGHT, FULL), CROSS JOIN.
6. GROUP BY - groups rows that have the same values. Used with aggregate functions.
7. HAVING - specifies a search condition for a group or an aggregate.
8. ORDER BY - sorts the result-table in ascending or descending order.
9. DISTINCT - eliminates duplicates from the result-table.
10. AGGREGATE FUNCTIONS - perform a calculation on a set of values and return a single value. Includes COUNT, SUM, AVG, MIN, MAX.
