## Data Query Language(DQL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

Unit - Data Query Language (DQL) Statements:
- Overview: 
  1. DQL: A language used to retrieve data from a database.
  2. Key DQL statements: SELECT, FROM, WHERE, GROUP BY, HAVING, ORDER BY.
- SELECT Statement:
  1. SELECT clause: Specifies the columns to be retrieved from the database.
  2. FROM clause: Specifies the table(s) from which the data is to be retrieved.
  3. WHERE clause: Specifies the conditions for retrieving the data.
- GROUP BY and HAVING Clauses:
  1. GROUP BY clause: Groups the data based on one or more columns.
  2. HAVING clause: Specifies conditions for the groups created by the GROUP BY clause.
- ORDER BY Clause:
  1. ORDER BY clause: Specifies the order in which the data is to be retrieved.

Note: The Data Query Language (DQL) is an essential component of database management. This unit covers the key DQL statements, including the SELECT statement, the FROM clause, the WHERE clause, the GROUP BY and HAVING clauses, and the ORDER BY clause. The SELECT statement is used to retrieve data from a database, and the WHERE clause is used to specify the conditions for retrieving the data. The GROUP BY and HAVING clauses are used to group the data, and the ORDER BY clause is used to specify the order in which the data is to be retrieved.
