## Data Definition Language(DDL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

Data Definition Language (DDL) Statements:
- Overview: DDL statements are used to define the structure of a database, including tables, columns, and relationships between tables.
- Key DDL statements:
  1. CREATE TABLE: Used to create a new table in the database.
  2. ALTER TABLE: Used to modify the structure of an existing table.
  3. DROP TABLE: Used to delete a table from the database.
  4. CREATE INDEX: Used to create an index on one or more columns of a table to improve query performance.
  5. DROP INDEX: Used to delete an index from a table.
- Usage:
  1. Creating a database: Use DDL statements to create tables, columns, and relationships between tables in a new database.
  2. Modifying a database: Use DDL statements to modify the structure of an existing database, including adding, modifying, or deleting tables and columns.
  3. Optimizing performance: Use DDL statements to create indexes on columns to improve query performance.

Note: DDL statements play a critical role in defining and managing the structure of a database. This unit covers the key DDL statements, including CREATE TABLE, ALTER TABLE, DROP TABLE, CREATE INDEX, and DROP INDEX, and the usage of these statements in creating and modifying a database, and optimizing performance.
