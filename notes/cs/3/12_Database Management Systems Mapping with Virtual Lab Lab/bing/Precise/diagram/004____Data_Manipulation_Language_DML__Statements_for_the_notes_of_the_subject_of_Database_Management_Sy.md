## Data Manipulation Language (DML) Statements

Data Manipulation Language (DML) is a subset of SQL used to manipulate data in a database. It includes statements such as `SELECT`, `INSERT`, `UPDATE`, and `DELETE`. These statements are used to retrieve, add, modify, and delete data in a database.

1. `SELECT` statement: The `SELECT` statement is used to retrieve data from one or more tables in a database. It can be used to retrieve specific columns or rows of data, or to retrieve data that meets certain criteria.

2. `INSERT` statement: The `INSERT` statement is used to add new rows of data to a table in a database. It can be used to insert a single row of data or multiple rows of data at once.

3. `UPDATE` statement: The `UPDATE` statement is used to modify existing data in a table in a database. It can be used to update one or more columns of data in one or more rows of a table.

4. `DELETE` statement: The `DELETE` statement is used to delete existing data from a table in a database. It can be used to delete one or more rows of data from a table.

These DML statements are essential for manipulating data in a database and are commonly used in Database Management Systems Mapping with Virtual Lab Lab. It is important to understand and be able to use these statements when working with databases.
