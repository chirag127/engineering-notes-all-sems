## Data Manipulation Language(DML) Statements

- Data manipulation language (DML) statements are SQL statements that access and manipulate data in existing schema objects, such as tables, views, and indexes  .
- DML statements include `INSERT`, `UPDATE`, `DELETE`, `MERGE`, `CALL`, and `SELECT`  .
- DML statements can be used to perform various operations on the data, such as adding new rows, modifying existing rows, deleting rows, merging data from multiple sources, invoking stored procedures, and querying data    .
- DML statements are part of a transaction, which is a sequence of one or more SQL statements that are treated as a unit by the database . A transaction can be committed (made permanent) or rolled back (undone) as a whole .
- DML statements can be executed in different ways, such as using SQL*Plus, SQL Developer, or other tools that can connect to the database and send SQL commands .
- DML statements can be affected by various factors, such as constraints, triggers, indexes, and privileges, that may enforce rules, perform actions, speed up queries, or restrict access on the data  .
- DML statements can be optimized by using hints, indexes, partitions, and other techniques, that may improve the performance, scalability, and efficiency of the data manipulation operations  .
