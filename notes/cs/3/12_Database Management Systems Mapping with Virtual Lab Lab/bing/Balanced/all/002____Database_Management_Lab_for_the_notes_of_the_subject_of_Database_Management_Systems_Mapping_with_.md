## Database Management Lab for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- Database Management Lab is a practical course that teaches the students how to use and implement database management systems (DBMS) for various applications.
- DBMS are software packages that store, manage, and manipulate data in a structured and efficient way.
- DBMS can be classified into different types based on the data model, such as relational, hierarchical, network, object-oriented, etc.
- Relational DBMS are the most widely used and follow the relational model, which represents data as tables with rows and columns.
- SQL (Structured Query Language) is the standard language for relational DBMS, which allows users to create, query, update, and delete data in a database.
- Database Management Lab covers the following topics:

  - Data definition language (DDL) and data manipulation language (DML) commands of base tables and views 
  - High level programming language extensions, such as PL/SQL, triggers, stored procedures, functions, etc. 
  - Front end tools, such as Oracle Forms, Oracle Reports, etc. that provide graphical user interfaces for database applications 
  - Design and implementation of database schemas, normalization, integrity constraints, etc. 
  - Database security, backup, recovery, concurrency control, transaction management, etc. 
  - Database concepts, such as entity-relationship model, relational algebra, relational calculus, etc. 
  - Database management for relational databases using Microsoft Azure Lab Services

- Database Management Lab provides practical examples and case studies for better understanding of concepts and also incorporates the experiments to be performed in the DBMS lab.
- Database Management Lab is a useful course for students who want to learn the fundamentals and applications of database systems and develop their skills in database design and development.
