## Data Definition Language(DDL) Statements for the notes of the subject of Database Management Systems Mapping with Virtual Lab Lab

- Data Definition Language (DDL) is a subset of SQL and a part of DBMS (Database Management System) .
- DDL statements are used to define and modify the database structure or schema, which is the organization of data   .
- DDL statements include commands like CREATE, ALTER, TRUNCATE and DROP, which are used to create or modify the tables, files, indexes, columns and other database objects  .
- DDL statements are different from Data Manipulation Language (DML) and Data Query Language (DQL), which are used to manipulate and query data within the database  .
- DDL statements are executed by the database system, which checks the syntax and semantics of the statements and updates the metadata accordingly .
- DDL statements can be used to specify the database schema, integrity constraints, security constraints and other properties of the database  .
- DDL statements can be used in conjunction with U-SQL, which is a language for processing structured and unstructured data .
- DDL statements can be tested and practiced using virtual lab tools, such as SQL Fiddle, SQLZoo and W3schools SQL Tryit Editor   .
