### associations encapsulation for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Associations and encapsulation are two important concepts in Object Oriented System Design, and they are used to represent the relationships and behavior of objects in a software system.

1. Associations: Associations are the relationships between objects in a software system, and they represent the way objects interact with each other. Associations can be one-to-one, one-to-many, many-to-one, or many-to-many.

2. Encapsulation: Encapsulation is the process of hiding the internal details of an object, and it is used to protect the object's internal state and behavior from external access. Encapsulation is achieved through the use of access modifiers and data hiding.

In this unit, you will learn about associations and encapsulation, and you will learn how to use these concepts to represent the relationships and behavior of objects in a software system. You will also learn about the different types of associations, and you will learn how to choose the appropriate type of association for a specific task.

This unit will provide a foundation for understanding the principles and practices of associations and encapsulation in Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
