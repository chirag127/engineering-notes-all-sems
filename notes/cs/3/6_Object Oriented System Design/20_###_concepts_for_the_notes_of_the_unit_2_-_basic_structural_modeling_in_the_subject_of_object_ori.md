### concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Unit 2 of Object Oriented System Design focuses on basic structural modeling, which is the process of creating a model of the structure of a software system. The following are some of the key concepts related to basic structural modeling:

1. Classes: Classes are the basic building blocks of object-oriented systems, and they represent objects and their attributes and behaviors.

2. Attributes: Attributes are the variables that define the state of an object, and they represent the data stored in an object.

3. Methods: Methods are the functions that define the behavior of an object, and they represent the operations that can be performed on an object.

4. Relationships: Relationships are the connections between classes and objects, and they represent the way objects interact with each other.

5. Association: Association is a relationship between two classes, where one class is associated with another class.

6. Aggregation: Aggregation is a relationship between two classes, where one class is composed of multiple instances of another class.

7. Inheritance: Inheritance is a relationship between two classes, where one class is derived from another class, inheriting its attributes and behavior.

In this unit, you will learn about the basic concepts of classes, attributes, methods, relationships, association, aggregation, and inheritance. You will also learn how to use these concepts to create a model of the structure of a software system.

This unit will provide a foundation for understanding the principles and practices of basic structural modeling in Object Oriented System Design, and for exploring the various concepts and techniques used in the field of Object Oriented System Design.
