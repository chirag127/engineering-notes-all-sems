### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

The Terms section of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design should cover the following topics:

1. Class (a blueprint that defines the properties and behavior of objects)
2. Object (an instance of a class)
3. Inheritance (the process of creating a new class from an existing class)
4. Overview of Inheritance (what it is, when it is used, advantages and disadvantages)
5. Inheritance in Object-Oriented Programming (how inheritance is implemented in object-oriented programming languages)
6. Polymorphism (the ability of an object to take on many forms)
7. Overview of Polymorphism (what it is, when it is used, advantages and disadvantages)
8. Polymorphism in Object-Oriented Programming (how polymorphism is implemented in object-oriented programming languages)
9. Abstraction (the process of hiding the implementation details of an object and exposing only its essential characteristics)
10. Overview of Abstraction (what it is, when it is used, advantages and disadvantages)
11. Abstraction in Object-Oriented Programming (how abstraction is implemented in object-oriented programming languages)
12. Association (the relationship between two classes)
13. Overview of Association (what it is, when it is used, advantages and disadvantages)
14. Association in Object-Oriented Programming (how association is implemented in object-oriented programming languages)
15. Aggregation (a special type of association where one class is a part of another class)
16. Overview of Aggregation (what it is, when it is used, advantages and disadvantages)
17. Aggregation in Object-Oriented Programming (how aggregation is implemented in object-oriented programming languages)
18. Composition (a special type of aggregation where one class is a part of another class and cannot exist without it)
19. Overview of Composition (what it is, when it is used, advantages and disadvantages)
20. Composition in Object-Oriented Programming (how composition is implemented in object-oriented programming languages)
21. Further reading and resources (books, articles, online resources)

Terms is an important component of the subject of Object Oriented System Design. Understanding the fundamental terms and concepts of object-oriented programming helps students to develop the skills required to design and implement object-oriented systems. The hands-on practice and further reading resources will help students to develop their skills and deepen their understanding of the material.
