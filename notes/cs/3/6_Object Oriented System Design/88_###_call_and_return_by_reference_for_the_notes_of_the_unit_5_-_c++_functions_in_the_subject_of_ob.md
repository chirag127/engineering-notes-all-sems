### Call and Return by reference for the notes of the Unit 5 - C++ Functions in the subject of Object Oriented System Design

Call by reference and return by reference are two important concepts in C++ programming, and they are used to pass and return values between functions.

1. Call by reference: Call by reference is a mechanism used to pass values between functions by reference, rather than by value. When a value is passed by reference, the address of the value is passed, rather than a copy of the value. This allows functions to modify the values of variables in the calling function.

2. Return by reference: Return by reference is a mechanism used to return values from a function by reference, rather than by value. When a value is returned by reference, the address of the value is returned, rather than a copy of the value. This allows functions to return values that can be modified in the calling function.

You will also learn about the benefits and limitations of call by reference and return by reference, and you will learn how to choose the appropriate mechanism for a specific task.
