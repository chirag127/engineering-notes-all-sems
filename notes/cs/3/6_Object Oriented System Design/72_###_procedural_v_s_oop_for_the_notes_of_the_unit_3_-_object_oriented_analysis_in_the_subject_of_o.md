### Procedural v/s OOP for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Procedural programming and Object-Oriented Programming (OOP) are two different programming paradigms used to design and develop software systems. 

The following are some of the key differences between procedural programming and OOP:

1. Structure: Procedural programming is structured around procedures or functions, while OOP is structured around objects and classes.

2. Abstraction: Procedural programming relies on abstraction through functions, while OOP relies on abstraction through objects and classes.

3. Encapsulation: OOP provides encapsulation, which allows data and behavior to be combined into a single unit, while procedural programming does not provide this level of encapsulation.

4. Reusability: OOP provides reusability through inheritance and polymorphism, while procedural programming relies on functions and procedures.

5. Modularity: OOP provides modularity through objects and classes, while procedural programming relies on functions and procedures.

In this unit, you will learn about the basic concepts of procedural programming and OOP, and you will learn how to choose the appropriate programming paradigm for a specific task. You will also learn about the benefits and limitations of each programming paradigm, and you will learn how to use OOP to design and develop software systems.

This unit will provide a foundation for understanding the principles and practices of procedural programming and OOP in Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
