### multilevel for the notes of the Unit 7 - Inheritance in the subject of Object Oriented System Design

Multilevel inheritance is a feature of object-oriented programming in which a class can inherit properties and behaviors from multiple classes, forming a hierarchy of classes. This allows for a more efficient and flexible way to reuse code and to model complex relationships between classes.

The following are some of the key concepts related to multilevel inheritance in C++:

1. Inheritance Hierarchy: The inheritance hierarchy is a tree-like structure that represents the relationships between classes, and it allows for a class to inherit properties and behaviors from multiple classes.

2. Base Class: The base class is the class from which another class inherits properties and behaviors, and it is also known as the parent class or superclass.

3. Derived Class: The derived class is the class that inherits properties and behaviors from a base class, and it is also known as the child class or subclass.

4. Overriding: Overriding is a mechanism used in C++ to change the behavior of a method in a derived class, and it allows for the behavior of a method to be changed based on the specific needs of the derived class.

5. Polymorphism: Polymorphism is a feature of object-oriented programming that allows for objects of different classes to be treated as objects of a common class, and it allows for a more flexible and efficient way to model complex relationships between classes.

You will also learn about base classes, derived classes, overriding, and polymorphism, and you will learn how to use these concepts to create a more efficient and flexible way to reuse code and to model complex relationships between classes.

This unit will provide a foundation for understanding the principles and practices of inheritance in C++, and for exploring the various concepts and techniques used in the field of software engineering.
