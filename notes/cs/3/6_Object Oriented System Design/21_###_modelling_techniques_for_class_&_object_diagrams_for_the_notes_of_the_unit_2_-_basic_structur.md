### modelling techniques for Class & Object Diagrams for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Modelling techniques for Class & Object Diagrams are used to represent the structure and behavior of software systems in Object Oriented System Design. Class diagrams show the relationships between classes and objects, and they are used to describe the structure of the system. Object diagrams show the relationships between objects, and they are used to describe the behavior of the system.

The following are some of the key modelling techniques for Class & Object Diagrams:

1. Classes: Classes are the basic building blocks of object-oriented systems, and they represent objects and their attributes and behaviors.

2. Attributes: Attributes are the data elements of a class, and they represent the properties of the objects in the system.

3. Methods: Methods are the functions of a class, and they represent the behaviors of the objects in the system.

4. Relationships: Relationships are the connections between classes and objects, and they represent the way objects interact with each other.

5. Association: Association is a relationship between two classes, and it represents the way objects of one class are related to objects of another class.

6. Aggregation: Aggregation is a relationship between two classes, and it represents the way objects of one class are composed of objects of another class.

7. Inheritance: Inheritance is a relationship between two classes, and it represents the way a subclass inherits the attributes and behaviors of its superclass.
