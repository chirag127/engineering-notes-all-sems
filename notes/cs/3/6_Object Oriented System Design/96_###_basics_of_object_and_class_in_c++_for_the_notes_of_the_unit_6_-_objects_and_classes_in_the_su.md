### Basics of object and class in C++ for the notes of the Unit 6 - Objects and Classes in the subject of Object Oriented System Design

Objects and classes are the fundamental building blocks of object-oriented programming in C++. Objects are instances of classes, and classes define the structure and behavior of objects in a software system.

The following are some of the key concepts related to objects and classes in C++:

1. Class Definition: Classes are defined in C++ using the "class" keyword, followed by the name of the class and a block of code that defines the structure and behavior of the class.

2. Object Creation: Objects are created in C++ using the class constructor, which is a special function that is called when an object is created.

3. Data Members: Data members are variables that are defined within a class, and they represent the state of an object.

4. Member Functions: Member functions are functions that are defined within a class, and they represent the behavior of an object.

5. Access Specifiers: Access specifiers are used to control the visibility of data members and member functions, and they include "private", "protected", and "public".

6. Encapsulation: Encapsulation is a mechanism used in C++ to protect the internal state of objects and to ensure that objects can only be modified in appropriate ways, and it allows objects to be treated as black boxes that can only be interacted with through their public interfaces.

In this unit, you will learn about the basic concepts of objects and classes in C++, and you will learn how to define, create, and use objects and classes in C++. You will also learn about data members, member functions, access specifiers, and encapsulation, and you will learn how to use these concepts to create objects and classes that represent the entities in a software system.

This unit will provide a foundation for understanding the principles and practices of objects and classes in C++, and for exploring the various concepts and techniques used in the field of software engineering.
