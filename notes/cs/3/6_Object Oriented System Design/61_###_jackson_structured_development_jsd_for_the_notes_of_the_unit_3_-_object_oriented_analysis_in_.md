### Jackson Structured Development (JSD) for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Jackson Structured Development (JSD) is a software development methodology that was developed in the 1970s by Michael A. Jackson. JSD is an object-oriented approach to software development that emphasizes the use of structured design techniques to create software systems.

The following are some of the key concepts related to JSD:

1. Structured Design: JSD is based on the principles of structured design, and it emphasizes the use of structured design techniques to create software systems.

2. Object-Oriented Analysis: JSD uses object-oriented analysis to identify and describe the objects in a system, and to describe the relationships between these objects.

3. Object-Oriented Design: JSD uses object-oriented design to create the structure and behavior of a system, and to describe the interactions between objects in a system.

4. Modeling: JSD uses modeling techniques to represent the structure, behavior, and requirements of a software system.

In this unit, you will learn about the principles and practices of JSD, and you will learn how to use JSD to create software systems. You will also learn about the different phases of JSD, and you will learn how to use JSD to create a complete and accurate representation of a software system.

This unit will provide a foundation for understanding the principles and practices of JSD in Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
