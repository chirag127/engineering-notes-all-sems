### Unit 7 - Inheritance in Object Oriented System Design

- Inheritance is a mechanism in object-oriented programming that allows a new class to be created based on an existing class.
- The new class, called the subclass, inherits the attributes and methods of the existing class, called the superclass.
- Inheritance allows for code reuse and can make it easier to maintain and update code.
- Inheritance can also be used to create a hierarchy of classes, where more specific classes inherit from more general classes.
- Inheritance is implemented using the `extends` keyword in Java and the `:` symbol in C++.
- When a subclass inherits from a superclass, it can override the methods of the superclass to provide its own implementation.
- Inheritance can also be used to achieve polymorphism, where objects of different classes can be treated as objects of a common superclass.
- Multiple inheritance, where a class can inherit from more than one superclass, is supported in some languages such as C++, but not in others such as Java.
- In languages that do not support multiple inheritance, similar functionality can be achieved using interfaces or composition.
