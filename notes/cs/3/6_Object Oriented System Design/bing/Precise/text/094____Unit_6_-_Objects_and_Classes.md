## Unit 6 - Objects and Classes

1. **Objects** are instances of a class that encapsulate data and behavior.
2. **Classes** are blueprints for creating objects and define the properties and methods that objects can have.
3. **Properties** are variables that belong to an object and hold its state.
4. **Methods** are functions that belong to an object and can manipulate its state.
5. **Constructors** are special methods that are called when an object is created and are used to initialize its properties.
6. **Inheritance** allows a class to inherit properties and methods from another class, enabling code reuse and reducing complexity.
7. **Polymorphism** allows objects of different classes to be treated as objects of a common superclass, enabling flexibility and extensibility.
8. **Encapsulation** is the practice of hiding the internal details of an object and providing a public interface for interacting with it, promoting modularity and maintainability.
9. **Abstraction** is the process of identifying the essential features of an object and ignoring its non-essential details, simplifying the design and implementation of software systems.
