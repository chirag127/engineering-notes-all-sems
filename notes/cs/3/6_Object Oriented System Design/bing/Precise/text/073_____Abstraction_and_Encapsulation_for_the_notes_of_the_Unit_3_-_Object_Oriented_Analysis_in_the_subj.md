### Abstraction and Encapsulation for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

- **Abstraction** is the process of identifying the essential features of an object while ignoring its inessential details. It is a way to reduce complexity and allow efficient design and implementation of complex software systems.

- **Encapsulation** is the process of combining data and functions that operate on that data into a single unit, called an object. It is a way to hide the internal details of an object from the outside world, and to control access to the object's data and behavior.

- Abstraction and encapsulation are closely related concepts in object-oriented programming. Abstraction allows us to focus on the essential features of an object, while encapsulation allows us to hide its internal details and control access to its data and behavior.

- Abstraction is achieved through the use of classes and interfaces, which define the essential features of an object and provide a way to interact with it. Encapsulation is achieved through the use of access modifiers, such as public, private, and protected, which control access to the object's data and behavior.

- Abstraction and encapsulation are important principles in the design of robust and maintainable software systems. They allow us to manage complexity, reduce coupling between components, and promote code reuse.
