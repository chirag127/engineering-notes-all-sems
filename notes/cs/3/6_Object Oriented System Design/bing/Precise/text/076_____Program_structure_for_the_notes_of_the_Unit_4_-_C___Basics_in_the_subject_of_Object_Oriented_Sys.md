### Program Structure

A C++ program is a collection of commands, which tell the computer to perform a specific task. The basic structure of a C++ program can be understood as follows:

1. **Documentation Section:** This section consists of a set of comment lines giving the name of the program, the author, and other details, which the programmer would like to refer to at a later stage.

2. **Link Section:** This section provides instructions to the compiler to link functions from the system library.

3. **Definition Section:** All the definitions of symbolic constants are provided in this section.

4. **Global Declaration Section:** This section is used to declare all global variables that will be used throughout the program.

5. **Main Function:** Every C++ program must have a main function. The code execution begins from the start of the main function.

6. **User-Defined Function:** These are the functions defined by the user, and the body of the function is written by the user to perform a specific task.

7. **Statement Section:** This section contains the executable statements, which are executed by the computer.

8. **Return Statement:** The return statement is used to return a value from a function. It is the last statement in a function.

This is the basic structure of a C++ program. It is important to follow this structure while writing a C++ program to ensure that the program is easy to read and understand.
