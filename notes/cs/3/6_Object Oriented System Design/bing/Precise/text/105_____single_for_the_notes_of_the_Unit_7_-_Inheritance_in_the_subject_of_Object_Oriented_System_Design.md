### Unit 7 - Inheritance in Object Oriented System Design

1. **Inheritance** is a mechanism in object-oriented programming that allows a new class to be created based on an existing class.
2. The new class, called the **subclass**, inherits the attributes and methods of the existing class, called the **superclass**.
3. Inheritance allows for **code reuse** and **modularity** in object-oriented programming.
4. Inheritance can be implemented using different techniques, such as **single inheritance**, **multiple inheritance**, and **interface inheritance**.
5. In single inheritance, a subclass inherits from only one superclass.
6. In multiple inheritance, a subclass can inherit from more than one superclass.
7. Interface inheritance allows a class to inherit only the interface, or the method signatures, of another class, without inheriting its implementation.
8. Inheritance can also be used to implement **polymorphism**, which allows objects of different classes to be treated as objects of a common superclass.
9. Inheritance should be used judiciously, as it can lead to **tight coupling** between classes and make the code more difficult to maintain.
