### Event and signals for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

- An **event** is an occurrence or happening of interest within a system or its environment.
- Events can be triggered by external stimuli or by the system itself.
- A **signal** is a specification of an asynchronous stimulus that can trigger a reaction in an object.
- Signals are used to represent events that are communicated between objects.
- In UML, a signal is represented as a named rectangle with a concave pentagon at the top.
- Signals can have parameters, which are used to pass data between objects.
- An object can send a signal to another object to trigger a specific behavior or response.
- An object can also receive signals from other objects and react accordingly.
- The handling of signals is defined in the state machine of the receiving object.
- Events and signals are important concepts in object-oriented system design as they allow for communication and interaction between objects.
