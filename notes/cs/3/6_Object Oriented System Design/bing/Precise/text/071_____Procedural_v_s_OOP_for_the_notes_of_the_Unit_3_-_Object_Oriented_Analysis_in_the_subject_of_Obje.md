### Procedural v/s OOP for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

1. **Procedural programming** is a programming paradigm that focuses on the procedure of executing a sequence of instructions to solve a problem. It is also known as imperative programming.
2. **Object-oriented programming (OOP)** is a programming paradigm that focuses on the concept of objects, which can contain data and methods to manipulate the data.
3. In procedural programming, the focus is on writing functions or procedures that operate on data, while in OOP, the focus is on creating objects that contain both data and methods.
4. Procedural programming is generally considered to be easier to learn and understand for beginners, as it follows a linear and top-down approach.
5. OOP, on the other hand, can be more complex to learn and understand, as it requires a shift in thinking from a procedural approach to an object-oriented approach.
6. OOP can provide benefits such as code reusability, modularity, and encapsulation, which can make it easier to maintain and scale large and complex software systems.
7. Procedural programming can be more efficient in terms of execution speed and memory usage for certain types of problems, while OOP can provide better organization and maintainability for larger and more complex software systems.
8. The choice between procedural and OOP depends on the specific problem being solved and the preferences and expertise of the programmer.
