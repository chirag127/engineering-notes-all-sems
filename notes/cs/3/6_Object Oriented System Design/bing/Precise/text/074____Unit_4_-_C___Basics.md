## Unit 4 - C++ Basics

C++ is a general-purpose programming language that was developed as an extension of the C language. It is an object-oriented language that supports encapsulation, inheritance, and polymorphism. Here are some basic concepts of C++:

1. **Variables**: A variable is a named location in memory that stores a value. In C++, you must declare the type of a variable before using it.

2. **Data Types**: C++ has several built-in data types, including int, char, float, double, and bool. You can also define your own data types using classes and structures.

3. **Operators**: C++ has a rich set of operators, including arithmetic, comparison, logical, and bitwise operators. These operators allow you to perform calculations and manipulate data.

4. **Control Structures**: C++ has several control structures, including if, else, switch, for, while, and do-while. These structures allow you to control the flow of your program based on conditions.

5. **Functions**: A function is a block of code that performs a specific task. In C++, you can define your own functions, and you can also use functions from the C++ Standard Library.

6. **Classes and Objects**: A class is a blueprint for an object. It defines the data and behavior of an object. An object is an instance of a class. In C++, you can use classes to create objects and manipulate them.

7. **Inheritance**: Inheritance is a mechanism that allows you to create a new class based on an existing class. The new class inherits the data and behavior of the existing class, and can also add new data and behavior.

8. **Polymorphism**: Polymorphism is a mechanism that allows you to use a single interface to represent different types of objects. In C++, you can achieve polymorphism using virtual functions and function overloading.
