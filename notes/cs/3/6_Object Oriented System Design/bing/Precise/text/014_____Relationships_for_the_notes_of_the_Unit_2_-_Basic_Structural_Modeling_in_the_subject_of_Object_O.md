### Relationships for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Relationships are used to represent the connections between objects in a system.
2. There are several types of relationships in object-oriented modeling, including association, aggregation, composition, and inheritance.
3. Association is a relationship between two objects where one object uses the other object. It is represented by a line connecting the two objects.
4. Aggregation is a special type of association where one object is a part of another object. It is represented by a diamond shape on the end of the line connecting the two objects.
5. Composition is a stronger form of aggregation where the part object cannot exist without the whole object. It is represented by a filled diamond shape on the end of the line connecting the two objects.
6. Inheritance is a relationship where one object is a specialized version of another object. It is represented by a triangle shape on the end of the line connecting the two objects.
7. These relationships are important for understanding the structure of a system and how the objects within the system interact with each other. They are also used to create more complex and reusable object-oriented designs.
