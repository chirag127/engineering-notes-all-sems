### Structured Analysis and Structured Design (SA/SD)

Structured Analysis and Structured Design (SA/SD) is a software engineering methodology used for designing and representing systems based on the flow of data and the processes that transform that data. It is a part of Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design.

- SA/SD is a graphical technique that uses a hierarchy of diagrams to represent the system.
- The top-level diagram is called a Context Diagram, which shows the system as a single process and its interactions with external entities.
- The next level of diagrams is called Data Flow Diagrams (DFDs), which show the flow of data between processes, data stores, and external entities.
- The final level of diagrams is called Structure Charts, which show the hierarchical organization of the system's modules and their relationships.
- SA/SD also includes techniques for analyzing and designing data structures, such as Entity-Relationship Diagrams (ERDs) and Data Dictionary.
- SA/SD is a top-down approach, where the system is first decomposed into its major components, and then each component is further decomposed into its subcomponents.
- SA/SD is a structured approach, where the system is represented using a set of well-defined graphical notations and rules.
- SA/SD is a popular methodology for designing information systems, but it has also been used for designing real-time systems, embedded systems, and other types of software systems.
