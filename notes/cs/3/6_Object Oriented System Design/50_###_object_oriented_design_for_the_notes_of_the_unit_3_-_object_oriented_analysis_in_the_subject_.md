### Object oriented design for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Unit 3 of the Object Oriented System Design course focuses on Object Oriented Analysis and covers the aspect of Object Oriented Design.

Object Oriented Design (OOD) is a software design process that is based on the principles of object-oriented programming (OOP). OOD involves creating a high-level representation of a software system, including the classes, objects, and relationships that make up the system.

In OOD, the design process is iterative, with multiple rounds of design, implementation, and testing. This allows the design to be refined and improved over time, based on feedback from testing and user feedback.

In the context of the Object Oriented System Design course, students in Unit 3 will learn about Object Oriented Design as part of the discussion on Object Oriented Analysis. This may include working with examples of Object Oriented Design, analyzing the benefits and limitations of OOD, and learning how to use OOD to create a high-level representation of a software system.
