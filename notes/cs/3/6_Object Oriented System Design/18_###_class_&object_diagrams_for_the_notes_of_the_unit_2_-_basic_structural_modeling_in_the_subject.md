### Class &Object Diagrams for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Class and Object diagrams are two of the most commonly used diagrams in Object Oriented System Design. They are used to represent the structure and behavior of objects and classes in a software system.

The following are some of the key concepts related to Class and Object diagrams:

1. Class Diagrams: Class diagrams are used to represent the structure of classes in a software system. They show the attributes and methods of each class, and the relationships between classes.

2. Object Diagrams: Object diagrams are used to represent the instances of classes in a software system. They show the values of the attributes of each object, and the relationships between objects.

3. Attributes: Attributes are the data elements of a class or an object, and they represent the state of the class or object.

4. Methods: Methods are the operations that can be performed on a class or an object, and they represent the behavior of the class or object.

In this unit, you will learn about Class and Object diagrams, and you will learn how to create and interpret these diagrams. You will also learn about the different types of relationships that can exist between classes and objects, and you will learn how to represent these relationships in Class and Object diagrams.

This unit will provide a foundation for understanding the principles and practices of Object Oriented System Design, and for exploring the various concepts and techniques used in the field of Object Oriented System Design.
