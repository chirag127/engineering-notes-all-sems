### object oriented modelling for the notes of the Unit 1 - Introduction: The meaning of Object Orientation in the subject of Object Oriented System Design

Unit 1 of the Object Oriented System Design course focuses on the Introduction to Object Orientation, including the aspect of Object Oriented Modelling.

Object Oriented Modelling (OOM) is a software development methodology that uses objects and classes to represent real-world entities and their relationships. OOM is based on the concept of object orientation, which is a way of thinking about software design that emphasizes the use of objects to represent real-world entities and their behavior.

In OOM, objects are used to represent entities in a system, and classes are used to define the properties and behaviors of these objects. OOM also includes the use of inheritance, polymorphism, and encapsulation, which are fundamental concepts in object-oriented programming.

In the context of the Object Oriented System Design course, students in Unit 1 will learn about Object Oriented Modelling as part of the Introduction to Object Orientation. This may include working with examples of OOM, analyzing the benefits and limitations of OOM, and learning how to use OOM in the design and implementation of object-oriented systems.

In summary, Unit 1 of the Object Oriented System Design course focuses on the Introduction to Object Orientation, and includes the aspect of Object Oriented Modelling. Object Oriented Modelling is a software development methodology that uses objects and classes to represent real-world entities and their relationships, and includes the use of inheritance, polymorphism, and encapsulation. Students will learn about Object Oriented Modelling through interactive activities and hands-on experiences, and will learn how to use OOM in the design and implementation of object-oriented systems.
