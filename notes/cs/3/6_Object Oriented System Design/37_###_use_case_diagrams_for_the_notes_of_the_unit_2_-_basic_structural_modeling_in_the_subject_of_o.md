### Use case Diagrams for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Use case diagrams are a type of UML diagram used to describe the functional requirements of a software system. They are used to model the interactions between the system and its users, and to describe the goals of the system.

The following are some of the key concepts related to use case diagrams:

1. Actors: Actors are the entities that interact with the system, and they represent the users of the system.

2. Use Cases: Use cases are the functional requirements of the system, and they represent the interactions between the system and its actors.

3. Relationships: Relationships are the connections between actors and use cases, and they represent the interactions between the actors and the system.

4. Include: The include relationship is used to show that one use case is included in another use case.

5. Extend: The extend relationship is used to show that one use case extends another use case.

In this unit, you will learn about the basic concepts of use case diagrams, and you will learn how to use use case diagrams to model the functional requirements of a software system. You will also learn about the different types of relationships that can exist between actors and use cases, and you will learn how to represent these relationships in use case diagrams.

This unit will provide a foundation for understanding the principles and practices of use case diagrams in Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
