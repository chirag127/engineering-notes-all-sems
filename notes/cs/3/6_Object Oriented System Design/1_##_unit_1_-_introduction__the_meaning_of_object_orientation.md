## Unit 1 - Introduction: The meaning of Object Orientation

Unit 1 of the Computer Graphics course focuses on Introduction and covers the meaning of Object Orientation.

Object Orientation is a programming paradigm that involves organizing data and code into objects, which are instances of classes. Objects contain both data (attributes) and code (methods) that operate on that data. Object Orientation is a key aspect of modern programming languages and is used to create reusable, modular, and scalable applications.

In the context of the Computer Graphics course, students in Unit 1 will learn about Object Orientation as an introduction to the course. This may include working with examples of Object Orientation, analyzing the benefits and limitations of Object Orientation, and learning how to use Object Orientation in a computer graphics program.
