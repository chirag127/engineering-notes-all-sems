### enum for the notes of the Unit 4 - C++ Basics in the subject of Object Oriented System Design

Enum is a user-defined data type in the C++ programming language that is used to represent a set of named constants. Enums are used to define a set of named constants that represent a specific set of values, and they are used to improve code readability and maintainability.

The following are some of the key concepts related to enums in C++:

1. Definition: Enums are defined using the "enum" keyword, followed by the name of the enum and a list of named constants separated by commas.

2. Usage: Enums are used in C++ to represent a set of named constants, and they are used in place of integer constants to improve code readability and maintainability.

3. Scoping: Enums are scoped to the block in which they are defined, and they are not accessible outside of that block unless they are declared with the "extern" keyword.

4. Type: Enums in C++ have an underlying integer type, and they can be explicitly cast to an integer type if needed.
