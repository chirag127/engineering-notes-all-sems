### Abstraction and Encapsulation for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Unit 3 of the Object Oriented System Design course focuses on Object Oriented Analysis and covers the aspects of Abstraction and Encapsulation.

Abstraction and Encapsulation are two fundamental concepts in object-oriented programming that are used to design and implement object-oriented systems.

Abstraction refers to the process of hiding the implementation details of a system and exposing only the essential features to the user. This allows the user to interact with the system at a higher level of abstraction, without having to understand the underlying implementation details.

Encapsulation refers to the process of packaging the data and behavior of an object into a single unit, and protecting the internal state of the object from external access. This allows objects to be designed and implemented in a modular manner, and makes it easier to maintain and modify the system.

In the context of the Object Oriented System Design course, students in Unit 3 will learn about Abstraction and Encapsulation as part of the discussion on Object Oriented Analysis. This may include working with examples of Abstraction and Encapsulation, analyzing the benefits and limitations of these concepts, and learning how to use Abstraction and Encapsulation to design and implement object-oriented systems.
