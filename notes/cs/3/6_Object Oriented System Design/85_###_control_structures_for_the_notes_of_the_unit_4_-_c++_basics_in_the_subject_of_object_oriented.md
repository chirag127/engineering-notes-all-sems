### control structures for the notes of the Unit 4 - C++ Basics in the subject of Object Oriented System Design

Unit 4 of the Object Oriented System Design course focuses on C++ Basics and covers the aspect of control structures.

Control structures are an important aspect of programming, and are used to control the flow of execution in a program. In C++, there are several types of control structures, including:
- Conditional statements (if, switch)
- Loops (for, while, do-while)

Conditional statements are used to execute a block of code based on a condition. For example, an if statement can be used to execute a block of code only if a certain condition is true.

Loops are used to repeat a block of code until a certain condition is met. For example, a for loop can be used to repeat a block of code a specific number of times, while a while loop can be used to repeat a block of code until a certain condition is true.

In the context of the Object Oriented System Design course, students in Unit 4 will learn about control structures as part of the discussion on C++ Basics. This may include working with examples of control structures, analyzing the benefits and limitations of different types of control structures, and learning how to use control structures to control the flow of execution in a C++ program.
