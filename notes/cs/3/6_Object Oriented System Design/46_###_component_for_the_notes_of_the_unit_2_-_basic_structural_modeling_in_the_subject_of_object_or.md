### Component for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Components are a key concept in Object Oriented System Design, and they are used to represent the building blocks of a software system. Components are used to describe the structure and behavior of a system, and to describe the way objects interact with each other.

The following are some of the key concepts related to components:

1. Component Diagrams: Component diagrams are used to represent the structure of a software system, and they are used to describe the relationships between components.

2. Components: Components are the building blocks of a software system, and they represent the objects and classes in the system.

3. Interfaces: Interfaces are the contracts between components, and they define the way components interact with each other.

4. Ports: Ports are the connectors between components, and they are used to describe the way objects interact with each other.

In this unit, you will learn about the basic concepts of components, and you will learn how to use component diagrams to describe the structure and behavior of a software system. You will also learn about the different types of interfaces and ports, and you will learn how to choose the appropriate type of interface or port for a specific task.

This unit will provide a foundation for understanding the principles and practices of Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
