### Object oriented programming style for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Object-oriented programming (OOP) style is a programming paradigm based on the concepts of objects and classes. It is used to model real-world objects and their interactions in a software system. OOP style is characterized by its use of inheritance, encapsulation, and polymorphism.

The following are some of the key concepts related to OOP style:

1. Objects: Objects are the basic building blocks of an OOP system, and they represent real-world objects.

2. Classes: Classes are the blueprint for objects, and they define the properties and methods of objects.

3. Inheritance: Inheritance is a mechanism that allows classes to inherit properties and methods from other classes.

4. Encapsulation: Encapsulation is a mechanism that protects the internal state of an object from external modification.

5. Polymorphism: Polymorphism is a mechanism that allows objects to be treated as objects of a more general type.

In this unit, you will learn about the basic concepts of OOP style, and you will learn how to use OOP style to model real-world objects and their interactions in a software system. You will also learn about the benefits of OOP style, and you will learn how to use OOP style to improve the design and implementation of a software system.

This unit will provide a foundation for understanding the principles and practices of Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
