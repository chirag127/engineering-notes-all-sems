### Inline functions for the notes of the Unit 5 - C++ Functions in the subject of Object Oriented System Design

Inline functions are a feature of C++ that allows a function to be expanded in place at the point of its call, rather than being executed as a separate function. Inline functions are used to improve the performance of a program by reducing the overhead associated with function calls.

The following are some of the key concepts related to inline functions in C++:

1. Definition: Inline functions are defined using the inline keyword, and they are typically defined in header files.

2. Expansion: The body of an inline function is expanded in place at the point of its call, rather than being executed as a separate function.

3. Performance: Inline functions can improve the performance of a program by reducing the overhead associated with function calls.

4. Limitations: Inline functions have some limitations, including the size of the function body and the complexity of the function.

You will also learn about the limitations of inline functions, and you will learn how to choose the appropriate type of function for a specific task.
