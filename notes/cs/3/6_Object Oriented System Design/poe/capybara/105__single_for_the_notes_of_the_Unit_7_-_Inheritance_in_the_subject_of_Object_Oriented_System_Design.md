### Inheritance

Inheritance is an important concept in Object Oriented System Design. It allows the creation of new classes based on existing ones. It helps in reusing the code, reducing redundancy and making the code more manageable. Inheritance is an example of the 'is-a' relationship, which means that a derived class is a specialized version of the base class. 

Some important points to remember about Inheritance are:

- Inheritance allows the derived class to inherit the properties and methods of the base class.
- The derived class can add new properties and methods, or modify the existing ones.
- The base class cannot access the properties and methods of the derived class.
- The derived class can access the properties and methods of the base class, if they are declared as public or protected.
- The derived class can override the methods of the base class, if they are declared as virtual or abstract.
- The derived class constructor can call the base class constructor using the 'base' keyword.
- Inheritance can create a hierarchy of classes, where each derived class inherits from its parent class.

Inheritance is a powerful tool in Object Oriented System Design, but it should be used carefully. Overuse of inheritance can lead to a complex and difficult to maintain code. It is important to understand the 'is-a' relationship and the principles of object-oriented design before using inheritance.

In conclusion, Inheritance is an important concept in Object Oriented System Design. It allows the creation of new classes based on existing ones, making the code more manageable and reducing redundancy. However, it should be used carefully and with a good understanding of object-oriented principles.
