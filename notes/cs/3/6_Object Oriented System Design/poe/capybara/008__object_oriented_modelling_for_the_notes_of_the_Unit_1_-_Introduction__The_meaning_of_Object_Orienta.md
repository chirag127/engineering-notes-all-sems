### Object Oriented Modelling for the Notes of Unit 1 - Introduction: The Meaning of Object Orientation in the Subject of Object Oriented System Design

Object oriented modelling is an important aspect of object oriented system design. It is a technique that helps in understanding the requirements of a system and designing it in a way that is easy to implement and maintain. Here are some key points to keep in mind when it comes to object oriented modelling:

- Object oriented modelling is a process that involves identifying the objects that make up a system and defining their attributes and relationships with each other.
- Objects are the basic building blocks of an object oriented system. They represent real-world entities or concepts and can have properties (attributes) and behaviors (methods).
- In object oriented modelling, objects are organized into classes. A class is a blueprint or template for creating objects of the same type. It defines the attributes and methods that all objects of that class will have.
- In addition to classes, object oriented modelling also involves identifying the relationships between objects. There are several types of relationships, including inheritance, composition, and association.
- Inheritance is a relationship in which one class (the subclass) inherits the attributes and methods of another class (the superclass). This allows for code reuse and can make the system easier to maintain.
- Composition is a relationship in which an object is made up of other objects. For example, a car object might be composed of an engine object, a transmission object, and so on.
- Association is a relationship in which two objects are related in some way, but one does not contain the other. For example, a customer object might be associated with an order object.
- Object oriented modelling is important because it helps to ensure that the system is designed in a way that is easy to understand, implement, and maintain. By identifying the objects, classes, and relationships that make up the system, developers can create a design that is both flexible and scalable.
