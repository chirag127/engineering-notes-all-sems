### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In this unit, we will learn about basic structural modeling in the field of Object Oriented System Design. Here are some important terms that you should familiarize yourself with:

- **Class:** A blueprint or template for creating objects that define the properties and behavior of a certain type of object.

- **Object:** An instance of a class that has attributes and methods. It represents a real-world entity and can interact with other objects.

- **Attribute:** A variable that belongs to an object and defines its state or characteristics.

- **Method:** A function that belongs to an object and defines its behavior or actions.

- **Inheritance:** The process of creating a new class from an existing class. The new class inherits the attributes and methods of the existing class, and can also add its own attributes and methods.

- **Polymorphism:** The ability of objects of different classes to be treated as if they were of the same class. This allows for more flexibility and reusability in the system.

- **Encapsulation:** The practice of hiding the internal details of an object and only exposing its public interface. This improves security and maintainability of the system.

- **Association:** A relationship between two objects where one object uses or interacts with the other object.

- **Aggregation:** A type of association where one object contains or owns another object, but the contained object can exist independently.

- **Composition:** A type of association where one object is made up of other objects, and the composed objects cannot exist independently.

These terms are crucial to understanding basic structural modeling in Object Oriented System Design. Make sure to study and review them thoroughly before moving on to more advanced topics.
