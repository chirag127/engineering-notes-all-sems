### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In this unit, we will be discussing the fundamental concepts of basic structural modeling in Object Oriented System Design. Here are some important points to keep in mind while studying this unit:

- **Object Oriented System Design**: Object Oriented System Design is a method of designing software systems based on the principles of object-oriented programming. It involves the use of objects to represent real-world entities and their relationships with each other.

- **Structural Modeling**: Structural modeling is a technique used in Object Oriented System Design to represent the structure of a software system. It involves the use of diagrams to show the relationships between the different components of the system.

- **Class Diagram**: A class diagram is a type of structural diagram that represents the classes and their relationships in a software system. It is used to visualize the static structure of the system.

- **Object Diagram**: An object diagram is a type of structural diagram that represents the instances of classes in a software system. It is used to visualize the dynamic structure of the system.

- **Association**: An association is a relationship between two or more classes in a software system. It represents the way in which the classes are related to each other.

- **Aggregation**: Aggregation is a special type of association where one class is composed of one or more instances of another class. It represents a "has-a" relationship between the classes.

- **Composition**: Composition is a stronger form of aggregation where one class is composed of one or more instances of another class. It represents a "part-of" relationship between the classes.

- **Inheritance**: Inheritance is a mechanism in Object Oriented System Design where one class inherits the properties and methods of another class. It is used to represent the "is-a" relationship between the classes.

- **Polymorphism**: Polymorphism is the ability of an object to take on multiple forms. It is achieved through inheritance and allows objects of different classes to be treated as if they were objects of the same class.

- **Encapsulation**: Encapsulation is the process of hiding the internal details of an object from the outside world. It is achieved through the use of access modifiers and helps to maintain the integrity of the object.

These are some of the important concepts that you should keep in mind while studying the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design. Understanding these concepts will help you to design software systems that are efficient, scalable, and maintainable.
