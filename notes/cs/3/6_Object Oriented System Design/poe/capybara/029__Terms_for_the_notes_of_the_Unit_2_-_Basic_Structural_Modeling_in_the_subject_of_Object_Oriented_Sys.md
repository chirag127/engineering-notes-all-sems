### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In this unit, we will be learning about basic structural modeling in object-oriented system design. Here are some important terms to keep in mind:

- **Class**: A blueprint or template for creating objects that define its attributes and methods.
- **Object**: An instance of a class that contains specific data and methods.
- **Attribute**: A characteristic or property of an object, such as size, color, or shape.
- **Method**: A function or behavior associated with an object that can manipulate its data and attributes.
- **Encapsulation**: The process of hiding the internal workings of an object and only exposing the necessary information through its public methods.
- **Inheritance**: The ability of a subclass to inherit attributes and methods from its superclass.
- **Polymorphism**: The ability of objects of different classes to be treated as if they have the same interface, allowing them to be used interchangeably.
- **Interface**: The set of public methods and attributes that define the behavior of an object.
- **Abstraction**: The process of simplifying complex systems by breaking them down into smaller, more manageable parts.

Understanding these terms is essential to successfully designing and implementing object-oriented systems. Make sure to review them thoroughly and apply them in your practice exercises and projects.
