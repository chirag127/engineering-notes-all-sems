### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In this unit, we will be discussing the basics of structural modeling in Object Oriented System Design. Here are some important terms that you need to know:

1. **Class**: A blueprint or template for creating objects of a particular type. A class defines the attributes and methods that an object will have.

2. **Object**: An instance of a class. An object has its own set of attributes and can perform the methods defined in its class.

3. **Attribute**: A characteristic or property of an object. Attributes can be of different data types such as strings, integers, floats, or booleans.

4. **Method**: A function or behavior that an object can perform. Methods are defined in the class and can be called by objects of that class.

5. **Encapsulation**: The process of hiding the internal details of an object and exposing only the necessary information. This is achieved by making attributes private and providing public methods to access and modify them.

6. **Inheritance**: The process of creating a new class by deriving properties and behaviors from an existing class. The new class is called the subclass or derived class, and the existing class is called the superclass or base class.

7. **Polymorphism**: The ability of objects of different classes to respond to the same message or method call in different ways. Polymorphism can be achieved through method overriding and method overloading.

8. **Aggregation**: A relationship between two classes where one class contains a reference to another class as one of its attributes. The contained class is known as the component, and the containing class is known as the composite.

9. **Composition**: A stronger form of aggregation where the contained class cannot exist without the containing class. The contained class is known as the part, and the containing class is known as the whole.

By understanding these terms, you will be able to better comprehend the concepts and principles of basic structural modeling in Object Oriented System Design.
