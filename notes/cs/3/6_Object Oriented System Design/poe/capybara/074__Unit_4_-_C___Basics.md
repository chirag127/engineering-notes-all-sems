## Unit 4 - C++ Basics

C++ is a powerful programming language that is widely used in software development. In this unit, we will cover the basics of C++ programming. Here are some key concepts to keep in mind:

### 1. Data Types

C++ has several built-in data types, including integers, floating-point numbers, characters, and Boolean values. It also supports user-defined data types, such as structures and classes.

### 2. Variables

Variables are used to store data in a program. In C++, variables must be declared before they can be used. The declaration includes the data type and the name of the variable.

### 3. Operators

C++ supports a wide variety of operators, including arithmetic, assignment, comparison, and logical operators. These operators are used to manipulate data in a program.

### 4. Control Structures

Control structures are used to control the flow of a program. C++ supports several control structures, including if statements, switch statements, and loops.

### 5. Functions

Functions are used to encapsulate a block of code that performs a specific task. C++ supports both built-in and user-defined functions.

### 6. Arrays

Arrays are used to store collections of data of the same data type. In C++, arrays can have one or more dimensions.

### 7. Pointers

Pointers are used to store the memory address of a variable. They are often used in C++ to manipulate data directly in memory.

### 8. Object-Oriented Programming

C++ is an object-oriented programming language. This means that it supports classes and objects, which are used to encapsulate data and behavior in a program.

By mastering these basic concepts, you will be well on your way to becoming proficient in C++ programming.
