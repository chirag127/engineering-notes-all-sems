## Unit 7 - Inheritance

Inheritance is a fundamental concept in object-oriented programming that allows one class to inherit the properties and behaviors of another class. It enables code reusability, making it easier to maintain and extend programs. Here are some important points to consider when studying inheritance:

- Inheritance is a way to create a hierarchy of classes, where each subclass inherits the properties and behaviors of its parent class.
- The parent class is also known as the superclass, and the subclass is also known as the derived class.
- Inheritance is implemented in Java using the `extends` keyword. A subclass can only extend one superclass, but a superclass can have multiple subclasses.
- The subclass inherits all the public and protected methods and variables of the superclass, but not the private ones.
- The `super` keyword is used to call the constructor and methods of the superclass from the subclass.
- Overriding is a mechanism in which a subclass provides its implementation of a method that is already defined in its superclass.
- Polymorphism is another important concept in inheritance, which allows objects of different classes to be treated as if they belong to a common superclass.
- The `instanceof` operator is used to determine if an object is an instance of a particular class or its subclass.
- Inheritance also has some limitations, such as the increase in complexity and the tight coupling between the superclass and its subclasses.

In conclusion, inheritance is a powerful concept in object-oriented programming that allows for code reusability and hierarchy creation. Understanding its implementation, limitations, and related concepts such as overriding and polymorphism is essential for writing efficient and effective programs.
