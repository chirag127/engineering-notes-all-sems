### Principles of Modelling

Modelling is a crucial aspect of Object Oriented System Design. By modelling, we can represent real-world objects and their relationships in a software system. Here are some principles of modelling that you should keep in mind:

1. Abstraction: Modelling involves abstraction, which means focusing on the essential features of an object and ignoring the rest. This allows us to simplify the complexity of the real world and create a software system that is easier to understand and maintain.

2. Encapsulation: Encapsulation involves hiding the implementation details of an object and only exposing its public interface. This helps to ensure that the object is used correctly and prevents unintended changes to its internal state.

3. Inheritance: Inheritance allows us to create new classes that are based on existing ones. This can help to reduce code duplication and make the system more flexible.

4. Polymorphism: Polymorphism allows us to use objects of different classes interchangeably. This can help to make the system more adaptable and easier to extend in the future.

5. Composition: Composition involves creating complex objects by combining simpler ones. This can help to create more modular and reusable code.

6. Modelling for Behaviour: Modelling is not just about creating a static representation of objects, but also about capturing their behaviour. This involves defining methods that describe what an object can do and how it interacts with other objects in the system.

By following these principles of modelling, we can create software systems that are easier to understand, maintain and extend.
