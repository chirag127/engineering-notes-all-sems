### Process and Thread

In the Unit 2 of the Object Oriented System Design subject, we will be discussing the basic structural modeling. One of the important topics that we will be covering in this unit is the Process and Thread. 

Here are some important points that you need to understand about Process and Thread:

- A process is an instance of a program that is being executed. It has its own memory space and system resources. 
- A thread is a lightweight process that can run concurrently with other threads in the same process. 
- Threads share the same memory space and system resources as the process they belong to. 
- A process can have multiple threads. 
- Threads within the same process can communicate with each other by sharing memory. 
- Threads can be used to perform tasks concurrently, which can improve the performance of the system. 
- Threads can also be used to perform tasks that require asynchronous processing, such as responding to user input while performing a long-running task in the background. 
- However, using threads also introduces some challenges, such as thread safety and synchronization issues. 

In summary, understanding the concepts of process and thread is essential for designing efficient and scalable systems. Make sure to study this topic thoroughly to prepare for the exams.
