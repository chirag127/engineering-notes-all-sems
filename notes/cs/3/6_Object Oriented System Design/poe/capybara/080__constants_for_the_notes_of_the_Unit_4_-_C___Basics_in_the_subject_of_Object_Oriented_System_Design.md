### Constants for the Notes of the Unit 4 - C++ Basics in the Subject of Object Oriented System Design

When studying C++ basics in the Object Oriented System Design subject, it is important to understand the constants that will be used throughout the course. Here are some key constants to keep in mind:

- **Data Types:** C++ has built-in data types, including integers, floating-point numbers, characters, and booleans. These data types are constants and cannot be changed.

- **Keywords:** C++ has reserved keywords that cannot be used as variable names or identifiers. Some examples of these keywords include `if`, `else`, `while`, and `class`.

- **Operators:** C++ has several operators that are used to perform various operations on data. These operators include arithmetic operators such as `+`, `-`, `*`, and `/`, as well as relational operators such as `==`, `!=`, `<`, `>`, `<=`, and `>=`.

- **Preprocessor Directives:** C++ has preprocessor directives that are used to perform operations before the code is compiled. Some common preprocessor directives include `#include`, `#define`, and `#ifdef`.

- **Control Structures:** C++ has control structures that are used to control the flow of a program. These structures include `if` statements, `for` loops, `while` loops, and `switch` statements.

- **Memory Allocation:** C++ has two types of memory allocation - stack and heap. Stack memory is allocated automatically when a function is called, while heap memory is allocated manually using `new` and `delete`.

Understanding these constants is crucial for mastering C++ basics in Object Oriented System Design. By keeping these constants in mind, students can better understand the code they are working with and write more efficient and effective programs.
