### Combining three models for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design.

Object Oriented Analysis is an essential aspect of Object Oriented System Design. It involves the use of models to represent the system being designed. In this unit, we will be looking at three models that are commonly used in Object Oriented Analysis. These models are:

1. Use Case Model
The Use Case Model is a model that represents the interactions between the system and its users. It is used to identify the various use cases that the system will need to support. The Use Case Model is an essential model in Object Oriented Analysis as it helps to identify the requirements of the system.

2. Class Diagram Model
The Class Diagram Model is a model that represents the classes and their relationships in the system. It is used to identify the attributes and methods of each class, as well as the relationships between the classes. The Class Diagram Model is an essential model in Object Oriented Analysis as it helps to identify the objects that will be used in the system.

3. Sequence Diagram Model
The Sequence Diagram Model is a model that represents the interactions between the objects in the system. It is used to identify the various sequences of events that occur in the system. The Sequence Diagram Model is an essential model in Object Oriented Analysis as it helps to identify the behavior of the objects in the system.

Combining these three models can provide a comprehensive analysis of the system being designed. By using the Use Case Model, the Class Diagram Model, and the Sequence Diagram Model together, we can identify the requirements of the system, the objects that will be used in the system, and the behavior of the objects in the system.

In conclusion, Object Oriented Analysis is an essential aspect of Object Oriented System Design. The Use Case Model, the Class Diagram Model, and the Sequence Diagram Model are three models that are commonly used in Object Oriented Analysis. By combining these three models, we can provide a comprehensive analysis of the system being designed.
