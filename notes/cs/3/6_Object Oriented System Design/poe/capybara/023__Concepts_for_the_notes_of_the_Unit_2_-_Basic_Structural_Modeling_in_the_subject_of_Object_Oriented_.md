### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

In this unit, we will be exploring the basic structural modeling concepts in Object Oriented System Design. Some of the important concepts to keep in mind are:

1. Class diagrams: 
   - Class diagrams are used to represent the static structure of a system.
   - They depict classes, interfaces, associations, and their relationships.
   - The UML notation is commonly used to create class diagrams.

2. Object diagrams: 
   - Object diagrams are used to represent instances of classes at a particular point in time.
   - They depict objects, their attributes, and their relationships.
   - Object diagrams are useful for testing and debugging.

3. Packages: 
   - Packages are used to organize classes into logical groups.
   - They help to manage the complexity of large systems.
   - Packages can contain other packages, classes, interfaces, and other types.

4. Relationships: 
   - Relationships between classes and objects are an important aspect of structural modeling.
   - Association, aggregation, and composition are some of the common relationships between classes.
   - Inheritance is a relationship between classes that represents an "is-a" relationship.

5. Visibility: 
   - Visibility is a property of classes and their members that determines their accessibility from other parts of the system.
   - Public, private, and protected are the three levels of visibility.
   - Maintaining proper visibility is important for ensuring the encapsulation and security of the system.

6. Stereotypes: 
   - Stereotypes are used to extend UML notation to represent specific domain concepts.
   - They are used to provide additional information about classes and their relationships.
   - Stereotypes can be defined by users to represent their own domain concepts.

By understanding these concepts, you will be able to create effective structural models of Object Oriented Systems. It is important to practice creating class and object diagrams to gain proficiency in this area.
