
## Unit 4 - C++ Basics

* C++ is a general-purpose, object-oriented programming language that was created in 1985 by Bjarne Stroustrup.
* C++ is a compiled language, meaning that the code written in C++ must be compiled into an executable program before it can be run.
* C++ supports both procedural and object-oriented programming styles.
* C++ supports the use of functions and classes, which allow for the encapsulation of data and code into a single unit.
* C++ allows for the use of templates, which allow for the reuse of code across multiple types.
* C++ supports the use of pointers, which allow for the efficient manipulation of data in memory.
* C++ supports the use of the Standard Template Library (STL), which provides a collection of useful data structures and algorithms.
* C++ supports the use of exception handling, which allows for the graceful handling of errors.
