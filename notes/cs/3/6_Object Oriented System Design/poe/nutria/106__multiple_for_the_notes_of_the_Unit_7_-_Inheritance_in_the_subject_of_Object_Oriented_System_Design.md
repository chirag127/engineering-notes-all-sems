
### Unit 7 - Inheritance in Object Oriented System Design

- Inheritance is a process by which an object acquires the properties and behaviors of another object.
- It is a form of code reuse, allowing developers to create new classes that share some of the same functionality of existing classes.
- Inheritance allows developers to create a hierarchy of classes, where a class can inherit from a parent class and then add its own unique features.
- Inheritance also enables developers to create relationships between classes, allowing for more complex and powerful code.
- In object-oriented programming, inheritance is used to create a class hierarchy, where one class is the parent of another class.
- The parent class is called the superclass, and the child class is called the subclass.
- The subclass can inherit all the methods and variables of the superclass, as well as add its own methods and variables.
- The subclass can also override methods defined in the superclass.
- In addition, inheritance enables developers to create relationships between classes, allowing for more complex and powerful code.
