
### Iterated Messages for the Notes of the Unit 2 - Basic Structural Modeling in the Subject of Object Oriented System Design

1. Iterated messages are a type of message used in object-oriented system design. They are used to send a message to a recipient object, which can then send a response back to the sender. 
2. Iterated messages are a form of communication between objects in a system. They allow objects to communicate with each other in a structured and consistent way. 
3. Iterated messages are composed of a header, a body, and a footer. The header contains information about the message, such as the sender and the recipient. The body contains the data to be sent, and the footer contains any additional information that the sender may need to include. 
4. Iterated messages can be sent synchronously or asynchronously. Synchronous messages are sent immediately, while asynchronous messages are sent at a later time. 
5. Iterated messages can be sent over a network, such as the internet, or directly between two objects. 
6. Iterated messages can be used to request information from an object, or to send data to an object. 
7. Iterated messages are a powerful tool for designing object-oriented systems. They allow objects to communicate with each other in a structured and consistent way, which can lead to more efficient and reliable systems.
