

### Implementing Inheritance for the Notes of the Unit 3 - Object Oriented Analysis in the Subject of Object Oriented System Design

1. Inheritance is a powerful feature of Object Oriented Programming (OOP) that allows a class to inherit the properties and methods of another class. 
2. Inheritance allows a subclass to inherit the properties and methods of its parent class, and to add its own unique properties and methods. 
3. When a subclass inherits from a parent class, the subclass is said to be a derived class or a child class. 
4. The parent class is referred to as the base class or the parent class. 
5. Inheritance allows code reuse, which reduces the amount of code that needs to be written and maintained. 
6. Inheritance also allows for polymorphism, which allows different classes to have different implementations of the same method. 
7. In order to implement inheritance, the subclass must use the keyword ‘extends’ to indicate that it is inheriting from a parent class. 
8. The subclass can then access the parent class’s properties and methods by using the keyword ‘super’. 
9. The subclass can also override the parent class’s methods by using the keyword ‘override’. 
10. In addition, the subclass can also add its own unique properties and methods.
