
### Friend Functions
Friend functions are functions that are declared outside of a class, but have access to the private and protected members of the class. Friend functions are declared with the keyword `friend` before the function declaration.

* Friend functions are not member functions of a class, but they still have access to the class's private and protected members.
* Friend functions are declared with the keyword `friend` before the function declaration.
* Friend functions can be declared either in the public or private section of a class. 
* Friend functions can be called like any other function, and they can access the class's private and protected members.
* Friend functions can be overloaded, and they can be declared as either global or static.
* Friend functions can be used to access private and protected members of a class from outside the class.
* Friend functions can be used to make operator overloading easier.
* Friend functions can also be used to allow two classes to access each other's private and protected members.
