
### Default Arguments for C++ Functions

1. Default arguments are parameters that can be passed to a function when calling it. If a default argument is not provided, the function will use the default argument’s value.
2. Default arguments can be used to simplify the function call and reduce code duplication.
3. Default arguments are defined in the function’s parameter list.
4. Default arguments must be the rightmost parameters in the parameter list.
5. Default arguments must have a value assigned to them.
6. Default arguments can be used to provide a default value to a parameter if one is not provided when the function is called.
7. Default arguments can be used to provide a value to a parameter if the function caller does not know the value.
8. Default arguments can be used to provide an optional parameter to a function.
9. Default arguments can be used to provide a default implementation for a function.
10. Default arguments are evaluated each time the function is called.
