
### Simple Functions for the Notes of the Unit 5 - C++ Functions in the Subject of Object Oriented System Design

1. A function is a set of instructions that can be used to perform a specific task.
2. A C++ function is a block of code that can be invoked from other parts of the program.
3. A function can take parameters, which are values that are passed to the function when it is called.
4. Functions can also return values, which are the values that are returned to the calling code when the function is finished.
5. C++ functions can be declared in the global scope or in a class.
6. When a function is declared in a class, it is known as a member function.
7. Member functions can be marked as public, protected, or private, which determines who can access the function.
8. C++ functions can also be overloaded, which means they can have multiple definitions with different parameters.
9. Functions can be recursive, which means they can call themselves.
10. Functions can also be passed as parameters to other functions, which is known as a callback.
