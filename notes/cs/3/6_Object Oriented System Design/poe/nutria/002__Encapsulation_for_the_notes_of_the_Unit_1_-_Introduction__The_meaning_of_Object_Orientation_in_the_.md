
### Encapsulation for the notes of the Unit 1 - Introduction: The meaning of Object Orientation in the subject of Object Oriented System Design

1. Object-oriented system design is an approach to problem-solving in which objects are used to represent real-world entities and their relationships with other objects.
2. Encapsulation is one of the fundamental principles of object-oriented programming. It is a mechanism of hiding the internal details of an object, allowing the object to be used without knowing its internal implementation.
3. Encapsulation allows the programmer to create a “black box”, which can be used without knowing the internal details of the object.
4. Encapsulation also allows the programmer to separate the interface of an object from its implementation. This allows the programmer to change the implementation of an object without affecting the interface.
5. Encapsulation also allows the programmer to create a secure system, as only the necessary information is exposed to the user.
6. Encapsulation also allows the programmer to create a more modular system, as the programmer can create objects that can be reused in different contexts.
7. Encapsulation also allows the programmer to create a more extensible system, as the programmer can add new features to the object without affecting existing code.
