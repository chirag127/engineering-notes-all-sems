
### Combining three models for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

1. Object-oriented analysis (OOA) is a process of analyzing a problem and then designing a software solution that is based on the analysis. It involves identifying the objects and their relationships in the problem domain, and then designing the software based on those objects and their relationships.

2. Object-oriented design (OOD) is the process of designing a software system based on the objects and their relationships identified during the analysis. OOD involves creating the classes, methods, and data structures that will be used to implement the software system.

3. Object-oriented programming (OOP) is the process of writing code to implement the software system designed in the OOD phase. OOP involves writing the code for the classes, methods, and data structures that were designed in the OOD phase.

4. Combining all three models into one cohesive system is essential to the success of any object-oriented system design. All three models must be considered when designing the system, and all three must be implemented correctly in order for the system to work properly.
