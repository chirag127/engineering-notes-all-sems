
### Unit 7 - Inheritance in Object Oriented System Design

1. Inheritance is a key concept in object-oriented programming that allows a class to inherit the properties and methods of another class.

2. The class that is inherited from is known as the parent class, or superclass, while the class that inherits is known as the child class, or subclass.

3. Inheritance allows for code reusability, as the child class can use the methods and properties of the parent class without having to rewrite them.

4. Inheritance also allows for polymorphism, which is the ability of an object to take on multiple forms.

5. The most common type of inheritance is single inheritance, which involves a single parent class and a single child class.

6. Multiple inheritance is also possible, which involves a single child class inheriting from multiple parent classes. This can be useful when dealing with complex data structures.

7. Inheritance also allows for abstraction, which is the process of hiding the implementation details of a class from the user.

8. Finally, inheritance also allows for encapsulation, which is the process of hiding the data and methods of a class from the user.
