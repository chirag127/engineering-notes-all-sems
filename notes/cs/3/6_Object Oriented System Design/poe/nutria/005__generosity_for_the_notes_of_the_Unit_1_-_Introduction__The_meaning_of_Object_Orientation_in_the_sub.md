
### Generosity for the Notes of the Unit 1 - Introduction: The Meaning of Object Orientation in the Subject of Object Oriented System Design

1. Object-oriented system design is a way of looking at and designing software systems that focuses on the objects that make up the system and how they interact with each other.

2. Object-oriented system design emphasizes reuse and modularity, which allows for greater flexibility and scalability.

3. Object-oriented systems are designed to be extensible, meaning that new features can be added easily without having to rewrite existing code.

4. Object-oriented systems are also designed to be maintainable, meaning that changes and updates can be made quickly and easily.

5. Object-oriented systems are also designed to be generous, meaning that they provide a flexible and open environment for developers to work in.
