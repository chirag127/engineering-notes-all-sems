
### Information Hiding for the Notes of the Unit 1 - Introduction: The Meaning of Object Orientation in the Subject of Object Oriented System Design

1. Object-oriented system design is a methodology used to create software applications. It relies on the principles of object-oriented programming (OOP) to create applications that are easy to understand, maintain, and extend.

2. Object-oriented system design focuses on the structure and behavior of objects. It emphasizes the use of objects to represent real-world entities and their relationships.

3. Object-oriented system design is based on the concept of information hiding. Information hiding is a technique used to ensure that the internal workings of an object are hidden from the outside world. This allows objects to be modified without impacting other parts of the system.

4. Object-oriented system design also emphasizes the use of abstraction. Abstraction is the process of hiding the details of an object’s implementation in order to focus on the object’s behavior.

5. Object-oriented system design also emphasizes the use of encapsulation. Encapsulation is the process of bundling data and behavior into a single unit. This allows objects to be reused and modified without impacting other parts of the system.

6. Object-oriented system design also emphasizes the use of inheritance. Inheritance is the process of creating a new class from an existing class. This allows objects to be reused and modified without impacting other parts of the system.

7. Object-oriented system design also emphasizes the use of polymorphism. Polymorphism is the process of creating objects that can be used in different contexts. This allows objects to be reused and modified without impacting other parts of the system.
