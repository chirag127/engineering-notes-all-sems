
### Asynchronous Messages with/without Priority

1. Asynchronous messages are messages that are sent and received independently from the main program flow.
2. They are typically used when a response from another process is not required immediately, or when a process needs to be run in the background.
3. Asynchronous messages can be sent with or without priority.
4. Messages with priority will be processed first, while messages without priority will be processed at a later time.
5. Asynchronous messages are used in object-oriented system design to allow for communication between different components of the system.
6. This communication can be used to trigger events, send data, or update the system state.
7. Asynchronous messages can also be used to create an architecture that is more resilient to failure, as the system can continue to operate even if one component is not responding.
