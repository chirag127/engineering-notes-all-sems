
### Object Oriented Design 

* Object Oriented Design is a software development methodology that focuses on creating software by combining objects. 
* Objects are self-contained units of code that contain both data and behaviors. 
* Object Oriented Design focuses on the relationships between objects and how they interact with each other. 
* Object Oriented Design encourages code reuse and modularity, which makes it easier to maintain and modify code. 
* Object Oriented Design is often used in the development of graphical user interfaces (GUI) and web applications. 
* Object Oriented Design is also used in the development of databases and distributed systems.
