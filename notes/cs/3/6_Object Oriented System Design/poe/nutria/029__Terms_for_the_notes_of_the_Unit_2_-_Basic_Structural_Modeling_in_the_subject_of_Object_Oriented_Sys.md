
### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. **Object-Oriented Design (OOD):** A software design methodology based on breaking a problem down into smaller, self-contained objects that interact with each other.

2. **Class:** A blueprint for an object. It defines the data and behavior of an object, and all objects created from the same class share the same properties.

3. **Encapsulation:** The process of hiding the inner workings of an object from the outside world.

4. **Inheritance:** A form of code reuse in which a child class inherits the behavior and properties of its parent class.

5. **Polymorphism:** The ability of an object to take on different forms depending on the context.

6. **Abstraction:** The process of hiding the details of an object and only exposing the essential features.

7. **Interface:** A set of methods and properties that an object must implement in order to be considered a member of a certain class.
