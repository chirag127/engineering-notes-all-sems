
### Associations Encapsulation

1. An association is a relationship between two classes in an object-oriented system. It is an important concept in object-oriented design and is used to represent the relationship between objects in a system.

2. Encapsulation is the process of hiding data and behavior within an object. It is an important concept in object-oriented programming and is used to protect an object's data from being accessed and modified by external sources.

3. An association can be either unidirectional or bidirectional. In a unidirectional association, one object has a reference to the other object, while in a bidirectional association, both objects have a reference to each other.

4. Associations can be one-to-one, one-to-many, or many-to-many. In a one-to-one association, one object is related to one other object. In a one-to-many association, one object is related to many other objects. In a many-to-many association, many objects are related to many other objects.

5. Encapsulation can be used to restrict access to certain data and behavior within an object. It is an important concept in object-oriented design and is used to protect an object's data from being accessed and modified by external sources.
