
### Control Structures for Unit 4 - C++ Basics

* Control structures are used to control the flow of execution in a program. They are used to execute a set of instructions based on certain conditions or to repeat a set of instructions until a certain condition is met. 
* The most common control structures in C++ are: 
  * **if-else**: This statement is used to execute a set of instructions if a certain condition is met, and a different set of instructions if the condition is not met. 
  * **switch**: This statement is used to execute a set of instructions based on the value of a variable. 
  * **for loop**: This statement is used to execute a set of instructions a specified number of times. 
  * **while loop**: This statement is used to execute a set of instructions until a certain condition is met. 
  * **do-while loop**: This statement is similar to the while loop, but it executes the set of instructions at least once.
