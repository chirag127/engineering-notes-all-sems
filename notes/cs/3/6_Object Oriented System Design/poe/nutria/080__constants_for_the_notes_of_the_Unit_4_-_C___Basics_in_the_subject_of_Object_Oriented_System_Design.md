
### Constants for Unit 4 - C++ Basics in Object Oriented System Design

* Constants are values that remain unchanged throughout the program and are declared with the `const` keyword.
* Constants can be of any data type such as `int`, `float`, `char`, `bool`, `double`, `string`, etc.
* Constants must be initialized at the time of declaration.
* Constants are also known as literals.
* Constants are stored in the memory at compile time and can be used to represent fixed values or strings.
* Constants are generally used to define values that will not change throughout the program, such as PI or the speed of light.
* Constants should be declared in capital letters to make them easily recognizable.
* Constants can also be used to define symbolic constants, which are constants that are assigned a meaningful name to represent a value.
