
### Overloading of functions 

* Overloading of functions is a feature of C++ which allows the same function name to be used for different functions. 
* This can be done by providing different parameters to the function. 
* The compiler then determines which function to call based on the parameters provided. 
* This allows the same function name to be used for different purposes, making the code more readable and easier to maintain. 
* Overloading of functions can also be used to provide default parameters to a function. 
* This allows the user to call the function with fewer parameters than the function is expecting, and the compiler will fill in the missing parameters with the default values. 
* This can be useful for providing a more user-friendly interface to a function.
