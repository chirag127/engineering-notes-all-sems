
### Object Oriented Modelling

Object oriented modelling is a method of designing software systems and applications that is based on the concept of objects and their interactions. It is an important part of object oriented system design, which is the process of designing software systems that are composed of objects and their interactions.

Object oriented modelling involves the following steps:

1. Identifying objects: This involves identifying the objects that need to be modelled in the system, and the attributes and behaviors of those objects.

2. Defining relationships: This involves defining the relationships between the objects, such as how they interact with each other.

3. Defining the system: This involves defining the system as a whole, and how the objects and their relationships interact with each other.

4. Testing the model: This involves testing the model against the requirements of the system, to ensure that it meets the requirements.

Object oriented modelling is an important part of object oriented system design, as it provides a way to design systems that are more maintainable, extensible and reusable. It is also a powerful tool for understanding complex systems and designing them in a more efficient manner.
