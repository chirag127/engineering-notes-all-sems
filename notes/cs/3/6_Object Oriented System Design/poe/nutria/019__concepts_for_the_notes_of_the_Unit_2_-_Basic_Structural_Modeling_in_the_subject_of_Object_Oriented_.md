
### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Object-Oriented Design: Object-oriented design is a method for designing software systems by breaking them down into objects or “nouns” that represent real-world entities. Each object has properties and behaviors that can be manipulated and interacted with.

2. Classes: Classes are the blueprints that define the properties and behaviors of objects. Each class contains the methods and variables necessary to create an instance of an object.

3. Inheritance: Inheritance is a feature of object-oriented programming that allows classes to inherit the properties and behaviors of other classes. This allows for code reuse and reduces the complexity of code.

4. Polymorphism: Polymorphism is the ability for objects of different classes to respond to the same message or method in different ways. This allows for code to be more flexible and adaptable.

5. Abstraction: Abstraction is the process of hiding the details of an object’s implementation. This allows for code to be more maintainable and extensible.

6. Encapsulation: Encapsulation is the process of wrapping up data and methods into a single unit. This allows for objects to be more secure and easier to maintain.
