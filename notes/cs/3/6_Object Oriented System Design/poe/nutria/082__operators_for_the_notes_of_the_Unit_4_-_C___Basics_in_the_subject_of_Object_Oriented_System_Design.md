
### Operators for the Notes of Unit 4 - C++ Basics 

* Operators are symbols that tell the compiler to perform specific mathematical or logical manipulations. 
* C++ supports the following types of operators: 
    * Arithmetic Operators
    * Comparison Operators
    * Logical Operators
    * Bitwise Operators
    * Assignment Operators 
    * Miscellaneous Operators
* Arithmetic Operators are used to perform basic mathematical operations, such as addition, subtraction, multiplication, and division. 
* Comparison Operators are used to compare two values. The result of a comparison is either true or false. 
* Logical Operators are used to combine two or more conditions in an expression. The result of a logical operation is either true or false. 
* Bitwise Operators are used to manipulate individual bits in a value. 
* Assignment Operators are used to assign a value to a variable. 
* Miscellaneous Operators are used to perform various operations, such as typecasting and size of operator.
