
### Extensibility for the Notes of the Unit 3 - Object Oriented Analysis in the Subject of Object Oriented System Design

1. Extensibility is a key feature of Object Oriented Analysis (OOA) and Object Oriented System Design (OOSD). It allows for the addition of new features and functionality to existing systems, without requiring the entire system to be re-designed or re-implemented.

2. OOA and OOSD allow for the creation of extensible systems by providing a set of well-defined interfaces, which allow for the addition of new components or features in a modular way.

3. Extensibility can also be achieved by using design patterns, which allow for the reuse of existing code and components. Design patterns are used to create systems that are easier to maintain and extend.

4. In addition, extensibility can be achieved by using object-oriented programming languages, such as Java and C#, which allow for the creation of extensible classes and objects.

5. Finally, extensibility can be achieved by using frameworks, such as Spring and Hibernate, which provide a set of pre-defined components and features that can be used to create extensible systems.
