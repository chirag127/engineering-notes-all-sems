
### Class & Object Diagrams

Class diagrams and object diagrams are used to model the structure of a system.

- A class diagram is a diagram that shows the relationships between classes, objects, attributes, and operations in an object-oriented system.
- An object diagram is a diagram that shows the relationships between objects and their attributes and operations.
- Both class diagrams and object diagrams can be used to design and document a system.
- Class diagrams are used to model the static structure of a system, while object diagrams are used to model the dynamic structure of a system.
- Class diagrams can be used to model the relationships between classes, objects, attributes, and operations.
- Object diagrams can be used to model the relationships between objects and their attributes and operations.
- Class diagrams and object diagrams can be used to document existing systems or to design new systems.
