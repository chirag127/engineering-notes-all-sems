
### Adjustment of Inheritance for the Notes of the Unit 3 - Object Oriented Analysis in the Subject of Object Oriented System Design

1. Inheritance is a key concept in Object Oriented System Design. It allows for the reuse of code and the creation of more specialized classes.
2. Inheritance is when a class is derived from an existing class. The derived class inherits all the members (variables and methods) of the existing class.
3. Multiple inheritance is when a class is derived from more than one existing class. This allows for more complex relationships between classes.
4. Polymorphism is when a class is derived from an existing class and redefines some of its methods. This allows for greater flexibility when creating classes.
5. A class can also override existing methods, which allows for the implementation of different behavior depending on the class.
6. Interfaces are a way to define a set of methods that a class must implement. This allows for more flexibility when creating classes, as the interface can be used to define a class’s behavior.
7. Abstract classes are classes that cannot be instantiated, but can be used as a base class for other classes. This allows for the creation of more specialized classes.
8. Object-oriented design patterns are reusable solutions to common programming problems. They are used to create more efficient and maintainable code.
