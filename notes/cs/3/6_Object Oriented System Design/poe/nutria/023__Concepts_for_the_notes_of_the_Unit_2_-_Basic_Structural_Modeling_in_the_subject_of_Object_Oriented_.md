
### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Object-oriented design: This is a process of designing computer programs and systems using objects as the basic building blocks. It is a way of thinking about problems and solutions that allows for flexibility and scalability.

2. Abstraction: This is the process of taking out the details that are not necessary for the problem at hand. It allows for the creation of simpler models and code that are easier to understand and maintain.

3. Encapsulation: This is the process of hiding the details of an object's implementation. This allows for the object to be used without needing to know how it works internally.

4. Inheritance: This is the process of creating objects that are related to each other and can share common properties and behavior. This allows for the reuse of code and the creation of more complex models.

5. Polymorphism: This is the process of allowing objects to behave differently depending on the context. This allows for the creation of more flexible and extensible code.
