
### Object-Oriented Language Features

* Object-oriented languages allow for the creation of objects that contain data and methods that act on that data. 
* Objects can be used to model real-world entities, such as people, animals, buildings, and cars.
* Objects can also be used to represent abstract concepts, such as numbers, text, and images.
* Classes are used to define the structure of objects, including their data and methods.
* Inheritance is a mechanism that allows classes to inherit properties and methods from parent classes.
* Polymorphism allows objects to behave differently based on the context in which they are used.
* Encapsulation is the process of hiding data and methods within an object, making them inaccessible to other objects.
* Abstraction is the process of simplifying a complex system by hiding unnecessary details.
