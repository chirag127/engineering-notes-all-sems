
### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

- **Object-oriented design:** A design approach that focuses on the structure of a system and uses objects and classes to represent the system's components and relationships.

- **Class:** A template that defines the attributes and behavior of an object.

- **Object:** An instance of a class that has its own state and behavior.

- **Inheritance:** A mechanism in object-oriented design that allows classes to inherit the attributes and behavior of parent classes.

- **Encapsulation:** A mechanism in object-oriented design that allows for the hiding of class implementation details.

- **Polymorphism:** A mechanism in object-oriented design that allows for the use of the same interface for different objects.

- **Abstraction:** A mechanism in object-oriented design that allows for the hiding of unnecessary details and the focusing on the essential features of a system.
