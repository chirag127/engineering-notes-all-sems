
### Classes for the Notes of the Unit 2 - Basic Structural Modeling in the Subject of Object Oriented System Design

1. Classes are the fundamental building blocks of object-oriented programming. They are the templates for creating objects, which are the basic components of an object-oriented system.

2. A class is a collection of related variables and methods that define the behavior of an object. Variables are the data that an object holds, and methods are the functions that act on an object's data.

3. Classes are organized into a hierarchical structure, where a class can be composed of other classes. This allows for the reuse of code and the creation of new classes with minimal effort.

4. Classes can also contain other types of objects, such as collections, which are used to store and manage data.

5. Classes can also contain properties, which are special variables that contain values that are used to control an object's behavior.

6. Classes can also contain events, which are special functions that are triggered when certain conditions are met. This allows for the creation of interactive objects.

7. Classes can also contain methods, which are functions that act on an object's data. Methods can be used to manipulate an object's data, as well as to perform calculations and other operations.

8. Classes can also contain constants, which are values that are used to define the behavior of an object. Constants are used to ensure that an object's behavior is consistent across different instances of the same class.
