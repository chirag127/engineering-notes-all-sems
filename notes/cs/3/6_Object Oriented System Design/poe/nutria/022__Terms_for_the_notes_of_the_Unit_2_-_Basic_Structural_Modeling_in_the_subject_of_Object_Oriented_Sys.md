
### Terms for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

1. Object-oriented design: A design methodology that uses objects as the basis for system architecture.
2. Encapsulation: The process of hiding the internal details of an object from the outside world.
3. Abstraction: The process of simplifying an object by focusing on its essential characteristics.
4. Inheritance: The ability of an object to inherit the properties and methods of another object.
5. Polymorphism: The ability of an object to take on multiple forms.
6. Classes: A blueprint for creating objects with the same characteristics.
7. Interfaces: A set of methods that an object must implement in order to be used in a certain context.
8. Association: An object-oriented relationship between two or more classes.
9. Aggregation: A relationship between two or more classes where one class is composed of the other.
10. Composition: A special type of aggregation where one class is composed of the other and the lifetime of the composed class is dependent on the lifetime of the composing class.
