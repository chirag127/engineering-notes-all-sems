
### Object Oriented Programming Style for Unit 3 - Object Oriented Analysis

1. Object Oriented Programming (OOP) is a programming style that uses objects to create and manipulate data. 
2. It is based on the concept of objects, which are data structures that contain data, as well as methods to manipulate the data. 
3. OOP is a powerful tool for creating complex systems and applications, as it allows for the reuse of code and the abstraction of data. 
4. OOP is based on the principles of encapsulation, inheritance, and polymorphism. 
5. Encapsulation is the process of hiding the implementation details of an object from the user. 
6. Inheritance is the process of creating new classes from existing classes. 
7. Polymorphism is the ability to define multiple implementations of a method for different classes. 
8. OOP is used in many programming languages, including Java, C++, and Python.
