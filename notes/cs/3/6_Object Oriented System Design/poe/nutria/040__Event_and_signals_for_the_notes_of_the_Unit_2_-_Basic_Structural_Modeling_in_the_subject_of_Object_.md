
### Event and Signals for Unit 2 - Basic Structural Modeling

* Event: An event is a notification that something has occurred. It is an asynchronous signal between objects. Events can be triggered by user input, system events, or other occurrences. 
* Signals: Signals are messages sent between objects to indicate that a particular event has occurred. Signals can be sent in response to user input, system events, or other occurrences. Signals are typically sent using a message-passing system. 
* Structural Modeling: Structural modeling is the process of creating a model of the relationships between objects. Structural models can be used to represent the structure of an application or system, and can also be used to represent the relationships between objects within an application or system. 
* Object Oriented System Design: Object oriented system design is the process of designing systems that are composed of objects and their interactions. Object oriented system design involves the use of object-oriented programming languages, such as Java and C++, to create systems that are modular, extensible, and reusable.
