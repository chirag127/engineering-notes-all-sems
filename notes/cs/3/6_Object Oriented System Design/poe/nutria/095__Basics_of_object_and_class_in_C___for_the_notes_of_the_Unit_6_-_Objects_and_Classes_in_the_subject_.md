
### Basics of Object and Class in C++

* Objects are the basic building blocks of object-oriented programming. They are self-contained entities that contain both data and behavior.
* Classes are the templates that define the structure of an object. They provide a blueprint for the objects that are created from them.
* In C++, classes are declared using the keyword `class`, followed by the name of the class.
* The data and behavior of the class are declared inside the class definition.
* Objects are created from classes using the keyword `new`.
* An object is an instance of a class, and each instance can have different values for its data members.
* Classes can contain member functions, which are functions that are part of the class and can access the data of the class.
* Classes can also contain static member functions, which are functions that can be accessed without creating an instance of the class.
* Classes can also contain static data members, which are variables that are shared between all instances of the class.
* Classes can also contain nested classes, which are classes declared inside another class.
* Classes can also contain constructors, which are special functions that are called when an object is created.
* Classes can also contain destructors, which are special functions that are called when an object is destroyed.
