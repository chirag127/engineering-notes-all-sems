
### Documenting design considerations for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

- Object-oriented analysis (OOA) is the process of analyzing a system to identify objects and how they interact with each other. 
- OOA is used to create a model of a system that describes the system's behavior and structure. 
- It is important to consider the data and behavior of each object, as well as its relationship to other objects in the system. 
- The goal of OOA is to identify objects and their relationships so that they can be used to create an object-oriented design. 
- OOA is also used to identify potential problems and areas of improvement in a system. 
- OOA is a useful tool for software engineers, as it allows them to create an efficient and maintainable design.
