### Program structure for the notes of the Unit 4 - C++ Basics in the subject of Object Oriented System Design

Program structure refers to the organization and arrangement of code in a software program. In C++, program structure is defined by the use of functions, statements, and control structures.

The following are some of the key concepts related to program structure in C++:

1. Functions: Functions are blocks of code that perform a specific task, and they can be called from other parts of the program.

2. Statements: Statements are the basic building blocks of a C++ program, and they are used to perform actions or to make decisions.

3. Control Structures: Control structures are used to control the flow of a program, and they include if-else statements, loops, and switch statements.

4. Variables: Variables are used to store data in a C++ program, and they can be of different data types, such as integers, floats, and strings.

In this unit, you will learn about the basic concepts of program structure in C++, and you will learn how to use functions, statements, and control structures to organize and arrange code in a C++ program. You will also learn about variables and data types, and you will learn how to use variables to store and manipulate data in a C++ program.

This unit will provide a foundation for understanding the principles and practices of C++ programming, and for exploring the various concepts and techniques used in the field of software engineering.
