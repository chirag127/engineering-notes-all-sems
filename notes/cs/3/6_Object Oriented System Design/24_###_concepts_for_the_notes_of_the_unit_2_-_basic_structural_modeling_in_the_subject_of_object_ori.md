### Concepts for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Unit 2 of the Object Oriented System Design course focuses on Basic Structural Modeling and includes the aspect of Concepts.

Concepts in the context of Object Oriented System Design refer to the abstract representations of entities and relationships within a system. Concepts are used to model the structure of a system and to represent the objects, classes, and relationships that make up the system.

There are several types of concepts that are commonly used in Object Oriented System Design, including:
- Class Concepts, which represent the objects and classes in a system and their relationships.
- Association Concepts, which represent the relationships between classes in a system.
- Inheritance Concepts, which represent the relationships between classes that share common attributes and behaviors.

In the context of the Object Oriented System Design course, students in Unit 2 will learn about Concepts as part of the discussion on Basic Structural Modeling. This may include working with examples of concepts, analyzing the benefits and limitations of different types of concepts, and learning how to use concepts to model the structure of a system.
