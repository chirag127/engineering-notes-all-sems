### virtual and pure virtual functions for the notes of the Unit 8 - Polymorphism in the subject of Object Oriented System Design

Unit 8 of the Object Oriented System Design course focuses on Polymorphism and covers the aspect of virtual and pure virtual functions.

Virtual functions in C++ are functions that can be overridden in derived classes. This allows a derived class to provide its own implementation of a virtual function, and to inherit the implementation of the virtual function from its base class.

Pure virtual functions are virtual functions that are declared with a "= 0" in their declaration. Pure virtual functions are used to declare an abstract class, which is a class that cannot be instantiated on its own, but must be subclassed by a derived class that provides an implementation for the pure virtual function.

Virtual and pure virtual functions are important concepts in polymorphism, as they allow objects of different classes to be treated as objects of a common type, and to be manipulated through a common interface.

In the context of the Object Oriented System Design course, students in Unit 8 will learn about virtual and pure virtual functions as part of the discussion on Polymorphism. This may include working with examples of virtual and pure virtual functions, analyzing the benefits and limitations of these concepts, and learning how to use virtual and pure virtual functions to implement polymorphic behavior in object-oriented systems.
