### Object oriented language features for the notes of the Unit 3 - Object Oriented Analysis in the subject of Object Oriented System Design

Object oriented language features are the features and constructs provided by object oriented programming languages, and they are used to represent the structure, behavior, and relationships of objects in a software system.

The following are some of the key concepts related to object oriented language features:

1. Classes: Classes are the basic building blocks of object oriented programming languages, and they define the structure and behavior of objects in a system.

2. Objects: Objects are instances of classes, and they represent the entities in a system.

3. Inheritance: Inheritance is a mechanism used in object oriented programming languages to represent the relationships between classes and objects, and it allows classes to inherit the attributes and behavior of other classes.

4. Polymorphism: Polymorphism is a mechanism used in object oriented programming languages to represent the ability of objects to take on different forms based on their context, and it allows objects to be treated as instances of different classes based on their context.

5. Encapsulation: Encapsulation is a mechanism used in object oriented programming languages to protect the internal state of objects and to ensure that objects can only be modified in appropriate ways, and it allows objects to be treated as black boxes that can only be interacted with through their public interfaces.
