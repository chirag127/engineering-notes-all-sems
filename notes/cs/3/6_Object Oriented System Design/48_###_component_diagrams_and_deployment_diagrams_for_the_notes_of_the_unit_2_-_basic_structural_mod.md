### Component diagrams and Deployment diagrams for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Component diagrams and Deployment diagrams are two types of UML diagrams used to describe the physical and logical components of a software system. 

1. Component diagrams: Component diagrams are used to represent the components of a system, and to describe the relationships between these components. Components are the building blocks of a system, and they represent the code, libraries, and executables that make up a system.

2. Deployment diagrams: Deployment diagrams are used to represent the physical deployment of a system, and to describe the relationships between the components of a system and the hardware and software environment in which they run. Deployment diagrams show the nodes in a system, and the relationships between these nodes, and they are used to describe the physical deployment of a system.

In this unit, you will learn about component diagrams and deployment diagrams, and you will learn how to use these diagrams to describe the physical and logical components of a software system. You will also learn about the different types of components that can be used in component diagrams, and you will learn how to choose the appropriate type of component for a specific task.

This unit will provide a foundation for understanding the principles and practices of component diagrams and deployment diagrams in Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
