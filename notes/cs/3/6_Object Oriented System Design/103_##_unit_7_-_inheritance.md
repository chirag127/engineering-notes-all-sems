## Unit 7 - Inheritance

Unit 7 of the Object Oriented System Design course focuses on Inheritance.

Inheritance is a fundamental concept in object-oriented programming that allows a new class to be defined based on an existing class. The new class, called the derived class, inherits the properties and behaviors of the existing class, called the base class.

Inheritance provides a way to reuse existing code and to create new classes that are extensions of existing classes. This allows the programmer to create a hierarchy of classes, where each derived class inherits the properties and behaviors of its base class, and can add new properties and behaviors as needed.

In the context of the Object Oriented System Design course, students in Unit 7 will learn about Inheritance as part of the discussion on object-oriented programming. This may include working with examples of Inheritance, analyzing the benefits and limitations of Inheritance, and learning how to use Inheritance to create and extend classes in object-oriented programs.

Inheritance is a fundamental concept in object-oriented programming that allows a new class to be defined based on an existing class, and provides a way to reuse existing code and to create new classes that are extensions of existing classes.
