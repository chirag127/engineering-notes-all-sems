### Use cases for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Use cases are a key concept in Object Oriented System Design, and they are used to describe the interactions between a system and its users. Use cases are used to capture the requirements of a system, and to describe the different scenarios in which the system will be used.

The following are some of the key concepts related to use cases:

1. Actors: Actors are the entities that interact with a system, and they represent the users of the system.

2. Use Case Scenarios: Use case scenarios are the sequences of interactions between actors and a system, and they represent the different ways in which the system will be used.

3. Use Case Diagrams: Use case diagrams are used to represent the relationships between actors and use cases, and they are used to describe the interactions between actors and the system.

4. Use Case Descriptions: Use case descriptions are detailed descriptions of the interactions between actors and a system, and they are used to capture the requirements of the system.

In this unit, you will learn about the basic concepts of use cases, and you will learn how to use use cases to capture the requirements of a system. You will also learn about the different types of use case diagrams, and you will learn how to choose the appropriate type of use case diagram for a specific task.
