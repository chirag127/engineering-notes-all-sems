### Macro Vs. Inline functions for the notes of the Unit 5 - C++ Functions in the subject of Object Oriented System Design

Macro and inline functions are two mechanisms used in C++ to improve the performance of a program. Both mechanisms are used to replace function calls with the actual code of the function, but they differ in how this is done and the benefits and limitations of each mechanism.

The following are some of the key differences between macro and inline functions:

1. Definition: A macro is defined using the #define directive, while an inline function is defined using the inline keyword.

2. Code Expansion: Macros are expanded by the preprocessor, while inline functions are expanded by the compiler.

3. Type Checking: Macros do not perform type checking, while inline functions perform type checking.

4. Debugging: Macros are difficult to debug, while inline functions are easier to debug.

5. Overhead: Macros have a smaller overhead than inline functions, but they can cause code bloat.
