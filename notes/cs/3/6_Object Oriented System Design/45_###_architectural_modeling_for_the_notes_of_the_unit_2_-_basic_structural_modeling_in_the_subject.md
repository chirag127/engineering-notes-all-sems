### Architectural Modeling for the notes of the Unit 2 - Basic Structural Modeling in the subject of Object Oriented System Design

Architectural modeling is a process used in Object Oriented System Design to describe the high-level structure of a software system. Architectural modeling is used to capture the overall design of a system, and to describe the relationships between the different components of the system.

The following are some of the key concepts related to architectural modeling:

1. Components: Components are the basic building blocks of a software system, and they represent the different parts of the system.

2. Connectors: Connectors are the relationships between components, and they represent the way components interact with each other.

3. Interfaces: Interfaces are the points of interaction between components, and they represent the way components communicate with each other.

4. Architecture Description Languages (ADLs): ADLs are languages used to describe the architecture of a software system, and they provide a standard way to represent the structure and behavior of a system.

In this unit, you will learn about the basic concepts of architectural modeling, and you will learn how to use architectural modeling to describe the high-level structure of a software system. You will also learn about the different types of ADLs, and you will learn how to choose the appropriate ADL for a specific task.

This unit will provide a foundation for understanding the principles and practices of Object Oriented System Design, and for exploring the various concepts and techniques used in the field of software engineering.
