### polymorphism for the notes of the Unit 1 - Introduction: The meaning of Object Orientation in the subject of Object Oriented System Design

Polymorphism is a fundamental concept in object-oriented programming and it refers to the ability of objects of different classes to respond to the same method call in different ways. This enables objects to be treated as objects of their base class, and to be used interchangeably in a program.

The following are some of the key concepts related to polymorphism:

1. Overloading: Overloading is a form of polymorphism that allows methods with the same name to be defined in different ways, based on the number or type of arguments.

2. Overriding: Overriding is a form of polymorphism that allows methods to be redefined in a subclass, in order to change the behavior of the method.

3. Dynamic Dispatch: Dynamic dispatch is the process of determining which method to call at runtime, based on the type of the object.

4. Abstract Methods: Abstract methods are methods that are declared but not defined in a base class, and that must be overridden in a subclass.

In this unit, you will learn about the different forms of polymorphism, and you will learn how to implement polymorphism in a program. You will also learn about the advantages and disadvantages of polymorphism, and you will learn how to choose the appropriate form of polymorphism for a specific task.

This unit will provide a foundation for understanding the principles and practices of polymorphism in object-oriented programming, and for exploring the various concepts and techniques used in the field of object-oriented system design.
