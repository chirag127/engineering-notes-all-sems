### Pointes and Objects for the notes of the Unit 8 - Polymorphism in the subject of Object Oriented System Design

Pointers and objects are two important concepts in C++ programming, and they are used to manipulate objects and classes in a software system. Pointers are variables that store the memory addresses of objects, while objects are instances of classes that represent the entities in a software system.

The following are some of the key concepts related to pointers and objects in C++:

1. Pointers: Pointers are variables that store the memory addresses of objects, and they are used to manipulate objects and classes in a software system.

2. Object Creation: Objects are created in C++ using the class constructor, which is a special function that is called when an object is created.

3. Dynamic Allocation: Dynamic allocation is the process of allocating memory for objects at runtime, and it is performed using the "new" operator.

4. Object Deletion: Objects are deleted in C++ using the "delete" operator, which is used to free up memory that was dynamically allocated for an object.

5. Pointer to Object: Pointers to objects are pointers that store the memory addresses of objects, and they are used to manipulate objects in a software system.

You will also learn about dynamic allocation and object deletion, and you will learn how to use these concepts to manage the memory associated with objects in a software system.

This unit will provide a foundation for understanding the principles and practices of pointers and objects in C++, and for exploring the various concepts and techniques used in the field of software engineering.
