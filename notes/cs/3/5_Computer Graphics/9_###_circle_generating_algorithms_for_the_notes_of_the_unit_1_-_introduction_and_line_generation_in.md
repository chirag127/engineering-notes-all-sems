### Circle generating algorithms for the notes of the Unit 1 - Introduction and Line Generation in the subject of Computer Graphics

Circle generation algorithms are mathematical procedures used to generate the pixels that make up an image of a circle on a computer screen. In computer graphics, circles are often used to represent objects, such as buttons, or to create graphical elements, such as pie charts.

There are several algorithms for generating circles, including:

1. Midpoint Circle Algorithm: A widely used algorithm that generates a circle by determining the midpoint of the circle and using this midpoint to calculate the pixels that make up the circle.

2. Bresenham's Circle Algorithm: A fast and efficient algorithm that generates a circle by using integer arithmetic and decision variables to determine the pixels that make up the circle.

3. Polar Coordinate Algorithm: An algorithm that generates a circle by using polar coordinates to determine the pixels that make up the circle.
