### Mid-point circle generating algorithm for the notes of the Unit 1 - Introduction and Line Generation in the subject of Computer Graphics

The Mid-point Circle Generating Algorithm is a popular algorithm for generating the pixels that make up a circle on a computer screen. The algorithm is based on the midpoint of a circle, which is defined as the point halfway between the center and the circumference of the circle.

The Mid-point Circle Generating Algorithm works by starting at the midpoint of a circle, and then moving in a clockwise direction to generate the pixels that make up the circumference of the circle. At each step, the algorithm calculates the next pixel by determining the midpoint between the current pixel and the next pixel, and then rounding the result to the nearest integer.

The algorithm continues this process until all the pixels that make up the circumference of the circle have been generated. The algorithm can be optimized by using symmetry to generate only one-eighth of the circle, and then using the symmetry of the circle to generate the remaining pixels.
