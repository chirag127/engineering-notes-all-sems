### Points and lines for the notes of the Unit 1 - Introduction and Line Generation in the subject of Computer Graphics

1. A point is the most basic element in computer graphics. It is represented by a pair of coordinates (x, y) in two-dimensional space.
2. A line is a set of points that are connected by a straight path. It is defined by two endpoints, which are points in two-dimensional space.
3. Line generation algorithms are used to draw lines on a computer screen. These algorithms determine which pixels should be turned on to create the appearance of a straight line.
4. The most common line generation algorithm is the Digital Differential Analyzer (DDA) algorithm. This algorithm uses simple arithmetic operations to calculate the coordinates of the points on a line.
5. Another popular line generation algorithm is Bresenham's line algorithm. This algorithm is more efficient than the DDA algorithm because it uses integer arithmetic instead of floating-point arithmetic.
6. Both the DDA and Bresenham's algorithms can be used to draw lines with different slopes and thicknesses.
7. In addition to straight lines, computer graphics also deals with curved lines, such as circles, ellipses, and Bezier curves. These curves are generated using more complex algorithms than those used for straight lines.
8. Understanding the basics of points and lines, and the algorithms used to generate them, is essential for anyone studying computer graphics. These concepts form the foundation for more advanced topics in the field.
