### Matrix representations and homogenous coordinates

Matrix representations are used to represent transformations in computer graphics. A transformation matrix is a square matrix that is used to perform a specific linear transformation on a vector. The most common transformations are translation, scaling, and rotation.

Homogeneous coordinates are a way of representing points in a projective space. They are used in computer graphics to represent points in three-dimensional space using four coordinates instead of three. This allows for more efficient calculations and makes it easier to represent certain transformations, such as perspective projection.

Here are some key points to remember about matrix representations and homogeneous coordinates:

1. A transformation matrix is a square matrix that is used to perform a specific linear transformation on a vector.
2. The most common transformations are translation, scaling, and rotation.
3. Homogeneous coordinates are used to represent points in three-dimensional space using four coordinates instead of three.
4. Homogeneous coordinates allow for more efficient calculations and make it easier to represent certain transformations, such as perspective projection.
5. Homogeneous coordinates are used in computer graphics to represent points in a projective space.
