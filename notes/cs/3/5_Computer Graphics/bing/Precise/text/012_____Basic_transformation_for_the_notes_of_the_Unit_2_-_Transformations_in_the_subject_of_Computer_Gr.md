### Basic Transformation

In the subject of Computer Graphics, Unit 2 - Transformations, basic transformations are fundamental operations that can be performed on objects in a two-dimensional or three-dimensional space. These transformations include:

1. **Translation**: This transformation involves moving an object from one position to another in a straight line. The movement can be in any direction along the x, y, or z-axis.

2. **Scaling**: This transformation involves changing the size of an object. The object can be made larger or smaller in any direction along the x, y, or z-axis.

3. **Rotation**: This transformation involves rotating an object around a fixed point. The rotation can be in any direction along the x, y, or z-axis.

4. **Reflection**: This transformation involves flipping an object over a line or a plane. The line or plane can be oriented in any direction along the x, y, or z-axis.

These basic transformations can be combined to create more complex transformations. They are essential for manipulating objects in computer graphics and are used in various applications such as animation, gaming, and virtual reality.
