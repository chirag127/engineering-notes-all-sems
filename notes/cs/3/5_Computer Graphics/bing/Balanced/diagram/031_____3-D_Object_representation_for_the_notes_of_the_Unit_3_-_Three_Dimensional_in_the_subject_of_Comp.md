### 3-D Object Representation

- A 3-D object is a mathematical representation of any three-dimensional shape that can be displayed on a computer screen or printed on a paper.
- A 3-D object can be created by using specialized software that allows the user to manipulate edges, vertices, and polygons in a simulated 3-D space.
- There are two main categories of 3-D object representation in computer graphics:
  - Boundary representations (B-reps) - It describes a 3-D object as a set of surfaces that separates the object interior from the environment. Examples of B-reps are polygon meshes, NURBS surfaces, and subdivision surfaces.
  - Space-partitioning representations - It is used to describe interior properties, by dividing the 3-D space into regions. Examples of space-partitioning representations are octrees, BSP trees, and voxel grids.
- Each category has its own advantages and disadvantages, depending on the application and the complexity of the object. Some of the factors that affect the choice of 3-D object representation are:
  - Memory and storage requirements
  - Rendering speed and quality
  - Editing and manipulation capabilities
  - Geometric accuracy and precision
  - Topological consistency and robustness
  - Interoperability and compatibility with other formats and software
