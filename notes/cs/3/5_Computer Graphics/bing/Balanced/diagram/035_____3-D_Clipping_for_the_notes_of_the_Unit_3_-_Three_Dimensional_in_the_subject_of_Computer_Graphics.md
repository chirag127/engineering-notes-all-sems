### 3-D Clipping

- 3-D clipping is the process of removing objects or parts of objects that are outside the viewing volume or the region of interest in a 3-D scene.
- The purpose of 3-D clipping is to reduce the computational effort and improve the rendering performance by discarding invisible or irrelevant objects.
- 3-D clipping can be done in two basic steps:
  - Discard objects that cannot be viewed, such as objects that are behind the camera, outside the field of view, or too far away. This can be done by comparing the object's bounding box or sphere against the dimensions of the viewing volume, either before or after projection.
  - Clip objects that intersect with any clipping plane, such as the near and far planes, or the left, right, top and bottom planes of the viewing volume. This can be done by using outcodes, which are binary codes that indicate the position of a point relative to each clipping plane. For example, a point can have an outcode of 001001, which means it is inside the left, right, and top planes, but outside the near, bottom, and far planes. Outcodes can be used to perform trivial accept or reject tests, or to compute the intersection points between a line segment and a clipping plane.
- 3-D clipping can be performed in different coordinate systems, such as object space, world space, eye space, clip space, or normalized device coordinates (NDC) space. The choice of the coordinate system depends on the type of projection (parallel or perspective) and the clipping algorithm used. Some common 3-D clipping algorithms are:
  - Cohen-Sutherland algorithm: This algorithm uses outcodes to clip line segments against a rectangular parallel projection viewing volume. It performs trivial accept or reject tests based on the bitwise OR and AND operations on the outcodes of the endpoints of the line segment. If the line segment is not trivially accepted or rejected, it computes the intersection point with the nearest clipping plane using a parametric equation of the line segment, and updates the outcode and the endpoint accordingly. The algorithm repeats until the line segment is either accepted or rejected.
  - Liang-Barsky algorithm: This algorithm is an improvement of the Cohen-Sutherland algorithm that reduces the number of intersection calculations by using a parametric form of the clipping window and the line segment. It computes four parameters, p, q, r, and s, that represent the direction and position of the line segment relative to the clipping window. It then finds the maximum and minimum values of the parameter t that satisfy the clipping conditions, and clips the line segment accordingly.
  - Sutherland-Hodgman algorithm: This algorithm clips a polygon against a convex clipping window by processing each edge of the clipping window in turn. It takes the vertices of the polygon as input and outputs a new polygon that is inside the current clipping edge. It classifies each vertex as either inside or outside the clipping edge, and generates a new vertex at the intersection point if the edge between two consecutive vertices crosses the clipping edge. The algorithm repeats until all the edges of the clipping window are processed.
  - Weiler-Atherton algorithm: This algorithm is an extension of the Sutherland-Hodgman algorithm that can handle concave clipping windows and polygons. It uses a data structure called a vertex list to store the vertices of the polygon and the clipping window, and marks them as either entry or exit points based on their orientation. It then traverses the vertex list in a cyclic manner, and outputs a clipped polygon whenever it encounters an entry point. The algorithm handles multiple clipped polygons and holes by using a stack to keep track of the active polygons.
