### Viewing transformations for the notes of the Unit 2 - Transformations in the subject of Computer Graphics

Unit 2 of the Computer Graphics course focuses on the topic of Transformations, including the aspect of Viewing Transformations.

Viewing Transformations are a set of mathematical operations used to transform a 3D scene into a 2D image that can be displayed on a computer screen. These transformations are used to control the position, orientation, and perspective of the camera in a 3D scene, and to determine what parts of the scene are visible in the final image.

There are several types of Viewing Transformations, including:
- Translation, which is used to move an object in a 3D scene along a specific axis.
- Scaling, which is used to change the size of an object in a 3D scene.
- Rotation, which is used to rotate an object in a 3D scene around a specific axis.
- Projection, which is used to project a 3D scene onto a 2D plane, such as a computer screen.

In the context of the Computer Graphics course, students in Unit 2 will learn about Viewing Transformations as part of the discussion on Transformations. This may include working with examples of each type of Viewing Transformation, analyzing the benefits and limitations of each transformation, and learning how to implement Viewing Transformations in a computer graphics program.
