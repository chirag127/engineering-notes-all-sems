## Unit 1 - Introduction and Line Generation

In this unit, we will introduce the fundamental concepts of computer graphics and focus on line generation algorithms. The following points will be covered in this unit:

1. Definition of computer graphics: Computer graphics is a field of study that deals with the creation, manipulation, and representation of visual data using computers.

2. Applications of computer graphics: Computer graphics have a wide range of applications in various fields such as entertainment, advertising, education, medicine, and many more.

3. Graphics systems: Graphics systems are the software and hardware components that are used to create, manipulate, and display graphics.

4. Raster and Vector graphics: Raster and Vector graphics are two types of graphics used in computer graphics. Raster graphics are made up of pixels, whereas vector graphics are made up of mathematical equations.

5. Line generation algorithms: Line generation algorithms are used to generate lines on a display device. Some of the commonly used line generation algorithms are DDA (Digital Differential Analyzer) algorithm, Bresenham's algorithm, and Mid-Point Line Algorithm.

6. DDA Algorithm: DDA algorithm is a simple and easy-to-understand algorithm used to generate lines on a display device. It uses the concept of slope and uses incremental or decremental calculations to generate a line.

7. Bresenham's Algorithm: Bresenham's algorithm is a more efficient algorithm than DDA algorithm, as it uses only integer calculations and avoids floating-point arithmetic. It generates straight lines with a high degree of accuracy.

8. Mid-point Line Algorithm: Mid-point Line Algorithm is another efficient algorithm used to generate lines. It uses the concept of midpoint and avoids the use of division and multiplication, making it faster than Bresenham's algorithm.

9. Advantages and disadvantages of line generation algorithms: Each line generation algorithm has its own advantages and disadvantages. For example, DDA algorithm is easy to understand but not very efficient, whereas Bresenham's algorithm is more efficient but complex to understand.

10. Practical applications of line generation algorithms: Line generation algorithms are used in various applications such as drawing tools, CAD (Computer-Aided Design) software, and computer games.

In conclusion, this unit provides a comprehensive introduction to computer graphics and line generation algorithms. It provides a foundation for further study in computer graphics and its applications.
