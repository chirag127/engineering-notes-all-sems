### Graphic Displays for the notes of the Unit 1 - Introduction and Line Generation in the subject of Computer Graphics

Graphic displays are the visual representation of data or information, and they are used to communicate information in a clear and concise manner. There are several types of graphic displays, including:

1. Bar Graphs: A bar graph is a type of graphic display that uses bars to represent data.

2. Line Graphs: A line graph is a type of graphic display that uses lines to represent data.

3. Pie Charts: A pie chart is a type of graphic display that uses a circle divided into sections to represent data.

4. Scatter Plots: A scatter plot is a type of graphic display that uses dots to represent data.

5. Histograms: A histogram is a type of graphic display that uses bars to represent the distribution of data.

In this unit, you will learn about the different types of graphic displays, and you will learn how to create and interpret graphic displays. You will also learn about the different types of data that can be represented using graphic displays, including categorical data and numerical data, among others.

This unit will provide a foundation for understanding the principles and practices of computer graphics, and for exploring the various concepts and techniques used in the field of computer graphics.
