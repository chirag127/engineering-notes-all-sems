### 3-D Object representation for the notes of the Unit 3 - Three Dimensional in the subject of Computer Graphics

3-D Object representation refers to the process of representing objects in 3-dimensional (3D) space on a computer screen. In computer graphics, 3D objects are represented using mathematical models, such as polyggonal meshes, and algorithms, such as transformations and shading, to create a realistic and interactive representation of the object.

There are several methods for representing 3D objects, including:

1. Wireframe Representation: A method of representing 3D objects using lines to represent the edges of the object.

2. Solid Representation: A method of representing 3D objects using shading and texture mapping to create a more realistic representation of the object.

3. Hidden Surface Removal: A method of removing the parts of a 3D object that are not visible on the screen, to create a more realistic representation of the object.

4. Shading: A method of adding depth and texture to a 3D object by simulating the way light interacts with the object.

In this unit, you will learn about the different methods for representing 3D objects, and you will learn how to implement these methods in a program. You will also learn about the advantages and disadvantages of each method, and you will learn how to choose the appropriate method for a specific task.

This unit will provide a foundation for understanding the principles and practices of 3D object representation in computer graphics, and for exploring the various concepts and techniques used in the field of computer graphics.
