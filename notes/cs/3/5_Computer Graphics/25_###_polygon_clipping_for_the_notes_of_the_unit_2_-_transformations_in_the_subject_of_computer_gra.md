### Polygon clipping for the notes of the Unit 2 - Transformations in the subject of Computer Graphics

Polygon clipping is a computer graphics technique used to determine which parts of a polygon are visible on a computer screen. The process of polygon clipping involves cutting a polygon into smaller parts so that only the visible parts are displayed on the screen.

There are several algorithms for polygon clipping, including:

1. Sutherland-Hodgman Algorithm: A widely used algorithm that uses a series of line-clipping operations to clip a polygon.

2. Weiler-Atherton Algorithm: A more complex algorithm that uses a series of set operations to clip a polygon.

In this unit, you will learn about the different algorithms for polygon clipping, and you will learn how to implement these algorithms in a program. You will also learn about the advantages and disadvantages of each algorithm, and you will learn how to choose the appropriate algorithm for a specific task.
