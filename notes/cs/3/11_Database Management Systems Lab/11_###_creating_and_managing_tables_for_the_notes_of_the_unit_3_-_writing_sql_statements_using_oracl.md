### Creating and managing tables for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

Unit 3 - Writing SQL Statements Using ORACLE/MYSQL:
- Creating and Managing Tables:
  1. CREATE TABLE statement: Used to create a new table in a database.
  2. ALTER TABLE statement: Used to modify an existing table in a database.
  3. DROP TABLE statement: Used to delete a table from a database.
  4. INSERT INTO statement: Used to add data to a table.
  5. SELECT statement: Used to retrieve data from a table.
  6. UPDATE statement: Used to modify data in a table.
  7. DELETE statement: Used to delete data from a table.

Note: Creating and managing tables is a critical component of database management systems. This unit covers the key SQL statements used to create, modify, and manage tables in ORACLE and MYSQL databases, including the CREATE TABLE, ALTER TABLE, DROP TABLE, INSERT INTO, SELECT, UPDATE, and DELETE statements.
