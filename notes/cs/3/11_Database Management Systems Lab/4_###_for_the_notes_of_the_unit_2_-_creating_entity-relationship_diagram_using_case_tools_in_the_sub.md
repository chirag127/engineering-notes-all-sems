Unit 2 - Creating Entity-Relationship Diagram using case tools:
- Entity-Relationship Diagrams (ERD): A graphical representation of entities and their relationships to each other.
- CASE (Computer-Aided Software Engineering) Tools: Software tools used to support the software development process, including the creation of ERDs.
- Steps for creating ERD using CASE tools:
  1. Identify entities and relationships between entities.
  2. Choose a CASE tool and create a new project.
  3. Create entities and relationships using the CASE tool.
  4. Review and refine the ERD as necessary.

Note: Entity-Relationship Diagrams (ERDs) are a critical component of database design and modeling. This unit covers the process of creating ERDs using Computer-Aided Software Engineering (CASE) tools. The steps include identifying entities and relationships, choosing a CASE tool, creating entities and relationships, and reviewing and refining the ERD as necessary.
