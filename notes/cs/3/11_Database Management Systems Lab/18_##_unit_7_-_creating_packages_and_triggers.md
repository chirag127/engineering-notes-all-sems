## Unit 7 - Creating packages and triggers

Unit 7 - Creating Packages and Triggers:
- Packages:
  1. Overview of packages: A collection of related procedures and functions that can be used to perform specific tasks.
  2. Creating packages: Steps for creating packages, including defining variables and procedures.
  3. Invoking packages: Steps for calling and using packages in an application.
- Triggers:
  1. Overview of triggers: A set of actions that are automatically performed in response to a specific event or change in the database.
  2. Creating triggers: Steps for creating triggers, including defining the trigger event and the actions to be performed.
  3. Triggers in action: Understanding how triggers work and how they can be used to automate tasks and enforce constraints in a database.

Note: Packages and triggers are advanced features in database management systems that can be used to automate tasks and enforce constraints. This unit covers the key concepts and techniques for creating and using packages and triggers, including creating packages, invoking packages, creating triggers, and understanding how triggers work.
