### Manipulating data for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

Unit 3 - Writing SQL Statements Using ORACLE/MYSQL:
- Manipulating Data:
  1. INSERT: Statement for adding new data to a table.
  2. UPDATE: Statement for modifying existing data in a table.
  3. DELETE: Statement for removing data from a table.
  4. SELECT: Statement for retrieving data from a table.
  5. JOIN: Statement for combining data from multiple tables.

Note: Manipulating data is a critical aspect of database management. This unit covers the key SQL statements for manipulating data in ORACLE/MYSQL, including INSERT, UPDATE, DELETE, SELECT, and JOIN. These statements allow users to add, modify, remove, and retrieve data from tables, and to combine data from multiple tables.
