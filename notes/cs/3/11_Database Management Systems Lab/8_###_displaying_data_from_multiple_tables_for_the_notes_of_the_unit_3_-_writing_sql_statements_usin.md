### Displaying data from multiple tables for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

Unit 3 - Writing SQL Statements Using ORACLE/MYSQL:
- Displaying Data from Multiple Tables:
  1. JOIN: A clause used to combine rows from two or more tables based on a related column.
  2. INNER JOIN: Returns only the rows that have matching values in both tables.
  3. LEFT JOIN: Returns all the rows from the left table and matching rows from the right table.
  4. RIGHT JOIN: Returns all the rows from the right table and matching rows from the left table.
  5. FULL OUTER JOIN: Returns all the rows from both tables, with NULL values for non-matching rows.

Note: Displaying data from multiple tables is a common task in database management. This unit covers the key concepts and techniques for displaying data from multiple tables, including the different types of joins (INNER JOIN, LEFT JOIN, RIGHT JOIN, and FULL OUTER JOIN) and how to use them to combine data from multiple tables.
