### Manipulating data for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

In this unit, we will learn how to manipulate data using SQL statements in ORACLE / MYSQL. Here are some important points to keep in mind:

- SQL stands for Structured Query Language, which is used to communicate with relational databases.
- The SELECT statement is used to retrieve data from one or more tables in a database.
- The WHERE clause is used to filter data based on specific conditions.
- The ORDER BY clause is used to sort data in ascending or descending order.
- The INSERT statement is used to insert new data into a table.
- The UPDATE statement is used to modify existing data in a table.
- The DELETE statement is used to delete data from a table.
- The JOIN clause is used to combine data from two or more tables based on a related column.
- The GROUP BY clause is used to group data based on a specific column.
- The HAVING clause is used to filter grouped data based on specific conditions.

When manipulating data using SQL statements, it is important to understand the structure of your database and the relationships between tables. This will help you write more efficient and effective SQL statements.

Additionally, it is important to always test your SQL statements before executing them on a production database. This can be done using a test database or by creating a backup of your production database.

Overall, mastering the art of manipulating data using SQL statements is an essential skill for anyone working with databases. With practice and patience, you can become proficient in using SQL to retrieve, modify, and analyze data in your database.
