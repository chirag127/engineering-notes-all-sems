### Creating and managing tables for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

In this unit, you will learn how to create and manage tables using SQL statements in ORACLE/MYSQL. Here are some important points to keep in mind:

- A table is a collection of related data stored in rows and columns.
- To create a table, you need to use the CREATE TABLE statement followed by the table name and the column definitions.
- Each column in a table has a name, data type, and optional constraints such as NOT NULL, UNIQUE, and PRIMARY KEY.
- The PRIMARY KEY constraint is used to define a unique identifier for each row in the table.
- You can also define foreign key constraints to enforce referential integrity between related tables.
- To insert data into a table, you need to use the INSERT INTO statement followed by the table name and the values to be inserted.
- To update data in a table, you need to use the UPDATE statement followed by the table name, the column to be updated, and the new value.
- To delete data from a table, you need to use the DELETE statement followed by the table name and the condition that specifies which rows to delete.
- To alter the structure of a table, you can use the ALTER TABLE statement followed by the table name and the desired changes such as adding or dropping columns, modifying data types, and adding or dropping constraints.

In conclusion, understanding how to create and manage tables using SQL statements is essential for working with databases in ORACLE/MYSQL. Make sure to practice these concepts and apply them to real-world scenarios to become proficient in database management.
