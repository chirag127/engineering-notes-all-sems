## Unit 6 - Creating Procedure and Functions

In this unit, we will discuss how to create procedures and functions in programming.

### Procedures

A procedure is a set of instructions that performs a specific task. It is a reusable code block that helps to reduce code duplication and improves code organization. Here are the key points to remember about procedures:

- A procedure is defined using the `PROCEDURE` keyword, followed by a name and a set of parameters (if any).
- The procedure body consists of a set of statements that perform a specific task.
- The `RETURN` statement is used to exit the procedure and return a value (if any).

### Functions

A function is a type of procedure that returns a value. It is a reusable code block that performs a specific task and returns a value to the caller. Here are the key points to remember about functions:

- A function is defined using the `FUNCTION` keyword, followed by a name and a set of parameters (if any).
- The function body consists of a set of statements that perform a specific task and return a value using the `RETURN` statement.
- The returned value can be of any data type, such as integer, string, or boolean.

### Differences between Procedures and Functions

There are some key differences between procedures and functions, which are:

- A function returns a value, whereas a procedure does not.
- A function is called using an expression, whereas a procedure is called using a statement.
- A function can be used in an expression, whereas a procedure cannot.
- A function can have a data type, whereas a procedure does not.

### Advantages of Procedures and Functions

There are several advantages of using procedures and functions in programming, such as:

- Reusability: Procedures and functions can be reused in different parts of the program, which reduces code duplication and improves code organization.
- Readability: Procedures and functions help to make the code more readable and easier to understand, as they break down complex tasks into smaller, more manageable tasks.
- Maintainability: Procedures and functions make it easier to maintain the code, as changes made to a procedure or function will affect all instances where it is used.

In conclusion, procedures and functions are essential building blocks of programming, which help to improve code organization, readability, and maintainability. Understanding how to create and use procedures and functions is critical to becoming a proficient programmer.
