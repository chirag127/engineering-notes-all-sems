## Unit 3 - Writing SQL Statements Using ORACLE/MYSQL

In this unit, you will learn about writing SQL statements using ORACLE/MYSQL. SQL (Structured Query Language) is a standard language used for managing data stored in a database. ORACLE and MYSQL are two popular relational database management systems that use SQL as their primary language.

### SQL Statements

SQL statements are used to retrieve, insert, update, and delete data from a database. Here are some of the most commonly used SQL statements:

- SELECT: Used to retrieve data from one or more tables.
- INSERT: Used to insert data into a table.
- UPDATE: Used to update existing data in a table.
- DELETE: Used to delete data from a table.

### ORACLE SQL

ORACLE SQL is used to write SQL statements for ORACLE databases. Here are some of the key features of ORACLE SQL:

- ORACLE SQL supports a wide range of data types, including numeric, character, date, and time data types.
- ORACLE SQL allows you to create complex queries using subqueries, joins, and unions.
- ORACLE SQL supports the use of functions for data manipulation, such as the use of aggregate functions to calculate totals and averages.
- ORACLE SQL provides a powerful set of tools for managing database security, including the ability to grant and revoke privileges.

### MYSQL SQL

MYSQL SQL is used to write SQL statements for MYSQL databases. Here are some of the key features of MYSQL SQL:

- MYSQL SQL supports a wide range of data types, including numeric, character, date, and time data types.
- MYSQL SQL allows you to create complex queries using subqueries, joins, and unions.
- MYSQL SQL supports the use of functions for data manipulation, such as the use of aggregate functions to calculate totals and averages.
- MYSQL SQL provides a powerful set of tools for managing database security, including the ability to grant and revoke privileges.

### Conclusion

In conclusion, writing SQL statements using ORACLE/MYSQL is an essential skill for anyone working with databases. It allows you to retrieve, insert, update, and delete data from a database with ease. By mastering the fundamentals of SQL statements, you will be able to manage data effectively and efficiently.
