## Unit 11 - Automatic Backup of Files and Recovery of Files

Unit 11 - Automatic Backup of Files and Recovery of Files:
- Backup: A copy of data or files that is used to restore data in the event of data loss.
- Types of backup: Full backup, incremental backup, differential backup, and mirror backup.
- Backup schedule: Determining the frequency of backups and choosing the appropriate type of backup.
- Backup software: Choosing and using software for backing up data and files.
- Recovery: The process of restoring data and files from a backup.
- Recovery software: Choosing and using software for restoring data and files.

Note: Backing up data and files and being able to recover them in the event of data loss is a critical aspect of data management. This unit covers the key concepts and techniques for backing up and recovering data and files, including the different types of backups, choosing a backup schedule, using backup software, and using recovery software.
