## Unit 4 - Normalization

Unit 4 - Normalization:
- Normalization: The process of organizing data in a database to reduce data redundancy and improve data integrity.
  1. First Normal Form (1NF): Each column in a table contains atomic values and no repeating groups.
  2. Second Normal Form (2NF): Each non-key attribute is dependent on the primary key.
  3. Third Normal Form (3NF): No transitive dependencies exist between non-key attributes.
  4. Boyce-Codd Normal Form (BCNF): Each determinant is a candidate key.
  5. Fourth Normal Form (4NF): No multi-valued dependencies exist between non-key attributes.

Note: Normalization is a critical aspect of database design and management. This unit covers the key concepts and techniques of normalization, including First Normal Form (1NF), Second Normal Form (2NF), Third Normal Form (3NF), Boyce-Codd Normal Form (BCNF), and Fourth Normal Form (4NF). These concepts and techniques help ensure that data is organized in a way that reduces data redundancy and improves data integrity.
