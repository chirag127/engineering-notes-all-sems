### Aggregating data using group function for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

Unit 3 - Writing SQL statements in ORACLE/MYSQL:
- Aggregating data using group functions:
  1. SUM: Returns the sum of values in a specified column.
  2. AVG: Returns the average of values in a specified column.
  3. MIN: Returns the minimum value in a specified column.
  4. MAX: Returns the maximum value in a specified column.
  5. COUNT: Returns the number of rows in a specified column.

Note: Group functions are used in SQL to aggregate data from multiple rows into a single result. This unit covers the key group functions, including SUM, AVG, MIN, MAX, and COUNT, and how to use them in SQL statements to analyze and summarize data from a database.
