### Restricting and sorting data for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

Unit 3 - Writing SQL Statements using ORACLE/MYSQL:
- Restricting and Sorting Data:
  1. SELECT Statement: Used to retrieve data from a database.
  2. WHERE Clause: Used to restrict the data retrieved from a database based on specific conditions.
  3. ORDER BY Clause: Used to sort the data retrieved from a database in ascending or descending order.
  4. GROUP BY Clause: Used to group data from a database based on specific criteria.
  5. HAVING Clause: Used to restrict the data retrieved from a database based on specific conditions for grouped data.

Note: Restricting and sorting data is a critical component of database management, as it allows users to retrieve and manipulate data in a meaningful and useful way. This unit covers the key SQL statements and clauses used to restrict and sort data, including the SELECT statement, WHERE clause, ORDER BY clause, GROUP BY clause, and HAVING clause.
