### Writing basic SQL SELECT statements for the notes of the Unit 3 - Writing SQL statements Using ORACLE /MYSQL in the subject of Database Management Systems Lab

Unit 3 - Writing SQL Statements Using ORACLE/MYSQL:
- Writing Basic SQL SELECT Statements:
  1. SELECT clause: Specifies the columns to be retrieved from the database.
  2. FROM clause: Specifies the table(s) from which data will be retrieved.
  3. WHERE clause: Specifies conditions for the data to be retrieved.
  4. GROUP BY clause: Groups rows based on the values in one or more columns.
  5. HAVING clause: Filters groups based on aggregate values.
  6. ORDER BY clause: Sorts the result set based on one or more columns.

Note: Writing basic SQL SELECT statements is a fundamental skill for working with databases. This unit covers the key components of a SELECT statement, including the SELECT clause, FROM clause, WHERE clause, GROUP BY clause, HAVING clause, and ORDER BY clause.
