## Unit 5 - Creating cursor

Unit 5 - Creating Cursor:
- Overview of cursors: A cursor is a database object used to retrieve data from a database.
- Types of cursors: Forward-only, scrollable, dynamic, and keyset-driven.
- Creating a cursor: Syntax for creating a cursor in a database management system, such as ORACLE or MYSQL.
- Opening a cursor: Syntax for opening a cursor and accessing data.
- Fetching data: Syntax for retrieving data from a cursor and manipulating it within a database application.
- Closing and deallocating a cursor: Syntax for closing and deallocating a cursor after it is no longer needed.

Note: Cursors are an important tool for accessing and manipulating data within a database management system. This unit covers the basics of cursors, including the different types of cursors, how to create, open, and fetch data from a cursor, and how to close and deallocate a cursor after it is no longer needed.
