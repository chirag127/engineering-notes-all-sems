
### Flow Chart of Genetic Algorithm

1. Initialize the population with a set of random solutions.
2. Evaluate the fitness of each solution in the population.
3. Repeat the following steps until the termination condition is met:
    1. Select the best-fit individuals for reproduction.
    2. Breed new solutions using crossover and mutation operations.
    3. Evaluate the new solutions and replace least-fit population members with the new ones.
4. Return the best-fit solution.
