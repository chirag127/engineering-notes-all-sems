
## Unit 4 - Fuzzy Logic –II (Fuzzy Membership, Rules)

1. Fuzzy membership is the degree of membership of an element in a fuzzy set. It is a value between 0 and 1.

2. Fuzzy sets are used to represent linguistic variables in fuzzy logic. A linguistic variable is a variable that can take on values from a natural language.

3. Fuzzy rules are used to represent the relationship between input and output variables. They are composed of fuzzy sets and fuzzy membership functions.

4. Fuzzy logic is used to approximate the behavior of a system that is too complex to be modeled accurately. It is based on the idea that a system can be approximated by a set of fuzzy rules.

5. Fuzzy logic can be used to control complex systems, such as robots and autonomous vehicles. It is also used in medical diagnosis and in decision support systems.
