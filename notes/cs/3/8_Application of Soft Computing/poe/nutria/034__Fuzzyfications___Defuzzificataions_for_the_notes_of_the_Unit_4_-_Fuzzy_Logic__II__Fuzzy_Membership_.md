
### Fuzzyfications & Defuzzificataions for the notes of the Unit 4 - Fuzzy Logic –II (Fuzzy Membership, Rules) in the subject of Application of Soft Computing

1. Fuzzification is the process of transforming crisp input data into fuzzy data. This is done by assigning a membership grade to each input value that indicates how much it belongs to a given fuzzy set.

2. Defuzzification is the process of transforming fuzzy output data into crisp output data. This is done by using a membership grade to determine the output value that best represents the fuzzy set.

3. Fuzzy membership functions are used to determine the degree of membership of a given input value to a fuzzy set. Examples of fuzzy membership functions include triangular, trapezoidal, and Gaussian functions.

4. Fuzzy rules are used to determine the output of a fuzzy system based on the input data. Fuzzy rules are composed of antecedents (inputs) and consequents (outputs).

5. Fuzzy logic is a form of many-valued logic in which the truth values of variables may be any real number between 0 and 1. It is used to handle the concept of partial truth, where the truth value may range between completely true and completely false.
