
## Unit 3 - Fuzzy Logic-I (Introduction)

* Fuzzy logic is a form of many-valued logic in which the truth values of variables may be any real number between 0 and 1. 
* It is employed to handle the concept of partial truth, where the truth value may range between completely true and completely false. 
* Fuzzy logic has been extended to handle the concept of “partial truth” in decision making. 
* It has been applied to a wide variety of fields, from control theory to artificial intelligence.
* Fuzzy logic systems use fuzzy sets, which are sets of fuzzy numbers, to represent imprecise concepts. 
* A fuzzy set is a set of elements that are related in some way, but may not have a precise boundary. 
* Fuzzy sets are used to represent imprecise concepts such as “high”, “medium”, and “low”. 
* Fuzzy logic systems use fuzzy inference to draw conclusions from fuzzy sets. 
* Fuzzy inference is the process of making decisions based on fuzzy sets. 
* Fuzzy inference is based on the idea that the truth of a statement can be determined by looking at the degree of membership of the elements in the set. 
* A fuzzy inference system is a computer program that uses fuzzy logic to make decisions. 
* Fuzzy logic systems can be used for a variety of tasks, such as pattern recognition, classification, and control.
