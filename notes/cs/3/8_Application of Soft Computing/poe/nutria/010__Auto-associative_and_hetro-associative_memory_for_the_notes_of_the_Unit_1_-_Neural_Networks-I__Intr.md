
### Auto-associative and Hetero-associative Memory

1. Auto-associative memory is a type of neural network that is used to store and recall patterns. It can store and recall patterns that are related to each other, such as a person's name and their address.

2. Hetero-associative memory is a type of neural network that is used to store and recall patterns that are unrelated. For example, it can store and recall a person's name and their favorite type of food.

3. Neural networks are used to store and recall patterns because they are able to learn from the data they are presented with. This means that they can learn to recognize patterns, and then use those patterns to store and recall information.

4. Neural networks are composed of neurons, which are connected to each other in a network. Each neuron is connected to multiple other neurons, and each connection has a weight associated with it. This weight determines how strongly the neurons are connected.

5. Neural networks are used in a variety of applications, including image recognition, speech recognition, and natural language processing. They are also used in robotics, where they can be used to control a robot's movements.

6. Neural networks are used in the field of artificial intelligence, where they are used to create intelligent systems that can learn from their environment and make decisions based on the data they are presented with.
