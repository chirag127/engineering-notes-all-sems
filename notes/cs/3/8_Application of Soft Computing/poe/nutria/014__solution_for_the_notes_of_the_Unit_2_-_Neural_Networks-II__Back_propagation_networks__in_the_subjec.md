
### Solution for the Notes of the Unit 2 - Neural Networks-II (Back propagation networks) in the Subject of Application of Soft Computing

1. Neural Networks-II (Back propagation networks) is a type of artificial neural network in which the weights of the nodes are adjusted based on the errors from the output layer.

2. It is a supervised learning technique, which means that the network is trained with labeled data in order to learn the desired output for a given input.

3. The backpropagation algorithm is used to adjust the weights of the nodes based on the errors from the output layer.

4. The backpropagation algorithm works by propagating the errors backwards through the network, adjusting the weights of the nodes accordingly.

5. The backpropagation algorithm can be used to train a neural network to recognize patterns and make predictions.

6. The backpropagation algorithm is commonly used in applications such as image recognition, speech recognition, natural language processing, and robotics.

7. The backpropagation algorithm can be used to create deep learning models that are capable of solving complex problems.
