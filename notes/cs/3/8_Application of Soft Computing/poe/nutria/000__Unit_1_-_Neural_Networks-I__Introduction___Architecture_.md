
## Unit 1 - Neural Networks-I (Introduction & Architecture)

1. Neural networks are a type of machine learning algorithm that are inspired by the structure and function of biological neural networks. 
2. In a neural network, a set of input nodes are connected to a set of output nodes by weights. 
3. The weights of the connections are adjusted to learn patterns in the data. 
4. The nodes in a neural network are organized into layers. 
5. The input layer takes in the data, and the output layer produces the result. 
6. In between the input and output layers are hidden layers, which are used to process the data. 
7. The number of hidden layers and the number of nodes in each layer can vary. 
8. The weights of the connections are adjusted using a learning algorithm, such as backpropagation. 
9. The goal of the learning algorithm is to minimize the error between the predicted output and the actual output. 
10. Neural networks can be used for a variety of tasks, including classification, regression, and clustering.
