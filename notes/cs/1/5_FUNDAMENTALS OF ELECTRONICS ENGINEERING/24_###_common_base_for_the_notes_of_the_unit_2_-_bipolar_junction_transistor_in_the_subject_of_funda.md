Common Base configuration of a bipolar junction transistor (BJT) is a type of transistor configuration where the base terminal of the transistor is a common terminal to both the input and output signals. In this configuration, the base-emitter junction is forward-biased and the base-collector junction is reverse-biased. The input signal is applied to the emitter terminal, and the output is taken from the collector terminal. The common base configuration is used as an amplifier, with the emitter current being proportional to the base current, and the collector current being proportional to the emitter current. The common base configuration has low voltage gain but high current gain, making it useful in applications such as audio amplification and power amplification.
