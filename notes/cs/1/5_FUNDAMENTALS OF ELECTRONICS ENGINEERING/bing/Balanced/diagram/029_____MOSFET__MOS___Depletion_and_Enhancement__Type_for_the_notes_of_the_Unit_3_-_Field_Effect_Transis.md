### MOSFET (MOS) (Depletion and Enhancement) Type

- MOSFET stands for Metal-Oxide-Semiconductor Field-Effect Transistor.
- It is a type of FET that uses an electric field to control the conductivity of a channel between the source and drain terminals.
- The channel is formed by a thin layer of semiconductor material (usually silicon) that is insulated from the gate terminal by a thin layer of metal oxide (usually silicon dioxide) .
- There are two major types of MOSFETs: depletion mode and enhancement mode.
- Depletion mode MOSFETs have a channel that is already present at zero gate-source voltage, and the channel conductivity can be reduced by applying a negative voltage to the gate (for n-channel) or a positive voltage to the gate (for p-channel)  .
- Enhancement mode MOSFETs have no channel at zero gate-source voltage, and the channel conductivity can be increased by applying a positive voltage to the gate (for n-channel) or a negative voltage to the gate (for p-channel)  .
- The main differences between depletion and enhancement MOSFETs are summarized in the table below:

| Depletion MOSFET | Enhancement MOSFET |
| ---------------- | ------------------ |
| The type of MOSFET where the channel depletes when a voltage is applied to the gate | The type of MOSFET where the channel enhances when a voltage is applied to the gate |
| The channel is fabricated during manufacturing | There is no channel during manufacturing |
| It conducts current between the source and drain terminals at zero gate-source voltage | It does not conduct current at zero gate-source voltage |
| Applying a reverse voltage to the gate reduces the channel width and conductivity | Applying a reverse voltage does not affect the channel |
| Applying a forward voltage to the gate increases the channel width and conductivity | Applying a forward voltage creates a channel and increases its conductivity |
| It has a lower input impedance than enhancement MOSFET | It has a higher input impedance than depletion MOSFET |
| It is less preferred for switching applications | It is more preferred for switching applications |

- Some of the applications of MOSFETs are:
  - Amplifiers: MOSFETs can be used to amplify weak signals in audio, radio, and optical devices.
  - Switches: MOSFETs can be used to switch on and off high-power devices such as motors, LEDs, and relays.
  - Logic gates: MOSFETs can be used to implement digital logic circuits such as AND, OR, NOT, NAND, NOR, etc.
  - Memory: MOSFETs can be used to store binary data in dynamic random-access memory (DRAM) and flash memory devices.
  - Sensors: MOSFETs can be used to sense physical parameters such as temperature, pressure, light, etc.
