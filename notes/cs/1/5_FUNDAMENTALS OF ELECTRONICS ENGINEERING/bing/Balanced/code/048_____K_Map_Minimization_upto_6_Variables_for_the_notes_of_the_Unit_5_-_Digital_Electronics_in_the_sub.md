### K Map Minimization upto 6 Variables

- Karnaugh map or K-map is a map of a function used in a technique used for minimization or simplification of a Boolean expression. It results in less number of logic gates and inputs to be used during the fabrication.
- A K-map consists of cells (squares) that represent the minterms of a Boolean function. Each cell is labeled with a binary code that corresponds to the values of the variables in the function. For example, a cell with the label 0110 represents the minterm A'B'CD'.
- The number of cells in a K-map depends on the number of variables in the function. For n variables, there are 2^n cells. For example, a 2-variable K-map has 4 cells, a 3-variable K-map has 8 cells, and so on.
- The cells in a K-map are arranged in such a way that adjacent cells differ by only one bit. This property is called the Gray code property. For example, in a 2-variable K-map, the cells 00 and 01 are adjacent, as they differ by only the least significant bit. Similarly, the cells 01 and 11 are adjacent, as they differ by only the most significant bit.
- The main idea of K-map minimization is to group adjacent cells that have the same output value (either 1 or 0) into larger regions called implicants. An implicant is a product term that covers one or more minterms of the function. For example, in a 2-variable K-map, the cell 00 is an implicant A'B', and the cells 00 and 01 form an implicant A'.
- The size of an implicant is determined by the number of cells it covers. The size must be a power of 2, such as 1, 2, 4, 8, etc. The larger the size, the fewer the literals in the implicant. For example, a size 1 implicant has 2 literals, a size 2 implicant has 1 literal, and a size 4 implicant has 0 literals (it is a constant 1).
- An implicant is called a prime implicant if it cannot be combined with any other implicant to form a larger implicant. A prime implicant is called an essential prime implicant if it covers at least one minterm that is not covered by any other prime implicant. The goal of K-map minimization is to find the minimum set of prime implicants that covers all the minterms of the function, and to select the essential prime implicants first.
- K-map minimization can be applied to functions with up to 6 variables, although the visualization becomes more difficult as the number of variables increases. For 5 and 6 variable K-maps, the cells are arranged in a 3-dimensional or 4-dimensional cube, and the adjacency is extended to the opposite faces of the cube. Alternatively, the 5 and 6 variable K-maps can be represented as a collection of smaller K-maps, called submaps, that share some variables .
- For example, a 5-variable K-map can be represented as two 4-variable K-maps, one for E=0 and one for E=1. Similarly, a 6-variable K-map can be represented as four 4-variable K-maps, one for each combination of F and E. The cells in the submaps are still adjacent according to the Gray code property, and the implicants can span across the submaps.
- To minimize a function using a K-map, the following steps can be followed :
  - Draw a K-map with the appropriate number of cells and variables, and label the cells with the binary codes.
  - Mark the cells that correspond to the minterms of the function with 1, and the cells that correspond to the don't care terms with X. Leave the remaining cells blank or mark them with 0.
  - Find the largest implicants that cover the 1s and Xs in the K-map, and circle them. These are the prime implicants. If there are multiple ways to cover the same cells, choose the one that results in the fewest prime implicants.
  - Identify the essential prime implicants, and select them for the minimized expression. These are the implicants that cover at least one 1 that is not covered by any other implicant.
