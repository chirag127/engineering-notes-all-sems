### Op-Amp Basics

- An operational amplifier (op-amp) is a device that can amplify the difference between two input voltages and produce a single-ended output voltage .
- An op-amp has two input terminals, labeled as V+ (non-inverting input) and V- (inverting input), and one output terminal, labeled as Vout .
- An op-amp also has two power supply terminals, labeled as Vs+ (positive supply) and Vs- (negative supply), which provide the maximum and minimum output voltages respectively .
- An op-amp can be considered as a differential-to-single-ended converter, as it converts a differential input signal (V+ - V-) to a single-ended output signal (Vout) .
- An op-amp has a very high open-loop gain, which means that the output voltage is proportional to the input voltage difference multiplied by a large constant .
- An op-amp has a very high input impedance, which means that it draws very little current from the input sources .
- An op-amp has a very low output impedance, which means that it can drive a large current to the load without significant voltage drop .
- An op-amp exhibits common-mode rejection, which means that it ignores any voltage component that is present in both input signals, such as noise or DC offset .
- An op-amp can be used in various configurations, such as inverting amplifier, non-inverting amplifier, summing amplifier, difference amplifier, integrator, differentiator, etc., by connecting external resistors and capacitors  .
