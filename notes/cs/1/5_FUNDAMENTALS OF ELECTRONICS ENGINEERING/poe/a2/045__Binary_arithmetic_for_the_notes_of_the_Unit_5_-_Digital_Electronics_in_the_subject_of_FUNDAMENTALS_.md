### Binary arithmetic

1. Binary number system: The binary number system uses only two digits 0 and 1. Each binary digit represents a power of 2 (starting from the right).

2. Binary addition:
    - Add corresponding bits
    - Carry over any 1s, if necessary
    - Example: 011001 + 101101 = 1001000

3. Binary subtraction:
    - Subtract corresponding bits
    - Borrow 1 if necessary
    - Example: 1001000 - 011001 = 101101

4. Binary multiplication:
    - Multiply each bit of one number with all bits of the other number
    - Add the partial products
    - Example: 011001 x 101101 = 11001001

5. Binary division:
    - Repeatedly divide the leading 1 of the dividend by the divisor and write the remainder as the next digit of the quotient
    - Bring down remaining digits and repeat until there are no more digits left in the dividend
    - Example: 11001001 / 011001 = 101101 (Quotient), 0 (Remainder)
