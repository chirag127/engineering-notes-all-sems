### Comparators for the notes of the Unit 4 - Operational Amplifiers

1. Comparator: A comparator is a device which compares two voltages or currents and switches its output to either high or low state depending upon which input is higher or lower than the other.
2. Applications: Some common applications of comparators are:
- To detect when an input voltage exceeds a reference voltage.
- To detect when an input voltage falls below a reference voltage.
- To convert an analog signal to a digital signal.
3. Open Loop Configuration: In open loop configuration, the comparator has two inputs - one for the signal to be compared called input signal and other for the reference voltage called reference input. The comparator compares the inputs and produces an output depending upon which input is higher. If input signal is higher than the reference voltage, the output is high and vice versa.
4. Closed Loop Configuration: In closed loop configuration, the comparator output is fed back to the inverting input through a feedback resistor. This results in a regenerative action which drives the output to either saturation level. This makes the circuit switch faster between the output states. The circuit has hysteresis and does not switch back until the input changes significantly. This avoids unwanted oscillations.
5. Applications with Microcontrollers: Comparators are commonly used with microcontrollers to detect when an input voltage reaches a certain threshold. This property is useful in applications like:
- Detecting when a sensor output reaches a certain value.
- Monitoring battery voltage and indicating when it is low.
- Detecting when a thermistor reaches a certain temperature.
