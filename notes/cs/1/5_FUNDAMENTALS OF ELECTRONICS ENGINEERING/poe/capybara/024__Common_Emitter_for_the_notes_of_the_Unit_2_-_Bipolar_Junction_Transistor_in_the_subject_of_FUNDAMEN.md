### Common Emitter

The common emitter configuration is one of the three basic configurations of the bipolar junction transistor (BJT). It is widely used because it provides the highest current gain of all the configurations.

Here are some important points to note about the common emitter configuration:

- In this configuration, the base of the transistor is connected to the input signal, the collector is connected to the output load, and the emitter is grounded.

- The voltage gain in this configuration is defined as the ratio of the output voltage (across the load) to the input voltage (applied to the base).

- The current gain in this configuration is defined as the ratio of the collector current to the base current.

- The power gain in this configuration is defined as the product of the voltage gain and the current gain.

- The common emitter configuration is inverting, which means that the output signal is 180 degrees out of phase with the input signal.

- The input impedance of this configuration is low, and the output impedance is high.

- The common emitter configuration is used in many applications, including amplifiers, oscillators, and switches.

- One of the disadvantages of this configuration is that it has a relatively low input impedance, which can lead to loading effects.

- Another disadvantage of this configuration is that it is not very suitable for high-frequency applications, because the parasitic capacitances of the transistor can reduce the gain and cause instability.

Overall, the common emitter configuration is an important and widely used configuration of the bipolar junction transistor, with many useful applications in electronics.
