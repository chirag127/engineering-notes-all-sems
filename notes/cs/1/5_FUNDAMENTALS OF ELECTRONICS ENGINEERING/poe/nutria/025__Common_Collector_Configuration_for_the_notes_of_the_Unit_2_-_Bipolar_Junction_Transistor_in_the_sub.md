
### Common Collector Configuration for the notes of the Unit 2 - Bipolar Junction Transistor in the subject of FUNDAMENTALS OF ELECTRONICS ENGINEERING

* The common collector configuration is also known as the emitter follower configuration. 
* In this configuration, the base of the transistor is connected to the input signal and the output is taken from the emitter. 
* The input signal is applied to the base of the transistor and the output is taken from the emitter. 
* The output voltage is slightly lower than the input voltage, so the transistor acts as a voltage follower. 
* The current gain in this configuration is less than unity, but the voltage gain is unity. 
* The output impedance is high and the input impedance is low. 
* This configuration is used for impedance matching, voltage buffering and for providing current gain.
