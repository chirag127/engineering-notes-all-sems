## Unit-4: 8

- This unit covers the topic of **linear programming**, which is a method of finding the optimal solution to a problem that involves multiple constraints and objectives.
- Linear programming can be used to model and solve various real-world problems, such as production planning, resource allocation, transportation, scheduling, etc.
- The basic idea of linear programming is to **maximize** or **minimize** a linear function of decision variables, subject to a set of linear equations or inequalities that represent the constraints of the problem.
- A linear function is a function that can be written as a sum of constant multiples of the decision variables, such as `f(x,y) = 3x + 5y`.
- A linear equation is an equation that can be written as a sum of constant multiples of the decision variables equal to a constant, such as `2x + y = 7`.
- A linear inequality is an inequality that can be written as a sum of constant multiples of the decision variables less than or equal to, greater than or equal to, or equal to a constant, such as `x + 2y <= 10`.
- The decision variables are the unknown quantities that need to be determined by the linear programming method, such as the amount of products to produce, the number of workers to hire, the routes to take, etc.
- The constraints are the limitations or restrictions that the decision variables must satisfy, such as the availability of resources, the demand of customers, the capacity of facilities, etc.
- The objective function is the linear function that represents the goal of the problem, such as the profit to maximize, the cost to minimize, the efficiency to optimize, etc.
- A feasible solution is a set of values for the decision variables that satisfies all the constraints of the problem.
- An optimal solution is a feasible solution that gives the best possible value for the objective function.
- A feasible region is the set of all feasible solutions, which can be represented graphically by a polygonal region on a coordinate plane.
- A corner point is a point on the boundary of the feasible region that has at least two adjacent sides that are not parallel.
- An optimal solution can always be found at one of the corner points of the feasible region, if it exists.
- A graphical method can be used to solve linear programming problems with two decision variables, by plotting the feasible region and the objective function on the same graph, and finding the corner point that gives the highest or lowest value for the objective function, depending on whether it is a maximization or minimization problem.
- An algebraic method can be used to solve linear programming problems with any number of decision variables, by using a systematic procedure called the **simplex method**, which involves transforming the problem into a standard form, constructing a table with basic and non-basic variables, and performing a series of row operations to find the optimal solution.
