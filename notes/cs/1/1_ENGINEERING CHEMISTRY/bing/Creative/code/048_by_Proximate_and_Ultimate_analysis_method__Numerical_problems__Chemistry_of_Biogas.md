# Proximate and Ultimate Analysis of Coal

## Proximate Analysis

- Proximate analysis of coal is the technique used to analyze the **moisture content, ash content, volatile matter, and fixed carbon** of coal.
- It is reported as **dry weight**.
- It is used on coals during **exploration, mining, and preparation**.
- It provides information about the **quality and rank** of coal.
- The most common method for proximate analysis is the **ASTM D3172** standard.
- The proximate analysis can be performed using an **automated instrument** called a **proximate analyzer**.

## Ultimate Analysis

- Ultimate analysis of coal is the technique used to analyze the **chemical composition** of coal.
- It measures the **weight percent** of **carbon, hydrogen, nitrogen, sulfur, and ash** from a coal sample.
- It provides information about the **heating value and environmental impact** of coal.
- The most common method for ultimate analysis is the **ASTM D3176** standard.
- The ultimate analysis can be performed using an **automated instrument** called an **ultimate analyzer**.

## Numerical Problems

- Example 1: A coal sample has the following proximate analysis (dry basis): moisture 2%, volatile matter 35%, fixed carbon 50%, ash 13%. Calculate the proximate analysis (as-received basis).
  - Solution: The moisture content (as-received basis) is 2%. The other components (as-received basis) are calculated by multiplying the dry basis values by the ratio of 100 minus the moisture content to 100. For example, the volatile matter (as-received basis) is 35% x (100 - 2) / 100 = 34.3%. Similarly, the fixed carbon (as-received basis) is 50% x (100 - 2) / 100 = 49%, and the ash (as-received basis) is 13% x (100 - 2) / 100 = 12.7%. Therefore, the proximate analysis (as-received basis) is: moisture 2%, volatile matter 34.3%, fixed carbon 49%, ash 12.7%.

- Example 2: A coal sample has the following ultimate analysis (dry basis): carbon 75%, hydrogen 5%, nitrogen 1.5%, sulfur 2%, ash 10%, oxygen 6.5%. Calculate the heating value of the coal in MJ/kg (dry basis).
  - Solution: The heating value of the coal can be estimated using the **Dulong formula**, which is:

    - Heating value = 0.3383 x C + 1.422 x (H - O/8) + 0.0954 x S

    - Where C, H, O, and S are the weight percentages of carbon, hydrogen, oxygen, and sulfur, respectively.

    - Substituting the values from the ultimate analysis, we get:

    - Heating value = 0.3383 x 75 + 1.422 x (5 - 6.5/8) + 0.0954 x 2

    - Heating value = 25.3725 + 6.2135 + 0.1908

    - Heating value = 31.7768 MJ/kg (dry basis)

## Chemistry of Biogas

- Biogas is a mixture of **methane, carbon dioxide, and other gases** produced by the **anaerobic digestion** of organic matter.
- Anaerobic digestion is the process of **breaking down** organic matter by **microorganisms** in the **absence of oxygen**.
- The main steps of anaerobic digestion are: **hydrolysis, acidogenesis, acetogenesis, and methanogenesis**.
- Hydrolysis is the step where **complex organic molecules** such as carbohydrates, proteins, and fats are **hydrolyzed** into **simple monomers** such as sugars, amino acids, and fatty acids by **extracellular enzymes**.
