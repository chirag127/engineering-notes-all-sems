Some points to remember about Unit-5: 8 are:

- A **function** is a relation that assigns exactly one output value to each input value. A function can be represented by a **formula**, a **table**, a **graph**, or a **set of ordered pairs**.
- A **linear function** is a function whose graph is a straight line. The general form of a linear function is **f(x) = mx + b**, where **m** is the **slope** and **b** is the **y-intercept**. The slope measures the **rate of change** of the function, and the y-intercept is the **output value** when the input value is zero.
- A **quadratic function** is a function whose graph is a parabola. The general form of a quadratic function is **f(x) = ax^2 + bx + c**, where **a**, **b**, and **c** are constants. The **vertex** of the parabola is the point where the function reaches its **maximum** or **minimum** value, and the **axis of symmetry** is the vertical line that passes through the vertex. The **zeros** of the function are the **input values** that make the output value zero, and they are the **x-intercepts** of the graph.
- An **exponential function** is a function whose output value is proportional to its input value raised to a constant power. The general form of an exponential function is **f(x) = ab^x**, where **a** and **b** are constants, and **b > 0** and **b ≠ 1**. The **base** of the function is **b**, and the **initial value** is **a**. The function has a **horizontal asymptote** at **y = 0**, and it is **increasing** if **b > 1** and **decreasing** if **0 < b < 1**.
- A **logarithmic function** is the inverse of an exponential function. The **domain** of the function is **(0, ∞)**, and the **range** is **(-∞, ∞)**.
