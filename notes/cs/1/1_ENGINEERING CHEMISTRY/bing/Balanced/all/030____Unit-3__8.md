  - The concept of **functions** and how to define, evaluate, and graph them.
  - The concept of **inverse functions** and how to find and use them.
  - The concept of **exponential functions** and how to model growth and decay phenomena with them.
  - The concept of **logarithmic functions** and how to use their properties and graphs.
  - The concept of **compound interest** and how to calculate the future and present value of an investment.
  - The concept of **continuous compounding** and how to use the natural exponential function and the natural logarithm function.
  - The concept of **exponential growth and decay models** and how to use them to analyze real-world situations.
  - The concept of **logistic growth models** and how to use them to describe limited growth phenomena.

- Some of the key terms and formulas related to this topic are:
  - A **function** is a rule that assigns to each input value exactly one output value.
  - The **domain** of a function is the set of all possible input values, and the **range** is the set of all possible output values.
  - A function can be represented by an **equation**, a **table**, a **graph**, or a **verbal description**.
  - A function can be **evaluated** by substituting a value for the input variable and simplifying the expression.
  - A function can be **graphed** by plotting ordered pairs that satisfy the equation of the function.
  - A function is **one-to-one** if it passes the **horizontal line test**, which means that no horizontal line intersects the graph of the function more than once.
  - The **inverse** of a function is another function that reverses the input-output relationship of the original function.
  - The inverse of a function can be found by **swapping** the input and output variables and **solving** for the new input variable.
  - The inverse of a function can be **verified** by showing that the composition of the function and its inverse is equal to the identity function, which means that f(f^(-1)(x)) = x and f^(-1)(f(x)) = x for all x in the domain of f and f^(-1).
  - The inverse of a function can be **graphed** by **reflecting** the graph of the original function over the line y = x.
  - An **exponential function** is a function of the form f(x) = a(b)^x, where a and b are constants, a is not zero, and b is positive and not equal to one.
  - The **base** of an exponential function is the constant b, and the **initial value** is the constant a.
  - The **growth factor** of an exponential function is the amount by which the function value changes when the input value increases by one unit. It is equal to the base b.
  - The **growth rate** of an exponential function is the percentage by which the function value changes when the input value increases by one unit. It is equal to (b - 1) * 100%.
  - The **decay factor** of an exponential function is the amount by which the function value changes when the input value decreases by one unit. It is equal to the reciprocal of the base b.
  - The **decay rate** of an exponential function is the percentage by which the function value changes when the input value decreases by one unit. It is equal to (1 - b) * 100%.
  - The **end behavior** of an exponential function describes how the function value approaches infinity or zero as the input value increases or decreases without bound. It depends on the sign of a and the value of b.
  - The **asymptote** of an exponential function is the horizontal line that the graph of the function approaches but never touches. It is given by the equation y = a.
