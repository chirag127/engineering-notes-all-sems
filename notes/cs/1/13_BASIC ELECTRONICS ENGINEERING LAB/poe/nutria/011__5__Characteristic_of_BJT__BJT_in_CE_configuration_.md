
### 5. Characteristic of BJT: BJT in CE Configuration
1. The BJT in CE configuration is a single-stage amplifier which is used for both voltage and current amplification.
2. It consists of a Base, Collector and Emitter. The Base is connected to the input signal, the Collector is connected to the output and the Emitter is connected to ground.
3. The current gain of the CE configuration is determined by the ratio of the collector current to the base current.
4. The voltage gain of the CE configuration is determined by the ratio of the collector voltage to the base voltage.
5. The output impedance of the CE configuration is determined by the ratio of the collector current to the base voltage.
6. The input impedance of the CE configuration is determined by the ratio of the collector voltage to the base current.
7. The CE configuration has a high input impedance and a low output impedance.
8. The CE configuration is commonly used in audio amplifiers, radio transmitters and receivers and other applications where voltage and current amplification is required.
