
### Characteristic of BJT: BJT in CE Configuration

1. Bipolar Junction Transistors (BJTs) are three-terminal semiconductor devices used as amplifiers, switches, and voltage regulators.
2. BJTs come in two types: NPN and PNP.
3. In the Common Emitter (CE) configuration, the emitter terminal is connected to the common ground, while the base and collector terminals are connected to the input and output signals, respectively.
4. The input signal applied to the base terminal controls the flow of current between the emitter and collector terminals.
5. The output signal is proportional to the input signal and can be used to amplify the input signal.
6. The CE configuration is used for amplifying small signals and for switching large currents.
