## Part B:

1. Types of Machine Learning
- Supervised Learning: Uses labeled training data to learn a function that maps inputs to outputs. Examples: Classification, Regression.
- Unsupervised Learning: Finds hidden patterns in unlabeled data. Examples: Clustering, Association Rule Learning.
- Reinforcement Learning: Learns by interacting with a dynamic environment. The agent learns the optimal way of achieving the highest reward through trial-and-error using feedback from the environment.

2. Classification
- Predicting a class or category. Examples: Spam detection, Image classification, Sentiment analysis.
- Types: Binary, Multi-class, Multi-label classification.
- Algorithms: Logistic regression, SVM, Decision trees, Naive Bayes, kNN, Neural networks.

3. Regression
- Predicting a continuous value. Examples: Stock price prediction, Predict housing prices.
- Types: Linear, Non-linear regression.
- Algorithms: Linear regression, Lasso, Ridge, Elastic net, Neural networks.
