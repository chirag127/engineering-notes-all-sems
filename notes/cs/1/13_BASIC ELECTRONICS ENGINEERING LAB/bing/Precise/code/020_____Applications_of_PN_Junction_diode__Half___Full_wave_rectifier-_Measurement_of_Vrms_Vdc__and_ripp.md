### Applications of PN Junction diode: Half & Full wave rectifier- Measurement of Vrms,Vdc, and ripple factor.

A PN junction diode is a two-terminal electronic device that allows the flow of current in only one direction. It is formed by bringing a P-type semiconductor in close contact with an N-type semiconductor. The PN junction diode has several applications, including its use as a rectifier in power supplies.

#### Half-wave rectifier:

A half-wave rectifier is a circuit that converts an AC input voltage into a pulsating DC output voltage. It does this by allowing only the positive half-cycles of the AC input voltage to pass through the diode, while blocking the negative half-cycles.

The output voltage of a half-wave rectifier can be calculated using the following formula:

Vdc = Vm / π

where Vdc is the average DC output voltage, and Vm is the peak value of the AC input voltage.

#### Full-wave rectifier:

A full-wave rectifier is a circuit that converts an AC input voltage into a pulsating DC output voltage. It does this by allowing both the positive and negative half-cycles of the AC input voltage to pass through the diode, but inverting the negative half-cycles so that they become positive.

The output voltage of a full-wave rectifier can be calculated using the following formula:

Vdc = 2Vm / π

where Vdc is the average DC output voltage, and Vm is the peak value of the AC input voltage.

#### Measurement of Vrms, Vdc, and ripple factor:

Vrms is the root mean square value of the AC input voltage. It can be calculated using the following formula:

Vrms = Vm / √2

where Vm is the peak value of the AC input voltage.

Vdc is the average DC output voltage of the rectifier. It can be calculated using the formulas given above for half-wave and full-wave rectifiers.

The ripple factor is a measure of the effectiveness of the rectifier in converting the AC input voltage into a smooth DC output voltage. It is defined as the ratio of the RMS value of the AC component of the output voltage to the DC component of the output voltage. It can be calculated using the following formula:

Ripple factor = √((Vrms / Vdc)² - 1)

where Vrms is the RMS value of the AC component of the output voltage, and Vdc is the average DC output voltage. The lower the ripple factor, the more effective the rectifier is in converting the AC input voltage into a smooth DC output voltage.
