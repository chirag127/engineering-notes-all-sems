### 6. To study Operational Amplifier as Adder and Subtractor

An operational amplifier, or op-amp, is a high-gain electronic voltage amplifier with a differential input and usually a single-ended output. It is used in a variety of applications, including as an adder and subtractor.

#### Adder
An adder circuit is used to add two or more input signals and produce a single output signal. In an op-amp adder circuit, the input signals are applied to the inverting input of the op-amp through individual resistors. The non-inverting input is connected to ground. The output of the op-amp is fed back to the inverting input through a feedback resistor. The output voltage is the sum of the input voltages, with each input voltage scaled by the ratio of the feedback resistor to the input resistor.

#### Subtractor
A subtractor circuit is used to subtract one input signal from another and produce a single output signal. In an op-amp subtractor circuit, the input signals are applied to the inverting and non-inverting inputs of the op-amp through individual resistors. The output of the op-amp is fed back to the inverting input through a feedback resistor. The output voltage is the difference between the input voltages, with each input voltage scaled by the ratio of the feedback resistor to the input resistor.

In summary, an operational amplifier can be used as an adder or subtractor by configuring the input and feedback resistors appropriately. These circuits are commonly used in analog computing and signal processing applications.
