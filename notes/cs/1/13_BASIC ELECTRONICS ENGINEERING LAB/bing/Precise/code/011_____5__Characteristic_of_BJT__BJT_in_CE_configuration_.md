### 5. Characteristics of BJT: BJT in CE configuration

1. **Voltage Gain:** In the common emitter (CE) configuration, the voltage gain of a BJT is high. The voltage gain is the ratio of the change in output voltage to the change in input voltage.

2. **Current Gain:** The current gain of a BJT in CE configuration is also high. The current gain is the ratio of the change in output current to the change in input current.

3. **Input Impedance:** The input impedance of a BJT in CE configuration is relatively low. This means that the input signal is not significantly attenuated when it is applied to the base of the transistor.

4. **Output Impedance:** The output impedance of a BJT in CE configuration is also relatively low. This means that the output signal is not significantly affected by the load connected to the collector of the transistor.

5. **Phase Shift:** In the CE configuration, the output signal is 180 degrees out of phase with the input signal. This means that the output signal is inverted with respect to the input signal.

6. **Frequency Response:** The frequency response of a BJT in CE configuration is relatively flat over a wide range of frequencies. This means that the gain of the transistor does not vary significantly with frequency.
