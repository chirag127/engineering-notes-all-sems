### Part A PCB Lab: 
a. Artwork & printing of a simple PCB. 
b. Etching & drilling of PCB 

This practical is not possible by virtual lab. It will be conducted only in physical mode.

1. Artwork and printing of a simple PCB involves creating a design for the circuit board and transferring it onto the board material. This can be done using a variety of methods, including hand-drawing, using specialized software, or using a photolithography process.
2. Etching involves removing unwanted copper from the board to create the desired circuit pattern. This is typically done using a chemical etching solution.
3. Drilling involves creating holes in the board for components to be inserted and soldered in place. This is typically done using a drill press or specialized PCB drilling machine.
4. As this practical involves the use of specialized equipment and materials, it is not possible to conduct it in a virtual lab. It must be conducted in a physical lab setting.
