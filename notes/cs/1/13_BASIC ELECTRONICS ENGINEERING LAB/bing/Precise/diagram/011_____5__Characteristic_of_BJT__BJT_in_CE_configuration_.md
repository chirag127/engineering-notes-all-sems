### 5. Characteristics of BJT: BJT in CE configuration

1. **Current Gain:** In the common emitter (CE) configuration, the current gain of a BJT is defined as the ratio of the collector current to the base current. This is also known as the beta (β) of the transistor.
2. **Voltage Gain:** The voltage gain of a BJT in CE configuration is the ratio of the change in output voltage to the change in input voltage. It is typically high, making the CE configuration useful for amplification.
3. **Input Impedance:** The input impedance of a BJT in CE configuration is the ratio of the change in input voltage to the change in input current. It is typically low, meaning that the transistor draws a relatively large amount of current from the input signal source.
4. **Output Impedance:** The output impedance of a BJT in CE configuration is the ratio of the change in output voltage to the change in output current. It is typically high, meaning that the transistor can drive a relatively large load without significant loss of gain.
5. **Phase Shift:** In the CE configuration, the output signal is 180 degrees out of phase with the input signal. This means that the output signal is inverted with respect to the input signal.
