### 5. Characteristics of BJT: BJT in CE configuration

- BJT stands for Bipolar Junction Transistor, which is a three-terminal device that can amplify electrical signals.
- CE stands for Common Emitter, which is one of the possible configurations of BJT, where the emitter terminal is common to both input and output circuits.
- The CE configuration is an inverting amplifier, which means that the output voltage is 180 degrees out of phase with the input voltage.
- The input characteristics of the CE configuration are the relation between the base current (I_B) and the base-emitter voltage (V_BE) for a given collector-emitter voltage (V_CE).
- The output characteristics of the CE configuration are the relation between the collector current (I_C) and the collector-emitter voltage (V_CE) for a given base current (I_B).
- The CE configuration has a high voltage gain, a high current gain, a moderate input impedance, and a low output impedance.
- The CE configuration is widely used for voltage amplification and signal processing in electronic circuits.
