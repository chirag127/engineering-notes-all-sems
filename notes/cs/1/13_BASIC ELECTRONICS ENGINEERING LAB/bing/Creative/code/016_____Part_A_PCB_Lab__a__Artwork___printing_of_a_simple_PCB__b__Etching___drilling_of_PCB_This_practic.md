### Part A PCB Lab: a. Artwork & printing of a simple PCB. b. Etching & drilling of PCB

This practical is not possible by virtual lab. It will be conducted only in physical mode.

#### Objectives:

- To learn the process of designing, printing, etching and drilling of a printed circuit board (PCB).
- To understand the basic principles and components of a PCB.
- To apply the knowledge of PCB design to create a simple circuit.

#### Theory:

- A PCB is a thin board made of fiberglass, epoxy or other insulating material, on which conductive tracks, pads and other features are etched or printed.
- A PCB is used to connect electronic components and devices in a circuit, and to provide mechanical support and protection.
- A PCB can have one or more layers of conductive tracks, separated by insulating layers. The number of layers depends on the complexity and density of the circuit.
- A PCB design consists of the following steps:
  - Schematic capture: The circuit diagram is drawn using a software tool, such as KiCad, Eagle, Proteus, etc. The schematic shows the components, their values, and their connections.
  - Layout design: The physical layout of the PCB is created using the same or another software tool, based on the schematic. The layout shows the size, shape and position of the components, pads, tracks, vias, holes, etc. The layout can be checked for errors and optimized for performance and cost.
  - Artwork generation: The layout is converted into a printable format, such as PDF, Gerber, etc. The artwork shows the positive or negative image of each layer of the PCB, which can be printed on a transparent film or paper.
  - Printing: The artwork is printed on a suitable material, such as photoresist, copper-clad board, etc. The printing can be done using a laser printer, inkjet printer, photocopier, etc. The printed material is then cut to the desired size and shape of the PCB.
  - Etching: The printed material is exposed to a chemical solution, such as ferric chloride, sodium persulfate, etc. The solution dissolves the unwanted copper or other metal from the board, leaving behind the desired tracks and pads. The etching time and temperature depend on the type and concentration of the solution, and the thickness and quality of the board.
  - Drilling: The holes for the components and vias are drilled on the board using a drill machine, a hand drill, or a CNC machine. The size and position of the holes should match the layout and the components. The holes should be clean and smooth, without any burrs or cracks.
  - Finishing: The board is cleaned, dried and inspected for any defects or errors. The board can be coated with a protective layer, such as solder mask, silkscreen, etc. The board can also be tested for electrical continuity and functionality.

#### Procedure:

- Design a simple circuit, such as a LED flasher, a buzzer, a voltage divider, etc. using a schematic capture software. Save the schematic file and generate a netlist file.
- Open the layout design software and import the netlist file. Create a new PCB project and set the parameters, such as board size, layer count, grid size, etc.
- Place the components on the board and arrange them according to the schematic. Use the auto-router or manual routing tools to connect the components with tracks and vias. Adjust the track width, clearance, via size, etc. as per the design rules.
- Check the layout for any errors or warnings using the design rule check (DRC) tool. Fix any issues and optimize the layout for performance and cost.
- Generate the artwork file for each layer of the PCB. Preview the artwork and verify that it matches the layout. Save the artwork file in a printable format, such as PDF, Gerber, etc.
- Print the artwork on a transparent film or paper using a laser printer, inkjet printer, photocopier, etc. Cut the printed artwork to the size and shape of the board.
- Prepare the copper-clad board by cleaning it with a cloth and alcohol. Cut the board to the size and shape of the artwork. Align the artwork with the board and secure it with tape or clips.
