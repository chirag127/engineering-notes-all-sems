### 2-Computer assisted software based Language Learning:

1. Computer-assisted language learning (CALL) refers to the use of computer software to aid in the learning of a new language.
2. CALL software can include interactive tutorials, exercises, and games that help learners practice their language skills.
3. CALL software can also provide learners with immediate feedback on their performance, allowing them to identify areas where they need to improve.
4. CALL software can be used in a classroom setting or for self-study.
5. CALL software can be used to learn a variety of languages, including English, Spanish, French, German, and Chinese.
6. CALL software can be used by learners of all ages and skill levels.
7. CALL software can be used on a variety of devices, including computers, tablets, and smartphones.
8. CALL software can be used in conjunction with traditional language learning methods, such as textbooks and classroom instruction.
9. CALL software can be an effective tool for language learning, but it is not a replacement for a qualified language teacher or immersion in a language-speaking environment.
10. CALL software is constantly evolving, with new features and capabilities being added to improve the language learning experience.
