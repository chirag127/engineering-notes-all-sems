### 2-Computer assisted software based Language Learning:

1. Computer-assisted language learning (CALL) refers to the use of computer software to support language learning.
2. CALL software can provide interactive and multimedia content to enhance the language learning experience.
3. CALL can be used for self-study or as a supplement to classroom instruction.
4. CALL software can provide immediate feedback to learners, allowing them to identify and correct errors in real-time.
5. CALL can be used to develop all language skills, including reading, writing, listening, and speaking.
6. CALL software can be tailored to the individual needs and learning styles of learners.
7. CALL can provide learners with access to authentic language materials and cultural information.
8. CALL can facilitate communication and collaboration among learners, both locally and globally.
9. CALL can provide learners with opportunities to practice language skills in a safe and supportive environment.
10. CALL can be an effective tool for language learning when used in conjunction with other methods and resources.
