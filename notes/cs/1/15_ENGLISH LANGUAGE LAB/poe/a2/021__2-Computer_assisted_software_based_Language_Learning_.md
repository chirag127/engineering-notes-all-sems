### 2-Computer assisted software based Language Learning:

1. Computer-assisted language learning (CALL) software provides interactive learning experiences for learners. These software include:
- Interactive tutorials for learning vocabulary, grammar, and pronunciation.
- Speech recognition for pronunciation practice.
- Virtual language environments for practicing speaking and listening skills.
- Adaptive learning systems which personalize instruction to individual learners.
2. Computer-mediated communication tools enable learners to connect and practice with other learners and native speakers. These include:
- Email, messaging, and discussion forums.
- Video conferencing for online conversation practice.
3. Corpora and concordancing tools provide authentic language examples for analysis. Learners can search corpora to find usage examples of vocabulary and grammar.
4. Multimedia and hypermedia reference works offer language learning materials in different formats like text, audio, images, and video.
5. Interactive multimedia software provides immersive simulations and game-like environments for learners to explore language in context.
