## Reference Books:

1. Fundamentals of Python: From First Programs Through Data Structures - Kenneth A. Lambert
- Covers basic to advanced features of Python with extensive examples. Good for beginners and intermediates both.

2. Think Python: How to Think Like a Computer Scientist - Allen B. Downey
- Using Python to teach fundamental concepts in computer science. Written in a very engaging and easy to understand style.

3. Python Crash Course: A Hands-On, Project-Based Introduction to Programming - Eric Matthes
- A fast-paced, thorough introduction to programming with Python that teaches programming concepts and skills through project-based learning.

4. Python for Everybody - Exploring Data in Python 3 - Charles R. Severance
- Focuses on teaching programming and data skills using Python 3 and interesting datasets. Great for learning data science and data analysis with Python.

5. Automate the Boring Stuff with Python: Practical Programming for Total Beginners - Al Sweigart
- Aimed at helping newcomers get started with programming in Python for practical tasks like filling out web forms, downloading files, updating spreadsheets, and more. Fast and easy to follow.
