# Solution of system of linear equations

- A system of linear equations is a set of equations that involve the same variables and can be written in the form of `a1x1 + a2x2 + ... + anxn = b`, where `a1, a2, ..., an` and `b` are constants and `x1, x2, ..., xn` are variables.
- A solution to a system of linear equations is an assignment of values to the variables such that all the equations are simultaneously satisfied. For example, the ordered pair `(4, 7)` is a solution to the system of linear equations `x + y = 11` and `2x - y = 1` .
- A system of linear equations can have one, infinitely many, or no solutions, depending on the relationship between the equations. For example, the system of linear equations `x + y = 5` and `x - y = 3` has one solution `(4, 1)`, the system of linear equations `x + y = 5` and `2x + 2y = 10` has infinitely many solutions `(x, 5 - x)`, and the system of linear equations `x + y = 5` and `x + y = 7` has no solution.
- There are multiple methods of solving systems of linear equations, such as graphing, substitution, elimination, matrix methods, and Cramer's rule. Each method has its own advantages and disadvantages, depending on the type and number of equations, the number of variables, and the coefficients of the equations   .
- Graphing method: This method involves plotting the graphs of the equations on the same coordinate plane and finding the point of intersection, if any, which is the solution to the system. This method is useful for visualizing the relationship between the equations, but it may not be very accurate or efficient for large or complicated systems .
- Substitution method: This method involves solving one equation for one variable in terms of the others, and then substituting the expression into the other equations to eliminate that variable. This process is repeated until only one variable remains, which can then be solved. This method is useful for systems with two or three equations and variables, but it may become tedious or difficult for larger or more complex systems .
- Elimination method: This method involves adding or subtracting multiples of the equations to eliminate one variable at a time, until only one variable remains, which can then be solved. This method is useful for systems with two or three equations and variables, but it may require careful manipulation of the coefficients to avoid fractions or large numbers .
- Matrix methods: This method involves representing the system of linear equations as a matrix equation of the form `AX = B`, where `A` is the coefficient matrix, `X` is the variable matrix, and `B` is the constant matrix. This method is useful for systems with any number of equations and variables, but it requires knowledge of matrix operations and properties, such as inverse, determinant, and rank .
- Cramer's rule: This method involves finding the solution to the system of linear equations by using the determinants of the coefficient matrix and the matrices obtained by replacing one column of the coefficient matrix with the constant matrix. This method is useful for systems with any number of equations and variables, but it requires computing the determinants of large matrices, which can be time-consuming or error-prone.
