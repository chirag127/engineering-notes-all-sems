# Euler's Theorem for Homogeneous Functions

- A function $f(x,y,z,...)$ is said to be **homogeneous** of degree $n$ if it satisfies the condition $$f(tx,ty,tz,...)=t^n f(x,y,z,...)$$ for any positive constant $t$ and any values of $x,y,z,...$.
- For example, the function $f(x,y,z)=x^3+y^3+z^3+3xyz$ is homogeneous of degree $3$ because $$f(tx,ty,tz)=(tx)^3+(ty)^3+(tz)^3+3(tx)(ty)(tz)=t^3(x^3+y^3+z^3+3xyz)=t^3 f(x,y,z).$$
- **Euler's theorem** for homogeneous functions states that if $f(x,y,z,...)$ is a homogeneous function of degree $n$ of $k$ variables $x,y,z,...$, then $$x \frac{\partial f}{\partial x}+y \frac{\partial f}{\partial y}+z \frac{\partial f}{\partial z}+...=n f.$$ This can be written in a compact form using the summation notation as $$\sum_{i=1}^k x_i \frac{\partial f}{\partial x_i}=n f.$$
- To prove Euler's theorem, we can use the chain rule and the definition of homogeneous function. Let $t$ be a positive constant and consider the function $$g(t)=f(tx,ty,tz,...).$$ Then by the chain rule, we have $$g'(t)=\frac{d}{dt}f(tx,ty,tz,...)=\sum_{i=1}^k \frac{\partial f}{\partial x_i} \frac{d}{dt}(tx_i)=\sum_{i=1}^k x_i \frac{\partial f}{\partial x_i} t.$$ On the other hand, by the definition of homogeneous function, we have $$g(t)=f(tx,ty,tz,...)=t^n f(x,y,z,...).$$ Therefore, $$g'(t)=\frac{d}{dt}(t^n f(x,y,z,...))=n t^{n-1} f(x,y,z,...).$$ Equating the two expressions for $g'(t)$ and setting $t=1$, we get $$\sum_{i=1}^k x_i \frac{\partial f}{\partial x_i}=n f,$$ which is Euler's theorem.
