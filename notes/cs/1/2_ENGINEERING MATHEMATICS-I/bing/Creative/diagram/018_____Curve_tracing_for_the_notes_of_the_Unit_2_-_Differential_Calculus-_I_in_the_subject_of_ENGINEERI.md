### Curve tracing for the notes of the Unit 2 - Differential Calculus- I in the subject of ENGINEERING MATHEMATICS-I

- Curve tracing is the method of studying the properties and shape of a curve whose equation is given in cartesian, polar or parametric form.
- Curve tracing helps to sketch the graph of a function using the information obtained from its derivatives, such as extrema, concavity, inflection points, asymptotes, etc .
- Curve tracing can also be used to find the traces of surfaces, which are the curves that represent the intersection of the surface and a plane.
- The steps involved in curve tracing are as follows:
  - Find the domain and range of the function.
  - Find the x- and y-intercepts of the function, if any.
  - Find the vertical and horizontal asymptotes of the function, if any.
  - Find the first derivative of the function and use it to determine the intervals of increase and decrease, and the local maxima and minima, if any.
  - Find the second derivative of the function and use it to determine the intervals of concavity and the points of inflection, if any.
  - Plot the points and curves obtained from the previous steps and sketch the graph of the function.
  - Check the symmetry and periodicity of the function, if any.
- The following is an example of curve tracing for the function f(x) = x^3 - 3x + 2:
  - The domain of the function is all real numbers, and the range is also all real numbers.
  - The x-intercepts are the solutions of f(x) = 0, which are x = -2, x = 1, and x = -1. The y-intercept is f(0) = 2.
  - The function has no vertical or horizontal asymptotes, as it is a polynomial function.
  - The first derivative of the function is f'(x) = 3x^2 - 3, which is zero at x = -1 and x = 1. These are the critical points of the function. To find the intervals of increase and decrease, we can use a sign chart or a number line:

    | x | -2 | -1 | 1 | 2 |
    | f'(x) | + | 0 | 0 | + |
    | f(x) | / | \ | / | \ |

    The function is increasing on (-infinity, -1) and (1, infinity), and decreasing on (-1, 1). The function has a local maximum at x = -1 and a local minimum at x = 1.
  - The second derivative of the function is f''(x) = 6x, which is zero at x = 0. This is the possible point of inflection of the function. To find the intervals of concavity, we can use another sign chart or number line:

    | x | -1 | 0 | 1 |
    | f''(x) | - | 0 | + |
    | f(x) | \ | / | \ |

    The function is concave down on (-infinity, 0) and concave up on (0, infinity). The function has a point of inflection at x = 0.
