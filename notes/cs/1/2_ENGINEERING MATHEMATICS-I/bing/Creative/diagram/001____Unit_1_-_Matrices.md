## Unit 1 - Matrices

- A matrix is a rectangular array of numbers, symbols, or expressions, arranged in rows and columns.
- The size or order of a matrix is given by the number of rows and columns it has. For example, a matrix with 3 rows and 2 columns has order 3 x 2.
- The elements of a matrix are denoted by a lowercase letter with two subscripts, indicating the row and column position. For example, a<sub>12</sub> is the element in the first row and second column of matrix A.
- A matrix can be represented by enclosing its elements in square brackets or parentheses. For example, A = [a<sub>11</sub> a<sub>12</sub>; a<sub>21</sub> a<sub>22</sub>] or A = (a<sub>11</sub> a<sub>12</sub>; a<sub>21</sub> a<sub>22</sub>).
- A matrix can also be represented by using a capital letter with a double underline. For example, **A** = [a<sub>11</sub> a<sub>12</sub>; a<sub>21</sub> a<sub>22</sub>].
- There are different types of matrices, such as row matrix, column matrix, square matrix, diagonal matrix, scalar matrix, identity matrix, zero matrix, transpose matrix, symmetric matrix, skew-symmetric matrix, etc.
- Matrices can be added, subtracted, multiplied, or divided by scalars, as well as multiplied or divided by other matrices, following certain rules and properties.
- Matrices can be used to represent various systems of linear equations, transformations, rotations, reflections, etc. in mathematics, physics, engineering, and other fields.
