# Solution of system of linear equations

- A system of linear equations is a set of equations that involve the same variables and can be written in the form of `a1x1 + a2x2 + ... + anxn = b`, where `a1, a2, ..., an` and `b` are constants and `x1, x2, ..., xn` are variables.
- A solution to a system of linear equations is an assignment of values to the variables such that all the equations are simultaneously satisfied. For example, the ordered pair `(4, 7)` is a solution to the system of linear equations `x + y = 11` and `2x - y = 1` .
- A system of linear equations can have one, infinitely many, or no solutions, depending on the relationship between the equations. For example, the system of linear equations `x + y = 5` and `2x + 2y = 10` has infinitely many solutions, since the second equation is a multiple of the first one. The system of linear equations `x + y = 5` and `x + y = 6` has no solutions, since the equations are inconsistent.
- There are multiple methods of solving systems of linear equations, such as graphing, substitution, elimination, matrix methods, and Cramer's rule. Each method has its own advantages and disadvantages, depending on the number of variables, the coefficients, and the complexity of the system   .
- Graphing method: This method involves plotting the graphs of the equations on the same coordinate plane and finding the point of intersection, if any. This point is the solution to the system of linear equations. This method is useful for visualizing the relationship between the equations, but it may not be very accurate or efficient for large or complicated systems .
- Substitution method: This method involves solving one of the equations for one variable and substituting it into the other equation(s). This reduces the number of variables and equations by one, and the process can be repeated until a single equation with one variable is obtained. The solution can then be found by back-substitution. This method is useful for systems with two or three variables, but it may involve a lot of algebraic manipulation and fractions .
- Elimination method: This method involves adding or subtracting multiples of the equations to eliminate one or more variables. This reduces the number of variables and equations by one, and the process can be repeated until a single equation with one variable is obtained. The solution can then be found by back-substitution. This method is useful for systems with two or three variables, but it may involve a lot of arithmetic and fractions .
- Matrix methods: This method involves writing the system of linear equations in matrix form, where the coefficients of the variables form a matrix `A`, the constants form a column vector `b`, and the variables form a column vector `x`. The system can then be written as `Ax = b`. The solution can be found by performing various matrix operations, such as row reduction, inverse, or determinant. This method is useful for systems with any number of variables, but it may involve a lot of computation and notation  .
- Cramer's rule: This method involves finding the determinant of the coefficient matrix `A` and the determinants of the matrices obtained by replacing each column of `A` with the constant vector `b`. The solution can then be found by dividing each of these determinants by the determinant of `A`. This method is useful for systems with any number of variables, but it may involve a lot of computation and notation  .
