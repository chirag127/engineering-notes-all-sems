### Solution of system of linear equations

- A system of linear equations is a set of equations with one or more variables, where each equation is linear, i.e., it can be written in the form `a1x1 + a2x2 + ... + anxn = b`, where `a1, a2, ..., an` and `b` are constants and `x1, x2, ..., xn` are variables.
- A solution to a system of linear equations is an assignment of values to the variables such that all the equations are simultaneously satisfied. For example, the ordered pair `(4, 7)` is a solution to the system of linear equations `x + y = 11` and `2x - y = 1`, since it makes both equations true.
- A system of linear equations can have zero, one, or infinitely many solutions, depending on the relationship between the equations. For example, the system `x + y = 5` and `x + y = 7` has no solution, since there is no pair of values that can satisfy both equations at the same time. The system `x + y = 5` and `2x + 2y = 10` has infinitely many solutions, since any pair of values that satisfies the first equation also satisfies the second equation, and vice versa. The system `x + y = 5` and `2x - y = 1` has a unique solution, as shown above.
- There are multiple methods of solving systems of linear equations, such as graphing, substitution, elimination, matrix methods, and Cramer's rule. Each method has its own advantages and disadvantages, depending on the type and number of equations, the number of variables, and the coefficients of the equations. Some methods are more efficient, some are more convenient, and some are more general than others.
- Graphing is a method of solving systems of linear equations by plotting the equations on a coordinate plane and finding the point(s) of intersection, if any. This method is useful for visualizing the relationship between the equations and the solutions, but it is not very accurate or reliable, especially for large or fractional coefficients or for systems with no or infinitely many solutions.
- Substitution is a method of solving systems of linear equations by expressing one variable in terms of another variable from one equation, and then substituting it into another equation. This method reduces the system to a single equation with one variable, which can be solved by algebraic methods. This method is useful for systems with two equations and two variables, but it can be tedious and complicated for larger systems or for systems with fractions or decimals.
- Elimination is a method of solving systems of linear equations by adding, subtracting, or multiplying the equations by a constant or by each other, in order to eliminate one or more variables. This method reduces the system to a simpler system with fewer variables, which can be solved by back-substitution. This method is useful for systems with three or more equations and variables, but it can also be applied to smaller systems. It can also handle fractions and decimals more easily than substitution.
- Matrix methods are methods of solving systems of linear equations by using matrices and matrix operations, such as addition, subtraction, multiplication, inverse, and determinant. A matrix is a rectangular array of numbers, arranged in rows and columns. A system of linear equations can be represented by a matrix equation of the form `AX = B`, where `A` is the coefficient matrix, `X` is the variable matrix, and `B` is the constant matrix. Matrix methods can be used to solve systems of any size and type, but they require knowledge of matrix algebra and manipulation.
- Cramer's rule is a method of solving systems of linear equations by using determinants. A determinant is a scalar value that can be computed from a square matrix, using a specific formula. Cramer's rule states that the solution to a system of linear equations can be found by dividing the determinant of a matrix obtained by replacing one column of the coefficient matrix with the constant matrix, by the determinant of the coefficient matrix. This method can be used to solve systems of any size and type, but it requires knowledge of determinants and their properties.
