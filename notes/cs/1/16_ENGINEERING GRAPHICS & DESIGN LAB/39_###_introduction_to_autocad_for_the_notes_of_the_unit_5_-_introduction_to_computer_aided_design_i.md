### Introduction to AutoCAD for the notes of the Unit 5 - Introduction to Computer Aided Design in the subject of ENGINEERING GRAPHICS & DESIGN LAB

"Introduction to AutoCAD" is a unit in the subject of Engineering Graphics & Design Lab that focuses on the basics of computer-aided design (CAD) using AutoCAD software. The unit provides an overview of the key features and functions of AutoCAD, including how to create and edit 2D drawings, work with layers, and use basic drawing and editing tools.

The unit covers the fundamental concepts and skills needed to start using AutoCAD effectively, including how to navigate the interface, create and modify basic shapes, and use precision drawing tools. The unit also covers more advanced topics such as using blocks, working with dimensions, and using the software's built-in tools for editing and manipulation.

The notes for this unit are designed to provide students with a comprehensive understanding of the basics of AutoCAD and how to use the software to create and edit 2D drawings. The notes include step-by-step instructions and illustrations to help students understand and apply the concepts covered in the unit.

In conclusion, the Introduction to AutoCAD unit in the Engineering Graphics & Design Lab subject provides students with a solid foundation in the basics of computer-aided design and the skills needed to start using AutoCAD effectively. The notes for this unit are an essential resource for students looking to develop their skills and understanding of this powerful software.
