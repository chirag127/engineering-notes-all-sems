### Line
- A line is the basic element of any drawing. It is used to represent the shape, size, and position of an object or a feature.
- A line can be straight, curved, or a combination of both. It can also have different types, such as solid, dashed, dotted, etc.
- A line can be defined by two points, a direction, and a length. Alternatively, a line can be defined by an equation, such as y = mx + b, where m is the slope and b is the y-intercept.
- A line can be drawn using various tools, such as a ruler, a compass, a protractor, or a computer software. In computer-aided design (CAD), a line can be drawn using commands, such as LINE, PLINE, XLINE, etc.
- A line can be modified using various operations, such as move, copy, rotate, scale, trim, extend, etc. In CAD, these operations can be performed using commands, such as MOVE, COPY, ROTATE, SCALE, TRIM, EXTEND, etc.
- A line can be measured using various parameters, such as length, angle, distance, midpoint, etc. In CAD, these parameters can be obtained using commands, such as LENGTH, ANGLE, DISTANCE, MIDPOINT, etc.
