# Unit 5 - Introduction to Computer Aided Design

- Computer Aided Design (CAD) is a manufacturing process that allows us to digitally create 2D drawings or 3D models of future products.
- CAD helps designers and engineers visualize a product’s construction, before fabricating it.
- CAD also enables the analysis and optimization of the product’s performance, functionality, and quality.
- CAD software can be classified into two categories: 2D CAD and 3D CAD.
  - 2D CAD software allows the creation of flat drawings of products and structures.
  - 3D CAD software allows the creation of solid models that can be viewed and manipulated from any angle.
- Solid modeling is a technique of creating 3D models using geometric primitives, such as points, lines, curves, surfaces, and solids.
- Solid modeling can be used for conceptual design, detailed design, and engineering analysis.
- Solid modeling software can be further divided into two types: parametric and direct.
  - Parametric modeling software allows the user to define the dimensions and constraints of the model, and automatically updates the model when any changes are made.
  - Direct modeling software allows the user to directly manipulate the geometry of the model, without relying on predefined parameters or constraints.
- Some examples of CAD software are AutoCAD, SolidWorks, Creo Parametric, CATIA, and SketchUp .
- CAD software can be integrated with other software tools, such as computer-aided engineering (CAE), computer-aided manufacturing (CAM), and product lifecycle management (PLM), to create a complete product development system.
- CAD software can also be used for creating artistic designs, animations, simulations, and virtual reality applications.
