# Dimensioning for the notes of the Unit 1 - Introduction to Engineering Drawing and Orthographic Projections

- Dimensioning is the process of indicating the size, shape, location and other details of an object on an engineering drawing using numerical values, symbols and notes.
- Dimensioning is essential for the construction, fabrication and inspection of the object.
- Dimensioning should follow some basic principles and standards to ensure clarity, accuracy and consistency .
- Some of the principles and standards of dimensioning are:

  - Dimensions should be placed outside the view as far as possible.
  - Dimensions should be taken from visible outlines rather than from hidden lines.
  - Dimensioning to a centre line should be avoided except when the centre line passes through the centre of a hole.
  - Each feature should be dimensioned once only on a drawing.
  - Dimensions should not be duplicated or derived from other dimensions.
  - Dimensions should be aligned with the dimension lines or placed above the dimension lines.
  - Dimensions should be placed parallel to the feature being dimensioned.
  - Dimensions should be placed in the same view where the feature is clearly shown.
  - Dimensions should not cross each other or the extension lines.
  - Dimensions should be grouped together and spaced uniformly.
  - Dimensions should be placed at least 10 mm away from the object outline.
  - Dimensions should be expressed in the same unit of measurement and should not include unit symbols.
  - Dimensions should be rounded off to the nearest 0.5 mm or 0.01 inch.
  - Dimensions should be placed with respect to a datum or a reference point.
  - Dimensions should be classified into functional, non-functional and auxiliary dimensions.
  - Functional dimensions are those that are essential for the function of the object or space.
  - Non-functional dimensions are those that are not essential for the function of the object or space but may be required for aesthetic or other reasons.
  - Auxiliary dimensions are those that are used for reference or information purposes only and do not affect the function or accuracy of the object or space.
  - Dimensions should be indicated using standard symbols and abbreviations as per the ASME Y14 series of standards.
  - Dimensions should include tolerances or allowable variations to specify the acceptable range of values for the dimension.
  - Dimensions should be applied using geometrical dimensioning and tolerancing (GD&T) methods to define the form, orientation, location and runout of the features.
  - Dimensions should be verified and checked for errors and inconsistencies before finalizing the drawing.

- Dimensioning is an important skill for engineering drawing and orthographic projection as it conveys the essential information for the fabrication and inspection of the object.
