### Line
- A line is the basic element of geometry that represents the path of a moving point.
- A line has length but no thickness or width.
- A line can be straight or curved, continuous or broken, horizontal, vertical, or inclined.
- A line can be defined by two points, a point and a direction, or a slope and an intercept.
- A line can be classified into different types based on its properties, such as:

  - Parallel lines: Two or more lines that are always equidistant from each other and never intersect.
  - Perpendicular lines: Two lines that intersect at right angles (90 degrees).
  - Intersecting lines: Two or more lines that cross each other at a point.
  - Skew lines: Two or more lines that are neither parallel nor intersecting, but lie in different planes.
  - Tangent lines: A line that touches a curve at one point without crossing it.
  - Normal lines: A line that is perpendicular to a curve at the point of tangency.
  - Secant lines: A line that cuts a curve at two points.
  - Asymptotes: A line that a curve approaches infinitely but never reaches.

- A line can be represented by different equations depending on the coordinate system used, such as:

  - Cartesian coordinates: y = mx + b, where m is the slope and b is the y-intercept.
  - Polar coordinates: r = a + bθ, where a and b are constants.
  - Parametric equations: x = f(t), y = g(t), where t is a parameter.
  - Implicit equations: F(x, y) = 0, where F is a function of x and y.

- A line can be drawn using different tools and methods, such as:

  - Ruler and compass: A straight line can be drawn by connecting two points with a ruler, or by using a compass to mark equal distances from a point along a direction.
  - Freehand sketching: A line can be drawn by hand using a pencil or a pen, following the eye or a reference.
  - Computer-aided design (CAD): A line can be drawn using a software application that allows the user to specify the coordinates, direction, length, or equation of the line, and displays it on a screen or a printer. Some examples of CAD software are AutoCAD, SolidWorks, SketchUp, etc.
