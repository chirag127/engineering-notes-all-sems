### Trim

Trim is a command in Computer Aided Design (CAD) software that is used to remove unwanted portions of an object or objects. It is commonly used in the subject of Engineering Graphics & Design Lab, particularly in Unit 5 - Introduction to Computer Aided Design. Here are some key points to remember about the Trim command:

1. The Trim command can be used to remove portions of lines, arcs, circles, and other objects.
2. To use the Trim command, first select the object or objects that you want to trim.
3. Next, specify the cutting edge or edges that will be used to trim the object or objects.
4. The portion of the object or objects that is/are on the side of the cutting edge that you click will be removed.
5. The Trim command can be used in conjunction with other commands, such as Extend, to modify objects in a precise and efficient manner.

It is important to practice using the Trim command in order to become proficient in its use. This will allow you to create and modify objects in CAD software quickly and accurately.
