### Basic commands for 2D drawing for the notes of the Unit 5 - Introduction to Computer Aided Design in the subject of ENGINEERING GRAPHICS & DESIGN LAB

1. **Line**: This command is used to draw a straight line between two points.
2. **Circle**: This command is used to draw a circle with a specified center point and radius.
3. **Arc**: This command is used to draw an arc with a specified center point, radius, and start and end angles.
4. **Rectangle**: This command is used to draw a rectangle with specified corner points.
5. **Polygon**: This command is used to draw a regular polygon with a specified number of sides and center point.
6. **Ellipse**: This command is used to draw an ellipse with a specified center point, major axis, and minor axis.
7. **Hatch**: This command is used to fill an enclosed area with a pattern or solid color.
8. **Text**: This command is used to add text to the drawing.
9. **Dimension**: This command is used to add dimensions to the drawing to specify the size and location of objects.
10. **Move**: This command is used to move objects in the drawing.
11. **Copy**: This command is used to make a copy of an object in the drawing.
12. **Rotate**: This command is used to rotate an object around a specified point.
13. **Scale**: This command is used to change the size of an object.
14. **Trim**: This command is used to trim lines or curves that extend beyond a specified boundary.
15. **Extend**: This command is used to extend lines or curves to a specified boundary.
16. **Offset**: This command is used to create a parallel copy of a line or curve at a specified distance.
17. **Mirror**: This command is used to create a mirror image of an object.
18. **Array**: This command is used to create an array of objects in a rectangular or polar pattern.
19. **Fillet**: This command is used to create a rounded corner between two lines.
20. **Chamfer**: This command is used to create a beveled corner between two lines.

These are some of the basic commands for 2D drawing in Computer Aided Design. It is important to become familiar with these commands in order to create accurate and detailed drawings.
