# Conversion of Pictorial View into Orthographic Projection

Orthographic projection is a method of representing a three-dimensional object in two dimensions. It is a form of parallel projection, where the view direction is orthogonal to the projection plane, resulting in each plane of the scene appearing in affine transformation on the viewing surface.

In the context of the subject of Engineering Graphics & Design Lab, Unit 4 - Isometric Projection, the conversion of a pictorial view into an orthographic projection involves the following steps:

1. **Identify the principal planes**: The first step in converting a pictorial view into an orthographic projection is to identify the principal planes of the object. These are the planes that are parallel to the sides of the object and are used to create the front, top, and side views of the object.

2. **Project the object onto the principal planes**: Once the principal planes have been identified, the object is projected onto these planes to create the orthographic views. This is done by drawing lines perpendicular to the principal planes from each point on the object.

3. **Draw the orthographic views**: After the object has been projected onto the principal planes, the orthographic views can be drawn. These views show the object as it would appear from the front, top, and side.

4. **Add dimensions and details**: Once the orthographic views have been drawn, dimensions and other details can be added to the drawing to provide additional information about the object.

In summary, the conversion of a pictorial view into an orthographic projection involves identifying the principal planes of the object, projecting the object onto these planes, drawing the orthographic views, and adding dimensions and details to the drawing. This process allows a three-dimensional object to be represented in two dimensions, providing a clear and accurate representation of the object for use in technical drawings and other applications.
