# Unit 5 - Introduction to Computer Aided Design
## Introduction to AutoCAD

- AutoCAD is a computer-aided design (CAD) software used for creating 2D and 3D designs.
- It is developed and marketed by Autodesk Inc.
- AutoCAD is used by architects, engineers, and other professionals to create technical drawings and plans.
- It allows users to create and edit designs using a variety of tools and features.
- AutoCAD supports both 2D and 3D modeling and can be used to create detailed technical drawings, floor plans, and other design documents.
- It is widely used in industries such as architecture, engineering, construction, and manufacturing.
- AutoCAD has a range of features that allow users to create precise and accurate designs, including the ability to draw lines, arcs, circles, and other shapes, as well as the ability to add text and dimensions to drawings.
- It also has tools for creating and editing 3D models, including the ability to extrude, revolve, and sweep 2D shapes to create 3D objects.
- AutoCAD files can be exported in a variety of formats, including DWG, DXF, and PDF, allowing for easy sharing and collaboration with others.
