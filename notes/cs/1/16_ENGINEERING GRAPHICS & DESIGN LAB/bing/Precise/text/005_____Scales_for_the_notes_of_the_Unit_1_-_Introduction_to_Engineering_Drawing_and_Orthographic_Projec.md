### Scales for the notes of the Unit 1 - Introduction to Engineering Drawing and Orthographic Projections in the subject of ENGINEERING GRAPHICS & DESIGN LAB

1. **Introduction to Engineering Drawing:** Engineering drawing is a graphical language used by engineers and other technical personnel to convey technical information. It is a means of communication between the design and manufacturing stages of a product.

2. **Orthographic Projections:** Orthographic projection is a method of representing three-dimensional objects in two dimensions. It is a form of parallel projection, where the view direction is orthogonal to the projection plane.

3. **Scales:** In engineering drawing, scales are used to represent the size of an object in a drawing. The scale is the ratio of the size of the object in the drawing to its actual size. There are three types of scales commonly used in engineering drawing: full scale, reduced scale, and enlarged scale.

    - **Full Scale:** A full scale drawing is one in which the size of the object in the drawing is the same as its actual size. This type of scale is used when the object is small enough to be drawn at its actual size.

    - **Reduced Scale:** A reduced scale drawing is one in which the size of the object in the drawing is smaller than its actual size. This type of scale is used when the object is too large to be drawn at its actual size.

    - **Enlarged Scale:** An enlarged scale drawing is one in which the size of the object in the drawing is larger than its actual size. This type of scale is used when the object is too small to be drawn at its actual size.

4. **Importance of Scales:** The use of scales in engineering drawing is important because it allows the designer to accurately represent the size of the object in the drawing. This is essential for the manufacturing stage, where the drawing is used to create the actual object. The use of scales also allows the designer to convey the relative size of different parts of the object, which is important for understanding the design.
