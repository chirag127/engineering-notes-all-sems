## Unit 5 - Introduction to Computer Aided Design

- Computer Aided Design (CAD) is the use of computer software to create, modify, analyze, and optimize the design of a product or a system.
- CAD software can help engineers, architects, designers, and other professionals to produce high-quality drawings, models, simulations, and documentation of their work.
- CAD software can also facilitate collaboration, communication, and data exchange among different stakeholders involved in a design project.
- CAD software can be classified into two main categories: 2D CAD and 3D CAD.
  - 2D CAD software allows the user to create and manipulate geometric shapes, such as lines, circles, arcs, and polygons, on a flat plane. 2D CAD software is often used for drafting, sketching, and technical drawing purposes.
  - 3D CAD software allows the user to create and manipulate solid or surface models, which represent the shape and volume of an object in three dimensions. 3D CAD software is often used for modeling, rendering, animation, and analysis purposes.
- CAD software can also be specialized for different domains or applications, such as mechanical, electrical, civil, architectural, or industrial design.
- Some examples of popular CAD software are AutoCAD, SolidWorks, SketchUp, Revit, and Fusion 360.
