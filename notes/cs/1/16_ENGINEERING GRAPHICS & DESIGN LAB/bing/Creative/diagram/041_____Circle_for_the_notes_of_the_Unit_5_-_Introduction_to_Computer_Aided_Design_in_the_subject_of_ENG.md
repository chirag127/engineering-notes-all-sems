### Circle

- A circle is a closed curve that consists of all points that are equidistant from a fixed point called the center.
- A circle can be defined by its center and radius, or by three non-collinear points on the curve, or by two points and the length of the arc between them.
- A circle can be drawn in a computer aided design (CAD) software by using various commands or tools, such as:
  - Circle command: This command allows the user to specify the center and radius of the circle, or the center and a point on the circle, or three points on the circle.
  - Ellipse command: This command allows the user to draw an ellipse or a circle by specifying the center, the major axis, and the minor axis of the ellipse. If the major and minor axes are equal, the ellipse becomes a circle.
  - Polygon command: This command allows the user to draw a regular polygon or a circle by specifying the number of sides, the center, and the radius of the polygon. If the number of sides is large enough, the polygon becomes a circle.
  - Offset command: This command allows the user to create a parallel curve to an existing curve by specifying the distance and the side of the offset. If the existing curve is a circle, the offset curve will also be a circle.
  - Fillet command: This command allows the user to create a smooth transition between two intersecting lines or curves by specifying the radius of the fillet. If the radius of the fillet is equal to the distance between the intersection point and the end points of the lines or curves, the fillet will be a circle.
- A circle can be modified in a CAD software by using various commands or tools, such as:
  - Move command: This command allows the user to relocate a circle by specifying a base point and a destination point.
  - Copy command: This command allows the user to create a duplicate of a circle by specifying a base point and a destination point.
  - Rotate command: This command allows the user to rotate a circle by specifying a base point and an angle of rotation.
  - Scale command: This command allows the user to resize a circle by specifying a base point and a scale factor.
  - Trim command: This command allows the user to remove unwanted portions of a circle by specifying a cutting edge or a boundary.
  - Extend command: This command allows the user to extend a circle to meet another curve or boundary by specifying the curve or boundary to extend to.
  - Break command: This command allows the user to split a circle into two or more segments by specifying one or more points on the circle.
  - Join command: This command allows the user to combine two or more segments of a circle into a single circle by selecting the segments to join.
