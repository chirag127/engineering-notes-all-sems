## Unit 5 - Introduction to Computer Aided Design

- Computer Aided Design (CAD) is the use of computer software to create, modify, analyze, and optimize the design of a product or a system.
- CAD software can help engineers, architects, designers, and other professionals to produce high-quality drawings, models, simulations, and documentation of their work.
- CAD software can also facilitate collaboration, communication, and data exchange among different stakeholders involved in the design process.
- CAD software can be classified into two main categories: 2D CAD and 3D CAD.
  - 2D CAD software allows the user to create and manipulate geometric shapes, such as lines, circles, arcs, and polygons, on a flat plane.
  - 2D CAD software is often used for drafting, sketching, and documenting simple or schematic designs, such as floor plans, circuit diagrams, and maps.
  - 3D CAD software allows the user to create and manipulate solid or surface models, which represent the shape and volume of an object in three dimensions.
  - 3D CAD software is often used for designing, modeling, and rendering complex or realistic designs, such as mechanical parts, buildings, and products.
- CAD software can have various features and functions, depending on the specific domain and application of the user. Some of the common features and functions are:
  - Drawing tools: These are the basic tools that allow the user to create and edit geometric entities, such as points, lines, curves, and surfaces.
  - Modeling tools: These are the tools that allow the user to create and edit solid or surface models, such as extruding, revolving, lofting, sweeping, and boolean operations.
  - Editing tools: These are the tools that allow the user to modify and manipulate the existing entities, such as moving, rotating, scaling, trimming, filleting, and chamfering.
  - Dimensioning and annotation tools: These are the tools that allow the user to add and edit the dimensions, labels, notes, and symbols that describe the specifications and details of the design.
  - Analysis and simulation tools: These are the tools that allow the user to perform various calculations and tests on the design, such as stress, strain, deformation, fluid flow, heat transfer, and dynamic behavior.
  - Rendering and visualization tools: These are the tools that allow the user to generate realistic images and animations of the design, using different materials, textures, lighting, and shading effects.
  - Data management and collaboration tools: These are the tools that allow the user to organize, store, retrieve, and share the design data and files, using different formats, standards, and protocols.
