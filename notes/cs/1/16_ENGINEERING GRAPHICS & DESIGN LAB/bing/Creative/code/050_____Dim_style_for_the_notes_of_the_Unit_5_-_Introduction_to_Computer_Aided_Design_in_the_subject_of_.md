# Unit 5 - Introduction to Computer Aided Design

## Dim Style

- Dim style is a feature in AutoCAD that allows the user to create and modify the appearance of dimensions in a drawing.
- Dim style stands for dimension style and it controls the size, color, text, symbols, and placement of dimensions.
- To create a new dim style, the user can use the DIMSTYLE command or select the Dimension Style Manager from the Annotate tab of the ribbon.
- The Dimension Style Manager dialog box shows the list of existing dim styles and allows the user to create a new one, modify an existing one, or set a current one.
- To create a new dim style, the user can click on the New button and enter a name for the new style. Then, the user can modify the various properties of the new style, such as:

  - Lines: This tab controls the appearance of dimension lines, extension lines, and leader lines. The user can specify the color, linetype, lineweight, and offset of these lines.
  - Symbols and Arrows: This tab controls the appearance of dimension symbols and arrows, such as center marks, centerlines, arrowheads, and oblique strokes. The user can specify the size, color, and shape of these symbols and arrows.
  - Text: This tab controls the appearance of dimension text, such as the font, color, height, alignment, and format of the text. The user can also specify the text placement and orientation relative to the dimension line.
  - Fit: This tab controls how the dimensions fit within the available space. The user can specify the scale, spacing, and alignment of the dimensions. The user can also choose how to handle the situations when the dimension text or arrows do not fit within the dimension line.
  - Primary Units: This tab controls the units and precision of the dimension values. The user can specify the unit format, measurement system, decimal places, rounding, and prefixes and suffixes of the dimension values.
  - Alternate Units: This tab controls the display of alternate units for the dimension values. The user can specify whether to show alternate units, and if so, the unit format, measurement system, decimal places, rounding, and prefixes and suffixes of the alternate units.
  - Tolerances: This tab controls the display of tolerances for the dimension values. The user can specify whether to show tolerances, and if so, the tolerance type, precision, format, and placement of the tolerances.

- To modify an existing dim style, the user can select the dim style from the list and click on the Modify button. Then, the user can change the properties of the dim style as described above.
- To set a current dim style, the user can select the dim style from the list and click on the Set Current button. The current dim style will be applied to all the new dimensions created in the drawing.
- To apply a dim style to an existing dimension, the user can select the dimension and use the Properties palette to change the dim style property.
