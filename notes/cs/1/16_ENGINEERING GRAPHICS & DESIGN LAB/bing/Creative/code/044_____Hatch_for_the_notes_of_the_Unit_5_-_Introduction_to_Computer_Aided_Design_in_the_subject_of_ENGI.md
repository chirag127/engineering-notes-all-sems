# Hatch in Computer Aided Design

- Hatch is a command in AutoCAD that is used to fill an area of selected objects with a hatch pattern or fill.
- Hatch patterns or fills represent materials to be used and incorporated within a design, such as concrete, wood, brick, etc.
- Hatch can also be used to designate areas or room types, such as kitchen, bathroom, office, etc.
- Hatch can be applied to closed boundaries, such as circles, rectangles, polygons, etc.
- Hatch can also be applied to non-closed boundaries, such as lines, arcs, splines, etc, by using the gap tolerance option.
- Hatch can be modified by changing its properties, such as angle, scale, origin, color, layer, etc.
- Hatch can be associated or dissociated with its boundary objects, which means that if the boundary changes, the hatch will update accordingly or not .
- Hatch can be edited by using the grips, the hatch edit command, or the properties palette.
- Hatch can be created by using the hatch command from the draw menu of the home tab, or by typing HATCH in the command line.
- Hatch can be selected by using the select object option, the select hatch option, or the select similar option.
