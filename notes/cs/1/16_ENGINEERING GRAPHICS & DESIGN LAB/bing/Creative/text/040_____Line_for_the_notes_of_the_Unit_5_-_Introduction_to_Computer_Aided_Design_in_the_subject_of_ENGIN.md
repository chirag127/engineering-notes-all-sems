### Line for the notes of the Unit 5 - Introduction to Computer Aided Design in the subject of ENGINEERING GRAPHICS & DESIGN LAB

- A line is a basic element of geometry that connects two points.
- A line can be defined by its direction, length, and position in space.
- A line can also be represented by its equation, slope, and intercepts.
- In computer aided design (CAD), a line is a primitive object that can be used to create more complex shapes and structures.
- A line can be drawn in CAD using various tools and commands, such as line, polyline, arc, circle, ellipse, etc.
- A line can be modified in CAD using various operations, such as move, copy, rotate, scale, trim, extend, offset, etc.
- A line can be measured in CAD using various tools, such as distance, angle, area, perimeter, etc.
- A line can be annotated in CAD using various tools, such as text, dimension, leader, hatch, etc.
- A line can be displayed in CAD using various settings, such as color, layer, linetype, lineweight, etc.
- A line can be printed in CAD using various options, such as layout, viewport, scale, plot style, etc.
