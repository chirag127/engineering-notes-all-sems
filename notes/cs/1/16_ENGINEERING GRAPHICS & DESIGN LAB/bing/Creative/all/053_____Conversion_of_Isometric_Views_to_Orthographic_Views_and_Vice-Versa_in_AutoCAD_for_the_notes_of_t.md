# Conversion of Isometric Views to Orthographic Views and Vice-Versa in AutoCAD

- Isometric views are 2D drawings that show 3D objects with the three principal axes equally inclined to the plane of projection. They are useful for showing the overall shape and dimensions of an object in a single view.
- Orthographic views are 2D drawings that show 3D objects with the three principal axes perpendicular to the plane of projection. They are useful for showing the details and measurements of an object in multiple views.
- To convert an isometric view to an orthographic view in AutoCAD, you can use the following steps:
  - On the status bar, pick the appropriate isoplane by clicking the drop-down arrow on the Isometric Drafting status bar button ( Find).
  - To return to orthographic drawing after finishing your 2D isometric drawing, click Find in the status bar.
  - Alternatively, you can toggle the Isodraft icon on the Status Bar to switch between orthographic and isometric modes.
  - You can also use the SNAPSTYL system variable to change the snap style from 0 (orthographic) to 1 (isometric) or vice versa.
- To convert an orthographic view to an isometric view in AutoCAD, you can use the following steps:
  - On the View tab, click Viewports > New Viewports.
  - In the Viewports dialog box, select a viewport configuration from the list.
  - In the Properties panel, under Type, select Standard View.
  - Under View, select one of the predefined isometric views, such as SW Isometric, SE Isometric, NE Isometric, or NW Isometric.
  - Click OK to create the viewport with the isometric view.
  - You can also use the VIEW command to select a preset 3D view from the list or the toolbar.
