# Unit 4 - Isometric Projection

- Isometric projection is a method for visually representing three-dimensional objects in two dimensions in technical and engineering drawings.
- It is an axonometric projection in which the three coordinate axes appear equally foreshortened and the angle between any two of them is 120 degrees .
- Isometric projection is one class of orthographic projections, in which any point in the object is mapped onto the drawing by dropping a perpendicular from that point to the plane of the drawing.
- Isometric projection preserves the proportions and angles of the object, but not the actual size or shape.
- Isometric projection is useful for showing the general shape and arrangement of the object, but not the exact dimensions or details.
- Isometric projection can be drawn using a 30-degree angle from the horizontal, or by using an isometric grid of equilateral triangles.
- Isometric projection can be used to create isometric drawings or isometric views of the object, which are also called isometric pictorials.
- Isometric projection can also be used to create isometric maps, isometric video games, and isometric art.
