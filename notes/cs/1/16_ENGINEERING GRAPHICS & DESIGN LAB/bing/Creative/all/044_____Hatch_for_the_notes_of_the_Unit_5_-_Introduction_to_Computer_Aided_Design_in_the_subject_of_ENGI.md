# Unit 5 - Introduction to Computer Aided Design

## Hatch

- Hatch is a command in AutoCAD that is used to fill an area of selected objects with a hatch pattern or fill.
- Hatch patterns or fills represent materials to be used and incorporated within a design, such as concrete, brick, wood, etc.
- Hatch patterns or fills can also be used to designate areas or room types, such as office, kitchen, bathroom, etc.
- Hatch command can be accessed from the Draw menu of the Home tab in the ribbon.
- Hatch command can also be invoked by typing HATCH or BH in the command line.
- Hatch command has various options and settings, such as:

  - Pattern: allows the user to choose from predefined or custom hatch patterns or fills.
  - Angle: allows the user to specify the angle of the hatch pattern or fill.
  - Scale: allows the user to specify the scale of the hatch pattern or fill.
  - Origin: allows the user to specify the origin point of the hatch pattern or fill.
  - Transparency: allows the user to specify the transparency level of the hatch pattern or fill.
  - Gap tolerance: allows the user to specify the maximum gap size that can be ignored when hatching an area.
  - Associative: allows the user to link the hatch pattern or fill to the boundary objects, so that the hatch updates automatically when the boundary changes .
  - Annotative: allows the user to create an annotative hatch pattern or fill, which can be scaled automatically according to the annotation scale.
  - Inherit properties: allows the user to apply the same hatch properties as the previously created hatch.
  - Select objects: allows the user to select the objects that define the boundary of the hatch area.
  - Pick points: allows the user to pick points inside the boundary of the hatch area.
  - Add: allows the user to add more objects or points to the hatch area.
  - Remove: allows the user to remove objects or points from the hatch area.
  - Preview: allows the user to preview the hatch pattern or fill before applying it.
  - Apply: allows the user to apply the hatch pattern or fill to the selected area.

- Hatch command can be modified or edited by using the HATCHEDIT or HE command, which allows the user to change the hatch properties, such as pattern, angle, scale, origin, transparency, gap tolerance, associative, and annotative.
- Hatch command can be deleted by using the ERASE or E command, which allows the user to erase the selected hatch pattern or fill.
- Hatch command can be used to create complex and realistic designs, such as floor plans, elevations, sections, etc .
- Hatch command can be used to comply with the computer-aided design standards, such as the United States National CAD Standard® (NCS), which set mandatory procedures for architects/engineers (A/Es) to follow for the creation and delivery of all CAD drawings to GSA.
