# Unit 5 - Introduction to Computer Aided Design

- Computer Aided Design (CAD) is the use of computer software to design and document a product's design process .
- CAD software can help create, modify, analyze, and optimize a design, as well as improve the quality, productivity, and communication of the designer  .
- CAD software can also create a database for manufacturing, which can be used to plan, manage, and control the production operations .
- CAD software can be classified into two types: 2D CAD and 3D CAD.
  - 2D CAD software uses graphical symbols such as points, lines, curves, and shapes to represent the geometry of a design in a two-dimensional plane.
  - 3D CAD software uses solid modeling, surface modeling, or wireframe modeling to represent the geometry of a design in a three-dimensional space.
- CAD software can be used for various applications, such as mechanical engineering, civil engineering, architecture, electrical engineering, and industrial design.
- Some examples of popular CAD software are AutoCAD, SolidWorks, CATIA, Pro/ENGINEER, and SketchUp.
