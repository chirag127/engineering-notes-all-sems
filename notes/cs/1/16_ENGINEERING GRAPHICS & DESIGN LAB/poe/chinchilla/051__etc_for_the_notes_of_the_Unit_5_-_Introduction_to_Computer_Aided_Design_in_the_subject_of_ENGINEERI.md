### Unit 5: Introduction to Computer Aided Design (CAD)

In this unit, you will learn about Computer Aided Design (CAD) and its applications in the field of Engineering Graphics and Design. CAD is a software tool that is extensively used in product design, architectural design, and engineering analysis. It allows designers and engineers to create, modify, and analyze 2D and 3D models with ease and precision. 

The following are the key topics covered in this unit:

#### 1. Introduction to CAD
- Definition of CAD
- Advantages of using CAD over manual drafting
- Applications of CAD in the field of Engineering Graphics and Design
- Types of CAD software available in the market

#### 2. Basic CAD Commands and Tools
- Understanding the CAD user interface
- Creating, saving, and opening a new file
- Drawing and editing 2D geometries using basic CAD commands such as line, circle, arc, and rectangle
- Modifying geometries using commands such as trim, extend, and fillet
- Zooming and panning the drawing area
- Using layers to organize the drawing

#### 3. Advanced CAD Commands and Tools
- Creating and editing 3D models using commands such as extrude, revolve, and sweep
- Adding dimensions and annotations to the drawing
- Generating 2D drawings from 3D models
- Using parametric modeling to create models that can be modified easily

#### 4. CAD Applications in Engineering Graphics and Design
- Creating 2D and 3D models of machine parts and assemblies
- Creating architectural floor plans, elevations, and sections
- Analyzing stress and strain on mechanical and structural components
- Simulating fluid flow and heat transfer in industrial processes
- Creating photorealistic renderings of products and buildings

#### 5. CAD File Management and Collaboration
- Saving and sharing CAD files using cloud-based storage and file sharing services
- Collaborating with team members using online CAD tools and platforms
- Understanding the importance of version control and file naming conventions

In conclusion, CAD is an essential tool for modern-day engineering and design professionals. This unit provides an introduction to the basic and advanced CAD commands and tools, as well as their applications in the field of Engineering Graphics and Design. With this knowledge, you will be able to create and modify 2D and 3D models with precision and efficiency, and collaborate with team members using online CAD tools and platforms.
