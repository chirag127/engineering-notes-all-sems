### Trim for the notes of the Unit 5 - Introduction to Computer Aided Design in the subject of ENGINEERING GRAPHICS & DESIGN LAB

Computer Aided Design (CAD) is a software used in creating designs for a wide range of applications. It allows for the creation, modification, and optimization of products and designs, and is used extensively in the fields of engineering, architecture, and industrial design. In this unit, we will be focusing on the use of CAD software in engineering graphics and design.

Here are some key points to keep in mind when studying this unit:

1. Introduction to CAD: The first step is to understand the basics of CAD software. This includes learning about the interface, commands, and tools available in the software. It is important to become familiar with the software before attempting to create any designs.

2. Creating 2D Drawings: CAD software allows for the creation of 2D drawings, which are used extensively in engineering graphics. This involves creating and manipulating lines, circles, arcs, and other fundamental shapes to create a detailed drawing.

3. Creating 3D Models: CAD software also allows for the creation of 3D models, which are used in various applications such as product design, architecture, and engineering. This involves creating solid and surface models, and manipulating them to create a detailed 3D representation of the design.

4. Using Constraints: Constraints are used to maintain the relationship between various elements in the design. This ensures that the design remains consistent and accurate throughout the design process.

5. Rendering and Visualization: CAD software allows for the creation of realistic renderings and visualizations of the design. This is useful in presenting the design to clients or stakeholders, and can aid in the design process by providing a better understanding of the final product.

6. Integration with Other Software: CAD software can be integrated with other software such as simulation software, analysis software, and CAM software. This allows for a more streamlined design process and can aid in the optimization of the design.

7. File Formats: CAD software uses various file formats for saving and transferring designs. It is important to become familiar with these file formats, and to ensure that the correct format is used when transferring designs between different software.

By understanding these key points, you will be able to effectively use CAD software in engineering graphics and design. Practice and experimentation are also important in becoming proficient in CAD software, so be sure to spend time exploring the software and trying out different commands and tools.
