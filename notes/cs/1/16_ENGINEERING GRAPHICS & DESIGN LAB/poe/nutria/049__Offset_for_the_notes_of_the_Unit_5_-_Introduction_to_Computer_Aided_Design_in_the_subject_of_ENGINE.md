
### Offset for the notes of the Unit 5 - Introduction to Computer Aided Design in the subject of ENGINEERING GRAPHICS & DESIGN LAB

* Offset is a Computer Aided Design (CAD) technique used to create a copy of an object at a specified distance from the original object.
* Offset can be used to create a copy of an object that is either larger or smaller than the original object.
* Offset can also be used to create an object with a different shape than the original object, by offsetting the original object in different directions.
* Offset can also be used to create objects with curved edges, such as circles and arcs.
* Offset can be used to create symmetrical shapes, such as squares, rectangles, and polygons.
* Offset can be used to create objects with multiple layers, such as three-dimensional objects.
