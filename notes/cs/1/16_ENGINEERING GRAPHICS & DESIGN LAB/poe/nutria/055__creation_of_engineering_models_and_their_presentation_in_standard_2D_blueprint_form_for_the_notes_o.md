
### Creation of Engineering Models and Their Presentation in Standard 2D Blueprint Form

1. Computer Aided Design (CAD) is a method of creating engineering models and drawings using computer software.
2. CAD software can be used to create models in three dimensions (3D) and two dimensions (2D).
3. 2D CAD models are used to create technical drawings, such as blueprints, which are used to communicate design ideas to engineers, manufacturers, and other stakeholders.
4. CAD software can also be used to create 3D models of components, which can be used to simulate the performance of the components in the real world.
5. CAD software is used in many engineering disciplines, including mechanical, electrical, and civil engineering.
6. In order to create a 2D blueprint, the user must first create a 3D model of the component or assembly.
7. The 3D model is then converted into a 2D drawing using the CAD software.
8. The 2D drawing is then used to create a blueprint, which is a technical drawing of the component or assembly in a standard format.
9. The blueprint is used to communicate the design of a component or assembly to engineers, manufacturers, and other stakeholders.
