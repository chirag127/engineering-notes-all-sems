### Basic Commands for 2D Drawing

In computer-aided design (CAD), 2D drawing is one of the basic skills that you need to master. Here are some of the basic commands that you should know to create accurate and precise 2D drawings:

1. Line command: This command is used to draw straight lines. To use this command, type "LINE" in the command prompt, then specify the starting point and ending point of the line.

2. Circle command: This command is used to draw circles. To use this command, type "CIRCLE" in the command prompt, then specify the center point and radius of the circle.

3. Arc command: This command is used to draw arcs. To use this command, type "ARC" in the command prompt, then specify the center point, start point, and end point of the arc.

4. Rectangle command: This command is used to draw rectangles. To use this command, type "RECTANGLE" in the command prompt, then specify two diagonal corners of the rectangle.

5. Polygon command: This command is used to draw regular polygons. To use this command, type "POLYGON" in the command prompt, then specify the number of sides, center point, and radius of the polygon.

6. Ellipse command: This command is used to draw ellipses. To use this command, type "ELLIPSE" in the command prompt, then specify the center point, major axis, and minor axis of the ellipse.

7. Hatch command: This command is used to fill an enclosed area with a pattern or color. To use this command, type "HATCH" in the command prompt, then specify the boundary of the area to be filled and the hatch pattern or color.

8. Dimension command: This command is used to add dimensions to the drawing. To use this command, type "DIMENSION" in the command prompt, then specify the objects to be dimensioned and the location of the dimension lines and text.

9. Text command: This command is used to add text to the drawing. To use this command, type "TEXT" in the command prompt, then specify the insertion point and the text string.

By mastering these basic commands, you will be able to create accurate and precise 2D drawings in CAD. Practice using these commands to improve your skills and efficiency in CAD.
