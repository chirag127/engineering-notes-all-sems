1. Computer Aided Design (CAD) is the use of computer systems to aid in the creation, modification, analysis, or optimization of a design. CAD software is used to increase the productivity of the designer, improve the quality of design, improve communications through documentation, and to create a database for manufacturing.

2. Some of the common CAD software packages are:
- AutoCAD
- SolidWorks
- CATIA
- Fusion 360
- FreeCAD

3. The basic components of a CAD system are:
- The graphics input devices like mouse, digitizer, touch screens, etc.
- The central processing unit (CPU) to carry out the operations
- The memory to store programs and data
- The display devices like monitors or plotters to display the output
- The software to enable the user to visualize and modify the design

 4. The steps involved in CAD are:
1. Draw the 2D sketch of the object.
2. Use the sketch to create 3D models.
3. Assemble the components into sub-assemblies and complete products.
4. Analyze the design for strength, kinematics, etc.
5. Make manufacturing drawings and plans.

5. The advantages of CAD are:
- Increased productivity
- Improved design quality
- Easier modification and version control
- Better documentation
- Support for automation and manufacturing
