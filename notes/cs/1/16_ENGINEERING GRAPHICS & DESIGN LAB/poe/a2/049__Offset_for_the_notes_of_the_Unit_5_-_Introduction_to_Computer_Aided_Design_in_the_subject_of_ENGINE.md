1. Introduction
- CAD stands for Computer-Aided Design.
- CAD software is used to create technical drawings of physical products.
- CAD replaces manual drafting with an automated process.
- CAD software offers more precision and efficiency than manual drafting.

2. Uses of CAD
- CAD is used in various industries like architecture, manufacturing, automotive, shipbuilding, aerospace, etc.
- CAD is used to design and develop new products and also modify existing product designs.
- CAD designs can be easily modified, thereby reducing rework and wasted effort.
- CAD models can be simulated and analyzed to detect and fix errors early in the design process.

3. Components of CAD Software
- The major components of CAD software are:
- Drawing tools to create shapes like lines, circles, arcs, etc.
- Modification tools to manipulate drawn shapes.
- Layering tools to organize drawings.
- Annotation tools to add dimensions and notes.
- Formatting and templating tools.
- Output options like printing and converting to different file formats.
