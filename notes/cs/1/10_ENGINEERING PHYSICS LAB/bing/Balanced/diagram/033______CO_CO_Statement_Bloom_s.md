#### CO CO Statement Bloom’s

- CO stands for Course Outcomes, which are the specific learning objectives that students should achieve by the end of a course.
- CO statements are written using action verbs that describe the observable and measurable behaviors that students should demonstrate after completing the course.
- Bloom's taxonomy is a framework that classifies the cognitive skills and processes involved in learning, from the lowest to the highest level.
- Bloom's taxonomy consists of six levels: remember, understand, apply, analyze, evaluate, and create. Each level has a set of verbs that can be used to write CO statements.
- The revised version of Bloom's taxonomy also includes four types of knowledge: factual, conceptual, procedural, and metacognitive.
- Writing CO statements using Bloom's taxonomy helps teachers to align the course content, activities, and assessments with the intended learning outcomes.
- Mapping CO statements with Program Outcomes (POs) helps to ensure that the course contributes to the overall goals and objectives of the program.
- An example of a CO statement using Bloom's taxonomy is:

  - CO1: Apply the principles of object-oriented programming to design and implement software solutions. (Apply, Procedural)
  - CO2: Analyze the requirements and specifications of a software project and select appropriate tools and techniques. (Analyze, Conceptual)
  - CO3: Evaluate the quality and performance of software systems using various testing and debugging methods. (Evaluate, Factual)
  - CO4: Create and document software artifacts using standard notations and formats. (Create, Metacognitive)
