### Concept of Linearity for the notes of the Unit 1 - DC Circuits

1. A linear system is one in which the output is directly proportional to the input. This means that if the input is doubled, the output is also doubled and if the input is halved, the output is also halved.
2. For a linear system, the output-input relationship can be represented by a straight line graph. The slope of the line is the gain (multiplier) of the system.
3. An important property of linear systems is that the output is the "sum" of the responses to each input separately. For example, if an input has two components (say, x(t) = x1(t) + x2(t)), the output will be the sum of the responses to each component separately (y(t) = y1(t) + y2(t)).
4. In linear circuits, the current and voltage relationships can be represented by straight line graphs. As the input voltage or current changes, the output voltage or current changes in direct proportion. The proportionality constant is the resistance or conductance of the element.
5. Linear elements in circuits include resistors, capacitors and inductors with unchanging parameter values. Diodes and transistors are nonlinear elements as their current-voltage relationships are not straight lines.
6. Analysis of linear circuits is simpler than analysis of nonlinear circuits. Superposition theorem can be applied to solve complex linear circuits. These methods cannot be applied to nonlinear circuits.
