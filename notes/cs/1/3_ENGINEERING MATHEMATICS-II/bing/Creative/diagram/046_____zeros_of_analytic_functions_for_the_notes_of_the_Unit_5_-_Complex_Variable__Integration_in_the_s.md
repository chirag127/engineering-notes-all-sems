### Zeros of Analytic Functions

- An analytic function is a complex function that is differentiable at every point of its domain. An analytic function can be represented by a power series around any point in its domain.
- A zero of an analytic function is a point where the function vanishes, or its value becomes zero. For example, the function f(z) = z^2 - 1 has zeros at z = ±1.
- The zeros of an analytic function are isolated, meaning that there is a neighborhood around each zero where the function has no other zeros. This is a consequence of the identity theorem, which states that if two analytic functions agree on a set that has a limit point, then they agree everywhere in their common domain.
- The order or multiplicity of a zero is the number of times that the function can be differentiated at that point before it becomes nonzero. For example, the function f(z) = (z - 1)^3 has a zero of order 3 at z = 1.
- The zeros of an analytic function can be counted by using the argument principle, which relates the change in the argument of a function along a closed contour to the number of zeros and poles (singularities) inside the contour. The argument principle states that if f is an analytic function on a simply connected domain D, and C is a positively oriented simple closed contour in D that does not pass through any zero or pole of f, then

  $$\frac{1}{2\pi i}\int_C \frac{f'(z)}{f(z)} dz = N - P$$

  where N is the number of zeros of f inside C, counted with multiplicity, and P is the number of poles of f inside C, counted with multiplicity.
- The zeros of an analytic function can also be located by using Rouche's theorem, which states that if f and g are analytic functions on a domain D, and C is a simple closed contour in D such that |f(z) - g(z)| < |f(z)| for all z on C, then f and g have the same number of zeros inside C, counted with multiplicity.
