# Zeros of Analytic Functions

- An **analytic function** is a complex function that is differentiable at each point of its domain in the complex plane .
- A **zero** of an analytic function is a point at which the function vanishes, or its value becomes zero, which is analogous to the zero of a real polynomial function .
- The zeros of an analytic function are **isolated**, unless the function is identically zero. This means that around each zero, there is a neighborhood where the function has no other zeros except possibly at the point itself  .
- The **multiplicity** of a zero of an analytic function is the number of times the function can be factored as a product of the form $(z-z_0)^m f(z)$, where $f(z)$ is an analytic function that does not vanish at $z_0$ .
- The **order** of an analytic function at a zero is the smallest positive integer $n$ such that the $n$-th derivative of the function at the zero is nonzero.
- The **identity theorem** states that if two analytic functions agree on a set that has a limit point, then they are equal on their entire domain of definition.
- The **principle of permanence** states that if an analytic function is equal to a polynomial on a set that has a limit point, then the function is equal to that polynomial on its entire domain of definition.
- The **factorization theorem** states that any non-constant analytic function can be written as a product of a constant, a power of the exponential function, and a finite or infinite number of linear factors, each corresponding to a zero of the function.
