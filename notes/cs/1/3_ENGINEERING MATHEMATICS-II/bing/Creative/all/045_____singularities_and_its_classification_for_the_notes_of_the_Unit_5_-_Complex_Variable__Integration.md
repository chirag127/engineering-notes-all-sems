# Singularities and its classification

- A singularity is a point in the domain of a complex function where the function fails to be analytic.
- A function is analytic at a point if it has a convergent power series expansion in some neighborhood of that point.
- Singularities are classified into different types according to the behavior of the function near the singularity.
- The main types of singularities are:

  - Isolated singularities: These are points where the function is not analytic, but there exists a neighborhood of the point where the function is analytic everywhere else. Isolated singularities can be further classified into:

    - Removable singularities: These are points where the function is not analytic, but can be made analytic by defining or redefining the value of the function at that point. For example, the function $f(z) = \frac{\sin z}{z}$ has a removable singularity at $z = 0$, because $\lim_{z \to 0} f(z) = 1$, so we can define $f(0) = 1$ and make the function analytic at $z = 0$.
    - Poles: These are points where the function is not analytic, and the absolute value of the function tends to infinity as the point is approached. For example, the function $f(z) = \frac{1}{z}$ has a pole at $z = 0$, because $|f(z)| \to \infty$ as $z \to 0$. Poles can have different orders, depending on how fast the function grows near the pole. The order of a pole is the smallest positive integer $n$ such that the function $f(z)(z - z_0)^n$ is analytic and nonzero at $z = z_0$, where $z_0$ is the location of the pole. For example, the function $f(z) = \frac{1}{z^2}$ has a pole of order 2 at $z = 0$, because $f(z)z^2 = 1$ is analytic and nonzero at $z = 0$.
    - Essential singularities: These are points where the function is not analytic, and the behavior of the function near the point is neither bounded nor unbounded. For example, the function $f(z) = e^{1/z}$ has an essential singularity at $z = 0$, because $f(z)$ takes on every complex value infinitely often, except for zero, as $z \to 0$.

  - Nonisolated singularities: These are points where the function is not analytic, and there is no neighborhood of the point where the function is analytic everywhere else. For example, the function $f(z) = \frac{1}{\sin \frac{1}{z}}$ has a nonisolated singularity at $z = 0$, because there are infinitely many other points in any neighborhood of $z = 0$ where the function is not analytic. Nonisolated singularities can be further classified into:

    - Branch points: These are points where the function is not analytic, but can be made analytic by choosing a branch of the function. A branch of a function is a single-valued function that is analytic on a domain that contains the point. For example, the function $f(z) = \sqrt{z}$ has a branch point at $z = 0$, because $f(z)$ is not analytic at $z = 0$, but can be made analytic by choosing a branch cut and a branch of the square root function. A branch cut is a curve that starts at the branch point and extends to infinity, such that the function is analytic on either side of the cut, but not across it. A branch of the square root function is a function that assigns a single value of the square root to each point in the domain, such as the principal branch that takes the positive real part of the square root.
