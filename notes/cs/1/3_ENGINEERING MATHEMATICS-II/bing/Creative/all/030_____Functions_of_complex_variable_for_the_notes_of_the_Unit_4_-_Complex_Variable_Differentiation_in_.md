# Functions of complex variable

- A complex function is a function that maps complex numbers to complex numbers.
- A complex number is a number of the form z = x + iy, where x and y are real numbers and i is the imaginary unit, such that i^2^ = -1.
- A complex function can be written as w = u + iv, where u and v are real-valued functions of x and y.
- A complex function can also be written as w = f(z), where f is a rule that assigns a complex number w to each complex number z in its domain.
- The domain of a complex function is the set of complex numbers for which the function is defined.
- The range of a complex function is the set of complex numbers that the function can take as values.
- A complex function can be visualized as a mapping from the complex plane (the set of all complex numbers) to another complex plane.
- A complex function can be represented by a graph, which is a surface in a four-dimensional space with coordinates (x, y, u, v).
- A complex function can be analyzed using tools from calculus, such as limits, derivatives, integrals, series, and residues.
- A complex function is said to be holomorphic or analytic if it is differentiable at every point in its domain.
- A complex function is said to be entire if it is holomorphic on the entire complex plane.
- A complex function is said to be meromorphic if it is holomorphic on the complex plane except for a set of isolated points called poles, where the function becomes infinite.
- A complex function is said to be harmonic if its real and imaginary parts are harmonic functions, that is, they satisfy Laplace's equation.
- A complex function is said to be conformal if it preserves angles between curves at every point in its domain.
- A complex function is said to be biholomorphic or conformal if it is holomorphic and has a holomorphic inverse. Such a function maps one complex plane onto another in a one-to-one and conformal manner.
