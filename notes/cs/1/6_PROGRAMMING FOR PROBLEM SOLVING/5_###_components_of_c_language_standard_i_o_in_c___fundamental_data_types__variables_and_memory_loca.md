### Components of C Language. Standard I/O in C , Fundamental Data types, Variables and Memory Locations, Storage Classes.

C is a high-level programming language that is widely used for system programming, embedded systems, and game development. In C, the following components are used to build programs:

1. Standard I/O: C provides standard input/output functions for reading from and writing to the keyboard and screen. These functions include printf() and scanf().

2. Fundamental Data Types: C provides several fundamental data types, including int, char, float, and double, which are used to declare variables and store data.

3. Variables and Memory Locations: In C, variables are used to store data. Each variable is assigned a memory location, where its value is stored.

4. Storage Classes: C provides several storage classes, including auto, static, extern, and register, which determine the scope and lifetime of variables.

Understanding these components is essential for students pursuing computer science degrees, as it forms the basis for many advanced topics in programming and computer science.
