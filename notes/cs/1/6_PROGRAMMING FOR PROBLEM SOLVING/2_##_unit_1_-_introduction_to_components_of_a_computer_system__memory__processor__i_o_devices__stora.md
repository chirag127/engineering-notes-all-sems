## Unit 1 - Introduction to Components of a Computer System: Memory, Processor, I/O Devices, Storage, Operating System, Concept of Assembler, Compiler, Interpreter, Loader and Linker.

Unit 1 - Introduction to Components of a Computer System:
A computer system is composed of several components that work together to perform tasks. The main components of a computer system are:

- Memory: A type of computer storage that holds data temporarily while it is being processed by the processor.
- Processor: The central processing unit of a computer that performs arithmetic, logical, and control operations on data.
- I/O Devices: Devices that allow data to be input into and output from a computer, such as a keyboard, mouse, monitor, and printer.
- Storage: A type of computer storage that holds data permanently, such as hard disk drives, solid-state drives, and optical drives.
- Operating System: A type of software that manages the resources of a computer and provides an interface between the user and the computer hardware.
- Assembler: A type of computer program that converts assembly language code into machine code.
- Compiler: A type of computer program that converts high-level language code into machine code.
- Interpreter: A type of computer program that executes high-level language code directly, without compiling it into machine code.
- Loader: A type of computer program that loads executable code into memory for execution.
- Linker: A type of computer program that combines multiple object files into a single executable file.

Each component of a computer system has a specific function and works together to perform tasks. The processor and memory work together to execute instructions, the I/O devices allow data to be input and output, the storage holds data permanently, and the operating system manages the resources of the computer. The assembler, compiler, interpreter, loader, and linker are types of software that help to convert and execute code.
