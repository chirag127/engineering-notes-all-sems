### Basic of Searching and Sorting Algorithms: Searching & Sorting Algorithms

In computer science, searching and sorting algorithms are fundamental concepts that are used to solve many problems. Here are some basic concepts and algorithms related to searching and sorting:

#### Searching Algorithms

1. Linear Search:
   - Also known as sequential search.
   - It checks every element in the list until the desired element is found.
   - The time complexity of this algorithm is O(n).
   
2. Binary Search:
   - Also known as logarithmic search.
   - It is used to search for an element in a sorted array.
   - The algorithm divides the array in half and repeatedly compares the middle element with the target element.
   - The time complexity of this algorithm is O(log n).

#### Sorting Algorithms

1. Bubble Sort:
   - It is a simple sorting algorithm that repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order.
   - The time complexity of this algorithm is O(n^2).
   
2. Insertion Sort:
   - It is a simple sorting algorithm that builds the final sorted array one item at a time.
   - It iterates through the list and for each element, finds the correct position in the sorted part of the list and inserts it there.
   - The time complexity of this algorithm is O(n^2).
   
3. Selection Sort:
   - It is a simple sorting algorithm that selects the smallest element from the unsorted part of the list and swaps it with the first element.
   - It then repeats the process with the remaining unsorted part of the list.
   - The time complexity of this algorithm is O(n^2).

Understanding these fundamental searching and sorting algorithms is essential for computer science students and professionals. By mastering these algorithms, you will be able to solve a wide range of problems and develop efficient solutions.
