## Unit 1 - Introduction to Components of a Computer System: Memory, Processor, I/O Devices, Storage, Operating System, Concept of Assembler, Compiler, Interpreter, Loader and Linker.

**Memory:** Stores data and instructions temporarily for processing by CPU. Types: RAM, ROM, Cache Memory.

**Processor (CPU):** Executes program instructions. Performs basic arithmetic, logical, and control operations. Consists of Control Unit and ALU.

**Input/Output (I/O) Devices:** Used to input data and instructions into computer and output the results. Examples: Keyboard, Mouse, Printer, Monitor, etc.

**Storage:** Used to store data and instructions permanently. Examples: Hard Drive, SSD, Pen Drive, etc.

**Operating System:** System software that acts as an interface between user and the hardware. Performs tasks like file management, memory management, process management, handling I/O operations, etc. Examples: Windows, Linux, macOS, etc.

**Assembler:** Converts assembly language programs into machine language instructions.

**Compiler:** Converts high-level language programs into machine language instructions.

**Interpreter:** Executes instructions of a high-level language program line by line at a time.

**Loader:** Loads the machine language instructions into memory and prepares the program for execution.

**Linker:** Combines two or more object modules and resolves references between them to generate an executable file.
