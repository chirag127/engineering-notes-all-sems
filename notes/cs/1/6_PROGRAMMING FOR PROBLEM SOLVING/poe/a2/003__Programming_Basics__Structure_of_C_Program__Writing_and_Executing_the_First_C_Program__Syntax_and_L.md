### Programming Basics:

1. Structure of C Program
- Include preprocessor directives
- Function declaration
- Main function
- Other function definitions

2. Writing and Executing the First C Program
- Write a program to print "Hello World!"
- Save the file with .c extension
- Compile using gcc compiler
- Run the executable file

3. Syntax and Logical Errors in Compilation
- Syntax errors: Mistakes in following programming language syntax like misspelled variable or function name, missing semicolon, unmatched brackets, etc.
- Logical errors: Program compiles successfully but does not produce desired output due to flawed logic. Also known as bugs.

4. Object and Executable Code
- The code written in C is called source code
- The output of compiler is object code or machine language instructions
- Linking object codes of functions produces executable code that can be run on system
