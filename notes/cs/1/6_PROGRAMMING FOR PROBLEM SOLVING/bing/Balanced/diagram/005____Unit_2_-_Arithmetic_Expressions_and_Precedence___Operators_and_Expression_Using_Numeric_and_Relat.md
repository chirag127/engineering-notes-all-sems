## Unit 2 - Arithmetic Expressions and Precedence

- Operators are symbols that perform operations on one or more operands. Operands are the values or variables that the operators act on.
- Expressions are combinations of operators and operands that produce a result. For example, `2 + 3 * 4` is an expression that evaluates to `14`.
- There are different types of operators in Java, such as arithmetic, relational, logical, bitwise, and assignment operators. Each operator has a specific meaning and a precedence level that determines the order of evaluation in an expression.
- Arithmetic operators perform basic mathematical operations on numeric operands, such as addition, subtraction, multiplication, division, and modulus. The modulus operator (`%`) returns the remainder of the division of two operands. For example, `5 % 2` evaluates to `1`.
- Relational operators compare two operands and return a boolean value (`true` or `false`) based on the result of the comparison. The relational operators are: `==` (equal to), `!=` (not equal to), `<` (less than), `>` (greater than), `<=` (less than or equal to), and `>=` (greater than or equal to). For example, `3 < 4` evaluates to `true`.
- Mixed operands are operands of different types in an expression. For example, `3 + 4.5` is an expression with mixed operands of type `int` and `double`. Java performs implicit type conversion to make the operands compatible before applying the operator. In this case, the `int` operand is converted to `double` and the result is also of type `double`.
- Type conversion is the process of changing the type of a value or a variable. There are two types of type conversion: implicit and explicit. Implicit type conversion is done automatically by the compiler when the types are compatible and no information is lost. Explicit type conversion is done by the programmer using a cast operator, which is a parenthesis with the desired type. For example, `(int) 4.5` is an explicit type conversion that converts the `double` value to `int` and truncates the decimal part.
- Logical operators perform boolean operations on boolean operands or expressions, such as conjunction, disjunction, negation, and conditional. The logical operators are: `&&` (logical AND), `||` (logical OR), `!` (logical NOT), `^` (logical XOR), `&` (boolean AND), `|` (boolean OR), and `? :` (ternary operator). For example, `true && false` evaluates to `false`.
- Bitwise operators perform bit-level operations on integer operands, such as shifting, complementing, and masking. The bitwise operators are: `<<` (left shift), `>>` (right shift), `>>>` (unsigned right shift), `~` (bitwise complement), `&` (bitwise AND), `|` (bitwise OR), `^` (bitwise XOR), and `&=` (bitwise AND assignment). For example, `5 << 2` evaluates to `20`, which is the result of shifting the binary representation of `5` (`00000101`) two bits to the left and filling the vacated bits with zeros (`00010100`).
- Assignment operator (`=`) assigns the value of the right operand to the variable on the left operand. For example, `int x = 10;` assigns the value `10` to the variable `x` of type `int`. There are also compound assignment operators that combine an arithmetic or bitwise operator with the assignment operator, such as `+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`, `>>>=`, `&=`, `|=`, and `^=`. For example, `x += 5;` is equivalent to `x = x + 5;`.
- Operator precedence and associativity determine the order of evaluation of operators and operands in an expression. Precedence is the priority of an operator over another in an expression. Associativity is the direction of evaluation of operators with the same precedence in an expression. Operators with higher precedence are evaluated before operators with lower precedence. Operators with the same precedence are evaluated according to their associativity, which can be either left-to-right or right-to-left.
