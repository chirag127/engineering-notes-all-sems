### Basic of searching and sorting algorithms

Searching and sorting algorithms are fundamental techniques for manipulating data in a computer program. They are widely used in various applications, such as databases, web search engines, cryptography, and artificial intelligence.

Searching algorithms are methods for finding a specific element or a set of elements that satisfy some criteria in a collection of data, such as an array, a list, or a tree. Sorting algorithms are methods for arranging the elements of a collection in a specific order, such as ascending, descending, or lexicographic.

There are many different searching and sorting algorithms, each with different advantages and disadvantages in terms of time complexity, space complexity, stability, and adaptability. Some of the most common and basic searching and sorting algorithms are:

- Linear search: A simple and brute-force method for searching an element in an array or a list by checking each element sequentially until a match is found or the end of the collection is reached. It has a time complexity of O(n), where n is the number of elements in the collection, and a space complexity of O(1), since it does not require any extra memory. It is easy to implement and works for any type of data, but it is inefficient for large or sorted collections.

- Binary search: A fast and efficient method for searching an element in a sorted array or a list by repeatedly dividing the collection into two halves and comparing the middle element with the target element. If the target element is equal to the middle element, the search is successful. If the target element is smaller than the middle element, the search continues in the left half. If the target element is larger than the middle element, the search continues in the right half. It has a time complexity of O(log n), where n is the number of elements in the collection, and a space complexity of O(1), since it does not require any extra memory. It is more efficient than linear search for large or sorted collections, but it requires the collection to be sorted in advance and it does not work for dynamic or unbounded collections.

- Bubble sort: A simple and intuitive method for sorting an array or a list by repeatedly swapping adjacent elements that are out of order until the collection is sorted. It has a time complexity of O(n^2), where n is the number of elements in the collection, and a space complexity of O(1), since it does not require any extra memory. It is easy to implement and stable, meaning that it preserves the relative order of equal elements, but it is inefficient and slow for large or nearly sorted collections.

- Insertion sort: A simple and adaptive method for sorting an array or a list by inserting each element into its correct position in a sorted subarray or sublist that grows from left to right. It has a time complexity of O(n^2) in the worst case, where n is the number of elements in the collection, and O(n) in the best case, when the collection is already sorted. It has a space complexity of O(1), since it does not require any extra memory. It is easy to implement and stable, and it works well for small or nearly sorted collections, but it is inefficient and slow for large or reverse sorted collections.

- Selection sort: A simple and in-place method for sorting an array or a list by repeatedly finding the minimum or maximum element in the unsorted part of the collection and swapping it with the first element of the unsorted part, until the collection is sorted. It has a time complexity of O(n^2), where n is the number of elements in the collection, and a space complexity of O(1), since it does not require any extra memory. It is easy to implement and does not depend on the initial order of the collection, but it is inefficient and slow for large or nearly sorted collections, and it is unstable, meaning that it may change the relative order of equal elements.
