### Idea of Algorithm: Representation of Algorithm, Flowchart, Pseudo Code with Examples, From Algorithms to Programs, Source Code

- An algorithm is a step-by-step procedure to solve a problem or achieve a goal.
- An algorithm can be represented in different ways, such as flowchart, pseudo code, or natural language.
- A flowchart is a graphical representation of an algorithm using symbols and arrows to show the flow of control and data.
- A pseudo code is a textual representation of an algorithm using a mixture of natural language and programming constructs.
- An example of a flowchart and a pseudo code for finding the maximum of three numbers is shown below:

![flowchart](https://i.imgur.com/0QJ0y1f.png)

```
//pseudo code
Input a, b, c
If a > b and a > c then
  max = a
Else if b > a and b > c then
  max = b
Else
  max = c
End if
Output max
```

- An algorithm can be converted into a program by implementing it in a programming language.
- A programming language is a set of rules and symbols that can be used to create instructions for a computer.
- A program is a set of instructions that can be executed by a computer to perform a specific task.
- A source code is a program written in a programming language that can be read and modified by humans.
- An example of a source code in Python for finding the maximum of three numbers is shown below:

```python
#source code
#input three numbers
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

#find the maximum
if a > b and a > c:
  max = a
elif b > a and b > c:
  max = b
else:
  max = c

#output the maximum
print("The maximum is", max)
```
