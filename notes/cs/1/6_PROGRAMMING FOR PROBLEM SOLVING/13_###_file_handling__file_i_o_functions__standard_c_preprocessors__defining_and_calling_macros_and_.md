### File Handling: File I/O Functions, Standard C Preprocessors, Defining and Calling Macros and Command-Line Arguments.

File Handling: 
- File I/O Functions: In C, file I/O is done using standard library functions such as fopen(), fread(), fwrite(), fclose(). 
- Standard C Preprocessors: #include, #define, #ifdef, #ifndef, #endif, #error, #pragma. These are used to control the compilation process. 
- Defining and Calling Macros: Macros are short snippets of code that can be reused. They are defined using #define and can be called anywhere in the code. 
- Command-Line Arguments: Arguments passed to a program at runtime can be accessed using argc and argv[] arrays in the main() function. argc gives the number of arguments and argv[] stores the values of the arguments.
