##### CO 4 Calculate efficiency of a single phase transformer and DC machine. K4

To calculate the efficiency of a single-phase transformer, you can use the following formula:

Efficiency = (Output Power / Input Power) * 100%

The output power is the power delivered by the transformer to the load, and the input power is the power supplied to the transformer. To determine the output power, you can measure the voltage and current at the output of the transformer and calculate the power using the formula:

Output Power = Voltage * Current

To determine the input power, you can measure the voltage and current at the input of the transformer and calculate the power using the formula:

Input Power = Voltage * Current

Once you have determined the output and input power, you can substitute these values into the efficiency formula to calculate the efficiency of the transformer.

To calculate the efficiency of a DC machine, you can use the following formula:

Efficiency = (Output Power / Input Power) * 100%

The output power is the power delivered by the DC machine to the load, and the input power is the power supplied to the DC machine. To determine the output power, you can measure the voltage and current at the output of the DC machine and calculate the power using the formula:

Output Power = Voltage * Current

To determine the input power, you can measure the voltage and current at the input of the DC machine and calculate the power using the formula:

Input Power = Voltage * Current

Once you have determined the output and input power, you can substitute these values into the efficiency formula to calculate the efficiency of the DC machine.

It is important to note that the efficiency of a transformer or DC machine can be influenced by a number of factors, including the design of the machine, the quality of the components, the operating conditions, and the load. To obtain accurate efficiency values, it is important to carefully control these factors and perform the calculations using accurate and calibrated equipment.
