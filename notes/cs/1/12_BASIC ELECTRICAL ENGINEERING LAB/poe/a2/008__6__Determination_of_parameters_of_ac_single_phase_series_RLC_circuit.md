##### 6. Determination of parameters of ac single phase series RLC circuit.

- A series RLC circuit contains a resistor, inductor and capacitor connected in series with an ac supply.
- The circuit parameters like resistance (R), inductance (L) and capacitance (C) can be determined using the following methods:

1. Using voltage and current measurements:
- Measure the voltage (V) and current (I) across each element using multimeter for a known frequency (f) supply.
- Apply Ohm's law to determine the resistance. R = V/I
- Use the relation XL = 2πfL and XC = 1/2πfC to determine the inductance and capacitance respectively.

2. Using Time period measurements:
- Apply a voltage and note down the time period (T) of the current waveform.
- Use the relation 1/f = 1/2π√(LC) to determine the value of the product LC.
- Short the capacitor and remeasure the time period to determine the value of L. Then use this to determine the value of C.

3. Using Impedance measurements:
- Measure the impedance (Z) of the RLC series combination and the individual R, XLand XC.
- Use the relations: Z = R + jXLand XC = 1/2πfC to determine the parameters.

- The parameters can also be determined using resonance frequency measurement when XLand XC nullify each other.
