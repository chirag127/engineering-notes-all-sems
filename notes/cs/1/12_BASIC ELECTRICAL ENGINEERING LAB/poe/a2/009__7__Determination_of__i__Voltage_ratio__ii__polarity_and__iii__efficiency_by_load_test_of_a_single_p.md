##### 7. Determination of (i) Voltage ratio (ii) polarity and (iii) efficiency by load test of a single phase Transformer.

1. Connect the transformer to a suitable power source and vary the input voltage such that full load current flows through the transformer. Note down the input and output voltages.

2. The voltage ratio is equal to the ratio of output and input voltages.

3. Connect a load to the secondary of the transformer and note the polarity. If the polarity is same as the primary, the transformer is step-up type otherwise it is step-down type.

4. Calculate the efficiency of the transformer using the input and output power. The input power is equal to input voltage x input current and output power is equal to output voltage x output current.

5. Efficiency = (Output power/Input power) x 100

The load test determines the performance parameters of a transformer accurately under operating conditions. The voltage ratio, polarity and efficiency can be determined with good precision using this test.
