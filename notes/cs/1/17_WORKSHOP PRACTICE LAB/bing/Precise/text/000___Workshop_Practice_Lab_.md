# Workshop Practice Lab:

Workshop Practice Lab is a course that introduces students to the basic skills and techniques used in various workshop processes. The course covers a range of topics, including:

1. Safety: Students learn about the importance of safety in the workshop, including the use of personal protective equipment and the proper handling of tools and machinery.

2. Hand Tools: Students learn about the various hand tools used in the workshop, including hammers, screwdrivers, pliers, and saws. They also learn how to use these tools safely and effectively.

3. Power Tools: Students learn about the various power tools used in the workshop, including drills, grinders, and sanders. They also learn how to use these tools safely and effectively.

4. Measuring and Marking: Students learn about the various measuring and marking tools used in the workshop, including rulers, calipers, and squares. They also learn how to use these tools to make accurate measurements and marks.

5. Materials: Students learn about the various materials used in the workshop, including wood, metal, and plastic. They also learn about the properties of these materials and how to work with them.

6. Joining Techniques: Students learn about the various joining techniques used in the workshop, including welding, brazing, and soldering. They also learn how to use these techniques to join materials together.

7. Finishing Techniques: Students learn about the various finishing techniques used in the workshop, including sanding, painting, and polishing. They also learn how to use these techniques to give their projects a professional finish.

Overall, Workshop Practice Lab provides students with a solid foundation in the skills and techniques used in the workshop. By the end of the course, students should be able to safely and effectively use a range of tools and materials to complete basic workshop projects.
