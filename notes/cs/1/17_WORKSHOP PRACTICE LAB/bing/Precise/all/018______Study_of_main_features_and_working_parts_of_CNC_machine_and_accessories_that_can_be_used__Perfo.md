#### Study of main features and working parts of CNC machine and accessories that can be used. Perform different operations on metal components using any CNC machines

CNC (Computer Numerical Control) machines are automated milling devices that make industrial components without direct human assistance. They use coded instructions that are sent to an internal computer, which allows factories to fabricate parts accurately and quickly.

The main parts of a CNC machine are:
1. **Input Devices**: These are devices that are used to input the part program into a CNC machine.
2. **Machine Control Unit (MCU)**: The machine control unit is called the heart of the CNC machine.
3. **Machine Tool**: A CNC machine tool always has a sliding table and a spindle to control the position and speed.
4. **Driving System**: This system is responsible for the movement of the different machine axes.
5. **Feedback System**: This system is responsible for ensuring the correct position of the machine axes.
6. **Display Unit**: This unit displays the information to the operator.

CNC machines can be used to perform different operations on metal components, such as milling, drilling, and cutting. The specific operations that can be performed depend on the type of CNC machine and the accessories that are used with it.
