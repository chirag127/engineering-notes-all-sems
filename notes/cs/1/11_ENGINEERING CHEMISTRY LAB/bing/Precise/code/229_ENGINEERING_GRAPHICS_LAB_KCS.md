# ENGINEERING GRAPHICS LAB KCS

Engineering Graphics is a subject that is taught to engineering students in their first year. It is a basic course that helps students to understand the fundamentals of technical drawing and computer-aided design (CAD). The subject is also known as Engineering Drawing or Technical Drawing.

The Engineering Graphics Lab is a practical course that complements the theoretical concepts taught in the classroom. In the lab, students get hands-on experience in creating technical drawings using various tools and techniques.

Some of the key topics covered in the Engineering Graphics Lab include:

1. Introduction to Engineering Graphics: In this topic, students are introduced to the basic concepts of engineering graphics, including the use of drawing instruments, lettering, and dimensioning.

2. Orthographic Projection: This topic covers the principles of orthographic projection, including the creation of multi-view drawings and the use of auxiliary views.

3. Isometric Projection: In this topic, students learn how to create isometric drawings, which are used to represent 3D objects in 2D.

4. Sectional Views: This topic covers the creation of sectional views, which are used to show the internal details of an object.

5. Computer-Aided Design (CAD): In this topic, students are introduced to the basics of CAD software and learn how to create technical drawings using a computer.

The Engineering Graphics Lab is an essential course for engineering students, as it helps them to develop the skills needed to create technical drawings and communicate their ideas effectively. It is a practical subject that provides students with hands-on experience in using various tools and techniques to create technical drawings.
