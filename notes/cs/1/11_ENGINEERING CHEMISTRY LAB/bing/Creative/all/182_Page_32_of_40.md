- This page covers the topic of **linear regression**, which is a statistical method for modeling the relationship between a dependent variable and one or more independent variables.
- Linear regression assumes that the dependent variable can be expressed as a linear combination of the independent variables, plus some random error term.
- The general form of a linear regression model is:

  `y = b0 + b1x1 + b2x2 + ... + bnxn + e`

  where:

  - `y` is the dependent variable
  - `x1, x2, ..., xn` are the independent variables
  - `b0, b1, b2, ..., bn` are the regression coefficients
  - `e` is the error term

- The goal of linear regression is to estimate the regression coefficients that minimize the sum of squared errors (SSE) between the observed and predicted values of the dependent variable.
- The most common method for estimating the regression coefficients is the **ordinary least squares (OLS)** method, which solves a system of normal equations to obtain the best fit line.
- The OLS method has some desirable properties, such as:

  - It is unbiased, meaning that the expected value of the estimated coefficients is equal to the true value of the coefficients.
  - It is consistent, meaning that as the sample size increases, the estimated coefficients converge to the true value of the coefficients.
  - It is efficient, meaning that it has the smallest variance among all unbiased estimators of the coefficients.

- However, the OLS method also has some limitations, such as:

  - It requires the independent variables to be linearly independent, meaning that none of them can be expressed as a linear combination of the others.
  - It requires the error term to be normally distributed, with a constant variance and zero mean, and to be independent of the independent variables.
  - It is sensitive to outliers, meaning that a few extreme observations can have a large influence on the estimated coefficients and the fit of the model.

- To overcome some of these limitations, there are other methods for estimating the regression coefficients, such as:

  - **Weighted least squares (WLS)**, which assigns different weights to the observations based on their reliability or importance, and minimizes the weighted sum of squared errors.
  - **Generalized least squares (GLS)**, which accounts for the heteroscedasticity (non-constant variance) or autocorrelation (non-independence) of the error term, and transforms the model to make the error term homoscedastic and independent.
  - **Ridge regression**, which adds a penalty term to the SSE that shrinks the coefficients towards zero, and reduces the multicollinearity (high correlation) among the independent variables.
  - **Lasso regression**, which also adds a penalty term to the SSE that shrinks the coefficients towards zero, but also sets some of them to exactly zero, and performs variable selection.
  - **Elastic net regression**, which combines the penalty terms of ridge and lasso regression, and balances the trade-off between shrinking and selecting the coefficients.

- To evaluate the performance of a linear regression model, there are several metrics that can be used, such as:

  - **Coefficient of determination (R-squared)**, which measures the proportion of the variance in the dependent variable that is explained by the independent variables, and ranges from 0 to 1, with higher values indicating a better fit.
  - **Adjusted R-squared**, which adjusts the R-squared for the number of independent variables in the model, and penalizes the addition of irrelevant variables, and ranges from 0 to 1, with higher values indicating a better fit.
  - **Root mean squared error (RMSE)**, which measures the average deviation of the predicted values from the observed values, and has the same units as the dependent variable, with lower values indicating a better fit.
  - **Mean absolute error (MAE)**, which measures the average absolute deviation of the predicted values from the observed values, and has the same units as the dependent variable, with lower values indicating a better fit.
  - **Mean absolute percentage error (MAPE)**, which measures the average relative deviation of the predicted values from the observed values, and is expressed as a percentage, with lower values indicating a better fit.
