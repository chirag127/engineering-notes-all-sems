# Upon completion of the course the student should be able to:

1. Understand the basics of Python programming language
- Know how to install Python and use the interactive interpreter
- Learn about basic data types like numbers, strings, lists, tuples, dictionaries etc.
- Understand variables, operators, control flows, functions, object oriented programming concepts etc.
- Learn to work with files using Python
- Gain expertise in Python modules like NumPy, Pandas, Matplotlib etc. for scientific computing and data science applications
- Apply learned skills to solve real world problems

2. Get an insight into Machine Learning and its applications
- Understand what Machine Learning is and its types (Supervised Learning, Unsupervised Learning, Reinforcement Learning)
- Learn about regression, classification and clustering algorithms
- Implement Machine Learning algorithms using scipy and scikit-learn libraries
- Work on projects like predicting house prices, detecting spam emails, identifying handwritten digits etc. to get a practical understanding of Machine Learning
- Stay up-to-date with the trends in Machine Learning and Deep Learning

3. Learn fundamental concepts of Deep Learning and Neural Networks
- Understand biological neural networks and their computational counterparts - artificial neural networks
- Get familiar with perceptrons, multilayer perceptrons and their applications
- Learn about convolutions, pooling, dropout, regularization etc. for deep learning with neural networks
- Implement deep neural networks using TensorFlow and Keras
- Work on projects like image classification, machine translation, text generation etc. to apply the Deep Learning concepts
- Keep up with the advancements in Deep Learning and its applications
