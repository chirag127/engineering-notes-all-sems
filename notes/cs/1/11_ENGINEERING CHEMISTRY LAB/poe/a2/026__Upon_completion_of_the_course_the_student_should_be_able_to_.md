### Upon completion of the course the student should be able to:

1. Understand the basic concepts of machine learning and deep learning.

3. Train and evaluate machine learning models and deep neural networks using Python and its libraries like Scikit-Learn, TensorFlow and Keras.
4. Gain expertise in deep learning concepts such as neural networks, convolutional neural networks and recurrent neural networks.
5. Apply machine learning and deep learning techniques to solve real-world problems like image classification, object detection, speech recognition, machine translation etc.
6. Stay up-to-date with the recent trends in machine learning and deep learning.
