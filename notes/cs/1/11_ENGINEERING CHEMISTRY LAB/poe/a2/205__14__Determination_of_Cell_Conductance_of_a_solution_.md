### 14. Determination of Cell Conductance of a solution.

1. Set up the conductivity cell with the given solution and note down the resistance.
2. Clean the conductivity cell and fill it with distilled water. Note down the resistance of distilled water.
3. Calculate the specific conductance (K) of the given solution using the formula:
K = l/RA
Where,
l = Distance between the electrodes in cm
A = Cross-sectional area of the solution in cm^2
R = Resistance in ohm
4. Calculate the equivalent conductance (Lambda) of the electrolyte using the formula:
Lambda = Kv/c
Where,
v = Volume of the solution in cm^3
c = Concentration of the solution in equiv. per cm^3
5. Compare the equivalent conductance value with the literature values to identify the electrolyte. The equivalent conductance value depends on the mobility and number of ions in the electrolyte.
