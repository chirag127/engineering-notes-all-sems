
### Clock Driven Approach for the notes of the Unit 2 - Real Time Scheduling in the subject of Real Time System

1. Clock Driven Approach is a scheduling algorithm used in Real Time Systems to ensure that tasks are completed before their deadlines. 
2. The algorithm works by assigning a time quantum to each task, which is the maximum amount of time that a task can run for before it is preempted. 
3. When the time quantum for a task expires, the scheduler will select the next task to run. 
4. This approach is advantageous because it allows the system to be more responsive to external events, and tasks can be completed in a timely manner.
5. The disadvantage of this approach is that it can lead to inefficient use of resources, as tasks may be preempted before they have a chance to finish.
6. Additionally, the system may become unresponsive if the scheduler is unable to select a task to run in a timely manner.
