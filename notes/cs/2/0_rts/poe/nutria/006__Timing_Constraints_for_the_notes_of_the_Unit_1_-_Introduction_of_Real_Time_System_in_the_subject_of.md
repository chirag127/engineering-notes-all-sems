
### Timing Constraints for the Unit 1 - Introduction of Real Time System

1. Real-time systems are systems that must respond to external events within a specific time frame.
2. Timing constraints can be divided into two categories: Hard and Soft.
3. Hard timing constraints must be met in order for the system to function correctly.
4. Soft timing constraints are not as strict, but should still be taken into consideration.
5. Meeting timing constraints can be achieved through the use of scheduling algorithms, such as rate monotonic scheduling and Earliest Deadline First.
6. Timing constraints can be affected by external factors, such as processor speed, memory size, and system load.
7. It is important to analyze and test the system for timing constraints in order to ensure that the system will function correctly.
