
### Effect of Resource Contention and Resource Access Control (RAC)

1. Resource contention occurs when multiple processes or threads attempt to access the same resource at the same time.

2. Resource access control (RAC) is a mechanism for managing access to resources by multiple processes or threads. It ensures that resources are used in an orderly and fair manner.

3. RAC can be implemented using locks, semaphores, monitors, and other synchronization mechanisms.

4. Locks are used to ensure that only one process or thread can access a resource at a time.

5. Semaphores are used to limit the number of processes or threads that can access a resource at a given time.

6. Monitors are used to ensure that only one thread can access a resource at a time and that the resource is used in a consistent manner.

7. In a real-time system, resource contention can lead to unpredictable delays and poor performance.

8. RAC ensures that resources are used in an orderly and fair manner, thus improving system performance and reliability.
