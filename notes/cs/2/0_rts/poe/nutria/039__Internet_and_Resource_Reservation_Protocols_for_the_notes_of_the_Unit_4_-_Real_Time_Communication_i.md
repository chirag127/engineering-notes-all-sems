
### Internet and Resource Reservation Protocols

* Internet Protocol (IP) is a protocol used for communication between computers on the Internet. It is responsible for routing packets of data between computers and networks.
* Resource Reservation Protocol (RSVP) is a network-layer protocol that allows applications to reserve resources on a network. It is used to reserve bandwidth, delay, and jitter on a network for real-time applications such as voice and video.
* RSVP allows applications to specify the resources they need in order to operate and then request those resources from the network.
* The protocol allows applications to reserve resources in a distributed manner, meaning that the resources are reserved in multiple nodes along the path of the connection.
* RSVP is also used to control the flow of traffic on the network by setting up Quality of Service (QoS) parameters such as bandwidth, latency, and jitter.
* RSVP is used in conjunction with other protocols such as the Differentiated Services (DiffServ) protocol and the Integrated Services (IntServ) protocol to provide a more sophisticated and reliable network experience.
