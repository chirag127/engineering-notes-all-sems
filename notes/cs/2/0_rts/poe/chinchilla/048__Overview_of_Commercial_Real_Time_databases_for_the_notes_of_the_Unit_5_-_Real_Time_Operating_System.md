### Overview of Commercial Real Time databases

In today's world, real-time systems are becoming increasingly important in various industries such as finance, healthcare, and transportation. A critical component of real-time systems is the database that stores and retrieves the data quickly and efficiently. In this section, we will provide an overview of commercial real-time databases.

1. **Oracle TimesTen:** 
   - Oracle TimesTen is a popular in-memory database that provides real-time data management and analytics capabilities. 
   - It is designed to deliver high performance, scalability, and fault-tolerance required for real-time applications. 
   - It supports SQL and PL/SQL, and can be integrated with other Oracle databases.

2. **IBM DB2:** 
   - IBM DB2 is a reliable and efficient database management system that provides real-time data processing capabilities. 
   - It supports a variety of platforms including mainframe, UNIX, and Windows. 
   - It also offers high availability and disaster recovery features.

3. **Microsoft SQL Server:**
   - Microsoft SQL Server is a robust database management system that provides real-time data processing capabilities. 
   - It supports high availability and disaster recovery features and can be integrated with other Microsoft products. 
   - It also provides a rich set of tools for managing and analyzing data.

4. **SAP HANA:**
   - SAP HANA is an in-memory database that provides real-time data processing capabilities. 
   - It is designed to handle large amounts of data and can be used for both transactional and analytical workloads. 
   - It supports SQL and MDX (Multidimensional Expressions) for querying data.

5. **MemSQL:** 
   - MemSQL is a distributed, in-memory database that provides real-time data processing capabilities. 
   - It is designed to deliver high performance and scalability for real-time applications. 
   - It supports SQL and can be integrated with other data sources.

6. **VoltDB:**
   - VoltDB is an in-memory database that provides real-time data processing capabilities. 
   - It is designed to handle high velocity and high volume data and can be used for both transactional and analytical workloads. 
   - It supports SQL and can be integrated with other data sources.

In conclusion, commercial real-time databases play a critical role in real-time systems by providing efficient and reliable data management capabilities. The above-mentioned databases are some of the most popular and widely used databases in the industry. Understanding their features and capabilities can be beneficial for building efficient real-time applications.
