### Informed for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

"Informed" is a term used in the field of artificial intelligence to describe a search algorithm that makes use of additional information to guide the search process. 

1. Problem Solving Methods: In AI, problem solving methods refer to the techniques and algorithms used to find solutions to problems. Informed search algorithms are a type of problem solving method that make use of additional information to guide the search process.

2. Heuristics: Heuristics are rules of thumb or estimates that are used to guide the search process. In informed search algorithms, heuristics are used to estimate the cost of reaching the goal state from the current state.

3. Best-First Search: Best-first search is a type of informed search algorithm that selects the next state to explore based on the estimated cost of reaching the goal state from that state. The state with the lowest estimated cost is selected first.

4. A* Search: A* search is a type of best-first search that uses a heuristic function to estimate the cost of reaching the goal state from the current state. The heuristic function is used to guide the search process and improve the efficiency of the algorithm.

5. Admissibility and Consistency: In order for a heuristic function to be effective, it must be admissible, meaning that it never overestimates the cost of reaching the goal state, and consistent, meaning that it satisfies the triangle inequality.

6. Integration with Uninformed Search: Informed search algorithms can be combined with uninformed search algorithms, such as breadth-first search and depth-first search, to improve the efficiency of the search process.

In conclusion, informed search algorithms are a type of problem solving method in AI that make use of additional information, such as heuristics, to guide the search process. Best-first search and A* search are examples of informed search algorithms that are widely used in AI. The effectiveness of informed search algorithms depends on the admissibility and consistency of the heuristic function used.
