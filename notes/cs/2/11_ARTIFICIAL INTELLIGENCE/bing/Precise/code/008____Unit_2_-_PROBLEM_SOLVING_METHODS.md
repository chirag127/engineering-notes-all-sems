## Unit 2 - PROBLEM SOLVING METHODS

Problem-solving is the process of finding a solution to an issue by using a systematic approach. There are several methods that can be used to solve problems, including:

1. **Trial and Error**: This method involves trying different solutions until the problem is solved. It is a simple approach but can be time-consuming.

2. **Algorithm**: An algorithm is a step-by-step procedure for solving a problem. It is a precise and well-defined method that guarantees a solution if followed correctly.

3. **Heuristics**: Heuristics are rules of thumb or mental shortcuts that can be used to quickly find a solution to a problem. They are not guaranteed to work but can be useful in finding a solution quickly.

4. **Divide and Conquer**: This method involves breaking down a large problem into smaller, more manageable sub-problems. Each sub-problem is then solved, and the solutions are combined to solve the original problem.

5. **Backtracking**: Backtracking is a method of solving problems by systematically trying different solutions and then backing up and trying a different approach if the current solution does not work.

6. **Brute Force**: Brute force is a method of solving problems by trying all possible solutions until the correct one is found. It is not an efficient method but can be useful in some cases.

These are some of the common methods used for problem-solving. The choice of method depends on the nature of the problem and the resources available to solve it.
