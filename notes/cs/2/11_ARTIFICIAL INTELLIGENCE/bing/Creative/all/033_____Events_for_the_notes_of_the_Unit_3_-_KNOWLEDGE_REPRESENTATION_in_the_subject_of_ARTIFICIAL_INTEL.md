# Events

- Events are occurrences or situations that happen in the world and can be represented by logical expressions.
- Events can be classified into different types, such as atomic, complex, deterministic, nondeterministic, static, dynamic, discrete, continuous, etc.
- Events can have properties, such as duration, frequency, location, participants, preconditions, effects, etc.
- Events can be related to each other by temporal, causal, spatial, or logical relations, such as before, after, during, causes, enables, prevents, overlaps, etc.
- Events can be modeled by different formalisms, such as situation calculus, event calculus, fluent calculus, etc.
- Events can be used for various purposes, such as planning, reasoning, learning, explanation, etc.
