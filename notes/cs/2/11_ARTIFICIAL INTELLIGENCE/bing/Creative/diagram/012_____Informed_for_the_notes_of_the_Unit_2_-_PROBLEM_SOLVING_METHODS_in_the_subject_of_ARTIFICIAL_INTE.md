# Informed Search

- Informed search is a type of search strategy that uses additional information or heuristics to guide the search process towards the goal state.
- Heuristics are estimates of the cost, distance, or quality of a solution from a given state.
- Informed search algorithms are also called heuristic search algorithms, as they use heuristics to evaluate the nodes in the search space.
- Informed search algorithms can be more efficient and effective than uninformed search algorithms, as they can avoid exploring irrelevant or suboptimal paths.
- Some examples of informed search algorithms are:
  - Best-first search: a general search strategy that expands the most promising node according to a given heuristic function.
  - Greedy best-first search: a type of best-first search that uses a heuristic function that estimates the cost of reaching the goal from a node, and expands the node with the lowest estimated cost.
  - A* search: a type of best-first search that uses a heuristic function that estimates the total cost of a solution path from a node, and expands the node with the lowest estimated total cost.
  - Hill-climbing search: a type of local search that starts from a random initial state and moves to a neighboring state that improves the heuristic value, until a local optimum is reached.
  - Simulated annealing: a type of local search that starts from a random initial state and moves to a neighboring state that improves or worsens the heuristic value, with a probability that decreases over time, until a global optimum is reached.
  - Genetic algorithms: a type of population-based search that starts from a set of random initial states and applies genetic operators such as selection, crossover, and mutation to generate new states, until a satisfactory solution is found.
