### Searching with Partial Observations

- Searching with partial observations is a problem-solving method in artificial intelligence that deals with environments that are **partially observable**, meaning that the agent cannot access the complete state of the environment at any given time .
- In such environments, an agent can be in one of several possible states, and an action can lead to one of several possible outcomes. Therefore, the agent needs to maintain a **belief state**, which is a set of possible states that are consistent with the agent's observations and actions.
- A belief state can be represented as a **contingency plan**, which is a tree of actions and observations that specifies what the agent should do in each possible situation. A contingency plan can be constructed by using a **search algorithm** that explores the space of belief states and actions, and finds a **goal state** that satisfies some criterion .
- Some examples of search algorithms for partial observations are:
  - **AND-OR search**: A search algorithm that alternates between two types of nodes: AND nodes, which represent belief states, and OR nodes, which represent actions. The algorithm expands the nodes in a depth-first manner, and backtracks when a dead end or a loop is encountered. The algorithm terminates when a goal state is found or when the search space is exhausted.
  - **Sensorless search**: A search algorithm that assumes that the agent has no sensors, and therefore the belief state is always the set of all possible states. The algorithm tries to find a sequence of actions that reduces the size of the belief state until it reaches a singleton set that contains the goal state.
  - **Online search**: A search algorithm that interleaves planning and execution, and updates the belief state based on the actual observations received from the environment. The algorithm uses a **heuristic function** to guide the search towards promising actions, and a **lookahead limit** to bound the depth of the search.
- Searching with partial observations is a challenging and computationally expensive task, as the size of the belief state and the contingency plan can grow exponentially with the number of actions and observations. Therefore, some techniques to improve the efficiency and scalability of the search are:
  - **Abstraction**: A technique that reduces the complexity of the search by grouping similar states or actions into abstract categories, and using a simpler representation of the belief state and the contingency plan.
  - **Learning**: A technique that acquires knowledge from the environment or from other sources, and uses it to construct or refine the action models or the heuristic functions that are used by the search algorithm .
  - **Approximation**: A technique that trades off optimality for tractability, and uses probabilistic or statistical methods to estimate the likelihood or the utility of the belief states and the actions.
