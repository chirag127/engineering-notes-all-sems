### Problem solving methods

- Problem solving methods are general strategies or techniques that can be applied to different types of problems in artificial intelligence.
- Problem solving methods can be classified into two main categories: **search-based methods** and **knowledge-based methods**.
- Search-based methods involve exploring a large space of possible solutions or actions, guided by some criteria or heuristics, until a goal or a satisfactory solution is found.
- Knowledge-based methods involve using domain-specific knowledge or rules to infer or deduce the solution or the best action from the given problem or situation.
- Some examples of search-based methods are:
  - **Blind search methods**: These methods do not use any domain knowledge or heuristics, and rely on brute-force exploration of the search space. Examples are breadth-first search, depth-first search, uniform-cost search, etc.
  - **Heuristic search methods**: These methods use some domain knowledge or heuristics to guide the search and prune the search space. Examples are best-first search, greedy search, A* search, etc.
  - **Local search methods**: These methods start from an initial solution and iteratively improve it by making small changes or moves. Examples are hill-climbing, simulated annealing, genetic algorithms, etc.
- Some examples of knowledge-based methods are:
  - **Logic-based methods**: These methods use logic as a representation language and a reasoning mechanism to derive the solution or the best action from the given problem or situation. Examples are propositional logic, first-order logic, resolution, etc.
  - **Rule-based methods**: These methods use rules as a representation language and a matching and firing mechanism to infer the solution or the best action from the given problem or situation. Examples are production systems, expert systems, etc.
  - **Frame-based methods**: These methods use frames as a representation language and a slot-filling and inheritance mechanism to organize and access the knowledge about the problem or situation. Examples are semantic networks, conceptual graphs, etc.
