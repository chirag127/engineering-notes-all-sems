### Informed Search

- Informed search is a type of search strategy that uses additional information or heuristics to guide the search process towards the goal state.
- Heuristics are estimates of the cost, distance, or quality of a solution from a given state. They can help reduce the search space and speed up the search process.
- Informed search algorithms include:
  - Best-first search: a general search algorithm that expands the most promising node according to a heuristic function.
  - Greedy best-first search: a type of best-first search that uses a heuristic function that estimates the cost of reaching the goal from a node, without considering the cost of the path so far. It is not optimal, but can be fast and efficient.
  - A* search: a type of best-first search that uses a heuristic function that combines the cost of reaching the goal from a node and the cost of the path so far. It is optimal and complete, but can be memory-intensive.
  - Iterative deepening A* search: a variation of A* search that uses a depth limit and iteratively increases it until a solution is found. It is optimal, complete, and memory-efficient, but can be slow.
  - Recursive best-first search: a variation of A* search that uses a recursive algorithm and a memory-bound to avoid expanding nodes that are not promising. It is optimal and complete, but can be slow and complex.
  - Beam search: a type of best-first search that keeps only a fixed number of best nodes at each level and discards the rest. It is not optimal or complete, but can be fast and memory-efficient.
  - Hill-climbing search: a type of local search that starts from a random initial state and moves to a neighboring state that improves the heuristic function. It is not optimal or complete, but can be fast and simple.
  - Simulated annealing: a type of local search that uses a probabilistic mechanism to escape from local optima and explore the search space. It is not optimal, but can be complete with a high probability.
  - Genetic algorithms: a type of population-based search that uses biological concepts such as reproduction, mutation, and selection to generate and improve solutions. It is not optimal or complete, but can be effective for complex and large problems.
