# Constraint Propagation

- Constraint propagation is a technique for reducing the search space of a problem by applying constraints that eliminate inconsistent or infeasible values from the domains of the variables.
- Constraints are rules or conditions that restrict the possible values or assignments of the variables in a problem. For example, in a map coloring problem, a constraint could be that adjacent regions cannot have the same color.
- A domain is the set of possible values that a variable can take. For example, in a map coloring problem, a domain could be the set of colors available for a region.
- Constraint propagation works by applying constraints repeatedly until no more values can be eliminated from the domains or a contradiction is found. A contradiction occurs when a domain becomes empty, meaning that no value can satisfy the constraints for that variable.
- Constraint propagation can be applied before or during the search process. Applying it before the search can reduce the branching factor and the depth of the search tree, making the search faster and more efficient. Applying it during the search can prune branches that lead to dead ends or suboptimal solutions, avoiding unnecessary exploration.
- There are different types of constraints and different algorithms for propagating them. Some of the common types of constraints are:

  - Unary constraints: Constraints that involve only one variable. For example, in a map coloring problem, a unary constraint could be that a certain region must have a specific color. Unary constraints can be propagated by simply removing the values that do not satisfy the constraint from the domain of the variable.
  - Binary constraints: Constraints that involve two variables. For example, in a map coloring problem, a binary constraint could be that two adjacent regions cannot have the same color. Binary constraints can be propagated by using algorithms such as arc consistency or path consistency.
  - Arc consistency: A binary constraint is arc consistent if for every value in the domain of one variable, there is a consistent value in the domain of the other variable. For example, in a map coloring problem, a binary constraint is arc consistent if for every color in the domain of one region, there is a different color in the domain of the adjacent region. Arc consistency can be enforced by using algorithms such as AC-3 or AC-4, which iteratively remove inconsistent values from the domains until all constraints are arc consistent or a contradiction is found.
  - Path consistency: A set of binary constraints is path consistent if for every pair of variables, there is a consistent value for the third variable that participates in a constraint with them. For example, in a map coloring problem, a set of binary constraints is path consistent if for every pair of adjacent regions, there is a consistent color for the region that is adjacent to both of them. Path consistency can be enforced by using algorithms such as PC-2, which iteratively remove inconsistent values from the domains until all constraints are path consistent or a contradiction is found.
  - Global constraints: Constraints that involve more than two variables. For example, in a map coloring problem, a global constraint could be that the number of colors used must be less than or equal to a given limit. Global constraints can be propagated by using specialized algorithms that exploit the structure or properties of the constraint, such as the alldifferent constraint, which ensures that all the variables in a set have different values.
