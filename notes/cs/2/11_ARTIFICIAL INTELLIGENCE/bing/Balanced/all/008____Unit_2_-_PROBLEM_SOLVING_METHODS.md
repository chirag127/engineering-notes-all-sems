## Unit 2 - PROBLEM SOLVING METHODS

- Problem solving is the process of finding solutions to difficult or complex issues.
- Problem solving methods are strategies or techniques that can be used to solve problems effectively and efficiently.
- Some common problem solving methods are:

  - Trial and error: Trying different solutions until finding one that works.
  - Algorithm: Following a step-by-step procedure that guarantees a correct solution.
  - Heuristic: Using a rule of thumb or a shortcut that may not guarantee a correct solution, but can help narrow down the search space.
  - Divide and conquer: Breaking down a large problem into smaller and simpler subproblems that can be solved separately and then combined.
  - Backtracking: Exploring different branches of a solution space and going back to a previous state if a dead end is reached.
  - Recursion: Solving a problem by using the solution of a smaller or simpler version of the same problem.
  - Simulation: Creating a model of a real-world situation and experimenting with different scenarios or parameters to find a solution.
  - Optimization: Finding the best solution among a set of possible solutions, based on some criteria or objective function.
  - Constraint satisfaction: Finding a solution that satisfies a set of constraints or rules that limit the solution space.
  - Artificial intelligence: Using techniques such as search, logic, knowledge representation, machine learning, natural language processing, computer vision, etc. to solve problems that require human intelligence.
