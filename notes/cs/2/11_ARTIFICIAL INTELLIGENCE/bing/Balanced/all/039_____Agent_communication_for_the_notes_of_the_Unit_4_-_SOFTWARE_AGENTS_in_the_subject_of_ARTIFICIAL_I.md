# Agent Communication

- Agent communication is the process of exchanging information and knowledge between intelligent agents in a multi-agent system.
- Agent communication is also known as artificial communication, as it is performed by artificial entities that work with artificial intelligence.
- Agent communication is important for achieving interoperability, coordination, cooperation and collaboration among agents that have different goals, beliefs and capabilities.
- Agent communication is based on the following concepts:

  - Agent communication languages (ACLs): These are standardized languages that define the syntax and semantics of the messages that agents can exchange. ACLs are inspired by the speech act theory, which states that utterances have both a literal meaning and a performative effect on the listener. Some examples of ACLs are KQML, FIPA-ACL and AgentSpeak.
  - Agent communication protocols: These are rules that specify the sequence and structure of the messages that agents can exchange in a given context or situation. Protocols define the roles, responsibilities and expectations of the agents involved in a communication. Some examples of protocols are contract net, query-ref, request and subscribe.
  - Agent communication ontologies: These are shared vocabularies that define the concepts and terms that agents can use to refer to the domain of interest. Ontologies enable agents to have a common understanding of the meaning and relevance of the messages they exchange. Some examples of ontologies are RDF, OWL and Cyc.
  - Agent communication models: These are abstract representations of the communication process that capture the essential features and characteristics of the agents, messages, languages, protocols and ontologies involved. Models help to analyze, design and implement agent communication systems. Some examples of models are mentalistic, social and pragmatic.
