### Searching with Partial Observations
- In some search problems, the agent does not have complete information about the state of the world, and can only observe some features or aspects of the state.
- This is called **partial observability**, and it makes the search problem more challenging and complex.
- Partial observability can arise due to various reasons, such as sensor limitations, noisy or unreliable data, hidden or unknown variables, or dynamic environments.
- To cope with partial observability, the agent needs to maintain a **belief state**, which is a set of possible states that are consistent with the agent's observations and actions.
- The agent's goal is to find a sequence of actions that leads to a belief state that contains only goal states, or that maximizes the probability of reaching a goal state.
- The search space for a partially observable problem is the space of all possible belief states, which can be exponentially large in the number of states and observations.
- Therefore, finding an optimal solution for a partially observable problem is often intractable, and the agent may need to use approximation methods or heuristics to guide the search.
- Some of the methods that can be used for searching with partial observability are:
  - **AND-OR search**: This is a type of tree search that alternates between two types of nodes: AND nodes, which represent belief states, and OR nodes, which represent actions. The agent expands an AND node by applying all possible actions and generating the corresponding OR nodes. The agent expands an OR node by applying the observation function and generating the corresponding AND nodes. The agent selects an action at an OR node that leads to a subtree that contains a goal state at every leaf. The agent selects an observation at an AND node that leads to a subtree that contains a goal state at every leaf. The solution is a conditional plan that specifies what action to take and what observation to expect at each step.
  - **Sensorless search**: This is a special case of AND-OR search where the agent assumes that it has no sensors and cannot observe anything about the state. The agent only maintains a single belief state that contains all possible states, and tries to find an action sequence that leads to a goal state regardless of the actual state. This is also known as **conformant search** or **conformant planning**.
  - **Heuristic search**: This is a type of search that uses a heuristic function to estimate the cost or value of a belief state or an action. The heuristic function can be derived from various sources, such as domain knowledge, relaxed problems, or learned models. The agent uses the heuristic function to guide the search and select the most promising belief states or actions to expand. Some examples of heuristic search algorithms are A*, Greedy Best-First Search, and Hill Climbing.
  - **Online search**: This is a type of search that interleaves planning and execution, and updates the belief state based on the actual observations and actions. The agent does not need to find a complete plan before acting, but only needs to find a local or partial plan that is sufficient for the current situation. The agent can use various methods to generate local or partial plans, such as lookahead search, Monte Carlo methods, or reinforcement learning. Online search can be useful when the environment is dynamic, uncertain, or unknown, and the agent needs to adapt to the changes and feedback.
