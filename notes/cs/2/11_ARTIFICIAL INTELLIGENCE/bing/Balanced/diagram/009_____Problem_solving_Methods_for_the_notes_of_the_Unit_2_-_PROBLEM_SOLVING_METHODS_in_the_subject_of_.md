### Problem Solving Methods

- Problem solving is the process of finding a solution to a given problem that satisfies some criteria or constraints.
- In artificial intelligence, problem solving often involves investigating potential solutions to problems through reasoning techniques, making use of polynomial and differential equations, and carrying them out and use modelling frameworks.
- A same problem may have multiple solutions, that are all accomplished using a unique algorithm.
- Problem solving methods in AI can be classified into four categories: search, optimization, constraint satisfaction, and logic.

#### Search
- Search algorithms are one of the common methods to solve problems in AI.
- The problem solving or rational agents with search algorithms are used to find the best optimal solution.
- This type of problem-solving technique is often called goal-based.
- Search algorithms in AI can be divided into two types: uninformed search and informed search.
- Uninformed search algorithms do not have any domain-specific knowledge and use only the information available in the problem definition.
- Examples of uninformed search algorithms are breadth-first search, depth-first search, uniform-cost search, and iterative deepening search.
- Informed search algorithms use some domain-specific knowledge or heuristics to guide the search process and reduce the search space.
- Examples of informed search algorithms are greedy search, A* search, hill-climbing search, and beam search.

#### Optimization
- Optimization algorithms are another type of problem solving methods in AI that aim to find the best possible solution among a set of feasible solutions.
- Optimization algorithms can be used to solve problems that involve minimizing or maximizing some objective function, such as cost, profit, distance, etc.
- Optimization algorithms can be classified into two types: deterministic optimization and stochastic optimization.
- Deterministic optimization algorithms use a fixed set of rules or procedures to find the optimal solution, such as gradient descent, Newton's method, and simplex method.
- Stochastic optimization algorithms use some random or probabilistic elements to explore the solution space, such as simulated annealing, genetic algorithms, and particle swarm optimization.

#### Constraint Satisfaction
- Constraint satisfaction algorithms are another type of problem solving methods in AI that aim to find a solution that satisfies a set of constraints or rules.
- Constraint satisfaction algorithms can be used to solve problems that involve finding a consistent assignment of values to variables, such as scheduling, map coloring, sudoku, etc.
- Constraint satisfaction algorithms can be divided into two types: backtracking search and local search.
- Backtracking search algorithms use a depth-first search strategy to explore the solution space and backtrack when a constraint is violated, such as backtracking, forward checking, and arc consistency.
- Local search algorithms use a hill-climbing strategy to move from one solution to another by changing some variables and improving the constraint satisfaction, such as min-conflicts, tabu search, and simulated annealing.

#### Logic
- Logic algorithms are another type of problem solving methods in AI that aim to find a solution that follows from a set of facts and rules.
- Logic algorithms can be used to solve problems that involve reasoning, inference, deduction, and proof, such as theorem proving, natural language understanding, and knowledge representation.
- Logic algorithms can be classified into two types: propositional logic and predicate logic.
- Propositional logic algorithms use symbols and connectives to represent facts and rules, such as truth tables, resolution, and DPLL.
- Predicate logic algorithms use symbols, connectives, quantifiers, and functions to represent facts and rules, such as unification, resolution, and Prolog.
