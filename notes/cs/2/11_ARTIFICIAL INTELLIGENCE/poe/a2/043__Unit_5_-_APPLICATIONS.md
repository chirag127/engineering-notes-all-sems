## Unit 5 - APPLICATIONS

1. Application software is software designed to perform a group of coordinated functions, tasks, or activities for the benefit of the user.

2. Word processors, spreadsheets, database management systems, multimedia applications, and web browsers are common examples of application software.

3. Application software relies on system software to execute. The system software provides a platform for the application software to run on and handles low-level functions like receiving input and displaying output.

4. Application software is developed to satisfy the users’ needs. It helps in streamlining business processes, aiding creativity, enhancing productivity, and making tasks more convenient.

5. The cost of application software can range from free to very expensive, depending on factors like the type of software, licensing options, and level of support and updates included.
