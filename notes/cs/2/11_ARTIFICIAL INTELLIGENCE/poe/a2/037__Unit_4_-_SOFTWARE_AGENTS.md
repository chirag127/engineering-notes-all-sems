## Unit 4 - SOFTWARE AGENTS

1. Software Agents: Software agents are automated computer programs that perform certain tasks or make decisions for a user. They are designed to simulate the functionality of a human agent or representative, but with a narrow and specific focus. Some examples of software agents include:
- Shopping bots that find products matching a user's needs
- Travel booking assistants that locate flights and hotels
- Email filters that sort important messages from spam
- Data mining tools that analyze data and detect patterns

2. Types of Software Agents: There are three main types of software agents:
- Simple Reflex Agents: These agents take an input and produce an output based on a predefined set of rules. They do not maintain any information about previous inputs or outputs. Example: Thermostat adjusting room temperature based on preset ranges.
- Goal-Based Agents: These agents choose actions that they believe will help them achieve a specific goal. They keep track of the current state, goals, and possible actions. Example: Shopping bot finding lowest prices for desired products.
- Utility-Based Agents: These agents select actions that maximize expected reward or utility. They evaluate possible actions based on their probabilities of success and expected rewards or penalties. Example: Email filter assessing probabilities of messages being important or spam.

3. Applications of Software Agents: Software agents have a wide range of applications including:
- Automating tasks like scheduling, data filtering, and information retrieval
- Assisting users with decisions or performing negotiations on their behalf
- Monitoring systems and detecting anomalies or errors
- Personalizing user experiences based on individual needs and preferences
- Handling routine transactions like billing, payments, and reservations
- Gathering and filtering information from various data sources
