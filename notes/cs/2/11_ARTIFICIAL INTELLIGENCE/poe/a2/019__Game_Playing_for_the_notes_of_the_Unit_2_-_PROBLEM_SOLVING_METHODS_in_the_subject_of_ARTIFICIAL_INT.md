### Game Playing for the notes of the Unit 2 - PROBLEM SOLVING METHODS in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Game playing is a common AI problem which involves designing agents or programs that can play games.
2. Games provide a useful testbed for AI research as they have clearly-defined rules and goals.
3. The AI agent must be able to reason about the current state of the game and determine optimal strategies or moves that will lead to the most favorable outcome.
4. Some approaches for game playing are:
- Minimax algorithm - examines all possible future moves and chooses the one that minimizes maximum loss. Used in zero-sum games.
- Alpha-beta pruning - enhances the minimax algorithm by pruning search space.
- Machine learning - trains agents using data from human gameplay or self-play. Often uses reinforcement learning.
- Combining search and machine learning.
5. Popular games for AI research include chess, checkers, Go, DOTA 2, Starcraft, etc. AI agents have achieved human-level performance and even superhuman performance in some games like chess and Go.
