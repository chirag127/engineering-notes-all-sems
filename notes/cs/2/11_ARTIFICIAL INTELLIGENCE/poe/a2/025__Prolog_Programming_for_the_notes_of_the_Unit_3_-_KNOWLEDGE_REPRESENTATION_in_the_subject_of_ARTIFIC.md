### Prolog Programming for the notes of the Unit 3 - KNOWLEDGE REPRESENTATION in the subject of ARTIFICIAL INTELLIGENCE KCS

1. Prolog is a logic programming language associated with artificial intelligence and computational linguistics.
2. It is mainly used to implement knowledge-based systems, with an emphasis on declarative programming and theorem proving.
3. The language uses binary relations and pattern matching to symbolically represent and solve problems.
4. Prolog has its roots in first-order logic, a formal logic, and unlike many other programming languages, Prolog is intended primarily as a declarative programming language.
5. The design of the Prolog language is based on the understanding that logic is a better and more efficient approach to problem-solving than procedural programming in imperative languages.
6. Knowledge in Prolog is represented in the form of facts and rules and computation is performed by running queries over these facts and rules.
7. The basic components of Prolog are:

- Facts: Facts are statements which are always true. For example- "birds can fly".
- Rules: Rules are statements of logic which relate facts. For example- "if something lays eggs, then it is a bird".
- Queries: Queries are statements which question the knowledge base and return either true or false. For example- "Is X a bird?".

8. Some key features of Prolog are:
- Pattern matching
- Backtracking
- Unification
- Finite recursion
