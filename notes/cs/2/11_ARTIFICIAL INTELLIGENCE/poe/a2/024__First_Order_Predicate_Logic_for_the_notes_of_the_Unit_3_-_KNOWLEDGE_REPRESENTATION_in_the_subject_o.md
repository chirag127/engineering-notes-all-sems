### First Order Predicate Logic

- First order predicate logic (FOPL) is a formal system used to express knowledge about the world.
- It consists of variables, constants, functions, predicates and quantifiers.
- Variables: Used to represent unspecified individuals.
- Constants: Used to represent specific individuals.
- Functions: Used to represent associations between inputs and outputs.
- Predicates: Used to represent relationships between variables.
- Quantifiers: Used to specify whether a statement is true for all or some of the individuals.

Quantifiers:
- Universal quantifier (∀): Indicates that a statement is true for all individuals.
- Existential quantifier (∃): Indicates that a statement is true for at least one individual.

Logical connectives:
- ¬: Negation (not)
- ∧: Conjunction (and)
- ∨: Disjunction (or)
- →: Implication (if-then)
- ↔: Biconditional (if and only if)

Rules of inference:
- Modus ponens: If P → Q and P are true, then Q must be true.
- Modus tollens: If P → Q and Q is false, then P must be false.
- Hypothetical syllogism: If P → Q and Q → R are true, then P → R must be true.

The main goal of FOPL is to represent knowledge in a precise and unambiguous manner to allow automated reasoning. It forms the basis for many knowledge representation formalisms used in AI.
