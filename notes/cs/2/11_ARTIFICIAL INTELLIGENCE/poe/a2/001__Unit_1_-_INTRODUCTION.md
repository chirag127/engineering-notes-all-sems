## Unit 1 - INTRODUCTION

1. Introduction to Web Development
- Web development refers to the tasks associated with developing a website for the Internet (World Wide Web).
- It includes web design, web programming, web content development, client liaison, and web server configuration.
- Web developers are highly employable and well compensated.
- In this course, you will learn the skills and technologies required for web development.

2. The Structure of a Website
- A website is a collection of web pages stored on a server and accessed via the Internet.
- A web page is written in HTML (Hypertext Markup Language) and typically has images, CSS stylesheets, and JavaScript programs.
- The main parts of a web page are:
-- Content - Headings, paragraphs, images, etc.
-- Structure - HTML elements that define sections and layout
-- Presentation - CSS styles that define the look and feel
-- Behavior - JavaScript functions that add interactivity

3. The History of the Internet and Web
- The Internet started as a government project in the 1960s called ARPANET. Researchers developed protocols to allow multiple different networks to connect and exchange data.
- In 1989, Tim Berners-Lee invented the World Wide Web while at CERN. He created HTML, HTTP, and the first web browser.
- In 1993, the first commercial web browser was released, Mosaic. This led to an explosion in websites and web users.
- In the 2000s, the spread of broadband Internet led to new complex web applications like Facebook, YouTube, and Gmail.
- Modern trends include increasing mobile usage, progressive web apps, and voice interfaces.
