Uninformed search, also known as blind search, is a type of problem-solving method in artificial intelligence that does not use any additional information about the problem other than the initial state and the goal state. This type of search is called uninformed because it does not use any additional information, such as heuristics, to guide the search.

Uninformed search algorithms are simple and straightforward, but they can be very slow and inefficient, especially for large or complex problems. The most common uninformed search algorithms are breadth-first search and depth-first search.

Breadth-first search (BFS) is a type of uninformed search that explores all the nodes at the current depth before moving on to the next level. BFS is guaranteed to find the optimal solution if one exists, but it can be very slow for large or complex problems.

Depth-first search (DFS) is a type of uninformed search that explores as far as possible along each branch before backtracking. DFS can be faster than BFS for some problems, but it may not find the optimal solution and it can get stuck in an infinite loop if the search space is not well defined.
