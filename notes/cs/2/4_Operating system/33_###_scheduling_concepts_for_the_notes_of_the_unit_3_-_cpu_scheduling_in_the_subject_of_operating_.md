### Scheduling Concepts for the notes of the Unit 3 - CPU Scheduling in the subject of Operating system

Unit 3 of the Operating System course covers the topic of CPU scheduling. CPU scheduling is the process of determining which process should be executed next by the computer's central processing unit (CPU). The goal of CPU scheduling is to ensure that the CPU is used efficiently and that processes are executed in a timely manner.

There are several scheduling concepts that are used to determine which process should be executed next by the CPU, including:

1. Preemptive scheduling: Preemptive scheduling is a scheduling algorithm that allows the operating system to interrupt a process that is currently running and to execute a different process. This is done to ensure that the CPU is used efficiently and that processes are executed in a timely manner.

2. Non-preemptive scheduling: Non-preemptive scheduling is a scheduling algorithm that does not allow the operating system to interrupt a process that is currently running. Instead, the process is allowed to run to completion before another process is executed.

3. Priority scheduling: Priority scheduling is a scheduling algorithm that assigns a priority to each process, with higher priority processes being executed before lower priority processes.

4. Round Robin scheduling: Round Robin scheduling is a scheduling algorithm that divides the CPU time into equal time slices and allocates a time slice to each process in a cyclic order.

5. Multilevel Queue scheduling: Multilevel Queue scheduling is a scheduling algorithm that divides processes into different priority levels and schedules processes within each priority level using a different scheduling algorithm.

In the context of the Operating System course, students will learn about scheduling concepts as part of Unit 3 - CPU Scheduling. This may include working with simulations of CPU scheduling algorithms, writing code to implement scheduling algorithms, and analyzing the behavior of CPU scheduling algorithms in response to different inputs.

In summary, Unit 3 of the Operating System course covers the topic of CPU scheduling, including preemptive scheduling, non-preemptive scheduling, priority scheduling, round robin scheduling, and multilevel queue scheduling. Students will learn about these topics through interactive activities and hands-on experiences.
