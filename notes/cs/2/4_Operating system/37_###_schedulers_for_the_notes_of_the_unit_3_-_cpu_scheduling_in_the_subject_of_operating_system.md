### Schedulers for the notes of the Unit 3 - CPU Scheduling in the subject of Operating system

A scheduler is a component of an operating system that determines which process should be executed next by the CPU. The scheduler is responsible for allocating the CPU to processes, and for deciding which process should be executed next.

There are several types of schedulers in operating systems, including:

1. Long-term scheduler (or job scheduler): This type of scheduler determines which processes should be admitted to the system for execution.

2. Short-term scheduler (or CPU scheduler): This type of scheduler determines which process should be executed next by the CPU.

3. Medium-term scheduler: This type of scheduler temporarily removes processes from the ready queue and places them in a secondary storage, such as disk, when the system becomes overloaded.

The performance of a scheduler is measured by several metrics, including:

1. Throughput: The number of processes that are completed per unit time.

2. Turnaround time: The time elapsed between the submission of a process and its completion.

3. Waiting time: The time a process spends waiting in the ready queue.

4. Response time: The time elapsed between the submission of a request and the first response to the request.

We will also study the various algorithms used by schedulers, such as first-come, first-served (FCFS), shortest job first (SJF), and round-robin (RR), and compare their performance and limitations. We will also study the impact of scheduling algorithms on the performance of the system, and the trade-offs involved in choosing a scheduling algorithm.
