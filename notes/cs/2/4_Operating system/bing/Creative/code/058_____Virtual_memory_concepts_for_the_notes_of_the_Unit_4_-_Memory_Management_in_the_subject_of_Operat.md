### Virtual memory concepts

- Virtual memory is a technique that allows the execution of processes that are not completely in memory.
- Virtual memory creates the illusion of having more physical memory than actually available by using disk space as an extension of main memory.
- Virtual memory allows multiple processes to share the same physical memory by dividing it into fixed-size units called frames.
- Virtual memory also divides the logical address space of each process into fixed-size units called pages.
- Virtual memory uses a data structure called page table to map the pages of a process to the frames of physical memory.
- Virtual memory allows the operating system to swap out some pages of a process to disk when the physical memory is full or when the process is not using them.
- Virtual memory enables the operating system to implement demand paging, which is a policy that only loads the pages of a process into memory when they are needed.
- Virtual memory improves the utilization of physical memory by allowing more processes to run concurrently and by reducing the internal fragmentation of memory.
- Virtual memory also provides memory protection and isolation by preventing one process from accessing the pages of another process.
- Virtual memory can also support memory sharing and memory mapping by allowing different processes to access the same pages of physical or disk memory.
