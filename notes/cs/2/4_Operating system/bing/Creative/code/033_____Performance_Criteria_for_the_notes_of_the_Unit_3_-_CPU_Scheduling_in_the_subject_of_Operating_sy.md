### Performance Criteria for CPU Scheduling

CPU scheduling is the process of selecting a process from the ready queue and allocating the CPU to it. CPU scheduling aims to maximize the utilization of the CPU and the throughput of the system, while minimizing the turnaround time, waiting time, and response time of the processes. Different CPU scheduling algorithms have different performance criteria, which can be evaluated using the following metrics   :

- **CPU utilization**: The percentage of time the CPU is busy executing processes. The main objective of any CPU scheduling algorithm is to keep the CPU as busy as possible. Theoretically, CPU utilization can range from 0 to 100%, but in a real system, it varies from 40 to 90% depending on the system load.
- **Throughput**: The number of processes that complete their execution per unit of time. Throughput is a measure of the work done by the CPU. Higher throughput means higher productivity of the system.
- **Turnaround time**: The amount of time it takes for a process to finish its execution, from the time it is submitted to the system until the time it is terminated. Turnaround time includes the waiting time in the ready queue, the execution time on the CPU, and the I/O time. Lower turnaround time means faster completion of the processes.
- **Waiting time**: The amount of time a process spends in the ready queue, waiting for its turn to run on the CPU. Waiting time does not include the execution time on the CPU or the I/O time. Lower waiting time means less idle time for the processes.
- **Response time**: The amount of time it takes from when a request is submitted by a process until the first response is produced by the system. Response time is important for interactive processes, such as user applications, that require immediate feedback from the system. Lower response time means better user satisfaction.

Different CPU scheduling algorithms may have different trade-offs among these performance criteria. For example, a CPU scheduling algorithm that favors short processes may have lower turnaround time and response time, but higher waiting time and lower CPU utilization. A CPU scheduling algorithm that favors long processes may have higher throughput and CPU utilization, but lower turnaround time and response time. Therefore, the choice of a CPU scheduling algorithm depends on the goals and requirements of the system.
