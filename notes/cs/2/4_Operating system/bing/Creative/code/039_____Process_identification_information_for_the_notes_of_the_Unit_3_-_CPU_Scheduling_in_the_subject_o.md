### Process identification information
- A process is an instance of a program in execution. It consists of a set of resources such as memory, CPU, files, etc. and a state such as ready, running, waiting, etc.
- A process needs to be identified uniquely by the operating system for management purposes. The operating system assigns a process identification number (PID) to each process when it is created. The PID is an integer that is used to refer to the process in system calls, signals, and other inter-process communication mechanisms.
- The PID is usually stored in a process control block (PCB), which is a data structure that contains various information about the process, such as its state, priority, CPU time, memory allocation, file descriptors, etc. The PCB is maintained by the operating system and is accessed by the CPU scheduler, the memory manager, the file system, and other components.
- The PID is also used to create a process hierarchy, which is a tree-like structure that shows the parent-child relationship among processes. A process can create one or more child processes using the fork() system call, which returns the PID of the child process to the parent process and 0 to the child process. The parent process can also wait for the termination of its child processes using the wait() system call, which returns the PID of the terminated child process. The process hierarchy is useful for organizing processes into groups, sharing resources, and controlling the execution of processes.
- The PID is usually a finite resource, which means that there is a limit on the number of processes that can exist in the system at any time. The operating system may use different methods to allocate and recycle PIDs, such as a bitmap, a linked list, a hash table, etc. The operating system may also impose some restrictions on the range and values of PIDs, such as reserving some PIDs for system processes, avoiding duplicate PIDs, etc.
