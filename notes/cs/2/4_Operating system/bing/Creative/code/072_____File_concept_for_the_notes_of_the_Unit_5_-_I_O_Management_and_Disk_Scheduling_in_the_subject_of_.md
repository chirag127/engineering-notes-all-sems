### File concept
- A file is a collection of related information that is stored on a secondary storage device, such as a disk or a tape.
- A file has a name and attributes, such as type, size, permissions, creation date, etc.
- A file can be accessed by various processes for reading, writing, appending, deleting, or modifying its contents.
- A file can be organized in different ways, such as sequential, direct, or indexed.
- A file system is a software component that manages the files and their attributes on a storage device.
- A file system provides operations for creating, deleting, opening, closing, reading, writing, and manipulating files.
- A file system also maintains the directory structure, which is a hierarchy of folders or directories that contain files and other subdirectories.
- A file system can support different types of files, such as text, binary, executable, or multimedia files.
- A file system can also implement different policies for file allocation, file protection, file sharing, file naming, and file backup.
