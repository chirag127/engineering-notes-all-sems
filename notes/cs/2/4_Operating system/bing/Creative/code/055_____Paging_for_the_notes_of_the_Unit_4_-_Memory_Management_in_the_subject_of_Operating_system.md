### Paging
- Paging is a memory management technique that allows the physical address space of a process to be non-contiguous.
- Paging avoids the problem of external fragmentation by dividing the physical memory into fixed-sized blocks called frames and the logical memory into blocks of the same size called pages.
- When a process is to be executed, its pages are loaded into any available memory frames from their source (disk, for example).
- A page table is used to keep track of the mapping between pages and frames. The page table is stored in the main memory and is accessed by the CPU every time a memory reference is made.
- The page table contains the frame number for each page of the process. The page number and the offset within the page are extracted from the logical address generated by the CPU.
- The frame number and the offset are combined to form the physical address that is sent to the memory unit.
- Paging increases the degree of multiprogramming, as more processes can be loaded into the main memory with less overhead and fragmentation.
- Paging also provides a mechanism for memory protection, as each process has its own page table and cannot access the frames of other processes.
- Paging may introduce some overhead and latency, as the page table needs to be updated and accessed for every memory reference, and some pages may need to be swapped in and out of the main memory to the disk.
