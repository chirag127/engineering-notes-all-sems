# Real Time System

- A real time system is a system that must respond to events within a specified time limit.
- A real time system can be classified into two types: hard real time system and soft real time system.
- A hard real time system is a system that must meet all the deadlines, otherwise it may cause catastrophic consequences. For example, a nuclear reactor control system, a flight control system, etc.
- A soft real time system is a system that can tolerate some missed deadlines, but the quality of service may degrade. For example, a video streaming system, a multimedia system, etc.
- A real time system has some characteristics, such as:
  - Predictability: the system must behave in a predictable manner and produce correct results.
  - Responsiveness: the system must respond to events within the required time limit.
  - Reliability: the system must be able to handle failures and errors gracefully and recover quickly.
  - Adaptability: the system must be able to adapt to changing conditions and requirements.

## Operating System and Functions

- An operating system is a software that manages the hardware and software resources of a computer system and provides services to the user and application programs.
- An operating system has some functions, such as:
  - Process management: the operating system creates, schedules, and terminates processes and provides mechanisms for inter-process communication and synchronization.
  - Memory management: the operating system allocates and deallocates memory to processes and implements memory protection and virtual memory techniques.
  - File system management: the operating system organizes and maintains files and directories on secondary storage devices and provides access control and security mechanisms.
  - Device management: the operating system controls and coordinates the input/output devices and drivers and implements buffering and caching techniques.
  - Network management: the operating system enables the communication and data transfer among different computers and devices over a network and implements protocols and standards.
  - User interface: the operating system provides a user-friendly and interactive interface to the user and application programs, such as command-line interface, graphical user interface, etc.
