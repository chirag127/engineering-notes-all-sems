# Unit 1 - Introduction: Operating system and functions

- An operating system (OS) is a software that manages the hardware and software resources of a computer system and provides common services for the execution of various applications.
- The main functions of an operating system are:
  - Process management: The OS creates and terminates processes, allocates and deallocates resources, schedules and synchronizes processes, handles inter-process communication and deadlock prevention and avoidance.
  - Memory management: The OS manages the main memory and secondary memory, allocates and frees memory space, implements paging and segmentation, handles virtual memory and memory protection.
  - File system management: The OS organizes files and directories, provides file access and security, implements file allocation and free space management, supports file sharing and locking.
  - Device management: The OS controls the input/output devices, allocates and frees device controllers, implements device drivers and interrupt handlers, supports buffering and spooling.
  - Security and protection: The OS protects the system from unauthorized access and malicious attacks, implements authentication and encryption, enforces access control and auditing, handles errors and exceptions.
  - User interface: The OS provides a user-friendly and consistent interface for the users and applications to interact with the system, supports command-line and graphical user interfaces, provides system calls and application programming interfaces.
