## Unit 4 - Memory Management

- Memory management is the process of allocating and deallocating memory to programs and processes in a computer system.
- Memory management can be divided into two levels: hardware and software.
- Hardware memory management involves the physical organization and operation of the memory hardware, such as RAM, ROM, cache, and virtual memory.
- Software memory management involves the logical organization and manipulation of the memory space by the operating system and the applications, such as memory allocation, memory protection, memory sharing, and memory mapping.
- Memory management can also be classified into two types: static and dynamic.
- Static memory management is when the memory allocation and deallocation are done at compile time or load time, and the memory size and location are fixed throughout the program execution.
- Dynamic memory management is when the memory allocation and deallocation are done at run time, and the memory size and location can vary during the program execution.
- Dynamic memory management can be further divided into two schemes: implicit and explicit.
- Implicit memory management is when the memory allocation and deallocation are done automatically by the system, without the programmer's intervention. Examples of implicit memory management are garbage collection and reference counting.
- Explicit memory management is when the memory allocation and deallocation are done manually by the programmer, using specific commands or functions. Examples of explicit memory management are malloc and free in C, and new and delete in C++.
- Memory management can affect the performance, reliability, and security of a computer system. Therefore, it is important to design and implement efficient and effective memory management techniques and algorithms.
