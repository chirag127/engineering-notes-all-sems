# Time Sharing

Time-sharing is a technique that allows multiple users to share the resources of a single computer system simultaneously. This is achieved by rapidly switching the CPU between the different user programs, giving the illusion that each user has their own dedicated system. Time-sharing is a key concept in the design of operating systems and is used to increase the efficiency and utilization of computer systems.

Some key points to note about time-sharing systems are:

- Time-sharing systems are designed to support multiple users simultaneously.
- The CPU is rapidly switched between different user programs to give the illusion of dedicated systems for each user.
- Time-sharing increases the efficiency and utilization of computer systems.
- Time-sharing is a key concept in the design of operating systems.
