### Process States

In the subject of Operating System, Unit 3 - CPU Scheduling, one of the important topics is Process States. Here are the key points to note:

1. A process is a program in execution. It is an active entity and can be in one of several states during its lifetime.
2. The state of a process is defined by its current activity. The various states that a process can be in are: New, Ready, Running, Waiting, and Terminated.
3. The **New** state is when a process is being created. It is the initial state of a process when it is first admitted into the system.
4. The **Ready** state is when a process is loaded into main memory and is ready to execute, but is waiting for the CPU to become available.
5. The **Running** state is when a process is currently being executed by the CPU.
6. The **Waiting** state is when a process is waiting for some event to occur, such as an I/O operation to complete, before it can continue execution.
7. The **Terminated** state is when a process has completed its execution and is removed from the system.
