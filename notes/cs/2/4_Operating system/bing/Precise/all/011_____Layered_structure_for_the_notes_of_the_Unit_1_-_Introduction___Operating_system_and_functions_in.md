# Unit 1 - Introduction: Operating System and Functions

### Layered Structure

1. The layered structure is a design approach to operating systems where the system is divided into a number of layers, each of which provides a set of functions.
2. Each layer uses the functions of the layer below it and provides functions to the layer above it.
3. The lowest layer, layer 0, interacts directly with the hardware, while the highest layer, the user interface, interacts with the user.
4. This approach simplifies the design and implementation of the operating system by breaking it down into smaller, more manageable components.
5. It also provides a level of abstraction, allowing changes to be made to one layer without affecting the others.
6. One example of an operating system that uses a layered structure is the THE operating system, developed at the Technische Hogeschool Eindhoven in the Netherlands.
