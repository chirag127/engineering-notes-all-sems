# System Components

- An operating system (OS) is a software that manages the resources of a computer system and provides services to the users and applications.
- A computer system consists of four main components: hardware, operating system, application programs, and users.
- Hardware: The physical devices that make up the computer system, such as the CPU, memory, disk, keyboard, mouse, monitor, etc.
- Operating system: The software that controls the hardware and coordinates the execution of application programs.
- Application programs: The software that performs specific tasks for the users, such as word processing, web browsing, gaming, etc.
- Users: The people who interact with the computer system, either directly or indirectly, through terminals, network, or other devices.

## Hardware

- The hardware provides the basic computing resources for the system, such as processing power, storage space, input/output devices, etc.
- The hardware components are organized in a hierarchical manner, with the CPU at the top, followed by the main memory, the secondary storage, and the input/output devices.
- The CPU (central processing unit) is the brain of the computer system. It executes the instructions of the programs and performs arithmetic and logical operations.
- The main memory (also called RAM or random access memory) is the primary storage area for the programs and data that are currently in use by the CPU. It is volatile, meaning that its contents are lost when the power is turned off.
- The secondary storage (also called disk or hard disk) is the permanent storage area for the programs and data that are not currently in use by the CPU. It is non-volatile, meaning that its contents are preserved when the power is turned off.
- The input/output devices (also called peripherals) are the devices that allow the user to communicate with the computer system, such as the keyboard, mouse, monitor, printer, scanner, etc.

## Operating System

- The operating system is the software that acts as an intermediary between the hardware and the application programs.
- The operating system has two main objectives: to make the computer system convenient to use and to utilize the computer hardware efficiently.
- The operating system performs various functions, such as:

  - Process management: The operating system creates and terminates processes, allocates and deallocates resources, schedules and synchronizes processes, handles process communication and coordination, etc.
  - Memory management: The operating system manages the main memory, allocates and deallocates memory space, implements virtual memory, handles memory protection and sharing, etc.
  - File system management: The operating system manages the secondary storage, organizes files and directories, provides file access and manipulation, implements file security and protection, etc.
  - Device management: The operating system manages the input/output devices, allocates and deallocates devices, implements device drivers, handles device interrupts and errors, etc.
  - Security and protection: The operating system protects the system from unauthorized access and malicious attacks, implements authentication and authorization, enforces access control and encryption, etc.
  - User interface: The operating system provides a user interface that allows the user to interact with the system, such as a command-line interface (CLI) or a graphical user interface (GUI).
  - System utilities: The operating system provides various system utilities that perform specific tasks, such as backup and restore, disk defragmentation, virus scanning, etc.

## Application Programs

- The application programs are the software that perform specific tasks for the users, such as word processing, web browsing, gaming, etc.
- The application programs use the services provided by the operating system to access the hardware resources and perform their functions.
- The application programs can be classified into two categories: system programs and application programs.
- System programs are the programs that are part of the operating system or are closely associated with it, such as compilers, editors, debuggers, etc.
- Application programs are the programs that are not part of the operating system and are developed by the users or third-party vendors, such as Microsoft Word, Google Chrome, Fortnite, etc.
