# Batch for the notes of the Unit 1 - Introduction : Operating system and functions in the subject of Operating system

- An operating system (OS) is a software program that manages the hardware and software resources of a computer.
- The OS performs basic tasks, such as controlling and allocating memory, prioritizing the processing of instructions, controlling input and output devices, facilitating network communication, and managing files.
- The OS also provides a user interface, such as a graphical user interface (GUI), that allows users to interact with the computer and its applications.
- The OS can be classified into different types based on various criteria, such as the number of users, the number of tasks, the type of hardware, the type of interface, the level of security, etc.
- Some common types of OS are:
  - Single-user OS: Only one user can access the computer at a time. Example: MS-DOS.
  - Multi-user OS: Multiple users can access the computer simultaneously. Example: UNIX, Linux, Windows Server.
  - Single-tasking OS: Only one program can run at a time. Example: Palm OS.
  - Multi-tasking OS: Multiple programs can run concurrently. Example: Windows, MacOS, Android.
  - Real-time OS: The OS responds to events or inputs within a fixed time interval. Example: Embedded systems, such as robots, sensors, etc.
  - Batch OS: The OS processes a batch of similar jobs at a time, without user interaction. Example: Mainframe computers, such as IBM 360.
  - Distributed OS: The OS manages a network of computers that work together as a single system. Example: Hadoop, Spark, etc.
  - Hybrid OS: The OS combines the features of two or more types of OS. Example: Windows NT, which is both a multi-user and a multi-tasking OS.

- The OS performs various functions, such as:
  - Process management: The OS creates, schedules, and terminates processes, and manages the communication and synchronization among them.
  - Memory management: The OS allocates and deallocates the main memory and the secondary memory to the processes, and implements techniques such as paging, segmentation, virtual memory, etc.
  - Device management: The OS controls and coordinates the input and output devices, such as keyboards, mice, printers, scanners, etc., and implements techniques such as buffering, caching, spooling, etc.
  - File management: The OS organizes and maintains the files and directories on the disk, and implements techniques such as file allocation, file protection, file sharing, etc.
  - Security management: The OS protects the system and the data from unauthorized access, and implements techniques such as authentication, encryption, firewall, etc.
  - User interface: The OS provides a user-friendly and consistent way of interacting with the system and the applications, and implements techniques such as menus, icons, windows, etc.
