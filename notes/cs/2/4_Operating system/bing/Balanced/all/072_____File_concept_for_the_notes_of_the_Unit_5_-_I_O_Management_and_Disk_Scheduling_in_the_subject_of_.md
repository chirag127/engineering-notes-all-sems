# File Concept

- A file is a collection of related information that is stored on a secondary storage device, such as a disk or a tape.
- A file has a name and some attributes, such as type, size, location, protection, and access permissions.
- A file can contain any type of data, such as text, images, audio, video, executable code, etc.
- A file can be viewed as a logical unit of information that is created and manipulated by users and processes.
- A file can be accessed in different modes, such as sequential, random, or direct.
- A file can be organized in different ways, such as fixed-length records, variable-length records, or unstructured streams of bytes.
- A file can be shared by multiple users and processes, either concurrently or exclusively.
- A file can be protected by various mechanisms, such as encryption, passwords, access control lists, etc.
- A file can be manipulated by various operations, such as create, open, read, write, append, delete, rename, copy, move, etc.
- A file can be associated with some metadata, such as creation time, modification time, owner, group, etc.
