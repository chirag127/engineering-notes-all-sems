# Real Time System

A real time system is a system that offers the guarantees real time applications a specific ability along with a particular deadline. A real time system processes data and events that have critically defined time constraints. A real time system is distinct from a time-sharing operating system, such as Unix, which manages the sharing of system resources with a scheduler, data buffers, or fixed task priorities.

## Operating System and Functions

An operating system (OS) is a software that manages the hardware and software resources of a computer system and provides common services for the execution of various application programs. An operating system performs the following functions:

- Process management: The operating system creates and terminates processes, allocates and deallocates resources, schedules and dispatches processes, and handles inter-process communication and synchronization .
- Memory management: The operating system manages the main memory and secondary memory of the computer system, allocates and frees memory space, implements virtual memory and paging, and handles memory protection and sharing .
- Device management: The operating system controls the input and output devices of the computer system, allocates and frees device channels, implements device drivers and interrupt handlers, and performs buffering and spooling .
- File management: The operating system manages the files and directories of the computer system, allocates and frees disk space, implements file systems and access methods, and handles file protection and security .
- User interface: The operating system provides a user interface that allows the user to interact with the computer system, such as a command-line interface or a graphical user interface .
