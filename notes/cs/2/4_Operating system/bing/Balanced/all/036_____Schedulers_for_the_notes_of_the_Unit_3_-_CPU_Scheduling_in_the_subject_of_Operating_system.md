# Schedulers for the notes of the Unit 3 - CPU Scheduling in the subject of Operating System

- Schedulers are the components of the operating system that decide which processes should be executed by the CPU and when.
- Schedulers are essential for achieving efficient utilization of the CPU and other system resources, as well as providing fairness and responsiveness to the processes.
- There are three types of schedulers in operating systems: long-term, mid-term, and short-term schedulers.
- Long-term scheduler (or admission scheduler) is responsible for selecting the processes that are admitted into the ready queue, where they wait for the CPU. It controls the degree of multiprogramming, which is the number of processes that are in memory at the same time. It runs infrequently and may use complex criteria to decide which processes to admit, such as priority, memory requirements, I/O devices, etc.
- Mid-term scheduler (or medium-term scheduler) is responsible for swapping out some of the processes from the main memory to the secondary memory (such as disk) when the degree of multiprogramming is too high and the main memory is overloaded. It also swaps in some of the processes from the secondary memory to the main memory when the degree of multiprogramming is too low and the CPU is underutilized. It runs more frequently than the long-term scheduler and may use criteria such as memory usage, CPU time, I/O requests, etc. to decide which processes to swap.
- Short-term scheduler (or CPU scheduler) is responsible for selecting the next process to run on the CPU from the ready queue. It runs very frequently (every few milliseconds) and may use various algorithms to decide which process to run, such as first-come first-served (FCFS), shortest job first (SJF), priority, round robin (RR), etc. It may also preempt the currently running process if a higher priority process arrives or if the current process exceeds its time quantum. The short-term scheduler affects the performance, throughput, turnaround time, waiting time, and response time of the processes.
