### System Components for the notes of the Unit 1 - Introduction : Operating system and functions

An operating system (OS) is a program that manages a computer's resources, especially the allocation of those resources among other programs. An operating system is a large and complex system that can only be created by partitioning into small pieces. These pieces are called system components, and they help to manage different areas of the computer. Some of the main system components are:

- **Process Management**: A process is a program in execution. A process can be suspended temporarily and the execution can be resumed later. Process management is the component that handles the creation, deletion, scheduling, synchronization, and communication of processes . It also handles the allocation of CPU time and memory to the processes.
- **File Management**: A file is a collection of related information that is defined by its creator. Files are used for long-term storage and for both input and output. File management is the component that handles the creation, deletion, modification, organization, and access of files . It also handles the allocation of disk space and the protection of files from unauthorized access.
- **Network Management**: A network is a collection of computers and devices that are connected by communication channels. Network management is the component that handles the establishment, maintenance, and termination of network connections. It also handles the transmission and reception of data, the routing of packets, the security of network communication, and the resolution of network errors.
- **Main Memory Management**: Main memory is the primary storage area of the computer, where the data and instructions are stored temporarily while being processed by the CPU. Main memory management is the component that handles the allocation and deallocation of main memory to the processes and files . It also handles the swapping and paging of data between main memory and secondary storage, and the protection of memory from unauthorized access.
- **Secondary Storage Management**: Secondary storage is the non-volatile storage area of the computer, where the data and instructions are stored permanently. Secondary storage management is the component that handles the allocation and deallocation of secondary storage to the files . It also handles the formatting and partitioning of disks, the backup and recovery of data, and the optimization of disk performance.
- **I/O Device Management**: I/O devices are the peripherals of the computer, such as keyboards, mice, monitors, printers, scanners, etc. I/O device management is the component that handles the detection, configuration, and control of I/O devices . It also handles the buffering, caching, and spooling of data, and the error handling of I/O operations.
- **Security Management**: Security management is the component that handles the protection of the computer system and its resources from unauthorized access, modification, or damage. It also handles the authentication, authorization, encryption, and auditing of users and processes, and the detection and prevention of malicious attacks.
- **Command Interpreter System**: Command interpreter system is the component that handles the interaction between the user and the operating system. It can be a graphical user interface (GUI) or a command-line interface (CLI). It allows the user to enter commands, execute programs, and view the results . It also provides feedback, help, and error messages to the user.
