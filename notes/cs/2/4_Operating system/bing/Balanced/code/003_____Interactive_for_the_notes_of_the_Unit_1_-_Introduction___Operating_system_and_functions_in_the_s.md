### Interactive

- An interactive operating system is one that allows the user to interact with the system through a graphical user interface (GUI) or a command-line interface (CLI).
- An interactive operating system provides features such as:
  - Multitasking: the ability to run multiple programs or processes at the same time.
  - Multiprogramming: the ability to load multiple programs or processes into the memory and switch between them.
  - Multithreading: the ability to divide a program or process into smaller units of execution called threads that can run concurrently.
  - Interprocess communication: the ability to exchange data or signals between different processes or threads.
  - Synchronization: the ability to coordinate the execution of multiple processes or threads that share resources or data.
  - Memory management: the ability to allocate and deallocate the memory space for processes or threads and to protect the memory from unauthorized access or modification.
  - File system: the ability to organize and store data in files and directories and to provide access and security mechanisms for them.
  - Device management: the ability to control and communicate with the input/output devices such as keyboard, mouse, monitor, printer, disk, etc.
  - Network management: the ability to connect and communicate with other computers or devices over a network and to provide network services such as file transfer, email, web browsing, etc.
- Examples of interactive operating systems are:
  - Windows: a family of operating systems developed by Microsoft that run on personal computers, servers, mobile devices, etc.
  - Linux: a family of operating systems based on the Linux kernel that run on various platforms such as personal computers, servers, mobile devices, etc.
  - MacOS: a family of operating systems developed by Apple that run on Macintosh computers and other Apple devices.
  - Android: a mobile operating system based on the Linux kernel and developed by Google that runs on smartphones, tablets, etc.
  - iOS: a mobile operating system developed by Apple that runs on iPhones, iPads, etc.
