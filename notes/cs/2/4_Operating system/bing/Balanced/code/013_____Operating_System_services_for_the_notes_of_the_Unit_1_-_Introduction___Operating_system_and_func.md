### Operating System services

- An operating system (OS) is a software that manages the hardware and software resources of a computer system and provides common services for the programs that run on it.
- The operating system services are the functions that the OS performs for the users and the system. Some of the common OS services are:

  - **User interface**: The OS provides a user interface that allows the users to interact with the system. The user interface can be graphical (GUI), command-line (CLI), or batch (BI).
  - **Program execution**: The OS loads the programs into the memory and runs them on the processor. The OS also handles the termination of the programs, either normally or abnormally (due to errors).
  - **I/O operations**: The OS controls the input and output devices and provides functions for the programs to perform I/O operations. The OS also handles the buffering, caching, and spooling of the I/O data.
  - **File system manipulation**: The OS manages the file system, which organizes the data on the storage devices. The OS provides functions for the programs to create, delete, read, write, and modify files and directories.
  - **Communication**: The OS enables the communication between processes, either on the same computer or on different computers connected by a network. The communication can be message-based or shared-memory-based.
  - **Error detection**: The OS detects and corrects the errors that may occur in the hardware or software components of the system. The OS also provides mechanisms for the programs to report and handle errors.
  - **Resource allocation**: The OS allocates the resources, such as CPU, memory, disk, and network, to the processes according to some policies. The OS also deals with the contention and deadlock situations that may arise due to the resource allocation.
  - **Accounting**: The OS keeps track of the usage of the resources and the performance of the system. The OS also provides functions for the users to monitor and control the system activities.
  - **Protection and security**: The OS protects the system and the data from unauthorized access and malicious attacks. The OS also provides functions for the users to authenticate and authorize themselves and their actions.
