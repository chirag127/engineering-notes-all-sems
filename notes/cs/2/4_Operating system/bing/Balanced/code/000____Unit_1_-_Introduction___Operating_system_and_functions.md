## Unit 1 - Introduction: Operating system and functions

- An operating system (OS) is a software that manages the hardware and software resources of a computer system and provides common services for the execution of various applications.
- The main functions of an operating system are:
  - Process management: The OS creates and terminates processes, allocates and deallocates memory and CPU resources, handles inter-process communication and synchronization, and provides mechanisms for process scheduling and deadlock prevention.
  - Memory management: The OS manages the physical and virtual memory of the system, allocates and frees memory pages, implements paging and swapping techniques, and provides memory protection and address translation.
  - File system management: The OS organizes the data on the secondary storage devices, such as disks and tapes, into files and directories, and provides operations for creating, deleting, reading, writing, and modifying files and directories.
  - Device management: The OS controls the input and output devices, such as keyboards, mice, monitors, printers, disks, and network cards, and provides drivers and interfaces for communicating with the devices.
  - Security and protection: The OS protects the system from unauthorized access and malicious attacks, and enforces policies and mechanisms for authentication, authorization, encryption, auditing, and backup.
  - User interface: The OS provides a user-friendly and consistent interface for the users to interact with the system, such as graphical user interface (GUI), command-line interface (CLI), or application programming interface (API).

- The main components of an operating system are:
  - Kernel: The core part of the OS that runs in the privileged mode and performs the essential functions of process, memory, file system, and device management.
  - Shell: The part of the OS that runs in the user mode and provides the user interface for the OS, such as GUI or CLI.
  - System programs: The programs that run in the user mode and provide various services and utilities for the OS, such as compilers, editors, file managers, network managers, etc.

- The main types of operating systems are:
  - Single-user and single-tasking: The OS that supports only one user and one task at a time, such as MS-DOS.
  - Single-user and multi-tasking: The OS that supports only one user but multiple tasks at a time, such as Windows and Mac OS.
  - Multi-user and multi-tasking: The OS that supports multiple users and multiple tasks at a time, such as Unix and Linux.
  - Real-time: The OS that responds to the events or inputs within a specified time limit, such as embedded systems and control systems.
  - Distributed: The OS that runs on multiple computers connected by a network and provides the illusion of a single system, such as Amoeba and Plan 9.
  - Mobile: The OS that runs on mobile devices, such as smartphones and tablets, and provides features such as touch screen, GPS, camera, etc., such as Android and iOS.
