### Operating System Structure for the notes of the Unit 1 - Introduction : Operating system and functions in the subject of Operating system

An operating system (OS) is a collection of software that manages computer hardware resources and provides common services for computer programs. The structure of an operating system can be divided into several components, including:

1. The kernel: This is the central part of the operating system that provides low-level services, such as memory management and process management.

2. System calls: These are the interface between the kernel and user-level programs, and allow programs to request services from the kernel.

3. Libraries: These are collections of pre-written code that can be used by programs to perform common tasks, such as reading and writing files.

4. Shell: This is a command-line interface that allows users to interact with the operating system and run programs.

5. File system: This is the component of the operating system that manages the organization and storage of files on disk.

6. Process management: This is the component of the operating system that manages the execution of processes, including creating and terminating processes, and scheduling them for execution.

7. Memory management: This is the component of the operating system that manages the allocation and deallocation of memory to processes.

In this unit, we will study the structure of operating systems, including the components listed above. We will examine the role of each component in the overall functioning of the operating system, and study the relationships between the components. We will also study the different types of operating systems, such as monolithic kernels, microkernels, and hybrid kernels, and compare their advantages and disadvantages.
