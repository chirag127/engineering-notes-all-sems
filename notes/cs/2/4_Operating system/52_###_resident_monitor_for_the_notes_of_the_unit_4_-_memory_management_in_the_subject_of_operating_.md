### Resident monitor for the notes of the Unit 4 - Memory Management in the subject of Operating system

Resident monitor is a type of memory management technique used in operating systems to manage memory. A resident monitor is a program that remains in memory at all times, and provides services to other programs.

The resident monitor is responsible for managing the allocation and deallocation of memory, and for ensuring that the memory is used efficiently. The resident monitor can be used to implement various memory management techniques, such as paging, segmentation, and virtual memory.

In paging, the resident monitor divides the memory into fixed-sized pages and allocates pages to processes as needed. In segmentation, the resident monitor divides the memory into variable-sized segments and allocates segments to processes as needed. In virtual memory, the resident monitor uses a combination of paging and swapping to provide a large, virtual memory space to processes, even if the physical memory is limited.
