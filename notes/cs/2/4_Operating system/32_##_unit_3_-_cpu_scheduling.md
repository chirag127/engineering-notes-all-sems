## Unit 3 - CPU Scheduling

CPU scheduling is the process of selecting a process from the ready queue and assigning it to the CPU for execution. The goal of CPU scheduling is to optimize the use of the CPU and ensure that processes are executed efficiently and fairly.

There are several CPU scheduling algorithms that can be used to determine which process should be executed next. Some of the most common algorithms include:

1. First-Come, First-Served (FCFS): This algorithm executes processes in the order in which they arrive in the ready queue.

2. Shortest Job First (SJF): This algorithm executes the process with the shortest burst time first.

3. Round Robin (RR): This algorithm allocates a fixed time quantum to each process and rotates through the ready queue, executing each process for its time quantum before moving on to the next process.

4. Priority Scheduling: This algorithm assigns a priority to each process and executes the process with the highest priority first.

5. Multilevel Queue Scheduling: This algorithm organizes processes into multiple priority levels and executes processes within each level using a different scheduling algorithm.

In this unit, we will study the concepts of CPU scheduling, including the algorithms listed above. We will examine the advantages and disadvantages of each algorithm, and study the relationship between CPU scheduling and other operating system concepts, such as process management and memory management. We will also study the performance of CPU scheduling algorithms and the factors that affect the performance of these algorithms.
