### Performance Criteria for the notes of the Unit 3 - CPU Scheduling in the subject of Operating system

Unit 3 of the Operating System course covers the topic of CPU scheduling, which is the process of determining which process should be executed next by the CPU. The goal of CPU scheduling is to maximize the performance of the computer system.

There are several performance criteria that are used to evaluate the performance of CPU scheduling algorithms. These criteria include:

1. CPU utilization: The CPU utilization measures the percentage of time that the CPU is busy executing processes. The goal is to maximize CPU utilization.

2. Throughput: The throughput measures the number of processes that are completed per unit of time. The goal is to maximize throughput.

3. Turnaround time: The turnaround time measures the time elapsed between the submission of a process and its completion. The goal is to minimize turnaround time.

4. Waiting time: The waiting time measures the amount of time that a process spends waiting to be executed. The goal is to minimize waiting time.

5. Response time: The response time measures the time elapsed between the submission of a request and the first response from the system. The goal is to minimize response time.

In the context of the Operating System course, students will learn about the performance criteria used to evaluate CPU scheduling algorithms as part of Unit 3 - CPU Scheduling. This may include writing code to implement different CPU scheduling algorithms, comparing the performance of different algorithms using the performance criteria, and analyzing the behavior of CPU scheduling algorithms in response to different inputs.

In summary, Unit 3 of the Operating System course covers the topic of CPU scheduling and the performance criteria used to evaluate the performance of CPU scheduling algorithms. These criteria include CPU utilization, throughput, turnaround time, waiting time, and response time. Students will learn about these topics through interactive activities and hands-on experiences.
