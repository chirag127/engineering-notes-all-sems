### Interactive for the notes of the Unit 1 - Introduction : Operating system and functions in the subject of Operating system

In this unit, we will learn about the basics of Operating System and its functions. Here are some interactive notes to help you understand the topic better:

- An Operating System (OS) is a collection of software programs that manage computer hardware resources and provide common services for computer programs. The OS acts as an interface between the user and the computer hardware. 

- The main functions of Operating System are:

  - Memory Management
  - Process Management
  - Security
  - File System Management
  - Device Management
  - User Interface

- Memory Management is the process of allocating and de-allocating memory space to different programs and processes.

- Process Management involves managing the execution of processes, scheduling them and ensuring that they are executed in an efficient and effective manner.

- Security is a critical function of the Operating system. It involves protecting the system from unauthorized access and ensuring that data is safe and secure.

- File System Management is the process of organizing and managing files on the system. It involves creating, deleting and modifying files and directories.

- Device Management involves managing the input and output devices of the system such as printers, keyboards, and mice.

- User Interface is the way in which users interact with the system. It includes the graphical user interface (GUI) and the command-line interface (CLI).

- Operating systems can be classified into several types such as Batch Operating System, Time-Sharing Operating System, Distributed Operating System, and Real-Time Operating System.

- Some popular Operating Systems are Windows, macOS, Linux, Unix, and Android.
