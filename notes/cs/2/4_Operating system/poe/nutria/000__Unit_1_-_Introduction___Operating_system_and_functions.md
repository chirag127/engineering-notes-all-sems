
## Unit 1 - Introduction : Operating System and Functions

1. An operating system (OS) is a software program that manages the hardware and software resources of a computer. 
2. It is responsible for the management and coordination of activities and the sharing of the resources of the computer. 
3. The operating system acts as an intermediary between the user and the computer hardware. 
4. It allows the user to interact with the computer without having to understand the details of the computer's hardware components. 
5. The operating system also provides a platform for the execution of application programs. 
6. Common functions of an operating system include managing memory, scheduling tasks, controlling input and output devices, and providing a user interface. 
7. A typical operating system consists of a kernel, device drivers, system libraries, and system utilities. 
8. The kernel is the core of the operating system and provides basic services such as memory management, process management, and device management. 
9. Device drivers are programs that allow the operating system to interact with hardware devices. 
10. System libraries are collections of functions that provide a higher-level interface to the operating system. 
11. System utilities are programs that perform system-level tasks such as file management, system monitoring, and system maintenance.
