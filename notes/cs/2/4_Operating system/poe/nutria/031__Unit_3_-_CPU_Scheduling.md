
## Unit 3 - CPU Scheduling

1. CPU scheduling is the process of determining which process should be allocated to the CPU and when.
2. CPU scheduling algorithms are used to improve system performance and provide better service to the users.
3. CPU scheduling algorithms can be classified into two categories: preemptive and non-preemptive.
4. Preemptive algorithms allow the CPU to be taken away from a process and allocated to another process.
5. Non-preemptive algorithms allow the CPU to remain with a process until it completes its execution or is blocked.
6. CPU scheduling algorithms can be further divided into different categories based on their approach.
7. These include: 
    - First Come First Serve (FCFS)
    - Shortest Job First (SJF)
    - Priority Scheduling
    - Round Robin (RR)
    - Multilevel Queue
    - Multilevel Feedback Queue
8. Each algorithm has its own advantages and disadvantages.
9. It is important to select the appropriate algorithm for a given system in order to achieve the best performance.
