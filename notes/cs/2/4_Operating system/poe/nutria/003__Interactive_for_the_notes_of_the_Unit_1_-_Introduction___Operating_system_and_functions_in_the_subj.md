
### Interactive for the notes of the Unit 1 - Introduction : Operating system and functions in the subject of Operating system

1. An operating system (OS) is a set of programs that manage the hardware and software resources of a computer. 
2. It is responsible for the management and coordination of activities and the sharing of resources of the computer. 
3. The OS acts as an intermediary between the user and the computer hardware, allowing the user to interact with the hardware in a more user-friendly way. 
4. It also provides a platform for running application software.
5. Operating systems are typically divided into three main components: kernel, shell, and user interface. 
6. The kernel is the core of the operating system and is responsible for managing the hardware and memory resources of the computer. 
7. The shell is a user interface that provides a way for users to interact with the operating system. 
8. The user interface is the graphical part of the operating system that provides an easy-to-use interface for users to interact with the system. 
9. Operating systems also provide various services such as file and device management, memory management, networking, and security. 
10. Operating systems can be divided into two main categories: single-user and multi-user. 
11. Single-user operating systems are designed to be used by one user at a time, while multi-user operating systems allow multiple users to access the system simultaneously.
