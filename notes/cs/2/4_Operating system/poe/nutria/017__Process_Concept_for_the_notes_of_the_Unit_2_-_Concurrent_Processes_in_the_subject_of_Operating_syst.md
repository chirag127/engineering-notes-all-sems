
### Process Concept for the Notes of Unit 2 - Concurrent Processes in Operating System

1. A process is an instance of a program running in a computer. It is the unit of work in a system.
2. A process is a dynamic entity that consists of a program counter, a set of registers, a set of data, a set of resources, and an execution stack.
3. A process can be in one of the following states: running, ready, waiting, or terminated.
4. A process is said to be concurrent when two or more processes are executing simultaneously.
5. Process synchronization is the process of coordinating the activities of multiple processes in order to ensure the correctness of the system.
6. Semaphores are a synchronization mechanism that can be used to control access to shared resources.
7. Deadlock is a situation in which two or more processes are unable to progress due to a circular dependency of resources.
8. Scheduling algorithms are used to determine which process should be executed next.
9. CPU scheduling is the process of deciding which process should be executed next on the CPU.
10. Memory management is the process of allocating memory to processes and managing the memory once it has been allocated.
