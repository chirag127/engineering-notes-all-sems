
### Process Address Space for the Notes of the Unit 3 - CPU Scheduling in the Subject of Operating System

1. Process address space is the area of memory allocated to a process. It is the range of memory addresses that the process can access.
2. The address space of a process is divided into three parts: code, data and stack.
3. The code segment contains the instructions that the process must execute.
4. The data segment contains the global and static variables used by the process.
5. The stack segment contains the local variables used by the process.
6. CPU scheduling is the process of selecting a process from a queue of processes and allocating the CPU resources to it.
7. CPU scheduling algorithms are used to decide which process to select from the queue and when to switch between processes.
8. The most common CPU scheduling algorithms are First Come First Serve (FCFS), Shortest Job First (SJF), Priority Scheduling, Round Robin (RR), and Multilevel Queue Scheduling.
9. FCFS scheduling algorithm selects the process that arrives first in the queue.
10. SJF scheduling algorithm selects the process with the shortest burst time.
11. Priority scheduling algorithm selects the process with the highest priority.
12. Round Robin scheduling algorithm selects the processes in a circular fashion.
13. Multilevel Queue scheduling algorithm divides the ready queue into multiple queues and assigns each process to a specific queue.
