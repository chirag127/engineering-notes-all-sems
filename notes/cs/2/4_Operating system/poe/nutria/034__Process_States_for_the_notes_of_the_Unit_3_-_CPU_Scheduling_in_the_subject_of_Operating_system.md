
### Process States

1. **New**: A process is in the new state when it is first created. At this point, the process is not yet associated with any processor or memory.

2. **Ready**: A process is in the ready state when it is waiting to be assigned to a processor. Processes in the ready state are stored in a queue, which is managed by the operating system.

3. **Running**: A process is in the running state when it is actively being executed by a processor.

4. **Waiting**: A process is in the waiting state when it is waiting for some external event to occur (e.g. user input, completion of an I/O request, etc).

5. **Terminated**: A process is in the terminated state when it has finished executing. At this point, the process is no longer associated with any processor or memory.
