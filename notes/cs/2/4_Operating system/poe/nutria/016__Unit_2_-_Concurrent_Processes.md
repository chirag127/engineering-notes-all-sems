
## Unit 2 - Concurrent Processes

1. Concurrent processes are processes that execute simultaneously and independently of each other.
2. Concurrent processes can be used to improve the performance and efficiency of computer systems.
3. Concurrent processes are implemented using threads, which are independent sequences of instructions that can be executed in parallel.
4. Threads can be used to execute multiple tasks at the same time, such as reading and writing files, or performing calculations.
5. Threads can also be used to improve the responsiveness of applications, by allowing them to respond to user input while still performing background tasks.
6. Concurrent processes can also be used to improve the reliability of computer systems, by allowing them to continue running even if one process fails.
7. A key concept in concurrent programming is synchronization, which is the process of ensuring that multiple threads are able to access and modify shared data without interfering with each other.
8. Synchronization can be achieved using locks, semaphores, and other synchronization primitives.
9. Concurrent programming can be challenging, as it requires the programmer to think carefully about how multiple threads will interact with each other.
10. Debugging concurrent programs can also be difficult, as it can be hard to reproduce the exact conditions that caused an error.
