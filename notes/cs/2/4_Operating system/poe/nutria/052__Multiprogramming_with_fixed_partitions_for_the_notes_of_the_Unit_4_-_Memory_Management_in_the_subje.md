
### Multiprogramming with Fixed Partitions

* Multiprogramming is the process of running multiple programs at the same time. 
* Fixed partitioning is a memory management technique which divides the main memory into several equal-sized partitions. 
* Each partition is allocated to a single program, and the size of the partition is fixed. 
* This technique is useful for systems that run multiple programs of the same type, such as a batch processing system. 
* It is also used in systems with limited memory, where the size of the partition is determined by the amount of memory available. 
* Fixed partitioning allows efficient memory utilization by reusing memory blocks. 
* It also ensures that the system is protected from memory overruns, since each program is allocated a fixed amount of memory. 
* However, this technique is not suitable for systems that require dynamic memory allocation, since the size of the partitions cannot be changed.
