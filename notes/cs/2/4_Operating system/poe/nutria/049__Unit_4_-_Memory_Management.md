
## Unit 4 - Memory Management

1. Memory Management is the process of managing computer memory. It involves allocating memory to programs and processes, as well as deallocating memory when programs and processes no longer require it.

2. Memory management is a critical component of an operating system, as it is responsible for allocating resources to programs and processes and ensuring that all memory is used efficiently.

3. Memory management is divided into two main categories: virtual memory and physical memory. Virtual memory is a system of using hard disk space as additional RAM, while physical memory is the RAM installed in a computer.

4. Memory management also involves the management of cache memory, which is a type of memory that stores frequently used data. By managing cache memory, the operating system can quickly access the data it needs, rather than having to search the hard disk each time it needs the data.

5. Memory management also involves the management of memory fragmentation. Memory fragmentation occurs when memory is allocated in small chunks, which can lead to wasted memory. To prevent this, memory management techniques are used to ensure that memory is allocated in large, contiguous chunks.

6. Memory management techniques can also be used to protect memory from unauthorized access. This is done by using memory protection techniques such as address space layout randomization (ASLR) and data execution prevention (DEP).
