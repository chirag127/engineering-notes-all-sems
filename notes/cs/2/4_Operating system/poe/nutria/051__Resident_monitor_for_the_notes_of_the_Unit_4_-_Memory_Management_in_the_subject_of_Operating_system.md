
### Resident Monitor for the notes of the Unit 4 - Memory Management in the subject of Operating System

* Resident monitor is a part of the operating system that is responsible for managing memory.
* It is responsible for allocating and de-allocating memory space to the various processes.
* It ensures that each process gets its required amount of memory and that no two processes are occupying the same memory space.
* It also ensures that the memory is not over-allocated, leading to memory fragmentation.
* Resident monitor also keeps track of the memory usage of each process and the amount of free memory available in the system.
* It also helps in garbage collection, where the memory occupied by a process is released when the process completes.
* It also helps in virtual memory management, where physical memory is allocated to the processes according to their needs.
