
### Deadlock for the Notes of Unit 3 - CPU Scheduling in Operating System

1. Deadlock is a state of a system in which two or more processes are blocked indefinitely, as they are each waiting for an event that can only be caused by the other process.

2. Deadlock can occur in a system with multiple CPUs, multiple processes, and resources that are shared between processes.

3. Deadlock can be avoided by using various algorithms such as Banker's Algorithm, Resource Allocation Graph, and Deadlock Prevention.

4. Deadlock can also be avoided by using various techniques such as Process Termination, Resource Preemption, and Time-out.

5. Deadlock can also be avoided by using various strategies such as Resource Acquisition Order, Resource Allocation Order, and Deadlock Avoidance.
