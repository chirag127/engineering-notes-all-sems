
### Reentrant Kernels 

* Reentrant kernels are a type of operating system kernel that allows multiple users to access the same program or code simultaneously. 
* Reentrant kernels are designed to be non-blocking, meaning that when one user is accessing the code, other users can still access the same code without being blocked. 
* Reentrant kernels are typically used in multi-user systems, such as mainframes and large-scale enterprise systems, to ensure that multiple users can access the same program or code at the same time without conflict. 
* Reentrant kernels are also used in embedded systems, such as embedded operating systems, to ensure that multiple users can access the same code without disruption. 
* Reentrant kernels are designed to be efficient and reliable, and provide a high level of performance for multi-user systems.
