
### Batch for the notes of the Unit 1 - Introduction: Operating System and Functions
1. An operating system is a set of software that manages the hardware and software resources of a computer. It is responsible for the management and coordination of activities and the sharing of resources of the computer. 
2. The operating system acts as an interface between the user and the hardware. It provides the user with an environment to work in and also provides a platform for the execution of application programs.
3. The main functions of an operating system are: 
    - Process Management: Manages the running processes, provides scheduling and synchronization.
    - Memory Management: Manages the system memory and provides virtual memory.
    - Storage Management: Manages the system storage and provides the file system.
    - Networking Management: Manages the system's network connections.
    - Security Management: Manages the system's security settings.
    - Device Management: Manages the system's hardware devices.
    - User Interface: Provides a user interface to interact with the system.
4. Operating systems can be either single-user or multi-user. Single-user operating systems are designed to allow only one user to access the system at a time. Multi-user operating systems are designed to allow multiple users to access the system at the same time. 
5. Operating systems can also be either real-time or non-real-time. Real-time operating systems are designed to respond to events within a certain amount of time. Non-real-time operating systems are designed to respond to events when they occur. 
6. Operating systems can also be either distributed or embedded. Distributed operating systems are designed to run on multiple computers connected by a network. Embedded operating systems are designed to run on a single computer.
