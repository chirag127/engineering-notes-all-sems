
### Scheduling Algorithms for the notes of the Unit 3 - CPU Scheduling in the subject of Operating System

1. CPU scheduling algorithms are used to determine which processes should be allocated to the CPU at any given time.
2. There are several types of scheduling algorithms, including First Come First Serve (FCFS), Shortest Job First (SJF), Round Robin (RR), and Priority Scheduling.
3. FCFS scheduling assigns processes to the CPU in the order that they arrive.
4. SJF scheduling assigns processes to the CPU based on the length of the job.
5. RR scheduling assigns processes to the CPU in a circular fashion, with each process getting a fixed amount of time to execute.
6. Priority scheduling assigns processes to the CPU based on priority levels.
7. Multilevel Queue Scheduling is a type of scheduling algorithm that uses multiple queues to separate processes by priority level.
8. Multilevel Feedback Queue Scheduling is a type of scheduling algorithm that dynamically adjusts the priority of processes based on their CPU usage.
