
### Protection schemes for the notes of the Unit 4 - Memory Management in the subject of Operating System

1. Memory Protection: Memory protection is a mechanism that helps to prevent unauthorized access to memory. It provides protection from malicious software and helps to protect the integrity of the system.

2. Address Space Layout Randomization (ASLR): ASLR is a security technique that randomizes the location of certain components in memory, making it harder for attackers to exploit software vulnerabilities.

3. Sandboxing: Sandboxing is a technique used to isolate a process from the rest of the system. It allows a process to run with limited privileges, preventing it from accessing system resources or other processes.

4. Virtual Memory: Virtual memory is a technique used to abstract physical memory and create a virtual address space. It allows multiple processes to share the same physical memory, while providing protection from one process accessing the memory of another.

5. Segmentation: Segmentation is a technique used to divide memory into separate segments, each of which can be protected separately. This allows processes to access memory that is allocated to them, while preventing them from accessing memory that is allocated to other processes.

6. Memory Protection Units (MPUs): MPUs are hardware components that provide memory protection. They can be used to provide protection from unauthorized access to memory, as well as to detect and prevent buffer overflows.
