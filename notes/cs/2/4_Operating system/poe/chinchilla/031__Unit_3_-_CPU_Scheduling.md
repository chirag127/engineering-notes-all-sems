## Unit 3 - CPU Scheduling

CPU scheduling is an essential component of the operating system that determines which process should be allocated the CPU at a particular time. This unit covers the following topics related to CPU scheduling:

1. CPU Scheduling Concepts:
   - Definition of CPU scheduling
   - Types of CPU scheduling algorithms: preemptive and non-preemptive
   - Goals of CPU scheduling: maximize CPU utilization, minimize turnaround time, minimize waiting time, and minimize response time
   
2. CPU Scheduling Algorithms:
   - First-Come, First-Served (FCFS) Scheduling
   - Shortest-Job-First (SJF) Scheduling
   - Priority Scheduling
   - Round Robin Scheduling
   - Multilevel Queue Scheduling
   - Multilevel Feedback Queue Scheduling
   
3. Evaluation of CPU Scheduling Algorithms:
   - Criteria for evaluating CPU scheduling algorithms
   - Comparison of different CPU scheduling algorithms based on the evaluation criteria
   
4. Thread Scheduling:
   - Definition of thread scheduling
   - Thread scheduling models
   - Comparison of different thread scheduling models
   
5. Real-time Scheduling:
   - Definition of real-time scheduling
   - Types of real-time scheduling: hard real-time scheduling and soft real-time scheduling
   - Real-time scheduling algorithms: Rate Monotonic Scheduling (RMS) and Earliest Deadline First (EDF)
   
6. Scheduling in Multiprocessor Systems:
   - Definition of multiprocessor system
   - Types of multiprocessor systems
   - Approaches to CPU scheduling in multiprocessor systems: Asymmetric multiprocessing (AMP) and Symmetric multiprocessing (SMP)
   - Load balancing algorithms in multiprocessor systems
   
7. Scheduling in Real-Time Operating Systems (RTOS):
   - Definition of RTOS
   - Real-time scheduling in RTOS
   - RTOS scheduling algorithms: Priority Inheritance Protocol (PIP), Priority Ceiling Protocol (PCP), and Stack Resource Policy (SRP)
   
In conclusion, understanding CPU scheduling concepts and algorithms is crucial for efficient utilization of CPU resources in operating systems. This unit provides a comprehensive overview of different CPU scheduling algorithms and their evaluation criteria, along with thread and real-time scheduling, and scheduling in multiprocessor systems and RTOS.
