### Batch for the notes of the Unit 1 - Introduction : Operating system and functions in the subject of Operating system

In this unit, we will introduce the concept of Operating System (OS) and its functions. Below are the key points that you should take note of:

1. Definition of Operating System (OS)
   - An OS is a software that manages computer hardware and software resources, and provides common services for computer programs.
   - Examples of OS include Windows, macOS, Linux, and Android.

2. Functions of Operating System (OS)
   - Memory management: OS manages the computer's memory by allocating and deallocating memory space for programs and data.
   - Processor management: OS manages the computer's CPU by scheduling tasks and allocating processing time to each task.
   - Device management: OS manages the computer's input/output devices, such as printers, keyboards, and mice.
   - File management: OS manages the computer's files and directories by organizing, storing, and retrieving data.
   - Security management: OS provides security by controlling access to the computer's resources and protecting against malicious software.

3. Types of Operating System (OS)
   - Single-user OS: OS designed for a single user to use the computer at a time. Examples include Windows and macOS.
   - Multi-user OS: OS designed for multiple users to use the computer at the same time. Examples include Linux and UNIX.
   - Real-time OS: OS designed for real-time applications, such as controlling machinery or scientific experiments. Examples include QNX and VxWorks.

4. Evolution of Operating System (OS)
   - Batch processing: The earliest form of OS, where jobs were submitted in batches and processed sequentially.
   - Time-sharing: OS that allowed multiple users to share a computer's resources at the same time.
   - Personal computer OS: OS designed for personal computers, such as Windows and macOS.
   - Mobile OS: OS designed for mobile devices, such as Android and iOS.

5. Popular Operating Systems (OS)
   - Windows: A popular OS developed by Microsoft, used mainly in personal computers and servers.
   - macOS: An OS developed by Apple, used mainly in Apple's personal computers.
   - Linux: A free and open-source OS, used mainly in servers and supercomputers.
   - Android: A mobile OS developed by Google, used mainly in smartphones and tablets.
   - iOS: A mobile OS developed by Apple, used mainly in iPhones and iPads.

These key points should provide you with a good understanding of the concept of Operating System and its functions. Make sure to review them thoroughly to prepare for your exams.
