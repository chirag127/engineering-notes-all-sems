### Planar graphs

- A planar graph is a graph that can be drawn on a plane without any edges crossing each other.
- A plane graph is a planar graph with a specific way of drawing it on the plane.
- A planar graph can have more than one plane graph representation.
- A planar graph divides the plane into regions called faces.
- The number of faces of a plane graph depends on how it is drawn.
- A planar graph has some properties that relate the number of vertices, edges, and faces. For example, if a connected planar graph has n vertices, e edges, and f faces, then n - e + f = 2. This is called Euler's formula.
- A planar graph cannot have too many edges. For example, if a connected planar graph has n vertices and n >= 3, then e <= 3n - 6. This is called the planar graph theorem.
- A planar graph can be colored with four colors such that no two adjacent vertices have the same color. This is called the four color theorem.
- Some graphs are not planar, such as the complete graph K5 and the complete bipartite graph K3,3. A graph is non-planar if it contains a subgraph that is a subdivision of K5 or K3,3. This is called Kuratowski's theorem.
