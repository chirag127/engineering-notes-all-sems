# Definition for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

- Set theory is the branch of mathematics that is concerned about collections of objects .
- A set is a collection of objects or groups of objects that are distinct and unordered .
- The objects in a set are called the elements or members of the set .
- A set is said to contain its elements.
- A set can be defined by simply listing its members inside curly braces. For example, the set {2,4,17,23} is the same as the set {17,4,23,2}.
- To denote membership, we use the symbol ∈. For example, 4 ∈ {2,4,17,23} means that 4 is an element of the set {2,4,17,23}.
- Sets can be discrete or continuous; discrete mathematics is primarily concerned with the former.
- Discrete sets are sets that have a finite or countably infinite number of elements.
- Continuous sets are sets that have an uncountably infinite number of elements, such as the set of real numbers.
- Set theory is concerned with how sets can be arranged, combined, and counted.
- Some common operations on sets are union, intersection, complement, difference, and Cartesian product .
- Some common properties of sets are equality, subset, superset, empty set, universal set, and power set .
- Some common laws of set theory are commutative, associative, distributive, identity, idempotent, and De Morgan's laws.
