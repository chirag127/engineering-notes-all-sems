### Proof Methods

A proof is a logical argument that establishes the validity of a statement or a theorem. A proof consists of a sequence of statements that are either axioms, definitions, or logical consequences of previous statements. A proof must follow the rules of logic and be clear and unambiguous.

There are different methods of proof that can be used depending on the type of statement or theorem to be proved. Some of the common proof methods are:

- **Direct proof**: A direct proof shows that a statement of the form "if p, then q" is true by assuming that p is true and then using logic to show that q must also be true. For example, to prove that if n is an even integer, then n^2 is also even, we can assume that n is even and then use the definition of even to show that n^2 is also even.

- **Indirect proof**: An indirect proof shows that a statement of the form "if p, then q" is true by assuming that q is false and then using logic to show that p must also be false. This is also known as proof by contradiction or reductio ad absurdum. For example, to prove that √2 is irrational, we can assume that √2 is rational and then use the properties of rational numbers to show that this leads to a contradiction.

- **Contrapositive proof**: A contrapositive proof shows that a statement of the form "if p, then q" is true by proving that its contrapositive, "if not q, then not p", is true. This is based on the fact that a statement and its contrapositive are logically equivalent. For example, to prove that if n is odd, then n^2 is odd, we can prove that if n^2 is even, then n is even.

- **Proof by cases**: A proof by cases shows that a statement is true by dividing the possible cases into mutually exclusive and exhaustive subcases and then proving the statement for each subcase. For example, to prove that for any integer n, n^3 + 5n is divisible by 6, we can consider the cases when n is divisible by 2, when n is divisible by 3, and when n is not divisible by either 2 or 3, and then show that the statement holds for each case.

- **Proof by induction**: A proof by induction shows that a statement is true for all natural numbers by proving two steps: the base case, which shows that the statement is true for the smallest natural number, and the induction step, which shows that if the statement is true for some natural number k, then it is also true for k + 1. For example, to prove that for any natural number n, 1 + 2 + ... + n = n(n + 1)/2, we can show that the statement is true for n = 1 (base case) and then assume that the statement is true for some k and show that it is also true for k + 1 (induction step).
