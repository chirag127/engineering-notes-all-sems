### Permutation and Symmetric Groups

- A **permutation** of a set is a bijective function from the set to itself, that is, a function that rearranges the elements of the set. For example, if X = {a, b, c}, then a possible permutation of X is f: X -> X such that f(a) = b, f(b) = c, and f(c) = a.
- A **symmetric group** on a set X is the set of all permutations of X, denoted by Sym(X) or S_n, where n is the cardinality of X. For example, if X = {1, 2, 3}, then Sym(X) = {e, (1 2), (1 3), (2 3), (1 2 3), (1 3 2)}, where e is the identity function and (a b c) denotes the permutation that maps a to b, b to c, and c to a.
- A **permutation group** is a subgroup of a symmetric group, that is, a subset of Sym(X) that is closed under function composition and contains the identity and inverses of all its elements. For example, if X = {1, 2, 3, 4}, then a possible permutation group is G = {e, (1 2)(3 4), (1 3)(2 4), (1 4)(2 3)}, where (a b)(c d) denotes the permutation that swaps a and b, and c and d.
- Permutation groups are useful for studying the symmetries of objects, such as geometric figures, graphs, or polynomials. For example, the dihedral group D_n is the permutation group of the symmetries of a regular n-gon, and the alternating group A_n is the permutation group of the even permutations of n elements, that is, the permutations that can be written as an even number of transpositions (swaps of two elements).
