### Introduction for the notes of the Unit 3 - Lattices in the subject of Discrete Structures & Theory of Logic

- A lattice is a partially ordered set (poset) in which every pair of elements has a unique least upper bound (lub) and a unique greatest lower bound (glb).
- A lub of two elements a and b is an element c such that a ≤ c and b ≤ c, and c is the smallest such element. A glb of two elements a and b is an element d such that d ≤ a and d ≤ b, and d is the largest such element.
- A lattice can be represented by a Hasse diagram, which is a graph that shows the partial order relation by drawing the elements as nodes and connecting them with edges if one element is the immediate predecessor or successor of another.
- A lattice is called bounded if it has a minimum element (denoted by 0) and a maximum element (denoted by 1). A lattice is called distributive if it satisfies the distributive laws: a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c) and a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c), where ∨ and ∧ denote the lub and glb operations, respectively. A lattice is called complemented if every element has a unique complement, which is an element x such that a ∨ x = 1 and a ∧ x = 0. A lattice is called Boolean if it is bounded, distributive, and complemented.
- A lattice is called modular if it satisfies the modular law: a ≤ c implies a ∨ (b ∧ c) = (a ∨ b) ∧ c. A lattice is called orthomodular if it is modular and satisfies the orthomodular law: a ≤ b implies b = a ∨ (b ∧ a'), where a' denotes the complement of a. Orthomodular lattices are used to model the logic of quantum mechanics.
