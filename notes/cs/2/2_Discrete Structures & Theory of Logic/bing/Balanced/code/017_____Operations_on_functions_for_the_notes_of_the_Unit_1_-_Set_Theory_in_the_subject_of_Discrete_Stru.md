### Operations on functions

- A function is a relation that maps each element of a set, called the domain, to exactly one element of another set, called the codomain.
- A function can be represented by a set of ordered pairs, a table, a graph, or an algebraic expression.
- The notation f: A -> B means that f is a function from the set A to the set B.
- The notation f(x) = y means that f maps the element x in the domain to the element y in the codomain.
- The image of a function is the set of all elements in the codomain that are mapped by the function. The notation f(A) denotes the image of the set A under the function f.
- The preimage of a function is the set of all elements in the domain that are mapped to a given element in the codomain. The notation f^-1(y) denotes the preimage of the element y under the function f.
- A function is one-to-one if it maps different elements in the domain to different elements in the codomain. A function is onto if it maps every element in the codomain to some element in the domain. A function is bijective if it is both one-to-one and onto.
- A function can be composed with another function to form a new function. The notation f o g means the function that maps x to f(g(x)). The domain of f o g is the set of all elements in the domain of g that are mapped to the domain of f. The codomain of f o g is the same as the codomain of f.
- A function can be inverted if it is bijective. The inverse of a function f is the function that maps y to x such that f(x) = y. The notation f^-1 denotes the inverse of f. The domain of f^-1 is the same as the image of f. The codomain of f^-1 is the same as the domain of f.
- A function can be restricted to a subset of its domain or codomain. The notation f|A means the function that maps x to f(x) for all x in A. The domain of f|A is A. The codomain of f|A is the same as the codomain of f.
- A function can be extended to a superset of its domain or codomain. The notation f:A -> B means the function that maps x to f(x) for all x in A, and maps any other element in B to some element in B. The domain of f:A -> B is B. The codomain of f:A -> B is B.
