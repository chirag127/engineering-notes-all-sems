### Bipartite Graphs

A bipartite graph is a graph that has the following properties:

- It has two sets of vertices, say X and Y, such that every edge connects a vertex in X to a vertex in Y.
- It has no edge between two vertices in the same set.
- It has no odd cycle, that is, a cycle with an odd number of vertices.

Some examples of bipartite graphs are:

- All acyclic graphs (graphs with no cycles) are bipartite.
- All complete bipartite graphs (graphs where every vertex in X is connected to every vertex in Y) are bipartite.
- All regular bipartite graphs (graphs where every vertex has the same degree) are bipartite.

Some properties of bipartite graphs are:

- A bipartite graph is two-colorable, that is, it can be colored with two colors such that no two adjacent vertices have the same color.
- A bipartite graph has a symmetrical spectrum, that is, its eigenvalues are symmetric around zero.
- A bipartite graph is a class 1 graph, that is, its edges can be colored with the same number of colors as its maximum degree.
