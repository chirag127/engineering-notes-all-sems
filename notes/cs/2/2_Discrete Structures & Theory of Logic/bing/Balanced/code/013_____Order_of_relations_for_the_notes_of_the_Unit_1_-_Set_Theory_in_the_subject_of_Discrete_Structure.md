### Order of relations

- A relation R on a set A is called an order relation or a partial order if it satisfies the following properties:
  - Reflexive: For every x in A, xRx.
  - Antisymmetric: For every x and y in A, if xRy and yRx, then x = y.
  - Transitive: For every x, y and z in A, if xRy and yRz, then xRz.
- A set A with an order relation R is called a partially ordered set or a poset, and is denoted by (A, R).
- Examples of posets are:
  - (N, ≤), where N is the set of natural numbers and ≤ is the usual less than or equal to relation.
  - (P(S), ⊆), where P(S) is the power set of a set S and ⊆ is the subset relation.
  - (D, |), where D is the set of positive divisors of a natural number n and | is the divides relation.
- A relation R on a set A is called a total order or a linear order if it is a partial order and also satisfies the following property:
  - Comparability: For every x and y in A, either xRy or yRx.
- A set A with a total order R is called a totally ordered set or a chain, and is denoted by (A, R).
- Examples of chains are:
  - (N, ≤), where N is the set of natural numbers and ≤ is the usual less than or equal to relation.
  - (R, ≤), where R is the set of real numbers and ≤ is the usual less than or equal to relation.
  - (S, ⊆), where S is a finite set and ⊆ is the subset relation.
- A relation R on a set A is called a strict partial order if it satisfies the following properties:
  - Irreflexive: For every x in A, not xRx.
  - Asymmetric: For every x and y in A, if xRy, then not yRx.
  - Transitive: For every x, y and z in A, if xRy and yRz, then xRz.
- A relation R on a set A is called a strict total order if it is a strict partial order and also satisfies the following property:
  - Comparability: For every x and y in A, either xRy or yRx or x = y.
- Examples of strict total orders are:
  - (N, <), where N is the set of natural numbers and < is the usual less than relation.
  - (R, <), where R is the set of real numbers and < is the usual less than relation.
  - (S, ⊂), where S is a finite set and ⊂ is the proper subset relation.
