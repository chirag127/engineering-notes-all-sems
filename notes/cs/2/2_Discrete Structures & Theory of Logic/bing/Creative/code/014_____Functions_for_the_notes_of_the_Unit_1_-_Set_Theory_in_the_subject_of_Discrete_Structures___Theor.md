### Functions

- A function is a relation between two sets that assigns to each element of the first set exactly one element of the second set.
- The first set is called the domain of the function, and the second set is called the codomain of the function.
- The set of all elements that are assigned by the function is called the range of the function, which is a subset of the codomain.
- A function can be represented by a set of ordered pairs, a table, a graph, or a formula.
- A function can be classified into different types based on its properties, such as injective, surjective, bijective, inverse, composite, identity, constant, linear, quadratic, exponential, logarithmic, trigonometric, etc.
- A function can be evaluated by substituting the value of the input variable into the formula and simplifying the expression.
- A function can be analyzed by finding its domain, range, zeros, intercepts, slope, rate of change, extrema, intervals of increase and decrease, concavity, asymptotes, etc.
- A function can be transformed by applying operations such as translation, scaling, reflection, rotation, etc. to its graph or formula.
- A function can be modeled by finding a suitable formula that fits the given data or situation.
