# Definition for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

## Set
- A set is a collection of distinct objects, called elements or members of the set.
- A set can be represented by listing its elements between braces, such as {1, 2, 3} or {a, b, c}.
- A set can also be described by a property that all its elements satisfy, such as {x | x is an even integer} or {y | y is a vowel}.
- The order and repetition of elements in a set do not matter, so {1, 2, 3} is the same as {3, 1, 2} or {1, 1, 2, 3}.
- The symbol ∈ is used to denote that an object is an element of a set, such as 1 ∈ {1, 2, 3} or a ∈ {a, b, c}.
- The symbol ∉ is used to denote that an object is not an element of a set, such as 4 ∉ {1, 2, 3} or d ∉ {a, b, c}.

## Subset
- A set A is a subset of another set B if every element of A is also an element of B.
- The symbol ⊆ is used to denote that a set is a subset of another set, such as {1, 2} ⊆ {1, 2, 3} or {a, b} ⊆ {a, b, c}.
- The symbol ⊂ is used to denote that a set is a proper subset of another set, meaning that it is a subset but not equal to the other set, such as {1, 2} ⊂ {1, 2, 3} or {a, b} ⊂ {a, b, c}.
- Every set is a subset of itself, and the empty set {} is a subset of any set.

## Set Operations
- The union of two sets A and B, denoted by A ∪ B, is the set of all elements that are in either A or B or both, such as {1, 2, 3} ∪ {2, 3, 4} = {1, 2, 3, 4} or {a, b} ∪ {b, c} = {a, b, c}.
- The intersection of two sets A and B, denoted by A ∩ B, is the set of all elements that are in both A and B, such as {1, 2, 3} ∩ {2, 3, 4} = {2, 3} or {a, b} ∩ {b, c} = {b}.
- The difference of two sets A and B, denoted by A - B, is the set of all elements that are in A but not in B, such as {1, 2, 3} - {2, 3, 4} = {1} or {a, b} - {b, c} = {a}.
- The complement of a set A, denoted by A^c, is the set of all elements that are not in A, such as {1, 2, 3}^c = {x | x ∉ {1, 2, 3}} or {a, b}^c = {x | x ∉ {a, b}}.
- The Cartesian product of two sets A and B, denoted by A × B, is the set of all ordered pairs (a, b) where a ∈ A and b ∈ B, such as {1, 2} × {a, b} = {(1, a), (1, b), (2, a), (2, b)} or {a, b} × {1, 2} = {(a, 1), (a, 2), (b, 1), (b, 2)}.
