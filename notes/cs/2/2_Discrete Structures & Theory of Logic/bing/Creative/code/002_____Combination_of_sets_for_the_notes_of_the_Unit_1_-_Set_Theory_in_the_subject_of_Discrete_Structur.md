### Combination of sets

- A set is a collection of distinct objects, such as numbers, letters, symbols, etc.
- A set can be represented by listing its elements inside curly braces, such as {1, 2, 3} or {a, b, c}.
- A set can also be represented by using a rule that defines its elements, such as {x | x is an even integer} or {y | y is a vowel}.
- There are different ways to combine two or more sets to form new sets. Some of the common operations are union, intersection, difference, and complement.

#### Union

- The union of two sets A and B, denoted by A ∪ B, is the set of all elements that belong to either A or B or both.
- For example, if A = {1, 2, 3} and B = {3, 4, 5}, then A ∪ B = {1, 2, 3, 4, 5}.
- The union operation is commutative, associative, and idempotent, meaning that A ∪ B = B ∪ A, (A ∪ B) ∪ C = A ∪ (B ∪ C), and A ∪ A = A.

#### Intersection

- The intersection of two sets A and B, denoted by A ∩ B, is the set of all elements that belong to both A and B.
- For example, if A = {1, 2, 3} and B = {3, 4, 5}, then A ∩ B = {3}.
- The intersection operation is commutative, associative, and idempotent, meaning that A ∩ B = B ∩ A, (A ∩ B) ∩ C = A ∩ (B ∩ C), and A ∩ A = A.

#### Difference

- The difference of two sets A and B, denoted by A - B, is the set of all elements that belong to A but not to B.
- For example, if A = {1, 2, 3} and B = {3, 4, 5}, then A - B = {1, 2}.
- The difference operation is not commutative, meaning that A - B ≠ B - A, but it is associative, meaning that (A - B) - C = A - (B ∪ C).

#### Complement

- The complement of a set A, denoted by A', is the set of all elements that do not belong to A.
- The complement of a set depends on the universal set U, which is the set of all possible elements under consideration.
- For example, if U = {1, 2, 3, 4, 5} and A = {1, 2, 3}, then A' = {4, 5}.
- The complement operation satisfies the following properties: A ∪ A' = U, A ∩ A' = ∅, and (A')' = A.
