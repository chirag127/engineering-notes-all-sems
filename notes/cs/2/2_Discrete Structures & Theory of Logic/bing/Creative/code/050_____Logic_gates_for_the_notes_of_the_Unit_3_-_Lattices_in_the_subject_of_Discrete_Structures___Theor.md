### Logic gates

- A logic gate is a device performing a Boolean logic operation on one or more binary inputs and then outputs a single binary output.
- A logic circuit is a combination of logic gates that performs a more complex operation than a single gate.
- There are seven basic types of logic gates: AND, OR, NOT, NAND, NOR, XOR, and XNOR.
- Each logic gate has a symbol, a truth table, and a Boolean expression that represents its operation.
- A symbol is a graphical representation of the gate, such as a rectangle with a label or a distinctive shape.
- A truth table is a table that shows all possible combinations of inputs and outputs for the gate, such as 0 or 1 for binary values.
- A Boolean expression is a mathematical formula that uses logical operators and variables to describe the output of the gate in terms of the inputs, such as A AND B or A + B.
