## Unit 3 - Lattices

- A lattice is a partially ordered set (L, ≤) in which every pair of elements has a least upper bound and a greatest lower bound .
- The least upper bound of a and b is denoted by a ∨ b and is called the join of a and b. The greatest lower bound of a and b is denoted by a ∧ b and is called the meet of a and b.
- A lattice is said to be bounded if it has a least element (denoted by 0) and a greatest element (denoted by 1).
- A lattice is said to be distributive if it satisfies the following distributive laws for all elements a, b, and c:
  - a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c)
  - a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)
- A lattice is said to be complemented if every element has a unique complement, that is, an element x such that a ∨ x = 1 and a ∧ x = 0.
- A lattice is said to be modular if it satisfies the following modular law for all elements a, b, and c:
  - If a ≤ c, then a ∨ (b ∧ c) = (a ∨ b) ∧ c
- A lattice is said to be complete if every subset of L has a join and a meet.
- A lattice can be represented by a Hasse diagram, which is a graphical representation of the partial order relation.
- A lattice can also be defined as a regular repeated three-dimensional arrangement of atoms, ions, or molecules in a metal or other crystalline solid .
- A lattice can be classified into different types based on the symmetry and shape of the unit cell, which is the smallest repeating unit of the lattice. Some common types of lattices are simple cubic, body-centered cubic, face-centered cubic, hexagonal close-packed, and diamond.
