### Operations on functions

- A function is a relation that assigns a unique output to each input.
- The domain of a function is the set of all possible inputs, and the range is the set of all possible outputs.
- The notation f(x) denotes the output of the function f when the input is x.
- There are four basic operations on functions: addition, subtraction, multiplication, and division.
- The addition of two functions f and g is defined as (f+g)(x) = f(x) + g(x), where x is in the domain of both f and g.
- The subtraction of two functions f and g is defined as (f-g)(x) = f(x) - g(x), where x is in the domain of both f and g.
- The multiplication of two functions f and g is defined as (f*g)(x) = f(x) * g(x), where x is in the domain of both f and g.
- The division of two functions f and g is defined as (f/g)(x) = f(x) / g(x), where x is in the domain of both f and g and g(x) is not zero.
- The operations on functions follow the same properties as the operations on real numbers, such as commutativity, associativity, and distributivity.
- For example, (f+g)(x) = (g+f)(x), (f+g)+h)(x) = (f+(g+h))(x), and (f+g)*h)(x) = (f*h)(x) + (g*h)(x).
- The operations on functions can be used to create new functions from existing ones, and to model various situations in mathematics and other fields.
