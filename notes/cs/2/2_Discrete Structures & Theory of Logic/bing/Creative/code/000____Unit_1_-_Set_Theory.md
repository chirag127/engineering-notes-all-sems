## Unit 1 - Set Theory

Set theory is a branch of mathematics that studies the properties and relationships of collections of objects, called sets. A set is a well-defined collection of distinct elements, which can be anything such as numbers, letters, symbols, or even other sets. The elements of a set are also called its members.

Some basic concepts and notations of set theory are:

- A set can be represented by listing its elements inside curly braces, such as {1, 2, 3} or {a, b, c}. Alternatively, a set can be defined by a rule that specifies the condition for an element to belong to the set, such as {x | x is an even integer} or {y | y is a vowel}.
- Two sets are equal if they have exactly the same elements, regardless of the order or repetition of the elements. For example, {1, 2, 3} = {3, 2, 1} = {1, 1, 2, 3}.
- The number of elements in a set is called its cardinality, denoted by |A| for a set A. For example, |{1, 2, 3}| = 3 and |{a, b, c}| = 3. A set that has no elements is called the empty set, denoted by ∅ or {}. The cardinality of the empty set is 0, i.e., |∅| = 0.
- A set A is a subset of another set B, denoted by A ⊆ B, if every element of A is also an element of B. For example, {1, 2} ⊆ {1, 2, 3} and {a, b} ⊆ {a, b, c}. Every set is a subset of itself, i.e., A ⊆ A for any set A. The empty set is a subset of any set, i.e., ∅ ⊆ B for any set B.
- A set A is a proper subset of another set B, denoted by A ⊂ B, if A ⊆ B and A ≠ B. For example, {1, 2} ⊂ {1, 2, 3} and {a, b} ⊂ {a, b, c}. The empty set is a proper subset of any non-empty set, i.e., ∅ ⊂ B for any set B such that B ≠ ∅.
- A set A is a superset of another set B, denoted by A ⊇ B, if B ⊆ A. For example, {1, 2, 3} ⊇ {1, 2} and {a, b, c} ⊇ {a, b}. A set A is a proper superset of another set B, denoted by A ⊃ B, if B ⊂ A. For example, {1, 2, 3} ⊃ {1, 2} and {a, b, c} ⊃ {a, b}.
- The union of two sets A and B, denoted by A ∪ B, is the set of all elements that belong to either A or B or both. For example, {1, 2, 3} ∪ {2, 4, 6} = {1, 2, 3, 4, 6} and {a, b, c} ∪ {c, d, e} = {a, b, c, d, e}.
- The intersection of two sets A and B, denoted by A ∩ B, is the set of all elements that belong to both A and B. For example, {1, 2, 3} ∩ {2, 4, 6} = {2} and {a, b, c} ∩ {c, d, e} = {c}.
