### Complemented for the notes of the Unit 3 - Lattices in the subject of Discrete Structures & Theory of Logic

Complemented is a term used in lattice theory, which is a branch of mathematics that studies partially ordered sets. A partially ordered set is a set of elements with a binary relation (i.e. "<" or ">") that defines a partial ordering of the elements. In a lattice, there is a unique greatest lower bound (glb) and a unique least upper bound (lub) for any two elements.

A complemented lattice is a lattice with an additional unary operation that assigns a complement to each element. The complement of an element is an element that, when combined with the original element using the lub operation, results in the greatest element in the lattice. The complement of an element, when combined with the original element using the glb operation, results in the least element in the lattice.

Complemented lattices have applications in many areas, including computer science, cryptography, and engineering. For example, in computer science, complemented lattices can be used to represent Boolean algebras, which are used to model digital circuits. In cryptography, complemented lattices can be used to design secure cryptographic systems. In engineering, complemented lattices can be used to design control systems.
