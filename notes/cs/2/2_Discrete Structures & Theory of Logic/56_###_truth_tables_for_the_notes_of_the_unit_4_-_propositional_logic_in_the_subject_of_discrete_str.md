### Truth tables for the notes of the Unit 4 - Propositional Logic in the subject of Discrete Structures & Theory of Logic

A truth table is a tool used in propositional logic to determine the truth value of a proposition for all possible combinations of truth values of its component propositions. Propositions are statements that can be either true or false.

A truth table lists the possible combinations of truth values of the component propositions and the corresponding truth value of the proposition. The truth value of a proposition is determined by the truth values of its component propositions and the logical connectives used to combine them.

The most common logical connectives used in propositional logic are negation (not), conjunction (and), disjunction (or), implication (if-then), and equivalence (if and only if). The truth values of these connectives can be determined using truth tables.

For example, the truth table for the proposition "p implies q" (denoted by p → q) lists the possible combinations of truth values of p and q and the corresponding truth value of the proposition. If p is true and q is false, then the proposition is false. If p is false, then the proposition is true regardless of the truth value of q.

Truth tables are a useful tool for evaluating the validity of arguments in propositional logic. By examining the truth table for a proposition, one can determine whether the proposition is logically equivalent to another proposition, or whether a given argument is valid or invalid.
