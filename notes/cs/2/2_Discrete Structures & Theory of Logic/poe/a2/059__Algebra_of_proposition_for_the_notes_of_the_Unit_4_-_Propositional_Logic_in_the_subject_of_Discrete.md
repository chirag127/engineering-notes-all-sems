### Algebra of proposition for the notes of the Unit 4 - Propositional Logic in Discrete Structures & Theory of Logic

1. Propositional variables: Letters p, q, r, s, ... are used to represent propositions. They can take either true or false values.
2. Propositional constants:
    - True: Represents always true propositions denoted by T or ⊤
    - False: Represents always false propositions denoted by F or ⊥
3. Propositional connectives: Used to combine propositions
    - Negation (¬): Denoted by ¬p. ¬True = False, ¬False = True.
    - Conjunction (∧): p ∧ q is true only if p and q both are true.
    - Disjunction (∨): p ∨ q is true if either p or q or both are true.
    - Exclusive disjunction (⊕): p ⊕ q is true if only one of p or q is true and false if both are true or both are false.
    - Conditional (→): p → q is false only if p is true and q is false, otherwise it is true.
    - Biconditional (↔): p ↔ q is true if p and q have the same truth value, otherwise it is false.
4. Precedence of operators: ¬ > ∧ > ∨
5. Associativity: ∧ and ∨ are associative
6. Distribution: p ∧ (q ∨ r) = (p ∧ q) ∨ (p ∧ r) and p ∨ (q ∧ r) = (p ∨ q) ∧ (p ∨ r)
7. De Morgan's laws: ¬(p ∧ q) = ¬p ∨ ¬q and ¬(p ∨ q) = ¬p ∧ ¬q
8. Absorption laws: p ∧ (p ∨ q) = p and p ∨ (p ∧ q) = p
9. Commutation: p ∧ q = q ∧ p and p ∨ q = q ∨ p (if p and q have the same truth value)
10. Idempotence: p ∧ p = p and p ∨ p = p
