### Inference theory of predicate logic for the notes of the Unit 5 - Predicate Logic

1. Introduction
- Predicate logic is an extension of propositional logic that allows predicates and variables to be used.
- Inference rules are used to derive conclusions from premises containing predicates and variables.

2. Inference Rules
- Modus ponens: If P implies Q and P is true, then Q must be true.
- Generalization: If P(x) is true for a particular x, then P(x) is true for all x.
- Specialization: If P(x) is true for all x, then P(x) is true for a particular x.

3. Proofs Using Inference Rules
- Proofs are step-by-step derivations of conclusions from premises using inference rules.
- Each step must be justified by citing the specific inference rule used and showing how it is applicable.
- Proofs may require working backwards from the conclusion to find a chain of inferences leading to the premises.

- Quantifiers are used to specify whether a statement is true for all or some members of a group.
