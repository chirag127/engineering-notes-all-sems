### Definition for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic:

1. Set: A set is a collection of distinct objects. The objects in a set are called the elements or members of the set.
2. Empty set: A set that contains no elements. It is denoted by { }.
3. Finite set: A set that contains a finite number of elements.
4. Infinite set: A set that contains an infinite number of elements.
5. Equal sets: Two sets are equal if and only if they have exactly the same elements.
6. Subset: A set A is a subset of set B if every element of A is also an element of B. A is called a proper subset of B if A is a subset of B but A ≠ B.
7. Power set: The set of all subsets of a given set.
8. Union: The union of two sets A and B is the set containing all elements that are in A, B, or both. It is denoted by A ∪ B.
9. Intersection: The intersection of two sets A and B is the set containing all elements that are common to both A and B. It is denoted by A ∩ B.
10. Complement: The complement of a set A with respect to the universal set U refers to the set of all elements in U that are not in A. It is denoted by A′ or U − A.
