### Multisets for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. A multiset is a collection of objects where multiple occurrences of the same object are possible. This is unlike a set where an object can occur only once.
2. The multiplicity of an element in a multiset refers to the number of times that element occurs in the multiset.
3. The notation used to represent a multiset is a set enclosed within braces { } with the elements listed inside along with their multiplicities. For example: {a, b, c, a} represents a multiset with elements a, b and c where a occurs twice.
4. Union, intersection and difference can be defined for multisets similar to sets. The result will be a multiset where the multiplicities of the elements are adjusted accordingly.
5. Multisets find applications in areas like data analysis and databases where repeated occurrences of data are common. They provide a more comprehensive representation of data as compared to sets.
