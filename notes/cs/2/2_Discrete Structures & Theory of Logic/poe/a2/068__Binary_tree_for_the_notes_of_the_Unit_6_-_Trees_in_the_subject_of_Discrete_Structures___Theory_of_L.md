### Binary tree for the notes of the Unit 6 - Trees in the subject of Discrete Structures & Theory of Logic

1. A binary tree is a tree data structure in which each node has at most two children, which are referred to as the left child and right child.

2. Nodes are structured in a hierarchical way with the root node at the top. The hierarchy can be seen as a set of parent-child relationships.

3. A binary tree has the benefits of both an ordered structure and fast (logarithmic) search, insertion, and removal.

4. The basic terminology for binary trees are:

- Root: The top node in a tree.
- Parent: The converse notion of child.
- Left/Right child: A child is a node directly connected to another node when moving away from the root.
- Descendant: A node reachable by repeated proceeding from parent to child.
- Ancestor: A node reachable by repeated proceeding from child to parent.
- Height: The number of edges from a node to the furthest leaf.
- Depth: The number of edges from the root to a node.

5. Binary search trees are binary trees which have the following additional property: the value in each node must be greater than or equal to the values in that node's left subtree and less than or equal to the values in that node's right subtree. This property allows for efficient insertion, deletion, and lookup.

6. The time complexity of various operations on binary trees are:

- Search: O(h) where h is the height of the tree.
- Insertion: O(h)
- Deletion: O(h)
