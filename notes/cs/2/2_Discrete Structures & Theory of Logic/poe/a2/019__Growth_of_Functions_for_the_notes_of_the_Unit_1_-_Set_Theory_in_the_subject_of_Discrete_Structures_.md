### Growth of Functions

- A function f: N → N grows linearly if there exist constants c and k such that f(n) ≤ cn + k for all n ∈ N.
- A function f: N → N grows polynomially if there exist constants c and k and a positive integer n0 such that f(n) ≤ cnk for all n ≥ n0.
- A function f: N → N grows exponentially if there exist constants c and k such that f(n) ≥ 2cn for all sufficiently large n.
- A function f: N → N grows superexponentially if f(n) grows faster than any exponential function.

The above points cover the key aspects of describing the growth of functions for comparing the efficiency of algorithms. The classification helps in analyzing the time and space complexity of algorithms to determine the efficiency.
