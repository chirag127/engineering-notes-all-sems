## Unit 5 - Predicate Logic

1. Predicate logic is an extension of propositional logic. It allows statements to be made about variables.
2. Predicate logic uses predicates, which are expressions that can have variables. The predicates are used to make statements about the variables.
3. Predicates take the form of relations. A relation is a set of ordered pairs. For example, the relation "father of" could be represented as a set of ordered pairs such as (John, James), (Robert, John) meaning John is the father of James and Robert is the father of John.
4. Quantifiers are used in predicate logic to specify whether a statement is true for all or some variables. The two quantifiers used are:
- Universal quantifier (∀): Indicates a statement is true for all variables. For example, ∀x (x > 0) means for all x, x is greater than 0.
- Existential quantifier (∃): Indicates a statement is true for at least one variable. For example, ∃x (x > 10) means there exists at least one x such that x is greater than 10.
5. Predicate logic can be used to formally prove mathematical theorems and is the foundation of automated theorem provers. It is a way to represent knowledge and reason about it logically.
