### Introduction for the notes of the Unit 1 - Set Theory

1.  Set: A well-defined collection of objects is called a set. The objects in a set are called its elements or members.
2.  Null or Empty set: A set with no elements is called a null or empty set. It is denoted by { }.
3.  Finite and Infinite Sets: A set which has a finite number of elements is called a finite set. A set with infinitely many elements is called an infinite set.
4.  Subsets: If all the elements of a set A are also elements of a set B, then A is called a subset of B. This relationship is denoted by A ⊂ B.
5.  Proper Subset: If A is a subset of B, but A ≠ B, then A is called a proper subset of B. This is denoted by A ⊂ B.
6.  Universal Set: The set which contains all the elements under consideration is called the universal set. It is denoted by U.
7.  Power Set: The set of all subsets of a given set A is called the power set of A. It is denoted by P(A) or 2^A.
8.  Venn Diagrams: Venn diagrams are diagrams that show logical relationships between groups. They are used to teach elementary set theory concepts.
