### Satisfiability for the notes of the Unit 4 - Propositional Logic

1. A propositional formula is satisfied by an assignment of truth values to its variables if and only if the formula evaluates to TRUE under that assignment.
2. A propositional formula is unsatisfiable if there is no assignment of truth values to its variables that makes the formula evaluate to TRUE.
3. A propositional formula is consistent if it is satisfiable. Otherwise, it is inconsistent.
4. The satisfiability problem is the problem of determining if there exists an assignment of truth values to the variables of a propositional formula that makes the formula evaluate to TRUE. This is equivalent to determining if the formula is satisfiable or unsatisfiable.
5. The satisfiability of a propositional formula can be determined using a truth table. A formula is satisfiable if and only if there is at least one row of the truth table in which the formula evaluates to TRUE. Otherwise, the formula is unsatisfiable.
6. The satisfiability of a propositional formula can also be determined using a semantic tableau. A branch in the tableau is closed if and only if the formula along that branch can be shown to be unsatisfiable. If all branches in the tableau close, then the original formula is unsatisfiable. If at least one branch remains open, then the original formula is satisfiable.
