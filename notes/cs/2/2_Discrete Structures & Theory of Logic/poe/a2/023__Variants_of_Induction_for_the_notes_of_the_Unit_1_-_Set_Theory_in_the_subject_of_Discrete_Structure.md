### Variants of Induction for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic:

1. Mathematical Induction:
- Proving a statement for the first natural number (base case).
- Assuming the statement is true for some natural number n and then proving that it must also be true for n+1 (inductive step).
- If both the base case and inductive step are proved, then the statement is true for all natural numbers.

2. Strong Induction:
- Proving a statement for the first k natural numbers (base case) where k > 1.
- Assuming the statement is true for some natural numbers upto n and then proving that it must also be true for n+1 (inductive step).
- If both the base case and inductive step are proved, then the statement is true for all natural numbers.

3. Structural Induction:
- Proving a statement for the simplest/ smallest structure (base case).
- Assuming the statement is true for a structure of size n and then proving that it must also be true for a larger structure of size n+1 (inductive step).
- If both the base case and inductive step are proved, then the statement is true for all possible structures.
