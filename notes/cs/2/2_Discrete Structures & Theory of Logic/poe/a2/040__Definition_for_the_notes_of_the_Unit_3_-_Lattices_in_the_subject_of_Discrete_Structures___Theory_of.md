### Definition

A lattice is a partially ordered set in which any two elements have a supremum (least upper bound) and an infimum (greatest lower bound).

- Supremum: Least upper bound of a set of elements in a lattice. It is the smallest element which is greater than or equal to all elements in the set.
- Infimum: Greatest lower bound of a set of elements in a lattice. It is the largest element which is less than or equal to all elements in the set.

Properties of Lattices:

1. Supremum and infimum exist for any subset.
2. Supremum of a set is unique.
3. Infimum of a set is unique.
4. Supremum of supremum is supremum.
5. Infimum of infimum is infimum.

Types of Lattices:

1. Complemented Lattice: Has a complement for each element.
2. Distributive Lattice: Satisfies distributive law. A ∨ (B ∧ C) = (A ∨ B) ∧ (A ∨ C) and dual.
3. Complemented Distributive Lattice: Satisfies both complemented lattice and distributive lattice properties.
4. Modular Lattice: Satisfies the modular law. A ≤ B implies A ∨ (B ∧ C) = (A ∨ B) ∧ C for all A, B, C in lattice.
