### Properties of lattices – Bounded

1. Bounded lattice: A lattice L is said to be bounded if it has a least element (denoted by 0) and a greatest element (denoted by 1).
2. In a bounded lattice, for any element a in L, 0 ≤ a ≤ 1.
3. Finite lattices are always bounded. The least and greatest elements are the minimum and maximum of the lattice respectively.
4. Infinite lattices need not be bounded. For example, the lattice of all subsets of a set ordered by inclusion is not bounded. There is no least subset or greatest subset.
5. Bounded lattices satisfy the property: for any elements a, b in L, a ∨ b = 1 if and only if a = 1 or b = 1 and a ∧ b = 0 if and only if a = 0 or b = 0.
6. Examples of bounded lattices:
    1. The lattice of subsets of a finite set ordered by inclusion.
    2. The lattice of integer intervals [0, n] for n > 0 ordered by reverse inclusion.
