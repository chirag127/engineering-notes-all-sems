### Contradiction for the notes of the Unit 4 - Propositional Logic

1. A contradiction is a statement that is necessarily false. It is not possible for a contradiction to be true.
2. In propositional logic, a contradiction occurs when a statement and its negation are both true at the same time. For example:
P: It is raining.
~P: It is not raining.
If both P and ~P are true, then there is a contradiction. This cannot be.
3. The law of non-contradiction states that contradictory statements cannot both be true in the same sense at the same time. One must be true and the other false.
4. When proving a statement in propositional logic, if you ever reach a point where a contradiction occurs, then you know the original statement must have been false. A contradiction shows the proof by exhaustion - all possibilities have been considered, and a contradiction results, so the initial assumption must have been wrong.
5. Similarly, when refuting or disproving a statement, if you can show that it logically leads to a contradiction, then you have demonstrated that the original statement must be false. Producing a contradiction is a useful way to refute a statement or argument.
