### Composite Relations for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Relations can be combined to form new relations called composite relations.
2. If R is a relation from set A to set B and S is a relation from set B to set C, then the composite of R and S, denoted by S o R or R;S, is a relation from set A to set C.
3. (a,c) ∈ (S o R) if and only if there exists b ∈ B such that (a,b) ∈ R and (b,c) ∈ S.
4. The composition of relations is associative, that is, if R, S and T are relations, then (S o R) o T = S o (R o T).
5. The identity relation on a set A, denoted by Ia or IdA, is a relation on A such that a Ia a for every a ∈ A. The identity relation serves as an identity element for the composition of relations, that is, for any relation R on A, Ia o R = R o Ia = R.
