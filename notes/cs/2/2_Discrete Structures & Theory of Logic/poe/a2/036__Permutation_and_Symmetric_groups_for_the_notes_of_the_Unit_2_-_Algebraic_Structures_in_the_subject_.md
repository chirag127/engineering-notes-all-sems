### Permutation and Symmetric groups for the notes of the Unit 2 - Algebraic Structures in the subject of Discrete Structures & Theory of Logic

1. Permutations:
- Arrangements of objects in a particular order.
- Can be represented using permutation notation or product of cycles.
- Two permutations are equal if they have the same effect on the set of objects.
- Identity permutation: leaves every object unchanged.
- Inverse permutation: undoes the effect of the original permutation.

2. Properties of permutations:
- Finite number of permutations for a finite set of objects.
- Composition of permutations is associative.
- Every permutation has an inverse permutation.
- Identity permutation is the identity element for composition.

3. Symmetric groups:
- Set of all permutations of a given set of objects forms a group under composition.
- This group is called the symmetric group on that set of objects.
- For a set of n objects, the symmetric group is denoted by Sn.
- Symmetric groups are important examples of permutation groups.
- They exhibit properties of groups like closure, associativity, identity, inverses.

- S2 = {I, (12)}
- S3 = {I, (12), (13), (23), (123)}
- S4 = {I, (12), (13), (14), (23), (24), (34), (123), (124), (134), (234), (1234)}
