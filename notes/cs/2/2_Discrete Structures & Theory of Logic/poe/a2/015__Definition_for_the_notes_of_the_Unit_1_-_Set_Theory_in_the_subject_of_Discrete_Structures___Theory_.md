### Definition for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Set: A set is a collection of objects where the order of objects does not matter. The objects in a set are called elements or members of the set.
2. Empty set: A set with no elements is called an empty set. It is denoted by { }.
3. Universal set: A set which contains all possible elements under consideration is called a universal set. It is denoted by U.
4. Subset: A set A is said to be a subset of set B if all elements of A are also elements of B. It is denoted by A ⊆ B.
5. Power set: The set of all subsets of a given set A is called the power set of A. It is denoted by P(A).
6. Equal sets: Two sets A and B are said to be equal if they have exactly the same elements. It is denoted by A = B.
7. Finite and Infinite sets: A set is said to be finite if it contains a finite number of elements and infinite if it contains an infinite number of elements.
