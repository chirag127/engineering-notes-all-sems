### Classification of functions for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Injective function: A function f from a set A to a set B is injective if for every a,b in A, f(a)=f(b) implies a=b. In other words, no two distinct elements in the domain have the same image.

2. Surjective function: A function f from a set A to a set B is surjective if for every b in B, there exists an a in A such that f(a)=b. In other words, every element in the codomain has a pre-image.

3. Bijective function: A function f from a set A to a set B is bijective if it is both injective and surjective. In other words, f is a one-to-one correspondence between the elements of A and B. For every a in A, there is a unique b in B such that f(a)=b and vice-versa.

The properties of injective, surjective and bijective functions are important in set theory and are commonly used in proofs. They form the basis for understanding many other concepts in mathematics.
