## Unit 1 - Set Theory

1. Set - A collection of objects is called a set. The objects in a set are called its elements or members.
2. Empty set - A set with no elements is called an empty set. It is denoted by { }.
3. Universal set - A set which contains all the elements under consideration is called the universal set. It is denoted by U.
4. Subset - A set A is said to be a subset of set B if every element of A is also an element of B. It is denoted by A ⊆ B.
5. Proper subset - If A is a subset of B and A is not equal to B, then A is called a proper subset of B. It is denoted by A ⊂ B.
6. Power set - The set of all subsets of a given set A is called the power set of A. It is denoted by P(A) or 2A.
7. Venn diagrams - Venn diagrams are pictorial representations of sets and their relationships. They consist of circles, also known as Venn diagrams.
