
### Definition and Terminology for Unit 7 - Graphs in Discrete Structures & Theory of Logic
- A graph is a mathematical structure used to represent relationships between objects. It consists of a set of vertices (or nodes) connected by edges.
- A directed graph (or digraph) is a graph in which the edges have a direction associated with them.
- An undirected graph is a graph in which the edges do not have a direction associated with them.
- A path in a graph is a sequence of vertices connected by edges.
- A cycle in a graph is a path that starts and ends at the same vertex.
- A graph is connected if there is a path between any two vertices.
- A graph is complete if there is an edge between any two vertices.
- A graph is bipartite if its vertices can be divided into two disjoint sets such that every edge has one endpoint in each set.
- A graph is planar if it can be drawn in the plane without any edges crossing.
- A graph is k-regular if every vertex has degree k.
- A graph is Hamiltonian if it contains a cycle that visits every vertex exactly once.
- A graph is Eulerian if it contains a path that visits every edge exactly once.
