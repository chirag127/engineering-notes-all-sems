
### Operations on Functions

1. Composition of functions: Composition of functions is a process of combining two functions to create a new function. The composition of two functions f and g can be written as (f ∘ g)(x) or f(g(x)).

2. Inverse functions: An inverse function is a function that undoes the effect of another function. If f is a function from A to B, then the inverse of f, denoted by f<sup>-1</sup>, is the function from B to A such that for all x in A, f(f<sup>-1</sup>(x)) = x.

3. One-to-one functions: A function f is said to be one-to-one if and only if for every y in the range of f, there is exactly one x in the domain of f such that f(x) = y.

4. Onto functions: A function f is said to be onto if and only if for every y in the range of f, there is at least one x in the domain of f such that f(x) = y.

5. Identity functions: An identity function is a function that returns the same value for every input. The identity function for a set A is a function f from A to A such that for all x in A, f(x) = x.
