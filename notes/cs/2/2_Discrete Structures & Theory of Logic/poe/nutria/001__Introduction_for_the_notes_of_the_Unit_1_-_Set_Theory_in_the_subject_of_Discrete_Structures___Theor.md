
### Introduction to Unit 1 - Set Theory
1. A set is a collection of objects, which are called its elements. 
2. Sets can be finite or infinite. 
3. Sets can be ordered, such as a sequence, or unordered, such as a collection of objects. 
4. Sets can be represented in a variety of ways, including lists, diagrams, and tables. 
5. Set operations, such as union, intersection, and complement, can be used to combine sets and create new sets. 
6. The power set of a set is the set of all subsets of the set. 
7. The Cartesian product of two sets is the set of all ordered pairs of elements from the two sets. 
8. Relations and functions are sets of ordered pairs of elements. 
9. Equivalence relations are used to determine if two elements are related in some way. 
10. The principle of mathematical induction can be used to prove statements about sets.
