
### Definition for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

- A **set** is a collection of distinct objects, called **elements**, which are grouped together into a single unit. 
- The elements of a set are usually related in some way, but this is not always the case. 
- Sets can be finite or infinite. 
- A set with a finite number of elements is called a **finite set**. 
- An infinite set is called an **infinite set**.
- The **order** of a set is the number of elements in it. 
- The **cardinality** of a set is the number of elements in it. 
- Sets can be **empty**, meaning they have no elements. 
- The **power set** of a set is the set of all possible subsets of a set. 
- Two sets are said to be **equal** if they have the same elements. 
- Two sets are said to be **disjoint** if they have no elements in common. 
- The **union** of two sets is the set of all elements in either set. 
- The **intersection** of two sets is the set of all elements in both sets. 
- The **difference** of two sets is the set of all elements in the first set that are not in the second set. 
- The **complement** of a set is the set of all elements not in the set. 
- The **Cartesian product** of two sets is the set of all ordered pairs of elements from the two sets.
