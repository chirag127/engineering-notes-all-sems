

### Truth Tables for Propositional Logic

1. A truth table is a tool used to analyze the validity of a logical statement. 
2. It is a chart that shows the truth value of a statement for every possible combination of truth values of its components. 
3. The components of a statement are known as its **propositions**. 
4. A proposition can either be true or false. 
5. The truth value of a statement is determined by the truth values of its propositions. 
6. A truth table consists of two columns: one for the propositions and one for the statement. 
7. Each row in the table represents a different combination of truth values for the propositions. 
8. The statement column will display the truth value of the statement for the corresponding combination of truth values of the propositions. 
9. The statement is true if and only if all of its propositions are true. 
10. The statement is false if and only if one or more of its propositions are false.
