
### Properties of Relations

1. A relation is a set of ordered pairs. 
2. A relation is a subset of the Cartesian product of two sets.
3. A relation is a set of inputs and outputs.
4. A relation can be represented as a graph, a table, a set of ordered pairs, or a mapping diagram.
5. A relation is said to be reflexive if every element in the set is related to itself. 
6. A relation is said to be symmetric if for every pair of elements (a, b), (b, a) is also a pair in the relation.
7. A relation is said to be transitive if for every pair of elements (a, b) and (b, c), (a, c) is also a pair in the relation.
8. A relation is said to be antisymmetric if for every pair of elements (a, b) and (b, a), a = b.
9. A relation can be either a function or a non-function. 
10. A function is a relation that satisfies the vertical line test.
