
### Multisets for the Notes of Unit 1 - Set Theory in the Subject of Discrete Structures & Theory of Logic

1. A **multiset** (also known as a **bag**) is a collection of elements that can contain multiple copies of the same element.
2. A multiset is a generalization of the concept of a set, which allows multiple copies of the same element to be present.
3. Multisets are not ordered, meaning that the order in which the elements appear does not matter.
4. The cardinality of a multiset is the number of elements it contains, regardless of how many copies of each element are present.
5. The union of two multisets is a multiset containing all elements of both multisets, with the number of copies of each element equal to the maximum of the two multisets.
6. The intersection of two multisets is a multiset containing all elements that are present in both multisets, with the number of copies of each element equal to the minimum of the two multisets.
7. The difference of two multisets is a multiset containing all elements of the first multiset, with the number of copies of each element equal to the difference between the two multisets.
8. The symmetric difference of two multisets is a multiset containing all elements that are present in one multiset but not in the other, with the number of copies of each element equal to the difference between the two multisets.
9. Multisets can also be compared using the subset and proper subset relations. A multiset is a subset of another multiset if all elements of the first multiset are also present in the second multiset, with the number of copies of each element equal to or less than the number of copies in the second multiset.
10. A multiset is a proper subset of another multiset if all elements of the first multiset are also present in the second multiset, with the number of copies of each element strictly less than the number of copies in the second multiset.
