
### Recursively defined functions for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. A recursive definition is a definition that refers to itself. It is a way of defining objects in which objects are defined in terms of other objects of the same type. 
2. A recursive definition of a set is a definition of a set that is defined in terms of other sets. 
3. A recursive definition of a function is a definition of a function that is defined in terms of other functions. 
4. A recursive function is a function that is defined in terms of itself. 
5. A recursive definition of a sequence is a definition of a sequence that is defined in terms of other sequences. 
6. A recursive definition of a graph is a definition of a graph that is defined in terms of other graphs. 
7. A recursive definition of a tree is a definition of a tree that is defined in terms of other trees. 
8. A recursive definition of an algorithm is a definition of an algorithm that is defined in terms of other algorithms. 
9. A recursive definition of a language is a definition of a language that is defined in terms of other languages.
