
### Recursive definition of functions

1. A **recursive definition** of a function is a definition that uses the function itself in its definition. 
2. A **recurrence relation** is an equation that describes the relationship between a sequence of values. 
3. A **generating function** is a special type of function that can be used to generate a sequence of values. 
4. A **recursive function** is a function that calls itself in its definition. 
5. A **recursive algorithm** is an algorithm that uses a recursive definition of a function to solve a problem. 
6. A **recurrence equation** is an equation that describes the relationship between a sequence of values. 
7. A **generating series** is a special type of series that can be used to generate a sequence of values. 
8. A **recursive procedure** is a procedure that calls itself in its definition.
