
### Growth of Functions for the Notes of the Unit 1 - Set Theory in the Subject of Discrete Structures & Theory of Logic

1. A function is a mapping between two sets, the domain and the codomain.
2. The domain is the set of all the inputs of the function, while the codomain is the set of all the outputs of the function.
3. A function is said to be growing if its output values increase as its input values increase.
4. A function is said to be strictly increasing if its output values are strictly greater than its input values.
5. A function is said to be strictly decreasing if its output values are strictly less than its input values.
6. A function is said to be constant if its output values are equal to its input values.
7. A function is said to be monotonic if it is either strictly increasing or strictly decreasing.
8. A function is said to be periodic if its outputs repeat at regular intervals.
9. The composition of two functions is the result of applying one function to the output of another.
10. The inverse of a function is the result of reversing the mapping between the domain and codomain.
