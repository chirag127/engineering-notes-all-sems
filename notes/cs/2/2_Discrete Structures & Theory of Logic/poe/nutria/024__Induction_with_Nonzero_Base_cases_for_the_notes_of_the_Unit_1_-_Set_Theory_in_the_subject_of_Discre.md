
### Induction with Nonzero Base Cases

* Induction is a method of mathematical proof used to prove that a statement holds true for all natural numbers. 
* In order to use induction, one must first prove that the statement holds true for the base case, which is usually 0 or 1. 
* Once the base case is proven, one can then assume that the statement holds true for any number n and show that it also holds true for n+1. 
* This is done by assuming that the statement holds true for n and then deriving a proof that the statement also holds true for n+1. 
* This is the principle of mathematical induction. 
* Nonzero base cases are used when the statement holds true for some number greater than 0. 
* For example, if one wanted to prove that the sum of the first n natural numbers is equal to n(n+1)/2, then one would prove this for the base case n = 1. 
* Then, by assuming that the statement holds true for n, one can prove that it also holds true for n+1. 
* This is done by showing that the sum of the first n+1 natural numbers is equal to (n+1)(n+2)/2. 
* This is an example of how induction with nonzero base cases can be used to prove a statement.
