
### Complemented for the notes of the Unit 3 - Lattices in the subject of Discrete Structures & Theory of Logic

1. A lattice is a partially ordered set with a unique minimal and maximal element.
2. In a lattice, the set of all elements that are less than a given element is called the lower set of that element.
3. The set of all elements that are greater than a given element is called the upper set of that element.
4. A lattice is said to be distributive if the meet and join operations satisfy the distributive law.
5. A lattice is said to be complemented if it has a unique complement for each element.
6. A lattice is said to be modular if the meet and join operations satisfy the modular law.
7. A lattice is said to be distributive if it is both distributive and modular.
8. A lattice is said to be Boolean if it is complemented and distributive.
9. A lattice is said to be homogeneous if all elements are equivalent.
10. A lattice is said to be planar if it can be drawn in a plane without any edges crossing.
