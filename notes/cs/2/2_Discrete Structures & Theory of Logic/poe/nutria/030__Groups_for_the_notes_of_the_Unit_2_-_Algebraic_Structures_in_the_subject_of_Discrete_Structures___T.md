

### Groups for the Notes of the Unit 2 - Algebraic Structures in the Subject of Discrete Structures & Theory of Logic

* A group is a set of elements with a binary operation that satisfies the following properties:
    * Closure: The result of combining any two elements of the set is also an element of the set.
    * Associativity: The order in which the elements are combined does not affect the result.
    * Identity: There is an element in the set (the identity element) such that when combined with any other element of the set, the result is the same element.
    * Inverse: For each element in the set, there is an inverse element such that when combined with the element, the result is the identity element.
* Examples of groups include the integers under addition, the non-zero rationals under multiplication, and the permutations of a set under composition.
* Subgroups are groups within a larger group. A subgroup must satisfy the same properties as a group, and any element of the subgroup must also be an element of the larger group.
* The order of a group is the number of elements in the group.
* The center of a group is the set of elements that commute with all other elements in the group.
* The conjugacy class of an element of a group is the set of all elements that are conjugate to that element.
* The normalizer of a subgroup is the set of elements that map the subgroup to itself under conjugation.
* A homomorphism is a mapping from one group to another that preserves the group structure.
* An isomorphism is a bijective homomorphism from one group to another.
* The kernel of a homomorphism is the set of elements of the domain that are mapped to the identity element.
* The image of a homomorphism is the set of elements of the codomain that are the images of elements of the domain.
* The direct product of two groups is the set of ordered pairs of elements of the two groups, with the operation of component-wise multiplication.
* The direct sum of two groups is the set of ordered pairs of elements of the two groups, with the operation of component-wise addition.
