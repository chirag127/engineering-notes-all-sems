
### Binary Tree

A binary tree is a type of data structure used to store data in a hierarchical manner. It is composed of nodes, which store data and have two or more branches. Each branch is a reference to another node or a null pointer, indicating that it does not point to any other node.

The data in a binary tree is organized in a hierarchical structure, with each node having a left and right child. The root node is the highest node in the tree and is the only node without a parent node. The left and right children of a node are referred to as the left and right subtrees of the node.

A binary tree is a type of tree in which each node has at most two children. The left child is referred to as the left subtree and the right child is referred to as the right subtree. The number of nodes in a binary tree is one less than the number of edges.

The height of a binary tree is the number of edges between the root node and the deepest node. The depth of a node is the number of edges between the node and the root node.

A binary search tree is a binary tree in which the value of each node is greater than or equal to the values of its left subtree and less than or equal to the values of its right subtree.

A complete binary tree is a binary tree in which every level, except possibly the last, is completely filled, and all nodes are as far left as possible.

A full binary tree is a binary tree in which every node has either zero or two children.

A perfect binary tree is a binary tree in which all leaves are at the same level and all internal nodes have two children.

A balanced binary tree is a binary tree in which the height of the left and right subtrees of every node differ by at most one.
