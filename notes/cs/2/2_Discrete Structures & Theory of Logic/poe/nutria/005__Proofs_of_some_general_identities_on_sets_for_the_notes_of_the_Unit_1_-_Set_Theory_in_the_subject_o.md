
### Proofs of some General Identities on Sets

1. If two sets A and B have the same elements, then A = B.
2. If A is a subset of B, then B is a superset of A.
3. If A is a subset of B and B is a subset of C, then A is a subset of C.
4. If A is a subset of B, then the number of elements in A is less than or equal to the number of elements in B.
5. If A and B are two sets, then the union of A and B (A U B) is the set of all elements that are in either A or B.
6. If A and B are two sets, then the intersection of A and B (A ∩ B) is the set of all elements that are in both A and B.
7. If A and B are two sets, then the complement of A (A') is the set of all elements that are not in A.
8. If A and B are two sets, then the difference between A and B (A - B) is the set of all elements that are in A but not in B.
