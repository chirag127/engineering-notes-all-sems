
### Mathematical Induction for the notes of the Unit 1 - Set Theory in the subject of Discrete Structures & Theory of Logic

1. Mathematical induction is an important proof technique used to establish the truth of a statement for all natural numbers. 
2. It is a form of proof by induction, which is a type of proof by contradiction.
3. The basic idea behind mathematical induction is that if a statement is true for a certain number, then it is also true for the next number.
4. To prove a statement using mathematical induction, we must first prove it is true for a base case, then prove that if it is true for one number, it is true for the next number.
5. The base case is usually the number 0 or 1.
6. To prove the statement for a base case, we must show that the statement is true for the base case.
7. To prove the statement for the next number, we must assume that the statement is true for the preceding number and then show that it is true for the next number.
8. Once the statement is proven for the base case and for the next number, it is true for all natural numbers.
