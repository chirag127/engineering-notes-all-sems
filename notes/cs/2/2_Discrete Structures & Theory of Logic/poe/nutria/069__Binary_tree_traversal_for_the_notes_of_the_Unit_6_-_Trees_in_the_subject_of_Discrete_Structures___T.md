
### Binary Tree Traversal 

* Binary tree traversal is the process of visiting each node in a tree in a specific order. 
* There are three main types of traversal: pre-order, in-order, and post-order. 
* Pre-order traversal visits the root node first, then its left and right subtrees. 
* In-order traversal visits the left subtree first, then the root node, then the right subtree. 
* Post-order traversal visits the left subtree first, then the right subtree, then the root node. 
* Each type of traversal has its own advantages and disadvantages. 
* Pre-order traversal is useful for creating a copy of the tree, while in-order traversal is useful for searching for specific values in the tree. 
* Post-order traversal is useful for deleting the tree since it visits the nodes in the reverse order of creation. 
* Traversing a tree can be done recursively or iteratively. 
* Recursive traversal is simpler to implement, but can be inefficient due to the large number of recursive calls. 
* Iterative traversal is more efficient, but requires more complex code.
