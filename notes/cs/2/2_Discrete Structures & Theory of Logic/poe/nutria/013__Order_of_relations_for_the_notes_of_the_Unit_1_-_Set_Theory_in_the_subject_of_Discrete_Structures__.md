
### Order of Relations for the Notes of the Unit 1 - Set Theory in the Subject of Discrete Structures & Theory of Logic

1. A relation is a set of ordered pairs, which can be represented in a table or graph.
2. The domain of a relation is the set of all first elements in the ordered pairs.
3. The range of a relation is the set of all second elements in the ordered pairs.
4. A relation is reflexive if, for every element in the domain, (x,x) is an ordered pair in the relation.
5. A relation is symmetric if, for every ordered pair (x,y) in the relation, (y,x) is also an ordered pair in the relation.
6. A relation is antisymmetric if, for every ordered pair (x,y) in the relation, (y,x) is not an ordered pair in the relation.
7. A relation is transitive if, for every ordered pair (x,y) and (y,z) in the relation, (x,z) is also an ordered pair in the relation.
8. A function is a special type of relation where each element in the domain is related to exactly one element in the range.
