
### Bipartite Graphs

1. A bipartite graph is a graph whose vertices can be divided into two disjoint sets such that every edge connects a vertex in one set to a vertex in the other set. 
2. Bipartite graphs are used to represent relationships between two sets of objects, such as in a social network.
3. A bipartite graph can be represented as an adjacency matrix, which is a two-dimensional array of boolean values. 
4. A bipartite graph can be tested for bipartiteness by using the two-color theorem, which states that a graph is bipartite if and only if it can be colored with two colors such that no two adjacent vertices have the same color.
5. The maximum matching problem is a problem in graph theory that seeks to find the maximum number of edges in a graph that are not incident to each other. 
6. An algorithm for finding a maximum matching in a bipartite graph is the Hopcroft-Karp algorithm, which runs in O(|E|sqrt(|V|)) time.
7. The minimum vertex cover problem is a problem in graph theory that seeks to find the smallest set of vertices that covers all the edges in a graph.
8. An algorithm for finding a minimum vertex cover in a bipartite graph is the König-Egerváry algorithm, which runs in O(|E|log|V|) time.
