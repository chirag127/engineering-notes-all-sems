### Discrete and Continuous Probability Distribution

A probability distribution is a function that describes all possible values of a random variable as well as the associated probabilities. A random variable is a variable whose value is determined by the outcome of a random experiment.

There are two types of probability distributions:

- Discrete probability distributions
- Continuous probability distributions

#### Discrete Probability Distributions

A discrete probability distribution is a probability distribution of a categorical or discrete variable. A discrete variable is a variable that can take only a finite or countable number of values, such as integers, letters, or words.

A discrete probability distribution assigns a probability to each possible value of the discrete variable. The sum of all the probabilities must be equal to 1. The probability of any event involving the discrete variable is the sum of the probabilities of the values that make up the event.

Some examples of discrete probability distributions are:

- Binomial distribution: The distribution of the number of successes in a fixed number of independent Bernoulli trials, where each trial has only two possible outcomes (success or failure) with the same probability of success.
- Poisson distribution: The distribution of the number of events that occur in a fixed interval of time or space, where the events are independent and rare.
- Geometric distribution: The distribution of the number of trials needed to get the first success in a sequence of independent Bernoulli trials.
- Uniform distribution: The distribution where all the possible values of the discrete variable have the same probability.

#### Continuous Probability Distributions

A continuous probability distribution is a probability distribution of a continuous variable. A continuous variable is a variable that can take any value in a continuous range, such as real numbers, lengths, or weights.

A continuous probability distribution assigns a probability density to each possible value of the continuous variable. The probability density is a function that measures how likely a value is to occur. The total area under the probability density function must be equal to 1. The probability of any event involving the continuous variable is the area under the probability density function over the interval that defines the event.

Some examples of continuous probability distributions are:

- Normal distribution: The distribution of a variable that is symmetric and bell-shaped, where most of the values are clustered around the mean and the variance measures how spread out the values are.
- Exponential distribution: The distribution of the time between events in a Poisson process, where the events are independent and rare.
- Uniform distribution: The distribution where all the possible values of the continuous variable have the same probability density.
- Beta distribution: The distribution of a variable that is bounded between 0 and 1, where the shape of the distribution depends on two parameters that measure how skewed and peaked the distribution is.
