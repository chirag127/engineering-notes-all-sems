### Linear and Non Linear Partial Equations of first order

- A partial differential equation (PDE) is an equation that involves partial derivatives of an unknown function of two or more variables. For example, `u_x + u_y = 0` is a PDE, where `u = u(x,y)` and `u_x` and `u_y` are the partial derivatives of `u` with respect to `x` and `y`, respectively.
- A PDE is said to be of first order if the highest partial derivatives of the unknown function are of the first order. For example, `u_x + u_y = 0` is a first order PDE, while `u_xx + u_yy = 0` is a second order PDE, where `u_xx` and `u_yy` are the second partial derivatives of `u` with respect to `x` and `y`, respectively.
- A PDE is said to be linear if it is linear in the unknown function and its partial derivatives. That is, if the PDE can be written in the form `a(x,y)u_x + b(x,y)u_y + c(x,y)u = f(x,y)`, where `a`, `b`, `c` and `f` are given functions of `x` and `y`, and `u` is the unknown function. For example, `u_x + u_y = 0` is a linear PDE, while `u_x + u_y + u^2 = 0` is a non-linear PDE, because it is not linear in `u` and `u_x`.
- A PDE is said to be non-linear if it is not linear. That is, if the PDE involves products, powers, or other non-linear functions of the unknown function and its partial derivatives. For example, `u_x + u_y + u^2 = 0` is a non-linear PDE, while `u_x + u_y = 0` is a linear PDE.
- The general form of a first order PDE is `F(x,y,u,u_x,u_y) = 0`, where `F` is a given function of five variables, and `u` is the unknown function. Depending on the form of `F`, the PDE can be linear or non-linear. For example, `F(x,y,u,u_x,u_y) = u_x + u_y + u^2` is a non-linear first order PDE, while `F(x,y,u,u_x,u_y) = u_x + u_y` is a linear first order PDE.
