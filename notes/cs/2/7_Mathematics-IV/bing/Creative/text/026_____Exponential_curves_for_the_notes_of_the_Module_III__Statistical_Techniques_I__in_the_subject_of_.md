### Exponential curves

- An exponential curve is a graph of an exponential function  .
- An exponential function is a mathematical function of the form f(x) = a^x, where a > 0 and a ≠ 1, and x is any real number .
- The exponential curve depends on the value of x and the base a. The curve is always positive and never touches the x-axis.
- The exponential curve has the following properties :
  - If a > 1, the curve is increasing and concave up. It has a horizontal asymptote at y = 0 and a y-intercept at (0, 1).
  - If 0 < a < 1, the curve is decreasing and concave down. It has a horizontal asymptote at y = 0 and a y-intercept at (0, 1).
  - The slope of the curve at any point is proportional to the function value at that point. The slope is positive if a > 1 and negative if 0 < a < 1.
  - The curve is symmetric about the y-axis if a = e, where e is the natural base (approximately 2.718). This is called the natural exponential function, denoted by f(x) = e^x.
  - The curve passes through the point (1, a) for any value of a.
  - The curve has an inverse function, called the logarithmic function, denoted by f^-1(x) = log_a(x), where log_a(x) is the exponent to which a must be raised to get x.
- The exponential curve can be used to model various phenomena that involve growth or decay, such as population, bacteria, radioactive decay, compound interest, etc .
