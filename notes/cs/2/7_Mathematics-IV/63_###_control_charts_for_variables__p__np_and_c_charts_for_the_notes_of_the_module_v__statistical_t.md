### Control Charts for Variables ( p, np and C charts) for the notes of the Module V: Statistical Techniques III: in the subject of Mathematics-IV KCS

Module V of the Mathematics-IV KCS course covers the topic of Statistical Techniques III, including control charts. Control charts are graphical tools used to monitor and control quality in a process.

There are three types of control charts for variables: p charts, np charts, and C charts.

p charts are used to monitor the proportion of defects in a process. The p chart is used when the number of defects is counted in each subgroup of a sample.

np charts are used to monitor the number of defects in a process. The np chart is used when the number of defects is counted in each subgroup of a sample.

C charts are used to monitor the number of defects per unit in a process. The C chart is used when the number of defects is counted in each unit of a sample.

In the context of the Mathematics-IV KCS course, students will learn about control charts for variables, including p charts, np charts, and C charts, as part of Module V. This may include working with examples of control charts, constructing control charts, and interpreting the results of control chart analysis.
