### Non Linear Regression

1. Non Linear Regression is a form of regression analysis in which the relationship between the independent variable x and the dependent variable y is modeled as a non-linear function.
2. The linear regression models the relationship using a linear function but in many real world scenarios, the relationship is non-linear. For example, the relationship between price and demand or price and sales is typically a non-linear curve.
3. Some commonly used non-linear functions are:
- Exponential function: y = aebx
- Logarithmic function: y = a + blog(x)
- Power function: y = axn
4. The non-linear regression model is more flexible than the linear regression model but it is also more complicated and time-consuming to compute.
5. The basic steps to perform non-linear regression are:
- Select a non-linear function that fits the data reasonably well
- Estimate the parameters of the non-linear function using least squares method
- Check the adequacy of the fitted model using diagnostic plots and tests
- Make inferences about the independent variable(s) or predictions
