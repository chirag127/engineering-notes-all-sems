### Probability mass function and Probability density function

- Probability mass function (PMF): For discrete random variables, probability mass function is defined as a function which gives the probability that the random variable takes on a specific value. It is denoted by p(x) where x takes values from the sample space of the random variable.
- Properties of PMF:
-- PMF is a non-negative function: p(x) >= 0 for all x.
-- Sum of PMF over the sample space is 1: Sum p(x) over all x = 1.
-- PMF can take only non-negative integer values.

- Probability density function (PDF): For continuous random variables, probability density function is defined as a function which gives the relative likelihood of the random variable taking on a given value. It is denoted by f(x) where x takes values from the sample space of the random variable.
- Properties of PDF:
-- PDF is a non-negative function: f(x) >= 0 for all x.
-- Integral of PDF over the range is 1: Integral f(x) dx = 1.
-- PDF can take fractional values.
