### Random variables (Discrete and Continuous Random variable)

Random variables are used in probability theory to describe the outcomes of a random process. They can be either discrete or continuous.

#### Discrete Random Variables

A discrete random variable is one that can only take on specific, separate values. Examples of discrete random variables include the number of heads in a coin toss, the number of children in a family, and the number of cars passing through a toll booth in a day.

The probability distribution of a discrete random variable is often represented using a probability mass function (PMF), which gives the probability of each possible outcome.

#### Continuous Random Variables

A continuous random variable is one that can take on any value within a certain range. Examples of continuous random variables include the height of a person, the time it takes to complete a task, and the temperature at a given location.

The probability distribution of a continuous random variable is often represented using a probability density function (PDF), which gives the probability of a random variable taking on a certain value within a certain range.

#### Relationship between Discrete and Continuous Random Variables

While the two types of random variables are distinct, they are also related. A continuous random variable can be thought of as a limit of a sequence of discrete random variables as the number of possible outcomes approaches infinity.

In addition, many probability distributions can be either discrete or continuous depending on the context. For example, the uniform distribution can be either discrete (if the possible outcomes are integers) or continuous (if the possible outcomes are real numbers).

#### Summary

- Random variables can be either discrete or continuous.
- Discrete random variables can only take on specific, separate values and are often represented using a PMF.
- Continuous random variables can take on any value within a certain range and are often represented using a PDF.
- The relationship between discrete and continuous random variables is complex and depends on the specific context.
