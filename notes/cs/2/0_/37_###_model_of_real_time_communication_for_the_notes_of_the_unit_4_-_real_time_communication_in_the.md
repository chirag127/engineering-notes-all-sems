### Model of Real Time Communication for the notes of the Unit 4 - Real Time Communication in the subject of Real Time System

"Model of Real Time Communication" is a topic covered in Unit 4 - Real Time Communication in the subject of Real Time Systems. The goal of this topic is to provide students with an understanding of the various models used for real-time communication, and the implications of these models for real-time systems.

There are several models used for real-time communication, including:

1. Polling Model: In the polling model, the sender polls the receiver to determine if the receiver is ready to receive data. This model is often used in real-time systems where the sender needs to send data at a specific rate, and the receiver needs to be able to receive data at that rate.

2. Interrupt Model: In the interrupt model, the receiver sends an interrupt to the sender when it is ready to receive data. This model is often used in real-time systems where the receiver needs to receive data as soon as it is available, and the sender needs to be able to send data as soon as the receiver is ready.

3. Event-Driven Model: In the event-driven model, the sender and receiver exchange data in response to events. This model is often used in real-time systems where the sender and receiver need to exchange data in response to specific events, such as the completion of a task or the arrival of new data.

The goal of studying the model of real-time communication is to provide students with an understanding of the various models used for real-time communication, and the implications of these models for real-time systems. This knowledge and understanding is important for students pursuing careers in real-time systems, as it provides the foundation for more advanced topics in real-time communication and real-time systems design.
