### Stack Based Priority-Ceiling Protocol for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

Stack-Based Priority Ceiling Protocol (SBPCP) is a resource allocation algorithm used in real-time systems for synchronizing access to shared resources. It prioritizes tasks based on their priority levels and assigns a unique ceiling priority to each resource. When a task requests access to a resource, it temporarily raises its priority to the ceiling priority of the resource, ensuring that no lower-priority task can interfere with its access. The task's original priority level is restored when it releases the resource. This protocol prevents priority inversion, a situation where a low-priority task holds a resource needed by a high-priority task, causing the high-priority task to wait.
