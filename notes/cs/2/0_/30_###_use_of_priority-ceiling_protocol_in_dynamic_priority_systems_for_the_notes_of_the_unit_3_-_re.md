### Use of Priority-Ceiling Protocol in Dynamic Priority Systems for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

"Priority-Ceiling Protocol" is a key concept in the field of Real Time Systems, and is often covered in Unit 3 - Resources Sharing in the subject of Real Time System.

The priority-ceiling protocol is a method used to manage resource sharing in dynamic priority systems. It is based on the idea of assigning a priority ceiling to each resource, which is the highest priority that can be assigned to a task that is using the resource.

The priority-ceiling protocol works by ensuring that tasks that are using a resource are assigned a priority that is higher than the priority of any other task that may need to use the same resource. This prevents priority inversion, which is a situation where a lower priority task holds a resource that is needed by a higher priority task, causing the higher priority task to be blocked.

The use of the priority-ceiling protocol in dynamic priority systems provides several benefits, including:

1. Improved Resource Sharing: The priority-ceiling protocol ensures that resources are shared fairly and efficiently between tasks, reducing the likelihood of resource contention and improving overall system performance.

2. Improved Real-Time Performance: The priority-ceiling protocol ensures that high-priority tasks have access to the resources they need when they need them, improving the real-time performance of the system.

3. Improved Predictability: The priority-ceiling protocol provides a predictable and deterministic method for managing resource sharing, which is important for real-time systems that require predictable and reliable behavior.
