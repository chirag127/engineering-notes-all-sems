### Dynamic Versus Static Systems for the notes of the Unit 2 - Real Time Scheduling in the subject of Real Time System

"Dynamic Versus Static Systems" is a topic covered in the Unit 2 - Real Time Scheduling of the subject of Real Time Systems. The goal of this topic is to provide students with an understanding of the differences between dynamic and static systems, and the implications of these differences for real-time scheduling.

Dynamic systems are systems that change over time, with the state of the system and the inputs to the system changing over time. Examples of dynamic systems include real-time operating systems, control systems, and communication systems.

Static systems, on the other hand, are systems that do not change over time. Examples of static systems include batch processing systems, file servers, and database systems.

The main differences between dynamic and static systems include:

1. Predictability: Dynamic systems are often less predictable than static systems, as the state of the system and the inputs to the system can change over time.

2. Scheduling: Real-time scheduling is often more challenging in dynamic systems, as the state of the system and the inputs to the system can change over time, making it more difficult to predict the execution time of tasks and to schedule tasks to meet deadlines.

3. Resource Utilization: Dynamic systems often require more resources than static systems, as the state of the system and the inputs to the system can change over time, requiring the system to respond to changing conditions.

The goal of this topic is to provide students with an understanding of the differences between dynamic and static systems, and the implications of these differences for real-time scheduling. This knowledge and understanding is important for students pursuing careers in real-time systems, as it provides the foundation for more advanced topics in real-time scheduling and real-time systems design.
