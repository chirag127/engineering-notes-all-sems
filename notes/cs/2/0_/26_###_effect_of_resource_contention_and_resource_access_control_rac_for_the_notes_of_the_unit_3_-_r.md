### Effect of Resource Contention and Resource Access Control (RAC) for the notes of the Unit 3 - Resources Sharing in the subject of Real Time System

Resource Contention:
- Occurs when multiple processes compete for a limited resource
- Can cause delays or failures in real-time systems
- Can be resolved through resource allocation policies or resource access control

Resource Access Control (RAC):
- Mechanism to regulate access to shared resources
- Can prevent resource contention and ensure predictable resource utilization in real-time systems
- Examples: priority-based scheduling, rate monotonic analysis, earliest deadline first scheduling.

Overall, resource contention and RAC are important considerations in real-time systems to ensure predictable resource utilization and prevent delays or failures.
