### Finite Automata and Regular Expression for the notes of the Unit 2 - Regular Expressions and Languages in the subject of Theory of Automata and Formal Languages

Finite Automata:
- A finite automaton (FA) is a mathematical model of a machine that can be in one of a finite number of states.
- It consists of a finite set of states, an input alphabet, a transition function that maps inputs and current state to next state, a start state, and a set of accepting/final states.
- The automaton reads a string of symbols from the input alphabet and transitions through the states according to the transition function. If the final state is an accepting state, the automaton accepts the input.
- There are two types of finite automata: deterministic finite automata (DFA) and non-deterministic finite automata (NFA).

Regular Expression:
- A regular expression (regex) is a sequence of characters that specifies a set of strings.
- It is used to match patterns in strings and is widely used in text processing, search and replace operations, and pattern matching.
- Regex consists of a set of symbols, including letters, digits, special characters, and operators, that define the pattern to be matched.
- There are different types of regex engines, including POSIX and Perl-compatible, each with its own syntax and features.
- Regex can be used to match and extract information from strings, validate the format of strings, and replace parts of strings with new values.
