# Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

## Derivations

1. A **derivation** is a sequence of grammar rule applications that transforms the start symbol into a string of terminal symbols.
2. A **leftmost derivation** is a derivation where the leftmost non-terminal symbol is always expanded first.
3. A **rightmost derivation** is a derivation where the rightmost non-terminal symbol is always expanded first.
4. A **sentential form** is any string of symbols that can be derived from the start symbol.
5. A **sentence** is a sentential form that consists only of terminal symbols.
6. A **language** generated by a grammar is the set of all sentences that can be derived from the start symbol.

## Regular Grammars

1. A **regular grammar** is a type of formal grammar that is used to generate regular languages.
2. Regular grammars can be either **right-linear** or **left-linear**.
3. A **right-linear grammar** is a regular grammar where all production rules are of the form `A -> aB` or `A -> a`, where `A` and `B` are non-terminal symbols and `a` is a terminal symbol.
4. A **left-linear grammar** is a regular grammar where all production rules are of the form `A -> Ba` or `A -> a`, where `A` and `B` are non-terminal symbols and `a` is a terminal symbol.
5. Regular grammars can be used to generate regular expressions, which can be used to describe regular languages.

## Non-Regular Grammars

1. A **non-regular grammar** is a type of formal grammar that is used to generate non-regular languages.
2. Non-regular grammars can generate languages that cannot be generated by regular grammars.
3. Non-regular grammars can have production rules of any form, unlike regular grammars which have restrictions on the form of their production rules.
4. Non-regular grammars can be used to generate context-free languages, which are a superset of regular languages.
