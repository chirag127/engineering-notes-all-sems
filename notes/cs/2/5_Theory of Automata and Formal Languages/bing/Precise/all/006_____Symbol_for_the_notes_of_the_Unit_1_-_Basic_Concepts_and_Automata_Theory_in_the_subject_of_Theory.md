# Unit 1 - Basic Concepts and Automata Theory

### Symbols

- A symbol is the smallest unit of information in a language.
- A symbol can be any character, digit, or special character.
- Symbols are used to construct strings, which are sequences of symbols.
- The set of all possible symbols in a language is called the alphabet of the language.
- The alphabet is usually denoted by the Greek letter Sigma (Σ).
- An example of an alphabet is the set of all lowercase letters in the English language: {a, b, c, ..., z}.
- Another example is the set of all binary digits: {0, 1}.
- The empty string, denoted by ε, is a special string that contains no symbols.
- The length of a string is the number of symbols it contains.
- The set of all strings that can be constructed from an alphabet is called the Kleene closure of the alphabet, denoted by Σ*.
