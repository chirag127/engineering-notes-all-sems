# Context Free Grammars for Pushdown Automata

- A context-free grammar (CFG) is a formal grammar that describes a set of strings or sentences that can be generated by a set of production rules.
- A pushdown automaton (PDA) is a type of automaton that can recognize context-free languages.
- A PDA is similar to a finite automaton, but it has an additional stack data structure that allows it to recognize context-free languages.
- The stack allows the PDA to keep track of the context of the input string, which is necessary for recognizing context-free languages.
- A PDA can be defined as a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F), where:
  - Q is a finite set of states
  - Σ is the input alphabet
  - Γ is the stack alphabet
  - δ is the transition function
  - q0 is the initial state
  - Z0 is the initial stack symbol
  - F is the set of accepting states
- The transition function δ takes as input the current state, the current input symbol, and the current stack symbol, and outputs a set of possible next states and stack symbols.
- A PDA can be in one of three modes: shift, reduce, or accept.
- In shift mode, the PDA reads the next input symbol and pushes it onto the stack.
- In reduce mode, the PDA pops symbols from the stack and applies a production rule to generate a new stack symbol.
- In accept mode, the PDA accepts the input string if it is in an accepting state and the stack is empty.
- A context-free grammar can be converted into an equivalent PDA by constructing a PDA that simulates the derivation of strings using the production rules of the grammar.
- The PDA can then be used to recognize strings that belong to the language generated by the grammar.
