# Derivation Trees and Ambiguity

Derivation trees are graphical representations of the derivations of strings in a context-free grammar. They are used to visualize the structure of a sentence according to the rules of the grammar.

Ambiguity in a context-free grammar occurs when there is more than one derivation tree for a given string. This means that the string can be derived in more than one way, leading to multiple possible interpretations of its structure.

Here are some key points to remember about derivation trees and ambiguity:

1. A derivation tree shows the application of production rules in a context-free grammar to derive a string.
2. Each node in the tree represents a non-terminal symbol, and its children represent the symbols on the right-hand side of the production rule applied to that non-terminal.
3. The leaves of the tree represent the terminal symbols in the derived string.
4. Ambiguity arises when there is more than one derivation tree for a given string.
5. Ambiguity can be resolved by rewriting the grammar to eliminate the ambiguity, or by using disambiguation techniques such as precedence and associativity rules.
