# Finite Automata and Regular Expression

## Unit 2 - Regular Expressions and Languages

### Finite Automata

- A finite automaton is a mathematical model of computation used to recognize patterns within input taken from some character set (or alphabet).
- It consists of a finite set of states, a set of input symbols, a transition function, an initial state, and a set of final or accepting states.
- There are two types of finite automata: deterministic finite automata (DFA) and nondeterministic finite automata (NFA).
- In a DFA, for each state and input symbol, there is exactly one transition to another state. In an NFA, there can be multiple transitions from a single state for a given input symbol, or even transitions without any input symbol (epsilon transitions).
- Finite automata are used in text processing, compilers, and hardware design, among other applications.

### Regular Expression

- A regular expression is a pattern that describes a set of strings.
- It is a way to describe and manipulate sets of strings using a compact notation.
- Regular expressions are used in text processing, search engines, and programming languages, among other applications.
- The basic building blocks of regular expressions are characters, character sets, and operators.
- Common operators include concatenation, alternation, and repetition.
- Regular expressions can be converted to finite automata and vice versa.
