# Unit 4 - Push Down Automata and Properties of Context Free Languages

## Definition

- A **Push Down Automaton (PDA)** is a type of automaton that is used to recognize context-free languages.
- It is an extension of the finite automaton model with an additional stack memory.
- The stack memory allows the PDA to keep track of an unbounded amount of information, which is necessary for recognizing context-free languages.
- A **context-free language** is a type of formal language that can be generated by a context-free grammar.
- A **context-free grammar** is a type of formal grammar that consists of a set of production rules that describe how strings in the language can be generated.
- The production rules have the form `A -> w`, where `A` is a non-terminal symbol and `w` is a string of terminal and non-terminal symbols.
- The production rules can be applied in any order, and the resulting strings are all part of the language generated by the grammar.
- Context-free languages have important properties, such as closure under union, concatenation, and Kleene star, and the existence of a normal form for context-free grammars.
- These properties make context-free languages a useful tool for modeling and analyzing many types of computational problems.
