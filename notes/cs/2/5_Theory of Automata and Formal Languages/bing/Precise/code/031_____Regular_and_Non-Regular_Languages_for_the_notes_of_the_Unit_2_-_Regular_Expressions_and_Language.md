### Regular and Non-Regular Languages

#### Regular Languages
- A regular language is a formal language that can be expressed using a regular expression.
- Regular languages can be recognized by a finite automaton.
- Regular languages are closed under union, intersection, and complementation.
- Examples of regular languages include the set of all binary strings ending in 0, the set of all strings over the alphabet {a, b} with an even number of a's, and the set of all strings of the form ww^R, where w is a string over the alphabet {0, 1} and w^R is the reverse of w.

#### Non-Regular Languages
- A non-regular language is a formal language that cannot be expressed using a regular expression.
- Non-regular languages cannot be recognized by a finite automaton.
- Examples of non-regular languages include the set of all palindromes over the alphabet {0, 1}, the set of all strings over the alphabet {a, b} with an equal number of a's and b's, and the set of all strings of the form a^n b^n, where n is a positive integer.
