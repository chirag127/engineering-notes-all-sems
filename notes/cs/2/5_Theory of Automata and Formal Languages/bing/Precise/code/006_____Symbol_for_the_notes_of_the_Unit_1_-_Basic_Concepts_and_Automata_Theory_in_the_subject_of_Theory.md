### Symbol for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1. **Alphabet**: A finite set of symbols, denoted by Σ.
2. **String**: A finite sequence of symbols from an alphabet.
3. **Language**: A set of strings over an alphabet.
4. **Automaton**: An abstract machine that recognizes a language.
5. **Deterministic Finite Automaton (DFA)**: A type of automaton that has a finite number of states and reads input strings one symbol at a time, transitioning between states based on the current symbol and the current state.
6. **Nondeterministic Finite Automaton (NFA)**: A type of automaton that, like a DFA, has a finite number of states and reads input strings one symbol at a time. However, unlike a DFA, an NFA can transition to multiple states for a given symbol and state.
7. **Regular Language**: A language that can be recognized by a finite automaton.
8. **Regular Expression**: A notation for describing regular languages.
9. **Context-Free Grammar (CFG)**: A formal grammar that generates a context-free language.
10. **Context-Free Language (CFL)**: A language that can be generated by a context-free grammar.
11. **Pushdown Automaton (PDA)**: A type of automaton that, like a finite automaton, reads input strings one symbol at a time and transitions between states. However, unlike a finite automaton, a PDA also has a stack that can be used to store and retrieve symbols.
12. **Turing Machine (TM)**: A type of automaton that has an infinite tape divided into cells, each of which can store a symbol. A TM reads and writes symbols on the tape, moving the tape left or right based on the current state and symbol.
