### Alphabet for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1. An alphabet is a finite set of symbols or characters.
2. It is denoted by the Greek letter sigma (Σ).
3. The symbols in an alphabet are used to form strings or words.
4. The set of all possible strings over an alphabet Σ is denoted by Σ*.
5. The empty string, denoted by ε, is a string with no symbols and is considered to be part of Σ*.
6. The length of a string is the number of symbols it contains.
7. The concatenation of two strings is the operation of appending one string to the end of the other.
8. The set of all strings of length n over an alphabet Σ is denoted by Σ^n.
9. A language is a set of strings over an alphabet.
10. The union, intersection, and complement of languages are defined in the same way as for sets.
11. The concatenation of two languages L1 and L2 is the set of all strings obtained by concatenating a string from L1 with a string from L2.
12. The Kleene closure of a language L, denoted by L*, is the set of all strings that can be obtained by concatenating zero or more strings from L.
13. The positive closure of a language L, denoted by L+, is the set of all strings that can be obtained by concatenating one or more strings from L.
