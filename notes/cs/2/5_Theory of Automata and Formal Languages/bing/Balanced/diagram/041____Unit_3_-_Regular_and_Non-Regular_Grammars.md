## Unit 3 - Regular and Non-regular Grammars

- A grammar is a set of rules that defines how a language is generated from a finite set of symbols (alphabet).
- A grammar consists of four components: a set of terminals (symbols that appear in the language), a set of non-terminals (symbols that represent intermediate structures in the derivation process), a start symbol (a special non-terminal that indicates the beginning of the derivation), and a set of production rules (rules that specify how a non-terminal can be replaced by a sequence of terminals and non-terminals).
- A grammar is said to be regular if it satisfies one of the following equivalent conditions:
  - All the production rules are of the form A -> a or A -> aB, where A and B are non-terminals and a is a terminal.
  - All the production rules are of the form A -> a or A -> Ba, where A and B are non-terminals and a is a terminal.
  - The grammar can be represented by a finite state automaton (FSA), a mathematical model of computation that consists of a finite set of states, a finite set of input symbols, a transition function that maps a state and an input symbol to a new state, a start state, and a set of final states. The FSA accepts a string if it can reach a final state from the start state by following the transitions according to the input symbols.
- A grammar is said to be non-regular if it does not satisfy any of the above conditions. Non-regular grammars can generate languages that are more complex and expressive than regular languages, such as languages that involve counting, nesting, or recursion.
- A language is a set of strings that are generated by a grammar. A language is said to be regular if it can be generated by a regular grammar, and non-regular otherwise.
- Some examples of regular languages are:
  - The language of all strings over {a, b} that end with a.
  - The language of all strings over {0, 1} that contain an even number of 0s.
  - The language of all strings over {a, b, c} that do not contain the substring "abc".
- Some examples of non-regular languages are:
  - The language of all strings over {a, b} that have the same number of a's and b's.
  - The language of all strings over {0, 1} that are palindromes (strings that are the same when read backwards).
  - The language of all strings over {a, b} that are of the form a^n b^n, where n is a positive integer.
