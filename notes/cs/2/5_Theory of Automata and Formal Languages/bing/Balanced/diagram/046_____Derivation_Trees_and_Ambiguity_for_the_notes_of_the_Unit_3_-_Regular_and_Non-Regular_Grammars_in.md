### Derivation Trees and Ambiguity

- A derivation tree or parse tree is a graphical representation of the derivation of a string by a context-free grammar (CFG).
- A derivation tree shows how the start symbol of the CFG is transformed into the string by applying the production rules in each step.
- A derivation tree has the following properties:
  - The root node is labeled with the start symbol of the CFG.
  - The internal nodes are labeled with the non-terminal symbols of the CFG.
  - The leaf nodes are labeled with the terminal symbols or # (empty string) of the CFG.
  - The order of the children of a node corresponds to the order of the symbols in the right-hand side of the production rule used to replace the node's label.
  - The concatenation of the leaf nodes from left to right gives the derived string.
- A derivation tree can be either leftmost or rightmost, depending on whether the leftmost or the rightmost non-terminal symbol is replaced at each step.
- A CFG is said to be ambiguous if there exists more than one derivation tree for the same string, i.e., more than one leftmost or rightmost derivation.
- Ambiguity is a property of grammars, not languages. There can be multiple grammars for the same language, where some are ambiguous and some are not.
- Some languages are inherently ambiguous, meaning that there are no unambiguous grammars for them.
- Ambiguity can cause problems in parsing and interpretation of the strings generated by a CFG, as different derivation trees may imply different meanings or structures for the same string.
- An example of an ambiguous CFG is:

  ```
  S -> aSb | bSa | SS | e
  ```

  This CFG generates the language of all strings of a's and b's with equal number of a's and b's. However, it is ambiguous, as the string `abab` has two different derivation trees:

  ```
       S              S
      / \            / \
     S   S          S   S
    / \ / \        / \ / \
   a  S b e      e a  S b
      |              |
      e              e
  ```

  The leftmost derivation corresponding to the left tree is:

  ```
  S -> SS -> aSbS -> aSeS -> aSeb -> aSebe -> abab
  ```

  The leftmost derivation corresponding to the right tree is:

  ```
  S -> SS -> SeS -> SeaS -> SeaSb -> SeaeSb -> abab
  ```
