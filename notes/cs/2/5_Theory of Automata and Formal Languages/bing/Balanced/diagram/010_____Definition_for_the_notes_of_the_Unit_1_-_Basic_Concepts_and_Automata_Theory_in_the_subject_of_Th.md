### Definition

- An **alphabet** is a finite set of symbols, usually denoted by Σ.
- A **string** or **word** is a finite sequence of symbols from an alphabet, usually denoted by w, x, y, z.
- The **length** of a string is the number of symbols in it, usually denoted by |w|.
- The **empty string** is the string of length zero, usually denoted by ε or λ.
- A **language** is a set of strings over an alphabet, usually denoted by L, M, N.
- A **concatenation** of two strings is the string obtained by appending the second string to the first, usually denoted by w.x or wx.
- A **concatenation** of two languages is the language obtained by concatenating every string from the first language with every string from the second language, usually denoted by L.M or LM.
- A **power** of a string is the string obtained by repeating it a certain number of times, usually denoted by w^n, where n is a non-negative integer.
- A **power** of a language is the language obtained by taking the power of every string in it, usually denoted by L^n, where n is a non-negative integer.
- A **Kleene star** of a language is the language obtained by taking the union of all the powers of the language, usually denoted by L*.
- A **Kleene plus** of a language is the language obtained by taking the union of all the positive powers of the language, usually denoted by L+.
- A **reverse** of a string is the string obtained by reversing the order of its symbols, usually denoted by w^R.
- A **reverse** of a language is the language obtained by reversing every string in it, usually denoted by L^R.
- A **prefix** of a string is a string that is obtained by removing zero or more symbols from the right end of the string.
- A **suffix** of a string is a string that is obtained by removing zero or more symbols from the left end of the string.
- A **substring** of a string is a string that is obtained by removing zero or more symbols from both ends of the string.
- A **subsequence** of a string is a string that is obtained by removing zero or more symbols from anywhere in the string.
- A **finite automaton** is a mathematical model of computation that consists of a finite set of states, a finite set of input symbols, a transition function that maps a state and an input symbol to a state, an initial state, and a set of final or accepting states.
- A **deterministic finite automaton (DFA)** is a finite automaton that has at most one transition for each state and input symbol, and no transitions for the empty string.
- A **nondeterministic finite automaton (NFA)** is a finite automaton that may have more than one transition for each state and input symbol, and may have transitions for the empty string.
- A **regular expression** is a notation for describing a language using symbols, concatenation, union, and Kleene star.
- A **regular language** is a language that can be described by a regular expression, or equivalently, recognized by a finite automaton.
