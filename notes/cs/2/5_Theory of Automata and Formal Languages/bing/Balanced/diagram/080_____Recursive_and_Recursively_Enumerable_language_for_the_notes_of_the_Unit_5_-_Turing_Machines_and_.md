### Recursive and Recursively Enumerable Languages

- A **recursive language** is a formal language for which there exists a Turing machine (or other computable function) that will halt and accept when presented with any string in the language as input and will halt and reject when presented with any string not in the language as input   .
- A **recursively enumerable language** is a formal language for which there exists a Turing machine (or other computable function) that will halt and accept when presented with any string in the language as input but may either halt and reject or loop forever when presented with a string not in the language as input   .
- A recursive language is also recursively enumerable, but the converse is not true   .
- A recursively enumerable language is also called a **semi-decidable language** or a **Turing-recognizable language**   .
- A recursive language is also called a **decidable language** or a **Turing-decidable language**   .
- A language is recursively enumerable if and only if there exists an enumeration procedure for it, that is, a procedure that can generate all the strings in the language in some order  .
- A language is recursive if and only if there exists a decision procedure for it, that is, a procedure that can determine whether any given string belongs to the language or not in a finite amount of time  .
- A language is recursive if and only if it is both recursively enumerable and co-recursively enumerable, that is, both the language and its complement are recursively enumerable  .
- A language is co-recursively enumerable if and only if its complement is recursively enumerable  .
- A language is recursive if and only if it is accepted by a **total Turing machine**, that is, a Turing machine that halts on every input  .
- A language is recursively enumerable if and only if it is accepted by a **partial Turing machine**, that is, a Turing machine that may or may not halt on every input  .
- A language is recursive if and only if it is accepted by a **deterministic Turing machine**, that is, a Turing machine that has at most one possible move for any given configuration  .
- A language is recursively enumerable if and only if it is accepted by a **non-deterministic Turing machine**, that is, a Turing machine that may have more than one possible move for any given configuration  .
