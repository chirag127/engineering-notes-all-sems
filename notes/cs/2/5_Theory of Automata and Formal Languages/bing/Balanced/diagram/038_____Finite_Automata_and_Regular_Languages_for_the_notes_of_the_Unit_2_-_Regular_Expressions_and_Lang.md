### Finite Automata and Regular Languages

- A **regular language** is a set of strings that can be described by a simple pattern or rule. For example, the set of all binary strings that end with 0 is a regular language.
- A **finite automaton** is a mathematical model of a machine that can process strings and accept or reject them based on some criteria. A finite automaton has a finite number of states and transitions between them, and can read one symbol of the input string at a time.
- Finite automata and regular expressions are different ways to represent regular languages. A **regular expression** is a symbolic notation that uses operators like concatenation, union, and star to define a regular language. For example, the regular expression 0(0 + 1)*0 defines the same language as above.

- There are two types of finite automata: **deterministic** and **nondeterministic**. A deterministic finite automaton (DFA) has exactly one transition for each state and symbol, and can be in only one state at a time. A nondeterministic finite automaton (NFA) can have multiple transitions for the same state and symbol, and can be in more than one state at a time.
- Every NFA can be converted to an equivalent DFA using the **subset construction** algorithm, which creates a new state for each possible subset of states of the NFA. The equivalence of regular expressions and finite automata is known as **Kleene's theorem** (after American mathematician Stephen Cole Kleene).
- In the **Chomsky hierarchy**, regular languages are the languages generated by **Type-3 grammars**, which are the simplest and most restricted type of grammars. A grammar is a set of rules that describe how to generate strings from a set of symbols. A Type-3 grammar has rules of the form A -> a or A -> aB, where A and B are variables and a is a terminal symbol.
- Regular languages and finite automata can model computational problems that require a very small amount of memory. For example, a finite automaton can generate a regular language to describe if a light switch is on or off, but it cannot keep track of how many times the light was switched on or off.
