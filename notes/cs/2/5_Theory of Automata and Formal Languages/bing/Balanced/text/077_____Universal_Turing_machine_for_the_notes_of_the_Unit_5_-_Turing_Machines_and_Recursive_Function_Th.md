### Universal Turing machine

- A universal Turing machine (UTM) is a Turing machine that can simulate any other Turing machine on any input.
- A UTM has a special tape that contains both the description of the machine to be simulated and the input to that machine .
- A UTM can also compute everything that a real computer can compute.
- A UTM was introduced by Alan Turing in 1936-1937 as a mathematical tool to investigate the extent and limitations of computability.
- A UTM can recognize undecidable propositions, which are those mathematical statements that cannot be shown to be either true or false within a given formal system.
- A UTM can be constructed from any Turing-complete model of computation, such as a lambda calculus or a register machine.
- A UTM is not a practical device, but a theoretical model that helps us understand the nature and power of computation.
