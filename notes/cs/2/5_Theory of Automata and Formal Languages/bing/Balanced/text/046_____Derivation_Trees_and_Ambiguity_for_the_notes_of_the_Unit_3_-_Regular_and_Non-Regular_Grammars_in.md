### Derivation Trees and Ambiguity

- A derivation tree or parse tree is a graphical representation of the derivation of a string by a context-free grammar.
- A derivation tree shows how the start symbol of the grammar generates the string by applying the production rules in a hierarchical manner.
- A derivation tree has the following properties:
  - The root node is labeled with the start symbol of the grammar.
  - The internal nodes are labeled with the non-terminal symbols of the grammar.
  - The leaf nodes are labeled with the terminal symbols or # (empty string) of the grammar.
  - The yield of the tree is the string obtained by concatenating the labels of the leaf nodes from left to right.
  - The height of the tree is the length of the longest path from the root to a leaf node.
- A derivation tree can be obtained from a leftmost derivation or a rightmost derivation of the string by the grammar.
  - A leftmost derivation is a derivation where the leftmost non-terminal symbol in each step is replaced by the right-hand side of a production rule.
  - A rightmost derivation is a derivation where the rightmost non-terminal symbol in each step is replaced by the right-hand side of a production rule.
- A context-free grammar is said to be ambiguous if there exists more than one derivation tree for the same string generated by the grammar.
  - Ambiguity is a property of grammars, not languages. There can be multiple grammars for the same language, where some are ambiguous and some are not.
  - Some languages are inherently ambiguous, meaning that there are no unambiguous grammars for them.
  - Ambiguity can cause problems in parsing and interpretation of the strings, as different derivation trees may imply different meanings or structures.
- An example of an ambiguous grammar is:

  - S -> aSb | bSa | SS | e
  - This grammar generates the language L = {w | w has equal number of a's and b's}
  - The string abab can be derived by this grammar in two different ways, as shown by the following derivation trees:

```
    S                S
   / \              / \
  S   S            S   S
 / \ / \          / \ / \
a  S b S         a  S b S
   |   |            |   |
   e   e            b   a
```

- To remove ambiguity from a grammar, one can try to rewrite the production rules to avoid multiple ways of deriving the same string, or use additional mechanisms such as precedence and associativity of operators to resolve the conflicts.
