### Derivations for the notes of the Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

- A **derivation** is a process of generating a string from a grammar by applying production rules.
- A **regular grammar** is a grammar that can generate only regular languages, which are languages that can be recognized by finite automata.
- A **non-regular grammar** is a grammar that can generate some non-regular languages, which are languages that cannot be recognized by finite automata.
- There are two types of regular grammars: **left-regular** and **right-regular**. A left-regular grammar has production rules of the form A -> aB or A -> a, where A and B are non-terminals and a is a terminal. A right-regular grammar has production rules of the form A -> Ba or A -> a, where A and B are non-terminals and a is a terminal.
- A **derivation tree** is a graphical representation of a derivation, where the root node is the start symbol, the internal nodes are non-terminals, and the leaves are terminals. The order of the children of a node corresponds to the order of the symbols in the production rule applied to that node.
- A **leftmost derivation** is a derivation where at each step, the leftmost non-terminal is replaced by a production rule. A **rightmost derivation** is a derivation where at each step, the rightmost non-terminal is replaced by a production rule.
- A **sentential form** is a string of terminals and non-terminals that can be derived from the start symbol. A **sentence** is a string of terminals that can be derived from the start symbol.
- A **language** is a set of sentences that can be derived from a grammar. A **regular language** is a language that can be derived from a regular grammar.
- There is a correspondence between regular grammars and finite automata. For every regular grammar, there exists a finite automaton that recognizes the same language, and vice versa. The conversion from a regular grammar to a finite automaton can be done as follows:
  - For a left-regular grammar, create a state for each non-terminal, and an additional final state. The initial state is the state corresponding to the start symbol. For each production rule of the form A -> aB, create a transition from state A to state B labeled with a. For each production rule of the form A -> a, create a transition from state A to the final state labeled with a. Mark the final state as accepting.
  - For a right-regular grammar, create a state for each non-terminal, and an additional initial state. The final state is the state corresponding to the start symbol. For each production rule of the form A -> Ba, create a transition from state B to state A labeled with a. For each production rule of the form A -> a, create a transition from the initial state to state A labeled with a. Mark the initial state as accepting.
- A **derivative** of a regular expression with respect to a symbol is a regular expression that describes the language obtained by removing the symbol from the beginning of every string in the original language. For example, the derivative of (a+b)* with respect to a is b*, since b* is the language of all strings that can be obtained by removing a from the beginning of any string in (a+b)*. The derivative of a regular expression can be computed by applying some rules based on the structure of the expression. For example, the derivative of R+S with respect to a is the derivative of R with respect to a plus the derivative of S with respect to a.
- A **Brzozowski derivative** of a regular expression with respect to a string is a regular expression that describes the language obtained by removing the string from the beginning of every string in the original language. For example, the Brzozowski derivative of (a+b)* with respect to ab is (a+b)*, since (a+b)* is the language of all strings that can be obtained by removing ab from the beginning of any string in (a+b)*. The Brzozowski derivative of a regular expression with respect to a string can be computed by applying the derivative operation repeatedly for each symbol in the string. For example, the Brzozowski derivative of R with respect to abc is the derivative of the derivative of the derivative of R with respect to a, b, and c, respectively.
