### Languages

- In automata theory, a formal language is a set of strings of symbols drawn from a finite alphabet .
- A formal language can be specified either by a set of rules (such as regular expressions or a context-free grammar) that generates the language, or by a formal machine that accepts (recognizes) the language .
- A word is a finite string of symbols from the alphabet.
- A language is a set of words, which may be finite or infinite.
- A language is said to be regular if it can be defined by a regular expression or recognized by a finite automaton .
- A language is said to be non-regular if it cannot be defined by a regular expression or recognized by a finite automaton .
- Examples of regular languages are:
  - The empty language, which contains no words.
  - The language containing only the empty word, which is the word of length zero.
  - The language containing all words over a given alphabet.
  - The language containing all words that start with a given symbol.
  - The language containing all words that end with a given symbol.
  - The language containing all words that have an even number of symbols.
- Examples of non-regular languages are:
  - The language containing all words that have an equal number of a's and b's.
  - The language containing all words that are palindromes, i.e., words that are the same when read backwards.
  - The language containing all words that have the form a^n b^n, where n is a positive integer.
  - The language containing all words that are valid arithmetic expressions with balanced parentheses.
