## Unit 5 - Turing Machines and Recursive Function Theory

- A Turing machine is a simple abstract computational device that can simulate any algorithm.
- A Turing machine consists of a finite set of states, a finite alphabet of symbols, a tape that can store symbols, and a read-write head that can move along the tape and change the symbols .
- A Turing machine can accept or reject an input string by reaching a special state called the accept or reject state, respectively.
- A Turing machine can also halt or loop on an input string, depending on whether it ever reaches a final state or not.
- A Turing machine can be deterministic or nondeterministic, depending on whether it has a unique or multiple possible transitions for each state and symbol combination.
- A Turing machine can be used to accept recursive enumerable languages, which are the languages generated by type-0 grammars.
- A recursive enumerable language is also called a Turing-recognizable language, because it can be recognized by some Turing machine.
- A recursive language is a special case of a recursive enumerable language, which can be accepted by some Turing machine that always halts on any input.
- A recursive language is also called a Turing-decidable language, because it can be decided by some Turing machine.
- A recursive function is a function from natural numbers to natural numbers that can be computed by some Turing machine.
- A recursive function is also called a Turing-computable function, because it can be computed by some Turing machine.
- A recursive function can be defined by using primitive recursion, which is a way of constructing new functions from simpler ones using a base case and a recursive step.
- A recursive function can also be defined by using the μ-operator, which is a way of finding the smallest natural number that satisfies a given property.
- The theory of Turing machines and the theory of recursive functions are equivalent, because they can both capture the notion of effective computability.
- The Church-Turing thesis is a conjecture that states that any function that can be effectively computed by a human using a finite set of rules and resources can also be computed by some Turing machine.
- The Church-Turing thesis is not a formal theorem, but a philosophical claim that is widely accepted by the computer science community.
- The Church-Turing thesis has several variations and extensions, such as the physical Church-Turing thesis, the quantum Church-Turing thesis, and the hypercomputation hypothesis.
