### Definition for the notes of the Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

- A **grammar** is a set of rules that describe how to generate strings from a given alphabet.
- A **regular grammar** is a grammar that can be expressed by a regular expression or a finite automaton. It has the following form:

  - G = (V, T, S, P) where
    - V is a finite set of variables or non-terminals
    - T is a finite set of terminals or symbols
    - S is a special variable called the start symbol
    - P is a finite set of production rules of the form A -> a or A -> aB, where A and B are variables and a is a terminal
- A **non-regular grammar** is a grammar that cannot be expressed by a regular expression or a finite automaton. It has more complex production rules than a regular grammar, such as A -> aA, A -> aBb, or A -> BC, where A, B, and C are variables and a and b are terminals.
- A **language** is a set of strings that can be generated by a grammar.
- A **regular language** is a language that can be generated by a regular grammar.
- A **non-regular language** is a language that cannot be generated by a regular grammar.
