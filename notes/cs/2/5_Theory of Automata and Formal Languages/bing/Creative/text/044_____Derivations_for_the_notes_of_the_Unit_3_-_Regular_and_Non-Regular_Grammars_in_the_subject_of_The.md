### Derivations for the notes of the Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

- A **grammar** is a set of rules that describe how to generate strings from a given alphabet.
- A **derivation** is the process of applying the rules of a grammar to produce a string.
- A **regular grammar** is a grammar that has rules of the form A -> aB or A -> a, where A and B are non-terminals and a is a terminal symbol.
- A **non-regular grammar** is a grammar that has rules that are not of the form A -> aB or A -> a, such as A -> aA or A -> aBb.
- A **regular language** is a language that can be generated by a regular grammar.
- A **non-regular language** is a language that cannot be generated by a regular grammar.
- A **regular expression** is a notation that can describe a regular language using symbols such as concatenation, union, and Kleene star.
- A **finite automaton** is a mathematical model of computation that can recognize a regular language by reading an input string and changing its state according to a transition function.
- A **derivative** of a regular expression with respect to a symbol is a new regular expression that describes the language of the suffixes that can follow the symbol in the original language.
- A **derivation tree** is a graphical representation of a derivation that shows the structure of the string and the rules that are applied.

Some examples of derivations and derivation trees are:

- Given the regular grammar G = ({S, A}, {a, b}, S, {S -> aA, S -> b, A -> aS, A -> bA}), we can derive the string "aab" as follows:

S -> aA -> aaS -> aab

- Given the non-regular grammar G = ({S, A}, {a, b}, S, {S -> aS, S -> bA, A -> aA, A -> b}), we can derive the string "aab" as follows:

S -> aS -> aaS -> aabA -> aab

The derivation tree for this string is:

![Derivation tree for aab](https://i.stack.imgur.com/9f7yE.png)

- Given the regular expression (a|b)*abb, we can find the derivative with respect to a as follows:

D(a, (a|b)*abb) = D(a, (a|b)*)D(a, abb) = (a|b)*D(a, abb) = (a|b)*bb

The derivative with respect to a describes the language of the strings that can follow an a in the original language, such as "abb", "bab", "babb", etc.

- Given the finite automaton that recognizes the language (a|b)*abb, we can find the transition function as follows:

![Finite automaton for (a|b)*abb](https://i.stack.imgur.com/0w0fE.png)

delta(q0, a) = q1
delta(q0, b) = q0
delta(q1, a) = q1
delta(q1, b) = q2
delta(q2, a) = q1
delta(q2, b) = q3
delta(q3, a) = q1
delta(q3, b) = q0

The transition function describes how the state of the automaton changes when reading a symbol from the input string. For example, if the automaton is in state q0 and reads an a, it goes to state q1. If it is in state q2 and reads a b, it goes to state q3.
