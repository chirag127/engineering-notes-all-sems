## Unit 1 - Basic Concepts and Automata Theory

- This unit introduces the fundamental concepts and models of computation, such as alphabets, strings, languages, grammars, automata, and Turing machines.
- It also covers the basic properties and limitations of these models, such as decidability, undecidability, and complexity classes.
- The main topics covered in this unit are:

  - **Alphabets and Strings**: An alphabet is a finite set of symbols, such as {0, 1} or {a, b, c, ... , z}. A string is a finite sequence of symbols from an alphabet, such as 0101 or hello. The length of a string is the number of symbols in it, denoted by |s|. The empty string is the string of length zero, denoted by ε. The set of all strings over an alphabet Σ is denoted by Σ*.
  - **Languages and Grammars**: A language is a set of strings over an alphabet, such as {0, 1}* or {a^n b^n | n ≥ 0}. A grammar is a set of rules that generate a language, such as S → aSb | ε. A grammar is said to be formal if it has a precise syntax and semantics, such as a context-free grammar or a regular grammar.
  - **Finite Automata**: A finite automaton is a mathematical model of a machine that has a finite number of states and transitions between them, and can accept or reject an input string based on its final state. A finite automaton can be deterministic (DFA) or nondeterministic (NFA), and can be represented by a state diagram or a transition table. A finite automaton can recognize a regular language, which is a language that can be described by a regular expression or a regular grammar.
  - **Pushdown Automata**: A pushdown automaton is an extension of a finite automaton that has a stack, which is a data structure that can store and retrieve symbols in a last-in first-out (LIFO) manner. A pushdown automaton can perform a push or a pop operation on the stack along with a state transition. A pushdown automaton can be deterministic (DPDA) or nondeterministic (NPDA), and can recognize a context-free language, which is a language that can be described by a context-free grammar.
  - **Turing Machines**: A Turing machine is a generalization of a finite automaton that has an infinite tape, which is a memory device that can store and manipulate symbols in a read-write manner. A Turing machine can move its tape head left or right along the tape, and can change the symbol under the tape head. A Turing machine can be deterministic (DTM) or nondeterministic (NTM), and can recognize a recursively enumerable language, which is a language that can be generated by a Turing machine. A Turing machine can also decide a decidable language, which is a language that can be accepted or rejected by a Turing machine in a finite amount of time.
  - **Decidability and Undecidability**: A problem is said to be decidable if there exists a Turing machine that can decide it, that is, give a yes or no answer for any input in a finite amount of time. A problem is said to be undecidable if there does not exist such a Turing machine, that is, no algorithm can solve it for all inputs. Examples of decidable problems are the halting problem for finite automata, the emptiness problem for context-free languages, and the membership problem for regular languages. Examples of undecidable problems are the halting problem for Turing machines, the equivalence problem for context-free languages, and the Post correspondence problem.
  - **Complexity Classes**: A complexity class is a set of problems that have similar resource requirements, such as time or space, for their solution. The most common complexity classes are P, NP, NP-complete, and NP-hard. P is the class of problems that can be solved by a deterministic Turing machine in polynomial time, that is, in time O(n^k) for some constant k, where n is the size of the input.
