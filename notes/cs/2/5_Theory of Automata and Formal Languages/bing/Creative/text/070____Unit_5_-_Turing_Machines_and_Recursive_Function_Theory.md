## Unit 5 - Turing Machines and Recursive Function Theory

- A Turing machine is a simple abstract computational device that can simulate any algorithm.
- A Turing machine consists of a finite set of states, a finite alphabet of symbols, a tape that can store symbols, and a read-write head that can move along the tape and change the symbols .
- A Turing machine can accept or reject an input string by reaching a special state, or it can loop forever.
- A Turing machine can be deterministic or nondeterministic, depending on whether it has a unique or multiple possible transitions for each state and symbol combination.
- A Turing machine can be universal, meaning that it can simulate any other Turing machine, given a suitable encoding of its description and input.
- A language is recursively enumerable (RE) if there is a Turing machine that accepts all and only the strings in the language .
- A language is recursive (or decidable) if there is a Turing machine that accepts all and only the strings in the language and halts on every input .
- A function from natural numbers to natural numbers is computable (or recursive) if there is a Turing machine that, on input n, halts and returns output f(n).
- The Church-Turing thesis states that any function that can be effectively computed by a human or a mechanical device can also be computed by a Turing machine.
- The theory of Turing machines and the theory of recursive functions are equivalent, as they can both express the same class of computable functions.
- The theory of computability studies the limitations and capabilities of Turing machines and recursive functions, as well as other models of computation.
