### Recursive and Recursively Enumerable Language

- A **recursive language** is a formal language that can be **decided** by a Turing machine, i.e., there exists a Turing machine that will **halt and accept** when presented with any string in the language as input, and will **halt and reject** when presented with any string not in the language as input .
- A **recursively enumerable language** is a formal language that can be **recognized** by a Turing machine, i.e., there exists a Turing machine that will **halt and accept** when presented with any string in the language as input, but may either **halt and reject** or **loop forever** when presented with any string not in the language as input  .
- A recursively enumerable language is also a **recursively enumerable subset** in the set of all possible words over the alphabet of the language, i.e., there exists a Turing machine (or other computable function) that will **enumerate** all valid strings of the language in some order.
- Every recursive language is also recursively enumerable, but not every recursively enumerable language is recursive .
- A language is **not recursively enumerable** if there is no Turing machine that can recognize it, i.e., for every Turing machine, it will either **reject or loop forever** for some string in the language as input.
- Some examples of recursive languages are: the language of all palindromes over a binary alphabet, the language of all even-length strings over a binary alphabet, the language of all strings over a binary alphabet that are divisible by 3 when interpreted as binary numbers.
- Some examples of recursively enumerable languages that are not recursive are: the language of all strings over a binary alphabet that encode a valid Turing machine, the language of all strings over a binary alphabet that encode a valid Turing machine that halts on the empty input, the language of all strings over a binary alphabet that encode a valid Turing machine that accepts itself as input.
- Some examples of languages that are not recursively enumerable are: the language of all strings over a binary alphabet that encode a valid Turing machine that does not accept itself as input, the language of all strings over a binary alphabet that encode a valid Turing machine that halts on every input, the language of all strings over a binary alphabet that are not divisible by 3 when interpreted as binary numbers.
