### Language Acceptability of Turing Machines

- A Turing machine (TM) is a mathematical model of computation that can perform any algorithmic task by reading and writing symbols on an infinite tape.
- A TM accepts a language if it enters into a final state for any input string w that belongs to the language .
- A language is recursively enumerable (RE) if it is accepted by a TM . RE languages are also called semi-decidable or recognizable languages.
- A TM decides a language if it accepts it and enters into a rejecting state for any input not in the language . A TM that decides a language is also called a decider or a halting TM.
- A language is recursive if it is decided by a TM . Recursive languages are also called decidable or computable languages.
- A language is Turing-acceptable if some TM accepts it. Turing-acceptable languages are equivalent to RE languages.
- A language is Turing-decidable if some TM decides it. Turing-decidable languages are equivalent to recursive languages.
