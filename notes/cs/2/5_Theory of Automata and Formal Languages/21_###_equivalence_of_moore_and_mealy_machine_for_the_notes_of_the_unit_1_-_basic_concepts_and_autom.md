Moore and Mealy machines are two types of finite state machines that are used to model sequential circuits. The main difference between these two types of machines is the way in which the output of the machine is determined.

In a Moore machine, the output of the machine is determined by the current state of the machine, and does not depend on the input. In a Mealy machine, the output of the machine depends on both the current state of the machine and the input.

It is possible to convert a Mealy machine into a Moore machine and vice versa. This conversion process is known as the equivalence of Moore and Mealy machines.
