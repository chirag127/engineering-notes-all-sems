### Moore Machine for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

A Moore machine is a type of finite state machine that is used to model sequential circuits. In a Moore machine, the output of the machine is determined by the current state of the machine, and does not depend on the input.

A Moore machine is defined by a 6-tuple (Q, Σ, δ, q0, F, λ), where:

1. Q is a finite set of states
2. Σ is a finite set of symbols, called the input alphabet
3. δ is a transition function, which maps a state and an input symbol to a new state
4. q0 is the initial state
5. F is a set of final states, which are the states that indicate a successful pattern match
6. λ is an output function, which maps a state to an output symbol

Moore machines are used to model sequential circuits, which are circuits that are composed of interconnected components, such as flip-flops and gates, that store and manipulate information over time.
