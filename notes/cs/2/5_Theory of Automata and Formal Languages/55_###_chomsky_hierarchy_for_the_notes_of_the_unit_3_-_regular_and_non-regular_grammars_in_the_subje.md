### Chomsky Hierarchy for the notes of the Unit 3 - Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages

The Chomsky Hierarchy is a classification of formal languages into four types, based on the complexity of the grammar used to generate the language. The Chomsky Hierarchy is named after Noam Chomsky, who first proposed the classification in the 1950s.

The four types of languages in the Chomsky Hierarchy are:

1. Type 0 languages (unrestricted grammars): languages generated by Turing machines, which are the most general type of language.
2. Type 1 languages (context-sensitive grammars): languages generated by context-sensitive grammars, which are less general than type 0 languages.
3. Type 2 languages (context-free grammars): languages generated by context-free grammars, which are less general than type 1 languages.
4. Type 3 languages (regular grammars): languages generated by regular grammars, which are the least general type of language.
