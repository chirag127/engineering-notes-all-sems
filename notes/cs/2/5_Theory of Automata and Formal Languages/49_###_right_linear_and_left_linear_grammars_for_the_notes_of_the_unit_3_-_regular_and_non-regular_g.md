A right linear grammar is a type of grammar in which each production rule has the form A → aB, where A and B are non-terminal symbols and a is a terminal symbol. This means that each production rule generates a string that is a concatenation of a terminal symbol followed by a non-terminal symbol.

A left linear grammar is a type of grammar in which each production rule has the form A → Ba, where A and B are non-terminal symbols and a is a terminal symbol. This means that each production rule generates a string that is a concatenation of a non-terminal symbol followed by a terminal symbol.
