### String

A string is a sequence of characters or symbols from an alphabet. In formal language theory, strings play a crucial role in the definition and analysis of formal languages. Here are some important concepts related to strings:

1. **Alphabet:** An alphabet is a finite set of symbols or characters. For example, the English alphabet consists of 26 letters.

2. **String Length:** The length of a string is the number of symbols or characters it contains. It is denoted by |s|, where s is a string.

3. **Empty String:** An empty string is a string with length 0. It is denoted by ε.

4. **Concatenation:** Concatenation is the operation of joining two or more strings to form a new string. It is denoted by the symbol •. For example, if s1 = "hello" and s2 = "world", then s1 • s2 = "helloworld".

5. **Substring:** A substring is a contiguous sequence of characters in a string. For example, if s = "hello", then "el" is a substring of s.

6. **Prefix and Suffix:** A prefix of a string is a substring that appears at the beginning of the string. A suffix of a string is a substring that appears at the end of the string.

7. **Language:** A language is a set of strings over a given alphabet. For example, the English language is a set of strings over the English alphabet.

8. **Regular Expression:** A regular expression is a pattern that describes a set of strings. It can be used to specify a language. For example, the regular expression "a*b" matches strings that have any number of "a"s followed by a single "b".

9. **Finite Automaton:** A finite automaton is a mathematical model of a machine that can recognize a language. It consists of a finite set of states, a set of input symbols, a transition function, a start state, and a set of accepting states. The automaton reads input symbols and transitions from one state to another until it reaches an accepting state.

In summary, strings are a fundamental concept in formal language theory. They are used to represent language and to define operations on languages such as concatenation and regular expressions. Finite automata can recognize and generate strings, making them a powerful tool in the study of formal languages.
