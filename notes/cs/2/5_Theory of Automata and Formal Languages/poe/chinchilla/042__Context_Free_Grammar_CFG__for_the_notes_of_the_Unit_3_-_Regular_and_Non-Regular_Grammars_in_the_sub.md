### Context Free Grammar(CFG)

Context Free Grammar (CFG) is a formal grammar used to describe the structure of programming languages, natural languages, and other formal languages. It is a type of formal grammar that consists of a set of rules called productions, which describe how to generate strings of symbols in the language. CFG is a powerful tool in the field of computer science, and it is widely used in compiler design, natural language processing, and artificial intelligence.

#### Definition

- A Context Free Grammar consists of four elements: 
    1. A set of non-terminal symbols.
    2. A set of terminal symbols.
    3. A start symbol.
    4. A set of production rules.

- The non-terminal symbols are symbols that can be replaced by other symbols or sequences of symbols.

- The terminal symbols are symbols that cannot be replaced any further.

- The start symbol is the symbol from which the grammar starts generating strings.

- The production rules are the rules that define how the non-terminal symbols can be replaced by other symbols or sequences of symbols.

#### Example

Let's take an example to understand the CFG. Consider the following grammar:

S -> aSb | ε

Here, S is the start symbol, a and b are the terminal symbols, and ε denotes the empty string. The production rules say that S can be replaced by either "aSb" or the empty string.

Using this grammar, we can generate strings like:

- ε
- ab
- aabb
- aaabbb
- aaaabbbb

#### Properties

- CFG is more powerful than Regular Grammar, and it can generate languages that Regular Grammar cannot.

- CFG can generate languages that are not context-free.

- Any regular language can be generated by a CFG.

- The language generated by a CFG is always context-free.

- Parsing a string generated by a CFG is an NP-hard problem.

#### Applications

- CFG is widely used in compiler design to generate the syntax of programming languages.

- CFG is used in natural language processing to generate and analyze sentences in natural languages.

- CFG is used in artificial intelligence to generate and analyze various formal languages.
