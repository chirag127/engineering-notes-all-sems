

### Programming Problems Based on the Properties of CFGs

In this unit, we will be discussing the Regular and Non-Regular Grammars in the subject of Theory of Automata and Formal Languages. Here are some programming problems based on the properties of CFGs to help you understand the concepts better:

1. Write a program in Python to determine whether a given CFG is regular or not.

2. Write a program in C++ to convert a regular grammar into an equivalent DFA.

3. Write a program in Java to convert a given NFA into an equivalent CFG.

4. Write a program in Python to generate strings from a given CFG.

5. Write a program in C++ to determine whether a given string can be generated from a given CFG or not.

6. Write a program in Java to minimize a given CFG.

7. Write a program in Python to convert a given CFG into Chomsky Normal Form.

8. Write a program in C++ to determine whether a given CFG is ambiguous or not.

9. Write a program in Java to generate a grammar for a given language.

10. Write a program in Python to determine whether a given grammar is context-free or not.

These programming problems will help you gain a deeper understanding of the properties of CFGs and their applications in automata theory. Practice them regularly to ace your exams and become a proficient programmer in this field.
