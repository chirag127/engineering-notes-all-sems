
## Unit 1 - Basic Concepts and Automata Theory

* Automata Theory is a branch of computer science that deals with the study of abstract machines and automata, as well as the computational problems that can be solved using them.
* Automata are abstract models of machines that can be used to solve computational problems.
* Automata can be classified into two types: deterministic and nondeterministic. Deterministic automata are machines that always produce the same output for a given input, while nondeterministic automata are machines that can produce different outputs for the same input.
* Automata can be used to solve a variety of problems, including language recognition, pattern matching, and graph problems.
* Finite Automata are a type of automata that are used to recognize patterns in strings of symbols. Finite automata have a finite number of states and transitions, and can be represented graphically as a directed graph.
* Pushdown Automata are a type of automata that can recognize languages that are not regular. Pushdown automata use a stack to store symbols, and can be represented graphically as a directed graph.
* Turing Machines are a type of automata that can recognize any language that is computable. Turing machines have an infinite number of states and transitions, and can be represented graphically as a Turing machine diagram.
