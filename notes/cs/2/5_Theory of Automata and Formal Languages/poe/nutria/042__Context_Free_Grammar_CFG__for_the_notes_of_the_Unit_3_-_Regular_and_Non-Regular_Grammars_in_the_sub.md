
### Context Free Grammar (CFG)

* A Context Free Grammar (CFG) is a set of rules used to generate strings of symbols from a given language. 
* CFGs are used to describe the structure of a language and are used to define the syntax of a language. 
* CFGs consist of four components: variables, terminals, productions, and start symbol.
* Variables are symbols that represent strings of symbols from the language.
* Terminals are symbols that represent the words of the language.
* Productions are rules that define how the variables can be rewritten in terms of other variables and terminals.
* The start symbol is the variable that is used to start the derivation process.
* CFGs can be used to describe both regular and non-regular languages.
* Regular languages are described by regular grammars, which are CFGs with certain restrictions on the form of the productions.
* Non-regular languages are described by unrestricted CFGs.
