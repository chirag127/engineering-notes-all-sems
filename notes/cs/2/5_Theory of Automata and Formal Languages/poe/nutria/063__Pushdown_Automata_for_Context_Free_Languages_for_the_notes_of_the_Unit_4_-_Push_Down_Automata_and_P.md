

### Pushdown Automata for Context Free Languages

- A Pushdown Automaton (PDA) is a finite-state machine that uses a stack to store and manipulate data. 
- It is used to recognize context-free languages, which are languages generated by context-free grammars. 
- A PDA consists of a finite set of states, a finite set of input symbols, a finite set of stack symbols, a transition function, an initial state, and an initial stack symbol. 
- The transition function takes as input the current state, the symbol read from the input, and the top symbol on the stack. 
- Based on this input, the transition function will either move to another state, push a new symbol on the stack, or pop a symbol off the stack. 
- The PDA will accept an input if the transition function moves to an accepting state after the input is completely read. 
- The language accepted by a PDA is the set of all strings that can be accepted by the PDA. 
- A PDA can recognize a context-free language if and only if the language is generated by a context-free grammar. 
- A context-free language is a language generated by a context-free grammar, which is a set of production rules that specify how strings can be created from symbols. 
- A context-free grammar consists of a set of nonterminal symbols, a set of terminal symbols, a start symbol, and a set of production rules. 
- A production rule consists of a nonterminal symbol followed by a sequence of terminal and nonterminal symbols. 
- The production rules specify how a string can be created from the start symbol. 
- A context-free language is a set of strings generated by the production rules of a context-free grammar. 
- A PDA can be used to recognize a context-free language by simulating the production rules of the context-free grammar.
