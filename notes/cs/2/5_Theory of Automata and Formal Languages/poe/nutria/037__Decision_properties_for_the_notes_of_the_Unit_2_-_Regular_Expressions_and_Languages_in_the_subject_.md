
### Decision Properties for the Notes of the Unit 2 - Regular Expressions and Languages in the Subject of Theory of Automata and Formal Languages

* A language is said to be **decidable** if there exists an algorithm that can determine whether a given string belongs to the language or not.
* A language is said to be **recognizable** if there exists an algorithm that can determine whether a given string belongs to the language or not and halt in a finite time.
* A language is said to be **semi-decidable** if there exists an algorithm that can determine whether a given string belongs to the language or not and halt in a finite time, but may not halt if the string does not belong to the language.
* A language is said to be **recursively enumerable** (or r.e.) if there exists an algorithm that can enumerate all the strings of the language.
* A language is said to be **context-free** if there exists a context-free grammar that generates the language.
* A language is said to be **context-sensitive** if there exists a context-sensitive grammar that generates the language.
* A language is said to be **regular** if there exists a regular expression that generates the language.
