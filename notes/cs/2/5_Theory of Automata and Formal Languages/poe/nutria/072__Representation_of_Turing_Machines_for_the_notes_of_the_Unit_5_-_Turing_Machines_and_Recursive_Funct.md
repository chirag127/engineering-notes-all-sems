
### Representation of Turing Machines

* A Turing Machine is a mathematical model of computation that consists of an infinite memory tape, a head that can read and write symbols and a finite set of instructions. 
* The tape is divided into cells, each of which contains a single symbol from a finite alphabet. 
* The head reads the symbol currently in the cell it is on and follows the instructions associated with that symbol. 
* The instructions tell the head to move left, right, or stay in the same place, and to write a new symbol in the cell it is on. 
* Turing Machines can be used to solve any computable problem, and are a useful tool for studying the theory of computation. 
* Turing Machines can be represented as a state transition diagram, which shows the states of the machine and the transitions between them. 
* The states are represented by circles, and the transitions are represented by arrows. 
* Each arrow is labeled with the symbol that is read and the symbol that is written, as well as the direction the head should move in. 
* The start state is represented by an arrow pointing to it, and the accept state is represented by a double circle. 
* Turing Machines can also be represented as a table, which shows the state, the symbol read, the symbol written, and the direction the head should move in. 
* The table is usually organized into rows, with each row representing a single state. 
* The columns represent the symbols that can be read, and the entries in the table tell the machine what to do when it reads a particular symbol. 
* Recursive Function Theory is a branch of mathematics that studies the properties of functions that can be computed by Turing Machines. 
* It is used to prove theorems about computability, and is an important tool in the study of algorithms and complexity.
