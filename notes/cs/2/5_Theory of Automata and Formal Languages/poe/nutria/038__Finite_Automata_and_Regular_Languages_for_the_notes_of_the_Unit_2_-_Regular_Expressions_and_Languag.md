
### Finite Automata and Regular Languages 

1. A **finite automaton** (FA) is a mathematical model of computation which consists of a finite set of states, a set of input symbols, and a transition function that defines the behavior of the model. 
2. A **regular language** is a set of strings that can be generated by a finite automaton. 
3. A **regular expression** is a notation for describing regular languages. It consists of symbols that represent individual characters, sets of characters, and operators for combining expressions. 
4. A **deterministic finite automaton** (DFA) is a finite automaton that has a unique transition for each input symbol. 
5. A **non-deterministic finite automaton** (NFA) is a finite automaton that has multiple possible transitions for each input symbol. 
6. A **pushdown automaton** (PDA) is a finite automaton that has an additional memory structure called a stack. 
7. The **Myhill-Nerode theorem** is a theorem that provides a characterization of regular languages. It states that two strings are in the same equivalence class of a regular language if and only if they have the same number of transitions when processed by a DFA. 
8. The **Kleene closure** is a concept used in regular expressions which allows for the repetition of a pattern. It is denoted by a star (*) and can be used to match zero or more occurrences of a pattern. 
9. A **minimization algorithm** is an algorithm that is used to minimize the number of states in a finite automaton. 
10. The **regular expression engine** is a program that is used to process regular expressions and generate strings that match the expression.
