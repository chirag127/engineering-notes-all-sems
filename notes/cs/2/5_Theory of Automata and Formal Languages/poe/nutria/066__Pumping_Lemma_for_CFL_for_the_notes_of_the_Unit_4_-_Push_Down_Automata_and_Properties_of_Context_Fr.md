
### Pumping Lemma for CFL

* The pumping lemma for context-free languages (CFL) is a tool used to prove that a language is not context-free. 
* It states that if a language is context-free, then there exists a constant, the so-called "pumping length", such that any string in the language of length greater than or equal to the pumping length can be broken into three parts, and the middle part can be repeated an arbitrary number of times, while still resulting in a string that is also in the language.
* The pumping lemma can also be used to prove that a language is not context-free. If a language is not context-free, then no matter what constant is chosen, there will always be a string in the language that cannot be broken into three parts and repeated an arbitrary number of times while still resulting in a string in the language. 
* This means that if a language is not context-free, then for any constant, there will always be a string in the language for which the pumping lemma fails.
