
### Moves for the Notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the Theory of Automata and Formal Languages

1. Push down automata (PDA) is an automaton that uses a stack to store information while processing an input string.
2. PDA is equivalent to a non-deterministic finite automaton (NFA) with an additional stack storage.
3. A PDA can be thought of as a finite state machine with an infinite memory.
4. The stack of a PDA is used to store symbols that are read from the input.
5. The stack can also be used to store intermediate results of computations.
6. The stack is also used to store the current state of the PDA.
7. The stack is manipulated by a set of instructions called stack operations.
8. A context-free language (CFL) is a language generated by a context-free grammar (CFG).
9. A CFG consists of a set of rules which specify how to generate strings from a given alphabet.
10. CFLs are closed under the operations of union, concatenation, and Kleene star.
11. CFLs are used to describe the syntax of programming languages, natural languages, and other formal languages.
12. The Chomsky hierarchy is a classification of formal languages based on their generative power.
13. CFLs are one of the four classes of languages in the Chomsky hierarchy.
14. The other classes are regular languages, context-sensitive languages, and unrestricted languages.
