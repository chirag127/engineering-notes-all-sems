
### Introduction to Recursive Function Theory 

* Recursive function theory is a branch of mathematical logic that studies the computability of functions and predicates.
* It is closely related to the theory of computation, which studies the power and limitations of computing machines.
* A recursive function is a function that calls itself, either directly or indirectly, and is used to solve complex problems by breaking them down into simpler subproblems.
* Recursive functions can be used to define sets of numbers, such as the Fibonacci sequence and the Ackermann function.
* Recursive functions can also be used to define the syntax and semantics of programming languages.
* The Church-Turing thesis states that any computable function can be computed by a Turing machine.
* Turing machines are abstract machines that can be used to solve any computable problem.
* Turing machines are composed of a finite set of states, a finite set of symbols, and a set of transition rules.
* Turing machines are capable of universal computation, meaning that they can compute any computable function.
* The Halting Problem is an undecidable problem that asks whether a given Turing machine will ever halt.
* The Recursion Theorem states that any set which is definable in terms of a Turing machine is also recursive.
* The Kleene-Rosser Theorem states that any Turing machine can be simulated by a recursive function.
* The Rice Theorem states that any non-trivial property of a Turing machine is undecidable.
