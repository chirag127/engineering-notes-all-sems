### Finite Automata and Regular Languages

- A finite automaton is a mathematical model of a machine which consists of a finite number of states. It can change from one state to another based on a finite number of input symbols.
- A finite automaton is defined by a 5-tuple (Q, Σ, δ, q0, F) where:
- Q is a finite set of states.
- Σ is a finite set of input symbols.
- δ is the transition function which maps Q x Σ to Q.
- q0 is the start state.
- F is a set of accepting or final states.
- A string is accepted by a finite automaton if it causes the automaton to end in an accepting state. The set of all accepted strings forms a regular language.
- Regular languages can be represented using regular expressions which consist of primitive symbols and operators to construct complex expressions.
- Regular languages are the simplest class of languages and are very useful in various applications like lexical analysis, pattern matching, etc.due to their unique properties like closure properties, decidability, etc.
