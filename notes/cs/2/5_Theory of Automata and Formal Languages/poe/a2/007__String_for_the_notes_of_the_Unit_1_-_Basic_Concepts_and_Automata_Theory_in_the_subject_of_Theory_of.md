### String for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1. Automata: Automata is an abstract self-contained device which consumes input symbols from its input tape and changes its state depending upon the input symbol and present state. It produces output symbols on its output tape.
2. Finite Automata: Finite Automata is a 5-tuple (Q, ∑, δ, q0, F) where
- Q is a finite set of states
- ∑ is a finite set of input symbols
- δ is a transition function: Q x ∑ → Q
- q0 ∈ Q is the initial state
- F ⊆ Q is the set of accepting or final states
3. Regular Languages: A language L over an alphabet ∑ is regular if there exists a finite automata which accepts L. Regular languages can be expressed using regular expressions.
4. Chomsky Hierarchy: The Chomsky Hierarchy classifies languages based on the complexity of grammars that can generate them. The levels from least to most complex are:
- Regular Languages: Generated by finite automata
- Context Free Languages: Generated by context-free grammars
- Context Sensitive Languages: Generated by context-sensitive grammars
- Recursively Enumerable Languages: Languages that can be accepted by Turing machines
