### Moves for the notes of the Unit 4 - Push Down Automata and Properties of Context Free Languages in the subject of Theory of Automata and Formal Languages

1. Pushdown Automata:
- A pushdown automaton is a way to implement a context-free grammar in a machine.
- It is a finite state machine equipped with a stack to track nested structures.
- The input is read one symbol at a time and the machine can change state and push/pop symbols from the stack based on the input and top of stack symbol.
- Acceptance is based on the machine reaching an accept state with an empty stack.

2. Properties of Context Free Languages:
- The languages accepted by pushdown automata are exactly the context-free languages.
- The class of context-free languages is closed under union, concatenation, and Kleene star.
- The class of context-free languages is not closed under intersection or complement.
- The pumping lemma can be used to show that a language is not context-free.
- The hierarchy theorem shows that the class of context-sensitive languages strictly contains the context-free languages.

3. Examples of Context Free Languages:
- The set of strings with balanced parentheses.
- The set of strings in which no letter occurs more than n times.
- The set of palindromes over some alphabet.
- The set of strings in which every prefix has at least as many a's as b's.
