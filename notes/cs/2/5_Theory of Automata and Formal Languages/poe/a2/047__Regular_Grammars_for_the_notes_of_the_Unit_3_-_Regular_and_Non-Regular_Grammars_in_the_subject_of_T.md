### Regular Grammars

1. A regular grammar is a type of formal grammar in which every production rule is of the form:
    - A → a
    - A → aB
    - A → aBc
    - where A, B, and C are symbols that represent variables or terminals and a represents a terminal symbol.
2. In a regular grammar, the right-hand side of every production rule contains either a single terminal symbol or two symbols (a variable and a terminal, or two variables).
3. A regular language is a language that can be generated by a regular grammar. Regular languages are the simplest languages in the Chomsky hierarchy.
4. Some examples of regular languages:
    - { anbn | n ≥ 0 } : Strings with equal number of a’s and b’s
    - { anb | n ≥ 0 } : Strings with at least one a
5. Applications of regular languages:
    - Lexical analysis: Breaking input into basic components like identifiers, keywords, literals, etc.
    - Pattern matching: Finding patterns in strings.
