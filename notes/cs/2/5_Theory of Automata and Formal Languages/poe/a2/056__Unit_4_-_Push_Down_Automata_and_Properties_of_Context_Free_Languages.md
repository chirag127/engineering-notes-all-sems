## Unit 4 - Push Down Automata and Properties of Context Free Languages

1. Pushdown Automata: A pushdown automaton is a type of automaton with additional memory called stack. It can push symbols onto the stack and pop symbols from the stack. A PDA decides a language if there exists a set of rules to tell when to push or pop symbols to/from the stack such that the input string is accepted if the PDA halts in an accepting state.

2. Context Free Languages: A context free language is a language that can be generated by a context free grammar. A context free grammar is a set of rules where each rule consists of a single symbol on the left hand side and a string of symbols on the right hand side such that the right hand side contains only a single symbol or terminal symbols or non-terminal symbols.

3. Properties: Some important properties of CFL are:
- The empty string belongs to every CFL.
- The union, concatenation and Kleene closure of any two CFLs results in a CFL.
- The intersection of two CFLs need not be a CFL.
- CFL is a proper subset of RE languages and a superset of regular languages.

4. Examples: Some examples of CFLs are:
- {a^n b^n | n >= 0}
- {ww | w belongs to {a,b}*}
