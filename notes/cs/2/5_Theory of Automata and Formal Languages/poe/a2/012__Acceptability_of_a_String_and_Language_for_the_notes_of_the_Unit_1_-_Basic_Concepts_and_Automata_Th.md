### Acceptability of a String and Language

- A string is said to be acceptable to a finite automaton if the automaton accepts the string when started in the start state and the string is read symbol by symbol.
- A language is said to be acceptable to a finite automaton if the language consists of all strings acceptable to the automaton.
- The set of all strings acceptable to a finite automaton is called the language accepted by the automaton.
- A regular language is a language that is accepted by some finite automaton. The class of all regular languages is denoted by REGULAR.
- The strings of a regular language can be specified by a regular expression. A regular expression is a notation for describing a set of strings.
- The equivalence of finite automata and regular expressions provides two ways of defining and representing regular languages - automata and regular expressions.
