### Post’s Correspondance Problem

- Post’s correspondance problem states that there is a one-to-one correspondance between the set of computable functions and Turing machines.
- In other words, for every Turing machine, there exists an equivalent computable function and vice-versa.
- This means that the power of Turing machines and computable functions is equivalent in terms of the functions they can compute.
- Post’s correspondance helps in establishing Turing machines as the right model of computation as they can compute exactly the set of functions that are intuitively computable.
- The correspondance is constructed by associating a Turing machine to a computable function and vice-versa in a recursive manner.
- Hence, Post’s correspondance problem proves that Turing machines and computable functions are two equivalent ways of defining computability.
