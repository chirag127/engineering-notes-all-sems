### Representation for the notes of the Unit 1 - Basic Concepts and Automata Theory in the subject of Theory of Automata and Formal Languages

1. Alphabet: A finite set of symbols. For example, {a, b, c} or {0, 1}.
2. String: A finite sequence of symbols from an alphabet. For example, aba or 101.
3. Language: A subset of strings from an alphabet. For example, {ww | w is a string containing only a's} is a language.
4. Automaton: A mathematical model of a machine that accepts strings (languages) based on some criteria.
5. Finite Automaton: An automaton with a finite number of states that accepts/rejects strings based on transition function and initial/final states.
6. Transition Function: A function that maps current state and current input symbol to the next state.
7. Accepting/Recognizing: A string is accepted/recognized by an automaton if it causes the automaton to end in an accepting state.
8. Regular Language: A language that can be accepted/recognized by a finite automaton.
9. Regular Expression: A concise representation of a regular language using operators and symbols. Can be converted to a finite automaton and vice versa.
