### Closure properties of CFL

1. Union: If L1 and L2 are context-free languages, then L1 ∪ L2 is also a context-free language.

2. Concatenation: If L1 and L2 are context-free languages, then L1⋅L2 is also a context-free language.

3. Kleene closure: If L is a context-free language, then L* is also a context-free language.

4. Homomorphism: If h is a homomorphism and L is a context-free language, then h(L) is also a context-free language.

5. Intersection with regular set: If L is a context-free language and R is a regular language, then L ∩ R is also a context-free language.

These closure properties allow us to generate more complex context-free languages from simpler context-free languages. This helps in analyzing the accepting power of pushdown automata.
