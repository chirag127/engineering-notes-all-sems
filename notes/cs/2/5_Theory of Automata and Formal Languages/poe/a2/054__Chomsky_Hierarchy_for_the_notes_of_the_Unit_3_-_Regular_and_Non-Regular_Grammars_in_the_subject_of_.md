### Chomsky Hierarchy for the notes of the Unit 3 - Regular and Non-Regular Grammars

1. Regular Grammars:Grammars in which all production rules are of the form:

A → a
A → aB
A → ε

Where A,B are non-terminals and a is a terminal.

These grammars can generate regular languages which can be accepted by finite state automata.

2. Context Free Grammars:Grammars in which production rules are of the form:

A → α

Where A is a non-terminal and α is a string of terminals and non-terminals.

These grammars can generate context free languages which can be accepted by pushdown automata.

3. Context Sensitive Grammars:Grammars in which production rules are of the form:

A → αβ

Where A,α and β are strings of terminals and non-terminals and |α|>0.

These grammars can generate context sensitive languages.

4. Recursive Grammars:Grammars with recursive production rules which can generate recursively enumerable languages.

The Chomsky Hierarchy depicts the inclusion relationship between the languages generated by different types of grammars.

Regular ⊂ Context Free ⊂ Context Sensitive ⊂ Recursive
