### Programming problems based on the properties of CFLs

1. Write a program to check whether a given string is in the language L = {w | w has equal number of a's and b's}.
- Take the input string.
- Count the occurrences of a's and b's in the input string.
- Check if the counts are equal.
- Print "Accepted" if equal else "Rejected".

2. Write a program to check whether a given string is in the language L = {w | w has equal number of 0's and 1's}.
- Take the input string.
- Count the occurrences of 0's and 1's in the input string.
- Check if the counts are equal.
- Print "Accepted" if equal else "Rejected".

3. Write a program to check whether a given string is in the language L = {w | w contains equal number of a's and b's with at least one a and at least one b}.
- Take the input string.
- Count the occurrences of a's and b's in the input string.
- Check if the counts are equal and both are greater than 0.
- Print "Accepted" if the condition is satisfied else "Rejected".
