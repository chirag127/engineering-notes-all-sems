### Context Free grammars for Pushdown Automata

1. A Context Free Grammar (CFG) is a 4-tuple (V, T, P, S) where
- V is a finite set of variables (non-terminals)
- T is a finite set of terminals
- P is a finite set of production rules of the form V → w where V is a variable and w is a string of variables and terminals
- S is the start variable (a variable from V)

2. Languages generated by CFGs are called Context Free Languages (CFLs). They can be recognized by Pushdown Automata (PDA).
3. A PDA is a 7-tuple (Q, Σ, Γ, δ, q0, Z0, F) where
- Q is a finite set of states
- Σ is the input alphabet (set of terminals)
- Γ is the stack alphabet
- δ is the transition function: Q × (Σ ∪ {ε}) × Γ → Q × Γ*
- q0 is the start state
- Z0 is the start stack symbol
- F is the set of accepting states

4. A PDA accepts an input string if there is a sequence of transitions that leads it from the start state-start stack configuration to an accepting state-final stack configuration. The language accepted by a PDA is the set of all input strings it accepts.

5. The PDA accepts a language if the language is generated by some CFG. The PDA simulates the derivations of the CFG. This establishes the equivalence between PDAs and CFGs in terms of the languages they accept/generate.
