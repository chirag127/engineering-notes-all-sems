# Importance of Notes in Unit 2 - Forms of Technical Communication

- Notes are a form of technical communication that provide helpful hints, tips, or additional information that is not essential for the understanding of the main text.
- Notes can help the user work more efficiently, avoid confusion, or clarify a point that might be ambiguous or complex.
- Notes can also be used to document information and communicate it in a concise, precise, and professional way.
- Notes should be distinguished from cautions and warnings, which are used to alert the reader about potential risks, dangers, or consequences of not following the instructions.
- Notes should be written in a clear, consistent, and courteous tone, using simple and direct language.
- Notes should be formatted differently from the main text, using indentation, bullets, numbering, or icons to draw attention and separate them from the rest of the document.
- Notes should be placed close to the relevant text, preferably at the end of a paragraph or section, or in the margin if possible.
- Notes should be used sparingly and only when necessary, as too many notes can distract the reader and reduce the impact of the main message.

Some examples of notes are:

- Note: This feature is only available for premium users.
- Note: For more information, see Chapter 4.
- Note: You can also use the shortcut Ctrl+Z to undo the last action.
