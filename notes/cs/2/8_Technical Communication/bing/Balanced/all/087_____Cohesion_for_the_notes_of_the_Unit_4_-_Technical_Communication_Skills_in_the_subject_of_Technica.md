# Cohesion

- Cohesion is the quality of a text that makes it easy to follow and understand.
- Cohesion is achieved by using various linguistic devices to link the sentences and paragraphs of a text.
- Cohesion helps to create a logical and coherent flow of information and ideas in a text.
- Cohesion is important for effective technical communication, as it helps the audience to grasp the main purpose and message of the text.

## Types of Cohesion

- There are different types of cohesion that can be used in technical communication, such as:
  - Grammatical cohesion: using words and structures that show the grammatical relationship between the elements of a text, such as pronouns, conjunctions, articles, and tense.
  - Lexical cohesion: using words that are related in meaning, such as synonyms, antonyms, hyponyms, collocations, and repetition.
  - Semantic cohesion: using words and expressions that convey the meaning and logic of the text, such as cause and effect, comparison and contrast, and condition and consequence.
  - Metrical cohesion: using words and phrases that create a rhythm and pattern in the text, such as rhyme, alliteration, and parallelism.

## Examples of Cohesion

- Here are some examples of how cohesion can be used in technical communication:

  - Grammatical cohesion: "The software has many features that make it user-friendly. **It** also has a simple and intuitive interface. **This** allows the user to perform various tasks easily and efficiently."
  - Lexical cohesion: "The device is designed to measure the temperature and humidity of the environment. The sensor collects the **data** and sends it to the **display**. The **display** shows the **data** in a graphical format."
  - Semantic cohesion: "To install the software, you need to follow these steps. **First**, download the setup file from the website. **Second**, run the file and follow the instructions. **Third**, restart your computer. **Finally**, launch the software and enjoy its features."
  - Metrical cohesion: "The product is durable, reliable, and affordable. It is suitable for home, office, and travel. It is compatible with various devices and platforms. It is the best choice for your needs."
