### Unit 4 - Technical Communication Skills

#### Style for the notes

1. Use a formal tone and avoid using emojis or informal language.
2. Write the content in markdown format.
3. Use headers to organize the content.
4. Write the content as if it is study material for exams.
5. Present the information in points for easy readability.
6. Do not include external links, instead, write or draw everything yourself.
7. Be concise and to the point.
