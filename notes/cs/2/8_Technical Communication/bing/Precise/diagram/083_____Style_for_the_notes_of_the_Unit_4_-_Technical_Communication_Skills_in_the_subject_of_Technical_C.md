### Unit 4 - Technical Communication Skills

#### Style for the notes

1. The notes should be written in a formal tone.
2. Avoid using emojis or showing feelings or friendliness.
3. The content should be written in markdown format.
4. Do not include external links. Write or draw everything yourself.
5. The content should be written inside a header diagram.
6. Write the content as if it is study material to learn and read from for exams.
7. Write in points for better readability and understanding.
