The following are some of the key terms and concepts that may be covered in the notes for Unit 4 - Graphs:

1. Graph: A graph is a collection of vertices and edges that represent relationships between objects.

2. Vertex: A vertex is a point in a graph that represents an object.

3. Edge: An edge is a line that connects two vertices in a graph, and represents a relationship between the objects represented by the vertices.

4. Adjacency: Adjacency refers to the relationship between two vertices in a graph, where an edge exists between the two vertices.

5. Adjacency Matrix: An adjacency matrix is a matrix representation of a graph, where each row and column represents a vertex, and the entries in the matrix represent the edges between the vertices.

6. Adjacency List: An adjacency list is a list representation of a graph, where each vertex is represented by a list of its adjacent vertices.

7. Graph Traversal: Graph traversal is the process of visiting all the vertices in a graph, and can be performed using depth first search or breadth first search.

8. Depth First Search: Depth first search is a graph traversal algorithm that visits vertices by exploring as far as possible along each branch before backtracking.

9. Breadth First Search: Breadth first search is a graph traversal algorithm that visits vertices by exploring all neighbors of a vertex before moving on to the next vertex.

10. Connected Component: A connected component is a subgraph of a graph that is connected, meaning that there is a path between any two vertices in the subgraph.

11. Spanning Tree: A spanning tree is a tree that spans a graph, meaning that it includes all the vertices of the graph and some of the edges.

12. Minimum Cost Spanning Tree: A minimum cost spanning tree is a spanning tree with the minimum possible total weight of its edges.

13. Prim's Algorithm: Prim's algorithm is a method for finding the minimum cost spanning tree of a graph.

14. Kruskal's Algorithm: Kruskal's algorithm is a method for finding the minimum cost spanning tree of a graph.

15. Transitive Closure: Transitive closure is the process of finding all the vertices that are reachable from a given vertex in a graph.

16. Shortest Path Algorithm: A shortest path algorithm is a method for finding the shortest path between two vertices in a graph.

17. Warshall's Algorithm: Warshall's algorithm is a method for finding the transitive closure of a graph.

18. Dijkstra's Algorithm: Dijkstra's algorithm is a method for finding the shortest path between two vertices in a graph.
