### Concept of Hashing & Collision resolution Techniques used in Hashing

Hashing is a technique of mapping a set of keys to a set of values using a hash function. A hash function is a function that takes a key as input and returns an integer value, called a hash value or a hash code, as output. The hash value is used to index a hash table, which is an array of fixed size that stores the values associated with the keys. The hash table allows for fast and efficient lookup, insertion and deletion of key-value pairs.

However, hashing may encounter a problem called collision, which occurs when two or more keys have the same hash value and map to the same slot in the hash table. Collision reduces the performance of hashing and may cause errors or data loss. Therefore, collision resolution techniques are needed to handle the situation when collision occurs.

There are two main types of collision resolution techniques: open hashing and closed hashing.

- Open hashing, also known as separate chaining, is a technique that uses a linked list to store the values that have the same hash value in the same slot of the hash table. Each slot of the hash table is either empty or contains a pointer to the head of the linked list. To search for a value, the hash function is applied to the key and the corresponding slot is accessed. Then, the linked list is traversed until the value is found or the end of the list is reached. To insert a value, the hash function is applied to the key and the value is added to the front of the linked list in the corresponding slot. To delete a value, the hash function is applied to the key and the linked list is traversed until the value is found and removed. The advantage of open hashing is that it can handle any number of collisions, as long as there is enough memory to store the linked lists. The disadvantage is that it requires extra space for the pointers and the linked lists may become long and slow to access.

- Closed hashing, also known as open addressing, is a technique that stores the values directly in the hash table, without using any pointers or linked lists. Each slot of the hash table can store at most one value. If a slot is already occupied by another value, a different slot is probed until an empty slot is found or the entire table is full. To search for a value, the hash function is applied to the key and the corresponding slot is accessed. If the slot is empty or contains a different value, a different slot is probed until the value is found or the entire table is searched. To insert a value, the hash function is applied to the key and the corresponding slot is accessed. If the slot is empty, the value is stored in the slot. If the slot is occupied, a different slot is probed until an empty slot is found or the entire table is full. To delete a value, the hash function is applied to the key and the corresponding slot is accessed. If the slot contains the value, the value is removed and the slot is marked as deleted. If the slot is empty or contains a different value, a different slot is probed until the value is found or the entire table is searched. The advantage of closed hashing is that it does not require extra space for pointers or linked lists. The disadvantage is that it has a limited capacity and may suffer from clustering, which is the tendency of values to cluster around certain slots, reducing the performance of hashing.

There are different methods of probing in closed hashing, such as linear probing, quadratic probing, double hashing, etc. Each method has its own advantages and disadvantages in terms of performance, complexity and memory usage.

- Linear probing is a method that probes the slots in a linear sequence, starting from the slot given by the hash function and moving to the next slot until an empty slot is found or the entire table is searched. The advantage of linear probing is that it is simple and easy to implement. The disadvantage is that it may cause primary clustering, which is the clustering of values with consecutive hash values, reducing the performance of hashing.
