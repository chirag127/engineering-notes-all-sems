# Unit 1 - Introduction

## Basic Terminology
- Data: A collection of facts or values that can be processed by a computer.
- Data structure: A way of organizing and storing data in memory or on disk, such as arrays, lists, stacks, queues, trees, graphs, etc.
- Data type: A set of values and operations that can be performed on those values, such as int, float, char, string, etc.
- Data abstraction: A way of hiding the implementation details of a data type or a data structure, and providing only the interface or the functionality to the user.
- Data encapsulation: A way of bundling the data and the operations on the data together in a single unit, such as a class or an object.

## Elementary Data Organization
- Primitive data types: The basic data types that are built-in in a programming language, such as int, float, char, bool, etc. They have a fixed size and range of values.
- Non-primitive data types: The data types that are derived from the primitive data types, such as arrays, structures, unions, enums, pointers, etc. They have a variable size and range of values, depending on the elements they contain.
- Linear data structures: The data structures that store data in a sequential order, such as arrays, lists, stacks, queues, etc. They have a simple and easy access to the elements, but may have a fixed or limited size.
- Non-linear data structures: The data structures that store data in a hierarchical or networked order, such as trees, graphs, heaps, etc. They have a complex and flexible access to the elements, but may have a dynamic or unlimited size.

## Built in Data Types in C
- C is a low-level and structured programming language that supports both primitive and non-primitive data types.
- The primitive data types in C are: int, float, double, char, and void. They have a fixed size and range of values, depending on the compiler and the platform.
- The non-primitive data types in C are: arrays, structures, unions, enums, pointers, and functions. They have a variable size and range of values, depending on the elements they contain and the memory allocation.
- The size and range of the data types in C can be checked using the sizeof() operator and the limits.h header file.

## Algorithm
- An algorithm is a finite and ordered set of steps or instructions that can be followed to solve a problem or perform a task.
- An algorithm can be expressed in various forms, such as natural language, pseudocode, flowchart, or programming code.
- An algorithm should have the following characteristics: input, output, definiteness, finiteness, effectiveness, and correctness.

## Efficiency of an Algorithm
- The efficiency of an algorithm is a measure of how well it performs in terms of time and space, or how fast and how much memory it uses.
- The efficiency of an algorithm depends on various factors, such as the size and nature of the input, the hardware and software environment, the design and implementation of the algorithm, etc.
- The efficiency of an algorithm can be analyzed using two methods: empirical analysis and theoretical analysis.

## Time and Space Complexity
- Time complexity is a measure of how much time an algorithm takes to execute as a function of the size of the input, denoted by T(n).
- Space complexity is a measure of how much memory an algorithm uses as a function of the size of the input, denoted by S(n).
- Time and space complexity can be classified into three types: best case, average case, and worst case, depending on the input and the algorithm.
- Best case complexity is the minimum time or space an algorithm takes for a given input, denoted by T(n) or S(n).
- Average case complexity is the expected time or space an algorithm takes for a given input, denoted by T(n) or S(n).
- Worst case complexity is the maximum time or space an algorithm takes for a given input, denoted by T(n) or S(n).
