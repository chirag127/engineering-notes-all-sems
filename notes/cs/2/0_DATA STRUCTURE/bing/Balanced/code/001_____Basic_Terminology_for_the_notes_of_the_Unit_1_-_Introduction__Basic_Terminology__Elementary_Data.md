# Basic Terminology

- **Data**: Data is a collection of facts and figures that can be processed to produce meaningful information. Data can be of different types, such as numbers, characters, symbols, images, audio, video, etc.
- **Data Structure**: Data structure is a way of organizing and storing data in a computer memory, so that it can be accessed and manipulated efficiently. Data structure defines the logical and physical relationship among the data elements. Data structure can be classified into two types: primitive and non-primitive.
- **Primitive Data Structure**: Primitive data structure is a basic data type that is built in the programming language, such as int, char, float, double, etc. Primitive data structure can store only one value at a time.
- **Non-Primitive Data Structure**: Non-primitive data structure is a user-defined data type that is derived from the primitive data types, such as array, list, stack, queue, tree, graph, etc. Non-primitive data structure can store multiple values of the same or different types, and can have complex operations on them.
- **Algorithm**: Algorithm is a finite set of instructions or steps that defines a procedure to solve a problem or perform a task. Algorithm has the following characteristics:
  - It must have a clear and unambiguous specification of the input and output.
  - It must have a finite number of steps that can be executed in a definite order.
  - It must be effective, meaning that each step can be performed in a finite amount of time and space.
  - It must be correct, meaning that it produces the desired output for any valid input.
- **Efficiency of an Algorithm**: Efficiency of an algorithm is a measure of how well the algorithm performs in terms of time and space. Efficiency of an algorithm depends on the size and nature of the input, the hardware and software environment, and the design and implementation of the algorithm. Efficiency of an algorithm can be analyzed using the following methods:
  - Empirical analysis: Empirical analysis is a method of measuring the actual running time and space of an algorithm by executing it on a computer with different inputs and recording the results. Empirical analysis can give accurate results, but it is time-consuming and depends on the specific implementation and environment.
  - Theoretical analysis: Theoretical analysis is a method of estimating the asymptotic running time and space of an algorithm by counting the number of basic operations performed by the algorithm as a function of the input size. Theoretical analysis can give general results, but it is not precise and depends on the choice of the basic operations.
