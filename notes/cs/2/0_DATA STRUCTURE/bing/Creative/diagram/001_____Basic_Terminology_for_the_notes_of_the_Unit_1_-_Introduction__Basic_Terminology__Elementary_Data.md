### Basic Terminology

- **Data**: Data is a collection of facts and figures that can be processed to produce meaningful information. Data can be of different types, such as numbers, characters, symbols, images, etc.
- **Data Structure**: Data structure is a way of organizing and storing data in a computer memory, so that it can be accessed and modified efficiently. Data structure can be of different types, such as arrays, lists, stacks, queues, trees, graphs, etc.
- **Data Type**: Data type is a classification of data that specifies the possible values, operations, and representation of data. Data type can be of two types: built-in data type and user-defined data type.
- **Built-in Data Type**: Built-in data type is a data type that is predefined and supported by the programming language, such as int, char, float, double, etc. in C language.
- **User-defined Data Type**: User-defined data type is a data type that is created by the programmer using the built-in data types, such as struct, union, enum, etc. in C language.
- **Algorithm**: Algorithm is a finite set of instructions or steps that defines a logical process to solve a problem. Algorithm can be expressed in various forms, such as pseudocode, flowchart, natural language, etc.
- **Efficiency of an Algorithm**: Efficiency of an algorithm is a measure of how well an algorithm performs in terms of time and space. Efficiency of an algorithm can be analyzed using various techniques, such as time complexity, space complexity, asymptotic notations, etc.
- **Time Complexity**: Time complexity is a measure of how much time an algorithm takes to execute as a function of the input size. Time complexity can be expressed using various notations, such as big O, big theta, big omega, etc.
- **Space Complexity**: Space complexity is a measure of how much space or memory an algorithm uses as a function of the input size. Space complexity can be expressed using various notations, such as big O, big theta, big omega, etc.
- **Asymptotic Notations**: Asymptotic notations are mathematical tools that are used to describe the behavior of an algorithm in terms of its time or space complexity as the input size grows. Asymptotic notations can be of different types, such as big O, big theta, big omega, etc.
- **Big O Notation**: Big O notation is an asymptotic notation that gives the upper bound or the worst case scenario of the time or space complexity of an algorithm. Big O notation is denoted by O(f(n)), where f(n) is a function of the input size n. For example, O(n) means that the time or space complexity of an algorithm is proportional to the input size n.
- **Big Theta Notation**: Big theta notation is an asymptotic notation that gives the tight bound or the average case scenario of the time or space complexity of an algorithm. Big theta notation is denoted by Θ(f(n)), where f(n) is a function of the input size n. For example, Θ(n) means that the time or space complexity of an algorithm is exactly proportional to the input size n.
- **Big Omega Notation**: Big omega notation is an asymptotic notation that gives the lower bound or the best case scenario of the time or space complexity of an algorithm. Big omega notation is denoted by Ω(f(n)), where f(n) is a function of the input size n. For example, Ω(n) means that the time or space complexity of an algorithm is at least proportional to the input size n.
- **Time-Space Trade-off**: Time-space trade-off is a concept that states that there is a trade-off between the time and space complexity of an algorithm, such that improving one may worsen the other. For example, an algorithm that uses more memory may run faster, and vice versa.
- **Abstract Data Type (ADT)**: Abstract data type is a data type that is defined by its behavior or operations, rather than its implementation or representation. Abstract data type can be implemented using various data structures, such as arrays, lists, stacks, queues, trees, graphs, etc. For example, a stack is an abstract data type that supports two operations: push and pop. A stack can be implemented using an array or a linked list.
