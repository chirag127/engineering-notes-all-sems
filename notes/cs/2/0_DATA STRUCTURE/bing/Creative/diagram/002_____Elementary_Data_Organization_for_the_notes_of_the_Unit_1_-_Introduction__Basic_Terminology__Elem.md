### Elementary Data Organization

- Data: Data are simply values or sets of values that represent some information. For example, marks obtained by the students, names of the countries, etc.  
- Data item: A data item is a single unit of value or a group of related values within the data. For example, a student's name, roll number, and marks are a data item.  
- Entity: An entity is a thing that has some properties or attributes that can take values. For example, a student is an entity that has attributes like name, roll number, marks, etc. 
- Built-in data types: Built-in data types are the data types that are predefined and supported by the programming language. For example, in C, int, char, float, double, etc. are built-in data types. 
- User-defined data types: User-defined data types are the data types that are defined by the user using the built-in data types. For example, in C, struct, union, enum, etc. are user-defined data types. 
- Data structure: A data structure is a way of organizing and storing data in a computer memory so that it can be accessed and modified efficiently. For example, array, linked list, stack, queue, tree, graph, etc. are data structures.  
- Abstract data type (ADT): An abstract data type is a logical description of how the data and the operations on the data are defined, without specifying the implementation details. For example, a stack is an ADT that defines the data as a collection of elements and the operations as push, pop, peek, etc.
