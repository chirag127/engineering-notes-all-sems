## Unit 1 - Introduction: Basic Terminology, Elementary Data Organization, Built in Data Types in C. Algorithm, Efficiency of an Algorithm, Time and Space Complexity, Asymptotic notations: Big Oh, Big Theta and Big Omega, Time-Space trade-off. Abstract Data Types (ADT)

- Basic Terminology
  - Data: A collection of facts or information that can be processed by a computer.
  - Data Structure: A way of organizing and storing data in a computer memory or disk, such that it can be accessed and manipulated efficiently.
  - Data Type: A classification of data that defines the possible values and operations on the data.
  - Primitive Data Type: A data type that is predefined by the programming language, such as int, char, float, etc.
  - Derived Data Type: A data type that is defined by the programmer using primitive data types or other derived data types, such as array, structure, union, etc.
  - Abstract Data Type: A data type that is defined by a set of operations and properties, without specifying the implementation details, such as stack, queue, list, etc.

- Elementary Data Organization
  - Linear Data Organization: A way of organizing data in which each element has a unique successor and predecessor, except the first and last element, such as array, list, stack, queue, etc.
  - Non-linear Data Organization: A way of organizing data in which each element can have more than one successor or predecessor, such as tree, graph, etc.
  - Sequential Data Organization: A way of organizing data in which the elements are stored and accessed in a sequential order, such as array, list, etc.
  - Random Data Organization: A way of organizing data in which the elements can be accessed in any order, such as hash table, etc.

- Built in Data Types in C
  - int: A data type that represents an integer value, such as 1, -5, 0, etc. It can be signed or unsigned, and can have different sizes depending on the compiler and platform, such as short int, long int, etc.
  - char: A data type that represents a single character, such as 'a', 'B', '*', etc. It can be signed or unsigned, and has a size of one byte.
  - float: A data type that represents a floating-point value, such as 3.14, -0.5, 1.0e-6, etc. It has a size of four bytes, and can store up to six decimal digits of precision.
  - double: A data type that represents a double-precision floating-point value, such as 3.14159, -0.000005, 1.0e-12, etc. It has a size of eight bytes, and can store up to 15 decimal digits of precision.
  - void: A data type that represents an empty value, such as the return type of a function that does not return anything, or the argument list of a function that does not take any parameters.

- Algorithm
  - An algorithm is a finite sequence of well-defined steps or instructions that can be followed to solve a problem or perform a task.
  - An algorithm should have the following characteristics:
    - Input: An algorithm should have zero or more inputs, which are the data or information that are given to the algorithm.
    - Output: An algorithm should have one or more outputs, which are the data or information that are produced by the algorithm.
    - Definiteness: An algorithm should have clear and unambiguous steps, such that each step can be executed without any confusion or error.
    - Finiteness: An algorithm should have a finite number of steps, such that it terminates after a finite amount of time or iterations.
    - Effectiveness: An algorithm should have feasible and practical steps, such that each step can be performed using the available resources and within a reasonable time.

- Efficiency of an Algorithm
  - The efficiency of an algorithm is a measure of how well the algorithm performs in terms of time and space, or the amount of resources that are required to execute the algorithm.
  - The time efficiency of an algorithm is the amount of time that is taken by the algorithm to complete its execution for a given input size.
  - The space efficiency of an algorithm is the amount of memory or storage that is used by the algorithm during its execution for a given input size.
  - The efficiency of an algorithm can be affected by various factors, such as the input size, the input distribution, the hardware and software environment, the implementation details, etc
