### Asymptotic notations: Big Oh, Big Theta and Big Omega

Asymptotic notations are mathematical tools used to describe the performance or complexity of an algorithm. They are used to represent the growth rate of an algorithm's time or space complexity as the input size grows. There are three common asymptotic notations: Big Oh, Big Theta and Big Omega.

1. **Big Oh (O)**: Big Oh notation provides an upper bound on the growth rate of an algorithm's time or space complexity. It is used to describe the worst-case performance of an algorithm. For example, if the time complexity of an algorithm is O(n), it means that the running time of the algorithm will increase linearly with the size of the input.

2. **Big Theta (Θ)**: Big Theta notation provides a tight bound on the growth rate of an algorithm's time or space complexity. It is used to describe the average-case performance of an algorithm. For example, if the time complexity of an algorithm is Θ(n), it means that the running time of the algorithm will increase linearly with the size of the input, on average.

3. **Big Omega (Ω)**: Big Omega notation provides a lower bound on the growth rate of an algorithm's time or space complexity. It is used to describe the best-case performance of an algorithm. For example, if the time complexity of an algorithm is Ω(n), it means that the running time of the algorithm will increase linearly with the size of the input, in the best case.

These notations are useful for comparing the performance of different algorithms and for choosing the most efficient algorithm for a particular problem. They allow us to abstract away from the details of the algorithm and focus on its overall behavior as the input size grows.
