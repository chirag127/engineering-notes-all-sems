### Basic Terminology

- **Data Structure**: A data structure is a way of organizing and storing data in a computer so that it can be accessed and used efficiently.
- **Elementary Data Organization**: This refers to the basic methods of organizing data, such as arrays, linked lists, stacks, queues, and trees.
- **Built-in Data Types in C**: C has several built-in data types, including int, char, float, and double, among others.
- **Algorithm**: An algorithm is a step-by-step procedure for solving a problem or achieving a specific task.
- **Efficiency of an Algorithm**: The efficiency of an algorithm refers to how well it performs in terms of time and space complexity.
- **Time and Space Complexity**: Time complexity refers to the amount of time an algorithm takes to complete, while space complexity refers to the amount of memory it requires.
- **Asymptotic Notations**: Asymptotic notations, such as Big Oh, Big Theta, and Big Omega, are used to describe the performance of an algorithm as the size of its input grows.
- **Time-Space Trade-off**: This refers to the balance between the time and space complexity of an algorithm. In some cases, an algorithm may be faster but require more memory, while in other cases it may be slower but require less memory.
- **Abstract Data Types (ADT)**: An ADT is a high-level description of a collection of data and the operations that can be performed on that data. It defines the behavior of the data, but not its implementation.
