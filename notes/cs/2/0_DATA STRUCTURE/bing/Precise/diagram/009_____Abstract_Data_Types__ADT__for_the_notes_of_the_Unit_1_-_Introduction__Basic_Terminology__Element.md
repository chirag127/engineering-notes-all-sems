### Abstract Data Types (ADT)

- An Abstract Data Type (ADT) is a high-level description of a collection of data and the operations that can be performed on that data.
- It defines a set of operations that can be performed on the data, without specifying how the data is organized or how the operations are implemented.
- ADTs provide a way to separate the interface of a data structure from its implementation, allowing for greater flexibility and ease of use.
- Common examples of ADTs include stacks, queues, lists, and trees.
- The implementation of an ADT can vary, and different implementations may have different time and space complexities.
- The efficiency of an algorithm that uses an ADT depends on the choice of implementation for the ADT.
- Asymptotic notations such as Big Oh, Big Theta, and Big Omega are used to describe the time and space complexity of an algorithm.
- Time-space trade-offs may be considered when choosing an implementation for an ADT, as a more space-efficient implementation may have a higher time complexity, and vice versa.
