## Unit 2 - Arrays and Linked Lists

### Arrays
- An array is a collection of elements of the same data type, stored in contiguous memory locations.
- Arrays can be single or multidimensional.
- Single dimensional arrays are used to store data in a linear fashion, while multidimensional arrays are used to store data in a tabular form.
- The representation of arrays can be done in two ways: row-major order and column-major order.
- In row-major order, the elements of an array are stored row by row, while in column-major order, the elements are stored column by column.
- The index formulae for 1-D, 2-D, 3-D, and n-D arrays can be derived based on the representation of the array.
- Arrays have many applications, including the representation of sparse matrices.
- Sparse matrices are matrices that have a large number of zero elements. They can be represented using arrays to save space.

### Linked Lists
- A linked list is a data structure that consists of a sequence of nodes, where each node contains data and a reference to the next node in the sequence.
- Linked lists can be implemented using arrays or pointers.
- Singly linked lists, doubly linked lists, and circularly linked lists are different types of linked lists.
- Operations on a linked list include insertion, deletion, and traversal.
- Linked lists can also be used to represent polynomials.
- Polynomial representation, addition, subtraction, and multiplication of single variable and two variable polynomials can be performed using linked lists.
