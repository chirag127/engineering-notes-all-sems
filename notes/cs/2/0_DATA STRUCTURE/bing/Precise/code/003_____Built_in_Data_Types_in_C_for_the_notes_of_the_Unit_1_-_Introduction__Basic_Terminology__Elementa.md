### Built in Data Types in C

C language supports several built-in data types, including:

1. **Integer types**: used to store whole numbers. There are several integer types, including `char`, `short`, `int`, and `long`, which differ in the range of values they can represent.

2. **Floating-point types**: used to store real numbers, i.e., numbers with a fractional part. There are two floating-point types: `float` and `double`.

3. **Void type**: used to indicate that a function does not return a value or that a pointer does not point to any specific data type.

4. **Enumerated type**: used to define a new data type that consists of a set of named integer constants.

5. **Derived types**: used to create more complex data types by combining the built-in data types. Derived types include arrays, pointers, structures, and unions.

Each data type has its own characteristics, such as the range of values it can represent, the amount of memory it occupies, and the operations that can be performed on it. It is important to choose the appropriate data type for a given variable or constant to ensure that the program works correctly and efficiently.
