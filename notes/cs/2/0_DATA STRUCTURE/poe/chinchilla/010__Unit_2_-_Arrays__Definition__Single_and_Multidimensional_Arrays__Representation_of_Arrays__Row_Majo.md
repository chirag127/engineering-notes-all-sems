## Unit 2 - Arrays and Linked Lists

### Arrays

- Definition: An array is a collection of homogeneous elements that are stored in contiguous memory locations and can be accessed using a single name or index.
- Single Dimensional Array: A single dimensional array is an array where elements are arranged in a linear fashion. It is also called a one-dimensional array.
- Multidimensional Array: A multidimensional array is an array where elements are arranged in a matrix-like structure. It is also called a two-dimensional array, three-dimensional array, and so on.
- Representation of Arrays: Arrays can be represented in row-major order or column-major order. In row-major order, the elements of a row are stored together, while in column-major order, the elements of a column are stored together.
- Derivation of Index Formulae: The index formulae for one-dimensional, two-dimensional, three-dimensional and n-dimensional arrays can be derived using various methods.
- Application of Arrays: Arrays are widely used in computer programming for various purposes such as storing and manipulating data, implementing algorithms, and for numerical computations.
- Sparse Matrices and their Representations: Sparse matrices are matrices in which most of the elements are zero. They can be represented using various techniques such as coordinate list, compressed sparse row, and compressed sparse column.

### Linked Lists

- Array Implementation: In the array implementation of a linked list, the elements of the list are stored in an array, and each element has a pointer to the next element in the list.
- Pointer Implementation: In the pointer implementation of a linked list, each element of the list is a separate object that contains a data element and a pointer to the next element in the list.
- Singly Linked Lists: A singly linked list is a linked list where each element has a pointer to the next element in the list.
- Doubly Linked Lists: A doubly linked list is a linked list where each element has a pointer to the next and the previous elements in the list.
- Circularly Linked Lists: A circularly linked list is a linked list where the last element has a pointer to the first element, creating a circular structure.
- Operations on a Linked List: The common operations on a linked list are insertion, deletion, and traversal.
- Polynomial Representation: Linked lists can be used to represent polynomials, where each element of the list represents a term of the polynomial.
- Addition, Subtraction, and Multiplication of Polynomials: Linked lists can be used to perform arithmetic operations on polynomials, such as addition, subtraction, and multiplication, by traversing the lists and performing the corresponding operations on the terms.
