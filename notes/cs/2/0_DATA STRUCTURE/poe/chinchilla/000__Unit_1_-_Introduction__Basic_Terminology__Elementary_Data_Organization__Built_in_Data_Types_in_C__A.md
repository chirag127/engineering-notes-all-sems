## Unit 1 - Introduction: Basic Terminology, Elementary Data Organization, Built in Data Types in C. Algorithm, Efficiency of an Algorithm, Time and Space Complexity, Asymptotic notations: Big Oh, Big Theta and Big Omega, Time-Space trade-off. Abstract Data Types (ADT)

In this unit, we will cover the following topics:

### Basic Terminology
- Data: Information or facts that are stored in a computer system.
- Program: A set of instructions that tells a computer what to do.
- Algorithm: A set of instructions that are followed to solve a specific problem.
- Data Structure: A way of organizing and storing data in a computer system.

### Elementary Data Organization
- Bit: The smallest unit of information that can be stored or manipulated by a computer.
- Byte: A group of 8 bits.
- Word: The number of bits that a computer can process at one time.
- Record: A collection of related data items.
- File: A collection of related records.

### Built-in Data Types in C
- Int: A whole number.
- Float: A decimal number.
- Char: A single character.
- Double: A decimal number with greater precision than Float.
- Void: No data type.

### Algorithm
- An algorithm is a set of instructions that are followed to solve a specific problem.
- It is a step-by-step procedure that takes input and produces output.
- An algorithm can be represented using pseudocode or flowcharts.

### Efficiency of an Algorithm
- The efficiency of an algorithm refers to the amount of time and memory required to execute the algorithm.
- The efficiency of an algorithm can be measured in terms of time complexity and space complexity.

### Time and Space Complexity
- Time Complexity: The amount of time required to execute an algorithm.
- Space Complexity: The amount of memory required to execute an algorithm.

### Asymptotic Notations: Big Oh, Big Theta and Big Omega
- Asymptotic notations are used to represent the upper and lower bounds of the time complexity of an algorithm.
- Big Oh (O) notation represents the upper bound of the time complexity.
- Big Omega (Ω) notation represents the lower bound of the time complexity.
- Big Theta (Θ) notation represents the tight bound of the time complexity.

### Time-Space Trade-off
- The time-space trade-off refers to the fact that reducing the space complexity of an algorithm may increase its time complexity, and vice versa.
- It is important to find the right balance between time and space complexity to optimize the performance of an algorithm.

### Abstract Data Types (ADT)
- An abstract data type is a data type that is defined by its behavior rather than its implementation.
- It specifies a set of operations that can be performed on the data type, but does not specify how these operations are implemented.
- Examples of abstract data types include stacks, queues, and linked lists.

In conclusion, this unit covers the basic terminology, elementary data organization, built-in data types in C, algorithms, time and space complexity, asymptotic notations, time-space trade-off, and abstract data types. Understanding these concepts is crucial for developing efficient and optimized algorithms.
