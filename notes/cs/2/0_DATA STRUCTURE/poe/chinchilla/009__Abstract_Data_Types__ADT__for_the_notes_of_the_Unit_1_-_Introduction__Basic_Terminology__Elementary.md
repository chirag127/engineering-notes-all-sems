### Abstract Data Types (ADT)

Abstract Data Types (ADT) are a way of defining data structures independent of their implementation. These data types are defined by their behavior rather than their implementation. ADTs provide a high-level view of a data structure, which makes it easy to reason about the data structure and its operations.

ADTs can be implemented using any programming language, and they are not tied to any specific implementation. This means that ADTs can be used in a wide range of applications and can be easily modified and extended.

ADTs have three essential components:

#### Data

Data is the information that is stored in an ADT. Data can be of any type, including integers, strings, and structures.

#### Operations

Operations are the functions that can be performed on the data stored in an ADT. These operations include inserting, deleting, and searching for data.

#### Properties

Properties are the characteristics of an ADT that define its behavior. These properties include the order of data, the uniqueness of data, and the size of the data structure.

Some common examples of ADTs include stacks, queues, and trees. These data structures are used in a wide range of applications, including computer science, engineering, and mathematics.

##### Stacks

A stack is an ADT that follows the Last-In-First-Out (LIFO) principle. This means that the last item added to the stack is the first item to be removed from the stack. The two primary operations on a stack are push and pop.

##### Queues

A queue is an ADT that follows the First-In-First-Out (FIFO) principle. This means that the first item added to the queue is the first item to be removed from the queue. The two primary operations on a queue are enqueue and dequeue.

##### Trees

A tree is an ADT that consists of nodes connected by edges. Each node in a tree can have zero or more child nodes, and each child node can have zero or more child nodes. The two primary operations on a tree are inserting and deleting nodes.

ADTs are essential in data structure because they provide a way to encapsulate data and operations, making it easy to reason about the behavior of a data structure. ADTs can also be used to hide the implementation details of a data structure, which can be useful in large-scale software development.
