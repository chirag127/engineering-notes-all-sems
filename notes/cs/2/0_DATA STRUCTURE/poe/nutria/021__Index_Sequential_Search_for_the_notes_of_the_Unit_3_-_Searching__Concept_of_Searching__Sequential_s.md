
### Index Sequential Search for the notes of the Unit 3 - Searching: Concept of Searching, Sequential search, Index Sequential Search, Binary Search. Concept of Hashing & Collision resolution Techniques used in Hashing. - **Index Sequential Search** is a search algorithm used to search for a particular element in a given list or array. It is a combination of two searching techniques, namely, indexing and sequential searching. This search is used when the list is sorted and when the elements of the list are known in advance. 

- **Concept of Searching** refers to the process of finding an item in a list or array. Searching algorithms are used to find a particular item in a list or array. The time complexity of a search algorithm depends on the size of the list or array and the number of elements in it.

- **Sequential search** is a searching technique used to find a particular element in a list or array. It is a linear search algorithm which compares the elements of the list one by one until the desired element is found.

- **Index Sequential Search** is an improvement over the sequential search algorithm. It uses an index table to store the index of the elements in the list. This helps to reduce the search time as the index table can be used to directly access the elements in the list.

- **Binary Search** is a search algorithm which is used to search for an element in a sorted list or array. It is a divide and conquer algorithm which divides the list into two halves and searches for the element in one of the halves.

- **Concept of Hashing** is the process of mapping a set of values to a unique identifier. Hashing is used to store data in an efficient and secure manner.

- **Collision Resolution Techniques** used in Hashing are methods used to resolve collisions in a hash table. Collisions occur when two or more elements are mapped to the same hash value. The common collision resolution techniques are linear probing, quadratic probing, chaining and rehashing.

- **Sorting** is the process of arranging a list of elements in a particular order. Insertion sort, selection sort, bubble sort, quick sort, merge sort, heap sort and radix sort are some of the common sorting algorithms. Insertion sort is a simple sorting algorithm which works by inserting the elements one by one into their correct positions. Selection sort works by selecting the smallest element in the list and swapping it with the first element. Bubble sort is a comparison-based sorting algorithm which works by swapping adjacent elements if they are not in the correct order. Quick sort is a divide and conquer algorithm which works by partitioning the list into two halves and sorting them recursively. Merge sort is a divide and conquer algorithm which works by dividing the list into two halves and then merging them in the correct order. Heap sort is a comparison-based sorting algorithm which works by building a heap and then sorting the elements in the heap. Radix sort is a sorting algorithm which works by sorting the elements based on their digits.
