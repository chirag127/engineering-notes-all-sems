
### Definition for the Notes of the Unit 2 - Data Structure

#### Arrays: 
* Definition: An array is a collection of items stored at contiguous memory locations. It can store data of any data type and can be of any size. 
* Single and Multidimensional Arrays: Arrays can be single-dimensional, multi-dimensional, or even jagged. 
* Representation of Arrays: Arrays can be represented in either row-major order or column-major order. 
* Derivation of Index Formulae for 1-D, 2-D, 3-D and n-D Array: Index formulae are used to calculate the position of each element in the array. 
* Application of Arrays: Arrays are used in many applications such as sorting, searching, and manipulation of data.
* Sparse Matrices and their Representations: Sparse matrices are matrices with a large number of zero elements. They can be represented using linked lists or hash tables. 

#### Linked Lists: 
* Array Implementation: Arrays can be used to implement linked lists. 
* Pointer Implementation of Singly Linked Lists: A singly linked list is a data structure in which each node contains a pointer to the next node in the list. 
* Doubly Linked List: A doubly linked list is a data structure in which each node contains a pointer to both the next and previous nodes in the list. 
* Circularly Linked List: A circularly linked list is a data structure in which the last node points back to the first node. 
* Operations on a Linked List: Operations on a linked list include insertion, deletion, traversal, and searching. 

#### Polynomial Representation and Addition Subtraction & Multiplications of Single Variable & Two Variables Polynomial: 
* Polynomial Representation: Polynomials can be represented using linked lists or arrays. 
* Addition, Subtraction and Multiplication of Single Variable Polynomials: Single variable polynomials can be added, subtracted and multiplied using the standard arithmetic operations. 
* Addition, Subtraction and Multiplication of Two Variables Polynomials: Two variables polynomials can also be added, subtracted and multiplied using the standard arithmetic operations.
