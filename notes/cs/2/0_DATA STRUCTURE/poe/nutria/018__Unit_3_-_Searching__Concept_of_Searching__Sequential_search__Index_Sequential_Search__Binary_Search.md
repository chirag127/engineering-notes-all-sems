

## Unit 3 - Searching

### Concept of Searching
Searching is a process of finding a particular item from a collection of items. It is a fundamental operation in computing and is used in many applications. Searching algorithms are used to search for an item in a collection of items. 

#### Sequential search
Sequential search is a type of search algorithm which searches for an item in a collection of items by comparing each item in the collection with the search item one by one. It is also known as linear search.

#### Index Sequential Search
Index sequential search is an improvement over sequential search. It uses an index to speed up the searching process. In this method, the collection is divided into multiple blocks and each block is indexed.

#### Binary Search
Binary search is an efficient search algorithm which searches for an item in a sorted collection of items by repeatedly dividing the collection into two halves. It is also known as logarithmic search.

### Concept of Hashing & Collision resolution Techniques used in Hashing
Hashing is a process of mapping a set of values to a fixed size data structure. It is used to store and retrieve data from a collection of items. There are various collision resolution techniques used in hashing such as linear probing, quadratic probing, chaining and double hashing.

### Sorting
Sorting is a process of arranging a collection of items in a specific order. There are various sorting algorithms such as insertion sort, selection sort, bubble sort, quick sort, merge sort, heap sort and radix sort.
