
### Basic Terminology for the notes of the Unit 1 - Introduction: 

- **Basic Terminology**: Terms used to describe the fundamental concepts of data structure, such as data, information, structure, algorithm, etc.
- **Elementary Data Organization**: A way of organizing data in a computer, such as arrays, linked lists, binary trees, etc.
- **Built in Data Types in C**: A set of data types that are built into the C programming language, such as int, float, char, etc.
- **Algorithm**: A step-by-step procedure for solving a problem or performing a task.
- **Efficiency of an Algorithm**: A measure of how well an algorithm performs in terms of time and space complexity.
- **Time and Space Complexity**: A measure of how much time and space an algorithm requires to complete its task.
- **Asymptotic Notations**: A way of measuring the time and space complexity of an algorithm, such as Big-Oh, Big-Theta, and Big-Omega.
- **Time-Space Trade-off**: The idea that an algorithm can be made faster by using more space, or vice versa.
- **Abstract Data Types (ADT)**: A set of data types that are abstracted from their implementation, such as stacks, queues, heaps, etc.
