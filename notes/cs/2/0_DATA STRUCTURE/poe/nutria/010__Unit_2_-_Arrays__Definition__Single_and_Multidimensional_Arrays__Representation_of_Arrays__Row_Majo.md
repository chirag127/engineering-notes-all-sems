
## Unit 2 - Arrays: 
* Arrays are data structures that store elements of the same type in a contiguous block of memory. 
* There are two types of arrays: single-dimensional and multidimensional. 
* Representation of arrays can be done in two ways: row major order and column major order. 
* Index formulae for 1-D,2-D,3-D and n-D arrays can be derived. 
* Arrays can be used in various applications. 
* Sparse matrices are a type of array that have many elements with zero values. 

## Linked Lists: 
* Linked lists are data structures that consist of nodes that are connected in a linear fashion. 
* Linked lists can be implemented using arrays or pointers. 
* There are three types of linked lists: singly linked lists, doubly linked lists, and circularly linked lists. 
* Operations on linked lists include insertion, deletion, and traversal. 

## Polynomials: 
* Polynomials are mathematical expressions that consist of variables and coefficients. 
* Polynomials can be represented as linked lists. 
* Addition, subtraction, and multiplication of single and two variable polynomials can be performed.
