
### Sorting: Insertion Sort, Selection, Bubble Sort, Quick Sort, Merge Sort, Heap Sort and Radix Sort

Insertion Sort: Insertion sort is an in-place comparison-based sorting algorithm. It works by taking elements from an unsorted list and inserting them into the correct position in a sorted list.

Selection Sort: Selection sort is an in-place comparison-based sorting algorithm. It works by taking the smallest element from the unsorted list and inserting it into the correct position in the sorted list.

Bubble Sort: Bubble sort is an in-place comparison-based sorting algorithm. It works by comparing adjacent elements in the unsorted list and swapping them if they are in the wrong order.

Quick Sort: Quick sort is an in-place comparison-based sorting algorithm. It works by picking an element from the unsorted list as the pivot, and then partitioning the list into two parts based on the pivot. The elements smaller than the pivot are placed to the left of the pivot and the elements larger than the pivot are placed to the right of the pivot.

Merge Sort: Merge sort is a divide-and-conquer sorting algorithm. It works by dividing the unsorted list into two smaller lists, sorting them and then merging them back together.

Heap Sort: Heap sort is an in-place comparison-based sorting algorithm. It works by creating a heap data structure out of the unsorted list and then sorting it by repeatedly removing the largest element from the heap and inserting it back into the list.

Radix Sort: Radix sort is a non-comparison-based sorting algorithm. It works by sorting the elements of the list based on the individual digits of their keys.
