
### Concept of Searching
Searching is the process of locating an item from a collection of items. It is the most important operation in data structures, as it helps to find a specific record from a large collection of records quickly. There are various searching techniques, such as linear search, binary search, index sequential search, and hashing. 

#### Sequential Search
Sequential search is the simplest searching algorithm. It searches every element of the list one by one, until it finds the desired element or until it reaches the end of the list. It is also known as a linear search. 

#### Index Sequential Search
Index sequential search is an improvement over the sequential search. It is a two-step process. First, the index of the list is searched to find the desired element. If the element is not found, then a sequential search is performed on the list. 

#### Binary Search
Binary search is an efficient searching algorithm. It is also known as a divide and conquer algorithm. It divides the list into two parts and searches for the desired element in one of the two parts. It is the most efficient searching algorithm. 

#### Concept of Hashing & Collision Resolution Techniques used in Hashing
Hashing is a technique used to store and retrieve data from a data structure. It is a method of mapping a large set of data to a smaller set of data. It is used to store and access data quickly. Collision resolution techniques are used to resolve conflicts when two different keys map to the same location in the data structure. These techniques include linear probing, quadratic probing, and double hashing. 

#### Sorting
Sorting is the process of arranging data in a particular order. Common sorting algorithms include insertion sort, selection sort, bubble sort, quick sort, merge sort, heap sort, and radix sort. Insertion sort is a simple sorting algorithm that sorts an array by inserting each element into its correct position. Selection sort is an algorithm that sorts an array by repeatedly finding the minimum element from the unsorted part and placing it at the beginning. Bubble sort is an algorithm that repeatedly swaps adjacent elements if they are in the wrong order. Quick sort is a divide and conquer algorithm that sorts an array by partitioning it into two parts and then recursively sorting the two parts. Merge sort is a divide and conquer algorithm that sorts an array by dividing it into two parts and then merging them in a sorted order. Heap sort is a sorting algorithm that sorts an array by building a heap data structure and then extracting the elements in sorted order. Radix sort is a sorting algorithm that sorts an array by grouping the elements according to their digits.
