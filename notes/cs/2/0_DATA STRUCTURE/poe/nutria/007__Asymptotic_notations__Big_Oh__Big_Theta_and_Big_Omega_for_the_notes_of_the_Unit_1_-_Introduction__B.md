
### Asymptotic Notations: Big Oh, Big Theta and Big Omega

* Asymptotic notations are mathematical tools used to represent the time complexity of algorithms. 
* Big Oh (O) notation is used to represent the upper bound on the time complexity of an algorithm. It is the worst case time complexity of an algorithm.
* Big Theta (Θ) notation is used to represent the average time complexity of an algorithm. It is the average case time complexity of an algorithm.
* Big Omega (Ω) notation is used to represent the lower bound on the time complexity of an algorithm. It is the best case time complexity of an algorithm.
* Time complexity is the measure of the amount of time taken by an algorithm to execute and produce the result.
* Space complexity is the measure of the amount of memory taken by an algorithm to execute.
* Time-Space trade-off is the concept of reducing the time complexity of an algorithm by increasing its space complexity.
* Abstract Data Types (ADT) are the logical description of data structures and the operations on them. They are used to define the data structures in the subject of Data Structure.
