

### Derivation of Index Formulae for 1-D,2-D,3-D and n-D Array

This section covers the derivation of index formulae for 1-D, 2-D, 3-D and n-D array. 

#### 1-D Array 
A 1-D array consists of a single row or column of elements. The index of an element in a 1-D array is given by the formula: 

Index = Element Number - 1 

#### 2-D Array 
A 2-D array consists of a matrix of elements. The index of an element in a 2-D array is given by the formula: 

Index = (Row Number - 1) * Number of Columns + (Column Number - 1) 

#### 3-D Array 
A 3-D array consists of a cube of elements. The index of an element in a 3-D array is given by the formula: 

Index = (Layer Number - 1) * Number of Rows * Number of Columns + (Row Number - 1) * Number of Columns + (Column Number - 1) 

#### n-D Array 
An n-D array consists of multiple layers of elements. The index of an element in an n-D array is given by the formula: 

Index = (Layer Number - 1) * Number of Rows * Number of Columns + (Row Number - 1) * Number of Columns + (Column Number - 1) + ... + (Element Number - 1)
