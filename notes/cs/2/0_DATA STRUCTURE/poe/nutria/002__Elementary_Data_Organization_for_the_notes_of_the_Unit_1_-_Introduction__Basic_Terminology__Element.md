

### Elementary Data Organization 

* **Basic Terminology**: A data organization is the way data is organized and stored in a computer system. It involves the structure of the data, the relationships between the data elements and the rules governing the data. 

* **Elementary Data Organization**: Elementary data organizations are the basic ways of organizing data. These include flat files, arrays, linked lists, stacks, queues, trees, and graphs.

* **Built in Data Types in C**: C programming language provides a set of built-in data types to handle different kinds of data. These data types are used to define a variable before it is used in a program. The built-in data types are int, float, char, and void. 

* **Algorithm**: An algorithm is a set of instructions that tells a computer how to perform a task. It is a step-by-step procedure for solving a problem or performing a task. 

* **Efficiency of an Algorithm**: Efficiency of an algorithm is the measure of how well it performs. It is usually measured in terms of time and space complexity. 

* **Time and Space Complexity**: Time complexity is the amount of time taken by an algorithm to complete its task. Space complexity is the amount of memory required by an algorithm to complete its task. 

* **Asymptotic notations: Big Oh, Big Theta and Big Omega**: Asymptotic notations are used to measure the time complexity of an algorithm. Big Oh is used to represent the upper bound of an algorithm's time complexity. Big Theta is used to represent the average case of an algorithm's time complexity. Big Omega is used to represent the lower bound of an algorithm's time complexity. 

* **Time-Space trade-off**: Time-space trade-off is a technique used to reduce the time complexity of an algorithm at the cost of an increase in the space complexity. 

* **Abstract Data Types (ADT) in the subject of DATA STRUCTURE**: Abstract Data Types (ADT) are data structures that are used to store and organize data. Examples of ADT include arrays, linked lists, stacks, queues, trees, and graphs.
