#### Arrays

#### Linked Lists 

Linked lists are a type of data structure that is used to store a collection of items. Linked lists can be implemented using either an array or a pointer. Singly linked lists, doubly linked lists and circularly linked lists are the three main types of linked lists. 

Linked lists can be used to perform a variety of operations, such as insertion, deletion, traversal, and addition/subtraction/multiplication of single and two variable polynomials. 

#### Polynomial Representation 

Polynomials can be represented using linked lists. Each node in the linked list contains a coefficient and an exponent. The coefficients and exponents of the polynomial can be added, subtracted, or multiplied to calculate the result.
