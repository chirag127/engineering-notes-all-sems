
### Efficiency of an Algorithm

* An algorithm is a step-by-step procedure for solving a problem or accomplishing a task. 
* The efficiency of an algorithm is the amount of time and/or space it takes to execute the algorithm.
* Time complexity is a measure of the amount of time it takes for an algorithm to complete its task.
* Space complexity is a measure of the amount of memory required to execute the algorithm.
* Asymptotic notations are used to describe the efficiency of an algorithm. These include Big Oh (O), Big Theta (Θ), and Big Omega (Ω).
* Time-space trade-off is a technique used to improve the efficiency of an algorithm by trading off time complexity for space complexity, or vice versa.
* Abstract Data Types (ADTs) are data structures used in the subject of Data Structure to represent and manipulate data.
