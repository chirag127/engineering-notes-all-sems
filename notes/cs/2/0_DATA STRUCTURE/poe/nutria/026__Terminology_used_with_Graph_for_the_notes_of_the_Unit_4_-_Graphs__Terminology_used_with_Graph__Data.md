

### Terminology used with Graph

* Graph: A graph is a data structure used to represent a set of objects (called vertices) and the connections between them (called edges).

* Data Structure for Graph Representations: 
  * Adjacency Matrices: An adjacency matrix is a two-dimensional array that stores the information about the connections between the vertices. 
  * Adjacency List: An adjacency list is a one-dimensional array that stores the information about the connections between the vertices. 
  * Adjacency: Adjacency is the relationship between two vertices that are connected by an edge.

* Graph Traversal: 
  * Depth First Search: Depth first search is an algorithm used to traverse a graph. It begins at the root node and explores as far as possible along each branch before backtracking.
  * Breadth First Search: Breadth first search is an algorithm used to traverse a graph. It begins at the root node and explores each level of the graph in a breadth-first manner.

* Connected Component: A connected component is a set of vertices in a graph that are all connected to each other.

* Spanning Trees: A spanning tree is a subgraph of a graph that contains all the vertices and some of the edges of the original graph.

* Minimum Cost Spanning Trees: 
  * Prims Algorithm: Prim's algorithm is an algorithm used to find the minimum cost spanning tree of a graph.
  * Kruskal Algorithm: Kruskal's algorithm is an algorithm used to find the minimum cost spanning tree of a graph.

* Transitive Closure and Shortest Path algorithm:
  * Warshal Algorithm: Warshal's algorithm is an algorithm used to find the transitive closure of a graph.
  * Dijikstra Algorithm: Dijkstra's algorithm is an algorithm used to find the shortest path between two vertices in a graph.
