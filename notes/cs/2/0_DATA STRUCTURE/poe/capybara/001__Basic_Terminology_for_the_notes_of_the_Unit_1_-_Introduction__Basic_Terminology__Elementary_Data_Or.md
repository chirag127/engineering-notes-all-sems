Here are some basic terminology for the notes of the Unit 1 - Introduction:

- **Data**: It refers to the collection of facts, figures, or information that can be processed by a computer.
- **Data Structure**: It is a way of organizing and storing data in a computer, so that it can be accessed and used efficiently.
- **Elementary Data Organization**: It is the way of organizing data in a simple and straightforward manner.
- **Built-in Data Types in C**: C language provides various built-in data types such as int, float, char, and double.
- **Algorithm**: It is a set of instructions that are followed to solve a particular problem.
- **Efficiency of an Algorithm**: It refers to the amount of time and space required by an algorithm to solve a particular problem.
- **Time Complexity**: It is the measure of the amount of time required by an algorithm to solve a problem.
- **Space Complexity**: It is the measure of the amount of memory required by an algorithm to solve a problem.
- **Asymptotic notations**: These are the mathematical notations used to describe the upper and lower bounds of an algorithm's time or space complexity. The three commonly used asymptotic notations are Big Oh, Big Theta, and Big Omega.
- **Big Oh**: It is used to describe the upper bound of an algorithm's time or space complexity.
- **Big Theta**: It is used to describe both the upper and lower bounds of an algorithm's time or space complexity.
- **Big Omega**: It is used to describe the lower bound of an algorithm's time or space complexity.
- **Time-Space trade-off**: It refers to the situation where an algorithm can be made more efficient in terms of either time or space, but not both.
- **Abstract Data Types (ADT)**: It is a way of defining data structures in terms of their behavior, without specifying their implementation details.

Understanding these basic terminologies is essential to learn and understand the subject of data structure.
