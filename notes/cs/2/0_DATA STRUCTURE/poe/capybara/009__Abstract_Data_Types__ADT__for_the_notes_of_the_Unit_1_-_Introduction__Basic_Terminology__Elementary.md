### Abstract Data Types (ADT)

- An abstract data type (ADT) is a high-level description of a set of operations that can be performed on a particular data type, without specifying how these operations are implemented.
- ADT provides a way to organize and encapsulate data and functions that operate on that data.
- ADT specifies the behavior of the data type, without specifying the underlying implementation details.
- ADT provides a way to abstract away the complexity of the data and operations, allowing users to focus on the functionality of the data type rather than its implementation.
- ADT can be thought of as a blueprint for creating new data types that have specific properties and behaviors.
- ADT can be implemented using different programming languages, and the implementation details can be hidden from the user.
- ADT is used extensively in computer science, especially in the design and development of data structures and algorithms.

### Basic Terminology

- Data: A collection of facts, figures, or information.
- Data Item: The smallest unit of information that can be processed.
- Data Structure: A way of organizing and storing data in a computer so that it can be accessed and used efficiently.
- Data Type: A classification of data items that tells the compiler or interpreter how the programmer intends to use the data.
- Variable: A named data item that can be changed during program execution.

### Elementary Data Organization

- Elementary data organization refers to the basic ways in which data can be organized and stored.
- The most common elementary data organizations are: 
    - Sequential
    - Direct
    - Indexed

### Algorithm

- An algorithm is a step-by-step procedure for solving a problem or achieving a specific goal.
- Algorithms are used to solve problems in computer science, mathematics, and engineering.
- An algorithm should be:
    - Correct
    - Efficient
    - Understandable
    - General

### Efficiency of an Algorithm

- The efficiency of an algorithm refers to the amount of resources it requires to solve a problem.
- The resources may include time, memory, or other system resources.
- The efficiency of an algorithm is usually measured in terms of its time complexity and space complexity.

### Time and Space Complexity

- Time complexity refers to the amount of time it takes for an algorithm to complete its task.
- Space complexity refers to the amount of memory required by an algorithm to solve a problem.
- Both time and space complexity are important factors in determining the efficiency of an algorithm.

### Asymptotic Notations: Big Oh, Big Theta and Big Omega

- Asymptotic notations are used to describe the upper and lower bounds of an algorithm's time complexity or space complexity.
- Big Oh notation (O) is used to describe the upper bound of an algorithm's time complexity or space complexity.
- Big Theta notation (Θ) is used to describe the tight bound of an algorithm's time complexity or space complexity.
- Big Omega notation (Ω) is used to describe the lower bound of an algorithm's time complexity or space complexity.

### Time-Space Trade-off

- Time-space trade-off is a common concept in computer science, where the use of additional memory can reduce the time complexity of an algorithm.
- By using additional memory, an algorithm can store intermediate results, which can reduce the number of computations required.
- However, the additional memory usage can increase the space complexity of the algorithm.
