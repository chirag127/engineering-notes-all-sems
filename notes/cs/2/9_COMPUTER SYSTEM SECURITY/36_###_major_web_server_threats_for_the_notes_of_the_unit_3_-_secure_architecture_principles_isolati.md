### Major web server threats for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

Unit 3 of the Computer System Security course focuses on Secure Architecture Principles, Isolation, and Least Privilege, including the aspect of major web server threats.

Web servers are a critical component of many computer systems, and are often the target of security threats. Some of the major web server threats include:

1. Cross-Site Scripting (XSS): XSS attacks inject malicious code into web pages, which can be executed by unsuspecting users who visit the affected web page.

2. SQL Injection: SQL injection attacks exploit vulnerabilities in web applications to gain unauthorized access to sensitive information stored in databases.

3. Remote Code Execution: Remote code execution attacks allow attackers to execute code on a web server, which can be used to steal information, modify data, or take control of the server.

4. Distributed Denial of Service (DDoS): DDoS attacks are designed to overwhelm a web server with traffic, making it unavailable to legitimate users.

5. Man-in-the-Middle (MitM) Attacks: MitM attacks allow attackers to intercept and modify network traffic, potentially stealing sensitive information or altering data.

In the context of the Computer System Security course, students in Unit 3 may learn about major web server threats as part of the Secure Architecture Principles, Isolation, and Least Privilege unit. This may include working with examples of different types of web server threats, learning about the impact of these threats on web server security, and learning strategies for protecting web servers from these threats.

In summary, Unit 3 of the Computer System Security course focuses on Secure Architecture Principles, Isolation, and Least Privilege, and includes a discussion of major web server threats. Major web server threats include Cross-Site Scripting (XSS), SQL Injection, Remote Code Execution, Distributed Denial of Service (DDoS), and Man-in-the-Middle (MitM) Attacks. Students will learn about these threats through interactive activities and hands-on experiences, and will learn strategies for protecting web servers from these threats.
