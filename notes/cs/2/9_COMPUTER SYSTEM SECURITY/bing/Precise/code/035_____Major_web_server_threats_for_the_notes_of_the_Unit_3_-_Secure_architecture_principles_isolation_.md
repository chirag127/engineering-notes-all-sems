### Unit 3 - Secure architecture principles isolation and least privilege
#### Major web server threats
1. **Injection attacks:** These attacks occur when an attacker sends malicious data to the web server, which is then interpreted and executed. Examples include SQL injection, where the attacker sends malicious SQL code to manipulate the database, and cross-site scripting (XSS), where the attacker sends malicious scripts to be executed by the user's browser.
2. **Denial of Service (DoS) attacks:** These attacks aim to overwhelm the web server with traffic, rendering it unable to respond to legitimate requests. This can be achieved through various means, such as sending a large number of requests to the server or exploiting vulnerabilities in the server software.
3. **Man-in-the-middle (MitM) attacks:** These attacks occur when an attacker intercepts the communication between the user and the web server, allowing them to eavesdrop on the conversation, alter the data being transmitted, or impersonate one of the parties.
4. **Brute force attacks:** These attacks involve repeatedly trying different combinations of usernames and passwords until the attacker gains access to the web server. This can be mitigated by implementing strong password policies and using multi-factor authentication.
5. **Malware:** Malware, such as viruses, worms, and Trojan horses, can be used to compromise the web server, steal data, or disrupt its operation. It is important to keep the server software up to date and to use anti-malware software to protect against these threats.
6. **Phishing:** Phishing attacks involve tricking the user into revealing sensitive information, such as login credentials or financial information, by posing as a legitimate entity. This can be mitigated by educating users about the dangers of phishing and how to identify and avoid these attacks.
7. **Physical attacks:** Physical attacks on the web server, such as theft or damage to the hardware, can compromise the security of the system. It is important to implement physical security measures, such as access controls and surveillance, to protect against these threats.
