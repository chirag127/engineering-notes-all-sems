### Unix and Windows Access Control Summary

#### Unit 3 - Secure Architecture Principles: Isolation and Least Privilege

- **Access control** is the process of granting or denying specific requests to obtain and use information and related information processing services.
- **Unix** and **Windows** are two popular operating systems that implement access control mechanisms to ensure the security of their systems.
- **Unix** uses a discretionary access control (DAC) model, where the owner of a file or directory has the ability to control access to it.
- **Windows** uses a combination of DAC and mandatory access control (MAC) models, where the system administrator defines the access control policy and the system enforces it.
- **Isolation** is a key principle in secure architecture, where different components of a system are separated to prevent unauthorized access or interference.
- **Least privilege** is another important principle, where a user or process is given the minimum level of access necessary to perform their tasks, reducing the potential for harm if their account is compromised.
- Both **Unix** and **Windows** implement these principles through their access control mechanisms, allowing for the creation of secure systems.
