### Summary of weaknesses of internet security for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

1. **Lack of a high-level strategy**: Many businesses, especially new and small ones, simply lack a high-level strategy for their cybersecurity needs.
2. **Unsecured networks**: If the network isn’t secured, it’s trivially easy for nefarious parties to gain access to your system.
3. **Unsecured communication channels**: If the business is using unsecured communication channels, it’s easy for cybercriminals to intercept and steal data.
4. **Unknown bugs**: Bugs in software can create vulnerabilities that can be exploited by cybercriminals.
5. **Outdated systems**: Outdated systems are more vulnerable to cyber attacks as they may not have the latest security patches.
6. **Lack of monitoring**: Lack of monitoring can make it difficult to detect and respond to cyber attacks.
7. **IoT and multiple connection points**: The increasing number of connected devices (IoT) can create multiple points of entry for cybercriminals.
8. **Untrained employees**: Employees who are not trained in cybersecurity best practices can inadvertently create vulnerabilities.
9. **Violations of security information system by employees**: Information system theft by employees has been evidenced in many companies.
10. **Misconfigurations**: Misconfigurations are the single largest threat to both cloud and app security.
11. **Unsecured APIs**: Unsecured application programming interfaces (APIs) can create vulnerabilities.
