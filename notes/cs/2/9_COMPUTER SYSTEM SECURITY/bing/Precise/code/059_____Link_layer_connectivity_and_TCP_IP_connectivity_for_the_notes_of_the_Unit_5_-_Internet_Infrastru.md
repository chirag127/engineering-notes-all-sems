### Link Layer Connectivity and TCP/IP Connectivity

Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

- The link layer is responsible for transferring data between two directly connected nodes in a network.
- This layer is responsible for the physical and logical link between the nodes, and it provides the means to transfer data between them.
- The link layer is also responsible for error detection and correction, flow control, and framing.
- The most common link layer protocol is Ethernet, which is used in local area networks (LANs).
- The Internet Protocol Suite, commonly known as TCP/IP, is the set of communication protocols used for the Internet and other similar networks.
- TCP/IP provides end-to-end connectivity, specifying how data should be formatted, addressed, transmitted, routed, and received.
- The TCP/IP model consists of four layers: the link layer, the internet layer, the transport layer, and the application layer.
- The internet layer is responsible for routing data packets across the network, while the transport layer is responsible for end-to-end communication between the source and destination nodes.
- The application layer provides the interface between the user and the network, and it is responsible for providing services such as email, file transfer, and web browsing.
