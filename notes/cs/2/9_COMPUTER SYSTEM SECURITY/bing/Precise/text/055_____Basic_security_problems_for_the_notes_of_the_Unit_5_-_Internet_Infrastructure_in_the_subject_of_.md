### Basic security problems for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

1. **Malware**: Malicious software that can infect a computer system and cause harm to the system or steal sensitive information.
2. **Phishing**: A type of social engineering attack where attackers attempt to trick users into revealing sensitive information or installing malware by posing as a trustworthy entity.
3. **Man-in-the-middle attacks**: An attack where an attacker intercepts communication between two parties and can read, modify, or inject new messages.
4. **Denial of Service (DoS) attacks**: An attack where an attacker floods a system with traffic or requests, overwhelming the system and making it unavailable to legitimate users.
5. **SQL injection**: An attack where an attacker injects malicious code into an SQL statement, allowing them to manipulate or steal data from a database.
6. **Cross-Site Scripting (XSS)**: An attack where an attacker injects malicious code into a web page, allowing them to steal data or manipulate the behavior of the page.
7. **Password attacks**: An attack where an attacker attempts to crack a user's password, either through brute force or by exploiting weak passwords.
8. **Eavesdropping**: An attack where an attacker intercepts communication between two parties and listens in on the conversation, potentially stealing sensitive information.
