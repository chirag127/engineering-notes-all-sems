### Unix and Windows Access Control Summary

#### Unit 3 - Secure Architecture Principles Isolation and Least Privilege

- **Access control** is the process of granting or denying specific requests to obtain and use information and related information processing services.
- **Unix** and **Windows** are two popular operating systems that implement access control mechanisms to protect the confidentiality, integrity, and availability of data and resources.
- **Unix** uses a discretionary access control (DAC) model, where the owner of a file or directory has the ability to control access to it.
- **Windows** uses both DAC and mandatory access control (MAC) models, where access control decisions are based on the security clearance of the user and the classification of the data.
- **Isolation** is a key principle in secure architecture, where different components or processes are separated to prevent unauthorized access or interference.
- **Least privilege** is another important principle, where a user or process is given the minimum level of access necessary to perform their tasks, reducing the potential for harm if the user or process is compromised.
- Both **Unix** and **Windows** implement these principles through various mechanisms, such as user and group permissions, file and directory permissions, and process isolation.
