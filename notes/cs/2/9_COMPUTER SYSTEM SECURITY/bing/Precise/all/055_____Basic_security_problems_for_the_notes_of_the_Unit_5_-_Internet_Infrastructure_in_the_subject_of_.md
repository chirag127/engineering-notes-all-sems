# Basic Security Problems

Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

1. **Malware**: Malicious software that can harm computer systems, steal data, or disrupt operations. Examples include viruses, worms, and Trojan horses.
2. **Phishing**: A type of social engineering attack where attackers attempt to trick users into revealing sensitive information, such as login credentials or financial information.
3. **Denial of Service (DoS)**: An attack that overwhelms a system or network with traffic, rendering it unavailable to users.
4. **Man-in-the-Middle (MitM)**: An attack where an attacker intercepts and alters communications between two parties without their knowledge.
5. **SQL Injection**: An attack where an attacker injects malicious code into a database query, allowing them to access, modify, or delete data.
6. **Cross-Site Scripting (XSS)**: An attack where an attacker injects malicious code into a website, allowing them to steal data or manipulate the behavior of the site.
7. **Password Attacks**: Attacks that attempt to crack or steal user passwords, allowing attackers to gain unauthorized access to systems or data.
8. **Insider Threats**: Threats that originate from within an organization, such as employees or contractors who abuse their access to systems or data.

These are some of the basic security problems that can arise in the context of internet infrastructure. It is important to be aware of these threats and to take appropriate measures to protect against them.
