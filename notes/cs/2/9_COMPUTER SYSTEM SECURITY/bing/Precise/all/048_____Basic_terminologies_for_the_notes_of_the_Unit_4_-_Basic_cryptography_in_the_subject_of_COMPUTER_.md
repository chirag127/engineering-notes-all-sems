### Basic Terminologies for the Notes of the Unit 4 - Basic Cryptography in the Subject of Computer System Security

1. **Cryptography**: The practice of secure communication in the presence of third parties.
2. **Encryption**: The process of converting plaintext into ciphertext to prevent unauthorized access.
3. **Decryption**: The process of converting ciphertext back into plaintext.
4. **Cipher**: An algorithm used for encryption and decryption.
5. **Key**: A piece of information used by a cipher to encrypt and decrypt data.
6. **Symmetric Key Cryptography**: A type of cryptography where the same key is used for both encryption and decryption.
7. **Asymmetric Key Cryptography**: A type of cryptography where different keys are used for encryption and decryption.
8. **Public Key**: A key used for encryption in asymmetric key cryptography, which can be shared publicly.
9. **Private Key**: A key used for decryption in asymmetric key cryptography, which must be kept secret.
10. **Digital Signature**: A mathematical scheme used to verify the authenticity of a digital message or document.
11. **Hash Function**: A function that takes an input and produces a fixed-size output, used for verifying the integrity of data.
12. **Message Authentication Code (MAC)**: A code used to authenticate a message, ensuring that it has not been tampered with in transit.
