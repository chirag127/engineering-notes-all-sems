## Unit 5 - Internet Infrastructure

1. The Internet is a global network of interconnected computer networks that communicate using standardized communication protocols.
2. The Internet infrastructure consists of several components, including:
    - Internet Service Providers (ISPs): These are companies that provide Internet access to customers.
    - Network Access Points (NAPs): These are physical locations where ISPs connect to exchange traffic.
    - Internet Exchange Points (IXPs): These are physical locations where multiple ISPs connect to exchange traffic.
    - Backbone providers: These are companies that provide high-speed, long-distance connections between NAPs and IXPs.
3. The Internet infrastructure also includes the Domain Name System (DNS), which translates human-readable domain names (e.g., www.example.com) into IP addresses (e.g., 93.184.216.34).
4. The Internet Protocol (IP) is the primary protocol used for communication on the Internet. It is responsible for routing data packets between devices.
5. The Transmission Control Protocol (TCP) is another important protocol used on the Internet. It provides reliable, ordered, and error-checked delivery of data between applications.
6. The Internet infrastructure is constantly evolving to meet the growing demands of users. New technologies, such as 5G and the Internet of Things (IoT), are being developed to improve the speed, reliability, and security of the Internet.
