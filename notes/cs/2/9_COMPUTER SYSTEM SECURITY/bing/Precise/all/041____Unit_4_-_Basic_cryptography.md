# Unit 4 - Basic Cryptography

Cryptography is the practice of secure communication in the presence of third parties. It involves the use of mathematical algorithms to convert information into a code that can only be deciphered by someone who has the key to unlock it.

Some key concepts in basic cryptography include:

1. **Encryption** - the process of converting plaintext (readable data) into ciphertext (encoded data) using an encryption algorithm and a key.
2. **Decryption** - the reverse process of encryption, where ciphertext is converted back into plaintext using a decryption algorithm and a key.
3. **Symmetric-key cryptography** - a type of cryptography where the same key is used for both encryption and decryption.
4. **Asymmetric-key cryptography** - a type of cryptography where different keys are used for encryption and decryption. This is also known as public-key cryptography.
5. **Hashing** - the process of converting data of any size into a fixed-size string of characters using a mathematical function. This is commonly used for verifying the integrity of data.
6. **Digital signatures** - a method of verifying the authenticity and integrity of a digital message or document using asymmetric-key cryptography.

These are some of the basic concepts in cryptography. Cryptography is a vast and complex field with many advanced techniques and algorithms. It is an essential tool for ensuring the security and privacy of digital communication.
