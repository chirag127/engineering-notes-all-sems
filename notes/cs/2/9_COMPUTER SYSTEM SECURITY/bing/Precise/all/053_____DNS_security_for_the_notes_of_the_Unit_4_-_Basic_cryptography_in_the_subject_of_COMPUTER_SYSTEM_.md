# DNS Security

DNS security refers to the measures taken to secure the Domain Name System (DNS), which is a critical component of the internet infrastructure. DNS is responsible for translating human-readable domain names into IP addresses, which are used by computers to communicate with each other. Here are some key points to consider when studying DNS security for Unit 4 - Basic Cryptography in the subject of Computer System Security:

1. DNS is vulnerable to various types of attacks, including cache poisoning, denial of service (DoS), and man-in-the-middle (MITM) attacks.
2. DNSSEC (Domain Name System Security Extensions) is a set of protocols that adds a layer of security to the DNS by digitally signing DNS data to ensure its authenticity and integrity.
3. DNS over HTTPS (DoH) and DNS over TLS (DoT) are two protocols that encrypt DNS queries and responses, providing an additional layer of security and privacy.
4. DNS filtering is a technique used to block access to malicious or unwanted websites by preventing the resolution of their domain names.
5. Regular monitoring and updating of DNS records, as well as the implementation of security measures such as firewalls and intrusion detection systems, can help improve the overall security of the DNS.

These are some of the key points to consider when studying DNS security for Unit 4 - Basic Cryptography in the subject of Computer System Security. It is important to have a thorough understanding of these concepts in order to effectively secure the DNS and protect against potential attacks.
