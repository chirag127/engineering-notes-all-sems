### VM based isolation

- VM based isolation is a technique that uses hardware virtualization features to create and isolate a secure region of memory from the normal operating system .
- VM based isolation can be used to protect code integrity, data confidentiality, and system integrity from malicious or compromised software running on the same physical system .
- VM based isolation can also be used to enforce access control policies and prevent unauthorized access to sensitive data or management interfaces by isolating them from other users or processes.
- VM based isolation requires support from the hardware, the hypervisor, and the operating system. Some examples of VM based isolation technologies are:
  - Virtualization-based Security (VBS) in Windows 10 and Windows Server 2016, which uses Hyper-V to create a secure kernel and enable features such as Device Guard, Credential Guard, and Windows Defender Application Guard  .
  - Kernel-based Virtual Machine (KVM) in Linux, which allows users to run multiple virtual machines with different security levels and policies on the same host.
  - VMware vSphere, which provides a virtualization platform that supports security features such as encryption, firewall, and access control for virtual machines and their data.
