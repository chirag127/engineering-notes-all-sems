### Basic security problems for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

- Internet infrastructure is the collection of hardware, software, networks, and protocols that enable the communication and exchange of data over the internet.
- Internet infrastructure security is the protection of these components from unauthorized access, modification, or destruction by malicious actors or applications.
- Some of the basic security problems that affect the internet infrastructure are:

  - Ransomware attack: A ransomware attack is a type of malware that encrypts the victim's data and demands a ransom for its decryption. The attacker may also threaten to delete or expose the data if the ransom is not paid. Ransomware attacks can target individual devices, networks, or cloud services. Ransomware attacks can disrupt the availability and integrity of the internet infrastructure and cause financial and reputational losses to the victims.
  - Code injection: Code injection is a technique that exploits a vulnerability in a system or application to execute arbitrary code on the target. The code may be injected through user input, network packets, files, or other means. Code injection can allow the attacker to gain unauthorized access, steal or modify data, execute commands, or install malware. Code injection can compromise the confidentiality, integrity, and availability of the internet infrastructure and its services. 
  - Cross-site scripting (XSS): XSS is a type of code injection that targets web applications and browsers. XSS occurs when an attacker injects malicious code into a web page or a web request that is executed by the browser of another user. XSS can allow the attacker to steal cookies, session tokens, or other sensitive information, impersonate the user, or perform actions on their behalf. XSS can violate the confidentiality and integrity of the web application and its users. 
  - Data breach: A data breach is an unauthorized access or disclosure of sensitive or confidential data. Data breaches can occur due to hacking, phishing, insider threats, human errors, or system failures. Data breaches can expose personal, financial, or business information that can be used for identity theft, fraud, blackmail, or espionage. Data breaches can damage the confidentiality and reputation of the internet infrastructure and its users. 
  - Malware and virus infection: Malware and virus are types of malicious software that can infect and harm a system or application. Malware and virus can perform various malicious activities, such as stealing or deleting data, spying on the user, displaying unwanted ads, or hijacking the system resources. Malware and virus can spread through email attachments, downloads, removable media, or network connections. Malware and virus can affect the confidentiality, integrity, and availability of the internet infrastructure and its services. 
  - Distributed denial-of-service (DDoS) attack: A DDoS attack is a type of cyberattack that aims to overwhelm and disrupt a system or service by sending a large amount of traffic or requests from multiple sources. A DDoS attack can consume the bandwidth, memory, or processing power of the target, making it slow or unavailable for legitimate users. A DDoS attack can target any component of the internet infrastructure, such as servers, routers, or networks. A DDoS attack can impair the availability and performance of the internet infrastructure and its services. 
  - Credential stuffing attack: A credential stuffing attack is a type of brute-force attack that attempts to gain access to a system or service by using stolen or leaked usernames and passwords. The attacker may use automated tools or bots to try different combinations of credentials on multiple websites or applications. Credential stuffing attacks can exploit the reuse of passwords by users across different platforms. Credential stuffing attacks can compromise the confidentiality and integrity of the internet infrastructure and its users. 
  - Brute-force attack: A brute-force attack is a type of cyberattack that tries to guess a secret value, such as a password, encryption key, or PIN, by trying all possible combinations or using a dictionary of common values. The attacker may use automated tools or bots to speed up the process. Brute-force attacks can exploit the use of weak or predictable passwords by users or systems. Brute-force attacks can compromise the confidentiality and integrity of the internet infrastructure and its users.
