### Browser isolation

Browser isolation is a cybersecurity model that aims to physically isolate an internet user's browsing activity (and the associated cyber risks) away from their local networks and infrastructure. Browser isolation can help protect computers from malware, phishing, ransomware, and other web-based threats by preventing malicious code from reaching the endpoint device.

Some of the key concepts and benefits of browser isolation are:

- Browser isolation typically leverages virtualization or containerization technology to isolate the user's web browsing activity away from the endpoint device - significantly reducing the attack surface for rogue links and files.
- Browser isolation can be implemented in different ways, such as remote browser isolation, on-premise browser isolation, or client-side browser isolation, depending on the location and type of the isolated environment.
- Browser isolation can enhance the user experience by allowing them to access any website without compromising security or performance. Browser isolation can also support features such as file download, copy-paste, printing, and extensions, depending on the configuration and policy.
- Browser isolation can complement other security solutions, such as antivirus, firewall, web filtering, and encryption, by adding an additional layer of protection and defense in depth.

One example of browser isolation is Microsoft Edge browser isolation using Application Guard, which is a feature that uses hardware-based isolation to create a new instance of Windows 10 and Microsoft Edge at the hardware layer and open untrusted websites in that instance. This way, the user can browse the web safely without exposing their device, data, or identity to malicious actors. To enable this feature, the user needs to install Microsoft Defender Application Guard and configure the settings and policies accordingly.
