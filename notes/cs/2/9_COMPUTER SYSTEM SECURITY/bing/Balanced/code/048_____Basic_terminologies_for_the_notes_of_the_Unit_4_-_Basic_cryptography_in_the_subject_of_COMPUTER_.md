### Basic terminologies for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

- Cryptography: The science or art of designing and using methods to protect information from unauthorized access or modification. Cryptography involves the use of mathematical techniques, algorithms, and keys to transform plain text (the original message) into cipher text (the encrypted message) and vice versa .
- Cryptanalysis: The science or art of breaking cryptosystems, i.e., recovering the plain text from the cipher text without knowing the key or the algorithm used.
- Cryptology: The umbrella term that encompasses both cryptography and cryptanalysis.
- Algorithm: A set of rules or steps that defines how to perform a certain task, such as encryption or decryption. An algorithm can be expressed in various ways, such as a mathematical formula, a computer program, or a flowchart.
- Key: A piece of information that is used as an input to an algorithm to control the encryption or decryption process. A key can be a number, a word, a phrase, or a combination of these. The security of a cryptosystem depends on the secrecy and randomness of the key .
- Encryption: The process of transforming plain text into cipher text using an algorithm and a key. Encryption aims to ensure the confidentiality, integrity, and authenticity of the information .
- Decryption: The process of transforming cipher text back into plain text using an algorithm and a key. Decryption aims to recover the original information from the encrypted message .
- Symmetric-key cryptography: A type of cryptography where the same key is used for both encryption and decryption. The sender and the receiver must share the same key in advance and keep it secret from anyone else. Symmetric-key cryptography is also known as secret-key cryptography or single-key cryptography .
- Asymmetric-key cryptography: A type of cryptography where different keys are used for encryption and decryption. The sender and the receiver each have a pair of keys: a public key and a private key. The public key can be shared with anyone, while the private key must be kept secret. The sender encrypts the message with the receiver's public key, and the receiver decrypts it with their own private key. Asymmetric-key cryptography is also known as public-key cryptography or two-key cryptography .
- Hash: A function that takes an arbitrary input (such as a message, a file, or a password) and produces a fixed-length output (such as a number or a string) that uniquely identifies the input. A hash function is one-way, meaning that it is easy to compute the output from the input, but hard to find the input from the output. A hash function is also collision-resistant, meaning that it is hard to find two different inputs that produce the same output. Hash functions are used for various purposes, such as verifying the integrity of data, generating digital signatures, and storing passwords .
- Salt: A random value that is added to an input before hashing it. A salt is used to make the hash output more unpredictable and resistant to attacks, such as dictionary attacks or rainbow table attacks. A salt can be stored along with the hash output, as it is not a secret value .
- Backdoor: A method of bypassing the security or authentication of a system, such as a product, a computer system, an algorithm, etc. A backdoor can be explicit or implicit. An explicit backdoor is a deliberate feature or flaw that allows unauthorized access or control of the system. An implicit backdoor is an unintended weakness or vulnerability that can be exploited by an attacker. Backdoors can be inserted by the system's designers, developers, or operators, or by external parties, such as hackers, governments, or agencies.
