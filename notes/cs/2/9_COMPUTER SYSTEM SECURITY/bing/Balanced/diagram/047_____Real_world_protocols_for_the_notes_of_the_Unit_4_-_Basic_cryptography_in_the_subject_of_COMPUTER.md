### Real world protocols for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

- Cryptography is the science of securing information by transforming it into a form that only the intended recipients can understand and use.
- Cryptography is used in many real world applications, such as web APIs, user authentication, digital signatures, encryption, hashing, and blockchain.
- Some of the common cryptographic techniques and protocols are:

  - Symmetric-key cryptography: A method of encryption and decryption that uses the same secret key for both parties. Examples of symmetric-key algorithms are AES, DES, and RC4.
  - Asymmetric-key cryptography: A method of encryption and decryption that uses a pair of keys: a public key that can be shared with anyone, and a private key that must be kept secret. Examples of asymmetric-key algorithms are RSA, DSA, and ECC.
  - Hash functions: A function that maps any input to a fixed-length output, such that it is easy to compute the output given the input, but hard to find the input given the output, or to find two inputs that have the same output. Examples of hash functions are SHA-1, SHA-2, and SHA-3.
  - Digital signatures: A technique that allows a sender to prove the authenticity and integrity of a message by using their private key to generate a signature, and a receiver to verify the signature by using the sender's public key. Examples of digital signature schemes are RSA, DSA, and ECDSA.
  - Encryption: A technique that allows a sender to transform a message into a ciphertext that can only be decrypted by the intended receiver, who has the key. Examples of encryption schemes are AES, RSA, and ECC.
  - Hash-based message authentication code (HMAC): A technique that allows a sender and a receiver to authenticate a message by using a shared secret key and a hash function. Examples of HMAC schemes are HMAC-SHA1, HMAC-SHA2, and HMAC-SHA3.
  - Transport Layer Security (TLS): A protocol that provides secure communication over the internet by using encryption, authentication, and integrity protection. Examples of TLS versions are TLS 1.2 and TLS 1.3.
  - Secure Shell (SSH): A protocol that provides secure remote access to a server by using encryption, authentication, and integrity protection. Examples of SSH versions are SSH-1 and SSH-2.
  - Blockchain: A distributed ledger that records transactions in a secure and verifiable way by using cryptography, consensus, and peer-to-peer network. Examples of blockchain platforms are Bitcoin, Ethereum, and Hyperledger.
