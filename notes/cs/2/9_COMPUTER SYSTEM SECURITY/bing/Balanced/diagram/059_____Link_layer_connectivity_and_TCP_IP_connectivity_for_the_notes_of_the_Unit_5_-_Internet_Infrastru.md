# Link layer connectivity and TCP IP connectivity

- The link layer is the lowest layer of the TCP/IP model, which is a simplified version of the OSI model.
- The link layer is responsible for the physical and logical connection of devices on a local network segment, such as Ethernet, Wi-Fi, or Bluetooth.
- The link layer handles the transmission and reception of data frames, error detection and correction, media access control, and addressing.
- The link layer is also called the network access layer or the network interface layer in some contexts.
- The link layer is not a single protocol, but a collection of protocols and standards that operate on different types of links and networks.
- Some examples of link layer protocols are ARP, RARP, PPP, SLIP, and MAC protocols.
- The link layer is often compared with the combination of the physical layer and the data link layer in the OSI model, but they are not identical in scope and functionality.

- The TCP/IP model has four layers: link, internet, transport, and application.
- The internet layer is the second layer of the TCP/IP model, which is similar to the network layer in the OSI model.
- The internet layer is responsible for the routing and delivery of data packets across different networks, using the Internet Protocol (IP).
- The internet layer also provides other functions, such as fragmentation and reassembly, congestion control, and addressing.
- The internet layer is also called the network layer or the IP layer in some contexts.
- The internet layer is not a single protocol, but a collection of protocols and standards that operate on different types of networks and hosts.
- Some examples of internet layer protocols are IP, ICMP, IGMP, and IPsec.
