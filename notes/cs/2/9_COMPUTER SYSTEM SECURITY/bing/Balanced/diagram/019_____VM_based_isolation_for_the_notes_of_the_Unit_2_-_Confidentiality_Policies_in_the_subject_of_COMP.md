### VM based isolation

- VM based isolation is a technique that uses hardware virtualization features to create and isolate a secure region of memory from the normal operating system .
- VM based isolation can be used to implement security policies that require confidentiality, integrity, and availability of data and code in a computer system.
- VM based isolation can also be used to protect code integrity and prevent unauthorized modifications of the system software by malicious actors.
- VM based isolation can provide the following benefits for security :
  - It can reduce the attack surface and limit the exposure of sensitive data and code to potential threats.
  - It can enable dynamic and granular security controls that can be applied and updated without affecting the performance or availability of the system.
  - It can facilitate the detection and response to security incidents by providing visibility and isolation of the affected components.
  - It can support the compliance and audit requirements of various security standards and regulations.
