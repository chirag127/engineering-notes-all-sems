### Hijacking & Defense

- Hijacking is a type of network security attack in which the attacker takes control of computer systems, software programs and/or network communications  .
- Hijacking can be used for various malicious purposes, such as stealing data, compromising the system, disrupting the service, impersonating the user, or redirecting the traffic.
- Hijacking can occur at different layers of the network stack, such as the application layer, the transport layer, or the network layer.
- Some common types of hijacking attacks are:
  - Session hijacking: The attacker intercepts and takes over an existing communication session between two parties, such as a web browser and a web server.
  - URL hijacking: The attacker registers a domain name that is similar to a legitimate one, and tricks the user into visiting the fake website, which may contain malware or phishing content.
  - DNS hijacking: The attacker modifies the DNS records of a domain name, and redirects the user to a different IP address than the intended one.
  - IP hijacking: The attacker announces a false route to a network prefix, and attracts the traffic destined to that prefix to their own network.
- Some common defense techniques against hijacking are:
  - Encryption: The use of cryptographic algorithms to protect the confidentiality and integrity of the data and the communication session.
  - Authentication: The use of credentials, tokens, certificates, or biometrics to verify the identity of the parties involved in the communication session.
  - Authorization: The use of access control policies and mechanisms to grant or deny the access to the resources and services based on the identity and privileges of the parties.
  - Validation: The use of checksums, digital signatures, or certificates to verify the correctness and authenticity of the data and the communication session.
  - Monitoring: The use of tools and techniques to detect and analyze the network traffic and the system activities for any signs of hijacking or other anomalies.
