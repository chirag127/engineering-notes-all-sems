### Basic terminologies for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

- Cryptography: The science or art of designing and using methods to protect information from unauthorized access or modification. Cryptography involves the use of mathematical techniques, algorithms, and keys to transform plain text into cipher text and vice versa .
- Plain text: The original message or data that needs to be encrypted or decrypted. Plain text is also called clear text or cleartext  .
- Cipher text: The transformed message or data that results from applying an encryption algorithm to plain text. Cipher text is also called encrypted text or cryptogram  .
- Algorithm: A set of rules or steps that defines how to perform a specific task, such as encryption or decryption. An algorithm can be expressed in various ways, such as a mathematical formula, a computer program, or a flowchart .
- Key: A piece of information that is used as an input to an encryption or decryption algorithm, along with the plain text or cipher text. A key determines the output of the algorithm and acts as a secret parameter that controls the security of the cryptographic system  .
- Encryption: The process of transforming plain text into cipher text using an algorithm and a key. Encryption is used to protect the confidentiality, integrity, and authenticity of information from unauthorized access or modification  .
- Decryption: The process of transforming cipher text into plain text using an algorithm and a key. Decryption is used to recover the original information from the encrypted data  .
- Symmetric cryptography: A type of cryptography that uses the same key for both encryption and decryption. Symmetric cryptography is also called secret-key cryptography or private-key cryptography. Symmetric cryptography is fast and efficient, but requires a secure way to distribute and manage the keys  .
- Asymmetric cryptography: A type of cryptography that uses different keys for encryption and decryption. Asymmetric cryptography is also called public-key cryptography or two-key cryptography. Asymmetric cryptography does not require a secure way to distribute the keys, but is slower and more complex than symmetric cryptography  .
- Hash: A function that maps an arbitrary input to a fixed-length output, such that it is easy to compute the output from the input, but hard to find the input from the output or to find two inputs that produce the same output. A hash is also called a digest, a checksum, or a fingerprint. Hashes are used to verify the integrity and authenticity of data, but not to encrypt or decrypt it  .
- Salt: A random value that is added to the input of a hash function to make it more resistant to attacks, such as brute-force or dictionary attacks. A salt is also called a nonce or a randomizer. Salts are used to enhance the security of passwords, keys, and other sensitive data .
- Backdoor: A method of bypassing the security or authentication of a system, such as a product, a computer system, an algorithm, etc. Backdoors can be intentional or unintentional, and can be used for legitimate or malicious purposes. Backdoors can compromise the security and privacy of the system and its users .
