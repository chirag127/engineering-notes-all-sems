### DNS security

- DNS security is the practice of protecting DNS infrastructure from cyber attacks in order to keep it performing quickly and reliably .
- DNS infrastructure consists of DNS servers, DNS resolvers, DNS clients, and DNS records that map domain names to IP addresses and other information.
- DNS security incorporates a number of overlapping defenses, such as:
  - Establishing redundant DNS servers to prevent DNS outages and denial-of-service attacks.
  - Applying security protocols like DNSSEC to ensure the authenticity and integrity of DNS data.
  - Requiring rigorous DNS logging to monitor and analyze DNS traffic and detect anomalies.
  - Using DNS filtering to block malicious or unwanted websites and media.
  - Implementing DNS encryption to protect DNS queries and responses from eavesdropping and tampering.
- DNS security is important because DNS is a critical component of the internet and a common target of cyber attacks. DNS attacks can compromise the availability, performance, and security of websites and online services, as well as the privacy and safety of users. Some examples of DNS attacks are :
  - DNS spoofing: altering DNS records to redirect users to fake or malicious websites.
  - DNS hijacking: taking over DNS servers or resolvers to manipulate DNS traffic.
  - DNS tunneling: using DNS queries and responses to covertly transmit data or malware.
  - DNS amplification: exploiting DNS servers to generate large volumes of traffic and overwhelm a target.
  - DNS cache poisoning: inserting false or outdated DNS data into DNS resolvers or clients.
