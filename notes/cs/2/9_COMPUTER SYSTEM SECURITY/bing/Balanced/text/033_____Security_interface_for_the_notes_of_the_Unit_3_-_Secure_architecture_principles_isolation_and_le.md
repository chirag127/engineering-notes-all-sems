### Security interface for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

- The security interface is a set of user interface elements that provide access to security features such as authorization, access to digital certificates, and access to items in keychains.
- Secure architecture principles are design guidelines that aim to enhance the security of a system by applying concepts such as isolation, least privilege, defense in depth, and simplicity.
- Isolation is the principle of separating different components or processes of a system so that they cannot interfere with each other or access each other's resources without proper authorization.
- Least privilege is the principle of granting the minimum amount of privileges or permissions to each user or process that are necessary to perform their tasks, and no more .
- Web security landscape is the overview of the threats and vulnerabilities that affect web applications and web users, and the goals and mechanisms to protect them .

Some points to remember are:

- Isolation can be achieved by using techniques such as virtualization, sandboxing, encryption, and firewalls.
- Least privilege can be enforced by using techniques such as role-based access control, mandatory access control, and discretionary access control.
- Web security goals include confidentiality, integrity, availability, authentication, authorization, and non-repudiation .
- Web security mechanisms include encryption, digital signatures, certificates, HTTPS, SSL/TLS, cookies, and web application firewalls .
- Azure guidance for secure isolation provides best practices and recommendations for designing and deploying secure cloud solutions using Azure services and features.
