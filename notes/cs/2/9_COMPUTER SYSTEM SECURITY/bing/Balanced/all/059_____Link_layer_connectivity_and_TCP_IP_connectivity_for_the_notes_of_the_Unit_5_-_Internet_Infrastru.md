# Link layer connectivity and TCP IP connectivity

- Link layer connectivity refers to the ability of devices to communicate with each other over a physical or logical link, such as a cable, a wireless network, or a switch.
- Link layer protocols are responsible for encapsulating data packets into frames, adding headers and trailers that contain information such as source and destination addresses, error detection and correction codes, and flow control signals.
- Link layer protocols also perform functions such as media access control, which determines how devices share the link bandwidth, and error detection and correction, which ensures the integrity of the transmitted data.
- Link layer protocols operate only on the local network segment, and do not involve routing or forwarding of packets to other networks.
- Examples of link layer protocols are Ethernet, Wi-Fi, Bluetooth, and PPP.
- The link layer of the TCP/IP model is often compared directly with the combination of the data link layer and the physical layer in the Open Systems Interconnection (OSI) protocol stack, although they are not identical.

- TCP/IP connectivity refers to the ability of devices to communicate with each other over the Internet or other IP-based networks, using the Transmission Control Protocol (TCP) and the Internet Protocol (IP).
- TCP/IP protocols are responsible for dividing data into packets, adding headers that contain information such as source and destination IP addresses, port numbers, sequence numbers, and checksums, and reassembling the packets at the destination.
- TCP/IP protocols also perform functions such as routing, which determines the best path for packets to reach their destination, and congestion control, which adjusts the sending rate of packets according to the network conditions.
- TCP/IP protocols operate on different layers of the TCP/IP model, which is a simplified version of the OSI model. The TCP/IP model consists of four layers: the network access layer, the internet layer, the transport layer, and the application layer.
- Examples of TCP/IP protocols are IP, TCP, UDP, ICMP, DNS, HTTP, and FTP.
