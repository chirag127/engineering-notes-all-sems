# Basic security problems for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

- Internet infrastructure is the collection of hardware, software, networks, and protocols that enable the communication and exchange of data over the internet.
- Internet infrastructure security is the protection of these components from unauthorized access, modification, or destruction by malicious actors or applications.
- Internet infrastructure security is essential for ensuring the availability, integrity, and confidentiality of the data and services that rely on the internet.
- Some of the basic security problems that affect the internet infrastructure are:

  - Ransomware attack: A ransomware attack is a type of malware that encrypts the victim's data and demands a ransom for the decryption key. Ransomware can affect individual devices, servers, or entire networks, and can cause significant disruption and financial loss .
  - Code injection: Code injection is a technique that exploits a vulnerability in a software application or system to execute arbitrary code on the target. Code injection can allow an attacker to gain remote access, execute commands, steal data, or cause damage to the system .
  - Cross-site scripting (XSS): XSS is a type of web application vulnerability that allows an attacker to inject malicious code into a web page that is viewed by other users. XSS can be used to steal cookies, session tokens, or other sensitive information, or to perform actions on behalf of the victim .
  - Data breach: A data breach is an unauthorized access or disclosure of confidential or personal data. Data breaches can occur due to hacking, phishing, insider threats, or human error, and can result in identity theft, fraud, or reputational damage .
  - Malware and virus infection: Malware and virus are types of malicious software that can infect a device, system, or network and perform harmful actions. Malware and virus can steal data, damage files, consume resources, or create backdoors for further attacks  .
  - Distributed denial-of-service (DDoS) attack: A DDoS attack is a type of cyberattack that aims to overwhelm a target system or service with a large volume of traffic or requests from multiple sources. DDoS attacks can cause slowdowns, crashes, or unavailability of the target, and can affect the performance or availability of other systems or services that depend on it .
  - Credential stuffing attack: A credential stuffing attack is a type of brute-force attack that uses stolen or leaked usernames and passwords to gain access to multiple accounts or services. Credential stuffing attacks rely on the fact that many users reuse the same credentials across different platforms, and can lead to account takeover, identity theft, or fraud .
  - Brute-force attack: A brute-force attack is a type of cyberattack that tries to guess a password or encryption key by systematically trying all possible combinations or using a dictionary of common passwords. Brute-force attacks can take a long time to succeed, but can be effective against weak or default passwords or keys  .

- Some of the possible solutions or countermeasures for these security problems are:

  - Ransomware attack: To prevent ransomware attacks, users and organizations should use antivirus software, update their systems and applications regularly, avoid opening suspicious attachments or links, and backup their data frequently. To recover from ransomware attacks, users and organizations should not pay the ransom, but instead try to restore their data from backups or use decryption tools if available .
  - Code injection: To prevent code injection attacks, developers and administrators should validate and sanitize user input, use parameterized queries or prepared statements, implement secure coding practices, and apply patches and updates to their software and systems. To detect and respond to code injection attacks, users and organizations should use intrusion detection and prevention systems, monitor their logs and network traffic, and isolate and remediate the affected systems .
  - Cross-site scripting (XSS): To prevent XSS attacks, developers and administrators should encode or escape user input, use secure HTTP headers, implement content security policy, and use frameworks and libraries that prevent XSS by default.
