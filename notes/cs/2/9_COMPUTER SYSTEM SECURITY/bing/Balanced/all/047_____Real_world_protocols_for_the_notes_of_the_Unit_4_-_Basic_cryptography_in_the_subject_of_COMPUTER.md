# Real world protocols for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

- Cryptography is the science of securing information by transforming it into a form that only the intended recipients can understand and use.
- Cryptography is used to protect the confidentiality, integrity, and authenticity of data and communications in various domains, such as web, email, e-commerce, cloud, blockchain, and IoT.
- Cryptography relies on two types of components: cryptographic primitives and cryptographic protocols.
- Cryptographic primitives are the basic building blocks of cryptography, such as encryption, decryption, hashing, digital signatures, and key exchange.
- Cryptographic protocols are the rules and procedures that define how cryptographic primitives are used to achieve a specific security goal, such as secure communication, authentication, or digital currency.
- Some examples of real world protocols that use cryptography are:

  - HTTPS: HyperText Transfer Protocol Secure is a protocol that enables secure web browsing by encrypting the data exchanged between a web browser and a web server using TLS (Transport Layer Security).
  - TLS: Transport Layer Security is a protocol that provides secure communication over a network by establishing a shared secret key between two parties using a key exchange algorithm, and then encrypting and authenticating the data using a symmetric encryption algorithm and a message authentication code (MAC).
  - SSH: Secure Shell is a protocol that allows secure remote access to a computer system by authenticating the user and the host using public-key cryptography and digital signatures, and then encrypting the data using a symmetric encryption algorithm.
  - PGP: Pretty Good Privacy is a protocol that allows secure email communication by encrypting and signing the email messages using public-key cryptography and digital signatures.
  - Bitcoin: Bitcoin is a protocol that enables a decentralized digital currency system by using cryptographic techniques such as hashing, digital signatures, and proof-of-work to create and verify transactions and blocks on a distributed ledger called the blockchain.
