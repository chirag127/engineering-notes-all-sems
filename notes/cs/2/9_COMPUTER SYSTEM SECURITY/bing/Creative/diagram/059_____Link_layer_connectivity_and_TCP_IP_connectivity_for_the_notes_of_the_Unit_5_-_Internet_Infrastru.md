### Link layer connectivity and TCP IP connectivity

- The link layer is the lowest layer of the TCP/IP model, which is a simplified version of the OSI model.
- The link layer is responsible for the physical and logical connection of devices on a local network segment, such as Ethernet, Wi-Fi, or Bluetooth.
- The link layer handles the transmission and reception of data frames, which are the basic units of communication on a network.
- The link layer also provides error detection, flow control, and media access control (MAC) functions, such as addressing, framing, and collision avoidance.
- The link layer is sometimes called the network access layer or the network interface layer, as it interfaces with the network hardware and the device drivers.
- The link layer is not concerned with routing or addressing beyond the local network, as those functions are performed by higher layers of the TCP/IP model, such as the internet layer and the transport layer.
- The internet layer is the second layer of the TCP/IP model, which provides the logical addressing and routing functions for data packets across different networks.
- The internet layer uses the Internet Protocol (IP) to assign unique addresses to each device on a network, and to route packets based on their destination addresses.
- The internet layer also handles the fragmentation and reassembly of packets, as well as the error reporting and control messages, using protocols such as ICMP and IGMP.
- The internet layer is sometimes called the network layer, as it connects different networks together using routers and gateways.
- The transport layer is the third layer of the TCP/IP model, which provides the reliable and efficient delivery of data between applications on different devices.
- The transport layer uses protocols such as TCP and UDP to establish connections, segment and reassemble data, and provide error detection and correction, flow control, and congestion control.
- The transport layer also provides port numbers, which identify the specific applications or services that are sending or receiving data on a device.
- The transport layer is sometimes called the host-to-host layer, as it enables communication between hosts on different networks.
