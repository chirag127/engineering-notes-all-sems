### DNS revisited

- DNS stands for Domain Name System, a system that translates human-readable domain names, such as www.example.com, into numerical IP addresses, such as 192.0.2.1, that computers use to communicate with each other over the internet.
- DNS operates in a hierarchical and distributed manner, with different levels of servers responsible for different parts of the domain name space. The root servers are at the top of the hierarchy, followed by the top-level domain (TLD) servers, such as .com or .org, and then the authoritative servers, which host the records for a specific domain, such as example.com.
- DNS also supports various types of records, such as A records (for IPv4 addresses), AAAA records (for IPv6 addresses), MX records (for mail servers), CNAME records (for aliases), NS records (for name servers), and TXT records (for arbitrary text information).
- DNS queries and responses are typically sent over UDP on port 53, but can also use TCP in some cases, such as when the response is too large to fit in a single UDP packet, or when DNSSEC is used to provide security and integrity for DNS data.
- DNS resolvers, also called recursive resolvers, are servers that receive DNS queries from clients, such as web browsers or other applications, and track down the IP addresses for the requested hostnames by contacting the appropriate servers in the DNS hierarchy.
- DNS caching is a technique that allows DNS resolvers and clients to store the results of previous DNS queries for a certain period of time, called the time to live (TTL), to reduce the number of DNS queries and improve the performance and efficiency of the DNS system.
- DNS spoofing is an attack that involves sending fake DNS responses to a client or a resolver, with the aim of redirecting the traffic to a malicious website or server. DNS spoofing can be done by compromising a DNS server, intercepting and modifying DNS packets on the network, or exploiting a vulnerability in the DNS protocol or implementation.
- DNSSEC is an extension of the DNS protocol that adds digital signatures to DNS records, to ensure that the DNS data is authentic and has not been tampered with. DNSSEC requires the cooperation of all the servers in the DNS hierarchy, from the root servers to the authoritative servers, to create and validate the signatures.
- DNS over HTTPS (DoH) and DNS over TLS (DoT) are protocols that encrypt the DNS queries and responses between the clients and the resolvers, using HTTPS and TLS respectively, to protect the privacy and security of the DNS traffic. DoH and DoT prevent eavesdropping, modification, and censorship of the DNS data by third parties, such as internet service providers or governments.
- DNS rebinding is an attack that exploits the dynamic nature of DNS to bypass the same-origin policy of web browsers, which prevents scripts from different domains from accessing each other's data. DNS rebinding works by changing the IP address of a domain name after the browser has loaded a malicious script from that domain, and then tricking the browser into sending requests to the new IP address, which belongs to a local or internal network device, such as a router or a printer.
