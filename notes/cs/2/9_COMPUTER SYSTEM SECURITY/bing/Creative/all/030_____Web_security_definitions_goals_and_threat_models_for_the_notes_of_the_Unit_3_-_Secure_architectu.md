# Web security definitions, goals and threat models

Web security is the practice of protecting web applications and services from unauthorized access, misuse, modification, or destruction. Web security aims to achieve the following goals:

- Confidentiality: ensuring that only authorized parties can access the data or resources on the web.
- Integrity: ensuring that the data or resources on the web are not altered or corrupted by unauthorized parties.
- Availability: ensuring that the data or resources on the web are accessible and functional for authorized parties.
- Accountability: ensuring that the actions and events on the web are traceable and auditable by authorized parties.

Threat modeling is a method of analyzing the web security risks and designing countermeasures to prevent or mitigate them. Threat modeling involves the following steps:

- Identify the assets: determine what data or resources are valuable and need to be protected on the web.
- Identify the threats: determine what potential or actual attacks or incidents can compromise the web security goals.
- Identify the vulnerabilities: determine what weaknesses or flaws in the web system or application can be exploited by the threats.
- Assess the risks: determine the likelihood and impact of the threats exploiting the vulnerabilities and violating the web security goals.
- Prioritize the countermeasures: determine what actions or controls can be implemented to reduce or eliminate the risks.

There are different methods and frameworks for conducting threat modeling, such as:

- STRIDE: a mnemonic that categorizes the threats into six types: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, and Elevation of privilege.
- ASF: an application security framework that defines threat categories such as Auditing & Logging, Authentication, Authorization, Configuration Management, Data Protection in Storage and Transit, Data Validation, and Exception Management.
- OWASP: an open source community that provides resources and tools for web security, such as the OWASP Top 10, which lists the most common web application vulnerabilities and risks.
