# Basic security problems for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

Internet infrastructure is the collection of hardware, software, networks, and protocols that enable the communication and exchange of data over the internet. Internet infrastructure includes routers, switches, servers, firewalls, DNS, web servers, email servers, and other components that facilitate the functioning of the internet.

Internet infrastructure is vulnerable to various security problems that can compromise the availability, integrity, and confidentiality of the data and services on the internet. Some of the basic security problems for the internet infrastructure are:

- **Ransomware attack**: This is a type of malware that encrypts the data on the victim's system and demands a ransom for the decryption key. Ransomware can affect the internet infrastructure by targeting servers, databases, or cloud services that store or host critical data or applications. Ransomware can cause data loss, downtime, and financial damage to the victims.

- **Code injection (Remote code execution)**: This is a type of attack that exploits a vulnerability in a web application or a server to execute arbitrary code on the target system. Code injection can allow the attacker to gain access to the system, steal data, install malware, or perform other malicious actions. Code injection can affect the internet infrastructure by targeting web servers, web applications, or other components that process user input or dynamic content .

- **Cross-site scripting (XSS)**: This is a type of attack that injects malicious scripts into a web page that is viewed by other users. XSS can allow the attacker to steal cookies, session tokens, or other sensitive information from the users, or perform actions on their behalf. XSS can affect the internet infrastructure by targeting web servers, web applications, or other components that generate or display web pages .

- **Data breach**: This is a type of attack that exposes or steals confidential or sensitive data from a system or a network. Data breach can occur due to various causes, such as hacking, phishing, insider threat, or human error. Data breach can affect the internet infrastructure by targeting servers, databases, cloud services, or other components that store or transmit data. Data breach can cause reputational damage, legal liability, or regulatory compliance issues to the victims .

- **Malware and virus infection**: This is a type of attack that installs malicious software or code on a system or a network. Malware and virus can perform various functions, such as spying, stealing, deleting, or encrypting data, or disrupting the normal operation of the system or the network. Malware and virus can affect the internet infrastructure by targeting servers, routers, switches, firewalls, or other components that run software or code. Malware and virus can cause performance degradation, data loss, or system compromise to the victims .

- **DDoS attack**: This is a type of attack that overwhelms a system or a network with a large amount of traffic or requests, making it unable to respond to legitimate requests or perform its intended function. DDoS can affect the internet infrastructure by targeting servers, routers, switches, firewalls, DNS, or other components that provide or rely on network connectivity. DDoS can cause service disruption, denial of service, or network congestion to the victims .

- **Credential stuffing attack**: This is a type of attack that uses stolen or leaked usernames and passwords to gain access to multiple accounts or services on the internet. Credential stuffing can affect the internet infrastructure by targeting web servers, web applications, or other components that require authentication or authorization. Credential stuffing can cause account takeover, identity theft, or fraud to the victims .

- **Brute force attack**: This is a type of attack that tries to guess the password or the encryption key of a system or a service by trying different combinations of characters or values. Brute force can affect the internet infrastructure by targeting servers, routers, switches, firewalls, or other components that use password or encryption for security. Brute force can cause unauthorized access, data theft, or system compromise to the victims .
