### Other issues in access control for computer system security

- Access control is the process of granting or denying access to resources based on the identity and attributes of the requester and the policies and rules defined by the system owner or administrator.
- Access control systems can have various issues that affect their security, functionality, and usability. Some of these issues are:

  - **Not secure enough**: Access control systems can have vulnerabilities that allow unauthorized access, such as weak passwords, default settings, misconfiguration, outdated software, or lack of encryption. These vulnerabilities can be exploited by attackers to bypass or compromise the access control system and gain access to sensitive or critical resources. To prevent this, access control systems should be properly set up, updated, and monitored, and use strong authentication and encryption methods.

  - **Keycards lack true authorization**: Keycards are a common method of authorization in access control systems, but they have some limitations and drawbacks. Keycards can be lost, stolen, duplicated, or shared, which can result in unauthorized access or identity fraud. Keycards also do not verify the identity of the holder, only the possession of the card. To overcome this, access control systems should use other factors of authentication, such as biometrics, PINs, or tokens, or implement anti-passback or anti-tailgating features to prevent unauthorized entry.

  - **Improper setup**: Access control systems can be improperly set up, which can cause errors, malfunctions, or security breaches. For example, access control systems can have incorrect or inconsistent policies, rules, or permissions, which can result in over- or under-privileged access, or conflicts or contradictions in access decisions. Access control systems can also have faulty or incompatible hardware or software components, which can affect their performance or reliability. To avoid this, access control systems should be carefully designed, tested, and validated, and follow best practices and standards for access control.

  - **Lack of management**: Access control systems can be poorly managed, which can result in inefficiency, inconsistency, or insecurity. For example, access control systems can have outdated or inaccurate information, such as user accounts, roles, or attributes, which can affect the accuracy or validity of access decisions. Access control systems can also have insufficient or excessive auditing, logging, or reporting, which can affect the accountability or transparency of access activities. To improve this, access control systems should have regular and effective management, such as updating, reviewing, and auditing the access control data, policies, and events.

  - **Cyber risks**: Access control systems can be exposed to cyber risks, such as hacking, malware, denial-of-service, or data breaches, which can compromise their integrity, availability, or confidentiality. For example, attackers can exploit the vulnerabilities or weaknesses of the access control system or its components, such as devices, networks, or servers, to gain unauthorized access, disrupt the access control service, or steal or tamper with the access control data. To mitigate this, access control systems should have adequate cyber security measures, such as firewalls, antivirus, encryption, or backup, and follow the cyber security best practices and guidelines.
