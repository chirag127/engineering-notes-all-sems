### Real world protocols for the notes of the Unit 4 - Basic cryptography in the subject of COMPUTER SYSTEM SECURITY

- Cryptography is the science of securing information by transforming it into a form that only the intended recipients can understand and use.
- Cryptography is used in many real world applications, such as web APIs, user authentication, digital signatures, encryption, hashing, and blockchain.
- Some of the cryptographic techniques that are commonly used in real world protocols are:

  - Symmetric-key cryptography: This is a method of encryption and decryption that uses the same secret key for both operations. The key must be shared securely between the communicating parties. Examples of symmetric-key algorithms are AES, DES, and RC4.
  - Asymmetric-key cryptography: This is a method of encryption and decryption that uses a pair of keys: a public key and a private key. The public key can be shared with anyone, while the private key must be kept secret. The public key can be used to encrypt messages that can only be decrypted by the private key, and vice versa. Examples of asymmetric-key algorithms are RSA, DSA, and ECC.
  - Hash functions: These are mathematical functions that map any input to a fixed-length output, called a hash or a digest. Hash functions are one-way, meaning that it is easy to compute the hash from the input, but hard to find the input from the hash. Hash functions are used to verify the integrity and authenticity of data, such as passwords, digital signatures, and blockchain transactions. Examples of hash functions are SHA-1, SHA-2, and SHA-3.
  - Digital signatures: These are methods of proving the identity and authenticity of a message sender, using asymmetric-key cryptography and hash functions. The sender signs a message by computing a hash of the message and encrypting it with their private key. The receiver verifies the signature by decrypting it with the sender's public key and comparing it with the hash of the message. Examples of digital signature schemes are RSA, DSA, and ECDSA.
  - Encryption: This is a method of transforming plaintext (the original message) into ciphertext (the encrypted message) using a key and an algorithm. Encryption is used to protect the confidentiality and privacy of data, such as web traffic, emails, and files. Examples of encryption algorithms are AES, DES, and RSA.
  - Decryption: This is a method of transforming ciphertext (the encrypted message) back into plaintext (the original message) using a key and an algorithm. Decryption is used to recover the original data from the encrypted data. Examples of decryption algorithms are AES, DES, and RSA.
