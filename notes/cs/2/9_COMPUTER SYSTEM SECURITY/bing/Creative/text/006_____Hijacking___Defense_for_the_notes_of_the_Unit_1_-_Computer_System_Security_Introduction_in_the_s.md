### Hijacking & Defense

- Hijacking is a type of network security attack in which the attacker takes control of computer systems, software programs and/or network communications  .
- Hijacking can be used to steal data, compromise the system, disrupt the service, impersonate the user, or manipulate the traffic.
- Hijacking can occur in various ways, such as:
  - Session hijacking: The attacker intercepts and takes over an existing network session between two parties, such as a web browser and a web server.
  - URL hijacking: The attacker registers a domain name that is similar to a legitimate one, and redirects the users to a malicious website, such as www.gooogle.com instead of www.google.com.
  - DNS hijacking: The attacker modifies the DNS records of a domain name, and redirects the users to a different IP address, such as 192.168.1.1 instead of 216.58.217.142 for www.google.com.
  - Browser hijacking: The attacker installs a malicious software or extension on the user's browser, and changes the browser settings, such as the homepage, the search engine, or the toolbar.
  - Ransomware hijacking: The attacker encrypts the user's files or locks the user's screen, and demands a ransom to restore the access, such as WannaCry or CryptoLocker.
- Defense against hijacking can be achieved by using various techniques, such as:
  - Encryption: The user can encrypt the data and the communication channels, such as using HTTPS, SSL, or VPN, to prevent the attacker from reading or modifying the traffic.
  - Authentication: The user can verify the identity and the integrity of the parties and the data, such as using passwords, digital signatures, or certificates, to prevent the attacker from impersonating or tampering with the traffic.
  - Firewall: The user can filter the incoming and outgoing network traffic, such as using rules, policies, or proxies, to prevent the attacker from accessing or injecting the traffic.
  - Antivirus: The user can scan and remove the malicious software or extensions from the computer system, such as using malware detection, removal, or prevention tools, to prevent the attacker from installing or executing the hijacking programs.
  - Awareness: The user can be aware of the potential hijacking threats and the best practices, such as using strong passwords, updating the software, avoiding suspicious links or attachments, or checking the domain names, to prevent the attacker from exploiting the vulnerabilities or tricking the user.
