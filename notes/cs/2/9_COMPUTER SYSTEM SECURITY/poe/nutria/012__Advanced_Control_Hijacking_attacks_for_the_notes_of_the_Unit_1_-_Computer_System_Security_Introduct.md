
### Advanced Control Hijacking attacks for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY

1. Control hijacking is a type of attack in which malicious code is injected into a system to gain access to system resources and data. 
2. This type of attack is commonly used to gain access to sensitive information, such as passwords, credit card numbers, or other confidential data. 
3. Control hijacking attacks can be used to gain access to user accounts, modify system settings, or even take control of the entire system. 
4. Attackers can use various techniques to gain access to a system, such as code injection, buffer overflow, and SQL injection. 
5. The most common form of control hijacking is known as a "return-oriented programming" attack, which involves injecting malicious code into a system to gain control over its execution. 
6. Attackers can also use social engineering techniques to gain access to a system, such as phishing or spear phishing. 
7. In order to protect against control hijacking attacks, organizations should implement secure coding practices, use encryption and authentication measures, and regularly monitor system activity for suspicious activity.
