

### Web Security Definitions, Goals and Threat Models

* Web security is the application of security measures to protect websites and web applications from malicious attacks. It involves preventing unauthorized access to data and functions, protecting against malicious code and ensuring the integrity of data and functions.
* The goal of web security is to ensure that websites and web applications are safe, secure and available to authorized users.
* Web security threat models are used to identify, assess and mitigate risks associated with websites and web applications. Threat models help organizations identify potential threats and develop effective security measures to protect their websites and web applications.
* Secure architecture principles are used to design secure websites and web applications. These principles include isolation, least privilege, defense in depth, secure communications, secure coding and system hardening.
* Isolation is used to ensure that different components of a website or web application are isolated from each other. This helps to limit the impact of malicious attacks on a single component.
* Least privilege is used to ensure that users are only granted the minimum level of access necessary to perform their tasks. This helps to reduce the risk of unauthorized access to sensitive data or functions.
