
### Routing Security for the Notes of the Unit 5 - Internet Infrastructure in the Subject of COMPUTER SYSTEM SECURITY

1. Routing security is a key component of internet infrastructure. It involves the secure transmission of data between two or more points on a network.
2. Routers are responsible for determining the best path for data transmission, and they must be configured with the appropriate security measures to ensure that the data is protected from malicious actors.
3. Network address translation (NAT) is a common security measure used in routing security. NAT enables the router to hide the internal IP addresses of computers on the network from external sources.
4. Access control lists (ACLs) are also used to ensure that only authorized users can access the network. ACLs can be configured on routers to limit access to specific IP addresses or ports.
5. Firewalls are another important security measure used in routing security. Firewalls can be configured to block certain types of traffic or to allow only specific types of traffic.
6. Encryption is also used to protect data transmission. Encryption can be used to encrypt data in transit, or to encrypt data at rest.
7. Network monitoring tools such as intrusion detection systems (IDS) and intrusion prevention systems (IPS) can be used to detect and block malicious traffic on the network.
8. Secure Socket Layer (SSL) and Transport Layer Security (TLS) are both protocols used to provide secure communication between two or more points on the network.
9. Finally, it is important to keep routers and other network devices up to date with the latest security patches and updates. This will help to ensure that the network is protected from the latest threats.
