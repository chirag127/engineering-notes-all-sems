

### Secure Development for Unit 3 - Secure Architecture Principles Isolation and Least Privilege

1. Secure architecture principles are based on the idea of least privilege, which means that users, processes, and systems should have the least amount of privileges necessary to perform their tasks.

2. Isolation is a security principle that ensures that different components of a system are separated from each other, so that if one component is compromised, the other components are not affected.

3. Least privilege requires that users, processes and systems are granted only the minimum amount of access necessary to perform their tasks. This helps to reduce the risk of malicious users or processes gaining access to sensitive data.

4. Access control is an important security principle that ensures that only authorized users are allowed to access certain resources. Access control can be implemented through authentication, authorization, and auditing.

5. Security policies are documents that outline the security requirements for a system. Security policies should be regularly reviewed and updated to ensure that they are up to date with the latest security practices.

6. Security testing is the process of testing a system to identify potential security vulnerabilities. Security testing should be conducted regularly to ensure that a system is secure.
