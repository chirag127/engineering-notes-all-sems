
### Introduction for the notes of the Unit 1 - Computer System Security Introduction

1. Computer system security is a broad term that encompasses the protection of computer systems from malicious attacks, unauthorized access, and data loss or corruption.
2. It includes both physical security, such as locks and firewalls, and logical security, such as encryption and authentication.
3. Physical security is the protection of the physical components of a computer system, such as the hardware, cables, and other components.
4. Logical security is the protection of the data and information stored on the computer system, such as passwords and user accounts.
5. Security measures must be implemented to protect against unauthorized access to the computer system, as well as to ensure the integrity of the data stored on the system.
6. Security measures must also be in place to protect against malicious attacks, such as viruses, worms, and Trojan horses.
7. Computer system security is an important part of any organization's security strategy.
8. It is important to maintain the security of the computer system in order to protect the data and information stored on the system, as well as to protect against unauthorized access and malicious attacks.
