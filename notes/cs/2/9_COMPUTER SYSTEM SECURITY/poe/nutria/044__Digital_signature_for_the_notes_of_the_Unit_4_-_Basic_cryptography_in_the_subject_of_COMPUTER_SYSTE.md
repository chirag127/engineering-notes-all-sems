
### Digital Signature for the Notes of Unit 4 - Basic Cryptography in Computer System Security

1. A digital signature is a mathematical technique used to validate the authenticity and integrity of a message, software or digital document.
2. It is used to verify that the sender of the message is who they claim to be and that the message has not been modified since it was sent.
3. Digital signatures are based on public key cryptography, which uses two different keys: a public key and a private key.
4. The public key is used to encrypt the message and the private key is used to decrypt it.
5. The sender of the message uses their private key to sign the message and the recipient of the message uses the sender's public key to verify the signature.
6. The digital signature also ensures that the message has not been altered in transit, as any change to the message will result in an invalid signature.
7. Digital signatures are used in a variety of applications, such as financial transactions, software distribution, and secure communications.
8. In order to be secure, digital signatures must be generated using a secure algorithm and the private key must be kept secure.
