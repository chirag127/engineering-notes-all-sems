

### Defense against Control Hijacking - Run-time Defenses

1. Control Hijacking is a type of attack in which an attacker gains control of a system by exploiting a vulnerability.
2. To prevent Control Hijacking, it is important to use run-time defenses.
3. Run-time defenses are techniques that are used to detect and respond to malicious activities during runtime.
4. Common run-time defenses include address space layout randomization (ASLR), data execution prevention (DEP), and code signing.
5. ASLR is a technique that randomizes the memory layout of a system, making it difficult for an attacker to predict the location of sensitive data.
6. DEP is a technique that prevents malicious code from executing in memory, by marking certain memory regions as non-executable.
7. Code signing is a technique that verifies the authenticity of code by digitally signing it with a cryptographic key.
8. By using these run-time defenses, it is possible to protect a system from Control Hijacking attacks.
