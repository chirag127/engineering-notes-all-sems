
### Certificates for the Notes of the Unit 4 - Basic Cryptography in the Subject of Computer System Security

1. A certificate is a digital document that verifies the identity of an individual or organization. It contains information such as the name of the issuer, the identity of the subject, an expiration date, and a digital signature.

2. Certificates are used to secure communication between two parties by providing a secure way to authenticate the identity of the sender and receiver. They can also be used to encrypt data and ensure its integrity.

3. Cryptography is the practice of using mathematical algorithms to protect data. It is used to protect data from being accessed or modified by unauthorized parties.

4. Cryptographic techniques are used to create certificates. These techniques include public key cryptography, digital signatures, and hashing algorithms.

5. Public key cryptography is used to create digital certificates. It uses two keys, a public key and a private key. The public key is used to encrypt data, while the private key is used to decrypt it.

6. Digital signatures are used to verify the authenticity of a certificate. They are created using the private key associated with the certificate.

7. Hashing algorithms are used to create a unique identifier for a certificate. This identifier is used to ensure that the certificate has not been tampered with or modified.

8. Certificates are used in a variety of applications, including web browsers, secure email, and secure networks. They are also used to secure financial transactions and protect user data.
