
### More on Confinement Techniques
Confinement techniques are used to restrict access to data and resources within a computer system. This is done to protect the system from malicious actors and to maintain the confidentiality of sensitive data. 

1. **Mandatory Access Control (MAC):** This is a type of access control that uses labels to define the security level of an object and users. This ensures that users can only access objects with a security level equal to or less than their own. 

2. **Discretionary Access Control (DAC):** This is a type of access control based on the identity of the user. It allows the owner of a file or resource to specify which users can access it.

3. **Role-Based Access Control (RBAC):** This is a type of access control based on the roles of users in an organization. It allows an administrator to assign different levels of access to different roles.

4. **Rule-Based Access Control (RBAC):** This is a type of access control that uses rules to define the access rights of users. These rules are based on the user's identity, role, and other attributes.

5. **Capability-Based Access Control (CBAC):** This is a type of access control based on the capabilities of users. It allows a user to access an object only if they have the necessary capability to do so.
