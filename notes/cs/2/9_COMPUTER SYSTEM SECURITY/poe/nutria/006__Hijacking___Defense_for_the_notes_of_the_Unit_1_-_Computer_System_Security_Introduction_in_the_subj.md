
### Hijacking & Defense

1. Hijacking is a type of attack that takes control of a computer system or network without the user’s permission. It can be done through a variety of means, such as exploiting a vulnerability in the system or using malicious software.

2. Common types of hijacking include:
    - Session hijacking: This type of attack intercepts an active session between two computers and takes control of it.
    - DNS hijacking: This attack redirects a user’s requests for a website or service to a malicious server.
    - IP hijacking: This attack takes control of a user’s IP address and redirects their traffic to a malicious server.

3. Defense against hijacking includes:
    - Keeping systems and networks up to date with the latest security patches
    - Using strong passwords and two-factor authentication
    - Implementing firewalls and security software
    - Monitoring for suspicious activity
    - Educating users about security best practices
