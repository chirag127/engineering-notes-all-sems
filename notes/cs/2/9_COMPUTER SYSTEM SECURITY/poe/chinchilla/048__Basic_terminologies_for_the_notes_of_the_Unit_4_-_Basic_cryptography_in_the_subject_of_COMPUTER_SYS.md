### Basic Terminologies for the Notes of Unit 4 - Basic Cryptography in the Subject of Computer System Security

Cryptography is the study of secure communication techniques that allow only authorized individuals to access confidential information. In this unit, we will cover various basic terminologies related to cryptography. Here are some important terminologies that you should know:

1. **Encryption:** Encryption is the process of converting plain text into cipher text using an encryption algorithm. Cipher text is the output of the encryption process, which is unreadable to anyone without the decryption key.

2. **Decryption:** Decryption is the process of converting cipher text back into plain text using a decryption algorithm and a decryption key.

3. **Cipher:** A cipher is an algorithm used for encryption and decryption. There are two types of ciphers: symmetric and asymmetric.

4. **Symmetric Key Cryptography:** Symmetric key cryptography is a type of cryptography in which the same key is used for both encryption and decryption. The sender and the receiver share the same secret key.

5. **Asymmetric Key Cryptography:** Asymmetric key cryptography is a type of cryptography in which two different keys are used for encryption and decryption. One key is known as the public key, and the other key is known as the private key.

6. **Public Key Cryptography:** Public key cryptography is a type of asymmetric key cryptography in which the public key is used for encryption, and the private key is used for decryption.

7. **Private Key Cryptography:** Private key cryptography is a type of asymmetric key cryptography in which the private key is used for both encryption and decryption.

8. **Digital Signature:** A digital signature is a mathematical scheme used for verifying the authenticity of digital documents or messages.

9. **Hash Function:** A hash function is a mathematical function used for converting data of arbitrary size into a fixed-size output. The output of a hash function is known as a hash value or message digest.

10. **Key Exchange:** Key exchange is the process of securely exchanging keys between two parties to establish a secure communication channel.

These are some of the basic terminologies related to cryptography that you should know for this unit. Understanding these terminologies is crucial for understanding the concepts of cryptography and its applications in computer system security.
