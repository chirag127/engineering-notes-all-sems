## Unit 4 - Basic cryptography

Cryptography is the practice of securing communication from adversaries or unauthorized access. It involves the use of mathematical algorithms to transform messages into a secret code that can be deciphered only by the intended recipient. Basic cryptography techniques are essential for secure communication, and they form the foundation for more advanced cryptographic methods.

In this unit, we will cover the following topics:

1. **Symmetric Key Cryptography:** This technique involves using a single key to encrypt and decrypt messages. The same secret key is used by both the sender and the receiver to encrypt and decrypt the message. We will discuss various symmetric key algorithms such as DES, AES, and Blowfish.

2. **Asymmetric Key Cryptography:** Unlike symmetric key cryptography, asymmetric key cryptography uses two different keys, one for encryption and another for decryption. The public key is used for encryption, and the private key is used for decryption. We will learn about public-key encryption algorithms such as RSA, ElGamal, and Diffie-Hellman.

3. **Hash Functions:** Hash functions are used to produce a fixed-size output from an input of variable size. These functions are used to verify the integrity of the message and ensure that it has not been tampered with during transmission. We will discuss various hash functions such as MD5, SHA-1, and SHA-2.

4. **Digital Signatures:** Digital signatures are used to ensure the authenticity of the message and the identity of the sender. A digital signature is created using a private key and can be verified using the corresponding public key. We will discuss various digital signature algorithms such as DSA and ECDSA.

5. **Key Management:** Key management is the process of generating, storing, distributing, and revoking cryptographic keys. It is essential for the security of any cryptographic system. We will discuss various key management techniques such as key exchange protocols, key storage, and key revocation.

In conclusion, basic cryptography techniques are essential for secure communication, and they form the foundation for more advanced cryptographic methods. Understanding the concepts and algorithms of cryptography is vital for anyone interested in information security. This unit will provide you with a solid understanding of basic cryptography, which will be useful in any security-related field.
