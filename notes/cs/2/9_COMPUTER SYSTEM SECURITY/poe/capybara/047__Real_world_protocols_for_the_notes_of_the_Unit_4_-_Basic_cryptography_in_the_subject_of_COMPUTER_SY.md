### Real World Protocols for the Notes of Unit 4 - Basic Cryptography in the Subject of Computer System Security

Cryptography is the practice of securing communication from unauthorized access by converting plaintext into ciphertext. It is an essential part of computer system security. In this unit, you will learn about basic cryptography and the real-world protocols used to implement it. Here are some key protocols to know:

1. SSL/TLS: Secure Sockets Layer (SSL) and Transport Layer Security (TLS) are protocols used to establish an encrypted connection between a client and a server. SSL and TLS are commonly used to encrypt web traffic, email, and other communication protocols.

2. AES: Advanced Encryption Standard (AES) is a symmetric key encryption algorithm used to protect sensitive data. It is widely used in government and military applications, as well as in commercial products such as VPNs and encrypted USB drives.

3. RSA: Rivest-Shamir-Adleman (RSA) is a public-key encryption algorithm used to secure communication over insecure channels. It is widely used in web browsers, email, and other communication protocols.

4. HMAC: Hash-based Message Authentication Code (HMAC) is a cryptographic technique used to verify the integrity and authenticity of a message. It is widely used in network protocols such as SSL/TLS and IPSec.

5. Diffie-Hellman: Diffie-Hellman (DH) is a key exchange protocol used to establish a shared secret between two parties over an insecure channel. It is widely used in SSL/TLS and other communication protocols.

6. Kerberos: Kerberos is a network authentication protocol used to provide secure authentication between clients and servers. It is widely used in enterprise networks to provide single sign-on and to secure network resources.

In conclusion, these real-world protocols are essential to implementing basic cryptography in computer system security. Understanding these protocols and their applications will help you secure communication and protect sensitive data.
