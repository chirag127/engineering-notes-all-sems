### Sample Attacks for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY

In order to understand the importance of computer system security, it is essential to consider the various types of attacks that can be launched against computer systems. The following are some sample attacks that can be used as a reference for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY:

1. **Phishing:** Phishing attacks are one of the most common types of attacks that are used to steal sensitive information from individuals. In this type of attack, the attacker sends an email or message that appears to be from a legitimate source, such as a bank or social media platform, to trick the victim into providing their personal information.

2. **Malware:** Malware is a type of software that is designed to harm computer systems. This can include viruses, worms, and Trojan horses, which can be used to steal data, damage files, or take control of the computer system.

3. **Denial-of-Service (DoS):** A denial-of-service attack is designed to overwhelm a computer system with traffic, making it unavailable to users. This can be achieved by flooding the system with requests or by exploiting vulnerabilities in the system's software.

4. **Man-in-the-Middle (MitM):** A man-in-the-middle attack occurs when an attacker intercepts communication between two parties, allowing them to eavesdrop on the conversation or even alter the information being transmitted.

5. **Password Attacks:** Password attacks are used to gain access to a system by guessing or cracking the password. This can be achieved through brute force attacks, dictionary attacks, or social engineering.

It is important to note that these are only a few examples of the types of attacks that can be launched against computer systems. As technology continues to advance, so do the methods and techniques used by attackers. Therefore, it is crucial to stay informed and up-to-date on the latest security measures to protect against these attacks.
