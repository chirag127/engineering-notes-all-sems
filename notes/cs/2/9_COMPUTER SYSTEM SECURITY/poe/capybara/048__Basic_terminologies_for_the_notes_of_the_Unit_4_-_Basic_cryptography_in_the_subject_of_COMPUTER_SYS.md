### Basic Terminologies for the Notes of Unit 4 - Basic Cryptography in the Subject of Computer System Security

Cryptography is a technique used to secure communication and protect sensitive information. It involves the use of mathematical algorithms to convert readable and understandable data into an encrypted form. Here are some basic terminologies that are essential to understand for the notes of Unit 4 - Basic Cryptography in the subject of Computer System Security:

1. Encryption: It is the process of converting plain text into a coded language to protect it from unauthorized access. The encrypted data can only be read by those who have the decryption key.

2. Decryption: It is the process of converting the encrypted data back to its original form using the decryption key.

3. Cipher: It is a set of rules or algorithm used to encrypt or decrypt data.

4. Key: It is a secret code or password used to encrypt or decrypt data.

5. Cryptanalysis: It is the process of studying encrypted data to break the encryption and read the message.

6. Cryptology: It is the study of cryptography and cryptanalysis.

7. Cryptosystem: It is a complete set of cryptographic algorithms, protocols, and key management techniques used to secure data.

8. Plaintext: It is the original and readable message before encryption.

9. Ciphertext: It is the encrypted message that is not readable without the decryption key.

10. Symmetric Key Cryptography: It is a type of encryption technique that uses the same key for both encryption and decryption of data.

11. Asymmetric Key Cryptography: It is a type of encryption technique that uses different keys for encryption and decryption of data.

12. Public Key: It is the key that is freely available to anyone for encrypting data.

13. Private Key: It is the key that is kept secret and used for decrypting data.

14. Digital Signature: It is a mathematical technique used to verify the authenticity of digital documents or messages.

15. Hash Function: It is a mathematical function used to convert data of any size into a fixed-size output.

These basic terminologies are essential to understand for the notes of Unit 4 - Basic Cryptography in the subject of Computer System Security. Having a good understanding of these terminologies will help you to comprehend the concepts of cryptography and its applications in securing computer systems.
