1. Computer System Security refers to the protection of computer systems and information from the harm that can be caused by the unauthorized access or abuse of resources available on the system.
2. Threats: The threats to computer systems and information can be classified into the following major categories:
- Deliberate threats: These include unauthorized access or cyber attacks by malicious actors such as hackers, criminals, terrorists, etc.
- Accidental threats: These include threats due to human errors, system failures, natural disasters, etc.
3. Vulnerabilities: Vulnerabilities refer to the weaknesses in the system that can be exploited by threats. These can be due to software bugs, misconfigurations, risky user behavior, etc.
4. Controls: Controls refer to the safeguards put in place to reduce the risks due to threats exploiting vulnerabilities. These include access controls, cryptography, security testing, etc.
5. Risks: Risks refer to the potential adverse impacts that can arise from the threats exploiting the vulnerabilities. The risks have to be mitigated using appropriate controls to an acceptable level.
