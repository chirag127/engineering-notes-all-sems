### Intrusion detection for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY.

1. Intrusion detection is the process of monitoring the events occurring in a computer system or network and analyzing them for signs of possible incidents, violations or threats of violation of computer security policies, acceptable use policies, or standard security practices.

2. Intrusion detection systems (IDS) are software or hardware products that automate the intrusion detection process.

3. An IDS inspects all inbound and outbound network activity and identifies suspicious patterns that may indicate a network or system attack from someone trying to break into or compromise a system.

4. The two main types of IDS are network-based and host-based. A network-based IDS (NIDS) monitors network traffic for suspicious activity, while a host-based IDS (HIDS) monitors activity on a single host or piece of hardware.

5. Once an IDS detects suspicious activity, it will typically generate alerts to a management console or security information and event management system. The security staff or administrators can then investigate further to determine if an actual attack or intrusion has occurred or if it was a false alarm.

6. Challenges with intrusion detection systems include false positives (alerting when no attack is occurring), false negatives (failing to detect an actual attack), and the inability to keep up with the evolving tactics of intruders. Constant updates to detection signatures and machine learning algorithms help address some of these challenges.
