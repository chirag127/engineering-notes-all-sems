### Certificates for Basic Cryptography (Unit 4 notes)

1. A certificate is an electronic document which uses a digital signature to bind a public key with an identity.
2. A certificate contains the following information:
- Serial number: Unique identification number of the certificate.
- Issuer: An entity that signs and issues the certificate.
- Validity period: Time period for which the certificate is valid.
- Subject: The entity identified by the certificate.
- Public key: The public key of the subject.
- Signature algorithm: Algorithm used to generate the digital signature.
3. The most common types of certificates are:
- SSL/TLS certificates: Used to secure websites and enable HTTPS.
- Code signing certificates: Used to sign executable software code.
- Email certificates: Used to secure email communications.
4. The process of issuing and verifying certificates is known as Public Key Infrastructure (PKI). It consists of the following components:
- Certificate authority (CA): Issues and verifies certificates.
- Registration authority (RA): Verifies the identity of entities requesting certificates.
- Certificate repository: Stores issued certificates and CRLs.
- Certificate validation: The process of verifying a certificate.
