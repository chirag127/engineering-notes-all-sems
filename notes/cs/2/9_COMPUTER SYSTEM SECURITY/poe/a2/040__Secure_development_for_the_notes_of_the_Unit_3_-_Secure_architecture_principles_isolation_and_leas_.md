### Secure development for the notes of the Unit 3 - Secure architecture principles isolation and leas

1. Isolation - Separating components/systems to limit the impact of a breach
- Process isolation - Separate processes to limit impact of a compromised process
- Containerization - Isolate applications into containers to limit impact
- Network isolation - Separate networks/segments to limit lateral movement
- Storage isolation - Separate storage to limit access across components

2. Least privilege - Granting minimum access required to perform a task
- Only provide access that is needed to perform a job/task
- Reduce the attack surface by limiting unnecessary access
- Contain damage by limiting access even when compromise occurs

3. Defense in depth - Applying multiple controls/measures to mitigate risk
- Don't rely on single controls/measures which can fail
- Combine preventive, detective, corrective controls across layers (network, system, application, data, etc.)
- Make it difficult for adversaries by implementing layered security
