### DNS security

- DNS spoofing: An attacker can spoof DNS responses to redirect users to fake websites without their knowledge. This can be used to conduct phishing attacks or install malware.
- DNS cache poisoning: An attacker can poison the DNS cache of a resolver to redirect users to fake websites. This is difficult to execute but can have a wide impact.
- DNS tunneling: An attacker can use DNS queries to transmit data and bypass firewalls. The data is encoded into DNS queries and responses. This technique is used by malware to communicate with C&C servers.
- DNSSEC: DNS Security Extensions (DNSSEC) uses digital signatures and cryptographic techniques to authenticate DNS data and prevent spoofing and poisoning attacks. The root zone and several top-level domains have been signed with DNSSEC.
