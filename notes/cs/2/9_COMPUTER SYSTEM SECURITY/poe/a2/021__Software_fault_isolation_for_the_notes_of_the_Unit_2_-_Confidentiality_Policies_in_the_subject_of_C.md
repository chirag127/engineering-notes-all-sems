### Software fault isolation for the notes of the Unit 2 - Confidentiality Policies in the subject of COMPUTER SYSTEM SECURITY

1. Software fault isolation is a technique used to compartmentalize software modules and restrict the impact of a fault in one module from spreading to others.
2. It prevents software bugs or errors in one module from affecting the execution of other modules.
3. This is achieved by restricting the sharing of resources between modules and permitting only limited, well-defined interactions between modules.
4. Some of the benefits of software fault isolation are:
- Increased reliability of software systems.
- Improved security as faults or attacks in one module do not spread to other modules.
- Allows for gradual updates by updating modules independently without affecting others.
5. However, software fault isolation may incur some performance overhead and complexity in software development due to the restrictions imposed.
6. Examples of software fault isolation techniques include module protection rings, process isolation, application firewalls, etc.
