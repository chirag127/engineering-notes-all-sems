### What is computer security and what to learn for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY:

1. Computer security refers to the protection of computer systems and networks from the theft of or damage to their electronic data, software, or hardware components.
2. The main objectives of computer security are:
- Confidentiality - ensuring that information is only accessible to authorized individuals.
- Integrity - safeguarding the accuracy and completeness of information and processing methods.
- Availability - ensuring that authorized users have access to information and associated assets when required.
3. Threats to computer security include:
- Malware - viruses, worms, Trojans, ransomware, etc.
- Phishing attacks - emails with malicious attachments or links to steal data or login credentials.
- Denial-of-service attacks - flood a computer, server, or network with traffic to disrupt services.
- Insider threats - legitimate users misusing their access rights to steal data or sabotage systems.
4. To protect against threats, computer security uses methods like:
- Access controls - authentication, passwords, etc. to control access to systems and data.
- Antivirus software - to detect and remove malware.
- Firewalls - to filter incoming and outgoing network traffic based on security rules.
- Patching - to fix vulnerabilities in software that could be exploited by attacks.
- Security training - to educate users on recognizing and avoiding threats.
