## Unit 5 - Internet Infrastructure

1. The Internet is a massive network that connects millions of computers and other devices from all over the world. It allows all of these computers and devices to share information with each other using a common set of rules and protocols called TCP/IP.

2. The infrastructure of the Internet consists of its hardware components and software protocols. The hardware components include servers, routers, cables, and other equipment that transmit data between network nodes. The software protocols are the common languages that allow network devices to communicate with each other, including protocols like IP, TCP, UDP, and DNS.

3. The Internet itself is a network of networks. It consists of smaller networks that are connected to each other. These networks might be at your home, at your office, or anywhere else. They are all interconnected using a variety of high-speed data lines and other networking equipment like routers, switches, and servers.

4. Data is transmitted between networks in small digital packets that include the address of the sender and recipient. These packets are routed between networks based on the most efficient path available, which is determined by the networking equipment using protocols like OSPF and BGP. The packets may take different routes to reach the final destination and are reassembled in the correct order once they arrive.

5. The Domain Name System (DNS) is crucial for navigating the Internet. It's what translates the website names we type into a browser to the IP addresses that identify the server hosting the website. Without DNS, we would have to type in lengthy IP addresses to access websites, which would be very difficult. The distributed DNS system consists of many servers around the world that keep track of website names and IP addresses.
