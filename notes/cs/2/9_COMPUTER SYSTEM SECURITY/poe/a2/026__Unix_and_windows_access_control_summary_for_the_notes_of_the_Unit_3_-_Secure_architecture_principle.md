 Here is the formal summary of Unix and Windows access control for the notes of Unit 3 - Secure architecture principles isolation and least privilege in the subject of Computer System Security:

### Unix access control

- Permissions: Read, write, execute for user, group, others
- Special permissions: Setuid, setgid, sticky bit
- Access control lists: Extended attributes on files/directories to specify access control for specific users/groups
- Capabilities: Limit root privileges by partitioning them into distinct units

### Windows access control

- Discretionary access control list (DACL): Specifies which users/groups have what access to an object
- System access control list (SACL): Specifies which users/groups can log access attempts and what they can log
- Privileged access management: Restrict privileges of highly privileged accounts and require justification for use
- User account control: Elevate privileges for admin accounts only when required
- Mandatory integrity control: Label processes/objects with integrity level and restrict interactions across levels
