### Cross site request forgery for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

Unit 3 of the Computer System Security course focuses on Secure Architecture Principles, Isolation, and Least Privilege, including the aspect of Cross-Site Request Forgery (CSRF).

Cross-Site Request Forgery (CSRF) is a type of security vulnerability that allows an attacker to perform unauthorized actions on behalf of a user. In a CSRF attack, the attacker tricks the user into making a request to a website that the user is already authenticated with, such as a bank website or an online shopping site. The request is made without the user's knowledge or consent, and the attacker can use this request to perform unauthorized actions, such as transferring money or making purchases.

In the context of the Computer System Security course, students in Unit 3 may learn about CSRF as part of the discussion on Secure Architecture Principles, Isolation, and Least Privilege. This may include working with examples of CSRF attacks, analyzing the impact of CSRF on the security of computer systems, and learning strategies for preventing CSRF attacks.
