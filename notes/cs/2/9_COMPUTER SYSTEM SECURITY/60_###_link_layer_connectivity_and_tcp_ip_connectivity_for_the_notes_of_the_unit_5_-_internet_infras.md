### Link layer connectivity and TCP IP connectivity for the notes of the Unit 5 - Internet Infrastructure in the subject of COMPUTER SYSTEM SECURITY

Link layer connectivity and TCP/IP connectivity are two important concepts in Internet infrastructure. These concepts are related to the way that data is transmitted over a network, and they play a critical role in ensuring the availability, reliability, and security of data transmission.

1. Link layer connectivity: Link layer connectivity refers to the way that data is transmitted between devices on a single network segment, such as a local area network (LAN) or a wireless network. The link layer is responsible for providing reliable data transmission between devices, and it is often implemented using the Ethernet protocol.

2. TCP/IP connectivity: TCP/IP connectivity refers to the way that data is transmitted between devices on different networks, such as between a local area network (LAN) and a wide area network (WAN). The TCP/IP protocol is used to transmit data between devices, and it is responsible for breaking down data into smaller packets and transmitting them over the network.

We will examine the strategies for implementing these technologies, and explore the use of link layer and TCP/IP connectivity in various applications, such as secure architecture design, isolation, and leasing. This will provide a foundation for understanding the principles and practices of computer system security, and for exploring the various security measures used to protect computer systems.
