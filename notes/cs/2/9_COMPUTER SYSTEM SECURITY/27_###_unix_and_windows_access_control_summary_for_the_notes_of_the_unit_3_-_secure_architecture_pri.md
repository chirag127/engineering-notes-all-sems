### Unix and windows access control summary for the notes of the Unit 3 - Secure architecture principles isolation and leas in the subject of COMPUTER SYSTEM SECURITY

The Unit 3 - Secure Architecture Principles, Isolation, and Least Privilege covers the following topic:

1. Unix and Windows Access Control:
Access control is a security mechanism that regulates access to resources in a computer system. In Unix and Windows systems, access control is implemented using a combination of permissions and access control lists (ACLs).

2. Unix Access Control:
In Unix systems, access control is implemented using file permissions, which specify the actions that can be performed on a file or directory by different users. Permissions can be set for the owner of the file, the group to which the file belongs, and other users.

3. Windows Access Control:
In Windows systems, access control is implemented using ACLs, which specify the permissions that different users have to access a file or directory. ACLs can be set at the file and directory level, and permissions can be granted to individual users or groups of users.

In both Unix and Windows systems, access control is an important aspect of security, as it helps to prevent unauthorized access to sensitive information and resources. By limiting access to only those users who need it, access control helps to reduce the risk of security breaches and data loss.

In conclusion, access control is a critical component of secure architecture, and is essential for protecting sensitive information and resources in Unix and Windows systems. By implementing access control mechanisms, such as file permissions and ACLs, organizations can help to ensure that their systems are secure and that sensitive information is protected from unauthorized access.
