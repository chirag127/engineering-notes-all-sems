### Defense against Control Hijacking - Run-time Defenses for the notes of the Unit 1 - Computer System Security Introduction in the subject of COMPUTER SYSTEM SECURITY

Unit 1 of the Computer System Security course focuses on Introduction to Computer System Security, including the aspect of defense against control hijacking.

One of the ways to defend against control hijacking is through the use of run-time defenses. Run-time defenses are security measures that are implemented at the time of execution of a program or process. These defenses can help prevent control hijacking by detecting and blocking malicious actions, such as attempts to exploit software vulnerabilities or access sensitive information.

Examples of run-time defenses include data execution prevention (DEP), address space layout randomization (ASLR), and stack canaries. These defenses work by creating a barrier between the program and the underlying operating system, making it more difficult for attackers to gain control of the system.

In the context of the Computer System Security course, students in Unit 1 may learn about run-time defenses as part of the discussion on defense against control hijacking. This may include working with examples of run-time defenses, analyzing the effectiveness of these defenses, and learning strategies for implementing run-time defenses in computer systems.
