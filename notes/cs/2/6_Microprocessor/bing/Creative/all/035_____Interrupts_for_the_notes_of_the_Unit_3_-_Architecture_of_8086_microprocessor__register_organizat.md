# Interrupts

- An interrupt is a signal that causes the CPU to temporarily stop its current execution and switch to a predefined subroutine called an interrupt service routine (ISR) or interrupt handler.
- Interrupts can be triggered by external devices (hardware interrupts) or by software instructions (software interrupts).
- Interrupts are useful for handling asynchronous events, such as keyboard input, disk I/O, timer signals, etc.
- Interrupts can also improve the performance and efficiency of the CPU by allowing it to execute other tasks while waiting for an I/O operation to complete.

## Hardware Interrupts

- Hardware interrupt is caused by any peripheral device by sending a signal through a specified pin to the microprocessor.
- The 8086 has two hardware interrupt pins, i.e. NMI and INTR.
- NMI is a non-maskable interrupt and INTR is a maskable interrupt having lower priority.
- One more interrupt pin associated is INTA called interrupt acknowledge.

### NMI (Non-Maskable Interrupt)

- It is a single pin non-maskable hardware interrupt that cannot be disabled.
- It is the highest priority interrupt in the 8086 microprocessor.
- It is triggered by a negative edge signal on the NMI pin.
- It is used for critical situations, such as power failure, parity error, etc.
- It causes the CPU to execute the ISR at the fixed memory location 00000H - 00003H.

### INTR (Maskable Interrupt)

- It is a single pin maskable hardware interrupt that can be enabled or disabled by software instructions.
- It is a level sensitive interrupt, which means it remains active until it is acknowledged by the CPU.
- It is used for normal peripheral devices, such as keyboard, mouse, printer, etc.
- It causes the CPU to execute the ISR at the memory location specified by the interrupt vector table (IVT).

### INTA (Interrupt Acknowledge)

- It is a signal generated by the CPU to acknowledge the receipt of an INTR signal.
- It is used to communicate with an external device called an interrupt controller, which is responsible for managing multiple hardware interrupts and assigning them priority levels.
- The most common interrupt controller for the 8086 is the 8259A programmable interrupt controller (PIC).
- The INTA signal is sent twice by the CPU for each INTR signal. The first INTA is used to inform the PIC that the CPU is ready to accept an interrupt. The second INTA is used to receive the interrupt type number from the PIC.

## Software Interrupts

- Software interrupt is caused by a software instruction, such as INT, INTO, INT3, BOUND, etc.
- The 8086 microprocessor has 256 types of software interrupts, numbered from 0 to 255.
- Each software interrupt has a predefined function, such as BIOS routines, DOS services, debugging, etc.
- Software interrupts can also be user-defined, by storing the address of the ISR in the IVT.
- Software interrupts cause the CPU to execute the ISR at the memory location specified by the IVT.

## Interrupt Vector Table (IVT)

- The IVT is a table of 256 interrupt vectors, each consisting of a 4-byte pointer to the ISR.
- The IVT starts at memory address 00000H and ends at 003FFH, occupying 1 KB of memory.
- The IVT is initialized by the BIOS during system startup, and can be modified by the operating system or the user programs.
- The IVT is indexed by the interrupt type number, which is multiplied by 4 to obtain the offset of the interrupt vector.
- The interrupt vector contains the segment and offset address of the ISR, which is loaded into the CS and IP registers by the CPU.
