# Logic for the notes of the Unit 4 - Assembly language programming based on intel 8085/8086

- Assembly language is a low-level language that uses mnemonics to represent machine instructions  .
- Assembly language is specific to a given processor, such as Intel 8085 or 8086 .
- Assembly language programming involves writing source code in assembly language, assembling it into machine code using an assembler, and debugging it using a simulator or debugger .
- Intel 8085 and 8086 are 8-bit and 16-bit microprocessors, respectively, that use the same instruction set architecture.
- The instruction set of Intel 8085/8086 consists of various types of instructions, such as data transfer, arithmetic, logic, branch, loop, count, index, stack, subroutine, and conditional call and return.
- Data transfer instructions are used to move data between registers, memory, and I/O devices.
- Arithmetic instructions are used to perform addition, subtraction, increment, decrement, multiplication, and division operations on data.
- Logic instructions are used to perform bitwise logical operations, such as AND, OR, XOR, NOT, and compare on data.
- Branch instructions are used to alter the sequence of execution by jumping to a specified address or label.
- Loop instructions are used to repeat a block of code for a given number of times or until a condition is met.
- Count instructions are used to increment or decrement a register or memory location by one.
- Index instructions are used to access data in memory using an index register, such as BX, SI, or DI in 8086.
- Stack instructions are used to manipulate the stack, which is a data structure that follows the last-in first-out (LIFO) principle.
- Subroutine instructions are used to call and return from a subroutine, which is a block of code that performs a specific task and can be reused.
- Conditional call and return instructions are used to call and return from a subroutine only if a certain condition is true or false.
- Programming techniques are methods or strategies to write efficient and reliable assembly language programs.
- Counters and time delays are used to measure the frequency or duration of events or signals in a microprocessor system.
