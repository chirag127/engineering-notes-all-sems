# Operating modes for the notes of the Unit 3 - Architecture of 8086 microprocessor: register organization, bus interface unit, execution unit, memory addressing, and memory segmentation. Operating modes. Instruction sets, instruction format, Types of instructions. Interrupts: hardware and software interrupts.

- The 8086 microprocessor is a 16-bit, N-channel, HMOS microprocessor that can operate in two modes: minimum mode and maximum mode.
- In minimum mode, the 8086 is the only processor in the system and provides all the control signals for memory and I/O interfacing.
- In maximum mode, the 8086 can work with other processors such as 8087, 8089, or 8088 and uses a bus controller chip (8288) to generate the control signals.
- The 8086 has a 20-bit address bus and a 16-bit data bus, which allows it to access 1 MB of memory and transfer 16 bits of data at a time.
- The 8086 has a register organization that consists of four general-purpose registers (AX, BX, CX, DX), four segment registers (CS, DS, SS, ES), four index registers (SI, DI, BP, SP), a flag register (FLAGS), and an instruction pointer (IP).
- The 8086 has a bus interface unit (BIU) and an execution unit (EU) that work in parallel to increase the performance of the processor.
- The BIU is responsible for fetching instructions from memory, generating physical addresses, and interfacing with external devices.
- The EU is responsible for decoding and executing instructions, performing arithmetic and logical operations, and manipulating data and flags.
- The 8086 has a memory addressing scheme that uses segment registers and index registers to form a 20-bit physical address.
- The 8086 has a memory segmentation scheme that divides the memory into four segments: code segment (CS), data segment (DS), stack segment (SS), and extra segment (ES).
- Each segment has a 64 KB size and a 16-bit base address that is stored in the corresponding segment register.
- The 8086 has an instruction set that consists of various types of instructions, such as data transfer, arithmetic, logical, branch, loop, string, flag, stack, interrupt, and machine control instructions.
- The 8086 has an instruction format that consists of one or more bytes, each containing an opcode, a mode, a register, and an operand field.
- The 8086 has an addressing mode that specifies how the operands of an instruction are located in memory or registers.
- The 8086 has six addressing modes: register, immediate, displacement, register indirect, based, and indexed.
- The 8086 has an interrupt mechanism that allows the processor to respond to external or internal events that require immediate attention.
- The 8086 has two types of interrupts: hardware and software interrupts.
- Hardware interrupts are generated by external devices, such as keyboard, mouse, or timer, and are handled by the interrupt controller chip (8259).
- Software interrupts are generated by the processor itself or by the instructions, such as INT, INTO, or BOUND, and are handled by the interrupt vector table (IVT).
- The 8086 has 256 interrupt vectors, each corresponding to a 4-byte address of an interrupt service routine (ISR) that is stored in the IVT.
