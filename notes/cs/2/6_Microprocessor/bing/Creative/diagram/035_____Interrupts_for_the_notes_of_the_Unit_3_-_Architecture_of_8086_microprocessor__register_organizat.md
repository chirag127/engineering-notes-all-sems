### Interrupts

- Interrupts are signals that cause the CPU to suspend its current execution and transfer control to a predefined service routine, called an interrupt handler or an interrupt service routine (ISR).
- Interrupts can be classified into two types: hardware interrupts and software interrupts.
- Hardware interrupts are generated by external devices, such as keyboards, timers, printers, etc., that are connected to the CPU through special pins or buses.
- Software interrupts are generated by instructions executed by the CPU, such as INT, INTO, BOUND, etc., that cause the CPU to execute a predefined ISR.
- The 8086 microprocessor has two hardware interrupt pins: NMI and INTR.
  - NMI (Non-Maskable Interrupt) is a single pin non-maskable hardware interrupt that cannot be disabled. It is the highest priority interrupt in the 8086 microprocessor. It is usually used for emergency situations, such as power failure, parity error, etc. The NMI is assigned a fixed type number of 2, which means it always invokes the ISR located at address 00008H in the interrupt vector table (IVT).
  - INTR (Interrupt Request) is a maskable hardware interrupt that can be enabled or disabled by setting or clearing the interrupt flag (IF) in the flags register. It is a lower priority interrupt than NMI. It is used for normal device requests, such as keyboard input, disk I/O, etc. The INTR is assigned a variable type number by an external device or controller, which is sent to the CPU through the data bus when the CPU acknowledges the interrupt by sending a signal through the INTA (Interrupt Acknowledge) pin. The type number determines the address of the ISR in the IVT, which is calculated as 4 times the type number.
- The 8086 microprocessor has 256 types of interrupts, numbered from 0 to 255. Each interrupt type has a corresponding ISR, which is stored in the IVT. The IVT is a table of 256 four-byte pointers, each pointing to the starting address of an ISR. The IVT starts at address 00000H and ends at address 003FFH in the memory.
- The 8086 microprocessor has two operating modes: minimum mode and maximum mode. In minimum mode, the 8086 operates as a single processor system, and the INTR pin is directly connected to an external device or controller. In maximum mode, the 8086 operates as a multiprocessor system, and the INTR pin is connected to an 8259A programmable interrupt controller (PIC), which can handle up to eight hardware interrupts from different sources and prioritize them according to a predefined scheme.
- The 8086 microprocessor has a rich instruction set, which can be classified into five types: data transfer instructions, arithmetic instructions, logical instructions, control transfer instructions, and string instructions. Each instruction has a specific format, which consists of one or more bytes, each byte having a specific meaning and function. The format of an instruction can be divided into four fields: prefix, opcode, mod-reg-mem, and displacement-immediate.
- The 8086 microprocessor has four types of software interrupts: predefined interrupts, user-defined interrupts, DOS interrupts, and BIOS interrupts.
  - Predefined interrupts are software interrupts that are assigned a fixed type number by the manufacturer, and have a predefined ISR in the IVT. They are used for testing, debugging, and error handling purposes. Some examples of predefined interrupts are: type 0 (divide by zero exception), type 1 (single step exception), type 3 (breakpoint exception), type 4 (overflow exception), etc.
  - User-defined interrupts are software interrupts that are assigned a variable type number by the programmer, and have a user-defined ISR in the IVT. They are used for customizing the functionality of the system, and implementing subroutines, macros, and device drivers. The type number of a user-defined interrupt can be specified by the INT instruction, which takes an 8-bit operand as the type number. For example, INT 21H invokes the ISR located at address 0084H in the IVT.
  - DOS interrupts are software interrupts that are provided by the disk operating system (DOS), and have a DOS-defined ISR in the IVT. They are used for accessing the DOS services, such as file management, memory management, process management, etc. The type number of a DOS interrupt is 21H, which means it always invokes the ISR located at address 0084H in the IVT.
