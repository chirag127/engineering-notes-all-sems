## Unit 4 - Assembly language programming based on intel 8085/8086

- Assembly language is a low-level language that uses mnemonics to represent the binary instructions that a microprocessor can execute  .
- Assembly language is specific to a given processor, so the syntax and instruction set may vary depending on the microprocessor .
- Intel 8085 and 8086 are two popular microprocessors that have their own assembly languages and architectures    .
- Some of the topics that are covered in assembly language programming based on intel 8085/8086 are:

  - Instructions: These are the basic commands that the microprocessor can execute, such as data transfer, arithmetic, logic, branch, etc. Each instruction has a mnemonic, an opcode, and operands   .
  - Data transfer: These are the instructions that move data between registers, memory, and input/output devices. Some examples are MOV, MVI, LDA, STA, IN, OUT, etc   .
  - Arithmetic: These are the instructions that perform arithmetic operations on data, such as addition, subtraction, multiplication, division, increment, decrement, etc. Some examples are ADD, SUB, MUL, DIV, INR, DCR, etc   .
  - Logic: These are the instructions that perform logical operations on data, such as AND, OR, XOR, NOT, complement, shift, rotate, etc. Some examples are ANA, ORA, XRA, CMA, RLC, RRC, etc   .
  - Branch: These are the instructions that alter the sequence of execution based on certain conditions, such as jump, call, return, etc. Some examples are JMP, JC, JNC, JZ, JNZ, CALL, RET, etc   .
  - Looping, counting, indexing: These are the techniques that use branch instructions and registers to repeat a set of instructions for a certain number of times or until a condition is met. Some examples are LOOP, CX, BX, etc .
  - Programming techniques: These are the methods that use various instructions and techniques to achieve certain tasks, such as sorting, searching, string manipulation, etc .
  - Counters and time delays: These are the techniques that use loop instructions and timers to generate a specific frequency or duration of signals or events .
  - Stacks and subroutines: These are the techniques that use memory and branch instructions to store and retrieve data or return addresses, and to implement modular programming .
  - Conditional call and return instructions: These are the instructions that perform call or return operations only if a certain condition is met, such as CC, CNC, CZ, CNZ, etc .

- Assembly language programming requires a good understanding of the microprocessor architecture, instruction set, addressing modes, registers, flags, memory, and input/output devices    .
- Assembly language programming can be done using an assembler, a debugger, and a simulator  . An assembler converts the assembly language code into machine code, a debugger helps to find and fix errors in the code, and a simulator helps to test and run the code on a virtual microprocessor  .
