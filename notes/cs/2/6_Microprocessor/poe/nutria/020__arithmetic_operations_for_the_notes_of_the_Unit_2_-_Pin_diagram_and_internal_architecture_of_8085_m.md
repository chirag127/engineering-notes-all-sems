3. The 8085 microprocessor has 8 registers which are used to store data and perform arithmetic operations. 
4. The 8085 microprocessor has a control unit which is responsible for controlling the flow of data and instructions. 
5. The 8085 microprocessor also has an interrupt system which is used to respond to external events. 
6. The 8085 microprocessor has a machine cycle which consists of four steps: fetch, decode, execute, and store. 
7. The 8085 microprocessor has an instruction set which consists of instructions for data transfer, arithmetic operations, logical operations, branching operations, and machine control. 
8. The 8085 microprocessor has various addressing modes which are used to access data and instructions. 
9. The 8085 microprocessor has various instruction formats which are used to define the type and length of instructions.
