
### Interrupt and Machine Cycle for the Notes of the Unit 2 - Pin Diagram and Internal Architecture of 8085 Microprocessor 

* The 8085 microprocessor consists of the following components: 
    * Registers: The 8085 microprocessor has six 8-bit registers which are used for various purposes. 
    * ALU (Arithmetic Logic Unit): The ALU is responsible for performing arithmetic and logical operations on data. 
    * Control and Status: This component is responsible for controlling the operations of the microprocessor. 
    * Interrupt and Machine Cycle: The interrupt and machine cycle are responsible for the execution of instructions. 

* Instruction Sets: The instruction sets of the 8085 microprocessor consist of data transfer, arithmetic operations, logical operations, branching operations, machine control, and assembler directives. 

* Addressing Modes: The 8085 microprocessor has five addressing modes which are used to specify the location of the data or the instruction. 

* Instruction Formats: The 8085 microprocessor has two instruction formats which are used to specify the instruction that is to be executed. 

* Instruction Classification: The instructions of the 8085 microprocessor can be classified into the following categories: 
    * Data Transfer: This type of instruction is used to move data from one location to another. 
    * Arithmetic Operations: This type of instruction is used to perform arithmetic operations on data. 
    * Logical Operations: This type of instruction is used to perform logical operations on data. 
    * Branching Operations: This type of instruction is used to change the flow of the program. 
    * Machine Control: This type of instruction is used to control the operations of the microprocessor. 
    * Assembler Directives: This type of instruction is used to provide information to the assembler.
