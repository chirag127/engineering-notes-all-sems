
### Memory Segmentation for Unit 3 - Architecture of 8086 Microprocessor:

* Register Organization: The 8086 microprocessor is divided into several functional units, each of which is responsible for a specific task. The main functional units are the register organization, the bus interface unit, the execution unit, the memory addressing unit, and the memory segmentation unit. 
* Bus Interface Unit: This unit is responsible for communication between the 8086 microprocessor and other components in the system. It consists of three main components: the data bus, the address bus, and the control bus.
* Execution Unit: This unit is responsible for the execution of instructions. It is composed of two main components: the instruction decoder and the arithmetic unit. The instruction decoder is responsible for decoding instructions into their corresponding machine language instructions. The arithmetic unit is responsible for performing arithmetic and logical operations.
* Memory Addressing: This unit is responsible for addressing memory locations and is composed of three main components: the address bus, the data bus, and the control bus. 
* Memory Segmentation: This unit is responsible for segmenting memory into different sections. It is composed of two main components: the segment register and the segmentation unit. The segment register is responsible for keeping track of the current segment of memory, while the segmentation unit is responsible for mapping memory segments to physical memory locations.
* Operating Modes: The 8086 microprocessor supports two main operating modes: real mode and protected mode. Real mode is the simplest operating mode and is used for basic tasks such as loading and running programs. Protected mode is more advanced and is used for more complex tasks such as multitasking, memory protection, and virtual memory.
* Instruction Sets: The 8086 microprocessor supports two main instruction sets: the 8086 instruction set and the 80286 instruction set. The 8086 instruction set is the original instruction set and is used for basic tasks. The 80286 instruction set is an extension of the 8086 instruction set and is used for more complex tasks.
* Instruction Format: The 8086 microprocessor supports two main instruction formats: the one-byte instruction format and the two-byte instruction format. The one-byte instruction format is used for basic instructions, while the two-byte instruction format is used for more complex instructions.
* Types of Instructions: The 8086 microprocessor supports several types of instructions, including arithmetic instructions, logical instructions, branch instructions, and interrupt instructions.
* Interrupts: The 8086 microprocessor supports two types of interrupts: hardware interrupts and software interrupts. Hardware interrupts are triggered by external hardware devices, while software interrupts are triggered by instructions in the program code.
