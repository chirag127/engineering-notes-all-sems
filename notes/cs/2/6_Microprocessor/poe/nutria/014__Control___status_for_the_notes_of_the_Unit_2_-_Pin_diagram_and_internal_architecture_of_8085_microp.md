
### Control & Status for the Notes of the Unit 2 - Pin Diagram and Internal Architecture of 8085 Microprocessor, Registers, ALU, Control & Status, Interrupt and Machine Cycle

* Pin Diagram: The 8085 microprocessor has 40 pins, each with a specific function. It includes 8-bit data bus, 8-bit address bus, control bus, power and ground pins, interrupt pins, etc.
* Internal Architecture: The internal architecture of the 8085 microprocessor consists of an Arithmetic Logic Unit (ALU), Program Counter (PC), Stack Pointer (SP), Accumulator (AC), Flag Register (FR), Instruction Register (IR), and General Purpose Registers (GPR).
* Registers: The 8085 microprocessor has 8-bit registers that are used to store data and instructions. These registers are Accumulator (AC), Flag Register (FR), Program Counter (PC), Stack Pointer (SP), and General Purpose Registers (GPR).
* ALU: The Arithmetic Logic Unit (ALU) is responsible for performing arithmetic and logical operations. It uses the data stored in the registers to perform the operations.
* Control & Status: The Control & Status block is responsible for controlling the flow of data and instructions. It also stores the status of the microprocessor, such as the type of instruction being executed, the current state of the processor, etc.
* Interrupt: The 8085 microprocessor supports four interrupts. These are TRAP, RST 7.5, RST 6.5, and RST 5.5.
* Machine Cycle: The 8085 microprocessor has five machine cycles. These are Fetch, Execute, Memory Read, Memory Write, and I/O Read/Write.
* Instruction Sets: The 8085 microprocessor has 256 instructions. These instructions are divided into five categories: data transfer, arithmetic operations, logical operations, branching operations, and machine control.
* Addressing Modes: The 8085 microprocessor supports five addressing modes. These are direct, indirect, immediate, register, and implied addressing modes.
* Instruction Formats: The 8085 microprocessor has three instruction formats. These are one byte instructions, two byte instructions, and three byte instructions.
* Instruction Classification: The instructions of the 8085 microprocessor can be classified into five categories. These are data transfer, arithmetic operations, logical operations, branching operations, and machine control. Assembler directives are also supported.
