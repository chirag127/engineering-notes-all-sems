
### Addressing Modes

1. **Immediate Addressing Mode:** In this mode, the instruction itself contains the data which is to be operated upon.

2. **Direct Addressing Mode:** In this mode, the address of the data is specified in the instruction.

3. **Register Addressing Mode:** In this mode, the data is stored in the registers of the processor and the instruction contains the address of the register.

4. **Register Indirect Addressing Mode:** In this mode, the address of the data is stored in the register and the instruction contains the address of the register.

5. **Indexed Addressing Mode:** In this mode, the instruction contains the address of the data which is to be operated upon and the address is modified by an index register.

6. **Relative Addressing Mode:** In this mode, the instruction contains the address of the data which is to be operated upon and the address is modified by the relative address of the program counter.
