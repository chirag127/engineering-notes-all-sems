
### Register Organization for the Notes of the Unit 3 - Architecture of 8086 Microprocessor: 

* Register Organization: The 8086 microprocessor has a total of 14 registers, of which 6 are general purpose registers and 8 are segment registers. The general purpose registers are used to store data, while the segment registers are used to store memory addresses. 

* Bus Interface Unit: The bus interface unit is responsible for communication between the 8086 microprocessor and the external devices. It consists of an address bus, a data bus, and a control bus. 

* Execution Unit: The execution unit is responsible for executing the instructions that are fetched from memory. It consists of an arithmetic logic unit (ALU) and a set of registers. 

* Memory Addressing: The 8086 microprocessor uses a segmented memory addressing system, which allows it to address up to 1MB of memory. 

* Memory Segmentation: Memory segmentation is a technique used by the 8086 microprocessor to divide memory into smaller chunks, which makes it easier to access and manage. 

* Operating Modes: The 8086 microprocessor has two operating modes: real mode and protected mode. Real mode is used for single-tasking applications, while protected mode is used for multitasking applications. 

* Instruction Sets: The 8086 microprocessor supports two instruction sets: the 8086 instruction set and the 80286 instruction set. 

* Instruction Format: The 8086 microprocessor uses a two-byte instruction format, which consists of an opcode and an operand. 

* Types of Instructions: The 8086 microprocessor supports two types of instructions: arithmetic instructions and logical instructions. 

* Interrupts: Interrupts are used to signal the 8086 microprocessor to start executing a specific task. There are two types of interrupts: hardware interrupts and software interrupts.
