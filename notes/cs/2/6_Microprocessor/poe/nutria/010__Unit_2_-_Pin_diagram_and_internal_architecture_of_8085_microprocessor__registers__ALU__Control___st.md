

## Unit 2 - Pin diagram and internal architecture of 8085 microprocessor

* The 8085 microprocessor has 40 pins, arranged in a dual in-line package. 
* The pins are divided into four major groups: power supply pins, address/data pins, control pins and interrupt pins.
* The power supply pins provide the power supply to the microprocessor, while the address/data pins are used to send data to and from the microprocessor.
* The control pins are used to control the timing and operation of the microprocessor, while the interrupt pins are used to signal interrupts to the microprocessor.

### Registers

* The 8085 microprocessor has 8 general purpose registers. 
* These registers are used to store data and addresses. 
* Each register can store 8-bit data and is identified by a 3-bit address. 
* The registers are identified by the letters A, B, C, D, E, H, L and M.

### ALU

* The Arithmetic and Logic Unit (ALU) is the part of the microprocessor that performs arithmetic and logical operations. 
* The ALU is responsible for the execution of instructions such as addition, subtraction, multiplication, division, and logical operations.

### Control & Status

* The Control & Status unit is responsible for controlling the operation of the microprocessor and providing status information. 
* It contains several control and status registers, including the Program Counter (PC), Stack Pointer (SP), and Status Register (SR).

### Interrupts

* Interrupts are special signals that can be sent to the microprocessor to indicate that an event has occurred. 
* The 8085 microprocessor has five interrupt lines, which can be used to signal various types of interrupts. 
* The interrupts are identified by the numbers 0, 1, 2, 3, and 4.

### Machine Cycle

* The machine cycle is the basic unit of operation for the 8085 microprocessor. 
* The machine cycle consists of four steps: fetch, decode, execute, and writeback. 
* During each step, the microprocessor fetches, decodes, executes, and writes back the instruction.

### Instruction Sets

* The instruction set of the 8085 microprocessor consists of a set of instructions that can be used to control the operation of the microprocessor. 
* The instruction set includes instructions for data transfer, arithmetic operations, logical operations, branching operations, machine control and assembler directives.

### Addressing Modes

* The 8085 microprocessor supports several addressing modes, which are used to specify the source and destination of data. 
* The addressing modes include immediate, direct, register, register indirect, indexed, and relative addressing.

### Instruction Formats

* The instruction formats of the 8085 microprocessor are the formats in which instructions are stored. 
* The instruction formats include one-byte, two-byte, and three-byte instructions.

### Instruction Classification

* The instructions of the 8085 microprocessor can be classified into several categories, including data transfer, arithmetic operations, logical operations, branching operations, machine control and assembler directives. 
* Each instruction type has its own set of instructions and addressing modes.
