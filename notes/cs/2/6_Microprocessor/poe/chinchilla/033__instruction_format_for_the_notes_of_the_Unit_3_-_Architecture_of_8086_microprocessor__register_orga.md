

### Instruction Format for Unit 3 - Architecture of 8086 Microprocessor

In this unit, we will be discussing the architecture of the 8086 microprocessor, which includes various components such as register organization, bus interface unit, execution unit, memory addressing, and memory segmentation. We will also be covering the operating modes, instruction sets, instruction format, types of instructions, and interrupts (hardware and software).

Here are the important points to keep in mind while studying the instruction format for the Unit 3 of Architecture of 8086 microprocessor:

- Register Organization: The 8086 microprocessor has a total of 14 registers, which are divided into three categories - general-purpose registers, segment registers, and instruction pointer. The general-purpose registers can be used for any purpose, whereas the segment registers are used to hold the base addresses of the different memory segments. The instruction pointer register holds the address of the next instruction to be executed.

- Bus Interface Unit: The bus interface unit is responsible for interfacing the microprocessor with the external devices. It provides the necessary signals and control lines to communicate with the peripheral devices.

- Execution Unit: The execution unit is responsible for executing the instructions fetched from the memory. It consists of ALU (Arithmetic Logic Unit), flags register, and control unit.

- Memory Addressing: The 8086 microprocessor uses a 20-bit address bus, which means it can access up to 2^20 memory locations. The memory addressing is done using segment and offset addresses.

- Memory Segmentation: The memory is divided into various segments, such as code segment, data segment, stack segment, and extra segment. The code segment contains the executable instructions, whereas the data segment contains the data used by the program.

- Operating Modes: The 8086 microprocessor has two operating modes - minimum mode and maximum mode. In the minimum mode, the microprocessor is interfaced with the peripheral devices directly, whereas in the maximum mode, it is interfaced with the system bus controller.

- Instruction Sets: The 8086 microprocessor has two instruction sets - 8086 instruction set and 8088 instruction set. The 8086 instruction set has 197 instructions, whereas the 8088 instruction set has 113 instructions.

- Instruction Format: The instruction format of the 8086 microprocessor consists of one to six bytes, depending on the type of instruction. The first byte contains the opcode, which specifies the operation to be performed. The remaining bytes contain the operands, which are the data or memory locations used by the instruction.

- Types of Instructions: The instructions in the 8086 microprocessor can be classified into various types, such as data transfer instructions, arithmetic instructions, logical instructions, control transfer instructions, and string instructions.

- Interrupts: The 8086 microprocessor supports two types of interrupts - hardware interrupts and software interrupts. The hardware interrupts are generated by the external devices, whereas the software interrupts are generated by the program itself.

By understanding the instruction format for Unit 3 of Architecture of 8086 microprocessor, you will be able to grasp the functioning of the microprocessor better. It is important to have a clear understanding of each component and its role in the microprocessor.
