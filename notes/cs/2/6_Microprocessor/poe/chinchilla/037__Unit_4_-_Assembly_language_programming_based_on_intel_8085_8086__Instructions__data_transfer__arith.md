## Unit 4 - Assembly language programming based on intel 8085/8086

This unit covers the following topics related to assembly language programming based on Intel 8085/8086:

### Instructions

- An instruction is a command given to the processor to perform a specific operation.
- The Intel 8085/8086 has a set of instructions that can be used to write programs in assembly language.
- The instructions can be classified into data transfer, arithmetic, logic, branch, and control instructions.

### Data transfer

- Data transfer instructions are used to move data between registers, memory locations, and input/output devices.
- The Intel 8085/8086 has instructions such as MOV, MVI, LXI, LDA, STA, LHLD, SHLD, XCHG, etc. for data transfer.

### Arithmetic

- Arithmetic instructions are used to perform arithmetic operations such as addition, subtraction, multiplication, and division on data.
- The Intel 8085/8086 has instructions such as ADD, ADI, ADC, ACI, SUB, SUI, SBB, SBI, INR, DCR, INX, and DCX for arithmetic operations.

### Logic

- Logic instructions are used to perform logical operations such as AND, OR, XOR, and NOT on data.
- The Intel 8085/8086 has instructions such as ANA, ANI, ORA, ORI, XRA, XRI, CMA, and CMP for logical operations.

### Branch operations

- Branch operations are used to change the flow of the program by jumping to a different location in the program based on certain conditions.
- The Intel 8085/8086 has instructions such as JMP, JC, JNC, JZ, JNZ, JP, JM, JPE, and JPO for branch operations.

### Looping, counting, and indexing

- Looping, counting, and indexing are important programming techniques used in assembly language programming.
- The Intel 8085/8086 has instructions such as LOOP, LCALL, RET, and CALL for looping and subroutine calls.

### Programming techniques

- Programming techniques such as counters and time delays are used in assembly language programming to control the execution of the program.
- The Intel 8085/8086 has instructions such as CNT, DELAY, and WAIT for programming techniques.

### Stacks and subroutines

- Stacks and subroutines are used in assembly language programming to store and retrieve data and to call and return from subroutines.
- The Intel 8085/8086 has instructions such as PUSH, POP, and CALL for stacks and subroutines.

### Conditional call and return instructions

- Conditional call and return instructions are used to call and return from subroutines based on certain conditions.
- The Intel 8085/8086 has instructions such as CZ, CNZ, CC, CNC, CP, CM, CPE, and CPO for conditional call and return instructions.

In conclusion, this unit covers a wide range of topics related to assembly language programming based on Intel 8085/8086. It is important to have a good understanding of these topics to write efficient and effective assembly language programs.
