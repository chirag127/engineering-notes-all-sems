### Operating modes for the notes of the Unit 3 - Architecture of 8086 microprocessor: register organization, bus interface unit, execution unit, memory addressing, and memory segmentation. Operating modes. Instruction sets, instruction format, Types of instructions. Interrupts: hardware and software interrupts. in the subject of Microprocessor KCS

Operating modes of 8086 microprocessor:
1. Real address mode (8086 mode)
2. Protected mode (80386 onwards)

Register organization:
1. General purpose registers (AX, BX, CX, DX)
2. Pointer and Index registers (SP, BP, SI, DI)
3. Segment Registers (CS, DS, SS, ES)

Bus Interface Unit:
1. Data bus (16-bit)
2. Address bus (20-bit)
3. Control bus (handles signals related to data transfer)

Execution Unit:
1. Arithmetic and Logical Unit (ALU)
2. Control Unit (CU)

Memory Addressing:
1. Physical addressing (directly accessing memory)
2. Logical addressing (segment:offset addressing)

Memory Segmentation:
1. Code Segment (CS)
2. Data Segment (DS)
3. Stack Segment (SS)
4. Extra Segment (ES)

Instruction Set:
1. Data transfer instructions
2. Arithmetic instructions
3. Logical instructions
4. String instructions
5. Program flow control instructions

Instruction Format:
1. One-byte opcode
2. ModR/M byte (specifies operand type and location)
3. Displacement (optional)
4. Immediate data (optional)

Types of Instructions:
1. Data transfer instructions
2. Arithmetic instructions
3. Logical instructions
4. String instructions
5. Program flow control instructions

Interrupts:
1. Hardware Interrupts (INT, NMI)
2. Software Interrupts (INT instruction)

Note: This information is just a brief overview of the topics and is not exhaustive.
