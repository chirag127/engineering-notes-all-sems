### Python Data Structure: 

Python provides various data structures to store and manipulate data. These data structures can be used in various ways to solve problems in Python programming. In this section, we will discuss the following data structures:

- Tuples
- Unpacking Sequences
- Lists
- Mutable Sequences
- List Comprehension
- Sets
- Dictionaries

#### Tuples:

- Tuples are immutable data structures in Python.
- They are similar to lists but cannot be modified once created.
- Tuples are created using parentheses () or the tuple() function.
- They can be used to store a collection of items that should not be modified.

#### Unpacking Sequences:

- Unpacking sequences is a way of assigning values to multiple variables in a single line of code.
- It can be used with tuples, lists, and other sequences.
- The syntax for unpacking sequences is to list the variables separated by commas and assign the sequence to the variables.

#### Lists:

- Lists are mutable data structures in Python.
- They are created using square brackets [] or the list() function.
- Lists can be used to store a collection of items that can be modified.
- They support various operations like indexing, slicing, appending, and more.

#### Mutable Sequences:

- Mutable sequences include lists and other data structures that can be modified.
- They are useful for storing and manipulating large volumes of data.
- Mutable sequences can be used to store items that can be modified, added, or removed.

#### List Comprehension:

- List comprehension is a concise way of creating lists in Python.
- It combines the elements of a list with a for loop and conditionals.
- List comprehension is a powerful tool for creating lists in a single line of code.

#### Sets:

- Sets are mutable collections of unique elements.
- They are created using the set() function or curly braces {}.
- Sets can be used to perform operations like union, intersection, and difference.

#### Dictionaries:

- Dictionaries are mutable collections of key-value pairs.
- They are created using curly braces {} or the dict() function.
- Dictionaries can be used to store and retrieve data based on keys.
- They support various operations like adding, deleting, and modifying key-value pairs.

### Parts of a Function:

- A function is a block of code that performs a specific task.
- Functions can take parameters and return values.
- A function is defined using the def keyword followed by the function name and parameters.

### Execution of a Function:

- Functions are executed using the function name followed by parentheses and arguments.
- Arguments can be passed by position, keyword, or default.
- Functions can return values using the return keyword.

### Keyword and Default Arguments:

- Keyword arguments allow you to pass arguments to a function by specifying the parameter name.
- Default arguments are used to provide a default value for a parameter if no argument is passed.

### Scope Rules:

- Scope rules determine the visibility of variables in a program.
- Variables can have local or global scope.
- Local variables are defined within a function and are only visible within that function.
- Global variables are defined outside of functions and are visible throughout the entire program.
