### Operator Precedence

**For notes of Unit 1 - Introduction: The Programming Cycle for Python, Python IDE, Interacting with Python Programs, Elements of Python, Type Conversion.**

- Operators are evaluated based on precedence
- Precedence determines the order of evaluation of operators
- Higher precedence operators are evaluated first
- Operators with same precedence are evaluated from left to right

**Precedence Table**

| Operator | Description |
|:-:|:-:|
| () | Parentheses |
| ** | Exponent |
| ~ + - | Unary operators |
| * / % // | Multiplication, division, modulo, and floor division |
| + - | Addition and subtraction |
| >> << | Bitwise right and left shifts |
| & | Bitwise AND |
| ^ | Bitwise XOR |
| \| | Bitwise OR |
| <= < > >= | Comparisons |
| == != | Equality tests |
| = %= /= //= -= += *= **= | Assignment operators |
| is is not | Identity tests |
| in not in | Membership tests |

**Notes**

- Use parentheses to explicitly specify evaluation order
- Exponent has highest precedence
- Multiplication, division, and modulo have higher precedence than addition and subtraction
- Comparisons have lower precedence than arithmetic operators
- Assignment operators have very low precedence
