## Unit 1 - Introduction: The Programming Cycle for Python

1. The Programming Cycle:
    - Analysis: Understand the problem and break it down into smaller steps.
    - Design: Plan the logic and structure of the program.
    - Implementation: Write the program code.
    - Testing: Detect and fix errors.
    - Documentation: Comment and document the code.

2. Python IDE:
    - IDE stands for Integrated Development Environment.
    - It provides a single program that includes all the tools needed for programming.
    - Some popular Python IDEs are:
        - PyCharm: Provides code completion, debugging, and project management features.
        - Visual Studio Code: Open source IDE with support for debugging, syntax highlighting, intelligent code completion, snippets, and code refactoring.
        - Spyder: Popular scientific IDE with variable explorer, interactive console, and debugging features.

3. Interacting with Python Programs
    - The two main ways to run Python code are:
        - Running code in the IDE terminal/console
        - Running Python scripts (.py files) in the terminal/command prompt

4. Elements of Python
    - Some key elements of the Python language are:
        - Indentation: Used to define block structures instead of braces {}
        - Comments: Used to document code and make it more readable; starts with #
        - Variables: Used to store data; does not need types to be defined
        - Data Types: int, float, complex, bool, str, list, tuple, dict, set, frozensets
        - Operators: arithmetic (+, -, *, /, %, **, //), comparison (>, >=, <, <=, ==, !=), logical (and, or, not)
        - Control Flow: if/else statements, for loops, while loops, try/except

5. Type Conversion
    - The process of changing an expression from one data type to another.
    - This is done using type conversion functions like:
        - int() - converts to integer
        - float() - converts to float (decimal)
        - str() - converts to string
        - chr() - converts integer to character
        - ord() - converts single character string to its integer value
