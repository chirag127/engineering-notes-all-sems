## Unit 3 - Function: Parts of A Function , Execution of A Function , Keyword and Default Arguments ,Scope Rules.

### Parts of a Function:

1. Function Definition: It includes the function name, parameters, and function body.
2. Function Name: It is an identifier that represents the function.
3. Parameters: They are the inputs to the function and are enclosed in parentheses.
4. Function Body: It contains a sequence of statements that are executed when the function is called.

### Execution of a Function:

1. When the function is called/invoked, the function definition is evaluated and the function body is executed.
2. The calling statement waits until the called function returns a value.
3. The returned value (if any) is passed back to the calling statement and the function execution ends.

### Keyword and Default Arguments:

1. Keyword arguments: They are arguments which are identified using keywords. They allow passing of arguments in any order.
2. Default arguments: They specify default values for one or more arguments. If the corresponding argument is not passed while calling the function, the default value is used.

### Scope Rules:

1. A variable defined inside a function body has a local scope and can only be accessed inside that function.
2. A global variable can be accessed inside a function. However, if a local variable with the same name is defined inside the function, the local variable shadows the global variable.
