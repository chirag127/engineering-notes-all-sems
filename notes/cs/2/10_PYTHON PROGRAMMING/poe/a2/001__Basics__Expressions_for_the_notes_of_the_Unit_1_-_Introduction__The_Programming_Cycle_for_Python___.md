### Basics: Expressions for the notes of the Unit 1 - Introduction: The Programming Cycle for Python , Python IDE, Interacting with Python Programs , Elements of Python, Type Conversion.

- The Programming Cycle for Python: Analyze the problem, Design the solution, Code the program, Test and Debug, Document the program.
- Python IDE: An Integrated Development Environment (IDE) is a software application that provides comprehensive facilities to computer programmers for software development. Some popular Python IDEs are PyCharm, Spyder, Jupyter Notebook, etc.
- Interacting with Python Programs: You can interact with the Python interpreter in interactive mode or by running .py files. The interactive mode is convenient for testing small bits of code and experimenting. The .py files are required to store the code permanently.
- Elements of Python: Some core elements of Python are:
-- Expressions: Combinations of values, variables, operators, and calls to functions that evaluate to a value.
-- Statements: Instructions that perform some action and do not evaluate to a value.
-- keywords: Special reserved words used in Python syntax. For example: if, else, while, etc.
-- Variables: Containers for storing values.
-- Data types: Classifications that determine the type of value that can be stored in a variable. For example: int, float, str, bool, etc.
- Type Conversion: Changing an entity of one data type into another data type. This is done using constructor functions like: int(), float(), str(), etc. Type conversion is necessary when a value needs to be operated on by a function that requires a specific data type.
