## Unit 3 - Function: Parts of A Function , Execution of A Function , Keyword and Default Arguments ,Scope Rules.

Unit 3 of the subject Python Programming will focus on functions, which are reusable blocks of code that can be called from other parts of a program. Functions are used to encapsulate logic, reduce code duplication, and increase code readability. 

A function in Python consists of the following parts:

1. Function definition: The function definition starts with the keyword `def` followed by the function name, a list of arguments in parentheses, and a colon.

2. Function body: The function body contains the code that is executed when the function is called.

3. Return statement: The return statement is used to return a value from the function.

The general structure of a function in Python is:

```
def function_name(arguments):
    # code to be executed when the function is called
    return value
```

In this unit, you will learn about the parts of a function, including the function definition, function body, and return statement. You will also learn about the execution of a function, including how to call a function, pass arguments to a function, and return a value from a function. You will also learn about keyword and default arguments, and the scope rules that govern the visibility of variables in a function. This will provide a foundation for understanding the principles and practices of functions in Python, and for exploring the various programming concepts and techniques used in Python.
