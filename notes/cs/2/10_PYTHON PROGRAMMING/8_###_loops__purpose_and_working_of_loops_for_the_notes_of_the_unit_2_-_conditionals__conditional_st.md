### Loops: Purpose and working of loops for the notes of the Unit 2 - Conditionals: Conditional statement in Python (if-else statement, its working and execution), Nested-if statement and Elif statement in Python, Expression Evaluation & Float Representation. in the subject of PYTHON PROGRAMMING

Loops are a fundamental concept in programming and are used to repeatedly execute a block of code. They are used to automate repetitive tasks, process data, and control the flow of a program. 

There are two types of loops in Python:

1. For loop: The for loop is used to iterate over a sequence (such as a list, tuple, or string) and execute a block of code for each item in the sequence. 

2. While loop: The while loop is used to repeatedly execute a block of code as long as a certain condition is met.

The general structure of a for loop in Python is:

```
for item in sequence:
    # code to be executed for each item in the sequence
```

The general structure of a while loop in Python is:

```
while condition:
    # code to be executed as long as the condition is met
```
