
### Unit 3 - Control Unit

* Control unit is responsible for controlling the operations of a computer system. 
* It interprets instructions given to it by the user and executes them.
* It fetches instructions from memory, decodes them, and then executes them.
* It also stores the results of the instructions in memory.
* It is responsible for the coordination of all the components of the computer system.
* It also controls the flow of data between the input devices, memory, and output devices.
* It also controls the flow of data between the arithmetic-logic unit and memory.
* It contains a set of registers which are used to store intermediate results.
* It also contains a program counter which stores the address of the next instruction to be executed.
* It also contains a status register which stores the status of the current instruction.
* It also contains a control register which stores the control signals for the various components of the system.
* It also contains a clock which is used to synchronize the operations of the various components of the system.
