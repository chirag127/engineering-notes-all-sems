
### Interrupt Hardware for the Notes of Unit 5 - Input/Output in Computer Organization and Architecture

1. An interrupt is an event that causes a computer to temporarily stop executing its current program and to immediately begin executing a special program known as an interrupt handler.
2. Interrupts are generated by hardware devices such as a keyboard, mouse, or network card, as well as software events such as a program error.
3. The interrupt handler is responsible for responding to the interrupt and returning control to the original program.
4. The interrupt handler typically examines the source of the interrupt and performs any necessary operations.
5. Interrupts can be enabled or disabled by setting a flag in the processor's control registers.
6. Interrupts can be prioritized so that more important events are handled first.
7. Interrupts can be nested, meaning that an interrupt handler can generate another interrupt.
8. Interrupts can be masked, meaning that they are ignored until the processor is ready to handle them.
9. Interrupts can be used to create a multitasking environment.
10. Interrupts can be used to implement communication between different components of a system.
