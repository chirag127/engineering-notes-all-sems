
## Unit 3 - Control Unit

1. Control units are responsible for executing instructions from the processor.
2. They are responsible for decoding instructions and executing them, as well as managing the flow of data between the processor and memory.
3. Control units are responsible for providing timing signals to the processor, memory, and other components of the system.
4. Control units can be divided into three main types: single-cycle, multi-cycle, and pipeline.
5. Single-cycle control units execute one instruction per clock cycle.
6. Multi-cycle control units execute multiple instructions in parallel, each taking multiple clock cycles to complete.
7. Pipeline control units divide instructions into multiple stages, allowing them to be executed in parallel.
8. Control units also contain circuitry that allows them to detect errors in instruction execution and take corrective action.
9. Control units are responsible for managing interrupts, which allow programs to respond to external events.
10. Control units also contain circuitry that allows them to detect and control access to privileged instructions.
