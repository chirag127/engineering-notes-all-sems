

### Instruction Cycles for Unit 3 - Control Unit

1. An instruction cycle is the process of executing a single instruction by the CPU. It consists of four steps: fetch, decode, execute and writeback.

2. The first step of an instruction cycle is the fetch step, in which the instruction is fetched from the memory. The address of the instruction is provided by the program counter.

3. The second step is the decode step, in which the instruction is decoded into a set of commands that the CPU can understand.

4. The third step is the execute step, in which the instruction is executed. This involves the use of the ALU and the data registers.

5. The final step is the writeback step, in which the results of the instruction are written back to the memory.
