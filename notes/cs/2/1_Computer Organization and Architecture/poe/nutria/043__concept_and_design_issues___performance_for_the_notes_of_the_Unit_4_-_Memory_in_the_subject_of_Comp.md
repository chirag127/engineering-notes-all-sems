
### Concept and Design Issues for Memory
1. Memory hierarchy: Memory in a computer system is organized in a hierarchy of storage devices, each having its own access time and cost.
2. Addressability: The size of an addressable memory unit is determined by the number of address lines and the number of bits that can be stored in each addressable unit.
3. Memory interleaving: Memory interleaving is a technique used to increase the speed of access to memory by interleaving multiple memory modules.
4. Cache memory: Cache memory is a fast memory unit used to store frequently used data and instructions.
5. Virtual memory: Virtual memory is a technique used to increase the amount of addressable memory by using disk storage to simulate additional main memory.

### Performance Issues for Memory
1. Access time: Access time is the time taken to access a particular memory location.
2. Bandwidth: Bandwidth is the rate at which data can be transferred between memory and the processor.
3. Capacity: Capacity is the total storage capacity of the memory system.
4. Latency: Latency is the time taken to access a particular memory location.
5. Reliability: Reliability is the ability of the memory system to maintain data integrity.
