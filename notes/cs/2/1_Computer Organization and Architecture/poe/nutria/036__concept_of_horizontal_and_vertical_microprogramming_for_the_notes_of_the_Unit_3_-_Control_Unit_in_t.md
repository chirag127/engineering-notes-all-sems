
### Concept of Horizontal and Vertical Microprogramming for the Notes of the Unit 3 - Control Unit in the Subject of Computer Organization and Architecture 

* Horizontal microprogramming is a type of microprogramming in which the instructions are arranged in a horizontal fashion. This type of microprogramming is often used for low-level machine instructions.

* Vertical microprogramming is a type of microprogramming in which the instructions are arranged in a vertical fashion. This type of microprogramming is often used for high-level machine instructions.

* Control Unit (CU) is the part of the computer's processor which is responsible for controlling the flow of instructions and data. It is also responsible for decoding instructions and activating the appropriate control signals.

* The CU is usually divided into two parts: the instruction register and the control store. The instruction register stores the instructions that are to be executed, while the control store contains the microprograms which are used to decode and execute the instructions.

* The CU also contains several other components such as the program counter, the instruction decoder, and the address generator. The program counter keeps track of the current instruction being executed, while the instruction decoder decodes the instructions and activates the appropriate control signals. The address generator is responsible for generating the addresses for the memory locations where the data is stored.

* The microprograms in the control store are used to decode and execute the instructions. Each instruction is broken down into a sequence of microinstructions which are then executed by the CU. The microinstructions are usually arranged in either a horizontal or a vertical fashion.

* Horizontal microprogramming is often used for low-level machine instructions, while vertical microprogramming is often used for high-level machine instructions. The advantage of horizontal microprogramming is that it is easier to read, while the advantage of vertical microprogramming is that it is more efficient in terms of memory usage.
