
### Types of Buses for the Notes of the Unit 1 - Introduction in the Subject of Computer Organization and Architecture

* Address Bus: The address bus is a collection of wires that carries address information from the processor to the main memory. It is used to specify the location of the data or instructions that are being accessed.

* Data Bus: The data bus is a collection of wires that carries data between the processor and the main memory. It is used to transfer data between the processor and the main memory.

* Control Bus: The control bus is a collection of wires that carries control signals from the processor to the main memory. It is used to control the operations of the main memory such as reading and writing.
