
### Instruction Types for the Notes of the Unit 3 - Control Unit in the Subject of Computer Organization and Architecture

1. Instruction Set: This is a set of instructions that a particular processor can understand and execute. It defines the operations that can be performed by the computer and the format of the data on which the operations are performed.

2. Instruction Format: This is the way in which instructions are represented in machine language. It specifies the length of the instruction and the type of data it contains.

3. Instruction Cycle: This is the process by which a processor executes instructions. It consists of the fetch, decode, and execute steps.

4. Control Unit: This is the part of the processor that is responsible for managing the instruction cycle. It fetches instructions from memory, decodes them, and then executes them.

5. Branching: This is the process by which a processor can change the flow of execution by jumping to a different part of the program. This is used to implement if-then-else statements and loops.

6. Interrupts: This is a signal that can be sent to the processor to temporarily suspend the current instruction cycle and execute a different set of instructions. This is used to handle events such as user input or hardware failures.
