
### Types of Interrupts and Exceptions for Unit 5 - Input/Output in Computer Organization and Architecture

1. Interrupts: Interrupts are signals generated by hardware or software that cause the processor to suspend its current activity and transfer control to an interrupt handler. Interrupts can be generated by external devices such as keyboards and mice, or by software events such as page faults.

2. Exceptions: Exceptions are similar to interrupts in that they cause the processor to suspend its current activity and transfer control to an exception handler. However, exceptions are generated by the processor itself in response to an erroneous condition, such as an attempt to divide by zero or an invalid memory access.

3. Interrupt Priorities: Interrupts can be prioritized by assigning them different levels of priority. Higher priority interrupts will be serviced first, with lower priority interrupts being serviced only after all higher priority interrupts have been serviced.

4. Interrupt Vectors: An interrupt vector is a table of interrupt handlers that is used to determine which handler should be used for a given interrupt. Each entry in the table contains the address of the appropriate handler.

5. Interrupt Masking: Interrupt masking is the process of disabling interrupts so that they will not be serviced until the mask is cleared. This is useful for ensuring that critical sections of code can be executed without interruption.

6. Interrupt Nesting: Interrupt nesting is the process of allowing interrupts to be serviced while another interrupt is already being serviced. This is useful for ensuring that all interrupts are serviced in a timely manner.
