

### Addressing Modes for the Notes of the Unit 1 - Introduction in the Subject of Computer Organization and Architecture

1. Immediate Addressing Mode: This addressing mode involves the use of a constant value in the instruction. The constant value can be a number, character, or address. The constant is part of the instruction and is used by the processor to perform the required operation.

2. Direct Addressing Mode: This addressing mode makes use of the memory address of the operand. The address of the operand is part of the instruction and it is used by the processor to fetch the operand from the memory.

3. Register Addressing Mode: This addressing mode makes use of the registers of the processor to store and access the operands. The processor uses the register number specified in the instruction to access the operand.

4. Indirect Addressing Mode: This addressing mode involves the use of a memory address of the operand. The address of the operand is part of the instruction and it is used by the processor to fetch the memory address of the operand. The processor then uses the memory address of the operand to fetch the operand from the memory.

5. Relative Addressing Mode: This addressing mode makes use of the program counter (PC) to access the operand. The offset is specified in the instruction which is added to the address of the next instruction in the program to obtain the address of the operand.

6. Indexed Addressing Mode: This addressing mode makes use of the index registers to access the operand. The index register is used to store the address of the operand and the processor uses the index register to access the operand.
