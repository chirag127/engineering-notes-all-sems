
### Micro Operations for the Notes of the Unit 3 - Control Unit in the Subject of Computer Organization and Architecture

1. Micro operations are the basic building blocks of computer instructions. They are the smallest operations that can be performed by the processor.

2. Control unit is responsible for fetching instructions from memory, decoding them and executing the instructions. 

3. Control unit also handles the flow of data and instructions between the processor and the memory.

4. It also coordinates the activities of other components of the computer, such as the arithmetic/logic unit, memory, input/output devices, etc.

5. Control unit also contains the program counter which stores the address of the next instruction to be executed.

6. Control unit also contains the instruction register which stores the instruction that is currently being executed.

7. Control unit also contains the status register which is used to store the status of the processor.

8. Control unit also contains the control logic which is responsible for decoding the instructions and generating the control signals for the other components of the computer.
