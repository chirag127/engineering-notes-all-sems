## Unit 4 - Memory

Memory is the ability to encode, store, and retrieve information. In this unit, we will study the different types of memory, the processes involved in memory formation and retrieval, and the factors that affect memory.

### Types of Memory

1. **Sensory Memory**: It is the initial stage of memory that holds sensory information for a brief period.
2. **Short-term Memory**: It is the memory system responsible for holding small amounts of information in our conscious awareness for a short period.
3. **Long-term Memory**: It is the storage of information over an extended period.

### Processes of Memory Formation

1. **Encoding**: It is the process of transforming information into a form that can be stored in memory.
2. **Storage**: It is the process of retaining information in memory over time.
3. **Retrieval**: It is the process of accessing and bringing stored information back into conscious awareness.

### Factors Affecting Memory

1. **Attention**: Paying attention to information increases the likelihood of encoding and retaining it in memory.
2. **Rehearsal**: Repeating information helps in encoding and retaining it in memory.
3. **Emotional State**: Emotions and mood can affect memory formation and retrieval.
4. **Interference**: Interference from other information can disrupt memory.
5. **Stress**: Stress can affect memory formation and retrieval negatively.
6. **Age**: Aging can affect memory function.

Memory is a crucial aspect of our lives, and understanding the processes involved in memory formation and retrieval can help us improve our memory capacity and recall.
