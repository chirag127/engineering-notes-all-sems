### Bus
- A bus is a communication system that transfers data between components inside a computer, or between computers.
- A bus consists of a set of electrical wires that connects major components (CPU, memory and I/O devices) of a computer system.
- A bus can be classified into three types based on the function they perform :
  - Data bus: It carries the data between the components. The width of the data bus determines the amount of data that can be transferred at a time.
  - Address bus: It carries the address of the memory location or I/O device that is to be accessed by the CPU. The width of the address bus determines the maximum memory size or I/O devices that can be addressed by the CPU.
  - Control bus: It carries the control signals that synchronize the operations of the components. The control signals include read, write, interrupt, reset, etc.
- A bus can also be classified into two types based on the topology they use:
  - Parallel bus: It uses multiple wires to transfer data bits simultaneously. It has higher bandwidth but also higher cost and complexity.
  - Serial bus: It uses a single wire to transfer data bits one by one. It has lower bandwidth but also lower cost and simplicity.
- A bus can also be classified into two types based on the arbitration scheme they use:
  - Single bus: It has a single shared bus for all the components. It requires a bus controller or a bus arbiter to resolve the conflicts when multiple components try to access the bus at the same time.
  - Multiple bus: It has multiple dedicated buses for different components or groups of components. It reduces the contention and increases the performance of the system.
