### Interrupt Hardware

- An interrupt is a signal to the processor emitted by hardware or software indicating an event that needs immediate attention.
- Interrupts are commonly used by hardware devices to indicate electronic or physical state changes that require time-sensitive attention. For example, moving a mouse or pressing a keyboard key.
- Interrupts are also commonly used to implement computer multitasking, especially in real-time computing. Systems that use interrupts in these ways are said to be interrupt-driven.
- The purpose of an interrupt is to allow the CPU to handle the most urgent tasks first, and then resume the normal processing.
- An interrupt can be generated by a device or a program to inform the operating system to halt its current activities and focus on something else.
- There are two types of interrupts: hardware interrupts and software interrupts.
- Hardware interrupts are generated by external devices that are connected to the interrupt request line of the CPU. For example, a printer, a disk, a timer, etc.
- Software interrupts are generated by programs that are running on the CPU. For example, a system call, a breakpoint, a division by zero, etc.
- When an interrupt occurs, the CPU saves the current state of the program that is being executed, and then jumps to a specific location in memory where the interrupt service routine (ISR) is stored.
- The ISR is a special program that handles the interrupt and performs the required actions. For example, reading the mouse position, printing a document, etc.
- After the ISR is completed, the CPU restores the state of the interrupted program and resumes its execution.
- Interrupts can be enabled or disabled by the CPU depending on the priority and the need of the system. For example, the CPU may disable interrupts while executing a critical section of code, and then enable them again after the section is completed.
- Interrupts can also be masked or unmasked by the CPU or the device. Masking an interrupt means ignoring it temporarily, while unmasking it means allowing it to be processed.
- Interrupts can be classified into different levels or vectors based on their source and priority. For example, a timer interrupt may have a higher priority than a keyboard interrupt, and a system call may have a lower priority than a division by zero.
- The CPU uses an interrupt vector table (IVT) to store the addresses of the ISRs for each interrupt level or vector. The IVT is usually located at the beginning of the memory.
- When an interrupt occurs, the CPU uses the interrupt level or vector as an index to the IVT, and then jumps to the corresponding ISR address.
