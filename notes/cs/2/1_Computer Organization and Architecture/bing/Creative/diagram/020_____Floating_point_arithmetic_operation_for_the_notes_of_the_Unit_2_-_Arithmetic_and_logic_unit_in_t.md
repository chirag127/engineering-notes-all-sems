### Floating point arithmetic operation

- Floating point arithmetic operation is a way of performing arithmetic operations on real numbers using a fixed number of bits to represent the significand and the exponent of a fixed base.
- The base is usually 2 or 10, and the exponent can be positive or negative. The significand is the part of the number that contains the significant digits, and it is usually normalized to have a leading non-zero digit.
- The advantage of floating point arithmetic is that it can handle a wide range of values with different magnitudes and precisions, unlike fixed point arithmetic which has a fixed number of decimal places.
- The disadvantage of floating point arithmetic is that it can introduce rounding errors, overflow, underflow, and other anomalies that can affect the accuracy and reliability of the results.
- The IEEE 754 standard defines the format and operations for floating point arithmetic in computers. It specifies the bit layout, rounding modes, special values, and exceptions for four basic formats: single precision, double precision, extended precision, and quadruple precision .
- The IEEE 754 standard also defines the required arithmetic operations on floating point numbers, which are addition, subtraction, multiplication, division, square root, and fused multiply-add. These operations must be performed with correct rounding and handling of exceptions.
- The exceptions are situations where the result of an operation is undefined, unsupported, or inaccurate. The IEEE 754 standard defines five types of exceptions: invalid operation, division by zero, overflow, underflow, and inexact .
- The IEEE 754 standard also defines special values for representing infinity, negative zero, and not-a-number (NaN). Infinity is the result of an operation that produces a value too large to be represented by the format. Negative zero is the result of an operation that produces a value too small to be represented by the format. NaN is the result of an operation that is mathematically undefined or indeterminate .
- Floating point arithmetic is implemented by a hardware unit called the floating point arithmetic unit (FPU) or the floating point unit (FPU). The FPU performs the arithmetic operations on floating point numbers using algorithms that are similar to those used on sign magnitude integers.
- The FPU can also perform conversions between different floating point formats, and between floating point and integer formats. The FPU can also support transcendental functions, such as trigonometric, logarithmic, and exponential functions, using approximation methods.
