### Sub cycles

- Sub cycles are the smaller steps that make up an instruction cycle.
- Each instruction cycle consists of four sub cycles: fetch, decode, execute, and store.
- The fetch sub cycle is responsible for fetching the next instruction from the memory and placing it in the instruction register.
- The decode sub cycle is responsible for decoding the instruction and determining the operation code and the operands.
- The execute sub cycle is responsible for performing the operation specified by the instruction and updating the flags register if needed.
- The store sub cycle is responsible for storing the result of the operation in the memory or a register.
- The sub cycles are controlled by the control unit, which generates the appropriate control signals for each sub cycle.
- The control unit can be implemented using hardwired logic or microprogramming.
