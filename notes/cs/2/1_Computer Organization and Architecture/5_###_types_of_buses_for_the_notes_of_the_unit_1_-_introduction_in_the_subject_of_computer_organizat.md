### types of buses for the notes of the Unit 1 - Introduction in the subject of Computer Organization and Architecture

1. Microprocessor-based buses: These buses are used to connect microprocessors to memory and input/output devices. Examples include the ISA, PCI, and AGP buses.

2. Memory buses: These buses are used to connect memory to the microprocessor. Examples include the SDRAM and DDR buses.

3. Input/Output buses: These buses are used to connect input/output devices to the microprocessor. Examples include the USB, SATA, and SCSI buses.

4. System buses: These buses are used to connect all the components of a computer system, including the microprocessor, memory, and input/output devices. Examples include the Front-side bus and Back-side bus.

5. Peripheral buses: These buses are used to connect peripheral devices to the computer system, such as printers and scanners. Examples include the parallel and serial buses.

6. Network buses: These buses are used to connect computers in a network. Examples include the Ethernet and Wi-Fi buses.
