### Functional units of digital system and their interconnections for the notes of the Unit 1 - Introduction in the subject of Computer Organization and Architecture

"Functional Units of Digital Systems and their Interconnections" is a topic covered in Unit 1 - Introduction in the subject of Computer Organization and Architecture.

The following are some of the key terms and concepts that may be covered in the notes for Unit 1 - Introduction:

1. Functional Units: The functional units of a digital system are the basic building blocks that perform specific tasks, such as arithmetic operations, data storage, and data transfer.

2. Arithmetic Logic Unit (ALU): The arithmetic logic unit (ALU) is the functional unit responsible for performing arithmetic operations, such as addition, subtraction, multiplication, and division.

3. Control Unit (CU): The control unit (CU) is the functional unit responsible for controlling the operation of the other functional units in the system, and for coordinating the transfer of data between the functional units.

4. Memory Unit: The memory unit is the functional unit responsible for storing data and instructions, and for providing access to this data and instructions as needed.

5. Input/Output Unit (I/O): The input/output unit (I/O) is the functional unit responsible for communicating with external devices, such as keyboards, mice, and displays.

6. Interconnections: The interconnections between the functional units in a digital system are the pathways that allow data and instructions to be transferred between the functional units.

7. Bus: A bus is a shared pathway that allows multiple functional units to transfer data and instructions to each other.

8. Register: A register is a small storage unit within a functional unit that holds data temporarily, and is used to transfer data between functional units.

9. Instruction Register (IR): The instruction register (IR) is a register within the control unit that holds the current instruction being executed.

10. Program Counter (PC): The program counter (PC) is a register within the control unit that holds the address of the next instruction to be executed.

11. Memory Address Register (MAR): The memory address register (MAR) is a register within the control unit that holds the address of the memory location to be accessed.

12. Memory Data Register (MDR): The memory data register (MDR) is a register within the control unit that holds the data to be written to, or read from, memory.

The goal of studying the functional units of digital systems and their interconnections is to provide students with a comprehensive understanding of the basic building blocks of digital systems, and to develop their skills in designing and implementing these systems. This knowledge and understanding is important for students pursuing careers in computer science and engineering, as it provides the foundation for more advanced topics in the field.
