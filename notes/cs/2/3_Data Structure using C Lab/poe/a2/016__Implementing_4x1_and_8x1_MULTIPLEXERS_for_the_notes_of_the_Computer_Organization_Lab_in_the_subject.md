1. 4x1 Multiplexer

- The truth table shows the input and output combinations.

2. 8x1 Multiplexer
- It has 3 select lines and 8 input lines.

- The truth table shows the input and output combinations.
- The multiplexer circuit is implemented using AND gates, OR gates and inverters.
