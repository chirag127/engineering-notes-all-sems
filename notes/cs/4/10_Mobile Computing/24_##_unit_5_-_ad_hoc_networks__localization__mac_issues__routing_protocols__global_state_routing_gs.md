## Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR),
Unit 5 of Ad Hoc networks covers the following topics:
1. Ad Hoc Networks: A type of wireless network where nodes communicate directly with each other without the need for a central router.
2. Localization: The process of determining the physical location of nodes in an Ad Hoc network.
3. MAC Issues: Medium Access Control issues in Ad Hoc networks, such as how nodes coordinate to transmit data.
4. Routing Protocols: The algorithms used to determine the best path for data to travel from one node to another in an Ad Hoc network.
5. Global State Routing (GSR): A type of routing protocol that uses information about the entire network to determine the best path for data.
