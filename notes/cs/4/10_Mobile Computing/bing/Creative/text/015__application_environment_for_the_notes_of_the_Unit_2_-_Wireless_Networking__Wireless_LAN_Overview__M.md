### Application Environment

- Application environment refers to the set of standards and technologies that enable wireless devices to access internet-based services and applications.
- One of the most widely used application environment standards is the Wireless Application Protocol (WAP), which was developed by a consortium of wireless industry players in 1997.
- WAP defines a protocol suite that consists of application, session, transaction, security, and transport layers, which are optimized for the constraints of wireless networks and devices.
- WAP also defines a Wireless Application Environment (WAE), which provides a vendor-neutral application architecture based on internet standards.
- The WAE supports browsing, scripting, and extensions that allow cellular network operators to offer network services within WAP.
- The WAE defines user agents, services, and formats for wireless applications.
- User agents are applications that run inside a WAP-capable device, such as a mobile phone or a personal digital assistant (PDA).
- Services include an XML-compliant Wireless Markup Language (WML), a scripting language (WMLScript) and supporting libraries, and telephony services provided by the Wireless Telephony Application (WTA) libraries.
- Formats identify each class of information within the WAE, such as WML, WMLScript, or WTA. Formats are encoded and decoded to ensure efficient use of bandwidth.
- WAP enables wireless devices to access a variety of internet-based applications, such as email, web browsing, news, weather, sports, entertainment, education, and e-commerce.
