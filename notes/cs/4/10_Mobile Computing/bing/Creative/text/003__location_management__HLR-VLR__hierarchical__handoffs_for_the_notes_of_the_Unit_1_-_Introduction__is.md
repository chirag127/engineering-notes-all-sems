### Location Management: HLR-VLR, Hierarchical, Handoffs

- Location management is the process of tracking and locating mobile users in a wireless network.
- Location management involves two main operations: location update and location search.
- Location update is the process of informing the network about the current location of a mobile user, usually when the user crosses a predefined boundary, such as a cell or a registration area (RA).
- Location search is the process of finding the current location of a mobile user, usually when the network receives a call or a message for the user.
- Location management schemes aim to balance the trade-off between location update and search costs, which depend on the frequency and pattern of user mobility and communication.
- Location management schemes can be classified into two categories: centralized and distributed.
- Centralized schemes use a single database, such as the Home Location Register (HLR), to store and update the location information of all users in the network. The HLR is contacted for every location search and update operation, which may cause high signaling overhead and congestion.
- Distributed schemes use multiple databases, such as the Visitor Location Registers (VLRs), to store and update the location information of users within their service areas. The VLRs communicate with the HLR and each other to perform location search and update operations, which may reduce the signaling overhead and congestion, but increase the complexity and storage requirements.
- A common distributed scheme is the HLR-VLR scheme, which is used in the Global System for Mobile Communications (GSM) and other cellular networks. In this scheme, the network is divided into registration areas (RAs), each with a VLR. Each RA covers a group of base stations (cells). A user has a permanent HLR, which stores the user's profile and the address of the current VLR. When a user moves from one cell to another within the same RA, the user sends a location update to the current VLR. When a user moves from one RA to another, the user sends a location update to the new VLR, which contacts the HLR and the old VLR to update the location information. When a call or a message arrives for a user, the network contacts the HLR, which provides the address of the current VLR, which then locates the user within its RA and pages the user in the corresponding cell.
- A variation of the HLR-VLR scheme is the forwarding pointer scheme, which uses pointers to link the VLRs that a user has visited. When a user moves from one RA to another, the user sends a location update to the new VLR, which sets up a pointer from the old VLR to the new VLR. The HLR is updated only when the length of the pointer chain reaches a predefined threshold. When a call or a message arrives for a user, the network contacts the HLR, which provides the address of the first VLR, which then follows the pointer chain to reach the current VLR, which then locates and pages the user in the corresponding cell.
- Another variation of the HLR-VLR scheme is the hierarchical scheme, which organizes the VLRs into a hierarchical structure, such as a tree or a graph. The HLR is the root of the hierarchy, and each VLR is a node. When a user moves from one RA to another, the user sends a location update to the new VLR, which updates its parent node in the hierarchy. The HLR is updated only when the user moves across different branches of the hierarchy. When a call or a message arrives for a user, the network contacts the HLR, which provides the address of the parent node of the current VLR, which then searches its subtree to find the current VLR, which then locates and pages the user in the corresponding cell.
- Handoff is the process of transferring an ongoing call or data session from one base station to another, without interrupting the communication, when a user moves across cell boundaries.
- Handoff involves four main steps: handoff initiation, handoff decision, handoff execution, and handoff completion.
- Handoff initiation is the process of detecting the need for a handoff, based on the signal strength, quality, or interference measurements of the current and neighboring base stations.
- Handoff decision is the process of selecting the best candidate base station for the handoff, based on the network policies, user preferences, or resource availability.
- Handoff execution is the process of establishing a new connection with the selected base station, while maintaining the old connection with the current base station, until the handoff is completed.
