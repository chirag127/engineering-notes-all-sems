### Location Management: HLR-VLR, Hierarchical, Handoffs

- Location management is the process of tracking and locating mobile users in a wireless network.
- Location management consists of two main operations: location update and location search (or paging).
- Location update is the process of informing the network about the current location of a mobile user, usually when the user crosses a predefined boundary, such as a cell or a registration area (RA).
- Location search (or paging) is the process of finding the current location of a mobile user, usually when the network needs to deliver a call or a message to the user.
- Location management involves the use of location databases, such as home location register (HLR) and visitor location register (VLR).
- HLR is a centralized database that stores the permanent information of all the users in the network, such as their service profile, billing information, and current location (at the RA level).
- VLR is a local database that stores the temporary information of the users who are currently visiting a certain RA, such as their identity, service profile, and current location (at the cell level).
- HLR and VLR communicate with each other to update and search the location of the users.
- The basic HLR-VLR scheme divides the network into RAs, each with a VLR. Each RA covers a group of cells, each with a base station (BS).
- When a user moves from one cell to another within the same RA, the user sends a location update to the VLR of the current RA, and the VLR updates the user's location at the cell level.
- When a user moves from one RA to another, the user sends a location update to the VLR of the new RA, and the VLR updates the user's location at the cell level and sends a location update to the HLR. The HLR updates the user's location at the RA level and sends a location update to the VLR of the old RA, which deletes the user's record.
- When the network needs to deliver a call or a message to a user, the network queries the HLR to find the user's current RA, and then queries the VLR of that RA to find the user's current cell. The network then pages the user in that cell and establishes the connection.
- The basic HLR-VLR scheme has some drawbacks, such as high signaling overhead, long search delay, and single point of failure.
- To overcome these drawbacks, some variations and enhancements of the basic HLR-VLR scheme have been proposed, such as hierarchical location databases, forwarding pointers, caching, replication, and mobility prediction.
- Hierarchical location databases organize the location information in a tree structure, where each node represents a certain level of granularity, such as a cell, a RA, a cluster, a region, or a zone. The root node represents the entire network and the leaf nodes represent the individual cells.
- Hierarchical location databases reduce the signaling overhead and the search delay by exploiting the locality of user mobility and by limiting the scope of location updates and searches to a certain subtree.
- Forwarding pointers are links that are set up between the VLRs of the old and new RAs when a user moves from one RA to another. The forwarding pointers allow the network to find the user's current location by following the chain of pointers, without querying the HLR.
- Forwarding pointers reduce the signaling overhead and the search delay by avoiding the HLR involvement and by reducing the number of VLRs that need to be queried.
- Caching is a technique that stores the location information of some frequently called or frequently moving users in some intermediate nodes, such as switches or routers, in the network. The caching nodes can answer the location queries for the cached users, without querying the HLR or the VLRs.
- Caching reduces the signaling overhead and the search delay by reducing the number of location queries and by bringing the location information closer to the callers or the users.
- Replication is a technique that copies the location information of some frequently called or frequently moving users to multiple VLRs in the network. The replicated VLRs can answer the location queries for the replicated users, without querying the HLR or the other VLRs.
- Replication reduces the signaling overhead and the search delay by reducing the number of location queries and by increasing the availability of the location information.
