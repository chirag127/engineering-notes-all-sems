### Applications for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

- Ad hoc networks are wireless networks that do not rely on any fixed infrastructure or centralized control. They are composed of mobile nodes that communicate with each other using wireless links. Ad hoc networks have many applications in various domains, such as military, disaster relief, vehicular, sensor, and flying networks  .
- Localization is the process of determining the position of a node or an object in an ad hoc network. Localization is essential for many applications that require location-aware services, such as navigation, tracking, routing, and data aggregation. Localization can be achieved using various techniques, such as GPS, triangulation, range-based, and range-free methods.
- MAC issues refer to the challenges and solutions for medium access control in ad hoc networks. MAC protocols are responsible for coordinating the access of multiple nodes to the shared wireless channel and avoiding collisions. MAC protocols can be classified into two categories: contention-based and contention-free. Contention-based protocols use techniques such as carrier sense multiple access (CSMA), request to send/clear to send (RTS/CTS), and time division multiple access (TDMA). Contention-free protocols use techniques such as code division multiple access (CDMA), frequency division multiple access (FDMA), and orthogonal frequency division multiple access (OFDMA) .
- Routing protocols are the algorithms that enable the nodes in an ad hoc network to discover and maintain routes to each other. Routing protocols can be classified into two categories: proactive and reactive. Proactive protocols maintain routing tables for all nodes in the network and update them periodically. Reactive protocols discover routes on demand when a source node needs to communicate with a destination node. Some examples of proactive protocols are destination-sequenced distance vector (DSDV), global state routing (GSR), and optimized link state routing (OLSR). Some examples of reactive protocols are dynamic source routing (DSR), ad hoc on-demand distance vector (AODV), and temporally ordered routing algorithm (TORA)  .
- Global state routing (GSR) is a proactive routing protocol for ad hoc networks that is based on link state routing. In GSR, each node maintains a global view of the network topology and the link states of all nodes. Each node floods the link state information periodically to the whole network. GSR reduces the overhead of link state routing by using a technique called fish-eye state routing (FSR), which means that each node updates the link state information of the nodes closer to it more frequently than the nodes farther away from it. GSR can achieve low routing delay and high route accuracy, but it may suffer from scalability and bandwidth consumption issues.
