### Application environment for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless

- The application environment refers to the set of standards and protocols that enable wireless devices to communicate with web servers and access internet services.
- The most common application environment for wireless networking is the Wireless Application Protocol (WAP), which was designed to overcome the limitations of mobile devices and networks, such as low bandwidth, high latency, small screens, and limited memory.
- WAP consists of two main components: the Wireless Application Environment (WAE) and the Wireless Session Protocol (WSP).
- The WAE provides a vendor-neutral application architecture based on internet standards, such as XML, HTTP, and TCP/IP. The WAE defines user agents, services, and formats for wireless applications.
- User agents are applications that run inside a wireless device, such as a mobile phone or a PDA. They can be independent or integrated with the device's operating system. User agents can request and display content from web servers using WAP.
- Services are the functionalities and features that WAE offers to user agents and web servers. They include:
  - Wireless Markup Language (WML), which is an XML-compliant language for creating web pages that can be displayed on wireless devices. WML is similar to HTML, but it is optimized for small screens and low bandwidth. WML pages can contain text, images, links, forms, and cards. Cards are logical units of information that can be navigated by the user. WML pages are stored in web servers and have the extension .wml.
  - WMLScript, which is a scripting language for adding interactivity and logic to WML pages. WMLScript is similar to JavaScript, but it is optimized for wireless devices and networks. WMLScript code can be embedded in WML pages or stored in separate files with the extension .wmls. WMLScript code is executed by the user agent or the WAP gateway, depending on the configuration.
  - Wireless Telephony Application (WTA), which is a set of libraries and interfaces that enable user agents to access telephony services, such as voice calls, SMS, and phone book. WTA allows user agents to integrate web applications with mobile network features. WTA uses WML and WMLScript to create user interfaces and control telephony functions.
- Formats are the ways of identifying and encoding different types of information within the WAE. Formats ensure that information sent between user agents and web servers uses minimal bandwidth and is compatible with different devices and networks. Formats include:
  - WML Binary XML (WBXML), which is a binary representation of WML and WMLScript code. WBXML reduces the size of WML and WMLScript files by using tokens and compression techniques. WBXML files have the extension .wbxml.
  - Compiled WMLScript (WMLSC), which is a binary representation of WMLScript code. WMLSC reduces the size and execution time of WMLScript code by using tokens and optimization techniques. WMLSC files have the extension .wmlsc.
  - Content types, which are identifiers that specify the type and format of the information exchanged between user agents and web servers. Content types are based on the MIME standard and are used to negotiate the best format for each request and response. Content types include text/vnd.wap.wml, application/vnd.wap.wmlc, text/vnd.wap.wmlscript, and application/vnd.wap.wmlscriptc.
- The WSP is the protocol that enables user agents to establish and maintain sessions with web servers using WAP. WSP is based on HTTP, but it is optimized for wireless devices and networks. WSP supports features such as connectionless and connection-oriented modes, caching, push, and security.
- WSP is part of the WAP protocol stack, which consists of four layers: WAE, WSP, Wireless Transaction Protocol (WTP), and Wireless Transport Layer Security (WTLS). The WAP protocol stack is mapped onto the wireless network protocols, such as GSM, CDMA, or Bluetooth, using the Wireless Datagram Protocol (WDP).
- The WAP protocol stack is implemented by two entities: the user agent and the WAP gateway. The user agent is the software component that runs on the wireless device and interacts with the WAE and the WSP. The WAP gateway is the software component that runs on the network side and acts as a bridge between the wireless network and the internet. The WAP gateway performs functions such as protocol translation, content adaptation, and security
