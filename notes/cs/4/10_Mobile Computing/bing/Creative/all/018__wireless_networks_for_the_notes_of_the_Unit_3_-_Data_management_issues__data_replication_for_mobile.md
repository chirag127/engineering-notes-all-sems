### Wireless networks for the notes of the Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile in the subject of Mobile Computing

- Wireless networks are networks that use radio waves or other wireless technologies to connect devices without cables or wires.
- Wireless networks enable mobile computing, which is the ability to access and process data from anywhere and anytime using portable devices such as laptops, smartphones, tablets, etc.
- Mobile computing poses several challenges for data management, such as:
  - Limited bandwidth and high latency of wireless links
  - Frequent disconnections and mobility of devices
  - Heterogeneity and diversity of devices and networks
  - Limited resources and battery power of mobile devices
  - Security and privacy issues
- Data management issues in mobile computing can be classified into three categories:
  - Data dissemination: how to efficiently deliver data from data sources to mobile devices
  - Data synchronization: how to maintain consistency and currency of data across multiple replicas
  - Data caching: how to store and access data locally on mobile devices to reduce communication cost and improve availability
- Data replication is a technique that creates and maintains multiple copies of data on different devices or locations. Data replication can improve data availability, reliability, performance, and fault tolerance in mobile computing.
- Data replication for mobile computers can be done in different ways, such as:
  - Static replication: the number and location of replicas are fixed and predetermined
  - Dynamic replication: the number and location of replicas are determined at runtime based on various factors such as access patterns, network conditions, device resources, etc.
  - Full replication: all data items are replicated on all devices
  - Partial replication: only a subset of data items are replicated on each device
  - Eager replication: replicas are updated as soon as a data item is modified
  - Lazy replication: replicas are updated periodically or on demand
- Data replication for mobile computers involves several trade-offs and challenges, such as:
  - Communication cost: the amount of data transferred between devices to create and update replicas
  - Storage cost: the amount of memory or disk space required to store replicas on each device
  - Consistency: the degree to which replicas reflect the same state of data
  - Concurrency: the ability to handle multiple simultaneous or conflicting updates to data
  - Recovery: the ability to restore data after failures or disconnections
  - Security: the protection of data from unauthorized access or modification
- Adaptive clustering is a technique that organizes mobile devices into groups or clusters based on their proximity, connectivity, or similarity. Adaptive clustering can improve data management in mobile wireless networks by:
  - Providing spatial reuse of bandwidth due to node clustering
  - Enabling bandwidth sharing or reservation in a controlled fashion in each cluster
  - Supporting dynamic reconfiguration of clusters as nodes move, join, or leave
  - Reducing the overhead of routing and broadcasting messages
  - Enhancing the scalability and robustness of the network
- Adaptive clustering for mobile wireless networks can be done in different ways, such as:
  - Centralized clustering: one node in each cluster acts as the clusterhead and coordinates the activities of other nodes
  - Distributed clustering: nodes in each cluster cooperate and communicate with each other to form and maintain clusters
  - Hierarchical clustering: clusters are organized into multiple levels of hierarchy, with higher-level clusters containing lower-level clusters
  - Flat clustering: clusters are organized into a single level of hierarchy, with no subclusters
  - Overlapping clustering: nodes can belong to more than one cluster
  - Non-overlapping clustering: nodes can belong to only one cluster
- Adaptive clustering for mobile wireless networks involves several trade-offs and challenges, such as:
  - Cluster formation: how to select clusterheads and cluster members based on various criteria such as node degree, node ID, node location, node mobility, node battery, etc.
  - Cluster maintenance: how to handle cluster changes due to node movement, node failure, node insertion, or node removal
  - Cluster communication: how to route or broadcast messages within or between clusters
  - Cluster performance: how to measure and optimize the efficiency, stability, and quality of clusters
  - Cluster security: how to protect clusters from malicious attacks or intrusions
