The air interface is the communication link between the two stations in mobile or wireless communication. It involves both the physical and data link layers of the OSI model. The physical layer is usually radio-based and uses antennas to transmit and receive electromagnetic waves. The data link layer is often divided into sublayers that handle media access control, logical link control, and radio resource control.

The air interface is the radio-frequency portion of the circuit between the mobile phone and the active base station. As a subscriber moves from one cell to another in the system, the active base station changes periodically. This is known as a handoff. The air interface can use different technologies and standards to provide wireless connectivity, such as GSM, CDMA, LTE, or 5G NR. Each technology has its own characteristics and specifications for data rates, frequency bands, modulation schemes, channel access methods, and so on. The air interface can also support different applications and use cases, such as voice, data, video, IoT, or mission-critical communications. The air interface is a key component of wireless telephony and mobile computing.
