## Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR)

1. **Ad Hoc networks**: An ad hoc network is a type of wireless network that is created spontaneously and does not rely on any pre-existing infrastructure. Nodes in an ad hoc network communicate with each other directly, without the need for a central router or access point.

2. **Localization**: Localization is the process of determining the physical location of a device or node in a network. This can be achieved through various methods, such as GPS, triangulation, or time-of-arrival measurements.

3. **MAC issues**: The medium access control (MAC) layer is responsible for controlling access to the shared communication medium in a network. In ad hoc networks, where there is no central control, MAC protocols must be designed to handle issues such as hidden and exposed terminal problems, and to ensure fair access to the medium.

4. **Routing protocols**: Routing protocols are used to determine the best path for data to travel from one node to another in a network. In ad hoc networks, where the topology is constantly changing, routing protocols must be able to quickly adapt to changes and find new routes.

5. **Global state routing (GSR)**: Global state routing is a type of routing protocol that maintains global information about the network topology. Each node maintains a complete view of the network and uses this information to make routing decisions. GSR can be more efficient in networks with low mobility, but may not scale well in larger networks or in networks with high mobility.
