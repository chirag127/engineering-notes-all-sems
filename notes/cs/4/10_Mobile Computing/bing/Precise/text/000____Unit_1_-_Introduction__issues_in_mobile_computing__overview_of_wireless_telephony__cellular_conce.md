## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

1. **Introduction:** Mobile computing refers to the use of computing devices that are portable and can be used while on the move. These devices include smartphones, tablets, laptops, and wearable devices. Mobile computing has revolutionized the way we live, work, and communicate.

2. **Issues in mobile computing:** Some of the issues in mobile computing include security, privacy, data synchronization, and power management. Mobile devices are vulnerable to security threats such as viruses, malware, and hacking. Privacy is also a concern as personal information can be accessed by unauthorized parties. Data synchronization is important to ensure that data is consistent across multiple devices. Power management is crucial as mobile devices rely on battery power and need to be charged regularly.

3. **Overview of wireless telephony:** Wireless telephony refers to the use of wireless communication technology to transmit voice and data signals. This technology has evolved over the years, with the first generation (1G) being analog and the current generation (5G) being digital.

4. **Cellular concept:** The cellular concept is the foundation of wireless telephony. It involves dividing a geographical area into smaller areas called cells, each served by a base station. This allows for efficient use of the available frequency spectrum and enables a large number of users to be served simultaneously.

5. **GSM:** Global System for Mobile Communications (GSM) is a digital mobile telephony standard that is widely used around the world. It is a second-generation (2G) technology that uses Time Division Multiple Access (TDMA) to transmit voice and data signals. GSM offers features such as voice calls, text messaging, and data transmission.
