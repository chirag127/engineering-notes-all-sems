### Location Management: HLR-VLR, Hierarchical, Handoffs

Location management is a key aspect of mobile computing, as it allows the network to keep track of the location of mobile devices. This is necessary for the delivery of services such as voice calls and data transmission.

- **HLR-VLR:** The Home Location Register (HLR) and Visitor Location Register (VLR) are two databases used in location management. The HLR stores information about the subscribers of a mobile network, including their current location. The VLR, on the other hand, is a temporary database that stores information about the subscribers currently located in a particular area.

- **Hierarchical:** Location management can be implemented in a hierarchical manner, where the network is divided into multiple levels of hierarchy. At the top level, there is a central database that stores information about the location of all mobile devices. At lower levels, there are regional databases that store information about the location of mobile devices within a particular region.

- **Handoffs:** Handoffs refer to the process of transferring an ongoing call or data session from one base station to another as the mobile device moves between the coverage areas of different base stations. This is necessary to maintain the continuity of the call or data session. Handoffs can be classified into two types: hard handoffs and soft handoffs. In a hard handoff, the connection to the old base station is terminated before the connection to the new base station is established. In a soft handoff, the connection to the old base station is maintained until the connection to the new base station is established.
