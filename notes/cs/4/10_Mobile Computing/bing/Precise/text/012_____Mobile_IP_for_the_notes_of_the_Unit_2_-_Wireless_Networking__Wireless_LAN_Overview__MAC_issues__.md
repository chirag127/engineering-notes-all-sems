### Mobile IP

Mobile IP is a protocol that allows mobile devices to move between different networks while maintaining a permanent IP address. It is an extension of the Internet Protocol (IP) designed to enable the mobility of devices. Here are some key points to note about Mobile IP:

1. Mobile IP is used to maintain internet connectivity while a device moves between different networks.
2. It allows a device to keep the same IP address even when it moves to a different network.
3. Mobile IP uses two addresses: a home address and a care-of address.
4. The home address is the permanent IP address of the device, while the care-of address is the temporary address assigned to the device when it moves to a new network.
5. Mobile IP uses a home agent and a foreign agent to facilitate communication between the mobile device and the network.
6. The home agent is responsible for forwarding packets to the mobile device's care-of address, while the foreign agent is responsible for delivering the packets to the mobile device.
7. Mobile IP is an important protocol for enabling seamless internet connectivity for mobile devices.
