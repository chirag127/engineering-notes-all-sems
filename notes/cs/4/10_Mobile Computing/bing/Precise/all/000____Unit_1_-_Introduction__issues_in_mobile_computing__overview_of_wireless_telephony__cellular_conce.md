## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

1. **Introduction:** Mobile computing refers to the use of computing devices that are not restricted to a fixed location and can be used while on the move. These devices include smartphones, tablets, laptops, and wearable devices.

2. **Issues in mobile computing:** Some of the issues in mobile computing include limited battery life, security concerns, and the need for reliable and fast wireless connectivity.

3. **Overview of wireless telephony:** Wireless telephony refers to the use of wireless communication technologies to transmit voice and data over a distance without the use of wires.

4. **Cellular concept:** The cellular concept is the foundation of modern wireless telephony. It involves dividing a large geographic area into smaller cells, each with its own base station. This allows for efficient use of the available radio spectrum and enables a large number of users to be served simultaneously.

5. **GSM:** GSM (Global System for Mobile Communications) is a standard for digital mobile telephony. It is widely used around the world and provides features such as voice calls, text messaging, and data transmission. GSM uses the cellular concept and operates in the 900 MHz and 1800 MHz frequency bands. It is a second-generation (2G) mobile technology.
