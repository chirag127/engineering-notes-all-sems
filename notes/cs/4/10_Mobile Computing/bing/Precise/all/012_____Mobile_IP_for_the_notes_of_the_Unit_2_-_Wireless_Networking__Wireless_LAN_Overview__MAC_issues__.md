### Mobile IP

Mobile IP is a protocol that allows mobile devices to maintain their internet connection while moving between different networks. It is a standard developed by the Internet Engineering Task Force (IETF) and is defined in RFC 5944.

Here are some key points to remember about Mobile IP:

1. Mobile IP is designed to enable seamless roaming of mobile devices across different IP networks.
2. It allows a mobile device to use the same IP address, regardless of its location, and to maintain ongoing connections while moving between networks.
3. Mobile IP uses two addresses: a home address and a care-of address. The home address is the permanent IP address of the mobile device, while the care-of address is the temporary address assigned to the device while it is connected to a foreign network.
4. Mobile IP uses a home agent and a foreign agent to facilitate communication between the mobile device and the network. The home agent is located on the home network, while the foreign agent is located on the foreign network.
5. When a mobile device moves to a new network, it registers its new care-of address with its home agent. The home agent then forwards any packets addressed to the mobile device's home address to its care-of address.
6. Mobile IP can be used with both IPv4 and IPv6 networks.
