
## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

* Mobile computing is a technology that allows computing devices to be used while moving between different physical locations. It is a type of computing that is done on a device such as a smartphone, laptop, or tablet.
* Issues in mobile computing include security, data protection, battery life, and limited storage.
* Wireless telephony is a technology that allows voice and data to be transmitted wirelessly over a network.
* The cellular concept is a type of wireless telephony that divides a geographic area into cells, each of which has its own base station.
* GSM (Global System for Mobile Communications) is a cellular concept that is used in many countries around the world. It is the most widely used cellular network in the world and is used for both voice and data communication.
