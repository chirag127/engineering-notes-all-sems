
### Mobile IP for the Notes of Unit 2 - Wireless Networking

* Mobile IP is an Internet Protocol (IP) that enables users to use the same IP address while roaming from one network to another. 
* A Wireless Local Area Network (WLAN) is a type of computer network that uses radio waves to provide wireless high-speed Internet and network connections.
* Medium Access Control (MAC) is a protocol layer that provides services to the network layer and is responsible for media access control.
* IEEE 802.11 is a set of standards for wireless networking developed by the Institute of Electrical and Electronics Engineers.
* Bluetooth is a wireless technology standard for exchanging data over short distances from fixed and mobile devices.
* Wireless networks can be used in a variety of applications, such as connecting computers to the Internet, connecting printers and other peripherals, and connecting mobile devices to each other.
