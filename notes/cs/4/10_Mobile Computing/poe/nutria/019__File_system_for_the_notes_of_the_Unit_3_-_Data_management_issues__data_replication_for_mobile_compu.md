
### File System for the Notes of the Unit 3 - Data Management Issues, Data Replication for Mobile Computers, Adaptive Clustering for Mobile in the Subject of Mobile Computing 

1. Data Management Issues: Data management is the process of organizing, storing and maintaining digital information. It is important for mobile computing as it allows for efficient storage and retrieval of data. Data management issues include data security, data integrity and data availability.

2. Data Replication for Mobile Computers: Data replication is the process of copying data from one location to another. It is important for mobile computing as it allows for data to be accessible from multiple locations. Data replication can be done manually or automatically.

3. Adaptive Clustering for Mobile: Adaptive clustering is the process of organizing data into clusters based on certain criteria. It is important for mobile computing as it allows for efficient data storage and retrieval. Adaptive clustering can be used to improve the performance of mobile applications.
