### File system for the notes of the Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile

1. Data management issues:
- Limited storage capacity
- Limited battery power
- Limited bandwidth
- Data inconsistency

2. Data replication for mobile computers:
- Master-slave replication: All writes go to master which replicates to slaves. Good for reads, not writes.
- Peer-to-peer replication: Each peer can receive updates from others. Complex to implement.
- Caching: Frequently accessed data cached for fast access. Need to maintain consistency.

3. Adaptive clustering for mobile:
- Nodes organized into clusters based on location proximity.
- Clustering adapts to device mobility.
- Delay-tolerant network used to exchange data between nodes and clusters.
- Data availability and consistency are key challenges.
