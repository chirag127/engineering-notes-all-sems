### Protocol Stack for Wireless Networking

- Physical Layer: Converts data into radio signals and sends them over the air. Specifies modulation techniques, frequency bands, etc.
- MAC Layer: Handles access to the shared wireless medium. Specifies MAC protocols like CSMA/CA. Also handles framing of network packets.
- Network Layer: Same as in wired networks. IP addresses are used to identify devices.
- Transport Layer: Same as in wired networks. Provides end-to-end connectivity and flow control.
- Application Layer: Same as in wired networks. Various applications like web, mail, streaming media, etc. operate at this layer.

### IEEE 802.11 Wireless LAN

- Uses 2.4 GHz or 5 GHz ISM band.
- Uses CSMA/CA protocol for medium access.
- Supports data rates of 1-54 Mbps (802.11a/b/g) or upto 600 Mbps (802.11n/ac).
- Has a basic service set (BSS) which is a group of connected devices. An extended service set (ESS) can be formed by connecting multiple BSSs.
- Uses various security mechanisms like WEP, WPA, WPA2 to authenticate devices and encrypt data.

### Bluetooth

- Uses 2.4 GHz ISM band and frequency hopping spread spectrum.
- Used for short range wireless connectivity between devices like headsets, speakers, keyboards, etc.
- Has a master-slave architecture with one master device coordinating connections between slave devices.
- Supports data rates of 1-3 Mbps.
- Uses various profiles to specify usage models for different types of devices.
