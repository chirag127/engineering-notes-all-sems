### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

1. Wireless Application Protocol (WAP) Architecture
- WAP stack: WAP, WTP, WSP, WDP, WTLS
- WAP gateway: converts WAP to HTTP and vice-versa
- WAP push: service indication, service loading

2. Wireless LAN Overview
- Infrastructure network: access point, distribution system
- Ad-hoc network: decentralized, peer-to-peer
-Coverage, data rate, security trade-offs

3. Medium Access Control (MAC) Issues
- Hidden terminal problem and exposed terminal problem
- Contention-based access: CSMA/CA, slotted ALOHA
- Contention-free access: TDMA, FDMA, CDMA

4. IEEE 802.11 Standards
- 802.11: 2Mbps, 2.4GHz, FHSS
- 802.11a: 54Mbps, 5GHz, OFDM
- 802.11b: 11Mbps, 2.4GHz, DSSS
- 802.11g: 54Mbps, 2.4GHz, OFDM
- 802.11n: 600Mbps, 2.4/5GHz, MIMO-OFDM

5. Bluetooth
- Frequency hopping spread spectrum (FHSS)
- Master-slave architecture: piconet, scatternet
- Profiles: hands-free, cordless phone, LAN access, etc.

6. Other Wireless Technologies
- Infrared: line-of-sight, limited range
- UWB: low power, high bandwidth
- WiMAX: metropolitan area network wireless access
