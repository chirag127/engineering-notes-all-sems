### Channel allocation in cellular systems

- Cellular systems divide the service area into small geographical units called cells. Each cell is served by a fixed transmitter/receiver called base station (BS).
- Cells are allocated a set of radio frequency channels which are reused in a periodic pattern of reusing distance. This is known as frequency reuse.
- The frequency reuse pattern is designed such that co-channel cells (cells using the same set of channels) are separated sufficiently so that unacceptable interference does not occur. This separation is known as reuse distance.
- The pattern of channel allocation to different cells in a cellular system is called channel allocation pattern or frequency assignment pattern. Efficient channel allocation patterns maximize the carrier to interference ratio andminimize the number of co-channel cells.
- The channel allocation problem is to allocate a limited number of channels to the cells in a wireless network such that the signal to interference ratio is maximized. This is an NP-hard problem. Heuristic algorithms are used to obtain sub-optimal solutions.
- Some commonly used channel allocation patterns are cluster size of 7, 4/12 and 1/3 reuse patterns. Larger cluster sizes reduce interference but fewer channels are available per cell. Smaller cluster sizes increase capacity but inter-cell interference is higher.
- Adaptive channel allocation is a technique where channels are allocated dynamically based on real-time traffic demand and interference conditions. This provides highertrunking efficiency compared to fixed allocation patterns.
