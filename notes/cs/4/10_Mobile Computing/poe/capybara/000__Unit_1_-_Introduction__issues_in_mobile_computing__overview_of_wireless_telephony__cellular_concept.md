## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

1. Introduction:
   - Mobile computing is the ability to use computing devices while on the move.
   - It allows users to access information and communicate from anywhere.
   - The evolution of mobile computing has led to the development of wireless telephony.

2. Issues in Mobile Computing:
   - Security: Mobile devices are vulnerable to hacking and cyber attacks.
   - Battery Life: Mobile devices have limited battery life, which affects their usability.
   - Network Coverage: Mobile devices rely on network coverage, which can be limited in certain areas.
   - Compatibility: Mobile devices may not be compatible with certain software or hardware.

3. Overview of Wireless Telephony:
   - Wireless telephony refers to the ability to make and receive calls without the use of wires.
   - It is based on the cellular concept, which divides a geographic area into smaller cells.
   - Each cell has a base station that communicates with mobile devices in that area.
   - The base stations are connected to a central network, allowing users to make and receive calls from anywhere within the network.

4. GSM:
   - GSM (Global System for Mobile Communications) is a standard for wireless telephony.
   - It is used by over 80% of the world's mobile networks.
   - GSM uses a SIM (Subscriber Identity Module) card to identify the user and store information.
   - It allows users to make and receive calls, send text messages, and access data services such as the internet. 

In conclusion, mobile computing and wireless telephony have revolutionized the way we communicate and access information. Understanding the issues and concepts behind these technologies is crucial for anyone interested in the field. GSM is a widely used standard that allows users to enjoy the benefits of wireless telephony.
