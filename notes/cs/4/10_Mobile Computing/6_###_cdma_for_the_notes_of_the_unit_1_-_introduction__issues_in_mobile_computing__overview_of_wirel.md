### CDMA for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

Code Division Multiple Access (CDMA) is a wireless communication technology used in mobile networks to support multiple users simultaneously. CDMA works by encoding each user's data with a unique code, which is then transmitted over the same frequency band. At the receiver, the data is decoded using the same code, allowing the receiver to separate the data from multiple users.

Advantages of CDMA include:

1. Increased capacity: CDMA allows multiple users to share the same frequency band, increasing the capacity of the network.

2. Improved security: CDMA provides improved security, as the data from each user is encoded with a unique code, making it difficult for unauthorized users to access the data.

3. Interference rejection: CDMA is designed to reject interference from other users, allowing for reliable communication even in environments with high levels of interference.

Disadvantages of CDMA include:

1. Complexity: CDMA is a complex technology, requiring specialized hardware and software to implement.

2. Limited bandwidth: CDMA requires a large bandwidth to support multiple users, which can be a challenge in certain environments.

3. Reduced data rate: CDMA can result in a reduced data rate compared to other wireless technologies, such as Time Division Multiple Access (TDMA).

In conclusion, CDMA is a wireless communication technology used in mobile networks to support multiple users simultaneously. CDMA works by encoding each user's data with a unique code, which is then transmitted over the same frequency band. CDMA has advantages, including increased capacity, improved security, and interference rejection, but also has disadvantages, including complexity, limited bandwidth, and reduced data rate.
