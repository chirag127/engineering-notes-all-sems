### First Order Predicate Logic for the notes of the Unit 3 - Knowledge Representation in the subject of Artificial Intelligence
First Order Predicate Logic (FOPL) is a formal system for representing knowledge and reasoning about the world. It consists of:
1. Predicates: represent properties or relations between objects
2. Variables: stand for objects
3. Quantifiers: specify the scope of variables
4. Sentences: built using predicates, variables, and quantifiers
5. Rules of inference: used to deduce new sentences from existing ones.
FOPL provides a way to describe relationships between objects and properties, and to reason about them using logical inference. It is widely used in Artificial Intelligence for knowledge representation and automated reasoning.
