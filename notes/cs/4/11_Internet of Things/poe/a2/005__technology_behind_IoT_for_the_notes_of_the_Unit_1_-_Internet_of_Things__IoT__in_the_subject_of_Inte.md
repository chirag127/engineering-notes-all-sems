### Technology behind IoT

1. Connectivity Technologies: The connectivity technologies that enable the Internet of Things include:
- Wi-Fi: Wi-Fi allows devices to connect to the internet wirelessly using radio waves. Wi-Fi enabled devices can connect to the internet via Wi-Fi hotspots or routers in homes/offices.
- Bluetooth: Bluetooth is a wireless technology standard for exchanging data over short distances using radio waves. It allows devices like headphones, speakers, wearables etc. to connect to other nearby devices like smartphones, tablets etc.
- Cellular: Cellular connectivity uses mobile networks to allow devices to connect to the internet. This allows IoT devices to stay connected even when there is no Wi-Fi network available.
- NFC: Near Field Communication (NFC) is a short-range wireless technology that allows devices brought in close proximity to establish radio communication. It is commonly used for contactless payments, data sharing etc.

2. Embedded Systems and Sensors: Embedded systems are small specialized computer systems that are embedded inside electronic devices to control their functions. Sensors are devices that detect and respond to physical inputs like light, heat, motion, pressure etc. These two components along with connectivity form the basic building blocks of IoT devices.

3.Data Storage and Analytics: The huge amounts of data generated by IoT devices need to be stored, processed and analyzed to derive insights and enable automation. This requires cloud storage, computing resources and analytical capabilities. Cloud platforms like AWS and Azure provide services for data storage, processing and analytics.

4.Software and Protocols: IoT systems require software and protocols to facilitate communication between devices, internet applications and networks. Some of the common IoT protocols are:
- Message Queue Telemetry Transport (MQTT)
- Constrained Application Protocol (CoAP)
- Data Distribution Service (DDS)
- Advanced Message Queuing Protocol (AMQP)
