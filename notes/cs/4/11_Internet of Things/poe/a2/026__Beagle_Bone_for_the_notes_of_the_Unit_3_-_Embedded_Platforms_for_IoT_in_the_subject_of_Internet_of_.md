### Beagle Bone for the notes of the Unit 3 - Embedded Platforms for IoT

1. BeagleBone is a low-cost, community-supported development platform for developers and hobbyists.
2. It is a open source hardware single board computer. It can run various operating systems like Linux, Android, etc.
3. It has a ARM Cortex-A8 processor and has inputs and outputs for interfacing with electronic circuits.
4. It has headers allowing for the addition of "cape" add-on boards and other expansion options.
5. It has a number of GPIO pins, SPI, I2C, UART serial interfaces, a microSD slot, HDMI output, and USB host ports.
6. It provides software libraries and development tools for interfacing with electronics.
7. It is suitable for learning about embedded systems and for IoT applications as it provides an affordable development board with good processing power and features for accessing sensors, displays, motors, etc.
8. It has good community support and documentation which helps developers in using the board and resolving any issues.
