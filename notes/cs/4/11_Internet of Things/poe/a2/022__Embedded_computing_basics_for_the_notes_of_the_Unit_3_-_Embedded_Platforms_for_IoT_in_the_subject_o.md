### Embedded computing basics

1. An embedded system is a computer system with a dedicated function within a larger mechanical or electrical system, often with real-time computing constraints.
2. Embedded systems are found in many devices including consumer electronics, appliances, manufacturing machinery, automobiles, medical equipment, cameras, household appliances, airplanes, vending machines, and toys.
3. Common components include:
- Microcontroller or microprocessor: Acts as the 'brain' of the system, responsible for executing program instructions.
- Memory: Stores programming instructions and data.
- I/O interfaces: Allow the system to interact with the external world through various protocols.
- Peripherals: Components which provide extended functionality such as timers, serial communication, ADCs, etc.
4. Real-time systems often require specific timing guarantees to function properly. They may use a real-time operating system to provide higher determinism for critical tasks.
5. Programming languages commonly used for embedded systems include C/C++, assembly language, and platform-specific languages.
6. Popular embedded processor families include ARM, AVR, PIC, Intel 8051, and MSP430. They vary in performance, power usage, functionality, and cost.
7. Debugging embedded systems can be challenging due to limited resources and real-time constraints. Commonly used tools include in-system programmers, logic analyzers, and emulators.
