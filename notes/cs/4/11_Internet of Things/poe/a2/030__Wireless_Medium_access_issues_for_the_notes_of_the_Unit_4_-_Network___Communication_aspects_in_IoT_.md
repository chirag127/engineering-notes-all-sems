### Wireless Medium access issues

1. Collision - When two or more devices transmit signals at the same time, collision occurs which corrupts the data. This needs to be avoided using protocols like CSMA/CA.
2. Hidden node problem - When a node is visible to the access point but not to other nodes, it can lead to collision at the receiver end. This can be avoided using RTS/CTS mechanism.
3. Exposed node problem - When a node avoids transmission due to overhearing of other transmissions unnecessarily, it leads to underutilization of the channel. This can be reduced by optimizing the transmission power and range.
4. Fairness - The medium access protocol should be fair to all nodes in getting access to the channel. This can be achieved using techniques like round-robin, weighted fair queuing, etc.
5. Throughput - The network throughput should be optimized by efficient utilization of the bandwidth and minimizing access delays. This can be done using both contention-based and contention-free protocols suitably.
6. Power consumption - The power consumption should be minimized by using sleep/wake-up schedules for nodes and minimizing retransmissions due to collisions or errors.
7. Scalability - The medium access protocol should be scalable to support a large number of devices in the network. Contention-free protocols offer more scalability compared to contention-based protocols.
