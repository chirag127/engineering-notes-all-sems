### Using Emulator for Programming Arduino (Unit 5 Notes)

1. Download the Arduino IDE and install it.
2. Download the Arduino Simulator and install it. This is the emulator which simulates the Arduino board on your system.
3. Open the Arduino IDE and go to Tools -> Board and select "Arduino/Genuino Uno" board.
4. Go to Tools -> Serial Port and select "Arduino Simulator". This will enable the IDE to communicate with the simulator and not the actual Arduino board.
5. Write the program as usual in the IDE for blinking an LED or any other task.
6. Click on Upload button to upload the code to the simulator.
7. The Serial Monitor will show the output of the simulated Arduino board. You can check if the LED is blinking or the task is performed as expected in the simulator.
8. This is useful when you do not have the Arduino board with you or if the board is not functioning. You can still write and test the programs using the emulator.
