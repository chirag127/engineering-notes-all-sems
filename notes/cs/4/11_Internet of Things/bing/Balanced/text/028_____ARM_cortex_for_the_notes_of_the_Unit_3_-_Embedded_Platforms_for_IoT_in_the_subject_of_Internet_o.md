### ARM cortex

- ARM cortex is a group of 32-bit and 64-bit RISC ARM processor cores licensed by Arm Holdings  .
- ARM cortex cores are intended for application use in embedded systems, such as microcontrollers, ASICs, ASSPs, FPGAs, and SoCs  .
- ARM cortex cores are divided into four profiles: A, R, M, and S.
  - Cortex-A profile: designed for high-performance applications, such as smartphones, tablets, laptops, servers, etc. Supports 32-bit and 64-bit instruction sets, virtual memory, and optional security extensions .
  - Cortex-R profile: designed for real-time applications, such as automotive, industrial, medical, etc. Supports 32-bit instruction set, memory protection, and optional security extensions.
  - Cortex-M profile: designed for low-cost and energy-efficient applications, such as sensors, IoT devices, wearables, etc. Supports 32-bit instruction set, reduced instruction set, and optional security extensions .
  - Cortex-S profile: designed for secure applications, such as smart cards, SIM cards, etc. Supports 32-bit instruction set, reduced instruction set, and security extensions.
- ARM cortex cores have different features and capabilities, such as:
  - Clock speed: the frequency at which the core executes instructions, measured in megahertz (MHz) or gigahertz (GHz).
  - Pipeline: the number of stages in the core that process instructions in parallel, improving performance and efficiency.
  - Cache: the small and fast memory that stores frequently used data and instructions, reducing access time and power consumption.
  - Floating-point unit (FPU): the hardware that performs arithmetic operations on floating-point numbers, improving accuracy and speed.
  - Digital signal processing (DSP) extensions: the instructions that perform common operations on digital signals, such as audio, video, etc., improving performance and efficiency.
  - Memory protection unit (MPU): the hardware that controls the access rights of different regions of memory, preventing unauthorized or erroneous access and improving security and reliability.
  - Memory management unit (MMU): the hardware that translates virtual addresses to physical addresses, enabling virtual memory and memory protection.
  - TrustZone: the security extensions that create a secure and non-secure world, isolating sensitive data and code from potential attacks and improving security and trust.
  - Helium: the technology that extends the SIMD capabilities of the core, enabling parallel processing of multiple data elements and improving performance and efficiency for machine learning and signal processing applications.
