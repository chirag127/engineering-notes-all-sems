### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Raspberry Pi is a small, low-cost, single-board computer that allows people to explore computing and learn programming languages like Scratch and Python .
- Raspberry Pi uses a system on a chip (SoC), which integrates the CPU and GPU in a single integrated circuit, with the RAM, USB ports, and other components soldered onto the board for an all-in-one package.
- Raspberry Pi can be plugged into a computer monitor or TV, and uses a standard keyboard and mouse. It can also connect to the internet via Ethernet or Wi-Fi .
- Raspberry Pi can run various operating systems, such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, and others. It can also run applications and software for different purposes, such as web browsing, gaming, media streaming, robotics, and IoT.
- Raspberry Pi has different models and features, such as Raspberry Pi 400, which is a complete personal computer built into a compact keyboard, and Raspberry Pi Pico, which is a microcontroller board for embedded applications .
- Raspberry Pi is widely used for educational, industrial, and hobbyist projects, such as creating smart devices, controlling robots, making music, and more. It is also supported by a large community of developers, makers, and educators, who share resources and tutorials online .
