### Using libraries for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

- A library is a collection of code that provides extra functionality for use in sketches, such as working with hardware or manipulating data.
- Libraries can be downloaded for free from various sources, such as the Arduino website, GitHub, or other online platforms.
- To use a library in a sketch, select it from Sketch > Import Library in the Arduino IDE, or click the "Include" button in the Arduino Web Editor .
- Some common libraries that are useful for programming the Arduino are:
  - Wire: This library allows communication with I2C devices, such as sensors, LCD displays, or EEPROMs.
  - SPI: This library allows communication with SPI devices, such as SD cards, Ethernet shields, or RFID modules.
  - Servo: This library allows controlling servo motors with PWM signals.
  - LiquidCrystal: This library allows interfacing with LCD displays that use the Hitachi HD44780 driver or compatible chips.
  - WiFi: This library allows connecting to wireless networks and accessing the internet using the Arduino WiFi Shield or the Arduino WiFi 101 Shield.
- To learn more about a specific library, refer to its documentation, examples, and source code.
