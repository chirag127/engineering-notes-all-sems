# ARM cortex

- ARM cortex is a group of 32-bit and 64-bit RISC ARM processor cores licensed by Arm Holdings  .
- ARM cortex cores are intended for application use in embedded systems, such as microcontrollers, ASICs, ASSPs, FPGAs, and SoCs  .
- ARM cortex cores are divided into four profiles: A, R, M, and S.
  - Cortex-A profile: designed for high-performance and complex applications, such as smartphones, tablets, laptops, servers, etc  .
  - Cortex-R profile: designed for real-time and safety-critical applications, such as automotive, industrial, medical, etc .
  - Cortex-M profile: designed for low-cost and energy-efficient applications, such as sensors, IoT devices, wearables, etc  .
  - Cortex-S profile: designed for secure and trusted applications, such as secure boot, secure storage, etc .
- ARM cortex cores support various features and extensions, such as:
  - Thumb instruction set: a 16-bit compressed instruction set that reduces code size and improves performance.
  - NEON technology: a SIMD engine that accelerates multimedia and signal processing applications.
  - Helium technology: a M-Profile Vector Extension (MVE) that enhances the Cortex-M profile with SIMD capabilities.
  - Security extensions: such as TrustZone, which provides hardware isolation and protection for sensitive data and code.
  - Large Physical Address Extension (LPAE): which enables the use of up to 1 TB of physical memory.
  - 64/32-bit architecture: which allows the use of both 64-bit and 32-bit instruction sets and registers.
