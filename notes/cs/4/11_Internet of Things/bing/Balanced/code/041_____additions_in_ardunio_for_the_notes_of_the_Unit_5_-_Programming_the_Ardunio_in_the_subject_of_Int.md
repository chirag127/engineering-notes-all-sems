### Additions in Arduino

- Addition is one of the four primary arithmetic operations. The operator `+` (plus) operates on two operands to produce the sum.
- Syntax: `sum = operand1 + operand2;`
- Example: `int a = 2; int b = 3; int sum = a + b; // sum is 5`
- Addition can also be performed using compound assignment operator `+=`, which adds the right operand to the left operand and assigns the result to the left operand.
- Syntax: `operand1 += operand2;`
- Example: `int x = 10; x += 5; // x is 15`
- Addition can also be performed using increment operator `++`, which increments the value of a variable by 1.
- Syntax: `x++; // increment x by one and returns the old value of x`
- Syntax: `++x; // increment x by one and returns the new value of x`
- Example: `int y = 5; y++; // y is 6`
- Example: `int z = 5; ++z; // z is 6`
- Addition can be used to perform various operations in Arduino, such as adding numbers, concatenating strings, increasing counters, etc.
