### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Raspberry Pi is a small, low-cost, single-board computer that can run various operating systems, such as Linux, Windows 10 IoT Core, and Raspbian.
- Raspberry Pi can be used for various IoT projects, such as smart home automation, environmental monitoring, industrial control, robotics, and more.
- Raspberry Pi has the following features that make it suitable for IoT applications:
  - A powerful CPU that can handle complex computations and data processing.
  - Wireless LAN and Bluetooth 4.1 radio that enable wireless connectivity and communication with other devices and cloud services.
  - A 40-pin GPIO (General Purpose Input/Output) connector that allows interfacing with external sensors, actuators, and other peripherals.
  - A microSD card slot that provides storage for the operating system and user data.
  - A HDMI port that supports video output and a 3.5mm audio jack that supports audio output and input.
  - A micro USB port that provides power supply and data transfer.
  - A camera interface (CSI) and a display interface (DSI) that support connecting a camera module and a touchscreen display respectively.
- Some examples of IoT projects that can be done using Raspberry Pi are:
  - An autonomous irrigation system that monitors soil moisture and weather conditions and controls water valves accordingly.
  - A face recognition robot that uses a camera and a servo motor to track and follow human faces.
  - An industrial IoT controller that replaces programmable logic controllers and performs automated tasks through its GPIO interface.
  - A motion sensor that detects human presence and sends data to a cloud service for analysis and visualization.
  - A smart mirror that displays weather, news, calendar, and other information on a reflective surface.
