## Unit 4 - Network & Communication aspects in IoT

- IoT stands for Internet of Things, which is the connection of devices over the internet, where these smart devices communicate with each other, exchange data, perform some tasks without any human involvement.
- IoT devices can communicate using various methods, such as wired or wireless, local or remote, direct or indirect, point-to-point or point-to-multipoint, etc.
- IoT devices need to use standardized protocols to ensure communication between heterogeneous devices is secure and reliable. Some of the common protocols used in IoT are:
  - IPv6: The latest internet protocol version, which is used for transferring data and communication. Each IoT device has an IP address and networking is the key aspect in the Internet of Things.
  - MQTT: A lightweight publish-subscribe protocol, which is designed for low-bandwidth and high-latency networks. It allows IoT devices to send and receive messages from a central broker.
  - CoAP: A web transfer protocol, which is optimized for constrained devices and networks. It supports RESTful interactions and enables IoT devices to access web services.
  - Zigbee: A wireless mesh network protocol, which is based on IEEE 802.15.4 standard. It enables low-power and low-data-rate communication among IoT devices in a local area network.
  - Bluetooth: A short-range wireless technology, which is widely used for connecting IoT devices to smartphones, tablets, or other devices. It supports various profiles and modes, such as Bluetooth Low Energy (BLE), Bluetooth Mesh, etc.
- IoT devices may also use gateways to translate and re-transmit information, typically linking local device networks to the Internet. Gateways can also provide additional functions, such as data processing, security, or management.
- IoT communication faces various challenges, such as scalability, interoperability, security, privacy, reliability, latency, etc. These challenges require careful design and implementation of the network and communication aspects in IoT.
