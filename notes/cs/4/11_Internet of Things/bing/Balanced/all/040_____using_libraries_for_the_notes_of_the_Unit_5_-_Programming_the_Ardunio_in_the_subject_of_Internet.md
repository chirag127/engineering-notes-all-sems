# Using Libraries for the Notes of the Unit 5 - Programming the Arduino in the Subject of Internet of Things

- Libraries are collections of code that provide extra functionality for use in sketches, such as working with hardware or manipulating data.
- Libraries can be installed from the Arduino IDE, from online sources, or from local files  .
- To use a library in a sketch, it must be imported using the `#include` directive at the beginning of the code .
- Some libraries are built-in to the Arduino IDE, such as the `Wire` library for I2C communication, the `SPI` library for SPI communication, and the `Ethernet` library for internet connectivity.
- Other libraries are contributed by the Arduino community or third-party developers, and can be found in the Library Manager or online  .
- Libraries can be used to interface with various sensors, actuators, displays, communication modules, and other devices that can be connected to the Arduino board .
- Libraries can also be used to implement algorithms, data structures, protocols, and other functionalities that are useful for IoT applications .
- Libraries can be updated, deleted, or modified using the Library Manager or the Arduino Libraries folder  .
- To write a library for the Arduino, the code must be organized into two files: a header file (`.h`) and a source file (`.cpp`), and placed in a folder with the same name as the library.
- The header file contains the declarations of the classes, variables, constants, and functions that are part of the library, and the source file contains the definitions of the functions.
- The library folder must be placed in the Arduino Libraries folder, which is located in the Documents folder by default .
- To use the library in a sketch, it must be included using the `#include` directive, and an object of the library class must be created.
- To share the library with others, it can be compressed into a ZIP file and uploaded to an online repository or website.
