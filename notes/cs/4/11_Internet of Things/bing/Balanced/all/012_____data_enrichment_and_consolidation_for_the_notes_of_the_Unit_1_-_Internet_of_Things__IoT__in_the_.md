# Data enrichment and consolidation for the notes of the Unit 1 - Internet of Things (IoT) in the subject of Internet of Things

- Data enrichment is the process of enhancing, refining, or otherwise improving raw data by adding or merging other data sources.
- Data consolidation is the process of combining data from multiple sources into a single, consistent, and integrated view.
- Data enrichment and consolidation are important for IoT applications because they can improve data visibility, data security, and data analysis options.
- For example, in a supply chain scenario, IoT data from sensors and devices can be enriched with non-IoT data from databases, contracts, or other sources to create a more complete and accurate picture of the assets, transactions, and events .
- Data enrichment and consolidation for IoT can be achieved by using different methods, such as:
  - Node-RED: a graphical tool that allows users to create data flows and connect IoT data with non-IoT data using predefined nodes and functions.
  - Contract: a piece of code that defines the logic and rules for merging IoT data and non-IoT data based on a correlation parameter, such as the IoT device ID.
  - Blockchain: a distributed ledger that stores and verifies the enriched and consolidated data in a secure and immutable way .
