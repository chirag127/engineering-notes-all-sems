# Overview of IoT Supported Hardware Platforms such as Arduino

- IoT (Internet of Things) is the concept of connecting various devices and sensors to the internet and enabling data exchange and communication among them.
- IoT devices require hardware platforms that can support the functionalities of sensing, processing, communication, and actuation.
- There are many IoT hardware platforms available in the market, each with different features, capabilities, and applications.
- Some of the common IoT hardware platforms are:

  - **Arduino**: Arduino is an open-source platform that consists of microcontroller boards, sensors, actuators, and software tools for developing IoT projects. Arduino boards are easy to use, program, and interface with various components. Arduino supports many communication protocols such as WiFi, Bluetooth, LoRa, GSM, etc. Arduino also has a cloud service called Arduino IoT Cloud that allows users to connect, manage, and monitor their IoT devices remotely .
  - **Raspberry Pi**: Raspberry Pi is a single-board computer that can run various operating systems such as Linux, Windows, etc. Raspberry Pi has a powerful processor, memory, and storage that can handle complex tasks and applications. Raspberry Pi can also interface with various sensors, actuators, and peripherals using GPIO pins, USB ports, HDMI ports, etc. Raspberry Pi can communicate with the internet using WiFi, Ethernet, or cellular modules. Raspberry Pi is suitable for IoT projects that require high performance, multimedia, or artificial intelligence .
  - **ESP8266**: ESP8266 is a low-cost and low-power microcontroller that has built-in WiFi capability. ESP8266 can be programmed using Arduino IDE or other tools and can communicate with various cloud services such as AWS, Google Cloud, etc. ESP8266 is ideal for IoT projects that require wireless connectivity, low power consumption, and small form factor .
  - **Intel Edison**: Intel Edison is a tiny computer module that has a dual-core processor, memory, storage, WiFi, Bluetooth, and GPIO pins. Intel Edison can run Linux or other operating systems and can support various sensors, actuators, and peripherals. Intel Edison can also connect to the cloud using Intel IoT Platform or other services. Intel Edison is designed for IoT projects that require high performance, scalability, and security .
  - **Intel Galileo**: Intel Galileo is a microcontroller board that is compatible with Arduino and can run Linux or other operating systems. Intel Galileo has a single-core processor, memory, storage, Ethernet, USB, and GPIO pins. Intel Galileo can interface with various sensors, actuators, and peripherals and can communicate with the cloud using Intel IoT Platform or other services. Intel Galileo is suitable for IoT projects that require Arduino compatibility, Linux support, and Ethernet connectivity .
  - **BeagleBone**: BeagleBone is a single-board computer that can run Linux or other operating systems and can support various sensors, actuators, and peripherals. BeagleBone has a single-core processor, memory, storage, Ethernet, USB, and GPIO pins. BeagleBone can also communicate with the internet using WiFi, Bluetooth, or cellular modules. BeagleBone is ideal for IoT projects that require Linux support, Ethernet connectivity, and low cost .
  - **Banana Pi**: Banana Pi is a single-board computer that can run Android, Linux, or other operating systems and can support various sensors, actuators, and peripherals. Banana Pi has a quad-core processor, memory, storage, Ethernet, USB, HDMI, and GPIO pins. Banana Pi can also communicate with the internet using WiFi, Bluetooth, or cellular modules. Banana Pi is suitable for IoT projects that require Android support, multimedia, or high performance .
  - **NodeMCU**: NodeMCU is a development kit that consists of an ESP8266 microcontroller and a Lua interpreter. NodeMCU can be programmed using Lua or Arduino IDE and can communicate with various cloud services such as AWS, Google Cloud, etc. NodeMCU is ideal for IoT projects that require wireless connectivity, low power consumption, and easy programming .
