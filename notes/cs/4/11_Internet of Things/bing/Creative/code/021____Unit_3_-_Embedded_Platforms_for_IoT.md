# Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are hardware and software systems that enable IoT devices to perform their functions and communicate with other devices and networks.
- Embedded platforms for IoT typically consist of:
  - A microcontroller or microprocessor that executes the application logic and controls the device's sensors and actuators.
  - A memory unit that stores the program code and data.
  - A communication interface that supports wired or wireless connectivity protocols such as Ethernet, Wi-Fi, Bluetooth, Zigbee, LoRa, etc.
  - A power supply that provides the required voltage and current for the device's operation.
  - An operating system or firmware that manages the device's resources and provides a software framework for developing and running IoT applications.
- Embedded platforms for IoT can be classified into different categories based on their performance, power consumption, size, cost, and functionality. Some examples of embedded platforms for IoT are:
  - Mbed OS: An open source platform that provides a secure and scalable software environment for developing IoT applications on ARM-based microcontrollers.
  - Amazon FreeRTOS: A real-time operating system that supports cloud connectivity and security features for IoT devices based on the FreeRTOS kernel.
  - Raspberry Pi: A single-board computer that runs Linux and can be used for prototyping and developing IoT applications using various sensors and modules.
  - Cisco Embedded Services Switches: A series of embedded switches that provide high-bandwidth, security, and edge computing capabilities for industrial IoT applications.
  - AMD Ryzen Embedded and EPYC Embedded Processors: A family of processors that offer high performance, graphics, and security for IoT gateways and edge computing applications.
