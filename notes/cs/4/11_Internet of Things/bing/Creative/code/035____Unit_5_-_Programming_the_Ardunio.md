## Unit 5 - Programming the Ardunio

- Arduino is an open-source platform that consists of a hardware board and a software IDE (Integrated Development Environment) that can be used to create and program electronic projects.
- The hardware board is based on a microcontroller, which is a small computer chip that can execute instructions and interact with sensors, actuators, and other components.
- The software IDE is a graphical interface that allows the user to write, compile, and upload code to the board using a programming language called Arduino C/C++.
- Arduino C/C++ is a simplified version of the C and C++ languages, which are widely used for software development. Arduino C/C++ has some specific features and libraries that make it easier to work with the hardware board and its peripherals.
- To program the Arduino, the user needs to connect the board to a computer via a USB cable, launch the IDE, and select the board model and the port from the Tools menu.
- The user can then write the code in the IDE editor, which has syntax highlighting, auto-completion, and error checking features. The code consists of two main functions: setup() and loop().
- The setup() function runs once when the board is powered on or reset, and it is used to initialize variables, pin modes, and libraries. The loop() function runs repeatedly after the setup() function, and it is used to implement the main logic and behavior of the project.
- The user can also define other functions, variables, constants, and data types to organize and simplify the code. The user can also use comments, which are lines of text that are ignored by the compiler, to document and explain the code.
- To upload the code to the board, the user needs to click on the Upload button in the IDE toolbar, which will compile the code and transfer it to the board via the USB cable. The user can then disconnect the board from the computer and power it with a battery or an external power source.
- To debug the code and monitor the board's status, the user can use the Serial Monitor, which is a window in the IDE that displays the data sent and received by the board via the USB cable. The user can use the Serial.print() and Serial.println() functions in the code to send data to the Serial Monitor, and the Serial.read() and Serial.available() functions to read data from the Serial Monitor. The user can also use the Serial Plotter, which is a window in the IDE that displays the data sent by the board as a graph. The user can use the Serial.print() function in the code to send data to the Serial Plotter.
