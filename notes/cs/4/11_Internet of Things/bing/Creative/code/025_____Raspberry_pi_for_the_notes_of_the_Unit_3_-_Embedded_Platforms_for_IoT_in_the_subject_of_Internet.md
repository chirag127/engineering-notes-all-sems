### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Raspberry Pi is a small, low-cost, single-board computer that allows people to explore computing and learn programming languages like Scratch and Python .
- Raspberry Pi uses a system on a chip (SoC), which integrates the CPU and GPU in a single integrated circuit, with the RAM, USB ports, and other components soldered onto the board for an all-in-one package.
- Raspberry Pi can be plugged into a computer monitor or TV, and uses a standard keyboard and mouse. It can also connect to the internet via Ethernet or Wi-Fi .
- Raspberry Pi can run various operating systems, such as Raspberry Pi OS, Ubuntu, Windows 10 IoT Core, and others. It can also run applications, games, and software tools .
- Raspberry Pi can be used for various projects, such as home automation, robotics, media center, web server, retro gaming, and more. It can also interface with sensors, actuators, cameras, and other devices via the 40-pin GPIO header  .
- Raspberry Pi has different models and features, such as Raspberry Pi Zero, Raspberry Pi 4, Raspberry Pi 400, and Raspberry Pi Pico. Each model has different specifications, such as processor speed, memory size, number of ports, and power consumption .
- Raspberry Pi is supported by the Raspberry Pi Foundation, a UK charity that aims to make computing accessible and affordable for everybody. The foundation also provides educational resources, online courses, and community support for Raspberry Pi users.
