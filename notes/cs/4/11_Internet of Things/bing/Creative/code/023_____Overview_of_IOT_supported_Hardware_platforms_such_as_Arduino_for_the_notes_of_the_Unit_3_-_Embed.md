### Overview of IOT supported Hardware platforms such as Arduino

- IoT (Internet of Things) is the concept of connecting various devices and sensors to the internet and enabling data exchange and communication among them.
- IoT devices require hardware platforms that can support the functionalities of sensing, processing, communication, and actuation.
- There are many IoT hardware platforms available in the market, each with different features, capabilities, and applications.
- Some of the common IoT hardware platforms are:

  - **Arduino**: Arduino is an open-source platform that consists of microcontroller boards, sensors, actuators, and software tools for developing IoT projects. Arduino boards are easy to use, program, and interface with various components. Arduino supports many communication protocols, such as WiFi, Bluetooth, LoRa, GSM, etc. Arduino also has a cloud service called Arduino IoT Cloud that allows users to connect, manage, and monitor their devices remotely .
  - **Raspberry Pi**: Raspberry Pi is a single-board computer that runs on Linux operating system and can perform various tasks, such as web browsing, gaming, media streaming, etc. Raspberry Pi can also be used as an IoT device, as it has GPIO pins that can interface with sensors and actuators, and supports various communication protocols, such as WiFi, Bluetooth, Ethernet, etc. Raspberry Pi can also run various IoT platforms, such as Adafruit IO, AWS IoT, Google Cloud IoT, etc .
  - **ESP8266**: ESP8266 is a low-cost WiFi module that can be used to add wireless connectivity to any microcontroller. ESP8266 can also be programmed as a standalone IoT device, as it has a built-in processor, memory, and GPIO pins. ESP8266 can be programmed using Arduino IDE, Lua, Python, etc. ESP8266 can communicate with various cloud services, such as ThingSpeak, Blynk, Firebase, etc .
  - **Intel Edison**: Intel Edison is a tiny computer module that can run Linux or Windows operating system and can perform various tasks, such as image processing, machine learning, etc. Intel Edison can also be used as an IoT device, as it has a built-in WiFi and Bluetooth module, and supports various sensors and actuators through expansion boards. Intel Edison can also run various IoT platforms, such as IBM Watson IoT, Microsoft Azure IoT, Intel IoT Analytics, etc .
  - **Intel Galileo**: Intel Galileo is a microcontroller board that is compatible with Arduino and can run Linux operating system. Intel Galileo can also be used as an IoT device, as it has a built-in Ethernet module, and supports various sensors and actuators through GPIO pins and expansion boards. Intel Galileo can also run various IoT platforms, such as Intel IoT Developer Kit, Intel XDK IoT Edition, Intel IoT Gateway, etc .
  - **BeagleBone**: BeagleBone is a single-board computer that runs on Linux operating system and can perform various tasks, such as robotics, automation, industrial control, etc. BeagleBone can also be used as an IoT device, as it has GPIO pins that can interface with sensors and actuators, and supports various communication protocols, such as WiFi, Bluetooth, Ethernet, etc. BeagleBone can also run various IoT platforms, such as AWS IoT, Google Cloud IoT, IBM Watson IoT, etc .
  - **Banana Pi**: Banana Pi is a single-board computer that runs on Linux or Android operating system and can perform various tasks, such as web browsing, gaming, media streaming, etc. Banana Pi can also be used as an IoT device, as it has GPIO pins that can interface with sensors and actuators, and supports various communication protocols, such as WiFi, Bluetooth, Ethernet, etc. Banana Pi can also run various IoT platforms, such as Baidu IoT, Alibaba IoT, Tencent IoT, etc .
  - **NodeMCU**: NodeMCU is a development kit that consists of an ESP8266 module and a USB-to-serial converter. NodeMCU can be used to program the ESP8266 module using Lua, a scripting language. NodeMCU can also be used as an IoT device, as it has a built-in WiFi module, and supports various sensors and actuators through GPIO pins. NodeMCU can communicate with various cloud services, such as ThingSpeak, Blynk, Firebase, etc .
