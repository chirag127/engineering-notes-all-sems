# ARM cortex for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- ARM cortex is a group of 32-bit and 64-bit RISC ARM processor cores licensed by Arm Holdings  .
- ARM cortex cores are optimized for low-cost and energy-efficient integrated circuits, which are suitable for embedded platforms for IoT.
- ARM cortex cores are divided into three profiles: A, R, and M.
  - Cortex-A profile: for high-performance and complex applications, such as smartphones, tablets, servers, etc .
  - Cortex-R profile: for real-time and safety-critical applications, such as automotive, industrial, medical, etc .
  - Cortex-M profile: for microcontroller and low-power applications, such as sensors, actuators, wearables, etc .
- ARM cortex cores support various features and extensions, such as:
  - Thumb-2 instruction set: a mixed 16/32-bit instruction set for code density and performance.
  - NEON technology: a SIMD (single instruction multiple data) engine for multimedia and signal processing.
  - Helium technology: a M-Profile Vector Extension (MVE) for efficient DSP and machine learning.
  - Security extensions: TrustZone for Cortex-A and Cortex-M, which provide hardware isolation and protection for sensitive data and code.
  - Large Physical Address Extension (LPAE): which allows addressing up to 1 TB of physical memory.
  - Split-Lock capability: which allows operating in either split mode (two independent cores) or lock mode (one fault-tolerant core) for safety-critical applications.
