### Additions in Arduino

- Addition is one of the four primary arithmetic operations in Arduino.
- The operator `+` (plus) operates on two operands to produce the sum.
- The syntax for addition is `sum = operand1 + operand2;` where `sum` is a variable and `operand1` and `operand2` are variables or constants.
- The data types allowed for `sum` and the operands are `int`, `float`, `double`, `byte`, `short`, or `long`.
- For example, to add two numbers `2` and `7` and store the result in a variable `sum`, we can write `int sum = 2 + 7;`.
- Another way to perform addition on a variable is to use the compound addition operator `+=`.
- The syntax for compound addition is `variable += value;` where `variable` is a variable and `value` is a constant or another variable.
- This is equivalent to `variable = variable + value;` but shorter and more convenient.
- For example, to add `5` to a variable `sum`, we can write `sum += 5;` which is the same as `sum = sum + 5;`.
- Addition can be used to perform various tasks in Arduino, such as calculating the average of sensor readings, adding delays, incrementing counters, etc.
