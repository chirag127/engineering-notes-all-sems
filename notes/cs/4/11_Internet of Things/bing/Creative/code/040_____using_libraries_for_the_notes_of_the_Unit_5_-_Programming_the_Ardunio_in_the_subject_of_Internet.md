### Using libraries for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

- A library is a collection of code that provides extra functionality for use in sketches, such as working with hardware or manipulating data.
- Libraries can be installed from the Arduino IDE, either by using the Library Manager or by downloading the source code and placing it in the Arduino Libraries folder .
- To use a library in a sketch, select it from Sketch > Import Library, or use the #include directive at the top of the code .
- Some common libraries that are useful for Internet of Things projects are:
  - WiFiNINA: Enables network connection (local and Internet) using the Arduino Nano 33 IoT, Arduino MKR WiFi 1010, Arduino MKR VIDOR 4000 and Arduino UNO WiFi Rev.2.
  - Ethernet: Enables network connection (local and Internet) using the Arduino Ethernet Shield 2 and the Arduino Leonardo ETH.
  - PubSubClient: A client library for MQTT messaging protocol, which is widely used for IoT applications.
  - ArduinoJson: A library for parsing and generating JSON data, which is a common format for exchanging data in IoT systems.
  - Adafruit IO Arduino: A library for connecting to Adafruit IO, a cloud service for IoT devices.
- To learn more about how to use these libraries, refer to the official documentation, examples and tutorials provided by Arduino and other sources    .
