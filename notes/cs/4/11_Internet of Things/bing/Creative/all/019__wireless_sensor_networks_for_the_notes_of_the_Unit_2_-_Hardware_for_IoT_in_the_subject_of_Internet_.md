### Wireless Sensor Networks for the Notes of the Unit 2 - Hardware for IoT in the Subject of Internet of Things

- A wireless sensor network (WSN) is a network of spatially distributed sensors that can sense, measure, and communicate environmental or physical data wirelessly  .
- WSNs are a subtype of the broader Internet of Things (IoT) networks, which enable connectivity and data exchange between various devices and applications.
- WSNs are typically composed of three main components: sensor nodes, gateways, and a central server or database  .
  - Sensor nodes are small, low-power, and low-cost devices that can sense one or more parameters, such as temperature, humidity, pressure, light, sound, motion, etc. Sensor nodes can also perform some basic data processing and communicate with other nodes or gateways using wireless protocols  .
  - Gateways are devices that act as bridges between sensor nodes and the internet or a local network. Gateways can receive, aggregate, and forward data from sensor nodes to a central server or database, or vice versa. Gateways can also perform some data analysis and control functions  .
  - A central server or database is a device or a cloud service that stores, manages, and analyzes the data collected from sensor nodes. It can also provide user interfaces, data visualization, and feedback mechanisms for the WSN applications  .
- WSNs can be arranged in different network topologies, such as star, mesh, tree, or cluster, depending on the communication pattern, network size, and application requirements .
  - In a star topology, each sensor node is directly connected to a gateway, and there is no communication between sensor nodes. This topology is simple, scalable, and energy-efficient, but it has limited coverage and reliability .
  - In a mesh topology, each sensor node can communicate with multiple other nodes, and data can be relayed through multiple hops to reach a gateway. This topology is robust, reliable, and self-healing, but it has high complexity and energy consumption .
  - In a tree topology, sensor nodes are organized in a hierarchical structure, where each node has a parent node and zero or more child nodes. Data flows from the leaf nodes to the root node, which is connected to a gateway. This topology is easy to manage and maintain, but it has low fault tolerance and scalability .
  - In a cluster topology, sensor nodes are grouped into clusters, where each cluster has a leader node that communicates with other leaders or a gateway. Data is aggregated and compressed at the cluster level before being transmitted. This topology is efficient, scalable, and flexible, but it has high overhead and latency .
- WSNs can use various wireless protocols to enable connectivity between sensor nodes and gateways, such as Wi-Fi, Bluetooth, ZigBee, LoRa, NB-IoT, etc. The choice of protocol depends on factors such as data rate, range, power consumption, security, and interoperability  .
  - Wi-Fi is a widely used and versatile wireless protocol that operates in the 2.4 GHz or 5 GHz frequency bands. It can support high data rates and medium ranges, but it has high power consumption and complexity .
  - Bluetooth is a short-range wireless protocol that operates in the 2.4 GHz frequency band. It can support low to medium data rates and low power consumption, but it has limited scalability and security .
  - ZigBee is a low-power wireless protocol that operates in the 2.4 GHz frequency band. It can support low data rates and long ranges, and it is suitable for mesh networks and IoT applications, but it has low compatibility and availability .
  - LoRa is a low-power wide-area network (LPWAN) protocol that operates in the sub-GHz frequency bands. It can support very low data rates and very long ranges, and it is ideal for remote and rural IoT applications, but it has low bandwidth and high latency
