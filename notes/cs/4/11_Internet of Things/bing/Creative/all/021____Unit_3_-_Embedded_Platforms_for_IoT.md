# Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are hardware and software systems that enable IoT devices to perform their functions and communicate with other devices and networks.
- Embedded platforms for IoT typically consist of:
  - A microcontroller or microprocessor that executes the application logic and controls the device's peripherals.
  - A memory unit that stores the program code and data.
  - A communication module that supports wired or wireless connectivity protocols such as Ethernet, Wi-Fi, Bluetooth, Zigbee, LoRa, etc.
  - A power supply unit that provides the required voltage and current for the device's operation.
  - A sensor or actuator that interacts with the physical environment and generates or receives data.
  - An optional display or user interface that provides feedback or input to the user.
- Embedded platforms for IoT can be classified into different categories based on their performance, power consumption, cost, size, and functionality. Some examples of embedded platforms for IoT are:
  - Mbed OS: An open source operating system for IoT devices that supports multiple architectures, connectivity protocols, cloud services, and security features.
  - Amazon FreeRTOS: A real-time operating system for IoT devices that integrates with Amazon Web Services (AWS) and provides libraries for connectivity, security, and over-the-air updates.
  - Raspberry Pi: A single-board computer that runs Linux or Windows and can be used for various IoT applications such as smart home, robotics, media center, etc.
  - Arduino: A microcontroller-based platform that supports a wide range of sensors, actuators, shields, and libraries for IoT prototyping and development.
  - Cisco Embedded Services Switches: A series of embedded switches that provide high-bandwidth, security, and reliability for industrial IoT applications.
  - AMD Ryzen Embedded and EPYC Embedded Processors: A family of processors that offer high performance, graphics, and security for IoT gateways and edge computing applications.
