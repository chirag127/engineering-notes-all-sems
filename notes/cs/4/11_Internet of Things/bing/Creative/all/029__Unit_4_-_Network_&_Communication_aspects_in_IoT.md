## Unit 4 - Network & Communication aspects in IoT

- The Internet of Things (IoT) is a network of physical devices, sensors, actuators, and applications that communicate and exchange data over the internet.
- IoT devices need to connect to other devices, services, and applications using various network technologies and protocols.
- Network technologies and protocols define the rules and formats for data transmission, addressing, routing, reliability, security, and interoperability among heterogeneous devices.
- Network technologies and protocols can be classified into different layers according to the OSI model or the TCP/IP model, which are abstract and concrete models of network communication respectively.
- The OSI model consists of seven layers: physical, data link, network, transport, session, presentation, and application. The TCP/IP model consists of four layers: network access, internet, transport, and application.
- The network access layer deals with the physical and logical connection of devices to the network using hardware and media access control (MAC) addresses. Examples of network access technologies for IoT are cellular, wifi, Ethernet, Bluetooth Low Energy (BLE), ZigBee, NFC, and RFID.
- The internet layer deals with the logical addressing and routing of packets of data between source and destination hosts using IP addresses. Examples of internet technologies for IoT are IPv6, 6LoWPAN, and Thread.
- The transport layer deals with the end-to-end communication and provides features such as reliability, congestion avoidance, and ordering of packets. Examples of transport technologies for IoT are TCP, UDP, CoAP, and MQTT.
- The application layer deals with the data exchange and presentation between applications and services running on top of the network. Examples of application technologies for IoT are HTTP, HTTPS, WebSocket, REST, SOAP, and OPC UA.

Some mnemonics and learning tricks for the Unit 4 - Network & Communication aspects in IoT are:

- To remember the seven layers of the OSI model, use the phrase "Please Do Not Throw Sausage Pizza Away" or "All People Seem To Need Data Processing".
- To remember the four layers of the TCP/IP model, use the phrase "Nice Internet To Access" or "A TIN".
- To remember the difference between TCP and UDP, use the analogy of a phone call and a text message. TCP is like a phone call, where you establish a connection, check for errors, and confirm the delivery. UDP is like a text message, where you send the data without checking for errors or confirmation.
- To remember the difference between CoAP and MQTT, use the analogy of a mailman and a newspaper delivery. CoAP is like a mailman, who delivers messages to specific addresses and expects a response. MQTT is like a newspaper delivery, who publishes messages to topics and does not expect a response.
