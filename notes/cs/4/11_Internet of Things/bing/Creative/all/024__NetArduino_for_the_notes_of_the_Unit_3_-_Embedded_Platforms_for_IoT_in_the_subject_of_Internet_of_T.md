### Netduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Netduino is an open source hardware platform that runs applications built with the .NET Micro Framework.
- Netduino is discontinued and has been completely superseded by Meadow, a complete IoT platform with defense-grade security that runs full .NET Standard applications on embeddable microcontrollers.
- Netduino was one of the first .NET Micro Framework boards that enabled .NET development on embedded devices.
- Netduino has a 32-bit ARM Cortex-M4 microcontroller running at 168 MHz with 1 MB Flash and 192 KB RAM .
- Netduino supports a variety of sensors, actuators, displays, and communication modules through its GPIO pins, SPI, I2C, UART, and PWM interfaces .
- Netduino can be programmed using Visual Studio on Windows or Xamarin Studio on Mac OS.
- Netduino.Foundation is a library that provides plug-and-play support for many peripherals, such as IR codecs, motor drivers, temperature sensors, etc .
- Netduino can be used for various IoT applications, such as home automation, robotics, environmental monitoring, etc .

Some mnemonics and learning tricks for Netduino are:

- Netduino is NET + DUINO, which means .NET + Arduino-like board.
- Netduino is Meadow's predecessor, which means Meadow is more advanced and secure than Netduino.
- Netduino has 192 KB RAM, which is 192 times more than the original Arduino Uno (1 KB RAM).
- Netduino.Foundation is a foundation for building IoT projects with Netduino, which provides drivers and libraries for many devices.
