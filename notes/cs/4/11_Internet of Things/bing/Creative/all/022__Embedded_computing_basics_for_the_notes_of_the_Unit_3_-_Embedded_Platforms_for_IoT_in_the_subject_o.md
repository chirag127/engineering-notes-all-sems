### Embedded computing basics for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

- Embedded systems are electronic devices that contain a microcontroller or a microprocessor, along with memory, input/output interfaces, and software, to perform a specific function within a larger system .
- Embedded systems are often used to support real-time computing and sensing in the Internet of Things (IoT), which is the network of physical objects that can communicate and exchange data over the internet .
- Embedded systems are designed to be reliable, efficient, and low-cost, as they often operate in harsh or constrained environments, such as industrial machines, medical devices, automotive systems, smart home appliances, etc  .
- Embedded systems can be classified into different types based on their performance, power consumption, complexity, and functionality, such as:
  - Stand-alone embedded systems: These systems can work independently without any external support, such as calculators, digital watches, etc.
  - Networked embedded systems: These systems are connected to a network, such as the internet, to share data and resources, such as smart thermostats, security cameras, etc.
  - Real-time embedded systems: These systems have to meet strict timing constraints and deadlines, as they are often involved in critical applications, such as airbags, pacemakers, etc. Real-time embedded systems can be further divided into hard real-time systems, where missing a deadline can cause catastrophic consequences, and soft real-time systems, where missing a deadline can degrade the system performance but not cause failure.
  - Mobile embedded systems: These systems are portable and battery-powered, such as smartphones, tablets, wearable devices, etc.
- Embedded systems typically consist of the following components  :
  - Power source: This provides the electrical energy for the system to operate. It can be utility power, batteries, solar panels, etc.
  - Time base: This provides a reference clock signal for the system to synchronize its operations. It can be a crystal oscillator, a timer, etc.
  - Digital processing: This performs the computation and logic operations for the system. It can be a microcontroller, a microprocessor, a digital signal processor, etc . A microcontroller is a single-chip device that contains a processor core, memory, and peripheral interfaces, while a microprocessor is a multi-chip device that requires external memory and interfaces. A digital signal processor is a specialized device that can process analog signals, such as audio, video, etc, efficiently.
  - Memory: This stores the data and instructions for the system. It can be volatile or non-volatile, and internal or external. Volatile memory loses its content when the power is off, while non-volatile memory retains its content. Internal memory is embedded within the microcontroller or microprocessor, while external memory is connected through an interface. Examples of memory types are ROM, RAM, EEPROM, flash, etc.
  - Software and firmware: This defines the functionality and behavior of the system. Software is the set of programs that run on the system, while firmware is the specific type of software that is stored in non-volatile memory and controls the low-level operations of the system . Software and firmware can be written in different languages, such as assembly, C, Python, etc.
  - Specialized circuitry: This provides additional functionality or features for the system, such as analog-to-digital converters, digital-to-analog converters, sensors, actuators, communication modules, etc .
  - Input from the environment: This allows the system to receive data or signals from the external world, such as temperature, humidity, light, sound, etc .
  - Output to the environment: This allows the system to send data or signals to the external world, such as display, sound, motion, etc .
