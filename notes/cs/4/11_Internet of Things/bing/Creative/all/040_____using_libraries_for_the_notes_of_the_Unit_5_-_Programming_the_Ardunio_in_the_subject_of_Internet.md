# Using Libraries for the Notes of the Unit 5 - Programming the Arduino in the Subject of Internet of Things

- A library is a collection of code that can be used by other sketches or programs. Libraries can provide useful functions, data structures, constants, and classes that can make programming easier and more efficient.
- Arduino has many built-in libraries that can be accessed from the IDE, as well as many third-party libraries that can be downloaded and installed from various sources. Libraries can extend the functionality of Arduino and allow it to communicate with different sensors, devices, and protocols.
- To use a library in a sketch, it must be included with the `#include` directive at the beginning of the code. For example, to use the Serial library, the sketch must have `#include <Serial.h>` at the top. Some libraries may also require additional initialization or configuration in the `setup()` or `loop()` functions.
- To install a new library into the Arduino IDE, the Library Manager can be used. It can be accessed from the Sketch menu, under Include Library > Manage Libraries. The Library Manager will show a list of libraries that are already installed or ready for installation. The user can search for a library by name, category, or author, and select the version to install. The Library Manager will also notify the user of any updates or dependencies for the libraries.
- To learn more about the libraries that are available for Arduino, the user can visit the Arduino documentation, where there are guides, tutorials, and references for the core libraries and many other libraries. The user can also browse the Arduino Library Collection, where there are hundreds of libraries contributed by the Arduino community. The user can also create and share their own libraries, following the guidelines and instructions from the Arduino website.
