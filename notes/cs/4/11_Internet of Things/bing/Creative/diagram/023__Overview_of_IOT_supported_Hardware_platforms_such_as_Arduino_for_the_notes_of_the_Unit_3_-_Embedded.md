The following is a detailed ASCII diagram for the overview of IoT supported hardware platforms such as Arduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things.

```
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |

+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Microcontroller|     | Single-board    |     | Single-board    |

+-----------------+     +-----------------+     +-----------------+
```

The diagram illustrates the basic features and connectivity options of three popular IoT hardware platforms: Arduino, Raspberry Pi, and Intel Galileo. Arduino is a microcontroller that runs on open source software and can interface with various analog and digital sensors. Raspberry Pi and Intel Galileo are single-board computers that run on Linux or Windows operating systems and can support various programming languages and peripherals. All three platforms can communicate with the internet or other devices using Wi-Fi, Bluetooth, cellular, or LPWAN technologies.
