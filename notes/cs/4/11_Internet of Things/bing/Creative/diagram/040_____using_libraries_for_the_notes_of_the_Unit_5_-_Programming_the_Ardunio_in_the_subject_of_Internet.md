### Using libraries for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

- A library is a collection of code that provides extra functionality for use in sketches, such as working with hardware or manipulating data.
- Libraries can be installed from the Arduino IDE, from online sources, or from the source code .
- To use a library in a sketch, select it from Sketch > Import Library, or use the #include directive at the top of the sketch .
- Some common libraries for Arduino programming are:
  - Serial: for communicating with the serial port.
  - Wire: for communicating with devices using the I2C protocol.
  - SPI: for communicating with devices using the SPI protocol.
  - Ethernet: for connecting to the internet using the Ethernet shield.
  - WiFi: for connecting to the internet using the WiFi shield or module.
  - PubSubClient: for using the MQTT protocol to publish and subscribe to messages.
  - DHT: for reading temperature and humidity from the DHT sensor.
  - Adafruit_Sensor: for interfacing with various sensors from Adafruit.
- To learn more about Arduino libraries, visit the Arduino Reference or the Arduino Documentation .
