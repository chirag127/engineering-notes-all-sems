The sources of the IoT are the devices, sensors, platforms, and networks that enable the collection, transmission, and analysis of data from the physical world to the digital world. The following diagram illustrates the basic architecture of a typical IoT system using ASCII art:

```
+-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |
|   IoT Devices   |    |   IoT Platform  |    |   IoT Users     |
|                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |
|  - Sensors      |    |  - Connectivity |    |  - Web/Mobile   |
|  - Actuators    |    |  - Data Storage |    |  - Dashboards   |
|  - Embedded     |    |  - Data Processing | |  - Analytics    |
|    Systems      |    |  - Device Management | |  - Applications |
|                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |
|  Data           |    |  Data           |    |  Data           |
|  Transmission   |    |  Transmission   |    |  Transmission   |
|                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+
```
