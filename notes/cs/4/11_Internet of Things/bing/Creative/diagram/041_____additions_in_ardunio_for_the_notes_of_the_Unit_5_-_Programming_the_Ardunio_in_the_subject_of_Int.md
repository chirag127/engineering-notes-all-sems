### Additions in Arduino

- Addition is one of the four primary arithmetic operations that can be performed on the Arduino.
- The operator + (plus) operates on two operands to produce the sum .
- The syntax for addition is: `sum = operand1 + operand2;` .
- The operands can be variables or constants, and the data types can be int, float, double, byte, short, or long .
- For example, to add two numbers 2 and 7 and store the result in a variable called sum, we can write: `int a = 2; int b = 7; int sum; sum = a + b;` .
- There is also a shorthand notation for addition, which is the compound addition operator (+=).
- The syntax for compound addition is: `variable += value;`.
- This is equivalent to: `variable = variable + value;`.
- For example, to increment a variable called count by 1, we can write: `count += 1;` or `count = count + 1;`.
