Mobiles are one of the most common and widely used devices for IoT applications. Mobile IoT apps allow users to interact with smart sensors, devices, and systems through their smartphones. Mobile IoT apps can provide various benefits, such as remote monitoring, control, automation, data analysis, and security. Some examples of mobile IoT applications are:

- Electric bikes tracking: Using NB-IoT technology, electric bikes can be tracked and managed remotely, reducing theft, accidents, and fire hazards.
- Smoke and gas detectors: Using NB-IoT technology, smoke and gas detectors can alert users and authorities in case of fire or gas leakage, improving safety and efficiency.
- Asset tracking: Using LTE-M or NB-IoT technology, assets such as vehicles, containers, or equipment can be tracked and located in real-time, optimizing logistics and transportation.
- Smart home: Using various wireless protocols, such as Wi-Fi, Bluetooth, Zigbee, or Z-Wave, smart home devices can be controlled and automated via mobile apps, enhancing comfort and convenience.
- Smart city: Using various wireless protocols, such as LoRaWAN, Sigfox, or NB-IoT, smart city devices can collect and transmit data on traffic, pollution, waste, energy, or water, improving urban management and sustainability.
- Healthcare: Using various wireless protocols, such as Bluetooth, NFC, or RFID, healthcare devices can monitor and transmit vital signs, medication, or activity of patients, improving diagnosis and treatment.

The following diagram illustrates the basic architecture of a mobile IoT app:

```
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|   IoT Device    |<--->|  Mobile App     |<--->|  Cloud Service  |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
```

The IoT device is the physical object that has sensors, actuators, and communication hardware. It can collect, send, and act on data from the environment or other devices.

The mobile app is the software application that runs on the smartphone. It can communicate with the IoT device via wireless protocols, such as Wi-Fi, Bluetooth, or cellular. It can also communicate with the cloud service via the Internet. It can provide a user interface for controlling, monitoring, and analyzing the IoT device.

The cloud service is the software service that runs on the cloud. It can communicate with the mobile app and the IoT device via the Internet or wireless protocols. It can provide data storage, processing, analytics, and security for the IoT system. It can also integrate with other cloud services, such as databases, AI, or web APIs.
