### Arduino IDE

- Arduino IDE is an integrated development environment for writing, compiling and uploading code to Arduino boards.
- Arduino IDE supports C and C++ languages, with some extensions and simplifications.
- Arduino IDE provides a code editor, a serial monitor, a board and library manager, and a built-in debugger.
- Arduino IDE can run on Windows, Mac OS X and Linux platforms.
- Arduino IDE can be downloaded from the official website: https://www.arduino.cc/en/software
- Arduino IDE can also be used online as a web editor: https://create.arduino.cc/editor
- Arduino IDE requires a USB cable to connect the Arduino board to the computer and upload the code.
- Arduino IDE uses a bootloader, a small program that runs on the Arduino board and allows the code to be uploaded without a hardware programmer.
- Arduino IDE has a standard structure for the code, which consists of two main functions: setup() and loop().
- setup() is executed once when the Arduino board is powered on or reset, and it is used to initialize variables, pin modes, libraries, etc.
- loop() is executed repeatedly in an endless cycle, and it is used to perform the main logic of the program, such as reading sensors, controlling actuators, communicating with other devices, etc.
- Arduino IDE also allows the use of user-defined functions, variables, constants, libraries, etc. to organize and modularize the code.
- Arduino IDE has a set of predefined constants and functions that are part of the core library, such as HIGH, LOW, digitalRead(), digitalWrite(), analogRead(), analogWrite(), Serial, etc.
- Arduino IDE also has a collection of additional libraries that can be installed and imported to extend the functionality of the code, such as Ethernet, WiFi, LCD, Servo, etc.
- Arduino IDE has a reference page that documents the syntax and usage of the core library and the additional libraries: https://www.arduino.cc/reference/en/
