### Overview of IoT supported Hardware platforms such as Arduino

Internet of Things (IoT) is the concept of connecting various devices and sensors to the Internet and enabling data exchange and communication among them. IoT devices can range from simple sensors to complex computing systems that perform various tasks and functions. To build IoT devices, developers need hardware platforms that provide the necessary components and capabilities, such as microcontrollers, wireless connectivity, sensors, actuators, etc.

There are many IoT hardware platforms available in the market, each with its own features, advantages, and limitations. Some of the most popular and widely used IoT hardware platforms are:

- **Arduino**: Arduino is an open-source platform that consists of a series of microcontroller boards and a software development environment. Arduino boards are easy to use and program, and can interface with various sensors, actuators, and modules. Arduino supports many communication protocols, such as Bluetooth, Wi-Fi, Ethernet, LoRa, etc. Arduino is suitable for beginners and hobbyists, as well as for prototyping and testing IoT applications. Some of the Arduino boards that are commonly used for IoT are Arduino Uno, Arduino Nano, Arduino Mega, Arduino MKR, etc.  

- **Raspberry Pi**: Raspberry Pi is a single-board computer that runs Linux or Windows operating systems. Raspberry Pi has a powerful processor, memory, and storage, and can run various applications and software. Raspberry Pi can also connect to various peripherals, such as cameras, keyboards, monitors, etc. Raspberry Pi can be used as a web server, a media center, a smart home hub, etc. Raspberry Pi supports many communication protocols, such as Wi-Fi, Bluetooth, Ethernet, etc. Raspberry Pi is suitable for advanced users and developers, as well as for complex and data-intensive IoT applications. Some of the Raspberry Pi models that are commonly used for IoT are Raspberry Pi 3, Raspberry Pi 4, Raspberry Pi Zero, etc.  

- **ESP8266**: ESP8266 is a low-cost and low-power microcontroller with built-in Wi-Fi connectivity. ESP8266 can be programmed using Arduino IDE or other tools, and can communicate with other devices and cloud services using HTTP, MQTT, etc. ESP8266 can be used as a standalone device or as a Wi-Fi module for other microcontrollers. ESP8266 is suitable for low-cost and low-power IoT applications, such as smart lighting, smart plugs, environmental monitoring, etc. Some of the ESP8266 boards that are commonly used for IoT are NodeMCU, Wemos D1, ESP-01, etc. 

- **Pycom**: Pycom is a platform that offers various modules and development boards with multiple connectivity options, such as Wi-Fi, Bluetooth, LoRa, Sigfox, LTE, etc. Pycom modules can be programmed using Python, which is a high-level and easy-to-use programming language. Pycom modules can also integrate with various sensors, actuators, and cloud services. Pycom is suitable for IoT applications that require flexible and reliable connectivity, such as smart agriculture, smart cities, asset tracking, etc. Some of the Pycom modules that are commonly used for IoT are WiPy, LoPy, FiPy, GPy, etc. 

- **Particle**: Particle is a platform that offers various development kits and connectivity modules for IoT. Particle hardware is designed to work with the Particle software platform, which includes tools to help developers build and connect their IoT devices. Particle supports cellular, Wi-Fi, and Bluetooth connectivity, and can integrate with various sensors, actuators, and cloud services. Particle is suitable for IoT applications that require secure and scalable connectivity, such as industrial IoT, smart home, smart energy, etc. Some of the Particle hardware that are commonly used for IoT are Photon, Electron, Boron, Argon, Xenon, etc. 

These are some of the IoT hardware platforms that are widely used by developers and makers. However, there are many other platforms that can also be used for IoT, such as Intel Edison, Intel Galileo, BeagleBone, Banana Pi, NodeMCU, etc. The choice of the IoT hardware platform depends on the requirements and preferences of the developer, as well as the features and limitations of the platform. Therefore, it is important to compare and evaluate different IoT hardware platforms before selecting one for a specific IoT project.
