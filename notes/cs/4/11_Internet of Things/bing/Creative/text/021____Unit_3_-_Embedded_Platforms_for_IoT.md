## Unit 3 - Embedded Platforms for IoT

- Embedded platforms for IoT are hardware and software systems that enable IoT devices to perform their functions and communicate with other devices and networks.
- Embedded platforms for IoT typically consist of:
  - A microcontroller or microprocessor that executes the application logic and controls the device's peripherals.
  - A memory unit that stores the program code and data.
  - A communication interface that allows the device to send and receive data over wired or wireless networks.
  - A power supply that provides the required voltage and current for the device's operation.
  - A sensor or actuator that interacts with the physical environment or performs a specific action.
  - An operating system or firmware that manages the device's resources and provides basic services such as scheduling, memory management, and device drivers.
- Embedded platforms for IoT can vary in size, performance, power consumption, and functionality depending on the device's requirements and use cases.
- Some examples of embedded platforms for IoT are:
  - Mbed OS: An open source operating system for IoT devices that supports multiple architectures, protocols, and cloud services. It provides a secure and scalable platform for developing and deploying IoT applications.
  - Amazon FreeRTOS: A real-time operating system for microcontrollers that extends the FreeRTOS kernel with libraries for connectivity, security, and over-the-air updates. It is designed to simplify the development of IoT devices that connect to AWS cloud services.
  - Cisco Embedded Services: A family of embedded switches and routers that provide high-bandwidth, secure, and feature-rich networking solutions for industrial IoT applications. They are designed to operate in remote and harsh environments.
  - AMD Embedded Solutions: A range of processors and graphics cards that offer high-performance, low-power, and scalable solutions for IoT gateways, edge computing, and smart devices. They support various operating systems, frameworks, and standards for IoT development.
