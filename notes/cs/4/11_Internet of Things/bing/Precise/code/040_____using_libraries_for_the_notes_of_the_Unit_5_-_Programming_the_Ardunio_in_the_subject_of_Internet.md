### Unit 5 - Programming the Arduino: Using Libraries

1. Libraries are collections of pre-written code that can be used to add functionality to your Arduino programs.
2. Libraries can be used to control hardware, perform calculations, and more.
3. To use a library in your Arduino program, you must first include it using the `#include` directive.
4. The `#include` directive must be placed at the top of your program, before any other code.
5. Once a library is included, you can use its functions and variables in your program.
6. Libraries can be installed using the Library Manager in the Arduino IDE.
7. To open the Library Manager, go to `Sketch` > `Include Library` > `Manage Libraries`.
8. In the Library Manager, you can search for and install libraries.
9. You can also add libraries manually by placing the library folder in the `libraries` folder of your Arduino sketchbook.
10. It is important to read the documentation for a library before using it, to understand how to use its functions and variables.
