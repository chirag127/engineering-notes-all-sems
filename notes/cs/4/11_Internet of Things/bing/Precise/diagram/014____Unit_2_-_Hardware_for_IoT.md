## Unit 2 - Hardware for IoT

1. **Sensors**: Sensors are the primary hardware components of IoT devices. They are used to collect data from the environment and convert it into a digital format that can be processed by a computer. Some common types of sensors used in IoT devices include temperature sensors, humidity sensors, light sensors, and motion sensors.

2. **Microcontrollers**: Microcontrollers are small, low-power computers that are used to control the operation of IoT devices. They are responsible for processing the data collected by the sensors and executing the appropriate actions based on that data.

3. **Communication Modules**: Communication modules are used to transmit data between IoT devices and the cloud. Some common communication technologies used in IoT devices include Wi-Fi, Bluetooth, and cellular networks.

4. **Power Sources**: IoT devices require a power source to operate. Some devices are powered by batteries, while others are powered by an external power source such as a wall outlet.

5. **Actuators**: Actuators are used to control the physical environment based on the data collected by the sensors. Some common types of actuators used in IoT devices include motors, relays, and solenoids.

6. **Memory**: Memory is used to store data and program instructions on IoT devices. Some common types of memory used in IoT devices include flash memory and RAM.

7. **User Interface**: The user interface is the means by which the user interacts with the IoT device. Some common user interface components include buttons, touchscreens, and displays.
