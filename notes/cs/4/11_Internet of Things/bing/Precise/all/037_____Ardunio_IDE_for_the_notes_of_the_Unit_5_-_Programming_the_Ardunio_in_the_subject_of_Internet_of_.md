# Unit 5 - Programming the Arduino

### Arduino IDE

1. The Arduino Integrated Development Environment (IDE) is a cross-platform application that allows users to write and upload code to an Arduino board.
2. The IDE includes a text editor for writing code, a message area, a text console, a toolbar with buttons for common functions, and a series of menus.
3. The Arduino IDE supports the C and C++ programming languages using special rules of code structuring.
4. The Arduino IDE comes with a software library called "Wiring" from the original Wiring project, which makes many common input/output operations much easier.
5. The Arduino IDE uses the program avrdude to convert the executable code into a text file in hexadecimal encoding that is loaded into the Arduino board by a loader program in the board's firmware.
6. The Arduino IDE includes a serial monitor which allows simple textual data to be sent to and from the Arduino board.
7. The Arduino IDE can also be used to program other microcontrollers, such as the ESP8266, by installing the appropriate add-on.
