# Netduino for IoT

Netduino is an open-source electronics platform that uses the .NET Micro Framework. It is a prototyping platform based on a 32-bit ARM microcontroller and is compatible with most Arduino shields. Netduino has 5 different models: Netduino, Netduino Plus, Netduino Plus 2, Netduino Mini, and Netduino Go .

The first platform chosen to build a Starter Kit is Netduino Plus 2, which runs at 168 MHz with 1 MB Flash and 192 KB RAM . To use Netduino, it is recommended to install the development environment in the following order: 
1. Microsoft Visual Studio Express 2013 
2. .NET Micro Framework SDK v4.3 
3. .NET MF plug-in for VS2013 
4. Netduino SDK v4.3.2.1 .

Wilderness Labs acquired Netduino in 2017 and used it to help prototype their next-gen .NET efforts on embedded as well as support the community that built around it. They fixed old bugs and created Netduino.Foundation (the precursor to Meadow.Foundation) to make it plug and play with sensors .
