# Unit 1 - Internet of Things (IoT)

### Technology behind IoT

1. **Sensors and Actuators**: These are the devices that collect data from the environment and perform actions based on the data. They are the interface between the physical and digital world.

2. **Connectivity**: IoT devices need to be connected to the internet to send and receive data. This can be achieved through various communication technologies such as Wi-Fi, Bluetooth, cellular, and satellite.

3. **Cloud Computing**: The data collected by IoT devices is often stored and processed in the cloud. This allows for easy access to the data from anywhere in the world.

4. **Data Analytics**: The data collected by IoT devices can be analyzed to gain insights and make informed decisions. This can be done using various data analytics tools and techniques.

5. **Machine Learning**: Machine learning algorithms can be used to analyze the data collected by IoT devices and make predictions or take actions based on the data.

6. **Security**: Security is a major concern in IoT as the devices collect and transmit sensitive data. Various security measures such as encryption and authentication are used to protect the data.

7. **User Interface**: The user interface is the means by which the user interacts with the IoT system. This can be through a mobile app, web interface, or voice commands.

These are some of the key technologies behind IoT. They work together to enable the collection, transmission, storage, analysis, and use of data from the physical world.
