### Unit 5 - Programming the Arduino in the subject of Internet of Things

- Arduino is an open-source electronics platform based on easy-to-use hardware and software.
- It is intended for anyone making interactive projects.
- The Arduino Integrated Development Environment (IDE) is the software used to write and upload code to the Arduino board.
- The Arduino programming language is based on C/C++.
- The basic structure of an Arduino program includes two functions: `setup()` and `loop()`.
- `setup()` is called once when the program starts and is used to initialize variables, pin modes, and other libraries.
- `loop()` runs continuously after `setup()` and is where the main logic of the program is executed.
- The Arduino language includes many built-in functions for controlling digital and analog inputs and outputs, as well as for interfacing with various sensors and actuators.
- Libraries can be used to extend the functionality of the Arduino and to easily interface with specific hardware.
- The Arduino community has developed a large number of libraries for various sensors, displays, and other hardware.
