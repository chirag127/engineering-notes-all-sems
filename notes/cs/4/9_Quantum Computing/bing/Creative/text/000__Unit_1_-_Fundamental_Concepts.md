## Unit 1 - Fundamental Concepts

- This unit covers the basic concepts and terminology of computer science, such as data, information, algorithms, programming languages, hardware, software, and problem-solving strategies.
- Data is the raw, unprocessed facts that can be stored, manipulated, and communicated by a computer system. Data can be represented in different formats, such as numbers, text, images, audio, video, etc.
- Information is the processed, organized, and meaningful data that can be used for decision making, communication, or knowledge creation. Information can be derived from data by applying various operations, such as sorting, filtering, calculating, summarizing, etc.
- An algorithm is a step-by-step procedure or set of rules for solving a specific problem or performing a certain task. An algorithm must be precise, unambiguous, finite, and effective. An algorithm can be expressed in different ways, such as natural language, pseudocode, flowcharts, or programming languages.
- A programming language is a formal language that consists of a set of symbols, rules, and conventions for creating instructions that can be executed by a computer. A programming language can be classified into different levels of abstraction, such as low-level, high-level, or intermediate-level languages. A programming language can also be categorized into different paradigms, such as imperative, declarative, functional, object-oriented, or logic-based languages.
- Hardware is the physical components and devices that make up a computer system, such as the central processing unit (CPU), memory, disk, keyboard, mouse, monitor, printer, etc. Hardware can be classified into different types, such as input, output, processing, storage, or communication devices.
- Software is the collection of programs, data, and instructions that control the operation and behavior of a computer system. Software can be classified into different types, such as system software, application software, or utility software. System software is the software that manages the basic functions and resources of a computer system, such as the operating system, device drivers, compilers, etc. Application software is the software that performs specific tasks or functions for the user, such as word processors, spreadsheets, games, etc. Utility software is the software that provides additional services or features for the computer system, such as antivirus, backup, compression, etc.
- Problem-solving is the process of finding a solution to a given problem or challenge. Problem-solving involves various steps, such as defining the problem, analyzing the problem, designing an algorithm, implementing the algorithm, testing and debugging the algorithm, and documenting the algorithm. Problem-solving requires various skills, such as logical thinking, creativity, analytical reasoning, and communication.
