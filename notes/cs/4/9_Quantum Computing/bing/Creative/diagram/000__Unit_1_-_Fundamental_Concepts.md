## Unit 1 - Fundamental Concepts

The following diagram illustrates the basic architecture of a computer system:

```
+-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |
|    Processor    |<-->|    Memory       |<-->|    Input/Output |
|                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+
```

The processor is the part of the computer that executes instructions and performs calculations. The memory is the part of the computer that stores data and programs. The input/output is the part of the computer that communicates with external devices, such as keyboards, mice, monitors, printers, etc.

The following diagram illustrates the basic structure of a program:

```
+-----------------+
|                 |
|    Variables    |
|                 |
+-----------------+
|                 |
|    Statements   |
|                 |
+-----------------+
|                 |
|    Functions    |
|                 |
+-----------------+
|                 |
|    Modules      |
|                 |
+-----------------+
```

Variables are the names that refer to values in memory. Statements are the instructions that tell the computer what to do. Functions are the named groups of statements that perform a specific task. Modules are the files that contain variables, statements, functions, and other definitions.
