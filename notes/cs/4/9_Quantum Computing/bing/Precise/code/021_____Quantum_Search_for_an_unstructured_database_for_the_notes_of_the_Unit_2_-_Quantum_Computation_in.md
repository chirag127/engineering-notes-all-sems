### Quantum Search for an unstructured database

- Quantum search of an unstructured database refers to finding one element having a certain property out of elements.
- A simple circuit implementation of the oracle for Grover's quantum search of a real unstructured classical database has been proposed.
- The oracle contains a kind of quantumly accessible classical memory, which stores the database.
- The architecture of the physical memory device entering the oracle has also been proposed.
