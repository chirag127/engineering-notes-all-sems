### Shor code for the notes of the Unit 5 - Quantum Error Correction in Quantum Computing

1. Introduction
- Quantum error correction is required to build a quantum computer that can perform useful computations.
- Qubits can become entangled with environment and decohere, causing errors. We need methods to detect and correct these errors.

2. Quantum Bit Flip Codes
- Encode a qubit into multiple physical qubits
- Check if all physical qubits are in the same state
- If not, flip the state of logical qubit
- Examples: Steane code, 7 qubit code

3. Quantum Phase Flip Codes
- Encode a qubit into multiple physical qubits
- Check for relative phase between states of physical qubits
- If wrong phase, flip phase of logical qubit
- Examples: 5 qubit code, 9 qubit code

4. Distance and Threshold
- Distance of a code defines the number of errors it can correct
- Threshold is the max error rate for which errors can still be reliably corrected
- Higher distance and threshold needed for scalable quantum computing

5. Concatenated Codes
- Combine multiple layers of quantum error correcting codes to increase distance and threshold
- Allows for efficient encoding and decoding circuits
- Necessary for building large scale quantum computers
