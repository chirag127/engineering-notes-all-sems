## Unit 6 - Failure Recovery in Distributed Systems

- A distributed system is a collection of independent nodes that communicate and coordinate to achieve a common goal.
- A failure in a distributed system is an event that prevents a node from functioning correctly or communicating with other nodes.
- Failure recovery is the process of restoring the system to a consistent and correct state after a failure occurs.
- Failure recovery is important for maintaining the availability, reliability, and performance of the system.
- Failure recovery can be challenging in distributed systems due to the following reasons:
  - The system may have partial failures, where some nodes fail while others continue to operate.
  - The system may have network failures, where the communication links between nodes are unreliable or disrupted.
  - The system may have concurrent failures, where multiple failures occur at the same time or in a short period.
  - The system may have inconsistent views, where different nodes have different information or assumptions about the system state.
  - The system may have conflicting actions, where different nodes perform incompatible operations on the same data or resource.
- Failure recovery can be achieved by using various techniques, such as:
  - Fault tolerance, where the system can continue to function correctly despite the presence of failures.
  - Fault detection, where the system can identify and isolate the failed nodes or components.
  - Fault diagnosis, where the system can determine the cause and extent of the failures.
  - Fault recovery, where the system can repair or replace the failed nodes or components.
  - Fault prevention, where the system can avoid or reduce the occurrence of failures.
- Failure recovery can be classified into two categories, depending on the system model and the recovery goal:
  - Rollback recovery, where the system restores the state of the nodes to a previous consistent checkpoint before the failure occurred.
  - Forward recovery, where the system updates the state of the nodes to a new consistent state after the failure occurred.
