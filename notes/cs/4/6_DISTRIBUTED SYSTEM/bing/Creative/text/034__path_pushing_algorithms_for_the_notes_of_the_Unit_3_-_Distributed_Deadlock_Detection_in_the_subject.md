### Path Pushing Algorithms

Path pushing algorithms are a class of distributed deadlock detection algorithms that use an explicit global wait-for graph (WFG) to detect cycles. A WFG is a directed graph that represents the dependencies between processes and resources in a distributed system. A node in a WFG is a process, and an edge from node P1 to node P2 means that P1 is waiting for a resource held by P2. A cycle in a WFG indicates a deadlock.

The main idea of path pushing algorithms is to construct and maintain a global WFG at each site of the distributed system. A site is a processor or a node that hosts one or more processes. Each site has a local WFG that contains the information about the processes and resources at that site. When a site performs a deadlock detection, it sends its local WFG to all its neighboring sites, where a neighbor is a site that shares a common edge in the global WFG. The receiving sites merge the received WFG with their own local WFG and propagate the updated WFG to their neighbors. This process continues until all the sites have the same global WFG, or a cycle is detected.

There are different variants of path pushing algorithms, such as the centralized, distributed, and hierarchical algorithms. The centralized algorithm has a designated site that initiates the deadlock detection and collects the WFG from all the other sites. The distributed algorithm does not have a designated site, and any site can initiate the deadlock detection. The hierarchical algorithm organizes the sites into a tree structure, and the deadlock detection is performed in a bottom-up and top-down manner.

The advantages of path pushing algorithms are that they can detect deadlocks quickly and accurately, and they do not require any additional messages for deadlock detection. The disadvantages are that they require a lot of storage space and communication bandwidth to maintain and exchange the global WFG, and they may cause false positives if the WFG is not consistent.
