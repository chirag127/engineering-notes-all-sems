### Logical Clocks

- A logical clock is a mechanism for capturing chronological and causal relationships in a distributed system .
- Distributed systems may have no physically synchronous global clock, so a logical clock allows global ordering on events from different processes in such systems .
- A logical clock is based on the concept of **happen-before** relationship, which is a partial order on events that preserves the causal dependencies .
- An event A happens before an event B, denoted as A -> B, if one of the following conditions holds :
  - A and B are events in the same process, and A occurs before B.
  - A is the sending of a message by one process, and B is the receipt of the same message by another process.
  - There exists some event C such that A -> C and C -> B.
- Two events are concurrent, denoted as A || B, if neither A -> B nor B -> A holds .
- A logical clock is a function C that assigns a number C(A) to any event A, such that if A -> B, then C(A) < C(B) .
- A logical clock does not necessarily reflect the actual physical time of the events, but rather the causal order of the events .
- A logical clock can be implemented using a counter that is incremented by one after each event in a process .
- When a process sends a message, it piggybacks its current counter value on the message .
- When a process receives a message, it updates its counter to be the maximum of its own counter and the received counter value, and then increments it by one .
- A logical clock can be used to detect causality violations, such as receiving a message before its sender has sent it .
- A logical clock can also be used to timestamp events and messages, and to order them according to their logical time .
- A logical clock is not sufficient to order concurrent events, as they may have the same logical time .
- A logical clock does not guarantee that if C(A) < C(B), then A -> B, as there may be no causal dependency between A and B .
- A logical clock is an example of a **scalar clock**, which assigns a single number to each event .
- A logical clock can be extended to a **vector clock**, which assigns a vector of numbers to each event, and can capture more information about the causal relationships among events .
