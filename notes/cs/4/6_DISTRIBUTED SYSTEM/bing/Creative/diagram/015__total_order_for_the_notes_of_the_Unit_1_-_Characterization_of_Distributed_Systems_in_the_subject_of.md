Total order is a property of a distributed system where all events in the system can be arranged in a linear sequence that is consistent with the causal order of the events. This means that if event A happens before event B in one process, then A must also happen before B in any other process that observes both events. Total order can be achieved by using different algorithms or protocols, such as Lamport timestamps, vector clocks, atomic broadcast, or distributed consensus  .

The following diagram illustrates the basic architecture of a distributed system that uses atomic broadcast to achieve total order. Atomic broadcast is a communication primitive that ensures that all processes in a group receive the same messages in the same order. A central process, called the sequencer, assigns a sequence number to each message and broadcasts it to the group. The other processes, called the members, deliver the messages according to the sequence numbers. If the sequencer fails, another process can take over its role.
