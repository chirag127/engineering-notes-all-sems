### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- Virtualization is the creation of a virtual version of something, like a server, storage device, network resources or even an operating system.
- The virtual version can be used just like the physical resource and is decoupled from the underlying hardware.
- Following are the main types of virtualization used in cloud computing:

1. Server virtualization: Multiple virtual servers are created on a single physical server. Each virtual server can run its own operating system and applications. Resources like CPU, memory, storage, and network can be allocated to the virtual servers. Example: VMware, KVM, Xen, etc.

Advantages: Increased server utilization, reduced equipment costs, easily scalable, isolation between applications, etc.

2. Storage virtualization: Physical storage from multiple storage devices is pooled together into what appears to be a single storage device. The physical characteristics of the underlying devices are abstracted. Example: RAID, NAS, SAN, etc.

Advantages: Increased storage utilization, centralized management, increased flexibility, etc.

3. Network virtualization: The physical network resources are decoupled from the network topology to create a virtual network with its own set of rules and configurations. The virtual network operates just like a physical network. Example: Software-Defined Networking (SDN), Virtual LAN (VLAN), etc.

Advantages: Increased network utilization, programmability, flexibility, security, etc.

4. Desktop virtualization: A user's desktop environment is separated from the physical client device and executed on a remote server. The user can access the virtual desktop from any device. Example: VMware View, Citrix XenDesktop, etc.

Advantages: Increased desktop utilization, centralized management, access from anywhere, security, etc.

- Overall, virtualization enables efficient utilization of resources, reduces costs, increases scalability and flexibility, enhances security, and enables centralized management in cloud computing.
- Mnemonics: "Move up VIRTUALLY by SERVERing, STORAGEing and NETWORKING desktops in the cloud."
