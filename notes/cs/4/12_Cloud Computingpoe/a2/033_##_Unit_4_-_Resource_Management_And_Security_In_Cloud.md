## Unit 4 - Resource Management And Security In Cloud

### Resource Management

- Elasticity: Ability to scale resources up and down as per the demand. This is one of the key benefits of cloud computing. Resources can be scaled manually or automatically using auto-scaling.
- Vertical Scaling: Increasing or decreasing the resources of a single instance like CPU, memory, storage, etc.
- Horizontal Scaling: Increasing or decreasing the number of instances.
- Load Balancers: Distribute traffic/load across multiple instances to handle high volumes and achieve redundancy.
- Auto-scaling: Automates the scaling process by monitoring metrics like CPU utilization and scaling resources up or down accordingly.
- Cloud Cost Management: Effective management of cloud costs is essential and can be done through regular monitoring, tagging resources, using reserved instances, automation to scale down unused resources, etc.

### Cloud Security

- Shared Responsibility Model: The cloud provider and customer share the responsibility of securing the cloud infrastructure and data/apps respectively.
- Identity and Access Management: Control access to resources through strong authentication and authorization mechanisms.
- Infrastructure Security: Includes hypervisor security, network security, DDoS protection, data encryption, etc. provided by the cloud provider.
- Application Security: Customer's responsibility to build secure apps and keep them patched.
- Data Security: Encryption, masks, etc. to protect data at rest and in transit.
- Monitoring and Logging: Continuous monitoring of activities and logging of events for security analysis and compliance.
- Compliance: Adherence to security standards and compliance with regulations like GDPR, HIPAA, etc.
