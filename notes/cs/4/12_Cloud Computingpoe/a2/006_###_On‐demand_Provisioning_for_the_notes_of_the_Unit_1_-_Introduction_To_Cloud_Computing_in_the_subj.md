### On‐demand Provisioning

- On‐demand provisioning refers to the ability of the cloud computing resources to provide scalable infrastructure, platform, software, and networking as and when required by the users without any human intervention.
- The resources are made available as soon as the request is made and they are released once the user is done with the usage. This leads to optimum utilization of resources and reduced wastage.
- The core characteristics of on‐demand provisioning are:
  - Self‐service: The user can provision the resources themselves via a Web interface or API without the need to interact with the service provider.
  - Elastic: The resources can be scaled up or down as per the actual demand. This enables optimum resource utilization and reduced costs.
  - Measured service: The usage of resources is monitored, controlled, and reported providing transparency to the user about resource utilization and charges. This enables accurate billing and cost tracking.
- The on‐demand provisioning of cloud resources enables high scalability, reduced costs, quick deployment, and high availability meeting the fluctuating demands of the users. This is one of the key benefits of cloud computing making it efficient and cost‐effective.

Some learning tricks to remember on‐demand provisioning:

- Think of a coffee vending machine. You insert money and select coffee, it provides you coffee instantly. Similarly, on‐demand provisioning provides resources instantly as requested.
- Relate on‐demand provisioning to elasticity. What can stretch and shrink? A rubber band. Similarly, cloud resources can stretch and shrink on demand.
- Associate self‐service with an ATM. You can withdraw cash on your own. Similarly, you can provision cloud resources on your own without any manual intervention.
