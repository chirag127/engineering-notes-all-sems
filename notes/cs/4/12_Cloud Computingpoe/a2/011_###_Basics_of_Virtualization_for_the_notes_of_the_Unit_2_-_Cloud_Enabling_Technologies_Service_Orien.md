### Basics of Virtualization

- Virtualization is the creation of a virtual version of something, like a hardware platform, operating system, storage device, or network resources.
- The key benefits of virtualization are:
    - Resource optimization: Multiple virtual machines can run on a single physical machine, increasing utilization.
    - Cost efficiency: Require less hardware as one physical server can act as multiple servers.
    - Flexibility: Easy to move virtual machines between physical servers.
    - Isolation: Applications can be isolated from each other in separate virtual machines.
- Types of Virtualization:
    - Full Virtualization: A complete simulation of the underlying hardware. Guest OS is unaware of being virtualized. Examples: VMware, VirtualBox.
    - Paravirtualization: Guest OS is modified to interact with the hypervisor. Examples: Xen.
    - Operating System-level Virtualization: Multiple isolated user space instances are virtualized at the operating system level. Examples: Containers (Docker).
- Virtualization enables cloud computing by providing the necessary environment to run cloud services and applications. It decouples the software from the hardware and makes resources easily scalable.
- Mnemonics: "VMs on demand - anytime, anywhere" to remember key benefits of virtualization. "Simulation, Modification, Isolation" to remember types of virtualization.
