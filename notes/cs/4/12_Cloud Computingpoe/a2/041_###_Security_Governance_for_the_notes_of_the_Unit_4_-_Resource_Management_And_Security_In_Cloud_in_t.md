### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security governance refers to the set of policies, processes, procedures, and technologies that are in place to ensure compliance with legal and regulatory requirements and also protect the organization's information and resources. Some key aspects of security governance in cloud computing are:
- clearly defined roles and responsibilities for security. For example, the cloud provider is responsible for the security of the infrastructure while the customer is responsible for the security of their data and applications.
- monitoring and metrics to track compliance and security posture. The cloud provider and customer should have visibility into security-related events and metrics.
- oversight and assurance through audits and compliance checks. Regular audits by internal and external parties help validate security controls and compliance.
- adjustment of controls as needed based on changes in regulations, risks, and threat landscape. Security governance needs to be an ongoing process to keep up with the evolving cloud landscape.

Some mnemonics and learning tricks:

- Think CIA - Confidentiality, Integrity, Availability - key aspects of security to govern
- Shared security responsibility - know what cloud provider is responsible for and what you are responsible for
- Continuous monitoring - security governance is ongoing process, keep monitoring and metrics in place
- Get assurance - conduct regular audits and compliance checks
