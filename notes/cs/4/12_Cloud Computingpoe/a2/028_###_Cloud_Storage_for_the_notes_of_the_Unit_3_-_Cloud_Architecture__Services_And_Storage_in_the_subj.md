## Cloud Storage

- Cloud storage refers to a model of storing and accessing data over the internet instead of storing it locally. The data is stored in logical pools, known as storage containers, and the physical resources are owned and managed by a cloud storage provider.
- Some key benefits of cloud storage are:
    - Scalability - Storage capacity can be easily increased or decreased as per requirement.
    - Geo-redundancy - Data is replicated across multiple regions/data centers for high availability and disaster recovery.
    - Accessibility - Data can be accessed from anywhere via internet.
    - Cost effectiveness - No upfront capital expenditure and pay-as-you-go model.
- Popular cloud storage providers are:
    - AWS S3 - Scalable, durable and highly available object storage.
    - Azure Blob Storage - Massively scalable object storage for unstructured data.
    - Google Cloud Storage - Scalable and durable object storage.
- When to use cloud storage:
    - Backup and archiving - Store backups or archive old data.
    - Content sharing - Share files/media with others.
    - Application data - Store application data/files.
    - Website hosting - Host website files.
- Things to consider:
    - Cost - Carefully choose storage type (object vs block vs file) and tier (hot vs cold) based on access patterns to minimize cost.
    - Security - Use IAM, access control lists and encryption to secure data.
    - Compliance - Choose a region and enable features to meet regulatory compliance needs.
    - Performance - Choose storage type and size configurations based on performance needs.
    - Availability - Choose a provider with SLAs for availability and resilience against disasters.
