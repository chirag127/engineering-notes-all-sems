### Virtual Box for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- VirtualBox is a general-purpose full virtualizer for x86 hardware, targeted at server, desktop and embedded use.
- It is a community effort led by Sun Microsystems as a Desktop Virtualization solution.
- It consists of a virtual machine monitor together with a number of front-ends for the guest operating systems.
- VirtualBox can run on Windows, macOS, Linux and Solaris hosts and supports a large number of guest operating systems including but not limited to Windows, macOS, Linux, and Solaris.
- VirtualBox is installed on the host operating system and allows you to run guest virtual machines. Each virtual machine can run its own operating system and applications as if it was a dedicated computer.
- VirtualBox provides "virtual devices" to guest operating systems, including emulated hard disks, CD/DVD-ROM drives, USB controllers, and virtual network cards. It uses 'virtual devices' on your host CPU and memory to simulate real hardware devices.
- Advantages:
   - Free and open-source.
   - Runs on multiple platforms.
   - Supports a wide variety of guest operating systems.
   - Easy to use with a graphical user interface.
   - Allows virtual machine portability.
   - Snapshots allow saving and restoring states of virtual machines.
- Disadvantages:
   - Performance overhead due to virtualization.
   - Limited features in free edition.
   - May not be suitable for running high-end applications.
- Applications: Testing, software development, running multiple operating systems simultaneously, machine learning, etc.
- Mnemonics: Nothing (Not easy to find Mnemonics for technical terms)
- Learning tricks: Practice by installing various operating systems as guests and using the features of VirtualBox to understand it better.
