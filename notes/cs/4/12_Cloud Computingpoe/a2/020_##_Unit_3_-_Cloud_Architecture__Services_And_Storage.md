## Unit 3 - Cloud Architecture, Services And Storage

### Cloud Architecture
- Cloud computing architecture comprises of multiple layers:
    - Front end - Consists of the client device interface (ex: web/mobile app).
    - Back end - Consists of the cloud and all the resources provisioned.
        - Cloud layer - Abstracted resources like servers, storage, applications.
        - Hardware/Infrastructure layer - Physical data center resources.
    - Internet connectivity - Connects the front end and back end.
- Cloud deployment models:
    - Public cloud - Available to the general public (ex: AWS, Azure, GCP).
    - Private cloud - Operated for internal organizational use.
    - Hybrid cloud - Composition of public and private clouds.
    - Multicloud - Use of multiple public clouds.

**Mnemonics:** *Remember 'FBIH' to recall the cloud deployment models - Public = FBI agency, Private = confidential data, Hybrid = combination, Multi = multiple.*

### Cloud Services
- Infrastructure as a Service (IaaS): Provides virtualized computing resources (ex: EC2).
- Platform as a Service (PaaS): Provides a platform to develop and deploy apps (ex: Elastic Beanstalk).
- Software as a Service (SaaS): Provides software applications (ex: G Suite, Office 365).
- Serverless computing: Runs code without managing servers (ex: AWS Lambda, Azure Functions).

**Learning trick:** *Think of 'IPaaS' ( Infrastructure, Platform, Software as a Service) to recall the main cloud services. Serverless is an evolved form of PaaS.*

### Cloud Storage
- Object storage: Store objects/files (ex: S3, Azure Blob storage).
- Block storage: Provide block level storage (ex: EBS, Azure Disks).
- File storage: Provide file system-based storage (ex: Elastic File System, Azure Files).
- Databases: Provide data management (ex: RDS, DynamoDB, Cosmos DB).

**Advantages:** Scalability, durability, high availability, low cost.
**Disadvantages:** Vendor lock-in, latency, security concerns.
**Applications:** Web apps, mobile apps, IoT, big data, analytics.
