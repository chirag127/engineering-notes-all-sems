### Architectural Design Challenges

The following are some of the major architectural design challenges for cloud computing:

1. Scalability - The cloud computing architecture must be highly scalable to accommodate increasing workload demands. The infrastructure must scale out/up seamlessly without impacting performance or reliability.
2. Redundancy - The cloud computing architecture must have redundancy built-in to avoid single points of failure. This could be through multiple availability zones, data replication, backup plans, etc.
3. Geographic distribution - The cloud computing resources are typically distributed across multiple data centers in different geographic locations. This introduces challenges in latency, bandwidth, and data synchronization.
4. Heterogeneity - The cloud computing environment is highly heterogeneous with diverse hardware, software, and networks. This heterogeneity brings challenges in management, monitoring, and orchestration.
5. Multi-tenancy - The resources in a public cloud are shared across multiple clients (tenants). This introduces challenges such as isolation, security, and quality of service.
6. Automation - Cloud computing relies heavily on automation for provisioning resources, scaling, and management. The automation software needs to be robust, fault-tolerant, and seamlessly handle the complexity and heterogeneity of the cloud.

Some mnemonics/learning tricks for the above points:

1. Scale out - Think of expanding outwards by adding more servers horizontally
2. DR - Think of data replication and backup as disaster recovery techniques
3. Geo-distribute - Think of data centers located in different countries/continents, resulting in high latency
4. Hetero-geneous - Think of diverse components like mix breed of animals, resulting in management challenges
5. Multi-tenant - Think of multiple apartments in a building sharing common resources, resulting in isolation issues
6. Auto-mation - Think of self-driven cars, the automation software must handle complexity robustly
