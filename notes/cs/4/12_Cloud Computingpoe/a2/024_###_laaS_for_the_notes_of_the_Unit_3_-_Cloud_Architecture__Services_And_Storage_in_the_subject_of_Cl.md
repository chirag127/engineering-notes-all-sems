### laaS for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

**IaaS:** Infrastructure as a Service. It provides virtualized computing resources as a service over the internet. Some key points about IaaS:

- It provides computing resources like virtual machines, storage, and networking on rent.
- The customer has control over the operating system, storage, deployed applications, and networking configuration but not the underlying cloud infrastructure.
- It is the most flexible and customizable cloud service model. The customer has the most control and responsibility.
- Popular IaaS providers are Amazon Web Services (AWS), Microsoft Azure, Google Cloud Platform (GCP), etc.

**Mnemonics:** Imagine Renting Virtual Machines With Complete Control.

**Learning Trick:** Think of IaaS as renting a house. You get the basic infrastructure like rooms, electricity, water, etc. but you have to maintain the house by yourself. Similarly, in IaaS, you get the computing resources but you have to manage the operating system, software, security, etc.

**Advantages:**

- Increased agility and scalability. Resources can be scaled up or down as per demand.
- Cost efficiency. Customer pays for what they use.
- Technical expertise is not required to set up the infrastructure.
- Highly automated and self-service based.

**Disadvantages:**

- The customer has to manage the operating system, software, security patches, etc which can be complex.
- Vendor lock-in can happen due to reliance on the cloud provider's infrastructure.
- Performance can be impacted by the underlying shared infrastructure and other customers.
- Data security and compliance can be challenging to ensure.
