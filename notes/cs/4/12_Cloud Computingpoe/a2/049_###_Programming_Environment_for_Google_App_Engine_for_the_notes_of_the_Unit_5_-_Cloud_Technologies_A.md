### Programming Environment for Google App Engine for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- Google App Engine is a platform as a service (PaaS) that allows developers to build and host web applications in managed data centers.
- It provides:
	- A dynamic web serving infrastructure.
	- APIs for authenticating users and querying data using Google Cloud services.
	- APIs for using services such as Memcache, Task queues, and email.
	- A dynamic scaling infrastructure that automatically scales to serve large amounts of traffic.
- Some key features of App Engine's programming environment are:
	- Supports applications written in Python, Java, Go, PHP, Node.js and Ruby.
	- Limited set of libraries are supported for each language.
	- Requests to external servers have quotas and limitations.
	- Limited file system access. Data must be stored using App Engine's data services: Datastore, Memcache and Cloud Storage.
	- Stateless and scalable architecture. App Engine manages scaling and load balancing.
	- Integrated development environment. Code can be edited, debugged and deployed within the web browser.
- Advantages:
	- Easy to get started. No infrastructure setup needed.
	- Auto scaling and high availability.
	- Pay as you go model. Low cost to get started.
	- Supports major programming languages.
- Disadvantages:
	- Limited set of libraries and access to resources due to sandboxed environment.
	- Vendor lock-in. Difficult to migrate applications to other platforms.
	- Costs can add up and be hard to optimize as applications scale.
