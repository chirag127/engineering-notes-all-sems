### MapReduce

MapReduce is a programming model for processing and generating large data sets. It consists of two major tasks - Map and Reduce.

**Map** - The master node takes the input and partitions it into smaller sub-problems and distributes them to worker nodes. The worker nodes process the smaller problem and return the answers to the master node.

**Reduce** - The master node then takes the answers to all the sub-problems and combines them in a way to form the output.

The advantages of MapReduce are:

- Scalable - It can scale to large clusters with thousands of machines.
- Fault Tolerant - If a machine fails, the job is assigned to another machine.
- Parallel processing - It processes data in parallel for faster execution.

The disadvantages are:

- Not suitable for iterative algorithms or interactive applications.
- Too much overhead for small datasets.
- Difficult to program.

Applications of MapReduce include:

- Web indexing
- Log processing
- Generating reports
- Data mining
- Machine Learning
