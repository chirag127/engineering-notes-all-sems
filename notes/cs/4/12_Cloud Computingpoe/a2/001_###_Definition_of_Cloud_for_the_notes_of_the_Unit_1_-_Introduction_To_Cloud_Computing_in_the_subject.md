### Definition of Cloud

The cloud refers to servers that are accessed over the Internet, allowing users to store and access data from anywhere. Instead of hosting apps and data on an on-site datacenter or servers, companies can host them on servers accessed via the Internet.

**Mnemonics**:

- C - Compute power
- L - Large amount of data storage capacity
- O - On-demand self-service
- U - Ubiquitous network access
- D - Dynamic scalability

**Advantages**:

- Cost efficiency - Pay only for what you use
- Scalability - Scale resources up or down as needed
- Accessibility - Access resources from anywhere via Internet
- Automatic updates - Software is always up-to-date
- High availability - Redundancy prevents downtime
- Multi-tenancy - Shared resources reduce costs

**Disadvantages**:

- Reliance on Internet connectivity
- Vendor lock-in - Can't easily migrate data or apps
- Performance variability - Dependent on Internet traffic and server loads
- Security concerns - Data is outside local network, rely on provider's security
- Compliance concerns - Need to ensure compliance with regulations

**Examples**:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

**Applications**:

- Web-based email (Gmail, Outlook 365)
- Social media (Facebook, Twitter)
- File sharing (Dropbox, Google Drive)
- Streaming services ( YouTube, Spotify)
- And more! Cloud computing has become the norm for many Internet-based applications and services.
