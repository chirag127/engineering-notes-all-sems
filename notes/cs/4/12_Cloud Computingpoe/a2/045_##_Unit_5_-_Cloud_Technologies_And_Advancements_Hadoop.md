## Unit 5 - Cloud Technologies And Advancements Hadoop

**Hadoop:** Hadoop is an open-source software framework used for distributed storage and processing of very large data sets on computer clusters built from commodity hardware. It is designed to scale up from single servers to thousands of machines, with very high fault tolerance. Rather than relying on hardware to provide high availability, the framework itself is designed to detect and handle failures at the application layer, so delivering a highly available service on top of a cluster of computers, each of which may be prone to failures.

**Advantages of Hadoop:**

- Cost effective: Hadoop runs on commodity hardware, making it very cost effective.
- Scalable: Hadoop can scale to process huge amounts of data across large clusters of machines.
- Flexible: Hadoop is highly flexible and can handle a wide variety of workloads.
- Fault tolerant: Hadoop has fault tolerance capabilities and can continue processing even if some nodes go down.
- Distributed processing: Hadoop enables distributed processing of large data sets across clusters of computers.

**Components of Hadoop:**

- HDFS: Hadoop Distributed File System - stores data on commodity machines.
- MapReduce: A programming model for processing large data sets.
- YARN: A framework for job scheduling and cluster resource management.

**Cloud technologies and advancements in Hadoop:**

- Hadoop as a Service (Haas): Providing Hadoop as a service, removing the complexities of setup and maintenance. Examples: Amazon EMR, Google Dataproc.
- Serverless Hadoop: Running Hadoop without managing servers. Example: AWS Glue.
- Kubernetes integration: Running Hadoop on Kubernetes for improved resource management.
- Performance improvements: Improvements in HDFS, YARN and underlying hardware leading to faster processing.
- Apache Spark integration: Running Spark on YARN for faster processing compared to MapReduce.
- Stream processing: Processing continuous data streams using frameworks like Apache Flink and Spark Streaming.
- SQL interfaces: Using SQL-like interfaces to work with Hadoop like Apache Hive and Apache Impala.
