### Security Standards for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

* Cloud Security Alliance (CSA) Controls - CSA has defined security guidance in the form of controls which help in assessing security risks in cloud computing. Some of the CSA controls are:
	* Data Location and Governance - Knowing the location of data and controlling how it is managed and used.
	* Legal Issues - Complying with applicable laws and regulations.
	* Threats and Vulnerabilities - Identifying and addressing threats and vulnerabilities specific to cloud computing.
	* Application Security - Ensuring application security measures are in place.
	* Identity and Access Management - Properly managing identity and access to resources.
* ISO/IEC 27001 - This is an international standard for information security management systems. It provides requirements and guidelines for designing, implementing, operating, monitoring, maintaining, and improving an ISMS.
* PCI DSS - Payment Card Industry Data Security Standard comprises requirements for enhancing payment account data security. It applies to companies that store, process, or transmit cardholder data.
* HIPAA - Health Insurance Portability and Accountability Act has security and privacy rules for safeguarding medical information. It applies to healthcare providers, insurers, and their business associates.

* PCI - Payment Card Industry, think of 'Protect Card Information' for data security
* HIPAA - Health Insurance Portability and Accountability Act, think of 'Health Information Protected, Always' for medical information security
