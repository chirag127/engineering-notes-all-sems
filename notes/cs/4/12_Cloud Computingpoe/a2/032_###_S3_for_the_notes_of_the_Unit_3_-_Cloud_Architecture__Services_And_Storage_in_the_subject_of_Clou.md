### S3 for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

S3 stands for Simple Storage Service. It is a storage as a service provided by Amazon Web Services (AWS).

Characteristics of S3:

- Object based storage: Data is stored as objects (files) in S3 buckets.
- Scalable: It is highly scalable and we can store massive amounts of data.
- Durable: S3 is designed for 99.999999999% durability. It stores data across multiple servers/data centers.
- Highly available: S3 offers high availability of objects (99.99%).
- Flexible: Supports various storage classes for different use cases and pricing.
- Secure: Provides encryption and access control features.

Some key terms:

- Bucket: A bucket is a container for storing objects (files). Bucket names are globally unique.
- Object: An object is a file (like images, docs, videos, etc.) stored in S3. Objects consist of data and metadata.
- Key: The name of the object (file) in the bucket is called as key.

Advantages of S3:

- Scalable and durable storage.
- Pay as you go model (pay for what you use).
- Integrations with other AWS services.
- Versioning and encryption support.
- Lifecycle management (archive/delete old objects).
- Geo-redundancy (replicate across regions).

Use cases of S3:

- Backup and archival storage.
- Static website hosting.
- Storage for media files/datasets.
- Storage for logs and analytics data.
- Mobile and web application data storage.
