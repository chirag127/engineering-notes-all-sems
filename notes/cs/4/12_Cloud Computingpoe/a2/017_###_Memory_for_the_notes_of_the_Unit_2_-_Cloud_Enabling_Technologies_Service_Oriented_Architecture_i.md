### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

- SOA stands for Service Oriented Architecture. It is a style of software design where applications are built as a set of services that can be used within an organization or over the Internet.
- Services are loosely coupled, reusable software components that encapsulate discrete functionality. They are accessed via protocols and defined interfaces.
- SOA focuses on the service rather than the application so that services can be shared across multiple applications. This facilitates reuse and increased interoperability.
- The key principles of SOA are:
-- Standardized service contract
-- Loose coupling
-- Service abstraction
-- Service reusability
-- Service discoverability
-- Service composability

Advantages:
- Increased interoperability and integration
- Improved reuse of services and applications
- Flexibility and adaptability to change
- Separation of concerns

Disadvantages:
- Complexity of implementation and management
- Performance overhead due to communication between services
- Versioning issues with services
- Security and governance challenges

Examples of SOA implementations:
- Amazon Web Services
- Google APIs
- Salesforce Platform

Applications:
- Enterprise application integration
- Business process management
- Cloud computing

 Mnemonics:
- SOA is all about sharing "Services"
- Loose coupling means "Less" dependency
- Services are like "Reusable" and "Flexible" building blocks

Learning tricks:
- Understand the key principles and benefits of SOA
- Read case studies and examples of successful SOA implementations
- Practice implementing a small SOA project to understand the concepts better
