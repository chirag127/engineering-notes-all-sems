### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Cloud security refers to the set of control-based technologies and policies designed to protect cloud-based systems, data, applications, and infrastructure. Since cloud computing relies on sharing computing resources, it is important to have strong security measures in place to prevent unauthorized access and to keep data secure.
- The key aspects of cloud security are:

1. Identity and access management: Provisioning and deprovisioning of user access, managing passwords, access control etc. Multi-factor authentication can be used for additional security.
2. Data protection: Data should be encrypted when in transit and at rest. Access to encrypted data can be controlled using keys.
3. Application security: Web applications need input validation and security patching. APIs also need to be secured from threats like spoofing.
4. Network security: Firewalls, monitoring and intrusion detection systems are required to protect from network based threats. VLANs and subnets can be used to isolate applications.
5. Governance and compliance: There should be visibility into security events and compliance with regulations like GDPR, HIPAA etc. Policies should be in place for security monitoring and incident response.

- Some additional tips for cloud security:

- Choose a reputable cloud provider with strong security controls and certifications like ISO 27001, SOC 2 etc.
- Use cloud provider's security groups and access controls to restrict access.
- Keep software and systems patched and up to date.
- Use encryption for data in transit and at rest.
- Monitor accounts and APIs for suspicious activity.
- Have an incident response plan in place.
- Train employees on security best practices.

- Mnemonics: CIA - Confidentiality, Integrity, Availability. The three pillars of security.
