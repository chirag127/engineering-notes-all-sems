### Cloud Characteristics for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud computing is a model for delivering computing services over the internet. It has become increasingly popular in recent years due to its many benefits, including cost savings, scalability, and flexibility. Cloud computing services are characterized by several key features, known as the cloud characteristics, which are essential for understanding the capabilities and limitations of cloud computing.

The following are the cloud characteristics:

1. On-demand self-service: Cloud computing services can be easily accessed and used by users without the need for human intervention. Users can provision and use computing resources such as servers, storage, and applications on an as-needed basis.

2. Broad network access: Cloud computing services are accessible over the internet from any device with internet connectivity, including desktop computers, laptops, tablets, and smartphones.

3. Resource pooling: Cloud computing resources are shared among multiple users, allowing for efficient use of resources and cost savings. Resources such as computing power, storage, and bandwidth are dynamically allocated and reassigned based on user demand.

4. Rapid elasticity: Cloud computing resources can be quickly and easily scaled up or down to meet changing user demand. This allows for flexibility and cost savings, as resources can be added or removed as needed.

5. Measured service: Cloud computing services are metered and billed based on actual usage. This allows users to pay only for the resources they use, rather than investing in costly infrastructure that may not be fully utilized.

Remembering the cloud characteristics can be challenging, but there are some helpful mnemonics and learning tricks that can aid in memorization. One such mnemonic is "ORBRR," which stands for On-demand self-service, Resource pooling, Broad network access, Rapid elasticity, and Measured service. Another learning trick is to visualize a cloud with five distinct parts, each representing one of the cloud characteristics.

In summary, understanding the cloud characteristics is essential for understanding the capabilities and limitations of cloud computing services. Remembering these characteristics can be aided by using mnemonics or visual aids, allowing for a deeper understanding of cloud computing and its benefits.
