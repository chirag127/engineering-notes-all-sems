## Unit 3 - Cloud Architecture, Services And Storage

Cloud computing has revolutionized the IT industry by providing a highly scalable and flexible infrastructure that enables businesses to focus on their core competencies. Cloud architecture, services and storage are the key components of cloud computing that enable businesses to leverage the benefits of the cloud. In this unit, we will explore the following topics:

### Cloud Architecture

- Cloud architecture is the design of the overall infrastructure and environment that supports the cloud computing services.
- There are three main types of cloud architecture: public cloud, private cloud, and hybrid cloud.
- Public cloud architecture is where the cloud infrastructure is owned and managed by a third-party cloud service provider.
- Private cloud architecture is where the cloud infrastructure is owned and managed by the organization itself.
- Hybrid cloud architecture is a combination of public and private cloud architectures.
- Cloud architecture involves the design of the network, servers, storage, and other components that make up the cloud infrastructure.

### Cloud Services

- Cloud services are the software applications and resources that are provided through the cloud infrastructure.
- There are three main types of cloud services: Software as a Service (SaaS), Platform as a Service (PaaS), and Infrastructure as a Service (IaaS).
- SaaS provides software applications that are hosted on the cloud and accessed through the internet.
- PaaS provides a platform for developing and deploying software applications on the cloud infrastructure.
- IaaS provides virtualized computing resources, such as servers, storage, and networking, that can be used to build and run applications on the cloud.

### Cloud Storage

- Cloud storage is the storage of data on remote servers that can be accessed over the internet.
- There are two main types of cloud storage: object storage and block storage.
- Object storage is used to store unstructured data, such as files and multimedia content.
- Block storage is used to store structured data, such as databases and virtual machines.
- Cloud storage provides scalability, durability, and accessibility to data stored on the cloud infrastructure.

## Mnemonics and Learning Tricks

- To remember the three main types of cloud architecture, use the mnemonic "P-P-H": Public, Private, Hybrid.
- To remember the three main types of cloud services, use the mnemonic "S-P-I": Software as a Service, Platform as a Service, Infrastructure as a Service.
- To remember the two main types of cloud storage, use the phrase "O-B, that's how I store my data on the cloud".
