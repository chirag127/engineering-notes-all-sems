### REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

REST, which stands for Representational State Transfer, is a popular architectural style for designing web-based systems. It is a lightweight and flexible approach that uses HTTP protocols to enable communication between clients and servers. RESTful web services are widely used in cloud computing applications due to their scalability, simplicity, and ease of use.

#### Key Concepts of REST

- **Resources**: In REST, resources are the key abstraction. A resource can be any object, concept, or entity that a client wants to access or manipulate. Resources are identified by their unique URLs, which are used to access or manipulate them.
- **HTTP Methods**: RESTful web services use HTTP methods to define the actions that can be performed on resources. The most commonly used HTTP methods are GET, POST, PUT, and DELETE. GET is used to retrieve a resource, POST is used to create a new resource, PUT is used to update an existing resource, and DELETE is used to delete a resource.
- **Representations**: RESTful web services use representations to transfer data between clients and servers. A representation is a format or encoding of a resource's state that can be understood by both the client and server. Common representation formats include JSON, XML, and HTML.

#### Advantages of REST

- **Scalability**: RESTful web services are highly scalable because they are stateless and cacheable. This means that the server does not need to maintain any state information about the client, and clients can cache responses to reduce the number of requests sent to the server.
- **Flexibility**: RESTful web services are flexible because they can be used with any programming language or platform that supports HTTP.
- **Simplicity**: RESTful web services are simple to use because they use standard HTTP methods and representations, which are familiar to most developers.
- **Compatibility**: RESTful web services are compatible with a wide range of devices and platforms, including desktops, mobile devices, and IoT devices.

#### Systems of Systems

A System of Systems (SoS) is a collection of independent systems that work together to achieve a common goal. SoS are commonly used in cloud computing to enable the integration of different systems and services. SoS can be used to build complex applications that require the integration of multiple systems and services, such as e-commerce platforms, social media platforms, and online banking systems.

#### Advantages of SoS

- **Integration**: SoS enable the integration of different systems and services, which can improve the functionality and performance of complex applications.
- **Flexibility**: SoS are flexible because they can be composed of different types of systems and services, including cloud services, legacy systems, and third-party services.
- **Scalability**: SoS can be scaled horizontally or vertically to meet the demands of changing workloads and user traffic.
- **Resilience**: SoS are resilient because they can continue to function even if some of the systems or services fail.

#### Learning Tricks

- Mnemonic for REST HTTP methods: GET, POST, PUT, and DELETE can be remembered using the acronym CRUD, which stands for Create, Read, Update, and Delete.
- Visualizing SoS: Draw a diagram that represents the different systems and services in the SoS and how they interact with each other. Use different colors and shapes to represent different types of systems and services.
