
### Resource Provisioning for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

Resource provisioning is a critical aspect of cloud computing, as it involves allocating, configuring, and managing the resources that are made available to users in the cloud. It is the process of obtaining, configuring, and managing the resources that are used to provide services to customers.

The main objective of resource provisioning is to ensure that the resources are available in the right quantity and at the right time. It also involves monitoring and managing the utilization of resources to ensure that they are used efficiently.

##### Mnemonics and Learning Tricks

* **R**esource **P**rovisioning **F**or **C**loud **C**omputing (RPFCC)
* **R**esource **A**llocation **M**anagement **S**ystem (RAMS)

##### Advantages

* Cost savings: Resource provisioning helps to reduce costs by allowing users to access resources on-demand.
* Flexibility: Resources can be easily scaled up or down as per the requirements.
* Improved performance: Resources can be quickly provisioned to ensure that applications and services run smoothly.

##### Disadvantages

* Security: Resource provisioning requires the user to trust the cloud provider with sensitive data.
* Resource wastage: If the resources are not allocated efficiently, it can lead to wastage of resources.
* Complexity: Resource provisioning can be complex and time-consuming.

##### Examples

* Amazon EC2: Amazon Elastic Compute Cloud (EC2) is a web service that provides scalable computing capacity in the cloud. It allows users to rent virtual machines on which to run their applications.
* Google Compute Engine: Google Compute Engine is a cloud computing service that allows users to create and run virtual machines on Google’s infrastructure.
* Microsoft Azure: Microsoft Azure is a cloud computing platform that provides a range of services including storage, compute, and networking.

##### Applications

* Web hosting: Resource provisioning can be used to host websites and web applications in the cloud.
* Big data: Resource provisioning can be used to process large amounts of data in the cloud.
* Machine learning: Resource provisioning can be used to build and deploy machine learning models in the cloud.
