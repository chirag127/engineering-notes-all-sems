
### Tools and Mechanisms for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

* Service Oriented Architecture (SOA): SOA is an architectural style that allows different applications to communicate with each other over a network. It provides the ability to create, deploy, and manage services that can be used by different applications. It also provides the ability to quickly and easily integrate different applications and services.

* Web Services: Web services are software applications that are exposed over the internet and can be used by other applications. They can be used to communicate between different applications, provide data and services, and provide access to databases.

* Service Bus: A service bus is a communication infrastructure that provides a way for applications to communicate with each other. It handles message routing, security, and other tasks related to communication between services.

* Enterprise Service Bus (ESB): An ESB is a type of service bus that is designed to provide a way for large organizations to integrate different applications and services. It provides a way to manage communication between different applications and services and provides additional features such as security and scalability.

* API Management: API management is the process of managing the lifecycle of APIs. It includes tasks such as creating, deploying, and managing APIs, as well as providing access control, monitoring, and analytics.

* Cloud Computing: Cloud computing is the delivery of computing services over the internet. It provides the ability to access computing resources on demand, and can be used for a variety of tasks such as storage, computing, and networking.

* Cloud Enabling Technologies: Cloud enabling technologies are technologies that enable the use of cloud computing. These technologies include virtualization, containerization, orchestration, and automation.

* Security: Security is an important part of cloud computing. It includes tasks such as authentication, authorization, encryption, and access control.
