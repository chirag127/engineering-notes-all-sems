
### Public, Private and Hybrid Clouds for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

1. **Public Cloud**
    * A public cloud is a type of cloud computing that delivers services over the internet. It is owned and operated by a third-party cloud service provider, which delivers its computing resources like servers and storage over the internet.
    * Advantages: 
        - Cost effective 
        - Easy to scale 
        - High availability 
        - Flexible
    * Disadvantages: 
        - Security 
        - Compliance 
        - Limited control

2. **Private Cloud**
    * A private cloud is a type of cloud computing that is deployed within an organization's own data center. It is owned and operated by the organization itself and is not shared with any other organizations.
    * Advantages: 
        - Enhanced security 
        - Greater control 
        - Improved compliance 
        - Flexibility
    * Disadvantages: 
        - High cost 
        - Limited scalability 
        - Difficulty in managing

3. **Hybrid Cloud**
    * A hybrid cloud is a type of cloud computing that combines public cloud services with private cloud services. It allows organizations to use a single cloud platform that can be used to store, manage and process data in both public and private environments.
    * Advantages: 
        - Cost savings 
        - Improved scalability 
        - Enhanced security 
        - Improved agility
    * Disadvantages: 
        - Complexity 
        - Interoperability 
        - Limited control
