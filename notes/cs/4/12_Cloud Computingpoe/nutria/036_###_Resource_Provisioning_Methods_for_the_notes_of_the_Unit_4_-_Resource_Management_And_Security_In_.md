
### Resource Provisioning Methods for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

1. On-Demand Provisioning: On-demand provisioning is a method of provisioning resources as and when the user requires them. This method is suitable for applications that require a large number of resources for a short period of time. The resources are made available on demand and can be released when the user no longer requires them.

2. Spot Provisioning: Spot provisioning is a method of provisioning resources at a discounted rate. This method is suitable for applications that require a large number of resources for a long period of time. The resources are made available at a discounted rate and can be released when the user no longer requires them.

3. Reserved Provisioning: Reserved provisioning is a method of provisioning resources for a specific period of time. This method is suitable for applications that require a large number of resources for a long period of time. The resources are made available for a specific period of time and can be released when the user no longer requires them.

4. Preemptible Provisioning: Preemptible provisioning is a method of provisioning resources for a short period of time. This method is suitable for applications that require a large number of resources for a short period of time. The resources are made available for a short period of time and can be released when the user no longer requires them.

5. Automated Provisioning: Automated provisioning is a method of provisioning resources using automated tools. This method is suitable for applications that require a large number of resources for a long period of time. The resources are made available using automated tools and can be released when the user no longer requires them.

6. Mnemonic: To remember the different resource provisioning methods, you can use the acronym "ODRSAP" which stands for On-Demand, Spot, Reserved, Preemptible, and Automated Provisioning.
