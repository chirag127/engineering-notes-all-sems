
## Unit 5 - Cloud Technologies And Advancements Hadoop

Hadoop is an open-source software framework for distributed storage and distributed processing of large data sets on computer clusters built from commodity hardware. It is a key technology for Big Data, and provides a cost-effective, fault-tolerant, and scalable platform for data storage and processing.

Hadoop is based on the MapReduce programming model, which divides a large task into smaller tasks that can be processed in parallel. This model is used to process large amounts of data quickly and efficiently.

Hadoop provides a distributed file system (HDFS) that stores data on multiple machines. This makes it possible to store and process large amounts of data quickly and efficiently. Hadoop also provides several tools for data processing, such as Pig, Hive, and HBase.

Hadoop is used in a variety of applications, such as machine learning, data mining, web indexing, log processing, recommendation systems, and more. It is also used in scientific research, financial analysis, and other fields.
