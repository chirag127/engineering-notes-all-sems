
### Implementation Levels of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a technology that enables the abstraction of physical hardware resources from a physical machine. It allows for the creation of multiple virtual machines on a single physical machine, each with its own operating system, CPU, RAM, and other hardware components.

Virtualization can be divided into four levels:

1. **Hardware Virtualization**: This is the most basic form of virtualization, where the hardware resources of the physical machine are abstracted and presented as a virtual machine. This allows multiple virtual machines to run on the same physical machine, each with its own operating system and hardware components.

2. **Platform Virtualization**: This type of virtualization allows multiple virtual machines to run on the same physical machine, but with their own operating systems. This allows for more efficient use of resources, as multiple operating systems can be running on the same physical machine.

3. **Application Virtualization**: This type of virtualization allows applications to run on different virtual machines, but in the same physical machine. This allows for better scalability and flexibility, as applications can be moved from one virtual machine to another.

4. **Desktop Virtualization**: This type of virtualization allows multiple users to access the same desktop environment, but on different virtual machines. This allows for better collaboration and security, as users can access the same desktop environment from different locations.

Advantages of virtualization include improved scalability, flexibility, and cost savings. Disadvantages include increased complexity, as well as potential security risks.
