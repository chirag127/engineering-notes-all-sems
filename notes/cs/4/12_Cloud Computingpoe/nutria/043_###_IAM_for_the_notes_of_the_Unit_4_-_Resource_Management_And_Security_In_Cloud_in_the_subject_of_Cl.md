
### IAM for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

IAM stands for Identity and Access Management, and is a process of managing user access to the cloud. It is the most important security measure that needs to be taken when using cloud services.

IAM helps to:

* Securely manage user access to the cloud
* Ensure that only authorized users have access to the cloud
* Monitor user activity on the cloud
* Protect data stored on the cloud
* Control access to resources on the cloud

There are three main components of IAM:

* Authentication: This is the process of verifying that a user is who they say they are. Authentication is typically done through the use of passwords, biometric data, or two-factor authentication.

* Authorization: This is the process of granting or denying access to a user based on their authentication credentials. Authorization can be done through the use of access control lists (ACLs) or role-based access control (RBAC).

* Monitoring: This is the process of keeping track of user activity on the cloud. This can be done through the use of audit logs or security event logs.

Mnemonics and learning tricks to remember IAM:

* IAM stands for Identity and Access Management
* IAM helps to Secure, Ensure, Monitor, Protect, and Control
* Authentication, Authorization, and Monitoring are the three main components of IAM
