
### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

Security Governance is an important part of cloud computing, as it ensures that all resources are managed and secured in a secure and efficient manner. It is a set of policies, procedures, and processes that are used to ensure the security and integrity of cloud resources. The following are some of the key aspects of Security Governance: 

* Access Control: Access control is the process of controlling or restricting access to cloud resources. It is used to ensure that only authorized users can access the resources. Access control can include authentication, authorization, and encryption.

* Data Protection: Data protection is the process of protecting data from unauthorized access and manipulation. This can include encryption, data masking, and data loss prevention.

* Risk Assessment: Risk assessment is the process of assessing the potential risks associated with cloud resources. This can include identifying potential threats, assessing the impact of those threats, and developing strategies to mitigate those threats.

* Security Monitoring: Security monitoring is the process of monitoring the security of cloud resources. This can include monitoring for malicious activity, monitoring for changes in the environment, and monitoring for compliance with security policies.

* Compliance: Compliance is the process of ensuring that the cloud resources are compliant with applicable laws and regulations. This can include ensuring that the cloud resources are compliant with industry standards and guidelines.

* Disaster Recovery: Disaster recovery is the process of recovering cloud resources in the event of a disaster. This can include restoring data, restoring services, and restoring access to cloud resources.

* Auditing: Auditing is the process of verifying that the cloud resources are compliant with applicable laws and regulations. This can include verifying that the cloud resources are compliant with industry standards and guidelines.
