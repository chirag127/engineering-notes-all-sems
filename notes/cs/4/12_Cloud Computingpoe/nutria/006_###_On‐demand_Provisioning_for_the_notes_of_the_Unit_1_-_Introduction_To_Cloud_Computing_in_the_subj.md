
### On‐demand Provisioning for the Notes of the Unit 1 - Introduction to Cloud Computing in the Subject of Cloud Computing

On-demand provisioning is a cloud computing concept that enables users to access and use computing resources as needed. It allows users to quickly and easily scale up or down their computing resources to meet their changing needs. This makes it an ideal solution for businesses that have unpredictable computing needs.

**Mnemonic**: ODPCU1CC

**Advantages**

- Cost-effectiveness: On-demand provisioning allows users to pay only for the resources they use, which makes it a cost-effective solution for businesses.

- Flexibility: On-demand provisioning allows users to quickly and easily scale up or down their computing resources to meet their changing needs.

- Reliability: With on-demand provisioning, users can be sure that their computing resources will always be available when they need them.

**Disadvantages**

- Security: On-demand provisioning can be vulnerable to security threats, as users are not always aware of the security measures taken by the cloud provider.

- Complexity: On-demand provisioning can be complex to set up and manage, as users need to configure the resources they need and monitor them for any changes.

**Examples**

- Amazon Elastic Compute Cloud (EC2): Amazon EC2 is a cloud computing service that provides users with on-demand access to virtual machines and other computing resources.

- Microsoft Azure: Microsoft Azure is a cloud computing platform that provides users with on-demand access to virtual machines and other computing resources.

**Applications**

- Web hosting: On-demand provisioning can be used to quickly and easily set up web servers to host websites.

- Big data processing: On-demand provisioning can be used to quickly and easily set up resources to process large amounts of data.

- Machine learning: On-demand provisioning can be used to quickly and easily set up resources to run machine learning algorithms.
