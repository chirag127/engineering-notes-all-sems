
### Cloud Characteristics for the Notes of the Unit 1 - Introduction to Cloud Computing in the Subject of Cloud Computing

1. **Scalability**: Cloud computing systems can easily be scaled up or down according to the user's needs. This allows for increased flexibility and cost savings.

2. **Elasticity**: Cloud computing systems can quickly and easily adjust to changes in demand. This allows for increased efficiency and better performance.

3. **Reliability**: Cloud computing systems are highly reliable, as they are redundant and can quickly switch to another server in case of failure.

4. **Availability**: Cloud computing systems are available 24/7, allowing users to access their data and applications anytime, anywhere.

5. **Security**: Cloud computing systems are highly secure, as they employ advanced encryption and authentication techniques to protect user data.

6. **Cost-effectiveness**: Cloud computing systems are cost-effective, as they are hosted on shared infrastructure and users only pay for the resources they use.

7. **Flexibility**: Cloud computing systems are highly flexible, as users can quickly and easily add or remove resources according to their needs.

8. **Mnemonic**: CERACS - Scalability, Elasticity, Reliability, Availability, Security, Cost-effectiveness, Flexibility.
