
### Security Standards for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

Security standards are essential for cloud computing, as they ensure the safety and security of data stored in the cloud. Cloud computing security standards are designed to protect cloud-based data and applications from unauthorized access and malicious attacks.

1. Authentication: Authentication is used to verify the identity of a user or system before granting access to cloud resources. Authentication can be done using passwords, biometric data, tokens, or other forms of identification.

2. Authorization: Authorization is used to determine which users or systems are allowed to access specific cloud resources. It is important to ensure that cloud resources are only accessible to authorized users and systems.

3. Encryption: Encryption is used to protect data stored in the cloud from unauthorized access. Encryption ensures that only authorized users and systems can access the data.

4. Data Integrity: Data integrity is used to ensure that data stored in the cloud has not been modified or corrupted. Data integrity is important for maintaining the accuracy and reliability of data stored in the cloud.

5. Threat Detection: Threat detection is used to detect malicious activities in the cloud. It is important to ensure that threats are identified and addressed in a timely manner.

6. Access Control: Access control is used to ensure that only authorized users and systems are able to access cloud resources. It is important to ensure that cloud resources are only accessible to authorized users and systems.

7. Disaster Recovery: Disaster recovery is used to ensure that data stored in the cloud is not lost in the event of a disaster. Disaster recovery is important for maintaining the availability of cloud-based data and applications.

8. Security Auditing: Security auditing is used to monitor and audit the security of cloud-based data and applications. Security auditing is important for ensuring that cloud resources are secure and compliant.
