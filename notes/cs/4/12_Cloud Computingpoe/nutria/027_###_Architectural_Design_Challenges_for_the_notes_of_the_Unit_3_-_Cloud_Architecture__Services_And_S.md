
### Architectural Design Challenges for the Notes of the Unit 3 - Cloud Architecture, Services and Storage in the Subject of Cloud Computing

- **Cloud architecture:** Cloud architecture is the design of a network of computers, servers, and storage that are connected to each other and used to provide services to users over the Internet. It is the foundation of cloud computing, which is the delivery of computing services through a network of connected devices.

- **Cloud services:** Cloud services are services that are delivered over the Internet, such as software applications, storage, and computing resources. These services are provided by cloud providers and can be used to store, manage, and process data.

- **Cloud storage:** Cloud storage is the storage of data in the cloud, which is a network of computers, servers, and storage devices that are connected to each other. Cloud storage can be used to store data that is not needed on a regular basis, or to back up data that is important and needs to be kept safe.

- **Mnemonics and learning tricks:** Mnemonics are techniques used to help remember information. Common mnemonics used to remember information related to cloud architecture, services, and storage include:
  - **C-A-S-S:** Cloud Architecture, Services, and Storage
  - **C-S-S-S:** Cloud Storage, Services, and Security
  - **C-S-C-S:** Cloud Storage, Computing, and Services
  - **S-C-S-S:** Storage, Computing, Services, and Security
  - **S-S-S-C:** Storage, Security, Services, and Cloud
