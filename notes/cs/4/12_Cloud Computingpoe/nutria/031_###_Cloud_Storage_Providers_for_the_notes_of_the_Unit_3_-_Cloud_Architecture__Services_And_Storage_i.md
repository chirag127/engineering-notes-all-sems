
### Cloud Storage Providers for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

Cloud storage providers are companies that provide storage space for data and files on the cloud. They provide services such as backup, synchronization, and file sharing. Cloud storage providers typically offer different levels of storage space and various features, such as the ability to access files from multiple devices or share files with others.

The most popular cloud storage providers are Google Drive, Dropbox, iCloud, Microsoft OneDrive, and Amazon S3. Each of these services offer different levels of storage space, features, and pricing. 

Google Drive is a cloud storage service provided by Google. It offers 15GB of free storage space and allows you to access your files from any device. Google Drive also offers additional features such as file sharing, collaboration, and version control.

Dropbox is a cloud storage service that offers 2GB of free storage space. It also offers additional features such as file sharing, collaboration, and version control.

iCloud is a cloud storage service provided by Apple. It offers 5GB of free storage space and allows you to access your files from any Apple device. Additionally, iCloud offers features such as file sharing, collaboration, and version control.

Microsoft OneDrive is a cloud storage service provided by Microsoft. It offers 5GB of free storage space and allows you to access your files from any device. It also offers additional features such as file sharing, collaboration, and version control.

Amazon S3 is a cloud storage service provided by Amazon. It offers unlimited storage space and allows you to access your files from any device. Additionally, Amazon S3 offers features such as file sharing, collaboration, and version control.

Mnemonics and Learning Tricks: 
- Google Drive: G for Google, D for Drive.
- Dropbox: D for Dropbox, B for Box.
- iCloud: I for iCloud, C for Cloud.
- Microsoft OneDrive: M for Microsoft, O for OneDrive.
- Amazon S3: A for Amazon, S for Storage.
