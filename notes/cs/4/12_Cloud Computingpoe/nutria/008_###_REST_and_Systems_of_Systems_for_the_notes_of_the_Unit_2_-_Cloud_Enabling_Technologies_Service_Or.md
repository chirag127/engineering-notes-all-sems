
### REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

REST (Representational State Transfer) is an architectural style for designing distributed systems. It is based on the principles of client-server communication, statelessness, and a uniform interface. Systems of Systems (SoS) is a concept that describes the integration of multiple autonomous systems into a single, unified system. This type of system is often used in distributed computing applications, such as cloud computing.

REST and SoS both have advantages and disadvantages. REST is a simpler architecture, making it easier to implement and maintain. However, it can be difficult to scale, as the number of clients and servers increases. SoS is more complex, but provides greater scalability and flexibility.

Mnemonics and Learning Tricks:

REST:
- Representational State Transfer
- Requests Should be Stateless
- Resources are Uniformly Accessed

SoS:
- Systems of Systems
- Scalability and Flexibility
- Separate Autonomous Systems
