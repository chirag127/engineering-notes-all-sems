
### Google App Engine for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

Google App Engine is a cloud computing platform that enables developers to build applications and services on the same infrastructure that Google uses internally. It provides features such as automatic scaling, load balancing, logging, and monitoring. It also provides an easy-to-use application programming interface (API) that allows developers to quickly develop, deploy, and manage applications on the Google cloud.

Google App Engine is used for a variety of applications, including web applications, mobile applications, and enterprise applications. It is also used for the development of large-scale applications such as Google Docs and Google Maps.

Advantages of Google App Engine:

- Automatic scaling and load balancing: App Engine automatically scales applications up and down according to demand, without any manual intervention. It also automatically balances the load across multiple servers, ensuring that applications are always running optimally.

- Easy to use API: App Engine provides a simple, intuitive API that makes it easy to develop, deploy, and manage applications.

- Cost savings: App Engine is cost-effective, as it only charges for the resources used.

- Security: App Engine provides robust security features, such as authentication, authorization, and encryption.

- Reliability: App Engine is highly reliable and provides 99.95% uptime.

Disadvantages of Google App Engine:

- Limited support for certain languages: App Engine only supports a limited number of languages, including Java, Python, and Go.

- Limited memory and disk space: App Engine provides limited memory and disk space, which can be a limitation for some applications.

- No support for custom code: App Engine does not allow users to run custom code, which can be a limitation for some applications.

- No support for custom hardware: App Engine does not allow users to use custom hardware, such as GPUs or FPGAs.
