
### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a technology that enables the creation of virtualized versions of physical hardware, software, networks, and storage. It is used to create a virtualized environment that can be used to run applications, store data, and provide services.

Virtualization provides many benefits, such as cost savings, improved scalability, increased availability, and better security. It also enables the use of cloud computing, which allows users to access services and applications from anywhere in the world. 

Virtualization Structures are used to create virtualized versions of physical hardware, software, networks, and storage. These structures include:

- **Virtual Machines (VMs):** A virtual machine is a software-based machine that runs on a physical computer. VMs are used to run multiple operating systems on a single physical computer.

- **Containers:** Containers are virtualized environments that allow applications to run without the need for a full operating system. Containers are lightweight, portable, and can be used to quickly deploy applications.

- **Hypervisors:** Hypervisors are software programs that manage the running of virtual machines. They are used to create, manage, and monitor the performance of virtual machines.

- **Cloud Platforms:** Cloud platforms are virtualized infrastructures that allow users to access services and applications from anywhere in the world. They are used to create, manage, and maintain cloud-based applications.

Mnemonics and learning tricks for Virtualization Structures:

- **VMs:** Virtualize Multiple Operating Systems
- **Containers:** Lightweight and Portable
- **Hypervisors:** Create, Manage, Monitor
- **Cloud Platforms:** Access Services Anywhere
