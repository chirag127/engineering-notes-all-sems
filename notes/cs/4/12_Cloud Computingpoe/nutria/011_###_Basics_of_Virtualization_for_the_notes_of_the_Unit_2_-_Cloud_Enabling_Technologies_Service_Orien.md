
### Basics of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a process of creating a virtual version of something, such as an operating system, a server, a storage device, or a network resource. It allows multiple operating systems and applications to run on the same physical server, thus reducing hardware costs and increasing efficiency.

Virtualization can be used to improve the performance, scalability, and availability of applications. It also allows for the creation of virtual machines, which can be used to test new software or applications without affecting the existing system.

The following are some of the advantages of virtualization:

- Increased hardware utilization: By running multiple applications on a single physical server, hardware utilization can be increased significantly.
- Improved scalability: Virtualization allows for the addition of more virtual machines to an existing server, thus allowing for increased scalability.
- Reduced costs: By running multiple applications on a single physical server, costs associated with hardware and software can be reduced significantly.
- Improved security: Virtualization can provide better security by isolating applications from each other and preventing them from accessing each other's data.
- Increased flexibility: Virtualization allows for the creation of multiple virtual machines, which can be used to test new software or applications without affecting the existing system.
