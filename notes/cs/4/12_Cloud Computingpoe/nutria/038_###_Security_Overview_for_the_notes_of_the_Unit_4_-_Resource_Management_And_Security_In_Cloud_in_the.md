

### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security is an essential aspect of cloud computing, as it affects the integrity and confidentiality of the data stored in the cloud.
- Cloud security is a shared responsibility between the cloud service provider and the customer. The cloud service provider is responsible for the security of the cloud infrastructure and the customer is responsible for the security of the data stored in the cloud.
- Cloud security includes the physical security of the cloud infrastructure, the security of the data stored in the cloud and the security of the applications running in the cloud.
- Security in the cloud can be achieved through a combination of technologies such as firewalls, authentication, encryption, access control, data loss prevention and intrusion detection.
- Security policies should be established and enforced to ensure that the cloud environment is secure.
- Security measures should be regularly monitored and tested to ensure that they are effective.
- Mnemonic: Cloud Security = Physical Security + Data Security + Application Security.
