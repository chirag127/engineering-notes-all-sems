
## Unit 1 - Introduction To Cloud Computing

- Cloud computing is a type of computing that relies on sharing computing resources over the internet. It allows users to access applications and data stored on remote servers, rather than on their own computers.
- Cloud computing is made up of three main components: Infrastructure as a Service (IaaS), Platform as a Service (PaaS) and Software as a Service (SaaS).
- IaaS provides users with access to virtualized computing resources, such as servers, storage and networking. PaaS provides users with access to development platforms and tools. SaaS provides users with access to applications and services over the internet.
- Cloud computing is beneficial for businesses and individuals because it allows them to access computing resources on-demand and pay for only what they use. It also provides users with flexibility and scalability, as they can quickly add or remove resources as needed.
- Cloud computing is also more secure than traditional computing, as data is stored and managed on remote servers, rather than on the user's computer.
- Mnemonics for remembering the three components of cloud computing are: IaaS (Infrastructure as a Service) = "I Serve", PaaS (Platform as a Service) = "Platforms Please", and SaaS (Software as a Service) = "Software Saves".
