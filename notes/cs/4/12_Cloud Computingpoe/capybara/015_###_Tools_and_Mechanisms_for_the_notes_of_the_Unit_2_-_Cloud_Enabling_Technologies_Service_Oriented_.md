### Tools and Mechanisms for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Service Oriented Architecture (SOA) is an architectural model that enables the creation of applications using services. Cloud Computing is based on the principles of SOA and provides various tools and mechanisms for the development and deployment of services. In this section, we will discuss some of the key tools and mechanisms used in Cloud Computing for SOA.

1. Web Services: Web services are self-contained and modular applications that can be accessed over the internet. They provide a standardized way of accessing and integrating applications across different platforms and technologies. Web services are based on open standards such as XML, SOAP, and WSDL.

2. Service Registry: A service registry is a centralized repository that contains information about the available services in a system. It provides a mechanism for service discovery, where clients can search for and locate the services they require. Service registries can be either UDDI-based or REST-based.

3. Service Bus: A service bus is a middleware component that provides a messaging infrastructure for the exchange of messages between services. It enables the decoupling of services by providing a layer of abstraction between them. Service buses can be either ESB-based or REST-based.

4. Service Orchestration: Service orchestration is the process of coordinating multiple services to achieve a specific business goal. It involves defining the sequence of service invocations, handling exceptions, and managing transactions. Service orchestration can be either BPEL-based or REST-based.

5. Cloud Computing Platforms: Cloud computing platforms provide a complete environment for the development, deployment, and management of cloud-based applications. They offer a range of tools and services such as storage, computing, and networking, which can be used to build and deploy cloud-based services.

Mnemonics and Learning Tricks:

1. Remember the acronym "WSSOB" to recall the key tools and mechanisms used in Cloud Computing for SOA: Web Services, Service Registry, Service Bus, Orchestration, and Cloud Platforms.

2. Visualize the service bus as a "traffic controller" that manages the flow of messages between services.

3. Think of service orchestration as a "conductor" that directs the sequence of service invocations to achieve a specific business goal.

In conclusion, Cloud Computing provides a range of tools and mechanisms for the development and deployment of services based on SOA principles. Understanding these tools and mechanisms is important for building scalable and resilient cloud-based applications.
