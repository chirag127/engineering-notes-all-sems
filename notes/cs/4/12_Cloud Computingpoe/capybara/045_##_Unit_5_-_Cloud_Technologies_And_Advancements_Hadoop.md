## Unit 5 - Cloud Technologies And Advancements Hadoop

Hadoop is an open-source software framework used for distributed storage and processing of large datasets on clusters of commodity hardware. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage. Hadoop is widely used in cloud technologies and advancements due to its ability to handle big data efficiently.

Here are some important points to help you understand Hadoop better:

1. Hadoop Architecture: Hadoop has a master-slave architecture consisting of a single master node called the NameNode and multiple slave nodes called DataNodes. The NameNode manages the file system metadata and the DataNodes store the actual data.

2. Hadoop Distributed File System (HDFS): HDFS is the primary storage system used by Hadoop. It is a distributed file system that provides high-throughput access to application data. HDFS is highly fault-tolerant and is designed to be deployed on low-cost hardware.

3. MapReduce: MapReduce is a programming model used for processing large datasets in parallel. It is used to write programs that process large amounts of data in parallel across multiple nodes in a Hadoop cluster.

4. Hadoop Ecosystem: Hadoop has a vast ecosystem of tools and technologies built around it. Some popular tools include Apache Hive, Apache Pig, Apache Spark, and Apache HBase.

5. Advantages of Hadoop: Hadoop is highly scalable, fault-tolerant, and cost-effective. It can handle a large amount of data and can be easily deployed on commodity hardware. It is also open-source and provides a vast ecosystem of tools and technologies.

6. Disadvantages of Hadoop: Hadoop has a high learning curve and requires a good understanding of distributed systems. It is also not suitable for real-time processing and has limited support for interactive queries.

Mnemonics and learning tricks:

1. Hadoop can be remembered as "Huge Amounts of Data Operating Optimally on Platforms".

2. The Hadoop architecture can be remembered as "One NameNode to Rule Them All and Multiple DataNodes to Store Them".

3. MapReduce can be remembered as "Map Your Data to Reduce the Workload".

Overall, Hadoop is a valuable tool in cloud technologies and advancements due to its ability to handle big data efficiently. By understanding its architecture, file system, and programming model, you can develop applications that process large amounts of data in parallel across a Hadoop cluster.
