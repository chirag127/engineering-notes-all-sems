## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

Service Oriented Architecture (SOA) is a design pattern used for developing and integrating enterprise-level software applications. It is a collection of services that communicate with each other. These services can be reused and combined to create composite services.

### Key Concepts of SOA
- Service: A service is a self-contained unit of functionality that is available to other applications via a network.
- Service Provider: An entity that provides a service.
- Service Consumer: An entity that consumes a service.
- Service Registry: A directory that stores the location and description of services available in the network.
- Service Broker: A mediator between a service provider and a service consumer.
- Service Contract: An agreement between the service provider and the consumer that describes the behavior of the service.

### Advantages of SOA
- Flexibility: Services can be developed independently and can be combined to create new services.
- Reusability: Services can be reused across different applications.
- Interoperability: Services can be developed using different technologies and can communicate with each other.
- Scalability: Services can be scaled up or down based on demand.
- Reduced Cost: Services can be developed and maintained independently, reducing the overall cost of development.

### Disadvantages of SOA
- Complexity: SOA can be complex to design, develop, and maintain.
- Performance: The use of SOA can lead to performance issues due to the overhead involved in communication between services.

### Examples of SOA
- Amazon Web Services (AWS) uses SOA for its cloud-based services.
- eBay uses SOA to integrate different applications and services.
- PayPal uses SOA for its payment processing services.

### Applications of SOA
- Enterprise Application Integration (EAI)
- Business Process Management (BPM)
- Cloud Computing
- Service Virtualization

In order to remember the key concepts of SOA, you can use the mnemonic "SPRBC". This stands for Service, Service Provider, Service Consumer, Service Registry, Service Broker, and Service Contract.
