### Virtualization Support and Disaster Recovery for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the creation of a virtual version of something, such as an operating system, server, storage device, or network resources. Virtualization support enables cloud services to run on virtual machines, which can be managed by cloud providers. Disaster recovery is the process of restoring the IT infrastructure of an organization to its normal state after a disaster or disruptive event.

Here are some important points to remember about Virtualization Support and Disaster Recovery in Cloud Computing:

#### Virtualization Support

- Virtualization enables cloud providers to run multiple virtual machines on a single physical machine, which can save money and improve efficiency.
- Virtualization also enables cloud providers to quickly provision and de-provision virtual machines to meet changing demand.
- Virtualization support in cloud computing allows customers to run their own virtual machines on cloud infrastructure, or to use pre-configured virtual machines provided by the cloud provider.
- Virtualization support can be provided at the hardware, operating system, or application level, depending on the needs of the cloud provider and the customer.

#### Disaster Recovery

- Disaster recovery is a critical aspect of cloud computing, as organizations rely on cloud services to store and process sensitive data.
- Disaster recovery plans should be in place to ensure that data is backed up and can be restored in the event of a disaster or disruptive event.
- Cloud providers often offer disaster recovery services, such as backup and recovery, replication, and failover.
- Disaster recovery plans should also include testing and validation to ensure that backups can be restored and systems can be recovered in a timely manner.

#### Mnemonics and Learning Tricks

- One mnemonic for remembering virtualization support is "VMs on VMs" – this emphasizes the concept of running virtual machines on a virtualized infrastructure.
- Another mnemonic for remembering disaster recovery is "prepare for the worst" – this emphasizes the importance of having a plan in place to recover from a disaster or disruptive event.
