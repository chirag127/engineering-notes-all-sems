### Open Stack for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

OpenStack is an open-source cloud computing platform that enables the creation and management of public and private clouds. It is designed to be scalable, flexible, and easy to use. OpenStack is used by many organizations to build and manage their cloud infrastructure.

Here are some important points to remember about OpenStack:

1. OpenStack is modular and flexible - OpenStack is composed of many different modules that can be combined to create a customized cloud infrastructure. This modular architecture makes OpenStack flexible and adaptable to different use cases.

2. OpenStack is open source - OpenStack is released under the Apache 2.0 license, which means that anyone can download, use, and modify the source code. This openness has led to a large and active community of developers working to improve and extend the platform.

3. OpenStack has a wide range of components - OpenStack is composed of many different components, including Nova (compute), Neutron (networking), Cinder (block storage), Glance (image service), and Swift (object storage), among others. Each component is responsible for a specific aspect of the cloud infrastructure.

4. OpenStack is compatible with multiple hypervisors - OpenStack supports multiple hypervisors, including KVM, VMware, and Hyper-V, among others. This allows organizations to choose the hypervisor that best meets their needs.

5. OpenStack has a web-based dashboard - OpenStack includes a web-based dashboard called Horizon, which provides a graphical user interface for managing the cloud infrastructure. Horizon allows users to perform tasks such as launching instances, creating networks, and managing storage.

Mnemonics and learning tricks:

- To remember the different components of OpenStack, you can use the mnemonic "NCGS": Nova (compute), Cinder (block storage), Glance (image service), and Swift (object storage).

- Another way to remember the different components is to think of them as building blocks that can be combined to create a customized cloud infrastructure. Each building block has a specific function, and together they form a complete cloud infrastructure.

Overall, OpenStack is a powerful and flexible cloud computing platform that can be used to create and manage public and private clouds. By understanding the key points and components of OpenStack, you will be better equipped to use it effectively in your organization.
