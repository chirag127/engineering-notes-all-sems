### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is a critical technology in cloud computing that enables the creation of multiple virtual environments on a single physical machine. It allows for the efficient use of resources and enables the creation of flexible and scalable cloud computing infrastructures. In this section, we will discuss the different virtualization structures used in cloud computing.

#### Types of Virtualization Structures

1. **Full Virtualization**: In full virtualization, the hypervisor creates a complete virtual machine that can run its own operating system and applications. This virtual machine is isolated from the host system and can access the physical resources of the host machine via the hypervisor.

2. **Para-Virtualization**: In para-virtualization, the guest operating system is modified to work in a virtualized environment. The hypervisor provides a modified interface to the guest operating system, allowing it to access the physical resources of the host machine. Para-virtualization provides better performance than full virtualization but requires modification of the guest operating system.

3. **Hardware-Assisted Virtualization**: Hardware-assisted virtualization uses hardware features to support virtualization. This technology is also known as native or bare-metal virtualization. It provides better performance and security than other virtualization technologies.

4. **Container-Based Virtualization**: Container-based virtualization uses a single operating system kernel to run multiple containers that share the same operating system resources. Containers are isolated from each other and from the host system, but they share the same kernel. This virtualization structure is lightweight and allows for faster startup times and better performance.

#### Advantages of Virtualization Structures

1. Efficient use of resources: Virtualization allows for the creation of multiple virtual machines on a single physical machine, enabling the efficient use of resources.

2. Scalability: Virtualization enables the creation of flexible and scalable cloud computing infrastructures.

3. Cost savings: Virtualization reduces the need for physical hardware, leading to cost savings.

4. Improved disaster recovery: Virtualization enables the creation of backup and recovery solutions that are easier to manage and more reliable.

#### Disadvantages of Virtualization Structures

1. Overhead: Virtualization can introduce overhead, which can affect performance.

2. Complexity: Virtualization can introduce complexity, which can make it difficult to manage and troubleshoot.
