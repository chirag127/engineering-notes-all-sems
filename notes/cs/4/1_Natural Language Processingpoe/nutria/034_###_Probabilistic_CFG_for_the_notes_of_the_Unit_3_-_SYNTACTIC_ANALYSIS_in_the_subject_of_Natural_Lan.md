
### Probabilistic CFG for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

* Probabilistic Context Free Grammars (PCFGs) are a type of grammar used in Natural Language Processing (NLP) to represent syntactic structure of a sentence. 
* PCFGs are a type of formal grammar, which means that they are a set of rules that can be used to generate valid sentences. 
* PCFGs are probabilistic, which means that they assign a probability to each rule they contain. This probability is used to decide which rule to use when generating a sentence. 
* PCFGs are context free, which means that the rules are independent of the context in which they are used. 
* PCFGs are used to generate syntactic structures for sentences. This is done by assigning a probability to each rule in the grammar and then using these probabilities to determine which rules to use when generating a sentence. 
* PCFGs can be used to generate parse trees, which represent the syntactic structure of a sentence. 
* PCFGs are useful for tasks such as natural language understanding, machine translation, and speech recognition. 
* PCFGs can also be used to generate language models, which can be used to determine the probability of a sentence being grammatically correct. 
* PCFGs are used in many NLP applications, such as in question answering and machine translation systems.
