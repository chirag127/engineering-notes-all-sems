
### Context Free Grammars for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

Context Free Grammars (CFG) are a type of formal grammar used to describe the structure of a natural language. They are used to analyze the syntax of a sentence and to generate a parse tree that shows how the words in the sentence are related. CFGs are also used in natural language processing (NLP) applications such as machine translation, speech recognition, and text-to-speech synthesis.

CFGs are composed of four components:

* Terminal symbols: These are the words of the language, such as nouns, verbs, adjectives, etc.

* Non-terminal symbols: These are the syntactic categories of the language, such as noun phrases, verb phrases, etc.

* Production rules: These are the rules that define how the symbols can be combined to form valid sentences.

* Start symbol: This is the symbol that begins the derivation of a sentence.

A CFG consists of a set of production rules that define how the symbols can be combined to form valid sentences. The production rules are of the form A -> B, where A is a non-terminal symbol and B is a sequence of terminal and non-terminal symbols.

For example, the rule S -> NP VP states that a sentence (S) can be derived from a noun phrase (NP) followed by a verb phrase (VP).

Learning Tricks:

• Think of a CFG as a set of instructions for creating valid sentences in a language.

• Remember that the production rules define how the symbols can be combined to form valid sentences.

• Try to visualize the parse tree to understand how the words in a sentence are related.
