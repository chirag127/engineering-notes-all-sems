## Unit 1 - INTRODUCTION

1. Computer Fundamentals
- A computer is an electronic device that receives input, stores and manipulates data, and provides output in a useful format.
- The major components of a computer are: CPU, Memory, Storage, Input Devices, Output Devices, Software.
- Binary number system: Only 0s and 1s are used to represent data. Uses bits and bytes. 8 bits = 1 byte.
- Data representation: Text, Images, Audio, Video are represented as binary data for storage and processing.
- Computer Architecture: Von Neumann architecture, Harvard architecture.
- Processor: Clock speed, word size, instructions.
- Memory: RAM, ROM, Cache memory. Volatile vs non-volatile memory.
- Storage: HDD, SSD, Flash drives. Primary vs secondary storage.

2. Operating Systems
- An operating system acts as an interface between the user and the hardware. It performs tasks like file management, memory management, process management, handling input/output, and controlling peripherals.
- Popular operating systems: Windows, Linux, macOS, Android, iOS.
- Components of an OS: Kernel, System calls, Shell, GUI, File system.
- Functions of OS: Process management, Memory management, File management, Handling I/O devices, Providing user interface, Maintaining security.
