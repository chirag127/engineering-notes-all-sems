### Transformation-based tagging for the notes of the Unit 2 - WORD LEVEL ANALYSIS in the subject of Natural Language Processing

- Transformation-based tagging is a supervised machine learning technique for assigning tags to tokens in a text. It uses a set of hand-tagged training data to learn a series of rules for tagging unseen tokens.
- The basic steps in transformation-based tagging are:
	1. Start with an initial tag for each token
	2. Apply a sequence of transformation rules that change the tags of individual tokens or sequences of tokens
	3. Repeat step 2 until no more transformations can be applied
- Advantages:
	- Simple to implement
	- Often achieves high accuracy
	- Provides insight into patterns in the data
- Disadvantages:
	- Requires hand-tagged training data
	- Accuracy depends heavily on the initial tags and the set of transformation rules
	- Does not scale well to large datasets or complex tagging schemes
- Examples: Parts-of-speech tagging, named entity recognition
- Applications: Text segmentation, information extraction, machine translation, etc.

- Mnemonics: Think of transformation-based tagging as repeatedly "transforming" the tags of tokens using rules until no more changes can be made. The end result is a fully tagged text.
- The key steps (start tagging, apply transformations, repeat) can be remembered using the mnemonic SAT.
