### Syntactic Parsing for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

- Syntactic parsing is the process of analyzing the structure of sentences to identify the syntactic elements and their relationships.
- It is done using context-free grammars which define the valid sequences of words (syntactic rules).
- The input is checked against these rules to identify the syntactic structure.
- The output is a parse tree that represents the syntactic structure.
- Examples of context-free grammars:
  - Chomsky Normal Form Grammar
  - Extended Backus–Naur Form (EBNF)
- Advantages:
  - It can handle ambiguity and complexity in language.
  - It provides a mathematical framework to analyze syntax.
- Disadvantages:
  - It does not consider semantics, only syntax.
  - It may result in multiple parse trees for a sentence leading to ambiguity.
- Applications:
  - Question answering systems
  - Machine translation
  - Text summarization
  - Part-of-speech tagging
- Mnemonics:
  - "Syntax before semantics, parse those trees!"
  - "EBNF is a handy form, to define the rules of syntax's norm!"
- To learn:
  - Understand context-free grammars and parsing algorithms.
  - Practice identifying parse trees for sentences.
  - Know the advantages and limitations of syntactic parsing.
