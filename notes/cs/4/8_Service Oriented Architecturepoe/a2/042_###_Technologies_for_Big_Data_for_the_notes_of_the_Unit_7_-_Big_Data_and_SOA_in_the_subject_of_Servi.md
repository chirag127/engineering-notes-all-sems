### Technologies for Big Data

The major technologies used for big data processing and analysis are:

1. Hadoop ecosystem - Hadoop is a distributed processing system. It has two major components -

- HDFS - Hadoop Distributed File System - stores data across multiple machines.
- MapReduce - a programming model for processing large data sets with a parallel, distributed algorithm on a cluster.

Other tools in the Hadoop ecosystem - Pig, Hive, HBase, Spark, etc. help with data processing, querying, and storage.

Advantages - Scalable, Fault tolerant, Cost effective.
Disadvantages - Complex to use, lack of real-time processing.

2. NoSQL databases - Not only SQL. Used for unstructured and semi-structured data. Eg - MongoDB, Cassandra, HBase, CouchDB, etc.

Advantages - Scalable, Schema-less.
Disadvantages - Limited query capabilities, eventual consistency.

3. Stream processing - Processing unbounded data streams in real-time. Eg - Apache Kafka, Apache Flink, Apache Spark Streaming, etc.

Advantages - Low latency, good for real-time data.
Disadvantages - Require high throughput, complex systems.

4. Search engines - Enable fast searches and queries on large data. Eg - Elasticsearch, Solr, Splunk, etc.

Advantages - Fast searches and aggregations.
Disadvantages - Require knowledge of query syntax.

Mnemonics:

- HDFS - High throughput, Distributed file system
- NoSQL - Not only SQL
- ACID - Atomicity, Consistency, Isolation, Durability (Transaction properties)

Learning tricks:

- Understand the use cases and requirements to choose the appropriate technology.
- Practice and hands-on experience to get familiar with the tools and frameworks.
- Look at the pros and cons of different options and see what suits the problem.
