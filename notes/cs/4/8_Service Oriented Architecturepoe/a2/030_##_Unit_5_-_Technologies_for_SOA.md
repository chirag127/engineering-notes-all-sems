## Unit 5 - Technologies for SOA

Some of the core technologies used for implementing Service Oriented Architecture (SOA) are:

1. XML - eXtensible Markup Language is the standard format for data interchange over the web. It is platform and language independent and acts as a medium for communication between heterogeneous systems. XML is used for defining service contracts, data interchange formats, configuration files, etc. in SOA.

 Mnemonic - "X" in XML denotes eXchange and "ML" denotes Markup Language.

2. SOAP - Simple Object Access Protocol is a messaging protocol used for exchanging information among computers. It uses XML for defining its message format and relies on application layer protocols like HTTP for message transmission. SOAP provides the basic messaging framework for web services which form the building blocks of SOA.

3. WSDL - Web Services Description Language is an XML based interface definition language. It is used for describing the interface of a web service in a platform and language neutral manner. WSDL files describe the location, bindings and operations of a web service which enables clients to discover and understand the functionality of a service.

4. UDDI - Universal Description, Discovery and Integration is a directory where businesses can register and discover web services. UDDI is a centralized registry which allows publishing of service description in a standard format and its subsequent discovery by interested parties. It enables service providers to advertise their services and service requesters to find suitable services dynamically.

Advantages - Facilitates loose coupling, Interoperability, Language and platform independence, Dynamic service discovery, etc.
Disadvantages - Complex technology stack, Vendor dependence, Performance overhead, etc.
Applications - Business Process Automation, Enterprise Application Integration, Distributed Computing, etc.
