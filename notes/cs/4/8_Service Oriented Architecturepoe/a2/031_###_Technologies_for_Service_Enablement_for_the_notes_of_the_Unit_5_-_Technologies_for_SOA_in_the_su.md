### Technologies for Service Enablement

The key technologies used for service enablement are:

1. XML - eXtensible Markup Language
- Used for defining data formats and messaging protocols in SOA
- Self describing language - contains metadata that describes the meaning of elements and attributes
- Platform and language independent
- Widely supported by tools and technologies
- Examples: SOAP, WSDL, XML Schema

Mnemonic: eXtensible Markup Language (XML) is used for eXchanging data over networks

2. SOAP - Simple Object Access Protocol
- Standard messaging protocol used for exchange of information in web services
- Uses XML for messaging
- Works over HTTP and SMTP
- Provides extensibility, neutrality, independence
- Examples: W3C Note, WS-I Basic Profile

Mnemonic: SOAP is used for Simple exchange Of Messages over HTTP

3. WSDL - Web Services Description Language
- XML based language for describing web services
- Contains information on location, operations, input/output messages
- Used by clients to discover available web services and understand how to interact with them

4. UDDI - Universal Description, Discovery and Integration
- XML based registry for publishing and discovering web services
- Enables services to be discovered and used dynamically
- Facilitates service oriented architecture and computing
- Being replaced by newer service registries with better functionality and wider adoption
