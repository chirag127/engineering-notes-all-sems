### Types of Cloud for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing
Types of Cloud:

1. Public Cloud: A public cloud is owned and operated by a third-party service provider, which makes resources and services available to the general public over the Internet.

2. Private Cloud: A private cloud is a cloud computing environment that is dedicated to a single organization. It is hosted on-premises or at a third-party data center and is only accessible by authorized users within the organization.

3. Hybrid Cloud: A hybrid cloud is a combination of both public and private clouds, where some workloads run on the public cloud and others run on the private cloud.

4. Community Cloud: A community cloud is a cloud computing environment that is shared by multiple organizations with common concerns (e.g. security, compliance, jurisdiction, etc.).

5. Multi-Cloud: A multi-cloud strategy involves the use of multiple cloud computing services from different providers, allowing organizations to take advantage of the best solutions for each workload.
