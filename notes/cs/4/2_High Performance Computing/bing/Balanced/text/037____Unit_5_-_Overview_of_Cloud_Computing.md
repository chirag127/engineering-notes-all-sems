## Unit 5 - Overview of Cloud Computing

- Cloud computing is the delivery of computing services such as servers, storage, databases, networking, software, analytics, and intelligence over the internet, or the cloud.
- Cloud computing offers various benefits such as scalability, flexibility, cost-efficiency, reliability, security, and innovation.
- Cloud computing can be classified into three main service models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
  - IaaS provides the basic computing resources such as servers, storage, and networking, which the users can rent and manage according to their needs.
  - PaaS provides the platform for developing, testing, and deploying applications, which includes the operating system, middleware, runtime, and tools.
  - SaaS provides the software applications that are hosted and managed by the cloud provider, which the users can access via a web browser or a mobile app.
- Cloud computing can also be classified into four main deployment models: public cloud, private cloud, hybrid cloud, and community cloud.
  - Public cloud is the cloud service that is available to anyone over the internet, which is owned and operated by a third-party cloud provider.
  - Private cloud is the cloud service that is dedicated to a single organization, which can be hosted on-premises or off-premises by the organization itself or a third-party cloud provider.
  - Hybrid cloud is the combination of public and private clouds, which allows the organization to leverage the best of both worlds.
  - Community cloud is the cloud service that is shared by a group of organizations that have common goals or interests, which can be hosted on-premises or off-premises by one of the organizations or a third-party cloud provider.
- Cloud computing involves various key concepts and technologies such as virtualization, containerization, orchestration, microservices, serverless computing, cloud storage, cloud networking, cloud security, cloud management, and cloud governance.
