## Unit 3 - Overview of Cluster Computing

- Cluster computing is a form of distributed computing that involves a set of computers that work together as a single system  .
- Cluster computing provides solutions to solve difficult problems by providing faster computational speed, enhanced data integrity, load balancing and high availability  .
- Cluster computing can range from a simple two-node system of two personal computers to a very fast supercomputer that has a cluster architecture .
- Cluster computing has two types of nodes: head node and compute nodes. The head node is responsible for managing the cluster, scheduling jobs, and distributing tasks to the compute nodes. The compute nodes are the ones that perform the actual computation and return the results to the head node.
- Cluster computing can be classified into different types based on the degree of coupling, the communication network, the hardware and software configuration, and the application domain. Some common types of cluster computing are: 
  - Beowulf cluster: a cluster of commodity hardware that runs Linux or other open-source operating systems and uses standard networking protocols.
  - High-performance computing (HPC) cluster: a cluster of high-end hardware that runs specialized operating systems and software and uses high-speed interconnects to achieve high performance and scalability.
  - High-availability (HA) cluster: a cluster of redundant hardware and software that provides fault tolerance and failover capabilities to ensure continuous operation of critical services.
  - Load-balancing cluster: a cluster of identical hardware and software that distributes the workload among the nodes to optimize the resource utilization and response time.
  - Grid computing: a cluster of heterogeneous and geographically distributed computers that cooperate to solve large-scale problems using a common middleware layer.
