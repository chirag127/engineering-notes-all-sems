### Internet Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Grid computing is a distributed architecture of multiple computers connected by networks to accomplish a joint task.
- These tasks are compute-intensive and difficult for a single machine to handle.
- Several machines on a network collaborate under a common protocol and work as a single virtual supercomputer to get complex tasks done.
- Grid computing is a subset of distributed computing, where a virtual supercomputer comprises machines on a network connected by some bus, mostly Ethernet or sometimes the Internet.
- Grid computing is distinguished from conventional high-performance computing systems such as cluster computing in that grid computers have heterogeneous hardware, are geographically dispersed, and are loosely coupled.
- Grid computing provides the ability to perform higher throughput computing by taking advantage of many networked computers to model a virtual computer architecture that is able to distribute process execution across a parallel infrastructure.
- Grid computing can be used for various applications, such as scientific research, data analysis, weather modeling, bioinformatics, engineering, and business .
- Grid computing can be classified into different types based on the nature and purpose of the tasks, such as computational grid, data grid, collaborative grid, manuscript grid, and modular grid.
- Computational grid computing involves the use of grid resources for performing large-scale computations, such as simulations, numerical analysis, and optimization.
- Data grid computing involves the use of grid resources for storing, managing, and accessing large volumes of distributed data, such as databases, archives, and multimedia.
- Collaborative grid computing involves the use of grid resources for enabling collaboration among multiple users, such as video conferencing, telemedicine, and online gaming.
- Manuscript grid computing involves the use of grid resources for creating and editing documents, such as books, articles, and reports.
- Modular grid computing involves the use of grid resources for designing and developing modular systems, such as software components, web services, and microservices.
