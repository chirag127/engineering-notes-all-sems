## Unit 2 - Open Grid Services Architecture

- Open Grid Services Architecture (OGSA) is a set of standards that extends Web services and service-oriented architecture to the grid computing environment .
- Grid computing is the use of a large number of computers, often geographically distributed and heterogeneous, to perform coordinated tasks that require a high level of processing power or data storage.
- OGSA defines how information is shared and distributed among the components of grid systems, which can include hardware, platforms, software, and data.
- OGSA uses most of Web service technologies, such as WSDL and SOAP, but it aims to be largely agnostic in relation to the transport-level handling of data on the grid.
- OGSA specifies a core set of interfaces, behaviors, resource models, and bindings that address key concerns in grid systems, such as security, discovery, monitoring, management, and virtualization.
- OGSA was developed within the Open Grid Forum, which was called the Global Grid Forum at the time, around 2002 to 2006.
- OGSA is not a complete architecture, but rather a framework that can be extended and customized for different domains and applications.
- OGSA is based on the concept of a Grid service, which is a Web service that conforms to a set of conventions and supports a set of capabilities defined by OGSA.
- OGSA also defines a Grid service instance, which is a transient and stateful service that can be created, named, and destroyed.
- OGSA provides a common way to model and access grid resources, such as computational elements, storage elements, networks, databases, and applications.
