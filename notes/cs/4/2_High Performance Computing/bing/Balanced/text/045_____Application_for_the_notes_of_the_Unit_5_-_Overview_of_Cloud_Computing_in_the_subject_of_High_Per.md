### Application for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is a model of delivering computing resources as services over the internet, rather than installing and maintaining them locally.
- Cloud computing enables users to access scalable, on-demand, and pay-per-use computing resources without investing in hardware, software, or infrastructure.
- Cloud computing consists of three main service models: Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).
- IaaS provides users with virtualized computing resources, such as servers, storage, networks, and operating systems, that can be provisioned and managed by the user.
- PaaS provides users with a platform for developing, testing, deploying, and managing applications, without worrying about the underlying infrastructure.
- SaaS provides users with access to software applications that are hosted and managed by the cloud provider, and can be accessed through a web browser or a mobile app.
- Cloud computing also consists of four main deployment models: public cloud, private cloud, hybrid cloud, and community cloud.
- Public cloud is a cloud service that is open and accessible to anyone over the internet, and is owned and operated by a cloud provider.
- Private cloud is a cloud service that is dedicated and isolated for a single organization, and can be hosted on-premises or off-premises by a cloud provider or a third party.
- Hybrid cloud is a cloud service that combines public and private clouds, and allows data and applications to move between them.
- Community cloud is a cloud service that is shared and managed by a group of organizations that have common goals or interests, and can be hosted on-premises or off-premises by a cloud provider or a third party.
- Cloud computing offers several benefits, such as cost reduction, scalability, elasticity, reliability, security, and innovation.
- Cloud computing also poses some challenges, such as privacy, compliance, interoperability, vendor lock-in, and performance.
