Cloud computing components are the various hardware, software, and services that make up a cloud computing system. A cloud computing architecture diagram is a visual representation of the components and their relationships in a cloud system. There are different types of cloud computing architectures, depending on the service model and deployment model of the cloud system. Some of the common service models are Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). Some of the common deployment models are public cloud, private cloud, hybrid cloud, and community cloud.

A basic cloud computing architecture diagram can be drawn using the following symbols:

- A cloud symbol to represent the cloud service provider and the cloud resources
- A rectangle to represent a server or a virtual machine
- A cylinder to represent a storage device or a database
- A circle to represent a network device or a load balancer
- A line to represent a network connection or a data flow
- A user icon to represent a client or an end user
- A text box to label the components and their properties
