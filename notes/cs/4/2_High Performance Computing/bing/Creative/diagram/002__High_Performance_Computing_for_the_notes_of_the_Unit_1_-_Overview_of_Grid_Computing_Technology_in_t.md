Grid computing is the use of widely distributed computer resources to reach a common goal. A computing grid can be thought of as a distributed system with non-interactive workloads that involve many files. Grid computing is distinguished from conventional high-performance computing systems such as cluster computing in that grid computers have each node set to perform a different task/application. Grid computers also tend to be more heterogeneous and geographically dispersed than cluster computers.

A typical grid computing architecture consists of the following components:

- A grid middleware that provides the software layer to enable resource sharing, communication, security, and coordination among the grid nodes.
- A grid fabric that consists of the physical and logical resources that are available for grid computing, such as computers, networks, storage, databases, etc.
- A grid user interface that allows users to access and use the grid resources and services, such as web portals, command-line tools, graphical user interfaces, etc.
- A grid resource broker that matches the user requests with the available grid resources and services, and schedules and monitors the execution of grid jobs.
- A grid service provider that offers grid services to users, such as data management, computation, collaboration, etc.
