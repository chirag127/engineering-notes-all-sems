### Platform for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is on-demand access, via the internet, to computing resources such as applications, servers, data storage, development tools, networking capabilities, and more, hosted at a remote data center managed by a cloud services provider.
- Cloud computing enables customers to use infrastructure and applications via the internet, without installing and maintaining them on-premises.
- Cloud computing helps lower IT costs, improve agility and time-to-value, and scale more easily and cost-effectively compared to traditional on-premises IT.
- Cloud computing also refers to the technology that makes cloud work, such as virtualization, which allows the abstraction and pooling of IT resources irrespective of physical hardware boundaries.
- Cloud computing services can be categorized into three main models: IaaS (Infrastructure-as-a-Service), PaaS (Platform-as-a-Service), and SaaS (Software-as-a-Service).
  - IaaS provides access to raw computing resources such as servers, storage, and networks over the internet. Users can provision and manage these resources according to their needs. Examples of IaaS providers are Amazon Web Services, Microsoft Azure, and Google Cloud Platform.
  - PaaS provides an on-demand environment for developing, testing, delivering, and managing software applications. Users can focus on the application logic and code, while the PaaS provider handles the underlying infrastructure and platform services. Examples of PaaS providers are Google App Engine, Microsoft Azure App Service, and Heroku .
  - SaaS provides access to ready-made software applications that run on the cloud and are delivered to users over the internet. Users do not need to install, update, or maintain the software, as the SaaS provider takes care of these tasks. Examples of SaaS applications are Gmail, Salesforce, and Microsoft Office 365.
- Cloud computing can be deployed in different ways, depending on the level of control, security, and scalability required by the users. The main deployment models are public cloud, private cloud, hybrid cloud, and multi-cloud.
  - Public cloud refers to the use of cloud services offered by a third-party provider over the public internet. Users can access the services on a pay-as-you-go basis, and share the same infrastructure with other users. Public cloud offers the most cost-effective, scalable, and flexible option for cloud computing, but may have less control and security than other models.
  - Private cloud refers to the use of cloud services that are dedicated to a single organization and hosted either on-premises or by a third-party provider. Users can have more control and security over the infrastructure and data, but may incur higher costs and complexity than public cloud.
  - Hybrid cloud refers to the use of both public and private cloud services in a coordinated way, to achieve the optimal balance of cost, performance, and security. Users can move workloads and data between public and private clouds, depending on their needs and policies. Hybrid cloud offers the most flexibility and agility for cloud computing, but may also introduce more challenges in integration and management.
  - Multi-cloud refers to the use of multiple public cloud services from different providers, to leverage the best features and avoid vendor lock-in. Users can choose the best cloud service for each workload and application, and optimize the cost, performance, and reliability of their cloud computing. Multi-cloud requires more expertise and governance to manage the complexity and diversity of the cloud services.
- Cloud computing is widely used for various purposes and applications, such as web hosting, data analytics, artificial intelligence, machine learning, high-performance computing, and more.
- High-performance computing (HPC) is the use of specialized systems and software to process large amounts of data and perform complex calculations at high speed.
- HPC applications are typically compute-intensive, data-intensive, or both, and require high levels of parallelism, scalability, and performance.
- HPC applications are used for various domains and fields, such as scientific research, engineering, simulation, modeling, weather forecasting, genomics, and more.
