### Cloud Computing Components for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Cloud computing is the on-demand availability of computing resources as services over the internet. It eliminates the need for enterprises to procure, configure, or manage resources themselves, and they only pay for what they use.

Cloud computing components are the essential elements that make up a cloud computing system. They include hardware, virtualization, storage, networking, service, application, management, and security components   .

- **Hardware**: Hardware is the physical equipment that provides the computing power, storage capacity, and network connectivity for the cloud. Hardware can be located in multiple geographical locations and can be owned and managed by different service providers .
- **Virtualization**: Virtualization is the technology that separates IT services and functions from hardware. It allows multiple virtual machines to run on a single physical server, sharing its resources. Virtualization also enables the creation of pools of abstracted resources that can be accessed by users as clouds  .
- **Storage**: Storage is the component that stores and manages data in the cloud. Storage can be distributed across multiple disks, arrays, or devices, and can be backed up, indexed, and retrieved as needed. Storage can also be abstracted from hardware and offered as a cloud service, allowing users to scale their storage capacity on demand .
- **Networking**: Networking is the component that connects the hardware, virtualization, storage, service, and application components of the cloud. Networking enables the communication and data transfer between different cloud resources, as well as between the cloud and the users. Networking can also provide security, load balancing, and firewall functions for the cloud .
- **Service**: Service is the component that defines the type and level of cloud computing resources that users can access. There are three main types of cloud computing service models: infrastructure as a service (IaaS), platform as a service (PaaS), and software as a service (SaaS). Each service model offers different degrees of abstraction, control, and responsibility for the users and the providers   .
- **Application**: Application is the component that provides the software or platform that users want to access in the cloud. Applications can be developed, deployed, and run on the cloud, or they can be existing software that is delivered as a service. Applications can also leverage the cloud's scalability, availability, and performance benefits   .
- **Management**: Management is the component that monitors and controls the cloud computing system. Management includes the tools and processes that enable the provisioning, configuration, orchestration, automation, optimization, and governance of cloud resources. Management also ensures the quality of service, performance, and compliance of the cloud  .
- **Security**: Security is the component that protects the cloud computing system from unauthorized access, data breaches, cyberattacks, and other threats. Security includes the policies, procedures, and technologies that ensure the confidentiality, integrity, and availability of cloud resources and data. Security also involves the identification, authentication, and authorization of users and providers  .

A possible mnemonic to remember the cloud computing components is **HAVNSAM** (Hardware, Virtualization, Networking, Storage, Application, Management) or **HAVSAMS** (Hardware, Virtualization, Storage, Application, Management, Security). A possible learning trick is to associate each component with a real-world example, such as:

- Hardware: A laptop, a server, a router, a disk, etc.
- Virtualization: VMware, Hyper-V, KVM, Docker, etc.
- Storage: Dropbox, Google Drive, Amazon S3, etc.
- Networking: Ethernet, Wi-Fi, VPN, TCP/IP, etc.
- Service: AWS, Azure, Google Cloud, etc.
- Application: Gmail, Netflix, Spotify, etc.
- Management: Kubernetes, Ansible, Terraform, etc.
- Security: SSL, encryption, firewall, password, etc.
