## Unit 3 - Overview of Cluster Computing

- Cluster computing is a technique of connecting multiple computers (nodes) via a network to work together as a single system.   
- Cluster computing provides solutions to solve difficult problems by providing faster computational speed, enhanced data integrity, and high availability of resources.  
- Cluster computing can be classified into different types based on the architecture, configuration, and purpose of the clusters, such as:
  - High-performance computing (HPC) clusters: These clusters are designed to achieve high performance and scalability for computationally intensive tasks, such as scientific simulations, machine learning, and big data analytics.  
  - High-availability (HA) clusters: These clusters are designed to provide fault tolerance and reliability for critical applications, such as databases, web servers, and email servers. HA clusters ensure that the failure of one or more nodes does not affect the availability of the service.  
  - Load-balancing clusters: These clusters are designed to distribute the workload among multiple nodes to optimize the resource utilization and performance of the system. Load-balancing clusters can also provide redundancy and failover capabilities for the nodes.  
- Cluster computing relies on a centralized management approach which makes the nodes available as orchestrated shared servers.  
- Cluster computing requires a software layer that sits atop the nodes and allows the users to treat the cluster as by and large one cohesive computing unit, e.g. via a single system image concept.  
- Cluster computing can use different types of network connections and topologies to link the nodes, such as Ethernet, InfiniBand, and Myrinet. The network performance and bandwidth can affect the efficiency and scalability of the cluster.  
- Cluster computing can use different types of hardware and software components to build the nodes, such as personal computers, servers, microprocessors, operating systems, and middleware. The choice of components can depend on the cost, performance, and compatibility of the cluster.  
- Cluster computing can have different types of applications and benefits, such as:
  - Reducing the cost and complexity of building and maintaining a single powerful computer.  
  - Increasing the speed and accuracy of solving complex problems that require parallel processing and distributed computing.  
  - Improving the availability and reliability of the system by providing redundancy and failover mechanisms.  
  - Enhancing the scalability and flexibility of the system by adding or removing nodes as needed.
