### Cloud Computing Architecture for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing architecture refers to the components and subcomponents required for cloud computing.
- These components typically consist of a front end platform (fat client, thin client, mobile), back end platforms (servers, storage), a cloud based delivery, and a network (Internet, Intranet, Intercloud).
- Cloud computing architecture provides higher bandwidth to its users due to which data over the cloud can be used from anywhere across the world at any time.
- Cloud computing architecture also shares resources among client source consumers and with open source communities like Microsoft and Red hat.
- Cloud computing architecture can be divided into two main parts: client platforms and cloud services.

#### Client Platforms

- Client platforms are the front-end platforms that users directly interact with.
- These platforms can be servers, fat (or thick) clients, thin clients, zero clients, tablets, and mobile devices.
- These platforms communicate with the cloud data storage via an application (middleware), a web browser, or a virtual session.
- A virtual session requires a secure encryption algorithm framework that spans the entire interface.
- A zero client is a device that runs entirely via the network and does not have any local storage or operating system.
- A zero client has a single point of failure, which means that if the network goes down, the device is rendered useless.

#### Cloud Services

- Cloud services are the back-end platforms that provide the core functionality of cloud computing.
- These services include storage, servers, databases, software, analytics, and other platforms that are accessible via the internet.
- Cloud services are generally deployed in one of the following configurations: public cloud, private cloud, community cloud, or hybrid cloud.
- A public cloud is a cloud service that is open to the general public and can be accessed by anyone who pays for the service.
- A private cloud is a cloud service that is dedicated to a single organization and can only be accessed by authorized users within that organization.
- A community cloud is a cloud service that is shared by a group of organizations that have common goals or interests.
- A hybrid cloud is a cloud service that combines two or more of the above configurations and allows data and applications to move between them.
- Cloud services can be delivered in different models, such as software as a service (SaaS), platform as a service (PaaS), and infrastructure as a service (IaaS).

##### Software as a Service (SaaS)

- SaaS is a cloud service model that involves the cloud provider installing and maintaining software in the cloud and users running the software from the cloud over the internet or intranet.
- The users do not need to install any application-specific software on their client platforms since cloud applications run in the cloud.
- SaaS is scalable and can be loaded on multiple servers by the system administrators.
- SaaS typically involves a monthly or annual fee.
- SaaS provides the equivalent of installed applications in the traditional (non-cloud computing) delivery of applications.
- SaaS has four common approaches: single instance, multi-instance, multi-tenant, and flex tenancy.
- A single instance SaaS is a SaaS that runs a single instance of the software for each customer.
- A multi-instance SaaS is a SaaS that runs multiple instances of the software for different customers.
- A multi-tenant SaaS is a SaaS that runs a single instance of the software for multiple customers and partitions the data and configuration for each customer.
- A flex tenancy SaaS is a SaaS that allows customers to choose between single instance, multi-instance, or multi-tenant options.
- A flex tenancy SaaS is considered the most user adaptive SaaS paradigm in designated multi-input four way manifold models.
- A flex tenancy SaaS is based on simplified encryption methods that target listed data sequences over multiple passes.
- A flex tenancy SaaS is popular among those without informatics processing experience, such as basic maintenance and custodial staff in franchise businesses.
