### Cluster Systems for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

- Cluster systems are a type of high performance computing (HPC) architecture that use multiple computer servers or nodes connected by a high-speed network to perform parallel computations.
- Cluster systems can offer several advantages over traditional supercomputers, such as lower cost, higher scalability, better fault tolerance, and easier maintenance.
- Cluster systems consist of the following components  :
  - A cluster provisioner that ensures node homogeneity and manages the installation and configuration of the cluster software and hardware.
  - Servers or nodes that perform the computations. Nodes can use either multi-core CPUs or GPUs for processing. Nodes can be homogeneous or heterogeneous in terms of hardware and software specifications.
  - A scheduler that queues up workloads against the cluster resources and allocates tasks to nodes based on availability and performance criteria.
  - A network for communication between nodes. The network can use different topologies and protocols depending on the cluster size and the communication requirements of the applications. The network should be high-speed, high-throughput, and low-latency to avoid bottlenecks and performance degradation.
  - A general-purpose storage solution used to store applications and user data. The storage can be local or remote, and can use different technologies such as hard disks, solid state drives, or tape drives. The storage should be reliable, secure, and accessible by all nodes.
  - A high-speed, low-latency clustered file system generally used for computational storage. The file system allows multiple nodes to access the same data concurrently and provides consistency, coherence, and fault tolerance. Examples of clustered file systems are Lustre, GPFS, and HDFS.
- Cluster systems can be classified into different types based on the application domain, the hardware configuration, the software environment, or the network topology. Some examples of cluster types are:
  - Beowulf clusters: These are clusters that use commodity hardware and open source software to provide a low-cost and flexible HPC solution. Beowulf clusters are typically used for scientific and engineering applications that require high CPU performance and moderate network bandwidth.
  - GPU clusters: These are clusters that use graphics processing units (GPUs) as the main processing units. GPUs are specialized hardware devices that can perform parallel computations faster than CPUs for certain types of problems, such as machine learning, image processing, and computer graphics. GPU clusters require specialized software frameworks and libraries to exploit the GPU capabilities, such as CUDA, OpenCL, and TensorFlow.
  - Grid clusters: These are clusters that span multiple geographic locations and administrative domains. Grid clusters enable the sharing of distributed resources among different organizations and users. Grid clusters require middleware software that provides security, authentication, resource discovery, and job scheduling. Examples of grid clusters are the European Grid Infrastructure (EGI) and the Open Science Grid (OSG).
  - Cloud clusters: These are clusters that are hosted and managed by a cloud service provider. Cloud clusters offer on-demand access to HPC resources without the need to own or maintain the hardware and software. Cloud clusters can scale up or down depending on the workload and the budget. Examples of cloud clusters are Amazon EC2, Google Compute Engine, and Microsoft Azure.

- A possible mnemonic to remember the components of a cluster system is **P**rovisioner, **S**ervers, **S**cheduler, **N**etwork, **S**torage, and **F**ile system, or **PSSNSF**. A possible sentence to remember this mnemonic is: **P**lease **S**end **S**ome **N**ice **S**nacks and **F**ruits.
