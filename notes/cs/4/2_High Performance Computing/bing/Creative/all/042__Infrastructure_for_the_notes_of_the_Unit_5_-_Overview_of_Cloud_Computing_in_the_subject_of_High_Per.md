### Infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing is the delivery of computing services over the Internet, such as servers, storage, databases, networking, software, analytics, and intelligence.
- Cloud infrastructure is the collection of hardware and software components needed to enable cloud computing, such as computing power, networking, storage, and an interface .
- Cloud infrastructure can be classified into three types: public, private, and hybrid.
  - Public cloud: The cloud services are provided by a third-party provider over the Internet and are available to anyone who wants to use them. The provider owns and manages the cloud infrastructure and resources. Examples of public cloud providers are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).
  - Private cloud: The cloud services are provided by an organization for its own use and are not accessible to others. The organization owns and manages the cloud infrastructure and resources, or outsources them to a third-party provider. Examples of private cloud platforms are VMware, OpenStack, and Red Hat OpenShift.
  - Hybrid cloud: The cloud services are a combination of public and private clouds, with some degree of integration and orchestration between them. The organization can use the public cloud for some services and the private cloud for others, depending on the cost, performance, security, and compliance requirements. Examples of hybrid cloud solutions are AWS Outposts, Azure Arc, and Google Anthos.
- Cloud infrastructure relies on four main components: hardware, virtualization, storage, and network.
  - Hardware: The physical devices that provide the computing power, memory, disk space, and network connectivity for the cloud services. The hardware can be located in one or more data centers, which are facilities that house the servers, storage arrays, backup devices, and networking equipment. The hardware can be owned by the cloud provider or the cloud user, depending on the type of cloud.
  - Virtualization: The technology that separates the IT functions and services from the hardware that supports them. A software layer called a hypervisor runs on top of the hardware and creates virtual machines (VMs), which are isolated instances of operating systems and applications that share the same physical resources. The hypervisor also manages the allocation and distribution of the resources among the VMs. Virtualization enables the cloud to offer self-service, scalability, and elasticity of the resources.
  - Storage: The technology that stores and manages the data used by the cloud services. The data can be stored on disks, tapes, or other media, and can be organized in different ways, such as file systems, databases, or object storage. The storage can be local or remote, depending on the location of the data relative to the hardware. The storage can also be abstracted from the hardware by using virtualization, which allows the cloud to offer cloud storage services, such as Amazon S3, Azure Blob Storage, and Google Cloud Storage.
  - Network: The technology that connects the hardware, the virtual machines, the storage, and the users of the cloud services. The network can use different protocols, such as TCP/IP, HTTP, or HTTPS, and different technologies, such as Ethernet, Wi-Fi, or VPN. The network can also be abstracted from the hardware by using virtualization, which allows the cloud to offer cloud networking services, such as Amazon VPC, Azure Virtual Network, and Google Cloud VPC.
- Cloud infrastructure can offer several benefits over traditional IT infrastructure, such as:
  - Cost: Cloud computing eliminates the capital expense of buying and maintaining hardware and software, and reduces the operating costs of power, cooling, and IT staff. The cloud users only pay for the resources they use, and can benefit from the economies of scale of the cloud providers.
  - Speed: Cloud computing provides on-demand and self-service access to the resources, which can be provisioned in minutes with a few clicks. The cloud users can also scale up or down the resources as needed, without having to worry about capacity planning or resource allocation.
  - Global scale: Cloud computing leverages the worldwide network of data centers of the cloud providers, which can offer high availability, performance, and redundancy of the resources. The cloud users can also choose the geographic location of the resources to optimize the latency, compliance, and disaster recovery of the services.
