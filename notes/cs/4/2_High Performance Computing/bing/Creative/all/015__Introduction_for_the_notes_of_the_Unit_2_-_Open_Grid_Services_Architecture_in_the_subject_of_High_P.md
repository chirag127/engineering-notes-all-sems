### Introduction for the notes of the Unit 2 - Open Grid Services Architecture in the subject of High Performance Computing

- Open Grid Services Architecture (OGSA) is a service-oriented architecture for a grid computing environment for business and scientific use. 
- Grid computing is the use of a large number of computers, often geographically distributed and heterogeneous, to perform coordinated tasks that require a high level of parallelism or collaboration. 
- OGSA was developed within the Open Grid Forum (OGF), formerly known as the Global Grid Forum (GGF), around 2002 to 2006. 
- OGSA aims to provide a common framework for distributed system integration, virtualization, and management, based on the concept of services. 
- Services are software components that expose their functionality through well-defined interfaces and that can be accessed over a network using standard protocols. 
- OGSA is based on several other Web service technologies, such as the Web Services Description Language (WSDL) and the Simple Object Access Protocol (SOAP), but it is largely independent of the transport-level handling of data. 
- OGSA defines a core set of interfaces, behaviors, resource models, and bindings that enable interoperability and resource sharing across heterogeneous and dynamic environments. 
- OGSA also defines a set of capabilities that address key concerns in grid systems, such as execution management, data services, resource management, security, self-management, and information. 
- OGSA is not a specific implementation or a product, but rather an architectural process and a set of normative specifications and profiles that document the precise requirements for a conforming hardware or software component. 
- OGSA is intended to support grid applications and systems in both e-science and e-business domains, by providing a common platform for developing, deploying, and managing distributed services and resources.
