### Cluster Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Cluster computing is a form of distributed computing that involves a group of computers (called nodes) that work together as a single system.    
- Cluster computing provides solutions to solve difficult problems by providing faster computational speed, enhanced data integrity, high availability, load balancing and parallel processing.   
- Cluster computing can be classified into two types: loosely coupled and tightly coupled.  
  - Loosely coupled clusters are composed of independent nodes that communicate over a network and have their own memory and storage.  
  - Tightly coupled clusters are composed of nodes that share memory and storage and communicate over a high-speed interconnect.  
- Cluster computing can be used for various applications, such as high-performance computing, scientific computing, web hosting, data analysis, database management, etc.   
- Cluster computing requires clustering middleware, a software layer that orchestrates the activities of the nodes and allows the users to treat the cluster as a single system.  
- Cluster computing has some advantages and disadvantages, such as:   
  - Advantages:
    - Cost-effective: Cluster computing can use low-cost commercial off-the-shelf computers and leverage their combined power.   
    - Scalable: Cluster computing can easily add or remove nodes to adjust to the workload and performance requirements.   
    - Reliable: Cluster computing can tolerate failures of individual nodes and continue to operate without interruption.   
    - Flexible: Cluster computing can support different operating systems, hardware and software configurations, and applications.   
  - Disadvantages:
    - Complex: Cluster computing requires sophisticated software and network infrastructure to manage the coordination and communication among the nodes.   
    - Overhead: Cluster computing introduces some overhead in terms of network latency, synchronization, load balancing, and fault tolerance.   
    - Security: Cluster computing exposes the nodes to potential attacks from the network and requires proper encryption and authentication mechanisms.   

- A simple mnemonic to remember the advantages of cluster computing is **C**ost-effective, **S**calable, **R**eliable, and **F**lexible, or **CSRF**. 
- A simple mnemonic to remember the disadvantages of cluster computing is **C**omplex, **O**verhead, and **S**ecurity, or **COS**.
