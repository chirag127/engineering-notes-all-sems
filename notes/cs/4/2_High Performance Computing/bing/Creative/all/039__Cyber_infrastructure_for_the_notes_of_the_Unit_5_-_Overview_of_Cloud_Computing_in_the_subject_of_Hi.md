### Cyber infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cyber infrastructure is a term that refers to the collection of components and elements that enable cloud computing, such as computing power, networking, storage, and an interface that allows users to access virtualized resources.
- Cloud computing is the process of delivering services, software, and databases over the Internet, without requiring local hardware or infrastructure. Cloud computing provides flexibility, scalability, agility, and cost savings for organizations that need to manage and process large amounts of data.
- Cloud computing can be categorized into three main service models: IaaS (Infrastructure-as-a-Service), PaaS (Platform-as-a-Service), and SaaS (Software-as-a-Service). Each model provides different levels of abstraction and control over the cloud resources.
  - IaaS: The cloud provider offers servers, hardware, networking, virtualization, and storage as a service. The user can rent and manage these resources according to their needs, while the provider handles the maintenance and security of the infrastructure. Examples of IaaS providers are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).
  - PaaS: The cloud provider offers a platform that includes operating systems, software updates, storage, and supporting infrastructure as a service. The user can develop and deploy applications using the platform, without worrying about the underlying infrastructure. Examples of PaaS providers are Heroku, Google App Engine, and AWS Elastic Beanstalk.
  - SaaS: The cloud provider offers software applications that are hosted online and accessible via a web browser or an API as a service. The user can subscribe and use these applications, without installing or maintaining them. Examples of SaaS providers are Gmail, Salesforce, and Dropbox.
- Cloud computing can also be classified into four main deployment models: public cloud, private cloud, hybrid cloud, and multi-cloud. Each model defines the ownership, location, and accessibility of the cloud resources.
  - Public cloud: The cloud provider owns and operates the cloud infrastructure, which is shared among multiple users over the Internet. The user can access the cloud services on demand, and pay only for the resources they use. Public clouds offer high scalability, availability, and cost-effectiveness, but may have less control and security over the data and applications. Examples of public cloud providers are AWS, Azure, and GCP.
  - Private cloud: The cloud infrastructure is owned and operated by a single organization, which can be located on-premise or off-premise. The user can access the cloud services via a private network, and have more control and security over the data and applications. Private clouds offer high performance, reliability, and customization, but may have less scalability, availability, and cost-effectiveness. Examples of private cloud providers are VMware, OpenStack, and IBM Cloud Private.
  - Hybrid cloud: The cloud infrastructure is a combination of public and private clouds, which are connected by a common network or technology. The user can leverage the benefits of both models, and move the data and applications between them according to their needs. Hybrid clouds offer high flexibility, interoperability, and optimization, but may have more complexity and management challenges. Examples of hybrid cloud providers are AWS Outposts, Azure Arc, and Google Anthos.
  - Multi-cloud: The cloud infrastructure is a combination of multiple public clouds, which are used for different purposes or workloads. The user can choose the best cloud service for each task, and avoid vendor lock-in or service disruption. Multi-clouds offer high diversity, redundancy, and innovation, but may have more integration and governance issues. Examples of multi-cloud providers are Cloudflare, HashiCorp, and IBM Cloud Pak.

- Cybersecurity is a critical aspect of cloud computing, as it involves protecting the data and infrastructure from external and internal threats. Cybersecurity in cloud computing requires a multi-faceted approach, which includes user access and privileges, hardware and software security, virtualization, firewalls, and other processes and technologies  .
  - User access and privileges: The cloud provider and the user should implement policies and mechanisms to control who can access the cloud resources, and what they can do with them. This includes authentication, authorization, encryption, auditing, and monitoring of the user activities and data. Examples of user access and privileges tools are AWS Identity and Access Management (IAM), Azure Active Directory (AD), and Google Cloud Identity and Access Management (IAM).
