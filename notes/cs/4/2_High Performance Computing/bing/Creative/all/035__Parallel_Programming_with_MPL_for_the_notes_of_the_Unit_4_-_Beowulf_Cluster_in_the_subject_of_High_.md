### Parallel Programming with MPL for the notes of the Unit 4 - Beowulf Cluster in the subject of High Performance Computing

- MPL stands for **MaPLe**, which is a compiler for **Parallel ML**, a language that extends **Standard ML** with features for parallel programming on shared-memory multicore machines .
- MPL supports **nested fork-join parallelism**, which allows the creation of parallel tasks inside other parallel tasks, and synchronizes them at join points .
- MPL uses a novel approach to **memory management** based on the theory of **disentanglement**, which avoids copying, locking, or garbage collection of shared data structures.
- MPL can generate executables with **excellent multicore performance** and **scalability**, as well as **deterministic** and **type-safe** semantics.
- MPL is compatible with the **MLton** compiler, which is a whole-program optimizing compiler for Standard ML.
- MPL can be used with the **mpllib** package, which provides a library of parallel data structures and algorithms, such as sequences, trees, sorting, and graph traversal.
- MPL can be learned through the **mpl-tutorial** repository, which contains source code and instructions for various examples of parallel programming with MPL.
- MPL can be integrated with **Visual Studio** and **.NET**, which provide tools and frameworks for parallel programming, such as the **Task Parallel Library (TPL)**, **Parallel LINQ (PLINQ)**, and **Parallel Diagnostic Tools**.
- MPL can be applied to various domains that require high-performance computing, such as scientific computing, machine learning, data analysis, and image processing.

Some mnemonics and learning tricks for MPL are:

- MPL = **M**ulticore **P**arallel **L**anguage
- MPL = **M**a**P****L**e = **M**ap and **P**arallelize with **L**ess effort
- MPL = **M**L + **P**arallelism
- Disentanglement = **Dis**-**entangle**-**ment** = **Dis**connect **entangle**d data structures with **ment**al clarity
- Fork-join parallelism = **Fork** a task into subtasks and **join** them at the end
- MLton = **ML** + **ton** = **ML** with a **ton** of optimizations
- mpllib = **mpl** + **lib** = **mpl** **lib**rary
- mpl-tutorial = **mpl** + **tutorial** = **mpl** **tutorial**
