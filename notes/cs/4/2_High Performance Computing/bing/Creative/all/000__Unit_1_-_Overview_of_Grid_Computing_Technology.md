## Unit 1 - Overview of Grid Computing Technology

- Grid computing is the use of widely distributed computer resources to reach a common goal. 
- A computing grid can be thought of as a distributed system with non-interactive workloads that involve many files. 
- Grid computing is distinguished from conventional high-performance computing systems such as cluster computing in that grid computers have each node set to perform a different task/application. 
- Grid computers also tend to be more heterogeneous and geographically dispersed (thus not physically coupled) than cluster computers. 
- Grid computing can be used for various purposes, such as scientific, mathematical, academic, commercial, and web applications. 
- Grid computing can leverage the power of many computers to perform large tasks, such as analyzing huge sets of data or weather modeling. 
- Grid computing can also save time and money by using existing resources and paying only for what is used. 
- Grid computing can be accessed through the cloud, which provides a platform for assembling and using vast computer grids. 
- Grid computing is a special type of parallel computing that relies on complete computers (with onboard CPUs, storage, power supplies, network interfaces, etc.) connected to a network (private, public or the Internet) by a conventional network interface producing commodity hardware. 
- Grid computing is different from parallel computing in that parallel computing requires a high degree of coordination and communication among processors, while grid computing allows for more autonomy and heterogeneity of the participating nodes. 
- Grid computing projects typically have no time dependency associated with them. They use computers that are part of the grid only when idle, and operators can perform tasks unrelated to the grid at any time. 
- Grid computing requires security and redundancy measures, as the controls on member nodes are usually very loose and many computers may disconnect or fail during processing. 
- Grid computing can be coordinated by grid middleware software libraries, which provide the necessary functions and protocols for resource discovery, allocation, scheduling, monitoring, and communication. 
- Grid computing can be classified into different types, such as computational grids, data grids, service grids, and cloud grids, depending on the nature and purpose of the resources and applications involved.
