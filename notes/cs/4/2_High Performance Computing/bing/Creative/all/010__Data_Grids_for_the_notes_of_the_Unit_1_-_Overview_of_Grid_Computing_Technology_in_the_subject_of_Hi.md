### Data Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

- Data grids are a type of grid computing that split data onto multiple computers or storage devices that are connected by a network .
- Data grids enable placing data onto a network of computers or storage devices, but the grid virtually treats them as one despite the splitting.
- Data grids provide the computing capacity of interconnected computers to evaluate, display, transmit, share, or analyze large amounts of data via grid nodes.
- Data grids can also be used as a large data store, where each site in a grid might store data that is owned by that site, but the coordinated sharing of all data across all grid users promotes collaboration and increased knowledge transfer.
- Data grids can also be used as the basis for private clouds, in which computers are pooled together and then a subset of the resources of that pool is dedicated to various users via virtual machines.
- Data grids work by running specialized software on every computer that participates in the grid. The software acts as the manager of the entire system and coordinates various tasks across the grid.
- The software assigns subtasks to each computer so they can work simultaneously on their respective subtasks. After the completion of subtasks, the outputs are gathered and aggregated to complete a larger-scale task.
- The software lets each computer communicate over the network with the other computers so they can share information on what portion of the subtasks each computer is running, and how to consolidate and deliver outputs.
- A specific type of data grid is an in-memory data grid (IMDG) which, as the name implies, runs processing in the computers’ main memory, e.g., random-access memory (RAM).
- The advantage of IMDG is that the data is stored in memory across all the computers in the grid, so data access is extremely fast.

#### Mnemonics and learning tricks

- To remember the definition of data grids, you can use the acronym **SPLIT**:

  - **S**plit data onto multiple computers or storage devices
  - **P**rovide computing capacity to process large amounts of data
  - **L**ink computers by a network and treat them as one
  - **I**ntegrate outputs from subtasks to complete a larger task
  - **T**ransmit and share data across all grid users

- To remember the types of data grids, you can use the acronym **DIK**:

  - **D**ata grids: split data onto multiple computers or storage devices
  - **I**n-memory data grids: store data in memory across all computers in the grid
  - **K**nowledge grids: scan, connect, collect, evaluate, or structure large data sets and knowledge bases
