### Internet Computing

- Internet computing is the use of the Internet as a platform for delivering applications and services to users. 
- Internet computing enables users to access various resources and capabilities over the network, such as data, software, hardware, and processing power. 
- Internet computing can be seen as a form of distributed computing, where multiple computers cooperate to perform a common task or achieve a shared goal. 
- Internet computing can also be seen as a form of cloud computing, where users can access scalable and elastic services on demand, without having to own or manage the underlying infrastructure. 

### Grid Computing Technology

- Grid computing technology is a subset of distributed computing, where a virtual supercomputer comprises machines on a network connected by some bus, mostly Ethernet or sometimes the Internet.  
- Grid computing technology can also be seen as a form of parallel computing, where instead of many CPU cores on a single machine, it contains multiple cores spread across various locations. 
- Grid computing technology allows computers to share resources, such as processing power, network bandwidth, and storage capacity, to perform operations requiring high computational power.  
- Grid computing technology operates by running specialized software on every computer involved in the grid network. The software coordinates and manages all the tasks of the grid. 
- Grid computing technology can be used for various applications, such as scientific computing, data analysis, simulation, and optimization.
