### High Performance Computing

- High performance computing (HPC) is a class of applications and workloads that solve computationally intensive tasks using supercomputers and computer clusters .
- HPC integrates systems administration, parallel programming, digital electronics, computer architecture, system software, programming languages, algorithms and computational techniques into a multidisciplinary field.
- HPC systems typically perform at speeds more than one million times faster than the fastest commodity desktop, laptop or server systems.
- HPC workloads uncover important new insights that advance human knowledge and create significant competitive advantage in various domains, such as scientific research, engineering, business, artificial intelligence, and big data .
- HPC leverages massively parallel computing, which runs multiple tasks simultaneously on multiple computer servers or processors.
- HPC clusters consist of multiple high-speed computer servers networked together, with a centralized scheduler that manages the parallel computing workload.
- HPC clusters use either high-performance multi-core CPUs or GPUs, which are well suited for rigorous mathematical calculations, machine learning models and graphics-intensive tasks.
- HPC clusters also require high-performance components for networking, memory, storage and file systems that can keep pace with the nodes and optimize the computing power and performance of the cluster.
- HPC in the cloud offers a significantly faster, more scalable and more affordable way for companies to take advantage of HPC, without the need to own or lease a supercomputer or build and host an HPC cluster in an on-premises data center.
