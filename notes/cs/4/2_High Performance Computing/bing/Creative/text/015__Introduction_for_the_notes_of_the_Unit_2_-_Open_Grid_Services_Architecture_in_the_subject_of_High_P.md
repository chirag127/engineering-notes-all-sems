### Introduction

- Open Grid Services Architecture (OGSA) is a service-oriented architecture for a grid computing environment for business and scientific use. 
- Grid computing is the use of distributed and heterogeneous resources to solve large-scale problems that require high performance, availability, or scalability. 
- OGSA aims to provide interoperability, resource sharing, optimization, quality of service, security, and self-management capabilities for grid systems and applications. 
- OGSA is based on several other Web service technologies, such as the Web Services Description Language (WSDL) and the Simple Object Access Protocol (SOAP), but it is largely independent of the transport-level handling of data. 
- OGSA defines a core set of interfaces, behaviors, resource models, and bindings for grid services, which are the basic components of OGSA. 
- OGSA also defines a set of functional capabilities that address key concerns in grid systems, such as execution management, data, resource management, security, self-management, and information. 
- OGSA was developed within the Open Grid Forum, which was called the Global Grid Forum (GGF) at the time, around 2002 to 2006. 
- OGSA is an ongoing architectural process that collects requirements and maintains a set of informational documents and normative specifications for grid standards.
