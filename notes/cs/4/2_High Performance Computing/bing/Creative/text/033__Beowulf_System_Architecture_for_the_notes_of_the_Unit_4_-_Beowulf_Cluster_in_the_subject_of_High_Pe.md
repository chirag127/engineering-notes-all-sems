### Beowulf System Architecture

- Beowulf is a multi-computer architecture which can be used for parallel computations. 
- It is a system which usually consists of one server node, and one or more client nodes connected via Ethernet or some other network. 
- The server node acts as the master node that controls the execution of parallel programs on the client nodes, which are also called slave or worker nodes. 
- The client nodes are typically identical, commodity-grade computers that share processing, memory, disk, and network resources. 
- The nodes run a Unix-like operating system, such as Linux, and use parallel processing libraries, such as MPI or PVM, to communicate and synchronize with each other. 
- The Beowulf system architecture provides a high-performance parallel computing cluster from inexpensive personal computer hardware. 
- The name Beowulf comes from the Old English epic poem of the same name. 
- The original Beowulf cluster was built in 1994 by Thomas Sterling and Donald Becker at NASA. 
- The cluster comprised 16 white box desktops each running a i486 DX4 processor clocked at 100 MHz, each containing a 500 MB hard disk drive, and each having 16 MB of RAM between them, leading to a total of roughly 8 GB of fixed disk storage and 256 MB of RAM shared within the cluster and a performance benchmark of 500 M FLOPS. 
- Beowulf systems operate worldwide, chiefly in support of scientific computing. 
- Since 2017, every system on the Top500 list of the world's fastest supercomputers has used Beowulf software methods and a Linux operating system. 
- The Beowulf's architecture can also be extended to a decentralized communication and data network by utilizing computing resources globally to form a supercomputer network. 
- Combining with blockchain for a payment system, Beowulf brings in transparency for all users and miners of the network.
