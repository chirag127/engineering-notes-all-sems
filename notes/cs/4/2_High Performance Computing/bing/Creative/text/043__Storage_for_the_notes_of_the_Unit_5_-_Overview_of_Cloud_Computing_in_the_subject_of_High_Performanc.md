### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud storage is a cloud computing model that enables storing data and files on the internet through a cloud computing provider that you access either through the public internet or a dedicated private network connection.
- The provider securely stores, manages, and maintains the storage servers, infrastructure, and network to ensure you have access to the data when you need it at virtually unlimited scale, and with elastic capacity.
- Cloud storage removes the need to buy and manage your own data storage infrastructure, giving you agility, scalability, and durability, with any time, anywhere data access.
- Cloud storage delivers cost-effective, scalable storage. You no longer need to worry about running out of capacity, maintaining storage area networks (SANs), replacing failed devices, adding infrastructure to scale up with demand, or operating underutilized hardware when demand decreases.
- Cloud storage is elastic, meaning you scale up and down with demand and pay only for what you use. It is a way for organizations to save data securely online so that it can be accessed anytime from any location by those with permission.
- Cloud storage offers different storage classes for different use cases, such as standard, nearline, coldline, and archive storage options.
- Cloud storage also provides features like automatic storage class transitions, continental-scale and SLA-backed replication, fast and flexible transfer services, default and configurable data security, and integration with leading analytics and ML/AI tools.
- Cloud storage can be used for various purposes, such as data backup and recovery, data archiving, data analytics, data sharing and collaboration, content delivery, and application development.
- Cloud storage can be classified into three main types: public cloud storage, private cloud storage, and hybrid cloud storage.
  - Public cloud storage is the most common type of cloud storage, where the data is stored on the servers of a third-party provider that offers storage services to the public over the internet.
  - Private cloud storage is the type of cloud storage where the data is stored on the servers of a dedicated provider that offers storage services to a specific organization over a private network.
  - Hybrid cloud storage is the type of cloud storage that combines the features of both public and private cloud storage, where the data is stored on the servers of both a third-party provider and a dedicated provider, and can be moved between them depending on the performance, security, and cost requirements.
- Cloud storage has many benefits, such as reduced cost, increased agility, improved scalability, enhanced security, and easy accessibility.
- Cloud storage also has some challenges, such as data privacy, data sovereignty, data availability, data migration, and data integration.
