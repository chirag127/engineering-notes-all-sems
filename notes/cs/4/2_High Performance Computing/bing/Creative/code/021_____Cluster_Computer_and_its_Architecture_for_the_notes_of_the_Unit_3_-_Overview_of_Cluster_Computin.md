### Cluster Computer and its Architecture

- A cluster computer is a set of connected computers that work together as a single system   .
- The connected computers are called nodes, and they can be personal computers, workstations, servers, or supercomputers  .
- A cluster computer can enhance the processing power, reliability, availability, scalability, or performance of a system  .
- A cluster computer can be used for various applications, such as high-performance computing, scientific computing, web hosting, data analysis, load balancing, or fault tolerance  .
- A cluster computer has a specific architecture that consists of the following components :
  - Nodes: The basic units of computation that execute tasks and communicate with each other.
  - Interconnects: The network devices and protocols that connect the nodes and enable data transfer and synchronization.
  - Middleware: The software layer that provides common services and functions for the nodes, such as scheduling, load balancing, fault tolerance, security, or parallel programming.
  - Applications: The software programs that run on the cluster and utilize its resources and capabilities.
- A cluster computer can be classified into different types based on the following criteria :
  - Hardware configuration: The physical arrangement and specification of the nodes and interconnects, such as symmetric or asymmetric, homogeneous or heterogeneous, dedicated or non-dedicated, etc.
  - Software configuration: The operating system and middleware that run on the nodes and interconnects, such as Linux, Windows, MPI, PVM, etc.
  - Deployment purpose: The main objective and function of the cluster, such as high-availability, high-performance, load-balancing, etc.
  - Application domain: The specific field or area that the cluster is designed for, such as scientific computing, web hosting, data analysis, etc.
