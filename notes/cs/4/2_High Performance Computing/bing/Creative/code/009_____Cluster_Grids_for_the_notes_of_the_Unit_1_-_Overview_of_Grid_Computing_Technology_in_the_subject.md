### Cluster Grids

- Cluster grids are a type of grid computing that involves a group of computers that are connected by a local area network (LAN) and have the same hardware and software configuration .
- Cluster grids are tightly coupled, meaning that the nodes communicate frequently and share a common memory and file system.
- Cluster grids are usually designed for high performance computing (HPC) applications that require a large amount of processing power and data transfer.
- Cluster grids can be classified into different types based on their architecture, such as symmetric multiprocessing (SMP), massively parallel processing (MPP), and distributed shared memory (DSM) clusters.
- Cluster grids can also be classified based on their functionality, such as load balancing, high availability, and high throughput clusters.
- Cluster grids have some advantages over other types of grid computing, such as lower latency, higher reliability, and easier management.
- Cluster grids also have some disadvantages, such as higher cost, lower scalability, and limited heterogeneity.
