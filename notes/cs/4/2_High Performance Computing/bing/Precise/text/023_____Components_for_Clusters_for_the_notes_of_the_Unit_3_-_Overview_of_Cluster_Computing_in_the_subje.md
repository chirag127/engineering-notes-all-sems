### Components for Clusters

- A cluster provisioner that ensures node homogeneity.
- Servers, often referred to as nodes.
- A scheduler that queues up workloads against the cluster resources.
- A network for communication between nodes.
- A general-purpose storage solution used to store applications and user data.
- A high-speed, low-latency clustered file system generally used for computational storage.
- Compute notes are the processing component of an HPC cluster. They execute the workload using local resources, like CPU, GPU, FPGA and other processing units. These workloads also use other resources on the compute node for processing, such as the memory, storage and network adapter.
- Clusters are composed of queue managers, cluster repositories, cluster channels, and cluster queues.
