### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

1. Cloud Computing is defined as storing and accessing data and computing services over the internet.
2. It doesn’t store any data on your personal computer.
3. It is the on-demand availability of computer services like servers, data storage, networking, databases, etc.
4. Cloud computing can be used for the storage of files.
5. It helps you automatically synchronize the files from different devices like desktop, tablet, mobile, etc.
6. The cloud storage is a computer data storage model in which the data that is digital in format is stored, and hence it is said to be on the cloud, in logical pools.
7. This physical storage consists of multiple servers which can be located in the different parts of the country or may be in different parts of the world depends on many factors.
8. Cloud computing is a model for enabling convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.
9. There are different types of cloud computing such as Public Cloud, Private Cloud, and Community Cloud.
10. To store a file in this architecture, HDFS splits the file into fixed-size blocks (e.g., 64 MB) and stores them on workers (DataNodes).
11. The NameNode (master) also manages the file system’s metadata and namespace.
