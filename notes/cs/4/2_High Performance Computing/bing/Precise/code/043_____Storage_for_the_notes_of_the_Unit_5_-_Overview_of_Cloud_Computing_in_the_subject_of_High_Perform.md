### Unit 5 - Overview of Cloud Computing: Storage

1. Cloud storage is a model of computer data storage in which the digital data is stored in logical pools.
2. The physical storage spans multiple servers and the physical environment is typically owned and managed by a hosting company.
3. These cloud storage providers are responsible for keeping the data available and accessible, and the physical environment protected and running.
4. People and organizations buy or lease storage capacity from the providers to store user, organization, or application data.
5. Cloud storage services may be accessed through a co-located cloud computing service, a web service application programming interface (API) or by applications that utilize the API, such as cloud desktop storage, a cloud storage gateway or Web-based content management systems.
6. Cloud storage can provide the benefits of greater accessibility and reliability, rapid deployment, strong protection for data backup, archival and disaster recovery purposes, and lower overall storage costs as a result of not having to purchase, manage and maintain expensive hardware.
7. There are many types of cloud storage, including public cloud storage, private cloud storage, hybrid cloud storage, and multi-cloud storage.
8. Public cloud storage is where the enterprise and storage service provider are separate and the data is stored outside of the enterprise's data center.
9. Private cloud storage is where the enterprise and cloud storage provider are integrated within the enterprise's data center.
10. Hybrid cloud storage is a combination of public and private cloud storage where some critical data resides in the enterprise's private cloud while other data is stored and accessible from a public cloud storage provider.
11. Multi-cloud storage is where an enterprise uses more than one cloud service, often from more than one cloud vendor, to store its data.
