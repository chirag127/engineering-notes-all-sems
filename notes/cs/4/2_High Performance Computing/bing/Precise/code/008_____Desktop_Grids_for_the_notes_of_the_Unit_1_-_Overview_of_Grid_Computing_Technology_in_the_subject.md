### Desktop Grids

- Desktop Grids are a type of grid computing that yokes together underutilized computational resources into a high-power virtual computing resource .
- Grid computing is distinguished from conventional high-performance computing systems such as cluster computing in that grid computers have each node set to perform a different task/application .
- Grid computers also tend to be more heterogeneous and geographically dispersed (thus not physically coupled) than cluster computers .
- Grid systems are highly efficient at tasks that require high computing power, as all the connected computers pool their processing power, storage, and other capabilities together over the network .
- Some experts classify grid computing as a subcategory of distributed computing .
- The Desktop Grid as a Service concept is aimed at adoption of the best practices in Cloud Computing to use with high-throughput computing based on Desktop Grid .
- Through the cloud, you can assemble and use vast computer grids for specific time periods and purposes, paying, if necessary, only for what you use to save both the time and expense of owning and maintaining your own infrastructure .
- Desktop grids are easy to install on a large number of personal computers, which is a prerequisite for the spread of grid technology .
- Current desktop grids connect all PCs into a flat hierarchy, that is, all computers to a central server .
