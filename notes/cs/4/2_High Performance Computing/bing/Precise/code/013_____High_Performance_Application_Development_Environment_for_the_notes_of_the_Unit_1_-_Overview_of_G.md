### High Performance Application Development Environment

- A High Performance Application Development Environment is a crucial system that connects users’ applications to supercomputers, and provides usability, efficiency, sharing, and collaboration capabilities.
- Grid computing is a dynamic technology trend that has set up high performance computing in several scientific environments.
- In theory, a grid can harness the power of an arbitrarily large collection of computing resources to meet the needs of compute intensive high performance computing (HPC) applications such as finite element model (FEM) simulations.
- Most existing Grid application development environments provide the application developer with a non-transparent Grid.
- Performance analysis supports automatic instrumentation and bottleneck detection (e.g. excessive synchronization, communication).
