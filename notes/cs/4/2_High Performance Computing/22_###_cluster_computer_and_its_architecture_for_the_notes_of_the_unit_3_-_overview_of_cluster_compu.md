### Cluster Computer and its Architecture for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing
Cluster computing is a type of parallel computing that involves grouping multiple interconnected computers to work together as a single system. The architecture of a cluster computer consists of several nodes, which are individual computers connected by a high-speed network. Each node has its own processing power, memory, and storage, and the nodes work together to solve complex problems.

The main components of a cluster computer architecture are:

1. Nodes: individual computers that make up the cluster
2. Network: high-speed interconnect that connects the nodes
3. Cluster Management Software: software that manages the allocation of tasks to nodes and monitors the health of the cluster
4. Job Scheduler: software that manages the execution of tasks on the nodes
5. Load Balancer: software that distributes tasks evenly across the nodes to ensure optimal performance.

In a cluster computer, tasks are divided into smaller subtasks, which are then assigned to individual nodes for processing. The results of these subtasks are then combined to produce the final result. This allows for much greater processing power and faster completion of tasks compared to a single computer.

Cluster computing is commonly used in high-performance computing applications, such as scientific simulations, data analysis, and large-scale database processing. It is also used in many other fields, such as finance, engineering, and media production.
