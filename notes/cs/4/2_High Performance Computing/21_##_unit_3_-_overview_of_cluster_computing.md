## Unit 3 - Overview of Cluster Computing
Cluster computing refers to the use of multiple computers to work together as a single system to perform a specific task. In cluster computing, each computer acts as a node and performs a specific function, with the overall performance of the system being determined by the combined performance of all nodes. Cluster computing can be used for a variety of applications, including scientific simulations, data analysis, and high-performance computing. The main advantage of cluster computing is that it allows for the processing of large amounts of data in a relatively short amount of time. Additionally, cluster computing can be used to provide high availability and failover capabilities, as well as to increase the overall performance of a system.
