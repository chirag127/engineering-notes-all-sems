### Programming for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing
Cluster Computing Overview:
- Cluster computing refers to a group of interconnected computers that work together as a single system to solve complex computational problems.
- Used in various fields such as scientific research, data analysis, and engineering simulations.
- Provides high performance computing by distributing tasks across multiple nodes, increasing processing power and memory.
- Cluster architecture can be of two types: homogeneous (identical nodes) or heterogeneous (different nodes).
- Cluster management software handles task scheduling, resource allocation, and communication between nodes.
- Popular cluster computing software: Hadoop, Apache Spark, OpenMPI, Rocks Cluster.

Advantages of Cluster Computing:
- Scalability: add more nodes to increase computing power.
- Reliability: nodes can continue working if one fails.
- Cost-effectiveness: use of commodity hardware instead of expensive supercomputers.

Challenges in Cluster Computing:
- Network Latency: communication between nodes can slow down computation.
- Synchronization: coordinating tasks between nodes can be complex.
- Load balancing: distributing tasks evenly across nodes can be a challenge.
