
### Programming for the Notes of the Unit 3 - Overview of Cluster Computing in the Subject of High Performance Computing

1. Cluster computing is a type of distributed computing that uses a collection of interconnected computers to perform a task. 
2. Clusters are typically used to increase the processing power, storage capacity, and reliability of a system. 
3. Clusters are composed of two or more computers that are connected through a network and are able to share resources. 
4. Clusters are used in a variety of applications, including scientific computing, data storage, web hosting, and video streaming. 
5. Clusters are typically used to improve the performance of a system by using multiple computers to divide a task into smaller tasks, which can then be run in parallel. 
6. Cluster computing can also be used to increase the availability of a system by providing redundancy and fault tolerance. 
7. Cluster computing is used in a variety of industries, including finance, healthcare, manufacturing, and telecommunications. 
8. Cluster computing systems are typically composed of a head node, which is responsible for managing the cluster, and a set of compute nodes, which are responsible for running the tasks. 
9. The head node is responsible for scheduling tasks, managing resources, and monitoring the health of the cluster. 
10. Cluster computing requires specialized software and hardware to manage the cluster. 
11. Cluster computing is often used in conjunction with other distributed computing technologies, such as grid computing and cloud computing.
