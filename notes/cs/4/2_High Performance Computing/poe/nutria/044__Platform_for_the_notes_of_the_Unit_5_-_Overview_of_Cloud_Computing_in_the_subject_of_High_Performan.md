
### Platform for the Notes of the Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

* Cloud computing is a type of computing that involves delivering computing services such as storage, databases, networking, software, analytics, and more over the Internet.
* Cloud computing is a form of distributed computing, where computing resources are delivered as a service over the Internet.
* Cloud computing provides users with access to a shared pool of computing resources, such as virtual machines, networks, storage, and applications.
* Cloud computing is a cost-effective and efficient way to access computing resources on demand.
* Cloud computing offers users the ability to scale computing resources quickly and easily, as well as the flexibility to choose the best service for their needs.
* Cloud computing is used for a variety of applications, such as web hosting, software development, data storage, and analytics.
* Cloud computing provides users with the ability to access their data and applications from anywhere, at any time.
* Cloud computing also provides users with the ability to access enterprise-level services, such as databases, messaging, and analytics.
* Cloud computing is a secure, reliable, and cost-effective way to access computing resources.
