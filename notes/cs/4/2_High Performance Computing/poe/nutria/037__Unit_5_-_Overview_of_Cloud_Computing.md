
## Unit 5 - Overview of Cloud Computing

1. Cloud Computing is a type of computing that involves delivering computing services such as applications, storage, and processing power over the internet.

2. It is an on-demand service that enables users to access computing resources without having to purchase, install, or maintain the physical hardware.

3. Cloud Computing provides a variety of services such as Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS).

4. IaaS is a cloud computing model that provides users with access to virtualized computing resources such as servers, networks, and storage.

5. PaaS is a cloud computing model that provides users with access to a platform for developing, deploying, and managing applications.

6. SaaS is a cloud computing model that provides users with access to software applications that can be accessed over the internet.

7. Cloud Computing also provides users with access to a variety of other services such as database services, analytics services, and security services.

8. Benefits of Cloud Computing include cost savings, scalability, and increased agility.

9. Challenges of Cloud Computing include security and privacy concerns, vendor lock-in, and lack of control.
