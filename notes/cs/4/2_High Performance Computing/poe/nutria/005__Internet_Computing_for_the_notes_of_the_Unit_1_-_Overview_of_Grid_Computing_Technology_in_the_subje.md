
### Internet Computing for the Notes of Unit 1 - Overview of Grid Computing Technology in High Performance Computing

1. Internet Computing is the use of distributed computing and communication technologies to solve complex computational problems.

2. It is a type of distributed computing that utilizes the resources of multiple connected computers over a network.

3. Grid Computing is a type of distributed computing that enables the sharing of resources, such as processing power, memory, and storage, across multiple computers.

4. Grid Computing allows for the efficient use of resources and helps to reduce the cost of computing.

5. Grid Computing is used in various fields, such as scientific research, artificial intelligence, and data analysis.

6. Grid Computing enables the sharing of data and resources across multiple computers, allowing for faster and more efficient computation.

7. Grid Computing can be used for tasks such as data mining, image processing, and other large-scale computations.
