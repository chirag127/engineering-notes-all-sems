
### Cluster Computer and its Architecture

* A cluster computer is a type of computer system that is composed of multiple interconnected computers, or nodes, working together to provide higher computing power or storage capacity than a single computer. 
* Cluster computing is a type of parallel computing in which multiple interconnected computers are used to solve complex problems. 
* It is used to solve problems that require a large amount of computing power or storage capacity, such as data processing, image and video processing, and scientific computing. 
* Cluster computers are composed of two or more computers, each of which is connected to the others via a high-speed network. 
* The nodes of a cluster computer can be connected via a variety of network technologies, such as Ethernet, Fibre Channel, and InfiniBand. 
* The nodes are typically connected to each other through a high-speed switch, which allows them to communicate quickly and efficiently. 
* Each node of a cluster computer is typically a powerful computer, such as a workstation or server, that can run its own operating system and applications. 
* The nodes are typically configured to work together to solve a problem, with each node performing a specific task. 
* Cluster computers are used in a variety of applications, such as data analysis, scientific computing, and high-performance computing. 
* Cluster computers are typically used in applications where the amount of data or the complexity of the problem requires a large amount of computing power. 
* Cluster computers can also be used for applications that require large amounts of storage capacity, such as data warehousing and distributed file systems.
