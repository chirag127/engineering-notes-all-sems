### Cluster Middleware and SSI

- Cluster middleware is software that sits between the application software and the cluster operating system to provide a convenient and simplified interface for using the cluster.
- It provides abstractions of cluster resources and handles communication and coordination.
- Examples: MPI, PVM, Linda, etc.
- Single System Image (SSI) makes a cluster of computers appear as a single system.
- It provides location transparency - application runs independently of which node it is executing on.
- Challenges in achieving SSI:
    - Resource sharing
    - Process migration
    - Load balancing
    - Fault tolerance
- Benefits of SSI:
    - Easy to use
    - Scalability (grow cluster capacity easily)
    - High utilization of resources
- Examples of SSI systems:
    - MOSIX
    - Kerrighed
    - OpenSSI
