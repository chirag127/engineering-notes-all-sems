### High Performance Computing for the notes of the Unit 1 - Overview of Grid Computing Technology

1. Grid Computing: Connecting geographically distributed computing resources such as supercomputers, databases, experimental facilities and human resources with the help of high speed networks to solve large-scale computational and data intensive problems in science, engineering and commerce is called Grid Computing.
2. Motivation: The growing complexity of applications and increasing volumes of data in many areas of science and engineering are demanding more computing power than a single computer can provide. This has led to the development of Grid computing which aggregates the power of many computers and databases at different locations to solve these problems.
3. Key Features:
- Heterogeneity: The resources connected in a grid can be of different types such as supercomputers, clusters, desktops, storage systems, software, sensors etc.
- Dynamicity: The availability and the load of the resources keep changing with time. The grid should adapt to these changes.
- Scalability: The grid should be able to incorporate new resources easily and the applications should be able to utilize the increased resources.
- Security: The grid system must provide adequate security and protection of resources.
- Fault Tolerance: The grid system should continue to function properly even when some resources fail or there are network problems.
