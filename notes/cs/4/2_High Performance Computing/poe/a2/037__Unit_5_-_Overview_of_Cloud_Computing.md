## Unit 5 - Overview of Cloud Computing

1. Cloud computing refers to the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers.
2. The key benefits of cloud computing are:
- Reduced costs: No upfront investment in hardware and software licenses. Pay as you go model.
- Increased scalability: Additional resources can be provisioned instantly to scale up or down based on business demands.
- Enhanced accessibility: Access to data and applications from anywhere on any device.
- Automatic updates: Software and hardware are automatically updated by the cloud provider.
3. The three main types of cloud computing services are:
- Infrastructure as a Service (IaaS): Provides virtualized computing resources like servers, storage, and networking. The customer has control over the infrastructure but not the platform or software. Examples: Amazon EC2, Microsoft Azure.
- Platform as a Service (PaaS): Provides a computing platform for customers to develop, run, and manage applications. The customer does not manage the infrastructure but controls the deployed applications. Examples: Heroku, AWS Elastic Beanstalk.
- Software as a Service (SaaS): Provides access to application software and databases. The cloud provider manages everything including the infrastructure, platform, and software. Examples: Google Workspace, Microsoft Office 365.
