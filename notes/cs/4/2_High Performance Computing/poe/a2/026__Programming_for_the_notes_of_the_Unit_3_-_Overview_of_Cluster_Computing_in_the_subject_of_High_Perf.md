### What is Cluster Computing?

- A cluster is a group of computers that work together to act like a single system to solve a computational problem.
- They are connected through a network which allows them to communicate and coordinate with each other.
- Cluster computing is used to provide high performance computing power, high availability and redundancy.

### Advantages of Cluster Computing

- Increased processing power - The combined processing power of multiple computers provides more processing power than a single computer. This enables solving larger problems faster.
- Cost effectiveness - Using multiple smaller computers can be more cost effective than using a single large powerful computer. The individual computers can be standard hardware and open source software can be used.
- Scalability - It is easy to add more computers to the cluster to scale the performance to handle larger problems or more simultaneous computations.
- Fault tolerance - The system has redundancy so if one computer fails, the other computers can take over its workload. This provides high availability of the computational resources.
