### Software Practices for the notes of the Unit 4 - Beowulf Cluster

1. Message Passing Interface (MPI)
- Standard library for message passing
- Process communication through sending and receiving messages
- Point to point and collective communication
- Synchronous and asynchronous communication

2. Parallel Virtual Machine (PVM)
- Message passing library and parallel programming environment
- Spawns multiple copies of a program across heterogeneous systems
- Message passing for inter-process communication
- Provides console for monitoring and controlling parallel jobs

3. Job Schedulers
- Used to allocate resources to parallel jobs and schedule their execution
- Examples: Slurm, Torque, Grid Engine
- Used for efficient resource allocation and management in clusters
- Factors considered: Fair sharing of resources, prioritizing jobs, resource monitoring, etc.

4. Version Control Systems
- Required to track changes in software and code
- Facilitates collaboration and maintains history of changes
- Popular tools: Git, Mercurial, Subversion
- Branching allows isolated development and merging branches
- Used to manage software on clusters with multiple users and updates
