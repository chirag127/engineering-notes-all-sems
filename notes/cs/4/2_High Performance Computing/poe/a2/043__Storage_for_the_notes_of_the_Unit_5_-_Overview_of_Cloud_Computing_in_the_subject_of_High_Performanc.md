### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

1. Object Storage: Stores data as objects with metadata. Scales to store and access billions of objects. Used for storage of unstructured data like images, videos, log files, backups, etc.
2. Block Storage: Stores data in blocks and manages it as raw block devices. Used for storage of structured data like databases, operating systems, etc. Can be used as a storage device directly attached to a single VM.
3. File Storage: Provides a file system interface and stores data in a hierarchy of files. Used for storing and running applications and services that require a file system interface.
4. Archival Storage: Used for long-term retention of rarely accessed data. Optimized for retention and not performance. Data is stored at the lowest cost but at the expense of speed of access.

The storage options provide varied capabilities and are suitable for different use cases. The selection of a suitable storage option depends on the structure, size, access frequency and cost requirements of the data to be stored in the cloud.
