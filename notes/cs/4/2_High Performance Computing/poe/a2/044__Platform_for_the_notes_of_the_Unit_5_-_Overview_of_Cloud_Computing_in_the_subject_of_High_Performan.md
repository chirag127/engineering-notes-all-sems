### Platform for the notes of the Unit 5 - Overview of Cloud Computing

1. Cloud computing is the delivery of computing services over the Internet. Companies that offer cloud computing services are referred to as cloud providers. They typically charge for cloud computing services based on usage, similar to how public utilities charge for services like electricity.
2. The key benefits of cloud computing include:
- Cost efficiency: Cloud computing eliminates the capital expense of buying hardware and software and setting up and maintaining data centers. Organizations pay only for the resources they use.
- Scalability: It is easy to scale cloud resources up or down as needs change. This makes cloud computing well suited for workloads that are variable or unpredictable.
- Accessibility: Resources are available over the network and can be accessed from anywhere using any device.
- Maintenance: The cloud provider handles hardware, software, and security updates and other maintenance tasks.
3. The three major types of cloud computing services are:
- Infrastructure as a Service (IaaS): Provides access to computing resources such as servers, storage, and networking. The customer is responsible for installing and managing their own software.
- Platform as a Service (PaaS): Provides a computing platform with an operating system and development tools. The customer creates their own applications using programming languages, libraries, and tools supported by the provider.
- Software as a Service (SaaS): Provides access to applications that are run over the Internet. The customer does not manage the underlying infrastructure or platforms that the applications run on. Examples include Microsoft Office 365, G Suite, and Salesforce.
