### Environments and Tools for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

1. OpenMP: OpenMP is an API that supports multi-platform shared memory multiprocessing programming in C/C++ and Fortran. It consists of a set of compiler directives, library routines, and environment variables that can be used to specify shared memory parallelism in Fortran and C/C++ programs.

2. MPI: Message Passing Interface (MPI) is a language-independent communications protocol used to program parallel computers. It is a library of routines that allow processes to coordinate their activities and exchange data. MPI processes can be mapped to processors in a parallel system in many different ways.

3. CUDA: CUDA is a parallel computing platform and programming model developed by Nvidia for general computing on its own graphics processing units (GPUs). It allows software developers to use the parallel compute power of Nvidia GPUs for general purpose computing rather than just for graphics rendering. CUDA comes with a software environment that allows developers to use C as a high-level programming language.

4. OpenACC: OpenACC is a programming standard for accelerators (primarily GPUs) that aims to provide a simple and portable programming model for parallel scientific applications. It uses compiler directives to specify parallelism and data mappings to accelerators. The OpenACC standard is designed to allow programmers to incrementally augment existing codes to take advantage of accelerators without major code restructuring.

It is designed to be lightweight, portable and scalable to tens of thousands of nodes.
