### Channel structure for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

I. Introduction
- Mobile computing: Portable computing devices with wireless connectivity allowing transmission of data, voice and video.
- Issues: Limited battery life, small display size, limited storage capacity, security and privacy threats.

II. Overview of wireless telephony
- Cellular concept: Geographic area divided into cells with each cell served by a fixed base station enabling frequency reuse.
- FDMA: Frequency Division Multiple Access divides available bandwidth into frequency slots assigned to users. Inefficient bandwidth utilization.
- TDMA: Time Division Multiple Access divides each frequency into time slots assigned to users. Slot synchronization required leading to complex RF circuitry.
- CDMA: Code Division Multiple Access uses spread spectrum technique with digital codes to differentiate user data. Bandwidth efficient but complex to implement.

III. GSM - Global System for Mobile Communication
- Most popular standard for digital cellular networks.
- Uses TDMA and FDMA for multiple access.
- Supports data rates up to 14.4 kbps.
- Security through authentication and encryption.
- International roaming supported.
- Services include voice calls, SMS, MMS, internet access, etc.

Mnemonics:
- Think C for CDMA: Code division multiple access
- Time is money for TDMA: Time division multiple access
- Frequency fuels FDMA: Frequency division multiple access

Advantages: Wide coverage, low power consumption, inexpensive.
Disadvantages: Call drops and handoff delays, limited data rates.
Applications: Mobile phones, internet access, vehicle tracking, etc.
