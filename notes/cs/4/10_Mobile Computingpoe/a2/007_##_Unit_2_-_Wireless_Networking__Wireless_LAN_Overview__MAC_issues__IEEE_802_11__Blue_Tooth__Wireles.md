## Wireless LAN Overview

- Wireless LANs eliminate the need for physical wired connections between devices. They use radio waves to communicate between devices.
- The medium access control (MAC) layer is responsible for coordinating access to the shared radio channel. It uses protocols for controlling the radio transmitters and receivers to ensure only one device transmits at a time. This avoids collisions of transmitted data.
- The most popular standards for wireless LANs are the IEEE 802.11 standards (Wi-Fi). The different versions of 802.11 (a, b, g, n, ac) have different radio frequencies, bandwidths, and maximum speeds. 802.11ac is the current highest performance standard.

## IEEE 802.11

- The IEEE 802.11 standard defines the MAC and physical layer (PHY) specifications for wireless LANs.
- The MAC layer utilizes Carrier Sense Multiple Access with Collision Avoidance (CSMA/CA). Devices listen for a clear channel before transmitting to avoid collisions. If a collision is detected, devices wait for a random backoff period before retransmitting.
- The original 802.11 standard specified two PHY layers:
  - Frequency Hopping Spread Spectrum (FHSS) which switches between different frequencies in a pseudorandom pattern.
  - Direct Sequence Spread Spectrum (DSSS) which spreads the signal over a range of frequencies using a pseudorandom code.
- Later versions of 802.11 (a, b, g, n, ac) specify different PHY layers using different radio bands and modulation techniques to achieve higher speeds.

## Bluetooth

- Bluetooth is a short-range wireless technology standard for connecting nearby devices and exchanging data over short distances using radio waves.
- It operates in the unlicensed 2.4 GHz band using a technique called spread-spectrum frequency hopping to prevent interference. Devices frequently hop between different frequencies in a pseudorandom pattern.
- Bluetooth is commonly used to wirelessly connect peripherals like headphones, keyboards, and other sensors to devices. It can also be used to create wireless personal area networks between nearby devices.
