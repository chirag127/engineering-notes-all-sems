### CDMA for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

CDMA stands for Code Division Multiple Access. It is a digital wireless technology that uses spread-spectrum techniques. Some key points about CDMA are:

- CDMA employs a spread-spectrum technology in which a pseudo-random code is used to spread the bandwidth of the data signal over a range of frequencies. This makes CDMA signals resilient to interference.
- In CDMA, each user is assigned a unique code to differentiate between different calls. This allows multiple users to share the same frequency spectrum simultaneously.
- CDMA is a 'spread spectrum' technology which makes the receiver resilient to interference from other users and multipath fading.
- The advantages of CDMA are its efficient use of bandwidth, resilience to interference and multipath fading. However, it suffers from the near-far problem and requires complex receiver designs.
- Some applications of CDMA are cellular networks, mobile ad-hoc networks, etc.

**Mnemonics:**

- Code Division: Users are differentiated by codes, not frequencies.
- Resilient to interference: Spread spectrum technique spreads signal across frequencies.
- Unique code: Each user has a unique pseudo-random code to identify their signal.

**Learning tricks:**

- Visualize the spread spectrum as spreading jam on bread. The signal is spread like jam across the bread (frequency range). This makes it resilient to removal of parts of the signal (interference/fading).
- The near-far problem can be understood by imagining two speakers playing the same song at different volumes. The louder speaker's signal may drown out the quieter one. CDMA receivers face a similar issue with nearby and distant signals.
