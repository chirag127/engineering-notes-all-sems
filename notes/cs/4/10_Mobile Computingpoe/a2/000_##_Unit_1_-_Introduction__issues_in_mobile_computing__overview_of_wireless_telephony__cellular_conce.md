## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

- Introduction to mobile computing: Mobile computing refers to the ability to use technology like laptops, tablets or smartphones to access data and applications without being connected to a fixed physical link. Mobile computing has enabled ubiquitous access to information anytime and anywhere. However, there are some unique issues and challenges in mobile computing such as:
- Limited battery power: Mobile devices operate on battery power which is limited. This impacts the performance and functionality of the devices. Power saving techniques need to be used to optimize battery life.
- Small screen size: Mobile devices have smaller screens than laptops or desktops. This can impact the user experience and design of applications for mobile devices needs to accommodate the smaller screen size.
- Variety of devices: There is a wide variety of mobile devices with different capabilities and screen sizes. This makes it challenging to design one solution that works across all devices. Responsive and adaptive design techniques are used to support multiple devices.
- Wireless connectivity: Mobile devices connect to networks via wireless connections which can be intermittent or slow. This can impact access to data and applications. Applications need to handle such connectivity issues gracefully.
- Security: Wireless networks are more prone to security threats like eavesdropping, man-in-the-middle attacks, etc. Extra security mechanisms are required to secure data over wireless networks.

- Overview of wireless telephony: Wireless telephony refers to the technology that enables wireless communication of voice and data. Some key concepts in wireless telephony are:
- Cellular concept: The area is divided into small geographical areas called cells. Each cell has a low-power base station for communication with mobile devices in that cell. This concept increases spectrum efficiency and enables mobility.
- Frequency reuse: Limited radio frequencies are reused in different cells that are far apart to support more simultaneous calls. Frequency planning is required to enable frequency reuse while avoiding interference.
- Handoff: As a mobile device moves across cells, its call is transferred to the new cell to avoid call drops. This is called handoff or handover and requires sophisticated mechanisms to transfer calls seamlessly across cells.

- GSM: Global System for Mobile communications (GSM) is a widely used standard for digital cellular networks. Some key aspects of GSM are:
- Digital communication: GSM uses digital communication and time division multiple access (TDMA) to enable more efficient use of spectrum than analog cellular systems.
- SIM card: GSM uses a subscriber identity module (SIM) card to uniquely identify subscribers and enable authentication and account information portability across devices.
- Services: GSM supports a wide range of services including voice calls, SMS, MMS, and data communication. GSM has evolved to enable high-speed data access as well with technologies like GPRS, EDGE, and HSPA.
