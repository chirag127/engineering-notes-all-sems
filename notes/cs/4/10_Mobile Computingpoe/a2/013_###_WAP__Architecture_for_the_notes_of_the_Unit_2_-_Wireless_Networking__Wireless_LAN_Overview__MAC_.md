### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

- WAP stands for Wireless Application Protocol. It is a communications protocol standard that allows mobile devices to access Internet content and services.
- WAP architecture has the following layers:
  - Wireless Application Environment (WAE): Provides an application framework for WAP applications. It defines things like a markup language for authoring WAP content.
  - Wireless Session Protocol (WSP): Provides a state-full session protocol layer on top of a wireless transport. It manages sessions between applications and the WAP system.
  - Wireless Transport Layer Security (WTLS): Provides security at the transport layer. It is responsible for data security and data integrity protection between WAP applications and the underlying bearer service.
  - Wireless Datagram Protocol (WDP): Provides an interface to different wireless transport bearers. It provides an interface to transport protocol stacks for different wireless networks.
- Benefits: Provides access to internet and internet services on mobile devices with limited capabilities. Supports wide range of wireless networks and devices.
- Limitations: Limited bandwidth and slower speeds. Displays are smaller leading to longer navigation paths. Requires WAP gateway to convert content to WAP formats leading to extra costs.
- Applications: Used to access emails, news, sports updates, banking, travel information, etc on mobile devices.
