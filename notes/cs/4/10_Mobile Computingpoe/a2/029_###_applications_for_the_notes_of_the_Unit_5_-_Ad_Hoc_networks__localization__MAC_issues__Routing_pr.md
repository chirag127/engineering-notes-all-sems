### Applications for the notes of the Unit 5 - Ad Hoc networks, localization, MAC issues, Routing protocols, global state routing (GSR), in the subject of Mobile Computing

Ad Hoc networks:
- A decentralized type of wireless network where nodes communicate with each other without the need for a centralized access point.
- Nodes act as routers and transmit data for other nodes.
- Self-configuring network topology.
- Example: Mobile ad hoc networks (MANETs).

Localization:
- Determining the physical locations of nodes in an ad hoc network.
- Methods: Received signal strength indication (RSSI), Time of arrival (ToA), Time difference of arrival (TDoA), Angle of arrival (AoA).
- Challenges: Inaccurate distance estimation, node mobility, limited resources.

MAC issues:
- Medium access control (MAC) protocols govern sharing of wireless medium.
- Challenges in ad hoc networks: Hidden terminal problem, Exposed terminal problem, Deafness problem, Capture effect.
- Solutions: Carrier sense multiple access (CSMA), Request-to-send/clear-to-send (RTS/CTS), Binary exponential backoff.

Routing protocols:
- Protocols to determine paths for data transmission between nodes.
- Classification: Proactive (table-driven), Reactive (on-demand), Hybrid.
- Examples: Destination-sequenced distance-vector (DSDV), Ad hoc on-demand distance vector (AODV), Dynamic source routing (DSR).

Global state routing (GSR):
- Maintains consistent and synchronized view of global network state.
- Allows computation of optimal paths.
- Challenges: High messaging overhead, latency in reacting to topology changes.
- Examples: Wireless routing protocol (WRP), Fisheye state routing (FSR).

Advantages: Flexible deployment, robustness.
Disadvantages: Limited bandwidth, security vulnerabilities, technical challenges.
Applications: Emergency/rescue operations, military applications, smart spaces.
