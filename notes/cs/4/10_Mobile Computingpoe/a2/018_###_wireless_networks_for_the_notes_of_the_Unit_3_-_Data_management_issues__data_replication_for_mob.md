### Wireless Networks

For the notes of Unit 3 - Data management issues, data replication for mobile computers, adaptive clustering for mobile in the subject of Mobile Computing

- wireless networks allow devices to connect and communicate wirelessly using radio waves
- devices can connect from anywhere within the range of a wireless access point
- popular wireless network standards:
    - Wi-Fi (802.11 a/b/g/n/ac) - local area wireless networking, commonly used to connect to the internet
    - Bluetooth - short-range wireless networking for peripherals like headphones, keyboards, etc.
    - cellular data (3G/4G LTE) - wireless data networks provided by mobile carriers
- advantages: convenience, mobility, reduced cabling
- disadvantages: potential security issues, interference, coverage limitations
- applications: internet access, network peripherals, mobile devices, IoT devices

Mnemonics:
- WiFly - helps remember Wi-Fi standard names (a/b/g/n/ac)
- Blue teeth - helps remember Bluetooth is for wireless peripherals

Learning tricks:
- understand the pros and cons of different wireless standards to know use cases
- visualize how wireless networks work using radio waves and access points to understand range and coverage
- configure own wireless network to learn hands-on and understand security considerations
