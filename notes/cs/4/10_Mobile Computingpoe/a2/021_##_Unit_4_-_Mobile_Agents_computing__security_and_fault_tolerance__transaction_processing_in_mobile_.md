## Unit 4 - Mobile Agents computing, security and fault tolerance, transaction processing in mobile computing

- Mobile Agents: Software agents that can migrate from one computer to another autonomously and continue their execution on the destination computer. They are used to reduce network traffic and latency in applications like Internet information retrieval, network management, and electronic commerce.
- Advantages: Reduced network traffic, overcome network latency, asynchronous and autonomous operation, adaptable to network conditions.
- Disadvantages: Security issues, compatibility issues, resource constraints on mobile devices.
- Examples: Internet information retrieval, network management, electronic commerce.

Mnemonics: MAgents (Mobile Agents) - MaMa (Migration, Management) for NNR (Network efficiency, reduced latency).

Security:
- Protect code and data of agents from tampering and eavesdropping using encryption and digital signatures.
- Restrict agents to authorized areas of the network and prevent unauthorized access using access control and authentication.
- Deal with malicious hosts which may misuse, copy or tamper with visiting agents.

Fault Tolerance:
- Use checkpointing to periodically save the state of agents.
- Replicate agents and use voting/comparison to mask failures.
- Choose reliable routes for agent migration.
- Restart agents from the last checkpoint in case of failures.

Transaction Processing:
- Ensure ACID properties for transactions spanning multiple hosts using commit protocols.
- Handle issues like decentralization of data, network failures and mobility.
- Employ optimistic/pessimistic concurrency control and recovery techniques suitable for mobile environments.
