### CDMA for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

CDMA stands for Code Division Multiple Access. It is a digital cellular technology that uses spread spectrum techniques for transmission. CDMA allows multiple users to share the same frequency band by assigning each user a unique code.

Here are some key points about CDMA:

- CDMA is a digital cellular technology that is used in mobile communication.
- CDMA uses spread spectrum techniques for transmission.
- In CDMA, each user is assigned a unique code, which is used to encode the data stream.
- The unique code allows multiple users to share the same frequency band without interfering with each other.
- CDMA is a popular technology used in 3G and 4G mobile networks.
- CDMA offers better call quality and higher data rates compared to other cellular technologies.

Advantages of CDMA:

- CDMA allows multiple users to share the same frequency band, which increases the capacity of the network.
- CDMA provides better call quality and higher data rates compared to other cellular technologies.
- CDMA is more secure than other cellular technologies because of the unique code assigned to each user.

Disadvantages of CDMA:

- CDMA requires more processing power and resources compared to other cellular technologies.
- CDMA is not as widely used as other cellular technologies such as GSM.

CDMA is an important technology in mobile communication and is used in many 3G and 4G networks. It offers several advantages over other cellular technologies, including better call quality, higher data rates, and increased network capacity. However, it also has some disadvantages, such as requiring more processing power and not being as widely used as other cellular technologies.
