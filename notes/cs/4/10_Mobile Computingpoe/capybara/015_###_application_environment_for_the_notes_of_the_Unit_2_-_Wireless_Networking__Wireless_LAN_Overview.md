### Application Environment for the Notes of Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Bluetooth, Wireless in the Subject of Mobile Computing

Wireless networking has become a crucial part of the modern computing environment. The ability to access the internet, share files and communicate without the need for cables has revolutionized the way we work and live. In this unit, we will explore the application environment for wireless networking, with a focus on wireless LAN overview, MAC issues, IEEE 802.11, Bluetooth, and Wireless in the subject of Mobile Computing.

#### Wireless LAN Overview

- Wireless LAN refers to the local area network that uses radio waves to transmit and receive data over the air.
- WLAN provides flexibility and mobility to the users as they can access the network from anywhere within the range of the access point.
- WLAN uses the IEEE 802.11 standards for wireless communication.

#### MAC Issues

- MAC address is a unique identifier assigned to each device in a network.
- MAC address filtering is a security feature that allows only specified MAC addresses to access the network.
- MAC spoofing is a technique used to forge a MAC address to gain unauthorized access to the network.

#### IEEE 802.11

- IEEE 802.11 is a standard that defines the specifications for WLAN.
- It defines the physical and data link layer specifications for wireless communication.
- The standard has evolved over the years, with the latest version being IEEE 802.11ax.

#### Bluetooth

- Bluetooth is a wireless technology that allows devices to communicate with each other over short distances.
- It uses radio waves to transmit and receive data.
- Bluetooth is commonly used for wireless headphones, speakers, and other peripheral devices.

#### Wireless in Mobile Computing

- Mobile computing refers to the use of portable devices like smartphones and tablets for computing tasks.
- Wireless networking is essential for mobile computing as it allows users to access the internet and other network resources on the go.
- Mobile devices use cellular networks, WLAN, and Bluetooth for wireless communication.

#### Mnemonics and Learning Tricks

- For remembering the IEEE 802.11 standards, you can use the phrase "802.11, heaven, heaven" where each "heaven" represents a different version of the standard (a, b, g, n, ac, ax).
- To remember the difference between MAC filtering and MAC spoofing, you can use the phrase "filter friends, spoof strangers."
