### Protocol Stack for Wireless LAN Overview

In wireless networking, protocol stack refers to the set of communication protocols that are used to transmit data over a wireless network. Protocol stack is divided into different layers, each layer performing a specific function in the communication process. The protocol stack for wireless LAN overview consists of the following layers:

1. Physical Layer: This layer is responsible for the transmission of raw data over the wireless medium. It converts the data into radio signals and transmits them over the air. The physical layer also handles modulation, coding, and channel access.

2. Data Link Layer: This layer is responsible for the reliable transmission of data between two devices. It ensures that data is transmitted without errors and in the correct order. The data link layer is divided into two sub-layers: Media Access Control (MAC) and Logical Link Control (LLC).

3. Network Layer: This layer is responsible for routing data between different devices on the network. It determines the best path for data transmission and handles issues related to addressing, routing, and congestion control.

4. Transport Layer: This layer is responsible for the end-to-end delivery of data between two devices. It provides reliable data transfer and flow control mechanisms.

5. Application Layer: This layer is responsible for providing services to end-users. It includes protocols such as HTTP, FTP, and SMTP.

Wireless LAN Overview: MAC Issues

The MAC sub-layer of the data link layer is responsible for media access control, which is the process of controlling access to the wireless medium. MAC issues in wireless LAN overview include the following:

1. Hidden Terminal Problem: This occurs when two devices are unable to detect each other's signals due to obstacles or distance. As a result, they may transmit data simultaneously, leading to collisions.

2. Exposed Terminal Problem: This occurs when a device refrains from transmitting data due to the presence of another device, even though the other device may not interfere with the transmission.

IEEE 802.11

IEEE 802.11 is a set of standards for wireless LANs that defines the physical and data link layer specifications for wireless communication. The IEEE 802.11 standard includes several protocols such as:

1. 802.11a: This protocol operates in the 5 GHz frequency band and provides higher data rates than 802.11b.

2. 802.11b: This protocol operates in the 2.4 GHz frequency band and provides data rates of up to 11 Mbps.

3. 802.11g: This protocol operates in the 2.4 GHz frequency band and provides data rates of up to 54 Mbps.

Bluetooth

Bluetooth is a wireless communication protocol that is used for short-range communication between devices. It operates in the 2.4 GHz frequency band and provides data rates of up to 3 Mbps. Bluetooth is commonly used for wireless audio streaming, file transfer, and device synchronization.

Wireless in Mobile Computing

Wireless communication is an integral part of mobile computing. Mobile devices such as smartphones, tablets, and laptops use wireless communication protocols to connect to the internet and other devices. Some of the applications of wireless communication in mobile computing include:

1. Wireless internet access: Mobile devices use wireless communication protocols such as Wi-Fi and cellular networks to connect to the internet.

2. Location-based services: Mobile devices use wireless communication protocols such as GPS and Bluetooth to provide location-based services.

3. Wireless file transfer: Mobile devices use wireless communication protocols such as Bluetooth and NFC to transfer files between devices.
