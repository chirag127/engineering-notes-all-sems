### Applications for the Notes of Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Bluetooth, Wireless in the Subject of Mobile Computing

Wireless networking has become an integral part of our lives, especially in the field of mobile computing. In order to understand and excel in this field, it is important to have a good understanding of several important topics like MAC issues, IEEE 802.11, Bluetooth, and wireless LAN overview. Here are some applications that can help you in studying and preparing for exams related to these topics:

1. Wireshark: Wireshark is a popular network protocol analyzer that allows you to see what's happening on your network at a microscopic level. It can be used to analyze wireless network traffic, including IEEE 802.11 networks. It can help you in understanding how different devices communicate with each other over a wireless network.

2. NetStumbler: NetStumbler is a wireless network scanner that can be used to detect wireless networks in your vicinity. It can also be used to find rogue access points and to test the security of your own wireless network. It can help you in understanding how wireless networks are set up and how they can be secured.

3. Bluetooth Low Energy (BLE) Explorer: BLE Explorer is an application that can be used to explore Bluetooth Low Energy devices. It can help you in understanding how Bluetooth devices communicate with each other and how data is transmitted wirelessly.

4. AirMagnet WiFi Analyzer: AirMagnet WiFi Analyzer is a wireless network analyzer that can be used to troubleshoot wireless network issues. It can help you in understanding how wireless networks work and how to diagnose and fix issues related to them.

5. Cisco Packet Tracer: Cisco Packet Tracer is a simulation tool that can be used to simulate networks and network devices. It can help you in understanding how different network devices work and how they interact with each other. It can also help you in understanding how wireless networks can be set up and configured.

Mnemonics and Learning Tricks:

- MAC issues can be remembered as "Media Access Control" issues, which refer to the way devices communicate with each other over a network.
- IEEE 802.11 can be remembered as "I Eat Eggs Eleven Times a Day", which can help you in remembering the name of the standard.
- Bluetooth can be remembered as "Blue + Tooth", which refers to the blue color of the first toothbrush that was used to name the technology.

In conclusion, these applications and mnemonics can be helpful in understanding and preparing for exams related to wireless networking and mobile computing. It is important to have a good understanding of these topics in order to excel in this field.
