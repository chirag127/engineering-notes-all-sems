
### Multiple Access Protocols for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC Issues, IEEE 802.11, Bluetooth, Wireless in the subject of Mobile Computing

- **Multiple Access Protocols** are a set of rules and regulations that govern how multiple nodes in a network can access the network's resources. These protocols are used to ensure that the network is used efficiently and that all users have access to the same resources.

- **IEEE 802.11** is a set of standards for wireless data transmission. This protocol is commonly used in wireless networks such as Wi-Fi networks. It is a set of standards that define how data is transmitted and how it is secured.

- **Bluetooth** is a wireless technology that is used to transmit data over short distances. It is commonly used in mobile phones and other devices to connect to other devices or to the Internet.

- **Wireless in the subject of Mobile Computing** is the use of wireless technology to transfer data between two or more devices. Wireless technology is used in mobile phones, tablets, and other devices to allow users to access the Internet and other services without the need for a physical connection.

- **MAC Issues** are issues related to the Media Access Control layer of the network. This layer is responsible for controlling access to the network by different devices. It is important to ensure that the MAC layer is configured correctly to ensure that all devices have access to the network.
