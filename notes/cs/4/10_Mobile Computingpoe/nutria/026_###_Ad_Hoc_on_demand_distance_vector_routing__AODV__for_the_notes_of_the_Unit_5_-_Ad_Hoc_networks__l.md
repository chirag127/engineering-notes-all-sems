
### Ad Hoc on Demand Distance Vector Routing (AODV) for the Notes of Unit 5 - Ad Hoc Networks, Localization, MAC Issues, Routing Protocols, Global State Routing (GSR), in the Subject of Mobile Computing

AODV is an on-demand routing protocol used in mobile ad hoc networks (MANETs). AODV is a reactive routing protocol, meaning that it only establishes routes between nodes when they are needed. This is in contrast to proactive routing protocols, which maintain up-to-date routing information at all times. 

AODV is a distance-vector routing protocol, meaning that each node maintains a table of the estimated distances to other nodes in the network. When a node needs to send a packet to another node, it consults its distance vector table to determine the best route to the destination.

AODV has several advantages over other routing protocols. It is loop-free, meaning that it does not suffer from the routing loops that can occur in distance-vector protocols. It is also self-starting, meaning that it does not require any configuration or manual intervention to begin operation. Finally, AODV has low overhead, meaning that it does not require a large amount of bandwidth to operate.

AODV is used in a variety of applications, including military operations, disaster relief, and sensor networks. It is also used in vehicular networks, where it can be used to provide real-time navigation information to vehicles.
