
### CDMA for the notes of the Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM: in the subject of Mobile Computing

- **Code Division Multiple Access (CDMA)** is a digital cellular technology that uses spread-spectrum techniques. It is a multiple access technique that allows multiple users to share a single communication channel.
- CDMA is a type of multiplexing, which allows numerous signals to occupy a single transmission channel, optimizing the use of available bandwidth.
- CDMA works by assigning a different code to each user. This code is used to spread the data across the available frequency spectrum.
- CDMA is used in both cellular systems and satellite systems. It is used in many mobile phones, wireless networks, and satellite communication systems.
- CDMA has several advantages over other multiple access techniques, such as better voice quality, improved security, and improved capacity.
- CDMA is a more secure form of communication than other multiple access techniques. It uses spread-spectrum techniques that make it difficult for unauthorized users to access the signal.
- CDMA is also more efficient than other multiple access techniques. It uses less power and is able to support more users in the same amount of bandwidth.
- CDMA is used in many cellular systems, such as GSM, CDMA2000, and WCDMA. It is also used in satellite communication systems, such as Iridium and Globalstar.
