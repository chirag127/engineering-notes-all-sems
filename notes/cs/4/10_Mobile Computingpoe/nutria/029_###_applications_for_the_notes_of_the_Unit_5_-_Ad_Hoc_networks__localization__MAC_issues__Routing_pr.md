

# Applications for the Notes of the Unit 5 - Ad Hoc Networks, Localization, MAC Issues, Routing Protocols, Global State Routing (GSR), in the Subject of Mobile Computing

1. Ad Hoc Networks: Ad hoc networks are wireless networks that are formed without the use of a centralized access point. They are self-organizing, self-configuring, and self-healing. They are used in scenarios where a wired network is not available or feasible.

2. Localization: Localization is the process of determining a device's location in a given environment. In mobile computing, localization is used to determine the location of a mobile device or user in order to provide services or applications that are location-aware.

3. MAC Issues: MAC (Media Access Control) is the protocol used to control access to the wireless medium. MAC protocols define how devices access the medium, how they transmit data, and how they resolve conflicts when multiple devices attempt to access the medium at the same time.

4. Routing Protocols: Routing protocols are used to route data packets between nodes in a network. They define the rules and procedures that nodes use to exchange information about the network topology and to update their routing tables.

5. Global State Routing (GSR): GSR is a distributed routing algorithm that is used in ad hoc networks. It is based on the concept of global state, which is the total knowledge of the network topology that is available to all nodes in the network. GSR uses this global state to determine the best route for each data packet.
