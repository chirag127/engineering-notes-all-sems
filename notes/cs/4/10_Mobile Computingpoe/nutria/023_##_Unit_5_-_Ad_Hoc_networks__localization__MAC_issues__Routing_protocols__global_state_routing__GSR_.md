
## Unit 5 - Ad Hoc Networks, Localization, MAC Issues, Routing Protocols, Global State Routing (GSR)

Ad Hoc networks are wireless networks that are formed without any infrastructure or centralized control. They are self-organizing and self-configuring networks, which makes them ideal for situations where a network needs to be established quickly, such as in emergency situations.

Localization is the process of determining the geographic location of a device in an Ad Hoc network. This is important for routing and for determining the best route for data to take.

MAC (Medium Access Control) is the protocol used for controlling access to a shared medium, such as a wireless network. It is responsible for deciding which device has access to the medium at any given time.

Routing protocols are the protocols used for routing data in an Ad Hoc network. These protocols are responsible for discovering and maintaining routes between nodes in the network, as well as for delivering data from one node to another.

Global State Routing (GSR) is a routing protocol that is used for large-scale Ad Hoc networks. It is a distributed protocol that uses a global view of the network to determine the best route for data to take.

Mnemonics and Learning Tricks:
- Ad Hoc: Always Have Direct Options
- Localization: Locate Objects With Accurate Coordinates
- MAC: Manage Access To Central Resources
- Routing Protocols: Relay Orders To Other Points
- GSR: Global State Routing
