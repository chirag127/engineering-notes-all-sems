
## Unit 1 - Introduction, issues in mobile computing, overview of wireless telephony: cellular concept, GSM:

1. Mobile Computing: Mobile computing is a technology that allows transmission of data, voice and video via a computer or any other wireless enabled device without having to be connected to a fixed physical link. This technology is used in a number of applications such as mobile phones, PDAs, laptops, tablets, etc.
2. Issues in Mobile Computing: Mobile computing has a number of issues that need to be addressed in order to make it more efficient and secure. These issues include battery life, data security, network coverage, compatibility with existing systems, and cost.
3. Overview of Wireless Telephony: Wireless telephony is the transmission of voice and data over a wireless network. This technology is used in a number of applications such as cellular phones, PDAs, laptops, tablets, etc. It has a number of advantages such as cost savings, increased mobility, and improved communication.
4. Cellular Concept: The cellular concept of wireless telephony is based on the idea of dividing a large area into smaller cells. Each cell is served by a base station that is responsible for transmitting and receiving signals from the mobile devices. This allows for the efficient use of radio frequency spectrum and improved coverage.
5. GSM: Global System for Mobile Communications (GSM) is a standard for digital cellular communication. It is the most widely used standard for mobile communication and is used in over 200 countries. GSM provides a number of features such as voice communication, data transmission, SMS, and security.
