

### Dynamic Source Routing (DSR)

DSR is a routing protocol used in mobile ad hoc networks (MANETs) for communication between nodes without the need for an existing infrastructure or centralized administration. It is a reactive protocol, meaning that it does not maintain routing information and only creates routes when needed.

#### Features of DSR

- DSR is a source-initiated routing protocol, meaning that it is initiated by the source node.
- It is a reactive routing protocol, meaning that routes must be discovered each time they are needed.
- It uses source routing, meaning that the source node is responsible for routing the packet to the destination.
- It is a loop-free protocol, meaning that it avoids routing loops.
- It is a distributed protocol, meaning that no centralized administration is required.
- It is a hop-by-hop routing protocol, meaning that each node forwards the packet to the next node in the route.
