
### Mobile IP for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

Mobile IP is a network layer protocol used in mobile computing to allow a mobile device to move from one network to another while maintaining an active connection to the Internet. It is part of the Internet Protocol suite and is an extension of the Internet Protocol (IP). Mobile IP allows a device to maintain a single IP address even when it moves from one network to another.

**Advantages of Mobile IP:**

- Allows mobile devices to remain connected to the Internet while they move from one network to another.
- Allows mobile nodes to maintain a single IP address even when they move from one network to another.
- Supports the delivery of packets to mobile nodes even when they are moving.
- Allows mobile nodes to roam between networks without losing their IP address.
- Allows mobile nodes to maintain a single IP address even when they are connected to multiple networks simultaneously.

**Disadvantages of Mobile IP:**

- Mobile IP requires more overhead than traditional IP.
- Mobile IP requires additional configuration and setup.
- Mobile IP is not as secure as traditional IP.
- Mobile IP can be expensive to implement.
- Mobile IP can be difficult to manage.
