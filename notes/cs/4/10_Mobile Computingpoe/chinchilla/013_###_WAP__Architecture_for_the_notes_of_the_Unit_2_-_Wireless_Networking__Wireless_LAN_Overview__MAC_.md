### WAP: Architecture for the notes of the Unit 2 - Wireless Networking, Wireless LAN Overview: MAC issues, IEEE 802.11, Blue Tooth, Wireless in the subject of Mobile Computing

Wireless Application Protocol (WAP) is a communication protocol used to access the internet from mobile devices. It is designed to work with various wireless network technologies, such as GSM, CDMA, and 3G. In this unit, we will cover the following topics related to wireless networking:

1. Wireless LAN Overview: 
   - Wireless LAN (WLAN) is a type of wireless network that allows devices to connect to the internet without using wires. 
   - WLANs use radio waves to transmit data between devices. 
   - They can be set up in public places like airports, coffee shops, and libraries to provide internet access to users.

2. MAC issues: 
   - The MAC (Media Access Control) layer is responsible for controlling access to the wireless network. 
   - The main MAC issues in WLANs are collisions and hidden terminals. 
   - Collisions occur when multiple devices try to transmit data at the same time, causing data loss. 
   - Hidden terminals occur when two devices cannot hear each other, causing interference in data transmission.

3. IEEE 802.11: 
   - IEEE 802.11 is a set of standards for WLANs. 
   - It defines the specifications for wireless communication, including data rates, frequency bands, and encryption. 
   - The most common standard is 802.11b, which uses the 2.4 GHz frequency band and provides data rates up to 11 Mbps.

4. Bluetooth: 
   - Bluetooth is a wireless technology used for short-range communication between devices. 
   - It is commonly used for connecting devices like smartphones, headphones, and speakers. 
   - Bluetooth uses low-power radio waves to transmit data between devices over short distances.

5. Wireless in Mobile Computing: 
   - Wireless networking plays a crucial role in mobile computing. 
   - It allows users to access the internet and communicate with other devices on the go. 
   - WLANs and Bluetooth are two of the most common wireless technologies used in mobile computing.

Some tips and tricks to remember the information covered in this unit are:

- For MAC issues, remember that collisions occur when multiple devices try to transmit data at the same time, while hidden terminals occur when two devices cannot hear each other.
- To remember the IEEE 802.11 standard, you could think of the number 11 as the data rate in Mbps for the most common standard, 802.11b.
- To remember Bluetooth's use cases, think of it as a technology commonly used for connecting devices like smartphones, headphones, and speakers.
