### Basics of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the process of creating a virtual version of a physical device, operating system, network, or storage, which can be used to run multiple operating systems and applications on a single physical server.

The main components of a virtualization system are:

1. Hypervisor: This is the software layer that runs on the physical server and manages the virtualization environment.

2. Virtual Machines (VMs): These are the virtual versions of physical devices, operating systems, networks, or storage, that run on the hypervisor.

3. Virtual Network: This is the virtual version of a physical network, which allows virtual machines to communicate with each other and with the physical network.

4. Virtual Storage: This is the virtual version of physical storage, which allows virtual machines to access and use shared storage resources.

Virtualization provides many benefits, including:

1. Increased resource utilization: Virtualization allows multiple operating systems and applications to run on a single physical server, which increases the utilization of physical resources.

2. Improved scalability: Virtualization allows you to easily add or remove virtual machines as needed, which makes it easier to scale your resources up or down.

3. Improved availability: Virtualization provides a high level of availability by allowing virtual machines to be migrated to other physical servers in the event of a hardware failure.

In conclusion, virtualization is the process of creating a virtual version of a physical device, operating system, network, or storage, which can be used to run multiple operating systems and applications on a single physical server. The main components of a virtualization system are the hypervisor, virtual machines, virtual network, and virtual storage, and virtualization provides many benefits, including increased resource utilization, improved scalability, and improved availability.
