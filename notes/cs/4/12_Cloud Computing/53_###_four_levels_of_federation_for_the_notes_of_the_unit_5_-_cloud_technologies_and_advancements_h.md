### Four Levels of Federation for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

1. Level 1: Standalone Hadoop Cluster
- Single node setup for testing and development purposes 
- No resource sharing or data sharing across nodes

2. Level 2: Pseudo-Distributed Hadoop Cluster
- Single node setup that acts as both master and worker node
- Simulates a multi-node cluster for testing and development purposes 

3. Level 3: Fully Distributed Hadoop Cluster
- Multiple nodes across a network 
- Nodes can be dedicated master and worker nodes or a combination of both 
- Resource and data sharing across nodes 

4. Level 4: Federated Hadoop Cluster
- Multiple fully distributed Hadoop clusters 
- Resource and data sharing across clusters 
- Load balancing and failover capabilities 
- Used for large scale data processing and storage.
