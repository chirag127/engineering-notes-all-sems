### REST and Systems of Systems for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

REST:

REST (Representational State Transfer) is a software architectural style used for designing web services. It is based on the HTTP protocol and defines a set of constraints and best practices for creating scalable and reliable web services.

The main features of REST include:

1. Client-server architecture: REST divides the application into two parts, the client and the server, which communicate with each other using HTTP.

2. Statelessness: REST does not maintain any state between requests, meaning that each request is independent and contains all the information necessary to complete the request.

3. Cacheability: REST allows for caching of responses, which can improve performance and reduce server load.

4. Layered system: REST allows for the use of intermediaries, such as proxy servers and load balancers, between the client and the server, which can improve scalability and security.

Systems of Systems:

Systems of Systems (SoS) refers to a collection of independent systems that work together to achieve a common goal. SoS is used to design complex systems, such as cloud computing systems, that require the integration of multiple systems and technologies.

The main characteristics of SoS include:

1. Decentralization: SoS is designed to be decentralized, meaning that each system operates independently and makes its own decisions.

2. Interoperability: SoS is designed to allow systems to communicate and exchange data with each other, allowing for the integration of multiple systems and technologies.

3. Scalability: SoS is designed to be scalable, allowing for the addition of new systems and technologies as needed.

4. Flexibility: SoS is designed to be flexible, allowing for changes to be made to individual systems without affecting the entire system.

In conclusion, REST is a software architectural style used for designing web services, based on the HTTP protocol and defined by constraints and best practices for creating scalable and reliable web services. Systems of Systems (SoS) refers to a collection of independent systems that work together to achieve a common goal, characterized by decentralization, interoperability, scalability, and flexibility.
