### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Here's a summary of the key points for Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in Cloud Computing:

1. Service Oriented Architecture (SOA) is a design pattern for software architecture that enables integration of multiple, independent services to form a complete application.

2. SOA allows for loose coupling between services, meaning that changes to one service do not affect the others.

3. SOA enables scalability, as services can be added or removed as needed without affecting the overall system.

4. SOA is a key enabler for cloud computing, as it enables the creation of scalable, flexible, and reusable services that can be deployed in the cloud.

5. Web services, such as SOAP and REST, are commonly used to implement SOA in cloud computing.

6. Service Registry and Repository (SRR) is a central repository that stores information about available services and their interfaces, enabling discovery and integration of services.

7. Service Level Agreements (SLA) are contracts between service providers and consumers that define the level of service to be provided and the responsibilities of each party.

8. Service Oriented Architecture is a key aspect of cloud computing and is critical for enabling the development of scalable, flexible, and reusable cloud services.
