
### Resource Provisioning Methods for the Notes of Unit 4 - Resource Management and Security in Cloud Computing

1. **Dynamic Provisioning**: This method allows for the automatic provisioning of resources based on user demand. It is a fast and efficient way of providing resources, as the resources are allocated as soon as the user requests them.

2. **Static Provisioning**: This method requires manual intervention to provision resources. It is a slower process, but it allows for more control over the resources that are allocated.

3. **On-Demand Provisioning**: This method allows for the allocation of resources on an as-needed basis. It is a more cost-effective option, as the user does not need to pay for resources that are not being used.

4. **Reservation-Based Provisioning**: This method allows for the reservation of resources in advance. It is a more secure option, as the user is guaranteed to have access to the resources when they need them.

5. **Hybrid Provisioning**: This method allows for the combination of different provisioning methods. It is a flexible option, as the user can choose the best method for their particular needs.
