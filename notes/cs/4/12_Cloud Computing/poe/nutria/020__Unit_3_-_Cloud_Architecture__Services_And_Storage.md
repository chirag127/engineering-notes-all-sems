

## Unit 3 - Cloud Architecture, Services And Storage

1. Cloud architecture refers to the components and sub-components that are required to build a cloud computing system. It includes the hardware, software, networks, storage, and services that are necessary to provide cloud computing services. 

2. Cloud services are the applications, tools, and services that are provided through the cloud. These services can be used to store data, run applications, and provide access to resources. Examples of cloud services include Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and Software as a Service (SaaS). 

3. Cloud storage is a service that provides users with the ability to store and access data in the cloud. Cloud storage can be used to store pictures, videos, documents, and other types of data. It is a cost-effective solution for businesses and individuals who need to store large amounts of data. 

4. Cloud security is the practice of protecting data and applications stored in the cloud from unauthorized access. Cloud security includes measures such as encryption, authentication, and access control to ensure that only authorized users can access the data. 

5. Cloud computing is a model for delivering computing services over the internet. It allows users to access applications, software, and storage without having to maintain the underlying infrastructure. This makes it easier for businesses and individuals to access the resources they need without having to invest in their own hardware and software.
