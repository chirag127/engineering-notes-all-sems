
### REST and Systems of Systems

* Representational State Transfer (REST) is an architectural style that enables communication between systems over the internet. It is based on the HTTP protocol and makes use of the existing infrastructure of the web.
* A system of systems (SoS) is a collection of distinct, yet interconnected, systems that work together to achieve a common goal. SoSs are often used in the context of cloud-enabled technologies, such as distributed computing, cloud storage, and service-oriented architectures (SOAs).
* Service-oriented architectures (SOAs) are designed to provide a platform for applications to interact with each other. This allows for the creation of distributed applications that can be scaled and managed more easily.
* Cloud-enabled technologies are those that make use of cloud computing services, such as Infrastructure-as-a-Service (IaaS), Platform-as-a-Service (PaaS), and Software-as-a-Service (SaaS), to deliver their services.
* REST and SoSs are two important concepts in cloud computing. REST provides a way for applications to communicate with each other over the internet, while SoSs allow for the creation of distributed applications that can be managed more efficiently. Together, they provide the foundation for cloud-enabled technologies.
