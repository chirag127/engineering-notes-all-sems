
### Virtualization Support and Disaster Recovery 

1. Virtualization is a technology that allows a single physical server to be divided into multiple isolated virtual environments. This enables multiple applications and operating systems to be run on the same physical server. 

2. Disaster recovery is the process of restoring data and applications in the event of a system failure or data loss. It ensures the continuity of the business operations and the protection of data. 

3. Cloud enabling technologies such as virtualization and disaster recovery can be used to create a Service Oriented Architecture (SOA). SOA is a model for designing and deploying distributed applications and services. 

4. Virtualization can be used to create multiple virtual machines on a single physical server. This allows for the isolation of applications, as well as the ability to quickly deploy and manage applications. 

5. Disaster recovery plans can be used to protect data in the event of a system failure or data loss. This includes the backup and restoration of data, as well as the ability to quickly recover from a system failure.

6. Service Oriented Architecture can be used to create a distributed application architecture. This allows applications to be easily deployed, managed, and scaled across multiple physical and virtual servers. 

7. Virtualization and disaster recovery can be used together to create a robust and resilient cloud architecture. This allows for the efficient deployment and management of applications and services, as well as the protection of data in the event of a system failure.
