
### Publish, Subscribe Model for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1. The Publish-Subscribe Model is a messaging pattern wherein a sender (publisher) sends a message to a topic (channel).
2. Subscribers receive the message from the topic, to which they have subscribed.
3. In the context of Cloud Computing, Publish-Subscribe Model enables service-oriented architecture (SOA) by enabling services to communicate with each other in an asynchronous manner.
4. It provides a loose coupling between services, allowing them to communicate without the need for direct interaction.
5. Publish-Subscribe Model is a powerful communication pattern that enables scalability, availability, and reliability of services.
6. The Publish-Subscribe Model is used in a variety of distributed systems, such as distributed databases, distributed file systems, and distributed object systems.
7. In the context of Cloud Computing, the Publish-Subscribe Model can be used to enable services to interact with each other without the need for direct interaction.
8. The Publish-Subscribe Model is also used to enable services to scale, as it allows for the distribution of workloads across multiple machines.
9. The Publish-Subscribe Model is also used to enable services to be reliable, as messages are sent reliably and consistently.
10. The Publish-Subscribe Model is also used to enable services to be available, as messages are sent to the appropriate subscribers in a timely manner.
