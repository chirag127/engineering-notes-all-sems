
## Unit 5 - Cloud Technologies And Advancements Hadoop

1. Hadoop is an open-source software framework that is used for distributed storage and processing of large datasets. It is based on the MapReduce programming model and is designed to scale up from a single server to thousands of computers.

2. Hadoop enables applications to work with thousands of nodes and petabytes of data. It provides a distributed file system (HDFS) which stores data across multiple nodes in the cluster. It also provides a resource management system (YARN) which allows applications to run on the cluster and to manage resources.

3. Hadoop is designed to be fault tolerant and highly available. It has the ability to detect and handle failures at the application layer. This makes it suitable for applications that require high availability and reliability.

4. Hadoop also provides a number of additional tools and libraries which can be used to build distributed applications. These include Hive, Pig, and Spark. These tools and libraries provide a wide range of capabilities including data processing, machine learning, and streaming.

5. Hadoop is widely used in many industries including finance, healthcare, retail, and media. It is used to process large datasets and to provide insights into customer behavior, market trends, and other business-critical information.
