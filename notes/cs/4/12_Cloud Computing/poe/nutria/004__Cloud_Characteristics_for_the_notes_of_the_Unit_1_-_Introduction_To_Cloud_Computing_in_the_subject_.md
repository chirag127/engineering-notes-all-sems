
### Cloud Characteristics

1. On-demand self-service: Cloud computing allows users to access services and resources quickly, without manual intervention from the provider.

2. Broad network access: Cloud services can be accessed from anywhere in the world, as long as there is an internet connection.

3. Resource pooling: Cloud providers pool resources from multiple users, so that resources can be shared among multiple users.

4. Rapid elasticity: Cloud services can be scaled up or down quickly to meet the needs of the user.

5. Measured service: Cloud providers measure the usage of resources, so that users only pay for the resources they use.
