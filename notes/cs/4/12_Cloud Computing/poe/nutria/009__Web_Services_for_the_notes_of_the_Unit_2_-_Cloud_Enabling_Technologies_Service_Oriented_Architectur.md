
### Web Services for the Notes of Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the Subject of Cloud Computing

* Web services are application components that enable communication between two or more applications over the internet.
* Web services are based on the concept of Service Oriented Architecture (SOA), which is a distributed computing architecture that structures applications into services.
* SOA enables applications to be built from reusable components that can be accessed over the internet.
* Web services use open standards such as XML, SOAP, and WSDL to communicate and exchange data between applications.
* Web services can be used to enable the creation of distributed applications that are accessible from any device or platform.
* Web services enable companies to create applications that can be accessed from anywhere, and can be used to integrate multiple applications into a single system.
* Web services are used to enable cloud computing, where applications and services can be accessed and used over the internet.
