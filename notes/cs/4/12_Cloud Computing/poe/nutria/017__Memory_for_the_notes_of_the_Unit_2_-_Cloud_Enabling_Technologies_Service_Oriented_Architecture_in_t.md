
### Memory for the Notes of Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the Subject of Cloud Computing

1. Service-Oriented Architecture (SOA) is an architectural paradigm that enables the construction of distributed applications by means of services.

2. SOA is based on the concept of services, which are self-contained units of functionality that can be composed into larger applications.

3. Services are independently deployable and can be used in a variety of ways, including web services, web applications, and mobile applications.

4. SOA enables the integration of different applications and systems, as well as the reuse of existing services and applications.

5. SOA is based on the principles of loose coupling and service-oriented design, which allow for the development of applications that are more resilient, flexible, and easier to maintain.

6. SOA also enables the development of applications that are more secure, as services are independent of each other and can be tested and deployed independently.

7. SOA is an important enabler of cloud computing, as it provides the necessary infrastructure for the deployment and management of cloud services.
