### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

In this unit, we learned about Service Oriented Architecture (SOA) and its role in enabling cloud computing technologies. Here are the key points to remember:

1. SOA is an architectural style that uses services as its fundamental building blocks. These services are self-contained, modular, and loosely coupled, which makes them easy to develop, deploy, and maintain.

2. Cloud computing is a model for delivering computing resources over the internet. It provides on-demand access to a shared pool of configurable computing resources, including servers, storage, networks, and applications.

3. SOA and cloud computing are closely related because SOA provides a service-based approach to building cloud applications. By using SOA principles, developers can create cloud services that are scalable, flexible, and reusable.

4. SOA services can be accessed over the internet using standard protocols such as HTTP, SOAP, and REST. This makes them interoperable and accessible from any platform or device.

5. SOA services can be composed and orchestrated to create complex business processes that span multiple services and systems. This enables organizations to automate their business processes and improve their efficiency and agility.

6. SOA services can be deployed in different environments, including on-premises, in the cloud, or in a hybrid model. This provides organizations with flexibility and choice in how they deploy and manage their services.

7. SOA services can be secured using standard security protocols such as SSL, OAuth, and SAML. This ensures that services are protected from unauthorized access and that data is kept confidential and secure.

By understanding these key points, you will be able to appreciate the importance of Service Oriented Architecture in enabling cloud computing technologies. You will also be able to apply these principles to design and develop your own cloud applications using SOA.
