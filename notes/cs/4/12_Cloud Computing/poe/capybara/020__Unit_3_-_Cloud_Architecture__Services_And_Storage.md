## Unit 3 - Cloud Architecture, Services And Storage

Cloud computing has become an essential part of modern businesses. In this unit, we will learn about cloud architecture, services, and storage.

### Cloud Architecture

Cloud architecture refers to the design of cloud computing systems. It includes various components such as servers, storage, networks, and software that work together to deliver cloud services. Some of the essential features of cloud architecture are:

- Scalability: Cloud architecture must be designed to handle the dynamic workload of users.
- High availability: Cloud services must be available 24/7, and the architecture must be designed to minimize downtime.
- Fault-tolerance: The system must be designed to tolerate hardware and software failures.
- Security: Cloud architecture must be designed to protect data and prevent unauthorized access.

### Cloud Services

Cloud services are the services provided by cloud computing platforms. These services can be categorized into three types:

- Infrastructure as a Service (IaaS): IaaS provides virtualized computing resources such as servers, storage, and networks.
- Platform as a Service (PaaS): PaaS provides a platform for developing, testing, and deploying applications.
- Software as a Service (SaaS): SaaS provides software applications that are accessible through the internet.

Some of the popular cloud services are:

- Amazon Web Services (AWS): Provides IaaS, PaaS, and SaaS services.
- Microsoft Azure: Provides IaaS and PaaS services.
- Google Cloud Platform: Provides IaaS and PaaS services.

### Cloud Storage

Cloud storage is a service that allows users to store and retrieve data from remote servers. It provides several benefits such as:

- Scalability: Users can easily increase or decrease their storage capacity based on their needs.
- Cost-effectiveness: Cloud storage is relatively cheaper than traditional storage methods.
- Accessibility: Users can access their data from anywhere and any device with an internet connection.
- Data security: Cloud storage providers use various security measures to protect user data.

Some of the popular cloud storage services are:

- Google Drive: Provides free storage for personal users and paid plans for businesses.
- Dropbox: Provides free and paid plans for personal and business users.
- OneDrive: Provides free storage for personal users and paid plans for businesses.

In conclusion, cloud computing is a complex system with various components and services. Understanding cloud architecture, services, and storage is essential for businesses that want to leverage the benefits of cloud computing.
