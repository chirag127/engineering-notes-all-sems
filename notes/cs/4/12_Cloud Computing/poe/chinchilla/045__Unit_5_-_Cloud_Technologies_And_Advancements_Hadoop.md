## Unit 5 - Cloud Technologies And Advancements Hadoop

In this unit, we will learn about Cloud Technologies and Advancements in Hadoop. Here are the key points to remember:

### Cloud Technologies

1. Cloud Computing: It is a model of providing on-demand access to a shared pool of configurable computing resources such as servers, storage, applications, and services.

2. Cloud Deployment Models: Cloud deployment models are the ways in which cloud computing resources are provisioned to users. The three deployment models are:

   * Public Cloud: It is a cloud infrastructure that is open for use by the public.
   
   * Private Cloud: It is a cloud infrastructure that is dedicated to a single organization.
   
   * Hybrid Cloud: It is a combination of both public and private clouds.

3. Cloud Service Models: Cloud service models define the level of control and responsibility that users have over the cloud resources they use. The three service models are:

   * Infrastructure as a Service (IaaS): It provides users with access to virtualized computing resources like servers, storage, and networking.
   
   * Platform as a Service (PaaS): It provides users with a complete development and deployment environment, including application development tools, databases, and web servers.
   
   * Software as a Service (SaaS): It provides users with access to pre-built software applications that run on the cloud.

### Advancements in Hadoop

1. Hadoop: It is an open-source software framework used for distributed storage and processing of big data.

2. Hadoop Components: The main components of Hadoop are:

   * Hadoop Distributed File System (HDFS): It is a distributed file system that provides scalable and reliable storage for big data.
   
   * MapReduce: It is a programming model used for processing large amounts of data in parallel across a large cluster of computers.
   
   * YARN: It is a resource management system that manages resources in a Hadoop cluster.

3. Advancements in Hadoop: Hadoop has evolved over the years, and the advancements in Hadoop include:

   * Hadoop 2.0: It introduced YARN, which improved the processing capabilities of Hadoop.
   
   * Hadoop 3.0: It introduced improvements in resource management, security, and performance.
   
   * Hadoop Distributed Data Store (HDDS): It is a distributed data store that provides scalable and reliable storage for big data.
   
   * Hadoop Data Lake: It is a centralized repository that stores all types of data in its native format, making it easier to access and analyze.
   
   * Hadoop Streaming: It is a feature that allows users to write MapReduce programs in any programming language, making it easier for developers to work with Hadoop. 

These are the key points to remember about Cloud Technologies and Advancements in Hadoop. By understanding these concepts, you will be able to gain a better understanding of how cloud computing and Hadoop can be used to store, process, and analyze big data.
