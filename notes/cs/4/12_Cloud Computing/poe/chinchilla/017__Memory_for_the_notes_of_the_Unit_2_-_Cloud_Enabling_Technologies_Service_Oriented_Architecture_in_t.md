### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

In the Unit 2 of Cloud Enabling Technologies, we learned about Service Oriented Architecture (SOA) and its role in cloud computing. Here are some important points to remember:

1. SOA is a software architecture that allows different applications to communicate with each other by exposing their functionalities as services.
2. SOA promotes loose coupling between services, making it easy to modify or replace a service without affecting the other services.
3. The key components of SOA are services, service consumers, service providers, service registry, and service bus.
4. Services are self-contained, modular, and reusable software components that expose their functionalities as interfaces.
5. Service consumers are the applications that use the services provided by the service providers.
6. Service providers are the applications that provide the services to the service consumers.
7. Service registry is a directory of available services and their metadata, such as their interfaces, endpoints, and security policies.
8. Service bus is a middleware that facilitates communication between services by routing messages between them.
9. SOA can be implemented using different technologies, such as SOAP, REST, and XML.
10. SOAP (Simple Object Access Protocol) is a protocol for exchanging structured messages over the internet using XML.
11. REST (Representational State Transfer) is an architectural style for building web services that uses HTTP verbs to perform CRUD (Create, Read, Update, Delete) operations on resources.
12. XML (Extensible Markup Language) is a markup language that is used to encode data in a format that is both human-readable and machine-readable.
13. SOA has several advantages, such as reusability, flexibility, scalability, and interoperability.
14. SOA also has some challenges, such as service discovery, service composition, service orchestration, and service security.
15. SOA can be used in various cloud computing scenarios, such as Software as a Service (SaaS), Platform as a Service (PaaS), and Infrastructure as a Service (IaaS).

Remembering these key points will help you understand the fundamentals of Service Oriented Architecture and its role in cloud computing. Good luck with your studies!
