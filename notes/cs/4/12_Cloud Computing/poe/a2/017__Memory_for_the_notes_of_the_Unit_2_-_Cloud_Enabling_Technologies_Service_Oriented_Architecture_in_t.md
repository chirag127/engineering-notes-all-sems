### Memory for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1.  Service Oriented Architecture (SOA) - It is a style of software design where applications are built as a set of services that can be used within multiple separate systems. Services communicate with each other by passing data from one service to another, or by coordinating an activity between two or more services.
2.  Loose Coupling - Services in a SOA are loosely coupled, meaning that they interact through well-defined interfaces and are designed to minimize dependencies on the internal structure or implementation of other services. This loose coupling allows services to be developed, deployed, and scaled independently of one another.
3.  Reusability - The services in a SOA are designed to be reusable for other applications. This increases efficiency and reduces duplication of effort.
4.  Interoperability - The services in a SOA use standard formats and protocols to exchange data, which allows services to work together even if they are developed using different technologies or platforms.
5.  Discovery - For services to interact, they must be able to find each other. Service discovery mechanisms are used to locate available services.
6.  Composition - Services can be combined and recombined in different ways to build composite applications that meet new or changing business requirements. New applications can be created by reusing and remixing existing services.
7.  Enterprise Service Bus (ESB) - ESB is a software architecture model used for integrating multiple applications or services. It acts as a central point of communication and manages interactions between software applications.
