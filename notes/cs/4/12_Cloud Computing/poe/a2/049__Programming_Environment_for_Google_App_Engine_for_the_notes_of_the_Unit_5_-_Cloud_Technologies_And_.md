### Programming Environment for Google App Engine

- Google App Engine supports applications written in several programming languages:
- Python - Support for Python 2.7 and Python 3.7
- Java - Support for Java 7 and Java 8
- Go
- PHP
- Ruby

The programming environment provides:

- A scalable infrastructure - Google's infrastructure automatically scales to support sudden increases in traffic.
- APIs - Provide access to services for Memcache, users, files, and more.
- Limits - There are limits on CPU usage, storage, bandwidth, and other resources to ensure applications perform well and do not impact other applications.
- Sandboxed environment - Applications run in a secure sandbox and do not have direct access to the underlying operating system.
- Libraries - Provide client libraries to simplify accessing App Engine services from your chosen language.

The notes aim to help learn and understand the programming environment and key aspects of developing applications for deployment on Google App Engine as part of learning Cloud Computing concepts. The points cover the supported programming languages, key features of the environment, and constraints to keep in mind while building applications.
