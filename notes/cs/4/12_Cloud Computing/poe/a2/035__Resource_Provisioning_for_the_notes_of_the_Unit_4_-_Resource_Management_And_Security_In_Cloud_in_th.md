### Resource Provisioning for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

1. Resource Provisioning: The allocation of resources such as CPU, memory, storage, and network to the applications or services as and when required is known as resource provisioning. In cloud computing, resources are provisioned on-demand whenever the user requests for them.

2. Types of Resource Provisioning: There are two types of resource provisioning:

- Static Provisioning: Resources are allocated in advance and remain reserved for the user even if they are not being utilized. This leads to wastage of resources.
- Dynamic Provisioning: Resources are allocated on-demand as and when required and can be reclaimed when not in use. This efficient utilization of resources and cost-effective as the user is charged only for the resources used.

3. Resource Provisioning in Cloud: In cloud computing, resource provisioning is the key as resources are provisioned on-demand based on user requirements. The tasks involved in resource provisioning in cloud are:

- Resource Monitoring: Constantly monitoring resource utilization and availability.
- Resource Discovery: Discovering available resources in the data center that can be provisioned.
- Resource Matching: Matching user requirements with the available resources.
- Resource Allocation: Appropriately allocating resources to the user based on requirements.
- Resource Configuration: Configuring the allocated resources for the user to use.

4. Resource Provisioning Challenges: Some of the key challenges involved in resource provisioning in cloud computing are:

- Handling workload spikes and fluctuations.
- Achieving performance isolation between applications.
- Energy efficiency and cost optimization.
- Scalability to provision resources for a large number of users and applications.
- Automation to quickly provision and de-provision resources.
