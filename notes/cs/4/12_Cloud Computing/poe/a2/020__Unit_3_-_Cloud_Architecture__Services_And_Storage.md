## Unit 3 - Cloud Architecture, Services And Storage

1. Cloud Architecture:
- Client-server model: User requests resources from the server over the network
- N-tier architecture: Presentation, application, data tiers with security at each level
- Elastic computing: Provision and deprovision resources on demand
- Scalability: Horizontal (scale out) and vertical (scale up) scaling
- High availability: Redundancy and geo-redundancy
- Monitoring: Performance, availability, errors, resource usage, etc.

2. Cloud Services:
- Infrastructure as a Service (IaaS): Virtual machines, storage, networking
- Platform as a Service (PaaS): Managed runtime environment for applications
- Software as a Service (SaaS): Hosted software applications
- Serverless computing: Run code without managing servers
- Databases: SQL and NoSQL databases as services
- Analytics: Analytics and data processing services
- API: Expose cloud services via APIs
- IoT: Connect and manage internet-connected devices

3. Cloud Storage:
- Object storage: Scale vast amounts of unstructured data via objects with metadata
- File storage: Share file data between multiple instances/users
- Block storage: Durable block-level storage for instances
- Encryption at rest and in transit
- Replication and versioning for redundancy and backups
- Performance tiers from hot/fast storage to cold/archive storage
