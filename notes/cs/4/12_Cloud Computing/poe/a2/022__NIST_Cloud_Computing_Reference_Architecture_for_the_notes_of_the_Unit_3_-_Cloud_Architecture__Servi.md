### NIST Cloud Computing Reference Architecture

1. The NIST Cloud Computing Reference Architecture consists of five major layers:

- Cloud consumer layer: The highest layer where the end users access the cloud services.
- Cloud provider layer: The layer where the cloud providers offer cloud services to the consumers.
- Cloud broker layer: The layer which acts as an intermediary between the consumers and providers to aggregate, integrate or customize cloud services.
- Cloud carrier layer: The layer which provides connectivity and delivery of cloud services.
- Cloud resource layer: The lowest layer which encompasses the computing resources.

2. The main components of the reference architecture are:

- Cloud auditor: To evaluate and monitor cloud services and data.
- Cloud carrier: To provide network connectivity and delivery of cloud services.
- Cloud broker: To act as an intermediary between consumers and providers.
- Cloud consumer: To access and use cloud services.
- Cloud provider: To offer cloud-based services to consumers.
- Underlying cloud resources: The computing resources that offer the cloud services.

3. The key characteristics of the reference architecture are:

- On-demand self-service: Consumers can provision computing capabilities on-demand without any human interaction with the provider.
- Broad network access: Capabilities are available over the network and accessed through standard mechanisms.
- Resource pooling: The provider's resources are pooled to serve multiple consumers using a multi-tenant model.
- Rapid elasticity: Capabilities can be elastically provisioned and released to scale rapidly.
- Measured service: Cloud systems automatically control and optimize resource use by leveraging a metering capability.
