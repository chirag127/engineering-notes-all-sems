### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud

1. Identity and Access Management: controlling access to resources is crucial in cloud computing. Authentication and authorization mechanisms are used to control access to resources. Federated identity management is commonly used where users can use their own credentials to access cloud services.
2. Data Security: Data in the cloud needs to be protected from unauthorized access and modification. Encryption is commonly used to protect data at rest and in transit. Data loss prevention mechanisms can be used to prevent unauthorized data exfiltration.
3. Application Security: Web applications in the cloud need to be secured from vulnerabilities like injection flaws, broken authentication, sensitive data exposure, etc. Regular security testing and securing the software development lifecycle is important.
4. Network Security: Cloud platforms need to be protected from network-based threats like DDoS attacks, eavesdropping, man-in-the-middle attacks, etc. VPNs, firewalls, network traffic monitoring and filtering are used to secure networks in the cloud.
5. Governance and Compliance: The growth of cloud adoption has made governance and compliance more complex with multitude of regulations and standards. Processes and tooling need to be put in place to ensure continuous compliance to applicable regulations.

The above points cover the key aspects of security in cloud computing that need to be considered as part of resource management. Strict security controls and monitoring are required to protect resources and data in the cloud.
