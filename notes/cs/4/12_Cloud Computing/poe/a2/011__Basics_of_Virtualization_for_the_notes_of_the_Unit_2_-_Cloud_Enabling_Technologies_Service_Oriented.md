### Basics of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

1. Virtualization is the creation of a virtual version of something, such as a hardware platform, operating system, storage device, or network resources.
2. The core benefit of virtualization is that it allows for more efficient use of system resources by allowing multiple virtual machines to run on the same physical machine.
3. Full virtualization: A VM simulates a full computer system and can run an unmodified guest operating system. The guest OS is decoupled from the host hardware. Example: VMware ESXi, KVM, VirtualBox.
4. Para-virtualization: The guest OS is modified to be virtualization-aware to achieve better performance. The guest OS and hypervisor share the hardware resources. Example: Xen.
5. Operating system-level virtualization: Multiple isolated user space instances are created using OS-level containers. Example: Docker, LXC.
6. Hardware-assisted virtualization: Uses CPU extensions to enhance the performance of virtual machines. Examples: Intel VT-x and AMD-V.
7. Benefits of virtualization: Consolidation, isolation, abstraction, agility, automation, reduced costs.
