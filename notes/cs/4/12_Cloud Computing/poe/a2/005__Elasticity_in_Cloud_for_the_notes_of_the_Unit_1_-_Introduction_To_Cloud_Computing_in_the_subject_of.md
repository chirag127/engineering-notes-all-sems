### Elasticity in Cloud

- Cloud computing provides the ability to scale resources on demand. This is known as elasticity.
- Resources can be scaled up or down as per the requirement. This provides the ability to handle variable loads and peak demands without impacting performance or increasing costs.
- Additional resources can be allocated during peak loads and released when the load decreases. This avoids wastage of resources and optimizes costs.
- The monitoring capabilities of cloud platforms allow automatic scaling based on metrics like CPU utilization, memory usage, etc. This is known as auto-scaling.
- Auto-scaling provides elasticity and high availability without manual intervention. The infrastructure can scale dynamically to meet the needs of the applications.
- Elasticity improves resource utilization and optimizes costs. Resources can be scaled based on actual needs and workloads. Pay-as-you-go billing models charge only for the resources used.
- The on-demand availability of resources in cloud computing enables high scalability and elasticity. There is no need to over-provision resources or wait for procurement and setup.
- Elasticity is one of the key benefits of cloud computing and enables handling of dynamic workloads in a cost-efficient manner.
