### Architectural Design Challenges for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

1. Scalability - The cloud infrastructure must be highly scalable to accommodate increasing workload demands. The cloud services must scale horizontally by adding more instances/nodes and scale vertically by increasing resources of existing instances.
2. Availability - The cloud services must be highly available with minimal downtime. This requires techniques like replication, failover, disaster recovery, etc.
3. Performance - The cloud services must meet certain performance SLAs like latency, throughput, etc. This requires optimizing resource allocation, caching, load balancing, etc.
4. Security - The cloud infrastructure must provide strong security and isolation between different clients using the infrastructure. Authentication, access control, encryption, etc. must be implemented.
5. Interoperability - The cloud services must be interoperable so that clients can use services from multiple cloud providers interchangeably. Standard interfaces and APIs are required to enable this.
6. Portability - The workload must be portable across cloud providers or data centers. This requires open standards and avoidance of proprietary APIs.

The points describe the key architectural challenges in building a robust cloud computing system to host various services and store data. The challenges must be addressed to develop, deploy and manage reliable and efficient cloud services.
