### Inter Cloud Resource Management

- Managing resources across multiple clouds is known as Inter Cloud Resource Management.
- It helps in workload migration, provisioning and scheduling of resources across different cloud providers.
- The key challenges in Inter Cloud Resource Management are:
- Heterogeneous infrastructure and different APIs of cloud providers.
- Performance interference and SLA violations across clouds.
- Security and policy enforcement across multiple administrative domains.
- Cost optimization by selecting most suitable and cost effective cloud for a workload.
- The approaches for Inter Cloud Resource Management are:
- Meta-Schedulers: Abstracts the heterogeneity and provides a single interface for management.
- VM Migration: Migrates VMs between clouds for load balancing or avoiding SLA violations.
- Application Level Scheduling: Considers application dependencies and constraints for scheduling.
- Economic Model based Scheduling: Selects the most cost effective cloud based on workload and pricing models.
- The key benefits of Inter Cloud Resource Management are:
- Increased resource utilization and reduced costs.
- Avoiding vendor lock-in by using multiple cloud providers.
- Mitigating risks of downtime or SLA violations by migrating to alternate clouds.
- Enabling new hybrid cloud applications that utilize resources from multiple clouds.
