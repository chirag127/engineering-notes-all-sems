### I/O Devices for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

I/O Devices:
1. Keyboard: input device used to type text and numbers into a computer.
2. Mouse: an input device used to interact with the graphical user interface.
3. Scanner: an input device used to digitize physical documents or images.
4. Printer: an output device used to produce physical copies of digital documents.
5. Monitor: an output device used to display visual information generated by a computer.
6. Microphone: an input device used to record audio.
7. Speaker: an output device used to play audio.
8. Webcam: an input device used to capture video and still images.
9. Touchscreen: an input device that combines the functions of a monitor and a touchpad.
10. Joystick: an input device used for gaming or controlling industrial equipment.
