### Cloud Storage for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- Cloud storage is a cloud computing model that enables storing data and files on the internet through a cloud computing provider that you access either through the public internet or a dedicated private network connection .
- The provider securely stores, manages, and maintains the storage servers, infrastructure, and network to ensure you have access to the data when you need it at virtually unlimited scale, and with elastic capacity.
- Cloud storage removes the need to buy and manage your own data storage infrastructure, giving you agility, scalability, and durability, with any time, anywhere data access.
- Cloud storage delivers cost-effective, scalable storage. You no longer need to worry about running out of capacity, maintaining storage area networks (SANs), replacing failed devices, adding infrastructure to scale up with demand, or operating underutilized hardware when demand decreases.
- Cloud storage is elastic, meaning you scale up and down with demand and pay only for what you use. It is a way for organizations to save data securely online so that it can be accessed anytime from any location by those with permission .
- Cloud storage uses remote servers to save data, such as files, business data, videos, or images. Users upload data to servers via an internet connection, where it is saved on a virtual machine on a physical server.
- To maintain availability and provide redundancy, cloud providers will often spread data to multiple virtual machines in data centers located across the world. If storage needs increase, the cloud provider will spin up more virtual machines to handle the load.
- Users can access data in cloud storage through an internet connection and software such as web portal, browser, or mobile app via an application programming interface (API).
- Cloud storage is available in four different models: public, private, hybrid, and multicloud .
  - Public cloud storage is a model where an organization stores data in a service provider’s data centers that are also utilized by other companies. Data in public cloud storage is spread across multiple regions and is often offered on a subscription or pay-as-you-go basis.
  - Private cloud storage is a model where an organization utilizes its own servers and data centers to store data within their own network. Alternatively, organizations can deal with cloud service providers to provide dedicated servers and private connections that are not shared by any other organization. Private clouds are typically utilized by organizations that require more control over their data and have stringent compliance and security requirements.
  - Hybrid cloud storage is a mix of private and public cloud storage models. A hybrid cloud storage model allows organizations to decide which data it wants to store in which cloud. Sensitive data and data that must meet strict compliance requirements may be stored in a private cloud while less sensitive data is stored in the public cloud.
  - Multicloud storage is a model where an organization uses multiple cloud storage providers to store data in different locations, regions, or clouds. Multicloud storage can help organizations avoid vendor lock-in, optimize costs, improve performance, and enhance reliability and availability.
- Some of the advantages of cloud storage are  :
  - Cost savings: Cloud storage eliminates the need to purchase, maintain, and upgrade storage hardware and software, reducing capital and operational expenses. Cloud storage also offers flexible pricing models that allow users to pay only for what they use and scale up or down as needed.
  - Scalability: Cloud storage can accommodate any amount of data, from a few gigabytes to petabytes, without requiring users to provision or deprovision storage resources. Cloud storage can also handle spikes in demand and adjust to changing workloads automatically.
  - Availability: Cloud storage ensures that data is always accessible and available, even in the event of a disaster, outage, or failure. Cloud storage providers typically offer high levels of service level agreements (SLAs) that guarantee uptime, durability, and reliability of data.
  - Security: Cloud storage providers use various methods to protect data from unauthorized access, modification, or deletion, such as encryption, authentication, authorization, backup, and replication. Cloud storage also enables users to implement their own security policies and controls, such as encryption keys, access logs, and audit trails.
