# Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

- Service Oriented Architecture (SOA) is a method of software development that uses software components called services to create business applications.
- Each service provides a business capability, and services can also communicate with each other across platforms and languages.
- SOA enables the construction of applications from loosely coupled services that can be easily integrated and reused.
- SOA is a critical technology for cloud computing as it enables the creation of scalable, flexible, and cost-effective applications that can leverage the resources of the cloud .
- SOA also supports the interoperability and portability of applications across different cloud providers and platforms.
- SOA has some similarities with microservices architecture, which is another popular approach for cloud-native applications, but they also have some differences in terms of granularity, governance, and communication patterns.
- SOA uses common interface standards and an architectural pattern so that services can be rapidly incorporated into new applications.
- SOA also follows some principles such as abstraction, reusability, autonomy, discoverability, and composability.
