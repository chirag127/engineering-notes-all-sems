### NIST Cloud Computing Reference Architecture for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- The NIST Cloud Computing Reference Architecture (NIST CCRA) is a document published by the National Institute of Standards and Technology (NIST) in 2011 that provides a framework and a common vocabulary for describing, comparing, and analyzing cloud computing services and offerings.
- The NIST CCRA is based on the NIST definition of cloud computing, which identifies five essential characteristics (on-demand self-service, broad network access, resource pooling, rapid elasticity, and measured service), three service models (software as a service, platform as a service, and infrastructure as a service), and four deployment models (private cloud, community cloud, public cloud, and hybrid cloud).
- The NIST CCRA consists of five major components: cloud consumer, cloud provider, cloud auditor, cloud broker, and cloud carrier. Each component represents a stakeholder or an entity that participates in the cloud ecosystem and performs a specific function or role.
- The cloud consumer is the entity that uses the cloud services provided by the cloud provider. The cloud consumer can be an individual, an organization, or a software application. The cloud consumer interacts with the cloud provider through a set of interfaces, such as web portals, application programming interfaces (APIs), or command-line tools.
- The cloud provider is the entity that provides the cloud services to the cloud consumer. The cloud provider can be a public or a private organization that owns and operates the cloud infrastructure and resources. The cloud provider offers different types of cloud services, such as SaaS, PaaS, and IaaS, and manages the service level agreements (SLAs) with the cloud consumer.
- The cloud auditor is the entity that conducts independent assessments of the cloud services, operations, performance, and security of the cloud provider. The cloud auditor can be a third-party organization or a government agency that verifies the compliance of the cloud provider with the relevant standards, regulations, and best practices. The cloud auditor provides audit reports and recommendations to the cloud consumer and the cloud provider.
- The cloud broker is the entity that acts as an intermediary between the cloud consumer and the cloud provider. The cloud broker can provide various services, such as cloud service selection, cloud service aggregation, cloud service integration, and cloud service arbitrage. The cloud broker helps the cloud consumer to find the best cloud service that meets their requirements and preferences, and facilitates the negotiation and management of the cloud service contracts.
- The cloud carrier is the entity that provides the connectivity and transport of cloud services between the cloud consumer and the cloud provider. The cloud carrier can be a network service provider, a telecommunication company, or an internet service provider (ISP) that offers the network infrastructure and bandwidth for accessing the cloud services. The cloud carrier ensures the quality of service (QoS) and the security of the data transmission.
- The NIST CCRA also defines a set of reference scenarios that illustrate the interactions and activities among the components in different cloud service and deployment models. The reference scenarios provide examples of how the cloud consumer, the cloud provider, the cloud auditor, the cloud broker, and the cloud carrier can work together to achieve the cloud computing objectives.
- The NIST CCRA is not a prescriptive or a normative standard, but rather a descriptive and an informative guide that can help the cloud stakeholders to communicate and understand the cloud computing concepts and issues. The NIST CCRA can also serve as a basis for developing more specific and detailed cloud architectures and taxonomies for different domains and applications.
