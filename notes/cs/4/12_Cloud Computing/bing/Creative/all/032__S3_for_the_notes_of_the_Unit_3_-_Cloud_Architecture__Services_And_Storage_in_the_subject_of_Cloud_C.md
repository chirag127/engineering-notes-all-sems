### S3 for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- S3 stands for Simple Storage Service, and it is a cloud storage service offered by Amazon Web Services (AWS)  .
- S3 is an object storage service, which means that it stores data as objects, each with a unique identifier, metadata, and data . Objects are organized into buckets, which are containers for objects that share common properties .
- S3 offers different storage classes for different use cases, such as frequent access, infrequent access, archive, and intelligent tiering . Each storage class has different pricing, performance, durability, and availability characteristics .
- S3 has various features for managing, securing, and analyzing data, such as lifecycle policies, object lock, replication, batch operations, encryption, access control, and query-in-place  .
- S3 can be used for a range of applications, such as data lakes, websites, mobile apps, backup and restore, archive, enterprise applications, IoT devices, and big data analytics  .

#### Mnemonics and learning tricks

- To remember the name of S3, think of the three S's: Simple, Storage, Service.
- To remember the difference between object storage and block storage, think of how objects are like files with metadata, while blocks are like chunks of data without metadata.
- To remember the different storage classes of S3, think of the acronym SSSOGI: Standard, Standard-IA, One Zone-IA, Glacier Instant Retrieval, Glacier Flexible Retrieval, Glacier Deep Archive, Intelligent-Tiering.
- To remember the features of S3, think of the acronym LORBEAQ: Lifecycle, Object Lock, Replication, Batch Operations, Encryption, Access Control, Query-in-place.
