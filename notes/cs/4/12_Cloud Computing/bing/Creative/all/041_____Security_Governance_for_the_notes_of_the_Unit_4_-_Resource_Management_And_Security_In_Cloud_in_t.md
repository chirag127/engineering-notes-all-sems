# Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security governance in cloud computing is a framework of policies designed to dictate what cloud resources can be used, how they should be used, and who can use them.
- Security governance also enforces rules governing how individual resources should be secured to prevent their misuse by malicious actors.
- Security governance bridges the business priorities with technical implementation like architecture, standards, and policy.
- Security governance provides oversight and monitoring to sustain and improve security posture over time.
- Security governance also reports compliance as required by regulating bodies.
- Security governance in cloud computing is based on five disciplines: cost management, security baseline, resource consistency, identity baseline, and deployment acceleration.
- Cost management involves developing policies for cost control for all cloud platforms.
- Security baseline involves establishing security requirements and applying them across network, data, and asset configurations.
- Resource consistency involves defining and enforcing standards for resource naming, tagging, and organization.
- Identity baseline involves managing access and permissions for cloud resources and users.
- Deployment acceleration involves automating and streamlining the deployment of cloud resources and services.
- Security governance in cloud computing requires a collaborative approach among different stakeholders, such as cloud providers, cloud consumers, cloud brokers, and cloud auditors.
- Security governance in cloud computing also requires a continuous process of assessment, review, and improvement to adapt to the changing cloud environment and business needs.
