## Unit 1 - Introduction To Cloud Computing

Cloud computing is a model for enabling ubiquitous, convenient, on-demand network access to a shared pool of configurable computing resources (e.g., networks, servers, storage, applications, and services) that can be rapidly provisioned and released with minimal management effort or service provider interaction.

Some of the benefits of cloud computing are:

- Cost: Cloud computing eliminates the capital expense of buying hardware and software and setting up and running on-site datacenters.
- Speed: Cloud computing services are provided self service and on demand, so even vast amounts of computing resources can be provisioned in minutes, typically with just a few mouse clicks.
- Global scale: Cloud computing services can scale elastically, delivering the right amount of IT resources when and where they are needed.
- Productivity: Cloud computing removes the need for many IT management tasks, such as hardware setup, software patching, and other chores, allowing IT teams to focus on more important business goals.
- Performance: Cloud computing services run on a worldwide network of secure datacenters, which are regularly upgraded to the latest generation of fast and efficient computing hardware, reducing network latency and increasing economies of scale.
- Reliability: Cloud computing makes data backup, disaster recovery, and business continuity easier and less expensive, as data can be mirrored at multiple redundant sites on the cloud provider's network.
- Security: Cloud computing services offer a broad set of policies, technologies, and controls that help protect data, applications, and infrastructure from potential threats.

There are different types of cloud computing, depending on the type of cloud deployment and the type of cloud service.

The type of cloud deployment refers to where the cloud infrastructure is located and who has access to it. There are three main types of cloud deployment:

- Public cloud: The cloud infrastructure is owned and operated by a third-party cloud service provider (or CSP), who delivers cloud services over the internet. Public cloud services are available to anyone who wants to use them, and customers share the same pool of resources. Examples of public cloud providers are Microsoft Azure, Amazon Web Services, and Google Cloud Platform.
- Private cloud: The cloud infrastructure is owned and operated by a single organization, who delivers cloud services over a private network. Private cloud services are available only to authorized users within the organization, and customers have more control and customization over the resources. Examples of private cloud providers are IBM Cloud Private, VMware Cloud Foundation, and Oracle Cloud Infrastructure.
- Hybrid cloud: The cloud infrastructure is a combination of public and private clouds, who deliver cloud services over both public and private networks. Hybrid cloud services are available to both internal and external users, and customers can move workloads and data between the clouds as needed. Examples of hybrid cloud providers are Microsoft Azure Stack, AWS Outposts, and Google Anthos.

The type of cloud service refers to what kind of computing resources are delivered by the cloud provider. There are three main types of cloud service:

- Infrastructure as a service (IaaS): The cloud provider delivers the basic computing resources, such as servers, storage, networking, and operating systems. Customers can rent these resources on demand and pay only for what they use. Customers have full control over the configuration and management of the resources, and can run any applications or services on them. Examples of IaaS providers are Microsoft Azure, Amazon EC2, and Google Compute Engine.
- Platform as a service (PaaS): The cloud provider delivers the computing resources, as well as the tools and platforms for developing, testing, and deploying applications and services. Customers can use these tools and platforms to create and run their own applications and services, without worrying about the underlying infrastructure. Customers pay only for the resources and tools they use. Examples of PaaS providers are Microsoft Azure App Service, AWS Elastic Beanstalk, and Google App Engine.
- Software as a service (SaaS): The cloud provider delivers the applications and services, as well as the computing resources to run them. Customers can access these applications and services over the internet, usually through a web browser or a mobile app. Customers pay only for the applications and services they use, and do not have to install or maintain anything. Examples of SaaS providers are Microsoft Office 365, Salesforce, and Gmail.

A mnemonic to remember the types of cloud service is:

- IaaS: You manage everything except the infrastructure.
- PaaS: You manage only the application and data.
- SaaS: You manage nothing.
