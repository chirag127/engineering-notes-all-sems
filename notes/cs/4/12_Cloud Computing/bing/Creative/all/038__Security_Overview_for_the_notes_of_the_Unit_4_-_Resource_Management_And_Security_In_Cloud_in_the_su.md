### Security Overview for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Resource management is the process of allocating computing, storage, networking and energy resources to the cloud applications and services in an efficient and optimal way.
- Resource management involves the following aspects:
  - Resource provisioning: the process of assigning resources to the cloud applications and services based on their requirements and SLAs.
  - Resource scheduling: the process of determining the order and timing of executing the cloud applications and services on the allocated resources.
  - Resource monitoring: the process of collecting and analyzing the performance and utilization of the resources and the cloud applications and services.
  - Resource scaling: the process of adjusting the amount and type of resources allocated to the cloud applications and services based on the changing demand and workload.
- Resource management can be done at different levels of the cloud architecture, such as:
  - Inter-cloud resource management: the process of managing resources across multiple cloud providers and platforms.
  - Intra-cloud resource management: the process of managing resources within a single cloud provider and platform.
  - Virtual machine (VM) level resource management: the process of managing resources at the level of VMs, which are the basic units of computation in the cloud.
  - Container level resource management: the process of managing resources at the level of containers, which are lightweight and isolated environments for running cloud applications and services.
- Resource management can be done using different methods, such as:
  - Static resource provisioning: the process of allocating resources to the cloud applications and services before their execution, based on the predefined and fixed requirements and SLAs.
  - Dynamic resource provisioning: the process of allocating resources to the cloud applications and services during their execution, based on the real-time and variable requirements and SLAs.
  - Reactive resource provisioning: the process of allocating resources to the cloud applications and services after detecting a change in the demand and workload, based on the feedback and adaptation mechanisms.
  - Proactive resource provisioning: the process of allocating resources to the cloud applications and services before detecting a change in the demand and workload, based on the prediction and anticipation mechanisms.
- Resource management can be done using different techniques, such as:
  - Optimization techniques: the techniques that aim to find the optimal or near-optimal solutions for the resource management problems, such as linear programming, integer programming, genetic algorithms, etc.
  - Heuristic techniques: the techniques that aim to find the feasible and satisfactory solutions for the resource management problems, such as greedy algorithms, local search, simulated annealing, etc.
  - Machine learning techniques: the techniques that aim to learn from the data and experience and improve the resource management decisions, such as regression, classification, clustering, reinforcement learning, etc.

- Security is the process of protecting the cloud resources, applications, services and data from unauthorized access, use, modification, disclosure and destruction.
- Security involves the following aspects:
  - Confidentiality: the property that ensures that the cloud resources, applications, services and data are accessible only to the authorized entities.
  - Integrity: the property that ensures that the cloud resources, applications, services and data are not altered or corrupted by unauthorized entities.
  - Availability: the property that ensures that the cloud resources, applications, services and data are accessible and usable by the authorized entities whenever needed.
  - Accountability: the property that ensures that the cloud resources, applications, services and data are traceable and auditable by the authorized entities.
  - Non-repudiation: the property that ensures that the cloud resources, applications, services and data are verifiable and provable by the authorized entities.
- Security can be done at different levels of the cloud architecture, such as:
  - Cloud security: the process of securing the cloud infrastructure, platform and software from the cloud provider's perspective.
  - Data security: the process of securing the data stored, processed and transmitted in the cloud from the cloud user's perspective.
  - Application security: the process of securing the applications and services deployed and executed in the cloud from the cloud user's perspective.
  - Network security: the process of securing the network connections and communications between the cloud components and entities from the cloud user's and provider's perspective.
- Security can be done using different methods, such as:
  - Encryption: the process of transforming the cloud resources, applications, services and data into an unreadable and unintelligible form using a secret key, so that only the authorized entities with the same key can decrypt and access them
