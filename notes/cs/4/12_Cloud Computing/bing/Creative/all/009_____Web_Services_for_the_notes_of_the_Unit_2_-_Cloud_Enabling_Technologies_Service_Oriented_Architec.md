# Web Services

- Web services are software systems that support interoperable machine-to-machine interaction over a network .
- Web services are accessible via standard web protocols, such as HTTP or HTTPS.
- Web services have an interface that describes their functionality and input/output parameters in a machine-processable format, such as WSDL (Web Services Description Language).
- Web services can provide data in different formats, such as XML, JSON, or images .
- Web services are designed to communicate with other programs, rather than directly with users.
- Web services can be used independently of the hardware or software platform on which they are implemented, and independently of the programming language or technology used to create them.
- Web services can be composed of other web services to create complex and distributed applications.
- Web services can be classified into two types: SOAP (Simple Object Access Protocol) and REST (Representational State Transfer).
- SOAP web services use XML messages to exchange information between the service provider and the service consumer, and rely on a predefined contract (WSDL) to define the structure and semantics of the messages.
- REST web services use HTTP methods (GET, POST, PUT, DELETE) to perform operations on resources identified by URIs, and rely on a common understanding of the resource representation and state transitions.
