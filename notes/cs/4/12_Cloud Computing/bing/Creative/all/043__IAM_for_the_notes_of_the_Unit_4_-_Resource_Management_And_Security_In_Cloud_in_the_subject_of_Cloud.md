### IAM for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- IAM stands for Identity and Access Management, which is a process of defining and managing the roles and access privileges of individual network entities (users and devices) to a variety of cloud and on-premises applications.
- IAM enables administrators to authorize who can take action on specific resources, giving them full control and visibility to manage cloud resources centrally.
- IAM also provides tools to manage resource permissions with minimum fuss and high automation, such as mapping job functions to groups and roles, using machine learning to make smart access control recommendations, and creating granular policies based on attributes like device security status, IP address, resource type, and date/time.
- IAM helps to ensure that users get access only to what they need to get the job done, and that the appropriate security controls are in place when granting access to cloud resources.
- IAM also simplifies compliance processes by providing a full audit trail history of permissions authorization, removal, and delegation.
- IAM can be a cloud service that users have to pass through to get to the rest of an organization's cloud infrastructure, or it can be deployed on an organization's premises on an internal network. Some public cloud vendors may bundle IAM with their other services.
- IAM can also leverage Cloud Identity, a built-in managed identity service that allows users to easily create or sync user accounts across applications and projects, set up single sign-on, and configure two-factor authentication.
- IAM can also support workforce identity federation, which allows users to access cloud resources using their existing identity providers, such as Google, Facebook, or Microsoft.

Some mnemonics and learning tricks for IAM are:

- IAM is about who can do what on which resources: Identity, Access, Management.
- IAM can be remembered as I AM authorized to access this cloud resource.
- IAM can be associated with the acronym RAM, which stands for Resource, Access, Management. RAM is also a type of memory that is used to store data temporarily, which can be related to the concept of granting temporary access to cloud resources.
