### Public, Private and Hybrid Clouds for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

- Public cloud is cloud computing that’s delivered via the internet and shared across organizations .
- Private cloud is cloud computing that is dedicated solely to your organization .
- Hybrid cloud is any environment that uses both public and private clouds  .

#### Public Cloud

- A public cloud is an environment made available over the internet, that anyone can subscribe to and then access.
- The public cloud offers vast choices in terms of solutions and computing resources to address the growing needs of organizations of all sizes and verticals.
- The defining features of a public cloud solution include:
  - High elasticity and scalability
  - A low-cost subscription-based pricing tier
  - A shared, multi-tenant infrastructure
  - A self-service provisioning model
  - A pay-as-you-go billing model
- The advantages of a public cloud solution include :
  - No upfront capital expenditure
  - Reduced operational and maintenance costs
  - Increased availability and reliability
  - Faster time to market and innovation
  - Greater flexibility and agility
- The disadvantages of a public cloud solution include :
  - Less control and customization
  - Potential security and compliance risks
  - Higher network dependency and latency
  - Vendor lock-in and interoperability issues
- Examples of public cloud providers are:
  - Amazon Web Services (AWS)
  - Microsoft Azure
  - Google Cloud Platform (GCP)
  - IBM Cloud
  - Alibaba Cloud

#### Private Cloud

- A private cloud, as the name implies, is the infrastructure used by just one organization.
- A private cloud can be hosted on-premises or off-premises by a third-party provider .
- A private cloud can be accessed via a private network or a virtual private network (VPN).
- The defining features of a private cloud solution include :
  - High security and privacy
  - A dedicated, single-tenant infrastructure
  - A customized and optimized environment
  - A greater degree of control and management
  - A fixed or variable cost model
- The advantages of a private cloud solution include  :
  - Enhanced security and compliance
  - Improved performance and efficiency
  - More control and customization
  - Higher scalability and availability
  - Easier integration and migration
- The disadvantages of a private cloud solution include  :
  - Higher upfront and ongoing costs
  - More complex and time-consuming deployment and maintenance
  - Limited flexibility and innovation
  - Lower resource utilization and optimization
  - Higher dependency on internal IT staff and skills
- Examples of private cloud platforms are:
  - VMware vCloud Suite
  - Microsoft Azure Stack
  - OpenStack
  - IBM Cloud Private
  - Oracle Cloud at Customer

#### Hybrid Cloud

- A hybrid cloud is a type of cloud computing that combines on-premises infrastructure—or a private cloud—with a public cloud.
- A hybrid cloud allows data and apps to move between the two environments.
- A hybrid cloud can also include edge workloads that bring the computing power of the cloud to IoT devices—closer to where the data resides.
- The defining features of a hybrid cloud solution include  :
  - A mix of public and private cloud resources
  - A unified and consistent platform
  - A dynamic and flexible environment
  - A balanced and optimized workload distribution
  - A hybrid cost model
- The advantages of a hybrid cloud solution include   :
  - The best of both worlds: the security and control of a private cloud and the scalability and cost-effectiveness of a public cloud
  - The ability to meet regulatory and data sovereignty requirements
  - The opportunity to take full advantage of on-premises technology investment
  - The capability to address low latency and offline issues
