### Google App Engine for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

- Google App Engine (GAE) is a platform-as-a-service (PaaS) product that provides web app developers and enterprises with access to Google's scalable hosting and tier 1 internet service.
- GAE requires that applications be written in one of the supported languages, such as Java, Python, Node.js, Ruby, C#, Go, or PHP, and use the Google query language .
- GAE also supports custom runtimes for other languages, such as Kotlin, Swift, or Rust.
- GAE stores data in Google Bigtable, a distributed database that can handle petabytes of data and millions of operations per second.
- GAE provides a fully managed environment that lets developers focus on code while App Engine manages infrastructure concerns, such as provisioning servers, scaling app instances, and monitoring performance .
- GAE also provides a range of developer tools, such as Cloud Monitoring, Cloud Logging, Cloud Debugger, and Error Reporting, to help diagnose and fix bugs quickly.
- GAE supports application versioning, which allows developers to easily host different versions of their app and create development, test, staging, and production environments.
- GAE also provides application security features, such as App Engine firewall, managed SSL/TLS certificates, and identity and access management (IAM) roles.
- GAE allows developers to tap into a growing ecosystem of Google Cloud services, such as Cloud Storage, Cloud Pub/Sub, Cloud Functions, Cloud AI, and Cloud Dataflow.
- GAE is mostly used to run web applications that can scale dynamically as demand changes over time, because of Google's vast computing infrastructure.
- GAE offers two environments: standard and flexible. The standard environment runs applications in a sandbox with preconfigured runtimes and libraries, and scales instances automatically. The flexible environment runs applications in Docker containers on Google Compute Engine virtual machines, and allows more customization and manual scaling.
- GAE pricing is based on the resources used by the app, such as CPU, memory, disk, network, and database operations. GAE also offers a free tier that includes 28 instance hours per day for the standard environment and 720 hours per month for the flexible environment.
