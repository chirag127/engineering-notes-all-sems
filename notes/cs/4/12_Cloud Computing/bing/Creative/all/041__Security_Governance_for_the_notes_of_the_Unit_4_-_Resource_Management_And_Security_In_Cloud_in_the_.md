### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security governance in cloud computing is a framework of policies designed to dictate what cloud resources can be used, how they should be used, and who can use them.
- Security governance also enforces rules governing how individual resources should be secured to prevent their misuse by malicious actors.
- Security governance bridges the business priorities with the technical implementation like architecture, standards, and policy.
- Security governance teams provide oversight and monitoring to sustain and improve security posture over time.
- Security governance teams also report compliance as required by regulating bodies.
- Security governance follows the risk management framework to align security efforts with the important matters for the organization.
- Security governance covers the following disciplines:
  - Cost Management: Develop policies for cost control for all cloud platforms.
  - Security Baseline: Establish and apply security requirements across network, data, and asset configurations.
  - Identity Baseline: Ensure that identity is consistently applied across cloud adoption efforts.
  - Resource Consistency: Configure resources consistently to manage risks related to onboarding, drift, discoverability, and recovery.
  - Deployment Acceleration: Centralize, standardize, and automate deployment and configuration activities.
- Security governance relies on cloud-based governance tooling to implement and enforce policies and rules across cloud platforms.
- Security governance is a dynamic and continuous process that adapts to the changing cloud environment and business needs .

#### Mnemonics and learning tricks

- To remember the five disciplines of cloud governance, use the acronym **CSIRD** (pronounced as "c-sired"), which stands for Cost, Security, Identity, Resource, and Deployment.
- To remember the key components of security governance, use the phrase **"Policies, Rules, and Compliance"** .
- To remember the difference between security governance and security management, use the analogy **"Governance is the what, management is the how"**.
