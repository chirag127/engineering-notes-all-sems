### Security Standards for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security standards are lists of best practices and processes defined by industry organizations to help organizations ensure their security posture and protect their data and systems in the cloud.
- Cloud security is a collection of procedures and technology designed to address external and internal threats to business security, such as data breaches, cyberattacks, unauthorized access, etc.
- Cloud security standards aim to provide guidance for cloud service providers and consumers on how to reduce the risk of a security incident in the cloud, and how to achieve compliance with various regulations and laws.
- Some of the cloud security standards that every business should consider are:
  - ISO-27017: A security standard established for cloud service providers and consumers with the goal of reducing the risk of a security incident in the cloud. It also provides control recommendations and implementation guidance for cloud-based organizations.
  - ISO-27018: A privacy standard that specifies the best practices for protecting personally identifiable information (PII) in the cloud. It also defines the roles and responsibilities of cloud service providers and consumers regarding PII processing and protection.
  - NIST-SP 500-291: A cloud computing standards roadmap that surveys the existing standards landscape for security, portability, and interoperability standards. It also identifies the standards gaps and priorities for cloud computing.
  - CSA CCM: A cloud security framework developed by the Cloud Security Alliance (CSA) that provides a comprehensive set of controls and best practices for cloud security. It also helps organizations assess the security level of cloud service providers and align their security requirements with industry standards.
  - PCI DSS: A security standard for organizations that handle payment card data. It applies to cloud service providers and consumers that store, process, or transmit cardholder data or sensitive authentication data in the cloud. It also specifies the security controls and requirements for protecting cardholder data in the cloud.
- Some of the security techniques that are implemented to make the cloud computing system more secure are:
  - SSL (Secure Socket Layer) Encryption: A cryptographic protocol that encrypts the data in transit between the client and the server, preventing eavesdropping, tampering, or forgery of the data.
  - Multi Tenancy based Access Control: A security mechanism that isolates the data and resources of different tenants (users or organizations) in a shared cloud environment, preventing unauthorized access or leakage of data.
  - Intrusion Detection System: A system that monitors the network or system activities for malicious or anomalous behavior, and alerts the administrator or takes corrective actions when an intrusion is detected.
  - Firewalls: A device or software that filters the incoming and outgoing network traffic based on predefined rules, blocking or allowing the traffic based on the source, destination, protocol, or content of the packets.
  - Penetration Testing: A method of testing the security of a system or network by simulating an attack from an external or internal source, and identifying the vulnerabilities and weaknesses that can be exploited by an attacker.
  - Tokenization: A technique that replaces sensitive data, such as credit card numbers, with non-sensitive tokens, which are randomly generated values that have no meaning or value outside of the system. This reduces the risk of data exposure or theft in the cloud.
  - VPN (Virtual Private Networks): A technology that creates a secure and encrypted connection between a client and a server over a public network, such as the internet. This allows the client to access the resources and services of the server as if they were in the same private network, and protects the data from interception or modification by third parties.
  - Avoiding Public Internet Connections: A practice of using private or dedicated network connections to access the cloud services, rather than using public internet connections that are more vulnerable to attacks or disruptions. This improves the performance, reliability, and security of the cloud services.
