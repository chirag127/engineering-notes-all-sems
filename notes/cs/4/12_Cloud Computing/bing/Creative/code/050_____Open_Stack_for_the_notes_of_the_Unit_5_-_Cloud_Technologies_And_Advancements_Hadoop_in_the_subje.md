### Open Stack

- Open Stack is a free, open source cloud computing platform that provides infrastructure-as-a-service (IaaS) in both public and private clouds.
- Open Stack consists of interrelated components that control diverse, multi-vendor hardware pools of processing, storage, and networking resources throughout a data center.
- Open Stack can be managed either through a web-based dashboard, through command-line tools, or through RESTful web services.
- Open Stack is developed by a community of thousands of contributors and hundreds of organizations around the world.
- Open Stack is trusted to manage millions of cores across dozens of industries, such as gaming, telecom, retail, finance, and research.

Some of the main components of Open Stack are:

- Nova: the compute service that manages the lifecycle of virtual machines and other instances.
- Swift: the object storage service that provides scalable and durable storage for unstructured data.
- Cinder: the block storage service that allows users to create and attach volumes to instances.
- Neutron: the network service that provides connectivity and network management for instances and other resources.
- Glance: the image service that stores and manages virtual machine images and other disk and server images.
- Keystone: the identity service that provides authentication and authorization for users and services.
- Horizon: the dashboard service that provides a web-based user interface for managing Open Stack resources.
- Heat: the orchestration service that allows users to define and manage cloud applications using templates.
- Ceilometer: the telemetry service that collects and monitors usage and performance data for billing and optimization purposes.
- Other components include: Designate (DNS service), Trove (database service), Sahara (big data service), Magnum (container service), Zaqar (messaging service), Manila (shared file system service), and more.
