### Types of Virtualization for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization is the process of creating a virtual representation of physical resources, such as servers, storage, network, and applications, in order to optimize the utilization and management of those resources. Virtualization enables cloud computing, which is the delivery of computing services over the internet on demand.

There are different types of virtualization in cloud computing, depending on the level of abstraction and the resource being virtualized. Some of the common types are:

- **Server virtualization**: Server virtualization is the process of partitioning a physical server into multiple virtual servers, each with its own operating system and applications. Server virtualization allows multiple workloads to run on the same hardware, improving efficiency, scalability, and availability. Server virtualization can be implemented using hypervisors, which are software layers that manage the virtual machines and the underlying hardware, or using containers, which are isolated environments that share the same operating system kernel.    

- **Storage virtualization**: Storage virtualization is the process of pooling and abstracting physical storage devices, such as disks, tapes, and arrays, into logical units that can be accessed and managed by applications and users. Storage virtualization enables data mobility, replication, backup, and recovery across different storage devices and locations, as well as improved performance, scalability, and availability. Storage virtualization can be implemented at different levels, such as block, file, or object, and using different methods, such as host-based, network-based, or array-based.   

- **Network virtualization**: Network virtualization is the process of creating virtual networks that are independent of the physical network infrastructure, such as switches, routers, and firewalls. Network virtualization allows multiple virtual networks to coexist and operate on the same physical network, each with its own policies, services, and security. Network virtualization enables network segmentation, isolation, and optimization, as well as improved performance, scalability, and availability. Network virtualization can be implemented using different techniques, such as overlay, underlay, or software-defined networking (SDN).   

- **Data virtualization**: Data virtualization is the process of creating a unified and abstracted view of data from different sources, such as databases, files, or web services, without requiring physical data integration or replication. Data virtualization allows applications and users to access and query data from multiple sources as if they were a single source, regardless of the data format, location, or structure. Data virtualization enables data integration, transformation, and analysis, as well as improved performance, scalability, and availability. Data virtualization can be implemented using different tools, such as middleware, data federation, or data abstraction. 

- **Application virtualization**: Application virtualization is the process of decoupling an application from the underlying operating system and hardware, and delivering it to the end-user as a service over the network. Application virtualization allows applications to run on any device and platform, without requiring installation or configuration, and with improved performance, scalability, and availability. Application virtualization can be implemented using different methods, such as streaming, encapsulation, or isolation. 

- **Operating system virtualization**: Operating system virtualization is the process of creating multiple isolated and secure user spaces on the same operating system kernel, each with its own applications and resources. Operating system virtualization allows multiple users to share the same operating system, improving efficiency, scalability, and availability. Operating system virtualization can be implemented using different technologies, such as containers, zones, or jails.
