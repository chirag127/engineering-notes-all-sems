### Security Governance for the notes of the Unit 4 - Resource Management And Security In Cloud in the subject of Cloud Computing

- Security governance is a set of rules and policies adopted by companies that run services in the cloud. The goal of security governance is to enhance data security, manage risk, and enable the smooth operation of cloud systems.
- Security governance bridges the business priorities with the technical implementation of security, such as architecture, standards, and policy. Security governance teams provide oversight and monitoring to sustain and improve the security posture over time. They also report compliance as required by regulating bodies.
- Security governance is important for several reasons, such as:
  - Improving cloud resource management by segregating cloud workloads into separate accounts that represent departments, projects, or cost centers within the organization.
  - Reducing shadow IT by enabling employees to request cloud resources in a convenient way, yet one that applies the relevant controls and visibility for the organization.
  - Reducing administrative overhead by using technology solutions to centrally define and apply policies to the entire cloud infrastructure.
- Security governance involves the following aspects:
  - Compliance and reporting: Security governance ensures that the cloud systems meet the external and internal security requirements and obligations, such as industry standards, regulations, and policies.
  - Architecture and standards: Security governance provides the critical translation from business requirements and risk into the technical environment, such as security design, configuration, and implementation.
  - Security posture management: Security governance monitors and measures the current security state and asset coverage of the cloud systems, and provides guidance and feedback to improve the security processes and practices.
  - Governance and protection disciplines: Security governance defines and enforces the security controls and mechanisms that protect the cloud systems from threats and attacks, such as identity and access management, encryption, firewall, and backup.
  - Governance and security operations: Security governance coordinates and collaborates with the security operations teams that perform the day-to-day security tasks and activities, such as incident response, threat detection, and vulnerability management.
