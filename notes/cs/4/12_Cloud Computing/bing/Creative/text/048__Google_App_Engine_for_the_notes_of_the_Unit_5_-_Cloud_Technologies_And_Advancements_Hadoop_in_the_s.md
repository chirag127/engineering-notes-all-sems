### Google App Engine

- Google App Engine is a platform-as-a-service (PaaS) product that provides web app developers and enterprises with access to Google's scalable hosting and tier 1 internet service .
- Google App Engine supports popular development languages such as Node.js, Java, Ruby, C#, Go, Python, or PHP, and allows developers to use their own frameworks and libraries .
- Google App Engine requires that applications store data in Google Bigtable and use the Google query language. It also provides a range of in-built services such as authentication, caching, logging, monitoring, debugging, and error reporting .
- Google App Engine is a fully managed, serverless platform that automatically scales app instances based on demand, and handles server provisioning, load balancing, health checking, and security  .
- Google App Engine offers two environments: the standard environment and the flexible environment. The standard environment runs apps in a sandboxed environment with pre-defined runtimes and restrictions, while the flexible environment runs apps in Docker containers on Google Compute Engine virtual machines with more customization options .
- Google App Engine is part of the Google Cloud ecosystem, and integrates with other Google Cloud products such as Cloud Storage, Cloud Datastore, Cloud SQL, Cloud Pub/Sub, Cloud Functions, Cloud Run, and Cloud Vision API .
- Google App Engine provides a free tier for new customers, and charges based on the resources used by the apps, such as CPU, memory, disk, network, and instances .
