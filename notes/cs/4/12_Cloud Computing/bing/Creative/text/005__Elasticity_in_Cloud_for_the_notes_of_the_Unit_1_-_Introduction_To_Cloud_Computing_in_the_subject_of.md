### Elasticity in Cloud

- Elasticity in cloud computing is the ability of a cloud system to dynamically adjust the amount of resources allocated to a service based on the current demand, such that the available resources match the current demand as closely as possible .
- Elasticity is a defining characteristic that differentiates cloud computing from other computing paradigms, such as grid computing.
- Elasticity enables cloud users to avoid over-provisioning (deploying more resources than needed) or under-provisioning (not deploying enough resources to meet the demand) of resources, and thus save costs and improve performance.
- Elasticity can be achieved by using horizontal scaling (adding or removing machines) or vertical scaling (increasing or decreasing the capacity of a machine) of resources, depending on the cloud service model (IaaS, PaaS, or SaaS) and the cloud provider's capabilities.
- Elasticity can be automatic, where the cloud system monitors the workload and adjusts the resources accordingly, or manual, where the cloud user decides when and how to scale the resources.
- Elasticity can be applied to different types of resources, such as CPU, memory, storage, network, or software licenses.
- Elasticity can be influenced by various factors, such as the resource provisioning time, the monitoring of elastic applications, the elasticity requirements, and the multiple levels of control in the cloud.
