### Web Services

- A web service is a software system that supports interoperable machine-to-machine interaction over a network  .
- A web service has an interface that is described in a machine-processable format, such as WSDL (Web Services Description Language), that specifies the operations, inputs, outputs, and protocols of the service .
- A web service can be accessed by other applications or devices using standard web protocols, such as HTTP or HTTPS, and data formats, such as XML or JSON .
- A web service can provide data, functionality, or both, depending on the needs of the client.
- A web service can be either:
  - A service offered by an electronic device to another electronic device, communicating with each other via the Internet, or
  - A server running on a computer device, listening for requests at a particular port over a network, serving web documents (HTTP, JSON, XML, images).
- A web service is always-on, meaning that it is available at any time and can respond to requests without human intervention.
- A web service can be implemented in any programming language or platform, as long as it follows the web service standards and specifications.
- A web service can be composed of other web services, creating a web service composition or orchestration.
- A web service can be classified into two types, based on the level of abstraction and complexity of the interface:
  - SOAP (Simple Object Access Protocol) web services, which use XML-based messages and follow a rigid structure and syntax.
  - REST (Representational State Transfer) web services, which use HTTP methods and URIs to manipulate resources and follow a flexible and simple approach.
