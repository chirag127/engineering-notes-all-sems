## Unit 4 - Resource Management And Security In Cloud

- Resource management in cloud is the process of allocating, monitoring, and optimizing the use of cloud resources such as compute, storage, network, and applications.
- Resource management in cloud aims to achieve the following objectives:
  - Maximize the performance and availability of cloud services and applications.
  - Minimize the cost and waste of cloud resources.
  - Ensure the compliance and governance of cloud resources.
  - Adapt to the changing demand and workload of cloud users and applications.
- Resource management in cloud involves the following tasks:
  - Resource provisioning: The process of creating, configuring, and deploying cloud resources based on the user's requirements and specifications.
  - Resource scaling: The process of adjusting the size and capacity of cloud resources based on the current and predicted demand and workload.
  - Resource monitoring: The process of collecting, analyzing, and reporting the performance, utilization, and health of cloud resources.
  - Resource optimization: The process of improving the efficiency and effectiveness of cloud resources by applying various techniques such as load balancing, caching, compression, deduplication, etc.
  - Resource automation: The process of automating the resource management tasks using tools, scripts, policies, and workflows.
  - Resource orchestration: The process of coordinating and integrating multiple cloud resources and services to achieve a desired outcome or functionality.

- Security management in cloud is a set of strategies designed to allow a business to use cloud applications and networks to their greatest potential while limiting potential threats and vulnerabilities.
- Security management in cloud aims to achieve the following objectives:
  - Protect the confidentiality, integrity, and availability of cloud data and services.
  - Prevent unauthorized access, modification, or disclosure of cloud data and services.
  - Detect and respond to security incidents and breaches in cloud environments.
  - Comply with the legal and regulatory requirements and standards for cloud security.
- Security management in cloud involves the following tasks:
  - Security assessment: The process of identifying and evaluating the security risks and gaps in cloud environments.
  - Security design: The process of designing and implementing the security controls and measures in cloud environments.
  - Security testing: The process of verifying and validating the effectiveness and functionality of the security controls and measures in cloud environments.
  - Security monitoring: The process of collecting, analyzing, and reporting the security events and activities in cloud environments.
  - Security auditing: The process of reviewing and verifying the compliance and governance of cloud security.
  - Security incident response: The process of managing and resolving the security incidents and breaches in cloud environments.
