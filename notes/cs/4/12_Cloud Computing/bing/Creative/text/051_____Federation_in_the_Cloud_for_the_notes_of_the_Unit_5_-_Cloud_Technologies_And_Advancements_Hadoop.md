### Federation in the Cloud

- Federation in the cloud means associating small divisions to a single group for performing a common task.
- Federation in the cloud is formed by connecting the cloud environment of several cloud providers using a common standard.
- Federation in the cloud helps the provider to easily scale up the resource to match business needs.
- Federation in the cloud integrates heterogeneous cloud environments such as community cloud, public cloud, and private cloud into scalable computing platforms .
- Federation in the cloud enables users to authenticate using on-premises credentials and access all resources in cloud .
- Federation in the cloud requires a high level of trust and security among the federated domains.
- Federation in the cloud can be achieved using technologies such as OpenNebula, Aneka coordinator, and Active Directory Federation Services .
