### Security Overview

- Security is one of the major concerns in cloud computing, as it involves storing and processing sensitive data and applications on shared and distributed resources.
- Security in cloud computing can be classified into three categories: cloud security, network security, and data security.
- Cloud security refers to the policies, technologies, and controls that protect the cloud infrastructure, platforms, and services from unauthorized access, modification, or damage.
- Network security refers to the measures that protect the communication and data transmission between the cloud and the users, as well as among the cloud components, from interception, tampering, or disruption.
- Data security refers to the mechanisms that ensure the confidentiality, integrity, and availability of the data stored and processed in the cloud, from unauthorized disclosure, alteration, or loss.
- Security in cloud computing can be achieved by applying various techniques, such as encryption, authentication, authorization, auditing, monitoring, firewall, intrusion detection and prevention, etc.
- Security in cloud computing can also be enhanced by following the best practices and standards, such as ISO/IEC 27017, ISO/IEC 27018, NIST SP 800-144, NIST SP 800-145, etc.
- Security in cloud computing is a shared responsibility between the cloud service provider (CSP) and the cloud service customer (CSC). The CSP is responsible for securing the cloud infrastructure, platform, and service, while the CSC is responsible for securing the data and applications that they use in the cloud.
