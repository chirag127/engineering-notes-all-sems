## Unit 5 - Cloud Technologies And Advancements Hadoop

The following diagram illustrates the basic architecture of a Hadoop cluster, which consists of a leader node and multiple follower nodes. The leader node runs the NameNode and the Resource Manager services, which are responsible for managing the file system metadata and the cluster resources respectively. The follower nodes run the DataNode and the Node Manager services, which are responsible for storing the data blocks and executing the tasks respectively. The leader node and the follower nodes communicate through the Hadoop Distributed File System (HDFS) and the Yet Another Resource Negotiator (YARN) frameworks, which enable distributed storage and processing of large data sets. The Hadoop cluster also interacts with external clients and applications, such as MapReduce, Hive, Pig, Spark, etc., which can submit jobs and access data through HDFS and YARN.
