### Security Governance

- Security governance is a framework of policies and controls that define and enforce how cloud resources can be used, secured, and monitored to achieve business objectives and manage risks  .
- Security governance bridges the gap between business priorities and technical implementation, and provides oversight and reporting to ensure compliance with regulations and standards .
- Security governance involves five disciplines: cost management, security baseline, resource consistency, identity baseline, and deployment acceleration.
- Cost management: This discipline aims to optimize the cloud spending and avoid unnecessary costs by defining policies and controls for budgeting, forecasting, and allocating cloud resources.
- Security baseline: This discipline aims to protect the cloud environment from threats and vulnerabilities by defining policies and controls for network, data, and asset configurations, encryption, access management, logging, and auditing .
- Resource consistency: This discipline aims to ensure the cloud resources are consistent, standardized, and aligned with the business requirements and best practices by defining policies and controls for resource naming, tagging, grouping, and provisioning.
- Identity baseline: This discipline aims to manage the identities and roles of the cloud users and applications by defining policies and controls for authentication, authorization, and federation.
- Deployment acceleration: This discipline aims to enable faster and smoother cloud adoption and migration by defining policies and controls for automation, orchestration, and integration of cloud services.
