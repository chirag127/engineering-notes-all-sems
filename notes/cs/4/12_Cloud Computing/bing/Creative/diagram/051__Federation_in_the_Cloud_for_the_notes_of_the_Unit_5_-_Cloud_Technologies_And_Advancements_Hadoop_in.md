### Federation in the Cloud for the notes of the Unit 5 - Cloud Technologies And Advancements Hadoop in the subject of Cloud Computing

Federation in the Cloud is a feature of Hadoop that allows multiple independent NameNodes to manage different namespaces in the same cluster. This improves the scalability, performance, and isolation of the HDFS architecture. Each NameNode has its own block pool, which is a set of blocks that belong to a single namespace. The DataNodes store blocks for all the block pools in the cluster and register with all the NameNodes. The NameNodes are federated, meaning they do not coordinate with each other and operate independently. The users can access the namespaces using ViewFs, which is a client-side mount table that creates a unified view of the federated cluster.
