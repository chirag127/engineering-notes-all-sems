## Unit 3 - Cloud Architecture, Services and Storage

Cloud architecture is the way technology components combine to build a cloud, in which resources are pooled through virtualization technology and shared across a network. Cloud architecture consists of the following components:

- A front-end platform (the client or device used to access the cloud)
- A back-end platform (servers and storage)
- A cloud-based delivery (the method of delivering cloud services to users)
- A network (the internet or a private network that connects the cloud components)

Cloud services are the types of services that can be delivered through the cloud, such as software as a service (SaaS), platform as a service (PaaS), and infrastructure as a service (IaaS). Cloud services enable organizations to reduce or eliminate their reliance on on-premises server, storage, and networking infrastructure. Cloud services offer the following benefits:

- Scalability: Cloud services can be scaled up or down according to the demand and usage of the users.
- Cost-effectiveness: Cloud services can reduce the capital and operational expenses of maintaining on-premises infrastructure.
- Availability: Cloud services can provide high availability and reliability by using multiple servers and data centers across different locations.
- Security: Cloud services can protect the data and applications from unauthorized access and threats by using encryption, authentication, and backup mechanisms.

Cloud storage is a type of cloud service that allows users to store and access data on remote servers over the internet. Cloud storage can be used for various purposes, such as backup, archiving, synchronization, sharing, and analytics. Cloud storage can be provided by an off-site provider (such as Amazon S3) or an on-site provider (such as ViON Capacity Services). Cloud storage can be classified into the following types:

- Blob storage: A massively scalable object store for text and binary data. Also includes support for big data analytics through Azure Data Lake Storage Gen2.
- File storage: Managed file shares for cloud or on-premises deployments. Supports standard protocols such as SMB and NFS.
- Queue storage: A service for storing large numbers of messages that can be accessed from anywhere in the world via authenticated calls using HTTP or HTTPS.
- Table storage: A NoSQL key-value store for rapid development using massive semi-structured datasets.
- Disk storage: A service for creating and managing highly durable and scalable virtual hard disks (VHDs) that can be attached to virtual machines. Supports both standard and premium SSD disks.
