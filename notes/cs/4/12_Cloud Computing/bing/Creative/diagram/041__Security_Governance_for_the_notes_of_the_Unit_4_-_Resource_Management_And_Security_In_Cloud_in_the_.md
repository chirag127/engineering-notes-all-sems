Security governance in cloud computing is a framework of policies designed to dictate what cloud resources can be used, how they should be used, and who can use them. They can also enforce rules governing how security requirements are applied across network, data, and asset configurations. Security governance bridges the business priorities with the technical implementation of security in the cloud environment. Security governance teams provide oversight and monitoring to sustain and improve security posture over time. They also report compliance as required by regulating bodies.
