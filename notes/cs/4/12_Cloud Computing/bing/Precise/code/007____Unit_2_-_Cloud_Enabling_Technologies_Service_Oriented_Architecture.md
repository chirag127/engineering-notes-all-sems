## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

Service Oriented Architecture (SOA) is an architectural style that supports service orientation. It is a way of designing, developing, deploying, and managing enterprise systems where services are the primary means of communication and integration.

1. **Service orientation** is a design paradigm that defines the use of services to support the requirements of software users. In a service-oriented architecture, services are the building blocks used to construct applications.

2. **Services** are self-contained, modular components that can be described, published, located, and invoked over a network. They are designed to perform a specific task and can be reused by different applications.

3. **SOA** provides a way to manage the complexity of large-scale distributed systems by breaking them down into smaller, more manageable components. It also promotes loose coupling between components, which makes it easier to change and evolve the system over time.

4. **SOA** can be implemented using a variety of technologies, including web services, messaging, and RESTful APIs. It is not tied to any specific technology or platform.

5. **Benefits of SOA** include increased flexibility, scalability, and reusability, as well as improved alignment between business and IT. It can also help reduce costs by enabling the reuse of existing services and components.

6. **Challenges of SOA** include the need for effective governance, the complexity of managing distributed systems, and the need for a cultural shift towards service orientation.
