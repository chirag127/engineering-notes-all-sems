# REST and Systems of Systems

## Unit 2 - Cloud Enabling Technologies Service Oriented Architecture

### REST

REST stands for Representational State Transfer. It is an architectural style for designing networked applications. REST is often used in the development of web services and is considered a simpler alternative to other methods such as SOAP.

### Systems of Systems

A system of systems is a collection of independent systems that work together to achieve a common goal. In the context of cloud computing, systems of systems can refer to the integration of multiple cloud services to provide a more comprehensive solution.

### Service Oriented Architecture

Service Oriented Architecture (SOA) is an architectural style that supports the creation of services that can be reused and combined to create new applications. SOA is often used in the development of web services and can be used in conjunction with REST.

### Web Services

Web services are software components that can be accessed over a network, typically using standard protocols such as HTTP. Web services can be used to provide a wide range of functionality, from simple data retrieval to complex business processes.

### Publish-Subscribe Model

The publish-subscribe model is a messaging pattern in which publishers send messages to topics, and subscribers receive messages from topics to which they have subscribed. This model is often used in the development of distributed systems and can be used in conjunction with web services.

### Virtualization

Virtualization is the creation of a virtual version of something, such as a server, storage device, or network resource. Virtualization can be used to improve the efficiency and flexibility of IT infrastructure, and is a key enabling technology for cloud computing.

### Types of Virtualization

There are several types of virtualization, including hardware virtualization, operating system virtualization, and application virtualization. Each type of virtualization has its own advantages and disadvantages, and the appropriate type of virtualization to use will depend on the specific needs of the organization.

### Implementation Levels of Virtualization

Virtualization can be implemented at different levels, including the hardware level, the operating system level, and the application level. The level at which virtualization is implemented will depend on the specific needs of the organization and the capabilities of the virtualization technology being used.

### Virtualization Structures

Virtualization can be structured in different ways, including full virtualization, para-virtualization, and hardware-assisted virtualization. The appropriate virtualization structure to use will depend on the specific needs of the organization and the capabilities of the virtualization technology being used.

### Tools and Mechanisms

There are many tools and mechanisms available to support the implementation of virtualization, including hypervisors, virtual machine managers, and virtualization management software. The appropriate tools and mechanisms to use will depend on the specific needs of the organization and the capabilities of the virtualization technology being used.

### Virtualization of CPU, Memory, and I/O Devices

Virtualization can be used to virtualize a wide range of resources, including CPUs, memory, and I/O devices. Virtualizing these resources can improve the efficiency and flexibility of IT infrastructure, and is a key enabling technology for cloud computing.

### Virtualization Support and Disaster Recovery

Virtualization can provide many benefits in terms of disaster recovery, including improved flexibility, faster recovery times, and reduced costs. Virtualization technologies can also provide support for disaster recovery, including backup and replication capabilities.
