### S3 for the notes of the Unit 3 - Cloud Architecture, Services And Storage in the subject of Cloud Computing

S3 (Simple Storage Service) is a highly scalable, object-based cloud storage service provided by AWS (Amazon Web Services). 

Features: 
- Unlimited storage capacity
- Easy to use API for data access
- Accessible from anywhere with internet access
- Secure with options for encryption and access control
- Durable, with 99.999999999% data durability and 99.99% availability
- Cost-effective, with pay-per-use pricing and no upfront costs 

Use cases: 
- Backup and disaster recovery 
- Big data analytics 
- Static website hosting 
- Media and entertainment storage 
- Mobile and gaming applications 

S3 is a popular choice for cloud storage due to its scalability, reliability, and ease of use. It is a key component of many cloud-based applications and services.
