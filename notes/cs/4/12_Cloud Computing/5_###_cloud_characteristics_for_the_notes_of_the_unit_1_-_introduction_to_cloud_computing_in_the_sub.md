### Cloud Characteristics for the notes of the Unit 1 - Introduction To Cloud Computing in the subject of Cloud Computing

Cloud Characteristics are the defining features that distinguish cloud computing from other computing models. These characteristics are:

1. On-demand self-service: Users can provision computing resources, such as virtual machines and storage, without requiring intervention from a service provider.

2. Broad network access: Cloud resources can be accessed over the internet from a variety of devices, including laptops, smartphones, and tablets.

3. Resource pooling: Cloud providers allocate computing resources from a shared pool, allowing multiple users to share the same infrastructure.

4. Rapid elasticity: Cloud computing resources can be quickly scaled up or down as needed, allowing users to respond to changing demand.

5. Measured service: Cloud providers monitor and measure resource usage, allowing users to pay only for what they use.

6. Multi-tenancy: Multiple users share the same physical resources, but each user's data and applications are isolated from others.

These characteristics enable cloud computing to offer benefits such as increased scalability, cost savings, and improved security compared to traditional computing models.
