### Virtualization Structures for the notes of the Unit 2 - Cloud Enabling Technologies Service Oriented Architecture in the subject of Cloud Computing

Virtualization Structures:
1. Hypervisor: software layer that allows multiple virtual machines to share the same physical hardware.
2. Virtual Machines (VMs): isolated operating systems and applications running on a virtualized environment.
3. Containers: lightweight virtualization structure that runs applications in isolated environments.
4. Virtualized Network Functions (VNFs): virtualized versions of network equipment such as firewalls and load balancers.
5. Virtualized Storage: virtualized storage resources that can be dynamically allocated to applications.
