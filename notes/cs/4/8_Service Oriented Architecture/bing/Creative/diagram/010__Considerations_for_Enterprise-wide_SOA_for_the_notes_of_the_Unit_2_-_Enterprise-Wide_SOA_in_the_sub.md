According to the IBM website, SOA, or service-oriented architecture, defines a way to make software components reusable and interoperable via service interfaces. Services use common interface standards and an architectural pattern so they can be rapidly incorporated into new applications. This removes tasks from the application developer who previously redeveloped or duplicated existing functionality or had to know how to connect or provide interoperability with existing functions.

An SOA roadmap provides an iterative and incremental way to capture (and recapture) your organization's unique plan as you progress. Your SOA roadmap should contain three critical characteristics: maturity, scope, and quality.

The following diagram illustrates the basic architecture of a service-oriented enterprise, based on the six domains of an SOA roadmap:

```
+--------------------------------------------------------------------+
|                                                                    |
|                            Business Strategy                       |
|                                                                    |
+--------------------------------------------------------------------+
|                                                                    |
|                            SOA Governance                          |
|                                                                    |
+--------------------------------------------------------------------+
|                                                                    |
|                            Service Portfolio                       |
|                                                                    |
+--------------------------------------------------------------------+
|                                                                    |
|                            Service Delivery                        |
|                                                                    |
+--------------------------------------------------------------------+
|                                                                    |
|                            Service Management                      |
|                                                                    |
+--------------------------------------------------------------------+
|                                                                    |
|                            Service Infrastructure                  |
|                                                                    |
+--------------------------------------------------------------------+
```

Each domain represents a different aspect of the SOA initiative:

- Business Strategy: The alignment of business goals and objectives with the SOA vision and roadmap.
- SOA Governance: The policies, processes, and roles that ensure the effective and efficient use of SOA services across the enterprise.
- Service Portfolio: The collection of services that provide business value and support the business strategy.
- Service Delivery: The methods and practices for designing, developing, testing, and deploying SOA services.
- Service Management: The activities and tools for monitoring, controlling, and optimizing the performance and availability of SOA services.
- Service Infrastructure: The hardware, software, and network components that enable the execution and integration of SOA services.
