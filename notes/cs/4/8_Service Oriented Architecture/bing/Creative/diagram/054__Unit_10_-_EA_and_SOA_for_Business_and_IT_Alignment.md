## Unit 10 - EA and SOA for Business and IT Alignment

Enterprise architecture (EA) is the practice of analyzing, designing, planning, and implementing enterprise analysis to successfully execute on business strategies. EA helps organizations structure IT projects and policies to achieve desired business results, to stay agile and resilient in the face of rapid change, and to stay on top of industry trends and disruptions using architecture principles and practices.

Service-oriented architecture (SOA) is an architectural strategy that uses the concept of “Services” as the underlying business-IT alignment entity. SOA is also tasked to bridge the gap between business and IT through business-aligned services. SOA can impact EA frameworks, methodologies, governance and tools.

EA and SOA share a similar goal of achieving business and IT alignment. However, EA is a framework that covers all the dimensions of IT architecture for the enterprise, while SOA is a specific approach to design and implement IT solutions that are aligned with business processes and goals.

The following diagram illustrates the basic architecture of EA and SOA for business and IT alignment:

```
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |
|  Business        |    |  Information     |    |  Technology      |
|  Architecture    |    |  Architecture    |    |  Architecture    |
|                  |    |                  |    |                  |
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |
|  Business        |    |  Data            |    |  Application     |
|  Processes       |    |  Models          |    |  Services        |
|                  |    |                  |    |                  |
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |
|  Business        |    |  Information     |    |  Infrastructure  |
|  Services        |    |  Services        |    |  Services        |
|                  |    |                  |    |                  |
+------------------+    +------------------+    +------------------+
|                  |    |                  |    |                  |
|  Business        |    |  Information     |    |  Infrastructure  |
|  Governance      |    |  Governance      |    |  Governance      |
|                  |    |                  |    |                  |
+------------------+    +------------------+    +------------------+
```

The diagram shows how EA consists of three layers: business, information, and technology architecture. Each layer has its own models, services, and governance. SOA is a cross-cutting concern that spans across all three layers, providing a common way to design, implement, and manage IT solutions that are aligned with business processes and goals. SOA also enables the reuse and integration of existing services, reducing complexity and cost. SOA governance is a subset of EA governance that focuses on the quality, consistency, and compliance of services.
