## Unit 3 - Service-Oriented Applications

- Service-oriented applications are software applications that use **services** as the building blocks for creating business processes and functionalities.
- A service is a **software component** that provides a **business capability** and can be accessed through a **standard interface** by other components or applications.
- Services can be **reused** and **combined** to form complex applications or workflows, without requiring detailed knowledge of their internal implementation or dependencies.
- Services can be implemented in different **platforms** and **languages**, and communicate using standard **protocols** and **formats**, such as SOAP, REST, HTTP, XML, JSON, etc.
- Services can be **discovered** and **published** in a **registry** or a **repository**, where they can be searched and accessed by other developers or applications.
- Service-oriented applications follow the principles of **service-oriented architecture (SOA)**, which is a design approach that structures system development and integration using services as the main components.
- SOA aims to achieve **faster time to market**, **efficient maintenance**, **greater adaptability**, and **interoperability** among different systems and applications.
