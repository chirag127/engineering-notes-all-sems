### Technologies for Big Data for the notes of the Unit 7 - Big Data and SOA in the subject of Service Oriented Architecture

Big data technologies are the software tools used to manage and analyze large and complex datasets and transform them into business insights. Big data technologies can be categorized into four main types: data storage, data mining, data analytics, and data visualization. Each of these types is associated with certain tools, and you’ll want to choose the right tool for your business needs depending on the type of big data technology required.

- Data storage: Big data technology that deals with data storage has the capability to fetch, store, and manage big data. It is made up of infrastructure that allows users to store the data so that it is convenient to access. Most data storage platforms are compatible with other programs. Two commonly used tools are Apache Hadoop and MongoDB.
  - Apache Hadoop: Apache is the most widely used big data tool. It is an open-source software platform that stores and processes big data in a distributed computing environment across hardware clusters. This distribution allows for faster data processing. The framework is designed to reduce bugs or faults, be scalable, and process all data formats .
  - MongoDB: MongoDB is a NoSQL database that can be used to store large volumes of data. Using key-value pairs (a basic unit of data), MongoDB categorizes documents into collections. It is written in C, C++, and JavaScript, and is one of the most popular big data databases because it can manage and store unstructured data with ease.
- Data mining: Data mining extracts the useful patterns and trends from the raw data. Big data technologies such as Rapidminer and Presto can turn unstructured and structured data into usable information.
  - Rapidminer: Rapidminer is a data mining tool that can be used to build predictive models. It draws on these two roles as strengths, of processing and preparing data, and building machine and deep learning models.
  - Presto: Presto is a distributed SQL query engine that can run interactive queries on big data sources. It can query data from multiple sources, such as Hadoop, MongoDB, MySQL, and Cassandra, and supports a variety of data formats, such as JSON, ORC, and Parquet.
- Data analytics: In big data analytics, technologies are used to clean and transform data into information that can be used to drive business decisions. Big data analytics can involve descriptive, diagnostic, predictive, and prescriptive analytics, as well as machine learning and artificial intelligence. Some of the tools used for big data analytics are Apache Spark, TensorFlow, and Tableau.
  - Apache Spark: Apache Spark is an open-source framework for large-scale data processing. It can run on Hadoop, Mesos, Kubernetes, or standalone clusters, and supports batch and stream processing, SQL queries, machine learning, and graph analytics. It is known for its speed, ease of use, and compatibility with various data sources and formats.
  - TensorFlow: TensorFlow is an open-source library for machine learning and deep learning. It can be used to build and train neural networks, perform image recognition, natural language processing, and computer vision tasks, and deploy models on various platforms, such as mobile, web, and cloud.
  - Tableau: Tableau is a data visualization tool that can connect to various data sources and create interactive dashboards and reports. It can handle large and complex datasets, and provide insights through charts, graphs, maps, and other visual elements. It also supports collaboration and sharing of data stories.
- Data visualization: Data visualization is the process of presenting data in a graphical or pictorial form. It can help users understand and communicate data better, as well as identify patterns, trends, and outliers. Data visualization can be done using tools such as D3.js, Plotly, and Power BI.
  - D3.js: D3.js is a JavaScript library for creating dynamic and interactive data visualizations on the web. It can manipulate HTML, SVG, and CSS elements, and supports various types of charts, graphs, maps, and animations. It is highly customizable and flexible, and can work with any data format.
  - Plotly: Plotly is a Python library for creating interactive and web-based data visualizations.
