
### Considerations for Service-oriented Applications

1. Service-oriented applications provide a level of abstraction that allows for greater flexibility in the development of applications.
2. Services should be designed with scalability and maintainability in mind.
3. Services should be designed to be modular and extensible.
4. Services should be designed to be loosely coupled and independent of other services.
5. Services should be designed to be highly available and resilient to failure.
6. Services should be designed to be secure and protect sensitive data.
7. Services should be designed to be interoperable and support different communication protocols.
8. Services should be designed to be extensible and support changes to the underlying technology.
9. Services should be designed to be fault tolerant and able to handle unexpected conditions.
10. Services should be designed to be testable and support automated testing.
