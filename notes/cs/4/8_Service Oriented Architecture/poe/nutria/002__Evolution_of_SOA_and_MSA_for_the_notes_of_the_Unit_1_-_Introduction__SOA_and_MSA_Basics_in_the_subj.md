
### Evolution of SOA and MSA 

* Service Oriented Architecture (SOA) is an approach to software development that focuses on the design of services, which provide a set of functions that can be used by other applications. 
* SOA is based on the idea of creating loosely coupled services that can be used in a variety of ways, allowing applications to be developed quickly and efficiently.
* Service Oriented Architecture has been used for many years and is still widely used today.
* Microservices Architecture (MSA) is a more recent approach to software development that is based on the principles of SOA. 
* MSA is focused on creating small, independent services that can be used to build applications quickly and efficiently.
* MSA is designed to be more flexible and scalable than traditional SOA, allowing applications to be built faster and more efficiently.
* MSA also allows for easier maintenance and updates, as services can be updated independently of each other.
* MSA is becoming increasingly popular as it allows for more flexibility and scalability than traditional SOA, and is better suited to modern applications and cloud-based architectures.
