
## Unit 5 - Technologies for SOA

1. Service-oriented architecture (SOA) is a software development approach that enables the creation of loosely coupled, reusable services.

2. SOA services are designed to be self-contained and independent, allowing them to be reused in different contexts without requiring modification.

3. SOA services communicate with each other using a variety of different communication protocols, such as Representational State Transfer (REST), Simple Object Access Protocol (SOAP), and Web Services Description Language (WSDL).

4. SOA services are often associated with distributed computing and distributed systems, as they are designed to be deployed across multiple machines.

5. SOA services are typically implemented using web services, which are software components that are accessible over the internet.

6. SOA services can be implemented using a variety of different technologies, such as Java, .NET, and JavaScript.

7. SOA services are typically hosted on a web server and accessed via a web browser.

8. SOA services are typically designed to be secure, reliable, and scalable. They are often built using security protocols, such as Transport Layer Security (TLS).
