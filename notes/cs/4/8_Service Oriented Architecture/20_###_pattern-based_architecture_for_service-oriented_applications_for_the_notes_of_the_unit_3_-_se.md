### Pattern-based Architecture for Service-oriented Applications for the notes of the Unit 3 - Service-Oriented Applications in the subject of Service Oriented Architecture

Pattern-based architecture is a design approach for service-oriented applications that uses well-established design patterns to address common design problems. 

The goal of pattern-based architecture is to provide a common vocabulary and set of best practices for designing and building service-oriented applications. This helps to ensure that the design is consistent, scalable, and maintainable.

Some common patterns used in pattern-based architecture for service-oriented applications include:

1. Service Layer: This pattern defines a layer of services that encapsulate business logic and provide a well-defined interface for client applications to access.

2. Service Registry: This pattern provides a central repository of information about available services, including their location and capabilities.

3. Service Contract: This pattern defines the interface that a service must implement, including the input and output data formats and the operations that it supports.

4. Data Contract: This pattern defines the structure of the data that is passed between services, including the format and structure of the data.

5. Service Composition: This pattern defines how services can be combined to create more complex applications.

In summary, pattern-based architecture provides a structured approach to designing and building service-oriented applications, using established design patterns to address common design problems.
