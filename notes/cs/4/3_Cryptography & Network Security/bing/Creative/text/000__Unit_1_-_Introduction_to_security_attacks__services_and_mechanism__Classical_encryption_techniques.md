- Security attacks are attempts by unauthorized entities to compromise the confidentiality, integrity, or availability of a system, network, or device. They can be classified into passive attacks, which involve monitoring or eavesdropping on communications, and active attacks, which involve modifying or disrupting communications. 
- Security services are the measures that provide protection against security attacks. They can be categorized into five types: authentication, confidentiality, integrity, non-repudiation, and availability. 
- Security mechanisms are the means of implementing security services. They can be classified into two types: preventive mechanisms, which deter or prevent attacks, and detective mechanisms, which detect or recover from attacks. 
- Classical encryption techniques are the methods of transforming plaintext into ciphertext using simple mathematical operations. They can be divided into two types: substitution ciphers, which replace each letter or symbol of the plaintext with another letter or symbol, and transposition ciphers, which rearrange the order of the letters or symbols of the plaintext. 
- Cryptanalysis is the study of principles and methods of deciphering ciphertext without knowing the key or the cipher. It can be performed by various techniques, such as frequency analysis, brute force, known plaintext, chosen plaintext, chosen ciphertext, etc. 
- Steganography is the art of hiding information within other information, such as images, audio, video, etc. It is different from encryption, as it does not alter the appearance of the information, but rather conceals its existence. 
- Stream ciphers are the methods of encrypting plaintext by generating a keystream, which is a sequence of random or pseudorandom bits, and combining it with the plaintext using bitwise operations, such as XOR. Stream ciphers can be synchronous, where the keystream is independent of the plaintext and ciphertext, or self-synchronizing, where the keystream depends on the previous ciphertext. 
- Block ciphers are the methods of encrypting plaintext by dividing it into fixed-length blocks, and applying a transformation function to each block using a secret key. Block ciphers can be designed using various principles, such as Shannon’s theory of confusion and diffusion, which states that a good cipher should obscure the relationship between the plaintext and the ciphertext, and spread the influence of each plaintext bit over many ciphertext bits. 
- Fiestel structure is a common way of designing block ciphers, where each block is split into two halves, and one half is passed through a round function, which involves substitution and permutation operations, and then XORed with the other half. This process is repeated for several rounds, with different subkeys derived from the main key. 
- Data Encryption Standard (DES) is a widely used block cipher, which operates on 64-bit blocks and uses a 56-bit key. It has 16 rounds of fiestel structure, and is vulnerable to brute force attacks and differential cryptanalysis. 
- Differential cryptanalysis is a technique of breaking block ciphers, which exploits the differences in the input and output pairs of the round function, and tries to find a characteristic pattern that occurs with a certain probability. It can be used to recover the subkeys or the main key of the cipher. 
- Block cipher modes of operation are the ways of using block ciphers to encrypt data that is larger than the block size. They can be classified into four types: electronic codebook (ECB), where each block is encrypted independently, cipher block chaining (CBC), where each block is XORed with the previous ciphertext before encryption, cipher feedback (CFB), where the previous ciphertext is encrypted and XORed with the current plaintext, and output feedback (OFB), where the previous output of the cipher is encrypted and XORed with the current plaintext.
