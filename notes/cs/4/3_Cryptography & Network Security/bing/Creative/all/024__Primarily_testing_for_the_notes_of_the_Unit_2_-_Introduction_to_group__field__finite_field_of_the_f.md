- A primality test is an algorithm for determining whether an input number is prime. Among other fields of mathematics, it is used for cryptography. Unlike integer factorization, primality tests do not generally give prime factors, only stating whether the input number is prime or not.
- Primality testing is important for cryptography because many public key crypto systems, such as RSA, rely on the difficulty of factoring large numbers that are products of two large primes. To generate such numbers, one needs a fast and reliable way of checking if a randomly generated number is prime or not.
- There are two types of primality tests: deterministic and probabilistic. Deterministic tests always give the correct answer, but they are usually slower than probabilistic tests, which can give a wrong answer with a very small probability. Probabilistic tests are often preferred for practical applications, as they can handle very large numbers efficiently.
- Some examples of deterministic primality tests are:
  - Trial division: This is the simplest primality test, which checks if the input number is divisible by any prime number between 2 and its square root. If so, then the number is composite. Otherwise, it is prime. This method is very slow for large numbers, as it requires many divisions.
  - Sieve of Eratosthenes: This is an ancient algorithm that generates all the primes up to a given limit by marking the multiples of each prime, starting from 2, as composite. The remaining numbers are prime. This method is fast for finding small primes, but it requires a lot of memory to store the sieve.
  - AKS algorithm: This is a modern algorithm that was discovered in 2002, and it is the first deterministic primality test that runs in polynomial time, meaning that its running time depends on the number of digits of the input number, not on its value. The algorithm is based on a generalization of Fermat's little theorem, and it uses some advanced concepts from number theory and algebra.
- Some examples of probabilistic primality tests are:
  - Fermat primality test: This is a simple primality test that is based on Fermat's little theorem, which states that if p is a prime number, then for any integer a, a^p ≡ a (mod p). The test chooses a random number a between 2 and p-1, and checks if a^p-1 ≡ 1 (mod p). If not, then p is definitely composite. If yes, then p is probably prime, but there is a chance that p is a pseudoprime, a composite number that passes the test for some values of a. The test can be repeated with different values of a to reduce the probability of error.
