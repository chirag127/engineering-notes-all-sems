- Modular arithmetic is a system of arithmetic for integers, where values reset to zero and begin to increase again, after reaching a certain predefined value, called the modulus (modulo) .
- Modular arithmetic is widely used in computer science and cryptography, as it directly underpins public key systems such as RSA and Diffie–Hellman, and provides finite fields which underlie elliptic curves, and is used in a variety of symmetric key algorithms including Advanced Encryption Standard (AES), International Data Encryption Algorithm (IDEA), and RC4 .
- The modulo operator (%) is used to calculate the remainder of a division operation. For example, 7 % 3 = 1, as 7 divided by 3 gives a quotient of 2 and a remainder of 1.
- The modulo operator can also be used to perform modular arithmetic, which is the arithmetic of congruence classes. Two integers are congruent modulo n if they have the same remainder when divided by n. For example, 7 and 10 are congruent modulo 3, as they both have a remainder of 1 when divided by 3. We write this as 7 ≡ 10 (mod 3).
- Modular arithmetic has the following properties :
  - (A + B) mod C = (A mod C + B mod C) mod C
  - (A - B) mod C = (A mod C - B mod C) mod C
  - (A * B) mod C = (A mod C * B mod C) mod C
  - (A / B) mod C = (A mod C * B^-1 mod C) mod C, where B^-1 is the modular inverse of B modulo C, such that B * B^-1 ≡ 1 (mod C)
- Modular arithmetic can be visualized using a clock, where the numbers on the clock face represent the congruence classes modulo n, where n is the number of hours on the clock. For example, a 12-hour clock can be used to represent the congruence classes modulo 12. To perform modular arithmetic using a clock, we can start at 0 and move around the clock by the number of steps given by the operands, in the direction given by the sign of the operands. For example, to calculate 8 + 5 (mod 12), we can start at 0 and move 8 steps clockwise, then 5 steps clockwise, and end up at 1. Therefore, 8 + 5 ≡ 1 (mod 12).
- Modular arithmetic is useful for cryptography because it allows us to perform arithmetic operations on large numbers without having to deal with their actual values, which can be computationally expensive and prone to errors. Instead, we can work with smaller numbers that represent the congruence classes of the large numbers modulo some modulus. For example, to encrypt a message using RSA, we can use the formula C = M^e mod n, where C is the ciphertext, M is the plaintext, e is the public exponent, and n is the public modulus. To decrypt the ciphertext, we can use the formula M = C^d mod n, where d is the private exponent. By using modular arithmetic, we can avoid having to calculate the large values of M^e and C^d, which can be infeasible for large values of e and d.
