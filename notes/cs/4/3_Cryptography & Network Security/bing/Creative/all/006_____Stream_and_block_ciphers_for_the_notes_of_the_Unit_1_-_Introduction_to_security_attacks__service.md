# Stream and block ciphers

- Stream and block ciphers are two types of symmetric encryption techniques that use a secret key to transform plaintext into ciphertext and vice versa.
- Stream ciphers encrypt one bit or byte of plaintext at a time, using a keystream that is generated from the secret key and an initialization vector (IV).
- Block ciphers encrypt a fixed-length block of plaintext (usually 64 or 128 bits) at a time, using a secret key and a mode of operation that specifies how to combine the blocks.
- Stream ciphers are faster and more suitable for continuous data streams, such as voice or video, while block ciphers are more secure and more suitable for discrete data, such as files or messages.
- Stream ciphers are vulnerable to attacks if the same keystream is used more than once, while block ciphers are vulnerable to attacks if the same plaintext block is encrypted with the same key more than once.
- Examples of stream ciphers are RC4, A5/1, and ChaCha20, while examples of block ciphers are DES, AES, and Blowfish.
