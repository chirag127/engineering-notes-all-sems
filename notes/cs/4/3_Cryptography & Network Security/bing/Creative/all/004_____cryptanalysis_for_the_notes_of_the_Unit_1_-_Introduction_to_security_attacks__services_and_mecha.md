# Cryptanalysis

Cryptanalysis is the process of analyzing information systems, such as codes, ciphers, or encrypted text, in order to understand hidden aspects of the systems or to break them. Cryptanalysis is used to breach cryptographic security systems and gain access to the contents of encrypted messages, even if the cryptographic key or the algorithm used to encrypt them is unknown  .

Cryptanalysis can be divided into two main types:

- **Ciphertext-only attack**: The attacker only has access to one or more encrypted messages, and tries to recover the plaintext or the key by using statistical analysis, pattern recognition, or brute force methods.
- **Known-plaintext attack**: The attacker has access to some pairs of plaintext and ciphertext, and tries to find the key or the algorithm by using mathematical techniques, such as linear or differential cryptanalysis.

Cryptanalysis can also be classified based on the type of cipher or cryptosystem being attacked:

- **Substitution cipher**: A cipher that replaces each letter or symbol in the plaintext with another letter or symbol, according to a fixed rule or key. For example, the Caesar cipher shifts each letter by a certain number of positions in the alphabet. Cryptanalysis of substitution ciphers can be done by using frequency analysis, which exploits the fact that some letters or symbols are more common than others in a given language or context.
- **Transposition cipher**: A cipher that rearranges the order of the letters or symbols in the plaintext, according to a fixed rule or key. For example, the rail fence cipher writes the plaintext in a zigzag pattern on a number of rails, and then reads it off row by row. Cryptanalysis of transposition ciphers can be done by using anagramming, which exploits the fact that some combinations of letters or symbols are more likely than others in a given language or context.
- **Steganography**: The art of hiding information within other information, such as an image, a sound, or a text. For example, the least significant bits of an image can be used to store a secret message. Cryptanalysis of steganography can be done by using statistical analysis, visual inspection, or watermark detection, which exploits the fact that some parts of the information may have been altered or added to hide the secret information.
- **Stream cipher**: A cipher that encrypts each bit or symbol of the plaintext with a bit or symbol of a keystream, which is generated by a pseudorandom number generator or a function of the key and a nonce. For example, the one-time pad cipher uses a keystream that is as long as the plaintext and is truly random. Cryptanalysis of stream ciphers can be done by using correlation attacks, which exploit the fact that some bits or symbols of the keystream may be related to each other or to the plaintext, or by using algebraic attacks, which exploit the fact that some functions of the keystream may have a simple mathematical structure.
- **Block cipher**: A cipher that encrypts each block of a fixed size of the plaintext with a key, using a mathematical function that is reversible. For example, the Data Encryption Standard (DES) cipher uses a 64-bit block and a 56-bit key, and applies a series of permutations and substitutions, known as the Feistel structure, to the block. Cryptanalysis of block ciphers can be done by using brute force attacks, which try all possible keys, or by using differential or linear cryptanalysis, which exploit the fact that some pairs of plaintexts or ciphertexts may have a certain probability of producing a certain difference or a certain linear relation between them.
