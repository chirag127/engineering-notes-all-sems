Modular arithmetic is a system of arithmetic for integers, where numbers "wrap around" when reaching a certain value, called the modulus. For example, if the modulus is 12, then 15 is congruent to 3 modulo 12, because 15 - 3 = 12 is a multiple of 12. We write this as 15 ≡ 3 (mod 12).

One way to visualize modular arithmetic is by using a clock, where the numbers 0 to 11 are arranged in a circle. To find the result of A mod B, we start at 0 and move around the clock A steps in the clockwise direction if A is positive, or in the counter-clockwise direction if A is negative. Wherever we land is our solution. For example, 8 mod 4 = 0, 7 mod 2 = 1, and -5 mod 3 = 1.
