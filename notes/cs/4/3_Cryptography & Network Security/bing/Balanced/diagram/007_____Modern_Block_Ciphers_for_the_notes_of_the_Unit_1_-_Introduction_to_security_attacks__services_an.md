### Modern Block Ciphers

- Block ciphers are symmetric-key encryption algorithms that operate on fixed-length blocks of plaintext and produce blocks of ciphertext of the same length.
- Block ciphers can be classified into two types: substitution-permutation networks (SPNs) and Feistel networks. SPNs apply a series of substitution and permutation layers to the plaintext, while Feistel networks apply a series of round functions that combine the plaintext with a subkey and then swap the halves of the block.
- Shannon's theory of confusion and diffusion states that a good cipher should have two properties: confusion, which means that the relationship between the plaintext and the ciphertext is complex and obscure, and diffusion, which means that a change in one bit of the plaintext affects many bits of the ciphertext.
- Data Encryption Standard (DES) is a widely used block cipher that was standardized in 1977. It has a block size of 64 bits and a key size of 56 bits. It uses a Feistel network with 16 rounds and a complex key schedule. DES is considered insecure today because of its small key size and the existence of efficient attacks, such as differential cryptanalysis and linear cryptanalysis.
- Differential cryptanalysis is a technique that exploits the statistical properties of the cipher to find correlations between the differences of plaintext pairs and the differences of ciphertext pairs. It can be used to recover the subkeys of the cipher by analyzing a large number of plaintext-ciphertext pairs.
- Block cipher modes of operation are methods of using a block cipher to encrypt or decrypt messages of arbitrary length. Some common modes are: electronic codebook (ECB), which encrypts each block independently; cipher block chaining (CBC), which XORs each block with the previous ciphertext block before encryption; cipher feedback (CFB), which uses the previous ciphertext block as the input to the cipher and XORs the output with the plaintext block; output feedback (OFB), which uses the output of the cipher as a keystream and XORs it with the plaintext block; and counter (CTR), which uses a counter value as the input to the cipher and XORs the output with the plaintext block.
- Triple DES (3DES) is a variant of DES that applies three DES encryptions with different keys to each block. It can be seen as a way of increasing the key size of DES to 168 bits. However, 3DES is also vulnerable to some attacks, such as the meet-in-the-middle attack, and it is slower than other modern block ciphers.
