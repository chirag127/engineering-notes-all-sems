### Modern Block Ciphers
- Block ciphers are symmetric-key encryption algorithms that operate on fixed-length blocks of plaintext and produce blocks of ciphertext of the same length.
- Block ciphers can be classified into two types: substitution-permutation networks (SPNs) and Feistel networks (FNs).
- SPNs are based on the idea of applying multiple rounds of substitution and permutation operations to the plaintext blocks, where substitution is a nonlinear mapping and permutation is a linear mapping.
- FNs are based on the idea of dividing the plaintext block into two halves and applying a round function to one half, which depends on the other half and a subkey, and then swapping the halves. This process is repeated for several rounds, with different subkeys for each round.
- Shannon's theory of confusion and diffusion states that a good cipher should have two properties: confusion, which means that the relationship between the plaintext and the ciphertext should be complex and obscure, and diffusion, which means that a small change in the plaintext should affect many bits in the ciphertext.
- Data Encryption Standard (DES) is a widely used block cipher that was standardized by NIST in 1977. It has a block size of 64 bits and a key size of 56 bits. It uses a Feistel network with 16 rounds and a complex key schedule. DES is vulnerable to brute-force attacks and differential cryptanalysis, which are techniques that exploit the statistical properties of the cipher to recover the key or the plaintext.
- Triple DES (3DES) is a variant of DES that applies DES three times with two or three different keys. It has a block size of 64 bits and a key size of 112 or 168 bits. It is more secure than DES, but also slower and less efficient.
- Block cipher modes of operation are methods of using block ciphers to encrypt or decrypt messages of arbitrary length. Some common modes are:
  - Electronic Codebook (ECB): Each block of plaintext is encrypted independently with the same key. This mode is simple and fast, but insecure, as it does not hide patterns or provide integrity.
  - Cipher Block Chaining (CBC): Each block of plaintext is XORed with the previous ciphertext block before being encrypted with the same key. The first block is XORed with an initialization vector (IV). This mode provides confidentiality, but not integrity or authentication.
  - Cipher Feedback (CFB): The cipher is used as a stream cipher, where the output of encrypting an IV is XORed with the first plaintext block to produce the first ciphertext block, and then the output of encrypting the first ciphertext block is XORed with the second plaintext block to produce the second ciphertext block, and so on. This mode provides confidentiality and error propagation, but not integrity or authentication.
  - Output Feedback (OFB): The cipher is used as a stream cipher, where the output of encrypting an IV is XORed with the first plaintext block to produce the first ciphertext block, and then the output of encrypting the IV is XORed with the second plaintext block to produce the second ciphertext block, and so on. This mode provides confidentiality and error resilience, but not integrity or authentication.
  - Counter (CTR): The cipher is used as a stream cipher, where the output of encrypting a counter value is XORed with the first plaintext block to produce the first ciphertext block, and then the counter is incremented and encrypted again to XOR with the second plaintext block to produce the second ciphertext block, and so on. This mode provides confidentiality and parallelism, but not integrity or authentication.
