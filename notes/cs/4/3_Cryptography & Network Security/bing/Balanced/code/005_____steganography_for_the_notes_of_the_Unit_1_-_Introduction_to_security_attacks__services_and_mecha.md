# Steganography

- Steganography is the practice of concealing messages or information within other nonsecret text or data    .
- Steganography can be used along with cryptography as an extra-secure method to protect data.
- Steganography techniques can be applied to images, video files, audio files, or text files .
- The main goal of steganography is to hide the existence of the secret message from anyone who is not the intended recipient .
- Steganography can be classified into two types: technical steganography and linguistic steganography.
  - Technical steganography uses physical or digital media to hide the message, such as hiding data in the pixels of an image, or in the least significant bits of an audio file.
  - Linguistic steganography uses natural language to hide the message, such as using code words, acronyms, or hidden meanings in text.
- Steganography can be used for various purposes, such as communication, espionage, watermarking, or cyber attacks  .
- Steganography can be detected by using steganalysis, which is the process of analyzing the suspected media or text for any hidden information .
- Steganography can be evaluated by using two criteria: capacity and security.
  - Capacity refers to the amount of data that can be hidden in the cover media or text without affecting its quality or appearance.
  - Security refers to the difficulty of detecting the hidden data by an unauthorized party.
