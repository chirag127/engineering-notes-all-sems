### Terminologies in Testing for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing
1. Test Case: A set of conditions or variables under which a tester will determine whether an application or system is working as intended.

2. Test Suite: Collection of test cases, test scripts, and test data that are used to test a software application.

3. Test Plan: A document that outlines the strategy, scope, objectives, and schedule of testing activities for a software application.

4. Test Script: A set of instructions that a tester follows to perform a test.

5. Test Data: The input values and expected results used in testing.

6. Test Environment: The hardware and software environment in which testing takes place.

7. Test Coverage: The extent to which testing activities examine the application or system.

8. Test Metrics: Quantifiable measures used to evaluate the effectiveness, efficiency, and quality of testing.

9. Test Result: The outcome of a test, indicating whether the test passed or failed.

10. Defect: An error, flaw, mistake, failure, or fault in a software application that causes it to produce incorrect or unexpected results.
