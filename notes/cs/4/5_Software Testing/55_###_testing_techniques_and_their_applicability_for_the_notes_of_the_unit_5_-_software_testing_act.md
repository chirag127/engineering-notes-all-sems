### Testing techniques and their applicability for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing
Testing techniques are methods used to evaluate the quality of software. They are applied during the testing phase of the software development life cycle. There are several types of testing techniques, including:

1. Black Box Testing: This technique tests the functionality of the software without knowledge of its internal structure or code.

2. White Box Testing: This technique tests the internal structure of the software, including its code, algorithms, and data structures.

3. Gray Box Testing: This technique combines aspects of both black box and white box testing.

4. Unit Testing: This technique tests individual units or components of the software to ensure they work as intended.

5. Integration Testing: This technique tests the interaction between different components of the software.

6. System Testing: This technique tests the software as a whole to ensure it meets the specified requirements.

7. Acceptance Testing: This technique tests the software to determine if it is acceptable for release to the customer.

Each technique has its own strengths and weaknesses, and the choice of technique depends on the specific requirements of the software being tested. For example, unit testing is useful for catching bugs early in the development process, while acceptance testing is more focused on ensuring the software meets the customer's needs.
