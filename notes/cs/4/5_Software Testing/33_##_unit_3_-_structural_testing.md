## Unit 3 - Structural Testing

Structural testing is a software testing technique that focuses on verifying the design and architecture of an application. It involves testing the internal structure of the code and the relationships between different components to ensure that they are functioning as intended. This type of testing is usually performed early in the software development life cycle, before functional testing begins. The goal of structural testing is to identify and fix any defects or issues in the design and architecture before they become more difficult or expensive to fix. Some common techniques used in structural testing include code inspections, code walk-throughs, and automated testing tools. The results of structural testing are used to improve the overall quality and reliability of the software.
