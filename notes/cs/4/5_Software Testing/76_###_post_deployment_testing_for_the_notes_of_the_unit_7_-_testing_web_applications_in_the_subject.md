### Post Deployment Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing
Post-deployment testing is a type of software testing performed after the software has been deployed to production. The main objective of this testing is to verify that the software is functioning as expected in the live environment and to identify any issues that may impact the end-users.

It includes:

1. Performance testing: to verify that the software meets the performance requirements and to identify any performance bottlenecks.

2. User acceptance testing: to ensure that the software meets the end-users' expectations and requirements.

3. Security testing: to verify that the software is secure and protected against potential security threats.

4. Monitoring: to monitor the software's performance and behavior in the live environment.

5. Maintenance testing: to verify that the software continues to function as intended after any changes or updates have been made.

It is important to perform post-deployment testing to ensure that the software is functioning correctly and to minimize the risk of any issues impacting the end-users.
