Unit 1 - Review of Software Engineering

1. Software testing is an important aspect of software engineering and is used to verify the functionality and quality of software applications.

2. Testing methods include manual testing, automated testing, and hybrid testing.

3. The goals of testing include finding bugs, improving quality, and ensuring that the software meets its requirements.

4. Test cases are used to verify the functionality of software and are typically written before the software is developed.

5. Test-driven development (TDD) is a software development methodology where tests are written before the code is written.

6. Test automation is the use of software tools to automate the testing process.

7. Test management involves the planning, design, execution, and reporting of tests.

8. Test metrics are used to measure the effectiveness of testing and to track progress.

9. Test documentation includes test plans, test cases, and test reports.

10. Test-driven development, test automation, and test management are key aspects of software testing and are essential for ensuring the quality of software applications.
