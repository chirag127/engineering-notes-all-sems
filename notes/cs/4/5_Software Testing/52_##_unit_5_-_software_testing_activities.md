## Unit 5 - Software Testing Activities
Software testing activities are a set of tasks performed to evaluate the quality and functionality of software. Unit 5 covers the following testing activities:

1. Planning and Preparation: Defining the testing strategy, creating test plans, identifying test cases, and preparing test data.

2. Test Design: Creating test cases, identifying test conditions, and defining test data.

3. Test Execution: Running tests, logging defects, and reporting results.

4. Test Closure: Reviewing test results, documenting lessons learned, and archiving test artifacts.

5. Test Automation: Automating test cases, creating test scripts, and integrating testing into the development process.

Each of these activities is important in ensuring that software meets its requirements and is of high quality. Effective testing requires careful planning, attention to detail, and continual improvement.
