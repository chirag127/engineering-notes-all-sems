# Exploratory Testing

Exploratory Testing is a type of software testing where test cases are not created in advance but testers check the system on the fly. They may note down ideas about what to test before test execution. The focus of exploratory testing is more on testing as a "thinking" activity.

Here are some key points to remember about Exploratory Testing:

1. Exploratory testing is an approach to software testing that is concisely described as simultaneous learning, test design, and test execution.
2. It is a powerful and fun approach to testing that can be used to complement other testing methods.
3. Exploratory testing is all about discovery, investigation, and learning.
4. It emphasizes personal freedom and responsibility of the individual tester.
5. Exploratory testing is done in a less structured way, with the tester actively controlling the design of the tests as they are performed and using information gained while testing to design new and better tests.
6. Exploratory testing is often used when there are no or poor specifications and when time is severely limited.
7. Exploratory testing can be used to find defects that are not easy to find using other testing techniques.
