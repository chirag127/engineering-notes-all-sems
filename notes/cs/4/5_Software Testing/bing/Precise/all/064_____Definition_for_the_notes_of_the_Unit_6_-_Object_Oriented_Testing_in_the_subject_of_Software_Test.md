# Unit 6 - Object Oriented Testing

### Definition

Object-oriented testing is a method of software testing that validates the functioning of object-oriented software. This type of testing is performed to ensure that the individual objects within the software are working as intended and that the interactions between objects are correct. Some key aspects of object-oriented testing include:

1. **State-based testing:** This involves testing the behavior of an object by changing its state and verifying that the object behaves correctly in each state.

2. **Interaction testing:** This involves testing the interactions between objects to ensure that the communication between objects is correct.

3. **Inheritance testing:** This involves testing the inheritance relationships between classes to ensure that the behavior of a subclass is consistent with the behavior of its superclass.

4. **Polymorphism testing:** This involves testing the polymorphic behavior of objects to ensure that an object can be used interchangeably with other objects of the same type.

Object-oriented testing is an important part of the software development process, as it helps to ensure that the software is reliable and meets the requirements of the user. It is typically performed by a team of testers who use a variety of testing techniques to validate the functioning of the software.
