## Unit 6 - Object Oriented Testing

1. Object-oriented testing is a method of testing software that is based on the principles of object-oriented programming.
2. This type of testing focuses on the interactions between objects and the behavior of individual objects.
3. Object-oriented testing involves creating test cases that exercise the methods and properties of the objects in the system.
4. This type of testing can help to ensure that the objects in the system are functioning correctly and that they are interacting with each other in the expected manner.
5. Object-oriented testing can be performed at various levels, including unit testing, integration testing, and system testing.
6. Unit testing involves testing individual objects and their methods, while integration testing focuses on the interactions between objects.
7. System testing, on the other hand, tests the entire system as a whole to ensure that it meets the specified requirements.
8. Object-oriented testing can be a powerful tool for ensuring the quality and reliability of object-oriented software systems.
