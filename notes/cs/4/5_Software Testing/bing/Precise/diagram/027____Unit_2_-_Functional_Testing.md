## Unit 2 - Functional Testing

Functional testing is a type of software testing that verifies that the software system or application is functioning according to the specified requirements. The main objective of functional testing is to ensure that the software meets the user's needs and expectations.

Functional testing involves the following steps:

1. **Identification of functions:** The first step in functional testing is to identify the functions that the software is expected to perform. This can be done by reviewing the software requirements specification (SRS) document.

2. **Creation of test cases:** Once the functions have been identified, test cases are created to test each function. Test cases should be designed to cover all possible scenarios, including both positive and negative test cases.

3. **Execution of test cases:** The test cases are then executed to verify that the software functions as expected. Any deviations from the expected behavior are recorded as defects.

4. **Reporting of defects:** Defects identified during functional testing are reported to the development team for resolution.

5. **Regression testing:** Once the defects have been resolved, regression testing is performed to ensure that the changes made to the software have not introduced any new defects.

Functional testing can be performed manually or using automated testing tools. Automated functional testing can save time and effort, and can also increase the accuracy and reliability of the testing process.

In summary, functional testing is an essential part of the software development process that helps to ensure that the software meets the user's needs and expectations. It involves the identification of functions, creation of test cases, execution of test cases, reporting of defects, and regression testing. Functional testing can be performed manually or using automated testing tools.
