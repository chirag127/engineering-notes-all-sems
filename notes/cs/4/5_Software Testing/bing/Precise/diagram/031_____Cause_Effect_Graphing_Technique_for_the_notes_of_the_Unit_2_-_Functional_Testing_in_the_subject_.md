### Cause Effect Graphing Technique

Cause Effect Graphing Technique is a black-box testing technique used in functional testing. It is used to identify test cases that exercise the interactions between different input conditions. Here are some key points to note about this technique:

1. It is a graphical representation of inputs and the associated outputs effects that can be used to design test cases.
2. It helps to identify the relationships between different input conditions and their effects on the system.
3. It is based on the principle that for a given input condition, there is an associated output effect.
4. It is used to reduce the number of test cases by identifying and eliminating redundant test cases.
5. It is useful for testing complex systems with multiple input conditions and interactions between them.

In summary, Cause Effect Graphing Technique is a useful tool for designing test cases in functional testing, particularly for complex systems with multiple input conditions and interactions between them. It helps to identify the relationships between different input conditions and their effects on the system, and can reduce the number of test cases by eliminating redundant ones.
