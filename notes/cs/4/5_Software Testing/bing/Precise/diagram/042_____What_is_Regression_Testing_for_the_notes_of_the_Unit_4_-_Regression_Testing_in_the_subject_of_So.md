### Unit 4 - Regression Testing

#### What is Regression Testing

Regression testing is a type of software testing that is performed to ensure that changes made to the code, such as adding new features or fixing bugs, do not negatively impact the existing functionality of the software. The goal of regression testing is to catch any unintended side effects that may have been introduced during the development process.

Some key points to remember about regression testing are:

- It is performed after changes have been made to the code.
- It is used to ensure that the existing functionality of the software is not negatively impacted by the changes.
- It can be performed manually or using automated testing tools.
- It is an important part of the software development process, as it helps to catch any unintended side effects that may have been introduced during development.
