### Terminologies in Testing

1. **Testing**: The process of evaluating a system or its component(s) with the intent to find whether it satisfies the specified requirements or not.
2. **Test Case**: A set of conditions or variables under which a tester will determine whether a system under test satisfies requirements or works correctly.
3. **Test Plan**: A document describing the scope, approach, resources, and schedule of intended test activities.
4. **Test Suite**: A collection of test cases that are intended to be used to test a software program to show that it has some specified set of behaviors.
5. **Test Scenario**: A hypothetical story used to help a person think through a complex problem or system.
6. **Test Script**: A written set of steps that should be performed to verify a particular functionality or feature of the software application.
7. **Test Harness**: A collection of software and test data configured to test a program unit by running it under varying conditions and monitoring its behavior and outputs.
8. **Test Data**: Data that has been specifically identified for use in tests, typically of a computer program.
9. **Test Environment**: The hardware and software environment in which tests will be run, and any other software or tools that will be used to conduct the tests.
10. **Test Coverage**: A measure of the proportion of the codebase that is being tested by a particular test suite.
