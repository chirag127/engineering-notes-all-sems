### Test for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. Software Engineering is the application of a systematic, disciplined, and quantifiable approach to the development, operation, and maintenance of software.
2. The main goal of software engineering is to produce high-quality software that meets the needs of its users within a predictable schedule and budget.
3. The software development process includes activities such as requirements analysis, design, coding, testing, and maintenance.
4. Software testing is an important part of the software development process. It involves the execution of a program or system with the intent of finding errors.
5. There are several types of testing, including unit testing, integration testing, system testing, and acceptance testing.
6. Software testing can be performed manually or with the use of automated tools.
7. The goal of software testing is to ensure that the software meets the specified requirements and to identify and fix any defects before the software is released to the end-users.
8. Software maintenance involves making changes to the software after it has been delivered to the end-users. These changes can include fixing defects, adding new features, or improving the performance of the software.
9. Software engineering principles and practices can help to improve the quality of software and reduce the cost and time required for software development and maintenance.
