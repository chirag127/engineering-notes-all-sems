## Unit 5 - Software Testing Activities

Software testing is a process of evaluating the functionality of a software application to find any software bugs. It checks whether the developed software met the specified requirements and identifies any defects to be fixed. Here are some of the key activities involved in software testing:

1. **Test Planning:** This involves defining the scope and objectives of the testing process, identifying the test environment, and preparing a test schedule.

2. **Test Design:** This involves identifying test cases and test scenarios, and preparing test data.

3. **Test Execution:** This involves executing the test cases and recording the results.

4. **Defect Reporting:** This involves identifying, documenting, and reporting any defects found during testing.

5. **Test Closure:** This involves evaluating the testing process, preparing a test summary report, and archiving test artifacts for future reference.

These activities are essential to ensure that the software is of high quality and meets the needs of the users. It is important to note that software testing is an iterative process and may involve repeating some of these activities until all defects are fixed and the software is ready for release.
