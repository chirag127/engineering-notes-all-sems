### Generation of Graph from Program

1. The first step in generating a graph from a program is to identify the control flow of the program. This can be done by analyzing the source code and identifying the different paths that can be taken during execution.
2. Once the control flow has been identified, the next step is to represent it in the form of a graph. This can be done by creating nodes for each statement or block of statements in the program, and edges to represent the flow of control between them.
3. The resulting graph is known as a control flow graph (CFG). It is a visual representation of the program's structure and can be used to identify potential areas for testing.
4. In the context of structural testing, the CFG can be used to identify different test cases that can be used to exercise the different paths in the program. This can help to ensure that the program is thoroughly tested and that all potential issues are identified and addressed.
5. There are several tools and techniques available for generating CFGs from programs, including static analysis tools and manual analysis by a developer or tester. The choice of tool or technique will depend on the specific needs and requirements of the project.
