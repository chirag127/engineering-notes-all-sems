## Unit 1 - Review of Software Engineering

Software engineering is the systematic application of engineering approaches to the development of software. It involves the use of principles, methods, and tools to design, develop, test, and maintain software systems.

Some key points to remember about software engineering include:

1. Software engineering is concerned with the entire software development life cycle, from requirements gathering to maintenance and evolution of the software system.
2. Software engineering involves the use of various methodologies, such as agile development, waterfall, and spiral, to manage the software development process.
3. Software engineering involves the use of various tools, such as integrated development environments (IDEs), version control systems, and testing frameworks, to support the development process.
4. Software engineering involves the use of various techniques, such as object-oriented design, design patterns, and refactoring, to improve the quality of the software system.
5. Software engineering involves the use of various quality assurance techniques, such as testing, code reviews, and static analysis, to ensure the reliability and correctness of the software system.
