### Boundary Value Analysis

Boundary Value Analysis is a black box testing technique used in functional testing. It is a method of testing the boundary values between valid and invalid partitions. This technique is based on the principle that the inputs at the boundaries have a higher probability of being incorrect compared to the inputs within the range.

Here are some key points to remember about Boundary Value Analysis:

1. It is a black box testing technique used in functional testing.
2. It tests the boundary values between valid and invalid partitions.
3. Inputs at the boundaries have a higher probability of being incorrect compared to the inputs within the range.
4. It is used to identify defects at the boundaries of input domains rather than in the center of the input domains.
5. It is based on the principle that if the system works correctly for the boundary values, it is more likely to work correctly for the values within the boundary.

Boundary Value Analysis is an effective technique for reducing the number of test cases while still maintaining a high level of test coverage. It is commonly used in combination with other testing techniques such as Equivalence Partitioning.
