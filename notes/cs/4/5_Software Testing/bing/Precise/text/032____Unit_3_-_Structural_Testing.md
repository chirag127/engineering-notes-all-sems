## Unit 3 - Structural Testing

Structural testing, also known as white-box testing, is a method of testing software that involves examining the internal structure of the code being tested. This type of testing is typically performed by developers and focuses on the implementation of the software, rather than its functionality.

Some key points to remember about structural testing are:

1. Structural testing is also known as white-box testing or glass-box testing.
2. It involves examining the internal structure of the code being tested.
3. It is typically performed by developers.
4. It focuses on the implementation of the software, rather than its functionality.
5. It can help identify issues with the code that may not be apparent through functional testing alone.
6. Common techniques used in structural testing include statement coverage, branch coverage, and path coverage.

Overall, structural testing is an important part of the software development process that can help ensure the quality and reliability of the code being produced. By examining the internal structure of the code, developers can identify and address potential issues before they become problems.
