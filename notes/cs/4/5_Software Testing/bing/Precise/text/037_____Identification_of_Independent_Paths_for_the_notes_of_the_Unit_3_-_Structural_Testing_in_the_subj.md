### Identification of Independent Paths

1. **Control Flow Graph:** A control flow graph is a graphical representation of the flow of control within a program. It is used to identify independent paths within the program.

2. **Cyclomatic Complexity:** Cyclomatic complexity is a measure of the number of independent paths within a program. It is calculated by counting the number of decision points within the program and adding one.

3. **Basis Path Testing:** Basis path testing is a technique used to identify independent paths within a program. It involves identifying the set of basis paths that provide full coverage of the program's control flow graph.

4. **Independent Paths:** Independent paths are paths within a program that do not share any common edges. These paths can be identified by using techniques such as basis path testing and cyclomatic complexity.

5. **Path Coverage:** Path coverage is a measure of the extent to which the independent paths within a program have been tested. It is calculated by dividing the number of independent paths that have been tested by the total number of independent paths within the program.

These are some of the key concepts related to the identification of independent paths in the context of structural testing in software testing. It is important to understand these concepts in order to effectively identify and test independent paths within a program.
