### Unit 4 - Regression Testing

Regression testing is the process of re-running functional and non-functional tests on software that has undergone changes, such as code updates or improvements, to ensure that the software still performs as expected. This type of testing is responsible for the overall stability and functionality of the existing features. If the software does not perform as expected after the changes, this is called a regression.

Some tools used for regression testing include Katalon Studio, Selenium, Watir (Web Application Testing in Ruby), and IBM Rational Functional Tester.

In summary, regression testing is an important practice in software development that helps ensure that changes to the code do not negatively impact the functionality of the software. It is performed using a variety of tools and is an integral part of the software development process.
