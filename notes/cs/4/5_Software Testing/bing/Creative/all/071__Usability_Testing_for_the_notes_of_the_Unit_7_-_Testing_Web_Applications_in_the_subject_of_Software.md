### Usability Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

- Usability testing is a method of testing the functionality of a web application by observing real users as they attempt to complete tasks on it .
- The goal of usability testing is to reveal areas of confusion and uncover opportunities to improve the overall user experience.
- Usability testing helps us to uncover problems, discover opportunities, and learn about users.
- Usability testing involves examining the user-friendliness of the web application’s interface to the end-user .
- Usability testing checks the following aspects of a web application :
  - Navigation: how easy it is for users to move around the web application and find what they need
  - Content: how clear, concise, and relevant the information on the web application is
  - Layout: how well the web application uses the available space and organizes the elements on the screen
  - Design: how appealing, consistent, and accessible the web application looks
  - Feedback: how well the web application communicates with the users and provides them with guidance and error messages
  - Performance: how fast and reliable the web application is
- Usability testing involves the following steps:
  1. Develop a testing strategy that ensures all functions of your web application will be examined
  2. Recruit test participants, either internally or externally
  3. Run the test under the observation of experts
  4. Analyze the results and improve your web application accordingly
- Usability testing can be done at any stage of the web application development process, from prototyping to the finished product.
- Usability testing can be done in different ways, such as:
  - Moderated testing: the facilitator guides the participant through the test process and asks follow-up questions
  - Unmoderated testing: the participant performs the test without any human intervention, using an application or a tool
  - Remote testing: the participant and the facilitator are in different locations and communicate through a video call or a chat
  - In-person testing: the participant and the facilitator are in the same location and interact face-to-face
  - Lab testing: the test is conducted in a controlled environment with special equipment, such as eye-tracking or biometric devices
  - Guerrilla testing: the test is conducted in a public place with random people who are asked to try the web application
- Usability testing can be done with different types of tasks, such as:
  - Scenario-based tasks: the participant is given a realistic situation and a goal to achieve using the web application
  - Exploratory tasks: the participant is asked to explore the web application and share their thoughts and impressions
  - Comparison tasks: the participant is asked to compare two or more web applications or versions and state their preferences and reasons
  - Benchmarking tasks: the participant is asked to perform the same task on different web applications or versions and measure the time, errors, and satisfaction
- Usability testing can be done with different types of data, such as:
  - Quantitative data: numerical data that can be measured and analyzed statistically, such as time, errors, clicks, ratings, etc.
  - Qualitative data: descriptive data that can be observed and interpreted, such as comments, feedback, emotions, behaviors, etc.
- Usability testing can be done with different types of tools, such as:
  - Screen-recording tools: tools that capture the screen activity and the audio of the participant during the test, such as Usersnap, Hotjar, etc.
  - Survey tools: tools that collect the feedback and the ratings of the participant after the test, such as Google Forms, SurveyMonkey, etc.
  - Analytics tools: tools that track and analyze the usage and the behavior of the users on the web application, such as Google Analytics, Mixpanel, etc.
  - Testing platforms: tools that provide a comprehensive solution for conducting and managing usability tests, such as UserTesting, UserZoom, etc.
