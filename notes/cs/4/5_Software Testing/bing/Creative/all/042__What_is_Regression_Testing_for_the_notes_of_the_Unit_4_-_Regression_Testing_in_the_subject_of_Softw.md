### What is Regression Testing for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

- Regression testing is a software testing technique that re-runs functional and non-functional tests to ensure that a software application works as expected after any code changes, updates, revisions, improvements, or optimizations.
- Regression testing is responsible for the overall stability and functionality of the existing features. Whenever a new modification is added to the code, regression testing is applied to guarantee that after each update, the system stays sustainable under continuous improvements.
- Regression testing detects new bugs early in the deployment cycle so that businesses do not have to invest in costs and maintenance efforts to resolve the built-up defects.
- Regression testing is an integral part of the extreme programming software development method. In this method, design documents are replaced by extensive, repeatable, and automated testing of the entire software package throughout each stage of the software development process.
- Regression testing is the final step in the software development process, as it verifies the product behaviors as a whole.

Some mnemonics and learning tricks for regression testing are:

- Regression testing can be remembered as **re**-running **g**ood **tests** after **changes**.
- Regression testing can be associated with the word **regress**, which means to go back to a previous state. Regression testing checks if the software has gone back to a previous state of defects after changes.
- Regression testing can be visualized as a filter that ensures quality as the product is improved. A filter can be represented by a funnel or a sieve that removes unwanted particles from a substance. Similarly, regression testing removes unwanted bugs from a software application.
