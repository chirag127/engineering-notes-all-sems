### Performance Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

- Performance testing is a form of software testing that focuses on how a system running the system performs under a particular load.
- Performance testing is not about finding software bugs or defects, but about measuring system behavior and quality attributes such as response time, throughput, resource utilization, scalability, reliability, etc .
- Performance testing is a type of non-functional testing, which is designed to determine the readiness of a system. Functional testing focuses on individual functions of software.
- Performance testing can be applied to web applications, which are software applications that run on web browsers and communicate with web servers.
- Performance testing of web applications is important because it helps to ensure that the web application can handle the expected user traffic, data volume, and network conditions without compromising the user experience or the business objectives .
- Performance testing of web applications can also help to identify and eliminate performance bottlenecks, optimize resource consumption, improve scalability and reliability, and reduce operational costs .
- There are different types of performance tests that can be applied to web applications, depending on the purpose and scope of the test . Some of the common types are:

  - Load testing: Load testing measures system performance as the workload increases. That workload could mean concurrent users or transactions. The system is monitored to measure response time and system staying power as workload increases. That workload falls within the parameters of normal working conditions.
  - Stress testing: Stress testing measures system performance outside of the parameters of normal working conditions. The software is given more users or transactions than it can handle. The goal of stress testing is to measure the software stability. At what point does software fail, and how does the software recover from failure?
  - Spike testing: Spike testing measures system performance when workloads are substantially increased quickly and repeatedly. The workload is beyond normal expectations for short amounts of time.
  - Endurance testing: Endurance testing measures system performance with a normal workload over an extended amount of time. The goal of endurance testing is to check for system problems such as memory leaks.
  - Scalability testing: Scalability testing measures system performance as the system resources are changed. This can be determined by gradually adding or removing users, data, CPUs, memory, etc. while monitoring system performance.
  - Volume testing: Volume testing measures system performance with large projected amounts of data. It is also known as flood testing because the test floods the system with data.

- To perform performance testing of web applications, the following steps can be followed :

  - Identify the testing environment: Identify the hardware, software, network configurations and tools available for the testing. This allows the testing team to design the test and identify performance testing challenges early on.
  - Identify the performance criteria: Identify the performance goals and objectives for the web application, such as the expected response time, throughput, resource utilization, etc. These criteria should be based on the user expectations and the business requirements .
  - Plan and design the test: Plan and design the test scenarios, test cases, test data, and test scripts that will simulate the realistic user behavior and workload for the web application. The test design should cover the different types of performance tests and the performance criteria .
  - Configure the test environment: Configure the test environment according to the test design and the testing environment. This includes setting up the test tools, test data, test scripts, and test monitors .
  - Run the test: Run the test scenarios and test cases according to the test plan and the test design. Collect the test results and the performance metrics from the test monitors .
  - Analyze the test results: Analyze the test results and the performance metrics to evaluate the performance of the web application. Compare the actual results with the expected results and the performance criteria. Identify the performance issues and the root causes of the issues .
  - Report and improve: Report the test results and the performance issues to the stakeholders and the development team. Provide recommendations and suggestions for improving the performance of the web application.
