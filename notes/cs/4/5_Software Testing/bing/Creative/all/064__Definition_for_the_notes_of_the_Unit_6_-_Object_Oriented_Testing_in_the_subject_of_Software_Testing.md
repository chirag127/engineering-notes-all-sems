### Definition for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

- Object Oriented Testing (OOT) is a software testing process that is conducted to test the software using object-oriented paradigms like, encapsulation, inheritance, polymorphism, etc.   
- OOT is different from conventional testing methods because it focuses on testing the classes and their interactions, rather than the functions and the control flow.   
- OOT is based on the concept of classes and instances. A class is an abstract definition of a type of object, which specifies the properties and methods that every object of that type has. An instance is a concrete object that is created from a class. 
- OOT involves testing the following aspects of a class: 
  - State: the data or attributes that an object has
  - Behavior: the methods or functions that an object can perform
  - Identity: the unique name or reference that an object has
- OOT also involves testing the following aspects of the object-oriented system: 
  - Inheritance: the mechanism by which a class can inherit the properties and methods of another class
  - Polymorphism: the ability of an object to behave differently depending on its type or context
  - Message passing: the communication between objects by sending and receiving messages
  - Concurrency: the ability of multiple objects to execute simultaneously or in parallel
- OOT requires different techniques and tools than conventional testing, such as:   
  - Class testing: testing a class as a unit, by creating test cases for its methods and state
  - Integration testing: testing the interactions and dependencies between classes, by creating test cases for the messages and the inheritance relationships
  - System testing: testing the functionality and performance of the whole system, by creating test cases for the use cases and the scenarios
  - Regression testing: testing the system after changes are made to the classes or the system, by reusing or modifying the existing test cases

A possible mnemonic to remember the aspects of OOT is **SBIMP**:

- **S**tate
- **B**ehavior
- **I**dentity
- **M**essage passing
- **P**olymorphism

A possible mnemonic to remember the types of OOT is **CISR**:

- **C**lass testing
