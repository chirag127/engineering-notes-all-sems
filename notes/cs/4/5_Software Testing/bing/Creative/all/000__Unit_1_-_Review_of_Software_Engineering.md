## Unit 1 - Review of Software Engineering

- Software engineering is the branch of computer science that deals with the design, development, testing, and maintenance of software applications  .
- Software engineers apply engineering principles and knowledge of programming languages to build software solutions for end users.
- Software engineers also test, improve, and maintain software built by other engineers.
- Software engineering involves various tasks and responsibilities, such as:
  - Designing and maintaining software systems
  - Evaluating and testing new software programs
  - Optimizing software for speed and scalability
  - Writing and testing code
  - Consulting with clients, engineers, security specialists, and other stakeholders
  - Presenting new features to stakeholders and internal customers
- Software engineering requires various skills and competencies, such as:
  - Analytical thinking and problem-solving
  - Creativity and innovation
  - Communication and collaboration
  - Knowledge of programming languages, platforms, and architectures
  - Knowledge of software development methodologies, such as agile, scrum, devops, etc.
  - Knowledge of software testing techniques, such as unit testing, integration testing, etc.
  - Knowledge of software quality standards, such as ISO, CMMI, etc.
  - Knowledge of software security principles, such as OWASP, etc.
- Software engineering has various benefits and challenges, such as:
  - Benefits:
    - Software engineering can solve real-world problems and create value for users and society
    - Software engineering can improve the efficiency and productivity of software systems and processes
    - Software engineering can enhance the reliability and usability of software products and services
    - Software engineering can foster innovation and creativity in software development
  - Challenges:
    - Software engineering can be complex and dynamic, requiring constant adaptation and learning
    - Software engineering can be costly and time-consuming, requiring careful planning and management
    - Software engineering can be risky and uncertain, requiring testing and verification
    - Software engineering can be affected by various factors, such as user requirements, stakeholder expectations, technology changes, etc.

- Mnemonics and learning tricks for Unit 1 - Review of Software Engineering:
  - To remember the definition of software engineering, use the acronym DDTM: Design, Development, Testing, Maintenance
  - To remember the tasks and responsibilities of software engineers, use the acronym DEWCTP: Design, Evaluate, Write, Consult, Test, Present
  - To remember the skills and competencies of software engineers, use the acronym APCKSK: Analytical, Programming, Communication, Knowledge, Skills, Competencies
  - To remember the benefits and challenges of software engineering, use the acronym BCRF: Benefits, Challenges, Risks, Factors
