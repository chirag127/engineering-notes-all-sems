## Unit 5 - Software Testing Activities

Software testing is the process of verifying and validating that a software product meets the specified requirements and expectations of the stakeholders. Software testing activities are the tasks and procedures that are performed during the software testing process. These activities include:

- **Planning:** This is the first activity where the process of testing software originates. It consists of defining the scope, objectives, strategy, resources, schedule, and risks of the testing process. A document called a test plan is created to document these aspects and guide the testing activities. 
- **Design:** This is the activity where the test cases and test data are designed based on the test plan and the software requirements. Test cases are the set of inputs, actions, and expected outputs that are used to test a specific functionality or feature of the software. Test data are the values or information that are used as inputs for the test cases. 
- **Execution:** This is the activity where the test cases and test data are executed on the software under test. The actual outputs and behaviors of the software are observed and compared with the expected outputs and behaviors. Any deviation or discrepancy is recorded as a defect or bug. 
- **Reporting:** This is the activity where the results and outcomes of the test execution are reported and communicated to the stakeholders. The test report is a document that summarizes the test activities, test results, defect status, test coverage, and test metrics. The test report helps to evaluate the quality and performance of the software and to make decisions about its release or improvement. 
- **Closure:** This is the final activity where the testing process is concluded and the test artifacts are archived. The test closure involves evaluating the testing process, identifying the lessons learned, and providing feedback and recommendations for future testing projects. The test closure also involves releasing the test resources and celebrating the testing achievements.
