The applicability of a testing technique depends on the context and the goal of the testing process. Some factors that can influence the applicability are:

- The type and complexity of the software system
- The requirements and specifications of the software system
- The available time and resources for testing
- The expected quality and reliability of the software system
- The skills and experience of the testers
- The standards and regulations of the software industry or domain

For example, unit testing is applicable for testing individual components or modules of a software system, while integration testing is applicable for testing the interactions between different components or modules. Black-box testing is applicable for testing the functionality of a software system without knowing its internal structure, while white-box testing is applicable for testing the logic and design of a software system with knowing its internal structure. Manual testing is applicable for testing the usability and user experience of a software system, while automated testing is applicable for testing the performance and scalability of a software system. Exploratory testing is applicable for testing the software system in an ad-hoc and creative way, while regression testing is applicable for testing the software system after changes or updates. Stress testing is applicable for testing the software system under extreme conditions, while risk-based testing is applicable for testing the software system based on the priority and impact of potential risks.
