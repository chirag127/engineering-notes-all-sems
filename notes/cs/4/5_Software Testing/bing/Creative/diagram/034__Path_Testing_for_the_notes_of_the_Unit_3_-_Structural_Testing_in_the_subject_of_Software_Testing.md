Path testing is a method that is used to design the test cases based on the control flow graph of the program, which shows all the possible paths of execution. Path testing aims to cover all the branches and statements in the program by generating test cases for each independent path. Path testing uses cyclomatic complexity to measure the number of independent paths in the program.

The following diagram illustrates the basic steps of path testing:

```
+----------------+      +-----------------+      +-----------------+      +-----------------+
| Draw a control |----->| Calculate       |----->| Find a basis set|----->| Generate test   |
| flow graph     |      | cyclomatic      |      | of paths        |      | cases           |
|                |      | complexity      |      |                 |      |                 |
+----------------+      +-----------------+      +-----------------+      +-----------------+
```

The control flow graph is a graphical representation of the program code, where each node is a statement or a condition, and each edge is a possible flow of control. The cyclomatic complexity is a metric that indicates the number of linearly independent paths in the graph, and can be calculated by the formula:

```
Cyclomatic complexity = E - N + 2P
```

Where E is the number of edges, N is the number of nodes, and P is the number of connected components in the graph. The basis set of paths is a set of independent paths that covers all the edges and nodes in the graph. The test cases are generated by assigning input values and expected outputs for each path in the basis set.

For example, consider the following program code:

```
1. if (a > b) then
2.   c = a - b
3. else
4.   c = b - a
5. end if
6. print c
```

The control flow graph for this code is:

```
    +---+
    | 1 |
    +---+
    /   \
  /       \
+---+     +---+
| 2 |     | 4 |
+---+     +---+
  \       /
    \   /
    +---+
    | 6 |
    +---+
```

The cyclomatic complexity for this graph is:

```
Cyclomatic complexity = 5 - 4 + 2 = 3
```

The basis set of paths for this graph is:

```
Path 1: 1, 2, 6
Path 2: 1, 4, 6
Path 3: 1, 6
```

The test cases for these paths are:

```
Test case 1: a = 10, b = 5, expected output: c = 5
Test case 2: a = 5, b = 10, expected output: c = 5
Test case 3: a = 5, b = 5, expected output: c = 0
```
