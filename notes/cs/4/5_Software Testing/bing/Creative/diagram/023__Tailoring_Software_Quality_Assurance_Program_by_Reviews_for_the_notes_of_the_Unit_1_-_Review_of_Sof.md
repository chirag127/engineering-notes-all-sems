The following diagram illustrates the basic architecture of a tailoring software quality assurance program by reviews:

```
+---------------------+    +---------------------+    +---------------------+
|                     |    |                     |    |                     |
|   Quality Goals     |    |   Quality Plan      |    |   Quality Metrics   |
|                     |    |                     |    |                     |
+---------------------+    +---------------------+    +---------------------+
|                     |    |                     |    |                     |
| - Critical          |    | - Quality           |    | - Defects           |
|   Parameters        |    |   Assurance         |    | - Test Coverage     |
| - Customer          |    |   Activities        |    | - Code Quality      |
|   Requirements      |    | - Quality           |    | - Customer          |
| - Industry          |    |   Standards         |    |   Satisfaction      |
|   Regulations       |    | - Quality           |    | - Process           |
|                     |    |   Reviews           |    |   Improvement       |
|                     |    |                     |    |                     |
+---------------------+    +---------------------+    +---------------------+
         |                         |                         |
         |                         |                         |
         +-------------------------+-------------------------+
                                   |
                                   |
                                   v
                          +---------------------+
                          |                     |
                          |   Software Product  |
                          |                     |
                          +---------------------+
```

The diagram shows how the quality goals, plan and metrics are aligned to ensure the software product meets the desired quality standards. The quality goals define the critical parameters, customer requirements and industry regulations that the software product must satisfy. The quality plan describes the quality assurance activities, standards and reviews that will be performed to ensure the quality goals are met. The quality metrics measure the defects, test coverage, code quality, customer satisfaction and process improvement that indicate the quality level of the software product. The quality reviews are the key mechanism to tailor the quality assurance program by providing feedback, verification and validation of the quality goals, plan and metrics.
