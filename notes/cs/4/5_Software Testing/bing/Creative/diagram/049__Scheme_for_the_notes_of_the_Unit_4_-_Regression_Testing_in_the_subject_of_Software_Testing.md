### Scheme for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

The following diagram illustrates the basic process of regression testing in software development:

```
+----------------+     +----------------+     +----------------+
|                |     |                |     |                |
|  Code changes  +---->+  Re-testing    +---->+  Regression    |
|                |     |                |     |  testing       |
|                |     |                |     |                |
+----------------+     +----------------+     +----------------+
```

- Code changes: This is the step where the developers modify or optimize the source code to add new features, fix bugs, or improve performance.
- Re-testing: This is the step where the testers verify that the code changes have not introduced any new defects or errors in the modified components or modules.
- Regression testing: This is the final step where the testers check that the code changes have not affected the existing functionality or behavior of the software as a whole. Regression testing ensures the quality and stability of the software after each update.
