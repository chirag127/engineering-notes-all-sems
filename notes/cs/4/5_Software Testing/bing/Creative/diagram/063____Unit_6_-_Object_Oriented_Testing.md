## Unit 6 - Object Oriented Testing

Object oriented testing is a testing technique that focuses on the behavior and structure of classes and objects in an object oriented system. Object oriented testing can be divided into two categories: class testing and system testing.

Class testing is the testing of individual classes and their methods, attributes, and interactions with other classes. Class testing can be further divided into state-based testing and interaction-based testing.

- State-based testing verifies the internal state of a class and its methods by checking the values of its attributes and the results of its operations. State-based testing can use techniques such as equivalence partitioning, boundary value analysis, and decision tables to generate test cases.
- Interaction-based testing verifies the external behavior of a class and its methods by checking the messages it sends and receives from other classes. Interaction-based testing can use techniques such as sequence diagrams, collaboration diagrams, and state transition diagrams to generate test cases.

System testing is the testing of the whole object oriented system and its functionality, usability, reliability, and performance. System testing can be further divided into scenario-based testing and use case-based testing.

- Scenario-based testing verifies the system's behavior and functionality by executing a sequence of actions and events that simulate a realistic situation. Scenario-based testing can use techniques such as user stories, storyboards, and scripts to generate test scenarios.
- Use case-based testing verifies the system's behavior and functionality by executing a sequence of actions and events that satisfy a user's goal. Use case-based testing can use techniques such as use case diagrams, use case specifications, and use case scenarios to generate test cases.
