## Unit 5 - Software Testing Activities

Software testing is the process of verifying and validating that a software product meets the requirements and expectations of the stakeholders. Software testing involves various activities that aim to ensure the quality, reliability, security, and usability of the software product. Some of the software testing activities are:

- **Planning**: This activity involves defining the scope, objectives, strategy, and resources for the testing process. Planning also includes identifying the test cases, test data, test environment, test tools, and test schedule. Planning helps to establish the test criteria, test metrics, and test deliverables for the testing process.
- **Design**: This activity involves designing the test cases, test data, and test procedures based on the test criteria and test strategy. Design also includes reviewing and refining the test cases, test data, and test procedures to ensure their completeness, correctness, and effectiveness. Design helps to prepare the test artifacts that will be used to execute the testing process.
- **Execution**: This activity involves executing the test cases, test data, and test procedures on the software product under test. Execution also includes recording the test results, test logs, test evidences, and test defects. Execution helps to evaluate the actual behavior and performance of the software product against the expected behavior and performance.
- **Analysis**: This activity involves analyzing the test results, test logs, test evidences, and test defects to identify the root causes, impacts, and severity of the defects. Analysis also includes reporting and communicating the test findings, test status, and test coverage to the stakeholders. Analysis helps to measure the quality, reliability, security, and usability of the software product and to provide feedback and recommendations for improvement.
- **Closure**: This activity involves completing the testing process by verifying that all the test objectives have been met, all the test deliverables have been produced, and all the test artifacts have been archived. Closure also includes evaluating the testing process by conducting a test review, a test audit, or a test retrospective. Closure helps to document the test lessons learned, test best practices, and test improvement actions for future testing projects.
