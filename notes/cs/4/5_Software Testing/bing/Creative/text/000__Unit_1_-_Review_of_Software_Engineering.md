## Unit 1 - Review of Software Engineering

- Software engineering is the application of engineering principles and practices to the development, maintenance, and evolution of software systems.
- Software engineering covers the entire software life cycle, from requirements analysis, design, implementation, testing, deployment, operation, and maintenance.
- Software engineering aims to deliver software products that meet the needs and expectations of the stakeholders, within the constraints of budget, schedule, and quality.
- Software engineering involves various activities, such as:

  - Software process: the set of activities and tasks that define how software is developed and managed.
  - Software project management: the planning, organizing, monitoring, and controlling of software projects.
  - Software requirements engineering: the elicitation, analysis, specification, validation, and management of software requirements.
  - Software design: the creation of the software architecture and components that satisfy the software requirements.
  - Software implementation: the coding, testing, debugging, and integration of software components.
  - Software testing: the verification and validation of software functionality, quality, and reliability.
  - Software deployment: the installation, configuration, and delivery of software products to the end users.
  - Software operation: the execution, monitoring, and support of software products in the operational environment.
  - Software maintenance: the modification and improvement of software products to fix defects, enhance performance, or adapt to changing requirements.
  - Software evolution: the continuous and iterative development of software products to cope with changing needs and technologies.

- Software engineering also involves various disciplines, such as:

  - Software engineering ethics: the study and application of moral principles and values to software engineering practice.
  - Software engineering standards: the norms and guidelines that define the best practices and quality criteria for software engineering.
  - Software engineering methods: the systematic and structured approaches to software engineering activities, such as agile, waterfall, spiral, etc.
  - Software engineering tools: the software applications and systems that support and automate software engineering activities, such as IDEs, CASE tools, testing tools, etc.
  - Software engineering models: the abstract and formal representations of software systems and processes, such as UML, ERD, DFD, etc.
  - Software engineering metrics: the quantitative and qualitative measures of software products and processes, such as size, complexity, defects, productivity, etc.
  - Software engineering paradigms: the fundamental concepts and principles that guide software engineering practice, such as object-oriented, functional, concurrent, etc.
  - Software engineering domains: the specific areas and applications of software engineering, such as web, mobile, embedded, AI, etc.
