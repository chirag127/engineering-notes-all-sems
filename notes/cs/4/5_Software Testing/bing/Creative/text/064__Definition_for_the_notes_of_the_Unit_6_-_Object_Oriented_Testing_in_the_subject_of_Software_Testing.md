### Definition

- Object Oriented Testing (OOT) is a testing approach that focuses on the testing of software systems that are developed using object oriented programming languages and paradigms.
- OOT aims to verify the correctness and quality of the software system by testing its classes, objects, methods, inheritance, polymorphism, encapsulation, abstraction, and other object oriented features and concepts.
- OOT can be applied at different levels of testing, such as unit testing, integration testing, system testing, and acceptance testing.
- OOT can also be classified into different types, such as class testing, object testing, state-based testing, scenario-based testing, fault-based testing, and mutation testing.
- OOT requires different techniques, tools, and metrics than traditional testing approaches, as it has to deal with the complexity and dynamism of object oriented software systems.
