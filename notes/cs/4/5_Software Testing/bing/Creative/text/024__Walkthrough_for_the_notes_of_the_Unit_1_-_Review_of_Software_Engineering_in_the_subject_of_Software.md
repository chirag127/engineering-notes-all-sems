### Walkthrough for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Software engineering is the discipline of applying systematic and rigorous methods to design, develop, test, maintain and improve software products and processes.
- Software testing is the process of verifying and validating that a software product or system meets the specified requirements and expectations of the stakeholders.
- Software testing can be classified into two main types: static testing and dynamic testing.
  - Static testing is the process of examining the software artifacts (such as code, design, documentation, etc.) without executing them. Static testing techniques include reviews, inspections, walkthroughs, audits, etc.
  - Dynamic testing is the process of executing the software artifacts (such as code, modules, components, systems, etc.) with test cases and observing the results. Dynamic testing techniques include unit testing, integration testing, system testing, acceptance testing, etc.
- Software testing can also be classified into two main levels: white-box testing and black-box testing.
  - White-box testing is the process of testing the software artifacts based on their internal structure, logic and implementation. White-box testing techniques include statement coverage, branch coverage, path coverage, etc.
  - Black-box testing is the process of testing the software artifacts based on their external functionality, behavior and specification. Black-box testing techniques include equivalence partitioning, boundary value analysis, decision table testing, etc.
- Software testing can also be classified into two main modes: verification and validation.
  - Verification is the process of checking whether the software artifacts conform to the predefined standards, rules and regulations. Verification techniques include code analysis, code reviews, code inspections, etc.
  - Validation is the process of checking whether the software artifacts fulfill the intended purpose and satisfy the needs and expectations of the stakeholders. Validation techniques include functional testing, non-functional testing, usability testing, etc.
- Software testing can also be classified into two main phases: testing during development and testing after development.
  - Testing during development is the process of testing the software artifacts as they are being developed, in order to detect and correct defects as early as possible. Testing during development techniques include test-driven development, agile testing, continuous testing, etc.
  - Testing after development is the process of testing the software artifacts after they are completed, in order to ensure their quality and reliability before delivery. Testing after development techniques include regression testing, performance testing, security testing, etc.
- Software testing can also be classified into two main approaches: manual testing and automated testing.
  - Manual testing is the process of testing the software artifacts by human testers, using their knowledge, skills and experience. Manual testing techniques include exploratory testing, error guessing, ad hoc testing, etc.
  - Automated testing is the process of testing the software artifacts by using software tools, scripts and frameworks. Automated testing techniques include test automation, test generation, test execution, test reporting, etc.
