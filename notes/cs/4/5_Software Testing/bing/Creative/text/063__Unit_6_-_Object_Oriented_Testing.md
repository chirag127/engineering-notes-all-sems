## Unit 6 - Object Oriented Testing

- Object oriented testing is a testing technique that focuses on the testing of software systems that are developed using object oriented methodologies.
- Object oriented testing is based on the concepts of classes, objects, inheritance, polymorphism, and dynamic binding.
- Object oriented testing aims to verify the correctness and quality of the software system at different levels of abstraction, such as class level, cluster level, and system level.
- Object oriented testing can be classified into two categories: structural testing and behavioral testing.
  - Structural testing is also known as white-box testing or glass-box testing. It involves testing the internal structure and implementation of the software system, such as methods, attributes, constructors, and destructors.
  - Behavioral testing is also known as black-box testing or functional testing. It involves testing the external behavior and functionality of the software system, such as use cases, scenarios, and contracts.
- Object oriented testing can be performed at different phases of the software development life cycle, such as unit testing, integration testing, system testing, and acceptance testing.
  - Unit testing is the testing of individual classes or methods in isolation, using test cases that are derived from the specifications and design of the class or method.
  - Integration testing is the testing of the interactions and dependencies between classes or clusters of classes, using test cases that are derived from the architecture and design of the system.
  - System testing is the testing of the whole software system as a single entity, using test cases that are derived from the requirements and specifications of the system.
  - Acceptance testing is the testing of the software system by the end users or customers, using test cases that are derived from the user expectations and needs.
- Object oriented testing can be performed using various tools and techniques, such as test drivers, test stubs, test frameworks, test patterns, test metrics, and test automation.
