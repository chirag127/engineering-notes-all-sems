### What is Regression Testing

- Regression testing is a type of software testing that verifies that software previously developed and tested still performs correctly after it was changed or interfaced with other software.
- Regression testing is done to ensure that changes such as bug fixes, enhancements, or configuration modifications do not introduce new faults or adversely affect the existing functionality of the system.
- Regression testing can be performed at any level of testing (unit, integration, system, or acceptance) and can be applied to functional or non-functional testing.
- Regression testing can be done manually or using automated tools. Automated regression testing is preferred when the system has frequent changes or a large number of test cases that need to be executed repeatedly.
- Regression testing can be done using different techniques, such as:
  - Retest all: This technique involves re-executing all the existing test cases on the modified system. This is the most comprehensive but also the most time-consuming and expensive technique.
  - Regression test selection: This technique involves selecting a subset of test cases that are relevant to the changes made in the system. This can be done using various criteria, such as test case priority, coverage, risk, or impact analysis.
  - Test case prioritization: This technique involves ordering the selected test cases based on some criteria, such as the severity of the defects, the frequency of use, the complexity of the functionality, or the business value. This helps to execute the most important test cases first and optimize the testing resources and time.
  - Test case minimization: This technique involves reducing the number of test cases by eliminating redundant or obsolete test cases. This helps to improve the efficiency and effectiveness of the testing process.
