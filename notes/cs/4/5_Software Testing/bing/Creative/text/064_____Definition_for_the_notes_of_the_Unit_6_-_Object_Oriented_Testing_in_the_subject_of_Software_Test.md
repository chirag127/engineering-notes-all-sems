### Definition for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

- Object Oriented Testing (OOT) is a testing approach that focuses on the testing of software systems developed using object oriented principles and techniques.
- OOT aims to verify and validate the functional and non-functional requirements of the software system by testing the interactions and collaborations among the objects that constitute the system.
- OOT involves testing the following aspects of the software system:
  - Class testing: testing the attributes, methods, constructors, and inheritance relationships of a single class.
  - Integration testing: testing the communication and coordination among the classes that form a subsystem or a component.
  - System testing: testing the overall functionality and performance of the software system as a whole.
  - Regression testing: testing the software system after changes or modifications to ensure that the existing functionality is not affected.
- OOT requires different testing techniques and strategies than traditional testing approaches, such as:
  - Test case design based on scenarios, use cases, state diagrams, and interaction diagrams.
  - Test case execution using test drivers, test stubs, test harnesses, and test frameworks.
  - Test case evaluation using test oracles, assertions, and contracts.
  - Test coverage measurement based on class, method, state, and branch coverage criteria.
