### Cause Effect Graphing Technique

- Cause effect graphing technique is a black box testing technique that uses a graphical representation of the inputs and outputs of a system to generate test cases.
- The graph consists of nodes and edges, where nodes represent causes (inputs or conditions) and effects (outputs or actions), and edges represent the logical relationships between them.
- The graph can be converted into a decision table, which shows the combinations of causes and effects for each test case.
- The graph can also be converted into a Boolean expression, which can be simplified using Boolean algebra to reduce the number of test cases.
- The steps involved in cause effect graphing technique are:

  - Identify the causes and effects of the system and assign them unique symbols or numbers.
  - Draw the cause effect graph by connecting the causes and effects with edges, using logical operators such as AND, OR, NOT, etc.
  - Convert the graph into a decision table by assigning values (0 or 1) to each cause and effect for each test case.
  - Convert the decision table into a Boolean expression by replacing the values with the symbols or numbers of the causes and effects, and using the logical operators as operators.
  - Simplify the Boolean expression using Boolean algebra rules to eliminate redundant or irrelevant test cases.
  - Generate the test cases from the simplified Boolean expression by assigning values to the causes and effects according to the expression.
