## Unit 2 - Functional Testing

- Functional testing is a type of software testing that verifies that the software performs as expected according to the requirements or specifications.
- Functional testing involves testing the functionality of the software at various levels, such as unit, integration, system, and acceptance testing.
- Functional testing can be done manually or with the help of automated tools, depending on the scope, complexity, and resources of the project.
- Functional testing can be classified into different types, such as black-box testing, white-box testing, and gray-box testing, based on the level of knowledge of the internal structure and logic of the software.
- Black-box testing is a type of functional testing that focuses on the input and output of the software, without considering the internal implementation details. Black-box testing is suitable for testing the user interface, usability, and compatibility of the software.
- White-box testing is a type of functional testing that examines the internal structure and logic of the software, using the source code or design documents. White-box testing is suitable for testing the performance, security, and reliability of the software.
- Gray-box testing is a type of functional testing that combines the aspects of black-box and white-box testing, using both the external and internal information of the software. Gray-box testing is suitable for testing the integration, functionality, and data flow of the software.
- Functional testing can also be classified into different types, such as positive testing, negative testing, and boundary testing, based on the nature of the test cases and expected results.
- Positive testing is a type of functional testing that verifies that the software works correctly with valid and expected inputs and produces the desired outputs. Positive testing is used to confirm the functionality and correctness of the software.
- Negative testing is a type of functional testing that verifies that the software handles gracefully with invalid and unexpected inputs and produces appropriate error messages. Negative testing is used to identify the defects and vulnerabilities of the software.
- Boundary testing is a type of functional testing that verifies that the software behaves correctly at the boundary values of the input domain and produces the expected outputs. Boundary testing is used to check the robustness and accuracy of the software.
