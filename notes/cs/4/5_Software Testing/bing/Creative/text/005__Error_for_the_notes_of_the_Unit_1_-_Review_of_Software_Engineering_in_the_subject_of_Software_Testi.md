### Error for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Error is a deviation from the expected or desired outcome of a software process, product, or service.
- Error can occur at any stage of the software development life cycle, such as requirements, design, coding, testing, deployment, or maintenance.
- Error can be classified into different types, such as syntax, logic, semantic, interface, performance, security, usability, compatibility, or reliability errors.
- Error can have different causes, such as human mistakes, ambiguous or incomplete specifications, incorrect assumptions, faulty algorithms, inadequate testing, or environmental factors.
- Error can have different impacts, such as functional failures, data corruption, system crashes, security breaches, user dissatisfaction, or legal liabilities.
- Error can be detected, prevented, or corrected by various techniques, such as reviews, inspections, testing, debugging, verification, validation, quality assurance, or quality control.
- Error can be measured, analyzed, or reported by various metrics, such as error density, error severity, error frequency, error cost, error rate, or error trend.
