### Decision Table Based Testing

- Decision table based testing is a technique for testing the functionality of a system based on the possible combinations of inputs and outputs.
- A decision table is a tabular representation of the logical rules that govern the behavior of a system for different input values and conditions.
- A decision table consists of four quadrants: condition stubs, condition entries, action stubs, and action entries.
- Condition stubs are the input variables or conditions that affect the system's behavior.
- Condition entries are the possible values or states of the condition stubs.
- Action stubs are the output variables or actions that the system performs based on the input conditions.
- Action entries are the expected values or states of the action stubs for each combination of condition entries.
- A decision table can be used to derive test cases by selecting one or more combinations of condition entries and verifying that the corresponding action entries are observed.
- A decision table can also be used to identify gaps, inconsistencies, or contradictions in the system's requirements or specifications.
- A decision table can be simplified by applying various rules, such as eliminating impossible or redundant combinations, merging equivalent combinations, or splitting complex combinations.
