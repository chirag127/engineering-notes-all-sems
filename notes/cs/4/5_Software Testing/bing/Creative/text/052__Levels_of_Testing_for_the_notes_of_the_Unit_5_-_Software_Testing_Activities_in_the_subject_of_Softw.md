### Levels of Testing for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

Levels of testing are the different stages of the software testing process that verify the quality and functionality of the software at various levels of development. The main purpose of levels of testing is to identify and fix the defects and errors in the software before it is delivered to the end-users.

There are mainly four levels of testing in software testing:

- **Unit testing**: This is the lowest level of testing that checks the individual components or units of the software. A unit is the smallest testable part of the software that can be compiled, linked, loaded, and executed. Unit testing ensures that each unit of the software performs as expected and meets the functional requirements. Unit testing is usually done by the developers using tools like JUnit, NUnit, TestNG, etc.
- **Integration testing**: This is the level of testing that checks the interaction and data flow between different modules or services of the software. Integration testing verifies that the integrated system works as a whole and meets the functional and non-functional requirements. Integration testing can be done in different ways, such as top-down, bottom-up, big-bang, or incremental. Integration testing is usually done by the testers using tools like Selenium, Postman, SoapUI, etc.
- **System testing**: This is the level of testing that evaluates the complete and fully integrated software system. System testing checks the system's compliance with the specified needs and the quality standards. System testing involves various types of testing, such as functional testing, non-functional testing, performance testing, security testing, usability testing, etc. System testing is usually done by the testers using tools like JMeter, LoadRunner, Appium, etc.
- **Acceptance testing**: This is the highest level of testing that validates whether the software meets the customer's expectations and requirements. Acceptance testing checks the suitability and readiness of the software for the end-users. Acceptance testing can be done by the customers, users, or other stakeholders with the help of the testers. Acceptance testing can be of different types, such as alpha testing, beta testing, user acceptance testing, etc.

These four levels of testing are performed in a sequential order, starting from unit testing and ending with acceptance testing. Each level of testing has its own objectives, scope, and techniques. The levels of testing help to ensure the quality and reliability of the software throughout the development lifecycle.
