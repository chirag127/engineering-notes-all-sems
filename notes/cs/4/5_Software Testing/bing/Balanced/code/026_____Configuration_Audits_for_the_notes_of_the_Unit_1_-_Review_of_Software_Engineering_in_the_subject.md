### Configuration Audits

- Configuration audits are a process of verifying that the software product conforms to the specified requirements and design documents .
- Configuration audits are performed by an independent team or authority that is not involved in the development or testing of the software product .
- Configuration audits help to ensure the quality, reliability, and consistency of the software product, as well as to identify and resolve any discrepancies or defects .
- Configuration audits are usually conducted at the end of each software development phase or before the delivery of the software product to the customer .
- There are two types of configuration audits: Functional Configuration Audit (FCA) and Physical Configuration Audit (PCA) .
  - FCA verifies that the software product meets the functional requirements and specifications .
  - PCA verifies that the software product matches the physical characteristics and documentation .
- Configuration audits are part of the configuration management process, which is a systems engineering process that tracks and monitors changes to the software product's configuration metadata.
- Configuration management helps to maintain the integrity, traceability, and reproducibility of the software product throughout its lifecycle.
- Configuration management also supports version control and continuous integration and delivery (CI/CD) infrastructure, which are tools and practices that facilitate the development, testing, and deployment of software products.
