### Verification for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Software engineering is a branch of computer science that deals with the design, implementation, and maintenance of complex computer programs .
- Software engineers apply engineering principles and knowledge of programming languages to build software solutions for end users.
- Software engineering is an engineering-style system of software development, which involves following a systematic process, applying quality standards, and using appropriate tools and techniques.
- Software engineering covers various aspects of software development, such as:
  - Software requirements analysis: defining the problem and the needs of the users and stakeholders.
  - Software design: creating a high-level plan and structure of the software solution.
  - Software implementation: writing the code and testing the functionality of the software components.
  - Software testing: verifying and validating the quality and performance of the software solution.
  - Software deployment: delivering and installing the software solution to the target environment and users.
  - Software maintenance: fixing bugs, adding features, and updating the software solution according to changing needs and feedback.
- Software engineering also involves managing the software development project, such as:
  - Software project planning: estimating the scope, cost, time, and resources of the project.
  - Software project management: coordinating and controlling the activities and resources of the project team and stakeholders.
  - Software project monitoring and control: measuring and reporting the progress and performance of the project.
  - Software project risk management: identifying and mitigating the potential threats and uncertainties of the project.
  - Software project quality management: ensuring and improving the quality of the project deliverables and processes.
- Software engineering aims to produce software solutions that are reliable, efficient, secure, usable, and maintainable. Software engineering also strives to meet the expectations and satisfaction of the users and stakeholders.
