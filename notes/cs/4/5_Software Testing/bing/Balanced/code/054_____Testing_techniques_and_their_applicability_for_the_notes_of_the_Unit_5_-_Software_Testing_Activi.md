### Testing techniques and their applicability

Testing techniques are the methods applied to evaluate a system or a component with a purpose to find if it satisfies the given requirements. Testing of a system helps to identify gaps, errors, or any kind of missing requirements differing from the actual requirements.

There are different types of testing techniques, each with its own advantages and disadvantages, and applicability to different scenarios. Some of the common testing techniques are:

- **Unit testing**: Validating that each software unit performs as expected. A unit is the smallest testable component of an application, such as a method or a function. Unit testing is very low level and close to the source of an application. It is usually done by the developers using tools like JUnit, NUnit, TestNG, etc. Unit testing is generally quite cheap to automate and can run very quickly by a continuous integration server. Unit testing helps to find defects at an early stage of development, improve code quality, and facilitate code refactoring .

- **Integration testing**: Ensuring that software components or functions operate together. Integration testing is done after unit testing and before system testing. It involves testing the interactions and interfaces between different units or modules of an application. Integration testing can be done using different approaches, such as top-down, bottom-up, big-bang, or incremental. Integration testing helps to find defects in the integration logic, data flow, and communication between components .

- **System testing**: Verifying whether the whole system works as intended. System testing is done after integration testing and before acceptance testing. It involves testing the functionality, performance, reliability, security, usability, and compatibility of the system as a whole. System testing can be done using different techniques, such as functional testing, non-functional testing, regression testing, etc. System testing helps to find defects in the system requirements, design, and architecture .

- **Acceptance testing**: Verifying whether the system meets the expectations and needs of the end-users and stakeholders. Acceptance testing is done after system testing and before deployment. It involves testing the system in a real or simulated environment with real or simulated data. Acceptance testing can be done by the customers, users, or a third-party team. Acceptance testing can be done using different techniques, such as alpha testing, beta testing, user acceptance testing, etc. Acceptance testing helps to find defects in the user interface, user experience, and user satisfaction .

- **Performance testing**: Evaluating the speed, scalability, stability, and responsiveness of the system under different workloads and conditions. Performance testing is a type of non-functional testing that can be done at any level of testing, but usually done at the system or acceptance level. Performance testing can be done using different techniques, such as load testing, stress testing, endurance testing, spike testing, etc. Performance testing helps to find defects in the system performance, resource utilization, and throughput .

- **Security testing**: Ensuring that the system and application are protected from all types of threats and vulnerabilities. Security testing is a type of non-functional testing that can be done at any level of testing, but usually done at the system or acceptance level. Security testing can be done using different techniques, such as penetration testing, vulnerability scanning, ethical hacking, etc. Security testing helps to find defects in the system security, confidentiality, integrity, and availability .

- **Usability testing**: Assessing the ease of use, learnability, efficiency, and satisfaction of the system by the end-users. Usability testing is a type of non-functional testing that can be done at any level of testing, but usually done at the system or acceptance level. Usability testing can be done using different techniques, such as heuristic evaluation, user testing, user surveys, etc. Usability testing helps to find defects in the system usability, user interface, user experience, and user feedback.

The applicability of testing techniques depends on various factors, such as the type and scope of the system, the development methodology, the testing objectives, the testing resources, the testing tools, the testing environment, the testing standards, the testing constraints, and the testing risks. The testing techniques should be selected and applied based on the testing context and the testing strategy .
