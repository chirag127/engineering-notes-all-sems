## Unit 6 - Object Oriented Testing

Object oriented testing is a testing technique that focuses on the behavior and structure of objects in an object oriented system. Object oriented testing can be divided into two types: class testing and system testing.

### Class Testing

Class testing is the testing of individual classes and their methods. Class testing can be further divided into two types: state-based testing and interaction-based testing.

- State-based testing: This type of testing verifies the internal state of an object and its attributes. State-based testing can be done using techniques such as equivalence partitioning, boundary value analysis, decision tables, and state transition diagrams.
- Interaction-based testing: This type of testing verifies the interactions between an object and its collaborators. Interaction-based testing can be done using techniques such as message sequence charts, collaboration diagrams, and use case testing.

### System Testing

System testing is the testing of the integrated system as a whole. System testing can be further divided into two types: scenario-based testing and exploratory testing.

- Scenario-based testing: This type of testing verifies the system functionality and performance based on predefined scenarios or use cases. Scenario-based testing can be done using techniques such as use case testing, user acceptance testing, and performance testing.
- Exploratory testing: This type of testing verifies the system behavior and quality based on the tester's intuition and creativity. Exploratory testing can be done using techniques such as error guessing, ad hoc testing, and heuristic testing.
