### Post Deployment Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

- Post deployment testing is a type of testing in which the software is tested after it is being deployed to production.
- The purpose of post deployment testing is to ensure that the software functions as intended in the real environment and meets the user expectations and requirements.
- Post deployment testing involves the following activities  :
  - Post-deployment verification: The QA or Test lead verifies the software application as per the test plan and test cases and compares them with the previous or existing ones.
  - User acceptance testing: The end users or stakeholders test the software application and provide feedback on its usability, functionality, performance, and quality.
  - Smoke testing: The basic functionality and features of the software application are tested to ensure that it is stable and ready for further testing.
  - Regression testing: The software application is tested for any defects or issues that may have been introduced during the deployment process or due to the changes in the environment.
  - Performance testing: The software application is tested for its speed, scalability, reliability, and resource consumption under different load and stress conditions.
  - Security testing: The software application is tested for its vulnerability to external threats and attacks and its compliance with the security standards and policies.
  - Monitoring: The software application is monitored for its availability, performance, errors, and usage using various tools and metrics.
  - Reporting: The test results, feedback, issues, and defects are reported and documented for further analysis and improvement.
- Post deployment testing is an ongoing process that continues throughout the life cycle of the software application. It helps to ensure the quality, reliability, and customer satisfaction of the software product.
