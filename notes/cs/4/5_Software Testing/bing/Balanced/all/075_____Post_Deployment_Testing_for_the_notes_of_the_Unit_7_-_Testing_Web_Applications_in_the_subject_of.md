# Post Deployment Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

- Post deployment testing is a type of testing in which the software is tested after it is being deployed to production .
- The main objectives of post deployment testing are to verify the functionality, performance, security, usability, and compatibility of the software in the real environment .
- Post deployment testing can also help to collect user feedback, identify defects, monitor the software behavior, and measure the quality and satisfaction of the software .
- Post deployment testing can be divided into two phases: post deployment verification and post deployment monitoring .

## Post Deployment Verification
- Post deployment verification is the process of checking the software features, functionality, and configuration against the expected requirements and specifications .
- Post deployment verification can be done by using the existing test plans and test cases from the previous testing stages, or by creating new test cases based on the production environment and user scenarios .
- Post deployment verification can include functional testing, regression testing, smoke testing, sanity testing, integration testing, user acceptance testing, and exploratory testing  .
- Post deployment verification can help to ensure that the software meets the business and user needs, and that there are no major defects or issues that can affect the software performance or reliability  .

## Post Deployment Monitoring
- Post deployment monitoring is the process of observing and measuring the software behavior, performance, and quality in the production environment .
- Post deployment monitoring can be done by using various tools and techniques, such as logging, analytics, metrics, alerts, dashboards, reports, feedback forms, surveys, and reviews  .
- Post deployment monitoring can include performance testing, load testing, stress testing, security testing, compatibility testing, usability testing, and accessibility testing  .
- Post deployment monitoring can help to identify and resolve any issues or bottlenecks that can affect the software availability, scalability, efficiency, or security  .
- Post deployment monitoring can also help to collect and analyze user feedback, behavior, and satisfaction, and to improve the software quality and functionality based on the user needs and expectations  .
