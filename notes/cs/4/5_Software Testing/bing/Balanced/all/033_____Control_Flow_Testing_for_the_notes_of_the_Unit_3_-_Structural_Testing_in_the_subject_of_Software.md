# Control Flow Testing

- Control flow testing is a type of software testing that uses the program's control flow as a model.
- Control flow testing is a structural testing strategy that comes under white box testing .
- Control flow testing is used to develop test cases of a program, where the tester selects a large portion of the program to test and to set the testing path.
- Control flow testing is based on the execution order of the statements or instructions given in the program.
- Control flow testing can be performed manually or automated as the control flow graph that is used can be made by hand or by using tools.

## Control Flow Graph

- A control flow graph is a graphical representation of the program's control flow.
- A control flow graph consists of nodes and edges, where nodes represent basic blocks of code and edges represent the transfer of control between nodes.
- A basic block is a sequence of statements that has only one entry point and one exit point.
- A control flow graph shows the possible paths that can be taken by the program during execution.
- A control flow graph can be used to measure the complexity of the program and to identify the independent paths that need to be tested.

## Control Flow Testing Techniques

- There are various techniques for control flow testing, such as statement coverage, branch coverage, condition coverage, path coverage, etc.
- Statement coverage is the percentage of executable statements that are executed by the test cases.
- Branch coverage is the percentage of branches or decision points that are executed by the test cases.
- Condition coverage is the percentage of logical conditions that are evaluated to both true and false by the test cases.
- Path coverage is the percentage of paths that are executed by the test cases.
- The higher the coverage, the more thorough the testing is.
