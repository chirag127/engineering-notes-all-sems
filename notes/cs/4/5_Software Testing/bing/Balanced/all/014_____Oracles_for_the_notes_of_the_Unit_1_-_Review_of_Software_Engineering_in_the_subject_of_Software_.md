# Oracles

- An oracle is a mechanism for determining whether a test has passed or failed  .
- An oracle can be a person, a document, a specification, a tool, or another program that provides the expected or correct output for a given input  .
- An oracle can be used to compare the actual output of the system under test with the expected output and report any discrepancies  .
- An oracle can be complete or partial, depending on whether it covers all possible inputs or only some of them .
- An oracle can be explicit or implicit, depending on whether it specifies the exact output values or only some constraints or properties on them .
- An oracle can be derived from various sources, such as requirements, specifications, design documents, user manuals, domain knowledge, expert opinions, or previous versions of the system  .
- An oracle can be static or dynamic, depending on whether it is fixed or can change over time.
- An oracle can be formal or informal, depending on whether it is based on rigorous mathematical proofs or heuristic rules.
- An oracle can be automated or manual, depending on whether it can be executed by a computer or requires human intervention .
- An oracle can be exact or approximate, depending on whether it can detect all errors or only some of them.
- An oracle can be consistent or inconsistent, depending on whether it agrees with other oracles or not.
- An oracle can be feasible or infeasible, depending on whether it can be implemented or not.
- An oracle can be reliable or unreliable, depending on whether it can be trusted or not.
- An oracle can be efficient or inefficient, depending on whether it can be executed in a reasonable time and space or not.
- An oracle can be effective or ineffective, depending on whether it can achieve the testing objectives or not.
