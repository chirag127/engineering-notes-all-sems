# Verification for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Verification is the process of checking whether the software meets the specified requirements and design specifications.
- Verification can be done by various methods, such as reviews, inspections, walkthroughs, audits, testing, etc.
- Verification aims to ensure that the software is built correctly, i.e., it conforms to the requirements and design specifications.
- Verification can be done at different stages of the software development life cycle (SDLC), such as requirement analysis, design, coding, testing, etc.
- Verification can be classified into two types: static verification and dynamic verification.
- Static verification is the process of checking the software without executing it, such as by reviewing the documents, code, etc.
- Dynamic verification is the process of checking the software by executing it, such as by testing the functionality, performance, etc.
- Verification can help to detect and prevent defects early in the SDLC, which can reduce the cost and time of software development and maintenance.
- Verification can also help to improve the quality and reliability of the software, as well as the customer satisfaction and confidence.
