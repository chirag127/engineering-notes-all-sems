### Issues for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

- Object oriented testing (OOT) is a testing approach that is based on the principles of object oriented programming, such as encapsulation, inheritance, polymorphism, and dynamic binding.
- OOT faces some challenges and issues that are different from those of traditional testing methods, such as:
  - Testing the base class and the derived classes that inherit from it, and ensuring that the inherited behavior is correct and consistent .
  - Testing the polymorphic behavior of objects, which can change depending on the context and the type of the object .
  - Testing the interactions and collaborations among objects, which can be complex and dynamic .
  - Testing the reusability and modifiability of objects, which can affect the quality and maintainability of the software .
  - Testing the aspects and cross-cutting concerns of objects, which can be difficult to identify and isolate .
- OOT requires some techniques and tools that are specific to the object oriented paradigm, such as:
  - Using object oriented modeling languages, such as UML, to design and document the software and its test cases .
  - Using object oriented metrics, such as coupling, cohesion, complexity, and inheritance, to measure and evaluate the software and its testability .
  - Using object oriented test strategies, such as class testing, integration testing, system testing, and regression testing, to plan and execute the testing process .
  - Using object oriented test methods, such as state-based testing, scenario-based testing, fault-based testing, and mutation testing, to generate and select test cases .
  - Using object oriented test tools, such as debuggers, profilers, code analyzers, and test automation tools, to support and automate the testing activities .
