### Testing Suite for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- A testing suite is a collection of test cases that are designed to verify the functionality, quality, and performance of a software system or component.
- A testing suite can be organized according to different criteria, such as:
  - The type of testing, such as unit testing, integration testing, system testing, or acceptance testing.
  - The level of testing, such as black-box testing, white-box testing, or gray-box testing.
  - The scope of testing, such as functional testing, non-functional testing, or regression testing.
  - The technique of testing, such as equivalence partitioning, boundary value analysis, or state transition testing.
- A testing suite can be executed manually or automatically, depending on the availability of test tools, test scripts, and test data.
- A testing suite can be evaluated based on the test coverage, test effectiveness, and test efficiency metrics.
- A testing suite can be documented using test plans, test specifications, test cases, test scripts, test data, test results, and test reports.
