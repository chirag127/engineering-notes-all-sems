## Unit 6 - Object Oriented Testing

- Object oriented testing is a testing technique that focuses on the behavior and structure of objects, classes, and their interactions in an object oriented system.
- Object oriented testing can be classified into two types: class testing and system testing.
- Class testing is the testing of individual classes and their methods, attributes, and constructors. Class testing can be further divided into state-based testing and interaction-based testing.
- State-based testing verifies the internal state of an object and its transitions between different states. State-based testing can use techniques such as state diagrams, state tables, and state coverage criteria.
- Interaction-based testing verifies the communication and collaboration between objects and classes. Interaction-based testing can use techniques such as sequence diagrams, collaboration diagrams, and interaction coverage criteria.
- System testing is the testing of the whole object oriented system and its functionality, performance, reliability, and usability. System testing can use techniques such as use case testing, scenario testing, and user acceptance testing.
- Object oriented testing faces some challenges and issues, such as inheritance, polymorphism, dynamic binding, encapsulation, and concurrency. These features make object oriented testing more complex and difficult than traditional testing.
- Object oriented testing requires some specific skills and tools, such as object oriented analysis and design, object oriented programming languages, object oriented testing frameworks, and object oriented metrics. These skills and tools help testers to design, implement, and execute effective object oriented tests.
