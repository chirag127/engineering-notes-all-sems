## Unit 1 - Review of Software Engineering

Software engineering is a discipline that involves the application of engineering principles to the development of software. It involves the use of a systematic and disciplined approach to the design, development, and maintenance of software. In this unit, we will review the basic concepts and principles of software engineering.

### Software Engineering Process

The software engineering process involves a series of steps that are followed in order to develop software. The steps in the software engineering process include:

1. Requirements gathering: This involves gathering information about the requirements of the software from the user or client.

2. Analysis and design: In this step, the requirements are analyzed, and a design is created that meets those requirements.

3. Implementation: This is the stage where the software is developed using programming languages and tools.

4. Testing: The software is tested to ensure that it meets the requirements and operates as expected.

5. Deployment: The software is deployed to the end-users.

6. Maintenance: The software is maintained to ensure that it continues to operate as expected.

### Software Development Life Cycle (SDLC)

The software development life cycle (SDLC) is a framework that outlines the steps involved in the development of software. The steps in the SDLC include:

1. Planning: This involves defining the goals and objectives of the software.

2. Analysis: In this stage, the requirements of the software are gathered and analyzed.

3. Design: A design is created for the software.

4. Implementation: The software is developed and tested.

5. Deployment: The software is deployed to the end-users.

6. Maintenance: The software is maintained to ensure that it continues to operate as expected.

### Software Development Models

There are different models that can be used to develop software. These models include:

1. Waterfall model: This model involves a linear approach to software development, where each stage of development is completed before moving on to the next stage.

2. Agile model: This model involves an iterative approach to software development, where the development process is broken down into smaller cycles.

3. Spiral model: This model involves a combination of the waterfall and agile models, where each cycle is broken down into smaller cycles.

### Software Testing

Software testing is the process of verifying that the software meets the requirements and operates as expected. There are different types of software testing, including:

1. Unit testing: This involves testing individual units or components of the software.

2. Integration testing: This involves testing the interaction between different components of the software.

3. System testing: This involves testing the software as a whole.

4. Acceptance testing: This involves testing the software with the end-users to ensure that it meets their requirements.

### Software Maintenance

Software maintenance is the process of making changes to the software to ensure that it continues to operate as expected. There are different types of software maintenance, including:

1. Corrective maintenance: This involves fixing defects or errors in the software.

2. Adaptive maintenance: This involves making changes to the software to accommodate changes in the environment or requirements.

3. Perfective maintenance: This involves making improvements to the software to enhance its functionality or performance.

4. Preventive maintenance: This involves making changes to the software to prevent future problems or issues.
