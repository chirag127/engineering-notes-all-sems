### Boundary Value Analysis for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

Boundary Value Analysis is a technique used in software testing to identify errors at the boundaries of input values. It is useful for testing the functionality of a system by checking whether the system responds correctly to input values that are at or near the boundaries of the acceptable input range.

The following are some key points to keep in mind when performing boundary value analysis:

- The input values at the boundaries should be tested separately from the input values within the acceptable range.
- The boundaries should be tested for both the upper and lower limits.
- The input values that are just below or just above the boundaries should also be tested.
- The input values that are exactly at the boundaries should be tested.
- The input values that are far away from the boundaries should also be tested to ensure that the system is functioning correctly over the entire range of input values.

Boundary Value Analysis is especially useful in situations where a small change in input values can produce a significant change in the output of the system. Examples of such situations include financial calculations, scientific calculations, and other complex computations.

In addition to identifying errors at the boundaries of input values, Boundary Value Analysis can also help identify errors in the logic of the system. By testing input values at or near the boundaries, testers can gain a better understanding of how the system is processing input and can identify any potential errors in the logic.

Overall, Boundary Value Analysis is an effective technique for testing the functionality of a system and identifying errors at the boundaries of input values. By following the key points outlined above, testers can ensure that the system is functioning correctly over the entire range of input values and that any errors are identified and addressed before the system is released for use.
