### Control Flow Testing

1. Control flow testing aims to exercise different logical paths through the code.
2. The three main types of control flow tests are:
- Basis path testing: Exercise all logical paths through the code at least once.
- Boundary value analysis: Test values that exist on boundaries of equivalence partitions.
- Error guessing: Try to guess where and what types of errors might occur and design tests specifically to uncover them.
3. Control flow tests are complementary to data flow tests. Applying both leads to more robust test coverage.
4. Control flow testing is more difficult to automate than data flow testing. It requires human insight to identify logical paths and potential errors. Tool support is limited to helping identify paths, but not guessing errors.
5. Examples of control flow structures to test include:
- Sequence: Tests that steps are executed in the correct order.
- Selection (if/else): Tests all possible logical paths.
- Loops: Tests looping with empty iterations, looping to boundaries, and looping with nested conditions.
6. Control flow testing increases confidence that all statements and branches in the code have been executed, and that critical sequences of steps and boundaries are processed correctly. However, it does not guarantee that all possible inputs or executions scenarios are tested.
