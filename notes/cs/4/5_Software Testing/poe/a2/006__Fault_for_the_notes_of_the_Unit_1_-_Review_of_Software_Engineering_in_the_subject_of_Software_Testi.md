### Fault for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. Software Engineering: Software Engineering is the systematic approach to the development, operation, maintenance, and retirement of computer software. It is the application of engineering principles to software development.

2. Software Testing: Software Testing is the process of evaluating a software product to identify differences between expected and actual outcomes. Testing assesses the quality of software.

3. Software Requirements: Software Requirements specify the functions and constraints placed on a software system. Requirements analysis is the process of determining user needs and documenting them.

4. Software Design: Software Design refers to the process of planning a software solution to a problem. It focuses on the architecture of software. The goal of software design is to ensure high quality, low cost, and on-time delivery of software systems.

5. Coding: Coding is the process of translating software design into source code. Programmers write code in programming languages. Code generation can also be automated using code generators.

6. Testing: Testing involves operation of a system or application under controlled conditions and evaluating the results (outputs) against the expected results. The goal of testing is to identify bugs and defects to ensure that the software product is of acceptable quality.

7. Debugging: Debugging is the process of finding and resolving bugs/defects in software. Debugging techniques include monitoring the state of the software, correlating the state with the source code, and making corrections. Debugging is an important part of software development and testing.

8. Maintenance: Software maintenance involves modifying and updating software after delivery to correct faults, improve performance, or adapt to a changed environment. Software maintenance is an ongoing phase in the software lifecycle.
