### Automated Test Data Generation for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

1. Automated Test Data Generation is the process of generating test inputs automatically for testing software.
2. It reduces the manual effort of generating test data and increases the coverage of testing.
3. The different techniques for automated test data generation are:
- Random Data Generation - Generates random values for the inputs.
- Symbolic Execution - Generates inputs based on the path conditions of the program.
- Search-Based Techniques - Uses search algorithms to generate test data that covers conditions. E.g. Genetic Algorithms, Hill Climbing.
4. The benefits of Automated Test Data Generation are:
- Increased test coverage
- Reduced test effort and cost
- Detection of complex bugs and edge cases
- Uniform distribution of test cases
