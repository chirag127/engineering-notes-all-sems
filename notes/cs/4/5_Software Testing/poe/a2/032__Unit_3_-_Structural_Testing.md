## Unit 3 - Structural Testing

1. Structural Testing techniques are design-based testing techniques which analyze the internal structure of a software to check whether all the statements, branches and paths have been executed at least once.
2. Various Techniques for Structural Testing are:
    - Statement Coverage - Ensuring that each statement in the program is executed at least once.
    - Branch Coverage - Ensuring that each possible execution branch has been tested.
    - Condition Coverage - Ensuring that each condition in the program has taken on all possible outcomes at least once.
    - Path Coverage - Ensuring that every possible path through the code has been executed.
3. Advantages of Structural Testing are:
    - Increased coverage of potential errors by testing each part of the internal structure of software.
    - Helps identify redundant/dead code paths.
    - Enforces disciplined approach to testing.
4. Disadvantages of Structural Testing are:
    - Difficulty analyzing complex program structures.
    - May be time-consuming and expensive for large systems.
    - Does not prove that all valid inputs have been tested.
    - Subject to human errors when creating test cases manually.
