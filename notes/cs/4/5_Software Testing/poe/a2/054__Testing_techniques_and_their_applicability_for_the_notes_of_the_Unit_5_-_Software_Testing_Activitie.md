### Testing techniques and their applicability for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing.

1. Black box testing:
- Applicable when internal structure/design of the system is not known.
- Focuses on functionality of the system.
- Output is checked against the expected output based on the specifications.

2. White box testing:
- Applicable when internal structure/design of the system is known.
- Focuses on code coverage, paths executed, internal logic, etc.
- Used to strengthen black box testing.

3. Unit testing:
- Applicable for individual units/modules of the software.
- Focuses on the correctness of the smallest testable part of the software.
- Done by the developers before integration.

4. Integration testing:
- Applicable after unit testing to check interface defects.
- Focuses on the interaction between integrated units/modules.
- Done to expose faults in the interfaces and interaction between integrated parts.

5. System testing:
- Applicable to the fully integrated system.
- Focuses on the end-to-end functionality and non-functional requirements.
- Simulates real-world scenarios to validate if the system meets requirements.
