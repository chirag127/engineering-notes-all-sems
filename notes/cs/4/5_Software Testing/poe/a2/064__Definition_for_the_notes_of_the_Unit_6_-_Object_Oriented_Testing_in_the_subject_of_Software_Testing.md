### Definition for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing:

1. Object Oriented Testing: Testing the object oriented software applications is known as object oriented testing.
2. Class Testing: Testing individual classes in isolation to identify any issues.
3. Interface Testing: Testing the interfaces for proper implementation of methods and functions.
4. Inheritance Testing: Checking for problems with inheritance hierarchy like overridden methods, accessibility of inherited members etc.
5. Encapsulation Testing: Verifying that encapsulated members are not accessible and validating get and set methods.
6. Polymorphism Testing: Testing polymorphic behavior of objects by passing different implementations to methods or functions.
7. Cohesion Testing: Testing class cohesion to ensure grouping of related methods/functions and data.
8. Coupling Testing: Testing coupling between classes to ensure loose coupling and high cohesion.
9. Frameworks for Object Oriented Testing: Some frameworks like JUnit, TestNG etc provide Annotation based testing and other features to easily test object oriented software.
