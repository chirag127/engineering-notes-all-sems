## Unit 5 - Software Testing Activities

1. Unit Testing - Testing individual software components/modules. Eg: Testing a single function.
2. Integration Testing - Testing integrated software modules/components. Eg: Testing interface between two modules.
3. System Testing - Testing the whole system as a whole.
4. Acceptance Testing - Testing software with the goal of confirming readiness of system delivery by checking if it meets the required specifications. Done by client or end user.
5. Regression Testing - Testing to ensure changes/fixes have not introduced new bugs. Re-running previously executed tests.
6. Performance Testing - Testing to determine speed, scalability, handling of peak loads, recovery time, etc.
7. Load Testing - Testing with increasing load to find what load level causes performance degradation.
8. Stress Testing - Testing beyond normal operational capacity to find breaking point of software.
9. Volume Testing - Testing with large volumes of data.
10. Usability Testing - Testing to determine how easy user interfaces are to use.
11. Compatibility Testing - Testing software with various combinations of operating systems and hardware to ensure compatibility.
12. Security Testing - Testing to find vulnerabilities and ensure software is secure from malicious attacks.
