## Unit 7 - Testing Web Applications

1. Introduction to Web Application Testing
- Web applications are software applications that are accessed over a network (such as the Internet) through a web browser.
- As web applications become increasingly complex, testing them thoroughly is critical to ensure high quality, performance, and security.
- Web application testing involves testing the functionality, usability, performance, and security of a web application.

2. Types of Web Application Testing
- Functional testing: Testing the functionality and features of the web application. Ensuring that the application behaves as expected.
- Usability testing: Testing how easy and intuitive the web application is to use. Evaluating the user experience.
- Performance testing: Testing the performance of the web application under certain load conditions. Checking response times, throughput, resource usage, etc.
- Security testing: Testing the security of the web application. Looking for vulnerabilities and weaknesses that could be exploited by attackers.

3. Web Application Testing Tools
- Selenium: Open source tool for automating web browsers to test web applications. Supports multiple languages and browsers.
- Watir: Open source tool for automating web browsers to test web applications using Ruby libraries.
- HTTPie: User-friendly command-line HTTP client for making HTTP requests and examining HTTP responses. Useful for testing APIs.
- Postman: Powerful GUI platform for testing and using APIs. Allows you to save requests, write scripts, create environments, etc.
- Burp Suite: Integrated platform for performing security testing of web applications. Contains a proxy server, scanner, intruder, repeater, etc.
