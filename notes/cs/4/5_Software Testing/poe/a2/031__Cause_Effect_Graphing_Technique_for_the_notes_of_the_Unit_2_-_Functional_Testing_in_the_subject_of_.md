### Cause Effect Graphing Technique for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

1. Cause Effect Graphing Technique is a technique used in Functional Testing to identify the possible causes that can lead to a particular effect or a bug in the software.
2. This technique helps the testers to visualize the conditions and inputs that can lead to a failure in the system and accordingly design the test cases to uncover those bugs.
3. To apply this technique, first list down the possible effects or bugs in the software. Then for each effect, identify possible causes that can lead to that effect. Represent this cause-effect relationship in a graph format. The causes become the input to the graph and the effects become the output.
4. This graphical representation gives a clear picture of the different combinations of conditions and inputs that can lead to a particular output or bug. The test cases can be designed to cover these combinations.
5. For example, consider the effect as 'Slow system response'. Possible causes for this can be 'High load', 'Memory leak', 'Hardware issues', 'Software bugs', etc. Representing this in a graph will show the relationship between these causes and the effect. Test cases can be designed to verify the system response under different combinations of these conditions.
