## Unit 6 - Object Oriented Testing

1. Object Oriented Programming (OOP) follows the concept of objects and classes. Similarly, Object Oriented Testing (OOT) focuses on testing objects and classes.
2. In OOT, every object under test is treated as a "black box" and testing is performed based on the specified inputs and expected outputs without worrying about the internal implementation of the object.
3. The key aspects of OOT are:
    - Testing individual objects in isolation.
    - Testing interactions between multiple objects.
    - Testing the state of objects.
    - Testing exceptions.
4. The different types of OOT are:
    - Unit Testing: Tests individual objects.
    - Integration Testing: Tests interactions between multiple objects.
    - System Testing: Tests the system as a whole.
5. The benefits of OOT are:
    - It is easy to locate and isolate faults as testing is done at the object level.
    - It increases reusability of test cases as objects can be tested independently and reused in multiple tests.
    - It has good coverage as all aspects of objects like state, interactions and exceptions can be tested.
