## Unit 1 - Review of Software Engineering

1. Software Engineering: Software Engineering is the application of engineering principles to software development. It involves a systematic approach to the development, operation, maintenance, and retirement of computer software.
2. Software Development Life Cycle: The Software Development Life Cycle or SDLC is a process used by the software industry to design, develop and test high quality softwares. The SDLC aims to produce a high-quality software that meets or exceeds customer expectations, reaches completion within times and cost estimates. The basic SDLC methodologies are:
    - Waterfall model: Requirements -> Design -> Implementation -> Testing -> Deployment
    - Agile model: Short iterations of Requirements -> Design -> Implementation -> Testing
3. Requirements Analysis: The first phase of SDLC is Requirements Analysis where the software requirements are studied and specified. The goal is to determine what exactly the customer needs and ensure that the software meets those requirements. Use cases and user stories are tools used to understand requirements.
4. Design: The design phase translates the requirements into a blueprint of the software. The software architecture is defined in this phase along with major components and interfaces. Common design methodologies are object-oriented design, component-based design, service-oriented design, etc.
5. Implementation: The implementation phase involves converting the design into code. The source code is written in a programming language using the chosen software architecture and design.
6. Testing: The testing phase evaluates the software to identify and fix any bugs, errors or other defects. Different testing methodologies like unit testing, integration testing, system testing, acceptance testing, etc. are employed to test the software.
7. Deployment: The deployment phase delivers the final software product to the customer. The software is installed and made operational in the customer environment.
