### Priority category for the notes of the Unit 4 - Regression Testing in the subject of Software Testing

1. Regression Testing:
- Regression Testing is a type of software testing to confirm that a recent program or code change has not adversely affected existing features.
- It is performed after a bug fix or new functionality is added to ensure that the change did not create new problems.
- The goal is to verify whether the program is still performing as expected after the change.

2. Reasons for Regression Testing:
- To ensure the changes made to the software are correct and do not disrupt the functioning of the unchanged parts of the software.
- Changes in one part of the software may affect other parts of the software. Regression Testing finds such unintended changes.
- It increases the reliability of the software and customer satisfaction.
- It reduces the risk of failure and expensive bugs in the future.

3. Types of Regression Testing:
- Retest All - Test the entire application.
- Selective - Test only the affected module or functionality.
- Progressive - Test from the basic to more complex functionalities.
- Complete - Test all parts of the software.
- Partial - Test only some test cases.
