### Post Deployment Testing

1. Objectives
- Check application performance and behavior in actual user environment.
- Identify issues that were not discovered during development and testing phases.
- Measure application performance, load handling capability and resource utilization.

2. Types
- Load Testing: Check application performance under different loads. Identify maximum load handling capacity.
- Stress Testing: Check application behavior under extreme workloads that are expected to strain system resources.
- Volume Testing: Check application performance by varying the volume of data.
- Scalability Testing: Check application capability to scale up or scale down and handle increased or decreased workload.
- Compliance Testing: Check if application complies with standards, specifications, design guidelines, etc.
- Business Process Testing: Check end-to-end business processes and scenarios.
- Usability Testing: Check ease of use and user satisfaction.

3. Methods
- Monitoring application performance, resource usage, server logs, etc.
- Recording and analyzing user interactions with the application.
- Comparing actual results with expected performance and usage parameters.
- Reviewing user feedback and complaints.
- Simulating various loads and scenarios and measuring response times and resource consumption.

4. Significance
- Identifies residual defects and performance bottlenecks.
- Measures actual application quality and user experience.
- Provides valuable feedback to improve the application.
- Gains user confidence by demonstrating application stability and reliability.
