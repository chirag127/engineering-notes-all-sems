### Cycyclomatic Complexity for the notes of the Unit 3 - Structural Testing in Software Testing

1. Cyclomatic Complexity is a software metric used to indicate the complexity of a program.
2. It measures the number of independent paths through the source code.
3. It was developed by Thomas J. McCabe, Sr. in 1976.
4. It is computed using the control flow graph of the program. The control flow graph is a directed graph where nodes represent basic blocks and edges represent control flow between basic blocks.
5. The cyclomatic complexity is defined as:

V(G) = E - N + 2

Where E is the number of edges of the graph and N is the number of nodes of the graph.
6. A program with high cyclomatic complexity is harder to test and is more prone to errors.
7. It can be used to determine the number of test cases required to obtain adequate coverage of a program.
8. The optimal value for cyclomatic complexity can vary but a value of 10 or less is desirable.
9. Some ways to reduce cyclomatic complexity are:
- Removing unnecessary conditional logic
- Extracting functions
- Simplifying complex logical expressions
