
### Usability Testing 

1. Usability testing is a type of software testing that evaluates the user experience of a website or application. 
2. It is used to identify any usability issues, such as user confusion or difficulty navigating the interface. 
3. Usability testing usually involves a series of tasks that the user is asked to perform, such as finding a specific item or completing a specific action. 
4. The user's performance is then measured and analyzed to identify any usability issues. 
5. Usability testing can be conducted in a lab setting, with a focus group, or even remotely. 
6. The goal of usability testing is to identify any areas of improvement in the user experience and make changes to improve the overall usability of the website or application.
