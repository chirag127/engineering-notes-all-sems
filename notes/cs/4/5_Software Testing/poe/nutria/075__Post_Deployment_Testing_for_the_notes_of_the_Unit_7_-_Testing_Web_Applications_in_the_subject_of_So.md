
### Post Deployment Testing

Post deployment testing is an important part of the software testing process. It is conducted after the application has been released to the public. The purpose of this type of testing is to ensure that the application meets all the requirements and performs as expected.

This type of testing includes:
1. Performance Testing - This type of testing is used to measure the performance of the application in terms of speed, scalability and stability.
2. Security Testing - This type of testing is used to ensure that the application is secure and that no unauthorized access is allowed.
3. Usability Testing - This type of testing is used to ensure that the application is easy to use and understand.
4. Compatibility Testing - This type of testing is used to ensure that the application works on different platforms and devices.
5. Accessibility Testing - This type of testing is used to ensure that the application is accessible to people with disabilities.
6. User Acceptance Testing - This type of testing is used to ensure that the application meets the expectations of the users.
