
### Terminologies in Testing

1. **Software Engineering**: The application of engineering principles and techniques to the development of software. It includes the study and application of software design, development, and testing.

2. **Software Testing**: The process of verifying that a software system meets the requirements and performs as expected. It includes the analysis of the system's correctness, completeness, security, and performance.

3. **Static Testing**: Testing that is done without executing the software. It includes reviews, inspections, and static analysis.

4. **Dynamic Testing**: Testing that is done by executing the software. It includes unit, integration, system, and acceptance testing.

5. **White Box Testing**: Testing that is done with knowledge of the internal structure of the software. It includes code coverage, branch coverage, and mutation testing.

6. **Black Box Testing**: Testing that is done without knowledge of the internal structure of the software. It includes functional, usability, and performance testing.

7. **Regression Testing**: Testing that is done to ensure that changes to the software have not caused any unintended side effects. It includes retesting and rerunning tests.
