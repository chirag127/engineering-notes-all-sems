
### Cyclomatic Complexity for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

1. Cyclomatic complexity is a software metric used in software testing to measure the complexity of a program. 
2. It is calculated by analyzing the control flow graph of the program, and counting the number of linearly independent paths through the program. 
3. A higher cyclomatic complexity indicates a more complex program, and is associated with a greater risk of bugs. 
4. Structural testing is a type of software testing that focuses on the internal structure of the program, and is used to ensure that the program is correctly structured and follows the rules of the language it is written in. 
5. Structural testing techniques include white box testing, which examines the program’s source code, and black box testing, which examines the program’s external behavior. 
6. Structural testing is used to identify errors in the program’s structure, such as syntax errors, logic errors, and incorrect control flow. 
7. Cyclomatic complexity can be used to guide the selection of structural tests, as tests should be designed to cover all linearly independent paths through the program. 
8. In addition, the results of cyclomatic complexity can be used to determine when a program is too complex and should be refactored.
