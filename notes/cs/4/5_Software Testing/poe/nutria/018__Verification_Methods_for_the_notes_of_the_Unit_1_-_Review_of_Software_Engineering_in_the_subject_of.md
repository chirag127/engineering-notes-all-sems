
### Verification Methods for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

1. **Static Analysis:** This is a type of software testing that involves verifying the code without running it. This is done by carefully examining the code for errors, bugs, and other issues.

2. **Dynamic Analysis:** This is a type of software testing that involves running the code to check for errors and bugs. This is done by executing the code and analyzing its behavior.

3. **Functional Testing:** This is a type of software testing that involves verifying the code's ability to meet the requirements. This is done by testing the code against the requirements and checking for any discrepancies.

4. **Integration Testing:** This is a type of software testing that involves verifying the code's ability to interact with other components. This is done by testing the code against the other components and checking for any errors or bugs.

5. **Regression Testing:** This is a type of software testing that involves verifying the code's ability to handle changes. This is done by testing the code against changes and checking for any errors or bugs.
