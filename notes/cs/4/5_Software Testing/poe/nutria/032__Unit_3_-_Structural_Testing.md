
## Unit 3 - Structural Testing

* Structural testing is a type of software testing that evaluates the structure of the code to ensure it meets the requirements.
* It is used to verify the correctness of the code, as well as its accuracy and reliability. 
* Structural testing is often used to identify errors in the code that may not be visible during normal testing.
* It is a type of white-box testing, which means it requires knowledge of the internal structure of the code.
* Structural testing can be used to find errors in the code, such as incorrect logic, missing code, or incorrect data structures.
* Common techniques used for structural testing include statement coverage, branch coverage, and path coverage.
* Structural testing can also be used to evaluate the quality of the code, as well as to ensure it is secure and robust.
