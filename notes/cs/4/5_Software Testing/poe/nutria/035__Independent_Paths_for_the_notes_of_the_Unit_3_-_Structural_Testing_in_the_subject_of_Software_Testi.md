
### Independent Paths for the notes of the Unit 3 - Structural Testing in the subject of Software Testing

1. Structural Testing is a form of software testing that focuses on the internal structure of the source code. 
2. It is based on the idea that the structure of the code should be tested before the code is tested in the real world.
3. Structural Testing is used to identify bugs and errors in the source code that could lead to errors in the program's execution.
4. Structural Testing focuses on the flow of control, data flow, and the structure of the program.
5. Structural Testing is used to identify common coding errors such as logic errors, syntax errors, and other errors that can affect the program's execution.
6. Structural Testing can be used to identify potential security vulnerabilities in the source code.
7. Structural Testing is used to ensure that the program meets the requirements of the customer.
8. Structural Testing is used to identify potential performance issues in the program.
9. Structural Testing is used to ensure that the program is maintainable and can be easily modified in the future.
10. Structural Testing is used to ensure that the program is reliable and can be trusted to perform its intended tasks.
