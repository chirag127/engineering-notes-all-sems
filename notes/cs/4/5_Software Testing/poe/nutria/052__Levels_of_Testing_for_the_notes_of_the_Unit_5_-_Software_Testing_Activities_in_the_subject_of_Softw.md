
### Levels of Testing for the Unit 5 - Software Testing Activities

1. Unit Testing: This type of testing focuses on individual units or components of a software system. It is usually done by the developers, and it is done to verify that each unit of the software performs as designed.

2. Integration Testing: This type of testing focuses on the integration of different units or components of a software system. It is usually done by testers, and it is done to verify that the different units of the software work together as expected.

3. System Testing: This type of testing focuses on the entire software system. It is usually done by testers, and it is done to verify that the software system meets the requirements specified in the requirements document.

4. Acceptance Testing: This type of testing focuses on the user acceptance of the software system. It is usually done by the customer, and it is done to verify that the software system meets the customer's requirements and expectations.
