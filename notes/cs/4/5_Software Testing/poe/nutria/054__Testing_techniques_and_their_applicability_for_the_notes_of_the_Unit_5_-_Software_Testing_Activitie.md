
### Testing Techniques and their Applicability for the Notes of the Unit 5 - Software Testing Activities in the Subject of Software Testing

1. White Box Testing: This technique focuses on the internal structure of a system, such as the source code, logic, and design. It is used to test the correctness, accuracy, and completeness of a system.

2. Black Box Testing: This technique is used to test the functionality of a system without any knowledge of the internal structure. It is used to test the functionality and usability of a system.

3. Unit Testing: This technique is used to test individual units of code. It is used to ensure that each unit of code is working correctly.

4. Integration Testing: This technique is used to test the integration of different components of a system. It is used to ensure that the components are working together correctly.

5. System Testing: This technique is used to test the entire system. It is used to ensure that the system is working correctly as a whole.

6. Acceptance Testing: This technique is used to test the system against the customer's requirements. It is used to ensure that the system meets the customer's expectations.
