### Verification Methods for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing
Verification methods in software testing are used to determine whether the software product meets the specified requirements and standards. There are several verification methods, including:

1. Inspection: A formal review process of the software product, performed by a team of experts, to identify defects and improve quality.

2. Walkthrough: A less formal review process where the software product is presented to a group of stakeholders for feedback and suggestions.

3. Peer Review: A review process where software product is reviewed by peers to identify defects and improve quality.

4. Prototyping: Creating a working model of the software product to test its functionality and usability.

5. Formal Verification: A mathematical approach to verifying software product, using formal methods and tools.

6. Test-driven development (TDD): A software development approach where tests are written before the code is written, to verify that the code meets the requirements.

These verification methods are used in different stages of the software development lifecycle to ensure the quality of the software product.
