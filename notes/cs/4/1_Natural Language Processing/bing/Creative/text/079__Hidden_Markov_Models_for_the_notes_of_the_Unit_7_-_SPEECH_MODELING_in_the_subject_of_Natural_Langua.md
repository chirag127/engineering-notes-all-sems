### Hidden Markov Models

Hidden Markov Models (HMMs) are a statistical framework for modeling sequences of observations that are generated by an underlying stochastic process. HMMs are widely used for speech recognition and modeling, as they can capture the temporal and spectral characteristics of speech signals. In this section, we will introduce the basic concepts and algorithms of HMMs, and how they are applied to speech recognition.

#### HMM Definition

A HMM is characterized by the following components:

- A set of **states** $S = \{s_1, s_2, ..., s_N\}$, where each state represents a possible configuration of the underlying process. For example, in speech recognition, each state can correspond to a phoneme or a sub-phoneme unit.
- A set of **observations** $O = \{o_1, o_2, ..., o_T\}$, where each observation is a vector of features extracted from the speech signal. For example, each observation can be a vector of Mel-frequency cepstral coefficients (MFCCs) or linear predictive coding (LPC) coefficients.
- A **transition probability matrix** $A = \{a_{ij}\}$, where each element $a_{ij}$ is the probability of transitioning from state $s_i$ to state $s_j$, i.e., $a_{ij} = P(q_{t+1} = s_j | q_t = s_i)$, where $q_t$ is the state at time $t$. The transition probabilities satisfy the following constraints:

  - $0 \leq a_{ij} \leq 1$ for all $i, j$
  - $\sum_{j=1}^N a_{ij} = 1$ for all $i$

- An **initial state probability distribution** $\pi = \{\pi_i\}$, where each element $\pi_i$ is the probability of starting in state $s_i$, i.e., $\pi_i = P(q_1 = s_i)$. The initial state probabilities satisfy the following constraints:

  - $0 \leq \pi_i \leq 1$ for all $i$
  - $\sum_{i=1}^N \pi_i = 1$

- An **observation probability distribution** $B = \{b_i(o)\}$, where each element $b_i(o)$ is the probability of emitting observation $o$ from state $s_i$, i.e., $b_i(o) = P(o | q_t = s_i)$. The observation probabilities can be modeled by different types of distributions, such as discrete, Gaussian, or mixture of Gaussians.

#### HMM Problems and Algorithms

There are three fundamental problems that can be solved using HMMs:

- **Evaluation**: Given a HMM $\lambda$ and an observation sequence $O$, compute the probability of the observation sequence given the model, i.e., $P(O | \lambda)$. This problem is useful for comparing different models and selecting the best one for a given task.
- **Decoding**: Given a HMM $\lambda$ and an observation sequence $O$, find the most likely state sequence that generated the observation sequence, i.e., $\arg\max_Q P(Q | O, \lambda)$, where $Q = \{q_1, q_2, ..., q_T\}$ is a state sequence. This problem is useful for finding the underlying structure or meaning of the observation sequence.
- **Training**: Given an observation sequence $O$ and a set of states $S$, find the optimal parameters of the HMM $\lambda$ that maximize the probability of the observation sequence, i.e., $\arg\max_\lambda P(O | \lambda)$. This problem is useful for learning the model from data.
