### Markov Processes for the notes of the Unit 7 - SPEECH MODELING in the subject of Natural Language Processing

- A Markov Process is a stochastic model that describes the evolution of a system over time, where the future state of the system depends only on the current state and not on the previous history. This is known as the Markov property or the memoryless property.
- A Markov Process can be used to model temporal or sequential data, such as speech, text, or music, where the current information is influenced by the previous information.
- A Markov Process consists of a set of states, a set of possible outputs or observations, and a set of transition probabilities that specify how likely the system is to move from one state to another, and a set of emission probabilities that specify how likely the system is to produce a certain output or observation in each state.
- A Markov Process can be represented by a state diagram, where the nodes are the states and the edges are the transition probabilities. For example, the following diagram shows a Markov Process that models the weather with three states: sunny, rainy, and cloudy.

```
   0.8    0.2
Sunny -----> Cloudy
  ^  |       |  ^
  |  |0.05   |  |0.2
  |  v       v  |
Rainy <----- Cloudy
   0.1    0.8
```

- A Markov Process can be used for speech modeling by assuming that the speech signal is generated by a sequence of states that correspond to different acoustic units, such as phonemes, syllables, or words. Each state can emit a certain acoustic feature vector, such as the spectral envelope or the pitch contour, with some probability. The transition probabilities between states can capture the temporal structure and the linguistic rules of the speech.
- A Markov Process can be classified into two types: observable and hidden. An observable Markov Process is one where the states of the system are directly visible or measurable, and the output or observation is the same as the state. For example, the weather Markov Process is observable, since we can directly observe whether it is sunny, rainy, or cloudy. A hidden Markov Process is one where the states of the system are not directly observable or measurable, and the output or observation is different from the state. For example, the speech Markov Process is hidden, since we cannot directly observe the acoustic units that generate the speech signal, and the output or observation is the acoustic feature vector.
- A Hidden Markov Model (HMM) is a statistical tool that can be used to infer the hidden states of a system from the observed outputs or observations, using the principles of Bayesian inference. An HMM can also be used to generate a sequence of outputs or observations from a sequence of hidden states, using the principles of stochastic simulation. An HMM can be used for various tasks in speech and language processing, such as speech recognition, speech synthesis, speech segmentation, speech enhancement, language modeling, part-of-speech tagging, named-entity recognition, and so on.
- An HMM can be defined by the following parameters: the number of states N, the number of possible outputs or observations M, the initial state probabilities π, the state transition probabilities A, and the state emission probabilities B. An HMM can be represented by the notation λ = (π, A, B).
- An HMM can be represented by a state diagram, where the nodes are the hidden states and the edges are the transition probabilities, and each state has a set of emission probabilities associated with it.
