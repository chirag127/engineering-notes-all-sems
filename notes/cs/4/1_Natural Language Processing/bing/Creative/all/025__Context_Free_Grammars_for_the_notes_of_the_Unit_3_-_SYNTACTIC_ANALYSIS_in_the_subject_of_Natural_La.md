### Context Free Grammars for the notes of the Unit 3 - SYNTACTIC ANALYSIS in the subject of Natural Language Processing

- A context-free grammar (CFG) is a notation used for describing the languages and it is a superset of regular grammar.
- A CFG consists of a finite set of grammar rules having the following four components :
  - Set of non-terminals: It is represented by V. The non-terminals are syntactic variables that denote the sets of strings, which help in defining the language that is generated with the help of grammar.
  - Set of terminals: It is also known as tokens and represented by Σ. Strings are formed with the help of the basic symbols of terminals.
  - Set of productions: It is represented by P. The set gives an idea about how the terminals and non-terminals can be combined. Every production consists of the following components:
    - A non-terminal symbol on the left-hand side, which is replaced by the right-hand side.
    - An arrow (→) to separate the left-hand side and the right-hand side.
    - A string of symbols on the right-hand side, which can be empty, a single terminal, a single non-terminal, or a combination of terminals and non-terminals.
  - Start symbol: It is represented by S. It is a special non-terminal symbol that appears in the initial string generated by the grammar.
- A CFG can be written as a 4-tuple (V, Σ, S, P) where V, Σ, S, and P are the sets of non-terminals, terminals, start symbol, and productions, respectively.
- A CFG can generate a language by applying the production rules recursively, starting from the start symbol, until no non-terminal symbols are left in the string. The language generated by a CFG is the set of all strings that can be derived from the start symbol.
- A CFG can also be represented by a parse tree, which is a graphical representation of the derivation process. A parse tree has the following properties:
  - The root node is labeled with the start symbol.
  - The leaf nodes are labeled with terminals or empty symbols.
  - The internal nodes are labeled with non-terminals.
  - The children of each node are labeled with the symbols on the right-hand side of the production rule that is applied to the parent node.
- A CFG can be used to model the constituent structure of natural language sentences, where each constituent is a phrase that behaves as a single unit. A commonly used mathematical system for modelling constituent structure in natural language is constituency grammar (CG), which is based on CFG .
- A CFG can also be used to define the high-level structure of a programming language, where each production rule specifies the syntax of a language construct. A commonly used notation for describing the syntax of a programming language is Backus-Naur form (BNF), which is based on CFG .
- A CFG has some limitations, such as:
  - It cannot capture the dependencies between non-adjacent words or phrases in a sentence, such as subject-verb agreement or anaphora resolution.
  - It cannot handle the ambiguity of natural language sentences, such as structural ambiguity or lexical ambiguity.
  - It cannot account for the semantic or pragmatic aspects of natural language, such as meaning or context.
- A CFG can be extended or modified to overcome some of these limitations, such as:
  - Adding features or attributes to the non-terminal symbols, such as number, gender, case, etc., to capture the agreement or agreement relations in a sentence. This leads to feature-based grammar (FBG).
  - Adding constraints or conditions to the production rules, such as semantic or pragmatic constraints, to filter out the invalid or inappropriate derivations. This leads to constraint-based grammar (CBG).
  - Adding probabilities or weights to the production rules, such as based on the frequency or likelihood of occurrence, to rank or select the best derivation among the possible ones. This leads to probabilistic grammar (PG).
