The Probabilistic CYK algorithm is a variant of the CYK algorithm that finds the most likely parse tree of a given sentence according to a probabilistic context-free grammar (PCFG). The algorithm uses dynamic programming to store the probabilities of each substring being generated by each nonterminal variable in a table. The algorithm also keeps track of the backpointers that indicate the best split point and the best rule for each substring. The algorithm returns the highest probability and the corresponding parse tree for the whole sentence.
