The production and classification of speech sounds involves four main processes: initiation, phonation, oro-nasal process, and articulation. Initiation is the generation of the air stream by the lungs. Phonation is the vibration of the vocal cords in the larynx. Oro-nasal process is the direction of the air stream into either the oral or the nasal cavity by the velum. Articulation is the modification of the air stream by the tongue and other organs in the oral cavity. The following diagram illustrates the basic architecture of a speech production system:

```

|                 |    |                 |    | process         |    |                 |
+-----------------+    +-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |    |                 |
|   Lungs         |    |   Larynx        |    |   Velum         |    |   Oral cavity   |
|                 |    |                 |    |                 |    |                 |
+-----------------+    +-----------------+    +-----------------+    +-----------------+
|                 |    |                 |    |                 |    |                 |
```

Speech sounds are classified into two broad phonetic categories: vowels and consonants. A vowel is a speech sound in which there is no obstruction or narrowing of the air stream in the oral cavity. A consonant is a speech sound in which there is some degree of obstruction or narrowing of the air stream in the oral cavity. Vowels and consonants can be further classified according to various features, such as the position of the tongue, the shape of the lips, the presence or absence of voicing, and the manner of articulation.
