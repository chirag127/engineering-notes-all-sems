A context-free grammar (CFG) is a mathematical system for modeling the syntax of natural languages. It consists of a set of rules that specify how words and phrases can be combined to form sentences. A CFG can be represented by a 4-tuple (N, T, S, P) where:

- N is a set of non-terminal symbols, which are abstract categories that group words or phrases with similar syntactic functions.
- T is a set of terminal symbols, which are the actual words or punctuation marks of the language.
- S is a start symbol, which is a special non-terminal symbol that represents the whole sentence.
- P is a set of production rules, which are of the form A -> B, where A is a non-terminal symbol and B is a sequence of terminal or non-terminal symbols. A production rule means that A can be replaced by B in a derivation.

A CFG can be used to generate or parse sentences in a natural language. To generate a sentence, we start with the start symbol S and apply production rules until we get a sequence of terminal symbols. To parse a sentence, we start with the sequence of terminal symbols and try to find a sequence of production rules that can derive it from the start symbol S.

A CFG can also be represented by a parse tree, which is a graphical representation of the structure of a sentence. A parse tree shows how the sentence is derived from the start symbol by applying production rules. Each node in the tree corresponds to a non-terminal or terminal symbol, and each branch corresponds to a production rule.

An example of a CFG for a fragment of English is:

N = {S, NP, VP, Det, N, V, PP, P}
T = {the, a, dog, cat, mouse, chased, bit, in, on, garden, house}
S = S
P = {S -> NP VP, NP -> Det N, NP -> NP PP, VP -> V NP, VP -> VP PP, Det -> the, Det -> a, N -> dog, N -> cat, N -> mouse, N -> garden, N -> house, V -> chased, V -> bit, PP -> P NP, P -> in, P -> on}

An example of a sentence generated by this CFG is:

the dog chased a cat in the garden
