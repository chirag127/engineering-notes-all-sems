Articulatory phonetics is the branch of phonetics that studies how humans produce speech sounds by using the movements and positions of the vocal organs (articulators). The vocal organs include the lips, tongue, teeth, alveolar ridge, hard palate, velum, uvula, pharynx, glottis, and vocal folds. Articulatory phonetics is concerned with the transformation of aerodynamic energy into acoustic energy. Aerodynamic energy refers to the airflow through the vocal tract. Acoustic energy refers to the sound waves that are generated by the vocal organs and transmitted through the air.

```
|                 |     |                 |     |                 |
|  Speech Plan    | --> |  Motor Control  | --> |  Vocal Organs   |
|                 |     |                 |     |                 |
+-----------------+     +-----------------+     +-----------------+
                                                    |
                                                    |
                                                    V
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|  Speech Signal  | <-- |  Acoustic       | <-- |  Aerodynamic    |
|                 |     |  Transformation |     |  Transformation |
+-----------------+     +-----------------+     +-----------------+
```

The speech plan is the cognitive representation of the intended speech sounds, which may include phonological, lexical, syntactic, and pragmatic information. The motor control is the neural mechanism that converts the speech plan into motor commands for the vocal organs. The vocal organs are the anatomical structures that execute the motor commands and produce speech sounds. The aerodynamic transformation is the process of converting the airflow through the vocal tract into sound waves. The acoustic transformation is the process of modifying the sound waves by the shape and size of the vocal tract. The speech signal is the final output of the speech production system, which can be perceived by the listener.
