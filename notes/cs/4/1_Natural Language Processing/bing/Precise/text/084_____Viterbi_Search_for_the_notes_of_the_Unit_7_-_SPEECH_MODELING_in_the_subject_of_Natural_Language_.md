### Viterbi Search

The Viterbi algorithm is a dynamic programming algorithm used to find the most likely sequence of hidden states in a Hidden Markov Model (HMM). It was introduced to Natural Language Processing as a method of part-of-speech tagging as early as 1987. The Viterbi path and Viterbi algorithm have become standard terms for the application of dynamic programming algorithms to maximization problems involving probabilities.

In the context of speech modeling, the Viterbi algorithm can be used to find the most likely sequence of part-of-speech tags for a given sentence. This is done by computing all the possible paths for the sentence and finding the one with the highest probability.

The Viterbi algorithm is a vital tool for computational linguistics and is commonly used in Natural Language Processing tasks such as part-of-speech tagging, auto-correct, and auto-complete  .
