## Unit 3 - SYNTACTIC ANALYSIS

Syntactic analysis is an essential aspect of natural language processing (NLP) that involves analyzing the grammatical structure of a sentence to determine its meaning. This unit covers the following topics:

### 1. Introduction to Syntactic Analysis
- Definition of Syntactic Analysis
- Importance of Syntactic Analysis in NLP
- Syntactic vs. Semantic Analysis

### 2. Context-Free Grammars (CFGs)
- Definition of Context-Free Grammars
- Components of CFGs: Terminals, Non-terminals, Productions
- Derivation Trees

### 3. Parsing Techniques
- Definition of Parsing
- Top-Down Parsing Techniques: Recursive Descent Parsing, LL Parsing
- Bottom-Up Parsing Techniques: Shift-Reduce Parsing, LR Parsing

### 4. Ambiguity in Syntactic Analysis
- Definition of Ambiguity
- Types of Ambiguity: Structural Ambiguity, Lexical Ambiguity
- Handling Ambiguity: Disambiguation Techniques

### 5. Advanced Syntactic Analysis Techniques
- Dependency Parsing
- Constituent Parsing
- Probabilistic Parsing

### 6. Applications of Syntactic Analysis
- Machine Translation
- Question Answering Systems
- Sentiment Analysis

Remember to practice syntactic analysis techniques on various example sentences to gain a better understanding of the concepts covered in this unit. Good luck with your studies!
