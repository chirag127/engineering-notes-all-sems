### Requirements for the consensus protocols for the notes of the Unit 2 - Consensus in the subject of Block chain Architecture Design

Consensus protocols play a crucial role in the blockchain network as they ensure that all nodes in the network agree on the state of the ledger. A consensus protocol is used to validate transactions, ensure immutability, and prevent double-spending. In this unit, we will learn about the various requirements for consensus protocols in the blockchain network. 

Here are the requirements for the consensus protocols for the notes of the Unit 2 - Consensus in the subject of Block chain Architecture Design:

1. **Fault Tolerance:** The consensus protocol should be able to tolerate the failure of some nodes in the network. This is important because nodes may fail due to hardware or software issues, and the consensus protocol should be able to continue functioning even if some nodes fail.

2. **Safety:** The consensus protocol should ensure that once a block is added to the blockchain, it cannot be removed or modified. This ensures the immutability of the blockchain and prevents double-spending.

3. **Liveness:** The consensus protocol should ensure that the network can continue to make progress even if some nodes are offline or unresponsive. This is important because the blockchain network should always be available for transactions.

4. **Decentralization:** The consensus protocol should be decentralized, meaning that no single entity should have control over the network. This ensures that the network is secure, transparent, and resistant to censorship.

5. **Scalability:** The consensus protocol should be scalable, meaning that it should be able to handle a large number of transactions without slowing down. This is important because as more users join the network, the blockchain should still be able to function efficiently.

6. **Incentives:** The consensus protocol should provide incentives for nodes to participate in the network and validate transactions. This ensures that the network is secure and that nodes have an incentive to act in the best interest of the network.
