### fabric SDK and Front End

- Fabric SDK provides APIs for application developers to interact with a Hyperledger Fabric blockchain network. It allows applications to be developed in Node.js, Java, Go and Python.
- The Fabric SDK includes a wallet to store identities, a CA client to interact with a certificate authority, and a channel client to submit transactions and query blocks, transactions and ledger data.
- The Fabcar tutorial demonstrates the usage of the Fabric SDK to build a simple car manufacturing supply chain application. It showcases deployment of chaincode, transaction processing and queries using the SDK.
- For frontend development, a web app can be built using JavaScript/TypeScript and frameworks like React or Angular to interact with the Fabric network via the SDK. The app can facilitate enrollment of users, transaction submission and result visualization.
- Key points to remember:
    - Fabric SDK provides language-specific APIs to interact with Fabric
    - Includes components like wallet, CA client and channel client
    - Facilitates chaincode deployment, transaction processing and querying
    - Can be used to build browser-based frontend apps via JavaScript frameworks
    - Frontend can enable user enrollment and transaction functionality visualization

- Mnemonics:
    - Want APIs? Use Fabric SDK!
    - Wallet, CA client, channel client - the Fab three musketeers
    - Fabcar shows SDK usage
    - React/Angular + TypeScript/JavaScript = Frontend delight!
