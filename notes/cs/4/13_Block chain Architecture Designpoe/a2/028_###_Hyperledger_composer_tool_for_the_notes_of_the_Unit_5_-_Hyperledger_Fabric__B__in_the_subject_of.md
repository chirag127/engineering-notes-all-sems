### Hyperledger composer tool for the notes of the Unit 5 - Hyperledger Fabric (B) in the subject of Block chain Architecture Design

- Hyperledger Composer is a set of tools developed by Hyperledger to make developing blockchain applications easier. It allows you to model a business network, create APIs from the model, and deploy the business network to a Hyperledger Fabric blockchain.
- Some key points about Hyperledger Composer:
    - It provides a modeling language (based on JavaScript Object Notation or JSON) to define assets, participants, and transactions of a blockchain business network.
    - It generates REST APIs from the model which allow you to create, read, update, and delete assets and submit transactions.
    - It generates a chaincode (Hyperledger Fabric smart contract) from the model which implements the logic of the network.
    - It packages all of the components into an executable .bna file which can be deployed to a Hyperledger Fabric blockchain.
- Mnemonics to remember: Think of Hyperledger Composer as a tool to COMPOSE/DEVELOP blockchain apps on Fabric EASILY by MODELING (language) -> APIs + Chaincode -> Deploy (.bna file).
- Advantages: Makes blockchain app development faster and easier. Uses familiar web languages and standards (JSON, REST).
- Disadvantages: Limited to Hyperledger Fabric blockchain. May not suitable for very complex blockchain networks. Still relatively new so learning resources and community support may be limited.
- Examples: Supply chain, letters of credit, trade finance, etc.
- Applications: Useful for developers, enterprises, and consortia looking to build blockchain applications on Hyperledger Fabric quickly and with less complexity.
