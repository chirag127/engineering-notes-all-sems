### Protocols for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

1. HTTP - Hypertext Transfer Protocol is the set of rules for transferring web pages on the World Wide Web. Blockchain uses HTTP for communication between nodes in a peer-to-peer network.

2. P2P - Peer-to-Peer protocol is a decentralized network architecture in which nodes share resources and communicate directly with each other instead of through a centralized server. Blockchain network follows a P2P protocol where nodes connect and communicate with each other directly to share the ledger and verify transactions.

3. TCP/IP - Transmission Control Protocol/Internet Protocol is the set of protocols for sending packets of data over the Internet. Blockchain uses TCP/IP for networking and communication between nodes.

**Advantages** - Decentralized, fault tolerant, transparent, immutable.

**Disadvantages** - Scalability, Interoperability, Privacy, Energy consumption.

**Applications** - Cryptocurrencies, Smart contracts, Voting, Healthcare records, etc.

**Mnemonics** -

HTTP - Web transfer
P2P - Direct connect
TCP/IP - Packets transfer

**Learning tricks** -

Remember HPT - HTTP, P2P, TCP/IP

H - Hypertext transfer over web
P - Peer-to-peer direct connection
T - Transmission of packets
