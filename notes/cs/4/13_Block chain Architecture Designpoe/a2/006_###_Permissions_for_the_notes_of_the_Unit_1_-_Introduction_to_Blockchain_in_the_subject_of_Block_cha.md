### Permissions for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

- Read Permission - Node can only read the blockchain data and transaction details but cannot modify or add any data to the blockchain.
- Write Permission - Node has the permission to add new blocks to the blockchain. The nodes with write permission are also called miners. They validate the transactions, solve proof of work problems and add new blocks to the blockchain.
- Administrator Permission - Nodes with administrator permission have full access to the blockchain. They can read, write and modify the blockchain data. The administrators manage the consensus process, add or remove mining nodes, modify mining difficulty, etc.

Mnemonics -

READ - Only read access
WRITE - Write access to add new blocks
ADMIN - Full access to manage blockchain

Advantages of permissions -

- Security is enhanced as only authorized nodes can access the blockchain.
- Consensus process can be managed efficiently by the administrator nodes.
- Malicious nodes can be prevented from manipulating the blockchain data.

Disadvantages of permissions -

- Centralization of power with the administrator nodes.
- Single point of failure as the entire blockchain depends on the administrator nodes. If they fail or act maliciously, the blockchain can be compromised.

Applications -

- Private blockchains where permissions are managed by a central authority.
- Consortium blockchains where a group of nodes manage the permissions.
