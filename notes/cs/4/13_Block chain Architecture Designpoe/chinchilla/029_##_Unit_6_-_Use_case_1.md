## Unit 6 - Use case 1

Use case 1 is one of the most common types of use cases in system development. It is a technique used to identify and document the functional requirements of a system by focusing on the interactions between the system and its actors. In this unit, we will explore the key aspects of Use case 1 and how it can be used in system development.

### What is Use case 1?

Use case 1 is a technique that is used to identify and document the functional requirements of a system by focusing on the interactions between the system and its actors. An actor is any external entity that interacts with the system. For example, a user, a customer, or another system can be an actor.

A use case is a set of interactions between the system and its actors that achieve a specific goal. Each use case represents a single piece of functionality that the system must provide. Use cases can be used to describe the behavior of the system, the inputs and outputs of the system, and the interactions between the system and its actors.

### How to create a Use case 1?

The following steps can be followed to create a Use case 1:

1. Identify the actors: Identify all the actors that interact with the system. Actors can be users, customers, or other systems.

2. Identify the goals: Identify the goals of each actor. What does the actor want to achieve by interacting with the system?

3. Identify the use cases: Identify the use cases that are required to achieve each goal. Each use case represents a specific piece of functionality that the system must provide.

4. Define the use cases: Define each use case in detail. Identify the inputs and outputs of the use case, the behavior of the system, and the interactions between the system and its actors.

5. Validate the use cases: Validate the use cases with the stakeholders to ensure that they accurately represent the requirements of the system.

### Advantages of Use case 1

1. Use case 1 helps to identify and document the functional requirements of a system.

2. It helps to identify the interactions between the system and its actors.

3. It provides a clear understanding of the behavior of the system.

4. It helps to identify the inputs and outputs of the system.

5. It helps to identify the limitations of the system.

### Disadvantages of Use case 1

1. Use case 1 can be time-consuming to create.

2. It may not be suitable for all types of systems.

3. It can be difficult to identify all the actors and their goals.
