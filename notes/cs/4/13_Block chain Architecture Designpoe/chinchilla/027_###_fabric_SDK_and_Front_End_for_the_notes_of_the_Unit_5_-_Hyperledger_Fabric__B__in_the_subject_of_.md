#### Fabric SDK

Fabric SDK (Software Development Kit) is a collection of libraries that allow developers to interact with the Hyperledger Fabric blockchain network. It provides a programming interface for developers to create, read, update and delete data on the blockchain network. Fabric SDK supports multiple programming languages such as Go, Java, Node.js, and Python. Some of the key features of Fabric SDK are:

- **Identity Management:** Fabric SDK provides a mechanism for managing identities on the blockchain network. It allows users to create, manage, and revoke identities, ensuring that only authorized users can access the network.

- **Transaction Management:** Fabric SDK provides a mechanism for managing transactions on the blockchain network. It allows developers to create, sign, and submit transactions to the network.

- **Querying the Blockchain:** Fabric SDK allows developers to query the blockchain network for information. It provides a mechanism for retrieving data from the blockchain network.

- **Event Management:** Fabric SDK provides a mechanism for managing events on the blockchain network. It allows developers to subscribe to events and receive notifications when certain events occur on the network.

Front End is typically built using web technologies such as HTML, CSS, and JavaScript. Some of the key features of Front End are:

- **User Management:** Front End provides a mechanism for managing users on the blockchain network. It allows users to create, manage, and revoke identities, ensuring that only authorized users can access the network.
