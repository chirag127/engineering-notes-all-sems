
### Hashchain to Blockchain for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

A hashchain is a type of data structure used to store information in a secure and tamper-proof way. It is composed of a series of “hashes” or “blocks” that are linked together to form a chain. Each block contains data that is cryptographically linked to the previous block, and together they form a secure chain of data. A blockchain is a type of distributed ledger technology (DLT) that uses a hashchain to store data in a secure and tamper-proof way.

A hashchain is used to store data in a distributed ledger in which each block is cryptographically linked to the previous block. The data stored in each block is cryptographically hashed, which ensures that it cannot be altered. The main advantage of using a hashchain is that it is very secure and tamper-proof. It is also very efficient and can be used to store large amounts of data. Additionally, it is easy to implement and maintain.
