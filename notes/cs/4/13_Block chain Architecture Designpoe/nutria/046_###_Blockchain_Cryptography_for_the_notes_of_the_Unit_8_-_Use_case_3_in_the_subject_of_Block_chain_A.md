
### Blockchain Cryptography for the Notes of the Unit 8 - Use Case 3 in the Subject of Block Chain Architecture Design

Cryptography is a branch of mathematics used to secure data and communication. It is used in the blockchain to ensure data integrity and security. Blockchain cryptography is used to secure the data stored in the blockchain, and to verify the authenticity of the transactions.

Blockchain cryptography consists of two main components:

1. Public Key Cryptography: This is used to protect the data stored in the blockchain. It uses a pair of keys, a public key and a private key. The public key is used to encrypt the data, while the private key is used to decrypt it.

2. Digital Signatures: These are used to verify the authenticity of the transactions. Digital signatures are created using a hash of the transaction data and the sender's private key. This ensures that the transaction data has not been tampered with and that it is coming from the correct sender.

Mnemonic:

Public Key Cryptography: PPC (Public Key Cryptography)
Digital Signatures: DS (Digital Signatures)
