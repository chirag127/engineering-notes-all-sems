
## Unit 4 - Hyperledger Fabric (A)

Hyperledger Fabric is an open source distributed ledger technology (DLT) platform, designed for use in enterprise contexts, that delivers some key distinguishing features over other popular DLT systems. It is a permissioned network that uses a modular architecture, allowing components such as consensus and membership services to be plug-and-play. 

Here are some key points to remember about Hyperledger Fabric:

- Fabric is a permissioned blockchain platform that is optimized for enterprise use cases.
- It is designed to support plug-and-play components such as consensus and membership services.
- It is modular and scalable, allowing it to be tailored to specific use cases.
- It provides a high degree of confidentiality, allowing users to control who has access to their data.
- It supports smart contracts written in chaincode, allowing users to automate business processes.
- It is secure and reliable, with a range of security features to protect users' data.

Mnemonic: F-P-P-C-C-S-S-C-S-S (Fabric - Permissioned - Plug-and-play - Components - Confidentiality - Smart Contracts - Secure - Reliable).
