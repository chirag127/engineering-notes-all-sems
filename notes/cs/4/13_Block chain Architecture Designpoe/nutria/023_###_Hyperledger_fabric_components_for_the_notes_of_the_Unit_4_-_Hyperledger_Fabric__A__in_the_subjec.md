
### Hyperledger Fabric Components for the Notes of the Unit 4 - Hyperledger Fabric (A) in the Subject of Block Chain Architecture Design

Hyperledger Fabric is a distributed ledger platform for developing blockchain applications. It is an open source platform built on the Linux Foundation's Hyperledger project. It is designed to support the development of enterprise-grade blockchain applications.

Hyperledger Fabric consists of several components:

* **Peer**: This is a node in the network that stores and validates transactions, maintains the ledger, and executes smart contracts.

* **Orderer**: This is a node in the network that is responsible for ordering transactions. It ensures that all peers in the network have the same view of the ledger.

* **Membership Service Provider (MSP)**: This is a component that is responsible for maintaining the identity of members in the network. It also provides authentication and authorization services.

* **Chaincode**: This is a program written in Go, Java, Node.js, or other languages, that runs on the peer nodes and is responsible for executing transactions and maintaining the ledger.

* **Ledger**: This is a database that stores the state of the network. It is updated with each transaction.

* **Consensus**: This is the process by which all peers in the network agree on the state of the ledger. It ensures that all peers have the same view of the ledger.

* **Identity**: This is the identity of the members in the network. It is used to authenticate and authorize transactions.

* **Smart Contracts**: These are programs that are written in Go, Java, Node.js, or other languages and are executed on the peer nodes. They are responsible for executing transactions and maintaining the ledger.

Mnemonics and learning tricks for the Hyperledger Fabric components can be helpful for remembering the different components and their roles. For example, one could remember the components by using the acronym "POMCULS":

* **P** - Peer
* **O** - Orderer
* **M** - Membership Service Provider
* **C** - Chaincode
* **U** - Ledger
* **L** - Consensus
* **S** - Smart Contracts
