
## Unit 7 - Use case 2

A use case is a set of scenarios that describe how a user interacts with a system to achieve a specific goal. Use cases are used to capture the requirements of a system and are often used in software development.

**Mnemonic**: U7UC2

**Advantages**
- Use cases provide a clear and concise way of representing the requirements of a system.
- Use cases provide a structured way of documenting interactions between a user and a system.
- Use cases are helpful in understanding the user's needs and objectives.

**Disadvantages**
- Use cases can be time consuming to create.
- Use cases can be difficult to maintain.
- Use cases can be difficult to understand for people who are not familiar with the system.

**Examples**
- A user logging into a system.
- A user searching for a product in an e-commerce store.
- A user placing an order in an e-commerce store.

**Applications**
- Use cases are used in software development to capture the requirements of a system.
- Use cases are used in product design to understand the user's needs and objectives.
- Use cases are used in project management to ensure that all stakeholders are on the same page.
