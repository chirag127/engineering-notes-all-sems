
## Unit 2 - Consensus

Consensus is the process of reaching agreement among participants in a distributed system. It is an important concept in distributed computing and is used to solve the problem of data consistency in distributed systems. It is also used to ensure that all nodes in a distributed system agree on the same set of data.

### Types of Consensus

There are two main types of consensus algorithms:

- **Proof of Work (PoW)**: This is the most commonly used consensus algorithm. It requires miners to solve difficult mathematical puzzles in order to add new blocks to the blockchain.

- **Proof of Stake (PoS)**: This consensus algorithm requires participants to stake their coins in order to validate transactions. This approach is more energy efficient than PoW and is gaining traction in the blockchain community.

### Advantages of Consensus

- **Decentralization**: Consensus algorithms enable distributed systems to run without a centralized authority. This allows for more robust and secure systems.

- **Faster Transactions**: Consensus algorithms allow for faster transaction times as they reduce the need for confirmation from multiple parties.

- **Fault Tolerance**: Consensus algorithms allow for fault tolerance as they enable nodes to continue to operate even when some nodes fail.

### Disadvantages of Consensus

- **Complexity**: Consensus algorithms can be difficult to understand and implement.

- **Energy Consumption**: PoW consensus algorithms require a large amount of energy to operate.

- **Security**: Consensus algorithms can be vulnerable to attacks such as the “51% attack”.
