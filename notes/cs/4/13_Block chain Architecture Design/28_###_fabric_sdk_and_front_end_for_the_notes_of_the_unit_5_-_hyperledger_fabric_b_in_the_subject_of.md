### fabric SDK and Front End for the notes of the Unit 5 - Hyperledger Fabric (B) in the subject of Block chain Architecture Design

Hyperledger Fabric SDK: 
- A software development kit that provides APIs for application developers to interact with the Hyperledger Fabric blockchain network. 
- The SDK abstracts the underlying blockchain implementation, allowing developers to focus on business logic. 
- Supports multiple programming languages such as Java, Go, Node.js, Python, and more. 

Hyperledger Fabric Front End:
- A user interface for interacting with the Hyperledger Fabric network. 
- Provides a visual representation of the network's components and transactions. 
- Can be developed using a variety of technologies such as React, Angular, and Vue.js. 
- Facilitates the management of identities, channels, smart contracts, and transactions.
