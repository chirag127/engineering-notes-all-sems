### Basic crypto primitives for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

Cryptographic primitives are the building blocks of cryptography, the science of secure communication. In the context of blockchain, these primitives are used to secure transactions and ensure the integrity of data.

1. Hash Functions: Hash functions are mathematical algorithms that take an input and produce a fixed-length output, called a hash. Hash functions are used in blockchain to create a unique identifier for each block of data.

2. Digital Signatures: Digital signatures are used to authenticate the identity of a sender and to ensure the integrity of data. A digital signature is created by encrypting a hash of the data with the sender’s private key.

3. Public Key Cryptography: Public key cryptography is a system that uses two keys, a public key and a private key, to encrypt and decrypt data. In blockchain, public key cryptography is used to secure transactions and ensure the privacy of data.

4. Symmetric Key Cryptography: Symmetric key cryptography is a system that uses a single key to encrypt and decrypt data. In blockchain, symmetric key cryptography is used to secure the communication between nodes in the network.

5. Elliptic Curve Cryptography: Elliptic curve cryptography is a type of public key cryptography that uses mathematical algorithms based on elliptic curves to encrypt and decrypt data. In blockchain, elliptic curve cryptography is used to secure transactions and ensure the privacy of data.

These cryptographic primitives are essential for ensuring the security and privacy of data in a blockchain, and are used in various aspects of blockchain technology, including consensus algorithms, smart contracts, and data storage.
