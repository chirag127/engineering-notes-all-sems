### Hyperledger composer tool for the notes of the Unit 5 - Hyperledger Fabric (B) in the subject of Block chain Architecture Design

Hyperledger Composer is a development tool for building blockchain applications on the Hyperledger Fabric framework. It provides a high-level modeling language for defining the business network, assets, participants, and transactions, and then generates the underlying code and artifacts for deployment. 

Composer abstracts the underlying complexities of the blockchain technology, making it easier for developers to focus on the business logic of the application. It also provides a REST API for interacting with the blockchain network, allowing for easy integration with other systems. 

Composer also includes a playground for testing and prototyping the blockchain application, which can be useful for quickly iterating on the design and functionality. 

Overall, Hyperledger Composer is a valuable tool for streamlining the development process for blockchain applications on the Hyperledger Fabric platform.
