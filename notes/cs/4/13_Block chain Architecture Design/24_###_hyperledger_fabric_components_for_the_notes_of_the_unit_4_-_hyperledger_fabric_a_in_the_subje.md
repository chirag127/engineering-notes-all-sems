### Hyperledger fabric components for the notes of the Unit 4 - Hyperledger Fabric (A) in the subject of Block chain Architecture Design

Hyperledger Fabric components:
1. Peers: nodes that maintain a copy of the ledger and execute transactions.
2. Orderers: nodes responsible for ordering transactions into blocks.
3. Chaincode: smart contracts written in Go, defining the business logic of the network.
4. Ledger: distributed database of all transactions in the network.
5. Certificate Authority (CA): responsible for issuing digital certificates to network entities.
6. CouchDB: optional database for storing chaincode data.
7. CLI: command line interface for managing network components.
8. SDKs: software development kits for building applications on top of the network.
