
### Fabric SDK and Front End 

1. Hyperledger Fabric is a permissioned blockchain platform that is designed to support enterprise-level applications.
2. It is an open-source framework that provides a modular architecture for developing distributed ledger applications.
3. The Fabric SDK is a set of software development kits that provide an interface for developers to interact with the Fabric network.
4. It includes a set of APIs and tools that allow developers to create, deploy, and manage their applications on the Fabric network.
5. The Fabric SDK also includes a front end that provides a graphical user interface for developers to interact with the network.
6. The front end allows developers to create and manage transactions, view the status of the network, and monitor the performance of the applications.
7. The Fabric SDK also provides a set of tools for developers to test and debug their applications.
8. The Fabric SDK is designed to be extensible, allowing developers to add custom features and functionality to their applications.
