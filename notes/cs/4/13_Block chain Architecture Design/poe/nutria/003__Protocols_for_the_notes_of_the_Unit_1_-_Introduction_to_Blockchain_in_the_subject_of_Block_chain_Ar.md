
### Protocols for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

1. Blockchain is a distributed ledger technology that enables secure and immutable transactions to be made between two or more parties.
2. It is a decentralized system that is not controlled by a single entity and is instead maintained by a network of computers.
3. It is a secure system as all transactions are encrypted and stored in blocks that are linked together.
4. All transactions are verified by the network before they are added to the blockchain.
5. It is an immutable system as all transactions are recorded and stored permanently.
6. It is a transparent system as all transactions are visible to all users of the network.
7. It is a trustless system as it eliminates the need for a third party to verify transactions.
8. It is a secure system as all transactions are cryptographically signed and stored on the blockchain.
9. It is a resilient system as it is not vulnerable to single points of failure.
10. It is a scalable system as it can handle large volumes of transactions.
