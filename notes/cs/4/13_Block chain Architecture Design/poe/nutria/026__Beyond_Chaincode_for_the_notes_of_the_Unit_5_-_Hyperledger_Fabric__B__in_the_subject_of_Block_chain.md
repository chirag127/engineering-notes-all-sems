
### Beyond Chaincode for the Notes of Unit 5 - Hyperledger Fabric (B) in the Subject of Blockchain Architecture Design

1. Chaincode is the programming language used to write smart contracts in Hyperledger Fabric. It is based on the Go programming language. 
2. Chaincode is used to create and manage assets on the blockchain. It can also be used to define business logic and to enable transactions between multiple parties. 
3. Chaincode is written in a declarative style, meaning that it is not necessary to explicitly specify the order of operations. This makes it easier to write and maintain chaincode. 
4. Chaincode can be deployed to the Fabric network in two ways: using the Fabric SDK or using the command line interface. 
5. Chaincode can be tested before deployment using the Fabric test network. This is useful for debugging and ensuring that the chaincode is working as expected. 
6. Chaincode can be upgraded without disrupting the network. This is done by creating a new version of the chaincode and deploying it to the network. 
7. Chaincode is stored in the Fabric ledger and is replicated across all peers in the network. This ensures that all peers have the same version of the chaincode. 
8. Chaincode can be used to interact with external systems such as databases. This allows for the integration of existing systems with the blockchain. 
9. Chaincode can be used to define access control rules. This allows for the creation of permissioned networks where only certain entities have access to certain data. 
10. Chaincode can also be used to define consensus mechanisms. This allows for networks to come to agreement on the state of the ledger without relying on a single entity.
