
## Unit 8 - Use Case 3

* Use cases are a type of software requirements document that describe how a system should be used in specific scenarios.
* Use cases are used to identify the functionality of a system and the actors that interact with it.
* Use case diagrams provide a visual representation of the system and its actors.
* Use case scenarios are a series of steps that describe how the system should respond to an actor's actions.
* Use cases are often used in software development to ensure that all user requirements are met.
* Use cases can also be used to identify potential problems in the system before they arise.
