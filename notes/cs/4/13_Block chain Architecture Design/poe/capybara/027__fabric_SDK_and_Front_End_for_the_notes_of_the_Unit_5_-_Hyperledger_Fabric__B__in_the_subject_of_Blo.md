### Fabric SDK and Front End

Fabric SDK is a software development kit that allows developers to create applications that interact with the Hyperledger Fabric blockchain network. The Fabric SDK provides a set of APIs for developers to use in their applications.

Front End refers to the user interface of an application that users interact with. It is responsible for displaying data to the user and allowing them to interact with the application.

Here are some important points to keep in mind about the Fabric SDK and Front End:

- Fabric SDKs are available in multiple programming languages, including Java, Node.js, and Python. This allows developers to create applications in their preferred language.

- The Fabric SDK provides APIs to interact with the Fabric network, including creating channels, installing chaincode, and querying the ledger.

- The Front End of a Fabric application can be built using a variety of web development technologies, such as HTML, CSS, and JavaScript. This allows developers to create a user interface that is customized to their application's needs.

- The Front End can interact with the Fabric network using the APIs provided by the Fabric SDK. This allows the user to interact with the blockchain network through the application's user interface.

- The Fabric SDK and Front End are essential components for developing applications on the Hyperledger Fabric blockchain network. They provide developers with the tools needed to create customized applications that can interact with the blockchain network.
