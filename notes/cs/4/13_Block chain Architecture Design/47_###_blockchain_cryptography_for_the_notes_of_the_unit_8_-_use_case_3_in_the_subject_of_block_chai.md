### Blockchain Cryptography for the notes of the Unit 8 - Use case 3 in the subject of Block chain Architecture Design

Blockchain Cryptography refers to the use of cryptographic techniques to secure data within a blockchain. It is a key component of blockchain technology, providing secure and tamper-proof data storage and transmission.

1. Hash functions: Hash functions are used to generate a unique digital fingerprint of data, which can be used to verify the integrity of data stored in a blockchain.

2. Digital signatures: Digital signatures are used to verify the authenticity of transactions within a blockchain, ensuring that only authorized users can perform transactions.

3. Public-key cryptography: Public-key cryptography is used to encrypt data and ensure that only authorized users can access it.

4. Zero-knowledge proofs: Zero-knowledge proofs are used to verify the authenticity of data without revealing the underlying data itself.

5. Symmetric encryption: Symmetric encryption is used to encrypt data in a way that only authorized users can access it.

Blockchain cryptography is essential for ensuring the security and integrity of data stored in a blockchain, and for preventing unauthorized access and tampering. It is a critical component of blockchain technology and is used to secure transactions, protect sensitive data, and ensure the privacy of users.
