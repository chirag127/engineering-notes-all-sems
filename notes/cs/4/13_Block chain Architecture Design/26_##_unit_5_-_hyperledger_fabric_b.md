## Unit 5 - Hyperledger Fabric (B)

Hyperledger Fabric is a blockchain platform that provides a modular architecture for building and deploying blockchain solutions. It is part of the Hyperledger project, an open-source initiative hosted by the Linux Foundation. Fabric provides a secure and scalable platform for developing and deploying decentralized applications. Key features include:

1. Permissioned Network: Fabric allows for a permissioned network where only authorized participants can join and participate in transactions.

2. Modular Architecture: Fabric allows for modular design and implementation, making it easy to add or remove components as needed.

3. Plug-and-Play Components: Fabric provides a range of plug-and-play components, including consensus algorithms, membership services, and smart contract execution.

4. Scalability: Fabric supports high-performance and high-throughput transactions, making it suitable for large-scale applications.

5. Privacy and Confidentiality: Fabric provides a range of privacy and confidentiality features, including the ability to control access to data and transactions based on roles and permissions.

6. Interoperability: Fabric provides interoperability with other blockchain networks, allowing for the exchange of data and assets between different blockchain platforms.
