### Fabric SDK and Front End

1. Fabric SDK (Software Development Kit) provides a set of APIs that enable developers to interact with a Hyperledger Fabric blockchain network.
2. The SDKs are available in multiple programming languages, including Node.js, Java, and Go.
3. The SDKs allow developers to perform various tasks, such as creating and joining channels, installing and instantiating chaincodes, and invoking and querying chaincodes.
4. The SDKs also provide support for certificate management, allowing developers to enroll users and register their identities with the network.
5. The front end of a Hyperledger Fabric application typically interacts with the blockchain network through the SDK.
6. The front end can be developed using any web development framework, such as React or Angular.
7. The front end is responsible for presenting the user interface and handling user input, while the SDK handles communication with the blockchain network.
8. The front end and the SDK work together to provide a seamless user experience, allowing users to interact with the blockchain network in a user-friendly manner.
