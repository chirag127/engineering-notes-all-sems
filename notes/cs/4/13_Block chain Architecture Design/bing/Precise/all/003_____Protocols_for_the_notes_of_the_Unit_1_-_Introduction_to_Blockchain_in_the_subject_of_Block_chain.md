# Unit 1 - Introduction to Blockchain

## Protocols

1. **Blockchain protocol**: A blockchain protocol is a set of rules that dictate how data is exchanged and verified on a blockchain network. It defines the structure of the blocks, the consensus mechanism, and the security measures used to validate transactions.

2. **Consensus protocol**: A consensus protocol is a mechanism used by a blockchain network to reach agreement on the state of the distributed ledger. It ensures that all nodes on the network have the same information and that the information is accurate. Examples of consensus protocols include Proof of Work (PoW) and Proof of Stake (PoS).

3. **Cryptographic protocol**: A cryptographic protocol is a set of rules that define how data is encrypted and decrypted to ensure secure communication on a blockchain network. It includes the use of cryptographic algorithms, such as hash functions and digital signatures, to protect the integrity and confidentiality of data.

4. **Network protocol**: A network protocol is a set of rules that define how data is transmitted and received over a network. In the context of blockchain, network protocols are used to facilitate communication between nodes on the blockchain network.

5. **Smart contract protocol**: A smart contract protocol is a set of rules that define how smart contracts are created, executed, and enforced on a blockchain network. It includes the programming language used to write smart contracts, the conditions under which they are executed, and the mechanisms used to enforce their terms.

These are some of the key protocols used in blockchain architecture design. Understanding these protocols is essential for building and maintaining secure and efficient blockchain systems.
