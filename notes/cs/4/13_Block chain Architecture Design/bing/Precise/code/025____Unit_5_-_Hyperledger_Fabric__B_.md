## Unit 5 - Hyperledger Fabric (B)

Hyperledger Fabric is a blockchain framework implementation and one of the Hyperledger projects hosted by The Linux Foundation. It is designed to be a foundation for developing applications or solutions with a modular architecture.

Some key features of Hyperledger Fabric include:
- **Modularity:** Hyperledger Fabric has a modular architecture, allowing components such as consensus and membership services to be plug-and-play.
- **Scalability:** Hyperledger Fabric is designed to scale to a large number of nodes and to support high transaction throughput.
- **Privacy:** Hyperledger Fabric supports private transactions and confidential contracts.
- **Security:** Hyperledger Fabric has a robust security infrastructure, with support for certificate authorities, access control lists, and node identity management.

Hyperledger Fabric is a permissioned blockchain, meaning that participants must be authenticated and authorized to join the network. This is in contrast to public blockchains, where anyone can join and participate.

Hyperledger Fabric is written in Go and supports chaincode (smart contracts) written in Go, Java, and Node.js. It also has a REST API for interacting with the blockchain.

Hyperledger Fabric is used in a variety of industries, including finance, healthcare, and supply chain management. It is a popular choice for enterprise blockchain solutions due to its modularity, scalability, privacy, and security features.
