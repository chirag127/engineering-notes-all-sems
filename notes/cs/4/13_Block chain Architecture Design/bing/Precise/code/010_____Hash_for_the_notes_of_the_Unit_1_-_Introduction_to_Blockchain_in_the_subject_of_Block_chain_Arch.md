### Unit 1 - Introduction to Blockchain: Hash

- A hash is a function that converts an input of letters and numbers into an encrypted output of a fixed length.
- Hash functions are used in many applications, including cryptography, data indexing, and data integrity verification.
- In the context of blockchain, hash functions are used to secure the data stored in blocks.
- Each block in a blockchain contains a cryptographic hash of the previous block, along with the data of the current block.
- This creates a chain of blocks, where each block is linked to the previous one through its hash.
- The use of hash functions ensures that once data is recorded in a block, it cannot be altered without changing the hash of the block and all subsequent blocks.
- This provides a high level of security and immutability for the data stored in a blockchain.
- Commonly used hash functions in blockchain include SHA-256 (used in Bitcoin) and Keccak-256 (used in Ethereum).
