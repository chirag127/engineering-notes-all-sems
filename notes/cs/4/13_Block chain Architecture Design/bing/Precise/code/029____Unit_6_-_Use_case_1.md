## Unit 6 - Use case 1

1. A use case is a description of how a system interacts with its environment to achieve a specific goal.
2. Use cases are typically used in software development to capture the functional requirements of a system.
3. A use case diagram is a visual representation of the interactions between the system and its actors.
4. Actors are external entities that interact with the system, such as users or other systems.
5. Each use case represents a specific interaction between the system and its actors.
6. Use cases are typically written in a structured format, with a title, a brief description, and a list of steps.
7. The steps describe the sequence of interactions between the system and its actors to achieve the goal of the use case.
8. Use cases can be used to validate the system design and to ensure that all functional requirements are met.
9. Use cases can also be used to generate test cases for the system.
