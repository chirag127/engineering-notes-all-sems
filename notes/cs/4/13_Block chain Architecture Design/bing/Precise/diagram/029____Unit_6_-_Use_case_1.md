## Unit 6 - Use case 1

1. A use case is a description of how a system interacts with its environment to achieve a specific goal.
2. Use cases are typically used in software development to capture the functional requirements of a system.
3. A use case diagram is a visual representation of the interactions between the system and its actors (users or other systems).
4. Use case diagrams are used to model the behavior of a system and to define its scope.
5. Each use case in a use case diagram represents a specific sequence of actions that the system performs to achieve a specific goal.
6. Actors in a use case diagram represent the users or other systems that interact with the system being modeled.
7. Use case diagrams are typically used in the early stages of software development to define the scope of the system and to identify the functional requirements.
