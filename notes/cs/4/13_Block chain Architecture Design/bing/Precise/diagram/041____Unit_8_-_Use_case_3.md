## Unit 8 - Use Case 3

1. A use case is a description of how a system interacts with its environment to achieve a specific goal.
2. Use Case 3 in Unit 8 could refer to the third use case scenario described in the unit.
3. The specifics of Use Case 3 would depend on the context of the unit and the system being described.
4. Use cases are typically used in software development to define the functional requirements of a system.
5. They help to ensure that the system meets the needs of its users and stakeholders.
6. Use cases are often represented visually using diagrams to show the interactions between the system and its environment.
7. A use case diagram typically includes actors, use cases, and relationships between them.
8. Actors represent the roles of users or other systems that interact with the system being described.
9. Use cases represent the goals that the system can help the actors achieve.
10. Relationships between actors and use cases show how the actors initiate or participate in the use cases.
