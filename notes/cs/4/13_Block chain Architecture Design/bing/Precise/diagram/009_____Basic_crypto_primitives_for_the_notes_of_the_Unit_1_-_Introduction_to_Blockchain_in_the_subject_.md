### Basic Crypto Primitives

#### Unit 1 - Introduction to Blockchain

##### Subject: Blockchain Architecture Design

1. **Hash Functions:** A hash function is a mathematical function that takes an input of arbitrary length and produces a fixed-size output, often called a hash or digest. Hash functions are commonly used in cryptography to ensure data integrity and authentication.

2. **Digital Signatures:** A digital signature is a mathematical scheme for verifying the authenticity of digital messages or documents. It is used to ensure that a message has not been altered in transit and that it originated from the sender.

3. **Public Key Cryptography:** Public key cryptography, also known as asymmetric cryptography, is a cryptographic system that uses pairs of keys: public keys, which may be disseminated widely, and private keys, which are known only to the owner. The generation of such keys depends on cryptographic algorithms based on mathematical problems to produce one-way functions.

4. **Symmetric Key Cryptography:** Symmetric key cryptography, also known as secret key cryptography, is a cryptographic system that uses the same key for both encryption and decryption. The key must be kept secret from anyone who should not have access to the encrypted data.

5. **Merkle Trees:** A Merkle tree is a tree in which every leaf node is labelled with the hash of a data block, and every non-leaf node is labelled with the cryptographic hash of the labels of its child nodes. Merkle trees are used in blockchain to ensure data integrity and to allow for efficient data verification.

These are some of the basic crypto primitives that are essential for understanding the architecture and design of blockchain systems. They provide the foundation for the security and integrity of blockchain systems.
