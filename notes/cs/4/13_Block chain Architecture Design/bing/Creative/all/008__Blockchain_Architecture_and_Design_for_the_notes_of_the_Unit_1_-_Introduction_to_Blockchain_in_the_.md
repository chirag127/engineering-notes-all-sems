### Blockchain Architecture and Design for the notes of the Unit 1 - Introduction to Blockchain in the subject of Block chain Architecture Design

Blockchain is a technology that allows digital information to be distributed, rather than copied, in a secure and decentralized way. Blockchain consists of a chain of blocks, each containing specific information, that are linked together in a peer-to-peer network. Blockchain can be used for various applications, such as cryptocurrencies, record keeping, digital notary, and smart contracts.

The following points describe the main components and design principles of blockchain architecture:

- **Nodes within P2P network**: A node is a computer that participates in the blockchain network by storing, validating, and propagating blocks and transactions. Nodes can have different roles and responsibilities, such as full nodes, light nodes, miners, validators, etc. Nodes communicate with each other using a protocol that defines the rules and formats of the messages. A peer-to-peer network is a network where nodes can connect directly to each other without intermediaries or central authorities. This makes the network more resilient, scalable, and democratic.

- **Properties of block & genesis block**: A block is a data structure that contains a header and a body. The header contains metadata, such as the block number, the timestamp, the hash of the previous block, the hash of the block itself, and the nonce. The body contains a list of transactions that are validated and executed by the nodes. The hash of the block is a unique identifier that is derived from the block content using a cryptographic function. The nonce is a random number that is used to adjust the difficulty of finding a valid hash. The genesis block is the first block in the blockchain, which is hardcoded and does not have a previous block.

- **Transactions within the ledger**: A transaction is a data structure that represents an action or an event that occurs on the blockchain, such as transferring value, creating an asset, executing a contract, etc. A transaction contains inputs, outputs, and signatures. Inputs specify the source of the value or the asset, outputs specify the destination or the new state, and signatures prove the authenticity and the authorization of the transaction. Transactions are grouped together in blocks and form a ledger, which is a chronological and immutable record of all the transactions that have ever occurred on the blockchain.

- **The validation process - mining**: The validation process is the mechanism that ensures the consistency and the security of the blockchain. The validation process involves verifying the validity of the transactions and the blocks, and reaching a consensus among the nodes on the state of the ledger. Mining is a specific type of validation process that is used in some blockchain systems, such as Bitcoin and Ethereum. Mining involves finding a valid hash for a block that satisfies a certain difficulty level, which is adjusted periodically to maintain a steady block generation rate. Mining requires a lot of computational power and energy, and rewards the miners with newly created coins and transaction fees.

- **The “consensus” within a blockchain architecture**: Consensus is the agreement among the nodes on the state of the ledger and the order of the blocks. Consensus is essential for maintaining the integrity and the reliability of the blockchain. Consensus can be achieved using different algorithms and protocols, such as proof-of-work, proof-of-stake, proof-of-authority, Byzantine fault tolerance, etc. Consensus algorithms and protocols have different trade-offs in terms of security, scalability, performance, and decentralization.

- **Proof-of-work**: Proof-of-work is a consensus algorithm that requires the nodes to solve a hard mathematical problem, such as finding a valid hash for a block, in order to participate in the validation process. Proof-of-work is designed to prevent malicious nodes from tampering with the blockchain, as it would require a lot of computational resources and energy to do so. Proof-of-work is used in some of the most popular blockchain systems, such as Bitcoin and Ethereum. However, proof-of-work also has some drawbacks, such as high energy consumption, low scalability, and vulnerability to 51% attacks.
