## Unit 4 - Hyperledger Fabric (A)

Hyperledger Fabric is a modular blockchain framework that acts as a foundation for developing blockchain-based products, solutions, and applications using plug-and-play components that are aimed for use within private enterprises.

Some of the key features and benefits of Hyperledger Fabric are:

- It is an open source project from the Linux Foundation, and the de facto standard for enterprise blockchain platforms .
- It supports a variety of consensus mechanisms, such as Raft, Kafka, and Solo, that can be configured to suit different network requirements and scenarios.
- It allows for the creation of multiple channels, which are private subnets of communication between two or more network members, enabling data privacy and confidentiality.
- It enables the use of smart contracts, also known as chaincode, which are written in general-purpose programming languages, such as Go, Java, and Node.js, and can be deployed and executed on the network.
- It supports a flexible and scalable membership service, which can be integrated with existing identity management systems, such as LDAP or OAuth, to authenticate and authorize network participants.
- It provides a rich set of APIs and SDKs, which allow developers to interact with the network, invoke chaincode, query ledger data, and monitor network events.

Hyperledger Fabric is intended for developing applications or solutions with a modular architecture, that can satisfy a broad range of industry use cases, such as finance, banking, healthcare, IoT, supply chain, manufacturing, and technology .
