### Signature for the notes of the Unit 1 - Introduction to Blockchain

- A signature is a way of verifying the authenticity and integrity of a message or document.
- A signature can be digital or physical, depending on the medium and the context of the communication.
- A digital signature is a mathematical scheme that uses cryptography to create a unique and unforgeable identifier for a message or document.
- A digital signature consists of two parts: a private key and a public key.
- A private key is a secret and random string of bits that is used to generate the signature. A public key is a derived string of bits that is used to verify the signature. The public key can be shared with anyone, but the private key must be kept secret and secure.
- A digital signature is created by applying a hash function to the message or document, and then encrypting the hash value with the private key. The encrypted hash value is the signature.
- A digital signature is verified by applying the same hash function to the message or document, and then decrypting the signature with the public key. The decrypted hash value is compared with the computed hash value. If they match, the signature is valid and the message or document is authentic and intact. If they do not match, the signature is invalid and the message or document is tampered or forged.
- A digital signature provides three main properties: authentication, non-repudiation, and integrity.
  - Authentication means that the sender of the message or document can be identified and verified by the receiver, using the public key.
  - Non-repudiation means that the sender of the message or document cannot deny or dispute having sent it, as the signature is linked to the private key that only the sender possesses.
  - Integrity means that the message or document has not been altered or corrupted during the transmission or storage, as any change would result in a different hash value and an invalid signature.
- A digital signature is essential for blockchain, as it enables the creation and verification of transactions and blocks, which are the basic units of data in a blockchain network.
- A transaction is a record of an exchange of value or information between two or more parties, such as sending money, transferring assets, or executing a contract.
- A block is a collection of transactions that are validated and linked together by a hash value, forming a chain of blocks.
- A blockchain is a distributed ledger that stores and updates the history of transactions and blocks in a network of nodes, without the need for a central authority or intermediary.
- A blockchain network relies on consensus algorithms and cryptographic protocols to ensure the security, validity, and consistency of the data across the nodes.
- A digital signature is used to sign each transaction and block, ensuring that they are authorized by the sender, and that they are not modified or duplicated by anyone else.
