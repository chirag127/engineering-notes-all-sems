### Basic crypto primitives

Cryptographic primitives are the low-level algorithms that are used to build cryptographic protocols for a strong secured network. They are the basic building blocks of the cryptosystem. The programmers develop new cryptographic algorithms with the help of cryptographic primitives .

Some of the common cryptographic primitives are:

- **One-way hash functions**: These are mathematical functions that map an arbitrary-length input to a fixed-length output, such that it is easy to compute the output given the input, but hard to find the input given the output, or to find two inputs that map to the same output. One-way hash functions are used for integrity verification, digital signatures, proof-of-work, and hash pointers  . Examples of one-way hash functions are SHA-256, SHA-512, and Ethash.
- **Symmetric key cryptography**: This is a type of encryption where the same secret key is used to encrypt and decrypt the data. Symmetric key cryptography is used for confidentiality, authentication, and encryption  . Examples of symmetric key algorithms are AES, DES, and RC4.
- **Asymmetric key cryptography**: This is also known as public key cryptography. It is a type of encryption where two different keys are used: a public key that can be shared with anyone, and a private key that is kept secret. The public key can be used to encrypt data that can only be decrypted by the private key, or to verify signatures that can only be generated by the private key. Asymmetric key cryptography is used for confidentiality, authentication, digital signatures, and key exchange  . Examples of asymmetric key algorithms are RSA, ECC, and ElGamal.
- **Randomized algorithms**: These are algorithms that use random numbers or bits to produce different outputs for the same input. Randomized algorithms are used for encryption, digital signatures, zero-knowledge proofs, and secure multiparty computation . Examples of randomized algorithms are Blum-Blum-Shub, RSA-OAEP, and Fiat-Shamir.
