### Hashchain to Blockchain

- A hash chain is a successive application of a cryptographic hash function to a piece of data. A cryptographic hash function is a mathematical function that takes any input and produces a fixed-length output, called a hash or a digest, that is unique for each input. A hash function is also one-way, meaning that it is easy to compute the hash from the input, but hard to find the input from the hash. 
- A hash chain can be used to produce many one-time keys from a single key or password, or to record the chronology of data's existence. For example, a hash chain of length 4 can be generated by applying a hash function h four times to an input x, as follows: h4(x) = h(h(h(h(x)))). The hash chain can be used to authenticate x by revealing the hashes in reverse order, starting from h4(x) and ending with x. 
- A blockchain is a distributed ledger that consists of a chain of blocks, where each block contains a set of transactions and a reference to the previous block's hash. A blockchain uses a hash chain to link the blocks together and ensure the integrity and immutability of the ledger. A blockchain also uses a consensus mechanism, such as proof-of-work or proof-of-stake, to validate the transactions and prevent double-spending or malicious attacks. 
- A hash chain is similar to a blockchain, as they both utilize a cryptographic hash function for creating a link between two nodes. However, a hash chain is a simpler data structure that does not require a distributed network or a consensus protocol. A hash chain can be used for various applications, such as password protection, digital signatures, micropayments, or time-stamping. A blockchain is a more complex and sophisticated system that enables peer-to-peer transactions, smart contracts, and decentralized applications.
