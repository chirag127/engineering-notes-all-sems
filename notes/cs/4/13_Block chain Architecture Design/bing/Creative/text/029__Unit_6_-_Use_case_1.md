## Unit 6 - Use case 1

- Use case 1 is a scenario that describes how a system or a software application interacts with a user or another system to achieve a specific goal.
- Use case 1 consists of the following elements:
  - Actor: the user or the system that initiates the interaction with the system under consideration.
  - System: the system under consideration that provides the functionality or service to the actor.
  - Goal: the objective or the outcome that the actor wants to achieve by interacting with the system.
  - Precondition: the state or the condition that must be true before the interaction can start.
  - Postcondition: the state or the condition that must be true after the interaction is completed.
  - Main flow: the sequence of steps or actions that describe the normal and successful interaction between the actor and the system.
  - Alternative flow: the sequence of steps or actions that describe the alternative or exceptional interaction between the actor and the system in case of errors, failures, or deviations from the main flow.
  - Exception: the event or the situation that causes the alternative flow to be executed.
- Use case 1 can be represented in different ways, such as text, diagram, or table.
- Use case 1 can be used for different purposes, such as requirements analysis, design, testing, or documentation.
