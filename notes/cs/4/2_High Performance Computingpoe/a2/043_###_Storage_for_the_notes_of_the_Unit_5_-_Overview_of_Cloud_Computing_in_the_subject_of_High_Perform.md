### Storage for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

**Cloud Storage:**
- Data is stored in logically pooled storage resources.
- The physical resources are owned and managed by a cloud provider.
- Example: AWS S3, Azure Blob Storage, Google Cloud Storage.

**Advantages:**
- Inexpensive: Pay for what you use. No upfront capital expenditure on hardware and storage devices.
- Scalable: Can store any amount of data. Easily scale up or down as needed.
- Durable: Data is redundantly stored across multiple servers and data centers.
- Highly available: Data can be accessed anytime from anywhere.
- Managed service: The cloud provider handles software updates, security patches, hardware issues, etc.

**Disadvantages:**
- Vendor lock-in: Difficult to migrate data out of a cloud provider's infrastructure.
- Costs can add up: Need to regularly monitor usage and costs to avoid surprises.
- Less control: Limited control and visibility into the underlying infrastructure.
- Security concerns: Need to ensure data is encrypted and access is properly controlled.

**Use cases:**
- Backup and disaster recovery
- File sharing and collaboration
- Hosting website images/videos
- Streaming media
- Log storage
- Application data
