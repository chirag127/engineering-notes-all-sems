### Cluster Computing

- A cluster is a group of loosely or tightly coupled computers that work together so that in many respects they can be viewed as a single system.
- Cluster computing is a cost-effective way to provide high availability and scalability. Clustering is a popular technique for implementing parallel computing.
- Advantages:
    - Cost effectiveness: Cluster computing uses inexpensive commodity hardware to provide high performance.
    - Scalability: Clusters can grow incrementally by just adding more nodes. This enables clusters to scale to very large sizes.
    - High availability: Clusters use redundancy and failover techniques to prevent single points of failure and allow the system to continue operating even if some nodes fail.
- Disadvantages:
    - Complex software: Managing clusters and parallel applications requires complex software.
    - Non-deterministic performance: The performance of a cluster application may vary due to load imbalance, communication overhead, and other factors. This can make performance tuning more difficult.
- Examples: Computer clusters are used for scientific computing, web serving, database processing, and other applications. Popular cluster software includes MPI, PVM, and openMosix.
- Mnemonics:
    - Think of a cluster as a group of computers working as a team (Teamwork analogy)
    - Cost-effective, scalable, high-available, but complex to manage (Advantages and disadvantages)
