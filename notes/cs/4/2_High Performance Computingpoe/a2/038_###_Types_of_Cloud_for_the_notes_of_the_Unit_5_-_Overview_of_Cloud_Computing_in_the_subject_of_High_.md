### Types of Cloud

The major types of cloud computing are:

1. **Infrastructure as a Service (IaaS)**: It provides raw computing resources such as servers, storage, and networking. The users have full control over the infrastructure and can install their own OS and software. Eg: Amazon EC2, Google Compute Engine.

Mnemonic: IaaS provides the basic **I**nfrastructure blocks of computing.

2. **Platform as a Service (PaaS)**: It provides a computing platform along with the infrastructure. The users can develop, run and manage their applications on the cloud platform without managing the underlying infrastructure. Eg: Google App Engine, Microsoft Azure, OpenShift.

Mnemonic: With PaaS, you get the whole **P**latform to develop and run your applications.

3. **Software as a Service (SaaS)**: It provides software applications running on cloud infrastructure. The users can access the software through a web browser or API. The underlying infrastructure and platform are fully managed by the cloud provider. Eg: Google Suite, Microsoft Office 365, Salesforce, Dropbox, etc.

Mnemonic: With SaaS, you get the **S**oftware to use without installing or managing anything.

Advantages of cloud computing:

- Scalability and elasticity: Resources can be scaled up or down as per demand.
- Lower costs: No upfront capital expenditure on infrastructure. Pay as you go model.
- High availability and redundancy: Data is redundant and available 99.99% of the time.
- Easy access: Resources can be accessed through the internet from anywhere using any device.
- Automatic software updates: Software is always up-to-date with the latest features and security patches.

Disadvantages of cloud computing:

- Reliance on internet connectivity: Cannot access resources without internet connectivity.
- Vendor lock-in: Difficult to move applications and data between cloud providers.
- Security concerns: There is a risk of losing control over data security.
- Performance unpredictability: Performance can be impacted by issues with the provider or the network.
