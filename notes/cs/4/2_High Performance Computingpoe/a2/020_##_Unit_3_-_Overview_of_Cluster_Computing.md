## Unit 3 - Overview of Cluster Computing

- Cluster computing refers to the use of multiple computers connected through a network to solve a single complex computational problem. The computing tasks are divided and distributed among the computers in the cluster to obtain faster results by harnessing their combined processing power.
- The key components of a computing cluster are:
- Nodes: Individual computers that are connected to the network. They can be regular PCs, servers or high-performance computers.
- Network: The interconnection between the nodes that allows them to communicate and coordinate with each other. It can be a local area network or wide area network.
- Software: The programs that are used to divide, distribute and integrate the computing tasks between the nodes. This includes operating systems, libraries and APIs for message passing and synchronization.
- Applications: The software that runs on the cluster to solve large-scale computational problems in various domains like scientific computing, data processing, web services, etc.

**Advantages:**
- Scalability: Cluster size can be increased by adding more nodes to handle larger problems.
- Cost-effectiveness: Commodity hardware and networking equipment can be used to build clusters at lower costs.
- High performance: The combined processing power of multiple nodes leads to faster computations.
- Fault tolerance: The failure of a few nodes does not affect the entire system as the tasks can be reassigned to the functioning nodes.

**Disadvantages:**
- Complex to program and administer
- Challenging to balance loads and coordinate nodes
- Data transmission overhead between nodes can impact performance for some applications

**Applications:** Scientific simulations, weather forecasting, drug design, data mining, web search, etc.

**Mnemonics:**
- Cluster of computers for complex calculations
- Divide and conquer for better performance
- Scale up for more power, scale out for more nodes

**Learning tricks:**
- Understand the key components and how they work together
- Know the pros and cons of cluster computing
- Study examples of real-world applications to understand the concepts better
