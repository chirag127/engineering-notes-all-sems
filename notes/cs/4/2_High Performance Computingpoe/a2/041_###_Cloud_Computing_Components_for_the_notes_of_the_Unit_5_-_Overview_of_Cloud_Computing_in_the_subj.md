### Cloud Computing Components

The major components of cloud computing are:

1.  **Front end** - It is also known as the client component. It comprises of interfaces and applications that are needed to access the cloud computing platforms. *For example*, the user interfaces and APIs that are needed to access the services of cloud providers like AWS and Azure.
2.  **Back end** - It refers to the cloud infrastructure that provides on-demand resources like computing power, storage, databases, etc. *For example*, the servers, clusters, and data storage that are required to run the client applications and enable the services. It is maintained by the cloud service providers.
3.  **Cloud-based applications** - They are the software applications that are accessed via cloud computing platforms. *For example*, the apps like Gmail, Spotify, etc. that can be accessed via devices and the front end interfaces.

Some important points to remember:

- The major components of cloud computing are front end, back end, and cloud-based applications.
- The front end refers to the interfaces needed to access the cloud. The back end refers to the infrastructure maintained by the cloud service providers.
- The cloud-based applications are the software programs accessed via the cloud computing platforms.
- The elasticity and on-demand self-service nature of cloud computing enables the scaling up and down of resources.

The advantages of cloud computing include reduced costs, increased mobility, automatic software updates, increased collaboration, and high reliability. The disadvantages include vendor lock-in, technical issues, and security concerns.

Cloud computing has a wide range of applications in sectors like businesses, healthcare, education, finance, and more. The leading cloud providers are Amazon Web Services, Microsoft Azure, and Google Cloud Platform.
