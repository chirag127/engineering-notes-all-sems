### Application for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Cloud computing is the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers. Some of the key benefits of cloud computing are:

- Scalability: It is easy to scale cloud resources up or down as needs change. This makes cloud computing ideal for businesses with variable demands.
- Cost: There are no large upfront capital expenditures to build and maintain data centers and infrastructure. Resources can be paid for on-demand as needed.
- Automatic updates: Software and servers are automatically updated and patched by the cloud provider.
- Accessibility: Resources are available from anywhere via the Internet.

Some of the popular cloud providers are:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

The three main types of cloud computing services are:

- Infrastructure as a Service (IaaS): Provides virtualized computing resources like servers, storage, and networking. The user has control over the infrastructure but not the operating system or software.
- Platform as a Service (PaaS): Provides a computing platform with an operating system and development tools. The user can build and deploy applications without managing the underlying infrastructure.
- Software as a Service (SaaS): Provides access to applications that are run and managed by the cloud provider. The user can access the software from various devices via the Internet. Examples include G Suite, Office 365, and Salesforce.

Some advantages of cloud computing are lower costs, increased scalability and flexibility, automatic updates, high availability, and easy access to resources. Some potential disadvantages are vendor lock-in, security and privacy concerns, downtime, and technical issues.

Cloud computing has a wide range of applications including web hosting, storage, backup, collaboration, development and testing, and running business software. It enables businesses to be more agile and innovative by reducing IT costs and complexity.
