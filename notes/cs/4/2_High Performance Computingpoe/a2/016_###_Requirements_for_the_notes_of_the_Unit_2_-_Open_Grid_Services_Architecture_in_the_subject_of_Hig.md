### Requirements for the notes of the Unit 2 - Open Grid Services Architecture in the subject of High Performance Computing

1. Open Grid Services Architecture (OGSA) - OGSA is a service-oriented architecture for grid computing. It defines a set of components and rules for how those components interact to create a grid. OGSA allows distributed computing resources to be shared as services.
2. Service Oriented Architecture (SOA) - SOA is a style of software design where applications are built as a set of interoperable services. In SOA, services are loosely coupled, platform-independent components that can be located anywhere and can be reused to create new applications. OGSA uses the SOA approach.
3. Grid Services - Grid services are addressing, naming, and discovery mechanisms for services in a grid based on OGSA. They have standard interfaces and can be dynamically discovered and used. Some examples of grid services are resource management, data management, and security.
4. Web Services - OGSA uses web services as a primary mechanism for implementing grid services. Web services use standard Internet protocols and formats, allowing interoperability across platforms and languages.
5. Advantages - OGSA has several advantages including interoperability, platform independence, dynamic resource discovery, and reusability. Using web services and SOA allows OGSA to leverage existing standards and technologies.
6. Disadvantages - Some of the disadvantages of OGSA include complexity, performance overhead from using web services, and lack of widespread adoption. The OGSA standards are quite complex and the performance of web services can be lower than more customized implementations. OGSA has not been widely adopted, though some of its concepts have continued in other grid architecture frameworks.
