### Infrastructure for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

- Cloud computing infrastructure consists of hardware and software components that provide computing services over the internet. The key components are:
- **Data centers:** Physical facilities that house the computing resources. They consist of networking equipment, storage systems, servers, and supporting infrastructure like power supply and cooling systems.
- **Servers:** Powerful computers that run applications and services. They are clustered together in the data centers.
- **Networking equipment:** Routers, switches, firewalls, etc. that provide connectivity and enable communication between servers and between servers and users.
- **Storage systems:** Disk arrays and databases that provide storage capacity to store data and applications.
- **Software:** Operating systems, virtualization software, management software, and applications that enable the functionality of the cloud infrastructure.
- **APIs:** Interfaces that enable user access to the cloud resources and services.

Advantages:
- Scalability: Resources can be scaled up or down as required.
- Flexibility: Multiple users can access the resources on-demand.
- Reduced costs: No upfront investment in infrastructure and pay-as-you-go model.
- Automatic software updates: Software and security patches are automatically updated.
- High availability: Resources are distributed and redundant for high uptime.

Disadvantages:
- Reliance on internet connectivity.
- Vendor lock-in: Difficult to move data and applications between cloud providers.
- Performance variability: Can be impacted by network traffic and resource contention.
- Security concerns: Loss of control and visibility into the infrastructure.

Examples of cloud providers: AWS, Microsoft Azure, Google Cloud Platform.
Applications: Web services, mobile apps, data storage, computing intensive tasks, etc.
