### Platform for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

 #### IaaS:
 - Infrastructure as a Service
 - Providers like AWS, Azure, GCP provide virtualized computing resources like VMs, storage, network, etc.
 - Users have control over the infrastructure and can install their own OS and software
 - Scalable and flexible
 - Pay as you go model
 - Examples: AWS EC2, Azure VMs, GCP Compute Engine
 #### PaaS:
 - Platform as a Service
 - Providers offer a computing platform with an OS, programming languages, DBs, etc.
 - Users can deploy their applications without managing the underlying infrastructure
 - Scalable and efficient
 - Examples: AWS Elastic Beanstalk, Azure App Service, GCP App Engine
 #### SaaS:
 - Software as a Service
 - Providers offer applications/software as a service over the internet
 - Users can access the software from any device through a web browser or client
 - No installation or maintenance required
 - Scalable and cost effective
 - Examples: Gmail, Office 365, Salesforce, etc.

Advantages of cloud computing:
 - Scalability and elasticity
 - High availability and reliability
 - Reduced costs (pay as you go model)
 - Increased mobility (access from anywhere)
 - Automatic updates
 - Multi-tenancy and resource pooling

Disadvantages of cloud computing:
 - vendor lock-in
 - loss of control over data
 - dependence on internet connectivity
 - security and privacy concerns
 - migration challenges

Applications of cloud computing:
 - Web applications
 - Mobile backend
 - Data storage and analytics
 - IoT backend
 - High performance computing
 - etc.
