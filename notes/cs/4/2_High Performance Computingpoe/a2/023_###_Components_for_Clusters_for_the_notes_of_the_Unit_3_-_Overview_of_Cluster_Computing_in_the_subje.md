### Components for Clusters for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

The major components of a cluster are:

1. Nodes: Individual computers that act as servers are called nodes. They are interconnected to work together as a single system. Each node has its own CPU, memory, and storage.
2. Network interconnect: The nodes are connected through a fast network interconnect like Ethernet or Infiniband. The network interconnect allows the nodes to communicate and collaborate with each other. A fast network is essential for clusters to work efficiently.
3. System software: Cluster management software is installed on each node to coordinate between the nodes and manage the cluster as a single system. The system software allows allocation of tasks, file sharing, coordination between processing at nodes, etc.
4. Job scheduler: The job scheduler allocates user jobs to individual nodes in the cluster. It schedules the jobs based on the availability of nodes and other resources. The job scheduler balances the workloads across the cluster for optimal resource utilization and performance.

Some key points to remember:

- Cluster computing connects individual computers to work as a single system.
- Nodes are the individual computers with CPUs, memory, and storage.
- A fast network interconnect like Ethernet or Infiniband connects the nodes.
- Cluster management software is installed on each node to coordinate the cluster.
- A job scheduler allocates user jobs to nodes and balances workloads across the cluster.

Cluster computing is useful for compute-intensive tasks like scientific simulations, machine learning, data processing, etc. that can be parallelized across multiple nodes. The major advantages are cost-effectiveness, flexibility, and scalability. The disadvantages are complexity in setup and management and challenges in parallelizing applications across nodes.
