### Services for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

The major services provided by cloud computing providers are:

1. Infrastructure as a Service (IaaS): Provides access to computing resources like servers, storage, and networking. The user has full control over the infrastructure and can install their own software. Eg: Amazon EC2, Google Compute Engine.

2. Platform as a Service (PaaS): Provides a computing platform with an operating system and set of software development tools. The user can develop and run their applications on the provider's infrastructure. Eg: Google App Engine, Microsoft Azure.

3. Software as a Service (SaaS): Provides access to application software and databases. The users can access and use the applications over the Internet. Eg: Google Apps, Microsoft Office 365, Salesforce.

Advantages:

- Low upfront costs and low maintenance since infrastructure is provided by the cloud provider.
- High scalability and availability. Resources can be scaled up or down as required.
- Accessibility from anywhere using Internet.

Disadvantages:

- Reliance on Internet connectivity. No access to apps and data if no connectivity.
- Vendor lock-in. Difficult to move applications and data to another cloud provider.
- Security and privacy concerns with data being stored externally.

Applications: Web-based email, storage, streaming media, business applications, etc.
