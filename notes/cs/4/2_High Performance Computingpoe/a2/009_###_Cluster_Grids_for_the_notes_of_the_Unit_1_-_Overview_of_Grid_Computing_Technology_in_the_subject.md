### Cluster Grids

- Cluster Grids are a type of grid computing which utilizes multiple computers (nodes) combined together to act as a single system to provide more computational power.
- The nodes are connected through a fast local area network (LAN) which allows them to communicate and coordinate with each other.
- Each node acts as an independent system with its own CPU, memory, storage, and network interface. The clustering software runs on top of the nodes to make the cluster of computers act as a single system.
- The key advantages of cluster grids are -
    - Increased computational power - The combined computational resources of multiple computers provide more processing power than a single system. This is useful for compute-intensive tasks like simulations, data mining, machine learning, etc.
    - High availability - If one node fails, the jobs can be reassigned to other nodes. This increases the availability and redundancy of the system.
    - Scalability - More nodes can be easily added to the cluster to scale the computational power as per the requirements.
    - Cost-effectiveness - Using commodity hardware and open-source software, cluster grids can be built cost-effectively.
- However, the challenges with cluster grids are -
    - Complex software and maintenance - The clustering software adds complexity and the cluster needs to be properly maintained, monitored, and managed.
    - Data management - It can be difficult to manage data across the distributed storage of multiple nodes. Proper data distribution and replication strategies need to be employed.
    - Communications overhead - Though the nodes are connected through a fast LAN, the inter-node communications can become a bottleneck and add latency when a large number of nodes are clustered.
