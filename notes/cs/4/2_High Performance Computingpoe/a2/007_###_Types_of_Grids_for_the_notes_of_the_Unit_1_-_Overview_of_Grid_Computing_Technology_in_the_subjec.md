### Types of Grids for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

The major types of Grids are:

1. Public Grids: These are open Grids that allow anyone to access the resources by providing credentials. The resources are donated and access is based on availability and policies. Example: SETI@home project which analyzes radio telescope data to search for extraterrestrial intelligence.
2. Private Grids: These are closed Grids setup within an organization. The resources are managed and accessed within the organization. Example: Grids setup by companies like IBM, Microsoft, etc. for internal usage.
3. Hybrid Grids: These combine both public and private Grids. The private Grids can access public Grid resources and vice-versa based on policies and requirements. This increases resource availability and utilization.

Advantages of Grid Computing:

- Harness underutilized resources and increase resource utilization.
- Scalability and Elasticity - Resources can be easily added or removed.
- Economical - Uses existing resources efficiently.
- Increased computational power - Solve larger problems by combining resources.
- Data Locality - Process data near resources containing the data for efficiency.

Disadvantages of Grid Computing:

- Complex architecture and management.
- Heterogeneous systems can introduce compatibility issues.
- Security concerns with resource sharing.
- Reliability can be impacted with multiple systems and resources.
- Performance can be variable depending on load and resource availability.
