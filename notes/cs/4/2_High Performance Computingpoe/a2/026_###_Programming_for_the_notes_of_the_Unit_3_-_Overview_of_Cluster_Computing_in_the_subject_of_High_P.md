### Programming for the notes of the Unit 3 - Overview of Cluster Computing in the subject of High Performance Computing

Cluster computing refers to the use of multiple computers, connected through a network, to solve a single problem. This approach is commonly used to provide high performance computing power at a lower cost than a single powerful computer. Some key points about cluster computing are:

- Multiple cheaper computers are connected together to act as a single system.
- The problem is divided into smaller parts that can be solved concurrently on the individual computers.
- Efficient communication between the computers is required to coordinate and combine the solutions to the sub-problems.
- Programming models like Message Passing Interface (MPI) are used to facilitate communication between the computers.
- Speedup is limited by the efficiency of dividing the problem and communication overhead.
- Cluster computing is cost-effective as commodity hardware can be used. However, maintenance and administration of the cluster can be challenging.

Some examples of applications of cluster computing are:

- Scientific simulations (e.g. weather forecasting, molecular dynamics)
- Web servers (e.g. handling high loads)
- Parallel processing (e.g. data mining on large datasets)

Advantages:

- Cost-effective - uses commodity hardware
- Scalable - can add more computers to increase performance
- Fault tolerance - if one computer fails, others can continue working

Disadvantages:

- Complex to program and administer
- Speedup limited by communication overhead and problem division efficiency
- Prone to faults which can be difficult to debug
