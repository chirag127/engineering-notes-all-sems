## Unit 5 - Overview of Cloud Computing

Cloud computing refers to the delivery of computing services over the Internet. Instead of companies hosting software, data, and computing resources on their own in-house servers, all of that is hosted by a cloud provider in their data centers. Some of the key characteristics of cloud computing are:

- On-demand self-service: Users can provision computing resources like servers, storage, applications, etc. as needed automatically without requiring human interaction with the cloud provider.
- Broad network access: Services are available over the network and accessed through standard mechanisms like mobile apps, browsers, etc.
- Resource pooling: Resources are pooled to serve multiple consumers using a multi-tenant model. Physical and virtual resources are assigned and reassigned according to consumer demand.
- Rapid elasticity: Resources can be elastically scaled up or down as needed.
- Measured service: Cloud services are automatically controlled and optimized using a metering capability. Resource usage can be monitored, controlled, and reported to provide transparency to the consumer.

The key benefits of cloud computing are:

- Increased agility and scalability: It is easy to scale resources up or down as needed and deploy applications faster.
- Lower upfront costs: No large capital expenditures on hardware and software licenses. Pay as you go model.
- Automatic updates: Software and security patches are automatically updated by the cloud provider.
- High availability: Resources are redundant and fault-tolerant, so there is a lower risk of downtime.
- Global reach: Services can reach a wider geographic area and support customers around the world.

The main cloud service models are:

- Infrastructure as a Service (IaaS): Provides access to computing resources like servers, storage, and networking. The consumer has control over the operating system, storage, and deployed applications.
- Platform as a Service (PaaS): Provides a computing platform with an operating system, programming language execution environment, database, and web server. The consumer can deploy applications onto the platform without managing the underlying infrastructure.
- Software as a Service (SaaS): Provides access to cloud-based software applications. The consumer does not manage the underlying infrastructure or platform that the application runs on. Examples include G Suite, Office 365, Salesforce, etc.

The key cloud providers are:

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)
