### Cloud Computing Components for the notes of the Unit 5 - Overview of Cloud Computing in the subject of High Performance Computing

Cloud computing is a technology that has gained immense popularity in recent years due to its flexibility, scalability, and cost-effectiveness. It comprises several components that work together to deliver services to users over the internet. In this section, we will discuss the major components of cloud computing.

1. **Hardware Infrastructure:** This component includes physical resources such as servers, storage devices, and networking devices that are used to provide cloud services. The hardware infrastructure can be owned by the cloud provider or can be leased from a third-party vendor.

2. **Virtualization:** Virtualization is the process of creating a virtual version of a resource, such as a server, operating system, storage device, or network. The virtualized resources can be dynamically allocated and de-allocated as per the user's requirements.

3. **Cloud Management Platform (CMP):** CMP is a software platform that provides a unified interface to manage and control the cloud infrastructure. It automates the deployment, scaling, and monitoring of cloud services.

4. **Application Programming Interfaces (APIs):** APIs are a set of protocols and tools that enable developers to build applications that can interact with cloud services. APIs provide a standard way of accessing cloud services, which makes it easier for developers to build applications.

5. **Cloud Storage:** Cloud storage is a service that allows users to store and retrieve data over the internet. It provides a scalable and cost-effective way of storing data.

6. **Cloud Computing Models:** Cloud computing models are the different ways in which cloud services are delivered to users. The three main cloud computing models are:

    - **Infrastructure as a Service (IaaS):** IaaS provides users with access to virtualized computing resources such as servers, storage, and networking. Users can install and operate their own operating systems and applications on the virtualized resources.

    - **Platform as a Service (PaaS):** PaaS provides users with a platform to develop, run, and manage their applications without the complexity of building and maintaining the infrastructure.

    - **Software as a Service (SaaS):** SaaS provides users with access to software applications over the internet. Users do not need to install or maintain the software, as it is hosted and managed by the cloud provider.

Mnemonics and learning tricks:

- For remembering the three cloud computing models, you can use the acronym 'IPS' where I stands for Infrastructure as a Service, P stands for Platform as a Service, and S stands for Software as a Service.
- To remember the components of cloud computing, you can use the acronym 'HAVICS' where H stands for Hardware Infrastructure, A stands for APIs, V stands for Virtualization, I stands for Infrastructure as a Service, C stands for Cloud Management Platform, and S stands for Cloud Storage.

In conclusion, understanding the components of cloud computing is essential for anyone looking to deploy or use cloud services. It is important to remember that cloud computing is a rapidly evolving technology, and new components may be added in the future.
