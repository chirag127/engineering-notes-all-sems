### High Performance Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

Grid Computing Technology is a distributed computing architecture that aims to provide access to a shared pool of resources, such as computational power and storage, over a network. High Performance Computing (HPC) is a key component of Grid Computing, which enables the processing of large sets of data and complex calculations at faster speeds. - Characteristics of Grid Computing
- Comparison with other distributed computing architectures

- Grid services - functions provided by Grid middleware

#### 3. Grid Applications

- Benefits of Grid Computing for scientific research and industry
- Examples of Grid Computing applications

- Characteristics of HPC systems
