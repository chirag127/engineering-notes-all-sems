### Cyber Infrastructure for the Notes of Unit 5 - Overview of Cloud Computing in the Subject of High Performance Computing

Cyber infrastructure refers to the hardware, software, and other computing resources that are used to support research and education in various fields, including high-performance computing. In the context of cloud computing, cyber infrastructure is essential for providing the necessary resources and services to users over the internet.

Here are some important concepts related to cyber infrastructure in cloud computing:

1. Virtualization: Virtualization is the process of creating a virtual version of something, such as a server, operating system, storage device, or network resource. In cloud computing, virtualization is used to create virtual machines (VMs) that can run multiple operating systems and applications on a single physical server.

2. Scalability: Scalability refers to the ability of a system to handle a growing amount of work or traffic without a significant decrease in performance. Cloud computing offers scalability by providing on-demand access to computing resources, allowing users to quickly scale up or down as needed.

3. Resilience: Resilience refers to the ability of a system to recover from failures or disruptions without significant impact on its overall performance. Cloud computing offers resilience by distributing data and services across multiple servers and data centers, so that if one server or data center goes down, the system can continue to operate.

4. Security: Security is a critical aspect of cyber infrastructure in cloud computing, as users need to be confident that their data and applications are protected from unauthorized access or theft. Cloud computing providers typically offer a range of security measures, such as firewalls, encryption, and identity management, to ensure that users' data is secure.

5. Cost: Cost is an important consideration when using cloud computing, as users typically pay for the resources and services they consume on a pay-as-you-go basis. Cloud computing can be cost-effective for users who need to scale up or down quickly, as they only pay for the resources they use.

Mnemonic: VRSCR (Virtualization, Resilience, Scalability, Cost, Security)

In summary, cyber infrastructure is a critical component of cloud computing, providing the necessary resources and services to support high-performance computing. Understanding the concepts of virtualization, scalability, resilience, security, and cost can help users make informed decisions about how to use cloud computing effectively.
