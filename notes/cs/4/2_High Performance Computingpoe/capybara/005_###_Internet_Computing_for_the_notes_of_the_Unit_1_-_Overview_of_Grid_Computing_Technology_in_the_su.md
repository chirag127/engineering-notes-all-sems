### Internet Computing for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

Internet computing is the process of using the internet to access and share resources and services remotely. Grid computing is a type of internet computing that allows multiple computers to work together to solve complex problems. In this unit, we will be discussing the overview of grid computing technology in the subject of High Performance Computing. Here are some important points to remember:

1. Grid computing is a distributed computing model that allows multiple computers to work together to solve large-scale computing problems.

2. The main components of grid computing are resources (such as computers, storage devices, and networks), middleware (software that manages the resources), and applications (software that uses the resources to solve problems).

3. Grid computing can be used in a variety of fields, including scientific research, engineering, finance, and entertainment.

4. Grid computing has several advantages, such as increased computing power, improved efficiency, and reduced costs. However, it also has some disadvantages, such as security risks and complexity.

5. Grid computing can be implemented using various technologies, such as Globus Toolkit, Condor, and BOINC.

6. Grid computing has several applications, such as weather forecasting, drug discovery, and financial modeling.

7. Some of the key challenges in grid computing include resource discovery, data management, security, and scalability.

8. To overcome these challenges, researchers are developing new technologies such as cloud computing, which complements grid computing by providing on-demand access to computing resources.
