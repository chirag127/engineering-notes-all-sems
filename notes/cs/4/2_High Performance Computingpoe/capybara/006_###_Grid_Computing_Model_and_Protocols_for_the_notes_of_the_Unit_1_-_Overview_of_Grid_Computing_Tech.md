### Grid Computing Model and Protocols for the notes of the Unit 1 - Overview of Grid Computing Technology in the subject of High Performance Computing

Grid Computing is a distributed computing model that allows multiple computers to work together to solve a common problem. In this model, resources such as CPU time, storage, and applications are shared across different computers connected over a network. The Grid Computing model comprises the following key components:

1. **Resource Broker** - It is responsible for managing and scheduling jobs across different computers. It keeps track of available resources and assigns jobs to the most suitable computer based on the job's requirements.

2. **Resource Manager** - It manages the resources available on a particular computer. It ensures that the resources are utilized efficiently and are available to the Resource Broker for scheduling.

3. **Grid Middleware** - It provides the necessary software infrastructure for communication and coordination between different computers. It includes protocols for authentication, data transfer, job scheduling, and monitoring.

4. **Grid Services** - These are the services that are provided by the Grid Middleware. These services include file storage, authentication, job scheduling, and monitoring.

The Grid Computing model uses various protocols for communication and coordination between different computers. Some of the commonly used protocols are:

1. **GridFTP** - It is a protocol used for reliable and efficient file transfer between different computers.

2. **Globus Toolkit** - It is a set of software tools and protocols for building Grid Computing applications. It provides services such as authentication, resource management, and job scheduling.

3. **Simple API for Grid Applications (SAGA)** - It is a high-level API for building Grid Computing applications. It provides a simple and consistent interface to access different Grid services.

4. **Open Grid Services Architecture (OGSA)** - It is a set of standards and protocols for building Grid Computing applications. It provides a framework for interoperability between different Grid services.

Mnemonics and Learning Tricks:

- Remember the 4 key components of the Grid Computing model using the acronym RRGSG, which stands for Resource Broker, Resource Manager, Grid Middleware, and Grid Services.
- To remember the commonly used protocols, use the mnemonic "GGOS" which stands for GridFTP, Globus Toolkit, Open Grid Services Architecture, and SAGA.
