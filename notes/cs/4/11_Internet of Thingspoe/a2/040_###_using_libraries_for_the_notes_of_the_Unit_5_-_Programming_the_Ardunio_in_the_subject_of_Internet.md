### Using libraries for the notes of the Unit 5 - Programming the Arduino in the subject of Internet of Things

- Libraries provide pre-written code that can be used to simplify programming tasks. Using libraries reduces the need to re-invent the wheel and saves time.
- Some advantages of using libraries are:
    - They are tested and debugged, so they are more reliable and less prone to errors.
    - They save time as functionality is readily available instead of having to code it from scratch.
    - They make code more readable and easier to understand as they have descriptive function and variable names.
- Some disadvantages are:
    - There is a learning curve to understand how the library works and how to implement it.
    - The library may not be optimized for specific requirements and extra coding may be needed.
    - Dependency on third-party libraries - if the library is not maintained or is discontinued, it may affect existing programs that depend on it.
- Some commonly used Arduino libraries are:
    - Servo - for controlling servo motors
    - Ethernet - for connecting to the internet
    - SD - for reading and writing to SD cards
    - LiquidCrystal - for controlling LCD displays
    - Wire and I2C - for I2C communication protocol
    - SPI - for SPI communication protocol
- To use a library, it first needs to be imported with an `#include` statement. Then functions, variables, etc. from the library can be accessed. Examples and documentation help in understanding the functionality and usage of the library.
- Mnemonics:
    - "Libs reduce code bulk" - to remember advantages of using libraries
    - "Learn library learn curve" - to remember disadvantages of learning to use a new library
