## Unit 3 - Embedded Platforms for IoT

Embedded platforms are microcontroller or microprocessor based systems that are designed to perform a specific task. They are the core components that power IoT devices and systems. Some key points about embedded platforms for IoT are:

- They are resource constrained systems with limited CPU, memory and storage. Hence, IoT software and applications are designed to be memory and energy efficient.
- They operate in real-time and the software is tightly coupled with the underlying hardware. This requires a deep understanding of the hardware components and their interactions.
- They are customized for the target use case. The hardware and software components are optimized for a specific application such as a medical device or an industrial controller.
- Popular embedded platforms for IoT include Arduino, Raspberry Pi, ESP32, etc. They provide customizable hardware and software options for a range of IoT applications.
- Programming languages for embedded platforms include C/C++, Python, JavaScript, etc. The choice of language depends on the capabilities and intended use of the platform.
- Some key characteristics of embedded software are resource efficiency, real-time constraints, robustness, security and memory safety. Default security protections may be lacking in some platforms and additional measures are required to build secure IoT systems.
