### Raspberry pi for the notes of the Unit 3 - Embedded Platforms for IoT

Raspberry Pi is a small, affordable, and capable mini-computer that can be used to learn programming and build digital devices. It is one of the most popular boards for developing IoT applications and prototyping embedded systems.

**Key Points:**

- Raspberry Pi is a credit-card sized computer that can be connected to a keyboard, mouse, and monitor to use as a desktop computer.
- It runs on Linux operating system and has a Broadcom BCM2835 system on a chip processor with 512MB of RAM.
- It has GPIO pins that can be programmed to interface sensors and actuators to build IoT projects.
- It is inexpensive, portable, and can be powered via a USB port or a smartphone charger.
- It supports various programming languages like Python, C/C++, Java, Scratch, etc. to develop applications.
- It has a huge developer community and resources available to build a wide range of projects.

**Applications:**

- IoT projects like home automation, weather station, smart mirror, etc.
- Learning programming and electronics.
- Building robots.
- Creating multimedia systems.
- Turning into a server to host websites.
- And many more DIY electronics projects.

**Advantages:**

- Inexpensive and easily available.
- Large community and resources for learning and developing projects.
- Supports various programming languages.
- Has GPIO pins to connect external circuits and devices.
- Small size and low power consumption.

**Disadvantages:**

- Limited processing power and memory compared to other computers.
- The small size can make it difficult to connect some components or devices.
- Requires additional hardware like breadboards, sensors, and actuators to build projects.

**Mnemonics:**

- Raspberry Pi is a mini-computer the size of a credit card.
- It runs Linux and has GPIO pins to connect circuits.
- Inexpensive, popular, and great for learning programming and IoT projects.
