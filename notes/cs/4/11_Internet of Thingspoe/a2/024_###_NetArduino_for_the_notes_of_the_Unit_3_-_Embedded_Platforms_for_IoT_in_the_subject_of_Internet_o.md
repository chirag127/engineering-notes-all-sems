### NetArduino for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

NetArduino is an open source hardware board designed for Internet of Things (IoT) projects. It is based on Atmel AVR microcontrollers and provides built-in Ethernet connectivity.

Some key points about NetArduino:

- It is Arduino compatible and can be programmed using the Arduino IDE. So, the large Arduino community and resources can be leveraged.
- It has on-board Ethernet which eliminates the need for additional shields. This reduces complexity and cost.
- It comes in multiple variations with different processors and memory to suit various needs. For e.g. Netduino Go has a 32-bit ARM Cortex M3 processor while Netduino Mini has a 8-bit AVR processor.
- The Ethernet port can be used to connect to local networks or the internet. This enables applications like data logging, home automation, etc.
- It has SPI, I2C, UART interfaces to connect various sensors and peripherals.
- The open source hardware and software along with a supportive community make it easy to learn and build projects.

Some applications of NetArduino:

- Home automation like controlling lights, appliances, monitoring sensors, etc.
- IoT prototypes and projects like weather stations, remote monitoring systems, etc.
- Educational platforms to learn embedded system and networking concepts.
- Rapid prototyping of IoT devices.

Advantages:

- Inexpensive and open source.
- Easy to get started due to Arduino compatibility.
- Has on-board Ethernet.

Disadvantages:

- Limited processing power and memory compared to other boards.
- Does not have built-in wireless connectivity. A separate shield may be required for that.

**Mnemonics:**

- NetArduino = Arduino compatible + On-board Ethernet
- For IoT and learning embedded networks on budget
