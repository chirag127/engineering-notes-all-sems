
### Sensor Deployment & Node Discovery for the Notes of Unit 4 - Network & Communication Aspects in IoT in the Subject of Internet of Things

* Sensor deployment is a key concept in the Internet of Things (IoT). It involves the placement of sensors in physical locations to collect data and send it to a central hub for analysis.
* Node discovery is the process of identifying and connecting to other nodes on a network. This is important in IoT networks, as nodes need to be able to communicate with each other in order to exchange data.
* Sensor deployment and node discovery can be used to monitor physical environments, such as temperature, humidity, light, sound, and motion.
* Sensors can also be used to detect the presence of people, animals, or objects in a given area.
* Node discovery can be used to create a mesh network, which is a network of interconnected nodes that can communicate with each other without the need for a central hub.
* Advantages of sensor deployment and node discovery include increased efficiency, scalability, and cost savings.
* Disadvantages of sensor deployment and node discovery include potential security risks, privacy concerns, and the complexity of the technology.
* Mnemonics and learning tricks for sensor deployment and node discovery include using diagrams to visualize the network and using acronyms to remember the steps involved in the process.
