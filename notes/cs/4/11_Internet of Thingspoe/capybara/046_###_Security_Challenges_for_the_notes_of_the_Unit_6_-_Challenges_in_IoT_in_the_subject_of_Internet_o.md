### Security Challenges for the notes of the Unit 6 - Challenges in IoT in the subject of Internet of Things

Internet of Things (IoT) is a network of devices that are connected to each other and can share data seamlessly. However, the widespread adoption of IoT has also brought with it several security challenges that need to be addressed. In this unit, we will be discussing some of the security challenges that IoT faces, and how we can mitigate them.

Here are some of the security challenges that IoT faces:

1. **Privacy and Data Protection:** IoT devices collect and store large amounts of data, which may include personal information. This data needs to be protected from unauthorized access or misuse.

2. **Device Authentication and Authorization:** IoT devices need to be authenticated and authorized before they can access the network. This helps to prevent unauthorized devices from accessing the network.

3. **Data Integrity and Confidentiality:** IoT devices need to ensure that the data they collect and transmit is both confidential and accurate. This can be achieved through encryption and other security measures.

4. **Network Security:** IoT devices are connected to the internet, which makes them vulnerable to external attacks. Network security measures need to be in place to prevent unauthorized access to the network.

5. **Physical Security:** IoT devices are often located in public places, making them vulnerable to physical attacks. Physical security measures need to be in place to prevent theft or damage to the devices.

6. **Firmware and Software Security:** IoT devices run on firmware and software that can be vulnerable to attacks. Firmware and software security measures need to be in place to prevent unauthorized access or tampering.

Mnemonics and Learning Tricks:

- Mnemonic: "PDAN-FP" - Privacy, Device Authentication, Network security, Firmware and software security, Physical security. This acronym can help you remember the main security challenges that IoT faces.

- Learning Trick: You can create flashcards with different security scenarios and test your knowledge on how to mitigate them. This will help you remember the different security challenges and how they can be addressed.
