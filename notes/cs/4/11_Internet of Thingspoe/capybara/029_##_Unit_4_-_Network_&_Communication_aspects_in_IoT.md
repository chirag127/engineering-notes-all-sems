## Unit 4 - Network & Communication aspects in IoT

Internet of Things (IoT) is all about connecting devices and sensors to the internet to gather, send, and analyze data. This requires an efficient network and communication system to facilitate the transfer of data between devices and servers. In this unit, we will discuss the various aspects of network and communication in IoT.

### Network Topologies

Network topology refers to the arrangement of nodes and links in a network. In IoT, there are three types of network topologies:

- Star Topology: In this topology, each device is connected to a central hub or switch. The hub acts as a mediator to transfer data between devices.

- Mesh Topology: In this topology, each device is connected to multiple devices, forming a mesh-like structure. This ensures redundancy and fault tolerance.

- Bus Topology: In this topology, all devices are connected to a single bus or backbone, which transfers data between devices.

### Communication Protocols

IoT devices use different communication protocols to transfer data. Some commonly used protocols are:

- MQTT (Message Queuing Telemetry Transport): A lightweight protocol that can be used in low-bandwidth and high-latency networks. It is widely used in IoT applications.

- CoAP (Constrained Application Protocol): A protocol designed for resource-constrained devices in low-power and lossy networks. It is used in smart home and industrial automation applications.

- HTTP (Hypertext Transfer Protocol): A protocol used in web applications to transfer data between servers and clients. It is also used in IoT applications for data transfer.

### Wireless Technologies

Wireless technologies play a crucial role in IoT communication. Some commonly used wireless technologies are:

- Wi-Fi: A wireless technology that uses radio waves to transfer data between devices. It is widely used in homes and offices.

- Bluetooth: A short-range wireless technology that is used to connect devices in a personal area network (PAN). It is used in smart home and wearable applications.

- Zigbee: A low-power wireless technology that is used in industrial automation and smart home applications.

### Security Issues

IoT devices are vulnerable to security threats such as hacking, data theft, and malware attacks. To ensure the security of IoT networks, some measures are:

- Encryption: Data should be encrypted during transmission to prevent data theft.

- Authentication: Devices should be authenticated before joining the network to prevent unauthorized access.

- Access Control: Access to the network should be restricted to authorized users only.

### Mnemonics and Learning Tricks

To remember the different network topologies, you can use the acronym SMB (Star, Mesh, Bus).

To remember the different wireless technologies, you can use the acronym WBZ (Wi-Fi, Bluetooth, Zigbee).

Overall, network and communication aspects play a crucial role in IoT. Understanding these aspects is essential for building secure and efficient IoT applications.
