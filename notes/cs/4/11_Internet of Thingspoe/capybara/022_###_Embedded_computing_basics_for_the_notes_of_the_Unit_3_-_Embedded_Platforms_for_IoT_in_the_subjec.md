### Embedded computing basics for the notes of the Unit 3 - Embedded Platforms for IoT in the subject of Internet of Things

Embedded computing is a system of computing that is designed for a specific task or function. It is a combination of hardware and software that is created to perform a specific function or set of functions. The following are the basics of embedded computing:

1. Hardware: The hardware of an embedded system is designed specifically for the function that it is supposed to perform. It is usually composed of a microcontroller or a microprocessor, memory, and input/output interfaces.

2. Software: The software of an embedded system is also designed specifically for the function that it is supposed to perform. It is usually written in a low-level programming language such as C or assembly language.

3. Real-time performance: Embedded systems are expected to perform their tasks in real-time, which means that they must respond to inputs and produce outputs within a specific time frame.

4. Power consumption: Embedded systems must operate on limited power, which means that they must be designed to consume as little power as possible.

5. Connectivity: Many embedded systems are connected to other systems or devices. This connectivity can be wired or wireless.

6. Memory: Memory is an important consideration in embedded systems. The amount of memory needed will depend on the complexity of the task that the system is supposed to perform.

7. Mnemonic: A useful mnemonic for remembering the basics of embedded computing is "H-S-R-P-M-C". The letters stand for Hardware, Software, Real-time performance, Power consumption, Memory, and Connectivity.

Embedded systems are used in a wide range of applications, including home appliances, medical devices, industrial control systems, and automotive systems. They are an essential component of the Internet of Things (IoT) because they provide the intelligence and connectivity that makes IoT devices possible. A good understanding of the basics of embedded computing is essential for anyone who wants to work in the field of IoT.
