### Wireless Medium Access Issues for the Notes of the Unit 4 - Network & Communication Aspects in IoT in the Subject of Internet of Things

Wireless medium access refers to the process of controlling the access to the wireless channel by different devices. In IoT, there are various types of wireless medium access issues that need to be considered. Some of these issues are:

1. Collision Avoidance: When multiple devices try to access the wireless medium at the same time, it can result in a collision. This can cause delays and reduce the overall network performance. To avoid collisions, different techniques can be used such as Carrier Sense Multiple Access (CSMA), CSMA with Collision Detection (CSMA/CD), and Random Early Detection (RED).

2. Channel Allocation: In wireless networks, the available frequency spectrum is limited. Therefore, it is important to allocate the channels efficiently. There are different channel allocation techniques such as Frequency Division Multiple Access (FDMA), Time Division Multiple Access (TDMA), and Code Division Multiple Access (CDMA).

3. Interference: Interference can occur when other wireless networks or devices use the same frequency spectrum. This can result in reduced network performance and data loss. To avoid interference, different techniques can be used such as Spread Spectrum Techniques, Frequency Hopping, and Direct Sequence Spread Spectrum.

4. Security: Wireless networks are more vulnerable to security threats than wired networks. Therefore, it is important to implement security measures such as encryption, authentication, and access control to prevent unauthorized access and malicious attacks.

Mnemonics and Learning Tricks:

1. For Collision Avoidance, remember the phrase "CSMA/CD - Collision Detection is the key to avoiding Collisions."

2. For Channel Allocation, remember the acronym "FTC" which stands for "Frequency, Time, and Code" to help remember the three different allocation techniques.

3. For Interference, remember the phrase "Spread Spectrum - Spread out the frequency to avoid interference."

4. For Security, remember the phrase "EAA" which stands for "Encryption, Authentication, and Access Control" to help remember the three main security measures.

Overall, understanding the wireless medium access issues in IoT is crucial for ensuring efficient and secure communication between devices. Remembering the mnemonics and learning tricks can help in retaining the information and applying it effectively in exams and real-world scenarios.
