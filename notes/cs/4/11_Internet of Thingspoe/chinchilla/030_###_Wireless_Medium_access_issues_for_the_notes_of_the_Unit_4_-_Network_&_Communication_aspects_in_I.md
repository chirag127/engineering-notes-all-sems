### Wireless Medium access issues for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

Wireless medium access is the process of determining which device can access the wireless medium at a particular time. In IoT, where a large number of devices are connected to the network, the efficient and fair allocation of the wireless medium is essential to ensure smooth communication. However, there are certain issues that need to be addressed to avoid interference and collisions in wireless medium access. Some of the significant wireless medium access issues in IoT are:

1. **Channel Congestion:** With the increasing number of IoT devices, the wireless channel can become congested, leading to interference and collisions between devices. This can result in reduced network performance and latency.

2. **Hidden Node Problem:** The hidden node problem occurs when two or more nodes cannot hear each other, but they can both communicate with a third node. In this situation, if two nodes transmit data simultaneously, it can cause a collision, leading to packet loss and reduced network throughput.

3. **Exposed Node Problem:** The exposed node problem occurs when a node refrains from transmitting data because it detects another node transmitting data, even though the other node's transmission does not interfere with the node's communication. In this situation, the wireless medium remains idle, leading to reduced network throughput.

4. **Fairness:** In IoT, devices with different priority levels and data rates may need to access the wireless medium. The fair allocation of the wireless medium is crucial to ensure that all devices have an equal opportunity to access the network.

To address these issues, various medium access control protocols have been developed, such as Carrier Sense Multiple Access with Collision Avoidance (CSMA/CA), Time Division Multiple Access (TDMA), and Frequency Division Multiple Access (FDMA). These protocols ensure fair and efficient allocation of the wireless medium by preventing collisions and interference between devices.

Some learning tricks to remember these wireless medium access issues for IoT are:

1. **CCCH:** Channel Congestion can be remembered using the mnemonic CCCH, which stands for "Crowded Channel, Collisions, and High Latency."

2. **HNP:** Hidden Node Problem can be remembered using the mnemonic HNP, which stands for "Hidden Nodes, No Communication, and Packet Loss."

3. **ENP:** Exposed Node Problem can be remembered using the mnemonic ENP, which stands for "Exposed Nodes, Empty Medium, and Reduced Throughput."

Remembering these mnemonics can help in recalling the wireless medium access issues and their impact on IoT networks.
