### Sensor Deployment & Node Discovery for the notes of the Unit 4 - Network & Communication aspects in IoT in the subject of Internet of Things

Sensor deployment and node discovery are crucial aspects of IoT network and communication. Proper deployment of sensors and discovery of nodes can ensure efficient communication between devices, which is necessary for the smooth operation of IoT systems. In this section, we will discuss the various aspects of sensor deployment and node discovery in IoT.

#### Sensor Deployment

Sensor deployment involves placing sensors in the appropriate locations to collect the required data. Here are some important points to consider when deploying sensors in an IoT system:

1. **Location**: The location of the sensor is critical to its functionality. The sensor should be placed in a location where it can capture the required data accurately.

2. **Power supply**: Sensors require a power source to function. Depending on the location of the sensor, the power supply can be wired or wireless.

3. **Communication**: Sensors need to communicate with other devices in the network. The communication method can be wired or wireless, depending on the application.

4. **Data processing**: The data collected by the sensor needs to be processed and analyzed. This can be done either locally or in the cloud.

5. **Security**: Sensor data can be sensitive and confidential. Therefore, the sensor should be placed in a secure location to prevent unauthorized access.

#### Node Discovery

Node discovery is the process of identifying and connecting devices in an IoT network. Here are some important points to consider when discovering nodes in an IoT system:

1. **Network topology**: The network topology determines how devices are connected in the network. The most common network topologies in IoT are star, mesh, and tree.

2. **Protocol**: The protocol used for communication between devices should be selected based on the application requirements. Some of the commonly used protocols in IoT are MQTT, CoAP, and HTTP.

3. **Addressing**: Each device in the network should have a unique address to enable communication. The addressing scheme can be hierarchical or flat.

4. **Discovery methods**: There are two main methods for discovering nodes in an IoT network: manual and automatic. Manual discovery involves manually configuring each device in the network, while automatic discovery uses discovery protocols to identify devices in the network.

5. **Security**: Security is a critical aspect of IoT networks. Nodes should be authenticated and authorized to ensure secure communication between devices.

Mnemonics and Learning Tricks:

1. Remember the acronym L-PADS for sensor deployment: Location, Power supply, Communication, Data processing, and Security.

2. To remember the network topology types in IoT, think of the phrase "Star Mesh Tree" or SMT.

3. To remember the commonly used protocols in IoT, use the acronym MCH: MQTT, CoAP, and HTTP.

In summary, sensor deployment and node discovery are critical aspects of IoT networks. Proper deployment of sensors and discovery of nodes can ensure efficient communication between devices, which is necessary for the smooth operation of IoT systems.
