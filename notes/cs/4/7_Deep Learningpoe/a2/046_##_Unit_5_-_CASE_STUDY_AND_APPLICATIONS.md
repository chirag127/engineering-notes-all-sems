## Unit 5 - CASE STUDY AND APPLICATIONS

This unit covers the application of Machine Learning algorithms and techniques to various real-world problems. The following key topics are discussed:

1. Spam Classification - Build a spam classifier using Naive Bayes algorithm. Learn how to preprocess text data and extract features. Understand the probabilistic approach of Naive Bayes in classifying spam emails.
Advantages: Simple to implement, efficent to train and test, works well with categorical features, handles irrelevant features well.
Disadvantages: Strong independence assumption may not always hold true.

2. Sentiment Analysis - Learn how to perform sentiment analysis on product reviews using SVM and logistic regression. Understand how to extract features from text data and vectorize features for model training.
Advantages of SVM: Effective in high dimensional spaces, flexible in modeling non-linear relationships.
Advantages of Logistic Regression: Simple and efficient to train, probability outputs are intuitively appealing.

3. Recommender Systems - Implement a collaborative filtering based recommender system. Learn to compute similarity between users or items and make predictions. Discuss issues like cold start and scalability.
Advantages: Personalized recommendations, scalable, performs well with sparse data.
Disadvantages: Does not utilize item metadata, may produce irrelevant recommendations, suffers from cold start problem.

4. Computer Vision - Discuss applications of machine learning to computer vision like object recognition, scene classification, face detection, etc. Learn about convolutional neural networks and their architecture for feature extraction from images.
Advantages of CNNs: Hierarchical feature extraction, translation invariance, handles 2D structured data well.
