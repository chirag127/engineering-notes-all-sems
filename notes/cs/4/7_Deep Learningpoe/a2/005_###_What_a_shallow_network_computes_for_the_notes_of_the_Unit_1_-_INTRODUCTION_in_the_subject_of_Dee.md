### What a shallow network computes

A shallow network is a neural network with only one hidden layer. Such a network can learn simple linear boundaries to separate data points. Some key points about what a shallow network computes are:

- It can only learn linear boundaries: A shallow network can only learn to separate inputs based on linear boundaries since it only has one layer of parameters (between input and hidden layer). This limits its modeling capacity.
- It performs a weighted sum of inputs: The output of a shallow network is essentially a weighted sum of its inputs, with the weights and summation happening in the hidden layer. This is still a limited transformation of the input data.
- It cannot capture complex nonlinear interactions: With only one layer, a shallow network cannot capture complex nonlinear interactions between input variables or learn complex nonlinear mappings. This limits the types of functions it can approximate.

To recap, a shallow network with one hidden layer can only learn simple linear boundaries and cannot capture complex nonlinear interactions between inputs. To overcome these limitations and learn more complex patterns, we need to use deeper networks with more layers of parameters.

Some mnemonics for remembering the key points:

- "One layer, linear play" - A single layer can only do linear separation
- "Weighted sum, no fun" - Output is a weighted sum of inputs, limited capacity
- "Complexity? No way!" - Cannot capture complex nonlinear patterns
