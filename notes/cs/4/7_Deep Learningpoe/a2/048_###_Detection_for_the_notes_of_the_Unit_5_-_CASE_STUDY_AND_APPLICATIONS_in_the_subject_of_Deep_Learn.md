### Detection for the notes of the Unit 5 - CASE STUDY AND APPLICATIONS in the subject of Deep Learning

- Object Detection: Identifying and localizing objects of a certain class in an image or video. Some applications are face detection, pedestrian detection, etc.
- - Mnemonic: Look for the object, find the box. Object detection finds the bounding box for the object in the image.
- - Learning trick: Train on thousands of images with bounding boxes around the object of interest. Use a convolutional neural network and optimize for reducing localization error.
- Semantic Segmentation: Assigning a semantic label to every pixel in an image. Some applications are self-driving cars, medical imaging, etc.
- - Mnemonic: Pixel perfect labels. Every pixel is assigned a label for what object it belongs to.
- - Learning trick: Use a convolutional neural network and optimize for reducing pixel-wise classification errors.
- Instance Segmentation: Assigning a instance label to every pixel in an image. It is a combination of object detection and semantic segmentation. Some applications are autonomous driving, video surveillance, etc.
- - Mnemonic: Detect and label. First detect the objects then label each pixel with an instance of the object.
- - Learning trick: Combine object detection and semantic segmentation methods. Detect objects first then segment each instance of the detected objects.
