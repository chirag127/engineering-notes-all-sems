### Face Recognition

- Face recognition is a computer vision task of identifying and verifying a person from a digital image or a video frame.
- Some popular applications of face recognition are:
    - Unlocking smartphones or laptops.
    - Tagging friends and family in social media photos.
    - Biometric security systems.
    - Law enforcement surveillance and criminal identification.
- The basic steps involved in face recognition are:
    1. Face Detection - Locating and extracting the face region from the input image.
    2. Face Alignment - Aligning and normalizing the pose, scale and illumination of the extracted face.
    3. Feature Extraction - Extracting key facial features and measuring distances and ratios between them.
    4. Classification - Applying a machine learning algorithm to classify the face based on the features extracted.
- Some key points to remember:
    - Face recognition accuracy drops with variations in pose, facial expression, lighting, aging, etc.
    - The more data we have for training, the better the recognition accuracy.
    - Deep learning based approaches using CNNs have achieved state-of-the-art results in face recognition.

- Advantages: Convenient and efficient alternative to passwords. Useful in surveillance and security systems.
- Disadvantages: Raises privacy concerns. Can be spoofed using photos or videos. Accuracy decreases under adverse conditions.
- Applications: Unlocking devices, tagging photos, surveillance, access control, etc.
