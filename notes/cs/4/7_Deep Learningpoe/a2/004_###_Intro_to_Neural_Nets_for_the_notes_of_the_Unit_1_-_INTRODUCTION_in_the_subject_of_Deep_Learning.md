### Intro to Neural Nets

- Neural Networks are a type of machine learning algorithm that is inspired by the human brain. They are made up of interconnected nodes that must be trained on large amounts of data to learn how to perform a task.
- The key components of a neural network are:
    - Input Layer: The input data is fed into the network through the input layer.
    - Hidden Layers: The hidden layers receive input from the previous layer, process it and then pass it to the next layer. A network can have multiple hidden layers that help the network learn complex patterns in the data.
    - Output Layer: The output layer produces the final output of the network. The number of nodes in the output layer depends on the task. For example, a network solving a classification problem might have an output layer with one node per class.
- As the network receives input, it passes data from the input layer through the hidden layers to the output layer. Each layer transforms the data and passes it to the next layer. This process requires weights and activation functions to determine how each layer's nodes respond to the input and transform it.
- The power of neural networks comes from their ability to learn complex patterns in large data sets. As they receive large amounts of data and the corresponding labels or answers, they adjust the weights between nodes in an iterative process until they can make predictions on new data. This is called training the network.
- Some advantages of neural networks are:
    - They can learn complex, nonlinear relationships between inputs and outputs.
    - They continue to improve their performance as they receive more data.
    - They can be applied to a variety of tasks like classification, regression, clustering, etc.
- Some disadvantages are:
    - They require large amounts of data to train the network.
    - Training can be time-consuming and computationally expensive.
    - The networks are opaque and it is difficult to understand why they make the predictions they do.
    - Overfitting can be a problem if the network is too complex for the amount of data.
