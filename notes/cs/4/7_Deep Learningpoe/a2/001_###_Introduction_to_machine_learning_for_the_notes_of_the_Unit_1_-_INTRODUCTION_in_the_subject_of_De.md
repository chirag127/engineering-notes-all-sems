### Introduction to machine learning for the notes of the Unit 1 - INTRODUCTION in the subject of Deep Learning

Machine learning is a field of computer science that gives computers the ability to learn without being explicitly programmed. Machine learning focuses on the development of computer programs that can change when exposed to new data.

Some key points about machine learning are:

- Machines learn from experience: Machine learning uses data to identify patterns and learn from experience, instead of following explicitly programmed instructions. The more data you provide, the more accurate it gets.
- Gets better over time: As the machine learns, its performance improves over time. The more you use the system, the more accurate it gets.
- Used for predictions: Machine learning powers many technologies we use every day like face recognition, recommendation systems, speech recognition, etc. The ultimate goal is to make accurate predictions and decisions without being explicitly programmed to perform the task.

Some mnemonics to remember the steps in machine learning -

1. Gather data
2. Prepare data
3. Choose algorithm
4. Train and evaluate
5. Make predictions

The basic steps to machine learning are:

1. Gather data - Collect relevant data to train the machine learning model.
2. Prepare data - Clean and preprocess the data.
3. Choose an algorithm - Select a machine learning algorithm to train the model (such as linear regression, logistic regression, decision trees, SVM, etc.).
4. Train and evaluate - Train the model and evaluate its performance using metrics like accuracy, precision, recall, etc.
5. Make predictions - Use the trained model to make predictions on new data.

Some advantages of machine learning are:

- Increased accuracy with increased data
- Automates tasks and reduces human labour
- Adapts to dynamic data
- Handles complex problems

Some disadvantages of machine learning are:

- Requirement of large amounts of data
- Black box models that are difficult to interpret
- Overfitting and underfitting
- Security and privacy concerns
- Bias in data and algorithms can lead to unfair outcomes
