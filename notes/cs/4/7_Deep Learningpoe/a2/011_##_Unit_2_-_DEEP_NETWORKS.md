## Unit 2 - DEEP NETWORKS

Deep Networks refer to neural networks with multiple hidden layers between the input and output layers. These deep architectures allow the learning of complex patterns in large data sets. Some key points about Deep Networks are:

1. They are fed with large amounts of data to learn features of different levels of abstraction. The multiple hidden layers allow them to automatically learn hierarchical features/representations of the data.
2. Pre-training: Initializing the weights of the deep network with unsupervised pre-training techniques like Restricted Boltzmann Machines (RBMs) helps the network to converge faster during supervised fine-tuning.
3. Regularization: Deep Networks are prone to overfitting due to large number of parameters. Hence, regularization techniques like Dropouts, Data Augmentation, etc. are used to reduce overfitting.
4. Training Challenges: Training deep networks is challenging due to problems like vanishing/exploding gradients. Techniques like initialization, activation functions, batch normalization, etc. are used to train deep networks efficiently.
5. Applications: Deep Networks have achieved state-of-the-art results in various applications like Image Classification, Object Detection, Speech Recognition, Machine Translation, etc. Some popular deep architectures are Convolutional Neural Networks (CNNs), Recurrent Neural Networks (RNNs), Long Short-Term Memory (LSTM) Networks, etc.

Some mnemonics/learning tricks for Deep Networks:

1. Think of hidden layers as extracting different levels of features/abstractions of the data. More layers can learn more complex features.
2. Pre-training is like providing some guidance/supervision to the network to speed up learning. Fine-tuning then adjusts the weights to the actual task.
3. Regularization is like a penalty to prevent overfitting. It makes the network generalize better to new data.
