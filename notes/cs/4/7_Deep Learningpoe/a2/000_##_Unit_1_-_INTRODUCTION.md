## Unit 1 - INTRODUCTION

1. Introduction to Data Science
- Data science is an interdisciplinary field that uses scientific methods, processes, algorithms and systems to extract knowledge and insights from data in various forms, both structured and unstructured.
- The main objectives of data science are prediction, summarization, clustering and classification.
- The key steps in a data science project are:
-- Problem definition
-- Data collection and acquisition
-- Data cleaning and preprocessing
-- Exploratory data analysis
-- Feature engineering
-- Model building
-- Evaluation
-- Deployment

2. Why Data Science?
- Data is being generated at an unprecedented rate in today's world due to increase in Internet activity, digitalization, IOT devices, etc. So there is a huge demand for processing and analyzing this data to gain meaningful insights. This is where data science comes into the picture.
- Some of the key reasons for the popularity of data science are:
-- Huge amounts of data generation leading to demand for extraction of insights
-- Powerful computing systems and algorithms to process large data
-- Need to make data-driven decisions in businesses
-- Lucrative career opportunities in data science
