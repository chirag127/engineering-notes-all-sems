### features of swift for the notes of the Unit 5 - TECHNOLOGY II –iOS in the subject of Design & Development Of Applications
Swift is a general-purpose, multi-paradigm, compiled programming language developed by Apple Inc. for iOS, iPadOS, macOS, watchOS, tvOS, and Linux. 

Features:
1. Easy to read and write: Swift uses a simple and expressive syntax that makes code easier to read and write. 
2. Fast and efficient: Swift is designed to be fast and efficient, making it suitable for large-scale applications. 
3. Safe and secure: Swift has built-in safety features that protect against errors and crashes, making it a secure choice for developing applications. 
4. Interoperable with Objective-C: Swift is fully interoperable with Objective-C, making it easy to integrate existing Objective-C code into Swift projects. 
5. Dynamic library support: Swift supports dynamic libraries, making it easy to share code between multiple applications. 
6. Open-source: Swift is open-source and actively maintained by the community, making it a popular choice for developers.
