### Location aware applications using Core Location and Map Kit for the notes of the Unit 5 - Technology II -iOS in the subject of Design & Development Of Applications

Core Location is a framework provided by iOS that provides APIs for accessing GPS and Wi-Fi data, allowing developers to determine the device's location. Core Location provides support for tracking the device's location, as well as monitoring changes in the device's location.

Map Kit is a framework provided by iOS that provides APIs for integrating maps into iOS applications, allowing developers to display maps, add markers, and provide navigation services to users. Map Kit provides support for customizing the appearance of maps, as well as adding annotations and overlays to maps.
