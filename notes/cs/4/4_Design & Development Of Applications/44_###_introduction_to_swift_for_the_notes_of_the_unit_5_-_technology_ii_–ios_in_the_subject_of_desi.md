### Introduction to Swift for the notes of the Unit 5 - TECHNOLOGY II –iOS in the subject of Design & Development Of Applications
Swift is a powerful and intuitive programming language for iOS, macOS, watchOS, and tvOS. It was developed by Apple Inc. and was first released in 2014. Swift is designed to be easy to read and write, and is intended to be more safe and faster than Objective-C.

Swift is a statically typed language, which means that variables and constants must be declared with a specific type before they can be used. This helps to prevent errors and makes it easier to understand and maintain code. Swift also supports type inference, which allows the compiler to deduce the type of a value based on its usage.

Swift is an object-oriented programming language, which means that it is based on the concept of objects, classes, and inheritance. Objects are instances of classes, which define the properties and methods that objects can have and perform. Inheritance allows you to create new classes based on existing classes, inheriting their properties and methods.

Swift also supports functional programming concepts, such as closures, which are self-contained blocks of code that can be passed as arguments to functions or used as variables. This makes it easy to write clean, concise, and reusable code.

In conclusion, Swift is a versatile and powerful programming language that is well suited for developing iOS, macOS, watchOS, and tvOS applications. With its focus on safety, performance, and ease of use, Swift is a great choice for developers who want to create high-quality and user-friendly applications.
