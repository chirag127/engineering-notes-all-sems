### Touch frameworks for the notes of the Unit 5 - TECHNOLOGY II –iOS in the subject of Design & Development Of Applications
Touch frameworks for iOS:
- UIKit: provides basic user interface elements and layout management for iOS apps.
- Core Animation: provides advanced animation capabilities for UI elements.
- Core Graphics: provides low-level graphics rendering and image manipulation capabilities.
- Core Text: provides text rendering and layout capabilities.
- Core Image: provides image processing and analysis capabilities.
- Core Location: provides location and mapping services.
- Core Motion: provides motion tracking and analysis capabilities.
- Core Video: provides video playback and recording capabilities.
