### Causal order for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

The notes for Unit 1 - Characterization of Distributed Systems cover the following topics in causal order:

1. Distributed System: A distributed system consists of multiple autonomous computers that communicate through a computer network. The computers interact with each other in order to achieve a common goal.

- Advantages: Increased resources utilization, increased reliability, increased processing power.
- Disadvantages: Complexity, lack of centralized control, increased communication delays.

2. Transparency: The difference between a distributed system and a non-distributed system should be transparent to the users. The users should not be able to see the distinction between the two. The key aspects of transparency are location transparency, concurrency transparency, replication transparency, and failure transparency.

3. Open vs Closed Systems: In an open distributed system, the membership of the system is not fixed and components can join and leave the system dynamically. In a closed distributed system, the membership is fixed and static. Most practical distributed systems are open.

4. Architectures: The architectures of distributed systems can be classified into client-server architecture, peer-to-peer architecture, and multi-tier architecture. In a client-server architecture, the clients request services from centralized servers. In a peer-to-peer architecture, all nodes are equal and there are no servers. In a multi-tier architecture, presentation, application logic, and data are physically separated.
