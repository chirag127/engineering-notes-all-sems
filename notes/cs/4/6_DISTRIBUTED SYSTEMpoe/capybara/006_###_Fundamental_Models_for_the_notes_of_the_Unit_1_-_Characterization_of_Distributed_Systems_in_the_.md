### Fundamental Models for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

In the subject of Distributed Systems, the fundamental models are important to understand the behavior and characteristics of the system. These models help in designing and implementing distributed systems. Let's discuss the fundamental models in detail:

1. Client-Server Model:
   - In this model, the system is divided into two parts: the client and the server.
   - The client sends requests to the server, and the server responds to those requests.
   - The communication between the client and server is through a network.
   - This model is widely used in web applications, where the client sends requests to the server for data and the server sends back the requested data.

2. Peer-to-Peer Model:
   - In this model, there is no central server. All the nodes in the system are equal and communicate with each other.
   - Each node can act as both a client and a server.
   - This model is used in file-sharing applications, where each node shares its files with other nodes.

3. Cluster Model:
   - In this model, a group of interconnected computers work together as a single system.
   - Each computer performs a specific task, and the tasks are distributed among the computers.
   - This model is used in high-performance computing, where multiple computers are used to solve a complex problem.

4. Cloud Model:
   - In this model, the system is hosted on the cloud, and the users access the system over the internet.
   - The system can be accessed from anywhere in the world through the internet.
   - This model is used in web applications, where the system is hosted on the cloud, and the users access it through a web browser.

Mnemonics and Learning Tricks:

1. To remember the Client-Server Model, think of it as a restaurant. The client is the customer who orders food, and the server is the waiter who serves the food.

2. To remember the Peer-to-Peer Model, think of it as a group study session. All the members are equal and can help each other with their studies.

3. To remember the Cluster Model, think of it as a group project. Each member has a specific task, and the tasks are distributed among the members.

4. To remember the Cloud Model, think of it as a virtual office. The system is hosted on the cloud, and the users can access it from anywhere in the world.
