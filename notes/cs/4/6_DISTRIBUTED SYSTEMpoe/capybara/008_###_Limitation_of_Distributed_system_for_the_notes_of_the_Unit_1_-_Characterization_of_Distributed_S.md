### Limitation of Distributed system for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

Distributed systems are becoming increasingly popular in today's world as they offer various advantages such as scalability, fault tolerance, and resource sharing. However, they also have some limitations that need to be taken into consideration. In this section, we will discuss the limitations of distributed systems that one should keep in mind while designing and implementing distributed systems.

1. **Network Latency:** In a distributed system, the nodes communicate with each other over a network. The network latency can cause delays in communication between nodes, which can affect the overall performance of the system. To overcome this limitation, techniques such as caching, load balancing, and data replication can be used.

2. **Partial Failure:** In a distributed system, it is possible that some of the nodes may fail while others continue to function. This can lead to data inconsistency and can affect the overall performance of the system. To overcome this limitation, techniques such as replica consistency, checkpointing, and rollback recovery can be used.

3. **Concurrency Control:** In a distributed system, multiple nodes may access the same resource simultaneously. This can lead to conflicts and inconsistency in the data. To overcome this limitation, techniques such as locking, two-phase commit, and optimistic concurrency control can be used.

4. **Security:** In a distributed system, it is difficult to ensure the security of the data and the system as a whole. The nodes are connected over a network, which makes it vulnerable to attacks such as hacking, eavesdropping, and denial of service attacks. To overcome this limitation, techniques such as encryption, authentication, and access control can be used.

5. **Scalability:** In a distributed system, adding more nodes to the system should increase its scalability. However, adding more nodes can also introduce new challenges such as network congestion and increased network latency. To overcome this limitation, techniques such as load balancing, data partitioning, and distributed caching can be used.

Mnemonics and Learning Tricks:

- To remember the limitations of distributed systems, one can use the acronym "NPCSS," where each letter represents one of the limitations discussed above.
- Another mnemonic can be "No Perfect Communication System Survives," where each word represents one of the limitations discussed above.
