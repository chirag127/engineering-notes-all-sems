### Examples of Distributed Systems for the notes of the Unit 1 - Characterization of Distributed Systems in the subject of DISTRIBUTED SYSTEM

Distributed systems are computer systems that are spread across multiple machines that communicate with each other to perform a common task. The following are some examples of distributed systems:

1. Internet: The internet is the largest distributed system in the world. It is a collection of interconnected networks that work together to provide a platform for communication and information exchange.

2. Cloud Computing: Cloud computing is a technology that enables users to access computing resources over the internet. It is a distributed system because it uses multiple servers to provide users with the computing power they need.

3. Social Networks: Social networks like Facebook, Twitter, and Instagram are examples of distributed systems. They allow users to share information, communicate with each other, and participate in online communities.

4. Distributed Databases: A distributed database is a database that is spread across multiple computers in a network. It allows users to access and share data from different locations.

5. Peer-to-Peer Networks: A peer-to-peer network is a distributed system in which all nodes in the network are equal and communicate with each other to share resources. Examples include BitTorrent and Napster.

6. Distributed File Systems: A distributed file system is a file system that is spread across multiple computers in a network. It allows users to access and share files from different locations.

7. Distributed Sensor Networks: A distributed sensor network is a network of sensors that are spread across different locations. They collect data and communicate with each other to provide information about their environment.
