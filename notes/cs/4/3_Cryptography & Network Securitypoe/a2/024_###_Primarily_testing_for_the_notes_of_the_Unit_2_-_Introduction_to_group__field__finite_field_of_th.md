1. Introduction to group, field, finite field of the form GF(p)
- A group is a set of elements and an operation that combines two elements to form another element. The set must be closed under the operation, the operation must be associative, there must be an identity element, and each element must have an inverse.
- A field is a group with commutative multiplication and with multiplicative and additive inverses for all elements except 0. The set of integers modulo p forms a field with p elements if p is prime. This is denoted by GF(p).
- Finite fields are useful in cryptography, coding theory, and other applications. The properties of finite fields are used to develop efficient algorithms for computations such as multiplication and finding multiplicative inverses.

2. Modular arithmetic
- Modular arithmetic is concerned with the remainders obtained after dividing integers by a fixed integer called the modulus. The results of adding, subtracting, multiplying, and dividing integers modulo a prime modulus p have interesting and useful properties.
- Some important properties:
-- If a and b are integers less than the modulus p, then a + b, a - b, and a * b leave remainders modulo p.
-- For any integer a, there exists an integer b such that a * b leaves a remainder of 1 modulo p.
-- If p is prime, then the multiplicative group modulo p contains a unique subgroup of order p-1.
