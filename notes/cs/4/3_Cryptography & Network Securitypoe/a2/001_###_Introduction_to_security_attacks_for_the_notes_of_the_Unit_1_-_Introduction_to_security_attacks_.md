### Introduction to security attacks
- Security attacks are attempts to compromise the confidentiality, integrity or availability of a resource.
- Types of security attacks: Passive attacks (eavesdropping), Active attacks (modifying data), Insider attacks (malicious insiders), Denial of service attacks (make a system unavailable)

### Services and mechanisms
- Cryptographic services: Confidentiality (only authorized parties can read), Integrity (detect changes), Authentication (verify identity), Non-repudiation (cannot deny sending a message)
- Cryptographic mechanisms: Encryption (converting plain text to cipher text), Digital signatures (data that can authenticate a message), Hash functions (one-way conversion of any size data to a fixed size data)

### Classical encryption techniques
- Substitution ciphers: Replace each character with another character/symbol, Example: Caesar cipher (shift letters in the alphabet)
- Transposition ciphers: Scramble the position of characters, Example: Rail fence cipher (zig-zag pattern to rearrange characters)
- Both can be broken using cryptanalysis (studying patterns in cipher text)

### Cryptanalysis
- Cipher text only attack: Analyze patterns in cipher text to deduce key/plaintext
- Known plaintext attack: Analyze patterns between known plaintext and corresponding cipher text to deduce key
- Chosen plaintext attack: Attacker can choose plain text and get corresponding cipher text to deduce key
- Brute force: Systematically try all possible keys to find the correct one (feasible only for short keys)
