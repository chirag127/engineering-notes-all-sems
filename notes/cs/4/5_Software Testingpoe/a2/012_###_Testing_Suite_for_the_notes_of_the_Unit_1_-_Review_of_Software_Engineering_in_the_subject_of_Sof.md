### Testing Suite for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

The different types of software testing that can be performed are:

1. Unit Testing: Testing individual software components or modules. Mnemonics: Check smallest parts.
- Performed by developers.
- Checks if each unit of the software works as intended.
- Example: Testing a single function or a class.

2. Integration Testing: Testing interactions between software modules.
- Performed after unit testing.
- Checks if software modules work properly together.
- Example: Testing interface between two modules.

3. System Testing: Testing the complete software product as a whole.
- Performed on the complete system.
- Checks if the software meets specified requirements.
- Examples: Recovery testing, Security testing, Usability testing, etc.

4. Acceptance Testing: Testing software with the customer perspective.
- Performed by customers or client teams.
- Checks if software satisfies customer requirements.
- Examples: User acceptance testing, Operational acceptance testing, etc.

Advantages of software testing:
- Identifies bugs and errors early.
- Increases software quality.
- Reduces costs due to errors detected and fixed early.
- Increases customer satisfaction.

Disadvantages of software testing:
- Time consuming and costly process.
- Difficult to perform exhaustive testing.
- Test cases may miss some bugs.
- Defects may be found late in the development cycle.
