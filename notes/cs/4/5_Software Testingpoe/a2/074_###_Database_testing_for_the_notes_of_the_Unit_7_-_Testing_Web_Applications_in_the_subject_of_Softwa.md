### Database testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Database testing is an important part of testing web applications as the data is stored and retrieved from the databases. Following are the key points to cover in database testing:

1. Check for correct data storage: Test if the data is getting stored correctly in the database as per the requirements. Check for data type, size, null values, etc. Check for duplicate data entry and other restrictions.
2. Check for correct data retrieval: Test if the data is getting retrieved correctly from the database as per the requirements. Check if the retrieved data is accurate and complete. Check for performance issues in data retrieval.
3. Check for database transactions: Test if the database transactions like commit, rollback, etc. are working correctly. Check for database locks and deadlocks.
4. Check for database migrations: Test the database migration scripts to ensure smooth migration of data from old database to new database versions. Check if the data is intact after migration.
5. Check for database performance: Test the performance of databases under load. Check for optimum configurations for best performance. Check for scalability of databases.

Some tips for database testing:

- Use test data generators to generate large volumes of data for testing.
- Capture database queries and check for most efficient queries.
- Check for SQL injection and other security vulnerabilities related to databases.
- Automate database testing using testing frameworks and tools.
- Check error handling in case of database failures or errors.
