### Equivalence Class Testing

- Equivalence class testing is a black box testing technique in which test cases are designed to execute representatives from equivalence classes.
- An equivalence class is a set of input conditions that are treated the same way by the system.
- The key idea is that once you've identified the equivalence classes for input conditions, you select one representative from each class to use in test cases. This helps reduce the number of test cases and determines whether the system under test handles all classes correctly.
- Some examples of equivalence classes:
- For a input of age: 0-4, 5-12, 13-19, 20-120
- For input salary: negative, 0, positive
- Advantages: Reduce number of test cases, handle inputs systematically, catch defects early
- Disadvantages: Difficult to identify equivalence classes, may miss defects if not identified properly
- Mnemonics: ECT => Equivalence Class Testing, reps from each class
- Learning trick: Think of inputs as buckets/classes, pick one rep from each bucket to test
