### Object Oriented Integration and System Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

- Integration testing is done to check if different modules work together properly. In object oriented integration testing, we check if the objects of different classes are interacting with each other correctly.
- Some tips for object oriented integration testing:
    - Test interactions between closely related objects first.
    - Test core functionalities of the system that use multiple objects.
    - Check for dependencies between objects and test those interactions.
    - Track object life cycles and ensure proper creation and destruction of objects.
    - Check for memory leaks by improper handling of objects.
- System testing is done on the complete software product to check if it meets the specified requirements. In object oriented system testing, we check if the object oriented system is working as intended as a whole.
- Some tips for object oriented system testing:
    - Test core features and functionalities of the system.
    - Check if key object oriented concepts like encapsulation, inheritance, polymorphism are implemented correctly.
    - Test the system with different inputs and check all output conditions.
    - Check for exceptions and edge cases in the system.
    - Performance testing and load testing should also be done to check scalability.
- Advantages of object oriented testing:
    - Modules can be tested independently and then integrated, making testing simpler.
    - Object interactions are limited and well defined, making it easier to trace issues.
    - Polymorphism and independence of objects allows testing some objects without complete system.
    - Object life cycle tracking helps find memory leaks and other object related bugs.
- Disadvantages of object oriented testing:
    - Dependence on objects and their complex interactions can make testing harder.
    - Testing all combinations of methods and objects can lead to exponential growth in test cases.
    - Core object oriented concepts like inheritance are harder to test thoroughly.
    - Debugging can be more complex due to object relationships and interactions.
