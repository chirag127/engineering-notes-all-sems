### Test for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

- Software Testing is a process of evaluating a software product to find differences between expected and actual outputs. It helps to identify defects, bugs or other flaws in the software product so that they can be corrected.
- Types of Software Testing -
	- Unit Testing - Testing individual software components or units.
	- Integration Testing - Testing integrated software modules or components.
	- System Testing - Testing the complete software product as a whole.
	- Acceptance Testing - Testing software with the aim of customer acceptance.
	- Performance Testing - Testing software for determining response time, throughput, reliability, scalability, etc.
	- stress Testing - Testing software under extreme workloads to assess its robustness and fault-tolerance.
	- Usability Testing - Testing software to determine how easy it is to use for end-users.
	- Alpha Testing - Testing software internally by in-house software testers.
	- Beta Testing - Testing software by external users at their sites.

- Mnemonics - UNIT IS PAS US (Unit, Integration, System, Acceptance, Performance, Stress, Usability)
- Advantages of Software Testing -
	- Helps to identify bugs or defects early and resolve them.
	- Improves software quality and reliability.
	- Reduces the time and cost required for debugging and maintenance.
	- Increases customer satisfaction.
- Disadvantages of Software Testing -
	- Time-consuming and adds to project cost.
	- Difficult to test all possible input conditions and combinations.
	- Subjective and depends on the skills of testers.
	- May not be able to find all defects.
