### Testing techniques and their applicability for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

The following testing techniques can be applied for testing the software:

1. **Black Box Testing:**
- It is a functional testing technique.
- The internal structure of the software is not considered.
- Only the output is checked for the given input.
- Applicable for:
    - Requirement Based Testing
    - User Acceptance Testing
- Advantages:
    - No code knowledge required.
    - Complete test coverage.
    - Bugs found are actual defects.
- Disadvantages:
    - May miss integration bugs.
    - Difficult to create exhaustive test cases.

2. **White Box Testing:**
- It is a structural testing technique.
- The internal structure of the software is considered.
- The control flows and loops are tested.
- Applicable for:
    - Unit Testing
    - Integration Testing
- Advantages:
    - Increases code coverage.
    - Provides path coverage.
    - Locates logical bugs.
- Disadvantages:
    - Requires code knowledge.
    - Difficult to create test cases.
    - May miss functional bugs.

3. **Grey Box Testing:**
- It is a combination of black box and white box testing techniques.
- The internal structure is partially considered.
- Applicable for:
    - Integration Testing
    - System Testing
- Advantages:
    - Increases effectiveness.
    - Provides good test coverage.
- Disadvantages:
    - Requires design and code knowledge.
    - Difficult to implement.
