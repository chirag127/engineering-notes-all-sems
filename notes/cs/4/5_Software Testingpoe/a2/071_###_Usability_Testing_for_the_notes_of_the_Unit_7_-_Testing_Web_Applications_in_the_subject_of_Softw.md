### Usability Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Usability testing is a technique used to evaluate a product (such as a website or app) by observing people using it. The goal is to identify any problems users might encounter and make improvements to create a better user experience.

Some key points about Usability Testing:

- Involves representative users (target audience) trying to complete tasks or goals using the product.
- Observes and records (video/audio) user behaviour and feedback.
- Looks for issues with learnability, efficiency, memorability, errors, and satisfaction.
- Can be moderated (facilitator observing) or unmoderated (users working independently).
- Sample size depends on goals but 5-8 users can uncover major issues.
- Report aggregates findings and makes recommendations for improvements.

 Mnemonics to remember the key points:

- UTT for Usability Testing - Users Try Tasks
- LOVEM - Learnability, Observable behaviours, Video recording, Errors, Memorability, Satisfaction
- 5-8 - Small sample size to find big issues

Benefits of Usability Testing:

- Identifies user problems early to fix them before launch.
- Provides direct user feedback to see what's really frustrating or confusing.
- Cheaper to fix issues found in testing vs. post-launch.
- Leads to better user experiences and higher customer satisfaction.

Disadvantages of Usability Testing:

- Requires representative users which can be difficult to recruit.
- Additional time and resources needed to conduct the tests and analyze results.
- Users may not act naturally if they know they are being observed (Hawthorne effect).
- Small sample size may not uncover all issues.

Examples of Usability Testing:

- Asking users to complete tasks like purchasing a product or finding information on a website.
- Having users think aloud as they use an app or website to understand their thoughts.
- Surveys or interviews to get user opinions and feedback.
- A/B or multivariate testing of different designs or features.

Applications of Usability Testing:

- Websites and web applications.
- Mobile apps.
- Software interfaces.
- Smart devices or systems.
- Basically, anywhere the user experience matters!
