### Web Testing

Web testing involves testing web applications to identify functional and performance issues before the app goes live. Some key types of web testing are:

- Functional testing: Verifies that web app functions as intended. Checks core functionalities and business logic. Examples:

- Login testing - Checks login/logout functions and user authorization
- Checkout testing - Verifies ecommerce checkout process
- Search testing - Confirms search functions return expected results

- Usability testing: Evaluates how easy and intuitive the web app is to use. Identifies UX issues and ways to improve user experience. Can involve real users or be simulated.

- Performance testing: Assesses the speed, stability, and scalability of the web app under different loads. Measures response time and resource usage under peak loads. Check for potential bottlenecks or other degradation of performance. Some tips:

- Test with gradually increasing load (users, data, etc.)
- Monitor key metrics like response time, CPU/memory usage, bandwidth, etc.
- Simulate common user workflows/journeys and spot performance gaps

- Compatibility testing: Checks that the web app functions correctly on different browsers, devices, and platforms. Ensure consistent experience across various configurations. Cross-browser and cross-device testing is important.

- Security testing: Identifies and addresses vulnerabilities in the web app that could be exploited by hackers. Some techniques:

- Cross-site scripting (XSS) testing - Injects malicious scripts into web pages
- SQL injection testing - Inserts malicious SQL statements through input data
- Broken authentication/session management testing - Tries to bypass login controls
- Sensitive data exposure testing - Checks for improper storage/transmission of sensitive data
