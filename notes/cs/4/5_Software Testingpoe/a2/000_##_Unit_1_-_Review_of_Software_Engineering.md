## Unit 1 - Review of Software Engineering

### Software Engineering Process
- Software engineering process involves phases like requirements analysis, design, implementation, testing, deployment and maintenance.
- Requirements analysis: Identifying the needs of the user and translating them into requirements.
- Design: Developing models/diagrams/documents that describe software architecture.
- Implementation: Coding the software.
- Testing: Check if software meets the requirements. Types: Unit testing, integration testing, system testing, acceptance testing.
- Deployment: Making the software available to the users.
- Maintenance: Fixing bugs/adding new features.

### Software Requirements
- Types: Functional (what software should do) and non-functional (quality attributes).
- Elicitation techniques: Interviews, focus groups, questionnaires, observing users, requirement workshops.
- Specification: Means of documenting requirements (informal, graphical, formal).
- Modeling requirements: Use case diagrams, activity/sequence diagrams.

### Software Design
- Components/modules and relationships between them.
- Design principles: Abstraction, information hiding, layering, separation of concerns.
- Architectural styles: Client-server, peer-to-peer, layered, pipeline, microkernel, event-driven.
- Diagrams: Class diagrams, object diagrams, state diagrams, deployment/package diagrams, component diagrams.
