### Verification for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

The following points cover the key concepts and topics from the notes of Unit 1 - Review of Software Engineering for the subject of Software Testing:

1. Software Engineering: It is the application of engineering principles to software development. It involves a systematic approach to the development, operation, maintenance, and retirement of computer software.

2. Software Development Life Cycle: The SDLC defines the various stages involved in the development of software. The stages are Requirements Analysis, Design, Coding, Testing, Deployment, and Maintenance.

3. Requirements Analysis: The requirements of the software to be developed are analyzed and specified in this phase. The requirements are gathered from the customer and documented in the SRS (Software Requirements Specification) document.

4. Design: The software design is created based on the requirements specified in the SRS. The design describes the components of the software, how they interact with each other, and the design patterns/architecture to be followed.

5. Coding: The design is implemented in a programming language in this phase. The developers write code for the software following the specified design.

6. Testing: The software is tested for any bugs or defects in this phase. Different types of testing like unit testing, integration testing, system testing, etc. are performed.

7. Deployment: The final software is deployed in the customer environment or released to the market.

8. Maintenance: The software is maintained in terms of fixing any issues or bugs reported by the customer. Enhancements and updates are also made to the software as required.

Some key points to remember:

- SDLC has defined stages/phases with specific objectives. The output of each phase acts as an input to the next phase.
- Requirements Analysis is the most important phase as the success of the software depends on gathering the correct requirements.
- Testing is done in parallel to Development to remove defects early and ensure high quality software.
- Software maintenance is an ongoing phase and not really the last phase of SDLC.
