### Software Testing Tools for the notes of the Unit 5 - Software Testing Activities in the subject of Software Testing

Following are the commonly used Software Testing Tools:

1. Selenium:
- Selenium is a free open source automated testing suite for web applications across different browsers and platforms.
- It supports multiple scripting languages like Java, Python, C#, PHP, Ruby, etc.
- It can be used to automate browser actions like clicking buttons, filling forms, etc. and asserting results.
- Mnemonic: *Selenium Saves Time By Automating Web Testing*

2. Junit:
- JUnit is a unit testing framework for the Java programming language.
- It is used to test individual units of source code.
- It can be integrated with build tools like Ant or Maven.
- It provides assertions for testing expected results.
- Mnemonic: *JUnit Tests JAVA Code Units*

3. TestNG:
- TestNG is a testing framework for the Java programming language inspired from JUnit and NUnit.
- It provides annotations to define test cases.
- It can handle multiple test suites with dependencies and prioritizations.
- It generates HTML reports and has better support for data driven and parameterization testing.
- Mnemonic: *TestNG Supports More Powerful Testing*
