### Performance Testing for the notes of the Unit 7 - Testing Web Applications in the subject of Software Testing

Performance Testing is done to determine the performance of a system or application under a particular workload. It can be considered as a subset of non-functional testing.
Following are the key points about Performance Testing -

- It is conducted to evaluate the speed, scalability, and/or stability characteristics of a system or application under a specific load.
- It helps to identify and address the performance bottlenecks or software faults that could adversely affect the performance of the system under evaluation.
- It focuses on factors such as response time, throughput, resource-utilization, scalability under increasing loads, ability to handle peak loads, etc.
- The key metrics to measure in Performance Testing are Response Time, Throughput, Utilization, Operational Profile, and Scalability.
- The performance of a system depends on software, hardware, network, DB, APIs, etc. So, Performance Testing must involve testing the system as a whole under real-world conditions.
- Some common types of Performance Tests are Load Testing, Stress Testing, Soak Testing or Endurance Testing, Spike Testing, Scalability Testing, Volume Testing, etc.
- Tools like JMeter, LoadRunner, WebLOAD, Apache JMeter, etc. are commonly used to conduct automated Performance Testing.
- Tips for Performance Testing - Identify performance requirements, Choose relevant tests, Focus on end-user experience, Test under production-like conditions, Run tests continuously, Monitor key metrics, Analyze and tune the system, etc.
