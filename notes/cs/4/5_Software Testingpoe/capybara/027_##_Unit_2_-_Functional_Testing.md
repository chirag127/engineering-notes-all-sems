## Unit 2 - Functional Testing

Functional testing is a type of software testing that evaluates the software system against functional requirements to ensure that they are met. It is a critical step in the software development life cycle, as it helps detect defects early in the process and ensures that the software meets the end-users' needs.

Functional testing can be performed manually or using automated tools. The goal of functional testing is to ensure that the software system is working as expected and meets the functional requirements specified by the end-users.

### Types of Functional Testing

1. Unit Testing: Unit testing is the process of testing individual units or components of the software system to ensure that they are functioning as expected. It is usually performed by developers and helps detect defects early in the development process.

2. Integration Testing: Integration testing is the process of testing the integration between different units or components of the software system to ensure that they are functioning as expected when integrated. This type of testing helps detect defects that may arise due to the interaction between different units.

3. System Testing: System testing is the process of testing the entire software system to ensure that it meets the functional requirements specified by the end-users. It is usually performed by a dedicated testing team and helps ensure that the software system is ready for release.

4. Acceptance Testing: Acceptance testing is the process of testing the software system against the functional requirements specified by the end-users to ensure that it meets their needs. It is usually performed by the end-users and helps ensure that the software system is ready for deployment.

### Mnemonics and Learning Tricks

1. FURPS: FURPS stands for Functionality, Usability, Reliability, Performance, and Supportability. It is a mnemonic used to remember the different aspects of functional testing that need to be evaluated.

2. BVA: BVA stands for Boundary Value Analysis. It is a technique used to test the boundary values of input parameters to ensure that the software system is functioning as expected at the edges of its range.

3. EP: EP stands for Equivalence Partitioning. It is a technique used to divide the input data into different partitions to ensure that the software system is functioning as expected for each partition.

### Advantages of Functional Testing

1. Early detection of defects: Functional testing helps detect defects early in the development process, reducing the cost of fixing them later.

2. Improved software quality: Functional testing helps ensure that the software system meets the functional requirements specified by the end-users, improving the overall quality of the software.

3. Better user experience: Functional testing helps ensure that the software system is easy to use and meets the needs of the end-users, improving their overall experience.

### Disadvantages of Functional Testing

1. Time-consuming: Functional testing can be time-consuming, especially when performed manually.

2. Costly: Functional testing can be expensive, especially when automated tools are used.

### Examples of Functional Testing

1. Testing the login functionality of a website to ensure that users can login successfully.

2. Testing the search functionality of a website to ensure that users can find what they are looking for.

### Applications of Functional Testing

1. Web development: Functional testing is commonly used in web development to ensure that websites are functioning as expected.

2. Mobile app development: Functional testing is commonly used in mobile app development to ensure that mobile apps are functioning as expected.
