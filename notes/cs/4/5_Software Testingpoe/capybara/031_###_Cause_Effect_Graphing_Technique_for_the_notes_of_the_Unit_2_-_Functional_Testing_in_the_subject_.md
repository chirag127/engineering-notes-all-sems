### Cause Effect Graphing Technique for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

The Cause Effect Graphing Technique is a popular method for functional testing. It is used to identify the root cause of a problem and to determine the effect of a particular input on the system. This technique helps to minimize the number of test cases required for testing.

#### Steps for using the Cause Effect Graphing Technique:

1. Identify the inputs and outputs of the system.
2. Create a cause and effect graph to identify the relationship between the inputs and outputs.
3. Identify the minimum and maximum values for each input.
4. Determine the test cases that need to be executed.
5. Execute the test cases and record the results.

#### Benefits of the Cause Effect Graphing Technique:

- Helps to minimize the number of test cases required for testing.
- Helps to identify the root cause of a problem.
- Helps to determine the effect of a particular input on the system.
- Helps to improve the quality of the software.

#### Mnemonics and Learning Tricks:

There are no specific mnemonics or learning tricks for the Cause Effect Graphing Technique. However, it is important to understand the relationship between the inputs and outputs of the system. The cause and effect graph can be a useful tool to visualize this relationship.

#### Example:

Suppose we have a system that calculates the salary of an employee based on the number of hours worked and the hourly rate. The cause and effect graph for this system would look something like this:

```
              Number of Hours Worked
            /                        \
Minimum Value                     Maximum Value
          |                              |
        Output                         Output
          |                              |
          \                              /
             Hourly Rate
```

Based on this graph, we can identify the minimum and maximum values for the number of hours worked and the hourly rate. We can then determine the test cases that need to be executed and record the results to ensure that the software is functioning correctly.

In conclusion, the Cause Effect Graphing Technique is an effective method for functional testing. It helps to minimize the number of test cases required for testing and improve the quality of the software. By understanding the relationship between the inputs and outputs of the system, we can identify the root cause of a problem and determine the effect of a particular input on the system.
