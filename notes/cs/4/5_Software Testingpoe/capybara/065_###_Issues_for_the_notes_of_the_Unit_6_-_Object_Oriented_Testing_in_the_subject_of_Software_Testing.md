### Issues for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

Object-oriented testing is an essential part of software development. It helps to ensure the quality of the software and reduce the risk of defects. However, there are certain issues that need to be considered while testing object-oriented software. Here are some of the common issues that you need to keep in mind while studying the notes of Unit 6 of Object-Oriented Testing in the subject of Software Testing:

1. **Inheritance:** Inheritance is a fundamental concept in object-oriented programming. However, it can create issues while testing. The derived class may inherit defects from the base class, which can lead to unexpected behavior. Therefore, it is crucial to test both the base class and derived class thoroughly.

2. **Polymorphism:** Polymorphism is another essential concept in object-oriented programming. It allows objects of different classes to be treated as if they were of the same class. However, it can make testing more complex. It is essential to test all the possible combinations of objects to ensure that the software behaves as expected.

3. **Encapsulation:** Encapsulation is the practice of hiding the implementation details of an object from the outside world. While it can improve the quality of the software, it can also create issues while testing. It is essential to test all the public methods of the object thoroughly to ensure that they behave as expected.

4. **Abstraction:** Abstraction is the process of simplifying complex systems by breaking them down into smaller, more manageable parts. While it can make testing more manageable, it can also create issues. It is essential to test all the components of the system to ensure that they work together correctly.

5. **Dependencies:** Dependencies are the relationships between objects that determine how they interact with each other. Dependencies can create issues while testing because a defect in one object can affect the behavior of other objects. It is essential to test all the objects and their dependencies thoroughly to ensure that the software behaves as expected.

Mnemonic/learning trick: Remember the acronym "IPAED" to help you remember the issues related to object-oriented testing: Inheritance, Polymorphism, Abstraction, Encapsulation, and Dependencies.
