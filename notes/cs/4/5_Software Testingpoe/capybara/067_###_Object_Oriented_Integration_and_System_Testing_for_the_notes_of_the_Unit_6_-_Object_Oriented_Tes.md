### Object Oriented Integration and System Testing for the notes of the Unit 6 - Object Oriented Testing in the subject of Software Testing

Object-oriented integration testing and system testing are two critical components of software testing. These testing techniques help to ensure that the software system is functioning as expected and meets all the requirements specified by the stakeholders.

Object-Oriented Integration Testing:

Object-oriented integration testing is a type of testing that focuses on testing the integration of individual objects within the software system. In other words, it ensures that the objects work together correctly and seamlessly. Here are some important points to remember about object-oriented integration testing:

- It's a form of white-box testing where the tester has knowledge of the code and the system architecture.
- It is performed after unit testing and before system testing.
- The primary goal of object-oriented integration testing is to identify and fix defects in the system's object interactions.
- It includes testing the interaction between objects, testing the methods and properties of objects, and testing the inheritance and polymorphism features of objects.
- The testing is performed using test cases that are designed to validate the interactions between objects.

Mnemonics and Learning Tricks: 
- Think of each object as a puzzle piece that fits together with other puzzle pieces to create a complete picture. Object-oriented integration testing ensures that all the puzzle pieces fit together perfectly.

System Testing:

System testing is a type of testing that focuses on testing the entire software system as a whole. It is performed after integration testing and focuses on ensuring that the system meets all the requirements specified by the stakeholders. Here are some important points to remember about system testing:

- It's a form of black-box testing where the tester has no knowledge of the code and the system architecture.
- It is performed after object-oriented integration testing.
- The primary goal of system testing is to identify and fix defects in the system's functionality, reliability, and performance.
- It includes testing the overall functionality of the system, testing the system's behavior under different operating conditions, and testing the system's performance under heavy loads.
- The testing is performed using test cases that are designed to validate the system's functionality and performance.

Mnemonics and Learning Tricks: 
- Think of the software system as a machine with many different parts. System testing ensures that all the parts work together correctly and produce the desired output.

Advantages of Object-Oriented Integration and System Testing:
- Identifies defects at an early stage, which helps to reduce the overall cost of software development.
- Helps to ensure that the software system meets all the requirements specified by the stakeholders.
- Improves the reliability and performance of the software system.
- Helps to increase the confidence of the stakeholders in the software system.

Disadvantages of Object-Oriented Integration and System Testing:
- Requires a significant amount of time and resources to perform.
- Can be complex, especially for large software systems.
- Requires skilled testers who have a deep understanding of the software system and the testing techniques.

Examples of Object-Oriented Integration and System Testing:
- Testing the interaction between different modules in a software system.
- Testing the communication between different software components.
- Testing the performance of the software system under heavy loads.

Applications of Object-Oriented Integration and System Testing:
- Used in software development to ensure that the software system meets all the requirements specified by the stakeholders.
- Used in quality assurance to ensure that the software system is reliable and performs well under different operating conditions.
- Used in software maintenance to identify and fix defects in the software system.
