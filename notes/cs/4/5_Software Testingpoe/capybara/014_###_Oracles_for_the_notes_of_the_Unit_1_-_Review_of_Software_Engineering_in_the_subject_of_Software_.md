### Oracles for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

In software testing, oracles are mechanisms that help testers determine whether the output of a software system is correct or not. Oracles can be useful in detecting defects and identifying areas that require improvement. Here are some of the most common oracles that are used in software testing:

1. Specification-based oracles: These oracles use the software specifications as a basis for determining whether the output of a system is correct or not. This type of oracle is useful when the software requirements are well-defined and documented.

2. Code-based oracles: These oracles examine the source code of the software to determine whether the output is correct or not. This type of oracle is useful when the software has a well-defined structure and the code is well-documented.

3. Comparison-based oracles: These oracles compare the output of the software with a known standard or reference output to determine whether the output is correct or not. This type of oracle is useful when the expected output is well-defined and documented.

4. Experience-based oracles: These oracles rely on the experience and knowledge of the tester to determine whether the output of the software is correct or not. This type of oracle is useful when there are no well-defined specifications or standards for the software.

Mnemonics and learning tricks:

- To remember the different types of oracles, try using the acronym "SCCE" which stands for Specification-based, Code-based, Comparison-based, and Experience-based oracles.

- Another helpful trick is to think of oracles as a type of "quality control" for software testing. Just like a quality control inspector in a manufacturing plant, oracles help ensure that the software is functioning correctly and meeting the necessary standards.

In conclusion, oracles are an important part of software testing and can help testers identify defects and areas of improvement. By using different types of oracles, testers can ensure that the output of the software is correct and meets the necessary requirements.
