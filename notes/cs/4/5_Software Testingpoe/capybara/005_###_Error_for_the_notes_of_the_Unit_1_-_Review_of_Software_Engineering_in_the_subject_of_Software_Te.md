### Error for the notes of the Unit 1 - Review of Software Engineering in the subject of Software Testing

Errors are an important aspect of software testing as they help us identify defects in the software. In this section, we will discuss different types of errors that can occur during software testing.

1. **Syntax Errors:** These errors occur when there is a violation of programming language rules. For example, missing semicolons, brackets, or quotes in the code.

2. **Runtime Errors:** These errors occur when a program is running and it encounters an unexpected situation. For example, division by zero or trying to access an array index that does not exist.

3. **Logic Errors:** These errors occur when a program runs without crashing, but the output is not what was expected. For example, a program that calculates the average of a list of numbers but produces the wrong result due to a mistake in the formula.

4. **Semantic Errors:** These errors occur when the program is syntactically correct and produces the expected output, but the output is not what was intended. For example, a program that sorts a list of numbers in ascending order but produces the result in descending order.

Mnemonic: Remember the acronym "SRLS" - Syntax, Runtime, Logic, and Semantic errors.

Learning Trick: Practice writing code and intentionally introduce errors of each type, then try to identify and fix them. This will help you become more familiar with common errors and develop your problem-solving skills.

In conclusion, understanding different types of errors is crucial for software testers as it helps them identify and fix defects in the software. Remembering the mnemonic "SRLS" and practicing writing code with intentional errors can help you prepare for exams and become a better software tester.
