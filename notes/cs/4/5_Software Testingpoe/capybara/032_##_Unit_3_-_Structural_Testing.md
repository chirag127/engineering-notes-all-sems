## Unit 3 - Structural Testing

Structural Testing is a type of testing that focuses on the internal structure of the software being tested. It is also known as "White Box Testing" or "Glass Box Testing". In this type of testing, the tester has knowledge of the internal workings of the software, including its code, architecture, and design.

### Types of Structural Testing

1. Statement Coverage Testing - In this type of testing, the tester tries to ensure that every statement in the code is executed at least once during the testing process.

2. Branch Coverage Testing - In this type of testing, the tester ensures that all possible branches in the code are executed at least once during the testing process.

3. Path Coverage Testing - In this type of testing, the tester ensures that every possible path through the code is executed at least once during the testing process.

4. Condition Coverage Testing - In this type of testing, the tester ensures that every possible condition in the code is tested, including both true and false conditions.

### Advantages of Structural Testing

1. It helps to identify errors and defects in the early stages of development, which saves time and money in the long run.

2. It ensures that the code is fully tested and meets all requirements.

3. It helps to improve the overall quality of the software.

4. It provides a way to measure the effectiveness of the testing process.

### Disadvantages of Structural Testing

1. It can be time-consuming and expensive to perform.

2. It requires a high level of technical expertise and knowledge of the software being tested.

3. It may not be practical for all types of software.

### Learning Tricks for Structural Testing

1. Mnemonic - STP (Statement, Branch, Path) - This helps to remember the different types of Structural Testing.

2. Mnemonic - TICC (True, False, Invalid, Conditional, Combinatorial) - This helps to remember the different types of conditions that need to be tested in Condition Coverage Testing.

3. Use code coverage tools to help automate the testing process and identify areas of the code that need to be tested.

### Examples of Structural Testing

1. Unit Testing - This is a type of testing that focuses on testing individual pieces of code, such as functions or methods.

2. Integration Testing - This is a type of testing that focuses on testing how different pieces of code work together.

### Applications of Structural Testing

1. It is commonly used in the development of software applications, including desktop, web, and mobile applications.

2. It is also used in the development of embedded systems, such as those found in automobiles and medical devices.

In conclusion, Structural Testing is an important type of testing that helps to ensure the quality and reliability of software applications. By understanding the different types of Structural Testing and using learning tricks such as mnemonics, testers can improve their testing process and identify errors and defects in the early stages of development.
