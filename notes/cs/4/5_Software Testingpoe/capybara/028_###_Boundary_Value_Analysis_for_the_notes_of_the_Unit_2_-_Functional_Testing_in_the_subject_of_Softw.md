### Boundary Value Analysis for the notes of the Unit 2 - Functional Testing in the subject of Software Testing

Boundary Value Analysis (BVA) is a black box testing technique that focuses on testing the boundaries between valid and invalid input values. It is a very effective technique that can help identify defects in the software system.

#### Advantages:
- It helps in identifying defects that are caused by boundary values.
- It helps in reducing the number of test cases that need to be executed.
- It helps in improving the quality of the software system.

#### Disadvantages:
- It is time-consuming to determine the boundary values.
- It may not be applicable to all types of software systems.

#### Mnemonic:
- Remember the acronym "DEB" which stands for "Don't cross the Edge or the Boundary".

#### Steps for Boundary Value Analysis:
1. Determine the input values for the software system.
2. Identify the minimum and maximum values for each input.
3. Identify the boundary values for each input, which are the values immediately before and after the minimum and maximum values.
4. Create test cases using these values.

#### Example:
Suppose we have a software system that accepts a number between 1 and 100. The minimum value is 1, the maximum value is 100, and the boundary values are 0, 1, 99, and 100. We can create test cases using these values, such as 0, 1, 2, 99, 100, and 101.

#### Application:
Boundary Value Analysis can be applied to various types of software systems, such as:
- Financial systems that deal with money values.
- Flight control software that deals with altitude, speed, and distance.
- Online shopping systems that deal with quantity and price. 

#### Conclusion:
Boundary Value Analysis is a very useful technique that can help in identifying defects in the software system. It is important to determine the boundary values accurately and create test cases accordingly. By using this technique, we can reduce the number of test cases and improve the quality of the software system.
