### Introduction to machine learning for the notes of the Unit 1 - INTRODUCTION in the subject of Deep Learning

- Machine learning is a branch of artificial intelligence that deals with creating and using algorithms and models that can learn from data and make predictions or decisions.
- Machine learning can be divided into three main types: supervised learning, unsupervised learning, and reinforcement learning.
- Supervised learning is the process of learning a function that maps an input to an output based on example input-output pairs. It requires labeled data, which means the desired output for each input is known. Examples of supervised learning tasks are classification, regression, and ranking.
- Unsupervised learning is the process of finding patterns or structure in unlabeled data, without any guidance from the output. It can be used for tasks such as clustering, dimensionality reduction, anomaly detection, and generative modeling.
- Reinforcement learning is the process of learning how to act in an environment by interacting with it and receiving feedback from the consequences of the actions. It can be used for tasks such as control, optimization, and game playing.
- Deep learning is a subfield of machine learning that uses multiple layers of nonlinear transformations to learn complex and high-level features from data. It can be applied to various types of data, such as images, text, speech, and graphs.
- Deep learning models are often composed of artificial neural networks, which are computational units that mimic the structure and function of biological neurons. Neural networks can be trained using various algorithms, such as gradient descent, backpropagation, and stochastic gradient descent.
- A mnemonic to remember the three types of machine learning is SURE: Supervised, Unsupervised, and REinforcement learning.
