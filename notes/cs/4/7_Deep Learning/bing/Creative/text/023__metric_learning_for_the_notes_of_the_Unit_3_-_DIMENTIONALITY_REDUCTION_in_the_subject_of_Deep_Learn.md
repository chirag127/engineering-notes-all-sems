### Metric Learning

- Metric learning is a branch of machine learning that aims at automatically constructing task-specific distance metrics from (weakly) supervised data, in a machine learning manner.
- The learned distance metric can then be used to perform various tasks (e.g., k-NN classification, clustering, information retrieval).
- Metric learning can be divided into two main categories depending on the type of supervision available about the training data:
  - Supervised learning: the algorithm has access to a set of data points, each of them belonging to a class (label) as in a standard classification problem. The goal is to learn a distance metric that puts points with the same label close together while pushing away points with different labels.
  - Weakly supervised learning: the algorithm has access to a set of data points with supervision only at the tuple level (typically pairs, triplets, or quadruplets of data points). A classic example of such weaker supervision is a set of positive and negative pairs: in this case, the goal is to learn a distance metric that puts positive pairs close together and negative pairs far away.
- In the metric-learn package, all algorithms currently implemented learn so-called Mahalanobis distances. A Mahalanobis distance is a Euclidean distance after a linear transformation of the feature space defined by a real-valued parameter matrix L of shape (num_dims, n_features) where n_features is the number features describing the data. Mahalanobis distance metric learning can thus be seen as learning a new embedding space of dimension num_dims. Note that when num_dims is smaller than n_features, this achieves dimensionality reduction.
- Deep metric learning, which tries to increase the distance between similar data while decreasing the distance between dissimilar samples, is directly related to the distance between samples. The metric loss function has been used in deep learning to carry out this process. Deep metric learning provides problem-based solutions that are caused by learning from raw data by utilizing deep architectures and finding embedded feature similarity through nonlinear subspace learning.
- Some of the common deep metric learning methods are:
  - Reconstruction autoencoders and supervised loss functions: these methods use an autoencoder to learn a low-dimensional representation of the data and then apply a supervised loss function (e.g., contrastive loss, triplet loss, etc.) to optimize the distance metric in the latent space.
  - Siamese networks and its various loss functions: these methods use a pair of neural networks with shared weights to learn a distance metric between two inputs. The networks are trained with a loss function that encourages the distance to be small for similar inputs and large for dissimilar inputs (e.g., contrastive loss, triplet loss, etc.).
  - Deep discriminant analysis methods: these methods are based on Fisher discriminant analysis, which seeks to maximize the between-class scatter and minimize the within-class scatter of the data. The methods use a neural network to learn a nonlinear transformation of the data and then apply a discriminant criterion to optimize the distance metric in the transformed space.
  - Multi-modal deep metric learning: these methods aim to learn a distance metric that can measure the similarity between data from different modalities (e.g., images, text, audio, etc.). The methods use a neural network to learn a common representation for the different modalities and then apply a loss function to optimize the distance metric in the shared space.
  - Geometric metric learning by neural networks: these methods aim to learn a distance metric that respects the geometric structure of the data manifold. The methods use a neural network to learn a Riemannian metric that adapts to the local curvature of the data manifold and then apply a loss function to optimize the distance metric in the manifold space.
  - Few-shot metric learning: these methods aim to learn a distance metric that can generalize to new classes with few examples. The methods use a neural network to learn a feature extractor that can produce discriminative embeddings for the data and then apply a classifier that can adapt to the new classes based on the distance metric in the embedding space.
