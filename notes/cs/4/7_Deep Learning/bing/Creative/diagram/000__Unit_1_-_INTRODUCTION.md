There are several tools and methods to draw ASCII diagrams, such as Asciio, DrawIt, Asciiflow, JavE, and Graph::Easy. Here is an example of how to draw a basic architecture diagram using Graph::Easy in markdown:

## Unit 1 - INTRODUCTION

```text
+-----------------+     +-----------------+     +-----------------+
|                 |     |                 |     |                 |
|    Web Server   |<--->|   Application   |<--->|    Database     |
|                 |     |     Server      |     |     Server      |
+-----------------+     +-----------------+     +-----------------+
```

This diagram shows three components of a web application: a web server, an application server, and a database server. They are connected by bidirectional arrows, indicating that they can communicate with each other.
