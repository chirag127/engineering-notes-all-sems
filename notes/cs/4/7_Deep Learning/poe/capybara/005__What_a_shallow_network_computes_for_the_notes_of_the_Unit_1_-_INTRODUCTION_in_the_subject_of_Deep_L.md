### What a Shallow Network Computes for the Notes of the Unit 1 - INTRODUCTION in the Subject of Deep Learning

When it comes to deep learning, shallow networks can still be useful for certain tasks. Here are some key things to understand about what a shallow network computes:

- A shallow network typically only has one hidden layer, which means it's not as complex as a deep network with multiple layers.
- The purpose of a shallow network is to learn a linear combination of input features, which can be used to make predictions or classify data.
- The computation that a shallow network performs involves taking the weighted sum of the input features, passing that sum through an activation function, and then outputting a result.
- The activation function is a key part of the computation, as it allows the network to introduce non-linearity into the model. Common activation functions include sigmoid, ReLU, and tanh.
- The weights of the network are learned through a process called backpropagation, which involves adjusting the weights based on the error between the predicted output and the true output.
- Shallow networks are often used for simpler tasks, such as linear regression, binary classification, or image recognition with small images.
- While deep networks are generally more powerful and can handle more complex tasks, shallow networks can still be useful in certain situations where a simpler model is sufficient.

Overall, understanding what a shallow network computes is an important part of learning about deep learning, as it helps to build a foundation for understanding more complex models.
