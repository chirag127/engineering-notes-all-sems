
### Logistic Regression for the Notes of Unit 1 - Introduction in Deep Learning

* Logistic regression is a supervised learning algorithm used in classification problems. It is used to predict a categorical dependent variable based on one or more independent variables.
* Logistic regression models the probability of an event occurring, such as the probability of a person being diagnosed with a certain disease.
* Logistic regression is used in deep learning to classify data into different categories, such as predicting whether an image contains a cat or a dog.
* Logistic regression works by mapping the input data to a set of weights and then applying a sigmoid or logistic function to the weighted sum. The output of the logistic function is a probability between 0 and 1, which can be used to classify the data into one of two categories.
* Logistic regression is used in deep learning to solve classification problems. It is a powerful tool for predicting the probability of an event occurring, such as whether a person has a certain disease or not.
