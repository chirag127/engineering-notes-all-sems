
### Metric Learning for the Notes of the Unit 3 - Dimensionality Reduction in the Subject of Deep Learning

* Metric learning is a machine learning technique that focuses on learning a distance metric between data points. It is used to measure the similarity and dissimilarity between data points in a dataset.
* The goal of metric learning is to find a distance metric that best describes the relationships between data points. This can be used to classify data points into different classes, or to cluster similar data points together.
* Dimensionality reduction is a process of reducing the number of features or dimensions in a dataset. It is used to reduce the complexity of the data and make it easier to analyze.
* Dimensionality reduction techniques include principal component analysis (PCA), linear discriminant analysis (LDA), and nonlinear dimensionality reduction (NLDR).
* PCA is a technique that finds the directions of maximum variance in a dataset. It reduces the dimensionality of the data by projecting it onto a lower dimensional space.
* LDA is a supervised technique that finds the directions of maximum class separability. It is used to reduce the dimensionality of the data while preserving the class structure.
* NLDR is an unsupervised technique that finds the directions of maximum nonlinearity. It is used to reduce the dimensionality of the data while preserving the nonlinear structure.
