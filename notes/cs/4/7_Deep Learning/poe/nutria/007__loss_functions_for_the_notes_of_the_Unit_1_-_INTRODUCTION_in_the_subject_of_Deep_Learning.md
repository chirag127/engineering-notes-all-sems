
### Loss Functions for the Notes of the Unit 1 - INTRODUCTION in the Subject of Deep Learning

* Loss functions are a measure of how well a given model is able to predict the desired output.
* Loss functions are used to optimize the parameters of the model to minimize the error between the predicted output and the desired output.
* Loss functions can be divided into two categories: regression and classification. 
* Regression loss functions measure the difference between the predicted output and the desired output. Examples of regression loss functions include mean squared error (MSE), mean absolute error (MAE), and Huber loss.
* Classification loss functions measure the probability of a given model predicting the correct class label. Examples of classification loss functions include log loss, cross-entropy loss, and hinge loss.
* In deep learning, loss functions are used to optimize the parameters of the model to minimize the error between the predicted output and the desired output.
* The choice of loss function depends on the task at hand. For example, mean squared error is often used for regression tasks, while log loss is often used for classification tasks.
