
### Training a Network for Unit 1 - Introduction to Deep Learning 

1. Deep learning is a subset of machine learning that uses neural networks to create powerful models that can be used to solve complex problems.

2. Neural networks are composed of layers of interconnected nodes, with each layer performing a specific task.

3. Each node in a neural network takes inputs from the previous layer and produces an output which is passed on to the next layer.

4. The weights of the connections between the nodes are adjusted during training in order to minimize the error between the predicted output and the actual output.

5. Training a neural network involves providing the network with a set of input data and the corresponding desired outputs.

6. The network is then trained using an optimization algorithm such as gradient descent in order to adjust the weights of the connections between the nodes.

7. Once the network is trained, it can be used to predict the output for new input data.

8. Deep learning can be used for a variety of tasks such as image recognition, natural language processing, and autonomous driving.
