
### Convolutional Networks for the Notes of Unit 2 - DEEP NETWORKS in Deep Learning

1. Convolutional networks are a type of deep learning neural network used for image classification and other computer vision tasks.

2. Convolutional networks are composed of multiple layers of neurons, each of which is connected to the previous and next layer by a convolutional filter.

3. The convolutional filter is used to extract features from the input image and pass them to the next layer.

4. The convolutional layers are arranged in a hierarchical manner, with each layer extracting more complex features from the input image.

5. The convolutional layers can be combined with other types of layers, such as fully connected layers, to form a deeper network.

6. Convolutional networks are trained using backpropagation and gradient descent, with the goal of minimizing the total loss of the network.

7. Convolutional networks are widely used in computer vision applications such as object detection, image segmentation, and image recognition.
