## Unit 4 - TECHNOLOGY I – ANDROID
Android is a mobile operating system developed by Google. It is based on the Linux kernel and designed primarily for touchscreen mobile devices such as smartphones and tablets. Android offers a unified approach to application development for mobile devices which means developers can create a single application that will run on various devices. Android provides access to a wide range of useful libraries and tools that can be used to build rich, innovative applications. Some of the key features of Android include support for multimedia, GPS, and accelerometer, and an extensive library of pre-built software components. Additionally, Android provides a rich development environment that includes an emulator, debugging tools, and a plugin for the Eclipse integrated development environment.
