### Location aware applications using Core Location and Map Kit for the notes of the Unit 5 - TECHNOLOGY II –iOS in the subject of Design & Development Of Applications
Location aware applications use the Core Location and Map Kit frameworks to access the device's GPS and other location services. These frameworks allow developers to build applications that can determine the user's current location, track their movements, and display maps and other location-based information.

Core Location provides the basic location services, including GPS, cell tower triangulation, and Wi-Fi positioning. It can also provide heading information, such as the direction the device is facing, and altitude information.

Map Kit provides a map display and a variety of map-based tools, such as the ability to add annotations (markers) to the map, display directions, and perform geocoding (converting a street address to a set of coordinates).

The two frameworks can be used together to create a wide range of location-based applications, such as navigation apps, social networking apps, and location-based games. Additionally, the Core Location and Map Kit frameworks can be used to access location data from third-party services, such as Google Maps and Foursquare.
