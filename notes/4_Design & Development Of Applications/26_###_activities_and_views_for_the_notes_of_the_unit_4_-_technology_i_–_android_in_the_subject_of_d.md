### Activities and views for the notes of the Unit 4 - TECHNOLOGY I – ANDROID in the subject of Design & Development Of Applications
- Activities: 
  - An activity is a single, focused task that a user can perform, such as sending an email or taking a photo. 
  - It represents the UI of an app and is responsible for handling user interactions. 
  - An Android app can have multiple activities, and users can navigate between them using intents.

- Views: 
  - A view is a widget that displays data and enables user interaction. 
  - Examples of views include buttons, text fields, and images. 
  - Views are organized into a hierarchy, and can be nested to create complex user interfaces.
  - Views are associated with activities, and the activity is responsible for managing the views and handling user interactions.
