### Android architecture for the notes of the Unit 4 - TECHNOLOGY I – ANDROID in the subject of Design & Development Of Applications
Android architecture consists of 4 main layers:
1. Linux Kernel: provides low-level system services such as memory management, process management, network stack, and driver model.
2. Libraries: provide higher-level services such as graphic rendering, database access, and media codecs.
3. Android Framework: includes the Activity Manager, Content Providers, and Resource Manager, among others, to manage application components and provide a standard set of APIs.
4. Android Apps: built using the APIs provided by the framework, run on top of the framework and interact with the underlying services and hardware.
