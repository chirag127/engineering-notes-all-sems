### Introduction to Objective C for the notes of the Unit 5 - TECHNOLOGY II –iOS in the subject of Design & Development Of Applications
Objective-C is an object-oriented, general-purpose programming language used for developing applications on Apple's Mac OS X and iOS operating systems. It was created in the early 1980s and is a high-level language, which means it is easy to read and write compared to low-level languages like Assembly or C. Objective-C is a dynamically typed language and uses message passing instead of function calls to interact with objects. It is also known for its use of dynamic binding, which allows for late binding of objects at runtime. Objective-C is widely used for developing applications for Apple's platforms and is a key component of the iOS software development kit (SDK).

In this unit, you will learn the basics of Objective-C programming, including syntax, variables, data types, control structures, and object-oriented programming concepts like inheritance and polymorphism. You will also learn how to use the Objective-C runtime library and the Foundation framework, which provides a set of basic data structures and algorithms for use in Objective-C applications. Additionally, you will learn how to use the Xcode development environment to create, build, and debug Objective-C applications.
