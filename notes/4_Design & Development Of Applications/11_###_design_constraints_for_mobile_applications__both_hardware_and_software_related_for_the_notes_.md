### Design constraints for mobile applications, both hardware and software related for the notes of the Unit 2 - BASIC DESIGN in the subject of Design & Development Of Applications
1. Hardware constraints:
- Screen size and resolution
- Processor speed and memory
- Battery life and charging time
- Network connectivity and speed
- Camera and other sensors

2. Software constraints:
- Operating system compatibility and version
- Application size and storage requirements
- User interface design and navigation
- Performance and response time
- Security and privacy considerations
