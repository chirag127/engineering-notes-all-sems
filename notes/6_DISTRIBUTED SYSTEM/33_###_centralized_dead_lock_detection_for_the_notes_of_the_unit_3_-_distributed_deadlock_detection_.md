### centralized dead lock detection for the notes of the Unit 3 - Distributed Deadlock Detection in the subject of DISTRIBUTED SYSTEM
Centralized deadlock detection is a method for detecting deadlocks in a distributed system. In this method, a central coordinator is responsible for detecting deadlocks. The coordinator periodically checks the state of the system and determines if any deadlocks exist. If a deadlock is detected, the coordinator takes action to resolve the deadlock. This method is simple and effective, but it can be slow and may not scale well to large systems. Additionally, if the coordinator fails, the entire system may fail.
