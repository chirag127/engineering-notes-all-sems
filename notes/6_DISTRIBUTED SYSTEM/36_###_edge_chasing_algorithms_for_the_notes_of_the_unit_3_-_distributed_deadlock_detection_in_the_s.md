### edge chasing algorithms for the notes of the Unit 3 - Distributed Deadlock Detection in the subject of DISTRIBUTED SYSTEM
Edge Chasing Algorithm is a distributed algorithm used to detect deadlocks in a distributed system. It works by having each process send a message to its neighbors to check if they are holding any resources that the process needs. If a process finds that it is waiting for a resource that is held by another process, it sends a message to that process to request the resource. The process that receives the request then checks if it is holding any resources that the process requesting the resource needs. If it is, it sends a message to that process to request the resource. This process continues until either a cycle is found or all processes have been checked. If a cycle is found, a deadlock has occurred. The algorithm terminates when all processes have been checked, and no deadlocks have been found.
