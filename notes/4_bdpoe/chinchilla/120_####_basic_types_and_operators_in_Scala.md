#### Basic Types and Operators in Scala

Scala is a statically typed language, which means that variables must be declared with a specific type. Scala's type system is based on the Java Virtual Machine (JVM) types, but it includes some additional types that are not present in Java. In this section, we will cover the basic types and operators in Scala.

##### Basic Types

Scala has several built-in data types, including:

1. Integers - `Int`: The `Int` type represents integers, which are whole numbers without decimal places. Scala supports integers in the range `-2147483648` to `2147483647`.

2. Floating-point numbers - `Float` and `Double`: The `Float` and `Double` types represent floating-point numbers, which are numbers with decimal places. `Float` represents single-precision floating-point numbers, while `Double` represents double-precision floating-point numbers.

3. Booleans - `Boolean`: The `Boolean` type represents logical values, which can be either `true` or `false`.

4. Characters - `Char`: The `Char` type represents a single character, such as a letter or a symbol.

5. Strings - `String`: The `String` type represents a sequence of characters.

6. Null - `Null`: The `Null` type represents a null or empty reference.

7. Nothing - `Nothing`: The `Nothing` type represents a value that can never be produced.

8. Any - `Any`: The `Any` type is the supertype of all other types in Scala.

9. AnyRef - `AnyRef`: The `AnyRef` type is the supertype of all reference types in Scala.

##### Operators

Scala supports a wide range of operators, including arithmetic, relational, and logical operators. Some of the most commonly used operators in Scala are:

1. Arithmetic Operators: `+`, `-`, `*`, `/`, `%`.

2. Relational Operators: `<`, `>`, `<=`, `>=`, `==`, `!=`.

3. Logical Operators: `&&`, `||`, `!`.

4. Bitwise Operators: `&`, `|`, `^`, `~`, `<<`, `>>`, `>>>`.

5. Assignment Operators: `=`, `+=`, `-=`, `*=`, `/=`, `%=`.
