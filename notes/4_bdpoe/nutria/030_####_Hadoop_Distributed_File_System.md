
#### Hadoop Distributed File System

- The Hadoop Distributed File System (HDFS) is a distributed, scalable, and portable file-system written in Java for the Hadoop framework. 
- HDFS stores data on commodity machines, providing very high aggregate bandwidth across the cluster. 
- HDFS is designed to reliably store very large files across machines in a large cluster. 
- It stores each file as a sequence of blocks, all blocks in a file except the last block are the same size.
- HDFS is designed to stream data efficiently from the disk.
- HDFS is fault tolerant, it stores each block of the file on multiple nodes, so even if one node fails, the data will still be available.
- HDFS is highly scalable, it can scale up to hundreds of nodes in a single cluster.
- HDFS is designed to be easily portable across different hardware and software platforms.
- HDFS provides a high throughput access to application data and is suitable for applications that have large data sets.

Mnemonic:
HDFS stands for "Hadoop Distributed File System".
