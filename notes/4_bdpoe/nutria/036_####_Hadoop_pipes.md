
#### Hadoop Pipes

* It enables applications written in C++ to use the Hadoop Distributed File System (HDFS) and the MapReduce framework to process data stored in HDFS.
* The Hadoop Pipes API provides an easy-to-use interface for applications written in C++ to access the Hadoop Distributed File System (HDFS) and the MapReduce framework. 
* It also provides a way for applications to run in parallel on multiple nodes in a Hadoop cluster.
* Hadoop Pipes provides a set of functions that allow applications to read and write data from HDFS and to run MapReduce jobs. 
* It also provides an interface for applications to access the distributed cache, which is used to store and share data across nodes in a Hadoop cluster.
* Hadoop Pipes is a powerful tool for applications that need to process large amounts of data stored in HDFS. 
* It allows applications to take advantage of the scalability and fault tolerance of the Hadoop cluster, and to process data efficiently and in parallel.
