

# Apache Hadoop

Apache Hadoop is an open-source software framework for distributed storage and distributed processing of very large data sets on computer clusters built from commodity hardware. It is designed to scale up from single servers to thousands of machines, each offering local computation and storage.

Hadoop is based on the MapReduce programming model and can be used to process and analyze large datasets stored in HDFS (Hadoop Distributed File System). It is designed to be highly reliable and fault-tolerant, and can be used for a wide range of applications, including data mining, web indexing, data warehousing, and log processing.

Mnemonics and Learning Tricks:

* **H**adoop **A**rchitecture: Hadoop consists of a master node and a set of worker nodes. The master node is responsible for scheduling tasks and managing resources, while the worker nodes are responsible for executing tasks and storing data.
* **D**ata Storage: HDFS (Hadoop Distributed File System) is the primary storage system used by Hadoop. It stores data in a distributed and fault-tolerant manner.
* **F**ault Tolerance: Hadoop is designed to be highly fault-tolerant. If a node fails, the system will automatically re-replicate the data and continue to process jobs.
* **S**calability: Hadoop is designed to be highly scalable. It can scale up from single servers to thousands of machines, each offering local computation and storage.
