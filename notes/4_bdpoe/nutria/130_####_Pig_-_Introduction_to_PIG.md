

#### Pig - Introduction to PIG

* Apache Pig is a high-level platform for creating programs that run on Apache Hadoop. It is designed to make the process of writing programs easier by allowing the user to focus on the analysis of data instead of the details of MapReduce.
* Pig Latin is a data flow language used to express data analysis programs. It is the language used to write Pig programs.
* Pig programs are made up of a series of operations or transformations that are applied to the input data to produce output.
* Pig programs are executed on a Hadoop cluster and are translated into a series of MapReduce jobs.
* Pig can be used for ETL (Extract, Transform, Load) operations, data processing, data analysis, and machine learning.
* Pig provides a rich set of operators for data manipulation and analysis.
* Pig provides built-in operators for common tasks such as filtering, sorting, joining, and grouping.
* Pig has a rich set of functions for data analysis, including statistical functions, mathematical functions, string functions, date functions, and more.
* Pig is extensible, allowing users to write their own functions in Java, Python, or JavaScript.
* Pig is easy to use and provides a powerful platform for data analysis.
* Mnemonic: PIG stands for Platform for Interacting with Grids.
