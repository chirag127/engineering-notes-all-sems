
### Types of Digital Data in Big Data

1. Structured Data: Structured data is data that is organized in a specific way and is easy to search and analyze. This type of data is usually stored in a relational database and can be accessed through SQL queries. Examples of structured data include customer records, financial transactions, and inventory records.

2. Semi-structured Data: Semi-structured data is data that is organized in a way that is not as structured as structured data, but still has some structure. This type of data is usually stored in a NoSQL database and can be accessed through APIs. Examples of semi-structured data include emails, XML files, and JSON documents.

3. Unstructured Data: Unstructured data is data that is not organized in any specific way. This type of data is usually stored in a file system and can be accessed through file-based APIs. Examples of unstructured data include text documents, images, audio files, and video files.

4. Streaming Data: Streaming data is data that is continuously generated and is often processed in real-time. This type of data is usually processed using stream processing frameworks such as Apache Kafka and Apache Storm. Examples of streaming data include stock market data, sensor data, and log data.

Mnemonic: 
S-Structured, 
S-Semi-structured, 
U-Unstructured,
