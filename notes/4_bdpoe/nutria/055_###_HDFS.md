
### HDFS

- HDFS stands for Hadoop Distributed File System. It is an open source distributed file system designed to store large amounts of data on commodity hardware.
- HDFS is designed to be fault tolerant, meaning it can recover from hardware failures. It also supports high availability, allowing applications to read and write data even when part of the system is down.
- HDFS is able to scale from a single server to thousands of machines, each offering local storage and computation.
- HDFS provides a high throughput access to data, allowing applications to read and write large amounts of data quickly and reliably.
- HDFS is designed to be used with MapReduce, a programming model for processing large amounts of data in parallel.
- HDFS is highly configurable and can be used in a variety of ways, including as a storage system for Hadoop clusters, as a data lake for analytics applications, or as a distributed file system for a variety of applications.

Mnemonics and Learning Tricks: 
- HDFS stands for Hadoop Distributed File System. 
- HDFS is designed to be Highly Durable and Fault Tolerant. 
- HDFS provides High Availability and Throughput access to data. 
- HDFS is Highly Configurable and can be used for a variety of applications.
