

#### Map Reduce Scripts in Hive

* Map Reduce is a programming model used to process large data sets with a parallel, distributed algorithm on a cluster.
* Hive is a data warehouse software that facilitates querying and managing large datasets stored in Hadoop.
* Map Reduce scripts in Hive are used to process data stored in the Hive warehouse.
* Hive provides a SQL-like language called HiveQL that is used to write Map Reduce scripts.
* Map Reduce scripts in Hive can be used to perform operations such as filtering, sorting, aggregation, and joining.
* Hive also provides a number of built-in functions that can be used in Map Reduce scripts, such as mathematical functions, string functions, date functions, and type conversion functions.
* Hive also provides a number of UDFs (User Defined Functions) that can be used to extend the functionality of Map Reduce scripts.
* Map Reduce scripts can be executed in Hive using the `hive` command.
* The output of Map Reduce scripts in Hive can be stored in the Hive warehouse or in external files.
