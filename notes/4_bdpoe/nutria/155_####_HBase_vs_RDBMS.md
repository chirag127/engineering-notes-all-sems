

#### HBase vs RDBMS

* HBase is a NoSQL database that is used for non-relational data storage, while RDBMS is a relational database that is used for relational data storage.
* HBase is designed to store large amounts of data in a distributed environment, while RDBMS is designed to store smaller amounts of data in a centralized environment.
* HBase is a column-oriented database, while RDBMS is a row-oriented database. 
* HBase is a schema-less database, while RDBMS is a schema-based database.
* HBase provides low latency and high throughput when dealing with large amounts of data, while RDBMS provides low latency and low throughput when dealing with smaller amounts of data.
* HBase is more suitable for applications that require quick reads and writes, while RDBMS is more suitable for applications that require complex queries and transactions.
* HBase is more suitable for applications that require high availability, while RDBMS is more suitable for applications that require data integrity.
* HBase is more suitable for applications that require scalability and flexibility, while RDBMS is more suitable for applications that require data consistency and data accuracy.
* HBase is an open source database, while RDBMS is a proprietary database.
* HBase is a distributed database, while RDBMS is a centralized database.
* HBase is more suitable for applications that require real-time data processing, while RDBMS is more suitable for applications that require batch processing.
