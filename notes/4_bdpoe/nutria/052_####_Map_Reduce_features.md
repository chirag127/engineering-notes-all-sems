
#### Map Reduce Features

* Map Reduce is a programming model and an associated implementation for processing and generating large data sets with a parallel, distributed algorithm on a cluster.
* It is an open-source framework used to process large data sets across clusters of computers using simple programming models.
* The MapReduce model consists of two main phases: the Map phase and the Reduce phase.
* The Map phase takes a set of data and converts it into another set of data, where individual elements are broken down into tuples (key/value pairs).
* The Reduce phase takes the output from the Map phase and combines the data tuples into a smaller set of tuples.
* MapReduce can be used to perform a wide variety of data processing tasks, such as counting the frequency of words in a large document, sorting a large data set, or computing the average of a large data set.
* MapReduce is a powerful tool for distributed computing, as it is able to process large amounts of data in parallel, across multiple machines.
* It is also highly fault tolerant, as it is able to detect and recover from machine failures.

Mnemonics and Learning Tricks:
* Map: Map the data into key/value pairs
* Reduce: Reduce the data set by combining the key/value pairs
